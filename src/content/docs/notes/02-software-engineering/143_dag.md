## 한 줄 본질
- 복잡한 작업 흐름에서 상호 참조로 인한 교착상태(Deadlock)나 무한 루프 위험 병목 → 한쪽 방향으로만 화살표가 이어지고 어떤 노드에서도 출발하여 자기 자신으로 되돌아오는 사이클이 없는 그래프 자료구조 / 동적 사이클 삽입 검증 오버헤드

## 핵심 그림
```text
+-------------------------------------------------------------------------+
|                  DAG(Directed Acyclic Graph) 구조 및 위상 정렬          |
+-------------------------------------------------------------------------+
|                                                                         |
|         [ A ] ─────────> [ B ] ─────────> [ D ]                         |
|           │                │                ▲                           |
|           │                v                │                           |
|           └────────────> [ C ] ─────────────┘                           |
|                                                                         |
|  * 특징:                                                                |
|    - 어떤 경로를 따라가도 자기 자신으로 돌아오는 순환(Cycle)이 없음       |
|    - [C]는 [A]와 [B] 두 부모를 가질 수 있음 (일반 트리와 다른 점)      |
|                                                                         |
|  * 위상 정렬 순서 (선행 의존성 준수) : A ──> B ──> C ──> D             |
|                                                                         |
|  [ 주요 활용 분야 ]                                                     |
|    1. 빌드 도구 (Make, Gradle) : 컴파일 의존성 순서 결정               |
|    2. 데이터 파이프라인 (Apache Airflow) : ETL 배치 작업 오케스트레이션 |
|    3. 버전 관리 (Git) : 커밋 브랜치 및 머지 히스토리 DAG 추적          |
+-------------------------------------------------------------------------+
```

## 핵심 용어
- 위상 정렬(Topological Sort): DAG의 모든 노드를 방향성에 거스르지 않도록(선행 작업이 후행 작업보다 반드시 앞에 오도록) 일렬로 나열하는 정렬 알고리즘 ($O(V+E)$)
- 진입 차수(In-degree): 특정 노드로 들어오는 방향성 간선의 개수로, 진입 차수가 0인 노드는 선행 조건이 없어 즉시 실행 가능한 작업을 의미함

## 핵심 통찰
- DAG의 가장 본질적인 공학적 가치는 "인과관계(Causality)와 선후 의존성의 표현"이며, 사이클이 없다는 수학적 보장이 있기에 비로소 데드락 없는 병렬 연산 스케줄링이 가능함
- 빅데이터 엔진인 Apache Spark는 RDD(Resilient Distributed Dataset)의 변환 연산을 즉시 실행하지 않고 DAG로 그려둔 뒤(Lazy Evaluation), 셔플링(Shuffle)을 최소화하는 최적의 실행 계획으로 파이프라이닝함
- 블록체인이 트랜잭션을 1차원 선형 체인으로 묶어 TPS(초당 처리량)가 10~30건에 갇히는 반면, DAG 기반 분산원장(IOTA Tangle, Hedera Hashgraph)은 이전의 여러 트랜잭션을 동시에 참조 승인하여 수만 TPS로 수평 확장함

## 이웃 토픽과 구분
- DAG vs 트리(Tree): 트리는 모든 자식 노드가 단 하나의 부모 노드만 가질 수 있지만, DAG는 사이클만 없다면 하나의 노드가 여러 개의 부모 노드로부터 진입 간선을 가질 수 있음
