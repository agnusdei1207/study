## 핵심 그림
```text
+-------------------------------------------------------------------------+
|                  반응형 웹 디자인(RWD)의 3대 기술 기둥                   |
+-------------------------------------------------------------------------+
|                                                                         |
|      1. 미디어 쿼리 (Media Queries) : CSS3 조건문 분기                   |
|         @media screen and (min-width: 768px) { ... }                    |
|                        │                                                |
|                        v                                                |
|      2. 가변 그리드 (Fluid Grid) : 고정 픽셀(px) 탈피, 백분율(%) 비례 배치|
|         - 목표 크기 ÷ 맥락 크기 = 가변 비율 (%)                         |
|         - 모던 CSS: Flexbox (`display: flex`), CSS Grid                 |
|                        │                                                |
|                        v                                                |
|      3. 유연한 이미지 (Flexible Images) : 부모 컨테이너 크기에 비례     |
|         - img { max-width: 100%; height: auto; }                        |
|         - `<picture>`, `<img srcset="..." sizes="...">`                 |
|                                                                         |
|  [ 화면 크기 변화 ] : [ 모바일 (1열) ] ──> [ 태블릿 (2열) ] ──> [ 데스크톱 (3열) ]|
+-------------------------------------------------------------------------+
```

## 핵심 용어
- 뷰포트(Viewport): 브라우저에서 실제 웹 페이지의 콘텐츠가 표시되는 가상 화면 영역 (`<meta name="viewport" content="width=device-width, initial-scale=1.0">`)
- 모바일 퍼스트(Mobile First): 제약이 가장 심한 모바일 화면의 핵심 콘텐츠와 스타일을 기본 CSS로 먼저 설계하고, 화면이 넓어질수록(`min-width`) 미디어 쿼리로 스타일을 확장해 나가는 설계 철학

## 핵심 통찰
- 반응형 웹의 가장 큰 약점은 "PC용 거대 이미지를 모바일 브라우저도 일단 다운로드한 뒤 화면에서만 작게 축소 렌더링"하여 모바일 네트워크 트래픽과 로딩 시간을 낭비한다는 점임
- 이를 해결하기 위해 HTML5의 `<picture>` 태그와 `srcset` 속성을 활용하여, 클라이언트 브라우저 해상도와 기기 픽셀 비율(DPR)에 딱 맞는 크기의 이미지만 네트워크로 선별 다운로드해야 함
- 데스크톱 퍼스트(`max-width`)로 작성된 CSS는 모바일에서 불필요한 데스크톱 오버라이드 코드를 읽게 만들어 렌더링을 차단하므로, 모바일 퍼스트(`min-width`) 방식으로 작성해야 페이지 로딩 속도가 30% 이상 향상됨

## 이웃 토픽과 구분
- 반응형 웹(RWD) vs 적응형 웹(AWD): 반응형 = 동일한 HTML을 내려받아 클라이언트 CSS가 화면 폭에 맞게 유동 재배치 / 적응형 = 서버(또는 스크립트)가 사용자 User-Agent 기기를 판별하여 기기 전용 템플릿을 선별 전송
