```text
[HCI] ◀━━ 머리: Ⅶ 내 의견 (접근성·인지 부하 최소화 중심의 데이터 주도적 인터랙션 최적화)
 ┃
 ┣━ Ⅰ 개요 ───── 복잡한 디지털 시스템과 인간의 상호작용 최적화 → 편의성, 유용성, 감성 만족 제공
 ┣━ Ⅱ 특징 ───── 다학제적 융합(컴퓨터공학+심리학+디자인) · 인간 중심 설계(HCD) · 인지 모델 기반
 ┣━ Ⅲ 구조 ───── 인간(Human, 감각/인지/운동) / 컴퓨터(Computer, I/O 장치) / 인터랙션(Interaction) / 맥락(Context)
 ┣━ Ⅳ 흐름 ───── 사용자 조사 → 인터랙션 모델링(GOMS, MHP) → UI/UX 프로토타입 → 사용성 평가(휴리스틱, UT) → 개선
 ┣━ Ⅴ 비교 ───── CLI(명령어, 전문가 중심) vs GUI(직관적 시각 그래픽) vs NUI(음성, 제스처, 자연스러운 인간 행동)
 ┗━ Ⅵ 실무 ───── 고령층/장애인 디지털 소외 / 웹 접근성(KWCAG 2.2) 및 멀티모달 인터랙션(Voice+Touch) 구축
```

## 한 줄 본질
- 시스템 기능이 아무리 뛰어나도 사용자가 인지하지 못하거나 조작하기 어려우면 폐기되는 인터랙션 단절 병목 → 인간의 인지적·물리적 특성을 모델링하여 최소한의 정신적 노력으로 목적을 달성하게 인터페이스를 설계 → 사용자 경험(UX) 및 업무 생산성 극대화 / 다양한 단말과 사용자 편차 수용 비용

## 핵심 그림
```text
+-------------------------------------------------------------------+
|               HCI (Human-Computer Interaction) 3대 상호작용 체계  |
+-------------------------------------------------------------------+
|  [ 인간 (Human) ]             [ 상호작용 (Interaction) ]  [ 컴퓨터 (Computer) ]
|  * 감각: 시각, 청각, 촉각      <=======================>   * 입력: 터치, 마이크, 센서
|  * 인지: 작업기억, 멘탈모델        피드백 루프 (Feedback)   * 처리: 비즈니스 로직, AI
|  * 운동: 손가락, 음성, 시선    <=======================>   * 출력: 디스플레이, 스피커
+-------------------------------------------------------------------+
|   진화 단계: CLI (텍스트) -> GUI (WIMP 기반) -> NUI (음성/제스처) -> OUI (뇌파/유기적)
+-------------------------------------------------------------------+
```

## 핵심 용어
- 멘탈 모델(Mental Model): 사용자가 시스템의 작동 방식에 대해 머릿속에 형성하는 구조적 믿음이나 개념적 모형
- NUI(Natural User Interface): 마우스나 키보드 같은 인위적 도구 없이, 인간의 자연스러운 신체 행동(말, 손짓, 눈동자)으로 기기를 제어하는 인터페이스

## 핵심 통찰
- HCI는 단순히 '예쁜 화면(UI)'을 그리는 미학적 작업이 아니라, 인간의 인지적 처리 한계(밀러의 법칙: $7 \pm 2$)를 고려해 '실수를 방지하는 공학'임
- 좋은 인터페이스는 사용자가 설명서를 읽지 않아도 객체의 형태만 보고 조작법을 직관적으로 유추할 수 있는 '어포던스(Affordance, 행동유도성)'를 갖춰야 함
- 생성형 AI와 공간 컴퓨팅(XR)의 등장으로 HCI는 과거 수동적 명령 입력 방식에서, 의도를 파악하고 선제적으로 제안하는 '에이전틱 인터랙션(Agentic Interaction)'으로 진화함

## 이웃 토픽과 구분
- HCI vs UI/UX: HCI = 학문적 연구 및 이론(원리) / UI = 사용자가 마주하는 시각적 접점(수단) / UX = 사용자가 시스템을 사용하며 느끼는 총체적 경험과 감정(결과)
