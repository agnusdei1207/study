```text
 ┃
 ┣━ Ⅰ 개요 ───── AI/검색/시뮬레이션 등 정답(테스트 오라클) 판별 불가 문제 해결
 ┣━ Ⅱ 특징 ───── 테스트 오라클 문제(Oracle Problem) 극복 · 메타모픽 관계(MR) 기반 변형 검증
 ┣━ Ⅲ 구조 ───── 원본 입력($x$) → 원본 출력($f(x)$) vs 후속 입력($x'$) → 후속 출력($f(x')$)
 ┣━ Ⅳ 흐름 ───── ① 대상 도메인 분석 → ② 메타모픽 관계(MR) 정의 → ③ 원본 테스트 케이스 실행 → ④ 변형 입력 생성/실행 → ⑤ MR 성립 검증
 ┣━ Ⅴ 비교 ───── 전통적 테스트(입력 vs 기대출력 1:1 대조) vs 메타모픽 테스트(다중 입출력 간의 내재적 관계 검증)
 ┗━ Ⅵ 실무 ───── 유효한 MR 도출의 어려움 / 자율주행 영상 변환 및 머신러닝 불변성(Invariance) 검증
```

## 한 줄 본질
- 머신러닝, 자율주행, 복잡한 과학 연산처럼 계산 결과의 절대적 정답(Oracle)을 사전에 알 수 없는 테스트 한계 병목 → 입력 데이터를 체계적으로 변형했을 때 출력 간에 성립해야 하는 수학적·논리적 관계(Metamorphic Relation)를 검증 → 정답 없이도 시스템 결함 발견 / 도메인별 고유한 MR 도출 난이도 대가

## 핵심 그림
```text
[ 원본 입력 x ]  ================ (대상 시스템 f) ================> [ 원본 출력 f(x) ]
       |                                                                   |
(메타모픽 변형)                                                            |
       v                                                                   v
[ 후속 입력 x' ] ================ (대상 시스템 f) ================> [ 후속 출력 f(x') ]
                                                                           |
                                 +-----------------------------------------+
                                 v
                 [ 메타모픽 관계(MR) 성립 여부 판정 ]
                   (예: sin(x) == sin(pi - x) 인가?)
                   (예: 도로 이미지 밝기 조절 시 표지판 인식 결과 동일한가?)
```

## 핵심 용어
- 테스트 오라클 문제(Test Oracle Problem): 테스트 케이스를 실행한 후 그 출력 결과가 옳은지 그른지 판별할 수 있는 기준(정답셋)이 없거나 판별 비용이 너무 큰 상황
- 메타모픽 관계(MR, Metamorphic Relation): 특정 도메인 함수에서 입력들의 변형 관계에 따라 출력들 사이에 반드시 유지되어야 하는 필수적 관계식(동일성, 부등식 등)

## 핵심 통찰
- 메타모픽 테스트는 "입력 5를 넣었을 때 10이 나오는가?"를 묻지 않고, "입력을 2배로 늘렸을 때 출력도 2배가 되는가?" 또는 "입력 순서를 뒤집어도 결과가 같은가?"를 검증함
- 검색 엔진 테스트에서 "기술사" 검색 결과는 수백만 건이라 정답을 알 수 없지만, "기술사 AND 컴퓨터" 검색 결과는 반드시 "기술사" 검색 결과의 부분집합이어야 한다는 MR로 검증 가능함
- 자율주행 객체 인식 AI에 원본 사진을 넣었을 때와 사진에 비나 눈 그래픽을 살짝 덧씌웠을 때 인식된 보행자 위치가 급변한다면 AI 모델에 심각한 견고성 결함이 있음을 증명함

## 이웃 토픽과 구분
- 메타모픽 테스트 vs 퍼징(Fuzzing): 퍼징 = 무작위 비정상 입력을 넣어 시스템 크래시/메모리 오류 유발 / 메타모픽 = 논리적 관계(MR)를 바탕으로 비즈니스 연산 결함 적출

## 문제·원인·대책
- 사례: 140회 기출 자율주행 비전 인식 딥러닝 모델의 신뢰성 테스트
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 야간이나 우천 시 자율주행 비전 모델이 표지판을 오인식 | 정적 주간 사진 라벨링 데이터셋에만 의존한 테스트(오라클 한계) | 이미지 회전, 명도 변경, 노이즈 추가 후에도 인식 라벨이 같아야 한다는 MR 적용 | 극한 환경 모델 강건성(Robustness) 결함 조기 탐지 |
| 대규모 검색 포털에서 검색어 필터링 적용 시 누락 발생 | 검색 결과가 수억 건이라 수동 검증 불가 | 검색어 $A$의 결과 $\subset$ 검색어 $(A \text{ OR } B)$의 결과라는 포함 관계 MR 검증 | 검색 엔진 인덱싱 및 랭킹 알고리즘 결함 100% 자동 검출 |
