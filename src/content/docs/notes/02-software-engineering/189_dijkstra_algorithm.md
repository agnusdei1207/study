## 한 줄 본질
- 출발 노드에서 가장 가까운 미방문 정점을 탐욕적으로 확정하고 그 정점을 거쳐가는 경로를 반복 갱신하여 전체 최단 거리를 산출하는 그래프 탐색 알고리즘 / 완화(Relaxation) 연산과 음수 가중치 제약

## 핵심 그림
```text
[ 다익스트라 최단 거리 완화(Relaxation) 메커니즘 ]

           ( u ) ─── w(u, v) = 3 ───> ( v )
             ▲                          ▲
             │                          │
        dist[u] = 4                기존 dist[v] = 10
             │                          │
             └──────── [ 완화 연산 ] ────┘
         dist[u] + w(u, v) = 4 + 3 = 7 < 10 이므로
                   ──> dist[v]를 7로 갱신!
```

## 핵심 용어
- 단일 출발점 최단 경로(SSSP, Single-Source Shortest Path): 그래프 내의 특정 단일 정점에서 출발하여 도달 가능한 다른 모든 정점까지의 최단 비용 경로를 찾는 문제
- 완화 연산(Relaxation): 정점 u를 거쳐 정점 v로 가는 경로가 기존에 알려진 v까지의 거리보다 짧을 경우, v의 최단 거리를 더 짧은 값으로 갱신하는 연산 (`if (d[v] > d[u] + w) d[v] = d[u] + w`)
- 우선순위 큐(Priority Queue / Min-Heap): 아직 방문하지 않은 정점들 중 현재까지 계산된 거리가 가장 작은 정점을 $O(\log V)$ 시간 내에 추출하기 위한 자료구조
- 링크 상태 라우팅(Link State Routing): 네트워크 라우터들이 링크 상태를 광고(LSA)하여 네트워크 토폴로지를 구축한 후 다익스트라 알고리즘을 수행하여 최적 라우팅 테이블을 만드는 프로토콜 (OSPF)

## 핵심 통찰
- 다익스트라의 탐욕적 접근법은 '현재 미방문 정점 중 거리가 가장 짧은 정점은, 다른 어떤 우회 경로를 거쳐오더라도 더 짧아질 수 없다'는 불변조건(Invariant)에 기반함
- 따라서 '음의 가중치'가 존재하는 순간, 뒤늦게 나타난 음수 간선 때문에 이미 최단 거리로 확정된 정점의 거리가 다시 줄어들 수 있으므로 그리디 가정 자체가 파괴됨
- 단순 2차원 인접 행렬로 구현하면 정점 탐색에 $O(V^2)$이 걸리지만, 인접 리스트와 이진 최소 힙(Min-Heap)을 결합하면 $O((V + E) \log V)$로 시간복잡도를 극적으로 단축할 수 있음

## 이웃 토픽과 구분
| 비교 항목 | 다익스트라 (Dijkstra) | 벨만-포드 (Bellman-Ford) | 플로이드-워셜 (Floyd-Warshall) | A* 알고리즘 |
| :--- | :--- | :--- | :--- | :--- |
| **경로 탐색 범위** | 단일 출발점 최단 경로 | 단일 출발점 최단 경로 | 모든 쌍(All-Pairs) 최단 경로 | 단일 출발점 → 특정 목적지 |
| **음수 가중치** | 사용 불가 (음수 허용 안 됨) | 가능 (음수 사이클 감지) | 가능 (음수 사이클 감지) | 사용 불가 |
| **시간 복잡도** | $O((V + E) \log V)$ | $O(V \cdot E)$ | $O(V^3)$ | 휴리스틱에 따라 상이 ($O(b^d)$) |
| **알고리즘 설계** | 탐욕법 (Greedy) + DP | 동적 계획법 (DP) | 동적 계획법 (3중 루프 DP) | 탐욕법 + 휴리스틱 ($f=g+h$) |
| **대표 활용처** | OSPF 라우팅, 내비게이션 | RIP 라우팅, 금융 차익거래 | 전사 네트워크 간 최단경로 매트릭스 | 게임 길찾기, 로봇 자율주행 |

## 문제·원인·대책
| 문제상황 | 원인 | 기술적 대책 |
| :--- | :--- | :--- |
| **음수 간선 존재 시 부정확한 결과 및 무한 루프** | 이미 방문 확정된 노드의 최단 거리가 음수 간선에 의해 번복되는 다익스트라 알고리즘의 가정 붕괴 | 음수 가중치가 포함된 그래프에서는 벨만-포드(Bellman-Ford) 알고리즘으로 대체 적용 |
| **밀집 그래프(Dense Graph)에서 힙 오버헤드** | 간선 수($E \approx V^2$)가 극도로 많을 때 힙 푸시/팝 연산이 빈번하여 속도 저하 | 간선이 매우 많은 밀집 그래프에서는 우선순위 큐 대신 $O(V^2)$ 단순 배열 구현 또는 피보나치 힙 활용 |
| **대규모 도로망 경로 탐색 시 메모리 및 탐색 지연** | 목적지와 무관하게 시작점 기준 360도 전 방향으로 원형 탐색 확산 | 목적지 방향으로 가중치를 부여하는 휴리스틱 함수 $h(n)$을 결합한 A* 알고리즘 도입 |

## 내 의견
- 다익스트라는 컴퓨터 과학 역사상 가장 우아하고 실용적인 알고리즘 중 하나로, 인터넷 백본 라우팅(OSPF, IS-IS)의 근간을 이룸
- 대용량 모빌리티 내비게이션(카카오맵, 티맵 등) 실무에서는 순수 다익스트라를 그대로 돌릴 경우 수천만 개의 노드로 인해 실시간 응답이 불가능함
- 따라서 실무 도로망 시스템에서는 다익스트라의 탐색 공간을 양방향에서 동시에 좁혀오는 양방향 다익스트라(Bidirectional Dijkstra), 고속도로 계층을 축약하는 축약 계층(Contraction Hierarchies, CH), 목적지 방향을 유도하는 A* 알고리즘을 융합하여 밀리초 단위 응답을 달성해야 함
