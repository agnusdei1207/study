## 답안 골격
```text
[IT-ROI 모델] ◀━━ 머리: Ⅶ 내 의견 (정통 재무 ROI에 정보화 특화 무형 편익 화폐화 로직을 결합한 다차원 IT-ROI 프레임워크 운영)
 ┃
 ┣━ Ⅰ 개요 ───── IT 투자의 특수성(비재무적·간접적 가치)을 감안하여 유무형의 성과를 계량화하고 비즈니스 연계를 측정하는 투자 평가 모델
 ┣━ Ⅱ 특징 ───── 유무형 편익 종합화 · 수명주기 전반 평가 · 가치 전환 메커니즘(지표 연결) · 정량적 화폐가치 환산
 ┣━ Ⅲ 구조 ───── 비용 산정(TCO) ↔ 편익 산정(직접 재무, 간접 운영, 무형 전략 가치) ↔ 정량화 알고리즘 ↔ IT-ROI 지표
 ┣━ Ⅳ 흐름 ───── ① 투자 비용(TCO) 집계 → ② 핵심 성과 지표(KPI) 식별 → ③ 무형 편익의 화폐가치 환산 → ④ IT-ROI 산출 및 사후 추적
 ┣━ Ⅴ 비교 ───── 전통적 재무 ROI vs IT-ROI (단순 단기 회계 손익 중심 vs 유무형 편익 화폐화 및 전략적 정렬성 포함)
 ┗━ Ⅵ 실무 ───── 무형 편익의 주관적 산출 공식 남발 / 인과관계가 증명되지 않은 매출 증대 기여 주장 / 사후 검증 루프 미비
```
- 필수 키워드: IT-ROI · 총소유비용(TCO) · 직접 편익 · 간접 편익 · 무형 편익 화폐화 · 가치 전환 모델 · 사후 성과 검증(PIR)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ IT-ROI 편익 분류 및 환산 프레임워크 도식 → Ⅴ 전통 ROI vs IT-ROI 비교 / 25점 = Ⅰ~Ⅶ 전개, 무형 편익(업무시간 단축, 결함 감소)의 구체적 화폐화 계산식 상술
- 기출: 128회 KPC `IT 투자의 유무형 가치 측정을 위한 IT-ROI 모델의 개념, 평가 프레임워크 및 정량화 기법` → Ⅰ·Ⅲ·Ⅳ·Ⅵ

## 한 줄 본질
- 시스템 도입으로 업무 속도가 빨라지고 고객 만족도가 올랐으나 이를 전통적 재무제표로 증명하지 못해 IT 예산이 삭감되는 병목 극복 → 유무형의 운영 성과(품질 향상·시간 절감)를 체계적인 계량화 알고리즘을 통해 화폐 가치로 변환하여 ROI를 산출 → IT 투자의 비즈니스 정당성 확보 / 편익 산출 계수의 자의적 해석 가능성

## 핵심 그림
```text
┌───────────────────────── [ IT-ROI 가치 전환 및 산출 프레임워크 ] ─────────────────────────┐
│                                                                                           │
│   [ 1. 총소유비용 (TCO) ]                                                                 │
│   - 초기 도입비 (H/W, S/W, SI 개발비) + 운영 유지비 (클라우드 인프라, 인건비, 교육비)     │
│                                           │                                               │
│                                           ▼                                               │
│   [ 2. IT 편익(Benefit)의 3단계 분류 체계 ]                                               │
│   ┌───────────────────────────────────────────────────────────────────────────────────┐   │
│   │  (1) 직접 편익 (Direct)   : 레거시 라이선스 해지 비용 절감, 종이 문서 인쇄비 절감 │   │
│   │  (2) 간접 편익 (Indirect) : 결재 리드타임 단축(시간 절감), 재고 회전율 증가       │   │
│   │  (3) 무형 편익 (Intangible): 브랜드 이미지 제고, 고객 이탈률 감소, 규제 벌금 회피 │   │
│   └───────────────────────────────────────┬───────────────────────────────────────────┘   │
│                                           │                                               │
│                                           ▼                                               │
│   [ 3. 무형/간접 편익의 화폐 가치화 공식 ]                                                │
│   - 시간 절감 가치 = 절감 시간(Hour) × 대상 인원 × 시간당 인건비 × 유효 기여율(50%)      │
│   - 불량 감소 가치 = 감소 건수 × 건당 재작업 비용 + 고객 이탈 방지 기여 마진             │
│                                           │                                               │
│                                           ▼                                               │
│   [ 4. 최종 IT-ROI 산출 공식 ]                                                            │
│   $$\text{IT-ROI} (\%) = \frac{\sum \text{화폐화된 총편익} - \text{TCO}}{\text{TCO}} \times 100$$│
│                                                                                           │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

## 핵심 용어
- 유효 기여율(Productivity Factor): IT 시스템으로 절약된 시간이 100% 다른 생산적 업무로 전환되지 않으므로, 이를 보수적으로 보정하기 위해 곱해주는 할인 계수(통상 40~60% 적용)
- 가치 전환 메커니즘(Value Conversion Mechanism): 시스템 성능 지표(응답시간 2초 단축) → 업무 프로세스 지표(일일 처리건수 20% 증가) → 재무 지표(인건비 절감 및 매출 증대)로 이어지는 단계적 인과 사슬

## 핵심 통찰
- IT-ROI의 성패는 '인과관계(Causality) 증명'에 달려 있음 → 전사 매출이 10% 증가했을 때 그중 얼마가 마케팅 덕분이고 얼마가 신규 CRM 시스템 덕분인지 분리해내지 못하면 재무팀을 설득할 수 없음
- 무형 편익의 억지 화폐화를 경계해야 함 → 직원 사기 진작이나 보안 인식 개선 같은 항목을 억지로 10억 원의 가치로 둔갑시키기보다는, 정량적 IT-ROI 지표와 비재무적 BSC 점수를 병기하는 다면 평가가 훨씬 높은 설득력을 가짐
- IT-ROI는 사업 착수 전의 '예측치'보다 시스템 가동 1년 후의 '실적치(PIR)'를 검증할 때 진정한 가치가 발휘됨

## 이웃 토픽과 구분
- IT-ROI vs BSC: IT-ROI = 유무형의 성과를 최종적으로 '화폐 가치 비율(%)'로 수렴시켜 산출 / BSC = 재무, 고객, 내부프로세스, 학습성장의 4대 관점을 '균형 있는 독립 지표'로 병렬 관리

## 문제·원인·대책
- 적용 상황: 전사 그룹웨어 및 협업 도구(SaaS) 교체 사업 IT-ROI 평가
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 재무부서에서 업무시간 단축 편익(수십억)을 허수로 판단해 전액 삭감 | 절감 시간 전부가 매출로 연결된다는 비현실적 전제 | 보수적 유효 기여율(50%) 적용 및 실제 야근 수당 절감액 기반 팩트 계산 | 재무팀 승인 및 신뢰도 확보 |
| 구축 완료 후 IT-ROI 측정 결과에 대한 사후 피드백 실종 | 프로젝트 종료와 함께 평가 태스크포스 해체 | 운영 단계에서 6개월 주기 실적 IT-ROI 재산출 및 차기 예산 배분 연동 | 지속적 가치 실현 보장 |

## 이렇게 출제된다
- 제128회 KPC: "IT 투자의 유무형 가치 측정을 위한 IT-ROI 모델의 개념, 평가 프레임워크 및 정량화 기법을 설명하시오." → 요구 포인트: Ⅰ 개념 + Ⅲ 편익 분류 및 화폐화 알고리즘 + Ⅵ 실무 적용 한계와 극복 방안

## 내 의견
- [IT-ROI 측정을 위한 'A/B 테스트 및 통제집단(Control Group)' 실험 기법 도입] IT 시스템 도입 전후를 단순 비교하면 경기 변동이나 계절적 요인이 섞여 IT의 순수 기여도를 분리할 수 없음 → 나라면: 신규 시스템을 전사 일괄 배포하지 않고 파일럿 지점 50곳(실험군)과 기존 시스템을 유지하는 50곳(대조군)으로 나누어 3개월간 동일 영업 조건에서 매출과 업무 시간을 비교하는 '이중차분법(Difference-in-Differences)'을 적용하여 순수 IT 기여도를 과학적으로 입증
