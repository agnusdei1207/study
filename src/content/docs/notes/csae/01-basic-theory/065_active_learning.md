## 답안 골격
```text
[능동 학습] ◀━━ 머리: Ⅶ 내 의견 (샘플링 편향 방지를 위한 불확실성-다양성 결합 하이브리드 배치 쿼리)
 ┃
 ┣━ Ⅰ 개요 ───── 라벨링 비용 병목 한계 → 모델 스스로 학습 효과가 가장 높은 데이터를 선별하여 라벨링 요청
 ┣━ Ⅱ 사이클 ──── 모델 훈련 $\to$ 불확실 샘플 질의(Query) $\to$ 오라클(인간) 라벨링 $\to$ 데이터셋 추가 및 재학습 루프
 ┣━ Ⅲ 전략 ───── 불확실성 샘플링(Uncertainty) · 위원회 질의(QBC) · 기대 오차 감소(Expected Error)
 ┣━ Ⅳ 수식 ───── 최소 확신도($1 - \max P(y|x)$) · 마진 샘플링($P(y_1|x) - P(y_2|x)$) · 엔트로피($-\sum P \log P$)
 ┣━ Ⅴ 비교 ───── 수동 전수 라벨링 vs 무작위 샘플링(Passive) vs 능동 학습(Active Learning)
 ┗━ Ⅵ 실무 ───── 라벨링 비용 대폭 절감 · 특정 영역 편향(Sampling Bias) 통제 · 인간 참여형(HITL) MLOps
```
- 필수 키워드: 오라클(Oracle) · 불확실성 샘플링 · 위원회 질의(QBC) · 마진 샘플링 · 엔트로피 · HITL(Human-in-the-Loop)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 능동 학습 순환 루프 도해 → Ⅲ 3대 쿼리 전략 수식 분석 → Ⅵ 실무 MLOps 연계

## 한 줄 본질
- 수백만 건의 원시 데이터를 무작정 사람이 라벨링하는 고비용 낭비를 차단 → 모델이 가장 헷갈려하는 불확실한 경계선 데이터만 골라 인간 전문가에게 라벨링을 요청 → 최소의 라벨링으로 최대 성능 달성 / 샘플링 편향 위험

## 핵심 그림
```text
          [ 라벨링되지 않은 대규모 데이터 풀 (Unlabeled Pool) ]
                                 |
                                 v
          +----------------> [ 머신러닝 모델 ]
          |                      | (예측 확신도 평가)
          |                      v
          |              [ 쿼리 전략 (Query Strategy) ]
          |              - 불확실성(Entropy, Margin)
          |              - 모델 간 의견 불일치(QBC)
          |                      |
          |                      v (가장 유망한 샘플 선별)
          |              [ 오라클 (인간 전문가 라벨러) ]
          |                      |
          |                      v (정답 라벨 부여)
          +--- [ 학습 데이터셋 추가 (Labeled Set) ] <--- 초기 소량 시드 데이터
```

## 핵심 통찰
- 이미 모델이 $99\%$ 확신하는 데이터는 라벨을 달아 학습시켜도 가중치에 아무런 변화를 주지 못하므로, 결정 경계(Decision Boundary)에 걸쳐 있는 마진(Margin)이 가장 작은 샘플을 학습시켜야 성능이 급상승함
- 불확실성 샘플링만 반복하면 결정 경계 주변의 이상치(Outlier)나 특정 좁은 영역에만 샘플이 몰려 전체 데이터 분포를 놓치는 '샘플링 편향(Sampling Bias)'이 발생함
- 따라서 데이터 공간 전체의 밀도와 다양성을 함께 고려하는 '밀도 가중 불확실성(Density-weighted Uncertainty)' 전략이 병행되어야 함

## 이웃 토픽과 구분
- 수동 라벨링 vs 수동적 학습 vs 능동 학습:
| 비교 항목 | 수동 전수 라벨링 | 수동적 학습 (Passive Learning) | 능동 학습 (Active Learning) |
|---|---|---|---|
| 데이터 선택 | 무작위 전수 작업 | 무작위 균등 샘플링 (Random) | 모델이 주도적으로 유익한 데이터 선별 |
| 라벨링 비용 | 극도로 높음 (모든 데이터 대상) | 높음 (원하는 성능 달성까지 다량 필요) | 극히 낮음 (필수적인 핵심 샘플만 작업) |
| 결정 경계 개선 | 중복 데이터로 인한 비효율 | 느린 학습 곡선 (느린 수렴) | 결정 경계 주변 집중으로 가파른 학습 수렴 |

## 문제·원인·대책
- 적용 상황: 전문 의료 영상(암 조직 판독) 라벨링 비용 절감 파이프라인
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 노이즈 데이터에 대한 집중 질의 발생 | 아웃라이어나 깨진 이미지에 대해 모델이 높은 불확실성을 보여 오라클에 쿼리 집중 | k-평균 군집화를 결합하여 데이터 밀도가 높은 영역의 대표 불확실 샘플만 선별 | 무의미한 노이즈 라벨링 비용 차단 |
| 배치(Batch) 질의 시 중복 유사 샘플 선별 | 단일 루프에서 여러 개를 뽑을 때 동일한 위치의 유사한 데이터가 대량 포함 | 코어셋(Core-set) 기법을 활용한 배치 다양성(Diversity) 제약 조건 부과 | 데이터 중복 제거 및 배치 효율성 극대화 |

## 내 의견
- [샘플링 편향 방지를 위한 불확실성-다양성 결합 하이브리드 배치 쿼리] 실무에서 단일 모델의 엔트로피 쿼리만 적용하면 특정 클래스에 편향되거나 이상치에 라벨링 자원이 낭비되는 실패를 겪음 → 나라면: 불확실성(Informativeness) 상위 후보군을 1차 선별한 후, 임베딩 공간에서 k-Medoids 군집화를 통해 공간적 다양성(Representativeness)을 보장하는 하이브리드 배치 쿼리 파이프라인을 MLOps에 통합하여 라벨링 비용 최소화
