## 답안 골격
```text
[부호화 체계 비교] ◀━━ 머리: Ⅶ 내 의견 (무선 채널 변동성에 대응하는 공동 소스-채널 코딩 JSCC 도입)
 ┃
 ┣━ Ⅰ 개요 ───── 정보 통신의 양대 상충 과제 → 데이터 압축(중복 제거)과 전송 오류 복원(잉여 추가)의 상호보완
 ┣━ Ⅱ 소스 ───── 소스 코딩(Source Coding): 정보원 엔트로피 $H(X)$ 기반 중복성 제거 및 데이터 압축
 ┣━ Ⅲ 채널 ───── 채널 코딩(Channel Coding): 채널 용량 $C$ 한계 내 인위적 패리티(잉여 비트) 부가 및 오류 정정
 ┣━ Ⅳ 흐름 ───── 정보 발생 → 소스 부호화(압축) → 채널 부호화(FEC 추가) → 변조 → 물리 전송
 ┣━ Ⅴ 비교 ───── 소스 코딩 vs 채널 코딩 종합 비교표 (목적, 수학적 한계, 중복성 제어, 대표 알고리즘)
 ┗━ Ⅵ 실무 ───── 통신 대역폭 절감 및 신뢰성 확보 · 섀넌 분리 정리 한계와 공동 소스-채널 코딩(JSCC)
```
- 필수 키워드: 소스 코딩 · 채널 코딩 · 섀넌 제1정리(엔트로피) · 섀넌 제2정리(채널 용량) · 중복성(Redundancy) · FEC
- 배점 전략: 10점 = Ⅰ 개요 → Ⅳ 전체 통신 파이프라인 도해 → Ⅴ 양대 부호화 심층 비교표 → Ⅵ JSCC 응용

## 한 줄 본질
- 원본 데이터의 낭비되는 중복성을 제거해 대역폭을 절감하는 소스 코딩과, 잡음 환경에서 비트 반전을 복구하기 위해 인위적 잉여를 덧붙이는 채널 코딩의 수학적 대칭 구조 → 최적 전송 효율과 무오류 신뢰성 동시 달성 / 압축 왜곡과 부호화 오버헤드

## 핵심 그림
```text
[정보원] ===> [소스 코딩 (Source)] ===> [채널 코딩 (Channel)] ===> [물리 채널]
(아날로그/텍스트) (중복성 제거: Redundancy 배제) (인위적 잉여 부가: FEC 추가)  (잡음 유입)
                   |                              |
             [데이터 압축]                  [오류 검출/정정]
             H(X) <= R_s                    R_c <= C
             (허프만, LZW, JPEG)            (해밍, CRC, LDPC, Polar)
```

## 핵심 통찰
- 소스 코딩은 데이터 내부의 불필요한 반복(Redundancy)을 최대한 깎아내어 데이터 크기를 엔트로피 $H(X)$ 한계까지 줄이는 작업임
- 반면 채널 코딩은 깎아낸 데이터 뒤에 수학적으로 계산된 규칙적인 잉여 비트(Parity)를 덧붙여, 전송 중 비트가 깨지더라도 수신측에서 스스로 복원(FEC)할 수 있게 만드는 작업임
- 섀넌의 분리 정리(Separation Theorem)에 따르면 이상적인 조건에서는 두 단계를 독립적으로 설계해도 최적이지만, 지연 시간이 극도로 짧아야 하는 무선 환경에서는 두 단계를 함께 고려하는 공동 소스-채널 코딩(JSCC)이 요구됨

## 이웃 토픽과 구분
- 소스 코딩 vs 채널 코딩:
| 비교 항목 | 소스 코딩 (Source Coding) | 채널 코딩 (Channel Coding) |
|---|---|---|
| 근본 목적 | 데이터 압축 (대역폭 및 저장 공간 절감) | 오류 검출 및 정정 (신뢰성 확보) |
| 중복성(Redundancy) | 데이터 내 잉여 중복성 **제거** | 제어된 인위적 잉여 비트 **부가** |
| 이론적 한계 | 섀넌 제1정리 (엔트로피 $H(X)$) | 섀넌 제2정리 (채널 용량 $C$) |
| 대표 기법 | 무손실(Huffman, LZW), 손실(JPEG, H.265) | 검출(CRC), 정정(Hamming, Reed-Solomon, LDPC) |

## 문제·원인·대책
- 적용 상황: 패킷 손실이 빈번한 위성 및 무선 통신 링크
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 소스 코딩된 고압축 비트열 1비트 손상 시 대규모 복호화 실패 | 중복성이 제거되어 비트 손상 시 후속 블록 전체의 동기화 붕괴 | 적응형 변조 및 부호화(AMC)를 통한 채널 코딩 부호율(Code Rate) 동적 강화 | 패킷 복원 성공률 향상 |
| 채널 코딩 잉여 비트 과다로 유효 전송량 급감 | 채널 상태가 양호함에도 높은 고정 패리티를 유지하여 전송 지연 발생 | 채널 피드백 기반 하이브리드 ARQ(HARQ) 및 레이트 매칭(Rate Matching) 도입 | 유효 전송률(Goodput) 극대화 |

## 내 의견
- [무선 채널 변동성에 대응하는 공동 소스-채널 코딩 JSCC 도입] 고전적인 분리 아키텍처는 고정 압축과 채널 부호화 간의 버퍼 지연으로 인해 초저지연 차량 통신(V2X)이나 드론 제어 링크에서 급격한 채널 열화 시 절벽 효과(Cliff Effect)를 겪음 → 나라면: 딥러닝 오토인코더를 활용하여 채널 상태(SNR) 피드백에 따라 소스 압축률과 오류 보호 비트를 종단 간(End-to-End)에서 동적으로 일체화하여 제어하는 신경망 기반 Deep JSCC를 적용하여 초저지연과 점진적 품질 열화(Graceful Degradation) 달성
