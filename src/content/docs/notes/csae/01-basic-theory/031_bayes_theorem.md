## 답안 골격
```text
[베이즈 정리] ◀━━ 머리: Ⅶ 내 의견 (기저율 오류 억제를 위한 우도비 보정 및 동적 사전확률 갱신)
 ┃
 ┣━ Ⅰ 개요 ───── 관측 불확실성 한계 → 새로운 증거(Evidence) 관측 시 사후확률(Posterior) 수학적 갱신
 ┣━ Ⅱ 수식 ───── $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$ (사후확률 = (우도 × 사전확률) / 정규화 상수)
 ┣━ Ⅲ 구조 ───── 사전확률 분포 → 증거 수집 및 우도 함수 결합 → 사후확률 분포 도출
 ┣━ Ⅳ 흐름 ───── ① 초기 사전확률 설정 → ② 신규 데이터 관측 → ③ 우도 연산 → ④ 사후확률 갱신 및 피드백
 ┣━ Ⅴ 비교 ───── 빈도주의(Frequentist) vs 베이지안(Bayesian) (고정 모수·장기 반복 vs 확률적 가변 모수·사전지식 갱신)
 ┗━ Ⅵ 실무 ───── 스팸 필터링 · 침입 탐지 시스템(IDS) / 기저율 오류(Base Rate Fallacy)로 인한 오탐 통제
```
- 필수 키워드: 사전 확률(Prior) · 우도(Likelihood) · 사후 확률(Posterior) · 증거(Evidence) · 나이브 베이즈(Naive Bayes)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 수식 및 각 항 의미 → Ⅲ 갱신 구조도 → Ⅵ 오탐 제어 방안

## 한 줄 본질
- 정적 데이터에 의존하는 빈도주의 확률 계산의 한계 극복 → 새로운 관측 증거를 반영해 가설의 신뢰도(사후확률)를 수학적으로 갱신 → 지속적 관측을 통한 정밀도 수렴 / 초기 사전확률 주관성에 따른 편향 위험

## 핵심 그림
```text
[사전 확률 P(H)]        [우도 P(E|H)]
 (사전 도메인 지식)      (가설 성립 시 증거 관측 확률)
         \                    /
          \                  /   (결합 곱 연산)
           v                v
      [ 결합 확률 P(H) * P(E|H) ]
      ---------------------------
         [ 증거 확률 P(E) ]      <-- 정규화 상수 (총확률 정리: sum P(H_i)*P(E|H_i))
                   |
                   v
          [사후 확률 P(H|E)]
        (증거 관측 후 갱신된 신뢰도) -> 차기 사전 확률로 피드백
```

## 핵심 통찰
- 베이즈 정리의 본질은 "증거를 보았을 때 믿음을 얼마나 수정해야 하는가"를 정량화하는 계산 프레임워크임
- 모수가 고정되어 있다고 가정하는 빈도주의와 달리, 모수 자체를 확률분포로 취급하므로 소량의 표본 데이터로도 유효한 추론을 시작할 수 있음
- 나이브 베이즈 분류기는 특성 간 상호 독립을 가정하여 계산량을 차원의 곱에서 합으로 축소하지만, 특성 간 강한 상관관계가 존재할 경우 사후확률이 양극단으로 왜곡되는 대가를 치름

## 이웃 토픽과 구분
- 베이즈 정리 vs 최대 우도 추정(MLE): MLE = 관측 데이터를 가장 잘 설명하는 단일 파라미터 값 추정(사전 지식 배제) / 베이지안 추론 = 사전 확률분포와 우도를 결합하여 파라미터의 사후 확률분포 전체를 유도

## 문제·원인·대책
- 적용 상황: 네트워크 이상 징후 기반 침입 탐지 시스템(IDS) 운용
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 정상 트래픽을 공격으로 과다 오탐 | 공격 발생의 사전 확률이 극히 낮음에도 탐지율(우도)만 과신하여 기저율 오류 발생 | 베이지안 분류 모델에 실제 공격 발생 기저율을 반영한 정규화 상수 보정 | 오탐률 하강 및 관제 피로도 완화 |
| 미관측 패턴 출현 시 사후확률이 0으로 왜곡 | 특정 토큰의 관측 빈도가 0일 때 결합 확률 전체가 0으로 전파되는 Zero Probability 문제 | 라플라스 스무딩(Laplace Smoothing) 가산 보정 적용 | 미출현 데이터에 대한 추론 연속성 확보 |

## 내 의견
- [기저율 오류 억제를 위한 우도비 보정과 동적 사전확률 갱신] 공격 트래픽의 발생 빈도가 전체 트래픽 대비 현저히 낮은 현실 환경에서 탐지 모델의 우도(Likelihood)만 신뢰하면 경보 피로(Alert Fatigue)로 인해 실제 침입을 놓치게 됨 → 나라면: 계절성 및 시간대별 네트워크 기준선(Baseline) 트래픽을 실시간 분석하여 사전확률(Prior)을 주기적으로 재산정하고, 우도비(Likelihood Ratio) 기반 임계값 동적 조정을 결합하여 정상 트래픽 급증 시의 오탐을 원천 제어
