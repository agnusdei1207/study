## 답안 골격
```text
[계산 복잡도와 NP-완전] ◀━━ 머리: 다항 시간 검증 가능성과 다항 시간 환원을 통한 계산 한계 규명
 ┃
 ┣━ Ⅰ 개요 ───── 알고리즘 해결 가능성 경계 → 다항 시간 해결(P)과 다항 시간 검증(NP)의 복잡도 계층 이론
 ┣━ Ⅱ 복잡도 ─── P(다항 시간 해결) · NP(다항 시간 검증) · NP-Hard(환원성) · NP-Complete(NP의 핵심)
 ┣━ Ⅲ 구조 ───── 벤 다이어그램: $P \subseteq NP$, $NP \cap NP\text{-Hard} = NP\text{-Complete}$ 관계도
 ┣━ Ⅳ 환원 ───── 다항 시간 환원($A \le_p B$): 문제 $A$를 문제 $B$의 형태로 다항 시간 내 변환하여 난이도 전이
 ┣━ Ⅴ 비교 ───── P vs NP vs NP-완전 vs NP-난해 (정의, 해결 시간, 검증 시간, 소속 관계)
 ┗━ Ⅵ 실무 ───── $P \ne NP$ 난제 · 현실적 대안(근사 알고리즘 Approximation, 휴리스틱, 유전 알고리즘)
```
- 필수 키워드: P 문제 · NP 문제 · NP-완전(NP-Complete) · NP-난해(NP-Hard) · 다항 시간 환원 · 쿡-레빈 정리

## 한 줄 본질
- 답을 직접 찾기는 지수 시간($O(2^n)$)이 걸려 극히 어렵지만 남이 제시한 답이 맞는지는 다항 시간($O(n^k)$)에 즉시 검증할 수 있는 문제 군 → 계산적 불가능성의 증명 / 최적해 대신 다항 시간 근사해로 타협

## 핵심 그림
```text
[P != NP 가정 하의 복잡도 관계도]
  +-------------------------------------------------------+
  |                   NP-Hard (NP-난해)                   |
  |   +-----------------------------------------------+   |
  |   |                NP (비결정론적 다항)             |   |
  |   |   +-------------------+   +---------------+   |   |
  |   |   |     P (다항 해결)  |   |  NP-Complete  |   |   |
  |   |   | (정렬, 최단경로 등) |   |  (SAT, TSP,   |===+===+ (교집합 영역)
  |   |   +-------------------+   |   배낭 문제)   |   |   |
  |   |                           +---------------+   |   |
  |   +-----------------------------------------------+   |
  +-------------------------------------------------------+
```

## 핵심 통찰
- NP-완전(NP-Complete)의 강력한 특징은 '다항 시간 환원(Polynomial-time Reduction)'에 의해 모든 NP 문제가 이 문제로 변환될 수 있으므로, NP-완전 문제 중 단 하나라도 다항 시간에 푸는 알고리즘이 발견되면 모든 NP 문제가 다항 시간에 풀려 $P=NP$가 됨
- 실무 엔지니어링에서 어떤 문제가 NP-완전으로 증명되면, 완전 탐색으로 최적해를 찾으려 하지 말고 다항 시간 내에 허용 오차 범위의 해를 구하는 '근사 알고리즘(Approximation Algorithm)'이나 휴리스틱으로 방향을 전환해야 함

## 이웃 토픽과 구분
- 복잡도 클래스 4분면 비교:
| 클래스 | 다항 시간 내 해결 가능? | 다항 시간 내 정답 검증 가능? | NP 문제 집합에 소속? |
|---|---|---|---|
| P | 가능 ($O(n^k)$) | 가능 ($O(n^k)$) | 소속됨 ($P \subseteq NP$) |
| NP | 미지 (일반적으로 지수 시간) | 가능 ($O(n^k)$) | 소속됨 |
| NP-Complete | 미지 (최악의 경우 지수 시간) | 가능 ($O(n^k)$) | 소속됨 ($NP$의 가장 어려운 문제) |
| NP-Hard | 미지 또는 해결 불가 | 불가능할 수도 있음 | 소속 안 될 수도 있음 (결정 문제 외 포함) |
