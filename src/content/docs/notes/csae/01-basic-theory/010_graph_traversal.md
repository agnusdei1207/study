## 답안 골격
```text
[그래프 순회 체계] ◀━━ 머리: 스택 기반 수직 깊이 우선(DFS)과 큐 기반 수평 너비 우선(BFS)의 상호보완
 ┃
 ┣━ Ⅰ 개요 ───── 비선형 그래프 구조 순회 한계 → 모든 정점(Vertex)을 중복 없이 빠짐없이 방문하는 탐색 알고리즘
 ┣━ Ⅱ DFS ────── 깊이 우선 탐색: 한 갈래를 끝까지 탐색 후 역추적(Backtrack), 재귀 호출 및 스택 자료구조
 ┣━ Ⅲ BFS ────── 너비 우선 탐색: 시작점으로부터 거리가 가까운 정점부터 레벨별 순회, 큐(Queue) 자료구조
 ┣━ Ⅳ 복잡도 ─── 인접 리스트 $O(V + E)$ vs 인접 행렬 $O(V^2)$ (방문 배열 visited 필수)
 ┣━ Ⅴ 비교 ───── DFS vs BFS (자료구조, 메모리 소비, 최단 경로 보장 여부, 활용처)
 ┗━ Ⅵ 실무 ───── 위상 정렬(DFS) · 가중치 없는 최단 경로(BFS) · 웹 크롤러 아키텍처
```
- 필수 키워드: 깊이 우선 탐색(DFS) · 너비 우선 탐색(BFS) · 스택(Stack) · 큐(Queue) · 방문 배열 · $O(V+E)$

## 한 줄 본질
- 노드 간의 복잡한 연결망에서 수직으로 파고들며 끝을 확인하는 DFS와 수평으로 동심원을 넓히며 계층별로 찾는 BFS의 양대 탐색 기법 → 완벽한 정점 방문 및 경로 발견 / 사이클 루프 시 무한 루프 방지 장치 필수

## 핵심 그림
```text
           [ 1 ]
          /     \
       [ 2 ]   [ 3 ]
       /   \       \
     [ 4 ] [ 5 ]   [ 6 ]
     
[DFS 방문 순서 (스택 / 재귀)]           [BFS 방문 순서 (큐: 레벨별 순회)]
 1 -> 2 -> 4 -> 5 -> 3 -> 6            1 -> 2 -> 3 -> 4 -> 5 -> 6
 (수직으로 끝까지 파고든 후 복귀)         (루트로부터 거리가 같은 이웃부터 탐색)
```

## 핵심 통찰
- BFS는 레벨(간선 수) 순으로 동심원을 그리며 탐색하므로, 간선 가중치가 모두 동일할 때 목적지까지의 '최단 경로(Shortest Path)'를 항상 보장하지만, 큐에 동일 레벨의 모든 노드를 담아야 해 메모리 소비가 큼
- DFS는 현재 탐색 경로 상의 정점들만 스택에 유지하므로 공간 복잡도가 트리 높이에 비례($O(h)$)하여 메모리가 절약되며, 사이클 검출 및 위상 정렬에 적합함

## 이웃 토픽과 구분
- DFS vs BFS:
| 비교 항목 | 깊이 우선 탐색 (DFS) | 너비 우선 탐색 (BFS) |
|---|---|---|
| 사용 자료구조 | 스택 (Stack) 또는 시스템 재귀 | 큐 (Queue) |
| 탐색 방향 | 수직적 심층 탐색 후 백트래킹 | 수평적 계층(레벨)별 탐색 |
| 최단 경로 | 가중치 없어도 최단 경로 보장 불가 | 간선 가중치 동일 시 최단 경로 항상 보장 |
| 공간 복잡도 | $O(V)$ (트리 높이에 비례, 경제적) | $O(V)$ (분기 계수에 따라 큐 메모리 급증) |
| 대표 활용처 | 미로 찾기, 위상 정렬, 사이클 판별 | 최단 거리 길찾기, 네트워크 브로드캐스트 |
