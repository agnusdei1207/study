- 본질: **TDMA(Time Division Multiple Access)** : 여러 사용자가 같은 무선 채널을 시간 슬롯별로 나누어 쓰는 다중접속 방식
- 메커니즘: 프레임을 슬롯으로 나누고 단말을 슬롯에 맞춰 송신시켜 수신기에서 시간으로 신호를 구분
- 통찰: 단일 반송파 주파수를 시간 축에서 복수의 주기적 타임 슬롯(Time Slot)으로 분할하여 다수 사용자가 순차적으로 채널을 점유하며 인접 슬롯 간 충돌 방지를 위한 정밀한 시간 동기화와 가드 타임 설정이 핵심임.

<details>
<summary>핵심 용어</summary>

- **TDMA(Time Division Multiple Access)** : 동일한 반송파를 시간 슬롯으로 나눠 여러 사용자가 공유하는 다중접속 방식
- **타임 슬롯(Time Slot)** : TDMA 프레임 안에서 특정 사용자 또는 채널에 배정되는 시간 구간
- **가드 시간(Guard Time)** : 전파 지연과 송신 시점 차이로 인접 슬롯이 겹치는 일을 줄이기 위한 시간 여유
- **프레임(Frame)** : 정해진 순서의 타임 슬롯을 묶어 반복하는 전송 단위
- **타이밍 어드밴스(Timing Advance)** : 이동국의 전파 지연 차이를 보상하도록 송신 시점을 앞당기는 제어 값; 적용은 시스템별 규격에 따름

## 2~4교시 25점 답안

## Ⅰ. TDMA(Time Division Multiple Access)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 단일 무선 주파수 대역의 전송 시간을 주기적인 타임 프레임(Time Frame)으로 나누고, 이를 다시 복수의 타임 슬롯(Time Slot)으로 분할하여 각 사용자에게 배타적으로 할당하는 시분할 다중 접속 방식 |
| 목적 | 동일 주파수 내에서 상호 간섭 없는 다자간 동시 통신 구현, 주파수 필터링 복잡도 완화 및 불연속 버스트 전송을 통한 단말 배터리 소모 절감 |

## Ⅱ. TDMA(Time Division Multiple Access)의 특징

| 특징 | 상세 내용 |
|---|---|
| 시간 분할 다원 접속 | 주파수는 전 대역을 공유하되 각 사용자는 자신에게 할당된 시간 슬롯 동안에만 송수신 수행 |
| 버스트(Burst) 전송 | 음성 및 데이터를 압축 버퍼링한 후 자신의 슬롯 동안 높은 전송률로 순간 방출 송신 |
| 엄격한 프레임 동기화| 기지국과 단말 간 전파 지연 시간(Propagation Delay) 차이를 보정하기 위한 타이밍 어드밴스 필수 |
| 가드 타임(Guard Time)| 슬롯 간 미세한 시간 오차로 인한 인접 슬롯 데이터 충돌을 물리적으로 차단하는 완충 구간 배치 |

## Ⅲ. TDMA(Time Division Multiple Access)의 체계·프로세스

**TDMA 프레임 구조 및 타임 슬롯 상세 구성**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ TDMA 프레임 및 슬롯 구조 (GSM 예시) ]        │
│                                                                        │
│   1 TDMA 프레임 (4.615 ms)                                             │
│   ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐            │
│   │Slot 0│Slot 1│Slot 2│Slot 3│Slot 4│Slot 5│Slot 6│Slot 7│ (8개 슬롯)  │
│   └──────┴──┬───┴──────┴──────┴──────┴──────┴──────┴──────┘            │
│             │                                                          │
│             ▼ [ 1개 타임 슬롯 상세 구조 (0.577 ms, 156.25 bits) ]       │
│   ┌───────┬────────────┬─────────────┬────────────┬───────┬────────┐   │
│   │ TB    │ Encrypted  │ Training    │ Encrypted  │ TB    │ Guard  │   │
│   │ (3b)  │ Data (57b) │ Seq (26b)   │ Data (57b) │ (3b)  │ Period │   │
│   └───────┴────────────┴─────────────┴────────────┴───────┴────────┘   │
│   * TB: Tail Bits (파워 램프업/다운 완충 비트)                         │
│   * Training Sequence: 무선 채널 등화기(Equalizer) 훈련용 기지국 동기  │
│   * Guard Period: 인접 슬롯 간 충돌 방지 가드 타임 (8.25 bits)         │
└────────────────────────────────────────────────────────────────────────┘
```

| 슬롯 필드 | 비트 크기 | 핵심 역할 및 기능 |
|---|---|---|
| **Data Payload** | 114 비트 (57b * 2) | 실제 암호화된 사용자 음성 또는 패킷 데이터 전송 |
| **Training Sequence** | 26 비트 | 수신측 등화기(Equalizer)가 무선 다중경로 왜곡을 보상하기 위한 기지국 패턴 |
| **Tail Bits** | 6 비트 (3b * 2) | 슬롯 시작과 끝에서 송신 전력 증폭기(PA) On/Off 램프 시간 제공 |
| **Guard Period** | 8.25 비트 | 단말의 기지국 간 거리 차이로 인한 슬롯 중첩 충돌 방지 완충 시간 |

## Ⅳ. TDMA(Time Division Multiple Access)의 종류·비교

| 비교 항목 | FDMA | TDMA | CDMA |
|---|---|---|---|
| **분할 축** | 주파수 (Frequency) | **시간 (Time)** | 부호 (Code) |
| **채널 점유 방식** | 전 시간 대역 일부 점유 | **특정 시간 전 대역 점유** | 전 시간 전 대역 동시 점유 |
| **송신 방식** | 연속 전송 (Continuous)| **불연속 버스트 전송** | 연속 전송 |
| **동기화 요구** | 불필요 | **극도로 엄격 (마이크로초)**| 엄격 (기지국 간 GPS 동기) |
| **대표 표준** | 1G 아날로그 (AMPS) | **2G 유럽 표준 (GSM)** | 2G/3G (IS-95, WCDMA) |

## Ⅴ. TDMA(Time Division Multiple Access)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 기지국에서 멀리 떨어진 단말의 신호가 전파 지연으로 인해 인접 단말의 타임 슬롯을 침범하는 문제 | 기지국이 거리를 측정하여 단말의 송신 시점을 앞당기도록 지시하는 타이밍 어드밴스(Timing Advance) 적용 |
| 고속 데이터 전송 시 슬롯당 데이터 용량 한계 및 주파수 효율 한계 | 주파수 대역 내 직교 다중 부반송파를 결합한 OFDM/OFDMA(LTE/5G) 기술로 진화 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
TDMA 기반 위성 통신(VSAT)망 구축 시, 정지궤도 위성과의 긴 RTT(약 500ms)로 인해 중앙 마스터국의 동기 클록 오차가 누적되기 쉬우므로, 각 슬롯의 가드 타임을 지상망 대비 10배 이상 넉넉히 설계하고 동적 대역폭 할당(DAMA) 프로토콜을 결합.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ TDMA 타이밍 어드밴스 (Timing Advance, TA) 동작 메커니즘 ]           │
│                                                                        │
│   [ 원거리 단말 UE-2 ]                 [ 근거리 단말 UE-1 ]   [ 기지국]│
│         │                                    │            │    │   │
│         │ (전파 지연 30μs 소요)              │            │    │   │
│         │                                    ├── 1μs 지연►│    │   │
│         │                                    │            ▼    │   │
│         │                                    │        [Slot 1] │   │
│         │◄─── "송신 타이밍을 30μs 앞당겨라" (TA 지시) ─────────┤   │
│         │                                                      ▼   │
│         ├─── [ 30μs 미리 송신 ] ──────────────────────────► [Slot 2]│
│         │                                                          │
│   결과: 기지국 슬롯 경계에 정확히 안착하여 Slot 1과 Slot 2 충돌 방지 성공 │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| TDMA 구현 방식 | 슬롯 할당 규칙 | 대역폭 활용도 | 주 적용 분야 |
|---|---|---|---|
| **고정 TDMA (Fixed)** | 각 사용자에게 슬롯 영구 고정 | 트래픽 없을 시 대역 낭비 | 음성 전용 2G GSM 망 |
| **동적 TDMA (Dynamic)**| 요구에 따라 슬롯 가변 할당 | 매우 높음 (패킷 효율화) | 위성 통신, 군용 전술 무선망 |
| **S-ALOHA (Slotted)** | 슬롯 경계에서 임의 경쟁 송신 | 충돌 발생 (최대 효율 36.8%)| 초기 무선 패킷 데이터망 |
