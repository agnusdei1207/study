## 연관 키워드

- TDMA(Time Division Multiple Access), 시분할 다중 접속, 프레임(Frame), 타임 슬롯(Time Slot)
- 버스트(Burst), 가드 타임(Guard Time), 타이밍 어드밴스(Timing Advance), 프리앰블(Preamble)
- FDMA(Frequency Division Multiple Access), CDMA(Code Division Multiple Access), 동적 슬롯 할당

## Ⅰ. TDMA의 개요

- 핵심 요약 : 하나의 주파수 채널을 시간 슬롯으로 나누어 가입자마다 전송 시간을 배정하는 다중 접속 방식.
- 개념 : 주파수 채널의 시간을 주기적 **프레임** (Frame)으로 구분하고, 프레임을 다시 **타임 슬롯** (Time Slot)으로 나누어 각 가입자가 배정받은 슬롯에서만 신호를 보내는 **시분할 다중 접속** (TDMA, Time Division Multiple Access) 방식.
- 배경 및 필요성 : 주파수 분할 다중 접속(FDMA, Frequency Division Multiple Access) 중심의 1세대 아날로그 방식은 통화 수만큼 주파수가 필요해 용량 확장에 한계가 있었음 → 디지털 음성 압축과 결합해 한 반송파에 여러 통화를 실을 방법이 요구됨.
- 주요 목적 : 주파수 자원의 시간축 재분할을 통한 수용 용량 증대와 무선 자원의 명확한 배분.

## Ⅱ. TDMA의 특징 및 장점

- 핵심 요약 : 슬롯 독점 전송과 정밀 동기 설계가 충돌 없는 결정론적 전송으로 이어지는 방식.

1. 슬롯 독점 전송 : 각 가입자가 자기 슬롯에서만 송신 → 가입자 간 충돌이 원리적으로 배제되는 예측 가능한 전송.
2. 단일 반송파 다중화 : 하나의 주파수 장비로 여러 통화 수용 → 기지국 무선 장비 구성의 단순화.
3. 전력 절감 : 디지털화·압축한 음성을 **버스트** (Burst, 짧은 신호 덩어리) 단위로 송출 → 슬롯 사이 유휴 구간에서 단말 전력 소모 절감.
4. 동기 설계 : 가드 타임과 타이밍 어드밴스로 거리에 따른 도착 시간 차를 보상 → 인접 슬롯 간 신호 겹침 방지.

## Ⅲ. TDMA의 구조 (흐름)

- 핵심 요약 : 프레임-슬롯-버스트의 3단 구조와 슬롯 내부의 동기·데이터·보호 구간 구성.
- **프리앰블** (Preamble) : 버스트 앞부분의 동기용 비트열로, 수신 측이 슬롯 기준 시각을 맞추는 데 사용.
- **가드 타임** (Guard Time) : 슬롯 사이의 여유 구간으로, 전파 지연 차와 클록 오차에 따른 침범을 흡수.
- **타이밍 어드밴스** (Timing Advance) : 기지국이 단말의 왕복 전파 지연을 측정해 송신 시각을 앞당기도록 지시하는 동기 제어.

```text
[ 프레임과 타임 슬롯 구조 ]

1개 프레임
   ↓ 시간 분할
슬롯 1 : 가입자 A 버스트
   ↓
슬롯 2 : 가입자 B 버스트
   ↓
슬롯 3 : 가입자 C 버스트
```

```text
[ 타임 슬롯 내부 구성 ]

프리앰블 (동기 비트열)
   ↓
정보 비트 (압축된 사용자 데이터)
   ↓
가드 타임 (슬롯 경계 보호)
```

- 타이밍 어드밴스 지시에 따라 단말이 송신 시점을 앞당기면 전파 지연과 무관하게 모든 버스트가 자기 슬롯 안에 도착하는 상태가 유지됨.

## Ⅳ. TDMA와 타 다중 접속 방식의 비교

- 핵심 요약 : 시간축 분할은 명확한 자원 배분과 결정론적 지연을 제공하는 대신 정밀 동기를 요구하는 방식.

| 비교 축 | FDMA | TDMA | CDMA |
| --- | --- | --- | --- |
| 채널 구분 기준 | 주파수 대역 | 시간 슬롯 | 확산 코드 |
| 전송 형태 | 연속 전송 | 불연속 버스트 | 연속 확산 전송 |
| 간섭 관리 | 보호 대역 | 동기화·가드 타임 | 전력 제어 |
| 동기 요구 수준 | 낮음 | 엄격 (슬롯 단위) | 코드 동기 |
| 적합 트래픽 | 고정 아날로그 음성 | 일정 전송률의 디지털 음성 | 음성·데이터 혼합 |

- 선택 기준 : 전송률이 일정하고 지연 예측이 중요한 음성·제어 트래픽에는 시분할이, 자원 배분의 유연성이 중요한 간헐적 데이터에는 패킷 기반 접속이 적합.

## Ⅴ. TDMA의 한계와 방안

- 핵심 요약 : 전파 지연 차에 따른 슬롯 침범, 유휴 슬롯 낭비, 전역 동기 부담을 적응형 동기·동적 할당·시각 동기 인프라로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 슬롯 침범 | 고속 이동·셀 경계에서 전파 지연 변화가 커져 인접 슬롯 데이터 훼손 | 타이밍 어드밴스 갱신 주기 단축과 가드 타임 재설계 | 슬롯 오류율 |
| 유휴 슬롯 낭비 | 무통화 가입자의 슬롯이 빈 채로 유지되어 채널 이용률 저하 | 트래픽 발생 시에만 배정하는 **동적 슬롯 할당** (트래픽 기반 슬롯 배정 방식) | 채널 이용률 |
| 전역 동기 부담 | 기지국 간 프레임 경계가 어긋나면 인접 셀 간 간섭 발생 | 위성 시각·네트워크 시각 동기 인프라 구축 | 기지국 간 시각 오차 |

## Ⅵ. TDMA에 대한 기술사적 제언

- 핵심 요약 : 슬롯 설계 원리의 계승과 트래픽 특성 기반 자원 배분 체계 구축.
- 이동통신 사업자 : 상·하향 트래픽 비율에 맞춘 슬롯 구성 최적화를 망 운영 지침에 반영.
- 위성 접속 사업자 : 긴 전파 지연 구간에 중앙 집중식 슬롯 예약 절차를 도입해 접속 충돌 방지.
- 산업 무선 설계 조직 : 결정론적 지연이 요구되는 공장 자동화 무선망에 슬롯 기반 스케줄링을 적용하고 동기 품질을 측정·관리.

## Ⅶ. 결론

- 핵심 요약 : TDMA는 시간 슬롯 배정으로 하나의 주파수에서 여러 가입자를 충돌 없이 수용하는 다중 접속 방식.
- 충돌 없는 전송의 대가인 정밀 시간 동기가 시스템 품질의 관건.
