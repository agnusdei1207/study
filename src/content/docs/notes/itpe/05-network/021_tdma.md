## 답안 골격
```text
[TDMA] ◀━━ 머리: Ⅶ 내 의견 (동기화 오버헤드 최소화를 위한 동적 대역폭 할당 D-TDMA 결합)
 ┃
 ┣━ Ⅰ 개요 ───── 단일 주파수 채널 충돌 방지 → 시간 프레임을 분할해 사용자별 배타 슬롯 할당
 ┣━ Ⅱ 특징 ───── 시간 분할 다중 접속, 버스트 전송, 상호 간섭 배제, 보호 시간(Guard Time) 필수
 ┣━ Ⅲ 구조 ───── TDMA 프레임 + 타임 슬롯(프리앰블 + 정보 데이터 + 보호 시간) + 마스터 클록
 ┣━ Ⅳ 흐름 ───── ① 기지국 동기 신호 브로드캐스트 → ② 단말 타이밍 동기화 → ③ 지정 슬롯 내 버스트 송신
 ┣━ Ⅴ 비교 ───── FDMA vs TDMA vs CDMA (주파수 분할 vs 시간 분할 vs 코드 분할)
 ┗━ Ⅵ 실무 ───── 전파 전파 지연차로 인한 슬롯 간 충돌 / 트래픽 미발생 시 타임 슬롯 낭비
```
- 필수 키워드: 타임 슬롯 · 프레임 구조 · 보호 시간(Guard Time) · 버스트 전송 · 동기화(Synchronization) · D-TDMA
- 배점 전략: 10점 = Ⅰ → Ⅲ TDMA 프레임 구조도 → Ⅴ 다중접속 3종 비교표 / 25점 = Ⅰ~Ⅶ, 140회 3교시 4번 기출(다. TDMA)에 맞춰 동기화 타이밍 어드밴스 상세
- 기출: 140회 3교시 4번 `다음 무선 통신 프로토콜을 설명하시오. 가. CSMA/CA 나. CDMA 다. TDMA` → Ⅰ~Ⅵ

## 한 줄 본질
- 여러 단말이 동일 주파수 대역을 동시 송신할 때 발생하는 물리적 전파 충돌 → 시간을 주기적인 프레임과 타임 슬롯으로 쪼개어 단말마다 고유한 송신 시간대를 독점 배정 → 주파수 필터링 복잡성 제거와 상호 간섭 원천 차단 / 슬롯 간 전파 겹침을 막기 위한 보호 시간(Guard Time) 소모와 엄격한 시간 동기화 요구

## 핵심 그림
```text
[ TDMA 프레임 및 타임 슬롯(Time Slot) 구조 ]

<------------------------ 1개 TDMA 프레임 (주기 T) ------------------------>
+----------------+----------------+----------------+----------------+
| 타임 슬롯 1    | 타임 슬롯 2    | 타임 슬롯 3    | 타임 슬롯 4    |
| (사용자 A 전송)| (사용자 B 전송)| (사용자 C 전송)| (사용자 D 전송)|
+----------------+----------------+----------------+----------------+
        |
        v [ 1개 타임 슬롯 상세 구조 ]
+----------------+--------------------------------+-----------------+
| 프리앰블/동기  | 사용자 정보 페이로드           | 보호 시간       |
| (Preamble/Sync)| (Data Payload)                 | (Guard Time)    |
+----------------+--------------------------------+-----------------+
                                                  <-- 충돌 방지 여유 -->
```

## 핵심 용어
- 보호 시간(Guard Time): 단말 간 거리 차이로 인한 전파 도달 시간 차이(Propagation Delay) 때문에 인접 타임 슬롯의 신호가 겹쳐 깨지는 것을 막기 위해 슬롯 끝에 비워두는 무신호 완충 구간
- 타이밍 어드밴스(Timing Advance): 기지국에서 멀리 떨어진 단말이 신호를 기지국의 수신 슬롯에 정확히 맞추기 위해 송신 타이밍을 앞당겨 쏘는 거리 보정 메커니즘
- 동적 TDMA(Dynamic TDMA): 고정된 슬롯 배정 대신 트래픽 유무에 따라 슬롯을 가변 할당하여 빈 슬롯 낭비를 방지하는 패킷 지향 통신 기법

## 핵심 통찰
- 주파수를 나누는 FDMA는 값비싼 아날로그 대역통과 필터(BPF)가 필수였으나, TDMA는 디지털 회로의 시간 스위칭만으로 다중화를 구현해 기지국 소형화와 경제성 혁신 주도
- 정적 TDMA(GSM 표준)는 음성 통화처럼 일정한 비트레이트에는 이상적이나, 버스트성 인터넷 데이터 통신에서는 단말이 데이터를 안 보낼 때도 슬롯이 낭비되는 근본 한계 노출
- 송신 단말이 고속 이동할 경우 기지국과의 거리가 실시간으로 변하므로, 슬롯 동기화가 조금만 어긋나도 이웃 사용자의 통화를 파괴하는 슬롯 붕괴 발생

## 이웃 토픽과 구분
- FDMA vs TDMA: FDMA는 전 시간에 걸쳐 좁은 주파수 대역을 쪼개어 연속 전송 / TDMA는 넓은 전체 주파수 대역을 정해진 짧은 시간 슬롯 동안만 버스트 전송

## 문제·원인·대책
- 적용 상황: 원거리 고속 이동체(KTX 열차 등)와 TDMA 기지국 통신
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 원거리 단말 신호가 인접 슬롯 침범 | 기지국-단말 거리 증가에 따른 전파 왕복 지연(RTT) 누적 | 기지국 측정 기반 정밀 타이밍 어드밴스(TA) 명령 하달 | 기지국 수신 타임 슬롯 경계 내 완벽한 신호 정렬 |
| 데이터 트래픽의 간헐적 발생 시 채널 낭비 | 고정 슬롯 할당 방식(Static Slot Allocation)의 유휴성 | 요구 기반 예약 접속(Reservation TDMA / D-TDMA) 전환 | 패킷 유무에 따른 동적 슬롯 배정으로 대역폭 활용률 2배 향상 |

## 내 의견
- [IoT 및 센서 네트워크에서의 TDMA 재조명] 경합 기반 CSMA/CA는 노드 밀집 시 충돌과 백오프 대기로 배터리를 빠르게 고갈시킴 → 나라면: 공장 센서망이나 스마트 그리드 AMR 환경에서 시간 동기화(IEEE 802.15.4e TSCH, Time Slotted Channel Hopping)를 적용한 저전력 TDMA를 도입하여, 충돌을 원천 배제하고 센서 배터리 수명을 10년 이상 연장하는 결정론적 인프라 구축
