## Ⅰ. TDMA의 개요

- 개념 : 동일한 무선 주파수 반송파의 전송 시간을 일정한 주기의 프레임(Frame)과 타임 슬롯(Time Slot)으로 분할하여, 복수의 가입자가 자신에게 독점적으로 할당된 시간 슬롯에만 버스트(Burst) 데이터를 전송하도록 하는 시분할 **다중 접속(Time Division Multiple Access)** 기술.
- 배경 및 필요성 : 1세대 이동통신(FDMA)의 아날로그 방식은 사용자가 통화하지 않는 묵음 구간에도 주파수 채널을 독점하여 자원 낭비가 심했으므로, 디지털 신호 압축 기술과 결합하여 단일 반송파당 다중 음성 채널을 수용하기 위해 2G GSM/IS-136의 핵심 기술로 채택됨.
- 핵심 목적 : 주파수 이용 효율 증대, 주파수 필터링 간소화를 통한 기지국 RF 비용 절감, 정밀한 시간 동기화를 통한 상호 간섭 없는 결정론적 전송 보장.

## Ⅱ. TDMA의 핵심 아키텍처 및 동작 메커니즘

TDMA는 프레임을 주기적으로 반복되는 타임 슬롯들로 나누고, 기지국과 단말 간의 전파 지연 차이를 보상하기 위해 가드 타임(Guard Time)과 타이밍 어드밴스(Timing Advance) 메커니즘을 적용하여 동작함.

```text
[ TDMA 프레임 구조 및 타이밍 어드밴스(TA) 메커니즘 ]

1. TDMA 다중 프레임 구조 (단일 주파수 F1)
+-----------------------------------------------------------------+
|                       1개 TDMA 프레임 (Frame)                   |
| +-----------+ +-----------+ +-----------+       +-------------+ |
| | Slot 1    | | Slot 2    | | Slot 3    |  ...  | Slot N      | |
| | (User 1)  | | (User 2)  | | (User 3)  |       | (User N)    | |
| +-----------+ +-----------+ +-----------+       +-------------+ |
+-----------------------------------------------------------------+

2. 단일 타임 슬롯 내부 구조
+-----------------------------------------------------------------+
| Preamble (동기) | Information Bits (데이터 페이로드) | Guard Time |
+-----------------------------------------------------------------+
                                                       ▲
                                    (슬롯 간 전파 겹침 방지 여백)

3. 기지국과의 거리에 따른 Timing Advance (TA)
   기지국 (gNB)
        │
        ├── [근거리 단말 A] : 지연시간 짧음 ──> 정시 발송
        │
        └── [원거리 단말 B] : 전파 지연 발생 ──> 기지국 지시에 따라 TA만큼 조기 발송!
            (결과: 기지국 수신단에서는 슬롯 1과 슬롯 2가 완벽히 동기화되어 충돌 없음)
```

- **타임 슬롯(Time Slot)** : 사용자에게 독점적으로 할당되는 수백 마이크로초 단위의 최소 전송 시간 단위.
- **가드 타임(Guard Time)** : 인접 슬롯 간 전파 지연 오차 및 클록 지터로 인해 신호가 겹쳐 충돌하는 것을 방지하기 위해 슬롯 끝에 배치된 유휴 시간 간격.
- **타이밍 어드밴스(Timing Advance: TA)** : 기지국이 원거리 단말의 전파 지연을 계산하여, 단말이 자신의 할당 슬롯보다 미리 앞당겨 신호를 발송하도록 명령하는 동기화 메커니즘.
- **프리앰블(Preamble)** : 매 타임 슬롯 서두에 배치되어 수신단이 버스트 신호의 시작 시점과 반송파 주파수 오프셋을 동기화할 수 있도록 지원하는 기지 신호열.

## Ⅲ. TDMA의 세부 구성 요소 및 비교 분석

| 비교 항목 | TDMA (시분할 다중 접속) | FDMA (주파수 분할) | CDMA (코드 분할) | CSMA/CA (경쟁 접속) |
|---|---|---|---|---|
| 채널 분할 축 | 시간 (Time Slot) | 주파수 (Frequency) | 부호 (Orthogonal Code) | 임의 경쟁 (Random Access) |
| 신호 전송 형태 | 불연속 버스트(Burst) | 연속 전송 (Continuous) | 연속 확산 전송 | 버스트 패킷 전송 |
| 상호 간섭 대책 | Guard Time & TA 보상 | Guard Band (주파수 여백)| 전력 제어 (Power Control)| Backoff & RTS/CTS |
| 동기화 요구도 | 매우 엄격 (마이크로초) | 낮음 | 매우 엄격 (칩 동기화) | 낮음 (비동기 경쟁) |
| 트래픽 적합성 | 음성 등 고정 전송률 | 고정 아날로그 음성 | 가변 음성 및 데이터 | 버스트 데이터 통신 |

- TDMA는 엄격한 시간 동기화와 가드 타임 설계를 전제로 단일 주파수에서 다중 가입자를 상호 간섭 없이 분리 수용하는 결정론적 다중 접속 방식임.

## Ⅳ. TDMA의 주요 한계점 및 해결 방안

- 지리적으로 분산된 단말 간 전파 지연 차이로 인한 슬롯 간 간섭(ISI) :
  - 한계점 : 단말의 고속 이동이나 셀 경계 위치 시 수신 신호가 인접 슬롯을 침범하여 타 사용자 데이터 파손.
  - 해결 방안 : 정밀한 폐루프 타이밍 어드밴스(TA) 명령어 갱신 주기 단축 및 적응형 가드 타임 확보.
- 버스트 데이터 통신 환경에서의 유휴 슬롯 자원 낭비 :
  - 한계점 : 사용자가 데이터를 전송하지 않는 유휴 순간에도 고정된 시간 슬롯이 점유되어 채널 이용률 저하.
  - 해결 방안 : 트래픽 발생 시에만 슬롯을 온디맨드로 할당하는 동적 TDMA(Dynamic TDMA) 및 패킷 예약 다중 접속(PRMA) 도입.
- 네트워크 전역의 고정밀 클록 동기화 인프라 구축 부담 :
  - 한계점 : 기지국 간 프레임 동기가 어긋날 경우 TDD 및 핸드오버 전송에 심각한 간섭 초래.
  - 해결 방안 : GPS 및 IEEE 1588 PTP(Precision Time Protocol) 기반 나노초 단위 백본 동기화망 구축.

## Ⅴ. TDMA 적용 및 발전을 위한 기술사적 제언

- 5G/6G TDD(Time Division Duplex) 프레임 구조 설계에 TDMA 원리 고도화 : 하향 링크(DL)와 상향 링크(UL) 간 슬롯 비율을 트래픽 패턴에 맞추어 실시간 재구성하는 동적 TDD(Dynamic TDD) 설계 권장.
- 위성 통신(DVB-RCS2) 및 항공 관제(VDL Mode 2)의 슬롯 스케줄러 최적화 : 수백 ms 지연이 발생하는 위성 백홀 환경에서 슬롯 충돌을 방지하기 위한 중앙 집중형 온디맨드 슬롯 예약 메커니즘 적용 필수.
- 시간 민감형 산업용 센서 네트워크(TSN over Wireless) 표준 연계 : 스마트 팩토리 무선 제어를 위해 IEEE 802.15.4e TSCH(Time Slotted Channel Hopping) 기술을 결합하여 결정론적 100% 무손실 슬롯 스케줄링 구현.
