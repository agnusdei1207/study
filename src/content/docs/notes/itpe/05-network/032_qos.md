## 30초 인출

- 본질: **QoS(Quality of Service)** : 네트워크 서비스의 대역폭·지연·지터·손실 요구를 구분해 자원을 관리하는 정책·기능
- 메커니즘: 트래픽 분류·마킹 → 대역폭·큐·우선순위 제어 → 혼잡·손실 관리 → 종단 성능 측정

<details>
<summary>핵심 용어</summary>

- **QoS(Quality of Service)** : 네트워크가 트래픽별 품질 요구를 다루기 위한 측정·자원 관리 정책과 기능
- **대역폭(Bandwidth)** : 링크가 전달할 수 있는 비트율 용량; 응용 처리율과 구별
- **지연(Delay/Latency)** : 패킷이 출발지에서 목적지까지 전달되는 시간
- **지터(Jitter)** : 패킷 지연의 변동
- **패킷 손실률(Packet Loss Rate)** : 보낸 패킷 중 목적지에 도달하지 못한 비율
- **폴리싱(Policing)** : 트래픽 프로파일 초과분을 표시·폐기하는 속도 제어 기능
- **셰이핑(Shaping)** : 트래픽을 버퍼에 보관해 설정된 프로파일에 맞춰 송출하는 기능
- **스케줄링(Scheduling)** : 혼잡 큐에서 패킷 전송 순서·자원을 배분하는 기능
- **WRED(Weighted Random Early Detection)** : 큐 혼잡이 심해지기 전에 설정된 조건·확률로 패킷을 조기 폐기하는 혼잡 회피 기법

</details>

| 정의 | **QoS** : 트래픽별 품질 요구에 맞춰 네트워크 자원과 전달 동작을 관리하는 정책·기능 |

---

## 2~4교시 25점 답안

### Ⅰ. QoS의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **QoS** : 트래픽별 품질 요구에 맞춰 네트워크 자원과 전달 동작을 관리하는 정책·기능 |
| 목적 | 서비스 요구에 맞는 품질 측정·차등 자원 운용 |

### Ⅱ. QoS 처리 흐름

```text
트래픽 분류·마킹
        ↓
폴리싱·셰이핑
        ↓
큐잉·스케줄링
        ↓
링크 전달
        ↓
지연·지터·손실·처리율 측정
```

### Ⅲ. 품질 지표

| 지표 | 관점 | 운용상 의미 |
|---|---|---|
| 대역폭·처리율 | 수용 용량·실제 전송률 | 링크 용량, 응용 처리량을 구별 |
| 지연 | 전송 소요 시간 | 대화형·제어 서비스의 응답성 |
| 지터 | 지연 변동 | 실시간 음성·영상의 버퍼링·재생 품질 |
| 손실 | 전달되지 않은 패킷 비율 | 재전송·화질·응용 정확도에 영향 |

### Ⅳ. 혼잡 관리 기능

| 기능 | 처리 | 주요 효과·비용 |
|---|---|---|
| 분류·마킹 | 서비스·정책 기준으로 트래픽 식별 | 이후 큐·PHB 정책의 입력값 |
| 폴리싱 | 초과분을 표시하거나 폐기 | 프로파일 준수, 초과 패킷 손실 가능 |
| 셰이핑 | 버퍼링 뒤 프로파일에 맞춰 송출 | 버스트 완화, 큐잉 지연·버퍼 필요 |
| 스케줄링 | 큐별 전송 순서·비율 배분 | 우선순위·공평성·기아 위험 조정 |
| 혼잡 회피 | 혼잡 전에 폐기·신호 | 큐 팽창 완화, 설정·응용 반응 고려 |

### Ⅴ. 적용 정책 선택

| 트래픽 특성 | 검토 정책 |
|---|---|
| 낮은 지연·지터 요구 | 우선 큐·혼잡 구간의 용량과 제한 설정 |
| 버스트 흡수 필요 | 셰이핑·버퍼 크기·허용 지연 검토 |
| 탄력적 데이터 전송 | 공정 스케줄링·혼잡 회피·처리율 측정 |
| 복수 도메인 통과 | 경계 간 분류·마킹·서비스 수준 매핑 확인 |

### Ⅵ. 한계와 대응

| 한계 | 대응 |
|---|---|
| 품질 정책은 링크 용량을 늘리지 않음 | 혼잡 링크 증설·우회와 정책 조정을 함께 비교 |
| 큐 우선순위가 낮은 트래픽을 굶길 수 있음 | 우선 큐 제한과 하위 클래스 최소 자원 검토 |
| 셰이핑이 지연·버퍼 소모를 유발 | 응용 지연 한도와 프로파일을 함께 설정 |
| 한 홉의 설정만으로 종단 품질 보장 불가 | 종단 경로 전체와 외부 도메인 구간을 측정·관리 |

### Ⅶ. 기술사적 제언

| 우선 설계 | 운영·확인 |
|---|---|
| 업무 중요도보다 서비스의 실제 지연·손실 요구에 기반해 정책 선정 | 종단 측정으로 목표 충족을 확인하고, 미충족 시 증설·경로·큐 정책을 재평가 |
