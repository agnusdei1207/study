## Ⅰ. QoS(Quality of Service)의 개요

- 개념 : 한정된 네트워크 대역폭과 자원 하에서 다양한 응용 서비스의 서로 다른 요구 조건(대역폭, 지연, 지터, 패킷 손실률)을 만족시키기 위해, 네트워크 트래픽을 분류·통제·우선순위화하여 차등화된 서비스 품질을 보장하는 종합 네트워킹 제어 기술.
- 배경 및 필요성 : 인터넷 트래픽이 단순 텍스트/웹 서핑 위주에서 실시간 화상회의, VoIP, 금융 트레이딩, 4K 스트리밍, AI 분산 학습 등 서비스 유형별 요구 사항이 극단적으로 분화됨에 따라 단순 **Best-Effort** 전송의 품질 붕괴를 해결하기 위해 필수화됨.
- 핵심 목적 : **대역폭(Bandwidth)** 보장, **종단 간 지연시간(Latency)** 단축, **지터(Jitter: 지연 변이)** 억제, 버퍼 오버플로우로 인한 패킷 손실률(Packet Loss) 최소화.

## Ⅱ. QoS(Quality of Service)의 핵심 아키텍처 및 동작 메커니즘

QoS는 4대 핵심 성능 지표를 기반으로 인입 제어(분류·마킹·폴리싱·셰이핑), 혼잡 관리(큐잉 스케줄링), 혼잡 회피(능동적 드롭)의 3단계 파이프라인 메커니즘으로 동작함.

```text
[ QoS 3단계 파이프라인 처리 아키텍처 ]

[ 인입 트래픽 ]
      │
      ▼
+-----------------------------------------------------------------+
| 1단계: 인입 제어 (Ingress Control & Conditioning)               |
|  - 분류 (Classification): ACL, IP 5-Tuple, CoS/DSCP 확인        |
|  - 마킹 (Marking): 패킷 헤더에 우선순위 등급 부여 (DSCP 0~63)    |
|  - 트래픽 미터링: 대역폭 초과 여부 측정 (Token Bucket)          |
|    * 폴리싱 (Policing): 초과분 즉시 드롭 (입구 인터페이스)       |
|    * 셰이핑 (Shaping): 초과분 버퍼링 후 평활 송출 (출구 링크)    |
+---------------------------------│────────────────---------------+
                                  │
                                  ▼
+-----------------------------------------------------------------+
| 2단계: 혼잡 관리 (Congestion Management: 스케줄링 & 큐잉)        |
|  - 출력 인터페이스 혼잡 시 트래픽을 복수 큐로 분리 격리          |
|  - 큐잉 알고리즘: FIFO, PQ, CQ, WFQ, CBWFQ, LLQ(Low Latency)   |
+---------------------------------│────────────────---------------+
                                  │
                                  ▼
+-----------------------------------------------------------------+
| 3단계: 혼잡 회피 (Congestion Avoidance: 큐 포화 방지)            |
|  - 큐가 100% 차기 전에 조기 무작위 드롭으로 TCP 전역 동기화 방지 |
|  - 알고리즘: Tail Drop (기본) -> RED -> WRED (DSCP 연동 차등)    |
+-----------------------------------------------------------------+
```

- QoS 4대 지표 : 대역폭(bps), 지연시간(One-way Delay), 지터(Delay Jitter), 패킷 손실률(Packet Loss Rate).
- **분류 및 마킹(Classification & Marking)** : 인입 패킷의 헤더 정보를 분석하여 적절한 CoS(L2 802.1p) 또는 DSCP(L3) 우선순위 값을 헤더에 기록.
- **트래픽 폴리싱 vs 셰이핑** : 폴리싱은 계약 대역폭 초과 시 즉시 패킷을 드롭(버스트 허용 안 함)하고, 셰이핑은 지연 버퍼를 두어 부드러운 전송률로 평활화(버퍼 메모리 소모).
- **혼잡 관리(스케줄링)** : LLQ(Low Latency Queuing)를 통해 실시간 음성 트래픽은 Strict Priority로 절대 우선 처리하고, 나머지 데이터는 CBWFQ로 공정 배분.
- **혼잡 회피(WRED)** : 가중치 기반 무작위 조기 검출(WRED)을 적용하여 큐의 평균 길이가 임계치에 도달하면 중요도가 낮은 패킷부터 무작위 드롭하여 TCP 슬로우 스타트 분산 유도.

## Ⅲ. QoS(Quality of Service)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 최선형 서비스 (Best-Effort) | 통합 서비스 모델 (IntServ) | 차등 서비스 모델 (DiffServ) |
|---|---|---|---|
| QoS 보증 수준 | 품질 보장 전혀 없음 | 절대적 결정론적 보장 | 통계적 상대적 차등 보장 |
| 자원 예약 방식 | 사전 예약 없음 | RSVP 프로토콜 명시적 예약 | 패킷 헤더 DSCP 기반 우선순위 |
| 코어 라우터 상태 | 상태 없음 (Stateless) | 플로우별 상태 유지 (Stateful) | 상태 없음 (Stateless) |
| 네트워크 확장성 | 무제한 | 매우 취약 (수천 플로우 한계) | 매우 뛰어남 (글로벌 백본 표준) |
| 구현 복잡도 | 가장 낮음 | 매우 높음 (종단간 시그널링) | 중간 (경계 라우터 정책 집중) |
| 주요 적용처 | 일반 웹 트래픽, 공용망 | 특수 폐쇄망, 원격 수술 | 엔터프라이즈 사내망, 클라우드 |

- 완벽한 QoS를 위해서는 IntServ식 시그널링보다 DiffServ 기반의 클래스 분류와 WRED, LLQ 스케줄링의 유기적 결합이 실무 엔지니어링의 정답으로 안착함.

## Ⅳ. QoS(Quality of Service)의 주요 한계점 및 해결 방안

- 공용 인터넷(ISP 구간) 통과 시 종단 간(E2E) QoS 정책 단절 :
  - 한계점 : 사내망에서 아무리 정교하게 마킹해도 공용 인터넷 구간을 지나면서 ISP가 DSCP를 0으로 리셋하여 QoS 파괴.
  - 해결 방안 : 클라우드 전용선(Direct Connect, ExpressRoute) 또는 SD-WAN 기반 오버레이 암호화 터널링 구성.
- 대용량 라우터 버퍼 적체로 인한 버퍼블로트(Bufferbloat) 현상 :
  - 한계점 : 손실을 줄이려고 버퍼를 과도하게 키우면 패킷 드롭은 없으나 지연시간이 수백 ms로 폭증하여 실시간 서비스 마비.
  - 해결 방안 : CoDel(Controlled Delay), FQ-CoDel, CAKE 등 최신 능동적 큐 관리(AQM) 알고리즘 적용.
- L7 암호화(HTTPS, QUIC) 트래픽 증가로 패킷 심층 분류 불가 :
  - 한계점 : 전통적 NBAR나 DPI 장비가 페이로드를 열어보지 못해 비디오와 일반 웹 트래픽 구분 실패.
  - 해결 방안 : SNI 정보, 패킷 크기 및 도달 간격 통계 특성을 학습한 AI 기반 트래픽 분류 엔진 도입.

## Ⅴ. QoS(Quality of Service) 적용 및 발전을 위한 기술사적 제언

- 엔터프라이즈 WAN 환경의 SD-WAN 지능형 경로 선택(Dynamic Path Selection) 구현 : 지연, 지터, 패킷 손실률을 실시간 프로빙하여 VoIP는 MPLS로, 일반 백업은 인터넷으로 동적 우회 정책 수립.
- AI 데이터센터 고성능 컴퓨팅을 위한 RoCE v2 무손실(Lossless) QoS 구축 : GPU 분산 학습 패브릭에서 인캐스트(Incast) 혼잡에 따른 패킷 드롭을 방지하기 위해 PFC(Priority Flow Control) 및 ECN 연계 튜닝 필수.
- SLA 모니터링 시스템과의 실시간 연동(Closed-Loop QoS) : 합성 트래픽 모니터링(Synthetic Probing)을 통해 지연 지표가 임계치를 초과할 경우 QoS 정책을 동적으로 상향 조정하는 오케스트레이션 수립 권장.
