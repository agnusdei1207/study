## 연관 키워드

- QoS(Quality of Service), 4대 품질 지표(대역폭·지연·지터·손실률), 분류(Classification), 마킹(Marking), 큐잉(Queuing)
- 폴리싱(Policing), 셰이핑(Shaping), 토큰 버킷(Token Bucket), DSCP(Differentiated Services Code Point), AQM(Active Queue Management), SLA(Service Level Agreement)

## Ⅰ. QoS의 개요

- 핵심 요약 : 한정된 망 자원에서 응용별 품질 요구를 맞추도록 트래픽을 구분하고 차등 처리하는 제어 체계.
- 개념 : 대역폭, 지연, 지터(지연 변동 폭), 패킷 손실률을 응용별 목표로 관리하도록 트래픽을 구분·우선 처리하는 **서비스 품질** (QoS, Quality of Service) 기술 체계.
- 배경 및 필요성 : 화상회의·음성·금융·AI 분산 학습 트래픽의 요구 조건이 상이한 가운데, 모든 패킷을 동일하게 취급하는 **최선형**(Best-Effort) 전송에서는 혼잡 시 품질이 무너지는 구조.
- 주요 목적 : 대역폭 보장, 지연·지터 억제, 손실 최소화, 망 자원의 용도별 배분.

## Ⅱ. QoS의 특징 및 장점

- 핵심 요약 : 지표 관리, 표시 기반 등급화, 메커니즘 조합이 체감 품질 확보로 연결되는 구조.

1. 4대 지표의 목표 관리 : 대역폭·지연·지터·손실률을 응용별로 정량 목표화 → 서비스별 품질 기준의 명확화.
2. 표시 기반 등급화 : **분류**(Classification, 트래픽의 판별)와 **마킹**(Marking, 헤더에 등급 기록)으로 이더넷 계층의 CoS(Class of Service)나 IP 계층의 DSCP(Differentiated Services Code Point) 부여 → 이후 장비가 헤더만 판독.
3. 등급별 큐잉 : **큐잉**(Queuing, 등급별 대기 큐와 송출 순서의 제어)으로 실시간·중요 트래픽 우선 송출 → 링크 혼잡 시에도 품질 유지.
4. 유입량 통제 : **폴리싱**(Policing, 초과 트래픽의 즉시 폐기·강등)과 **셰이핑**(Shaping, 초과 트래픽의 버퍼링 후 평활 송출)으로 계약 대역 준수 → 하류 구간 보호.
5. 조기 혼잡 회피 : 큐 포화 이전의 확률적 폐기로 송신측 감속 유도 → 전면 붕괴의 예방.

## Ⅲ. QoS의 구조 (흐름)

- 핵심 요약 : 분류·마킹 → 유입 통제 → 등급별 큐잉 → 혼잡 회피로 이어지는 파이프라인.

```text
[ QoS 처리 파이프라인 ]

패킷 인입
    ↓
1. 분류 · 마킹 (등급 부여)
    ↓
2. 유입 통제 (미터링 기준)
    ↓
3. 등급별 큐잉 (스케줄링)
    ↓
4. 혼잡 회피 (조기 폐기)
    ↓
출력 링크
```

- 유입 통제의 기준은 **토큰 버킷**(Token Bucket, 토큰의 충전 속도로 허용 전송량을 판정하는 알고리즘)으로 판정하는 구성이 대표적.

```text
[ 초과 트래픽의 두 처리 ]

폴리싱 : 즉시 폐기·재표시
    → 버퍼 없음, 재전송 유발
셰이핑 : 버퍼링 후 평활 송출
    → 지연 추가, 손실 감소
```

- 큐잉 기법은 절대 우선 큐, 클래스별 가중 배분, 저지연 큐의 조합으로 구성되며 가중 공정 배분 계열의 상세는 별도 노트에서 다룸.

## Ⅳ. QoS 모델의 비교 (Best-Effort와 IntServ, DiffServ)

- 핵심 요약 : 보장 수준과 확장성의 균형에서 등급 집약 방식이 대규모 망의 실무 기본값이 되는 관계.
- 흐름 예약 방식은 IntServ(Integrated Services), 등급 집약 방식은 DiffServ(Differentiated Services)라 부름.

| 비교 축 | Best-Effort | IntServ (통합 서비스) | DiffServ (차등 서비스) |
| --- | --- | --- | --- |
| 보장 수준 | 없음 | 흐름별 절대 보장 | 클래스별 상대 보장 |
| 자원 예약 | 없음 | RSVP(Resource Reservation Protocol) 명시 예약 | 사전 예약 없음 |
| 코어 상태 | 없음 | 흐름별 상태 보유 | 상태 비보유 |
| 확장성 | 제한 없음 | 흐름 수에 취약 | 대규모에 적합 |
| 구현 부담 | 최소 | 종단 시그널링으로 높음 | 경계 정책으로 중간 |

- 선택 기준 : 대규모 공용 망은 등급 집약 방식이 기본이고, 소규모 폐쇄망의 절대 보장은 흐름 예약 방식, 품질 요구가 없는 구간은 최선형 유지.

## Ⅴ. QoS의 한계와 방안

- 핵심 요약 : 공용 구간의 정책 단절, 과대 버퍼의 지연, 암호화 트래픽의 분류 곤란을 구간별 설계·능동 큐 관리·통계 분류로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 공용 구간 정책 단절 | 사업자 구간의 DSCP 재설정 → 종단 품질 파괴 | 전용선·암호화 오버레이로 구간별 품질 계약 체결 | 구간별 DSCP 유지율 |
| 과대 버퍼의 지연 | 손실 회피용 대형 버퍼가 큐잉 지연 확대 | 능동 큐 관리(AQM, Active Queue Management) 기법 적용 | 큐 지연 시간 |
| 암호화 트래픽 분류 곤란 | 페이로드 검사 불가 → 응용 식별 실패 | 흐름 통계 기반 분류와 응용 단 마킹 정책 병용 | 분류 정확도 |

## Ⅵ. QoS에 대한 기술사적 제언

- 핵심 요약 : 구간별 품질 책임의 명확화와 측정 기반 자동 조정으로 QoS를 상시 운영 체계에 내재화하는 방향.
- 광역망 운영 조직은 소프트웨어 정의 광역 네트워크(SD-WAN, Software-Defined Wide Area Network)로 응용 식별 결과를 등급 표시에 연결하고 회선 품질에 따라 경로를 선택하는 체계 도입.
- 데이터센터 운영 조직은 무손실 수요 구간에 우선순위 기반 흐름 제어와 혼잡 통지(ECN, Explicit Congestion Notification) 임계치를 짝지어 튜닝하는 절차 운영.
- 품질 관리 조직은 SLA(Service Level Agreement) 지표를 합성 측정으로 상시 감시하고 임계 초과 시 정책을 자동 갱신하는 폐루프 체계 구축.

## Ⅶ. 결론

- 핵심 요약 : QoS는 자원을 늘리는 대신 요구에 따라 나누는 배분 규율의 체계.
- 분류부터 혼잡 회피까지의 일관된 설계와 구간별 책임 체계가 갖춰질 때 품질 보장의 실효성이 성립.
