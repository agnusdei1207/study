## 연관 키워드

- 6G, IMT-2030, 테라헤르츠(THz), 지능형 반사 표면(RIS)
- 극대규모 안테나(ELAA), 통신-감지 일체화(ISAC), AI 네이티브 네트워크
- 비지상망(NTN), 양자 암호키 분배(QKD), 포스트 양자 암호(PQC), 오픈 RAN(O-RAN)

## Ⅰ. 6G 이동통신기술의 개요

- 핵심 요약 : 통신에 인공지능·감지·위성 연동을 결합한 2030년대 차세대 이동통신 기술.
- 개념 : 지상 중심 통신을 넘어 인공지능 운영과 환경 감지, 지상·공중·우주를 잇는 **비지상망** (NTN, Non-Terrestrial Network) 환경을 수용하는 차세대 이동통신 기술인 **6G** (6th Generation)으로, ITU(International Telecommunication Union)의 **IMT-2030** (International Mobile Telecommunications-2030) 프레임워크가 국제 기준임.
- 배경 및 필요성 : 5G(IMT-2020, International Mobile Telecommunications-2020)는 지상 기지국 중심의 커버리지와 수십 밀리초 실효 지연, 망 운영의 외부 AI 의존이라는 한계가 제기됨. 초실감 서비스와 디지털 트윈, 도심항공교통(UAM, Urban Air Mobility) 같은 2030년대 수요에 대응이 필요함.
- 주요 목적 :
  1. 초대용량·초저지연 전송 성능의 확보
  2. 통신 신호 기반 감지 기능의 제공
  3. 3차원 무음영 커버리지의 실현
  4. 망 전 계층의 자율 운영

## Ⅱ. 6G의 특징 및 장점

- 핵심 요약 : 주파수 확장과 지능형 제어, 3차원 망 구성이 용량·커버리지·자율성의 동시 향상으로 이어지는 구조.

1. **테라헤르츠** (THz, Terahertz) 대역 활용 : 100GHz 이상의 광대역 자원 사용 → 초대용량 전송과 고해상도 감지의 가능성 확보.
2. **지능형 반사 표면** (RIS, Reconfigurable Intelligent Surface) : 반사체의 위상을 능동 제어해 전파 경로를 조정 → 음영 지역 커버리지 보완.
3. **극대규모 안테나** (ELAA, Extremely Large Aperture Array) : 수천 소자 규모의 안테나 배열로 좁은 빔 형성 → 고주파 경로 손실의 보상.
4. **AI 네이티브 네트워크** : 무선 제어와 망 운영 전 계층에 학습 기능 내재화 → 자원 배분·장애 대응의 자율성 향상.
5. **통신-감지 일체화** (ISAC, Integrated Sensing and Communication) : 하나의 신호로 통신과 객체 감지를 동시 수행 → 하드웨어 중복 감소와 환경 인지 기능 획득.
6. 보안 강화 기술 : **양자 암호키 분배** (QKD, Quantum Key Distribution)와 **포스트 양자 암호** (PQC, Post-Quantum Cryptography) 적용 연구 → 양자컴퓨터 시대의 장기 보안성 확보.

## Ⅲ. 6G의 구조 (흐름)

- 핵심 요약 : AI 제어 계층이 개방형 무선망과 지상·비지상 링크를 통합 조정하는 계층 구조.
- **오픈 RAN** (O-RAN, Open Radio Access Network) : 무선 장비의 하드웨어·소프트웨어 분리와 지능형 제어기(RIC, RAN Intelligent Controller)를 통한 개방형 무선망 구조.

```text
[ 6G 네트워크 계층 구조 ]

AI 네이티브 제어 (코어·무선 지능)
    ↓
오픈 RAN (무선 지능 제어기 포함)
    ↓
지상망 + 비지상망 (위성·고고도 플랫폼)
    ↓
테라헤르츠·중대역 링크 + RIS
```

```text
[ 통신-감지 일체화 동작 ]

통신 데이터를 담은 송신 신호
    ↓ 주변 객체에서의 반사
반사 신호 수신·비교 분석
    ↓
위치·속도·형상 정보 산출
```

- IMT-2030 사용 시나리오 : 여섯 축으로 정의됨.
  1. 몰입형 통신 (Immersive Communication)
  2. 초신뢰·초저지연 통신 (Hyper Reliable and Low-Latency Communication)
  3. 대규모 통신 (Massive Communication)
  4. 어디서나 연결 (Ubiquitous Connectivity)
  5. AI와 통신의 융합 (AI and Communication)
  6. 통신-감지 일체화 (Integrated Sensing and Communication)

## Ⅳ. 5G와 6G의 비교

- 핵심 요약 : 5G의 성능 축을 확장하면서 감지·AI 제어·3차원 커버리지를 새 축으로 추가한 진화.

| 비교 항목 | 5G (IMT-2020) | 6G (IMT-2030) |
| --- | --- | --- |
| 정점 속도 목표 | 20Gbps | 50~200Gbps (권고 시범값) |
| 지연 목표 | 사용자면 1ms | 0.1~1ms 수준 (시범값) |
| 연결 밀도 | 10⁶ 기기/km² | 최대 10⁸ 기기/km² (시범값) |
| 커버리지 | 지상 중심 | 지상·공중·우주 3차원 |
| 지능화 수준 | AI 보조·사후 최적화 | AI 내재화·자율 운영 |
| 감지 기능 | 별도 센서 의존 | 통신 신호 기반 감지 |

- 선택 기준 : 고정형 광대역 서비스는 5G·5G-Advanced로 충족하고, 감지·자율 제어와 3차원 커버리지가 필요한 영역을 6G 대상으로 구분함.

## Ⅴ. 6G의 한계와 방안

- 핵심 요약 : 테라헤르츠 전파 한계와 부품 전력 문제, AI 신뢰성을 반사 표면·고효율 소자·설명가능 AI로 극복.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 테라헤르츠 전파 감쇠 | 대기 흡수·낮은 회절로 도달 거리가 짧음 | RIS의 분산 배치와 중대역 반송파 집성 | 셀 반경·음영률 |
| 고주파 부품 전력·발열 | 증폭기·변환기의 낮은 효율이 운영비와 배터리 부담 | 화합물 반도체 소자와 광-무선 융합 전송의 적용 | 전력 효율 |
| AI 제어 신뢰성 부족 | 판단 근거가 불투명해 이상 동작 추적이 곤란 | 설명가능 AI(XAI, Explainable AI) 적용과 안전 모드 전환 설계 | 이상 복구 시간 |

## Ⅵ. 6G에 대한 기술사적 제언

- 핵심 요약 : 주파수 확보·검증 체계·표준 주도를 선제 준비하는 국가 차원의 전략.

1. 정부는 세계전파통신회의(WRC, World Radiocommunication Conference) 논의에 맞춰 중대역·서브테라헤르츠 대역의 주파수 로드맵을 조기에 확정할 필요가 있음.
2. 연구기관과 사업자는 후보 기술의 공동 실증 시험베드를 구축해 표준화 반영 전에 성능과 안전성을 검증해야 함.
3. 표준·법제 부문은 **6G 기술개발 촉진 및 표준화에 관한 특별법**의 체계를 활용해 표준 특허 확보와 지상·위성 연동 표준화를 지원해야 함.

## Ⅶ. 결론

- 핵심 요약 : 6G는 감지·AI·3차원 커버리지를 통신에 결합한 차세대 무선 인프라임.
- 시사점 : 기술 완성도와 함께 주파수·검증·표준의 준비 속도가 상용화 시점을 결정함.
