## 연관 키워드

- 6G, IMT-2030, 테라헤르츠(THz), 지능형 반사 표면(RIS)
- 통신-감지 일체화(ISAC), AI-Native 네트워크, 극대규모 MIMO(E-MIMO)
- 오픈 RAN(O-RAN), 양자 암호 통신(QKD), 포스트 양자 암호(PQC), 비지상망(NTN)

## Ⅰ. 6G 이동통신기술의 개요

- 핵심 요약 : 통신, 인공지능, 감지, 위성 연동을 하나의 무선 네트워크로 묶는 차세대 이동통신 기술.
- 개념 : 사람 중심 통신을 넘어 인공지능, 자율 시스템, 초실감 서비스, 지상과 우주를 잇는 **비지상망** (NTN, Non-Terrestrial Network) 환경을 수용하는 차세대 이동통신 기술로, 국제전기통신연합(ITU, International Telecommunication Union)의 **IMT-2030**(International Mobile Telecommunications-2030) 프레임워크가 기준이 됨.
- 배경 및 필요성 : 5G는 지상 중심의 커버리지, 수십 밀리초 수준의 실효 지연, 망 운영 측면의 외부 AI 의존이라는 한계를 드러냈고, 디지털 트윈, 무선 환경 감지, 도심항공교통(UAM, Urban Air Mobility) 같은 2030년대 서비스 수요가 예상됨.
- 주요 목적 :
  1. 5G보다 훨씬 높은 전송 성능 확보
  2. 무선 구간의 저지연 및 초신뢰 통신 확보
  3. 무선 신호로 물리 환경을 감지하는 기능 제공
  4. 지상과 공중, 우주를 포함한 3차원 무음영 커버리지 구현

## Ⅱ. 6G의 특징 및 장점

- 핵심 요약 : 주파수 확장, 지능형 제어, 3차원 망 구성이 결합되어 성능 향상과 커버리지 확대를 동시에 얻는 구조.

1. **테라헤르츠** (THz, Terahertz) 대역 활용 : 100GHz 이상의 넓은 대역을 사용 → 초대용량 무선 전송 가능성 확보.
2. **지능형 반사 표면** (RIS, Reconfigurable Intelligent Surface) : 메타물질 표면으로 전파의 반사 방향과 위상을 제어 → 전파 음영 지역의 커버리지 보완.
3. **AI-Native 네트워크** : 무선 제어와 망 운영 전 계층에 학습 기능을 내재화 → 자원 배분과 장애 대응의 자율성 향상.
4. **극대규모 MIMO** (E-MIMO, Extremely Large MIMO) : 수천 개 이상의 안테나 소자로 좁은 빔을 형성 → 테라헤르츠 대역의 경로 손실 보상.
5. **통신-감지 일체화** (ISAC, Integrated Sensing and Communication) : 하나의 무선 신호로 통신과 주변 객체 감지를 동시에 수행 → 하드웨어 중복 감소와 환경 인지 기능 확보.
6. **양자 암호 통신** (QKD, Quantum Key Distribution)과 **포스트 양자 암호** (PQC, Post-Quantum Cryptography) : 양자 컴퓨터 시대의 도청 위협에 대비해 무선 링크의 보안 계층을 강화하는 연구 대상 → 장기 보안성 확보.

## Ⅲ. 6G의 구조 (흐름)

- 핵심 요약 : AI 제어 계층이 개방형 무선망과 지상·비지상 링크를 조정하는 계층 구조.

```text
[ 6G 네트워크 계층 구조 ]

AI-Native 제어 (코어·무선 지능)
            ↓
오픈 RAN (Near-RT RIC 실시간 제어)
            ↓
지상망 + 비지상망 (위성, 고고도 플랫폼)
            ↓
THz·중대역 무선 링크 + RIS
```

- **오픈 RAN** (O-RAN, Open Radio Access Network) : 무선 하드웨어와 소프트웨어를 분리하고, 준실시간 무선 지능 제어기(Near-RT RIC, Near-Real-Time RAN Intelligent Controller)로 무선 자원을 실시간 제어하는 개방형 구조.

```text
[ 통신-감지 일체화 (ISAC) ]

송신 신호 (통신 데이터 포함)
            ↓
주변 객체에서 반사
            ↓
수신 신호 분석 → 위치·속도·형상
```

## Ⅳ. 5G와 6G의 비교

- 핵심 요약 : 5G의 성능 축을 확장하면서 감지, AI 제어, 3차원 커버리지를 새 축으로 추가한 진화.

| 비교 항목 | 5G (IMT-2020) | 6G (IMT-2030) |
| --- | --- | --- |
| 최대 전송 속도 | 20Gbps 수준 (IMT-2020 요구값) | 5G 대비 대폭 향상 목표, 수치는 표준화 진행 중 |
| 무선 지연 | 사용자면 지연 1ms 요구 | 1ms 미만 수준의 저지연 목표 논의 |
| 최대 연결 밀도 | 10⁶ 기기/km² 요구 | 상향된 연결 밀도 목표 논의 |
| 커버리지 | 지상 중심 | 지상·공중·우주를 포함한 3차원 커버리지 |
| 네트워크 지능화 | AI 보조 활용, 사후 최적화 | AI-Native, 무선 제어 전 계층 학습 |
| 감지 기능 | 별도 레이더 또는 센서 의존 | 통신 신호 기반 감지 (ISAC) |

- 선택 기준 : 고정 광대역 서비스는 5G 확장으로, 감지와 자율 제어가 필요한 산업 환경은 6G 기능으로 나누어 도입.

## Ⅴ. 6G의 한계와 방안

- 핵심 요약 : 테라헤르츠 전파의 감쇠와 고주파 부품의 발열이 핵심 한계이며, 지능형 반사 표면과 고효율 소자로 극복.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 테라헤르츠 전파의 감쇠와 회절 한계 | 주파수 상승에 따른 대기 흡수 증가, 장애물 투과 불가로 도달 거리 짧아짐 | RIS를 다수 분산 배치, 고집적 빔포밍 안테나 적용, 중대역과의 반송파 집성 | 셀 반경, 음영 발생률 |
| 고주파 부품의 발열과 전력 소모 | 고속 변환기와 고주파 증폭기의 전력 소모 증가 → 기지국 운용비와 단말 배터리 부담 | 화합물 반도체(GaN, InP) 기반 고효율 RF(Radio Frequency) 소자, 광-무선 융합 전송 | 전력 효율, 발열 온도 |
| AI 제어의 설명가능성 부족 | 무선 제어 판단 근거가 불투명해 이상 동작 원인 추적 곤란 | 설명가능 AI(XAI, Explainable AI) 기법 적용, 이상 시 안전 모드로 복귀하는 구조 | 이상 동작 복구 시간 |

## Ⅵ. 6G에 대한 기술사적 제언

- 핵심 요약 : 주파수 확보, 인증 체계, 위성 연동 표준을 선제적으로 준비해 6G 기술 주도권을 확보하는 방향.

1. 주파수 전략 선점 : 세계전파통신회의(WRC, World Radiocommunication Conference)와 3GPP(3rd Generation Partnership Project) 표준화 회의에서 중대역과 서브 테라헤르츠 대역 확보를 국가 전략 과제로 추진할 필요가 있음.
2. AI 무선망 신뢰성 검증 : AI 제어 기능의 검증 절차와 인증 기준을 마련하여 상용망 투입 전에 안전성을 확인하는 체계를 갖출 필요가 있음.
3. 지상-비지상 연동 표준 선행 : 국내 저궤도 위성 사업과 지상 이동통신망의 연동 인터페이스를 미리 표준화하여 도서·해상·공중 통신 기반을 확보해야 함.

## Ⅶ. 결론

- 핵심 요약 : 6G는 통신에 감지와 AI 제어, 3차원 커버리지를 결합한 차세대 무선 인프라.
- 시사점 : 기술 자체보다 주파수, 검증, 표준의 준비 속도가 상용화 시점과 산업 경쟁력을 좌우함.
