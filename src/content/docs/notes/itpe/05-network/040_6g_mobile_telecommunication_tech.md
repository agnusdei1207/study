## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 차세대 이동통신 → IMT-2030(6G)

## 30초 인출

- 본질: **6G 이동통신 (IMT-2030)** 은 2030년 이후 이동통신의 이용 시나리오와 성능 목표를 정립하는 차세대 국제 표준화 대상
- 메커니즘: ITU의 공통 프레임워크·요구 조건 → 표준화 기구의 무선 인터페이스 제안·평가 → 장비·망의 구현과 검증
- 통찰: Sub-THz 초광대역 주파수와 지능형 재구성 표면(RIS)을 결합하여 초성능 전송을 달성하고 통신 전파 신호 자체로 실시간 3차원 공간을 고정밀 스캔하는 통신-센싱 융합(ISAC) 기술이 6G의 본질임.

<details>
<summary>핵심 용어</summary>

- **IMT-2030 (International Mobile Telecommunications-2030)** : ITU가 정한 차세대 이동통신 시스템의 국제 프레임워크 명칭.
- **ITU (International Telecommunication Union)** : 정보통신 분야 국제 표준·전파 조정을 담당하는 국제기구.
- **RIT (Radio Interface Technology)** : 이동통신 시스템의 무선 접속 기술 제안 단위.
- **ISAC (Integrated Sensing and Communication)** : 통신과 센싱 기능을 연계하는 이용 시나리오·기술 방향.
- **AIAC (Artificial Intelligence and Communication)** : 인공지능과 통신을 함께 고려하는 이용 시나리오.
- **HRLLC (Hyper Reliable and Low-Latency Communication)** : 높은 신뢰성과 낮은 지연이 요구되는 통신 시나리오.
- **NTN (Non-Terrestrial Network)** : 위성 등 비지상 노드를 포함하는 네트워크 구성.

</details>

## 2~4교시 25점 답안

## Ⅰ. 6G 이동통신 기술의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 100GHz~300GHz 대역의 서브 테라헤르츠(Sub-THz) 주파수와 메타표면, 딥러닝 신호처리를 융합하여 1Tbps 전송속도와 0.1ms 무선 지연을 실현하는 차세대 무선 통신 기술 체계 |
| 목적 | 초실감 3D 홀로그램, 디지털 트윈 기반 자율 도시 관제, 무선 기반 촉각 인터넷 및 통신망을 활용한 고해상도 환경 센싱 구현 |

## Ⅱ. 6G 이동통신 기술의 특징

| 특징 | 상세 내용 |
|---|---|
| Sub-THz 주파수 활용| 100GHz 이상의 극초고주파를 활용하여 수십 GHz 이상의 전례 없는 초광대역 전송 대역폭 확보 |
| 스마트 무선 환경(RIS)| 자연 법칙에 종속되던 전파 경로를 인공 메타물질 표면을 통해 반사·굴절 각도를 프로그래밍 제어 |
| 통신과 센싱의 결합 | 통신 프레임 신호의 반사파(Echo)를 분석하여 카메라/라이다 없이도 고정밀 객체 위치·형상 탐지 |
| 극초다중 안테나(E-MIMO)| 수천 개의 초소형 안테나 소자를 집적하여 초정밀 지향성 연필 빔(Pencil Beam) 형성 |

## Ⅲ. 6G 이동통신 기술의 체계·프로세스

**6G 핵심 무선 기술 아키텍처 및 ISAC 동작 메커니즘**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 6G 무선 핵심 기술 체계 ]                      │
│                                                                        │
│   [ 6G 기지국 (gNodeB) ] ── (Sub-THz 초광대역 빔포밍)                  │
│          │                                                             │
│          ├──── 직접 통신파 전송 ────────────────────────► [ 6G 단말 ]  │
│          │                                                             │
│          ├──── 장애물 음영 지역 반사파 전송 ──┐                         │
│          │                                    │                        │
│          │                                    ▼                        │
│          │                           [ RIS (지능형 재구성 표면) ]      │
│          │                           - 메타물질 위상 편이              │
│          │                           - 음영지역으로 빔 우회 반사       │
│          │                                    │                        │
│          │                                    ▼                        │
│          │                           [ 음영지대 자율차량 ]             │
│          │                                                             │
│          ▼ (반사파 에코 수신 및 레이더 신호처리)                       │
│   [ ISAC 센싱 엔진 ] ──► 전방 낙하물, 보행자 형상, 도로 침수 실시간 매핑│
└────────────────────────────────────────────────────────────────────────┘
```

| 핵심 기술 | 동작 원리 | 핵심 해결 과제 |
|---|---|---|
| **Sub-THz 무선 전송** | 100~300GHz 대역에서 고차 변조 및 수십 GHz 대역폭 활용 | 대기 가스 흡수 감쇠 및 전력증폭기(PA) 출력 한계 극복 |
| **RIS (재구성 표면)** | 수천 개의 수동형 메타원자(Meta-atom) 위상을 제어하여 전파 반사 | 고속 채널 추정 및 초저전력 위상 제어 회로 설계 |
| **ISAC (센싱 융합)** | 통신 송수신 신호를 동시 활용하여 타깃 거리/속도/각도 추정 | 통신 처리율과 센싱 해상도 간의 자원 최적 분배 |
| **Extreme MIMO** | 수천 개 안테나 어레이를 패키징하여 3차원 공간 다중화 | 안테나 상호 간섭 제거 및 초고속 디지털 빔 연산 |

## Ⅳ. 6G 이동통신 기술의 종류·비교

| 비교 항목 | 5G 밀리미터파 (28GHz) | 6G 서브 테라헤르츠 (Sub-THz) |
|---|---|---|
| **주파수 범위** | 24 GHz ~ 29.5 GHz | **100 GHz ~ 300 GHz** |
| **가용 대역폭** | 최대 400 MHz ~ 800 MHz | **수 GHz ~ 수십 GHz (수십 배 확장)** |
| **최대 전송 속도** | 약 4 Gbps | **최대 1 Tbps (테라비트급)** |
| **전파 도달 거리** | 약 100m ~ 300m | **수십 미터 (LOS 한정)** |
| **안테나 소자 크기**| 수 밀리미터(mm) | **수백 마이크로미터(μm, 온칩 집적)** |
| **음영 극복 방안** | 빔포밍 및 중계기 증설 | **RIS (지능형 표면) 필수 구축** |

## Ⅴ. 6G 이동통신 기술의 한계와 방안

| 한계 | 방안 |
|---|---|
| Sub-THz 대역의 심각한 경로 손실 및 비가시선(NLOS) 환경에서 인체·유리창 차폐 시 신호 즉시 두절 | 건물 외벽 및 실내 벽면에 메타물질 기반 무전원/초저전력 RIS 패널을 대규모 배치하여 가상 가시선(Virtual LOS) 확보 |
| 통신 데이터 전송과 고정밀 레이더 센싱 신호 동시 송출 시 상호 간섭으로 인한 센싱 허위 경보 및 통신 BER 급증 | 상호 간섭이 직교하는 이중 기능 파형(Dual-Function Radar-Communication, DFRC) 및 시간·주파수 자원 분할 최적화 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
6G 시범 인프라 구축 시, Sub-THz 대역을 매크로 광역망에 무리하게 적용하지 않고 데이터센터 내 랙 간 무선 광대역 연결(Wireless Interconnect) 및 옥외 고정형 무선 백홀(FWA)에 우선 한정 적용하고, 도심 모빌리티 통신은 7~15GHz 대역(FR3)을 주력으로 활용.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ RIS (Reconfigurable Intelligent Surface) 빔 제어 메커니즘 ]         │
│                                                                        │
│   입사파 (Incident Wave) : 각도 θ_i ──► [ RIS 메타표면 컨트롤러 ]       │
│                                                   │                    │
│   - 수천 개의 메타원자(Varactor Diode) 바이어스 전압 미세 조정         │
│   - 표면 공간 위상 분포(Phase Gradient) Φ(x,y) 형성                    │
│                                                   │                    │
│   스넬의 반사 법칙을 깨뜨리고 원하는 각도 θ_r로 ──► 반사파 (Reflected) │
│   (기존 벽면 흡수/무작위 산란을 극복하고 단말 방향으로 빔 에너지 집중) │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 메타표면 기술 | 능동/수동 구분 | 전력 소모 | 주요 역할 |
|---|---|---|---|
| **수동형 RIS (Passive)** | 수동 위상 천이기 기반 | 거의 없음 (수 mW) | 전파 굴절 및 반사 각도 변경 |
| **능동형 RIS (Active)** | 초소형 증폭기(PA) 내장 | 중간 수준 | 약한 반사 신호의 능동 증폭 |
| **STAR-RIS** | 동시 투과 및 반사 (Simultaneous) | 낮음 | 벽면 투과 실내 전파 + 외벽 반사 동시 지원 |
