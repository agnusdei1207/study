## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 핵심 개념 → AI Native Network

## 30초 인출

- 본질: 외부 플랫폼에서 AI를 얹어 모니터링하던 사후 부가형 방식의 느린 제어 루프와 인터페이스 단편화
- 메커니즘: 물리 계층 신호처리부터 코어망 라우팅까지 모든 계층을 딥러닝 기반 폐루프(Closed-loop) 추론 모듈로 직접 설계

## 핵심 용어

- AI-Native Air Interface: Shannon의 분리 정리(소스 코딩과 채널 코딩의 분리)를 넘어 송신기와 수신기를 하나의 심층 신경망(오토인코더)으로 구성해 무선 채널에 최적화된 변복조를 직접 학습하는 무선 인터페이스
- 시맨틱 통신(Semantic Communication): 모든 비트를 정확히 복원하는 대신, 메시지의 "의미와 목적"을 AI가 추출하여 핵심 의미 정보만 압축 전송하는 차세대 통신 패러다임
- ZSM(Zero-touch network and Service Management): ETSI가 정의한 개념으로 사람의 개입 없이 AI가 네트워크 분석·판단·실행을 100% 자율 수행하는 운영 프레임워크

## 1교시 10점 답안

### 정의·목적

- 정의: AI Native Network은/는 물리 계층 신호처리부터 코어망 라우팅까지 모든 계층을 딥러닝 기반 폐루프(Closed-loop) 추론 모듈로 직접 설계 방식이다.
- 목적: 자율 운영(Zero-touch)과 극한의 자원 효율 달성에 기여한다.

### 핵심 구조와 작동

```text
[ AI-Native Network 폐루프(Closed-Loop) 아키텍처 ]

  +-----------------------------------------------------------------+
  |           [ 서비스 및 비즈니스 의도 (Intent) 계층 ]              |
  +-----------------------------------------------------------------+
                                  |
                                  v
  +-----------------------------------------------------------------+
  |  [ 인공지능 오케스트레이션 평면 (AI Orchestration Plane) ]       |
  |  - 글로벌 모델 학습, 연합학습 집계, 네트워크 디지털 트윈 시뮬레이션 |
  +-----------------------------------------------------------------+
            ^                                       |
  (데이터)  | 실시간 텔레메트리                      | (제어) 최적 파라미터 정책
            |                                       v
  +---------+---------------------------------------+---------------+
  | [ 네트워크 기능 계층 (통신 프로토콜 스택) ]                      |
  |  - 코어망: NWDAF 기반 실시간 혼잡/트래픽 예측                     |
  |  - 무선망: O-RAN Near-RT RIC xApp/rApp 기반 실시간 빔/자원 제어  |
  |  - 물리 계층: Deep Autoencoder 기반 송수신 엔드-투-엔드 신경망 변복조|
  +-----------------------------------------------------------------+
```

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
[ AI-Native Network 폐루프(Closed-Loop) 아키텍처 ]

  +-----------------------------------------------------------------+
  |           [ 서비스 및 비즈니스 의도 (Intent) 계층 ]              |
  +-----------------------------------------------------------------+

  +-----------------------------------------------------------------+

  +-----------------------------------------------------------------+
            ^                                       |
  (데이터)  | 실시간 텔레메트리                      | (제어) 최적 파라미터 정책
            |                                       v
  +---------+---------------------------------------+---------------+

  |  - 물리 계층: Deep Autoencoder 기반 송수신 엔드-투-엔드 신경망 변복조|
  +-----------------------------------------------------------------+
```

### Ⅱ. 핵심 특성

- 기존 통신망(5G)은 인간 엔지니어가 수학적 채널 모델과 규칙(IF-THEN)을 만들고 AI는 외부 분석기(NWDAF)에 머물렀으나, 6G AI-Native는 통신 프로토콜 자체가 신경망 가중치(Weight)로 정의됨
- "시맨틱 통신"을 통해 텍스트나 비디오를 전송할 때 불필요한 배경 비트를 90% 이상 걷어내고 의미론적 토큰만 전달함으로써 초광대역 한계를 돌파
- 완전 자율 폐루프 제어가 상용화되려면 AI가 내린 판단(특정 기지국 출력 축소 등)의 이유를 검증할 수 있는 설명 가능 인공지능(XAI)과 샌드박스 안전장치 필수

### Ⅲ. 관련 개념과 구분

- AI-Infused Network vs AI-Native Network: AI-Infused는 기존 레거시 프로토콜 위에 AI 모니터링 도구를 외장형으로 덧붙임 / AI-Native는 통신 계층 알고리즘과 인터페이스 자체가 AI 학습 모델을 기반으로 설계됨

### Ⅳ. 적용 문제와 대응

- 적용 상황: 전국 기지국 AI 자율 빔포밍 가동 중 특정 구역 통신 블랙아웃 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| AI 모델 추론 오류로 인한 자원 할당 실패 | 학습 데이터 분포 밖(OOD, Out-Of-Distribution)의 이상 기상/트래픽 유입 | Rule-based 안전 가드레일(Safe Fallback) 및 XAI 모니터링 | 이상 징후 감지 즉시 표준 확정적 알고리즘으로 안전 롤백 |
| 전 기지국 모델 재학습 시 백홀 트래픽 포화 | 수 테라바이트의 원시 무선 신호 데이터를 중앙 클라우드로 전송 | 연합학습(Federated Learning) 및 지능형 엣지 모델 압축 | 파라미터 델타값만 전송하여 백홀 대역폭 95% 절감 |

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 적용 환경에서 발생하는 핵심 제약 | 기존 대책을 적용하고 핵심 운영 지표를 확인해 개선한다. |
