## 연관 키워드

- 거리벡터 라우팅, 벨만-포드(Bellman-Ford), 동적 라우팅, 분산 계산
- 수렴(Convergence), 무한 계수(Count-to-Infinity)
- 수평 분할, 독성 역전, 링크상태 라우팅, 경로벡터

## Ⅰ. 거리벡터 라우팅의 개요

- 핵심 요약 : 이웃 간 거리 정보 교환만으로 최단 경로를 분산 계산하는 동적 라우팅의 기본 알고리즘.
- 개념 : 각 라우터가 목적지별 최소 비용 추정치 목록인 거리 벡터를 인접 라우터와 주기적으로 교환해 경로를 계산하는 방식(**거리벡터 라우팅** (Distance Vector Routing)).
- 배경 및 필요성 : 전체 토폴로지를 아는 중앙 노드 없이, 이웃 간 최소 정보 교환만으로 각 노드가 자율적으로 경로를 세워야 하는 환경이 존재.
- 주요 목적 : 낮은 연산·기억 자원으로 경로의 자동 학습과 토폴로지 변화의 반영.

## Ⅱ. 거리벡터 라우팅의 특징 및 장점

- 핵심 요약 : 이웃 요약 정보에 대한 단순 계산과 분산 비동기 갱신이 저부하 운영을 가능하게 하는 구조.

1. 벨만-포드 계산 : **벨만-포드 알고리즘** (Bellman-Ford)의 점화식 `D_x(y) = min_v { c(x,v) + D_v(y) }`를 목적지마다 적용 → 덧셈과 비교만으로 경로 산출이 가능한 저부하 효과.
2. 분산 비동기 동작 : 동기화 약속 없이 각 노드가 자기 계산 결과를 이웃에만 통지 → 중앙 제어 불필요와 통신 부담의 국소화 효과.
3. 소문 기반 학습 : 이웃이 알려준 요약 정보를 신뢰해 경로를 세우는 **소문에 의한 라우팅** (Routing by Rumor) 구조 → 기억 자원 절약과 정보 오염 전파 위험의 공존.

## Ⅲ. 거리벡터 라우팅의 구조 (흐름)

- 핵심 요약 : 거리 벡터 수신 → 재계산 → 재통지의 반복으로 수렴이 진행되고, 낡은 정보의 순환 시 무한 계수가 발생하는 흐름.

```text
[ 거리 벡터 갱신 절차 ]

이웃으로부터 거리 벡터 수신
        ↓
이웃까지 링크 비용을
각 항목에 가산
        ↓
기존 추정치와 비교 후
최소값 채택
        ↓
변경분을 이웃에 재통지
```

```text
[ 링크 단절 시 무한 계수 ]

A–Y 구간 단절 감지
        ↓
A : Y 도달 불가 판정
        ↓
B가 "A 경유 Y 도달" 광고 재수신
   (낡은 정보의 순환)
        ↓
비용이 상한에 닿을 때까지 증가
```

- 계산의 기억 단위 : 목적지, 최소 비용, 다음 홉(Next Hop)의 세 필드로 이루어진 거리 벡터 테이블.
- 두 번째 도식의 순환 구조가 **무한 계수** (Count-to-Infinity)이며, 수렴(Convergence) 지연의 대표 원인.

## Ⅳ. 거리벡터 라우팅과 링크상태 라우팅의 비교

- 핵심 요약 : 거리벡터는 이웃 요약 정보의 가벼움, 링크상태는 전체 토폴로지 기반의 빠른 수렴과 루프 배제라는 상반 강점.

- **링크상태 라우팅** (Link State Routing) : 각 노드가 전체 토폴로지를 공유·저장하고 자체적으로 최단 경로를 일괄 계산하는 대비 방식.

| 비교 축 | 거리벡터 | 링크상태 |
| --- | --- | --- |
| 보유 정보 | 이웃이 통지한 거리 요약 | 전체 토폴로지 데이터베이스 |
| 계산 방식 | 벨만-포드 점화식 반복 | 다익스트라(Dijkstra) 일괄 계산 |
| 수렴 속도 | 느림 (나쁜 소문의 지연 전파) | 빠름 (변화 즉시 재계산) |
| 루프 성향 | 과도 상태에서 루프 가능 | 계산 결과상 루프 배제 |
| 자원 요구 | 낮음 | 높음 (토폴로지 저장·연산) |
| 적합 범위 | 소규모·변화 적은 말단망 | 대규모·변화 잦은 내부망 |

- 선택 기준 : 규모와 변화 빈도가 기준 — 말단 소규모 구간은 거리벡터, 내부 코어는 링크상태, 도메인 간은 경유 AS(Autonomous System) 목록을 기록하는 경로벡터 방식이 적합.

## Ⅴ. 거리벡터 라우팅의 한계와 방안

- 핵심 요약 : 무한 계수와 느린 수렴, 단순 메트릭을 광고 통제 기법과 지표 개선으로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 무한 계수 | 낡은 경로 정보의 순환 참조 → 비용 상승과 긴 루프 지속 | **수평 분할** (Split Horizon, 배운 방향으로 재광고 금지), **독성 역전** (Poison Reverse, 배운 경로를 도달 불가로 광고) | 수렴 완료 시간 |
| 느린 수렴 | 단절 감지가 주기 광고에 의존 → 복구까지의 지연 | 즉시 갱신(Triggered Update), 홀드다운(Holddown) 병용 | 경로 복구 지연 시간 |
| 메트릭 단순성 | 거리 지표가 대역폭·지연을 반영하지 않음 → 비효율 경로 선택 | 링크 비용 기반 지표 도입 또는 상위 방식 전환 | 경로의 실제 처리량 |

## Ⅵ. 거리벡터 라우팅에 대한 기술사적 제언

- 핵심 요약 : 적용 범위의 원칙화, 광고 신뢰성 확보, 중앙 집중 구조로의 점진 전환을 조직 차원에서 준비하는 방향.

1. 망 설계 조직은 프로토콜 선정 기준(말단 소규모는 거리벡터, 내부 코어는 링크상태, 도메인 간은 경로벡터)을 문서화해 혼용 경계를 관리.
2. 보안 운영 조직은 라우팅 광고 인증과 인접 관계 필터링으로 위조 경로 주입을 차단하는 체계를 구축.
3. 대규모 운영 조직은 SDN(Software-Defined Networking) 컨트롤러 기반 전역 경로 관리로의 전환을 단계 검토.

## Ⅶ. 결론

- 핵심 요약 : 거리벡터 라우팅은 이웃 정보만으로 경로를 세우는 경량 분산 알고리즘.
- 수렴 지연과 루프 가능성이라는 이론적 한계를 제어하는 기법들이 동적 라우팅 발전의 토대가 된 점이 함의.
