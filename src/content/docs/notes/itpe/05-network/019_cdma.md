## 답안 골격
```text
[CDMA] ◀━━ 머리: Ⅶ 내 의견 (폐루프 전력제어 원리와 현대 다중접속(NOMA)으로의 진화 이해)
 ┃
 ┣━ Ⅰ 개요 ───── 주파수·시간 분할의 용량 한계 → 동일 주파수·동일 시간에 직교 코드로 다중 접속
 ┣━ Ⅱ 특징 ───── 직접 확산(DSSS), 직교 코드(Walsh), 주파수 재사용 계수 1, 소프트 핸드오버
 ┣━ Ⅲ 구조 ───── 송신측(데이터 × 직교 부호 = 확산 신호) + 무선 채널 + 수신측(신호 × 동일 부호 = 역확산)
 ┣━ Ⅳ 흐름 ───── ① 사용자 데이터 생성 → ② 칩(Chip) 시퀀스 곱연산 확산 → ③ 전송 → ④ 상관기(Correlator) 역확산
 ┣━ Ⅴ 비교 ───── FDMA vs TDMA vs CDMA (주파수 분할 vs 시간 분할 vs 직교 코드 분할)
 ┗━ Ⅵ 실무 ───── 원근 문제(Near-Far Problem) / 기지국 용량의 소프트 한계 / 레이크(RAKE) 수신기
```
- 필수 키워드: 대역확산(DSSS) · 직교 부호(Walsh Code) · PN 시퀀스 · 원근 문제 · 전력 제어 · 소프트 핸드오버
- 배점 전략: 10점 = Ⅰ → Ⅲ 대역확산 및 역확산 수식/도식 → Ⅴ FDMA/TDMA/CDMA 비교표 / 25점 = Ⅰ~Ⅶ, 140회 3교시 4번 기출(나. CDMA)에 맞춰 원근 문제 극복 메커니즘 상세
- 기출: 140회 3교시 4번 `다음 무선 통신 프로토콜을 설명하시오. 가. CSMA/CA 나. CDMA 다. TDMA` → Ⅰ~Ⅵ

## 한 줄 본질
- 주파수를 쪼개거나(FDMA) 시간을 쪼개는(TDMA) 방식의 경직된 채널 용량 한계 → 모든 사용자가 동일한 주파수와 시간을 공유하되 서로 직교하는 고유 부호(Code)를 곱해 넓은 대역으로 확산 전송한 뒤 수신측에서 동일 부호로 역확산 복원 → 주파수 재사용률 극대화와 도청 방지 / 가까운 단말의 강한 신호가 먼 단말의 신호를 덮는 원근 문제 발생

## 핵심 그림
```text
[ CDMA 대역 확산 및 역확산 원리 ]

송신측:
사용자 데이터 (+1, -1) ---+
                         | (곱셈 연산)
직교 왈시 코드 (4칩) -----+===> 확산 신호 (넓은 대역폭, 노이즈처럼 보임)
(+1, -1, +1, -1)                     |
                                    v (공중 무선 채널: 타 사용자 신호와 합성)
                                    |
수신측:                             v
합성 수신 신호 -----------+
                         | (상관기: 동일 왈시 코드 곱셈 및 적분)
동일 왈시 코드 -----------+===> 원래 사용자 데이터 (+1, -1) 완벽 복원!
                                (타 사용자 신호는 직교성으로 인해 0으로 상쇄)
```

## 핵심 용어
- 직교 부호(Orthogonal Code / Walsh Code): 두 코드 벡터의 내적(Inner Product) 결과가 정확히 0이 되는 수학적 부호. 상호 간섭 없이 독립 채널을 생성
- 칩 레이트(Chip Rate): 정보 비트 하나를 여러 개의 조각(Chip)으로 쪼개는 속도. 칩 속도가 빠를수록 주파수 확산 대역폭이 넓어짐
- 원근 문제(Near-Far Problem): 기지국에 가까이 있는 단말의 송신 신호가 기지국 안테나에 너무 강하게 도달하여, 멀리 있는 단말의 약한 신호를 완전히 묻어버리는 간섭 현상

## 핵심 통찰
- CDMA의 용량은 주파수 슬롯 수로 딱딱 끊어지는 "하드 리미트(Hard Limit)"가 아니라, 사용자 수가 늘어날수록 통화 품질이 서서히 저하되는 "소프트 리미트(Soft Limit)" 특성을 가짐
- 모든 기지국이 동일한 주파수를 사용하므로(주파수 재사용 계수 = 1), 기지국 경계를 넘을 때 연결을 끊고 새로 맺는 하드 핸드오버 대신 두 기지국 신호를 동시에 수신하는 "소프트 핸드오버(Make-Before-Break)"가 가능
- 원근 문제를 해결하지 못하면 CDMA는 동작 불가능 → 기지국이 초당 수천 번(1,500회) 단말의 출력을 1dB 단위로 미세 조절하는 "초고속 폐루프 전력 제어"가 CDMA 기술의 핵심 심장

## 이웃 토픽과 구분
- TDMA vs CDMA: TDMA는 동일 주파수를 시간 슬롯(Time Slot)으로 나누어 사용 / CDMA는 동일 주파수와 동일 시간을 공유하면서 고유 코드로 분리

## 문제·원인·대책
- 적용 상황: 도심 음영지역에서 멀리 떨어진 단말의 통화 끊김
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 원근 문제로 인한 원거리 단말 신호 유실 | 기지국 근처 단말의 과도한 송신 출력으로 배경 잡음 레벨 상승 | 800Hz~1.5kHz 초고속 폐루프 전력 제어(Closed-loop PC) | 기지국 수신 안테나에 모든 단말 신호가 동일한 세기로 도달 |
| 다중 경로 반사파로 인한 신호 왜곡 | 건물 반사로 시간차가 나는 에코 신호 발생 | 레이크 수신기(RAKE Receiver) 다중 핑거 합성 | 다중 경로 신호를 버리지 않고 합성하여 다이버시티 이득 확보 |

## 이렇게 출제된다

## 내 의견
- [4G/5G OFDM 시대로의 전환과 CDMA의 유산] 고속 데이터 전송 시 칩 레이트 증가로 인한 광대역화 한계로 4G LTE부터는 직교 주파수 분할(OFDMA)로 패러다임이 전환됨 → 나라면: 기술사 답안에서 과거 2G/3G의 역사적 유물로만 보지 않고, 비직교 다중 접속(NOMA) 및 스프레드 스펙트럼 기반 군용 통신 보안 기술의 기반 이론으로서 CDMA의 코드 직교성과 전력 제어 원리를 최신 기술과 연결해 제시
