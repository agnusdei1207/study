## 연관 키워드

- CDMA(Code Division Multiple Access), 코드 분할 다중 접속, 대역 확산(Spread Spectrum), 직접 확산(DSSS, Direct Sequence Spread Spectrum)
- PN 코드(Pseudo-Noise Code), 왈시 코드(Walsh Code), 레이크 수신기(Rake Receiver)
- 원근 문제(Near-Far Problem), 전력 제어(Power Control), 소프트 핸드오버(Soft Handover), 셀 브리딩(Cell Breathing)

## Ⅰ. CDMA의 개요

- 핵심 요약 : 모든 사용자가 같은 주파수·시간을 공유하고 고유 확산 코드로 신호를 구분하는 다중 접속 방식.
- 개념 : 가입자별로 서로 간섭이 없는 고유 코드를 배정하고, 데이터를 넓은 주파수 대역으로 펼쳐 동시 전송하는 **코드 분할 다중 접속** (CDMA, Code Division Multiple Access) 방식.
- 배경 및 필요성 : 주파수 분할 다중 접속(FDMA, Frequency Division Multiple Access)에 기반한 1세대 아날로그 이동통신은 채널 수 한계와 도청 취약성을 안고 있었음.
- 주요 목적 : 주파수 재사용 효율의 극대화, 간섭·도청에 대한 내성 확보, 셀 경계 통화 품질 보장.

## Ⅱ. CDMA의 특징 및 장점

- 핵심 요약 : 코드 구분 구조가 주파수 효율·보안성·핸드오버 품질로 이어지는 방식.

1. 신호 분산 : 데이터를 **대역 확산** (Spread Spectrum, 확산 코드로 신호를 광대역에 흩어 전송하는 기법) 처리 → 좁은 대역 간섭과 의도 전파 방해에 대한 내성 확보.
2. 코드 구분 : 상호 상관도가 낮은 코드를 가입자별 배정 → 같은 주파수·시간을 전 셀에서 공유하는 주파수 재사용 실현.
3. 다중 경로 활용 : **레이크 수신기** (Rake Receiver, 다중 경로 신호를 따로 수신해 합성하는 장치)로 반사 신호를 이득으로 전환 → 페이딩 영향 완화.
4. 연결 전환 : **소프트 핸드오버** (Soft Handover, 새 기지국 연결 수립 후 기존 연결 해제) 방식 → 셀 경계에서의 통화 단절 감소.

## Ⅲ. CDMA의 구조 (흐름)

- 핵심 요약 : 확산 코드 곱셈으로 보내고 같은 코드 곱셈으로 골라 내는 확산·역확산의 짝 구조.
- **직접 확산** (DSSS, Direct Sequence Spread Spectrum) : 데이터 비트열을 코드 비트열과 곱해 대역폭을 넓히는 확산 방식.
- **PN 코드** (Pseudo-Noise Code) : 잡음처럼 보이는 패턴의 코드로, 역방향 링크의 가입자 구분과 기지국 식별에 활용.
- **왈시 코드** (Walsh Code) : 서로 직교하는 코드로, 순방향 링크에서 채널 간 간섭을 제거.

```text
[ 송신 측 확산 과정 ]

원시 데이터 (협대역)
   ↓ 확산 코드 곱셈
광대역 확산 신호
   ↓
동일 주파수로 다중 가입자 전송
```

```text
[ 수신 측 역확산 과정 ]

다중 가입자 신호가 중첩된 수신 신호
   ↓ 목표 가입자의 동일 코드 곱셈
목표 신호만 역확산·집중
   ↓
타 가입자 신호는 잡음화 → 데이터 복원
```

## Ⅳ. CDMA와 타 다중 접속 방식의 비교

- 핵심 요약 : 채널 구분 축이 주파수·시간·코드 중 무엇이냐에 따라 용량 구조와 간섭 관리 방식이 달라짐.

| 비교 축 | FDMA | TDMA(Time Division Multiple Access) | CDMA |
| --- | --- | --- | --- |
| 채널 구분 기준 | 주파수 대역 | 시간 슬롯 | 확산 코드 |
| 주파수 재사용 | 셀마다 다른 주파수 | 인접 셀 주파수 계획 | 전 셀 동일 주파수 |
| 간섭 관리 | 보호 대역 | 동기화·가드 타임 | 전력 제어 |
| 핸드오버 | 하드 핸드오버 | 하드 핸드오버 | 소프트 핸드오버 |
| 주요 제약 | 채널 수 한계 | 슬롯 동기 부담 | 원근 문제 |

- 선택 기준 : 주파수 자원이 귀하고 통화 보안이 중요한 환경에서는 코드 분할이 유리하고, 슬롯 단위의 명확한 자원 배분이 필요하면 시분할이 적합.

## Ⅴ. CDMA의 한계와 방안

- 핵심 요약 : 원근 문제·셀 브리딩·자체 간섭 누적을 전력 제어·부하 관리로 통제하는 운영 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **원근 문제** (Near-Far Problem, 근거리 단말 신호가 원거리 신호를 덮는 현상) | 가까운 단말의 강한 신호가 먼 단말의 약한 신호 수신 판정을 방해 | **전력 제어** (Power Control, 단말 송신 전력의 실시간 조정)로 수신 전력 수준 균일화 | 전력 제어 정확도 |
| **셀 브리딩** (Cell Breathing, 부하에 따른 커버리지 수축 현상) | 접속 부하 증가로 간섭이 커지면서 유효 서비스 반경이 줄어듦 | 접속 허용 제한과 인접 셀 간 부하 분산 | 셀당 동시 접속 수 |
| 자체 간섭 누적 | 가입자 수 증가가 수신 잡음 바닥을 높여 용량이 서서히 저하 | 섹터 분할과 용량 기반 셀 설계 | 호 차단율 |

## Ⅵ. CDMA에 대한 기술사적 제언

- 핵심 요약 : 대역 확산 원리의 계승과 무선 자원 관리 역량의 이전을 중심으로 한 세대 교체 대응.
- 이동통신 사업자 : 2·3세대 서비스 종료 시 확산 코드 기반 원리가 계승되는 측위·국방·사물인터넷 분야와의 연계 로드맵 수립.
- 국방·항법 조직 : 의도 전파 방해 내성이 필요한 통신·측위 체계에 대역 확산 설계를 표준으로 유지.
- 무선표준 설계 조직 : 다중 접속 방식 선정 시 용량·커버리지·단말 복잡도의 균형을 평가하는 기준 마련.

## Ⅶ. 결론

- 핵심 요약 : CDMA는 코드로 사용자를 구분해 주파수를 전 셀에서 재사용하는 대역 확산형 다중 접속 기술.
- 용량과 보안을 얻는 대신 정밀 전력 제어라는 운영 조건을 요구하는 방식.
