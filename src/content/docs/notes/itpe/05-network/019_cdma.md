- 메커니즘: 송신 데이터에 코드를 곱해 확산하고, 수신기가 같은 코드와 상관 연산으로 원하는 신호를 복원
- 통찰: 모든 사용자가 동일한 시간과 주파수 대역을 공유하되 상호 직교하는 고유 확산 부호(Walsh/PN)를 부여하여 다원 접속을 구현하며 원근 효과 극복을 위한 고속 전력 제어가 시스템 용량을 결정하는 핵심 기술임.

## 2~4교시 25점 답안

## Ⅰ. CDMA(Code Division Multiple Access)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 모든 사용자가 동일한 주파수 대역과 동일한 시간 슬롯을 공유하면서 상호 직교성(Orthogonality)을 갖는 고유 확산 코드를 부여하여 신호를 다중화하는 다중 접속 기술 |
| 목적 | 한정된 주파수 자원의 공간 재사용률 극대화, 도청 및 도청 방지(대역확산 보안성) 및 페이딩 채널 환경에서의 통화 품질 확보 |

## Ⅱ. CDMA(Code Division Multiple Access)의 특징

| 특징 | 상세 내용 |
|---|---|
| 직접 시퀀스 확산(DSSS)| 협대역 데이터 신호에 고속의 칩 레이트(Chip Rate)를 갖는 확산 부호를 곱하여 광대역으로 변환 |
| 부호 분할 다원 접속 | 수신측에서 송신 시 사용된 동일 부호의 상관(Correlation) 연산만 통과시키고 타 부호는 잡음으로 처리 |
| 소프트 핸드오버 | 주파수가 동일하므로 통화 단절 없이 구 기지국과 신 기지국의 신호를 동시 수신 후 합성(Make-Before-Break) |
| 레이크 수신기(Rake) | 다중 경로(Multipath)로 지연 도달한 반사파 신호들을 시간축에서 분리한 후 결합(Maximal Ratio Combining) |

## Ⅲ. CDMA(Code Division Multiple Access)의 체계·프로세스

**CDMA 대역 확산(DSSS) 및 직교 부호 역확산 원리**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ CDMA 대역 확산 및 복원 흐름 ]                 │
│                                                                        │
│   [ 송신단 ]                                                           │
│     데이터 비트 d(t) [ +1, -1 ]                                        │
│          │                                                             │
│          ▼ (배타적 논리합 / 곱셈 연산)                                │
│     직교 확산 부호 c(t) [ +1, -1, +1, +1, -1, ... ] (고속 칩 레이트)     │
│          │                                                             │
│          ▼                                                             │
│     광대역 확산 신호 s(t) ──► 무선 채널 (다수 사용자 신호 중첩)        │
│                                      │                                 │
│   [ 수신단 ]                         ▼                                 │
│     수신 합성 신호 r(t) = s1(t) + s2(t) + Noise                        │
│          │                                                             │
│          ▼ (동일 확산 부호 c1(t) 곱셈 연산: 역확산 Despreading)        │
│     상관기(Correlator) 적분 연산 ──► 데이터 d1(t) 완벽 복원           │
│     (직교 부호 특성: c1(t)*c2(t)의 적분값 = 0, 타 사용자 간섭 제거)    │
└────────────────────────────────────────────────────────────────────────┘
```

| 구성 요소 | 주요 역할 | 특성 및 수학적 원리 |
|---|---|---|
| **Walsh Code (직교 부호)** | 순방향(다운링크) 사용자 채널 구분 | Hadamard 행렬 기반 완전 직교성 만족 (상호 상관 = 0) |
| **PN Code (의사 잡음 부호)**| 기지국 식별 및 역방향 사용자 다원 접속| 자기 상관(Auto-correlation) 피크 특성, 백색 잡음 유사성 |
| **칩 레이트 (Chip Rate)** | 부호 전송 속도 (1.2288 Mcps) | 데이터 비트 속도(9.6 kbps)보다 훨씬 높아 프로세싱 이득(PG) 제공 |
| **프로세싱 이득 (PG)** | `PG = W / R = B_ss / B_info` | 대역 확산에 따른 간섭 억제 능력 (IS-95 기준 약 21dB 이득) |

## Ⅳ. CDMA(Code Division Multiple Access)의 종류·비교

| 비교 항목 | FDMA (주파수 분할) | TDMA (시분할) | CDMA (부호 분할) |
|---|---|---|---|
| **신호 분할 기준** | 주파수 대역 분할 | 시간 슬롯 분할 | 고유 확산 부호 분할 |
| **주파수 재사용 계수**| 1/7 또는 1/4 (인접 셀 간섭) | 1/7 또는 1/3 | **1 (모든 셀이 동일 주파수 사용)** |
| **동기화 요구 수준** | 낮음 | 매우 높음 (가드 타임 필수) | 기지국 간 정밀 동기(GPS) 요구 |
| **채널 용량 한계** | 경성 용량(Hard Capacity)| 경성 용량 (타임 슬롯 수 제한)| **연성 용량(Soft Capacity, 간섭 의존)**|
| **핸드오버 방식** | 하드 핸드오버 | 하드 핸드오버 | 소프트 핸드오버 지원 |

## Ⅴ. CDMA(Code Division Multiple Access)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 기지국 근처의 강한 단말 신호가 원거리 단말의 미약한 신호를 덮어버리는 원근 효과(Near-Far Problem) | 초당 800회 이상의 고속 폐루프 전력 제어(Fast Closed-loop Power Control)를 적용하여 수신 전력 균일화 |
| 동시 통화 가입자 수 증가 시 간섭량 누적으로 인한 통화 품질 저하 및 셀 반경 축소(Cell Breathing) | 간섭 제거 기술(Multi-User Detection) 적용 및 기지국 호 수락 제어(CAC) 기반 엄격한 접속 통제 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
CDMA 기반 전력 제어 설계 시, 개루프(Open-loop) 제어로 기지국 신호 세기를 기반으로 초기 송신 전력을 산출하고, 1.25ms 주기(초당 800회)의 폐루프(Closed-loop) 전력 제어를 통해 기지국이 1dB 단위의 Up/Down 비트를 송출하여 모든 단말의 기지국 도달 전력을 완벽히 일치화.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ CDMA 고속 폐루프 전력 제어 (Closed-loop Power Control) 메커니즘 ]   │
│                                                                        │
│   [ 단말 (UE) ]                                   [ 기지국 (BTS) ]     │
│       │                                                  │             │
│       ├─── 역방향 프레임 송신 (Eb/No 측정용 신호) ──────►│             │
│       │                                                  ├─► 수신 Eb/No│
│       │                                                  │   실측 측정 │
│       │                                                  │      │      │
│       │                                                  ▼      ▼      │
│       │                                            [ 임계치 비교 ]     │
│       │                                            - 실측 < 목표: Up   │
│       │                                            - 실측 > 목표: Down │
│       │                                                  │             │
│       │◄─── 전력 제어 비트 (1.25ms마다 1dB 조정 지시) ───┤             │
│       │                                                                │
│   (송신 출력 1dB 즉각 가감 -> 모든 단말의 기지국 수신 전력 평준화 성공) │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 전력 제어 방식 | 제어 주기 | 제어 방향 | 주요 보정 대상 |
|---|---|---|---|
| **개루프 전력 제어** | 호 설정 초기 1회 | 단말 자체 추정 | 경로 손실(Path Loss) 및 대규모 지형 감쇠 |
| **내부 루프 (Fast Closed)**| 1.25 ms (800 Hz) | 기지국 ──► 단말 | 레일리 페이딩(Rayleigh Fading) 등 급격한 채널 변화 |
| **외부 루프 (Outer Loop)**| 20 ms (50 Hz) | 기지국 제어기 | 목표 FER(Frame Error Rate 1%) 유지를 위한 Eb/No 설정점 갱신 |
