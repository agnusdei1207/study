- 본질: **CDMA(Code Division Multiple Access)** : 같은 주파수 대역의 사용자를 확산 코드로 구분하는 다중접속 방식
- 메커니즘: 송신 데이터에 코드를 곱해 확산하고, 수신기가 같은 코드와 상관 연산으로 원하는 신호를 복원

<summary>핵심 용어</summary>

- **CDMA(Code Division Multiple Access)** : 확산 코드로 사용자 신호를 구분하는 다중접속 방식
- **확산 코드(Spreading Code)** : 사용자 신호의 대역을 넓히고 수신기의 상관 복원에 쓰는 코드
- **칩 레이트(Chip Rate)** : 확산 코드의 칩이 초당 전송되는 횟수
- **원근 문제(Near-Far Problem)** : 강한 사용자 신호가 약한 사용자 신호를 간섭으로 덮을 수 있는 수신 문제
- **RAKE 수신기(RAKE Receiver)** : 지연이 다른 다중경로 성분을 별도 경로로 수신·결합하는 수신기
- **전력 제어(Power Control)** : 수신 품질과 간섭을 고려해 송신 전력을 조정하는 기법


## 2~4교시 25점 답안

### Ⅰ. CDMA의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CDMA** : 확산 코드를 이용해 같은 주파수 대역의 사용자 신호를 구분하는 다중접속 방식 |
| 목적 | 주파수 대역을 공유하며 사용자별 신호 구분 |

### Ⅱ. 확산·역확산 원리

```text
사용자 데이터
    ↓ 코드 곱셈
확산 신호 ─────┐
               ├→ 무선 채널 합성 → 같은 코드 상관 → 데이터 복원
다른 사용자 신호 ┘
```

수신 복원은 코드 간 상관 특성과 동기 상태에 의존하며, 사용자 간 간섭이 항상 0이 되는 것은 아님.

### Ⅲ. 다중접속 방식 비교

| 구분 | 분리 자원 | 사용자 구분 기준 |
|---|---|---|
| FDMA(Frequency Division Multiple Access) | 주파수 대역 | 할당 주파수 |
| TDMA(Time Division Multiple Access) | 시간 슬롯 | 할당 시간 |
| CDMA | 같은 대역을 공유 | 확산 코드와 상관 특성 |

### Ⅳ. 무선 운용 특성과 수신

| 현상·기능 | 의미 | 운용상 고려 |
|---|---|---|
| 원근 문제 | 강한 신호가 약한 신호의 복조를 어렵게 하는 현상 | 전력 제어로 수신 품질과 간섭 관리 |
| 다중경로 | 반사 등으로 지연된 신호 성분이 도착 | RAKE 수신기 등으로 성분 활용 가능 |
| 소프트 핸드오버 | 일부 CDMA 계열에서 기지국 간 통신을 겹쳐 유지하는 방식 | 적용 무선 인터페이스·망 설정에 따라 지원 여부 확인 |

### Ⅴ. 한계와 대응

| 한계 | 대응 |
|---|---|
| 사용자 신호 전력 차이로 간섭 증가 | 송신 전력 제어와 수신 품질 감시 |
| 비동기·다중경로로 코드 간 간섭 발생 | 동기·상관 특성 및 수신기 성능 검증 |
| 사용자 수 증가에 따라 간섭과 품질 저하 | 수용량을 고정 슬롯 수처럼 단정하지 말고 부하·서비스 품질 기준으로 관리 |

### Ⅵ. 기술사적 제언

| 우선 선택 | 적용·확인 |
|---|---|
| 무선 환경과 서비스 품질을 기준으로 CDMA 적용성 판단 | 사용자 부하·수신 품질·전력 제어·핸드오버 지원을 현장 시험으로 확인 |
