## 연관 키워드

- CDMA(Code Division Multiple Access), 대역 확산(Spread Spectrum), 직접 확산(DSSS), 칩 레이트(Chip Rate)
- PN 코드(Pseudo-Noise Code), 왈시 코드(Walsh Code), 레이크 수신기(Rake Receiver), 역확산(Despreading)
- 원근 문제(Near-Far Problem), 고속 전력 제어(Fast Power Control), 소프트 핸드오버(Soft Handover), 셀 브리딩(Cell Breathing)

## Ⅰ. CDMA의 개요

- 핵심 요약 : 모든 사용자가 같은 주파수와 시간을 공유하되 고유 확산 코드로 구분하는 **코드 분할 다중 접속** 방식.
- 개념 : 각 사용자에게 상호 상관이 매우 낮은 고유 코드를 부여하고, 신호를 넓은 대역으로 확산해 전송하는 **대역 확산** (Spread Spectrum) 기반 다중 접속 기술.
- 배경 및 필요성 : 1세대 아날로그 방식인 주파수 분할 다중 접속(FDMA)은 주파수 자원이 금방 고갈되고 도청에 취약하여, 주파수 재사용 효율을 높일 방식이 필요해짐.
- 주요 목적 : 가입자 용량 증대, 전파 방해와 도청에 대한 내성 확보, 기지국 전환 시 통화 단절 방지.

## Ⅱ. CDMA의 특징 및 장점

- 핵심 요약 : 코드로 사용자를 구분하는 구조가 주파수 재사용과 통화 품질 보장으로 이어지는 방식.

1. 전 셀 주파수 재사용 : 모든 셀이 같은 주파수를 쓰고 코드로만 사용자를 구분 → 주파수 이용 효율과 가입자 용량 증가.
2. 대역 확산 : 신호를 넓게 펼쳐 전송 → 특정 주파수 간섭과 전파 방해에 강하고 신호 노출이 적어 보안성 향상.
3. 레이크 수신 : 다중 경로로 도착한 신호를 여러 경로에서 모아 합성 → 페이딩을 이용한 다이버시티 이득 확보.
4. 소프트 핸드오버 : 새 기지국과 연결을 먼저 맺은 뒤 이전 연결을 끊음 → 셀 경계에서도 통화 단절이 적음.

## Ⅲ. CDMA의 구조 (흐름)

- 핵심 요약 : 송신 측은 데이터에 확산 코드를 곱해 광대역으로 보내고, 수신 측은 같은 코드를 다시 곱해 원래 데이터를 복원하는 구조.
- **직접 확산** (DSSS, Direct Sequence Spread Spectrum) : 데이터 신호에 칩 속도가 훨씬 빠른 확산 코드를 직접 곱하여 대역폭을 넓히는 방식.
- **왈시 코드** (Walsh Code) : 기지국에서 단말로 가는 순방향 링크에서 사용자 간 간섭을 없애는 직교 코드.
- **PN 코드** (Pseudo-Noise Code) : 잡음처럼 보이는 의사 난수 코드로, 역방향 링크와 기지국 식별에 쓰임.

```text
[ 송신 측 확산 ]

원시 데이터 (협대역)
   ↓ 확산 코드 곱셈 (Spreading)
광대역 신호
   ↓ 무선 채널 전송 (타 사용자 신호와 혼합)
```

```text
[ 수신 측 복원 ]

혼합 신호 수신
   ↓ 동일 확산 코드 곱셈 (Despreading)
타 사용자 신호는 잡음으로 소멸
   ↓ 적분 및 판정
원시 데이터 복원
```

- **레이크 수신기** (Rake Receiver) : 다중 경로 신호를 여러 핑거로 따로 받아 위상을 맞춰 합성하는 수신 장치.
- **고속 전력 제어** (Fast Power Control) : 기지국이 단말의 송신 전력을 초당 수백 회 이상 조절하여 원근 문제를 해결하는 기능.

## Ⅳ. CDMA의 비교

- 핵심 요약 : CDMA는 주파수 재사용률과 소프트 핸드오버에서 강점을 가지지만, 전력 제어가 필수이고 광대역 전송에 불리함.

| 비교 축 | FDMA (1세대) | TDMA (2세대 GSM) | CDMA (2·3세대) | OFDMA (4·5세대) |
| --- | --- | --- | --- | --- |
| 다중 접속 기준 | 주파수 분할 | 시간 슬롯 분할 | 코드 분할 | 직교 부반송파 분할 |
| 주파수 재사용 | 인접 셀 간섭 회피를 위해 낮게 설계 | 인접 셀 간 주파수 계획 필요 | 전 셀 동일 주파수 사용 | 전 셀 동일 주파수 사용 |
| 다중 경로 대응 | 등화기 | 적응형 등화기 | 레이크 수신기로 활용 | 순환 전치(CP) 삽입 |
| 핸드오버 | 하드 핸드오버 | 하드 핸드오버 | 소프트 핸드오버 | 하드 핸드오버 기반 |
| 주요 제약 | 가입자 용량 한계 | 슬롯 동기화 부담 | 원근 문제, 전력 제어 필수 | 높은 PAPR로 증폭기 부담 |

- 선택 기준 : 용량과 보안이 중요한 음성·저속 데이터 시대에는 CDMA의 코드 분할이 유리했고, 광대역 고속 데이터에는 직교 부반송파 방식이 적합함.

## Ⅴ. CDMA의 한계와 방안

- 핵심 요약 : 원근 문제, 셀 축소, 광대역 처리 부담이 주요 한계이며, 고속 전력 제어, 부하 분산, 광대역 다중화 전환으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 원근 문제 (Near-Far Problem) | 가까운 단말 신호가 먼 단말 신호를 압도하여 수신 실패 발생 | 고속 폐루프 전력 제어로 모든 단말 신호 세기를 맞춤 | 전력 제어 오차 |
| 셀 브리딩 (Cell Breathing) | 가입자가 몰리면 간섭이 커져 셀 반경이 줄어듦 | 인접 기지국 간 부하 분산과 핸드오버 영역 조정 | 셀당 부하율, 호 차단율 |
| 광대역 처리 부담 | 전송 속도가 높아질수록 칩 레이트와 레이크 연산량이 커짐 | 광대역에 유리한 OFDMA 계열로 전환 | 단말당 처리량 |

## Ⅵ. CDMA에 대한 기술사적 제언

- 핵심 요약 : CDMA의 원리는 이동통신 세대교체 이후에도 항법과 보안 무선 분야에서 유효하므로, 기술 특성에 맞춘 용도 선택이 중요함.
- 항법과 군용 통신 조직은 대역 확산이 주는 재밍 내성과 저피탐 특성을 계속 활용하도록 무선 시스템을 설계함.
- 클라우드 운영 조직은 기지국 전환 때 이전 연결을 유지하는 소프트 핸드오버의 발상을 무중단 배포와 트래픽 전환 설계에 참고함.
- 이동통신 사업자는 용량 증설을 셀 분할과 부하 분산으로 풀고, 광대역 서비스는 직교 다중화 기반 표준에서 운영함.

## Ⅶ. 결론

- 핵심 요약 : CDMA는 코드로 사용자를 구분하여 주파수를 전 셀에서 재사용하는 대역 확산 기반 다중 접속 기술이다.
- 시사점 : 용량과 보안을 얻는 대신 전력 제어와 광대역 처리의 부담을 감수한 방식으로서, 세대별 기술 선택의 기준점을 보여준다.
