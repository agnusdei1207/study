## 한 줄 본질
- 서로 다른 하드웨어와 OS를 가진 컴퓨터들이 대화할 때 발생하는 데이터 형식 불일치와 통신 오류의 혼란 → 데이터의 물리적 배치 형식(구문), 담긴 명령의 뜻(의미), 주고받는 순서와 속도(타이밍)의 3대 요소를 표준으로 규정 → 전 세계 모든 단말 간 완벽한 상호운용성 보장 / 명세의 미세한 해석 차이로 인한 통신 교착(Deadlock) 발생 위험

```text
  +---------------------------------+---------------------------------+
                                    | (데이터가 올바른 형식으로 도착하면)
                                    v
  +-------------------------------------------------------------------+
  | 2. 의미 (Semantics) : "무슨 뜻이며, 무엇을 해야 하는가?"           |
  |    - 각 제어 필드의 기능 정의, 오류 처리 지침, 상태 전이 명령     |
  |    (예: SYN 플래그=1이면 '연결 요청', RST=1이면 '강제 즉시 종료')   |
  +---------------------------------+---------------------------------+
                                    | (올바른 뜻을 알았으면)
                                    v
  +-------------------------------------------------------------------+
  | 3. 타이밍 (Timing) : "언제 보내고, 속도는 얼마인가?"              |
  |    - 송수신자 간의 전송 속도 일치, 패킷의 순서 제어, 타임아웃 규칙|
  |    (예: 3초 동안 ACK가 안 오면 재전송, 3-way 핸드셰이크 순서)     |
  +-------------------------------------------------------------------+
```

## 핵심 용어
- 구문(Syntax): 데이터의 형식(Format), 부호화(Coding) 방식 및 신호 레벨을 정의. 비트 스트림의 어느 위치에 어떤 정보가 들어가는지 물리적 구조를 규정
- 의미(Semantics): 각 비트 필드가 무엇을 뜻하며, 해당 신호를 받았을 때 수신 장치가 어떤 제어 동작을 수행해야 하는지 행동 규칙을 정의
- 타이밍(Timing): 송신자와 수신자 사이의 전송 속도 조절(흐름제어) 및 패킷이 오고 가는 시간 순서(Sequencing)를 정의

## 핵심 통찰
- 프로토콜은 컴퓨터 공학의 "외교 언어"와 같아서, 문법(구문)만 맞다고 통신이 되는 것이 아니라 그 안의 약속된 의미와 대화 예절(타이밍)이 모두 일치해야 함
- 구문 오류는 헤더 파싱 단계에서 즉시 드롭(Drop)되어 쉽게 고쳐지지만, 타이밍 오류(타임아웃 경쟁 상태, 레이스 컨디션)는 간헐적으로 시스템을 굳게 만드는 최악의 장애 유발
- 실제 프로토콜 설계 표준(IETF RFC)을 작성할 때는 유한 상태 머신(FSM, Finite State Machine) 다이어그램을 통해 모든 타이밍과 상태 전이를 수학적으로 명확히 정의

## 이웃 토픽과 구분
- 구문(Syntax) vs 의미(Semantics): 구문은 패킷의 "껍데기 형태(비트 위치와 크기)" / 의미는 그 껍데기 속 값에 부여된 "실제 동작 명령(행동 지침)"

## 문제·원인·대책
- 적용 상황: 이기종 벤더 장비 간 프로토콜 연동 통신 두절
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 양측 장비 간 패킷 헤더 파싱 실패 | 구문(Syntax) 정의 상의 엔디안(Big-Endian vs Little-Endian) 불일치 | 네트워크 바이트 오더(Network Byte Order, 빅엔디안) 표준 준수 | 이기종 CPU 아키텍처 간 완벽한 바이너리 호환성 확보 |
| 패킷 무한 대기로 인한 통신 교착상태(Deadlock) | 타이밍(Timing) 명세 누락으로 양측이 상대방 응답을 동시 대기 | 재전송 타임아웃(Timer) 및 상태 전이도(FSM) 엄격 정의 | 비정상 지연 발생 시 타임아웃을 통한 안전한 연결 리셋 |
