## 30초 인출

- 본질: **통신 프로토콜** 은 통신 주체가 메시지 형식과 처리 규칙을 공유하도록 정한 약속
- 메커니즘: 구문이 메시지 형식을 정하고, 의미가 필드의 동작을 정하며, 타이밍이 송수신 순서·속도 조건을 정함

<details>
<summary>핵심 용어</summary>

- **통신 프로토콜 (Communication Protocol)** : 통신 주체가 메시지를 교환하기 위한 형식·의미·절차의 약속.
- **구문 (Syntax)** : 메시지의 형식·필드 배치·부호화 규칙.
- **의미 (Semantics)** : 필드 값과 메시지에 따른 처리·응답 동작.
- **타이밍 (Timing)** : 메시지 교환 시점·순서·속도와 시간 제한 조건.
- **상태 기계 (State Machine)** : 현재 상태와 입력 이벤트에 따라 다음 동작·상태를 정하는 모델.
- **상호운용성 (Interoperability)** : 서로 다른 구현이 정해진 규격에 따라 함께 동작하는 능력.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **통신 프로토콜** 은 통신 주체가 메시지 형식과 처리 규칙을 공유하도록 정한 약속 |
| 목적 | 상호 간 메시지 교환과 일관된 처리 지원 |

## Ⅱ. 기본 요소와 검증 질문

```text
통신 프로토콜 명세
    ├── 구문: 메시지의 형식
    ├── 의미: 메시지에 따른 동작
    └── 타이밍: 교환 시점·순서
```

정적 분류도. 세 요소는 시간 순서가 아니라 함께 명세해야 하는 관점.

## Ⅲ. 요소별 설계 내용

| 요소 | 설계·명세 내용 | TCP 예 |
|---|---|---|
| 구문 | 필드 구조·길이·인코딩·허용 값 | 포트·시퀀스·플래그 필드 |
| 의미 | 필드 해석·요청 처리·오류 응답 | SYN·ACK에 따른 연결 상태 동작 |
| 타이밍 | 메시지 순서·재전송·시간 초과 | 연결 수립·재전송 타이머 동작 |

## Ⅳ. 오류 유형과 검증

```text
프로토콜 명세
    ├→ 형식·인코딩 시험 → 필드 파싱 확인
    ├→ 동작 시험 → 상태·응답 확인
    └→ 시간 시험 → 순서·타임아웃 확인
             ↓ 세 시험 결과를 반영
       독립 구현 간 상호운용 시험
```

| 오류 유형 | 나타나는 현상 | 검증 방법 |
|---|---|---|
| 구문 불일치 | 필드 파싱·길이 해석 오류 | 경계값·잘못된 형식 입력 시험 |
| 의미 불일치 | 같은 메시지에 다른 처리 | 상태 전이·오류 응답 시험 |
| 타이밍 불일치 | 재전송 중복·응답 대기·순서 오류 | 지연·손실·중복 메시지 시험 |

## Ⅴ. 기술사적 제언 — 규격과 구현의 교차 검증

| 한계 | 해결 방안 |
|---|---|
| 문서상 형식 검토만으로 구현 간 동작 차이와 시간 오류를 찾기 어려움 | 독립 구현 간 적합성·상호운용 시험에 지연·손실·오류 입력을 포함하고, 결과를 규격 요구사항과 추적 가능하게 관리 |
