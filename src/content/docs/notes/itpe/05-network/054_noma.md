## 30초 인출

- 본질: **NOMA(Non-Orthogonal Multiple Access)** : 동일한 시간·주파수·공간 무선 자원 블록에 복수 사용자의 신호를 비직교 방식으로 중첩 전송하고 수신단에서 연속 간섭 제거(SIC)를 통해 분리 복호하는 차세대 다중 접속 기술
- 메커니즘: 송신단에서 채널 이득이 열악한 원거리 단말에 고전력을, 양호한 근거리 단말에 저전력을 차등 배분하여 중첩 부호화(Superposition Coding) 송신 후, 근거리 단말은 SIC 기법으로 원거리 신호를 먼저 제거하고 자기 신호 복호
- 통찰: 주파수 스펙트럼 효율성과 대규모 동시 연결성을 극대화할 수 있으나 수신단 SIC 처리 시 채널 추정 오류가 후속 신호로 누적 전파되는 한계 극복을 위해 채널 이득 차 기반 사용자 페어링 알고리즘 구축 필수

<details>
<summary>핵심 용어</summary>

- **Superposition Coding (중첩 부호화)** : 송신 기지국에서 동일한 무선 자원에 서로 다른 사용자 신호를 채널 품질에 역비례하는 전력 가중치를 부여해 하나로 합성하는 송신 기술
- **SIC (Successive Interference Cancellation)** : 수신단에서 신호 세기가 가장 강한 간섭 신호부터 차례대로 복호·재생성한 후 수신 신호에서 감산하여 최종 목표 신호를 분리하는 연속 간섭 제거 기술
- **Power-domain NOMA** : 동일 시간·주파수 자원에서 전력 레벨의 차이만을 이용하여 사용자를 다중화하는 방식
- **Code-domain NOMA** : 사용자마다 저밀도 서명(Sparse Signature)이나 비직교 확산 코드를 부여하여 다중화하는 방식 (SCMA, MUSA 등)
- **User Pairing (사용자 페어링)** : SIC 성능 최적화를 위해 채널 이득 차이가 가장 큰 원거리 단말과 근거리 단말을 하나의 자원 블록에 짝지어 할당하는 스케줄링 기법

</details>

## 2~4교시 25점 답안

## Ⅰ. NOMA의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 단일 시간·주파수 무선 자원 블록(RB)에 복수 사용자의 데이터를 직교 분할 없이 전력 또는 코드 도메인에서 중첩 할당하여 동시 송수신하는 비직교 다중 접속 기술 |
| 목적 | 한정된 주파수 스펙트럼의 주파수 이용 효율(Spectral Efficiency) 극대화, 대규모 사물인터넷(mMTC) 기기의 초대용량 동시 접속성 확보, 셀 경계 단말의 전송 공정성(Fairness) 향상 |

## Ⅱ. NOMA의 특징 및 전력 도메인 핵심 원리

| 특징 항목 | 세부 동작 원리 및 특성 |
|---|---|
| **비직교 자원 공유** | 시간이나 주파수를 쪼개어 단독 할당하던 기존 OMA와 달리 동일 자원을 복수 단말이 완전 공유하여 샤논 용량(Shannon Capacity) 한계 근접 |
| **채널 이득 역비례 전력 할당** | 기지국 기준 채널 이득이 낮은 셀 경계 단말(Far User)에 높은 송신 전력($P_{far}$)을, 채널이 우수한 근거리 단말(Near User)에 낮은 전력($P_{near}$)을 배분 |
| **수신단 간섭 제거 (SIC)** | Near User는 전력이 압도적으로 큰 Far User 신호를 잡음이 아닌 유효 신호로 먼저 복호하여 제거한 후 자신의 미약한 신호를 성공적 검출 |
| **Far User의 단순 수신** | Far User는 자신의 고전력 신호 대비 미약한 Near User 신호를 단순 백그라운드 잡음(Noise)으로 간주하고 SIC 없이 직접 복호 |

## Ⅲ. NOMA 송수신 아키텍처 및 SIC 동작 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 전력 도메인 NOMA 송수신 및 SIC 아키텍처 ]          │
│                                                                        │
│   [기지국 (gNodeB)]                                                    │
│   - Near User 데이터: x1 (채널 우수, 배분 전력 P1 = 20%)               │
│   - Far User 데이터 : x2 (채널 열악, 배분 전력 P2 = 80%)               │
│   - 합성 신호: s = √(P1)·x1 + √(P2)·x2 ─── (동일 주파수 f1, 시간 t1)   │
│                      │                                                 │
│          ┌───────────┴────────────────────────┐                        │
│          ▼                                    ▼                        │
│   [Far User 단말 (채널 열악)]        [Near User 단말 (채널 우수)]      │
│   - 수신 신호: y2 = h2·s + n2         - 수신 신호: y1 = h1·s + n1      │
│   - 처리 방식: P2 신호가 압도적이므로 - 1단계: P2 신호(x2)를 먼저 복호 │
│     P1을 단순 잡음 취급하여           - 2단계: 복호된 x2를 재생성 후   │
│     SIC 없이 x2 직접 복호               수신 신호 y1에서 감산 제거(SIC)│
│                                       - 3단계: 간섭 제거 후 x1 복호    │
└────────────────────────────────────────────────────────────────────────┘
```

| 동작 단계 | 주관 엔터티 | 세부 수행 메커니즘 |
|---|---|---|
| **1. 채널 추정 및 사용자 페어링** | 기지국 스케줄러 | 각 단말의 CSI 피드백을 분석하여 채널 이득 차이가 현저한 Near User와 Far User를 1개 자원에 페어링 |
| **2. 중첩 부호화 (Superposition)**| 기지국 변조기 | 사용자별 전송 전력을 차등 곱하여 단일 복합 파형($s = \sqrt{P_1}x_1 + \sqrt{P_2}x_2$)으로 가산 변조 |
| **3. Far User 직접 복호** | Far User 단말 | 수신 신호에서 전력이 큰 자신의 신호($x_2$)를 즉시 판정; 미소 전력 $x_1$은 가우시안 잡음으로 처리 |
| **4. Near User SIC 간섭 제거** | Near User 단말 | 전력이 큰 $x_2$를 먼저 완벽히 복호하여 RF 신호로 재합성한 뒤, 원 수신 신호에서 차감하여 $x_1$ 순수 복호 |

## Ⅳ. OMA(직교 다중 접속) vs NOMA(비직교 다중 접속) 비교

| 비교 항목 | OMA (Orthogonal Multiple Access) | NOMA (Non-Orthogonal Multiple Access) |
|---|---|---|
| **자원 할당 원리** | 시간(TDMA), 주파수(FDMA/OFDMA)를 직교 분할 | 단일 시간·주파수 블록에 전력/코드로 복수 사용자 중첩 |
| **다중 사용자 간섭 (MUI)**| 직교성 보장으로 사용자 간 간섭이 원천 없음 | 동일 자원 공유로 상호 간섭 발생 (SIC로 사후 제거) |
| **스펙트럼 효율성** | 할당된 서브캐리어 수에 비례하여 대역폭 제한 | 동일 대역폭 내 2~3배 이상의 시스템 총 전송 용량 달성 |
| **수신단 복잡도** | 단순 FFT 및 단일 채널 이퀄라이저로 복호 가능 | 복수 단계의 복호 및 감산 연산을 수행하는 고성능 SIC DSP 필요 |
| **셀 경계 사용자 공정성** | 경계 단말에 자원을 많이 주면 전체 용량 급감 | 고전력 배분으로 셀 경계 단말의 QoS 보장과 용량 증대 동시 만족 |
| **적용 표준 및 기술** | 4G LTE (OFDMA/SC-FDMA), Wi-Fi 6 (OFDMA) | 5G-Advanced 후보 기술, 6G 초대용량 무선 접속망 |

## Ⅴ. NOMA의 한계와 방안

| 한계 | 방안 |
|---|---|
| 수신단 SIC 처리 시 1단계 신호(Far User 신호) 복호에 오류가 발생하면 잔여 간섭이 제거되지 않고 누적 증폭되어 2단계 자신의 신호까지 연쇄 파괴되는 오류 전파(Error Propagation) 발생 | 채널 이득 차이가 확연한 단말끼리만 짝을 짓는 동적 사용자 페어링(Near-Far Pairing)을 적용하고, 3개 이상의 다중 중첩을 지양하여 2-User 페어링으로 제한하며 터보/LDPC 강력한 채널 코딩 결합 |
| 다중 사용자 중첩 전송을 위해 기지국이 모든 단말의 순간 채널 상태 정보(CSI)를 완벽히 파악해야 하므로 고속 이동 환경에서 채널 에이징(Aging) 및 업링크 피드백 오버헤드 급증 | 딥러닝(Autoencoder) 기반 CSI 압축 피드백 기술을 도입하고, 채널 변화에 강인한 부분 공간 기반 통계적 채널 정보 활용 빔포밍 결합 |
| 단말이 타인의 패킷을 선복호하여 제거하는 물리적 메커니즘 특성상 암호화되지 않은 정보가 타 단말에 노출될 수 있는 물리 계층 도청(Eavesdropping) 보안 취약성 상존 | 물리 계층 보안(PLS, Physical Layer Security) 기법을 연계하여 기지국에서 인공 잡음(Artificial Noise)을 Far User 신호 방향으로 부가 송출하거나 단말 간 직교 프리코딩 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
6G 이동통신 인프라 설계 시 NOMA는 Massive MIMO와 결합된 Beamformed-NOMA 형태로 진화하고 있으므로, 단일 빔 내에서 채널 상관도가 높고 채널 이득 차이가 큰 사용자들을 그룹화하고, 단말의 연산 부담과 배터리 소모를 고려하여 기지국 스케줄러에서 OMA 모드와 NOMA 모드를 실시간 트래픽 요구량에 따라 동적으로 스위칭하는 하이브리드 접속 정책 수립 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 전력 도메인 vs 코드 도메인 NOMA 구조 비교 ]       │
│                                                                        │
│   [방식 1: 전력 도메인 NOMA]           [방식 2: 코드 도메인 NOMA (SCMA)]│
│                                                                        │
│   User 1 ──► [x1] ──► * √P1 (Low) ─┐   User 1 ──► [희소 코드북 1] ─┐   │
│                                     ├►Σ                              ├►Σ│
│   User 2 ──► [x2] ──► * √P2 (High)─┘   User 2 ──► [희소 코드북 2] ─┘   │
│                                                                        │
│   - 분리 원리: 신호 전력 크기 차이    - 분리 원리: 희소 다차원 성좌점 │
│   - 수신 알고리즘: SIC (순차 제거)    - 수신 알고리즘: MPA (메시지 전달)│
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| NOMA 기술 유형 | 다중화 도메인 | 송신단 특징 | 수신단 검출 기법 | 장단점 및 특징 |
|---|---|---|---|---|
| **Power-domain NOMA** | 전력 (Power) | 중첩 부호화 (전력 차등 배분) | 연속 간섭 제거 (SIC) | 구현 단순, 사용자 수 증가 시 오류 전파 위험 |
| **SCMA (Sparse Code)**| 코드 (Code) | 비트열을 다차원 희소 성좌로 매핑 | 메시지 전달 알고리즘 (MPA) | 과적합 우수, 수신단 연산 복잡도 매우 높음 |
| **PDMA (Pattern Div)** | 공간/코드/전력 | 불균일한 패턴 행렬 다중화 | SIC 및 확장 터보 복호 | 유연한 다중화 가능, 패턴 최적화 난이도 높음 |
| **RSMA (Rate-Splitting)**| 전력 + 공간 | 공통 메시지와 개별 메시지 분할 | 부분 SIC 및 선형 결합 | 불완전 CSI에 가장 강인, 차세대 6G 표준 유력 |
