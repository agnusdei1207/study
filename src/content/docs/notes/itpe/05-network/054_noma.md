## 연관 키워드

- NOMA, 비직교 다중 접속, OMA, 직교 다중 접속, 샤논 용량 한계
- 중첩 코딩(Superposition Coding), 전력 할당, 연속 간섭 제거(SIC)
- SCMA, MPA, 사용자 페어링, 그랜트 프리(Grant-Free), mMTC, CSI

## Ⅰ. NOMA(Non-Orthogonal Multiple Access)의 개요

- 핵심 요약 : 같은 시간·주파수 자원에 여러 사용자의 신호를 전력 차이로 겹쳐 보내 주파수 효율을 높이는 다중 접속 기술.
- 개념 : 동일한 시간·주파수 자원에 서로 다른 사용자의 데이터를 직교하지 않게 겹쳐 전송하는 **비직교 다중 접속** (NOMA, Non-Orthogonal Multiple Access) 기술로, 다중화 영역은 전력 영역 또는 코드 영역임.
- 배경 및 필요성 : 기존 4G·5G의 **직교 다중 접속** (OMA, Orthogonal Multiple Access, OFDMA(Orthogonal Frequency-Division Multiple Access), TDMA(Time Division Multiple Access), CDMA(Code Division Multiple Access)) 방식은 자원 블록 간 간섭을 없애려고 직교성을 강제하므로, 주파수 효율이 **샤논 용량 한계** (Shannon Capacity Limit)에 가까워져 개선 여지가 줄어듦.
- 주요 목적 : 대역폭을 넓히지 않고 주파수 효율을 높이고, mMTC(massive Machine Type Communications) 같은 대규모 사물 접속을 수용하며, 원거리 단말의 통신 공정성을 보장.

## Ⅱ. NOMA의 특징 및 장점

- 핵심 요약 : 중첩 전송과 연속 간섭 제거를 결합해, 자원을 나눠 쓰는 대신 같은 자원을 여러 단말이 동시에 쓰는 구조.

1. **중첩 코딩** (Superposition Coding) : 기지국이 채널 이득이 다른 단말들의 신호를 전력 비율을 달리해 한 블록에 더해 동시 송신 → 같은 자원에서 여러 단말의 동시 접속 가능.
2. **전력 할당** (Power Allocation) : 셀 경계의 먼 단말에 큰 전력을, 셀 중심의 가까운 단말에 작은 전력을 배분 → 약한 신호의 단말도 수신할 수 있어 공정성 확보.
3. **연속 간섭 제거** (SIC, Successive Interference Cancellation) : 강한 신호를 먼저 복조해 수신 신호에서 빼고 자신의 신호를 복원 → 간섭을 단계적으로 제거하며 자원을 공유.

## Ⅲ. NOMA의 구조 (흐름)

- 핵심 요약 : 기지국의 중첩 송신과 단말별 수신 처리가 짝을 이루며, 근거리 단말은 SIC를, 원거리 단말은 자기 신호의 우세를 이용하는 구조.

```text
[ 근거리 단말의 수신 흐름 (SIC) ]

중첩 수신 신호
      ↓ 1단계: 강한 원거리 신호 복조
      ↓ 2단계: 수신 신호에서 감산
      ↓ 3단계: 자기 신호 복조
```

```text
[ 원거리 단말의 수신 ]

중첩 수신 신호
      ↓ 큰 전력의 자기 신호가 우세
자기 신호 바로 복조 (타 신호는 잡음으로 처리)
```

## Ⅳ. NOMA와 직교 다중 접속의 비교

- 핵심 요약 : OMA는 수신이 단순한 대신 주파수 효율에 한계가 있고, NOMA는 효율과 접속 수를 얻는 대신 수신단과 채널 정보의 부담이 커지는 상반 구조.

| 비교 축 | OMA (OFDMA, 4G·5G) | NOMA (전력 영역) | NOMA (코드 영역, SCMA) |
| --- | --- | --- | --- |
| 자원 직교성 | 시간·주파수 완전 직교 | 비직교 (같은 주파수·시간 공유) | 비직교 (공유 코드북) |
| 다중화 영역 | 주파수 블록 (부반송파) | 전력 영역 | 희소 코드 영역 |
| 수신단 복잡도 | 낮음 (단순 FFT 기반 복조) | 높음 (SIC 연산 필수) | 매우 높음 (MPA 반복 연산) |
| 주파수 효율 | 직교성 유지로 제약 | 높음 | 높음 (초고밀도 접속에 특화) |
| 동시 접속 확장 | 부반송파 수에 제한 | 전력 단계 수에 따라 확장 | 희소 코드로 확장 |
| 채널 정보 요구 | 기본적인 채널 품질 피드백 | 고정밀 CSI 필요 | 정밀 채널과 코드북 정보 필요 |

- **SCMA** (Sparse Code Multiple Access) : 비트열을 다차원 희소 코드북으로 직접 매핑해 여러 사용자가 같은 자원을 공유하며, 수신단은 MPA(Message Passing Algorithm)로 비직교 신호를 분리.
- 선택 기준 : 수신 장비 연산이 제한되고 접속 수가 적으면 OMA를, 주파수 효율과 접속 수가 중요하면 NOMA를 택하되 수신단 연산 능력을 함께 검토.

## Ⅴ. NOMA의 한계와 방안

- 핵심 요약 : SIC의 오류 전파와 채널 이득 차이 부족이 성능을 떨어뜨리므로, 단말 짝짓기와 채널 코딩으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| SIC 오류 전파와 수신단 복잡도 | 1단계 복조 오류가 감산 오차로 누적되어 이후 복조가 연쇄 실패하고, 단말 수가 늘면 연산량 급증 | 한 자원당 NOMA 페어링 단말 수를 제한하는 사용자 클러스터링, LDPC(Low-Density Parity-Check)나 Polar 코드 같은 강한 채널 코딩 결합 | 연쇄 복조 실패율, 수신단 처리 지연 |
| 단말 간 채널 이득 차이 부족 | 페어링된 단말의 채널이 비슷하면 전력 차이를 주기 어려워 OMA 대비 이득이 소멸 | 채널 이득 차이가 큰 단말을 짝짓는 동적 사용자 페어링 알고리즘 | 페어링 단말 간 채널 이득 차, OMA 대비 처리량 이득 |
| 정밀 CSI(Channel State Information, 채널 상태 정보) 피드백 부담 | 전력 배분을 위해 정밀 채널 정보가 자주 필요해 제어 오버헤드 증가 | 피드백 주기 조절, 채널 예측 기반 추정 | 피드백 오버헤드 비율 |

## Ⅵ. NOMA에 대한 기술사적 제언

- 핵심 요약 : 적용 환경에 따라 NOMA의 이득이 달라지므로, 그랜트 프리와 공간 다중화 같은 결합 방식을 환경별로 검증한 뒤 도입하는 방향.

대규모 IoT(Internet of Things) 센서망처럼 단말이 자주 짧은 패킷을 보내는 환경에서는 스케줄링 신호를 줄이는 그랜트 프리(Grant-Free) 방식의 NOMA를 검토하되, 패킷 충돌 비율을 측정해 허용 범위를 정하는 것이 바람직하다. MIMO(Multiple-Input Multiple-Output)와 빔포밍을 결합해 빔을 먼저 나눈 뒤 각 빔 안에서 전력 다중화를 적용하는 설계도 가능하지만, 빔 간 간섭과 SIC 부담이 함께 늘어나므로 단계별 성능 검증이 필요하다. 위성 등 비지상망(NTN, Non-Terrestrial Network)에 적용할 때는 지연과 채널 변화가 커서 SIC의 전제가 흔들릴 수 있으므로, 지상망 기준 설계를 그대로 옮기지 말고 환경별 실험을 선행해야 한다.

## Ⅶ. 결론

- 핵심 요약 : NOMA는 자원의 직교성을 버리는 대신 전력 차이와 연속 간섭 제거로 주파수 효율과 접속 수를 함께 얻는 다중 접속 기술.
- 시사점 : 차세대 망에서 초대규모 접속을 감당하려면 수신단 복잡도와 채널 정보 비용을 함께 관리해야 실효성이 확보된다.
