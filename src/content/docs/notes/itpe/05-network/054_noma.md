```text
[NOMA] ◀━━ 머리: Ⅶ 내 의견 (근거리·원거리 채널 이득 차 기반 단말 페어링과 SIC 연산 한계 극복)
 ┃
 ┣━ Ⅰ 개요 ───── 직교 자원 분할(OFDMA)의 동시 접속 한계 → 전력 영역 다중화로 주파수 효율 극대화
 ┣━ Ⅱ 특징 ───── 비직교 중첩, 전력 영역 다중화(Power Domain), 수신단 SIC, 대규모 접속(mMTC)
 ┣━ Ⅲ 구조 ───── 중첩 부호화기(Superposition Coding) + 무선 채널 + 연속 간섭 제거기(SIC)
 ┣━ Ⅳ 흐름 ───── ① 채널 상태(CSI) 피드백 → ② 차등 전력 할당 및 신호 중첩 → ③ 강신호 복호 후 SIC 감산
 ┣━ Ⅴ 비교 ───── OMA(OFDMA) vs NOMA (자원 할당, 스펙트럼 효율, 수신단 복잡도, 다중 사용자 간섭)
 ┗━ Ⅵ 실무 ───── 수신단 SIC 처리 지연 및 하드웨어 복잡도 / 불완전 CSI에 따른 에러 전파(Error Propagation)
```

## 한 줄 본질
- 시간·주파수 직교 자원 분할 방식의 동시 수용 용량 고갈 → 동일 자원 블록에 송신 전력을 차등 분배하여 신호를 중첩 전송하고 수신단에서 연속 간섭 제거(SIC)로 분리 복호화 → 주파수 효율 및 접속 용량 대폭 증대 / 수신단 연산 지연 및 에러 전파 위험

## 핵심 그림
```text
[ 송신단 (기지국) : 전력 중첩 ]             [ 수신단 : SIC 연속 간섭 제거 ]
                                    
채널 열악 (원거리 단말 B)            단말 B (높은 전력 수신) :
  데이터 B ──> [ 전력 80% ] ┐          - 단말 A 신호를 단순 잡음 취급 후 바로 복호
                          ├─> [신호 중첩]
채널 양호 (근거리 단말 A)   │           단말 A (낮은 전력 수신) :
  데이터 A ──> [ 전력 20% ] ┘          1. 전력 큰 신호 B를 먼저 복호
                                       2. 수신 신호에서 신호 B를 감산 제거 (SIC)
                                       3. 남은 신호에서 자신의 신호 A 복호
```

## 핵심 용어
- 중첩 부호화(Superposition Coding): 송신 기지국이 동일한 시간·주파수 대역에서 여러 사용자의 데이터에 서로 다른 전력 가중치를 부여해 단일 RF 신호로 합성 전송하는 기법
- 연속 간섭 제거(SIC, Successive Interference Cancellation): 수신단에서 수신 전력이 가장 큰 사용자 신호부터 먼저 복호화한 뒤, 원래 수신 신호에서 해당 신호를 빼내는 과정을 반복해 원하는 약한 신호를 복원하는 하드웨어 연산 기법
- 단말 페어링(User Pairing): 전력 차이를 통한 SIC 분리 성능을 극대화하기 위해 기지국 인근 채널이 우수한 단말과 셀 경계 채널이 열악한 단말을 한 쌍으로 묶는 스케줄링 기법

## 핵심 통찰
- 모든 단말에 동일한 전력을 나누면 수신단에서 신호를 분리할 수 없음: 채널 상태 차이가 극명한 단말끼리 묶어 전력 차이를 크게 벌려야만 SIC의 감산 정확도가 보장됨
- 근거리 단말의 하드웨어 사양이 통신 성패를 좌우함: 원거리 단말은 복잡한 SIC 없이 기존 방식대로 복호하지만, 근거리 단말은 남의 신호를 먼저 풀고 지우는 연산을 실시간 수행해야 하므로 배터리 소모와 프로세서 부하가 집중됨
- 완벽한 채널 정보(CSI) 피드백이 전제되지 않으면 시스템 전체가 붕괴: 기지국이 추정한 채널과 실제 채널 간 불일치가 발생하면 잘못된 전력 할당으로 인해 앞단 SIC 복호 실패가 뒷단 신호 전체의 연쇄 에러 전파로 이어짐

## 이웃 토픽과 구분
- OFDMA vs NOMA: OFDMA는 주파수 부반송파를 직교 분할하여 간섭을 원천 배제하는 직교 접속 / NOMA는 동일 주파수·시간 자원을 공유하고 전력 차이와 신호 처리(SIC)로 간섭을 사후 분리하는 비직교 접속

## 문제·원인·대책
- 적용 상황: 셀 경계 밀집 환경에서 대규모 IoT 센서와 초고속 단말 동시 수용
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 근거리 단말의 복호화 오류 연쇄 발생 | 채널 피드백 오차로 인한 원거리 신호 감산(SIC) 불완전(잔여 간섭 잔존) | 보수적 전력 마진 할당 및 심볼 단위 신호 대 잡음비(SINR) 기반 동적 전력 제어 | 에러 전파 억제 및 근거리 단말 블록 오류율(BLER) 안정화 |
| 사용자 수 증가 시 수신단 연산 지연 급증 | 다중 사용자 중첩 시 반복적인 복호·감산 루프 연산 오버헤드 | 단일 자원 블록당 다중화 단말 수를 2대로 제한하는 2-User 페어링 기법 적용 | 하드웨어 복잡도 통제 및 실시간 통신 지연 요구조건 충족 |

## 내 의견
- [단말 연산 능력과 채널 차이를 고려한 하이브리드 NOMA/OMA 운용] 단말의 수신 하드웨어 제약을 무시한 전면 NOMA 도입은 저전력 모바일 기기의 배터리 조기 고갈과 지연 초래 → 나라면: 채널 이득 차이가 뚜렷한 셀 경계 단말과 중심부 고성능 단말 구간에만 2-User NOMA를 선별 적용하고, 채널 차이가 미미하거나 연산 능력이 떨어지는 초저가 센서 구간은 기존 OFDMA로 스케줄링하는 하이브리드 무선 자원 제어(RRC) 정책 수립
