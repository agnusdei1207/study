## 연관 키워드

- NOMA(Non-Orthogonal Multiple Access), OMA, 전력 도메인, 코드 도메인
- 중첩 코딩(Superposition Coding), 전력 할당, SIC(Successive Interference Cancellation)
- SCMA, 사용자 페어링, CSI, 그랜트 프리(Grant-Free)

## Ⅰ. NOMA(Non-Orthogonal Multiple Access)의 개요

- 핵심 요약 : 같은 시간·주파수 자원을 전력이나 코드의 차이로 겹쳐 쓰게 하여 주파수 효율과 접속 밀도를 높이는 다중 접속 방식.
- 개념 : 동일 시간·주파수 자원 위에 복수 사용자의 신호를 비직교로 중첩 전송하고 수신단에서 분리하는 **비직교 다중 접속** (NOMA, Non-Orthogonal Multiple Access). 다중화 축은 전력 도메인과 코드 도메인으로 나뉨.
- 배경 및 필요성 : OFDMA(Orthogonal Frequency Division Multiple Access) 같은 **직교 다중 접속** (OMA, Orthogonal Multiple Access)은 자원 분할로 간섭을 제거하는 구조라 주파수 효율이 샤논 한계(Shannon Limit)에 근접하고 접속 밀도 확장에 한계가 나타남.
- 주요 목적 : 대역폭 확장 없는 주파수 효율 향상, 대규모 사물 접속(mMTC, massive Machine Type Communication) 수용, 셀 가장자리 사용자의 전송 기회 보장.

## Ⅱ. NOMA의 특징 및 장점

- 핵심 요약 : 중첩 송신과 차등 전력, 수신단 간섭 제거의 조합이 자원 공유를 실현하는 구조.

1. 중첩 코딩 : 기지국이 채널 여건이 다른 사용자 신호를 상이한 전력 비율로 합성 송출하는 **중첩 코딩** (Superposition Coding) → 같은 자원에서 복수 사용자의 동시 서비스 효과.
2. 전력 할당 : 셀 가장자리 사용자에 높은 전력, 셀 중심 사용자에 낮은 전력을 배분하는 **전력 할당** (Power Allocation) → 열애 사용자의 수신 가능성 확보라는 공정성 효과.
3. 연속 간섭 제거 : 수신단이 강한 신호부터 복조·감산 후 자기 신호를 복원하는 **연속 간섭 제거** (SIC, Successive Interference Cancellation) → 자원 공유를 완성하는 분리 원리.
4. 코드 도메인 확장 : 비트열을 희소 코드북에 직접 매핑하는 **희소 코드 다중 접속** (SCMA, Sparse Code Multiple Access) → 과밀 접속 환경의 접속 수 확장 효과.

## Ⅲ. NOMA의 구조 (흐름)

- 핵심 요약 : 기지국의 중첩 송신과 사용자 여건별 차등 수신 처리가 짝을 이루는 구조.

```text
[ 근거리 사용자 수신 (SIC) ]

중첩 수신 신호
        ↓
강한 원거리 신호 복조
        ↓
복조 결과를 수신 신호에서 감산
        ↓
자기 신호 복원
```

```text
[ 원거리 사용자 수신 ]

중첩 수신 신호
        ↓
높은 전력의 자기 신호가 우세
        ↓
타 사용자 신호를 잡음으로
처리하고 직접 복조
```

- 시스템 구성 : 전력 비율을 정하는 스케줄러, 채널 추정부, 감산 복조의 SIC 수신기로 구성되고, 코드 도메인은 반복 분리를 수행하는 MPA(Message Passing Algorithm) 해석기를 추가.

## Ⅳ. NOMA와 직교 다중 접속의 비교

- 핵심 요약 : OMA는 수신이 단순한 대신 자원 분할의 효율 한계가 있고, NOMA는 효율·밀도를 얻는 대신 수신단과 채널 정보의 부담이 커지는 상반 구조.

| 비교 축 | OMA (OFDMA) | 전력 도메인 NOMA | 코드 도메인 NOMA (SCMA) |
| --- | --- | --- | --- |
| 자원 배분 | 시간·주파수 직교 분할 | 전력 비율 중첩 | 희소 코드 공유 |
| 수신 복잡도 | 낮음 | 높음 (SIC 필수) | 매우 높음 (MPA 반복) |
| 주파수 효율 | 직교성 유지 비용으로 제약 | 높음 | 높음 |
| 접속 확장 | 자원 블록 수 의존 | 전력 단계 수 의존 | 코드북 설계 의존 |
| 채널 정보 요구 | 기본 품질 피드백 | 정밀 CSI(Channel State Information) | 정밀 채널·코드북 정보 |

- 선택 기준 : 접속 밀도가 낮고 단말이 단순하면 OMA, 주파수 효율과 접속 수가 중시되면 NOMA를 택하되 수신단 연산 여력을 함께 검토.

## Ⅴ. NOMA의 한계와 방안

- 핵심 요약 : 간섭 제거의 오류 전파, 채널 이득 차 부족, 피드백 부담을 페어링 제어와 부호화·피드백 설계로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| SIC 오류 전파 | 앞 단계 복조 오류가 감산 오차로 누적 → 후속 복조의 연쇄 실패 | 자원당 페어링 수 제한, LDPC(Low-Density Parity-Check)·Polar 코드 결합 | 연쇄 복조 실패율 |
| 채널 이득 차 부족 | 페어링 사용자 간 여건이 비슷하면 전력 차별의 이득 소멸 | 이득 차가 큰 조합을 고르는 동적 **사용자 페어링** (User Pairing) | 페어링 간 이득 차 |
| CSI 피드백 부담 | 전력 배분에 정밀 채널 정보가 상시 필요 → 제어 오버헤드 증가 | 피드백 압축·주기 조절, 채널 예측 기반 추정 | 피드백 오버헤드 비율 |

## Ⅵ. NOMA에 대한 기술사적 제언

- 핵심 요약 : 접속 환경별 결합 방식의 검증 절차와 비지상 확장의 실험 선행 원칙을 조직 차원에서 수립하는 방향.

1. 이동통신 사업자는 단말 밀집 센서 구간에 스케줄링 신호를 줄이는 **그랜트 프리** (Grant-Free) 결합을 충돌률 측정 후 단계 도입.
2. 장비·표준화 조직은 MIMO(Multiple-Input Multiple-Output) 빔포밍과의 결합 시 빔 간 간섭과 수신 부담을 단계 검증하는 절차를 마련.
3. 위성 사업 조직은 지연·채널 변동이 큰 비지상망(NTN, Non-Terrestrial Network) 환경에서 지상망 설계 이식 전에 환경 실험을 선행하는 원칙을 정함.

## Ⅶ. 결론

- 핵심 요약 : NOMA는 자원의 직교성을 포기하고 전력·코드의 차이로 분리하는 밀도 지향 다중 접속.
- 수신단 복잡도와 채널 정보 비용의 관리가 실제 이득 실현의 관문이 되는 구조.
