## 연관 키워드

- WFQ(Weighted Fair Queuing), 패킷 스케줄링(Packet Scheduling), GPS(Generalized Processor Sharing)
- 가상 시간(Virtual Time), 가상 완료 시간(Virtual Finish Time), 가중치(Weight), 기아(Starvation)
- FIFO(First In First Out), PQ(Priority Queuing), WRR(Weighted Round Robin), DRR(Deficit Round Robin)
- WF2Q(Worst-case Fair Weighted Fair Queueing), CBWFQ(Class-Based WFQ), LLQ(Low Latency Queuing)

## Ⅰ. WFQ의 개요

- 핵심 요약 : 플로우별 가중치로 대역폭을 비례 분배하고 패킷 크기와 무관한 공정성을 보장하는 스케줄링 기법.
- 개념 : 라우터·스위치에서 플로우(Flow)마다 가중치를 부여해 대역폭을 비례 분배하는 **패킷 스케줄링** (Packet Scheduling) 알고리즘 (**WFQ**, Weighted Fair Queuing).
- 배경 및 필요성 : 단순 **FIFO** (First In First Out) 큐는 대용량 패킷을 보내는 트래픽이 큐를 독점해 음성 통신(VoIP, Voice over Internet Protocol)처럼 짧은 패킷의 지연을 키우고, 고정 우선순위 방식은 하위 큐의 **기아** (Starvation, 서비스를 영원히 받지 못하는 상태)를 유발하므로 대역폭 보장과 공정성의 동시 충족이 필요했음.
- 주요 목적 : 플로우 간 대역폭 격리와 최소 보장, 지연 민감 트래픽의 저지연 전송, 패킷 크기에 따른 편향 제거.

## Ⅱ. WFQ의 특징 및 장점

- 핵심 요약 : 이상적 유체 모델을 패킷 단위로 모사해 가상 완료 시간 순서로 전송함으로써 공정한 대역 분배와 기아 방지를 함께 얻는 방식.
- 기준 모델 : **GPS** (Generalized Processor Sharing)는 플로우들의 비트가 가중치에 비례해 동시에 흐른다고 가정한 이상적 유체 모델이며, WFQ는 **가상 시간** (Virtual Time)을 기준점으로 이를 패킷 단위로 모사함.

1. 가상 시간 : 활성 플로우 가중치 합에 반비례해 흐르는 시스템 논리 시계 → 패킷 도착 시점의 공통 기준점 제공.
2. **가상 완료 시간** (Virtual Finish Time) : 패킷이 GPS에서 전송을 마쳤을 가상 시각이며 `F = max(직전 F, 도착 시 가상 시간) + (패킷 길이 ÷ 가중치)`로 계산 → 짧고 가중치가 큰 패킷일수록 값이 작아 먼저 전송됨.
3. 가중 대역폭 보장 : 각 플로우는 자신의 가중치 비율만큼 최소 대역폭을 보장받음 → 트래픽이 몰려도 기아 상태가 발생하지 않음.
4. 패킷 크기 불변의 공정성 : 전송 순서가 바이트 기준으로 결정되므로 패킷 길이가 제각각이어도 공정 분배 유지 → 가변 길이 패킷 망에 적합.

## Ⅲ. WFQ의 구조 (흐름)

- 핵심 요약 : 플로우 분류와 플로우별 큐, 가상 시간 계산, 가상 완료 시간 기준 출구 스케줄러가 맞물린 구조.
- 플로우 분류기 : 출발·도착 주소, 포트, 프로토콜 조합으로 패킷을 플로우 단위로 분류.
- 플로우 큐 : 플로우별로 독립된 큐를 유지해 대역폭 격리를 확보.
- 출구 스케줄러 : 가상 완료 시간이 가장 작은 패킷을 선택해 전송.

```text
[ WFQ 구성 요소 관계 ]

플로우 분류기
    ↓
가중치가 부여된 플로우 큐
    ↓
가상 시간 계산기
    ↓
출구 스케줄러 (최소 F 선택)
```

```text
[ 가상 완료 시간 계산 예시 ]

가중치 : Flow 1 = 2, Flow 2 = 1
같은 길이(1000)의 패킷 도착
    ↓ F = 길이 ÷ 가중치
Flow 1의 F = 500, Flow 2의 F = 1000
    ↓
F가 작은 Flow 1 패킷 먼저 전송
```

## Ⅳ. WFQ와 다른 큐잉 방식의 비교

- 핵심 요약 : 단순성과 공정성, 지연 보장이 상충하는 관계에서 WFQ는 공정성과 지연 상한을 우선하는 위치에 놓임.
- 비교 대상 : FIFO, 우선순위 방식인 **PQ** (Priority Queuing), 가중 순환 방식인 **WRR** (Weighted Round Robin), 그리고 WFQ.

| 비교 축 | FIFO | PQ | WRR | WFQ |
| --- | --- | --- | --- | --- |
| 스케줄링 원리 | 도착 순서대로 처리 | 최상위 큐를 비운 뒤 하위 큐 처리 | 가중치만큼 패킷 수를 분배 | 가상 완료 시간 순서로 처리 |
| 대역폭 공정성 | 없음 (독점 가능) | 없음 (하위 큐 기아) | 패킷 크기가 같을 때만 공정 | 패킷 크기가 달라도 공정 |
| 지연 보장 | 예측 불가 | 최상위 큐만 보장 | 보통 수준 | 이론적 지연 상한 보장 |
| 구현 복잡도 | 매우 낮음 | 낮음 | 낮음 | 정렬 비용 수반 |
| 하드웨어 적합성 | 초고속 백본에 적합 | 코어 라우터에 기본 탑재 | 전용 칩 구현이 용이 | 고속 링크에서 구현 비용 높음 |

- 선택 기준 : 가변 길이 패킷 환경에서 지연 상한과 공정성이 필요하면 WFQ, 단순 고속 전달이 우선이면 FIFO나 PQ, 패킷 크기가 균일한 환경이면 WRR이 적합함.

## Ⅴ. WFQ의 한계와 방안

- 핵심 요약 : 패킷당 정렬 비용, 지연 지터, 플로우 식별 부담을 근사 알고리즘과 클래스 집약으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 패킷당 정렬 연산 부담 | 활성 플로우가 많은 고속 코어 라우터에서 가상 시간 계산과 정렬이 병목 → 처리율 저하 | O(1) 근사 기법인 **DRR** (Deficit Round Robin) 또는 프로그래머블 스위치의 PIFO(Push-In First-Out) 구조 활용 | 패킷당 처리 지연, 정렬 큐 깊이 |
| 지연 지터 발생 | 큰 패킷 전송 중에 도착한 지연 민감 패킷이 즉시 나가지 못함 → 음성·영상 품질 저하 | 가상 시작 시간까지 고려하는 **WF2Q** (Worst-case Fair Weighted Fair Queueing) 계열 적용 | 플로우별 지터, 지연 상한 위반 횟수 |
| 플로우 상태 관리 부담 | 주소·포트 단위 마이크로 플로우 상태 유지로 메모리 부하 증가 | 차등 서비스(DiffServ, Differentiated Services) 클래스로 플로우를 묶는 **CBWFQ** (Class-Based WFQ) 구성 | 클래스별 큐 점유율, 상태 테이블 크기 |

## Ⅵ. WFQ에 대한 기술사적 제언

- 핵심 요약 : WAN 에지, AI 패브릭, 가상화 계층 세 영역에 클래스 기반 설계와 검증 절차를 갖추는 방향.

1. 엔터프라이즈 WAN을 운영하는 네트워크 조직은 음성·핵심 업무 트래픽의 SLA(Service Level Agreement) 보장을 위해 CBWFQ에 LLQ(Low Latency Queuing)를 결합한 구조를 표준 설계로 채택해야 한다.
2. AI 클러스터 인프라 조직은 GPU(Graphics Processing Unit) 간 집합 통신의 버스트 트래픽 격리를 위해 공정 큐잉 기능을 갖춘 스위치를 도입 전에 실제 통신 패턴으로 검증하는 절차를 두어야 한다.
3. 플랫폼 운영 조직은 가상화 환경의 소프트웨어 스케줄러에서 계층형 대역 정책과 지연 정책의 충돌을 막도록 정책 템플릿을 표준화하고 주기 점검 체계를 운영해야 한다.

## Ⅶ. 결론

- 핵심 요약 : WFQ는 가중치와 가상 완료 시간으로 대역폭 공정성과 지연 상한을 함께 제공하는 패킷 스케줄링 기법임.
- 시사점 : 가변 길이 패킷이 일반화된 망에서 품질 보장의 기준 알고리즘으로 자리 잡았으며 고속화에 따라 근사형·클래스형 변형과 함께 발전 중임.
