## 연관 키워드

- Wi-Fi 7, IEEE 802.11be, EHT(Extremely High Throughput)
- MLO(Multi-Link Operation), 320 MHz 채널, 4K-QAM, 다중 RU, 저지연 WLAN

## Ⅰ. Wi-Fi 7의 개요

- 핵심 요약 : Wi-Fi 7은 IEEE 802.11be 기반 무선랜으로 다중 링크 운용과 넓은 채널·고차 변조를 통해 처리량·지연·혼잡 성능을 개선.
- 개념 : 2.4·5·6 GHz 대역에서 MLO, 최대 320 MHz 채널폭, 4K-QAM 등 물리·매체접근 기능을 제공하는 EHT(Extremely High Throughput) 무선랜 세대.
- 배경 및 필요성 : 영상회의·실시간 게임·XR·다수 단말로 무선망의 처리량뿐 아니라 혼잡 상황 지연과 링크 신뢰성 요구가 증가.
- 주요 목적 : 다중 대역·채널 자원을 효율적으로 활용해 고밀도 환경에서 무선 접속의 처리량, 응답성, 안정성을 향상.

## Ⅱ. Wi-Fi 7의 특징 및 장점

- 핵심 요약 : MLO가 여러 링크의 동시·선택적 사용을 지원하고, 넓은 채널과 고차 변조가 채널 조건이 좋은 구간의 전송 효율을 높임.

1. MLO : 단말과 AP(Access Point)가 복수 대역·링크를 함께 활용 → 처리량·복원력 향상과 지연 민감 트래픽의 유연한 전송.
2. 넓은 채널 : 6 GHz에서 최대 320 MHz 채널폭 활용 가능 → 간섭이 적은 조건에서 더 큰 대역폭 제공.
3. 4K-QAM : 심볼당 더 많은 비트를 인코딩 → 높은 신호대잡음비 환경에서 링크 전송 효율 향상.
4. 다중 RU(Resource Unit)·프리앰블 펑처링 : 채널 내 사용 가능한 일부 자원을 유연하게 할당 → 혼잡·간섭 채널에서도 잔여 스펙트럼 활용.

## Ⅲ. Wi-Fi 7의 동작 흐름

- 핵심 요약 : AP와 단말이 지원기능·채널상태를 협상하고, MLO·RU·변조방식을 링크 품질과 트래픽 요구에 맞춰 선택.

```text
AP·단말의 Wi-Fi 7 기능 협상
          ↓
대역·채널·링크 상태 측정
          ↓
트래픽 지연·대역폭 요구 분류
          ↓
MLO 링크·RU·변조방식 선택
          ↓
프레임 전송·재전송·품질 피드백
          ↓
링크·자원 재조정
```

```text
음성·게임 → 낮은 지연 링크 우선
대용량 파일 → 용량 여유 링크·넓은 채널 활용
링크 열화 → 다른 링크 선택·동시 사용
채널 일부 간섭 → 펑처링·RU 재할당
```

## Ⅳ. Wi-Fi 세대별 비교

- 핵심 요약 : Wi-Fi 7은 Wi-Fi 6/6E의 OFDMA·MU-MIMO 기반 위에 다중 링크·320 MHz·4K-QAM을 더해 용량과 지연 대응을 확장.

| 비교 항목 | Wi-Fi 6/6E(802.11ax) | Wi-Fi 7(802.11be) |
| --- | --- | --- |
| 주요 개선 | OFDMA, MU-MIMO, 6 GHz 지원(6E) | MLO, 320 MHz, 4K-QAM, 다중 RU |
| 처리 방식 | 채널·대역 중심의 단일 링크 운영 | 여러 링크의 동시·유연한 이용 가능 |
| 혼잡 대응 | 사용자·자원 단위 스케줄링 개선 | 링크 선택·펑처링·RU 배분을 추가 활용 |
| 적용 고려 | 기존 단말 호환과 일반 고밀도 WLAN | AP·단말 동시 지원과 대역별 정책이 필요한 고성능 WLAN |

## Ⅴ. Wi-Fi 7의 한계와 방안

- 핵심 요약 : 실제 성능은 단말·AP 동시 지원, 규제·대역 가용성, 채널 품질과 유선 백홀에 좌우되므로 현장측정 기반으로 도입.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기능 호환성 | AP·단말이 MLO·대역·폭을 모두 지원하지 않을 수 있음 | 장비 호환표와 혼합세대 시험, 점진적 교체 | 기능 협상 성공률 |
| 채널폭 확보 제약 | 320 MHz 연속 대역과 6 GHz 사용은 지역 규제·환경 영향 | 국가별 허용 채널·출력 확인, 현장 스펙트럼 조사 | 채널 이용률·간섭률 |
| 기대 처리량 미달 | 거리·벽·간섭·단말 성능으로 고차 변조가 유지되지 않음 | 셀 설계·AP 밀도·채널 계획 조정 | 실제 처리량·SNR·재전송률 |
| 유선 백홀 병목 | 무선 링크 처리량이 유선 업링크를 초과 | 스위치 포트·전원·백홀 용량 동시 증설 | 백홀 사용률·유선 지연 |

## Ⅵ. Wi-Fi 7 도입에 대한 기술사적 제언

- 핵심 요약 : 네트워크 설계자는 사용 단말·업무부하·전파환경에 맞춰 AP를 배치하고 무선·유선 구간을 함께 용량 설계.

1. 설계자 : 요구 대역폭·지연·동시접속 단말을 조사하고 MLO·6 GHz·채널폭을 현장 RF 측정에 따라 계획.
2. 운영자 : AP·단말 펌웨어와 기능 협상을 관리하고, 채널 간섭·로밍·백홀까지 포함한 성능 기준을 운영.
3. 보안 담당자 : WPA3 등 인증·암호화 정책, 게스트·업무망 분리, AP 관리면 보호를 검증.

## Ⅶ. 결론

- 핵심 요약 : Wi-Fi 7은 다중 링크와 확장된 채널·변조 기능으로 무선랜의 처리량·지연 대응을 개선하는 IEEE 802.11be 세대.
- 시사점 : 규격상 최대 성능보다 단말 호환성·전파환경·백홀·운영정책을 포함한 실제 서비스 품질로 도입 효과를 판단.
