## 연관 키워드

- Wi-Fi 7, IEEE 802.11be, EHT(Extremely High Throughput), WLAN(Wireless Local Area Network)
- MLO(Multi-Link Operation), 4096-QAM, 320MHz 채널, 펑처링(Puncturing), Multi-RU(Multi Resource Unit)
- TID-to-Link 매핑, WPA3(Wi-Fi Protected Access 3), 멀티기가비트 백홀

## Ⅰ. Wi-Fi 7(IEEE 802.11be EHT)의 개요

- 핵심 요약 : 넓은 채널, 고차 변조, 다중 링크 동작을 결합해 속도와 지연을 동시에 끌어올린 차세대 무선랜 표준.
- 개념 : IEEE(Institute of Electrical and Electronics Engineers) 802.11be 표준에 기반해 극초고속(EHT, Extremely High Throughput) 전송을 목표로 하는 차세대 무선랜(WLAN, Wireless Local Area Network) 규격 (**Wi-Fi 7**).
- 배경 및 필요성 : 8K 영상 스트리밍, 몰입형 XR 기기, 클라우드 게이밍처럼 대역폭과 저지연을 동시에 요구하는 서비스가 늘어나 기존 무선랜의 용량과 지연 한계가 드러남.
- 주요 목적 : 주파수 대역폭의 확장, 여러 무선 링크의 동시 활용을 통한 지연 안정화, 간섭 채널의 유연한 회피를 통한 스펙트럼 효율 극대화.

## Ⅱ. Wi-Fi 7(IEEE 802.11be EHT)의 특징 및 장점

- 핵심 요약 : 넓은 채널과 고차 변조, 다중 링크, 펑처링이 처리량·전송 효율·지연 안정성의 장점으로 이어지는 구조.

1. **320MHz 채널** : 6GHz 비인가 대역에서 연속 또는 비연속 대역을 하나의 채널로 병합 → 채널 폭이 이전 세대의 두 배로 늘어나 물리 전송률 향상.
2. **4096-QAM** (QAM, Quadrature Amplitude Modulation) : 한 심볼에 12비트를 실어 1024-QAM 대비 같은 시간의 정보 전송량을 약 20% 늘림 → 전송 효율 향상.
3. **MLO** (Multi-Link Operation, 다중 링크 동작) : 단일 단말이 2.4GHz, 5GHz, 6GHz의 여러 링크를 묶어 데이터를 분산 전송하거나 장애 링크를 즉시 전환 → 처리량 향상과 지연 안정화.
4. **펑처링** (Puncturing) : 간섭이 걸린 일부 부채널만 비우고 나머지 광대역을 계속 사용 → 간섭 시 채널 전체를 포기하던 낭비 제거.

## Ⅲ. Wi-Fi 7(IEEE 802.11be EHT)의 구조 (흐름)

- 핵심 요약 : 주파수 대역을 여러 링크로 나누어 동시에 쓰고, 각 링크 안에서 채널을 세분화해 간섭을 피하는 물리 계층 구조.
- MLD(Multi-Link Device) : 여러 링크를 함께 운용하는 접속점(AP, Access Point)과 단말의 공통 논리 장치.
- Multi-RU : 하나의 사용자에게 여러 자원 단위를 할당해 펑처링 후 남은 채널 조각까지 활용하는 자원 배분 방식.
- TID-to-Link 매핑 : 트래픽 식별자(TID, Traffic Identifier)별로 사용할 링크를 지정해 트래픽 성격에 맞는 전송 경로를 설계하는 기능.

```text
[ MLO : 다중 링크 구조 ]

단일 MLD (AP 또는 단말)
    ↓               ↓
2.4GHz 링크    5GHz·6GHz 링크
(커버리지·IoT)  (고속·저지연)
    ↓               ↓
   병합된 하나의 논리 연결
```

```text
[ 펑처링 : 간섭 채널 처리 ]

기존 : 간섭 시 80MHz 전체 포기
    ↓
Wi-Fi 7 : 간섭 난 20MHz만 제외
    ↓
잔여 60MHz를 계속 사용
```

## Ⅳ. Wi-Fi 7(IEEE 802.11be EHT)의 비교

- 핵심 요약 : Wi-Fi 7은 속도 향상뿐 아니라 다중 링크 구조로 지연과 지터를 낮춘 점에서 이전 세대와 구분됨.

| 비교 축 | Wi-Fi 7 (802.11be) | Wi-Fi 6 (802.11ax) | Wi-Fi 5 (802.11ac) |
| --- | --- | --- | --- |
| 이론 최대 속도 | 약 46Gbps | 약 9.6Gbps | 약 6.9Gbps |
| 주파수 대역 | 2.4·5·6GHz | 2.4·5GHz | 5GHz |
| 최대 채널 폭 | 320MHz | 160MHz | 160MHz |
| 최고 변조 방식 | 4096-QAM (12비트/심볼) | 1024-QAM (10비트/심볼) | 256-QAM (8비트/심볼) |
| 다중 링크 | MLO 지원 | 단일 링크 | 단일 링크 |
| 최대 MIMO(Multiple-Input Multiple-Output) 공간 스트림 | 16 스트림 | 8 스트림 | 4 스트림 |

- 선택 기준 : 고화질 영상·대용량 전송 중심 환경은 채널 폭과 변조 차이가, 음성·XR처럼 지연에 민감한 환경은 MLO의 링크 분리 효과가 선택의 핵심 기준임.

## Ⅴ. Wi-Fi 7(IEEE 802.11be EHT)의 한계와 방안

- 핵심 요약 : 고차 변조의 높은 신호 품질 요구, 단말 내부 간섭, 유선 백홀 병목이 주요 한계이며 빔포밍·필터·유선 개량으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 4096-QAM의 신호 품질 요구 | 촘촘한 성상도 구분에 고품질 신호가 필요해 실효 커버리지가 접속점 인근으로 축소 | 빔포밍 안테나 고도화, 거리·간섭에 따른 변조 단계 자동 하향 운영 | 평균 전송률, 재전송률 |
| 단말 내부 자기 간섭 | MLO 동시 송수신 시 인접 대역 송신 신호가 수신부로 유입되어 감도 저하 | BAW(Bulk Acoustic Wave)·SAW(Surface Acoustic Wave) 대역통과 필터 적용, 제약 시 단일 라디오 기반 eMLSR(Enhanced Multi-Link Single Radio) 모드 | 수신 감도 저하량, 링크 전환 빈도 |
| 유선 백홀 병목 | 무선 용량 증가에도 기존 1Gbps급 유선 구간이 상향 병목으로 작동 | 멀티기가비트 스위치와 파이버 백홀로의 단계적 전환 | 업링크 이용률, 포트 포화 시간 |

## Ⅵ. Wi-Fi 7(IEEE 802.11be EHT)에 대한 기술사적 제언

- 핵심 요약 : 트래픽 성격에 맞춘 링크 정책과 무선 구간까지 확장한 보안 체계, 유무선 통합 용량 계획으로 Wi-Fi 7을 안정 운영하는 방향.

1. 무선 운영 조직은 지연에 민감한 트래픽과 대용량 전송 트래픽을 서로 다른 링크로 분배하도록 TID-to-Link 매핑 정책을 표준 설계로 정해 QoS(Quality of Service) 일관성을 확보해야 한다.
2. 보안 조직은 WPA3(Wi-Fi Protected Access 3)-Enterprise와 802.1X 기반 상호 인증을 기본 채택하고, 접속 단말의 신뢰 상태를 지속 검증하는 제로 트러스트 원칙을 무선 구간까지 적용해야 한다.
3. 인프라 기획 조직은 무선 용량뿐 아니라 백홀 유선망과 전원 설비를 포함한 통합 용량 계획 절차를 두어 규격 도입의 효과가 현장에서 온전히 실현되도록 검증해야 한다.

## Ⅶ. 결론

- 핵심 요약 : Wi-Fi 7은 넓은 채널, 고차 변조, 다중 링크를 묶어 무선랜의 속도와 지연 한계를 함께 끌어올린 차세대 표준임.
- 시사점 : 무선 속도의 효과는 유선 백홀과 단말 설계가 함께 뒷받침될 때 온전히 드러나므로 유·무선을 함께 보는 용량 설계가 필요함.
