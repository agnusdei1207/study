## 30초 인출

- 본질: **정보이론(Information Theory)** : 클로드 섀넌(Claude Shannon)이 정립한 이론으로, 정보의 불확실성을 수학적으로 정량화하고 데이터의 압축(소스 코딩) 및 전송 한계(채널 코딩)를 분석하는 디지털 통신의 수학적 근간
- 메커니즘: 사건 확률에 반비례하는 자기 정보량과 평균 불확실성인 섀넌 엔트로피($H(X)$)를 기반으로 무손실 압축의 이론적 최소 한계와 AWGN 잡음 채널 용량을 규명
- 통찰: 무한 블록 길이를 전제한 소스-채널 분리 정리의 지연 한계와 고차원 미디어의 복잡한 확률 분포 불일치 극복을 위해 딥러닝 기반 결합 소스-채널 코딩(Deep JSCC) 연계 필수

<details>
<summary>핵심 용어</summary>

- **자기 정보량 (Self-Information)** : 특정 사건 $x$가 발생했을 때 얻게 되는 정보의 양으로 사건 발생 확률 $P(x)$의 역수의 로그값 ($I(x) = -\log_2 P(x)$)
- **섀넌 엔트로피 (Shannon Entropy)** : 정보원에서 발생하는 모든 기호들의 자기 정보량에 대한 기댓값으로, 정보원의 평균 불확실성을 의미 ($H(X) = -\sum P(x) \log_2 P(x)$)
- **상호정보량 (Mutual Information)** : 하나의 확률변수 $Y$를 관측함으로써 다른 확률변수 $X$에 대해 얻게 되는 불확실성의 감소량 ($I(X; Y) = H(X) - H(X|Y)$)
- **소스 코딩 (Source Coding)** : 데이터에 내재된 통계적 중복성(Redundancy)을 제거하여 평균 부호 길이를 엔트로피 한계까지 압축하는 부호화 기술
- **채널 코딩 (Channel Coding)** : 잡음 채널 통과 시 발생하는 비트 오류를 검출 및 정정하기 위해 의도적으로 제어용 중복 패리티를 부가하는 부호화 기술

</details>

## 2~4교시 25점 답안

## Ⅰ. 정보이론의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 1948년 클로드 섀넌이 발표한 이론으로, 정보의 발생, 정량적 측정, 압축, 무오류 전송의 수학적 법칙과 물리적 한계를 확률론적으로 규명한 디지털 통신의 근간 학문 |
| 목적 | 한정된 네트워크 대역폭과 저장 공간에서 데이터의 통계적 중복성을 극소화하고 잡음이 존재하는 전송 매체에서 데이터 전송의 신뢰성을 극대화 |

## Ⅱ. 정보이론의 특징 및 3대 핵심 척도

| 핵심 척도 | 정의 및 계산 수식 | 물리적 의미 및 특징 |
|---|---|---|
| **자기 정보량 (Self-Information)** | $I(x) = -\log_2 P(x) = \log_2 \frac{1}{P(x)}$ [bit] | 일어날 확률이 희박한 사건일수록 발생 시 놀라움(정보량)이 크고, 확실한 사건($P=1$)은 정보량 0 |
| **섀넌 엔트로피 (Shannon Entropy)**| $H(X) = E[I(X)] = -\sum_{i=1}^n P(x_i) \log_2 P(x_i)$ | 정보원의 평균 불확실성 척도; 모든 사건의 발생 확률이 균등($1/n$)할 때 엔트로피가 최대($\log_2 n$) |
| **상호정보량 (Mutual Information)** | $I(X; Y) = H(X) - H(X \mid Y) = \sum \sum P(x,y) \log_2 \frac{P(x,y)}{P(x)P(y)}$ | 수신 신호 $Y$를 관측함으로써 얻는 송신 신호 $X$에 대한 유효 정보량; 채널 용량은 $C = \max_{P(x)} I(X; Y)$ |

## Ⅲ. 정보이론 통신 시스템 아키텍처 및 섀넌의 기본 정리

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 섀넌의 디지털 통신 시스템 수학적 모델 ]            │
│                                                                        │
│   [정보원 (Source)]                                                    │
│          │ 원본 메시지 (엔트로피 H(X))                                  │
│          ▼ [1. 소스 코딩 (Source Coding)]                              │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ 섀넌 제1정리 (소스 코딩 정리): 무손실 압축의 하한선은 H(X)      │   │
│   │ - 통계적 중복성(Redundancy) 제거 -> 부호어 평균 길이 L >= H(X) │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ 압축된 비트 스트림                 │
│                                   ▼ [2. 채널 코딩 (Channel Coding)]    │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ 섀넌 제2정리 (채널 코딩 정리): R < C 이면 오류율 -> 0 달성     │   │
│   │ - 에러 검출/정정을 위한 인위적 중복성(Parity) 부가             │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ 부호화된 심볼 스트림               │
│                                   ▼                                    │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │               잡음 채널 (AWGN: 잡음 N 부가)                    │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ 수신 신호 Y                        │
│                                   ▼                                    │
│                     [ 채널 복호화 ] ──► [ 소스 복호화 ] ──► [ 수신처 ] │
└────────────────────────────────────────────────────────────────────────┘
```

| 섀넌의 핵심 정리 | 핵심 원리 | 엔지니어링 한계 및 가치 |
|---|---|---|
| **제1정리: 소스 코딩 정리** | 무손실 데이터 압축 시 심볼당 평균 부호 길이 $L$은 정보원의 엔트로피 $H(X)$보다 작을 수 없음 ($L \ge H(X)$) | 무손실 압축 알고리즘(Huffman, Deflate 등)의 궁극적 압축 한계선 제시 |
| **제2정리: 채널 코딩 정리** | 전송률 $R$이 채널 용량 $C$보다 작으면($R < C$), 적절한 부호화로 비트 오류율을 임의로 0에 수렴시킬 수 있음 | 잡음이 존재하는 물리 채널에서도 오류 없는 신뢰성 통신이 가능함을 입증 |
| **소스-채널 분리 정리** | 소스 코딩과 채널 코딩을 완전히 독립적으로 설계해도 점근적으로 최적의 종단 성능을 달성할 수 있음 | 현대 7계층 모듈러 네트워크 아키텍처의 이론적 근거 확립 |

## Ⅳ. 소스 코딩(Source Coding) vs 채널 코딩(Channel Coding) 비교

| 비교 항목 | 소스 코딩 (Source Coding) | 채널 코딩 (Channel Coding) |
|---|---|---|
| **주요 목적** | 데이터 압축을 통한 저장 공간 절약 및 전송 효율화 | 전송 채널 잡음에 대한 내성 및 비트 오류 정정 |
| **중복성 처리** | **불필요한 통계적 중복성(Redundancy)을 제거** | **의도적으로 제어용 중복성(Parity Bit)을 부가** |
| **이론적 한계선** | **정보원 엔트로피 ($L \ge H(X)$)** | **채널 용량 ($R < C$)** |
| **손실 여부** | 무손실(Huffman) 및 손실(JPEG/MP3) 압축 존재 | 오류 정정 성공 시 완벽한 무손실 원본 복원 |
| **대표 기술** | 허프만 코딩, 산술 코딩, LZW, gzip, H.265/AV1 | 해밍 부호, 리드 솔로몬, 컨볼루션, **LDPC, Polar** |

## Ⅴ. 정보이론의 공학적 한계와 극복 방안

| 한계 | 방안 |
|---|---|
| 섀넌의 소스-채널 분리 정리(Separation Theorem)는 무한한 블록 길이($n \to \infty$)와 무한한 계산 지연을 전제하므로, 5G URLLC 및 차량 통신과 같은 초저지연 단축 패킷 환경에서는 소스와 채널의 분리 설계 시 심각한 전송 실패(Cliff Effect) 발생 | 소스 압축과 채널 부호화를 하나의 심층 신경망(오토인코더)으로 통합 최적화하여 시변 무선 채널의 SNR 변화에 유연하게 대응하는 심층 결합 소스-채널 코딩(Deep JSCC) 적용 |
| 실제 음성, 영상 등 고차원 미디어 데이터는 심볼 간의 고차 상관관계로 인해 정확한 확률 밀도 함수(PDF)를 수식화하기 불가능하여 전통적 산술 부호화 시 엔트로피 한계에 도달하지 못하는 모델 불일치 손실 발생 | 데이터 기반의 생성형 인공지능(VAE, Diffusion Model)을 활용하여 데이터의 내재적 잠재 공간(Latent Space) 엔트로피를 동적으로 추정하는 인공신경망 기반 적응형 압축 기법 도입 |
| 연속 신호(아날로그 음성/영상)를 디지털로 변환할 때 정보의 손실이 불가피하게 발생하는 율-왜곡(Rate-Distortion) 한계 상존 | 왜곡 척도 $D$를 비트 전송률 $R(D)$의 함수로 정량화하고, 인간의 시각/청각 인지 한계를 반영한 인지적 왜곡 메트릭(LPIPS, SSIM) 기반 손실 압축 최적화 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
6G 이동통신 및 차세대 멀티미디어 전송 인프라 설계 시, 단순히 비트를 있는 그대로 무오류 전달하는 전통적 섀넌 패러다임(Syntactic Level)에서 탈피하여 데이터의 의미와 의도를 추출해 압축·전송하는 시맨틱 통신(Semantic Communications) 아키텍처를 도입하고, 엣지 AI 디바이스 환경에서 Deep JSCC 기반 경량화 추론 엔진 연계 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 6G 차세대 Deep JSCC 시맨틱 통신 아키텍처 ]             │
│                                                                        │
│   [멀티미디어 원천 데이터 (이미지/영상)]                               │
│          │                                                             │
│          ▼                                                             │

│   │  - 심각한 채널 잡음 환경에서도 급격한 단절(Cliff) 없는 평활 복원│   │
│   └────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 구분 | 무손실 소스 코딩 (Huffman) | 손실 소스 코딩 (H.265/JPEG) | 블록 채널 코딩 (LDPC/Polar) | 결합 소스-채널 코딩 (Deep JSCC) |
|---|---|---|---|---|
| **처리 목표** | 통계적 중복 제거 (완전 복원)| 인지적 중복 제거 (고압축비) | 비트 오류 검출 및 정정 | 의미 추출 및 무선 채널 직접 매핑 |
| **수학적 기준** | 섀넌 엔트로피 ($H(X)$) | 율-왜곡 이론 ($R(D)$) | 채널 용량 ($C$) | 시맨틱 상호정보량 ($I(S; \hat{S})$) |
| **채널 오류 민감도**| 비트 1개 오염 시 전체 붕괴 | 매크로블록 깨짐 발생 | 임계치 이하 완전 복원 | 채널 악화 시 점진적 화질 저하 (우수) |
| **적용 영역** | 텍스트 압축, 파일 시스템 | OTT 동영상 스트리밍 | 5G 물리 계층 전송 채널 | 6G 시맨틱 통신, 자율주행 V2X |
