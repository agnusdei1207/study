## 연관 키워드

- 정보이론(Information Theory), 자기 정보량(Self-Information), 섀넌 엔트로피(Shannon Entropy)
- 상호 정보량(Mutual Information), 쿨백-라이블러 발산(KL Divergence), 크로스 엔트로피(Cross-Entropy)
- 소스 부호화 정리, 채널 부호화 정리, 율-왜곡 정리
- 유한 블록장(Finite Blocklength), 시맨틱 정보이론(Semantic Information Theory), 양자화(Quantization)

## Ⅰ. 정보이론의 개요

- 핵심 요약 : 정보를 확률과 비트로 정량화해 압축과 전송의 이론적 한계를 계산 가능하게 만든 응용 수학 이론.
- 개념 : 1948년 클로드 섀넌(Claude Shannon)의 논문에서 출발해 정보의 양을 발생 확률로 재고, 데이터 압축과 신뢰성 있는 전송의 한계를 규정하는 **정보이론**(Information Theory).
- 배경 및 필요성 : 아날로그 통신은 잡음이 쌓일수록 원신호 복원이 어려워 설계가 경험에 의존했고, 압축률과 전송률을 미리 계산할 수 없어 과잉 자원 투입과 비용 예측 실패의 원인이 되었음.
- 주요 목적 : 불확실성의 정량화, 손실 없는 압축의 하한 규정, 잡음 환경에서 신뢰 전송의 조건 규정, 압축·전송·학습에 공통으로 쓰이는 척도 체계 제공.

## Ⅱ. 정보이론의 특징 및 장점

- 핵심 요약 : 확률 모델 위의 정량 척도가 시스템의 성능 한계를 설계 전에 계산하게 하여 자원 낭비를 줄이는 구조.

1. 자기 정보량 척도 : **자기 정보량**(개별 사건이 주는 정보의 양, Self-Information) I(x) = -log2 p(x) → 발생 확률이 낮은 사건일수록 정보량이 커져 관측 가치를 수치로 비교 가능.
2. 평균 불확실성 측정 : **섀넌 엔트로피**(확률변수의 평균 정보량, Shannon Entropy) H(X) → 무손실 압축에 필요한 최소 평균 비트 수를 계산해 압축 목표를 설정.
3. 전달 정보량 측정 : **상호 정보량**(한 변수의 관측으로 얻는 다른 변수의 정보, Mutual Information) I(X;Y) → 채널이 실제로 전달하는 정보의 크기를 측정해 통로 품질을 판정.
4. 분포 간 거리 측정 : **쿨백-라이블러 발산**(두 확률분포의 비대칭 차이 척도, Kullback-Leibler Divergence) → 실제 분포 대비 모델 분포의 오차를 수치화해 학습 기준으로 활용.

## Ⅲ. 정보이론의 구조 (흐름)

- 핵심 요약 : 자기 정보량에서 출발한 척도들이 엔트로피와 상호 정보량으로 연결되고, 통신계 모델의 각 단계를 세 근본 정리가 규정하는 구조.
- 소스 부호화 : 정보원의 출력을 엔트로피 한계에 가깝게 압축하는 단계.
- 채널 부호화 : 잡음 채널의 오류에 대비해 여분 정보를 덧붙이는 오류 정정 단계.
- 채널 : 신호에 잡음이 더해지는 물리적 전송 매체.

```text
[ 섀넌 통신계 모델 ]

정보원
    ↓
송신기 (소스 · 채널 부호화)
    ↓
채널 (잡음 추가)
    ↓
수신기 (복호화)
    ↓
목적지
```

```text
[ 정보 척도의 연결 ]

자기 정보량 I(x) = -log2 p(x)
    ↓ 기댓값
섀넌 엔트로피 H(X)
    ↓ 채널을 거치며 공유되는 정보
상호 정보량 I(X;Y)
    ↓ 입력 분포에 대한 최댓값
채널의 정보 전달 능력 (용량)
```

## Ⅳ. 정보이론 세 근본 정리의 비교

- 핵심 요약 : 세 정리는 압축의 하한, 전송의 상한, 왜곡 허용 시의 하한을 각각 규정하며 적용 분야와 대표 기법이 서로 다름.

| 비교 축 | 소스 부호화 정리 (무손실 압축) | 채널 부호화 정리 (신뢰 전송) | 율-왜곡 정리 (손실 압축) |
| --- | --- | --- | --- |
| 핵심 명제 | 평균 비트 수는 엔트로피 H(X) 미만이 될 수 없음 | 전송률이 채널 능력 미만이면 오류를 임의로 낮추는 부호 존재 | 허용 왜곡 D에서 최소 전송률 R(D)가 존재 |
| 기술 분야 | 데이터 압축 | 오류 정정 부호화 | 멀티미디어 압축 |
| 대표 기법 | 허프만 부호, 산술 부호, LZW(Lempel-Ziv-Welch) | 해밍 부호, 리드-솔로몬 부호, 터보·LDPC·폴라 부호 | JPEG, H.264, HEVC(High Efficiency Video Coding) |
| 한계 해석 | 엔트로피 이하 압축은 정보 손실 | 한계 초과 전송은 신뢰성 보장 불가 | 왜곡을 줄이려면 전송률 상승 필요 |

- 선택 기준 : 원본 복원이 필수면 소스 부호화 정리, 잡음 있는 경로의 신뢰성이 과제면 채널 부호화 정리, 화상·음성처럼 왜곡 허용이 가능하면 율-왜곡 정리 기준을 적용.
- 현대 AI와의 연결 : 실제 분포와 모델 예측 분포의 **크로스 엔트로피**(Cross-Entropy) 최소화가 분류 모델 학습의 표준 손실로 쓰이며, 이는 분포 간 차이 척도의 직접 응용.

## Ⅴ. 정보이론의 한계와 방안

- 핵심 요약 : 의미 배제, 무한 블록장 가정, 분포 사전 지식 의존이 이론의 한계이며 확장 이론과 추정 기법으로 일대일 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 의미 배제 | 비트 패턴과 확률만 다루어 메시지의 의미와 목적 달성도를 측정하지 못함 | 시맨틱 정보이론(Semantic Information Theory)을 결합해 의미 유사성과 과제 달성도를 평가 | 과제 달성률, 의미 유사도 |
| 무한 블록장 가정 | 블록 길이가 충분히 클 때의 결과이므로 짧은 패킷 통신에서 실제 성능이 이론치에서 벗어남 | 유한 블록장(Finite Blocklength) 보정 모델로 짧은 패킷의 전송률 산정 | 블록 길이별 오류율 |
| 분포 사전 지식 의존 | 실제 확률분포를 알아야 엔트로피 계산이 가능한데 실측 분포는 불명 | 최대 엔트로피 원리로 보수적 추정, 실측 데이터로 분포 보완 | 추정 엔트로피 편차 |

## Ⅵ. 정보이론 활용 확대를 위한 기술사적 제언

- 핵심 요약 : 모델 경량화 기준, 데이터 품질 지표, 양자 정보이론 연구로 정보이론의 적용 범위를 확장하는 것.

1. AI 플랫폼 조직은 거대 모델의 경량화·양자화 과정에 엔트로피 기반 손실 측정 기준을 파이프라인에 내장해, 압축 단계별 정보 손실을 추적하는 절차를 마련해야 한다.
2. 데이터 관리 조직은 학습 데이터의 결측·잡음·편향을 엔트로피 기반 지표로 계량하는 정제 기준을 수립해, 데이터 품질 관리를 수치화해야 한다.
3. 통신 연구기관은 양자 정보이론을 후속 이론 과제로 육성하고, 양자 키 분배(QKD, Quantum Key Distribution) 시험망에서 도청 탐지 성능을 검증하는 역량을 확보해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 정보이론은 불확실성을 비트로 재어 압축·전송·학습의 성능 한계를 계산 가능하게 만든 기반 이론.
- 압축, 전송, 모델 학습이 엔트로피와 분포 간 차이라는 같은 척도 위에서 비교되므로, 이 척도의 이해가 새 기술의 한계 판단 출발점.
