## 30초 인출

- 본질: '정보'라는 추상적 개념을 수치화하지 못해 전송 효율과 오류 방지를 과학적으로 설계하지 못했던 한계
- 메커니즘: 사건의 발생 확률을 로그 역수로 변환하여 정보량(비트)과 엔트로피로 정량화하고 데이터 압축과 잡음 통신의 이론적 한계선을 수학적으로 도출

## 핵심 용어

- 자기 정보량($I(x) = -\log_2 P(x)$): 어떤 사건이 일어났을 때 얻는 정보의 크기. '내일 해가 동쪽에서 뜬다'처럼 일어날 확률이 1인 사건은 정보량이 0이며, 일어날 확률이 희박한 사건일수록 정보량이 큼
- 정보 엔트로피($H(X)$): 확률 변수가 가진 평균적인 정보량 또는 불확실성의 크기. 모든 사건의 일어날 확률이 균등할 때(동전의 앞뒤가 0.5일 때) 엔트로피가 최댓값(1비트)을 가짐
- 소스 코딩 정리(Shannon's Source Coding Theorem): 무손실 압축으로 줄일 수 있는 심볼당 평균 비트 수($L$)는 해당 정보원의 엔트로피($H(X)$)보다 작아질 수 없다는 압축의 절대 하한선($L \ge H(X)$)

## 1교시 10점 답안

### 정의·목적

- 정의: 정보이론은/는 사건의 발생 확률을 로그 역수로 변환하여 정보량(비트)과 엔트로피로 정량화하고 데이터 압축과 잡음 통신의 이론적 한계선을 수학적으로 도출 방식이다.
- 목적: 컴퓨터 과학과 디지털 통신의 수학적 기초 확립에 기여한다.

### 핵심 구조와 작동

```text
[ 정보이론의 핵심 척도 관계 벤 다이어그램 ]

+-------------------------+-------------------------+
|     H(X) : 송신 엔트로피 |      H(Y) : 수신 엔트로피|
|                         |                         |
|        H(X|Y)           |  I(X;Y)  |    H(Y|X)    |
|       조건부            |   상호   |    조건부    |
|      엔트로피           |  정보량  |   엔트로피   |
|     (유실 정보)         | (전송량) |  (잡음/오류) |
+-------------------------+----------+--------------+
|<----------------- 결합 엔트로피 H(X,Y) ----------->|

* 핵심 수식 :
  1. 자기 정보량 : I(x) = -log_2 P(x)   (확률 낮을수록 정보량 큼)
  2. 평균 엔트로피 : H(X) = - Σ P(x) * log_2 P(x)  (불확실성의 크기)
  3. 상호 정보량 : I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)
```

### Ⅱ. 핵심 특성

- 정보는 '새로움(Surprise)'의 측정치: 이미 알고 있는 뻔한 데이터는 정보를 전달하지 않으며, 오직 불확실했던 상태가 해소되는 정도만이 진정한 정보(비트)로 가치를 인정받음
- 상호 배타적인 두 가지 부호화의 조화: 소스 코딩(압축)은 전송 효율을 위해 데이터 내부의 쓸데없는 중복(Redundancy)을 최대한 쥐어짜내는 작업이고, 채널 코딩(에러 제어)은 잡음에 버티기 위해 계산된 중복 비트(패리티, FEC)를 고의로 덧붙이는 작업임
- 현대 딥러닝 인공지능의 손실 함수(Loss Function)의 뿌리: 분류 모델에서 사용하는 교차 엔트로피(Cross Entropy)와 잠재 공간 분포를 맞추는 KL 발산(Kullback-Leibler Divergence)이 모두 정보이론의 정보량 차이 계산식에서 직접 파생됨

### Ⅲ. 관련 개념과 구분

- 엔트로피(열역학) vs 정보 엔트로피: 열역학 엔트로피는 물리 계의 분자 무질서도를 측정 / 정보 엔트로피는 통계적 확률 변수의 불확실성 및 정보 표현에 필요한 최소 평균 비트 수를 측정

### Ⅳ. 적용 문제와 대응

- 적용 상황: 대규모 텍스트/로그 데이터의 네트워크 전송 대역폭 절감
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 반복적인 로그 패턴으로 인한 대역폭 낭비 | 문자 빈도 불균형에도 불구하고 고정 8비트(ASCII) 전송 | 허프만 코딩(Huffman Coding) 및 Zstandard 엔트로피 압축 적용 | 고빈도 문자에 짧은 비트를 부여하여 엔트로피 한계까지 60% 압축 |
| 전송 채널 잡음으로 인한 비트 반전 오류 | 채널 코딩 없이 소스 코딩(압축)된 데이터 전송 시 1비트 에러가 전체 파일 오염 | 채널 용량($C$) 이내에서 해밍/리드솔로몬/LDPC 에러 정정 부호 결합 | 재전송 없이 수신단에서 역 연산으로 비트 오류 100% 자체 복구 |
