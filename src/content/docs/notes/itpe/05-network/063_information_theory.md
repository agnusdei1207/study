## 연관 키워드

- 정보이론(Information Theory), 섀넌 엔트로피(Shannon Entropy), 자기 정보량(Self-Information)
- 상호 정보량(Mutual Information), 쿨백-라이블러 발산(KL Divergence), 채널 용량(Channel Capacity)
- 소스 부호화 정리, 채널 부호화 정리, 율-왜곡 정리, 크로스 엔트로피(Cross-Entropy)
- 유한 블록장(Finite Blocklength), 시맨틱 정보이론(Semantic Information Theory), 양자화(Quantization)

## Ⅰ. 정보이론의 개요

- 핵심 요약 : 정보를 확률과 비트로 정량화하여 압축과 전송의 이론적 한계를 계산 가능하게 만든 응용 수학 이론.
- 개념 : 1948년 클로드 섀넌(Claude Shannon)의 논문에서 출발하여, 정보의 양을 확률로 재고 데이터 압축과 신뢰성 있는 전송의 한계를 규명하는 이론 (**정보이론**, Information Theory).
- 배경 및 필요성 : 아날로그 통신은 잡음이 쌓일수록 원신호 복원이 어려워 설계가 경험에 의존했고, 그 결과 과잉 대역 사용과 재전송 비용을 미리 예측하기 어려웠다. 정보를 비트 단위로 환원하면 잡음 환경에서 달성 가능한 압축률과 전송률의 상한을 수식으로 계산할 수 있어, 이 비용을 설계 단계에서 줄일 수 있게 되었다.
- 주요 목적 : 불확실성의 정량화, 손실 없는 압축의 한계 규명, 잡음 환경의 채널 용량 산출, 그리고 머신러닝 손실 함수의 수학적 기반 제공.

## Ⅱ. 정보이론의 특징 및 장점

- 핵심 요약 : 확률 모델 위의 정량 척도가 시스템의 성능 한계를 설계 전에 계산하게 하여 자원 낭비를 줄이는 구조.

1. 정량 척도 : 사건이 주는 정보량을 로그 확률의 음수로 정의 → 희귀한 사건일수록 정보량이 커져 관측 가치를 수치로 비교 가능.
2. 불확실성 측정 : **섀넌 엔트로피** (Shannon Entropy, 확률변수의 평균 정보량) → 표현에 필요한 최소 평균 비트 수를 계산해 압축 목표를 설정.
3. 채널 한계 산출 : **채널 용량** (Channel Capacity, 오류 확률을 임의로 낮출 수 있는 최대 전송률) → 목표 전송률이 채널 한계를 넘는지 사전에 판정.
4. 분포 간 차이 측정 : **쿨백-라이블러 발산** (KL Divergence, 두 확률분포의 차이를 재는 비대칭 척도) → 모델 예측 분포와 실제 분포의 차이를 줄이는 학습 기준으로 활용.

## Ⅲ. 정보이론의 구조 (흐름)

- 핵심 요약 : 자기 정보량에서 시작한 세 가지 척도가 채널 용량까지 이어지고, 이를 바탕으로 세 가지 근본 정리가 성립하는 구조.
- 자기 정보량 I(x) = -log2 p(x) : 사건 x가 주는 놀람의 정도이며, 발생 확률이 낮을수록 값이 커진다.
- 상호 정보량 I(X;Y) : 수신 신호 Y를 관측해 송신 신호 X에 대해 얻는 정보량이며, 채널 용량 C는 입력 분포에 대한 이 값의 최댓값으로 정의된다.

```text
[ 정보 척도의 연결 ]

자기 정보량 I(x) = -log2 p(x)
   ↓ 기댓값
섀넌 엔트로피 H(X)
   ↓ 잡음 채널을 거치며 공유되는 정보
상호 정보량 I(X;Y)
   ↓ 입력 분포에 대한 최댓값
채널 용량 C
```

```text
[ 3대 근본 정리의 흐름 ]

무손실 압축 : 평균 비트 수 ≥ H(X)
   ↓ 잡음이 있는 채널로 확장
신뢰성 전송 : 전송률 R < C 이면
  오류 확률을 임의로 낮춘 부호 존재
   ↓ 왜곡을 허용하는 경우로 확장
손실 압축 : 허용 왜곡 D에서 최소 전송률 R(D)
```

## Ⅳ. 정보이론의 세 근본 정리 비교

- 핵심 요약 : 세 정리는 압축의 하한, 전송의 상한, 왜곡 허용 시의 하한을 각각 정하며, 적용 분야와 대표 기법이 서로 다르다.

| 비교 축 | 소스 부호화 정리 (무손실 압축) | 채널 부호화 정리 (신뢰성 전송) | 율-왜곡 정리 (손실 압축) |
| --- | --- | --- | --- |
| 핵심 명제 | 평균 비트 수는 H(X) 미만이 될 수 없음 | R < C 이면 오류 확률을 임의로 작게 만드는 부호 존재 | 허용 왜곡 D에서 최소 전송률 R(D)가 존재 |
| 기술 분야 | 데이터 압축 | 오류 정정 부호화 (FEC, Forward Error Correction) | 멀티미디어 압축 |
| 대표 기법 | 허프만 부호, 산술 부호, LZW (Lempel-Ziv-Welch), DEFLATE | 해밍 부호, 리드-솔로몬 부호, 터보 부호, LDPC (Low-Density Parity-Check), 폴라 부호 | JPEG (DCT, Discrete Cosine Transform 기반), H.264, HEVC (High Efficiency Video Coding), AV1, AAC (Advanced Audio Coding) |

- 현대 AI와의 연결 : 실제 분포 P와 모델 예측 분포 Q 사이의 **크로스 엔트로피** (Cross-Entropy, 두 분포의 엔트로피 합으로 정의되는 손실)는 분류 모델 학습의 표준 손실 함수로 쓰인다.
- 선택 기준 : 원본 복원이 필수인지, 잡음이 있는 전송 경로인지, 왜곡을 허용할 수 있는지에 따라 세 정리 중 적용할 기준을 고른다.

## Ⅴ. 정보이론의 한계와 방안

- 핵심 요약 : 의미 무시와 무한 블록 길이 가정이 핵심 한계이며, 의미 기반 확장과 유한 블록장 이론으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 의미(Semantics) 배제 | 샤논 이론은 비트 패턴과 확률 분포만 다루어 메시지의 의미와 목적 달성도를 측정하지 못함 | 시맨틱 정보이론(Semantic Information Theory)을 결합해 의미 유사성과 과제 달성도를 엔트로피와 함께 평가 | 과제 달성률, 의미 유사도 |
| 무한 블록 길이 가정 | 채널 부호화 정리는 블록 길이가 커질 때의 결과이므로, 짧은 패킷의 URLLC(Ultra-Reliable Low-Latency Communications) 환경에서는 실제 성능이 용량에서 벗어남 | 유한 블록장 정보이론(Finite Blocklength Information Theory)으로 짧은 패킷의 부호율을 보정 | 블록 길이별 오류율, 지연 시간 |

## Ⅵ. 정보이론 적용 및 발전을 위한 기술사적 제언

- 핵심 요약 : 정보 척도를 모델 압축, 데이터 품질 관리, 양자 통신 검증으로 확장하는 실행 방향.

1. 거대 언어 모델의 가중치 양자화에 정보이론 기준을 적용한다. 4비트 이하로 줄일 때 엔트로피 손실을 측정하는 기준을 학습 파이프라인에 넣어 정확도 저하를 추적해야 한다.
2. 데이터 조직은 고객 데이터의 결측치, 잡음, 편향을 엔트로피 기반 지표로 계량하여 AI 학습 데이터의 정제 기준으로 삼는 것이 바람직하다.
3. 연구 조직은 양자 정보이론을 장기 과제로 두고, 양자 키 분배(QKD, Quantum Key Distribution) 시험망에서 도청 탐지 성능을 검증해 차세대 보안 통신 역량을 확보해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 정보이론은 불확실성을 비트로 재어 통신과 AI의 성능 한계를 계산 가능하게 만든 기반 이론.
- 시사점 : 압축, 전송, 학습 설계가 모두 엔트로피와 채널 용량이라는 같은 척도 위에서 비교되므로, 이 척도를 이해하는 것이 새 기술의 한계를 판단하는 출발점이 된다.
