## Ⅰ. 해저케이블(Submarine Cable)의 개요

- **개념** : 대륙과 대륙, 국가와 국가 간의 대용량 국제 데이터 및 음성 트래픽을 광속으로 전송하기 위해 해저 바닥에 포설된 고강도 광섬유 케이블 기반의 글로벌 물리적 전송 인프라.
- **배경 및 필요성** : 전 세계 대륙 간 인터넷 트래픽의 대부분이 해저케이블을 통해 전송되고 있으며, 인공위성 통신 대비 막대한 대역폭, 초저지연, 경제성을 제공하므로 국가 디지털 경제의 핵심 생명선.
- **핵심 목적** : 대륙 간 테라비트(Tbps)~페타비트(Pbps)급 초광대역 데이터 전송, 글로벌 클라우드 데이터센터 간 동기화, 국가 간 디지털 주권 및 백본 통신망의 다중화 생존성 확보.

## Ⅱ. 해저케이블 시스템의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 해저케이블 시스템 전송 및 구성 아키텍처 ]           │
│                                                                        │
│   [ 육상 설비 (Dry Plant) ]                                            │
│   - 케이블 양륙국 (CLS: Cable Landing Station)                         │
│   - SLTE (Submarine Line Terminating Equipment) : DWDM 광전송 단말     │
│   - PFE (Power Feeding Equipment) : 해저 중계기용 수만 볼트 직류 전원 급전│
│                             │                                          │
│   [ 해양 설비 (Wet Plant) ] ▼ 해안선 통과                              │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ 천해부 (Shallow Water) : 이중 외장(Double Armor) 강철 와이어 보호│   │
│   │ (어선 트롤 어망, 닻 긁힘 방지를 위해 해저 1~3m 매설 포설)      │   │
│   └────────────────────────┬───────────────────────────────────────┘   │
│                            ▼ 심해 진입 (수심 수천 미터)                │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ 심해부 (Deep Sea) : 경량 무외장(Lightweight) 케이블            │   │
│   │ (수압 견디는 강철선 + 구리 튜브 + 절연 폴리에틸렌 + 중심 광섬유)│   │
│   └────────────────────────┬───────────────────────────────────────┘   │
│                            │                                           │
│   - 해저 광중계기 (Repeater / EDFA) : 매 50~100km마다 광신호 전광 증폭 │
│   - 분기 장치 (BU: Branching Unit) : 주 해저 간선에서 특정 국가로 분기│
└────────────────────────────────────────────────────────────────────────┘
```

- **육상 설비 (Dry Plant)** : 케이블 양륙국(CLS)에 위치하며, 테라급 파장분할다중화(DWDM) 단말 장비(SLTE)와 해저 중계기에 수천~수만 볼트(10~15kV)의 정전류 DC를 공급하는 PFE(Power Feeding Equipment)로 구성.
- **해양 설비 (Wet Plant)** : 해저 바닥에 침설되는 광케이블, 50~100km 간격으로 광신호를 감쇠 없이 증폭하는 에르븀 첨가 광섬유 증폭기(EDFA) 해저 중계기, 케이블을 다방향으로 분기하는 해저 분기장치(BU).
- **공간분할다중화 (SDM: Space Division Multiplexing)** : 단일 케이블 내에 수십 쌍(16~24 코어 페어) 이상의 다심 광섬유를 집적하고, 개별 광섬유의 펌프 파워를 최적화하여 케이블당 페타비트(Pbps) 전송 용량 구현.

## Ⅲ. 해저케이블 보호 구조 및 위성 통신과의 비교 분석

| 비교 항목 | 해저케이블 (Submarine Cable) | 위성 통신 (LEO / GEO Satellite) |
|---|---|---|
| **트래픽 분담률** | 전 세계 국제 트래픽의 **대부분** | 국제 트래픽의 일부 (오지, 해양 한정) |
| **전송 용량** | 수십 ~ 수백 Tbps (케이블당 대용량) | 수백 Gbps ~ 수 Tbps (위성군 전체) |
| **전송 지연 (RTT)**| 최소 지연 (빛의 해저 광섬유 전파 속도) | LEO는 유사하나, GEO는 500ms 이상 지연 |
| **단위 대역폭 비용**| 극도로 저렴 (규모의 경제) | 상대적 고비용 (발사 비용, 수명 5~10년) |
| **물리적 위협 요인**| 선박 닻(Anchor), 트롤 어업, 해저 지진, 절단 | 우주 방사선, 대기 감쇠, 우주 쓰레기 충돌 |
| **수리 및 유지보수**| 전용 해저케이블 작업선 투입 (수주일 소요) | 궤도 상 물리 수리 불가 (위성 교체 필요) |

- **물리적 외장 등급** :
  - **Double Armored (DA)** : 항만, 어로 구역, 얕은 수심용 (극강도 강철선 2중 권선).
  - **Single Armored (SA)** : 수심 500m~1500m 암초 구역용.
  - **Lightweight (LW)** : 수심 1,500m 이상 심해 평원용 (외부 위협이 없어 수압만 견디는 경량 구조).

## Ⅳ. 해저케이블의 주요 한계점 및 복원력 해결 방안

- **선박 닻 투하 및 해저 지진에 의한 케이블 물리적 절단 (Cut)** :
  - **한계점** : 대만 해협 지진, 홍해 분쟁, 어선 닻 끌림 등으로 일시에 다수 케이블이 동시 절단되면 대륙 간 통신 블랙아웃 발생.
  - **해결 방안** : 완전 분산 메시(Mesh) 토폴로지 구축, 다중 경로(태평양 횡단, 인도양-유럽, 북극해 항로) 다변화 및 50ms 광 자동 복구 스위칭(ASON/WSS) 적용.
- **국제 분쟁 시 물리적 사보타주 및 감청 보안 위협** :
  - **한계점** : 심해 공작 잠수정이나 원격 무인잠수정(UUV)을 이용한 고의적 케이블 절단 및 비침투식 광섬유 굽힘 감청(Optical Tapping) 리스크.
  - **해결 방안** : 양륙국 및 SLTE 단에서 L1 광 전송 계층 전송 암호화(OTN Encryption) 의무화 및 음향 센서 기반 해저 침입 탐지 시스템 구축.

## Ⅴ. 해저케이블 적용 및 발전을 위한 기술사적 제언

- **북극해 해저케이블 루트 개척을 통한 초저지연 허브 도약** : 기후 변화로 해빙된 북극해를 통과하여 아시아와 유럽을 최단 거리로 연결하는 북극 항로 해저케이블 사업에 국가 차원의 전략적 참여 및 지연시간 30% 단축.
- **해저케이블 환경 감시 센서 네트워크화 (SMART Cable)** : 단순 통신 케이블을 넘어 중계기 내에 해저 지진계, 수온계, 쓰나미 압력 센서를 내장하여 조기 재난 경보 인프라로 융합 활용.
- **국내 해저 양륙국(CLS)의 지리적 다변화 및 국가 핵심기반시설 지정** : 부산·거제 등 특정 지역에 편중된 해저케이블 양륙 거점을 서해안과 동해안으로 분산 배치하여 전시 및 재난 시 단일 거점 피격 리스크 원천 분산.
