- **해저케이블(Submarine Cable):** 해저 광섬유와 관련 설비로 국제 통신 구간을 연결하는 케이블 시스템
- **육양국(Cable Landing Station):** 해저 케이블을 육상 통신망과 접속하는 시설
- **해저 중계기(Submarine Repeater):** 장거리 광전송에서 신호를 증폭하는 해저 설비
- **분기 유닛(Branching Unit):** 해저 간선과 분기 구간의 광섬유를 연결해 트래픽 경로를 분기하는 장치
- **SDM(Space-Division Multiplexing):** 공간적으로 분리된 광섬유 경로를 병렬 활용하는 다중화 방식

## Ⅱ. 전송 구성

```text
육양국 A
   ↓ 육상망의 광신호 접속
해저 광섬유 ── 중계기·분기 유닛(필요 구간)
   ↓ 광신호 전송
육양국 B
   ↓
상대 지역의 지상망
```

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **해저케이블(Submarine Cable)** 은 해저 광섬유와 관련 설비로 육양국 간 국제 통신을 제공하는 전송 시스템 |
| 목적 | 대륙·도서 지역 통신망의 대용량 국제 연결 |

## Ⅱ. 시스템 구성과 데이터 경로

```text
발신 지상망
    ↓
육양국 종단 장치
    ↓ 전기·광 인터페이스
해저 광섬유 ── 광증폭 중계기 ── 분기 유닛 ── 해저 광섬유
    ↓
수신 육양국 종단 장치
    ↓
수신 지상망
```

| 구성 | 역할 |
|---|---|
| 육양국 종단 장치 | 육상망과 해저 광전송 시스템의 인터페이스 |
| 광섬유 케이블 | 해저 구간의 광신호 전달 |
| 중계기 | 장거리 전송의 광 신호 증폭 |
| 분기 유닛 | 간선에서 분기 구간으로 광섬유 경로 연결 |
| 전력 공급 장치 | 설계에 따른 해저 중계기·분기 설비의 원격 전력 공급 |

## Ⅲ. 광전송·분기 구조

```text
육양국 A ── 광섬유 간선 ── 분기 유닛 ── 광섬유 간선 ── 육양국 B
                                  │
                                  └─ 분기 구간 ── 육양국 C
```

| 전송 관점 | 설명 |
|---|---|
| 광 증폭 | 광증폭기를 사용하는 시스템은 장거리 구간 신호 감쇠를 보상 |
| 파장 다중화 | 한 광섬유에 여러 파장 채널을 실어 전송 용량 확대 |
| **SDM(Space-Division Multiplexing)** | 공간적으로 분리한 광섬유 경로를 병렬 활용하는 방식; 구체적 케이블 구성은 시스템별 설계 사항 |

| 프로젝트 사례 | 경로 |
|---|---|
| Equiano | Google 발표 기준 포르투갈에서 아프리카 서해안을 따라 남아프리카공화국으로 연결하는 해저 케이블; 토고·나이지리아·나미비아·세인트헬레나 등의 육양 지점 포함 |

## Ⅳ. 장애 요인과 복원 대책

| 한계 | 대응 |
|---|---|
| 어업·선박 활동이나 해저 지진 등으로 물리적 단선 가능 | 해저 경로 조사·보호 설계, 장애 신고·수리 절차와 예비 부품 운영 |
| 한 케이블·육양국에 국제 트래픽 집중 | 서로 다른 경로·육양국을 이용하는 다중 케이블과 육상 백홀 구성 |
| 케이블 수리 중 우회 용량 부족 | 통신사업자 간 용량 계약과 우회 경로의 전환 시험 |
| 경로 다양성이 지도상에서만 확보되고 공통 장애 지점이 남음 | 해저 구간·육양국·육상 백홀의 공통 위험 구간을 함께 확인 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 케이블을 여러 개 계약해도 해안 진입부·육양국·지상 백홀을 공유하면 실제 장애 독립성이 낮음 | 국제 경로 설계 때 해저 노선뿐 아니라 육양국과 육상 전송망까지 종단 간 다양성을 우선 확인하고 공통 구간을 분리 |
