## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 차세대 이동통신 → 지상망·비지상망 연동

## 30초 인출

- 본질: **6G·위성통신 융합** 은 지상 이동통신과 위성 등 비지상망의 연동으로 서비스 연결 범위를 확장하려는 차세대 네트워크 방향
- 메커니즘: 단말 → 위성 무선 구간 → 위성 게이트웨이 또는 위성 간 링크 → 지상 코어망·서비스
- 통찰: 지상 2차원 셀룰러망의 물리적 한계를 넘어 저궤도(LEO) 위성군을 지상 6G 기지국 및 코어망과 단일 통신 프로토콜로 유기 결합하여 전 지구 100% 초공간 입체 통신을 완성하는 기술임.

<details>
<summary>핵심 용어</summary>

- **NTN (Non-Terrestrial Network)** : 위성·고고도 플랫폼 등 비지상 노드를 포함하는 통신망 구성.
- **LEO (Low Earth Orbit)** : 지구 저궤도 위성 운용 영역. 이동에 따른 핸드오버와 도플러 영향 고려.
- **서비스 링크 (Service Link)** : 사용자 단말과 위성 사이의 무선 링크.
- **피더 링크 (Feeder Link)** : 위성과 지상 게이트웨이 사이의 통신 링크.
- **ISL (Inter-Satellite Link)** : 위성 간 트래픽 전달에 사용하는 링크.
- **위성 직접 단말 연결 (Direct-to-Device, D2D)** : 사용자 단말이 위성과 직접 연결되는 서비스 방식. 지원 대역·단말·사업자 조건에 의존.
- **투명 페이로드 (Transparent Payload)** : 위성에서 무선 신호를 주로 변환·중계하고 기지국 기능을 지상에 두는 구성.
- **재생 페이로드 (Regenerative Payload)** : 위성 탑재체에서 일부 기지국·패킷 처리 기능을 수행하는 구성.

</details>

## 2~4교시 25점 답안

## Ⅰ. 6G와 위성 융합의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 지상의 6G 초광대역 셀룰러 네트워크와 수백~수천 기의 저궤도(LEO) 군집 위성망을 표준 3GPP 단일 인터페이스로 융합하여 3차원 공간 전역에 연속적인 통신 서비스를 제공하는 기술 |
| 목적 | 해양, 항공, 사막, 극지 등 지상망 미도달 음영 해소, 지진 등 대형 재난 시 통신 백업 및 UAM·원양 자율선박의 글로벌 연속 관제 지원 |

## Ⅱ. 6G와 위성 융합의 특징

| 특징 | 상세 내용 |
|---|---|
| 단일 코어망 통합 | 지상망 가입자와 위성망 가입자를 단일 6G 코어(6GC)에서 통합 인증, 이동성 관리 및 세션 제어 |
| 위성간 레이저 링크(ISL)| 지상 기지국 경유 없이 우주 궤도 상에서 레이저(Optical ISL)로 위성 간 테라비트급 패킷 라우팅 |
| 지상 단말 직접 연결 | 전용 대형 안테나 없이 일반 상용 스마트폰으로 저궤도 위성 신호를 직접 송수신(Direct-to-Cell) |
| 다계층 입체 핸드오버| 고속 비행하는 위성 빔 간 핸드오버와 지상-위성 이종 계층 간 끊김 없는 수직 핸드오버(VHO) 지원 |

## Ⅲ. 6G와 위성 융합의 체계·프로세스

**6G 지상-위성 3차원 통합 네트워크 아키텍처**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 6G 위성-지상 통합망 구조 ]                    │
│                                                                        │
│   우주 계층: [ LEO 위성군 ] ◄── Optical ISL (레이저 링크) ──► [ LEO 위성 ] │
│                   │                                         │          │
│                   ▼ Service Link (3GPP NTN)                 ▼          │
│   공중 계층: [ HAPS / 드론 릴레이 ]                                    │
│                   │                                                    │
│                   ▼                                                    │
│   지상 계층: [ 6G 단말 (차량, 스마트폰, 선박) ]                        │
│                   ▲                                                    │
│                   │ 6G Terrestrial Uu                                  │
│              [ 지상 기지국 (gNodeB) ] ──► [ 통합 6G 코어망 (6GC) ]     │
│                                                    ▲                   │
│              [ 지상 위성 게이트웨이 ] ─────────────┘ Feeder Link       │
└────────────────────────────────────────────────────────────────────────┘
```

| 네트워크 계층 | 주요 인프라 플랫폼 | 고도 범위 | 주요 역할 및 서비스 특성 |
|---|---|---|---|
| **우주 계층** | LEO 저궤도 군집 위성 | 500 ~ 1,500 km | 전 지구 광역 커버리지, 원거리 글로벌 백홀 라우팅 |
| **공중 계층** | HAPS (성층권 비행선/드론) | 18 ~ 25 km (성층권) | 도심 상공 저지연(수 ms) 통신, 재난 지역 국지적 집중 지원 |
| **지상 계층** | 6G 매크로셀, 스몰셀 기지국 | 지표면 ~ 고도 100m | 도심 밀집지 1Tbps급 초고속, 0.1ms 극저지연 데이터 전송 |

## Ⅳ. 6G와 위성 융합의 종류·비교

| 비교 항목 | 기존 분리형 위성 통신 | 6G 위성-지상 융합망 |
|---|---|---|
| **통신 규격** | 독자 위성 독점 규격 (DVB-S2 등) | **3GPP 표준 단일 프로토콜 스택** |
| **단말기 요구 조건**| 별도 위성 전용 단말 및 위성 전화기 필요 | **일반 상용 6G 스마트폰 직접 연결** |
| **코어망 구조** | 지상망과 위성망 코어가 완전 분리 | **단일 6G 통합 코어 (AMF/SMF 공유)** |
| **전파 지연 (RTT)** | 정지궤도(GEO) 기준 약 500 ms | **저궤도(LEO) 기준 20 ~ 40 ms 수준** |
| **핸드오버 방식** | 망 간 연동 불가 (통화 단절) | **지상-위성 간 끊김 없는 무중단 수직 핸드오버**|

## Ⅴ. 6G와 위성 융합의 한계와 방안

| 한계 | 방안 |
|---|---|
| 저궤도 위성의 초고속 공전(약 7.5km/s)으로 2분마다 위성 빔이 바뀌어 발생하는 빔 스위칭 폭증 및 호 절단 | 위성 궤도력(Ephemeris) 기반의 위치 예측형 조건부 핸드오버(CHO) 및 지구 고정형(Earth-Fixed) 스마트 빔포밍 적용 |
| 지상-위성 간 긴 전파 왕복 지연차로 인해 TCP 패킷 재정렬 버퍼 오버플로 및 처리율 급감 발생 | 세션 관리 계층 다중 경로 전송 제어(MPTCP, QUIC) 및 패킷 시퀀스 예측 기반 패킷 가속 프록시(PEP) 결합 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
6G 위성 융합망 서비스 설계 시, 도심지에서는 지상 기지국을 기본망으로 설정하고 위성 링크는 대기 상태(Standby)로 유지하다가 지상 신호 단절 감지 시 100ms 내 즉각 전환되는 정책 기반 이종망 스티어링(Policy-based Traffic Steering)을 필수 구성.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ LEO 위성의 빠른 이동에 대응하는 조건부 핸드오버 (CHO) ]              │
│                                                                        │
│ 1. 기지국(위성)이 단말에 사전 핸드오버 실행 조건(CHO Config) 전달       │
│ 2. 단말이 내장 GNSS로 이동 경로 감시하며 목표 위성 도달 시간 예측      │
│ 3. 조건 만족 즉시 네트워크 질의 없이 단말 주도로 목표 위성에 즉각 접속│
│                                                                        │
│   위성 A (이탈 중) ──────────► [ 단말 (CHO 조건 달성) ] ────────► 위성 B│
│   (신호 급감)                       │ (0ms 즉시 스위칭)          (진입 중)│
│                                     ▼                                  │
│   (시그널링 지연 없는 무중단 세션 보존 성공)                           │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 융합 구현 모델 | 위성 탑재체 기능 | 지연 시간 | 구현 복잡도 |
|---|---|---|---|
| **투명 모드 (Transparent)** | 단순 RF 주파수 변환 중계 | 2홉 지연 (지상국 필수 경유) | 낮음 (선제 상용화) |
| **재생 모드 (Regenerative)**| 온보드 6G gNodeB 기지국 탑재 | 1홉 지연 (우주 직접 복호) | 높음 (위성 내 방사선 차폐 NPU 필요) |
| **위성 라우터 모드 (ISL)** | 위성 간 레이저 스위칭 내장 | 최저 (지상 백홀 불필요) | 최상 (우주 패킷 라우팅망 구축) |
