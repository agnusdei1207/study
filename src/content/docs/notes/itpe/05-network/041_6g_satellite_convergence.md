## Ⅰ. 6G·위성통신 융합의 개요

- **개념** : 지상 이동통신 기지국망과 저궤도(LEO)·중궤도(MEO)·정지궤도(GEO) 위성 및 고고도 플랫폼(HAPS)을 단일 표준 프로토콜로 통합하여 지구 전역과 공중·우주를 연결하는 3차원 비지상 네트워크(3D NTN).
- **배경 및 필요성** : 전 세계 지표면의 약 70% 이상을 차지하는 해양, 사막, 산악 및 공중 구간은 지상 기지국 설치가 불가능하여 음영 지역으로 잔존하며, UAM과 해상 물류의 초연결 요구 증가.
- **핵심 목적** : 지구 표면 전역 무음영 커버리지 실현, 자연재해 발생 시 지상망 단절에 대한 완벽한 생존성 확보 및 항공·해상·우주 모빌리티 간 단절 없는 통신 세션 유지.

## Ⅱ. 6G·위성통신 융합의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 6G-위성 통합 3차원 다계층 네트워크 토폴로지 ]           │
│                                                                        │
│   [ 우주 계층 (Space) ]                                                │
│   GEO (36,000km) ── 정지궤도 광역 방송 / 백홀 지원                    │
│         ▲                                                              │
│         │ 레이저 위성간 링크 (Optical ISL)                             │
│         ▼                                                              │
│   LEO (300~1,500km) ─ 저궤도 위성 군집 (gNB 탑재 재생 페이로드)       │
│         ▲                                                              │
│         │ NTN 무선 링크 (Feeder / Service Link)                        │
│         ▼                                                              │
│   [ 공중 계층 (Air) ]                                                  │
│   HAPS / 드론 (10~50km 성층권) ── 성층권 통신 플랫폼 (도심 보조)      │
│         ▲                                                              │
│         ▼                                                              │
│   [ 지상 계층 (Ground) ]                                               │
│   UE (스마트폰/단말) ────── 지상 6G 기지국 ────── 위성 게이트웨이      │
│     (직접 위성 통신 D2D)     (Cellular RAN)      (Ground Station)      │
└────────────────────────────────────────────────────────────────────────┘
```

- **직접 단말 연결 (Direct-to-Cell / D2D)** : 별도의 대형 위성 안테나 없이 일반 스마트폰의 표준 안테나와 모뎀으로 LEO 위성과 직접 송수신.
- **위성 탑재형 기지국 (Regenerative Payload)** : 위성 자체에 5G/6G gNodeB 및 UPF 기능을 탑재하여 지상 게이트웨이를 거치지 않고 위성 간 레이저 통신(ISL)으로 우주 공간 패킷 라우팅 수행.
- **투명형 중계 방식 (Transparent / Bent-Pipe)** : 위성이 단순 주파수 변환 및 증폭만 수행하고 지상 기지국 및 코어망으로 신호를 즉시 바이패스.

## Ⅲ. 6G·위성통신 융합의 세부 구성 요소 및 위성 궤도별 특성 비교 분석

| 궤도 구분 | 고도 | 편도 지연 시간 | 장점 | 단점 및 과제 |
|---|---|---|---|---|
| **저궤도 (LEO)** | 300 ~ 1,500 km | 낮음 | 지연 시간 최소화, 경로 손실 적음, 단말 직접 통신 용이 | 초고속 공전(90분 주기), 빈번한 핸드오버, 수천 기 군집 필요 |
| **중궤도 (MEO)** | 2,000 ~ 20,000 km | 50 ~ 100 ms | LEO 대비 넓은 커버리지, 적은 위성 수로 전 지구 커버 | GPS/항법 위성 주력, 통신용 지연 다소 큼 |
| **정지궤도 (GEO)** | 35,786 km | 수백 ms 수준 (RTT) | 위성 3기로 전 지구 커버 가능, 지상 안테나 지향 용이 | 막대한 지연 시간, 극지방 커버리지 제한, 단말 대형화 필수 |
| **성층권 (HAPS)** | 18 ~ 25 km | < 1 ms | 초저지연, 특정 지역 장기 체공, 기상 영향 적음 | 태양광/수소 플랫폼 체공 한계, 국지적 커버리지 |

- **광 위성간 링크 (Inter-Satellite Optical Link: O-ISL)** : 위성 간 레이저 빔을 이용해 고속 대역폭으로 우주 백본망 구축.
- **도플러 보상 엔진** : 초속 7.5km로 이동하는 LEO 위성으로 인한 수십 kHz 주파수 편이를 위성 궤도력(Ephemeris) 기반으로 실시간 계산·보정.
- **공통 코어망 (Unified 5GC/6GC)** : 지상 기지국과 위성 기지국을 단일 AMF/SMF로 제어하여 이기종 망 간 seamless 무손실 세션 이동 보장.

## Ⅳ. 6G·위성통신 융합의 주요 한계점 및 해결 방안

- **초고속 궤도 이동에 따른 빈번한 빔/위성 간 핸드오버 실패** :
  - **한계점** : 단말 상공을 수 분 내로 통과하는 LEO 특성으로 인해 위성 간 핸드오버가 수 분 단위로 발생, 제어 시그널링 폭증 및 호 절단 유발.
  - **해결 방안** : 조건부 핸드오버(CHO: Conditional Handover) 적용, 위성 궤도 궤적 사전 예측 기반 사전 연결 수립 및 이중 연결성(Dual Connectivity) 유지.
- **위성-지상망 간 주파수 간섭 및 한정된 스펙트럼 충돌** :
  - **한계점** : Ku/Ka 대역 및 이동통신 주파수(Sub-6GHz) 공유 시 지상 셀룰러 신호와 위성 다운링크 간 극심한 상호 간섭 발생.
  - **해결 방안** : 인지 무선(Cognitive Radio) 기반의 동적 주파수 공유(DSS), 적응형 빔 널링(Beam Nulling) 및 3GPP 규격의 지리정보 연계 간섭 회피 기술 채택.

## Ⅴ. 6G·위성통신 융합 적용 및 발전을 위한 기술사적 제언

- **우주 데이터센터 및 에지 컴퓨팅 기술의 융합** : 위성군 자체를 분산형 에지 컴퓨팅 노드로 진화시켜 원격 탐사 데이터를 우주에서 실시간 처리(AI On-board Inference)하는 아키텍처 수립.
- **독자 저궤도 통신 위성망 및 발사체 주권 확보** : 외국 상용 위성망(스타링크 등) 의존에 따른 안보 취약성을 해소하기 위해 K-위성통신 국석화 및 우주 발사체 수직 통합 체계 가속화.
- **지상-위성 통합 3GPP 표준화 활동 강화** : Rel-19/20 위성 NTN 규격에 한국형 지형 특성 및 해양·항공 운항 프로파일이 반영되도록 산학연 표준화 컨소시엄 대응력 제고.
