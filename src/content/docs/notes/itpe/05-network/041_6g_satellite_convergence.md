## 연관 키워드

- 6G·위성통신 융합, 비지상망(NTN), 저궤도(LEO), 중궤도(MEO), 정지궤도(GEO)
- 고고도 플랫폼(HAPS), 직접 단말 연결(D2D), 위성 탑재형 기지국, 투명 중계(Bent-Pipe)
- 광 위성간 링크(O-ISL), 도플러 보정, 조건부 핸드오버(CHO), 동적 주파수 공유(DSS)

## Ⅰ. 6G·위성통신 융합의 개요

- 핵심 요약 : 지상 기지국망과 위성, 고고도 플랫폼을 하나의 프로토콜로 묶어 지구 전역과 상공을 잇는 3차원 네트워크.
- 개념 : 지상 이동통신망에 **비지상망** (NTN, Non-Terrestrial Network)을 통합하여, 저궤도(LEO, Low Earth Orbit)·중궤도(MEO, Medium Earth Orbit)·정지궤도(GEO, Geostationary Earth Orbit) 위성과 고고도 플랫폼(HAPS, High-Altitude Platform Station)을 단일 표준으로 연결하는 3차원 통신 구조.
- 배경 및 필요성 : 해양, 사막, 산악, 상공은 지상 기지국을 설치하기 어려운 음영 지역으로 남아 있고, 도심항공교통(UAM, Urban Air Mobility)과 해상 물류의 연결 수요가 늘어나 지상망만으로는 연속 서비스가 어려움.
- 주요 목적 :
  1. 지구 표면 전역의 무음영 커버리지 확보
  2. 자연재해로 지상망이 끊겨도 통신을 유지하는 생존성 확보
  3. 항공, 해상, 지상 사이에서 끊기지 않는 통신 세션 유지

## Ⅱ. 6G·위성통신 융합의 특징 및 장점

- 핵심 요약 : 단말이 위성과 직접 연결되고 위성 자체가 기지국 기능을 가지며, 공통 코어망이 두 망을 함께 제어하는 구조.

1. **직접 단말 연결** (D2D, Direct-to-Device) : 일반 스마트폰의 표준 안테나와 모뎀으로 저궤도 위성과 직접 송수신 → 별도 대형 위성 안테나 없이 음영 구간 연결.
2. **위성 탑재형 기지국** (Regenerative Payload) : 위성에 기지국 기능을 실어 신호를 우주에서 처리 → 지상 게이트웨이를 거치지 않아 지연 감소.
3. **광 위성간 링크** (O-ISL, Optical Inter-Satellite Link) : 위성끼리 레이저로 직접 연결 → 우주 백본망의 고속 경로 확보.
4. **공통 코어망** (5GC/6GC, 5G/6G Core) : 지상 기지국과 위성 기지국을 하나의 제어 기능으로 관리 → 이기종 망 사이의 세션 연속성 보장.

## Ⅲ. 6G·위성통신 융합의 구조 (흐름)

- 핵심 요약 : 우주, 공중, 지상 계층이 위성 링크로 이어지는 3차원 계층 구조.

```text
[ 3차원 비지상 네트워크 계층 ]

우주 계층 : GEO · MEO · LEO 위성
          ↓ 위성 서비스 링크
공중 계층 : HAPS · 드론 (성층권)
          ↓
지상 계층 : 기지국 · 단말 · 게이트웨이
```

- 위성 탑재 방식은 두 가지로 나뉨. 투명 중계는 위성이 주파수 변환과 증폭만 맡고, 재생 방식은 위성이 기지국 기능을 직접 수행함.

```text
[ 투명 중계 (Bent-Pipe) ]

단말 → 위성 (주파수 변환·증폭)
          ↓
지상 게이트웨이 → 기지국·코어망
```

```text
[ 위성 탑재형 기지국 (재생 방식) ]

단말 → 위성 (기지국 기능 수행)
          ↓ 광 위성간 링크
다른 위성 → 지상 코어망
```

## Ⅳ. 궤도별 특성 비교

- 핵심 요약 : 고도가 낮을수록 지연과 경로 손실은 줄고 핸드오버는 잦아지므로, 궤도 선택은 지연과 커버리지의 상충 관계로 결정됨.

| 궤도 구분 | 고도 (대략) | 장점 | 단점 및 과제 |
| --- | --- | --- | --- |
| 저궤도 (LEO) | 수백 km ~ 1,500km 수준 | 지연 짧음, 경로 손실 적음, 단말 직접 통신 용이 | 공전 주기 약 1.5~2시간, 빈번한 핸드오버, 대규모 군집 필요 |
| 중궤도 (MEO) | 약 2,000 ~ 20,000km | 적은 위성 수로 넓은 커버리지 | 지연이 LEO보다 큼, 항법 위성 중심 운용 |
| 정지궤도 (GEO) | 약 35,786km | 위성 3기로 전 지구 커버 가능, 지상 안테나 지향 용이 | 큰 지연, 극지방 커버리지 제한, 단말 대형화 |
| 고고도 플랫폼 (HAPS) | 약 18~25km (성층권) | 낮은 지연, 특정 지역 장기 체공 | 체공 시간 한계, 국지적 커버리지 |

- 도플러 보정 : LEO 위성은 초속 약 7.5km로 움직여 큰 주파수 편이가 생기므로, 궤도력(Ephemeris)으로 편이를 미리 계산해 보정함.

## Ⅴ. 6G·위성통신 융합의 한계와 방안

- 핵심 요약 : 빈번한 위성 전환과 위성·지상 간 주파수 간섭이 핵심 한계이며, 예측 기반 핸드오버와 동적 주파수 공유로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 빈번한 위성 간 핸드오버 실패 | 위성이 단말 상공을 짧은 시간에 통과 → 시그널링 폭증과 호 절단 | **조건부 핸드오버** (CHO, Conditional Handover)와 궤도 예측 기반 사전 연결, 이중 연결성 유지 | 핸드오버 실패율, 호 절단율 |
| 위성-지상 간 주파수 간섭 | 같은 대역을 쓰는 지상 셀룰러 신호와 위성 하향 링크가 상호 간섭 | **동적 주파수 공유** (DSS, Dynamic Spectrum Sharing), 적응형 빔 널링, 지리정보 기반 간섭 회피 | 간섭 발생 빈도, 대역 이용률 |

## Ⅵ. 6G·위성통신 융합에 대한 기술사적 제언

- 핵심 요약 : 위성 기능을 AI 처리와 자주적 위성망 확보에 연결하고, 표준화를 국내 환경에 맞춰 선행하는 방향.

1. 위성 엣지 컴퓨팅 연계 : 위성군을 분산 엣지 노드로 발전시켜 원격 탐사 데이터를 궤도에서 1차 처리하는 구조를 검토할 필요가 있음.
2. 위성망 자주권 확보 : 특정 외국 상용 위성망에 대한 의존이 안보 취약성을 키우므로, 국내 저궤도 위성망과 발사체 역량을 함께 키워야 함.
3. 3GPP(3rd Generation Partnership Project) 위성 규격 대응 : 비지상망 규격의 제정 과정에 한국의 지형과 해상, 항공 운항 조건이 반영되도록 산학연 표준화 대응력을 높여야 함.

## Ⅶ. 결론

- 핵심 요약 : 6G·위성통신 융합은 지상망의 연장이 아니라 3차원 무음영 커버리지를 만드는 네트워크 구조의 전환.
- 시사점 : 궤도별 상충 관계를 이해하고 핸드오버와 주파수 공유를 표준 수준에서 해결하는 기업과 국가가 위성 기반 통신의 주도권을 가짐.
