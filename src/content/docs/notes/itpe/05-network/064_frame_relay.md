## 30초 인출

- 본질: **프레임릴레이(Frame Relay)** 는 공유 패킷 교환망에서 가상 회선으로 프레임을 전달하는 광역망 기술
- 메커니즘: 프레임의 DLCI로 망 내부 논리 경로를 식별하고, 혼잡 알림 비트와 폐기 우선 표시로 트래픽을 관리

<details>
<summary>핵심 용어</summary>

- **프레임릴레이(Frame Relay):** 가상 회선을 사용해 데이터링크 프레임을 패킷 교환망으로 전달하는 WAN 기술
- **DLCI(Data Link Connection Identifier):** 프레임릴레이 접속에서 가상 회선을 식별하는 로컬 식별자
- **CIR(Committed Information Rate):** 서비스 제공자가 계약상 약정한 정보 전송률
- **FECN(Forward Explicit Congestion Notification):** 혼잡을 향하는 방향의 프레임에 혼잡 상태를 알리는 표시
- **BECN(Backward Explicit Congestion Notification):** 반대 방향 프레임으로 송신 측에 혼잡을 알리는 표시
- **DE(Discard Eligibility):** 혼잡 시 먼저 폐기할 수 있도록 프레임에 표시하는 비트

</details>

## Ⅱ. 식별·혼잡 제어

```text
송신 DTE
   │ 프레임에 DLCI 부여
   ▼
프레임릴레이 교환망 ── 가상 회선 전달 ──▶ 수신 DTE
   │ 혼잡 시 FECN·BECN 표시
   └── DE 표시는 우선 폐기 대상 식별
```

| 필드 | 역할 |
|---|---|
| DLCI | 접속 내 가상 회선 식별 |
| FECN·BECN | 혼잡 방향과 송신 측에 혼잡 상태 통지 |
| DE | 혼잡 시 우선 폐기 가능한 프레임 표시 |

제언: 회선 식별자와 계약 전송률을 접속 설정·운영 자료에 함께 기록

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **프레임릴레이(Frame Relay)** 는 가상 회선으로 데이터링크 프레임을 전달하는 패킷 교환 WAN 기술 |
| 목적 | 공유망에서 논리 회선별 데이터 전달과 대역폭 서비스 제공 |

## Ⅱ. 프레임과 가상 회선 식별

| 항목 | 역할 |
|---|---|
| DLCI | 프레임릴레이 접속에서 가상 회선 식별 |
| FECN·BECN | 프레임 전달 방향에 따른 혼잡 알림 |
| DE | 혼잡 시 먼저 폐기할 프레임 표시 |
| CIR | 접속 서비스에서 약정된 정보 전송률 |

## Ⅲ. 혼잡 알림·폐기 표시

```text
프레임 A ── 혼잡 지점 ──▶ 수신 측
              │ FECN 표시: 혼잡 진행 방향 알림

송신 측 ──▶ 혼잡 지점 ── 프레임 B
     ◀── BECN 표시: 송신 방향에 혼잡 알림

DE 표시 프레임 ── 혼잡 시 우선 폐기 가능한 대상
```

| 표시 | 의미 | 종단 측 고려 |
|---|---|---|
| FECN | 혼잡 방향의 수신 측 통지 | 수신 측 혼잡 인식 |
| BECN | 반대 방향 송신 측 통지 | 전송률 조정 지원 |
| DE | 혼잡 시 우선 폐기 허용 | 중요 트래픽 분류와 표시 정책 |

## Ⅳ. X.25 비교와 운용 고려

| 비교축 | X.25 | 프레임릴레이 |
|---|---|---|
| 전달 단위 | 패킷 교환 | 데이터링크 프레임 교환 |
| 망 내부 처리 | 오류·흐름 제어 기능을 더 많이 수행 | 상대적으로 간소한 전달과 혼잡 알림 |
| 가상 회선 식별 | 논리 채널 식별 | DLCI |
| 적용 고려 | 낮은 품질의 회선에서 신뢰성 기능 중시 | 회선 품질과 서비스 계약에 맞는 혼잡·폐기 관리 |
