## 연관 키워드

- ARQ, 오류 제어, ACK, NAK, 타임아웃, 순서 번호, 검사합
- 정지-대기 ARQ, Go-Back-N ARQ, 선택적 재전송 ARQ, 슬라이딩 윈도우
- HARQ, FEC, SACK

## Ⅰ. ARQ의 개요

- 핵심 요약 : 수신 확인 응답과 재전송의 반복 루프로 오류·유실 프레임을 자동 복구하는 오류 제어 방식.
- 개념 : 수신 측의 오류 검출 결과를 응답으로 통보받아, 송신 측이 오류·유실 프레임을 자동으로 다시 보내게 하는 **ARQ** (Automatic Repeat reQuest, 자동 반복 요청) 방식.
- 배경 및 필요성 : 전송 매체의 잡음·간섭으로 오류를 원천 차단할 수 없고, 순방향 오류 정정(FEC, Forward Error Correction)만으로는 검출된 오류의 복구가 불가능해 재전송 계층의 보완 필요.
- 주요 목적 : 데이터 무결성과 순서 보장의 확보, 신뢰성과 회선 효율 사이의 균형.

## Ⅱ. ARQ의 특징 및 장점

- 핵심 요약 : 확인 응답·타이머·순서 번호·윈도우·오류 정정의 조합이 무손실 전달과 효율을 동시에 만드는 구조.

1. 확인 응답 루프 : 수신 측이 **ACK**(Acknowledgment, 긍정 응답)와 **NAK**(Negative Acknowledgment, 부정 응답)로 수신 결과를 통보 → 송신 측의 전달 성공 확정.
2. 타임아웃 복구 : 응답 미도착을 타이머 만료로 감지해 재전송 → 프레임 소실까지의 자동 복구.
3. 순서 번호 제어 : 프레임에 순서 번호를 부여해 중복 수신의 폐기와 재정렬 수행 → 순차적 무손실 전달.
4. 윈도우 파이프라이닝 : **슬라이딩 윈도우**(Sliding Window, 응답 대기 없이 연속 전송을 허용하는 범위)로 회선 활용률 향상.
5. 오류 정정과의 결합 : 물리 계층 FEC가 잔여 오류만 재전송으로 넘김 → 재전송 횟수 절감.

## Ⅲ. ARQ의 구조 (흐름)

- 핵심 요약 : 전송·검출·응답·재전송의 기본 절차와, 응답 대기 방식·재전송 범위에 따른 유형 분류.

```text
[ ARQ 기본 절차 ]

프레임 전송 (검사합 부착)
   ↓
수신 측 오류 검출
   ↓  정상 : ACK / 오류 : NAK
응답 수신 또는 타임아웃
   ↓  NAK·타임아웃 발생 시
해당 프레임 재전송
```

```text
[ ARQ 유형 분류 ]

정지-대기 ARQ (윈도우 1)
   ↓  1프레임마다 응답 대기
연속 전송형 ARQ (윈도우 N)
   ↓  Go-Back-N과 Selective Repeat
HARQ (FEC 결합형)
   ↓  정정과 재전송의 결합
```

- 정지-대기 ARQ : 가장 단순한 유형으로 짧은 지연·소량 전송에 적합.
- Go-Back-N ARQ : 오류 발생 지점부터 이후 프레임을 재전송하는 연속 전송형.
- 선택적 재전송 ARQ : 손실 프레임만 골라 재전송하는 연속 전송형.
- **HARQ**(Hybrid ARQ) : 수신 오류 프레임을 버리지 않고 버퍼에 보관해 재전송분과 합성하는 방식으로 Chase Combining과 증분 중복(Incremental Redundancy)의 결합 방식 구성.

## Ⅳ. ARQ 유형 간의 비교

- 핵심 요약 : 윈도우 크기와 재전송 범위의 선택이 채널 효율·버퍼 비용·복잡도의 균형을 결정.

| 비교 축 | 정지-대기 | Go-Back-N | Selective Repeat | HARQ |
| --- | --- | --- | --- | --- |
| 송신 윈도우 | 1 | N | N | 복수 프로세스 병행 |
| 오류 시 재전송 범위 | 해당 프레임 | 오류점 이후 전부 | 손실 프레임만 | 재전송분 (증분 비트 포함) |
| 채널 효율 | 긴 지연 링크에서 급락 | 오류율 상승 시 저하 | 높음 | 무선 환경에서 높음 |
| 버퍼·복잡도 | 최소 | 낮음 | 높음 (재정렬 버퍼) | 높음 (합성 버퍼) |
| 적합 환경 | 짧은 지연·소량 전송 | 지연이 짧은 링크 | 긴 지연·고속 링크 | 무선 링크 |

- 선택 기준 : 전파 지연과 오류율 측정값을 기준으로 단순성이 우선이면 정지-대기, 효율이 우선이면 Selective Repeat 계열, 무선 링크면 HARQ를 채택.

## Ⅴ. ARQ의 한계와 방안

- 핵심 요약 : 긴 지연 링크의 효율 저하, 중복 재전송, 계층 간 재전송 경쟁을 윈도우 설계·응답 고도화·타이머 조정으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 긴 지연 링크의 효율 저하 | 응답 대기 동안의 회선 유휴 → 처리율 감소 | 윈도우 확대와 Selective Repeat 계열 적용 | 유효 처리율, 재전송률 |
| 응답 손실의 중복 재전송 | ACK 유실 시 동일 프레임의 재도착 | 순서 번호 관리와 SACK(Selective Acknowledgment) 기반의 상세 수신 통보 | 중복 수신 프레임 수 |
| 계층 간 재전송 경쟁 | 링크 계층 재전송 중 전송 계층 타이머 만료 → 상위 중복 재전송 | 계층별 재전송 책임 분리와 타이머 산정의 상호 조정 | 불필요 재전송 수 |

## Ⅵ. ARQ에 대한 기술사적 제언

- 핵심 요약 : 신뢰 기능의 계층 배치 원칙, 링크 특성 기반 선택 절차, 신형 프로토콜 참고의 상위 전략 필요.
- 설계 : 프로토콜 설계 조직은 신뢰성을 담당할 계층의 배치 원칙을 설계 표준에 명시해 기능 중복 아키텍처의 방지 권장.
- 운영 : 망 운영 조직은 지연·오류율 측정 결과에 따라 유형과 파라미터를 결정하는 선택 절차의 표준화 권장.
- 기술 검토 : 전송 프로토콜 개발 조직은 QUIC처럼 재전송 패킷에 새 일련번호를 부여해 재전송 모호성을 제거한 설계 참고 권장.

## Ⅶ. 결론

- 핵심 요약 : ARQ는 확인 응답과 재전송의 폐쇄 루프로 신뢰성 있는 전달을 만드는 오류 제어의 기본 골격임.
- 시사점 : 링크의 지연·오류 특성에 맞는 윈도우와 재전송 범위의 선택이 전송 효율을 결정하는 구조임.
