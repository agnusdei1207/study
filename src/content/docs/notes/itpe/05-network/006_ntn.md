## 연관 키워드

- NTN(Non-Terrestrial Network), 3GPP(3rd Generation Partnership Project), Release 17, LEO(Low Earth Orbit)
- 5G NR(New Radio), NB-IoT(Narrowband Internet of Things), 직접 단말 통신(Direct-to-Device)
- 투명 중계(Transparent Payload), 재생성 중계(Regenerative Payload), 타이밍 어드밴스(Timing Advance), PEP(Performance Enhancing Proxy)

## Ⅰ. NTN(Non-Terrestrial Network)의 개요

- 핵심 요약 : 위성과 고고도 플랫폼을 3GPP 이동통신 표준의 무선 접속망에 직접 수용해 지상 기지국이 닿지 않는 곳까지 연결을 확장하는 기술.
- 개념 : 3GPP(3rd Generation Partnership Project)가 Release 17부터 표준화한 바와 같이 저궤도(LEO, Low Earth Orbit) 위성과 성층권 플랫폼(HAPS, High Altitude Platform Station)을 5G NR(New Radio), NB-IoT(Narrowband Internet of Things) 무선 접속망에 통합하는 **비지상 네트워크** (NTN, Non-Terrestrial Network) 기술.
- 배경 및 필요성 : 기지국을 세울 수 없는 대양, 사막, 고산지대는 지상망만으로 연결이 불가능하고, 글로벌 물류 추적과 재난 시 통신 백업을 위해 전 지구적 무선 연결이 요구됨.
- 주요 목적 : 일반 셀룰러 단말의 음영 지역 해소, 위성 기반 원격 사물인터넷 관제, 지상망 마비 상황의 비상 통신 확보.

## Ⅱ. NTN(Non-Terrestrial Network)의 특징 및 장점

- 핵심 요약 : 기존 5G 단말과 코어를 그대로 활용하면서 위성 구간을 확장해 단말 교체 부담과 망 운영의 이질성을 줄이는 구조.

1. 표준 단말 호환 : 3GPP 표준을 따르므로 일반 5G 단말이 위성 셀에 직접 접속 → 전용 단말 없이 음영 지역 연결.
2. 5G 코어 통합 : 지상 5G 코어망(5GC, 5G Core Network)과 동일한 인증·세션 체계 사용 → 지상·위성을 아우르는 단일 운영 체계.
3. 페이로드 방식의 선택 : 신호 중계만 하는 투명 방식과 위성 안에서 처리하는 재생성 방식 중 서비스에 맞는 구성 선택 → 위성 능력과 서비스 목표의 균형 설계.
4. 재난 대응 복원력 : 지상 기지국이 끊겨도 위성 경로로 메시지·음성 전달 → 지상망 마비 상황의 통신 확보.

## Ⅲ. NTN(Non-Terrestrial Network)의 구조 (흐름)

- 핵심 요약 : 위성이 신호를 중계만 하는 투명 모드와 위성 안에서 기지국 기능을 수행하는 재생성 모드로 나뉘며 둘 다 단말과 5G 코어를 연결하는 구조.
- 사용자 단말(UE, User Equipment)과 위성 사이를 서비스 링크, 위성과 지상 게이트웨이 사이를 피더 링크라 부름.
- **투명 중계** (Transparent Payload) : 위성이 무선 신호의 주파수 변환과 증폭만 수행하고 지상 기지국(gNB, next generation NodeB)이 나머지를 처리 → 구현이 단순하고 위성 경량화에 유리.
- **재생성 중계** (Regenerative Payload) : 위성 탑재체에 기저대역과 기지국 기능을 두고 위성 간 링크 라우팅까지 수행 → 지상 의존 감소, 위성 복잡도 증가.
- 타이밍 어드밴스(Timing Advance) 확장 : 수백~수천 km의 전파 지연을 보상하도록 송신 타이밍 보정 범위를 넓혀 프레임 동기 유지.
- HARQ(Hybrid Automatic Repeat Request) 조정 : 긴 왕복 지연으로 전송이 멈추지 않도록 프로세스 수 조정 또는 피드백 비활성화 모드 지원.

```text
[ 투명 모드 (Bent-pipe) ]

단말 (UE)
    ↓ 서비스 링크
LEO 위성 (주파수 변환·증폭만)
    ↓ 피더 링크
지상 게이트웨이 + 지상 gNB
    ↓
5G 코어망
```

```text
[ 재생성 모드 (On-board gNB) ]

단말 (UE)
    ↓ 서비스 링크
LEO 위성 (기지국 기능 내장)
    ↓ 위성 간 링크 라우팅
지상 게이트웨이
    ↓
5G 코어망
```

## Ⅳ. NTN(Non-Terrestrial Network)의 비교

- 핵심 요약 : 3GPP 표준 NTN은 기존 단말 활용의 호환성, 독자 저궤도 위성은 고속 광대역, 레거시 위성은 저속 음성에서 강점을 가짐.

| 비교 축 | 3GPP 표준 5G NTN | 독자 저궤도 위성망 | 레거시 위성 통신 |
| --- | --- | --- | --- |
| 표준 체계 | 3GPP Release 17 이후의 글로벌 표준 | 사업자별 독자 설계 | 독자 규격과 ITU(International Telecommunication Union) 체계 |
| 단말 | 일반 5G 스마트폰 수용 | 전용 안테나·단말 | 전용 위성 전화 단말 |
| 주요 서비스 | 긴급 메시지, 음성, 광대역 데이터 | 고속 인터넷 백홀 | 저속 음성·텍스트 |
| 코어 연동 | 지상 5G 코어와 통합 | 독자 게이트웨이 운영 | 독자 지상 설비 운영 |
| 확장성 | 표준 릴리스마다 기능 확장 | 독자 위성 발사 주기에 종속 | 규격 교체에 긴 시간 소요 |

- 선택 기준 : 기존 스마트폰으로 음영을 메우는 것이 목표이면 3GPP 표준 NTN이, 고속 백홀이 목표이면 독자 위성 방식이 적합하고, 장기적으로는 표준 NTN이 단말 생태계 확산의 기반이 됨.

## Ⅴ. NTN(Non-Terrestrial Network)의 한계와 방안

- 핵심 요약 : 도플러 편이, 긴 왕복 지연, 단말 송신 전력의 한계가 주요 문제이며 사전 보상, 프로토콜 조정, 고이득 안테나로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 도플러 편이에 따른 동기 파괴 | 저궤도 위성의 고속 이동으로 중심 주파수가 크게 편이되어 직교 부반송파 구조가 무너짐 | 위성 궤도력과 단말 위치 기반의 송신단 사전 도플러 보상 | 주파수 오차, 동기 실패율 |
| 긴 왕복 지연의 성능 저하 | 긴 RTT(Round-Trip Time)로 HARQ 버퍼 고갈과 유효 대역폭 감소 발생 | HARQ 피드백 비활성화 설정, 무선 구간 가속을 위한 PEP(Performance Enhancing Proxy) 도입 | 유효 대역폭, RTT |
| 단말 송신 전력의 한계 | 단말의 제한된 송신 전력으로 수백 km 상공 위성까지 도달이 어려움 | 위성 측 대형 위상 배열 안테나와 고이득 빔포밍, 커버리지 확장용 반복 전송 | 상향 링크 예산, 수신 성공률 |

## Ⅵ. NTN(Non-Terrestrial Network)에 대한 기술사적 제언

- 핵심 요약 : 서비스 범위의 광대역 확장, 지상·위성 통합 이동성 설계, 독자 기술 내재화를 함께 추진하는 방향.

1. 통신 사업자는 사물인터넷 중심의 Release 17 기능에서 광대역 데이터를 지원하는 5G NR-NTN으로 서비스 범위를 넓혀 재난 지역에서도 음성·데이터가 끊기지 않는 인프라를 준비해야 한다.
2. 망 설계 조직은 지상 셀과 위성 셀이 같은 5G 코어 안에서 끊김 없이 이동하도록 정책 제어 기능과 핸드오버 파라미터를 통합 설계하는 절차를 두어야 한다.
3. 국가는 해외 민간 위성에 통신을 의존하지 않도록 표준 참여와 함께 독자 위성 통신 기술의 내재화 로드맵을 세우고 우주·통신 인프라 정책을 연계 추진해야 한다.

## Ⅶ. 결론

- 핵심 요약 : NTN은 3GPP 표준 위에서 위성과 지상 5G를 하나의 무선 접속망으로 묶어 음영 지역을 없애는 기술임.
- 시사점 : 표준 단말 호환의 강점을 살리려면 도플러와 전력 같은 물리 한계를 표준 기능으로 함께 해소하는 노력이 필요함.
