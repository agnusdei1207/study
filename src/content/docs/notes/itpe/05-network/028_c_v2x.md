## 지식 로드맵 내 현재 위치

지식 위치: 네트워크 → 이동·차량 통신 → **C-V2X**

## 30초 인출

- 본질: **C-V2X(Cellular Vehicle-to-Everything)** : 3GPP 이동통신 기술을 이용해 차량과 네트워크·주변 단말 간 통신을 지원하는 기술군
- 메커니즘: **Uu** 로 차량과 기지국망을 연결하고 **PC5 sidelink** 로 단말 간 직접 통신
- 통찰: DSRC의 통신 거리 및 대역폭 한계를 극복하고 기지국 통신망(Uu)과 차량 간 직접 통신(PC5 사이드링크)을 융합하여 센서 사각지대를 해소하고 자율주행 협조 제어를 실현하는 이동통신 기반 V2X 기술임.

<details>
<summary>핵심 용어</summary>

- **C-V2X(Cellular Vehicle-to-Everything)** : 이동통신 표준 기반 차량·도로 이용자·네트워크 간 통신 기술군
- **V2V(Vehicle-to-Vehicle)** : 차량 간 통신
- **V2I(Vehicle-to-Infrastructure)** : 차량과 도로 인프라 간 통신
- **V2P(Vehicle-to-Pedestrian)** : 차량과 보행자 단말 간 통신
- **V2N(Vehicle-to-Network)** : 차량과 네트워크 서비스 간 통신
- **Uu 인터페이스(Uu Interface)** : 사용자 단말과 기지국 사이의 무선 접속 인터페이스
- **PC5 사이드링크(PC5 Sidelink)** : 단말들이 기지국을 경유하지 않고 직접 통신하는 인터페이스
- **LTE-V2X(Long-Term Evolution Vehicle-to-Everything)** : LTE 기반 V2X 기술; PC5 자원 선택 모드와 절차는 3GPP 규격에 따름
- **NR-V2X(New Radio Vehicle-to-Everything)** : 5G NR 기반 V2X 기술; LTE-V2X와 절차·기능을 동일시하지 않음

</details>

## 2~4교시 25점 답안

## Ⅰ. C-V2X(Cellular Vehicle-to-Everything)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 이동통신 표준(3GPP)을 기반으로 차량과 차량(V2V), 인프라(V2I), 보행자(V2P), 네트워크(V2N) 간에 주행 및 안전 정보를 실시간 교환하는 무선 통신 기술 |
| 목적 | 라이다·카메라 등 온보드 센서의 가시거리(LOS) 한계 및 기상 악화 시 탐지 불능 극복, 군집주행(Platooning) 및 원격 주행 지원 |

## Ⅱ. C-V2X(Cellular Vehicle-to-Everything)의 특징

| 특징 | 상세 내용 |
|---|---|
| 이중 통신 인터페이스 | 단거리 초저지연 직접통신(PC5 Sidelink)과 장거리 광역 통신(Uu 기지국 통신)을 유기적으로 병행 |
| 기지국 비의존 동작 | 통신 음영 지역(산악, 지하터널)에서도 Mode 4 / Mode 2 자율 스케줄링을 통해 차량 간 직접 통신 보장 |
| 초고신뢰·저지연(URLLC)| 3GPP Rel-16 NR-V2X 기준 1ms 이내 무선 전송 지연 및 99.999% 수신 신뢰도 제공 |
| 대규모 센서 데이터 공유| 원시 센서 데이터 공유(Sensor Sharing) 및 주행 경로 공유를 통해 자율주행 판단 정밀도 향상 |

## Ⅲ. C-V2X(Cellular Vehicle-to-Everything)의 체계·프로세스

**C-V2X 듀얼 인터페이스 아키텍처 및 4대 통신 유형**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ C-V2X 통신 인터페이스 구조 ]                 │
│                                                                        │
│   [ 셀룰러 기지국 (gNodeB) / MEC / V2X 서버 ]                          │
│          ▲                              ▲                              │
│          │ Uu Interface (셀룰러 망)     │ Uu Interface                 │
│          ▼                              ▼                              │
│   ┌──────────────┐   PC5 Sidelink   ┌──────────────┐                   │
│   │ [ 차량 A ]   │◄════ (직접통신) ════►│ [ 차량 B ]   │ (V2V 통신)         │
│   └──────┬───────┘ (5.9GHz 면허대역)└──────┬───────┘                   │
│          │                                 │                           │
│          │ PC5                             │ PC5                       │
│          ▼                                 ▼                           │
│   ┌──────────────┐                  ┌──────────────┐                   │
│   │ [ 보행자 ]   │ (V2P 충돌 경고)  │ [ 노변 RSU ] │ (V2I 신호등 잔여시간)│
│   └──────────────┘                  └──────────────┘                   │
└────────────────────────────────────────────────────────────────────────┘
```

| 인터페이스 구분 | 주요 주파수 대역 | 통신 거리 | 지연 시간 | 핵심 역할 및 용도 |
|---|---|---|---|---|
| **PC5 (사이드링크)** | 5.9 GHz ITS 면허대역 | 300m ~ 1km | 1 ~ 5 ms (초저지연) | 차량 간 직접 충돌 방지, 교차로 사고 예방, 보행자 경고 |
| **Uu (인프라 링크)** | 3GPP 이동통신 대역 | 수 km (셀룰러 반경) | 10 ~ 50 ms | 광역 교통 관제, 실시간 동적 지도(HD Map) 다운로드 |

## Ⅳ. C-V2X(Cellular Vehicle-to-Everything)의 종류·비교

| 비교 항목 | DSRC / WAVE (IEEE 802.11p) | LTE-V2X (3GPP Rel-14/15) | NR-V2X (3GPP Rel-16/17) |
|---|---|---|---|
| **무선 표준 기반** | Wi-Fi (802.11a/p) 변형 | 4G LTE 물리 계층 | 5G NR 초광대역 / URLLC |
| **최대 전송 속도** | 최대 27 Mbps | 최대 100 Mbps | 1 Gbps 이상 (센서 공유 가능) |
| **무선 지연 시간** | 수십 ms (경쟁 기반 지연) | 10 ~ 20 ms | **1 ms 이하** |
| **통신 범위** | 100m ~ 300m (단거리) | 최대 500m ~ 1km | 1km 이상 |
| **사이드링크 전송** | CSMA/CA 브로드캐스트 | 브로드캐스트 위주 (Mode 3/4) | **유니캐스트, 그룹캐스트, 브로드캐스트**|
| **주요 지원 서비스** | 단순 위험 알림, 신호 정보 | 기본 안전 주행, 전방 충돌 경고 | 군집주행, 원격 운전, 센서 공유 |

## Ⅴ. C-V2X(Cellular Vehicle-to-Everything)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 5.9GHz 대역에서 고속 주행 시(200km/h 이상) 심각한 도플러 천이 발생으로 반송파 주파수 오프셋 및 채널 추정 실패 | NR-V2X 기반 위상 추적 참조 신호(PT-RS) 및 고밀도 복조 참조 신호(DMRS) 심볼을 시간 축에 적응형 추가 배치 |
| 통신 음영지대(터널, 산악)에서 기지국 없이 다수 차량이 사이드링크(Mode 2) 자율 분산 예약 시 패킷 충돌 급증 | GNSS 정밀 시각 동기화 기반 지리적 구역 분할(Zone-based Resource Allocation) 및 사전 센싱 기반 채널 예약(Sensing-based SPS) 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
국내 C-ITS 전국망 구축 시, 5.9GHz 주파수 정책에 따라 단일 DSRC 방식을 지양하고 LTE/NR-V2X를 단일 통신 표준으로 확정하되, RSU(노변기지국)와 차량 간 보안 무결성 검증을 위해 V2X-SCMS(보안인증관리체계) 기반 1회용 익명 가명인증서(Pseudonym Certificate) 체계를 필수 탑재.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ C-V2X Mode 2 사전 센싱 기반 자원 예약 (Sensing-based SPS) ]        │
│                                                                        │
│ 1. [ 센싱 윈도우 (최근 1000ms) ] 타 차량의 전송 신호 세기(RSRP) 실측  │
│ 2. 예약된 자원과 간섭량이 높은 자원 블록을 후보군에서 1차 제외        │
│ 3. [ 선택 윈도우 (향후 100ms) ] 간섭이 가장 낮은 하위 20% 자원 식별  │
│ 4. 해당 최적 자원 블록을 임의 선택하고 자원 예약 간격 카운터 설정     │
│                                                                        │
│   Tx ──► [ 선택된 자원 블록에 BSM(기본안전메시지) 송출 ] ──► 충돌 방지│
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 3GPP 통신 모드 | 자원 할당 주체 | 기지국 연결 필요성 | 주 적용 상황 |
|---|---|---|---|
| **Mode 1 (NR)** / Mode 3 | 기지국(gNB)이 동적 스케줄링 | 필수 (셀 커버리지 내부) | 도심 혼잡 구간 무충돌 보장 |
| **Mode 2 (NR)** / Mode 4 | 차량 단말이 센싱 후 자율 선택 | 불필요 (독립 분산 동작) | 고속도로, 음영지대, 재난 상황 |
