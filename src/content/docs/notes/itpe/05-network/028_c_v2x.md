## 답안 골격
```text
[C-V2X] ◀━━ 머리: Ⅶ 내 의견 (5G NR-V2X 기반 센서 공유 군집주행과 지능형 RSU 엣지 인프라 결합)
 ┃
 ┣━ Ⅰ 개요 ───── WAVE(DSRC)의 RSU 인프라 비용·단거리 한계 → 셀룰러 기반 차량 사물 통신
 ┣━ Ⅱ 특징 ───── 광역 인프라(Uu) + 직접 통신(PC5 사이드링크), 초저지연, 고신뢰도, 진화 연속성
 ┣━ Ⅲ 구조 ───── 통신 대상(V2V·V2I·V2P·V2N) + 통신 링크(PC5 직접 통신 vs Uu 기지국 통신)
 ┣━ Ⅳ 흐름 ───── ① 차량 센서 데이터 수집 → ② 기지국 스케줄링(모드 3/1) or 단말 자율 선택(모드 4/2) → ③ 안전 메시지 방송
 ┣━ Ⅴ 비교 ───── WAVE(802.11p) vs C-V2X (와이파이 기반 vs 3GPP 셀룰러, 독립 RSU vs 기지국 인프라 재활용)
 ┗━ Ⅵ 실무 ───── 기지국 음영 시 사이드링크 충돌 / 고속 주행 도플러 주파수 천이 / 단말 간 보안 인증 지연
```
- 필수 키워드: 3GPP Rel-14/16 · PC5(사이드링크) · Uu 인터페이스 · V2V/V2I/V2P/V2N · 모드 4 자율 스케줄링 · NR-V2X
- 배점 전략: 10점 = Ⅰ → Ⅲ C-V2X 4대 통신 유형 및 이중 인터페이스 도식 → Ⅴ WAVE vs C-V2X 비교표 / 25점 = Ⅰ~Ⅶ, 121회 기출에 맞춰 DSRC와의 표준 경쟁 역사와 5G 진화 경로 상세
- 기출: 121회 2교시: "자율주행 차량 통신 기술인 WAVE와 C-V2X를 비교하고 향후 발전 방향을 제시하시오." → Ⅰ~Ⅶ

## 한 줄 본질
- 와이파이 기반 WAVE의 비싼 RSU 노변 기지국 추가 설치 비용과 셀룰러 망과의 단절 한계 → 통신사 기지국 망(Uu)을 통한 광역 교통 정보와 차량 간 직접 통신(PC5 사이드링크)을 단일 칩셋으로 통합 → 자율주행 안전성 확보 및 전국 단위 커버리지 즉시 활용 / 기지국 음영지역에서 차량 간 사이드링크 무선 자원 충돌 제어 난이도 발생

## 핵심 그림
```text
[ C-V2X 통신 인터페이스 및 대상 구조 ]

                         +-------------------------+
                         | 5G/LTE 기지국 (gNB/eNB) |
                         +------------+------------+
                                      | (Uu 인터페이스: V2N 광역 교통관제)
                                      v
  [ 차량 (Vehicle) ] <---(PC5 사이드링크)---> [ 인접 차량 (V2V) ]
         |
         +---------------(PC5 사이드링크)---> [ 보행자 스마트폰 (V2P) ]
         |
         +---------------(PC5 사이드링크)---> [ 신호등 노변기지국 (V2I) ]
```

## 핵심 용어
- PC5 인터페이스(Sidelink): 기지국을 거치지 않고 차량과 차량(V2V), 차량과 보행자(V2P), 차량과 신호등(V2I)이 5.9GHz 대역에서 직접 데이터를 1ms 내로 주고받는 직결 통신 링크
- Uu 인터페이스: 차량과 셀룰러 기지국(V2N) 사이의 전통적 상/하향 통신 링크. 수십 km 전방의 사고, 기상 악화, 클라우드 HD 맵 업데이트 수신
- 사이드링크 자원 할당 모드 4 (NR 모드 2): 기지국의 전파가 닿지 않는 터널이나 지하 주차장에서도 차량 단말 스스로 비어 있는 주파수 자원을 센싱(Sensing-based)하여 패킷 충돌 없이 자율 송신하는 기제

## 핵심 통찰
- 자율주행 라이다(LiDAR)와 카메라는 "가시거리(Line of Sight)" 안의 사물만 보지만, V2X는 앞서가는 대형 트럭에 가려진 전방 상황이나 건물 모퉁이의 돌발 상황을 무선으로 미리 알려주는 "무선 센서" 역할
- WAVE는 2000년대 기술(802.11p)에 머물러 고속 이동 시 전송률이 급감하나, C-V2X는 LTE-V2X(Rel-14)에서 5G NR-V2X(Rel-16)로 하위 호환성을 유지하며 초광대역 센서 공유로 지속 진화
- 한국 정부(과기정통부·국토부)도 수년간의 WAVE vs C-V2X 논쟁 끝에 단일 표준으로 C-V2X(LTE-V2X 우선, 향후 5G-V2X 전환)를 최종 확정

## 이웃 토픽과 구분
- WAVE vs C-V2X: WAVE는 802.11a 무선랜 기반으로 구조가 단순하나 전국망 연동 불가 / C-V2X는 3GPP 표준 기반으로 기지국 통신(Uu)과 차량 직결(PC5)을 결합해 전국망과 근거리 안전망을 동시 지원

## 문제·원인·대책
- 적용 상황: 터널 내부 다중 추돌 사고 시 차량 간 긴급 제동 메시지 전송
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 기지국 음영 구간에서 차량 간 패킷 충돌 | 기지국 중앙 스케줄러(모드 3) 부재 시 다수 차량의 동시 전송 | 모드 4(센싱 기반 반영구 스케줄링 SPS) 자율 알고리즘 | 단말 간 채널 에너지 감지로 충돌 확률을 5% 미만으로 억제 |
| 시속 150km 이상 고속 주행 시 신호 복조 오류 | 차량 간 고속 상대 이동으로 인한 심각한 도플러 주파수 확산 | DMRS(復調 참조 신호) 심볼 밀도 증설 및 주파수 옵셋 보정 | 고속 이동 환경에서도 페이딩 왜곡 극복 및 통신 유지 |

## 이렇게 출제된다
- 제121회 2교시: "자율주행 차량 통신 기술인 WAVE와 C-V2X를 비교하고 향후 발전 방향을 제시하시오." → 요구 포인트: 양 기술의 물리/MAC 계층 비교, 인프라 비용, 전송 지연, 5G-V2X 진화 로드맵

## 내 의견
- [사이드링크 보안 인증 지연과 개인 프라이버시 보호] 차량이 초당 수십 번 뿌리는 안전 메시지에 매번 무거운 공개키 암호(PKI) 서명을 검증하면 차량 ECU 연산 과부하 발생 → 나라면: IEEE 1609.2 표준의 가명 인증서(Pseudonym Certificate) 체계를 적용해 차량 이동 궤적 프라이버시를 보호하고, 하드웨어 보안 모듈(HSM) 전용 암호화 가속기를 탑재해 서명 검증 시간을 1ms 이내로 단축
