## 지식 로드맵 내 현재 위치

지식 위치: 네트워크 → 이동·차량 통신 → **C-V2X**

## 30초 인출

- 본질: **C-V2X(Cellular Vehicle-to-Everything)** : 3GPP 이동통신 기술을 이용해 차량과 네트워크·주변 단말 간 통신을 지원하는 기술군
- 메커니즘: **Uu**로 차량과 기지국망을 연결하고 **PC5 sidelink**로 단말 간 직접 통신

<details>
<summary>핵심 용어</summary>

- **C-V2X(Cellular Vehicle-to-Everything)** : 이동통신 표준 기반 차량·도로 이용자·네트워크 간 통신 기술군
- **V2V(Vehicle-to-Vehicle)** : 차량 간 통신
- **V2I(Vehicle-to-Infrastructure)** : 차량과 도로 인프라 간 통신
- **V2P(Vehicle-to-Pedestrian)** : 차량과 보행자 단말 간 통신
- **V2N(Vehicle-to-Network)** : 차량과 네트워크 서비스 간 통신
- **Uu 인터페이스(Uu Interface)** : 사용자 단말과 기지국 사이의 무선 접속 인터페이스
- **PC5 사이드링크(PC5 Sidelink)** : 단말들이 기지국을 경유하지 않고 직접 통신하는 인터페이스
- **LTE-V2X(Long-Term Evolution Vehicle-to-Everything)** : LTE 기반 V2X 기술; PC5 자원 선택 모드와 절차는 3GPP 규격에 따름
- **NR-V2X(New Radio Vehicle-to-Everything)** : 5G NR 기반 V2X 기술; LTE-V2X와 절차·기능을 동일시하지 않음

</details>


## 2~4교시 25점 답안

### Ⅰ. C-V2X의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **C-V2X** : 이동통신 표준으로 차량과 기지국망·주변 단말의 통신을 지원하는 기술군 |
| 목적 | 차량 안전·교통 서비스에 필요한 네트워크 통신과 직접 통신 지원 |

### Ⅱ. 통신 경로

```text
차량 단말
  ├─ Uu ─→ 기지국망 ─→ 교통·클라우드 서비스
  └─ PC5 직접 통신 ─→ 주변 차량·보행자·도로 장치
```

Uu는 네트워크 접속 경로, PC5는 단말 간 직접 경로로 구별. 지원 기능·자원 배정·지연 특성은 세대와 규격 릴리스에 따라 확인.

### Ⅲ. 통신 유형·인터페이스

| 유형 | 통신 상대 | 주된 경로 예 |
|---|---|---|
| V2V | 차량 ↔ 차량 | PC5 직접 통신 또는 네트워크 연계 |
| V2I | 차량 ↔ 도로 인프라 | PC5 또는 Uu 기반 구성 |
| V2P | 차량 ↔ 보행자 단말 | 직접·네트워크 경로; 기기·망 지원 확인 |
| V2N | 차량 ↔ 네트워크 서비스 | Uu 접속 후 이동통신망 |

### Ⅳ. LTE-V2X와 NR-V2X

| 관점 | LTE-V2X | NR-V2X |
|---|---|---|
| 무선 기술 계열 | LTE | 5G NR |
| 표준화 맥락 | 3GPP Rel-14 이후 V2X 기능 | 3GPP Rel-16 이후 NR sidelink V2X 확장 |
| 자원 선택 | LTE 규격의 모드·절차 사용 | NR 규격의 자원 할당 절차 사용 |
| 상호운용 | 단말·주파수·서비스 규격 확인 | LTE와 절차·기능의 호환성을 별도 검증 |

LTE Mode 4와 NR Mode 2는 자율 자원 선택을 포함하나 서로 다른 무선 기술의 규격상 모드이며, 명칭만으로 동일 절차를 전제하지 않음.

### Ⅴ. 적용 고려사항

| 고려 영역 | 확인 내용 |
|---|---|
| 안전 메시지 | 지연·전달률·우선순위 요구와 혼잡 조건 |
| 자원 선택 | 기지국 커버리지 유무에 따른 네트워크 지원·자율 선택 절차 |
| 상호운용성 | 단말 세대·주파수·프로파일·메시지 형식 |
| 보안·개인정보 | 인증·메시지 검증·위치정보 최소화·키 관리 |
| 서비스 연속성 | 이동성, 망 장애, 기지국 음영에서의 동작 시험 |

### Ⅵ. 한계와 대응

| 한계 | 대응 |
|---|---|
| 무선 혼잡·음영에서 전달 품질 변동 | 현장 밀도·속도·전파환경별 패킷 전달 시험 |
| LTE·NR 간 세대 차이에 따른 비호환 | 지원 규격·릴리스·주파수·메시지 프로파일 확인 |
| 안전 경보 오용·위치정보 노출 | 메시지 인증·접근 통제·데이터 최소화 적용 |

### Ⅶ. 기술사적 제언

| 우선 적용 | 검증 방향 |
|---|---|
| 안전 서비스별 요구사항을 먼저 정하고 Uu·PC5 조합 선정 | 혼잡·음영·세대 혼재 조건에서 지연·전달·보안·연동을 실증 |
