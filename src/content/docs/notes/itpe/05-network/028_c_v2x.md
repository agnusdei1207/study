## 연관 키워드

- C-V2X(Cellular Vehicle-to-Everything), PC5 사이드링크(Sidelink), Uu 인터페이스, 모드 1·모드 2(Mode 1·Mode 2)
- V2V·V2I·V2P·V2N, 협력 인지(Collective Perception), 군집 주행(Platooning), SCMS(Security Credential Management System)

## Ⅰ. C-V2X의 개요

- 핵심 요약 : 셀룰러 기술을 차량 환경으로 확장해 차량·인프라·보행자가 직접 경로와 네트워크 경로로 실시간 정보를 교환하는 통신 기술.
- 개념 : 3GPP(3rd Generation Partnership Project) 셀룰러 표준을 기반으로 차량이 차량(V2V, Vehicle-to-Vehicle), 도로 인프라(V2I, Vehicle-to-Infrastructure), 보행자(V2P, Vehicle-to-Pedestrian), 네트워크(V2N, Vehicle-to-Network)와 정보를 교환하는 **C-V2X**(Cellular Vehicle-to-Everything). LTE(Long-Term Evolution)-V2X와 5G NR(New Radio) V2X 단계로 진화.
- 배경 및 필요성 : 카메라·라이다·레이더 같은 차재 센서는 가려진 구간과 악천후에서 인지 공백이 생기므로, 주변 교통 참여자와 인지 결과를 공유하는 **협력 인지**(Collective Perception)의 필요.
- 주요 목적 : 교통사고의 예방, 저지연 직접 통신 기반의 자율주행 지원, 도로 운영 효율의 향상.

## Ⅱ. C-V2X의 특징 및 장점

- 핵심 요약 : 기지국 없이 동작하는 직접 링크와 광역 셀룰러 링크의 이중 구조가 커버리지 밖 동작과 광역 서비스를 동시에 만족.

1. **PC5 사이드링크**(Sidelink, 단말 간 직접 무선 링크) : 기지국을 거치지 않는 차량 간·차량-노변 장치 간 직접 통신 → 커버리지 밖에서도 밀리초 수준의 경고 전달.
2. Uu 인터페이스(기지국 경유 셀룰러 링크) : 교통 정보 수집, 원격 관제, 정밀 지도 갱신 같은 광역 서비스의 제공.
3. 자원 할당의 이원화 : **모드 1**(Mode 1, 기지국이 전송 자원을 지정하는 방식)은 혼잡 구간의 충돌 억제, **모드 2**(Mode 2, 단말이 채널을 감지해 자원을 스스로 선택하는 방식)는 기지국 없는 독립 동작 지원.
4. 5G NR V2X의 기능 확장 : 유니캐스트·그룹캐스트 지원 → **군집 주행**(Platooning, 차열 주행)과 센서 공유 같은 고신뢰 그룹 통신의 실현.

## Ⅲ. C-V2X의 구조 (흐름)

- 핵심 요약 : 통신 상대에 따라 PC5와 Uu 링크를 선택하고, 사이드링크 자원은 모드 1과 모드 2로 나뉘는 구조.

```text
[ 통신 대상과 링크 선택 ]

차량 ↔ 차량 (V2V : PC5)
차량 ↔ 노변 장치 (V2I : PC5 또는 Uu)
차량 ↔ 보행자 단말 (V2P : PC5)
차량 ↔ 클라우드 (V2N : Uu)
```

```text
[ 사이드링크 자원 할당 모드 ]

모드 1 (스케줄링 방식)
    기지국이 자원 지정
    ↓
충돌 가능성 최소화

모드 2 (자율 분산 방식)
    단말이 채널 센싱
    ↓
유휴 자원의 자체 선택
```

## Ⅳ. DSRC와 LTE-V2X, 5G NR V2X의 비교

- 핵심 요약 : 무선랜 기반 DSRC의 진화 정체와 셀룰러 계열의 단계적 확장이라는 대비.
- **DSRC**(Dedicated Short-Range Communications)는 IEEE(Institute of Electrical and Electronics Engineers) 802.11p 기반의 무선랜 계열 차량 통신 기술.

| 비교 축 | DSRC (IEEE 802.11p) | LTE-V2X (Rel-14·15) | 5G NR V2X (Rel-16 이후) |
| --- | --- | --- | --- |
| 기반 기술 | 무선랜 CSMA/CA(Carrier Sense Multiple Access with Collision Avoidance) | 4G 셀룰러 SC-FDMA(Single-Carrier Frequency-Division Multiple Access) | 5G 셀룰러 OFDMA(Orthogonal Frequency-Division Multiple Access) |
| 통신 방식 | 브로드캐스트 중심 | 브로드캐스트 중심 | 브로드캐스트·그룹캐스트·유니캐스트 |
| 자원 제어 | 분산 경쟁 | 모드 1·모드 2 | 모드 1·모드 2 + 확장 기능 |
| 목표 수준 | 상대적으로 제한적 | 중간 수준 | 초저지연·고신뢰 |
| 진화성 | 표준 진화 정체 | NR V2X로 승계 | 6G V2X 논의로 연결 |

- 선택 기준 : 기존 자산 호환의 단기 과제면 DSRC 계열 검토, 장기적 고신뢰 협력 주행이 목표면 셀룰러 계열(C-V2X) 채택이 일반적.

## Ⅴ. C-V2X의 한계와 방안

- 핵심 요약 : 밀집 구간의 자원 충돌, 음영 구간의 단절, 허위 노드 공격을 혼잡 제어, 중계 구조, 인증 체계로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 밀집 구간 자원 충돌 | 모드 2 자율 선택의 자원 예약 겹침 → 패킷 충돌과 전달률 저하 | 혼잡도 기반 전송 전력·주기 제어, 밀집 구간의 모드 1 병행 | 채널 점유율(CBR, Channel Busy Ratio)·전달률 |
| 음영 구간 단절 | 터널·지하차도의 전파 차단 → 관제·지도 갱신의 공백 | 노변 장치의 전략 배치와 다중 홉(Multi-hop) 중계 | 음영 구간 연결 유지율 |
| 허위 노드 공격 | 자격증명 탈취 노드의 가짜 경고 → 연쇄 사고 유발 | **SCMS**(Security Credential Management System, 보안 자격증명 관리 체계) 기반 인증과 하드웨어 보안 모듈 탑재 | 인증 실패율·폐기 반영 지연 |

## Ⅵ. C-V2X에 대한 기술사적 제언

- 핵심 요약 : 노변 인프라·보안 체계·표준 추적을 함께 고도화하는 단계별 도입 방향.
- 도로 인프라 투자 주체는 고속도로와 교차로부터 노변 장치와 엣지 컴퓨팅을 우선 배치하고, 협력 인지 메시지(CPM, Collective Perception Message) 기반의 실증을 진행하는 방안.
- 보안 조직은 인증서의 발급·폐기·갱신이 자동화된 SCMS 운영 체계와 프라이버시 보호용 가명 인증서 설계를 선행할 필요.
- 자동차·통신 산업 조직은 3GPP 표준 릴리스 동향을 상시 추적하고 5G NR V2X 장비의 상호운용성 시험 체계를 구축하는 절차 권장.

## Ⅶ. 결론

- 핵심 요약 : C-V2X는 셀룰러 기술을 차량 간 직접 통신으로 확장해 협력 자율주행의 통신 기반을 만드는 기술.
- 통신 성능과 함께 인증 체계와 노변 인프라의 확충이 갖춰질 때 협력 주행의 실효성이 성립.
