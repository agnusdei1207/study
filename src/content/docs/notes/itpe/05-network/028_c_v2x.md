## 연관 키워드

- C-V2X(Cellular Vehicle-to-Everything), PC5 사이드링크(Sidelink), Uu 인터페이스, 모드 1·모드 2(Mode 1, Mode 2)
- DSRC(Dedicated Short-Range Communications), WAVE(IEEE 802.11p), 군집 주행(Platooning), 협력 인지
- SCMS(Security Credential Management System), Sybil 공격(Sybil Attack), 동적 정밀 지도(LDM, Local Dynamic Map)

## Ⅰ. C-V2X의 개요

- 핵심 요약 : 셀룰러 망으로 차량, 인프라, 보행자가 실시간으로 정보를 교환해 센서의 인지 한계를 넘는 협력 주행 기술.
- 개념 : 3GPP(3rd Generation Partnership Project) 셀룰러 표준을 기반으로, 차량이 다른 차량(V2V, Vehicle-to-Vehicle), 도로 인프라(V2I, Vehicle-to-Infrastructure), 보행자(V2P, Vehicle-to-Pedestrian), 네트워크(V2N, Vehicle-to-Network)와 정보를 교환하는 **C-V2X**(Cellular Vehicle-to-Everything) 무선 통신 기술. 표준은 LTE(Long-Term Evolution)-V2X와 5G NR(New Radio) V2X로 나뉨.
- 배경 및 필요성 : 차량의 카메라, 라이다, 레이더는 가려진 사각지대와 악천후에서 인지 한계가 있어, 통신으로 전방의 위험 상황을 미리 공유하는 **협력 인지**가 필요해짐.
- 주요 목적 : 교통사고 감소, 센서 정보 공유와 군집 주행 지원, 저지연 직접 통신을 통한 자율주행 안전성 확보.

## Ⅱ. C-V2X의 특징 및 장점

- 핵심 요약 : 기지국 없이 차량끼리 직접 통신하는 사이드링크와 광역 망에 연결되는 Uu 인터페이스가 결합된 이중 구조.

1. **PC5 사이드링크** (Sidelink) : 기지국 없이 차량과 노변 장치가 직접 통신 → 기지국 커버리지 밖에서도 밀리초 단위의 전달 확보.
2. Uu 인터페이스 : 기지국을 경유하는 광역 링크 → 교통 정보 수집, 도로 위험 경고, 정밀 지도 수신 같은 장거리 서비스 제공.
3. 자원 할당 모드 : 모드 1은 기지국이 전송 자원을 지정해 충돌을 줄이고, 모드 2는 차량이 채널을 감지해 유휴 자원을 스스로 선택 → 기지국 유무에 따른 운용 선택 가능.
4. 5G NR V2X 고급 기능 : 유니캐스트와 그룹캐스트를 지원 → 군집 주행, 센서 데이터 공유, 원격 주행 같은 고대역 저지연 서비스 가능.

## Ⅲ. C-V2X의 구조 (흐름)

- 핵심 요약 : 통신 대상에 따라 사이드링크와 Uu 링크를 나누어 쓰고, 사이드링크 자원은 기지국 지정 방식과 자율 분산 방식으로 나뉘는 구조.

```text
[ C-V2X 통신 대상 ]

차량 ←→ 차량 (V2V, PC5)
차량 ←→ 노변 장치 (V2I, PC5 또는 Uu)
차량 ←→ 보행자 (V2P, PC5)
차량 ←→ 클라우드 (V2N, Uu)
```

```text
[ 사이드링크 자원 할당 모드 ]

모드 1 (기지국 스케줄링)
      ↓
기지국이 전송 자원 지정
      ↓
충돌 가능성 최소화

모드 2 (자율 분산)
      ↓
차량이 채널 센싱
      ↓
유휴 자원 스스로 선택
```

## Ⅳ. DSRC/WAVE, LTE-V2X, 5G NR V2X의 비교

- 핵심 요약 : 무선랜 기반의 DSRC(Dedicated Short-Range Communications)/WAVE는 기술 진화가 멈춘 상태이고, 셀룰러 기반 C-V2X는 5G NR V2X로 승계되며 기능이 확장되는 흐름.
- 선택 기준 : 기존 장비 호환이 중요하면 DSRC/WAVE 자산을 검토하고, 협력 주행과 장기 확장이 목표이면 셀룰러 기반 C-V2X를 기준으로 삼음.

| 비교 축 | DSRC/WAVE (WAVE: Wireless Access in Vehicular Environments, IEEE 802.11p) | LTE-V2X (3GPP Rel-14/15) | 5G NR V2X (3GPP Rel-16 이후) |
| --- | --- | --- | --- |
| 기반 기술 | 무선랜 기반 CSMA/CA(Carrier Sense Multiple Access with Collision Avoidance) | 4G 셀룰러 기반 SC-FDMA(Single-Carrier Frequency-Division Multiple Access) | 5G 셀룰러 기반 OFDMA(Orthogonal Frequency-Division Multiple Access), 유연한 뉴머롤로지 |
| 지연 특성 | 상대적으로 높음 | 중간 | 초저지연 요구 충족을 목표 |
| 통신 모드 | 브로드캐스트 전용 | 브로드캐스트 중심 | 브로드캐스트, 그룹캐스트, 유니캐스트 |
| 커버리지 | 상대적 근거리 | 확대 | 빔포밍 지원으로 더 확대 |
| 진화 방향 | 기술 진화 정체 | 5G NR V2X로 승계 | 6G V2X 연구로 이어짐 |

## Ⅴ. C-V2X의 한계와 방안

- 핵심 요약 : 혼잡 자원 충돌, 음영 구역 단절, 위조 노드 공격의 세 한계를 혼잡 제어, 중계 구조, 인증 체계로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 모드 2 자원 충돌 | 교차로 등 밀집 구간에서 자원 예약이 겹쳐 패킷 충돌과 전달률 저하 | 혼잡도 기반 전송 전력과 주기 제어, 모드 1 기지국 스케줄링 병행 | 패킷 전달률, 채널 점유율(CBR, Channel Busy Ratio) |
| 음영 구역의 연결 단절 | 터널이나 지하차도에서 기지국 전파가 닿지 않아 원격 관제와 지도 갱신 불가 | 터널 내 노변 장치 집중 배치, 직접 통신 기반 다중 홉(Multi-hop) 중계 | 음영 구간 연결 유지율 |
| 위조 노드 공격 | 악의적 노드가 허위 경고를 보내 연쇄 추돌 유발 (Sybil 공격) | 공개키 기반구조(PKI, Public Key Infrastructure) 인증서 관리 체계(SCMS)와 하드웨어 보안 모듈(HSM, Hardware Security Module) 탑재 | 인증서 검증 실패율, 폐기 목록 반영 지연 |

## Ⅵ. C-V2X에 대한 기술사적 제언

- 핵심 요약 : 노변 인프라와 엣지 컴퓨팅을 먼저 확충하고, 인증 체계와 정밀 지도를 함께 고도화하는 순서.
- 고속도로와 주요 도로에 노변 장치와 모바일 에지 컴퓨팅(MEC, Multi-access Edge Computing)을 우선 확충하여 협력 주행의 전국 기반을 마련할 필요가 있다.
- 고속 주행 중에도 대규모 차량의 인증서를 검증하고, 인증서 폐기 목록(CRL, Certificate Revocation List)을 즉시 동기화하는 인증 체계를 SCMS 기반으로 고도화하는 것이 선행되어야 한다.
- 차량의 인지 데이터와 노변 센서 데이터를 엣지 클라우드의 동적 정밀 지도(LDM, Local Dynamic Map)에 통합하는 파이프라인을 구축하면, 레벨 4 이상 자율주행의 인지 공백을 보완할 수 있다.

## Ⅶ. 결론

- 핵심 요약 : C-V2X는 기지국 중심의 셀룰러 기술을 차량 간 직접 통신으로 확장해 협력 자율주행의 기반을 만드는 기술.
- 시사점 : 통신 성능만큼 인증 체계와 인프라 확충이 함께 갖춰져야 협력 주행의 실효성이 확보됨.
