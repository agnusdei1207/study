## Ⅰ. C-V2X(Cellular Vehicle-to-Everything)의 개요

- 개념 : **3GPP** 셀룰러 이동통신 표준(LTE(Long-Term Evolution)-V2X, 5G-NR(New Radio) V2X)을 기반으로 차량이 다른 차량(V2V), 도로변 인프라(V2I), 보행자(V2P), 네트워크/클라우드(V2N)와 실시간으로 데이터를 교환하여 협력 자율주행과 차세대 지능형 교통체계(C-ITS)를 구현하는 무선 통신 기술.
- 배경 및 필요성 : 차량 자체 센서(카메라, 라이다, 레이더)는 시야각 밖(Non-Line-of-Sight) 사각지대나 악천후 환경에서 인지 한계가 명확하므로, 센서의 한계를 넘어 전방 수백 미터의 도로 위험 상황을 공유하는 통신 기반 협력 인지가 필수화됨.
- 핵심 목적 : 도로 교통사고 제로화, 차량 간 고용량 센서 공유(Sensor Sharing) 및 군집주행(Platooning) 지원, 초저지연 직접 통신을 통한 완전 자율주행 안전성 보장.

## Ⅱ. C-V2X(Cellular Vehicle-to-Everything)의 핵심 아키텍처 및 동작 메커니즘

C-V2X는 기지국 없이 차량 간 직접 통신하는 PC5(사이드링크) 인터페이스와 광역 통신망과 연결되는 Uu 인터페이스의 이중화된 통신 아키텍처로 동작함.

```text
[ C-V2X 이중 통신 인터페이스 아키텍처 및 V2X 통신 유형 ]

                       [ 5G 코어망 / 교통 관제 클라우드 ]
                                       ▲
                                       │ (광역 도로 상황, 원격 관제)
                                       ▼
                       [ 5G 기지국 (gNodeB / Uu Interface) ]
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
[ 인프라 통신 (V2N / V2I: Uu 링크) ]                   [ 인프라 통신 (V2N: Uu 링크) ]
+------------------------------------+               +------------------------------------+
| 노변 기지국 / RSU (Roadside Unit)  |               | 일반 주행 차량 B                  |
+------------------------------------+               +------------------------------------+
       ▲                                                    ▲
       │ (V2I)                                              │ (V2V)
       ▼                                                    ▼
+-----------------------------------------------------------------------------------------+
| 자율주행 차량 A (단말: OBU)                                                             |
| - 기지국 없는 직결 직접 통신 (PC5 Sidelink): 밀리초 극저지연 통신                       |
+-----------------------------------------------------------------------------------------+
       │ (V2P)                                              │ (V2V)
       ▼                                                    ▼
[ 보행자 스마트폰 (Pedestrian) ]                     [ 전방 트럭 (군집주행 Platooning) ]
```

- **PC5 사이드링크(Sidelink) 인터페이스** : 기지국 커버리지 밖(Out-of-Coverage)에서도 차량 간, 차량-RSU 간 5.9GHz 전용 대역에서 1~10ms 이내로 직접 통신하는 단거리 직결 링크.
- **Uu 인터페이스** : 상용 셀룰러 망 기지국(gNB)을 경유하여 광역 교통 정보 수집, 도로 위험 경고, 정밀 지도(HD Map) 다운로드 및 원격 제어를 수행하는 장거리 링크.
- 사이드링크 자원 할당 모드 (Mode 1 vs Mode 2) :
  - **Mode 1 (5G NR)** : 기지국이 차량의 PC5 전송 무선 자원을 스케줄링하여 충돌 원천 차단.
  - **Mode 2 (자율 분산)** : 기지국 없이 차량이 스스로 채널을 센싱하여 유휴 자원을 예약 선택.
- **5G NR-V2X 고급 서비스** : 유니캐스트/그룹캐스트를 지원하여 군집주행(Platooning), 센서 데이터 공유(Sensor Sharing), 원격 주행(Teleoperated Driving) 등 고대역 저지연 서비스 지원.

## Ⅲ. C-V2X(Cellular Vehicle-to-Everything)의 세부 구성 요소 및 비교 분석

| 비교 항목 | DSRC / WAVE (IEEE(Institute of Electrical and Electronics Engineers) 802.11p) | LTE-V2X (3GPP Rel-14/15) | 5G NR-V2X (3GPP Rel-16/17) |
|---|---|---|---|
| 기반 통신 기술 | 무선랜 (Wi-Fi 기반 CSMA/CA) | 4G 셀룰러 (SC-FDMA) | 5G 셀룰러 (OFDMA(Orthogonal Frequency-Division Multiple Access), 유연한 뉴머롤로지)|
| 전송 지연 (Latency) | 10 ~ 20 ms | 10 ~ 20 ms | 1 ~ 3 ms (초저지연) |
| 전송 속도 / 대역폭 | 최대 27 Mbps (10MHz 채널) | 고속 (20MHz) | 초광대역 고속 |
| 통신 모드 | 브로드캐스트 전용 | 브로드캐스트 위주 | 브로드캐스트, 그룹캐스트, 유니캐스트|
| 커버리지 반경 | 상대적 근거리 | 확대 | 더 확대 (빔포밍 지원) |
| 진화 지속성 | 기술 진화 중단 (정체) | 5G NR-V2X로 자연스러운 승계 | 6G V2X로 지속 발전 로드맵 보유 |

- 레거시 **WAVE** 방식 대비 C-V2X는 통신 거리와 신뢰성이 우수하며, 특히 5G NR-V2X로 진화하면서 군집주행 및 원격 자율주행을 위한 초저지연 센서 공유 능력을 완비함.

## Ⅳ. C-V2X(Cellular Vehicle-to-Everything)의 주요 한계점 및 해결 방안

- 고밀도 도심 정체 구역에서 Mode 2 자율 센싱 무선 자원 충돌 :
  - 한계점 : 교차로 등 수백 대 차량 밀집 시 센싱 윈도우 내 동시 자원 예약으로 패킷 충돌 및 PDR(패킷 전달률) 저하.
  - 해결 방안 : 혼잡도 기반 송신 전력/전송 주기 제어(CBR 기반 동적 제어) 및 기지국 스케줄링(Mode 1) 적극 병행.
- 통신 음영 지역(터널, 지하차도)에서의 V2N 광역망 연결 단절 :
  - 한계점 : Uu 셀룰러 기지국 전파 미도달 구역에서 원격 관제 및 클라우드 동적 지도 갱신 불가.
  - 해결 방안 : 터널 내 노변 RSU 집중 배치 및 PC5 기반 멀티홉(Multi-hop) 릴레이 통신 구성.
- 차량 사칭, 위치 위조(Sybil Attack) 및 제어권 탈취 사이버 위협 :
  - 한계점 : 악의적 노드가 허위 브레이크 경고를 송신할 경우 대형 연쇄 추돌 사고 유발 가능.
  - 해결 방안 : V2X 전용 PKI(Public Key Infrastructure) 기반 보안 인증서 관리 체계(SCMS) 및 차량 하드웨어 보안 모듈(HSM, Hardware Security Module) 탑재 의무화.

## Ⅴ. C-V2X(Cellular Vehicle-to-Everything) 적용 및 발전을 위한 기술사적 제언

- 대한민국 C-ITS 표준 단일화(LTE-V2X 상용화 및 5G NR-V2X 전환)에 따른 전국망 구축 가속 : 고속도로 및 전국 주요 도로에 RSU와 모바일 에지 컴퓨팅(MEC, Multi-access Edge Computing) 인프라 조기 확충 권장.
- 차량-사물 인증을 위한 국가 V2X 보안 인증 관리 체계(SCMS) 고도화 : 대규모 차량이 고속 주행 중에도 인증서를 실시간 검증하고 폐기 목록(CRL, Certificate Revocation List)을 즉시 동기화하는 초저지연 보안 인프라 구축 필수.
- 자율주행 레벨 4/5 상용화를 위한 동적 정밀 지도(LDM) 연계 : 차량의 인지 센서 데이터와 도로 인프라의 CCTV(Closed-Circuit Television)/라이다 데이터를 엣지 클라우드 LDM에 실시간 통합하는 데이터 파이프라인 수립.
