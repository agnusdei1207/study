## 지식 로드맵 내 현재 위치

지식 위치: 네트워크 → 비지상·이동통신 → **위성·공중·지상 연계**

## 30초 인출

- 본질: **SATIN** : 위성·공중 플랫폼·지상망을 연계해 한 종류의 망만으로 닿기 어려운 지역까지 접속을 제공하는 통합망 개념
- 메커니즘: 세 접속 영역의 커버리지·지연·용량을 비교해 연결을 선택하고 이동 시 경로를 전환
- 통찰: 지상망의 물리적 음영 지역을 극복하고 3차원 입체 공간 커버리지를 구현하기 위해 LEO 위성, HAPS, 지상 5G/6G 기지국 간 동적 핸드오버 및 공통 코어망 기반 통합 라우팅 체계 구축이 필수적임.

<details>
<summary>핵심 용어</summary>

- **SATIN(Satellite-Aerial-Terrestrial Integrated Network)** : 위성·공중·지상 통신망을 통합해 접속 범위를 넓히는 연구·설계 개념
- **NTN(Non-Terrestrial Network)** : 위성·고고도 플랫폼 등을 활용하는 비지상 접속망
- **HAPS(High-Altitude Platform Station)** : 높은 고도에서 통신 서비스를 제공하는 공중 플랫폼
- **LEO(Low Earth Orbit)** : 지구에 비교적 가까운 저궤도 위성의 궤도 범주
- **핸드오버(Handover)** : 단말의 연결을 다른 셀·빔·접속망으로 옮기는 절차
- **GEO(Geostationary Earth Orbit)** : 지표의 일정 지역에 대해 상대적으로 고정된 위치를 유지하는 정지궤도

</details>

## 2~4교시 25점 답안

## Ⅰ. 위성·공중·지상 통합망(SATIN)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 저궤도·정지궤도 위성망(Space), 성층권 통신 플랫폼·무인기(Aerial), 지상 이동통신망(Terrestrial)을 단일 통신 인프라로 유기적 결합한 3차원 입체 통합 네트워크 |
| 목적 | 해상, 극지, 도서산간 등 지상 기지국 미도달 음영 해소, UAM·자율선박 대상 전 지구적(Ubiquitous) 초공간 3D 통신 서비스 제공 |

## Ⅱ. 위성·공중·지상 통합망(SATIN)의 특징

| 특징 | 상세 내용 |
|---|---|
| 3차원 초공간 통신 | 지표면 2D 평면 커버리지를 지상~성층권(20km)~저궤도(500~2000km) 공간으로 수직 확장 |
| 이종망 협력 제어 | 전파 지연 및 채널 특성이 서로 다른 다계층 링크를 소프트웨어 정의 기반으로 동적 스케줄링 |
| 글로벌 상시 커버리지| 대규모 지진·해일 등 지상망 괴멸 재난 상황에서도 위성/공중 플랫폼을 통한 비상 통신망 유지 |
| 단일 코어망 연계 | 3GPP Rel-17/18 기반 5G Core(5GC)를 공통 제어 평면으로 활용하여 E2E 세션 연속성 보장 |

## Ⅲ. 위성·공중·지상 통합망(SATIN)의 체계·프로세스

**SATIN 3차원 입체 계층 구조 및 데이터 흐름**

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 우주 계층 (Space Tier) : 고도 500km ~ 36,000km ]                     │
│   GEO (정지궤도, 광역 방송) ◄── ISL (위성간 레이저 링크) ──► LEO (저궤도)│
│                                      │                                 │
│   ▼ 피더 링크 (Feeder Link)           ▼ 서비스 링크 (Service Link)      │
│                                                                        │
│ [ 공중 계층 (Aerial Tier) : 고도 10km ~ 20km ]                         │
│   HAPS (성층권 비행선/드론), UAM 통신 릴레이 노드                      │
│                                      │                                 │
│   ▼ 액세스 링크 (Access Link)        ▼ 백홀 링크 (Backhaul Link)       │
│                                                                        │
│ [ 지상 계층 (Terrestrial Tier) : 지표면 ~ 고도 100m ]                   │
│   지상 5G/6G 기지국 (gNodeB) ── 코어망 (5GC) ── 위성 관제 게이트웨이   │
│   단말 (스마트폰, 자율주행차, UAM, 원양 선박)                          │
└────────────────────────────────────────────────────────────────────────┘
```

| 계층 구분 | 주요 플랫폼 | 고도 및 특징 | 핵심 역할 |
|---|---|---|---|
| **우주 계층** | LEO, MEO, GEO 위성군 | 500km ~ 36,000km | 전 지구적 글로벌 광역 커버리지 및 대용량 원격 백홀 제공 |
| **공중 계층** | HAPS, 드론, 고고도 비행체 | 10km ~ 20km (성층권) | 국지적 트래픽 집중 영역 보조, 저지연(수 ms) 준지상 커버리지 |
| **지상 계층** | 매크로/스몰셀 기지국, 5GC | 지표면 | 도심지 초고속·초저지연(eMBB/URLLC) 고밀도 데이터 서비스 제공 |

## Ⅳ. 위성·공중·지상 통합망(SATIN)의 종류·비교

| 비교 항목 | 지상 이동통신망 (TN) | 비지상 위성망 (NTN/LEO) | 통합망 (SATIN) |
|---|---|---|---|
| **커버리지 영역** | 전 세계 육지 면적의 약 20% | 해상·사막 포함 전 지구 광역 | 지상 고밀도 + 글로벌 100% 전 영역 |
| **전파 전송 지연** | 극저지연 (1 ~ 10ms) | 중지연 (LEO 20~40ms, GEO 250ms)| 트래픽 특성별 최적 계층 동적 분기 |
| **단말 이동 속도** | 최대 500km/h (고속철도) | 초고속 궤도 비행 (7.5km/s) | 고속 위성 빔 스위칭 및 다계층 핸드오버 |
| **망 구축 비용** | 인구 밀집지 대비 경제적 | 발사체 및 위성군 초기 투자 막대| 지상-위성 자원 공유로 총 소유비용 최적화 |

## Ⅴ. 위성·공중·지상 통합망(SATIN)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 저궤도 위성의 고속 이동(7.5km/s)으로 인한 빈번한 핸드오버 및 도플러 천이(Doppler Shift) 발생 | 이동성 예측 기반 사전 조건부 핸드오버(CHO) 및 지연/주파수 오프셋 사전 보상 알고리즘 적용 |
| 이종 다계층 간 링크 전송 지연차(지상 1ms vs 위성 30ms)로 인한 패킷 순서 역전 현상 | 세션 관리 함수(SMF) 기반 다중 경로 제어(MPTCP, QUIC) 및 패킷 재정렬 버퍼 최적화 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
UAM(도심항공교통) 및 자율운항선박 관제 인프라 구축 시, 고도별 전파 간섭 모델을 사전에 시뮬레이션하고 지상 기지국 상향 틸팅 안테나와 LEO 위성 수신 빔의 커버리지 중첩 영역에 대해 지능형 빔포밍 스케줄링을 필수 수립.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ SATIN 공통 5G Core(5GC) 기반 통합 제어 평면 아키텍처 ]              │
│                                                                        │
│   [ 단말 (UE) ]                                                        │
│     ├─── 3GPP Uu (지상파) ────► [ 지상 gNodeB ] ─────┐                │
│     │                                                 │                │
│     └─── 3GPP NTN Uu ────────► [ LEO Satellite ]     │                │
│                                       │ (Feeder Link) │                │
│                                       ▼               │                │
│                                [ NTN Gateway ]        │                │
│                                       │               │                │
│            ┌──────────────────────────┴───────────────┘                │
│            ▼ (N2 / N3 Interface)                                       │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ 통합 5G 코어망 (Unified 5GC) ]                               │   │
│   │   - AMF (통합 이동성 관리)   - SMF (이종망 세션 제어)          │   │
│   │   - UPF (사용자 데이터 평면) - UDM (통합 가입자 인증)          │   │
│   └────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 위성 궤도 유형 | 궤도 고도 | 편도 전파 지연 | 위성 수명 | 주 용도 |
|---|---|---|---|---|
| **LEO (저궤도)** | 500 ~ 2,000 km | 10 ~ 25 ms | 5 ~ 7년 | 초고속 인터넷 백홀, 저지연 실시간 관제 통신 |
| **MEO (중궤도)** | 2,000 ~ 35,786 km | 50 ~ 150 ms | 10 ~ 12년 | 위성 항법 시스템(GPS, Galileo), 해상 통신 |
| **GEO (정지궤도)** | 35,786 km | 약 250 ms | 15년 이상 | 기상 관측, 광역 위성 방송, 비상 백업 통신 |
