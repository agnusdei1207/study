## 답안 골격
```text
[VLAN] ◀━━ 머리: Ⅶ 내 의견 (IEEE 802.1Q 태깅 기반 세그멘테이션 및 보안 구역 마이크로 세분화)
 ┃
 ┣━ Ⅰ 개요 ───── 물리적 스위치 환경의 브로드캐스트 과부하·보안 결여 → 논리적 L2 브로드캐스트 도메인 분할
 ┣━ Ⅱ 특징 ───── 브로드캐스트 도메인 격리, 보안성 강화, 물리 배선 독립성, 비용 절감
 ┣━ Ⅲ 구조 ───── 액세스 포트(단일 VLAN) + 트렁크 포트(다중 VLAN) + IEEE 802.1Q 프레임 태그(4바이트)
 ┣━ Ⅳ 흐름 ───── ① 단말 프레임 수신 → ② 스위치 802.1Q VLAN 태그 부착 → ③ 트렁크 링크 통과 → ④ 태그 제거 후 수신 단말 전달
 ┣━ Ⅴ 비교 ───── 포트 기반 vs MAC 기반 vs 프로토콜 기반 VLAN (단순성 vs 이동성 vs 프로토콜 분리)
 ┗━ Ⅵ 실무 ───── VLAN 호핑(VLAN Hopping) 공격 / 4,096개 VLAN ID 확장 한계(VXLAN 등장 배경)
```
- 필수 키워드: 가상 LAN · 브로드캐스트 도메인 격리 · IEEE 802.1Q · 트렁크(Trunk) 포트 · VID(12비트, 4096개) · Inter-VLAN 라우팅
- 기출: 120회 1교시: "VLAN(Virtual LAN)의 개념, 필요성, 분류 방식 및 IEEE 802.1Q 프레임 태깅 구조를 설명하시오." → Ⅰ~Ⅴ

## 한 줄 본질
- 하나의 스위치에 연결된 모든 PC가 동일한 L2 브로드캐스트 폭풍과 해킹 패킷에 무방비 노출되는 문제 → 물리적 케이블 공사 없이 스위치 포트마다 논리적 가상 네트워크(VLAN ID)를 부여해 브로드캐스트 도메인을 완벽 격리 → 네트워크 보안성과 대역폭 효율 극대화 / 서로 다른 VLAN 간 통신을 위해 별도의 L3 라우팅 장비가 반드시 필요

## 핵심 그림
```text
[ VLAN 트렁크(Trunk) 링크 및 IEEE 802.1Q 태그 구조 ]

  [ 스위치 A ] ================= (트렁크 링크) ================= [ 스위치 B ]
    |      |       (여러 VLAN 프레임이 802.1Q 태그를 달고 통과)       |      |
    v      v                                                         v      v
  VLAN 10 VLAN 20                                                  VLAN 10 VLAN 20
  (인사팀)(개발팀)                                                 (인사팀)(개발팀)

[ IEEE 802.1Q 태그 헤더 (4바이트 추가) ]
+-------------------+-------------------+-------------------+-------------------+
| 이더넷 목적지/출발지 | 802.1Q 태그 (4B)  | 원래 EtherType    | 데이터 페이로드   |
+-------------------+---------+---------+-------------------+-------------------+
                              |
              +---------------+---------------+
              |                               |
              v                               v
    TPID (2바이트, 0x8100)            TCI (2바이트)
                                      - Priority (3비트: CoS 우선순위)
                                      - CFI/DEI (1비트: 드롭 적격)
                                      - VLAN ID (12비트: 0~4095, 총 4096개)
```

## 핵심 용어
- 액세스 포트(Access Port): 단 하나의 특정 VLAN에만 속하는 포트로, 일반 PC나 서버가 연결되며 패킷에 태그가 붙지 않은 일반 이더넷 프레임으로 송수신
- 트렁크 포트(Trunk Port): 스위치와 스위치, 또는 스위치와 라우터를 연결하는 포트로, 여러 서로 다른 VLAN의 트래픽을 식별 태그(802.1Q)를 붙여 단일 선로로 다중 전송
- Inter-VLAN 라우팅: 서로 다른 VLAN은 L2 레벨에서 철저히 차단되므로, 두 VLAN 간에 통신을 허용하려면 L3 스위치나 라우터(Router-on-a-stick)를 거쳐 IP 라우팅을 수행하는 작업

## 핵심 통찰
- VLAN은 "스위치를 물리적으로 톱으로 잘라 여러 대의 스위치로 나누어 쓰는 것"과 수학적으로 완전히 동일한 논리적 분할 효과를 제공
- 이더넷 프레임에 4바이트 802.1Q 헤더가 중간에 끼어들어가므로 최대 프레임 크기가 1518바이트에서 1522바이트(Baby Giant Frame)로 늘어나며 구형 장비는 이를 인식 못해 드롭 가능
- 12비트 VLAN ID의 한계로 인해 생성 가능한 최대 가상망 개수가 4,096개로 제한되어, 대규모 멀티테넌트 클라우드 데이터센터에서는 24비트 ID를 쓰는 VXLAN으로 진화

## 이웃 토픽과 구분
- 서브넷 vs VLAN: 서브넷은 L3 네트워크 계층에서 IP 주소를 기준으로 분할 / VLAN은 L2 데이터링크 계층에서 MAC 브로드캐스트 도메인을 기준으로 분할 (실무에서는 보통 1 VLAN = 1 서브넷 1:1 매핑)

## 문제·원인·대책
- 적용 상황: VLAN 호핑(VLAN Hopping) 공격을 통한 비인가 네트워크 침입
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 스위치 스푸핑 공격으로 타 VLAN 패킷 도청 | 스위치 포트가 동적 트렁킹 프로토콜(DTP) 자동 협상 모드로 방치 | 일반 사용자 포트를 무조건 Access 모드로 고정 (`switchport mode access`) | 비인가 단말의 가짜 트렁크 협상 시도를 원천 무력화 |
| 이중 태깅(Double Tagging) 공격으로 다른 VLAN 침투 | 내부 태그와 외부 태그를 중첩하여 스위치 태그 제거 취약점 악용 | 기본 네이티브 VLAN(Native VLAN 1)을 미사용 번호로 변경 | 네이티브 VLAN 경유 패킷 조작 우회 공격 차단 |

## 이렇게 출제된다
- 제120회 1교시: "VLAN(Virtual LAN)의 개념, 필요성, 분류 방식 및 IEEE 802.1Q 프레임 태깅 구조를 설명하시오." → 요구 포인트: Ⅰ 개념 + Ⅱ 필요성 + Ⅲ 802.1Q 4B 구조도(TPID, TCI, VID) + Ⅴ 분류 방식

## 내 의견
- [제로 트러스트 환경에서의 마이크로 세그멘테이션 진화] 전통적 VLAN 기반 네트워크 분리는 동일 VLAN 내부의 횡적 이동(Lateral Movement) 공격에 무방비 → 나라면: 거시적 부서 분리는 VLAN으로 1차 격리하되, 내부 워크로드 간 통신은 가상화 하이퍼바이저 수준에서 호스트 방화벽으로 개별 제어하는 마이크로 세그멘테이션(Micro-segmentation)을 중첩 적용하여 보안 심층화
