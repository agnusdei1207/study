## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 이동통신망 진화 → 5G-Advanced

## 30초 인출

- 본질: **5G-Advanced** 는 기존 5G 시스템을 성능·기능 측면에서 확장하는 3GPP의 진화 단계
- 메커니즘: Release 18을 첫 단계로 무선 성능, 단말·IoT, 비지상망 등 기존 기능을 개선하고 Release 19에서 후속 기능 확장
- 통찰: 5G와 6G 사이의 기술적 가교로서 3GPP Release 18/19를 통해 인공지능(AI/ML)을 무선망 전반에 기본 내재화하고 단말 경량화(RedCap) 및 초정밀 위치 추적과 위성 통합(NTN)을 완성하는 고도화 이동통신 표준임.

<details>
<summary>핵심 용어</summary>

- **5G-Advanced** : 3GPP Release 18부터 시작된 5G 시스템의 진화 단계.
- **3GPP (3rd Generation Partnership Project)** : 이동통신 기술 규격을 개발하는 표준화 협력체.
- **Release 18 (Rel-18)** : 3GPP의 첫 5G-Advanced 릴리스.
- **Release 19 (Rel-19)** : Rel-18에 이은 두 번째 5G-Advanced 릴리스.
- **RedCap (Reduced Capability)** : 기능·성능 범위를 낮춰 복잡도와 전력 요구를 줄인 5G NR 단말 범주.
- **NTN (Non-Terrestrial Network)** : 위성 등 비지상 노드를 이용하는 이동통신망 구성.
- **AI/ML (Artificial Intelligence / Machine Learning)** : 무선망 데이터·모델을 이용해 성능 최적화 가능성을 다루는 기술 영역.
- **XR (Extended Reality)** : 가상·증강·혼합 현실을 포괄하는 몰입형 서비스 범주.

</details>

## 2~4교시 25점 답안

## Ⅰ. 5G-Advanced의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 3GPP Release 18을 기점으로 5G 상용망의 성능 한계를 극복하고 6G 핵심 기술을 선행 실증하기 위해 인공지능(AI/ML)과 위성 통신을 통합한 차세대 5.5G 이동통신 기술 표준 |
| 목적 | B2C 데이터 속도 개선을 넘어 B2B 제조·물류 특화 산업망 완성, 저비용 IoT(RedCap) 확산 및 몰입형 확장현실(XR) 무선 품질 극대화 |

## Ⅱ. 5G-Advanced의 특징

| 특징 | 상세 내용 |
|---|---|
| AI/ML 무선망 내재화 | 무선 에어 인터페이스(L1/L2) 및 기지국 스케줄링에 딥러닝 모델을 직접 적용하여 빔포밍 최적화 |
| RedCap(경량 단말) 진화| 스마트워치, 산업용 센서를 위해 대역폭(20MHz)과 안테나 수를 줄여 단말 원가와 배터리 소모 대폭 절감 |
| 몰입형 XR 특화 최적화| 대용량 비디오 프레임 버스트 특성에 맞추어 지터(Jitter)를 제어하고 포비디드 렌더링 지원 |
| 비지상망(NTN) 고도화| 정지궤도 및 저궤도 위성을 통한 단말 직접 통신(Direct-to-Cell) 성능 및 핸드오버 절차 완성 |

## Ⅲ. 5G-Advanced의 체계·프로세스

**5G-Advanced 4대 기술 진화 프레임워크**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 5G-Advanced 핵심 기술 영역 ]                  │
│                                                                        │
│   ┌───────────────────────────┬───────────────────────────┐            │
│   ▼                           ▼                           ▼            │
│ [ AI / ML 내재화 ]        [ RedCap 진화 (eRedCap) ]   [ 몰입형 XR 최적화 ]│
│  - 무선 채널 피드백 압축   - 대역폭 20MHz/5MHz 축소    - 프레임 단위 스케줄│
│  - 빔 관리 및 이동성 예측  - 단말 배터리 수명 10년     - 극저지연 지터 제어│
│  - 기지국 에너지 동적절감  - 웨어러블/CCTV 대중화      - 포비디드 스트리밍 │
│   ┌───────────────────────────┴───────────────────────────┐            │
│   ▼                                                       ▼            │
│ [ 5G NTN 비지상 위성망 ]                              [ 센싱 통신 융합 ] │
│  - LEO 위성 직접 통신 (음성/데이터)                   - 기지국 전파 기반  │
│  - 글로벌 100% 음영 제로화                            - 드론/장애물 탐지  │
└────────────────────────────────────────────────────────────────────────┘
```

| 진화 영역 | 핵심 기술 요소 | 5G 대비 주요 개선 성과 |
|---|---|---|
| **무선 AI (Air Interface AI)**| AI 기반 CSI(채널상태정보) 피드백 압축 | 업링크 피드백 오버헤드 50% 절감, Massive MIMO 빔 정확도 향상 |
| **RedCap (Reduced Capability)**| eRedCap (Peak ~10Mbps, 5MHz 대역폭) | 기존 LTE Cat-1/Cat-4 대체, 모듈 단가 80% 절감 |
| **XR 최적화** | PDU Set 기반 패킷 중요도 차등 스케줄링 | XR 안경 렌더링 지연시간 5ms 이하 보장, 멀미 현상 방지 |
| **상향링크 강화 (Uplink)** | Tx Switching, 다중 반송파 동시 집약 | 고화질 머신비전 전송을 위한 업링크 처리율 2배 향상 |

## Ⅳ. 5G-Advanced의 종류·비교

| 비교 항목 | 초기 5G (Rel-15/16) | 5G-Advanced (Rel-18/19) | 6G 이동통신 (예정) |
|---|---|---|---|
| **AI 통합 방식** | 코어망 사후 분석 (NWDAF) | **무선 에어(PHY/MAC)에 AI 직접 내재화** | 완전한 E2E AI-Native 네트워크 |
| **사물인터넷(IoT)**| NB-IoT 또는 고가 5G 모뎀 양극화 | **중간급 실용적 IoT (RedCap/eRedCap)** | 무전원 Zero-Energy IoT |
| **위성 통신 지원** | 지상망 중심 (Rel-17 초기 NTN) | **스마트폰 위성 직접 연결 고도화** | 지상-위성 3차원 입체 통합망 |
| **네트워크 에너지**| 정적 기지국 전원 관리 | **트래픽 예측 기반 마이크로 슬립** | 탄소 중립 제로 에너지 통신 |
| **산업 포지션** | 스마트폰 상용화 중심 | **B2B 제조/로봇/XR 산업 전면 확산** | 디지털 트윈, 홀로그램 융합 |

## Ⅴ. 5G-Advanced의 한계와 방안

| 한계 | 방안 |
|---|---|
| 이종 벤더 기지국과 단말 간 AI 모델 구조가 상이할 경우 채널 추정 파라미터 불일치로 통신 단절 발생 | 3GPP 표준 기반 AI 수명주기 관리(LCM) 프레임워크 준수 및 원시 데이터 기반 안전 폴백(Fallback) 보장 |
| XR 기기의 고속 움직임 시 헤드 트래킹 데이터와 수신 비디오 프레임 간 지연 불일치로 인한 어지럼증 유발 | 애플리케이션 계층과 L2 MAC 스케줄러 간 긴밀한 크로스 레이어 연동을 통해 프레임 조각(PDU Set) 단위 우선순위 전송 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
스마트 물류창고 및 제조 공장 내 무선 센서 네트워크 도입 시, 고가의 풀스펙 5G 단말 대신 Release 18 RedCap 전용 산업용 라우터를 선정하여 인프라 구축 비용을 60% 이상 절감하고, 공장 천장 조명 레일에 소형 분원 스몰셀 안테나를 배치.

### 2. 아키텍처 및 상세 메커니즘

┌────────────────────────────────────────────────────────────────────────┐
│ [ 5G-Advanced XR 전송을 위한 PDU Set 스케줄링 메커니즘 ]              │
│                                                                        │
│   단일 비디오 프레임 (I-Frame) ──► [ 패킷 분할: PDU 1, PDU 2, PDU 3 ]    │

│                                                                        │
│   [ 5G-Advanced PDU Set 스케줄러 : 프레임 단위 통합 인지 ]            │

### 3. 기술 유형 및 비교 평가
| 단말 유형 | 대역폭 | 안테나 수 | 최대 하향 속도 | 배터리 수명 |
|---|---|---|---|---|
| **기존 5G (eMBB)** | 100 MHz | 4x4 MIMO | 수 Gbps | 수일 단위 |
| **RedCap (Rel-17)** | 20 MHz | 1x2 또는 2x2 | 150 ~ 220 Mbps | 수개월 ~ 1년 |
| **eRedCap (Rel-18)**| 5 MHz | 1x1 SISO | 약 10 Mbps | 수년 ~ 10년 |
