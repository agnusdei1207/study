## 30초 인출

- 본질: **6G 표준화** : 차세대 이동통신의 사용 시나리오·성능 요구·무선 기술을 국제 절차로 합의하는 작업
- 메커니즘: ITU-R의 IMT-2030 프레임워크·평가 절차와 3GPP의 6G 기술 연구·규격 개발을 구분
- 통찰: 5G의 통신 속도 한계를 극복하고 디지털 트윈, 초실감 홀로그램 및 전 지구 3차원 입체 통신을 실현하기 위해 Sub-THz 대역과 AI 내생망 및 통신-센싱 융합(ISAC)을 표준 프레임워크로 정립하는 것이 6G의 본질임.

<details>
<summary>핵심 용어</summary>

- **IMT-2030(International Mobile Telecommunications-2030)** : ITU-R의 2030년대 이동통신 체계에 대한 프레임워크·표준화 명칭
- **ITU-R(International Telecommunication Union Radiocommunication Sector)** : 국제전기통신연합의 전파통신 부문
- **3GPP(3rd Generation Partnership Project)** : 이동통신 시스템 규격을 개발하는 표준화 협력체
- **M.2160** : IMT-2030의 개발 방향과 여섯 사용 시나리오를 제시한 ITU-R 권고
- **ISAC(Integrated Sensing and Communication)** : 통신과 주변 환경의 감지 기능을 함께 연구하는 기술 방향
- **RIT(Radio Interface Technology)** : IMT 평가에 제출하는 무선 인터페이스 기술

</details>

## 2~4교시 25점 답안

## Ⅰ. 6G 표준화와 IMT-2030의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | ITU-R의 IMT-2030 비전과 3GPP 표준화 로드맵을 바탕으로 2030년경 상용화를 목표로 추진 중인 최대 1Tbps 전송속도와 0.1ms 무선 지연을 제공하는 차세대 이동통신 기술 표준 |
| 목적 | 인간·사물·가상 공간의 완벽한 융합(디지털 트윈), 몰입형 XR/홀로그램 서비스, 자율 비행체 입체 제어 및 탄소 중립 통신 인프라 달성 |

## Ⅱ. 6G 표준화와 IMT-2030의 특징

| 특징 | 상세 내용 |
|---|---|
| Sub-THz 주파수 개척| 100GHz ~ 300GHz 극초고주파 대역의 수십 GHz 광대역폭을 활용하여 Tbps급 전송 속도 구현 |
| 6대 사용 시나리오 | 기존 5G 3대 시나리오(eMBB/URLLC/mMTC) 고도화 + AI융합, 센싱융합, 유비쿼터스 연결 신설 |
| 통신·센싱 융합(ISAC)| 통신 신호를 레이더처럼 활용하여 주변 환경의 위치, 형상, 움직임을 감지하는 내생 센싱 구현 |
| AI-Native 아키텍처| 프로토콜 설계 단계부터 인공지능이 무선 인터페이스 및 코어망 전체에 기본 내장(Native) |

## Ⅲ. 6G 표준화와 IMT-2030의 체계·프로세스

**ITU-R IMT-2030 6대 사용 시나리오 및 15대 성능 지표 체계**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ IMT-2030 6대 핵심 시나리오 ]                  │
│                                                                        │
│                      [ 몰입형 통신 (Immersive Comm) ]                  │
│                             (초실감 XR, 홀로그램)                      │
│                                      ▲                                 │
│                                     / \                                │
│                                    /   \                               │
│      [ 유비쿼터스 연결 ]          /     \        [ 초고신뢰·저지연 ]   │
│     (위성/NTN 연계 입체망)       /       \       (원격 수술, 자율주행) │
│           ▲                    /  IMT-2030 \                    ▲      │
│           │                   /    비전     \                   │      │
│           │                  /               \                  │      │
│           ▼                 /                 \                 ▼      │
│   [ 대규모 연결 (mMTC+) ]  /───────────────────\  [ AI와 통신의 결합 ] │
│   (스마트시티, 환경 센싱)         ▲                     (생성형 AI 분산)│
│                                  │                                     │
│                   [ 통신과 센싱의 결합 (ISAC) ]                        │
│                   (물리 공간 고정밀 매핑, 제스처)                      │
└────────────────────────────────────────────────────────────────────────┘
```

| 구분 | 주요 성능 지표 (KPI) | 5G (IMT-2020) 대비 성능 목표치 |
|---|---|---|
| **최대 전송 속도** | Peak Data Rate | 20 Gbps ──► **최대 1 Tbps (50배 향상)** |
| **체감 전송 속도** | User Experienced Data Rate | 100 Mbps ──► **최대 1 Gbps (10배 향상)** |
| **무선 전송 지연** | Latency (Over-the-air) | 1 ms ──► **최대 0.1 ms (10배 단축)** |
| **연결 밀도** | Connection Density | 10^6 기기/km^2 ──► **10^7 기기/km^2 (10배 확대)** |
| **위치 정밀도** | Positioning Accuracy | 10 cm 수준 ──► **센티미터(1cm) 및 실내 정밀도** |
| **에너지 효율** | Energy Efficiency | 기준 대비 ──► **2배 이상 향상 및 탄소 중립** |

## Ⅳ. 6G 표준화와 IMT-2030의 종류·비교

| 비교 항목 | 5G (IMT-2020) | 6G (IMT-2030) |
|---|---|---|
| **주요 주파수 대역** | Sub-6GHz (3.5GHz) 및 mmWave (28GHz) | Mid-band (7~24GHz) 및 Sub-THz (100~300GHz) |
| **통신 서비스 영역** | 지표면 중심 2차원 평면 커버리지 | 위성(LEO/GEO) + HAPS + 지상 3차원 입체망 (NTN) |
| **AI 기술의 역할** | 네트워크 일부 기능에 사후 부가(AI for Net) | 설계 단계부터 통신망 전 주기에 내재화(AI-Native) |
| **센싱 기능** | 통신 기능과 별도의 독립 센서 필요 | 통신 전파 신호 자체로 고해상도 환경 센싱(ISAC) |
| **핵심 킬러 서비스** | 4K UHD 영상, 스마트폰 데이터 소비 | 홀로그램 화상회의, 완전자율주행, UAM 교통 관제 |

## Ⅴ. 6G 표준화와 IMT-2030의 한계와 방안

| 한계 | 방안 |
|---|---|
| Sub-THz 대역의 극심한 대기 가스 흡수 감쇠 및 전파 직진성으로 인한 극단적 도달 거리 축소 | RIS(Reconfigurable Intelligent Surface, 지능형 재구성 표면) 및 초다중 안테나(Extreme MIMO) 배치 |
| 글로벌 지정학적 패권 경쟁으로 인한 미국/유럽 vs 중국 진영 간 6G 표준 파편화(Balkanization) 위험 | ITU-R 공식 표준 회의 중심의 공통 권고안 준수 및 3GPP 단일 사실 표준 로드맵 사수 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
대한민국 주도 6G 상용화 전략에 맞추어 국가 전략기술 R&D 과제 수행 시, Sub-THz 대역의 RF 부품 국산화뿐 아니라 7~15GHz 대역(Upper Mid-band)의 광역 커버리지 확보를 병행하고, 통신망 에너지 절감을 위해 기지국 반도체 저전력화(GaN 전력증폭기)를 필수 확보.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 6G 통신·센싱 융합(ISAC) 및 RIS 기반 커버리지 확장 아키텍처 ]         │
│                                                                        │
│   [ 6G 기지국 (gNodeB) ]                                               │
│     ├─── Dual-purpose Waveform 송출 ────────────────┐                  │
│     │   (통신 데이터 + 레이더 탐색 펄스 결합)       │                  │
│     │                                               ▼                  │
│     │                                     [ RIS (지능형 반사 표면) ]   │
│     │                                       - 메타물질 위상 제어      │
│     │                                       - 전파 굴절/반사 각도 조절 │
│     │                                               │                  │
│     │ (반사파 에코 수신)                            ▼ (빌딩 음영 극복) │
│     ▼                                       [ 6G 단말 (차량/UAM) ]     │
│   [ 실시간 3D 환경 점군(Point Cloud) 매핑 ] ── 고화질 홀로그램 수신    │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 6G 신기술 | 핵심 물리 메커니즘 | 해결 과제 | 기대 성과 |
|---|---|---|---|
| **Sub-THz RF** | 100~300GHz 초고주파 소자 | 증폭기 출력 효율 한계 극복 | 단일 링크 100Gbps 이상 전송 |
| **RIS (지능형 표면)** | 메타물질 기반 수동형 반사판 | 실시간 능동 빔 트래킹 알고리즘 | 전력 소모 없는 무선 음영지역 제로화 |
| **ISAC (센싱 융합)** | 레이더 파형 및 통신 프레임 다중화 | 센싱 해상도와 통신 전송률 트레이드오프| 고정밀 도로 교통 및 기상 실시간 탐지 |
