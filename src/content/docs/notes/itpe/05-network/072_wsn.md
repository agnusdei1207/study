## 30초 인출

- 본질: 화산, 산불 감시, 교량처럼 사람이 접근하여 전원선을 깔거나 배터리를 교체할 수 없는 극단적 환경의 계측 불가능성
- 메커니즘: 초소형 센서 노드들이 스스로 자율 애드혹 망을 형성하고 수면/각성을 반복하며 멀티홉으로 데이터를 싱크 노드에 중계

## 핵심 용어

- 싱크 노드(Sink Node / Base Station): 센서 필드 내 수많은 센서 노드들이 보낸 데이터를 최종적으로 집약하여 유선 인터넷, 셀룰러, 또는 위성망을 통해 관제 센터로 전송하는 게이트웨이 장비
- LEACH(Low-Energy Adaptive Clustering Hierarchy): 센서 노드들이 확률적으로 클러스터 헤드(CH) 역할을 주기적으로 돌아가며 맡음으로써 특정 노드에 에너지가 집중 소모되는 것을 방지하는 대표적 분산 라우팅 알고리즘
- 데이터 집약(Data Aggregation / In-network Processing): 중간 노드가 하위 센서 노드들의 개별 패킷을 그대로 전달하지 않고 최댓값, 최솟값, 평균값 등으로 연산·통합하여 패킷 전송 횟수를 획기적으로 줄이는 기술

### Ⅱ. 핵심 특성

- "1비트 무선 전송 에너지 = 1,000번의 CPU 명령어 실행 에너지": 통신용 RF 트랜시버를 켜고 패킷을 쏘는 전력 소모가 MCU 연산보다 수천 배 크므로, 데이터를 덜 보내기 위해 중간 노드에서 복잡한 필터링과 압축 연산을 수행하는 것이 전체 수명 연장에 압도적으로 유리
- 에너지 홀(Energy Hole) 현상의 딜레마: 싱크 노드 바로 주변에 있는 센서 노드들은 자신의 데이터뿐만 아니라 외곽 모든 노드의 패킷을 대신 중계해야 하므로 배터리가 가장 먼저 방전되어, 외곽 노드에 전력이 남아 있어도 망 전체가 고립되는 현상 발생
- 듀티 사이클링(Duty Cycling)이 배터리 10년 수명의 핵심: 센서 노드는 99%의 시간을 완전 절전 수면(Sleep) 상태로 유지하다가, 사전에 동기화된 주기(S-MAC)나 신호 감지(B-MAC) 시에만 1% 미만의 극히 짧은 시간 동안 깨어나(Wakeup) 통신 수행

### Ⅲ. 관련 개념과 구분

- WSN vs 애드혹 네트워크(MANET): MANET(Mobile Ad-hoc Network)은 노트북, 스마트폰 등 이동 단말 간의 고속 IP 통신 중심 / WSN은 정지된 극소형 초저전력 센서 노드들의 환경 데이터 수집 및 에너지 보존이 최우선 목표

### Ⅳ. 적용 문제와 대응

- 적용 상황: 대규모 산불 조기 감시를 위해 산악 지대에 살포된 WSN 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 싱크 노드 인근 노드의 조기 방전으로 망 단절(에너지 홀) | 중앙 싱크로 트래픽이 집중되는 깔때기 효과(Funneling Effect) | 모바일 싱크(드론/차량 순회 수집) 도입 및 잔여 에너지 기반 가중 라우팅 적용 | 특정 노드 병목 제거 및 센서 네트워크 전체 생존 시간 3배 연장 |
| 동일 이벤트 감지 시 수십 개 중복 패킷 폭증(Implosion) | 단순 플러딩(Flooding) 방식으로 인한 브로드캐스트 패킷 중복 전달 | 지향성 확산(Directed Diffusion) 및 중간 클러스터 헤드의 데이터 통합(Aggregation) | 네트워크 패킷 전송량 70% 감소 및 무선 충돌 방지 |
