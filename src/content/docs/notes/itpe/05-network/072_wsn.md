## 연관 키워드

- 무선센서네트워크(WSN, Wireless Sensor Network), 센서 노드, 싱크 노드(Sink Node), 애드혹(Ad-hoc)
- 다중 홉(Multi-hop), 클러스터 헤드(CH, Cluster Head), 데이터 통합(Data Aggregation), 듀티 사이클링(Duty Cycling)
- 6LoWPAN, RPL, LEACH, IEEE 802.15.4, 시빌 공격(Sybil Attack), 싱크홀 공격(Sinkhole Attack), 웜홀 공격(Wormhole Attack)

## Ⅰ. 무선센서네트워크(WSN)의 개요

- 핵심 요약 : 자율로 망을 이루는 저전력 센서 노드가 환경 데이터를 수집해 집약 지점으로 전달하는 분산 무선 네트워크.
- 개념 : 온도·습도·진동·침입 같은 물리 조건을 감지하는 소형 센서 노드들이 **애드혹** (Ad-hoc, 사전 인프라 없이 노드 간 협의로 망을 구성하는 방식)으로 연결되어 데이터를 수집·전달하는 **무선센서네트워크** (WSN, Wireless Sensor Network).
- 배경 및 필요성 : 산불 감시, 교량 안전 진단, 위험 지역 감시처럼 유선 설치와 인력 순찰이 어려운 현장에서 실시간 모니터링 수단이 필요.
- 주요 목적 : 인프라 없는 환경의 자율 망 구성, 배터리 수명 극대화, 수집 데이터의 **싱크 노드** (Sink Node, 데이터를 집약해 외부망으로 내보내는 게이트웨이) 전달.

## Ⅱ. 무선센서네트워크(WSN)의 특징 및 장점

- 핵심 요약 : 자원 제약 노드의 저전력 설계와 협력 라우팅·데이터 요약이 장기 운용과 전송 효율로 이어지는 구조.

1. 자율 구성 : 노드가 이웃 탐색으로 스스로 망 형성 → 인프라 없는 현장의 즉시 배치.
2. **다중 홉** (Multi-hop) 라우팅 : 낮은 출력 노드가 이웃을 중계로 삼아 패킷 전달 → 저전력으로 광역 수집 가능.
3. **듀티 사이클링** (Duty Cycling) : 트랜시버를 대부분 슬립 상태로 유지하고 짧게 기상 → 배터리 수명 연장.
4. **데이터 통합** (Data Aggregation) : 인접 노드의 중복 측정값을 **클러스터 헤드** (CH, Cluster Head)에서 평균·최댓값 등으로 요약 → 전송 패킷 수와 에너지 소모 감소.

## Ⅲ. 무선센서네트워크(WSN)의 구조 (흐름)

- 핵심 요약 : 센싱 필드의 노드 데이터가 다중 홉과 데이터 통합을 거쳐 싱크 노드와 관제 서버로 전달되는 계층 흐름.
- 센서 노드 하드웨어 구성 :
  1. 센싱 유닛 : 물리 신호의 ADC(Analog-to-Digital Converter) 디지털 변환.
  2. 처리 유닛 : 초저전력 MCU(Microcontroller Unit)의 센싱·통신 제어.
  3. 무선 트랜시버 : 2.4GHz 또는 Sub-GHz 대역의 RF(Radio Frequency) 통신.
  4. 전원 유닛 : 배터리 또는 태양광·진동 기반 에너지 하베스팅.

```text
[ WSN 데이터 전달 흐름 ]

센서 노드 (센싱 필드)
   ↓ 다중 홉 릴레이
클러스터 헤드 (데이터 통합)
   ↓
싱크 노드 (Sink Node)
   ↓ 백홀 (인터넷·셀룰러)
관제 서버
```

- **6LoWPAN** (IPv6 over Low-Power Wireless Personal Area Networks, RFC 4944) : IPv6(Internet Protocol version 6) 헤더를 압축·단편화하여 자원 제약 노드에 IP 연결성 부여.
- **RPL** (Routing Protocol for Low-Power and Lossy Networks, RFC 6550) : DODAG(Destination-Oriented Directed Acyclic Graph) 트리로 손실 많은 망의 경로를 구성.
- **LEACH** (Low-Energy Adaptive Clustering Hierarchy) : 클러스터 헤드를 확률적으로 선출·교대시켜 특정 노드의 조기 소진 방지.

```text
[ WSN 프로토콜 계층 ]

관제 응용 데이터
   ↓
6LoWPAN 적응 계층 (헤더 압축)
   ↓
RPL 라우팅 계층 (목적지 중심 트리)
   ↓
저전력 MAC 계층 (듀티 사이클링)
   ↓
IEEE 802.15.4 물리 계층
```

## Ⅳ. WSN 계층별 표준의 비교

- 핵심 요약 : 물리 접속부터 라우팅·클러스터링까지 계층별 표준이 저전력이라는 공통 목표 아래 보완하는 구조.

| 계층 | 주요 표준·프로토콜 | 동작 방식 | 설계 목표 |
| --- | --- | --- | --- |
| 물리·MAC | IEEE(Institute of Electrical and Electronics Engineers) 802.15.4 | 2.4GHz·Sub-GHz 무선, 충돌 회피 접근 | 저비용·저전력 저속 전송 |
| MAC 에너지 절감 | S-MAC, B-MAC | 듀티 사이클링, 저전력 청취 | 유휴 청취 전력 차단 |
| 적응 계층 | 6LoWPAN | 헤더 압축, 단편화·재조립 | 제약 노드의 IPv6 연결 |
| 라우팅 | RPL | DODAG 트리 기반 경로 | 손실 많은 망의 안정 경로 |
| 클러스터링 | LEACH | 헤더 선출과 주기 교대 | 노드 간 에너지 소모 분산 |

- 선택 기준 :
  1. IP 기반 상호운용과 백엔드 연계가 필요하면 802.15.4+6LoWPAN+RPL 조합.
  2. 에너지 균형이 최우선인 광역 배치는 클러스터링 기반 적용.
  3. 보고 주기와 이벤트 특성에 따라 듀티 사이클링 정책 조정.

## Ⅴ. 무선센서네트워크(WSN)의 한계와 방안

- 핵심 요약 : 에너지 고갈과 노드 탈취 공격이 망 수명·신뢰성을 좌우하며, 에너지 균형과 경량 인증으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 싱크 근처 노드의 에너지 고갈 | 릴레이 부하 집중으로 주변 노드 조기 소진 → 망 분단 | 잔여 에너지 기반 라우팅 가중치, 이동형 싱크 노드, 에너지 하베스팅 결합 | 노드 잔여 에너지 분포, 생존 노드 비율 |
| 노드 탈취에 따른 **시빌 공격** (Sybil Attack, 단일 노드가 다수 가짜 신원을 주장하는 공격) | 가짜 신원으로 라우팅·집계 왜곡 | ECC(Elliptic Curve Cryptography) 기반 경량 상호 인증, 노드 신뢰도 평가 | 비인가 신원 탐지율 |
| 경로 유인형 공격 | **싱크홀 공격** (Sinkhole Attack, 유리한 경로를 허위 광고해 트래픽을 흡수하는 공격)과 웜홀 공격(Wormhole Attack, 원거리 노드를 터널로 연결하는 공격)으로 트래픽 가로채기 | 이상 라우팅 탐지, 다중 경로 라우팅 | 이상 경로 탐지 건수 |

## Ⅵ. 무선센서네트워크(WSN)에 대한 기술사적 제언

- 핵심 요약 : 지능형 온노드 처리, 디지털 트윈 연계, 위성 백홀 보완으로 적용 범위를 확대하는 방향.

1. 기반시설 관리기관은 WSN 계측 데이터를 디지털 트윈에 연계해 구조 상태를 예측하는 예지 보전(PdM, Predictive Maintenance) 체계로 단계 전환해야 한다.
2. 플랫폼 개발 조직은 노드에 TinyML(Tiny Machine Learning) 추론을 탑재하여 원시 데이터 대신 판정 결과만 전송하는 구조로 트래픽과 전력 소모를 함께 줄여야 한다.
3. 통신사와 공공 안전기관은 지상망이 닿지 않는 해양·산간 구간을 3GPP(3rd Generation Partnership Project) NTN(Non-Terrestrial Network) 위성 연계로 보완하는 백홀 구조를 검토해야 한다.

## Ⅶ. 결론

- 핵심 요약 : WSN은 저전력 노드의 자율 협업으로 광역 환경 데이터를 모으는 분산 감시 인프라.
- 망 수명과 보안이 노드 자원 제약 안에서 결정되므로 에너지 균형과 경량 신뢰 체계가 확산의 전제가 됨.
