- **WSN(Wireless Sensor Network):** 센서·무선 통신 노드로 관측 데이터를 수집하는 네트워크
- **싱크 노드(Sink Node):** 센서망 데이터를 수집해 관제·상위 네트워크로 전달하는 노드
- **LEACH(Low-Energy Adaptive Clustering Hierarchy):** 센서 노드를 클러스터로 묶고 클러스터 헤드 역할을 교대시키는 계층형 라우팅 기법
- **데이터 집약(Data Aggregation):** 중간 노드에서 여러 관측값을 결합해 전달량을 줄이는 처리
- **듀티 사이클링(Duty Cycling):** 통신·감지 상태와 절전 상태를 전환해 노드 에너지 사용을 조정하는 방식

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **WSN(Wireless Sensor Network)** 은 무선 센서 노드가 관측 데이터를 수집·전달하는 네트워크 |
| 목적 | 분산된 현장 상태의 원격 관측과 데이터 수집 |

## Ⅱ. 구성과 데이터 전달

```text
센서 노드 ── 직접 전송 ──▶ 싱크 노드

센서 노드
    ↓ 중계 노드
센서 노드
    ↓ 멀티홉 전달
싱크 노드
    ↓
상위망·관제 시스템
```

| 구성 | 기능 |
|---|---|
| 센서 노드 | 감지·표본화와 무선 전송 |
| 클러스터 헤드 | 구성에 따라 구성원 데이터 수집·집약·상위 전달 |
| 싱크 | 센서망 데이터를 상위 시스템으로 연계 |

## Ⅲ. 토폴로지와 라우팅

| 방식 | 전달 구조 | 설계 관점 |
|---|---|---|
| 직접 전송 | 센서에서 싱크로 직접 전달 | 단순하지만 거리·송신 에너지 고려 |
| 멀티홉 | 중간 노드가 다음 노드로 중계 | 도달 범위 확대와 중계 노드 부하 균형 |
| 클러스터 | 구성원 → 클러스터 헤드 → 싱크 | 집약·헤드 교대 정책과 헤드 에너지 고려 |

**LEACH(Low-Energy Adaptive Clustering Hierarchy)** 는 클러스터 헤드 역할을 주기적으로 바꾸는 대표 방식으로, 모든 WSN에 적용되는 필수 프로토콜은 아님

## Ⅳ. 에너지·데이터 품질 운영

| 한계 | 대응 |
|---|---|
| 무선 송수신과 중계가 특정 노드에 집중 | 경로·헤드 역할 분산, **듀티 사이클링(Duty Cycling)**, 필요 시 **데이터 집약(Data Aggregation)** |
| 절전 주기 중 긴급 이벤트 감지·전달 지연 | 이벤트 중요도에 따른 수면·보고 주기와 긴급 통지 경로 설정 |
| 손실·중복 수집으로 관측 결과 왜곡 | 시각·노드 식별자, 중복 처리, 재전송·저장 정책 적용 |
| 장기 무인 환경의 노드 장애·전원 고갈 | 배터리·통신 상태 감시와 현장 교체·재배치 계획 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모든 노드를 동일한 주기로 운영하면 관측 중요도와 전력·통신 여건의 차이를 반영하기 어려움 | 임무 중요도와 이벤트 조건별 수집 주기·전달 경로를 구분하고, 현장 전원 교체 여건에 맞춰 집약·절전 수준을 조정 |
