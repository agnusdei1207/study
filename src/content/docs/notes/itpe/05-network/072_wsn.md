## 지식 로드맵 내 현재 위치

네트워크 → 제약 무선망 및 센서 네트워킹 → **무선센서네트워크(WSN)**

## 30초 인출

- 본질: **WSN(Wireless Sensor Network)** : 배터리 기반의 초소형 센서 노드들이 물리적 환경 정보를 자율적으로 감지하고, 저전력 애드혹(Ad-hoc) 멀티홉 무선 메시 네트워크를 구성하여 싱크 노드(Sink Node)로 데이터를 전달하는 분산 센싱 인프라
- 메커니즘: 센서 노드들이 클러스터링(LEACH) 및 에너지 인식 라우팅을 통해 데이터를 중간 집약(Data Aggregation)하고, 듀티 사이클링(Duty Cycling) 슬립 제어로 배터리 소모를 극소화하며 전송
- 통찰: 싱크 노드 주변 중계 노드의 조기 방전으로 망이 단절되는 에너지 홀(Energy Hole) 현상 및 무인 노드 물리적 탈취 극복을 위해 모바일 싱크 순회 수집과 보안 하드웨어(SE) 연계 필수

<details>
<summary>핵심 용어</summary>

- **Sensor Node (모트, Mote)** : 센서, 초저전력 프로세서(MCU), 무선 RF 트랜시버, 소형 배터리로 구성되어 데이터를 수집·중계하는 기본 하드웨어
- **Sink Node (Base Station)** : 센서 필드 내 수천 개 노드가 송신한 데이터를 최종 수집하여 인터넷, 위성 등 상위 외부 백본망으로 연계하는 고성능 관문 노드
- **LEACH (Low-Energy Adaptive Clustering Hierarchy)** : 클러스터 헤드(CH) 역할을 확률적으로 순환 교대시켜 노드 간 에너지 소모 균형을 달성하는 자가 조직화 계층 라우팅 프로토콜
- **Data Aggregation (데이터 집약)** : 중간 클러스터 헤드 노드가 주변 노드들의 중복 측정값을 평균, 최댓값 등으로 병합 압축하여 상위 전송 패킷 수를 극감시키는 기법
- **Duty Cycling (듀티 사이클링)** : 주기적으로 무선 트랜시버를 끄는 수면(Sleep) 모드와 깨어나는 활성(Active) 모드를 교대하여 유휴 청취(Idle Listening) 전력 낭비를 차단하는 기법
- **Energy Hole Problem** : 모든 멀티홉 트래픽이 싱크 노드 주변 1홉 노드로 집중되어 주변부 노드가 먼저 방전되어 망 전체가 고립 마비되는 현상

</details>

## 2~4교시 25점 답안

## Ⅰ. 무선센서네트워크(WSN)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 공간적으로 분산된 수많은 저전력 초소형 무선 센서 노드들이 인프라 없이 자율적으로 무선 애드혹 네트워크를 형성하여 온도, 진동, 압력 등 물리적 현상을 협력 감지하고 수집하는 센서 네트워크 |
| 목적 | 인간이 접근하기 어려운 오지, 재난 구역, 군사 경계선, 대형 플랜트의 환경 상태를 무인 실시간 원격 감시 및 자율 데이터 수집 |

## Ⅱ. WSN의 특징 및 핵심 하드웨어 4대 구성 요소

| 하드웨어 구성 요소 | 주요 역할 | 저전력 엔지니어링 특징 |
|---|---|---|
| **센싱부 (Sensors & ADC)** | 온도, 습도, 가속도 등 물리 아날로그 신호를 감지하여 디지털 변환 | 이벤트 발생 시에만 웨이크업(Wake-up) 인터럽트로 전력 소비 차단 |
| **프로세싱부 (MCU & Memory)**| 센서 데이터 가공, 데이터 압축, 라우팅 알고리즘 연산 수행 | 저전력 슬립 모드를 지원하는 8/16비트 초저전력 마이크로컨트롤러 |
| **통신부 (RF Transceiver)** | IEEE 802.15.4 규격 기반의 2.4GHz/900MHz 무선 패킷 송수신 | 전체 에너지의 80% 이상을 소모하므로 유휴 시 Deep-Sleep 전환 필수 |
| **전원부 (Power Unit)** | 코인형 배터리, 리튬 전지 또는 주변 에너지 하베스팅 장치 | 교체 불가 환경을 전제하여 10년 이상 가동 목표 설계 |

## Ⅲ. WSN 네트워크 토폴로지 및 계층형 클러스터링(LEACH) 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ WSN 계층형 클러스터링(LEACH) 전송 아키텍처 ]       │
│                                                                        │
│   [클러스터 1]                                 [클러스터 2]            │
│     ● 노드 1 ──┐                                 ● 노드 4 ──┐          │
│     ● 노드 2 ──┼─► [클러스터 헤드 A]             ● 노드 5 ──┼─► [헤드 B]│
│     ● 노드 3 ──┘   (데이터 집약/압축)            ● 노드 6 ──┘  (집약)   │
│                           │                                      │     │
│                           └──────────────────┬───────────────────┘     │
│                                              ▼ 고출력 직접 전송        │
│                                     ┌──────────────────┐               │
│                                     │  싱크 노드(Sink) │               │
│                                     │  (Base Station)  │               │
│                                     └────────┬─────────┘               │
│                                              │ 인터넷 백홀 (LTE/위성)   │
│                                              ▼                         │
│                                     [중앙 관제 클라우드]               │
└────────────────────────────────────────────────────────────────────────┘
```

| LEACH 동작 단계 | 세부 수행 메커니즘 | 에너지 절감 효과 |
|---|---|---|
| **1. 셋업 단계 (Setup)** | 각 노드가 0과 1 사이의 난수를 생성하여 임계값 $T(n)$ 미만이면 스스로 클러스터 헤드(CH)로 선출 후 광고 송출 | 특정 노드만 헤드를 지속 전담하지 않고 전 노드가 균등 교대 |
| **2. 클러스터 형성** | 일반 노드들은 수신 신호 강도(RSSI)가 가장 강한 CH를 선택하여 가입 요청 회신 | 최소 송신 출력으로 헤드에 도달 가능 |
| **3. 스케줄링 (TDMA)** | CH는 가입 노드들에게 TDMA 타임슬롯을 배정하여 충돌(Collision) 방지 | 일반 노드는 자기 슬롯 외에는 슬립 모드 유지 |
| **4. 전송 및 집약 (Steady)**| 일반 노드가 측정값 전송 시, CH는 중복 데이터를 평균화 압축하여 싱크로 원거리 단일 전송 | 전체 네트워크 전송 패킷량 70~80% 대폭 절감 |

## Ⅳ. 플랫 라우팅 vs 계층형 클러스터링 vs 위치 기반 라우팅 비교

| 비교 항목 | 플랫 라우팅 (Flat: Directed Diffusion) | 계층형 라우팅 (Hierarchical: LEACH) | 위치 기반 라우팅 (Location: GPSR) |
|---|---|---|---|
| **토폴로지 구조** | 모든 노드가 동등한 단일 계층 (Flat) | 클러스터 헤드 중심의 2계층 구조 | 지리적 좌표 기반의 탐욕적 전달 |
| **경로 결정 방식**| 데이터 중심(Data-centric), 관심사(Interest) 전파 | 클러스터 헤드 선출 및 싱크 직접 전달 | 목적지 좌표와 가장 가까운 이웃 홉 선택 |
| **데이터 집약** | 경로 상의 중간 노드에서 기회적 집약 | **클러스터 헤드(CH)에서 전담 집약** | 집약 기능 부재 (패킷 단위 중계) |
| **노드 확장성** | 소규모 망에 적합 (플러딩 오버헤드 큼) | **대규모 광역 센서망에 우수** | 초대규모 노드 확장에 최적화 |
| **네트워크 수명** | 트래픽 집중 경로 노드 조기 방전 | **헤드 순환 교대로 수명 2~3배 연장** | 최단 경로 상의 노드 조기 방전 |

## Ⅴ. WSN 구축 및 운영 시 핵심 엔지니어링 한계와 방안

| 한계 | 방안 |
|---|---|
| 멀티홉 전송 특성상 모든 센서 데이터가 싱크 노드로 깔때기처럼 집중되면서 싱크 주변 1홉 거리의 중계 노드들이 타 노드 대비 수십 배의 패킷을 전달하다가 조기 방전되어 네트워크 전체가 고립되는 에너지 홀(Energy Hole) 현상 발생 | 이동 경로를 자율 주행하며 센서 필드를 순회 수집하는 무인 이동 로봇 기반의 모바일 싱크(Mobile Sink)를 투입하여 핫스팟 부하를 동적 분산하고, 고정 싱크 환경에서는 싱크 주변부에 노드를 기하급수적 고밀도로 배치하는 불균일 노드 배치(Non-uniform Deployment) 적용 |
| 무인 야외/산악 지대에 노출된 센서 노드가 악의적 공격자에게 물리적으로 노획(Node Capture)되어 펌웨어 및 메모리 덤프를 통해 네트워크 마스터 암호키가 유출되고 가짜 노드를 대량 위장 투입하는 시빌(Sybil) 공격 발생 | 하드웨어 보안 칩(Secure Element / PUF 기반 고유키)을 센서 보드에 실장하여 메모리 물리 덤프를 원천 차단하고, 확률적 키 사전 분배(Eschenauer-Pligman) 방식을 채택하여 노드 1개가 노획되어도 전체 네트워크 키가 유출되지 않는 국소 보안 격리 체계 구축 |
| 센서 노드의 배터리 용량 한계로 인해 주기적 배터리 교체 비용이 초기 인프라 구축 비용을 초과하는 유지보수 경제성 한계 봉착 | 태양광, 열전소자(TEG), 진동 압전 소자 기반의 초소형 에너지 하베스팅(Energy Harvesting) 모듈을 결합하고, 잔여 에너지 축적량에 따라 패킷 송신 주기를 동적으로 조절하는 에너지 중립(Energy-Neutral) 적응형 듀티 사이클링 알고리즘 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
스마트 농업, 산불 감시, 교량 안전 진단 등 실무 WSN 구축 시, 전송 거리 100m 이내의 고밀도 구간은 IEEE 802.15.4 기반 6LoWPAN/Zigbee 메시망을 구성하고, 1km 이상의 광역 센싱 구간은 사설 WSN 대신 통신사 인프라를 활용하는 LPWAN(LoRaWAN, NB-IoT)을 복합 연계하는 계층적 하이브리드 아키텍처 수립 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 에너지 홀 극복을 위한 모바일 싱크 WSN 아키텍처 ]        │
│                                                                        │
│   [클러스터 영역 A]                            [클러스터 영역 B]        │
│   (CH-1에 데이터 임시 저장)                    (CH-2에 데이터 임시 저장)│
│          │                                            │                │
│          │                                            │                │
│          ▼ 1. 지정 랑데부 지점 도달                   ▼                │
│   ┌────────────────────────────────────────────────────────┐           │
│   │        모바일 싱크 (Mobile Sink / 자율 순회 로봇)      │           │
│   │  - 센서 필드 랑데부 포인트를 주기적으로 이동 순회      │           │
│   │  - 근거리 1홉 무선 통신으로 CH 버퍼 데이터 고속 수거  │           │
│   └──────────────────────────┬─────────────────────────────┘           │
│                              │                                         │
│                              ▼ 2. 고용량 LTE-M / 5G 백홀 업로드        │
│               [ 중앙 관제 모니터링 시스템 ]                            │
│   * 싱크가 직접 찾아가므로 중간 노드의 에너지 홀(전력 방전) 원천 해소!   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 구분 | 근거리 WSN (IEEE 802.15.4 / Zigbee) | 비면허 LPWAN (LoRaWAN) | 면허 셀룰러 IoT (NB-IoT / LTE-M) |
|---|---|---|---|
| **통신 거리** | 10 ~ 100 m (멀티홉 메시 확장) | **5 ~ 15 km (스타 토폴로지)** | **10 ~ 20 km (기지국 커버리지)** |
| **네트워크 구조** | 애드혹 메시 (자체 중계 라우팅) | 단일 홉 스타 토폴로지 | 셀룰러 기지국 직접 접속 |
| **망 구축 주체** | 사설 자체 구축 (게이트웨이 필요) | 사설 구축 또는 통신사 망 | 이동통신 사업자 상용망 가입 |
| **전력 소모** | 극저전력 (듀티 사이클링 적용) | 초저전력 (수면 모드 최적화) | 저전력 (PSM / eDRX 지원) |
| **주 활용 분야** | 스마트 빌딩 조명/냉난방, 공장 센서 | 스마트 팜, 상수도 원격 검침 | 스마트 가로등, 물류 자산 트래커 |
