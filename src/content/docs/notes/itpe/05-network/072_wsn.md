## 연관 키워드

- 무선센서네트워크(WSN, Wireless Sensor Network), 센서 노드, 싱크 노드(Sink Node), 애드혹(Ad-hoc)
- 다중 홉(Multi-hop), 클러스터 헤드(CH, Cluster Head), 데이터 통합(Data Aggregation), 듀티 사이클링(Duty Cycling)
- 6LoWPAN, RPL, LEACH, IEEE 802.15.4, 싱크홀 공격(Sinkhole Attack), 시빌 공격(Sybil Attack), 웜홀 공격(Wormhole Attack)

## Ⅰ. 무선센서네트워크(WSN)의 개요

- 핵심 요약 : 자율적으로 망을 이루는 소형 무선 센서 노드들이 환경 정보를 모아 싱크 노드로 전달하는 분산 무선 네트워크.
- 개념 : 온도·습도·진동·압력·침입 같은 물리·환경 조건을 감지하도록 배치된 다수의 소형 센서 노드(Mote)가 **애드혹** (Ad-hoc, 사전 인프라 없이 노드끼리 망을 구성하는 방식)으로 연결되어 데이터를 수집·전달하는 **무선센서네트워크** (WSN, Wireless Sensor Network).
- 배경 및 필요성 : 사람이 접근하기 어려운 산불 감시, 교량 안전 진단, 군사 정찰 지역 등은 유선 설치가 어려워, 무선 메쉬로 실시간 환경 모니터링 체계를 구축할 필요가 커짐.
- 주요 목적 : 기존 인프라 없이 토폴로지를 자율 구성하고, 배터리 수명을 늘리는 초저전력 통신을 쓰며, 수집 데이터를 **싱크 노드** (Sink Node, 데이터를 집약해 외부로 내보내는 게이트웨이)에 모으는 것.

## Ⅱ. 무선센서네트워크(WSN)의 특징 및 장점

- 핵심 요약 : 자원 제약 노드의 저전력 설계와 협력형 라우팅·데이터 통합이 장기 운용과 전송 효율로 이어지는 구조.

1. 애드혹 자율 구성 : 노드가 이웃을 찾아 스스로 망을 형성 → 인프라가 없는 현장에도 즉시 배치 가능.
2. **다중 홉** (Multi-hop) 라우팅 : 전송 출력이 작은 노드가 이웃을 중계기로 삼아 패킷을 전달 → 저출력으로도 광역 수집 가능.
3. **듀티 사이클링** (Duty Cycling) : 트랜시버를 대부분 슬립 상태로 두고 짧게만 깨어남 → 배터리 수명 연장.
4. **데이터 통합** (Data Aggregation) : 인접 노드의 중복 측정값을 클러스터 헤드(CH, Cluster Head)에서 평균·최댓값 등으로 요약 → 전송 패킷 수와 에너지 소모 감소.

## Ⅲ. 무선센서네트워크(WSN)의 구조 (흐름)

- 핵심 요약 : 센싱 필드의 노드들이 다중 홉으로 데이터를 모아 싱크 노드를 거쳐 관제 서버로 전달되는 계층 흐름.
- 센서 노드 하드웨어는 네 부분으로 구성.
  1. 센싱 유닛 : 물리 신호를 ADC(Analog-to-Digital Converter)로 디지털 값으로 변환.
  2. 처리 유닛 : 초저전력 MCU(Microcontroller Unit)가 센싱과 통신을 제어.
  3. 무선 트랜시버 : 2.4GHz 또는 Sub-GHz 대역의 RF(Radio Frequency) 통신 수행.
  4. 전원 유닛 : 코인형 배터리 또는 태양광·진동 기반 에너지 하베스팅 전원.

```text
[ WSN 데이터 전달 흐름 ]

센서 노드 (센싱 필드)
   ↓ 다중 홉 릴레이
클러스터 헤드 (데이터 통합)
   ↓
싱크 노드 (Sink Node)
   ↓ 백홀 (인터넷·셀룰러)
관제 서버
```

```text
[ WSN 프로토콜 계층 ]

관제 데이터 (응용)
   ↓
주소 압축·단편화 적응 계층
   ↓
목적지 중심 트리 라우팅 계층
   ↓
듀티 사이클링 MAC 계층
   ↓
저전력 무선 물리 계층
```

- **6LoWPAN** (IPv6 over Low-Power Wireless Personal Area Networks, RFC(Request for Comments) 4944) : 128비트 IPv6(Internet Protocol version 6) 헤더를 압축하고 프레임을 단편화·재조립하여, 자원이 적은 노드에도 IPv6 연결성을 부여.
- **RPL** (Routing Protocol for Low-Power and Lossy Networks, RFC 6550) : DODAG(Destination-Oriented Directed Acyclic Graph)라는 목적지 중심 트리를 구성하여, 손실이 많은 망에서 최적 경로를 찾음.
- **LEACH** (Low-Energy Adaptive Clustering Hierarchy) : 클러스터 헤드를 확률적으로 선출하고 주기적으로 교대시켜 특정 노드의 조기 고갈을 막음.

## Ⅳ. 무선센서네트워크(WSN)의 비교

- 핵심 요약 : 계층마다 전송, 에너지 절감, 주소 압축, 경로, 클러스터링 표준이 나뉘어 서로 보완하는 구조.

| 계층 | 주요 표준·프로토콜 | 동작 방식 | 설계 목표 |
| --- | --- | --- | --- |
| 물리·MAC | IEEE(Institute of Electrical and Electronics Engineers) 802.15.4 | 2.4GHz 및 Sub-GHz 대역 무선, 충돌 회피 방식 채널 접근 | 저비용·저전력 저속 전송 |
| MAC 에너지 절감 | S-MAC, B-MAC | 듀티 사이클링, LPL(Low Power Listening) | 유휴 청취 전력 소모 차단 |
| 적응 계층 | 6LoWPAN (RFC 4944) | 헤더 압축, 프레임 단편화·재조립 | 자원 제약 노드의 IPv6 연결 |
| 라우팅 | RPL (RFC 6550) | DODAG 기반 트리 라우팅 | 손실 많은 망에서의 최적 경로 |
| 클러스터링 | LEACH | 확률적 헤더 선출과 주기적 교대 | 노드 간 에너지 소모 분산 |

## Ⅴ. 무선센서네트워크(WSN)의 한계와 방안

- 핵심 요약 : 에너지 고갈과 물리적 노출이 망 수명과 신뢰성을 좌우하므로, 에너지 균형 라우팅과 경량 인증을 함께 설계.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 싱크 근처 노드의 에너지 고갈 | 릴레이 노드가 전체 트래픽을 중계해 먼저 소진 → 깔때기(Funneling) 효과로 주변 노드 고립 | 잔여 에너지 기반 라우팅 가중치, 이동형 싱크 노드(Mobile Sink), 에너지 하베스팅 결합 | 노드 잔여 에너지 분포, 생존 노드 비율 |
| 노드 탈취에 따른 시빌 공격(Sybil Attack)·웜홀 공격(Wormhole Attack)·싱크홀 공격(Sinkhole Attack) | 방치된 노드를 탈취해 가짜 신원을 만들거나 악성 경로를 열어 트래픽을 가로챔 | ECC(Elliptic Curve Cryptography) 기반 경량 상호 인증, 노드 신뢰도 평가(Trust Management), 이상 라우팅 탐지 | 비인가 노드 탐지율, 이상 경로 탐지 건수 |

## Ⅵ. 무선센서네트워크(WSN)에 대한 기술사적 제언

- 핵심 요약 : 수동적 중계 센서를 지능형 센싱 노드로 바꾸고, 위성과 디지털 트윈으로 적용 범위를 넓히는 방향.

1. 국가 기반시설에는 WSN 계측 데이터를 디지털 트윈에 실시간으로 연계해 구조 피로도를 예측하는 예지 보전(PdM, Predictive Maintenance) 플랫폼을 단계적으로 도입하는 것이 필요.
2. 노드에 TinyML(Tiny Machine Learning) 추론 기능을 두어 원시 데이터 대신 이상 판정 결과만 전송하도록 설계하면 무선 트래픽과 배터리 소모를 함께 줄일 수 있음.
3. 지상 망이 닿지 않는 대양·극지 구간은 3GPP(3rd Generation Partnership Project) NTN(Non-Terrestrial Network) 위성 연계로 보완하는 구조를 검토하는 것이 필요.

## Ⅶ. 결론

- 핵심 요약 : WSN은 저전력 노드의 자율 협업으로 광역 환경 데이터를 모으는 분산 감시 인프라.
- 시사점 : 망 수명과 보안은 노드 자원과 물리 노출의 제약 안에서 결정되므로, 에너지 균형과 경량 신뢰 체계가 확산의 전제 조건이 됨.
