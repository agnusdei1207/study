## 지식 로드맵 내 현재 위치

네트워크 → 광 무선통신 → **FSO(자유공간 광통신 채널 특성)**

## 30초 인출

- 본질: **자유공간 광통신 전파 특성** : 레이저 광선이 대기 매질을 통과할 때 발생하는 기하학적 확산 손실, 대기 흡수 및 산란, 난류 신틸레이션(Scintillation) 등 채널 열화 요인을 분석하여 링크 마진(Link Margin)을 설계하는 물리 계층 이론
- 메커니즘: 비어-램버트(Beer-Lambert) 법칙 및 ITU-R P.1814 전파 모델을 기반으로 $P_{rx} = P_{tx} - A_{geo} - A_{atmo} - A_{scint} - A_{sys} \ge S_{rx}$ 링크 예산식을 도출하여 수신 감도 여유 확보
- 통찰: 맑은 날씨 기준의 링크 마진 계산은 농무 발생 시 100dB/km 이상의 미에 산란 손실로 채널이 붕괴하므로 지역별 가시거리 누적 통계 기반 페이딩 마진과 개구 평균화 기법 연계 필수

<details>
<summary>핵심 용어</summary>

- **비어-램버트 법칙 (Beer-Lambert Law)** : 매질을 통과하는 빛의 투과율이 전파 거리와 대기 소멸 계수(Extinction Coefficient)에 지수 함수적으로 반비례함을 나타내는 기본 물리 법칙 ($I(z) = I_0 e^{-\gamma z}$)
- **미에 산란 (Mie Scattering)** : 입자 크기가 빛의 파장과 유사할 때(안개, 구름) 발생하는 산란으로, 파장 의존성이 낮고 전방위 산란 손실이 극심한 대기 감쇠 주원인
- **대기 굴절률 구조 상수 ($C_n^2$)** : 태양 복사열에 따른 대기 온도 변화로 인한 굴절률 요동의 강도를 나타내는 척도 ($10^{-17} m^{-2/3}$ 약한 난류 ~ $10^{-13} m^{-2/3}$ 강한 난류)
- **개구 평균화 (Aperture Averaging)** : 수신 렌즈의 직경을 대기 난류의 공간적 상관 길이(Correlation Length)보다 크게 제작하여 신틸레이션에 의한 광세기 요동을 공간적으로 평균화 평활화하는 기법
- **링크 마진 (Link Margin)** : 실제 수신단에 도달하는 유효 수신 전력과 목표 비트오류율(BER $10^{-9}$)을 만족하는 최소 수신 감도 간의 전력 격차 (dB)

</details>

## 2~4교시 25점 답안

## Ⅰ. FSO 채널 전파 특성의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 광섬유 코어가 아닌 자유 대기 공간을 통과하는 레이저 광선의 기하학적 확산, 분자 흡수, 에어로졸 산란, 대기 난류에 따른 전파 감쇠 특성을 정량화하는 광학 통신 해석 모델 |
| 목적 | 기상 조건(안개, 강우, 강설, 기온 역전) 변화에 따른 수신 광전력 저하를 사전에 예측하여 99.999% 캐리어급 전송 품질을 보장하는 최적 링크 버짓 설계 |

## Ⅱ. FSO 채널의 특징 및 주요 손실 파라미터

| 채널 손실 파라미터 | 물리적 발생 원인 | 감쇠 수식 및 영향도 |
|---|---|---|
| **기하학적 손실 ($A_{geo}$)** | 빔 방사 각도(Divergence Angle, $\theta$)에 따라 거리가 멀어질수록 빔 단면적이 확산되어 수신 구경에 도달하는 면적비 축소 | $A_{geo} = 10 \log_{10} \left[ \frac{\pi (d_1 + L\theta)^2 / 4}{\pi d_2^2 / 4} \right]$ (dB)<br/>거리 $L$의 제곱에 비례하여 발생 |
| **대기 흡수 ($A_{abs}$)** | 대기 중의 수증기($H_2O$), 이산화탄소($CO_2$), 오존($O_3$) 분자가 특정 파장의 광자 에너지를 흡수 | 특정 공진 파장에서 피크 발생 (850, 1064, 1550nm 등 대기의 창 대역 활용) |
| **대기 산란 ($A_{scat}$)** | 대기 분자(레일리) 및 안개/먼지 입자(미에)와 충돌하여 광자 진행 경로가 전방위로 분산 굴절 | 안개 시 100~300dB/km에 달하여 FSO의 최대 통신 단절 요인으로 작용 |
| **신틸레이션 ($A_{scint}$)**| 태양열에 의한 대기 온도 차이로 공기 굴절률($n$)이 요동쳐 파면 왜곡 및 순간 페이딩 발생 | 수신단에서 수십 ms 주기의 광세기 급변(Flickering) 초래 (최대 20~30dB 손실) |

## Ⅲ. FSO 링크 버짓(Link Budget) 계산 구조 및 전파 손실 모델

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ FSO 링크 버짓(Link Budget) 감쇠 스택 구조 ]         │
│                                                                        │
│   [송신 레이저 출력: P_tx (예: +20 dBm)]                                │
│          │                                                             │
│          ▼ [기하학적 확산 손실: -A_geo (거리 L, 발산각 θ)]              │
│   (빔 단면적이 수신 렌즈 면적보다 커져 발생하는 불가피한 면적 손실)    │
│          │                                                             │
│          ▼ [대기 감쇠: -A_atmo (비어-램버트 법칙, 김/크루즈 모델)]      │
│   (흡수 손실 + 미에 산란 손실: 안개, 연무, 강우 감쇠)                  │
│          │                                                             │
│          ▼ [대기 난류 및 신틸레이션 마진: -A_scint (Log-normal 분산)]  │
│   (대기 굴절률 요동 C_n^2에 따른 순간 광세기 강하 보상 마진)           │
│          │                                                             │
│          ▼ [광학계 및 포인팅 손실: -A_sys (렌즈 투과율, PAT 오차)]     │
│   (송수신 렌즈 먼지, 커플링 손실, 건물 진동 Boresight 오차)            │
│          │                                                             │
│          ▼                                                             │
│   [실효 수신 전력: P_rx] ─── (차이: Link Margin) ───► [최소 수신 감도: S_rx]│
│   * 수식: Link Margin = P_rx - S_rx >= 0 dB (통상 20~30 dB 이상 확보 권장)│
└────────────────────────────────────────────────────────────────────────┘
```

| 버짓 구성 항목 | 산정 공식 및 기준 모델 | 핵심 설계 지침 |
|---|---|---|
| **대기 감쇠 계수 ($\gamma$)** | $\gamma(\lambda) = \frac{3.91}{V} \left( \frac{\lambda}{550} \right)^{-q}$ (Kim 모델) | 가시거리 $V \le 0.5km$ 시 $q=0$ 적용 (미에 산란 극대화, 파장 무관 감쇠) |
| **수신 전력 ($P_{rx}$)** | $P_{rx} = P_{tx} \cdot \frac{D_{rx}^2}{(D_{tx} + \theta L)^2} \cdot 10^{-\frac{\gamma L + A_{sys}}{10}}$ | 송신 출력 $P_{tx}$ 증대 및 빔 발산각 $\theta$ 극소화(1 mrad 이하) |
| **신틸레이션 지수 ($\sigma_R^2$)**| $\sigma_R^2 = 1.23 C_n^2 k^{7/6} L^{11/6}$ (Rytov 분산) | 난류 세기에 비례하여 요구 링크 마진을 15~25dB 상향 할당 |
| **수신 감도 ($S_{rx}$)** | $BER = \frac{1}{2} \text{erfc}\left(\frac{SNR}{2\sqrt{2}}\right) \le 10^{-9}$ 만족 전력 | 고감도 InGaAs APD 채택 시 $-35 \sim -40 dBm$ 수준 요구 |

## Ⅳ. 대기 산란 유형 비교

| 비교 항목 | 레일리 산란 (Rayleigh) | 미에 산란 (Mie) | 비선택적 산란 (Non-selective) |
|---|---|---|---|
| **입자 크기 ($r$)** | 파장보다 훨씬 작음 ($r \ll \lambda$) | 파장과 유사한 크기 ($r \approx \lambda$) | 파장보다 훨씬 큼 ($r \gg \lambda$) |
| **원인 입자** | 대기 분자(질소, 산소), 미세 연기 | **안개(Fog), 연무(Haze), 에어로졸** | 빗방울(Rain), 눈(Snow), 우박 |
| **파장 의존성** | 파장의 4제곱에 반비례 ($\lambda^{-4}$) | 파장에 미세 반비례 ($\lambda^{-q}$, $q \approx 0$) | 파장과 무관 (모든 파장 균일 산란) |
| **산란 패턴** | 전후방 대칭 산란 | 강한 전방 산란 | 기하 광학적 전방위 차폐 |
| **FSO 링크 영향** | 영향 거의 없음 (무시 가능) | **가장 치명적 (최대 300dB/km)** | 강우 시 20~30dB/km 수준 (안개보다 적음) |

## Ⅴ. FSO 링크 설계 시의 한계와 방안

| 한계 | 방안 |
|---|---|
| 기상청 국지성 짙은 안개 발생 시 가시거리가 50m 이하로 급감하면서 미에 산란 계수가 급상승하여 링크 마진 40dB를 초과하는 전파 차단 현상 발생 | 도심 간 FSO 전송 거리를 최대 800m~1km 이내로 엄격히 제한하고, ITU-R P.1814 전파 모델 기반의 지역별 연간 안개 지속 시간 통계를 반영하여 60GHz 밀리미터파 자동 우회 링크 병행 구성 |
| 직사광선이 수신 렌즈 광축으로 직접 입사될 때 배경 태양광 잡음(Background Solar Noise)으로 인해 수신기 APD 광검출기가 포화되어 신호 대 잡음비(SNR) 붕괴 | 수신단 전면에 1nm 이하의 초협대역 광학 대역통과 필터(Narrowband Optical BPF)를 실장하고, 태양 궤적각을 고려하여 동서 축 정렬을 피하는 공간 배치 설계 적용 |
| 대기 난류($C_n^2$)로 인한 빔 방랑(Beam Wander)과 수신 평면의 광세기 불균일로 인해 수신 아이 다이어그램(Eye Diagram)이 닫히며 버스트 비트 에러 발생 | 수신 구경 직경을 난류 상관 거리보다 크게 키우는 개구 평균화(Aperture Averaging) 설계 및 수신단 전단에 리드 솔로몬(RS) 또는 저밀도 패리티 검사(LDPC) 순방향 오류 정정(FEC) 부호화 의무화 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
FSO 링크 구축 전 대상 구간의 지리적 열원(아스팔트 도로, 건물 환기구 등 난류 유발 구역)을 사전 회피하도록 경로를 설계하고, 연간 99.999% 가용률을 달성하기 위해 최소 25dB 이상의 페이딩 여유 마진을 확보해야 하며, 수신단 RSSI 값을 24시간 실시간 텔레메트리로 수집하여 렌즈 오염 및 광축 변위를 사전 감지하는 예지정비 체계 수립 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ FSO 링크 버짓 및 개구 평균화 설계 아키텍처 ]       │
│                                                                        │
│   [소구경 수신 렌즈 (D < r0)]          [대구경 개구 평균화 (D > r0)]   │
│   - 난류 반점(Speckle) 크기보다 작음    - 수많은 난류 반점을 동시 수용  │
```

### 3. 기술 유형 및 비교 평가
| 설계 구분 | 단거리 FSO (< 500m) | 중거리 FSO (500m ~ 2km) | 위성-지상 간 FSO (> 500km) |
|---|---|---|---|
| **주요 제한 손실** | 건물 진동 포인팅 손실 | 대기 산란 (안개 미에 산란) | 대기 난류 신틸레이션 및 빔 방랑 |
| **요구 링크 마진** | 10 ~ 15 dB | 25 ~ 40 dB | 20 ~ 30 dB (적응 광학 필수) |
| **빔 발산각** | 2 ~ 5 mrad (광시야각) | 0.5 ~ 2 mrad (집광) | 10 ~ 50 µrad (초극협 빔) |
| **광학계 보정 기술**| 단순 수동 광축 정렬 | 개구 평균화, 다중 빔 송신 | 적응 광학(Adaptive Optics), 고속 PAT |
| **주 활용 분야** | 캠퍼스 건물 간 LAN 브리지 | 이동통신 기지국 무선 백홀 | 지구-위성 광 피더 링크 (6G NTN) |
