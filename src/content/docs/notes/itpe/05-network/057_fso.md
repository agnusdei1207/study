## Ⅰ. FSO(자유공간 광통신) 채널 특성의 개요

- 개념 : 레이저 광선이 대기 매질을 통과할 때 발생하는 기하학적 확산 손실, 대기 분자 흡수, 에어로졸 산란, 대기 난류 **신틸레이션(Scintillation)** 등 다양한 채널 열화 요인을 정량 분석하여 통신 링크 마진을 설계하는 **광학 전파** 이론.
- 배경 및 필요성 : 밀폐된 광섬유 내부와 달리, 자유 대기는 기상 상태(안개, 비, 눈, 기온 역전)에 따라 채널 특성이 시시각각 극심하게 변동하므로, 캐리어급 신뢰도 설계를 위한 채널 모델링 필수.
- 핵심 목적 : ITU-R P.1814 권고 기반 **링크 버짓(Link Budget)** 정밀 산출, **기상 페이딩 마진** 확보 및 개구 평균화(Aperture Averaging)를 통한 수신 감도 최적화.

## Ⅱ. FSO 채널의 핵심 물리 메커니즘 및 손실 모델

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ FSO 대기 전파 손실 종합 메커니즘 ]                  │
│                                                                        │
│   비어-램버트(Beer-Lambert) 법칙 : P_rx = P_tx * exp(-γ * L)           │
│   (수신 광전력은 전파 거리 L과 대기 소멸 계수 γ에 지수함수적으로 감쇠) │
│                                                                        │
│   [ 1. 대기 감쇠 (Attenuation: γ = α_abs + β_scat) ]                   │
│   - 대기 흡수 (α_abs) : H2O, CO2 분자가 특정 파장의 광자 흡수          │
│   - 에어로졸 산란 (β_scat) : 맑은 날 레일리 산란, 안개/구름 미에 산란  │
│                                                                        │
│   [ 2. 기하학적 손실 (Geometric Loss: A_geo) ]                         │
│   - 빔 발산각(θ)에 따른 확산 면적 증가: A_geo ∝ (d1 + θ*L)^2 / d2^2  │
│                                                                        │
│   [ 3. 대기 난류 신틸레이션 (Scintillation) ]                           │
│   - 지표면 열기로 굴절률 구조상수(Cn^2) 요동 ──► 빔 일렁임 및 세기 변동│
│   - 감마-감마(Gamma-Gamma) 확률 분포 기반의 페이딩 유발                │
└────────────────────────────────────────────────────────────────────────┘
```

- **비어-램버트(Beer-Lambert) 감쇠 법칙** : 매질을 통과하는 빛의 강도는 거리($L$)와 전체 소멸 계수($\gamma = \alpha_{\text{abs}} + \beta_{\text{scat}}$)에 따라 지수함수적으로 감쇠($I = I_0 e^{-\gamma L}$).
- **킴(Kim) 및 크루스(Kruse) 산란 모델** : 가시거리($V$)에 따른 안개 감쇠 계수를 파장($\lambda$)의 지수함수로 모델링하여 기상 관측 데이터로부터 감쇠량(dB/km) 추정.
- **대기 굴절률 구조 상수 ($C_n^2$)** : 태양열 복사로 인한 국지적 공기 팽창과 난류로 굴절률이 급변하는 척도로, $10^{-17}\text{ m}^{-2/3}$(약한 난류)에서 $10^{-13}\text{ m}^{-2/3}$(강한 난류) 범위를 가짐.

## Ⅲ. FSO 주요 채널 손실 요인 및 완화 기법 비교 분석

| 채널 손실 요인 | 물리적 발생 원인 | 정량적 감쇠 영향도 | 기술적 완화 방안 |
|---|---|---|---|
| 기하학적 확산 ($A_{\text{geo}}$) | 빔 방사 각도에 따른 광 단면적 확산 | 거리의 제곱에 비례 ($10\sim30\text{ dB}$) | 고품질 시준 렌즈, 대구경 수신 렌즈 |
| 미에 산란 ($A_{\text{fog}}$) | 레이저 파장 크기의 안개 입자에 의한 산란 | 최대 $100\sim300\text{ dB/km}$ (최대 위협) | 1550nm 광원 채택, RF 하이브리드 절체 |
| 대기 흡수 ($A_{\text{abs}}$) | 공기 중 수증기($H_2O$), $CO_2$ 분자 흡수 | 특정 공진 흡수선에서 급증 | 대기의 창(Atmospheric Window) 파장 선택 |
| 신틸레이션 ($A_{\text{scint}}$) | 온도 불균일로 인한 공기 굴절률 요동 | 수신 광세기 $\pm20\text{ dB}$ 랜덤 변동 | 개구 평균화, 적응 광학(Adaptive Optics) |
| 빌딩 동요 ($A_{\text{sway}}$) | 바람/진동에 따른 수신 렌즈 광축 이탈 | 순간적 광 전력 차단 | 고속 폐루프 PAT(FSM), 다중 빔 전송 |

- **개구 평균화 (Aperture Averaging)** : 수신 렌즈 구경을 대기 난류의 공간적 상관 길이(Correlation Length)보다 크게 설계하여, 렌즈 표면에 도달하는 밝고 어두운 무늬를 공간적으로 평균화함으로써 광세기 요동(Scintillation)을 억제.

## Ⅳ. FSO 채널 엔지니어링의 주요 한계점 및 해결 방안

- 대기 난류 페이딩에 따른 순간 버스트 오류(Burst Error) 발생 :
  - 한계점 : 신틸레이션으로 인해 수 밀리초 동안 수신 광량이 수신 감도 임계치 이하로 떨어져 연속적인 비트 에러 유발.
  - 해결 방안 : 공간 다이버시티(다중 송수신 광학계: MIMO-FSO) 적용, 긴 인터리빙(Interleaving) 및 강력한 순방향 오류 정정(LDPC 코딩) 결합.
- 국지적 안개 통계 부재로 인한 링크 가용률 설계 오차 :
  - 한계점 : 공항 기상 데이터와 실제 건물 옥상 국소 지역의 안개 지속 시간 간의 괴리로 통신 품질 SLA 위반.
  - 해결 방안 : 설치 예정 지역의 마이크로 기후 데이터 기반 링크 버짓 계산($P_{\text{rx}} = P_{\text{tx}} - \sum A_i \ge S_{\text{rx}} + \text{Margin}$) 및 고가용 설계를 위한 전송 거리 1km 이내 보수적 제한.

## Ⅴ. FSO 채널 엔지니어링 발전을 위한 기술사적 제언

- 적응형 전송률 및 전력 제어 (Adaptive Modulation & Power Control) : 채널 상태 정보(CSI)를 실시간 피드백하여 맑은 날에는 64-QAM 및 저출력 운용, 기상 악화 시 BPSK 및 고출력으로 동적 가변하는 적응형 스택 구현.
- 적응 광학(Adaptive Optics: AO) 기술의 상용화 도입 : 천체 망원경에서 대기 왜곡을 보정하던 파면 센서(Shack-Hartmann)와 변형 거울(Deformable Mirror)을 FSO 수신단에 소형 집적화하여 수신 파면 위상 왜곡 실시간 복원.
- 양자 암호 통신(QKD) 지상-위성 채널 링크 버짓 체계화 : 대기권을 통과하는 위성-지상 간 광 채널의 손실 및 편광 회전 특성을 정밀 계산하여 포스트 양자 시대의 무선 보안 통신 인프라 설계 표준화 주도.
