- **자율 네트워크(Autonomous Network):** 네트워크 상태를 바탕으로 운영 판단과 조치의 일부를 자동 수행하는 통신망 운영 방식

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **자율 네트워크(Autonomous Network)** 는 망 상태에 따라 운영 판단과 조치의 일부를 자동 수행하는 네트워크 운영 방식 |
| 목적 | 반복 운영 부담과 장애·성능 저하의 대응 지연 감소 |

## Ⅱ. 운영 폐루프 구조

```text
망·서비스 상태 수집
        ↓
정책·목표와 현재 상태 비교
        ↓
조치 후보와 영향 분석
        ↓ 승인 또는 허용된 자동 실행
네트워크 설정·자원 변경
        ↓
서비스 결과 측정 ── 기준 미달이면 재판단
```

| 단계 | 주요 입력·행위 | 운영 기록 |
|---|---|---|
| 관측 | 성능·장애·자원 상태 수집 | 측정 지표와 수집 시점 |
| 판단 | 목표·정책과 현재 상태 비교 | 판단 근거·대상 |
| 실행 | 설정·자원 변경 | 변경 주체·승인·롤백 정보 |
| 검증 | 서비스 결과와 목표 비교 | 개선 여부·후속 조치 |

## Ⅲ. 자율화 범위의 단계적 확대

| 적용 범위 | 자동화 대상 | 사람의 역할 |
|---|---|---|
| 관측·분석 | 상태 수집, 이상 탐지·원인 분석 지원 | 결과 검토와 조치 결정 |
| 권고 | 조치 후보와 영향 제시 | 승인·우선순위 결정 |
| 제한된 자동 조치 | 사전 승인된 범위의 반복 설정 변경 | 예외 승인·중단·감사 |
| 확장 자율 운영 | 여러 운영 기능의 연계·조정 | 목표·권한·안전 경계 감독 |

IITP의 2026 AI·ICT 이슈는 네트워크의 자율행동과 완전자율통신망의 성숙도 논의를 전망 항목으로 제시

## Ⅳ. 적용 한계와 통제

| 한계 | 대응 |
|---|---|
| 잘못된 측정·정책이 자동 조치로 확대될 수 있음 | 데이터 품질 확인, 변경 범위 제한, 안전 임계치와 중단 조건 설정 |
| 조치 결과가 예측과 달라 서비스 영향 발생 가능 | 사전 영향 분석, 소규모 적용, 자동 롤백과 수동 전환 경로 확보 |
| 자동화가 늘며 변경 책임·감사 근거가 흩어질 수 있음 | 입력 상태·판단 근거·실행 결과를 변경 기록으로 연결 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 완전자율화를 목표로 일괄 적용하면 오판의 영향 범위와 책임 구분이 커질 수 있음 | 영향이 제한된 반복 업무부터 자동 실행하고, 서비스 영향·복구 가능성을 확인하며 권한 범위를 확대 |
