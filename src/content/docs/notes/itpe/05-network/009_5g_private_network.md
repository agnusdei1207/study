## 30초 인출

- 본질: **5G 특화망** : 특정 조직·지역의 업무에 맞춰 구축·운영하는 비공중 5G망
- 메커니즘: 전용 무선접속망과 5G 코어의 전체 또는 일부를 업무 요구에 맞춰 배치하고 현장 서비스에 연결
- 통찰: 통신 3사의 공용망에 의존하지 않고 기업이 자사 전용 주파수(4.7GHz/28GHz)를 할당받아 특정 공간에 맞춤형 초고속·초저지연 무선망을 구축하여 데이터 주권과 보안을 확보하는 사설 무선 인프라임.

<details>
<summary>핵심 용어</summary>

- **5G 특화망(이음5G)** : 국내에서 기업·기관 등의 수요에 맞춰 구축하는 5G 기반 통신망
- **NPN(Non-Public Network)** : 특정 조직 또는 이용 범위에 제공하는 3GPP의 비공중망 개념
- **SNPN(Standalone NPN)** : 공중망과 독립적으로 식별·운영되는 비공중망 구성
- **PNI-NPN(Public Network Integrated NPN)** : 공중망의 자원 또는 기능을 활용하는 비공중망 구성
- **UPF(User Plane Function)** : 사용자 데이터의 전달·분기 등을 담당하는 5G 코어 기능
- **로컬 브레이크아웃(Local Breakout)** : 트래픽을 현장 가까운 데이터망으로 분기하는 배치 방식

## 2~4교시 25점 답안

## Ⅰ. 5G 특화망(이음5G)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 토지 또는 건물 등 특정 구역에 한해 비통신 사업자가 자체 전용 5G 주파수(4.7GHz, 28GHz)를 정부로부터 승인받아 맞춤형으로 구축·운용하는 사설(Private) 5G 네트워크 |
| 목적 | 공용망 간섭 없는 무선 초저지연(URLLC) 달성, 산업 기밀 데이터의 역외 유출 방지(데이터 주권 확보) 및 제조/물류 현장의 전주기 자동화 |

## Ⅱ. 5G 특화망(이음5G)의 특징

| 특징 | 상세 내용 |
|---|---|
| 전용 주파수 할당 | 공용 통신사 대역과 격리된 전용 대역(Sub-6: 4.7GHz 100MHz폭, mmWave: 28GHz 600MHz폭) 사용 |
| 서비스 맞춤 설계 | 상향(Uplink)과 하향(Downlink) 트래픽 비율을 공용망(3:7)과 달리 영상 전송 중심(6:4)으로 커스텀 배분 |
| 완전한 보안 격리 | 데이터 평면(UPF)을 사내 전산실에 온프레미스로 배치하여 민감한 산업 제어 데이터의 외부 반출 차단 |
| 초고신뢰·저지연 | 공용 통신사 망의 트래픽 혼잡과 분리되어 99.999% 무선 가용성 및 1ms대 무선 전송 지연 보장 |

## Ⅲ. 5G 특화망(이음5G)의 체계·프로세스

**이음5G 시스템 아키텍처 및 산업 현장 데이터 처리 흐름**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 이음5G 온프레미스 독립망 구조 ]              │
│                                                                        │
│ [ 산업 현장 (Factory Floor) ]                                          │
│   ┌──────────────┐     ┌──────────────┐     ┌──────────────┐           │
│   │ AGV / AMR    │     │ 협동 로봇    │     │ 4K 머신비전  │           │
│   │ (실시간 제어)│     │ (원격 제어)  │     │ (영상 검사)  │           │
│   └──────┬───────┘     └──────┬───────┘     └──────┬───────┘           │
│          │                    │                    │                   │
│          ▼ (이음5G 전용 주파수: 4.7GHz / 28GHz)     ▼                   │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ 이음5G 무선 접속망 (Private gNodeB Radio / Distributed Unit) ] │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │                                    │
│ [ 사내 전산실 / 온프레미스 에지 ] ▼ (N3 Interface)                    │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ 사설 5G 코어 (Private 5GC) & MEC ]                           │   │
│   │   - 로컬 UPF (User Plane Function): 고속 패킷 라우팅           │   │
│   │   - 경량 AMF/SMF: 사내 전용 SIM 단말 인증 및 세션 제어         │   │
│   │   - 에지 컴퓨팅 (MEC): 머신비전 AI 추론 및 AGV 경로 관제       │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │                                    │
│                                   ▼ (사내 LAN 격리 보존)               │
│                     [ 기업 내부 MES / ERP 서버 ]                       │
└────────────────────────────────────────────────────────────────────────┘
```

| 구성 계층 | 주요 컴포넌트 | 기능 및 구축 방안 |
|---|---|---|
| **단말 계층** | 5G 전용 모뎀, 전용 eSIM/USIM | 이음5G 전용 PLMN ID(450-xx)가 등록된 산업용 단말만 접속 허가 |
| **무선망 (RAN)** | Private gNodeB, RU/DU/CU | 제조 현장 천장 및 기둥에 소형 스몰셀 분산 배치, 빔포밍 안테나 적용 |
| **코어망 (5GC)** | 경량화 온프레미스 5GC Appliance | 가상화(K8s/Docker) 기반 5GC 패키지 도입으로 상면 및 유지보수 간소화 |
| **에지 컴퓨팅** | Edge Computing (MEC) | 공장 내부 로컬 UPF와 직결하여 트래픽 백홀 전송 없이 1ms 내 AI 분석 완료 |

## Ⅳ. 5G 특화망(이음5G)의 종류·비교

| 비교 항목 | 온프레미스 독립형 (Full Private) | 통신사 망 연동형 (RAN/Core 공유형) |
|---|---|---|
| **구축 방식** | 무선 기지국 및 5G Core 전체를 사내에 자체 구축 | 기지국만 사내 설치하고 5G Core는 통신사 클라우드 이용 |
| **데이터 보안** | 완벽한 보안 격리 (외부 인터넷 완전 차단 가능) | 제어 신호가 공용망으로 전송되어 보안 심의 필요 |
| **초기 투자비** | 높음 (전용 코어망 및 기지국 장비 일체 구매) | 낮음 (통신사 장비 임대 및 월 과금 서비스 형태) |
| **유지보수 책임**| 기업 자체 전문 운영 인력 필요 | 통신사 매니지드 서비스를 통한 24x365 관제 지원 |
| **적합 분야** | 국가 첨단 보안 시설, 방위산업체, 대규모 제조공장 | 중소형 물류창고, 지자체 스마트시티 실증 단지 |

## Ⅴ. 5G 특화망(이음5G)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 28GHz 초고주파 대역의 직진성 및 강한 회절 손실로 인한 실내 음영 발생 | Sub-6 대역(4.7GHz)을 커버리지 기본망으로 구축하고 28GHz는 특정 집중 작업 구역에 분원 스몰셀 배치 |
| 중소·중견 기업의 무선 통신 전문 운영 엔지니어 부재 및 초기 CAPEX 부담 | NaaS(Network-as-a-Service) 형태의 구독형 이음5G 매니지드 서비스 도입 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
스마트 팩토리 이음5G 구축 시, AGV 자율주행과 CCTV 영상 검사가 동시 수행되는 현장에서는 TDD 프레임 슬롯 구성을 특화망 전용 3:1 또는 2:2(DL:UL) 비율로 커스터마이징하여 업링크 병목 현상을 선제적으로 해소.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 이음5G TDD 프레임 슬롯 커스터마이징 구조 ]                           │
│                                                                        │
│   [ 공용 통신사 5G TDD 슬롯 : 다운링크 중심 (소비자 콘텐츠 소비) ]     │
│   ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐            │
│   │ D    │ D    │ D    │ D    │ D    │ D    │ D    │ U    │ (DL:UL = 7:1)│
│   └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘            │
│                                                                        │
│   [ 이음5G 스마트 팩토리 TDD 슬롯 : 업링크 대폭 강화 (비전 검사 데이터)│
│   ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐            │
│   │ D    │ D    │ S    │ U    │ U    │ U    │ U    │ U    │ (DL:UL = 2:5)│
│   └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘            │
│   * D: Downlink, U: Uplink, S: Special Slot (전환 갭)                  │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 구분 | 4.7 GHz 대역 | 28 GHz 대역 |
|---|---|---|
| **할당 대역폭** | 100 MHz 폭 (4.72 ~ 4.82 GHz) | 600 MHz 폭 (28.9 ~ 29.5 GHz) |
| **전파 도달 범위** | 300m ~ 1km (회절성 우수) | 50m ~ 100m (가시선 LOS 한정) |
| **최대 전송 속도** | 약 1 Gbps | 약 4 Gbps 이상 |
| **주요 추천 용도** | 공장 전역 AGV 주행 제어, IoT 센서 수집 | 초고화질 8K 비전 검사, 실시간 AR 원격 수리 |
