## Ⅰ. 5G 특화망(이음5G)의 개요

- **개념** : 통신 3사의 공용 5G 이동통신망을 거치지 않고, 특정 기업·기관이 토지·건물 등 한정된 자가 구역에 맞춤형 소프트웨어와 전용 5G 주파수(4.7GHz, 28GHz)를 할당받아 직접 구축·운영하는 독립형 사설 5G 인프라.
- **배경 및 필요성** : 제조 스마트 팩토리, 물류, 항만, 국방 등 산업 현장에서 공용망 사용 시 트래픽 혼잡에 따른 지연시간 가변성과 기업 내부 핵심 데이터 유출 우려를 해소하고, Wi-Fi의 핸드오버 불안정성을 극복하기 위해 출현함.
- **핵심 목적** : 제조·물류 현장의 극초저지연(1ms 내외) 무선 제어, 데이터의 로컬 구역 내 완벽한 격리(Data Sovereignty), 특정 산업 워크로드(AMR, 디지털 트윈) 맞춤형 QoS 보장.

## Ⅱ. 5G 특화망(이음5G)의 핵심 아키텍처 및 동작 메커니즘

이음5G는 전용 주파수를 기반으로 구축 형태에 따라 온프레미스 독립형, 클라우드 코어 공유형, 상용망 슬라이싱 모델 등으로 분화되며, 현장 에지 컴퓨팅(MEC)과 직접 결합하여 트래픽을 처리함.

```text
[ 5G 특화망 (이음5G) 온프레미스 완전 독립형 아키텍처 ]

+-----------------------------------------------------------------+
|                   공장 / 빌딩 자가 구역 (On-Premise)            |
|                                                                 |
|  [ 전용 단말군 ]         [ 무선 기지국 ]        [ 코어 & 컴퓨팅]  |
|  +-------------+        +-------------+        +-------------+  |
|  | 자율이동로봇| <====> | Radio Unit  |        | Private 5GC |  |
|  | (AMR / AGV) |        | (RU: 안테나)|        | - UPF (로컬)|  |
|  +-------------+ (4.7GHz│      │      |        | - AMF / SMF |  |
|  +-------------+  28GHz)│      ▼      | (eCPRI)+-------------+  |
|  | AI 비전 검사| <====> | DU / CU     | <====> | Edge MEC    |  |
|  | 카메라 (4K) |        | (분산/집중) | (10GbE)| (AI 검사 S/W|  |
|  +-------------+        +-------------+        |  디지털트윈)|  |
|                                                +-------------+  |
|                                                        │        |
|  * 기업 내부 데이터 외부 유출 원천 차단 (Local UPF)   ▼        |
|  * 1ms 극초저지연 유지 (On-site UPF Offloading)   [사내 ERP/MES]|
+-----------------------------------------------------------------+
                     (외부 인터넷/공용망 단절)
```

- **전용 주파수(4.7GHz & 28GHz)** : 간섭 없는 초광대역 전송을 위해 과학기술정보통신부가 이음5G 전용으로 분배한 주파수 대역(4.7GHz 대역 100MHz폭, 28GHz 대역 600MHz폭).
- **Private 5GC(독립형 코어)** : AMF, SMF, UPF 등 5G 코어 기능을 기업 구역 내에 경량 소프트웨어로 배치하여 단말 인증과 세션 관리를 사내에서 직접 통제.
- **Local UPF(사용자 평면 기능)** : 모든 현장 무선 트래픽을 외부 통신사망으로 보내지 않고 사내 LAN 및 로컬 MEC로 직접 오프로딩하여 보안성과 극저지연 확보.
- **개방형 기지국(O-RAN 기반 CU/DU/RU)** : 특정 통신장비 제조사에 종속되지 않고 개방형 인터페이스 기반의 상용 COTS 하드웨어 및 소프트웨어 기지국 채택 가능.

## Ⅲ. 5G 특화망(이음5G)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 5G 특화망 (이음5G) | 통신사 공용 5G망 (MNO 망) | 산업용 무선랜 (Wi-Fi 6 / 7) |
|---|---|---|---|
| **주파수 대역** | 전용 주파수 (4.7GHz, 28GHz) | 통신사 면허 대역 (3.5GHz, 28GHz) | 비인가 대역 (2.4GHz, 5GHz, 6GHz) |
| **트래픽 격리** | 완벽한 사내 격리 (외부망 단절) | 공용 백본 경유 (네트워크 슬라이싱) | 사내망 격리 가능 (자체 AP 구축) |
| **핸드오버 신뢰성** | 고속 이동 시 무손실 핸드오버 | 우수한 광역 핸드오버 | AP 간 이동 시 패킷 끊김/지연 잦음 |
| **서비스 품질 (QoS)**| 100% 자가 보장 (간섭 제로) | 타 사용자 트래픽에 따른 가변성 | 비인가 대역 간섭으로 QoS 불안정 |
| **구축/운영 비용** | 초기 인프라 CAPEX 부담 높음 | 통신사 회선 OPEX 과금 형태 | 구축 비용 저렴 (저가 AP 활용) |

- 이음5G는 공용 5G의 광역성과 Wi-Fi의 보안 격리성을 이상적으로 결합하여, 산업 현장의 로봇 제어와 미션 크리티컬 워크로드를 무선화하는 스마트 제조의 핵심 동력임.

## Ⅳ. 5G 특화망(이음5G)의 주요 한계점 및 해결 방안

- **초기 망 구축 CAPEX 및 전문 네트워크 운영 인력 부재** :
  - **한계점** : 중소/중견기업이 기지국과 코어망을 자체 구매하여 운영하기에는 초기 비용과 기술적 진입 장벽이 극심함.
  - **해결 방안** : 코어망을 중앙 CSP 클라우드에 두고 UPF만 현장에 두는 클라우드 관리형 사설 5G(NaaS: Network-as-a-Service) 모델 도입.
- **28GHz 밀리미터파(mmWave)의 회절성 취약 및 음영 지역 발생** :
  - **한계점** : 금속 설비와 기계가 밀집한 공장 환경에서 28GHz 전파의 직진성으로 인해 기계 뒤편 통신 단절 초래.
  - **해결 방안** : 4.7GHz 대역을 기반 커버리지로 구성하고, 28GHz는 초고화질 비전 검사 구역에 국소 배치하는 하이브리드 주파수 설계.
- **산업용 레거시 유선 프로토콜과의 이종 연동 난제** :
  - **한계점** : 기존 공장의 Profinet, Modbus, EtherCAT 등 산업용 이더넷 표준과의 상호 연동성 결여.
  - **해결 방안** : 3GPP 표준 5G TSN(Time-Sensitive Networking) 브리지 기술을 적용하여 유무선 통합 확정적 지연 환경 구현.

## Ⅴ. 5G 특화망(이음5G) 적용 및 발전을 위한 기술사적 제언

- **스마트 팩토리 AMR/자율주행 지게차 관제를 위한 5G TSN 연계 고도화** : 공장 내 초정밀 동기화(마이크로초 단위)를 위해 이음5G 인프라에 IEEE 802.1AS 표준 동기 프로파일 연계 필수.
- **생태계 확장을 위한 이음5G 전용 단말(CPE) 및 모듈 단가 인하 지원** : 국산 통신 모듈 및 단말 칩셋 인증을 간소화하고 공공 주도 실증 사업을 통해 규모의 경제 조기 달성 유도.
- **제로 트러스트 기반 사설 5G 보안 거버넌스 수립** : SIM/eSIM 기반의 강력한 하드웨어 디바이스 상호 인증과 내부 마이크로 세그멘테이션을 결합한 융합 보안 체계 구축 권장.
