## Ⅰ. 차동적 맨체스터(Differential Manchester) 부호화의 개요

- **개념** : 전송 선로의 절대 전압 레벨에 의존하지 않고 신호의 위상 변화(Phase Transition) 유무를 통해 데이터를 표현하며, 매 비트 구간의 정중앙에서 항상 강제 전이를 발생시켜 완벽한 클록 복원과 직류 평형을 보장하는 바이페이즈(Biphase) 물리 계층 부호화 기술.
- **배경 및 필요성** : 장거리 물리 케이블 포설 시 발생하기 쉬운 꼬임선 결선 반전(Polarity Reversal) 오류에 대해 시스템 중단 없이 강인하게 동작하고, 변압기 결합 회로에서 직류 바이어스로 인한 자기 포화를 원천 방지하기 위해 정립됨.
- **핵심 목적** : 케이블 극성 반전에 대한 100% 하드웨어 내결함성(Fault Tolerance) 확보, 수신단 PLL의 연속 클록 동기화 유지, 기저대역 전송 신호의 직류 성분(DC Offset) 완전 제거.

## Ⅱ. 차동적 맨체스터(Differential Manchester) 부호화의 핵심 아키텍처 및 동작 메커니즘

차동적 맨체스터 부호화는 이전 비트의 종료 상태를 기준으로 시작점 전이(비트 '0') 또는 무전이(비트 '1')를 결정하고, 비트 중앙에서 클록 추출용 강제 전이를 일으키는 상태 머신 메커니즘으로 동작함.

```text
[ 차동적 맨체스터 부호화의 상태 머신 및 신호 전이 원리 ]

상태 전이 규칙:
 - 비트 시작점: '0'이면 이전 신호 레벨 반전 (전이 발생)
                '1'이면 이전 신호 레벨 유지 (전이 없음)
 - 비트 정중앙: 비트 값과 무관하게 항상 레벨 반전 (클록 에지 생성)

[ 신호 생성 상태 전이 다이어그램 ]
                 ┌────────────────────────────────┐
                 │                                │
                 ▼                                │
  [ 이전 비트 끝 레벨: Low ]                     [ 이전 비트 끝 레벨: High ]
      │                     │                         │                     │
      │ 비트 '0' (시작전이) │ 비트 '1' (시작유지)     │ 비트 '0' (시작전이) │ 비트 '1' (시작유지)
      ▼                     ▼                         ▼                     ▼
  시작: High            시작: Low                 시작: Low             시작: High
  중앙: Low로 반전      중앙: High로 반전         중앙: High로 반전     중앙: Low로 반전
  끝:   Low             끝:   High                끝:   High            끝:   Low

[ 하드웨어 수신단 구조 ]
선로 신호 ──► [ 차동 증폭기 / 리시버 ] ──► [ DPLL (중앙 에지 클록 복원) ]
                                              │
                                              ▼
                                         [ 시작점 전이 판별기 ] ──► 0/1 복원 데이터
```

- **차동 상태 전이 논리** : 비트 '0'은 경계면에서 신호 반전이 발생하고, 비트 '1'은 이전 상태를 그대로 연장함으로써 신호의 상대적 변화량만으로 정보를 전달.
- **중앙 클록 전이(Mid-bit Transition)** : 매 비트 셀(Bit Cell)의 50% 지점에서 무조건 전이가 발생하여 수신단 디지털 위상동기루프(DPLL)가 연속적으로 클록 주파수를 잠금(Lock).
- **직류 평형(DC Balance)** : 모든 비트 셀 내에서 High 레벨과 Low 레벨이 정확히 50:50의 듀티 사이클(Duty Cycle)을 유지하므로 장거리 전송 시 신호 왜곡 및 감쇠 최소화.
- **차동 선로 결선 무관성** : 신호선($+$와 $-$)이 반대로 연결되어 전압 극성이 완전히 뒤집히더라도 전이의 유무 자체는 변하지 않으므로 수신 데이터가 정상 복원됨.

## Ⅲ. 차동적 맨체스터(Differential Manchester) 부호화의 세부 구성 요소 및 비교 분석

| 비교 항목 | NRZ-I (차동 NRZ) | 표준 맨체스터 (Manchester) | 차동적 맨체스터 (Diff. Manchester) |
|---|---|---|---|
| **부호화 계열** | 비복귀 영 (NRZ 계열) | 바이페이즈 (Biphase 계열) | 바이페이즈 (Biphase 계열) |
| **비트 판별 방식** | 비트 시작 전이로 1/0 판별 | 중앙 전이 방향 (상승:1, 하강:0) | 비트 시작 전이 유무 (0:전이, 1:무전이) |
| **중앙 클록 전이** | 없음 (연속 0 입력 시 동기 상실)| 항상 존재 (클록 겸용) | 항상 존재 (순수 클록 역할만 전담) |
| **극성 반전 영향** | 정상 수신 가능 | 비트 오류 (0과 1이 반전됨) | 정상 수신 가능 (완벽한 극성 내성) |
| **주파수 대역폭** | $B$ (비트레이트 수준) | $2B$ (비트레이트의 2배 요구) | $2B$ (비트레이트의 2배 요구) |
| **하드웨어 복잡도**| 낮음 | 보통 | 보통 ~ 높음 (시작/중앙 판별 로직) |

- 차동적 맨체스터는 표준 맨체스터가 지닌 클록 동기화 및 직류 평형의 이점을 모두 취하면서도, 결선 극성 반전 시 데이터가 뒤집히는 치명적 약점을 완벽히 해결한 기술임.

## Ⅳ. 차동적 맨체스터(Differential Manchester) 부호화의 주요 한계점 및 해결 방안

- **Baud Rate 증가에 따른 신호 감쇠 및 구리선 고주파 대역폭 한계** :
  - **한계점** : 1비트 전송에 2회의 상태 변화가 수반되므로 100Mbps 전송에 200Mbaud가 필요하여 동축/TP 케이블 거리 제약.
  - **해결 방안** : 고속 전송 구간에서는 Scrambling 기반 블록 코딩(8b/10b, 64b/66b) 또는 다준위 PAM 코딩으로 전환.
- **케이블 분산(Dispersion)으로 인한 에지 지터와 샘플링 윈도우 마진 감소** :
  - **한계점** : 전송 거리가 길어질수록 신호 에지가 완만해져 비트 시작점 전이와 중앙 전이의 시간 구분이 모호해짐.
  - **해결 방안** : 수신단에 고대역 적응형 하드웨어 이퀄라이저(Equalizer) 탑재 및 오버샘플링 DPLL 적용.
- **트랜시버 하드웨어 회로의 복잡도 및 칩셋 단가 상승** :
  - **한계점** : 단순 레벨 감지 회로 대비 상태 머신과 차동 복호 로직이 추가되어 물리 계층 칩셋 설계 비용 증가.
  - **해결 방안** : 표준 임베디드 통신 PHY ASIC 칩셋 단일 다이(Die) 집적화.

## Ⅴ. 차동적 맨체스터(Differential Manchester) 부호화 적용 및 발전을 위한 기술사적 제언

- **가혹한 전자기 간섭(EMI) 환경의 산업용 필드버스 및 항공전자(Avionics) 표준 채택** : 공장 자동화 현장이나 항공기 내부 제어망처럼 노이즈와 오배선 위험이 상존하는 영역에 필수 적용 권장.
- **차동 신호 인터페이스(RS-485/CAN)와의 물리적 시너지 극대화** : 차동 전압 전송 하드웨어와 차동 맨체스터 로직 부호화를 결합하여 공통 모드 잡음(Common-mode Noise) 완전 차단망 구축.
- **신호 무결성(Signal Integrity) 보증을 위한 아이 패턴(Eye Pattern) 자동 검사** : 지터 허용 오차 및 비트 셀 듀티 사이클 변동을 사전에 모니터링하여 케이블 노후화에 따른 통신 단절 선제 예방.
