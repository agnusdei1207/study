## 연관 키워드

- 차동 맨체스터 부호화(Differential Manchester Coding), 물리 계층(Physical Layer), 라인 코딩(Line Coding), 자체 클록(Self-Clocking)
- 맨체스터 부호화(Manchester Coding), NRZ-L, IEEE 802.3, IEEE 802.5, 토큰링(Token Ring), 직류 평형(DC Balance)

## Ⅰ. 차동 맨체스터 부호화의 개요

- 핵심 요약 : 비트 시작점의 전이 유무로 0과 1을 가리고 비트 중앙의 전이로 클록을 공급하는 물리 계층 라인 코딩.
- 개념 : 디지털 비트열을 전기 신호로 보낼 때 **라인 코딩**(Line Coding)의 한 방식으로, 매 비트 구간의 중앙에서 반드시 전이가 일어나 **자체 클록**(Self-Clocking)을 제공하고, 비트 값은 구간 시작점의 전이 유무로 판별하는 방식.
- 배경 및 필요성 : 절대 레벨을 쓰는 비복귀 영(NRZ, Non-Return-to-Zero) 계열의 NRZ-L 방식은 같은 비트가 이어질 때 클록을 잃고, 배선이 뒤바뀌면 0과 1이 모두 반전되는 한계가 있음. 이를 해결하기 위해 IEEE(Institute of Electrical and Electronics Engineers) 802.5 토큰링 같은 LAN 표준에서 차동 방식이 채택됨.
- 주요 목적 : 클록 동기 확보, 선로 극성 반전 내성 확보, 직류 성분 제거.

## Ⅱ. 차동 맨체스터 부호화의 특징 및 장점

- 핵심 요약 : 중앙 전이와 상대적 판별이 결합해 클록 동기와 배선 무관성을 함께 얻는 구조.

1. 클록 내장 : 중앙 전이를 수신단 PLL(Phase-Locked Loop, 위상 고정 루프)이 추적 → 긴 연속 비트에서도 샘플링 시점 유지.
2. 상대적 판별 : 절대 전압이 아닌 전이 유무로 비트를 판정 → 극성이 뒤집혀도 결과가 변하지 않아 배선 오류에 강함.
3. 직류 평형 : 비트 셀마다 양과 음의 레벨이 절반씩 존재 → 변압기 결합과 장거리 전송에 유리.

## Ⅲ. 차동 맨체스터 부호화의 구조 (흐름)

- 핵심 요약 : 시작점 규칙으로 값을 정하고 중앙 규칙으로 클록을 만드는 두 전이 규칙의 순서.

```text
[ 비트 1개 구간의 전이 순서 ]

비트 시작점
  0 → 전이 있음
  1 → 전이 없음
      ↓
비트 중앙
  값과 무관하게 전이 (클록 에지)
      ↓
다음 비트 구간
```

```text
[ 비트열 0 1 0 0 의 판별 예 ]

비트 0 : 시작점 전이 O → 0
비트 1 : 시작점 전이 X → 1
비트 0 : 시작점 전이 O → 0
비트 0 : 시작점 전이 O → 0
```

## Ⅳ. 맨체스터 계열과의 비교

- 핵심 요약 : 표준 맨체스터의 클록 장점은 유지하되, 판별 기준을 절대 방향에서 상대 전이로 바꿔 극성 취약성을 없앤 방식.

| 비교 축 | NRZ-L | 표준 맨체스터 (IEEE 802.3 이더넷) | 차동 맨체스터 (IEEE 802.5 토큰링) |
| --- | --- | --- | --- |
| 판정 기준 | 전압 레벨 (High/Low) | 중앙 전이의 방향 | 시작점 전이 유무 |
| 클록 동기 | 어려움 (연속 비트에서 상실) | 우수 | 우수 |
| 극성 반전 내성 | 취약 | 취약 (방향이 뒤집힘) | 강함 (전이 유무만 봄) |
| 대역폭 | 비트레이트 수준 | 비트레이트의 2배 | 비트레이트의 2배 |
| 직류 성분 | 누적되기 쉬움 | 제거 | 제거 |

- 선택 기준 : 배선 극성이 안정적이고 단순 구조가 중요하면 표준 맨체스터, 배선 오류와 노이즈가 잦으면 차동 맨체스터가 적합.

## Ⅴ. 차동 맨체스터 부호화의 한계와 방안

- 핵심 요약 : 대역폭 소모, 전이 지터, 칩 복잡도의 세 한계를 블록 부호화, 등화, 집적으로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 대역폭 소모 | 비트당 2회 전이로 고속 구간의 신호 주파수 증가, 구리선 감쇠 | 고속에서는 4B/5B, 8B/10B 같은 블록 부호화나 다준위 변조로 전환 | 보드 레이트, 신호 감쇠 |
| 전이 지터 | 장거리 전송에서 에지가 무뎌져 시작점과 중앙 전이 판별이 흔들림 | 이퀄라이저 보강과 고정밀 DPLL 클록 복원 | 지터 폭, 비트 오류율 |
| 회로 복잡도 | 상태 판별과 차동 복호 로직이 추가되어 칩 설계 비용 증가 | 물리 계층 칩에 집적해 단일 부품으로 공급 | 칩 단가, 설계 비용 |

## Ⅵ. 차동 맨체스터 부호화에 대한 기술사적 제언

- 핵심 요약 : 노이즈와 오배선이 상존하는 현장 제어망을 우선 대상으로 하고, 고속 구간과의 역할을 나누는 적용 원칙.
- 공장 자동화 현장과 항공기 내부 제어망처럼 전자기 잡음과 오배선 위험이 큰 영역에서 차동 맨체스터 기반 필드버스를 표준으로 채택하는 것이 적절하다.
- 차동 신호 인터페이스(RS-485, CAN(Controller Area Network))와 함께 쓰면 공통 모드 잡음 억제 효과가 커지므로, 물리 계층 설계 시 두 방식을 함께 검토할 필요가 있다.
- 운용 단계에서는 아이 패턴(Eye Pattern)을 주기 점검하여 지터 여유와 듀티 사이클 변동을 추적하고, 케이블 노후화를 통신 단절 전에 발견하는 체계가 필요하다.

## Ⅶ. 결론

- 핵심 요약 : 차동 맨체스터 부호화는 상대적 전이 판별로 클록과 배선 무관성을 함께 보장하는 물리 계층 라인 코딩.
- 시사점 : 가혹한 배선 환경의 저속 제어망에서 가치가 크며, 고속 전송 영역은 블록 부호화가 담당하는 구조로 이해하는 것이 적절.
