## 연관 키워드

- FSO(Free Space Optics), 자유공간 광통신, 레이저 빔, 가시선(LOS, Line of Sight)
- PAT(Pointing, Acquisition, Tracking), FSM(Fast Steering Mirror), 폐루프 제어
- 미에 산란(Mie Scattering), 하이브리드 FSO/RF, 밀리미터파, 광섬유
- 양자 키 분배(QKD, Quantum Key Distribution), 무면허 주파수

## Ⅰ. FSO(Free Space Optics) 통신의 개요

- 핵심 요약 : 광섬유 대신 대기 등 자유공간에 레이저 빔을 쏘아 고속 데이터를 전달하는 무선 광통신 방식.
- 개념 : 광섬유를 포설하지 않고 자유공간을 채널로 삼아 적외선 레이저 빔으로 고속 데이터를 주고받는 **자유공간 광통신** (FSO, Free Space Optics).
- 배경 및 필요성 : 하천, 철도, 도심 밀집 구역처럼 지중 광케이블 매설이 어렵거나 토목 비용이 큰 구간에서 광급 링크를 단기간에 개통해야 하는 요구가 늘어남.
- 주요 목적 : 주파수 인허가 없이 광대역 링크를 열고, 좁은 빔으로 도청 위험을 낮추며, 재난 시 임시 백홀을 신속히 복구.

## Ⅱ. FSO 통신의 특징 및 장점

- 핵심 요약 : 레이저의 좁은 지향성과 무면허 특성이 보안과 빠른 개통으로 이어지고, 빔 정렬을 자동으로 유지하는 제어가 전제됨.

1. 무면허 광대역 : 전파 주파수를 쓰지 않아 인허가 절차가 없음 → 개통 기간 단축.
2. 좁은 지향성 : 빔 폭이 좁아 제3자가 빔 경로에 접근하기 어려움 → 물리 계층 수준의 도청 억제.
3. 전자파 간섭 무관 : 전파 대역을 쓰지 않아 기존 무선 장비나 레이더와 충돌하지 않음 → 설치 시 간섭 우려 감소.
4. 자동 정렬 : **PAT** (Pointing, Acquisition, Tracking, 지향·포착·추적) 제어가 빔을 수신기에 유지 → 건물 진동 속에서도 링크 유지.

## Ⅲ. FSO 통신의 구조 (흐름)

- 핵심 요약 : 송신부의 레이저 빔이 가시선으로 날아가 수신부에서 전기 신호로 복원되고, 그 사이의 빔 정렬을 폐루프가 지속 보정하는 구조.
- 광학계 송수신 : 전기 신호를 레이저 다이오드로 빛에 싣고 렌즈로 시준(Collimation)해 가시선으로 송출하며, 수신 렌즈가 모은 빛을 광검출기가 다시 전기 신호로 바꿈.
- 지향 : 마이크로라디안($\mu\text{rad}$) 단위의 미세 빔을 목표 수신기의 개구면으로 조준.
- 포착과 추적 : 수신 측 센서가 레이저 스팟 위치를 감지하고, **고속 조향 거울** (FSM, Fast Steering Mirror)이 바람이나 진동으로 틀어진 광축을 실시간 보정.

```text
[ 송신부 ]
전기 신호 → 레이저 다이오드
        ↓ 렌즈 시준 (Collimation)
[ 자유공간 채널 ]
가시선 레이저 빔 전파
        ↓
[ 수신부 ]
대구경 수신 렌즈 → 광검출기
        ↓
전기 신호 복원
```

```text
수신 빔 위치 감지 (4분할 포토다이오드)
        ↓
위치 오차 계산 (폐루프)
        ↓
고속 조향 거울 각도 보정
        ↓
빔 중심 유지 후 다시 감지
```

## Ⅳ. FSO와 밀리미터파 무선(RF)의 비교

- 핵심 요약 : 무면허와 전파 간섭 없음이 FSO의 강점이고, 기상 취약성과 정렬 의존이 약점이라 두 기술은 상호 보완 관계.

| 비교 축 | FSO (자유공간 광통신) | 밀리미터파 무선 (RF, Radio Frequency; 60GHz, E-band) |
| --- | --- | --- |
| 전송 매체 | 적외선 레이저 | 밀리미터파 전파 |
| 전송 대역폭 | 광대역 (수 Gbps 이상) | 중·광대역 |
| 주파수 라이선스 | 무면허 (전파법 규제 대상 아님) | 인허가 또는 비인가 대역 |
| 전파 간섭 | 전자기 간섭 없음 | 다른 전파 장비와 간섭 가능 |
| 기상 취약 요인 | 짙은 안개, 연무 (급격한 감쇠) | 강우 (빗방울에 의한 감쇠) |
| 도청 보안성 | 빔이 좁아 도청 어려움 | 전파 누설 시 도청 가능 |
| 설치 편의성 | 건물 옥상, 창문 사이 설치 가능 | 안테나 크기와 전파 음영 고려 필요 |

- 안구 안전 파장 : 1550nm 파장은 각막과 수정체에서 대부분 흡수되어 850nm보다 높은 광출력 송출이 허용됨.
- 선택 기준 : 링크 구간의 기상 조건과 개통 기간을 먼저 보고, 안개가 잦은 구간은 RF를 병행하도록 정함.

## Ⅴ. FSO 통신의 한계와 방안

- 핵심 요약 : 안개, 건물 진동, 대기 난류가 링크를 끊거나 흔들며, 이를 RF 절체, 폐루프 정렬, 공간 다이버시티로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 짙은 안개에 의한 감쇠 | 안개 입자 크기가 레이저 파장과 비슷해 미에 산란이 커져 링크가 끊김 | 밀리미터파 RF 링크를 병렬 배치하고 하이브리드 FSO/RF로 무손실 절체 | 링크 가용률, 절체 횟수 |
| 건물 동요와 열팽창에 의한 광축 이탈 | 바람과 태양열로 건물이 흔들려 빔이 수신 렌즈를 벗어남 | 고속 폐루프 PAT 제어, 다중 빔 분산 송신 | 정렬 이탈 횟수, 복구 시간 |
| 대기 난류에 의한 신틸레이션 | 공기 굴절률 요동으로 수신 광세기가 빠르게 변동 | 개구 평균화, 적응 광학 적용 | 비트 오류율 |

## Ⅵ. FSO 통신 적용 및 발전을 위한 기술사적 제언

- 핵심 요약 : 통신 사업자의 FSO·RF 백홀 활용, 위성 간 레이저 링크 표준화, FSO와 QKD의 광학 계층 통합으로 활용 범위를 넓히는 것.

1. 통신 사업자가 도심 5G·6G 기지국의 백홀 대안으로 FSO와 RF를 함께 배치하면, 광케이블 공사가 어려운 핫스팟에서 망 구축 기간과 비용 부담을 줄일 수 있다.
2. 국가 우주 기관과 위성 사업자가 저궤도 위성 간 레이저 링크를 공동 표준화하면, 대기 감쇠가 없는 궤도 구간의 광 백본을 체계적으로 구축할 수 있다.
3. 국가 기밀 통신을 맡는 기관은 FSO 광학계와 양자 키 분배(QKD, Quantum Key Distribution)를 함께 설계해 광학 계층의 보안을 강화해야 한다.

## Ⅶ. 결론

- 핵심 요약 : FSO는 광섬유 없이 빠르게 개통하고 도청을 줄이는 무선 광 백홀 기술.
- 시사점 : 기상에 따른 가용성 한계는 RF 하이브리드와 정렬 제어로 보완해야 하며, 이 설계가 실용화의 전제가 된다.
