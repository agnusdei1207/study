## Ⅰ. FSO(Free Space Optics) 통신의 개요

- **개념** : 물리적인 광섬유(Optical Fiber) 케이블 포설 없이, 대기나 우주 진공 등 자유공간(Free Space)을 전송 채널로 활용하여 적외선 레이저 광선으로 수 Gbps 이상의 고속 데이터를 전송하는 무선 광통신 기술.
- **배경 및 필요성** : 하천, 철도, 도심 밀집 구역 등 지중 광케이블 매설 공사가 불가능하거나 막대한 토목 비용이 발생하는 구간에서 단기간에 초고속 광링크를 개통해야 하는 필요성 증대.
- **핵심 목적** : 주파수 인허가(License) 없는 광대역 테라비트급 무선 전송, 도청이 불가능한 극한의 군사/금융 보안 통신망 확보, 자연재해 시 긴급 통신 백홀 긴급 복구.

## Ⅱ. FSO 통신의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ FSO 송수신 시스템 및 PAT 제어 구조 ]                │
│                                                                        │
│   [ 송신부 (Transmitter) ]                                             │
│   전기 신호 ──► 레이저 다이오드(LD) ──► 콜리메이터 ──► 좁은 레이저 빔 방사│
│   (10Gbps)     (850/1310/1550nm 변조)   (렌즈 시준)     (가시선 LOS)    │
│                                                               │        │
│   [ 자유공간 대기 채널 (Free Space Channel) ]                 ▼        │
│   - 기하학적 확산 손실   - 안개에 의한 미에 산란 (Mie)     수 킬로미터 │
│   - 대기 분자 흡수       - 대기 난류 신틸레이션             공간 전파   │
│                                                               │        │
│   [ 수신부 (Receiver) & PAT 서보 시스템 ]                     ▼        │
│   수신 렌즈 ──► 광학 필터 ──► 4분할 포토다이오드 ──► 고감도 APD 광수신  │
│   (대구경)      (태양광 차단) (빔 위치 감지 센서)   (전기 신호 복원)   │
│        │                            │                                  │
│        └────────◄── FSM / 짐벌 ─────┘                                  │
│                 (초고속 미세 거울 각도 보정)                           │
└────────────────────────────────────────────────────────────────────────┘
```

- **광학계 송수신 메커니즘** : 고속 전기 신호(Ethernet 등)를 고출력 반도체 레이저 다이오드로 직접 또는 외부 변조(Mach-Zehnder)한 후 광학 렌즈로 시준(Collimation)하여 가시선(LOS)으로 송출.
- **초정밀 PAT (Pointing, Acquisition, Tracking) 시스템** :
  - **지향 (Pointing)** : 마이크로라디안($\mu\text{rad}$) 단위의 미세 빔을 목표 수신기의 개구면으로 정확히 조준.
  - **포착 (Acquisition)** : 광학 센서(CCD/QPD)를 통해 유입된 레이저 스팟의 초기 입사 위치를 신속 감지.
  - **추적 (Tracking)** : 바람, 빌딩 동요(Sway), 지진 진동에 의해 광축이 틀어질 때 고속 조향 거울(FSM: Fast Steering Mirror)과 압전 액추에이터를 통해 실시간 보정.

## Ⅲ. FSO 통신의 세부 구성 요소 및 고주파 무선(RF)과의 비교 분석

| 비교 항목 | 자유공간 광통신 (FSO) | 고주파 밀리미터파 (60GHz / E-band RF) |
|---|---|---|
| **전송 매체** | 적외선 레이저 (850nm / 1550nm) | 밀리미터파 전파 (60GHz, 70~80GHz) |
| **전송 대역폭** | 수 Gbps ~ 수십 Gbps (극대 대역) | 1 ~ 10 Gbps |
| **주파수 라이선스**| 무면허 (전파법 규제 대상 제외) | 인허가 필요 또는 비인가(60GHz) |
| **전파 간섭(EMI)** | 전자기 간섭 완전 무관 (간섭 제로) | 타 전파 장비 및 레이다 간섭 가능 |
| **기상 취약 요인** | **짙은 안개, 연무 (극심한 감쇠)** | **폭우, 강우 (빗방울에 의한 감쇠)** |
| **도청 보안성** | 지향각 극소로 도청 절대 불가 | 사이드롭 누설 시 전파 도청 가능 |
| **설치 편의성** | 건물 옥상/창문 실내 설치 가능 | 안테나 크기 및 전파 음영 고려 |

- **안구 안전망 파장 (Eye-Safe 1550nm)** : 850nm 파장은 망막에 초점이 맺혀 실명 위험이 있으나, 1550nm 파장은 각막과 수정체에서 대부분 흡수되어 100배 높은 광출력 송출이 허용됨.

## Ⅳ. FSO 통신의 주요 한계점 및 해결 방안

- **짙은 안개(Fog) 발생 시 미에 산란(Mie Scattering)에 의한 링크 차단** :
  - **한계점** : 안개 입자의 직경(수 $\mu\text{m}$)이 레이저 파장($1.55\mu\text{m}$)과 유사하여 미에 산란 손실이 최대 $100\sim300\text{ dB/km}$까지 급증, 통신 전면 중단.
  - **해결 방안** : 안개에 강한 60GHz 밀리미터파 무선 링크를 병렬 배치하여, FSO 수신 전력 저하 시 밀리초 단위로 무손실 절체하는 `하이브리드 FSO/RF` 시스템 구축.
- **고층 건물 동요 및 열 팽창으로 인한 광축 어긋남 (Misalignment)** :
  - **한계점** : 태양열에 의한 옥상 철골 팽창이나 돌풍으로 빌딩이 수 센티미터 진동할 경우 빔 스팟이 수신 렌즈를 이탈하여 링크 단절.
  - **해결 방안** : 다중 광학 빔(Multi-Beam) 분산 송신 및 폐루프 액티브 PAT 서보 제어기 고도화.

## Ⅴ. FSO 통신 적용 및 발전을 위한 기술사적 제언

- **우주 인터넷(위성 간 통신) 레이저 백본망 표준화** : 지상과 달리 대기 감쇠가 전무한 LEO 저궤도 위성 간 통신(O-ISL)에 FSO를 필수 채택하여 테라비트급 우주 광통신 고속도로 완성.
- **도심 5G/6G 기지국 프론트홀/백홀의 대안 수립** : 유선 광케이블 인입 비용이 수억 원에 달하는 도심 핫스팟에 FSO/RF 하이브리드 무선 백홀을 배치하여 망 구축 공기 단축 및 CAPEX 70% 절감.
- **양자 키 분배(QKD)와의 광학 계층 통합** : 단일 광자(Single Photon) 수준의 극미약 신호를 다루는 자유공간 무선 양자 암호 통신망과 FSO 광학계를 일체화하여 국가 기밀급 도청 불가능 전송망 확보.
