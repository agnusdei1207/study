## 30초 인출

- 본질: **FSO(Free Space Optics) 통신** : 광섬유 케이블 포설 없이 대기나 우주 진공 등 자유공간(Free Space)을 전송 매질로 활용하여 적외선 레이저 빔으로 초고속 데이터를 전송하는 무선 광통신 기술
- 메커니즘: 송신부에서 전기 신호를 레이저 다이오드로 변조하여 콜리메이터 렌즈로 시준 후 방사하고, 수신부 포토다이오드(APD)로 복조하며 초정밀 PAT(Pointing, Acquisition, Tracking) 서보로 광축을 지속 정렬
- 통찰: 안개·연무에 의한 미에 산란(Mie Scattering) 및 대기 난류 신틸레이션으로 인한 급격한 수신 전력 감쇠 극복을 위해 60GHz 밀리미터파와 연계한 하이브리드 FSO/RF 자동 절체 체계 구축 필수

<details>
<summary>핵심 용어</summary>

- **PAT (Pointing, Acquisition and Tracking)** : 수 마이크로라디안(µrad) 단위의 좁은 레이저 빔을 목표 수신기에 정확히 지향(Pointing), 포착(Acquisition), 지속 추적(Tracking)하는 서보 제어 기술
- **LOS (Line of Sight)** : 송신 광학계와 수신 광학계 사이에 전파 방해물이 전혀 존재하지 않는 완전한 물리적 가시선 경로
- **미에 산란 (Mie Scattering)** : 레이저 광선 파장(0.8~1.55µm)과 크기가 유사한 안개, 연무 입자에 의해 전방위로 빛이 산란되어 100dB/km 이상의 극심한 감쇠를 유발하는 현상
- **신틸레이션 (Scintillation)** : 태양열에 의한 지표면 공기 팽창과 대기 난류로 굴절률이 급변하여 수신 레이저 빔이 일렁이고 광세기가 급격히 변동하는 현상
- **FSM (Fast Steering Mirror)** : 압전 소자(Piezoceramic)를 활용해 수 밀리초(ms) 단위로 레이저 빔의 각도를 미세 조정하는 고속 빔 조향 거울

</details>

## 2~4교시 25점 답안

## Ⅰ. FSO 통신의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 광케이블의 물리적 포설 없이 대기, 우주 등 자유공간을 전송 채널로 활용하여 레이저 다이오드(LD) 광선을 송수신함으로써 기가비트급 데이터를 무선 전송하는 광 무선 통신 기술 |
| 목적 | 강, 도로, 도심 밀집 지역 등 유선 광케이블 매설이 불가능하거나 막대한 비용이 소요되는 구간의 초고속 백홀 회선 확보 및 군사용 도청 방지 보안 링크 구축 |

## Ⅱ. FSO 통신의 특징 및 핵심 구성 요소

| 핵심 구성 요소 | 주요 기능 및 특징 | 상세 사양 및 기술 |
|---|---|---|
| **송신 광학계** | 전기 디지털 신호를 고출력 레이저 빔으로 변조 및 시준 방사 | 파장: 850nm / 1310nm / 1550nm (1550nm는 안구 안전망 눈 손상 방지 규격 준수) |
| **자유공간 채널** | 무면허 광대역 주파수 채널을 형성하여 수 Gbps~수십 Gbps 대역 전송 | 주파수 규제 및 라이선스 비용 전무, 전파 간섭(EMI) 원천 차단 |
| **수신 광학계** | 집광 렌즈로 미약한 광 신호를 모아 초고감도 광전 변환 수행 | APD (Avalanche Photo Diode) 또는 PIN-PD 채택, 광학 필터로 태양광 잡음 억제 |
| **PAT 서보 시스템** | 건물 흔들림이나 플랫폼 이동 시 송수신 빔 광축을 상호 정밀 추적 | 초당 수천 회 각도 보정, 고속 조향 거울(FSM) 및 사분원 검출기(QPD) 연계 |

## Ⅲ. FSO 종단 간 전송 아키텍처 및 PAT 제어 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ FSO 종단 간 송수신 및 PAT 제어 아키텍처 ]          │
│                                                                        │
│   [송신 노드 A]                                        [수신 노드 B]   │
│   ┌───────────────┐                                    ┌─────────────┐ │
│   │전기 데이터 입력│                                    │최종 수신 복조││
│   └───────┬───────┘                                    └──────▲──────┘ │
│           │ 변조                                              │ 광전 변환│
│   ┌───────▼───────┐                                    ┌──────┴──────┐ │
│   │ 레이저 송신기  │  자유공간 대기 채널 (LOS 경로)     │ 고감도 APD  │ │
│   │ (1550nm LD)   │  [안개 산란, 대기 난류 신틸레이션] │ 검출 수신기 │ │
│   └───────┬───────┘                                    └──────▲──────┘ │
│           │ 광학계                                            │ 집광 렌즈│
│   ┌───────▼───────┐  지향 빔 (몇 mrad 발산)    ┌──────────────┴──────┐ │
│   │ PAT 조향 거울 ├───────────────────────────►│ 빔 스플리터 / 센서  │ │
│   │ (FSM 초정밀)  │                            └──────────────┬──────┘ │
│   └───────▲───────┘                                           │ 각도 오차│
│           │           피드백 제어 신호                        │        │
│           └───────────────────────────────────────────────────┘        │
└────────────────────────────────────────────────────────────────────────┘
```

| PAT 동작 단계 | 주관 요소 | 세부 수행 메커니즘 |
|---|---|---|
| **1. 지향 (Pointing)** | 대구경 짐벌(Gimbal) | 기밀 지리 좌표(GPS)를 기반으로 상대 수신국의 대략적 위치로 송신 빔 방사 방향 조향 |
| **2. 포착 (Acquisition)** | 광시야각(FOV) CCD/CMOS | 나선형(Spiral) 탐색 패턴으로 비콘 광선을 방사하고 상대방의 응답 빔을 시야각 내 감지 |
| **3. 추적 (Tracking)** | 4분할 포토다이오드(QPD) | 광축 중심 이탈량(Spot Center Error)을 마이크로초 단위로 연산하여 FSM 거울을 피드백 구동 |

## Ⅳ. FSO(자유공간 광통신) vs RF 밀리미터파(mmWave) 비교

| 비교 항목 | FSO (자유공간 광통신) | 밀리미터파 RF (60GHz / E-band) |
|---|---|---|
| **전송 주파수** | 193 ~ 350 THz (적외선 파장 0.8~1.55µm) | 30 ~ 300 GHz (밀리미터파 대역) |
| **주파수 인허가** | 비인가(Unlicensed) 대역 (글로벌 규제 없음) | 각국 전파법 규제 및 면허 취득 필요 (일부 비면허 제외) |
| **전송 대역폭** | 수 Gbps ~ 100 Gbps (초고속 대용량) | 1 ~ 10 Gbps 수준 |
| **전파 간섭(EMI)** | 광선 특성상 주변 전자기파 간섭 전무 | 주변 동일 대역 기기 간 상호 간섭 발생 |
| **보안성** | 지향 빔 물리 차단 시 통신 두절, 도청 불가능 | 사이드로브(Side-lobe) 누설 전파 도청 가능성 존재 |
| **기상 취약점** | **안개·연무(Mie 산란)에 극도로 취약** (폭우엔 강함) | **폭우(물 분자 공진 흡수)에 극도로 취약** (안개엔 강함) |

## Ⅴ. FSO 통신의 한계와 방안

| 한계 | 방안 |
|---|---|
| 안개 입자(지름 1~20µm)가 근적외선 레이저 파장(0.85~1.55µm)과 일치하여 미에 산란이 극대화됨으로써 안개 발생 시 100~300dB/km에 달하는 대기 감쇠로 링크가 완전 두절 | 안개 감쇠에 영향을 받지 않는 60GHz 또는 70/80GHz E-band 밀리미터파를 병렬 백업 링크로 구성하여, 광 링크 신호 대 잡음비(SNR) 저하 시 수 밀리초 내 무중단 절체되는 하이브리드 FSO/RF 링크 아키텍처 구축 |
| 태양 복사열에 의한 지표면 난류로 대기 굴절률 구조 상수($C_n^2$)가 변화하여 빔의 파면이 일그러지고 수신 전력이 급변하는 신틸레이션(Scintillation) 발생 | 수신단에 다수의 광검출기 어레이를 공간적으로 이격 배치하는 공간 다이버시티(Aperture Averaging) 기법을 적용하고, 변형 거울(DM) 기반의 적응 광학(Adaptive Optics) 파면 보정 기술 도입 |
| 고층 빌딩 옥상에 FSO 장비 설치 시 태양열에 의한 건물 열팽창 및 풍하중 진동으로 송수신 광축이 틀어지는 보어사이트(Boresight) 정렬 오차 발생 | 초고속 압전 소자 구동 미러(FSM) 기반의 폐루프 능동 PAT 서보를 장착하여 진동 주파수(수십 Hz 대역)를 실시간 상쇄하고 빔 발산각을 최적화 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
도심 간 단거리(1km 이내) 백홀 구축 시 기상 통계청의 연간 안개 일수 및 강우 통계를 사전 분석하여 링크 가용률 99.999% 달성을 목표로 설계해야 하며, 인간의 눈 망막 손상을 방지하기 위해 반드시 눈 안전 규격(IEC 60825-1 Class 1M)을 만족하는 1550nm 파장 대역 레이저 모듈 채택 필수

### 3. 기술 유형 및 비교 평가
| 구분 | 단일 빔 FSO (Single-beam) | 다중 빔 FSO (Multi-beam) | 하이브리드 FSO/RF (Hybrid) |
|---|---|---|---|
| **빔 구성** | 단일 송신 레이저 빔 방사 | 3~4개의 독립 레이저 빔 중첩 | FSO 빔 + 밀리미터파 RF 결합 |
| **신틸레이션 내성** | 낮음 (대기 난류 시 페이딩 심각) | 우수 (공간 다이버시티 페이딩 상쇄) | 최우수 (전파-광학 상호 보완) |
| **안개 내성** | 매우 취약 (단절 발생) | 취약 (대기 산란 투과 한계) | 완전 극복 (RF 링크로 즉각 절체) |
| **링크 가용률** | 99% ~ 99.9% (기상 의존적) | 99.9% 수준 | 99.999% (캐리어 그레이드 달성) |
| **구축 비용** | 경제적, 장비 단순 | 중간 수준 | 이중 송수신기로 투자비 다소 증가 |
