## 연관 키워드

- IEEE 802.11bn, TGbn(Task Group bn), 개정 표준(Amendment), UHR(Ultra High Reliability)
- 다중 AP 협력 전송(Multi-AP Coordination), 조정 빔포밍(Co-BF), 조정 OFDMA(Co-OFDMA), 조인트 전송(J-Tx)
- 확장 다중 링크 동작(E-MLO), 무손실 로밍, 전력 절감(Power Save), 결정론적 지연
- PAR(Project Authorization Request), Wi-Fi Alliance, 상호운용성 인증

## Ⅰ. IEEE 802.11bn의 개요

- 핵심 요약 : 속도 경쟁에서 신뢰성과 지연 안정성으로 목표를 옮긴 IEEE 802.11 계열의 차세대 개정 표준.
- 개념 : IEEE(Institute of Electrical and Electronics Engineers) 802.11 워킹그룹 산하 **TGbn**(Task Group bn)이 표준화를 진행 중인 **초고신뢰 무선랜** (UHR, Ultra High Reliability) 개정 표준(Amendment), 산업계 통칭은 Wi-Fi 8.
- 배경 및 필요성 : 공장 자동화·원격 의료·몰입형 XR(Extended Reality)처럼 지연 변동과 순간 끊김에 민감한 서비스가 늘어나 평균 속도만으로 품질을 담보하기 어려운 환경, 신규 목표를 담은 후속 규격의 제정 필요.
- 주요 목적 :
  1. 여러 AP(Access Point) 사이 협력 전송 기술의 규격화
  2. 결정론적 지연(예측 가능한 전송 지연)과 지연 지터 감소
  3. 단말 전력 소모 개선과 이동성·상호운용성 확보

## Ⅱ. IEEE 802.11bn의 특징 및 장점

- 핵심 요약 : 개별 AP의 경쟁 동작을 AP 간 협력으로 바꾸는 기술 항목들이 규격에 담기면서 신뢰성과 전력 효율이 함께 향상되는 구조.

1. **다중 AP 협력 전송** (Multi-AP Coordination) : 인접 AP가 채널 상태와 자원 정보를 공유 → AP 간 간섭 억제와 셀 경계 품질의 균일화.
2. **조정 빔포밍** (Co-BF, Coordinated Beamforming) : 이웃 AP가 타 단말 방향으로 널(Null)을 형성 → 간섭의 원천을 송신단에서 차단.
3. **조정 OFDMA** (Co-OFDMA, Coordinated Orthogonal Frequency Division Multiple Access) : 인접 AP가 자원 단위(RU, Resource Unit)를 충돌 없이 분할 사용 → 밀집 환경 대기 지연 감소.
4. **조인트 전송** (J-Tx, Joint Transmission) : 분산된 여러 AP가 같은 데이터를 동시 송신 → 공간 다이버시티로 음영 구간 보완.
5. **확장 다중 링크 동작** (E-MLO, Enhanced Multi-Link Operation) : 다른 AP에 걸친 링크까지 묶어 전환 → 이동 중 링크 단절 시간 감소.
6. **무손실 로밍** : 단말 이동 시 인접 AP로 세션을 인수 → 이동 중 패킷 손실과 끊김 감소.
7. 전력 절감(Power Save) 강화 : 접속 유지·탐색 동작의 협력 최적화 → 배터리 수명 개선.

## Ⅲ. IEEE 802.11bn의 구조 (흐름)

- 핵심 요약 : 논의 그룹에서 목표를 정의하고 태스크그룹이 초안·투표를 거쳐 개정 표준으로 완성하는 표준화 절차.
- **TIG**(Topic Interest Group) : 본격 표준화에 앞서 신규 주제의 목표 기술을 검토하는 논의 그룹.
- **PAR**(Project Authorization Request) : 규격의 목표와 범위를 정의하는 프로젝트 승인 문서.

```text
[ 802.11bn 표준화 절차 ]

UHR 논의 그룹(TIG) 구성
   ↓
PAR 승인 · TGbn 발족
   ↓
초안(Draft) 작성·공개
   ↓
초안 투표와 의견 수렴 반복
   ↓
최종 표준 승인
   ↓
Wi-Fi Alliance 인증 연계
```

```text
[ 다중 AP 협력 동작 흐름 ]

인접 AP 간 채널 상태 공유
   ↓
Co-BF 널 형성 · Co-OFDMA 자원 분할
   ↓
J-Tx 동시 송신
   ↓
단말 측 간섭 억제·음영 보완
```

- 개정 표준 방식 : 기본 규격(802.11-2024)에 새 기능을 덧붙이는 형태로 제정되며, 인증과 상호운용성 시험은 Wi-Fi Alliance가 담당.

## Ⅳ. 802.11bn과 선행 규격의 비교

- 핵심 요약 : 규격 명칭과 목표 항목 기준에서 고대역폭·고변조 중심의 선행 규격과 달리 802.11bn은 신뢰성 항목을 규격 목표로 명시하는 차이.

| 비교 항목 | 802.11ax (Wi-Fi 6) | 802.11be (Wi-Fi 7) | 802.11bn (Wi-Fi 8) |
| --- | --- | --- | --- |
| 규격 명칭 | 고효율 (HE, High Efficiency) | 극고처리율 (EHT, Extremely High Throughput) | 초고신뢰 (UHR, Ultra High Reliability) |
| 규격 목표 | 밀집 환경 접속 효율 | 최대 처리량과 저지연 | 전송 신뢰성과 지연 안정성 |
| AP 간 협력 | 미표준화 | 미표준화 | 다중 AP 협력 전송 규격화 |
| 다중 링크 | 미지원 | 다중 링크 동작 (MLO, Multi-Link Operation) | 확장 다중 링크 (E-MLO) |
| 표준화 초점 | 단일 AP 효율 | 단일 AP 성능 | 다 AP 협력·전력·이동성 |

- 선택 기준 : 도입 시점 판단은 Wi-Fi Alliance 인증 프로그램 개시 여부를 기준으로 삼고, 표준 확정 전 장비는 초안 기반 상호운용성 리스크를 감안.

## Ⅴ. IEEE 802.11bn의 한계와 방안

- 핵심 요약 : 표준 확정 전 불확실성, AP 간 동기화 부담, 비인가 대역 간섭을 절차·기술·규제 대응으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 초안 변동 리스크 | 표준화 진행 중 항목 채택·삭제 반복 → 조기 도입 장비의 규격 불일치 | 표준 확정·인증 개시 시점에 맞춘 도입 계획 수립 | 규격 불일치 장비 비율 |
| AP 간 동기화 부담 | 협력 전송에 정밀 시간 동기화·백홀 교환 필요 → 백홀 지연 시 협력 이득 감소 | 유선 백홀 용량 설계와 시간 동기화 프로토콜(IEEE 802.1AS) 적용 | 동기화 오차, 백홀 사용률 |
| 6GHz 대역 간섭 | 비인가 대역 기기 증가로 혼신과 규제 준수 부담 | AFC(Automated Frequency Coordination) 기반 출력·주파수 관리 | 간섭 발생 건수 |

## Ⅵ. IEEE 802.11bn에 대한 기술사적 제언

- 핵심 요약 : 기업 IT 조직과 제조·의료 현장이 표준 진행 상황 추적과 시험 검증을 병행하며 신뢰성 기반 무선망을 준비하는 방향.

1. 기업 IT 조직 : 무선랜을 유선의 대체 인프라로 격상시키는 관점에서 세대 전환 예산과 검증 환경을 선제 확보.
2. 제조·의료 현장 : 결정론적 무선 통신 시험베드를 구성해 유선 배선이 어려운 제어 구간의 적용 가능성 검증.
3. 국내 표준화 대응 조직 : 국내 산업 환경의 신뢰성 요구를 국제 표준 회의에 제출하는 상시 의견 개발 체계 운영.

## Ⅶ. 결론

- 핵심 요약 : IEEE 802.11bn은 속도 대신 신뢰성과 지연 안정성을 규격 목표로 명시하는 무선랜 표준의 방향 전환.
- 표준 절차의 진행과 인증 개시 시점 추적이 현장 도입 성패의 전제 조건.
