## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 무선 LAN → IEEE 802.11bn(UHR)

## 30초 인출

- 본질: **IEEE 802.11bn** 은 WLAN의 실제 사용 환경에서 신뢰성을 높이기 위한 IEEE 802.11 개정 프로젝트
- 메커니즘: 단일 AP의 최대 전송률보다 여러 AP·단말의 공존과 전송 안정성 개선을 목표로 하는 MAC·PHY 기능을 표준화
- 통찰: 단순 최고 전송 속도 경쟁을 넘어 99.99% 이상의 고신뢰성과 최악 지연(Worst-case Latency)을 1ms 수준으로 통제하기 위해 다중 AP 간 상호 협력 통신(Co-BF, Co-OFDMA)을 표준화하는 차세대 Wi-Fi 8 기술 규격임.

<details>
<summary>핵심 용어</summary>

- **IEEE 802.11bn** : WLAN의 UHR 기능을 다루는 IEEE 802.11 개정 프로젝트. 통상 Wi-Fi 8로 불리는 개발 표준.
- **UHR (Ultra High Reliability)** : 802.11bn 프로젝트의 초고신뢰 WLAN 목표 범주.
- **AP (Access Point)** : 무선 단말을 유선 LAN·분배 시스템에 연결하는 무선 접속점.
- **STA (Station)** : IEEE 802.11 네트워크에서 통신하는 무선 단말.
- **Multi-AP Coordination** : 여러 AP의 자원·전송 동작을 조정해 WLAN 성능을 개선하려는 기능군.

</details>

## 2~4교시 25점 답안

## Ⅰ. IEEE 802.11bn의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 기존 Wi-Fi 7의 처리량 중심 진화에서 벗어나 통신 신뢰도 99.99%와 결정론적(Deterministic) 극저지연 보장을 목표로 표준화가 진행 중인 IEEE 무선랜 표준(UHR, Ultra High Reliability) |
| 목적 | 산업용 로봇 제어, 실시간 원격 수술, 차량 무선 진단 등 미션 크리티컬 환경에서 무선랜의 패킷 손실 및 지연 급증(Jitter) 원천 방지 |

## Ⅱ. IEEE 802.11bn의 특징

| 특징 | 상세 내용 |
|---|---|
| 초고신뢰성 (UHR) | 최고 전송률보다 패킷의 99.99% 이상이 정해진 마감시간 내에 도달하는 결정론적 신뢰성 우선 |
| 다중 AP 협력 (MAPC) | 인접한 복수의 독립 AP들이 유선 백홀로 연계되어 빔포밍 및 무선 자원을 공동 스케줄링 |
| 통합 전력 제어 | 셀 경계에 위치한 단말들의 상향링크 간섭을 완화하기 위해 AP 간 협력 송신 전력 최적화 |
| 논-STR 향상 | 하드웨어 단가가 낮은 단말에서도 MLO(다중 링크)의 링크 전환 지연을 마이크로초 단위로 단축 |

## Ⅲ. IEEE 802.11bn의 체계·프로세스

**IEEE 802.11bn 다중 AP 협력(MAPC) 기술 아키텍처**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ IEEE 802.11bn 다중 AP 협력 구조 ]            │
│                                                                        │
│   [ 컨트롤러 / 고속 이더넷 백홀 ]                                      │
│          ├─── 고속 유선 동기화 ──────────────────┐                    │
│          ▼                                        ▼                    │
│   ┌──────────────┐                        ┌──────────────┐             │
│   │ [ AP 1 ]     │                        │ [ AP 2 ]     │             │
│   └──────┬───────┘                        └──────┬───────┘             │
│          │                                       │                     │
│          │ Co-BF (협력 빔포밍)                  │ Co-BF 빔 동시 집중  │
│          ▼                                       ▼                     │
│       ═══════════════════════════════════════════════                  │
│               [ 셀 경계 단말 (Boundary STA) ]                         │
│               - 인접 간섭 신호가 증폭된 수신 신호로 합성               │
│               - 99.999% 무선 수신 성공률 달성                          │
└────────────────────────────────────────────────────────────────────────┘
```

| MAPC 세부 기술 | 동작 메커니즘 | 기술적 기대 성과 |
|---|---|---|
| **Co-BF (협력 빔포밍)** | 복수 AP가 채널 상태(CSI)를 공유하여 타 AP 단말 방향으로는 널(Null)을 형성하고 자사 단말에는 빔 집중 | 인접 BSS 간 셀 간섭 완벽 상쇄 |
| **Co-OFDMA (협력 OFDMA)** | 동일 시간 슬롯에서 복수 AP가 중첩되지 않게 RU(Resource Unit)를 나누어 동시 통신 | 주파수 재사용률 극대화 및 충돌 방지 |
| **Co-SR (협력 공간재사용)**| AP 간 송신 파워를 상호 조절하여 간섭 반경을 제어하며 동시 전송 허용 | 고밀도 오피스 환경 처리율 3배 개선 |
| **Dynamic Sub-band** | 160MHz/320MHz 채널 중 간섭이 감지된 협대역을 1ms 내에 실시간 감지하여 우회 | 간섭 회피 시간 수 초에서 1ms로 단축 |

## Ⅳ. IEEE 802.11bn의 종류·비교

| 비교 항목 | Wi-Fi 6 (802.11ax) | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
|---|---|---|---|
| **표준 명칭** | High Efficiency (HE) | Extremely High Throughput (EHT) | **Ultra High Reliability (UHR)** |
| **설계 최우선 순위** | 스펙트럼 효율성 향상 | **최대 전송 속도 (Peak 46Gbps)**| **초고신뢰성 및 지연 결정론성** |
| **AP 간 관계** | 독립적 경쟁 (CSMA/CA) | 독립적 동작 (간섭 회피 위주) | **다중 AP 완전 협력 (Co-BF/Co-OFDMA)**|
| **신뢰도 지표** | Best Effort | 통계적 QoS | **99.99% @ 1ms 지연 보장** |
| **주요 킬러 앱** | 공공장소 다자간 접속 | 8K 스트리밍, VR 게임 | **산업용 로봇 제어, 원격 수술, 자율주행**|

## Ⅴ. IEEE 802.11bn의 한계와 방안

| 한계 | 방안 |
|---|---|
| 복수 AP 간 실시간 협력 빔포밍(Co-BF)을 위해 AP 간 유선 백홀(10Gbps 이상)로 교환해야 하는 CSI 오버헤드 폭증 | CSI 양자화 압축 알고리즘 적용 및 백홀 지연시간 100μs 이내의 IEEE 802.1AS TSN 스위치망 의무화 |
| 레거시 단말(Wi-Fi 5/6)이 공유 채널에 혼재 시 긴 랜덤 백오프로 인해 802.11bn의 1ms 결정론적 슬롯 파괴 | 신규 UHR 전용 채널 슬라이싱(Dedicated Channel) 할당 및 타임 슬롯 기반 무경쟁 구간(CFP) 강제 격리 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
스마트 팩토리 내 AGV 관제 시스템 구축 시, Wi-Fi 8(802.11bn)의 MAPC 기능을 활성화하기 위해 AP 간 유선 인프라를 지연 편차가 없는 TSN(Time-Sensitive Networking) 스위치 패브릭으로 선행 업그레이드하고, 공장 내 이동 단말에는 Co-OFDMA 전용 프로파일을 우선 적용.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ Wi-Fi 8 Co-OFDMA 주파수 자원 분할 메커니즘 ]                        │
│                                                                        │
│   단일 160MHz 무선 채널 공간                                          │
│   ┌───────────────────────────────┬───────────────────────────────┐   │
│   │ [ RU Block A : AP 1 사용 ]   │ [ RU Block B : AP 2 사용 ]   │   │
│   │ (AP 1이 단말 STA-1에 할당)    │ (AP 2가 단말 STA-2에 할당)    │   │
│   └───────────────────────────────┴───────────────────────────────┘   │
│   * 두 AP가 상호 동기화되어 동일 채널을 충돌 없이 동시 전송 (처리율 2배) │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 신뢰성 평가 요소 | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
|---|---|---|
| **Worst-case Latency** | 확률적 제어로 최대 수백 ms 튈 수 있음 | **1ms 이내로 엄격 상한 제한** |
| **패킷 유실률** | 10^-2 ~ 10^-3 수준 | **10^-5 (99.999% 무손실 수준)** |
| **셀 경계 처리율** | 인접 간섭으로 처리율 80% 급감 | **협력 빔포밍으로 경계 처리율 2.5배 개선**|
