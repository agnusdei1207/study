## 연관 키워드

- IEEE 802.11bn, Wi-Fi 8, 초고신뢰(UHR, Ultra High Reliability)
- 다중 AP 협력 전송(Multi-AP Coordination), 조정 빔포밍(Co-BF), 조정 OFDMA(Co-OFDMA), 조인트 전송(J-Tx)
- 결정론적 지연, 지연 지터, 다중 링크 동작(MLO), 무선랜 센싱(IEEE 802.11bf)
- 시간 민감 네트워킹(TSN), EasyMesh, 6GHz 대역 AFC

## Ⅰ. IEEE 802.11bn의 개요

- 핵심 요약 : 최고 속도 경쟁 대신 전송 신뢰성과 지연 안정성을 목표로 하는 차세대 무선랜 표준.
- 개념 : Wi-Fi 7(IEEE 802.11be, EHT)에 이어 표준화가 진행 중인 **초고신뢰 무선랜** (IEEE 802.11bn, UHR, Ultra High Reliability), 산업계에서는 Wi-Fi 8로 불림.
- 배경 및 필요성 : 무선랜 트래픽이 늘고 같은 대역을 쓰는 기기 간 간섭이 심해지면서, 실시간 공장 자동화, 원격 수술, 몰입형 XR 같은 서비스에 요구되는 안정적 전송과 결정론적 지연(예측 가능한 지연)을 확보하기 어려워짐.
- 주요 목적 :
  1. 여러 AP(Access Point) 사이의 협력 전송 구현
  2. 지연 지터(Jitter) 감소와 패킷 손실 개선
  3. 무선 단말의 전력 소모 절감

## Ⅱ. IEEE 802.11bn의 특징 및 장점

- 핵심 요약 : 인접 AP가 간섭을 상쇄하거나 신호를 합쳐 보내는 협력 구조가 신뢰성과 지연 안정성을 함께 높이는 방식.

1. **다중 AP 협력 전송** (Multi-AP Coordination) : 인접 AP가 단말 채널 정보를 공유 → 간섭 신호를 상쇄하고 전파 혼잡을 줄임.
2. **조정 빔포밍** (Co-BF, Coordinated Beamforming) : 이웃 AP가 다른 단말 방향으로 널(Null)을 형성 → 단말 간 간섭의 원천 억제.
3. **조정 OFDMA** (Co-OFDMA, Coordinated Orthogonal Frequency Division Multiple Access) : 자원 블록(RU, Resource Unit)을 인접 AP가 충돌 없이 나눠 씀 → 밀집 환경의 대기 시간 감소.
4. **조인트 전송** (J-Tx, Joint Transmission) : 분산된 여러 AP가 한 단말에 같은 데이터를 동시에 송신 → 공간 다이버시티 이득과 음영 지역 보완.
5. **무손실 로밍** (Seamless Roaming) : 단말 이동 시 인접 AP로 세션을 넘겨 패킷 손실을 줄임 → 이동 중에도 끊김 없는 연결.
6. **무선랜 센싱** (IEEE 802.11bf, WLAN Sensing) : 무선 신호의 반사 변화로 재실이나 동작을 감지하는 별도 표준 → 통신용 무선랜 인프라를 감지에 활용할 가능성 확보.

## Ⅲ. IEEE 802.11bn의 구조 (흐름)

- 핵심 요약 : 인접 AP가 채널 정보를 공유한 뒤, 빔과 자원을 나누어 쓰거나 함께 송신하는 순서로 동작하는 구조.

```text
[ 다중 AP 협력 전송 흐름 ]

인접 AP 간 채널 정보 공유
          ↓
Co-BF : 타 단말 방향 널(Null) 형성
Co-OFDMA : 자원 블록 분할 배분
          ↓
J-Tx : 여러 AP가 한 단말에 동시 송신
```

```text
[ 무손실 로밍 흐름 ]

단말이 AP 1에서 AP 2 방향으로 이동
          ↓
AP 1과 AP 2 사이 세션 정보 전달
          ↓
연결이 AP 2로 끊김 없이 이전
```

## Ⅳ. 세대별 무선랜 비교

- 핵심 요약 : Wi-Fi 6과 Wi-Fi 7이 대역폭과 변조 방식으로 속도를 높였다면, Wi-Fi 8은 AP 간 협력으로 신뢰성을 높이는 방향으로 전환.

| 비교 항목 | Wi-Fi 6 (802.11ax) | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
| --- | --- | --- | --- |
| 표준 명칭 | 고효율 (HE, High Efficiency) | 극고처리율 (EHT, Extremely High Throughput) | 초고신뢰 (UHR, Ultra High Reliability) |
| 핵심 지향점 | 고밀도 환경의 접속 효율 | 초고속 전송 | 전송 신뢰성과 지연 안정성 |
| 최대 대역폭 | 160MHz | 320MHz | 대역폭 확장보다 신뢰성 기법 중심 |
| 변조 방식 | 1024-QAM (Quadrature Amplitude Modulation) | 4096-QAM | 4096-QAM 유지, 복합 변조 최적화 |
| 다중 링크 | 미지원 | MLO (Multi-Link Operation) | 개선형 다중 링크 협력 (Enhanced MLO) |
| AP 간 협력 | 독립 동작 | 독립 경쟁 방식 | 다중 AP 협력 전송 |
| 주요 적용처 | 스마트홈, 공공 Wi-Fi | 고화질 스트리밍, 대용량 전송 | 스마트 팩토리, 원격의료, XR |

- 선택 기준 : 가정과 일반 사무 환경은 Wi-Fi 6 또는 7로 충분하고, 지연과 신뢰성이 중요한 현장은 협력 기능을 가진 Wi-Fi 8 계열 도입을 검토.

## Ⅴ. IEEE 802.11bn의 한계와 방안

- 핵심 요약 : AP 간 동기화 지연과 이종 벤더 호환성, 6GHz 간섭이 핵심 한계이며, 시간 동기화 표준과 공개 인터페이스, 간섭 관리 절차로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| AP 간 동기화 지연 | 협력 전송에 정밀한 시간 동기화와 채널 정보 교환이 필요해 백홀 지연이 생기면 성능 급락 | TSN(Time-Sensitive Networking, IEEE 802.1AS) 기반 정밀 시간 동기화와 백홀 품질 관리 | 동기화 오차, 백홀 지연 |
| 이종 벤더 협력 불가 | 제조사별 독자 빔포밍과 제어 프로토콜 때문에 혼재 환경에서 협력 전송이 되지 않음 | EasyMesh 기반의 공개 다중 AP 인터페이스 준수 | 협력 전송 성공률 |
| 6GHz 대역 간섭 | 비인가 대역에 기기가 늘어 혼신이 발생하고 주변 시스템과 충돌 | AFC(Automated Frequency Coordination) 기반 표준 출력 운용과 규제 샌드박스 연계 | 간섭 발생 건수 |

## Ⅵ. IEEE 802.11bn에 대한 기술사적 제언

- 핵심 요약 : 무선랜을 유선 대체 수단으로 키우고, 캠퍼스 내부와 외곽 이동망을 이어 주는 하이브리드 구조로 발전시키는 방향.

1. 산업 현장의 무선 제어 도입 : 유선 이더넷 배선이 어려운 공정 제어 구간에 결정론적 무선 통신을 시험 도입하여 유연 생산 체계를 검토할 필요가 있음.
2. 무선랜과 셀룰러의 역할 분담 : 캠퍼스 내부는 무선랜으로, 외곽 이동 구간은 5G 또는 6G 프라이빗망으로 연계하는 하이브리드 제어 구조를 설계해야 함.

## Ⅶ. 결론

- 핵심 요약 : IEEE 802.11bn은 속도보다 신뢰성과 지연 안정성을 무선랜의 기준으로 끌어올리는 표준.
- 시사점 : 협력 전송의 효과는 AP 간 동기화와 벤더 호환성에 달려 있어, 표준 준수와 시간 동기화 기반이 현장 도입의 전제가 됨.
