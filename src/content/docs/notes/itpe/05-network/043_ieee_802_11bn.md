- 메커니즘: 단일 AP의 최대 전송률보다 여러 AP·단말의 공존과 전송 안정성 개선을 목표로 하는 MAC·PHY 기능을 표준화

<details>
<summary>핵심 용어</summary>

- **IEEE 802.11bn** : WLAN의 UHR 기능을 다루는 IEEE 802.11 개정 프로젝트. 통상 Wi-Fi 8로 불리는 개발 표준.
- **UHR (Ultra High Reliability)** : 802.11bn 프로젝트의 초고신뢰 WLAN 목표 범주.
- **AP (Access Point)** : 무선 단말을 유선 LAN·분배 시스템에 연결하는 무선 접속점.
- **STA (Station)** : IEEE 802.11 네트워크에서 통신하는 무선 단말.
- **Multi-AP Coordination** : 여러 AP의 자원·전송 동작을 조정해 WLAN 성능을 개선하려는 기능군.

</details>

## Ⅱ. 표준화 목적과 구조

```text
WLAN의 실제 사용 환경 요구
        ↓ 프로젝트 목표 반영
802.11bn UHR 개정 작업
        ↓ 초안·투표·의견 해결
IEEE 규격 승인 절차
```

IEEE 802.11 작업반 공지 기준으로 2026년 9월 P802.11bn D2.0 작업반 초기 투표를 통과하고 의견 해결 단계. 최종 표준 발행 전 상태.

## Ⅲ. 세대별 초점

| 비교축 | Wi-Fi 7 (IEEE 802.11be) | IEEE 802.11bn (Wi-Fi 8로 통칭) |
|---|---|---|
| 프로젝트 초점 | EHT(Extremely High Throughput) | UHR(초고신뢰 WLAN) |
| 성능 관점 | 높은 PHY 전송률·다중 링크 등 | 실제 환경의 신뢰성·일관성 개선 |
| 상태 | IEEE Std 802.11be-2024 | 2026년 9월 D2.0 초안 의견 해결 중 |

## Ⅳ. 적용 고려사항

```text
AP·컨트롤러 기능 확인
        ↓ 단말 조합 검증
STA 호환성 시험
        ↓ 혼잡·간섭 조건 재현
실환경 성능 측정
        ↓ 규격·제품 지원 확인
도입 범위 결정
```

| 한계 | 검토 항목 |
|---|---|
| 초안의 기술 항목과 상용 제품 기능이 다를 수 있음 | 인증·제품 사양·펌웨어 지원 확인 |
| AP 협력 기능은 유선 백홀·관리 플랫폼에 의존 가능 | 네트워크 구성과 다중 사업자 장비 상호운용 시험 |
| 무선 환경이 위치·부하에 따라 변동 | 셀 경계·혼잡 구역에서 지연·재전송·처리량 측정 |

## Ⅴ. 기술사적 제언 — 실환경 검증을 통한 도입 판단

| 한계 | 해결 방안 |
|---|---|
| UHR 목표 문구만으로 실제 서비스 품질을 보장할 수 없음 | 기존 WLAN과 동일한 혼잡·이동 조건에서 지표를 비교하고, 지원이 확인된 AP·단말 구간부터 적용 |
