## Ⅰ. IEEE 802.11bn의 개요

- 개념 : Wi-Fi 7(802.11be EHT)의 뒤를 이어 단순 최고 전송 속도 경쟁을 넘어 극한의 신뢰성과 결정론적 지연 시간을 보장하기 위해 표준화가 진행 중인 **차세대 무선랜** 표준 규격 (Wi-Fi 8, UHR: Ultra High Reliability).
- 배경 및 필요성 : 무선랜 트래픽의 폭증과 공존 간섭 심화로 인해 실시간 공장 자동화, 원격 수술, 몰입형 메타버스 등에서 높은 수준의 전송 신뢰도와 안정적 지연 시간 확보가 절실.
- 핵심 목적 : **복수 AP(Access Point) 간 협력 전송(Multi-AP Coordination)** 구현, **지연 지터(Jitter)** 최소화, 패킷 손실률 개선 및 무선 단말 배터리 수명 획기적 연장.

## Ⅱ. IEEE 802.11bn의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│              [ IEEE 802.11bn 핵심 혁신: 다중 AP 협력 전송 ]            │
│                                                                        │
│                ┌───────────────────────────────────┐                   │
│                │  Centralized AP Controller / CPO  │                   │
│                └─────────────────┬─────────────────┘                   │
│                                  │                                     │
│        ┌─────────────────────────┴─────────────────────────┐           │
│        ▼                                                   ▼           │
│   ┌───────────┐      Coordinated Beamforming (Co-BF)   ┌───────────┐   │
│   │   AP 1    │ ◄────────────────────────────────────► │   AP 2    │   │
│   └─────┬─────┘      Coordinated OFDMA (Co-OFDMA)      └─────┬─────┘   │
│         │            Joint Transmission (J-Tx)               │         │
│         │                                                    │         │
│         │ 간섭 신호 상쇄                                     │ 보강 신호│
│         ▼                                                    ▼ 전송    │
│   ┌───────────┐                                        ┌───────────┐   │
│   │   STA 1   │                                        │   STA 2   │   │
│   │  (단말)   │                                        │  (단말)   │   │
│   └───────────┘                                        └───────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

- **다중 AP 조정 빔포밍 (Co-BF)** : 인접 AP들이 단말 채널 정보를 상호 공유하여, 이웃 AP가 타 단말 방향으로 널(Null)을 형성해 간섭을 원천 억제.
- **다중 AP 조정 OFDMA (Co-OFDMA)** : 주파수 자원(RU: Resource Unit)을 인접 AP들이 시간·주파수 영역에서 충돌 없이 분할 배분하여 전파 혼잡 완화.
- **조인트 전송 (Joint Transmission)** : 복수의 분산 AP가 단일 단말로 동일 데이터를 동시 송신하여 공간 다이버시티 이득 극대화 및 음영 지역 극복.

## Ⅲ. IEEE 802.11bn의 세부 구성 요소 및 세대별 무선랜 비교 분석

| 비교 항목 | Wi-Fi 6/6E (802.11ax) | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
|---|---|---|---|
| 표준 명칭 | High Efficiency (HE) | Extremely High Throughput (EHT) | Ultra High Reliability (UHR) |
| 핵심 지향점 | 고밀도 환경 접속 효율 | 최대 46Gbps 초고속 전송 | 무선 전송 신뢰성 및 무지연 확정성 |
| 최대 대역폭 | 160 MHz | 320 MHz | 320 MHz 유지 (신뢰성 중심) |
| 변조 방식 | 1024-QAM(Quadrature Amplitude Modulation) | 4096-QAM | 4096-QAM 유지 및 복합 변조 최적화 |
| 다중 링크 (MLO) | 미지원 | MLO 지원 (개별 AP 단말 링크) | E-MLO (진화형 다중 링크 협력 스케줄링) |
| AP 간 협력 | 독립적 동작 (간섭 발생) | 조정 불가 (독립 경쟁 방식) | Multi-AP Coordination (Co-BF, J-Tx) |
| 주요 적용처 | 스마트홈, 공공 Wi-Fi | 8K 스트리밍, 대용량 다운로드 | 스마트팩토리 로봇, 원격의료, XR(Extended Reality) |

- **Integrated Sensing and Communication (ISAC)** : 무선랜 전파를 레이더로 활용하여 실내 재실 감지, 동작 인식, 낙상 사고 감지 동시 지원.
- **Enhanced Power Saving** : 단말의 수신 대기 시간을 동적으로 극소화하는 비지상/비주기적 초저전력 동작 모드 지원.
- **Seamless Roaming** : 단말이 이동할 때 패킷 손실(Packet Drop) 없이 수 밀리초 내에 인접 AP로 세션을 전달하는 무손실 핸드오버 체계.

## Ⅳ. IEEE 802.11bn의 주요 한계점 및 해결 방안

- AP 간 유선 백홀(Backhaul) 동기화 지연 및 오버헤드 :
  - 한계점 : Co-BF 및 Joint Tx 수행을 위해 다수 AP 간 나노초(ns) 단위 정밀 시각 동기화와 기가비트급 채널 정보 교환 필수, 유선 스위치망 지연 시 성능 급락.
  - 해결 방안 : TSN(Time-Sensitive Networking, IEEE 802.1AS) 기반 고정밀 시간 동기화 및 백홀 전용 초저지연 광 인터페이스 연동.
- 이종 제조사 AP 간 Multi-AP 협력 호환성 부재 :
  - 한계점 : 제조사별 독자 빔포밍 알고리즘 및 제어 프로토콜 사용 시 이종 벤더 AP 혼재 환경에서 협력 전송 불가.
  - 해결 방안 : Wi-Fi Alliance 차원의 EasyMesh 표준 고도화 및 오픈 무선랜 인터페이스 표준 규격 준수 의무화.

## Ⅴ. IEEE 802.11bn 적용 및 발전을 위한 기술사적 제언

- 산업용 무선 이더넷(Industrial Wireless)의 주력화 : 유선 이더넷 케이블을 대체하기 어려웠던 극한 공정 제어 분야에 802.11bn의 결정론적 무선 통신을 도입하여 유연 생산 체계 실현.
- Wi-Fi 8과 5G/6G 프라이빗망의 이종 융합 : 캠퍼스망 내부에서는 저비용 고성능 802.11bn을, 외곽 모빌리티 구간은 셀룰러를 연계하는 하이브리드 제어 평면 구축.
- 비인가 대역(6GHz) 청정 전파 환경 보호 정책 : 6GHz Wi-Fi 대역에서의 혼신 방지를 위한 AFC(Automated Frequency Coordination) 고도화 및 국내 전파 규제 샌드박스 연계 필수.
