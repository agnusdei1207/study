## 연관 키워드

- 샤논의 정리(Shannon's Theorem), 채널 용량(Channel Capacity), 대역폭(Bandwidth)
- 신호 대 잡음비(SNR, Signal-to-Noise Ratio), AWGN(Additive White Gaussian Noise)
- 샤논 한계(Shannon Limit), 나이키스트 공식(Nyquist Formula), 채널 부호화
- 터보 코드, LDPC(Low-Density Parity-Check), 폴라 코드, OFDM(Orthogonal Frequency Division Multiplexing)

## Ⅰ. 샤논의 정리의 개요

- 핵심 요약 : 잡음이 있는 대역제한 채널에서 오류 없이 보낼 수 있는 최대 전송률의 상한을 수식으로 규정한 정보이론의 기본 정리.
- 개념 : 백색 가우시안 잡음(AWGN, Additive White Gaussian Noise)이 있는 채널에서 달성 가능한 최대 전송률, 즉 **채널 용량**(Channel Capacity)을 대역폭과 신호 대 잡음비(SNR, Signal-to-Noise Ratio)의 함수로 제시한 **샤논의 정리**(Shannon's Theorem).
- 배경 및 필요성 : 대역폭과 전력, 잡음에는 물리적 한계가 존재함에도 전송 속도의 이론 상한이 규명되지 않아 통신 설계가 경험과 시행착오에 의존하는 문제가 있었음.
- 주요 목적 : 용량 상한의 수식화로 달성 가능 속도의 판정 기준 제공, 신뢰성 있는 통신이 가능한 조건의 증명, 변복조와 부호화 설계의 이론적 지침 확립.

## Ⅱ. 샤논 채널 용량의 특징 및 장점

- 핵심 요약 : 대역폭과 신호 대 잡음비라는 두 요인이 용량을 결정하며, 대역폭은 정비례로 신호 대 잡음비는 로그로 작용하는 관계.

1. 대역폭 선형 효과 : 용량이 대역폭에 정비례 → 용량 확보의 가장 직접적인 수단이지만 주파수 자원은 유한하다는 제약 존재.
2. 신호 대 잡음비 로그 효과 : 용량이 log2(1 + S/N)에 따라 증가 → 송신 전력 증대의 효과가 점차 둔화되어 전력 투입만으로 용량의 선형 확대가 불가.
3. 무한 대역폭 극한 : 대역폭을 무한히 넓혀도 용량은 신호 전력 대 잡음 전력 밀도비의 약 1.44배로 수렴 → 대역 확장만으로 무한 용량 확보가 불가.
4. **샤논 한계**(Shannon Limit) : 비트 에너지 대 잡음 전력 밀도비(Eb/N0)가 약 -1.59dB 이하이면 임의로 낮은 오류율 달성이 불가능한 이론적 하한 → 전력 효율 설계의 절대 기준.
5. 부호 존재 명제 : 전송률이 용량 미만이면 오류 확률을 임의로 낮추는 채널 부호화 기법이 존재 → 신뢰성과 전송률 사이의 균형 판단 기준 제공.

## Ⅲ. 샤논 채널 용량 정리의 구조 (흐름)

- 핵심 요약 : 대역폭과 신호 대 잡음비가 용량을 결정하고, 전송률과 용량의 대소 비교가 통신 설계의 판정 절차가 되는 구조.
- 공식 변수 : C는 채널 용량(bps), B는 대역폭(Hz), S/N은 신호 대 잡음 전력비.

```text
[ 채널 용량의 결정 ]

C = B × log2(1 + S/N)
    ↓
B : 대역폭 (Hz) — 용량에 정비례
    ↓
S/N : 신호 대 잡음비 — 로그 비례
    ↓
C : 오류 없이 달성 가능한 최대 전송률 (bps)
```

```text
[ 전송률과 용량의 판정 ]

전송률 R과 용량 C의 비교
    ↓ R < C
오류를 임의로 낮추는 부호 존재
    ↓ R > C
아무리 부호화해도 신뢰성 확보 불가
```

## Ⅳ. 나이키스트 공식과 샤논 정리의 비교

- 핵심 요약 : 나이키스트 공식이 잡음 없는 채널의 심볼 전송률 상한이라면, 샤논 정리는 실제 잡음 채널의 정보 전송률 절대 상한.

| 비교 축 | 나이키스트 공식 (무잡음 채널) | 샤논 채널 용량 정리 (잡음 채널) |
| --- | --- | --- |
| 잡음 가정 | 잡음 없는 이상적 채널 | 백색 가우시안 잡음 존재 |
| 결정 요인 | 대역폭과 심볼 레벨 수 | 대역폭과 신호 대 잡음비 |
| 용량 식 | C = 2B × log2 M | C = B × log2(1 + S/N) |
| 의미 | 심볼 전송률의 상한 | 정보 전송률의 절대 상한 |
| 설계 용도 | 변조 다중 수준의 상한 추정 | 달성 가능 최대 속도의 판정 |

- 선택 기준 : 심볼 설계의 물리적 가능 여부는 **나이키스트 공식**(Nyquist Formula)으로, 실제 잡음 환경의 속도 상한은 샤논 정리로 판정하며 두 기준은 동시 적용.
- 실무 판단 : 심볼 레벨을 높여도 잡음으로 오류율이 나빠지므로, 최종 달성 속도는 샤논 용량이 묶는 구조.

## Ⅴ. 샤논 정리 적용의 한계와 방안

- 핵심 요약 : 구현 부호 미제시, 가우시안 가정의 괴리, 간섭 환경의 미반영이 적용 한계이며 부호 기술과 채널 대응 기술로 일대일 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 구현 부호 미제시 | 오류 없는 부호의 존재만 증명되어 실용 부호는 장기 미해 과제로 남음 | 터보 코드, LDPC(Low-Density Parity-Check), 폴라 코드 도입으로 용량 근접 | 용량 대비 필요 SNR 여유 |
| 가우시안 가정의 괴리 | 페이딩·도플러가 있는 실제 채널은 단순 모델과 오차 발생 | OFDM(Orthogonal Frequency Division Multiplexing)과 적응 변복조로 채널 분할 대응 | 채널 추정 오차, 패킷 오류율 |
| 간섭 환경 미반영 | 셀 간 간섭이 있는 실제 망에서는 이론 용량만큼 달성되지 않음 | 셀 간 간섭 조정과 자원 배분 최적화 | 실달성 스펙트럼 효율 |

## Ⅵ. 샤논 정리 활용 확대를 위한 기술사적 제언

- 핵심 요약 : 용량의 공간 확장 설계, 저지연 서비스의 보정 모델 채택, 의미 기반 통신 연구로 활용 범위를 넓히는 것.

1. 이동통신 사업자와 표준 단체는 대규모 다중 안테나(Massive MIMO)와 지능형 반사면(RIS, Reconfigurable Intelligent Surface)의 결합 설계 기준을 망 계획 지침에 포함해, 대역 증설 한계를 공간 차원의 용량 확장으로 보완해야 한다.
2. 초저지연 서비스를 운영하는 사업자는 짧은 패킷에서 이론 용량과 달성 속도가 달라지는 유한 블록장(Finite Blocklength) 용량 모델을 설계 지침으로 채택해야 한다.
3. 6G 연구기관은 비트 전달을 넘어 의미 전달 효율을 다루는 시맨틱 통신(Semantic Communication)을 후속 이론 과제로 육성하고, 의미 기반 평가 지표를 함께 연구해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 샤논의 정리는 잡음 채널의 속도 상한을 규정해 모든 통신 설계의 이론적 기준선이 되는 정리.
- 용량 상한에 근접하는 부호 기술은 실용화 단계에 있으며, 이후 과제는 채널 모델의 현실성과 의미 전달 효율로 이동하는 중.
