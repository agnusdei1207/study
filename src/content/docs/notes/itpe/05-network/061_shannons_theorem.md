- **샤논 채널 용량 정리(Shannon Channel Capacity Theorem):** 잡음 채널에서 신뢰성 있는 통신의 최대 전송률을 채널 용량으로 규정하는 정리
- **AWGN(Additive White Gaussian Noise):** 부가성·백색성·가우시안 분포를 가정하는 잡음 채널 모델

- **SNR(Signal-to-Noise Ratio):** 신호 전력과 잡음 전력의 비

## Ⅰ. 개요

| 목적 | 통신 채널의 이론적 용량과 부호화 성능의 기준 제시 |

## Ⅱ. AWGN 채널 용량

| 조건 | 용량 관계 |
|---|---|
| 대역폭 (B), SNR (S/N)인 AWGN 채널 | (C = B\log_2(1+S/N)) bit/s |
| 전송률 (R<C) | 충분히 긴 부호를 사용하면 오류 확률을 임의로 작게 설계 가능 |
| 전송률 (R>C) | 임의로 작은 오류 확률을 보장하는 통신 불가 |

제언: 대역폭·전력·목표 전송률로 채널 용량 여유를 먼저 검토

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **샤논 채널 용량 정리(Shannon Channel Capacity Theorem)** 는 잡음 채널에서 신뢰성 있는 통신이 가능한 최대 전송률을 규정하는 정리 |
| 목적 | 통신 채널의 이론적 용량과 부호화 성능의 기준 제시 |

## Ⅱ. 용량과 신뢰성의 관계

```text
대역폭 B · 신호대잡음비 S/N
              │ 용량식 적용
              ▼
     채널 용량 C = B log₂(1+S/N)
              │ 전송률 R 비교
       ┌──────┴──────┐
       ▼             ▼
     R < C          R > C
       │             │
오류 확률을 낮출   신뢰성 있는 전송의
수 있는 부호화     보장 불가
```

AWGN 채널에서 (C=B\log_2(1+S/N)). 이 결과는 특정 부호가 아니라 장거리 부호의 존재와 한계를 제시하는 점근적 정리

## Ⅲ. 나이퀴스트 기준과 구분

| 기준 | 전제 | 제한 요소 |
|---|---|---|
| 나이퀴스트 심볼률 기준 | 이상적 무잡음 채널 | 대역폭과 심볼 간섭 조건 |
| 샤논 채널 용량 | 잡음 채널 모델 | 대역폭과 신호대잡음비 |

## Ⅳ. 설계 적용과 한계

| 적용 요소 | 설계 해석 |
|---|---|
| 대역폭 증가 | AWGN 용량식에서 대역폭에 비례하는 용량 증가 |
| SNR 증가 | 로그 관계에 따라 용량은 증가하나 증가 폭은 점차 작아짐 |
| 실제 변복조·부호화 | 유한 블록 길이와 구현 손실 때문에 이론 용량에 정확히 도달하지 못함 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 채널 용량을 장비의 실효 처리량과 동일하게 보면 구현 손실·변동 여유가 누락 | 서비스 목표와 측정 SNR 분포를 기준으로 변조·부호화와 재전송을 설계하고, 용량식은 상한 검토에 사용 |
