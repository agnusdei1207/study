## 연관 키워드

- 샤논의 정리(Shannon's Theorem), 채널 용량(Channel Capacity), 신호 대 잡음비(SNR, Signal-to-Noise Ratio)
- AWGN(Additive White Gaussian Noise), 샤논 한계(Shannon Limit), 나이키스트 공식(Nyquist Formula)
- 채널 부호화, 소스 부호화, 율-왜곡 이론(Rate-Distortion Theory)
- 터보 코드, LDPC(Low-Density Parity-Check), 폴라 코드, MIMO, 시맨틱 통신

## Ⅰ. 샤논의 정리(Shannon's Theorem)의 개요

- 핵심 요약 : 잡음이 있는 대역제한 채널에서 오류 없이 보낼 수 있는 최대 전송률의 상한을 제시한 정보이론의 기본 정리.
- 개념 : 백색 가우시안 잡음(AWGN, Additive White Gaussian Noise)이 있는 대역제한 채널에서 오류 없이 보낼 수 있는 최대 전송률, 즉 **채널 용량** (Channel Capacity)의 상한을 대역폭과 신호 대 잡음비의 관계로 유도한 **샤논의 정리** (Shannon's Theorem).
- 배경 및 필요성 : 선로의 잡음과 대역폭에는 물리적 한계가 있어 전송 속도를 무한정 올릴 수 없다는 점을 수학적으로 규명하고, 변복조와 채널 코딩 설계의 기준을 제공할 필요가 있었음.
- 주요 목적 : 채널 용량의 상한을 규명하고, 적절한 부호화로 오류율을 임의로 낮출 수 있다는 가능성을 증명하며, 이동통신 설계의 이론적 지침을 제공.

## Ⅱ. 샤논 채널 용량의 특징 및 장점

- 핵심 요약 : 대역폭과 신호 대 잡음비가 채널 용량을 결정하며, 대역폭 확대는 용량을 비례로 늘리고 전력 증대는 로그 형태로 완만하게 늘림.

1. 대역폭 효과 : 용량이 대역폭에 정비례 → 용량을 가장 직접적으로 늘리는 수단이지만 주파수 자원은 한정됨.
2. 신호 대 잡음비 효과 : 용량이 log2(1 + S/N)에 따라 증가 → 송신 전력을 올려도 증가율이 점차 둔화.
3. 극한 용량 : 대역폭을 무한히 넓혀도 용량은 (S/N0) × log2(e), 약 1.44 × (S/N0)로 수렴 → 대역 확장만으로 무한 속도를 얻을 수 없음.
4. 샤논 한계 : 비트당 에너지 대 잡음 밀도비(Eb/N0)가 약 -1.59 dB 이하이면 임의로 낮은 오류율의 통신이 불가능하다는 이론적 하한.

```text
C = B × log2(1 + S/N)
        ↓
C : 채널 용량 (bps)
B : 대역폭 (Hz)
S/N : 신호 대 잡음 전력비
```

```text
전송률 R < 채널 용량 C
        ↓
오류를 줄이는 채널 부호 존재
        ↓
오류율을 임의로 낮출 수 있음
```

## Ⅲ. 샤논 정보이론의 구조 (흐름)

- 핵심 요약 : 정보원에서 압축, 채널 부호화, 전송, 복호화로 이어지는 흐름에서 각 단계의 한계를 정보이론의 세 정리가 나누어 규정.

```text
정보원
        ↓
소스 부호화 (1정리: 압축 한계)
        ↓
채널 부호화 (2정리: 전송률 한계)
        ↓
잡음 채널 (AWGN)
        ↓
채널 복호화 → 소스 복호화
```

| 구분 | 1정리 (소스 부호화) | 2정리 (채널 부호화) | 3정리 (율-왜곡 이론) |
| --- | --- | --- | --- |
| 핵심 내용 | 무손실 데이터 압축의 한계 | 오류 없는 전송률의 한계 | 손실 압축에서 허용 왜곡의 한계 |
| 기준 척도 | 데이터 엔트로피 H(X) | 채널 용량 C = B log2(1 + S/N) | 왜곡 척도 D와 최소 전송률 R(D) |
| 의미 | 평균 부호 길이는 엔트로피보다 짧을 수 없음 | 전송률이 용량보다 작으면 오류를 줄이는 부호가 존재 | 허용 왜곡 이하를 보장하는 최적 압축률 |
| 대표 기술 | 허프만 코딩, 산술 코딩 | 터보 코드, LDPC(Low-Density Parity-Check), 폴라 코드 | JPEG, MP3, H.264/HEVC 영상 압축 |

## Ⅳ. 나이키스트 공식과 샤논 정리의 비교

- 핵심 요약 : 나이키스트 공식은 잡음을 무시한 심볼 수준의 상한이고, 샤논 정리는 실제 열잡음이 있는 채널의 절대 상한이라 설계 기준으로 더 엄격함.

| 비교 축 | 나이키스트 공식 (무잡음 채널) | 샤논 채널 용량 (잡음 채널) | 실제 무선 채널 |
| --- | --- | --- | --- |
| 잡음 가정 | 잡음 미고려 | 백색 가우시안 잡음 | 페이딩, 도플러, 버스트 간섭 |
| 결정 요인 | 대역폭과 심볼 레벨 M | 대역폭과 신호 대 잡음비 | 다중 경로, 이동 속도, 간섭 |
| 용량 식 | C = 2B log2 M | C = B log2(1 + S/N) | 샤논 모델로 근사하여 판단 |
| 설계상 용도 | 변조 다중 수준의 상한 추정 | 이론적 최대 전송률 판단 | 채널 모델 보정과 부호 선택 |

- 극복 기술 : 대역폭 확대(밀리미터파, 테라헤르츠 대역), 공간 다중화(MIMO, Multiple-Input Multiple-Output, 용량 근사 min(송신, 수신 안테나 수) × B log2(1 + SNR)), 고차 변조(QAM, Quadrature Amplitude Modulation)로 같은 대역에서 전송 비트수를 늘림.

## Ⅴ. 샤논 정리 적용의 한계와 방안

- 핵심 요약 : 샤논은 부호의 존재만 증명했고 실제 채널은 가우시안 가정과 다르므로, 근접 부호 기술과 채널 모델 보정으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 구현 가능한 부호를 제시하지 않음 | 오류 없는 부호의 존재만 증명되어, 실제로 한계에 가까운 부호는 수십 년간 과제로 남음 | 터보 코드, LDPC, 폴라 코드를 도입해 한계 가까이 근접 | 블록 오류율(BLER, Block Error Rate) 대비 필요 SNR 여유 |
| AWGN 가정과 실제 채널의 괴리 | 레일리(Rayleigh)·라이시안(Rician) 페이딩, 도플러 시프트, 버스트 간섭으로 단순 모델의 설계 오차 발생 | OFDM(Orthogonal Frequency Division Multiplexing)으로 광대역 선택적 페이딩 채널을 협대역 평탄 채널로 나누어 모델 적용 | 채널 추정 오차, 패킷 오류율 |

## Ⅵ. 샤논 정리 적용 및 발전을 위한 기술사적 제언

- 핵심 요약 : 시맨틱 통신 연구와 의미 기반 평가 지표 마련, Massive MIMO와 RIS 결합 설계, 유한 블록장 모델 채택으로 한계를 넘는 것.

1. 6G 설계 연구 기관과 표준 단체는 비트를 정확히 옮기는 목표에서 나아가 정보의 의미를 전달하는 **시맨틱 통신** (Semantic Communication)을 연구 과제로 두고, 의미 기반 평가 지표를 함께 마련해야 한다.
2. 밀집 도심 환경에서는 대규모 다중 안테나(Massive MIMO)와 지능형 반사면(RIS, Reconfigurable Intelligent Surface)을 결합한 설계 기준을 망 계획에 포함해, 대역폭 증설의 한계를 신호 세기 향상으로 보완해야 한다.
3. 초저지연 미션 크리티컬 통신을 맡는 사업자는 짧은 패킷 블록에서 달라지는 유한 블록장(Finite Blocklength) 용량 모델을 설계 지침으로 채택해, 이론 상한과 실제 달성 가능 속도의 차이를 관리해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 샤논의 정리는 잡음 있는 채널의 속도 상한을 규정해 모든 무선 설계의 이론적 기준선이 되는 정보이론의 기초.
- 시사점 : 상한에 근접하는 부호 기술은 이미 실용화되었고, 이후의 과제는 채널 모델의 현실성과 의미 전달 효율로 옮겨가고 있다.
