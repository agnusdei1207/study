## Ⅰ. 샤논의 정리(Shannon's Theorem)의 개요

- 개념 : **가우시안 백색 잡음(AWGN)** 이 존재하는 대역제한 아날로그 전송 채널에서 오류 없이 정보를 전송할 수 있는 이론적 최대 전송률(채널 용량: Channel Capacity)의 상한선을 대역폭과 신호 대 잡음비의 관계로 유도한 정보이론의 핵심 정리 (샤논-하틀리 정리).
- 배경 및 필요성 : 전송 선로의 잡음과 대역폭의 물리적 한계 속에서 무한정 전송 속도를 높일 수 없다는 수학적 한계를 명확히 규명하고, 최적의 디지털 변복조 및 **채널 코딩** 설계 기준을 제공하기 위해 도출.
- 핵심 목적 : **채널 용량** 상한선($C$) 규명, 주어진 잡음 환경에서 오류율을 임의로 0에 가깝게 만들 수 있는 부호화의 이론적 가능성 증명, 이동통신(4G/5G/6G) 시스템 설계의 물리적 가이드라인 제공.

## Ⅱ. 샤논의 핵심 수식 및 물리적 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 샤논-하틀리 채널 용량 수식 및 의미 ]                │
│                                                                        │
│                      C = B * log_2 ( 1 + S/N )                         │
│                                                                        │
│   - C : 채널 용량 (Channel Capacity, bps)                              │
│   - B : 채널 대역폭 (Bandwidth, Hz)                                    │
│   - S : 신호의 평균 전력 (Signal Power, Watt)                          │
│   - N : 잡음의 평균 전력 (Noise Power = N0 * B, Watt)                  │
│   - S/N : 신호 대 잡음 전력비 (SNR, 진수값: SNR_dB = 10*log_10(S/N))  │
│                                                                        │
│   [ 물리적 시사점 ]                                                    │
│   1. 대역폭(B) 증가 ──► 채널 용량 선형적 증가 (가장 효과적인 증대 방안)│
│   2. 송신전력(S) 증가 ──► log 함수 특성상 채널 용량 증가율 점진 둔화    │
│   3. 대역폭이 무한대(B ──► ∞)로 갈 때의 극한값:                       │
│      C_max = (S / N0) * log_2(e) ≈ 1.44 * (S / N0)  (무한 확장 불가)   │
└────────────────────────────────────────────────────────────────────────┘
```

- **대역폭(B)과 SNR의 상호 교환성 (Trade-off)** : 동일한 채널 용량($C$)을 달성하기 위해, 대역폭이 좁으면 높은 송신 전력(SNR)이 필요하고, 전력이 제한된 위성 통신 등에서는 넓은 대역폭을 사용하여 극복 가능.
- 나이키스트(Nyquist) 공식과의 관계 :
  - **나이키스트 (무잡음 채널)** : $C = 2B \log_2 M$ (심볼 레벨 $M$에 의해서만 결정, 잡음 미고려).
  - **샤논 (유잡음 채널)** : $C = B \log_2(1 + S/N)$ (실제 열잡음이 존재하는 물리 환경의 절대적 한계치).
- **샤논 한계 (Shannon Limit, $-1.6\text{ dB}$)** : 임의의 작은 오류율로 통신을 수행하기 위해 요구되는 최저의 비트당 신호 대 잡음 밀도비($E_b/N_0$) 한계는 약 $-1.59\text{ dB}$임.

## Ⅲ. 샤논의 정리 3대 기본 정리 및 현대 무선통신 비교 분석

| 구분 | 샤논의 1정리 (소스 부호화) | 샤논의 2정리 (채널 부호화) | 샤논의 3정리 (율-왜곡 이론) |
|---|---|---|---|
| 핵심 정리 | 무손실 데이터 압축 한계 | 오류 없는 전송률 한계 | 손실 압축의 왜곡 한계 |
| 물리적 기준 | 데이터 엔트로피 $H(X)$ | 채널 용량 $C = B \log_2(1+S/N)$ | 왜곡 척도 $D$와 최소 전송률 $R(D)$ |
| 의미 | 평균 부호 길이는 엔트로피보다 작을 수 없음 | 전송률 $R < C$이면 오류율을 0으로 만드는 부호 존재 | 허용 왜곡 $D$ 이하를 보장하는 최적 데이터 압축률 |
| 대표 기술 | 허프만 코딩, 산술 코딩 | 터보 코드, LDPC(Low-Density Parity-Check), 폴라 코드 | JPEG, MP3, H.264/HEVC 영상 압축 |

- 샤논 한계 극복을 위한 현대 통신 기술 :
  - **대역폭($B$) 극대화** : 초광대역 밀리미터파(mmWave 28GHz) 및 테라헤르츠(THz) 대역 개척.
  - **공간 다중화 (MIMO, Multiple-Input Multiple-Output)** : $C \approx \min(M, N) \cdot B \log_2(1 + \text{SNR})$ 다중 안테나를 통해 단일 주파수 대역폭을 가상으로 배수 증대.
  - **고차 변조 (QAM, Quadrature Amplitude Modulation)** : 높은 SNR 구간에서 1024-QAM, 4096-QAM을 적용하여 심볼당 전송 비트수 극대화.

## Ⅳ. 샤논의 정리 적용 시 주요 한계점 및 해결 방안

- 이론적 존재성만 증명하고 구체적 부호화 알고리즘 미제시 :
  - 한계점 : 샤논은 $R < C$ 조건에서 오류 없는 부호가 존재한다는 수학적 확률만을 증명했을 뿐, 실제 구현 가능한 부호화 방식을 제시하지 못함 (반세기 동안 학계 난제).
  - 해결 방안 : 터보 코드(Turbo Code), LDPC(Low Density Parity Check) 및 폴라 코드(Polar Code)가 개발되어 5G/6G 표준에서 샤논 한계에 0.01dB 단위로 근접 달성.
- 가우시안 백색 잡음(AWGN) 가정과 실제 다중경로 무선 채널의 괴리 :
  - 한계점 : 실제 무선망은 레일리/라이시안 페이딩, 도플러 시프트, 돌발적 버스트 간섭이 발생하여 샤논의 단순 채널 모델 적용 한계.
  - 해결 방안 : OFDM(직교 주파수 분할 다중화)을 통해 광대역 주파수 선택적 페이딩 채널을 수많은 협대역 평탄(Flat) AWGN 채널로 쪼개어 샤논 모델 적용.

## Ⅴ. 샤논의 정리 적용 및 발전을 위한 기술사적 제언

- 시맨틱 통신(Semantic Communication)으로의 패러다임 전환 : 단순 비트(Bit)를 정확하게 전송하는 샤논의 통신 한계(Level A)를 넘어, 전송되는 정보의 '의미(Meaning)'와 '효과(Effectiveness)'를 지능적으로 전송하는 AI(Artificial Intelligence) 기반 시맨틱 6G 통신 패러다임 개척.
- 초고용량 Massive MIMO 및 RIS 메타물질 융합 : 대역폭 증대 한계를 극복하기 위해 수천 개의 안테나 빔과 RIS 반사면을 결합하여 SNR을 인위적으로 증폭시키는 공간 차원 샤논 용량 확장 지속.
- 초저지연 양자 한계 극복 통신 연구 : 극초저지연 환경에서 패킷 블록 길이가 극단적으로 짧아질 때 발생하는 유한 블록장(Finite Blocklength) 영역의 샤논 용량 보정 모델을 6G 미션 크리티컬 통신에 선제 적용.
