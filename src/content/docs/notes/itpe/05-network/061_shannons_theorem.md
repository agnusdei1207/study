## 30초 인출

- 본질: **샤논의 채널 용량 정리(Shannon's Channel Capacity Theorem)** : 대역폭 $B$와 신호 대 잡음비(SNR)가 주어졌을 때 백색 가우시안 잡음(AWGN) 환경에서 오류 없이(Error-free) 전송 가능한 이론적 최대 정보 전송률의 상한선($C = B \log_2(1 + S/N)$ bps)을 증명한 정리
- 메커니즘: 전송률 $R < C$인 경우 적절한 채널 부호화를 적용하여 오류 확률을 0으로 수렴시킬 수 있음을 증명하며, 대역폭과 송신 전력 간의 상호 교환(Trade-off) 이론 기반 제공
- 통찰: 무한 블록 길이 가정에 따른 초저지연(URLLC) 환경의 유한 블록 길이 용량 페널티와 고차 QAM 성좌 성형 손실 극복을 위해 폴리안스키 유한 블록 모델과 PCS 확률적 성좌 성형 연계 필수

<details>
<summary>핵심 용어</summary>

- **AWGN (Additive White Gaussian Noise)** : 전 주파수 대역에 걸쳐 균일한 전력 밀도를 가지며 진폭이 가우시안 정규 분포를 따르는 이상적 잡음 채널 모델
- **채널 용량 (Channel Capacity, $C$)** : 잡음이 존재하는 물리 채널을 통해 오류 없이 신뢰성 있게 전송할 수 있는 단위 시간당 최대 비트 수 (bps)
- **샤논 한계 (Shannon Limit)** : 대역폭이 무한대로 발산할 때 1비트의 정보를 무오류 전송하기 위해 요구되는 절대 최소 신호 대 잡음 전력비 ($E_b/N_0 = \ln 2 \approx -1.59 dB$)
- **유한 블록 길이 (Finite Blocklength)** : 통신 패킷 길이가 유한할 때 발생하는 전송 용량 감쇄를 설명하는 현대 정보이론 (Polyanskiy 모델)
- **PCS (Probabilistic Constellation Shaping)** : 고차 QAM 변조 시 전력 소모가 적은 안쪽 성좌점을 바깥쪽 성좌점보다 높은 확률로 송출하여 가우시안 분포를 근사하는 성형 기술

</details>

## 2~4교시 25점 답안

## Ⅰ. 샤논의 채널 용량 정리 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 부가성 백색 가우시안 잡음(AWGN)이 존재하는 물리 통신 채널에서 정보 손실 없이 신뢰성 있게 전송할 수 있는 수학적 최대 데이터 전송률의 상한선($C = B \log_2(1 + S/N)$ bps)을 규정한 정보이론의 핵심 정리 |
| 목적 | 물리적 통신 채널의 전송 한계를 정량화하고, 주어진 대역폭과 송신 전력 조건 하에서 비트 오류율을 극소화하는 최적 채널 부호화 및 변조 기법의 설계 척도 제공 |

## Ⅱ. 샤논 정리의 특징 및 수식 분석

| 분석 항목 | 수식 및 수학적 관계 | 물리적 의미 및 엔지니어링 특징 |
|---|---|---|
| **채널 용량 기본식** | $C = B \log_2 \left( 1 + \frac{S}{N} \right)$ [bps] | 채널 용량 $C$는 채널 대역폭 $B$(Hz)에 선형 비례하고, 신호 대 잡음 전력비($S/N$)에는 로그 비례 |
| **대역폭 제한 영역** | $B$가 작고 $S/N$이 매우 큰 영역 ($S/N \gg 1$) | $C \approx B \log_2(S/N)$, 대역폭 확장이 어려울 때 고차 변조(256-QAM 등)로 전송률 증대 (유선/케이블) |
| **전력 제한 영역** | $S/N$이 작고 $B$가 매우 넓은 영역 ($S/N \ll 1$) | $C \approx 1.44 \cdot B \cdot (S/N)$, 전력이 부족할 때 광대역 확산(DSSS/UWB)으로 통신 가능 (위성/우주) |
| **샤논 한계 (무한 대역폭)**| $\lim_{B \to \infty} C = \frac{S}{N_0 \ln 2} \approx 1.44 \frac{S}{N_0}$ | 대역폭 $B$를 무한대로 확장해도 채널 용량은 무한대가 되지 않고 송신 전력 $S$에 비례한 상한 수렴 |

## Ⅲ. 샤논 채널 용량 아키텍처 및 전송률-오류율 관계

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 샤논 채널 용량과 신뢰성 통신 판정 ]               │
│                                                                        │
│   물리 채널 파라미터                                                   │
│   - 가용 대역폭: B (Hz)                                                │
│   - 신호 전력 / 잡음 전력: S / N                                       │
│          │                                                             │
│          ▼ 샤논 채널 용량 연산                                         │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │               이론적 한계 용량 C = B log₂(1 + S/N)             │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ 실제 데이터 전송률 R 비교          │
│          ┌────────────────────────┴────────────────────────┐           │
│          ▼ (전송률 R < C)                                  ▼ (R > C)   │
│   ┌───────────────────────────────┐ ┌───────────────────────────────┐   │
│   │ [샤논 제2정리 만족]           │ │ [신뢰성 통신 불가]            │   │
│   │ - 충분히 긴 블록 부호화 적용 시│ │ - 어떠한 채널 부호화를 써도   │   │
│   │ - 비트 오류율(BER) -> 0 달성  │ │   비트 오류율을 0으로 낮출 수 │   │
│   │ - 신뢰성 있는 통신 완전 보장  │ │   없음 (오류 마루 현상 발생)  │   │
│   └───────────────────────────────┘ └───────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

| 판정 영역 | 조건 | 통신 신뢰성 및 물리적 특성 |
|---|---|---|
| **무오류 전송 가능 영역** | $R < C$ | 적절한 오류 정정 부호(FEC)를 적용하면 오류 확률을 임의의 작은 값($P_e \to 0$)으로 수렴 가능 |
| **신뢰성 전송 불가 영역** | $R > C$ | 아무리 복잡한 채널 부호화를 설계하더라도 오류율이 특정 하한선 이하로 떨어지지 않고 통신 단절 |
| **샤논 한계 (Shannon Limit)** | $E_b/N_0 \ge -1.59 dB$ | 1비트 정보를 신뢰성 있게 전송하기 위한 물리적 절대 최소 에너지 잡음비 |

## Ⅳ. 나이퀴스트 채널 용량(무잡음) vs 샤논 채널 용량(잡음) 비교

| 비교 항목 | 나이퀴스트 채널 용량 (Nyquist) | 샤논 채널 용량 (Shannon) |
|---|---|---|
| **대상 채널 전제** | **잡음이 전혀 없는 이상적 채널 (Noiseless)**| **백색 가우시안 잡음이 존재하는 실제 채널 (AWGN)**|
| **용량 산출 수식** | **$C = 2B \log_2 M$ [bps]** | **$C = B \log_2(1 + S/N)$ [bps]** |
| **핵심 제한 요인** | 대역폭($B$) 및 부호화 진폭 레벨 수($M$) | 대역폭($B$) 및 신호 대 잡음 전력비($S/N$) |
| **심볼 간 간섭(ISI)** | 나이퀴스트 제1기준(최대 심볼 전송률 $2B$ baud) | ISI 극복 및 최적 수신 정합 필터(Matched Filter) 전제 |
| **의의 및 가치** | 변조 방식(M-ary)에 따른 데이터 전송률 척도 | 물리 채널이 허용하는 궁극의 정보 전송 한계선 규정 |

## Ⅴ. 샤논 채널 용량의 엔지니어링 한계와 방안

| 한계 | 방안 |
|---|---|
| 샤논 정리는 블록 길이 $n \to \infty$인 무한 부호 길이를 전제하므로, 5G URLLC와 같은 초저지연(단축 패킷, 서브 ms) 통신 환경에서는 유한 블록 길이(Finite Blocklength) 효과로 샤논 용량 대비 심각한 백오프 손실(Back-off Loss) 발생 | 폴리안스키-푸어-베르두(Polyanskiy-Poor-Verdú)의 유한 블록 채널 용량 정규 근사 모델($C \approx C_{AWGN} - \sqrt{V/n} Q^{-1}(\epsilon)$)을 적용하여 요구 패킷 길이와 지연시간에 맞는 현실적 부호율 마진 사전 설계 |
| 채널 용량에 근접하기 위해 256-QAM, 1024-QAM 등 초고차 변조를 적용할 때 격자형(Grid) 성좌점 배치로 인해 가우시안 최적 입력 확률 분포를 형성하지 못하여 최대 1.53dB의 성좌 성형 손실(Shaping Loss) 발생 | 중심부 성좌점의 송출 빈도를 외곽보다 기하급수적으로 높여 가우시안 분포를 근사하는 확률적 성좌 성형(PCS) 기술을 광통신 및 5G-Advanced 기저대역 변조기에 도입 |
| 샤논 정리는 채널의 통계적 특성이 정적인 시불변 AWGN을 가정하나, 실제 무선 채널은 다중경로 반사로 인해 레일리/라이시안 페이딩(Fading)이 발생하여 순간 수신 SNR이 급격히 저하 | 주파수/시간/공간 축에서 다이버시티를 확보하는 다중 안테나(Massive MIMO) 공간 다중화 및 채널 상태 정보(CSI) 기반 적응형 변복조(AMC) 기법 연계 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
차세대 6G 무선 접속망 및 테라비트 광전송망 설계 시, 단순 송신 전력 증대는 비선형 왜곡과 전력 증폭기(HPA) 포화만 야기하므로 지양해야 하며, 샤논 한계와의 격차가 0.1dB 이내로 좁혀진 극부호(Polar Codes)와 저밀도 패리티 검사(LDPC) 부호를 결합하고, 공간 자유도를 극대화하는 초대용량 MIMO 빔포밍 아키텍처 수립 권장

### 3. 기술 유형 및 비교 평가
| 채널 코딩 기법 | 복호 알고리즘 | 샤논 한계 근접도 | 복호 지연시간 | 5G/6G 표준 채택 영역 |
|---|---|---|---|---|
| **컨볼루션 부호 (CC)** | 비터비(Viterbi) 알고리즘 | 2 ~ 3 dB 격차 (한계 큼) | 낮음 | 3G/4G 제어 채널 (레거시) |
| **터보 부호 (Turbo)** | 반복 MAP (BCJR) 알고리즘 | 0.5 ~ 0.7 dB 근접 | 중간 (반복 연산 지연) | 3G/4G LTE 데이터 채널 |
| **LDPC 부호** | 신뢰도 전파(Belief Propagation)| **0.05 ~ 0.1 dB 초근접** | 낮음 (완전 병렬 하드웨어) | **5G NR eMBB 데이터 채널, Wi-Fi 7** |
