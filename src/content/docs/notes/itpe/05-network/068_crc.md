<summary>핵심 용어</summary>

- **CRC(Cyclic Redundancy Check):** 생성 다항식 나눗셈의 나머지로 비트열 오류를 검출하는 방식
- **생성 다항식(Generator Polynomial):** 송수신 양측이 나눗셈에 공통으로 사용하는 이진 다항식
- **모듈로-2 연산(Modulo-2 Arithmetic):** 올림·빌림 없이 XOR로 수행하는 이진 다항식 연산
- **FCS(Frame Check Sequence):** 전송 프레임에 붙이는 오류 검출용 나머지 비트열
- **LFSR(Linear Feedback Shift Register):** 생성 다항식에 따라 XOR 피드백을 수행하는 CRC 회로 구현 방식

| 목적 | 데이터 전송·저장 중 발생한 비트 오류 검출 |

## Ⅱ. FCS 생성·검사

```text
송신 데이터 M(x)
       ↓ 생성 다항식 G(x)로 모듈로-2 나눗셈
나머지 R(x) = FCS
       ↓ 데이터 뒤에 첨부
전송 프레임 [M(x) | FCS]
       ↓ 수신 측에서 같은 G(x)로 나눗셈
나머지 0 → 오류 검출 조건을 통과
나머지 비영(非零) → 오류 검출
```

제언: 오류 검출용 CRC와 악의적 변조 방지용 암호학적 무결성 검증을 구분

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CRC(Cyclic Redundancy Check)** 는 이진 생성 다항식 나눗셈의 나머지를 이용하는 오류 검출 방식 |
| 목적 | 데이터 전송·저장 중 발생한 비트 오류 검출 |

## Ⅱ. 생성 다항식과 송신 부호화

```text
데이터 M(x) ── 뒤에 r개의 0 추가 ──▶ M(x)·xʳ
                                         │ G(x)로 모듈로-2 나눗셈
                                         ▼
                                  나머지 R(x)
                                         │
전송 프레임: M(x)와 R(x) 결합 ◀──────────┘
```

| 연산 요소 | 역할 |
|---|---|
| 차수 r의 생성 다항식 G(x) | 송수신기가 공유하는 오류 검출 규칙 |
| 모듈로-2 나눗셈 | 자리올림·빌림 없이 XOR로 나머지 산출 |
| FCS | 계산된 나머지를 프레임에 추가한 검사 비트열 |

## Ⅲ. 수신 검사와 검출 범위

| 수신 측 계산 | 판정 |
|---|---|
| 수신 프레임을 G(x)로 나눈 나머지가 0 | 검사 통과; 모든 오류가 없음을 증명하지는 않음 |
| 나머지가 0이 아님 | 전송·저장 비트열 오류 검출 |
| 생성 다항식 차수 r | 길이 r 이하의 모든 연집 오류 검출 특성 |

CRC는 오류를 검출하지만 원래 데이터를 복구하는 오류 정정 코드는 아님. 다항식 선택에 따라 검출 가능한 오류 패턴이 달라짐

## Ⅳ. 오류 검출 방식 비교·적용

| 방식 | 연산 원리 | 주요 특징 |
|---|---|---|
| 단순 패리티 | 비트 XOR 관계 확인 | 단일 비트 오류 검출에 간단하나 일부 다중 비트 오류 미검출 |
| 체크섬 | 고정 폭 워드 덧셈·보수 | 계산이 간단하며 CRC와 다른 오류 패턴 특성 |
| CRC | 생성 다항식 모듈로-2 나눗셈 | 연집 오류 검출에 적합하며 정정 기능은 없음 |

| 적용 환경 | 고려사항 |
|---|---|
| 링크·저장 장치의 우발 오류 | 표준화된 생성 다항식과 프레임 형식 일치 |
| 소프트웨어·하드웨어 구현 | 데이터 폭·처리량·엔디언 및 비트 처리 순서 일치 |
| 공격자에 의한 변조 | CRC를 인증·암호학적 무결성으로 대체하지 않고 MAC·전자서명 등 별도 적용 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| CRC 값이 맞아도 공격자가 데이터와 검사값을 함께 바꾸면 변조를 판별하지 못함 | 통신 계층의 우발 오류 검출은 CRC로 수행하고, 신뢰 경계를 넘는 데이터에는 인증된 암호학적 무결성 검증을 별도 적용 |
