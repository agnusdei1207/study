## 연관 키워드

- 5G SA(Standalone), 5GC(5G Core), 3GPP Option 2, NSA(Non-Standalone)
- 서비스 기반 아키텍처(SBA), AMF, SMF, UPF, NRF, NSSF, SCP
- 네트워크 슬라이싱, CUPS, URLLC, MEC, VoNR, EPS Fallback

## Ⅰ. 5G 단독모드(SA)의 개요

- 핵심 요약 : 4G 코어에 기대지 않고 5G 기지국과 5G 코어만으로 전체 망을 운용하는 독립형 5G 구성.
- 개념 : LTE(Long-Term Evolution) 제어망에 의존하지 않고 5G 무선 접속망 기지국인 gNB(next generation NodeB)와 클라우드 네이티브 5G 코어(5GC)만으로 제어·사용자 평면을 구성하는 **5G 단독모드** (5G SA, Standalone) 방식으로, 3GPP(3rd Generation Partnership Project) 배치 옵션 중 Option 2에 해당함.
- 배경 및 필요성 : 초기 상용 5G인 비단독모드 **NSA** (Non-Standalone, Option 3 계열)는 LTE 앵커를 공유해 빠른 구축이 가능했으나, 4G 코어의 제어 절차가 남아 5G 고유 기능 제공에 한계가 있었음.
- 주요 목적 :
  1. 종단 간 **네트워크 슬라이싱** (Network Slicing) 구현
  2. URLLC(Ultra-Reliable Low-Latency Communication) 기반의 초저지연·초신뢰 서비스 제공
  3. 에지 컴퓨팅(MEC, Multi-access Edge Computing) 연계와 서비스 배포 속도 향상

## Ⅱ. 5G 단독모드(SA)의 특징 및 장점

- 핵심 요약 : 독립 코어, 모듈형 제어 구조, 평면 분리가 슬라이싱·저지연·신속 배포로 이어지는 구조.

1. 독립 코어 운용 : 등록과 세션 절차를 5GC만으로 처리 → 4G 제어 오버헤드 제거와 초저지연 스케줄링 확보.
2. **서비스 기반 아키텍처** (SBA, Service-Based Architecture) : 코어 기능들이 표준화된 API로 상호 호출하는 모듈 구조 → 기능 단위 업그레이드와 장애 격리 용이.
3. **CUPS** (Control and User Plane Separation) : 제어 기능과 사용자 트래픽 처리 기능의 분리 → **UPF** (User Plane Function)의 에지 분산 배치와 병목 해소.
4. 슬라이스 격리 : 단말·무선·코어를 관통하는 논리적 독립망 구성 → 서비스별 품질·보안 요구의 맞춤 제공.

## Ⅲ. 5G 단독모드(SA)의 구조 (흐름)

- 핵심 요약 : 서비스 기반의 제어 평면이 사용자 평면을 제어하며, 단말은 gNB를 거쳐 UPF를 통해 데이터망과 통신하는 구조.
- 접속·세션 제어 : **AMF** (Access and Mobility Management Function)는 등록·이동성, **SMF** (Session Management Function)는 PDU(Protocol Data Unit) 세션과 단말 IP 할당을 담당함.
- 지원 기능 : 정책의 PCF(Policy Control Function), 가입자 데이터의 UDM(Unified Data Management), 기능 탐색의 NRF(Network Repository Function), 슬라이스 선택의 NSSF(Network Slice Selection Function)가 제어를 보조함.

```text
[ 5GC 이중 평면 구조 ]

제어 평면 : AMF·SMF·PCF·UDM 등
    ↓ N4 (세션 제어)
사용자 평면 : UPF
    ↓ N6
데이터망 (인터넷 · MEC)
```

```text
[ 등록·세션 수립 흐름 ]

단말
    ↓ gNB 경유 접속
AMF 등록 절차
    ↓
SMF 세션 생성·IP 할당
    ↓ N4
UPF 전송 경로 설정
    ↓
데이터 전송 개시
```

## Ⅳ. 5G NSA와 5G SA의 비교

- 핵심 요약 : NSA는 LTE 인프라를 재사용한 빠른 구축 방식이고, SA는 5G 고유 기능을 완성하는 완전 전환 방식.

| 비교 항목 | 5G NSA (Option 3) | 5G SA (Option 2) |
| --- | --- | --- |
| 코어망 | 4G EPC(Evolved Packet Core) | 5GC (AMF·SMF·UPF) |
| 기지국 구성 | LTE 앵커 + gNB | gNB 단독 |
| 제어 절차 | LTE 코어가 대부분 처리 | 5GC가 직접 처리 |
| 네트워크 슬라이싱 | 무선 일부만 지원 | 종단 간 슬라이싱 |
| 초저지연 서비스 | 4G 제어 한계로 제약 | URLLC·에지 UPF 연계 가능 |
| 음성 서비스 | VoLTE(Voice over LTE) 재사용 | VoNR(Voice over New Radio) 또는 EPS(Evolved Packet System) Fallback |

- 선택 기준 : 커버리지 확보가 우선인 초기 단계는 NSA가, 슬라이싱·저지연 서비스 제공이 목적이면 SA 전환이 필요함.

## Ⅴ. 5G 단독모드(SA)의 한계와 방안

- 핵심 요약 : 초기 커버리지 공백과 서비스 기반 시그널링 증가, 이기종 코어 간 이동 부담을 폴백 절차와 공통 제어 기능으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고주파 커버리지 공백 | 3.5GHz 대역 전파 특성상 실내·교외 음영으로 음성 서비스 단절 | 음영 구간에서 LTE로 전환하는 EPS Fallback과 상호 핸드오버 최적화 | 접속 실패율·호 절단율 |
| SBA 시그널링 증가 | 기능 간 API 호출 증가로 제어 지연과 복잡도 상승 | SCP(Service Communication Proxy)로 호출 경로를 집중 관리하고 NRF 기반 동적 탐색 고도화 | 제어 호출 응답 시간 |
| 4G·5G 상호 이동 부담 | 이기종 코어 간 문맥 전달 절차로 이동 시 지연 발생 | 4G·5G 코어 간 상호 접속 인터페이스(N26) 활용 절차의 정비 | 이동 절체 시간 |

## Ⅵ. 5G 단독모드(SA)에 대한 기술사적 제언

- 핵심 요약 : 특화망 실증과 클라우드 네이티브 운영, 슬라이스 보안 거버넌스를 축으로 SA 확산을 설계하는 방향.

1. 사업자와 산업 현장은 스마트팩토리·원격의료처럼 격리·저지연 요구가 큰 영역에 SA 기반 특화망을 우선 적용해 5G 가치를 실증할 필요가 있음.
2. 사업자의 인프라 부서는 코어 기능을 컨테이너 기반 클라우드 네이티브 환경으로 표준화해 장애 자동 복구와 수요 기반 확장을 구현해야 함.
3. 정책·보안 조직은 슬라이스 간 침범을 막는 제로 트러스트 기반 격리 기준을 마련하고, 슬라이스별 보안 인증 절차를 도입 체계에 포함해야 함.

## Ⅶ. 결론

- 핵심 요약 : 5G SA는 독립 코어와 서비스 기반 구조로 5G 고유 가치를 실현하는 완성형 구성임.
- 시사점 : 망 전환의 성패는 슬라이스 운영력과 보안 체계의 성숙도에 달려 있음.
