## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 이동통신망 → 5G 무선·코어 결합 구조

## 30초 인출

- 본질: **5G 단독모드 (5G Standalone, SA)** 는 5G 무선 접속망과 5G 코어를 함께 사용해 5G 시스템 기능을 제공하는 배치 방식
- 메커니즘: UE의 NR 접속 → gNB → 5GC의 제어·사용자 평면 기능 → 외부 데이터망
- 통찰: 기존 4G LTE 코어망(EPC)에 의존하는 과도기적 NSA(비단독모드)와 달리 순수 5G Core(5GC)와 서비스 기반 아키텍처(SBA)를 전면 구축하여 엔드투엔드 네트워크 슬라이싱과 진정한 1ms 초저지연(URLLC)을 구현하는 기술임.

<details>
<summary>핵심 용어</summary>

- **5G SA (5G Standalone)** : 5G New Radio 접속망을 5G Core에 연결하는 독립형 5G 시스템 배치 방식.
- **5G NSA (5G Non-Standalone)** : LTE와 5G NR을 함께 사용하는 5G 배치 방식. 구성 옵션에 따라 LTE 코어를 이용.
- **NR (New Radio)** : 3GPP가 정의한 5G 무선 접속 기술.
- **gNB (Next Generation Node B)** : 5G NR 기지국.
- **5GC (5G Core)** : 5G 시스템의 제어·사용자 평면 기능을 제공하는 코어망.
- **SBA (Service-Based Architecture)** : 5GC 네트워크 기능이 서비스 인터페이스를 통해 상호 작용하는 구조.
- **AMF (Access and Mobility Management Function)** : 접속·이동성 관리 기능.
- **SMF (Session Management Function)** : 세션 관리와 사용자 평면 자원 제어 기능.
- **UPF (User Plane Function)** : 사용자 데이터 패킷의 전달·처리 기능.
- **EPS Fallback (Evolved Packet System Fallback)** : 음성 서비스 연결을 위해 LTE/EPS로 전환하는 절차.

</details>

## 2~4교시 25점 답안

## Ⅰ. 5G 단독모드(5G SA)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 4G LTE 기지국과 EPC 코어망의 도움 없이 순수 5G 기지국(gNodeB)과 클라우드 네이티브 기반 5G 코어망(5GC)만으로 제어 평면과 사용자 평면을 독자 구축한 3GPP 표준 Option 2 구조 |
| 목적 | 4G 앵커링 오버헤드 제거, 엔드투엔드 진정한 1ms 초저지연(URLLC) 보장 및 기업 맞춤형 완전한 E2E 네트워크 슬라이싱 상용화 |

## Ⅱ. 5G 단독모드(5G SA)의 특징

| 특징 | 상세 내용 |
|---|---|
| 서비스 기반 아키텍처(SBA)| 코어망 기능(NF)들이 HTTP/2 기반 RESTful API로 상호 통신하는 클라우드 마이크로서비스 구조 |
| E2E 네트워크 슬라이싱 | 단일 물리 인프라 위에서 eMBB, URLLC, mMTC 전용의 독립적 가상 네트워크를 코어망까지 완벽 격리 |
| 제어/사용자 평면 분리(CUPS)| UPF(User Plane Function)를 데이터 소비 현장(MEC)으로 전진 배치하여 백홀 전송 지연 극소화 |
| 스마트폰 배터리 절감 | 4G/5G 듀얼 무선 연결(EN-DC)로 인한 전력 소모를 단일 5G 무선 링크로 전환하여 단말 수명 개선 |

## Ⅲ. 5G 단독모드(5G SA)의 체계·프로세스

**5G SA Option 2 아키텍처 및 5GC 서비스 기반 인터페이스(SBI)**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 5G SA (Option 2) 아키텍처 ]                   │
│                                                                        │
│   [ 5G 코어망 (5GC) : Service-Based Architecture ]                     │
│     ┌──────┐ Namf ┌──────┐ Nsmf ┌──────┐ Nudm ┌──────┐ Nnrf ┌──────┐   │
│     │ AMF  │◄────►│ SMF  │◄────►│ UDM  │◄────►│ PCF  │◄────►│ NRF  │   │
│     └──────┘      └──────┘      └──────┘      └──────┘      └──────┘   │
│        ▲             ▲                                                 │
│        │ N2 (제어)   │ N4                                              │
│        │             ▼                                                 │
│   [ 5G gNodeB ] ─────────────► [ UPF (User Plane) ] ──► 데이터 네트워크│
│        ▲              N3             │ (로컬 브레이크아웃) (인터넷/MEC)│
│        │ 5G-Uu 무선 인터페이스       ▼                                 │
│     [ 단말 (UE) ]              [ 온프레미스 사내망 ]                   │
└────────────────────────────────────────────────────────────────────────┘
```

| 5GC 핵심 기능 (NF) | 역할 및 동작 원리 |
|---|---|
| **AMF (Access & Mobility)** | 단말의 등록, 연결 상태 관리, 이동성 제어 (기존 MME의 제어 기능) |
| **SMF (Session Management)**| IP 주소 할당, 세션 수립/변경/해제 및 UPF 트래픽 스티어링 제어 |
| **UPF (User Plane Function)**| 패킷 라우팅 및 포워딩, QoS 집행, 외부 데이터망 연동 (기존 S/P-GW의 데이터 평면) |
| **UDM (Unified Data Mgmt)** | 가입자 인증 자격 증명(Credential) 보관 및 가입자 프로파일 관리 (기존 HSS) |
| **NRF (NF Repository)** | 코어망 내 마이크로서비스 NF들의 등록, 검색 및 동적 상태 관리 (Service Mesh Registry)|

## Ⅳ. 5G 단독모드(5G SA)의 종류·비교

| 비교 항목 | 5G NSA (Non-Standalone, Option 3x) | 5G SA (Standalone, Option 2) |
|---|---|---|
| **코어망 인프라** | 기존 4G 코어망 (EPC) 재활용 | **신규 5G 코어망 (5GC, Cloud-Native)** |
| **제어 평면 앵커** | 4G LTE 기지국 (eNodeB) 앵커링 필수 | **5G 기지국 (gNodeB) 단독 제어** |
| **네트워크 슬라이싱** | RAN 일부만 제한적 가상화 | **RAN + 전송망 + 5GC 완전한 E2E 슬라이싱** |
| **무선 단말 접속** | Dual Connectivity (LTE + 5G 동시 송수신)| **5G 단일 연결 (Single Carrier 전력 절감)** |
| **전송 지연 (RTT)** | 10 ~ 15 ms (LTE 코어 경유 병목) | **1 ~ 5 ms (초저지연 MEC 직결)** |
| **주요 서비스 타깃** | B2C 초고속 대용량 데이터 다운로드 | **B2B 스마트 팩토리, 자율주행, 원격 의료** |

## Ⅴ. 5G 단독모드(5G SA)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 5G 커버리지 미흡 지역에서 음성 통화 시 VoNR(Voice over NR) 단절 및 4G EPS 폴백(Fallback) 호 설정 지연 발생 | 초기 VoNR 안정화 전까지 빠른 EPS Fallback 최적화 및 5G NR 신호 감도 기반 사전 핸드오버 알고리즘 적용 |
| 5GC의 수많은 마이크로서비스 간 HTTP/2 API 호출 폭증으로 인한 코어망 내부 시그널링 오버헤드 및 메시 지연 | Istio 기반 서비스 메시(Service Mesh) 및 eBPF 기반 커널 인라인 네트워킹 가속화 도입 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
통신사 5G SA 전국망 전환 시, 망 전환 초기 가입자의 체감 통화 품질 저하를 방지하기 위해 음성 호는 지연이 1초 미만인 EPS Fallback(4G VoLTE 전환)을 기본 운용하고, 기지국 밀도가 완비된 특화망 및 대도시 중심부부터 점진적으로 순수 VoNR을 개통하는 2단계 전략 수립.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 5G SA 엔드투엔드 네트워크 슬라이싱 (E2E Slicing) 구조 ]             │
│                                                                        │
│   단말 (UE) ──► [ 무선망: 5G RAN ] ──► [ 전송망: IP/MPLS ] ──► [ 5GC ] │
│                                                                        │
│   [ 슬라이스 1 : 초고속 eMBB ]  5G 대용량 슬롯 ── FlexE 대역 ── AMF/UPF│
│   (초고화질 8K 미디어, VR)                                             │
│                                                                        │
│   [ 슬라이스 2 : 초저지연 URLLC ] 미니슬롯 우선 ── TSN 확정지연 ── 로컬MEC│
│   (스마트 팩토리 로봇, 자율주행)                                       │
│                                                                        │
│   [ 슬라이스 3 : 대규모 mMTC ]  스몰 패킷 슬롯 ── BE 패킷망 ── 경량코어│
│   (수만 개 스마트 검침기, 원격 센서)                                   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 슬라이스 식별자 (S-NSSAI) | SST (Slice/Service Type) | 보장 특성 | 대표 산업 |
|---|---|---|---|
| **eMBB** | SST 1 | 초대용량 대역폭 (수 Gbps) | 스마트폰 미디어, 메타버스 |
| **URLLC** | SST 2 | 무선 1ms 지연, 99.999% 무손실 | 협동 로봇, 무인 비행체, UAM |
| **MIoT (mMTC)** | SST 3 | 초저전력, 100만 기기/km^2 밀도 | 지자체 스마트시티, 환경 센서 |
| **V2X** | SST 4 | 이동성 예측 기반 초고속 핸드오버 | 자율주행 협조 제어 |
