## 연관 키워드

- 5G SA, 5GC, gNodeB, 3GPP Option 2, NSA, 네트워크 슬라이싱
- 서비스 기반 아키텍처(SBA), CUPS, AMF, SMF, UPF, NSSF, SCP
- URLLC, MEC, VoNR, EPS Fallback

## Ⅰ. 5G 단독모드 (5G SA)의 개요

- 핵심 요약 : 4G 코어에 기대지 않고 5G 무선망과 5G 코어만으로 전체 망을 운용하는 독립형 5G 아키텍처.
- 개념 : LTE(Long-Term Evolution) 인프라에 의존하지 않고, 5G 무선 접속망(gNodeB)과 클라우드 네이티브 기반 5G 코어망(5GC)만으로 제어 평면과 사용자 평면을 독립적으로 처리하는 **5G 단독모드** (5G SA, Standalone) 구조로, 3GPP Option 2에 해당함.
- 배경 및 필요성 : 초기 상용화된 5G 비단독모드(NSA, Non-Standalone, Option 3x)는 LTE 제어 평면을 공유하여 빠르게 구축할 수 있었으나, 5G 고유의 초저지연 URLLC(Ultra-Reliable Low-Latency Communications)와 진정한 **네트워크 슬라이싱** (Network Slicing) 제공에는 한계가 드러남.
- 주요 목적 : 종단 간(E2E, End-to-End) 네트워크 슬라이싱 구현, **서비스 기반 아키텍처** (SBA, Service-Based Architecture)로 신규 서비스의 신속한 배포, MEC(Multi-access Edge Computing) 연계, 단말 전력 효율 개선.

## Ⅱ. 5G 단독모드 (5G SA)의 특징 및 장점

- 핵심 요약 : 독립 코어, 모듈형 제어 구조, 평면 분리가 슬라이싱과 저지연, 서비스 신속 배포로 이어지는 구조.

1. 독립 코어 : 5GC가 등록과 세션을 단독으로 처리 → LTE 제어 오버헤드가 사라져 초저지연 스케줄링과 에지 연계가 가능.
2. API 기반 모듈형 제어 : 제어 기능들이 HTTP/2 기반 REST API로 호출하는 마이크로서비스 형태 → 기능 단위의 신규 배포와 장애 격리가 용이.
3. **CUPS** (Control and User Plane Separation) : 제어 평면(AMF, SMF)과 사용자 평면(UPF)을 분리 → 트래픽 집중에 따른 병목을 해소하고 UPF를 에지에 분산 배치.
4. E2E 슬라이스 격리 : 단말부터 무선과 코어까지 슬라이스를 격리 → 서비스별 품질과 보안 요구를 맞춘 맞춤형 망 제공.

## Ⅲ. 5G 단독모드 (5G SA)의 구조 (흐름)

- 핵심 요약 : 서비스 기반 제어 평면이 N4로 사용자 평면을 제어하며, 단말(UE, User Equipment)은 gNB를 거쳐 5GC에 등록한 뒤 UPF를 통해 데이터망과 통신하는 구조.

```text
[ 제어 평면 : 서비스 기반 구조 ]
  NRF · AMF · SMF · PCF · UDM
      ↓ N4 (SMF와 UPF 제어 연결)
[ 사용자 평면 ]
  UE ── gNB ── UPF ── 데이터망
             N3 (GTP-U)  N6 (인터넷, MEC)
```

- **AMF** (Access and Mobility Management Function) : 무선 접속과 단말 이동성 관리를 전담하며, 4G MME의 역할을 분리한 기능.
- **SMF** (Session Management Function) : PDU 세션의 생성·수정·해제와 단말 IP 할당을 제어.
- **UPF** (User Plane Function) : 고속 패킷 라우팅과 포워딩, QoS 집행, 외부 데이터망 연동을 담당.
- **NSSF** (Network Slice Selection Function) : 단말이 요청한 서비스에 맞는 네트워크 슬라이스 인스턴스를 선택.
- PCF(Policy Control Function)와 UDM(Unified Data Management)은 정책 제어와 가입자 데이터 관리를 맡는 제어 기능임.
- 등록과 세션 : 단말은 gNB를 거쳐 AMF에 바로 등록하고, SMF와 UPF 사이의 N4 인터페이스로 PDU 세션을 수립하여 순수 5G 경로로 통신함.

## Ⅳ. 5G 단독모드 (5G SA)의 비교

- 핵심 요약 : NSA는 LTE 코어를 공유해 빠르게 구축하는 방식이고, SA는 5G 코어로 슬라이싱과 저지연을 완성하는 방식.

| 비교 항목 | 5G NSA (Option 3x) | 5G SA (Option 2) |
| --- | --- | --- |
| 코어 네트워크 | 기존 4G EPC(Evolved Packet Core, MME, S-GW, P-GW) | 순수 5G 코어망 (5GC: AMF, SMF, UPF) |
| 기지국 구성 | eNodeB(LTE 앵커 기지국) + gNodeB | gNodeB 단독 운용 |
| 제어 평면 처리 | LTE eNodeB와 MME가 주로 담당 | gNodeB와 AMF가 직접 처리 |
| 네트워크 슬라이싱 | 무선 구간 일부만 가능, 코어망 미지원 | E2E(단말-무선-코어) 격리 슬라이싱 지원 |
| 초저지연 (URLLC) | LTE 제어 오버헤드로 개선 폭 제한 | 순수 5G 스케줄링과 에지 UPF 연계로 목표 달성 가능 |
| 음성 서비스 | 기존 VoLTE(Voice over LTE) 활용 | VoNR(Voice over New Radio) 또는 EPS(Evolved Packet System) Fallback |

- 선택 기준 : 구축 초기에 커버리지를 빠르게 넓히는 단계는 NSA가 유리하고, 슬라이싱과 신규 저지연 서비스를 제공하려면 SA로 전환해야 함.

## Ⅴ. 5G 단독모드 (5G SA)의 한계와 방안

- 핵심 요약 : 고주파 음영과 SBA 시그널링 부하를 EPS Fallback, 핸드오버 최적화, SCP 기반 라우팅으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 초기 5G 커버리지 음영 | 고주파(3.5GHz, 28GHz) 전파 특성상 건물 내부와 교외에서 공백이 생겨 VoNR 통화가 끊김 | 음영 지역에서 LTE 망으로 신속히 절체하는 EPS Fallback 적용, 5G-LTE 간 핸드오버 최적화 | 음영 구간 접속 실패율 |
| SBA 전환에 따른 시그널링 부하 | NF 사이의 HTTP/2 REST API 호출이 늘어 제어 평면 지연과 코어 라우팅 복잡도 증가 | SCP(Service Communication Proxy)로 메시지 라우팅과 로드 밸런싱을 집약하고, NRF(Network Repository Function) 기반 동적 서비스 탐색 고도화 | 제어 평면 호출 지연 |

## Ⅵ. 5G 단독모드 (5G SA)에 대한 기술사적 제언

- 핵심 요약 : 5G SA는 특화망과 클라우드 네이티브 운영을 중심으로 확산시키고, 슬라이스 보안을 설계 단계에서 포함하는 것이 바람직함.
- 스마트팩토리, 자율주행, 원격의료처럼 저지연과 보안 격리가 필수적인 산업 현장에는 이음5G 같은 특화망 형태로 5G SA 기반 프라이빗 인프라를 먼저 적용하는 것이 효과적임.
- 5GC의 네트워크 기능을 CNF(Cloud-native Network Function)와 쿠버네티스 환경으로 표준화하면, 장애 자동 복구와 수요 기반 자동 확장을 함께 확보할 수 있음.
- 슬라이스 사이의 트래픽 침범을 막기 위해 제로 트러스트 원칙을 적용하고, 하이퍼바이저와 컨테이너 수준의 격리 통제를 엄격히 설계해야 함.

## Ⅶ. 결론

- 핵심 요약 : 5G SA는 독립 코어와 서비스 기반 구조로 5G 고유의 슬라이싱과 저지연을 실현하는 완성형 5G 아키텍처임.
- 시사점 : 망 구축 속도보다 슬라이스 운영과 보안 체계가 서비스 가치를 좌우하므로, 도입 시 기술 전환과 운영 체계를 함께 설계하는 것이 타당함.
