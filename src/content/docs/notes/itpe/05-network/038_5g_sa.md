## Ⅰ. 5G 단독모드 (5G SA)의 개요

- 개념 : 기존 LTE(4G) 인프라에 의존하지 않고, 5G 신규 무선 접속망(gNodeB)과 **클라우드 네이티브** 기반 5G 코어망(5GC)만으로 무선 및 제어/사용자 평면을 전적으로 독립 처리하는 **이동통신 아키텍처** (3GPP Option 2).
- 배경 및 필요성 : 초기 상용화된 5G 비단독모드(NSA, Option 3x)는 빠른 망 구축이 가능했으나, LTE 제어 평면 공유로 인한 5G 고유의 초저지연(URLLC) 및 진정한 **네트워크 슬라이싱(Network Slicing)** 제공 한계 노출.
- 핵심 목적 : 엔드투엔드(E2E) 네트워크 슬라이싱 구현, **서비스 기반 아키텍처(SBA)** 기반의 신속한 신규 서비스 배포, **MEC(모바일 에지 컴퓨팅)** 최적 연계 및 단말 배터리 수명 극대화.

## Ⅱ. 5G SA의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│                    [ 5G SA (Option 2) E2E 아키텍처 ]                    │
│                                                                        │
│   [ 제어 평면 (Control Plane) : HTTP/2 Service-Based Architecture ]    │
│   ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐  │
│   │  NRF   │    │  AMF   │    │  SMF   │    │  PCF   │    │  UDM   │  │
│   └────┬───┘    └───┬────┘    └───┬────┘    └───┬────┘    └───┬────┘  │
│        └────────────┴─────────────┴─────────────┴─────────────┘        │
│                                   │                                    │
│   [ 사용자 평면 (User Plane) ]     │ N4                                 │
│   ┌────────┐    N1/N2         ┌───┴────┐        N6       ┌─────────┐  │
│   │   UE   ├──────────────────┤  gNB   ├─────────────────┤ DataNet │  │
│   │ (단말) │   N3 (GTP-U)     │ (5G SA)│    ┌───────┐    │ (인터넷)│  │
│   └────────┘                  └────────┘───►│  UPF  ├────┤ /MEC    │  │
│                                             └───────┘    └─────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

- **SBA (Service-Based Architecture)** : 제어 평면의 네트워크 기능(NF)들이 RESTful API(HTTP/2, JSON)를 통해 상호 호출 및 상태를 공유하며 마이크로서비스 형태로 동작.
- **CUPS (Control and User Plane Separation)** : 제어 평면(AMF/SMF)과 사용자 평면(UPF)을 완전 분리하여 트래픽 집중에 따른 병목 해소 및 UPF의 초근접 에지 분산 배치 지원.
- **독립적 등록 및 PDU 세션 수립** : 단말(UE)은 gNodeB를 통해 AMF로 바로 등록(Registration)하고 SMF/UPF 간 N4 인터페이스로 PDU 세션을 확립하여 순수 5G 경로 통신 수행.

## Ⅲ. 5G SA의 세부 구성 요소 및 NSA(Option 3x)와의 비교 분석

| 비교 항목 | 5G NSA (Option 3x) | 5G SA (Option 2) |
|---|---|---|
| 코어 네트워크 | 기존 4G EPC (MME, S-GW, P-GW) | 순수 5G 코어망 (5GC: AMF, SMF, UPF) |
| 기지국 구성 | eNodeB(Anchor 기지국) + gNodeB | 순수 gNodeB 단독 운용 |
| 제어 평면 처리 | LTE eNodeB 및 EPC(MME)가 전담 | 5G gNodeB 및 5GC(AMF)가 직접 처리 |
| **네트워크 슬라이싱** | 무선 구간 일부만 가능, 코어망 미지원 | E2E(단말-무선-코어) 완전 격리 슬라이싱 지원 |
| **초저지연(URLLC)** | LTE 제어 오버헤드로 인한 지연 (15~20ms) | 순수 5G 스케줄링 및 에지 UPF 연계 (1ms급) |
| 음성 서비스 | 기존 VoLTE 직접 활용 | VoNR (Voice over New Radio) 또는 EPS Fallback |

- **AMF (Access and Mobility Management Function)** : 무선 접속 및 단말 이동성 관리 전담 (4G MME 역할 분리).
- **SMF (Session Management Function)** : PDU 세션 생성, 수정, 해제 및 단말 IP 할당 제어.
- **UPF (User Plane Function)** : 고속 패킷 라우팅 및 포워딩, QoS 집행, 외부 데이터망(DN) 연동.
- **NSSF (Network Slice Selection Function)** : 단말의 요청 서비스에 적합한 네트워크 슬라이스 인스턴스 선택.

## Ⅳ. 5G SA의 주요 한계점 및 해결 방안

- 초기 5G 커버리지 음영에 따른 접속 단절 및 통화 품질 저하 :
  - 한계점 : 고주파(3.5GHz, 28GHz) 전파 특성상 건물 내부 및 교외 지역 커버리지 공백 시 VoNR 통화 끊김 발생.
  - 해결 방안 : 커버리지 미흡 지역 진입 시 신속히 LTE 망으로 절체하는 EPS Fallback 메커니즘 적용 및 5G-LTE 간 핸드오버 프로토콜 최적화.
- SBA 마이크로서비스 전환에 따른 시그널링 오버헤드 :
  - 한계점 : 수많은 NF 간 HTTP/2 REST API 호출 증가로 제어 평면 통신 지연 및 코어 라우팅 복잡도 급증.
  - 해결 방안 : SCP(Service Communication Proxy) 도입을 통한 메시지 라우팅, 로드밸런싱, 트래픽 집약 및 NRF 기반 동적 서비스 디스커버리 체계 고도화.

## Ⅴ. 5G SA 적용 및 발전을 위한 기술사적 제언

- 특화망(이음5G) 중심의 B2B 버티컬 산업 확산 : 스마트팩토리, 자율주행, 원격의료 등 초저지연 및 보안 격리가 필수적인 산업 현장에 5G SA 기반 프라이빗 5G 인프라 우선 적용.
- 클라우드 네이티브 텔코 플랫폼 구축 : 5GC NF들을 컨테이너(CNF) 및 쿠버네티스 오케스트레이션 환경으로 표준화하여 장애 자동 복구(Self-Healing) 및 수요 기반 탄력적 오토스케일링 확보.
- E2E 네트워크 슬라이싱 보안 정책 강화 : 슬라이스 간 트래픽 침범을 방지하는 Zero Trust 아키텍처 및 하이퍼바이저/컨테이너 레벨 격리 제어 기법을 엄격히 적용.
