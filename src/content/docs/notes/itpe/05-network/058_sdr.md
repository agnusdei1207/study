## 연관 키워드

- SDR(Software Defined Radio), 인지 무선(Cognitive Radio), 스펙트럼 센싱
- ASIC(Application-Specific Integrated Circuit), FPGA(Field-Programmable Gate Array), DSP(Digital Signal Processor)
- ADC(Analog-to-Digital Converter), DAC(Digital-to-Analog Converter), DDC/DUC(Digital Down/Up Converter)
- COTS(Commercial Off-The-Shelf), O-RAN(Open Radio Access Network), vRAN, TCO(Total Cost of Ownership)

## Ⅰ. SDR의 개요

- 핵심 요약 : 무선 신호 처리를 고정 회로 대신 소프트웨어로 구현해 표준 대응을 하드웨어 교체가 아닌 소프트웨어 갱신으로 바꾸는 기술.
- 개념 : 믹서, 필터, 변복조기 같은 무선 기능을 전용 칩이 아닌 범용 프로세서 위의 소프트웨어로 구현하는 **소프트웨어 정의 라디오** (SDR, Software Defined Radio).
- 배경 및 필요성 : 4G·5G·Wi-Fi·위성 등 무선 표준이 계속 추가되는데 전용 회로 기반 무선기는 표준 하나가 늘 때마다 하드웨어를 재설계해야 하는 비용과 경직성이 존재.
- 주요 목적 : 소프트웨어 갱신만으로 다중 표준 수용, 기지국 하드웨어의 범용화를 통한 총소유비용 절감, 인지 무선으로의 진화 기반 마련.

## Ⅱ. SDR의 특징 및 장점

- 핵심 요약 : 디지털 변환 지점을 안테나 가까이 두고 처리를 소프트웨어로 이전해 유연성과 자원 효율을 함께 확보하는 구조.

1. 다중 표준 지원 : 대역·변조 방식·프로토콜 스택을 소프트웨어 파라미터로 전환 → 한 장비에서 복수 표준 수용으로 장비 종류와 재고 감소.
2. 광대역 디지털 튜닝 : 광대역 RF(Radio Frequency) 전단부와 고속 변환기로 넓은 대역을 디지털 영역에서 선택 → 주파수 변경을 회로 재설계 없이 처리.
3. 신속한 기능 갱신 : 알고리즘 수정과 펌웨어 배포만으로 기능 변경 → 개발 주기 단축과 신기술 적용 속도 향상.
4. 범용 하드웨어 활용 : **범용 상용 제품**(COTS, Commercial Off-The-Shelf) 서버에서 신호 처리 수행 → 특정 벤더 종속 완화와 도입 비용 절감.
5. 인지 무선 확장 기반 : 스펙트럼 센싱과 정책 엔진을 소프트웨어로 결합 → 주파수 환경을 스스로 인지해 유휴 대역을 활용하는 **인지 무선**(Cognitive Radio)으로 진화 가능.

## Ⅲ. SDR의 구조 (흐름)

- 핵심 요약 : 아날로그 RF 전단부에서 디지털 샘플로 바뀐 신호를 고속 계층과 유연 계층이 나누어 담당하는 계층 구조.
- ADC/DAC : **아날로그-디지털 변환기**(ADC, Analog-to-Digital Converter)와 **디지털-아날로그 변환기**(DAC, Digital-to-Analog Converter)가 상호 변환을 수행하며, 디지털화 지점이 SDR의 구현 범위를 결정.
- DDC/DUC : **DDC/DUC**(Digital Down/Up Converter)가 수치 제어 발진기와 디지털 필터로 주파수 천이와 샘플률 변환을 수행.
- FPGA/DSP : **FPGA**(Field-Programmable Gate Array)와 **DSP**(Digital Signal Processor)가 샘플 처리·채널화·동기화 같은 고속 계층을 담당.
- 범용 프로세서 : CPU(Central Processing Unit)와 GPU(Graphics Processing Unit)가 변복조·부호화·프로토콜 스택 같은 상위 기능을 담당.

```text
안테나
    ↓
RF 전단부 (증폭 · 혼합 · 필터)
    ↓
ADC / DAC (디지털 샘플화)
    ↓
FPGA / DSP (고속 신호 처리)
    ↓
범용 CPU/GPU (변복조 · 프로토콜)
```

```text
[ 처리 계층의 역할 분담 ]

고속 계층 : FPGA / DSP
  샘플 처리 · 채널화 · 타이밍
    ↓ 처리 결과 전달
유연 계층 : 범용 프로세서
  프로토콜 스택 · 알고리즘 갱신
```

## Ⅳ. 전통 무선 하드웨어와 SDR의 비교

- 핵심 요약 : 전용 회로는 효율과 단가에서, SDR은 표준 대응 속도와 다중 대역 수용에서 우위를 보이므로 용도와 수명 주기에 따라 선택.

| 비교 축 | 전통 무선 하드웨어 | SDR |
| --- | --- | --- |
| 기능 구현 | 고정 ASIC(Application-Specific Integrated Circuit)과 아날로그 회로 | 범용 프로세서(FPGA, DSP, CPU)의 소프트웨어 |
| 표준 변경 대응 | 보드 재설계와 장비 교체 | 알고리즘 수정과 펌웨어 배포 |
| 다중 대역 수용 | 협대역 전용 회로로 제한 | 광대역 전단부와 디지털 튜닝 |
| 개발 주기 | 칩 설계와 양산에 장기간 소요 | 코드 수정과 재컴파일로 단축 |
| 전력 효율 | 전용화로 유리 | 범용 처리 오버헤드로 불리 |
| 단위 원가 | 대량 생산 시 저렴 | 고성능 변환기와 프로세서로 높음 |

- 선택 기준 : 기능이 고정되고 양산 규모가 큰 단말은 전용 회로, 표준 대응과 기능 확장이 잦은 기지국·군용·실험 플랫폼은 SDR이 유리.
- 트레이드오프 판단 : 유연성 확보의 대가가 전력 소모와 단가 상승이므로, 장비 수명 주기의 총소유비용(TCO, Total Cost of Ownership) 관점에서 판단.

## Ⅴ. SDR의 한계와 방안

- 핵심 요약 : 고속 변환기 성능 한계와 범용 프로세서의 실시간성 부족이 핵심 제약이며, 변환 기법 개선과 실시간 처리 기술로 일대일 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고속 변환기 성능 한계 | 광대역 고주파 신호의 왜곡 없는 디지털화가 어렵고 양자화 잡음과 전력 소모 증가 | 대역통과 샘플링, RF 직접 샘플링 칩(RFSoC, Radio Frequency System-on-Chip) 채택 | 신호 대 잡음비, 변환 단계 전력 |
| 실시간성 부족 | 범용 OS의 비결정적 스케줄링과 인터럽트 지연으로 짧은 무선 프레임 타이밍 위협 | 실시간 커널 패치(PREEMPT_RT), 커널 우회(DPDK(Data Plane Development Kit)), 하드웨어 가속 | 지연 지터, 프레임 처리 성공률 |

## Ⅵ. SDR 적용 확산을 위한 기술사적 제언

- 핵심 요약 : 개방형 무선망 전환, 국방 무전기 통합, 물리 계층 AI 연구 인프라 구축으로 SDR 생태계를 넓히는 것.

1. 통신 사업자는 O-RAN(Open Radio Access Network) 구조와 vRAN(Virtualized Radio Access Network) 도입으로 COTS 서버에서 무선 처리 소프트웨어를 운영하는 방향의 전환 근거를 마련해야 한다.
2. 국방 기관은 기종별 전술 무전기를 SDR 단일 플랫폼으로 통합해, 합동 작전에서 파형 소프트웨어 교체만으로 상호운용을 확보하는 체계로 전환해야 한다.
3. 연구기관과 장비 업체는 채널 추정과 복조를 신경망으로 대체하는 뉴럴 리시버 연구를 공동 수행하고, 실측 검증이 가능한 공개 실험 환경을 구축해야 한다.

## Ⅶ. 결론

- 핵심 요약 : SDR은 무선 기능을 소프트웨어로 이전해 표준 변화를 흡수하는 무선기 패러다임.
- 성능 한계는 변환기와 실시간 처리 기술의 발전으로 완화되는 중이며, 개방형 표준과 생태계가 확산 속도를 결정한다.
