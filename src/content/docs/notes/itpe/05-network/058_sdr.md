## 연관 키워드

- SDR(Software Defined Radio), 인지 무선(Cognitive Radio), 주파수 스펙트럼 센싱
- FPGA(Field-Programmable Gate Array), DSP(Digital Signal Processor), GPP(General Purpose Processor)
- ADC(Analog-to-Digital Converter), DAC(Digital-to-Analog Converter), DDC/DUC, RFSoC
- O-RAN(Open Radio Access Network), vRAN, COTS(Commercial Off-The-Shelf), TCO(Total Cost of Ownership)
- DPDK(Data Plane Development Kit), PREEMPT_RT, 뉴럴 리시버(Neural Receiver)

## Ⅰ. SDR(Software Defined Radio)의 개요

- 핵심 요약 : 무선 신호 처리 기능을 고정 회로 대신 소프트웨어로 구현해, 표준 변경을 하드웨어 교체가 아닌 소프트웨어 작업으로 바꾸는 기술.
- 개념 : 믹서, 필터, 변복조기 같은 기능을 고정 회로(ASIC, Application-Specific Integrated Circuit) 대신 FPGA(Field-Programmable Gate Array), DSP(Digital Signal Processor), CPU(Central Processing Unit)/GPU(Graphics Processing Unit) 위의 소프트웨어로 구현하는 **소프트웨어 정의 라디오** (SDR, Software Defined Radio).
- 배경 및 필요성 : 4G, 5G, Wi-Fi, 위성 등 다양한 무선 표준이 공존하고 새 표준이 나올 때마다 하드웨어를 전면 재설계해야 하는 비용과 경직성 문제.
- 주요 목적 : 소프트웨어 업데이트로 **다중 표준** 지원, 기지국 하드웨어의 범용화를 통한 **총소유비용** (TCO, Total Cost of Ownership) 절감, 인지 무선으로 진화할 기반 제공.

## Ⅱ. SDR의 특징 및 장점

- 핵심 요약 : 디지털 변환 지점을 안테나 가까이 옮기고 처리를 소프트웨어로 넘겨, 유연성과 확장성을 함께 확보하는 구조.

1. 다중 표준 지원 : 대역과 변조 방식을 소프트웨어로 바꿔 한 장비에서 여러 표준을 수용 → 장비 종류와 재고 감소.
2. 광대역 디지털 튜닝 : 광대역 무선 주파수(RF, Radio Frequency) 전단부와 고속 변환기로 넓은 대역을 디지털 영역에서 선택 → 주파수 변경을 회로 재설계 없이 처리.
3. 빠른 기능 갱신 : 알고리즘 수정과 펌웨어 배포만으로 기능을 바꿈 → 개발 주기 단축과 신규 기능 적용 속도 향상.
4. 범용 하드웨어 활용 : COTS(Commercial Off-The-Shelf, 상용 범용 제품) 서버와 GPU에서 신호 처리를 수행 → 특정 벤더 종속 완화와 장비 비용 절감 가능.

## Ⅲ. SDR의 구조 (흐름)

- 핵심 요약 : 아날로그 RF 전단부에서 디지털 IQ 샘플로 바뀐 신호를 FPGA·DSP가 고속 처리하고, 범용 프로세서가 상위 기능을 담당하는 계층 구조.
- 저잡음 증폭기(LNA, Low Noise Amplifier)가 수신 신호를 증폭하고, 믹서가 기저대역 또는 중간 주파수로 내린 뒤 필터가 잡음을 제거.
- **아날로그-디지털 변환기** (ADC, Analog-to-Digital Converter)와 **디지털-아날로그 변환기** (DAC, Digital-to-Analog Converter)가 신호를 디지털 샘플로 바꾸거나 되돌림.
- **DDC/DUC** (Digital Down/Up Converter) : 수치 제어 발진기와 디지털 필터로 주파수 천이와 데시메이션을 수행.

```text
안테나
        ↓
RF 전단부 (증폭 · 혼합 · 필터)
        ↓
ADC / DAC (디지털 IQ 샘플)
        ↓
FPGA / DSP (DDC · DUC · 동기화)
        ↓
범용 CPU/GPU: 변복조 · 코딩 · 프로토콜
```

```text
[ 고속 · 병렬 계층 ] FPGA/DSP
  샘플 처리, 채널화, 동기화
        ↓
[ 유연 계층 ] GPP(CPU/GPU)
  프로토콜 스택, AI 추론
```

## Ⅳ. 하드웨어 무선기와 SDR의 비교

- 핵심 요약 : 하드웨어 무선기는 특정 기능의 효율과 대량 원가에서 강점이 있고, SDR은 표준 변경 속도와 다중 대역 수용에서 강점이 있음.

| 비교 축 | 전통적 무선 하드웨어 | 소프트웨어 정의 라디오 (SDR) |
| --- | --- | --- |
| 기능 구현 | 고정 ASIC과 아날로그 믹서, 필터 | 범용 프로세서(FPGA, DSP, 범용 CPU·GPU) 소프트웨어 |
| 표준 변경 | 보드 재설계와 교체 | 알고리즘 수정과 펌웨어 다운로드 |
| 다중 대역 수용 | 협대역 전용 회로로 한정 | 광대역 RF 전단부와 디지털 튜닝으로 수용 |
| 개발 주기 | 칩 설계와 양산에 긴 기간 소요 | 코드 수정과 재컴파일로 짧음 |
| 전력 소모 | 전용화로 효율이 높음 | 범용 처리 오버헤드로 상대적으로 큼 |
| 단위 원가 | 대량 생산 시 매우 저렴 | 고성능 변환기와 프로세서로 단가가 높음 |

- **인지 무선** (Cognitive Radio) : SDR 플랫폼에 스펙트럼 센싱 엔진을 결합해 유휴 주파수 대역(White Space)을 찾아 간섭 없이 통신하는 기술.

## Ⅴ. SDR의 한계와 방안

- 핵심 요약 : 고속 변환기의 성능 한계와 범용 CPU의 실시간성 부족이 핵심 제약이며, 변환 방식 개선과 실시간 처리 기술로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고속 ADC/DAC의 샘플링 속도와 분해능 한계 | 광대역 고주파 신호를 왜곡 없이 디지털화하기 어렵고 양자화 잡음과 전력 소모가 커짐 | 대역통과 샘플링, 압축 센싱, RFSoC(RF-Sampling System-on-Chip) 채택 | 신호 대 잡음비, 샘플링 대역 대비 전력 |
| 범용 CPU의 실시간성 부족 | 범용 OS의 비결정적 스케줄링과 인터럽트 지연으로 5G NR(New Radio)의 짧은 슬롯 타이밍을 맞추기 어려움 | 실시간 커널(PREEMPT_RT), 커널 우회(DPDK(Data Plane Development Kit)), GPU 가속 | 지연 지터, 슬롯 처리 성공률 |

## Ⅵ. SDR 적용 및 발전을 위한 기술사적 제언

- 핵심 요약 : O-RAN 기반 COTS 무선 처리 전환, 국방 전술 무전기의 SDR 단일 플랫폼화, 뉴럴 리시버의 공동 연구로 개방성과 성능을 높이는 것.

1. 통신사는 O-RAN(Open Radio Access Network) 기반의 가상화 무선 접속망(vRAN, Virtualized Radio Access Network)을 도입하며 COTS 서버에 무선 처리 소프트웨어를 올리는 방향을 택해야, 특정 벤더 장비에 묶이는 구조를 피할 수 있다.
2. 국방 기관은 기종별로 나뉜 전술 무전기를 SDR 플랫폼 하나로 묶는 전환을 검토해, 합동 작전 시 무선 장비 간 상호운용 문제를 줄여야 한다.
3. 연구 기관과 장비 업체는 채널 추정과 복조를 신경망으로 대체하는 뉴럴 리시버 연구를 공동으로 진행해, 물리 계층 성능을 실험으로 검증할 수 있는 환경을 마련해야 한다.

## Ⅶ. 결론

- 핵심 요약 : SDR은 무선 기능을 소프트웨어로 옮겨 다중 표준과 기능 변화를 하드웨어 교체 없이 수용하는 기술.
- 시사점 : 성능 한계는 고속 변환기와 실시간 처리 기술의 발전에 달려 있으며, 개방형 생태계가 그 확산을 좌우한다.
