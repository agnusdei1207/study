네트워크 → 무선통신 장비 및 개방형 기지국 → **SDR(Software Defined Radio)**

## 30초 인출

- 본질: **SDR(Software Defined Radio)** : 하드웨어 교체 없이 소프트웨어의 동적 재구성(Reconfiguration)만으로 주파수 대역, 변복조 방식, 무선 통신 규격을 자유롭게 변경·운용하는 개방형 무선 통신 시스템
- 메커니즘: 광대역 RF 프런트엔드와 고속 ADC/DAC를 통해 변환된 디지털 I/Q 샘플을 FPGA, DSP, 범용 프로세서(GPP) 상의 소프트웨어 파형(Waveform) 엔진으로 실시간 고속 신호 처리
- 통찰: 파형의 유연한 업그레이드 이점 이면에 고속 샘플링에 따른 연산 지연 및 전력 소모 한계 극복을 위해 물리 계층 하드웨어 가속(FPGA/GPU)과 상위 프로토콜 소프트웨어 분담 체계 구축 필수

<details>
<summary>핵심 용어</summary>

- **RF 프런트엔드 (RFFE)** : 안테나로부터 수신된 고주파 RF 신호를 저잡음 증폭(LNA)하고 중간 주파수(IF) 또는 기저대역으로 주파수 하향 변환하는 아날로그 회로
- **ADC / DAC** : 아날로그 RF/IF 신호와 디지털 I/Q 베이스밴드 샘플 데이터 간을 고속 표본화 및 양자화하는 핵심 변환 소자
- **DDC / DUC** : 디지털 영역에서 주파수를 천이하고 표본화율을 낮추거나(Decimation) 높이는(Interpolation) 디지털 하향/상향 변환기
- **SCA (Software Communications Architecture)** : 파형(Waveform) 응용 소프트웨어의 이식성, 재사용성, 상호운용성을 보장하는 군사 및 개방형 SDR 표준 아키텍처
- **vRAN / O-RAN** : 통신사 기지국의 베이스밴드 처리 기능(CU/DU)을 범용 COTS x86 서버 상의 소프트웨어 SDR 기술로 가상화한 개방형 무선 접속망

</details>

## 2~4교시 25점 답안

## Ⅰ. SDR의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 전통적인 하드웨어 고정형 회로(ASIC) 대신 재구성 가능한 디지털 하드웨어(FPGA/DSP) 및 범용 프로세서(GPP) 상의 소프트웨어 프로그래밍으로 변복조, 필터링, 프로토콜 처리를 수행하는 무선 시스템 |
| 목적 | 단일 통신 장비에서 다중 무선 표준(5G, LTE, Wi-Fi, 위성)을 수용하고, 물리적 기기 교체 없는 원격 소프트웨어 패치 기반 기능 진화 지원 |

## Ⅱ. SDR의 특징 및 핵심 계층 구조

| 구성 계층 | 세부 구성 요소 | 주요 역할 및 특징 |
|---|---|---|
| **RF 아날로그 계층** | 안테나, 광대역 필터, LNA(저잡음 증폭기), PA(전력 증폭기) | 다중 대역(Multi-band) RF 신호 송수신, 아날로그 신호 필터링 및 전력 증폭 |
| **데이터 변환 계층** | 고속 ADC (수 GSPS), 고속 DAC, 클록 분주기 | RF/IF 아날로그 신호와 디지털 I/Q 데이터 간의 초고속 표본화 및 역변환 |
| **디지털 IF/기저대역** | FPGA, DSP, 전용 가속 ASIC (DDC/DUC 내장) | 고속 디지털 필터링, 고속 푸리에 변환(FFT), 채널 추정, 등화기, LDPC/터보 채널 코딩 |
| **소프트웨어 파형 계층**| GPP(x86/ARM), 실시간 OS(RTOS), SCA 미들웨어 | MAC/네트워크 계층 프로토콜 스택 처리, 세션 관리, 무선 자원 스케줄링 |

## Ⅲ. SDR 신호 처리 아키텍처 및 하드웨어/소프트웨어 파이프라인

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ SDR 송수신 신호 처리 파이프라인 ]                  │
│                                                                        │
│   [수신 경로 (Rx)]                                                     │
│   Antenna ──► [RF Front-End] ──► [고속 ADC] ──► [FPGA: DDC & FFT] ──┐   │
│               (광대역 LNA/믹서)   (디지털 변환)  (채널 필터링/복조)   │   │
│                                                                      ▼   │
│   [송신 경로 (Tx)]                                             [PCIe/광] │
│   Antenna ◄── [RF Front-End] ◄── [고속 DAC] ◄── [FPGA: DUC & IFFT] ◄┤   │
│               (광대역 PA/믹서)    (아날로그 변환)(채널 변조/업샘플)   │   │
│                                                                      ▼   │
│                                                     ┌──────────────────┐ │
│                                                     │ COTS x86 / GPP   │ │
│                                                     │ (파형 SW & MAC)   │ │
│                                                     │ - SCA 미들웨어   │ │
│                                                     │ - L2/L3 프로토콜 │ │
│                                                     └──────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

| 파이프라인 단계 | 처리 하드웨어 | 수행 작업 명세 |
|---|---|---|
| **RF 송수신 및 변환** | RFFE 및 ADC/DAC | 기가헤르츠(GHz) 전파를 수신하여 나이퀴스트 표본화율 이상의 속도로 샘플링 |
| **디지털 하향/상향 변환**| FPGA (하드웨어) | Numerically Controlled Oscillator(NCO)와 결합하여 관심 대역을 기저대역으로 천이 및 데시메이션 |
| **물리 계층(PHY) 연산** | FPGA / GPU 가속기 | 대규모 행렬 연산이 필요한 MIMO 채널 추정, FFT/IFFT, 순방향 오류 정정(LDPC/Polar) 수행 |
| **상위 프로토콜 처리** | GPP (CPU) | Linux RT 커널 상에서 패킷 캡슐화, QoS 스케줄링, 무선 링크 제어(RLC/PDCP) 실행 |

## Ⅳ. 전통적 하드웨어 무선기 vs SDR vs CR(Cognitive Radio) 비교

| 비교 항목 | 전통적 하드웨어 무선기 (Hardware Radio) | SDR (Software Defined Radio) | CR (Cognitive Radio: 인지 무선) |
|---|---|---|---|
| **기능 구현 방식** | 고정형 아날로그 회로 및 ASIC 칩셋 | 재구성 가능한 FPGA/DSP 및 소프트웨어 | SDR 기반 + AI/학습 기반 주파수 인지 엔진 |
| **주파수/파형 변경** | 장비 교체 또는 기판 재설계 필수 | 소프트웨어 코드 교체 및 파라미터 재설정 | 주변 전파 환경을 실시간 감지하여 자동 전환 |
| **하드웨어 유연성** | 유연성 전무 (단일 표준 전용) | 매우 높음 (다중 표준 지원 가능) | 최고 수준 (환경 적응형 자율 통신) |
| **전력 소모 및 단가** | 대량 양산 시 단가 저렴, 저전력 | 범용 연산 소자 채택으로 전력 소모 및 단가 높음 | 신호 센싱 및 AI 연산으로 전력 소모 극대화 |
| **주요 적용 분야** | 저가형 AM/FM 라디오, 단순 센서 단말 | 5G O-RAN 기지국, 군용 다대역 전술 무전기 | 주파수 공유(LSA/CBRS), 차세대 전파 센싱망 |

## Ⅴ. SDR 구현 시의 핵심 엔지니어링 한계와 방안

| 한계 | 방안 |
|---|---|
| 샘플링 주파수($f_s$)를 광대역으로 상향할수록 ADC의 열잡음 및 클록 지터(Clock Jitter)로 인해 유효 비트 수(ENOB)가 급감하고 양자화 잡음(SNR 저하) 심화 | 아날로그 대역통과 필터와 믹서를 전단에 배치하여 관심 대역만을 선택 표본화하는 IF 서브샘플링(Bandpass Sampling) 기법을 적용하고 저지터 초정밀 VCXO 클록 발진기 실장 |
| 범용 프로세서(GPP) 기반 소프트웨어 처리 시 리눅스 커널의 인터럽트 지연 및 메모리 복사 오버헤드로 인해 5G NR TDD 규격의 서브 밀리초(sub-ms) HARQ 타이밍 마감 실패 | 커널 우회 기술(DPDK: Data Plane Development Kit)을 적용하여 제로 카피(Zero-copy) 패킷 처리를 구현하고, 초고속 PHY 계층 연산은 FPGA 또는 GPU(NVIDIA Aerial 등)에 전담 오프로딩 |
| FPGA와 고성능 GPP가 동시 구동됨에 따라 발열량이 급증하고 전력 소모가 기존 ASIC 전용 기지국 대비 2~3배 증가하여 이동체나 오지 기지국 탑재 제약 | 송수신 데이터 유무에 따라 클록 주파수를 동적으로 차단하는 클록 게이팅(Clock Gating) 기술과 트래픽 비혼잡 시간대에 RF 체인을 슬립시키는 적응형 전력 관리(APM) 기법 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
통신사 개방형 무선 접속망(O-RAN) 도입 시, 모든 연산을 x86 CPU에서 처리하는 순수 소프트웨어 vDU(Lookaside 가속) 방식은 연산 코어 소모가 극심하므로, FEC(LDPC 복호)와 빔포밍 등 연산 집약적 계층을 전용 가속 카드에 위임하는 인라인(Inline) 하드웨어 가속 아키텍처 채택 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ O-RAN 인라인 가속 기반 SDR 기지국 아키텍처 ]       │
│                                                                        │
│   [RU (Radio Unit)] ══════ eCPRI (25G 광통신) ══════ [vDU COTS 서버]   │
│                                                            │           │
│                                                            ▼           │
│                                               ┌──────────────────────┐ │
│                                               │ 인라인 PCIe 가속 카드│ │
│                                               │ (FPGA / 전용 eASIC)  │ │
│                                               │ - LDPC / Polar 복호  │ │
│                                               │ - 디지털 빔포밍 FFT  │ │
│                                               └──────────┬───────────┘ │
│                                                          │ 제로카피    │
│                                                          ▼             │
│                                               ┌──────────────────────┐ │
│                                               │ Host Xeon CPU        │ │
│                                               │ - MAC High / RLC     │ │
│                                               │ - DPDK 실시간 스케줄 │ │
│                                               └──────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 구분 | GPP 전용 SDR (Lookaside) | FPGA/GPU 가속 SDR (Inline) | 전용 ASIC 고정형 무선 |
|---|---|---|---|
| **연산 주체** | 범용 CPU 코어 전담 (AVX-512) | 전용 PCIe 가속 카드 전담 | 단일 칩 ASIC 하드웨어 |
| **처리 지연시간** | 지연 변동성 높음 (CPU 부하 종속) | 극저지연 보장 (Deterministic) | 최저 지연 (와이어 스피드) |
| **소프트웨어 유연성**| 최고 (C/C++ 코드 즉시 컴파일) | 우수 (RTL 펌웨어 재구성) | 전무 (하드웨어 고정) |
| **시스템 전력 효율** | 낮음 (많은 CPU 코어 점유) | 우수 (전력 대비 처리량 높음) | 최고 (단일 기능 최적화) |
| **대표 활용 사례** | 오픈소스 연구(GNU Radio, srsRAN)| 상용 5G O-RAN vDU, 국방 무전기 | 대량 보급형 스마트폰 모뎀 칩 |
