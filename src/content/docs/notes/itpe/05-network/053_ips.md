## Ⅰ. IPS(Indoor Positioning System)의 개요

- 개념 : 콘크리트 벽체와 천장에 의해 위성 항법 신호(GPS)가 차단되거나 극심한 다중경로 감쇠를 겪는 실내 환경에서 다양한 무선 통신 인프라와 센서를 융합하여 사람 또는 사물의 정밀한 2차원/3차원 위치를 측정하는 실내 측위 시스템.
- 배경 및 필요성 : 대형 복합 쇼핑몰, 지하 물류 창고, 스마트 팩토리, 병원 등에서 **자율주행 물류로봇(AMR)** 유도, 자산 위치 추적, 화재 시 소방관 인명 구조 등을 위한 고정밀 실내 위치 정보 수요 폭발.
- 핵심 목적 : **GPS** 음영 해소, **서브미터(Sub-meter)~센티미터(cm)급** 위치 측정 정밀도 확보, 저전력 인프라 운용 및 실시간 모빌리티 추적.

## Ⅱ. IPS의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│                      [ IPS 측위 알고리즘 3대 메커니즘 ]                │
│                                                                        │
│   [ 1. 삼변측량 (Trilateration) ]      [ 2. 삼각측량 (Triangulation) ] │
│   기준점과의 거리(r1, r2, r3) 교차점   기준점과의 도달 각도(AoA/AoD)   │
│         AP1 (x1, y1)                         AP1 (x1, y1)              │
│          ○                                    ○                        │
│         / \  r1                                \ θ1                    │
│        /   \                                    \                      │
│       /  ●  \                                    ● (목표 위치)         │
│      / r2   r3\                                 /                      │
│     ○          ○                               ○ θ2                    │
│    AP2        AP3                             AP2 (x2, y2)             │
│                                                                        │
│   [ 3. 핑거프린팅 (Fingerprinting) ]                                   │
│   - 사전 단계 : 실내 공간을 그리드로 분할하고 각 지점의 RSSI 맵 구축   │
│   - 온라인 단계 : 현재 측정된 무선 신호 패턴과 DB 내 k-NN 패턴 매칭   │
└────────────────────────────────────────────────────────────────────────┘
```

- **삼변측량법 (Trilateration)** : 최소 3개 이상의 기준 노드(AP/앵커)로부터 대상 단말까지의 거리($r_1, r_2, r_3$)를 측정한 후 원의 방정식을 연립하여 교점 좌표 도출 (RSSI, ToF, TDoA 방식 활용).
- **삼각측량법 (Triangulation / AoA)** : 다중 안테나 어레이에 도달하는 무선 신호의 위상차를 분석하여 도달 각도(Angle of Arrival)를 구하고, 두 개 이상의 각도 직선이 교차하는 지점 계산.
- **핑거프린팅 (Fingerprinting)** : 실내 벽면 반사로 인한 다중경로 오차를 역이용하여, 사전에 측정한 전파 수신강도(RSSI) 공간 지도를 데이터베이스화하고 현재 수신 패턴과 머신러닝(k-NN)으로 비교 측위.

## Ⅲ. IPS 핵심 무선 통신 기술의 세부 비교 분석

| 기술 구분 | UWB (초광대역) | BLE Beacon (블루투스) | Wi-Fi FTM (RTT) | PDR / 복합 센서 |
|---|---|---|---|---|
| 표준 규격 | IEEE 802.15.4z / FiRa | Bluetooth 5.1+ (AoA) | IEEE 802.11mc / az | 관성 센서 (IMU, 지자기) |
| 측위 정확도 | 10 ~ 30 cm (초정밀) | 1 ~ 3 m (AoA 적용 시 1m) | 1 ~ 2 m | 누적 오차 발생 (발산) |
| 측정 원리 | ToF (Two-Way Ranging) / TDoA | RSSI 감쇠 모델 / AoA | Round-Trip Time 왕복시간| 가속도, 자이로 보폭 계산|
| 신호 대역폭 | 500 MHz 이상 초광대역 | 2 MHz 협대역 | 20 ~ 160 MHz | 비통신 센서 기반 |
| 장애물 내성 | 극도로 강함 (나노초 펄스) | 약함 (벽체 반사/흡수 심함) | 중간 (다중경로 영향 존재)| 기계적 진동 영향 |
| 구축 비용 | 전용 앵커 필요 (고비용) | 배터리 비콘 (극저비용) | 기존 공유기 재활용 (중간)| 단말 내장 센서 (추가비용 無)|
| 주요 적용처 | 스마트팩토리 물류로봇, 디지털키| 매장 마케팅, 실내 길안내 | 캠퍼스 자산 추적, 공공안내 | 보행자 추측 항법 보조 |

- **ToF (Time of Flight) 및 TDoA (Time Difference of Arrival)** : 신호의 빛 속도($c \approx 3 \times 10^8 \text{m/s}$) 이동 시간을 피코초 단위로 정밀 측정하여 거리 환산.
- **하이브리드 융합 측위 (Sensor Fusion)** : UWB/Wi-Fi 신호와 스마트폰의 가속도계, 지자기계(Magnetic Field), 기압계(고도 측정) 데이터를 확장 칼만 필터(EKF)로 결합하여 오차 극소화.

## Ⅳ. IPS의 주요 한계점 및 해결 방안

- NLOS(비가시선) 환경에서의 전파 굴절 및 다중경로(Multipath) 왜곡 :
  - 한계점 : 실내 기둥, 철골 벽체, 이동하는 사람에 의해 직접 신호가 차단되고 반사파가 먼저 도달하여 거리 측정 오차 수 미터 이상 급증.
  - 해결 방안 : CIR(Channel Impulse Response) 분석을 통해 직접 경로(First Path)와 반사 경로를 수학적으로 분리하고, 딥러닝 기반 NLOS 판별 및 칼만 필터 가중치 재조정.
- 핑거프린팅 라디오 맵(Radio Map)의 지속적 노후화 및 유지보수 비용 :
  - 한계점 : 실내 구조 변경, 가구 이동, 문 개폐에 따라 전파 환경이 수시로 변하여 초기에 전수 실측한 DB 신뢰도 급락.
  - 해결 방안 : 일반 사용자의 단말 궤적과 센서 데이터를 수집하여 라디오 맵을 자가 학습·갱신하는 크라우드소싱 SLAM(Simultaneous Localization and Mapping) 도입.

## Ⅴ. IPS 적용 및 발전을 위한 기술사적 제언

- UWB 기반의 차세대 정밀 물리 보안 인프라 구축 : 도난 및 차량 탈취를 방지하기 위해 ToF 거리 측정의 암호학적 타임스탬프를 검증하는 Secure Ranging 기술(IEEE 802.15.4z)을 표준 스마트키 시스템에 필수 채택.
- 실내 3차원 공간정보(BIM/GIS) 플랫폼과의 결합 : 2차원 평면 좌표를 넘어 고도(층수)와 3D 디지털 트윈 모델을 연동하여, 화재 및 재난 시 요구조자의 입체적 위치를 소방 관제탑에 실시간 시각화 제공.
- Wi-Fi 7/8 표준 실내 측위(IEEE 802.11az) 조기 수용 : 별도의 UWB 앵커를 추가 설치하지 않고도 기존 무선랜 AP 인프라를 그대로 활용하여 1m 이하의 측위 성능을 달성하는 엔터프라이즈 통합망 구현.
