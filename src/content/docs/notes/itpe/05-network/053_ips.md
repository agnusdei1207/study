컴퓨터 시스템 및 네트워크 → 무선 통신 및 위치 기반 서비스 → **IPS(Indoor Positioning System)**

## 30초 인출

- 본질: **IPS (Indoor Positioning System)** : GPS 신호 수신이 불가능한 실내 환경에서 Wi-Fi, BLE, UWB 등 무선 신호의 물리적 전파 특성(세기, 시간, 각도)을 활용하여 객체의 2D/3D 위치 좌표를 추정하는 실내 측위 시스템
- 메커니즘: 삼변측량(ToF/TDoA), 삼각측량(AoA/AoD), 무선 신호 지도 대조(Fingerprinting, RSSI/k-NN), 센서 융합(PDR/칼만 필터)을 복합 적용하여 좌표 산출
- 통찰: 실내 콘크리트 벽체와 동적 장애물에 의한 다중경로 페이딩 및 비가시선(NLOS) 신호 왜곡 극복을 위해 UWB 초광대역 펄스와 PDR 관성 센서 융합 필터링 체계 구축 필수

<details>
<summary>핵심 용어</summary>

- **RSSI (Received Signal Strength Indicator)** : 수신 신호의 세기 감쇠 정도를 경로 손실 모델(Log-distance)에 대입하여 거리를 추정하는 지표
- **ToF (Time of Flight)** : 전파가 송신단에서 수신단까지 이동한 전파 비행 시간을 측정하여 광속($c$)을 곱해 절대 거리를 환산하는 방식
- **TDoA (Time Difference of Arrival)** : 3개 이상의 동기화된 기준국에서 신호 도착 시간 차이로 쌍곡선을 형성하여 교점을 구하는 방식
- **AoA (Angle of Arrival)** : 안테나 어레이 간에 수신되는 신호의 위상차(Phase Difference)를 분석하여 신호의 입사 각도를 측정하는 기술
- **Fingerprinting** : 대상 구역을 격자 분할 후 사전 수집한 신호 세기 지도(Radio Map)와 실시간 수신치를 k-NN/머신러닝으로 패턴 매칭하는 측위 기법
- **PDR (Pedestrian Dead Reckoning)** : 스마트폰의 가속도계, 자이로센서, 지자기센서를 활용해 걸음 수, 보폭, 진행 방향을 추정하는 관성 항법

</details>

## 2~4교시 25점 답안

## Ⅰ. IPS의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | GPS 위성 전파가 차단되는 실내 빌딩, 지하 시설, 공장 등에서 무선 신호(Wi-Fi, BLE, UWB) 및 관성 센서를 활용하여 사람이나 사물의 실시간 위치를 추정하는 측위 시스템 |
| 목적 | 대형 쇼핑몰·공항 길안내, 스마트 공장 자산·물류 실시간 추적, 재난 화재 시 소방대원 및 구조자 정밀 위치 파악 |

## Ⅱ. IPS의 특징 및 주요 물리적 측정 파라미터

| 측정 파라미터 | 원리 및 측정 대상 | 정확도 및 주요 특징 |
|---|---|---|
| **RSSI (신호 세기)** | 거리 제곱에 반비례하는 신호 감쇠 측정 ($P_r \propto 1/d^n$) | 3~5m 오차 / 기구축 AP 활용 가능하나 벽체·사람 흡수에 극도로 취약 |
| **ToF (비행 시간)** | 신호 송수신 간 전파 왕복 시간($\Delta t$) 측정 ($d = c \cdot \Delta t / 2$) | 10~30cm 오차 / 고정밀 클록 타이밍 동기화 및 광대역 펄스 신호 필요 |
| **TDoA (시간차)** | 복수 기준국 간 수신 시간 차이로 쌍곡선 교점 산출 | 10~50cm 오차 / 기준국 간 서브 나노초(ns) 단위 하드웨어 시간 동기화 필수 |
| **AoA (도착 각도)** | 안테나 어레이 간 전파 수신 위상차($\Delta \phi$)로 입사각 계산 | 1m 내외 오차 / BLE 5.1 표준 채택, 다중 안테나 어레이 하드웨어 요구 |

## Ⅲ. IPS 측위 아키텍처 및 알고리즘 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ IPS 핵심 측위 알고리즘 아키텍처 ]                  │
│                                                                        │
│   [방식 1: 기하학적 삼변측량 (ToF/TDoA)]   [방식 2: 신호 핑거프린팅]   │
│                                                                        │
│          Anchor 1      Anchor 2            [Offline 훈련 단계]         │
│             (x1,y1)      (x2,y2)            - 격자별 RSSI 수집         │
│                ○            ○               - Radio Map 데이터베이스   │
│                 \  r1    r2/                            │              │
│                  \        /                             ▼              │
│                   ▼  ●   ▼                 [Online 측위 단계]          │
│                   단말(x, y)                - 단말 실시간 RSSI 수신    │
│                     /                       - k-NN / SVM / 머신러닝   │
│                  r3/                          최근접 격자 좌표 추정    │
│                   ○                                     │              │
│               Anchor 3                                  ▼              │
│                (x3,y3)                         [ 단말 위치 (x, y) ]    │
└────────────────────────────────────────────────────────────────────────┘
```

| 처리 단계 | 수행 알고리즘 | 세부 동작 메커니즘 |
|---|---|---|
| **신호 수집** | RSSI / ToF / AoA 측정 | 비콘, AP, UWB 앵커로부터 무선 프레임을 수신하고 물리 계층 파라미터 추출 |
| **신호 전처리** | 칼만 필터 / 이동 평균 필터 | 다중경로 잡음, 채널 페이딩에 따른 RSSI 튀는 현상(Outlier) 제거 평활화 |
| **위치 연산** | 삼변측량(Trilateration) | 3개 이상 기준점 중심의 원 방정식을 세워 최소제곱법(LS)으로 최적 교점 계산 |
| **패턴 매칭** | Fingerprinting (k-NN) | 유클리디안 거리 기반으로 라디오 맵에서 신호 벡터가 가장 유사한 k개 좌표의 가중 평균 산출 |

## Ⅳ. 주요 실내 측위 무선 기술 비교

| 비교 항목 | Wi-Fi (IEEE 802.11az) | BLE 비콘 (Bluetooth 5.1) | UWB (IEEE 802.15.4z) |
|---|---|---|---|
| **동작 주파수** | 2.4 GHz / 5 GHz / 6 GHz | 2.4 GHz ISM 밴드 | 3.1 GHz ~ 10.6 GHz (광대역) |
| **주요 측위 방식**| RSSI 핑거프린팅, FTM(ToF) | RSSI, AoA/AoD 위상차 | ToF(왕복시간), TDoA(도착시간차) |
| **측위 정밀도** | 1 ~ 3 m 내외 | 1 ~ 2 m 내외 (AoA 적용 시 0.5m) | 10 ~ 30 cm (센티미터급 초정밀) |
| **인프라 비용** | 기존 AP 활용으로 추가비용 낮음 | 저가 비콘 배터리 구동, 구축 용이 | 전용 앵커/태그 필요, 인프라 비용 높음 |
| **장애물 간섭** | 다중경로 페이딩 영향 큼 | 금속 및 인체 수분에 매우 취약 | 수 나노초 미세 펄스로 다중경로 완벽 분리 |
| **주요 활용 처** | 쇼핑몰, 공항, 전시장 고객 안내 | 매장 타깃 마케팅, 실내 박물관 | 정밀 스마트 팩토리, 물류 AGV, 로봇 제어 |

## Ⅴ. IPS의 한계와 방안

| 한계 | 방안 |
|---|---|
| 실내 콘크리트 벽체, 철골 프레임, 이동 인원에 의한 전파의 다중경로 반사(Multipath) 및 비가시선(NLOS) 장애물로 신호 감쇠와 지연 오차가 극심하게 발생 | 수 기가헤르츠(GHz) 광대역 펄스를 송출하여 나노초 단위로 직접파와 반사파를 시간축에서 완벽히 분리해내는 UWB(IEEE 802.15.4z) 기술 도입 및 NLOS 감지 머신러닝 분류기 적용 |
| 핑거프린팅 방식 구축 후 실내 가구 재배치, 인테리어 공사, 계절별 실내 온습도 변화 시 사전 구축된 라디오 맵(Radio Map)과 실시간 신호가 불일치하여 위치 오차 급증 | 스마트폰 관성 센서(PDR) 궤적 정보를 결합하여 사용자가 보행하는 동안 변경된 신호 세기를 백그라운드에서 동적 보정하는 크라우드소싱 기반 능동형 라디오 맵 자동 갱신 체계 구축 |
| BLE 비콘 및 UWB 앵커를 전 공간에 고밀도로 설치함에 따른 배터리 교체 유지보수 부담 및 단말의 지속적 무선 스캔으로 인한 배터리 급속 소모 | 에너지 하베스팅(태양광, RF 하베스팅) 기반 무전원 비콘 도입 및 가속도 센서 정지 상태 감지 시 스캔 주기를 동적으로 늘리는 적응형 절전 스케줄링 기법 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
단일 무선 기술만으로는 실내의 음영 구역과 동적 환경 변화를 극복하기 어려우므로, 정밀도가 요구되는 물류/공장 라인은 UWB 앵커망을 격자 배치하고, 일반 방문객 구역은 Wi-Fi FTM과 BLE 비콘을 혼용하며, 최종 단말에서는 확장 칼만 필터(EKF) 기반으로 무선 측위 결과와 스마트폰 내장 관성 항법(PDR)을 융합하는 하이브리드 아키텍처 수립 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 하이브리드 IPS 센서 융합 처리 아키텍처 ]               │
│                                                                        │
│   [무선 신호 계측]                    [스마트폰 센서 계측]             │
│   - UWB ToF / TDoA                    - 가속도계 (걸음 감지)           │
│   - BLE AoA 각도 정보                 - 자이로 / 지자기 (보폭/방향)    │
│   - Wi-Fi RSSI 맵                     - 기압계 (층수 판별)             │
│          │                                     │                       │
│          ▼ [전파 전처리]                       ▼ [PDR 관성 항법]       │
│   다중경로/NLOS 이상치 제거           누적 오차(Drift) 발생 궤적       │
│          │                                     │                       │
│          └─────────────────┬───────────────────┘                       │
│                            ▼                                           │
│               [ 확장 칼만 필터 (EKF) 엔진 ]                            │
│               - 예측 단계: PDR 관성 궤적 기반 예측                     │
│               - 갱신 단계: UWB/BLE 무선 측정값으로 오차 보정           │
│                            │                                           │
│                            ▼                                           │
│               [ 실시간 정밀 3D 좌표 산출 ]                             │
│               (오차 10~30cm 이내 수렴 및 드리프트 방지)                │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 측위 기법 | 계산 복잡도 | 인프라 추가 구축 여부 | 환경 변화 민감도 | 융합 보정 기법 |
|---|---|---|---|---|
| **기하학적 삼변측량** | 낮음 (선형 방정식 연산) | 3개 이상 고정 앵커 설치 필수 | 가시선(LOS) 확보에 민감 | 비선형 최적화(Levenberg-Marquardt) |
| **신호 핑거프린팅** | 높음 (공간 라디오 맵 탐색) | 기구축 AP 활용 가능 | 인테리어/구조 변경에 매우 취약 | 딥러닝(CNN/Autoencoder) 맵 보정 |
| **보행자 관성항법(PDR)**| 중간 (센서 신호 적분 연산) | 추가 인프라 불필요 (단말 자체) | 시간에 비례한 오차 누적(Drift) | ZUPT(Zero Velocity Update) 보정 |
| **하이브리드 센서융합** | 높음 (확장 칼만 필터 연산) | 복합 인프라 및 단말 센서 활용 | 동적 환경에 가장 강인한 복원력 | 파티클 필터(Particle Filter) 융합 |
