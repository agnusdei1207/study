## 연관 키워드

- 6G 이동통신(6G Mobile Communication), IMT-2030, 서브 테라헤르츠(Sub-THz, Sub-Terahertz)
- 지능형 반사 표면(RIS), 통신-센싱 융합(ISAC), 비지상 네트워크(NTN), AI 네이티브(AI-Native), 앰비언트 IoT(Ambient IoT), 개방형 무선 접속망(O-RAN)

## Ⅰ. 6G 이동통신의 개요

- 핵심 요약 : 초광대역 무선과 비지상 망, 센싱·지능의 융합으로 5G 이후의 용량·커버리지·기능 한계를 넘으려는 차세대 이동통신.
- 개념 : 국제전기통신연합(ITU, International Telecommunication Union)이 **IMT-2030**(2030년 이후 국제이동통신의 미래 발전 프레임워크)으로 방향을 제시하는 5G 이후 세대의 이동통신(6G).
- 배경 및 필요성 : 완전 자율주행, 원격 수술, 몰입형 가상 공간처럼 초저지연·초신뢰·초대용량의 동시 요구가 확대되는 가운데, 지상 기지국만으로는 해상·산간·상공의 커버리지 공백이 남는 구조.
- 주요 목적 : 전송 용량의 확장, 지상·공중·우주로 이어지는 3차원 커버리지 확보, 통신과 센싱·인공지능(AI, Artificial Intelligence)의 결합.

## Ⅱ. 6G 이동통신의 특징 및 장점

- 핵심 요약 : 초광대역 대역, 반사 표면, 센싱 융합, 비지상 망, 내장형 지능, 무전원 통신이 용량·커버리지·기능의 확장으로 연결되는 구조.

1. 서브 테라헤르츠 초광대역 : 100GHz 이상 영역의 광대역 확보 → 대용량 실시간 데이터의 전송 수용.
2. **지능형 반사 표면** (RIS, Reconfigurable Intelligent Surface) : 전파를 제어해 반사하는 표면 장치 → 건물 음영 지역의 신호 보완과 전파 경로 설계.
3. **통신-센싱 융합** (ISAC, Integrated Sensing and Communication) : 같은 전파로 통신과 객체 감지를 동시 수행 → 환경 인지 서비스의 신규 창출.
4. **비지상 네트워크** (NTN, Non-Terrestrial Network) : 저궤도 위성과 고고도 플랫폼의 무선망 통합 → 해상·극지·상공의 연속 커버리지.
5. AI 네이티브 설계 : 무선 자원 스케줄링과 신호 처리에 인공지능 내장 → 자원 활용 효율과 운용 자동화의 향상.
6. **앰비언트 IoT**(Ambient IoT, 주변 에너지를 수확하는 무전원·초저전력 통신) : 전파·빛·진동 에너지의 수확 → 배터리 교체 없는 초대규모 센서의 확산.

## Ⅲ. 6G 이동통신의 구조 (흐름)

- 핵심 요약 : 지능 계층, 비지상 계층, 지상 계층이 하나의 접속망으로 통합되는 3계층 구조.

```text
[ 6G 3계층 통합 구조 ]

지능 계층 (AI 코어·엣지 지능)
    ↓ 자원 제어
비지상 계층 (위성·고고도 플랫폼)
    ↓ 커버리지 보완
지상 계층 (Sub-THz 기지국·RIS)
    ↓
단말 (통신 + 센싱 동시 수행)
```

```text
[ 통신-센싱 융합의 동작 ]

기지국의 전파 송신
    ↓
객체 반사 신호의 수신
    ↓
위치·속도·형태의 분석
    ↓
디지털 트윈 갱신
    ↓
빔·자원의 재배치
```

## Ⅳ. 4G, 5G와 6G의 비교

- 핵심 요약 : 6G는 속도 향상을 넘어 주파수 대역, 커버리지 차원, 네트워크 기능이 함께 바뀌는 세대 전환.
- 수치 목표는 표준화가 확정되지 않은 연구 방향이므로, 정성 비교를 기준으로 삼는 접근이 안전.

| 비교 축 | 4G LTE(Long-Term Evolution) | 5G NR(New Radio) | 6G (논의 단계) |
| --- | --- | --- | --- |
| 주파수 대역 | GHz 이하 중심 | 밀리파 대역 포함 | Sub-THz 대역 검토 |
| 커버리지 차원 | 지상 2차원 | 지상 중심 + 슬라이싱 | 우주·공중·지상 3차원 |
| 서비스 초점 | 모바일 광대역 | 초저지연·대규모 연결 | 센싱·지능 융합 서비스 |
| 네트워크 지능 | 외부 최적화 도구 수준 | 자동화·분석의 도입 | 설계 단계부터의 지능 내장 |
| 단말 범위 | 사람 중심 | 사람 + 사물 | 사물 + 무전원 센서까지 |

- 선택 기준 : 현재 시점의 실무 적용은 5G 고도화가 기본이고, 초광대역 센싱과 비지상 커버리지가 필수인 미래 서비스 설계에 6G 방향을 반영.

## Ⅴ. 6G 이동통신의 한계와 방안

- 핵심 요약 : 고주파 전파 손실, 전력·발열, 촘촘한 셀의 투자 부담을 빔 기술, 저전력 설계, 개방형 인프라로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| Sub-THz 경로 손실 | 파장 단축으로 도달 거리 감소, 장애물·강우에 의한 차단 | 대규모 안테나 빔포밍과 RIS 배치 설계 | 셀 반경·음영 비율 |
| 전력 소모와 발열 | 초고속 변환·연산 부하 → 단말 배터리와 기지국 열 문제 | 하이브리드 빔포밍, 연산 양자화, 고효율 증폭기 | 장비 소비 전력 |
| 투자 부담 | 짧은 도달 거리 → 기지국 밀도 증가 → 자본 지출 확대 | 개방형 무선 접속망(O-RAN, Open Radio Access Network) 기반 장비 공유와 인프라 공동 활용 | 셀당 구축 비용 |

## Ⅵ. 6G 이동통신에 대한 기술사적 제언

- 핵심 요약 : 원천 기술 확보, 주파수 전략, 실증 인프라의 병행 추진이라는 국가·산업 차원의 준비 방향.
- 연구개발 조직은 Sub-THz 반도체, RIS 제어, ISAC 파형 같은 원천 기술에 투자를 집중하고 표준 특허 확보 전략을 병행할 필요.
- 주파수 정책 기관은 세계전파통신회의(WRC, World Radiocommunication Conference) 일정에 맞춰 중간 대역과 Sub-THz 대역의 국가 주파수 로드맵을 수립하는 방안.
- 통신 사업자와 지자체는 5G 고도화망과 비지상 연계 실증을 먼저 수행하여 상용화 이전의 응용 서비스 검증 기반을 확보하는 절차 권장.

## Ⅶ. 결론

- 핵심 요약 : 6G는 속도 경쟁을 넘어 통신·센싱·지능과 우주 공간을 아우르는 융합 인프라로의 전환.
- 표준화 진행 중인 만큼 검증된 근거를 바탕으로 단계적으로 준비하는 접근이 타당.
