## 지식 로드맵 내 현재 위치

지식 위치: 네트워크 → 차세대 이동통신 → **6G(IMT-2030)**

## 30초 인출

- 본질: **6G 이동통신(IMT-2030)** : 2030년 이후 이동통신의 사용 시나리오와 성능·기능 목표를 발전시키는 국제 표준화 세대
- 메커니즘: 몰입형 통신·초신뢰 저지연·대규모 통신·유비쿼터스 연결에 AI·센싱 통합 시나리오를 더해 요구 성능·기능을 연구·표준화
- 통찰: 지상 2차원 셀룰러 한계를 넘어 저궤도 위성과 HAPS를 포괄하는 3차원 초공간 커버리지를 구축하고, Sub-THz 대역과 내생형 인공지능(AI-Native) 및 통신-센싱 융합을 실현하는 차세대 융합 통신 인프라임.

<details>
<summary>핵심 용어</summary>

- **IMT-2030(International Mobile Telecommunications-2030)** : ITU-R이 정한 2030년 및 이후 IMT 발전 프레임워크
- **6G 이동통신(IMT-2030)** : IMT-2030 프레임워크를 바탕으로 2030년 이후 발전시키는 차세대 이동통신
- **IMT-2020(International Mobile Telecommunications-2020)** : 5G 이동통신 세대의 ITU 명칭
- **ISAC(Integrated Sensing and Communication)** : 통신과 센싱 기능을 함께 다루는 사용 시나리오·기능 영역
- **AI(Artificial Intelligence)** : IMT-2030의 네트워크·서비스 활용을 지원할 수 있는 인공지능 기능
- **NTN(Non-Terrestrial Network)** : 위성·고고도 플랫폼 등 비지상 구성요소를 포함하는 네트워크
- **RIS(Reconfigurable Intelligent Surface)** : 전파 반사 특성을 조정해 무선 환경을 제어하려는 표면 기술 연구 분야
- **피크 데이터율(Peak Data Rate)** : 이상적인 조건에서 단말별 달성 가능한 최대 데이터율
- **사용자 체감 데이터율(User-experienced Data Rate)** : 목표 커버리지에서 사용자가 이용할 수 있는 데이터율

## 2~4교시 25점 답안

## Ⅰ. 6G 이동통신의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 5G 대비 50배 빠른 최대 1Tbps 전송속도, 10분의 1 수준인 0.1ms 무선 지연, 고도 10km 이상의 3차원 공간 커버리지를 제공하는 차세대 이동통신 기술 표준 |
| 목적 | 완전 몰입형 홀로그램, 원격 로봇 수술, 플라잉카(UAM) 관제, 현실과 가상의 완전 동기화(디지털 트윈) 및 글로벌 전 지구 무선망 구축 |

## Ⅱ. 6G 이동통신의 특징

| 특징 | 상세 내용 |
|---|---|
| 초성능 (Tbps급 전송)| Sub-THz(100GHz~300GHz) 광대역 주파수를 개척하여 기가급을 넘어선 테라비트급 데이터 전송 달성 |
| 초저지연 (0.1ms) | 무선 구간 지연을 0.1ms 이하로 단축하고 E2E 종단 지연 1ms 이하를 보장하여 촉각 인터넷 실현 |
| 초공간 (3D 네트워크)| LEO 위성 및 HAPS와 연계하여 지표면뿐 아니라 최대 고도 10km 상공까지 음영 없는 커버리지 확장 |
| 초지능 (AI 내생화) | 통신 신호 변복조부터 코어망 라우팅까지 시스템 전반에 AI 모델이 기본 내장되어 자율 운영 실현 |

## Ⅲ. 6G 이동통신의 체계·프로세스

**6G 5대 핵심 성능 지표 및 아키텍처 비전**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 6G 이동통신 핵심 성능 목표 ]                  │
│                                                                        │
│                [ 초성능: 1 Tbps (5G 대비 50배) ]                       │
│                              ▲                                         │
│                             / \                                        │
│                            /   \                                       │
│   [ 초공간: 고도 10km ]   /     \   [ 초저지연: 0.1 ms (5G 대비 1/10) ]│
│   (위성·HAPS·지상 통합)  /  6G   \  (촉각 인터넷, 무선 원격 제어)     │
│           ▲             /  비전   \             ▲                      │
│           │            /           \            │                      │
│           ▼           /─────────────\           ▼                      │
│   [ 초정밀: 1 cm급 측위 ]             [ 초지능: Zero-touch AI-Native ] │
│   (통신·센싱 융합 ISAC)               (전 계층 딥러닝 자율 최적화)     │
└────────────────────────────────────────────────────────────────────────┘
```

| 핵심 요구조건 | 세부 성능 지표 (KPI) | 핵심 구현 기술 |
|---|---|---|
| **초성능 (Extreme Throughput)** | 최대 속도 1 Tbps, 체감 1 Gbps | Sub-THz 주파수, 초광대역 RF, Extreme MIMO |
| **초저지연 (Extreme Latency)** | 무선 0.1 ms, 사용자 지연 1 ms | 초단축 TTI, TSN(Time-Sensitive Networking), 온프레미스 에지 |
| **초공간 (3D Coverage)** | 위성 연계 고도 10km, 이동속도 1000km/h| 3GPP NTN, 고속 도플러 보상, 3차원 빔포밍 |
| **초정밀 (Extreme Precision)** | 위치 오차 1cm급, 3D 점군 센싱 | ISAC (통신 센싱 융합), 극초광대역 전파 반사 분석 |
| **초지능 (Native Intelligence)**| Level 5 완전 자율 무인 운용 | AI-RAN, 분산 연합학습, 딥러닝 종단 변복조 |

## Ⅳ. 6G 이동통신의 종류·비교

| 비교 항목 | 4G LTE | 5G NR | 6G 이동통신 |
|---|---|---|---|
| **상용화 시기** | 2011년 | 2019년 | **2030년경 (예정)** |
| **최대 전송 속도** | 1 Gbps | 20 Gbps | **최대 1 Tbps** |
| **무선 전송 지연** | 10 ms | 1 ms | **0.1 ms (100 μs)** |
| **주요 주파수 대역** | 800MHz ~ 2.6GHz | 3.5GHz / 28GHz | **7~15GHz / 100~300GHz (Sub-THz)** |
| **서비스 공간 영역** | 지표면 2D 평면 | 지표면 2D 중심 | **지상 + 공중 + 우주 3D 입체 공간** |
| **핵심 융합 기술** | 스마트폰 음성/데이터 | MEC, 네트워크 슬라이싱 | **통신-센싱 융합(ISAC), RIS, AI 내생망** |

## Ⅴ. 6G 이동통신의 한계와 방안

| 한계 | 방안 |
|---|---|
| Sub-THz 극초고주파 신호의 높은 자유 공간 경로 손실(Path Loss) 및 장애물 투과 불가 | 수동형 전파 반사 패널인 RIS(Reconfigurable Intelligent Surface)를 도심 빌딩 외벽에 전면 배치 |
| 대규모 위성군 및 테라비트급 장비 가동에 따른 통신망 총 전력 소모 폭증 | 질화갈륨(GaN) 고효율 전력증폭기 채택 및 AI 기반 동적 빔 수면(Micro-sleep) 제어 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
차세대 통신망 R&D 로드맵 수립 시, Sub-THz 대역의 원거리 전송 한계를 감안하여 도심 광역망은 7~15GHz 대역(FR3)을 핵심 주파수로 타깃팅하고, Sub-THz는 데이터센터 랙 간 단거리 초고속 무선 백홀 및 키오스크 초고속 다운로드 존에 국소 배치.

### 2. 아키텍처 및 상세 메커니즘

### 3. 기술 유형 및 비교 평가
| 기술 요소 | 핵심 역할 | 기술적 난제 |
|---|---|---|
| **Sub-THz RF** | 1Tbps 전송을 위한 10GHz 이상 광대역 확보 | 초소형 안테나 어레이 패키징 및 발열 제어 |
| **RIS (재구성 표면)** | 전파 음영 지역에 인위적 반사 경로 형성 | 초저전력 위상 제어 회로 및 실시간 채널 피드백 |
| **ISAC (통신센싱)** | 통신 전파로 레이더급 3D 환경 인식 동시 수행 | 센싱 간섭 제거 및 다중 목표물 추적 알고리즘 |
