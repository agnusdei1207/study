## 30초 인출

- 본질: **슬라이딩 윈도우** : 확인 응답을 기다리지 않고 여러 데이터를 연속 전송하는 범위를 관리하는 방식
- 메커니즘: 송신 가능한 번호 범위를 두고, ACK가 도착하면 왼쪽 경계를 전진시켜 새 데이터의 송신을 허용

<details>
<summary>핵심 용어</summary>

- **슬라이딩 윈도우(Sliding Window)** : 송신·수신 범위의 경계를 확인 응답에 따라 이동시키는 전송 제어 방식
- **송신 윈도우(Send Window)** : 확인 응답 없이 송신할 수 있는 데이터의 순서 번호 범위
- **누적 ACK(Cumulative Acknowledgment)** : 표시한 번호 이전의 연속 데이터를 수신했음을 알리는 확인 응답
- **rwnd(Receive Window)** : TCP 수신 측이 광고하는 수신 가능 버퍼 범위
- **cwnd(Congestion Window)** : TCP 송신 측이 경로 혼잡 상태에 따라 조절하는 송신 한도
- **RTT(Round-Trip Time)** : 송신부터 해당 응답을 받을 때까지의 왕복 시간
- **영속 타이머(Persist Timer)** : 수신 윈도우가 0인 동안 윈도우 갱신을 확인하기 위한 TCP 타이머

</details>

## 1교시 10점 답안

### Ⅰ. 슬라이딩 윈도우의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **슬라이딩 윈도우** : ACK를 기다리는 동안에도 일정 범위의 데이터를 연속 송신하고 확인에 따라 그 범위를 옮기는 방식 |
| 목적 | 왕복 지연 중 송신 중단을 줄이고 수신 가능 범위에 맞춘 전송 |

### Ⅱ. 경계의 이동

```text
송신 윈도우
  ├─ 이미 송신·ACK 대기
  └─ 아직 송신 가능

ACK 도착 → 왼쪽 경계 전진 → 새 데이터 진입
```

- 제언: 수신 여유와 경로 혼잡 한도를 함께 고려해 송신 범위를 설정.

## 2~4교시 25점 답안

## Ⅰ. 슬라이딩 윈도우의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **슬라이딩 윈도우** : ACK를 기다리는 동안에도 일정 범위의 데이터를 연속 송신하고 확인에 따라 그 범위를 옮기는 방식 |
| 목적 | 왕복 지연 중 송신 중단을 줄이고 수신 가능 범위에 맞춘 전송 |

## Ⅱ. 송신 윈도우의 구성

```text
송신 윈도우: 4~9번 바이트(예시)
  ├─ 4~6: 송신 완료·ACK 대기
  └─ 7~9: 송신 가능

ACK 7 수신 → 4~6 확인 → 왼쪽 경계 7로 이동
```

번호는 TCP의 바이트 순서 번호 예시. **ACK 7**은 7번 이전의 연속 바이트 수신을 의미하며 7번 패킷의 수신 확인이 아님.

## Ⅲ. 연속 송신과 경계 이동

```text
허용 범위에서 여러 바이트 송신
    ↓
수신 측의 누적 ACK 도착
    ↓
확인된 범위 제거·윈도우 경계 전진
    ↓
새 데이터 송신 가능
```

ACK가 지연되어도 윈도우 안의 데이터는 연속 송신 가능. 재전송 여부와 범위는 손실 복구 방식에 따라 결정.

## Ⅳ. TCP의 두 한도

| 한도 | 누가 정하는가 | 보호 대상 |
|---|---|---|
| **rwnd** | 수신 측의 광고 윈도우 | 수신 버퍼 용량 |
| **cwnd** | 송신 측 혼잡 제어 | 네트워크 경로의 혼잡 |

TCP의 실제 미확인 데이터 한도는 두 값과 이미 전송한 데이터량을 함께 고려. **슬라이딩 윈도우** 자체를 수신 흐름 제어 하나와 동일시하지 않음.

## Ⅴ. 한계와 대응

| 한계 | 대응 |
|---|---|
| 작은 윈도우와 긴 RTT로 인한 유휴 시간 | 수신 버퍼·윈도우 확장 지원·경로 조건 검토 |
| rwnd=0 상태의 지속 | 윈도우 갱신 확인을 위한 영속 타이머·프로브 |
| 혼잡을 고려하지 않은 연속 전송 | cwnd와 ACK·손실 신호를 함께 반영 |

## Ⅵ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 고속·장거리 경로에서 송신 윈도우 부족으로 전송 중단 | RTT·수신 버퍼·cwnd를 측정하고 실제 병목 한도에 맞춰 윈도우 설정 조정 |
