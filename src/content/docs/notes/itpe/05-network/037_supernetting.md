## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → IP 주소와 라우팅 → CIDR 기반 경로 집약

## 30초 인출

- 본질: **슈퍼네팅 (Supernetting)** 은 연속된 IP 주소 블록의 공통 접두사를 광고해 여러 구체 경로를 하나의 요약 경로로 표현하는 방법
- 메커니즘: 주소 경계 정렬과 도달성 확인 → 요약 경로 광고 → 내부의 더 구체적인 경로로 전달
- 통찰: 클래스풀 경계를 초월하여 연속된 복수의 네트워크 주소를 공통 최상위 비트(Prefix)로 집약(Aggregation)함으로써 인터넷 백본 라우터의 라우팅 테이블 크기를 획기적으로 축소하는 CIDR 기반 경로 요약 기술임.

<details>
<summary>핵심 용어</summary>

- **슈퍼네팅 (Supernetting)** : 연속된 주소 블록을 더 짧은 접두사의 요약 경로로 나타내는 주소·경로 집약 방식.
- **CIDR (Classless Inter-Domain Routing)** : 클래스 구분 대신 접두사 길이로 IPv4 주소 블록을 할당·라우팅하는 체계.
- **경로 집약 (Route Aggregation)** : 여러 도달 가능한 세부 경로를 하나의 상위 접두사 경로로 광고하는 처리.
- **최장 접두사 일치 (Longest Prefix Match)** : 목적지 주소와 일치하는 경로 중 접두사가 가장 긴 경로를 선택하는 포워딩 규칙.
- **Null0 경로** : 요약 범위 안에 실제 도달 경로가 없는 목적지 패킷을 폐기하는 경로.

</details>

## 2~4교시 25점 답안

## Ⅰ. 슈퍼네팅(Supernetting)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 연속된 여러 개의 소규모 C 클래스 네트워크 주소들을 서브넷 마스크 비트를 좌측으로 이동(Prefix 축약)시켜 단일 상위 대형 네트워크로 병합(CIDR 기반 집약)하는 기법 |
| 목적 | 전 세계 인터넷 백본 BGP 라우터의 라우팅 테이블 엔트리 폭증 억제, 라우터 포워딩 메모리(TCAM) 절감 및 경로 플래핑(Flapping) 전파 차단 |

## Ⅱ. 슈퍼네팅(Supernetting)의 특징

| 특징 | 상세 내용 |
|---|---|
| 네트워크 비트 축약 | 서브네팅과 정반대로 마스크 길이를 줄여(예: /24 -> /22) 복수 주소 대역을 단일 접두사로 포함 |
| 2의 거듭제곱 연속성 | 병합하려는 서브넷 개수는 반드시 2^n개(2, 4, 8, 16...)여야 하며 블록이 수치상 연속되어야 함 |
| 시작 주소 배수 제약 | 슈퍼넷의 첫 번째 네트워크 주소는 반드시 전체 블록 크기의 정수 배수여야 유효한 요약 성립 |
| 경로 플래핑 격리 | 하위 개별 서브넷의 링크 장애 시에도 상위 집약 경로가 유지되어 외부 백본망의 불필요한 재계산 방지 |

## Ⅲ. 슈퍼네팅(Supernetting)의 체계·프로세스

**슈퍼네팅 4개 C클래스 병합 비트 연산 메커니즘**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 슈퍼네팅 공통 프리픽스 추출 연산 ]            │
│                                                                        │
│   병합 대상 4개 네트워크 (연속된 C 클래스)                              │
│   Net 0 : 192.168.0.0/24 ──► [ 11000000.10101000.000000 00.00000000 ]   │
│   Net 1 : 192.168.1.0/24 ──► [ 11000000.10101000.000000 01.00000000 ]   │
│   Net 2 : 192.168.2.0/24 ──► [ 11000000.10101000.000000 10.00000000 ]   │
│   Net 3 : 192.168.3.0/24 ──► [ 11000000.10101000.000000 11.00000000 ]   │
│                               │◄────── 공통 22비트 일치 ─────►│        │
│                                                                        │
│   ▼ 슈퍼넷 마스크 도출: 22비트 1 세팅 (255.255.252.0, /22)             │
│                                                                        │
│   [ 요약된 슈퍼넷 경로 ]                                               │
│   = 192.168.0.0/22 (단 1개의 라우팅 엔트리로 백본 전파 완료)          │
└────────────────────────────────────────────────────────────────────────┘
```

| 검증 단계 | 판정 기준 및 공식 | 192.168.0.0/22 적용 결과 |
|---|---|---|
| **블록 개수 검증** | 2^n 개 연속성 | 4개 서브넷 (2^2) -> 충족 |
| **3번째 옥텟 범위** | 0, 1, 2, 3 (연속된 4개 숫자) | 00b, 01b, 10b, 11b -> 충족 |
| **시작 주소 정렬** | 첫 옥텟 값이 블록 크기(4)의 배수 | 0 mod 4 = 0 -> 정렬 충족 |
| **총 가용 호스트 수**| `2^(32-22) - 2 = 1024 - 2` | 총 1,022개 가용 IP 생성 |

## Ⅳ. 슈퍼네팅(Supernetting)의 종류·비교

| 비교 항목 | 서브네팅 (Subnetting) | 슈퍼네팅 (Supernetting) |
|---|---|---|
| **마스크 조작** | 네트워크 비트 확장 (마스크 증가: /24 -> /26)| **네트워크 비트 축약 (마스크 감소: /24 -> /22)**|
| **네트워크 크기** | 단일 대형 망을 복수 소형 망으로 분할 | **복수 소형 연속 망을 단일 대형 망으로 통합** |
| **브로드캐스트 도메인**| 도메인을 쪼개어 ARP 플러딩 트래픽 감소 | 여러 서브넷을 하나의 상위 경로로 묶음 |
| **적용 주요 위치** | 조직 내부 캠퍼스 및 엔터프라이즈 LAN | **기업 경계 라우터(ABR/ASBR) 및 인터넷 백본 BGP**|
| **핵심 목적** | 주소 낭비 방지 및 보안/브로드캐스트 격리 | **전 세계 라우팅 테이블 엔트리 압축 및 메모리 보존**|

## Ⅴ. 슈퍼네팅(Supernetting)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 요약된 슈퍼넷 범위 내에 실제 존재하지 않는 비할당 IP 대역이 포함될 경우 패킷 블랙홀링(Black-holing) 또는 라우팅 루프 발생 | 요약 라우터에 동일 프리픽스의 널 인터페이스(`ip route 192.168.0.0 255.255.252.0 Null0`) 정적 폐기 경로를 필수 연동 |
| 비연속적인 서브넷 주소 블록을 무리하게 요약 시 타 ISP로 가야 할 트래픽까지 오라우팅(Misrouting)되는 경로 누수(Route Leak) | IP 주소 계획 단계부터 지리적·조직적 계층형 어드레싱을 강제하고 BGP Prefix-list 필터링 검증 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
BGP 외부 피어링 및 OSPF ABR 구성 시, 경로 축약을 적용할 때는 반드시 상위 집약 경로와 함께 라우터 내부에 `Null 0` 라우트를 자동 생성하여, 서브넷 중 다운된 특정 대역으로 향하는 패킷이 기본 게이트웨이(0.0.0.0/0)로 재전송되어 상하위 라우터 간 핑퐁 루프가 발생하는 현상을 물리적으로 차단.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 슈퍼네팅 시 Null 0 인터페이스를 통한 라우팅 루프 차단 메커니즘 ]     │
│                                                                        │
│   [ 인터넷 백본 ] ──► 192.168.3.50 (존재하지 않는 가상 IP) 패킷 유입    │
│                             │                                          │
│                             ▼                                          │
│   [ 기업 경계 라우터 (ABR) ]                                           │
│   - 라우팅 테이블: 192.168.0.0/22 via Null0 (집약 블랙홀 경로)         │
│   - 구체적 서브넷: 192.168.0.0/24 (LAN 0), 192.168.1.0/24 (LAN 1)      │
│     (192.168.3.0/24는 아직 미할당 상태)                               │
│                             │                                          │
│                             ▼ LPM 매칭 결과: Null 0 폐기               │
│   (패킷 즉각 안전 폐기 완료 -> 상위 라우터로 되돌아가는 루프 원천 방지) │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 경로 집약 방식 | 동작 프로토콜 | 설정 위치 | 장점 | 주의점 |
|---|---|---|---|---|
| **OSPF Area 요약** | OSPF (area range) | ABR 라우터 | Area 내부 토폴로지 은폐 | 비연속 Area 적용 불가 |
| **BGP 자동 집약** | BGP (auto-summary) | BGP 경계 라우터 | 클래스풀 단위 자동 요약 | 서브넷 정보 유실 위험으로 비권장 |
| **BGP 수동 집약** | BGP (aggregate-address)| BGP 스피커 | 정밀한 비트마스크 요약 | summary-only 옵션 검증 필수 |
