## 연관 키워드

- 슈퍼네팅(Supernetting), 경로 요약(Route Aggregation), CIDR(Classless Inter-Domain Routing)
- 슈퍼넷 마스크, 최장 접두사 일치(LPM), 블랙홀링(Blackholing)
- Null0 경로, 계층적 주소 설계, BGP 경로 필터링

## Ⅰ. 슈퍼네팅의 개요

- 핵심 요약 : 연속된 여러 소규모 네트워크를 공통 접두사 하나로 묶어 라우팅 정보를 줄이는 기법.
- 개념 : 연속된 복수의 네트워크 대역을 상위 공통 비트 기준의 단일 접두사로 합쳐 하나의 경로로 광고하는 **경로 요약** (Route Aggregation) 기법인 **슈퍼네팅** (Supernetting). 클래스 기반 주소 체계의 한계를 넘기 위해 도입된 **CIDR** (Classless Inter-Domain Routing) 체계 위에서 동작함.
- 배경 및 필요성 : 클래스풀(Classful) 어드레싱의 주소 낭비와 함께, 인터넷 백본 라우터의 라우팅 테이블이 경로 수 폭증으로 포화되는 문제가 대두됨.
- 주요 목적 : 라우팅 테이블의 축소와 전달 자원의 확보, 하위 망 경로 변동의 외부 전파 차단.

## Ⅱ. 슈퍼네팅의 특징 및 장점

- 핵심 요약 : 공통 접두사 도출과 구체 경로 우선 선택의 조합이 라우팅 규모 축소와 정확한 전달을 동시에 보장하는 구조.

1. **프리픽스 축약** (Prefix Aggregation) : 마스크의 네트워크 비트를 줄여 공통 상위 비트만 남김 → 복수 대역이 하나의 경로로 광고됨.
2. **최장 접두사 일치** (LPM, Longest Prefix Match) : 라우터가 가장 구체적인(접두사가 긴) 경로를 우선 선택 → 요약 경로 안의 세부 경로로의 정확한 전달 유지.
3. 플래핑(Flapping, 링크의 반복적 상·하 변동) 격리 : 요약 경로 뒤쪽의 링크 변동이 외부 광고에 반영되지 않음 → 백본 경로의 안정성과 갱신 트래픽 절감.
4. 자원 효율 : 경로 수 감소로 전달 정보 기억 장치와 경로 계산 부하가 감소 → 안정적인 고속 포워딩 확보.

## Ⅲ. 슈퍼네팅의 구조 (흐름)

- 핵심 요약 : 공통 상위 비트 도출이라는 연산 규칙과 연속성·개수·정렬이라는 세 가지 성립 조건으로 구성됨.
- 성립 조건 : 요약 대상 블록이 주소 공간상 연속되어야 하고, 대상 개수는 2의 거듭제곱(2, 4, 8...)이어야 하며, 대표 주소는 블록 크기의 배수로 정렬되어야 함.

```text
[ 경로 집약 연산 흐름 ]

연속된 /24 네트워크 4개 (192.168.0~3)
    ↓ 공통 상위 비트 확인
슈퍼넷 마스크 /22 (255.255.252.0) 도출
    ↓
대표 경로 192.168.0.0/22 단일 광고
```

- 적용 위치 : 요약은 경계 장비에서 수행되며, 대표적으로 BGP(Border Gateway Protocol) 피어링 지점과 OSPF(Open Shortest Path First) 영역 경계 라우터임.

```text
[ 요약 경로와 세부 경로 관계 ]

외부 백본 : /22 요약 경로 단일 광고
    ↓ 경계 라우터의 세부 경로 조회
내부 세부 경로 (/24 단위)
    ↓
최장 접두사 일치로 목적지 전달
```

## Ⅳ. 슈퍼네팅과 서브네팅의 비교

- 핵심 요약 : 서브네팅은 네트워크 비트를 늘려 주소를 쪼개고, 슈퍼네팅은 네트워크 비트를 줄여 주소를 묶는 반대 방향의 기법.

| 비교 항목 | 서브네팅(Subnetting) | 슈퍼네팅(Supernetting) |
| --- | --- | --- |
| 마스크 조작 | 네트워크 비트 확장 (/24→/26) | 네트워크 비트 축약 (/24→/22) |
| 적용 목적 | 주소 절약과 세그먼트 분할 | 라우팅 테이블 축소와 백본 안정화 |
| 적용 위치 | 조직 내부 LAN(Local Area Network) | ISP(Internet Service Provider) 경계와 BGP 백본 |
| 경로 수 변화 | 세부 경로 증가 | 광고 경로 감소 |
| 플래핑 전파 | 세그먼트 변동이 상위에 전파 가능 | 내부 변동이 외부에 숨겨짐 |

- 선택 기준 : 주소 활용 효율 문제는 서브네팅으로, 백본 규모와 안정성 문제는 슈퍼네팅으로 접근하되, 계층적 주소 설계가 양쪽의 전제가 됨.

## Ⅴ. 슈퍼네팅의 한계와 방안

- 핵심 요약 : 미할당 대역의 폐기 처리, 비연속 대역의 광고 금지, 과잉 집약 통제를 Null0 경로와 필터링으로 해결.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 요약 범위 안의 미할당 주소 | 목적지 없는 트래픽이 상위 기본 경로와 요약 경로 사이를 순환하는 **블랙홀링**·루프 발생 | 요약 라우터에 요약 프리픽스를 가리키는 Null0 폐기 경로 등록 | 폐기 트래픽 비율 |
| 비연속 대역의 잘못된 집약 | 다른 지역에 흩어진 대역을 묶어 엉뚱한 경로로 유입되는 서비스 장애 | 계층적 주소 설계 준수와 BGP 경로 필터링으로 광고 범위 통제 | 오광고 경로 건수 |
| 과잉 집약에 의한 가시성 상실 | 세부 경로가 숨겨져 장애 지점 추적과 정밀 제어가 곤란 | 필요 구간에 한한 세부 경로 유출(De-aggregation) 절차 운영 | 세부 경로 노출 구간 수 |

## Ⅵ. 슈퍼네팅에 대한 기술사적 제언

- 핵심 요약 : 주소 할당 단계부터 계층 구조를 설계하고, 경계 장비 설정의 표준 템플릿에 방어 경로를 내장하는 방향.

1. 주소 관리 조직은 지역·기능 단위로 주소 블록을 2의 거듭제곱 크기로 사전 배정하는 IP 주소 관리 규정을 운영해, 집약 가능한 구조를 할당 단계에서 확보할 필요가 있음.
2. 네트워크 운영 조직은 경계 장비 설정 템플릿에 요약 경로와 Null0 폐기 경로의 동시 등록을 표준 항목으로 포함해, 설정 누락에 의한 루프를 구조적으로 차단해야 함.
3. 상호접속 담당 부서는 BGP 피어링 계약에 광고 가능한 프리픽스 범위와 필터링 정책을 명시하고, 경로 누출 방지 점검을 정기 모니터링 항목으로 두어야 함.

## Ⅶ. 결론

- 핵심 요약 : 슈퍼네팅은 계층적 주소 구조 위에서만 안전하게 효과를 내는 경로 요약 기술임.
- 시사점 : 요약의 이득은 주소 설계의 질에 비례하므로, 할당 단계의 계층 설계가 인터넷 라우팅 확장성의 출발점임.
