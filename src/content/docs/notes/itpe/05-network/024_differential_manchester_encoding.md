## Ⅰ. 차동 맨체스터 부호화의 개요

- 개념 : 디지털 2진 비트열을 물리적 전기 신호로 전송할 때, 매 비트 시간(Bit Time)의 정중앙에서 항상 전압 전이(Transition)를 발생시켜 자체 클록 동기화를 제공하고, 비트 값(0 또는 1)은 비트 구간 시작점에서의 전이 유무로 판별하는 **물리 계층(L1)** 부호화 방식.
- 배경 및 필요성 : 단순 **NRZ(Non-Return-to-Zero)** 부호화는 동일 비트(0 또는 1)가 연속될 때 신호 변화가 없어 수신단 클록 동기화가 파괴되고 직류 성분(DC Offset)이 누적되는 문제가 있어, 동기화가 필수적인 LAN(Local Area Network) 표준(IEEE(Institute of Electrical and Electronics Engineers) 802.5 토큰링)을 위해 제정됨.
- 핵심 목적 : 데이터 신호 자체에 완전한 클록 신호 내재화(Self-Clocking), 전송 선로의 결선 극성 반전(Polarity Inversion)에 무관한 안정적 통신 보장, 기저대역 직류 성분 제거.

## Ⅱ. 차동 맨체스터 부호화의 핵심 아키텍처 및 동작 메커니즘

차동 맨체스터 부호화는 매 비트 중간 전이로 수신단 **PLL** 클록을 복원하며, 비트 시작 시점의 전이 존재 여부로 '0'과 '1'을 식별하는 차동 논리 메커니즘으로 동작함.

```text
[ 차동 맨체스터 부호화 신호 파형 및 판별 규칙 ]

판별 규칙 (IEEE 802.5 표준 기준):
 - 비트 중간 전이: 항상 존재 (클록 동기화용: Low->High 또는 High->Low)
 - 비트 시작점 전이 있음: 비트 '0'
 - 비트 시작점 전이 없음: 비트 '1'

비트열:        [  0  ]      [  1  ]      [  0  ]      [  0  ]
신호 레벨:
+V   ──┐      ┌──┐         ┌──┐         ┌──┐         ┌──┐
       │      │  │         │  │         │  │         │  │
-V     └──┐───┘  └──┐──────┘  └──┐───┐──┘  └──┐───┐──┘  └──
       ▲  ▲         ▲            ▲   ▲        ▲   ▲
       │  │         │            │   │        │   │
  비트시작 중간    중간         비트시작 중간 비트시작 중간
  (전이O) (전이)   (전이만)     (전이O) (전이)(전이O) (전이)
   => '0'           => '1'        => '0'       => '0'
```

- **자체 클록 동기화(Self-Clocking)** : 비트 시간 중간에서 반드시 극성이 바뀌므로 연속된 0이나 1이 지속되더라도 수신단은 매 비트마다 정확한 클록 에지(Edge)를 추출 가능.
- **차동 판별(Differential Detection)** : 절대적인 전압 레벨(+V, -V)이 아니라 '이전 상태로부터의 전이(Transition) 유무'로 비트를 판별하므로 선로 배선이 뒤바뀌어도 데이터 왜곡 없음.
- **DC 성분 억제(DC Balance)** : 매 비트 구간 동안 양전압과 음전압이 균등하게 절반씩 존재하므로 신호의 평균 전압이 0에 수렴하여 변압기 결합(Transformer Coupling)에 매우 유리.
- **보드 레이트(Baud Rate) 증가** : 1비트를 표현하기 위해 최대 2회의 전압 변화가 발생하므로 데이터 전송률(bps)의 2배에 달하는 대역폭(Nyquist Bandwidth) 소비.

## Ⅲ. 차동 맨체스터 부호화의 세부 구성 요소 및 비교 분석

| 비교 항목 | NRZ-L (단순 복극성) | 맨체스터 (IEEE 802.3 이더넷) | 차동 맨체스터 (IEEE 802.5 토큰링) |
|---|---|---|---|
| 비트 판정 기준 | 전압의 절대 레벨 (High/Low) | 비트 중간 전이의 방향 (상승/하강) | 비트 시작점에서의 전이 유무 |
| 클록 동기화 | 불가능 (연속 0/1 시 동기 상실) | 우수 (중간 전이 활용) | 우수 (중간 전이 활용) |
| 극성 반전 내성 | 취약 (선로 바뀌면 0과 1 반전) | 취약 (전이 방향 바뀌어 오류 발생) | 완벽 지원 (전이 유무만 보므로 무관)|
| 필요 대역폭 | $B$ (비트레이트 수준) | $2B$ (비트레이트의 2배 소비) | $2B$ (비트레이트의 2배 소비) |
| DC 직류 성분 | 심각한 DC 바이어스 누적 | 완전 제거 (DC Balance) | 완전 제거 (DC Balance) |
| 주요 적용 분야 | RS-232C, 내부 버스 | 10BASE-T 이더넷 | 토큰링, 산업용 필드버스(Profibus) |

- 표준 맨체스터가 배선 반전에 취약한 반면, 차동 맨체스터는 선로 극성이 뒤바뀌어도 비트 시작점의 전이 유무만으로 완벽한 복원이 가능하여 가혹한 산업 현장 배선 환경에 최적화됨.

## Ⅳ. 차동 맨체스터 부호화의 주요 한계점 및 해결 방안

- 데이터 비트레이트 대비 2배의 대역폭(Baud) 소모로 인한 고속화 한계 :
  - 한계점 : 100Mbps 이상의 고속 통신 환경에서 신호 주파수가 200MHz로 증가하여 구리 케이블의 고주파 감쇠 급증.
  - 해결 방안 : 고속 이더넷에서는 4B/5B, 8B/10B 등 블록 부호화나 PAM(Pulse Amplitude Modulation)-4 다준위 부호화로 전환.
- 고빈도 스위칭에 따른 전자파 간섭(EMI) 및 누화(Crosstalk) 발생 :
  - 한계점 : 신호 전이 빈도가 높아 케이블 외부로 고주파 노이즈가 방출되어 인접 신호선에 간섭 유발.
  - 해결 방안 : 차폐 트위스티드 페어(STP) 케이블 사용 및 슬루 레이트(Slew Rate) 제한 회로 적용.
- 클록 지터(Jitter) 누적으로 인한 시작점 전이 샘플링 마진 축소 :
  - 한계점 : 장거리 전송 시 케이블 분산 특성으로 에지가 왜곡되어 비트 시작점 전이 여부 판정 오류 발생.
  - 해결 방안 : 고정밀 디지털 위상동기루프(DPLL) 클록 복원 칩셋 채택 및 케이블 이퀄라이저 회로 보강.

## Ⅴ. 차동 맨체스터 부호화 적용 및 발전을 위한 기술사적 제언

- 노이즈가 극심한 산업용 임베디드 및 철도/항공 제어망 적용 : 극성 역결선 실수가 잦고 전자기 노이즈가 심한 가혹 환경의 필드버스 통신 링크에 차동 맨체스터의 높은 신뢰성 활용 권장.
- 물리 계층 보안 및 신호 무결성(Signal Integrity) 계측 표준화 : 오실로스코프 아이 다이어그램(Eye Diagram)을 통해 중간 전이 에지의 지터 폭을 정기 측정하여 선로 열화 사전 진단 체계 수립.
- 현대 고속 라인 코딩 기술과의 진화론적 연계 교육 : 차동 맨체스터의 직류 평형 원리가 차세대 PCIe(Peripheral Component Interconnect Express) 및 SerDes의 8b/10b, 128b/130b 스크램블링 기술로 계승 발전한 계보를 이해하고 시스템 설계에 응용.
