지식 위치: 네트워크 → 물리 계층 부호화 → **차동 맨체스터 부호화**

## 30초 인출

- 본질: **차동 맨체스터 부호화(Differential Manchester Encoding)** : 비트 경계의 전이 유무로 데이터를 표시하고 비트 중앙 전이로 수신 동기를 제공하는 선로 부호
- 메커니즘: 매 비트 중앙에서 전이 → 비트 시작 전이 여부를 판정 → 비트값 복원
- 통찰: 신호의 절대적인 전압 레벨 대신 비트 시작 시점의 전이(Transition) 유무로 '0'과 '1'을 판정하고 비트 중간에서는 항상 전이를 발생시켜 데이터 전송과 클록 동기화를 동시에 완벽하게 달성하는 물리 계층 선로 부호화 기법임.

<details>
<summary>핵심 용어</summary>

- **차동 맨체스터 부호화(Differential Manchester Encoding)** : 비트 중앙 전이를 유지하며 비트 경계의 전이 여부로 정보를 표현하는 부호
- **비트 경계 전이(Bit-boundary Transition)** : 이 부호에서 비트값을 나타내는 비트 시작 시점의 신호 변화
- **자가 클로킹(Self-clocking)** : 신호의 규칙적인 전이에서 수신 타이밍을 복원하는 성질
- **극성 반전(Polarity Inversion)** : 송수신 배선·회로 극성 변화로 신호의 High와 Low가 뒤바뀌는 현상; 차동 판정은 절대 레벨에 의존하지 않음
- **라인 코딩(Line Coding)** : 비트열을 전송 매체에 맞는 신호 파형으로 표현하는 방식

## 2~4교시 25점 답안

## Ⅰ. 차동 맨체스터 인코딩의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 비트 시간의 정중앙(Mid-bit)에서는 항상 신호 전이가 발생하여 클록을 제공하고, 비트 구간의 시작점(Bit Boundary)에 전이가 존재하는지 여부에 따라 2진 비트(0 또는 1)를 구별하는 차동 방식의 2단계(Biphase) 선로 부호화 기법 |
| 목적 | 수신측 클록 복원(Clock Recovery) 용이화, 직류 성분 누적 방지 및 전선 극성 반전(Polarity Inversion) 오류 극복 |

## Ⅱ. 차동 맨체스터 인코딩의 특징

| 특징 | 상세 내용 |
|---|---|
| 자체 클록 동기(Self-clocking)| 모든 비트 중앙에서 반드시 전이가 발생하므로 별도의 클록 신호선 없이 데이터선에서 동기 추출 |
| 차동 논리 판정 | 신호의 High/Low 절대 전압이 아닌 직전 상태 대비 '전이 유무'로 판정하여 역극성 케이블 연결에도 불변 |
| DC 바이어스 제거 | 각 비트 주기 동안 절반은 양(+) 전압, 절반은 음(-) 전압을 유지하여 평균 직류 전압을 0으로 유지 |
| 2배 대역폭 요구 | 1비트를 전송하기 위해 2번의 전이가 발생할 수 있어 기본 신호 대역폭의 2배(Baud Rate = 2 * Bit Rate) 필요 |

## Ⅲ. 차동 맨체스터 인코딩의 체계·프로세스

**차동 맨체스터 신호 파형 및 비트 판정 타이밍도**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ 차동 맨체스터 신호 전이 타이밍도 ]            │
│                                                                        │
│ 비트 스트림:   │   '0'   │   '1'   │   '0'   │   '0'   │   '1'   │     │
│                │ (전이O) │ (전이X) │ (전이O) │ (전이O) │ (전이X) │     │
│ ───────────────┼─────────┼─────────┼─────────┼─────────┼─────────┼──── │
│                │  ┌──┐   │         │  ┌──┐   │  ┌──┐   │         │     │
│  +V ───────────┼──┘  │   │     ┌───┼──┘  │   ├──┘  │   │     ┌───┤     │
│                │     │   │     │   │     │   │     │   │     │   │     │
│  -V ───────────┤     └───┴─────┘   │     └───┤     └───┴─────┘   │     │
│ ───────────────┼────▲────┼────▲────┼────▲────┼────▲────┼────▲────┼──── │
│                │    │    │    │    │    │    │    │    │    │    │     │
│ [ 비트 중앙 전이]  항상전이 항상전이 항상전이 항상전이 항상전이 (클록 동기)│
│ [ 비트 시작 전이]  전이발생 전이없음 전이발생 전이발생 전이없음 (비트 판정)│
│   * 통상 규격: 비트 시작점에 전이 있음 = '0', 전이 없음(이전 상태 유지) = '1' │
└────────────────────────────────────────────────────────────────────────┘
```

| 판정 시점 | 신호 동작 규칙 | 비트 의미 및 역할 |
|---|---|---|
| **비트 시작점 (Boundary)** | 전이(Transition) 발생 시 | 비트 **'0'** 으로 판정 |
| **비트 시작점 (Boundary)** | 전이 없음 (이전 상태 유지)| 비트 **'1'** 으로 판정 |
| **비트 중앙점 (Mid-bit)** | 무조건 신호 반전 전이 발생 | 수신측 PLL 클록 추출(동기화) 전용 |
| **직류 균형 (DC Balance)**| High 시간 = Low 시간 동일 | 전송 선로 트랜스포머의 직류 포화 완벽 차단 |

## Ⅳ. 차동 맨체스터 인코딩의 종류·비교

| 비교 항목 | NRZ-L (Non-Return-to-Zero) | 맨체스터 (Manchester) | 차동 맨체스터 (Differential) |
|---|---|---|---|
| **신호 레벨 수** | 2 레벨 (+V, -V) | 2 레벨 (Biphase) | 2 레벨 (Biphase) |
| **비트 '0' 표현** | High (+V) 레벨 | High ──► Low 전이 | **시작점에 전이 있음** |
| **비트 '1' 표현** | Low (-V) 레벨 | Low ──► High 전이 | **시작점에 전이 없음** |
| **자체 클록 동기** | 불가 (연속 0/1 시 동기 상실)| 완벽함 (비트 중앙 전이) | **완벽함 (비트 중앙 전이)** |
| **케이블 역극성 내성**| 취약 (극성 반전 시 0/1 역전)| 취약 (0과 1이 뒤바뀜) | **완벽 내성 (상대적 전이 판정)** |
| **대표 표준** | RS-232 직렬 통신 | IEEE 802.3 10Base-T 이더넷 | **IEEE 802.5 토큰링 망** |

## Ⅴ. 차동 맨체스터 인코딩의 한계와 방안

| 한계 | 방안 |
|---|---|
| 1비트 전송에 2회의 보(Baud) 변화가 요구되어 주파수 대역폭 소모가 NRZ 대비 2배로 증가 | 고속 통신망에서는 4비트를 5비트로 변환하는 4B/5B 및 다단계 심볼 부호화(MLT-3, PAM-4) 적용 |
| 잡음으로 인해 특정 비트의 시작 전이를 오인식할 경우 후속 비트 전체에 전이 오차가 전파되는 현상 | 프레임 헤더에 명시적인 프리앰블(Preamble) 및 고정 위상 재동기화 패턴 주기적 삽입 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
선박, 철도, 산업용 플랜트 등 전기적 노이즈가 극심하고 케이블 배선 시 오결선(극성 반전) 위험이 높은 열악한 산업용 버스 제어망 구축 시, 절대 전압에 민감한 NRZ 방식을 배제하고 차동 맨체스터 인코딩을 적용하여 통신 신뢰성을 담보.

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 차동 맨체스터 송신 인코더 논리 회로 구조 ]                          │
│                                                                        │
│   데이터 비트 (Data) ──► [ 인버터 ] ──┐                                │
│                                       ├──► [ D 플립플롭 / XOR 게이트 ] │
│   동기 클록 (Clock)  ─────────────────┘           │                   │
│                                                   ▼                    │
│                                     차동 맨체스터 인코딩 출력 신호     │
│                                     (비트 시작 전이 + 중앙 클록 전이)   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 선로 부호 방식 | 클록 추출 용이성 | 직류 성분 유무 | 대역폭 효율 | 주 적용 분야 |
|---|---|---|---|---|
| **NRZ-L / NRZ-I** | 나쁨 (연속 비트 시 난해) | 높음 (신호 왜곡 발생) | 최우수 (1 bps/Hz) | 컴퓨터 내부 버스 |
| **Manchester** | 최우수 (중앙 전이 보장) | 없음 (0V 평형) | 낮음 (0.5 bps/Hz) | 10Mbps 레거시 이더넷 |
| **Diff Manchester**| 최우수 + 극성 불감 | 없음 (0V 평형) | 낮음 (0.5 bps/Hz) | 토큰링, 안전 산업 통신망 |
