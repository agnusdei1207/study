## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 핵심 개념 → 차동 맨체스터 부호화

## 30초 인출

- 본질: 연속된 0이나 1 전송 시 신호 전이가 없어 수신측 클록 동기가 풀리는 문제
- 메커니즘: 비트 중앙에서 무조건 전이를 일으켜 동기를 맞추고, 비트 시작점의 전이 유무로 데이터를 표현

## 핵심 용어

- 자가 클록 동기화(Self-Clocking): 별도의 클록 신호선 없이 데이터 신호 자체에 포함된 주기적 전이(비트 중간 전이)로부터 수신측이 수신 타이밍을 복원하는 능력
- 직류 성분(DC Component / DC Wandering): 신호의 평균 전압이 0이 되지 않고 양이나 음으로 편향되어 변압기 결합 회로나 커패시터를 통과할 때 왜곡을 일으키는 현상
- 극성 무관(Polarity Insensitive): 전선 2가닥(꼬임선)의 +와 -가 물리적으로 거꾸로 결선되어도, 절대 전압이 아닌 "전이 유무(차동)"로 판별하므로 정상 복구되는 성질

## 1교시 10점 답안

### 정의·목적

- 정의: 차동 맨체스터 부호화은/는 비트 중앙에서 무조건 전이를 일으켜 동기를 맞추고, 비트 시작점의 전이 유무로 데이터를 표현 방식이다.
- 목적: 절대 전압 극성이 뒤집혀도 완벽한 복원 가능에 기여한다.

### 핵심 구조와 작동

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
[ 차동 맨체스터 부호화 규칙 및 파형 예시 ]

- 규칙:
  * 비트 중간: 무조건 전이 발생 (자가 클록 동기화 용도)
  * 비트 시작: 비트 '0'이면 전이 있음 / 비트 '1'이면 전이 없음 (이전 신호 유지)

입력 비트:    |     0     |     1     |     0     |     0     |     1     |
클록 신호:    +-+   +-+   +-+   +-+   +-+   +-+   +-+   +-+   +-+   +-+
              | |   | |   | |   | |   | |   | |   | |   | |   | |   | |
            --+ +---+ +---+ +---+ +---+ +---+ +---+ +---+ +---+ +---+ +---+---
신호 파형:
  (시작=Low)
 High        +-----+     +-----+     +-----+           +-----+
             |     |     |     |     |     |           |     |
 Low   ------+     +-----+     +-----+     +-----+-----+     +-----+
             ^     ^     ^     ^     ^     ^     ^     ^     ^     ^
          (전이) (중간) (유지) (중간) (전이) (중간) (전이) (중간) (유지) (중간)
          (Bit 0)       (Bit 1)       (Bit 0)       (Bit 0)       (Bit 1)
```

### Ⅱ. 핵심 특성

- 일반 맨체스터 부호화(이더넷 802.3)는 High→Low를 0, Low→High를 1로 해석하므로 전선 가닥이 반대로 꽂히면 데이터가 0과 1이 뒤집히는 치명적 문제 발생
- 차동 맨체스터는 "절대 레벨"이 아니라 "직전 상태와의 차이(전이가 있는가 없는가)"만을 읽기 때문에 배선 극성 역전(Reverse Polarity) 사고에 면역
- 비트당 최소 1회~최대 2회의 전이가 발생하므로 보드 레이트(Baud Rate)가 비트 레이트의 2배가 됨 → 고속 광통신(10Gbps 이상)에는 부적합하여 4B/5B, 8B/10B 또는 다준위 PAM4로 진화

### Ⅲ. 관련 개념과 구분

- 맨체스터 vs 차동 맨체스터: 맨체스터는 비트 중간의 전이 방향(상승/하강)으로 데이터를 결정 / 차동 맨체스터는 비트 시작점의 전이 유무(Transition vs No Transition)로 데이터를 결정

### Ⅳ. 적용 문제와 대응

- 적용 상황: 열악한 산업용 공장 제어선로 배선
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 현장 작업자의 UTP 케이블 극성 반대 결선 | 물리 결선 실수로 수신 신호의 전압 반전 발생 | 차동 맨체스터(Differential Manchester) 부호화 채택 | 전선 극성 반전과 무관하게 데이터 100% 정상 수신 |
| 장거리 전송 시 고주파 성분 감쇠 왜곡 | 비트 중간 전이 강제로 인한 신호 대역폭 2배 증가 | 스크램블러(Scrambler) 결합 다준위(MLT-3/PAM) 부호화 전환 | 신호 전이 빈도를 낮춰 대역폭 소모 50% 절감 |

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 적용 환경에서 발생하는 핵심 제약 | 기존 대책을 적용하고 핵심 운영 지표를 확인해 개선한다. |
