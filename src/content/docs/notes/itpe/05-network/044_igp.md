<details>
<summary>핵심 용어</summary>

- **IGP (Interior Gateway Protocol)** : 하나의 자율 시스템 안에서 라우팅 정보를 교환하는 프로토콜 범주.
- **AS (Autonomous System)** : 공통 라우팅 정책 아래 운영되는 네트워크 집합.
- **거리벡터 (Distance Vector)** : 이웃에게 목적지까지의 거리 정보를 주고받아 경로를 계산하는 라우팅 방식.
- **링크 상태 (Link State)** : 링크 상태 정보를 배포해 토폴로지 데이터베이스를 만들고 경로를 계산하는 방식.
- **SPF (Shortest Path First)** : 링크 상태 데이터베이스에 최단 경로 우선 계산을 적용하는 알고리즘 계열.
- **RIP (Routing Information Protocol)** : 홉 수를 메트릭으로 사용하는 거리벡터 IGP.
- **OSPF (Open Shortest Path First)** : 링크 상태 기반 IGP. 영역과 링크 상태 정보를 이용해 경로 계산.
- **IS-IS (Intermediate System to Intermediate System)** : 링크 상태 기반 내부 라우팅 프로토콜.
- **BFD (Bidirectional Forwarding Detection)** : 전달 경로의 장애를 빠르게 감지하기 위한 프로토콜.

| 방식 | 정보 교환·계산 | 예 |
|---|---|---|
| 거리벡터 | 이웃과 목적지 거리 교환 | RIP |

```text
IGP: AS 내부 라우팅
    ├── 거리벡터: 이웃 경유 거리 정보

```

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **IGP (Interior Gateway Protocol)** 는 하나의 자율 시스템 내부에서 라우팅 정보를 교환하고 경로를 계산하는 프로토콜 범주 |
| 목적 | AS 내부의 목적지 도달성과 경로 갱신 지원 |

## Ⅱ. 라우팅 방식의 분류

```text
AS 내부 라우팅
    ├── 거리벡터 ── RIP
    └── 링크 상태
            ├── OSPF
            └── IS-IS
```

방식·프로토콜의 정적 분류. 선은 상하위·분류 관계이며 시간 순서나 패킷 흐름이 아님.

## Ⅲ. 정보 교환과 경로 계산

| 비교축 | 거리벡터 | 링크 상태 |
|---|---|---|
| 교환 정보 | 목적지까지의 거리와 다음 홉 | 인접 링크 상태·비용 |
| 계산 관점 | 이웃의 경로 정보를 반영 | 토폴로지 데이터베이스에서 경로 계산 |
| 대표 예 | RIP | OSPF, IS-IS |
| 운영 고려 | 수렴 특성·루프 방지 기능 | 영역 설계·상태 정보의 범위와 SPF 부하 |

## Ⅳ. 경로 수렴과 장애 대응

```text
BFD 세션의 인접 경로 감시
        ↓ 장애 감지 통보
연동된 IGP의 인접 상태 갱신
        ↓ 프로토콜별 계산
라우팅 테이블 갱신
```

BFD는 라우팅 계산을 대신하지 않고, 연동된 프로토콜이 전달 경로 장애를 감지하도록 돕는 수단.

| 한계 | 대응 |
|---|---|
| 토폴로지 변화가 잦으면 갱신·계산 부하가 커질 수 있음 | 영역·요약 경로 등 프로토콜 설계와 타이머를 검토 |
| 빠른 장애 감지가 모든 회선·장비 조합에서 동일하지 않음 | BFD 등 지원 여부와 장애 시나리오를 실제 환경에서 시험 |

## Ⅴ. 기술사적 제언 — 규모에 맞춘 영역·장애감지 설계

| 한계 | 해결 방안 |
|---|---|
| 단일 메트릭·타이머 설정만으로 성능과 복구 품질을 판단하기 어려움 | 서비스 경로와 토폴로지에 맞는 메트릭·영역을 설계하고, 정상·장애 상황에서 수렴시간과 경로 안정성을 검증 |

## 출제 이력과 검증 출처
