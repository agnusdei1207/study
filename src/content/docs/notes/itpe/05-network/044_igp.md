## 30초 인출

- 본질: 관리자가 수천 개 내부 경로를 수작업으로 입력하는 정적 라우팅의 유지보수 불가능성
- 메커니즘: 단일 AS 내부에서 라우터들이 링크 상태와 홉 수를 자동으로 주고받아 최단 경로를 실시간 계산

## 핵심 용어

- 링크 상태(Link State): 라우터가 자신에게 직접 연결된 인터페이스의 IP, 서브넷 마스크, 대역폭, 가동 상태를 패킷(LSA)으로 만들어 망 전체에 뿌리는 정보
- 다익스트라 최단 경로(SPF): 그래프 이론에 기반하여 출발지 노드로부터 망 내 모든 목적지 노드까지의 가중치 합이 최소가 되는 최단 경로 트리를 구하는 알고리즘
- ECMP(Equal-Cost Multi-Path): 목적지까지 가는 비용이 동일한 최적 경로가 여러 개 존재할 때, 트래픽을 두 회선으로 분산시켜 로드밸런싱하는 기술

## 1교시 10점 답안

### 정의·목적

- 정의: IGP은/는 단일 AS 내부에서 라우터들이 링크 상태와 홉 수를 자동으로 주고받아 최단 경로를 실시간 계산 방식이다.
- 목적: 회선 장애 시 자동 우회 수렴 달성에 기여한다.

### 핵심 구조와 작동

```text
[ IGP (내부 게이트웨이 프로토콜) 분류 체계 ]

                      +-------------------------------+
                      |   IGP (AS 내부 라우팅 프로토콜)|
                      +---------------+---------------+
                                      |
         +----------------------------+----------------------------+
         |                                                         |
         v                                                         v
 [ 1. 거리벡터 (Distance Vector) ]               [ 2. 링크상태 (Link State) ]
 - 알고리즘: Bellman-Ford                        - 알고리즘: Dijkstra SPF
 - 특징: 홉수 기반, 이웃 주장 신뢰              - 특징: 전체 토폴로지 지도 공유
 - 프로토콜:                                     - 프로토콜:
   * RIPv1 / RIPv2 (최대 15홉)                     * OSPF (Area 계층 분할, 사실상 표준)
   * EIGRP (DUAL 알고리즘, 복합 메트릭)            * IS-IS (통신사 백본, 대규모 적합)
```

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
[ IGP (내부 게이트웨이 프로토콜) 분류 체계 ]

                      +-------------------------------+
                      |   IGP (AS 내부 라우팅 프로토콜)|
                      +---------------+---------------+
                                      |
         +----------------------------+----------------------------+
         |                                                         |
         v                                                         v
 [ 1. 거리벡터 (Distance Vector) ]               [ 2. 링크상태 (Link State) ]
 - 알고리즘: Bellman-Ford                        - 알고리즘: Dijkstra SPF
 - 특징: 홉수 기반, 이웃 주장 신뢰              - 특징: 전체 토폴로지 지도 공유
 - 프로토콜:                                     - 프로토콜:
   * RIPv1 / RIPv2 (최대 15홉)                     * OSPF (Area 계층 분할, 사실상 표준)
   * EIGRP (DUAL 알고리즘, 복합 메트릭)            * IS-IS (통신사 백본, 대규모 적합)
```

### Ⅱ. 핵심 특성

- IGP는 "단일 조직의 울타리 안"에서 돌기 때문에 복잡한 정치적 정책(Policy)보다는 "어느 선이 가장 빠르고 안 끊어지는가(성능)"가 유일한 판단 기준
- 거리벡터는 이웃 라우터의 "결과표"만 전해 들으므로 루프(Loop)가 생길 위험이 있으나, 링크상태는 모든 라우터가 "원시 지도"를 똑같이 들고 있어 구조적으로 루프 프리(Loop-free)
- 클라우드 대규모 데이터센터(IP Fabric)에서는 과거 복잡한 OSPF 대신 BGP를 AS 내부 IGP처럼 활용하는 "BGP in the Data Center(RFC 7938)" 아키텍처가 최신 트렌드로 급부상

### Ⅲ. 관련 개념과 구분

- IGP vs EGP: IGP는 단일 AS 내부에서 최단 경로로 패킷을 고속 전달 / EGP는 독립된 AS 경계에서 국가나 사업자 간 정책 계약에 따라 트래픽을 통제

### Ⅳ. 적용 문제와 대응

- 적용 상황: 대규모 엔터프라이즈 사옥 간 라우터 링크 플래핑 장애
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 회선 불안정 시 전 라우터 CPU 100% 포화 | OSPF 링크 상태 변경 시마다 즉각적인 SPF 알고리즘 재수행 | SPF 스로틀링(SPF Throttling) 타이머 및 LSA 감쇠 적용 | 연속된 연산을 일정 시간 지연시켜 CPU 과부하 방지 |
| 회선 장애 감지 시간 지연(수십 초) | IGP 기본 Hello/Dead 타이머의 긴 주기(10초/40초) | BFD(Bidirectional Forwarding Detection) 연동 | 50ms 이내에 회선 단절을 감지해 즉각 백업 경로 절체 |

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 적용 환경에서 발생하는 핵심 제약 | 기존 대책을 적용하고 핵심 운영 지표를 확인해 개선한다. |
