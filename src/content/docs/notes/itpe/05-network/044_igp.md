## 연관 키워드

- IGP(Interior Gateway Protocol), 자율 시스템(AS), 거리 벡터(Distance Vector), 링크 상태(Link State)
- Bellman-Ford, Dijkstra SPF, RIP, OSPF, IS-IS, EIGRP, DUAL, 수렴(Convergence)
- Area 0, LSA(Link State Advertisement), 무한 계수(Count-to-Infinity), 수평 분할(Split Horizon)
- BFD(Bidirectional Forwarding Detection), 플래핑(Flapping), 세그먼트 라우팅(SR)

## Ⅰ. IGP의 개요

- 핵심 요약 : 하나의 관리 주체가 운영하는 자율 시스템 내부에서 경로를 자동으로 학습·갱신하는 내부 게이트웨이 라우팅 프로토콜.
- 개념 : 동일한 관리 주체의 **자율 시스템** (AS, Autonomous System) 내부 라우터 사이에서 경로를 학습하고 갱신하는 내부 게이트웨이 프로토콜(IGP, Interior Gateway Protocol).
- 배경 및 필요성 : 기관 망의 규모 확대로 정적 라우팅(Static Routing)의 수작업 경로 관리가 한계에 도달, 링크 장애 시 자동 우회 경로 계산의 필요가 제기.
- 주요 목적 :
  1. 토폴로지 변경 시 빠른 **수렴** (Convergence, 모든 라우터가 동일 경로 정보를 공유하는 상태) 달성
  2. 라우팅 루프 방지와 경로 정보의 일관성 유지
  3. 대역폭 등 링크 특성을 반영한 최적 경로 선택

## Ⅱ. IGP의 특징 및 장점

- 핵심 요약 : 경로 정보 교환 방식에 따라 거리 벡터와 링크 상태, 절충형으로 나뉘며 수렴 속도와 자원 소모의 상충 관계를 형성.

1. **거리 벡터** (Distance Vector) : 인접 라우터와 라우팅 테이블을 주기 교환, Bellman-Ford 알고리즘으로 갱신, 대표 프로토콜은 RIP(Routing Information Protocol) → 구성이 단순하고 자원 소모가 낮음.
2. **링크 상태** (Link State) : 각 라우터가 자신의 링크 상태를 AS 전역에 통보하고 동일 토폴로지 DB에서 Dijkstra SPF(Shortest Path First) 실행, 대표 프로토콜은 OSPF(Open Shortest Path First)와 IS-IS(Intermediate System to Intermediate System) → 빠른 수렴과 루프 없는 경로 확보.
3. 절충형 : EIGRP(Enhanced Interior Gateway Routing Protocol)가 거리 벡터 계열에서 DUAL(Diffusing Update Algorithm)로 백업 경로를 사전 계산 → 장애 시 재계산 없는 즉시 절체.
4. 계층적 확장 : 링크 상태 계열은 **LSA**(Link State Advertisement) 전파 범위를 Area 단위로 제한 → 대규모 망의 플러딩·계산 부담 완화.

## Ⅲ. IGP의 구조 (흐름)

- 핵심 요약 : 거리 벡터는 이웃 정보의 중계 전파, 링크 상태는 전체 지도 공유 후 각자 계산하는 방식의 차이.

```text
[ 링크 상태 방식의 경로 계산 ]

링크 상태 통보(LSA) 플러딩
   ↓
모든 라우터가 동일 토폴로지 DB 구성
   ↓
SPF로 자기 관점의 최단 경로 계산
   ↓
라우팅 테이블 갱신
```

```text
[ OSPF Area 계층 구조 ]

Area 1 → Area 0 (백본) ← Area 2
일반 Area 사이 직접 연결 금지
```

- Area 구조 : 백본 영역인 Area 0을 중심으로 일반 Area를 연결해 LSA 플러딩 범위를 통제하고, **ABR**(Area Border Router)이 Area 사이 경로를 요약하는 계층.

## Ⅳ. IGP 주요 프로토콜의 비교

- 핵심 요약 : 소규모 망은 거리 벡터 계열로 충분하고 대규모 백본은 링크 상태 계열이 수렴·확장성에서 유리한 구분.
- 구분 : AS 내부는 IGP가, AS 경계의 외부 경로는 외부 게이트웨이 프로토콜(EGP, Exterior Gateway Protocol)이 담당하는 이원 구조.

| 비교 항목 | RIPv2 | OSPF | IS-IS | EIGRP |
| --- | --- | --- | --- | --- |
| 유형 | 거리 벡터 | 링크 상태 | 링크 상태 | 절충형 |
| 알고리즘 | Bellman-Ford | Dijkstra SPF | Dijkstra SPF | DUAL |
| 메트릭 | 홉 수 (최대 15) | 대역폭 기반 비용 | 설정 비용 | 대역폭·지연 복합 |
| 계층 구조 | 평면 | Area (백본 Area 0) | Level 1 / Level 2 | 평면 |
| 전송 | UDP(User Datagram Protocol) 520 | IP(Internet Protocol) 프로토콜 89 | 데이터링크 계층 직접 | IP 프로토콜 88 |

- 선택 기준 : 소규모 사이트는 RIPv2로 충분, 대규모 엔터프라이즈는 OSPF, 통신사·대형 데이터센터 백본은 IS-IS를 우선 검토.

## Ⅴ. IGP의 한계와 방안

- 핵심 요약 : 플래핑에 따른 계산 부하, 거리 벡터의 루프, 장애 감지 지연을 타이머·루프 방지 기법·BFD로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 플래핑에 따른 SPF 부하 | 링크의 반복적인 오르내림 → LSA 플러딩과 SPF 재계산 누적으로 CPU 과부하 | SPF 지연 타이머 조정, Area 세분화, ABR 경로 요약 | SPF 실행 횟수, CPU 사용률 |
| 무한 계수(Count-to-Infinity) | 단절 정보의 왜곡 전파 → 메트릭이 최대값까지 증가하는 동안 루프 지속 | **수평 분할**(Split Horizon), 독성 역전, 즉시 갱신, 보류 타이머 병용 | 루프 탐지 건수 |
| 장애 감지 지연 | 긴 헬로 주기로 링크 단절 인지가 늦음 | **BFD**(Bidirectional Forwarding Detection) 연동으로 밀리초 단위 감지 | 장애 감지 시간 |

## Ⅵ. IGP에 대한 기술사적 제언

- 핵심 요약 : 망 규모별 프로토콜 선정 기준의 표준화와 라벨 배포 절차의 단순화로 운영 부담이 낮은 내부 라우팅 체계 구축.

1. 네트워크 운영 조직 : 망 규모·수렴 요구에 따른 프로토콜 선정 기준과 변경 절차를 설계 표준으로 문서화.
2. 백본 설계 조직 : OSPF와 IS-IS 중 이중 스택·확장성 요건에 맞는 프로토콜을 선제 선정하고 Area 설계를 함께 확정.
3. 전환 계획 조직 : LDP(Label Distribution Protocol) 같은 별도 라벨 배포 없이 IGP 확장 정보로 라벨을 배포하는 **세그먼트 라우팅** (SR, Segment Routing) 도입을 단계 로드맵으로 편성.

## Ⅶ. 결론

- 핵심 요약 : IGP는 AS 내부의 경로를 자동으로 학습하고 장애에 대응하는 내부 라우팅의 기반 계층.
- 수렴 속도와 자원 소모의 상충 관계 이해와 규모에 맞는 프로토콜 선정이 안정적 내부 망 운영의 출발점.
