## Ⅰ. Wi-Fi 8 (IEEE 802.11bn UHR)의 개요

- **개념** : 2028년 상용화를 목표로 IEEE 802.11bn 워킹그룹에서 표준화를 진행 중인 차세대 무선랜 규격으로, 처리량 중심에서 탈피하여 초고신뢰성(Ultra High Reliability)과 초저지연을 실현하는 와이파이 기술.
- **배경 및 필요성** : Wi-Fi 7까지의 지속적 속도 향상에도 불구하고 실시간 스트리밍, 클라우드 게이밍, 산업용 제어망 등에서 순간적인 간섭으로 인한 패킷 지연 스파이크(Jitter) 및 전송 끊김 문제 지속.
- **핵심 목적** : 99.999% 무선 전송 신뢰도 달성, 최악 조건(99.9 백분위수) 지연 시간 5ms 이하 억제, 단말의 실효 배터리 수명 25% 이상 향상.

## Ⅱ. Wi-Fi 8의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ Wi-Fi 8 초고신뢰 다중 AP 조정 아키텍처 ]                │
│                                                                        │
│                      ┌──────────────────────┐                          │
│                      │   Edge Coordinator   │                          │
│                      └──────────┬───────────┘                          │
│                                 │ CPO Protocol                         │
│        ┌────────────────────────┴────────────────────────┐             │
│        ▼                                                 ▼             │
│   ┌───────────┐      Co-BF (다중 AP 조정 빔포밍)       ┌───────────┐   │
│   │ Master AP │ ◄────────────────────────────────────► │ Slave AP  │   │
│   └─────┬─────┘      Co-SR (다중 AP 공간 재활용)       └─────┬─────┘   │
│         │            Co-OFDMA (주파수 분할 스케줄링)         │         │
│         │                                                    │         │
│         ▼                                                    ▼         │
│   ┌───────────┐                                        ┌───────────┐   │
│   │ Client A  │                                        │ Client B  │   │
│   │ (스마트폰)│                                        │(산업로봇) │   │
│   └───────────┘                                        └───────────┘   │
│   [ 전파 간섭 신호 완벽 제거 ]                       [ 1ms 무지연 확정성]│
└────────────────────────────────────────────────────────────────────────┘
```

- **Co-SR (Coordinated Spatial Reuse)** : 인접 AP들이 상호 송신 전력을 정밀 조절하여 동일 채널을 인접 구역에서 동시 재사용함으로써 전체 주파수 효율 대폭 증대.
- **Co-BF (Coordinated Beamforming)** : 여러 AP가 각자의 안테나 가중치를 상호 협력 계산하여 상대방 단말 방향으로 전파 간섭을 널링(Nulling).
- **Co-OFDMA** : 복수의 AP가 동일 시간 슬롯 내에서 서로 다른 서브캐리어(RU)를 나누어 할당함으로써 단말 간 전파 경쟁(Contention) 지연 원천 배제.

## Ⅲ. Wi-Fi 8의 세부 구성 요소 및 Wi-Fi 7과의 기술적 비교 분석

| 비교 항목 | Wi-Fi 7 (802.11be EHT) | Wi-Fi 8 (802.11bn UHR) |
|---|---|---|
| **개발 목표** | 극한 처리량 (최대 46 Gbps) | 초고신뢰성 및 지연 시간 결정론적 보장 |
| **최대 채널 대역폭** | 320 MHz | 320 MHz (대역폭 유지, 효율 고도화) |
| **변조 방식** | 4096-QAM | 4096-QAM + 저신뢰 구간 Robust 변조 |
| **AP 조정 메커니즘**| 미지원 (개별 AP 자율 경쟁) | MAPC (Multi-AP Coordination 표준 내재화) |
| **단말 링크 제어** | MLO (단일 AP 내 다중 대역 링크) | E-MLO (이기종 AP 간 분산 다중 링크 지원) |
| **부반송파 펑처링** | 정적 프리앰블 펑처링 지원 | 동적 서브채널 펑처링 (간섭 실시간 회피) |
| **레이더 센싱** | 미지원 (기초 논의 단계) | ISAC (통신과 고정밀 실내 센싱 완전 통합) |

- **동적 서브채널 펑처링 (Dynamic Subchannel Puncturing)** : 320MHz 넓은 대역 내에 협대역 간섭 신호가 발생해도 전체 채널을 포기하지 않고 해당 부분만 동적으로 도려내어 전송 유지.
- **AP 간 로밍 지연 제로화 (Seamless Roaming)** : 단말 이동 시 기존 링크를 끊기 전에 대상 AP와 사전 협력 링크를 수립하는 Make-Before-Break 기법 구현.

## Ⅳ. Wi-Fi 8의 주요 한계점 및 해결 방안

- **다중 AP 간 정밀 동기화 및 백홀 대역폭 점유 급증** :
  - **한계점** : Co-BF와 Joint Tx를 구동하기 위해 AP 간 나노초 단위 클럭 동기화와 방대한 채널 피드백 데이터가 유선 백홀망에 부하 초래.
  - **해결 방안** : TSN(Time-Sensitive Networking) 이더넷 연동 의무화 및 채널 상태 정보(CSI)를 인공지능 오토인코더로 압축 전송하는 AI 압축 기법 채택.
- **기존 레거시 기기(Wi-Fi 5/6/7) 혼재에 따른 협력 효율 저하** :
  - **한계점** : 신규 메커니즘을 지원하지 않는 구형 단말이 채널을 점유하면 전체 MAPC 협력 메커니즘이 일시 중단되는 역호환성 병목.
  - **해결 방안** : BSS Coloring 및 6GHz 단독 청정 대역으로 Wi-Fi 8 전용 슬라이스 분리 지정 운용.

## Ⅴ. Wi-Fi 8 적용 및 발전을 위한 기술사적 제언

- **무선 기반 스마트 팩토리 OT 망 전면 전환** : 높은 신뢰도를 바탕으로 산업용 로봇(AGV/AMR), 디지털 트윈 공정 라인의 케이블을 제거하여 제조 유연성 극대화.
- **실내 전파 센싱(ISAC) 비즈니스 모델 발굴** : 별도 카메라나 적외선 센서 없이도 Wi-Fi 8 신호만으로 노약자 낙상 사고 감지, 침입 탐지, 에너지 절감 공조 제어 연동.
- **기업용 무선망 설계의 패러다임 전환** : 단일 AP의 고출력 커버리지 설계 방식에서 탈피하여, 소형 저전력 협력 AP 다수를 분산 배치하는 메시 아키텍처 설계 수용.
