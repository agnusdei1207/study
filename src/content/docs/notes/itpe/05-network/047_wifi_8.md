## 30초 인출

- 본질: **Wi-Fi 8 (IEEE 802.11bn)** : 이론적 최대 전송속도 경쟁을 넘어 99.99% 이상의 전송 신뢰성과 최악 지연시간(Worst-case Latency)을 엄격히 통제하는 차세대 초고신뢰 무선랜 규격
- 메커니즘: Multi-AP Coordination(Co-BF, Co-OFDMA, Co-SR)과 정밀 전력 제어를 통해 셀 경계 단말의 간섭을 제거하고 결정론적 슬롯 스케줄링 수행
- 통찰: 무선 신호의 확률적 충돌 한계를 극복하기 위해 다중 AP 간 유선 백홀 기반 분산 빔포밍과 자원 블록 사전 조정을 표준화한 차세대 산업용 무선 인프라 규격임.

<details>
<summary>핵심 용어</summary>

- **IEEE 802.11bn (UHR)** : Ultra High Reliability를 목표로 개발 중인 차세대 IEEE 무선랜 표준 프로젝트
- **Multi-AP Coordination (MAPC)** : 인접한 복수의 독립 AP들이 상호 정보를 교환하여 주파수, 시간, 공간 자원을 공동 제어하는 협력 통신
- **Co-BF (Coordinated Beamforming)** : 여러 AP가 단말 채널 정보를 공유하여 상호 간섭 방향으로 신호가 방사되지 않도록 널링(Nulling)하는 협력 빔포밍
- **Co-OFDMA** : 복수 AP가 단일 채널 내에서 자원 단위(RU)를 시간/주파수 단위로 직교 분할하여 충돌 없이 동시 전송하는 기술
- **Worst-case Latency** : 통계적 평균 지연이 아닌 99.99% 이상의 패킷이 반드시 도달해야 하는 최대 지연시간 상한선

</details>

## 2~4교시 25점 답안

## Ⅰ. Wi-Fi 8 (IEEE 802.11bn UHR)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 기존 Wi-Fi 7의 최대 대역폭 확장(320MHz)에서 나아가, 다중 AP 간 완전한 자원 협력(Multi-AP Coordination)을 통해 99.99% 이상의 고신뢰성과 1ms 미만의 결정론적 지연을 보장하는 차세대 무선랜 표준 규격 |
| 목적 | 공장 자동화(OT), 원격 의료 제어, 자율 모빌리티 등 유선 이더넷 수준의 무손실·확정적 지연이 요구되는 미션 크리티컬 무선 환경 제공 |

## Ⅱ. Wi-Fi 8의 특징

| 특징 | 상세 내용 |
|---|---|
| 신뢰성 최우선 설계 | 최대 처리량(Gbps) 증대 대신 패킷 손실률 10^-5 달성 및 꼬리 지연(Tail Latency) 제어에 집중 |
| 다중 AP 협력 통신 | 개별 AP의 독자적 경쟁 전송을 배제하고 인접 AP 간 빔포밍, 주파수 자원(RU), 공간 재사용을 통합 통제 |
| 매끄러운 로밍 (Seamless)| 단말 이동 시 AP 간 세션 단절 시간을 마이크로초(μs) 단위로 단축하여 실시간 제어 연속성 보장 |
| 채널 상태 동적 회피 | 1ms 이내에 레이더 신호 또는 협대역 간섭을 감지하여 비간섭 서브밴드로 즉각 회피 전송 |

## Ⅲ. Wi-Fi 8의 체계·프로세스

**Multi-AP Coordination (MAPC) 시스템 아키텍처**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        [ Wi-Fi 8 다중 AP 협력 통신 체계 ]              │
│                                                                        │
│   [ 전사 Wi-Fi 중앙 컨트롤러 / 초고속 유선 백홀 스위치 ]                │
│          ├─── 10Gbps TSN 백홀 (μs 단위 정밀 동기화) ──┐                │
│          ▼                                            ▼                │
│   ┌──────────────┐                            ┌──────────────┐         │
│   │ [ AP 1 ]     │                            │ [ AP 2 ]     │         │
│   │ (Master AP)  │                            │ (Slave AP)   │         │
│   └──────┬───────┘                            └──────┬───────┘         │
│          │                                           │                 │
│          ├─ Co-BF: 단말 B 방향 널링(Null) 형성       │                 │
│          ├─ Co-OFDMA: 자원 블록 1번 할당             ├─ RU 2번 할당    │
│          │                                           │                 │
│          ▼                                           ▼                 │
│     [ 단말 A (STA 1) ]                          [ 단말 B (STA 2) ]     │
│     (인접 AP 전파 간섭 없이 99.999% 무손실 수신 완료)                   │
└────────────────────────────────────────────────────────────────────────┘
```

| 협력 통신 기술 | 동작 원리 | 핵심 기대 성과 |
|---|---|---|
| **Co-BF (협력 빔포밍)** | 복수 AP가 단말 간 CSI를 공유하여 타 AP 수신 단말 방향으로 신호 방사를 상쇄 | 셀 경계 단말의 신호 대 잡음비(SINR) 10dB 이상 개선 |
| **Co-OFDMA (협력 OFDMA)** | 동일한 채널 공간에서 AP 간 사전에 합의된 RU(Resource Unit)를 나누어 할당 | 다중 AP 동시 전송 시 패킷 충돌 0% 보장 |
| **Co-SR (협력 공간재사용)**| AP 상호 간의 전송 파워를 실시간 미세 조절하여 간섭 반경을 제어하며 동시 송출 | 고밀도 전시장/오피스 환경 처리율 3배 개선 |
| **Integrated Power Control**| 셀 경계 단말의 상향링크 전력을 AP들이 공동 계산하여 지시 | 배터리 소모 절감 및 상향링크 간섭 원천 억제 |

## Ⅳ. Wi-Fi 세대별 진화 비교 (Wi-Fi 6 vs 7 vs 8)

| 비교 항목 | Wi-Fi 6/6E (802.11ax) | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
|---|---|---|---|
| **표준화 명칭** | High Efficiency (HE) | Extremely High Throughput (EHT) | **Ultra High Reliability (UHR)** |
| **최우선 목표** | 스펙트럼 효율화 및 다중접속 | **최대 전송 속도 (Peak 46Gbps)**| **초고신뢰성 및 지연 결정론성** |
| **최대 채널 대역폭**| 160 MHz | 320 MHz | **320 MHz (동적 서브밴드 최적화)** |
| **다중 링크 (MLO)**| 미지원 | MLO 도입 (처리량 극대화) | **Seamless MLO (신뢰성/저지연 특화)**|
| **AP 간 동작 구조** | 독립적 경쟁 (CSMA/CA) | 독립적 동작 (간섭 회피 위주) | **다중 AP 완전 협력 (MAPC 프레임워크)**|
| **핵심 평가지표** | 평균 처리량 (Throughput) | 최대 피크 속도 | **99.99% 신뢰도 및 최악 지연 (Worst Latency)**|

## Ⅴ. Wi-Fi 8의 한계와 방안

| 한계 | 방안 |
|---|---|
| 복수 AP 간 실시간 협력 빔포밍(Co-BF)을 위해 유선 백홀을 통해 교환해야 하는 채널 상태 정보(CSI)의 데이터 오버헤드 폭증 | 딥러닝 기반 CSI 양자화 압축 알고리즘을 도입하고, AP 간 유선 백홀망에 마이크로초 단위 지연 보장이 가능한 IEEE 802.1AS TSN 스위치 인프라 의무화 |
| 기존 레거시 단말(Wi-Fi 5/6)이 동일 채널에 혼재할 경우 비협력적인 긴 CSMA/CA 랜덤 백오프로 인해 Wi-Fi 8의 1ms 결정론적 슬롯 파괴 | UHR 전용 보호 주파수 채널을 물리적으로 분리 할당하거나, 비콘 프레임 내 엄격한 무경쟁 구간(CFP)을 스케줄링하여 레거시 단말의 채널 경합 강제 배제 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
제조 플랜트 및 스마트 병원 등 미션 크리티컬 환경에 Wi-Fi 8을 도입할 경우, 단순 무선 AP 교체에 그치지 않고 AP 간 유선 백홀을 10Gbps 광케이블 및 TSN(Time-Sensitive Networking) 스위치 패브릭으로 선행 구축하여 Co-BF 동기화 지연을 100μs 이내로 격리 통제.

### 3. 기술 유형 및 비교 평가
| 무선 통신 신뢰성 지표 | Wi-Fi 6 (802.11ax) | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
|---|---|---|---|
| **지연 시간 편차 (Jitter)** | 수십 ms ~ 수백 ms | 수 ms ~ 수십 ms | **1 ms 이내 결정론적 통제** |
| **셀 경계 패킷 손실률** | 5 ~ 10% 수준 | 1 ~ 3% 수준 | **0.001% (99.999% 무손실)** |
| **산업용 이더넷 대체 가능성**| 불가 | 제한적 적용 | **완전한 무선 산업 이더넷 대체 가능** |
