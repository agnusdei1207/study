<summary>핵심 용어</summary>

- **Wi-Fi 8** : IEEE 802.11bn 개정 프로젝트를 가리키는 업계 통칭.
- **IEEE 802.11bn** : Ultra High Reliability(UHR) 기능 향상을 목표로 하는 IEEE WLAN 개정 프로젝트.
- **UHR (Ultra High Reliability)** : 실제 사용 조건에서 무선 연결 신뢰성을 개선하려는 프로젝트 목표.
- **AP (Access Point)** : WLAN 단말을 무선으로 접속시키는 네트워크 장비.
- **STA (Station)** : WLAN에 접속하는 무선 단말.
- **Multi-AP Coordination** : AP 사이의 동작을 조정해 단말 연결과 무선 자원 이용을 개선하려는 기능 방향.
- **Co-BF (Coordinated Beamforming)** : 여러 AP의 빔 형성을 조정하는 협력 무선 기능 방향.
- **Co-SR (Coordinated Spatial Reuse)** : 여러 AP의 동시 전송을 조정해 공간 재사용을 돕는 기능 방향.

## Ⅱ. UHR 기술 방향

```text
AP 1의 전송·자원 상태 ──┐
                         ├→ Multi-AP 조정 → 대상 STA 연결 품질 개선 목표
AP 2의 전송·자원 상태 ──┘
```

개발 중인 UHR 방향을 개념화한 그림. AP 협력의 구체 절차와 기능 채택 범위는 최종 규격·장비 구현에 따름.

## Ⅲ. Wi-Fi 세대별 초점

| 비교축 | Wi-Fi 7 (IEEE 802.11be) | Wi-Fi 8 (IEEE 802.11bn 개발 중) |
|---|---|---|
| 프로젝트 목표 | Extremely High Throughput(EHT) | UHR 목표의 무선 신뢰성 개선 |
| 성능 관점 | 높은 전송률·다중 링크 등 | 실제 조건의 일관된 연결 경험 |
| 표준 상태 | IEEE Std 802.11be-2024 | D2.0 작업반 투표 통과 후 의견 해결 단계(2026년 9월 기준) |

## Ⅳ. 도입 전 검증

| 한계 | 검증 항목 |
|---|---|
| 초안의 기능이 최종 제품에 그대로 반영되지 않을 수 있음 | 규격 버전·제품 사양·인증 상태 확인 |
| AP 협력은 백홀·컨트롤러·단말 조합의 영향을 받음 | 장비 상호운용·관리 기능 시험 |
| 성능은 설치 위치·간섭·이동 부하에 따라 달라짐 | 셀 경계와 혼잡 구역의 지연·재전송·처리량 측정 |

```text
규격·기능 지원 확인
        ↓ 장비 조합 구성
AP·STA 상호운용 시험
        ↓ 현장 조건 재현
혼잡·이동 환경 측정
        ↓ 목표 지표와 비교
도입 범위 결정
```
