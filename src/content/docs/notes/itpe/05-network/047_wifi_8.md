## 연관 키워드

- Wi-Fi 8, UHR(Ultra High Reliability), 성능 지표 전환, MAPC(Multi-AP Coordination)
- 협력 공간 재사용(Co-SR), 동적 서브채널 펑처링, E-MLO(Enhanced Multi-Link Operation)
- ISAC(통신·센싱 통합), 지연 지터(Jitter), 최악 조건 신뢰성, 도입 시나리오

## Ⅰ. Wi-Fi 8의 개요

- 핵심 요약 : 세대마다 최대 속도를 높여 온 무선랜의 발전 축을 신뢰성과 지연 안정성으로 바꾸는 여덟 번째 세대 규격.
- 개념 : IEEE(Institute of Electrical and Electronics Engineers) 802.11bn 규격에 대한 Wi-Fi Alliance의 세대 통칭(**Wi-Fi 8**), 목표 기술은 **초고신뢰성** (UHR, Ultra High Reliability)이고 다수의 AP(Access Point) 협력을 핵심으로 함.
- 배경 및 필요성 : Wi-Fi 7까지 세대 전환의 관심사가 최대 전송 속도와 대역폭 확대에 있었으나, 클라우드 게이밍·산업 제어·원격 진료처럼 순간 끊김과 지연 흔들림이 치명적인 응용의 대중화로 평균 속도 중심 지표의 한계가 노출.
- 주요 목적 :
  1. 최악 조건에서의 전송 신뢰도 확보
  2. **지연 지터** (Jitter, 지연 시간의 편차) 억제를 통한 예측 가능한 반응성
  3. 동일 인프라에서의 단말 전력 효율 개선

## Ⅱ. Wi-Fi 8의 특징 및 장점

- 핵심 요약 : AP 간 협력과 간섭 회피 기능을 세대 전환의 축으로 삼아 평균 성능 대신 최악 순간의 품질을 끌어올리는 구조.

1. 성능 지표 축의 전환 : 평균 최대 속도 대신 하위 지연 구간과 신뢰도를 세대 목표로 명시 → 사용자 체감 품질 하한선의 상승.
2. **다중 AP 조정** (MAPC, Multi-AP Coordination) : 인접 AP가 송신 시점과 자원을 협의 → 개별 AP 경쟁에 따른 충돌·재전송 감소.
3. **협력 공간 재사용** (Co-SR, Coordinated Spatial Reuse) : 인접 AP가 송신 전력을 조절해 같은 채널의 동시 사용 → 주파수 이용 효율 향상.
4. **동적 서브채널 펑처링** (Dynamic Subchannel Puncturing) : 간섭받는 부분 대역만 제외하고 전송 → 채널 전체를 포기하지 않는 처리량 유지.
5. **확장 다중 링크 동작** (E-MLO, Enhanced Multi-Link Operation) : 서로 다른 AP의 링크를 묶어 끊김을 다른 링크로 보완 → 이동·간섭 상황의 단절 시간 감소.
6. **통신·센싱 통합** (ISAC, Integrated Sensing and Communication) : 통신 신호의 반사로 실내 상황 감지 → 별도 센서 없는 상황 인지 (논의 단계).

## Ⅲ. Wi-Fi 8의 구조 (흐름)

- 핵심 요약 : AP 간 채널 정보 공유가 협력 기법의 출발점이고 조정된 전송이 단말별 품질 안정화로 이어지는 흐름.

```text
[ 다중 AP 조정 흐름 ]

AP 간 채널 상태·부하 정보 공유
   ↓
MAPC 협의 (시점·자원·전력)
   ↓
Co-SR·빔포밍 기반 전송
   ↓
단말별 간섭 억제·품질 안정화
```

```text
[ 동적 서브채널 펑처링 ]

4개 부대역 중 간섭 대역 감지
   ↓
간섭 부대역만 펑처링 (제외)
   ↓
나머지 부대역으로 전송 유지
```

- 협력 제어 정보는 AP 사이의 유선 백홀로 교환되며, 단말은 협력 결과의 수신 대상으로 동작.

## Ⅳ. Wi-Fi 7과 Wi-Fi 8의 비교

- 핵심 요약 : Wi-Fi 7이 단일 AP의 처리량 극대화 세대라면 Wi-Fi 8은 AP 협력 기반의 신뢰성 세대로 지표 축이 이동한 차이.

| 비교 축 | Wi-Fi 7 (802.11be) | Wi-Fi 8 (802.11bn) |
| --- | --- | --- |
| 세대 목표 | 최대 처리량 확대 | 신뢰성·지연 안정성 |
| 대역폭·변조 | 320MHz·4096-QAM(Quadrature Amplitude Modulation) | 대역폭 확장보다 협력·효율 기법 중심 |
| 성능 지표 | 평균·최대 속도 | 최악 조건 지연·신뢰도·지연 지터 |
| AP 간 협력 | 미표준화 | 다중 AP 조정 표준 기능 |
| 간섭 대응 | 정적 프리앰블 펑처링 | 동적 서브채널 펑처링 |
| 대표 도입 시나리오 | 고화질 스트리밍·대용량 전송 | 스마트 팩토리·원격 의료·XR(Extended Reality) |

- 선택 기준 : 대용량 전송 중심 환경은 Wi-Fi 7 장비가 현실적이고, 제어 신호의 끊김이 곧 장애로 이어지는 현장은 협력 기능이 표준화된 Wi-Fi 8을 대상 검토.

## Ⅴ. Wi-Fi 8의 한계와 방안

- 핵심 요약 : 협력 기능이 백홀·시간 동기에 기대는 구조적 제약과 레거시 단말 혼재, 센싱 프라이버시를 설계·운영 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 백홀·동기화 부담 | 정밀 시간 동기와 제어 정보 교환의 백홀 대역 점유 | 백홀 용량 설계와 제어 트래픽의 우선순위 분리 | 백홀 사용률, 동기화 지터 |
| 레거시 단말 혼재 | 구형 단말의 채널 점유로 협력 이득 저하 | 협력 대상 AP 그룹 분리, 신규 단말 전용 자원 운용 | 협력 전송 성공률 |
| 센싱의 프라이버시 리스크 | 무선 신호로 재실·움직임 추정 가능 | 기기 내 처리 원칙, 목적 제한·원시 신호 비저장 | 개인 식별 데이터 저장 건수 |

## Ⅵ. Wi-Fi 8에 대한 기술사적 제언

- 핵심 요약 : 기업·현장 조직이 검증된 범위에서 단계적으로 세대 전환을 준비하고 센싱 확산 전 절차를 마련하는 방향.

1. 기업 무선망 운영 조직 : 고출력 단일 AP 중심 설계에서 저출력 협력 AP 촘촘 배치로의 전환 로드맵과 표준 확정 시점 기준 교체 주기 설정.
2. 제조 현장 관리 조직 : 무선 신뢰성 지표의 선행 측정 후 자동 이동 로봇 구역처럼 영향이 제한된 구역부터 적용하는 단계 도입 절차 운영.
3. 보안·개인정보 관리 조직 : 통신·센싱 통합 기능의 서비스 확산 전 개인정보 영향 평가를 의무 절차로 편성.

## Ⅶ. 결론

- 핵심 요약 : Wi-Fi 8은 최대 속도 경쟁을 마치고 최악 순간의 신뢰성을 세대 기준으로 삼는 전환 규격.
- 평가 지표를 평균 속도에서 최악 조건 지표로 옮기는 것이 조달·설계의 새로운 판단 기준.
