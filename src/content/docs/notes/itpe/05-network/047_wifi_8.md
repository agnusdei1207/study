## 연관 키워드

- Wi-Fi 8, IEEE 802.11bn, UHR(Ultra High Reliability), 다중 AP 조정(MAPC)
- 협력 공간 재사용(Co-SR), 협력 빔포밍(Co-BF), 동적 서브채널 펑처링, E-MLO
- 다중 링크 동작(MLO), ISAC(통신·센싱 통합), Wi-Fi 7, 지연 안정성

## Ⅰ. Wi-Fi 8의 개요

- 핵심 요약 : 처리량 경쟁에서 벗어나 초고신뢰성과 지연 안정성을 목표로 하는 차세대 무선랜 규격.
- 개념 : IEEE(Institute of Electrical and Electronics Engineers) 802.11bn 워킹그룹에서 표준화가 진행 중인 차세대 무선랜 규격(**Wi-Fi 8**)으로, 목표 기술은 **UHR** (Ultra High Reliability, 초고신뢰성)이며 여러 무선 접속 장치(AP, Access Point)의 협력을 핵심으로 한다.
- 배경 및 필요성 : Wi-Fi 7까지 최대 전송 속도가 크게 높아졌으나, 실시간 스트리밍·클라우드 게이밍·산업용 제어처럼 지연의 흔들림과 순간 끊김에 민감한 응용이 늘어나 평균 속도보다 신뢰성이 요구됨.
- 주요 목적 : 무선 전송의 신뢰도 확보, 최악 조건에서의 지연 억제, 단말 배터리 효율 개선.

## Ⅱ. Wi-Fi 8의 특징 및 장점

- 핵심 요약 : 다중 AP 협력과 간섭 회피를 표준 기능으로 넣어 신뢰성과 지연 안정성을 확보하는 구조.

1. **다중 AP 조정** (MAPC, Multi-AP Coordination) : 인접 AP들이 송신 시점과 자원을 함께 조정 → 개별 AP가 경쟁하며 생기는 충돌과 대기 시간 감소.
2. **협력 공간 재사용** (Co-SR, Coordinated Spatial Reuse) : 인접 AP가 송신 전력을 조절해 같은 채널을 가까운 구역에서 함께 사용 → 주파수 효율 향상.
3. **협력 빔포밍** (Co-BF, Coordinated Beamforming) : 여러 AP가 빔 가중치를 함께 계산해 다른 단말 방향의 간섭을 억제 → 단말 수신 품질 안정.
4. **동적 서브채널 펑처링** (Dynamic Subchannel Puncturing) : 넓은 채널 안의 간섭 구간만 제외하고 나머지로 전송 → 채널 전체를 버리지 않아 처리량 손실 최소화.
5. **다중 링크 동작** (MLO, Multi-Link Operation)을 확장한 **확장 다중 링크 동작** (E-MLO, Enhanced Multi-Link Operation) : 서로 다른 AP에 걸친 링크를 묶어 한 링크의 끊김을 다른 링크로 보완 → 단절 시간 감소.
6. **통신·센싱 통합** (ISAC, Integrated Sensing and Communication) : 통신용 무선 신호를 실내 물체 움직임 감지에도 쓰는 구조 → 별도 센서 없이 상황 인지 (논의 단계).

## Ⅲ. Wi-Fi 8의 구조 (흐름)

- 핵심 요약 : AP 간 채널 정보 공유가 협력 기법의 출발점이며, 그 결과가 단말별 간섭 억제 전송으로 이어지는 흐름.

```text
[ 다중 AP 협력 흐름 ]

AP 간 채널 상태 공유
          ↓
다중 AP 조정 (MAPC)
          ↓
협력 빔포밍·공간 재사용 자원 배분
          ↓
단말별 간섭 억제 전송
```

```text
[ 동적 서브채널 펑처링 ]

[ 1 ][ 2 ][ 간섭 ][ 4 ]
          ↓
[ 1 ][ 2 ][  제외 ][ 4 ]  ← 나머지만 전송
```

## Ⅳ. Wi-Fi 7과 Wi-Fi 8의 비교

- 핵심 요약 : Wi-Fi 7은 처리량 극대화에, Wi-Fi 8은 신뢰성과 지연 보장에 초점을 둔 차이.

| 비교 축 | Wi-Fi 7 (802.11be EHT, Extremely High Throughput) | Wi-Fi 8 (802.11bn UHR) |
| --- | --- | --- |
| 개발 목표 | 처리량 극대화 (이론 최대 약 46 Gbps) | 초고신뢰성과 지연 안정성 |
| 최대 채널 대역폭 | 320 MHz | 대역폭 확대보다 효율 개선에 초점 (논의 중) |
| AP 협력 | 제한적 (AP 간 협력 기능 미표준화) | 다중 AP 조정 (MAPC) 표준 기능으로 논의 |
| 다중 링크 | 단일 AP 내 다중 대역 링크 (MLO) | 서로 다른 AP를 묶는 확장 (E-MLO) |
| 간섭 대응 | 정적 프리앰블 펑처링 | 동적 서브채널 펑처링 |
| 센싱 | 미지원 | 통신·센싱 통합 (ISAC) 논의 |

- 선택 기준 : 대용량 전송이 핵심이면 Wi-Fi 7 이하의 기존 장비가 현실적이고, 끊김 없는 제어 신호가 핵심이면 Wi-Fi 8의 신뢰성 기능이 판단 기준이 됨.

## Ⅴ. Wi-Fi 8의 한계와 방안

- 핵심 요약 : 협력 기능이 백홀과 구형 단말에 기대는 구조적 제약을 자원 분리와 보안 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| AP 간 동기화 부담 | 정밀 시간 동기와 채널 피드백 데이터가 유선 백홀 대역을 점유 | 백홀 대역 용량 설계와 제어 트래픽 우선순위 분리 | 백홀 사용률, 동기화 지터 |
| 레거시 단말 혼재 | 구형 단말이 채널을 점유하면 협력 기능이 저하 | 협력 대상 그룹 분리, 신규 기기 전용 자원 분리 운용 | 레거시 점유율, 협력 성공률 |
| 센싱 기능의 사생활 침해 우려 | 무선 신호로 사람의 움직임과 위치를 추정 가능 | 기기 내 처리와 목적 제한, 원시 신호 비저장 원칙 | 개인 식별 데이터 저장 건수 |

## Ⅵ. Wi-Fi 8에 대한 기술사적 제언

- 핵심 요약 : 무선 신뢰성을 검증 가능한 범위에서 단계적으로 도입하고, 센싱 기능은 설계 단계부터 보호 기준을 함께 갖추는 방향.

제조 현장은 유선 케이블을 한꺼번에 무선으로 바꾸기보다, 무선 신뢰성 지표를 먼저 측정하면서 자동 이동 로봇처럼 범위가 제한된 구역부터 적용하는 것이 현실적이다. 기업 무선망은 고출력 단일 AP 중심 설계에서 저출력 협력 AP를 촘촘히 배치하는 방식으로 옮겨 가되, 협력 기능의 표준 확정 시점에 맞춰 장비 교체 주기를 정하는 것이 바람직하다. 통신·센싱 통합 기능은 편의 기능으로 확산되기 전에 개인정보 보호 기준을 설계 단계에서 마련해야 한다.

## Ⅶ. 결론

- 핵심 요약 : Wi-Fi 8은 처리량보다 신뢰성과 지연 안정성을 기준으로 무선망을 재설계하는 차세대 표준.
- 시사점 : 표준이 확정되기 전에는 협력 기능을 전제로 한 설계를 검증된 범위에서만 적용하는 것이 안전하다.
