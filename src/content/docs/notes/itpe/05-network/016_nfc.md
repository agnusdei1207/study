## Ⅰ. NFC(Near Field Communication)의 개요

- **개념** : 13.56MHz 비인가 ISM 주파수 대역을 사용하여 10cm 이내의 초근거리에서 기기 간 양방향 데이터 전송을 가능하게 하는 비접촉식 근거리 무선 통신 기술(ISO/IEC 18092 및 14443 기반).
- **배경 및 필요성** : 기존 고주파 RFID는 단방향 태그 인식에 치중되었고, 블루투스는 페어링 절차가 복잡하여 간편 결제 및 순간적 기기 연동에 한계가 있어 직관적인 터치(Touch) 기반의 보안 통신 표준으로 제정됨.
- **핵심 목적** : 모바일 결제 및 교통카드의 신속한 트랜잭션, 복잡한 설정 없는 즉각적 페어링(Zero-Config), 초근거리 전파 특성을 활용한 물리적 도청 방어.

## Ⅱ. NFC(Near Field Communication)의 핵심 아키텍처 및 동작 메커니즘

NFC는 전자기 유도(Electromagnetic Induction) 결합 원리로 구동되며, 카드 에뮬레이션, 리더/라이터, P2P의 3대 동작 모드를 지원함.

```text
[ NFC 3대 동작 모드 및 보안 아키텍처 ]

                      [ 13.56MHz 전자기 유도 결합 ]
       +---------------------------------------------------------+
       |                                                         |
       ▼                                                         ▼
[ 스마트폰 / 활성 장치 ]                                  [ 수동 태그 / 결제 단말기 ]
+----------------------+                                  +----------------------+
| 1. 카드 에뮬레이션   | <====== 모바일 결제 (POS) =====> | 결제 단말기 (POS)    |
|    - SE / HCE 연동   |                                  +----------------------+
|                      |
| 2. 리더 / 라이터 모드| <====== 태그 정보 읽기/쓰기 ====> | 스마트 포스터/도어락 |
|    - NDEF 메시지     |                                  +----------------------+
|                      |
| 3. P2P 모드          | <====== 기기간 명함/데이터 =====> | 타 스마트폰 (P2P)    |
|    - SNEP / LLCP     |                                  +----------------------+
+----------------------+
       │
       ▼ (보안 실행 환경)
[ Secure Element (eSE/USIM) ] OR [ Host Card Emulation (HCE: 클라우드 기반 토큰) ]
```

- **전자기 유도 결합(Inductive Coupling)** : 송신 코일에 교류 전류를 흘려 생성된 유도 자기장으로 수신 코일에 기전력을 유발하여 무전원 태그까지 구동.
- **카드 에뮬레이션(Card Emulation)** : 스마트폰이 신용카드나 교통카드처럼 동작하여 기존 비접촉 결제 리더기(POS)와 통신(Apple Pay, Samsung Pay).
- **리더/라이터(Reader/Writer) 모드** : 스마트폰이 주도적으로 스마트 포스터나 NFC 태그에 기록된 NDEF(NFC Data Exchange Format) 데이터를 판독하거나 기록.
- **P2P(Peer-to-Peer) 모드** : ISO 18092 표준에 따라 두 활성 NFC 장치 간에 Wi-Fi/블루투스 페어링 정보를 교환하거나 명함 데이터를 직접 전송.
- **SE(Secure Element) vs HCE(Host Card Emulation)** : 하드웨어 보안 칩(USIM/eSE) 기반 보안 결제와 소프트웨어 OS 레벨 가상화 결제(HCE)의 이원화 구조.

## Ⅲ. NFC(Near Field Communication)의 세부 구성 요소 및 비교 분석

| 비교 항목 | NFC | 고주파 RFID (13.56MHz) | 블루투스 BLE (Bluetooth) | 초광대역 (UWB) |
|---|---|---|---|---|
| **표준 규격** | ISO/IEC 18092, 14443 | ISO/IEC 15693, 14443 | IEEE 802.15.1, SIG | IEEE 802.15.4z |
| **통신 거리** | 10 cm 이내 (접촉 수준) | 수십 cm ~ 1 m | 10 ~ 100 m | 수십 m 이내 |
| **전송 속도** | 최대 424 kbps | 약 수십 kbps | 1 ~ 2 Mbps | 최대 수십 Mbps |
| **통신 방향** | 양방향 (Two-way) | 단방향 (리더 $\rightarrow$ 태그) | 양방향 | 양방향 |
| **페어링 절차** | 즉시 통신 (터치 방식) | 불필요 | 수 초 소요 (탐색/인증) | 센티미터 정밀 측위 |
| **주요 용도** | 간편결제, 교통, 출입증 | 물류 재고 관리, 도서관 | 비콘, 무선 이어폰, IoT | 정밀 위치 추적, 디지털 키 |

- NFC는 전송 속도와 거리가 극히 제한적이나, 역설적으로 '10cm 이내 물리적 터치'라는 특성이 최고의 사용자 직관성과 물리 계층 보안성을 제공함.

## Ⅳ. NFC(Near Field Communication)의 주요 한계점 및 해결 방안

- **10cm 이내의 짧은 전송 거리 및 424kbps의 저속 전송률** :
  - **한계점** : 대용량 사진, 파일 전송이나 원거리 인증(스마트 카키 등) 서비스에 단독 사용 불가.
  - **해결 방안** : NFC는 초기 기기 인증 및 보안 토큰 교환의 대역 외(Out-of-band) 수단으로만 쓰고 실제 데이터는 BLE/Wi-Fi Direct로 핸드오버.
- **무선 도청(Eavesdropping) 및 릴레이 공격(Relay Attack) 보안 취약성** :
  - **한계점** : 공격자가 고이득 안테나로 수 미터 거리에서 신호를 도청하거나 프록시 장치로 결제 신호를 중계하는 공격 노출.
  - **해결 방안** : 응답 지연시간(RTT)을 마이크로초 단위로 엄격히 제한하는 거리 경계(Distance-Bounding) 프로토콜 및 토큰화(Tokenization) 적용.
- **물리적 HCE(Host Card Emulation) 환경에서의 모바일 악성코드 위협** :
  - **한계점** : OS 루팅이나 커널 탈취 시 메모리에 상주하는 가상 카드 자격증명 유출 위험.
  - **해결 방안** : TEE(신뢰 실행 환경) 격리 영역 구동 및 일회용 동적 암호화 토큰(One-Time Token) 발급 체계 필수화.

## Ⅴ. NFC(Near Field Communication) 적용 및 발전을 위한 기술사적 제언

- **EMV Contactless 및 모바일 신분증 표준 보안 아키텍처 준수** : 모바일 운전면허증 및 사원증 구축 시 ISO 18013-5 표준과 하드웨어 eSE 결합 강제화.
- **UWB(초광대역)와의 상호보완적 하이브리드 디지털 키 설계** : 원거리 접근 감지 및 도어 오픈은 UWB/BLE로 처리하고, 최종 비상 접촉 결제는 NFC로 폴백(Fallback)하는 다중 무선 프로파일링 구현 권장.
- **NFC 태그 무결성 검증을 위한 비대칭 암호화 서명 도입** : 정품 인증 및 자산 관리용 태그의 위조 복제를 방지하기 위해 ECC 기반 비대칭 키 전자서명 태그 도입 필요.
