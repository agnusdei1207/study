## 연관 키워드

- NFC, 근거리 무선 통신, 13.56MHz, 전자기 유도 결합, 동작 모드
- 카드 에뮬레이션, 리더·라이터, P2P, NDEF, SE, HCE
- 릴레이 공격, 거리 경계, TEE, 일회용 토큰

## Ⅰ. NFC의 개요

- 핵심 요약 : 수 센티미터의 터치 거리에서 13.56MHz 대역으로 양방향 통신을 수행하는 근거리 무선 통신 기술.
- 개념 : 13.56MHz 대역의 전자기 유도 결합으로 약 10cm 이내에서 양방향 통신을 수행하는 **NFC** (Near Field Communication, 근거리 무선 통신) 기술이며, ISO/IEC 18092와 ISO/IEC 14443 표준에 기반함.
- 배경 및 필요성 : 기존 RFID(Radio-Frequency Identification)는 단방향 태그 인식 중심이고 블루투스는 페어링 절차가 길어, 결제·출입처럼 짧은 순간에 끝나는 상호작용의 담당 수단 필요.
- 주요 목적 : 터치 기반의 빠른 거래, 설정 없는 즉시 연동, 초근거리 전파 특성 기반의 거래 신뢰 확보.

## Ⅱ. NFC의 특징 및 장점

- 핵심 요약 : 즉시 연결, 무전원 동작, 근접 제약, 표준 호환의 특성이 편의성과 보안성으로 이어지는 구조.

1. 터치 기반 즉시 연결 : 기기 접촉 동작으로 통신 성립 → 페어링 절차 없이 거래 완결과 대기 시간 단축.
2. **전자기 유도 결합**(Inductive Coupling) : 리더의 교류 자기장이 무전원 태그에 전력 공급 → 배터리 없는 카드·태그의 동작 가능.
3. 근접 거리 제약 : 통신 범위가 수 센티미터로 제한 → 원거리 도청·무단 접속 위험의 축소.
4. 표준 기반 상호 운용 : **NDEF**(NFC Data Exchange Format, NFC 데이터 교환 형식)의 공용 데이터 구조 → 제조사가 달라도 태그·단말 호환.

## Ⅲ. NFC의 구조 (흐름)

- 핵심 요약 : 하나의 전자기 결합 위에 세 동작 모드가 분기하고, 카드 에뮬레이션은 자격증명 저장 방식에 따라 나뉘는 구조.

```text
[ NFC 3대 동작 모드 ]

13.56MHz 전자기 유도 결합
   ↓
리더·라이터 모드 (태그 읽기·쓰기)
   ↓
카드 에뮬레이션 모드 (결제·교통)
   ↓
P2P 모드 (기기 간 데이터 교환)
```

```text
[ 카드 에뮬레이션 결제 흐름 ]

결제 단말기 접촉
   ↓  카드 에뮬레이션 응답
자격증명 조회 (SE 또는 HCE)
   ↓  일회용 토큰 생성
결제 승인 요청 전송
```

- **카드 에뮬레이션**(Card Emulation) : 단말이 교통카드·신용카드처럼 동작하여 결제 단말기와 통신하는 모드.
- **리더·라이터 모드**(Reader/Writer Mode) : 단말이 태그의 NDEF 데이터를 읽고 쓰는 모드.
- **P2P 모드** (Peer-to-Peer) : 두 활성 기기가 직접 데이터를 교환하며 Wi-Fi·블루투스 연결 정보를 넘기는 모드.
- **POS**(Point of Sale) : 카드 에뮬레이션 거래의 상대가 되는 매장 결제 단말기.
- **SE**(Secure Element, 보안 요소) : 하드웨어 보안 칩에 자격증명을 상주시키는 방식으로 금융 거래의 신뢰도가 높음.
- **HCE**(Host Card Emulation, 호스트 카드 에뮬레이션) : OS 소프트웨어가 가상 카드를 구현하고 클라우드 토큰으로 실카드 번호를 대체하는 방식.

## Ⅳ. NFC와 유사 근거리 기술의 비교

- 핵심 요약 : 통신 거리와 속도는 열세이나 터치 직관성과 근접 보안에서 강점을 갖는 포지션.
- 비교 대상 : NFC, 고주파 RFID, 블루투스 저에너지(BLE, Bluetooth Low Energy), 초광대역(UWB, Ultra-Wideband).

| 비교 축 | NFC | 고주파 RFID | BLE | UWB |
| --- | --- | --- | --- | --- |
| 표준 | ISO/IEC 18092, 14443 | ISO/IEC 15693, 14443 | Bluetooth SIG 규격 | IEEE 802.15.4z |
| 통신 거리 | 약 10cm 이내 | 수십 cm 수준 | 수 m 이상 | 수십 m 이내 |
| 통신 방향 | 양방향 | 주로 단방향 | 양방향 | 양방향 |
| 연결 절차 | 터치로 즉시 성립 | 별도 연결 없음 | 탐색·인증 절차 | 정밀 거리 측정 기반 |
| 주요 용도 | 결제·교통·출입 | 물류·자산 관리 | 웨어러블·센서 | 정밀 위치·디지털 키 |

- 선택 기준 : 물리적 터치가 자연스러운 거래는 NFC, 지속 연결은 BLE, 정밀 거리 측정이 필요하면 UWB를 채택하는 역할 분담이 표준적.

## Ⅴ. NFC의 한계와 방안

- 핵심 요약 : 전송 용량 한계, 릴레이 공격, 소프트웨어 자격증명 노출을 대역 외 연동·거리 검증·격리 실행으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 낮은 전송률과 짧은 거리 | 대용량 전송·원거리 인증 불가 | NFC 초기 인증 후 BLE·Wi-Fi로 전환하는 대역 외 연동 | 연동 성공률 |
| **릴레이 공격**(Relay Attack) | 신호 중계로 원거리에서 인증 성립 | **거리 경계**(Distance Bounding, 응답 지연 시간 검증) 적용 | 비정상 지연 탐지 건수 |
| HCE 자격증명 노출 | 루팅·메모리 탈취 시 상주 정보 위험 | TEE(Trusted Execution Environment) 격리 실행과 토큰 재발급 | 토큰 재사용 탐지 건수 |

## Ⅵ. NFC에 대한 기술사적 제언

- 핵심 요약 : 자격증명 저장 위치, 무선 기술 조합, 태그 신뢰 검증을 서비스 위험도 기준으로 설계하는 접근 필요.
- 신원 서비스 : 모바일 신분증 조직은 ISO/IEC 18013-5 표준 준수와 하드웨어 보안 요소 기반 구성의 기본 원칙화 권장.
- 디지털 키 : 차량·건물 출입 서비스 조직은 UWB·BLE의 원거리 감지와 NFC 근접 인증의 복합 구성 검토 권장.
- 자산 관리 : 태그 운영 조직은 공개키 전자서명을 담은 태그 도입으로 정품 검증 절차 구축 권장.

## Ⅶ. 결론

- 핵심 요약 : NFC는 터치 거리의 즉시 연결과 근접 보안을 강점으로 하는 근거리 무선 통신 기술임.
- 시사점 : 다른 무선 기술과의 역할 분담 설계에서 NFC의 실용적 가치가 극대화되는 구조임.
