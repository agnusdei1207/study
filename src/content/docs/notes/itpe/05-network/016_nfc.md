## 연관 키워드

- NFC(Near Field Communication), 근거리 무선 통신, 13.56MHz, 전자기 유도 결합(Inductive Coupling)
- 카드 에뮬레이션(Card Emulation), 리더/라이터(Reader/Writer), P2P(Peer-to-Peer), NDEF(NFC Data Exchange Format)
- SE(Secure Element), HCE(Host Card Emulation), 거리 경계(Distance Bounding), 릴레이 공격(Relay Attack)

## Ⅰ. NFC(Near Field Communication)의 개요

- 핵심 요약 : 수 cm 이내의 터치 거리에서 13.56MHz 대역으로 기기 간 데이터를 주고받는 비접촉 근거리 무선 통신 기술.
- 개념 : 13.56MHz 대역을 사용해 약 10cm 이내에서 양방향 통신을 수행하는 **근거리 무선 통신** (NFC, Near Field Communication) 기술이며, ISO/IEC 18092와 ISO/IEC 14443 등 국제 표준에 기반함.
- 배경 및 필요성 : 기존 RFID는 주로 단방향 태그 인식에 쓰였고 블루투스는 페어링 절차가 길어, 결제나 출입처럼 짧은 순간에 끝나야 하는 상호작용을 맡기 어려워 터치 기반 통신이 요구됨.
- 주요 목적 : 간편 결제와 교통카드의 빠른 거래, 설정 없이 이뤄지는 즉시 연동, 초근거리 전파 특성을 이용한 도청 위험 축소.

## Ⅱ. NFC(Near Field Communication)의 특징 및 장점

- 핵심 요약 : 짧은 통신 거리와 터치 동작이 직관성과 물리적 근접 보안으로 이어지는 방식.

1. 터치 기반 즉시 연결 : 기기를 맞대는 동작으로 통신이 시작 → 페어링 없이 거래가 끝나 사용자 대기 시간 단축.
2. 전자기 유도 결합 : 리더가 만든 교류 자기장으로 무전원 태그에 전력을 공급 → 배터리가 없는 카드·태그도 동작 가능.
3. 근접 거리 제약 : 전파 도달 거리가 짧아 원거리 도청이 어렵다 → 물리적 근접 상황에서만 거래가 일어나 보안 위험이 낮음.
4. 표준 기반 상호 운용 : ISO/IEC 표준과 NDEF 형식을 따름 → 제조사가 달라도 같은 태그와 단말기를 사용할 수 있음.

## Ⅲ. NFC(Near Field Communication)의 구조 (흐름)

- 핵심 요약 : 하나의 13.56MHz 결합 위에서 카드 에뮬레이션, 리더/라이터, P2P의 세 동작 모드가 나뉘어 동작하는 구조.
- **카드 에뮬레이션** (Card Emulation) : 스마트폰이 신용카드나 교통카드처럼 동작하여 결제 단말기(POS, Point of Sale)와 통신.
- **리더/라이터 모드** (Reader/Writer Mode) : 스마트폰이 NFC 태그의 **NDEF** (NFC Data Exchange Format, NFC 데이터 교환 형식) 데이터를 읽거나 기록.
- **P2P 모드** (Peer-to-Peer Mode) : 두 활성 기기가 직접 데이터를 교환하며, Wi-Fi나 블루투스 연결 정보를 넘기는 용도로 쓰임.

```text
[ NFC 3대 동작 모드 ]

13.56MHz 전자기 유도 결합
   ↓
1. 카드 에뮬레이션 (결제·교통카드)
   ↓
2. 리더/라이터 (NDEF 태그 읽기·쓰기)
   ↓
3. P2P (기기 간 데이터 교환)
```

```text
[ 결제 자격증명의 저장 위치 ]

보안 요소 SE
   ↓ 하드웨어 칩(eSE, USIM)에 자격증명 보관
호스트 카드 에뮬레이션 HCE
   ↓ OS 소프트웨어가 가상 카드 역할 수행
   ↓ 일회용 토큰으로 자격증명 대체
```

- **SE** (Secure Element, 보안 요소) : 하드웨어 보안 칩에 자격증명을 보관하는 방식으로, 금융 결제에서 신뢰도가 높음.
- **HCE** (Host Card Emulation, 호스트 카드 에뮬레이션) : 소프트웨어가 가상 카드를 구현하는 방식으로, 클라우드 토큰과 결합하여 쓰임.

## Ⅳ. NFC(Near Field Communication)의 비교

- 핵심 요약 : NFC는 속도와 거리에서 블루투스나 UWB에 밀리지만, 터치 직관성과 근접 보안에서 강점을 가짐.

| 비교 축 | NFC | 고주파 RFID (13.56MHz) | 블루투스 BLE (Bluetooth Low Energy) | UWB (Ultra-Wideband) |
| --- | --- | --- | --- | --- |
| 표준 | ISO/IEC 18092, 14443 | ISO/IEC 15693, 14443 | Bluetooth SIG 규격 | IEEE 802.15.4z |
| 통신 거리 | 약 10cm 이내 | 수십 cm 수준 | 수 m ~ 수십 m | 수십 m 이내 |
| 통신 방향 | 양방향 | 주로 단방향 (리더→태그) | 양방향 | 양방향 |
| 연결 절차 | 터치로 즉시 통신 | 별도 연결 없음 | 탐색과 인증 필요 | 정밀 거리 측정 기반 |
| 주요 용도 | 간편 결제, 교통, 출입 | 물류, 도서관 자산 관리 | 웨어러블, IoT 센서 | 정밀 위치, 디지털 키 |

- 선택 기준 : 결제나 출입처럼 물리적 터치가 자연스러운 상황은 NFC, 지속적인 데이터 연결은 BLE, 정밀 거리 측정이 필요하면 UWB를 택함.

## Ⅴ. NFC(Near Field Communication)의 한계와 방안

- 핵심 요약 : 짧은 거리와 낮은 전송률, 릴레이 공격, HCE 환경의 악성코드 위협이 주요 한계이며, 대역 외 연동과 거리 경계 검증, 토큰화로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 낮은 전송률과 짧은 거리 | 대용량 데이터 전송이나 원거리 인증에 단독 사용 불가 | NFC로 초기 인증만 수행하고 본 데이터는 BLE나 Wi-Fi로 전환 (대역 외 연동) | 연동 성공률 |
| 릴레이 공격 | 신호를 중계하여 원거리에서 결제·인증 가능 | **거리 경계** (Distance Bounding) 검증으로 응답 지연 시간을 제한 | 비정상 응답 지연 탐지 건수 |
| HCE 자격증명 유출 | 루팅·커널 탈취 시 메모리 상주 자격증명 노출 | TEE(Trusted Execution Environment) 격리 실행, 일회용 토큰 발급 | 토큰 재사용 탐지 건수 |

## Ⅵ. NFC(Near Field Communication)에 대한 기술사적 제언

- 핵심 요약 : 보안 요소 선택과 무선 기술 조합을 서비스 위험도에 맞춰 설계하는 것이 NFC 도입의 출발점임.
- 모바일 신분증처럼 신원 정보를 다루는 서비스는 ISO/IEC 18013-5 등 공식 표준을 따르고, 자격증명은 하드웨어 보안 요소에 두는 구성을 기본으로 삼는 것이 바람직함.
- 디지털 키처럼 원거리 감지와 근접 접촉을 함께 쓰는 서비스는 UWB나 BLE로 접근을 감지하고 NFC를 비상 수단으로 두는 복합 구성을 검토할 만함.
- 태그 위조가 문제되는 자산 관리에는 공개키 기반 전자서명을 담은 태그를 도입하여 정품 여부를 검증할 수 있도록 하는 편이 실효성이 있음.

## Ⅶ. 결론

- 핵심 요약 : NFC는 터치 거리에서 맺는 즉시 연결과 근접 보안을 강점으로 하는 근거리 무선 통신 기술이다.
- 시사점 : 전송 용량과 거리의 한계를 다른 무선 기술과의 역할 분담으로 보완할 때 NFC의 효용이 극대화된다.
