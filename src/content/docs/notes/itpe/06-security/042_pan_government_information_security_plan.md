- **범부처 정보보호 종합대책**: 부처별 보안 대응을 공동 과제로 묶어 국가 차원의 개선을 추진하는 정부 계획.
- **ISMS(Information Security Management System, 정보보호 관리체계)**: 정보보호 정책·조직·위험관리·통제의 운영체계.
- **ISMS-P(Information Security and Privacy Management System, 정보보호 및 개인정보보호 관리체계)**: 정보보호와 개인정보보호 관리체계를 함께 심사하는 국내 인증제도.
- **CISO(Chief Information Security Officer, 정보보호최고책임자)**: 조직의 정보보호 업무와 책임을 총괄하는 임원.
- **원스톱 신고체계**: 관계기관에 분산된 사고 신고·조사 절차를 이용자 관점에서 연계하려는 대책 과제.

```text
                 ┌─ 핵심 IT 시스템 점검·취약점 탐지
                 ├─ 이용자 중심 사고 대응·피해 구제
종합대책 ────────┼─ 공공·민간 보안 역량 강화
```

2025년 10월 발표된 1차 대책은 단기 실행과제를 제시했으며, 이후 2026년 1월 2차 종합대책이 별도로 발표된 점에 유의.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **범부처 정보보호 종합대책**은 관계부처가 공동으로 공공·민간의 긴급한 보안 개선 과제를 추진하는 정부 실행 계획. |
| 목적 | 반복되는 침해사고에 대응해 정보보호 역량과 이용자 보호를 강화. |

## Ⅱ. 추진 배경과 정책 방향

2025년 10월 22일 대책은 통신·금융·공공 등에서 이어진 해킹 사고에 대응하기 위한 단기 실행계획. 중·장기 과제는 별도 국가 사이버보안 전략으로 다룬다고 발표.

| 정책 방향 | 대책의 초점 |
|---|---|
| 핵심 IT 시스템 점검 | 주요 정보시스템의 대규모 보안 점검과 지속적 취약점 탐지 |
| 이용자 중심 대응 | 피해 예방·구제와 재발 방지 조치 강화 |
| 보안 역량 강화 | 공공·민간 투자·인력·산업·기술 역량 보강 |
| 국가 협력 강화 | 부처 간 신고·조사 연계와 정보 공유 |

## Ⅲ. 실행 과제 구성

```text
시스템 점검·취약점 탐지 ── 취약점 확인·개선
이용자 보호·사고 대응 ───── 신고·조사 연계·피해 구제
보안 역량 강화 ─────────── 투자·인력·기술 지원
국가 협력 ─────────────── 관계기관 공동 대응
```

정부 발표에는 1,600개 이상 IT 시스템 점검, 통신사 불시 점검, 공공부문 보안 투자·인력 강화, 원스톱 신고와 조사 협력 등이 포함. 이는 대책의 발표 과제이며 이행 성과와 구별.

## Ⅳ. 부처 공동 이행관리

| 관리 항목 | 확인 내용 |
|---|---|
| 과제 책임 | 소관·협조 기관과 의사결정 책임 명확화 |
| 실행 일정 | 점검·개선·제도 변경의 기한과 선행조건 관리 |
| 현장 확인 | 문서 제출만이 아니라 보안 통제와 피해 대응의 실제 작동 확인 |
| 결과 공개·환류 | 확인 가능한 성과와 미완료 사유를 공개 범위에 맞춰 점검·보완 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 정책 과제가 부처별 일정·성과 기준으로 나뉘면 범정부 성과를 국민 보호 결과와 연결하기 어려움. | 공통 과제 식별자 아래 책임부처·협조부처·현장 증적·이용자 영향 지표를 묶어 분기별 공동 점검하는 이행대장을 도입하는 방안을 제안. |
