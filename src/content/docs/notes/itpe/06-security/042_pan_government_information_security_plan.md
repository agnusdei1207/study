## Ⅰ. 범부처 정보보호 종합대책의 개요

- **개념** : 국가 사이버안보 위협 고도화, 지능형 공급망 침해, 국가 배후 해킹 조직의 기간망 공격에 대응하기 위해, 국가안보실을 중심으로 국정원, 과기정통부, 행안부, 국방부 등 범정부 유관 부처가 합동으로 수립한 국가 차원의 최상위 사이버 안보 종합 실행 전략.
- **배경 및 필요성** : 행정망 전산 장애 사태, 통신·금융 기반시설 침해, 국가 핵심 방산 기술 탈취 등 국가 안보와 국민 생활에 직결된 대형 보안 사고가 빈발함에 따라 개별 부처 단위 파편화된 대응의 한계 절감.
- **핵심 목적** : 국가 사이버안보 컨트롤타워 확립, 민·관·군 실시간 위협 정보 공유 체계 완성, 공급망 보안 및 제로트러스트 전면 확산, 국가 사이버 회복력 극대화.

## Ⅱ. 범부처 정보보호 종합대책의 핵심 아키텍처 및 동작 메커니즘

종합대책은 거버넌스 개편, 선제적 예방, 실시간 공조 대응, 보안 산업 생태계 육성의 4대 전략 축을 중심으로 범국가적 보안 체계를 가동함.

```text
[ 범부처 정보보호 종합대책 거버넌스 및 연계 구조 ]

                 +-------------------------------------+
                 |  국가안보실 (사이버안보 컨트롤타워) |
                 +------------------┬------------------+
                                    │ 정책 총괄 및 국가위기관리
         ┌──────────────────────────┼──────────────────────────┐
         ▼                          ▼                          ▼
  +---------------+          +---------------+          +---------------+
  | 국가정보원    |          | 과학기술정보  |          | 행안부 / 국방 |
  | (공공·안보)  |          | 통신부 (민간) |          | (전자정부/군) |
  | - 국가 MLS    |          | - C-TAS 고도화|          | - 행정망 안정 |
  | - N2SF 추진   |          | - 제로트러스트|          | - 국방 사이버 |
  +-------┬-------+          +-------┬-------+          +-------┬-------+
          │                          │                          │
          └──────────────────────────┼──────────────────────────┘
                                     │ 실시간 CTI 위협 공유 및 합동 분석
                                     ▼
  +-------------------------------------------------------------+
  | 민·관·군 통합 사이버 위협 조기경보 및 침해대응 센터        |
  |  - 위협 정보(STIX/TAXII) 자동 전파, 공급망 SBOM 검증 지원   |
  |  - 주요정보통신기반시설 보호 강화, 핵심 인재 양성 지원      |
  +-------------------------------------------------------------+
```

- **국가 사이버안보 컨트롤타워 강화** : 국가안보실의 사이버안보비서관을 중심으로 범부처 사이버위기관리 컨트롤타워 일원화.
- **민·관·군 통합 CTI 공유(C-TAS 2.0)** : KISA의 C-TAS(사이버위협정보분석공유시스템)와 국정원 국가사이버안보센터를 연계하여 위협 지표 실시간 양방향 공유.
- **SW 공급망 전주기 보안 내재화** : 공공 조달 소프트웨어에 대해 SBOM 제출 및 취약점 검증을 단계적으로 의무화.
- **핵심 정보통신기반시설 보호체계 고도화** : 전력, 가스, 통신, 금융 등 국가 기반시설에 대해 사이버 공격 모의훈련(Cyber Range) 의무화.

## Ⅲ. 범부처 정보보호 종합대책의 세부 구성 요소 및 비교 분석

| 구분 | 기존 사이버보안 체계 | 범부처 종합대책 개선 체계 | 기대 효과 |
| --- | --- | --- | --- |
| 컨트롤타워 | 부처별 분절 운영 (국정원, 과기부, 국방부) | 국가안보실 중심 총괄 지휘 및 법제화 | 위기 시 일사불란한 국가 총력 대응 |
| 위협 정보 공유 | 기관별 폐쇄적 수동 통보 (수시간 소요) | STIX/TAXII 기반 실시간 기계 판독형 자동 공유 | 제로데이 공격 발생 시 수분 내 전사 전파 |
| 인프라 보안 | 획일적 망분리 의존 | N2SF 다층보안체계 및 제로트러스트 전환 | 공공 AI 혁신과 국가 기밀 보호 양립 |
| 공급망 통제 | 완제품 납품 후 사후 취약점 점검 | 개발 단계부터 SBOM, 무결성 검증 의무화 | SolarWinds형 공급망 테러 사전 예방 |
| 인력 양성 | 단순 자격증 중심 단기 교육 | 화이트해커 대규모 양성 및 실전 사이버훈련장 | 국가 방어 전문 최정예 화이트햇 육성 |

- 범부처 정보보호 종합대책은 개별 조직의 '점(Point)' 방어에서 국가 전체를 아우르는 '면(Surface)' 방어로 확장하여 국가 배후 APT 공격에 대응하는 국가 생존 전략임.

## Ⅳ. 범부처 정보보호 종합대책의 주요 한계점 및 해결 방안

- **국가사이버안보기본법 등 상위 법률 제정 지연에 따른 부처 간 R&R 갈등** :
  - **한계점** : 사이버안보 컨트롤타워를 법적으로 명시하는 기본법 제정이 국회에서 장기간 표류하여 부처 간 관할권 분쟁 잔존.
  - **해결 방안** : 대통령 훈령 및 국가사이버위기관리규정을 개정하여 실효적 집행력을 확보하고 여야 합의 기반 기본법 조속 통과 추진.
- **민간 기업의 침해사고 자발적 공유 기피(기업 이미지 실추 우려)** :
  - **한계점** : 침해 발생 시 과징금이나 대외 신뢰도 하락을 우려하여 C-TAS에 위협 정보를 은폐하거나 늑장 신고하는 문제.
  - **해결 방안** : 자발적 신속 신고 기업에 대해 행정 처분 감경(Safe Harbor 제도) 및 피해 복구 기술 지원 인센티브 법제화.
- **중소 협력업체의 공급망 보안 요건 충족 비용 부담** :
  - **한계점** : 공공 입찰에 SBOM 제출 및 제로트러스트 인증이 요구될 경우 영세 SW 개발업체의 납품 포기 및 양극화 심화.
  - **해결 방안** : 정부 주도의 오픈소스 기반 공급망 보안 검증 플랫폼(K-SBOM 플랫폼) 무상 개방 및 보안 컨설팅 지원.

## Ⅴ. 범부처 정보보호 종합대책 적용 및 발전을 위한 기술사적 제언

- **국가 사이버 위협 통합 데이터 레이크 구축** : 국정원, 경찰청, KISA, 군의 침해 데이터를 단일 빅데이터 플랫폼에 결합하여 국가 배후 공격 그룹 프로파일링 강화.
- **공공·금융 핵심 시스템의 BCP(업무연속성) 상시 모의훈련 의무화** : 시스템 전면 마비 상황을 가정한 국가급 재해복구(DR) 불시 전환 훈련 연 2회 이상 정례화.
- **글로벌 동맹국(미국, 일본, 파이브아이즈)과의 사이버 공조 확대** : 랜섬웨어 자금 세탁 추적 및 국가 배후 해커 제재를 위한 국제 다자간 공조 협약 체결 필수.
