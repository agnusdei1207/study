## 연관 키워드

- 벨라파듈라 모델(BLP, Bell-LaPadula), 다중 보안 등급(MLS, Multi-Level Security), 강제 접근통제(MAC, Mandatory Access Control)
- 단순 보안 속성(Simple Security Property), No Read Up, No Write Down, *-property
- 은닉 채널(Covert Channel), 비바 모델(Biba), 클락-윌슨 모델(Clark-Wilson), 탈분류(Declassification), 신뢰된 주체(Trusted Subject)

## Ⅰ. 벨라파듈라 모델(BLP)의 개요

- 핵심 요약 : 다중 보안 등급 환경에서 기밀 정보의 하향 유출을 규칙으로 차단하는 강제 접근통제 기반 기밀성 모델.
- 개념 : 주체(Subject)와 객체(Object)에 보안 등급을 부여하고, 등급 차이에 따라 읽기와 쓰기를 제한하는 **기밀성 모델** (BLP, Bell-LaPadula Model). 미 국방부(DoD, Department of Defense)의 **다중 보안 등급** (MLS, Multi-Level Security) 체계를 형식화한 모델임.
- 배경 및 필요성 : 군사·국가 기밀 시스템에서는 사용자 재량에 맡긴 접근통제만으로 기밀 누설을 막기 어려워, 시스템이 규칙으로 강제하는 **강제 접근통제** (MAC, Mandatory Access Control) 이론이 요구됨.
- 주요 목적 : 트로이 목마 같은 악성 프로세스가 상위 기밀을 하위 등급으로 빼내는 것을 막고, 기밀성을 형식적으로 보장.

## Ⅱ. 벨라파듈라 모델(BLP)의 특징 및 장점

- 핵심 요약 : 등급 기반 읽기·쓰기 규칙을 시스템이 강제해 기밀 정보의 하향 유출을 원천 차단하는 구조.

1. **단순 보안 속성** (Simple Security Property, No Read Up) : 주체는 자신보다 높은 등급의 객체를 읽을 수 없음 → 상위 기밀 열람 차단.
2. 쓰기 규칙 (**No Write Down**, \*-property) : 주체는 자신보다 낮은 등급의 객체에 쓸 수 없음 → 기밀 내용의 하향 복사 차단.
3. 강제성 : 사용자가 등급 규칙을 임의로 바꿀 수 없고 시스템이 판정 → 악성 프로그램이 있어도 등급 간 흐름이 통제 상태를 유지.

## Ⅲ. 벨라파듈라 모델(BLP)의 구조 (흐름)

- 핵심 요약 : 보안 등급이 격자(Lattice) 형태로 정렬되고, 읽기와 쓰기 요청이 등급 비교 한 번으로 판정되는 구조.

```text
[ 보안 등급 격자 ]

Top Secret (최상위)
   ↓ 하위 등급 읽기 허용
Secret
   ↓ 하위 등급 읽기 허용
Unclassified (최하위)
```

```text
[ 읽기 요청 판정 ]

읽기 요청 (Read)
   ↓
객체 등급 ≤ 주체 등급 ?
   ↓ 예 : 허용 (Read Down)
   ↓ 아니오 : 거부 (No Read Up)
```

```text
[ 쓰기 요청 판정 ]

쓰기 요청 (Write)
   ↓
객체 등급 ≥ 주체 등급 ?
   ↓ 예 : 허용 (Write Up, Blind Write)
   ↓ 아니오 : 거부 (No Write Down)
```

## Ⅳ. 벨라파듈라 모델(BLP)과 유사 모델의 비교

- 핵심 요약 : BLP는 기밀성, 비바 모델은 무결성, 클락-윌슨 모델은 업무 절차 기반 무결성을 목표로 해 보호 대상이 서로 다름.

| 비교 축 | 벨라파듈라 모델 (BLP) | 비바 모델 (Biba) | 클락-윌슨 모델 (Clark-Wilson) |
| --- | --- | --- | --- |
| 핵심 목표 | 기밀성 보장 | 무결성 보장 | 상업적 무결성과 직무 분리 |
| 읽기 규칙 | No Read Up | No Read Down | 인증된 변환 절차를 거친 접근 |
| 쓰기 규칙 | No Write Down | No Write Up | 검증된 절차 외 변경 금지 |
| 주된 적용 분야 | 군사, 국방, 정보기관 | 금융 원장, 시스템 무결성 | 기업 ERP, 회계 시스템 |
| 한계 | 무결성 훼손 가능, 은닉 채널 취약 | 기밀성 유출 방어 불가 | 구현 복잡도와 운영 부담 큼 |

- 선택 기준 : 보호 목표가 기밀성이면 BLP, 데이터 무결성이면 비바 모델, 업무 절차와 직무 분리가 핵심이면 클락-윌슨 모델을 기준으로 삼음.

## Ⅴ. 벨라파듈라 모델(BLP)의 한계와 방안

- 핵심 요약 : 무결성 미보장, 은닉 채널, 경직된 등급 운영을 이중 모델 적용, 채널 분석, 신뢰 주체 기반 탈분류로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 무결성 훼손 | Write Up이 허용되어 하위 주체가 고등급 객체에 내용을 덧붙여 무결성 오염 | 무결성 규칙을 담당하는 **비바 모델**을 함께 적용하는 이중 모델 구성 | 무결성 검증 실패 건수 |
| **은닉 채널** (Covert Channel) | 공유 자원의 점유 시간 등을 조작해 기밀이 우회 전달됨 | **공유 자원 매트릭스** (Shared Resource Matrix) 분석으로 채널을 식별하고 대역폭 제한, 타이밍 잡음 주입 | 식별된 채널 수, 채널 대역폭 |
| 경직된 등급 운영 | 상위 문서의 하향 공개가 전면 차단되어 업무 지연 발생 | **신뢰된 주체** (Trusted Subject)만 감사 로그와 다중 승인을 거쳐 **탈분류** (Declassification) 수행 | 탈분류 처리 시간, 감사 로그 완전성 |

## Ⅵ. 벨라파듈라 모델(BLP)에 대한 기술사적 제언

- 핵심 요약 : 기밀 시스템은 BLP 규칙을 설계 기준선으로 두고, 무결성과 동적 권한 요구는 별도 체계로 보완하는 다층 설계로 운영.

1. 정책 : 정보보안 정책 부서가 기밀 등급 체계와 객체 분류 기준을 문서로 정하고, 업무 변화에 맞추어 주기적으로 재검토하도록 제도화.
2. 설계 : 시스템 설계 단계에서 기밀성 규칙을 강제 기능으로 명시하고, 무결성 요구는 별도 모델로 분리해 설계 검토 항목에 포함.
3. 운영 : 보안 관제 조직이 접근 판정 로그를 상시 분석해 규칙 위반 시도를 탐지하고, 정적 등급 모델의 경직성은 속성 기반 접근통제(ABAC, Attribute-Based Access Control)와 제로 트러스트 원칙을 결합해 보완.

## Ⅶ. 결론

- 핵심 요약 : BLP는 정보 흐름의 방향을 규칙으로 고정해 기밀성을 형식적으로 보장한 모델.
- 시사점 : 기밀성 규칙만으로는 무결성과 은닉 채널을 막을 수 없으므로, 다른 모델과 운영 통제를 함께 갖출 때 실효성이 확보됨.
