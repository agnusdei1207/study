## 지식 로드맵 내 현재 위치

지식 위치: 디지털 신원 → 정부 발급 신분증 → **모바일 신분증**

## 30초 인출

- 본질: 행정기관이 발급하고 스마트폰에 저장해 신원·자격을 제시하는 전자적 신분증
- 국내 정부 모바일 신분증은 실물 신분증과 같은 법적 효력으로 안내되며, 검증자는 공식 검증 앱·연계 방식으로 진위 확인
- 선택적 정보 제공과 분실 신고·폐기 중요. DID·블록체인·영지식증명·오프라인 검증을 모든 모바일 ID의 필수 구조로 일반화하지 않음

## 1교시 예상문제 (10점)

> 모바일 신분증의 발급·제시·검증 주체와 개인정보 최소 제공 방식을 설명하시오. (예상·10점)

## 1교시 10점 답안

### Ⅰ. 개념·주체

| 주체 | 역할 |
|---|---|
| 발급기관 | 신원 확인과 신분증 발급·상태 관리 |
| 보유자 | 단말에 신분증 보유·필요 정보 제시 |
| 검증자 | 공식 검증 수단으로 진위와 요청 속성 확인 |

### Ⅱ. 이용 흐름

```text
발급기관의 신원 확인 → 단말 발급·보호
                    → 검증자의 속성 요청 → 보유자 제시
                    → QR·공식 검증 서비스로 진위 확인
```

성인 여부 등 필요한 속성만 요청·제공해 과잉 노출을 줄이는 방향.

## 2~4교시 예상문제 (25점)

> 모바일 신분증의 발급·저장·제시·검증·폐기 생명주기와 개인정보 보호 및 도용 방지 방안을 설명하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

국내 정부 모바일 신분증은 행정기관이 발급하는 스마트폰 기반 신분증. 실물 신분증과 같은 효력의 사용 범위를 공식 안내에 따라 확인.

### Ⅱ. 서비스 구조

```text
발급기관 → 본인 확인·발급 → 보유자 단말
                              │ 필요한 정보 제시
                              ▼
                      검증자 앱·연계 서비스
                              │ 진위·유효 상태 확인
                              ▼
                       요청한 속성의 확인
```

행정안전부는 국내 서비스의 공개키 암호와 블록체인 기반 검증을 설명. 이 설명을 모든 모바일 ID 기술의 필수 국제 구조로 확대하지 않음.

### Ⅲ. 단계별 보호

| 단계 | 위협 | 통제 |
|---|---|---|
| 발급 | 타인 명의 발급 | 실물·본인 확인, 발급 이력 |
| 저장 | 단말 분실·악성코드 | 단말 보안 기능, 앱 인증 |
| 제시 | 화면 캡처·재사용 | 동적 QR·검증 앱·시각 확인 |
| 검증 | 과다 개인정보 수집 | 필요한 정보만 요청·제공 |
| 폐기 | 분실 후 계속 이용 | 신고·잠금·재발급 절차 |

### Ⅳ. 법·기술 경계

| 항목 | 올바른 해석 |
|---|---|
| 법적 효력 | 국내 정부가 발급하는 모바일 신분증의 공식 효력 안내 |
| 선택적 제공 | 이용 사례·검증 방식별 지원 속성 확인 |
| 블록체인 | 국내 서비스 구성 요소로 설명; 개인정보 원문이 원장에 저장된다고 단정 금지 |
| ZKP | 가능한 프라이버시 기술이나 모든 검증에 사용한다고 단정 금지 |
| 온라인 여부 | 검증 방식·연계 시스템에 따라 확인 |

### Ⅴ. 기술사적 제언

정부 발급 신원증명의 신뢰성, 최소 속성 제공, 분실·폐기 처리와 검증자 측 데이터 보관을 함께 설계.
