## 연관 키워드

- 모바일 신분증, 모바일 주민등록증, 보안 영역(SE, Secure Element), 신뢰 실행 환경(TEE, Trusted Execution Environment)
- 검증 가능한 자격증명(VC, Verifiable Credential), 선택적 정보 제시, 1회용 제시 정보, 폐기 목록
- ISO/IEC 18013-5, 영지식 증명(ZKP, Zero-Knowledge Proof), 화이트박스 암호, 킬스위치

## Ⅰ. 모바일 신분증의 개요

- 핵심 요약 : 스마트폰 보안 영역에 신원 정보를 저장하고 필요한 정보만 제시하는 국가 공인 디지털 신분증 체계.
- 개념 : 개인의 스마트폰 **보안 영역** (SE, Secure Element 또는 TEE)에 암호화 저장되어 온·오프라인에서 신원과 자격을 증명하는 **모바일 신분증**.
- 배경 및 필요성 : 플라스틱 실물 신분증의 위변조, 분실, 과도한 개인정보 노출 문제를 해결하기 위해 도입됨. 2024년 12월 27일 세종 등에서 **모바일 주민등록증** 발급이 시작되었고 2025년 3월 전국 발급으로 확대되었음.
- 주요 목적 : 신분증 휴대의 불편과 분실 시 개인정보 노출을 줄이고, 위변조 방지와 최소 정보 제공을 통한 프라이버시 중심의 디지털 행정을 구현.

## Ⅱ. 모바일 신분증의 특징 및 장점

- 핵심 요약 : 선택적 정보 제시, 단말 기반 키 보관, 실시간 폐기, 전자서명 검증이 결합되어 신원 노출을 줄이고 위변조를 어렵게 하는 방식.

1. **선택적 정보 제시** (Selective Disclosure) : 검증 요청에 맞춰 필요한 속성만 추출해 전자서명과 함께 제출 → 주민등록번호 등 과다 노출 방지.
2. **단말 기반 키 보관** : 발급된 자격 정보를 보안 영역에 하드웨어 바인딩하여 저장 → 복제와 키 추출이 어려워짐.
3. **전자서명 검증** : 발급기관의 **공개키 기반 구조**(PKI, Public Key Infrastructure) 서명으로 진위를 확인 → 육안 위조 판별을 대체.
4. **실시간 폐기 확인** : 분실 신고 시 폐기 목록에 반영하여 즉시 무효화 → 습득자의 도용 기간 단축.

## Ⅲ. 모바일 신분증의 발급·제시 구조 (흐름)

- 핵심 요약 : 발급기관의 서명으로 자격 정보를 단말에 저장하고, 검증자가 1회용 제시 정보를 공개키와 폐기 상태로 확인하는 구조.

```text
[ 1. 발급 ]

신원 확인 (주민센터, 운전면허시험장)
   ↓
발급기관이 전자서명한 자격 정보 생성
   ↓
단말 보안 영역에 암호화 저장
```

```text
[ 2. 제시와 검증 ]

이용자: 필요한 속성만 선택
   ↓
1회용 제시 정보 생성 (QR 또는 BLE)
   ↓
검증자: 발급기관 공개키로 서명 확인
   ↓
폐기 상태 조회 후 승인
```

## Ⅳ. 실물 신분증·모바일 신분증·민간 인증서의 비교

- 핵심 요약 : 실물 신분증의 노출과 위조 문제를 모바일 신분증이 선택 공개와 전자서명으로 줄이고, 민간 인증서는 신분증과 같은 법적 효력이 제한됨.

| 비교 항목 | 실물 플라스틱 신분증 | **모바일 신분증** | 민간 모바일 인증서 |
|---|---|---|---|
| 발급 주체 | 행정안전부, 경찰청 | 행정안전부 | 민간 전자서명인증사업자 |
| 법적 효력 | 법정 신분증 | 실물 주민등록증과 동일한 법적 효력 | 전자서명 효력 (신분증 대체는 제한) |
| 정보 제공 방식 | 주민등록번호, 주소 등 전부 노출 | 필요한 속성만 선택 공개 | 민간 앱 내부 인증 확인 |
| 위변조 검증 | 육안 홀로그램 확인 (위조 위험) | 발급기관 전자서명 검증 | 중앙 인증 서버 질의 |
| 분실 시 위험 | 습득자의 개인정보 악용 | 생체인증 잠금과 원격 폐기 | 단말 잠금 해제 시 위험 |

## Ⅴ. 모바일 신분증의 한계와 방안

- 핵심 요약 : 오프라인 폐기 확인, 단말 탈취, 화면 위조, 저가 단말의 키 보관 문제를 단말 보안과 검증 절차로 보완.

| 한계 | 원인·영향 | 대응 방안 |
|---|---|---|
| 오프라인 폐기 확인 불가 | 통신 음영 지역에서 실시간 폐기 여부를 확인하지 못함 | 짧은 유효 기간을 둔 검증 정보를 캐싱하고 주기적으로 갱신 |
| 단말 탈취 후 PIN 우회 | PIN을 훔쳐보거나 강제로 잠금 해제하여 신분증 도용 | 생체 인증 실패 누적 시 앱 데이터 잠금, 분실 신고 시 원격 폐기(킬스위치) |
| 위조 화면 제시 | 루팅 단말에서 화면 캡처 방지가 무력화됨 | 움직이는 동적 워터마크와 짧은 유효 시간 표시, 검증자 앱의 스캔 확인 의무화 |
| 저가 단말의 키 탈취 | 보안 영역이 없어 소프트웨어 키스토어에 키를 저장 | 화이트박스 암호 라이브러리 적용과 주기적 재인증 등 차등 보안 정책 |

## Ⅵ. 모바일 신분증에 대한 기술사적 제언

- 핵심 요약 : 프라이버시 기술, 국제 표준 호환, 민간 개방을 함께 추진하여 모바일 신분증을 공공과 민간이 공유하는 신원 기반으로 확산.

개인정보 최소 제공을 기술로 보장하려면 영지식 증명 기반 자격 증명을 단계적으로 도입하고, 주민등록번호 노출 없이 속성만 확인하는 방식을 검토해야 한다.

해외 공항이나 렌터카 등에서 통용되려면 국제 표준인 ISO/IEC 18013-5 및 mdoc 형식과의 호환성을 확보하는 것이 필요하다. 세부 기술 구조는 행정안전부 공식 자료를 기준으로 확인해야 한다.

신원 검증 기능을 공개된 API와 SDK로 제공하면 유통, 핀테크 등 민간 서비스가 신원 확인 비용을 줄이고 비대면 거래의 신뢰를 높일 수 있다.

## Ⅶ. 결론

- 핵심 요약 : 모바일 신분증은 정보 노출을 줄이는 신원 증명 체계이며, 신뢰는 보안 영역과 폐기 검증이 뒷받침될 때 성립함.
- 선택적 공개와 단말 보안이 결합되어야 편의성과 프라이버시를 함께 얻을 수 있음.
