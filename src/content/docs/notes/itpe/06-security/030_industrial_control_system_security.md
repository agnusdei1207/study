## Ⅰ. 산업제어시스템(ICS) 보안의 개요

- 핵심 요약 : 공정의 안전성과 가용성을 최우선으로 두고 제어 설비를 사이버 위협으로부터 보호하는 보안 체계.
- 개념 : 발전, 전력, 상수도, 석유화학 등 국가 기반시설의 물리 공정을 감시하고 제어하는 **ICS** (Industrial Control System, 산업제어시스템)의 사이버 위협을 방어하는 체계. 주요 구성 장비는 SCADA(Supervisory Control and Data Acquisition, 감시제어 및 데이터 수집), DCS(Distributed Control System, 분산제어시스템), PLC(Programmable Logic Controller, 프로그램 가능 논리 제어기), RTU(Remote Terminal Unit, 원격 단말 장치).
- 배경 및 필요성 : 폐쇄망으로 운영되던 공정 제어망이 스마트화와 원격 유지보수를 위해 IT망과 인터넷에 연결되면서, Stuxnet(2010), Industroyer(2016), 콜로니얼 파이프라인 랜섬웨어(2021) 등 사이버 공격이 실제 물리 피해로 이어짐이 확인되어 보안 체계가 필요해짐.
- 주요 목적 : 기반시설의 가용성(Availability)과 안전성(Safety) 최우선 보장, 제어 명령의 위변조 차단, IT와 OT(Operational Technology, 운영기술) 경계의 격리.

## Ⅱ. 산업제어시스템(ICS) 보안의 특징 및 장점

- 핵심 요약 : 계층 분리와 프로토콜 검사를 결합해 제어 명령을 통제하고, 가용성과 안전성 중심으로 운영하여 공정 중단을 막는 구조.

1. **퍼듀 모델** (Purdue Model, 공장 네트워크를 레벨 0~5로 나누는 참조 모델) : 계층별로 영역을 분리 → IT망의 공격이 공정 제어망으로 번지는 경로를 차단.
2. **산업용 DMZ** (Demilitarized Zone, 비무장지대) : IT와 OT 사이에 완충 영역을 두어 두 망의 직접 통신을 차단 → 외부 접속이 공정망에 닿기 전에 중계와 검사를 거침.
3. **Data Diode** (단방향 데이터 전송장치) : 송신 방향만 허용하는 하드웨어 → 공정 데이터는 IT망으로 반출되고 역방향 유입은 원천 차단.
4. **산업용 프로토콜 DPI** (Deep Packet Inspection, 심층 패킷 검사) : Modbus, DNP3 등 제어 프로토콜의 쓰기 명령과 펌웨어 업데이트 패킷을 검사 → 허용되지 않은 제어 명령을 차단.
5. 가용성과 안전성 중심 설계 : 기밀성보다 공정 연속성과 인명 안전을 우선 → 보안 조치가 공정 중단을 일으키지 않도록 설계.

## Ⅲ. 산업제어시스템(ICS) 보안의 구조 (흐름)

- 핵심 요약 : 퍼듀 모델의 계층 사이에 산업용 DMZ를 두고, 단방향 전송장치로 OT 데이터만 IT망에 전달하는 구조.
- **ISA/IEC 62443** (산업 자동화 및 제어 시스템 보안 국제 표준) : 구성요소, 시스템, 조직 프로세스 단위의 보안 요구사항을 정한 표준으로, ISA(International Society of Automation)와 IEC(International Electrotechnical Commission)가 공동으로 마련.

```text
[ 퍼듀 모델 기반 ICS 계층 ]

Level 5 : 기업 비즈니스망 (업무 시스템, 인터넷)
   ↓
Level 4 : 기업 전산망 (IT 인프라)
   ↓
[ 산업용 DMZ (IT/OT 경계) ]
   ↓
Level 3 : 공정 운영 관리망 (SCADA 서버)
   ↓
Level 2 : 단위 제어망 (운전 콘솔)
   ↓
Level 1 : 로컬 제어망 (PLC, RTU)
   ↓
Level 0 : 물리 공정 (센서, 밸브, 모터)
```

```text
[ 단방향 전송 흐름 ]

공정 데이터 (OT 영역)
   ↓ 송신 광케이블만 연결
Data Diode (수신선 물리 절단)
   ↓ 단방향 전달
IT망 (분석과 보고)
```

## Ⅳ. 산업제어시스템(ICS) 보안의 비교

- 핵심 요약 : IT 보안은 기밀성을 우선하고 ICS 보안은 가용성과 안전성을 우선하므로, 같은 보안 기술도 적용 방식이 달라야 함.

| 비교 항목 | 전통적 IT 보안 | 산업제어시스템 (OT/ICS) 보안 | 적용 보안 기술 |
| --- | --- | --- | --- |
| 최우선 가치 (CIA, Confidentiality·Integrity·Availability) | 기밀성 우선 | 가용성 우선 | 무중단 안전 설계 |
| 보안 목표 | 데이터 유출과 지식재산 보호 | 인명 안전과 설비 파괴 방지 | ISA/IEC 62443, 단방향 보안 게이트웨이 |
| 설비 수명 | 장비 교체 주기가 비교적 짧아 패치가 상대적으로 용이 | 설비가 수십 년 운영되어 패치 적용이 어려움 | 가상 패칭 (Virtual Patching) |
| 실시간성 | 일정 수준의 지연 허용 | 결정론적 저지연 필수 | 인라인 차단 대신 미러링 모니터링 |
| 프로토콜 특성 | 표준 암호화 (TLS(Transport Layer Security), IPsec(Internet Protocol Security)) | 인증과 암호화가 약한 레거시 (Modbus, DNP3) | 산업용 IDS (Intrusion Detection System, 침입 탐지 시스템), 프로토콜 DPI |

- 선택 기준 : 백신 업데이트나 재부팅 한 번이 공정 중단으로 이어질 수 있으므로, 인라인 차단보다 패시브 미러링 기반 이상 탐지를 우선 적용.

## Ⅴ. 산업제어시스템(ICS) 보안의 한계와 방안

- 핵심 요약 : 레거시 프로토콜, 패치 불가 설비, 원격 유지보수 경로라는 세 가지 취약 지점을 보안 게이트웨이, 가상 패칭, 접근 통제로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 레거시 프로토콜의 인증·암호화 부재 | Modbus, DNP3 등 오래된 통신은 암호화와 송신자 인증이 없어 스푸핑과 재생 공격에 취약 | 신규 설비에는 보안 내장 프로토콜인 OPC UA(OPC Unified Architecture, TLS 지원)를 적용하고, 기존 설비에는 IPsec 암호화 래퍼 게이트웨이 배치 | 평문 프로토콜 잔존 비율 |
| **PLC 펌웨어 패치 지연** | 24시간 가동되는 연속 공정에서는 재부팅이 필요한 패치를 정기 보수 시점까지 적용하기 어려움 | **산업용 IPS** (Intrusion Prevention System, 침입 방지 시스템)로 취약점 공격 패킷을 네트워크에서 차단하는 **가상 패칭** (Virtual Patching) | 미패치 취약점 보유 설비 수 |
| 유지보수 업체의 원격 접속과 USB 반입 | 원격 벤더의 상시 접속 경로나 감염된 노트북, USB가 제어망에 연결되어 악성코드 전파 | 제어망 반입 기기의 검사 절차 의무화, 원격 유지보수는 **ZTNA** (Zero Trust Network Access, 제로트러스트 네트워크 접근) 게이트웨이 경유와 세션 녹화 | 원격 접속 세션 기록률, 반입 검사 실패 건수 |

## Ⅵ. 산업제어시스템(ICS) 보안에 대한 기술사적 제언

- 핵심 요약 : 표준 기반 거버넌스, 공정 데이터 기반 탐지, 기반시설 정기 진단을 결합하여 공정 안전을 상시 보장하는 체계로 전환.

1. 표준 기반 인증 체계 : 제어 시스템 보안 요구사항을 ISA/IEC 62443의 구성요소, 시스템, 조직 프로세스 단위로 나누어 단계별 인증을 받는 거버넌스를 수립하는 것이 필요.
2. 공정 데이터 기반 탐지 : 네트워크 패킷뿐 아니라 압력, 온도, 회전수 같은 공정 센서 데이터의 이상 패턴을 함께 보는 **공정 이상 탐지** (Process Anomaly Detection) 체계를 도입하는 것이 필요.
3. 기반시설 정기 진단 : **주요정보통신기반시설** 지정 설비를 대상으로 취약점 분석과 평가를 정기적으로 실시하고, 재해복구 훈련을 공정 제어 관점에서 함께 점검하는 것이 필요.

## Ⅶ. 결론

- 핵심 요약 : ICS 보안은 정보 보호가 아니라 공정의 안전과 연속성을 지키는 보안이며, 그 기준이 IT 보안과 근본적으로 다름.
- 시사점 : 계층 분리와 물리 공정 감시를 결합하는 설계가 기반시설 사이버 안전의 기본 전제로 자리 잡는 흐름.
