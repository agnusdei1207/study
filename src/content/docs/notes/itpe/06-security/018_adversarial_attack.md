## Ⅰ. 적대적 공격(Adversarial Attack)의 개요

- **개념** : 인공지능 및 딥러닝 모델의 취약점을 악용하여, 인간의 시각이나 청각으로는 감지할 수 없는 미세한 노이즈(적대적 섭동, Perturbation)를 정상 데이터에 의도적으로 주입함으로써 모델이 완전히 잘못된 예측이나 오분류를 내리도록 유도하는 사이버 공격.
- **배경 및 필요성** : 자율주행차(표지판 인식 오류), 금융 이상탐지(FDS 사기 탐지 회피), 의료 AI(오진 유도), 공항 안면인식 시스템 등 미션 크리티컬한 AI 시스템이 실제 환경에 배포되면서 심각한 물리적·경제적 안전 위협으로 대두.
- **핵심 목적** : 딥러닝 모델의 결정 경계(Decision Boundary) 취약성 이해, 모델 강건성(Robustness) 평가 및 적대적 방어 기법을 통한 고신뢰 AI 구축.

## Ⅱ. 적대적 공격(Adversarial Attack)의 핵심 아키텍처 및 동작 메커니즘

적대적 공격은 손실 함수(Loss Function)의 기울기(Gradient)를 역이용하여 모델의 손실을 최대화하는 방향으로 미세 노이즈를 계산하여 원본 입력에 덧씌우는 원리로 동작함.

```text
[ FGSM(Fast Gradient Sign Method) 공격 메커니즘 ]

   [ 원본 이미지 (x) ]           [ 적대적 섭동 (Perturbation) ]        [ 적대적 예제 (x_adv) ]
   "팬더" (낮은 신뢰도)        ε * sign(∇x J(θ, x, y))              "긴팔원숭이" (높은 신뢰도)
  +--------------------+        +--------------------+              +--------------------+
  |                    |        |                    |              |                    |
  |     (정상 이미지)   |   +    | (인간 눈에 안보이는|      =       | (인간은 팬더로 봄,  |
  |                    |        |  미세한 노이즈 패턴)|              |  AI는 확신 긴팔원숭이|
  +--------------------+        +--------------------+              +--------------------+
            │                             │                                   │
            ▼                             ▼                                   ▼
      [ AI 모델 f(x) ]            [ 손실 함수 기울기 ]                 [ 오분류 발생 ]
       y = 'Panda'                 최대화 방향 탐색                    y' = 'Gibbon'
```

- **FGSM(Fast Gradient Sign Method)** : 입력에 대한 손실 함수의 기울기 부호(sign) 방향으로 엡실론(ε)만큼 노이즈를 1회 추가하여 초고속으로 적대적 예제 생성.
- **PGD(Projected Gradient Descent)** : 미세한 스텝 크기로 여러 번 반복하여 기울기를 계산하고 허용 범위 내로 투영하는 가장 강력한 1차 화이트박스 공격.
- **C&W 공격(Carlini & Wagner)** : 섭동 크기(L0, L2, L∞ 노름)를 최소화하면서 오분류를 유도하는 최적화 기반 공격으로 기존 방어 메커니즘을 대부분 무력화.
- **화이트박스 vs 블랙박스 공격** : 모델 구조와 가중치를 완전히 알고 공격하는 화이트박스와, 입출력 쿼리 결과(점수)만으로 모델을 복제(Surrogate Model)하여 공격하는 블랙박스.

## Ⅲ. 적대적 공격(Adversarial Attack)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 적대적 예제 (Adversarial Example) | 데이터 중독 (Data Poisoning) | 백도어 공격 (Backdoor Attack) |
| --- | --- | --- | --- |
| 공격 수행 시점 | 추론 단계 (Inference Time) | 학습/훈련 단계 (Training Time) | 학습/훈련 단계 (Training Time) |
| 조작 대상 | 입력 데이터 (노이즈 섭동 주입) | 학습 데이터셋 전체 또는 일부 | 학습 데이터 + 특정 트리거(Trigger) |
| 모델 가중치 변화 | 모델 가중치는 변경되지 않음 | 모델 파라미터 자체가 오염됨 | 특정 트리거에 반응하도록 파라미터 변조 |
| 공격 목적 | 단일 인스턴스 예측 오분류 유도 | 전반적인 모델 정확도 저하 | 평시 정상 동작, 트리거 제시 시 악성 동작 |
| 대표 방어 기법 | 적대적 훈련(Adversarial Training) | 데이터 위생화(Data Sanitization) | 신경망 역엔지니어링(Neural Cleanse) |

- 적대적 예제는 학습 완료 후 서빙 중인 정상 모델을 실시간으로 속이는 공격인 반면, 포이즈닝과 백도어는 학습 파이프라인 자체를 오염시키는 공급망 공격에 해당함.

## Ⅳ. 적대적 공격(Adversarial Attack)의 주요 한계점 및 해결 방안

- **방어 기법 도입 시 정상 데이터에 대한 일반화 정확도(Accuracy) 하락** :
  - **한계점** : 적대적 훈련(Adversarial Training)을 통해 강건성을 높이면 결정 경계가 지나치게 완만해져 정상 샘플에 대한 인식 성능이 저하되는 트레이드오프 발생.
  - **해결 방안** : TRADES 및 고유값 정규화 기법을 도입하여 깨끗한 정확도(Clean Accuracy)와 강건한 정확도(Robust Accuracy) 사이의 수학적 최적 평형점 도출.
- **전이성(Transferability)을 악용한 블랙박스 대리 모델 공격의 범용성** :
  - **한계점** : 타깃 모델의 내부 구조를 몰라도 공격자가 자체 구축한 오픈소스 모델에서 생성한 적대적 예제가 다른 상용 AI 모델에서도 동일하게 오작동하는 취약성.
  - **해결 방안** : 입력 데이터에 무작위 리사이징, 패딩, JPEG 압축 등의 랜덤 변환(Random Transformation)을 적용하여 섭동의 구조적 전이성을 파괴.
- **물리적 세계(Physical World)에서의 패치 공격(Adversarial Patch)** :
  - **한계점** : 정지 표지판에 특수 스티커를 부착하거나 티셔츠에 적대적 패턴을 인쇄하여 CCTV 및 자율주행 라이다/비전 센서를 물리적으로 기만.
  - **해결 방안** : 카메라 입력 외에 라이다(LiDAR), 레이다(Radar), 초음파 센서를 융합하는 다중 모달(Multi-modal) 교차 검증 시스템 구현.

## Ⅴ. 적대적 공격(Adversarial Attack) 적용 및 발전을 위한 기술사적 제언

- **CI/CD 파이프라인 내 적대적 강건성 자동 평가(Robustness Testing) 내재화** : 모델 배포 전 Foolbox, ART(Adversarial Robustness Toolbox)를 통해 공격 저항성 점수를 측정하고 배포 게이트 설정.
- **적대적 훈련의 표준 학습 파이프라인 의무화** : 미션 크리티컬 도메인의 신경망 학습 시 PGD 적대적 샘플을 훈련 배치에 상당 비율 혼합 학습하도록 아키텍처 개선.
- **입력 가드레일(Input Guardrails) 레이어 전면 배치** : 모델 추론 직전에 비정상 고주파 노이즈를 필터링하는 오토인코더(Autoencoder) 기반 디노이징 전처리 모듈 구축.
