## 연관 키워드

- 드론 통신·항법 보안, 무인항공기(UAV, Unmanned Aerial Vehicle), 지상통제소(GCS, Ground Control Station)
- MAVLink 2 서명, GNSS 스푸핑, 재밍, C2 하이재킹, 자동 복귀(RTH), 관성항법(INS)
- 안티드론(C-UAS), 하드웨어 신뢰점(RoT), Secure Boot, 자율 Fail-safe

## Ⅰ. 드론 통신·항법 보안의 개요

- 핵심 요약 : 무인항공기의 무선 제어 링크와 위성항법 신호를 사이버 공격으로부터 지키는 물리·사이버 융합 보안 체계.
- 개념 : 드론과 지상통제소(GCS) 사이의 무선 통신 링크, 위성항법(GNSS, Global Navigation Satellite System) 신호, 펌웨어와 임무 데이터를 도청·재밍·탈취로부터 보호하는 통합 보안 체계.
- 배경 및 필요성 : 드론의 군사·산업 활용이 늘면서 제어권 탈취(하이재킹), **GNSS 스푸핑**에 따른 경로 이탈, 센서 데이터 도청 같은 물리·사이버 복합 위협이 현실화됨. 무선 암호화와 항법 무결성 확보가 필요해짐.
- 주요 목적 : 제어권 탈취로 인한 공중 충돌과 시설 피해, 임무 정찰 정보 유출을 막고 비행 안전성(Safety)과 기밀성을 보장.

## Ⅱ. 드론 통신·항법 보안의 특징 및 장점

- 핵심 요약 : 명령 무결성, 링크 암호화, 센서 융합, 기체 물리 보안, 자율 안전 통제가 맞물려 탈취와 추락 피해를 줄이는 구조.

1. **MAVLink 2 서명** (MAVLink 2 Message Signing) : 공유 비밀키 기반 해시의 일부와 타임스탬프를 명령마다 붙여 검증 → 위조 명령과 재생 공격 차단.
2. **DTLS** (Datagram Transport Layer Security) 기반 링크 암호화 : 제어 명령과 영상 스트림을 전 구간 암호화 → 정찰 영상과 텔레메트리 도청 방지.
3. **센서 융합 항법** : 위성항법, 관성항법, 비전 정보를 **확장 칼만 필터**(EKF, Extended Kalman Filter)로 결합 → 한 신호가 위조되어도 불일치를 감지.
4. **하드웨어 신뢰점** (RoT, Root of Trust) : 보안 부팅과 **TPM**(Trusted Platform Module)으로 키를 격리 → 펌웨어 변조와 키 추출 방지.
5. **자율 Fail-safe** : 링크가 끊기면 관성 정보만으로 안전 귀환 또는 착륙 → 통신 공격을 받아도 추락 피해 최소화.

## Ⅲ. 드론 통신·항법 보안의 구조 (흐름)

- 핵심 요약 : 위성항법 위조와 명령 주입이 연쇄되는 공격 체인을, 지상·무선·기체 3계층 방어가 끊는 구조.

```text
[ 사이버 물리 공격 체인 ]

공격자 (재머 / SDR)
   ↓
위성항법 위조 신호 송출
   ↓
기체 위치 오인 → 경로 이탈
   ↓
비인가 명령 주입 (C2 하이재킹)
   ↓
모터 정지 또는 추락
```

```text
[ 3계층 방어 구조 ]

[ 지상통제소 ]
  조종사 FIDO2 인증
  종단 간 암호 터널
        ↓
[ 무선 링크 구간 ]
  MAVLink 2 서명
  주파수 도약 확산
        ↓
[ 기체 비행 제어기 ]
  다중 센서 융합 항법
  Secure Boot, TPM 키 격리
  링크 두절 시 안전 귀환
```

## Ⅳ. 드론 통신·항법 보안과 안티드론 시스템의 비교

- 핵심 요약 : 드론 통신·항법 보안은 아군 기체와 GCS 사이의 신뢰 채널을 세우고, 안티드론은 적대적 침입 드론을 무력화하는 역할로 구분됨.

| 비교 항목 | **드론 통신·항법 보안** (Drone Security) | **안티드론 시스템** (Anti-Drone, C-UAS) |
|---|---|---|
| 보호 주체 | 아군 및 정상 운영 드론 자체 | 공항, 원자력 발전소 등 지상 중요 시설 |
| 주요 목적 | 기체의 안전 비행과 데이터 보호 | 미승인 침입 드론의 탐지·식별과 무력화 |
| 기술적 수단 | 통신 암호화, MAVLink 서명, 센서 융합 항법, TPM | 레이더, EO/IR 카메라, RF 스캐너, RF 재머, 포획 그물 |
| 상대와의 관계 | GCS와 기체 간 신뢰 채널 확립 | 비신뢰 적대 관계 (무력화 대상) |
| 실패 시 영향 | 기체 추락, 정찰 임무 실패, 기밀 누출 | 시설 테러, 공항 운영 마비 |

## Ⅴ. 드론 통신·항법 보안의 한계와 방안

- 핵심 요약 : 암호 기능의 공백, 위성항법 기만, 복귀 지점 위변조, 소형 기체의 연산 한계를 계층별 대응으로 통제.

| 한계 | 원인·영향 | 대응 방안 |
|---|---|---|
| 명령 서명의 암호화 부재 | MAVLink 2 서명은 무결성과 재생 방지만 제공 → 텔레메트리 도청 노출 | 링크 계층에 DTLS 1.3 등 암호화를 병행 적용 |
| 위성항법 기만 (스푸핑) | 상용 수신기가 강한 스푸퍼 신호를 정상으로 오인 → 기체 납치 | 이중 주파수(L1/L5) 수신기 적용, 관성 데이터와 위성항법 속도 간 잔차 실시간 감시 |
| 자동 복귀 기능 악용 | 위조된 홈 좌표로 복귀하여 적진으로 비행 | 홈 좌표를 비행 전 암호화 저장, 복귀 시 위성항법 없이 비전 기반 항법 병행 |
| 소형 기체의 연산 한계 | 탑재 CPU와 배터리 한계로 무거운 암호 연산 불가 | NIST가 표준화한 경량 암호 Ascon 등 경량 암호 채택 |

## Ⅵ. 드론 통신·항법 보안에 대한 기술사적 제언

- 핵심 요약 : 암호 모듈 검증, 위성항법 독립 항법, 기체 물리 보호를 설계 기준으로 제도화하는 방향.

드론 제조사와 운용 기관은 무선 제어 링크의 암호화를 설계 단계의 필수 요건으로 두고, 암호 모듈은 국가 검증 체계를 거치도록 하는 것이 바람직하다.

위성항법이 거부되거나 기만되는 환경을 전제로, 비전 기반 항법을 실증하여 임무 연속성을 확보하는 투자가 필요하다.

비인가 분해나 포획이 감지될 때 핵심 키와 메모리를 영구 소거하는 기체 설계를 표준 요구사항으로 정하는 것이 국가 핵심 시설 정보 보호에 효과적이다.

## Ⅶ. 결론

- 핵심 요약 : 드론 보안은 암호화, 항법 독립성, 물리 보호를 하나의 설계로 묶을 때 임무 안전이 성립하는 체계.
- 무선 링크와 항법 신호를 함께 보호해야 제어권 탈취와 추락을 동시에 막을 수 있음.
