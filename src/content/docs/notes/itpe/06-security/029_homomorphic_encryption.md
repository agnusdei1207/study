## 30초 인출

- **본질:** **동형암호**는 비밀키를 공개하지 않고 암호문에 계산을 수행할 수 있게 하는 암호기술
- **관계:** 암호문 연산 결과를 복호화하면 대응하는 평문 연산 결과에 해당
- **제약:** 계산 가능한 연산·깊이·정확도·성능은 스킴과 파라미터에 따라 달라짐

<details>
<summary>핵심 용어</summary>

- **동형암호(Homomorphic Encryption):** 암호문에 허용 연산을 적용해 평문 연산 결과에 대응하는 암호문을 얻는 암호기술
- **부분 동형암호(PHE, Partially Homomorphic Encryption):** 특정 연산 종류를 동형으로 지원하는 방식
- **준동형암호(SHE, Somewhat Homomorphic Encryption):** 제한된 회로 깊이·연산 범위에서 암호문 계산을 지원하는 방식
- **완전 동형암호(FHE, Fully Homomorphic Encryption):** 임의의 유한 연산회로를 암호문에서 평가할 수 있도록 구성한 방식
- **부트스트래핑(bootstrapping):** 암호문 노이즈를 새로 고쳐 후속 계산을 이어가게 하는 절차
- **CKKS (Cheon-Kim-Kim-Song):** 실수·복소수 연산의 근삿값을 암호문 상태에서 처리하는 스킴
- **BFV (Brakerski/Fan-Vercauteren):** 정수의 모듈러 산술을 지원하는 동형암호 스킴
- **BGV (Brakerski-Gentry-Vaikuntanathan):** 정수의 모듈러 산술을 지원하는 동형암호 스킴
- **노이즈 예산:** 암호문 연산이 누적될수록 소모되는 복호 가능 여유를 설명하는 값

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **동형암호**는 비밀키를 공개하지 않고 암호문에 계산을 수행할 수 있게 하는 암호기술 |
| 목적 | 처리과정에서 평문 공개를 줄여 민감정보 계산을 지원 |

### Ⅱ. 동작 원리와 유형

| 구분 | 평문·암호문 관계 |
|---|---|
| 동형 연산 | `Dec(sk, Eval(f, Enc(pk, x))) = f(x)` 관계의 계산 |
| PHE | 특정 연산 종류를 지원 |
| SHE | 지원하는 제한된 종류·횟수의 연산 계산 |
| Leveled FHE | 미리 정한 회로 깊이 안에서 계산, 부트스트래핑 없이 처리 가능 |
| FHE | 부트스트래핑 등을 통해 임의로 깊은 유한 회로 계산을 이어가는 구성 |

```text
평문 데이터
    ↓ 암호화·키 보유자 관리
암호문 ──허용 연산 f──> 결과 암호문
                              ↓ 권한 있는 주체의 복호화
                    평문 연산 f(x)에 대응하는 결과
```

**제언:** 실제 연산회로와 정확도 요구에 맞는 스킴을 선정하고 연산 깊이·자원소모를 검증

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **동형암호**는 비밀키를 공개하지 않고 암호문에 계산을 수행할 수 있게 하는 암호기술 |
| 목적 | 처리과정에서 평문 공개를 줄여 민감정보 계산을 지원 |

동형성은 연산 결과의 대응관계를 제공하며, 데이터의 입·출력·키·허용 결과까지 자동 보호하는 성질은 아님.

## Ⅱ. 암호문 연산 원리

| 표기 | 의미 |
|---|---|
| `Enc(pk, x)` | 공개키 `pk`를 이용한 평문 `x`의 암호화 |
| `Eval(f, c)` | 암호문 `c`에 함수·회로 `f`를 동형 평가 |
| `Dec(sk, c')` | 비밀키 `sk`로 결과 암호문을 복호화해 평문 결과 획득 |

```text
평문 x ──Enc(pk)──> 암호문 c ──Eval(f)──> 암호문 c'
                                              │
                                 Dec(sk) <────┘
                                   ↓
                       평문 함수 f(x)에 대응
```

계산 수행자는 비밀키 없이 암호문 연산을 수행할 수 있으나, 복호 결과를 받을 주체와 결과의 정보노출은 별도 설계.

## Ⅲ. 동형암호 유형·스킴

| 유형·스킴 | 지원·정확도 | 적합한 계산 관점 |
|---|---|---|
| PHE | 특정 연산 종류 | 한 종류의 집계 등 제한된 계산 |
| SHE | 특정 연산 종류·횟수 제한 | 제한된 연산을 미리 구성하는 계산 |
| Leveled FHE | 설정한 회로 깊이 안에서 계산, 부트스트래핑 없이 처리 가능 | 최대 회로 깊이를 예측할 수 있는 계산 |
| FHE | 부트스트래핑 등을 통해 추가 계산을 이어갈 수 있는 구성 | 깊이가 큰 계산이나 확장 계산 |
| BFV·BGV | 정수 모듈러 산술, 정확한 값 | 정확한 정수 연산 |
| CKKS | 실수·복소수 산술, 근삿값 | 허용 오차가 있는 벡터·수치 계산 |

## Ⅳ. 노이즈·파라미터·성능 관리

| 관리요소 | 의미와 설계 |
|---|---|
| 회로 깊이 | 연산을 미리 분석해 지원 가능한 깊이·파라미터 결정 |
| 노이즈 | 연산 누적에 따른 복호 가능성 관리, 필요 시 스킴 지원 부트스트래핑 검토 |
| CKKS 정밀도 | 근사오차·스케일 조정·재스케일링 영향 측정 |
| 연산 성능 | 암호문 크기·연산시간·메모리·통신량을 실제 회로로 측정 |

`재선형화`는 곱셈 후 암호문 크기를 줄이는 키 전환 과정이며 부트스트래핑과 같은 노이즈 새로고침으로 간주하지 않음.

## Ⅴ. 한계와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 지원 연산·깊이·정밀도가 스킴과 구현에 따라 달라 임의의 평문 프로그램을 그대로 계산하기 어려움 | 업무 회로를 암호문에서 가능한 연산으로 재설계하고 근사오차·자원·지연을 사전 시험 |
| 서버 계산 중 평문은 숨겨도 결과·키·접근권한 설계가 약하면 정보가 노출될 수 있음 | 키 보유자·복호권한을 분리하고 입력·출력·결과공유를 위협모델에 포함 |
