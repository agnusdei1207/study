## 답안 골격
```text
[동형암호] ◀━━ 머리: Ⅶ 내 의견 (부트스트래핑 오버헤드 해소 → GPU 가속기 결합 4세대 근사 동형암호(CKKS) 실용화)
 ┃
 ┣━ Ⅰ 개요 ───── 데이터 활용 시 복호화로 인한 프라이버시 유출 위험 → 암호문 상태 그대로 덧셈·곱셈 연산을 지원하는 차세대 암호
 ┣━ Ⅱ 특징 ───── 연산 동형성($\text{Enc}(m_1) \otimes \text{Enc}(m_2) = \text{Enc}(m_1 \circ m_2)$) · 노이즈 축적 관리 · 부트스트래핑(Bootstrapping)
 ┣━ Ⅲ 구조 ───── 부분 동형암호(PHE: RSA, ElGamal) · 준 동형암호(SHE: BGV, BFV) · 완전 동형암호(FHE: Gentry, CKKS)
 ┣━ Ⅳ 흐름 ───── ① 평문 암호화(노이즈 포함) → ② 암호문 덧셈/곱셈 연산 수행 → ③ 노이즈 임계치 도달 시 부트스트래핑(노이즈 리셋) → ④ 최종 복호화
 ┣━ Ⅴ 비교 ───── BGV/BFV(정수 정확 연산, 금융 거래) vs CKKS(실수 근사 연산, 머신러닝/AI 추론)
 ┗━ Ⅵ 실무 ───── 연산 속도 저하(평문 대비 수백~수천 배) / 암호문 크기 팽창 / AI 프라이버시 보존 추론(PPML) 적용
```
- 필수 키워드: 완전 동형암호(FHE) · 부트스트래핑(Bootstrapping) · CKKS 스킴 · 노이즈(Noise) 관리 · 격자 기반 암호(RLWE) · PPML
- 기출: 133회 1교시 5번 `동형암호의 동작원리와 유형` → Ⅰ·Ⅱ·Ⅲ / 125회 1교시 `완전 동형암호(FHE)의 부트스트래핑` → Ⅳ·Ⅵ

## 한 줄 본질
- 데이터를 복호화하여 평문으로 만들지 않고 암호화된 상태 그대로 연산(덧셈·곱셈)을 수행하여도 복호화 시 올바른 결과가 도출되는 암호 체계 → 데이터 연산 중 유출 원천 차단 / 극심한 연산 오버헤드 및 노이즈 관리 필요

## 핵심 그림
```text
[동형암호(Homomorphic Encryption) 핵심 연산 개념 및 흐름]

  [ 평문 공간 (Plaintext) ]                    [ 암호문 공간 (Ciphertext) ]
 ┌─────────────────────────┐                  ┌─────────────────────────┐
 │   데이터 A     데이터 B │                  │ Enc(A)        Enc(B)    │
 │       │           │     │   ──(암호화)──>   │   │             │       │
 │       ▼           ▼     │                  │   ▼             ▼       │
 │     [ A  +  B 연산 ]    │                  │  [ Enc(A) ⊕ Enc(B) ]    │
 │            │            │                  │            │            │
 │            ▼            │   <──(복호화)──  │            ▼            │
 │       [ 결 과 C ]       │                  │       [ Enc(C) ]        │
 └─────────────────────────┘                  └─────────────────────────┘
      (원격 서버에 평문 노출 없음)                    (클라우드 서버는 암호문만 처리)
```

## 핵심 용어
- 부트스트래핑(Bootstrapping): 동형 연산(특히 곱셈)을 반복할수록 암호문 내부 노이즈가 누적되어 복호화가 불가능해지는데, 암호화된 상태에서 자신의 복호화 회로를 스스로 수행하여 노이즈를 깨끗하게 리셋하는 기법
- CKKS 스킴: 서울대 천정희 교수팀이 개발한 4세대 동형암호로, 정수가 아닌 '실수(Floating-point)'의 근사 연산을 고속으로 지원하여 딥러닝 AI 모델 추론의 글로벌 표준으로 정착

## 핵심 통찰
- 클라우드 AI 서비스에 민감한 의료 영상이나 금융 데이터를 보낼 때, 동형암호로 암호화해 보내면 클라우드 제공자조차 데이터를 볼 수 없으면서도 AI 진단 결과를 암호문으로 돌려받을 수 있음
- 1세대 완전동형암호(Gentry, 2009)는 1비트 곱셈에 수 시간이 걸렸으나, 최신 4세대 CKKS 스킴과 GPU 가속을 통해 밀리초(ms) 단위 추론이 가능해져 상용화 문턱에 도달함
- 동형암호는 양자컴퓨터의 공격에 내성을 가지는 격자 기반 암호(RLWE: Ring Learning With Errors) 난제를 기반으로 하므로 PQC의 성질을 동시에 보유함

## 이웃 토픽과 구분
- 동형암호 vs 안전한 다자간 계산(SMPC): 동형암호 = 단일 클라우드 서버가 모든 암호 연산을 독립 수행(통신량 적음, 연산량 극대) / SMPC = 여러 서버가 네트워크로 통신하며 협력 연산(연산량 적음, 네트워크 병목)

## 문제·원인·대책
- 사례: 133회 기출 금융 사기 탐지(FDS) AI 모델에 동형암호 적용 시 실시간 트랜잭션 지연으로 결제 타임아웃 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 곱셈 연산 시 노이즈 폭증으로 복호화 에러 | 부트스트래핑 연산 누락 및 회로 깊이(Depth) 초과 | 곱셈 회로 깊이를 사전에 고정하는 Leveled HE 적용 및 CKKS 리스케일링(Rescaling) 최적화 | 부트스트래핑 최소화로 연산 속도 10배 향상 |
| CPU 단독 연산 시 처리량 한계로 실시간 서비스 불가 | 다항식 텐서 곱셈 연산의 막대한 CPU 부하 | GPU(CUDA/Tensor Core) 가속 프레임워크(Lattigo, Microsoft SEAL) 결합 | 실시간 FDS 판정 레이턴시 1초 미만 단축 |

## 이렇게 출제된다
