## 지식 로드맵 내 현재 위치

지식 위치: 암호 분석 → 암호문 관찰 모델 → **COA**

## 30초 인출

- 본질: 공격자가 평문·키·암호화 오라클 없이 암호문만 관찰하여 평문·키 또는 관련 정보를 추정하는 공격 모델
- 메커니즘: 암호문 길이·반복·빈도를 관찰해 평문·키 후보를 세우고 통계·전수 분석으로 확인
- 통찰: 한계: 암호문의 높은 엔트로피만으로 안전을 입증할 수 없음 → 방안: 현대 암호의 운용 모드·키·논스 조건을 검증

<details><summary>핵심 용어</summary>

- COA: 공격자가 암호문만 관찰하는 정보 모델.
- 완전 안전성: 암호문 관찰이 평문에 관한 정보를 추가하지 않는 정보이론적 성질.

</details>

## 2~4교시 예상문제 (25점)

> 암호문 단독 공격의 분석 흐름과 한계를 설명하고, 고전 암호·블록 암호 운용 모드·완전 안전성의 차이를 비교하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 암호문 단독 공격은 대응 평문·키·질의 오라클 없이 암호문을 관찰해 정보를 얻으려는 공격 모델 |
| 목적 | 암호문 노출에 따른 구조·메타데이터 확인과 적절한 암호 운용 선택 |

```text
암호문 수집 → 길이·반복·빈도·형식 관찰
          → 후보 알고리즘·키·평문 가정
          → 통계·전수 분석 → 후보 검증
```

공격자가 암호문만 본다는 가정은 평문 형식·프로토콜 헤더 등 공개 정보를 모두 모른다는 뜻은 아님.

### Ⅱ. 사례별 정보 누출

```text
고전 치환 암호 ─> 문자 빈도 노출
ECB ──────────> 동일 블록 반복 노출
논스·키스트림 재사용 ─> 암호문 간 관계 노출
현대 암호의 올바른 운용 ─> 길이 등 메타데이터 점검
```

| 구성 | 관찰 가능한 것 | 한계 |
|---|---|---|
| 고전 단순 치환 | 언어 문자 빈도 | 문자 분포에 의존 |
| ECB | 같은 평문 블록의 같은 암호문 블록 | 비밀키 전체가 자동 복원되지는 않음 |
| 약한 스트림 암호 운용 | 논스·키스트림 재사용의 관계 | 구성·재사용 조건별 분석 필요 |
| 올바른 현대 암호 | 길이 등 메타데이터는 남을 수 있음 | 키·논스·프로토콜 안전성 별도 필요 |

### Ⅲ. 완전 안전성과 계산 안전성

| 구분 | 뜻 |
|---|---|
| 완전 안전성 | 암호문 관찰 후에도 평문 분포에 관한 정보가 추가되지 않는 정보이론적 성질 |
| 계산 안전성 | 현실적인 계산 자원으로 평문·키를 얻기 어렵게 하는 성질 |

일회용 패드는 올바른 무작위 키를 메시지 길이만큼 사용하고 재사용하지 않는 조건에서 완전 안전성의 대표 예. AES 같은 블록 암호가 완전 안전성과 동일하다고 설명하지 않음.

#### 방어 검증

| 항목 | 확인 |
|---|---|
| 암호 방식 | 표준 구성과 안전한 운용 모드 |
| 키 | 충분한 강도·비밀 유지·수명 관리 |
| IV·논스 | 선택한 모드의 생성·재사용 제약 |
| 메타데이터 | 길이·빈도·접속 시각 등 잔여 누출 |
| 무결성 | GCM 등 인증 암호의 태그 검증 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 암호문 엔트로피가 높아도 운용 모드·키·nonce 오류가 남을 수 있음 | 보안 모델과 키·nonce·프로토콜 조건을 함께 검증 |

### Ⅴ. 제언

'암호문이 난수처럼 보인다'는 관찰보다 보안 모델·키·논스·운용 프로토콜을 함께 검증.

## 출제 이력과 검증 출처

- 제137회 Q-net 원문 1교시 4번 표제어 “암호문 공격(Ciphertext Attack)” 확인. 위 25점 문항은 확장 예상문제.
- [Claude Shannon, Communication Theory of Secrecy Systems](https://onlinelibrary.wiley.com/doi/pdf/10.1002/j.1538-7305.1949.tb00928.x)
- [NIST SP 800-38A, 운용 모드](https://csrc.nist.gov/pubs/sp/800/38/a/final)
