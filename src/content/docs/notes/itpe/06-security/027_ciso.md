## 30초 인출

- **본질:** **CISO (Chief Information Security Officer)** 는 조직의 정보보호 거버넌스와 보안위험 관리를 이끄는 책임자
- **메커니즘:** 보호계획·위험평가·통제점검·교육·사고대응을 경영 의사결정과 연결
- **법적 관점:** 지정·신고·겸직 요건은 조직 유형과 적용 법령·시행령 기준에 따라 확인

<details>
<summary>핵심 용어</summary>

- **CISO (Chief Information Security Officer):** 조직의 정보보호 정책·위험·통제·대응을 총괄하는 정보보호 책임자
- **CIO (Chief Information Officer):** 조직의 정보기술·IT 서비스 운영과 활용을 총괄하는 책임자
- **CPO (Chief Privacy Officer):** 개인정보 처리와 정보주체 권리 보호를 총괄하는 책임자
- **보안 거버넌스:** 경영목표와 위험에 맞춰 보안 책임·의사결정·자원·성과를 관리하는 체계
- **겸직 제한:** 법령이 정한 대상·기준의 CISO가 다른 업무를 함께 수행하지 못하도록 하는 법적 요건으로, 적용 범위·예외는 해당 조문과 시행령 확인 대상
</details>

## 1교시 예상문제 (10점)

> CISO의 개념과 주요 역할, 효과적인 보안 거버넌스 운영방안을 설명하시오. *(10점 예상문제)*

---
## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CISO (Chief Information Security Officer)** 는 조직의 정보보호 거버넌스와 보안위험 관리를 이끄는 책임자 |
| 목적 | 보안위험을 경영 의사결정에 반영하고 보호계획·통제의 이행을 조정 |

### Ⅱ. 역할과 운영기반

| 역할 | 주요 업무 |
|---|---|
| 계획·위험관리 | 보호계획 수립, 위험 식별·평가, 대책 마련 |
| 점검·개선 | 보안 실태 점검, 통제 개선, 교육·훈련 운영 |
| 사고대응 | 침해사고 예방·대응 조직과 절차 조정 |
| 거버넌스 | 경영진 보고, 책임·권한·인력·예산 확보 |

**제언:** CISO에 명확한 보고 경로와 의사결정 권한·자원을 부여하고 이행 결과를 경영진이 정기 검토

---
## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CISO (Chief Information Security Officer)** 는 조직의 정보보호 거버넌스와 보안위험 관리를 이끄는 책임자 |
| 목적 | 보안위험을 경영 의사결정에 반영하고 보호계획·통제의 이행을 조정 |

CISO는 보안 전문가 조직의 관리자를 넘어 조직의 위험·통제·책임을 의사결정에 연결하는 거버넌스 역할.

## Ⅱ. 거버넌스와 협업관계

| 주체 | 중심 책임 | 협업 접점 |
|---|---|---|
| 이사회·경영진 | 위험수용·우선순위·자원 승인 | CISO의 보고를 통한 감독 |
| CISO | 정보보호 계획·위험·통제·대응 | 사업·IT·개인정보 책임자와 조정 |
| CIO | 정보기술·서비스 운영 | 보안통제의 시스템·운영 반영 |
| CPO | 개인정보 처리와 정보주체 권리 보호 | 개인정보 위험·사고·통제 협의 |

```text
이사회·경영진
       │ 위험수용·자원·감독
       ↓
      CISO ──보안요구·위험조정── CIO
       │
       └────개인정보 위험협의──── CPO
```

## Ⅲ. 주요 책임과 산출

| 책임 | 대표 활동·산출 |
|---|---|
| 계획·정책 | 정보보호 계획·정책, 책임과 목표 |
| 위험관리 | 위험 식별·평가, 통제와 개선과제 |
| 점검·교육 | 실태 점검, 교육·모의훈련, 개선 기록 |
| 사고관리 | 예방·대응계획, 보고·복구 협업 |

## Ⅳ. 법적 지정·독립성 고려

정보통신망법은 일정 기준에 해당하는 정보통신서비스 제공자의 CISO 지정·신고와 법정 업무를 규정하며, 대상·예외·겸직 범위는 법률과 시행령 기준 확인 필요.

| 검토사항 | 확인 기준 |
|---|---|
| 지정·신고 | 사업자 유형, 법률·시행령상 규모 기준, 신고 예외 |
| 겸직·독립성 | 법 적용 대상·겸직 제한·허용 업무와 조직 내 이해상충 |
| 책임·자원 | 업무 범위에 맞는 권한·인력·예산·보고 경로 |
| 수행 증적 | 계획·점검·개선·교육·사고 대응의 이행 기록 |

## Ⅴ. 한계와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 직책만 지정하고 경영 의사결정·자원과 분리하면 책임 수행이 형식화될 수 있음 | 이사회·경영진 보고와 위험수용 절차에 CISO를 포함하고 통제 개선 결과를 정기 검토 |
| CISO·CIO·CPO의 책임이 중첩되거나 공백이면 사고·개선 과제의 주관이 불명확 | 책임분장표와 공동 의사결정 경로를 수립하고 사고·개인정보 이슈별 주관·협업 기준을 명시 |
