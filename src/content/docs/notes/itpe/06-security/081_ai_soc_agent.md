## 지식 로드맵 내 현재 위치

보안 운영 → 보안관제(SOC) → AI SOC 에이전트

## 30초 인출

- **본질:** 대량의 다기종 보안 경보(Alert)와 위협 인텔리전스를 LLM 및 자율 추론 엔진이 종합 분석하여 위협 가설을 검증하고 조치를 오케스트레이션하는 지능형 관제 시스템.
- **메커니즘:** SIEM/XDR 이벤트 수집 → RAG 기반 내외부 위협 맥락(CTI/자산) 매핑 → 위협 인과관계 추론 및 증거 요약 → HITL 승인을 거쳐 SOAR 격리 명령 실행.
- 통찰: 모델 환각으로 인한 비정상 업무 차단과 프롬프트 인젝션 공격에 대비하여 가드레일 정책 집행점(PEP) 구축과 영향도별 단계적 자율권 통제 설계 필수.

<details><summary>핵심 용어</summary>

- **AI SOC 에이전트**: 경보 분류, 위협 심층 조사, 근본 원인 분석, 대응 가이드 생성을 자율 또는 반자율적으로 수행하는 생성형 AI 기반 에이전트.
- **SIEM(Security Information and Event Management)**: 전사 보안 장비 및 서버의 로그를 중앙 집중 수집하여 규칙 기반 상관분석을 수행하는 시스템.
- **SOAR(Security Orchestration, Automation and Response)**: 사전 정의된 플레이북을 바탕으로 보안 대응 워크플로우를 자동화하는 플랫폼.
- **HITL(Human-in-the-Loop)**: AI의 분석 결과를 인간 보안 분석가가 최종 검증하고 승인하도록 통제하는 협업 모델.
- **가드레일(Guardrails)**: 에이전트가 실행 가능한 도구 호출(Tool Calling)의 범위와 명령 파라미터의 유효성을 실시간 검증하는 보안 프레임워크.
</details>

## 2~4교시 예상문제 (25점)

> 전통적인 SIEM 및 SOAR 기반 보안관제의 한계를 극복하기 위한 AI SOC 에이전트의 아키텍처와 핵심 동작 메커니즘을 설명하고, AI 에이전트 도입 시 발생하는 신뢰성·보안 한계 및 이를 극복하기 위한 엔지니어링 방안을 제시하시오. (25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | SIEM, EDR, NDR 등에서 쏟아지는 방대한 보안 경보를 LLM 기반 추론 엔진이 맥락과 결합하여 심층 분석하고 대응을 보조·수행하는 자율 관제 체계 |
| 목적 | 보안 분석가의 경보 피로(Alert Fatigue) 해소, 침해사고 대응 골든타임 단축(MTTD/MTTR 혁신), 고도화된 타깃 공격의 맥락 기반 신속 규명 |

## Ⅱ. AI SOC 에이전트의 주요 특징

| 특징 | 세부 내용 | 구현 요소 및 차별성 |
|---|---|---|
| 비정형 맥락 융합 | 정형화된 SIEM 로그 외에 CTI 리포트, 소스코드, 시스템 히스토리를 RAG로 융합 분석 | 벡터 DB, 하이브리드 검색(BM25+Dense) |
| 자율 가설 수립 및 검증 | 다단계 추론(ReAct, Chain-of-Thought)을 통해 공격 체인(Kill Chain) 역추적 | 멀티 에이전트 협업, 인과관계 그래프 |
| 자연어 질의 및 브리핑 | 침해사고 발생 원인, 영향 범위, 대응 권고사항을 자연어 보고서 형태로 즉시 출력 | 프롬프트 엔지니어링, 역할 기반 리포팅 |
| 동적 도구 활용(Tool Calling) | API를 통해 EDR 격리, 방화벽 IP 차단, 샌드박스 파일 분석 명령을 직접 호출 | OpenAPI 스펙 연동, Function Calling |
| 분석가 역량 상향 평준화 | 초급 분석가(Tier-1)도 최상급(Tier-3) 수준의 상관분석 가설과 대응 가이드를 즉시 활용 | 지식 베이스 임베딩, 인터랙티브 챗봇 |

## Ⅲ. AI SOC 에이전트 동작 프로세스 및 아키텍처

```text
[ 다기종 보안 인프라 ]       [ AI SOC 에이전트 핵심 계층 ]                [ 대응 및 거버넌스 ]
+-------------------+      +-----------------------------------------+      +-------------------+
| SIEM / XDR Alerts | ────> | 1. Alert Triage & Deduplication         |      | SOAR Playbook     |
| EDR Host Logs     |      |    (경보 정규화, 중복 제거, 우선순위 배정)|      | (사전 승인 차단)  |
+-------------------+      +-----------------------------------------+      +-------------------+
                                               │                                      ▲
                                               ▼                                      │ API 실행
                           +-----------------------------------------+                │
+-------------------+      | 2. Context Retrieval & Fusion (RAG)     |                │
| Threat Intel(CTI) | ────> |    - 내외부 위협 인텔리전스 매핑        |                │
| CMDB 자산 중요도  |      |    - 자산 취약점 및 통신 이력 대조      |                │
+-------------------+      +-----------------------------------------+                │
                                               │                                      │
                                               ▼                                      │
                           +-----------------------------------------+                │
                           | 3. Reasoning & Hypothesis Testing       |                │
                           |    - MITRE ATT&CK 전술/기법 매핑        |                │
                           |    - 공격 시나리오 인과관계 추론         |                │
                           +-----------------------------------------+                │
                                               │                                      │
                                               ▼                                      │
                           +-----------------------------------------+      +-------------------+
                           | 4. Policy Enforcement & HITL Approval   | ───> | Tier-2/3 분석가   |
                           |    (가드레일 검증, 고위험 조치 인간 승인)|      | (최종 승인/검증)  |
                           +-----------------------------------------+      +-------------------+
```

| 처리 계층 | 세부 구현 메커니즘 | 적용 기술 및 프로토콜 |
|---|---|---|
| 경보 수집 및 분류 | 실시간 스트리밍으로 유입되는 대량의 경보를 노이즈 필터링 및 공격 유형별 클러스터링 | Kafka, Flink, 임베딩 클러스터링 |
| 맥락 검색 (RAG) | 공격 IP/도메인을 VirusTotal, MISP, 내부 CMDB 자산 정보와 실시간 연동하여 맥락 보강 | Vector DB(Milvus), GraphQL API |
| 다단계 추론 및 계획 | LLM이 공격자의 횡적 이동 경로와 권한 상승 가능성을 트리 형태로 탐색(Tree-of-Thought) | ReAct 패턴, LangGraph, AutoGen |
| 가드레일 정책 검증 | 호출하려는 파괴적 명령(호스트 셧다운, 핵심 DB 격리 등)의 파라미터 유효성 검사 | NeMo Guardrails, OPA(Open Policy Agent) |
| 조치 오케스트레이션 | 정해진 임계치 이하 저위험 조치는 자동화, 고위험 자산 통제는 분석가 승인 후 실행 | SOAR REST API, 슬랙/웹훅 승인 인터페이스 |

## Ⅳ. 전통적 SOC(SIEM/SOAR) vs AI SOC 에이전트 비교

| 구분 | 규칙 기반 SIEM | 정적 플레이북 SOAR | AI SOC 에이전트 |
|---|---|---|---|
| 분석 패러다임 | 사전 정의된 상관분석 Rule 매칭 | 사전 정의된 If-Else 워크플로우 실행 | 자율 추론 기반 비정형 맥락 및 가설 검증 |
| 미탐/변종 대응 | 규칙에 없는 신규 공격 탐지 불가 | 미정의 예외 상황 발생 시 프로세스 중단 | CTI 유사도 및 다단계 추론으로 변종 식별 |
| 맥락 이해력 | 로그 필드 간의 단순 일치 여부 비교 | 제한된 데이터 연동 스크립트 실행 | 공격자의 의도, 비즈니스 영향도 심층 이해 |
| 분석 보고서 작성 | 분석가가 수작업으로 쿼리 실행 후 작성 | 템플릿 기반 단순 필드 채우기 | 자연어 기반 사고 경위, 타임라인 자동 생성 |
| 유지보수 부담 | 대량의 룰 튜닝 및 오탐 제외 룰 추가 | API 변경 시마다 플레이북 전면 재수정 | 프롬프트 조정 및 지식 베이스 업데이트로 대응 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| LLM 환각(Hallucination)으로 인해 정상 트래픽을 C2 통신으로 오판하여 핵심 서비스 차단 위험 | 모든 추론 단계에 원천 로그 근거(Raw Evidence ID) 링크를 강제 표기하고, 핵심 프로덕션 자산은 인간 승인(HITL) 필수 적용 |
| 공격자가 로그나 웹 요청 헤더에 악의적 프롬프트를 은닉하는 간접 프롬프트 인젝션(Indirect Prompt Injection) 취약점 | 수집된 보안 로그 데이터를 입력 데이터 영역으로 완전 격리(Data-Instruction Separation)하고 LLM 가드레일 검증 레이어 배치 |
| 복합 멀티 홉 로그 분석 시 과도한 토큰 소모 및 API 지연으로 실시간 긴급 차단 골든타임 상실 | 1차 필터링용 경량 모델(SLM)로 80% 단순 경보를 고속 처리하고, 심층 조사가 필요한 고난도 사건만 고성능 추론 LLM으로 라우팅 |
| 에이전트에 과도한 IAM 권한이 부여될 경우 탈취된 에이전트 키를 통한 전사 인프라 파괴 위험 | 도구 호출 권한을 세분화(Least Privilege)하고 임시 단기 토큰(STS) 기반으로 감사 로그가 상시 기록되는 환경 구축 |

| 통제 영역 | 엔지니어링 구현 과제 | 운영 성숙도 지표 |
|---|---|---|
| 자율권 통제 | 위험도 기반 단계적 자율화(Tier-1 완전 자동, Tier-2 승인 기반, Tier-3 인간 주도) | 인간 개입 비율(HITL Rate), 오차단율 0.01% 이하 |
| 신뢰성 검증 | 의사결정 추론 과정의 투명성(Explainability) 확보 및 원천 로그 100% 매핑 | 감사 증적 일치율 100%, 분석가 신뢰도 만족도 |
| 적대적 방어 | AI 에이전트 대상 프롬프트 인젝션 및 데이터 오염 모의 해킹(AI Red Teaming) 정례화 | 보안 가드레일 우회 방어율 99.9% 유지 |

## 출제 이력과 검증 출처

- 제134회 정보관리기술사 (생성형 AI 보안 활용 및 보안관제 고도화)
- NIST AI Risk Management Framework (AI RMF 1.0)
- OWASP Top 10 for LLM Applications & Agentic AI
- Gartner, Innovation Insight for AI-Powered SOC Tools

## 연결 토픽

- SIEM(보안 정보 및 이벤트 관리)
- SOAR(보안 오케스트레이션 자동화)
- LLM 보안 및 프롬프트 인젝션
- 비인간 신원(NHI)
