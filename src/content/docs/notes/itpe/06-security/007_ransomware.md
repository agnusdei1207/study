## Ⅰ. 랜섬웨어(Ransomware)의 개요

- 개념 : 피해 시스템의 중요 데이터(파일, DB, 백업본)를 고강도 암호화 알고리즘으로 동결하거나 유출한 뒤, 정상 복구 키 제공 또는 비공개를 빌미로 금전(암호화폐)을 요구하는 악성코드 및 복합 사이버 테러 공격.
- 배경 및 필요성 : 단순 파일 암호화에서 출발하여 다크웹 **RaaS** (Ransomware-as-a-Service) 플랫폼의 등장, **이중·삼중 협박** (Extortion), 공급망 침투를 통한 대규모 파괴로 진화하여 국가 핵심 기반시설까지 위협.
- 핵심 목적 : 공격 경로(초기 침투, 권한 상승, 횡적 이동, 데이터 암호화) 조기 차단, 신속한 비상 복구 체계(BCP) 확립 및 데이터 백업 **불변성** (Immutability) 보장.

## Ⅱ. 랜섬웨어(Ransomware)의 핵심 아키텍처 및 동작 메커니즘

최신 랜섬웨어는 비대칭키와 대칭키를 결합한 **하이브리드 암호화** 아키텍처를 사용하여 고속 대용량 암호화를 수행하며, 복구 원천 차단을 위해 **VSS 삭제** 및 백업 서버부터 우선 장악함.

```text
[ 기업 표적형 랜섬웨어의 5단계 다중 협박 및 침해 메커니즘 ]

  [ 1. 초기 침투 ] -> 스피어피싱, RDP 노출 포트 스캔, VPN 취약점 악용
           │
           ▼
  [ 2. 횡적 이동 ] -> Mimikatz 자격증명 탈취 -> AD(Active Directory) 도메인 장악
           │
           ▼
  [ 3. 사전 작업 ] -> Shadow Copy 삭제(vssadmin), 백업 데이터 파괴, C2로 기밀 유출
           │
           ▼
  [ 4. 하이브리드 암호화 실행 ]
    - 파일별 대칭키(AES-256) 생성 -> 고속 파일 암호화
    - AES 대칭키를 공격자의 공개키(RSA-4096)로 암호화 후 파일 헤더에 삽입
           │
           ▼
  [ 5. 다중 협박 ] -> 1차: 복구 키 비용 요구 / 2차: 데이터 다크웹 폭로 협박
                      3차: 고객사 대상 DDoS 공격 및 규제 기관 고발 압박
```

- **초기 거점 확보** : 패치되지 않은 외곽 VPN 게이트웨이 취약점(CVE) 악용 또는 피싱 메일 매크로를 통해 내부망 침투.
- **도메인 컨트롤러** (DC) 장악 : Kerberoasting, **Pass-the-Hash** 공격을 통해 Active Directory 도메인 관리자 권한 획득 후 그룹 정책(GPO)으로 전사 감염 명령 배포.
- **간헐적 암호화** (Intermittent Encryption) : 파일 전체를 암호화하지 않고 일부 구간만 건너뛰며 암호화하여 안티바이러스 I/O 탐지 우회 및 암호화 속도 향상.
- **안티 백업** (Anti-Backup) : 온라인 백업 볼륨 탐색 후 볼륨 섀도우 복사본(`vssadmin delete shadows /all /quiet`) 및 백업 에이전트를 강제 종료.

## Ⅲ. 랜섬웨어(Ransomware)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 1세대 (대량 무차별 랜섬웨어) | 2세대 (표적형 APT 랜섬웨어) | 3세대/현대 (RaaS & 다중 협박 랜섬웨어) |
| --- | --- | --- | --- |
| 공격 대상 | 불특정 다수 개인 PC (스팸 메일) | 특정 기업 및 공공기관 (APT 기법) | 글로벌 엔터프라이즈 및 공급망 벤더 |
| 비즈니스 모델 | 단독 해커 그룹의 직접 유포 | 전문 해커 조직의 타깃 인텔리전스 | RaaS (운영자-파트너 수익 분배 생태계) |
| 협박 방식 | 단순 파일 복구 인질 (1중 협박) | 파일 복구 + 데이터 유출 협박 (이중 협박) | 복구 + 유출 + DDoS + 주주/고객사 연락 (4중 협박) |
| 암호화 기법 | 단순 대칭키 (키 하드코딩 빈번) | RSA-2048 + AES-256 하이브리드 | 간헐적 암호화, ChaCha20/Curve25519 고속 암호화 |
| 방어 전략 | 시그니처 백신, 단순 외장하드 백업 | EDR 도입, 망분리, 중앙 백업 | 3-2-1-1-0 불변 백업, 제로트러스트, MDR |

- 현대 랜섬웨어는 단순한 악성코드 공격이 아닌 데이터 유출과 기업 이미지 파괴를 결합한 **사이버 갈취** (Extortion) 범죄이므로, 암호화 탐지 이전의 **횡적 이동** 차단과 불변 백업이 핵심임.

## Ⅳ. 랜섬웨어(Ransomware)의 주요 한계점 및 해결 방안

- **정상 시스템 관리 도구 악용** (Living off the Land)을 통한 백신 우회 :
  - 한계점 : PowerShell, WMI, PsExec 등 윈도우 내장 관리 도구를 악용하여 악성 바이너리 실행 없이 메모리 상에서 공격을 진행하므로 시그니처 백신 무력화.
  - 해결 방안 : EDR/XDR을 도입하여 프로세스 계보(Process Lineage)와 부모-자식 프로세스 비정상 호출 행위를 기계학습으로 분석하고 WMI 원격 명령 제한.
- 동일 네트워크 내 연결된 온라인 백업 스토리지 동시 감염 및 파괴 :
  - 한계점 : AD 권한을 탈취한 공격자가 네트워크 드라이브 및 클라우드 백업 콘솔에 접속하여 백업 이미지까지 일괄 삭제함으로써 복구 불능 상태 야기.
  - 해결 방안 : **3-2-1-1-0 백업 원칙** (3벌 복제, 2종류 매체, 1개 오프사이트, 1개 불변 WORM 스토리지, 무오류 검증) 수립 및 **에어갭** (Air-Gapped) 격리 보관.
- 암호화폐 세탁을 통한 공격자 자금 추적 및 법적 처벌 난항 :
  - 한계점 : 모네로(Monero) 등 프라이버시 코인 및 믹싱(Mixing) 서비스를 악용하여 랜섬 머니를 세탁하므로 범죄 조직 규명 및 피해 자금 회수 곤란.
  - 해결 방안 : 블록체인 분석 CTI 도구(Chainalysis 등)를 통한 트랜잭션 추적 및 전사 랜섬웨어 피해 시 복구 협상 대행을 엄격히 통제하고 신고 의무화 법제화.

## Ⅴ. 랜섬웨어(Ransomware) 적용 및 발전을 위한 기술사적 제언

- **네트워크 마이크로세그멘테이션** (Micro-Segmentation) 전면 적용 : 단말 간(East-West) 직접 통신을 원천 차단하여 단일 PC 감염이 AD 전체로 확산되는 횡적 이동 경로 봉쇄.
- 최소 권한 원칙 기반의 **자격증명 격리** (Tiering Model) : 도메인 관리자 계정은 전용 **PAM** (Privileged Access Management) 솔루션을 통해서만 접속을 허용하고 워크스테이션 로그인 금지.
- 정기적인 **불변 백업** 기반 재해복구(DR) 실전 훈련 정례화 : 연 2회 이상 무작위 침해 시나리오를 설정하여 4시간 이내 클라우드 격리 존에 핵심 시스템을 복구하는 실전 훈련 수행.
