## 연관 키워드

- 랜섬웨어(Ransomware), RaaS(Ransomware-as-a-Service), 이중 협박(Double Extortion), 하이브리드 암호화(Hybrid Encryption)
- 간헐적 암호화(Intermittent Encryption), 횡적 이동(Lateral Movement), Pass-the-Hash, 도메인 컨트롤러(DC)
- 3-2-1-1-0 백업 원칙, 불변 백업(Immutable Backup), 에어갭(Air-Gapped), 마이크로 세그멘테이션(Micro-Segmentation), PAM(Privileged Access Management)

## Ⅰ. 랜섬웨어(Ransomware)의 개요

- 핵심 요약 : 데이터를 잠그거나 유출한 뒤 복구 대가를 요구하는 금전 갈취형 악성코드 공격.
- 개념 : 피해 시스템의 파일, DB, 백업본을 강력한 암호로 잠그거나 유출한 뒤, 복구 키 제공이나 비공개를 대가로 암호화폐를 요구하는 악성코드 및 복합 사이버 공격인 **랜섬웨어** (Ransomware).
- 배경 및 필요성 : 단순 파일 잠금에서 출발해 **RaaS** (Ransomware-as-a-Service, 운영자가 공격 도구를 임대하고 파트너와 수익을 나누는 서비스 모델), **이중 협박** (Double Extortion, 암호화와 데이터 유출을 함께 내세운 협박) 등으로 진화하면서, 공급망 침투를 통해 국가 핵심 기반시설까지 위협하게 됨.
- 주요 목적 : 공격 경로(초기 침투, 권한 상승, 횡적 이동, 암호화)를 조기에 차단하고, 신속한 비상 복구 체계인 BCP(Business Continuity Plan)를 세우며, 백업의 **불변성** (Immutability, 저장 후 변경과 삭제가 불가능한 상태) 보장.

## Ⅱ. 랜섬웨어(Ransomware)의 특징 및 장점

- 핵심 요약 : 하이브리드 암호화와 백업 파괴 선행 작업이 결합되어 피해자의 복구 수단을 원천 차단하는 구조.

1. **하이브리드 암호화** (Hybrid Encryption) : 파일마다 AES(Advanced Encryption Standard) 대칭키로 고속 암호화하고, 그 대칭키를 공격자의 공개키(RSA, Rivest-Shamir-Adleman)로 감싸 파일 헤더에 넣음 → 공격자만 복호 키를 보유.
2. **간헐적 암호화** (Intermittent Encryption, 파일의 일부 구간만 건너뛰며 암호화) → 암호화 속도를 높이고 백신의 입출력 탐지를 우회.
3. 백업 선행 파괴 : 볼륨 섀도 복사본을 삭제(vssadmin delete shadows)하고 백업 에이전트를 강제 종료 → 복구 수단을 먼저 제거.
4. 도메인 장악 : 자격증명 탈취 도구와 **Pass-the-Hash** (비밀번호 대신 해시 값으로 인증하는 횡적 이동 기법)로 AD(Active Directory) 관리 권한을 얻은 뒤, 그룹 정책으로 전사에 감염 명령을 배포.

## Ⅲ. 랜섬웨어(Ransomware)의 구조 (흐름)

- 핵심 요약 : 초기 침투에서 다중 협박까지 다섯 단계가 순서대로 진행되며, 백업 파괴가 복구 가능성을 막는 흐름.
- 초기 거점 : 패치되지 않은 원격 접속 장비의 CVE(Common Vulnerabilities and Exposures) 취약점이나 피싱 메일 매크로로 내부망에 침투.
- 도메인 컨트롤러(DC, Domain Controller) 장악 : 권한을 얻은 뒤 전사 단말을 한꺼번에 감염시키는 준비 단계.

```text
[ 표적형 랜섬웨어 5단계 ]

1. 초기 침투 : 피싱, 원격 접속 장비 취약점
   ↓
2. 횡적 이동 : 자격증명 탈취, 도메인 장악
   ↓
3. 사전 작업 : 섀도 복사본 삭제, 데이터 유출
   ↓
4. 하이브리드 암호화 실행
   ↓
5. 다중 협박 : 복구 대가, 유출 협박, 디도스
```

## Ⅳ. 랜섬웨어(Ransomware)의 비교

- 핵심 요약 : 1세대의 무차별 파일 잠금에서 3세대의 RaaS 기반 다중 협박으로 옮겨 가면서, 협박의 범위와 방어의 중심이 단말에서 네트워크와 백업으로 이동.

| 비교 항목 | 1세대 (무차별 랜섬웨어) | 2세대 (표적형 APT 랜섬웨어) | 3세대 (RaaS·다중 협박) |
| --- | --- | --- | --- |
| 공격 대상 | 불특정 다수의 개인 PC, 스팸 메일 | 특정 기업과 공공기관 (APT, Advanced Persistent Threat 기법) | 글로벌 기업과 공급망 벤더 |
| 비즈니스 모델 | 단독 조직의 직접 유포 | 전문 해커 조직의 표적 정보 활용 | RaaS, 운영자와 파트너의 수익 분배 |
| 협박 방식 | 파일 복구를 대가로 한 단일 협박 | 복구와 데이터 유출을 동시에 협박하는 이중 협박 | 복구, 유출, 디도스(DDoS, Distributed Denial of Service), 고객사 연락 압박 |
| 암호화 기법 | 단순 대칭키 (키 하드코딩 빈번) | RSA와 AES의 하이브리드 암호화 | 간헐적 암호화와 고속 스트림 암호 |
| 방어 전략 | 시그니처 백신, 단순 외장 백업 | EDR(Endpoint Detection and Response), 망 분리, 중앙 백업 | 불변 백업, 제로 트러스트, MDR(Managed Detection and Response) |

- 현대 랜섬웨어는 데이터 유출과 기업 이미지 파괴를 결합한 사이버 갈취 범죄이므로, 암호화가 시작되기 전 횡적 이동 차단과 불변 백업이 핵심.

## Ⅴ. 랜섬웨어(Ransomware)의 한계와 방안

- 핵심 요약 : 내장 도구 악용에 의한 백신 우회, 백업의 동시 감염, 자금 세탁에 따른 추적 난항을 탐지, 백업, 추적 체계로 나눠 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **정상 관리 도구 악용** (Living off the Land)에 의한 백신 우회 | PowerShell, WMI(Windows Management Instrumentation), PsExec로 악성 파일 없이 메모리에서 공격을 진행하여 시그니처 백신이 무력화 | EDR/XDR(Extended Detection and Response)로 프로세스 계보와 부모-자식 프로세스의 비정상 호출을 분석하고, WMI 원격 명령을 제한 | 비정상 프로세스 체인 탐지 건수 |
| 온라인 백업의 동시 감염과 파괴 | AD 권한을 탈취한 공격자가 네트워크 드라이브와 클라우드 백업 콘솔에 접근해 백업 이미지까지 삭제 | **3-2-1-1-0 백업 원칙** (3벌 복제, 2종류 매체, 1곳 오프사이트, 1개 불변 WORM(Write Once Read Many) 저장소, 0 오류 검증)과 **에어갭** (Air-Gapped, 네트워크에서 물리적으로 분리된 보관) | 백업 복구 시험 성공률, 불변 백업 적용 비율 |
| 암호화폐 세탁에 의한 자금 추적 난항 | 프라이버시 코인과 믹싱 서비스로 몸값이 세탁되어 범죄 조직 규명과 피해 자금 회수가 곤란 | 블록체인 분석 도구를 활용한 트랜잭션 추적, 피해 신고 의무화, 복구 협상 대행의 통제 | 추적 가능 비율, 신고 접수율 |

## Ⅵ. 랜섬웨어(Ransomware)에 대한 기술사적 제언

- 핵심 요약 : 횡적 이동 차단, 특권 계정 격리, 불변 백업의 실전 검증을 함께 운영하는 방향.

1. 단말 간 직접 통신을 막는 마이크로 세그멘테이션(Micro-Segmentation)을 전면 적용하여, 한 대의 감염이 AD 전체로 번지는 경로를 봉쇄하는 것이 필요.
2. 도메인 관리자 계정은 PAM(Privileged Access Management) 솔루션을 통해서만 접속을 허용하고 일반 워크스테이션 로그인은 금지하는 계층형 자격증명 모델을 도입하는 것이 필요.
3. 불변 백업을 기반으로 한 재해복구(DR, Disaster Recovery) 훈련을 정례화하여, 무작위 침해 시나리오에서 핵심 시스템을 격리된 클라우드 영역으로 복구하는 절차를 정기적으로 검증하는 것이 필요.

## Ⅶ. 결론

- 핵심 요약 : 랜섬웨어는 암호화 자체보다 횡적 이동과 백업 파괴 단계에서 승부가 갈리는 갈취형 사이버 범죄.
- 시사점 : 복구 가능성을 지키는 불변 백업과 특권 계정 통제를 탐지 기술보다 먼저 확보해야 피해 규모를 제한할 수 있음.
