## Ⅰ. PIMS(Personal Information Management System)의 개요

- **개념** : 조직이 수집·보유하고 있는 개인정보를 안전하게 관리하기 위해 개인정보보호 관리체계의 수립, 실행, 모니터링, 개선(PDCA) 전 과정을 체계화하고 적합성을 제3자 인증기관이 심사하여 인증을 부여했던 한국의 공인 개인정보보호 관리체계 (2018년 ISMS와 통합되어 현재는 'ISMS-P'로 발전).
- **배경 및 필요성** : 과거 방송통신위원회의 PIMS와 행정안전부의 PIPL(개인정보보호 인증제)로 이원화되어 기업의 인증 중복 부담이 심각했으며, 정보보호 관리체계(ISMS)와의 연계성 부족을 해소하기 위해 2018년 과학기술정보통신부와 개인정보보호위원회가 'ISMS-P'로 전면 통합함.
- **핵심 목적** : 개인정보의 수집, 저장, 이용, 파기 전 생명주기에 걸친 법적 보호조치 기준을 충족하고 기업의 자율적 개인정보보호 거버넌스를 확립.

## Ⅱ. PIMS(Personal Information Management System)의 핵심 아키텍처 및 동작 메커니즘

구 PIMS의 체계는 현행 ISMS-P의 3대 영역(관리체계 수립 16개, 보호대책 요구사항 64개, 개인정보 처리단계별 요구사항 22개 = 총 102개 항목)의 핵심 근간으로 계승됨.

```text
[ PIMS의 역사적 발전 계보 및 현행 ISMS-P 통합 아키텍처 ]

  [ 과거 분립 체계 ]
  * 행정안전부: PIPL (개인정보보호 인증제)  \
  * 방송통신위원회: PIMS (개인정보보호 관리체계) -+---> [ 2018년 전면 통합! ]
  * 과학기술정보통신부: ISMS (정보보호 관리체계) /
                                                 |
                                                 v
 +--------------------------------------------------------------------------+
 |               현행 통합 ISMS-P 인증 기준 체계 (총 102개 통제 항목)         |
 |                                                                          |
 |  [ 1. 관리체계 수립 및 운영 ] (16개 항목)                                 |
 |   * 경영진의 참여, 최고책임자(CISO/CPO) 지정, 위험 관리, 내부 감사       |
 |  ----------------------------------------------------------------------  |
 |  [ 2. 보호대책 요구사항 ] (64개 항목 - 기존 ISMS 영역)                   |
 |   * 정책 수립, 인적 보안, 자산 관리, 접근 통제, 암호화, 침해사고 관리     |
 |  ----------------------------------------------------------------------  |
 |  [ 3. 개인정보 처리단계별 요구사항 ] (22개 항목 - 구 PIMS 영역 계승!)     |
 |   * 수집 시 보호조치 (최소 수집, 적법 동의, 법정대리인)                 |
 |   * 보유/이용 시 보호조치 (암호화, 접근권한, 분리보관)                   |
 |   * 제공 시 보호조치 (제3자 제공 동의, 위탁 관리)                        |
 |   * 파기 시 보호조치 (지체 없는 파기, 파기 절차 검증)                    |
 |   * 정보주체 권리 보장 (열람, 정정, 삭제, 처리정지 대응)                 |
 +--------------------------------------------------------------------------+
```

- **PIMS에서 ISMS-P로의 전면 통합** : 기업의 중복 심사 부담(컨설팅 비용, 기간)을 대폭 완화하기 위해 정보보호 관리체계(ISMS)와 개인정보 관리체계(PIMS)를 단일 인증 제도로 전격 통합.
- **개인정보 처리단계별 22개 특화 기준** : ISMS-P의 3영역에 온전히 녹아들어 수집, 저장, 이용·제공, 파기, 정보주체 권리 보장 등 법적 필수 요구사항을 완벽히 점검.
- **인증 의무 대상자 제도** : 일정 규모 이상의 정보통신서비스 제공자(전년도 매출 100억 이상, 일평균 이용자 100만 명 이상 등) 및 상급종합병원, 대학교는 매년 인증 취득 의무화.
- **국제 표준(ISO/IEC 27701)과의 정렬** : ISO 27001의 프라이버시 확장 표준인 ISO/IEC 27701(PIMS)과 유사한 구조를 지니며 글로벌 컴플라이언스 준수의 초석 제공.

## Ⅲ. PIMS(Personal Information Management System)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 구 PIMS | 구 ISMS | 현행 통합 ISMS-P |
| --- | --- | --- | --- |
| 주관 부처 | 방송통신위원회 | 과학기술정보통신부 | 개인정보보호위원회 / 과기정통부 공동 |
| 인증 대상 | 개인정보 처리 전반 (자율 신청) | 정보통신 인프라 보안 (법정 의무) | ISMS(80개) 또는 ISMS-P(102개) 선택 취득 |
| 핵심 목적 | 개인정보 침해 방지 및 프라이버시 | 기업 정보자산의 기밀성/무결성/가용성 | 정보보안과 개인정보보호의 통합 거버넌스 |
| 심사 영역 | 개인정보 라이프사이클 중심 | 네트워크/시스템 기술적 보호 중심 | 관리체계(16) + 보호대책(64) + 개인정보(22) |
| 유효 기간 | 3년 (매년 사후 심사) | 3년 (매년 사후 심사) | 3년 (매년 사후 심사 수행) |

- PIMS는 한국의 선도적인 개인정보 관리체계로서 현행 ISMS-P로 발전 계승되었으며, 기업의 컴플라이언스 준수와 신뢰성을 입증하는 국가 공인 척도임.

## Ⅳ. PIMS(Personal Information Management System)의 주요 한계점 및 해결 방안

- **중소·영세 스타트업의 막대한 인증 취득 및 유지 비용 부담** :
  - **한계점** : 102개 통제 항목을 충족하기 위한 보안 컨설팅 비용, 인증 수수료, 매년 사후 심사 비용으로 인해 스타트업의 규제 진입 장벽화.
  - **해결 방안** : 클라우드 SaaS를 활용하는 중소기업을 위한 간이 심사 제도 및 KISA 인증 수수료 바우처 지원 확대.
- **서류 작업 중심의 형식적 심사(Paperwork Security) 한계** :
  - **한계점** : 인증 심사 통과를 위해 방대한 증적 문서 작성에만 치중하여 실제 시스템의 제로데이 취약점이나 실시간 침해사고 방어 실효성 괴리.
  - **해결 방안** : 서류 심사 비중을 줄이고 실전 모의 해킹 및 실제 시스템 취약점 점검 중심의 기술 심사 배점 대폭 강화.
- **클라우드(AWS, Azure) 환경에서의 인증 범위 산정 복잡성** :
  - **한계점** : 서버리스, 컨테이너, MSA 등 수시로 생성·삭제되는 동적 클라우드 리소스에 대해 정적인 자산 인벤토리 기반 심사 기준 적용 곤란.
  - **해결 방안** : 클라우드 책임 공유 모델을 반영한 '클라우드 환경 ISMS-P 심사 가이드'를 준용하여 CSP 인증 상호 인정.

## Ⅴ. PIMS(Personal Information Management System) 적용 및 발전을 위한 기술사적 제언

- **상시 지속적 컴플라이언스(Continuous Compliance) 모니터링 구축** : 심사 시즌에만 반짝 증적을 모으는 관행을 탈피하고, SIEM 및 CSPM과 연동하여 102개 통제 항목 준수 상태를 365일 실시간 대시보드로 시각화.
- **CPO(개인정보보호책임자)의 위상 및 독립적 조사 권한 부여** : 개정 개인정보보호법에 따라 CPO의 독립성을 법적으로 보장하고, 프라이버시 침해 우려 시 서비스 출시를 중단시킬 수 있는 거부권(Veto) 부여.
- **글로벌 ISO/IEC 27701 및 CBPR과의 통합 심사 추진** : 해외 진출 기업의 경우 국내 ISMS-P 준비 증적을 바탕으로 국제 프라이버시 표준인 ISO 27701 및 APEC CBPR을 동시 취득하여 글로벌 규제 비용 절감.
