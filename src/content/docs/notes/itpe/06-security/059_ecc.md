## 지식 로드맵 내 현재 위치

암호기술 → 공개키 암호 → 타원곡선 암호(ECC) 및 이산대수 난제

## 30초 인출

- **본질:** 유한체 상의 타원곡선 군에서 점의 스칼라 배수 연산($Q = d \cdot G$)은 쉬우나 역연산인 타원곡선 이산대수 문제(ECDLP)를 풀기는 극도로 어렵다는 수학적 난제에 기반한 공개키 암호 알고리즘
- **메커니즘:** 도메인 파라미터($p, a, b, G, n$) 합의 → 개인키($d$) 생성 → 스칼라 점 곱셈($Q = dG$)으로 공개키 도출 → ECDH(키 합의) 및 ECDSA(전자서명) 수행
- 통찰: 짧은 키 길이와 저전력 고효율성에도 불구하고 ECDSA 서명 생성 시 임시 난수 재사용에 따른 개인키 유출 위험과 부채널 공격 및 쇼어 알고리즘 기반 양자 취약성에 대비하여 결정론적 서명(RFC 6979) 및 PQC 마이그레이션 필수

<details><summary>핵심 용어</summary>

- **ECC(Elliptic Curve Cryptography):** 닐 코블리츠(Neal Koblitz)와 빅터 밀러(Victor Miller)가 1985년 독립적으로 제안한 타원곡선 기반 비대칭 암호 방식.
- **ECDLP(Elliptic Curve Discrete Logarithm Problem):** $Q = d \cdot G$에서 $G$와 $Q$를 알 때 스칼라 정수 $d$(개인키)를 역추적하는 것의 계산 복잡도 난제.
- **와이어슈트라스 방정식(Weierstrass Equation):** $y^2 = x^3 + ax + b \pmod p$ ($4a^3 + 27b^2 \neq 0$).
- **ECDH(Elliptic Curve Diffie-Hellman):** 타원곡선 연산을 활용하여 안전하지 않은 통신 채널에서 대칭 비밀키를 공유하는 프로토콜.
- **ECDSA(Elliptic Curve Digital Signature Algorithm):** 타원곡선 기반 전자서명 표준(ANSI X9.62, FIPS 186-5).
- **몽고메리 사다리(Montgomery Ladder):** 스칼라 비트에 무관하게 일정한 연산 시간을 유지하여 부채널 타이밍 공격을 방어하는 곱셈 알고리즘.

</details>

> 타원곡선암호(ECC)의 수학적 원리(타원곡선 방정식, 점의 덧셈 및 스칼라 곱)와 공개키 생성 메커니즘을 설명하고, RSA와의 보안 강도 및 성능 비교와 운영 시 고려해야 할 구현 취약점 극복 방안을 제시하시오. (기출·제136회 1교시 12번)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 유한체 $GF(p)$ 상에 정의된 타원곡선의 대수적 군(Group) 구조에서 점들의 덧셈과 스칼라 곱셈 연산으로 도출되는 이산대수 난제(ECDLP)를 이용한 공개키 암호 알고리즘 |
| 목적 | RSA 대비 훨씬 짧은 키 길이(256비트 대 3072비트)로 동일 수준의 보안 강도를 제공하여 IoT, 스마트카드, 모바일 등 자원 제약 환경에 최적화된 기밀성 및 전자서명 제공 |

## Ⅱ. 타원곡선암호(ECC)의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 짧은 키 길이 | 256비트 키 길이로 RSA 3072비트와 대등한 128비트 보안 강도(Security Strength) 달성 | NIST secp256r1, Curve25519 |
| 고속 연산 및 저전력 | 키와 암호문 크기가 작아 연산 속도가 빠르고 네트워크 대역폭 및 배터리 소모 극소화 | 모바일 TLS, 블록체인(비트코인 secp256k1) |
| 수학적 지수적 복잡도 | RSA를 공격하는 준소수 인체(GNFS)와 달리 아인호른 알고리즘의 지수적 복잡도($O(\sqrt{n})$) 유지 | Pollard's rho 알고리즘 내성 |
| 표준화된 응용 프로토콜 | 키 교환(ECDH), 전자서명(ECDSA, EdDSA), 통합 암호화(ECIES) 등 다양한 보안 규격 완비 | FIPS 186-5, RFC 7748 |

## Ⅲ. ECC 수학적 연산 원리 및 키 생성 프로세스

```text
[ 1. 유한체 타원곡선: y^2 ≡ x^3 + ax + b (mod p) ]
점 P(x1, y1)와 점 Q(x2, y2)의 대수적 점 덧셈 (Point Addition)
       │
       ├─ P ≠ Q : 두 점을 잇는 직선이 곡선과 만나는 제3의 점 R'를 x축 대칭한 점 R = P + Q
       ├─ P = Q : 점 P에서의 접선이 곡선과 만나는 점을 x축 대칭한 점 R = 2P (Point Doubling)
       ▼
[ 2. 스칼라 곱셈 (Scalar Multiplication) ]
기준점 G를 d번 더하는 연산: Q = d · G = G + G + ... + G (d번 덧셈)
       │
       ▼ (순방향 연산: Double-and-Add 알고리즘으로 O(log d) 고속 계산 가능)
[ 3. 공개키 Q 및 개인키 d 생성 ]
   - 개인키(Private Key): 임의의 난수 d (1 ≤ d < n) 비밀 유지
   - 공개키(Public Key) : 타원곡선 상의 좌표점 Q = d · G 공개
       ▲
       │ (역방향 연산: Q와 G로부터 d를 구하는 것은 ECDLP 난제로 계산 불가능)
```

| 단계 | 수행 작업 | 수학적 정의 및 메커니즘 |
|---|---|---|
| 1. 도메인 파라미터 정의 | 소수 $p$, 계수 $a, b$, 기준점 $G(x, y)$, 위수 $n$, 보조인수 $h$ 합의 | 표준 곡선(secp256r1, Ed25519) 채택 |
| 2. 개인키 생성 | 암호학적 난수 생성기(CSPRNG)를 이용하여 $1$부터 $n-1$ 사이의 스칼라 정수 $d$ 선택 | 하드웨어 난수기(TRNG) 권장 |
| 3. 공개키 계산 | 스칼라 곱셈을 통해 타원곡선 상의 좌표 $Q(x_Q, y_Q) = d \cdot G$ 도출 | 몽고메리 사다리 연산 적용 |
| 4. 공개키 검증 | $Q$가 무한원점($\mathcal{O}$)이 아니며 타원곡선 방정식 및 $nQ = \mathcal{O}$ 만족 여부 검사 | 유효하지 않은 곡선 공격 방어 |

## Ⅳ. ECC vs RSA 보안 강도 및 성능 비교

| 구분 | 타원곡선 암호 (ECC) | RSA 암호 |
|---|---|---|
| 수학적 기반 난제 | 타원곡선 이산대수 문제 (ECDLP) | 큰 합성수의 소인수분해 문제 (IFP) |
| 128비트 보안 강도 키 크기 | **256 비트** (매우 작음) | **3072 비트** (매우 큼) |
| 192비트 보안 강도 키 크기 | **384 비트** | **7680 비트** |
| 256비트 보안 강도 키 크기 | **512 비트** | **15360 비트** |
| 연산 속도 및 오버헤드 | 서명 생성 빠름, 키 생성 극도로 빠름 | 서명 검증은 빠르나 키 생성/서명 느림 |
| 메모리 및 대역폭 | 암호문 및 인증서 크기가 작아 패킷 최적화 | 큰 키 크기로 통신 지연 및 스토리지 낭비 |
| 주요 적용 분야 | TLS 1.3, 비트코인/이더리움, IoT 보안 칩 | 레거시 PKI, 과거 공인인증서, 웹 서버 인증 |

## Ⅴ. ECC의 한계와 방안

| 한계 | 방안 |
|---|---|
| ECDSA 서명 생성 시 임시 난수($k$)가 중복되거나 비트 편향이 발생하면 두 개의 서명값 대조만으로 개인키($d$)가 즉시 역추출 | 개인키와 메시지 해시값을 결합하여 결정론적으로 일회용 난수를 유도하는 RFC 6979 결정론적 ECDSA 또는 Ed25519(EdDSA) 도입 |
| 스칼라 곱셈(Double-and-Add) 과정에서 비밀키 비트(0과 1)에 따른 연산 시간 및 전력 소모 패턴 차이로 인한 단순 전력 분석(SPA) 부채널 공격 노출 | 비트 값에 관계없이 매 루프마다 항상 동일한 덧셈과 2배 연산을 수행하는 몽고메리 사다리(Montgomery Ladder) 및 상수 시간(Constant-time) 라이브러리 채택 |
| 미래 대규모 범용 양자컴퓨터 등장 시 쇼어(Shor) 알고리즘에 의해 다항 시간($O((\log n)^3)$) 내에 ECDLP가 완전 붕괴 | 격자 기반 양자내성 암호(ML-KEM/Kyber, ML-DSA/Dilithium)와의 하이브리드 키 교환(X25519 + Kyber) 및 암호 민첩성(Crypto-Agility) 체계 수립 |

## Ⅵ. 제언

```text
[ 전통적 공개키 환경 ]                 [ 양자 전환기 하이브리드 암호 체계 ]
무거운 RSA 3072+ ────┐               ┌── 경량 통신: Ed25519 (결정론적 고속 서명)
높은 통신 오버헤드 ──┼─→ [ 성능 병목 ] ─┼── 부채널 방어: 몽고메리 사다리 상수 시간 연산
양자 공격 완전 취약 ──┘               └── 미래 대비: ECC + PQC(Kyber) 복합 하이브리드
```

| 평가 영역 | RSA 암호 체계 | ECC 암호 체계 | 향후 PQC 하이브리드 체계 |
|---|---|---|---|
| 통신 효율성 | 키 크기로 인해 낮음 | 초소형 키로 극대화 | 키 크기 다소 증가하나 양자 내성 확보 |
| IoT 적합성 | 연산 부하로 적용 곤란 | 초경량 스마트카드 최적 | 경량 PQC 알고리즘 선별 적용 |
| 포스트 퀀텀 내성 | 양자컴퓨터에 즉시 해독 | 양자컴퓨터에 즉시 해독 | 쇼어 및 그로버 알고리즘 동시 방어 |

타원곡선암호(ECC)는 짧은 키 길이와 뛰어난 연산 효율성을 무기로 현대 인터넷 보안과 블록체인의 표준 기저 암호로 자리 잡았으며, 양자 컴퓨터 시대에 대응하기 위해 격자 기반 PQC와의 하이브리드 결합 형태로 진화 필수.
