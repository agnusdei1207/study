## 지식 로드맵 내 현재 위치

공공 정보보호·사고 대응 → 행정전자서명 보호 → 온나라·GPKI 인증 체계 침해 대응

## 30초 인출

- **본질:** 원격근무 단말 악성코드 감염 등으로 정부 온나라시스템 접속 로그, GPKI(행정전자서명) 인증서 파일 및 개인키가 다크웹에 노출되어 행정망 신뢰성이 위협받은 공공 침해 사고
- **메커니즘:** 원격 PC 인포스틸러 침투 → 파일형 GPKI 인증서(.der/.key) 및 비밀번호 탈취 → G-VPN 우회 접속 시도 → 유출 인증서 긴급 폐지(CRL/OCSP) → 모바일 공무원증 및 ZTNA 전환
- 통찰: 단순 패스워드 변경을 넘어 파일 형태 인증서의 무단 복제를 근원 차단하기 위해 하드웨어 보안 토큰(HSM), FIDO 기반 모바일 공무원증, ZTNA 기반 상황 인지 원격 접속 통제 전환 시급

<details><summary>핵심 용어</summary>

- **온나라시스템(On-Nara):** 대한민국 중앙부처 및 지자체 공무원이 문서 기안, 결재, 유통을 수행하는 표준 전자결재 행정업무시스템.
- **GPKI(Government Public Key Infrastructure):** 전자정부 서비스 및 공무원 신원 확인, 전자결재 위변조 방지를 위한 국가 행정전자서명 인증체계.
- **G-VPN(Government Virtual Private Network):** 외부 인터넷 환경에서 정부 내부 업무망으로 암호화 터널을 생성하여 안전하게 원격 접속하도록 지원하는 공공 VPN.
- **인포스틸러(Infostealer):** 웹 브라우저 캐시, 파일 시스템 내 인증서, 계정 자격증명을 무단 탈취하여 C2 서버로 전송하는 악성코드.
- **CRL / OCSP:** 폐지된 인증서 목록(CRL) 및 온라인 인증서 상태 프로토콜(OCSP)을 통해 실시간 유효성을 판별하는 체계.

</details>

## 2~4교시 예상문제 (25점)

> 최근 발생한 정부 온나라시스템 접속 로그 및 GPKI 인증서 유출 사고의 발생 경위와 구조적 보안 취약점을 분석하고, 공공 원격근무(G-VPN) 인증 체계 고도화 및 제로 트러스트(ZTA) 전환 관점의 재발 방지 대책을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 외부 인터넷 PC에 저장된 온나라 업무시스템 접속 로그, 약 650명분의 GPKI 인증서 파일 및 개인키(12명분)가 인포스틸러 악성코드 등에 의해 탈취되어 다크웹에 유출된 침해 사고 |
| 목적 | 유출 인증서의 신속한 효력 정지, 행정망 접근 통제 강화, 파일형 인증 체계의 근본적 취약점 해소를 통한 전자정부 신뢰성 확보 |

## Ⅱ. 온나라·GPKI 인증서 유출 사고의 주요 특징

| 특징 | 세부 내용 | 취약 요인 |
|---|---|---|
| 파일 기반 인증서 복제 | PC 로컬 디스크(NPKI/GPKI 폴더)에 .der 및 .key 파일 형태로 평문 저장 | 인포스틸러 악성코드 감염 시 무단 파일 탈취 용이 |
| 비밀번호 의존성 | 탈취된 개인키 복호화 비밀번호가 브라우저 자동 완성 등에 노출 | 단일 인증 요소 탈취로 인한 사칭 공격 가능 |
| 원격근무 단말 통제 한계 | 개인 PC 또는 외부 단말에서 G-VPN을 통해 내부망 접근 허용 | 단말 무결성(EDR, 백신 검사) 검증 우회 가능성 |
| 즉각적 무효화 지연 | 인증서 유출 인지 시점과 CRL/OCSP 반영 간 시차 존재 | 공격자의 잠재적 내부망 정찰 및 전자결재 시도 위험 |

## Ⅲ. 온나라·GPKI 침해 사고 발생 메커니즘 및 대응 체계

```text
[ 외부 침해 단계 ]
공무원 외부 PC ──▶ 인포스틸러 감염 ──▶ GPKI 인증서(.der/.key) & 계정 탈취
                                                    │
                                                    ▼
[ 위협 확산 단계 ]                           다크웹 유출 및 판매 시도
G-VPN 터널 접속 ──▶ 온나라 업무망 우회 접근 시도 ──┘
         │
         ▼
[ 정부 긴급 대응 체계 ]
┌──────────────────────────────────────────────────────────┐
│ 1. 긴급 무효화 : 잔여 유효기간 보유 인증서 즉시 폐지 (CRL/OCSP)    │
│ 2. 접근 통제 강화: G-VPN 로그인 시 2차 채널 인증(ARS/OTP) 강제     │
│ 3. 단말 무결성 : 세션 재사용 방지 및 온나라 중복 로그인 전면 차단   │
│ 4. 감사 추적   : 유출 계정의 최근 6개월 전자결재 및 기안 이력 전수 조사 │
└──────────────────────────────────────────────────────────┘
```

| 단계 | 침해 및 대응 내용 | 적용 기술 및 조치 |
|---|---|---|
| 1. 침해 인입 | 비인가 외부 PC에서 정부 업무망 원격 접속 중 악성코드 감염 | 브라우저 캐시 및 로컬 디렉터리 자격증명 수집 |
| 2. 데이터 노출 | 접속 로그, GPKI 인증서 파일, 과거 API 코드 일부 다크웹 유출 | OSINT 모니터링, 사이버 위협 인텔리전스(CTI) 탐지 |
| 3. 긴급 통제 | 유효 인증서 3건 즉시 폐지 및 잔여 인증서 효력 상실 확인 | 행정전자서명 인증관리센터 폐지 공고, OCSP 갱신 |
| 4. 원격 접속 보강 | G-VPN 접속 절차에 전화 인증(ARS) 및 다중 인증(MFA) 강제 | 2단계 인증 연동, 세션 타임아웃 단축 |
| 5. 전수 감사 | 비인가 접근 로그, 전자문서 열람 및 기안 조작 여부 조사 | SIEM 연계 로그 분석, 포렌식 무결성 검증 |

## Ⅳ. 공공 인증 방식별 보안 특성 비교

| 구분 | 파일형 GPKI 인증서 (사고 대상) | 보안토큰 (HSM / 스마트카드) | FIDO 기반 모바일 공무원증 |
|---|---|---|---|
| 저장 매체 | PC 로컬 디스크 (하드/USB) | 하드웨어 보안 칩 (Secure Element) | 스마트폰 TEE/SE 내 격리 저장 |
| 개인키 추출 가능 여부 | 가능 (파일 복사 및 탈취 취약) | 불가 (칩 내부 연산, 추출 차단) | 불가 (비대칭키 쌍 단말 내부 보관) |
| 인증 메커니즘 | 인증서 암호(패스워드) 단일 입력 | 물리 토큰 삽입 + PIN 번호 | 생체인증(지문/Face) + 공개키 서명 |
| 원격근무 보안성 | 인포스틸러에 극도로 취약 | 물리 토큰 소지 필요로 안전 | 생체정보 결합 무단 도용 원천 차단 |
| 편의성 및 배포성 | 복사 간편하나 분실/유출 위험 | 별도 토큰 리더기 필요, 비용 발생 | 모바일 앱 기반 간편 발급 및 폐지 |

## Ⅴ. 온나라·GPKI 침해 사고 대응의 한계와 방안

| 한계 | 방안 |
|---|---|
| 파일 시스템 기반 .der/.key 인증서는 소프트웨어 복제가 가능하여 단말 감염 시 원천 방어 불가능 | 파일형 인증서 전면 폐지 및 스마트폰 보안영역(SE)에 개인키를 은닉하는 FIDO 기반 모바일 공무원증 또는 하드웨어 HSM 의무화 |
| G-VPN의 단순 네트워크 터널링 방식은 단말의 악성코드 감염 상태나 비정상 컨텍스트를 인지 불가 | 단말 보안 상태(EDR 점검, 백신 최신화, 탈옥 여부)를 검증하여 접속을 동적 제어하는 제로 트러스트 네트워크 액세스(ZTNA) 도입 |
| 인증서 폐지 목록(CRL) 배포 주기 지연으로 인해 유출 인지 후 실시간 차단까지 공격 허용 시차 존재 | OCSP(온라인 인증서 상태 프로토콜) 실시간 스테이플링 및 단말·세션 기반 즉시 강제 로그아웃(Revocation Push) 체계 확립 |

## Ⅵ. 제언

```text
[ 기존 공공 원격근무 ]                 [ 제로 트러스트 기반 공공 보안 ]
파일형 인증서 ──────┐                 ┌── FIDO2 모바일 공무원증 (HW 격리)
G-VPN 경계 침투 ───┼─→ [ 침해 확산 ] ─┼── ZTNA 기반 엔드포인트 무결성 검증
단일 패스워드 ──────┘                 └── 지속적 문맥 평가 및 조건부 접근 제어
```

| 평가 영역 | 기존 원격근무 체계 | ZTA 기반 원격근무 체계 | 향후 발전 방향 |
|---|---|---|---|
| 자격증명 보안 | 파일 복제로 위변조 위험 | 비추출 하드웨어 서명 | 다자간 계산(MPC) 기반 분산 키 관리 |
| 네트워크 경계 | 내부망 접속 시 전체 노출 | 앱 단위 마이크로 세그멘테이션 | SDP(소프트웨어 정의 경계) 기반 은닉화 |
| 인증 신뢰도 | 로그인 시점 1회 인증 | 세션 전주기 지속 검증(CAC) | AI 기반 비정상 행위(UEBA) 탐지 연동 |

온나라·GPKI 유출 사고는 전통적인 경계선 보안과 파일형 공인인증서의 구조적 한계를 입증한 사례이며, 향후 행정망 보안은 하드웨어 기반 무시크릿 인증과 ZTNA 기반 제로 트러스트 모델로 전면 전환 필수.

## 출제 이력과 검증 출처

- 행정안전부 정부업무관리시스템(온나라) 보안 침해 대응 공식 브리핑
- 행정전자서명 인증관리센터(GPKI) 운영 지침 및 인증서 관리 규정
- 전자정부법 및 공공부문 정보보안 기본지침
- 국가사이버안보센터 공공부문 제로 트러스트 도입 가이드라인
