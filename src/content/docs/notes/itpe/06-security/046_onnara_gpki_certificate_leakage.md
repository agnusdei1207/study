## 30초 인출

- **본질**: 온나라·GPKI 사고는 해킹 관련 게시물에 정부 업무시스템 접속 로그와 행정전자서명 인증서 파일 등이 포함된 공공부문 침해 사례.
- **메커니즘**: 외부 PC에서 G-VPN을 통한 온나라 접근 정황과 GPKI 자료 노출을 확인하고, 인증서 폐지·추가 인증·업무기록 조사를 병행.

<details><summary>핵심 용어</summary>

- **온나라시스템·GPKI 인증서 유출**: 온나라 접속 로그·GPKI 인증서 파일·API 코드 일부가 외부 해킹 게시물에서 확인된 2025년 공공부문 침해 사례.
- **GPKI(Government Public Key Infrastructure, 행정전자서명 인증체계)**: 공무원의 사용자 인증과 전자결재 등에 쓰이는 행정전자서명 체계.
- **G-VPN(Government Virtual Private Network, 정부원격근무시스템)**: 외부 환경에서 정부 업무망에 원격 접속하도록 제공하는 체계.
- **API(Application Programming Interface, 응용 프로그래밍 인터페이스)**: 시스템·소프트웨어 간 요청과 기능 사용을 정하는 접점.
- **인증서 폐지**: 더 이상 신뢰할 수 없는 인증서를 폐지 목록에 등록해 이후 검증에서 거부되게 하는 조치.

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **온나라시스템·GPKI 인증서 유출**은 해킹 관련 게시물에서 온나라 접속 로그·행정전자서명 인증서 파일·API 코드 일부가 확인된 공공부문 침해 사례. |
| 목적 | 노출된 인증수단을 무효화하고 시스템·업무기록을 조사해 비인가 접근과 피해 확산을 차단. |

### Ⅱ. 확인 내용과 대응

```text
외부 PC → G-VPN → 온나라 접근 정황
                        ↓
게시물에서 로그·GPKI 인증서 파일·API 코드 확인
                        ↓
650명가량의 인증서 파일 확인
  ├─ 12명: 인증서 키·비밀번호 포함
  └─ 3명: 유효기간이 남은 인증서 폐지
```

행정안전부의 2025-10-17 브리핑 기준. 유출 경위와 피해 영향은 당시 국가정보원 주관으로 조사 중이었으며, 모든 인증서 파일에 키·비밀번호가 포함된 것은 아님.

### Ⅲ. 한 줄 제언

제언: 인증서 파일 발견 즉시 비밀번호 변경에 그치지 않고 유효성 폐지·재발급과 단말·접속기록 조사를 함께 수행.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **온나라시스템·GPKI 인증서 유출**은 해킹 관련 게시물에서 온나라 접속 로그·행정전자서명 인증서 파일·API 코드 일부가 확인된 공공부문 침해 사례. |
| 목적 | 노출된 인증수단을 무효화하고 시스템·업무기록을 조사해 비인가 접근과 피해 확산을 차단. |

## Ⅱ. 공식 브리핑에서 확인된 사실

| 항목 | 확인 내용 |
|---|---|
| 접근 정황 | 외부 인터넷 PC에서 G-VPN을 통해 업무망 온나라시스템에 접근한 정황 |
| 게시 자료 | 온나라 접속 로그, GPKI 인증서 파일, 구버전 API 소스 일부 |
| 인증서 파일 | 약 650명분 확인; 12명분 자료에 인증서 키와 비밀번호 포함 |
| 긴급 조치 | 유효기간이 남은 3개 인증서 폐지; G-VPN 접속 시 ARS 추가 인증 및 온나라 로그인 재사용 방지 조치 |
| 조사 상태 | 2025-10-17 브리핑 시점에 유출 경위·피해 영향 조사 중 |

구버전 API 코드는 2018년부터 사용하지 않아 관련 보안 위협이 없다고 행정안전부가 해당 브리핑에서 설명. 조사 발표와 확인되지 않은 공격 경로를 구분.

## Ⅲ. 위험 발생 경로

```text
외부 PC·원격근무 환경의 침해 가능성
                    ↓
온나라 접속 정황·GPKI 자료 노출
                    ↓
유효 인증수단이면 사용자 사칭·업무 접근 위험
                    ↓
인증 기록·전자결재 기록으로 실제 영향 확인
```

## Ⅳ. 대응 통제

| 통제 영역 | 적용 방향 |
|---|---|
| 인증서 | 노출 가능성이 있는 인증서 즉시 폐지·재발급; 비밀번호 변경만으로 키 유출을 해소한 것으로 간주하지 않음 |
| 원격접속 | G-VPN 추가 인증, 승인된 단말과 접속 조건 점검, 로그인 재사용 방지 |
| 업무시스템 | 인증·전자결재 로그 보존, 비정상 시간·단말·문서 행위 확인 |
| 단말·사용자 | 외부 PC 악성코드·저장매체 노출 조사와 인증서 공유 제한 |
| 운영절차 | 발급·갱신·폐지 기록과 사고 통지·영향평가 책임 관리 |

```text
의심 인증수단 ── 유효성 확인 ── 폐지·재발급
       │                             │
       └── 계정·단말 조사 ── 인증·업무기록 분석
                                     ↓
                          영향 범위·재발 경로 확인
```

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 파일형 인증수단은 원격근무 단말에 복제될 경우 사용자·업무시스템 경계를 넘어 악용될 가능성. | 내부 행정시스템의 인증을 단말·사용자 맥락에 묶고, 중요 업무부터 모바일 공무원증 등 대체 인증을 단계 적용하며 기존 인증서 폐지·복구 절차를 병행하는 방안을 제안. |
