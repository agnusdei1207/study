## Ⅰ. 온나라시스템·GPKI 전자서명 인증서 유출 침해사고의 개요

- **개념** : 원격근무 공무원의 PC가 인포스틸러(Infostealer) 악성코드에 감염되어 정부 전자문서결재 표준 시스템인 '온나라(On-Nara)' 시스템의 접속 자격증명과 파일 형태의 GPKI(행정전자서명) 인증서(.der/.key) 및 비밀번호가 다크웹에 유출된 대규모 전자정부 침해사고.
- **배경 및 필요성** : 공공기관의 재택·원격근무 확산으로 개인 단말이나 외부 인터넷 환경에서 정부 내부 행정망(G-VPN)에 접속하는 과정에서 엔드포인트 보안 통제 결함으로 발생.
- **핵심 목적** : 파일 기반 인증서 취약성 분석, 원격 접속 G-VPN 보안 결함 극복, 모바일 공무원증 및 FIDO2 기반 차세대 무마찰 제로트러스트 인증 체계로의 전환.

## Ⅱ. 온나라시스템·GPKI 전자서명 인증서 유출 침해사고의 핵심 아키텍처 및 동작 메커니즘

인터넷 PC에 침투한 인포스틸러가 NPKI/GPKI 폴더 내 인증서 파일과 웹 브라우저 캐시 비밀번호를 탈취한 후 G-VPN을 통해 정부 행정망 접속을 시도한 사건임.

```text
[ 온나라·GPKI 인증서 유출 사고 공격 경로 및 침해 흐름 ]

  [ 공격자 (다크웹 인포스틸러 유포) ]
           │ 1. 원격근무 공무원 PC 감염 (피싱 메일 / 비인가 SW 다운로드)
           ▼
  +-------------------------------------------------------------+
  | 원격근무자 개인 PC (보안 취약 단말)                         |
  |  - 브라우저 계정 자동 완성 자격증명 탈취                    |
  |  - C:\GPKI 폴더 내 파일형 인증서(.der) 및 개인키(.key) 탈취  |
  +------------------------------┬------------------------------+
                                 │ 2. 다크웹 유출 및 해커 손에 전달
                                 ▼
  +-------------------------------------------------------------+
  | 공격자의 정부망 침투 시도                                    |
  |  - 탈취된 GPKI 인증서 및 비밀번호로 공무원 사칭             |
  |  - G-VPN(정부 원격 접속 게이트웨이) 통과 시도               |
  +------------------------------┬------------------------------+
                                 │ 3. 내부망 접근 위협
                                 ▼
  +-------------------------------------------------------------+
  | 정부 전자결재망 : 온나라시스템 (On-Nara)                     |
  |  - 비인가 공문서 결재, 정부 내부 기밀 문서 열람 위협 직면   |
  |  - 긴급 대응: 650명 GPKI 인증서 폐지(CRL/OCSP), 비밀번호 변경|
  +-------------------------------------------------------------+
```

- **파일 기반 인증서 저장 취약성** : 인증서 공개키(.der)와 개인키(.key)가 로컬 디스크 특정 폴더에 평문 파일 형태로 보관되어 손쉬운 복사 탈취 허용.
- **단일 패스워드 의존성** : 개인키를 복호화하는 비밀번호가 단순 텍스트로 브라우저나 메모리에 잔류하여 인포스틸러에 의해 일괄 탈취.
- **원격 접속 단말 무결성 검증 미흡** : G-VPN 접속 시 단말에 최신 백신, EDR 실행 여부 및 악성코드 감염 상태 검증이 결여된 채 인증서만으로 통과 허용.
- **사후 긴급 대응** : 유출 확인 즉시 정부인증체계(GPKI) 등록원부에서 해당 인증서를 전면 효력정지(CRL/OCSP)하고 접속 차단 단행.

## Ⅲ. 온나라시스템·GPKI 전자서명 인증서 유출 침해사고의 세부 구성 요소 및 비교 분석

| 비교 항목 | 레거시 GPKI 파일 인증서 | 보안 토큰 (HSM) 인증서 | 모바일 공무원증 (DID 기반) |
| --- | --- | --- | --- |
| 개인키 보관 위치 | PC 로컬 디스크 (C:\GPKI) | 하드웨어 보안 토큰 (USB Dongle) | 스마트폰 하드웨어 보안 칩 (SE/TEE) |
| 키 복제 가능성 | 매우 쉬움 (단순 파일 복사 가능) | 복제 불가 (하드웨어 칩 내부 격리) | 복제 불가 (단말 고유 바인딩) |
| 원격 탈취 위험 | 인포스틸러 악성코드에 취약 | 물리적 도난 없는 한 원격 탈취 불가 | 원격 추출 원천 차단 (생체인증 연동) |
| 인증 편의성 | 편리함 (PC에 저장 후 자동 사용) | 불편함 (항상 USB 토큰 휴대 필요) | 최고 (스마트폰 생체인식으로 간편 승인) |
| 적용 아키텍처 | 전통적 클라이언트-서버 | 전자서명법 공인인증 체계 | 블록체인 분산 신원(DID), FIDO2 |

- 이 사건은 파일 형태로 PC에 저장되는 소프트웨어 인증서의 시대가 종말을 고했음을 명백히 보여주며, 하드웨어 보안 칩셋에 개인키가 영구 봉인되는 차세대 인증 체계 도입의 기폭제가 됨.

## Ⅳ. 온나라시스템·GPKI 전자서명 인증서 유출 침해사고의 주요 한계점 및 해결 방안

- **공무원 편의 중심의 소프트웨어 인증서 파일 다운로드 관행** :
  - **한계점** : 보안 토큰 휴대의 불편함으로 인해 PC 하드디스크나 이동식 USB에 인증서 파일을 복사해 두고 사용하는 현장 관행 지속.
  - **해결 방안** : 로컬 디스크 내 `.der`, `.key` 파일 저장을 OS 레벨에서 원천 금지하고 모바일 공무원증(FIDO2)을 표준 인증 수단으로 전면 의무화.
- **G-VPN의 네트워크 계층 전면 개방 한계** :
  - **한계점** : G-VPN 인증 통과 시 내부 서브넷 전체 IP에 접속할 수 있어 단일 단말 감염이 온나라시스템뿐 아니라 전 행정망 침해로 확산 위험.
  - **해결 방안** : ZTNA(Zero Trust Network Access)를 도입하여 단말 상태(단말 무결성, 보안 패치 여부)를 검증하고 오직 온나라 애플리케이션 포트만 개별 접속 허용.
- **인포스틸러 악성코드의 신속한 C2 전송으로 인한 골든타임 상실** :
  - **한계점** : 인증서 탈취 후 다크웹에 유출되어 탐지될 때까지 수개월이 소요되어 선제적 방어 실패.
  - **해결 방안** : 공공 전산망에 엔드포인트 위협 탐지 및 대응(EDR) 에이전트를 강제 배포하여 중요 인증서 파일 접근 및 비정상 아웃바운드 전송 즉시 차단.

## Ⅴ. 온나라시스템·GPKI 전자서명 인증서 유출 침해사고 적용 및 발전을 위한 기술사적 제언

- **'파일형 공공 인증서 완전 폐지' 로드맵 수립** : 모든 중앙부처 및 지자체 행정 시스템에서 파일형 GPKI 인증서 로그인을 영구 퇴출하고 스마트폰 DID 기반 모바일 공무원증으로 단일화.
- **공공 원격근무 단말에 제로트러스트 3대 원칙 강제** : 비인가 개인 PC 원격 접속을 불허하고, 공공 전용 격리 VDI(가상 데스크톱) 또는 관리형 노트북(MDM/EDR 탑재)만 허용.
- **다크웹 계정 유출 실시간 CTI 모니터링 연동** : 정부 도메인(go.kr) 계정 및 인증서가 다크웹 인포스틸러 로그에 등재되는 즉시 해당 인증서를 OCSP로 자동 폐기하는 자동화 파이프라인 구축.
