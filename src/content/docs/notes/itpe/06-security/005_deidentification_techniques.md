## 연관 키워드

- 가명·익명·비식별 처리, 가명정보(Pseudonymized Data), 익명정보(Anonymized Data), 데이터 3법
- 준식별자(QI, Quasi-Identifier), k-익명성(k-Anonymity), l-다양성(l-Diversity), t-근접성(t-Closeness)
- 링크 공격(Linkage Attack), 차분 프라이버시(Differential Privacy), 합성 데이터(Synthetic Data), TEE(Trusted Execution Environment), HSM(Hardware Security Module)

## Ⅰ. 가명·익명·비식별 처리 기술의 개요

- 핵심 요약 : 식별 가능성을 낮추는 공학적 변환으로 데이터 활용과 프라이버시 보호를 함께 달성하는 기술.
- 개념 : 개인정보의 일부를 삭제·대체·범주화해 추가 정보 없이는 특정 개인을 알아볼 수 없게 한 **가명정보** (Pseudonymized Data)와, 합리적 수단으로도 재식별할 수 없게 한 **익명정보** (Anonymized Data)를 만드는 **비식별 처리** (De-identification).
- 배경 및 필요성 : **데이터 3법** (개인정보 보호법, 정보통신망법, 신용정보법) 개정으로 가명정보의 결합과 활용이 허용되면서, 데이터 유통 활성화와 프라이버시 침해 방지를 함께 만족시키는 기술적 통제가 필요해짐.
- 주요 목적 : 데이터의 통계적·분석적 **유용성** (Utility)을 유지하면서 정보주체의 **프라이버시 리스크** (Privacy Risk)를 최소화하고, 합법적 데이터 결합과 AI 학습 데이터 활용을 지원.

## Ⅱ. 가명·익명·비식별 처리 기술의 특징 및 장점

- 핵심 요약 : 식별자 분류, 조치 기법, 수학적 적정성 평가, 결합 환경 통제가 맞물려 재식별 위험을 관리하는 구조.

1. 식별자와 준식별자 분류 : 주민등록번호·이름 같은 직접 식별자는 삭제하거나 일방향 해시로 처리하고, 나이·성별·우편번호처럼 결합 시 개인을 좁히는 **준식별자** (QI, Quasi-Identifier)를 따로 도출 → 결합 공격의 출발점을 차단.
2. 다섯 가지 조치 기법 : 삭제, 마스킹, 범주화, 가명처리, 잡음 추가를 목적에 맞게 조합 → 식별 위험의 크기와 데이터 유용성을 함께 조정.
3. 수학적 적정성 평가 : **k-익명성** (k-Anonymity, 같은 준식별자 조합을 가진 레코드가 최소 k개 이상이 되도록 보장), **l-다양성** (l-Diversity, 집단 안의 민감 속성 값이 다양하도록 보장), **t-근접성** (t-Closeness, 집단 내 민감 속성 분포가 전체 분포와 t 이내로 유사하도록 보장) → 위험을 수치 기준으로 판정.
4. 결합키 분리 : 가명정보를 결합할 때 결합키 생성과 관리를 분리하고, 전용 폐쇄망 분석 공간에서만 연동과 반출 심사를 수행 → 결합 과정의 재식별 가능성을 차단.

## Ⅲ. 가명·익명·비식별 처리 기술의 구조 (흐름)

- 핵심 요약 : 사전 검토, 비식별 조치, 적정성 평가, 사후 관리의 4단계를 평가 결과에 따라 반복하는 수명주기.

```text
[ 비식별 조치 4단계 수명주기 ]

1. 사전 검토
   식별자·준식별자 분류
   ↓
2. 비식별 조치
   삭제·마스킹·범주화·가명처리·잡음
   ↓
3. 적정성 평가
   k·l·t 기준으로 재식별 위험 측정
   ↓ 위험이 높으면 2단계로 재조치
4. 사후 관리
   활용 통제, 재식별 모니터링, 결합키 파기
```

```text
[ 가명정보 결합 흐름 ]

기관 A 가명정보 + 기관 B 가명정보
   ↓ 결합키 생성 (결합 전문기관)
폐쇄망 분석 공간
   ↓ 반출 심사 (통계 결과만)
분석 결과 활용
```

## Ⅳ. 가명·익명·비식별 처리 기술의 비교

- 핵심 요약 : 개인정보는 전면 규제, 가명정보는 보호조치를 조건으로 활용, 익명정보는 규제 밖에 있으나 재식별 불가 입증이 전제되는 구도.

| 비교 항목 | 개인정보 (Personal Data) | 가명정보 (Pseudonymized Data) | 익명정보 (Anonymized Data) |
| --- | --- | --- | --- |
| 개념 정의 | 살아 있는 개인을 알아볼 수 있는 정보 | 추가 정보 없이는 특정 개인 식별 불가 | 합리적 수단을 동원해도 식별 불가 |
| 법적 규제 | 개인정보 보호법 전면 적용, 동의 원칙 | 통계작성·과학적 연구·공익적 기록보존 목적에서 동의 없이 활용 가능 | 개인정보 보호법 적용 제외, 재식별 점검은 필요 |
| 추가 정보 결합 | 본래 상태에서 즉시 식별 가능 | 매핑 정보 결합 시 재식별 가능 | 재식별 불가 |
| 안전성 조치 | 법정 기술적·관리적 보호조치 준수 | 추가 정보 분리 보관, 접근 권한 통제 | 적정성 평가 후 사후 모니터링 |
| 예시 | 이름, 주민등록번호, 주소 | 일방향 해시값, 연령대, 시군구 단위 지역 | 지역·연령대별 통계 집계표 |

- 가명정보는 유용성을 유지한 채 결합과 분석에 쓰이지만 추가 정보 분리 같은 보호조치가 계속 따르고, 익명정보는 재식별 가능성이 없다는 평가 기록이 있어야 규제 밖으로 인정됨.

## Ⅴ. 가명·익명·비식별 처리 기술의 한계와 방안

- 핵심 요약 : 교차 결합에 의한 재식별, 과잉 일반화로 인한 유용성 저하, 키 관리 부실이라는 세 한계를 차분 프라이버시, 목적 기반 비식별, 키 격리로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **링크 공격** (Linkage Attack) | 공공 데이터, SNS 프로필, 구매 이력 같은 보조 데이터와 교차 결합하면 희귀 속성으로 재식별 | k-익명성 단독 적용을 지양하고 **차분 프라이버시** (Differential Privacy, 질의 결과에 수학적 잡음을 더해 개인 포함 여부의 영향을 제한)을 결합 | 재식별 위험 점수, 프라이버시 예산 소진율 |
| 과도한 일반화와 잡음 주입 | 나이를 넓은 단일 구간으로 묶는 식의 과잉 범주화로 AI 학습과 예측 정확도 저하 | 목적 기반 맞춤형 비식별화를 수행하고, 정보 손실량(Information Loss)을 유전 알고리즘 등 탐색 기법으로 최적화 | 정보 손실량, 예측 모델 정확도 저하율 |
| 결합키·솔트 관리 부실 | 가명화에 쓴 솔트나 매핑 테이블이 개발 환경이나 공용 DB에 유출되면 전체 가명 데이터가 복원 | 결합키와 솔트를 **HSM** (Hardware Security Module, 하드웨어 보안 모듈) 안에 격리하고, **Shamir's Secret Sharing** (비밀을 여러 조각으로 나눠 일정 수 이상이 모여야 복원되는 기법)으로 분산 보관 | 키 접근 이상 건수, 매핑 테이블 권한 검토 주기 |

## Ⅵ. 가명·익명·비식별 처리 기술에 대한 기술사적 제언

- 핵심 요약 : 원본 변형형 비식별에서 합성 데이터와 자동 검증, 신뢰 실행 환경으로 무게를 옮기는 방향.

1. 원본 레코드를 변형하는 방식에서 벗어나, 원본의 통계적 특성만 학습한 **합성 데이터** (Synthetic Data, 실제 레코드 대신 생성한 가상 데이터) 활용을 단계적으로 늘리는 것이 필요.
2. 비식별 결과의 k, l, t 값과 재식별 확률을 CI(Continuous Integration)/CD(Continuous Delivery) 파이프라인 안에서 자동 측정하여, 수작업 검토에 의존하지 않는 체계를 갖추는 것이 필요.
3. 이종 기업 간 결합 전문기관에는 **TEE** (Trusted Execution Environment, 신뢰 실행 환경) 기반 기밀 컴퓨팅을 적용하여, 데이터 운영자도 평문을 볼 수 없도록 통제를 강화하는 것이 필요.

## Ⅶ. 결론

- 핵심 요약 : 비식별 처리는 데이터 유용성과 재식별 위험 사이의 균형을 수학적 기준으로 관리하는 기술.
- 시사점 : 재식별 방지는 기법 선택보다 적정성 평가와 사후 통제에 달려 있으므로, 결합 환경과 키 관리를 함께 설계해야 함.
