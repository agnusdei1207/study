## 30초 인출

- **본질:** 비식별 처리는 개인을 알아볼 위험을 낮추도록 데이터 식별성을 줄이는 처리
- **메커니즘:** 식별자·준식별자·민감정보를 찾아 변환·삭제하고 결합 가능성을 포함해 재식별 위험을 평가
- **구분:** 가명정보는 추가정보 없이는 특정 개인을 알아보기 어렵게 한 개인정보이며, 익명성은 합리적 수단을 고려한 식별 가능성으로 판단

<details>
<summary>핵심 용어</summary>

- **가명처리:** 개인정보 일부를 삭제·대체해 추가정보 없이는 특정 개인을 알아보기 어렵게 하는 처리
- **비식별 처리:** 데이터에서 개인을 알아볼 가능성을 낮추기 위한 식별자 변환·삭제·접근통제 등의 처리
- **가명정보:** 가명처리로 추가정보를 사용·결합하지 않으면 특정 개인을 알아볼 수 없는 정보
- **익명정보:** 시간·비용·기술 등 합리적으로 고려할 수 있는 수단으로도 개인을 알아볼 수 없는 정보
- **준식별자:** 단독으로 직접 식별하지 않더라도 다른 정보와 결합해 개인 식별에 기여할 수 있는 속성
- **k-익명성 (k-Anonymity):** 준식별자 값 조합이 같은 레코드가 최소 k개가 되도록 하는 공개 데이터 모델
- **l-다양성 (l-Diversity):** 같은 준식별자 집단 안에서 민감 속성 값의 다양성을 고려하는 모델
- **t-근접성 (t-Closeness):** 집단 내 민감 속성 분포와 전체 분포의 차이를 제한하는 모델

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비식별 처리**는 개인을 알아볼 위험을 낮추도록 데이터의 식별성을 줄이는 처리 |
| 목적 | 개인정보 노출 위험 완화와 데이터의 안전한 이용 지원 |

### Ⅱ. 처리 유형과 방법

| 유형·방법 | 핵심 |
|---|---|
| 가명처리 | 추가정보를 분리·보호해 결합 전 식별 위험을 낮춤 |
| 익명처리 | 합리적으로 고려할 수 있는 수단으로도 개인 식별이 어렵도록 처리 |
| 변환 기법 | 삭제·범주화·마스킹·총계처리·노이즈 추가 등 데이터 특성에 맞는 선택 |
| 위험 모델 | k-익명성·l-다양성·t-근접성 등 공개 데이터의 식별·속성 노출 위험 평가 |

```text
목적·공개범위·수신자 확인
              ↓
직접 식별자·준식별자·민감정보 분류
              ↓ 변환·삭제·접근통제
재식별 위험과 데이터 유용성 평가
       ├─ 허용 가능 → 승인·관리
       └─ 높음 → 재처리·공개 제한
```

**제언:** 공개 데이터의 결합 가능성까지 반영한 재식별 위험평가와 재검토 절차

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비식별 처리**는 개인을 알아볼 위험을 낮추도록 데이터의 식별성을 줄이는 처리 |
| 목적 | 개인정보 노출 위험 완화와 데이터의 안전한 이용 지원 |

가명정보는 개인정보에 해당하며 추가정보와의 분리·보호가 핵심. 익명성은 단순 삭제 여부가 아니라 합리적으로 고려할 수 있는 정보·기술·비용을 포함한 식별 가능성 판단.

## Ⅱ. 데이터와 식별 위험

| 데이터 요소 | 위험 요인 | 주요 처리 |
|---|---|---|
| 직접 식별자 | 이름·식별번호 등 직접 식별 가능성 | 삭제·대체, 추가정보 분리 |
| 준식별자 | 다른 공개·보유 자료와 결합 가능성 | 범주화·일반화·억제 |
| 민감 속성 | 식별 이후 속성 추론·노출 | 접근통제, 집계·노이즈 등 목적별 보호 |

```text
직접 식별자 ── 개인을 직접 식별
준식별자   ── 다른 자료와 결합해 식별 위험
민감 속성  ── 개인 식별 후 속성 노출 위험
```

## Ⅲ. 처리 기법과 효과

| 기법 | 처리 방식 | 검토할 영향 |
|---|---|---|
| 삭제·마스킹 | 값 제거 또는 일부 감춤 | 결합 가능한 다른 속성 잔존 여부 |
| 범주화·일반화 | 세부 값을 넓은 구간·범주로 변환 | 분석 정밀도 저하 |
| 총계·집계 | 개별 레코드 대신 그룹 통계 제공 | 소규모 집단의 추론 위험 |
| 노이즈 추가 | 값 또는 통계에 임의 변동 부여 | 분석 오차와 누적 공개 위험 |
| 가명처리 | 식별정보를 대체하고 추가정보 분리 | 추가정보 접근·결합 통제 |

## Ⅳ. 프라이버시 모델의 역할과 한계

| 모델 | 확인하는 관점 | 한계 |
|---|---|---|
| k-익명성 | 준식별자 기준 집단의 크기 | 같은 집단의 민감 속성 값이 같을 수 있음 |
| l-다양성 | 집단 내 민감 속성 값의 다양성 | 값의 빈도·전체 분포 차이를 충분히 반영하지 못할 수 있음 |
| t-근접성 | 집단과 전체의 민감 속성 분포 차이 | 거리척도·유용성 손실을 함께 검토할 필요 |

## Ⅴ. 처리·검증 운영

```text
이용목적·공개환경 정의
          ↓ 데이터 분류
처리 기법·모델 선택
          ↓ 결합·추론 위험 검증
유용성·보호수준 검토
   ├─ 위험 수용 → 승인·접근통제·기록
   └─ 위험 과다 → 추가 처리·범위 축소
          ↓ 환경·목적 변경 시 재평가
```

| 통제 지점 | 확인 내용 |
|---|---|
| 처리 전 | 목적·법적 근거·공개 대상·결합 가능 자료 |
| 처리 후 | 재식별 공격 시나리오·속성 추론·유용성 저하 |
| 운영 중 | 접근권한·추가정보 분리·반출기록·변경 시 재평가 |

## Ⅵ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 정해진 변환기법이나 k 값만으로 모든 공개 환경의 익명성을 보장할 수 없음 | 이용 목적·수신자·결합 가능한 외부자료를 포함한 위험평가를 기준으로 처리수준과 공개범위 결정 |
