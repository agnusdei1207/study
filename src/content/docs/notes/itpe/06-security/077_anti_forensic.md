## 지식 로드맵 내 현재 위치

정보보안 → 디지털 포렌식 → 안티포렌식(Anti-Forensics) 및 증거 보존

## 30초 인출

- **본질:** 침해사고 조사 및 법적 소송 과정에서 디지털 증거(Digital Artifact)의 발견, 추출, 분석을 방해하고 증거 능력을 상실시키기 위해 공격자가 자행하는 증거 은닉·변조·파괴 기술
- **메커니즘:** 데이터 파괴(Wiping) → 데이터 은닉(Steganography/ADS) → 메타데이터 변조(Timestomp) → 분석 방해(Packing/Anti-debugging) → 포렌식 조사 무력화
- 통찰: 로컬 단말의 로그 삭제 및 타임스탬프 조작을 극복하기 위해 실시간 외부 원격 WORM 스토리지 로그 수집, 라이브 메모리 포렌식, 엔드포인트 EDR 이벤트 체인 교차 검증 결합 필수

<details><summary>핵심 용어</summary>

- **안티포렌식(Anti-Forensics):** 디지털 포렌식 도구와 수사관의 증거 수집 및 분석 활동을 의도적으로 방해, 지연, 차단하는 모든 기법.
- **와이핑(Data Wiping):** 복구 불가능하도록 데이터 저장 공간에 무의미한 난수나 제로(0) 패턴을 다회 덮어쓰기(DoD 5220.22-M 등)하는 기술.
- **타임스톰프(Timestomping):** 파일의 MACB(수정, 접근, 생성, MFT 변경) 시간 속성을 조작하여 타임라인 포렌식 분석을 교란하는 기법.
- **스테가노그래피(Steganography):** 이미지, 오디오, 동영상 등 일반 미디어 파일의 미세 비트(LSB) 공간에 기밀 데이터나 악성코드를 숨기는 기술.
- **ADS(Alternate Data Stream):** 윈도우 NTFS 파일 시스템에서 파일 이름 뒤에 숨겨진 추가 데이터 스트림을 생성하여 악성코드를 은닉하는 기술.

</details>

## 2~4교시 예상문제 (25점)

> 사이버 침해사고 현장에서 증거 확보를 방해하는 안티포렌식(Anti-Forensics)의 주요 기법(데이터 파괴, 은닉, 변조, 분석 방해)을 설명하고, 컴플라이언스 증적 시스템 구축 및 포렌식 조사관 관점의 대응 방안을 제시하시오. (기출·제133회 3교시 1번)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 디지털 범죄 및 해킹 공격자가 수사관의 포렌식 도구, 조사 절차, 증거 수집 활동을 방해하거나 수집된 디지털 증거의 법적 증거 능력(무결성, 진정성)을 훼손하기 위해 사용하는 일체의 기술 |
| 목적 | 침투 흔적 및 거점 은폐, 공격자 프로파일링(TTPs) 방해, 법정 제출 증거의 오염 및 증거 배제 유도 |

## Ⅱ. 안티포렌식의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 증거 능력 무력화 | 법정 증거의 필수 요건인 진정성, 무결성, 신뢰성을 훼손하여 증거 효력 상실 유도 | 메타데이터 변조, 해시 불일치 유발 |
| 공격 흔적의 능동적 은닉 | 침투 완료 후 이벤트 로그 삭제 및 흔적 없는 메모리 상 구동(Fileless) 공격 구사 | wevtutil, Reflective DLL Injection |
| 다층적 방해 기법 | 단순 파일 삭제뿐만 아니라 암호화, 패킹, 스테가노그래피, 가상머신 회피 복합 적용 | UPX 패킹, 안티 디버깅 |
| 정상 시스템 기능 악용 | OS의 정상 기능(NTFS ADS, 프리패치 비활성화, 볼륨 섀도 삭제)을 안티포렌식 도구로 전환 | vssadmin delete shadows |

## Ⅲ. 안티포렌식 4대 기술 분류 및 침해 은닉 아키텍처

```text
┌────────────────────────────────────────────────────────┐
│ [ 안티포렌식 4대 핵심 공격 영역 ]                      │
│                                                        │
│  ├─ 1. 데이터 파괴 (Data Destruction)                  │
│  │   - 파일 완전삭제(Wiping), 디가우징, 디스크 파쇄    │
│  │                                                     │
│  ├─ 2. 데이터 은닉 (Data Hiding)                       │
│  │   - 스테가노그래피, NTFS 대체 데이터 스트림(ADS)    │
│  │                                                     │
│  ├─ 3. 메타데이터 변조 (Artifact Modification)         │
│  │   - MFT 타임스톰프(Timestomping), 이벤트 로그 삭제 │
│  │                                                     │
│  └─ 4. 분석 방해 (Analysis Hindrance)                  │
│      - 코드 패킹, 난독화, 안티 디버깅, 가상머신 탐지   │
└────────────────────────┬───────────────────────────────┘
                         ▼
┌────────────────────────────────────────────────────────┐
│ [ 포렌식 수사관 및 컴플라이언스 대응 체계 ]            │
│  - 실시간 원격 WORM 감사 로그 수집 (SIEM 연계)         │
│  - 휘발성 메모리 포렌식 (Volatility, LiME)             │
│  - NTFS 저널($LogFile, $UsnJrnl) 타임라인 교차 복원   │
└────────────────────────────────────────────────────────┘
```

| 분류 | 주요 공격 기법 | 동작 메커니즘 | 포렌식 분석 영향 |
|---|---|---|---|
| 1. 데이터 파괴 | 디스크 와이핑 (Wiping), 제로필, 물리적 파쇄 | 잔여 자기 정보를 없애기 위해 0 또는 난수로 덮어쓰기 | 비할당 영역 카빙 복구 원천 불가 |
| 2. 데이터 은닉 | 스테가노그래피, NTFS ADS, 슬랙(Slack) 공간 은닉 | 이미지 LSB 변조, 파일명 뒤 `:hidden` 스트림 부착 | 디렉터리 브라우징 및 일반 백신 탐지 회피 |
| 3. 흔적 변조 | Timestomping, 윈도우 로그 삭제(wevtutil cl) | 파일의 생성/수정/접근 일시를 과거 정상 시점으로 조작 | 타임라인 침해 연대기 분석 교란 |
| 4. 분석 방해 | 코드 난독화, UPX 패킹, 안티 VM, 골리앗 안티 디버깅 | 디버거 감지 시 자가 종료(IsDebuggerPresent), 가상환경 회피 | 정적 역공학 및 동적 샌드박스 분석 지연 |

## Ⅳ. 안티포렌식 공격 기법 vs 포렌식 대응 기법 비교

| 안티포렌식 기법 | 공격자 행위 | 포렌식 조사관 대응 기법 | 증거 복원 원리 |
|---|---|---|---|
| **타임스톰핑 (Timestomp)** | `$STANDARD_INFORMATION`의 MACB 시간을 조작 | `$FILE_NAME` 속성 및 `$UsnJrnl` 교차 검증 | NTFS는 두 개의 시간 속성을 가지므로 불일치 탐지 |
| **이벤트 로그 삭제** | `wevtutil cl System`으로 로컬 이벤트 로그 삭제 | 외부 SIEM 원격 로그 및 메모리 내 잔존 아티팩트 분석 | 삭제 행위 자체(이벤트 ID 1102: 감사로그 삭제) 추적 |
| **파일 완전 와이핑** | SDelete 도구로 디스크 섹터 덮어쓰기 수행 | 볼륨 섀도 복사본(VSS) 및 메모리 캐시 덤프 분석 | 삭제 직전 VSS 스냅샷 또는 RAM 내 잔존 평문 복구 |
| **NTFS ADS 은닉** | `malware.exe > normal.txt:mal.exe` 스트림 은닉 | Sysinternals `streams` 도구 및 MFT 레코드 전수 파싱 | MFT 엔트리 내 `$DATA` 속성이 2개 이상인 레코드 추출 |

## Ⅴ. 안티포렌식 대응의 한계와 방안

| 한계 | 방안 |
|---|---|
| 로컬 시스템의 이벤트 로그 삭제 및 타임스탬프 조작 시 단일 단말 분석만으로는 사건의 전후 인과관계 시간선(Timeline) 입증 불가 | 로그 발생 즉시 로컬 단말 외부의 원격 불변(WORM) 스토리지로 전송하는 중앙 집중 SIEM 파이프라인 구축 및 NTFS 저널($LogFile, $UsnJrnl) 교차 분석 |
| 디스크 와이핑(DoD 덮어쓰기) 및 볼륨 섀도 복사본 삭제 시 기존 시그니처 기반 파일 카빙(File Carving) 기술로 데이터 복구 불가능 | 전원이 켜진 상태에서 휘발성 RAM 메모리 라이브 덤프를 우선 채취(Volatility 분석)하여 프로세스 메모리에 상주하는 복호화 키 및 잔존 아티팩트 추출 |
| 악성코드가 가상머신(VMware, VirtualBox) 환경을 탐지하고 자가 소멸하거나 정상 동작으로 위장하여 동적 악성코드 분석 실패 | 커널 레벨의 베어메탈(Bare-metal) 샌드박스를 구축하고, 하이퍼바이저 아티팩트를 은닉하는 맞춤형 분석 환경(Anti-Anti-VM) 도입 |

## Ⅵ. 제언

```text
[ 단말 로컬 증거 의존의 한계 ]       [ 실시간 연속 증적 컴플라이언스 체계 ]
단말 로그 삭제에 무력화 ─┐           ┌── 실시간 원격 WORM 로그 전송 (위변조 차단)
와이핑 시 영구 증거 상실 ┼─→ [ 수사 단절 ] ┼── 라이브 메모리 포렌식 우선 확보
단일 소스 타임라인 오류 ─┘           └── MFT, 저널, EDR 다차원 교차 검증
```

| 평가 영역 | 과거 단말 사후 포렌식 | 컴플라이언스 실시간 포렌식 | 향후 발전 방향 |
|---|---|---|---|
| 증거 수집 시점 | 사고 발생 수주 후 단말 확보 | 사고 발생 즉시 메모리/로그 동결 | 클라우드 스냅샷 기반 자동 포렌식 |
| 위변조 대응력 | 안티포렌식 조작에 취약 | 불변 증적(WORM) 보관으로 안전 | 블록체인 기반 증거 무결성(Hash) 공표 |
| 수사 효율성 | 디스크 카빙 수동 분석 | EDR/XDR 기반 프로세스 트리 추적 | AI 기반 공격자 TTPs 및 타임라인 자동 재구성 |

안티포렌식 기술은 날로 고도화되어 단순한 파일 삭제를 넘어 시스템 시간선 자체를 왜곡하므로, 단말 증거에만 의존하지 않고 실시간 원격 증적 관리와 메모리 포렌식을 결합한 입체적 증거 보존 체계 구축이 필수적 과제.
