- **본질:** 안티포렌식은 디지털 조사에서 자료를 찾고 신뢰성 있게 해석하는 일을 방해하는 행위다.
- **메커니즘:** 데이터·메타데이터를 숨기거나 지우고 바꾸며, 분석·기록 경로를 훼손해 증거 확보와 사건 재구성을 어렵게 한다.

- **컴플라이언스 증적 시스템**: 조직의 정책·감사 요건에 따라 활동기록을 수집·보호·검토하는 체계다.

## 1교시 10점 답안

### 1. 정의·목적

정의: **안티포렌식**은 디지털 증거를 숨기거나 훼손해 조사와 해석을 어렵게 하는 행위다.
목적: 행위의 흔적과 시간관계, 데이터의 신뢰성을 약화시켜 조사 지연이나 책임 회피를 노린다.

### 2. 유형과 대응

| 유형 | 예 | 대응 |
|---|---|---|
| 은닉 | 숨김 영역·파일 내 정보 삽입 | 원시 데이터와 연관 아티팩트 조사 |
| 삭제·파괴 | 와이핑, 로그 제거 | 독립된 원격 기록과 백업 확인 |
| 변조 | 시간정보·기록 변경 | 여러 출처의 시간·행위 교차검증 |
| 분석 방해 | 암호화·도구 방해 | 원본 보존, 격리 분석, 한계 기록 |

제안: 단말 로컬 로그 외에 중요 감사기록을 별도 보호영역으로 전달해 사고 전 자료를 보존한다.

## 2~4교시 25점 답안

### Ⅰ. 개요

정의: **안티포렌식**은 디지털 조사에 필요한 자료의 발견·보존·분석을 어렵게 하는 기법과 행위다.
목적: 흔적과 증거의 신뢰성을 훼손해 사건 규명과 책임 추적을 방해한다.

| 조사 취약점 | 안티포렌식 영향 |
|---|---|
| 단말 내부에만 기록 보존 | 로컬 기록 삭제·변조 시 시간선 단절 |
| 원본 상태·취급 이력 불명확 | 증거의 무결성·해석 근거 논란 |
| 한 종류의 흔적에 의존 | 은닉·메타데이터 변경으로 분석 누락 가능 |

### Ⅱ. 주요 기법

| 기법 | 조사에 미치는 영향 |
|---|---|
| 은닉 | 데이터 위치·존재 확인을 어렵게 함 |
| 삭제·와이핑 | 잔존 데이터의 복구 가능성을 낮춤 |
| 메타데이터·로그 변조 | 행위 순서·시점 판단을 흐림 |
| 암호화·도구 방해 | 분석 대상 접근과 도구 실행을 어렵게 함 |

이 기법의 흔적만으로 범죄 의도나 특정 사용자를 확정하지 않는다. 시스템 정상 동작·관리 행위 가능성을 배제하고 다른 증거와 함께 판단한다.

### Ⅲ. 컴플라이언스 증적 시스템 구축

```mermaid
flowchart LR
  A[감사 목적·기록 대상 선정] --> B[기록 생성·수집 지점 설계]
  B --> C[전송·접근·보존 통제 적용]
  C --> D[경보·조회·조사 절차 시험]
  D --> E[운영 결과에 따라 개선]
```

시스템은 수집 대상·책임자·접근권한·보존기준·검토 역할을 조직의 요건에 맞춰 정한다. 원격 보관이나 변경방지 통제는 유용할 수 있지만, 제품·보관방식이 모든 기록의 삭제·변조를 완전히 막는다고 단정하지 않는다.

### Ⅳ. 증적 활용과 조사

| 단계 | 활용 |
|---|---|
| 경보·사고 인지 | 이상 로그 삭제·설정변경·도구 실행 징후 탐색 |
| 보존 | 원본 자료와 기록을 식별하고 취급 이력 유지 |
| 분석 | 원격 로그·단말·네트워크·백업 등 독립 출처 대조 |
| 보고 | 직접 관찰 사실, 해석, 신뢰도와 한계 구분 |

NIST의 포렌식 지침은 자료 수집·검사·분석·보고를 연결한다. 로그관리 지침은 기록의 생성, 전송, 저장, 분석, 폐기 절차를 조직적으로 운영하도록 안내한다.

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 중요 기록을 모두 수집하려 하면 비용·개인정보 부담이 커지고, 아무 우선순위 없이 수집하면 핵심 사건 흐름이 빠질 수 있다. | 우선 침해 영향이 큰 인증·권한변경·관리자 명령·중요 데이터 접근 기록을 선정하고, 해당 기록의 단말 외 보관·검색 가능성을 모의 사고로 검증한 뒤 수집 범위를 넓힌다. |
