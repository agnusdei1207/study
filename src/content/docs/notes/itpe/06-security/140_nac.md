## 답안 골격
```text
[네트워크 접근 제어(NAC, Network Access Control)] ◀━━ 머리: Ⅶ 내 의견 (단순 IP/MAC 차단 한계 극복 → 802.1X 기반 단말 무결성 검증과 제로트러스트 지속 격리 체계 구축)
 ┃
 ┣━ Ⅰ 개요 ───── 내부 네트워크에 접속을 시도하는 모든 엔드포인트 단말(PC, 모바일, IoT)에 대해 사용자 신원 인증과 단말 보안 상태(백신 설치, 패치 여부)를 검증하여 비인가 단말을 사전에 차단·격리하는 네트워크 보안 통제 기술
 ┣━ Ⅱ 특징 ───── 접속 전 검증(Pre-admission)과 접속 중 지속 모니터링(Post-admission) · 단말 무결성 검증(Posture Assessment) · 검역소(Quarantine) 격리 및 자동 치료 유도
 ┣━ Ⅲ 구조 ───── 단말(Supplicant) + 스위치/AP(Authenticator) + 인증·정책 서버 + 선택적 단말 상태 평가 + 격리·복구 네트워크
 ┣━ Ⅳ 흐름 ───── 접속 시도 → 802.1X/EAP 인증과 정책 평가 → 허용·제한·격리 → 연결 중 상태 변경 시 재평가. 단말 무결성 검사는 NAC 구현별 선택 기능
 ┣━ Ⅴ 비교 ───── 방화벽(패킷 L3/L4 헤더 필터링) vs NAC(단말의 기기 속성, 보안 소프트웨어 설치 여부, 접속 자격 기반 엔드포인트 접근 통제)
 ┗━ Ⅵ 실무 ───── 에이전트 설치 거부 단말(BYOD, 프린터 등 IoT) 관리 난제 / ARP 스푸핑 차단 방식의 네트워크 브로드캐스트 부하 / 우회 접속(IP 변조)
```
- 필수 키워드: NAC · 단말 무결성 검증(Posture Assessment) · 802.1X · 검역망(Quarantine VLAN) · 정책 서버 · 에이전트리스(Agentless) · ARP 스푸핑 통제
- 출제 이력: 제124회 문항은 공식 Q-Net 원문 미수집으로 미확인. 아래 문항은 예상문제

## 한 줄 본질
- 사내 랜선에 임의의 미인증 노트북이나 바이러스 감염 PC를 꽂으면 내부망 전체로 악성코드가 번지는 무방비 노출 병목 → 단말의 신원과 백신·OS 패치 상태를 검증해 합격한 단말만 업무망을 열어주고 미달 단말은 검역소로 격리 → 안전한 내부망 클린존 확보 / 단말 에이전트 관리 및 IoT 예외 처리 공수 발생

## 핵심 용어
- 단말 무결성 검증 (Posture Assessment): 단말기가 네트워크에 접속하기 직전, 최신 OS 보안 패치가 적용되어 있는지, 정품 백신이 실시간 감시 중인지, 불법 P2P 프로그램이 구동 중인지 검사하는 헬스체크
- 검역 네트워크 (Quarantine VLAN): 보안 기준에 미달한 단말기를 사내 업무망으로부터 물리적·논리적으로 완전히 분리된 가상 랜으로 격리하여, 오직 백신 업데이트 서버나 OS 패치 서버에만 접근할 수 있도록 제한하는 보호 구역

## 핵심 통찰
- NAC은 내부 유·무선 접속 지점의 사용자·단말을 정책에 따라 인증·분리. 방화벽과 함께 적용할 때 접속 초기와 연결 이후 위험을 다르게 통제
- 구현은 802.1X·캡티브 포털·MAC 인증 등으로 나뉘며 기능·우회 가능성·운영 비용을 비교해야 함
- IEEE 802.1X는 포트 기반 인증·인가를 제공하지만 물리 포트의 전원 개폐나 모든 단말 취약점 제거를 뜻하지 않음. 단말 상태 평가는 별도 기능

## 이웃 토픽과 구분
- NAC vs MDM(모바일 기기 관리): NAC = 네트워크 레벨에서 유무선 접속을 차단·허용 / MDM = 단말기 OS 레벨에서 카메라 잠금, 업무용 앱 배포, 분실 시 원격 공장초기화를 수행

## 문제·원인·대책
- 가상 사례: 미등록 노트북이 회의실 유선 포트에 연결을 시도한 상황
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미등록 단말의 내부망 접속 | 포트 단위 인증·인가 정책 부재 | IEEE 802.1X 인증과 제한 네트워크 정책 적용 | 인증 전 업무 자원 접근 제한·우회 경로 점검 |
| 에이전트 설치가 불가능한 네트워크 프린터/CCTV의 접속 장애 | 모든 기기에 에이전트 설치를 강제하는 경직된 운영 | Agentless 방식(SNMP, DHCP 핑거프린팅)의 기기 자동 분류 및 화이트리스트 적용 | 에이전트 미탑재 IoT 기기의 식별 및 전용 격리망 배치 |

## 1교시 예상문제 (10점)
- NAC의 개념과 802.1X 기반 접속 제어 구성을 설명하시오.

## 1교시 10점 답안
- **정의:** 네트워크 접속 주체의 인증·단말 상태·정책에 따라 내부 자원 접근을 허용·제한·격리하는 통제.
- **구성:** 단말(Supplicant), 스위치/AP(Authenticator), 인증·정책 서버, 선택적 상태 평가·검역망.
- **절차:** 접속 시도 → EAP 인증·정책 결정 → 업무망 또는 제한망 할당 → 상태 변화 재평가.

## 2~4교시 예상문제 (25점)
- NAC의 구성과 접속 전·후 정책 집행, 미관리 단말 운영 방안을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 목적
- 연결 지점에서 미등록·위험 단말의 업무 자원 접근을 통제하고 위반 단말에 복구 경로 제공.
### Ⅱ. 구조
- Supplicant의 인증 요청, Authenticator의 포트 제어, 인증 서버의 자격·정책 확인, 선택적 상태 평가와 VLAN/ACL 집행.
### Ⅲ. 정책 흐름
- 사전 인증·평가 → 정상/제한/격리 부여 → 연결 중 상태 변경·이상 신호에 따른 재평가. 802.1X 자체와 백신 점검 기능을 구분.
### Ⅳ. 예외·검증
- 프린터·IoT의 식별·전용망·접근 범위 지정, 스위치 장애·우회·게스트 접근 시험, 운영 지표와 사용자 영향 측정.
