## 답안 골격
```text
[네트워크 접근 제어(NAC, Network Access Control)] ◀━━ 머리: Ⅶ 내 의견 (단순 IP/MAC 차단 한계 극복 → 802.1X 기반 단말 무결성 검증과 제로트러스트 지속 격리 체계 구축)
 ┃
 ┣━ Ⅰ 개요 ───── 내부 네트워크에 접속을 시도하는 모든 엔드포인트 단말(PC, 모바일, IoT)에 대해 사용자 신원 인증과 단말 보안 상태(백신 설치, 패치 여부)를 검증하여 비인가 단말을 사전에 차단·격리하는 네트워크 보안 통제 기술
 ┣━ Ⅱ 특징 ───── 접속 전 검증(Pre-admission)과 접속 중 지속 모니터링(Post-admission) · 단말 무결성 검증(Posture Assessment) · 검역소(Quarantine) 격리 및 자동 치료 유도
 ┣━ Ⅲ 구조 ───── 정책 서버(Policy Server) + 정책 시행 센서(Sensor/Enforcer, ARP/802.1X) + 단말 에이전트(Agent/Agentless) + 검역 네트워크(Quarantine VLAN)
 ┣━ Ⅳ 흐름 ───── 단말 네트워크 연결(DHCP 요청) → 사용자 신원 인증 → 단말 무결성 점검(백신 최신화 확인) → [통과 시 업무망 VLAN 할당] / [미달 시 격리망으로 이동 및 패치 유도]
 ┣━ Ⅴ 비교 ───── 방화벽(패킷 L3/L4 헤더 필터링) vs NAC(단말의 기기 속성, 보안 소프트웨어 설치 여부, 접속 자격 기반 엔드포인트 접근 통제)
 ┗━ Ⅵ 실무 ───── 에이전트 설치 거부 단말(BYOD, 프린터 등 IoT) 관리 난제 / ARP 스푸핑 차단 방식의 네트워크 브로드캐스트 부하 / 우회 접속(IP 변조)
```

## 한 줄 본질
- 사내 랜선에 임의의 미인증 노트북이나 바이러스 감염 PC를 꽂으면 내부망 전체로 악성코드가 번지는 무방비 노출 병목 → 단말의 신원과 백신·OS 패치 상태를 검증해 합격한 단말만 업무망을 열어주고 미달 단말은 검역소로 격리 → 안전한 내부망 클린존 확보 / 단말 에이전트 관리 및 IoT 예외 처리 공수 발생

## 핵심 용어
- 단말 무결성 검증 (Posture Assessment): 단말기가 네트워크에 접속하기 직전, 최신 OS 보안 패치가 적용되어 있는지, 정품 백신이 실시간 감시 중인지, 불법 P2P 프로그램이 구동 중인지 검사하는 헬스체크
- 검역 네트워크 (Quarantine VLAN): 보안 기준에 미달한 단말기를 사내 업무망으로부터 물리적·논리적으로 완전히 분리된 가상 랜으로 격리하여, 오직 백신 업데이트 서버나 OS 패치 서버에만 접근할 수 있도록 제한하는 보호 구역

## 핵심 통찰
- 방화벽은 "외부에서 들어오는 적"을 막지만, NAC은 "내부에서 선을 꽂는 아군과 방문자"를 감시함 → 사내 침해 사고의 70%가 직원이 집에서 쓰던 감염된 노트북을 회사 랜선에 꽂는 순간 발생함
- 국내 NAC은 스위치 교체 비용을 아끼기 위해 'ARP 스푸핑' 방식을 많이 썼으나, 이는 네트워크에 브로드캐스트 부하를 주고 스위치 장애를 유발하는 기술적 부채가 됨
- 글로벌 표준이자 정답은 'IEEE 802.1X' 포트 기반 제어임 → 스위치 포트 자체가 잠겨 있다가 EAP 인증을 통과해야만 포트가 물리적으로 열리므로 네트워크 오염을 사전에 원천 차단함

## 이웃 토픽과 구분
- NAC vs MDM(모바일 기기 관리): NAC = 네트워크 레벨에서 유무선 접속을 차단·허용 / MDM = 단말기 OS 레벨에서 카메라 잠금, 업무용 앱 배포, 분실 시 원격 공장초기화를 수행

## 문제·원인·대책
- 사례: 외주 협력사 직원이 개인 노트북을 빈 회의실 LAN 포트에 무단 연결하여 사내 파일서버에 침투한 사건
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미등록 비인가 단말의 사내 유선 LAN 포트 무단 접속 | 포트 단위의 인증 제어 부재 및 고정 IP 무단 설정 | IEEE 802.1X 기반 포트 인증 및 미인증 단말 기본 차단 | 미등록 MAC 및 미인증 단말의 패킷 전송 100% 차단 |
| 에이전트 설치가 불가능한 네트워크 프린터/CCTV의 접속 장애 | 모든 기기에 에이전트 설치를 강제하는 경직된 운영 | Agentless 방식(SNMP, DHCP 핑거프린팅)의 기기 자동 분류 및 화이트리스트 적용 | 에이전트 미탑재 IoT 기기의 식별 및 전용 격리망 배치 |

## 내 의견
- [제로트러스트 아키텍처(ZTNA)와 연계한 동적 NAC 고도화] 네트워크에 한 번 들어오면 검사가 끝나는 고전적 NAC은 이후 단말기가 악성코드에 감염되어 측면 이동을 시작해도 막지 못함 → 나라면: NAC을 EDR 및 ZTNA 게이트웨이와 실시간 API로 연동하여, 평소에 접속해 있던 단말이라도 EDR에서 이상 랜섬웨어 행위가 감지되는 즉시 스위치에 명령을 내려 해당 포트를 1초 내에 동적으로 격리(Disconnect)하는 능동적 연동 방어선 구축
