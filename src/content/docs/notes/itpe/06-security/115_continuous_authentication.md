## Ⅰ. 무자각 지속인증과 세션 모니터링의 개요

- 개념 : 최초 로그인 성공 이후에도 세션이 유지되는 동안 사용자의 행동 패턴(타이핑, 마우스, 터치)과 단말·네트워크 상태를 실시간 수집하여 본인 일치 여부를 무자각으로 지속 평가하는 인증 체계.
- 배경 및 필요성 : 최초 1회 로그인 후 세션이 유지되는 동안 발생하는 세션 하이재킹과 대리 사용 위협을 방지하기 위해, 사용자의 키스트로크, 마우스 움직임 등 무의식적 행동 생체 특징을 배경에서 지속적으로 분석·검증하기 위해 개발됨.
- 핵심 목적 : 로그인 직후 발생하는 세션 하이재킹, 토큰 탈취, 단말기 무단 사용(어깨너머 훔쳐보기 후 조작)을 실시간 탐지하여 내부 침해 및 계정 도용 원천 차단.

## Ⅱ. 무자각 지속인증과 세션 모니터링의 핵심 아키텍처 및 동작 메커니즘

무자각 지속인증과 세션 모니터링은(는) 신뢰할 수 있는 보안 구조와 표준화된 절차를 기반으로 동작하며, 세부적인 아키텍처와 구성요소 간의 상호작용 메커니즘은 다음과 같음.

```text
[ 사용자 단말 (Client Device) ]
  ├── 1. 행동 텔레메트리 수집: 키 입력 리듬, 마우스 가속도, 스마트폰 자이로스코프
  └── 2. 환경 텔레메트리 수집: 단말 무결성, 네트워크 Wi-Fi BSSID, 앱 포그라운드 상태
         │
         ▼ (암호화 스트리밍 전송: TLS 1.3 mTLS)
+---------------------------------------------------------------------------------+
| 지속인증 AI 분석 엔진 (Continuous Risk & Trust Engine)                         |
|  ├── [특징 추출]: 키 간격 시간(Flight Time), 누름 시간(Dwell Time), 궤적 곡률   |
|  ├── [프로파일 대조]: 사용자별 정상 행동 기준선(Baseline ML 모델)과 실시간 대조 |
|  └── [신뢰 점수 산출]: 다차원 위험 스코어링 (Trust Score: 0 ~ 100)              |
+---------------------------------------------------------------------------------+
         │
         ▼ (신뢰 점수 기반 동적 정책 집행)
       ┌─────────────────────┼─────────────────────┐
       ▼ [80 ~ 100점: 정상]  ▼ [50 ~ 79점: 의심]   ▼ [0 ~ 49점: 고위험]
  세션 유지 및 무자각 작업    Step-Up 인증 요구     세션 즉시 강제 종료 (Kill)
                             (FIDO2 패스키/지문)   + 보안관제(SOC) 긴급 경보
```

- **키스트로크 역학 (Keystroke)** : 키 누름 시간(Dwell Time), 키 간격 이동 시간(Flight Time), 오타율 (순환신경망(LSTM), 오토인코더 기반 시계열 이상 탐지).
- **마우스/터치 역학 (Pointer)** : 마우스 이동 궤적 곡률, 가속도, 드래그 속도, 화면 터치 면적 및 압력 (CNN 기반 이미지 패턴 매핑, 이상 궤적 분류).
- **디바이스 물리 센서** : 스마트폰 파지 각도, 보행 패턴(걸음걸이), 자이로스코프 진동 데이터 (랜덤 포레스트(Random Forest), 모션 프로파일 매칭).
- **네트워크 및 환경** : IP 지리적 위치(Geo-IP), VPN 사용 여부, 세션 요청 주기 빈도 (비정상 접근 탐지 룰셋, 네트워크 텔레메트리 상관분석).
- **단말 보안 태세** : OS 패치 버전, EDR 프로세스 감시 상태, 탈옥/루팅 탐지 여부 (Zero Trust 단말 컴플라이언스(Device Posture) 검증).

## Ⅲ. 무자각 지속인증과 세션 모니터링의 세부 구성 요소 및 비교 분석

| 비교 항목 | 1회성 정적 인증 (Static Auth) | 주기적 재인증 (Periodic Re-auth) | 무자각 지속인증 (Continuous Auth) |
|---|---|---|---|
| 인증 시점 | 로그인 시점 단 1회 | 일정 시간 경과 시 | 세션 활성화 전 기간 (실시간 연속) |
| 사용자 개입 | ID/PW, OTP 수작업 입력 필수 | 주기마다 팝업 창에 패스워드 재입력 | 사용자 개입 전혀 없음 (무자각) |
| 사용자 피로도 | 보통 | 매우 높음 (업무 흐름 단절 발생) | 최저 (Zero Friction) |
| 세션 탈취 방어 | 취약 (로그인 후 세션 쿠키 탈취 시 무방비) | 부분 방어 (최대 주기 시간만큼 노출) | 완벽 방어 (사용자 교체 즉시 감지 차단) |
| 인증 데이터 | 고정된 문자열, 일회용 난수 | 고정된 문자열, 생체 지문 | 동적 행동 생체 패턴 및 환경 컨텍스트 |

- 무자각 지속인증과 세션 모니터링은(는) 상기 핵심 비교 지표와 아키텍처 구성을 바탕으로 보안 위협에 대한 방어 효과성을 극대화하며, 기존 레거시 통제 기법 대비 우수한 신뢰성과 운영 효율성을 제공함.

## Ⅳ. 무자각 지속인증과 세션 모니터링의 주요 한계점 및 해결 방안

- 한계점 : 사용자가 손목을 다치거나 서서 작업하는 등 물리적 상태 변화 시 일시적으로 **오거부율** (FRR)이 급증하여 업무 차단 유발.
  - 해결 방안 : 단일 지표 신뢰도 하락 시 즉시 세션을 차단하지 않고, 신뢰 점수 가중치를 단말 무결성/IP 위치로 동적 재분배하며 FIDO2 Step-Up 인증 제공.
- 한계점 : 임직원의 모든 키보드 입력과 마우스 조작을 실시간 감시함에 따른 개인정보보호법상 감시 피로 및 프라이버시 침해 논란.
  - 해결 방안 : 입력된 텍스트 내용(Content)은 일절 저장하지 않고 오직 키 간의 '시간 간격(Timing Delta)' 수치 데이터만 로컬에서 암호화 추출 후 폐기.
- 한계점 : 고빈도 센싱 데이터의 실시간 서버 전송으로 인한 단말 배터리 소모 및 네트워크 트래픽 과부하.
  - 해결 방안 : 단말기 내부 **신경망 처리 장치** (NPU)를 활용하여 **온디바이스** (On-Device Edge AI)로 1차 신뢰 점수를 계산하고 이상 시에만 서버 통보.
- 한계점 : 공격자가 원격 제어 도구를 통해 사람처럼 보이는 마우스 곡선과 무작위 딜레이를 주입하는 봇(Bot) 기반 위장 공격.
  - 해결 방안 : 휴먼 인터랙션 고유의 **미세 손떨림** (Micro-tremor) 및 비선형 가속도 성분을 **푸리에 변환** (FFT) 주파수 영역에서 분석하여 기계적 패턴 식별.

## Ⅴ. 무자각 지속인증과 세션 모니터링 적용 및 발전을 위한 기술사적 제언

- 단말 런타임 최적화 중심의 거버넌스 및 실행 체계 구축 : 모바일/PC NPU를 활용한 경량화 경계 기반 행동 생체 추론 모델(SLM) 내재화을(를) 적극 추진하여, 단말 배터리 소모 및 네트워크 지연 최소화 효과를 극대화해야 함.
- 정책 엔진 연동 중심의 거버넌스 및 실행 체계 구축 : ZTNA 게이트웨이 및 IAM 서버와 연동하여 실시간 세션 권한 축소/차단 자동화을(를) 적극 추진하여, 세션 하이재킹 피해를 침해 발생 즉시 무력화 효과를 극대화해야 함.
- 데이터 윤리 및 거버넌스 중심의 거버넌스 및 실행 체계 구축 : '**개인정보 보호 중심 설계** (Privacy by Design)' 원칙에 따라 생체 특징점 비가역 해시화을(를) 적극 추진하여, 노사 합의 기반의 안전하고 합법적인 지능형 보안 환경 정착 효과를 극대화해야 함.
