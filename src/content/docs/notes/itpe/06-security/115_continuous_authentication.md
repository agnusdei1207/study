## 지식 로드맵 내 현재 위치

신원 및 접근 제어(IAM) → 적응형 인증(Adaptive Auth) → 무자각 지속인증과 세션 모니터링

## 30초 인출

- **본질:** 초기 로그인 시점의 1회성 정적 인증 한계를 극복하고, 사용자의 세션 전 수명주기 동안 행동 생체(키스트로크, 터치, 마우스)와 환경 컨텍스트를 백그라운드에서 사용자 개입 없이 지속 검증하는 제로트러스트 인증 기술.
- **메커니즘:** 클라이언트 단말에서 행동 텔레메트리 무자각 수집 → 머신러닝 엔진이 신뢰 점수(Trust Score) 실시간 산출 → 이상 감지 시 단계적 추가 인증(Step-Up Auth) 또는 세션 강제 차단.
- 통찰: 로그인 후 세션 하이재킹 및 단말 탈취 위협을 원천 차단할 수 있으나, 행동 변화에 따른 오거부율(FRR) 완화와 프라이버시 보호를 위한 온디바이스(Edge AI) 모델링 필수.

<details><summary>핵심 용어</summary>

- **무자각 지속인증(Continuous Adaptive Authentication)**: 사용자가 별도의 인증 행위를 인지하지 못하는 상태에서 백그라운드 센싱 데이터를 통해 본인 여부를 지속 확인하는 기술.
- **행동 생체인식(Behavioral Biometrics)**: 키보드 입력 속도/리듬(Keystroke Dynamics), 마우스 이동 궤적, 스마트폰 터치 압력/각도 등 개인의 무의식적 행동 습관을 분석하는 기술.
- **신뢰 점수(Trust Score)**: 사용자의 현재 행동과 과거 정상 기준선(Baseline)의 유사도를 0~100점으로 실시간 수치화한 지표.
- **스텝업 인증(Step-Up Authentication)**: 신뢰 점수가 임계치 이하로 하락하거나 고위험 트랜잭션(거액 송금 등) 발생 시 추가적인 생체/MFA 인증을 요구하는 절차.
- **CARTA(Continuous Adaptive Risk and Trust Assessment)**: 가트너가 제시한 모델로, 1회성 인증을 지양하고 세션 전주기에서 위험과 신뢰를 연속적으로 적응 평가하는 프레임워크.
</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 최초 로그인 성공 이후에도 세션이 유지되는 동안 사용자의 행동 패턴(타이핑, 마우스, 터치)과 단말·네트워크 상태를 실시간 수집하여 본인 일치 여부를 무자각으로 지속 평가하는 인증 체계 |
| 목적 | 로그인 직후 발생하는 세션 하이재킹, 토큰 탈취, 단말기 무단 사용(어깨너머 훔쳐보기 후 조작)을 실시간 탐지하여 내부 침해 및 계정 도용 원천 차단 |

## Ⅱ. 무자각 지속인증의 핵심 특징 및 신뢰 평가 메커니즘

| 특징 항목 | 세부 구현 내용 | 보안 및 사용자 경험 가치 |
|---|---|---|
| 무자각성 (Zero-Effort) | 패스워드 입력, OTP 확인 등 번거로운 인증 절차 없이 백그라운드에서 자동 수행 | 사용자의 업무 몰입 방해 없는 최상의 사용자 경험(UX) 제공 |
| 연속적 검증 (Continuous) | 로그인 시점 1회성 검증이 아닌 세션 종료 시까지 밀리초(ms) 단위로 상시 평가 | 인증 통과 직후 발생하는 세션 쿠키 탈취 및 중간자 공격 방어 |
| 다차원 컨텍스트 융합 | 행동 생체 정보뿐 아니라 IP 대역, 접속 시간대, 단말 보안 태세(EDR), 위치 정보 결합 | 단일 지표 오탐을 방지하는 다계층 심층 신뢰 분석(CARTA) |
| 위험 기반 적응형 통제 | 신뢰 점수에 따라 정상 유지, 세부 권한 축소, Step-Up 재인증, 즉각 차단 등 동적 집행 | 비정상 징후 발생 시 선제적 리스크 국소화 및 격리 |
| 복제 불가능성 | 지문이나 얼굴 등 정적 생체정보와 달리 신체적 행동 습관은 위조나 도용이 극히 난해 | 딥페이크 및 실리콘 지문 위조 등 물리적 생체 해킹 무력화 |

## Ⅲ. 무자각 지속인증 및 세션 모니터링 아키텍처

```text
[ 사용자 단말 (Client Device) ]
  ├── 1. 행동 텔레메트리 수집: 키 입력 리듬, 마우스 가속도, 스마트폰 자이로스코프
  └── 2. 환경 텔레메트리 수집: 단말 무결성, 네트워크 Wi-Fi BSSID, 앱 포그라운드 상태
         │
         ▼ (암호화 스트리밍 전송: TLS 1.3 mTLS)
+---------------------------------------------------------------------------------+
| 지속인증 AI 분석 엔진 (Continuous Risk & Trust Engine)                         |
|  ├── [특징 추출]: 키 간격 시간(Flight Time), 누름 시간(Dwell Time), 궤적 곡률   |
|  ├── [프로파일 대조]: 사용자별 정상 행동 기준선(Baseline ML 모델)과 실시간 대조 |
|  └── [신뢰 점수 산출]: 다차원 위험 스코어링 (Trust Score: 0 ~ 100)              |
+---------------------------------------------------------------------------------+
         │
         ▼ (신뢰 점수 기반 동적 정책 집행)
       ┌─────────────────────┼─────────────────────┐
       ▼ [80 ~ 100점: 정상]  ▼ [50 ~ 79점: 의심]   ▼ [0 ~ 49점: 고위험]
  세션 유지 및 무자각 작업    Step-Up 인증 요구     세션 즉시 강제 종료 (Kill)
                             (FIDO2 패스키/지문)   + 보안관제(SOC) 긴급 경보
```

| 수집 신호 범주 | 세부 수집 데이터 항목 | 분석 및 이상 탐지 기법 |
|---|---|---|
| 키스트로크 역학 (Keystroke) | 키 누름 시간(Dwell Time), 키 간격 이동 시간(Flight Time), 오타율 | 순환신경망(LSTM), 오토인코더 기반 시계열 이상 탐지 |
| 마우스/터치 역학 (Pointer) | 마우스 이동 궤적 곡률, 가속도, 드래그 속도, 화면 터치 면적 및 압력 | CNN 기반 이미지 패턴 매핑, 이상 궤적 분류 |
| 디바이스 물리 센서 | 스마트폰 파지 각도, 보행 패턴(걸음걸이), 자이로스코프 진동 데이터 | 랜덤 포레스트(Random Forest), 모션 프로파일 매칭 |
| 네트워크 및 환경 | IP 지리적 위치(Geo-IP), VPN 사용 여부, 세션 요청 주기 빈도 | 비정상 접근 탐지 룰셋, 네트워크 텔레메트리 상관분석 |
| 단말 보안 태세 | OS 패치 버전, EDR 프로세스 감시 상태, 탈옥/루팅 탐지 여부 | Zero Trust 단말 컴플라이언스(Device Posture) 검증 |

## Ⅳ. 1회성 정적 인증 vs 주기적 재인증 vs 무자각 지속인증 비교

| 비교 항목 | 1회성 정적 인증 (Static Auth) | 주기적 재인증 (Periodic Re-auth) | 무자각 지속인증 (Continuous Auth) |
|---|---|---|---|
| 인증 시점 | 로그인 시점 단 1회 | 일정 시간(예: 30분, 1시간) 경과 시 | 세션 활성화 전 기간 (실시간 연속) |
| 사용자 개입 | ID/PW, OTP 수작업 입력 필수 | 주기마다 팝업 창에 패스워드 재입력 | 사용자 개입 전혀 없음 (무자각) |
| 사용자 피로도 | 보통 | 매우 높음 (업무 흐름 단절 발생) | 최저 (Zero Friction) |
| 세션 탈취 방어 | 취약 (로그인 후 세션 쿠키 탈취 시 무방비) | 부분 방어 (최대 주기 시간만큼 노출) | 완벽 방어 (사용자 교체 즉시 감지 차단) |
| 인증 데이터 | 고정된 문자열, 일회용 난수 | 고정된 문자열, 생체 지문 | 동적 행동 생체 패턴 및 환경 컨텍스트 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 사용자가 손목을 다치거나 서서 작업하는 등 물리적 상태 변화 시 일시적으로 오거부율(FRR)이 급증하여 업무 차단 유발 | 단일 지표 신뢰도 하락 시 즉시 세션을 차단하지 않고, 신뢰 점수 가중치를 단말 무결성/IP 위치로 동적 재분배하며 FIDO2 Step-Up 인증 제공 |
| 임직원의 모든 키보드 입력과 마우스 조작을 실시간 감시함에 따른 개인정보보호법상 감시 피로 및 프라이버시 침해 논란 | 입력된 텍스트 내용(Content)은 일절 저장하지 않고 오직 키 간의 '시간 간격(Timing Delta)' 수치 데이터만 로컬에서 암호화 추출 후 폐기 |
| 고빈도 센싱 데이터의 실시간 서버 전송으로 인한 단말 배터리 소모 및 네트워크 트래픽 과부하 | 단말기 내부 신경망 처리 장치(NPU)를 활용하여 온디바이스(On-Device Edge AI)로 1차 신뢰 점수를 계산하고 이상 시에만 서버 통보 |
| 공격자가 원격 제어 도구를 통해 사람처럼 보이는 마우스 곡선과 무작위 딜레이를 주입하는 봇(Bot) 기반 위장 공격 | 휴먼 인터랙션 고유의 미세 손떨림(Micro-tremor) 및 비선형 가속도 성분을 푸리에 변환(FFT) 주파수 영역에서 분석하여 기계적 패턴 식별 |

## Ⅵ. 제언

```text
[ 제로트러스트 무자각 지속인증 구축 3대 로드맵 ]

+-------------------------+      +-------------------------+      +-------------------------+
|     1. 온디바이스 AI    | ---> |     2. 적응형 CARTA 정책| ---> |     3. 프라이버시 보증  |
| (NPU 기반 로컬 추론)    |      | (Step-Up 동적 인가 연계)|      | (키 입력 내용 비저장 원칙
+-------------------------+      +-------------------------+      +-------------------------+
```

| 발전 영역 | 핵심 엔지니어링 구현 과제 | 비즈니스 가치 |
|---|---|---|
| 단말 런타임 최적화 | 모바일/PC NPU를 활용한 경량화 경계 기반 행동 생체 추론 모델(SLM) 내재화 | 단말 배터리 소모 0.1% 미만 및 네트워크 지연 제로화 |
| 정책 엔진 연동 | ZTNA 게이트웨이 및 IAM 서버와 연동하여 실시간 세션 권한 축소/차단 자동화 | 세션 하이재킹 피해를 침해 발생 5초 이내에 100% 무력화 |
| 데이터 윤리 및 거버넌스 | '개인정보 보호 중심 설계(Privacy by Design)' 원칙에 따라 생체 특징점 비가역 해시화 | 노사 합의 기반의 안전하고 합법적인 지능형 보안 환경 정착 |
