## 지식 로드맵 내 현재 위치

지식 위치: 접근 제어 → 세션 중 위험 평가 → **지속인증**

## 30초 인출

- 본질: 로그인 뒤에도 사용 패턴·단말·위치·행동 생체 특성 등 세션 신호를 평가해 탈취·부정사용 가능성을 찾는 방식
- NIST SP 800-63B의 Session Monitoring은 세션 중 부정행위 탐지 목적의 선택적 위험 완화 수단. 정해진 재인증 요구를 대체하지 않음
- 행동 생체의 오탐·프라이버시와 데이터 보존 위험을 함께 평가

## 1교시 예상문제 (10점)

> 지속인증의 개념과 세션 신호·위험 대응 방식을 설명하시오. (예상·10점)

## 1교시 10점 답안

### Ⅰ. 개념

세션 유지 중 행동·기기·위치 등의 신호를 관찰하고 위험을 평가해 필요할 때 추가 인증·세션 종료·조사를 수행하는 방식.

### Ⅱ. 신호와 조치

| 신호 | 예 | 조치 |
|---|---|---|
| 행동 | 타이핑 리듬·사용 속도 | 신뢰도 변화 분석 |
| 단말 | 브라우저·기기 상태 | 재확인 |
| 네트워크 | IP·위치 급변 | 위험 기반 추가 인증 |

3초 이내 자동 탐지 같은 성능 보장은 없음. 임계값·오탐률·업무 영향 검증 필요.

## 2~4교시 예상문제 (25점)

> 무자각 지속인증의 구조와 세션 모니터링·주기적 재인증의 차이, 개인정보 보호 및 오탐 대응 방안을 설명하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 필요성

초기 로그인 성공 후 세션 쿠키·단말이 탈취되거나 사용자가 교체될 위험. 단일 로그인 시점의 판단을 세션 전 기간에 그대로 적용하기 어려움.

### Ⅱ. 구조

```text
인증 완료 → 세션 발급 → 사용·단말·네트워크 신호 수집
                       → 위험 평가
                       ├─ 정상: 세션 유지
                       ├─ 의심: 추가 인증·권한 제한
                       └─ 고위험: 세션 종료·조사
```

행동 생체는 가능한 신호 중 하나이며 모든 사용자를 항상 센서로 추적할 필요는 없음.

### Ⅲ. 주기적 재인증과 비교

| 구분 | 세션 모니터링 | 재인증 |
|---|---|---|
| 트리거 | 세션 중 위험 신호 | 시간 경과·중요 작업·위험 판단 |
| 성격 | 위험 완화 수단 | 인증 상태를 다시 확인하는 절차 |
| 관계 | 재인증 요청의 근거가 될 수 있음 | 모니터링을 했다는 이유로 면제되지 않음 |

### Ⅳ. 위험과 통제

| 위험 | 대응 |
|---|---|
| 행동 변화에 따른 오탐 | 다중 신호·보수적 임계값·재확인 경로 |
| 타인 오인식 | 평가 성능과 공격 시나리오 시험 |
| 민감 데이터 축적 | 목적·수집 항목·보유 기간 제한 및 프라이버시 위험 평가 |
| 세션 탈취 | 세션 비밀 보호·재인증·종료 정책 병행 |

### Ⅴ. 기술사적 제언

탐지 정확도만이 아니라 재인증·세션 종료의 사용자 영향과 개인정보 처리의 정당성을 검증.

## 출제 이력과 검증 출처

- 제120회 관련 출제 이력은 공식 원문 미확보로 회차·문구 미검증. 위 문항은 예상문제.
- [NIST SP 800-63B, Session Monitoring](https://pages.nist.gov/800-63-4/sp800-63b.html#session-monitoring)
