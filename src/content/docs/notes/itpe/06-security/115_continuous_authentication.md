## 답안 골격
```text
[무자각 지속인증(Continuous Authentication)] ◀━━ 머리: Ⅶ 내 의견 (로그인 시점 단발성 인증의 세션 탈취 한계 극복 → 행위 생체인식 기반 실시간 위험 적응형 지속 신뢰 평가)
 ┃
 ┣━ Ⅰ 개요 ───── 초기 로그인 시점에 한 번만 신원을 검증하는 일회성(Point-in-Time) 인증의 취약점을 극복하기 위해, 서비스 사용 중 사용자의 개입(자각) 없이 백그라운드에서 행위 생체인식과 문맥 데이터를 수집해 실시간으로 신뢰도를 지속 평가하는 인증 기술
 ┣━ Ⅱ 특징 ───── 무자각성(사용자 피로도 Zero) · 동적 지속성(세션 전주기 감시) · 정적 생체(지문/얼굴)가 아닌 동적 행위 생체(타이핑, 터치 압력) 활용 · 위험 기반 적응형 대응(RBA)
 ┣━ Ⅲ 구조 ───── 데이터 수집기(키스트로크, 터치, 센서) + 프로파일링 엔진(AI 머신러닝 모델) + 위험 점수 계산기(Trust Score) + 정책 집행기(PEP: 세션 유지/추가 인증/차단)
 ┣━ Ⅳ 흐름 ───── 1차 기본 인증(로그인 성공) → 백그라운드 행위 데이터 수집 → 정상 사용자 패턴 모델과 실시간 비교 → 신뢰 점수 하락 감지 → 적응형 스텝업(Step-Up) 인증 또는 강제 로그아웃
 ┣━ Ⅴ 비교 ───── 일회성 정적 인증(로그인 시 1회 검증, 세션 하이재킹 무방비) vs 무자각 지속인증(세션 내내 투명 검증, 로그인 후 단말 탈취 즉각 차단)
 ┗━ Ⅵ 실무 ───── 신체 컨디션/환경 변화에 따른 오인식률(FRR) 증가 / 실시간 센서 수집에 따른 배터리 소모 / 사용자 프라이버시 침해 우려
```
- 필수 키워드: 무자각 지속인증 · 행위 생체인식(Behavioral Biometrics) · 키스트로크 다이내믹스 · 신뢰 점수(Trust Score) · 제로트러스트 지속 검증 · 적응형 인증(RBA)
- 배점 전략: 10점 = Ⅰ 무자각 지속인증 개념 및 필요성 → Ⅲ 시스템 구조도 → Ⅵ 핵심 행위 생체 특징 요약 / 25점 = Ⅰ~Ⅶ 전개, 제120회 기출 대응, 제로트러스트 "Never Trust, Always Verify" 철학과의 연계, AI 기반 이상 행동 탐지 모델 및 스텝업 인증 연동 심층 상술
- 기출: 제120회 기출: "무자각 지속인증(Continuous Authentication)"

## 한 줄 본질
- 로그인에 성공한 세션 쿠키나 열려 있는 단말기를 타인이 가로채는 세션 하이재킹 병목 → 키보드 타이핑 리듬, 터치 각도 등 행위 생체를 무자각으로 상시 분석해 신뢰 점수를 산출 → 세션 가로채기 실시간 차단 / 사용자 행태 변화에 따른 오탐 및 배터리 소모 발생

## 핵심 그림
```text
[무자각 지속인증(Continuous Authentication)의 신뢰 점수(Trust Score) 평가 흐름]

  [1. 최초 로그인] (ID/PW + 지문) ──> [신뢰 점수 100점 부여]
            │
            ▼ (서비스 이용 중: 사용자 개입 없는 무자각 백그라운드 감시)
┌─────────────────────────────────────────────────────────────┐
│               동적 행위 생체 데이터 수집 및 분석            │
│  - 키스트로크 리듬 (타이핑 속도, 누름 시간)                │
│  - 터치스크린 제스처 (스와이프 속도, 터치 면적 및 압력)    │
│  - 단말기 파지 각도 및 자이로스코프 미세 떨림               │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
                    [실시간 AI 신뢰 점수 산출]
                               │
       ┌───────────────────────┼───────────────────────┐
       ▼ (점수 80 이상)        ▼ (점수 50~79)          ▼ (점수 50 미만)
  [정상 상태 유지]        [스텝업(Step-Up) 인증]   [세션 즉시 강제 종료]
  (무자각 백그라운드       (지문/FaceID 재요구,     (공격자로 간주 차단,
   지속 모니터링)           송금 등 위험 거래 제한)  단말 화면 잠금)
```

## 핵심 용어
- 키스트로크 다이내믹스 (Keystroke Dynamics): 사용자가 키보드를 누르고 있는 시간(Dwell Time)과 한 키에서 다음 키로 넘어가는 비행 시간(Flight Time)의 고유한 리듬을 분석해 본인 여부를 식별하는 행위 생체인식
- 적응형 스텝업 인증 (Risk-Based Step-Up Authentication): 평소에는 비밀번호 입력 없이 편하게 쓰다가, 위치가 급변하거나 타이핑 패턴이 바뀌어 위험 점수가 올라갈 때만 추가 인증(OTP, 안면인증)을 요구하는 기술

## 핵심 통찰
- "문 앞의 경비원"만으로는 은행 금고를 지킬 수 없음 → 정적 인증은 로그인 창에서만 경비원이 서 있고, 일단 들어오면 내부에서 무슨 짓을 하든 아무도 간섭하지 않는 것과 같음
- 정적 생체정보(지문, 홍채)는 한 번 유출되면 바꿀 수 없는 치명적 약점이 있지만, 행위 생체정보(걸음걸이, 마우스 궤적)는 시시각각 변화하며 위조하기가 불가능에 가까움
- 금융 사기(보이스피싱, 원격제어 앱 악용) 방지의 게임 체인저임 → 피해자가 강제로 비밀번호를 눌러주더라도, 사기범이 원격으로 단말기를 조작하는 순간 마우스 움직임과 터치 좌표가 완전히 달라져 즉각 차단됨

## 이웃 토픽과 구분
- 무자각 지속인증 vs 다중 요소 인증(MFA): MFA = 로그인 시점에 2개 이상의 지식·소유·특징 요소를 요구하는 정적 단발성 검증 / 무자각 지속인증 = 로그인 이후 세션 유지 전 과정에 걸쳐 행위 데이터를 무인으로 지속 검증

## 문제·원인·대책
- 사례: 사내 카페에서 직원이 로그인된 노트북을 열어두고 자리를 비운 사이 타인이 기밀 문서를 메일로 유출한 사고
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 로그인된 단말기 방치로 인한 비인가자 세션 도용 | 정적 로그인 방식의 세션 타임아웃 이전 무방비 노출 | 키스트로크 및 마우스 궤적 기반 무자각 지속인증 적용 | 타인이 마우스를 잡고 3초 이내에 화면 즉각 잠금 |
| 정상 사용자가 피로하거나 보행 중일 때 오탐으로 인한 세션 차단 | 신체 조건 변화에 따른 단일 행위 생체 지표의 신뢰도 왜곡 | 위치·시간·Wi-Fi BSSID 등 다중 문맥(Context) 복합 가중치 평가 | 환경 변화 시 오탐률(FRR) 대폭 감소 및 사용자 편의성 보장 |

## 이렇게 출제된다
- 제120회 기출: "무자각 지속인증(Continuous Authentication)의 개념, 주요 수집 데이터, 신뢰 점수 기반 통제 메커니즘을 설명하시오." → 요구 포인트: Ⅰ 개념 및 등장 배경 + Ⅲ 시스템 구조 및 데이터 유형 + Ⅵ 제로트러스트 지속 검증 연계 방안

## 내 의견
- [원격 금융 거래 앱의 피싱 방지 필수 기능 탑재] 스마트폰을 탈취당하거나 악성 원격 제어 앱(팀뷰어 등)이 깔렸을 때 1차 비밀번호 인증은 무력화됨 → 나라면: 전자금융 거래 시 이체 버튼을 누르는 순간의 '화면 터치 압력'과 '손가락 접촉 면적', '단말기 기울기 센서' 데이터를 측정하는 무자각 지속인증을 금융앱 필수 보안 모듈로 의무화하여, 원격 조작 패킷이나 타인의 손길이 감지되면 거래를 자동 동결하도록 조치
