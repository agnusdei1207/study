## 연관 키워드

- 무자각 지속인증(Continuous Authentication), 세션 하이재킹, 세션 모니터링, 행동 생체(Behavioral Biometrics)
- 키스트로크 역학, 신뢰 점수(Trust Score), Step-Up 인증, 오거부율(FRR)
- 제로 트러스트(Zero Trust), 단말 자세 검증(Device Posture), 온디바이스 AI, 개인정보 보호 중심 설계

## Ⅰ. 무자각 지속인증과 세션 모니터링의 개요

- 핵심 요약 : 최초 로그인 이후에도 사용자의 행동과 단말 환경을 무자각으로 계속 평가하여 세션 도용을 실시간 차단하는 인증 체계.
- 개념 : 로그인 성공 이후 세션이 유지되는 동안 타이핑, 마우스, 터치 등 **행동 패턴**과 단말·네트워크 상태를 수집해 본인 일치 여부를 지속 평가하는 인증 방식.
- 배경 및 필요성 : 최초 1회 로그인 뒤 발생하는 **세션 하이재킹**(Session Hijacking)과 자리 비움 중 무단 조작을 막기 위해, 사용자가 의식하지 않는 행동 특징을 배경에서 분석하는 방식이 요구됨.
- 주요 목적 : 세션 하이재킹, 토큰 탈취, 어깨너머 조작 같은 내부 침해와 계정 도용을 세션 중에도 탐지하여 차단.

## Ⅱ. 무자각 지속인증과 세션 모니터링의 특징 및 장점

- 핵심 요약 : 행동 생체와 환경 맥락을 결합한 위험 점수가 사용자 개입 없이 세션 보호를 계속 수행하는 방식.

1. **행동 생체 특징** (Behavioral Biometrics) : 키 입력 리듬과 마우스 궤적을 사용자별 기준선과 대조 → 세션 교체를 즉시 감지.
2. **환경 맥락 결합** : 단말 무결성, IP 위치, 앱 상태를 함께 평가 → 정상 사용자의 이상 접속과 탈취 세션을 구분.
3. **무자각 동작** : 추가 입력 없이 백그라운드에서 수행 → 업무 흐름을 끊지 않으면서 보안 수준 유지.
4. **동적 정책 집행** : 위험 점수 구간별로 세션 유지, Step-Up 인증, 세션 종료를 차등 적용 → 오탐 피해와 보안 공백을 함께 줄임.

## Ⅲ. 무자각 지속인증과 세션 모니터링의 구조 (흐름)

- 핵심 요약 : 단말의 행동 텔레메트리와 환경 텔레메트리를 분석 엔진이 점수로 바꾸고, 점수 구간에 따라 정책이 집행되는 구조.

```text
[ 사용자 단말 ]
  행동 텔레메트리 수집
  환경 텔레메트리 수집
        ↓ 암호화 전송
[ 지속인증 분석 엔진 ]
  특징 추출 (키 간격, 궤적 곡률)
  기준선 모델과 실시간 대조
  신뢰 점수 산출
```

```text
[ 신뢰 점수 기반 정책 집행 ]
(예시 구간 설계)

80~100점 : 세션 유지
   ↓
50~79점 : Step-Up 인증 요구
   ↓
0~49점 : 세션 종료 + 보안관제 경보
```

- **키스트로크 역학** (Keystroke Dynamics) : 키 누름 시간(Dwell Time)과 키 간 이동 시간(Flight Time)을 시계열 모델로 분석.
- **포인터 역학** : 마우스 궤적 곡률, 가속도, 터치 압력 등의 패턴을 이상 궤적 분류 모델에 입력.
- **단말 자세 검증** (Device Posture) : OS 패치 수준, EDR 동작 상태, 탈옥·루팅 여부를 확인.

## Ⅳ. 정적 인증·주기적 재인증·무자각 지속인증의 비교

- 핵심 요약 : 인증 시점을 로그인 1회에서 주기 재인증을 거쳐 실시간 연속 평가로 옮기면서 세션 탈취 방어와 사용자 편의가 함께 높아지는 방향.

| 비교 항목 | **정적 인증** (Static Auth) | **주기적 재인증** (Periodic Re-auth) | **무자각 지속인증** (Continuous Auth) |
|---|---|---|---|
| 인증 시점 | 로그인 시점 1회 | 일정 시간 경과 시 | 세션 전 기간 연속 |
| 사용자 개입 | ID/PW, OTP 수동 입력 | 주기마다 재입력 팝업 | 개입 없음 |
| 사용자 피로도 | 보통 | 높음 (업무 흐름 단절) | 낮음 |
| 세션 탈취 방어 | 취약 (탈취 후 무방비) | 부분 방어 (주기만큼 노출) | 사용자 교체 시 즉시 감지 |
| 인증 데이터 | 고정 문자열, 일회용 난수 | 고정 문자열, 지문 | 동적 행동 패턴, 환경 맥락 |

## Ⅴ. 무자각 지속인증과 세션 모니터링의 한계와 방안

- 핵심 요약 : 오거부, 프라이버시 침해, 단말 자원 소모, 행동 모방 공격을 점수 가중치 조정, 데이터 최소 수집, 온디바이스 처리, 봇 탐지로 보완.

| 한계 | 원인·영향 | 대응 방안 |
|---|---|---|
| 오거부율(FRR) 급증 | 사용자의 신체 상태나 작업 자세 변화로 행동 패턴이 달라져 업무가 차단됨 | 단일 지표 하락만으로 세션을 끊지 않고 단말 무결성, IP 위치 가중치를 재분배하며 Step-Up 인증 제공 |
| 프라이버시 침해 논란 | 임직원의 입력 활동을 상시 감시하여 개인정보 보호 문제 발생 | 입력 내용은 저장하지 않고 키 간 시간 간격 같은 수치만 로컬에서 추출 후 폐기 |
| 단말 배터리와 트래픽 부담 | 고빈도 센싱 데이터의 상시 서버 전송 | 단말 신경망 처리 장치(NPU)에서 1차 점수를 계산하고 이상 시에만 서버에 통보 |
| 봇 기반 행동 모방 | 원격 도구로 사람처럼 보이는 곡선과 무작위 지연을 주입 | 기계적 입력 패턴을 식별하는 봇 탐지 모델을 행동 분석과 함께 운용 |

## Ⅵ. 무자각 지속인증과 세션 모니터링에 대한 기술사적 제언

- 핵심 요약 : 온디바이스 처리, 접근 정책 엔진 연동, 개인정보 보호 설계를 함께 갖춘 지속 보안 체계로 정착.

단말 자원을 활용하는 경량 행동 분석 모델을 단말에 내재화하면 배터리 소모와 네트워크 지연을 줄이면서 실시간 판정이 가능하다.

제로 트러스트 게이트웨이와 IAM 서버에 점수 결과를 연동하여 위험 징후가 확인되면 세션 권한을 자동으로 축소하거나 차단하도록 정책을 구성하는 것이 필요하다.

생체 특징점은 원본 대신 비가역 해시 형태로만 보관하고, 노사 합의를 거친 운영 기준을 마련하여 개인정보 보호 중심 설계를 전제로 도입해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 무자각 지속인증은 로그인 이후의 세션을 연속 검증하는 방식으로, 세션 도용 방어와 사용자 편의를 함께 높이는 인증 체계.
- 다만 오거부와 프라이버시 문제를 정책과 데이터 설계로 함께 관리해야 실효성이 확보됨.
