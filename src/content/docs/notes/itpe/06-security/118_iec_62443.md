## 지식 로드맵 내 현재 위치

지식 위치: 산업제어 보안 → 위험 기반 표준 → **ISA/IEC 62443**

## 30초 인출

- 본질: 산업자동화·제어시스템(IACS)의 자산 소유자·서비스 제공자·제품 공급자에 걸친 보안 요구·절차의 표준군
- 메커니즘: 대상 IACS의 Zone·Conduit 구분 → 위험 평가 → 목표 보안 수준(SL-T)·통제 설정 → 검증
- 통찰: 한계: 보안 수준과 인증을 모든 제품의 일괄 의무로 보면 적용 오류가 생김 → 방안: 시스템 위험·역할별 표준과 목표 수준을 확인

<details>
<summary>핵심 용어</summary>

- **IACS** : 산업자동화·제어시스템.
- **Zone** : 비슷한 보호 요구를 가진 자산을 묶은 영역.
- **Conduit** : Zone 사이의 통신 경로와 그 보호 요구.
- **SL-T** : 위험 평가로 정하는 목표 보안 수준.

</details>

## 2~4교시 예상문제 (25점)

> ISA/IEC 62443의 표준 구성, Zone·Conduit 위험 평가 및 보안 수준 적용 절차를 설명하고 OT 운영상 제약의 대응을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

| 항목 | 개요 |
|---|---|
| 정의 | ISA/IEC 62443은 산업자동화·제어시스템의 자산 소유자·서비스 제공자·제품 공급자에 적용하는 보안 표준군 |
| 목적 | 위험 평가에 따른 Zone·Conduit·목표 보안 수준 설정과 수명주기 보안 요구 검증 |

ISA/IEC 62443은 산업자동화·제어시스템의 수명주기 전반에 걸친 보안 표준군. 안전·가용성 요구와 보안 통제를 함께 검토하되 안전공학 요구를 보안 수준 하나로 대체하지 않음.

### Ⅱ. 표준 구성

```text
자산 소유자·서비스 제공자 ──운영 프로그램(2-x)
                  │
시스템 Zone·Conduit·SL-T ──설계·요구(3-x)
                  │
제품 공급자 ──────────────개발·구성요소(4-x)
```

| 영역 | 초점 |
|---|---|
| 1-x | 용어·개념·모델 |
| 2-x | 자산 소유자·서비스 제공자의 보안 프로그램 |
| 3-2 | 시스템 설계 위험 평가와 Zone·Conduit, SL-T |
| 3-3 | 시스템 보안 요구와 수준 |
| 4-1 | 제품 개발 수명주기의 보안 |
| 4-2 | 구성요소의 기술 보안 요구 |

### Ⅲ. 설계 절차

```text
자산·기능·위험 파악 → 보호 요구가 유사한 Zone 설정
                   → Zone 간 Conduit·통신 정책
                   → Zone/Conduit별 SL-T → 통제 설계·시험
```

| 요소 | 의미 |
|---|---|
| Zone | 공통 보안 요구를 가진 자산의 논리·물리적 묶음 |
| Conduit | Zone 간 통신과 그 보호 수단 |
| SL-T | 위험 평가에서 정한 목표 수준 |
| SL-C·SL-A | 제품·시스템의 지원 능력 또는 구현·평가 상태와 구분 |

#### OT 적용 고려

| 제약 | 대응 |
|---|---|
| 장기 사용·구형 시스템 | 지원 종료 자산 식별, 보완 통제와 교체 계획 |
| 패치 중단 비용 | 시험 환경·정비 창·롤백 계획 |
| 실시간 제어 | 지연·가용성 영향을 측정한 통신 정책 |
| IT/OT 원격 접속 | Zone 간 접속 통제·기록·승인 |

#### 적용상 오해

SL-4를 특정 공격자 유형이나 '국가 배후 공격 완전 차단'과 동치로 단정하지 않음. 표준 준수·인증 여부는 부문별 계약·규제·제품 범위에 따라 달라짐.

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 산업제어 보안 수준·인증을 모든 제품에 일괄 적용하면 오류 | 시스템 위험·역할별 요구와 목표 보안 수준을 확인 |

### Ⅴ. 제언

일괄 등급 적용보다 자산·공정 위험에 맞는 Zone별 목표 수준, 검증 가능한 보완 통제와 운영 절차 수립.
