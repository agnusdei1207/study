## Ⅰ. ISA/IEC 62443 산업제어시스템 보안의 개요

- 개념 : **산업자동화 및 제어시스템** (IACS: Industrial Automation and Control Systems)의 운영 연속성, 기능 안전성, 사이버 복원력을 확보하기 위해 자산 소유자, 시스템 통합자, 기기 제조사 전 주기에 걸친 **위험 기반 심층 방어** 체계를 규정한 국제 표준군.
- 배경 및 필요성 : 전통적인 폐쇄망 기반 **OT(Operational Technology)/ICS** 인프라가 스마트 팩토리, 산업용 사물인터넷(IIoT), 클라우드와 융합되면서 외부 위협에 직접 노출되었고, **스턱스넷** (Stuxnet), **트라이톤** (Triton) 등 국가 배후의 고도화된 물리 파괴형 사이버 공격이 증가함에 따라 제어 전용 보안 표준이 필수화됨.
- 핵심 목적 : IT(Information Technology) 환경 중심의 기밀성 우선 원칙에서 탈피하여 가용성(Availability)과 안전성(Safety)을 최우선으로 보장하고, 구역(Zone) 및 도관(Conduit) 분할을 통해 위협의 수평 확산을 원천 차단.

## Ⅱ. ISA/IEC 62443 산업제어시스템 보안의 핵심 아키텍처 및 동작 메커니즘

ISA(International Society of Automation)/IEC(International Electrotechnical Commission) 62443은 거버넌스(Part 1), 운영 절차(Part 2), 시스템 보안(Part 3), 부품/기기 보안(Part 4)의 4계층 구조로 구성되며, **Purdue 모델**과 연계된 Zone/Conduit 위험 평가 기반 보안 수준(Security Level) 통제를 구현함.

```text
[ ISA/IEC 62443 4계층 표준 체계 및 Zone/Conduit 통제 모델 ]

+-----------------------------------------------------------------------+
| Part 1. General (62443-1-x) : 개념, 공통 용어, 메트릭, SL 모델 정의   |
+-----------------------------------------------------------------------+
| Part 2. Policies & Procedures (62443-2-x) : 자산 소유자 관리 프로세스 |
+-----------------------------------------------------------------------+
| Part 3. System (62443-3-x) : 시스템 통합자 위험 평가 및 Zone/Conduit  |
+-----------------------------------------------------------------------+
| Part 4. Component (62443-4-x) : 벤더 제품 보안 개발 수명주기(SDL)/기술 |
+-----------------------------------------------------------------------+

             [ Zone & Conduit 기반 OT 심층 분할 아키텍처 ]
 +-----------------------------+             +--------------------------+
 | Zone A (제어 서버 영역)     |             | Zone B (현장 PLC/RTU 영역)|
 | - SCADA Master, HMI         |             | - PLC, DCS Controller, IO|
 | - 요구 보안 수준: SL-T 3    |             | - 요구 보안 수준: SL-T 2 |
 +--------------+--------------+             +------------+-------------+
                |                                         |
                +===============[ Conduit 1 ]=============+
                                (통신 도관)
                     * 산업용 방화벽 (DPI 검사)
                     * 일방향 전송 장비 (Data Diode)
                     * 프로토콜 엄격 제약 (Modbus/IP 필터)
```

- **계층별 표준 구성** : Part 1(용어/개념), Part 2(자산 소유자 정책/절차/패치), Part 3(시스템 통합자 Zone/Conduit 설계 및 기술 요구사항), Part 4(제조사 SDL 및 부품 보안 규격)로 상호 유기적 결합.
- **Zone 및 Conduit 모델** : 논리적/물리적 보안 요구도가 유사한 자산을 그룹화한 'Zone'과 서로 다른 Zone 간 통신 경로를 엄격히 통제하는 'Conduit'으로 분할하여 침해 확산 방지.
- **보안 수준(Security Level: SL)** : SL 1(우발적 노출 방어)부터 SL 2(단순 의도적 공격), SL 3(정교한 전문 공격), SL 4(국가 차원의 자금과 지능형 자원을 갖춘 공격 대응)까지 4단계 체계로 목표(SL-T), 역량(SL-C), 달성(SL-A) 평가.
- **7대 기초 요구사항(Foundational Requirements)** : 식별 및 인증 제어(IAC), 사용 제어(UC), 시스템 무결성(SI), 데이터 기밀성(DC), 제한된 데이터 흐름(RDF, Resource Description Framework), 이벤트 적시 대응(TRE), 자원 가용성(RA)으로 규정.

## Ⅲ. ISA/IEC 62443 산업제어시스템 보안의 세부 구성 요소 및 비교 분석

| 비교 항목 | ISA/IEC 62443 | ISO(International Organization for Standardization)/IEC 27001 | NIST(National Institute of Standards and Technology) SP 800-82 |
| --- | --- | --- | --- |
| 대상 환경 | 산업자동화 및 제어시스템 (OT/ICS) | 전사 정보보호 관리체계 (IT 엔터프라이즈) | 연방 산업제어시스템 보안 가이드 (OT) |
| 보안 우선순위 | 가용성(Availability) > 무결성 > 기밀성 | 기밀성(Confidentiality) > 무결성 > 가용성 | 안전(Safety) 및 가용성 > 무결성 > 기밀성 |
| 핵심 구조 | 4계층 (General, Policy, System, Component) | PDCA(Plan, Do, Check, Act) 사이클 기반 ISMS(Information Security Management System) 통제 항목 (Annex A) | ICS 아키텍처, 위협 모델, 완화 대책 가이드 |
| 분할 원칙 | Zone & Conduit 위험 평가 및 SL 연계 | 조직 및 정보자산 분류 경계 | Purdue 모델 기반 네트워크 세그멘테이션 |
| 인증 체계 | **ISASecure** 제품/조직 적합성 인증 | ISO 27001 제3자 공인 인증 | 가이드라인 (자율 준수 및 연방 표준 준용) |

- ISA/IEC 62443은 일반 IT 중심 ISO 27001과 달리 공정 정지 및 물리적 폭발 방지를 최우선으로 두며, Component 단위(Part 4) 하드웨어/소프트웨어 검증까지 관할하는 독보적 OT 실효 표준임.

## Ⅳ. ISA/IEC 62443 산업제어시스템 보안의 주요 한계점 및 해결 방안

- 레거시 PLC(Programmable Logic Controller)/RTU 기기의 연산 자원 한계로 인한 단말 암호화 적용 제약 :
  - 한계점 : 장기간 노후화된 현장 제어 기기는 메모리와 CPU(Central Processing Unit) 자원이 극히 제한되어 TLS(Transport Layer Security)나 인증서 기반 암호 통신 탑재 시 실시간 제어 지연 유발.
  - 해결 방안 : 단말 수정 대신 Conduit 경계에 산업용 IPS(Intrusion Prevention System) 및 프로토콜 게이트웨이를 배치하여 **심층 패킷 검사** (DPI, Deep Packet Inspection) 및 인라인 **가상 패칭** (Virtual Patching) 수행.
- 연속 무중단 공정 특성상 가동 중 SL-A 검증 및 침투 테스트 불가 :
  - 한계점 : 가동 중인 화학, 제철, 원자력 플랜트에 보안 패치나 모의 침투를 수행할 경우 미세한 네트워크 플루딩으로도 공정 정지(Fail-stop) 발생 위험.
  - 해결 방안 : CPS(Cyber-Physical System) **디지털 트윈** (Digital Twin)을 구축하여 가상 환경에서 사전 보안성 검증 및 패치 적합성 테스트를 완료한 후 정기 유지보수(Overhaul) 기간에 배포.
- 수많은 멀티벤더 하위 시스템 통합에 따른 공급망 보안 파편화 :
  - 한계점 : 다양한 제조사(Siemens, Schneider, Rockwell 등) 기기가 혼재되어 벤더별 취약점 패치 주기 불일치 및 62443-4 인증 미확보 모듈 유입.
  - 해결 방안 : 조달 단계부터 62443-4-1/4-2 ISASecure 인증 필수화, **소프트웨어 자재명세서** (SBOM, Software Bill of Materials) 제출 의무화, 공급망 위험 평가 체계 구축.

## Ⅴ. ISA/IEC 62443 산업제어시스템 보안 적용 및 발전을 위한 기술사적 제언

- IT/OT 통합 보안관제센터(SOC, Security Operations Center) 구축 및 OT 텔레메트리 융합 : 전통 **SIEM(Security Information and Event Management)/SOAR**(Security Orchestration, Automation and Response) 체계에 Modbus, DNP3, OPC(Open Platform Communications)-UA(Unified Architecture) 등 산업용 프로토콜 비정상 패킷 텔레메트리를 결합한 통합 이상징후 탐지 거버넌스 확립.
- Purdue 모델 기반 마이크로 세그멘테이션과 제로 트러스트 도입 : Level 0~3 제어 계층 간에 일방향 **데이터 다이오드** (Data Diode)와 ZTNA(Zero Trust Network Access) 정책을 결합하여 경계 침투 시에도 횡적 이동(Lateral Movement)을 물리적으로 차단.
- 안전 계장 시스템(SIS)의 물리적 망분리 유지 : 비상 정지 및 생명 안전을 담당하는 **Safety Instrumented System**은 상용 제어망과 물리적으로 완전히 분리된 안전 전용 Conduit으로 격리 설계 필수.
