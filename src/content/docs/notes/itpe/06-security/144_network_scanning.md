## 답안 골격
```text
[네트워크 스캐닝(Network Scanning)] ◀━━ 머리: Ⅶ 내 의견 (정적 포트 개방의 정보 노출 한계 극복 → 포트 노킹과 공격 표면 관리(ASM) 기반 사전 정찰 무력화)
 ┃
 ┣━ Ⅰ 개요 ───── 공격 대상 네트워크 및 호스트의 가동 여부, 개방된 포트(Port), 구동 중인 서비스 데몬 및 운영체제(OS) 취약점 정보를 사전에 수집하기 위해 패킷을 전송하고 응답을 분석하는 정보 수집(Reconnaissance) 기법
 ┣━ Ⅱ 특징 ───── 사이버 킬체인의 1단계(정찰) 핵심 활동 · 오픈 스캔과 스텔스(Stealth) 스캔의 분화 · 비정상 TCP 플래그 조합(Xmas, Null) 악용 · 방어자의 취약점 자가 진단 도구로도 활용
 ┣━ Ⅲ 구조 ───── 스캐닝 3단계: 호스트 활성화 확인(ICMP/ARP) → 포트 스캔(TCP/UDP) → 서비스/OS 식별(Banner Grabbing, Fingerprinting)
 ┣━ Ⅳ 흐름 ───── 표적 IP 대역 설정 → ICMP Ping 스윕 → TCP SYN 패킷 발송(Half-Open) → SYN/ACK 수신 시 즉시 RST 발송(세션 미완료로 로그 회피) → 열린 포트 서비스 배너 수집
 ┣━ Ⅴ 비교 ───── 오픈 스캔(TCP Connect, 3-Way Handshake 완료, 완전한 로그 기록) vs 스텔스 스캔(TCP SYN/FIN/Xmas/Null, 연결 미수립으로 방화벽/IDS 탐지 회피)
 ┗━ Ⅵ 실무 ───── 스텔스 스캔에 대한 일반 웹서버 로그 부재 / UDP 스캔의 타임아웃 지연 및 패킷 손실 / 방화벽의 상태 추적(Stateful Inspection)에 의한 차단
```

## 핵심 그림
```text
[TCP Open 스캔(Connect) vs TCP Stealth 스캔(SYN / Half-Open) 비교]

[1. TCP Connect 스캔 (오픈 스캔: 완전 연결, 로그 남음)]
  [스캐너] ─── 1. SYN ─────────> [타깃 서버]
  [스캐너] <── 2. SYN + ACK ──── [타깃 서버]
  [스캐너] ─── 3. ACK ─────────> [타깃 서버] ──> 3-Way Handshake 완료! (시스템 로그 기록)

[2. TCP SYN 스캔 (스텔스 스캔: 미완료 연결, 로그 회피)]
  [스캐너] ─── 1. SYN ─────────> [타깃 서버]
  [스캐너] <── 2. SYN + ACK ──── [타깃 서버] (포트가 열려 있음을 확인!)
  [스캐너] ─── 3. RST (강제리셋)─> [타깃 서버] ──> 세션을 맺지 않고 즉시 파기! (로그 남지 않음)
```

## 핵심 용어
- TCP SYN 스캔 (Half-Open Scan): 3-Way Handshake의 마지막 ACK 패킷 대신 연결을 강제 종료하는 RST 패킷을 보내어, 타깃 서버의 애플리케이션 계층에 완전한 세션 연결 로그를 남기지 않고 포트 개방 여부만 알아내는 스텔스 기법
- 배너 그래핑 (Banner Grabbing): 열린 포트로 접속하여 서비스 데몬(Apache 2.4.49, OpenSSH 8.2 등)이 클라이언트에게 친절하게 응답하는 소프트웨어 명칭과 정확한 버전 텍스트를 수집하여 기공개된 CVE 취약점을 매핑하는 기법

## 핵심 통찰
- 네트워크 스캐닝은 "도둑이 담장을 넘기 전 집안의 모든 창문과 방문을 흔들어보는 행위"임 → 공격자는 공격을 감행하기 전 스캐닝을 통해 공격 성공률이 100%인 타깃 소프트웨어 버전을 특정함
- RFC 793 표준의 빈틈을 파고듦 → TCP 표준에 따르면 포트가 닫혀 있으면 어떤 이상한 플래그(Xmas, Null)가 들어와도 반드시 RST를 보내야 하지만, 포트가 열려 있으면 비정상 패킷을 그냥 무시(Drop)하므로 이 무응답을 통해 포트 개방을 역추론함
- 최고의 방어는 "포트를 닫는 것"이 아니라 "포트가 닫힌 것처럼 보이게 만드는 것(Port Knocking)"임

## 이웃 토픽과 구분
- 네트워크 스캐닝 vs 스니핑(Sniffing): 스캐닝 = 패킷을 능동적으로 전송하여 반응을 살피는 액티브 정찰 / 스니핑 = 네트워크를 지나가는 남들의 패킷을 조용히 엿듣는 패시브 도청

## 내 의견
- [외부 공격 표면 관리(EASM) 솔루션의 정례적 자가 스캐닝 의무화] 기업 보안팀이 인지하지 못하는 그림자 서버(개발 테스트용 클라우드 인스턴스)가 인터넷에 열린 포트를 달고 방치되어 첫 번째 침투 경로가 됨 → 나라면: 해커의 시각에서 매일 전사 공인 IP 대역과 서브도메인을 Nmap/Masscan으로 전수 자가 스캐닝하는 EASM 파이프라인을 구축하고, 비인가 개방 포트 발견 시 클라우드 보안 그룹을 통해 10분 내 자동 격리 조치
