## 30초 인출

- **본질**: 비인간 신원(NHI)은 사람 아닌 애플리케이션·서비스·워크로드를 식별해 시스템 접근을 통제하는 신원.
- **메커니즘**: 신원에 자격증명을 연결하고 권한을 부여한 뒤 사용을 감시하며 변경·종료 때 회수.

<details><summary>핵심 용어</summary>

- **비인간 신원(NHI, Non-Human Identity)**: 사용자 대신 애플리케이션·서비스·워크로드를 식별하고 접근권한과 연결하는 디지털 신원.
- **시크릿(Secret)**: 신원 인증에 쓰이는 API 키·토큰·인증서 개인키 등 비밀 자격증명.
- **API(Application Programming Interface, 응용 프로그래밍 인터페이스)**: 소프트웨어 구성요소 사이의 요청·기능 사용을 정하는 접점.
- **OAuth(Open Authorization)**: 사용자의 자격증명 자체를 공유하지 않고 제한된 권한을 위임하기 위한 인가 프레임워크.
- **MFA(Multi-Factor Authentication, 다중 인증)**: 서로 다른 유형의 인증요소를 둘 이상 조합해 신원을 확인하는 방식.
- **워크로드 신원(Workload Identity)**: 실행 중인 서비스·프로세스에 부여해 다른 시스템이 그 실행 주체를 검증하는 신원.

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|

## Ⅱ. NHI와 자격증명 유형

| 대상 | 신원·인증 수단 | 핵심 관리 |
|---|---|---|
| 애플리케이션·서비스 | 서비스 계정, OAuth 토큰, API 키 | 소유자·용도·대상 API·권한 범위 |
| 클라우드·컨테이너 워크로드 | 워크로드 신원, 단기 토큰 | 실행 환경 검증·단기 발급·최소 권한 |
| 시스템 간 연결 | 인증서와 비밀키 | 발급·갱신·키 보호·폐기 |

## Ⅲ. 수명주기 통제

```text
요청·소유자 지정
       ↓ 승인된 업무와 권한 확인
신원·자격증명 발급
       ↓ 저장소·전송 경로 보호
사용·감사 ── 권한·활동 주기 검토
       ↓ 변경·만료·유출
회전·권한 축소·즉시 폐기
       ↓
서비스 종료 확인과 잔여 신원 정리
```

## Ⅳ. 사람 계정과의 차이 및 위협 통제

| 구분 | 사람 신원 | 비인간 신원 |
|---|---|---|
| 생성·종료 사건 | 입사·이동·퇴사 | 배포·구성 변경·서비스 종료 |
| 인증 수단 | 비밀번호·MFA·인증서 | 키·토큰·서비스 계정·인증서 |
| 주요 위험 | 계정 탈취·권한 오남용 | 시크릿 노출·장기 권한·고아 신원 |
| 관리 통제 | 사용자 확인·역할 재검토 | 자동 발급·단기 자격증명·업무 종료 연동 회수 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 신원 수가 빠르게 늘고 서비스 소유권이 바뀌면 권한 검토가 배포 기록과 분리될 가능성. | 신원 인벤토리를 서비스 카탈로그·배포 파이프라인과 연계하고, 담당자 없는 신원은 사용 중지 후 소유 확인을 거쳐 폐기하는 정책을 제안. |
