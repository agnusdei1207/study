## Ⅰ. 에이전틱 AI 보안 감독 (Agentic AI Security Supervision)의 개요

- **개념** : 단순한 텍스트 응답을 넘어 자율적인 추론, 계획(Planning), 도구 호출(Tool Calling), 멀티 에이전트 협업을 통해 스스로 작업을 완수하는 에이전틱 AI(Agentic AI) 시스템의 폭주, 권한 오남용, 적대적 탈취를 감시·통제·감독하는 전주기 보안 아키텍처.
- **배경 및 필요성** : LLM이 실제 운영체제 명령을 실행하고, 금융 거래를 체결하며, 클라우드 인프라를 수정하는 자율 에이전트로 진화함에 따라 환각이나 간접 프롬프트 주입 한 번으로 전사 인프라가 파괴되는 '과도한 대리인(Excessive Agency)' 위험 급부상.
- **핵심 목적** : 에이전트의 자율적 행동에 대한 실시간 가드레일 정책 집행, 비인가 도구 실행 차단, 인간 승인(HITL) 체계 보장 및 의사결정 추적성(Auditability) 확보.

## Ⅱ. 에이전틱 AI 보안 감독 (Agentic AI Security Supervision)의 핵심 아키텍처 및 동작 메커니즘

에이전틱 AI 보안 감독은 계획 수립(Planning) -> 도구 선택(Tool Selection) -> 실행(Execution) -> 사후 평가의 전 과정에 보안 인터셉터를 배치하여 비인가 작업을 차단함.

```text
[ 에이전틱 AI 자율 행동 및 3단계 보안 감독 아키텍처 ]

  [ 사용자 요청 ] ──> [ 에이전틱 AI (Planner / Orchestrator) ]
                               │
                               ▼ 1. 행동 계획 수립 (Plan)
  +-------------------------------------------------------------+
  | [ 감독 계층 1 : 계획 검증 (Plan Verification) ]             |
  |  - 에이전트의 목표 및 단계별 서브태스크 적합성 검증         |
  |  - 비정상적인 우회 경로, 기밀 자산 접근 계획 탐지 시 반려   |
  +------------------------------┬------------------------------+
                                 │ 2. 도구 호출 생성 (Tool Call)
                                 ▼
  +-------------------------------------------------------------+
  | [ 감독 계층 2 : 정책 집행 지점 (PEP / Guardrail) ]           |
  |  - 파라미터 유효성 검사 (셸 주입 공격 필터링)               |
  |  - 고위험 작업 판별 (DB 삭제, 자금 이체, 외부 메일 발송)    |
  |  ├─> [ 고위험 작업 ] ──> [ Human-in-the-Loop 관리자 최종 승인 ]
  |  └─> [ 안전한 작업 ] ──> 인가 완료
  +------------------------------┬------------------------------+
                                 │ 3. 격리된 도구 실행
                                 ▼
  [ 샌드박스 실행 환경 (Wasm / Container) ] ──> 백엔드 시스템 연동
                                 │
                                 ▼ 4. 사후 감사
  +-------------------------------------------------------------+
  | [ 감독 계층 3 : 텔레메트리 및 추론 감사 (Audit & Explain) ] |
  |  - 에이전트의 사고 과정(Chain of Thought) 불변 로그 기록   |
  +-------------------------------------------------------------+
```

- **다계층 행동 감독(Multi-tier Supervision)** : 에이전트의 생각(CoT), 계획(Plan), 도구 호출(Tool Call) 단계별로 독립된 보안 검증기 배치.
- **Human-in-the-Loop (HITL) 강제** : 읽기 전용 작업은 자율 허용하되, 쓰기/수정/삭제/외부 전송 등 비가역적 작업은 인간의 명시적 승인을 거치도록 강제.
- **실행 샌드박싱(Micro-Sandbox)** : 에이전트가 호출하는 파이썬 코드나 셸 스크립트는 호스트 OS와 격리된 경량 Wasm 또는 임시 컨테이너에서만 구동.
- **사고 과정 감사 추적(Chain-of-Thought Auditing)** : 에이전트가 어떤 근거와 추론을 거쳐 해당 명령을 내렸는지 전 과정을 감사 로그로 기록하여 책임성 입증.

## Ⅲ. 에이전틱 AI 보안 감독 (Agentic AI Security Supervision)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 전통적 챗봇 (Chatbot) | RAG 기반 QA 시스템 | 에이전틱 AI (Agentic AI) |
| --- | --- | --- | --- |
| 동작 모델 | 단순 텍스트 질의-응답 | 검색 문서 기반 텍스트 생성 | 자율적 목표 수립, 계획 및 도구 실행 |
| 환경 영향력 | 없음 (화면 출력에 국한) | 없음 (화면 출력에 국한) | 매우 높음 (실제 API 호출, 파일 수정) |
| 핵심 보안 위협 | 유해 발언, 편향성, 탈옥 | 데이터 오염, 검색 문서 프롬프트 주입 | 과도한 권한 남용, 무한 루프 폭주, 시스템 파괴 |
| 필요 보안 통제 | 입출력 키워드 필터링 | RAG 벡터 DB 접근제어, 출처 검증 | 실시간 행동 감독, HITL, 마이크로 샌드박스 |
| 신뢰 경계 | 모델 단독 | 검색기 + 모델 | 오케스트레이터 + 도구 + 외부 인프라 전반 |

- 에이전틱 AI는 '말하는 AI'에서 '행동하는 AI'로의 진화이므로, 보안의 패러다임 역시 '텍스트 필터링'에서 '자율 행동의 실행 통제 및 거버넌스'로 완전히 전환되어야 함.

## Ⅳ. 에이전틱 AI 보안 감독 (Agentic AI Security Supervision)의 주요 한계점 및 해결 방안

- **에이전트 간 협업(Multi-Agent) 시 공격 감염의 연쇄 전파** :
  - **한계점** : 단 하나의 에이전트가 간접 프롬프트 주입에 감염되면, 협업 네트워크 내의 다른 에이전트들에게 왜곡된 지시를 전달하여 전체 군집 오염.
  - **해결 방안** : 에이전트 간 메시지 교환 시에도 상호 인증(mTLS)과 데이터 무결성 검증을 거치고, 에이전트 간 최소 권한 격리 프로토콜 적용.
- **자율 계획(Planning) 단계에서의 논리적 환각 및 무한 실행 루프** :
  - **한계점** : 복잡한 문제 해결 중 에이전트가 오류 복구를 시도하다가 동일한 API를 수만 번 반복 호출하여 과도한 클라우드 비용(Denial of Wallet) 초래.
  - **해결 방안** : 최대 실행 스텝 수, 토큰 소비 한도, 일일 호출 비용 상한을 하드웨어적으로 강제하는 서킷 브레이커(Circuit Breaker) 내재화.
- **HITL 승인 피로도(Approval Fatigue)로 인한 기계적 승인** :
  - **한계점** : 승인 요청이 지나치게 자주 발생하면 인간 관리자가 세부 인수를 확인하지 않고 승인하여 보안 통제 무력화.
  - **해결 방안** : 위험도 기반 적응형 승인 모델을 적용하여 일상적인 작업은 자동 승인하고, 임계치를 넘는 변칙 작업만 선별하여 인간에게 시각적 컨텍스트 제공.

## Ⅴ. 에이전틱 AI 보안 감독 (Agentic AI Security Supervision) 적용 및 발전을 위한 기술사적 제언

- **'감독 전용 AI 에이전트(Supervisor Agent)' 독립 배치** : 업무 수행 에이전트와 분리된 비판적 보안 감독 에이전트를 두어 모든 행동 계획을 교차 검증.
- **AI 에이전트 전용 IAM 및 최소 권한 프로파일 수립** : 에이전트마다 별도의 서비스 어카운트를 부여하고 오직 작업에 필요한 최소 API 스코프만 임시 발급.
- **국제 AI 안전 표준(ISO/IEC 42001) 연계 에이전트 감사 체계 수립** : 에이전트의 모든 행동 이력과 의사결정 추론을 규제 기관에 소명할 수 있는 불변 감사 데이터 파이프라인 구축.
