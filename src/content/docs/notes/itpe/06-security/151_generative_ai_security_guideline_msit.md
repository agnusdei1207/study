# 생성형 AI 활용 보안 가이드라인

## 핵심 개념
- 공공기관 및 기업이 챗GPT(ChatGPT) 등 상용 대규모 생성형 AI 서비스를 업무에 안전하게 도입·활용할 수 있도록 국가 및 관계 기관(국가정보원 국가사이버안보센터, 과기정통부 등)이 제시한 범정부 보안 지침.
- 업무 비밀 유출, 개인정보 침해, 허위정보(환각)로 인한 오판을 예방하기 위해 '생성형 AI 활용 3대 기본원칙'과 사용자 및 관리자 보안 수칙을 체계화.

```
+-------------------------------------------------------------+
|               생성형 AI 활용 3대 기본 원칙 (보안 가이드)         |
+-------------------------------------------------------------+
| 1. 기밀성 보장 | 업무상 비공개 정보, 비공개 소스코드, 개인정보 입력 금지|
| 2. 정확성 검증 | AI 생성물은 오류·환각 가능성이 있으므로 반드시 사람 검증 |
| 3. 책임성 확립 | 생성 결과물을 활용한 업무의 최종 책임은 사용자 본인 귀속 |
+-------------------------------------------------------------+
```

## 사용자 및 관리자 보안 수칙

### 1. 업무 사용자 필수 보안 수칙
- **비인가 정보 입력 원천 금지**: 비공개 공문서, 대외비 기밀문서, 내부 시스템 IP/계정/비밀번호, 미공개 소스코드 입력 배제.
- **개인정보 침해 방지**: 주민등록번호, 계좌번호, 건강정보 등 개인식별가능정보(PII)의 프롬프트 주입 차단.
- **생성물 팩트체크(검증 의무)**: 환각(Hallucination)에 의한 허위 법령, 가짜 판례, 잘못된 기술 규격 등이 포함될 수 있으므로 원천 출처를 직접 대조·검증.
- **옵트아웃(Opt-out) 설정**: 모델 서비스 제공자의 재학습(Training)에 사용자 입력 데이터가 활용되지 않도록 데이터 공유 거부(Data Controls) 설정 의무화.

### 2. 보안 관리자 통제 수칙
- **네트워크 및 엔드포인트 통제**: 비인가 생성형 AI 사이트 접근을 보안 프록시/차단 솔루션으로 제한하고, 인가된 기업용 계정(Enterprise)만 허용.
- **DLP(데이터 유출 방지) 연계**: 웹 프록시 수준에서 클립보드 복사-붙여넣기 및 HTTP POST 페이로드에 대한 실시간 키워드·정규식 기반 민감정보 필터링.
- **프라이빗 LLM(On-Premise) 검토**: 민감 연구·개발 및 행정 업무는 외부 클라우드 SaaS 대신 사내 격리망에 배포된 자체 프라이빗 모델 활용 유도.
- **로그 감사 및 모니터링**: 접속 일시, 사용자 계정, 프롬프트 전송 내역에 대한 정기적 감사 로그 분석 수행.

## 생성형 AI 도입 방식별 보안성 비교

| 구분 | 퍼블릭 SaaS 모델<br>(ChatGPT, Claude 등) | 엔터프라이즈 전용 SaaS<br>(Azure OpenAI 등) | 온프레미스/프라이빗 LLM<br>(자체 인프라 배포) |
|---|---|---|---|
| **데이터 기밀성** | 학습 데이터로 재활용될 위험 존재 (기본 설정 시) | 전용 테넌트 격리, 데이터 재학습 미수행 보증 | 외부 네트워크와 완전 격리, 사내 통제 완벽 |
| **인프라 비용** | 월간 구독료 수준으로 저렴 | 토큰 기반 사용료 발생 (중간 수준) | 고성능 GPU 서버 도입 및 운영 인프라 비용 큼 |
| **망분리 규제** | 망분리 환경에서 직접 접근 불가 | 전용망/보안 프록시 연계 검토 필요 | 망분리 내부망에 직접 탑재하여 규제 충족 |
| **보안 통제력** | 서비스 제공자 보안 체계에 전적 의존 | IAM 연계, 로깅, 접근통제 적용 가능 | 모델 가중치, 입출력 파이프라인 전 주기 직접 통제 |

- [ ] AI 생성 결과물의 검증 주체 및 법적 책임 소재를 명확히 규정하였는가?

## 결론 및 실무 시사점
- 생성형 AI 활용 가이드라인은 AI 도입을 무조건 억제하는 것이 아니라, 안전한 업무 생산성 혁신을 위한 가드레일을 제공하는 것이 목적임.
- 공공·금융의 망분리 개선 로드맵과 발맞추어, 민감도 높은 업무에는 프라이빗 AI 모델 구축을 병행하고 엔터프라이즈 보안 거버넌스를 강화해야 함.
