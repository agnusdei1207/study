## 지식 로드맵 내 현재 위치

지식 위치: 사이버 물리 시스템 → 무인항공기 → **드론 보안**

## 30초 인출

- 보호 대상: 기체·지상통제소(GCS)·명령제어(C2) 링크·항법·저장 데이터
- MAVLink 2 서명은 메시지 출처와 무결성 확인을 지원하나 **기밀성 암호화는 제공하지 않음**
- GNSS 스푸핑·재밍은 메시지 서명만으로 해결되지 않으며 다중 센서·이상 탐지·안전 착륙 정책 필요

## 1교시 예상문제 (10점)

> 드론의 C2 링크와 항법 위협을 구분하고 MAVLink 2 서명의 보안 범위를 설명하시오. (예상·10점)

## 1교시 10점 답안

| 위협 | 공격 대상 | 대응 |
|---|---|---|
| 명령 주입 | GCS·기체 간 제어 메시지 | MAVLink 2 서명·키 관리·미서명 수신 정책 |
| 도청 | 무선 전송 내용 | 별도 보안 링크 암호화 |
| GNSS 스푸핑·재밍 | 항법 수신기 | 관성·영상 등 센서 교차 검증, Fail-safe |

MAVLink 2 서명은 공유 비밀키와 메시지·링크 ID·시각을 결합한 SHA-256 해시의 앞 48비트를 사용. HMAC이나 암호화라고 부르지 않음.

## 2~4교시 예상문제 (25점)

> 드론 시스템의 기체·GCS·C2 링크·항법 위협을 분석하고 통신 인증, 데이터 보호, 안전한 비행 종료를 포함한 방어 구조를 설계하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 보호 범위

드론 보안은 기체 펌웨어·지상통제소·무선 링크·항법 센서·촬영 자료·운영 계정을 함께 보호하는 문제. 불법 드론 탐지·무력화인 안티드론과 구분.

### Ⅱ. 경로와 위협

```text
GCS ── C2 링크(명령·원격측정) ── 기체
          │ 도청·주입·재전송          │ 펌웨어·저장 데이터
          └─ GNSS 수신·센서 융합 ────┘ 항법 스푸핑·재밍
```

| 층 | 통제 |
|---|---|
| 명령 인증 | MAVLink 2 서명, 공유키 관리, 미서명 메시지 거부 정책 |
| 기밀성 | 별도 링크 암호화와 종단 키 관리 |
| 항법 | GNSS와 INS·영상·지도 등 독립 정보 비교 |
| 기체 | 안전한 업데이트·설정·분실 시 데이터 보호 |
| 비행 안전 | 링크 손실·항법 이상 시 임무별 복귀·정지·착륙 정책 |

### Ⅲ. MAVLink 2 서명 구조

```text
공유 비밀키 + 패킷 헤더·본문·CRC + 링크 ID·타임스탬프
        → SHA-256 → 앞 48비트 서명 필드
        → 수신 측 출처·무결성·시간 창 검증
```

서명 유효성은 명령 내용의 안전성이나 GNSS 위치의 진실성까지 보장하지 않음.

### Ⅳ. 검증·운영 과제

| 과제 | 시험 |
|---|---|
| 미서명 메시지 허용 | 호환성 예외로 인증이 무력화되지 않는지 확인 |
| 키 교체 | 기체 분실·정비·GCS 변경 시 폐기·갱신 |
| 링크 장애 | 재밍·지연·패킷 손실에서 Fail-safe |
| 항법 교란 | 센서 불일치 탐지와 잘못된 자동 귀환 방지 |

### Ⅴ. 기술사적 제언

명령 메시지의 인증, 무선 구간의 기밀성, 항법 정보의 신뢰성과 실제 비행 안전을 서로 다른 통제로 설계·시험.
