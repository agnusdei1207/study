## 지식 로드맵 내 현재 위치

사이버 물리 시스템(CPS) 보안 → 무인항공기(UAV) 체계 → 드론 통신 및 항법 보안

## 30초 인출

- **본질:** 무인항공기(UAV/드론) 시스템의 기체(Drone), 지상통제소(GCS), C2 무선 통신 링크, 위성항법(GNSS) 신호 및 탑재 데이터에 대한 도청, 위조, 탈취, 재밍 공격을 차단하는 사이버 물리 보안 체계.
- **메커니즘:** GCS-기체 간 통신에 MAVLink 2 암호학적 서명 및 대칭키 암호화(AEAD) 적용 → GNSS 신호와 관성항법장치(INS)/비전 센서의 복합 융합으로 스푸핑 방어 → 비상 시 Fail-safe 자율 복귀.
- 통찰: MAVLink 2 서명 단독으로는 통신 기밀성과 GPS 물리적 신호 교란을 방어하지 못하므로, 종단 간 AEAD 암호화 터널과 항재밍(Anti-Jamming)/센서 융합 아키텍처 필수.

<details><summary>핵심 용어</summary>

- **C2 링크(Command and Control Link)**: 지상통제소(GCS)와 드론 기체 간에 비행 제어 명령과 텔레메트리(상태 정보)를 송수신하는 핵심 무선 링크.
- **MAVLink 2 서명(Message Signing)**: 제어 메시지의 위변조와 재생 공격을 방지하기 위해 패킷 헤더와 페이로드에 SHA-256 기반 48비트 서명을 부여하는 표준.
- **GNSS 스푸핑(GPS Spoofing)**: 위성 신호보다 강력한 가짜 RF 신호를 방사하여 드론이 자신의 현재 위치와 시간을 잘못 인식하도록 유도하는 하이재킹 공격.
- **센서 융합 항법(Sensor Fusion Navigation)**: 위성 신호(GNSS) 외에 가속도계/자이로스코프(IMU/INS), 기압계, 비전 오도메트리(VIO)를 결합하여 GPS 음영/교란 시에도 비행을 유지하는 기술.
- **Fail-safe(안전 고장 대응)**: 무선 링크 두절, 배터리 부족, 항법 오류 발생 시 호버링, 이륙 지점 자동 복귀(RTH), 또는 안전 낙하산 전개를 자율 집행하는 기능.
</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 무인항공기 기체와 지상통제소 간의 무선 통신 링크, 위성항법 신호, 임베디드 펌웨어 및 임무 데이터를 사이버 도청, 신호 교란, 강제 탈취로부터 보호하는 통합 보안 체계 |
| 목적 | 드론 제어권 탈취로 인한 공중 충돌, 국가 중요시설 테러, 군사·산업 정찰 정보 유출을 방지하고 물리적 비행 안전성(Safety)과 기밀성 보장 |

## Ⅱ. 드론 통신·항법 보안의 핵심 특징 및 공격 표면

| 구성 요소 | 주요 공격 벡터 (Attack Surface) | 기술적 피해 및 파급 효과 |
|---|---|---|
| C2 통신 링크 | 비인가 RF 제어 신호 주입, 중간자(MitM) 패킷 도청 | 기체 제어권 상실, 원격 강제 조종 및 추락 유발 |
| 위성항법 (GNSS) | GPS RF 신호 재밍(Jamming) 및 스푸핑(Spoofing) | 비행 궤적 왜곡, 금지 구역 침범, 적지 강제 착륙 유도 |
| 지상통제소 (GCS) | 운영 PC/태블릿 악성코드 감염, 조종사 계정 탈취 | 비행 계획 임의 변경, 기체 텔레메트리 및 영상 유출 |
| 기체 하드웨어/펌웨어 | UART/JTAG 디버그 포트를 통한 악성 펌웨어 주입 | 부트로더 탈취, 암호키 추출, 분실 시 저장 데이터 유출 |
| 페이로드 데이터 | 촬영 영상 및 라이다(LiDAR) 센서 데이터 도청 | 군사/공공 시설 촬영 데이터의 비인가 실시간 중계 |

## Ⅲ. 드론 시스템 사이버 물리 공격 체인 및 다계층 방어 아키텍처

```text
[ 사이버 물리 공격 체인 ]
공격자 (RF Jammer / SDR) ──▶ [ GPS 위조 신호 방사 (GNSS Spoofing) ] ──▶ 기체 위치 오인 (경로 이탈)
                         ──▶ [ 비인가 MAVLink 주입 (C2 Hijacking) ] ──▶ 모터 강제 정지 / 추락

[ 다계층 드론 보안 엔지니어링 아키텍처 ]
+---------------------------------------------------------------------------------+
| [지상통제소 (GCS)]                                                              |
|  ├── 기체 조종사 FIDO2 인증 및 조종 권한 관리                                   |
|  └── 종단 간 AEAD 암호화 터널 (WireGuard / DTLS 1.3) 생성                      |
+---------------------------------------------------------------------------------+
                                         │
                                         ▼ (무선 C2 링크 구간)
+---------------------------------------------------------------------------------+
| [무선 링크 보안]                                                                |
|  ├── MAVLink 2 Message Signing (SHA-256 기반 타임스탬프 무결성 검증)             |
|  └── 주파수 도약 확산 대역(FHSS)을 통한 RF 재밍 회피                            |
+---------------------------------------------------------------------------------+
                                         │
                                         ▼
+---------------------------------------------------------------------------------+
| [기체 자율 항법 및 안전 제어 (Flight Controller)]                                |
|  ├── 다중 센서 융합: GNSS + EKF(확장 칼만 필터) + INS(관성항법) + 비전 오도메트리|
|  ├── 보안 부팅: Secure Boot 및 하드웨어 TPM 기반 암호키 격리                    |
|  └── 자율 Fail-safe: 링크 두절 시 관성항법 기반 안전 귀환(RTH) 또는 안전 착륙  |
+---------------------------------------------------------------------------------+
```

| 보안 계층 | 세부 통제 기술 | 핵심 엔지니어링 구현 상세 |
|---|---|---|
| 제어 명령 무결성 | MAVLink 2 서명 | 256비트 공유 비밀키 기반 SHA-256 해시의 상위 48비트 서명 및 타임스탬프 윈도우 검증 |
| 통신 구간 기밀성 | DTLS / WireGuard VPN | 전송되는 제어 명령 및 고화질 H.265 비디오 스트림을 ChaCha20-Poly1305로 전 구간 암호화 |
| 항법 신호 방어 | 항재밍 안테나, 센서 융합 | CRPA(다중 빔포밍 안테나) 적용 및 EKF 기반 관성항법(INS) 데이터 불일치 실시간 탐지 |
| 기체 물리 보안 | Secure Boot, eMMC 암호화 | 하드웨어 신뢰점(RoT) 기반 펌웨어 서명 검증 및 기체 추락/포획 시 메모리 즉시 영구 소거 |
| 비상 안전 통제 | 자율 Fail-safe 로직 | 통신 두절 지속 시 사전 프로그래밍된 비상 착륙 장소로 관성 센서만을 이용해 안전 자율 착륙 |

## Ⅳ. 드론 보안(드론 보호) vs 안티드론(불법 드론 무력화) 비교

| 비교 항목 | 드론 통신·항법 보안 (Drone Security) | 안티드론 시스템 (Anti-Drone / C-UAS) |
|---|---|---|
| 보호 주체 | 아군 및 정상 운영 드론 시스템 자체 | 공항, 원자력발전소 등 지상 중요 시설 |
| 주요 목적 | 외부 공격으로부터 기체의 안전 비행 및 데이터 보호 | 미승인/적대적 침입 드론을 탐지·식별하고 물리적 무력화 |
| 기술적 수단 | 통신 암호화, MAVLink 서명, 센서 융합 항법, TPM | 레이더, EO/IR 카메라, RF 스캐너, RF 재머, 포획 그물 |
| 대상과의 관계 | GCS와 기체 간의 신뢰 채널 확립 | 침입 드론과의 비신뢰 적대적 관계 (무력화 대상) |
| 실패 시 영향 | 기체 추락, 정찰 임무 실패, 기업 기밀 누출 | 지상 시설 폭탄 테러, 공항 활주로 마비 등 대형 참사 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 오픈소스 MAVLink 2 서명은 무결성과 재생 방지만 제공하며 암호화 기능이 없어 정찰 영상 및 텔레메트리 도청 노출 | 통신 링크 하위 계층에 DTLS 1.3 또는 고속 대칭키 암호화(AES-GCM/ChaCha20) 하드웨어 가속기를 결합하여 전 구간 종단 간 암호화(E2EE) 의무화 |
| 상용 GPS 수신기는 강력한 지상 스푸퍼(Spoofer) 신호 유입 시 가짜 좌표를 정상으로 오인하여 기체 납치 발생 | 이중 주파수(L1/L5) 수신기를 탑재하고, 관성항법장치(INS)의 가속도 데이터와 GPS 속도 벡터 간의 공분산을 실시간 감시하는 잔차 분석(Residual Monitoring) 적용 |
| RF 통신 두절 시 자동 복귀(RTH) 기능이 스푸핑된 가짜 홈 위치로 이동하여 적진으로 스스로 날아가는 역이용 취약점 | 홈 좌표(Home Position)를 비행 전 GCS 암호화 메모리에 불변 저장하고, 복귀 시 순수 비전 오도메트리(VIO) 및 지형 대조 항법(TERCOM)만으로 비행 |
| 초소형 드론(Micro UAV)의 경우 탑재 컴퓨터의 CPU 성능과 배터리 용량 한계로 무거운 암호 연산 적용 불가 | NIST 경량 암호 표준인 Ascon 또는 경량화된 타원곡선 서명(Ed25519)을 채택하고 통신 주기별 비대칭키-대칭키 혼용 최적화 |

## Ⅵ. 제언

```text
[ 차세대 고신뢰 무인항공기(UAV) 사이버 물리 보안 모델 ]

+-------------------------+      +-------------------------+      +-------------------------+
|     1. 암호 통신 링크   | ---> |     2. 비GPS 자율 항법  | ---> |     3. 하드웨어 불변보호 |
| (MAVLink 2 + DTLS 1.3)  |      | (INS/비전 센서 융합)    |      | (RoT 보안 부팅/키 소거) |
+-------------------------+      +-------------------------+      +-------------------------+
```

| 연구 및 개발 축 | 세부 엔지니어링 구현 과제 | 비즈니스 및 안보 가치 |
|---|---|---|
| 통신 프로토콜 표준화 | 국토부/KISA 주도의 K-드론 무선 통신 암호 모듈 검증(KCMVP) 필수 탑재 의무화 | 불법 전파 도청 및 상용 드론 원격 해킹 원천 차단 |
| 내결함 항법 시스템 | GPS 거부 환경(GPS-Denied)에서도 동작하는 AI 비전 기반 지형 매칭 자율 비행 실증 | 전자전 및 대규모 GPS 재밍 상황에서도 100% 임무 완수 |
| 기체 레질리언스 | 기체 비인가 분해나 포획 감지 시 플래시 메모리 물리적 자폭/영구 소거 회로 구성 | 국가 핵심 시설 순찰 영상 및 통신 기밀의 적성국 유출 방어 |
