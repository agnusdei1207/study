## Ⅰ. 드론 통신·항법 보안의 개요

- **개념** : 무인항공기 기체와 지상통제소 간의 무선 통신 링크, 위성항법 신호, 임베디드 펌웨어 및 임무 데이터를 사이버 도청, 신호 교란, 강제 탈취로부터 보호하는 통합 보안 체계.
- **배경 및 필요성** : 무인 항공기(UAV/드론)의 군사·산업적 활용이 폭증함에 따라, 무선 조종 링크 탈취(하이재킹), GPS 스푸핑을 통한 경로 이탈, 센서 데이터 도청 등 물리·사이버 융합 위협을 차단하기 위해 무선 암호화 및 항법 보안이 시급해짐.
- **핵심 목적** : 드론 제어권 탈취로 인한 공중 충돌, 국가 중요시설 테러, 군사·산업 정찰 정보 유출을 방지하고 물리적 비행 안전성(Safety)과 기밀성 보장.

## Ⅱ. 드론 통신·항법 보안의 핵심 아키텍처 및 동작 메커니즘

드론 통신·항법 보안은(는) 신뢰할 수 있는 보안 구조와 표준화된 절차를 기반으로 동작하며, 세부적인 아키텍처와 구성요소 간의 상호작용 메커니즘은 다음과 같음.

```text
[ 사이버 물리 공격 체인 ]
공격자 (RF Jammer / SDR) ──▶ [ GPS 위조 신호 방사 (GNSS Spoofing) ] ──▶ 기체 위치 오인 (경로 이탈)
                         ──▶ [ 비인가 MAVLink 주입 (C2 Hijacking) ] ──▶ 모터 강제 정지 / 추락

[ 다계층 드론 보안 엔지니어링 아키텍처 ]
+---------------------------------------------------------------------------------+
| [지상통제소 (GCS)]                                                              |
|  ├── 기체 조종사 FIDO2 인증 및 조종 권한 관리                                   |
|  └── 종단 간 AEAD 암호화 터널 (WireGuard / DTLS 1.3) 생성                      |
+---------------------------------------------------------------------------------+
                                         │
                                         ▼ (무선 C2 링크 구간)
+---------------------------------------------------------------------------------+
| [무선 링크 보안]                                                                |
|  ├── MAVLink 2 Message Signing (SHA-256 기반 타임스탬프 무결성 검증)             |
|  └── 주파수 도약 확산 대역(FHSS)을 통한 RF 재밍 회피                            |
+---------------------------------------------------------------------------------+
                                         │
                                         ▼
+---------------------------------------------------------------------------------+
| [기체 자율 항법 및 안전 제어 (Flight Controller)]                                |
|  ├── 다중 센서 융합: GNSS + EKF(확장 칼만 필터) + INS(관성항법) + 비전 오도메트리|
|  ├── 보안 부팅: Secure Boot 및 하드웨어 TPM 기반 암호키 격리                    |
|  └── 자율 Fail-safe: 링크 두절 시 관성항법 기반 안전 귀환(RTH) 또는 안전 착륙  |
+---------------------------------------------------------------------------------+
```

- **제어 명령 무결성** : MAVLink 2 서명 (256비트 공유 비밀키 기반 SHA-256 해시의 상위 48비트 서명 및 타임스탬프 윈도우 검증).
- **통신 구간 기밀성** : DTLS / WireGuard VPN (전송되는 제어 명령 및 고화질 H.265 비디오 스트림을 ChaCha20-Poly1305로 전 구간 암호화).
- **항법 신호 방어** : 항재밍 안테나, 센서 융합 (CRPA(다중 빔포밍 안테나) 적용 및 EKF 기반 관성항법(INS) 데이터 불일치 실시간 탐지).
- **기체 물리 보안** : Secure Boot, eMMC 암호화 (하드웨어 신뢰점(RoT) 기반 펌웨어 서명 검증 및 기체 추락/포획 시 메모리 즉시 영구 소거).
- **비상 안전 통제** : 자율 Fail-safe 로직 (통신 두절 지속 시 사전 프로그래밍된 비상 착륙 장소로 관성 센서만을 이용해 안전 자율 착륙).

## Ⅲ. 드론 통신·항법 보안의 세부 구성 요소 및 비교 분석

| 비교 항목 | 드론 통신·항법 보안 (Drone Security) | 안티드론 시스템 (Anti-Drone / C-UAS) |
|---|---|---|
| 보호 주체 | 아군 및 정상 운영 드론 시스템 자체 | 공항, 원자력발전소 등 지상 중요 시설 |
| 주요 목적 | 외부 공격으로부터 기체의 안전 비행 및 데이터 보호 | 미승인/적대적 침입 드론을 탐지·식별하고 물리적 무력화 |
| 기술적 수단 | 통신 암호화, MAVLink 서명, 센서 융합 항법, TPM | 레이더, EO/IR 카메라, RF 스캐너, RF 재머, 포획 그물 |
| 대상과의 관계 | GCS와 기체 간의 신뢰 채널 확립 | 침입 드론과의 비신뢰 적대적 관계 (무력화 대상) |
| 실패 시 영향 | 기체 추락, 정찰 임무 실패, 기업 기밀 누출 | 지상 시설 폭탄 테러, 공항 활주로 마비 등 대형 참사 |

- 드론 통신·항법 보안은(는) 상기 핵심 비교 지표와 아키텍처 구성을 바탕으로 보안 위협에 대한 방어 효과성을 극대화하며, 기존 레거시 통제 기법 대비 우수한 신뢰성과 운영 효율성을 제공함.

## Ⅳ. 드론 통신·항법 보안의 주요 한계점 및 해결 방안

- **한계점** : 오픈소스 MAVLink 2 서명은 무결성과 재생 방지만 제공하며 암호화 기능이 없어 정찰 영상 및 텔레메트리 도청 노출.
  - **해결 방안** : 통신 링크 하위 계층에 DTLS 1.3 또는 고속 대칭키 암호화(AES-GCM/ChaCha20) 하드웨어 가속기를 결합하여 전 구간 종단 간 암호화(E2EE) 의무화.
- **한계점** : 상용 GPS 수신기는 강력한 지상 스푸퍼(Spoofer) 신호 유입 시 가짜 좌표를 정상으로 오인하여 기체 납치 발생.
  - **해결 방안** : 이중 주파수(L1/L5) 수신기를 탑재하고, 관성항법장치(INS)의 가속도 데이터와 GPS 속도 벡터 간의 공분산을 실시간 감시하는 잔차 분석(Residual Monitoring) 적용.
- **한계점** : RF 통신 두절 시 자동 복귀(RTH) 기능이 스푸핑된 가짜 홈 위치로 이동하여 적진으로 스스로 날아가는 역이용 취약점.
  - **해결 방안** : 홈 좌표(Home Position)를 비행 전 GCS 암호화 메모리에 불변 저장하고, 복귀 시 순수 비전 오도메트리(VIO) 및 지형 대조 항법(TERCOM)만으로 비행.
- **한계점** : 초소형 드론(Micro UAV)의 경우 탑재 컴퓨터의 CPU 성능과 배터리 용량 한계로 무거운 암호 연산 적용 불가.
  - **해결 방안** : NIST 경량 암호 표준인 Ascon 또는 경량화된 타원곡선 서명(Ed25519)을 채택하고 통신 주기별 비대칭키-대칭키 혼용 최적화.

## Ⅴ. 드론 통신·항법 보안 적용 및 발전을 위한 기술사적 제언

- **통신 프로토콜 표준화 중심의 거버넌스 및 실행 체계 구축** : 국토부/KISA 주도의 K-드론 무선 통신 암호 모듈 검증(KCMVP) 필수 탑재 의무화을(를) 적극 추진하여, 불법 전파 도청 및 상용 드론 원격 해킹 원천 차단 효과를 극대화해야 함.
- **내결함 항법 시스템 중심의 거버넌스 및 실행 체계 구축** : GPS 거부 환경(GPS-Denied)에서도 동작하는 AI 비전 기반 지형 매칭 자율 비행 실증을(를) 적극 추진하여, 전자전 및 대규모 GPS 재밍 상황에서도 100% 임무 완수 효과를 극대화해야 함.
- **기체 레질리언스 중심의 거버넌스 및 실행 체계 구축** : 기체 비인가 분해나 포획 감지 시 플래시 메모리 물리적 자폭/영구 소거 회로 구성을(를) 적극 추진하여, 국가 핵심 시설 순찰 영상 및 통신 기밀의 적성국 유출 방어 효과를 극대화해야 함.
