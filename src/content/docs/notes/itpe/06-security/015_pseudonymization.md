## Ⅰ. 가명처리(Pseudonymization)의 개요

- **개념** : 개인정보의 일부를 삭제하거나 대체(일방향 암호화, 가명 식별자 매핑)하여 추가적인 정보(결합키, 복호화 키) 없이는 특정 개인을 알아볼 수 없도록 처리하는 개인정보보호 기술이자 법적 보호조치.
- **배경 및 필요성** : 데이터 3법 개정을 통해 통계 작성, 과학적 연구, 공익적 기록 보존 목적에 한해 정보주체의 동의 없이도 데이터를 결합·가공·활용할 수 있는 법적 근거가 마련되면서 핵심 처리 기법으로 정립.
- **핵심 목적** : 원본 데이터의 식별 위험을 차단하여 정보주체의 프라이버시를 보호하는 동시에, 연구 및 산업적 빅데이터 분석의 유용성(Utility) 보존.

## Ⅱ. 가명처리(Pseudonymization)의 핵심 아키텍처 및 동작 메커니즘

가명처리는 식별자 추출 -> 가명화 연산(해시, 치환) -> 결합키 생성 및 분리 보관 -> 안전한 결합 및 사후 분석의 단계로 진행됨.

```text
[ 가명처리 및 결합전문기관 결합 프로세스 ]

  [ 기관 A (금융) ]                     [ 결합전문기관 (KISA 등) ]                     [ 기관 B (통신) ]
  - 식별자(주민번호 등)                  - 결합키 수신 및 대조                      - 식별자(주민번호 등)
         │                                         │                                         │
         ▼ 1. 결합키 연산(일방향 솔트 해시)        │                                         ▼ 1. 동일 솔트 결합키 연산
    [ 결합키 A ] ─────────────────────────────────>│<────────────────────────────────────── [ 결합키 B ]
         │                                  2. 결합키 연계                                   │
         │                                  (일치 레코드 매핑)                               │
         ▼ 3. 가명정보 전송                        │                                         ▼ 3. 가명정보 전송
    [ 가명정보 A ] ───────────────────────────────>│<────────────────────────────────────── [ 가명정보 B ]
                                            4. 결합 데이터 생성
                                            5. 추가 비식별 조치 & 반출 심사
                                                   │
                                                   ▼
                                         [ 결합 분석 데이터 반출 ]
```

- **식별자 가명화 기법** : 일방향 해시 함수(SHA-256 + Salt), 난수 기반 토큰화(Tokenization), 암호화(AES)를 적용하여 원래의 고유값을 난독화.
- **결합키(Join Key) 관리** : 서로 다른 기관 간 데이터를 매핑하기 위해 결합전문기관이 배포한 비밀 솔트(Salt)를 결합하여 일방향 결합키를 도출.
- **추가 정보의 엄격한 분리 보관** : 가명정보와 결합키 매핑 테이블, 솔트값은 물리적·논리적으로 분리된 별도 서버에 저장하고 접근 권한을 최소화.
- **반출 심사 위원회 승인** : 결합 완료된 가명정보는 전문위원회의 적정성 평가를 통과해야만 폐쇄 분석실 외부로 반출 가능.

## Ⅲ. 가명처리(Pseudonymization)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 가명처리 (Pseudonymization) | 익명처리 (Anonymization) | 암호화 (Encryption) |
| --- | --- | --- | --- |
| 정의 | 추가 정보 없이는 개인 식별 불가 | 어떠한 수단으로도 개인 식별 영구 불가 | 비밀키를 통해 평문을 암호문으로 변환 |
| 법적 성격 | 여전히 '개인정보'에 해당 (안전조치 의무) | 개인정보 보호법 적용 전면 제외 | 기술적 보호조치의 일환 |
| 가역성 | 추가 정보(키) 보유 시 원본 복원 가능 | 비가역적 (원본 복원 원천 불가) | 복호화 키 보유 시 완전 복원 가능 |
| 활용 목적 | 통계 작성, 과학적 연구, 산업 데이터 결합 | 공공 데이터 개방, 제한 없는 자유 활용 | 데이터 저장 및 전송 구간 보안 |
| 안전 통제 | 추가 정보 분리 보관, 내부 감사 필수 | 적정성 평가 완료 시 법적 규제 해제 | KMS를 통한 암호키 수명주기 관리 |

- 가명처리는 비식별화와 달리 여전히 개인정보 보호법의 규율 대상이므로, 법적 면책을 받기 위한 조치가 아니라 연구 목적 활용 시 동의 요건을 완화해 주는 절차적 특례로 이해해야 함.

## Ⅳ. 가명처리(Pseudonymization)의 주요 한계점 및 해결 방안

- **동일한 해시 알고리즘 사용 시 사전 대입(Dictionary) 공격에 의한 복원** :
  - **한계점** : 주민등록번호나 휴대전화번호와 같이 입력 도메인의 크기가 작은 데이터를 단순 해시화하면 공격자가 사전 계산된 룩업 테이블로 손쉽게 원본 역산.
  - **해결 방안** : 사용자별/기관별 암호학적 동적 솔트(Salt)를 주입하고, 키 유도 함수(PBKDF2, HMAC)를 결합하여 레인보우 테이블 공격 원천 차단.
- **가명정보 결합 후 준식별자 결합으로 인한 특이점(Outlier) 재식별** :
  - **한계점** : 소득 상위 0.01%, 100세 이상 고령자, 희귀 질환자 등 극단적 속성을 가진 개인의 경우 가명화 상태에서도 사회적 배경 지식으로 재식별 가능.
  - **해결 방안** : 상하단 코딩(Top/Bottom Coding) 기법으로 이상치를 범주화(예: '90세 이상')하고, 준식별자 레코드에 k-익명성 기준(k>=5) 강제 적용.
- **가명정보의 재식별 시도 금지 법령 위반 내부자 리스크** :
  - **한계점** : 분석 권한을 가진 내부 연구자가 개인적 호기심이나 금전적 목적으로 원본 데이터와의 결합 및 특정 개인 재식별을 시도하는 내부 통제 결함.
  - **해결 방안** : 분석실 내 인터넷/외부 매체 반출 원천 차단, 화면 캡처 방지, 분석 쿼리 감사 로그 실시간 AI 모니터링 및 개보법 상 형사처벌 조항 공지.

## Ⅴ. 가명처리(Pseudonymization) 적용 및 발전을 위한 기술사적 제언

- **안전한 분석 전용 안심구역(Safe Room) 인프라 고도화** : 데이터 반출 없이 원격 분석 환경 내에서 가명 결합 데이터를 활용하고 결과값만 비식별 통계로 반출하는 체계 수립.
- **가명정보 결합키 라이프사이클의 HSM 자동화** : 수작업에 의존하는 결합키 생성 및 파기 절차를 전용 HSM 클러스터에 위임하여 키 노출 가능성 영구 제거.
- **합성 데이터(Synthetic Data) 결합 파이프라인으로의 점진적 고도화** : 가명정보의 재식별 위험을 근원적으로 배제하기 위해 원본 가명 데이터를 모사하는 생성형 AI 기반 합성 데이터 활용 비중 확대.
