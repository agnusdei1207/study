## 답안 골격
```text
[양자암호통신] ◀━━ 머리: Ⅶ 내 의견 (단순 QKD 링크 한계 극복 → PQC 융합 하이브리드 통신망 구축 및 신뢰 노드 물리 보안 강화)
 ┃
 ┣━ Ⅰ 개요 ───── 양자컴퓨터의 쇼어(Shor) 알고리즘에 의한 공개키 암호체계 붕괴 위협 대비 → 양자역학 물리 법칙(불확정성/복제불가)을 적용한 무조건적 안전성 통신
 ┣━ Ⅱ 특징 ───── 물리법칙 기반 보안(Information-Theoretic Security) · 도청자 즉각 탐지 · 양자난수생성기(QRNG) · 1회용 패드(OTP) 결합
 ┣━ Ⅲ 구조 ───── 양자난수발생기(QRNG) · 양자키분배(QKD) · 양자키관리시스템(QKMS) · 암호화 전송 장비(광전송망/전송계층 암호기)
 ┣━ Ⅳ 흐름 ───── ① 양자채널을 통해 광자 기반 난수 키 분배(QKD) → ② 도청 시도 시 양자 상태 붕괴로 도청 감지 → ③ 오류 정정/키 증폭 후 비밀키 확정 → ④ 공용 데이터 채널에서 대칭키 암호화(AES/OTP) 데이터 전송
 ┣━ Ⅴ 비교 ───── 양자암호통신(QKD: 물리적 하드웨어 전용망 필요, 도청 즉각 검출) vs 양자내성암호(PQC: 수학적 난제 기반 소프트웨어 업그레이드 가능, 도청 검출 불가)
 ┗━ Ⅵ 실무 ───── 전송 거리 한계(광섬유 감쇄로 약 100km 내외) / 신뢰 노드(Trusted Node) 보안 위험 / 전용 광선로 구축 비용
```
- 필수 키워드: 양자암호통신 · QKD · QRNG · QKMS · 양자 불확정성 · 복제불가원리 · 신뢰 노드(Trusted Node) · PQC 하이브리드
- 기출: KPC 128회 `양자암호통신의 원리와 구성요소 및 기존 통신망과의 연동 방안` → Ⅰ 원리 + Ⅲ 구성요소(QRNG, QKD, QKMS) + Ⅵ 연동 방안

## 한 줄 본질
- 양자컴퓨팅 공격에 취약한 수학적 공개키 암호(RSA)의 계산적 한계 병목 → 광자 단위의 양자 중첩과 단일 광자 복제 불가능성(물리 법칙)을 이용해 암호키를 안전하게 분배하고 도청을 원천 차단 → 무조건적 통신 기밀성 보장 / 전용 광섬유 인프라 및 전송 거리 제약 발생

## 핵심 그림
```text
[양자암호통신 네트워크 아키텍처 및 2중 채널 구조]

   [송신 노드 (Alice)]                          [수신 노드 (Bob)]
  ┌──────────────────┐                         ┌──────────────────┐
  │ QRNG (양자난수)  │                         │ 단일 광자 검출기 │
  │ QKD 송신기       │                         │ QKD 수신기       │
  └────────┬─────────┘                         └────────┬─────────┘
           │                                            │
           │  [양자 채널 (Quantum Channel)] - 단일 광자 │
           ├════════════════════════════════════════════┤ (도청 시 붕괴)
           │                                            │
           │  [공공 채널 (Public Channel)] - 키 협의    │
           ├────────────────────────────────────────────┤
           ▼                                            ▼
  ┌──────────────────┐                         ┌──────────────────┐
  │ QKMS (키 관리)   │ ──(공유된 대칭 비밀키)──>│ QKMS (키 관리)   │
  └────────┬─────────┘                         └────────┬─────────┘
           │                                            │
           ▼  [데이터 채널 (Data Channel)] - 암호 통신  ▼
  ┌──────────────────┐  AES-256 / OTP 고속 암호화 ┌──────────────────┐
  │ 광전송 암호 장비 │ ───────────────────────>│ 광전송 암호 장비 │
  └──────────────────┘                         └──────────────────┘
```

## 핵심 용어
- QKMS(Quantum Key Management System): QKD 장비가 생성한 양자 비밀키를 안전하게 저장·관리하고, 상위 계층의 전송 암호화 장비에 실시간으로 공급하는 중앙 키 관리 시스템
- 신뢰 노드(Trusted Node): 광신호 증폭이 불가능한 양자 채널의 거리 한계를 극복하기 위해 중간 기점마다 키를 복호화 후 재암호화하여 전달하는 물리적 중계 거점

## 핵심 통찰
- 양자암호통신은 데이터 자체를 양자로 보내는 것이 아님 → 키 분배(QKD)만 양자 채널로 수행하고, 실제 기가비트 대용량 데이터는 기존 광케이블에서 대칭키(AES-256)로 고속 암호화하여 전송함
- 도청자가 중간에서 광자를 엿보는 순간 하이젠베르크 불확정성 원리에 의해 양자 상태가 영구적으로 변형(오류율 증가)되므로, 송수신자는 도청 사실을 100% 탐지하고 해당 키를 즉시 폐기함
- 장거리 통신의 치명적 약점은 '신뢰 노드(Trusted Node)'임 → 중간 신뢰 노드 내부에서는 암호키가 평문으로 재조합되므로 중계소에 대한 강력한 물리적 출입 통제 및 내부자 보안이 필수적임

## 이웃 토픽과 구분
- QKD vs 양자암호통신: QKD = 암호키를 양자 상태로 안전하게 나누는 프로토콜 기술 / 양자암호통신 = QRNG, QKD, QKMS, 광통신 암호장비가 결합된 전체 엔드투엔드 보안 네트워크 시스템

## 문제·원인·대책
- 사례: 국가 백본망에 QKD를 구축했으나 80km마다 설치된 신뢰 노드의 물리적 탈취 위험성 제기
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 광섬유 흡수 손실로 인한 100km 이상 장거리 전송 불가 | 양자 상태의 복제 불가능성으로 전통 광증폭기(EDFA) 사용 불가 | 신뢰 노드(Trusted Node) 분산 배치 및 양자 중계기(Quantum Repeater) 연구 | 전국 단위 양자 백본망 구성 가능 |
| 신뢰 노드 내부 침투 시 평문 키 노출 위험 | 중계소에서 키 재결합 및 릴레이 과정의 평문 노출 | 신뢰 노드에 HSM 기반 하드웨어 보안 및 물리 탬퍼 방지(Tamper-proof) 적용 | 중간 중계 거점의 내부자 키 탈취 차단 |

## 이렇게 출제된다
- 제128회 기출: "양자암호통신의 원리와 구성요소 및 기존 통신망과의 연동 방안에 대하여 설명하시오." → 요구 포인트: Ⅰ 양자역학적 기본 원리 + Ⅲ 구성요소(QRNG, QKD, QKMS) + Ⅵ 광전송망 연동 아키텍처

## 내 의견
- [모든 네트워크를 QKD로 바꾸려는 비현실적 투자 계획] 막대한 전용 광섬유 인프라 비용이 소요되는 QKD를 엔드포인트 단말까지 보급하려는 시도는 비용 효율성 결여 → 나라면: 국가 데이터센터 간 핵심 백본망은 물리적 도청 검출이 가능한 QKD를 구축하고, 일반 단말과 클라우드 구간은 소프트웨어로 배포 가능한 양자내성암호(PQC)를 적용하는 'QKD 백본 + PQC 엣지' 하이브리드 망 설계 추진
