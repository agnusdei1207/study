## 지식 로드맵 내 현재 위치

암호기술 → 양자 기술 기반 키 분배 → 양자키분배망(QKDN)과 하이브리드 보안

## 30초 인출

- **본질:** 양자역학의 물리학적 특성(단일 광자의 불확정성 원리 및 복제 불가능 정리)을 이용하여 송수신자 간에 도청이 불가능한 대칭 암호키를 안전하게 분배하는 통신 보안 기술
- **메커니즘:** 단일 광자 편광 상태 전송(양자채널) → 기저 정보 비교(고전채널) → 양자오류율(QBER) 측정 및 도청 판별 → 오류 정정 및 프라이버시 증폭 → 최종 비밀키 생성
- 통찰: 물리 법칙에 기반한 무조건적 키 안전성에도 불구하고 전송 거리 한계와 신뢰 노드의 물리적 취약점을 극복하기 위해 PQC와의 상호보완적 하이브리드(QKD+PQC) 아키텍처 구축 필수

<details><summary>핵심 용어</summary>

- **QKD(Quantum Key Distribution):** 양자역학적 성질을 활용하여 두 원격 당사자 사이에 비밀키를 공유하는 프로토콜(예: BB84, E91, Coherent One-Way).
- **양자 불확정성 원리(Uncertainty Principle):** 양자 상태는 관측(측정)하는 행위 자체로 인해 본래 상태가 변화하여 도청 시도를 100% 감지 가능.
- **복제 불가능성 정리(No-Cloning Theorem):** 임의의 미지의 양자 상태를 물리적으로 완벽하게 복제할 수 없다는 양자역학의 기본 정리.
- **BB84 프로토콜:** 찰스 베넷과 질 브라사르가 1984년 제안한 최초의 편광 기반 QKD 프로토콜.
- **QBER(Quantum Bit Error Rate):** 양자 비트 전송 중 발생하는 오류율로, 일정 임계치(통상 11%)를 초과하면 도청 시도로 판단하여 키 전량 폐기.
- **신뢰 노드(Trusted Node):** 장거리 전송을 위해 중간에서 양자 신호를 복호화 후 재암호화하여 전달하는 중계 지점.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 광자의 양자역학적 상태(편광, 위상)를 정보 전달 매개체로 활용하여 송·수신자 간에 안전한 일회용 대칭 비밀키를 분배하고 도청을 실시간 감지하는 물리 보안 기술 |
| 목적 | 미래 양자컴퓨터의 쇼어(Shor) 알고리즘에 의한 공개키 암호체계 붕괴에 대비하여 물리학적으로 증명 가능한 무조건적 보안성(Information-theoretic Security) 확보 |

## Ⅱ. 양자암호통신의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 물리 법칙 기반 안전성 | 수학적 난제에 의존하지 않고 양자역학의 물리학적 법칙(불확정성, 중첩)에 의해 안전성 보장 | 단일 광자원, 광학 편광판 |
| 복제 불가능성 (No-Cloning) | 공격자가 전송 중인 양자 신호를 가로채어 중간에서 복사한 후 원본을 보낼 수 없음 | 양자 단일성(Single Photon) |
| 도청 실시간 감지 | 제3자가 양자 채널을 관측하는 순간 파동함수가 붕괴되어 수신단에서 QBER 급증 감지 | 편광 붕괴 측정, 통계적 검정 |
| 이원 채널 구성 | 실제 광자 펄스를 전송하는 '양자 채널'과 기저 대조 및 에러 정정을 위한 '공인 고전 채널' 병행 | 다크파이버, 기존 공용 광통신망 |

## Ⅲ. 양자키분배(BB84 프로토콜) 체계 및 키 분배 프로세스

```text
[ 송신자 (Alice) ]                                  [ 수신자 (Bob) ]
단일 광자 생성 (QRNG) ─── 양자 채널 (단일 광자 전송) ───▶ 편광 측정 (기저 무작위 선택)
       │                                                    │
       ▼                                                    ▼
[ 1. 양자 전송 ] : 4개 편광 상태 (|0°>, |90°>, |45°>, |135°>) 중 무작위 전송
       │
       ▼ [ 2. 고전 기저 협의 ] : 인증된 공개 채널(인터넷/광통신망)
Alice: 사용한 기저 정보 공표 ◀──────────────────────▶ Bob: 측정한 기저 정보 공표
       │
       ▼ [ 3. 기저 불일치 비트 폐기 (Sifting) ] ── 양측 일치 기저만 남김 (Raw Key)
       │
       ▼ [ 4. 에러율(QBER) 측정 및 도청 검증 ]
QBER > 11% ──▶ [ 도청 발생 판정: 키 전량 폐기 후 재시도 ]
QBER ≤ 11% ──▶ [ 5. 오류 정정 (Cascade/LDPC) ]
       │
       ▼ [ 6. 프라이버시 증폭 (Privacy Amplification) ] ── 도청자 잔여 정보 완벽 소거
최종 공유 비밀키 확정 (Secret Key) ──▶ 일회용 패드(OTP) 또는 AES-256 대칭 암호화에 공급
```

| 단계 | 주요 수행 내용 | 핵심 메커니즘 |
|---|---|---|
| 1. 양자 전송 | 앨리스가 무작위 비트(0, 1)를 십자(+) 또는 대각(×) 기저로 광자 변조 후 전송 | QRNG, 레이저 감쇄 펄스 |
| 2. 기저 협의 | 밥이 무작위 기저로 측정 후, 공개 채널을 통해 서로 어떤 기저를 썼는지만 대조 | 기저 일치 여부만 비교 (비트값 비공개) |
| 3. 키 선별 (Sifting) | 기저가 일치한 비트만 남기고 불일치 비트는 버려 체 비트(Raw Key) 도출 | 이론상 전송량의 50% 보존 |
| 4. 도청 탐지 | 일부 비트를 공개 대조하여 양자오류율(QBER) 계산 (도청 시 QBER 25% 도달) | QBER 허용 임계치(11%) 초과 검사 |
| 5. 오류 정정 | 광케이블의 자연 손실 및 장비 노이즈로 발생한 비트 에러 교정 | Shannon 한계 근접 오류정정 부호 |
| 6. 프라이버시 증폭 | 해시 함수를 적용하여 공격자가 알 수 있는 잠재적 정보량을 수학적으로 0으로 수렴 | 범용 해시 함수(Universal Hashing) |

## Ⅳ. QKD(양자키분배) vs PQC(양자내성암호) 비교

| 구분 | 양자키분배 (QKD) | 양자내성암호 (PQC) |
|---|---|---|
| 안전성 근거 | 물리학적 법칙 (양자 불확정성, 비복제성) | 수학적 난제 (격자, 다변수, 해시 기반 복잡도) |
| 필요 인프라 | 전용 광선로(다크파이버), 단일 광자 검출기, 냉각기 | 기존 소프트웨어 및 네트워크 인프라 그대로 사용 |
| 전송 거리 | 물리적 거리 제한 (통상 100~200km, 신뢰노드 필요) | 거리 제한 없음 (인터넷 전 구간 통신 가능) |
| 처리 속도 | 초당 수십~수백 kbps 키 생성률 | 소프트웨어 연산으로 수 Gbps 이상 암호화 처리 |
| 주요 용도 | 백본망, 데이터센터 간 고보안 전용 회선망 | 인터넷 일반 구간, TLS/SSL, 엔드포인트 기기 전반 |
| 결합 전략 | **하이브리드 QKD+PQC:** 백본은 QKD로 보호하고 종단/사용자 구간은 PQC로 암호화 연계 |

## Ⅴ. 양자암호통신의 한계와 방안

| 한계 | 방안 |
|---|---|
| 광섬유 자체의 빛 흡수 감쇠 및 양자 복제 불가능 정리로 인해 신호 증폭기(EDFA)를 쓸 수 없어 전송 거리 제한(100~200km) 발생 | 중간 신뢰 노드(Trusted Node)를 단계적으로 배치하고 장기적으로는 양자 얽힘을 복원하는 양자 중계기(Quantum Repeater) 및 위성 QKD 도입 |
| 다중 광자 방출 결함을 악용한 광자 분할 공격(PNS, Photon Number Splitting) 및 광학 장치 결함 부채널 공격 노출 | 신호 광자 사이에 강도가 다른 미끼 펄스를 섞어 도청을 탐지하는 미끼 상태(Decoy State) 프로토콜 및 측정장치 무관 QKD(MDI-QKD) 적용 |
| 전용 다크파이버 포설 비용 과다 및 기존 패킷 통신망과의 이종 프로토콜 인터페이스 결합 병목 | 기존 상용 광케이블에서 파장분할다중화(WDM) 기술을 통해 양자 채널과 고전 데이터 채널을 단일 광케이블로 전송하는 QKD-WDM 공존 기술 적용 |

## Ⅵ. 제언

```text
[ 단일 암호 체계 ]                     [ 차세대 하이브리드 양자 보안망 ]
기존 공개키(RSA/ECC) ──┐               ┌── 국가 백본망: QKD 기반 물리적 키 분배
양자컴퓨터 공격 취약 ─┼─→ [ 통신 마비 ] ─┼── 종단 서비스: PQC 알고리즘 소프트웨어 배포
단일 장애점 상존 ─────┘               └── 통합 KMS 기반 QKD-PQC 하이브리드 제어
```

| 평가 영역 | 전통적 공개키 암호망 | QKD 전용망 | QKD + PQC 하이브리드망 |
|---|---|---|---|
| 장기 안전성 | 쇼어 알고리즘에 완전 붕괴 | 물리 법칙 기반 절대 안전 | 수학적 난제 + 물리 법칙 이중 방어 |
| 인프라 경제성 | 매우 우수 (추가 비용 없음) | 매우 낮음 (전용 장비 필요) | 핵심 구간 선별 투자로 비용 최적화 |
| 서비스 확장성 | 전 세계 글로벌 통신 가능 | 포인트 투 포인트 제한 | 클라우드-단말 전 구간 엔드투엔드 암호화 |

양자암호통신은 국가 안보, 금융망, 핵심 인프라 백본의 기밀성을 수호하는 최상위 물리 방어 체계이며, 현실적 적용성과 경제성을 고려하여 소프트웨어 기반 PQC와 유기적으로 결합된 하이브리드 국가 암호망으로 발전 필수.
