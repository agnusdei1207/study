## Ⅰ. 바이오정보(Biometric Information) 분산관리의 개요

- 개념 : 지문, 홍채, 정맥, 안면 등 개인의 고유한 바이오인식정보 특징점(Template)을 단일 서버에 통째로 보관하지 않고, 2개 이상의 수학적 조각(조각 A, 조각 B)으로 분할하여 금융회사와 공인 분산관리기관(금융결제원 등)에 상호 분산 보관 및 인증하는 보안 기술.
- 배경 및 필요성 : 바이오정보는 비밀번호와 달리 유출 시 평생 변경이 불가능(비가역성)하므로, 중앙 서버 해킹으로 대규모 바이오정보가 털릴 경우 회복 불가능한 피해가 발생하는 구조적 위험을 방지하기 위해 금융위원회를 중심으로 법제화.
- 핵심 목적 : 단일 저장소 해킹에 의한 바이오정보 유출 원천 방지, 비밀 분산(Secret Sharing) 기반 무결성 및 프라이버시 보장, 전자금융거래의 신뢰성 제고.

## Ⅱ. 바이오정보(Biometric Information) 분산관리의 핵심 아키텍처 및 동작 메커니즘

바이오정보 분산관리는 등록 단계에서 특징점을 2개로 분할하여 금융회사와 분산관리센터에 나누어 저장하고, 인증 시 양쪽의 조각을 임시 결합하여 일치 여부를 판별한 후 즉시 폐기하는 메커니즘을 가짐.

```text
[ 바이오정보 분산관리 아키텍처 및 2단계 프로세스 ]

  [ 등록 단계 (Registration) ]
  1. 사용자 단말에서 바이오정보 취득 (지문/정맥 스캔)
  2. 특징점 추출 -> 암호학적 알고리즘으로 분할 (조각 1 + 조각 2)
  3. 조각 1 ──(TLS 전송)──> [ 금융회사 서버 ] (금융회사 보관)
  4. 조각 2 ──(TLS 전송)──> [ 금융결제원 분산관리센터 ] (공인기관 보관)

  [ 인증 단계 (Authentication) ]
  1. 단말에서 인증 요청 -> 특징점 조각 획득
  2. 금융회사 조각 1 + 결제원 조각 2 결합 -> [ 안전한 메모리 내 임시 결합 ]
  3. 원본 특징점 복원 -> 현재 입력된 특징점과 매칭 연산 (Score 비교)
  4. 인증 성공/실패 결과 반환 -> [ 임시 결합 특징점 즉시 메모리 영구 파기 ]
```

- **특징점 분할(Template Splitting)** : 고유 바이오 원본 이미지를 폐기하고, 좌표화된 특징점을 Shamir's Secret Sharing 또는 퍼지 볼트(Fuzzy Vault) 기법으로 2개 이상의 조각으로 분리.
- **독립적 암호화 저장** : 금융회사와 금융결제원은 각자의 고유 대칭키(AES-256)로 조각을 암호화하여 별도의 물리적 DB에 분산 격리 보관.
- **조각 자체의 무의미성** : 단일 조각만으로는 원본 바이오정보를 복원하거나 역공학하는 것이 수학적으로 불가능.
- **인증 후 즉시 파기** : 인증 완료 즉시 결합된 특징점 메모리 영역을 0으로 덮어쓰기(Zeroization)하여 잔류 메모리 공격 방어.

## Ⅲ. 바이오정보(Biometric Information) 분산관리의 세부 구성 요소 및 비교 분석

| 비교 항목 | 중앙 집중형 바이오 저장 | FIDO 표준 로컬 인증 | 금융결제원 바이오 분산관리 |
| --- | --- | --- | --- |
| 보관 장소 | 금융사 중앙 DB 단일 저장 | 사용자 스마트폰 Secure Enclave | 금융회사 + 금융결제원 분할 보관 |
| 유출 위험도 | 치명적 (중앙 DB 탈취 시 전 고객 유출) | 극히 낮음 (단말 분실 시 단일 침해) | 극히 낮음 (양 기관 동시 해킹 불가) |
| 단말 교체성 | 단말 교체 시에도 중앙 재인증 가능 | 스마트폰 교체 시 바이오 재등록 필수 | 단말 독립적 (ATM, 키오스크, 앱 모두 가능) |
| 적합 채널 | 보안 취약으로 현재 금융권 금지 | 스마트폰 모바일 뱅킹, 웹 브라우저 | 오프라인 영업점 창구, ATM, 무인 키오스크 |
| 주요 보안 기술 | 단순 DB 암호화, 접근 통제 | 공개키 전자서명, TPM, TEE | 비밀 분산, 매칭 후 즉시 메모리 소거 |

- FIDO가 개인 소유 스마트폰의 로컬 인증에 최적화되어 있다면, 바이오정보 분산관리는 은행 창구, ATM 등 공용 기기에서 금융 거래를 비대면으로 수행할 때 가장 안전한 국가 표준 모델임.

## Ⅳ. 바이오정보(Biometric Information) 분산관리의 주요 한계점 및 해결 방안

- 인증 순간 양쪽 조각이 메모리 상에서 결합될 때 발생하는 **인메모리 탈취** 위험 :
  - 한계점 : 인증 서버의 휘발성 메모리(RAM)에 일시적으로 결합된 전체 특징점이 상주하는 찰나의 순간에 메모리 덤프 또는 루트킷 공격에 노출될 가능성.
  - 해결 방안 : 신뢰실행환경(TEE)인 Intel SGX나 AMD SEV 내에서만 조각 결합 및 매칭 연산을 수행하고, 결합 없이 암호화 상태로 매칭하는 동형암호 기반 분산 매칭 고도화.
- **바이오정보 위조** (Presentation Attack / Spoofing) 위협 :
  - 한계점 : 실리콘 모조 지문, 고해상도 안면 사진, 딥페이크 영상을 센서에 제시하여 분산 보관된 정상 템플릿과 매칭을 성공시키는 위조 공격 취약.
  - 해결 방안 : 생체 활력 징후 감지(Liveness Detection) 기술(혈류 감지, 적외선 깊이 측정, 깜빡임 유도 챌린지)을 하드웨어 센서 단에 의무화.
- 네트워크 전송 구간에서의 **중간자 공격** (MitM) 및 지연 오버헤드 :
  - 한계점 : 인증 시마다 금융회사와 금융결제원 간 전용선 통신 홉이 추가되어 네트워크 트래픽 급증 및 통신 장애 시 ATM 거래 중단.
  - 해결 방안 : 전용 mTLS 가속 암호화 게이트웨이를 구축하고, 회선 장애 시 FIDO 기반 백업 인증 수단으로 자동 우회하는 다중화 체계 수립.

## Ⅴ. 바이오정보(Biometric Information) 분산관리 적용 및 발전을 위한 기술사적 제언

- 금융권 바이오 분산관리망의 **동형암호** (HE) 전환 연구 : 조각을 결합하여 복원하지 않고도 암호화된 조각 상태 그대로 일치도를 계산하는 제3세대 분산인증 아키텍처 도입 추진.
- FIDO2(WebAuthn)와 분산관리의 융합 옴니채널 인증 수립 : 모바일 환경에서는 FIDO를, 영업점 및 창구 금융 거래에서는 분산관리 바이오를 유기적으로 연계하는 전사 통합 인증 허브 구축.
- 생체정보 폐기 및 생명주기 투명성 보장 : 금융거래 종료 고객의 바이오 조각이 양 기관에서 영구 삭제되었음을 증명하는 블록체인 기반 폐기 증적 공증 체계 도입 필요.
