## 연관 키워드

- 바이오정보 분산관리, 특징점(Template), 비밀 분산(Secret Sharing), 퍼지 볼트(Fuzzy Vault)
- 메모리 소거(Zeroization), FIDO(Fast IDentity Online), FIDO2(WebAuthn)
- 신뢰실행환경(TEE), 생체 활력 징후 감지(Liveness Detection), 동형암호(HE)
- 중간자 공격(MitM), 바이오 위조(Presentation Attack)

## Ⅰ. 바이오정보 분산관리의 개요

- 핵심 요약 : 바이오정보를 한 곳에 보관하지 않고 두 기관에 조각으로 나눠 인증하는 보안 방식.
- 개념 : 지문, 홍채, 정맥, 안면 등 고유한 바이오인식정보의 **특징점** (Template)을 단일 서버에 통째로 두지 않고, 두 개 이상의 조각으로 분할해 금융회사와 금융결제원 분산관리센터에 나눠 보관·인증하는 보안 기술.
- 배경 및 필요성 : 바이오정보는 비밀번호와 달리 유출되어도 바꿀 수 없어(비가역성), 중앙 서버가 뚫리면 회복이 어려운 피해가 생기므로 이를 구조적으로 막을 장치가 필요함.
- 주요 목적 : 단일 저장소 해킹에 따른 유출을 막고, **비밀 분산** (Secret Sharing) 기반으로 무결성과 개인정보 보호를 확보해 전자금융거래의 신뢰를 높이는 것.

## Ⅱ. 바이오정보 분산관리의 특징 및 장점

- 핵심 요약 : 조각 분할, 기관별 독립 암호화, 인증 후 즉시 소거가 원본 유출 위험을 줄이는 구조.

1. 조각 분할 : 특징점을 두 조각 이상으로 나눠 기관별로 보관 → 한 기관이 뚫려도 원본 복원 불가.
2. 퍼지 볼트 기법 적용 : **퍼지 볼트** (Fuzzy Vault)로 조각을 생성해 원본 좌표를 직접 노출하지 않음 → 조각 자체의 역산 위험 감소.
3. 독립 암호화 : 기관마다 별도 키로 조각을 암호화해 격리 저장 → 한쪽 키가 유출되어도 다른 조각은 보호.
4. 인증 후 즉시 소거 : 매칭이 끝나면 결합된 특징점이 머문 메모리를 0으로 덮어씀 → 잔류 메모리를 통한 노출 방지.

## Ⅲ. 바이오정보 분산관리의 구조 (흐름)

- 핵심 요약 : 등록 단계의 분할 저장과 인증 단계의 임시 결합이 짝을 이루는 2단계 흐름.

```text
[ 등록 단계 (Registration) ]

바이오정보 취득 (지문·정맥 스캔)
        ↓
특징점 추출 후 분할 (조각 A, 조각 B)
        ↓
조각 A → 금융회사 보관 (TLS 전송)
        ↓
조각 B → 금융결제원 분산관리센터 보관
```

```text
[ 인증 단계 (Authentication) ]

인증 요청 → 조각 A·B 수집
        ↓
메모리 내 임시 결합 → 원본 특징점 복원
        ↓
입력 특징점과 매칭 (점수 비교)
        ↓
결과 반환 후 결합 값 즉시 소거
```

- 단일 조각만으로는 원본 바이오정보를 복원하거나 역산할 수 없도록 설계되어, 두 기관을 모두 장악해야만 위험이 실현됨.

## Ⅳ. 바이오정보 분산관리와 다른 인증 방식의 비교

- 핵심 요약 : 중앙 저장은 유출 시 피해가 크고, 단말 기반 인증은 단말 제약이 있어, 분산관리는 공용 기기 환경에 적합.
- **FIDO** (Fast IDentity Online)는 개인 스마트폰의 로컬 인증에 최적화된 표준이고, 분산관리는 창구·ATM 같은 공용 기기에서 비대면에 가까운 거래를 수행할 때 적합함.

| 비교 축 | 중앙 집중형 저장 | FIDO 기반 로컬 인증 | 바이오정보 분산관리 |
| --- | --- | --- | --- |
| 보관 장소 | 금융사 중앙 DB 단일 저장 | 사용자 스마트폰 보안 영역 | 금융회사와 금융결제원에 분할 보관 |
| 유출 위험 | 중앙 DB 탈취 시 전 고객 정보 유출 우려 | 단말 단위로 침해 범위 제한 | 두 기관을 동시에 뚫어야 하므로 낮음 |
| 단말 의존성 | 단말 제약이 적음 | 등록된 단말에 의존 | 창구, ATM, 키오스크 등 공용 기기 가능 |
| 주요 기술 | 데이터 암호화, 접근 통제 | 공개키 전자서명, 보안 하드웨어 | 비밀 분산, 매칭 후 즉시 소거 |

## Ⅴ. 바이오정보 분산관리의 한계와 방안

- 핵심 요약 : 인증 순간의 메모리 노출, 위조 매체, 기관 간 통신 부담을 보안 영역 연산·생체 신호 확인·다중화로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 인메모리 노출 | 인증 순간 결합된 특징점이 RAM에 머물러 메모리 덤프나 루트킷 공격에 노출 | **신뢰실행환경** (TEE, Trusted Execution Environment) 안에서만 결합·매칭 수행 | 메모리 잔류 시간, 보안 영역 적용률 |
| **바이오 위조** (Presentation Attack) | 모조 지문, 고해상도 사진, 딥페이크 영상을 센서에 제시해 정상 템플릿과 매칭 시도 | **생체 활력 징후 감지** (Liveness Detection, 혈류·깜빡임 등 생체 신호 확인)을 센서 단에 적용 | 위조 탐지율 |
| **중간자 공격** (MitM, Man-in-the-Middle) | 인증마다 기관 간 통신 구간이 추가되어 노출 지점과 지연이 증가하고, 장애 시 거래 중단 | 기관 간 상호 TLS(mTLS) 게이트웨이 구축, 회선 장애 시 FIDO 기반 백업 인증으로 자동 우회 | 인증 응답 시간, 장애 우회 성공률 |

## Ⅵ. 바이오정보 분산관리에 대한 기술사적 제언

- 핵심 요약 : 암호 연산 고도화, 채널별 인증 연계, 폐기 증적 관리를 분산관리의 발전 방향으로 제시.

1. 동형암호 기반 매칭 연구 : 조각을 복원하지 않고 암호화된 상태에서 일치도를 계산하는 **동형암호** (HE, Homomorphic Encryption) 방식을 단계적으로 검증하는 것이 바람직하다.
2. 옴니채널 인증 연계 : 모바일 환경은 **FIDO2** (WebAuthn, Web Authentication), 영업점 창구는 분산관리로 연계하는 통합 인증 체계를 금융권이 공동으로 설계할 필요가 있다.
3. 폐기 증적 관리 : 거래가 끝난 고객의 조각이 양 기관에서 삭제되었음을 증명하는 기록 방식을 도입해 생명주기 투명성을 확보하는 것이 좋다.

## Ⅶ. 결론

- 핵심 요약 : 바이오정보 분산관리는 조각 분할과 즉시 소거로 바이오정보의 비가역성 위험을 구조적으로 낮추는 인증 기술.
- 시사점 : 인증 편의와 보안을 함께 얻으려면 채널별로 FIDO와 분산관리를 나눠 쓰는 설계가 현실적이다.
