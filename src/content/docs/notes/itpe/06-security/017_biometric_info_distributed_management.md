---
## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **바이오정보 분산관리**는 참가기관과 금융결제원이 생체정보를 분할·분산 관리해 비대면 본인확인을 지원하는 금융서비스 구조 |
| 목적 | 한 기관에 생체정보가 집중되는 위험 완화와 금융·연계기관의 본인확인 서비스 지원 |

생체정보는 유출 이후 교체가 어렵다는 특성. 분할·분산만으로 유출·오남용·인증 우회가 방지된다고 단정하지 않음.

## Ⅱ. 구성주체와 신뢰경계

| 구성주체 | 역할·책임 |
|---|---|
| 고객 | 등록·인증 요청과 이용 동의 |
| 참가기관 | 생체정보 분할, 금융서비스 제공, 고객·서비스 관리 |
| 금융결제원 | 참가기관 공동의 분산관리 시스템·인증중계 운영 |
| 이용기관 | 계약된 범위의 생체정보 활용 서비스 제공 |

| 관계 | 공개된 역할 |
|---|---|
| 참가기관 ↔ 금융결제원 | 분산관리 시스템과 인증중계의 연계 |
| 금융결제원 ↔ 이용기관 | 서비스 이용계약에 따른 연계 |

금융결제원 공개 안내는 역할·API 유형을 설명하며, 저장분할 알고리즘과 생체 템플릿 재구성의 상세 절차는 공개 안내만으로 특정할 수 없음.

## Ⅲ. 등록·인증 처리 흐름

```text
고객 등록·인증 요청
          ↓
참가기관 등록 API / 인증 API
          ↓ 기관 간 요청 연계
금융결제원 분산관리 시스템·인증중계
          ↓ API 응답·인증 결과 연계
참가기관의 서비스 판단
```

| 공개된 API 유형 | 운영상 검토 |
|---|---|
| 등록 API | 등록 주체·동의·최소 수집·분할관리 권한 |
| 인증 API | 요청 위변조·재전송·인증결과의 출처 확인 |
| 관리 API | 관리자 인증·변경 승인·접근이력 |
| 연계인증 API | 이용기관 계약범위·요청 목적·결과 전달 제한 |

## Ⅳ. 중앙집중 방식 및 FIDO와 비교

| 구분 | 중앙집중 생체정보 관리 | 금융결제원 분산관리 | FIDO 인증 |
|---|---|---|---|
| 처리 구조 | 한 서비스 주체의 저장·인증에 집중 | 참가기관과 인증중계 간 정보 분할·분산 | 기기에서 사용자 검증, 공개키 기반 인증 결과 전달 |
| 생체정보 위치 | 시스템 설계에 따라 서버 저장 가능 | 기관 간 분산관리 구조 | 바이오정보는 사용자 기기 환경을 벗어나지 않음 |
| 주요 보호점 | 집중 저장소·접근권한·키 보호 | 기관 간 API·분할정보·인증중계 보호 | 인증기 분실·등록해제·복구 절차 |

FIDO의 기기 내 생체검증과 금융결제원 분산관리 서비스는 구조·운영 주체가 다른 접근.

## Ⅴ. 안전한 적용·운영

| 위험 | 통제 |
|---|---|
| 분산정보와 연계정보 동시 접근 | 기관별 역할분리·최소권한·접근기록·키 보호 |
| API 요청·응답 위변조 | 상호 인증·전송보호·요청 무결성·응답 출처 검증 |
| 목적 외 생체정보 이용 | 목적·계약·보유기간·이용자별 권한 관리 |
| 운영계정·연계기관 침해 | 관리자 다중인증, 변경 승인, 이상 호출 탐지, 사고대응 연습 |

## Ⅵ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 정보가 여러 기관에 나뉘어 있어도 API·운영계정·연계정책의 통제가 약하면 공동 침해 경로가 남음 | 분산 저장과 함께 기관 간 신원·권한·요청 목적을 검증하고, 생체정보 접근·인증결과·관리변경 로그를 연계해 점검 |
