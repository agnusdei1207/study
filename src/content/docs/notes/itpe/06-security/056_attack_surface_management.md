## 지식 로드맵 내 현재 위치

외부 위협 관리 → 노출 자산 파악 → 공격표면관리(ASM: EASM + CAASM)

## 30초 인출

- **본질:** 공격자의 시각에서 인터넷에 노출된 조직의 유·무형 디지털 자산(서버, 포트, 클라우드, 도메인, 섀도우 IT)을 지속적으로 탐색·분석하여 잠재적 침투 경로를 선제 차단하는 위험 관리 체계
- **메커니즘:** 자산 자동 탐색(OSINT/스캔) → 자산 인벤토리화 및 맥락화(CAASM 연계) → 위험 분석 및 우선순위화(EPSS/KEV 결합) → 교정 조치(SOAR/패치) → 지속적 모니터링
- 통찰: 단순 외부 포트 스캐닝에 그치지 않고 내부 자산 관리(CAASM) 및 비즈니스 서비스 맥락(CMDB)과 연계하여 섀도우 IT와 클라우드 설정 오류를 실시간 통제하는 동적 공격표면 축소 체계 구축 필수

<details><summary>핵심 용어</summary>

- **공격표면(Attack Surface):** 공격자가 시스템에 무단 접근하거나 데이터를 탈취하기 위해 진입점으로 악용할 수 있는 모든 노출 접점의 총합.
- **EASM(External Attack Surface Management):** 외부 인터넷 관점에서 조직이 보유한 공인 IP, 서브도메인, 오픈 포트, 인증서 만료 등을 에이전트리스로 탐색하는 기술.
- **CAASM(Cyber Asset Attack Surface Management):** 내부 API를 통해 온프레미스, 클라우드, 엔드포인트 솔루션(EDR, IAM, CMDB)의 데이터를 취합하여 자산 가시성을 통합 제공하는 기술.
- **섀도우 IT(Shadow IT):** 중앙 보안·IT 부서의 승인 없이 현업 부서나 개발자가 임의로 개설하여 사용하는 클라우드 인스턴스, SaaS 서비스 등 미관리 자산.
- **CTEM 연계:** 공격표면관리(ASM)를 5단계 지속적 위협 노출 관리(CTEM)의 자산 탐색 및 우선순위화 핵심 엔진으로 활용.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 공격자가 침투 경로로 악용할 수 있는 조직 내·외부의 모든 디지털 자산, 연결 통로, 취약 구성, 섀도우 IT를 지속적으로 식별·평가·축소하는 선제적 보안 관리 체계 |
| 목적 | 가시성 사각지대(Blind Spot) 제거, 미관리 자산의 비인가 노출 차단, 침해 사고 발생 확률 및 공격 비용 극대화 |

## Ⅱ. 공격표면관리(ASM)의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 공격자 관점 정찰 | 내부 방화벽 설정에 안주하지 않고 외부 해커의 정찰(Reconnaissance) 시각에서 탐색 | OSINT, DNS 브루트포스, 인증서 투명성(CT) |
| 에이전트리스 탐색 | 타깃 시스템에 별도 소프트웨어 에이전트 설치 없이 외부 네트워크 스캔 및 API 연동 | 비간섭 포트 스캔, Shodan/Censys 연동 |
| 섀도우 IT 식별 | 개발자가 임시 배포한 클라우드 버킷, 테스트 서버, 레거시 서브도메인 자동 추적 | 서브도메인 탈취(Takeover) 탐지 |
| 지속적 실시간 가시성 | 연례 1회 모의해킹을 탈피하여 365일 24시간 실시간 변화 추적 및 경보 발령 | 변경 감지 엔진, 웹훅 연동 |

## Ⅲ. ASM 아키텍처 및 5단계 운영 프로세스

```text
[ 1. 자산 탐색 (Asset Discovery) ] ─── EASM (도메인, IP, 포트, 인증서) + CAASM (내부 API)
       │  (인터넷 노출 자산, 섀도우 클라우드, 서드파티 연결 탐지)
       ▼
[ 2. 인벤토리화 (Asset Contextualization) ] ── CMDB / 클라우드 태그 / 소유자 매핑
       │  (자산의 비즈니스 중요도, 관리 부서, 서비스 맥락 부여)
       ▼
[ 3. 취약점 및 위험 평가 (Risk Assessment) ] ─ CVE + CVSS + EPSS + CISA KEV
       │  (원격 코드 실행 가능 여부, 미인증 접근, 설정 오류 평가)
       ▼
[ 4. 우선순위화 (Prioritization) ] ─── 비즈니스 영향도 × 익스플로잇 가능성
       │  (실제 침투 경로가 형성된 고위험 노출 선별)
       ▼
[ 5. 조치 및 모니터링 (Remediation & Monitoring) ] ── SOAR / ITSM / 방화벽 차단
```

| 단계 | 주요 활동 내용 | 적용 기술 및 도구 |
|---|---|---|
| 1. 자산 탐색 | 조직과 연관된 모든 IP 대역, 도메인, SaaS, 클라우드 자산 자동 식별 | DNS 분석, BGP 라우팅 테이블, OSINT |
| 2. 인벤토리화 | 발견된 자산의 소유 부서 및 비즈니스 애플리케이션 연관관계 매핑 | CAASM, CMDB 동기화, 클라우드 메타데이터 |
| 3. 위험 평가 | 오픈 포트 취약점, SSL/TLS 인증서 만료, 기본 관리자 페이지 노출 점검 | 취약점 스캐너, 프로토콜 핸드셰이크 |
| 4. 우선순위화 | 실제 공격자가 도달 가능하고 비즈니스 피해가 큰 치명적 노출 선별 | 공격 경로 분석(Attack Path), EPSS |
| 5. 교정 및 모니터링 | 불필요 포트 폐쇄, 방화벽 차단 룰 적용, 개발팀 패치 티켓팅 | Jira, ServiceNow, SOAR 플레이북 |

## Ⅳ. EASM vs CAASM vs 전통적 취약점 평가(VA) 비교

| 구분 | 외부 공격표면관리 (EASM) | 사이버자산 공격표면관리 (CAASM) | 전통적 취약점 평가 (VA) |
|---|---|---|---|
| 관점 및 위치 | 조직 외부 (인터넷에서 조직을 관찰) | 조직 내부 (API를 통한 내부 자산 통합) | 내부/외부 지정된 특정 대역 대상 |
| 데이터 수집 | OSINT, 외부 네트워크 스캐닝, DNS | EDR, IAM, CSPM, CMDB API 통합 | 스캐너(Nessus, Qualys) 에이전트/크리덴셜 |
| 주요 관리 대상 | 도메인, 미등록 포트, 섀도우 IT, 클라우드 버킷 | 전체 엔터프라이즈 자산(사용자, 디바이스, 앱) | 알려진 자산의 소프트웨어 CVE 취약점 |
| 배포 방식 | 에이전트리스 (설치 없음) | API 기반 커넥터 연동 | 에이전트 설치 또는 관리자 권한 필요 |
| 핵심 가치 | 외부 침투 공격 표면의 조기 축소 | 전사 자산 인벤토리 단일 진실 공급원(SSOT) | 기보유 자산의 패치 누락 식별 |

## Ⅴ. 공격표면관리(ASM)의 한계와 방안

| 한계 | 방안 |
|---|---|
| 외부에서 자동 탐색된 자산(서브도메인, 임시 IP)의 실제 소유자(Owner)가 불명확하여 취약점 조치 티켓이 표류 | 내부 CAASM 및 클라우드 태그(Tagging) 정책을 연계하여 미소유 자산 발생 시 자동 격리하거나 생성 계정으로 담당자를 자동 추적하는 시스템 구축 |
| 오토스케일링 및 컨테이너 환경에서 초/분 단위로 동적 생성·소멸되는 휘발성 클라우드 자산의 인벤토리 불일치 | CSPM 및 클라우드 감사 로그(CloudTrail) 이벤트 기반 실시간 자산 웹훅 연동으로 동적 인벤토리 자동 갱신 |
| 비즈니스 영향 분석(BIA) 없는 기계적 포트 차단 및 자산 폐쇄 시 정상 대고객 서비스 장애 유발 리스크 | 서비스 중요도에 따른 위험 등급별 자동 차단과 관리자 승인(HITL) 워크플로우를 분리하고 변경 전 카나리 검증 수행 |

## Ⅵ. 제언

```text
[ 전통적 정적 자산 관리 ]             [ ASM 기반 선제적 위험 축소 ]
연례 정기 취약점 진단 ──┐             ┌── 365일 24시간 실시간 EASM 탐색
내부 등록 자산만 관리 ┼─→ [ 침해 노출 ] ─┼── CAASM 연동 통합 섀도우 IT 가시화
포트 개방 방치 ─────────┘             └── 비즈니스 위험 기반 자동 조치 파이프라인
```

| 평가 영역 | 레거시 자산 관리 체계 | 현대적 ASM 체계 | 향후 발전 방향 |
|---|---|---|---|
| 관리 범위 | 사내 승인된 서버 중심 | 클라우드, 서드파티, 섀도우 IT | 공급망(Supply Chain) 전반으로 확장 |
| 탐지 주기 | 월간/분기별 일회성 진단 | 실시간 상시 이벤트 기반 탐지 | 디지털 트윈 기반 자산 토폴로지 시각화 |
| 조치 연계 | 수동 보고서 발행 및 전달 | ITSM 및 SOAR 자동 연계 교정 | 자율 에이전트 기반 공격표면 자동 무력화 |

공격표면관리(ASM)는 경계선 보안이 무너진 멀티클라우드 시대에 방어자가 공격자보다 한발 앞서 침투 경로를 지워나가는 필수 전략이며, EASM과 CAASM의 융합을 통한 완벽한 사이버 자산 가시성 확보 필수.
