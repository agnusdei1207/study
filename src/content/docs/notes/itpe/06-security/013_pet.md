## 지식 로드맵 내 현재 위치

정보보호 기술 → 개인정보 보호기술 → 안전한 데이터 처리·분석

## 30초 인출

- **본질:** PET(Privacy-Enhancing Technology)는 데이터 활용 과정의 개인정보 위험을 줄이는 기술적 통제
- **메커니즘:** 보호 목표와 위협모델 선택 → 데이터·연산·출력에 맞는 기법 적용 → 보호수준·유용성 평가
- 통찰: 한계: 보호 기술의 이름만으로 안전성을 판단하면 입력·출력·실행환경의 다른 노출을 놓침 → 방안: 위협모델에 맞춰 보호수준과 유용성을 함께 시험

<details>
<summary>핵심 용어</summary>

- **PET (Privacy-Enhancing Technology):** 개인정보 위험을 줄이면서 데이터 처리·분석·공유를 지원하는 기술적 통제
- **동형암호 (Homomorphic Encryption):** 암호문 상태에서 연산하고 복호화 시 평문에 대한 연산 결과를 얻는 암호기술
- **안전한 다자간 계산 (SMPC, Secure Multi-Party Computation):** 여러 참여자가 입력값을 서로 공개하지 않고 공동 계산하는 암호 프로토콜
- **차등정보보호 (DP, Differential Privacy):** 개별 레코드 포함 여부에 따른 출력 변화와 프라이버시 손실을 수학적으로 제한하는 프레임워크
- **영지식증명 (ZKP, Zero-Knowledge Proof):** 비밀정보 자체를 공개하지 않고 명제의 참을 증명하는 암호기술
- **신뢰실행환경 (TEE, Trusted Execution Environment):** 프로세서·플랫폼 기능을 이용해 특정 코드와 데이터 실행을 격리하는 환경
</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **PET (Privacy-Enhancing Technology)** 는 데이터 활용 과정의 개인정보 위험을 줄이는 기술적 통제 |
| 목적 | 필요한 분석·공유를 지원하면서 개인정보 노출과 추론 위험 완화 |

PET는 단일 기술이 아니며 보호 목표·데이터 구조·참여자 신뢰관계에 맞춰 선택하는 기술군.

## Ⅱ. PET 선택·검증 프로세스

```text
개인정보·업무 목적·위협 정의
               ↓
허용 가능한 노출·신뢰 가정 설정
               ↓ 기법·구성 선택
작은 범위의 시험·위험평가
         ├─ 보호·유용성 충족 → 운영·감사
         └─ 미충족 → 기법·범위 재설계
               ↓ 변경·질의 누적 시 재평가
```

| 검증 항목 | 확인 내용 |
|---|---|
| 보호 보장 | 기술의 전제와 실제 시스템 설정 간 일치 |
| 분석 품질 | 정확도·편향·서비스 성능 변화 |
| 운영 통제 | 키·개인정보·접근·감사기록 관리 |
| 누적 위험 | 반복 질의·다중 데이터 결합의 영향 |

## Ⅲ. 보호 목적별 기술 유형과 동작

```text
입력 비공개 계산 → SMPC·동형암호
출력의 개인 기여 제한 → 차등정보보호
비밀 없이 조건 증명 → 영지식증명
격리 실행 → TEE
보호 지점·위협에 따라 조합
```

| 보호할 상황 | 적합한 접근 예 | 주요 검토점 |
|---|---|---|
| 입력값을 상대방에게 공개하지 않는 공동 계산 | SMPC·동형암호 | 계산 종류·통신량·참여자 신뢰 |
| 공개 통계에서 개인 기여 추론 제한 | 차등정보보호 | 프라이버시 예산·질의 누적·정확도 |
| 비밀 자체 대신 조건 충족을 증명 | 영지식증명 | 증명 대상·검증비용·프로토콜 안전성 |
| 격리된 코드에서 민감정보 처리 | TEE·기밀컴퓨팅 | 하드웨어·펌웨어 신뢰와 부채널 위험 |



| 기술 | 작동 개념 | 보호 범위·특징 |
|---|---|---|
| 동형암호 | 암호문을 대상으로 정해진 연산 수행 | 평문 공개 없이 암호화 데이터 연산; 연산비용·기능 제한 고려 |
| SMPC | 비밀분산·암호 프로토콜로 여러 입력의 공동 함수 계산 | 참여자 간 원본 입력 공유 제한; 통신·공모 가정 고려 |
| 차등정보보호 | 통계 출력에 수학적 프라이버시 보장을 구성 | 반복 질의의 누적 손실과 데이터 정확도 관리 |
| 영지식증명 | 비밀을 공개하지 않고 명제의 참을 증명 | 최소 정보로 검증 가능; 증명 체계·설정 신뢰 확인 |
| TEE | 격리된 실행영역에서 데이터와 코드를 처리 | 실행 중 노출 감소 지원; 플랫폼·부채널 위험 검토 |

### 기술별 선택·절충

| 선택축 | 판단 기준 |
|---|---|
| 기밀성 요구 | 누가 입력·중간값·결과에 접근할 수 있는지 |
| 연산 특성 | 정확한 공동계산, 통계 공개, 조건 증명 등 필요한 기능 |
| 신뢰 가정 | 서버·하드웨어·참여기관·프로토콜 중 신뢰해야 하는 주체 |
| 성능·유용성 | 응답시간·통신량·정확도와 프라이버시 수준의 균형 |
| 운영 가능성 | 키·예산·코드·장비·감사정보의 관리역량 |

## Ⅳ. 한계와 방안

| 한계 | 해결 방안 |
|---|---|
| 특정 PET 도입만으로 모든 처리단계의 프라이버시가 보장된다고 오해 | 수집 최소화·접근통제·암호학적 처리·출력 위험관리의 역할을 위협모델로 구분하고 대표 업무에서 보호와 유용성을 함께 검증한 뒤 확대 |

## Ⅴ. 제언

대표 데이터 활용 업무의 공격자 모델과 보호 목표를 먼저 정하고 PET의 보호 효과·유용성을 함께 시험.
