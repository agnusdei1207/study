## 연관 키워드

- PET(Privacy Enhancing Technology), 동형암호(Homomorphic Encryption), 안전 다자간 연산(SMPC, Secure Multi-Party Computation)
- 영지식 증명(ZKP, Zero-Knowledge Proof), 차분 프라이버시(Differential Privacy), 연합학습(Federated Learning)
- 신뢰실행환경(TEE, Trusted Execution Environment), 보안 집계(Secure Aggregation), 프라이버시 예산(Privacy Budget)

## Ⅰ. PET의 개요

- 핵심 요약 : 데이터를 공개하지 않고도 분석, 결합, 학습이 가능하도록 암호학과 분산 연산, 통계적 노이즈를 결합한 기술군.
- 개념 : 데이터의 프라이버시 침해 위험을 줄이면서도 활용성을 유지하기 위한 기술군을 **프라이버시 강화 기술** (PET, Privacy Enhancing Technology)이라 하며, 연산 과정 보호, 분산 협업, 통계적 보호로 나뉨.
- 배경 및 필요성 : 인공지능(AI, Artificial Intelligence)과 클라우드 확산으로 의료, 금융, 위치 같은 민감 데이터의 활용 수요가 커졌지만, GDPR(General Data Protection Regulation, 유럽연합 개인정보 보호 규정)과 국내 개인정보 보호법 등 규제가 강화되어 단순 암호화나 마스킹만으로는 활용과 규제 준수를 함께 충족하기 어려움.
- 주요 목적 : 데이터 활용성과 프라이버시 보호의 상충 관계를 완화하고, 제3자를 신뢰하지 않고도 기관 간 데이터 협업을 가능하게 함.

## Ⅱ. PET의 특징 및 장점

- 핵심 요약 : 계산 중 보호, 분산 협업, 통계적 보호라는 세 가지 방식이 서로 다른 비용과 장점을 가지며, 목적에 따라 조합해 쓰는 구조.

1. 계산 중 보호 : 암호문이나 격리된 하드웨어 영역에서 연산 → 처리 중에도 원본 노출을 줄임. 대신 연산 비용이 크거나 하드웨어 신뢰에 의존함.
2. 분산 협업 : 원본을 옮기지 않고 데이터 조각이나 모델 가중치만 교환 → 기관 간 데이터 결합 장벽을 낮춤. 대신 통신 부담이 큼.
3. 통계적 보호 : 질의 결과에 수학적 노이즈를 더함 → 특정 개인의 포함 여부를 추론하기 어렵게 함. 대신 분석 정확도가 떨어짐.

## Ⅲ. PET의 구조 (흐름)

- 핵심 요약 : PET은 암호 기술, 분산 협업, 통계 기법의 세 갈래로 나뉘며, 실제 설계에서는 여러 갈래를 결합하는 구조.
- **동형암호** (Homomorphic Encryption) : 암호문 상태에서 덧셈과 곱셈을 수행해 평문을 노출하지 않고 연산하는 기술.
- **안전 다자간 연산** (SMPC, Secure Multi-Party Computation) : 각 참여자가 비밀 조각만 나누어 가지고 공동 연산 결과만 얻는 기술.
- **영지식 증명** (ZKP, Zero-Knowledge Proof) : 명제가 참이라는 사실만 증명하고 세부 정보는 공개하지 않는 기술.
- **연합학습** (Federated Learning) : 원본 데이터를 모으지 않고 로컬 장치에서 학습한 모델 가중치만 모아 전역 모델을 갱신하는 방식.
- **신뢰실행환경** (TEE, Trusted Execution Environment) : CPU 내부에 격리된 실행 영역을 만들어 외부에서 평문 데이터와 연산 과정을 들여다볼 수 없게 하는 하드웨어 기반 기술.

```text
[ PET 분류 ]

프라이버시 강화 기술 (PET)
      ↓
1. 암호학적 연산 보호
   동형암호, 영지식 증명, TEE
2. 분산 협업
   SMPC, 연합학습
3. 통계적 보호
   차분 프라이버시, 가명·익명화
```

```text
[ 하이브리드 학습 설계 예 ]

기관 내부 원본 데이터 보관
      ↓
TEE 안에서 로컬 모델 학습
      ↓
보안 집계 (Secure Aggregation)
      ↓
차분 프라이버시 노이즈 주입
      ↓
전역 모델 갱신
```

## Ⅳ. PET의 비교

- 핵심 요약 : 기술마다 보호 대상과 성능 부담이 달라, 연산 부담이 큰 기술과 정확도를 낮추는 기술을 용도에 맞게 골라야 함.

| 비교 항목 | 동형암호 (FHE, Fully Homomorphic Encryption) | SMPC | 차분 프라이버시 (DP, Differential Privacy) | TEE |
| --- | --- | --- | --- | --- |
| 보안 근거 | 격자 기반 수학적 난제 | 비밀 분산 | 노이즈의 확률 분포 | 하드웨어 격리 |
| 데이터 상태 | 암호문 상태에서 연산 | 조각 데이터로 연산 | 질의 결과에 노이즈 추가 | 격리 영역 안에서 평문 연산 |
| 성능 부담 | 매우 큼 | 참여자 간 통신 부담 큼 | 낮음 | 상대적으로 낮음 |
| 주요 한계 | 연산 지연과 부트스트래핑 비용 | 참여자 수가 늘면 통신 병목 | 정확도 저하 | 부채널 공격 취약성 |
| 대표 활용 | 암호문 상태의 외부 분석 | 기관 간 이상거래 탐지 결합 | 통계 결과 공개 | 기밀 컴퓨팅과 AI 추론 |

- 선택 기준 : 연산 지연이 허용되는지, 참여자 간 통신이 가능한지, 정확도 저하를 감수할 수 있는지를 기준으로 기술을 고르고, 단일 기술의 약점은 다른 기술로 보완.

## Ⅴ. PET의 한계와 방안

- 핵심 요약 : 연산 지연, 연합학습의 공격, 하드웨어 부채널 취약성을 근사 연산, 보안 집계, 소프트웨어 대응으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 동형암호의 연산 지연과 **부트스트래핑** (Bootstrapping) 비용 | 잡음 제거 과정에서 자원 사용이 커져 실시간 처리가 어려움 | 머신러닝 연산에 맞는 근사 동형암호(CKKS) 선택, 가속기 도입 검토 | 질의당 처리 지연 시간 |
| 연합학습의 **데이터 중독 공격** (Data Poisoning)과 모델 역공학 | 악성 노드가 오염된 그래디언트를 보내거나, 그래디언트로 원본 데이터를 복원하려는 시도 | 보안 집계와 차분 프라이버시 노이즈 병행, Krum 같은 비정상 갱신 필터링 | 이상 갱신 탐지 건수 |
| TEE의 부채널 공격 | Spectre, Meltdown 계열 공격으로 격리 영역의 데이터가 유출될 수 있음 | 마이크로코드와 펌웨어 최신 패치, 상수 시간 구현, ZKP와 교차 검증 | 패치 적용률 |

## Ⅵ. PET에 대한 기술사적 제언

- 핵심 요약 : 원본을 옮기지 않는 분석 방식의 실증, 라이브러리 검증 체계, 프라이버시 예산 관리를 통해 PET을 실제 운영 기준으로 정착시키는 방향.

공공과 금융 분야의 데이터 결합 기관은 원본 데이터를 이동하지 않는 분석 방식을 단계적으로 실증해, 데이터 결합의 기본 방식을 원본 전송에서 연산 위임으로 바꾸는 것이 바람직하다.

PET 오픈소스 라이브러리를 도입할 때는 보안성 검증과 버전 관리 기준을 정해, 구현 결함이 운영 환경에 그대로 들어가지 않도록 거버넌스를 두어야 한다.

차분 프라이버시를 적용하는 조직은 **프라이버시 예산** (Privacy Budget, ε)의 누적 소진을 모니터링해, 같은 데이터에 대한 질의 횟수를 통제하는 체계를 함께 운영해야 한다.

## Ⅶ. 결론

- 핵심 요약 : PET은 데이터를 드러내지 않고 활용하는 암호, 분산, 통계 기술의 묶음으로, 활용과 보호의 상충을 완화하는 수단.
- 시사점 : 단일 기술은 각자 성능, 통신, 정확도의 한계를 지니므로 목적에 맞춘 조합 설계와 예산 통제가 실효성을 좌우함.
