## Ⅰ. PET(개인정보 강화 기술)의 개요

- **개념** : 데이터의 프라이버시 침해 리스크를 원천적으로 차단하면서도 데이터의 결합, 통계 분석, 머신러닝 모델 학습 등 유용성을 극대화하기 위해 암호학, 분산 컴퓨팅, 통계적 노이즈 기법을 결합한 차세대 프라이버시 보호 엔지니어링 기술군.
- **배경 및 필요성** : AI 및 클라우드 확산으로 민감 데이터(의료, 금융, 위치) 활용 수요가 급증하는 반면, GDPR 및 개보법 등 글로벌 프라이버시 규제가 강화되어 기존의 단순 암호화나 마스킹으로는 법적·기술적 한계 봉착.
- **핵심 목적** : 데이터 활용(Data Utility)과 프라이버시 보호(Data Protection)의 상충 관계(Trade-off) 극복, 제3자 신뢰 없는 데이터 협업 및 규제 준수 달성.

## Ⅱ. PET(개인정보 강화 기술)의 핵심 아키텍처 및 동작 메커니즘

PET은 계산 과정에서 원본 데이터를 보호하는 암호 기술(동형암호, 영지식증명, SMPC)과 통계적 추론 공격을 차단하는 기법(차분 프라이버시), 그리고 분산 학습(연합학습)으로 상호 보완적 생태계를 형성함.

```text
[ PET(프라이버시 강화 기술)의 핵심 분류 및 아키텍처 ]

  +-----------------------------------------------------------------+
  |                PET (Privacy Enhancing Technology)               |
  +--------------------------------+--------------------------------+
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
  [ 1. 암호학적 연산 보호 ]    [ 2. 분산 협업/신뢰 분산 ]  [ 3. 통계적 보호 ]
  - 동형암호 (FHE)             - 안전 다자간 연산(SMPC)    - 차분 프라이버시(DP)
    (복호화 없이 암호문 연산)    (데이터 공유 없이 결합연산)  (질의 결과에 노이즈 주입)
  - 영지식 증명 (ZKP)          - 연합학습 (Federated L.)   - 가명/익명화
    (원문 비공개 무결성 증명)   (가중치만 전송 분산학습)     (k, l, t 비식별)
  - 신뢰실행환경 (TEE)
    (CPU 하드웨어 엔클레이브 격리 연산)
```

- **동형암호(Homomorphic Encryption)** : 암호화된 상태 그대로 덧셈과 곱셈 연산을 수행하여 원본 평문을 클라우드 제공자에게 일체 노출하지 않고 분석.
- **안전 다자간 연산(SMPC)** : 데이터를 비밀 분산(Secret Sharing)하여 여러 참가자가 자신의 원본 데이터를 상대방에게 공개하지 않고 공동의 연산 결과만 도출.
- **영지식 증명(ZKP)** : 특정 명제가 참이라는 사실 외에는 명제의 세부 정보(비밀번호, 자산 규모 등)를 일체 공개하지 않고 진위 여부를 증명.
- **차분 프라이버시(Differential Privacy)** : 데이터셋에 단일 개인의 포함 여부가 질의 결과에 영향을 미치지 않도록 수학적 노이즈(Laplace/Gaussian)를 주입.
- **연합학습(Federated Learning)** : 중앙 서버로 원본 데이터를 수집하지 않고 각 로컬 디바이스에서 학습된 모델 가중치(Gradient)만 수집하여 글로벌 모델 갱신.

## Ⅲ. PET(개인정보 강화 기술)의 세부 구성 요소 및 비교 분석

| 비교 기술 | 동형암호 (FHE) | 안전 다자간 연산 (SMPC) | 차분 프라이버시 (DP) | 신뢰실행환경 (TEE) |
| --- | --- | --- | --- | --- |
| 보안 근거 | 수학적 격자 난제 (RLWE) | 정보이론적 비밀 분산 | 수학적 노이즈 확률 분포 | 하드웨어 보안 칩셋 격리 |
| 데이터 상태 | 암호화 상태 연산 (Data-in-Use) | 데이터 분할 조각 연산 | 질의 결과값 변형 | 엔클레이브 메모리 내 평문 연산 |
| 성능 오버헤드 | 매우 높음 (수백~수천 배 지연) | 네트워크 통신 병목 큼 | 매우 낮음 (즉각 연산) | 낮음 (네이티브 수준 성능) |
| 주요 한계점 | 부트스트래핑 연산 복잡도 | 참여자 간 대규모 네트워크 대역폭 | 노이즈로 인한 분석 정확도 저하 | 하드웨어 부채널 공격 취약성 |
| 대표 활용처 | 클라우드 아웃소싱 암호 분석 | 금융사 간 이상거래(FDS) 결합 | 빅데이터 통계 공개, 애플/구글 | 기밀 컴퓨팅, TEE 기반 AI 추론 |

- PET의 단일 기술은 각각 연산 성능, 통신 비용, 정확도 저하의 단점을 지니므로, TEE 내부에서 연합학습을 구동하고 결과에 차분 프라이버시를 결합하는 하이브리드 PET 설계가 글로벌 표준임.

## Ⅳ. PET(개인정보 강화 기술)의 주요 한계점 및 해결 방안

- **동형암호의 막대한 연산 지연 및 부트스트래핑(Bootstrapping) 오버헤드** :
  - **한계점** : 완전동형암호(FHE)는 잡음(Noise) 제거를 위한 부트스트래핑 과정에서 일반 평문 연산 대비 수천 배 이상의 CPU 및 메모리 자원 낭비 유발.
  - **해결 방안** : FPGA 및 전용 ASIC 하드웨어 가속기 도입, 근사 동형암호(CKKS) 알고리즘을 활용하여 머신러닝 연산에 최적화된 저잡음 파이프라인 구성.
- **연합학습 환경에서의 중독 공격(Data Poisoning) 및 모델 역공학** :
  - **한계점** : 악의적인 분산 노드가 오염된 그래디언트를 전송하여 글로벌 모델을 망가뜨리거나, 수집된 그래디언트 분석을 통해 역으로 원본 학습 데이터를 복원.
  - **해결 방안** : 그래디언트 전송 시 SMPC 기반 보안 집계(Secure Aggregation)와 차분 프라이버시 노이즈를 동시 적용하고, 비정상 그래디언트 필터링(Krum 알고리즘) 적용.
- **하드웨어 기반 TEE(Intel SGX 등)의 마이크로아키텍처 부채널 공격** :
  - **한계점** : Spectre, Meltdown, 캐시 타이밍 공격 등을 통해 TEE 엔클레이브 내부의 메모리 키와 평문 데이터가 유출되는 하드웨어 취약점 노출.
  - **해결 방안** : CPU 마이크로코드 최신 패치 및 타이밍 독립적 상수 시간(Constant-time) 알고리즘 구현, TEE와 암호학적 ZKP를 결합한 상호 보완 검증.

## Ⅴ. PET(개인정보 강화 기술) 적용 및 발전을 위한 기술사적 제언

- **공공·금융 데이터 결합 전문기관의 PET 기술 실증 확대** : 원본 데이터 결합 중심 체계에서 벗어나, SMPC와 동형암호 기반의 '데이터 미이동(Data-In-Place) 분석' 플랫폼 구축.
- **PET 오픈소스 프레임워크 표준화 및 거버넌스 수립** : OpenMined(PySyft), Microsoft SEAL, Google Differential Privacy 등 공인 라이브러리의 보안성 검증 체계 확립.
- **프라이버시 예산(Privacy Budget, ε) 관리 체계 제도화** : 차분 프라이버시 적용 시 누적 질의에 따른 정보 누출을 통제하기 위해 조직 차원의 프라이버시 예산 소진 모니터링 시스템 구축 필수.
