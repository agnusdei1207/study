---

## 1교시 10점 답안

### 1. 정의·목적

정의: PET는 개인정보 노출을 줄이면서 데이터의 안전한 처리·분석을 돕는 프라이버시 강화 기술군이다.
목적: 원본 데이터 노출과 개인정보 침해 위험을 낮추고 필요한 데이터 활용을 가능하게 한다.

### 2. 기술 유형과 절충점

| 유형 | 예시·특징 |
|---|---|
| 암호학적 | 동형암호·영지식증명·다자간계산; 보호된 상태에서 연산 |
| 데이터 변형 | 차분프라이버시·합성데이터; 공개 정보의 식별 위험 완화 |
| 하드웨어 기반 | 기밀컴퓨팅·TEE; 격리된 실행환경에서 처리 |

제안: 데이터 민감도와 허용 가능한 연산비용·정확도에 맞춰 PET를 선택한다.

## 한 줄 본질
- 원본 개인정보를 복호화하지 않고도 암호화된 상태나 통계적 노이즈가 주입된 상태에서 분석·학습을 가능하게 하는 기술군 → 프라이버시 침해 원천 방지 / 연산 속도 저하 및 유용성 손실 수반

## 핵심 용어
- 안전한 다자간 계산(SMPC): 여러 참여자가 각자의 비밀 데이터를 상대방에게 공개하지 않고도 공동의 함수 결과값을 안전하게 산출하는 분산 암호 프로토콜
- 차분 프라이버시(Differential Privacy): 질의 결과에 수학적으로 정밀하게 제어된 무작위 노이즈(라플라스 등)를 주입하여 특정 개인의 데이터 포함 여부를 숨기는 통계적 기법

## 핵심 통찰
- 완벽한 만능 PET 기술은 존재하지 않으며 각 기술마다 명확한 병목이 존재함: 동형암호는 CPU 계산량, SMPC는 네트워크 대역폭, 차분 프라이버시는 데이터 정확도 저하가 대가임
- 전통적 암호화는 저장(At-Rest)과 전송(In-Transit) 상태만 보호하지만, PET(동형암호, TEE)는 최초로 사용(In-Use) 상태의 메모리 상 연산까지 보호함
- 최근 AI 학습에서는 실제 개인정보 대신 통계적 분포를 모사한 합성데이터(Synthetic Data)를 결합하여 법적 규제 리스크를 우회하는 방식이 급부상함

## 이웃 토픽과 구분
- PET vs 전통적 암호화(AES/RSA): 전통 암호화 = 데이터를 보관·전송할 때만 암호화하고 연산 시 복호화 필수 / PET = 복호화하지 않은 암호문 상태 그대로 연산 및 검증 수행

## 문제·원인·대책
- 사례: 138회 기출 의료기관 간 환자 데이터 결합 연구 시 프라이버시 법 규제로 인한 데이터 반출 불가
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 원본 의료 데이터의 외부 전송 법적 불가 | 개인정보보호법 상 민감정보 국외/기관간 이전 제약 | 연합학습(Federated Learning) + 차분 프라이버시 결합 | 데이터는 병원 내부에 두고 모델 가중치만 암호화 공유 |
| 동형암호 적용 시 연산 속도가 수천 배 저하 | 다항식 암호문 링 연산 및 부트스트래핑(Bootstrapping) 오버헤드 | 암호화 가속기(GPU/FPGA QPU) 도입 및 덧셈·곱셈 횟수 제한(LEVELED HE) | 실시간 트랜잭션 연산 시간 단축 및 실용성 확보 |

## 이렇게 출제된다
- 제134회 1교시 11번: "개인정보 보호 강화기술(Privacy Enhancing Technology: PET)의 개념과 주요 기술 요소를 설명하시오." → 요구 포인트: Ⅰ 정의 + Ⅲ 3대 분류(동형암호, SMPC, 차분프라이버시 등)
- 제138회 4교시 6번: "인공지능(AI) 기술의 확산으로 데이터의 가치가 증대됨에 따라, 프라이버시를 보호하면서도 데이터의 활용성을 극대화할 수 있는 개인정보 보호 강화기술(PET: Privacy Enhancing Technology)이 주목받고 있다. 다음 내용을 설명하시오." → 요구 포인트: Ⅲ 주요 기술 메커니즘 + Ⅵ AI 데이터 파이프라인 적용 방안

## 내 의견
- [단일 PET 기술의 무리한 강제 도입 실패] 연산 부하가 극심한 동형암호만을 전사 DB에 적용하려다 응답 지연으로 시스템이 중단되는 설계 실패 다수 발생 → 나라면: 메모리 보호가 필요한 고속 연산은 Intel SGX 기반 TEE 기밀컴퓨팅으로 처리하고, 외부 기관과의 다자간 집계는 SMPC, 외부 AI 모델 학습 데이터셋 공개에는 차분 프라이버시 합성데이터를 적용하는 하이브리드 PET 파이프라인을 구축
