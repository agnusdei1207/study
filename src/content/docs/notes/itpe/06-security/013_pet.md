## 30초 인출

- **본질:** 데이터의 수집, 저장, 처리, 공유 전 과정에서 개인정보 침해 위험을 최소화하면서 데이터의 분석적 유용성을 극대화하는 암호·컴퓨팅 기술군
- **메커니즘:** 저장·전송 암호화를 넘어 연산 중(Data-in-Use) 상태의 원본 노출을 차단하는 동형암호(HE), 비밀분산(SMPC), 차등정보보호(DP), 영지식증명(ZKP), TEE 적용
- 통찰: FHE와 SMPC의 극심한 연산·통신 오버헤드 및 DP 프라이버시 예산 소진 문제를 극복하기 위해 FPGA 하드웨어 가속과 합성 데이터 하이브리드 결합 필수

<details>
<summary>핵심 용어</summary>

- **동형암호 (Homomorphic Encryption):** 데이터를 암호화한 상태에서 복호화 없이 덧셈, 곱셈 등 수학적 연산을 수행할 수 있는 차세대 암호 기술
- **안전한 다자간 계산 (SMPC, Secure Multi-Party Computation):** 비밀 분산(Secret Sharing)을 통해 여러 참여자가 자신의 입력 데이터를 공개하지 않고 공동의 연산 결과를 도출하는 프로토콜
- **차등정보보호 (DP, Differential Privacy):** 질의 결과에 수학적으로 제어된 라플라스/가우시안 노이즈를 추가하여 개별 데이터의 포함 여부를 추론할 수 없도록 제한하는 메커니즘
- **영지식증명 (ZKP, Zero-Knowledge Proof):** 증명자가 자신이 알고 있는 비밀 정보(Witness)를 검증자에게 직접 공개하지 않고도 그 명제가 참임을 증명하는 암호학적 기법
- **기밀 컴퓨팅 (Confidential Computing / TEE):** CPU 하드웨어 기반의 보안 엔클레이브(Enclave) 내에서 메모리를 실시간 암호화하여 OS나 하이퍼바이저로부터 실행 중 데이터를 격리
</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **PET(Privacy Enhancing Technology)** 는 데이터 생애주기 전반에서 개인정보 및 민감 데이터를 보호하면서도 데이터의 결합, 분석, 공유 등 비즈니스 활용 가치를 보존하는 암호학·소프트웨어·하드웨어 보안 기술의 총칭 |
| 목적 | 데이터 3법 및 GDPR 등 규제 준수, 제3자 신뢰 없이 안전한 이종 산업 간 데이터 결합, 연산 중(Data-in-Use) 데이터 유출 방지 및 AI 모델 학습 프라이버시 보장 |

기존의 정적 가명·익명화 기법이 재식별 공격에 취약함에 따라, 수학적 증명 및 하드웨어 격리 기반의 능동적 보호 체계로 진화.

## Ⅱ. PET의 특징

| 특징 | 설명 | 기술적 가치 |
|---|---|---|
| **Data-in-Use 보호** | 저장(At-Rest), 전송(In-Transit)뿐 아니라 메모리 상 연산 중 데이터 보호 | 클라우드 서비스 제공자(CSP)도 원본 데이터를 열람 불가 |
| **수학적 보증성** | 휴리스틱 마스킹과 달리 엄밀한 수학적 한계($\epsilon$-차등정보보호, 정보이론적 안전성) 제공 | 재식별 공격 시도에 대한 정량적 리스크 산출 가능 |
| **프라이버시-유용성 절충** | 보호 수준을 높일수록 데이터 분석 왜곡 또는 연산 비용 증가 | 비즈니스 요구사항에 맞춘 파라미터 최적화 요구 |
| **융합 적용성** | 단일 기술 단독 사용보다 TEE + DP, FHE + SMPC 등 상호 보완적 조합 | 성능 병목 완화 및 다계층 심층 방어 달성 |

## Ⅲ. PET 아키텍처 및 5대 핵심 기술

```text
[연산 중(Data-in-Use) 보호를 위한 PET 핵심 기술 스펙트럼]

       +-------------------------------------------------------+
       |               PET (프라이버시 강화 기술)              |
       +---------------------------+---------------------------+
                                   |
         +-------------------------+-------------------------+
         |                                                   |
 [암호학적 알고리즘 기반]                              [하드웨어 격리 기반]
         |                                                   |
 +-------+-------+-------+                           +-------+-------+
 | 동형암호 (HE) | SMPC  |                           |  TEE / 기밀   |

 +---------------+-------+                           +---------------+

```

### 1. 5대 핵심 PET 기술 메커니즘 상세

| 기술 명칭 | 핵심 동작 메커니즘 | 주요 활용 시나리오 |
|---|---|---|
| **동형암호 (HE)** | 격자 기반 암호(LWE)를 활용하여 $Enc(m_1) \oplus Enc(m_2) = Enc(m_1 + m_2)$ 성질 만족. 부분(PHE), 준(SHE), 완전(FHE) 동형암호로 구분 | 암호화된 상태의 의료 CT/MRI 진단 AI 추론, 금융 신용평가 점수 산출 |
| **안전한 다자간 계산 (SMPC)** | 샤미르 비밀 분산(Shamir's Secret Sharing) 또는 난독화 회로(Garbled Circuits)를 통해 각 참여자 비밀 $x_i$ 노출 없이 $f(x_1, \dots, x_n)$ 공동 연산 | 복수 은행 간 사기 탐지(FDS) 공동 룰셋 실행, 기업 간 교집합(PSI) 계산 |
| **차등정보보호 (DP)** | 질의 응답 $f(D)$에 개인의 기여도에 비례하는 민감도($\Delta f$) 기반 라플라스/가우시안 노이즈 주입 ($Pr[\mathcal{M}(D) \in S] \le e^\epsilon Pr[\mathcal{M}(D') \in S]$) | 통계청 인구조사 마이크로데이터 공개, 빅테크 사용자 원격 텔레메트리 수집 |
| **영지식증명 (ZKP)** | 증명자(Prover)가 검증자(Verifier)에게 완전성(Completeness), 건전성(Soundness), 영지식성(Zero-Knowledge)을 만족하는 수학적 증거(zk-SNARKs) 제시 | 실명 노출 없는 성인 인증, 블록체인 프라이빗 트랜잭션, DID 자격 증명 |
| **기밀 컴퓨팅 (TEE)** | 인텔 SGX, AMD SEV, ARM TrustZone을 활용해 CPU 캐시/메모리 암호화 및 하드웨어 원격 검증(Remote Attestation) 수행 | 클라우드 환경 내 민감 DB 쿼리 실행, 비식별 데이터 결합 전문기관 인프라 |

## Ⅳ. 주요 PET 기술 심층 비교

| 비교 항목 | 완전동형암호 (FHE) | 안전 다자간 계산 (SMPC) | 차등정보보호 (DP) | TEE (기밀 컴퓨팅) |
|---|---|---|---|---|
| **보호 방식** | 암호학적 연산 | 비밀 분산 및 통신 프로토콜 | 통계적 노이즈 삽입 | 하드웨어 기반 메모리 격리 |
| **신뢰 가정** | 수학적 난제 (격자 기반) | 참여자 간 비공모 (과반 정직) | 중앙 큐레이터 또는 로컬 신뢰 | CPU 칩 제조사 (하드웨어 신뢰) |
| **연산 속도** | 평문 대비 $10^3 \sim 10^5$배 느림 | 네트워크 통신 속도에 종속 | 매우 빠름 (노이즈 추가만 수행) | 네이티브 수준 ($1.1 \sim 1.3$배 지연) |
| **데이터 왜곡** | 왜곡 없음 (정확한 연산) | 왜곡 없음 (정확한 연산) | 노이즈로 인한 통계 오차 발생 | 왜곡 없음 (정확한 연산) |
| **네트워크 부하**| 단일 서버 연산 (통신 없음) | 라운드 수 증가로 통신량 폭증 | 없음 | 없음 |
| **대표 솔루션** | Microsoft SEAL, OpenFHE | MP-SPDZ, Sharemind | Google DP Library, OpenDP | Intel SGX, AMD SEV-SNP |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **완전동형암호(FHE) 및 SMPC의 극심한 연산·통신 레이턴시 병목**<br>FHE 부트스트래핑(Bootstrapping) 연산에 수 초가 소요되고, SMPC는 참여 노드 간 대역폭 소모로 인해 실시간 온라인 서비스 적용 불가 | **ASIC/FPGA 하드웨어 가속 및 Beaver Triple 오프라인 전처리**<br>NTT(수론 변환) 연산을 전용 FPGA 카드로 가속하여 FHE 레이턴시를 100배 단축하고, SMPC에서는 연산량이 큰 곱셈 삼중항(Beaver Triples) 생성을 비동기 오프라인 단계에서 사전 완료 |
| **차등정보보호(DP)의 프라이버시 예산($\epsilon$) 소진 및 유용성 파괴**<br>동일 데이터셋에 대한 지속적인 분석 질의 시 컴포지션(Composition) 정리에 의해 누적 $\epsilon$이 급증하여 프라이버시 보증이 무력화되거나 과도한 노이즈로 데이터 왜곡 심화 | **Rényi 차등 프라이버시(RDP) 합성 및 생성형 합성 데이터(Synthetic Data)**<br>엄격한 누적 예산 계산을 지원하는 RDP 분석 기법을 적용하고, DP 기반 조건부 생성 모델(DP-CTGAN)을 통해 원본 통계 분포를 복제한 고품질 인공 합성 데이터를 생성하여 원본 질의를 전면 차단 |

## Ⅵ. 제언

```text
[산업 데이터 공유를 위한 PET 다계층 하이브리드 아키텍처]

 +--------------------+     +---------------------+     +--------------------+
 | 원본 데이터 소스   | --> | TEE + DP 결합 연산  | --> | ZKP 기반 검증 공개 |
 | 분산 노드 (Local)  |     | 기밀 엔클레이브 분석|     | 위변조 없는 증명서 |
 +--------------------+     +---------------------+     +--------------------+
```

| 도입 단계 | 대상 업무 영역 | 권장 PET 조합 |
|---|---|---|
| **1단계: 규제 대응** | 이종 데이터 간 가명 결합 | TEE 기반 격리 인프라 + 결합 키 암호화 |
| **2단계: 데이터 개방** | 공공·금융 통계 API 공개 | 차등정보보호(DP) 노이즈 주입 + 합성 데이터 제공 |
| **3단계: 분산 협업** | 다자간 AI 모델 공동 학습 | 연합학습(FL) + SMPC 그래디언트 집계 + 동형암호 |

단일 PET 기술에 의존하기보다, 성능이 우수한 TEE와 수학적 안전성을 보장하는 DP 및 ZKP를 상호 결합한 하이브리드 프라이버시 아키텍처 구축 권장.
