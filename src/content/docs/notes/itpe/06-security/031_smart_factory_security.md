- **본질:** **스마트팩토리 보안**은 연결된 제조 설비·데이터·제어 경로의 사이버 위험을 관리하는 활동
- **메커니즘:** 자산과 통신 경로 식별 → 위험에 맞는 접근·분리·감시 통제 → 공정 영향 확인·복구
- **설계 기준:** 보안 통제의 성능 영향과 생산 안전·신뢰성 검토

<details>
<summary>핵심 용어</summary>

- **스마트팩토리 보안:** 연결된 제조 설비·데이터·제어 경로를 보호하면서 공정 위험을 관리하는 활동
- **IIoT (Industrial Internet of Things):** 제조 현장의 장비·센서를 연결해 공정 데이터를 수집·교환하는 기술
- **OT (Operational Technology):** 물리 설비·공정을 감시하거나 변경하는 장치·시스템
- **IT (Information Technology):** 정보의 저장·처리·전달을 다루는 컴퓨팅 기술
- **MES (Manufacturing Execution System):** 제조 현장의 생산 실행·실적 정보를 관리하는 시스템
- **NIST (National Institute of Standards and Technology):** 미국 국립표준기술연구소
- **제조 프로파일:** 제조 환경의 목표와 위험에 맞춰 보안 프레임워크 적용을 구체화한 참고자료

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **스마트팩토리 보안**은 연결된 제조 설비·데이터·제어 경로의 사이버 위험을 관리하는 활동 |
| 목적 | 공정의 안전·신뢰성·연속성을 해치지 않는 정보보호 |

```text
스마트팩토리 보안 범위
├── 운영 대상: 설비·센서·제어기
├── 정보 경로: OT망·엣지·MES·분석 플랫폼
└── 외부 경계: 공급자 계정·원격 유지보수
```

세 갈래는 보호할 자산, 그 사이의 통신 경로, 공장 외부에서 들어오는 접속 경계의 구분

## Ⅱ. 연결 확장과 보호 경계

| 연결 지점 | 보호 대상 | 경계 설계 |
|---|---|---|
| 현장 설비·IIoT (Industrial Internet of Things) | 제어기·센서·로봇·펌웨어 | 자산 식별, 변경·업데이트 검증 |
| OT (Operational Technology)와 엣지 | 제어 통신·원격정비 경로 | 구간별 통신 허용, 관리 접속 분리 |
| MES (Manufacturing Execution System)·기업 IT | 작업 정보·생산 데이터·계정 | 업무상 필요한 데이터·명령만 연계 |
| 외부 공급자 | 유지보수 계정·도구·업데이트 | 승인·시간 제한 접속과 변경 기록 |

## Ⅲ. 주요 위협과 대응

| 위협 경로 | 공정 영향 | 핵심 대응 |
|---|---|---|
| 취약 계정·장치 침해 | 설비 설정 변경·생산 중단 | 개별 계정·최소 권한·검증된 업데이트 |
| 평면망·불필요한 통신 | 제어 구간으로 침해 확산 | 업무 흐름에 맞춘 망 분리·허용목록·수동형 감시 |
| 원격 유지보수 | 비인가 명령·계정 악용 | 중계 지점·다중 인증·승인·세션 기록 |
| 랜섬웨어·데이터 손상 | 생산·복구 지연 | 분리된 백업·복구 시험·운영 연속성 계획 |

```text
현장 자산 목록 → 통신·계정 경계 설정 → 수동 감시·이상 확인
                                           ↓
                               공정 영향 평가 → 안전한 복구
```

## Ⅳ. 생애주기 운영

| 단계 | 핵심 활동 |
|---|---|
| 설계·도입 | 자산·데이터 흐름·안전 요구 분석, 보안 통제의 성능 영향 확인 |
| 운영·변경 | 계정·통신·패치 변경 승인, 제조사 지원 범위와 시험 결과 기록 |
| 대응·복구 | 공정 안전 상태 확보, 백업·수동운전·생산 재개 조건 검증 |

NIST의 제조 프로파일은 제조 환경에 맞춘 위험기반 참고자료이며 기존 표준·지침을 대체하지 않는 자율 적용 경로

## Ⅴ. 한계와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모든 생산 셀에 같은 순서로 통제를 적용하면 공정 중요도와 안전 요구 차이를 반영하기 어려움 | 생산 중단·안전 영향이 큰 셀부터 위험을 평가하고, 해당 셀의 원격접속 경계와 복구 요구를 우선 설계 |
| 외부 접속·장수명 설비의 변경 이력이 분산되면 침해 경로와 복구 상태 파악 곤란 | 자산·계정·통신·변경 기록을 생산 셀 단위로 연결하고 복구 훈련으로 검증 |
