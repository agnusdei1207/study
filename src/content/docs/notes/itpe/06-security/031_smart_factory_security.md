## 답안 골격
```text
[스마트팩토리 보안] ◀━━ 머리: Ⅶ 내 의견 (초연결 생산라인 안전을 위한 OT 제로트러스트 + 엣지 AI 기반 변칙 제어 탐지)
 ┃
 ┣━ Ⅰ 개요 ───── 제조업의 디지털 전환(DX)과 5G·IoT·클라우드 융합 → 제조 설비와 엔터프라이즈망 연결로 인한 사이버 공격 표면 확대
 ┣━ Ⅱ 특징 ───── 초연결성(IoT/5G) · 실시간성 및 무중단 요구 · 이기종 프로토콜 혼재 · 랜섬웨어 표적 공격(생산 라인 볼모)
 ┣━ Ⅲ 구조 ───── 제조 디바이스단(센서/로봇) · 네트워크단(5G 특화망/TSN) · 플랫폼단(MES/ERP/스마트팩토리 플랫폼) · 보안 관제단
 ┣━ Ⅳ 흐름 ───── ① 공정 이상 징후 센싱 → ② 무선 패킷 암호화 전송 → ③ 엣지 AI 이상 탐지 → ④ 비정상 설비 제어 세션 차단
 ┣━ Ⅴ 비교 ───── 전통 공장(폐쇄망, 단절된 물리 제어, 단순 시그니처) vs 스마트팩토리(초연결 클라우드 연동, AI 예지보전, 다계층 융합보안)
 ┗━ Ⅵ 실무 ───── 산업용 IoT(IIoT) 기기 펌웨어 위변조 / 생산 라인 타깃 랜섬웨어 감염 / 과기정통부 스마트공장 보안 가이드라인
```
- 필수 키워드: 스마트제조 · 퍼듀 모델 확장 · IIoT 보안 · OT 망분리 · IEC 62443 · 예지보전 AI 보안
- 기출: 125회 1교시 `스마트팩토리 보안 가이드라인 및 주요 위협` → Ⅰ·Ⅲ·Ⅵ / 120회 1교시 `스마트제조 보안 아키텍처` → Ⅱ·Ⅴ

## 한 줄 본질
- 센서, 산업용 로봇, 클라우드 AI가 결합된 초연결 제조 환경 → 외부 침투 경로 다변화로 생산 라인 중단 및 산업 기밀 도면 유출 위험 초래 → 스마트 제조 생산성 극대화 / 공격 표면 폭증 및 랜섬웨어 취약

## 핵심 그림
```text
[스마트팩토리 융합 아키텍처 및 다계층 보안 통제선]

 [ 클라우드 / 빅데이터 ] ──(AI 예지보전/MES)──> [ 보안 통제: 클라우드 연계 API 암호화 ]
            │
 [ 엣지 컴퓨팅 / 5G 특화망 ] ───────────────> [ 보안 통제: 5G 슬라이싱 격리 + ZTNA ]
            │
 [ 산업용 제어망 (OT) ]   ───────────────────> [ 보안 통제: 산업용 방화벽 + DPI 감시 ]
   - PLC, SCADA, 로봇 암
            │
 [ 현장 디바이스 (IIoT) ] ───────────────────> [ 보안 통제: 하드웨어 보안 칩(TPM/PUF) ]
   - 무선 센서, AGV (물류)
```

## 핵심 용어
- 스마트공장 보안 가이드라인: 과학기술정보통신부와 KISA가 제정한 가이드라인으로 공장 생애주기(설계·구축·운영)별 5대 보안 요구사항 규정
- IIoT(Industrial Internet of Things): 제조 현장의 상태 데이터를 실시간 수집하기 위해 공정 설비에 부착된 산업용 사물인터넷 센서 및 통신 모듈

## 핵심 통찰
- 스마트팩토리는 수백 대의 자율이동로봇(AGV)과 무선 센서가 5G 특화망(이음5G)으로 연결되어 있어, 전통적 물리적 망분리가 구조적으로 불가능함
- 해커가 공장 전체를 랜섬웨어로 암호화할 경우 1시간 중단만으로 수억~수십억 원의 피해가 발생하므로 공격자들의 최우선 타깃이 됨
- 보안 조치 설계 시 센서의 배터리 수명, 초저지연(URLLC, 1ms 이내) 통신 요건을 저해하지 않는 초경량 암호화(LEA/HIGHT) 기술 적용이 필수적임

## 이웃 토픽과 구분
- 스마트팩토리 보안 vs 전통 IT 보안: 전통 IT = 정보 유출 방지 및 기밀성 중심 / 스마트팩토리 보안 = 작업자 신체 안전(Safety) 및 설비 가용성 중심

## 문제·원인·대책
- 사례: 125회 기출 스마트 자동차 조립 라인이 랜섬웨어에 감염되어 전 생산 라인이 사흘간 가동 중단된 대형 사고
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 외부 협력업체 공급망을 통한 랜섬웨어 공장망 침투 | IT 전산망과 OT 생산망 간의 단일 방화벽 플랫 연결 | 공정 라인별 마이크로 세그멘테이션 및 산업용 일방향 게이트웨이 구축 | 감염 시 해당 셀만 격리하여 공장 전체 셧다운 방지 |
| 현장 IIoT 무선 센서의 위조 데이터 주입 | 센서 펌웨어 인증 부재 및 평문 무선 통신 | 물리적 복제방지기능(PUF) 및 경량 상호인증(IEEE 802.1AR) 탑재 | 악의적 센서 위조 및 공정 데이터 변조 차단 |

## 이렇게 출제된다
- 제125회 1교시: "스마트팩토리(Smart Factory)의 보안 위협과 정부 가이드라인의 핵심 보안 대책을 설명하시오." → 요구 포인트: Ⅰ 초연결 배경 + Ⅲ 계층별 보안 요구사항
- 제120회 1교시: "스마트제조 환경에서 무선 IoT 기기와 클라우드 연동 시 보안 고려사항을 설명하시오." → 요구 포인트: Ⅱ IIoT 특성 + Ⅵ 실무 대책

## 내 의견
- [생산 속도 우선주의로 인한 기본 보안 패스워드 방치] 스마트팩토리 구축 시 장비 세팅 편의를 위해 PLC 및 현장 센서의 기본 관리자 계정을 "admin/1234"로 방치하여 초보적 해커에게도 공장이 탈취되는 후진적 보안 사고 다발 → 나라면: 공장 스마트화 정부 지원 사업 평가 시 디바이스 초기 비밀번호 강제 변경 및 펌웨어 무결성 검증 통과를 보조금 지급의 필수 검수 조건으로 강제
