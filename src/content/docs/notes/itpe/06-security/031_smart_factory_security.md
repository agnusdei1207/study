## Ⅰ. 스마트팩토리(Smart Factory) 보안의 개요

- 개념 : 사물인터넷(IoT, Internet of Things), 인공지능(AI, Artificial Intelligence), 빅데이터, 클라우드 기술이 융합된 제조 현장에서 **사이버물리시스템** (CPS, Cyber-Physical System), 엣지 디바이스, 공정 네트워크, 제조 데이터를 사이버 공격과 생산 차질 위험으로부터 보호하는 융합 보안 체계.
- 배경 및 필요성 : 공장 자동화가 지능화·초연결화되면서 전통적 폐쇄망이었던 제조 라인이 외부 공급망, ERP(Enterprise Resource Planning), 클라우드와 실시간 연동됨에 따라 랜섬웨어 감염, 핵심 생산 공정 기밀 도난, 설비 오작동 테러 위험 급증.
- 핵심 목적 : 생산 라인의 무중단 연속성(가용성) 보장, **제조 지적재산권** (IP, Intellectual Property) 보호, 작업자 안전 확보 및 공급망 생태계 전반의 보안 신뢰성 확보.

## Ⅱ. 스마트팩토리(Smart Factory) 보안의 핵심 아키텍처 및 동작 메커니즘

스마트팩토리 보안은 디바이스/센서 계층, 현장 제어 계층, 공정 운영 계층, 엔터프라이즈/클라우드 계층의 4단계 수직적 연계 구조와 엔드투엔드 공급망 수평적 연계를 동시에 방어함.

```text
[ 스마트팩토리 융합 아키텍처 및 보안 영역 ]

  [ 클라우드 / 공급망 ] : 스마트팩토리 클라우드 플랫폼, 협력업체 공급망 포털
           │ (보안 위협: SaaS 데이터 유출, API 인증 취약점)
           ▼ [ 클라우드 보안 게이트웨이 / ZTNA ]
  [ 엔터프라이즈 계층 ] : MES (제조실행시스템), PLM, 전사 ERP
           │ (보안 위협: 랜섬웨어 감염, 내부자 도면 유출)
           ▼ [ 산업용 방화벽 / 단방향 보안 게이트웨이 ]
  [ 공정 제어 계층   ] : SCADA, DCS, HMI, 산업용 이더넷 (TSN, OPC-UA)
           │ (보안 위협: 제어 명령 변조, DoS 공격)
           ▼ [ 엣지 AI 침입탐지 / 제어 프로토콜 DPI ]
  [ 필드 디바이스    ] : 스마트 센서, 로봇(AGV/AMR), PLC, CNC 공작기계
             (보안 위협: 디바이스 위조, 펌웨어 변조, 무선 도청)
```

- **디바이스 보안** (Hardware-Root-of-Trust) : 스마트 센서 및 로봇 제어기에 **하드웨어 보안 칩** (TPM(Trusted Platform Module)/PUF)을 내장하여 **안전한 부팅** (Secure Boot) 및 기기 인증 수행.
- **통신 및 프로토콜 보안** : 실시간 제조 통신(TSN(Time-Sensitive Networking), OPC(Open Platform Communications)-UA(Unified Architecture))에 암호화와 상호 인증을 적용하고, 비인가 기기의 네트워크 접속을 차단(NAC).
- **엣지 AI 기반 이상 탐지** : 공정 센서 데이터(진동, 전류, 온도)를 엣지 AI가 실시간 모니터링하여 평소 생산 패턴과 다른 이상 설비 조작 즉시 감지.
- **엔드포인트 및 제조 도면 보안** : 설계 PC(Personal Computer) 및 작업자 HMI 콘솔에 대해 매체 제어, 화면 워터마크, DRM(Digital Rights Management)을 적용하여 첨단 제조 도면(CAD, Computer-Aided Design) 유출 방지.

## Ⅲ. 스마트팩토리(Smart Factory) 보안의 세부 구성 요소 및 비교 분석

| 비교 항목 | 전통 제조 공장 (공장 자동화) | 스마트팩토리 (지능형 공장) | 핵심 보안 요구사항 |
| --- | --- | --- | --- |
| 네트워크 환경 | 폐쇄망, 전용 시리얼 통신 (RS-485) | 초연결망, 5G 특화망(이음5G), Wi-Fi 6, IP화 | 무선 통신 암호화, 네트워크 마이크로세그멘테이션 |
| 설비 특성 | 단순 자동화 기계, 장수명 레거시 | 자율이동로봇(AMR, Autonomous Mobile Robot), AI 비전, 스마트 센서 | 임베디드 기기 무결성 검증, 펌웨어 서명 |
| 데이터 흐름 | 공장 내부 로컬 디스플레이 표시 | 실시간 클라우드 빅데이터 전송, 디지털 트윈 | 전송 구간 mTLS, 클라우드 저장 데이터 암호화 |
| 공격 표면 | 내부자 물리적 침투, USB(Universal Serial Bus) 반입 | 외부 클라우드, 원격 유지보수, 공급망 협력사 | 공급망 보안, ZTNA(Zero Trust Network Access) 기반 원격 접속 통제 |
| 피해 파급력 | 개별 라인 일시 정지 | 전 공장 셧다운, 폭발/화재, 국가 공급망 마비 | Fail-Safe 안전 설계, 신속한 비상 백업 복구 |

- 스마트팩토리는 IT(Information Technology)의 개방성과 OT(Operational Technology)의 물리적 파괴력이 결합된 환경이므로, 생산 효율을 저해하지 않으면서도 현장 디바이스부터 클라우드까지 일관된 제로트러스트 원칙을 적용해야 함.

## Ⅳ. 스마트팩토리(Smart Factory) 보안의 주요 한계점 및 해결 방안

- 5G 특화망(이음5G) 및 산업용 Wi-Fi 무선망의 **전파 스푸핑** 위험 :
  - 한계점 : 자율이동로봇(AMR)과 AGV 관제를 위해 공장 내 무선망을 사용할 때 비인가 **전파 방해** (Jamming)나 무선 감청으로 인한 물류 충돌 사고 발생.
  - 해결 방안 : 이음5G 전용 SIM 기반의 상호 인증 강제, 5G SA 슬라이싱을 통한 물류 제어망 완전 격리, **무선 침입방지시스템** (WIPS) 공장 전역 배치.
- 저사양 IoT 센서의 암호화 알고리즘 구동 부하 :
  - 한계점 : 공정 센서는 초저전력/저용량 MCU(Microcontroller Unit)를 사용하여 무거운 공개키 암호나 TLS(Transport Layer Security)를 처리하지 못해 평문 데이터 전송 불가피.
  - 해결 방안 : **경량 암호 알고리즘** (LEA, HIGHT, Ascon)을 적용하고, 센서 전면에 산업용 보안 엣지 게이트웨이를 두어 구간 암호화 대리 수행.
- 협력업체 원격 유지보수 채널을 통한 악성코드 유입 :
  - 한계점 : 설비 제조사 엔지니어가 유지보수를 위해 팀뷰어 등 원격 제어 도구를 사적으로 설치하여 공장 제어망 백도어로 전락.
  - 해결 방안 : 비인가 원격 접속 프로토콜을 네트워크 단에서 전면 차단하고, 세션 녹화와 시간 제한 승인이 결합된 원격 접속 전용 솔루션 강제.

## Ⅴ. 스마트팩토리(Smart Factory) 보안 적용 및 발전을 위한 기술사적 제언

- **스마트공장 보안 취약점 점검 가이드** (KISA, Korea Internet & Security Agency) 기반 인증제 도입 : 중기부 스마트공장 구축 지원 사업 선정 시 보안 점검 지표를 필수 평가 항목으로 지정.
- 디지털 트윈을 활용한 사이버 침해 시뮬레이션 환경 구축 : 가동 중인 실제 공장 대신 가상 트윈 환경에서 최신 랜섬웨어 침투 시나리오를 검증하고 복구 절차 훈련.
- **스마트팩토리 전용 SOC** (Security Operations Center, 보안관제센터) 구축 : IT 트래픽과 OT 공정 이상 데이터를 단일 화면에서 상호 연관 분석하는 통합 융합 관제 플랫폼 운용.
