## 연관 키워드

- 큐싱(QR Code Phishing), 큐싱(Qshing), QR 코드, 피싱, 스미싱
- 악성 APK, 도메인 위장(Typosquatting), 이메일 보안 게이트웨이, 광학 문자 인식(OCR)
- 모바일 단말 관리(MDM), 모바일 EDR, FIDO2 패스키, 동적 리다이렉션

## Ⅰ. 큐싱(QR Code Phishing)의 개요

- 핵심 요약 : QR 코드에 피싱 주소나 악성 앱 링크를 숨겨 스마트폰 스캔으로 계정과 금융 정보를 빼내는 피싱 공격.
- 개념 : 공격자가 **QR 코드** (QR, Quick Response Code)에 피싱 사이트 URL(Uniform Resource Locator)이나 악성 앱 다운로드 링크를 넣어 안내판, 주차 정산기, 이메일 등에 배치하고, 이를 스캔한 피해자의 계정 정보와 금융 정보를 탈취하는 **큐싱** (Qshing, QR Code Phishing).
- 배경 및 필요성 : 비접촉 결제, 공유 모빌리티 등에서 QR 스캔이 일상화되었지만, 사용자는 스캔 전에 QR 내부의 목적지를 육안으로 확인할 수 없어 공격에 노출됨.
- 주요 목적 : 텍스트 기반 URL 필터를 우회하고 모바일 단말을 감염시켜 OTP(One-Time Password) 탈취, 소액 결제, 사내 계정 도용을 실행.
- 국내 동향 : 과학기술정보통신부, 경찰청 등 관련 부처가 큐싱 피해에 주의를 당부하였고, 한국인터넷진흥원(KISA, Korea Internet & Security Agency)은 QR 링크를 사전에 판별하는 확인 서비스를 준비한다고 2024년 12월 발표함.

## Ⅱ. 큐싱(QR Code Phishing)의 특징 및 장점

- 핵심 요약 : 물리적 부착과 이메일 이미지 첨부, 모바일 전환이 결합되어 기존 보안망을 우회하는 공격 구조.

1. 물리적 덧붙이기 (Overstickering) : 공유 킥보드, 자전거, 식당 주문대 등 공공장소의 정상 QR 위에 악성 스티커를 덧붙임 → 불특정 다수가 무심코 스캔.
2. 이메일 필터 우회 : 본문에 텍스트 링크가 없고 QR 이미지만 첨부 → **이메일 보안 게이트웨이** (SEG, Secure Email Gateway)의 링크 기반 필터를 통과하고, 사용자가 모바일로 전환하여 PC 보안망 밖에서 열람.
3. 동적 리다이렉션 : 정상 주소로 먼저 접속시킨 뒤 모바일 환경에서만 피싱 페이지로 이동 → 자동 분석 도구의 탐지를 회피.
4. 악성 앱 유포 : 금융, 공공 안내 앱으로 위장한 **악성 APK** (APK, Android Package Kit)를 설치하게 하여 문자(SMS, Short Message Service) 수신 권한과 통화 권한을 장악.

## Ⅲ. 큐싱(QR Code Phishing)의 구조 (흐름)

- 핵심 요약 : 공격 벡터가 물리 환경과 디지털 환경에서 시작되어 모바일 단말과 C2 서버로 이어지는 흐름.
- 물리 벡터 : 공공장소의 QR 위에 악성 스티커를 덧붙여 노출.
- 디지털 벡터 : 이메일 본문에 QR 이미지를 넣어 "계정 잠김 예고" 같은 긴급 문구로 스캔 유도.
- 모바일 단계 : **도메인 위장** (Typosquatting)으로 만든 가짜 로그인 창에 계정과 2차 인증번호를 입력하거나 악성 APK를 내려받음.
- C2(Command and Control) 서버 : 탈취한 SSO 계정이나 OTP로 무단 이체와 내부망 침투 실행.

```text
[ 물리 벡터: 정상 QR 위 악성 스티커 ]
[ 디지털 벡터: 이메일 속 QR 이미지 ]
              ↓ 스마트폰 카메라 스캔
[ 모바일 단말: 피싱 사이트 또는 악성 APK ]
              ↓ 계정·OTP 입력, 앱 권한 획득
[ 공격자 C2 서버 ]
              ↓
[ 계정 도용, 무단 이체, 내부망 침투 ]
```

- 큐싱의 핵심 특징은 공격 무대가 PC의 보안망에서 개인 모바일 단말로 옮겨간다는 점이다.

## Ⅳ. 큐싱(QR Code Phishing)과 유사 공격의 비교

- 핵심 요약 : 전달 매체가 QR 이미지로 바뀌면서 기존 URL 검사와 인식 방식이 모두 달라지는 구조.

| 비교 항목 | 큐싱 | 이메일 피싱 | 스미싱 (Smishing) |
| --- | --- | --- | --- |
| 전달 매체 | QR 코드 이미지 | 이메일 본문 텍스트 링크 | SMS(Short Message Service) 링크 |
| 인식 방식 | 스마트폰 카메라 스캔 | PC 마우스 클릭 | 스마트폰 화면 터치 |
| 보안 장치 우회 | 텍스트 기반 URL 검사 우회 | 스팸 필터, URL 평판 분석에 탐지 가능 | 문자 필터와 키워드 차단에 탐지 가능 |
| 핵심 대응 | 광학 문자 인식(OCR, Optical Character Recognition) 기반 QR 검사, 모바일 EDR(Endpoint Detection and Response) | DMARC(Domain-based Message Authentication, Reporting and Conformance), SPF(Sender Policy Framework) 검증, 피싱 도메인 차단 | 발신 번호 인증, 번호 도용 차단 |

- 선택 기준 : 기업은 PC 중심의 메일 보안과 **모바일 단말 관리** (MDM, Mobile Device Management)를 포함한 모바일 보안을 함께 설계해야 하며, 공공장소 노출 여부에 따라 물리적 점검 주기를 달리함.

```text
[ 텍스트 기반 메일 검사 ]
   본문에 링크가 없어 통과
              ↓
[ 사용자가 모바일로 전환 ]
   QR 스캔 후 PC 보안망 밖에서 접속
              ↓
[ 모바일 단말에서 피싱 실행 ]
```

## Ⅴ. 큐싱(QR Code Phishing)의 한계와 방안

- 핵심 요약 : QR 내부를 사람이 확인할 수 없고, 게이트웨이의 이미지 분석 부담과 현장 부착물 관리가 어려운 구조적 한계를 기술과 절차로 보완해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 스캔 전 목적지 식별 불가 | 2차원 바코드 특성상 육안 확인이 불가능 | 디코딩된 전체 URL과 평판 결과를 보여주고 바로 열지 않는 안전 브라우징 | 경고 후 접속 중단율 |
| 게이트웨이 이미지 분석 부하 | 모든 첨부 이미지와 PDF(Portable Document Format)의 OCR 처리로 지연 발생 | QR 존재 여부를 먼저 경량 탐지하고, 검출된 메일만 심층 샌드박스 분석 | QR 검출 후 분석 지연 시간 |
| 현장 부착 스티커 관리 한계 | 다수 안내판의 악성 스티커를 사람이 상시 점검하기 어려움 | 변조 흔적이 남는 훼손 방지 재질과 정기 현장 점검 | 점검 주기 준수율, 신고 접수 건수 |

## Ⅵ. 큐싱(QR Code Phishing)에 대한 기술사적 제언

- 핵심 요약 : 메일 보안의 QR 분석 체계, 인증 수단의 전환, 대국민 예방 체계를 함께 운영해야 큐싱을 상시 관리할 수 있음.

1. 기업 이메일 보안 장비는 QR 코드를 자동 추출하고 최종 도착 주소까지 추적하는 샌드박스 기능을 갖추어야 한다.
2. 로그인 수단은 FIDO2(Fast Identity Online 2) 기반 패스키로 전환하는 것이 바람직하다. 패스키는 접속 도메인이 일치하지 않으면 인증이 거부되므로, 사용자가 가짜 사이트에 유인되더라도 자격증명이 노출되지 않는다.
3. 공공과 금융 분야에서는 전자서명이 포함된 공인 QR 체계를 검토하고, 출처 불명 QR 스캔과 앱 설치 유도에 대한 예방 수칙을 상시 홍보한다.

## Ⅶ. 결론

- 핵심 요약 : 큐싱은 QR이라는 시각 매체를 통해 보안 경계를 PC에서 모바일로 옮기는 공격 방식.
- 메일 분석, 패스키 인증, 사용자 인식을 함께 갖춘 다층 방어만이 이 우회 공격을 억제할 수 있음.
