## 연관 키워드

- 모델 전도 공격, Model Inversion Attack, 예측 출력값, 신뢰도 점수
- 멤버십 추론 공격, 모델 추출 공격, 차분 프라이버시, DP-SGD, 그래디언트 클리핑
- 출력 차분 프라이버시, 워터마킹, 쿼리 감사, 호출 제한, GAN

## Ⅰ. 모델 전도 공격의 개요

- 핵심 요약 : 학습된 모델의 출력 점수를 반복 질의해 학습 데이터의 개인 특징을 복원하는 프라이버시 공격.
- 개념 : 학습된 인공지능 모델의 **예측 출력값** (클래스별 신뢰도 벡터)을 반복 질의하여 손실을 역으로 최적화함으로써, 학습 데이터에 포함된 개인의 민감한 특징이나 이미지를 재구성하는 적대적 프라이버시 공격 (**모델 전도 공격**, Model Inversion Attack).
- 배경 및 필요성 : 상용으로 배포된 AI(Artificial Intelligence)와 ML(Machine Learning) 모델의 신뢰도 점수로부터 얼굴, 의료 정보 같은 민감 개인정보가 복원될 수 있어, 모델 배포 단계의 방어 체계가 필요해짐.
- 핵심 목적 : 비인가 공격자가 모델의 출력 정보만으로 학습 데이터의 민감 특징을 추출하는 경로를 이해하고, 이를 차단하는 설계 기준을 마련.

## Ⅱ. 모델 전도 공격의 특징 및 장점

- 핵심 요약 : 원본 데이터 접근 없이 출력 질의만으로 학습 데이터를 재구성하는 점이 공격의 위협성을 높이는 특징.

1. **블랙박스 질의** (Black-box Query) : 모델 내부 구조 없이 입력과 출력 점수만 얻어도 공격 가능 → 원본 데이터 접근 권한이 없는 외부 공격자에게도 위협.
2. 신뢰도 점수 활용 : 클래스별 확률 벡터의 미세한 변화를 손실 신호로 사용 → 레이블만 공개해도 일부 특징 복원이 가능한 구조적 위험.
3. 특징 단위 복원 : 개별 샘플이 아닌 클래스 대표 특징을 재구성 → 얼굴 윤곽이나 특정 질환 특징 같은 개인 식별 정보 노출.

## Ⅲ. 모델 전도 공격의 구조 (흐름)

- 핵심 요약 : 목표 클래스 지정에서 출력 확률 획득, 입력 역전파 최적화, 복원 판독으로 이어지는 반복 최적화 구조.

```text
[ 입력 역추적 반복 흐름 ]

임의 노이즈 입력 x 생성
      ↓
모델에 질의 → 타깃 클래스 확률 획득
      ↓
손실 계산 후 입력에 대한 그래디언트 산출
      ↓
입력 갱신 (수렴할 때까지 반복)
      ↓
복원된 입력 = 학습 데이터 특징의 근사
```

```text
[ 방어 계층 3단 구조 ]

학습 단계: 차분 프라이버시 학습 (그래디언트 클리핑·노이즈)
      ↓
출력 단계: 확률 정보 노출 제한, 노이즈 주입
      ↓
질의 단계: 쿼리 감사와 호출 제한
```

1. 목표 정의 : 복원하려는 인물이나 클래스 레이블 y를 지정.
2. 예측 확률 획득 : 입력 x에 대한 모델의 출력 확률 벡터 f(x)를 수집.
3. **경사 하강법** (Gradient Descent) 기반 역전 : 타깃 클래스의 확률이 최대가 되도록 $x^* = \arg\min_x (c(x) - \log f_y(x))$를 최적화하며, $c(x)$는 사전 지식을 반영하는 항.
4. 입력 그래디언트 역전파 : 모델 파라미터가 아닌 입력 텐서 x에 대해 오차를 역전파하여 $x \leftarrow x - \alpha \frac{\partial \mathcal{L}}{\partial x}$로 갱신.
5. 이미지 복원 및 판독 : 최적화된 $x^*$를 시각화하여 안면 윤곽, 피부색 같은 개인 식별 특징이 드러나는지 확인.

## Ⅳ. 모델 전도 공격과 유사 공격의 비교

- 핵심 요약 : 모델 전도 공격은 학습 데이터의 내용을 복원하고, 멤버십 추론은 포함 여부를 판별하며, 모델 추출은 기능을 복제한다는 점에서 목표가 다름.

| 구분 | 모델 전도 공격 (Model Inversion) | 멤버십 추론 공격 (Membership Inference) | 모델 추출 공격 (Model Extraction) |
| --- | --- | --- | --- |
| 공격 목표 | 학습 데이터의 특징과 원본 데이터 재구성 | 특정 샘플이 학습 데이터셋에 포함되었는지 판별 | 대상 모델의 기능을 복제한 모델 생성 |
| 공격자 질문 | 이 클래스의 학습 데이터는 어떤 특징을 가졌는가 | 이 데이터가 학습에 사용되었는가 | 같은 분류 성능의 모델을 만들 수 있는가 |
| 출력 결과 | 복원된 이미지, 특징 벡터, 민감 속성 값 | 포함 여부의 이진 판정 | 같은 기능을 하는 대리 모델 (Surrogate) |
| 피해 영향 | 개인정보(PII, Personally Identifiable Information) 유출 | 개인의 질병이나 서비스 이용 사실 노출 | 지식재산권(IP, Intellectual Property) 침해 |
| 핵심 방어 | **차분 프라이버시** (DP, Differential Privacy), 노이즈 주입 | 일반화 성능 강화, 과적합 억제 | API 쿼리 호출 제한, 워터마킹 |

- 선택 기준 : 학습 데이터 보호가 우선이면 차분 프라이버시를, 모델 자산 보호가 우선이면 호출 제한과 워터마킹을 중심에 둠.

## Ⅴ. 모델 전도 공격의 한계와 방안

- 핵심 요약 : 출력 완화의 우회, 학습 정확도 저하, 분산 질의 탐지 실패를 출력 노이즈, 민감 계층 선별 적용, 질의 패턴 분석으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 출력 완화책의 무력화 | 확률 반올림이나 Top-1 레이블만 반환하는 방식은 적응형 최적화와 GAN(Generative Adversarial Network) 기반 복원에 우회됨 | 출력 확률에 노이즈를 더해 노출 정밀도를 제한하는 출력 차분 프라이버시 적용 | 출력 노출 정밀도 |
| DP-SGD(Differentially Private Stochastic Gradient Descent) 학습 시 정확도 저하 | 그래디언트 클리핑과 노이즈로 추론 정확도가 크게 떨어짐 | 민감 속성을 담당하는 계층에만 선별 적용하고, 사전학습 후 파인튜닝으로 정확도 보완 | 정확도 저하율 |
| 분산 질의를 통한 우회 | 다수 계정과 프록시로 소량씩 질의하면 단일 IP 기반 차단이 탐지하지 못함 | 세션 간 질의 패턴을 분석하는 쿼리 감사, 특정 클래스에 편중된 질의의 실시간 감시 | 탐지된 분산 질의 건수 |

## Ⅵ. 모델 전도 공격에 대한 기술사적 제언

- 핵심 요약 : 학습 데이터 민감도에 따른 차분 프라이버시 기준, API 노출 관리, 배포 전 프라이버시 평가를 하나의 체계로 묶는 방향.

1. AI 서비스 기획 단계에서 학습 데이터의 민감도를 등급으로 나누고, 민감 데이터로 학습한 모델에는 차분 프라이버시를 적용하는 기준을 정책으로 정할 필요가 있음.
2. 모델을 API로 제공하는 조직은 출력 정보의 노출 수준을 업무 목적에 맞게 제한하고, 질의 로그를 정기적으로 감사하는 운영 절차를 갖추는 것이 바람직함.
3. 개인정보 보호 조직은 모델 배포 전에 학습 데이터의 개인정보 위험을 평가하는 절차를 필수 단계로 두어, 기술 방어와 정책 통제가 함께 작동하도록 할 필요가 있음.

## Ⅶ. 결론

- 핵심 요약 : 모델 전도 공격은 모델의 출력 점수만으로 학습 데이터의 개인 특징을 복원하는 프라이버시 공격.
- 시사점 : 모델의 정확도만큼 출력 노출을 관리하는 것이 보안 설계의 핵심이며, 학습 단계와 출력 단계의 방어를 함께 설계해야 함.
