## 지식 로드맵 내 현재 위치

정보보안 → 인공지능 보안 → AI 프라이버시 침해 공격(Model Inversion)

## 30초 인출

- **본질:** 배포된 머신러닝 모델의 출력값(예측 확률, 신뢰도 점수)을 분석하고 역전 최적화를 수행하여 모델 학습에 사용된 민감한 원본 데이터나 개인의 특징을 재구성하는 프라이버시 공격
- **메커니즘:** 타깃 클래스 질의 → 예측 신뢰도 벡터 수신 → 입력값에 대한 손실 함수 기울기 계산(Gradient Descent on Input) → 입력 공간 역전 최적화 → 학습 데이터 복원
- 통찰: 단순 신뢰도 은닉이나 레이블만 반환하는 방식은 생성 모델(GAN) 기반 전도 공격에 우회되므로 학습 단계에 차분 프라이버시(DP-SGD)를 적용하여 수학적 프라이버시 경계를 강제하는 원천 방어 체계 구축 필수

<details><summary>핵심 용어</summary>

- **모델 전도 공격(Model Inversion Attack):** Matt Fredrikson 등이 2015년 제안한 기법으로, 모델의 출력 확률을 역이용하여 학습에 쓰인 안면 이미지나 유전자 정보를 복원하는 공격.
- **멤버십 추론 공격(Membership Inference Attack):** 특정 데이터 샘플이 대상 모델의 훈련 데이터셋에 포함되었는지 여부(In/Out)만을 판별하는 공격.
- **차분 프라이버시(Differential Privacy, DP):** 데이터셋에 단일 데이터가 추가되거나 삭제되어도 연산 결과의 확률 분포 변화를 수학적 파라미터($\epsilon, \delta$) 이하로 제한하는 기법.
- **DP-SGD:** 모델 훈련 시 그래디언트 클리핑(Gradient Clipping)과 가우시안 노이즈 주입을 결합하여 개별 샘플의 기억(Memorization)을 방지하는 알고리즘.
- **GMI(Generative Model Inversion):** 사전 학습된 GAN의 잠재 공간(Latent Space)을 탐색하여 고해상도 학습 이미지를 사실적으로 복원하는 고도화된 전도 공격.

</details>

## 2~4교시 예상문제 (25점)

> 인공지능(AI) 프라이버시 침해 위협인 모델 전도 공격(Model Inversion Attack)의 개념과 수학적 재구성 원리를 설명하고, 멤버십 추론 공격(MIA)과의 차이점 및 차분 프라이버시(DP-SGD) 기반의 단계별 방어 전략과 한계 극복 방안을 제시하시오. (기출·제138회 1교시 13번)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 학습된 인공지능 모델의 예측 출력값(클래스별 신뢰도 벡터)을 반복 질의하여 손실 함수를 역으로 최적화함으로써 학습 데이터셋에 포함된 개인의 민감한 특징이나 이미지를 재구성하는 적대적 프라이버시 공격 |
| 목적 | 비인가 공격자가 블랙박스 또는 화이트박스 환경에서 모델 내부의 기밀 학습 데이터(의료 기록, 생체 정보, 얼굴 사진)를 무단 추출 및 복원 |

## Ⅱ. 모델 전도 공격의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 출력 기반 역공학 | 모델 내부 가중치를 알지 못하는 블랙박스 API 환경에서도 출력 확률값만으로 원본 특징 추론 | 신뢰도 점수(Confidence Score), Softmax 출력 |
| 최적화 기반 재구성 | 모델의 예측 손실을 최소화하는 방향으로 더미 입력 데이터를 경사하강법을 통해 점진적 업데이트 | $\arg\min_x \mathcal{L}(f(x), y)$ 최적화 |
| 생성 모델(GAN) 결합 | 최신 공격은 사전 학습된 생성자(Generator)의 잠재 벡터를 역전시켜 고해상도 사실적 이미지 복원 | Generative Model Inversion (GMI) |
| 개인정보 규제 위반 | 모델 배포 자체가 간접적인 개인정보 유출 통로가 되어 GDPR 및 개인정보 보호법 위반 위험 | 데이터 비식별화 무력화 |

## Ⅲ. 모델 전도 공격의 수학적 원리 및 재구성 프로세스

```text
[ 1. 초기화 단계 ]
임의의 노이즈 입력 x_0 생성 ──▶ 타깃 모델 f(x)에 질의
                                      │
                                      ▼
[ 2. 신뢰도 평가 ]
타깃 클래스 y에 대한 예측 확률 p(y|x) 획득 ──▶ 손실 함수 계산: L = 1 - p(y|x)
                                      │
                                      ▼
[ 3. 경사하강법 역전 (Gradient Descent on Input) ]
입력값 x에 대한 그래디언트 계산: ∇_x L ──▶ 입력값 업데이트: x_{t+1} = x_t - α · ∇_x L
                                      │
                                      ▼ (반복 수렴 조건 만족 시)
[ 4. 원본 이미지 복원 완료 ] ──▶ 환자의 얼굴 이미지 또는 질병 유전자 특징 시각화!
```

| 단계 | 수행 작업 | 수학적 정의 및 메커니즘 |
|---|---|---|
| 1. 목표 정의 | 복원하고자 하는 특정 인물 또는 클래스 레이블 $y$ 지정 | 타깃 클래스 $y$ 선정 |
| 2. 예측 확률 획득 | 입력 $x$에 대한 모델의 출력 확률 벡터 $f(x)$ 수집 | $f(x) = [\hat{y}_1, \hat{y}_2, \dots, \hat{y}_C]$ |
| 3. 목적함수 역전 | 모델 출력이 타깃 레이블 $y$에 최대가 되도록 하는 입력 $x$ 탐색 | $x^* = \arg\min_x (c(x) - \log f_y(x))$, $c(x)$는 사전 지식 |
| 4. 입력 그래디언트 역전파 | 모델 파라미터가 아닌 입력 텐서 $x$에 대해 오차 역전파 수행 | $x \leftarrow x - \alpha \frac{\partial \mathcal{L}}{\partial x}$ |
| 5. 이미지 복원 및 판독 | 최적화된 $x^*$를 시각화하여 학습 데이터의 개인 식별 특징 확인 | 안면 윤곽, 피부색, 눈코입 형상 복원 |

## Ⅳ. 모델 전도 vs 멤버십 추론 vs 모델 추출 공격 비교

| 구분 | 모델 전도 공격 (Model Inversion) | 멤버십 추론 공격 (Membership Inference) | 모델 추출 공격 (Model Extraction) |
|---|---|---|---|
| 공격 목표 | 학습 데이터의 **특징 및 원본 데이터 재구성** | 특정 샘플의 **학습 데이터셋 포함 여부 판별** | 대상 모델의 **기능 및 가중치를 복제한 모델 생성** |
| 질문 형태 | "이 환자의 얼굴이나 유전자 특징은 무엇인가?" | "이 환자의 데이터가 학습에 사용되었는가?" | "이 상용 AI 모델의 분류 로직을 어떻게 훔칠 것인가?" |
| 출력 데이터 | 복원된 이미지, 특징 벡터, 민감 속성 값 | 이진 판정 (In: 1, Out: 0) | 동일한 분류 성능을 내는 대리 모델(Surrogate) |
| 피해 영향 | 개인정보(PII) 유출, 프라이버시 침해 | 개인 식별 및 질병/금융 참여 사실 노출 | 지식재산권(IP) 침해, 모델 도난 |
| 핵심 방어 | 차분 프라이버시 (DP-SGD), 노이즈 주입 | 일반화 성능 강화, 과적합(Overfitting) 억제 | API 쿼리 레이트 제한, 워터마킹 |

## Ⅴ. 모델 전도 공격 방어의 한계와 방안

| 한계 | 방안 |
|---|---|
| 단순 출력단 완화책(소수점 반올림, 신뢰도 숨김 및 Top-1 레이블만 반환)은 의사결정 경계를 근사하는 적응형 블랙박스 최적화 및 GAN에 의해 무력화 | 모델 출력 확률에 라플라스 노이즈를 주입하여 출력의 수학적 상한을 통제하는 출력 차분 프라이버시(Output DP) 기법 적용 |
| 모델 훈련 시 DP-SGD(그래디언트 클리핑 + 노이즈 주입)를 적용할 경우 데이터 노이즈로 인해 모델의 추론 정확도(Utility)가 급격히 저하 | 모델 전체가 아닌 개인정보 민감 속성 계층에만 가중치를 선별 적용하는 민감도 인지형 차분 프라이버시 및 사전학습-파인튜닝 전이학습 결합 |
| 단일 IP 기반의 질의 차단 정책은 공격자가 분산 프록시 네트워크를 통해 수천 개의 계정으로 소량씩 분산 질의 시 탐지 실패 | 사용자 세션 간 시맨틱 유사 쿼리 패턴을 분석하는 쿼리 감사 엔진 구축 및 특정 클래스에 집중되는 질의 엔트로피 실시간 감시 |

## Ⅵ. 제언

```text
[ 프라이버시 취약 모델 ]               [ 차분 프라이버시 기반 강인화 모델 ]
원시 데이터 무제한 학습 ──┐           ┌── DP-SGD 기반 훈련 중 그래디언트 클리핑
정밀한 신뢰도 점수 노출 ─┼─→ [ 원본 복원 ] ─┼── 출력단 차분 노이즈 주입 및 레이블 양자화
반복 질의 무제한 허용 ──┘           └── 시맨틱 쿼리 엔트로피 분석 및 API 차단
```

| 평가 영역 | 일반 딥러닝 모델 | 완화책 적용 모델 | DP-SGD 적용 모델 |
|---|---|---|---|
| 전도 공격 내성 | 원본 이미지 고화질 복원 | 저화질 복원 가능 | 수학적으로 복원 불가능 ($\epsilon$ 보증) |
| 추론 정확도 | 최고 (100% 성능) | 우수 (98~99%) | 다소 감소 (90~95%, 튜닝 필요) |
| 컴플라이언스 | GDPR 삭제권 위반 | 감사 지적 가능 | 개인정보보호 규정 완벽 충족 |

모델 전도 공격은 배포된 인공지능 모델 자체가 학습 데이터를 기억하고 누출하는 거대한 메모리 저장소가 될 수 있음을 입증한 중대한 위협이며, 모델의 효용성과 프라이버시 간의 최적 트레이드오프를 달성하는 차분 프라이버시(DP-SGD) 내재화가 필수적 과제.
