## Ⅰ. 디지털 포렌식(Digital Forensics)의 개요

- 개념 : PC, 스마트폰, 서버, 클라우드 등 디지털 매체에 저장되거나 네트워크를 통해 전송되는 디지털 데이터를 법적 효력을 갖는 증거로 채택시키기 위해 수집, 보존, 분석, 보고하는 과학적 수사 기법이자 공학 프로세스.
- 배경 및 필요성 : 랜섬웨어 침해, 지능형 기술 유출, 금융 사기 등 모든 범죄가 디지털 환경에서 발생함에 따라 전자 증거의 취약성(위변조 및 휘발성)을 극복하고 사법 기관에 제출 가능한 법적 무결성 확보 필요성 증대.
- 핵심 목적 : 디지털 증거의 법적 **증거능력** (Admissibility) 확보, 침해사고의 **근본 원인** (Root Cause) 및 공격 경로 규명, 피해 확산 차단 및 재발 방지 대책 수립.

## Ⅱ. 디지털 포렌식(Digital Forensics)의 핵심 아키텍처 및 동작 메커니즘

디지털 포렌식은 증거 훼손을 방지하기 위한 5대 기본 원칙을 엄격히 준수하며, 준비 -> 증거 수집 -> 보존 및 이송 -> 분석 -> 보고의 표준 수명주기로 수행됨.

```text
[ 디지털 포렌식 표준 5단계 절차 및 5대 기본 원칙 ]

  [ 1. 준비/수사 의뢰 ] -> 포렌식 장비 검증, 영장 및 권한 범위 확인
           │
           ▼
  [ 2. 증거 획득/수집 ] -> 휘발성 순서(Order of Volatility) 준수
           │              하드웨어 쓰기방지기(Write Blocker) 장착, 원본 보존
           ▼
  [ 3. 보존 및 이송 ]   -> 원본 비트스트림 이미징(Bit-stream Image: Raw/E01)
           │              해시값(SHA-256) 검증, 연계보관성(Chain of Custody) 확립
           ▼
  [ 4. 정밀 분석 ]     -> 타임라인 분석, 아티팩트 복원, 슬랙 공간(Slack) 정밀 추적
           │
           ▼
  [ 5. 법정 보고서 작성] -> 전문가 의견서 작성, 법정 증언, 재현성 검증

  * 핵심 5대 원칙: 정당성, 재현성, 신속성, 연계보관성(CoC), 무결성
```

- **정당성의 원칙** : 적법 절차(Due Process)에 따라 영장 획득 및 합법적 권한 내에서 증거를 수집해야 함 (위법수집증거 배제).
- **무결성의 원칙** : 수집된 증거는 분석 과정에서 일체 변조되지 않았음을 입증하기 위해 수집 직후 **SHA-256/MD5** 해시값을 생성하고 사후 비교.
- **연계보관성의 원칙** (Chain of Custody) : 증거가 획득된 시점부터 법정 제출 시까지 취급자, 보관 장소, 이송 내역을 빈틈없이 문서로 기록.
- **재현성의 원칙** : 동일한 도구와 동일한 사본 데이터를 바탕으로 제3의 전문가가 재분석하더라도 동일한 결과가 도출되어야 함.
- **신속성의 원칙** : 시스템 전원 차단, 휘발성 메모리 소멸, 안티포렌식 로그 삭제가 발생하기 전 신속하게 증거를 획득.

## Ⅲ. 디지털 포렌식(Digital Forensics)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 라이브 포렌식 (Live Forensics) | 데드 포렌식 (Dead/Post-Mortem Forensics) | 클라우드 포렌식 (Cloud Forensics) |
| --- | --- | --- | --- |
| 대상 시스템 상태 | 전원이 켜져 실행 중인 활성 시스템 | 전원이 차단된 정지 상태의 하드디스크 | CSP 데이터센터 내 가상머신 및 컨테이너 |
| 수집 데이터 | RAM 메모리, 네트워크 연결, 활성 프로세스 | MFT, 비할당 공간(Unallocated), 슬랙 | 스냅샷, CSP 감사 로그, vFlow, 볼륨 이미지 |
| 증거 훼손 위험 | 수집 스크립트 실행으로 인한 메모리 변경 | 쓰기방지기 사용으로 무결성 보장 용이 | CSP 가상화 계층 통제 불가, 멀티테넌시 오염 |
| 주요 도구 | LiME, FTK Imager Lite, Volatility | EnCase, FTK, Autopsy, X-Ways | CloudTrail, AWS Athena, K8s Audit Log |
| 핵심 분석 기법 | 루트킷 탐지, 인메모리 프로세스 인젝션 분석 | 삭제 파일 복구, 프리페치, 레지스트리 분석 | 시간 동기화(NTP), 다중 리전 로그 상호상관 |

- 파일리스 악성코드와 메모리 상주 공격이 일반화되면서 전통적인 데드 포렌식 이전에 메모리와 활성 네트워크 상태를 보존하는 라이브 포렌식의 중요성이 결정적임.

## Ⅳ. 디지털 포렌식(Digital Forensics)의 주요 한계점 및 해결 방안

- **안티포렌식** (Anti-Forensics) 기법의 고도화로 인한 증거 인멸 :
  - 한계점 : 공격자가 **타임스탬프 변조** (Timestomp), 메모리 와이핑, 침해 흔적 안티포렌식 툴(SDelete, BleachBit)을 사용하여 로그 및 MFT 레코드 영구 파괴.
  - 해결 방안 : **VSS** (볼륨 섀도우 복사본) 및 슬랙 공간(Volume Slack) 정밀 복원, 저수준 파일시스템 저널($UsnJrnl, $LogFile) 교차 검증을 통해 타임라인 재구성.
- 클라우드 멀티테넌트 환경에서의 물리적 쓰기방지 및 전체 디스크 이미징 불가 :
  - 한계점 : 클라우드 환경에서는 하드웨어 디스크에 직접 접근할 수 없으며, 물리적 이미징 시 타 기업의 개인정보까지 침해되어 법적 분쟁 초래.
  - 해결 방안 : CSP가 제공하는 무중단 EBS/스토리지 암호화 스냅샷 복제 API를 활용하고, API 호출 로그에 전자서명을 부여하여 신뢰 체인 확보.
- **엔드투엔드 암호화** (E2EE) 및 하드웨어 보안 칩(TPM/Secure Enclave)으로 인한 복호화 불가 :
  - 한계점 : 스마트폰 및 최신 OS(Windows BitLocker, macOS FileVault)의 전체 디스크 암호화로 인해 물리적 복제 후에도 평문 획득 난항.
  - 해결 방안 : 라이브 상태에서 메모리 덤프를 통해 램(RAM)에 상주하는 암호화 키를 긴급 추출하거나, 합법적 보증 명령을 통한 클라우드 **키 에스크로** 백업 연계.

## Ⅴ. 디지털 포렌식(Digital Forensics) 적용 및 발전을 위한 기술사적 제언

- **사이버 침해사고 대응팀** (DFIR)의 실시간 EDR 텔레메트리 통합 : 사후 수사에 의존하지 않고 전사 엔드포인트의 시스템 콜 및 프로세스 트리를 실시간 시계열 데이터베이스로 기록해야 함.
- 증거 연계보관성(Chain of Custody)의 블록체인 스마트 컨트랙트화 : 증거물의 수집 시간, 해시값, 취급자를 변경 불가능한 프라이빗 블록체인에 자동 기록하여 법정 증거력 극대화.
- 클라우드 네이티브 **포렌식 자동화** (Forensics-as-Code) 구현 : 침해 발생 즉시 격리 VPC 생성, 인스턴스 격리, 메모리 덤프 및 스냅샷 생성을 Lambda로 1분 내 자동화하는 체계 수립 필요.
