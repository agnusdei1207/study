- 휘발성 순서(Order of Volatility), 쓰기 방지기(Write Blocker), 비트스트림 이미징(Bit-stream Imaging)

## Ⅰ. 디지털 포렌식(Digital Forensics)의 개요

- 핵심 요약 : 디지털 증거를 법정에서 채택될 수 있도록 수집, 보존, 분석, 보고하는 과학적 수사 공학.
- 개념 : PC, 스마트폰, 서버, 클라우드 등 디지털 매체와 네트워크에 남은 데이터를 법적 증거로 인정받도록 수집·보존·분석·보고하는 **디지털 포렌식** (Digital Forensics).
- 배경 및 필요성 : 랜섬웨어 침해, 기술 유출, 금융 사기 등 범죄 대부분이 디지털 환경에서 일어나면서, 전자 증거의 위변조와 휘발성을 극복하고 사법 기관에 제출할 수 있는 무결성을 확보할 필요가 커짐.
- 주요 목적 : 디지털 증거의 **증거능력** (Admissibility) 확보, 침해사고의 **근본 원인** (Root Cause)과 공격 경로 규명, 피해 확산 차단과 재발 방지 대책 수립.

## Ⅱ. 디지털 포렌식(Digital Forensics)의 특징 및 장점

- 핵심 요약 : 정당성, 무결성, 연계보관성, 재현성, 신속성의 다섯 원칙이 증거를 법정에서 설명 가능한 상태로 만드는 구조.

1. 정당성 : 적법 절차와 영장 범위 안에서 수집 → 위법 수집 증거 배제 원칙을 피함.
2. 무결성 : 수집 직후 **해시값** (SHA-256 등 해시 함수로 구한 고정 길이 지문)을 만들고 사후 비교 → 분석 과정에서 원본이 변조되지 않았음을 입증. MD5는 충돌 취약성이 알려져 있어 SHA-256과 병행하여 사용.
3. **연계보관성** (Chain of Custody, 증거의 취득부터 법정 제출까지 취급자·보관 장소·이송 내역을 기록하는 원칙) → 증거 흐름의 빈틈을 문서로 막음.
4. 재현성 : 같은 도구와 같은 사본으로 제3의 전문가가 재분석해도 같은 결과가 나와야 함 → 분석 결과의 객관성 확보.
5. 신속성 : 전원 차단, 휘발성 메모리 소멸, 로그 삭제 전에 증거를 먼저 확보 → **휘발성 순서** (Order of Volatility, 휘발성이 높은 증거부터 수집하는 순서)에 따라 수집.

## Ⅲ. 디지털 포렌식(Digital Forensics)의 구조 (흐름)

- 핵심 요약 : 준비, 증거 수집, 보존·이송, 정밀 분석, 보고로 이어지는 표준 5단계 수명주기.
- 증거 수집 단계에서는 **쓰기 방지기** (Write Blocker, 원본 저장장치에 대한 쓰기 명령을 차단하는 장치)를 장착하고, 저장 단계에서는 **비트스트림 이미징** (Bit-stream Imaging, 섹터 단위로 원본을 그대로 복제하는 방식)을 사용.

```text
[ 디지털 포렌식 5단계 절차 ]

1. 준비 : 수사 의뢰, 영장·권한 범위 확인
   ↓
2. 증거 수집 : 휘발성 순서 준수, 쓰기 방지
   ↓
3. 보존·이송 : 비트스트림 이미징, 해시 검증
   ↓
4. 정밀 분석 : 타임라인, 아티팩트 복원, 슬랙 영역
   ↓
5. 보고 : 전문가 의견서, 법정 증언, 재현성 검증
```

## Ⅳ. 디지털 포렌식(Digital Forensics)의 비교

- 핵심 요약 : 분석 대상의 전원 상태와 실행 환경에 따라 라이브, 데드, 클라우드 포렌식의 수집 대상과 훼손 위험이 달라지는 구도.

| 비교 항목 | 라이브 포렌식 (Live Forensics) | 데드 포렌식 (Dead Forensics) | 클라우드 포렌식 (Cloud Forensics) |
| --- | --- | --- | --- |
| 대상 상태 | 전원이 켜진 활성 시스템 | 전원이 차단된 저장장치 | CSP(Cloud Service Provider) 가상머신과 컨테이너 |
| 수집 데이터 | RAM 메모리, 네트워크 연결, 활성 프로세스 | MFT(Master File Table), 비할당 영역, 슬랙 영역 | 스냅샷, CSP 감사 로그, VPC 흐름 로그, 볼륨 이미지 |
| 증거 훼손 위험 | 수집 도구 실행으로 메모리 상태 변경 | 쓰기 방지기로 무결성 확보 용이 | 물리 계층 통제 불가, 멀티테넌시 오염 |
| 주요 도구 | LiME, FTK Imager Lite, Volatility | EnCase, FTK, Autopsy, X-Ways | CloudTrail, AWS Athena, 쿠버네티스 감사 로그 |
| 핵심 분석 기법 | 루트킷 탐지, 메모리 내 프로세스 인젝션 분석 | 삭제 파일 복구, 프리페치, 레지스트리 분석 | 시각 동기화 (NTP, Network Time Protocol), 다중 리전 로그 상호 상관 분석 |

- 파일리스 악성코드와 메모리 상주 공격이 일반화되면서, 전통적인 데드 포렌식 이전에 메모리와 활성 네트워크 상태를 보존하는 라이브 포렌식의 중요성이 커짐.

## Ⅴ. 디지털 포렌식(Digital Forensics)의 한계와 방안

- 핵심 요약 : 증거 인멸, 클라우드 물리 접근 불가, 암호화에 따른 복호 불능이라는 세 한계를 복구 기술, 제공자 API, 키 절차로 각각 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **안티포렌식** (Anti-Forensics) 기법에 의한 증거 인멸 | 타임스탬프 변조(Timestomp), 메모리 와이핑, 삭제 도구 사용으로 로그와 MFT 기록이 파괴 | VSS(Volume Shadow Copy Service)와 볼륨 슬랙 복원, NTFS(New Technology File System) 저널($UsnJrnl, $LogFile) 교차 검증으로 타임라인 재구성 | 복원 성공률, 타임라인 공백 구간 수 |
| 클라우드 멀티테넌트 환경의 물리 이미징 불가 | 물리 디스크에 접근할 수 없고, 물리 이미징 시 타 고객의 데이터까지 침해 | CSP가 제공하는 스냅샷 복제 API로 서비스 중단 없이 증거 확보, API 호출 로그에 전자서명을 부여해 신뢰 체인 확보 | 증거 확보 소요 시간, 로그 서명 검증률 |
| **E2EE** (End-to-End Encryption, 종단 간 암호화)와 하드웨어 보안 칩의 복호화 불가 | 전체 디스크 암호화(BitLocker, FileVault)와 TPM(Trusted Platform Module), Secure Enclave로 복제 후에도 평문 확보가 어려움 | 라이브 상태에서 메모리 덤프로 RAM에 상주하는 복호 키를 추출하고, 합법적 명령에 따른 **키 에스크로** (Key Escrow, 키를 제3 기관에 맡겨 두는 제도)를 연계 | 키 추출 성공률, 법적 절차 준수 기록 |

## Ⅵ. 디지털 포렌식(Digital Forensics)에 대한 기술사적 제언

- 핵심 요약 : 사후 수사에 기대지 않고, 탐지 단계에서 증거를 기록하고 포렌식 절차를 자동화하는 방향.

1. 침해 대응 조직(DFIR, Digital Forensics and Incident Response)은 EDR(Endpoint Detection and Response)의 텔레메트리를 실시간으로 수집해 프로세스 트리와 시스템 호출을 시계열 데이터로 남기는 체계를 갖추는 것이 필요.
2. 증거물의 수집 시각, 해시값, 취급자 정보를 변경이 어려운 기록 저장소에 남겨 연계보관성의 입증력을 높이는 것이 필요.
3. 클라우드 환경에서는 침해 탐지 직후 격리 네트워크 생성, 인스턴스 격리, 메모리 덤프와 스냅샷 생성을 코드로 정의해 자동 실행하는 체계를 구축하는 것이 필요.

## Ⅶ. 결론

- 핵심 요약 : 디지털 포렌식은 디지털 증거를 법정에서 설명 가능하게 만드는 수집·보존·분석 공학.
- 시사점 : 증거의 가치는 사후 분석 기술보다 사고 직후의 신속한 확보와 기록의 연속성에서 크게 좌우되므로, 탐지 체계와 포렌식 절차를 평소에 연결해 두어야 함.
