# 사용자 인증(User Authentication)

## 핵심 개념
- 정보 시스템에 접근을 시도하는 주체(User)가 자신이 주장하는 본인(Identity)임을 증명하고 시스템이 이를 검증하는 보안 메커니즘.
- 식별(Identification) 단계 이후 수행되며, 지식·소유·생체·특징(행위) 기반의 인증 요소를 단독 또는 복합(MFA)으로 활용하여 무인가 접근을 통제.

```
+-------------------------------------------------------------+
|                      인증 요소 4대 분류                      |
+-------------------------------------------------------------+
| 1. 지식 기반 (Something You Know)  | 비밀번호, PIN, 질의응답     |
| 2. 소유 기반 (Something You Have)  | OTP 토큰, 스마트카드, SMS   |
| 3. 생체 기반 (Something You Are)   | 지문, 홍채, 안면, 음성      |
| 4. 특징/행위 (Something You Do)    | 타이핑 키스트로크, 걸음걸이   |
+-------------------------------------------------------------+
```

---

## 사용자 인증 4대 요소 비교

| 인증 요소 | 정의 및 메커니즘 | 대표 사례 | 장점 및 취약점 |
|---|---|---|---|
| **지식 기반**<br>(Something You Know) | 사용자가 기억하고 있는 비밀 정보 검증 | 패스워드, 패스프레이즈, PIN | - 장점: 구현 비용 저렴, 범용성 우수<br>- 취약점: 망각, 크리덴셜 스터핑, 무차별 대입 |
| **소유 기반**<br>(Something You Have) | 사용자가 물리적 또는 논리적으로 보유한 매체 검증 | 보안토큰(HSM), 스마트카드, OTP 토큰, USIM | - 장점: 지식 기반 대비 탈취 난이도 상승<br>- 취약점: 분실, 도난, SIM 스와핑, 물리적 복제 |
| **생체 기반**<br>(Something You Are) | 사용자의 고유한 신체적 특성을 디지털 템플릿화하여 대조 | 지문, 정맥, 홍채, 망막, 안면 인식 | - 장점: 망각 및 도난 불가, 높은 편의성<br>- 취약점: 유출 시 변경 불가, 오인식률(FAR/FRR) |
| **특징/행위 기반**<br>(Something You Do) | 사용자의 고유한 행동 패턴 및 동적 생체 습관 측정 | 키보드 입력 리듬, 마우스 이동 궤적, 필기 서명, 걸음걸이 | - 장점: 지속적 인증(Continuous Auth) 가능<br>- 취약점: 환경·신체 조건에 따른 가변성, 초기 학습 필요 |

## 사용자 인증 강화 기술 체계

### 1. 다중 요소 인증(MFA, Multi-Factor Authentication)
- **개념**: 서로 다른 두 개 이상의 독립된 범주의 인증 요소를 조합하여 검증하는 방식(예: 지식 + 소유, 소유 + 생체).
- **주의점**: '비밀번호 + 2차 비밀번호' 조합은 동일 범주(지식+지식)이므로 진정한 의미의 MFA(Two-Factor)가 아닌 Multi-Step 인증임.

### 2. 패스키(Passkey) 및 FIDO2
- **원리**: 비대칭 공개키 암호(WebAuthn/CTAP) 기반으로 클라이언트에 개인키를 안전한 하드웨어(Secure Enclave)에 보관하고 서버는 공개키만 검증.
- **효과**: 피싱 사이트 유도, 서버 DB 해킹 시에도 자격증명 유출 원천 차단.

### 3. 적응형/위험 기반 인증(Adaptive / Risk-based Authentication)
- **맥락 정보 분석**: 접속 IP 위치(Geo-IP), 디바이스 핑거프린트, 접속 시간대, 비정상적 이동 속도(Impossible Travel) 분석.
- **차등 인증 요구**: 위험 점수(Risk Score)가 기준치를 초과할 때만 추가 생체/OTP 인증을 요구하여 보안성과 사용자 경험의 균형 확보.

```
[사용자 로그인 시도]
        |
        v
[위험 점수 평가 (Risk Engine)]
   - 위치/IP 이상 여부?
   - 평소와 다른 기기인가?
   - 심야 비정상 시간대인가?
        |
        +---- Low Risk ----> [단일 인증 완료 및 즉시 세션 발급]
        |
        +---- High Risk ---> [추가 인증(MFA / OTP / FIDO) 강제 요구]
        |
        +---- Critical ----> [접근 즉각 차단 및 보안 관리자 경보]
```

## 인증 오류 지표: 생체 인증 성능 평가

```
오류율(Error Rate)
  ^
  |      \                     /
  |       \   FAR (오인식률)  /
  |        \                 /
  |         \       *       /
  |          \     / \     /
  |           \   /   \   /
  |            \ /     \ /
  |             *  EER  *
  |            / \     / \
  |           /   \   /   \
  |          /     \ /     \   FRR (오거부율)
  |         /       *       \
  +-------------------------------------> 임계값(Threshold)
```

- **FAR(False Acceptance Rate, 타인수락률)**: 비인가자를 인가자로 잘못 승인하는 비율(보안성 척도, 낮을수록 보안 우수).
- **FRR(False Rejection Rate, 본인거부률)**: 인가된 본인을 비인가자로 오인하여 거부하는 비율(편의성 척도, 낮을수록 편의 우수).
- **EER(Equal Error Rate, 등가오류율)**: FAR과 FRR이 같아지는 지점으로, 생체인증 시스템의 전반적 성능 평가 기준.

## 결론 및 실무 시사점
- 단일 패스워드 체계는 크리덴셜 스터핑과 피싱 공격에 무력화되었으며, 전 산업군에서 MFA와 FIDO2/패스키 도입이 표준으로 정착.
- 제로 트러스트 아키텍처 환경에서는 로그인 시점의 1회성 인증을 넘어, 세션 전 주기에 걸쳐 행위 기반 위험도를 연속 평가하는 지속적 적응형 인증(Continuous Adaptive Authentication)으로 진화하고 있음.
