## 연관 키워드

- 식별, 인증, 인증 요소, 다중 인증(MFA), 최소 권한

- MFA 피로, 번호 매칭, 크리덴셜 스터핑, NIST AAL, UEBA, CAEP

## Ⅰ. 식별·인증·인증 요소의 개요

- 핵심 요약 : 식별로 주체를 주장하고 서로 독립된 인증 요소로 진위를 증명해 권한을 부여하는 접근 통제의 출발점.
- 개념 : 주체가 신원을 주장하는 **식별**(Identification)과, 독립된 인증 요소로 그 주장을 검증하는 **인증**(Authentication)을 묶어 접근 권한을 결정하는 체계.
- 배경 및 필요성 : 비밀번호 하나로는 신원 도용과 계정 탈취를 막기 어려워, 범주가 다른 요소를 결합하는 **다중 인증** (MFA, Multi-Factor Authentication) 요구가 커짐.
- 주요 목적 : 비인가 접근과 사칭 방지, 계정 탈취 예방, 최소 권한 원칙 집행, 사후 책임추적성 확보.

## Ⅱ. 식별·인증·인증 요소의 특징 및 장점

- 핵심 요약 : 요소의 독립성과 문맥 기반 판단이 결합되어, 한 가지 정보가 탈취되어도 인증이 뚫리지 않는 구조.

1. 요소 독립성 : 지식·소유·생체 중 서로 다른 범주를 결합 → 한 범주가 노출되어도 나머지 범주가 방어선을 유지.
2. **피싱 저항성** (Phishing Resistance) : 인증자가 접속 도메인을 암호학적으로 바인딩 → 가짜 사이트에는 응답이 전달되지 않아 중간자 탈취 차단.
3. 문맥 기반 판단 : 접속 IP, 위치, 단말 무결성을 평가 → 비정상 접속을 추가 인증이나 차단으로 연결.
4. 지속 검증 : 세션 중에도 위험 신호를 반영 → 세션 쿠키가 탈취되어도 악용 시간을 줄임.

## Ⅲ. 식별·인증·인증 요소의 구조 (흐름)

- 핵심 요약 : 식별 후 인증 요소를 검증하고, 문맥 평가를 거쳐 인가와 세션 발급으로 이어지는 순차 구조.
- **지식 요소** (Knowledge) : 사용자가 기억하는 비밀 정보로, 비밀번호와 PIN(Personal Identification Number) 등. 구현이 쉬우나 탈취와 재사용에 노출.
- **소유 요소** (Possession) : 사용자가 소지한 장치나 토큰으로, SMS(Short Message Service)나 OTP(One-Time Password) 단말, 보안키 등. 지식 요소가 노출되어도 2차 방어선으로 작동.
- **생체 요소** (Inherence) : 지문, 안면, 홍채 같은 신체 특성. 분실 위험은 없으나 원본 정보가 유출되면 교체가 어려움.

```text
[ 인증 흐름 ]

신원 주장 (식별, ID 입력)
   ↓
인증 요소 검증 (서로 다른 2개 이상)
   ↓
문맥 신호 평가 (IP, 위치, 단말)
   ↓
인증 성공 → 인가 (역할 기반) → 세션
```

```text
[ 인증 요소 3범주 ]

지식  : 비밀번호, PIN
소유  : OTP 단말, 보안키, 스마트카드
생체  : 지문, 안면, 홍채, 정맥
          ↓
   서로 다른 범주끼리 결합
```

## Ⅳ. 식별·인증·인증 요소의 비교

- 핵심 요약 : 단일 요소, SMS·OTP 2단계, 피싱 저항성 MFA의 차이는 중간자 공격과 승인 피로에 대한 내성.

| 비교 축 | 단일 요소 인증 | SMS·OTP 2단계 인증 | 피싱 저항성 MFA (FIDO2, 패스키) |
| --- | --- | --- | --- |
| 적용 요소 | 지식 (비밀번호) | 지식 + 소유 (SMS, OTP) | 소유 (보안키) + 생체 또는 PIN |
| AitM(Adversary-in-the-Middle) 프록시 피싱 | 입력 즉시 유출 | 실시간 중계로 일회용 코드 탈취 가능 | 도메인 바인딩으로 차단 |
| MFA 피로 공격 | 해당 없음 | 취약 (무의식 승인 유도) | 생체·제스처 확인으로 방어 |
| NIST(National Institute of Standards and Technology) AAL(Authenticator Assurance Level) | AAL1 (단일 요소 기준선) | AAL2 (SMS는 제한적으로만 허용) | AAL3 요건 충족 가능 |

- 선택 기준 : 자산 중요도와 위협 모델에 따라 요구 AAL을 정하고, 외부 노출 서비스일수록 피싱 저항성 요소를 우선 적용.

## Ⅴ. 식별·인증·인증 요소의 한계와 방안

- 핵심 요약 : 요소 중복, 승인 피로, 중간자 공격이라는 세 한계를 범주 분리, 번호 매칭, 피싱 저항성 요소로 막는 구조.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 동일 범주 요소 중복 | 비밀번호를 두 번 묻는 방식이 MFA로 오인되어 크리덴셜 스터핑에 노출 | 서로 다른 범주 요소의 결합을 IAM(Identity and Access Management) 정책으로 강제 | 범주 불일치 인증 예외 건수 |
| MFA 피로 공격 | 반복 푸시 승인 요청으로 사용자가 무의식중에 승인 | 단순 승인 버튼을 없애고 화면의 숫자를 단말에 입력하는 번호 매칭(Number Matching) 적용 | 푸시 거부율, 비정상 승인 건수 |
| 중간자 프록시와 SMS 가로채기 | Evilginx 같은 도구로 세션 쿠키와 OTP를 실시간 탈취, 기존 2FA 무력화 | FIDO2·WebAuthn(Web Authentication) 기반 피싱 저항성 패스키 도입 | 피싱 저항성 인증 적용률 |

## Ⅵ. 식별·인증·인증 요소에 대한 기술사적 제언

- 핵심 요약 : 인증을 개별 기능이 아닌 전사 신원 거버넌스와 지속 평가 체계 안에서 운영.

1. 정보보호 조직은 인증 수준을 자산 중요도별로 등급화하고, 등급마다 요구 AAL을 정책으로 지정해 IAM 체계에 통합한다.
2. 접근 결정을 한 번의 로그인으로 끝내지 않고, CAEP(Continuous Access Evaluation Profile) 같은 연속 평가 프로토콜과 연계해 위험 변화에 따라 세션을 재평가한다.
3. 인증 로그를 UEBA(User and Entity Behavior Analytics)와 함께 보안관제 체계에 편입하고, 이상 행위를 탐지하면 경영진 보고 체계로 연결되는 대응 절차를 둔다.

## Ⅶ. 결론

- 핵심 요약 : 식별·인증은 접근 통제의 첫 관문이며, 효과는 피싱 저항성 요소와 문맥 평가에서 나옴.
- 시사점 : 비밀번호 중심 인증에서 피싱 저항성 요소와 지속 평가로 무게중심을 옮기는 것이 계정 탈취를 억제하는 핵심.
