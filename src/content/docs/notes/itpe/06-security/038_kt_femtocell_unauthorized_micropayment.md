## Ⅰ. KT 불법 펨토셀 무단 소액결제 침해사고의 개요

- 개념 : 공격자가 통신사(KT)의 공통 인증서 관리 부실을 악용하여 복제된 비인가 소형 기지국(펨토셀)을 통신사 코어망에 무단 접속시키고, 인근 가입자 단말의 통신을 가로채 IMSI 식별정보와 결제 ARS/SMS 인증을 탈취한 후 수억 원대의 무단 소액결제를 감행한 대규모 통신 인프라 침해사고.
- 배경 및 필요성 : 음영지역 해소를 위해 보급된 초소형 기지국(펨토셀)의 인증 체계가 취약하여 발생하였으며, 무선 통신망의 신뢰 모델(기지국은 무조건 신뢰한다)이 붕괴될 수 있음을 증명한 사건.
- 핵심 목적 : 통신사 장비 인증의 근본적 결함 규명, 가짜 기지국(IMSI Catcher) 공격 메커니즘 차단, 통신사 및 결제 인프라의 공급망 보안 및 다요소 인증 아키텍처 재설계.

## Ⅱ. KT 불법 펨토셀 무단 소액결제 침해사고의 핵심 아키텍처 및 동작 메커니즘

공격자는 불법 펨토셀에 복제된 사설 인증서를 탑재하여 코어망 IPsec 터널을 뚫고, 높은 송출 출력으로 주변 단말을 유인한 뒤 통신 제어를 평문으로 다운그레이드하여 결제 인증을 가로챔.

```text
[ 불법 펨토셀 무단 소액결제 침해 및 인증 탈취 메커니즘 ]

  [ 공격자 (불법 복제 펨토셀 가동) ]
           │ 1. 복제된 통신사 사설 인증서로 코어망 접속
           ▼
  +-------------------------------------------------------------+
  | 통신사 코어망 (IPsec SeGW 보안 게이트웨이)                 |
  |  - 결함: 장비별 개별 인증서가 아닌 공통 사설 인증서 검증! |
  |  - 불법 펨토셀을 정상 기지국으로 오인하여 IPsec 터널 수립   |
  +-------------------------------------------------------------+
           │
           │ 2. 강한 전파 송출로 주변 단말의 기지국 핸드오버 강제 유도 (IMSI Catching)
           ▼
  [ 피해자 스마트폰 단말 ]
           │ 3. 암호화 해제(Null Cipher) 협상 -> 음성/SMS 평문 수신
           ▼
  [ 불법 펨토셀 ] ──> 4. 가입자 식별정보(IMSI/전화번호) 탈취
           │
           │ 5. 결제 사이트에서 피해자 명의로 무단 소액결제 시도
           ▼
  [ 결제 대행사 (PG사) ] ──(ARS 승인 전화 / SMS 전송)──> [ 통신사 코어망 ]
                                                                 │
                                                                 ▼
                                                  [ 불법 펨토셀로 전화/SMS 수신 ]
                                                  - 공격자가 ARS 통화 승인 버튼 조작
                                                  - 결제 승인 완료 (수억 원 피해 발생!)
```

- **공통 장비 인증서 복제** : 수만 대의 펨토셀에 동일한 통신사 공통 사설 인증서가 설치되어 있어, 공격자가 정상 장비를 덤프하여 인증서와 개인키를 복제.
- **전파 출력 조작을 통한 IMSI Catching** : 단말이 가장 강한 수신 신호(RSSI)를 가진 기지국에 우선 접속하는 무선 메커니즘을 악용해 강제 접속 유도.
- **암호화 다운그레이드 공격** : 통신 협상 단계에서 암호화 알고리즘을 무암호(A5/0 또는 Null Cipher)로 다운그레이드시켜 패킷을 평문 도청.
- **결제 승인 채널의 단일 의존성** : 결제 승인이 통신 회선(ARS/SMS)과 분리되지 않아, 통신망 도청만으로 소액결제 인증이 무력화.

## Ⅲ. KT 불법 펨토셀 무단 소액결제 침해사고의 세부 구성 요소 및 비교 분석

| 침해 단계 | 공격자의 악용 수법 | 통신 인프라 보안 결함 요인 | 근본적 엔지니어링 대책 |
| --- | --- | --- | --- |
| 장비 인증 | 사설 인증서 덤프 후 복제 펨토셀에 탑재 | 장비별 고유 인증서 부재, 폐기 목록(CRL) 미검증 | 하드웨어 TPM 기반 장비 고유 인증서 (IEEE 802.1AR) |
| 무선 접속 | 주변보다 높은 전파 출력 송출 (가짜 기지국) | 단말의 신호 세기 우선 접속 메커니즘 악용 | 기지국 상호 인증 강제, 5G SUPI/SUCI 암호화 |
| 무선 통신 | 암호화 미적용(Null Cipher)으로 다운그레이드 | 통신 구간 암호화 알고리즘 강제성 결여 | A5/3, AES 암호화 필수 적용, 무암호 협상 차단 |
| 소액결제 | 착신 ARS 통화 및 인증 SMS 가로채기 승인 | 통신망과 결제 승인 채널의 동일성 (단일 채널) | 앱 기반 FIDO2 생체인증, 대역 외(Out-of-Band) 인증 |

- 이 사고는 하드웨어 보안 모듈(TPM) 부재로 인한 장비 인증서 복제와, 무선 통신망의 무암호 다운그레이드 취약점이 결합하여 금융 결제망까지 붕괴시킨 대표적 공급망 침해 사례임.

## Ⅳ. KT 불법 펨토셀 무단 소액결제 침해사고의 주요 한계점 및 해결 방안

- **공용 사설 인증서** 발급 관행으로 인한 전 기지국 동시 위조 가능성 :
  - 한계점 : 유지보수 편의를 위해 수만 대의 장비에 단일 인증서를 일괄 복사·설치하여 단 하나의 인증서 유출로 전사 장비 신뢰 붕괴.
  - 해결 방안 : 장비 제조 단계에서 하드웨어 신뢰점(Root of Trust)인 TPM/eSE 칩에 장비별 고유 인증서(DevID)를 봉인하고 온라인 상태 검증(OCSP) 필수화.
- 레거시 2G/3G/LTE 표준의 기지국-단말 간 **단방향 인증** 취약점 :
  - 한계점 : 기지국은 단말을 인증하지만 단말은 접속하는 기지국이 진짜 통신사 기지국인지 암호학적으로 검증하지 못하는 구조적 결함.
  - 해결 방안 : 3GPP 표준 상호 인증(AKA)을 무선 제어 계층까지 강제하고, 5G의 암호화된 가입자 식별자(SUCI) 기술을 전면 조기 도입.
- SMS/ARS 단일 채널 인증의 구조적 감청 취약성 :
  - 한계점 : 통신망 회선이 탈취되면 회선으로 전송되는 인증 문자나 전화 역시 공격자가 직접 수신하게 되는 단일 실패점(SPOF).
  - 해결 방안 : 통신 회선에 의존하는 SMS/ARS 인증을 전면 폐지하고, 전용 금융 뱅킹 앱 내의 푸시 기반 FIDO2/WebAuthn 생체인증 채널로 분리.

## Ⅴ. KT 불법 펨토셀 무단 소액결제 침해사고 적용 및 발전을 위한 기술사적 제언

- 기간통신망 통신 장비 제로트러스트 인증 표준 제정 : 공공 및 기간망에 납품되는 모든 소형 기지국 및 AP에 대해 하드웨어 TPM 기반 장비 무결성 검증 의무화.
- 통신사 **이상 펨토셀 실시간 위치/트래픽 탐지** (FDS) 구축 : 펨토셀이 등록된 GPS 위치나 유선 IP 대역을 벗어나 이동하거나 급격한 트래픽 패턴 변화 시 코어망 연결 자동 차단.
- 소액결제 FDS의 기지국 식별자 교차 검증 연계 : 결제 요청 단말이 접속된 기지국 Cell ID가 평소 생활 반경과 급격히 상이하거나 펨토셀일 경우 결제 한도 축소 및 추가 인증 요구.
