## 연관 키워드

- 펨토셀(Femtocell), IMSI(International Mobile Subscriber Identity), IMSI 캐처(IMSI Catcher), 가짜 기지국
- 공통 인증서, 암호화 다운그레이드(Downgrade Attack), 단방향 인증, 소액결제 사기
- SMS, ARS, 단일 실패점(SPOF), FIDO2, TPM(Trusted Platform Module), SUCI, FDS(Fraud Detection System)

## Ⅰ. KT 불법 펨토셀 무단 소액결제 침해사고의 개요

- 핵심 요약 : 통신 인증 체계의 취약점을 이용해 가짜 기지국으로 가입자 정보를 가로채고 소액결제를 승인한 통신 인프라 침해사고.
- 개념 : 공격자가 복제된 불법 **펨토셀** (Femtocell, 소형 기지국)을 통신사 코어망에 접속시키고, 주변 단말의 통신을 가로채 가입자 식별정보인 **IMSI** (International Mobile Subscriber Identity)와 ARS(Automatic Response Service), SMS(Short Message Service) 인증 정보를 탈취한 뒤 무단 소액결제를 시도한 사고.
- 배경 및 필요성 : 음영지역 해소를 위해 보급된 소형 기지국의 인증 체계가 취약하면, 기지국은 무조건 신뢰된다는 무선망의 전제가 무너질 수 있음을 보여 준 사례.
- 주요 목적 : 장비 인증의 결함을 규명하고, 가짜 기지국 공격을 차단하며, 결제 인증을 통신 회선과 분리하는 설계 원칙을 도출하는 것.

## Ⅱ. KT 불법 펨토셀 무단 소액결제 침해사고의 특징 및 장점

- 핵심 요약 : 장비 인증의 공통 키 의존, 신호 세기 기반 접속, 암호화 다운그레이드, 단일 채널 결제 인증이 결합된 복합 공격.

1. **공통 인증서 사용** : 다수 장비가 같은 사설 인증서를 공유하면 한 장비의 유출로 전체 신뢰가 무너짐 → 복제 장비의 코어망 접속 허용.
2. **IMSI 캐칭** (IMSI Catching) : 단말이 신호가 강한 기지국에 접속하는 특성을 이용해 강제 접속을 유도 → 가입자 식별정보 수집.
3. **암호화 다운그레이드** (Downgrade Attack) : 협상 단계에서 암호화 방식을 약하거나 없는 방식으로 낮춤 → 통신 구간 도청 가능.
4. 단일 채널 결제 인증 : ARS와 SMS 승인이 통신 회선에 의존 → 회선을 장악하면 결제 인증도 함께 무력화.

## Ⅲ. KT 불법 펨토셀 무단 소액결제 침해사고의 구조 (흐름)

- 핵심 요약 : 불법 펨토셀의 코어망 접속에서 인증 정보 탈취와 결제 승인까지 이어지는 흐름, 그리고 결제 승인 경로의 단일 실패점.

```text
[ 침해 흐름 ]

불법 펨토셀 가동 (복제 인증서 사용)
          ↓
통신사 코어망 접속 (인증서 검증 통과)
          ↓
주변 단말 강제 접속 (IMSI 캐칭)
          ↓
암호화 다운그레이드 후 식별정보와 문자 수신
          ↓
피해자 명의 결제 요청, 승인 채널 가로채기
```

```text
[ 결제 승인 경로의 단일 실패점 ]

결제 대행사의 결제 요청
          ↓
ARS 또는 SMS 인증 발송
          ↓
통신 회선 (가로채기 가능 구간)
          ↓
승인 입력 후 결제 완료
```

| 침해 단계 | 악용 수법 | 결함 요인 | 엔지니어링 대책 |
| --- | --- | --- | --- |
| 장비 인증 | 사설 인증서를 복제해 불법 장비에 탑재 | 장비별 고유 인증서 부재, 인증서 폐기 상태 미검증 | TPM(Trusted Platform Module) 기반 장비 고유 인증서, 인증서 폐기 목록(CRL, Certificate Revocation List) 확인 |
| 무선 접속 | 강한 전파로 주변 단말의 접속 유도 | 신호 세기 기반 접속 우선 특성 | 기지국 상호 인증 강제 |
| 무선 통신 | 무암호 협상으로 다운그레이드 | 암호 적용의 강제성 부족 | 강한 암호 알고리즘 필수 적용, 무암호 협상 차단 |
| 결제 승인 | 승인 문자와 통화 가로채기 | 통신 회선과 결제 승인의 동일 채널 | 앱 기반 FIDO2 인증, 대역 외(Out-of-Band) 인증 |

## Ⅳ. KT 불법 펨토셀 무단 소액결제 침해사고의 비교

- 핵심 요약 : 회선 기반 인증은 통신망이 뚫리면 함께 무너지고, 기기 기반 인증은 채널을 분리해 피해 범위를 줄임.

| 비교 항목 | SMS, ARS 인증 | 앱 기반 FIDO2 인증 |
| --- | --- | --- |
| 인증 채널 | 통신 회선 (단일 채널) | 전용 앱과 기기 인증자 (별도 채널) |
| 도청 위험 | 회선 도청과 번호 이동 시 노출 | 개인키가 기기에 있어 회선 도청으로 탈취 곤란 |
| 피싱 내성 | 문자와 통화 내용 노출 | 출처 바인딩으로 피싱 내성 확보 |
| 사용자 부담 | 낮음 | 기기 등록 과정 필요 |

## Ⅴ. KT 불법 펨토셀 무단 소액결제 침해사고의 한계와 방안

- 핵심 요약 : 공통 인증서 관행, 기지국 단방향 인증, 회선 기반 단일 채널이 주요 한계이며 장비 신뢰와 채널 분리로 대응해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 공통 사설 인증서 관행 | 유지보수 편의로 다수 장비가 한 인증서를 공유해, 한 번의 유출로 전 장비 신뢰 붕괴 | 장비별 고유 인증서를 TPM에 봉인하고 온라인 인증서 상태 프로토콜(OCSP, Online Certificate Status Protocol)로 폐기 여부 상시 검증 | 장비별 고유 인증서 적용률 |
| 기지국 단방향 인증 구조 | 단말이 접속한 기지국이 진짜인지 암호학적으로 검증하지 못함 | 인증 및 키 합의(AKA, Authentication and Key Agreement) 기반 상호 인증을 무선 제어 계층까지 강제하고, 5G의 은닉 가입자 식별자(SUCI, Subscription Concealed Identifier) 도입 | 상호 인증 적용 기지국 비율 |
| 회선 기반 단일 인증 채널 | 통신 회선이 장악되면 SMS와 ARS 인증이 모두 노출되는 단일 실패점(SPOF, Single Point of Failure) | 회선 기반 인증 의존을 줄이고 전용 앱의 푸시 기반 FIDO2 인증으로 채널 분리 | 회선 기반 인증 비율 |

## Ⅵ. KT 불법 펨토셀 무단 소액결제 침해사고에 대한 기술사적 제언

- 핵심 요약 : 장비 신뢰, 무선 인증, 결제 인증을 각각 독립적으로 검증하는 다층 설계와 이상 탐지의 연계.
- 기간통신망에 납품되는 소형 기지국과 무선 접속점(AP, Access Point)에 대해서는 하드웨어 기반 장비 무결성 검증을 의무 요건으로 두는 방향이 바람직하다.
- 통신사는 펨토셀의 등록 위치나 망 연결 경로가 평소와 달라질 때 코어망 연결을 자동으로 제한하는 이상 탐지 체계인 사기 탐지 시스템(FDS, Fraud Detection System)을 갖출 필요가 있다.
- 결제 사업자는 결제 요청 단말의 셀 식별자(Cell ID, Cell Identifier)가 평소 생활 반경과 크게 다르면 결제 한도를 낮추고 추가 인증을 요구하는 위험 기반 인증을 도입하는 것이 바람직하다.

## Ⅶ. 결론

- 핵심 요약 : 이 사고는 통신 인프라의 신뢰 가정과 단일 인증 채널이 결합될 때 금융 피해로 번질 수 있음을 보여 준 사례임.
- 통신 장비 인증과 결제 인증을 서로 독립된 신뢰 근거로 설계하는 것이 재발 방지의 기본임.
