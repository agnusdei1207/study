## Ⅰ. 국가 망 보안체계(N2SF)의 개요

- 개념 : 국가정보원이 2006년 도입된 획일적 **물리적 망분리** 제도의 한계를 극복하고, 공공부문의 생성형 AI(Artificial Intelligence) 및 클라우드(SaaS) 도입을 촉진하기 위해 업무와 데이터의 중요도에 따라 C(기밀)·S(민감)·O(공개) 3등급으로 분류하여 차등화된 보안 통제를 적용하는 차세대 국가 **다층보안체계** (MLS, Multi-Level Security) 프레임워크.
- 배경 및 필요성 : 인터넷망과 업무망의 획일적 단절로 인해 공공 행정의 생산성 저하, **1인 2PC** 유지비용 폭증, 최신 AI 신기술 도입 차단 등의 문제가 지속되어 제로트러스트 기반의 데이터 중심 보안으로 패러다임 전환 요구 급증.
- 핵심 목적 : 국가 핵심 기밀의 보호 강화, 공공 AI 및 민간 클라우드 활용 유연성 극대화, 크로스 도메인 솔루션(CDS)을 통한 안전한 데이터 연계 및 정부 디지털 혁신 가속화.

## Ⅱ. 국가 망 보안체계(N2SF)의 핵심 아키텍처 및 동작 메커니즘

N2SF는 업무와 데이터를 C(기밀), S(민감), O(공개) 3등급으로 식별하고, 상호 다른 등급 간의 데이터 이동은 엄격한 보안 게이트웨이(CDS)를 통해서만 허용하는 다층 보안 아키텍처를 가짐.

```text
[ 국가 망 보안체계(N2SF) C/S/O 3대 등급 체계 및 통제 모델 ]

  +-------------------------------------------------------------+
  | [ C 등급 : 기밀 (Classified) ]                              |
  |  - 국가 안보, 국방, 외교, 핵심 수사 및 기밀 데이터          |
  |  - 통제: 온프레미스 망분리 유지, 완벽한 인터넷 차단, 엄격 암호화|
  +------------------------------┬------------------------------+
                                 │ CDS (Cross Domain Solution: 연계 게이트웨이)
                                 ▼
  +-------------------------------------------------------------+
  | [ S 등급 : 민감 (Sensitive) ]                               |
  |  - 비공개 일반 행정 업무, 민감 개인정보, 부처 내부 정책     |
  |  - 통제: 제로트러스트(ZTA), CSAP 인증 클라우드, 논리적 격리 |
  +------------------------------┬------------------------------+
                                 │ 안전한 파일 전송 / CDR 연계
                                 ▼
  +-------------------------------------------------------------+
  | [ O 등급 : 공개 (Open) ]                                    |
  |  - 대민 공공 서비스, 공개 데이터, 인터넷 검색, 민간 SaaS    |
  |  - 통제: 인터넷망 직접 연결 허용, 생성형 AI(ChatGPT 등) 활용|
  +-------------------------------------------------------------+
```

- **C등급** (Classified, 기밀) : 국가 안보 및 핵심 기밀이 유통되는 영역으로 기존 물리적 망분리 수준의 최고 보안 유지.
- **S등급** (Sensitive, 민감) : 내부 행정 및 개인정보를 처리하는 영역으로, 검증된 민간 클라우드 및 제로트러스트 논리적 망분리 적용.
- **O등급** (Open, 공개) : 대민 공개 정보 및 인터넷 연구 영역으로 민간 SaaS 및 최신 생성형 AI 서비스 자유롭게 활용.
- **크로스 도메인 솔루션** (CDS, Cross Domain Solution) : 상이한 보안 등급 간(C망과 S망, S망과 O망) 데이터 이동 시 악성코드 유입 및 정보 유출을 차단하는 고신뢰 다계층 게이트웨이.

## Ⅲ. 국가 망 보안체계(N2SF)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 기존 국가 망분리 체계 (2006년~) | 차세대 국가 망 보안체계 (N2SF) | 실무 적용 기술 |
| --- | --- | --- | --- |
| 보안 철학 | 물리적 경계 보안 (성벽 모델) | 데이터 중심 다층보안체계 (MLS & Zero Trust) | C/S/O 등급 매핑 |
| 망 구조 | 인터넷망 vs 업무망 획일적 2분법 | C(기밀) - S(민감) - O(공개) 3등급 다계층 | 단일 PC(Personal Computer) 환경 논리적 격리 |
| 클라우드/AI | 공공 업무망 내 SaaS/AI 활용 전면 불가 | S·O 등급에 민간 클라우드 및 생성형 AI 개방 | CSAP(Cloud Security Assurance Program) 클라우드, AI 가드레일 |
| 업무 단말 | 1인 2PC (물리적 PC 2대 사용) | 1인 1PC (소프트웨어 정의 논리적 보안 분리) | ZTNA(Zero Trust Network Access) 에이전트, 하이퍼바이저 격리 |
| 데이터 연계 | 망연계 솔루션(스토리지 방식) | 실시간 크로스 도메인 솔루션(CDS) | 하드웨어 단방향 전송, 무해화(CDR, Content Disarm and Reconstruction) |

- N2SF는 '망 자체를 쪼개는 것'에서 '데이터 중요도에 따라 보호 수준을 차등화하는 것'으로 패러다임을 전환하여 국가 기밀의 보호와 공공 업무 혁신을 양립시킴.

## Ⅳ. 국가 망 보안체계(N2SF)의 주요 한계점 및 해결 방안

- 공공 데이터의 **C/S/O** 등급 분류에 대한 자의적 기준 및 과잉 지정 :
  - 한계점 : 공무원이 감사 책임 회피를 위해 일반 업무까지 모두 C(기밀) 등급으로 과잉 지정하여 클라우드/AI 활용이 다시 차단되는 역효과.
  - 해결 방안 : **데이터 보안 태세 관리** (DSPM) 도구를 도입하여 개인정보, 대외비 키워드를 AI가 자동 판별하고 객관적 등급을 추천하는 자동화 시스템 구축.
- **CDS** (크로스 도메인) 게이트웨이를 경유하는 신종 멀웨어 유입 :
  - 한계점 : O망에서 다운받은 외부 문서나 데이터가 CDS를 통해 S망 또는 C망으로 반입되는 과정에서 지능형 스테가노그래피나 제로데이 악성코드 침투.
  - 해결 방안 : **콘텐츠 악성코드 무해화** (CDR, Content Disarm & Reconstruction) 기술을 연동하여 문서 내 매크로, 자바스크립트를 원천 파괴하고 재구성.
- 단일 PC 환경에서의 로컬 데이터 유출 및 **클립보드 공유** 결함 :
  - 한계점 : 1인 1PC에서 O등급 영역과 S등급 영역 간에 화면 캡처나 클립보드 복사/붙여넣기를 통한 데이터 유출 가능성.
  - 해결 방안 : OS(Operating System) 커널 레벨의 **마이크로 가상화** (Micro-VM) 샌드박싱 및 단말 DLP(Data Loss Prevention)를 통해 메모리 및 클립보드 상호 격리 강제.

## Ⅴ. 국가 망 보안체계(N2SF) 적용 및 발전을 위한 기술사적 제언

- 공공기관 정보자산 전수 C/S/O 데이터 분류 사업 조기 착수 : 본격적인 인프라 전환 전 전사 업무 데이터의 민감도 인벤토리를 작성하고 데이터 거버넌스 수립.
- KISA(Korea Internet & Security Agency) 제로트러스트 2.0 가이드라인과의 완벽한 아키텍처 연계 : S등급 영역의 논리적 보안 통제 수단으로 KISA가 인증한 ZTNA 및 피싱 저항 MFA(Multi-Factor Authentication) 도입.
- 공공 조달 및 보안적합성 검증 체계의 **N2SF** 표준 반영 : CDS 및 망보안 장비 도입 시 국가정보원 보안적합성 검증 기준에 N2SF 준수 요건 명문화.
