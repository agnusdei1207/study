## 연관 키워드

- N2SF(National Network Security Framework), 망분리, 다층보안체계(MLS, Multi-Level Security)
- 크로스 도메인 솔루션(CDS, Cross Domain Solution), 콘텐츠 무해화(CDR, Content Disarm and Reconstruction)
- CSAP(Cloud Security Assurance Program), 제로트러스트(Zero Trust), 데이터 보안 태세 관리(DSPM)

## Ⅰ. 국가 망 보안체계(N2SF)의 개요

- 핵심 요약 : 물리적 망분리의 획일성을 넘어 데이터 중요도별로 보안 통제를 차등 적용하는 국가 차원의 다층 보안 체계.
- 개념 : 국가정보원이 2006년 도입한 획일적 **망분리** (물리적으로 인터넷망과 업무망을 나누는 방식)의 한계를 넘어, 업무와 데이터를 C(기밀)·S(민감)·O(공개) 3등급으로 나누어 등급별 통제를 달리하는 **다층보안체계** (MLS, Multi-Level Security) 프레임워크인 차세대 국가 망 보안체계(N2SF, National Network Security Framework).
- 배경 및 필요성 : 인터넷망과 업무망의 단절로 공공 행정 생산성이 떨어지고, 1인 2대 PC(Personal Computer) 유지 비용이 늘며, 생성형 AI(Artificial Intelligence)와 클라우드 도입이 막히는 문제가 누적됨. 이에 따라 데이터 중심 보안으로 전환할 필요가 커짐.
- 주요 목적 : 국가 핵심 기밀 보호 강화, 공공 AI와 민간 클라우드 활용 확대, **크로스 도메인 솔루션** (CDS, Cross Domain Solution)을 통한 안전한 데이터 연계.

## Ⅱ. 국가 망 보안체계(N2SF)의 특징 및 장점

- 핵심 요약 : 등급 분류와 등급 간 게이트웨이 통제가 결합되어, 보안 수준과 업무 편의를 동시에 확보하는 구조.

1. **C/S/O 등급 분류** : 업무와 데이터를 기밀, 민감, 공개 3등급으로 식별 → 등급에 맞는 통제만 적용하여 과잉 차단 감소.
2. 등급 간 게이트웨이 통제 : 서로 다른 등급 사이의 데이터 이동을 CDS로만 허용 → 상위 등급 유출과 외부 악성코드 유입 차단.
3. 민간 클라우드와 AI 개방 : S·O 등급에 **CSAP** (Cloud Security Assurance Program) 인증 클라우드와 생성형 AI 활용 허용 → 행정 생산성 향상.
4. 1인 1대 PC 논리 분리 : 물리적 단말 두 대 대신 소프트웨어로 영역을 분리 → 단말 유지 비용 절감.

```text
[ N2SF 3등급 통제 구조 ]

C 등급 (기밀)
  온프레미스 망분리 유지, 인터넷 차단
        ↓ CDS
S 등급 (민감)
  제로트러스트, 인증 클라우드, 논리 격리
        ↓ 무해화 후 전송
O 등급 (공개)
  인터넷 직접 연결, 민간 클라우드·AI
```

## Ⅲ. 국가 망 보안체계(N2SF)의 구성 요소 및 흐름

- 핵심 요약 : 등급 간 데이터는 CDS에서 무해화와 검증을 거친 뒤에만 이동하는 단방향 흐름이 핵심이며, 무해화는 콘텐츠 무해화(CDR, Content Disarm and Reconstruction)로 수행됨.

```text
[ O 등급 → S 등급 데이터 반입 ]

외부 문서 다운로드 (O 등급)
        ↓
CDR 무해화
  매크로·스크립트 제거, 재구성
        ↓
크로스 도메인 솔루션(CDS) 검사
        ↓
S 등급 영역 반입 (기록·감사)
```

| 비교 항목 | 기존 망분리 체계 (2006년~) | 차세대 N2SF | 실무 적용 기술 |
| --- | --- | --- | --- |
| 보안 철학 | 물리적 경계 보안 | 데이터 중심 다층 보안 | C/S/O 등급 매핑 |
| 망 구조 | 인터넷망과 업무망의 2분법 | C-S-O 3등급 다계층 | 단일 PC의 논리적 격리 |
| 클라우드·AI | 업무망 내 SaaS·AI 활용 제한 | S·O 등급 개방 | CSAP 인증 클라우드, AI 가드레일 |
| 데이터 연계 | 망연계 솔루션 중심 | 실시간 CDS 연계 | 단방향 전송, 콘텐츠 무해화 |

- N2SF는 망 자체를 나누는 방식에서 데이터 중요도에 따라 보호 수준을 차등화하는 방식으로 전환하여, 기밀 보호와 공공 업무 혁신을 함께 달성하려는 체계임.

## Ⅳ. 국가 망 보안체계(N2SF)의 비교 분석

- 핵심 요약 : 망을 나누는 기존 방식과 데이터 등급으로 통제하는 N2SF의 차이는 보호 대상과 통제 수단에 있음.

| 비교 축 | 기존 망분리 | N2SF |
| --- | --- | --- |
| 보호 대상 | 네트워크 경계 | 데이터 등급 |
| 통제 수단 | 물리적 단말·망 분리 | CDS 게이트웨이, 제로트러스트, 논리 격리 |
| 활용 범위 | 외부 클라우드·AI 제한 | 등급에 따라 클라우드·AI 개방 |
| 운영 부담 | 단말 2대와 망연계 장비 | 단말 1대와 등급 분류 체계 |

## Ⅴ. 국가 망 보안체계(N2SF)의 한계와 방안

- 핵심 요약 : 등급 분류의 자의성, 게이트웨이를 통한 악성코드 유입, 단일 단말 내 유출이 주요 한계이며 자동 분류와 무해화, 메모리 격리로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 등급 과잉 지정 | 감사 부담을 피하려 일반 업무까지 기밀로 지정 → 클라우드·AI 재차단 | 데이터 보안 태세 관리(DSPM, Data Security Posture Management)로 개인정보·대외비를 자동 판별해 등급 추천 | 등급 재분류율 |
| CDS 경유 악성코드 유입 | 외부 문서의 매크로·스크립트가 게이트웨이를 통과 | 콘텐츠 무해화(CDR) 연동으로 실행 요소 제거 후 재구성 | 무해화 차단 건수 |
| 단일 PC 내 클립보드 유출 | 등급 영역 간 복사·붙여넣기와 화면 캡처로 데이터 이동 | 마이크로 가상화 격리와 단말 DLP(Data Loss Prevention) 적용 | 비인가 전송 시도 건수 |

## Ⅵ. 국가 망 보안체계(N2SF)에 대한 기술사적 제언

- 핵심 요약 : 등급 분류 기준을 먼저 세우고, 게이트웨이와 조달 기준에 N2SF를 반영하는 순서의 제도화가 필요함.

1. 공공기관 정보자산의 민감도 목록을 먼저 작성하여 등급 분류 기준을 정립한 뒤, 인프라 전환 사업에 착수하는 것이 바람직함.
2. 제로트러스트 관련 공공 가이드라인과 N2SF 아키텍처를 연계하여, S등급 영역의 접근 통제 수단을 인증된 제품으로 한정하는 방향이 필요함.
3. CDS와 망보안 장비의 도입 요건에 N2SF 준수 항목을 명시하여 조달 단계에서 보안 적합성을 검증하는 것이 필요함.

## Ⅶ. 결론

- 핵심 요약 : N2SF는 망을 나누는 보안에서 데이터 등급에 맞춰 통제하는 보안으로의 전환을 뜻함.
- 시사점 : 등급 분류의 정확성과 CDS 경유 검증이 함께 확보될 때 기밀 보호와 공공 AI 활용이 양립됨.
