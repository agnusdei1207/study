- 필수 키워드: N2SF · 다층보안체계(MLS) · C(기밀)/S(민감)/O(공개) · 데이터 등급분류 · 제로트러스트 · 보안통제 게이트웨이
- 기출: 137회 3교시 6번 `N2SF 보안 가이드라인` → Ⅰ 개요 + Ⅲ C/S/O 구조 및 통제 + Ⅵ 실무 고려사항

## 한 줄 본질
- 획일적 물리적 2분법 망분리로 인한 클라우드·AI 도입 차단 병목 → 데이터·업무의 중요도에 따라 C(기밀)·S(민감)·O(공개)로 다층 분류하고 차등 보안통제를 적용 → 공공 AI/SaaS 혁신 촉진 / 데이터 분류 책임 및 게이트웨이 집중 관리 비용 발생

## 핵심 그림
```text
[국가 망 보안체계(N2SF) C/S/O 다층 구조]

 ┌──────────────────────────────────────────────────────────┐
 │ [공개 망 (O, Open)]                                       │
 │ - 대국민 서비스, 인터넷 직접 연결, 공공 민간 SaaS 활용     │
 └────────────────────────────┬─────────────────────────────┘
                              │ 통제 게이트웨이 (API/접근제어)
 ┌────────────────────────────┴─────────────────────────────┐
 │ [민감 망 (S, Sensitive)]                                  │
 │ - 비공개 행정업무, 개인정보/내부 결재 (데이터 암호화 필수) │
 └────────────────────────────┬─────────────────────────────┘
                              │ 엄격한 단방향/망간연계 전송
 ┌────────────────────────────┴─────────────────────────────┐
 │ [기밀 망 (C, Confidential)]                              │
 │ - 국가 안보, 국방·외교·수사 등 핵심 기밀 (외부망 물리 격리)│
 └──────────────────────────────────────────────────────────┘
```

## 핵심 용어
- 다층보안체계(MLS, Multi-Level Security): 단일 경계 차단 대신 데이터 기밀성 수준에 따라 보안 등급을 복수로 정의하고 접근을 통제하는 기제
- C/S/O 체계: 국가정보원이 제시한 공공 데이터 3대 분류군으로 기밀(Confidential), 민감(Sensitive), 공개(Open)를 지칭

## 핵심 통찰
- 망분리를 풀고 다층보안으로 전환하는 본질은 '보안 완화'가 아닌 '데이터 중심 통제 세분화'임 → 기밀 데이터는 오히려 더 강력히 통제하고 일반 행정은 SaaS를 활용해 생산성 확보
- N2SF의 성공 여부는 '데이터 등급분류의 객관성'에 좌우됨 → 분류 책임이 현업 담당자에게 전가되면 보신주의로 인해 모든 데이터를 C(기밀)로 지정해 제도 전환 취지가 무력화됨
- 제로트러스트 정책(지속적 검증, 최소 권한)이 뒷받침되지 않은 채 망 연계만 확대하면 민감 망 침해 사고 발생 시 측면 이동(Lateral Movement) 위험 증가

## 이웃 토픽과 구분
- 기존 망분리 vs N2SF: 기존 망분리 = 단말/네트워크 물리적 2분법(내부/외부망) / N2SF = 데이터와 서비스 가치 중심의 다계층(C/S/O) 논리적·물리적 복합 통제

## 문제·원인·대책
- 사례: 국가정보원 N2SF 가이드라인 시범 적용 및 공공 SaaS 연계 사업
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 공공기관 데이터의 C/S/O 등급분류 기준 모호 | 정량적 자산 가치 평가 체계 및 분류 가이드 세부 매뉴얼 부재 | 데이터 식별·분류 자동화(DLP/메타데이터 태깅) 및 위원회 심의 제도 도입 | 자의적 등급 지정 방지 및 일관된 통제 적용 |
| O(공개) 망을 통한 민감(S) 데이터 유출 위험 | 외부 SaaS 및 생성형 AI 도구 활용 시 데이터 이동 경로 감시 미흡 | 망간 연계 보안통제 게이트웨이에 프롬프트 필터 및 비식별화 엔진 강제 | 기밀 정보의 외부 생성형 AI 전송 차단 |

## 이렇게 출제된다
- 제137회 3교시 6번: "2025년 1월 국가정보원에서는 공공기관을 대상으로 국가 망 보안체계(National NetworkSecurityFramework,N2SF) 보안 가이드라인을발표하였다. 다음에대하여 설명하시오." → 요구 포인트: Ⅰ 추진 배경과 필요성 + Ⅲ C/S/O 3계층 모델 및 보안통제 기준 + Ⅵ 공공 혁신 및 고려사항

## 내 의견
- [기밀 지정 만능주의로 인한 신망 보안체계 유명무실화 위험] 처벌을 피하려는 공공기관 관행상 현업 부서가 거의 모든 데이터를 '민감/기밀'로 분류하여 기존 물리 망분리와 다를 바 없는 폐쇄망으로 회귀할 가능성 높음 → 나라면: 공공데이터법상 개방 의무 데이터와 연계하여 네거티브 규제 방식(기밀 제외 기본 공개/민감 원칙)을 적용하고, 자동화된 데이터 분류 엔진을 행정망 결재 시스템에 탑재하여 등급 판정 객관화
