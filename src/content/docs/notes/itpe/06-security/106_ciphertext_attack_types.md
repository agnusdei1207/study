## 답안 골격
```text
[암호문 공격 유형] ◀━━ 머리: Ⅶ 내 의견 (공격자 능력 가정의 현실화 → 선택 암호문 공격(CCA)에도 안전한 IND-CCA2 보안성 검증 알고리즘 채택)
 ┃
 ┣━ Ⅰ 개요 ───── 암호 분석가(공격자)가 보유한 정보의 수준과 암호화 장치에 대한 개입 능력에 따라 분류되는 현대 암호 해독 공격의 4대 표준 모델(COA, KPA, CPA, CCA)
 ┣━ Ⅱ 특징 ───── 공격자 권한 단계적 상승(수동적 도청 → 능동적 질의) · 보안성 증명의 기준선(IND-CPA, IND-CCA) 제공 · 암호 알고리즘의 강도 평가 척도
 ┣━ Ⅲ 구조 ───── 암호문 단독 공격(COA) < 기지 평문 공격(KPA) < 선택 평문 공격(CPA) < 선택 암호문 공격(CCA: CCA1, CCA2)
 ┣━ Ⅳ 흐름 ───── 수동적 암호문 수집(COA) → 평문-암호문 쌍 획득(KPA) → 원하는 평문 암호화 오라클 질의(CPA) → 원하는 암호문 복호화 오라클 질의(CCA) → 비밀키 복원 또는 평문 판별
 ┣━ Ⅴ 비교 ───── 4대 공격 유형 비교: 공격자 확보 정보(암호문 vs 평문-암호문 쌍 vs 암호화 장치 vs 복호화 장치) 및 공격 난이도
 ┗━ Ⅵ 실무 ───── 결정론적 암호화(Deterministic Encryption)의 CPA 취약점 / 오류 메시지를 통한 패딩 오라클(CCA) / 부채널 공격과의 결합
```
- 필수 키워드: COA(Ciphertext-Only Attack) · KPA(Known-Plaintext Attack) · CPA(Chosen-Plaintext Attack) · CCA(Chosen-Ciphertext Attack) · IND-CCA2 · 오라클 공격(Oracle Attack)
- 기출: 제137회 1교시 4번: "암호문 공격(Ciphertext Attack)을 설명하시오."

## 한 줄 본질
- 공격자가 암호문만 볼 수 있다는 안일한 가정의 취약성 병목 → 공격자가 임의의 암호문을 복호화 장치에 넣어 결과를 관찰할 수 있는 최악의 능력(CCA)을 가정하고 방어 설계 → 최고 수준의 수학적 안전성 확보 / 무결성 인증 태그(MAC) 등 추가 연산 오버헤드 발생

## 핵심 그림
```text
[암호 해독 4대 공격 모델의 공격자 능력 스펙트럼]

  공격자 능력 (상승) ───────────────────────────────────────────>
┌──────────────────┬──────────────────┬──────────────────┬──────────────────┐
│  COA             │  KPA             │  CPA             │  CCA             │
│  (암호문 단독)   │  (기지 평문)     │  (선택 평문)     │  (선택 암호문)   │
├──────────────────┼──────────────────┼──────────────────┼──────────────────┤
│ - 암호문 C 만    │ - 암호문 C 와    │ - 공격자가 선택한│ - 공격자가 선택한│
│   도청하여 보유  │   대응하는       │   평문 M을 암호화│   임의 암호문 C' │
│ - 통계적 빈도,   │   평문 M 일부 보유│  하여 C를 획득   │   의 복호화 결과 │
│   전수조사 의존  │ - 패턴 분석      │   (암호화 오라클)│   획득(복호 오라클)
└──────────────────┴──────────────────┴──────────────────┴──────────────────┘
  방어 요구 수준 (상향): 안전성 증명 ──> IND-CPA (기본) ───> IND-CCA2 (최고 수준)
```

## 핵심 용어
- 암호화 오라클 (Encryption Oracle): 공격자가 원하는 어떤 평문이든 입력하면 비밀키를 몰라도 해당 암호문을 즉시 반환해 주는 가상의 블랙박스 장치 (CPA 공격 모델의 전제)
- IND-CCA2 (Indistinguishability under Adaptive Chosen Ciphertext Attack): 공격자가 타깃 암호문을 본 후에도 타깃 암호문 자체를 제외한 다른 암호문들을 오라클에 적응적으로 질의할 수 있는 최악의 환경에서도 평문을 구별할 수 없는 최고 수준의 암호학적 안전성

## 핵심 통찰
- 현대 암호학에서 "COA나 KPA에만 안전한 암호"는 암호로 취급되지 않음 → 오늘날 모든 상용 공개키 및 대칭키 암호는 최소한 IND-CPA를 만족해야 하며, 통신 프로토콜에서는 IND-CCA2가 필수 요건임
- 교과서적인 RSA(Textbook RSA)는 동형성(M1^e * M2^e = (M1*M2)^e)을 가지므로 CPA 및 CCA에 완벽히 무력함 → 무작위 패딩(OAEP)을 적용해야만 CCA2 안전성을 획득함
- 실무에서 가장 흔한 CCA 공격은 '오라클'을 소프트웨어 에러 메시지 형태로 제공하는 것임 → 패딩이 틀렸는지, MAC이 틀렸는지를 알려주는 서버의 친절한 에러 응답이 공격자의 복호화 오라클 역할을 함

## 이웃 토픽과 구분
- CPA vs CCA: CPA = 공격자가 "암호화 기계"를 쥐고 있는 상황(공개키 암호는 공개키가 공개되어 있으므로 기본적으로 CPA 환경임) / CCA = 공격자가 "복호화 기계"의 일부 기능(유효성 검증, 시간차 등)을 쥐고 있는 상황

## 문제·원인·대책
- 사례: TLS 1.2 환경에서 CBC 모드 복호화 오류를 악용한 Bleichenbacher 및 POODLE 공격
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 동일한 평문 암호화 시 항상 동일한 암호문 생성 (CPA 취약) | 무작위성(Nonce, IV) 없는 결정론적(Deterministic) 암호화 사용 | 확률적 암호화(Probabilistic Encryption) 및 CBC/CTR 모드 IV 적용 | 동일 평문이라도 매번 무작위 암호문이 생성되어 식별 불가 |
| 수신자의 패딩 오류 응답을 악용한 적응적 선택 암호문 공격(CCA) | 복호화 성공 여부 및 에러 메시지의 시간차 정보 노출 | 패딩 검증 전에 먼저 메시지 무결성을 검증하는 AEAD(AES-GCM) 적용 | 변조된 암호문 복호화 자체를 즉시 거부하여 오라클 제거 |

## 이렇게 출제된다
- 제137회 1교시 4번: "암호문 공격(Ciphertext Attack)을 설명하시오." → 요구 포인트: Ⅰ 공격 모델 개요 + Ⅲ COA, KPA, CPA, CCA 4단계 구조 + Ⅴ 공격 능력 및 대응 알고리즘 비교표

## 내 의견
- [암호 라이브러리 선정 시 IND-CCA2 표준 준수 검증] 많은 레거시 사내 솔루션이 안전하지 않은 ECB 모드나 패딩 없는 RSA를 사용하여 CPA/CCA 공격에 노출되어 있음 → 나라면: 사내 표준 암호화 라이브러리를 'AES-256-GCM(대칭키)'과 'RSA-OAEP 3072비트 이상 또는 ECIES(공개키)'로 한정하고, 단위 테스트 단계에서 의도적 암호문 변조 테스트를 통해 복호화 에러 메시지가 항상 일정 시간(Constant-time)과 단일 에러 코드로 반환되는지 검증
