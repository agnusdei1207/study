# 콘텐츠 무해화 기술(CDR)

## 핵심 개념
- 문서(Office, PDF, HWP 등) 및 이미지 파일 내에 포함된 잠재적 보안 위협 요소(매크로, 자바스크립트, 실행 가능한 하이퍼링크 등 활성 콘텐츠)를 원천 분리·제거한 후 안전한 텍스트·시각 요소만 추출하여 원본 포맷으로 재조합(Reconstruction)하는 보안 기술.
- 알려진 악성코드 시그니처나 행위 분석에 의존하지 않고, 실행 가능한 모든 동적 요소를 악의적으로 간주하여 제거함으로써 제로데이(Zero-day) 공격을 사전에 차단.

```
+-------------------------------------------------------------+
|                      CDR 처리 4단계 프로세스                   |
+-------------------------------------------------------------+
| 1. 파일 분석(Analyze)   | 파일 포맷 파싱 및 구성요소 분해          |
| 2. 위협 격리(Disarm)    | 매크로, VBA, 임베디드 OLE, 악성 스크립트 제거|
| 3. 안전 데이터 추출     | 순수 텍스트, 이미지, 서식 데이터만 선별    |
| 4. 재조합(Reconstruct)  | 규격에 부합하는 안전한 새 문서 파일 생성   |
+-------------------------------------------------------------+
```

---

## CDR 동작 메커니즘 및 파이프라인

```
[외부 유입 파일 (PDF / Office / HWP)]
                  |
                  v
[1. 파일 유효성 검증 및 파싱 (Deconstruction)]
   - 파일 헤더/구조 분석, 비정상 확장자 위장 검증
                  |
                  v
+-------------------------------------------------------------+
| 구성요소 분리 (Splitting)                                    |
|  [안전한 정적 요소]                [잠재적 위험 요소 (Active)]|
|   - 텍스트 본문                     - VBA 매크로 / 악성 OLE   |
|   - 이미지 / 벡터 그래픽            - 임베디드 실행 파일 (PE) |
|   - 테이블 및 글꼴 스타일           - 악성 자바스크립트 / URL |
+-------------------------------------------------------------+
         |                                     |
         v                                     v
[안전 요소 유지]                      [원천 격리 및 폐기 (Disarm)]
         \                                     /
          \-------------------.---------------/
                              |
                              v
[2. 문서 재조합 (Reconstruction)]
   - 표준 파일 사양(ISO 32000, OOXML 등)에 맞추어 새 파일로 재생성
                              |
                              v
[사용자에게 안전한 무해화 문서 전달]
```

## 기존 보안 기술 vs CDR 비교

| 비교 항목 | 안티바이러스 (AV) | 지능형 행위분석 (샌드박스) | 콘텐츠 무해화 (CDR) |
|---|---|---|---|
| **동작 원리** | 알려진 시그니처 패턴 매칭 | 가상환경 내 파일 실행 및 이상행위 감시 | 파일 분해 후 비인가 활성 객체 원천 제거 |
| **제로데이 방어** | 시그니처 미등록 시 탐지 불가 | 회피 기술(가상화 감지, 지연 실행)에 우회 | 활성 객체 자체를 제거하므로 제로데이 무력화 |
| **분석 소요 시간** | 즉각적(수 밀리초) | 실행 관찰 시간 필요 (수 분 소요, 지연 발생) | 파일 분해·재합성 수 초 내 완료 (실시간성 우수) |
| **문서 기능성 영향** | 파일 구조 변경 없음 | 파일 구조 변경 없음 | 정당한 업무용 매크로까지 함께 제거될 수 있음 |
| **오탐/미탐** | 미탐율 존재 (신종 공격) | 오탐 및 우회 미탐 존재 | 미탐률 제로에 수렴 (모든 매크로 제거) |

## 주요 적용 영역 및 연계 아키텍처

### 1. 망연계(망간 자료전송) 시스템
- 외부 인터넷망에서 내부 업무망으로 전송되는 모든 문서 파일을 CDR 서버를 통과시켜 무해화된 안전한 파일만 내부망 반입 허용.

### 2. 이메일 보안 게이트웨이 (SEG, Secure Email Gateway)
- 수신 이메일의 첨부파일을 수신자에게 전달하기 전 실시간 CDR 처리를 거쳐 피싱 및 랜섬웨어 감염 예방.

### 3. 웹 다운로드 및 포털 업로드 게이트웨이
- 대민 포털에 업로드되는 민원 첨부파일, 사내 직원이 인터넷에서 다운로드하는 파일에 대해 실시간 무해화 적용.

---

## 결론 및 실무 시사점
- 파일 기반 지능형 악성코드가 고도화되고 샌드박스 우회 기법이 발달함에 따라, 무해화(CDR) 기술이 방어의 필수 요소로 정착됨.
- 업무에 필요한 정당한 매크로까지 무조건 삭제될 경우 현업의 반발을 초래할 수 있으므로, 문서 내 매크로 화이트리스트 사전 승인 절차 및 샌드박스와의 상호보완적 하이브리드 연동 구성이 필요함.
