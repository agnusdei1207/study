## 지식 로드맵 내 현재 위치

보안 운영 → 보안 로그 통합·분석 → 중앙 집중형 이벤트 관리(SIEM)

## 30초 인출

- **본질:** 이기종 네트워크, 서버, 보안 장비로부터 대량의 로그 데이터를 실시간 수집·정규화하여 다차원 상관분석 및 위협 탐지를 수행하는 중앙 통합 보안 플랫폼
- **메커니즘:** 분산 로그 수집 → 공통 스키마 정규화 및 시간 동기화 → 상관분석 룰 및 UEBA 머신러닝 탐지 → 보안 이벤트 경보 발령 → SOC 관제 분석 및 SOAR 대응
- 통찰: 단순 로그 적재와 임계치 룰셋의 경보 피로(Alert Fatigue)를 극복하기 위해 사용자·엔티티 행위 분석(UEBA)과 SOAR 기반의 자동화된 플레이북 오케스트레이션 연계 체계 필수

<details><summary>핵심 용어</summary>

- **SIEM(Security Information and Event Management):** 보안 정보 관리(SIM)의 장기 저장/보고서 기능과 보안 이벤트 관리(SEM)의 실시간 모니터링/상관분석을 결합한 플랫폼.
- **정규화(Normalization):** 방화벽, IPS, 윈도우 이벤트 등 제각각인 로그 포맷을 일관된 표준 필드(출발지 IP, 목적지 IP, 포트, 이벤트 유형)로 파싱·변환하는 작업.
- **상관분석(Correlation Analysis):** 서로 다른 시스템에서 발생한 이벤트들을 시간, IP, 계정 등의 연관성을 바탕으로 복합 룰을 적용해 침해 징후를 판별하는 기법.
- **UEBA(User and Entity Behavior Analytics):** 머신러닝 알고리즘을 활용하여 계정 및 단말의 정상 행위 베이스라인을 수립하고 비정상 일탈 행위를 식별하는 분석.
- **경보 피로(Alert Fatigue):** 매일 수천~수만 건의 오탐(False Alarm) 경보가 발생하여 보안 관제 요원의 집중도와 실제 위협 대응 능력이 저하되는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 전사 IT 인프라와 보안 장비로부터 발생하는 대용량 로그와 이벤트를 중앙에서 실시간 수집·정규화·저장하고 다차원 상관분석을 통해 지능형 위협을 탐지하는 통합 보안 관제 플랫폼 |
| 목적 | 전사 위협 가시성 확보, 복합 침해 공격의 조기 탐지, 침해 사고 포렌식 증적 보존 및 법적 컴플라이언스 준수 |

## Ⅱ. SIEM의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 이기종 로그 정규화 | 벤더마다 상이한 로그 형식을 공통 스키마(OCSF, CEF, CIM)로 표준화 변환 | 로그 파서(Regex, Grok), Syslog |
| 실시간 상관분석 | 단일 장비로는 식별할 수 없는 분산 침투 시나리오를 시간축과 자산축으로 교차 검증 | 룰 엔진(Drools, SPL), 시간 윈도우 |
| 위협 인텔리전스(TI) 결합 | 최신 악성 IP, 도메인, 파일 해시(IoC) 피드를 실시간 매칭하여 침해 위협 즉각 식별 | STIX/TAXII, MISP 연동 |
| 장기 감사 증적 보존 | 금융/공공 규제에 따른 로그 위변조 방지 및 1년 이상의 장기 아카이빙 지원 | WORM 스토리지, HDFS, S3 Glacier |

## Ⅲ. SIEM 아키텍처 및 침해 탐지 프로세스

```text
[ 1. 로그 생성 및 수집 계층 ]
방화벽 / IPS / WAF / EDR / 클라우드 로그 / AD 계정 로그
       │ Syslog / Winlogbeat / API Pull
       ▼
[ 2. 처리 및 정규화 계층 ] ── Kafka 버퍼 ── Logstash / Fluentd
       │  (시간 정합 NTP, PII 마스킹, 공통 스키마 OCSF 파싱)
       ▼
[ 3. 분석 및 탐지 계층 ] ── Elasticsearch / OpenSearch / Splunk
       ├── 실시간 상관분석 엔진 (다중 이벤트 조건 매칭)
       └── 머신러닝 UEBA 엔진 (비정상 권한 상승, 이상 트래픽 탐지)
       ▼
[ 4. 표출 및 대응 계층 ]
SOC 관제 대시보드 경보 표출 ──▶ 고위험 이벤트 SOAR 자동 차단 연계
```

| 단계 | 주요 활동 내용 | 핵심 기술 및 지표 |
|---|---|---|
| 1. 수집 | 분산된 네트워크·호스트·애플리케이션 로그의 무손실 수집 | Syslog-ng, Beats, 메시지 큐(Kafka) |
| 2. 파싱 및 정규화 | 필드 분리, NTP 기반 타임스탬프 동기화, 민감정보 암호화 | CEF, JSON, OCSF 표준 스키마 |
| 3. 상관분석 | 시나리오 기반 룰(Brute-force 후 관리자 로그인 등) 매칭 | 윈도우 타임 분석, 카운트 임계치 |
| 4. 행위 분석 | 계정별 평소 접속 시간/데이터 전송량 대비 비정상 편차 탐지 | 통계적 프로파일링, 비지도 학습 |
| 5. 경보 및 대응 | 위협 스코어링 및 SOC 티켓팅, SOAR 차단 플레이북 구동 | Webhook, REST API, SOAR 연동 |

## Ⅳ. SIEM vs SOAR vs XDR 비교

| 구분 | SIEM | SOAR | XDR (Extended Detection & Response) |
|---|---|---|---|
| 핵심 역할 | 로그 통합 수집, 장기 보존, 상관분석 탐지 | 보안 툴 간 조율(오케스트레이션) 및 자동 대응 | 엔드포인트/네트워크 네이티브 통합 탐지·대응 |
| 주요 데이터 | 텍스트 로그, 이벤트, 감사 기록 | SIEM 경보, 인시던트 티켓, API 페이로드 | 원시 텔레메트리(Raw Telemetry), 프로세스 트리 |
| 대응 방식 | 관제사에게 경보 표출 및 수동 티켓팅 | 플레이북 기반 자동화된 차단/격리 조치 | 플랫폼 자체 에이전트를 통한 네이티브 자동 격리 |
| 구축 형태 | 온프레미스 / 클라우드 데이터 레이크 | SIEM 상단에 연계되는 오케스트레이터 | SaaS 기반 단일 벤더 통합 패키지 |
| 한계점 | 오탐으로 인한 경보 피로, 대응 자동화 부재 | 고품질 플레이북 개발 및 API 연동 부담 | 타사 솔루션 연동 제약(Vendor Lock-in) |

## Ⅴ. SIEM 구축 및 운영의 한계와 방안

| 한계 | 방안 |
|---|---|
| 클라우드 및 마이크로서비스 전환으로 일일 수십 TB의 로그가 유입되어 인덱싱 지연 및 라이선스 비용 폭증 | 수집단에 경량 데이터 파이프라인(Vector, Kafka)을 배치하여 무의미한 노이즈 로그를 사전 드롭하고 Hot-Warm-Cold 스토리지 계층화 구축 |
| 단순 임계치 룰셋(Rule-based)에 의존하여 수천 건의 오탐 경보 발생 및 관제 인력의 경보 피로(Alert Fatigue) 극복 불가 | 머신러닝 기반 UEBA를 결합하여 사용자 행위 위험도(Risk Score) 기반으로 경보를 집약하고 정적 룰셋의 정기적 임계치 튜닝 |
| 침해 탐지 후 분석가가 수동으로 IP를 방화벽에 등록하고 단말을 격리하는 과정에서 골든타임 상실 | 침해 분석 결과 고신뢰 위협(True Positive)에 대해 방화벽/EDR과 연동된 SOAR 플레이북을 자동 격리 파이프라인으로 연결 |

## Ⅵ. 제언

```text
[ 전통적 1세대 SIEM ]                 [ 차세대 AI 기반 통합 SecOps ]
단순 로그 보관/검색 ──┐               ┌── 클라우드 네이티브 데이터 레이크
정적 임계치 룰 탐지 ─┼─→ [ 관제 마비 ] ─┼── 머신러닝 UEBA 기반 적응형 탐지
수동 분석 및 차단 ───┘               └── SOAR 연계 자율 대응 플레이북 가동
```

| 평가 영역 | 레거시 SIEM 체계 | 차세대 데이터레이크 SIEM | 향후 발전 방향 |
|---|---|---|---|
| 로그 처리 용량 | 단일 DB 스케일업 한계 | 분산 클라우드 오브젝트 스토리지 | 클라우드 레이크하우스(Snowflake) 연계 |
| 탐지 정밀도 | 시그니처 매칭 (미탐 취약) | 다차원 행동 분석 (UEBA 결합) | LLM 기반 자연어 쿼리 및 위협 헌팅 |
| 사고 대응 속도 | 수시간~수일 소요 | 수초 내 자동 플레이북 실행 | AI 에이전트 기반 자율 SOC(Autonomous SOC) |

SIEM은 사후 감사용 로그 저장소에서 벗어나 현대 보안관제센터(SOC)의 중추 신경망으로 진화하였으며, UEBA의 정밀 탐지와 SOAR의 신속한 조율 대응을 유기적으로 융합하는 것이 보안 운영의 핵심 과제.
