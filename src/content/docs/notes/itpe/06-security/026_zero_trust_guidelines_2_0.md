## Ⅰ. 국가 제로트러스트 가이드라인 2.0의 개요

- 개념 : 과학기술정보통신부와 한국인터넷진흥원(KISA)이 국내 정보통신 환경에 최적화하여 발표한 한국형 제로트러스트 보안 모델로서, 6대 핵심 보안 요소와 성숙도 모델, 참조 아키텍처 및 실무 도입 절차를 구체화한 국가 가이드라인.
- 배경 및 필요성 : 공공·민간의 클라우드 전환 가속화와 원격 근무 일상화로 기존 망분리 및 경계 보안의 한계가 명백해짐에 따라, 2023년 가이드라인 1.0(개념 정립)에 이어 실제 구축·운영 및 실증 사업 성과를 반영한 2.0 고도화 필요성 증대.
- 핵심 목적 : 한국형 제로트러스트 6대 핵심요소 식별, 기업 규모별 도입 성숙도(기본-발전-고도) 가이드 제공 및 망분리 완화 정책과의 연계 구현.

## Ⅱ. 국가 제로트러스트 가이드라인 2.0의 핵심 아키텍처 및 동작 메커니즘

가이드라인 2.0은 식별자(신원), 기기(단말), 네트워크, 시스템, 응용프로그램, 데이터의 6대 핵심 보안 요소를 정의하고, 도입 준비부터 지속 개선에 이르는 도입 절차를 제시함.

```text
[ 국가 제로트러스트 가이드라인 2.0의 6대 핵심 요소 및 제어 체계 ]

  +-------------------------------------------------------------+
  |              통합 제로트러스트 제어 평면 (PDP)              |
  |  - 정책 결정 엔진 (PE) + 정책 관리자 (PA)                    |
  |  - 위협 인텔리전스, 이상 행위 분석(AI), 컴플라이언스 연계    |
  +------------------------------┬------------------------------+
                                 │ 정책 지침 하달 (Control)
                                 ▼
  +-------------------------------------------------------------+
  | 6대 핵심 보안 요소 (Enforcement 계층 / PEP)                 |
  |  1. 식별자(Identity)   : 피싱 저항 MFA, 중앙 통합 IdP       |
  |  2. 기기(Device)       : 단말 무결성, EDR 연계 상태 검증    |
  |  3. 네트워크(Network)  : ZTNA, SDP, 마이크로세그멘테이션     |
  |  4. 시스템(System)     : 워크로드 보호, 가상화/컨테이너 격리|
  |  5. 애플리케이션(App)  : API 보안, 세션 단위 최소 권한 인가 |
  |  6. 데이터(Data)       : 민감도 분류, 저장/전송/사용 암호화 |
  +-------------------------------------------------------------+
```

- 6대 핵심 요소의 체계화 : 신원과 기기를 검증하여(Who & What) 네트워크와 시스템을 통제하고(Where & How), 애플리케이션과 데이터를 최종 보호(Which asset).
- **3단계 성숙도 모델(기본-발전-고도)** : 기본(수동 정책/초기 MFA), 발전(중앙화된 자동 정책/컨텍스트 평가), 고도화(머신러닝 기반 실시간 동적 신뢰 평가).
- **PDP/PEP 참조 아키텍처** : 컨트롤 플레인(제어 평면)과 데이터 플레인을 엄격 분리하여 모든 통신이 사전 승인된 암호화 터널로만 형성되도록 규정.
- **공공 망분리 개선과의 연계** : N2SF 다층보안체계의 C/S/O 등급제와 결합하여 논리적 격리를 위한 실질적 보안 통제 수단으로 채택.

## Ⅲ. 국가 제로트러스트 가이드라인 2.0의 세부 구성 요소 및 비교 분석

| 성숙도 단계 | 식별자 (Identity) | 네트워크 (Network) | 데이터 (Data) |
| --- | --- | --- | --- |
| 1단계: 기본 (Basic) | 정적 패스워드 + 2차 SMS/OTP 인증 | 서브넷 기반 방화벽, VPN 게이트웨이 | 중요 DB 단순 컬럼 암호화 |
| 2단계: 발전 (Advanced) | 중앙 집중 IdP, 조건부 액세스 정책 | ZTNA 도입, 소프트웨어 정의 경계(SDP) | DLP 도입, 자동 데이터 분류 및 라벨링 |
| 3단계: 고도화 (Optimal) | 지속적 무마찰 인증, FIDO2, UEBA | 완전한 마이크로세그멘테이션, 서비스메시 | DSPM 연계, 사용 중 암호화(기밀컴퓨팅) |

- 가이드라인 2.0은 일괄 전면 전환의 비용 부담을 고려하여, 기업이 현재 자사의 성숙도를 자가 진단하고 점진적으로 3단계 고도화로 이행할 수 있는 실무 로드맵을 제공함.

## Ⅳ. 국가 제로트러스트 가이드라인 2.0의 주요 한계점 및 해결 방안

- 국내 중소·중견기업의 솔루션 도입 예산 및 전문 인력 부족 :
  - 한계점 : 제로트러스트 2.0 구현을 위해 IdP, EDR, ZTNA, SIEM 등 다수의 고가 외산/국산 솔루션 결합이 필요하여 도입 장벽 고조.
  - 해결 방안 : 클라우드 서비스형(SECaaS) 형태의 통합 제로트러스트 플랫폼을 활용하고 정부의 중소기업 보안 바우처 지원 사업과 연계.
- 기존 망분리 법령(**전자금융감독규정** 등)과의 규제 충돌 :
  - 한계점 : 가이드라인 2.0은 논리적 통제를 권장하나, 금융·공공 법령은 여전히 물리적 망분리를 강제하고 있어 현장 적용 시 컴플라이언스 위반 리스크.
  - 해결 방안 : 규제 샌드박스(혁신금융서비스) 활용 및 국정원 N2SF/전자금융감독규정 개정에 맞춘 단계적 망분리 완화 실증 추진.
- 이기종 제로트러스트 솔루션 간 **상호운용성** (Interoperability) 부재 :
  - 한계점 : A사 IdP, B사 EDR, C사 ZTNA 게이트웨이 간에 실시간 신뢰 점수(Trust Score)를 교환할 수 있는 표준 프로토콜 결여.
  - 해결 방안 : CAEP(Continuous Access Evaluation Profile) 및 SSF(Shared Signals Framework) 표준을 준수하는 솔루션을 우선 도입.

## Ⅴ. 국가 제로트러스트 가이드라인 2.0 적용 및 발전을 위한 기술사적 제언

- '신원(IdP) 및 엔드포인트(EDR)' 우선의 2대 축 구축 : 전면 재구축 대신 가장 침해 빈도가 높은 계정 및 단말 보안부터 고도화 단계로 업그레이드.
- 국가 공공 제로트러스트 실증 사업 표준 모델 확산 : KISA 실증 과제에서 검증된 한국형 ZTNA 참조 아키텍처를 사내 정보화 사업 RFP 표준 규격으로 채택.
- **지속적 적응형 위험 및 신뢰 평가** (CARTA) 연계 : 한 번의 인증에 만족하지 않고 세션 전반의 행위를 AI로 실시간 평가하는 적응형 정책 엔진 내재화 필수.
