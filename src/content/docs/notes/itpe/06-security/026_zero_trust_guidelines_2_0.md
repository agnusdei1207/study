## 지식 로드맵 내 현재 위치

보안 아키텍처 → 제로트러스트 → 국가 제로트러스트 가이드라인 2.0 및 성숙도 모델

## 30초 인출

- **본질:** 과학기술정보통신부와 KISA가 국내 기업 및 공공기관의 환경에 적합하도록 6대 핵심 보호요소와 성숙도 모델을 정립한 국가 제로트러스트 구현 가이드라인
- **메커니즘:** 6대 보호요소(신원·기기·네트워크·시스템·응용·데이터) 진단 → 성숙도 4단계(기존·초기·고도·최적) 평가 → 단계적 ZTA 전환
- 통찰: 물리적 망분리 규제와의 충돌과 형식적 체크리스트 자가진단을 극복하기 위해 다층보안체계(MLS) 연계와 침해 공격 시뮬레이션(BAS) 실증 필수

<details>
<summary>핵심 용어</summary>

- **제로트러스트 가이드라인 2.0:** 1.0의 개념 정립을 넘어 실증 사업 결과와 구체적 성숙도 모델(CMM), 평가 체크리스트를 보강하여 발표한 국내 표준 실무 지침
- **6대 핵심 보호요소:** 신원(Identity), 기기(Device), 네트워크(Network), 시스템(System), 응용/워크로드(Application/Workload), 데이터(Data)
- **3대 핵심 철학:** 강화된 인증(Continuous MFA), 마이크로세그멘테이션(Micro-segmentation), 소프트웨어 정의 경계(SDP)
- **성숙도 모델 (CMM, Capability Maturity Model):** 기존(Traditional) → 초기(Advanced) → 고도(Advanced) → 최적화(Optimal) 4단계로 조직의 ZTA 이행 수준을 평가하는 프레임워크
</details>

## 2~4교시 예상문제 (25점)

> 과기정통부·KISA의 '제로트러스트 가이드라인 2.0'의 핵심 3대 철학과 6대 보호요소를 설명하고, 제로트러스트 성숙도 모델(CMM)의 4단계 평가 체계와 기존 1.0 대비 변경점 및 물리적 망분리 환경에서의 엔지니어링 구현 전략을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **제로트러스트 가이드라인 2.0** 은 과기정통부와 KISA가 국내 네트워크 인프라 및 보안 환경을 고려하여 6대 보호요소와 단계별 성숙도 평가 모델(CMM), 구체적 실증 사례를 집대성한 국가 차원의 보안 아키텍처 실무 안내서 |
| 목적 | 경계 기반 보안의 한계 극복, 클라우드·원격근무 확산에 따른 공격 표면 축소, 단계적 제로트러스트 도입 로드맵 제시 |

이론적 개념에 머물던 1.0에서 진화하여 실제 통신·금융·공공 실증 사업의 교훈과 구체적 기술 진단 메트릭을 수록.

## Ⅱ. 제로트러스트 가이드라인 2.0의 특징 및 6대 보호요소

```text
[제로트러스트 가이드라인 2.0의 6대 핵심 보호요소 체계]

 +---------------------------------------------------------------+
 |                        [신원 (Identity)]                      |
 |         사용자 계정, 서비스 계정, 역할, 다요소 인증(MFA)      |
 +-------------------------------+-------------------------------+
                                 | (접근 요청)
 +-------------------------------v-------------------------------+
 |                         [기기 (Device)]                       |
 |         단말 무결성, 보안 패치, EDR 상태, 위협 인텔리전스     |
 +-------------------------------+-------------------------------+
                                 | (컨텍스트 검증)
 +-------------------------------v-------------------------------+
 |                      [네트워크 (Network)]                     |
 |         소프트웨어 정의 경계(SDP), 마이크로세그멘테이션, mTLS |
 +-------------------------------+-------------------------------+
                                 | (암호화 터널 통신)
 +-------------------------------+-------------------------------+
 |       [시스템]        |     [응용 / 워크로드]  |     [데이터]  |
 | OS/가상화/서버 인프라 | 마이크로서비스/API 호출| 라벨링/DLP/암호화|
 +-----------------------+------------------------+---------------+
```

| 보호요소 | 핵심 진단 항목 | 엔지니어링 구현 기술 |
|---|---|---|
| **1. 신원 (Identity)** | 중앙화된 단일 신원, 상황 인지 기반 지속 인증 | SSO, FIDO2 패스워드리스, 조건부 액세스 |
| **2. 기기 (Device)** | 실시간 기기 신뢰도 판정(Posture Check), 미인가 단말 차단 | EDR, MDM, TPM 하드웨어 무결성 검증 |
| **3. 네트워크 (Network)** | 인바운드 포트 은닉(Dark IP), 최소 권한 통신 | SDP 게이트웨이, SPA(단일 패킷 인가), VXLAN |
| **4. 시스템 (System)** | OS 커널 및 하이퍼바이저 불변성 보장 | 시스템 무결성 모니터링(FIM), 불변 인프라 |
| **5. 응용/워크로드** | 서비스 간 mTLS 상호 인증 및 API 호출 인가 | 서비스 메시(Istio/Envoy), 컨테이너 CNI |
| **6. 데이터 (Data)** | 데이터 분류, 전송/저장 암호화, DRM 연계 | DSPM, 자동 라벨링, 토큰화, DLP |

## Ⅲ. 가이드라인 2.0의 3대 핵심 철학 및 성숙도 모델

```text
[제로트러스트 성숙도 모델 (CMM) 4단계 진화 프로세스]

 [Level 1: 기존]        [Level 2: 초기]        [Level 3: 고도화]       [Level 4: 최적화]
+---------------+     +---------------+     +---------------+     +---------------+
| 정적 방화벽   | --> | 부분적 MFA    | --> | 전사 SDP 도입 | --> | 행동기반 인증 |
| ID/PW 단일인증|     | VPN 원격 접속 |     | 워크로드 격리 |     | eBPF 동적격리 |
| 사일로화 운영 |     | SIEM 중앙 로깅|     | SOAR 연계     |     | ML 자율 대응  |
+---------------+     +---------------+     +---------------+     +---------------+
```

### 1. 제로트러스트 3대 핵심 철학

- **강화된 인증 (Continuous MFA):** 최초 로그인 1회로 끝내지 않고, 위험 신호(위치 변경, 이상 트래픽) 발생 시 지속적으로 재인증 요구.
- **마이크로세그멘테이션 (Micro-segmentation):** 동일 서브넷 내에서도 호스트 간 횡적 통신을 원천 차단하고 개별 워크로드 단위로 방화벽 격리.
- **소프트웨어 정의 경계 (SDP):** SPA 패킷으로 사전 인증된 단말에 대해서만 컨트롤러가 게이트웨이 포트를 동적으로 개방.

### 2. 제로트러스트 성숙도 모델 (CMM) 4단계

| 성숙도 단계 | 신원 및 기기 통제 | 네트워크 및 워크로드 통제 | 거버넌스 및 자동화 |
|---|---|---|---|
| **Level 1: 기존 (Traditional)** | 고정 패스워드, 수동 계정 관리 | 정적 방화벽, 대규모 서브넷 분할 | 수동 감사, 사일로화된 도구 |
| **Level 2: 초기 (Initial)** | 부분적 MFA 적용, 디바이스 자산 등록 | VPN 기반 원격 접속, 일부 L4 세그먼트 | 정기 감사, SIEM 로그 중앙화 |
| **Level 3: 고도화 (Advanced)** | 전사 SSO/MFA, 기기 상태 동적 평가 | SDP 적용, 워크로드 간 마이크로 세그먼트 | SOAR 연계, 정책 중앙 집중화 |
| **Level 4: 최적화 (Optimal)** | 행동 기반 연속 인증(UEBA), 무인 자율 인가 | eBPF 동적 네트워크 제어, 완전 암호화 | 머신러닝 기반 이상 탐지, 자율 치유 |

## Ⅳ. 가이드라인 1.0 vs 2.0 상세 비교

| 비교 항목 | 제로트러스트 가이드라인 1.0 (2023) | 제로트러스트 가이드라인 2.0 (2024~2026) |
|---|---|---|
| **발표 목적** | 제로트러스트 기본 개념 및 글로벌 표준(NIST) 소개 | **국내 환경 맞춤형 실전 도입 및 평가 기준 정립** |
| **보호요소 정의** | 6대 기본 요소의 개념적 나열 수준 | **보호요소별 세부 기술 명세 및 연계 메커니즘 구체화** |
| **성숙도 모델** | CISA 모델 단순 인용 (일반론) | **국내 공공·기업 실정에 맞춘 한국형 CMM 4단계 수립** |
| **실증 결과 반영** | 실증 사례 없음 (이론 중심) | **통신·금융·제조 분야 정부 실증 사업 결과 반영** |
| **망분리 규제 연계** | 전통적 물리적 망분리와의 관계 미정의 | **다층보안체계(MLS) 및 클라우드 연계 가이드 제시** |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **공공·금융의 물리적 망분리 규제와의 아키텍처 충돌**<br>가이드라인은 클라우드 및 원격접속 환경의 논리적 통제(SDP/ABAC)를 지향하나, 전자금융감독규정 및 공공 망분리 지침의 획일적 물리적 분리 조항으로 인해 도입 불가 | **국가 다층보안체계(MLS) 개편 연계 및 등급별 실증 특례**<br>국정원 다층보안체계(MLS: 기밀/탑시크릿, 민감/대외비, 공개) 개편과 발맞추어, 공개(O) 및 민감(S) 등급 시스템에 대해 물리적 망분리 대신 제로트러스트 논리적 통제를 법적 대체 수단으로 공인 |
| **체크리스트 위주의 형식적 자가진단 및 실시간 집행 누락**<br>인증 취득이나 보고용으로 성숙도 설문지만 고득점으로 작성하고, 실제 런타임 트래픽에 대한 실시간 PEP 정책 집행과 가시성 확보는 부재 | **BAS(침해 공격 시뮬레이션) 연계 정량적 성숙도 지속 검증**<br>모의 침투 및 악성 행위를 자동으로 주입하는 BAS 솔루션을 도입하여 SDP 포트 은닉 및 마이크로세그멘테이션의 횡적 이동 차단율을 실시간 메트릭으로 자동 측정 |

## Ⅵ. 제언

```text
[한국형 제로트러스트(K-ZTA) 전환 3단계 로드맵]

 +--------------------+     +---------------------+     +--------------------+
 | 1단계: 외부 접점   | --> | 2단계: 클라우드/DC  | --> | 3단계: 내부 업무망 |
 | VPN 전면 폐기      |     | 컨테이너 CNI 격리   |     | 전사 단말 EDR 연계 |
 | SDP / ZTNA 전환    |     | 서비스 메시 mTLS    |     | 마이크로세그멘트   |
 +--------------------+     +---------------------+     +--------------------+
```

| 전환 영역 | 우선 과제 | 기대 효과 |
|---|---|---|
| **1단계: 원격 접근** | 기존 SSL-VPN을 전면 퇴역시키고 SDP ZTNA 구축 | 외부 노출 포트 제거로 인터넷 공격 표면 원천 은닉 |
| **2단계: 클라우드 인프라** | 쿠버네티스 환경에 Cilium eBPF 마이크로세그멘테이션 적용 | 파드 간 비인가 횡적 이동(Lateral Movement) 원천 봉쇄 |
| **3단계: 전사 엔드포인트** | 통합 IdP(Okta/Azure AD) 및 단말 포스처 기반 조건부 액세스 | 크리덴셜 유출 시에도 미인가 단말 접근 완벽 차단 |

가이드라인 2.0을 일회성 진단표로 소비하지 않고, 외부 접점 VPN 대체부터 시작하여 클라우드 워크로드 격리로 확장하는 단계적 도입 로드맵 실행 권장.
