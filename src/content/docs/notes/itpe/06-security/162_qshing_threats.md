## 30초 인출

- **본질:** 큐싱은 악성 주소를 QR코드에 넣어 사용자가 가짜 로그인·결제 화면으로 이동하도록 유도하는 피싱.
- **메커니즘:** QR코드 노출 → 휴대전화로 스캔 → 피싱 사이트·앱 설치 유도 → 자격증명·결제정보 탈취.
- **핵심 대응:** QR코드의 출처 확인, 이동 주소 점검, 계정·세션 보호.

<details>
<summary>핵심 용어</summary>

- **큐싱(QR Code Phishing)**: QR코드를 매개로 악성 주소에 접속하게 해 정보 입력·결제·앱 설치를 유도하는 피싱.
- **QR(Quick Response) 코드**: 문자·주소 등을 기계가 읽을 수 있도록 2차원으로 표현한 코드.
- **피싱(Phishing)**: 신뢰하는 기관·사람을 사칭해 정보를 빼내거나 위험한 행동을 유도하는 공격.
- **세션 쿠키**: 웹 서비스가 로그인 상태를 식별하는 데 쓰는 값.
- **MFA(Multi-Factor Authentication)**: 서로 다른 인증 요소를 둘 이상 사용하는 방식.
</details>

## 1교시 10점 답안

### Ⅰ. 정의·목적

| 구분 | 내용 |
|---|---|
| 정의 | **큐싱(QR Code Phishing)**은 악성 주소가 담긴 QR코드로 가짜 화면·앱에 접근하게 만드는 피싱 |
| 목적 | QR코드 출처와 이동 주소를 확인해 계정·결제정보 탈취 예방 |

### Ⅱ. 공격과 방어

```text
QR코드 노출
    ↓ 휴대전화로 스캔
악성 주소·가짜 화면
    ↓ 정보 입력·앱 설치 유도
계정·결제정보 탈취
```

| 노출 경로 | 점검 |
|---|---|
| 이메일·문서의 QR | 발신자와 이동 주소를 별도 확인 |
| 현장 부착 QR | 스티커 덧붙임·공식 안내판 확인 |
| 로그인 화면 | 도메인·인증수단·의심 요청 확인 |

**제언:** QR 링크에서 로그인·결제 요청이 나오면 공식 앱이나 직접 입력한 주소로 다시 확인.

## 2~4교시 25점 답안

## Ⅰ. 큐싱의 정의와 목적

| 구분 | 내용 |
|---|---|
| 정의 | **큐싱(QR Code Phishing)**은 악성 주소가 담긴 QR코드로 가짜 화면·앱에 접근하게 만드는 피싱 |
| 목적 | QR코드 출처와 이동 주소를 확인해 계정·결제정보 탈취 예방 |

QR코드는 주소를 육안으로 바로 읽기 어려워 이메일에서 휴대전화로 이동할 때 기존 URL 검사 경계가 달라질 수 있음.

## Ⅱ. 공격 흐름과 노출 경로

```text
QR코드 노출
    ↓ 휴대전화로 스캔
악성 주소·가짜 화면
    ↓ 정보 입력·앱 설치 유도
계정·결제정보 탈취
```

| 경로 | 위장 방식 | 피해 |
|---|---|---|
| 이메일·첨부 문서 | 회사·기관 안내 사칭 | 계정 탈취 |
| 현장 부착물 | 정상 QR 위에 스티커 부착 | 결제정보 탈취 |
| 택배·인쇄물 | 확인·환급 안내 사칭 | 개인정보·앱 설치 |

## Ⅲ. 일반 링크 피싱과의 차이

```text
이메일 속 QR 이미지
    ↓ 기존 메일 URL 검사에서 놓칠 수 있음
사용자의 휴대전화
    ↓ 관리되지 않는 브라우저·앱 가능
가짜 로그인·결제 페이지
```

| 관점 | 일반 링크 | QR 링크 |
|---|---|---|
| 주소 확인 | 메시지에서 주소가 보일 수 있음 | 스캔 전에는 주소 확인 어려움 |
| 접속 기기 | 메일 열람 기기에서 이어질 수 있음 | 휴대전화로 이동하는 경우 많음 |
| 탐지 | 링크 검사 적용 가능 | 이미지 해석·모바일 경로 고려 필요 |

## Ⅳ. 예방과 사고 대응

```text
QR 수신
    ↓ 출처·이동 주소 확인
공식 앱·직접 입력 주소와 대조
    ↓ 의심 시 입력 중단·신고
입력했으면 암호 변경·세션 폐기
```

| 담당 | 조치 |
|---|---|
| 사용자 | QR 출처·최종 도메인 확인 |
| 보안 관리자 | 메일의 QR 이미지·리다이렉트 경로 검사 |
| 사고 대응 | 계정·세션·결제정보 노출 범위 확인 |

## Ⅴ. 한계와 제언

| 한계 | 대응 |
|---|---|
| 메일의 문자 URL만 검사하면 QR 이미지에 숨은 링크를 놓침 | QR 이미지 해석과 최종 이동 주소 검사를 메일·모바일 경계에 연결 |
| 사용자 교육만으로 현장 부착물 위조를 막기 어려움 | 공식 QR 부착물의 정기 점검과 신고 채널 마련 |
