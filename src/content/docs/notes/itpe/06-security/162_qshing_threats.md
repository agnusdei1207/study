## Ⅰ. 큐싱(QR Code Phishing)의 개요

- 개념 : 공격자가 **QR 코드** (Quick Response Code)에 피싱 사이트 URL, **악성 애플리케이션 다운로드 링크** 또는 악의적인 결제 스크립트를 삽입하여 정상적인 안내판이나 이메일에 위장 배치하고, 이를 스마트폰으로 스캔한 피해자의 금융 정보, 계정 자격증명, 개인정보를 탈취하는 사이버-물리 복합 보안 위협.
- 배경 및 필요성 : 스마트폰 카메라를 이용한 QR 코드 스캔이 비접촉 주문, 대중교통, 공유 모빌리티, 결제 등 일상 생활에 깊숙이 정착하였으나, 인간의 시각으로는 QR 코드 내부의 실제 목적지 링크를 사전에 검증할 수 없다는 치명적 보안 맹점이 악용됨.
- 핵심 목적 : 전통적인 이메일 보안 솔루션의 텍스트 기반 악성 URL 필터링을 우회하고, 사용자의 모바일 단말을 감염시켜 OTP 탈취, 소액 결제, 사내 인트라넷 계정 도용을 감행.

## Ⅱ. 큐싱(QR Code Phishing)의 핵심 아키텍처 및 동작 메커니즘

큐싱 위협은 물리적 환경의 오프라인 스티커 조작, 엔터프라이즈 이메일 침투를 위한 이미지 기반 우회, 모바일 악성 APK 다운로드 및 C2 통신의 다차원 공격 표면으로 전개됨.

```text
[ 큐싱(QR Code Phishing) 다차원 위협 벡터 및 방어 아키텍처 ]

 1. 물리적 위협 벡터 (Physical Attack Vector)
    * 공공 자전거 / 전동 킥보드 / 식당 결제 QR 코드
    * 정상 QR 위에 정교한 악성 QR 스티커 덧붙이기 (Overstickering)
 
 2. 디지털 위협 벡터 (Digital Attack Vector)
    * 피싱 이메일 본문에 텍스트 링크 대신 QR 코드 이미지 첨부
    * "MFA 인증 만료, 계정 잠김 예고: 스마트폰으로 QR을 스캔하세요"
    * 보안 이메일 게이트웨이(SEG)의 텍스트 URL 분석 완벽 우회!
                |
                v (사용자가 스마트폰 카메라로 스캔)
 +-------------------------------------------------------------+
 |              모바일 단말기 브라우저 (피싱 사이트 접속)      |
 |  - 유사 도메인 (Typosquatting: corp-login.com 등)            |
 |  - 가짜 로그인창에서 사내 계정 ID/PW 및 2차 인증번호 입력  |
 |  - 또는 원격 제어용 악성 APK(보안 모듈 위장) 백그라운드 다운 |
 +------------------------------+------------------------------+
                                |
                                v
 +-------------------------------------------------------------+
 |                      공격자 C2 서버                         |
 |  * 사내 SSO 계정 자격증명 즉시 획득                         |
 |  * 금융 OTP 가로채기 -> 무단 계좌 이체 및 내부망 침투       |
 +-------------------------------------------------------------+
 ================================================================
 [ 기술적 방어 체계: OCR 딥스캔, 안전 QR 스캐너, FIDO2 패스키 ]
```

- **물리적 덧붙이기(Overstickering)** : 공유 킥보드, 키오스크, 주차 요금 정산기 등 공공장소에 노출된 정상 QR 코드 위에 동일한 크기의 악성 스티커를 덧붙여 다수의 무작위 이용자 유인.
- **이메일 보안 게이트웨이(SEG) 필터 우회** : 본문에 하이퍼링크가 없어 일반적인 안티스팸 필터를 무사 통과하며, 사용자로 하여금 PC에서 모바일 단말로 플랫폼을 전환하게 만들어 PC 백신의 보호망을 무력화.
- **다단계 리다이렉션과 동적 URL 난독화** : QR 코드 스캔 시 초기에는 정상 URL로 접속되었다가 클라이언트 User-Agent가 모바일인 경우에만 악성 피싱 사이트로 리다이렉트하는 지능형 회피.
- **원격 제어 악성 APK 유포** : 뱅킹 앱이나 공공기관 안내 앱으로 위장한 악성 APK를 자동 다운로드하게 하여 SMS 수신 권한과 통화 녹음 권한을 장악.

## Ⅲ. 큐싱(QR Code Phishing)의 세부 구성 요소 및 비교 분석

| 비교 항목 | **큐싱 위협** (Qshing) | **전통적 이메일 피싱** | **문자 스미싱** (Smishing) |
| --- | --- | --- | --- |
| 전달 매체 | QR 코드 그래픽 이미지 | 이메일 본문 텍스트 링크 | SMS/MMS 단문 메시지 링크 |
| 인식 방식 | 스마트폰 카메라 광학 스캔 | PC 마우스 클릭 | 스마트폰 화면 터치 |
| 보안 솔루션 우회 | 텍스트 기반 검사 도구 완벽 우회 | 스팸 필터 및 URL 평판 분석에 탐지 | 통신사 문자 필터링 및 키워드 차단 |
| 사용자 심리 | 호기심, 빠른 인증 유도 | 긴급한 업무 요청, 세금 고지 위장 | 택배 배송, 모바일 청첩장 위장 |
| 핵심 대응 | 광학 문자 인식(OCR), 모바일 EDR | DMARC/SPF, 피싱 도메인 차단 | RCS 안심 마크, 번호 도용 차단 |

- 큐싱은 PC의 강력한 엔터프라이즈 보안망을 벗어나 상대적으로 보안이 취약한 개인 모바일 단말로 공격 무대를 옮기는 지능형 우회 공격이므로, 모바일 단말 관리(MDM)와 결합된 방어가 필수적임.

## Ⅳ. 큐싱(QR Code Phishing)의 주요 한계점 및 해결 방안

- QR 코드 내부의 인간 시각적 인지 불가능성 :
  - 한계점 : 2차원 바코드 매트릭스 특성상 사용자가 스캔 전에 목적지 도메인을 사전에 육안으로 식별할 수 있는 방법이 전무함.
  - 해결 방안 : 모바일 카메라 앱에서 링크를 바로 열지 않고, 디코딩된 전체 URL과 도메인 평판 분석 결과를 사용자에게 명시적으로 경고하는 안전 브라우징 탑재.
- 이메일 게이트웨이(SEG)의 이미지 OCR 처리 부하 및 지연 :
  - 한계점 : 수신되는 모든 이메일 첨부 이미지와 PDF 내의 QR 코드를 실시간 광학 문자 인식(OCR)으로 파싱하는 데 막대한 서버 컴퓨팅 부하 유발.
  - 해결 방안 : 경량화된 비전 AI 모델을 파이프라인에 배치하여 QR 코드 존재 여부만 고속 탐지하고, QR이 검출된 이메일에 한해 심층 샌드박싱 수행.
- 오프라인 물리적 부착물의 실시간 현장 순찰 한계 :
  - 한계점 : 공공기관이나 프랜차이즈 매장의 수많은 안내판에 부착된 악성 큐싱 스티커를 일일이 관리 인력이 감시·제거하기 어려움.
  - 해결 방안 : QR 코드 표면에 훼손 방지 홀로그램 패턴 적용, 변조 시 자동 파기되는 특수 파괴성 스티커 재질 도입.

## Ⅴ. 큐싱(QR Code Phishing) 적용 및 발전을 위한 기술사적 제언

- 이메일 보안 솔루션의 QR 코드 전용 디코딩 및 동적 분석 탑재 : 기업 이메일 게이트웨이에 QR 코드 자동 추출 및 최종 랜딩 URL 다단계 추적 샌드박스 엔진을 의무 연동.
- FIDO2 기반 패스키(Passkey) 전면 적용을 통한 피싱 자격증명 탈취 차단 : 사용자가 큐싱 사이트에 유인되어 접속하더라도 오리진(도메인)이 일치하지 않으면 패스키 인증이 거부되므로 계정 유출을 원천 방어.
- 대국민 큐싱 예방 수칙 홍보 및 '공인 보안 QR' 인증제 도입 : 출처가 불분명한 QR 스캔 금지, 앱 설치 유도 시 즉시 중단 등 대국민 홍보를 강화하고, 금융/공공 기관에 암호학적 전자서명이 포함된 보안 QR 체계 확립.
