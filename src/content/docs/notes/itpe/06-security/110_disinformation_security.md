## 지식 로드맵 내 현재 위치

지식 위치: 정보 환경 보안 → 영향 공작 → **허위정보 대응**

## 30초 인출

- Disinformation은 의도적 기만을 포함한 허위·조작 정보. 오보(Misinformation)와 의도 구분 필요
- DISARM은 영향 공작의 전술·기법을 기록·공유하는 틀. FIMI는 외국 행위자와 관련된 정보 조작·간섭을 가리키는 정책·분석 용어
- C2PA 자격증명은 서명된 출처 주장의 검증 수단으로, 내용의 진실성 판정기는 아님

## 1교시 예상문제 (10점)

> 허위정보 위협의 전파 구조와 출처증명·팩트체크의 역할을 설명하시오. (예상·10점)

## 1교시 10점 답안

### Ⅰ. 개념·전파

```text
행위자 → 허위 주장·조작 매체 제작 → 계정·채널 배포
       → 반복·증폭 → 수용자 노출·행동 영향
```

### Ⅱ. 대응 구분

| 수단 | 확인 대상 |
|---|---|
| DISARM | 공작의 전술·기법·행동 패턴 |
| C2PA | 서명된 콘텐츠 출처·편집 주장 |
| 팩트체크 | 주장과 독립 증거의 대조 |
| 플랫폼 조치 | 조직적 사칭·비정상 증폭 행동 |

## 2~4교시 예상문제 (25점)

> 허위정보 공작의 탐지·분석·대응 과정을 DISARM과 출처증명 관점에서 설명하고 오판·표현의 자유 위험을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 위협 정의

의도적으로 조작된 주장·매체를 이용해 수용자 판단을 왜곡하는 정보 작전. 국가 행위자만 해당하거나 모든 잘못된 정보가 악의적인 것은 아님.

### Ⅱ. 분석 흐름

| 단계 | 분석 증거 |
|---|---|
| 기획·자산 준비 | 사칭 도메인·계정·내러티브 |
| 콘텐츠 제작 | 이미지·영상·텍스트의 주장과 출처 |
| 유포·증폭 | 계정 연결·게시 시각·반복·봇 징후 |
| 영향 | 도달·공유·현실 피해와 반박 확산 |

DISARM은 전술·기법 언어로 관측 행동을 정리하는 도구이며, 모든 사건이 고정된 선형 5단계를 밟는다는 의미는 아님.

### Ⅲ. 검증 수단의 역할과 한계

| 수단 | 가능한 일 | 할 수 없는 일 |
|---|---|---|
| C2PA | 매니페스트·서명·콘텐츠 결합 확인 | 주장 자체의 진실성 보증 |
| 탐지 모델 | 조작 가능성의 신호 제공 | 모든 딥페이크 확정 판정 |
| 독립 출처 대조 | 사건·시각·장소의 사실 확인 | 모든 의도·행위자 자동 특정 |

### Ⅳ. 대응 절차

```text
이상 확산 탐지 → 원본·출처·독립 증거 수집
              → 조직적 조작 여부 분석
              → 사실 확인·정정·플랫폼 신고
              → 대응 근거 보존·오판 재검토
```

### Ⅴ. 권리·운영 고려

풍자·비판·오보를 악성 공작으로 성급하게 분류하지 않음. 조직적 사칭·가짜 계정 같은 행동 증거와 내용의 사실 확인을 분리. 금융시장·선거 피해 규모는 사건별 공식 근거 없이 단정 금지.

### Ⅵ. 기술사적 제언

콘텐츠 진위의 단일 자동 판정 대신 출처·행동·독립 증거를 결합하고, 정정·이의제기 절차를 함께 설계.
