## 지식 로드맵 내 현재 위치

- 정보보안 → 제어시스템(OT/ICS) 및 융합보안 → 사이버 물리 시스템(CPS) → 스마트 그리드 보안

```text
[스마트 그리드 생태계]
  ├── 지능형 원격검침 (AMI)   ──> 스마트 미터(Meter) 조작, 계량 데이터 변조, 프라이버시 침해
  ├── 전력 계통 제어 (SCADA) ──> EMS/DMS 제어 명령 위조, 대규모 광역 정전(Blackout) 유발
  └── 분산 에너지 자원 (DER)  ──> ESS/태양광 인버터 악성 제어, 주파수·전압 교란
                               │
                               ▼
        [NISTIR 7628 / IEC 62351 기반 종단간 암호화 및 심층 방어 체계]
```

## 30초 인출

- **본질:** 양방향 디지털 통신과 전력망이 결합된 사이버-물리 시스템(CPS) 환경에서 제어 명령 위조, 계량 데이터 변조, 펌웨어 감염을 통해 물리적 전력 공급 마비와 설비 파괴를 야기하는 보안 위협.
- **메커니즘:** 무선/PLC 통신 도청 및 중간자(MitM) 공격 → 제어 프로토콜(DNP3/Modbus) 무인증 취약점 악용 → 악성 제어 명령 주입 → 차단기 오동작 및 국가 기반시설 광역 정전.
- **통찰:** 단순 IT 망분리만으로는 유지보수용 원격 접속 및 공급망 펌웨어 변조를 방어할 수 없으므로, IEC 62351 기반의 제어 패킷 전자서명과 하드웨어 보안모듈(HSM/KCMVP) 탑재 필수.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 기존 전력망에 IT 및 통신 기술을 접목하여 공급자와 소비자가 실시간으로 정보를 교환하는 지능형 전력망에서 발생하는 기밀성, 무결성, 가용성 침해 위협 |
| 목적 | 계량 데이터의 위변조 방지, 소비자 프라이버시 보호, 전력 공급망의 무중단 가용성(24/7) 및 물리 설비 파괴(Blackout) 예방 |

- 기존 폐쇄망 중심의 전력 계통이 IP 네트워크와 양방향 통신으로 개방됨에 따라 사이버 공간의 공격이 대규모 물리적 재난으로 직결되는 위험성 증대.

## Ⅱ. 스마트 그리드의 핵심 특징 및 사이버-물리(CPS) 위험성

### 1. 스마트 그리드의 핵심 특징

| 특징 | 설명 | 기술적 파급 영향 |
|---|---|---|
| 양방향 통신 결합 | 전력 공급자와 소비자 간 실시간 데이터 교환 | 지능형 검침 인프라(AMI)를 통한 광범위한 외부 공격 표면 노출 |
| IT와 OT의 융합 | 정보시스템(ERP)과 물리 제어망(SCADA) 연계 | 상용 OS 및 TCP/IP 표준 프로토콜 도입으로 기성 악성코드 감염 위험 전파 |
| 사이버-물리 결합 (CPS) | 소프트웨어 명령이 물리적 기계 설비 구동 | 발전기 터빈 과속, 변전소 차단기 개방 등 물리적 기기 폭발 및 설비 소손 |
| 초저지연 실시간성 요구 | 밀리초(ms) 단위의 계통 제어 타이밍 | 무거운 비대칭키 암호화 적용 시 제어 지연으로 인한 전력 계통 불안정 초래 |

### 2. 스마트 그리드 보안 3대 요소의 우선순위 역전

```text
[전통 IT 보안 vs 스마트 그리드(OT) 보안 우선순위]
  전통 IT 시스템:   1. 기밀성 (C)  ──>  2. 무결성 (I)  ──>  3. 가용성 (A)
  스마트 그리드:    1. 가용성 (A)  ──>  2. 무결성 (I)  ──>  3. 기밀성 (C)
  * 정전 방지를 위한 '가용성'과 제어 명령 왜곡을 막는 '무결성'이 최우선 과제임
```

## Ⅲ. 스마트 그리드 구성 요소별 보안 아키텍처

### 1. NISTIR 7628 기반 종단간 보안 아키텍처

```text
+-----------------------------------------------------------------------------------------+
|                               스마트 그리드 엔드투엔드 보안 아키텍처                       |
+-----------------------------------------------------------------------------------------+
  [수용가 영역 (HAN/BAN)]          [집중/통신 영역 (NAN/WAN)]          [전력 제어/운영 영역]
  - 스마트 가전 / 전기차(EV)      - 데이터 집중장치 (DCU)             - 원격검침 헤드엔드 (HES)
  - 스마트 미터 (Smart Meter)     - 전력선 통신(PLC) / 무선 LTE/5G    - 전력관리시스템 (EMS/SCADA)
  - 하드웨어 보안칩 (HSM)         - TLS / IPsec 암호화 터널          - 계량데이터관리 (MDMS)
         │                                   │                                    │
         └──(Zigbee/Wi-SUN 보안)──> [DCU] ───┴──(IEC 62351-3/4 TLS)──> [단방향 보안 게이트웨이]
                                                                                  │
                                                                                  ▼
                                                                       [물리적 제어망 분리 유지]
+-----------------------------------------------------------------------------------------+
```

### 2. 주요 제어 프로토콜 및 보안 표준 적용

| 계통 영역 | 표준 프로토콜 | 기존 보안 취약점 | 표준 보안 대책 (IEC 62351) |
|---|---|---|---|
| 변전소 자동화 | IEC 61850 (GOOSE, SV) | 평문 멀티캐스트 전송, 재생 공격 취약 | IEC 62351-6 (디지털 서명 및 HMAC-SHA256 인증) |
| 원격 제어 통신 | DNP3, Modbus TCP | 인증 부재, 명령 변조 및 스푸핑 가능 | IEC 62351-5 (DNP3 Secure Authentication v5) |
| AMI 통신 계층 | DLMS/COSEM | 키 관리 취약, 도청 및 리플레이 노출 | IEC 62351-9 (PKI 인증서 및 대칭키 정기 갱신) |
| SCADA 네트워크 | TCP/IP, ICCP (IEC 60870-6) | 세션 하이재킹 및 중간자 도청 | IEC 62351-3 (mTLS 기반 전송 계층 암호화) |

## Ⅳ. 스마트 그리드 영역별(AMI, SCADA/EMS, DER) 위협 및 보안 대책 비교

### 1. 3대 핵심 도메인별 위협 및 대책 비교

| 비교 항목 | 지능형 원격검침 (AMI) | 계통 감시제어 (SCADA/EMS) | 분산 에너지 자원 (DER / ESS) |
|---|---|---|---|
| 주요 구성 | 스마트 미터, DCU, HES, MDMS | RTU, PLC, HMI, EMS 서버 | 태양광 인버터, 배터리 관리(BMS), EV 충전기 |
| 주요 보안 위협 | 전기요금 조작, 대량 미터기 벽돌화(Bricking), 사용자 생활패턴 도청 | 변전소 원격 차단기 트립(Trip), 계통 주파수 왜곡을 통한 광역 정전 | 인버터 위상각 조작, ESS 배터리 과충전 유도로 화재/폭발 유발 |
| 공격 기법 | 펌웨어 위조, 무선 도청, 물리적 탬퍼링 | Stuxnet형 악성코드, 제어 명령 인젝션 | 클라우드 플랫폼 해킹, Modbus 프로토콜 변조 |
| 핵심 방어 기술 | 물리적 탬퍼 감지 센서, KCMVP 인증 암호칩 | 단방향 데이터 전송 장비(Data Diode), 패킷 서명 | 제어 명령 이상치 AI 탐지, 인버터 제어 권한 분립 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 현장에 이미 수백만 대 설치된 레거시 스마트 미터 및 RTU 장비의 CPU 성능과 메모리 용량이 극도로 낮아 고강도 공개키 암호(RSA/ECC) 탑재 불가 | 연산 부하가 적은 경량 블록 암호 알고리즘(ARIA, LEA) 및 ChaCha20-Poly1305를 적용하고 하드웨어 기반 보안 칩(KCMVP 검증 암호모듈)을 일체형으로 모듈화 |
| 변전소 간 고속 보호 제어(GOOSE 메시지)는 4ms 이내의 엄격한 전송 지연 한계를 요구하여 암호화 연산 시 시간 초과(Timeout)로 인한 전력망 차단 발생 | 전체 페이로드를 암호화하는 대신 메시지 인증 코드(HMAC)만 병렬 하드웨어 파이프라인으로 생성하여 4ms 지연 조건을 충족하는 고속 무결성 인증 체계 구현 |
| 스마트 미터 원격 무선 펌웨어 업데이트(FOTA) 과정에서 공격자가 서명되지 않은 악성 펌웨어를 브로드캐스트하여 수십만 가구 동시 정전(Bricking) 위험 | 보안 부팅(Secure Boot) 기반 하드웨어 신뢰 루트(Root of Trust)를 구현하고, 다중 관리자 서명이 검증된 펌웨어만 수용하며 단계적 카나리(Canary) 롤아웃 강제 |

## Ⅵ. 제언

### 1. 스마트 그리드 제로 트러스트 다계층 제어 모델

```text
[물리적 발전/변전 설비] ──(단방향 데이터 전송기: Data Diode)──> [모니터링 전용 SCADA망]
                                                                            │
[원격 유지보수 엔지니어] ──> [ZTNA 인증 게이트웨이] ──> [명령어 인가 프록시] ──┘
  - FIDO2 피싱 저항 인증      - 이상 명령 차단(AI 룰셋)     (승인된 제어 패킷만 통과)
  - 전용 관리 단말기 한정      - 이중 승인(2-Man Rule)
```

### 2. 스마트 그리드 보안 기술 성숙도 비교 평가

| 보안 기술 | 구축 복잡도 | 계통 안정성 영향 | 보안 효과성 | 비고 |
|---|---|---|---|---|
| 단방향 보안 게이트웨이 | 중간 | 전혀 없음 (물리적 차단) | 최고 (외부 침투 원천 차단) | 제어망에서 업무망으로의 일방향 데이터 수집 |
| IEC 62351 프로토콜 암호화 | 높음 | 보통 (지연 시간 튜닝 필수) | 최상 (명령어 변조 차단) | 차세대 변전소 자동화(IEC 61850) 표준 규격 |
| 스마트미터 보안칩 (HSM) | 중간 | 낮음 | 상 (키 탈취 방지) | 미터기 제조 단계부터 KCMVP 모듈 실장 |
| OT 전용 이상 징후 탐지 (NDR) | 낮음 | 없음 (패시브 미러링) | 상 (비정상 제어 명령 식별) | AI 기반 제어 프로세스 이상치 실시간 감시 |

- 스마트 그리드 보안은 IT 시스템의 관점을 벗어나 전력 계통의 물리적 가용성과 실시간성을 최우선으로 고려해야 하며, IEC 62351 기반의 통신 무결성과 단방향 물리 망분리를 결합한 CPS 심층 방어 체계 확립 필수.
