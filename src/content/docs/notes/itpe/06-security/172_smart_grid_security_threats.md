## 연관 키워드

- 스마트 그리드(Smart Grid), AMI(Advanced Metering Infrastructure), SCADA(Supervisory Control and Data Acquisition), EMS(Energy Management System)
- DER(Distributed Energy Resource), ESS(Energy Storage System), OT(Operational Technology), CPS(Cyber-Physical System)
- IEC 62351, IEC 61850, DNP3, 데이터 다이오드(Data Diode), KCMVP, 대정전(Blackout), 마이크로 세그멘테이션

## Ⅰ. 스마트 그리드 보안 위협의 개요

- 핵심 요약 : 폐쇄되어 있던 전력망이 양방향 통신과 스마트 미터, 분산 전원에 연결되면서 사이버 공격이 물리적 대정전으로 이어지는 위협.
- 개념 : 단방향 전력망에 사물인터넷(IoT, Internet of Things), 양방향 통신망, **AMI** (Advanced Metering Infrastructure, 스마트 미터와 검침 서버를 잇는 계측 인프라)를 결합한 **스마트 그리드** (Smart Grid)에 가해지는 사이버-물리 복합 위협.
- 배경 및 필요성 : 폐쇄망으로 운영되던 전력 설비가 IP(Internet Protocol) 기반 통신망과 연결되면서 외부 공격 표면이 넓어졌고, 2015년 우크라이나 전력망이 사이버 공격으로 정전을 겪는 사례가 공개되어 위협이 현실화됨.
- 주요 목적 : 원격 제어권 탈취로 인한 광역 정전, 계량 데이터 조작에 따른 요금 사기, 발전·변전 설비 파괴를 막아 국가 핵심 인프라의 가용성 확보.

## Ⅱ. 스마트 그리드 보안 위협의 특징 및 장점

- 핵심 요약 : 계측, 제어, 분산 전원, 광역 통신의 네 영역이 각각 다른 공격 경로를 가지므로 영역별 방호를 설계해야 함.

1. **AMI 계층** (가정·수용가 계량 영역) : 스마트 미터의 펌웨어 변조와 무선 구간 도청이 주요 위협 → 상호 인증과 변조 방지 칩으로 계량 데이터 신뢰성 확보.
2. **SCADA** (Supervisory Control and Data Acquisition, 송배전 감시제어 시스템) 계층 (송배전·변전 제어 영역) : 산업용 제어 프로토콜 평문 취약점을 이용한 명령 위조가 위협 → 프로토콜 암호화와 변전소 내부 세그멘테이션으로 명령 주입 차단.
3. **EMS** (Energy Management System, 중앙 에너지 관리 시스템) 계층 (중앙 에너지 관리 영역) : 관리자 계정 탈취와 랜섬웨어가 광역 정전으로 이어질 수 있음 → 데이터 다이오드로 외부 신호 유입을 물리적으로 차단.
4. **DER** (Distributed Energy Resource, 분산 에너지 자원) 계층 (태양광 인버터와 ESS(Energy Storage System, 에너지 저장 장치) 영역) : 다수 인버터의 동시 장악이 계통 주파수 불안정을 유발 → 인버터 보안 인증과 사전 검사로 집합적 교란 예방.

## Ⅲ. 스마트 그리드 보안 위협의 구조 (흐름)

- 핵심 요약 : 가정 계량에서 중앙 제어까지 계층이 올라갈수록 영향 범위가 커지므로, 상위 계층일수록 단방향 통신과 물리 격리가 강화되는 구조.
- **IEC 62351** (전력 계통 통신 프로토콜에 기밀성, 무결성, 상호 인증을 부여하기 위한 국제 표준군) : 제어 통신 보안의 기준으로 참조됨.

```text
[ 1. 가정·수용가 (AMI) ]
  스마트 미터 펌웨어 변조, 무선 도청
        ↓ 양방향 통신망
[ 2. 송배전·변전 (SCADA) ]
  IEC 61850 변조, 차단기 강제 개방
        ↓ 전력 백본 광통신망
[ 3. 중앙 에너지 관리 (EMS) ]
  랜섬웨어, 계정 탈취, 광역 정전
        ↑ 인버터 조작 위협
[ 4. 분산 에너지 자원 (DER·ESS) ]
  태양광·ESS 인버터 동시 탈락
```

## Ⅳ. 스마트 그리드 보안과 일반 보안의 비교

- 핵심 요약 : 전력 제어망은 가용성과 안전이 최우선이라 기밀성 중심의 IT 보안 방식을 그대로 적용하기 어려움.

| 비교 항목 | 스마트 그리드 (OT) 보안 | 전통적 IT 보안 | 스마트홈 IoT 보안 |
| --- | --- | --- | --- |
| 최우선 가치 | 가용성, 안전 | 기밀성, 무결성 | 사용 편의, 경제성 |
| 실시간성 | 수 밀리초 단위 보장 필요 | 수 초 이내 허용 | 수 초 이내 허용 |
| 시스템 수명 | 매우 김 (장기 운용) | 짧음 (빈번한 교체) | 짧음 |
| 패치 적용 | 무중단 운영 때문에 어려움 | 정기 패치 용이 | 제조사의 사후 패치 부재 |
| 침해 영향 | 국가 단위 정전, 설비 손상 | 데이터 유출, 금전 손실 | 사생활 유출, 기기 오작동 |

- 선택 기준 : 침해 시 물리적 영향이 큰 영역일수록 가용성 우선 설계와 물리적 통제를 앞세움.

## Ⅴ. 스마트 그리드 보안 위협의 한계와 방안

- 핵심 요약 : 실시간 보호 통신의 암호 지연, 대량 계량기의 물리 노출, 민간 분산 전원의 보안 공백을 경량 인증, 물리 탬퍼 대응, 인증 의무화로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 실시간 보호 통신의 암호 지연 | 고장 시 수 밀리초 안에 차단해야 하는 GOOSE(Generic Object Oriented Substation Event)·SV(Sampled Values) 통신에 무거운 공개키 연산을 쓰면 보호 동작이 늦어짐 | 사전 공유 대칭키 기반의 경량 인증 코드를 적용하여 처리 지연을 최소화 | 처리 지연 시간 |
| 스마트 미터의 물리 노출 | 외벽이나 전신주에 노출되어 시리얼 포트 접근과 펌웨어 덤프가 가능 | 외함 개방 시 키를 즉시 소거하는 탬퍼 스위치와 KCMVP(Korea Cryptographic Module Validation Program) 검증 보안 칩 탑재 | 탬퍼 경보 건수 |
| 민간 분산 전원의 보안 공백 | 저보안 인버터가 인터넷에 직접 노출되어 원격 공격 통로가 됨 | 계통 연계 전 사이버보안 인증과 사전 보안성 검사를 의무화 | 연계 전 검사 이행률 |

## Ⅵ. 스마트 그리드 보안에 대한 기술사적 제언

- 핵심 요약 : 망 분리와 암호 통신, 이상 탐지를 전력 계통의 물리 특성과 결합해 사이버 공격을 조기에 물리 사고 전에 차단하는 방향.
- 중앙 제어망에서 외부로 데이터를 내보낼 때는 **데이터 다이오드** (Data Diode, 한 방향으로만 신호를 흘려보내는 물리 장치)를 적용하여 외부에서 제어 명령이 들어올 경로를 원천 차단하는 것이 바람직하다.
- 변전소 자동화와 원격 제어 구간에는 IEC 62351 기반의 암호화와 디지털 서명을 단계적으로 적용하되, 밀리초 단위 보호 통신은 경량 인증 방식과 병행해야 한다.
- 전압, 주파수, 조류 데이터와 통신 메타데이터를 함께 분석하는 OT 전용 이상 탐지 체계를 구축하면, 사이버 공격으로 인한 계통 불안정을 조기에 감지할 수 있다.

```text
[ 중앙 제어망 (EMS) ]
        ↓ 광 단방향 전송만 허용
[ 데이터 다이오드 ]
        ↓
[ 외부 업무망·분석 시스템 ]
  역방향 신호 유입은 물리적으로 차단
```

## Ⅶ. 결론

- 핵심 요약 : 스마트 그리드 보안은 사이버 공격이 물리 설비와 국가 전력 공급으로 직결되는 사이버-물리 시스템의 보안임.
- 시사점 : 기밀성보다 가용성과 안전을 앞세운 설계와 물리적 격리가 기본이며, 분산 전원까지 포함한 전 계층 인증이 전제되어야 함.
