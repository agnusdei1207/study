## 30초 인출

- **본질**: SK텔레콤 유심 정보 유출은 가입자 식별정보와 인증키 등 이동통신 핵심 개인정보가 해킹으로 외부에 유출된 사고.
- **메커니즘**: 내부 시스템 침투와 보호조치 미흡이 인증정보 노출로 이어져 유심 복제 등 후속 악용 우려를 높임.

<details><summary>핵심 용어</summary>

- **SK텔레콤 유심 정보 유출 사고**: 해킹으로 가입자 식별정보·USIM 인증정보가 외부로 유출된 개인정보 침해사고.
- **USIM(Universal Subscriber Identity Module, 범용가입자식별모듈)**: 가입자 식별·인증 정보를 담아 이동통신 서비스에 쓰는 모듈.
- **IMSI(International Mobile Subscriber Identity, 국제이동가입자식별번호)**: 이동통신망에서 가입자를 식별하는 정보.
- **Ki(가입자 인증키)**: USIM 가입자 인증에 쓰이는 비밀키.
- **OP(Operator Variant Algorithm Configuration Field, 사업자별 알고리즘 구성값)**: MILENAGE 인증 알고리즘에서 사업자별로 설정하는 값.
- **OPc(사업자별 파생 알고리즘 값)**: 사업자 값 OP와 가입자 키 K로 계산해 MILENAGE 인증 알고리즘에 쓰는 값.
- **HSS(Home Subscriber Server, 홈가입자서버)**: LTE 이동통신망에서 가입자 정보와 서비스 프로파일을 관리하는 핵심 시스템.
- **심 스와핑(SIM swapping)**: 공격자가 가입자 번호의 SIM 변경 절차를 악용해 통신서비스를 탈취하는 공격.
