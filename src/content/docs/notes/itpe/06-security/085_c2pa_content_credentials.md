## 2~4교시 25점 답안

**공통 개요**

| 구분 | 핵심 |
|---|---|
| 정의 | C2PA 콘텐츠 자격증명은 디지털 자산의 출처·편집 주장을 서명된 매니페스트로 전달하는 표준 구조 |
| 목적 | 콘텐츠 결합 주장에 대한 서명·무결성 확인과 출처 이력 투명성 향상 |

### Ⅰ. 목적
- 미디어의 생성·편집 이력을 검증 가능한 주장으로 전달해 출처 투명성 지원.
### Ⅱ. 흐름
- 생성·편집 도구의 주장 기록 → 클레임·자산 결합 → 서명 → 배포 → 검증자의 서명·자산 연결·신뢰 목록 확인.
### Ⅲ. 한계
- 재인코딩·스크린샷으로 매니페스트가 유실될 수 있고, 서명자의 주장이 실제 사건의 진실을 보장하지 않음.
### Ⅳ. 대응
- 유통 경로의 매니페스트 보존, 소프트 바인딩·외부 조회의 검증, 신뢰 목록 상태와 사실 검증의 분리.

## 기술사적 제언

서명 검증 결과와 콘텐츠 사실 확인을 별도 화면·절차로 표시해 이용자의 오해를 줄인다.
