```text

 ┃
 ┣━ Ⅰ 개요 ───── 디지털 미디어(사진, 영상, 오디오)의 생성자, 편집 이력, AI 생성 여부를 암호학적 서명으로 기록하여 출처를 증명하는 개방형 기술 표준(C2PA)
 ┣━ Ⅱ 특징 ───── 출처 추적성(Provenance) · 암호학적 위변조 방지(Tamper-evident) · 메타데이터 계보(Manifest Chain) · 플랫폼 독립적 상호운용성
 ┣━ Ⅲ 구조 ───── 클레임(Claim) + 매니페스트(Manifest) + 암호화 서명(Signature, X.509 PKI) + 리소스(Resource/Media) + 검증 도구(Verify Tool)
 ┣━ Ⅳ 흐름 ───── 미디어 촬영/AI 생성 → 도구가 출처 주장을 매니페스트에 기록 → 서명자 개인키로 서명 → 파일 또는 외부 저장소에 연결 → 검증자가 서명자 공개키·자산 연결 검증
 ┣━ Ⅴ 비교 ───── C2PA 콘텐츠 자격증명(서명된 출처 주장과 자산 결합 검증) vs 디지털 워터마킹(신호 삽입과 검출). 각각 메타데이터 유실·재인코딩에 따른 한계 평가
 ┗━ Ⅵ 실무 ───── 소셜 미디어 리사이징 및 스크린샷 캡처 시 메타데이터 유실(Stripping) 방어 / 원격 클라우드 매니페스트 저장소(Cloud Binding) 연동
```

- 출제 이력: 확인 가능한 공식 제132~140회 원문에서 이 표제어의 직접 문항 미확인. 아래 문항은 예상문제

## 한 줄 본질
- 생성·편집 과정에서 기록된 출처 주장을 매니페스트와 전자서명으로 검증하는 방법. 서명 검증은 기록의 무결성과 서명자 신뢰를 확인할 뿐 촬영 내용의 사실 여부나 전체 편집 이력을 보장하지 않음.

## 핵심 그림
```text
[C2PA 매니페스트 체인(Manifest Chain) 및 검증 흐름: 가상 예시]

  1. [원본 촬영 (카메라/스마트폰)]
     [원본 사진] + [카메라 제조사/촬영시간] ──(하드웨어 서명)──> [매니페스트 #1]
                                                                        │
  2. [편집 단계 (포토샵/AI 도구)]                                     ▼
     [편집 사진] + [포토샵 자르기/색보정 이력] ──(소프트웨어 서명)─> [매니페스트 #2]
                                                                        │
  3. [소비자 열람 (웹 브라우저/SNS)]                                    ▼
     [CR 배지 클릭 (Content Credentials)]
     - 촬영 장비: Sony A7 (2026-03-01)
     - 편집 도구: Photoshop v27 (자르기 적용)
     - AI 생성 여부: 미사용 (인간 직접 촬영)
     - 서명 검증 결과: 유효함(Valid) ➔ 서명된 기록과 자산 연결의 무결성 확인
```

## 핵심 용어
- 매니페스트(Manifest): 콘텐츠에 관한 주장·서명·자산 연결 정보를 담는 출처 기록. 담긴 항목과 이전 기록의 범위는 생성 도구와 작업에 따라 달라짐
- 콘텐츠 자격증명(Content Credentials): 자산의 출처 주장을 암호학적으로 묶은 매니페스트. 사용자 화면의 표시 방식은 검증 도구마다 다름

## 핵심 통찰
- C2PA는 서명된 매니페스트와 자산 결합을 검증해 기록의 무결성을 확인. 결합 방식과 허용 편집 범위에 따라 자산 변경 시 검증 결과가 달라지며, 매니페스트가 제거되면 출처를 확인할 수 없음. 워터마킹도 구현에 따라 압축·변환 내성이 다름.
- 파일 변환·스크린샷 등으로 매니페스트가 사라지면 해당 사본의 출처 검증이 어려울 수 있음. 외부 저장소·소프트 바인딩은 보조 수단이며 원본과의 연결을 추가로 검증해야 함.
- AI 생성물 표시 의무와 C2PA 사용 의무는 구분해야 함. 표시 요건을 다루는 법령이 곧 특정 메타데이터 표준의 의무 채택을 뜻하지 않음.

## 이웃 토픽과 구분
- C2PA vs 디지털 워터마킹: C2PA = 파일에 메타데이터와 전자서명을 붙여 출처를 투명하게 공개하는 방식 / 워터마킹 = 픽셀 데이터 속에 눈에 안 띄게 패턴을 숨겨 저작권을 주장하는 방식

## 문제·원인·대책
- 가상 사례: 메시징 앱의 재인코딩 과정에서 매니페스트가 사라져 원본 출처 확인이 어려워진 상황
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미디어 재인코딩·스크린샷 시 매니페스트 유실 가능성 | 플랫폼의 메타데이터 제거·자산 변환 | 지원되는 외부 매니페스트 저장과 자산 재결합·표시 정책 검토 | 검증 가능한 원본과 연결될 때 출처 주장 조회 가능성 향상 |
| 신뢰되지 않은 서명자의 매니페스트를 공인 출처로 오해 | 서명 유효성과 서명자 신뢰를 혼동 | 사용 중인 신뢰 목록과 서명자 신원·표시 상태를 구분 | 출처 표시의 오해 감소 |

## 1교시 예상문제 (10점)
- C2PA 콘텐츠 자격증명의 개념과 검증 범위를 설명하시오.

## 1교시 10점 답안
- **정의:** 디지털 자산의 출처·편집 주장 등을 매니페스트에 담고 전자서명·자산 결합으로 무결성을 검증하는 표준.
- **구성:** 주장(Assertion), 클레임, 서명, 자산 결합 및 선택적인 이전 매니페스트 연결.
- **한계:** 유효한 서명은 주장 내용의 사실 여부나 기록되지 않은 전체 편집 이력을 보증하지 않음.

## 2~4교시 예상문제 (25점)
- C2PA 매니페스트 생성·검증 흐름과 메타데이터 유실 대응을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 목적
- 미디어의 생성·편집 이력을 검증 가능한 주장으로 전달해 출처 투명성 지원.
### Ⅱ. 흐름
- 생성·편집 도구의 주장 기록 → 클레임·자산 결합 → 서명 → 배포 → 검증자의 서명·자산 연결·신뢰 목록 확인.
### Ⅲ. 한계
- 재인코딩·스크린샷으로 매니페스트가 유실될 수 있고, 서명자의 주장이 실제 사건의 진실을 보장하지 않음.
### Ⅳ. 대응
- 유통 경로의 매니페스트 보존, 소프트 바인딩·외부 조회의 검증, 신뢰 목록 상태와 사실 검증의 분리.

## 내 의견
- 유통 과정에서 서명된 매니페스트 보존·검증 경로를 지원하되, 출처 정보의 누락이나 유효한 서명을 콘텐츠의 거짓·진실 판정으로 곧바로 연결하지 않는 운영 지침을 제안.
