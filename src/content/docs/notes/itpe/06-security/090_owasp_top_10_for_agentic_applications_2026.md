- 에이전트 공급망, 예기치 않은 코드 실행, 메모리 및 컨텍스트 오염, 에이전트 간 통신

## Ⅰ. OWASP Top 10 for Agentic Applications 2026의 개요

- 핵심 요약 : 자율적으로 계획하고 도구를 실행하는 에이전트의 보안 위험을 10개 항목으로 분류한 OWASP(Open Worldwide Application Security Project) 목록.
- 개념 : 자율적으로 계획하고 도구를 실행하는 인공지능(AI, Artificial Intelligence) 애플리케이션, 즉 **에이전틱 AI** (Agentic AI)의 보안 위험 10개를 분류한 목록으로, OWASP GenAI Security Project가 2025년 12월에 공개함.
- 배경 및 필요성 : 단순 응답 생성을 넘어 외부 시스템의 상태를 바꾸는 에이전트가 늘면서, 도구 오용과 에이전트 간 신뢰 붕괴처럼 기존 목록이 다루지 않던 위험에 대한 기준이 필요해짐.
- 주요 목적 : 외부 시스템과 인프라를 직접 제어하는 에이전트의 침해와 연쇄 장애를 설계 단계에서 선제적으로 통제하는 것.

## Ⅱ. OWASP Top 10 for Agentic Applications 2026의 특징 및 장점

- 핵심 요약 : 위험을 계획, 도구, 신원, 메모리, 다중 에이전트 축으로 나눠 통제 대상을 명확히 하는 분류 체계.

1. 행위 단계별 분류 : 목표, 계획, 도구 실행, 메모리, 통신 축으로 위험을 나눔 → 에이전트 동작의 단계마다 점검 지점을 설정할 수 있음.
2. 통제 수단 연결 : 항목마다 권한 최소화, 샌드박스, 행위 감시 같은 통제 수단을 연결 → 설계 기준으로 바로 옮길 수 있음.
3. 연쇄 위험 명시 : 한 에이전트의 실패가 다른 에이전트로 번지는 위험을 별도 항목으로 둠 → 다중 에이전트 구조에서 장애 격리 설계의 근거가 됨.

## Ⅲ. OWASP Top 10 for Agentic Applications 2026의 구조 (흐름)

- 핵심 요약 : 비신뢰 입력이 계획을 오염시키고, 실행 권한을 거쳐 다른 에이전트로 확산되는 단계형 흐름.

```text
[ 위험 전파 흐름 ]

비신뢰 입력 (웹 문서, 이메일)
              ↓
[ 계획 오염 ]
목표 탈취, 메모리 및 컨텍스트 오염
              ↓
[ 실행 권한 남용 ]
도구 오용, 신원 및 권한 남용
예기치 않은 코드 실행
              ↓
[ 다중 에이전트 확산 ]
에이전트 간 통신 취약점, 연쇄 장애
탈주 에이전트
              ↓
[ 피해 ]
데이터 삭제, 비인가 송금, 내부망 장악
```

```text
[ 다중 에이전트 구조 ]

사용자
  ↓
마스터 에이전트 (오케스트레이터)
  ↓                    ↓
서브 에이전트 A       서브 에이전트 B
  ↓                    ↓
외부 도구            데이터 저장소
```

1. **목표 탈취** (Agent Goal Hijack) : 에이전트가 읽은 문서 속 지시로 목표가 바뀌어 악의적 행동을 수행하는 위험.
2. **도구 오용** (Tool Misuse and Exploitation) : 허용된 도구를 공격자가 원하는 방식으로 호출하게 만드는 위험.
3. **신원 및 권한 남용** (Identity and Privilege Abuse) : 과도하게 부여된 자격증명과 권한이 악용되는 위험.
4. **에이전트 공급망 취약점** (Agentic Supply Chain Vulnerabilities) : 변조된 플러그인이나 모델 컨텍스트 프로토콜(MCP, Model Context Protocol) 서버 등 신뢰하며 가져온 외부 구성요소의 위험.
5. **예기치 않은 코드 실행** (Unexpected Code Execution) : 에이전트가 생성한 코드를 격리 없이 호스트에서 실행하는 위험.
6. **메모리 및 컨텍스트 오염** (Memory and Context Poisoning) : 악성 입력이 장기 메모리에 저장되어 이후 세션의 판단을 오염시키는 위험.
7. **에이전트 간 통신 취약점** (Insecure Inter-Agent Communication) : 에이전트 사이의 메시지가 도청되거나 위조되는 위험.
8. **연쇄 장애** (Cascading Failures) : 한 에이전트의 오류가 다른 에이전트의 연속 호출과 무한 루프로 번지는 위험.
9. **인간-에이전트 신뢰 악용** (Human-Agent Trust Exploitation) : 설득력 있는 에이전트 출력을 사람이 검증 없이 승인하게 만드는 위험.
10. **탈주 에이전트** (Rogue Agents) : 정책을 우회해 비인가 자원에 접근하거나 스스로 복제를 시도하는 위험.

## Ⅳ. OWASP Top 10 for Agentic Applications 2026과 LLM Top 10의 비교

- 핵심 요약 : 대규모 언어 모델(LLM, Large Language Model) 중심의 2025년 Top 10과 달리, 2026년판은 자율 루프와 다중 에이전트의 행위 통제를 다룸.

| 비교 축 | LLM Top 10 (2025) | Agentic Top 10 (2026) |
| --- | --- | --- |
| 동작 패러다임 | 질의-응답 기반 수동 생성 | 목표-계획-실행 기반 자율 루프 |
| 주 보호 대상 | 프롬프트, 검색 결과, 모델 | 도구 연동 인터페이스, 호스트 환경, 장기 메모리, 통신 채널 |
| 주요 실패 양상 | 민감정보 노출, 환각 | 데이터 삭제, 금전 이체, 시스템 중단 |
| 상호작용 구조 | 사용자와 단일 모델 | 사용자, 오케스트레이터, 서브 에이전트의 협업 |
| 방어 핵심 축 | 입출력 필터링과 프롬프트 가드레일 | 도구 호출 권한 통제, 메시지 무결성, 실행 샌드박스 |

## Ⅴ. OWASP Top 10 for Agentic Applications 2026의 한계와 방안

- 핵심 요약 : 메시지 추적, 호출 비용 폭증, 코드 실행 탈출, 감시 우회를 서명과 분산 추적, 서킷 브레이커, 격리 샌드박스, 커널 수준 감시로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 다단계 메시지 변조 추적 곤란 | 중계 과정에서 최초 발신자와 변조 여부 확인이 어려움 | 에이전트 간 메시지에 전자 서명과 분산 추적 식별자 적용 | 서명 검증 실패율 |
| 반복 호출에 따른 비용 폭증 | 계획 루프의 과다 호출로 API 비용과 서비스 거부 발생 | 서킷 브레이커 도입, 태스크당 실행 시간·토큰·도구 호출 상한 설정 | 태스크당 도구 호출 횟수 |
| 코드 실행 샌드박스 탈출 | 생성된 코드가 시스템 호출을 우회해 호스트 장악 | 일반 컨테이너보다 격리가 강한 샌드박스에서만 코드 실행 허용 | 샌드박스 이탈 시도 탐지 건수 |
| 통제 프로세스 우회 | 탈주 에이전트가 감시 프로세스를 종료하거나 우회 통신로를 개설 | 커널 수준 eBPF(Extended Berkeley Packet Filter) 감시로 비인가 소켓과 프로세스 즉시 차단 | 비인가 소켓 생성 차단 건수 |

## Ⅵ. OWASP Top 10 for Agentic Applications 2026에 대한 기술사적 제언

- 핵심 요약 : 에이전트를 사람의 권한에 준하는 주체로 다루고, 신원 관리와 행위 감시를 플랫폼 수준에서 표준화해야 함.

1. 승인 체계 : 기업은 에이전트 도입 전에 목표, 권한, 도구 목록을 문서화하고 고위험 행위에 사람의 승인을 거치는 거버넌스 기준 필요.
2. 플랫폼 표준 : 개발 조직은 에이전트 전용 신원과 격리된 실행 환경을 공통 플랫폼의 기본값으로 채택하는 방향 필요.
3. 비상 대응 : 보안 조직은 다중 에이전트 간 신뢰 경계와 비상 차단 절차를 정책으로 정하고, 정기 훈련으로 실효성을 검증하는 체계 필요.

## Ⅶ. 결론

- 핵심 요약 : 에이전트 보안은 모델 출력 필터링을 넘어 도구 권한과 실행 경계를 설계하는 문제임.
- 시사점 : 자율성이 커질수록 통제의 단위가 답변에서 행위로 옮겨가므로, 권한 설계와 행위 감시를 함께 갖춘 조직이 에이전트를 안전하게 확산할 수 있음.
