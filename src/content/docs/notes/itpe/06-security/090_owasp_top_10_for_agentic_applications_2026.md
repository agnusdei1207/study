## 핵심 용어
- 목표 하이재킹(Goal Hijacking): 에이전트의 원래 수행 목표(예: "일정 정리")를 공격자가 주입한 적대적 프롬프트로 변조하여 악의적 목표(예: "연락처 전체 유출")로 대체해 버리는 공격
- 다중 에이전트 신뢰 사슬(Multi-Agent Trust Chain): 여러 에이전트가 협업할 때 앞선 에이전트의 출력물을 다음 에이전트가 검증 없이 신뢰함으로써 악성 명령이 연쇄 전파되는 현상

## 핵심 통찰
- OWASP LLM Top 10에도 과도한 자율성·정보 유출 등 행동과 관련된 위험이 있다. Agentic Top 10은 에이전트의 목표, 도구, 권한 및 상호 작용이 만드는 위험을 더 자세히 다룬다.
- 셸이나 코드 실행 도구를 제공할 때에는 업무 필요성을 검토하고 샌드박스, 최소 권한, 실행 제한과 승인 경계를 둔다. 범용 도구의 사용 여부는 위험 평가에 따른 설계 선택이다.
- 다중 에이전트 환경은 호출 주체, 도구, 입력, 승인, 결과를 연계해 기록해야 한다. 모든 메시지에 디지털 서명이나 블록체인 로그가 요구되는 것은 아니다.

## 이웃 토픽과 구분
- OWASP Agentic Top 10 vs OWASP LLM Top 10: Agentic = 환경 조작(도구 호출, API 실행, OS 상호작용) 보안 위협 / LLM = 모델의 자연어 입출력 및 텍스트 프롬프트 위협

## 문제·원인·대책
- 가상 사례: 사내 업무 자동화 에이전트가 고객 지원 이메일의 악성 지시를 따르다가 삭제 API를 실행하는 상황
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 외부 비정형 데이터 유입에 의한 목표 왜곡 및 비인가 삭제 API 실행 | 에이전트의 자연어 계획을 검증 없이 신뢰하고 삭제 권한을 직접 부여 | 도구 호출 정책과 파괴적 명령 시 인간 승인 | 목표 조작이 실제 삭제로 이어질 위험 감소 |
| 코드 실행 도구를 통한 호스트 침해 위험 | 도구 실행 환경의 격리 부재와 과도한 권한 | 격리 실행 환경, 최소 권한, 자원 제한 및 취약점 관리 | 침해 범위 축소; 샌드박스 탈출 가능성을 0으로 만들지는 못함 |

## 이렇게 출제된다
- 확인한 제132~140회 공식 문제지에서 직접 출제 미확인. 예상: "에이전틱 AI의 주요 보안 위험과 도구 실행 통제 방안을 설명하시오."

## 내 의견
- [에이전트 권한의 최소화 및 파괴적 도구의 원천 배제] 에이전트 개발 시 개발 편의를 위해 'Bash 실행 도구'를 붙여주는 관행이 가장 위험함 → 나라면: 에이전트가 호출할 수 있는 도구 목록에서 임의 명령 실행 도구를 원천 박탈하고, 데이터베이스도 읽기 전용 뷰(Read-only View)만 제공하며, 결제·삭제 등 고영향 행위는 반드시 '인간 확인(User Confirmation)' 없이는 트리거되지 않는 결정론적 안전 가드를 강제

## 10점 답안
OWASP Top 10 for Agentic Applications 2026은 자율적으로 계획·도구 호출·협업하는 AI 에이전트의 주요 보안 위험을 정리한 OWASP 가이드. 목표 탈취, 도구 오용, 권한 남용, 공급망, 예상치 못한 코드 실행, 기억·문맥 오염, 에이전트 간 통신, 연쇄 실패, 인간의 과신, 악성 에이전트를 포함. 불신 입력과 지시의 분리, 도구별 최소 권한, 위험 행위 승인, 실행 격리, 호출 기록과 모니터링으로 대응.

## 25점 답안
### Ⅰ. 특징과 공식 분류
일반 LLM 출력 위험에 더해 도구 실행과 에이전트 간 위임이 외부 상태를 바꿀 수 있는 위험. OWASP 공식 ASI01~ASI10 항목은 아래 출처 절과 같이 구분.

### Ⅱ. 위협 흐름
```text
불신 콘텐츠 유입 → 목표·문맥 오염 → 도구 호출 또는 권한 오용
→ 다른 에이전트로 전파·연쇄 실패 → 데이터·시스템 영향
```
이는 가능한 시나리오이며 모든 항목이 한 번에 발생하는 필수 공격 순서는 아님.

### Ⅲ. 통제 설계
| 통제 지점 | 확인 항목 |
|---|---|
| 입력·계획 | 외부 데이터의 지시 승격 차단, 업무 목표 검증 |
| 신원·도구 | 호출 주체 확인, 도구별 권한·입력 제약, 고영향 작업 승인 |
| 실행·협업 | 격리, 예산·반복 제한, 에이전트 간 출처와 전달 내용 확인 |
| 운영 | 호출·승인·결과 로그, 이상 행위 탐지와 복구 절차 |

## 공식 분류와 출처

OWASP 원문의 10개 항목은 ASI01 Agent Goal Hijack, ASI02 Tool Misuse and Exploitation, ASI03 Identity and Privilege Abuse, ASI04 Agentic Supply Chain Vulnerabilities, ASI05 Unexpected Code Execution, ASI06 Memory and Context Poisoning, ASI07 Insecure Inter-Agent Communication, ASI08 Cascading Failures, ASI09 Human-Agent Trust Exploitation, ASI10 Rogue Agents다. 위 4계층 그림은 이 문서의 학습용 재구성이며 공식 분류 체계가 아니다.
