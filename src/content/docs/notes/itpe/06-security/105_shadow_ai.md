## 지식 로드맵 내 현재 위치

지식 위치: 생성형 AI 보안 → 비인가 도구 사용 → **섀도우 AI**

## 30초 인출

- 본질: 조직 승인·가시성 밖에서 업무용 데이터나 작업에 AI 서비스를 사용하는 행위·환경
- 위험: 개인정보·소스코드 외부 전송, 서비스별 보존·학습·공유 정책 불일치, 승인되지 않은 플러그인·에이전트 권한
- 경계: 모든 입력이 곧 모델 학습에 쓰이는 것은 아님. 학습 제외와 보존 제한(Zero Data Retention)은 서로 다른 계약·기능 조건

## 1교시 예상문제 (10점)

> 섀도우 AI의 발생 원인과 주요 정보보호 위험을 설명하시오. (예상·10점)

## 1교시 10점 답안

### Ⅰ. 개념과 원인

업무 생산성 수요에 비해 승인된 AI 도구·이용 규칙이 부족할 때 임직원이 개인 계정·확장 프로그램으로 외부 AI를 사용하는 현상.

### Ⅱ. 위험과 기본 통제

| 위험 | 통제 |
|---|---|
| 민감 프롬프트 전송 | 데이터 분류·최소화·DLP |
| 이용 현황 미파악 | 승인 서비스 목록·네트워크/단말 가시성 |
| 과다 권한 연결 | 플러그인·API 토큰 권한 검토 |
| 공급자 처리 조건 오인 | 계약·설정의 보존·학습·국외 이전 확인 |

## 2~4교시 예상문제 (25점)

> 섀도우 AI의 위협 모델을 설명하고, 조직의 안전한 AI 활용·감독 체계를 설계하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

조직의 허가·관리 범위 밖 AI 사용은 업무 데이터의 이동과 제삼자 처리 조건을 파악하기 어렵게 함. 비인가 사용의 범위를 개인 웹 서비스뿐 아니라 AI 브라우저 확장·자동화 도구·API 연계까지 평가.

### Ⅱ. 데이터 흐름

```text
업무 자료 → 사용자 입력·파일 업로드 → 외부 AI 서비스
                                     ├─ 계약·설정에 따른 보존
                                     ├─ 학습 사용 여부
                                     └─ 접근·공유·삭제 조건
```

'외부 모델 서버 학습 풀에 무조건 흡수'라는 단정은 부정확.

### Ⅲ. 위험별 통제

| 위험 | 관리·기술 대책 |
|---|---|
| 기밀·개인정보 노출 | 데이터 등급·허용 목적 정의, 입력 최소화·DLP |
| 비인가 계정·서비스 | 사용 현황 파악, 승인된 대체 서비스 제공 |
| 확장 프로그램 권한 | 설치 승인·권한 점검·단말 관리 |
| AI 출력의 오류 | 사람 검토·근거 확인·업무 책임자 지정 |
| 로그·사고 대응 공백 | 서비스별 기록·보존·삭제·통지 계약 확인 |

### Ⅳ. 운영 구조

```text
사용 사례 등록 → 데이터·모델·공급자 위험 평가
             → 승인 서비스·접근 정책
             → 이용자 안내·입력 통제
             → 로그·사고 대응·정기 재평가
```

CASB나 AI 프록시는 가시성·인라인 통제에 유용하나 모든 개인 단말·우회 경로를 자동 해결하지 않음. 사내 프라이빗 AI도 데이터 접근·모델 출력·공급망 위험이 남음.

### Ⅴ. 기술사적 제언

사용자가 합법적으로 쓸 수 있는 도구와 구체적 데이터 입력 규칙을 제공하고, 차단·예외·감사를 위험 등급에 맞게 운영.
