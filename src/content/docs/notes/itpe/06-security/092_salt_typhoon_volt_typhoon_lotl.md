## 답안 골격
```text
[Salt Typhoon / Volt Typhoon (LotL)] ◀━━ 머리: Ⅶ 내 의견 (국가 배후 APT 위협 극복 → 네트워크 엣지 장비 제로트러스트 검증 및 LotL 행위 분석 기반 방어선 구축)
 ┃
 ┣━ Ⅰ 개요 ───── 미국 핵심 인프라(통신, 수자원, 항만)를 침투한 국가 배후 해킹 그룹(Volt/Salt Typhoon)과 이들이 사용하는 '정상 도구 악용(LotL)' 중심의 스텔스 침해 전술
 ┣━ Ⅱ 특징 ───── 악성 바이너리 미사용(Fileless/LotL) · SOHO 라우터/VPN 엣지 장비 침투 · 장기 은닉 및 사전 배치(Pre-positioning) · 통신 감청 및 파괴 공작 준비
 ┣━ Ⅲ 구조 ───── 엣지 장비 취약점(Cisco, Fortinet 등) + KV-botnet(프록시 망) + OS 내장 도구(PowerShell, WMI, netsh) + 정상 관리자 자격증명 탈취
 ┣━ Ⅳ 흐름 ───── 엣지 라우터 제로데이 침투 → 정상 자격증명 수탈 → LotL 도구로 내부 정찰 → 통신 백본 스위치 장악(Salt) / 위기 시 인프라 파괴 준비(Volt)
 ┣━ Ⅴ 비교 ───── Typhoon 계열 LotL 공격(정상 바이너리 악용, 백신 탐지율 0%, 장기 스파이/파괴) vs 고전적 APT 공격(외부 악성코드 드롭, C2 통신, 시그니처 탐지 가능)
 ┗━ Ⅵ 실무 ───── 엣지 네트워크 장비 펌웨어 무결성 검증 / 스크립트 실행 제어(AppLocker, WDAC) / 정상 계정의 비정상 명령어 실행 상관분석
```
- 필수 키워드: Volt Typhoon · Salt Typhoon · LotL(Living off the Land) · 핵심 인프라 침투 · 사전 배치(Pre-positioning) · 통신 백본 감청 · 엣지 장비 취약점
- 기출: 미출제. 국가 안보 및 사이버전 최신 시사 문제로 출제 유력 예상

## 한 줄 본질
- 보안 솔루션이 외부에서 들어오는 악성 실행파일을 잡아내는 탐지 체계의 맹점 → 시스템에 이미 설치된 정상적인 OS 관리 도구(PowerShell, WMI)와 탈취한 자격증명만으로 조용히 내부망을 장악 → 백신과 IDS를 완벽히 우회하는 장기 은닉 달성 / 행위 기반 상관분석과 계정 이상 징후 추적으로만 탐지 가능

## 핵심 그림
```text
[Typhoon 그룹의 LotL(Living off the Land) 기반 스텔스 침투 구조]

   [공격자 (국가 배후 조직)]
              │ 1. 지원 종료(EOL) SOHO 라우터 / 방화벽 제로데이 침투
              ▼
   ┌────────────────────────────────────────────────────────┐
   │ 엣지 네트워크 장비 (KV-botnet 형성, 공격 근원지 세탁)   │
   └──────────────────────────┬─────────────────────────────┘
                              │ 2. 정상 관리자 VPN 계정으로 내부 침투
                              ▼
   ┌────────────────────────────────────────────────────────┐
   │ 피해 조직 내부 시스템 (엔드포인트 / 서버)             │
   │  [악성코드 다운로드 안 함! (No Malware on Disk)]        │
   │  - `netsh` : 포트 포워딩 터널 생성                    │
   │  - `wmic` : 내부 원격 프로세스 실행                   │
   │  - `ntdsutil` : Active Directory 비밀번호 DB 추출      │
   │  - `certutil` : 데이터 은닉 인코딩 및 C2 전송          │
   └──────────────────────────┬─────────────────────────────┘
                              │ 3. 백신(Anti-Virus)의 반응:
                              ▼
   [백신 / EDR: "모두 윈도우 정식 시스템 파일이므로 차단 안 함(정상 판단)"]
```

## 핵심 용어
- 사전 배치(Pre-positioning): 군사적 충돌이나 유사시 전력망, 수자원, 통신 인프라를 즉각 마비시키기 위해 평시에 중요 시스템에 미리 침투하여 대기하는 사이버전 전술
- CALEA 시스템: 미국 통신 사업자가 법원의 영장에 따라 수사 기관에 통화 내용을 제공하기 위해 구축한 '합법적 통신 감청 인프라'로, Salt Typhoon이 이를 직접 해킹하여 역감청을 수행함

## 핵심 통찰
- Volt Typhoon은 단순한 정보 탈취(스파이)가 아니라 유사시 국가 기반시설을 물리적으로 파괴하기 위한 '사전 배치'라는 점에서 전쟁 행위에 준하는 위협임
- Salt Typhoon은 AT&T, 버라이즌 등 통신사 백본망을 뚫고 미국 정부의 합법적 감청 시스템 자체를 장악하여 고위급 통신을 도청함 → "통신 인프라를 신뢰할 수 없다"는 제로트러스트의 당위성을 증명함
- 백신(Anti-Virus)이 악성코드를 찾는 시대는 끝남 → 정상 프로그램(`powershell.exe`, `wmic.exe`)이 평소와 다른 시간대에 다른 사용자의 권한으로 실행되는 '비정상 행동의 문맥(Context)'을 찾는 이상행위 탐지만이 유일한 해법임

## 이웃 토픽과 구분
- LotL 공격 vs 일반 악성코드 공격: LotL = 디스크에 악성 바이너리를 생성하지 않고 OS 내장 도구만 활용(Fileless) / 일반 = 트로이목마, 랜섬웨어 등 독자적 악성 실행파일을 유입시킴

## 문제·원인·대책
- 사례: 국가 중요 통신망 내부에서 EOL(단종)된 외곽 라우터 취약점을 통해 침투한 후 윈도우 기본 명령어로 1년 이상 잠복 감청을 수행한 APT 침해 사건
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 악성코드 탐지 엔진을 우회하는 OS 정상 관리 도구 기반 잠복 | 시그니처 기반 안티바이러스의 LotL 도구 감시 한계 | WDAC(Windows Defender Application Control) 기반 스크립트 실행 제한 | 비인가 사용자의 PowerShell 및 WMI 실행 원천 통제 |
| 취약한 엣지 네트워크 장비를 통한 최초 거점 확보 | 외곽 VPN 및 라우터의 패치 지연과 EOL 장비 방치 | 엣지 장비 자격증명 MFA 강제 및 제로트러스트 네트워크 접속(ZTNA) | 엣지 장비 침해 시에도 내부망으로의 측면 이동 차단 |

## 이렇게 출제된다
- 미출제. 예상: "국가 배후 해킹 조직(Volt Typhoon, Salt Typhoon)이 사용하는 'Living off the Land(LotL)' 공격 기법의 특징과 작동 메커니즘을 설명하고, 국가 핵심 인프라 및 통신망 보안을 위한 대응 방안을 제시하시오." → 요구 포인트: Ⅰ 사건 배경 및 LotL 개념 + Ⅲ 정상 도구 악용 흐름 도식 + Ⅵ 엔드포인트 행위 통제 및 엣지 장비 보안 대책

## 내 의견
- [인프라 엣지 장비의 가시성 사각지대 해소] 많은 기업이 서버와 PC에는 EDR을 설치하면서도 라우터, VPN, 방화벽 등 엣지 장비는 패치조차 하지 않고 방치함 → 나라면: 공공·통신·에너지 전 영역에서 외부 접점에 노출된 모든 네트워크 어플라이언스에 대해 EOL 장비 즉시 퇴출, 펌웨어 무결성 원격 감사, 엣지 장비 접근 시 MFA 및 전용 점프서버 경유를 의무화하는 '네트워크 접점 보안 강화 특별 지침'을 수립
