> **사건 구분:** 2025년 롯데카드 외부 서버 침해는 2014년 카드사 내부자·USB 유출 사고와 다른 사건. 금융위원회 발표 범위에서 확인된 경로와 영향을 아래에 정리.

## 30초 핵심

- **표제어 정의:** 2025년 롯데카드 온라인 결제 서버 침해와 개인신용정보 유출 사고
- **확인된 경로:** 온라인 결제 서버 침입 → 웹셸 설치 → 2025년 8월 14~27일 정보 유출
- **대응:** 인터넷 노출 서버의 패치·악성 웹셸 탐지, 개인정보 암호화, 유출 범위 조사·고객 보호

## 10점 답안

### Ⅰ. 개요

2025년 롯데카드 해킹은 외부 공격자가 온라인 결제 서버에 침입해 웹셸을 설치하고 개인신용정보를 유출한 사건. 금융위원회는 약 200GB의 정보 유출과 약 296.9만 명의 개인신용정보 포함 사실을 발표함

### Ⅱ. 구조와 대응

```text
인터넷 노출 온라인 결제 서버(WAS)
       ↓ 침입·웹셸 설치
서버 내부 자료 접근 → 외부로 정보 유출
       ↓
서버 패치·웹셸 탐지·접근 기록 분석·정보 암호화·고객 보호
```

| 관점 | 대응 |
|---|---|
| 침투면 | WAS 보안 패치, 설정 점검, 웹셸·비정상 요청 탐지 |
| 데이터 | 주민등록번호·비밀번호 등 보호 조치와 접근 최소화 |
| 사고 대응 | 유출 범위 조사, 고객 안내·카드 재발급 등 피해 방지 |

### Ⅲ. 결론

사고의 핵심은 외주 인력의 USB 반출이 아닌 외부 해커의 온라인 결제 서버 침해와 데이터 유출임

## 25점 답안

### Ⅰ. 사건 개요

금융위원회 발표 기준, 2025년 8월 온라인 결제 서버에 침입한 해커가 웹셸을 설치하고 8월 14~27일 자료를 반출한 사고. 개인신용정보 약 296.9만 명분이 포함되며, 약 28.3만 명은 카드 비밀번호와 CVC도 유출된 것으로 파악됨

### Ⅱ. 공격 흐름과 영향

```text
온라인 결제 서버 침해 → 웹셸 설치 → 자료 수집·반출 → 고객 정보 노출 위험
     패치·진입 통제       무결성 감시    로그·전송 감시     고객 보호·재발 방지
```

2014년 카드사 내부자 유출 사고와 혼동하지 않아야 함. 이 사건의 공격 표면은 외부 접속 가능한 결제 서버이며, 정확한 침투 취약점·권한 확대 경로는 공개 조사 결과의 범위 안에서 설명할 것

### Ⅲ. 기술·관리 대응

| 단계 | 관리 항목 | 검증 |
|---|---|---|
| 예방 | 인터넷 노출 서버 자산 현황, 패치, 접근 최소화, 중요정보 암호화 | 정기 취약점 점검·설정 검토 |
| 탐지 | 웹셸·비정상 파일 변경, 대량 조회 및 외부 전송 모니터링 | 로그 연계 분석·모의 침투 |
| 대응 | 증거 보존, 서버 격리·재구축, 유출 범위 확인 | 침해 경로와 데이터 범위 대조 |
| 고객 보호 | 비밀번호 변경·카드 재발급·부정사용 감시 | 고객 통지와 피해 처리 이행 점검 |

### Ⅳ. 제언

결제 서버의 패치 누락과 중요정보 보호 미흡을 사업 위험으로 관리하고, 탐지부터 고객 보호까지 연계된 대응 훈련 실시
