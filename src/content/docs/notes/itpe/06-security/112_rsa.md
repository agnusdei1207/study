## 지식 로드맵 내 현재 위치

정보보안 → 암호학 → 공개키 암호화(비대칭키) → RSA 알고리즘

## 30초 인출

- **본질:** 큰 두 소수의 곱으로 이루어진 합성수의 소인수분해 난치성(Factoring Problem)에 기반하여 기밀성 암호화와 전자서명을 모두 지원하는 최초의 상용 비대칭키 암호 알고리즘.
- **메커니즘:** 두 소수 $p, q$로 모듈러스 $n=pq$ 및 오일러 피 함수 $\phi(n)=(p-1)(q-1)$ 계산 → 공개 지수 $e$와 개인 지수 $d$ 도출 ($ed \equiv 1 \pmod{\phi(n)}$) → OAEP 암호화 및 PSS 서명 적용.
- 통찰: 원시(Textbook) RSA의 대수적 취약점(CPA 노출)을 극복하기 위해 RSA-OAEP/PSS 표준 패딩 적용과 양자 컴퓨터(Shor 알고리즘) 위협에 대비한 PQC 전환 필수.

<details><summary>핵심 용어</summary>

- **RSA(Rivest-Shamir-Adleman)**: 1977년 MIT 연구진이 발표한 소인수분해 난치성 기반 공개키 암호 시스템.
- **소인수분해 난치성**: 두 소수의 곱 $n=pq$를 구하기는 쉬우나, 거대한 합성수 $n$이 주어졌을 때 이를 소인수 $p, q$로 분해하는 것은 고전 컴퓨터로 계산 불가능하다는 원리.
- **오일러 피 함수($\phi(n)$)**: $n$ 이하의 양의 정수 중 $n$과 서로소인 정수의 개수로, $n=pq$일 때 $\phi(n) = (p-1)(q-1)$.
- **RSA-OAEP(Optimal Asymmetric Encryption Padding)**: Feistel 네트워크와 암호학적 해시를 결합하여 IND-CCA2 안전성을 보장하는 RSA 암호화 패딩 표준.
- **RSA-PSS(Probabilistic Signature Scheme)**: 서명 생성 시 무작위 난수(Salt)를 결합하여 선택 메시지 공격(EUF-CMA)에 대한 안전성을 수학적으로 증명한 서명 표준.
</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 매우 큰 두 개의 소수를 곱한 합성수의 소인수분해 계산 복잡성에 기반하여 데이터 암호화(기밀성)와 전자서명(인증/부인방지)을 구현하는 비대칭 암호 알고리즘 |
| 목적 | 대칭키 암호의 키 사전 공유 난제를 해결하고, 단일 공개키-개인키 쌍을 통해 안전한 키 교환, 종단 간 기밀 통신 및 공인인증서 신뢰 체계 확립 |

## Ⅱ. RSA 알고리즘의 수학적 원리 및 핵심 특징

| 특징 항목 | 수학적 메커니즘 | 기술적 의미 및 영향 |
|---|---|---|
| 소인수분해 난치성 | $n=p \times q$ 계산은 쉬우나, 거대한 $n$으로부터 $p, q$ 역산은 준지수 시간 소요 | 현대 2048/3072-bit 환경에서 계산적 안전성 보장 |
| 오일러 정리 활용 | $M^{\phi(n)} \equiv 1 \pmod n$ 관계를 이용하여 $M^{ed} \equiv M \pmod n$ 성립 | 암호화 연산($e$)과 복호화 연산($d$)의 완벽한 가역성 보장 |
| 암호화/서명 양방향성 | 공개키 암호화-개인키 복호화(기밀성) 및 개인키 서명-공개키 검증(서명) 동시 지원 | 단일 알고리즘으로 전자봉투와 전자서명 모두 구현 가능 |
| 비대칭적 연산 부하 | 공개 지수 $e=65537$ 고정으로 암호화/검증은 빠르나, 개인 지수 $d$ 복호화는 연산 과다 | 고성능 서버 및 모바일 단말에서 하드웨어 가속기(Crypto Engine) 요구 |
| 대수적 준동형성 | $Enc(M_1) \times Enc(M_2) \equiv Enc(M_1 \times M_2) \pmod n$ 승법 준동형 성질 | 암호문 조작 공격에 취약하므로 필수적인 무작위 패딩 요구 |

## Ⅲ. RSA 키 생성, 암호화/복호화 및 서명 프로세스 아키텍처

```text
[ 1. RSA 키 쌍 생성 단계 ]
서로 다른 대형 소수 p, q 선택 (각 1024-bit 이상)
       │
       ▼
모듈러스 n = p * q 및 오일러 함수 phi(n) = (p-1)(q-1) 계산
       │
       ▼
공개 지수 e 선택: 1 < e < phi(n) 이며 gcd(e, phi(n)) = 1 (통상 e = 65537)
       │
       ▼
개인 지수 d 계산: e * d = 1 (mod phi(n)) (확장 유클리드 알고리즘 적용)
       │
       ▼
[공개키: (e, n)] 배포  /  [개인키: (d, n), p, q] HSM에 기밀 보관

[ 2. RSAES-OAEP 암호화 / 복호화 ]             [ 3. RSASSA-PSS 전자서명 / 검증 ]
평문 메시지 M                                 원문 메시지 M
     │                                             │
     ▼                                             ▼
OAEP 패딩 인코딩 (M + Salt + MGF1)            SHA-256 해시 H(M) 도출
     │                                             │
     ▼                                             ▼
인코딩된 블록 EM                              PSS 패딩 인코딩 (H(M) + Salt)
     │                                             │
     ▼                                             ▼
암호화: C = EM^e mod n (공개키)                서명 생성: S = EM^d mod n (개인키)
     │                                             │
     ▼ (전송)                                      ▼ (전송)
복호화: EM = C^d mod n (개인키)                서명 검증: EM' = S^e mod n (공개키)
     │                                             │
     ▼                                             ▼
OAEP 언패딩 및 원문 M 복원                     PSS 무결성 및 해시 H(M) 일치 검증
```

| 처리 단계 | 상세 수식 및 절차 | 적용 표준 및 규격 |
|---|---|---|
| 소수 생성 | 암호학적 난수 생성기(CSPRNG)와 밀러-라빈(Miller-Rabin) 소수 판정법 적용 | FIPS 186-5 규격 |
| 키 생성 | $n = p \times q$, $e = 65537$, $d = e^{-1} \pmod{\text{lcm}(p-1, q-1)}$ | PKCS#1 v2.2 |
| 복호화 가속 | 중국인의 나머지 정리(CRT)를 적용하여 복호화 연산 속도 약 4배 향상 ($d_p, d_q, q_{inv}$) | RSA-CRT 최적화 |
| 암호화 (OAEP) | 평문에 2개의 해시 함수와 무작위 시드(Seed)를 Feistel 구조로 결합하여 암호화 | RFC 8017 RSAES-OAEP |
| 서명 (PSS) | 메시지 해시값에 무작위 Salt를 결합하여 매 서명마다 다른 서명값 출력 | RFC 8017 RSASSA-PSS |

## Ⅳ. 암호화 패딩 방식 비교: 원시 RSA vs PKCS#1 v1.5 vs RSA-OAEP/PSS

| 비교 항목 | 원시 RSA (Textbook RSA) | RSA PKCS#1 v1.5 | RSA-OAEP / RSA-PSS (최신) |
|---|---|---|---|
| 무작위성 (Randomness) | 없음 (결정론적 암호화) | 존재 (무작위 패딩 바이트 추가) | 완벽함 (암호학적 마스크 생성 함수 MGF1) |
| 대수적 공격 내성 | 취약 (승법 준동형성 조작 가능) | 일부 취약 | 우수 (수학적 준동형성 완전 차단) |
| 패딩 오라클 내성 | 해당 없음 (패딩 미사용) | 치명적 취약 (Bleichenbacher 공격 노출) | 안전함 (오라클 오류 정보 누출 차단) |
| 암호 안전성 증명 | 안전성 증명 불가 | 휴리스틱 안전성 (수학적 증명 없음) | 랜덤 오라클 모델 하에서 IND-CCA2 증명 |
| 현대 표준 권고 | 사용 절대 금지 | 신규 시스템 퇴역 (Legacy 유지) | NIST 및 FIPS 186-5 표준 권고 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| Shor 알고리즘 기반 양자컴퓨터 등장 시 다항식 시간($O((\log n)^3)$) 내 소인수분해 완료로 RSA 체계 전면 붕괴 | NIST PQC 표준인 격자 기반 ML-KEM(Kyber) 및 ML-DSA(Dilithium)로 마이그레이션하고, 과도기적으로 RSA-PQC 하이브리드 암호화 도입 |
| 고정된 작은 공개 지수($e=3$) 사용 시 동일 메시지를 3개 이상의 수신자에게 전송할 경우 중국인의 나머지 정리로 평문 복원(Coppersmith 공격) | 공개 지수 $e$를 관례적인 $65537(2^{16}+1)$로 강제 고정하고 최신 RSAES-OAEP 패딩을 적용하여 메시지 간 연관성 제거 |
| 복호화 실패 시 반환되는 오류 메시지(패딩 불일치 vs 암호문 손상)의 차이를 이용한 블라이헨바허(Bleichenbacher) 백만 메시지 공격 | 패딩 검증 실패 시 즉시 에러를 반환하지 않고 무작위 가짜 평문을 생성하여 복호화 루틴을 끝까지 수행하는 상수 시간 오류 처리 적용 |
| 모듈러 멱승 연산($C^d \bmod n$) 수행 시 비트가 1일 때와 0일 때의 연산 시간 및 전력 소비 차이를 측정하는 부채널(Side-Channel) 공격 | 멱승 연산 전에 암호문에 무작위 난수를 곱해 연산하고 사후에 제거하는 RSA 블라인딩(Blinding) 기법 강제 적용 |
