## 연관 키워드

- 다자간 계산(MPC, Multi-Party Computation), 비밀 공유(Secret Sharing), 샤미르 (t, n) 임계치 방식
- 비의도적 전송(OT, Oblivious Transfer), 혼합 회로(Garbled Circuit), 준수 적대자, 악의적 적대자
- 동형 암호(FHE), 신뢰 실행 환경(TEE), 임계치 서명(TSS), 연합학습, 비대화형 영지식 증명(NIZKP)

## Ⅰ. 다자간 계산의 개요

- 핵심 요약 : 참여자가 입력을 공개하지 않고도 모든 입력에 대한 함수 결과를 함께 계산하는 암호학적 기법.
- 개념 : 복수의 참여자가 각자의 입력 데이터를 서로 공개하지 않은 상태에서, 모든 입력값에 대한 함수 결과를 안전하게 공동 계산하는 암호학적 기법(**다자간 계산**, MPC).
- 배경 및 필요성 : 인공지능과 빅데이터 분석을 위해 기관 간 데이터 결합 수요가 늘었으나, 개인정보 보호 법령과 GDPR(General Data Protection Regulation) 등으로 원시 데이터의 직접 공유가 어려워져 기술적 대안이 요구됨.
- 주요 목적 : 데이터 기밀성을 유지하면서 협업 분석과 모델 학습의 가치를 실현하고, 중앙 집중 저장소에 의한 대규모 유출 위험(단일 실패 지점, SPOF)을 줄임.

## Ⅱ. 다자간 계산의 특징 및 장점

- 핵심 요약 : 입력 비공개, 임계치 기반 분산, 소프트웨어 중심 구현이 결합되어 규제를 지키면서 협업 분석을 가능하게 하는 방식.

1. **입력 비공개** : 각 참여자가 원본을 공유하지 않고 결과만 얻음 → 법적 규제 하에서도 기관 간 협업 분석 가능.
2. **임계치 비밀 공유** (Shamir Secret Sharing, (t, n)) : 원본을 n개 조각으로 나누고 t개 이상이 모여야 복원 → 단일 저장소의 유출 위험 제거.
3. **순수 소프트웨어 구현** : 특정 하드웨어에 의존하지 않음 → 벤더 종속 없이 다자간 결합 분석 구현.
4. **적대자 모델 구분** : 준수 적대자(Semi-Honest)와 악의적 적대자(Malicious)를 나누어 프로토콜 강도를 선택 → 보안 요구와 성능의 균형.

## Ⅲ. 다자간 계산의 구조 (흐름)

- 핵심 요약 : 입력을 조각내 분산 보관한 뒤 조각 상태에서 회로를 연산하고, 최종 결과만 복원하는 구조.

```text
[ 비밀 공유 기반 연산 ]

참여자 A, B, C가 각자 입력 분할
   ↓
조각 교환 (노드마다 1개씩만 보유)
   ↓
분산 회로 연산 (중간값 비공개)
   ↓
결과 f(xA, xB, xC)만 복원
```

```text
[ 임계치 서명 (TSS) 흐름 ]

키 조각을 여러 노드에 분산 생성
   ↓
t개 이상 노드가 부분 서명 생성
   ↓
부분 서명 결합 → 단일 서명
   ↓
개인키 전체는 어느 노드에도 없음
```

- **비의도적 전송** (OT, Oblivious Transfer) : 송신자는 수신자가 무엇을 골랐는지 알 수 없고, 수신자는 고른 값 외에는 알 수 없도록 보장하는 기본 프리미티브.
- **혼합 회로** (Garbled Circuit) : 불리언 회로의 진리표를 암호화하여 두 참여자가 서로의 입력을 모른 채 회로를 평가하게 하는 방식.

## Ⅳ. 다자간 계산, 동형 암호, 신뢰 실행 환경의 비교

- 핵심 요약 : MPC는 참여자 간 신뢰를 암호 이론으로 분산하고, FHE는 수학적 난제, TEE는 하드웨어 신뢰에 기대는 점에서 차이가 있음.

| 비교 항목 | **다자간 계산** (MPC) | **동형 암호** (FHE, Fully Homomorphic Encryption) | **신뢰 실행 환경** (TEE, Trusted Execution Environment) |
|---|---|---|---|
| 신뢰 기반 | 참여자 간 임계치 신뢰 | 격자 기반 수학적 난제 | 하드웨어 제조사의 칩 신뢰 |
| 통신 부담 | 라운드마다 노드 간 통신 큼 | 단일 노드 연산 | 단일 하드웨어 노드 실행 |
| 연산 속도 | 통신 대역폭에 따라 달라짐 | 연산 부하로 매우 느림 | 네이티브에 가까움 |
| 취약 요인 | 과반 결탁 시 프라이버시 붕괴 | 키 관리와 암호문 크기 | 부채널 공격, 메모리 버스 도청 |
| 주요 적용 | 금융사 간 이상거래 탐지, 연합학습 | 클라우드 암호 데이터 분석 | 기밀 컴퓨팅, 블록체인 노드 |

## Ⅴ. 다자간 계산의 한계와 방안

- 핵심 요약 : 통신 라운드, 결탁, 실수 연산의 세 가지 한계를 사전 연산, 검증 가능한 증명, 고정소수점 근사로 대응.

| 한계 | 원인·영향 | 대응 방안 |
|---|---|---|
| 통신 라운드에 따른 지연 | 곱셈 연산마다 반복 통신이 필요하여 WAN 환경에서 지연 급증 | 연산 의존성이 없는 난수를 미리 생성하는 **오프라인 전처리**(Beaver Triple) 기법과 라운드 압축 프레임워크 적용 |
| 참여자 결탁 | 임계치 이상이 공모하면 원본 비밀이 복원되어 프라이버시가 깨짐 | **비대화형 영지식 증명**(NIZKP)으로 각 노드의 연산 정직성을 검증하고 감사 로그로 공모 행위 추적 |
| 실수와 비선형 함수 연산 비용 | 유한체 정수 연산에 최적화되어 부동소수점과 ReLU, Sigmoid 처리 비용이 큼 | **고정소수점**(Fixed-point) 양자화와 다항식 근사로 회로 크기 축소 |

## Ⅵ. 다자간 계산 적용에 대한 기술사적 제언

- 핵심 요약 : 키 관리, 데이터 협업, 하이브리드 구조에 MPC를 적용하여 단일 실패 지점과 원시 데이터 이동을 함께 줄이는 방향.

단일 개인키 보관에 따른 단일 실패 지점을 없애기 위해 암호화폐 수탁과 키 관리 서비스에 MPC 기반 분산 키 생성과 임계치 서명 체계를 도입하는 것이 바람직하다.

의료와 금융 분야의 다기관 AI 학습에서는 원시 데이터를 옮기지 않고 MPC로 모델 가중치만 안전하게 집계하는 연합학습 실증이 필요하다.

대규모 연산은 하드웨어 TEE에서 처리하고 키 관리와 상호 검증은 MPC로 분산하는 계층형 기밀 컴퓨팅 구조를 설계하면 성능과 신뢰를 함께 확보할 수 있다.

## Ⅶ. 결론

- 핵심 요약 : 다자간 계산은 원본 공유 없이 공동 분석을 가능하게 하는 암호 기술로, 분산 신뢰가 필요한 영역에서 쓰임.
- 성능과 통신 비용이 여전히 과제이므로 적용 범위를 키 관리와 연합 분석부터 점진적으로 넓히는 접근이 현실적임.
