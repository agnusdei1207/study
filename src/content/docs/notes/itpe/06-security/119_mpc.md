## Ⅰ. 다자간 계산(MPC)의 개요

- **개념** : 복수의 참여자가 자신의 입력 데이터를 상대방에게 공개하지 않은 상태에서, 모든 참여자의 입력값에 대한 임의의 함수 결과를 안전하게 공동 계산하는 암호학적 기법.
- **배경 및 필요성** : 인공지능(AI)과 빅데이터 분석을 위해 기관 간 데이터 결합 요구가 폭증하고 있으나, 개인정보보호법 및 GDPR 등 엄격한 규제로 인해 원시 데이터(Raw Data)의 직접 공유 및 통합이 법적으로 금지됨에 따라 기술적 대안으로 부각됨.
- **핵심 목적** : 데이터의 프라이버시(기밀성)를 완전 보장하면서 협업 분석 및 모델 훈련의 가치를 실현하고, 단일 실패 지점(SPOF)에 의한 대규모 유출 위협 해소.

## Ⅱ. 다자간 계산(MPC)의 핵심 아키텍처 및 동작 메커니즘

다자간 계산은 샤미르 비밀 공유(SSS), 비의도적 전송(OT), 야오의 혼합 회로(Garbled Circuit), GMW 프로토콜 등의 암호학적 프리미티브를 기반으로 분산 계산을 수행함.

```text
[ 다자간 계산(MPC) 동작 메커니즘 및 3자 비밀 공유 모델 ]

 +-----------------+     +-----------------+     +-----------------+
 |  참여자 A (x_A) |     |  참여자 B (x_B) |     |  참여자 C (x_C) |
 +--------+--------+     +--------+--------+     +--------+--------+
          |                       |                       |
   [비밀 분할 (SSS)]       [비밀 분할 (SSS)]       [비밀 분할 (SSS)]
          |                       |                       |
   [x_A1, x_A2, x_A3]      [x_B1, x_B2, x_B3]      [x_C1, x_C2, x_C3]
          \                       |                       /
           +----------------------+----------------------+
                                  |
              [조각 교환: 각 참여자는 1개씩의 조각만 보유]
              * 노드 1: [x_A1, x_B1, x_C1]
              * 노드 2: [x_A2, x_B2, x_C2]
              * 노드 3: [x_A3, x_B3, x_C3]
                                  |
            [분산 암호 회로 연산 (덧셈/곱셈 게이트 평가)]
            * 통신 라운드 교환을 통해 중간값 노출 없이 연산
                                  |
            [결과 결합: 함수 f(x_A, x_B, x_C) 최종 복원]
```

- **비밀 공유(Secret Sharing)** : 샤미르의 $(t, n)$ 임계치 비밀 공유 기법으로 원본 데이터를 $n$개의 조각으로 나누어 배포하며, $t$개 이상의 조각이 모여야만 복원 가능.
- **비의도적 전송(Oblivious Transfer: OT)** : 송신자가 여러 데이터 중 하나를 수신자에게 전송하되, 수신자가 무엇을 선택했는지 알 수 없고 수신자는 선택한 것 외에 다른 값을 알 수 없도록 보장.
- **혼합 회로(Garbled Circuits)** : 불리언 회로(Boolean Circuit)의 진리표를 암호화하여 상대방이 중간 입력값을 모른 채 회로를 순차 평가하도록 지원(2자간 계산 Yao 프로토콜의 핵심).
- **적대자 모델(Adversary Model)** : 프로토콜을 충실히 따르며 정보만 엿보려는 준수 적대자(Semi-Honest)와 임의로 조작 및 이탈하는 악의적 적대자(Malicious) 모델로 구분 대응.

## Ⅲ. 다자간 계산(MPC)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 다자간 계산 (MPC) | 동형 암호 (FHE) | 신뢰 실행 환경 (TEE) |
| --- | --- | --- | --- |
| 신뢰 기반 | 분산 참여자 간 암호학적 임계치 신뢰 | 수학적 격자 암호 난제 신뢰 | 하드웨어 제조사(Intel, AMD) 칩셋 신뢰 |
| 통신 복잡도 | 연산 라운드별 노드 간 통신 오버헤드 높음 | 단일 노드 연산 (네트워크 통신 불필요) | 단일 하드웨어 노드 실행 (통신 없음) |
| 연산 속도 | 비교적 빠름 (통신망 대역폭에 종속) | 극도로 느림 (연산 부트스트래핑 부하) | 네이티브에 준하는 극도로 빠른 속도 |
| 취약점 요인 | 과반 참여자 결탁(Collusion) 시 프라이버시 붕괴 | 키 관리 복잡성 및 대용량 암호문 | 부채널 공격(Spectre, Meltdown) 및 메모리 버스 도청 |
| 주요 적용 | 금융사 간 이상거래탐지(FDS), 연합학습 | 클라우드 아웃소싱 암호 데이터 검색/분석 | 엔클레이브 기반 기밀 컴퓨팅, 블록체인 노드 |

- MPC는 하드웨어 벤더 종속 없이 순수 소프트웨어 암호 이론만으로 다자간 결합 분석을 가능케 하므로, 연합학습 및 분산 키 관리(TSS)의 차세대 표준 기술로 안착함.

## Ⅳ. 다자간 계산(MPC)의 주요 한계점 및 해결 방안

- **노드 간 통신 라운드 폭증에 따른 네트워크 레이턴시 병목** :
  - **한계점** : 곱셈 게이트 및 비선형 활성화 함수 평가 시 참여자 간 반복적인 통신 동기화가 필요하여 WAN 환경에서 연산 지연이 기하급수적으로 증가.
  - **해결 방안** : 연산 의존성이 없는 난수 생성 작업을 사전에 완료하는 오프라인 전처리(Beaver Triples) 기법과 통신 라운드를 압축하는 고속 MPC 프레임워크 적용.
- **참여자 결탁(Collusion) 시 비밀 노출 위험** :
  - **한계점** : 사전에 합의된 임계치($t$) 이상의 참여자가 공모할 경우 원본 비밀 데이터가 역산되어 프라이버시가 완전히 파괴됨.
  - **해결 방안** : 비대화형 영지식 증명(NIZKP)을 연계하여 각 노드의 연산 정직성을 상시 증명하고, 악의적 공모 차단을 위한 부인 방지 감사 로그 체계 수립.
- **AI 딥러닝 모델의 복잡한 실수 연산 지원 한계** :
  - **한계점** : MPC는 유한체(Finite Field) 상의 정수 연산에 최적화되어 있어, 부동소수점(Float) 및 비선형 함수(ReLU, Sigmoid) 처리 시 막대한 연산 비용 발생.
  - **해결 방안** : 고정소수점(Fixed-point) 양자화 모델 적용 및 비선형 구간 근사화(Polynomial Approximation) 기법을 통한 회로 크기 최소화.

## Ⅴ. 다자간 계산(MPC) 적용 및 발전을 위한 기술사적 제언

- **디지털 자산 임계치 서명(TSS: Threshold Signature Scheme) 확립** : 단일 개인키 보관의 단일 실패점(SPOF)을 제거하기 위해 MPC 기반 분산 키 생성 및 서명 체계를 암호화폐 수탁 및 KMS에 필수 도입.
- **의료·금융 마이데이터 결합 연합학습(Federated Learning) 실증** : 원시 민감정보의 물리적 이동 없이 MPC 프로토콜을 경유해 다기관 AI 모델 가중치(Gradient)만 안전하게 집계하는 프라이버시 보존 AI(PPML) 표준 구현.
- **TEE와 MPC의 하이브리드 기밀 컴퓨팅 설계** : 대규모 연산은 하드웨어 TEE에서 고속 처리하고, 키 관리 및 상호 검증은 MPC로 분산화하는 계층적 보안 아키텍처 수립.
