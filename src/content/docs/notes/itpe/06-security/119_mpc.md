## 지식 로드맵 내 현재 위치

지식 위치: 프라이버시 강화 암호 → **다자간 계산(MPC)**

## 30초 인출

- 본질: 여러 참여자가 각자의 입력 원문을 서로 공개하지 않고 공동 함수 결과를 계산하는 암호학적 프로토콜
- 기술 종류: 비밀 공유 기반 연산, 가블드 회로·불확정 전송 기반 2자 계산 등. 모든 구현이 이 구성요소를 동시에 쓰는 것은 아님
- 경계: 입력 원문 노출을 줄여도 결과로부터의 추론, 공모, 통신량, 법적 처리 근거는 별도 검토

## 1교시 예상문제 (10점)

> MPC의 개념과 비밀 공유 기반 계산 원리를 설명하시오. (예상·10점)

## 1교시 10점 답안

### Ⅰ. 개념

MPC(Multi-Party Computation)는 참여자들이 입력값을 서로 공개하지 않은 채 공동 함수의 정해진 결과만 얻도록 하는 프로토콜.

### Ⅱ. 원리와 조건

```text
참여자 A의 입력 x ─┐
참여자 B의 입력 y ─┼─ 비밀 공유·공동 연산 ─> 결과 f(x,y)
참여자 C의 입력 z ─┘     (원문 공유 제한)
```

보호 수준은 공격자 모델, 허용 공모 수, 출력 범위, 프로토콜 선택에 따라 다름. 통신·연산 비용을 함께 평가.

## 2~4교시 예상문제 (25점)

> MPC의 개념·원리·특징, 기술 종류 및 MPC 기반 인증서비스를 설명하시오. (제133회 2~4교시 원문 연계·25점)

## 2~4교시 25점 답안

### Ⅰ. 개념·특징

각 참여자가 입력의 비밀을 유지하면서 합의한 함수를 계산하고 결과를 획득하는 방식. 단순 암호화 저장과 달리 다수 조직의 공동 연산 과정에서 입력 공개를 제한.

### Ⅱ. 원리

```text
입력 분할·인코딩 → 참여자 간 프로토콜 메시지 교환
                 → 보호된 중간 연산 → 승인된 결과만 복원
```

| 요건 | 확인 내용 |
|---|---|
| 비밀성 | 정해진 공모 한도 내에서 상대의 입력 추론 억제 |
| 정확성 | 악의적 참여자의 잘못된 값·중단에 대한 처리 |
| 결과 통제 | 결과 공개 범위와 빈도 제한 |
| 성능 | 통신 라운드·연산량·참여자 수 |

### Ⅲ. 기술 종류

| 방식 | 핵심 아이디어 | 대표 고려 |
|---|---|---|
| 비밀 공유 기반 | 입력을 여러 조각으로 분산해 공동 연산 | 공모 한도와 통신 비용 |
| 가블드 회로 기반 | 함수 회로의 인코딩된 평가 | 회로 규모와 입력 전달 |
| 불확정 전송(OT) | 선택한 입력만 얻고 선택 정보를 상대에게 숨김 | 2자 계산의 구성요소로 활용 |
| 임계값 서명 | 개인키의 한곳 집중 없이 공동 서명 | 키 조각·참여자 인증·복구 |

비밀 공유·가블드 회로·OT는 대체 또는 조합 가능한 기법. 한 개의 필수 고정 파이프라인으로 도식화하지 않음.

### Ⅳ. MPC 기반 인증서비스 예시

```text
등록: 인증 비밀 또는 서명 키를 여러 주체에 분산
인증: 사용자 요청·정책 확인 → 정해진 임계값 이상의 주체가 공동 계산
검증: 서비스가 결과 서명 또는 인증 응답 확인
```

예를 들어 기기·서버가 키 조각을 나눠 갖고 협력해야 서명하도록 설계 가능. 이는 MPC 적용 예시이며, 모든 패스키·FIDO 서비스가 MPC 인증을 사용한다는 뜻은 아님. 참여자 중 하나가 탈취되거나 오프라인일 때의 정책과 복구 경로 필요.

### Ⅴ. 한계와 적용 조건

| 쟁점 | 대응 |
|---|---|
| 결과를 통한 민감정보 추론 | 결과 최소화·질의 제한·필요 시 차등 프라이버시 결합 |
| 공모·악의적 입력 | 공격자 모델 및 검증 가능한 프로토콜 선택 |
| 성능·가용성 | 참여자 수와 임계값·복구 절차의 성능 시험 |
| 개인정보 법적 근거 | MPC 사용과 처리의 법적 근거를 별도 판단 |

### Ⅵ. 기술사적 제언

보호하려는 입력·허용할 결과·공모 한도를 먼저 명시하고, 인증 적용에서는 키 조각의 생명주기와 장애 복구를 함께 설계.
