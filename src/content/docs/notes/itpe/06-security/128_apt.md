## 지식 로드맵 내 현재 위치

지식 위치: 침해 대응 → 표적형 다단계 공격 → **APT**

## 30초 인출

- **본질:** 명확한 목적(기밀 탈취, 인프라 파괴)을 가진 공격 집단이 특정 표적을 선정하여 장기간 은밀하게 취약점을 탐색하고 다단계 침투를 수행하는 고도화된 지속 위협
- **메커니즘:** 표적 정찰·스피어피싱(초기 접근) → LotL/C2 장악(지속성 확보) → 자격증명 탈취(AD 장악) → 내부 횡적 이동(Lateral Movement) → 핵심 자산 유출 및 파괴
- **통찰:** 정상 시스템 도구를 악용하는 LotL 공격은 시그니처 탐지가 불가능하므로 프로세스 부모-자식 계보 분석과 AD 티어링 및 허니토큰 기반 다층 방어 필수

<details>
<summary>핵심 용어</summary>

- **APT (Advanced Persistent Threat)** : 지능적(Advanced), 지속적(Persistent), 표적화된 위협(Threat)의 복합체.
- **Cyber Kill Chain** : 공격의 단계를 7단계로 모델링하여 각 단계별 차단 지점을 식별하는 방어 체계.
- **MITRE ATT&CK** : 공격자의 실제 전술(Tactics), 기법(Techniques), 절차(Procedures)를 집대성한 매트릭스.
- **LotL (Living off the Land)** : 악성코드 파일 없이 OS 내부의 정상 유틸리티(PowerShell, WMI, Certutil)를 악용하는 기법.

</details>

## 2~4교시 예상문제 (25점)

> 지능형 지속 위협(APT)의 특징, Cyber Kill Chain 7단계와 MITRE ATT&CK 14대 전술을 비교 설명하고, Living-off-the-Land(LotL) 및 횡적 이동(Lateral Movement) 대응을 위한 엔지니어링 다층 방어 체계를 제시하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 국가 배후 또는 고도화된 공격 조직이 특정 표적을 사전에 지정하고, 제로데이 및 정상 도구를 복합 악용하여 장기간 은밀하게 침투·잠복·목적을 달성하는 표적형 지속 공격 |
| 목적 | 군사·산업 기밀 탈취, 핵심 기반시설(발전소, 금융망) 마비, 장기적 첩보 수집 및 공급망 거점 확보 |

- 불특정 다수를 노리는 일반 악성코드와 달리 성공할 때까지 사회공학, 제로데이, 공급망 침투 등 모든 수단을 동원하며 장기 평균 잠복 기간(Dwell Time) 수개월 이상 지속

## Ⅱ. APT 공격의 핵심 기술적 특성

| 특성 항목 | 세부 내용 및 기술적 의미 | 전통적 공격 대비 차별점 |
|---|---|---|
| 고도의 지능성 (Advanced) | 표적 맞춤형 제로데이(0-day), 드라이브 바이 다운로드, 파일리스(Fileless) 기법 총동원 | 범용 악성코드 배포가 아닌 대상 환경 맞춤형 제작 |
| 은밀한 지속성 (Persistent) | 단기 파괴를 지양하고 백도어, WMI 영속성, 레지스트리 Run 키를 통해 수개월간 은폐 잠복 | 침해 즉시 실행 및 탈취하는 단발성 공격과 대조 |
| 명확한 표적성 (Targeted) | 국가 기관, 방산업체, 핵심 금융망 등 사전에 명확한 타깃을 정의하고 맞춤형 정보 수집 | 대량 불특정 스팸/랜섬웨어 살포와 달리 정밀 타깃팅 |
| 정상 도구 악용 (LotL) | PowerShell, WMI, PsExec, BITSAdmin 등 OS 기본 도구를 활용하여 백신 탐지 무력화 | 디스크에 악성 바이너리를 생성하지 않는 파일리스 행위 |

- 최초 침투 성공 후 즉각적인 악의적 행위를 유보하고 내부 자격증명 수집 및 횡적 이동(Lateral Movement)에 집중하는 침투 양상 보유

## Ⅲ. Cyber Kill Chain vs MITRE ATT&CK 연계 분석

```text
[Cyber Kill Chain 7단계와 MITRE ATT&CK 매핑 및 엔지니어링 방어선]

  [Cyber Kill Chain]        [MITRE ATT&CK 핵심 전술]           [단계별 핵심 기술 방어선]
  1. 정찰 (Recon)       ──> Reconnaissance, Resource Dev. ──> 공격 표면 관리 (ASM), OSINT 차단
  2. 무기화 (Weaponize) ──> (공격자 인프라 구축 단계)      ──> 위협 인텔리전스 (CTI) 침해지표 수집
  3. 전달 (Delivery)    ──> Initial Access               ──> 이메일 보안 (SEG), 웹 격리 (RBI)
  4. 취약점 악용 (Exploit)──> Execution, Persistence        ──> EDR 메모리 보호, 제로데이 가상 패치
  5. 설치 (Installation)──> Defense Evasion, Discovery   ──> AMSI 스크립트 차단, AppLocker
  6. 명령제어 (C2)      ──> Command and Control          ──> 차세대 방화벽 DNS 필터, TLS 복호화
  7. 목표달성 (Action)  ──> Lateral Movement, Exfiltration──> 마이크로세그멘테이션, DLP, WORM 감사
```

| Kill Chain 단계 | MITRE ATT&CK 기법 (TTPs) | 침투 행위 상세 | 엔지니어링 방어 통제 |
|---|---|---|---|
| 초기 접근 (Initial Access) | T1566 (Phishing), T1190 (Exploit Public-Facing App) | 악성 오피스 매크로 메일 발송, DMZ 웹서버 취약점 악용 | 피싱 저항형 FIDO2 MFA, WAF 가상 패치 |
| 실행 및 지속 (Execution) | T1059 (Command/Script), T1547 (Boot/Logon Auto) | PowerShell 무단 실행, 스케줄러 등록 | 공격 표면 축소(ASR) 룰, 레지스트리 감시 |
| 자격증명 탈취 (Credential) | T1003 (OS Credential Dumping: LSASS) | Mimikatz 활용 LSASS 메모리 덤프, NTDS.dit 추출 | LSA Protection 활성화, Credential Guard |
| 횡적 이동 (Lateral Move) | T1021 (Remote Services: RDP, SMB, WMI) | Pass-the-Hash 기법을 통한 내부 서버 순차 장악 | 내부 방화벽 포트 445/3389 격리, Jumpbox |
| 유출 및 파괴 (Exfiltration) | T1041 (C2 Channel), T1486 (Data Encrypted for Impact) | 압축 파일 암호화 분할 전송, 파괴형 와이퍼 실행 | 네트워크 유출 차단(NDR), 불변 백업 보존 |

## Ⅳ. APT vs 일반 사이버 공격 vs 표적형 랜섬웨어 비교

| 비교 항목 | APT (지능형 지속 위협) | 일반 사이버 범죄 (기회주의적) | 현대 표적형 랜섬웨어 |
|---|---|---|---|
| 공격 목표 | 전략적 기밀 정보 수집, 시설 무력화 | 즉각적인 금전 탈취, 계정 사기 | 대규모 금전 요구 (다중 협박) |
| 공격 대상 | 사전에 정해진 특정 기업/국가 기관 | 보안이 취약한 불특정 다수 시스템 | 지불 능력이 높은 대기업 및 병원 |
| 공격 기간 | 수개월 ~ 수년 (장기 잠복) | 수분 ~ 수시간 (단기 완료) | 수주 ~ 수개월 (데이터 탈취 후 암호화) |
| 사용 기법 | 0-day, LotL, 커스텀 백도어, 공급망 침투 | 알려진 1-day 취약점, 대량 스팸 | APT 기법(초기침투, 횡적이동) 차용 |
| 탐지 난이도 | 극도로 높음 (정상 관리자 행위 위장) | 보통 (시그니처 및 IP 블랙리스트 탐지) | 초기 잠복 시 극도로 높음, 암호화 시 노출 |

## Ⅴ. APT 방어 시 엔지니어링 한계와 해결 방안

| 한계 | 방안 |
|---|---|
| 악성코드가 파일 없이 메모리에서만 동작하고 정상 유틸리티(PowerShell, WMI, BITS)를 악용하는 LotL 기법으로 시그니처 백신 무력화 | AMSI(Antimalware Scan Interface) 연동을 통한 동적 스크립트 실행 직전 버퍼 난독화 해제 검사, 프로세스 부모-자식 트리(Word $\rightarrow$ cmd $\rightarrow$ powershell) 이상 행위 기반 EDR 차단 |
| 공격자가 내부 침투 후 Active Directory 도메인 컨트롤러(DC)를 장악하여 Kerberos Golden Ticket을 생성함으로써 영구 권한 획득 | Active Directory 티어링 모델(Tier 0/1/2 분리 및 자격증명 이동 원천 차단) 구축, `krbtgt` 계정 암호 반기별 강제 2회 재설정, 허니토큰(Honeytoken) 어카운트 감시 체계 가동 |
| C2 통신을 일반적인 상용 클라우드 서비스(GitHub, Google Drive, Telegram API) 뒤로 은닉하여 네트워크 아웃바운드 차단 회피 | 엔드포인트 EDR과 네트워크 NDR을 연동하여 프로세스별 클라우드 API 호출 빈도 분석, TLS 1.3 인라인 복호화 검사 및 CASB 기반 비인가 테넌트 토큰 차단 |
| 백도어가 내부망에 수개월간 잠복하여 정상 운영 트래픽과 완벽히 융합됨에 따라 방화벽 및 정적 경보 체계의 사각지대 발생 | 마이크로세그멘테이션(Micro-segmentation) 기반 동서(East-West) 트래픽 격리, 위협 헌팅(Threat Hunting) 전담팀 정기 가동, 침해사고 분석(CTI) IOC 실시간 매칭 |

## Ⅵ. APT 대응 엔터프라이즈 제로 트러스트 다층 방어 체계 제언

```text
[APT 무력화를 위한 제로 트러스트 4대 방어 계층 아키텍처]

  +---------------------------------------------------------------+
  |                 1. 아이덴티티 계층 (Identity First)           |
  |     - AD Tiering 모델 (Tier 0 도메인 컨트롤러 완전 격리)      |
  |     - 조건부 접근 통제 및 피싱 저항성 FIDO2 패스키 전면 적용  |
  +---------------------------------------------------------------+
                                  │
                                  ▼
  +---------------------------------------------------------------+
  |                 2. 엔드포인트 계층 (EDR / XDR)                |
  |     - Credential Guard (LSASS 메모리 가상화 격리)             |
  |     - ASR (공격 표면 축소) 룰 및 AMSI 스크립트 블록 로깅      |
  +---------------------------------------------------------------+
                                  │
                                  ▼
  +---------------------------------------------------------------+
  |                 3. 네트워크 계층 (Micro-segmentation)         |
  |     - 단말 간 SMB/RDP 통신 전면 차단 (횡적 이동 원천 봉쇄)    |
  |     - C2 탐지 전용 DNS 터널링 분석 및 NDR 인라인 차단        |
  +---------------------------------------------------------------+
                                  │
                                  ▼
  +---------------------------------------------------------------+
  |                 4. 복구 및 탄력성 계층 (Cyber Resilience)     |
  |     - 논리적 에어갭(Air-gap) 기반 불변 백업(WORM) 인프라      |
  |     - SOAR 플레이북 기반 침해 단말 3분 내 자동 네트워크 격리  |
  +---------------------------------------------------------------+
```

| 영역 | 엔지니어링 핵심 과제 | 성과 지표 |
|---|---|---|
| 초기 침투 억제 | 전사 외부 접점 공격 표면(ASM) 취약점 자동 패치 및 FIDO2 인증 | 스피어피싱 침투 성공률 < 0.1%, 외부 노출 취약점 제로화 |
| 횡적 이동 차단 | 워크스테이션 간 P2P 통신 차단 및 Tiered Admin 접근 통제 | 내부 횡적 이동 시도 시 격리 소요 시간 < 5분 |
| 사고 탐지 대응 | XDR 및 SIEM 연계 위협 헌팅 기반 잠복 위협 지속 발굴 | 침해 위협 평균 체류 시간(Dwell Time) 0일(실시간 차단) 수렴 |
