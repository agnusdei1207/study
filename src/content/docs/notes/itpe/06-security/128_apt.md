## 지식 로드맵 내 현재 위치

지식 위치: 침해 대응 → 표적형 다단계 공격 → **APT**

## 30초 인출

- 본질: 특정 목표에 대해 지속적 접근을 시도하며 여러 경로·기법을 조합하는 표적형 위협
- 메커니즘: 정찰·초기 접근 → 실행·내부 탐색·측면 이동 → 정보 수집·유출 또는 영향
- 통찰: 한계: APT를 특정 기법·체류기간으로 단정하면 실제 경로를 놓침 → 방안: Kill Chain·ATT&CK으로 단계별 관측 근거와 탐지 공백을 검증

<details>
<summary>핵심 용어</summary>

- **APT** : 특정 목표를 향해 여러 기법을 조합하며 지속적으로 접근하는 표적형 위협.
- **Cyber Kill Chain** : 공격 과정을 단계로 나누어 개입 지점을 찾는 분석 틀.
- **MITRE ATT&CK** : 관측되는 공격 전술·기법을 분류한 지식 기반.
- **LotL** : 정상 운영 도구·기능을 공격에 악용하는 방식.

</details>

## 2~4교시 예상문제 (25점)

> APT의 다단계 공격을 Cyber Kill Chain과 MITRE ATT&CK 관점에서 설명하고, 각 단계의 탐지·대응 체계를 설계하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

| 항목 | 개요 |
|---|---|
| 정의 | APT는 특정 목표에 지속적으로 접근하며 여러 공격 경로와 기법을 조합하는 표적형 위협 |
| 목적 | 초기 접근부터 내부 이동·목표 달성까지의 공격 단계별 탐지·대응 설계 |

APT는 표적과 목적을 두고 지속적으로 접근하는 위협. 공격자의 실제 전술은 피해 환경과 목표에 따라 달라지므로 특정 도구나 경로를 필수 조건으로 보지 않음.

### Ⅱ. 분석 프레임워크

```text
침해 사건의 시간 흐름 ─> Kill Chain의 개입 단계
관측된 행동·증거 ─────> ATT&CK 전술·기법
             두 관점을 대조해 탐지 공백 확인
```

| 구분 | 주요 목적 | 활용상 주의 |
|---|---|---|
| Cyber Kill Chain | 정찰부터 목표 달성까지 단계별 개입 지점 파악 | 선형 순서만 강요하지 않음 |
| MITRE ATT&CK | 관측 가능한 전술·기법과 탐지 공백 정리 | 최신 전술 수·이름은 개정에 따라 변동 |

### Ⅲ. 단계별 방어 구조

| 공격 단계 | 관측 신호 | 통제 |
|---|---|---|
| 초기 접근 | 피싱·취약 공개 서비스·유효 계정 남용 | 패치·접근 제한·피싱 저항형 인증 |
| 실행·지속성 | 신규 프로세스·자동 실행·계정 변화 | EDR·변경 감시·권한 관리 |
| 자격증명·탐색 | 비정상 인증·AD 질의·내부 스캔 | 최소 권한·로그 상관 분석 |
| 측면 이동 | 원격 접속·관리 도구의 비정상 사용 | 망 분리·세션 기록·통제 |
| 수집·유출·영향 | 대량 접근·외부 전송·서비스 변경 | 데이터 접근 감사·유출 탐지·복구 |

```text
자산·권한 목록 ─> 로그·엔드포인트 관측 ─> TTP 매핑
                                      └─> 조사·격리·복구·룰 개선
```

#### LotL과 탐지 한계

LotL은 운영체제·관리 도구 등 정상 기능의 악용. 도구 이름만으로 악성 여부를 판정할 수 없으므로 사용자·호스트·시각·권한·목적지의 맥락을 결합. EDR이나 XDR 역시 완전 탐지 보장 수단이 아님.

#### 랜섬웨어와의 관계

랜섬웨어 운영자도 표적형 초기 접근·측면 이동·장기 준비를 수행할 수 있음. APT와 랜섬웨어를 잠복 여부 또는 침해 목표만으로 상호 배타적으로 구분하지 않음.

#### 실무 적용

| 과제 | 실행·검증 |
|---|---|
| 탐지 공백 | 중요 자산별 ATT&CK 전술·기법에 대한 로그와 탐지 규칙 점검 |
| 대응 속도 | 탐지→분석→격리→복구 절차와 권한의 사전 합의 |
| 업무 영향 | 격리 자동화의 오탐·중단 영향을 훈련으로 검증 |
| 재발 방지 | 침해 원인·이동 경로와 누락 로그를 사후 보완 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| APT를 특정 기법·체류기간으로 단정하면 실제 공격 경로를 놓침 | Kill Chain·ATT&CK 관측 근거와 탐지 공백을 단계별 검증 |

### Ⅴ. 제언

특정 솔루션의 완전 방어 주장보다 자산별 공격 경로의 가시성, 검증 가능한 탐지와 복구 능력 확보.
