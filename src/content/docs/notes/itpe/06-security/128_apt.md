## Ⅰ. 지능형 지속 위협(APT)의 개요

- 개념 : 특정 조직이나 국가의 핵심 기밀, 지적 재산권 탈취 또는 기반시설 마비를 명확한 목표로 설정하고, 장기간에 걸쳐 다양한 **고도화 공격 기법** (사회공학, 제로데이, 은닉 도구)을 융합하여 지속적으로 은밀하게 침투·잠복·파괴하는 지능형 사이버 위협.
- 배경 및 필요성 : 과거 불특정 다수를 대상으로 한 단순 과시형 악성코드나 단기적 금전 탈취 공격에서 진화하여, **국가 지원 해킹 그룹** (APT28, 라자루스 등)에 의해 정밀 타깃형 군사·경제적 첩보 수집 목적으로 발전함.
- 핵심 목적 : 단일 보안 솔루션의 탐지를 우회하고 대상 네트워크 내부에 장기 거점을 확보하여 관리자가 침해 사실을 인지하지 못하는 상태에서 핵심 자산을 은닉 유출.

## Ⅱ. 지능형 지속 위협(APT)의 핵심 아키텍처 및 동작 메커니즘

APT(Advanced Persistent Threat) 공격은 록히드 마틴의 **사이버 킬 체인** (Cyber Kill Chain) 7단계와 **MITRE ATT&CK** 프레임워크의 **TTP** (전술, 기법, 절차) 매트릭스를 기반으로 체계적으로 전개됨.

```text
[ Lockheed Martin Cyber Kill Chain 기반 APT 공격 라이프사이클 ]

 1. 정찰 (Reconnaissance)   : SNS, OSINT, 임직원 이메일 수집, 포트 스캔
             |
             v
 2. 무기화 (Weaponization)  : 제로데이 취약점 익스플로잇 + 백도어 RAT 결합
             |
             v
 3. 전달 (Delivery)        : 스피어 피싱(Spear Phishing) 악성 문서, 워터링 홀
             |
             v
 4. 취약점 공격 (Exploitation) : OS/애플리케이션 취약점 실행 (오피스 매크로 등)
             |
             v
 5. 설치 (Installation)     : 레지스트리 자동 실행 등록, 지속성(Persistence) 확보
             |
             v
 6. C2 연결 (Command&Control) : 은닉 채널(DNS 터널링, HTTPS)로 C2 서버 접속
             |
             v
 7. 목표 달성 (Actions on Objectives):
    +-------------------------------------------------------------+
    | 내부 정찰 -> 권한 상승(AD 장악) -> 측면 이동(Lateral Move) |
    | -> 데이터 스테이징/압축 -> 은닉 유출(Exfiltration) / 파괴  |
    +-------------------------------------------------------------+
```

- **공격의 지속성(Persistence)** : 단발성 침투에 그치지 않고 WMI, 예약 작업, 서비스 등록, DLL 사이드로딩 등을 통해 시스템 재부팅 후에도 제어권을 유지.
- **정상 도구의 악용(LOLBins: Living Off the Land)** : 외부 해킹 도구를 반입하지 않고 OS(Operating System) 내장 정상 도구(PowerShell, Certutil, Bitsadmin, PsExec)를 사용하여 안티바이러스 탐지 회피.
- **내부 측면 이동(Lateral Movement)** : Pass-the-Hash, Pass-the-Ticket(Kerberos) 기법으로 초기 감염 단말에서 Active Directory(AD) 도메인 컨트롤러로 순차적 권한 상승.
- **C2(Command and Control) 은닉 통신 채널** : 일반적인 포트 차단을 우회하기 위해 정상 클라우드(Google Drive, Dropbox, Slack) API(Application Programming Interface)를 C2 채널로 악용하거나 DNS(Domain Name System) 쿼리 터널링 기법 사용.

## Ⅲ. 지능형 지속 위협(APT)의 세부 구성 요소 및 비교 분석

| 비교 항목 | **지능형 지속 위협** (APT) | **일반 악성코드 공격** | **랜섬웨어 공격** |
| --- | --- | --- | --- |
| 공격 대상 | 특정 기업, 정부 기관, 군사 인프라 (표적) | 불특정 다수의 취약한 인터넷 사용자 | 불특정 다수 또는 지불 능력 높은 기업 |
| 공격 동기 | 국가 첩보 수집, 지적재산 탈취, 망 파괴 | 단순 금전 갈취, 스팸 발송, PC(Personal Computer) 좀비화 | 직접적인 몸값(Ransom) 암호화폐 요구 |
| 공격 기간 | 수개월에서 수년 (장기 잠복 및 은닉) | 수시간에서 수일 (단발성 실행) | 수일 내에 전격 암호화 후 몸값 통보 |
| 공격 기법 | 스피어피싱, 제로데이, TTP 맞춤 설계 | 알려진 시그니처 취약점, 단순 대량 유포 | RaaS 기반 유포, 이중/삼중 협박 |
| 침해 징후 | 탐지가 극도로 어려움 (로그 삭제 및 LOLBins) | 백신 경고, 시스템 이상 동작 즉각 감지 | 배경화면 변경 및 파일 암호화로 즉시 노출 |

- APT는 완벽한 사전 차단이 불가능하므로, '이미 침투당했다(Assume Breach)'는 전제하에 내부 횡적 이동을 조기에 탐지하고 피해를 국소화하는 **XDR/EDR**(Endpoint Detection and Response) 체계가 핵심임.

## Ⅳ. 지능형 지속 위협(APT)의 주요 한계점 및 해결 방안

- 알려지지 않은 제로데이(0-day) 취약점 사용으로 시그니처 백신 무력화 :
  - 한계점 : 패치가 존재하지 않는 신규 취약점을 무기화하여 침투하므로 기존 패턴 기반 안티바이러스 및 네트워크 방화벽이 전혀 반응하지 못함.
  - 해결 방안 : 정적 시그니처 대신 엔드포인트 행위 기반 탐지(EDR), 인공지능 이상 징후 분석, 클라우드 샌드박스 동적 실행 분석 결합.
- 장기 잠복 기간 동안 발생하는 대규모 알람 속 신호 탐지 난제 (Alert Fatigue) :
  - 한계점 : 공격자가 수개월에 걸쳐 천천히 정상 명령어를 사용하여 측면 이동하므로 일상적인 시스템 관리 트래픽과 구별 불가능.
  - 해결 방안 : MITRE ATT&CK 기반으로 개별 이벤트를 공격 시나리오 그래프로 상관 연관화(Correlation)하는 XDR 및 위협 헌팅(Threat Hunting) 도입.
- 공급망(Supply Chain) 경유 침투에 따른 경계 보안 붕괴 :
  - 한계점 : 대상 기관을 직접 공격하지 않고 신뢰받는 보안 소프트웨어(SolarWinds 등) 업데이트 서버를 먼저 감염시켜 정상 서명된 패치로 악성코드 배포.
  - 해결 방안 : 소프트웨어 자재명세서(SBOM, Software Bill of Materials) 검증, 빌드 파이프라인 무결성 감시, 제로 트러스트 기반 내부 서비스 간 상호 인증 강화.

## Ⅴ. 지능형 지속 위협(APT) 적용 및 발전을 위한 기술사적 제언

- 선제적 위협 디셉션(Deception: 허니팟, 허니토큰) 구축 : 내부망 곳곳에 가짜 관리자 자격증명과 가짜 DB(Database) 서버를 배치하여 측면 이동을 시도하는 공격자를 즉각적으로 탐지 및 유인 격리.
- Active Directory 및 신원(Identity) 인프라 하드닝 : Tier 아키텍처(Tier 0/1/2 분리), 특권 접근 관리(PAM, Privileged Access Management), LAPS(로컬 관리자 비밀번호 솔루션) 도입을 통해 티켓 탈취 원천 봉쇄.
- 침해사고 대응 훈련을 위한 사이버 공격방어 훈련(사이버 레인지) 정례화 : 실제 APT 그룹의 TTP 시나리오를 바탕으로 레드팀(공격)과 블루팀(방어) 간의 공방 훈련을 수행하여 침해 지연 시간(Dwell Time) 최소화.
