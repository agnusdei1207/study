## 연관 키워드

- Salt Typhoon, Volt Typhoon, LotL, 국가 배후 APT, 파일리스(Fileless), 유효 계정
- LOLBins, 자격증명 탈취, 측면 이동, UEBA, WDAC, Sysmon

## Ⅰ. Salt Typhoon / Volt Typhoon (LotL)의 개요

- 핵심 요약 : 정상 관리 도구와 유효 계정을 악용해 파일을 남기지 않고 장기 잠복하는 국가 배후 공격 양상.
- 개념 : 중국 국가 배후로 분류되는 Volt Typhoon은 **Living-off-the-Land** (LotL, 악성 실행 파일 없이 시스템에 기본 설치된 도구로 공격하는 기법)을 써서 중요 기반시설 네트워크에 잠복하고, Salt Typhoon은 통신 사업자 장비를 노려 도청 기반을 마련한 것으로 보도된 국가 배후 고급 지속 위협(APT, Advanced Persistent Threat)임.
- 배경 및 필요성 : 공격자가 별도의 악성코드를 설치하지 않고 기본 관리 도구로 활동하면서 시그니처 기반 탐지가 무력화되어, 행위와 맥락을 보는 탐지의 필요성이 커짐. 미국 CISA와 NSA 등은 2024년 2월 공동 권고(AA23-144A)를 통해 이 기법의 식별과 완화 지침을 제시함.
- 주요 목적 : 평시에 기반시설 네트워크에 발판을 확보해 두고, 필요할 때 교란이나 정보 수집을 수행할 수 있는 은밀한 지속성을 유지하는 것.

## Ⅱ. Salt Typhoon / Volt Typhoon (LotL)의 특징 및 장점

- 핵심 요약 : 파일 없이 정상 도구와 계정을 쓰는 은닉성이 탐지 회피와 장기 지속성으로 이어지는 공격 방식.

1. **파일리스** (Fileless, 디스크에 악성 파일을 남기지 않고 메모리에서만 실행하는 방식) 실행 : 파일 기반 백신과 해시 탐지를 우회 → 잠복 기간이 길어짐.
2. 정상 도구 악용 : 운영체제 내장 도구인 LOLBins(Living-off-the-Land Binaries)를 사용 → 관리자 작업과 구분이 어려워 대응 시점이 늦어짐.
3. 유효 계정 활용 : 탈취한 관리자 계정으로 진입 → 정상 세션처럼 보여 경계 통제를 쉽게 통과함.

## Ⅲ. Salt Typhoon / Volt Typhoon (LotL)의 구조 (흐름)

- 핵심 요약 : 초기 침투, 자격증명 탈취, 측면 이동, 지속성 유지의 순으로 진행되며 각 단계가 정상 도구로 이루어짐.

```text
[ 공격 단계 ]

1. 초기 침투
   외부 노출 엣지 장비의 취약점 악용
              ↓
2. 자격증명 탈취
   LSASS 메모리 덤프, NTDS.dit 추출
              ↓
3. 측면 이동 및 터널링
   netsh 포트 포워딩으로 내부 경로 확보
              ↓
4. 지속성 유지
   예약 작업 등록, 이벤트 로그 선별 삭제
```

```text
[ 다계층 방어 구조 ]

엣지 계층 : 관리 인터페이스 외부 차단
              ↓
호스트 계층 : 실행 허용 목록, 언어 모드 제한
              ↓
분석 계층 : 프로세스 트리, 스크립트 블록 로그
```

1. **정찰** (Reconnaissance) : `whoami`, `net user`, `nltest /dclist` 명령으로 관리자 그룹과 도메인 컨트롤러 목록을 파악.
2. **자격증명 탈취** (Credential Dumping) : `comsvcs.dll`의 MiniDump 기능으로 LSASS(Local Security Authority Subsystem Service) 메모리를 덤프하고, `ntdsutil`로 AD(Active Directory) 데이터베이스인 NTDS.dit에서 패스워드 해시를 추출.
3. 트래픽 터널링 : `netsh interface portproxy`로 외부 명령 서버와 내부 호스트 사이의 포트 포워딩 경로를 구축.
4. 원격 실행 : `wmic`과 WinRM을 통해 탈취한 도메인 관리자 계정으로 내부 단말을 원격 실행.
5. 인메모리 스크립트 : `powershell.exe -enc`로 Base64 인코딩된 스크립트를 디스크 기록 없이 실행.

## Ⅳ. Salt Typhoon / Volt Typhoon (LotL)과 전통적 악성코드 공격의 비교

- 핵심 요약 : 파일 기반 악성코드 공격과 달리, LotL 공격은 탐지의 대상이 파일에서 행위와 맥락으로 옮겨감.

| 비교 항목 | 전통적 악성코드 공격 | LotL 기반 은닉 공격 |
| --- | --- | --- |
| 페이로드 존재 | 디스크에 악성 실행 파일 생성 | 디스크 파일 없이 기본 도구를 메모리에서 실행 |
| 탐지 기술 | 시그니처 해시, YARA 룰, 백신 엔진 | 프로세스 부모-자식 관계, 실행 인자 등 행위 분석 |
| 권한 및 계정 | 취약점을 이용한 서비스 악용 | 탈취된 유효 관리자 계정 사용 |
| 네트워크 트래픽 | 비표준 포트의 외부 통신으로 탐지가 비교적 쉬움 | 80/443 등 정상 관리 프로토콜과 VPN 세션으로 위장 |
| 대응 난이도 | 파일 격리와 백신 업데이트로 대응 가능 | 정상 관리 작업과 공격 행위의 구분이 어려움 |

## Ⅴ. Salt Typhoon / Volt Typhoon (LotL)의 한계와 방안

- 핵심 요약 : 정상 관리 행위와의 구분, 감시 사각지대, 로그 인멸, 유효 계정 남용을 행위 분석, 흐름 감시, 원격 로그 보존, 피싱 저항 인증으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 정상 관리 행위와의 오탐 | 관리 스크립트와 공격 명령의 인자가 유사해 경보가 과다 발생 | UEBA(User and Entity Behavior Analytics)로 비업무 시간, 비인가 IP 대역, 비정상 명령 조합에 한정해 고위험 경보 발령 | 경보 오탐률 |
| 엣지 장비 감시 사각지대 | 상용 EDR 에이전트를 설치할 수 없는 장비에서 행위 식별 불가 | 엣지 장비의 NetFlow 및 IPFIX 흐름 메타데이터를 수집해 비인가 포트 포워딩 탐지 | 비인가 포트 포워딩 탐지 건수 |
| 로그 삭제를 통한 증적 인멸 | 공격자가 이벤트 로그를 삭제해 추적이 불가능해짐 | Windows 이벤트 전달(WEF, Windows Event Forwarding)로 중앙 서버에 실시간 전달하고 WORM 저장 설정 | 로그 전달 누락률 |
| 유효 계정 기반 MFA 우회 | 탈취된 계정으로 정상 세션처럼 로그인 | 피싱 저항성 하드웨어 인증키(FIDO2) 적용과 기기 상태 검증 기반 세션 통제 | 기기 미준수 세션 차단 건수 |

## Ⅵ. Salt Typhoon / Volt Typhoon (LotL)에 대한 기술사적 제언

- 핵심 요약 : 노출면 축소, 실행 통제, 행위 가시성을 순서대로 갖춰 파일 없는 침해를 조기에 드러내야 함.

1. 노출면 최소화 : 방화벽과 VPN의 관리 콘솔을 사설망에서만 접근하도록 제한하고, 제조사 지원이 끝난 노후 엣지 장비를 주기적으로 교체하는 정책 필요.
2. 실행 통제 : 불필요한 내장 도구의 실행을 **Windows Defender Application Control** (WDAC)로 차단하는 방식을 기본 설정으로 적용하는 방향 필요.
3. 행위 가시성 : PowerShell 스크립트 블록 로깅과 Sysmon의 프로세스 기록을 중앙에서 상관분석하는 체계 필요.

## Ⅶ. 결론

- 핵심 요약 : LotL 위협은 악성코드의 존재가 아니라 정상 행위의 맥락을 읽는 능력의 문제임.
- 시사점 : 국가 배후 장기 잠복에 대비해 행위 가시성과 계정 신뢰 기반을 함께 갖춘 기관이 피해 범위를 줄일 수 있음.
