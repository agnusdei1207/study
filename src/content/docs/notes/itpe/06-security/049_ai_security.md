## 지식 로드맵 내 현재 위치

정보보호 관리 → 인공지능 시스템 보호 → AI 생애주기 보안 및 신뢰성 확보

## 30초 인출

- **본질:** 데이터 수집, 모델 학습, 배포, 추론 등 AI 전주기에서 발생하는 적대적 공격(Adversarial Attack), 지식재산 탈취, 데이터 유출을 방어하고 모델의 견고성과 신뢰성을 확보하는 종합 보안 체계
- **메커니즘:** 학습 데이터 정제 및 무결성 검증 → 적대적 훈련(Adversarial Training) 및 가중치 보호 → 입력/출력 가드레일 필터링 → 런타임 이상 탐지 및 AI 레드팀(Red Teaming) 검증
- 통찰: 단순 소프트웨어 취약점 패치를 넘어 데이터 무결성 검증, 적대적 섭동 방어, 입출력 가드레일, AI 공급망(MLSecOps)을 아우르는 전주기 심층 방어 체계 구축 필수

<details><summary>핵심 용어</summary>

- **AI 보안(AI Security):** AI 시스템의 기밀성, 무결성, 가용성뿐만 아니라 모델의 견고성, 안전성, 설명가능성을 보장하기 위한 기술적·관리적 보호 활동.
- **적대적 머신러닝(AML, Adversarial Machine Learning):** 인공지능 모델의 학습 데이터나 추론 입력을 조작하여 모델의 오분류 및 비정상 동작을 유도하는 공격 및 방어 기법.
- **데이터 중독(Data Poisoning):** 학습 데이터셋에 악의적 백도어 트리거를 삽입하여 특정 조건에서 공격자가 원하는 출력을 생성하도록 유도하는 공격.
- **회피 공격(Evasion Attack):** 사람 눈에는 보이지 않는 미세한 노이즈(섭동, Perturbation)를 입력 데이터에 추가하여 모델의 오작동을 유발하는 추론 단계 공격.
- **AI RMF(AI Risk Management Framework):** 미국 NIST가 제정한 인공지능 위험 관리 프레임워크(Govern, Map, Measure, Manage 4대 기능 구성).

</details>

## 2~4교시 예상문제 (25점)

> 인공지능(AI) 시스템의 수명주기(데이터 수집, 학습, 배포, 추론)별 주요 보안 위협과 취약점을 분석하고, 적대적 공격 방어 및 신뢰성 확보를 위한 기술적·관리적 대응 방안을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 머신러닝 및 딥러닝 기반 시스템의 데이터 파이프라인, 모델 가중치, 추론 API, 외부 도구 연동 전반에 걸쳐 악의적 공격과 오용을 차단하고 신뢰성을 보장하는 융합 보안 체계 |
| 목적 | 적대적 공격으로 인한 인공지능 오작동 방지, 학습 데이터 내 민감정보 유출 차단, 안전하고 설명 가능한 인공지능 운영 거버넌스 확립 |

## Ⅱ. AI 보안의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 비결정론적 특성 대응 | 입력 값에 대한 고정된 로직이 아닌 확률적 추론 결과의 신뢰성과 경계값 왜곡 방어 | 가드레일, 불확실성 추정 |
| 데이터-모델 복합성 | 소스코드 결함뿐만 아니라 학습 데이터의 편향/오염 및 모델 가중치 탈취 위협 존재 | 데이터 무결성 해시, 가중치 암호화 |
| 공격 표면의 광범위성 | 학습 데이터 수집, 모델 아티팩트 공급망, 프롬프트 인젝션, API 출력 등 전방위 노출 | MLSecOps 파이프라인 |
| 신뢰성·투명성 결합 | 보안 통제 적용 시 단순 차단을 넘어 설명 가능성(XAI) 및 공정성(Fairness) 동시 만족 | NIST AI RMF, ISO/IEC 42001 |

## Ⅲ. AI 라이프사이클별 위협 및 보안 아키텍처

```text
[ 1. 데이터 수집/정제 ] ── 위협: 데이터 중독(Poisoning), 편향 삽입
       │  방어: 데이터 출처 검증, 서명 검증, 이상치 필터링
       ▼
[ 2. 모델 설계/학습 ]   ── 위협: 백도어 삽입, 공급망 라이브러리 악성코드
       │  방어: 적대적 훈련(FGSM/PGD 방어), Safetensors, 차분 프라이버시
       ▼
[ 3. 모델 배포/검증 ]   ── 위협: 모델 도난, 가중치 변조, 역공학
       │  방어: TEE(신뢰실행환경) 기반 가중치 보호, AI 레드팀 모의 침투
       ▼
[ 4. 추론 및 운영 ]     ── 위협: 회피 공격(Evasion), 프롬프트 인젝션, 모델 추출
       │  방어: 입력 가드레일, API 쿼리 레이트 제한, 차분 프라이버시 노이즈
       ▼
[ 통합 거버넌스 ]       ── NIST AI RMF / ISO 42001 기반 생애주기 위험 모니터링
```

| 생애주기 단계 | 주요 위협 유형 | 핵심 보안 대책 |
|---|---|---|
| 1. 데이터 수집 | 데이터 중독(Poisoning), 레이블 변조, 저작권 침해 | 데이터 계통(Data Lineage) 추적, 이상치 클러스터링 필터링 |
| 2. 모델 학습 | 학습 데이터 프라이버시 유출, 백도어 삽입 | 차분 프라이버시(Differential Privacy), 적대적 훈련 |
| 3. 모델 배포 | 모델 파일 내 임의 코드 실행(Pickle RCE), 가중치 탈취 | Safetensors 형식 채택, 기밀 컴퓨팅(TEE) 메모리 암호화 |
| 4. 추론 및 운영 | 적대적 섭동 회피 공격, 모델 역공학(Model Inversion) | 입력 정규화, 출력 레이트 제한, 듀얼 가드레일 |
| 5. 전주기 거버넌스 | 규제 미준수, 설명 불가능성으로 인한 책임 소재 불명확 | AI RMF 프레임워크 구축, XAI(설명가능한 AI) 지표 적용 |

## Ⅳ. 전통적 IT 보안과 AI 보안 비교

| 구분 | 전통적 IT 보안 (Traditional IT Security) | 인공지능 보안 (AI Security) |
|---|---|---|
| 보호 대상 | 서버, 네트워크, DB, 소스코드, 시스템 엔드포인트 | 학습 데이터, 신경망 가중치, 하이퍼파라미터, 추론 API |
| 주요 위협 | SQLi, XSS, 버퍼 오버플로우, 랜섬웨어 | 데이터 중독, 적대적 회피, 모델 역추출, 프롬프트 인젝션 |
| 취약점 본질 | 소프트웨어 구현 결함 및 설정 오류(CVE) | 딥러닝 모델의 수학적·통계적 결정 경계의 취약성 |
| 방어 메커니즘 | 방화벽, IPS, WAF, 패치 관리, 안티바이러스 | 적대적 훈련, 입력 전처리, 출력 노이즈 주입, 가드레일 |
| 표준 프레임워크 | ISMS-P, ISO 27001, NIST CSF | NIST AI RMF, ISO/IEC 42001, OWASP AI Top 10 |

## Ⅴ. AI 보안의 한계와 방안

| 한계 | 방안 |
|---|---|
| 적대적 훈련(Adversarial Training) 적용 시 고차원 결정 경계 평활화로 인해 정상 데이터의 추론 정확도가 저하되는 트레이드오프 발생 | 무작위 평활화(Randomized Smoothing) 기법 및 다중 모델 앙상블 투표 방식을 도입하여 적대적 견고성과 표준 추론 정확도의 균형 확보 |
| 생성형 AI(LLM) 환경에서 RAG 및 외부 도구 결합 시 시스템 프롬프트 우회 및 간접 프롬프트 인젝션을 완벽히 필터링 불가능 | 입력/출력 듀얼 가드레일(NeMo Guardrails 등) 배치와 실행 계층 격리(gVisor 샌드박스)를 결합한 심층 방어 아키텍처 구축 |
| 오픈소스 허깅페이스(Hugging Face) 등 외부 모델 다운로드 시 악의적 임베디드 코드(Pickle 직렬화 취약점) 탐지 한계 | 바이트코드 정적 분석 도구 도입, Safetensors 파일 포맷 강제 변환 및 공급망 아티팩트 암호화 서명 검증 파이프라인 수립 |

## Ⅵ. 제언

```text
[ 기존 사후 보안 ]                     [ MLSecOps 기반 내재적 AI 보안 ]
완성된 모델에 방화벽 ──┐               ┌── 데이터 수집 단계 무결성 검증
단순 텍스트 필터링 ──┼─→ [ 모델 탈취 ] ─┼── 훈련 단계 적대적 강인화(Adversarial)
운영 중 취약점 노출 ──┘               └── 런타임 가드레일 및 TEE 기밀 컴퓨팅
```

| 평가 영역 | 외곽 방어 중심 체계 | AI 내재적 보안 체계 | 향후 발전 방향 |
|---|---|---|---|
| 모델 견고성 | 적대적 예제에 무방비 | 수학적 강인성 보장 | 양자 내성 암호 기반 연합학습(FL) 결합 |
| 프라이버시 보호 | 비식별화 단순 적용 | 차분 프라이버시 적용 | 동형암호(HE) 기반 암호화 상태 추론 |
| 공급망 안전성 | 모델 출처 신뢰 의존 | 소프트웨어 자재명세서(AIBOM) | AI 모델 무결성 블록체인 검증 연계 |

AI 보안은 시스템의 기술적 결함을 막는 것을 넘어 인공지능이 도출하는 결과물의 사회적 안전성과 비즈니스 신뢰성을 담보하는 필수 기반이며, 전주기 MLSecOps와 글로벌 AI 거버넌스 표준 준수 병행 필수.

- NIST SP AI 100-2: Adversarial Machine Learning: A Taxonomy and Terminology of Attacks and Mitigations
- ISO/IEC 42001: Artificial Intelligence Management System (AIMS)
