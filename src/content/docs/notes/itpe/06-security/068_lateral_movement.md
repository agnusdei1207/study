## 답안 골격
```text
[측면 이동(Lateral Movement)] ◀━━ 머리: Ⅶ 내 의견 (단순 평면 네트워크 방어 탈피 → 마이크로세그멘테이션 및 원격 프로토콜(RDP/SSH) 엄격 격리)
 ┃
 ┣━ Ⅰ 개요 ───── 최초 침투(Initial Access)에 성공한 공격자가 최종 목표(핵심 DB/도메인 컨트롤러)에 도달하기 위해 내부 네트워크를 탐색하고 다른 시스템으로 권한을 확장하며 이동하는 기법
 ┣━ Ⅱ 특징 ───── 정상 관리 도구 악용(LotL: PsExec, WMI, PowerShell) · 자격증명 재사용(Pass-the-Hash, Kerberoasting) · 평면 네트워크 취약성 악용
 ┣━ Ⅲ 구조 ───── 내부 정찰(Recon) · 자격증명 탈취(Credential Dumping) · 원격 실행(Remote Execution) · 연결 지속성 확보
 ┣━ Ⅳ 흐름 ───── ① 최초 단말 감염 → ② LSASS 메모리에서 관리자 해시 탈취 → ③ Pass-the-Hash 기법으로 인접 서버 로그인 → ④ 최종 도메인 컨트롤러(DC) 장악
 ┣━ Ⅴ 비교 ───── 수직 이동(Privilege Escalation: 동일 시스템 내 일반 사용자 → 관리자 권한 상승) vs 수평 이동(Lateral Movement: 네트워크 내 호스트 A → 호스트 B로 확산)
 ┗━ Ⅵ 실무 ───── 로컬 관리자 비밀번호 통일(LAPS 미도입) 취약점 / SMB(445), RDP(3389) 평면 개방 / EDR의 LotL 정상 명령어 오탐 회피 대응
```
- 필수 키워드: 측면 이동 · Lateral Movement · Pass-the-Hash · LotL(Living-off-the-Land) · 마이크로세그멘테이션 · LAPS · 제로트러스트
- 배점 전략: 10점 = Ⅰ 정의 및 킬체인 내 위치 → Ⅲ 측면 이동 4단계 흐름 도식 → Ⅴ 권한 상승(수직) 대비 비교 / 25점 = Ⅰ~Ⅶ 전개, 대표 기법(Pass-the-Hash, PsExec) 메커니즘과 Ⅵ 네트워크 세그멘테이션 및 허니토큰 실무 방어 대책 집중
- 기출: 138회 3교시 5번 `IT 인프라 확장에 따른 사이버 위협(측면 이동)` → Ⅰ 정의 + Ⅲ 기법 메커니즘 + Ⅵ 차단 대책

## 한 줄 본질
- 경계선 방화벽을 뚫고 들어온 공격자가 내부의 평면적(Flat) 네트워크를 타고 최종 자산으로 번져나가는 확산 병목 → 호스트 간 통신을 차단하는 마이크로세그멘테이션과 계정 해시 재사용 방지(LAPS)를 적용해 이동 통로를 차단 → 피해를 최초 침투 단말로 격리 / 네트워크 설정 복잡도 및 운영 관리 비용 발생

## 핵심 그림
```text
[측면 이동(Lateral Movement) 킬체인과 차단 메커니즘]

 [1. 최초 침투]              [2. 내부 정찰 및 자격증명 탈취]    [3. 수평 확산]
  ┌──────────────┐           ┌──────────────┐                ┌──────────────┐
  │ 일반 직원 PC │ ──감염──> │ Mimikatz 실행│ ──Pass-the───> │ 파일 서버    │
  │ (피싱 유입)  │           │ (LSASS 덤프) │   Hash (SMB)   │ (DB 접속권한)│
  └──────────────┘           └──────────────┘                └──────┬───────┘
                                                                    │
                               [4. 최종 목표 장악]                  │
                             ┌──────────────────────┐               │ RDP 원격접속
                             │ 도메인 컨트롤러(DC)  │ <─────────────┘
                             │ (전사 랜섬웨어 배포) │
                             └──────────────────────┘
 * 차단 대책:
   1. 네트워크 마이크로세그멘테이션 (PC 간 P2P 통신 전면 차단)
   2. LAPS 적용 (모든 PC의 로컬 관리자 패스워드 개별 난수화)
```

## 핵심 용어
- Pass-the-Hash(PtH): 암호화된 비밀번호 해시값을 굳이 평문으로 크래킹하지 않고, 탈취한 해시값 그대로 NTLM 인증 프로토콜에 주입해 다른 서버에 로그인하는 공격
- Living-off-the-Land(LotL): 공격자가 별도의 악성코드 파일을 심지 않고 윈도우/리눅스에 기본 내장된 정상 관리 도구(PowerShell, WMI, certutil 등)를 이용해 탐지를 회피하며 이동하는 기법

## 핵심 통찰
- 외곽 방화벽이 아무리 두꺼워도 내부 네트워크가 '방 하나짜리 평면 원룸(Flat Network)'이라면 최초 단말 1대 감염으로 30분 만에 회사 전체가 랜섬웨어에 마비됨
- 측면 이동의 80%는 새로운 제로데이 취약점이 아니라 '로컬 관리자 계정의 비밀번호 통일'이라는 관리 부실에서 기인함 (1대의 로컬 관리자 비번이 뚫리면 모든 PC가 뚫림)
- 일반 PC와 PC끼리는 업무상 직접 통신할 일이 전혀 없음 → 스위치/방화벽 수준에서 호스트 간(P2P) 통신을 전면 차단(Private VLAN/마이크로세그멘테이션)하는 것만으로 측면 이동의 90%를 물리적으로 저지 가능

## 이웃 토픽과 구분
- 권한 상승 vs 측면 이동: 권한 상승(수직) = 단일 PC 안에서 User → SYSTEM 권한 획득 / 측면 이동(수평) = 획득한 권한을 바탕으로 옆 서버로 징검다리 건너뛰기

## 문제·원인·대책
- 사례: 일반 사원 PC 1대가 랜섬웨어에 감염된 후 사내 모든 PC와 백업 서버까지 수평 감염되어 전사 업무가 중단된 대형 침해사고
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 호스트 간 통신 허용으로 인한 랜섬웨어 전파 | 내부 네트워크의 평면적(Flat) 설계 및 세그멘테이션 부재 | 제로트러스트 마이크로세그멘테이션(단말 간 통신 차단) 적용 | 최초 감염 단말 내에서 악성코드 자가 격리 |
| 메모리 덤프를 통한 관리자 NTLM 해시 탈취 및 재사용 | LAPS 미적용으로 모든 단말의 로컬 관리자 패스워드 동일 | 윈도우 LAPS(로컬관리자 비밀번호 자동 무작위화) 및 Credential Guard 강제 | 탈취된 해시를 통한 타 시스템 로그인 원천 차단 |

## 이렇게 출제된다
- 제138회 3교시 5번: "IT 인프라 확장에 따른 사이버 위협에 대하여 다음 내용을 설명하시오." → 요구 포인트: Ⅰ 측면 이동의 개념 + Ⅲ 공격 기법(Pass-the-Hash, LotL) + Ⅵ 실무 방어 아키텍처(세그멘테이션, LAPS)

## 내 의견
- [경계 기반 방어의 한계를 인정한 제로트러스트 전환] "내부망은 안전하다"는 낡은 신뢰 모델을 버리지 못해 내부망 침투 시 무방비로 당하는 구조적 결함 상존 → 나라면: 사내 모든 단말에 엔드포인트 격리 정책을 적용하여 직원 PC 간 SMB(445), RDP(3389) 포트 직접 접속을 전면 차단하고, 서버 접속은 반드시 세션 녹화 기능이 있는 중앙 배스천 호스트(Bastion Host)를 경유하도록 강제
