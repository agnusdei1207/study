## 30초 인출

- **본질:** 해시 알고리즘은 메시지를 고정 길이 다이제스트로 변환하는 암호 알고리즘이다.
- **메커니즘:** SHA-2는 반복 압축 구조를, SHA-3는 Keccak 순열 기반 구조를 사용한다. 출력 길이와 보안 용도는 알고리즘별로 다르다.
- **선택:** 새 설계는 승인된 SHA-2·SHA-3 계열 중 상호운용성과 용도를 고려해 고르고, 충돌 저항이 필요한 신규 용도에는 MD5·SHA-1을 사용하지 않는다.

<summary>핵심 용어</summary>

- **해시 알고리즘**: 가변 길이 메시지를 고정 길이 다이제스트로 바꾸는 알고리즘이다.
- **SHA-2**: SHA-224·256·384·512 등 FIPS 180 계열의 해시 알고리즘군이다.

## 2~4교시 25점 답안

## Ⅰ. 해시 알고리즘의 역할

| 구분 | 내용 |
|---|---|
| 정의 | **해시 알고리즘**은 임의 길이 입력을 고정 길이 다이제스트로 변환하는 암호학적 함수 |
| 목적 | 무결성 검증과 전자서명·HMAC 등의 기반 제공 |

해시 알고리즘은 입력을 고정 길이 다이제스트로 요약해 무결성 비교·전자서명 등 다른 보안구성에 제공한다. 해시 알고리즘 자체는 메시지의 출처인증이나 기밀성을 제공하지 않는다.

| 이용 목적 | 결합 방식 |
|---|---|
| 데이터 무결성 비교 | 신뢰할 수 있는 경로로 전달된 기준 다이제스트와 비교 |
| 메시지 인증 | HMAC처럼 비밀키와 해시를 결합 |
| 전자서명 | 표준 서명 절차의 다이제스트 입력으로 사용 |
| 비밀번호 검증 | 범용 해시 대신 전용 비밀번호 KDF 사용 |

## Ⅱ. 안전성 평가 기준

해시 선택은 충돌·역상 공격의 목표, 출력 길이, 적용 표준과 프로토콜 요구사항을 함께 고려한다. 충돌 탐색의 일반적 비용은 출력 길이보다 낮을 수 있어 출력 길이만으로 안전성을 단정하면 안 된다.

```text
해시 알고리즘 선택 기준
  ├─ 출력 길이·용도
  ├─ 역상 저항성·충돌 저항성
  └─ 표준 승인·상호운용성
           ↓
     용도별 보안강도 판단
```

## Ⅲ. SHA-2와 SHA-3 계열 비교

NIST는 FIPS 180-4에서 SHA-1과 SHA-2 계열을, FIPS 202에서 SHA-3와 SHAKE 계열을 규정한다. SHA-2와 SHA-3는 내부 구조가 다르며, 단순히 한 계열이 모든 환경에서 다른 계열보다 우수하다고 일반화하지 않는다.

| 비교 기준 | SHA-2 | SHA-3 |
|---|---|---|
| 표준 | FIPS 180-4 | FIPS 202 |
| 대표 구조 | 반복 압축 기반 Merkle–Damgård 계열 | Keccak 순열 기반 sponge 구조 |
| 출력 선택 | SHA-224·256·384·512 등 | SHA3-224·256·384·512, SHAKE XOF |
| 선택 고려 | 기존 프로토콜·구현·호환성 | 별도 구조 선택지, XOF는 출력 길이·사용 규칙 확인 |

## Ⅳ. 레거시 알고리즘과 용도별 적용

MD5와 SHA-1은 충돌 공격이 실증되어 충돌 저항이 중요한 신규 보안 용도로 적절하지 않다. NIST는 SHA-1 사용을 제한된 범위로 전환하는 정책을 안내하며, 관련 표준의 개정도 진행 중이므로 적용 시 현행 지침을 확인해야 한다.

| 알고리즘·구성 | 적용 판단 |
|---|---|
| SHA-256 등 SHA-2 | 요구 표준과 보안강도에 맞으면 일반 해시 용도 후보 |
| SHA3-256 등 SHA-3 | 호환성과 구현 환경을 확인해 선택 가능한 대안 |
| MD5·SHA-1 | 신규 충돌 민감 보안 용도에는 사용하지 않고 레거시를 식별·전환 |
| PBKDF2 등 비밀번호 KDF | 비밀번호 검증 저장에 별도 salt·비용 설정 적용 |

## Ⅴ. 기술사적 제언

| 한계 | 대응 |
|---|---|
| 레거시 다이제스트를 쓰는 시스템은 상호운용성 때문에 한 번에 바꾸기 어려워 취약한 검증 경로가 장기간 남을 수 있다. | 먼저 서명·패키지 검증 등 보안 영향이 큰 사용처부터 의존 서비스를 식별하고, 새 알고리즘 검증·호환 시험을 거쳐 전환한 뒤 구 알고리즘 검증을 종료한다. |
