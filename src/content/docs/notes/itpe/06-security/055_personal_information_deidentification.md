## 답안 골격
```text
[개인정보 비식별화] ◀━━ 머리: Ⅶ 내 의견 (단순 식별자 마스킹 탈피 → k-익명성 정량 모델 검증 및 재식별 위험 적응형 모니터링)
 ┃
 ┣━ Ⅰ 개요 ───── 빅데이터·AI 분석을 위한 데이터 활용 요구와 개인정보 침해 위험 간 상충 → 특정 개인을 알아볼 수 없도록 변환하는 기술적·관리적 조치
 ┣━ Ⅱ 특징 ───── 비가역성(익명화) vs 가역성(가명화) · 프라이버시 보호 모델 적용 · 유용성(Utility)과 프라이버시의 트레이드오프
 ┣━ Ⅲ 구조 ───── 비식별 조치 5대 기법(가명처리, 총계처리, 데이터 삭제, 데이터 범주화, 데이터 마스킹) · 프라이버시 모델(k, l, t)
 ┣━ Ⅳ 흐름 ───── ① 사전 검토(개인정보 여부) → ② 비식별 조치(기법 적용) → ③ 적정성 평가(k-익명성 등 정량 평가) → ④ 사후 관리
 ┣━ Ⅴ 비교 ───── 식별정보(실명) vs 가명정보(추가정보 결합 시 식별 가능, 통계/연구 활용) vs 익명정보(시간·비용 투입해도 복원 불가, 규제 제외)
 ┗━ Ⅵ 실무 ───── 연결 공격(Linking Attack)을 통한 재식별 위험 / 과도한 비식별화로 인한 데이터 분석 가치 훼손 / 비정형 데이터 비식별화 난제
```
- 필수 키워드: 개인정보 비식별화 · 비식별 조치 가이드라인 · 가명정보 · 익명정보 · k-익명성 · l-다양성 · t-근접성 · 차분 프라이버시
- 배점 전략: 10점 = Ⅰ 정의 및 4단계 절차 → Ⅲ 5대 기법 및 k-익명성 모델 도식 → Ⅴ 가명 vs 익명 비교 / 25점 = Ⅰ~Ⅶ 전개, 프라이버시 모델 3종(k, l, t)의 한계 극복 수학적 원리와 Ⅵ 실무 적정성 평가 방안 집중
- 기출: KPC 120회 `개인정보 비식별 조치 가이드라인 및 프라이버시 보호 모델` → Ⅲ 5대 기법 + 프라이버시 모델(k, l, t) + Ⅳ 적정성 평가 절차

## 한 줄 본질
- 개인 식별성으로 인한 데이터 결합·활용의 법적 규제 병목 → 데이터 변환 기법과 수학적 프라이버시 모델(k/l/t)을 적용해 개인 특정성을 제거 → 데이터 가치 창출 / 원본 정밀도 손실 및 결합 재식별 위험 관리 비용 발생

## 핵심 그림
```text
[개인정보 비식별화 4단계 절차 및 프라이버시 보호 모델]

 [1단계: 사전 검토]  ──>  [2단계: 비식별 조치] ──> [3단계: 적정성 평가] ──> [4단계: 사후 관리]
  - 식별자 / 준식별자      - 가명처리, 마스킹      - k-익명성 검증         - 재식별 모니터링
    분류 정의                범주화, 총계처리        l-다양성 / t-근접성     접근 권한 통제

 [정량적 프라이버시 보호 모델 체계]
  1. k-익명성 (k-Anonymity): 동일한 준식별자 속성 조합을 가진 레코드가 최소 k개 이상 존재
  2. l-다양성 (l-Diversity): 각 동질 집합 내 민감 속성이 최소 l개 이상의 다양한 값을 가짐
  3. t-근접성 (t-Closeness): 집합 내 민감 속성의 분포가 전체 데이터 분포와 t 이하의 거리를 유지
```

## 핵심 용어
- 준식별자(Quasi-Identifier): 단독으로는 개인을 식별할 수 없으나, 타 정보와 결합 시 개인을 특정할 수 있는 속성(예: 나이, 성별, 우편번호)
- k-익명성(k-Anonymity): 공개된 데이터셋에서 동일한 준식별자 값을 갖는 레코드가 최소 k개 이상 존재하도록 하여 특정인을 확률 1/k 이하로 은폐하는 기법

## 핵심 통찰
- 단순히 이름과 주민번호만 지우거나 별표(*) 처리하는 마스킹은 비식별화가 아님 → 외부 유출 데이터셋과 나이, 성별, 거주지를 조인하는 순간 개인 식별 가능(연결 공격)
- k-익명성을 달성해도 동질 집합 내 모든 환자의 병명이 '암'이면 특정인의 질병을 바로 알 수 있음(동질성 공격) → 이를 보완하는 l-다양성과 왜곡 공격을 막는 t-근접성까지 검증해야 안전함
- 비식별화 강도를 무한정 높이면 데이터의 통계적 왜곡이 심해져 AI 학습용으로 쓸모가 없어짐 → 유용성(Utility)과 프라이버시(Privacy) 사이의 최적 절충점 도출이 핵심

## 이웃 토픽과 구분
- 가명처리 vs 익명처리: 가명처리 = 추가 정보 없이는 식별 불가(법적 개인정보 포함) / 익명처리 = 다른 정보와 결합해도 복원 불가능(개인정보보호법 적용 배제)

## 문제·원인·대책
- 사례: 병원 진료 데이터에서 이름을 마스킹했으나, 환자의 우편번호와 생년월일을 투표인 명부와 결합해 유명 인사의 질병 정보가 특정된 사건
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 준식별자 결합에 의한 연결 공격(Linking Attack) | 단순 마스킹만 적용하고 준식별자 결합 위험성 미고려 | 데이터 범주화(연령대, 시·군 단위 주소)를 통한 k-익명성(k>=5) 강제 | 외부 데이터 결합 시에도 개인 특정 차단 |
| 과도한 잡음 추가로 인한 AI 분석 정밀도 저하 | 일률적인 노이즈 주입 및 데이터 절단 | 차분 프라이버시(Differential Privacy) 기반 수학적 프라이버시 예산(Epsilon) 최적화 | 개인정보 보호 수준과 모델 분석 정확도 양립 |

## 이렇게 출제된다
- 제120회 기출: "개인정보 비식별화 기법과 프라이버시 보호 모델(k-익명성, l-다양성, t-근접성)에 대하여 설명하시오." → 요구 포인트: Ⅰ 비식별 조치 개념 + Ⅲ 5대 기법 및 프라이버시 모델 상세 + Ⅵ 적정성 평가 절차

## 내 의견
- [적정성 평가의 형식적 위원회 승인 관행] 외부 전문가 몇 명이 모여 정성적 서류 검토로 적정성을 판정하고 사후 데이터 결합 위험을 방치하는 문제 존재 → 나라면: 오픈소스 비식별화 엔진(ARX 등)을 데이터 파이프라인에 탑재하여 데이터 적재 시 자동으로 k-익명성 수치를 실시간 계산하고, 외부 위협 인텔리전스와 연계하여 신규 데이터 결합 위험도를 상시 평가하는 '동적 비식별 거버넌스' 도입

## 찾아볼 것
