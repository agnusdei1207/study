## 지식 로드맵 내 현재 위치

개인정보 보호 → 데이터 활용과 식별 위험 → 가명·익명정보 비식별화(De-identification)

## 30초 인출

- **본질:** 데이터의 통계적·비즈니스적 유용성을 보존하면서 특정 개인을 알아볼 수 없도록 식별자 및 준식별자를 변환·가명화하고 재식별 위험을 차단하는 기술적 조치
- **메커니즘:** 사전 준비 및 위험도 평가 → 비식별 기술 적용(가명화/범주화/마스킹 등) → 적정성 검토(k-익명성, l-다양성, t-근접성) → 추가정보 분리 보관 및 안전조치
- 통찰: 단순 가명처리에 그치지 않고 외부 데이터와의 연계 결합에 따른 재식별 위험을 차단하기 위해 추가정보의 물리적·논리적 완전 분리 보관과 위험도 기반 적정성 평가의 동적 피드백 루프 확립 필수

<details><summary>핵심 용어</summary>

- **비식별화(De-identification):** 데이터 집합에서 특정 개인을 식별할 수 없도록 직·간접 식별 요소를 변환·삭제하는 기술적 처리 과정의 총칭.
- **가명정보(Pseudonymized Data):** 추가정보 없이는 특정 개인을 알아볼 수 없도록 처리된 정보(개인정보 보호법상 개인정보 지위 유지).
- **익명정보(Anonymized Data):** 시간·비용·기술을 합리적으로 고려해도 더 이상 특정 개인을 알아볼 수 없는 정보(개인정보 보호법 적용 제외).
- **k-익명성(k-Anonymity):** 동일한 준식별자 값을 갖는 레코드가 최소 k개 이상 존재하도록 하여 특정인을 1/k 이하의 확률로만 식별되게 하는 모델.
- **l-다양성(l-Diversity):** 동질 집단 내 민감 정보(Sensitive Attribute)의 종류가 최소 l개 이상 다양하게 분포하도록 보장하는 모델.
- **t-근접성(t-Closeness):** 동질 집단 내 민감 정보의 분포가 전체 데이터 집합의 민감 정보 분포와 거리 t 이하로 유지되도록 하는 모델.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 데이터 세트 내의 직접 식별자(이름, 주민번호 등)와 준식별자(나이, 주소, 성별 등)를 삭제, 대체, 범주화하여 추가 정보 없이는 특정 개인을 식별할 수 없도록 변환하는 기법 |
| 목적 | 데이터의 산업적·학술적 연구 활용 가치(Utility)를 극대화하면서 정보주체의 프라이버시(Privacy) 침해 및 재식별 위험 원천 차단 |

## Ⅱ. 개인정보 비식별화의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 법적 지위의 이원화 | 추가정보 결합 시 식별 가능한 '가명정보'와 영구적 식별 불가능한 '익명정보'로 구분 | 개인정보 보호법 제28조의2 |
| 유용성과 안전성의 트레이드오프 | 비식별화 강도가 높아질수록 프라이버시는 보호되나 데이터 유용성은 왜곡 저하 | 최적 파라미터(k, l, t) 설정 |
| 결합 전문기관 제도 | 서로 다른 기업 간 가명정보 결합은 정부가 지정한 전문기관을 통해서만 수행 | 데이터 결합 및 반출 심사 |
| 안전조치 의무화 | 추가정보의 별도 분리 보관, 물리적/기술적 접근통제, 재식별 시도 즉시 중단 의무 | 암호화, 파기, WORM 로그 |

## Ⅲ. 비식별화 5단계 프로세스 및 프라이버시 보호 모델

```text
[ 1. 사전 준비 ] ── 데이터 식별, 활용 목적 정의, 필수 항목 최소화
       │
       ▼
[ 2. 위험도 평가 ] ── 내부 분석 / 제3자 제공 / 결합 여부에 따른 재식별 위험도 판정
       │
       ▼
[ 3. 비식별 조치 ] ── 5대 기술 적용 (가명화, 총계처리, 데이터삭제, 범주화, 마스킹)
       │
       ▼
[ 4. 적정성 평가 ] ── 프라이버시 모델 검증 ── [ 미흡 시 ] ──▶ [ 재식별 조치 보완 ]
       │  (k-익명성, l-다양성, t-근접성 충족 여부 확인)
       ▼ [ 적정 승인 ]
[ 5. 사후 관리 ]   ── 추가정보 분리 보관, 재식별 모니터링, 안전한 반출
```

| 단계 | 주요 활동 내용 | 핵심 산출물 및 기준 |
|---|---|---|
| 1. 사전 준비 | 개인정보 처리 목적 명확화, 분석에 불필요한 속성 제거 | 식별자 목록, 비식별화 계획서 |
| 2. 위험도 평가 | 활용 환경(보안 구역 vs 외부 반출), 데이터 결합 가능성 평가 | 재식별 위험도 등급(상/중/하) |
| 3. 비식별 조치 | 식별자 삭제, 대체, 준식별자 범주화 및 잡음 추가 | 비식별화 데이터셋 |
| 4. 적정성 평가 | 전문가 위원회를 통한 k-익명성, l-다양성, t-근접성 계측 평가 | 비식별 적정성 평가 보고서 |
| 5. 사후 관리 | 매핑 테이블 암호화 분리 저장, 외부 반출 통제, 처리 기록 보관 | 접근 로그, 추가정보 관리 대장 |

## Ⅳ. 가명정보 vs 익명정보 및 프라이버시 모델 비교

### 1. 가명정보와 익명정보 비교

| 구분 | 가명정보 (Pseudonymized Data) | 익명정보 (Anonymized Data) |
|---|---|---|
| 법적 개념 | 추가정보 없이는 특정 개인을 식별할 수 없는 정보 | 합리적 수단을 고려해도 영구히 식별할 수 없는 정보 |
| 법 적용 여부 | 개인정보 보호법 전면 적용 (안전조치 의무 존재) | 개인정보 보호법 적용 전면 제외 |
| 활용 범위 | 통계 작성, 과학적 연구, 공익적 기록 보존 목적 | 제한 없음 (상업적 자유 활용 가능) |
| 복원 가능성 | 추가정보(매핑키)가 존재하면 복원 가능 | 영구 비가역적 변환으로 복원 불가능 |

### 2. 프라이버시 보호 모델 비교

| 모델 | 핵심 개념 | 방어 가능한 공격 | 한계점 |
|---|---|---|---|
| k-익명성 ($k$-Anonymity) | 준식별자 결합 속성이 동일한 레코드가 최소 $k$개 이상 존재 | 연결 공격 (Linking Attack) | 동질성 공격, 배경지식 공격 취약 |
| l-다양성 ($l$-Diversity) | 동질 집단 내 민감 정보의 종류가 최소 $l$개 이상 분산 | 동질성 공격 (Homogeneity Attack) | 왜곡 공격, 유사성 공격 취약 |
| t-근접성 ($t$-Closeness) | 동질 집단과 전체 집단의 민감 속성 분포 거리가 $t$ 이하 | 왜곡 공격, 정보 누설 공격 | 의미 정보 손실, 유용성 급감 |

## Ⅴ. 개인정보 비식별화의 한계와 방안

| 한계 | 방안 |
|---|---|
| 고차원 다속성(High-dimensional) 데이터셋의 경우 속성 간 결합으로 인해 k-익명성을 충족하기 위한 데이터 삭제/일반화가 과도하여 유용성 급감 | 실제 데이터 대신 원본의 통계적 특성을 학습하여 생성하는 생성형 합성 데이터(Synthetic Data) 기법 및 차분 프라이버시(Differential Privacy) 적용 |
| AI 머신러닝 모델 학습용 데이터셋으로 가명정보 사용 시 멤버십 추론(Membership Inference) 및 모델 역전 공격으로 원본 데이터 유출 가능 | 모델 학습 단계에 경사하강법 노이즈(DP-SGD)를 주입하고 가명정보 학습 모델의 배포 전 프라이버시 침해 모의 평가 의무화 |
| 가명정보와 추가정보(매핑 테이블)가 동일한 내부 인프라에 보관되어 내부자에 의한 자의적 재식별 위험 상존 | 추가정보를 하드웨어 보안 모듈(HSM)에 암호화하여 물리적·논리적으로 분리 보관하고 접근 시 2인 결재 및 WORM 스토리지 감사 로깅 강제 |

## Ⅵ. 제언

```text
[ 기존 단순 마스킹 ]                 [ 차세대 복합 비식별 거버넌스 ]
단순 식별자 삭제 ────┐               ┌── 위험도 기반 동적 k-l-t 프라이버시 모델
데이터 유용성 훼손 ─┼─→ [ 재식별 취약 ] ─┼── 생성형 AI 기반 안전한 합성 데이터(Synthetic)
추가정보 관리 소홀 ──┘               └── 차분 프라이버시(DP) 결합 암호화 연동
```

| 평가 영역 | 1세대 비식별 체계 | 현대적 비식별 체계 | 향후 발전 방향 |
|---|---|---|---|
| 기술 모델 | 단순 마스킹 및 노이즈 | k-익명성, l-다양성, t-근접성 | 차분 프라이버시(DP) 수학적 보증 |
| 데이터 형태 | 정형 테이블 중심 | 정형·비정형(텍스트, 이미지) | 멀티모달 프라이버시 보호 모델 |
| 결합 안전성 | 단순 내부 결합 | 법정 데이터 결합 전문기관 | 동형암호(HE) 기반 비노출 데이터 결합 |

개인정보 비식별화는 데이터 주권 보호와 데이터 경제 활성화라는 양립적 가치를 조화시키는 핵심 기술이며, 향후 합성 데이터 및 차분 프라이버시와 결합하여 안전성을 수학적으로 보증하는 방향으로 고도화 필수.

## 출제 이력과 검증 출처

- 정보관리기술사 제130회 2교시 (가명정보 처리 및 프라이버시 보호 모델)
- 정보관리기술사 제124회 1교시 (k-익명성, l-다양성, t-근접성)
- 개인정보 보호법 및 동법 시행령 (가명정보의 처리에 관한 특례)
- 개인정보보호위원회 가명정보 처리 가이드라인 전면 개정판
- ISO/IEC 20889: Privacy enhancing data de-identification techniques
