## Ⅰ. Tor와 어니언 라우팅의 개요

- **개념** : 전 세계 자원봉사자들이 운영하는 분산 릴레이 네트워크를 통해 트래픽을 다중 암호화하고 무작위 경로로 우회시켜, 통신 참여자의 실제 IP 주소와 통신 내용을 완벽히 은닉하는 오버레이 익명 통신 네트워크.
- **배경 및 필요성** : 인터넷상의 감시, 검열, 도청으로부터 개인의 프라이버시를 보호하기 위해 미국 해군 연구소(NRL)의 어니언 라우팅(Onion Routing) 연구를 모태로 개발되었으며, 언론인, 내부고발자, 프라이버시 옹호자들의 필수 통신 수단으로 정착함.
- **핵심 목적** : 네트워크 트래픽 분석(Traffic Analysis) 공격을 무력화하여 발신지와 목적지 간의 상관관계를 차단하고, 익명 웹 브라우징 및 검열 우회 환경 제공.

## Ⅱ. Tor와 어니언 라우팅의 핵심 아키텍처 및 동작 메커니즘

Tor는 어니언 프록시(OP), 가드 노드(Guard/Entry), 미들 릴레이(Middle), 엑시트 노드(Exit)의 3계층 서킷(Circuit) 구조로 동작하며, 겹겹이 포장된 암호문을 양파 껍질 벗기듯 순차 복호화함.

```text
[ Tor 어니언 라우팅 암호화 래핑 및 서킷 패킷 전달 메커니즘 ]

 [사용자 (Tor 클라이언트)]
   * 서킷 구성: Entry(K_E), Middle(K_M), Exit(K_X) 대칭키 사전 협상
   * 3중 암호화: E_KE( E_KM( E_KX( 평문 메시지 ) ) )
         |
         | (1) Entry 암호문 전송
         v
 +-----------------------+
 | 가드 노드 (Entry)     | : K_E로 최외곽 껍질 복호화
 | - 발신자 실제 IP 파악 |   -> 다음 홉(Middle IP)만 확인 가능
 | - 메시지 내용 모름    |
 +-----------+-----------+
             | (2) 2중 암호문 전송
             v
 +-----------------------+
 | 미들 릴레이 (Middle)  | : K_M으로 중간 껍질 복호화
 | - 이전(Entry)/다음 노드만 인지
 | - 발신자/최종 목적지 모름
 +-----------+-----------+
             | (3) 1중 암호문 전송
             v
 +-----------------------+
 | 출구 노드 (Exit Node) | : K_X로 최종 껍질 복호화
 | - 최종 목적지 서버 IP 인지
 | - 발신자 IP 절대 모름 |
 +-----------+-----------+
             | (4) 평문 or TLS 패킷 전달
             v
 [최종 목적지 웹 서버 (인터넷)]
```

- **계층 암호화(Onion Encryption)** : 클라이언트는 서킷 상의 각 노드 공개키를 이용해 디피-헬만(Diffie-Hellman) 키 교환을 수행하고, 패킷을 역순으로 3중 암호화하여 전송.
- **서킷(Circuit) 주기적 재구성** : 통신 경로의 추적을 방지하기 위해 통상 10분 주기로 노드 조합(서킷)을 자동 파기하고 새로운 경로를 동적 수립.
- **디렉터리 서버(Directory Authority)** : 네트워크 전체 릴레이 노드의 상태, 대역폭, 가동률, 공개키 정보를 합의(Consensus) 문서를 통해 클라이언트에 안전하게 배포.
- **히든 서비스(Hidden Services, .onion)** : 서버의 실제 IP와 위치까지 완벽히 숨긴 채 랑데부 포인트(Rendezvous Point)와 소개 노드(Introduction Point)를 통해 상호 익명 접속 지원.

## Ⅲ. Tor와 어니언 라우팅의 세부 구성 요소 및 비교 분석

| 비교 항목 | Tor (The Onion Router) | 상용 VPN (Virtual Private Network) | I2P (Invisible Internet Project) |
| --- | --- | --- | --- |
| 네트워크 구조 | 자원봉사자 기반 분산 3-hop 오버레이 | 중앙 집중형 상용 서버 단일 홉 터널 | P2P 기반 분산 갈릭 라우팅(Garlic) |
| 신뢰 모델 | 어떤 단일 노드도 전체 경로를 모름 | VPN 서비스 제공자를 전적으로 신뢰해야 함 | 완전한 P2P 분산 신뢰 모델 |
| 속도/지연 | 다중 홉 경유 및 암호화로 인해 매우 느림 | 고속 대역폭 보장 (스트리밍 가능) | P2P 트래픽 기반으로 속도 가변적 |
| 주요 목적 | 일반 인터넷 웹서핑 시 발신자 익명화 | 단순 IP 우회 및 공용 Wi-Fi 패킷 암호화 | 내부 폐쇄망(Darknet) 서비스 통신 최적화 |
| 취약 공격 | 트래픽 상관관계 분석, 출구 노드 도청 | VPN 사업자의 로그 보관 및 정부 제출 | Sybil 공격 및 이클립스(Eclipse) 공격 |

- Tor는 이론적으로 강력한 익명성을 보장하지만, 출구 노드에서의 평문 도청 위험과 통계적 트래픽 분석 공격이라는 구조적 한계를 내포함.

## Ⅳ. Tor와 어니언 라우팅의 주요 한계점 및 해결 방안

- **출구 노드(Exit Node)에서의 패킷 스니핑 및 조작 취약점** :
  - **한계점** : 마지막 어니언 껍질이 벗겨진 후 출구 노드에서 대상 서버로 향하는 구간이 HTTP 평문일 경우, 악의적인 엑시트 노드 운영자가 자격증명 및 쿠키를 가로채거나 악성코드 주입 가능.
  - **해결 방안** : Tor 브라우저 내 'HTTPS-Everywhere' 강제화, 엔드-투-엔드 TLS 암호화 검증, 안전한 .onion 히든 서비스 사용 권장.
- **엔드-투-엔드 타이밍 및 패킷 크기 상관관계 공격(Traffic Correlation Attack)** :
  - **한계점** : 글로벌 도청 능력을 가진 국가 차원의 공격자(NSA 등)가 Entry 진입 트래픽과 Exit 유출 트래픽의 패킷 타이밍, 버스트 패턴을 통계적으로 대조하여 발신자 역추적 가능.
  - **해결 방안** : 고정 크기 셀(512바이트) 강제, 더미 트래픽 패딩(Padding) 주입, 패킷 전송 간격 무작위 지연(Jitter) 알고리즘 적용.
- **다크웹 범죄 악용 및 사이버 위협 배후 인프라화** :
  - **한계점** : 랜섬웨어 C2 서버 은닉, 불법 자금 세탁, 마약 및 무기 거래 등 사이버 범죄의 은폐 수단으로 악용되어 각국 사법기관의 집중 차단 대상화.
  - **해결 방안** : 비정상 출구 노드 평판(IP Reputation) DB 기반 실시간 모니터링, 포렌식 수사 협조를 위한 진입/출구 상관성 빅데이터 분석 프레임워크 연구.

## Ⅴ. Tor와 어니언 라우팅 적용 및 발전을 위한 기술사적 제언

- **가드 노드 고정 정책(Entry Guards) 유지 및 강화** : 사용자가 매번 임의의 Entry 노드를 선택할 경우 장기적으로 악의적 노드에 걸릴 확률이 높아지므로, 신뢰도 높은 소수의 Guard 노드를 장기 고정하여 Sybil 공격 방어.
- **검열 우회를 위한 플러거블 트랜스포트(Pluggable Transports) 고도화** : 정부 검열 방화벽이 Tor 시그니처를 패킷 단위로 차단하지 못하도록 obfs4, Snowflake 등 트래픽 난독화 기술 지속 업데이트.
- **기업 내부 네트워크의 비인가 Tor 접속 통제 정책 확립** : 사내 기밀 유출 방지를 위해 차세대 방화벽(NGFW)의 App-ID 필터링을 통해 Tor 핸드셰이크 시그니처 및 디렉터리 IP 목록을 원천 차단.
