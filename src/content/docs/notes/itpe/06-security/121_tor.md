## 지식 로드맵 내 현재 위치

지식 위치: 프라이버시 네트워크 → 다중 릴레이 경로 → **Tor**

## 30초 인출

- 본질: 사용자의 트래픽을 여러 릴레이로 분산하고 구간별 암호화 계층을 적용해 단일 관측자가 출발지와 목적지를 동시에 파악하기 어렵게 하는 네트워크
- 메커니즘: 클라이언트가 구간별 암호화 회로를 통해 Guard → Middle → Exit → 일반 웹 목적지에 연결
- 통찰: 한계: 출발·도착 경로 상관이나 Exit 이후 평문은 Tor만으로 막을 수 없음 → 방안: 계정·브라우저 식별을 줄이고 목적지 TLS를 확인

- **Tor** : 다중 릴레이와 계층별 암호화로 통신 경로의 연결을 어렵게 하는 네트워크.
- **Guard·Middle·Exit** : 각각 출발지 연결, 중간 중계, 일반 웹 목적지 연결을 맡는 릴레이.
- **어니언 서비스** : 일반 Exit 경로 없이 Tor 네트워크 안에서 서비스에 접속하는 방식.
- **트래픽 상관** : 출발·도착 측 관측치를 시간·크기 등으로 대조해 통신 관계를 추정하는 공격.

## 2~4교시 예상문제 (25점)

> Tor의 어니언 라우팅 구조와 경로 선택·암호화 원리를 설명하고, 익명성의 범위와 운영상 위험을 분석하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

| 항목 | 개요 |
|---|---|
| 정의 | Tor는 다중 릴레이와 계층별 암호화로 통신 경로의 연결을 어렵게 하는 네트워크 |
| 목적 | 출발지와 목적지의 연관성 노출을 줄여 사용자 프라이버시 강화 |

Tor는 프라이버시를 높이기 위해 다중 릴레이와 계층적 암호화를 사용하는 네트워크. 완전한 익명성이나 모든 경로에서 종단간 암호화를 자동 보장하는 서비스는 아님.

### Ⅱ. 릴레이별 역할

| 위치 | 아는 정보 | 고려 |
|---|---|---|
| Guard | 사용자 IP와 다음 릴레이 | 안정적 경로 선택으로 상관 위험 감소 |
| Middle | 앞뒤 릴레이 | 사용자·최종 목적지 동시 파악 제한 |
| Exit | 목적지와 이전 릴레이 | Exit 이후 통신에 HTTPS 등 별도 보호 필요 |

```text
클라이언트: 릴레이별 암호화 계층 생성
Guard: 바깥 계층 제거 → Middle: 다음 계층 제거
Exit: 목적지로 전달 → 목적지 응답은 역경로
```

### Ⅲ. 목적지 유형 구분

| 유형 | 경로 |
|---|---|
| 일반 웹 서비스 | Tor Exit를 거쳐 공개 인터넷으로 연결 |
| Onion service | Tor 네트워크 내부의 별도 서비스 연결 구조; 일반 Exit 경로와 다름 |

#### 공격·한계

| 위험 | 설명·대응 |
|---|---|
| 양 끝단 관측 | 시간·크기 상관 가능; 절대 익명성 주장 금지 |
| Exit 이후 평문 | HTTPS 등 응용 계층 암호화 사용 |
| 브라우저 지문·계정 로그인 | 사용자 행동과 애플리케이션 설정 관리 |
| 악성 활동의 Tor 악용 | 조직은 정책·법적 목적에 맞게 탐지·조사; Tor 사용 자체를 공격 확정 신호로 오인 금지 |

'대다수 C2가 Tor를 사용한다' 같은 근거 없는 비율은 제외. Tor는 언론·연구·검열 회피 등 합법적 목적에도 사용.

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| Tor만으로 출발·도착 경로 상관과 Exit 이후 평문을 막지 못함 | 계정·브라우저 식별을 줄이고 목적지 TLS와 위협 모델 확인 |

### Ⅴ. 제언

익명성 목표와 공격자 관측 능력을 먼저 명시하고, 사용자 행태·HTTPS·엔드포인트 보호를 Tor 경로 설계와 함께 검토.
