## Ⅰ. GADI(Global Architecture for Digital Identity)의 개요

- 개념 : 전 세계적으로 상이한 국가, 플랫폼, 기관의 디지털 신원 시스템 간 상호운용성(Interoperability)을 보장하고, 사용자 스스로 자신의 신원 데이터를 소유·통제할 수 있도록 분산 원장(DID)과 개방형 표준 프로토콜을 융합한 글로벌 분산 디지털 신원 아키텍처.
- 배경 및 필요성 : 구글, 애플 등 빅테크 중심의 중앙집중형 연합 신원(SAML, OAuth)은 개인정보 독점 및 대규모 프라이버시 침해 위험을 초래하고, 국경을 넘는 다국적 서비스 이용 시 신원 확인 절차가 파편화되어 막대한 비용 발생.
- 핵심 목적 : 국가나 특정 기업에 종속되지 않는 탈중앙화 자기주권신원(SSI)을 글로벌 단위로 실현하고, 최소 정보 공개(Selective Disclosure)를 통해 프라이버시를 완벽히 보호.

## Ⅱ. GADI(Global Architecture for Digital Identity)의 핵심 아키텍처 및 동작 메커니즘

GADI는 W3C 탈중앙 식별자(DID)와 검증 가능한 자격증명(VC) 표준을 확장하며, 발행자, 보유자, 검증자, 신뢰 분산 레지스트리의 4자 모델과 신뢰 오버 IP(Trust Over IP: ToIP) 프레임워크를 기반으로 동작함.

```text
[ GADI 글로벌 디지털 신원 아키텍처 및 4자 신뢰 상호작용 ]

 +--------------------------------------------------------------------------+
 |                 신뢰 분산 레지스트리 (Trust Registry / Blockchain)        |
 | - DID Document 등록 (공개키, 서비스 엔드포인트)                          |
 | - 발급 기관(Issuer)의 공인 자격 상태 및 폐기 목록(Revocation Registry)   |
 +---------------------+------------------------------+--------------------+
                       ^                              ^
                       | (1) DID/공개키 등록          | (4) 공개키/폐기여부 조회
                       |                              |
 +---------------------+--------+            +--------+--------------------+
 | 발급자 (Issuer)              |            | 검증자 (Verifier / RP)      |
 | - 정부(여권), 대학(학위), 은행|            | - 출입국관리소, 글로벌 플랫폼|
 +--------------+---------------+            +----------------+------------+
                |                                             ^
                | (2) 영지식 증명(ZKP) 서명                   | (3) 검증 가능한 프레젠테이션
                |     VC(검증가능 자격증명) 발급              |     (VP) 제출 (선택적 공개)
                v                                             |
 +------------------------------------------------------------+------------+
 |                      보유자 (Holder: 모바일 기기 신원 지갑)                |
 |  * 사용자의 모바일 신원 지갑 (Edge Identity Wallet)                     |
 |  * 개인키를 디바이스 TEE에 안전 보관                                     |
 |  * "20세 이상 성인인가?" -> "예"라는 영지식 증명만 생성하여 검증자에 전송! |
 +-------------------------------------------------------------------------+
```

- **탈중앙 식별자(DID: Decentralized Identifier)** : 중앙 기관의 발급 없이 사용자가 수학적 암호키 쌍을 기반으로 임의로 생성하는 고유 식별자(did:method:string).
- **검증 가능한 자격증명(VC)과 프레젠테이션(VP)** : 발행자의 전자서명이 포함된 자격 데이터(VC)를 보유자가 수신하고, 검증자에게 필요한 정보만 선택적으로 가공하여 제출하는 VP(Verifiable Presentation).
- **영지식 증명(ZKP) 기반 선택적 속성 공개** : 생년월일, 주민번호 등 원시 데이터를 직접 노출하지 않고 '특정 조건(예: 19세 이상 성인 여부)을 만족함'만을 수학적으로 증명하여 프라이버시 침해 원천 차단.
- **신뢰 오버 IP(ToIP) 프레임워크 준수** : 인간 및 조직 간의 거버넌스 신뢰(Layer 1~4)와 기술적 유틸리티/통신 프로토콜 신뢰를 결합한 통합 계층 모델 적용.

## Ⅲ. GADI(Global Architecture for Digital Identity)의 세부 구성 요소 및 비교 분석

| 비교 항목 | **GADI** (글로벌 분산 디지털 신원) | **중앙집중형 연합 신원** (OAuth/SAML) | **공인 인증 체계** (전통적 PKI) |
| --- | --- | --- | --- |
| 신원 제어권 | 개인 사용자 (자기주권신원: SSI) | 빅테크 플랫폼 (Google, Apple, Meta) | 국가 공인 인증기관 (CA) |
| 단일 실패점 | 없음 (분산 원장 및 P2P 상호작용) | 존재 (중앙 IdP 침해 시 전 서비스 유출) | 존재 (루트 CA 해킹 시 인증 붕괴) |
| 프라이버시 | 극상 (선택적 정보 공개, 영지식 증명) | 취약 (플랫폼이 사용자의 모든 방문지 추적) | 보통 (인증서 내에 개인 식별 정보 노출) |
| 상호운용성 | 글로벌 개방형 표준 (W3C DID, VC) | 플랫폼 종속적 API 매핑 필요 | 국가별/인증기관별 독자 규격 분립 |
| 신원 복구 | 소셜 복구, 분산 시드 복구 체계 | 이메일/SMS 기반 중앙 계정 복구 | 인증기관 오프라인 대면 재발급 |

- GADI는 전 세계 어디서나 통용되는 디지털 여권이자 프라이버시 친화적 분산 신원망으로, 미래 웹3(Web3) 및 초연결 스마트 시티의 핵심 신뢰 계층임.

## Ⅳ. GADI(Global Architecture for Digital Identity)의 주요 한계점 및 해결 방안

- 이종 블록체인 및 DID 메서드(did:indy, did:ion 등) 간 상호운용성 결여 :
  - 한계점 : 전 세계적으로 수십 개 이상의 DID 메서드가 난립하여 서로 다른 원장 간 자격증명 검증 시 데이터 변환 및 브릿지 오버헤드 심각.
  - 해결 방안 : W3C DID Core 1.0 표준 및 DIDComm v2 메시징 프로토콜 강제화, 범용 리졸버(Universal Resolver) 단일 표준화.
- 사용자 모바일 디바이스 분실 시 개인키 복구 난제 :
  - 한계점 : 중앙 관리 서버가 없으므로 스마트폰 파손이나 분실 시 개인키가 영구 유실되어 디지털 신원이 영구 고아화될 위험.
  - 해결 방안 : 신뢰할 수 있는 지인이나 기관에 키 조각을 분산 보관하는 샤미르 비밀 공유 기반 소셜 복구(Social Recovery) 및 다자간 계산(MPC) 키 백업 구축.
- 각국 데이터 주권 법제 및 개인정보보호법과의 법적 규제 상충 :
  - 한계점 : 블록체인 분산 원장에 기록된 DID 도큐먼트의 불변성이 GDPR의 '잊힐 권리(삭제권)'와 정면 충돌할 우려.
  - 해결 방안 : 원장에는 개인정보를 일절 기록하지 않고 오직 발급자의 공개키와 암호학적 해시 및 무효화 상태(Revocation Bit)만 기록하는 오프체인(Off-chain) 원칙 준수.

## Ⅴ. GADI(Global Architecture for Digital Identity) 적용 및 발전을 위한 기술사적 제언

- 모바일 신분증(모바일 운전면허증, 주민등록증)의 GADI 글로벌 표준 정렬 : 국내 모바일 신분증 아키텍처를 ISO/IEC 18013-5(mDL) 및 W3C VC와 연계하여 해외 공항 및 글로벌 렌터카에서 즉시 호환되도록 고도화.
- 영지식 증명(ZKP) 전용 하드웨어 가속기 연구 개발 : 모바일 단말기에서 복잡한 영지식 회로 증명(zk-SNARKs) 생성 시 발생하는 CPU 부하와 배터리 소모를 줄이기 위해 모바일 NPU 가속 드라이버 최적화.
- 글로벌 신뢰 레지스트리(Trust Registry) 연합체 구축 : 국가 간 외교적 협약을 바탕으로 각국 정부의 최상위 발급 기관 목록을 상호 공인하는 다자간 신뢰 프레임워크 협약 체결.
