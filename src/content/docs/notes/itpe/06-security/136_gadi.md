## 30초 인출

- **본질:** 파편화된 이종 블록체인 메인넷 및 탈중앙화 신원(DID) 체계 간의 신뢰 연동과 자격증명(VC) 상호운용성을 보장하기 위해 DID Alliance가 제안한 글로벌 디지털 신원 아키텍처
- **메커니즘:** 신뢰 앵커 등록 → Universal Resolver 기반 이종 DID 해석 → 표준 VC 발급/제시 → 암호학적 서명 및 누산기 기반 실시간 유효성 검증
- **통찰:** 블록체인 간 DID 해석 병목은 유니버설 리졸버 캐싱으로 해결하고 법적 상호인정 공백은 eIDAS 2.0 및 신뢰 레지스트리 거버넌스 연계 필수

<details>
<summary>핵심 용어</summary>

- **GADI** : 글로벌 디지털 신원 아키텍처(Global Architecture for Digital Identity).
- **DID (Decentralized Identifier)** : 중앙 기관 없이 개인이 직접 소유하고 제어하는 분산 식별자.
- **VC (Verifiable Credential)** : 발급자의 전자서명이 포함된 검증 가능한 디지털 자격증명.
- **Universal Resolver** : 다양한 DID 메서드(`did:sov`, `did:ion` 등)를 단일 인터페이스로 조회하는 통합 해석기.

</details>

## 2~4교시 예상문제 (25점)

> 글로벌 디지털 신원 상호운용성을 위한 GADI(Global Architecture for Digital Identity)의 개념, 계층 아키텍처, 자격증명 연동 메커니즘을 설명하고, 이종 DID 체계 연동 시 엔지니어링 한계와 해결 방안을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 서로 다른 블록체인 플랫폼과 이종 탈중앙화 신원(DID) 인프라 간의 상호운용성을 확보하고 글로벌 신뢰 연계를 달성하기 위해 DID 얼라이언스가 수립한 개방형 디지털 신원 참조 아키텍처 |
| 목적 | 국가 및 기업별로 분절된 파편화된 DID/VC 생태계(Siloed Identity)를 통합하여 전 세계 어디서나 신뢰 가능한 디지털 신원 검증 환경 구축 |

- W3C의 DID/VC 표준을 준수하면서도, 서로 다른 분산 원장 간의 상호 신뢰와 실시간 철회 검증을 가능케 하는 상호운용성 프레임워크

## Ⅱ. GADI의 핵심 기술적 특성

| 특성 항목 | 세부 내용 및 기술적 의미 | 엔지니어링 구현 가치 |
|---|---|---|
| 이종 인프라 상호운용성 | 이더리움, 하이퍼레저, 비트코인 기반 등 서로 다른 DID 메서드 간 상호 변환 및 해석 지원 | 단일 벤더 및 특정 블록체인 종속성(Lock-in) 탈피 |
| 신뢰 레지스트리 연계 | 발급자(Issuer)의 신뢰 수준과 거버넌스 프레임워크를 글로벌 레지스트리에서 검증 | 위조 발급자 판별 및 글로벌 신뢰 앵커(Trust Anchor) 수립 |
| 프라이버시 보존 설계 | 영지식 증명(ZKP) 및 선택적 정보 공개(Selective Disclosure) 지원 | 최소 정보만 노출하여 GDPR 및 개인정보보호법 완벽 준수 |
| 실시간 철회 검증 | 블록체인 트랜잭션 부하 없이 대규모 자격증명의 실시간 유효 상태 확인 | 고속 암호학적 누산기(Cryptographic Accumulator) 적용 |

- 자기주권 신원(SSI: Self-Sovereign Identity) 철학을 계승하여 사용자의 자기 정보 통제권을 글로벌 범위로 확장하는 특성 보유

## Ⅲ. GADI 4계층 아키텍처 및 자격증명 연동 프로세스

```text
[GADI 기반 글로벌 디지털 신원 상호운용 아키텍처]

 ┌─────────────────────────────────────────────────────────────┐
 │  4계층: 글로벌 신뢰 생태계 (Trust Governance & Legal)       │
 │   - 국가 간 상호인정 협약, 발급자 신뢰 레지스트리 (Trust Registry) │
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │  3계층: 검증 가능한 자격증명 교환 (VC Exchange & Protocols) │
 │   - W3C VC 표준 데이터 교환, 영지식 증명(ZKP) 선택적 공개  │
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │  2계층: 탈중앙화 식별자 계층 (DID & Universal Resolver)    │
 │   - Universal Resolver: 다중 DID 메서드(did:eth, did:ion 등) 통합│
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │  1계층: 분산 원장 및 스토리지 (Decentralized Storage)       │
 │   - Public / Consortium Blockchains, IPFS, DLT 분산 저장소  │
 └─────────────────────────────────────────────────────────────┘
```

| 프로세스 단계 | 핵심 세부 동작 메커니즘 | 상호운용성 통제 포인트 |
|---|---|---|
| 1. 신뢰 앵커 수립 | 발급 기관이 GADI 글로벌 신뢰 레지스트리에 기관 DID 및 공개키 등록 | 공인된 발급자인지 검증자 확인 가능 |
| 2. 자격증명 발급 | 사용자가 신원 증명 요청 $\rightarrow$ 발급자가 검증 후 표준 W3C VC에 전자서명 발급 | 사용자 모바일 신원 지갑(Edge Wallet) 보관 |
| 3. 자격증명 제시 | 사용자가 해외 서비스(검증자)에 접속하여 검증 가능한 프레젠테이션(VP) 제출 | 영지식 증명 적용으로 불필요한 속성 은닉 |
| 4. 글로벌 해석 및 검증 | 검증자가 Universal Resolver로 발급자 DID 문서 조회 및 서명·철회 상태 검증 | 이종 메인넷에 관계없이 단일 API로 검증 완결 |

## Ⅳ. 디지털 신원 상호운용 모델 비교

| 비교 항목 | GADI (DID Alliance) | W3C DID / VC 단독 모델 | OIDC Federation (OpenID) |
|---|---|---|---|
| 핵심 초점 | 이종 DID 생태계 간 상호운용 아키텍처 | 분산 식별자 및 데이터 표현 표준 | 웹 기반 페더레이션 신원 연계 |
| 신뢰 기반 | 분산 신뢰 레지스트리 및 거버넌스 | 개별 블록체인/원장 신뢰 | 중앙 IdP(Identity Provider) 신뢰 |
| 블록체인 의존성 | 멀티 블록체인 추상화 계층 제공 | 블록체인별 메서드 구현에 종속 | 블록체인 미사용 (HTTPS REST API) |
| 구현 성숙도 | 산업 얼라이언스 참조 아키텍처 규격 | W3C 공식 웹 표준 권고안 | IETF/OIDC 글로벌 상용 표준 |
| 법적 상호인정 | 국가 간 신뢰 프레임워크 연계 추진 | 개별 국가/도메인 정책에 일임 | 기업 간 B2B 연동 중심 |

## Ⅴ. GADI 적용 시 엔지니어링 한계와 해결 방안

| 한계 | 방안 |
|---|---|
| 블록체인 플랫폼마다 상이한 DID 메서드 구조로 인해 범용 해석기(Universal Resolver)의 쿼리 레이턴시 및 병목 발생 | DIF(Decentralized Identity Foundation) 표준 드라이버 기반의 플러그인 아키텍처를 도입하고, 분산 캐싱 레이어(Redis/CDN)를 연동하여 DID Document 조회 속도 극대화 |
| 기술적 암호 서명 검증이 통과하더라도 국가 간 법률적 효력(예: 한국 모바일 운전면허증의 EU 효력) 불인정 | EU eIDAS 2.0 및 ICAO DTC(디지털 여행 자격증명) 규격을 수용하는 신뢰 프레임워크 매핑 계층을 구축하고, 정부 간 상호인정 협약(MRA) 기반 신뢰 앵커 운영 |
| 수천만 건의 자격증명 유효 상태를 블록체인 트랜잭션으로 조회 시 발생하는 가스비(Gas Fee) 및 실시간 처리 한계 | 암호학적 누산기(Cryptographic Accumulator) 또는 동적 머클 트리 기반의 영지식 철회 증명(ZKP Revocation Proof)을 도입하여 오프체인 무비용 검증 구현 |
| 스마트폰 분실 및 개인키 유출 시 글로벌 분산 환경에서 신원 복구(Identity Recovery)의 어려움 | 단일 개인키 의존을 탈피하고 소셜 복구(Social Recovery) 및 다자간 계산(MPC) 기반 분산 키 관리 아키텍처(TSS)를 모바일 지갑에 결합 |

## Ⅵ. 글로벌 디지털 신원 생태계 구축을 위한 단계별 제언

```text
[글로벌 디지털 신원 상호운용성 확립 3대 추진 방향]

  ┌─────────────────────────────────────────────────────────────┐
  │                 1. 기술 계층: 범용 해석기 고도화           │
  │   - Universal Resolver 드라이버 오픈소스 생태계 확충        │
  │   - Trust over IP (ToIP) 4계층 스택 표준 완전 준수          │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────┴──────────────────────────────┐
  │              2. 데이터 계층: 글로벌 스키마 정규화           │
  │   - W3C VC v2.0 기반 자격증명 스키마 상호 매핑 엔진 구축   │
  │   - 영지식 증명(BBS+ 서명) 기반 개인정보 최소화 강제        │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
  ┌──────────────────────────────┴──────────────────────────────┐
  │                 3. 제도 계층: 국가 간 신뢰 앵커             │
  │   - APEC 및 EU 연계 다자간 디지털 신분증 상호인정 추진      │
  │   - 공공·민간 통합 거버넌스 프레임워크 제도화              │
  └─────────────────────────────────────────────────────────────┘
```

| 영역 | 엔지니어링 세부 과제 | 통제 목표치 |
|---|---|---|
| 해석 성능 | Universal Resolver 기반 이종 DID Document 조회 지연 시간 | 평균 응답 시간 < 200ms |
| 상호운용성 | 국내 K-DID 규격과 글로벌 W3C VC 규격 간 상호 변환율 | 스키마 매핑 적합률 100% |
| 프라이버시 | 모바일 신원 제시 시 최소 필요 속성 외 원천 은닉성 보장 | 속성 과다 노출(Over-disclosure) 0건 |
