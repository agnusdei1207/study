## 지식 로드맵 내 현재 위치

지식 위치: 정보보안 → 사이버·물리 보안 → **드론**

## 30초 인출

- **본질:** 무인항공기(UAV)의 지상관제소(GCS), C2 통신 링크, 항법 센서(GNSS/IMU), 비행제어기(FC) 펌웨어를 침해하여 비행 통제권을 탈취하거나 물리적 충돌을 유발하는 사이버-물리 위협
- **메커니즘:** C2 링크 도청/재밍 $\rightarrow$ GPS 스푸핑을 통한 좌표 왜곡 $\rightarrow$ MAVLink 패킷 주입 $\rightarrow$ 비인가 비행 유도 및 공중 납치(Hijacking) 발생
- **통찰:** 단순 MAVLink 서명은 기밀성을 보장하지 못하므로 하드웨어 E2EE 암호화와 관성항법(INS) 융합 칼만 필터 및 다중 페일세이프 결합 필수

<details>
<summary>핵심 용어</summary>

- **UAV (Unmanned Aerial Vehicle)** : 조종사가 탑승하지 않고 무선으로 제어되는 무인 비행체.
- **GCS (Ground Control Station)** : 비행 계획 수립, 원격 명령 하달 및 상태 모니터링을 수행하는 지상 관제 시스템.
- **GNSS Spoofing** : 실제 위성 신호보다 강력한 위조 GPS 신호를 방사하여 드론을 가짜 위치로 유도하는 공격.
- **MAVLink (Micro Air Vehicle Link)** : 드론과 GCS 간 텔레메트리 및 명령 교환에 사용되는 표준 경량 프로토콜.

</details>

## 2~4교시 예상문제 (25점)

> 무인항공기(드론)의 4대 핵심 도메인(GCS, C2 링크, 항법 센서, 기체 펌웨어)별 사이버-물리 보안 위협과 침투 메커니즘을 설명하고, GPS 스푸핑 및 C2 재밍 대응을 위한 엔지니어링 방어 아키텍처를 제시하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 드론(무인항공기)의 하드웨어, 펌웨어, 무선 통신 데이터링크(C2), 항법 센서 체계를 대상으로 사이버 공격을 가해 비행 제어권을 탈취하거나 물리적 추락을 유발하는 복합 사이버-물리(CPS) 위협 |
| 목적 | 군사 작전 마비, 주요 국가 시설(원자력 발전소, 공항) 공중 정찰 차단, 도심 물류 드론의 비인가 납치 및 공중 충돌로 인한 대규모 인명 피해 예방 |

- 정보 유출에 그치는 일반 IT 위협과 달리 공중에서 물리적 추락, 비행 금지 구역 침범, 폭발물 탑재 테러로 직결되는 물리적 파괴력을 수반하는 극한 위협

## Ⅱ. 드론 시스템의 핵심 보안 특성

| 특성 항목 | 세부 내용 및 기술적 의미 | 엔지니어링 영향 |
|---|---|---|
| 사이버-물리 융합성 (CPS) | 소프트웨어 명령 오류나 센서 조작이 즉각적인 공중 물리 궤적 이탈로 발현 | 밀리초 단위의 실시간성 및 가용성이 최우선 |
| 저전력·경량화 제약 | 배터리 수명 및 탑재 하중(Payload) 한계로 고사양 암호화 하드웨어 장착 제한 | 경량 암호 알고리즘(LEA, ChaCha20) 탑재 필수 |
| 개방형 무선 채널 노출 | ISM 대역(2.4GHz, 5.8GHz) 무선 링크 사용으로 물리적 도청 및 전파 방해 취약 | 전파 재밍(Jamming)에 대한 주파수 도약(FHSS) 요구 |
| 취약한 항법 신호 의존 | 지상 20,000km 상공에서 도달하는 미약한 위성 신호(-130dBm)에 절대적 의존 | 저출력 사제 GPS 스푸퍼로도 손쉬운 위치 기만 가능 |

- 기체 자체의 무결성뿐 아니라 무선 링크와 지상관제소(GCS)를 아우르는 종단간 심층 방어 설계가 요구되는 특성 보유

## Ⅲ. 드론 4대 도메인별 침투 위협 및 방어 아키텍처

```text
[드론 4대 도메인 보안 위협 및 종합 방어 아키텍처]

 ┌─────────────────────────────────────────────────────────────┐
 │  1. 지상관제소 계층 (GCS: Ground Control Station)          │
 │   - 위협: 조종사 PC 랜섬웨어, 비행 계획 변조, 비인가 이륙   │
 │   - 방어: 하드웨어 보안키 MFA, GCS 무결성 EDR, 세션 암호화  │
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │  2. C2 통신 데이터링크 계층 (RF / LTE / 5G)                │
 │   - 위협: MAVLink 명령 주입, 패킷 스니핑, C2 전파 재밍     │
 │   - 방어: MAVLink v2 전자서명 + AES-CCM 암호화 + FHSS 도약   │
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │  3. 항법 및 센서 계층 (GNSS / IMU / Compass)               │
 │   - 위협: GPS 스푸핑(가짜 좌표 유도), 음향 자이로 공진 공격 │
 │   - 방어: 다중 센서 융합(GNSS+INS+VIO) 칼만 필터, CRPA 안테나│
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │  4. 기체 및 비행제어기 계층 (FC / Firmware)                │
 │   - 위협: 악성 펌웨어 덮어쓰기, CAN 버스 주입, 공급망 변조 │
 │   - 방어: Secure Boot, 하드웨어 RoT(TPM), CAN-FD 인증 프레임│
 └─────────────────────────────────────────────────────────────┘
```

| 도메인 | 침투 공격 벡터 | 발생 영향 | 엔지니어링 방어 대책 |
|---|---|---|---|
| GCS 관제소 | 비인가 원격 접속, 악성코드 감염 | 비행 경로 조작, 강제 착륙 명령 | 관제 소프트웨어 서명 검증, 관리자 FIDO2 인증 |
| C2 데이터링크 | RF 중간자 공격, MAVLink 패킷 주입 | 통제권 피탈, 기체 공중 납치 | MAVLink v2 서명 + 전송 계층 AES-GCM 암호화 |
| 항법 및 센서 | 가짜 위성 RF 송출 (GPS Spoofing) | 지정 구역 이탈, 적진 유인 착륙 | IMU 관성항법 융합 EKF, 다중 GNSS(GPS/Galileo) |
| 기체 펌웨어 | JTAG/SWD 디버그 포트 펌웨어 변조 | 비행 제어 로직 훼손, 추락 | Secure Boot, 펌웨어 서명 검증, 하드웨어 RoT |

## Ⅳ. 드론 보안 위협 및 방어 기법 비교

| 비교 항목 | C2 데이터링크 위협 | GNSS 항법 신호 위협 | 기체 비행제어기(FC) 위협 | 지상관제소(GCS) 위협 |
|---|---|---|---|---|
| 주요 공격 수단 | RF 패킷 주입, C2 무선 재밍 | GPS 스푸퍼 전파 방사, 재밍 | 악성 펌웨어 업로드, CAN 버스 스니핑 | 스피어피싱, 관제 PC 권한 탈취 |
| 침해 속성 | 기밀성, 무결성, 가용성 | 무결성(위치 조작), 가용성 | 무결성(제어로직), 안전성 | 진정성(조종사 사칭), 무결성 |
| 탐지 난이도 | 보통 (신호 세기 및 CRC 에러) | 높음 (정상 위성 신호와 흡사) | 높음 (공급망 침투 시 은폐) | 보통 (EDR 및 시스템 로그) |
| 피해 파급력 | 즉각적인 조종 통제권 상실 | 가짜 홈(Home) 위치 유도로 납치 | 비행 중 모터 정지 및 수직 추락 | 다수 드론 군집 동시 오작동 |
| 핵심 기술 방어선 | MAVLink v2 서명, 주파수 도약(FHSS) | 센서 융합(INS/VIO), CRPA 안테나 | 하드웨어 Secure Boot, TPM | 제로 트러스트 MFA, 관제망 폐쇄화 |

## Ⅴ. 드론 보안 구현 시 엔지니어링 한계와 해결 방안

| 한계 | 방안 |
|---|---|
| MAVLink v2 메시지 서명(SHA-256)을 적용하더라도 메시지 본문이 평문으로 전송되어 실시간 비행 영상 및 정찰 좌표 도청 발생 | 초소형 하드웨어 보안 모듈(Crypto Co-processor)을 온보드 탑재하여 전송 계층에서 AES-256-GCM 종단간 암호화(E2EE)를 병행 처리하여 기밀성과 무결성 동시 보장 |
| 민간 저가형 GPS 수신기가 사제 GPS 스푸퍼의 강한 위조 전파에 속아 지오펜스(Geofence)가 해제되고 기체가 비인가 납치되는 위협 | 위성 신호에만 의존하지 않고 관성항법장치(IMU), 지자기 센서, 카메라 기반 비전 오도메트리(VIO)를 결합한 확장 칼만 필터(EKF) 다중 센서 융합 위치 검증 알고리즘 적용 |
| C2 링크가 RF 재밍 공격으로 단절되었을 때 사전 설정된 페일세이프(RTH: 귀환) 모드가 GPS 스푸핑과 결합되어 적진으로 자진 유인 추락 | 통신 두절 발생 시 단순 RTH에 의존하지 않고, 관성 센서 기반 데드 레코닝(Dead Reckoning)을 통해 현 위치에서 즉시 수직 안전 착륙(Failsafe Land)을 수행하도록 로직 고도화 |
| 현장 정비 시 기체 내부 물리 디버그 인터페이스(UART, JTAG)가 노출되어 현장 탈취 기기의 펌웨어 무단 덤프 및 비밀키 유출 | 출하 단계에서 칩 레벨 보안 퓨즈(eFuse)를 영구 블로잉(Blowing)하여 하드웨어 디버그 포트를 완전 비활성화하고, 모든 펌웨어 갱신은 서명 검증 FOTA로만 제한 |

## Ⅵ. 드론 비행 안전 및 사이버 탄력성 보증 체계 제언

```text
[안전한 드론 자율 비행을 위한 3단계 사이버 탄력성 프레임워크]

 ┌─────────────────────────────────────────────────────────────┐
 │                 1. 이륙 전 검증 (Pre-Flight Integrity)       │
 │   - 기체 Secure Boot 무결성 점검 (TPM PCR Quote 검증)       │
 │   - 조종자 신원 및 GCS 단말 기기 인증 (FIDO2 MFA)          │
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │              2. 비행 중 실시간 방어 (In-Flight Defense)      │
 │   - C2 링크 AES-GCM 암호화 및 FHSS 주파수 도약             │
 │   - 다중 센서(GNSS + INS + VIO) 융합 칼만 필터 항법 검증   │
 └──────────────────────────────┬──────────────────────────────┘
                                │
 ┌──────────────────────────────┴──────────────────────────────┐
 │                 3. 비상 상황 격리 (Emergency Fail-Safe)      │
 │   - C2/GNSS 이상 동시 감지 시 제자리 수직 안전 착륙 전환     │
 │   - 기체 탈취 감지 시 내부 저장 기밀 데이터 즉각 영구 소거  │
 └─────────────────────────────────────────────────────────────┘
```

| 관리 영역 | 핵심 엔지니어링 세부 과제 | 통제 목표치 |
|---|---|---|
| 통신 보안 | C2 및 비행 영상 전송 전 구간 E2EE 암호화 및 MAVLink v2 서명 | 비인가 위조 명령 실행률 0% |
| 항법 탄력성 | GPS 스푸핑/재밍 환경 모의 비행 테스트 및 센서 융합 검증 | 위치 오차 왜곡 감지 및 차단율 > 99% |
| 기체 무결성 | Secure Boot를 통한 비인가 펌웨어 바이너리 부팅 방지 | 변조 펌웨어 실행 차단율 100% |
