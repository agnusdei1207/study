## 2~4교시 25점 답안

## Ⅰ. 드론 보안위협의 정의와 목적

| 구분 | 내용 |
|---|---|
| 정의 | **드론 보안위협**은 기체·관제소·통신·항법 침해로 비행 정보와 제어를 왜곡하는 위협 |
| 목적 | 비인가 제어·정보 유출·비행 장애를 줄여 안전한 운용 확보 |

드론 보안은 정보 보호뿐 아니라 잘못된 명령이나 위치 판단이 실제 비행에 미치는 영향을 함께 다루는 분야.

## Ⅱ. 운용 구조와 주요 침해 경로

```text
드론 운용
  ├─ 관제·명령 ─ 인증·권한 검증
  ├─ 통신 링크 ─ 명령 무결성·링크 보호
  ├─ 항법·센서 ─ 신호 이상 탐지·대체 항법
  └─ 기체·펌웨어 ─ 서명 검증·안전 업데이트
```

| 영역 | 위협 | 비행 영향 |
|---|---|---|
| 관제소 | 계정 탈취·악성코드 | 비인가 비행계획·명령 |
| 무선 링크 | 도청·명령 위조·재밍 | 정보 유출·제어 두절 |
| 항법·센서 | GNSS 신호 위조·교란 | 위치 오판·경로 이탈 |
| 기체 소프트웨어 | 펌웨어 변조 | 제어 로직·안전 기능 훼손 |

## Ⅲ. 명령과 통신 보호

```text
관제소의 비행 명령
        ↓ 인증·무결성 검증
기체의 명령 수락 여부
        ↓ 유효한 명령만 실행
비행제어기
```

MAVLink 2 메시지 서명은 출처 확인과 무결성 검증에 쓰이며 메시지 내용을 암호화하지는 않는다. 기밀성이 필요한 링크에는 별도의 전송 보호가 필요하다.

| 통제 | 확인 대상 |
|---|---|
| 관제 주체 인증 | 허가된 조종자·단말 여부 |
| 명령 무결성·재전송 방지 | 변조·재생된 명령 여부 |
| 링크 보호 | 기밀성 요구와 무선 구간 특성 |
| 관제소 보호 | 패치·악성코드·접근권한 상태 |

## Ⅳ. 항법·기체 안전 통제

```text
GNSS 위치 ─┐
관성·기타 센서 ─┼─ 정합성 판단
비행 상태 ─┘         ↓ 이상 시
              경고·대체 항법·페일세이프
```

| 위협 | 통제 | 검증 방법 |
|---|---|---|
| GNSS 스푸핑·재밍 | 신호·센서 정합성 확인 | 위치 급변·신호 이상 시험 |
| 펌웨어 변조 | 서명 검증·보안 업데이트 | 변조 이미지의 부팅 차단 |
| 통신 두절 | 사전 정의한 안전 동작 | 환경별 페일세이프 시험 |

## Ⅴ. 적용 한계와 제언

| 한계 | 대응 |
|---|---|
| 통신 서명만으로 링크 기밀성·재밍 방어까지 보장한다고 오인 | 인증·무결성·기밀성·가용성 통제를 따로 시험하고 결과를 비행 안전 요구와 연결 |
| 항법 이상 시 대체 동작이 현장 환경에 맞지 않을 가능성 | 운용 구역과 기체 유형별 통신 두절·위치 이상 시나리오를 정해 페일세이프 검증 |
