## 지식 로드맵 내 현재 위치

지식 위치: 콘텐츠 신뢰 → 출처·편집 이력 → **C2PA**

## 30초 인출

- 본질: 디지털 콘텐츠에 제작·편집에 대한 주장(Assertion)을 매니페스트로 결합하고 서명해 출처·변경 이력을 검증 가능하게 하는 기술
- 구별: 서명의 유효성은 **누가 무엇을 주장했는지와 콘텐츠 결합**을 검증. 촬영 장면의 진실성·주장 완전성 보장은 아님
- 한계: 매니페스트 제거, 서명 키 침해, 잘못된 최초 주장, 플랫폼의 표시·보존 미지원

## 1교시 예상문제 (10점)

> C2PA 기반 디지털 출처증명의 구성과 검증 범위를 설명하시오. (예상·10점)

## 1교시 10점 답안

### Ⅰ. 구성

| 요소 | 역할 |
|---|---|
| 콘텐츠·매니페스트 | 콘텐츠와 출처·처리 주장 연결 |
| Claim·Assertion | 제작·편집에 관한 서명 대상 진술 |
| 서명·신뢰 목록 | 주장 서명자와 변경 여부 검증 |
| 검증기 | 서명·결합·이력 확인 후 표시 |

### Ⅱ. 검증 경계

```text
생성·편집 도구 → 주장 작성·서명 → 콘텐츠와 결합 → 유통 → 검증기
```

유효한 자격증명도 실제 장면이 참이라는 판정은 아님. 미서명 콘텐츠도 곧 허위라고 판정할 수 없음.

## 2~4교시 예상문제 (25점)

> C2PA 기반 디지털 출처증명의 매니페스트 생성·검증 흐름과 딥페이크 대응의 효과·한계를 설명하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 목적과 구조

생성형 AI와 편집 도구가 늘어난 환경에서 콘텐츠의 제작·편집 주장과 서명자를 검증 가능하게 하는 표준. 사후 딥페이크 탐지와 보완 관계.

### Ⅱ. 생성·검증 경로

```text
캡처/생성 → 매니페스트의 Claim·Assertion 작성
         → 콘텐츠 바인딩·서명 → 편집 시 새 주장·이력 연결
         → 배포 → 서명·바인딩·이력 검증·사용자 표시
```

서명자의 개인키가 주장에 서명하며, 인증기관이 콘텐츠 자체에 직접 서명한다고 일반화하지 않음.

### Ⅲ. 관련 기술 비교

| 수단 | 장점 | 한계 |
|---|---|---|
| C2PA 매니페스트 | 서명된 출처·처리 이력의 구조화 | 최초 주장·서명자 신뢰, 메타데이터 제거 |
| 워터마크 | 콘텐츠와 함께 남을 가능성 | 강도·복원·오탐이 구현에 좌우 |
| 사후 탐지 모델 | 자격증명 없는 자료도 분석 | 정확도·공격 적응·설명성 한계 |

워터마크로 매니페스트가 언제나 복원되는 것은 아님. 별도 레지스트리·바인딩 설계가 필요.

### Ⅳ. 위협과 운영 대응

| 위협 | 대응 |
|---|---|
| 유통 플랫폼의 메타데이터 제거 | 보존·표시 지원과 사이드카·검색 경로 설계 |
| 서명 키 탈취 | 키 보호·회수·사고 통지 |
| 허위 최초 주장 | 발급자 신원·캡처 장치 신뢰·사후 검증 |
| 사용자 오해 | ‘검증된 주장’과 ‘사실 확인’을 구분해 표시 |

### Ⅴ. 기술사적 제언

콘텐츠 진실성 판정과 출처 이력 확인을 분리하고, 제작·편집·유통·검증 주체별 신뢰 경계를 명시.
