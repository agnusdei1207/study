## 30초 인출

- **본질:** **CSAP (Cloud Security Assurance Program)** 는 보안인증기준에 맞는 클라우드컴퓨팅서비스를 평가·인증하는 제도
- **구조:** 신청 서비스·범위 확인 → 인증기관 평가·보완 → 결과·운영범위 관리
- **유의점:** 인증은 지정된 서비스 범위의 평가 결과이며 이용기관 책임 전체를 대신하지 않음

<details>
<summary>핵심 용어</summary>

- **CSAP (Cloud Security Assurance Program):** 클라우드컴퓨팅법에 근거해 클라우드서비스의 보안인증기준 적합성을 평가·인증하는 제도
- **보안인증기준:** 관리적·물리적·기술적 보호조치 등 클라우드서비스 평가에 적용하는 기준
- **인증 범위:** 평가·인증 대상 서비스와 그 구성요소를 특정한 범위
- **KISA (Korea Internet & Security Agency):** 한국인터넷진흥원으로, 법령에 따라 CSAP 인증업무를 수행할 수 있는 기관
- **사후관리:** 인증된 서비스의 범위·요건·운영 상태를 유지·확인하는 절차
</details>

### Ⅱ. 평가 흐름과 활용

```text
신청 서비스·범위 확정

기준에 따른 평가·기술자문
          ↓ 필요 시

인증 결과·범위·사후관리
```

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CSAP (Cloud Security Assurance Program)** 는 보안인증기준에 맞는 클라우드컴퓨팅서비스를 평가·인증하는 제도 |
| 목적 | 클라우드서비스의 보안수준 향상을 지원하고 이용기관의 서비스 선택에 필요한 보안정보 제공 |

클라우드컴퓨팅법 제23조의2의 보안인증은 장관이 기준에 적합한 서비스에 대해 시행할 수 있는 인증이며, 국가기관 등의 서비스 이용에서는 인증 서비스를 우선 고려하도록 규정.

## Ⅱ. 신청·평가 구조

| 역할 | 주요 활동 |
|---|---|
| 신청기관·서비스 제공자 | 서비스·범위 정의, 신청자료·증적 제출 |
| 인증기관 | 기준에 따른 평가, 미흡사항 확인·보완 처리, 인증업무 수행 |
| 기술자문·인증 심의 | 법령·운영기준에 따른 전문 검토와 인증절차 지원 |
| 이용기관 | 인증범위·서비스 구성·내부 책임을 비교해 도입 판단 |

```text
서비스·범위 정의 → 신청·증적 제출 → 인증기관 평가
                                      ├─ 기준 미달 → 보완 후 재평가
                                      └─ 적합 → 인증결과·범위 확정
                                                        ↓
                                                 도입·운영·사후관리
```

## Ⅲ. 기준·범위 확인

| 확인축 | 검토 내용 |
|---|---|
| 서비스 유형·범위 | 신청 서비스, 데이터 흐름, 구성요소·제외 범위 |
| 보안기준 | 적용되는 현행 법령·고시·인증 안내서 |
| 증적·책임 | 제공자 통제, 계약, 이용기관의 계정·데이터·설정 책임 |

인증 등급·유형·평가기준은 개정될 수 있으므로 숫자나 분류를 노트에 고정하기보다 현행 KISA 안내서·고시 확인.

## Ⅳ. 도입·운영 통제

| 위험 | 관리 방향 |
|---|---|
| 인증 서비스와 실제 이용 구성의 차이 | 인증 범위·지역·서비스 옵션과 실제 도입 설계 대조 |
| 인증 보유 사실을 전면적 보안보증으로 해석 | 인증 기준·대상·제외 범위를 계약·위험평가에 반영 |
| 이용기관의 통제 공백 | 계정·접근권한·데이터 분류·사용자 설정의 내부 책임 지정 |
| 변경 후 기존 평가범위 불일치 | 서비스·구성 변경 시 인증 영향과 사후관리 요건 점검 |

## Ⅴ. 한계와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 인증 결과가 이용기관의 구체적 설계·계정·데이터 통제까지 대신하지 않음 | 도입 시 인증 범위와 공동 책임을 구성요소별로 매핑하고 운영 증적으로 확인 |
| 유형·기준·인증 서비스 범위가 바뀌면 오래된 점검표가 실제 요구와 어긋날 수 있음 | KISA 최신 안내·법령·인증서 상태를 도입 및 정기 재검토 절차에 연결 |
