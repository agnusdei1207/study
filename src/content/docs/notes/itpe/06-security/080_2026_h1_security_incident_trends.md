## 한 줄 본질
- 공급망·계정·원격접속·정상 도구 악용 등은 서로 다른 사건에서 나타날 수 있음. 조직별 자산·위협을 기준으로 예방·탐지·복구를 결합하고, 확인된 사고와 전망을 구별해 기술한다.

## 핵심 용어
- LotL(Living off the Land): 외부 악성 바이너리를 다운로드하지 않고, 피해 시스템에 이미 정상적으로 설치된 OS 기본 도구(PowerShell, Certutil, WMI 등)만을 악용하여 탐지를 우회하는 공격 기법
- 비인간 신원(NHI, Non-Human Identities): 사람이 아닌 서비스, 워크로드, 마이크로서비스, 자동화 스크립트, CI/CD 파이프라인이 시스템 접근을 위해 사용하는 API 토큰, 서비스 계정, SSH 키

## 핵심 통찰
- 정상 자격증명·공급망 악용은 악성코드 유포와 함께 고려할 공격 경로. 파일 탐지와 더불어 계정·행위·배포 무결성의 이상 징후 확인.
- AI 악용 가능성은 시나리오별 자료로 평가하며, 모든 2026년 사고에 동일하게 나타난다고 일반화하지 않음.
- 복구목표시간(RTO)은 업무 영향 분석과 복구 시험으로 정한다. 모든 조직에 동일한 2시간 복구 목표를 적용할 근거는 없음.

## 이웃 토픽과 구분
- 침해사고 대응 vs 사이버 복원력: 침해사고 대응 = 사고 탐지·분석·차단에 집중 / 사이버 복원력 = 사고 발생 중에도 비즈니스 연속성을 유지하고 신속히 원상 복구하는 총체적 역량

## 문제·원인·대책
- 참고 사례: 2024년 XZ Utils 공급망 침해 시도. 2026년 상반기 발생 사건이나 모든 리눅스 배포판의 실제 감염으로 쓰지 않음.
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| XZ Utils의 후보 배포 패키지에 악성 코드가 포함된 공급망 침해 시도 | 빌드 산출물과 배포 경로의 무결성 검증 부족 | 출처·빌드 산출물 검증, 의존성 목록과 배포 단계 점검 | 의심 패키지 식별 및 배포 범위 추적 지원 |
| 정상 시스템 관리 도구 악용으로 보안 탐지 회피 | 파일 시그니처 중심 탐지의 한계 | EDR·로그의 프로세스·네트워크 행위 상관분석 | 의심 행위 조사와 정책에 따른 연결 제한 지원 |

## 1교시 예상문제 (10점)
- 2026년 상반기 침해 위협을 점검할 때 실제 사고와 전망을 구분하는 방법을 설명하시오.

## 1교시 10점 답안
- **범위:** 발생 시기·지역·피해 대상을 확인한 실제 사고와 전년도 자료의 향후 전망을 분리.
- **경로:** 공급망 변조, 정상 도구 악용, 계정·토큰 오용, 랜섬웨어 등 공격 경로별 증거 정리.
- **대응:** 자산·신원·소프트웨어 구성요소 파악, 행위 탐지, 복구 가능성 시험과 시점별 공식 통계 확인.

## 2~4교시 예상문제 (25점)
- 상반기 침해 위협 분석의 근거 구분과 조직의 예방·탐지·복구 체계를 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 분석 범위
- 연도·기간·지역을 먼저 정하고 공식 통계, 사고 원인 조사, 전망을 다른 근거로 표시.
### Ⅱ. 공격 경로
- 공급망 업데이트의 무결성 훼손, 정상 관리 도구 악용, 비인간 계정 탈취, 데이터 유출·랜섬웨어의 연결 가능성 검토.
### Ⅲ. 통제
- SBOM·서명·배포 검증, 최소 권한·단기 자격증명, EDR·로그 상관분석, 불변 백업·복구 훈련.
### Ⅳ. 우선순위
- 업무 중요도·노출 가능성·복구 시간에 따른 조치. 2024년 XZ Utils와 ENISA의 2025년 EU 자료를 2026년 상반기 발생 통계로 사용 금지.
