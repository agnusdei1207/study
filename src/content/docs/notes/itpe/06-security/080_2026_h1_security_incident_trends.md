## 핵심 용어
- LotL(Living off the Land): 외부 악성 바이너리를 다운로드하지 않고, 피해 시스템에 이미 정상적으로 설치된 OS 기본 도구(PowerShell, Certutil, WMI 등)만을 악용하여 탐지를 우회하는 공격 기법
- 비인간 신원(NHI, Non-Human Identities): 사람이 아닌 서비스, 워크로드, 마이크로서비스, 자동화 스크립트, CI/CD 파이프라인이 시스템 접근을 위해 사용하는 API 토큰, 서비스 계정, SSH 키

## 핵심 통찰
- 2026년의 공격자는 "시스템을 해킹(Hacking)"하지 않고 정상 자격증명이나 공급망을 통해 "로그인(Logging in)"함 → 악성코드 유입 탐지보다 비정상 행위 추적이 방어의 성패를 가름
- 생성형 AI가 공격자의 진입 장벽을 급격히 낮춤 → 완벽한 한국어 피싱 이메일, 타깃 기업 맞춤형 공격 스크립트, 취약점 패치 리버스 엔지니어링이 자동화됨
- 100% 방어는 불가능하다는 전제 하에, 침해를 당하더라도 2시간 이내에 핵심 비즈니스를 복구하는 '사이버 복원력(Cyber Resilience)'이 2026년 보안의 최종 지향점임

## 이웃 토픽과 구분
- 침해사고 대응 vs 사이버 복원력: 침해사고 대응 = 사고 탐지·분석·차단에 집중 / 사이버 복원력 = 사고 발생 중에도 비즈니스 연속성을 유지하고 신속히 원상 복구하는 총체적 역량
