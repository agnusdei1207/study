## Ⅰ. 경계 기반 보안(Perimeter Security)의 개요

- 개념 : 외부 인터넷과 내부 사내망 사이의 물리적·논리적 경계 지점에 방화벽, **침입방지시스템** (IPS, Intrusion Prevention System), **VPN**(Virtual Private Network) 등을 구축하여 외부 위협의 진입을 방어하는 보안 접근법.
- 배경 및 필요성 : 신뢰하는 내부망과 신뢰하지 않는 외부망 사이에 방화벽, DMZ(Demilitarized Zone), 침입차단시스템(IPS) 등 물리적·논리적 장벽을 구축하여 외부 위협의 내부 진입을 통제하던 전통적 보안 모델로서, 클라우드 확산에 따른 한계 극복을 위해 **ZTA**로 발전 중임.
- 핵심 목적 : 단일 통제 지점을 통한 중앙 집중적 트래픽 검사 및 정책 집행, 명확한 네트워크 물리적 신뢰 구획 분리를 통한 인프라 자산 보호.

## Ⅱ. 경계 기반 보안(Perimeter Security)의 핵심 아키텍처 및 동작 메커니즘

경계 기반 보안(Perimeter Security)은(는) 신뢰할 수 있는 보안 구조와 표준화된 절차를 기반으로 동작하며, 세부적인 아키텍처와 구성요소 간의 상호작용 메커니즘은 다음과 같음.

```text
[ 1. 전통적 경계 기반 보안 모델 (Castle-and-Moat) ]
외부 인터넷 ──▶ [ 방화벽 / VPN 게이트웨이 ] ──▶ [ 내부 신뢰 사내망 (Implicit Trust Zone) ]
                     (1회성 경계 인증)                    ├── 업무용 PC (침해 발생!)
                                                           ├── 파일 서버 ◀── [측면 이동 무차별 확산]
                                                           └── 코어 DB   ◀── [랜섬웨어 암호화]

[ 2. 제로트러스트 아키텍처 (ZTA) 전이 모델 ]
사용자/단말 ──▶ [ 정책 결정점 (PDP) ] ◀── CTI / EDR 단말 무결성 / IAM 정책 엔진
                     │ (지속적 위험 평가: Continuous Assessment)
                     ▼
              [ 정책 집행점 (PEP) / ZTNA 게이트웨이 ]
                     │ (신원 확인 + 기기 적합성 통과 시 최소 권한 1:1 연결)
                     ├──────────────────┬──────────────────┐
                     ▼                  ▼                  ▼
              [ App A 워크로드 ]   [ App B 워크로드 ]   [ 코어 DB 워크로드 ]
              (마이크로세그멘테이션 격리: 타 워크로드 간 직접 통신 전면 차단)
```

- **신원 (Identity)** : ID/PW 기반 VPN 1회성 로그인, 정적 패스워드 (피싱 저항 MFA(FIDO2), 위험 기반 연속 인증(CARTA)).
- **기기 (Device)** : 인가된 MAC(Media Access Control) 주소 또는 사내 자산 태그 확인 (EDR(Endpoint Detection and Response) 텔레메트리 연동, 단말 무결성(컴플라이언스) 실시간 평가).
- **네트워크 (Network)** : 거대한 단일 사내망 서브넷, DMZ 분리 수준 (마이크로세그멘테이션, **ZTNA**(Zero Trust Network Access) 기반 1:1 소프트웨어 정의 경계).
- **워크로드 (Workload)** : 서버 OS(Operating System) 단위 방화벽 룰, 정적 인프라 호스팅 (서비스 메시(Istio) mTLS 상호 인증, 컨테이너 불변 실행).
- **데이터 (Data)** : 사내망 저장 파일 평문 유지, 네트워크 유출 차단 의존 (데이터 분류, 컬럼 암호화, DRM(Digital Rights Management)/DLP(Data Loss Prevention), 객체 레벨 세부 인가).

## Ⅲ. 경계 기반 보안(Perimeter Security)의 세부 구성 요소 및 비교 분석

| 비교 항목 | **경계 기반 보안** (Perimeter Security) | **제로트러스트 보안** (Zero Trust Architecture) |
|---|---|---|
| 기본 보안 철학 | 신뢰하되 검증한다 (Trust, but Verify) | 절대 신뢰하지 않고 항상 검증한다 (Never Trust, Always Verify) |
| 신뢰의 기준 | 물리적 네트워크 위치 (내부 사내망 vs 외부 인터넷) | 검증된 사용자 신원, 기기 무결성 상태, 요청 컨텍스트 |
| 네트워크 토폴로지 | 북-남(North-South) 트래픽 중심 집중 검사 | 동-서(East-West) 트래픽 전수 인라인 검사 및 격리 |
| 원격 접속 기술 | VPN (사내 네트워크 대역 전체로 IP(Internet Protocol) 할당 진입) | ZTNA (인가된 특정 애플리케이션 단일 세션만 브로커링) |
| 측면 이동 내성 | 취약 (내부 진입 시 다른 호스트로 자유로운 이동) | 우수 (마이크로세그멘테이션으로 호스트 간 이동 차단) |
| 클라우드 적합성 | 낮음 (모든 트래픽을 본사로 백홀하여 병목 유발) | 매우 높음 (클라우드 네이티브 분산 환경 완벽 지원) |

- 경계 기반 보안(Perimeter Security)은(는) 상기 핵심 비교 지표와 아키텍처 구성을 바탕으로 보안 위협에 대한 방어 효과성을 극대화하며, 기존 레거시 통제 기법 대비 우수한 신뢰성과 운영 효율성을 제공함.

## Ⅳ. 경계 기반 보안(Perimeter Security)의 주요 한계점 및 해결 방안

- 한계점 : 전사 임직원 재택근무 시 VPN 장비로 트래픽이 집중되어 대역폭 병목 및 서비스 가용성 다운타임 유발.
  - 해결 방안 : **클라우드 기반 보안 서비스 엣지** (SSE/SASE)를 도입하여 사용자와 가장 가까운 글로벌 PoP에서 분산 ZTNA 인라인 검사 수행.
- 한계점 : 경계 방화벽 통과 후 내부 호스트 간 통신(East-West)에 대한 모니터링 및 접근 제어 부재.
  - 해결 방안 : 호스트 기반 소프트웨어 방화벽 및 eBPF 기반 **마이크로세그멘테이션** 솔루션(Illumio/Cilium)을 적용하여 프로세스 단위 횡적 통신 강제 차단.
- 한계점 : 공격자가 사내망 상주 직원의 정상 자격증명을 탈취할 경우 경계 장비에서 악의적 행위 식별 불가.
  - 해결 방안 : **사용자 및 엔티티 행위 분석** (UEBA, User and Entity Behavior Analytics)을 연동하여 평소와 다른 자원 접근, 대량 파일 다운로드 등 이상 징후 발생 시 세션 즉시 강제 종료.
- 한계점 : 레거시 메인프레임이나 구형 프로토콜을 사용하는 기간계 시스템의 경우 현대적 ZTNA 에이전트 설치 불가.
  - 해결 방안 : 레거시 자산 전면에 **역방향 프록시** (Reverse Proxy) 또는 **점프 호스트** (Bastion)를 배치하고 계정 권한을 시간 제한 단기 토큰으로 중계 통제.

## Ⅴ. 경계 기반 보안(Perimeter Security) 적용 및 발전을 위한 기술사적 제언

- 1단계 (초기 정비) 중심의 거버넌스 및 실행 체계 구축 : 관리자 계정 대상 FIDO2 MFA 강제화 및 인터넷 접점 엣지 장비 취약점 전수 패치을(를) 적극 추진하여, 자격증명 도용 및 외부 침입 위험 차단 효과를 극대화해야 함.
- 2단계 (클라우드 ZTNA) 중심의 거버넌스 및 실행 체계 구축 : 비즈니스 중요 SaaS 및 클라우드 워크로드부터 VPN 접속을 배제하고 ZTNA 전환을(를) 적극 추진하여, VPN 트래픽 병목 해소 및 직무별 세부 인가 구현 효과를 극대화해야 함.
- 3단계 (성숙도 완성) 중심의 거버넌스 및 실행 체계 구축 : 사내 코어 DB(Database) 및 서버 팜 대상 마이크로세그멘테이션 완성 및 CARTA 동적 인가 연동을(를) 적극 추진하여, 침해 발생 시에도 피해 범위를 단일 노드로 국소화하는 효과를 극대화해야 함.
