## 지식 로드맵 내 현재 위치

지식 위치: 접근통제·무결성 모델 → 정형 거래와 직무 분리 → **Clark-Wilson 모델**

## 30초 인출
- Clark-Wilson 모델은 상업적 데이터의 무결성을 위해 검증된 절차를 통한 변경과 직무 분리를 강제하는 접근통제 모델

<details>
<summary>핵심 용어</summary>

- **CDI** : 무결성 제약을 유지해야 하는 통제 데이터.
- **UDI** : 아직 무결성이 확인되지 않은 입력 데이터.
- **TP** : 유효한 상태를 다른 유효한 상태로 전환하는 검증된 절차.
- **IVP** : CDI가 무결성 제약을 만족하는지 검증하는 절차.

</details>

## 핵심 요소
| 요소 | 의미 | 예 |
|---|---|---|
| CDI | 무결성을 유지해야 할 통제 데이터 | 회계 원장 |
| UDI | 아직 무결성이 보장되지 않은 입력 | 외부 입력 전표 |
| TP | 유효한 상태를 다른 유효한 상태로 바꾸는 변환 절차 | 승인된 분개 처리 |
| IVP | CDI가 무결성 제약을 만족하는지 검증하는 절차 | 차변·대변 합계 점검 |

## 1교시 10점 답안

### Ⅰ. 개요

| 항목 | 개요 |
|---|---|
| 정의 | Clark-Wilson 모델은 검증된 거래 절차와 직무 분리로 업무 데이터의 무결성을 유지하는 접근통제 모델 |
| 목적 | 임의 변경 제한과 승인 절차·검증·감사에 의한 거래 데이터 유효성 유지 |

### Ⅱ. 구성 요소

Clark-Wilson은 기업의 거래 데이터 무결성을 정형화된 거래와 직무 분리로 보장하는 모델. 사용자가 CDI를 임의로 바꾸지 않고 승인된 TP를 통해 변경하며, IVP가 데이터의 유효성을 점검. UDI를 CDI에 반영할 때도 적절한 TP의 검증 필요. 접근 허가는 사용자·TP·CDI의 조합에 대해 관리하며 감사 기록으로 책임 추적 지원.

## 2~4교시 25점 답안
### Ⅰ. 보호 목적

| 항목 | 개요 |
|---|---|
| 정의 | Clark-Wilson 모델은 검증된 거래 절차와 직무 분리로 업무 데이터의 무결성을 유지하는 접근통제 모델 |
| 목적 | 임의 변경 제한과 승인 절차·검증·감사에 의한 거래 데이터 유효성 유지 |

금융·회계 업무에서 입력 오류, 무단 변경, 한 사람에 의한 부정 거래를 방지하는 상업용 무결성 정책. 기밀성 계층 모델인 Bell-LaPadula와 보호 목표가 다름.

### Ⅱ. 통제 흐름
```text
UDI(외부 입력) ── 검증된 TP ──> CDI(통제 데이터)
사용자 ── 승인된 사용자·TP·CDI 조합 ──> TP 실행
IVP ──> CDI가 무결성 제약을 만족하는지 확인
감사 기록 ──> 변경 주체·절차·결과 추적
```

### Ⅲ. 운영 규칙
TP는 CDI를 유효 상태에서 유효 상태로만 전환하도록 인증. 사용자는 허가된 TP와 CDI 조합에만 접근. 인증·권한 관리 담당과 실제 거래 수행자의 직무 분리. 모든 TP 실행에 대한 충분한 감사 기록.

### Ⅳ. 적용과 한계
주문 등록과 지급 승인 분리, 회계 전표 입력과 원장 반영 분리 등 업무 규칙에 적용. 절차의 정확성, 권한 설계, 실제 운영 통제가 필요하며 모델만으로 부정 행위의 완전 차단을 보장할 수 없음.
