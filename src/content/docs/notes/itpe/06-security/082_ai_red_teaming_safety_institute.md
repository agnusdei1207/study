- **절차:** 범위·승인·위협 모델 설정 → 사람·자동화 시험 → 증거 기록·완화 → 재시험.
- **기관 역할:** AI안전연구소는 안전성 평가 방법·연구·협력에 기여. 개별 시험이 보편적 안전 인증은 아님.

## 2~4교시 25점 답안

**공통 개요**

| 구분 | 핵심 |
|---|---|
| 정의 | AI 레드티밍은 승인된 범위에서 모델·응용·도구의 오용 가능성을 공격자 관점으로 시험하는 활동 |
| 목적 | 배포 위험 발견과 완화 조치의 재시험 |

### Ⅰ. 목적
- 배포 전후 AI 시스템의 위험을 적대적 시나리오로 발견하고 완화 효과를 확인.
### Ⅱ. 시험 대상
- 탈옥·간접 프롬프트 인젝션, 민감정보 노출, 도구 오용, 편향·유해 출력 등을 모델·응용 맥락별 선정.
### Ⅲ. 절차
- 승인된 범위와 중단 조건 → 공격 시나리오·평가 지표 → 시험·재현 → 위험도 분류 → 조치·회귀시험.
### Ⅳ. 역할·한계
- 연구기관의 평가 방법·공동 연구와 조직의 배포 책임을 구분. 시험 통과는 새 공격이나 모델 변경 이후의 안전을 보장하지 않음.

## 기술사적 제언

평가 범위와 중단 조건을 먼저 승인하고 발견된 공격을 수정·회귀시험 항목으로 남긴다.
