## Ⅰ. 위조(Fabrication) 공격의 개요

- **개념** : 비인가된 공격자가 시스템 내부에 존재하지 않던 거짓 정보, 허위 네트워크 패킷, 조작된 자격증명, 위조 트랜잭션, 사칭된 디지털 자산을 새롭게 생성하여 주입함으로써 시스템의 인증(Authentication), 진본성(Authenticity), 가용성(Availability)을 근본적으로 무너뜨리는 능동적(Active) 정보보호 침해 공격.
- **배경 및 필요성** : 인터넷 초기 프로토콜(ARP, IP, DNS, SMTP)은 발신지의 진위 여부를 검증하는 암호학적 인증이 결여된 채 설계되었으며, 공격자들은 이러한 구조적 결함을 악용하여 신원을 위조하는 스푸핑(Spoofing)과 가짜 데이터를 대량 생성함.
- **핵심 목적** : 합법적인 사용자나 서버로 위장하여 보안 통제 시스템을 기만하고, 피해자의 트래픽을 가로채거나 시스템 자원을 허위 요청으로 고갈시켜 마비시킴.

## Ⅱ. 위조(Fabrication) 공격의 핵심 아키텍처 및 동작 메커니즘

위조 공격은 네트워크 계층(ARP/IP/DNS 스푸핑), 인증 계층(위조 인증서, 토큰 조작), 애플리케이션 계층(이메일 발신자 사칭, 딥페이크 위조) 등 시스템 전 계층에 걸쳐 발생함.

```text
[ 위조(Fabrication) 공격 유형별 침투 아키텍처 ]

 1. L2 데이터링크 계층: ARP 위조 (ARP Spoofing)
    [ 공격자 ] ====== (가짜 ARP Reply: "내가 게이트웨이다!") ======> [ 피해자 PC ]
    * 피해자의 ARP 캐시 테이블 오염 -> 모든 트래픽이 공격자에게 전달!

 2. L3 네트워크 계층: IP 스푸핑 (IP Spoofing)
    [ 공격자 (가짜 소스 IP 주입) ] ---- SYN 패킷 폭탄 ----> [ 대상 서버 ]
    * 소스 IP를 피해자 IP로 위조하여 반사 DDoS 공격 수행

 3. L7 애플리케이션 계층: DNS 위조 및 가짜 신원 생성
    [ DNS 포이즈닝 ] : 허위 DNS 응답을 질의자에게 먼저 주입하여 가짜 사이트 유도
    [ 이메일 위조 ]   : 발신자 주소 조작 (CEO 사칭 BEC 금융 사기)
    [ 딥페이크 위조 ] : 생성형 AI로 경영진 음성/얼굴을 위조하여 거액 송금 지시

 [ 공통 방어 원칙: 상호 인증(Mutual Auth) 및 암호학적 서명 ]
  * L2: 802.1X, Dynamic ARP Inspection (DAI)
  * L3: IPsec, uRPF (Unicast Reverse Path Forwarding)
  * L7: DNSSEC, DMARC/DKIM/SPF, FIDO2, 블록체인 공증
```

- **신원 사칭(Identity Spoofing)** : IP 스푸핑, MAC 스푸핑, 이메일 헤더 위조 등을 통해 공격자 자신을 정당한 발신인으로 완벽히 위장하여 시스템 접근 권한 획득.
- **인증서 및 토큰 위조** : 도난당한 서명 키나 취약한 알고리즘을 악용하여 위조 X.509 SSL 인증서를 발행하거나, JWT 서명을 위조하여 관리자 세션 사칭.
- **반사 및 증폭 공격의 도구화** : 출발지 IP를 희생자 IP로 위조한 후 DNS, NTP, Memcached 서버에 대량 질의를 보내 거대한 응답 패킷이 희생자에게 쏟아지도록 유도(DDoS).
- **AI 생성형 위조(Deepfake)** : 최신 음성 복제(Voice Cloning) 및 페이스 스왑 기술을 결합하여 CEO나 가족의 음성/영상을 실시간 위조하는 사회공학적 사기 급증.

## Ⅲ. 위조(Fabrication) 공격의 세부 구성 요소 및 비교 분석

| 비교 항목 | 위조 (Fabrication) | 변조 (Modification) | 가로채기 (Interception) | 가로막기 (Interruption) |
| --- | --- | --- | --- | --- |
| 행위 본질 | 허위 메시지 및 신원을 새로 생성 주입 | 기존의 정상 메시지 내용을 수정/삭제 | 정상 트래픽을 몰래 훔쳐봄 (도청) | 통신 회선이나 자원을 파괴하여 차단 |
| 침해 속성 | 인증성 (Authenticity), 무결성 | 무결성 (Integrity) | 기밀성 (Confidentiality) | 가용성 (Availability) |
| 주요 사례 | ARP 스푸핑, 가짜 송장 발송, 딥페이크 | 파라미터 변조 결제, DB 데이터 변경 | 스니핑(와이어샤크), 패킷 도청 | DDoS 트래픽 공격, 랜섬웨어 파일 파괴 |
| 대표 기술 | 스푸핑, 가짜 트랜잭션 삽입 | 중간자 공격(MITM), 데이터 조작 | 수동적 도청, 트래픽 분석 | 플루딩, 물리적 케이블 절단 |
| 대응 기술 | 상호 인증, 전자서명, DNSSEC | HMAC, 무결성 해시, 블록체인 | 종단간 암호화(TLS), VPN | 이중화 인프라, 안티 DDoS |

- 위조 공격은 무결성과 인증성을 동시에 파괴하여 전체 시스템의 신뢰 기반을 붕괴시키므로, 발신처의 진본성을 암호학적으로 검증하는 제로 트러스트 상호 인증이 필수적임.

## Ⅳ. 위조(Fabrication) 공격의 주요 한계점 및 해결 방안

- **비연결형 프로토콜(UDP)의 원천적 발신지 검증 불가능성** :
  - **한계점** : UDP는 핸드셰이크 없이 패킷을 전송하므로 헤더의 소스 IP를 임의로 조작해도 라우터가 이를 검증하지 않고 목적지로 중계.
  - **해결 방안** : 네트워크 경계 라우터에서 소스 IP의 역방향 라우팅 경로를 검증하는 uRPF(Unicast Reverse Path Forwarding) 필터링 전면 적용.
- **도난당한 유효 인증서/개인키를 악용한 합법적 위조 서명** :
  - **한계점** : 공격자가 엔터프라이즈 사설 CA나 코드 서명(Code Signing) 개인키를 탈취하여 악성코드에 정상 서명할 경우 시스템은 이를 신뢰.
  - **해결 방안** : 개인키를 파일이 아닌 하드웨어 HSM에 격리하고, 인증서 투명성(CT: Certificate Transparency) 로그 모니터링을 통한 이상 발급 즉시 적발.
- **인간의 감각으로 구별 불가능한 고품질 딥페이크 위조** :
  - **한계점** : 실시간 영상 통화에서 경영진의 얼굴과 목소리를 완벽히 위조하여 거액 송금을 요구할 경우 직원의 육안 판단 한계.
  - **해결 방안** : 음성/영상 주파수 대역의 인공 합성 노이즈를 판별하는 멀티모달 포렌식 탐지 AI 도입 및 자금 이체 시 다중 승인 프로세스 강제.

## Ⅴ. 위조(Fabrication) 공격 적용 및 발전을 위한 기술사적 제언

- **DNSSEC 및 RPKI 코어 라우팅 인프라 위조 방어 체계 완비** : 도메인 네임 조회 전 과정에 디지털 서명을 검증하는 DNSSEC과 BGP 라우팅 정보의 출처를 검증하는 RPKI를 전사 네트워크에 필수 도입.
- **이메일 위조 방지 3대 표준(SPF, DKIM, DMARC) 전면 강제** : 사내 도메인을 사칭하는 피싱 메일을 원천 차단하기 위해 SPF IP 검증, DKIM 전자서명, DMARC 차단(p=reject) 정책 전면 적용.
- **제로 트러스트 상호 인증(mTLS) 및 연속적 신원 검증** : 네트워크 위치나 IP 주소를 신뢰하지 않고, 모든 통신 세션마다 X.509 인증서 상호 교환 및 단기 토큰 검증을 수행하는 구조적 전환.
