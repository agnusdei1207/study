## Ⅰ. NIST CSF 2.0 및 신규 거버넌스(Govern) 기능의 개요

- **개념** : 미국 국립표준기술원(NIST)이 전 세계 기업과 기관의 사이버 보안 위험 관리를 위해 제정한 글로벌 표준 프레임워크(Cybersecurity Framework) 2.0 버전으로서, 기존 5대 핵심 기능에 전사적 의사결정과 정책을 총괄하는 '지배/거버넌스(Govern)' 기능을 최상위 축으로 신설한 개정 체계.
- **배경 및 필요성** : 보안이 단순 IT 실무 부서의 기술적 방어에 머무를 경우 경영진의 의사결정 및 전사 비즈니스 리스크와 괴리되는 한계를 극복하고, 공급망 위험과 이사회 수준의 법적 책임을 반영하기 위해 10년 만에 2.0 전면 개정.
- **핵심 목적** : 조직의 비즈니스 전략과 사이버 보안 위험 관리의 일체화, 이사회 및 C-레벨 거버넌스 확립, 6대 핵심 기능을 통한 엔드투엔드 사이버 회복탄력성(Cyber Resilience) 구축.

## Ⅱ. NIST CSF 2.0 및 신규 거버넌스(Govern) 기능의 핵심 아키텍처 및 동작 메커니즘

NIST CSF 2.0은 기존 5대 기능(식별-방어-탐지-대응-복구)을 아우르는 최상위 중앙 통제 축으로 'Govern(거버넌스)'을 추가하여 6개 핵심 기능 체계로 완성됨.

```text
[ NIST CSF 2.0의 6대 핵심 기능 및 거버넌스(Govern) 중심 아키텍처 ]

             +---------------------------------------------------+
             |           ★ GV: Govern (지배 / 거버넌스)          |
             |  - 조직 맥락(Organizational Context) 이해          |
             |  - 리스크 관리 전략 및 리스크 선호도(Appetite) 결정 |
             |  - 사이버보안 역할, 책임 및 권한(RACI) 부여        |
             |  - 전사 정책 수립 및 공급망 리스크 관리(C-SCRM)   |
             +-------------------------┬-------------------------+
                                       │ 전사 정책 및 리스크 지침 하달
         ┌─────────────────────────────┼─────────────────────────────┐
         ▼                             ▼                             ▼
  +---------------+             +---------------+             +---------------+
  | ID: 식별      |             | PR: 방어      |             | DE: 탐지      |
  | (Identify)    |             | (Protect)     |             | (Detect)      |
  | - 자산 관리   |             | - 접근 통제   |             | - 이상 징후   |
  | - 위험 평가   |             | - 데이터 보안 |             | - 보안 모니터링|
  +-------┬-------+             +-------┬-------+             +-------┬-------+
          │                             │                             │
          └─────────────────────────────┼─────────────────────────────┘
                                        │ 침해 발생 시 대응 및 복구 피드백
         ┌──────────────────────────────┴──────────────────────────────┐
         ▼                                                             ▼
  +---------------+                                             +---------------+
  | RS: 대응      |                                             | RC: 복구      |
  | (Respond)     |                                             | (Recover)     |
  | - 사고 분석   |                                             | - 비상 계획   |
  | - 피해 완화   |                                             | - 복원력 개선 |
  +---------------+                                             +---------------+
```

- **Govern (GV, 지배/거버넌스) 신설** : 사이버보안 전략을 전사 비즈니스 목표와 결합하고, 이사회 보고 체계와 공급망 리스크(C-SCRM)를 독립 통제 범주로 격상.
- **Identify (ID, 식별)** : 조직의 물리/소프트웨어 자산, 공급망 파트너, 잠재적 사이버 위험과 취약점을 전사 차원에서 가시화.
- **Protect (PR, 방어)** : 신원 관리 및 접근 통제(IAM), 데이터 보안, 플랫폼 보안 조치를 통해 사이버 공격 표면 최소화.
- **Detect (DE, 탐지)** : SIEM, EDR, 위협 인텔리전스를 활용하여 비인가 접근 및 공격 시도를 실시간 감지.
- **Respond (RS, 대응)** : 침해 발생 시 통제된 플레이북에 따라 시스템을 격리하고 피해 확산을 차단하며 이해관계자 소통.
- **Recover (RC, 복구)** : 불변 백업 및 비즈니스 연속성 계획(BCP)에 입각하여 시스템을 정상 상태로 복원하고 교훈 반영.

## Ⅲ. NIST CSF 2.0 및 신규 거버넌스(Govern) 기능의 세부 구성 요소 및 비교 분석

| 비교 항목 | NIST CSF 1.1 (기존) | NIST CSF 2.0 (개정) | 실무 엔지니어링 시사점 |
| --- | --- | --- | --- |
| 기본 프레임워크 | 5대 기능 (ID, PR, DE, RS, RC) | 6대 기능 (GV 신설 + 기존 5대 기능) | 거버넌스가 5대 기능의 방향성을 통제 |
| 적용 대상 | 미국 중요 국가 기반시설 중심 | 모든 규모(대/중/소), 모든 산업군 포괄 | 공공뿐 아니라 민간 엔터프라이즈 범용 가이드 |
| 공급망 보안 (C-SCRM) | 식별(ID) 기능의 하위 항목 일부 | 거버넌스(GV) 내 핵심 범주로 독립 격상 | 협력사/오픈소스 SBOM 보안 감사 의무화 |
| 이사회 책임 | 명시적 언급 부족 (CISO/실무진 중심) | 경영진 및 이사회의 실질적 감독 책임 규정 | 사이버 리스크의 재무적 영향 평가(FAIR) 연계 |
| 프로파일 및 구현 계층 | Current/Target 프로파일 | Community 프로파일 및 세부 액션 가이드 | 기업 상황별 맞춤형 보안 성숙도 매핑 |

- CSF 2.0의 본질은 보안을 기술 엔지니어링의 영역에서 '경영 거버넌스(Governance)'의 영역으로 끌어올린 것으로, C-레벨의 의사결정과 예산 배분이 전제되지 않으면 5대 기술 기능이 무용지물임을 천명함.

## Ⅳ. NIST CSF 2.0 및 신규 거버넌스(Govern) 기능의 주요 한계점 및 해결 방안

- **중소기업의 거버넌스(Govern) 조직 및 리소스 구축 역량 부족** :
  - **한계점** : 전담 CISO나 이사회 내 보안위원회를 둘 수 없는 중소기업에게 CSF 2.0의 거버넌스 요건은 지나치게 이상적이고 실행 난항.
  - **해결 방안** : NIST가 함께 배포한 'Quick Start Guide for Small Businesses'를 적용하고 vCISO 및 보안 파트너십을 통한 단계적 내재화.
- **기술적 지표와 비즈니스 리스크 간의 언어적 단절** :
  - **한계점** : 보안팀의 취약점 수치(CVE, CVSS)를 이사회나 경영진이 비즈니스 손실 금액으로 이해하지 못해 예산 편성 거부.
  - **해결 방안** : FAIR(Factor Analysis of Information Risk) 정량 모델을 연계하여 사이버 위험을 예상 손실액(Loss Exposure)으로 환산 보고.
- **글로벌 공급망(C-SCRM) 통제의 실질적 강제력 한계** :
  - **한계점** : 수백 개의 협력사 및 해외 SaaS 공급자에 대해 보안 감사를 수행하거나 CSF 준수를 강제할 법적 권한 부재.
  - **해결 방안** : 공급업체 계약서(SLA)에 보안 평가 기준 명시, 서드파티 위험 관리(TPRM) 플랫폼을 통한 실시간 신용/보안 평가 연동.

## Ⅴ. NIST CSF 2.0 및 신규 거버넌스(Govern) 기능 적용 및 발전을 위한 기술사적 제언

- **ISMS-P 관리체계 수립 영역과 CSF 2.0 Govern의 통합 매핑** : 국내 ISMS-P 인증 준비 시 CSF 2.0의 거버넌스 지표를 연계하여 글로벌 수준의 보안 체계로 동시 격상.
- **사이버보안 공급망 위험 관리(C-SCRM) 전담 체계 신설** : 구매 및 조달 프로세스에 보안 검증을 의무화하고 협력사 소프트웨어 납품 시 SBOM 제출을 조건화.
- **전사 사이버 복원력(Cyber Resilience) KPI 수립** : 방어율 중심의 지표에서 벗어나, 침해 시 정상 비즈니스 복구 시간(MTTR)과 데이터 손실률(RPO)을 이사회 핵심 지표로 관리.
