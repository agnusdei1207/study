## 30초 인출

- **본질:** 정보보호 정책은 조직이 어떤 정보를 어떤 책임과 원칙으로 보호할지 정하는 최상위 관리 기준.
- **메커니즘:** 보호 목적·범위·책임 결정 → 세부 표준·절차로 구체화 → 운영·점검 결과를 정책에 반영.
- **핵심:** 경영진 승인, 조직 적용 범위, 담당 역할, 정책과 실제 통제의 일치.

<details>
<summary>핵심 용어</summary>

- **정보보호 정책**: 조직의 정보 보호 목적·범위·책임과 기본 규칙을 정하는 상위 문서.
- **표준**: 정책을 일관되게 실행하기 위한 구체적인 기술·운영 기준.
- **절차**: 표준·정책을 업무에서 수행하는 순서와 담당을 정한 지침.
- **ISMS(Information Security Management System)**: 조직의 정보보호 위험과 통제를 지속적으로 관리하는 체계.
- **CISO(Chief Information Security Officer)**: 조직의 정보보호 업무를 총괄하는 책임자.

## 1교시 10점 답안

### Ⅰ. 정의·목적

| 구분 | 내용 |
|---|---|
| 정의 | **정보보호 정책**은 조직의 정보 보호 목적·범위·책임과 기본 규칙을 정하는 상위 기준 |
| 목적 | 위험에 맞는 통제를 조직 전체에 일관되게 적용 |

### Ⅱ. 문서 체계와 운영

```text
정보보호 정책 ─ 무엇을·왜 보호하는가
  ├─ 표준 ─ 공통으로 지킬 기준
  ├─ 지침 ─ 상황별 권고·해석
  └─ 절차 ─ 누가·언제·어떻게 수행하는가
```

| 관리 지점 | 확인 내용 |
|---|---|
| 승인·배포 | 경영진 승인, 적용 대상 공유 |
| 실행 | 기준·절차·시스템 설정의 연결 |
| 점검 | 사고·감사·환경 변화 반영 |

**제언:** 정책 조항마다 실행 기준·담당자·점검 증적을 연결.

## 2~4교시 25점 답안

## Ⅰ. 정보보호 정책의 정의와 목적

| 구분 | 내용 |
|---|---|
| 정의 | **정보보호 정책**은 조직의 정보 보호 목적·범위·책임과 기본 규칙을 정하는 상위 기준 |
| 목적 | 위험에 맞는 통제를 조직 전체에 일관되게 적용 |

정책은 보호 목표와 책임을 밝히고 세부 기술 설정은 표준·절차에서 구체화.

## Ⅱ. 정책·표준·절차의 관계

```text
정보보호 정책 ─ 무엇을·왜 보호하는가
  ├─ 표준 ─ 공통으로 지킬 기준
  ├─ 지침 ─ 상황별 권고·해석
  └─ 절차 ─ 누가·언제·어떻게 수행하는가
```

| 문서 | 예 | 적용 방식 |
|---|---|---|
| 정책 | 접근권한은 업무상 필요 범위로 제한 | 조직의 기본 요구 |
| 표준 | 관리자 계정의 인증·기록 기준 | 공통 설정 |
| 절차 | 권한 신청·승인·회수 순서 | 담당자의 실행 |
| 지침 | 예외 상황의 적용 방법 | 해석·권고 |

## Ⅲ. 수립과 승인

```text
보호 대상·법규·위험 파악
    ↓ 보호 목표·책임 결정
정책안 작성
    ↓ 경영진 승인·배포
표준·절차에 반영
```

| 수립 항목 | 확인 질문 |
|---|---|
| 범위 | 어떤 정보·시스템·인력에 적용하는가 |
| 책임 | 승인·실행·점검 담당은 누구인가 |
| 예외 | 허용 사유·기간·승인권자는 누구인가 |
| 우선순위 | 위험 수준과 통제 비용은 맞는가 |

## Ⅳ. 실행과 개선

```text
정책 조항
    ↓ 표준·절차·교육
기술·관리 통제 적용
    ↓ 점검·감사·사고 분석
정책·기준 개정
```

| 점검 대상 | 증적 |
|---|---|
| 계정·권한 | 승인·회수 이력 |
| 시스템 설정 | 기준 준수 결과 |
| 교육 | 대상자·이수 내역 |
| 예외 | 승인 기간·보완 통제 |

## Ⅴ. 한계와 제언

| 한계 | 대응 |
|---|---|
| 정책 문구만 있고 실행 기준·담당이 없으면 준수 여부 판단 곤란 | 조항별 표준·절차·담당·증적을 한 체계로 관리 |
| 규제·시스템 변화가 정책에 늦게 반영 | 변경·사고·감사 결과를 개정 조건으로 명시 |
