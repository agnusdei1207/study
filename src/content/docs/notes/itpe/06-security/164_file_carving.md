## 지식 로드맵 내 현재 위치

- 정보보안 → 디지털 포렌식 → 데이터 복구 및 복원 → 파일카빙(File Carving)

```text
[비할당 공간 (Unallocated Space)] ──(메타데이터 손상/부재)──> [원시 바이너리 스트림]
                                                                     │
                                      ├── 1세대: 헤더/푸터 매칭 (Header-Footer)
                                      ├── 2세대: 파일 내부 구조 및 크기 파싱
                                      └── 3세대: 조각화 복원 (Smart / Bifragment Carving)
                                                                     │
                                                                     ▼
                                             [무결성 검증 및 복원 파일 추출]
```

## 30초 인출

- **본질:** 파일시스템의 디렉터리 엔트리나 MFT 등 메타데이터가 파괴된 상태에서, 비할당 영역의 원시 바이트 스트림 내 파일 매직 넘버와 포맷 구조를 추적하여 파일을 복원하는 포렌식 추출 기술.
- **메커니즘:** 원시 디스크 섹터 순차 스캔 → 파일 시작 시그니처(헤더) 탐지 → 종료 시그니처(푸터) 또는 내부 길이 필드 계산 → 파일 바이트 카빙 및 파서 렌더링 검증.
- **통찰:** 디스크 단편화(Fragmentation)가 발생한 비연속 클러스터 환경에서는 단순 헤더-푸터 매칭 시 오탐과 파손이 급증하므로, 청크 유효성과 바이트 엔트로피 연속성을 추적하는 스마트 카빙(Smart Carving) 적용 필수.

## 2~4교시 예상문제 (25점)

> 파일시스템 메타데이터가 손상된 환경에서 활용되는 파일카빙(File Carving)의 동작 원리와 세대별 발전 과정을 설명하고, 비연속 단편화(Fragmentation) 파일 복원을 위한 스마트 카빙 알고리즘 및 한계 극복 방안을 제시하시오. (25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 파일시스템의 디렉터리 테이블, MFT, Inode 등 파일 메타데이터를 참조하지 않고, 저장매체의 비할당 영역(Unallocated Space) 원시 바이너리 데이터에서 파일 고유의 시그니처와 구조를 기반으로 파일을 추출·복원하는 포렌식 기술 |
| 목적 | 고의적 포맷, 파일 완전 삭제, 파일시스템 손상 환경에서 삭제된 증거 파일(문서, 사진, 영상 등)을 물리적 비트스트림으로부터 복구하여 범죄 입증 증거 확보 |

- 일반적인 파일 복구(Undelete)가 메타데이터의 삭제 플래그를 해제하는 방식인 반면, 파일카빙은 데이터 페이로드 자체를 조각조각 조각질(Carve)하듯 도려내어 복원.

## Ⅱ. 파일카빙의 핵심 특징 및 세대별 발전 단계

### 1. 파일카빙의 핵심 특징

| 특징 | 설명 | 포렌식 분석 관점 |
|---|---|---|
| 메타데이터 비의존성 | 파티션 테이블/MFT 파손 무관 | OS 파일시스템 구조가 초기화되거나 변조된 상태에서도 페이로드 복원 가능 |
| 매직 넘버 기반 식별 | 파일 포맷별 고유 바이트 시그니처 | JPEG(`FF D8 FF`), PDF(`25 50 44 46`), ZIP/Office(`50 4B 03 04`) 탐색 |
| 속성 정보 소실 | 원래의 파일명, 폴더 경로, MAC 시간 소실 | 카빙된 파일은 임의의 번호(`file001.jpg`)로 명명되며 타임라인과의 교차 검증 필요 |
| 오탐 및 왜곡 가능성 | 헤더와 무관한 가짜 푸터 오인 | 다른 파일의 파편이 섞이거나 비연속 저장된 경우 불완전한 파손 파일 생성 |

### 2. 파일카빙 기술의 세대별 발전

```text
[1세대: 단순 시그니처 카빙] ──> [2세대: 구조/크기 기반 카빙] ──> [3세대: 고급 스마트 카빙]
- Header / Footer 매칭          - 내부 메타 필드 파싱            - 비연속 조각화(Fragmentation) 재조합
- 고정 최대 크기 일괄 추출      - 청크(Chunk) 구조 기반 검증      - 통계적 바이트 연속성 / 엔트로피
- Scalpel, Foremost 초기 모델   - PhotoRec, Defraser             - Graph 기반 최단 경로 / Smart Carving
```

---

## Ⅲ. 파일카빙 4단계 프로세스 및 조각화 복원 아키텍처

### 1. 파일카빙 표준 처리 절차

```text
+-----------------------------------------------------------------------------------------+
|                                    파일카빙 4단계 프로세스                                |
+-----------------------------------------------------------------------------------------+
  [1단계: 비할당 영역 스캔] ──> [2단계: 시그니처 매칭] ──> [3단계: 경계/구조 결정] ──> [4단계: 무결성 검증]
  - 디스크 비트스트림 덤프      - 매직 넘버(Header) 검색   - Footer 시그니처 식별     - 이미지/문서 파서 구동
  - 파일시스템 할당 블록 배제   - 파일 포맷 후보군 분류    - 내부 청크/길이 계산      - 렌더링 및 해시 산출
  - 원시 바이트 스트림 정렬     - False Positive 필터링   - 오프셋 단위 블록 추출    - 증거 유효성 확정
+-----------------------------------------------------------------------------------------+
```

### 2. 비연속 단편화(Fragmentation) 스마트 카빙 아키텍처

```text
[비할당 공간 디스크 블록]
  Block A (JPEG Header) ──> Block B (무관한 텍스트) ──> Block C (JPEG Payload) ──> Block D (JPEG Footer)
       │                                                      ▲                         ▲
       │                  [스마트 카빙 (Smart Carving) 엔진]    │                         │
       ├─────────────────> 1. Block B 배제 (엔트로피 불일치)──┘                         │
       └─────────────────> 2. Block A + Block C + Block D 재조합 (디코더 파싱 검증) ────┘
                                        │
                                        ▼
                             [온전한 JPEG 파일 복원 완료]
```

## Ⅳ. 파일카빙 기법 4종 비교

### 1. 주요 카빙 알고리즘 비교

| 카빙 기법 | 동작 원리 | 장점 | 단점 | 대표 포맷 |
|---|---|---|---|---|
| 헤더-푸터 카빙 (Header-Footer) | 시작 시그니처부터 종료 시그니처까지의 바이트를 통째로 추출 | 알고리즘이 단순하고 고속 처리 가능 | 푸터가 없거나 단편화 발생 시 쓰레기 데이터 삽입 및 오탐 급증 | JPEG, GIF, PDF |
| 파일 크기 기반 카빙 (Size-based) | 헤더 내부의 길이 필드(File Size)를 읽어 명시된 바이트만큼 추출 | 푸터가 없는 포맷도 정확한 경계 추출 가능 | 길이 필드가 변조되었거나 파일이 중간에 잘린 경우 추출 실패 | BMP, WAV, AVI |
| 파일 구조 기반 카빙 (Structure-based) | 포맷 고유의 청크/태그 구조(TLV: Tag-Length-Value)를 연속 파싱 | 내부 논리 구조 무결성 보장, 압축 블록 복원율 우수 | 포맷별 파서 구현 복잡도가 높고 연산 오버헤드 큼 | PNG(IHDR/IDAT), ZIP/DOCX |
| 스마트 카빙 (Smart / Graph-based) | 블록 간 바이트 유사도, 엔트로피, 언어 모델, 디코딩 연속성을 추적하여 조각 재조합 | 2개 이상의 파편으로 쪼개진 단편화 파일 복원 가능 | 연산 복잡도 $O(N^2)$ 이상 폭증으로 대용량 디스크 분석 시 성능 저하 | 고해상도 영상, 대용량 DB 파일 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 디스크 사용량이 많은 환경에서 고도로 단편화(Fragmented)된 파일의 경우 블록 조합의 경우의 수가 기하급수적으로 폭증하여 복원 지연 | 파일 헤더의 양자화 테이블 및 예측 오차 연속성을 평가하는 휴리스틱 그래프 최적화 알고리즘과 GPU 가속 병렬 연산 엔진 적용 |
| SSD의 TRIM 명령 및 백그라운드 가비지 컬렉션(GC) 동작으로 비할당 영역이 0x00으로 자동 소거되어 카빙 대상 원시 데이터 소멸 | 사고 인지 즉시 전원 강제 차단 후 쓰기 방지 장치 하에서 칩오프(Chip-off) 또는 NAND 플래시 컨트롤러 디버그 포트 직접 덤프 |
| 원본 파일명, 디렉터리 경로, 생성/수정/접근(MAC) 타임스탬프가 완전 소실되어 법정에서 행위 주체 및 작성 시점 입증 한계 | NTFS $LogFile, $UsnJrnl 저널 로그 및 웹 브라우저 다운로드 히스토리, 윈도우 프리페치 파일과 카빙 결과물의 해시값 결합 분석 |

## Ⅵ. 제언

### 1. 차세대 AI 기반 스마트 파일카빙 파이프라인

```text
[비할당 공간 덤프] ──> [딥러닝 블록 분류기 (CNN/Transformer)] ──> [파일 타입별 블록 군집화]
                                                                        │
                                                                        ▼
                                                   [시맨틱 파서 및 조각화 경로 탐색 (Beam Search)]
                                                                        │
                                                                        ▼
                                                   [자동화 렌더링 무결성 검증 (Headless Viewer)]
```

### 2. 포렌식 복구 기법별 특성 및 우선순위 비교 평가

| 복구 기법 | 복구 신뢰도 | 메타데이터 보존 | 처리 속도 | 적용 시점 |
|---|---|---|---|---|
| 파일시스템 레벨 복구 (Undelete) | 최고 | 완벽 보존 | 즉시 완료 | 단순 삭제 직후, MFT가 손상되지 않은 경우 (1차) |
| 저널/섀도 복사본 복원 (VSS) | 최상 | 완벽 보존 | 매우 빠름 | 볼륨 섀도 복사본 스냅샷이 존재하는 경우 (2차) |
| 시그니처 기반 단순 카빙 | 보통 | 소실 (내용만 복원) | 빠름 | 메타데이터 파손 시 대량 연속 블록 복원 (3차) |
| 스마트 조각화 카빙 (Fragmented) | 상 | 소실 (내용만 복원) | 느림 (고연산) | 핵심 증거 파일이 단편화되어 파손된 경우 (최종) |

- 파일카빙은 메타데이터가 파괴된 극단적 상황에서 최후의 증거를 건져내는 핵심 기법이므로, 단순 문자열 검색에 의존하지 않고 스마트 카빙과 타임라인 아티팩트의 교차 입증 체계 병행 필수.
