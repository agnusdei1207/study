## 연관 키워드

- 파일 카빙(File Carving), 시그니처 기반 카빙, 구조 기반 카빙, 스마트 카빙, 매직 넘버
- 비할당 영역, 파편화, 헤더·푸터, 파일 시스템 메타데이터, MFT, 디지털 포렌식, 연계보관성, 해시

## Ⅰ. 파일카빙(File Carving)의 개요

- 핵심 요약 : 파일 시스템 메타데이터가 사라진 상태에서 원시 데이터의 시그니처와 내부 구조로 파일을 복원하는 포렌식 기법.
- 개념 : 파일 시스템의 디렉터리 정보(FAT(File Allocation Table) 엔트리, NTFS **MFT**(Master File Table), EXT Inode)가 손상되거나 삭제되어 유실된 상태에서, 저장 매체의 **비할당 영역** (Unallocated Space)과 원시 디스크 이미지에서 **매직 넘버** (Magic Number, 헤더·푸터 시그니처)를 찾아 원본 파일을 복원하는 **파일 카빙** (File Carving).
- 배경 및 필요성 : 피의자가 증거 인멸을 위해 파티션을 포맷하거나 MFT를 파괴하면 파일 시스템 기반 복구 도구가 무력화되므로, 메타데이터에 의존하지 않는 저수준 복구가 필요함.
- 주요 목적 : 비할당 영역에서 사진, 동영상, 문서, 이메일, 데이터베이스 같은 결정적 증거 파일을 원형대로 추출.

## Ⅱ. 파일카빙(File Carving)의 특징 및 장점

- 핵심 요약 : 메타데이터 독립성과 시그니처 검색이 메타데이터 손상 상황에서도 증거를 살리는 장점으로 이어지는 방식.

1. 시그니처 기반 (Header-Footer Carving) : 헤더 매직 넘버와 푸터 시그니처 사이의 바이트를 추출 → 메타데이터가 없어도 JPEG, PDF 같은 포맷을 복원.
2. 파일 크기 기반 (File Size Carving) : 푸터가 없는 포맷은 헤더에 적힌 전체 크기 값을 읽어 그만큼 추출 → 종료 지점이 불명확한 포맷도 복원.
3. 구조 기반 (Structure-based Carving) : 문서 컨테이너(DOCX, XLSX 등)의 내부 디렉터리와 순환 중복 검사(CRC32, Cyclic Redundancy Check) 값을 검증 → 복원 결과의 유효성 확보.
4. 스마트 카빙 (Smart Carving) : 엔트로피 분석과 디코딩 검사로 흩어진 파편을 재조합 → 단편화된 파일의 복구율 향상.

## Ⅲ. 파일카빙(File Carving)의 구조 (흐름)

- 핵심 요약 : 헤더와 푸터의 경계를 찾아 연속 구간을 잘라내는 기본 흐름과, 단편화된 파일을 구조 검증으로 이어 붙이는 확장 흐름의 이중 구조.

```text
[ 비할당 영역 원시 바이트 스트림 ]
              ↓
 헤더 시그니처 발견 (FF D8 FF)
              ↓
 푸터 시그니처 탐색 (FF D9)
              ↓
 헤더~푸터 사이 바이트 추출 → 파일 복원
```

```text
[ 단편화된 파일 A ]
 클러스터 1 : A의 헤더
 클러스터 2 : 파일 B의 조각 (혼입)
 클러스터 3 : A의 나머지 데이터와 푸터
              ↓
 구조 검증으로 클러스터 1과 3을 결합
              ↓
 파일 A 복원
```

## Ⅳ. 파일카빙(File Carving)과 복구 기법의 비교

- 핵심 요약 : 시그니처 카빙은 빠르지만 파편화에 약하고, 파일 시스템 기반 복구는 정확하지만 메타데이터 손상에 취약한 상보적 관계.

| 비교 항목 | 시그니처 기반 카빙 | 구조 기반 카빙 | 파일 시스템 기반 복구 |
| --- | --- | --- | --- |
| 복구 근거 | 헤더·푸터 매직 넘버 검색 | 포맷 내부 명세와 체크섬 파싱 | MFT, FAT, Inode 메타데이터 참조 |
| 메타데이터 의존 | 없음 | 없음 | 절대적 (메타데이터 손상 시 불가) |
| 파편화 파일 복구 | 타 파일 혼입으로 실패 가능 | 유효성 검증 기반 재조합 가능 | 클러스터 목록이 있으면 복구 가능 |
| 복원 정보 한계 | 원본 파일명과 시간 정보 복구 불가 | 원본 파일명 복구 불가 | 파일명, 경로, 시간 정보 복원 가능 |
| 연산 부하 | 낮음 | 높음 (압축 해제와 포맷 검사) | 낮음 (포인터 조회) |

- 선택 기준 : 파일 시스템이 온전하면 메타데이터 기반 복구를, 파괴되었으면 시그니처 카빙을 먼저 쓰고 구조 검증으로 결과를 보강.

## Ⅴ. 파일카빙(File Carving)의 한계와 방안

- 핵심 요약 : 파편화, 메타데이터 소실, SSD의 0 초기화가 복구율을 떨어뜨리므로 알고리즘 보강과 하드웨어 수단을 병행.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 심한 파편화 파일의 복구율 저하 | 대용량 동영상, 데이터베이스(DB, Database) 파일이 불연속 클러스터로 쪼개져 중간에 타 파일이 섞여 재생 불가 | 이중 분할(Bifragment Gap Carving) 기법과 디코더 검증 자동화 | 복구 파일의 재생 성공률 |
| 파일명과 시간 정보 소실 | 'File0001.jpg' 같은 임의 이름, 생성·수정 시각 입증 곤란 | 내부 Exif(Exchangeable image file format) 메타데이터와 문서 XML(Extensible Markup Language)의 2차 파싱으로 증거 보강 | 메타데이터 보강 비율 |
| SSD TRIM에 의한 0 초기화 | 삭제 영역이 플래시 셀 단위로 지워져 카빙 대상이 없음 | 웨어 레벨링으로 남은 예비 영역을 칩오프(Chip-off) 방식으로 추출 | 칩오프 수행 건수 |

## Ⅵ. 파일카빙(File Carving)에 대한 기술사적 제언

- 핵심 요약 : 카빙 엔진의 분류 능력을 높이고, 산출물의 무결성을 증거 절차에 자동으로 묶는 운영 체계가 필요함.

1. 헤더와 푸터가 없는 암호화 파일이나 파편 블록의 종류를 가려내기 위해, 바이트 패턴을 학습한 분류 모델을 카빙 엔진에 결합하는 연구와 도입이 필요하다.
2. 대용량 디스크 이미지는 여러 카빙 규칙을 병렬로 처리하는 분산 파이프라인으로 돌려 수사 시간을 줄여야 한다.
3. 추출된 모든 파일에는 추출 시각과 해시값(SHA(Secure Hash Algorithm)-256)을 즉시 기록하고, 이를 연계보관성 문서에 자동 등재하여 법정 증거 능력을 뒷받침해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 파일 카빙은 파일 시스템이 파괴된 최악의 조건에서 증거를 살려내는 마지막 수단.
- 시그니처 기반 탐색과 구조 기반 검증을 함께 쓰고 산출물의 무결성을 기록하는 것이 증거 가치를 지키는 조건임.
