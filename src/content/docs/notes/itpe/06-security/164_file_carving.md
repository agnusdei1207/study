## Ⅰ. 파일카빙(File Carving)의 개요

- 개념 : 파일 시스템의 메타데이터(FAT 디렉토리 엔트리, NTFS MFT, EXT Inode)가 손상, 포맷, 고의적 삭제로 인해 완전히 유실된 상태에서, 저장 매체의 비할당 영역(Unallocated Space)이나 원시 디스크 덤프 이미지에서 파일 고유의 매직 넘버(Header/Footer Signature)와 내부 구조적 특징을 분석하여 원본 파일을 온전히 복원해 내는 고급 디지털 포렌식 복구 기술.
- 배경 및 필요성 : 사이버 범죄 피의자들은 증거 인멸을 위해 파티션을 강제 포맷하거나 MFT 테이블을 고의로 파괴하여 일반적인 파일 시스템 기반 복구 도구를 무력화하므로, 메타데이터에 의존하지 않는 저수준 복구 기법이 요구됨.
- 핵심 목적 : 삭제되거나 파손된 디스크 비할당 영역에서 범죄와 관련된 결정적 증거 파일(사진, 동영상, 문서, 이메일, 데이터베이스)을 원형 그대로 추출 및 복원.

## Ⅱ. 파일카빙(File Carving)의 핵심 아키텍처 및 동작 메커니즘

파일 카빙은 단순 시그니처 기반(Header-Footer), 파일 크기 기반, 내부 구조 기반(Semantic Structure), 파편화 복원(Fragmented Carving: 스마트 카빙)의 단계적 정밀 분석 기법으로 구성됨.

```text
[ 파일 카빙(File Carving) 동작 메커니즘 및 연속/파편화 블록 복원 ]

 [ 비할당 영역 (Unallocated Disk Sectors) ]
  Sector 100               Sector 108                 Sector 115
 +------------------------+--------------------------+-----------------------+
 | [JPEG 헤더 시그니처]    | [JPEG 이미지 압축 데이터] | [JPEG 푸터 시그니처]  |
 | 0xFF 0xD8 0xFF 0xE0    | (Exif 메타데이터, 픽셀)  | 0xFF 0xD9             |
 +------------------------+--------------------------+-----------------------+
  * 헤더(FF D8) 발견 -> 푸터(FF D9) 탐색 -> 사이의 모든 바이트 추출 = 완벽 복원!

 =============================================================================
 [ 파편화된 파일 카빙 (Fragmented Smart Carving: 이중 분할) ]

  [ Cluster 1: 파일 A 헤더 ] ---> [ Cluster 2: 파일 B 파편 (타 파일 끼어듦) ]
                                 |
                                 v (연속 추출 시 이미지 깨짐 발생!)
                                 +-----------------------+
                                                         v
                                  [ Cluster 3: 파일 A 푸터 (불연속 지점) ]
  * 해결: 파일 포맷 구조 검증(JPEG Restart Marker 추적, 통계적 엔트로피 분석)
  * Cluster 1과 Cluster 3을 정밀 결합하여 원본 파일 A 정상 복원!
```

- **헤더-푸터 카빙(Header-Footer Carving)** : 파일 시작을 알리는 헤더 매직 넘버(예: JPEG 'FF D8 FF', PDF '%PDF')와 끝을 알리는 푸터 시그니처('FF D9', '%%EOF')를 검색하여 그 사이의 바이트를 통째로 추출.
- **파일 크기 기반 카빙(File Size Carving)** : 푸터 시그니처가 존재하지 않는 파일 포맷(BMP, WAV, ZIP 등)의 경우, 파일 헤더 내부의 메타데이터 필드에 명시된 'Total File Size' 값을 파싱하여 해당 크기만큼 정확히 추출.
- **구조 기반 카빙(Structure-based Carving)** : 문서 파일(DOCX, XLSX 등 ZIP 기반 컨테이너)의 내부 디렉토리 엔트리와 압축 블록 체크섬(CRC32)을 파싱하여 파일의 내부 유효성을 검증하며 복원.
- **스마트 카빙(Smart Carving / Fragmented Carving)** : 디스크 단편화로 인해 파일 데이터가 비연속적인 클러스터로 쪼개져 분산되었을 때, 엔트로피 분석 및 디코딩 유효성 검사를 통해 흩어진 파편들을 올바른 순서로 재조합.

## Ⅲ. 파일카빙(File Carving)의 세부 구성 요소 및 비교 분석

| 비교 항목 | **시그니처 기반 카빙** | **구조 기반 카빙** (Semantic) | **파일 시스템 기반 복구** |
| --- | --- | --- | --- |
| 복구 기반 | 헤더 및 푸터 매직 넘버 검색 | 파일 포맷 내부 명세 및 체크섬 파싱 | MFT, FAT, Inode 메타데이터 참조 |
| 메타데이터 의존 | 완전 독립 (메타데이터 불필요) | 완전 독립 (메타데이터 불필요) | 절대적 의존 (MFT 손상 시 불가) |
| 파편화 파일 복구 | 실패 확률 높음 (타 파일 혼입) | 성공 가능 (유효성 검증 재조합) | 완벽 성공 (클러스터 런 목록 존재) |
| 복원 정보 한계 | 원본 파일명, 수정시간(MAC) 복구 불가 | 원본 파일명 복구 불가 (내부 제목 가능) | 원본 파일명, 경로, 생성시간 완벽 복원 |
| 연산 부하 | 낮음 (단순 바이트 시그니처 매칭) | 높음 (압축 해제 및 포맷 유효성 검사) | 극도로 낮음 (메타데이터 포인터 조회) |

- 파일 카빙은 파일 시스템이 파괴된 극한의 환경에서 최종 증거를 추출하는 핵심 수단이나, 파편화 극복을 위한 AI 및 시맨틱 기반 스마트 카빙 기술의 병행이 필수적임.

## Ⅳ. 파일카빙(File Carving)의 주요 한계점 및 해결 방안

- 비연속적으로 심하게 파편화된(Fragmented) 대용량 파일의 복구율 급감 :
  - 한계점 : 동영상이나 대용량 DB 파일이 수십 개의 불연속 클러스터로 쪼개져 분산된 경우 단순 카빙 적용 시 중간에 타 파일이 섞여 파일 재생 불가.
  - 해결 방안 : 파일 포맷의 내부 문맥(Context)을 분석하는 이중 분할 알고리즘(Bifragment Gap Carving) 및 디코더 테스트 자동화.
- 원본 파일명 및 타임스탬프(MAC 시간) 증거 가치 상실 :
  - 한계점 : 메타데이터가 없으므로 카빙된 파일은 'File0001.jpg'와 같이 임의 명칭으로 복원되며 정확한 생성/수정 일시 입증 난제.
  - 해결 방안 : 파일 내부의 Exif 메타데이터(카메라 모델, 촬영 일시, GPS 좌표)나 오피스 문서 내부 메타데이터 XML을 2차 파싱하여 증거 보강.
- SSD TRIM 명령어에 의한 비할당 블록 0 초기화(Zero-filling) :
  - 한계점 : SSD에서 삭제된 비할당 영역은 운영체제 TRIM 신호로 인해 플래시 메모리 셀이 이미 0으로 지워져 카빙 대상 바이트 자체가 부재.
  - 해결 방안 : 웨어 레벨링(Wear Leveling)으로 인해 아직 지워지지 않은 예비 영역(Over-provisioning)을 추출하는 칩오프(Chip-off) 하드웨어 포렌식 병행.

## Ⅴ. 파일카빙(File Carving) 적용 및 발전을 위한 기술사적 제언

- 딥러닝 기반 데이터 엔트로피 및 바이트 패턴 카빙 엔진 도입 : 헤더나 푸터가 없는 암호화 파일 및 파편화 블록의 데이터 타입을 분류하기 위해 딥러닝(CNN/Transformer) 기반의 바이트 스트림 분류기 구축.
- 포렌식 전용 오픈소스 카빙 도구(Scalpel, Foremost) 파이프라인 자동화 : 대용량 디스크 이미지 유입 시 다양한 카빙 룰셋을 병렬 분산(Spark/Hadoop) 처리하여 수 시간 내 전수 복원.
- 법정 증거 능력을 위한 카빙 산출물 무결성 해시(SHA-256) 자동 검증 : 카빙된 모든 파일에 대해 추출 즉시 타임스탬프와 SHA-256 해시를 생성하고 수사관의 연계보관성(Chain of Custody) 문서에 자동 등재.
