## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 내용 |
|---|---|
| 정의 | **파일카빙(File Carving)** 은 파일시스템 메타데이터 없이 원시 데이터의 형식·구조 단서로 파일 내용을 추출하는 기법 |
| 목적 | 삭제·손상된 파일의 잔존 내용 조사 |

파일카빙은 원시 데이터에서 파일 형식·내용 단서를 검색하는 방법이다. 파일시스템 메타데이터가 손상되거나 없는 영역의 분석에 쓸 수 있으나, 정상 파일 복구나 모든 삭제 데이터 복원을 보장하지 않는다.

| 분석 상황 | 카빙의 역할 |
|---|---|
| 파일시스템 메타데이터가 없거나 손상됨 | 데이터 내용에서 파일 후보 추출 |
| 삭제 흔적·비할당 영역 분석 | 남아 있는 데이터에서 형식 단서 확인 |
| 파일시스템 정보가 보존됨 | 메타데이터 기반 복구와 함께 교차검증 |

## Ⅱ. 후보 탐색과 추출 원리

단순 카빙은 파일 시작·끝 시그니처를 단서로 후보 구간을 정한다. 다만 모든 파일 형식에 고유한 푸터가 있는 것은 아니며, 내부 길이·청크·컨테이너 구조를 함께 해석해야 하는 형식도 있다.

```text
저장매체 이미지·원시 데이터
    ↓
형식 시그니처 탐색 → 후보 구간 구성
    ↓
파일 내부 구조 검증
  ├─ 유효 → 파일·부분 조각 추출
  └─ 무효 → 오탐 후보 제외
```

## Ⅲ. 카빙 방법과 선택 기준

카빙은 파일 형식과 증거 상태에 따라 여러 단서를 사용한다. 특정 알고리즘 하나가 모든 포맷과 단편화에 적합하지 않다.

| 방법 | 사용하는 단서 | 주요 제약 |
|---|---|---|
| 헤더·푸터 기반 | 파일 시작·끝 시그니처 | 푸터가 없거나 중복되면 경계 판단이 어려움 |
| 크기 필드 기반 | 파일 헤더·내부에 기록된 길이 | 길이 필드의 위치·의미를 형식별로 알아야 함 |
| 구조 기반 | 청크·인덱스·컨테이너 구조 | 압축·손상·중첩구조에 따라 복구 복잡 |
| 단편화 분석 | 조각 경계·포맷 연속성·인접 블록 단서 | 후보 조합이 많고 정확한 원래 순서를 보장하기 어려움 |

### 단편화와 결과 검증

단편화된 파일은 시작 시그니처 다음 데이터를 단순히 연속 추출해도 원래 파일 내용이 아닐 수 있다. 결과가 구조적으로 열리는지 확인하고, 메타데이터·시간정보·다른 증거와 대조한다.

| 한계 | 검증 방식 |
|---|---|
| 단편화로 인해 무관한 바이트가 함께 추출 | 파일 형식 파서·내부 구조 검증, 대체 조각 여부 확인 |
| 헤더·푸터만 일치해 오탐 발생 | MIME·내부 필드·압축 해제·렌더링 등 형식별 검증 |
| 파일명·경로·원래 시간정보 소실 | 파일시스템 메타데이터·로그·타임라인에서 별도 확인 |
| 덮어쓰기로 일부 데이터만 남음 | 복구된 구간·손상 정도를 표시하고 완전 복구로 과장하지 않음 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 카빙 도구의 성능은 파일 형식·단편화·손상 정도에 따라 달라 제품 설명만으로 적합성을 판단하기 어렵다. | 실제 취급 포맷과 단편화 조건을 반영한 기준 이미지 묶음을 만들고, 도구·버전별 복구 범위와 오탐을 비교해 분석 환경을 선택한다. |

## Ⅴ. 제언

실제 조사 포맷과 단편화 조건을 반영한 기준 이미지로 도구를 먼저 비교하고 결과의 완전성을 별도 검증.
