## 30초 인출

- **본질:** 생성형 AI 보안 교육은 AI 사용 때 생기는 정보 노출·오용·오판을 줄이는 조직의 학습 활동이다.
- **메커니즘:** 직무별 위험을 정하고, 안전한 업무 절차를 익히며, 실제 행동을 연습한 뒤 결과를 보고 교육을 고친다.

<details><summary>핵심 용어</summary>

- **보안 인식 교육**: 구성원이 업무 중 보안 위험을 알아보고 안전한 행동을 선택하도록 돕는 학습 활동이다.
- **역할 기반 교육**: 직무에서 실제로 다루는 정보와 작업에 맞춰 학습 내용을 나누는 방식이다.
- **행동 지표**: 교육 뒤 위험 행동과 신고 행동이 어떻게 달라졌는지 살피는 관찰값이다.

|---|---|

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 내용 |
|---|---|
| 정의 | **생성형 AI 보안 인식 교육**은 AI 사용 위험에 맞춘 구성원의 안전한 업무 행동 학습 |
| 목적 | 민감정보 입력 통제와 생성 결과 검증 행동의 정착 |

```text
직무와 AI 사용 현황 파악
    ↓
위험·행동 목표 설정 → 교육·실습
    ↓
행동 변화 확인 → 미흡점은 목표·교육에 반영
```

NIST SP 800-50 Rev. 1은 보안·개인정보 학습 프로그램을 조직의 위험과 역할에 맞춰 설계하고 평가하는 생애주기 관점으로 다룬다.

## Ⅱ. 설계 원칙

| 설계 축 | 적용 |
|---|---|
| 위험 중심 | 조직에서 승인한 AI 사용과 취급 정보에서 위험 사례를 고른다. |
| 역할 중심 | 공통 원칙에 더해 실제 직무의 입력·검토·승인 행동을 다룬다. |
| 업무 적용 | 설명만 하지 않고 판단·확인·신고 절차를 연습한다. |

## Ⅲ. 역할별 학습 내용

```text
공통: 정보 분류·승인 도구·신고 경로
  ├─ 일반 사용자: 입력 전 정보 확인·결과 검증
  ├─ 개발자: 생성 코드 검토·시험
  ├─ 승인 담당: 민감 요청 별도 확인
  └─ 보안·IT: 정책·기록·대응 절차
```

공통 과정은 정보 취급과 신고 방법을 다루고, 직무 과정은 실제 업무에서 실행할 확인 행동을 연습한다. 특정 AI 서비스의 설정이나 학습 데이터 처리 방식은 조직이 승인한 서비스 문서와 정책에 따라 안내한다.

## Ⅳ. 훈련과 평가

| 활동 | 확인할 행동 |
|---|---|
| 모의 피싱·사칭 시나리오 | 지시를 바로 실행하지 않고 별도 경로로 확인·신고하는가 |
| 민감정보 입력 판단 연습 | 정보 분류와 승인된 사용 조건을 적용하는가 |
| 생성 결과 검토 사례 | 근거를 대조하고 불확실한 결과를 상위 검토로 넘기는가 |

교육 효과는 출석률만으로 판단하지 않는다. 훈련의 확인·신고 행동, 반복되는 오류 유형, 사고·근접사고의 추세를 함께 보고 교육 내용을 조정한다. 지표는 조직의 업무와 기준선에 맞게 정하고, 특정 목표 수치를 보편 기준처럼 두지 않는다.

## Ⅴ. 기술사적 제언

| 한계 | 대응 |
|---|---|
| 모든 직군에 같은 교육을 제공하면 영향이 큰 AI 사용 지점이 뒤늦게 다뤄질 수 있다. | 먼저 AI 사용사례를 업무·데이터 민감도별로 정리하고, 고위험 입력·검증 업무를 맡은 직무부터 교육과 훈련을 설계한 뒤 나머지 업무로 확대한다. |
