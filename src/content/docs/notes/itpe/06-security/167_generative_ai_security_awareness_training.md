# 생성형 AI 시대 보안 인식 교육

## 핵심 개념
- ChatGPT, Copilot 등 생성형 AI 서비스가 임직원의 일상 업무에 급속히 침투함에 따라, 기업 기밀 유출, 개인정보 침해, 딥페이크 사기, 환각(Hallucination) 맹신을 방지하기 위해 시행하는 전사적 보안 인식 제고 프로그램.
- 일방적인 집체 교육을 탈피하여, 실제 AI 악용 시나리오 기반의 실전형 모의훈련과 직군별 맞춤형 교육 커리큘럼을 결합하여 조직의 인간 방화벽(Human Firewall)을 강화.

```
+-------------------------------------------------------------+
|               생성형 AI 시대의 새로운 보안 위협 4선             |
+-------------------------------------------------------------+
| 1. 기밀/코드 유출 | 프롬프트에 미공개 소스코드, 고객 개인정보 입력  |
| 2. 딥페이크 사기 | CEO/임원 음성·영상 복제 기반 송금 유도 (BEC 사기)|
| 3. AI 피싱 메일   | 문법 오류 없는 정교한 한국어 맞춤형 스피어피싱 |
| 4. 환각 정보 오염 | 가짜 법령, 가짜 판례, 취약 오픈소스 맹신 도입  |
+-------------------------------------------------------------+
```

## 직군별 맞춤형 보안 교육 체계

```
+-------------------------------------------------------------+
| [전사 공통 임직원]                                          |
|  - 기밀정보/개인정보 프롬프트 입력 금지 원칙                 |
|  - 생성물 팩트체크(환각 검증) 의무                          |
|  - AI 생성 피싱 메일 및 딥페이크 화상통화 식별 요령         |
+-------------------------------------------------------------+
                              |
       +----------------------+-----------------------+
       v                                              v
+-----------------------------+ +-----------------------------+
| [소프트웨어 개발자]         | | [IT / 보안 관리자]          |
|  - AI 생성 코드 보안 취약점 |  - 기업용 전용 계정 통제      |
|    (OWASP Top 10, 버퍼결함) |  - DLP 프롬프트 필터링 정책   |
|  - 할루시네이션 패키지 공격 |  - AI 서비스 접속 로그 감사   |
|    (존재하지 않는 라이브러리)|  - Opt-out(학습 배제) 검증   |
+-----------------------------+ +-----------------------------+
```

### 1. 전사 공통 임직원 교육
- **입력 데이터 분류 기준 교육**: 사내 정보등급(극비, 대외비, 일반) 중 어떤 데이터가 AI 툴에 입력 가능한지 명확한 가이드 제공.
- **옵트아웃(Opt-out) 설정 실습**: 개인용/무료 계정 사용 시 대화 이력이 모델 학습에 반영되지 않도록 데이터 공유 설정을 끄는 방법 실습.
- **사회공학적 공격 식별**: 완벽한 맞춤법과 사내 보고서 스타일을 흉내 낸 악성 피싱 이메일 및 문자 구별법 전파.

### 2. 소프트웨어 개발 직군 교육
- **AI 생성 코드의 보안 내재화**: Copilot 등이 자동 생성한 코드에 하드코딩된 API 키, SQL Injection, XSS 취약점이 포함될 수 있음을 주지시키고 코드 리뷰 의무화.
- **슬롭쿼트/패키지 환각 공격(Package Hallucination)**: LLM이 실존하지 않는 가짜 라이브러리 이름을 추천할 때, 공격자가 이를 악성 패키지로 npm/PyPI에 등록해 두는 공급망 공격 사례 교육.

### 3. 경영진 및 재무 부서 특화 교육
- **딥페이크 CEO 사기(BEC) 대응**: 화상 회의나 메신저에서 대표이사의 목소리나 얼굴을 흉내 내어 긴급 송금을 요구하는 공격을 방어하기 위한 '오프라인 교차 검증(Out-of-band Verification)' 프로토콜 훈련.

## 실전형 모의 훈련 프로그램

```
[1. AI 기반 맞춤형 모의 피싱 훈련]
   - LLM을 활용하여 임직원 직급·업무에 맞춘 정교한 모의 피싱 메일 발송
   - 클릭자 대상 즉각적인 1:1 교정 교육 화면 노출 및 피드백 제공
        |
        v
[2. 딥페이크 음성/영상 사기 대응 모의훈련]
   - 재무/회계 부서 대상 음성 복제(Voice Phishing) 공격 시뮬레이션
   - 사전 정의된 2차 인증(비공개 구두 암호 확인 등) 이행 여부 점검
        |
        v
[3. 프롬프트 DLP 탐지 시뮬레이션]
   - 임직원이 테스트용 가상 기밀 데이터를 입력하도록 유도하여 차단 팝업 확인
```

## 교육 효과성 측정 지표 (KPI)

| 측정 지표 | 산출 방식 및 목표치 |
|---|---|
| **모의 피싱 감염률** | 모의 피싱 첨부파일/링크 클릭률 (목표: 5% 미만으로 감소) |
| **자발적 신고율** | 피싱 의심 메일을 보안팀에 즉각 신고한 비율 (목표: 70% 이상 달성) |
| **DLP 차단 발생 건수** | 프롬프트 내 주민번호/API 키 입력 시도 차단 건수 추이 (지속적 감소 유도) |
| **개발 코드 취약점 검출률**| AI 코드 자동 완성 후 SAST(정적 분석) 도구에서 지적되는 결함 비율 |

---

## 결론 및 실무 시사점
- 기술적 보안 솔루션(DLP, WAF 등)만으로는 끊임없이 변형되는 생성형 AI 기반 사회공학적 공격을 완벽히 차단할 수 없음.
- 조직의 보안 문화(Security Culture)를 조성하고, 임직원 개개인이 AI 기술의 편익을 누리면서도 위험을 능동적으로 식별·보고할 수 있는 실전 훈련 체계를 상시 가동해야 함.
