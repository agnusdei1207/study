## 지식 로드맵 내 현재 위치

정보보안 → 악성코드 → 정보 탈취

## 30초 인출

- **본질:** 인포스틸러는 감염 단말의 자격증명·세션 쿠키·파일을 모아 공격자에게 보내는 정보탈취 악성코드.
- **메커니즘:** 악성코드 실행 → 저장 정보 수집 → 외부 유출 → 계정·세션 재사용.
- **통찰:** 한계: 감염 단말 정리만으로 이미 탈취된 세션·토큰의 사용을 막지 못함 → 방안: 단말 격리와 함께 자격증명·세션을 폐기하고 타 시스템 사용 이력을 확인.

<details>
<summary>핵심 용어</summary>

- **인포스틸러(Infostealer)** : 감염 기기의 인증정보·파일 등을 수집해 외부로 유출하는 악성코드.
- **세션 쿠키** : 웹 서비스의 로그인 상태를 식별하는 브라우저 저장 값.
- **자격증명(Credential)** : 접근 검증에 쓰는 암호·키·토큰 등의 정보.
- **C2(Command and Control)** : 악성코드의 명령제어 체계.
- **MFA(Multi-Factor Authentication)** : 서로 다른 종류의 인증 요소를 둘 이상 사용하는 방식.
</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 내용 |
|---|---|
| 정의 | **인포스틸러(Infostealer)** 는 감염 단말의 자격증명·세션·파일을 모아 외부로 보내는 악성코드 |
| 목적 | 노출 범위를 파악해 계정 재사용·추가 침해 예방 |

피해 범위는 단말 감염을 넘어 계정·세션과 업무 자료의 후속 침해까지 확장 가능.

## Ⅱ. 탈취와 악용 흐름

```text
악성코드 실행
    ↓ 브라우저·파일·토큰 수집
외부 유출
    ↓
계정·세션 재사용 → 추가 접근
```

| 단계 | 행위 | 관찰 지점 |
|---|---|---|
| 실행 | 악성 파일·스크립트 동작 | 프로세스·다운로드 이력 |
| 수집 | 저장소·브라우저 접근 | 비정상 파일·메모리 접근 |
| 유출 | 외부 서버에 전송 | 네트워크 연결 |
| 악용 | 계정·세션 재사용 | 새로운 기기·위치의 로그인 |

## Ⅲ. 탈취 대상별 영향

```text
탈취 정보
  ├─ 비밀번호 ─ 새 로그인 시도
  ├─ 세션 쿠키 ─ 기존 로그인 상태 악용
  ├─ API 토큰 ─ 서비스 간 접근
  └─ 파일 ─ 직접 유출·후속 공격
```

세션 쿠키 탈취는 일부 환경에서 비밀번호나 MFA 재입력 없이 기존 로그인 상태를 악용할 수 있음.

| 대상 | 회수·확인 |
|---|---|
| 비밀번호 | 변경과 중복 사용 조사 |
| 세션·토큰 | 만료·폐기·재발급 |
| 파일 | 유출 항목·접근권한 조사 |

### 탐지와 사고 대응

```text
의심 단말 격리
    ↓ 수집·전송 흔적 확인
계정·세션·토큰 회수
    ↓ 타 서비스 접근 이력 확인
단말 복구·재감염 감시
```

| 계층 | 핵심 통제 |
|---|---|
| 단말 | 실행 통제·패치·행위 탐지 |
| 계정 | 피싱 저항성 인증·이상 로그인 탐지 |
| 서비스 | 세션 만료·토큰 회수·접근 로그 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 악성코드만 제거하고 탈취된 세션을 남기면 공격 지속 | 단말 처리와 세션·토큰 폐기를 하나의 사고 절차로 연결 |
| 암호 변경만으로 파일·API 토큰 유출을 놓침 | 수집 대상별 영향표를 작성해 회수·통지 판단 |

## Ⅴ. 제언

감염 단말 격리와 동시에 세션·토큰 폐기를 시작하고 타 서비스 접근 이력을 조사.
