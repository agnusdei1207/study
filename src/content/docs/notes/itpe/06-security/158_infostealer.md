# 인포스틸러(Infostealer)

## 핵심 개념
- 감염된 엔드포인트(PC, 스마트폰 등)에 저장된 사용자 자격증명(웹 브라우저 자동완성 비밀번호, 세션 쿠키), 암호화폐 지갑 개인키, 메신저 토큰 등을 은밀히 수집하여 원격 C&C 서버로 유출하는 악성코드.
- 지하 다크웹의 MaaS(Malware-as-a-Service, 서비스형 악성코드) 비즈니스 모델과 결합하여 대량 유포되며, 탈취된 유효 세션 쿠키는 다중요소인증(MFA)을 우회하는 초기 침투(Initial Access) 경로로 악용됨.

```
+-------------------------------------------------------------+
|                     인포스틸러 공격 생애주기                   |
+-------------------------------------------------------------+
| 1. 유포/감염     | 피싱 메일, 불법 소프트웨어(크랙/토렌트), 광고 악용|
| 2. 자격증명 탈취 | 브라우저 SQLite DB, 로컬 마스터키, 메모리 덤프  |
| 3. 데이터 압축   | 탈취 정보 ZIP 압축 후 C&C 서버/텔레그램 전송    |
| 4. 다크웹 유통   | 로그 마켓(Genesis, 2easy) 판매 및 랜섬웨어 연계 |
+-------------------------------------------------------------+
```

## 인포스틸러 공격 프로세스 아키텍처

```
[공격자 (MaaS 구매자)]
       |  1. 피싱 메일 / 크랙 소프트웨어 / 검색광고 스미싱(Malvertising)
       v
[희생자 PC 감염]
       |
       |-- 2. DPAPI(Data Protection API) 복호화 키 추출
       |-- 3. 웹 브라우저 저장 정보 탐색 (Chrome, Edge 등 SQLite 파일)
       |      - Saved Passwords, Autofill, Login Data
       |      - Session Cookies (Google, AWS, GitHub 세션 토큰)
       |-- 4. 암호화폐 지갑(Metamask 등) 및 메신저(Telegram, Discord) 토큰 수집
       |-- 5. VPN / RDP 클라이언트 자격증명 파일 추출
       |
       v
[로그 데이터 ZIP 압축 및 암호화]
       |
       |  6. HTTPS / Telegram Bot API / Discord Webhook으로 전송
       v
[공격자 C&C 서버 / 텔레그램 채널] ===> 다크웹 마켓 판매 ===> 랜섬웨어 조직 2차 침투
```

## 주요 탈취 대상 데이터 및 탈취 기법

### 1. 웹 브라우저 저장 자격증명 및 세션 쿠키
- **저장 비밀번호**: 브라우저의 `Login Data` SQLite 데이터베이스에서 암호화된 비밀번호를 추출하고, Windows DPAPI 마스터키로 복호화.
- **활성 세션 쿠키**: 로그인 상태가 유지되는 인증 쿠키를 탈취하여, 공격자가 ID/PW 입력 및 MFA 인증 없이 브라우저에 쿠키를 주입(Pass-the-Cookie)하여 즉시 로그인.

### 2. 암호화폐 지갑 및 메신저 토큰
- 브라우저 익스텐션(Metamask, Phantom)의 로컬 스토리지 파일(`leveldb`) 탐색을 통한 개인키 및 니모닉(Mnemonic) 구문 탈취.
- Discord, Telegram의 로컬 세션 데이터 탈취를 통한 비인가 계정 제어.

### 3. 엔터프라이즈 접근 자격증명
- Cisco AnyConnect, OpenVPN, Fortinet 등 사내 SSL-VPN 설정 파일 및 인증서.
- 원격 데스크톱(RDP) 연결 프로필(`Default.rdp`) 및 SSH 키 파일(`~/.ssh/id_rsa`).

## 대표적인 인포스틸러 계열 및 특징

| 악성코드 명칭 | 주요 전파 방식 및 기능 특징 |
|---|---|
| **레드라인(RedLine)** | 가장 널리 유포된 MaaS 인포스틸러, 브라우저/VPN/지갑 탈취 및 디스코드 채널 연동 |
| **비다(Vidar)** | 텔레그램 프로필을 C&C 주소 리졸버로 악용하여 방화벽 차단 회피, 정밀한 파일 타깃팅 |
| **루마(Lumma Stealer)** | C 언어 기반 경량화, 난독화 및 안티 가상머신/안티 디버깅 기법 고도화 |
| **라쿤(Racoon v2)** | C/C++ 기반 재작성, 브라우저 외 수십 종의 암호화폐 지갑 집중 탈취 |

## 조직 차원의 인포스틸러 대응 방안

```
+-------------------------------------------------------------+
|                     인포스틸러 다계층 대응 전략                |
+-------------------------------------------------------------+
| 1. 엔드포인트 보안 | 브라우저 비밀번호 저장 정책 차단 (GPO 설정)      |
| 2. 세션 제어       | 세션 바인딩(DPoP, Token Binding), 단축 만료시간 |
| 3. 위협 인텔리전스 | 다크웹 크리덴셜 모니터링 (CTI 솔루션 연동)        |
| 4. 접근 통제       | 제로 트러스트 기기 신뢰성(단말 상태 검증) 평가    |
+-------------------------------------------------------------+
```

- **브라우저 비밀번호 저장 금지**: 그룹 정책(GPO) 또는 MDM 솔루션을 적용하여 사내 엔드포인트 웹 브라우저의 '비밀번호 저장 및 자동완성' 기능 강제 비활성화.
- **쿠키 및 토큰 바인딩(DPoP / Token Binding)**: 세션 쿠키가 탈취되더라도 최초 발급된 단말의 TLS 세션 또는 개인키와 바인딩되어 다른 기기에서 재사용 불가하도록 구현.
- **CTI(사이버 위협 인텔리전스) 연동**: 다크웹 및 텔레그램 마켓에 사내 도메인 임직원 계정이 유출되었는지 실시간 모니터링하고, 발견 즉시 계정 잠금 및 세션 강제 만료 조치.
- **MFA 피싱 저항성 강화**: 단순 SMS/푸시 알림 기반 MFA를 지양하고, FIDO2/WebAuthn 기반 피싱 저항성(Phishing-resistant) 인증 체계 도입.

## 결론 및 실무 시사점
- 인포스틸러는 자격증명 유출의 진원지이자 랜섬웨어 및 지능형 지속 위협(APT) 침투의 최전방 무기로 작동함.
- 전통적인 악성코드 백신 탐지만으로는 한계가 있으므로, EDR(엔드포인트 탐지 및 대응) 솔루션과 세션 무결성 검증을 융합한 엔드포인트 제로 트러스트 통제를 완성해야 함.
