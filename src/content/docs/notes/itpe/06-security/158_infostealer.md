## Ⅰ. 인포스틸러(Infostealer)의 개요

- 개념 : 감염된 엔드포인트 기기의 웹 브라우저, 암호화폐 지갑, 메신저(디스코드, 텔레그램), VPN(Virtual Private Network) 클라이언트 등에 저장된 **계정 자격증명** (ID(Identifier)/PW), **세션 쿠키** (Session Cookies), 자동완성 데이터, 신용카드 정보를 은밀히 탈취하여 공격자 C2(Command and Control) 서버로 전송하는 악성코드군.
- 배경 및 필요성 : **다중 인증** (MFA, Multi-Factor Authentication) 도입이 확산되자 공격자들은 로그인 시점의 2차 인증을 우회하기 위해, 이미 인증을 통과한 웹 브라우저의 유효한 세션 쿠키를 통째로 훔쳐내는 인포스틸러를 대량 유포함.
- 핵심 목적 : 탈취한 기업 및 개인의 계정 자격증명과 유효한 세션 쿠키를 **다크웹 마켓** (Genesis Market, Russian Market 등)에 대량 판매하거나, 기업 내부망 침투(초기 침투 브로커: IAB)의 교두보로 악용.

## Ⅱ. 인포스틸러(Infostealer)의 핵심 아키텍처 및 동작 메커니즘

인포스틸러(RedLine, Vidar, Raccoon, Lumma 등)는 불법 크랙 소프트웨어, 피싱 메일, 구글 광고(SEO(Search Engine Optimization) 포이즈닝)를 통해 유포되며, 브라우저 SQLite DB(Database)를 복호화하여 데이터를 유출함.

```text
[ 인포스틸러의 자격증명 탈취 메커니즘 및 다크웹 유통 생태계 ]

  [ 사용자 PC (불법 크랙/구글 가짜 광고 클릭) ]
         |
         v (1) 인포스틸러 악성코드 감염 (Lumma, RedLine 등)
  +-------------------------------------------------------------+
  |              인포스틸러 수집 엔진 (메모리 실행)             |
  |                                                             |
  |  * 크롬/엣지 브라우저 저장소 접근 (SQLite DB)               |
  |    - Login Data (저장된 ID/PW)                              |
  |    - Network/Cookies (유효한 세션 쿠키)                     |
  |  * OS 마스터 키 추출 (DPAPI CryptUnprotectData 호출)         |
  |  * 암호화폐 지갑 확장프로그램(Metamask), 텔레그램 세션 수집 |
  +------------------------------+------------------------------+
                                 |
                                 | (2) ZIP 압축 후 C2 서버 은닉 전송 (HTTPS)
                                 v
  +-------------------------------------------------------------+
  |                    공격자 C2 서버 / 봇넷                     |
  +------------------------------+------------------------------+
                                 |
                                 | (3) '로그(Logs)' 패키지 다크웹 유통
                                 v
  +-------------------------------------------------------------+
  |          다크웹 사이버 범죄 마켓 (Genesis / 텔레그램 채널)   |
  |  * 건당 수 달러~수십 달러에 초기 침투 브로커(IAB)에게 판매   |
  +------------------------------+------------------------------+
                                 |
                                 v (4) 구매자가 쿠키 주입(Cookie Injection)
  [ 기업 내부 SaaS (M365, AWS, GitHub, Slack) ]
  * MFA 인증 요구 없이 정상 로그인 성공! -> 전사 랜섬웨어 유포로 직결!
```

- **브라우저 DPAPI 복호화** : 크롬, 엣지 등 크로미움 기반 브라우저가 사용자 비밀번호로 보호하는 DPAPI(Data Protection API) 마스터 키를 메모리에서 훔쳐 저장된 비밀번호와 쿠키를 즉각 평문 복호화.
- **세션 하이재킹(Pass-the-Cookie)** : 비밀번호를 몰라도 탈취한 세션 쿠키를 브라우저에 주입(Cookie Injection)하면 MFA 인증을 완벽히 우회하여 정상 사용자로 세션 즉시 장악.
- **초기 침투 브로커(IAB: Initial Access Broker) 연계** : 인포스틸러 운영자는 탈취한 자격증명 로그를 랜섬웨어 갱단에게 판매하여 기업 내부망 침투의 발판을 제공하는 BaaS(Botnet-as-a-Service) 범죄 분업화.
- **인포스틸러 주요 패밀리** : RedLine Stealer, Vidar, Raccoon, Lumma Stealer, Agent Tesla 등이 있으며 지속적인 난독화와 패커를 적용하여 시그니처 백신 탐지 회피.

## Ⅲ. 인포스틸러(Infostealer)의 세부 구성 요소 및 비교 분석

| 비교 항목 | **인포스틸러** (Infostealer) | **키로거** (Keylogger) | **트로이목마** (RAT) | **스파이웨어** (Spyware) |
| --- | --- | --- | --- | --- |
| 수집 대상 | 브라우저 저장 암호, 세션 쿠키, 지갑 | 실시간 키보드 타이핑 입력 스트림 | 원격 쉘, 화면 캡처, 시스템 제어권 | 웹서핑 이력, 마케팅 정보, 마이크 도청 |
| MFA 우회 | 가능 (유효한 세션 쿠키 통째 탈취) | 불가능 (일회용 OTP(One-Time Password) 번호는 만료) | 가능 (원격 데스크톱으로 직접 조작) | 불가능 (단순 추적 소프트웨어) |
| 실행 방식 | 정보 탈취 후 즉시 자폭 또는 C2 대기 | 상주하며 백그라운드 키 입력 후킹 | 상시 백도어 연결 유지 및 원격 명령 | 백그라운드 은닉 실행 |
| 주요 유포 | 구글 검색광고(말버타이징), 크랙 파일 | 피싱 이메일 첨부 문서, 워터링 홀 | 취약점 익스플로잇, 공급망 공격 | 애드웨어 번들 프로그램 설치 |
| 비즈니스 모델 | 다크웹 마켓 자격증명 로그 대량 판매 | 타깃 공격용 자격증명 탈취 | 랜섬웨어 유포 및 기업망 침투 | 광고 수익 및 사용자 프로파일링 |

- 인포스틸러는 세션 쿠키 탈취를 통해 기업의 고비용 다중 인증(MFA)을 완벽히 무력화하므로, 브라우저 자격증명 저장 금지와 토큰 바인딩 기술 도입이 시급함.

## Ⅳ. 인포스틸러(Infostealer)의 주요 한계점 및 해결 방안

- 유효한 정상 세션 쿠키 악용 시 서버 측 탐지 불가능 :
  - 한계점 : 공격자가 훔친 쿠키로 접속할 경우 서버 관점에서는 완벽하게 인증된 정상적인 HTTP(Hypertext Transfer Protocol) 세션 요청으로 보여 방화벽이나 WAF(Web Application Firewall)가 패스.
  - 해결 방안 : OAuth 접근 토큰에 DPoP(Demonstrating Proof-of-Possession, RFC 9449)를 적용하여 클라이언트 키 소유 증명을 검증. JA3/JA4 지문이나 일반 세션 쿠키에 자동 적용되는 표준은 아니므로 쿠키 보호와 별도로 설계.
- 임직원의 사내 PC(Personal Computer) 웹 브라우저 내 '비밀번호 저장' 관행 :
  - 한계점 : 편의를 위해 브라우저의 '비밀번호 저장' 팝업을 수락하여 수십 개의 업무 시스템 계정 자격증명이 단일 SQLite 파일에 평문 저장.
  - 해결 방안 : Active Directory 그룹 정책(GPO) 및 MDM(Mobile Device Management)을 통해 전사 PC 브라우저의 비밀번호 저장 및 자동완성 기능을 강제 비활성화.
- 구글 검색 광고를 악용한 말버타이징(Malvertising) 유포 급증 :
  - 한계점 : Notion, Slack 등 정상 업무용 소프트웨어 검색 시 공격자가 결제한 스폰서 광고가 최상단에 노출되어 사용자가 가짜 다운로드 사이트 접속.
  - 해결 방안 : 사내 보안 DNS(DoH/DoT)를 구축하여 알려진 가짜 타이포스쿼팅 도메인 접속을 차단하고 직원 대상 말버타이징 모의 훈련 수행.

## Ⅴ. 인포스틸러(Infostealer) 적용 및 발전을 위한 기술사적 제언

- 다크웹 자격증명 유출 모니터링(Threat Intelligence) 솔루션 도입 : 다크웹 마켓과 텔레그램 유출 채널을 상시 크롤링하여 사내 도메인 계정 및 세션 쿠키가 탐지되는 즉시 해당 계정 강제 패스워드 리셋 및 활성 세션 일괄 종료.
- 엔드포인트 EDR(Endpoint Detection and Response)을 통한 브라우저 SQLite DB 접근 비정상 프로세스 감시 : 크롬/엣지의 쿠키 저장 파일(Cookies)에 비인가 프로세스나 알 수 없는 스크립트가 접근하려는 행위를 실시간 탐지하여 즉시 프로세스 사살.
- 조건부 접근 제어 정책에 디바이스 식별자(Device ID) 검증 결합 : 세션 쿠키가 탈취되더라도 회사가 지급하고 보안 에이전트가 설치된 공인 디바이스에서 발생하는 트래픽이 아니면 사내 시스템 접근을 거부하는 ZTNA(Zero Trust Network Access) 구성.
