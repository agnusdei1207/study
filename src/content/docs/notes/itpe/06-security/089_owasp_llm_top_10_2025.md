## 2~4교시 25점 답안

**공통 개요**

| 구분 | 핵심 |
|---|---|
| 정의 | OWASP LLM Top 10 2025는 LLM 애플리케이션에서 점검할 열 가지 위험 범주를 정리한 보안 가이드 |
| 목적 | 위협 모델과 통제 우선순위 검토를 위한 공통 언어 제공 |

### Ⅰ. 제시 배경·특징
- LLM의 비신뢰 문서 해석, 생성 출력, 외부 도구 실행 및 RAG 검색 때문에 기존 웹 통제만으로 놓칠 수 있는 위험을 목록화.
### Ⅱ. 10대 위협
| 번호 | 위협 | 검토 경계 |
|---|---|---|
| 01·02 | 프롬프트 인젝션·민감정보 노출 | 입력·출력과 데이터 권한 |
| 03·04 | 공급망·데이터/모델 중독 | 모델·패키지·지식 출처 |
| 05·06 | 부적절한 출력 처리·과도한 대행 | 후속 코드 실행·도구 권한 |
| 07·08 | 시스템 프롬프트 노출·벡터/임베딩 취약점 | 정책 의존·검색 테넌트 분리 |
| 09·10 | 잘못된 정보·무제한 자원 소비 | 근거 검증·사용량 제한 |
### Ⅲ. 기업 대응
- 설계 시 위협 모델과 데이터 분류, 구현 시 권한·출력 검증·공급망 검사, 운영 시 로깅·한도·레드티밍과 사고 대응.
### Ⅳ. 유의점
- 체크리스트 통과만으로 안전성 보장 불가. 모델·검색 데이터·도구 권한 변경 때 재평가.

## 기술사적 제언

열 가지 범주를 그대로 순위로 쓰기보다 조직의 데이터·도구 권한·노출 경로로 재평가한다.
