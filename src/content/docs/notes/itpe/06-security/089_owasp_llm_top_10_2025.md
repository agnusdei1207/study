## 핵심 그림
```text
[OWASP Top 10 for LLM Applications (2025년 버전) 10대 위협 구성]

   [입력/데이터 계층]
   ├─ LLM01: 프롬프트 인젝션 (Prompt Injection - 직접/간접 조작)
   ├─ LLM02: 민감정보 노출 (Sensitive Information Disclosure)
   ├─ LLM03: 공급망 취약점 (Supply Chain Vulnerabilities - 모델/데이터/플러그인)
   └─ LLM04: 데이터 및 모델 중독 (Data and Model Poisoning)

   [추론/시스템 계층]
   ├─ LLM05: 부적절한 출력 처리 (Improper Output Handling - XSS/RCE 유발)
   ├─ LLM06: 과도한 대행 (Excessive Agency - 에이전트의 과도한 자율 권한)
   ├─ LLM07: 시스템 프롬프트 유출 (System Prompt Leakage)
   └─ LLM08: 벡터 및 임베딩 취약점 (Vector and Embedding Weaknesses - RAG 오염)

   [운영/서비스 계층]
   ├─ LLM09: 잘못된 정보 (Misinformation - 부정확한 출력의 의사결정 영향)
   └─ LLM10: 무제한 자원 소비 (Unbounded Consumption - 비용·가용성 영향)
```

## 핵심 용어
- 과도한 대행(Excessive Agency, LLM06): LLM 에이전트에게 비즈니스 프로세스를 실행할 수 있는 과도한 권한이나 자율성을 부여하여, 프롬프트 인젝션이나 환각 발생 시 비인가 데이터 삭제나 금전 이체가 발생하는 결함
- 벡터 및 임베딩 취약점(Vector Weaknesses, LLM08): 2025년 버전에 강조된 위협으로, RAG의 지식 검색을 담당하는 벡터 데이터베이스에 악성 임베딩을 주입하여 검색 결과를 오염시키는 공격

## 핵심 통찰
- 2025년 목록은 모델 자체의 위험과 함께 RAG 데이터·벡터 검색·도구 실행 등 애플리케이션 경계를 다룸.
- LLM01은 직접·간접 프롬프트 인젝션을 함께 다룸. 외부 문서·검색 결과를 신뢰된 지시와 구분하고, 도구 호출 전 정책 검사 필요.
- 보안 통제는 입력·출력 검사 외에도 데이터 접근제어, 도구 최소 권한, 후속 실행 검증, 운영 모니터링을 결합.

## 이웃 토픽과 구분
- OWASP LLM Top 10 vs OWASP Top 10(Web): LLM Top 10 = 확률적 자연어 처리와 자율 에이전트의 의미론적(Semantic) 결함 / Web Top 10 = HTTP 프로토콜과 구문론적(Syntactic) 코드 결함

## 문제·원인·대책
- 가상 사례: 고객 상담용 RAG 시스템이 공격자가 올린 외부 문서의 지시를 따르면, 허용되지 않은 내부 자료를 답변에 포함할 위험
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| RAG 검색 오염을 통한 기밀 데이터 유출 (LLM02, LLM04) | 외부 자료의 신뢰 경계와 검색 권한 분리 부족 | 데이터 출처 검증, 검색 권한 분리, 응답 전 권한 검사 | 오염 문서의 영향과 기밀 노출 위험 축소 |
| 조작된 프롬프트가 에이전트의 관리자 DB 삭제를 유도 (LLM06) | AI 에이전트에 과도한 쓰기·삭제 권한 부여 | 최소 권한과 파괴적 명령의 독립 승인 | 비인가 파괴 행위 가능성과 피해 범위 축소 |

## 1교시 예상문제 (10점)
- OWASP LLM Top 10 2025의 목적과 주요 위험 유형을 설명하시오.

## 1교시 10점 답안
- **목적:** LLM 애플리케이션의 설계·운영에서 우선 점검할 위험 범주 10개와 완화 방향 제시.
- **범주:** 프롬프트 인젝션(01), 민감정보 노출(02), 공급망(03), 데이터·모델 중독(04), 출력 처리(05), 과도한 대행(06), 시스템 프롬프트 노출(07), 벡터·임베딩(08), 잘못된 정보(09), 자원 소비(10).
- **적용:** 모델·데이터·도구·출력 경계별 공격 경로를 평가하며 목록 순위를 개별 조직의 실제 위험도와 동일시하지 않음.

## 2~4교시 예상문제 (25점)
- OWASP LLM Top 10 2025의 배경·주요 위협과 기업의 설계·운영 대응을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 제시 배경·특징
- LLM의 비신뢰 문서 해석, 생성 출력, 외부 도구 실행 및 RAG 검색 때문에 기존 웹 통제만으로 놓칠 수 있는 위험을 목록화.
### Ⅱ. 10대 위협
| 번호 | 위협 | 검토 경계 |
|---|---|---|
| 01·02 | 프롬프트 인젝션·민감정보 노출 | 입력·출력과 데이터 권한 |
| 03·04 | 공급망·데이터/모델 중독 | 모델·패키지·지식 출처 |
| 05·06 | 부적절한 출력 처리·과도한 대행 | 후속 코드 실행·도구 권한 |
| 07·08 | 시스템 프롬프트 노출·벡터/임베딩 취약점 | 정책 의존·검색 테넌트 분리 |
| 09·10 | 잘못된 정보·무제한 자원 소비 | 근거 검증·사용량 제한 |
### Ⅲ. 기업 대응
- 설계 시 위협 모델과 데이터 분류, 구현 시 권한·출력 검증·공급망 검사, 운영 시 로깅·한도·레드티밍과 사고 대응.
### Ⅳ. 유의점
- 체크리스트 통과만으로 안전성 보장 불가. 모델·검색 데이터·도구 권한 변경 때 재평가.

## 이렇게 출제된다
