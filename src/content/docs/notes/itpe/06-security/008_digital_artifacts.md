| 사용자 상호작용 | 바로가기·최근 항목·검색 기록 | 계정·동기화·자동 생성 가능성 고려 |
| 이벤트·파일시스템 | 이벤트 로그·파일시스템 메타데이터 | 시계·수집 시점·보존 상태 확인 |

```text
출처·생성조건 확인
       ↓ 시간·내용 분석

       ↓
근거와 해석의 범위 구분
```

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **디지털 아티팩트**는 시스템·응용프로그램 사용과 상태를 분석하는 데 참고하는 디지털 흔적 |
| 목적 | 여러 흔적의 연관성을 검토해 사건·사용 행위에 관한 근거 확보 |

아티팩트의 생성·보존·시간 의미는 시스템 설정과 버전, 사용자 행위, 공격자 조작에 따라 달라짐.

## Ⅱ. 주요 유형과 정보원

| 정보원 | 예시 흔적 | 분석 질문 |
|---|---|---|
| 운영체제·실행환경 | 실행·설치·서비스 상태 관련 자료 | 어떤 프로그램·설정이 확인되는가 |
| 사용자 활동 | 최근 파일·바로가기·계정 활동 | 어떤 계정에서 어떤 상호작용이 있었는가 |
| 파일시스템 | 파일 메타데이터·변경 기록 | 파일의 생성·변경·이동 근거는 무엇인가 |
| 이벤트·네트워크 | 시스템 이벤트·연결·인증 로그 | 사건과 외부 통신의 시간 관계는 무엇인가 |

```text
운영체제 흔적 ─┐
사용자 흔적   ─┼─ 상호 보완하는 증거 원천
파일·이벤트   ─┤
네트워크 흔적 ─┘
```

## Ⅲ. 수집·분석 절차

```text
조사 범위·시간 기준 설정
            ↓ 출처별 수집·보존
아티팩트 파싱·정규화
            ↓ 타임라인 구성
가설별 흔적 대조·검증
            ↓
근거·한계·대안 해석 보고
```

| 단계 | 수행 내용 |
|---|---|
| 범위 설정 | 사건 질문·대상 시스템·수집 권한·시간대 정의 |
| 획득 | 원본 보존, 출처·도구·수집시각·무결성 기록 |
| 분석 | 형식별 파싱, 시간 정규화, 관련 흔적 비교 |
| 보고 | 관측 사실과 추론 구분, 한계·대안 설명 포함 |

## Ⅳ. 타임라인·시간정보 검증

| 오류·조작 가능성 | 확인 방법 |
|---|---|
| 시스템 간 시계 차이·시간대 차이 | 시간대·시각원·수집시각과 보정 근거 기록 |
| 타임스탬프 조작 | 파일·로그·백업·네트워크 등 서로 다른 출처 대조 |
| 기록 누락·순환 덮어쓰기 | 로그 보존정책·시스템 상태·수집 범위 확인 |
| 자동·간접 생성 | 사용자 직접 행위 외의 생성 경로와 프로세스 검토 |

```text
시간값만 확인
      ↓ 출처·시간대·시계 상태 검증
독립 정보원과 순서 대조
      ↓ 일치·불일치 근거 기록
행위 해석의 신뢰도 판단
```

## Ⅴ. 분석 결과의 해석 한계

| 한계 | 분석상 보완 |
|---|---|
| 같은 흔적이 자동 실행·동기화로 생성될 수 있음 | 생성 조건과 다른 계정·프로세스 정보를 함께 확인 |
| 흔적의 부재가 행위의 부재를 뜻하지 않을 수 있음 | 삭제·보존기간·수집범위·환경 차이 검토 |
| 타임스탬프 하나로 행위 주체를 식별할 수 없음 | 계정·장치·접근·네트워크 흔적을 결합하되 귀속의 불확실성 표기 |

## Ⅵ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 조직별 로그·시간원·보존기간 차이가 조사 후 뒤늦게 드러남 | 중요 시스템의 시간동기화·로그 보존·수집 권한을 사전에 표준화하고 사건 유형별 증거수집 계획으로 검증 |
