# BYOD(Bring Your Own Device)

## 핵심 개념
- 임직원이 개인 소유의 스마트폰, 태블릿, 노트북 등 모바일 IT 단말기를 회사 업무 환경에 반입하여 사내 인트라넷, 이메일, 업무 데이터에 접근할 수 있도록 허용하는 근무 방식.
- 업무 생산성과 근무 유연성을 향상시키지만, 단말 분실·도난에 따른 기밀 유출, 악성코드 사내 유입, 개인 사생활 침해(프라이버시) 문제가 상충하는 양면적 특성을 지님.

```
+-------------------------------------------------------------+
|                     BYOD 보안 관리 핵심 과제                  |
+-------------------------------------------------------------+
| 1. 데이터 보안       | 개인 단말 내 기업 기밀/고객 정보 유출 차단  |
| 2. 기기 관리 및 통제 | 단말 탈옥(Jailbreak), 분실 시 원격 데이터 삭제|
| 3. 프라이버시 보호   | 사생활 영역(개인 사진, 통화 이력) 감시 배제  |
| 4. 네트워크 보안     | 악성 앱에 감염된 단말의 사내망 침투 차단   |
+-------------------------------------------------------------+
```

---

## EMM(Enterprise Mobility Management) 기술 스택

BYOD 환경에서 단말의 개인 영역과 기업 업무 영역을 분리하고 통제하기 위한 기술 체계.

```
+-------------------------------------------------------------+
|            EMM (엔터프라이즈 모빌리티 관리) 체계            |
+-------------------------------------------------------------+
| MDM (기기 관리)   | 단말 잠금, 원격 와이프(Wipe), 암호화 강제, 루팅 탐지 |
| MAM (앱 관리)     | 업무용 앱 배포, 앱 간 복사-붙여넣기 차단, 샌드박스  |
| MCM (콘텐츠 관리) | 사내 문서 암호화 전송, 모바일 DRM, 문서 뷰어 통제   |
| MIM (신원/접근)   | 모바일 단말 인증서 발급, 앱 단위 VPN(Per-App VPN)   |
+-------------------------------------------------------------+
```

---

## EMM 구성 요소별 비교

| 통제 솔루션 | 관리 대상 | 핵심 기능 | 프라이버시 침해 우려 |
|---|---|---|---|
| **MDM**<br>(Mobile Device Mgmt) | 단말기 하드웨어 및 OS 전체 | 카메라 차단, Wi-Fi 통제, GPS 위치 추적, 기기 전체 초기화(Full Wipe) | 높음 (개인 기기 전체 통제 및 위치 추적으로 반발 유발) |
| **MAM**<br>(Mobile App Mgmt) | 업무용 애플리케이션 | 업무 앱 샌드박싱, 클립보드 복사 제한, 업무 앱만 선택적 삭제(Selective Wipe) | 낮음 (업무 앱만 통제하므로 개인 영역 보장) |
| **MCM**<br>(Mobile Content Mgmt)| 업무용 문서 및 데이터 | 기업 문서 뷰어 내 워터마크 표시, 로컬 저장 금지, 전송 구간 암호화 | 없음 (업무 파일 자체만 보호) |
| **MIM**<br>(Mobile Identity Mgmt)| 모바일 사용자 신원 및 인증 | SSO 연계, 생체인증(FIDO), 앱 단위 전용 VPN 터널 개설 | 없음 (접근 인가 통제) |

## 컨테이너화(Containerization) 및 분리 아키텍처

개인용 OS 환경과 격리된 안전한 가상 업무 영역(Container)을 생성하여 사생활 보호와 보안 요구를 동시에 충족.

```
+-------------------------------------------------------------+
|                   BYOD 단말기 논리적 분리 구조                |
+-------------------------------------------------------------+
| [개인 영역 (Personal Space)]  |  [업무 전용 컨테이너 (Work Space)] |
|  - 개인 사진, 카카오톡, 게임 |  - 사내 메일, ERP, 메신저       |
|  - 개인 클라우드 백업        |  - 암호화된 전용 스토리지        |
|  - 자유로운 외부 인터넷     |  - 앱 단위 VPN 연결              |
|                              |  - 화면 캡처 및 복사-붙여넣기 금지|
+------------------------------+-------------------------------+
| <================= 데이터 교환 원천 차단 =================> |
+-------------------------------------------------------------+
|                 모바일 OS 계층 (Android / iOS)               |
+-------------------------------------------------------------+
```

## BYOD 보안 대책 체계

### 1. 기술적 대책
- **선택적 원격 삭제(Selective / Enterprise Wipe)**: 단말 분실 또는 직원 퇴사 시 개인 사진이나 메시지는 보존하고, 업무용 컨테이너 및 데이터만 선별적으로 원격 삭제.
- **단말 무결성 검증**: 루팅(Android)이나 탈옥(iOS)이 탐지된 단말은 사내망 접속 즉시 자동 차단(NAC 연동).
- **앱 단위 VPN(Per-App VPN)**: 개인 트래픽은 일반 통신망을 이용하고, 인가된 업무용 앱의 트래픽만 사내망으로 암호화 터널링.

### 2. 관리적·정책적 대책
- **BYOD 보안 정책 및 서약서 체결**: 개인 단말기 등록 절차, 분실 시 즉시 신고 의무, 모니터링 허용 범위를 명확히 규정.
- **비인가 기기 차단**: 사전에 승인된 MAC 주소 또는 인증서가 탑재된 BYOD 기기만 내부 무선랜(802.1X EAP-TLS) 접속 허용.

## 결론 및 실무 시사점
- BYOD는 인프라 비용 절감과 업무 효율을 제공하지만, 개인 프라이버시와 기업 보안 통제 사이의 균형이 성패를 좌우함.
- 전체 기기를 통제하는 구형 MDM 방식에서 벗어나, 컨테이너화 기반의 MAM과 제로 트러스트 기기 검증 체계로 고도화해야 함.
