## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 내용 |
|---|---|
| 정의 | **BYOD(Bring Your Own Device)**는 개인 소유 단말을 조직 업무에 사용하는 운영 방식 |
| 목적 | 업무 유연성 확보와 기업 정보·개인 영역의 분리 보호 |

| 이점 | 관리 과제 |
|---|---|
| 익숙한 단말 활용과 업무 유연성 | 단말 보안상태·분실·퇴사 관리 |
| 단말 선택 폭 확대 | 개인 데이터와 업무 데이터의 구분 |

NIST SP 800-124 Rev. 2는 조직 소유와 개인 소유 단말을 포함해 모바일 단말의 배포·사용·폐기 생애주기 보안을 다룬다.

## Ⅱ. 위험과 요구사항

```text
개인 단말의 업무 접근
  ├─ 단말 취약·분실 → 업무 데이터 노출 위험
  │                    └─ 업무 데이터 분리·접근 통제
  └─ 과도한 단말 관리 → 개인 정보 침해 위험
                       └─ 관리 범위 최소화·고지
```

BYOD 정책은 단말의 안전한 접근과 데이터 통제뿐 아니라 조직이 수집할 수 있는 단말 정보의 범위도 정해야 한다. 단말 전체를 항상 감시하거나 원격 초기화할 수 있다고 가정하지 말고 실제 관리 기술과 사용자 동의·조직 정책을 확인한다.

## Ⅲ. 단말·데이터 관리

| 관리 대상 | 통제 예 |
|---|---|
| 단말 상태 | 지원 버전, 화면 잠금, 암호화 등 조직의 기준 확인 |
| 업무 앱·계정 | 승인된 앱과 인증을 이용하고 업무 데이터 저장 위치 관리 |
| 업무 데이터 | 분리 저장, 공유·복사 제한을 위험에 맞게 적용 |
| 퇴사·분실 | 계정과 세션 차단, 관리 가능한 업무 데이터 삭제 |

EMM은 단말 전체 또는 앱·업무 데이터 중심 등 서로 다른 범위로 구현될 수 있다. 개인 소유 단말에서는 필요한 최소 범위를 선택하고 관리 제품의 실제 기능과 운영 조건을 검증한다.

## Ⅳ. 접근·운영 통제

```text
단말 등록 → 사용자·단말 확인
    ↓
업무 접근 조건 충족?
  ├─ 예 → 필요한 업무 자원만 허용
  └─ 아니오 → 접근 제한·복구 안내

분실·퇴사 시: 계정 회수·업무 자료 정리
```

접근은 등록 여부만으로 허용하지 않고 사용자·단말 상태·업무 필요에 따라 제한한다. 분실·퇴사 때는 계정과 업무 데이터 처리 절차를 실행하며, 원격 삭제가 개인 영역까지 미치지 않는지 사전에 시험한다.

## Ⅴ. 기술사적 제언

| 한계 | 대응 |
|---|---|
| BYOD를 일괄 허용하거나 금지하면 업무상 필요한 단말 통제와 개인 소유권을 함께 반영하기 어렵다. | 업무 자료의 민감도에 따라 먼저 운영방식을 선택한다: 민감자료·강한 통제가 필요한 업무는 조직 관리 단말, 승인 앱 중심 업무는 분리된 업무공간을 둔 BYOD, 저위험 자료만 다루는 업무는 접근 범위를 제한한 BYOD를 검토한다. |
