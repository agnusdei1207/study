## 지식 로드맵 내 현재 위치

사이버위험 관리 → 사전 노출 감소와 침해 대응 → 선제적 사이버보안

## 30초 인출

- **본질:** 침해 사고 발생 후 대응(Reactive)의 한계를 극복하고, 공격자 관점에서 공격 표면과 악용 경로를 사전에 식별·평가·무력화하는 능동적 보안 운영 체계
- **메커니즘:** 외부 공격표면 탐색(EASM) 및 자산 식별(CAASM) → 지속적 위협 노출 관리(CTEM) 기반 우선순위화 → 침해·공격 시뮬레이션(BAS) 검증 → 자동 교정 및 피드백
- 통찰: 사후 대응 중심 침해 차단에서 벗어나 외부 노출 자산과 실시간 익스플로잇 가능성을 기준으로 조치 우선순위를 동적 최적화하는 지속적 위협 노출 통제 체계 정립 필요

<details><summary>핵심 용어</summary>

- **선제적 사이버보안(Preemptive Cybersecurity)** : 침해 발생 전 공격 표면 식별, 경로 차단, 보안 통제 유효성을 사전 검증하는 방어 모델.
- **EASM(External Attack Surface Management)** : 인터넷에 노출된 미승인 자산, 포트, 인증서 만료, 설정 오류를 공격자 시각에서 탐지하는 기술.
- **CAASM(Cyber Asset Attack Surface Management)** : 내부 API 연동을 통해 온프레미스·클라우드·SaaS 내 모든 사이버 자산 가시성을 통합 확보하는 기술.
- **BAS(Breach and Attack Simulation)** : 실제 공격 시나리오와 TTPs를 소프트웨어 기반으로 자동 시뮬레이션하여 방어 통제를 검증하는 도구.
- **CTEM(Continuous Threat Exposure Management)** : 범위 설정, 탐색, 우선순위화, 검증, 조치로 이어지는 가트너의 5단계 지속 노출 관리 프레임워크.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 공격자가 악용 가능한 조직 내·외부 공격 표면과 잠재적 침투 경로를 사전에 식별·검증·제거하여 침해 발생 확률과 피해 규모를 최소화하는 능동적 보안 패러다임 |
| 목적 | 가시성 사각지대 해소, 취약점 조치 우선순위 최적화, 통제 유효성 상시 검증을 통한 선제적 방어 탄력성 확보 |

## Ⅱ. 선제적 사이버보안의 주요 특징

| 특징 | 세부 내용 | 구현 요소 |
|---|---|---|
| 공격자 관점 분석 | 방어자 경계선 내부가 아닌 외부 공격자의 정찰 및 진입 경로 시각에서 노출 자산 탐지 | EASM, OSINT, 포트 스캐닝 |
| 지속적 노출 검증 | 연 1~2회 단발성 모의해킹 탈피, 자동화된 공격 시나리오 상시 수행을 통한 방어 유효성 검증 | BAS, 자동 침투 테스트 |
| 위험 기반 우선순위화 | 단순 취약점 수치(CVSS) 의존을 탈피하여 악용 가능성(EPSS, KEV) 및 비즈니스 영향도 결합 | RBVM, 위협 인텔리전스 |
| 통합 자산 가시성 | 섀도우 IT, 클라우드 워크로드, 서드파티 연결 등 다변화된 자산의 실시간 중앙 집중 가시화 | CAASM, API 연동 |

## Ⅲ. 선제적 사이버보안 체계 및 추진 프로세스

```text
[ 1. 범위 설정 (Scope) ]
       │  (핵심 자산, 비즈니스 영향도, 외부 노출 시스템 정의)
       ▼
[ 2. 자산 탐색 (Discovery) ] ─── EASM (외부 표면) + CAASM (내부 자산)
       │  (섀도우 IT, 오픈 포트, 인증서 만료, 미패치 취약점)
       ▼
[ 3. 우선순위화 (Prioritization) ] ─── CVSS + EPSS + CISA KEV + 자산 중요도
       │  (실제 익스플로잇 가능성이 높은 고위험 노출 선별)
       ▼
[ 4. 공격 검증 (Validation) ] ─── BAS 시뮬레이션 + 위협 헌팅 (Threat Hunting)
       │  (방화벽/EDR 탐지 차단율 확인, 공격 성공 경로 실증)
       ▼
[ 5. 조치 및 피드백 (Mobilization) ] ─── SOAR 자동 격리 + 패치 + 방어 규칙 업데이트
```

| 단계 | 활동 내용 | 핵심 도구 및 표준 |
|---|---|---|
| 1. 범위 설정 | 비즈니스 핵심 자산 정의 및 조직의 공격 노출 표면 범위 결정 | 위험 평가 매트릭스, BIA |
| 2. 자산 탐색 | 온프레미스·클라우드·SaaS 전반의 자산 및 미승인 섀도우 자산 발견 | EASM, CAASM, 네트워크 매핑 |
| 3. 우선순위화 | 실제 악용 가능성과 비즈니스 영향도에 기반한 위험 점수 산출 | EPSS, CISA KEV, RBVM |
| 4. 공격 검증 | 방어 통제 도구(SIEM, EDR, NDR)의 실제 탐지·차단 유효성 실증 | BAS, MITRE ATT&CK 기반 TTPs |
| 5. 조치 및 피드백 | 보안 통제 룰 조정, 취약점 패치, 정책 보완 및 피드백 루프 구축 | SOAR, ITSM 티켓팅 연동 |

## Ⅳ. 선제적 보안과 사후 대응적 보안 비교

| 구분 | 사후 대응적 보안 (Reactive Security) | 선제적 사이버보안 (Preemptive Cybersecurity) |
|---|---|---|
| 접근 철학 | 공격 발생 및 경보 인입 후 대응 및 복구 | 공격 발생 전 표면 축소 및 침투 경로 사전 무력화 |
| 핵심 기술 | SIEM, SOAR, EDR/NDR, 사고대응(IR) | EASM, CAASM, BAS, CTEM 프레임워크 |
| 점검 주기 | 정기 모의해킹(연 1~2회), 이벤트 발생 시 분석 | 실시간 자동 탐색 및 지속적 시뮬레이션(Continuous) |
| 취약점 관리 | 정적 스캐너 기반 CVSS 점수 일괄 관리 | 악용 정황(KEV, EPSS) 결합 위험 기반 동적 우선순위화 |
| 한계점 | 탐지 실패 시 랜섬웨어 감염 등 피해 확산 불가피 | 복잡한 멀티클라우드 환경 내 전체 가시성 유지 난이도 |

## Ⅴ. 선제적 사이버보안의 한계와 방안

| 한계 | 방안 |
|---|---|
| 멀티클라우드 및 마이크로서비스 확장으로 인한 섀도우 IT 급증 및 자산 가시성 사각지대 발생 | CSPM, CIEM, SaaS API 연동형 CAASM 도입으로 자산 인벤토리의 실시간 중앙 동기화 및 섀도우 자산 자동 식별 체계 확립 |
| 단순 CVSS 수치 기준 패치 시 수천 개 취약점 조치 병목 및 개발·운영 현업 부서와의 패치 마찰 | CISA KEV(실제 악용), FIRST EPSS(공격 확률), 내부 자산 비즈니스 중요도를 결합한 다차원 스코어링 엔진 구축 |
| BAS 공격 시뮬레이션 트래픽이 운영 환경에 유입될 경우 서비스 장애 또는 대량 오탐 알람 유발 위험 | 통제된 샌드박스 및 카나리 워크로드 기반 시뮬레이션 우선 수행, 에이전트 무영향 세이프 모드 적용 |

## Ⅵ. 제언

```text
[ 기존 보안 운영 ]                     [ 선제적 사이버보안 고도화 ]
사후 경보 분석 ──────┐                 ┌── EASM / CAASM 상시 표면 탐색
정기 취약점 점검 ───┼─→ [ 운영 과부하 ] ──┼── BAS 기반 통제 유효성 실증
단편적 패치 적용 ────┘                 └── CTEM 기반 위험 중심 능동 조치
```

| 평가 영역 | 전통적 대응 체계 | 선제적 사이버보안 체계 | 향후 발전 방향 |
|---|---|---|---|
| 공격 방어 효과 | 침해 후 확산 차단 주력 | 침투 시도 자체의 선제 차단 | AI 에이전트 기반 자율 노출 탐색 및 자동 교정 |
| 리소스 효율성 | 수많은 오탐 경보 분석 병목 | 고위험 악용 경로 선별 집중 | SecOps와 DevOps 통합 DevSecOps 선제 파이프라인 연계 |
| 통제 신뢰성 | 정책 설정 후 방치 위험 | 실시간 공격 시뮬레이션 검증 | 제로 트러스트(ZTA) 아키텍처와 통합 PDP 엔진 연동 |

선제적 사이버보안은 보안의 패러다임을 '경보 대응'에서 '노출 제거'로 전환하는 핵심 전략이며, CTEM 프레임워크와 결합하여 방어 탄력성을 실현하는 것이 미래 사이버보안의 필수 방향.
