- 필수 키워드: 스마트 컨트랙트 · ERC-721 · IPFS · 재진입 공격(Reentrancy) · 오프체인 메타데이터 · 러그풀(Rug Pull)
- 기출: 128회 4교시 1번 `NFT 마켓 침해사례와 스마트 컨트랙트 취약점 대응` → Ⅰ·Ⅲ·Ⅵ / 127회 1교시 `NFT 보안위협` → Ⅱ·Ⅴ

## 한 줄 본질
- 블록체인 상의 고유 토큰(ERC-721)과 외부 대용량 미디어 데이터를 연결하는 거래 환경 → 온체인 컨트랙트 결함 및 오프체인 링크 조작으로 자산 탈취 위험 초래 → 디지털 소유권 거래 보장 / 코드 배포 후 수정 불가능

## 핵심 그림
```text
[NFT 마켓플레이스 이원화 아키텍처 및 보안 공격 접점]

 ┌─ [사용자/지갑] ──(Web3 서명)──> [ 프론트엔드 / 마켓플레이스 ]
 │                                         │
 │ [위협: 악성 서명 유도 피싱]            │ [위협: 중앙 서버 변조]
 │                                         ▼
 └─> [ 블록체인 네트워크 (온체인) ] ────────────────────────┐
     - 스마트 컨트랙트 (ERC-721)                             │
     - 토큰 ID, 소유자 주소, TokenURI 매핑                 │ TokenURI 참조
     [위협: 재진입성(Reentrancy), 정수 오버플로우]          ▼
                                                [ 분산 스토리지 (오프체인) ]
                                                - IPFS / Arweave / 중앙 S3
                                                - 미디어 파일(PNG, MP4), 속성
                                                [위협: 미디어 링크 교체/서버 중단]
```

## 핵심 용어
- 재진입 공격(Reentrancy Attack): 외부 컨트랙트를 호출한 뒤 상태 변수가 갱신되기 전에 원래 함수를 재귀적으로 다시 호출하여 자금을 중복 인출하는 공격
- 러그풀(Rug Pull): 가상자산/NFT 개발팀이 프로젝트를 홍보하여 투자금을 모은 뒤 스마트 컨트랙트의 권한을 이용해 유동성을 빼돌리고 잠적하는 사기 수법

## 핵심 통찰
- 대부분의 NFT는 이미지나 영상 자체가 블록체인에 저장되는 것이 아니라, 외부 URL(TokenURI)만을 저장하므로 오프체인 서버가 다운되면 '빈 껍데기 토큰'으로 전락함
- 스마트 컨트랙트는 한 번 배포되면 블록체인의 불변성으로 인해 버그 패치가 극도로 어려우므로 프록시 패턴(Upgradeable Proxy) 기반 아키텍처 설계가 권장됨
- 마켓플레이스 공격의 대다수는 블록체인 코어 해킹이 아닌 웹 프론트엔드의 취약한 서명 검증(EIP-712 미적용)을 노린 피싱 공격임

## 이웃 토픽과 구분
- NFT 보안 vs DeFi 보안: NFT 보안 = 토큰 소유권 이전 검증과 오프체인 미디어 무결성이 핵심 / DeFi 보안 = 오라클 가격 조작(Flash Loan)과 유동성 풀 고갈 방지가 핵심

## 문제·원인·대책
- 사례: 128회 기출 OpenSea 마켓플레이스에서 구버전 Wyvern 프로토콜 컨트랙트 미취소 주문을 악용한 저가 매수 사건
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 취소되지 않은 과거 오프체인 서명을 악용한 염가 매수 | 온체인 가스비 절감을 위해 오프체인 서명 방식을 쓰면서 취소 로직 불일치 | Seaport 신규 프로토콜 전환 및 타임스탬프 기반 서명 만료 강제 | 과거 서명 유효성 자동 무효화 및 부당 거래 방지 |
| 이미지 원본이 사라지고 깨진 링크 발생 | AWS S3 등 중앙 집중식 웹 호스팅 URL을 TokenURI로 사용 | 탈중앙 분산 영구 스토리지(IPFS 핀닝 서비스, Arweave) 적용 | 미디어 데이터의 영구 가용성 및 위변조 방지 |

## 이렇게 출제된다
- 제128회 4교시 1번: "최근 NFT(Non-Fungible Token) 마켓 활성화에 따른 보안 위협이 증가하고 있다. 대표적 NFT 거래소 침해사례를 바탕으로 스마트 컨트랙트 취약점과 마켓플레이스 보안 대응 방안을 설명하시오." → 요구 포인트: Ⅲ 온·오프체인 아키텍처 + Ⅵ 스마트 컨트랙트 보안 통제
- 제123회 1교시: "스마트 컨트랙트 보안 취약점 유형과 정적 분석 도구를 설명하시오." → 요구 포인트: Ⅱ 재진입성, 가스 한도 초과 등 취약점 유형
