## 연관 키워드

- QKD(Quantum Key Distribution), 양자 키 분배, BB84, 양자 채널, 공용 고전 채널
- 기저 교환(Basis Sifting), QBER(Quantum Bit Error Rate), 프라이버시 증폭(Privacy Amplification)
- PQC(Post-Quantum Cryptography), 신뢰 노드(Trusted Node), 양자 중계기(Quantum Repeater), 미끼 상태 프로토콜(Decoy State Protocol)
- 광자수 분할 공격(PNS Attack), MDI-QKD, ETSI GS QKD 014, 하이브리드 암호

## Ⅰ. QKD(양자 키 분배)의 개요

- 핵심 요약 : 양자 물리 법칙으로 도청 시도를 탐지하면서 대칭키를 나눠 갖는 양자 암호 통신 기술.
- 개념 : 광자의 **중첩** (Superposition), **불확정성 원리** (Uncertainty Principle), **복제 불가능성** (No-Cloning Theorem)을 이용해 송수신자 사이에 비밀 대칭키를 공유하는 **양자 키 분배** (QKD, Quantum Key Distribution).
- 배경 및 필요성 : 쇼어(Shor) 알고리즘을 실행할 수 있는 대규모 양자 컴퓨터가 현실화되면 RSA(Rivest-Shamir-Adleman)·ECC(Elliptic Curve Cryptography) 같은 공개키 암호의 안전성이 약해질 수 있어, 물리 법칙에 근거한 키 분배 대안이 검토됨.
- 주요 목적 : 가정 아래에서 계산 능력과 무관한 **정보이론적 안전성** (Information-Theoretic Security)을 확보하고, 도청이 시도되면 이를 물리적으로 즉시 드러내는 체계 구축.

## Ⅱ. QKD(양자 키 분배)의 특징 및 장점

- 핵심 요약 : 양자 채널과 고전 채널의 이중 구조, 그리고 오류율 점검이 도청 탐지와 키 기밀성으로 이어지는 원리.

1. 이중 채널 구조 : 단일 광자를 보내는 양자 채널과 기저 정보만 주고받는 공용 고전 채널을 분리 → 비밀값은 양자 채널에만 실리고, 고전 채널은 인증된 상태로 기저 정보만 담당.
2. 도청 즉시 탐지 : 도청자가 광자를 측정하면 상태가 바뀌어 기저가 일치하는 비트에서 오류가 늘어남 → 오류율 점검으로 도청을 확인하고 키를 폐기.
3. **기저 교환** (Basis Sifting) : 송수신자가 사용한 기저만 공개 비교하여 일치한 비트만 취함 → 비트값을 노출하지 않고 후보 키 확보.
4. **프라이버시 증폭** (Privacy Amplification, 도청자가 얻었을 잔여 정보를 해시 변환으로 줄이는 과정) → 최종 키의 기밀성 확보.

```text
[ QKD 이중 채널 구조 ]

송신자 (Alice)
   ══ 양자 채널 (단일 광자) ══>
수신자 (Bob)
   <── 공용 고전 채널 ──
   (기저 정보만, 인증 필수)
```

## Ⅲ. QKD(양자 키 분배)의 구조 (흐름)

- 핵심 요약 : **BB84** (Bennett과 Brassard가 1984년 제안한 대표 QKD 프로토콜)는 양자 전송, 기저 교환, 오류 측정, 후처리 순으로 최종 비밀키를 만든다.
- 원시 키 생성 (Raw Key Exchange) : 송신자가 무작위 비트를 편광 상태로 인코딩해 보내고, 수신자는 무작위 기저로 측정.
- **QBER** (Quantum Bit Error Rate, 양자 비트 오류율) : 샘플 비트를 공개 비교해 오류율을 계산하고 도청 여부를 판정.
- 도청 임계치 : 이론상 BB84 후처리 기준은 오류율 약 11%이며, 가로채기 후 재전송 방식의 도청은 기저 일치 구간에 약 25%의 오류를 만들어 탐지됨.

```text
[ BB84 키 분배 절차 ]

1. 송신 : 광자 전송 (4가지 편광)
   ↓
2. 수신 : 무작위 기저로 측정
   ↓
3. 공용 채널 : 기저만 공개
   ↓
4. 일치 비트 추출 (시프트 키)
   ↓
5. 샘플 비교 → QBER 측정
   ↓ 임계치 초과 시 폐기
6. 오류 정정 → 프라이버시 증폭
   ↓
최종 비밀키 공유
```

## Ⅳ. QKD(양자 키 분배)의 비교

- 핵심 요약 : QKD는 물리적 안전성과 장비 비용이 특징이고, PQC는 소프트웨어 전환이 쉬운 수학 기반 대안으로 서로 보완하는 관계.

| 비교 항목 | QKD (양자 키 분배) | PQC (Post-Quantum Cryptography, 양자내성암호) | 전통 공개키 암호 (RSA, ECC) |
| --- | --- | --- | --- |
| 안전성 근거 | 양자 물리 법칙 (불확정성, 비복제) | 수학적 난제 (격자, 다변수, 해시 기반) | 수학적 난제 (소인수분해, 이산대수) |
| 하드웨어 요구 | 전용 광학 링크, 단일광자 검출기 SPAD(Single-Photon Avalanche Diode) | 기존 통신 인프라와 범용 CPU | 기존 통신 인프라와 범용 CPU |
| 전송 거리 | 광섬유 감쇄로 장거리에서 신뢰 노드 필요 | 거리 제한 없음 | 거리 제한 없음 |
| 제공 기능 | 대칭키 분배 | 공개키 암호, 전자서명, 키 교환 | 공개키 암호, 전자서명, 키 교환 |
| 비용·배포성 | 고비용 (전용 광학망과 장비) | 소프트웨어 업그레이드 중심 | 기존 인프라 활용 |

- QKD는 인증된 고전 채널과 장비 가정 아래에서 키 분배 보안을 제공하지만, 구현 결함과 부채널 위협은 별도로 통제해야 하고 전용 광망 비용이 커서, 소프트웨어 전환이 가능한 PQC와 결합한 하이브리드 구성이 현실적 대안으로 거론됨.
- 참고 : [NSA의 QKD 보안 가정 및 구현상 한계 설명](https://www.nsa.gov/Cybersecurity/Quantum-Key-Distribution-QKD-and-Quantum-Cryptography-QC/).

## Ⅴ. QKD(양자 키 분배)의 한계와 방안

- 핵심 요약 : 거리 제약, 단일 광자 구현 한계, 검출기 공격이 남아 있으므로 신뢰 노드, 미끼 상태, 측정 장치 독립 구조로 나눠 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 광섬유 전송 감쇄에 따른 거리 제약 | 양자 비복제 원리상 고전 증폭기를 쓸 수 없어 장거리에서 광자 손실로 키 분배가 어려움 | 물리 보안이 인증된 **신뢰 노드** (Trusted Node)를 단계 배치, 장기적으로 **양자 중계기** (Quantum Repeater)와 위성 자유공간 광통신 (FSO, Free Space Optics) 구축 | 키 생성률, 신뢰 노드 보안 인증 상태 |
| **광자수 분할 공격** (PNS Attack, Photon Number Splitting) | 감쇄 레이저 펄스가 다중 광자를 내보내 도청자가 광자 하나를 가로챌 수 있음 | **미끼 상태 프로토콜** (Decoy State Protocol)로 신호와 미끼 펄스의 강도를 무작위로 바꿔 광자수 통계 왜곡을 탐지 | 미끼 상태 검사 이상 건수 |
| 검출기 **부채널 공격** (Side-Channel Attack) | APD(Avalanche Photodiode) 검출기에 강한 빛을 쏘아 블라인딩시키는 하드웨어 조작 | **MDI-QKD** (Measurement-Device-Independent QKD, 측정 장치 독립형) 도입으로 검출기 신뢰 가정을 제거 | 장치 검증 결과, 키 생성률 |

## Ⅵ. QKD(양자 키 분배)에 대한 기술사적 제언

- 핵심 요약 : 키 공급 표준, 우선 적용 구간, PQC와의 이중화를 묶어 QKD를 단독 기술이 아닌 하이브리드 전송 계층의 일부로 운영하는 방향.

1. 양자 키를 암호 장비에 넘기는 인터페이스는 ETSI(European Telecommunications Standards Institute) GS QKD 014 표준 API를 따르도록 하여, IPsec(Internet Protocol Security)과 MACsec(Media Access Control Security) 같은 고속 암호 장비에 키를 안정적으로 주입하는 구조를 표준화하는 것이 필요.
2. 전용 광망 구축 비용을 고려해 국방 지휘통제망, 정부 행정망, 금융 핵심 전송망처럼 장기 기밀성이 중요한 구간부터 우선 적용하는 것이 필요.
3. 인증 계층은 PQC 디지털 서명으로 검증하고 데이터 암호키 분배는 QKD로 이중화하는 하이브리드 전송 계층을 설계하는 것이 필요.

## Ⅶ. 결론

- 핵심 요약 : QKD는 도청 탐지를 물리 법칙에 위임하는 키 분배 기술이며, 단독으로 전체 통신 보안을 완성하지는 않음.
- 시사점 : 거리와 비용 제약 때문에 PQC와 결합한 하이브리드 설계가 현실적 경로이며, 키 분배의 보안은 장비 구현 보증과 함께 평가되어야 함.
