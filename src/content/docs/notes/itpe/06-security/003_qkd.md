## Ⅰ. QKD(양자 키 분배)의 개요

- **개념** : 양자역학의 기본 원리인 광자의 중첩(Superposition), 불확정성 원리(Uncertainty Principle), 복제 불가능성(No-Cloning Theorem)을 이용하여 송수신자 간에 도청이 불가능한 절대 안전 비밀 대칭키를 실시간 공유하는 양자 암호 통신 기술.
- **배경 및 필요성** : 쇼어(Shor) 알고리즘을 탑재한 대규모 양자 컴퓨터 출현 시 현재 인터넷 보안의 근간인 RSA, ECC 등 공개키 암호체계가 수초 내에 붕괴되는 '양자 암호학적 위기(Y2Q)'에 대응하기 위해 출현.
- **핵심 목적** : 물리 법칙에 기반한 무조건적 정보이론적 안전성(Information-Theoretic Security) 제공 및 도청 시도에 대한 물리적 즉각 탐지 체계 구축.

## Ⅱ. QKD(양자 키 분배)의 핵심 아키텍처 및 동작 메커니즘

QKD는 단일 광자 상태를 전송하는 양자 채널(Quantum Channel)과 측정 기저 정보를 교환하는 공용 고전 채널(Public Classical Channel)의 2중 경로를 사용하여 BB84 등의 프로토콜을 수행함.

```text
[ QKD(BB84) 양자 키 분배 동작 절차 ]

  +-------------+                                       +-------------+
  | Alice (송신) |                                       | Bob (수신)  |
  +------+------+                                       +------+------+
         │                                                     │
         │  1. 광자 송출 (단일 광자, 무작위 편광 4종류: 0°,90°,45°,135°)
         │===================[ 양자 채널 ]====================>│
         │                                                     │
         │  2. 기저 선택 측정 (수평/수직 '+' 또는 대각 'x')   │
         │                                                     │
         │  3. 사용 기저 정보 교환 (고전 채널, 비트값 미공개)   │
         │<------------------[ 고전 채널 ]-------------------->│
         │                                                     │
         │  4. 기저 일치 비트 추출 (Sifting) -> 시프트 키 형성  │
         │                                                     │
         │  5. 오류율(QBER) 측정 -> 임계치(11%) 초과 시 폐기   │
         │  6. 오류 정정(Cascade) 및 프라이버시 증폭(풍성 추출)│
         ▼                                                     ▼
    [ 최종 비밀키 공유 ] <==============================> [ 최종 비밀키 공유 ]
```

- **원시 키 생성(Raw Key Exchange)** : 송신자(Alice)가 무작위 비트열을 단일 광자의 4가지 편광 상태로 인코딩하여 양자 채널로 전송하고, 수신자(Bob)가 무작위 기저로 측정.
- **기저 교환(Basis Sifting)** : 고전 채널을 통해 서로 어떤 기저(+, x)를 사용했는지만 비교하여, 일치하는 기저에서 측정된 비트열만 추출(시프트 키).
- **오류율 측정(QBER Evaluation)** : 시프트 키의 일부를 공개 비교하여 양자 비트 오류율(QBER)을 산출. 도청자(Eve) 개입 시 25% 이상의 오류가 발생하여 도청 즉각 탄로.
- **오류 정정 및 비밀 증폭(Privacy Amplification)** : 전송 중 발생한 광학 잡음을 오류 정정 코드로 제거하고, 유니버설 해시 함수를 통해 도청자가 얻었을 수 있는 잔여 정보량을 0에 수렴하도록 압축하여 최종 비밀키 생성.

## Ⅲ. QKD(양자 키 분배)의 세부 구성 요소 및 비교 분석

| 비교 항목 | QKD (양자 키 분배) | PQC (양자내성암호) | 전통적 공개키 암호 (RSA/ECC) |
| --- | --- | --- | --- |
| 안전성 근거 | 양자 물리학 법칙 (불확정성, 비복제) | 수학적 난제 (격자, 다변수, 해시) | 수학적 난제 (소인수분해, 이산대수) |
| 하드웨어 요구 | 전용 광학 링크, 단일광자검출기(SPAD) | 기존 통신 인프라 및 범용 CPU 활용 | 기존 통신 인프라 및 범용 CPU 활용 |
| 전송 거리 한계 | 광섬유 감쇄로 통상 100~200km (신뢰노드 필요) | 거리 제한 없음 (글로벌 인터넷 적용) | 거리 제한 없음 (글로벌 인터넷 적용) |
| 제공 기능 | 대칭키(Symmetric Key) 분배만 수행 | 공개키 암호, 전자서명, 키 교환 | 공개키 암호, 전자서명, 키 교환 |
| 비용 및 배포성 | 고비용 (전용 광학망 및 암호장비 구축) | 저비용 (소프트웨어/알고리즘 업그레이드) | 기존 인프라 완비 |

- QKD는 물리적으로 완벽한 안전성을 보장하지만 전용 광선로 구축 비용과 거리 제약이 따르므로, 광역망 소프트웨어 전환이 가능한 PQC와 상호 결합된 QKD+PQC 하이브리드 아키텍처가 현실적인 대안으로 부각됨.

## Ⅳ. QKD(양자 키 분배)의 주요 한계점 및 해결 방안

- **광섬유 전송 감쇄에 따른 전송 거리 제약 및 중계기 한계** :
  - **한계점** : 양자 비복제 원리로 인해 고전 통신 증폭기(EDFA)를 사용할 수 없어 100~200km 이상 거리에서 광자 손실로 키 분배 불가.
  - **해결 방안** : 물리적 보안이 인증된 신뢰 노드(Trusted Node)를 단계적으로 배치하거나, 장기적으로 양자 얽힘 스와핑 기반 양자 중계기(Quantum Repeater) 및 위성 자유공간(FSO) 양자 통신망 구축.
- **단일 광자 소스 구현 한계로 인한 광자수 분할 공격(PNS Attack) 위협** :
  - **한계점** : 완벽한 단일 광자 대신 감쇄 레이저 펄스를 사용할 때 다중 광자(Multi-photon)가 방출되어 도청자가 광자 하나를 가로채 정보를 획득하는 PNS 취약점 잔존.
  - **해결 방안** : 미끼 상태 프로토콜(Decoy State Protocol)을 적용하여 신호 펄스와 미끼 펄스의 강도를 무작위 변경함으로써 광자수 통계 왜곡을 실시간 감지하여 PNS 공격 차단.
- **엔드포인트 검출기 하드웨어의 부채널 공격(Side-Channel Attack)** :
  - **한계점** : 광자 검출기(APD)에 강력한 레이저를 조사하여 검출기를 블라인딩(Blinding)시키는 하드웨어 조작 공격에 취약.
  - **해결 방안** : 측정 장치 독립 QKD(MDI-QKD, Measurement-Device-Independent QKD)를 도입하여 도청자가 모든 검출기를 제어하더라도 키의 기밀성을 완벽 보장하는 구조 적용.

## Ⅴ. QKD(양자 키 분배) 적용 및 발전을 위한 기술사적 제언

- **Q-KMS(양자 키 관리 시스템) 표준화 및 대칭 암호(AES-256) 연동** : QKD로 생성된 양자키를 고속 암호화 장비(IPsec, MACsec)에 안정적으로 주입하는 인터페이스(ETSI GS QKD 014) 표준화 필수.
- **국가 백본망 및 금융 핵심 전송망 우선 도입** : 전용선 구축 비용을 고려하여 국방 지휘통제망, 정부 종합행정망, 금융 코어망을 중심으로 우선 타깃 배포.
- **PQC와의 융합 하이브리드 전송 계층 설계** : 인증 계층은 PQC 디지털 서명으로 검증하고, 전송 데이터 암호키 분배는 QKD로 이중화하는 심층 다계층 양자 보안 체계 수립 필요.
