## 30초 인출

- 본질: **QKD (Quantum Key Distribution)** : 양자역학의 근본 법칙인 단일 광자 복제 불가성(No-Cloning)과 측정 시 상태 붕괴(불확정성 원리)를 이용하여 송수신자 간에 도청 시도가 물리적으로 즉시 발각되는 무조건적 안전성(Unconditional Security)을 보장하는 대칭키 분배 기술
- 메커니즘: 양자 채널을 통한 단일 광자 편광 전송 → 인증된 고전 채널을 통한 측정 기저 대조 및 원시 키 추출 → QBER 오류율 측정(임계치 11% 미만) → 오류 정정 및 비밀성 증폭(Privacy Amplification)을 거쳐 최종 비밀키 확정
- 통찰: 광섬유 전송 거리 한계(약 100km)와 광증폭 불가에 따른 신뢰 노드 메모리 노출 한계 극복을 위해 미끼 상태(Decoy-State) 프로토콜과 PQC 하이브리드 결합 체계 구축 필수

<details>
<summary>핵심 용어</summary>

- **BB84 프로토콜** : 1984년 베넷과 브라사드가 제안한 최초의 QKD 프로토콜로, 2개의 직교 기저(십자 기저, 대각 기저)와 4개 편광 상태를 활용
- **복제 불가능성 (No-Cloning Theorem)** : 임의의 알려지지 않은 미지의 양자 상태를 완벽하게 복제하는 물리적 연산자는 존재하지 않는다는 양자역학 정리
- **QBER (Quantum Bit Error Rate)** : 수신된 키 비트열 중 오류가 발생한 비율로, 11%를 초과할 경우 도청자가 개입한 것으로 판단하여 키 폐기
- **비밀성 증폭 (Privacy Amplification)** : 도청자가 부분 도청을 통해 얻었을 수 있는 미세한 정보량까지 압축 함수(Universal Hash)를 통해 수학적으로 0으로 소멸시키는 최종 키 정제 과정
- **PNS 공격 (Photon Number Splitting)** : 단일 광자 대신 감쇠 레이저 사용 시 2개 이상의 광자가 방출되는 다중 광자 펄스에서 1개만 가로채 도청하는 물리적 공격

## 2~4교시 25점 답안

## Ⅰ. QKD의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 단일 광자(Photon)의 양자 상태(편광 또는 위상)에 암호키 정보를 부호화하여 전송함으로써, 양자 물리학 법칙에 기반하여 도청자의 존재를 100% 탐지하고 절대적으로 안전한 비밀키를 원격 분배하는 기술 |
| 목적 | 양자컴퓨터(Shor 알고리즘)에 의해 무력화되는 RSA, ECC 등 현대 공개키 암호체계의 수학적 취약점을 물리 법칙 기반으로 영구 극복 |

## Ⅱ. QKD의 특징 및 기반 물리 이론

| 물리 이론 | 핵심 물리 법칙 | QKD 보안성 기여 특징 |
|---|---|---|
| **복제 불가능성** | No-Cloning Theorem | 도청자가 양자 채널을 지나가는 단일 광자를 복제하여 가로채고 원본을 그대로 통과시키는 도청 원천 불가 |
| **불확정성 원리** | Heisenberg Uncertainty | 단일 광자의 편광 상태를 관측(측정)하는 순간 양자 상태가 교란(붕괴)되어 비트 오류(QBER) 급증 |
| **일회용 패드 (OTP)** | One-Time Pad 연계 | QKD로 안전하게 생성된 비밀키를 평문과 1:1 XOR 암호화하여 샤논(Shannon)의 완전 비밀성(Perfect Secrecy) 달성 |
| **채널 이원화 구조** | Quantum + Classical | 단일 광자를 전송하는 '양자 채널'과 기저 대조 및 오류 정정을 수행하는 '인증된 고전 채널'의 분리 운용 |

## Ⅲ. BB84 프로토콜 아키텍처 및 4단계 키 정제 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ BB84 QKD 송수신 및 키 정제 프로세스 ]              │
│                                                                        │
│   [송신자 Alice]                                       [수신자 Bob]    │
│   - 난수 비트:  0   1   1   0   1                       │
│   - 선택 기저:  +   x   +   x   +                       │
│   - 송출 광자:  ↑   ↗   →   ↘   ↑                       │
│          │                                                │            │
│          ▼ [1. 양자 채널 (단일 광자 전송)]                │            │
│          ├───────────────────────────────────────────────►│            │
│          │                                                │ 측정 기저: │
│          │                                                │  +  +  x  x│
│          │                                                │ 측정 결과: │
│          │                                                │  0  0  0  0│
│          │                                                │            │
│          ▼ [2. 인증된 고전 채널 (기저 대조 및 후처리)]   │            │
│          │◄═══════ 사용한 측정 기저 정보만 상호 교환 ═════►│            │
│          │  - 일치 기저만 추출 -> 원시 키(Sifted Key) 생성 │            │
│          │  - 일부 비트 공개로 QBER(양자 비트 오류율) 측정 │            │
│          │  - QBER < 11% 만족 시: 오류 정정(Cascade) 집행 │            │
│          │  - 해시 함수 적용: 비밀성 증폭(Privacy Amplification) 완료 │
│          ▼                                                ▼            │
│   [최종 마스터 대칭 비밀키 공유 완료] (AES-256 / OTP 암호화에 즉각 투입)│
└────────────────────────────────────────────────────────────────────────┘
```

| 키 정제 단계 | 주관 채널 | 세부 수행 메커니즘 |
|---|---|---|
| **1. 원시 키 추출 (Sifting)** | 인증된 고전 채널 | Alice와 Bob이 각자 무작위로 선택했던 측정 기저(+, x) 목록을 대조하여 기저가 일치한 비트만 남김 (이론상 50% 추출) |
| **2. 오류율 추정 (QBER)** | 인증된 고전 채널 | 원시 키 중 일부 표본 비트를 공개하여 오류율을 계산; QBER이 임계치(통상 11%)를 넘으면 도청 감지로 판정하여 전량 폐기 |
| **3. 오류 정정 (Error Correction)**| 인증된 고전 채널 | 전송로 노이즈로 인해 발생한 불일치 비트를 쌍방향 정보 교환 알고리즘(Cascade / Winnow)으로 무오류 일치화 |
| **4. 비밀성 증폭 (Amplification)** | 인증된 고전 채널 | 오류 정정 과정에서 도청자에게 노출되었을 가능성이 있는 정보량만큼 유니버설 해시 함수를 통해 키 길이를 압축하여 잔여 정보 0 수렴 |

## Ⅳ. QKD(양자키분배) vs PQC(양자내성암호) 비교

| 비교 항목 | QKD (Quantum Key Distribution) | PQC (Post-Quantum Cryptography) |
|---|---|---|
| **보안 기반** | **물리학 법칙 (양자역학 상태 붕괴 및 복제 불가)**| **수학적 난제 (격자, 다변수, 해시 기반 복잡도)** |
| **하드웨어 요구사항** | **단일 광자 검출기(APD), 레이저, 전용 암실 광섬유**| **기존 범용 컴퓨터, 스마트폰, 서버 그대로 사용 가능** |
| **전송 거리 및 확장성**| 물리 광섬유 감쇠로 80~100km 제한 (중계기 필요)| **소프트웨어 업데이트로 전 세계 인터넷 즉각 배포 가능** |
| **수행 암호 기능** | **대칭키 분배(Key Distribution) 기능만 단독 수행** | **공개키 암호화(KEM) 및 전자서명(Signature) 완전 수행** |
| **도청 탐지 능력** | **물리적 도청 시도 즉각 실시간 탐지 가능** | 도청 여부 탐지 불가 (수학적 해독 저항성에 의존) |
| **국제 표준화** | ITU-T Y.3800 시리즈, ETSI QKD ISG | **NIST FIPS 203(ML-KEM), FIPS 204(ML-DSA) 제정 완료**|

## Ⅴ. QKD 구축 및 운영 시 핵심 엔지니어링 한계와 방안

| 한계 | 방안 |
|---|---|
| 광섬유 코어 내 레일리 산란 및 흡수 손실(0.2dB/km)로 인해 전송 거리가 80~100km로 제한되며, 양자 복제 불가성으로 인해 광증폭기(EDFA)를 쓸 수 없어 장거리 전송 시 신뢰 노드(Trusted Node)를 거칠 때 키가 메모리에 평문 노출되는 중간자 위험 발생 | 단기적으로 신뢰 노드에 내충격성 군사 등급 하드웨어 보안 모듈(HSM)과 물리적 침입 탐지 센서를 결합하고, 장기적으로는 양자 얽힘 스와핑(Entanglement Swapping) 기반의 순수 전광 양자 중계기(Quantum Repeater) 및 LEO 저궤도 양자 통신 위성 링크를 결합한 전 지구적 커버리지 구축 |
| 단일 광자원(Single Photon Source) 제작의 기술적 한계로 감쇠 레이저 펄스를 대체 사용할 때, 확률적으로 2개 이상의 광자가 한 펄스에 묶여 방출되는 다중 광자 결함을 악용하여 도청자가 1개 광자만 분리 도청하는 광자수 분리(PNS) 공격 발생 | 신호 광자 외에 세기가 다른 미끼 광자를 무작위로 섞어 전송하여 도청자의 채널 투과율 왜곡을 통계적으로 완벽히 잡아내는 미끼 상태(Decoy-state) 프로토콜을 도입하고, 측정 장비의 물리적 결함 도청을 원천 배제하는 측정 장치 독립형(MDI-QKD) 아키텍처 적용 |
| QKD 후처리 단계에서 기저 대조 및 에러 정정을 수행하는 고전 채널(Classical Channel)이 스푸핑될 경우 Man-in-the-Middle 공격으로 가짜 키가 수립되는 위험 상존 | 고전 통신 채널에 사전에 안전하게 공유된 소량의 초기 대칭키를 활용하여 웨그먼-카터(Wegman-Carter) 정보이론적 안전성을 갖는 메시지 인증 코드(MAC) 무조건 적용 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
국가 백본망 및 금융 코어망 설계 시, QKD와 PQC를 상호 배타적 경쟁 기술로 인식하는 관점을 버리고, 백본 국사 간 물리 전송 링크는 QKD로 보호하고 종단 단말 및 클라우드 구간은 PQC 알고리즘을 적용하는 'QKD + PQC 하이브리드 심층 방어(Defense-in-Depth)' 표준 아키텍처 수립 권장

### 2. 아키텍처 및 상세 메커니즘
```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ QKD + PQC 하이브리드 차세대 양자 보안망 아키텍처 ]     │
│                                                                        │
│   [통신 국사 A (Core)]                                 [통신 국사 B (Core)]│
│   ┌──────────────┐                                     ┌─────────────┐ │
│   │ QKD 송신 장치├─── 양자 채널 (암실 광섬유 케이블) ──►│ QKD 수신 장치│ │
│   └──────┬───────┘                                     └──────┬──────┘ │
│          │ QKD 비밀키 생성                                    │        │
│          ▼                                                    ▼        │
│   ┌──────────────┐                                     ┌─────────────┐ │
│   │ 키 관리기(KMS)│                                     │ 키 관리기(KMS││
│   └──────┬───────┘                                     └──────┬──────┘ │
│          │                                                    │        │
│          ▼ [키 결합 엔진: K = KDF(QKD_Key || PQC_Key)]        ▼        │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │      IPsec / MACsec 고속 광전송 암호화 장비 (하이브리드 암호)    │   │
│   │  - PQC KEM(ML-KEM)으로 교환된 키와 QKD 물리키를 XOR 믹싱       │   │
│   │  - 초당 수십만 회 고속 키 갱신 -> 800Gbps 트래픽 실시간 암호화│   │
│   └────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| QKD 프로토콜 유형 | 신호 상태 원리 | 최대 전송 거리 | PNS 공격 내성 | 시스템 구현 난이도 |
|---|---|---|---|---|
| **표준 BB84** | 단일 광자 편광 | ~ 50 km | 취약 (PNS 공격 노출) | 낮음 (최초 상용화) |
| **Decoy-State BB84** | 다중 강도 펄스 혼용 | **~ 100 km 이상** | **완전 면역 (도청 탐지)** | **중간 (현재 글로벌 상용 표준)**|
| **E91 프로토콜** | 양자 얽힘(Entanglement) 벨 부등식 | ~ 100 km | 완전 면역 (얽힘 파괴 탐지) | 높음 (얽힘 광자원 필요) |
| **MDI-QKD** | 수신단 측정 장비 독립화 | **~ 400 km (비신뢰 릴레이)** | **검출기 해킹 완전 면역** | **매우 높음 (차세대 연구)** |
