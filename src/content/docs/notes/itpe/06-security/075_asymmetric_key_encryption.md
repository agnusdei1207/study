## Ⅰ. 비대칭키 암호화(Asymmetric Key Encryption)의 개요

- ** 개념** : 수학적으로 연결된 한 쌍의 키(누구나 알 수 있는 공개키와 소유자만 아는 개인키)를 사용하여 데이터 기밀성, 전자서명, 키 교환을 제공하는 공개키 암호 기술.
- ** 배경 및 필요성** : 대칭키 암호화의 근본적 한계인 사전에 안전한 키 분배 채널이 필요하다는 문제(Key Distribution Problem)를 수학적 일방향 트랩도어 함수를 통해 공개 채널에서도 안전하게 해결하기 위해 출현함.
- ** 핵심 목적** : 대칭키의 본질적 난제인 안전하지 않은 채널에서의 '키 배송 문제(Key Distribution)' 해결 및 법적 효력을 갖는 부인방지(Non-repudiation) 제공.

## Ⅱ. 비대칭키 암호화(Asymmetric Key Encryption)의 핵심 아키텍처 및 동작 메커니즘

비대칭키 암호화(Asymmetric Key Encryption)은(는) 신뢰할 수 있는 보안 구조와 표준화된 절차를 기반으로 동작하며, 세부적인 아키텍처와 구성요소 간의 상호작용 메커니즘은 다음과 같음.

```text
[ 1. 기밀성 보장 (Confidentiality) ] ── 수신자의 공개키 사용
송신자 ──▶ 평문 (M) ──▶ [ 수신자 공개키로 암호화 ] ──▶ 암호문 (C) ──▶ [ 수신자 개인키로 복호화 ] ──▶ 평문 (M)

[ 2. 인증 및 부인방지 (Digital Signature) ] ── 송신자의 개인키 사용
송신자 ──▶ 원본 (M) 해시 ──▶ [ 송신자 개인키로 서명 ] ──▶ 서명값 (S) ──▶ [ 송신자 공개키로 검증 ] ──▶ 무결성/신원 확인!

[ 3. 키 합의 및 수송 (Key Establishment / KEM) ]
클라이언트 ──▶ 공개키 파라미터 교환 (ECDH / ML-KEM) ◀── 서버
                    │                                        │
                    ▼                                        ▼
             동일한 대칭 세션키 (Session Key) 유도 ──▶ AES-GCM 대칭 통신 개시
```

- ** 데이터 기밀성** : ** 수신자의 공개키 (Receiver's Public Key)** (** 수신자의 개인키 (Receiver's Private Key)**).
- ** 전자서명 (인증)** : ** 송신자의 개인키 (Sender's Private Key)** (** 송신자의 공개키 (Sender's Public Key)**).
- ** 키 교환 (KEM/ECDH)** : 양측의 공개키 파라미터 교환 (각자의 개인키로 동일 공유 비밀 유도).

## Ⅲ. 비대칭키 암호화(Asymmetric Key Encryption)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 비대칭키 암호화 (Asymmetric) | 대칭키 암호화 (Symmetric) |
|---|---|---|
| 키 구성 | 공개키 + 개인키 (비대칭 쌍) | 동일한 단일 비밀키 |
| 연산 속도 | 상대적으로 느림 (모듈러 멱승 연산) | 극도로 빠름 (비트 단위 치환/순열) |
| 키 개수 ($N$명) | **$2N$ 개** (선형적 확장) | **$N(N-1)/2$ 개** (기하급수적 폭증) |
| 키 배송 문제 | 해결 (공개키는 공개 채널로 배포) | 미해결 (사전 비밀 공유 경로 필요) |
| 제공 기능 | 기밀성, 전자서명, 부인방지, 키 교환 | 기밀성, 무결성(AEAD) |
| 주 용도 | TLS 키 교환, 인증서, 블록체인 서명 | 대용량 DB 암호화, 파일/디스크 암호화 |
| 구분 | RSA | 타원곡선 암호 (ECC) | 디피-헬만 (DH) | 격자 기반 PQC (ML-KEM) |
|---|---|---|---|---|
| 기반 난제 | 큰 합성수의 소인수분해 | 타원곡선 이산대수 (ECDLP) | 유한체 이산대수 (DLP) | 모듈 격자 상의 오류 학습 (MLWE) |
| 키 크기 (128bit 보안)| 3072 비트 | ** 256 비트** | 3072 비트 | 공개키 약 1184 바이트 |
| 특징 | 표준화 역사 오래됨, 검증됨 | 소형 키, 고속 연산, 저전력 | 키 교환 전용 알고리즘 | ** 양자컴퓨터 쇼어 알고리즘 내성** |
| 대표 표준 | PKCS#1, FIPS 186-5 | secp256r1, Ed25519 | RFC 3526, RFC 7919 | FIPS 203 (Kyber) |

- 비대칭키 암호화(Asymmetric Key Encryption)은(는) 상기 핵심 비교 지표와 아키텍처 구성을 바탕으로 보안 위협에 대한 방어 효과성을 극대화하며, 기존 레거시 통제 기법 대비 우수한 신뢰성과 운영 효율성을 제공함.

## Ⅳ. 비대칭키 암호화(Asymmetric Key Encryption)의 주요 한계점 및 해결 방안

- ** 공개키가 공개 채널로 전달될 때 중간자 공격(MitM) 관련 보안 한계 및 취약점** : - ** 한계점** : 공개키가 공개 채널로 전달될 때 중간자 공격(MitM)에 의해 공격자의 가짜 공개키로 바꿔치기 당할 위험.
  - ** 해결 방안** : 공인인증기관(CA)이 소유자 신원과 공개키를 바인딩하여 서명한 X.509 공개키기반구조(PKI) 체계 수립.
- ** 복잡한 고차원 수학 연산(모듈러 지수 연산) 관련 보안 한계 및 취약점** : - ** 한계점** : 복잡한 고차원 수학 연산(모듈러 지수 연산)으로 인해 대용량 멀티미디어 및 데이터베이스 암호화 시 심각한 CPU 병목.
  - ** 해결 방안** : 실제 대용량 데이터는 AES 대칭키로 암호화하고, 해당 대칭키만 수신자 공개키로 암호화하는 하이브리드 암호화(Hybrid Encryption) 적용.
- ** 쇼어(Shor) 알고리즘 기반 양자컴퓨팅 환경에서의 수학적 붕괴** : - ** 한계점** : 대규모 범용 양자컴퓨터의 쇼어(Shor) 알고리즘 구동 시 소인수분해(RSA)와 이산대수(ECC) 기반 암호가 다항 시간 내에 완전 붕괴.
  - ** 해결 방안** : 미국 NIST가 표준화한 격자 기반 양자내성 암호(ML-KEM, ML-DSA)를 도입하고 기존 공개키와 PQC를 결합한 하이브리드 암호 민첩성(Crypto-Agility) 구축.

## Ⅴ. 비대칭키 암호화(Asymmetric Key Encryption) 적용 및 발전을 위한 기술사적 제언

- ** 하이브리드 키 교환 (X25519 + ML-KEM) 체계 도입** : 하이브리드 키 교환 (X25519 + ML-KEM) 기술을 적극 적용하여 보안 취약점을 차단하고 시스템 신뢰성을 보장해야 함.
- ** 하이브리드 전자서명 (Ed25519 + ML-DSA) 체계 도입** : 하이브리드 전자서명 (Ed25519 + ML-DSA) 기술을 적극 적용하여 보안 취약점을 차단하고 시스템 신뢰성을 보장해야 함.
- ** X.509 PKI 인증서 체인 PQC 확장 표준화 체계 도입** : X.509 PKI 인증서 체인 PQC 확장 표준화 기술을 적극 적용하여 보안 취약점을 차단하고 시스템 신뢰성을 보장해야 함.
