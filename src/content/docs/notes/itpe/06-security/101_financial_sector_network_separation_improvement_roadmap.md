## 지식 로드맵 내 현재 위치

지식 위치: 금융 보안 → 망분리 정책 → **2024년 개선 로드맵**

## 30초 인출

- 본질: 금융위가 2024년 발표한 AI·SaaS 활용과 연구·개발 환경 개선을 위한 망분리 규제의 단계적 개선 방향
- 메커니즘: 단기 혁신금융서비스의 조건부 실증 → 중기 감독규정 개선 검토 → 장기 법·제도 정비 구상
- 통찰: 한계: 발표된 로드맵을 현행 일괄 허용으로 오해할 수 있음 → 방안: 개별 지정 조건·후속 규정과 데이터 전송 범위를 확인

<details><summary>핵심 용어</summary>

- 혁신금융서비스: 특정 금융 서비스에 조건을 붙여 규제 특례를 시험하는 제도.
- 망분리: 업무·인터넷 등 네트워크 경계를 분리해 접근을 통제하는 방식.

</details>

## 2~4교시 예상문제 (25점)

> 금융분야 망분리 개선 로드맵의 배경과 단계별 방안을 설명하고 AI·SaaS 활용 시 데이터·접근·운영 보안 대책을 제시하시오. (예상·25점)

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 금융분야 망분리 개선 로드맵은 2024년 금융위원회가 발표한 AI·SaaS 활용과 개발 환경의 단계적 규제 개선 방향 |
| 목적 | 조건부 실증과 후속 제도 정비를 통한 금융 혁신·데이터 보호의 병행 검토 |

업무망과 외부 서비스의 일률적 단절이 AI·SaaS·개발 협업을 제한. 개선은 업무 혁신과 개인신용정보·핵심 시스템 보호를 함께 검토하는 규제 조정 과제.

### Ⅱ. 데이터 중심 적용 구조

```text
업무 데이터 분류
    ↓
AI·SaaS 사용 목적·전송 범위 승인
    ↓
신원·단말 확인 → 접근 중개·기록 → 데이터 반출 검사
    ↓
서비스 제공자 계약·로그·사고 대응·복구 검증
```

### Ⅲ. 발표된 로드맵

```text
조건부 실증 ─> 후속 규정 검토 ─> 장기 법제 구상
    │               │                  │
개별 지정 조건   실제 개정 여부       입법 여부 확인
```

| 구분 | 정책 방향 | 현행 여부 판단 |
|---|---|---|
| 단기 | 혁신금융서비스 등 조건부 실증 | 지정 내용·부가 조건 확인 |
| 중기 | 감독규정과 가이드 개선 | 실제 개정 문서 확인 |
| 장기 | 자율보안·사후 책임 법체계 검토 | 입법 완료와 계획을 구분 |

'디지털 금융보안법 제정 완료', '전 금융권 SaaS 전면 허용' 등은 발표 자료만으로 현행 의무·허용 사항이라고 단정할 수 없음.

#### 주요 위험과 통제

| 위험 | 대책 |
|---|---|
| 프롬프트에 개인신용정보 포함 | 데이터 분류·최소화·전송 제한·검토 |
| SaaS 계정·권한 탈취 | MFA·최소 권한·세션·퇴직자 계정 관리 |
| 개발망에서 운영망으로 이동 | 환경 분리·배포 승인·비밀정보 관리 |
| 외부 서비스 장애·유출 | 계약상 통지·데이터 반환·대체 절차 |

자동 마스킹이나 특정 제로트러스트 제품 하나가 모든 샌드박스 사례의 법정 필수 조건인 것은 아님.

#### 도입 검증

업무별 이용 데이터와 위험 수준을 분리하고, 규제 샌드박스 지정 조건·전자금융감독규정·개인정보 및 신용정보 관련 의무를 각각 확인. 변경 전 보안성 평가와 경영진 잔여 위험 수용 절차 운영.

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 발표된 망분리 완화 로드맵을 현행 일괄 허용으로 오해할 위험 | 개별 지정 조건·후속 규정과 데이터 전송 범위를 확인한 뒤 단계 적용 |

### Ⅴ. 제언

망 연결 방식만 바꾸는 것이 아니라 데이터 이동·접근 권한·공급자 책임과 사고 복구를 묶어 단계별 검증.
