## Ⅰ. 벨라파듈라 모델(BLP)의 개요

- ** 개념** : 미 국방부(DoD) 다중 보안 등급(Top Secret, Secret, Confidential, Unclassified) 체계에서 상위 기밀 정보가 하위 보안 등급으로 유출되는 것을 차단하기 위해 고안된 형식적 강제 접근통제(MAC) 기밀성 모델.
- ** 배경 및 필요성** : 군사 및 국가 기밀 정보 시스템에서 비인가자에 의한 기밀 누설을 수학적으로 방지하기 위해, 다중 보안 등급(MLS)을 기반으로 정보의 하향 유출을 원천 통제하는 강제적 접근통제(MAC) 이론으로 정립됨.
- ** 핵심 목적** : 트로이목마나 악성 프로세스에 의한 기밀 정보의 불법 하향 유출 방지 및 상태 전이 기반의 엄격한 기밀성(Confidentiality) 보장.

## Ⅱ. 벨라파듈라 모델(BLP)의 핵심 아키텍처 및 동작 메커니즘

벨라파듈라 모델(BLP)은(는) 신뢰할 수 있는 보안 구조와 표준화된 절차를 기반으로 동작하며, 세부적인 아키텍처와 구성요소 간의 상호작용 메커니즘은 다음과 같음.

```text
[ 높은 보안 등급 (Top Secret) ]
          │                    ▲
   읽기   │ (Read Down 가능)   │ 쓰기 (Write Up 가능: Blind Write)
   허용   ▼                    │ 허용
[ 낮은 보안 등급 (Unclassified) ]

─────────────────────────────────────────────────────────────
[ 접근 통제 규칙 판정 매트릭스 ]
           ┌───────────────────────────────┐
           │      객체 (Object Level)      │
           ├───────────────┬───────────────┤
           │  높음 (High)  │  낮음 (Low)   │
┌────┬─────┼───────────────┼───────────────┤
│    │ High│ 읽기/쓰기 가능│ 읽기만 가능   │
│주체│     │               │ (NWD:쓰기금지)│
│    ├─────┼───────────────┼───────────────┤
│(S) │ Low │ 쓰기만 가능   │ 읽기/쓰기 가능│
│    │     │ (NRU:읽기금지)│               │
└────┴─────┴───────────────┴───────────────┘
```

- ** 읽기 (Read)** : ** 거부 (No Read Up)** (허용).
- ** 쓰기 (Write)** : ** 허용 (Write Up: Append)** (허용).
- ** 실행 (Execute)** : 거부 (허용).

## Ⅲ. 벨라파듈라 모델(BLP)의 세부 구성 요소 및 비교 분석

| 구분 | 벨-라파듈라 모델 (BLP) | 비바 모델 (Biba) | 클락-윌슨 모델 (Clark-Wilson) |
|---|---|---|---|
| 핵심 보안 목표 | ** 기밀성 보장 (Confidentiality)** | ** 무결성 보장 (Integrity)** | ** 상업적 무결성 및 직무 분리** |
| 읽기 통제 원칙 | No Read Up (NRU) | No Read Down (NRD) | 인증된 변환 절차(TP) 경유 읽기 |
| 쓰기 통제 원칙 | No Write Down (NWD) | No Write Up (NWU) | 비인가된 데이터 변경 원천 차단 |
| 주된 적용 분야 | 군사, 국방, 정보기관 | 금융, 거래 원장, 시스템 무결성 | 기업 ERP, 회계 시스템, 전자상거래 |
| 치명적 약점 | 무결성 파괴, 은닉 채널 취약 | 기밀성 유출 방어 불가 | 구현 복잡도 및 오버헤드 과다 |

- 벨라파듈라 모델(BLP)은(는) 상기 핵심 비교 지표와 아키텍처 구성을 바탕으로 보안 위협에 대한 방어 효과성을 극대화하며, 기존 레거시 통제 기법 대비 우수한 신뢰성과 운영 효율성을 제공함.

## Ⅳ. 벨라파듈라 모델(BLP)의 주요 한계점 및 해결 방안

- ** No Write Down 규칙 관련 보안 한계 및 취약점** : - ** 한계점** : No Write Down 규칙으로 인해 하위 주체가 상위 객체에 내용을 추가하는 상향 쓰기(Write Up, Blind Write)가 허용되어 고등급 시스템 무결성 오염 위험.
  - ** 해결 방안** : 기밀성의 BLP 모델과 무결성의 Biba 모델을 동시 적용하는 이중 격자(Dual-Lattice) 다중 등급 보안 모델 채택.
- ** CPU 점유 시간 위험** : - ** 한계점** : CPU 점유 시간, 공유 디스크 여유 공간, 시스템 플래그 등 공유 자원을 시간차로 조작하여 정보를 전달하는 은닉 채널(Covert Channel) 방어 불가.
  - ** 해결 방안** : 공유 자원 매트릭스(Shared Resource Matrix) 분석을 통해 은닉 채널을 식별하고 타이밍 채널에 무작위 노이즈 주입 및 대역폭 제한.
- ** 실제 상용 비즈니스 관련 보안 한계 및 취약점** : - ** 한계점** : 실제 상용 비즈니스 환경에서 상위 관리자가 하위 실무자에게 보고서를 공개하거나 등급을 낮추는 업무(Downgrade)가 전면 차단되는 경직성.
  - ** 해결 방안** : 인증된 보안 관리자(Trusted Subject)만이 엄격한 감사 로깅과 다중 승인을 거쳐 문서를 안전하게 하향 공개하는 탈분류(Declassification) 프로세스 제도화.

## Ⅴ. 벨라파듈라 모델(BLP) 적용 및 발전을 위한 기술사적 제언

- ** MLS 이중 격자 (BLP 기밀성 + Biba 무결성) 체계 도입** : MLS 이중 격자 (BLP 기밀성 + Biba 무결성) 기술을 적극 적용하여 보안 취약점을 차단하고 시스템 신뢰성을 보장해야 함.
- ** Trusted Subject 기반 안전한 탈분류 체계 도입** : Trusted Subject 기반 안전한 탈분류 기술을 적극 적용하여 보안 취약점을 차단하고 시스템 신뢰성을 보장해야 함.
- ** 속성 기반 동적 접근제어 (ABAC / ZTA) 체계 도입** : 속성 기반 동적 접근제어 (ABAC / ZTA) 기술을 적극 적용하여 보안 취약점을 차단하고 시스템 신뢰성을 보장해야 함.
