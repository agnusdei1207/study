## 지식 로드맵 내 현재 위치

정보보안 → 접근 통제 → 강제적 접근통제(MAC) 및 기밀성 모델(BLP)

## 30초 인출

- **본질:** 다중 등급 보안(MLS) 환경에서 주체와 객체의 보안 레벨을 기반으로 상위 기밀 정보의 비인가 유출을 차단하는 최초의 수학적 상태 전이 기밀성(Confidentiality) 접근통제 모델
- **메커니즘:** 단순 보안 속성(No Read Up: 하위 주체 상위 읽기 금지) + 스타 속성(No Write Down: 상위 주체 하위 쓰기 금지) + 재량적 보안 속성(접근 제어 행렬 만족)
- 통찰: 기밀성 유출 방지에 완벽한 수학적 정합성을 제공하지만 무결성 훼손과 은닉 채널의 취약점을 극복하기 위해 비바(Biba) 모델과의 결합 및 신뢰된 주체(Trusted Subject) 기반 탈분류 거버넌스 수립 필수

<details><summary>핵심 용어</summary>

- **벨-라파듈라 모델(BLP):** David Bell과 Leonard LaPadula가 1973년 미 국방부(DoD) 보안 요구에 따라 설계한 최초의 형식적 기밀성 다중 등급 보안 모델.
- **단순 보안 속성 (Simple Security Property):** No Read Up (NRU). 주체는 자신보다 높은 보안 등급의 객체를 읽을 수 없음.
- **스타(*) 속성 (*-Property, Confinement):** No Write Down (NWD). 주체는 자신보다 낮은 보안 등급의 객체에 데이터를 쓸 수 없음(트로이목마 정보 유출 방어).
- **재량적 보안 속성 (ds-property):** 강제적 등급 통제 외에 접근 행렬(Access Matrix) 상의 명시적 권한을 추가로 만족해야 접근 허용.
- **지배 관계 (Dominance):** 주체의 보안 등급이 객체의 보안 등급 이상이고, 주체의 범주(Category) 집합이 객체의 범주 집합을 완전히 포함할 때 지배한다고 판정.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 미 국방부(DoD) 다중 보안 등급(Top Secret, Secret, Confidential, Unclassified) 체계에서 상위 기밀 정보가 하위 보안 등급으로 유출되는 것을 차단하기 위해 고안된 형식적 강제 접근통제(MAC) 기밀성 모델 |
| 목적 | 트로이목마나 악성 프로세스에 의한 기밀 정보의 불법 하향 유출 방지 및 상태 전이 기반의 엄격한 기밀성(Confidentiality) 보장 |

## Ⅱ. 벨-라파듈라 모델의 주요 특징 및 3대 핵심 보안 속성

| 속성 명칭 | 규칙 및 핵심 원리 | 상세 설명 | 방어 목적 |
|---|---|---|---|
| 단순 보안 속성 (Simple Security) | **No Read Up (NRU)** | 주체는 자신보다 높은 보안 등급을 가진 객체를 절대 읽을 수 없음 | 하위 권한 주체의 기밀 도청 차단 |
| 스타(*) 속성 (*-Property) | **No Write Down (NWD)** | 주체는 자신보다 낮은 보안 등급을 가진 객체에 절대 데이터를 기록할 수 없음 | 트로이목마에 의한 비밀 정보 하향 유출 차단 |
| 재량적 보안 속성 (ds-property) | **Access Matrix 준수** | 강제 등급 규칙을 통과하더라도 접근 제어 행렬 상에 명시된 재량 권한이 없으면 거부 | 다중 계층 최소 권한 원칙 집행 |

## Ⅲ. BLP 모델의 정보 흐름 및 보안 상태 전이 체계

```text
[ 높은 보안 등급 (Top Secret) ]
          │                    ▲
   읽기   │ (Read Down 가능)   │ 쓰기 (Write Up 가능: Blind Write)
   허용   ▼                    │ 허용
[ 낮은 보안 등급 (Unclassified) ]

─────────────────────────────────────────────────────────────
[ 접근 통제 규칙 판정 매트릭스 ]
           ┌───────────────────────────────┐
           │      객체 (Object Level)      │
           ├───────────────┬───────────────┤
           │  높음 (High)  │  낮음 (Low)   │
┌────┬─────┼───────────────┼───────────────┤
│    │ High│ 읽기/쓰기 가능│ 읽기만 가능   │
│주체│     │               │ (NWD:쓰기금지)│
│    ├─────┼───────────────┼───────────────┤
│(S) │ Low │ 쓰기만 가능   │ 읽기/쓰기 가능│
│    │     │ (NRU:읽기금지)│               │
└────┴─────┴───────────────┴───────────────┘
```

| 접근 요청 유형 | 객체 > 주체 | 객체 = 주체 | 객체 < 주체 |
|---|---|---|---|
| 읽기 (Read) | **거부 (No Read Up)** | 허용 | **허용 (Read Down)** |
| 쓰기 (Write) | **허용 (Write Up: Append)** | 허용 | **거부 (No Write Down)** |
| 실행 (Execute) | 거부 | 허용 | 거부 |

## Ⅳ. 벨-라파듈라(BLP) vs 비바(Biba) vs 클락-윌슨(Clark-Wilson) 비교

| 구분 | 벨-라파듈라 모델 (BLP) | 비바 모델 (Biba) | 클락-윌슨 모델 (Clark-Wilson) |
|---|---|---|---|
| 핵심 보안 목표 | **기밀성 보장 (Confidentiality)** | **무결성 보장 (Integrity)** | **상업적 무결성 및 직무 분리** |
| 읽기 통제 원칙 | No Read Up (NRU) | No Read Down (NRD) | 인증된 변환 절차(TP) 경유 읽기 |
| 쓰기 통제 원칙 | No Write Down (NWD) | No Write Up (NWU) | 비인가된 데이터 변경 원천 차단 |
| 주된 적용 분야 | 군사, 국방, 정보기관 | 금융, 거래 원장, 시스템 무결성 | 기업 ERP, 회계 시스템, 전자상거래 |
| 치명적 약점 | 무결성 파괴, 은닉 채널 취약 | 기밀성 유출 방어 불가 | 구현 복잡도 및 오버헤드 과다 |

## Ⅴ. 벨-라파듈라(BLP) 모델의 한계와 방안

| 한계 | 방안 |
|---|---|
| No Write Down 규칙으로 인해 하위 주체가 상위 객체에 내용을 추가하는 상향 쓰기(Write Up, Blind Write)가 허용되어 고등급 시스템 무결성 오염 위험 | 기밀성의 BLP 모델과 무결성의 Biba 모델을 동시 적용하는 이중 격자(Dual-Lattice) 다중 등급 보안 모델 채택 |
| CPU 점유 시간, 공유 디스크 여유 공간, 시스템 플래그 등 공유 자원을 시간차로 조작하여 정보를 전달하는 은닉 채널(Covert Channel) 방어 불가 | 공유 자원 매트릭스(Shared Resource Matrix) 분석을 통해 은닉 채널을 식별하고 타이밍 채널에 무작위 노이즈 주입 및 대역폭 제한 |
| 실제 상용 비즈니스 환경에서 상위 관리자가 하위 실무자에게 보고서를 공개하거나 등급을 낮추는 업무(Downgrade)가 전면 차단되는 경직성 | 인증된 보안 관리자(Trusted Subject)만이 엄격한 감사 로깅과 다중 승인을 거쳐 문서를 안전하게 하향 공개하는 탈분류(Declassification) 프로세스 제도화 |

## Ⅵ. 제언

```text
[ 단일 BLP 모델의 한계 ]             [ 현대적 다차원 접근 통제 체계 ]
기밀성만 극단적 통제 ──┐             ┌── MLS 이중 격자 (BLP 기밀성 + Biba 무결성)
상향 쓰기로 데이터 오염 ┼─→ [ 통제 왜곡 ] ─┼── Trusted Subject 기반 안전한 탈분류
은닉 채널 무방비 노출 ──┘             └── 속성 기반 동적 접근제어 (ABAC / ZTA)
```

| 평가 영역 | 전통적 BLP 모델 | 복합 보안 모델 (BLP + Biba) | 차세대 제로 트러스트 (ZTA) |
|---|---|---|---|
| 보호 범위 | 기밀성 단독 | 기밀성 + 무결성 융합 | 기밀성, 무결성, 가용성 동시 만족 |
| 통제 유연성 | 극도로 경직 (군사용 한정) | 부분적 완화 가능 | 상황 인지(Context-aware) 동적 제어 |
| 은닉 채널 제어 | 이론적 통제 불가 | 대역폭 제한 기법 적용 | 하드웨어 TEE 기반 물리적 메모리 분리 |

벨-라파듈라 모델은 현대 강제적 접근통제(MAC)와 다중 등급 보안(MLS) 이론의 초석이며, 상용 및 클라우드 환경에서는 무결성 보장 모델(Biba)과 유연한 속성 기반 접근제어(ABAC)를 결합하여 입체적 보안 거버넌스 구축 필수.
