- **쇼어 알고리즘(Shor's Algorithm)**: 양자 중첩과 양자 푸리에 변환을 이용해 소인수분해와 이산대수 문제를 다항식 시간($O((\log N)^3)$) 안에 풀어내는 양자 알고리즘
- **SNDL(Store Now, Decrypt Later)**: 공격자가 현재 암호화된 기밀 통신 트래픽을 미리 대량 도청해 저장해 둔 뒤, 미래에 고성능 양자컴퓨터가 개발되면 일괄 해독하는 위협

</details>

## 1교시 10점 답안

### 1. 정의·목적

| 항목 | 답안 |
|---|---|
| 정의 | 양자내성암호(PQC)는 양자컴퓨터 공격을 고려해 설계된 암호 알고리즘이다. |
| 목적 | 양자 알고리즘이 위협하는 공개키 암호를 대체하거나 보완해 장기 기밀성을 지킨다. |

| FIPS 203 | 키 캡슐화 | ML-KEM |

| FIPS 205 | 전자서명 | SLH-DSA |

## 2~4교시 25점 답안


### Ⅰ. NIST 표준 알고리즘
| 표준 기능 | NIST 표준 | 기반 계열 |
|---|---|---|
| 키 캡슐화(KEM) | ML-KEM (FIPS 203) | 격자 기반 |
| 전자서명 | ML-DSA (FIPS 204) | 격자 기반 |
| 전자서명 | SLH-DSA (FIPS 205) | 해시 기반 |

이 밖의 후보 계열은 표준화·평가 상태를 확인해 별도로 다룬다.

### Ⅱ. 전환 시 고려할 점

| 고려 사항 | 적용 방법 |
|---|---|
| 나중에 해독하는 공격(SNDL) | 장기 기밀 데이터와 공개키 암호 사용처를 파악해 전환 우선순위를 정한다. |
| 메시지 크기·성능 | 실제 알고리즘·구현으로 프로토콜, MTU, 메모리, 지연 영향을 측정한다. |
| 하이브리드 전환 | 표준과 구현 지침에 따라 기존 암호와 병용할지 검증한다. |

### Ⅲ. PQC와 양자키분배 비교

| 구분 | PQC | QKD |
|---|---|---|
| 방식 | 양자컴퓨터를 고려해 설계한 암호 알고리즘 | 양자 상태를 이용해 키를 분배하는 기술 |
| 적용 | 기존 컴퓨터·통신망의 암호 전환 | 광통신 등 키 분배 인프라를 구축 |

### Ⅳ. 구현 검증

| 위험 | 원인 | 검증 항목 |
|---|---|---|
| 핸드셰이크 지연·패킷 분할 | 일부 PQC 메시지가 기존 메시지보다 클 수 있음 | 표준 알고리즘을 실제 TLS 구현·망 조건에서 시험 |
| 상호운용성 문제 | 라이브러리·프로토콜 지원이 다를 수 있음 | 장비·서비스 조합별 호환성을 검증 |
| 전환 과정에서 알고리즘·구현 위험 발생 | 제품별 지원과 배포 성숙도가 다름 | 표준 및 검증된 구현을 선택하고 필요 시 하이브리드 구성을 평가 |

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 알고리즘을 시스템에 고정하면 표준 변경과 취약점 대응이 어려워질 수 있다. | 알고리즘을 교체할 수 있는 구조를 설계하고 검증된 구현으로 단계별 전환을 시험한다. |
