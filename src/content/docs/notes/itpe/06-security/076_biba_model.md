## 30초 인출

- **본질:** Biba 모델은 무결성 등급으로 주체와 객체 사이의 읽기·쓰기·호출을 제한하는 접근통제 모델이다.
- **메커니즘:** 단순 무결성 규칙은 낮은 등급의 객체 읽기를 막고, 스타 무결성 규칙은 높은 등급 객체 쓰기를 막아 정보 오염의 흐름을 제한한다.

<details><summary>핵심 용어</summary>

- **무결성 등급**: 데이터나 주체의 신뢰 수준을 순서로 표현한 값이다.
- **단순 무결성 속성**: 주체가 자신보다 낮은 무결성 등급의 객체를 읽지 못하게 하는 규칙이다(No Read Down).
- **스타 무결성 속성**: 주체가 자신보다 높은 무결성 등급의 객체를 수정하지 못하게 하는 규칙이다(No Write Up).
- **호출 속성**: 낮은 무결성 주체가 더 높은 무결성 주체를 호출하지 못하도록 제한하는 규칙이다.
</details>

> Biba 무결성 모델의 개념과 주요 접근통제 규칙을 설명하시오. (예상)

---

## 1교시 10점 답안

### 1. 정의·목적

정의: **Biba 모델**은 **무결성 등급**에 따라 주체의 데이터 읽기·쓰기 접근을 통제하는 보안 모델이다.
목적: 낮은 신뢰의 정보가 높은 신뢰 데이터에 오염을 일으키거나 낮은 신뢰 주체가 높은 신뢰 객체를 변경하지 못하게 한다.

### 2. 핵심 규칙

| 규칙 | 접근 제한 | 목적 |
|---|---|---|
| 단순 무결성 | No Read Down | 낮은 등급 데이터에 의한 주체의 오염 제한 |
| 스타 무결성 | No Write Up | 낮은 등급 주체의 상위 객체 변조 제한 |
| 호출 속성 | 낮은 등급 주체의 높은 등급 주체 호출 제한 | 신뢰 수준을 거슬러 권한을 넘는 호출 억제 |

제안: 업무 데이터의 신뢰등급과 주체 권한을 정한 뒤 규칙이 업무를 막는 경로를 먼저 검증한다.

## 2~4교시 25점 답안

### Ⅰ. 개요

정의: **Biba 모델**은 무결성 수준을 기준으로 정보 흐름과 주체의 접근을 제한하는 형식적 보안 모델이다.
목적: 부정확하거나 낮은 신뢰의 정보가 고신뢰 데이터·프로세스를 오염시키는 것을 줄인다.

| 모델 | 우선 보호 목표 |
|---|---|
| Biba | 무결성: 부적절한 변경·오염 방지 |
| Bell-LaPadula | 기밀성: 비인가 정보 공개 방지 |

### Ⅱ. 등급과 흐름 규칙

```mermaid
flowchart LR
  L[낮은 무결성 객체] -->|읽기 허용| SL[낮은 무결성 주체]
  H[높은 무결성 객체] -->|읽기 허용| SH[높은 무결성 주체]
  SH -->|쓰기 허용: down| L
  L -. 읽기 금지: No Read Down .-> SH
  SL -. 쓰기 금지: No Write Up .-> H
```

모델은 무결성 등급을 순서로 두고 주체·객체 관계에서 허용되는 흐름을 제한한다. 도해의 실선은 허용 예, 점선은 Biba 규칙이 금지하는 흐름을 나타낸다.

### Ⅲ. 접근통제 속성

| 속성 | 규칙 | 차단하려는 흐름 |
|---|---|---|
| **단순 무결성** | 주체는 자신보다 낮은 무결성 등급을 읽지 않음 | 낮은 신뢰 데이터가 높은 신뢰 주체에 유입 |
| **스타 무결성** | 주체는 자신보다 높은 등급 객체에 쓰지 않음 | 낮은 신뢰 주체가 높은 신뢰 객체를 변경 |
| 호출 속성 | 주체는 자신보다 높은 무결성 주체를 호출하지 않음 | 낮은 신뢰 실행이 높은 신뢰 주체의 권한을 이용 |

### Ⅳ. BLP와 비교·적용 한계

| 비교 기준 | Biba | Bell-LaPadula |
|---|---|---|
| 보호 속성 | 무결성 | 기밀성 |
| 단순 규칙 | No Read Down | No Read Up |
| 스타 규칙 | No Write Up | No Write Down |
| 주된 위험 | 데이터 오염·비인가 변경 | 비인가 공개·유출 |

두 모델은 서로 다른 보안 목표를 다룬다. 엄격한 무결성 규칙은 낮은 등급 정보의 상위 처리 제한으로 업무 유연성을 낮출 수 있으므로, 등급 정의와 데이터 검증·승격 절차를 함께 설계한다. 상용 무결성 통제는 Biba의 순수 규칙과 같은 구현이라고 단정하지 않는다.

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 등급만 지정하고 저신뢰 입력을 업무상 승인된 결과로 바꾸는 절차가 없으면 Biba 규칙이 필요한 정보 흐름까지 막을 수 있다. | 상위 등급 데이터에 반영되는 외부 입력을 우선 식별하고, 검증 책임자·검사 항목·승인 기록이 있는 별도 검증 경로를 둔 뒤 그 경로를 통과한 데이터만 상위 업무에 반영한다. |
