- 필수 키워드: AI 제로트러스트 · 성숙도 모델(Maturity Model) · Never Trust, Always Verify · 5대 기둥 · 지속적 검증 · CISA ZTMM
- 출제 이력: 확인 가능한 공식 제132~140회 원문에서 이 표제어의 직접 문항 미확인. 아래 문항은 예상문제

## 한 줄 본질
- CISA의 범용 성숙도 단계를 조직의 AI 서비스에 적용할 수 있으나, 표의 AI별 통제 수준은 자체 설계 예시이며 CISA의 공식 AI 보안 등급으로 제시해서는 안 됨.

## 핵심 그림
```text
[CISA ZTMM 단계를 AI 서비스에 적용한 예시 — 공식 AI 표준 아님]

  ─────────────────────────────────────────────────────────────────────────────

  (Model)        │ (블랙박스 운영)     │ (SBOM 목록화)    │ (탈옥/인젝션 탐지)│ (자가 치유 및 모델 격리)
  ─────────────────────────────────────────────────────────────────────────────
  4. 인프라      │ 공유 관리계정       │ 환경·계정 분리   │ 워크로드별 권한·통신 │ 정책·기록 지속 검증
  (Infra)        │                    │                   │                      │
```

## 핵심 용어
- 지속적 검증(Continuous Verification): 한 번 인증을 통과했더라도 신뢰를 영구 부여하지 않고, 데이터 조회 및 모델 추론이 일어날 때마다 실시간으로 위험 점수를 재평가하는 제로트러스트 핵심 원칙
- 기밀 컴퓨팅(Confidential Computing): 하드웨어 기반 TEE 안의 사용 중 데이터를 보호하는 접근. GPU·vGPU까지 보호되는지는 구체 제품·구성과 증명 범위에 따라 달라짐

## 핵심 통찰
- CISA의 원 모델은 신원·기기·네트워크/환경·애플리케이션/워크로드·데이터를 함께 다룸. AI 데이터 출처·모델 무결성은 이 범용 통제에 추가로 연결할 검토 대상임.
- 초기 단계 기업이 처음부터 최적화(Optimal) 수준의 복잡한 기밀 컴퓨팅이나 동형암호를 도입하려 하면 개발이 중단됨 → "1단계: 데이터 암호화 및 API Key 제거"부터 시작하는 현실적 로드맵이 중요함
- 모델이 외부 웹을 검색하거나 플러그인을 호출하는 모든 아웃바운드 트래픽 역시 잠재적 공격 통로로 보고 검증해야 완결된 AI 제로트러스트가 됨

## 이웃 토픽과 구분
- AI 제로트러스트 vs 전통 제로트러스트: AI 제로트러스트 = 비결정론적 모델 추론 및 학습 데이터 변조 방어에 특화 / 전통 제로트러스트 = 사용자 단말, 네트워크 패킷, 정적 서버 인가에 집중

## 문제·원인·대책
- 가상 사례: 사내 AI 학습 데이터 경로에 검증되지 않은 자료가 유입된 상황
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미검증 학습 데이터 유입과 중독 가능성 | 데이터 출처·승인 절차 부재 | CISA 범용 데이터 기둥에 계보·서명·변경 승인 통제 연결 | 무인가 변경 추적과 평가 자료 확보 |
| 다중 테넌트 환경의 가중치·프롬프트 노출 우려 | 격리·접근 정책 미검증 | 기밀 컴퓨팅 지원 범위·증명과 메모리 격리 시험 | 제품·구성별 노출 위험 평가 |

## 1교시 예상문제 (10점)
- CISA 제로트러스트 성숙도 모델의 5대 기둥과 AI 서비스 적용 원칙을 설명하시오.

## 1교시 10점 답안
- **원 모델:** 신원·기기·네트워크/환경·애플리케이션/워크로드·데이터의 5대 기둥과 단계별 성숙도.
- **AI 적용:** 에이전트 신원, 학습·검색 데이터, 모델 배포·도구 호출을 관련 기둥의 통제에 연결.
- **경계:** 표의 AI별 등급은 조직의 응용안이며 CISA의 공식 AI 전용 성숙도 표준이 아님.

## 2~4교시 예상문제 (25점)
- 범용 제로트러스트 성숙도 모델을 AI 시스템에 적용하는 방법과 평가상 한계를 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 기준
- CISA 모델의 5대 기둥과 전통적·초기·고급·최적화 단계, 공통 기능을 원문 기준으로 파악.
### Ⅱ. AI 자산 매핑
- 사용자·에이전트 신원, 데이터 출처·접근, 모델·도구 워크로드, 네트워크 경계를 해당 기둥에 연결.
### Ⅲ. 단계적 통제
- 공유 키 제거와 접근 기록 → 세분화 인가·데이터 계보 → 지속적 신호 평가·배포 검증 등 업무 위험에 맞춘 로드맵.
### Ⅳ. 평가
- 정책 적용 범위·우회 가능성·업무 영향·감사 가능성을 시험. AI 전용 점수표는 자체 평가안으로 명시.
