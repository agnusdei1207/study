## 30초 인출

- **본질:** 익명처리는 다른 정보를 합쳐도 합리적으로 개인을 알아볼 수 없도록 데이터를 바꾸는 처리.
- **메커니즘:** 직접 식별자 제거와 속성 일반화·집계 → 다른 데이터와의 결합 위험 평가 → 잔여 위험 확인.
- **구분:** 가명처리한 정보는 추가 정보와 결합하면 다시 특정 개인을 알아볼 수 있으므로 익명정보와 같지 않음.

<details>
<summary>핵심 용어</summary>

- **익명처리**: 합리적으로 고려할 수 있는 시간·비용·기술과 다른 정보의 결합 가능성을 감안해 개인 식별이 어렵도록 처리하는 것.
- **가명처리**: 추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인정보의 일부를 삭제·대체하는 처리.
- **재식별 위험**: 처리된 자료를 다른 정보와 연결해 특정 개인을 다시 알아볼 가능성.
- **일반화**: 세부 값을 범주·구간처럼 덜 구체적인 값으로 바꾸는 기법.
- **집계**: 개별 레코드 대신 여러 대상의 통계 결과를 제공하는 기법.
</details>

## 1교시 10점 답안

### Ⅰ. 정의·목적

| 구분 | 내용 |
|---|---|
| 정의 | **익명처리**는 다른 정보와의 결합 가능성까지 고려해 특정 개인을 알아볼 수 없도록 하는 처리 |
| 목적 | 개인 식별 위험을 낮추면서 통계·분석에 필요한 데이터 활용 |

### Ⅱ. 처리와 판단

```text
원본 데이터
    ↓ 식별자 제거·속성 일반화·집계
처리 데이터
    ↓ 다른 데이터와의 결합 위험 검토
식별 불가능성·활용성 판단
```

| 구분 | 개인 식별 가능성 |
|---|---|
| 가명처리 | 추가 정보와 결합하면 식별 가능 |
| 익명처리 | 합리적으로 고려할 수 있는 방법으로 식별 불가 |

**제언:** 제공 범위와 결합 가능한 외부 데이터를 기준으로 재식별 위험을 재평가.

## 2~4교시 25점 답안

## Ⅰ. 익명처리의 정의와 목적

| 구분 | 내용 |
|---|---|
| 정의 | **익명처리**는 다른 정보와의 결합 가능성까지 고려해 특정 개인을 알아볼 수 없도록 하는 처리 |
| 목적 | 개인 식별 위험을 낮추면서 통계·분석에 필요한 데이터 활용 |

익명처리 여부는 이름·주민등록번호 제거만으로 판정하지 않음. 다른 정보를 사용한 식별 가능성까지 고려.

## Ⅱ. 처리 구조와 가명처리의 차이

```text
원본 데이터
    ↓ 식별자 제거·속성 일반화·집계
처리 데이터
    ↓ 다른 데이터와의 결합 위험 검토
식별 불가능성·활용성 판단
```

| 기준 | 가명처리 | 익명처리 |
|---|---|---|
| 추가 정보 | 결합하면 복원·식별 가능 | 합리적으로 가능한 결합에도 식별 불가 |
| 관리 초점 | 추가 정보 분리·접근 통제 | 잔여 재식별 위험 평가 |
| 법적 성격 | 개인정보 보호법의 가명정보 특례 대상 | 식별 가능성 평가 결과에 따라 판단 |

## Ⅲ. 주요 처리 기법

```text
속성별 선택
  ├─ 식별자 ─ 삭제·대체
  ├─ 준식별자 ─ 범주화·일반화
  └─ 상세 값 ─ 집계·노이즈 등
         ↓
분석 목적에 필요한 정보의 유지
```

| 기법 | 예 | 주의점 |
|---|---|---|
| 삭제·대체 | 이름·전화번호 제거 | 다른 속성의 조합으로 식별 가능 |
| 일반화 | 나이 → 연령대 | 정보 손실과 재식별 위험 균형 |
| 집계 | 개인별 값 → 구간별 통계 | 작은 집단의 노출 가능성 |
| 노이즈 | 통계값에 제한된 변동 부여 | 정확도와 보호 수준 설정 |

k-익명성 같은 수치는 보조 지표. 단일 임계값 달성만으로 재식별 불가능을 보장하지 않음.

## Ⅳ. 적정성 평가와 사후 관리

```text
데이터 이용 목적 확인
    ↓ 제공 대상·공개 범위 설정
처리 기법 적용
    ↓ 외부 데이터 결합 시험
잔여 위험 판단
    ↓ 환경 변화 시 재평가
```

| 평가 항목 | 질문 |
|---|---|
| 제공 환경 | 공개·제한 제공 중 무엇인가 |
| 결합 정보 | 수신자가 접근 가능한 다른 자료는 무엇인가 |
| 희소성 | 소수 집단·특이 값이 남는가 |
| 활용성 | 분석에 필요한 정확도는 유지되는가 |

## Ⅴ. 한계와 제언

| 한계 | 대응 |
|---|---|
| 한 번의 처리 결과를 모든 공개·활용 환경에 그대로 적용 | 제공 대상·목적·외부 데이터 변동에 따라 적정성 재판단 |
| 직접 식별자 제거만으로 익명성을 선언 | 속성 조합과 희소 집단을 이용한 재식별 시험을 판단 근거로 기록 |
