## 2~4교시 25점 답안

**공통 개요**

| 구분 | 핵심 |
|---|---|
| 정의 | CrowdStrike 장애는 2024년 보안 센서 콘텐츠 업데이트 결함으로 Windows 장치의 가용성이 대규모로 영향을 받은 사고 |
| 목적 | 업데이트 입력 검증·단계 배포·복구 설계를 통한 공통 장애 위험 감소 |

### Ⅰ. 사고 범위
- 2024년 7월 보안 센서 콘텐츠 업데이트 결함으로 Windows 장치가 충돌한 가용성 사고. 악성 침해로 단정하지 않음.
### Ⅱ. 원인 사슬
- 21개 입력 템플릿과 20개 전달값의 불일치 → 검증·시험 누락 → 채널 파일 291 배포 → 범위 밖 읽기·커널 충돌.
### Ⅲ. 예방
- 콘텐츠 스키마·입력 경계 검증, 실제 센서 조합 회귀시험, 제한된 링에서 상태 확인 후 확대.
### Ⅳ. 복구
- 영향 장치 목록·현장 복구 절차, 암호화 장치의 복구 키 접근성, 수동 복구 시간과 서비스 대체 경로 훈련.

## 기술사적 제언

콘텐츠 업데이트도 실행 입력으로 간주해 스키마 검사·제한 배포·현장 복구 시간을 함께 검증한다.
