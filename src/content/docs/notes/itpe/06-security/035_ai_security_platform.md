## 답안 골격
```text
[AI 보안 플랫폼] ◀━━ 머리: Ⅶ 내 의견 (파편화된 가드레일 탈피 → 엔드포인트-LLM-클라우드 전구간 통합 AI-SPM 구축)
 ┃
 ┣━ Ⅰ 개요 ───── 기업 내 다양한 AI/LLM 모델 및 에이전트 도입 확산 → 보안 가시성 부재 및 신종 AI 공격 방어를 위한 통합 관제 플랫폼
 ┣━ Ⅱ 특징 ───── 전사 AI 자산 자동 발견(섀도우 AI 탐지) · 실시간 입출력 가드레일 · AI 자세 관리(AI-SPM) · 규제 컴플라이언스 감사
 ┣━ Ⅲ 구조 ───── 탐지 레이어(섀도우 AI 발견) · 프록시/게이트웨이(입출력 검사/필터링) · 정책/거버넌스 엔진 · 위협 인텔리전스(AI-CTI)
 ┣━ Ⅳ 흐름 ───── ① 사용자 AI 요청 인터셉트 → ② 프롬프트 내 악성/기밀 검사(가드레일) → ③ LLM 전달 및 추론 → ④ 응답 유해성 검증 후 반환
 ┣━ Ⅴ 비교 ───── 전통 WAF/API 게이트웨이(정적 룰, 문법 검사) vs AI 보안 플랫폼(시맨틱 문맥 분석, 할루시네이션/탈옥/PII 탐지)
 ┗━ Ⅵ 실무 ───── API 응답 지연(Latency) 증가 / 비결정론적 판정에 따른 오탐(False Positive) / 다종 LLM 모델 연동 복잡성
```
- 필수 키워드: AI-SPM(AI Security Posture Management) · 섀도우 AI 탐지 · 입출력 가드레일 · 프롬프트 방화벽 · 시맨틱 검사 · PII 마스킹
- 기출: 미출제. 예상: "기업의 LLM 및 생성형 AI 도입에 따른 위협을 통제하기 위한 'AI 보안 플랫폼(AI Security Platform)'의 아키텍처와 핵심 기능, 도입 시 고려사항을 설명하시오."

## 한 줄 본질
- 사내에서 사용되는 모든 AI 모델, 프롬프트, API 트래픽을 단일 통제선에서 가시화하고 실시간 인젝션 공격 및 데이터 유출을 방어하는 종합 보안 게이트웨이 플랫폼 → 전사 AI 거버넌스 및 안전성 확보 / 트랜잭션 지연 및 플랫폼 구축 비용 수반

## 핵심 용어
- AI-SPM(AI Security Posture Management): 클라우드 및 온프레미스에 배포된 AI 모델, 학습 파이프라인, 벡터 DB의 설정 오류와 취약점을 지속 점검하고 거버넌스를 관리하는 체계
- 시맨틱 검사(Semantic Inspection): 단순 문자열 매칭이 아니라 텍스트 임베딩과 분류기 모델을 통해 문맥상 악의적 의도(탈옥, 악성코드 생성 요청 등)를 식별하는 검사 기법

## 핵심 통찰
- 전통적인 웹 방화벽(WAF)은 정규식 기반으로 SQL 인젝션을 막지만, 자연어로 우회하는 "프롬프트 인젝션"이나 "시스템 기밀 누설"은 전혀 판별할 수 없음
- 기업 내 임직원들이 회사 승인 없이 개인 계정으로 수십 종의 AI 도구를 사용하는 '섀도우 AI(Shadow AI)' 현상이 데이터 유출의 최대 취약점으로 대두됨
- AI 보안 플랫폼은 LLM 앞단에서 개인정보(주민번호, 카드번호, API키)를 실시간 감지해 가명화/마스킹한 후 외부 LLM에 전달하는 데이터 프라이버시 필터 역할을 수행함

## 이웃 토픽과 구분
- AI 보안 플랫폼 vs CASB(Cloud Access Security Broker): CASB = 클라우드 SaaS 접속 통제 및 파일 업로드 차단 / AI 보안 플랫폼 = 생성형 AI 특화 프롬프트 문맥 분석, 탈옥 탐지, 모델 취약점 관리

## 문제·원인·대책
- 사례: 사내 직원이 외부 번역 AI 사이트에 고객 개인정보가 포함된 계약서 전문을 붙여넣어 유출된 섀도우 AI 사고
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 승인되지 않은 외부 AI 도구 사용으로 데이터 유출 | 사내 네트워크 및 엔드포인트의 AI 접속 가시성 부재 | AI 보안 플랫폼의 섀도우 AI 자동 탐지 및 비인가 AI URL 차단 | 비인가 생성형 AI 접근 100% 통제 |
| LLM 응답에 개인정보나 유해 콘텐츠가 포함되어 고객 노출 | 모델의 할루시네이션 및 가드레일 없는 직접 출력 | 응답단 아웃바운드 시맨틱 필터링 및 PII 역마스킹 검증 | 안전하지 않은 응답의 사용자 노출 차단 |

## 이렇게 출제된다
- 미출제. 예상: "기업의 LLM 및 생성형 AI 도입에 따른 위협을 통제하기 위한 'AI 보안 플랫폼(AI Security Platform)'의 아키텍처와 핵심 기능, 도입 시 고려사항을 설명하시오." → 요구 포인트: Ⅰ 부상 배경 + Ⅲ 참조 아키텍처 + Ⅳ 인바운드/아웃바운드 검증 절차

## 내 의견
- [단순 프록시 게이트웨이 도입 시의 성능 병목 현상] 모든 AI 호출마다 고비용의 LLM 기반 가드레일을 직렬로 통과시켜 실시간 챗봇 응답 지연이 2~3초 이상 증가하는 사용성 저하 발생 → 나라면: 정규식 및 경량 분류기(BERT 기반)로 1차 초고속 필터링을 수행하고, 의심스러운 트랜잭션만 비동기 정밀 검증 모델로 우회시키는 '2계층 적응형 인라인 파이프라인'을 설계
