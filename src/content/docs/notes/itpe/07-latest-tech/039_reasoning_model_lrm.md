## 지식 로드맵 내 현재 위치

지식 위치: 대규모 언어 모델 → 추론 시 계산 배분 → **추론 모델(LRM)**

## 30초 인출

- 본질: **대규모 추론 모델(Large Reasoning Model, LRM)** 은 복합 과업에 추가 추론 계산을 사용할 수 있도록 학습·구성한 언어 모델
- 메커니즘: 입력·추론 예산 설정 → 후보 풀이 탐색·검토 → 응답 생성 → 품질·비용 측정

<details>
<summary>핵심 용어</summary>

- **대규모 추론 모델(Large Reasoning Model, LRM)** : 복합 추론 과업에 추가 계산을 활용할 수 있도록 학습·구성된 언어 모델
- **추론 시 계산(Test-Time Compute)** : 모델 학습이 끝난 뒤 응답을 생성할 때 사용하는 계산 자원
- **추론 노력(Reasoning Effort)** : 과업 수행에 투입하도록 설정한 추론 계산 수준
- **테스트 시 탐색(Test-Time Search)** : 추론 시점에 여러 후보 경로나 풀이를 탐색·평가하는 기법
- **검증기(Verifier)** : 결과가 정답·형식·실행 조건을 충족하는지 평가하는 구성요소
</details>

| 한계 | 추가 계산만으로 잘못된 전제·지식 부족 해결 불가 |

제언: 과업별 품질·비용 평가로 추론 예산을 정하고 결과를 별도로 검증.

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **대규모 추론 모델(Large Reasoning Model, LRM)** 은 복합 과업에 추가 추론 계산을 사용할 수 있도록 학습·구성한 언어 모델 |
| 목적 | 다단계 문제의 탐색·검토를 지원하고 답변 품질 개선 여부를 평가 |

### Ⅱ. 추론 시 계산 흐름

```text
문제·추론 예산
      ↓
후보 풀이 탐색·검토
      ↓
응답 생성·검증
      ↓
품질·지연·계산량 측정
```

### Ⅲ. 계산 배분의 차이

| 관점 | 일반 생성 설정 | 추론 중심 설정 |
|---|---|---|
| 계산 | 정해진 생성 방식으로 응답 산출 | 과업·설정에 따라 더 많은 추론 계산 활용 가능 |
| 기대 | 낮은 지연의 응답 | 일부 복합 문제에서 성능 개선 가능 |
| 비용 | 상대적으로 적은 계산일 수 있음 | 응답 지연·연산 비용 증가 가능 |

### Ⅳ. 적용 평가

| 평가 축 | 확인 방법 |
|---|---|
| 정확성 | 실제 과업·분리 평가 자료에서 정답률·실패 유형 |
| 지연·비용 | 응답시간·토큰·가속기 사용량 |
| 과업 적합성 | 일반 모델과 난도별 비교 |
| 결과 신뢰성 | 근거·출력 검증과 고영향 작업의 사람 검토 |

모델 내부의 구체적 추론 절차는 구현별로 다를 수 있음. 외부 응답 시간이나 설정만으로 내부 동작을 단정하지 않음.

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모든 요청에 추론 중심 처리를 적용하면 간단한 요청까지 지연·비용이 늘 수 있음 | 저비용 기준 경로를 두고 품질 기준에 미달하는 과업에만 추론 예산을 늘리는 라우팅을 실제 요청군에서 평가 |
