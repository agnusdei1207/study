## 연관 키워드

- 2차원 바코드(2D Barcode), QR 코드(Quick Response Code), 데이터 매트릭스(Data Matrix), PDF417
- 큐싱(Qshing), 동적 QR(Dynamic QR), TOTP(Time-based One-Time Password), 오류 정정(Error Correction)
- 직접 부품 마킹(DPM), 위치 검출 패턴(Finder Pattern), 여백 영역(Quiet Zone)

## Ⅰ. 2차원 바코드의 개요

- 핵심 요약 : 가로와 세로 두 방향으로 명암 모듈을 배열해 많은 데이터를 담는 광학 심볼이며, 손상 복원과 복호 후 검증을 함께 설계해야 하는 기술.
- 개념 : 수평과 수직 두 방향으로 흑백 명암 모듈을 배열해 문자, 숫자, 바이너리 데이터를 고밀도로 저장하는 2차원 광학 데이터 심볼 (**2차원 바코드**, 2D Barcode).
- 배경 및 필요성 : 사람이 육안으로 내용을 확인하기 어려운 점을 노린 **큐싱** (Qshing, QR 코드와 피싱의 결합) 공격이 나타나, 복호 뒤 악성 주소를 평판으로 검증하고 **동적 QR** (Dynamic QR, 주기적으로 내용이 바뀌는 QR 코드) 발급 체계가 필요해짐.
- 주요 목적 : 1차원 바코드의 식별자 역할을 넘어 독립된 데이터 저장 매체로 쓰고, 손상된 심볼을 스스로 복구하며, 모바일 결제와 물류 추적을 지원.

## Ⅱ. 2차원 바코드의 특징 및 장점

- 핵심 요약 : 대용량 수용, 오류 정정, 전방향 인식, 소형 각인이 결합되어 물리 매체를 독립된 데이터 저장소로 바꾸는 구조.

1. 대용량 수용 : 1차원 바코드와 달리 QR 코드 최대 버전(40-L) 기준 숫자 7,089자, 한자 1,817자를 수록 → 긴 정보를 심볼 하나에 담음.
2. 강인한 오류 정정 : **리드-솔로몬 부호** (Reed-Solomon code)로 심볼 일부가 훼손되어도 원본을 복구 → 마모와 오염이 있는 환경에서도 판독 유지.
3. 전방향 고속 인식 : 위치 검출 패턴 (Finder Pattern)으로 기울기와 방향을 파악 → 스캐너 진입 각도에 관계없이 판독.
4. 극소형 각인 : **직접 부품 마킹** (DPM, Direct Part Marking)으로 부품 표면에 직접 새김 → 반도체 부품이나 의료 기구처럼 작은 면에도 이력 추적 가능.

```text
[ QR 코드 기본 구조 ]

여백 영역 (Quiet Zone, 사방 4모듈 이상)
        ↓
위치 검출 패턴 (3개 귀퉁이)
        ↓
타이밍 패턴 (흑백 교차 기준선)
        ↓
형식 정보 (오류 정정 레벨 표시)
        ↓
데이터와 오류 정정 코드워드
        ↓
정렬 패턴 (기울기와 왜곡 보정)
```

```text
[ 스캔과 복호 흐름 ]

카메라로 심볼 촬영
        ↓
위치 검출 패턴으로 방향 파악
        ↓
오류 정정 코드워드로 훼손 복구
        ↓
데이터 복호 (단축 URL 등)
        ↓
평판 검증 후 목적지 열람
```

## Ⅲ. 2차원 바코드의 구조 및 구성 요소

- 핵심 요약 : 여백 영역과 위치 검출 패턴이 판독 기준을 잡고, 오류 정정 레벨이 데이터 복구 능력을 정하는 구조.

- **여백 영역** (Quiet Zone) : 심볼 주변에 두는 흰색 여백으로, 사방 4모듈 이상을 두어 스캐너가 심볼 경계를 구분하게 함.
- **위치 검출 패턴** (Finder Pattern) : 세 귀퉁이에 배치되는 1:1:3:1:1 명암 비율의 기호로, 판독 기준 위치와 회전 방향을 알려 줌.
- **오류 정정 레벨** (Error Correction Level) : L, M, Q, H 네 단계로 나뉘며, 각각 약 7%, 15%, 25%, 30%의 훼손을 복구함. 레벨이 높을수록 데이터 용량이 줄고 심볼이 커짐.
- **정렬 패턴** (Alignment Pattern) : 곡면이나 기울어진 면에서 격자 왜곡을 보정하는 기호.

## Ⅳ. 매트릭스형과 적층형의 비교

- 핵심 요약 : 매트릭스형은 정방형 격자로 전방향 고속 판독에 강하고, 적층형은 가로로 긴 형태로 레이저 판독 환경과 인쇄 면적 여유에 맞는 방식.
- 비교 대상은 **매트릭스형** (Matrix, QR 코드와 데이터 매트릭스)과 **적층형** (Stacked, PDF417 등).

| 비교 축 | 매트릭스형 | 적층형 |
| --- | --- | --- |
| 배열 구조 | 바둑판 모양의 2차원 정방형 격자 | 1차원 코드를 세로로 여러 단 쌓은 구조 |
| 심볼 형태 | 정방형 (초소형 구현에 유리) | 가로로 긴 직사각형 (인쇄 면적 필요) |
| 스캔 방식 | 2차원 이미지 센서(카메라) 필요 | 레이저 스캐너와 이미지 센서 모두 판독 가능 |
| 판독 방향 | 전방향 즉시 인식 | 레이저 라인이 지나가는 방향에 제약 |
| 오류 정정 | 리드-솔로몬 부호로 심볼 면 전체 복구 | 리드-솔로몬 코드워드 기반 복구 |
| 대표 활용 | QR 코드(결제, 정보 전달), 데이터 매트릭스(전자부품 마킹) | PDF417(해외 운전면허증, 항공권 탑승권 등) |

- 선택 기준 : 소형 부착과 전방향 촬영이 중요하면 매트릭스형을, 레이저 판독 설비와 인쇄 면적 여유가 있으면 적층형을 택함.

## Ⅴ. 2차원 바코드의 한계와 방안

- 핵심 요약 : 악성 스티커, 표면 훼손, 데이터 밀도에 따른 판독 거리 문제를 동적 코드와 복호 후 검증, 고복구 레벨과 직접 마킹, 단축 토큰과 저버전 설계로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 큐싱 (Qshing) 보안 공격 | 정상 스티커 위에 악성 스티커를 덧씌워 피싱 사이트로 유도, 금융 정보와 인증 정보 탈취 | 정적 URL 인쇄를 금지하고 짧은 유효 시간의 **TOTP** (Time-based One-Time Password) 기반 동적 QR 채택, 스캐너가 최종 도메인의 보안 연결 인증서(SSL, Secure Sockets Layer)와 악성 도메인 평판을 검증 | 악성 스티커 신고 건수, 평판 차단 건수 |
| 산업 현장의 표면 오염과 마모 | 절삭유, 자외선에 의한 퇴색, 긁힘으로 명암 대비가 떨어져 판독 실패 | 오류 정정 레벨을 H로 설계하고, 종이 라벨 대신 부품 표면에 직접 마킹하며 2차원 광학 링 조명 적용 | 판독 성공률, 재인쇄 건수 |
| 데이터 밀도 증가에 따른 판독 거리 한계 | 버전이 높아질수록 모듈이 작아져 스마트폰 카메라의 초점 범위를 벗어남 | 긴 원본 데이터 대신 서버에 매핑된 고유 식별자(UUID, Universally Unique Identifier) 토큰만 부호화하고, 모듈이 큰 저버전 심볼 우선 사용 | 평균 스캔 거리, 스캔 실패율 |

## Ⅵ. 2차원 바코드에 대한 기술사적 제언

- 핵심 요약 : 정적 주소의 관행을 줄이고, 판독 기준을 용도별로 정하며, 복호 후 검증을 사용자 교육과 함께 운영 기준으로 삼는 것이 핵심.

1. 발급 기관은 QR 코드에 정적 주소를 담는 관행을 줄이고, 동적 코드 발급과 검증 체계를 결제와 인증 서비스의 기본 설계로 채택할 필요가 있다.
2. 스캐너 앱 개발 조직은 복호 직후 목적지 도메인을 사용자에게 보여 주고 평판 검증을 거치도록 설계하는 것이 바람직하다.
3. 물류와 제조 부서는 용도에 따라 오류 정정 레벨과 인쇄 방식을 표준으로 정하고, 현장 판독률을 정기적으로 점검하는 체계를 두는 것이 필요하다.
4. 보안 조직은 큐싱을 사용자 교육 항목에 포함해, 공공장소의 스티커를 무조건 신뢰하지 않도록 안내할 필요가 있다.

## Ⅶ. 결론

- 핵심 요약 : 2차원 바코드는 고밀도 데이터 심볼이자 물리 매체의 오류 정정을 갖춘 광학 데이터 저장 체계.
- 편의성만큼 물리 매체의 위변조 위험이 따르므로, 심볼 자체보다 복호 후 검증 절차를 함께 설계하는 것이 실질적 안전장치임.
