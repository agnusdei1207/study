## 답안 골격
### 1교시 예상문제 (10점)
2D 바코드의 유형과 QR 코드의 위치 검출·오류 정정 요소를 설명하시오.

### 1교시 10점 답안
- **정의:** 가로·세로의 광학 패턴에 정보를 부호화하는 기계 판독 심볼.
- **유형:** QR·Data Matrix 같은 매트릭스형과 PDF417 같은 적층형.
- **QR 구조:** 위치 검출·타이밍·정렬 패턴과 데이터·정정 코드워드, 정숙 영역. 리드-솔로몬 정정 수준은 설정과 손상 양상에 종속.

### 2~4교시 예상문제 (25점)
공유 모빌리티의 2D 바코드 활용 구조와 판독·큐싱 위험 대책을 설명하시오.

### 2~4교시 25점 답안
1. **규격 선택:** 저장할 내용·인쇄 면적·기기 카메라·현장 조도를 고려해 심볼과 크기·정정 등급 결정.
2. **처리:** 서비스 ID 또는 짧은 토큰 부호화 → 앱 스캔 → 도메인·서명·만료 검증 → 서버의 권한 확인 후 잠금 해제.
3. **위험:** 악성 스티커 덧씌우기, 마모·저조도 판독 실패, 오래된 토큰 재사용.
4. **통제:** 목적지 표시와 앱 내 검증, 현장 스티커 점검, 일회용 토큰·재사용 차단, 조명·훼손 조건별 판독 시험.

```text
[2D 바코드] ◀━━ 머리: Ⅶ 내 의견 (리드-솔로몬 오류 정정 부호와 2차원 매트릭스 인코딩을 통한 고밀도 데이터 저장 및 모바일 결제·물류 트래킹 혁신)
 ┃
 ┣━ Ⅰ 개요 ───── 정보를 두 차원 패턴에 부호화하는 광학 심볼. 용량·오류 정정·스캔 방식은 심볼 종류·크기·설정에 따라 차이
 ┣━ Ⅱ 특징 ───── 1차원 대비 높은 정보 밀도 · 다양한 데이터 모드 · 위치 검출 패턴 · 심볼별 오류 정정. QR 코드 H 등급의 약 30% 복원은 조건부 기준
 ┣━ Ⅲ 분류 ───── 매트릭스형(Matrix: QR Code, Data Matrix, MaxiCode) vs 적층형(Stacked: PDF417, Code 49)
 ┣━ Ⅳ 핵심기술 ─ 리드-솔로몬(Reed-Solomon) 에러 정정 부호 · 위치 검출 패턴(Finder Pattern) · 타이밍 패턴 · 정숙 영역(Quiet Zone)
 ┣━ Ⅴ 비교 ───── 1차원 바코드(선형 패턴·리더기별 카메라/레이저 지원) vs 2차원 바코드(면 패턴·이미지 기반 판독). 데이터 용량과 정정 수준은 규격별 상이
 ┗━ Ⅵ 실무 ───── 큐싱(Qshing) 등 악성 URL 유포 보안 위협 / 표면 훼손·오염에 따른 인식 실패 / 저해상도 카메라 초점 지연
```
- 필수 키워드: 2D 바코드 · QR 코드(QR Code) · 데이터 매트릭스(Data Matrix) · PDF417 · 리드-솔로몬(Reed-Solomon) · 위치 검출 심볼 · 오류 정정(Error Correction) · 큐싱(Qshing)
- 출제 이력: 92회·96회 공식 문제지 원문 미대조. 해당 회차의 실제 문항·표현 미확인

## 한 줄 본질
- QR·Data Matrix·PDF417처럼 두 차원 배열에 정보를 담는 광학 코드. 용량과 손상 복구 성능은 심볼 규격·크기·오류 정정 등급에 종속

## 핵심 그림
```text
[대표적 2D 바코드 QR 코드의 내부 구조 및 리드-솔로몬 복원]

   ┌─────────────────────────────────────────────────────────────┐
   │ [위치 검출 패턴]                               [위치 검출]   │
   │ ┌───┐ 1:1:3:1:1 비율                           ┌───┐         │
   │ │█ █│                                          │█ █│         │
   │ └───┘ ─── 타이밍 패턴 (검은색/흰색 교대 모듈) ─── └───┘         │
   │                                                             │
   │   [데이터 인코딩 및 리드-솔로몬(Reed-Solomon) 오류 정정 영역]│
   │   - L 레벨: 7% 복원    / M 레벨: 15% 복원                  │
   │   - Q 레벨: 25% 복원   / H 레벨: 30% 복원                  │
   │                                                             │
   │ ┌───┐                     ┌───┐                             │
   │ │█ █│                     │ █ │ [정렬 패턴 Alignment]       │
   │ └───┘                     └───┘ (곡면 왜곡 보정)            │
   │ [위치 검출]                                                 │
   └─────────────────────────────────────────────────────────────┘
   * 외곽 4개 모듈 너비의 정숙 영역(Quiet Zone: 여백) 필수 유지
```

## 핵심 용어
- 리드-솔로몬 부호(Reed-Solomon Code): 손상된 코드워드를 정정하는 대수적 오류 정정 기법. 허용 범위를 넘는 훼손·촬영 오류는 복원 불가
- 위치 검출 패턴(Finder Pattern): QR 코드의 세 모서리에 배치된 1:1:3:1:1 비율의 이중 사각형 심볼로, 카메라가 어느 각도(360도)에서 스캔하더라도 바코드의 방향과 크기를 즉시 계산하게 해주는 기준점
- 큐싱(Qshing): QR 코드와 피싱(Phishing)의 합성어로, 공공장소의 정상적인 QR 코드 위에 가짜 악성 URL이 담긴 스티커를 덧붙여 사용자의 개인정보나 금융 정보를 탈취하는 사이버 공격

## 핵심 통찰
- 1D와 2D의 활용: 두 방식 모두 식별자 또는 제한된 데이터를 저장할 수 있으며, 2D는 상대적으로 큰 페이로드와 다양한 데이터 모드를 지원. 의료·결제 정보의 실제 저장 범위는 보안·용량 정책에 따라 결정
- 로고 삽입과 정정 여유: QR 코드 H 등급은 약 30% 코드워드 복원 기준이지만, 로고 크기·위치·인쇄 상태에 따라 판독 실패 가능. 실제 기기·조건별 시험 필요
- 카메라 기반 판독: 스마트폰 등 범용 이미지 센서 활용 가능. 인식 시간과 결제 완료 여부는 화질·조도·연결 상태·서비스 절차에 좌우

## 이웃 토픽과 구분
- 매트릭스형(QR/Data Matrix) vs 적층형(PDF417): 매트릭스형은 흑백 정사각형 격자 배열로 전방향 고속 인식과 모바일 결제 최적 / 적층형은 1D 바코드를 위로 얇게 여러 층 쌓은 형태로 주민등록증, 항공권 등 긴 텍스트 문서 보관에 최적

## 문제·원인·대책
- 적용 상황: 전국 단위 공유 킥보드 대여 및 모바일 결제 QR 코드 인프라 운용
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 악성 URL 스티커로 큐싱 발생 | 인쇄 코드의 목적지를 육안 확인하기 어려움 | 앱에서 도메인·서명·서비스 ID 확인과 사용자 경고 | 잘못된 목적지 탐지율 평가 |
| 야외 코드 훼손으로 판독 실패 | 마모·인쇄 대비 저하 | 규격에 맞는 정숙 영역, 오류 정정 등급 선택, 재인쇄 주기 | 조건별 판독 성공률 측정 |
| 저조도에서 판독 지연 | 명암비·초점 부족 | 조명·인쇄 재질·카메라 초점 개선 | 주야간 판독 시간 비교 |
