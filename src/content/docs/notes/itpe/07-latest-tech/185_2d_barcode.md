## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 2D 바코드(2D Barcode)

## 30초 인출

- **본질:** 가로·세로의 광학 패턴에 정보를 부호화하는 기계 판독 심볼. 기계 판독 심볼에 식별자와 데이터를 부호화.
- **메커니즘:** 데이터 부호화·정정 → 심볼 인쇄·표시 → 카메라 판독·검증.

<details><summary>핵심 용어</summary>

- **매트릭스형 심볼:** QR·Data Matrix처럼 2차원 격자에 정보를 배치한 코드
- **정숙 영역:** 판독을 위해 심볼 둘레에 확보하는 빈 여백

</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 가로·세로의 광학 패턴에 정보를 부호화하는 기계 판독 심볼. |
| 목적 | 기계 판독 심볼에 식별자와 데이터를 부호화 |

### Ⅱ. 핵심 구조와 적용

```text
데이터 부호화·정정 → 심볼 인쇄·표시 → 카메라 판독·검증
```

1. **규격 선택:** 저장할 내용·인쇄 면적·기기 카메라·현장 조도를 고려해 심볼과 크기·정정 등급 결정.
2. **처리:** 서비스 ID 또는 짧은 토큰 부호화 → 앱 스캔 → 도메인·서명·만료 검증 → 서버의 권한 확인 후 잠금 해제.
3. **위험:** 악성 스티커 덧씌우기, 마모·저조도 판독 실패, 오래된 토큰 재사용.
4. **통제:** 목적지 표시와 앱 내 검증, 현장 스티커 점검, 일회용 토큰·재사용 차단, 조명·훼손 조건별 판독 시험.

### Ⅲ. 유사 개념과 구분

- 매트릭스형(QR·Data Matrix)은 격자에 정보를 배치하고, 적층형(PDF417)은 선형 바코드의 행을 쌓는다. 판독 방향·용량·인쇄 공간·오류 정정은 심볼 규격과 설정에 따라 비교한다.

### Ⅳ. 문제·원인·대책

- 적용 상황: 전국 단위 공유 킥보드 대여 및 모바일 결제 QR 코드 인프라 운용
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 악성 URL 스티커로 큐싱 발생 | 인쇄 코드의 목적지를 육안 확인하기 어려움 | 앱에서 도메인·서명·서비스 ID 확인과 사용자 경고 | 잘못된 목적지 탐지율 평가 |
| 야외 코드 훼손으로 판독 실패 | 마모·인쇄 대비 저하 | 규격에 맞는 정숙 영역, 오류 정정 등급 선택, 재인쇄 주기 | 조건별 판독 성공률 측정 |
| 저조도에서 판독 지연 | 명암비·초점 부족 | 조명·인쇄 재질·카메라 초점 개선 | 주야간 판독 시간 비교 |

### Ⅴ. 제언

- [용도별 보안 통제] 결제·출입처럼 권한이 필요한 용도는 만료 시간·일회용 토큰·서버 검증·사용자 인증을 결합하고, 인쇄된 안내용 QR은 목적지 확인과 위변조 점검 강화

## 출제 이력과 검증 출처
