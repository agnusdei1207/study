## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 2D 바코드(2D Barcode)

## 30초 인출

- 본질: 가로·세로의 광학 패턴에 정보를 부호화하는 기계 판독 심볼. 기계 판독 심볼에 식별자와 데이터를 부호화.
- 메커니즘: 데이터 부호화·정정 → 심볼 인쇄·표시 → 카메라 판독·검증.
- 통찰: 한계: 오류 정정이 있어도 악성 스티커의 목적지 치환은 막지 못한다 → 방안: 판독 뒤 도메인·서명·만료를 검증하고 현장 코드 훼손을 점검한다.

<details><summary>핵심 용어</summary>

- **매트릭스형 심볼:** QR·Data Matrix처럼 2차원 격자에 정보를 배치한 코드
- **정숙 영역:** 판독을 위해 심볼 둘레에 확보하는 빈 여백

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 가로·세로의 광학 패턴에 정보를 부호화하는 기계 판독 심볼. |
| 목적 | 기계 판독 심볼에 식별자와 데이터를 부호화 |

## Ⅱ. 심볼 판독과 서비스 검증

```text
식별자·토큰 → 부호화·정정 코드 → 인쇄 심볼
                                     ↓ 카메라 판독
                                데이터 복원
                                     ↓ 도메인·서명·만료 검증
                                서비스 요청
```

1. **규격 선택:** 저장할 내용·인쇄 면적·기기 카메라·현장 조도를 고려해 심볼과 크기·정정 등급 결정.
2. **처리:** 서비스 ID 또는 짧은 토큰 부호화 → 앱 스캔 → 도메인·서명·만료 검증 → 서버의 권한 확인 후 잠금 해제.
3. **위험:** 악성 스티커 덧씌우기, 마모·저조도 판독 실패, 오래된 토큰 재사용.
4. **통제:** 목적지 표시와 앱 내 검증, 현장 스티커 점검, 일회용 토큰·재사용 차단, 조명·훼손 조건별 판독 시험.

## Ⅲ. 매트릭스형과 적층형 심볼

| 구분 | 매트릭스형 | 적층형 |
|---|---|---|
| 배치 | 2차원 격자 | 선형 코드의 여러 행 |
| 선택 | 인쇄 공간·카메라 판독 | 기존 선형 판독 환경과 용량 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 악성 URL 스티커로 큐싱 발생 — 인쇄 코드의 목적지를 육안 확인하기 어려움 | 앱에서 도메인·서명·서비스 ID 확인과 사용자 경고 |
| 야외 코드 훼손으로 판독 실패 — 마모·인쇄 대비 저하 | 규격에 맞는 정숙 영역, 오류 정정 등급 선택, 재인쇄 주기 |
| 저조도에서 판독 지연 — 명암비·초점 부족 | 조명·인쇄 재질·카메라 초점 개선 |

## Ⅴ. 제언

- [용도별 보안 통제] 결제·출입처럼 권한이 필요한 용도는 만료 시간·일회용 토큰·서버 검증·사용자 인증을 결합하고, 인쇄된 안내용 QR은 목적지 확인과 위변조 점검 강화

## 출제 이력과 검증 출처

- **출제 상태:** 위 문항은 학습용 예상문제이며, 공식 기출 원문과 동일하다고 단정하지 않는다.
- [DENSO WAVE QR Code 특징](https://www.qrcode.com/en/about/): QR 코드 용량·오류 정정의 원 개발사 설명
- [GS1 2D Barcodes](https://www.gs1.org/standards/barcodes/2d): 2차원 바코드의 표준 적용 안내
