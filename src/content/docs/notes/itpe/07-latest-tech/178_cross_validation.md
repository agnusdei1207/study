## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 교차검증(Cross Validation)

## 30초 인출

- **본질:** 데이터의 검증 구간을 바꾸어 여러 차례 학습·평가함으로써 성능 추정의 분할 의존성을 살피는 방법. 분할에 따른 성능 추정의 변동을 확인해 모델 선택 지원.
- **메커니즘:** 데이터 분할 → 폴드별 학습·평가 → 점수 분포 확인 → 독립 시험.

<details><summary>핵심 용어</summary>

- **폴드:** 교차검증에서 학습·평가 순환에 사용하는 데이터 분할
- **데이터 누수:** 평가 대상의 정보가 학습 과정에 섞이는 오류

</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 데이터의 검증 구간을 바꾸어 여러 차례 학습·평가함으로써 성능 추정의 분할 의존성을 살피는 방법. |
| 목적 | 분할에 따른 성능 추정의 변동을 확인해 모델 선택 지원 |

- **절차:** K개 폴드 구성 → K-1개로 학습·나머지 1개로 평가를 K회 반복 → 점수의 평균·분산 확인.
- **분할:** 분류의 클래스 비율 유지에는 층화, 시간 순서와 미래 정보 차단에는 시계열 분할, 동일 개체의 누수 차단에는 그룹 분할.

```text
데이터 분할 → 폴드별 학습·평가 → 점수 분포 확인 → 독립 시험
```

---

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 데이터의 검증 구간을 바꾸어 여러 차례 학습·평가함으로써 성능 추정의 분할 의존성을 살피는 방법. |
| 목적 | 분할에 따른 성능 추정의 변동을 확인해 모델 선택 지원 |

### Ⅱ. 핵심 구조와 적용

```text
데이터 분할 → 폴드별 학습·평가 → 점수 분포 확인 → 독립 시험
```

1. **목적:** 모델·하이퍼파라미터 선택을 위한 검증 점수의 안정성 확인. 최종 일반화 평가는 별도 시험 집합 사용.
2. **설계:** 독립 표본이면 KFold, 불균형 분류면 StratifiedKFold, 환자·사용자 반복 자료면 GroupKFold, 시간 의존 자료면 미래 구간을 뒤에 둔 순차 분할.
3. **누수 차단:** 정규화·결측 대체·특징 선택은 각 훈련 폴드 안에서만 학습하고 검증 폴드에 적용. 튜닝 후 평가에는 중첩 검증 또는 홀드아웃 시험 사용.
4. **보고:** 평균뿐 아니라 폴드별 편차, 집단별 오류와 데이터 분포, 학습 계산 비용·무작위 시드 명시.

### Ⅲ. 유사 개념과 구분

- 홀드아웃(Hold-out) vs 교차검증(Cross Validation): 홀드아웃은 데이터를 단순히 Train/Test 1회 분할하여 연산이 빠르지만 평가 편향 큼 / 교차검증은 모든 데이터가 적어도 한 번씩 검증셋으로 사용되어 평가 신뢰도 극대화

### Ⅳ. 문제·원인·대책

- 적용 상황: 희귀 질환 진단 AI 모델 개발 및 주가 예측 알고리즘 백테스팅
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 소수 클래스가 일부 검증 폴드에 없음 | 양성 표본 수와 분할 수의 불일치 | 양성 수를 확인하고 가능한 경우 층화 분할 적용 | 폴드별 클래스 수와 재현율의 변동 기록 |
| 시계열 평가에서 미래 정보 유입 | 임의 셔플과 시간 순서 무시 | 학습 시점보다 뒤 자료만 검증에 사용하고 전처리도 폴드 안에서 수행 | 예측 시점별 이용 가능한 정보만 사용했는지 확인 |
| K회 학습 비용이 과도 | 모델 훈련 비용과 분할 수 증가 | 자원 예산에 맞춰 K와 별도 테스트 집합을 설계 | 연산 시간과 추정 불확실성 함께 보고 |

### Ⅴ. 제언

- 전처리·특성 선택·하이퍼파라미터 탐색은 훈련 폴드 안에서만 학습. 최종 성능 보고에는 모델 선택에 쓰지 않은 별도 테스트 집합과 데이터 의존성 검토를 포함

## 출제 이력과 검증 출처
