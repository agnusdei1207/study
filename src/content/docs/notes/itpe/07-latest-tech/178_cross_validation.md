## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 교차검증(Cross Validation)

## 30초 인출

- 본질: 데이터의 검증 구간을 바꾸어 여러 차례 학습·평가함으로써 성능 추정의 분할 의존성을 살피는 방법. 분할에 따른 성능 추정의 변동을 확인해 모델 선택 지원.
- 메커니즘: 데이터 분할 → 폴드별 학습·평가 → 점수 분포 확인 → 독립 시험.
- 통찰: 한계: 무작위 폴드가 시간·집단 의존성을 깨면 실제 배포 성능을 과대평가한다 → 방안: 데이터 생성 구조에 맞춰 시간·집단 분할을 정하고 독립 시험 집합을 보존한다.

<details><summary>핵심 용어</summary>

- **폴드:** 교차검증에서 학습·평가 순환에 사용하는 데이터 분할
- **데이터 누수:** 평가 대상의 정보가 학습 과정에 섞이는 오류

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 데이터의 검증 구간을 바꾸어 여러 차례 학습·평가함으로써 성능 추정의 분할 의존성을 살피는 방법. |
| 목적 | 분할에 따른 성능 추정의 변동을 확인해 모델 선택 지원 |

## Ⅱ. 폴드 평가와 독립 시험

```text
전체 데이터 → 독립 시험 집합 분리
       ↓ 남은 학습 집합을 K개 폴드로 분할
각 반복: K-1개 학습 + 1개 검증
       ↓ 폴드 점수 분포로 모델 선택
고정 모델 → 독립 시험 1회 평가
```

1. **목적:** 모델·하이퍼파라미터 선택을 위한 검증 점수의 안정성 확인. 최종 일반화 평가는 별도 시험 집합 사용.
2. **설계:** 독립 표본이면 KFold, 불균형 분류면 StratifiedKFold, 환자·사용자 반복 자료면 GroupKFold, 시간 의존 자료면 미래 구간을 뒤에 둔 순차 분할.
3. **누수 차단:** 정규화·결측 대체·특징 선택은 각 훈련 폴드 안에서만 학습하고 검증 폴드에 적용. 튜닝 후 평가에는 중첩 검증 또는 홀드아웃 시험 사용.
4. **보고:** 평균뿐 아니라 폴드별 편차, 집단별 오류와 데이터 분포, 학습 계산 비용·무작위 시드 명시.

## Ⅲ. 홀드아웃과 교차검증

| 구분 | 분할 방식 | 주의점 |
|---|---|---|
| 홀드아웃 | 학습·검증 한 번 분할 | 분할 선택에 민감 |
| 교차검증 | 폴드별 반복 학습·평가 | 시간·집단 누출 방지 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 소수 클래스가 일부 검증 폴드에 없음 — 양성 표본 수와 분할 수의 불일치 | 양성 수를 확인하고 가능한 경우 층화 분할 적용 |
| 시계열 평가에서 미래 정보 유입 — 임의 셔플과 시간 순서 무시 | 학습 시점보다 뒤 자료만 검증에 사용하고 전처리도 폴드 안에서 수행 |
| K회 학습 비용이 과도 — 모델 훈련 비용과 분할 수 증가 | 자원 예산에 맞춰 K와 별도 테스트 집합을 설계 |

## Ⅴ. 제언

- 전처리·특성 선택·하이퍼파라미터 탐색은 훈련 폴드 안에서만 학습. 최종 성능 보고에는 모델 선택에 쓰지 않은 별도 테스트 집합과 데이터 의존성 검토를 포함

## 출제 이력과 검증 출처

- **출제 상태:** 위 문항은 학습용 예상문제이며, 공식 기출 원문과 동일하다고 단정하지 않는다.
