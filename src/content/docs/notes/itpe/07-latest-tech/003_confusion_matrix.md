## 30초 인출

- 본질: **분류 모델 성능지표** 는 지도학습 모델의 예측 결과와 실제 참값을 대조하여 오탐과 미탐의 규모 및 모델의 판별 역량을 다각도로 정량화하는 평가 기준 체계
- 메커니즘: 참값과 예측값의 2×2 교차 행렬에서 TP, FP, FN, TN을 도출하고, 분류 임계값(Threshold) 변화에 따른 민감도·특이도 및 정밀도·재현율의 트레이드오프 곡선 면적(AUC) 산출
- 통찰: 클래스 불균형 환경에서 단순 정확도(Accuracy)는 다수 클래스 편향을 은폐하므로 불균형 도메인에서는 PR-AUC 분석과 비즈니스 오류 비용 기반 최적 임계값 튜닝 필수

<details><summary>핵심 용어</summary>

- **혼동행렬 (Confusion Matrix)** : 실제 정답(Positive/Negative)과 모델 예측(Positive/Negative)을 4분면으로 교차 집계한 2×2 행렬.
- **정밀도 (Precision)** : 모델이 Positive로 예측한 것 중 실제 Positive인 비율 (`TP / (TP + FP)`).
- **재현율 (Recall / Sensitivity)** : 실제 Positive인 것 중 모델이 Positive로 올바르게 찾아낸 비율 (`TP / (TP + FN)`).
- **ROC-AUC (Receiver Operating Characteristic - AUC)** : 참양성률(TPR)과 위양성률(FPR) 간의 변화를 그린 곡선 아래 면적으로 전반적인 클래스 분리 성능 지표.
- **PR-AUC (Precision-Recall - AUC)** : 희소 클래스(불균형 데이터)에서 위음성(FN)과 위양성(FP)에 민감하게 반응하는 정밀도-재현율 곡선 아래 면적.

</details>

## 2~4교시 25점 답안

## Ⅰ. 분류 모델 성능지표의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **분류 모델 성능지표** 는 머신러닝 모델의 추론 결과와 실제 라벨 간의 일치·불일치 빈도를 체계화하여 오류의 유형과 판별 성능을 다차원적으로 검증하는 정량적 평가 척도 |
| 목적 | 단순 정답률 왜곡 극복, 오탐(Type I Error)과 미탐(Type II Error)의 비즈니스 손실 측정 및 최적 운영 임계값 선정 |

## Ⅱ. 혼동행렬 기반 성능지표의 핵심 특성

| 구분 | 평가지표 | 산출 수식 | 공학적 특성 및 해석 |
|---|---|---|---|
| **기본 척도** | 정확도 (Accuracy) | `(TP + TN) / (TP + FP + FN + TN)` | 전체 샘플 중 올바르게 분류된 비율이나 불균형 데이터셋에서 심각한 착시 유발 |
| | 정밀도 (Precision) | `TP / (TP + FP)` | 모델 예측의 신뢰도 척도, 스팸 필터나 추천 시스템처럼 오탐(FP) 방지가 핵심인 분야 적용 |
| | 재현율 (Recall) | `TP / (TP + FN)` | 실제 양성의 탐지율(민감도), 암 진단이나 금융 사기(FDS)처럼 미탐(FN) 방지가 핵심인 분야 적용 |
| | 특이도 (Specificity) | `TN / (TN + FP)` | 실제 음성 중 모델이 음성으로 정확히 식별한 비율, ROC 곡선의 가로축(1-특이도) 구성 |
| **복합 척도** | F1-Score | `2 × (Precision × Recall) / (Precision + Recall)` | 정밀도와 재현율의 조화평균, 클래스 불균형 시 모델의 종합 균형 성능 평가 |
| | MCC (Matthews Correlation) | `(TP×TN - FP×FN) / sqrt((TP+FP)(TP+FN)(TN+FP)(TN+FN))` | 혼동행렬의 모든 사분면을 동등하게 반영하는 -1 ~ +1 범위의 통계적 상관계수 |

## Ⅲ. 혼동행렬 계산 체계 및 임계값 분류 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 혼동행렬 구조 및 임계값 결정 아키텍처 ]                 │
└────────────────────────────────────────────────────────────────────────┘
                                    │
               ┌────────────────────┴────────────────────┐
               ▼                                         ▼
      [ 실제 Positive (P) ]                     [ 실제 Negative (N) ]
 ┌───────────────────────────┐             ┌───────────────────────────┐
 │ True Positive (TP)        │             │ False Positive (FP)       │
 │ - 올바른 양성 판정        │             │ - 1종 오류 (오탐)         │
 ├───────────────────────────┤             ├───────────────────────────┤
 │ False Negative (FN)       │             │ True Negative (TN)        │
 │ - 2종 오류 (미탐)         │             │ - 올바른 음성 판정        │
 └───────────────────────────┘             └───────────────────────────┘
               │                                         │
               └────────────────────┬────────────────────┘
                                    ▼
       [ 모델 예측 확률 출력 P(Y=1|X) vs 분류 임계값 (Threshold: θ) ]
        - θ 상향 이동: FP 감소 (정밀도 증가), FN 증가 (재현율 감소)
        - θ 하향 이동: FN 감소 (재현율 증가), FP 증가 (정밀도 감소)
                                    │
                                    ▼
             [ ROC 곡선(TPR vs FPR) 및 PR 곡선(Precision vs Recall) ]
```

| 검증 단계 | 주요 활동 내용 | 핵심 산출 지표 |
|---|---|---|
| **확률값 추론** | 모델 추론 엔진의 시그모이드/소프트맥스 연속 확률 출력 | 예측 확률 분포 `P(Y=1\|X)` |
| **사분면 집계** | 특정 임계값 `θ` 기준 샘플별 4개 사분면 분류 및 집계 | TP, FP, FN, TN 계수 |
| **곡선 트레이드오프** | `θ`를 0에서 1까지 변화시키며 민감도/정밀도 궤적 산출 | ROC Curve, PR Curve |
| **통합 면적 계산** | 사다리꼴 적분(Trapezoidal rule)을 통한 곡선 하부 면적 산출 | ROC-AUC, PR-AUC |

## Ⅳ. ROC 곡선과 PR 곡선의 비교 및 적용 전략

| 비교 항목 | ROC (Receiver Operating Characteristic) | PR (Precision-Recall) |
|---|---|---|
| **그래프 축** | Y축: TPR (Recall), X축: FPR (1 - Specificity) | Y축: Precision, X축: Recall |
| **기준선 (Baseline)** | 대각선 (AUC = 0.5, 무작위 찍기) | 양성 클래스 비율 (P / (P + N)) |
| **음성(TN) 영향도** | TN이 매우 클 경우 FPR 왜곡으로 성능 과대평가 | TN을 수식에 포함하지 않아 희소 클래스 왜곡 배제 |
| **적합한 데이터셋** | 클래스 비율이 균등하거나 유사한 일반 분류 | 사기 탐지(FDS), 희귀 질환 등 극심한 불균형 데이터 |
| **최적 운영점 탐색** | Youden's J Index (`TPR - FPR` 최대화 지점) | F-beta Score 최대화 지점 (업무 가중치 beta 반영) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 불균형 데이터(예: 양성 0.1%)에서 다수 클래스(TN) 영향으로 ROC-AUC가 0.99로 왜곡 | TN을 배제하고 오탐과 미탐의 비율을 직접 반영하는 PR-AUC를 주 지표로 채택하고 Average Precision(AP) 평가 |
| 통계적 F1-Score 최적 임계값이 실제 비즈니스의 미탐 손실 비용과 불일치 | 오탐 비용(`C_FP`)과 미탐 비용(`C_FN`)을 반영한 총 비용 함수(`Cost = C_FP × FP + C_FN × FN`)를 정의하고 비용 최소화 임계값 선정 |

## Ⅵ. 제언

비즈니스 도메인의 오류 비용 매트릭스(Cost Matrix)를 시스템화하고, 실시간 추론 스트림에서 데이터 드리프트를 추적하여 최적 임계값을 동적으로 보정하는 적응형 임계값 운영 파이프라인 구축.

```text
[ 모델 추론 확률 스트림 ]
           │
           ▼
[ 동적 임계값 컨트롤러 (Dynamic Thresholding Engine) ]
   ├── Step 1: 비즈니스 손실 함수 결합 (Loss = FP × $10 + FN × $500)
   ├── Step 2: 실시간 데이터 분포 드리프트(PSI 지수) 감지
   └── Step 3: 최적 운영 임계값 θ* 실시간 조정 (예: 0.5 -> 0.35)
           │
           ▼
[ 최종 클래스 의사결정 및 오류 비용 최소화 달성 ]
```

| 구분 | 고정 임계값 운영 (Static 0.5) | 제언: 비용 기반 적응형 임계값 (Cost-sensitive) |
|---|---|---|
| **기준 결정** | 수학적 기본값 0.5 일률 적용 | 오탐 대 미탐의 경제적 손실 가중치 반영 |
| **환경 변화** | 데이터 분포 변화 시 성능 급락 | 드리프트 지표에 따른 임계값 동적 자동 튜닝 |
| **평가 초점** | 모델 자체의 통계적 정답률 극대화 | 시스템 도입에 따른 순 비즈니스 수익 극대화 |
