- 통찰: 한계: 낮은 성능을 모델 복잡도 탓으로만 돌리면 유용한 특성 부족을 놓침 → 방안: 표현력·입력 특성·학습 조건을 각각 조정해 검증

<details>
<summary>핵심 용어</summary>

- **언더피팅(Underfitting, 과소적합)** : 모델이 자료의 주요 패턴을 충분히 표현하지 못한 상태
- **오버피팅(Overfitting, 과적합)** : 학습 자료의 우연한 특성까지 맞춰 새 자료에서 성능이 낮아지는 상태
- **고편향(High Bias)** : 단순한 모델 가정이나 제한된 학습으로 실제 관계를 충분히 설명하지 못하는 오차 경향
- **모델 표현력(Model Capacity)** : 모델이 표현할 수 있는 관계의 복잡도 수준
- **특성 공학(Feature Engineering)** : 원자료를 과업에 유용한 입력 특성으로 변환·구성하는 과정
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **언더피팅(Underfitting, 과소적합)** 은 모델이 자료의 주요 관계를 충분히 학습하지 못해 훈련·검증 자료에서 모두 성능이 낮은 상태 |
| 목적 | 학습 부족과 표현력 한계를 진단해 일반화 성능 개선 |

### Ⅱ. 성능 징후

```text
모델 학습
   ↓
훈련 오차 높음 ── 검증 오차 높음
   ↓ 원인 분석
표현력·특성·학습 조건 조정
   ↓
훈련·검증 자료에서 재평가
```

### Ⅲ. 적합 상태 비교

| 상태 | 훈련 성능 | 검증 성능 | 해석 |
|---|---|---|---|
| **언더피팅(Underfitting)** | 낮음 | 낮음 | 주요 관계를 충분히 학습하지 못함 |
| 적절한 적합 | 높음 | 높음 | 새 자료에서도 학습 관계가 유지됨 |
| **오버피팅(Overfitting)** | 높음 | 낮아지거나 악화 | 훈련 자료에 지나치게 맞춤 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모델이 과업 관계를 표현하기에 단순함 | 모델 계열·복잡도 조정 후 검증 |
| 예측에 필요한 입력 특성이 부족함 | 도메인 근거에 따라 특성 추가·변환 |
| 규제가 지나치거나 학습이 부족함 | 규제 강도·학습 조건 조정 |
| 자료·레이블 품질이나 과업 정의 문제 | 표본 대표성·레이블·문제 정의 점검 |

### Ⅴ. 제언

목표 성능·운영 제약을 먼저 정하고 검증 자료에서 요인을 하나씩 조정해 기준을 충족하는 단순한 모델 선택.
