## 연관 키워드

- 언더피팅, 과소적합, 편향-분산 트레이드오프, 고편향(High Bias), 학습 곡선, 잔차 분석
- 모델 용량, 특성 공학, 전이 학습, 학습률 스케줄러, 오버피팅

## Ⅰ. 언더피팅(Underfitting)의 개요

- 핵심 요약 : 모델의 표현력이 데이터 패턴에 못 미쳐 훈련 데이터조차 잘 맞추지 못하는 과소적합 현상.
- 개념 : 모델의 **복잡도** (Capacity)가 데이터에 내재한 패턴을 담기에 부족해, 훈련 오차와 검증 오차가 모두 높은 수준에서 머무르는 **과소적합** (Underfitting) 현상.
- 배경 및 필요성 : **편향-분산 트레이드오프** (Bias-Variance Tradeoff)에서 높은 편향(High Bias)이 원인이며, 과적합(Overfitting)과 정반대의 처방이 필요하므로 진단 기준을 정확히 알아야 함.
- 주요 목적 : 모델의 표현력 확보, 비선형 특성 포착, 훈련 손실의 기준선 달성을 통한 모델 유효성 확인.

## Ⅱ. 언더피팅(Underfitting)의 특징 및 장점

- 핵심 요약 : 언더피팅은 손실 곡선과 잔차 패턴으로 드러나며, 원인을 구분해 처방하면 성능 개선이 빠름.

1. 높은 편향 : 모델 가정이 지나치게 경직되어 데이터 변화에 둔감 → 파라미터 수가 데이터 구조를 설명하기에 부족.
2. 평행한 손실 곡선 : 에포크를 늘려도 훈련 손실이 일정 수준에서 멈춤 → 학습 부족이 아니라 표현력 부족임을 판별하는 단서.
3. 체계적 잔차 : 잔차(실제값 - 예측값)가 무작위 분포가 아니라 곡선 등 규칙적 형태를 보임 → 빠진 비선형 항이나 특성을 찾는 근거.

```text
[ 손실 곡선으로 보는 언더피팅 ]

손실
  ▲
  │ ====================  검증 오차 (높음)
  │ ----------------------  훈련 오차 (높음)
  │   정체 구간 (평행선)
  └──────────────────────────► 에포크
```

## Ⅲ. 언더피팅(Underfitting)의 구조 (흐름)

- 핵심 요약 : 원인을 모델, 특성, 정규화 세 축으로 나누어 차례로 확인하는 진단 흐름.

```text
[ 언더피팅 진단 순서 ]

훈련 오차가 높은가?
          ↓ 예
모델 용량이 충분한가? ── 아니오 → 복잡도 상향
          ↓ 예
특성이 핵심 정보를 담는가? ── 아니오 → 특성 추가
          ↓ 예
정규화가 과하지 않은가? ── 예 → 정규화 완화
```

- 세 원인은 서로 다른 처방을 요구하므로, 한 번에 여러 가지를 바꾸지 않고 순서대로 확인하는 것이 원칙임.

## Ⅳ. 언더피팅(Underfitting)의 비교

- 핵심 요약 : 언더피팅과 오버피팅은 편향과 분산의 방향이 반대이며, 적정 적합은 두 오차가 모두 낮은 지점임.

| 비교 항목 | 언더피팅 | 적정 적합 (Good Fit) | 오버피팅 (Overfitting) |
| --- | --- | --- | --- |
| 편향·분산 | 높은 편향, 낮은 분산 | 적절한 편향과 분산 | 낮은 편향, 높은 분산 |
| 훈련 데이터 오차 | 높음 | 낮음 | 매우 낮음 |
| 검증 데이터 오차 | 높음, 훈련 오차와 비슷 | 낮음 | 높음, 훈련 오차와 큰 격차 |
| 모델 복잡도 | 데이터 대비 지나치게 단순 | 데이터에 부합 | 노이즈까지 암기할 만큼 복잡 |
| 주된 처방 | 모델 확장, 특성 공학 | 현재 설정 유지 | 정규화, 드롭아웃, 데이터 증강 |

- 개발 절차상 언더피팅을 먼저 해결해 학습 능력을 확보한 뒤에 과적합을 규제하는 것이 일반적인 순서임.

## Ⅴ. 언더피팅(Underfitting)의 한계와 방안

- 핵심 요약 : 표현력 부족, 특성 손실, 학습 설정 오류를 모델 확장, 특성 공학, 스케줄링으로 해결.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 선형 알고리즘의 비선형 패턴 포착 실패 | 복잡한 이상거래나 이미지에 선형 모델을 적용해 패턴을 놓침 | 트리 기반 앙상블(XGBoost, LightGBM) 또는 **심층 신경망** (DNN, Deep Neural Network)으로 복잡도 상향 | 검증 오차, 잔차 구조 |
| 피처 표현력 부족과 과도한 차원 축소 | 핵심 변수가 빠지거나 PCA (Principal Component Analysis) 과정에서 중요한 분산이 소실됨 | 도메인 기반 파생 변수 생성, **다항 특성** (Polynomial Features) 추가, 특성 선택 기준 완화 | 특성별 기여도 |
| 학습률과 에포크 설정 오류 | 학습률이 작거나 조기 종료 기준이 엄격해 수렴 전에 멈춤 | **학습률 스케줄러** (Learning Rate Scheduler, 학습 중 학습률을 조정하는 장치) 적용, 에포크 증대, Patience 여유 확보 | 학습 곡선의 수렴 시점 |

## Ⅵ. 언더피팅(Underfitting)에 대한 기술사적 제언

- 핵심 요약 : 표현력 점검, 잔차 분석, 전이 학습을 개발 절차의 기본 단계로 제도화.

1. 표현력 상한 점검 절차 : 모델 개발 초기에 소량의 데이터로 훈련 손실이 거의 0까지 내려가는지 확인해, 해당 구조가 데이터를 담을 수 있는 능력이 있는지 먼저 판단하도록 절차에 넣음.
2. 잔차 분석의 상시화 : 예측 실패 사례의 잔차를 구간별로 시각화해 비선형성이 빠진 영역을 찾고, 그 영역에 맞는 파생 특성을 반복적으로 추가함.
3. 사전 학습 모델의 활용 : 데이터가 제한된 과제에서는 대규모 데이터로 사전 학습된 모델을 가져와 미세조정하는 **전이 학습** (Transfer Learning)을 기본 경로로 검토함.

## Ⅶ. 결론

- 핵심 요약 : 언더피팅은 모델이 데이터를 충분히 설명하지 못하는 편향 문제이며, 복잡도와 특성 설계로 해결함.
- 시사점 : 과적합 규제에 앞서 표현력을 먼저 확보하는 순서가 개발 효율을 높임.
