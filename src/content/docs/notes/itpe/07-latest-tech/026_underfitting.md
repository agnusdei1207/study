## 30초 인출

- 본질: **언더피팅(Underfitting, 과소적합)** 은 머신러닝 모델의 복잡도와 표현력이 데이터의 내재적 패턴을 학습하기에 지나치게 단순하여 훈련 데이터셋과 검증 데이터셋 모두에서 높은 오차를 기록하는 상태
- 메커니즘: 편향-분산 트레이드오프에서 높은 편향(High Bias)으로 인해 발생하며, 모델 용량(Capacity) 증대, 피처 엔지니어링, 과도한 규제 완화를 통해 최적 적합 상태로 유도
- 통찰: 단순 데이터 추가 수집만으로는 고편향 문제를 해결할 수 없으므로 다항 특성 확장, 딥러닝 레이어 추가 및 규제 계수(Weight Decay) 축소 결합 필수

<details><summary>핵심 용어</summary>

- **언더피팅 (Underfitting)** : 모델이 데이터의 기본적인 내재 패턴조차 포착하지 못하여 훈련과 검증 오차가 모두 높게 유지되는 현상.
- **고편향 (High Bias)** : 모델의 가정이 너무 엄격하여 실제 데이터 분포와의 괴리가 크게 발생하는 통계적 오차 상태.
- **모델 표현력 (Model Capacity)** : 주어진 모델 아키텍처가 임의의 복잡한 함수 관계를 근사(Approximate)할 수 있는 가용 수학적 자유도.
- **특성 공학 (Feature Engineering)** : 모델이 비선형 패턴을 쉽게 분리할 수 있도록 원천 데이터로부터 다항식 피처, 교차 피처를 파생 생성하는 기법.
- **규제 완화 (Regularization Loosening)** : L1/L2 규제 계수(λ)를 줄여 모델 가중치가 더 넓은 파라미터 공간을 탐색하도록 허용하는 조치.

</details>

## 2~4교시 25점 답안

## Ⅰ. 언더피팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **언더피팅(Underfitting)** 은 기계학습 모델의 아키텍처가 너무 단순하거나 학습이 불충분하여 훈련 세트의 핵심적인 상관관계조차 반영하지 못함으로써 훈련 오차와 검증 오차가 동시에 높게 나타나는 현상 |
| 목적 | 고편향(High Bias) 오차 진단, 모델 표현력(Capacity) 확장 및 목표 비즈니스 기준치를 충족하는 일반화 성능 확보 |

## Ⅱ. 언더피팅의 핵심 특징 및 고편향(High Bias) 속성

| 구분 | 언더피팅의 특징 | 통계학적 및 공학적 세부 원리 |
|---|---|---|
| **고편향 저분산 (High Bias)** | 지나치게 단순화된 가정 | 데이터의 실제 형태가 3차 곡선임에도 1차 선형 모델로 강제 가정하여 회귀선이 전 구간에서 오차 발생 |
| **높은 훈련 손실** | 학습 데이터조차 미적합 | 최적화가 수렴했음에도 불구하고 훈련 데이터셋에서의 정확도가 비즈니스 허용 임계치에 미달 |
| **데이터 증대 무용론** | 훈련 샘플 추가의 비효율 | 모델 용량이 이미 포화 상태이므로 동일한 모델에 데이터 샘플을 10배 늘려도 성능 개선 불가 |
| **조기 학습 중단 징후** | 부적절한 에포크 및 학습률 | 과도하게 큰 학습률로 발산하거나, 너무 작은 에포크 설정으로 최적 수렴점에 도달하기 전에 학습 종료 |

## Ⅲ. 언더피팅 진단 체계 및 학습 곡선 분석 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 언더피팅 vs 최적 적합 학습 곡선 분석 체계 ]              │
└────────────────────────────────────────────────────────────────────────┘
 손실 (Loss)
    ▲
    │
    │  ─── 훈련 손실 (Training Loss)    ───┐
    │                                      ├── 언더피팅 구간 (수렴 손실이 목표치 상회)
    │  ─── 검증 손실 (Validation Loss)  ───┘
    │  - 두 곡선 간의 갭(Gap)은 작으나, 손실 절대값이 너무 높음
    ├────────────────────────────────────────────────────────────────────
    │ [ 비즈니스 허용 오차 기준선 (Target Benchmark) ]
    │
    │  \
    │   \  최적 모델의 훈련/검증 손실 ──> 목표 기준선 이하로 안정적 안착
    │    \───────────────────────────────
    └────────────────────────────────────────────────► 학습 반복 (Epochs)
```

| 진단 단계 | 주요 관측 지표 | 공학적 원인 분석 |
|---|---|---|
| **훈련 손실 관측** | 훈련 오차가 벤치마크 기준치 이상으로 높음 | 모델 파라미터 수 부족, 특성 표현력 한계 |
| **검증 갭 측정** | 훈련 손실과 검증 손실 간 격차(Variance)가 거의 없음 | 과적합은 아니나, 학습 자체가 덜 된 고편향 상태 |
| **학습 곡선 기울기** | 초기 몇 에포크 만에 손실 감소가 멈추고 평탄화 | 국소 최솟값(Local Minima) 조기 안착 또는 과도한 규제 |

## Ⅳ. 언더피팅 vs 오버피팅 비교

| 비교 항목 | 언더피팅 (Underfitting) | 오버피팅 (Overfitting) |
|---|---|---|
| **오차 원인** | 높은 편향 (High Bias) | 높은 분산 (High Variance) |
| **모델 복잡도** | 데이터 복잡도 대비 지나치게 단순함 | 데이터 복잡도 대비 지나치게 복잡함 |
| **훈련 손실** | 높음 (훈련 셋도 못 맞춤) | 극히 낮음 (훈련 셋 완벽 암기) |
| **검증 손실** | 높음 (훈련 손실과 유사하게 높음) | 높음 (훈련 손실과 큰 격차로 반등) |
| **결정 경계** | 지나치게 평평하고 단순한 직선/평면 | 모든 노이즈를 포함하는 꼬불꼬불한 곡면 |
| **대응 방향** | 모델 복잡도 증대, 피처 추가, 규제 완화 | 데이터 증강, 정규화, 드롭아웃, 조기 종료 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 입력 특징(Feature) 간의 비선형 상호작용이 원천 데이터에 누락되어 선형 모델이 언더피팅 발생 | 다항식 특성 생성(PolynomialFeatures) 및 도메인 지식 기반 교차 피처(Interaction Feature) 엔지니어링 수행 |
| 모델의 파라미터 규제(Weight Decay, Dropout)가 과도하여 뉴런의 표현력이 억압된 상태 | L1/L2 정규화 계수를 10배 단위로 축소 조정하고 드롭아웃 비율을 0.5에서 0.1~0.2 수준으로 하향 |

## Ⅵ. 제언

언더피팅 발생 시 데이터 추가 수집에 자원을 낭비하지 않고, 딥러닝 신경망의 깊이(Depth)와 너비(Width)를 점진적으로 확장하는 점진적 모델 스케일링(Gradual Scaling) 파이프라인 구축.

```text
[ 초기 단순 모델 (선형/얕은 트리) 언더피팅 확인 ]
                        │
                        ▼
[ 1단계: 피처 엔지니어링 (특성 비선형 변환 및 임베딩) ]
                        │
                        ▼
[ 2단계: 모델 복잡도 확장 (레이어 추가, 비선형 활성화 함수 GELU 결합) ]
                        │
                        ▼
[ 3단계: 규제 완화 및 학습률 스케줄러 (Cosine Annealing) 적용 ]
                        │
                        ▼
[ 훈련/검증 손실 목표치 이하 도달 및 비즈니스 기준선 충족 ]
```

| 구분 | 무작정 데이터 추가 수집 | 제언: 점진적 모델 스케일링 |
|---|---|---|
| **비용 효율** | 데이터 레이블링 비용 수천만 원 낭비 | 알고리즘 구조 변경으로 추가 비용 0원 해결 |
| **해결 속도** | 수주 간 데이터 재수집 대기 | 하이퍼파라미터 튜닝으로 수시간 내 검증 |
| **성능 달성** | 용량 한계로 정확도 정체 지속 | 모델 표현력 확장을 통한 비약적 정확도 향상 |
