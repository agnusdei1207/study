## 핵심 용어
- DSML 플랫폼(Data Science and Machine Learning Platform): 데이터 접근, 탐색, 모델 개발, 검증, 배포 및 모니터링에 이르는 머신러닝 라이프사이클 전체를 지원하는 응집력 있는 소프트웨어 제품군(예: Databricks, Dataiku, Vertex AI)
- 시민 데이터 과학자(Citizen Data Scientist): 통계나 코딩 전문가는 아니지만, 비즈니스 지식을 바탕으로 AutoML이나 드래그앤드롭 GUI 툴을 이용해 예측 모델을 구축하고 업무에 활용하는 현업 실무자
- AutoML(Automated Machine Learning): 데이터 전처리, 특성 공학, 알고리즘 선택, 하이퍼파라미터 튜닝의 전 과정을 기계가 스스로 수행하여 비전문가도 수준 높은 모델을 만들 수 있게 돕는 자동화 기술

## 핵심 통찰
- 도구 통합과 데이터 계보: 수집·실험·배포의 메타데이터를 연결하면 재현성과 추적성이 높아지지만, 외부 시스템까지 포함한 계보의 완전성은 연결 범위와 기록 정책에 따라 달라짐
- 양손잡이 조직 지원(Code-first & Low-code): 파이썬 코드로 깊이 파고드는 전문 데이터 과학자와 클릭 몇 번으로 수요 예측을 하고 싶은 영업팀 대리가 동일한 데이터와 모델 카탈로그를 보며 협업할 수 있어야 진정한 전사적 AI 전환(AX)이 완성됨
- 생성형 AI(GenAI)와의 융합: 최신 DSML 플랫폼들은 기존 예측형 머신러닝(분류/회귀)뿐만 아니라, 사내 RAG 파이프라인 구축, LLM 미세조정, 프롬프트 엔지니어링 기능까지 기본 탑재하는 추세로 급진화함

## 이웃 토픽과 구분
- DSML 프로젝트 vs DSML 플랫폼: DSML 프로젝트는 개별 비즈니스 과제를 해결하는 방법론과 관리 프로세스 / DSML 플랫폼은 그 프로젝트들을 전사적으로 수행할 수 있도록 뒷받침하는 기술 소프트웨어 인프라

### Ⅰ. 플랫폼 구조
