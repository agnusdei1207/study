## 30초 인출

- 본질: **SOM (Self-Organizing Map, 자기조직화지도)** 은 고차원 입력 데이터의 위상학적(Topological) 근접 관계를 손실 없이 보존하면서 2차원 격자(Grid) 평면의 뉴런으로 사상(Mapping)하는 비지도 경쟁 학습(Competitive Learning) 기반 인공신경망
- 메커니즘: 입력 벡터와 유클리디안 거리가 가장 가까운 승자 뉴런(BMU, Best Matching Unit)을 선발하고, 이웃 반경 함수($h_{ci}(t)$)에 속한 인접 뉴런들의 가중치 벡터를 입력 방향으로 동시 업데이트
- 통찰: 초기 학습률과 이웃 반경 설정에 따른 국소 최적해(Local Minima) 수렴 및 격자 뒤틀림(Twist) 위험이 존재하므로 가우시안 감쇠 스케줄링과 U-Matrix 기반 위상 오차 진단 체계 구축 필수

<details><summary>핵심 용어</summary>

- **SOM (Self-Organizing Map)** : 테우보 코호넨(Teuvo Kohonen)이 제안한 비지도 신경망으로 고차원 패턴을 2차원 맵에 군집화하는 알고리즘.
- **승자 독식 (Winner-Take-All)** : 입력 데이터와 가장 유사한 단 하나의 뉴런만이 승자(BMU)가 되어 학습 권한을 획득하는 경쟁 메커니즘.
- **BMU (Best Matching Unit)** : 입력 벡터와의 유클리드 거리가 최소인 최적 매칭 격자 뉴런.
- **위상 보존 (Topology Preservation)** : 고차원 원본 공간에서 서로 가까운 거리에 위치한 데이터가 저차원 2차원 맵에서도 인접한 격자에 배치되는 기하학적 성질.
- **U-Matrix (Unified Distance Matrix)** : 인접한 뉴런 가중치 벡터 간의 기하학적 거리를 음영(Color map)으로 표현하여 군집 경계를 시각화하는 다이어그램.

</details>

## 2~4교시 25점 답안

## Ⅰ. SOM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SOM** 은 대뇌 피질의 시각 인지 메커니즘을 모방하여, 고차원 다변량 데이터를 입력받아 입력 공간의 기하학적 위상 구조를 유지한 채 저차원(주로 2차원) 격자 신경망으로 투영하는 비지도 경쟁 학습 모델 |
| 목적 | 복잡한 고차원 데이터의 차원 축소, 비지도 군집화(Clustering) 및 2차원 시각화를 통한 잠재 패턴 직관적 탐색 |

## Ⅱ. SOM의 4대 핵심 구성 요소 및 위상 보존 특징

| 구성 요소 | 수학적 정의 및 메커니즘 | 기술적 특징 및 역할 |
|---|---|---|
| **입력 계층 (Input Layer)** | $X = [x_1, x_2, \dots, x_D]^T \in \mathbb{R}^D$ | $D$차원 입력 특징 벡터를 수신하여 경쟁 계층으로 100% 완전 연결(Fully-Connected) |
| **경쟁 계층 (2D Grid Layer)** | 2차원 격자 배열 뉴런 집합 ($M \times N$) | 각 뉴런 $i$는 입력과 동일한 차원의 가중치 프로토타입 벡터 $W_i \in \mathbb{R}^D$를 보유 |
| **승자 선발 (BMU 탐색)** | $c = \arg\min_i \|X - W_i\|$ | 입력 벡터 $X$와의 유클리드 거리가 가장 가까운 최소 거리 뉴런 $c$를 단독 승자로 선출 |
| **이웃 함수 ($h_{ci}(t)$)** | $h_{ci}(t) = \exp\left(-\frac{\|r_c - r_i\|^2}{2\sigma(t)^2}\right)$ | 승자 뉴런 $c$의 물리적 격자 위치 $r_c$를 중심으로 주변 뉴런 $r_i$에 차등적 가중치 업데이트 부여 |

## Ⅲ. SOM 경쟁 학습 및 가중치 갱신 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             SOM (Self-Organizing Map) 순환 경쟁 학습 파이프라인        │
└────────────────────────────────────────────────────────────────────────┘
 [ 고차원 입력 데이터 벡터 X_k 취득 ]
                  │
                  ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 1단계: 유클리드 거리 경쟁 (Competition)                              │
 │  - 모든 뉴런 i에 대해 d_i = ||X_k - W_i|| 계산                       │
 │  - 최소 거리 뉴런 탐색: c = argmin_i d_i ──> [ 승자 뉴런 (BMU) 확정 ]│
 └────────────────┬─────────────────────────────────────────────────────┘
                  │
                  ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 2단계: 협력 및 이웃 반경 결정 (Cooperation)                          │
 │  - 시간 t에 따라 이웃 반경 σ(t) 및 학습률 α(t) 지수 감쇠              │
 │  - 가우시안 이웃 함수 계산: h_ci(t) = exp( -||r_c - r_i||^2 / 2σ(t)^2)│
 └────────────────┬─────────────────────────────────────────────────────┘
                  │
                  ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 3단계: 가중치 적응 갱신 (Synaptic Adaptation)                        │
 │  - W_i(t+1) = W_i(t) + α(t) * h_ci(t) * [ X_k - W_i(t) ]             │
 │  - BMU 및 그 이웃 뉴런들을 입력 벡터 X_k 쪽으로 끌어당김              │
 └────────────────┬─────────────────────────────────────────────────────┘
                  │
                  ▼
 [ 다음 훈련 샘플 입력 및 에포크 반복 (반경 σ가 0에 수렴할 때까지 순환) ]
```

| 학습 단계 | 상세 수행 작업 | 파라미터 변화 |
|---|---|---|
| **초기화 단계** | 가중치 벡터 $W_i$를 랜덤 난수 또는 PCA 제1, 제2 주성분 축으로 초기화 | $t = 0$ |
| **순서화 단계 (Ordering)** | 큰 학습률($\alpha \approx 0.1$)과 넓은 이웃 반경으로 대략적인 위상 뼈대 형성 | $\sigma(t), \alpha(t)$ 급격 감쇠 |
| **수렴 단계 (Convergence)** | 매우 작은 학습률($\alpha \approx 0.01$)과 반경 1 미만으로 미세 가중치 튜닝 | 국소 영역 정밀 배치 |
| **결과 매핑** | 완성된 2D 격자 위에 U-Matrix를 생성하여 군집 간 계곡과 능선 시각화 | 거리 행렬 플로팅 |

## Ⅳ. 신경망 패러다임 비교 (비지도 SOM vs 지도학습 MLP)

| 비교 항목 | 자기조직화지도 (SOM - 본 토픽) | 다층 퍼셉트론 (MLP: Multi-Layer Perceptron) |
|---|---|---|
| **학습 유형** | 비지도 학습 (Unsupervised Learning) | 지도 학습 (Supervised Learning) |
| **정답 레이블** | 불필요 (입력 데이터 자체의 패턴 학습) | 필수 (Ground Truth 정답 타깃 요구) |
| **오차 전파 방식** | 역전파 없음 (순전파 경쟁 및 국소 갱신) | 손실 함수 오차의 전 계층 역전파 (Backpropagation) |
| **활성화 함수** | 없음 (유클리드 거리 기반 경쟁) | Sigmoid, ReLU, GELU 등 비선형 활성화 |
| **결과 출력물** | 고차원의 2차원 위상 격자 맵 (Clustering) | 단일 분류 클래스 확률 또는 회귀 연속값 |
| **적용 목적** | 차원 축소, 고객 세분화, 이상 탐지 가시화 | 객체 분류, 주가 예측, 텍스트 생성 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 가중치 벡터를 무작위 난수로 초기화할 경우 초기에 맵이 꼬이는 위상학적 뒤틀림(Twisting) 및 국소 최적화 함몰 | 데이터의 공분산 행렬에서 상위 2개 고유벡터를 추출하여 초기 가중치를 정렬하는 주성분분석(PCA) 기반 선형 초기화 적용 |
| 고정된 2차원 직사각형/육각형 격자 크기를 사전에 정적으로 정의해야 하므로 데이터 복잡도에 따른 유연한 증설 불가 | 학습 진행에 따라 오차가 큰 영역에 신규 뉴런을 동적으로 추가 삽입하는 성장형 그리드(Growing SOM / GNG) 기법 채택 |
| 학습 데이터가 수십만 건 이상일 때 매 스텝마다 모든 뉴런과 거리 계산을 수행함에 따른 $O(N \cdot M \cdot D)$ 연산 지연 | GPU 텐서 병렬화 기반 배치 SOM(Batch SOM) 알고리즘을 도입하여 에포크당 1회 누적 가중치 업데이트로 가속화 |

## Ⅵ. 제언

고차원 산업 설비 이상 징후 분석에서 정확한 위상 보존과 직관적 군집 해석을 달성하기 위해 PCA 초기화와 U-Matrix 및 계층적 클러스터링을 결합한 하이브리드 SOM 파이프라인 구축 권고.

```text
[ 고차원 센서 시계열 데이터 (D > 50) ]
                  │
                  ▼
┌────────────────────────────────────────────────────────┐
│ 1단계: 주성분 분석(PCA) 기반 맵 초기화                 │
│  - 꼬임(Twist) 없는 안정적 2D 격자 가중치 사전 배치    │
└─────────────────┬──────────────────────────────────────┘
                  │
                  ▼
┌────────────────────────────────────────────────────────┐
│ 2단계: GPU 가속 Batch-SOM 경쟁 학습                    │
│  - 양자화 오차(QE) 및 위상 오차(TE) 수렴 모니터링      │
└─────────────────┬──────────────────────────────────────┘
                  │
                  ▼
┌────────────────────────────────────────────────────────┐
│ 3단계: U-Matrix & 계층적 클러스터링(Agglomerative) 결합 │
│  - 뉴런 간 거리를 히트맵으로 가시화하여 경계선 자동 추출│
│  - 설비 정상 / 주의 / 고장 임계 구역 2차원 공간 자동 구획│
└────────────────────────────────────────────────────────┘
```

| 구분 | 무작위 초기화 기본 SOM | 제언: PCA 초기화 + U-Matrix 결합 파이프라인 |
|---|---|---|
| **위상 오차 (TE)** | 격자 꼬임으로 15~20% 오차 발생 | 위상 오차 2% 미만으로 신뢰성 확보 |
| **학습 수렴 속도** | 수백 에포크 반복 학습 필요 | 초기 방향성 확보로 수렴 속도 5배 가속 |
| **군집 경계 해석** | 뉴런 배치만으로 경계 모호 | U-Matrix 음영으로 군집 간 장벽 명확화 |
| **산업 적용성** | 연구용 장난감 모델 수준 | 설비 FDC(Fault Detection) 실시간 관제 투입 |
