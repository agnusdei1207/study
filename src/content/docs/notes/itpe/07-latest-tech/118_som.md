## 연관 키워드

- 자기조직화 지도(SOM, Self-Organizing Map), 승자 뉴런(BMU, Best Matching Unit), 이웃 반경, 가중치 벡터
- U-Matrix, 위상 오차(Topographic Error), 양자화 오차(Quantization Error), 주성분 분석(PCA)
- 성장형 SOM(Growing SOM), 배치 SOM(Batch SOM), 비지도 학습, 군집화(Clustering)

## Ⅰ. SOM의 개요

- 핵심 요약 : 고차원 데이터를 입력 공간의 위상 구조를 유지한 2차원 격자에 투영하는 비지도 경쟁 학습 모델.
- 개념 : 입력과 가장 가까운 뉴런을 중심으로 이웃 뉴런을 함께 갱신해, 정답 레이블 없이 고차원 데이터의 위상 구조를 2차원 격자에 보존하는 **자기조직화 지도**(SOM, Self-Organizing Map).
- 배경 및 필요성 : 레이블이 없는 고차원 데이터는 사람이 구조를 직접 보기 어렵다. 그러나 초기 가중치와 학습 설정에 따라 학습이 국소 최적에 머물거나 격자가 꼬이는 문제가 생기므로, 초기화 방식과 **U-Matrix**(Unified Distance Matrix, 인접 뉴런 간 거리를 음영으로 표시한 지도) 같은 진단 절차를 함께 설계해야 한다.
- 주요 목적 : 차원 축소, 비지도 군집화, 2차원 시각화를 통해 데이터에 숨은 구조를 직관적으로 탐색하는 것.

## Ⅱ. SOM의 특징 및 장점

- 핵심 요약 : 경쟁과 이웃 협력을 통한 국소 갱신이 위상 보존과 시각화 능력으로 이어지는 구조.

1. 위상 보존 : 입력 공간에서 가까운 데이터가 격자에서도 가까운 뉴런에 대응 → 군집 간 관계를 지도 위 거리로 해석 가능.
2. 경쟁 학습 : **승자 뉴런**(BMU, Best Matching Unit, 입력과 유클리드 거리가 가장 가까운 뉴런)을 선출 → 뉴런별 역할이 분화되어 군집 구조가 드러남.
3. 이웃 협력 : 승자 주변의 뉴런을 함께 갱신 → 인접 뉴런이 비슷한 대표 벡터를 가져 지도가 매끄러워짐.
4. 레이블 불요 : 정답 없이 입력 패턴만으로 학습 → 라벨링 비용 없이 탐색적 분석 수행.

## Ⅲ. SOM의 구조 (흐름)

- 핵심 요약 : 경쟁, 협력, 적응의 세 단계가 순환하며 뉴런의 가중치가 입력 분포에 맞춰 이동하는 구조.
- **가중치 벡터**(Weight Vector, 각 뉴런이 입력 차원과 같은 길이로 가진 대표 벡터) : 학습이 끝나면 각 뉴런의 가중치가 해당 영역의 대표 패턴이 됨.
- **이웃 반경**(Neighborhood Radius, 함께 갱신할 이웃의 범위) : 학습이 진행될수록 줄어들어, 초기에는 전체 구조를 잡고 후기에는 세부를 다듬음.

```text
[ SOM 학습 순환 ]

입력 벡터 X 취득
   ↓ 1단계 경쟁
모든 뉴런과 거리 계산 후 BMU 선정
   ↓ 2단계 협력
BMU 주변 이웃 반경 결정 (가우시안 가중)
   ↓ 3단계 적응
BMU와 이웃의 가중치를 X 쪽으로 이동
   ↓
반경이 충분히 줄 때까지 반복
```

```text
[ 입력 공간에서 격자 공간으로 ]

고차원 입력 (D차원)
   ↓ 경쟁 학습으로 위상 보존 매핑
2차원 격자 (M × N 뉴런)
   ↓
U-Matrix로 군집 경계 확인
```

## Ⅳ. SOM의 비교

- 핵심 요약 : 지도 학습 모델과 달리 SOM은 정답 없이 구조를 드러내므로, 목적이 탐색인지 예측인지에 따라 선택이 갈린다.

| 비교 축 | SOM (본 토픽) | 다층 퍼셉트론(MLP, Multi-Layer Perceptron) |
| --- | --- | --- |
| 학습 유형 | 비지도 학습 | 지도 학습 |
| 정답 레이블 | 불필요 | 필수 |
| 오차 전파 | 역전파 없이 경쟁과 국소 갱신 | **역전파**(Backpropagation, 출력 오차를 역방향으로 전파해 가중치를 갱신하는 방법) |
| 결과물 | 2차원 위상 격자 맵과 군집 | 분류 확률 또는 회귀 값 |

- 선택 기준 : 레이블이 없고 구조 탐색이 목적이면 SOM을, 명확한 예측 목표가 있으면 지도 학습 모델을 택한다.

## Ⅴ. SOM의 한계와 방안

- 핵심 요약 : 초기화 민감성, 고정 격자, 연산 지연을 PCA 초기화, 성장형 구조, 배치 갱신으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 위상 뒤틀림과 국소 최적 | 가중치를 무작위로 초기화하면 격자가 꼬이고 국소 최적에 갇힘 | **주성분 분석**(PCA, Principal Component Analysis)의 상위 두 고유벡터로 초기 가중치 정렬 | **위상 오차**(Topographic Error, 최적과 차선 승자가 격자에서 인접하지 않는 샘플 비율) |
| 고정 격자 크기 | 격자 크기를 사전에 정해야 해 데이터 복잡도 변화에 대응하지 못함 | 오차가 큰 영역에 뉴런을 추가하는 **성장형 SOM**(Growing SOM) 적용 | 양자화 오차(Quantization Error) 추이 |
| 대규모 데이터 연산 지연 | 매 스텝마다 모든 뉴런과 거리를 계산해 연산량이 급증 | 에포크 단위로 누적 갱신하는 **배치 SOM**(Batch SOM)과 병렬 연산 | 에포크당 학습 시간 |

## Ⅵ. SOM에 대한 기술사적 제언

- 핵심 요약 : SOM을 확률적 판단이 아닌 탐색 도구로 쓰되, 초기화와 진단을 포함한 분석 절차로 정착시키는 것이 적용의 핵심.

1. 데이터 분석 조직은 SOM 결과를 최종 판단이 아닌 탐색 단계의 근거로 두고, U-Matrix와 위상 오차를 함께 확인하는 점검 절차를 분석 표준에 포함해야 한다.
2. 분석 인프라 조직은 대규모 데이터에 대비해 배치 방식과 병렬 연산 환경을 공통 자원으로 마련하여, 분석가마다 학습 방식이 달라지지 않도록 해야 한다.
3. 현업 조직은 SOM이 만든 군집을 라벨 설계나 후속 지도 학습의 입력으로 연결해, 탐색 결과가 실제 의사결정으로 이어지도록 해야 한다.

## Ⅶ. 결론

- 핵심 요약 : SOM은 정답 없이 고차원 데이터의 구조를 2차원 지도로 드러내는 비지도 학습 도구임.
- 시사점 : 지도를 시각적으로 해석하는 강점이 크지만, 초기화와 진단을 소홀히 하면 왜곡된 군집을 보게 되므로 절차를 함께 설계해야 한다.
