## 30초 인출

- 본질: **데이터 라벨링 (Data Labeling)** 은 원천 비정형 데이터(텍스트, 이미지, 음성, 영상)에 인공지능 모델이 지도학습(Supervised Learning)을 수행할 수 있도록 정답에 해당하는 메타데이터 표지(Tag/Annotation)를 체계적으로 부여하는 데이터 공학 활동
- 메커니즘: 작업 가이드라인 수립 → 수동/자동 표지 부여(Bounding Box, Segmentation, NER) → 작업자 간 일치도(IAA, Cohen's Kappa) 통계 검증 → 골든 데이터셋 확정
- 통찰: 인간 라벨러의 주관적 편향과 비용·시간 병목이 프로젝트 성패를 좌우하므로 파운데이션 모델 기반 오토 라벨링과 불확실성 기반 능동 학습(Active Learning) 결합 필수

<details><summary>핵심 용어</summary>

- **데이터 라벨링 (Data Labeling)** : 원시 데이터에 목적에 부합하는 정답 라벨(어노테이션)을 부착하는 가공 공정.
- **바운딩 박스 (Bounding Box)** : 영상 내 특정 객체의 위치를 최소 크기의 2D 직사각형 좌표($(x_{\min}, y_{\min}, x_{\max}, y_{\max})$)로 감싸는 표지.
- **세그멘테이션 (Segmentation)** : 픽셀 단위로 객체의 윤곽선을 정밀 분할하여 클래스를 지정하는 고밀도 라벨링 기법 (시맨틱/인스턴스 분할).
- **작업자 간 일치도 (IAA, Inter-Annotator Agreement)** : 복수의 라벨러가 동일한 데이터에 대해 얼마나 일관된 라벨을 부여했는지 정량화하는 신뢰도 지표.
- **코헨 카파 (Cohen's Kappa, $\kappa$)** : 두 작업자 간의 평가 결과에서 우연히 일치할 확률을 수학적으로 배제하여 산출하는 정밀 일치도 계수.

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 라벨링의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 라벨링** 은 이미지, 텍스트, 오디오 등 가공되지 않은 로우 데이터(Raw Data)에 기계학습 모델이 패턴을 학습하고 정답을 유추할 수 있도록 목표 속성값(클래스, 위치, 의미)을 부여하는 어노테이션(Annotation) 작업 |
| 목적 | AI 모델 훈련을 위한 고품질 지도학습 그라운드 트루스(Ground Truth) 확보 및 데이터 중심 AI(Data-Centric AI) 품질 완성 |

## Ⅱ. 데이터 모달리티별 라벨링 유형 및 특징

| 모달리티 | 라벨링 유형 | 작업 방식 및 데이터 형태 | 주요 특징 및 적용 분야 |
|---|---|---|---|
| **비전 (Vision)** | 바운딩 박스 (Bounding Box) | 객체 외곽에 최소 직사각형 2D/3D 박스 지정 | 자율주행 차량/보행자 검출, 결함 탐지 |
| | 폴리곤/세그멘테이션 | 객체 외곽선을 다각형 정점 또는 픽셀 단위 마스킹 | 의료 영상 종양 분석, 위성 지도 도로 분할 |
| | 키포인트 (Keypoints) | 인체 관절이나 안면 랜드마크 중심점 좌표 지정 | 모션 캡처, 자세 추정, 제스처 인식 |
| **자연어 (Text)** | 개체명 인식 (NER) | 텍스트 내 인명, 기관명, 지명 등 엔티티 태깅 | 정보 추출, 계약서 분석, 질의응답 |
| | 감성 및 의도 분류 | 문장 전체에 긍정/부정 극성 또는 의도 라벨 부여 | 고객 상담 챗봇, 소셜 평판 분석 |
| **음성 (Audio)** | 전사 (Transcription) | 발화 음성 구간과 일치하는 텍스트 전사(STT) | 음성 인식 비서, 콜센터 녹취 분석 |

## Ⅲ. 데이터 라벨링 전주기 구축 프로세스 및 품질 검수 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             데이터 라벨링 엔드투엔드 구축 및 품질 거버넌스 파이프라인    │
└────────────────────────────────────────────────────────────────────────┘
 [ 1단계: 라벨링 기획 및 작업 기준서(가이드라인) 수립 ]
  - 모호한 경계 사례(Corner Case) 예시 명시 및 라벨 스키마 정의
               │
               ▼
 [ 2단계: 사전 파일럿 라벨링 및 지침 보정 (Pilot Phase) ]
  - 소량(100~500건) 라벨링 후 작업자 간 일치도(IAA) 1차 측정
               │
               ▼
 [ 3단계: 본 라벨링 수행 (Production Annotation) ]
  - 모델 보조 라벨링(AI Pre-labeling) ──> 인간 작업자 검토 및 수정
               │
               ▼
 [ 4단계: 통계적 품질 검수 계층 (Quality Assurance & Validation) ]
  ├── 전수 규칙 검사: 포맷 무결성, 바운딩 박스 크기(최소 픽셀) 검증
  ├── 교차 검수: 복수 작업자 중복 라벨링을 통한 코헨 카파(κ) 계측
  └── 불일치(Disagreement) 데이터 ──> 전문 검수자(Adjudicator) 최종 확정
               │
               ▼
 [ 5단계: 골든 데이터셋 패키징 및 계보 관리 (Data Lineage / Versioning) ]
```

| 프로세스 단계 | 세부 작업 내용 | 품질 관리 도구 |
|---|---|---|
| **가이드라인 수립** | 라벨 클래스 정의, 제외 조건, 예외 처리 규칙 문서화 | 작업 표준 가이드 문서 |
| **자동 사전 라벨링** | 사전학습 모델(YOLO, SAM, LLM)을 이용해 초안 라벨 자동 생성 | Segment Anything (SAM) |
| **휴먼 검수 및 보정** | 인간 라벨러가 자동 생성된 초안의 오차를 클릭으로 보정 | Label Studio, CVAT |
| **통계적 일치도 검증** | 샘플의 10%를 교차 검수하여 코헨 카파 계수 $\ge 0.8$ 달성 확인 | Cohen's Kappa, Fleiss' Kappa |

## Ⅳ. 라벨링 작업 방식 비교

| 비교 항목 | 전통적 수작업 라벨링 | 크라우드소싱 라벨링 | 모델 보조 라벨링 (Pre-labeling) | 능동 학습 (Active Learning) |
|---|---|---|---|---|
| **작업 주체** | 사내 전문 전담 인력 | 불특정 다수 대중 작업자 | AI 사전 라벨링 + 인간 감수 | 모델 불확실성 데이터만 인간 선별 |
| **구축 비용** | 매우 높음 (인건비 비례) | 중간 (건당 단가 지급) | 낮음 (작업 시간 70% 단축) | 최저 (필수 데이터만 라벨링) |
| **작업 속도** | 느림 | 빠름 (대규모 인원 동원) | 매우 빠름 | 빠름 |
| **품질 일관성** | 최상 (지침 숙련도 높음) | 낮음 (어뷰징 및 오염 위험) | 높음 (AI 초안 기반 일관성) | 높음 (고가치 데이터 집중) |
| **적합한 과업** | 의료, 법률, 반도체 등 전문 영역 | 대규모 단순 이미지 분류 | 객체 탐지, 세그멘테이션 | 대용량 미라벨 데이터 풀 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 라벨러 개인의 주관과 피로도에 따른 오라벨링 및 작업자 간 불일치로 인한 모델 훈련 오염 발생 | 전체 데이터의 10%를 무작위 교차 라벨링하여 코헨 카파($\kappa < 0.7$) 미달 시 가이드라인 개정 및 작업자 재교육 의무화 |
| 대규모 데이터셋(수백만 건) 라벨링 시 발생하는 막대한 외주 비용과 프로젝트 납기 지연 병목 | SAM(Segment Anything) 및 VLM 기반 오토 라벨링을 선행 도입하고 모델의 예측 신뢰도가 낮은 상위 10% 데이터만 인간에게 전달 |
| 원천 데이터 및 작업 지침 변경 시 어떤 라벨이 어떤 버전의 지침으로 작성되었는지 추적 불가한 계보 단절 | DVC(Data Version Control) 및 MLflow를 도입하여 원천 데이터 해시값, 가이드라인 버전, 라벨러 ID를 1:1 결합 관리 |

## Ⅵ. 제언

데이터 라벨링 비용을 80% 이상 절감하고 최상위 데이터 품질을 확보하기 위해 SAM 기반 오토 라벨링과 능동 학습(Active Learning) 루프를 통합한 지능형 데이터 팩토리 구축 권고.

```text
[ 대규모 원천 미라벨 데이터 풀 (Unlabeled Pool) ]
                       │
                       ▼
┌────────────────────────────────────────────────────────┐
│ 능동 학습 선별 엔진 (Active Learning Engine)          │
│  - 엔트로피 기반 불확실성 샘플링 (Uncertainty Sampling) │
│  - 고난도/모호한 상위 15% 핵심 데이터만 선별 추출      │
└──────────────────────┬─────────────────────────────────┘
                       │ 선별된 데이터
                       ▼
┌────────────────────────────────────────────────────────┐
│ SAM / VLM 기반 초고속 자동 사전 라벨링 (Pre-Annotation)│
│  - 픽셀 세그멘테이션 및 바운딩 박스 1초 만에 자동 생성 │
└──────────────────────┬─────────────────────────────────┘
                       │ AI 초안 라벨
                       ▼
┌────────────────────────────────────────────────────────┐
│ 전문 검수자 HITL 최종 감수 및 승인 (Human-in-the-Loop) │
│  - 코헨 카파(κ ≥ 0.85) 통과 데이터만 골든셋 편입     │
└────────────────────────────────────────────────────────┘
```

| 구분 | 100% 수작업 크라우드소싱 | 제언: Active Learning + SAM 융합 팩토리 |
|---|---|---|
| **구축 비용** | 건당 100% 인건비 발생 | 필수 데이터 15%만 라벨링하여 비용 80% 절감 |
| **구축 속도** | 수개월 소요 | 자동 사전 라벨링으로 납기 4배 단축 |
| **데이터셋 품질** | 검증 없는 다수결 의존 | 능동 학습으로 모델 취약점 집중 학습 |
| **거버넌스** | 단순 엑셀 파일 관리 | 데이터 버전 관리(DVC)로 100% 추적 가능 |
