## 30초 인출
- **본질:** 데이터 라벨링은 원천 데이터에 학습·평가 목적에 맞는 표지를 붙이는 데이터 구축 작업.
- **메커니즘:** 라벨 기준을 정하고, 작업자가 표지를 부여한 뒤 검수·조정해 데이터셋으로 관리.
- **품질:** 기준의 명확성, 표본 검토, 작업자 간 일치도, 데이터 출처·버전 관리가 핵심.

<details><summary>핵심 용어</summary>

- **데이터 라벨링(Data Labeling):** 데이터에 분류·위치·속성 등 목적에 맞는 표지를 연결하는 작업.
- **어노테이션(Annotation):** 원천 데이터에 의미 있는 표지·주석을 연결하는 과정이나 그 결과.
- **지도학습(Supervised Learning):** 입력 사례와 목표 라벨의 짝을 사용해 예측 모델을 학습하는 방식.
- **바운딩 박스(Bounding Box):** 영상 속 객체 위치를 둘러싼 사각형 표지.
- **세그멘테이션(Segmentation):** 영상의 픽셀이나 영역에 객체·장면 범주를 지정하는 라벨링 방식.
- **작업자 간 일치도(Inter-Annotator Agreement, IAA):** 복수 작업자가 같은 기준으로 독립 라벨링했을 때의 일치 정도.
- **코헨 카파(Cohen's Kappa, κ):** 두 평가자의 범주형 판단에서 우연 일치를 보정해 일치도를 나타내는 계수.
- **능동 학습(Active Learning):** 모델이 추가 라벨을 요청할 사례를 선택해 학습 데이터를 확장하는 접근.
- **모델 보조 라벨링(Model-Assisted Labeling):** 모델의 예측을 초안으로 삼고 사람이 검토·수정하는 라벨링 방식.

</details>

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 라벨링**은 원천 데이터에 학습·평가 목적에 맞는 표지를 연결하는 데이터 구축 작업 |
| 목적 | 데이터에서 모델이 학습하거나 평가할 목표 정보의 제공 |

## Ⅱ. 라벨 유형
라벨은 학습·평가에서 필요한 정답의 단위에 따라 설계하며, 데이터 형식과 과업이 달라지면 표기 방법도 달라짐.

| 데이터·과업 | 라벨 단위 | 예 |
|---|---|---|
| 이미지 분류 | 이미지·영상 전체 | 질병 유무, 장면 종류 |
| 객체 탐지 | 객체별 위치·범주 | **바운딩 박스**와 객체명 |
| 영상 분할 | 픽셀 또는 영역 | 객체 마스크, 장면 영역(**세그멘테이션**) |
| 텍스트 분석 | 문서·문장·토큰·관계 | 주제 범주, 개체명, 개체 간 관계 |
| 음성 인식 | 구간·발화 | 전사문, 화자·시간 정보 |

## Ⅲ. 구축 절차와 검수
```text
원천 데이터
     |
     v
라벨 기준·작업 지침
     |
     v
작업자의 표지 부여
     |
     v
검수·불일치 조정
     |
     v
목적·출처가 기록된 데이터셋
```

지침에는 라벨 범위, 경계 사례, 제외 조건, 기록 형식을 예시와 함께 명시. 초기 표본 검수에서 반복 불일치를 찾으면 라벨러 개인의 오류로만 처리하지 않고 기준의 모호성도 점검.

| 검토 지점 | 다음 조치 |
|---|---|
| 라벨 정의·예시의 해석이 갈림 | 지침 보완 후 해당 표본 재검수 |
| 작업 지침은 명확하나 개별 표지가 잘못됨 | 작업자 피드백과 표본 재검수 |
| 원천 사례 자체가 모호하거나 대표성이 낮음 | 제외·보류 기준과 데이터 구성 재검토 |

## Ⅳ. 품질 관리와 자동화
| 관리 방법 | 역할 | 적용 시 주의 |
|---|---|---|
| 표본 검수 | 라벨 오류와 기준 누락 확인 | 표본 선정 근거·검수 범위 기록 |
| **작업자 간 일치도** | 독립 작업 간 기준 적용의 일관성 확인 | 과업·척도에 맞는 지표 선택 |
| **코헨 카파** | 두 평가자의 범주형 판단에서 우연 일치 보정 | 수치만으로 라벨의 진실성·정확성을 보장하지 않음 |
| **모델 보조 라벨링** | 예측을 초안으로 제공해 반복 작업 지원 | 예측 오류의 편향 전파 여부를 사람 검수로 확인 |
| **능동 학습** | 추가 라벨링이 유용할 사례를 선택 | 선택 편향과 대표성 변화를 함께 점검 |

모델 보조·능동 학습은 라벨링 업무의 우선순위를 바꾸는 방법이며, 정확도나 비용 절감률을 보장하는 수단은 아님. 구축 규모·모델 성능·검수 방식에 따라 효과가 다름.

## Ⅴ. 데이터 거버넌스
| 관리 항목 | 기록·통제 내용 |
|---|---|
| 출처·권리 | 수집 경로, 이용 권한, 재사용 조건 |
| 라벨 계보 | 작업 지침 버전, 작업·검수 이력, 조정 근거 |
| 개인정보 | 목적에 필요한 최소 범위, 접근 권한, 보관·삭제 기준 |
| 데이터셋 변경 | 원천·라벨 변경 내역, 학습·평가 버전 간 연결 |

```text
원천·이용 권한
       |
       v
작업 지침·라벨 버전
       |
       v
검수·조정 이력
       |
       v
학습·평가 데이터셋 버전
```

라벨은 데이터에 부여한 작업 기준상의 표지이며, 실제 현상을 완벽히 반영하는 정답으로 자동 간주할 수 없음. 기준의 타당성과 데이터의 대표성도 별도로 확인.

## Ⅵ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 라벨의 불일치가 기준 모호성, 작업 오류, 원천 데이터 편향 중 어디에서 비롯됐는지 사후에 구분하기 어려움 | 지침·원천·라벨·검수 버전을 연결해 기록하고, 표본 재검토로 원인을 구분한 뒤 해당 기준·작업·데이터의 수정 이력 관리 |
