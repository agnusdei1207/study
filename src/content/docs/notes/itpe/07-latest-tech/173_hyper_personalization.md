## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 초개인화(Hyper-Personalization)

## 30초 인출

- **본질:** 이용자의 동의된 행동·선호·상황 데이터를 활용해 시점별 콘텐츠나 제안을 조정하는 방식. 개인과 상황에 맞는 콘텐츠를 제공하고 효과와 불편을 함께 평가.
- **메커니즘:** 적법한 이벤트 수집 → 후보 생성·랭킹 → 노출 → 반응·불편 지표 평가.

<details><summary>핵심 용어</summary>

- **초개인화:** 개인·상황 신호에 맞춰 콘텐츠나 제안을 조정하는 방식
- **랭킹:** 후보 중 표시할 항목과 순서를 정하는 처리

</details>

---

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 이용자의 동의된 행동·선호·상황 데이터를 활용해 시점별 콘텐츠나 제안을 조정하는 방식. |
| 목적 | 개인과 상황에 맞는 콘텐츠를 제공하고 효과와 불편을 함께 평가 |

### Ⅱ. 핵심 구조와 적용

```text
적법한 이벤트 수집 → 후보 생성·랭킹 → 노출 → 반응·불편 지표 평가
```

1. **설계:** 구매·검색·재고·상황 정보를 목적별로 분리하고 적법한 수집·이용 범위와 보존 기간 정의.
2. **처리:** 이벤트 수집 → 고객·상품 표현 → 후보 생성·랭킹 → 다양성·품질 제한 → A/B 시험과 피드백.
3. **위험:** 과도한 추적의 불쾌감, 인기 품목 쏠림, 민감 특성 추론, 신규 고객·상품의 데이터 부족.
4. **통제:** 최소 수집·옵트아웃, 추천 이유와 조정권, 다양한 노출, 전환율과 불만·차별·장기 만족도의 균형 평가.

### Ⅲ. 유사 개념과 구분

- 전통적 개인화 vs 초개인화: 전통적 개인화는 "지난달에 청바지를 샀으니 티셔츠를 추천한다"는 과거 이력 기반 / 초개인화는 "현재 비가 오고 외출 준비 중이니 레인부츠와 방수 재킷을 추천한다"는 실시간 맥락 기반

### Ⅳ. 문제·원인·대책

- 적용 상황: 대형 이커머스 쇼핑몰의 실시간 초개인화 추천 시스템 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 이미 구매한 상품이 반복 노출 | 갱신되지 않은 구매·노출 상태 | 구매 완료 상태 반영과 추천 빈도 제한 | 중복 노출·이탈·클릭 지표 비교 |
| 실시간 추천 응답이 느림 | 데이터 결합·후보 검색·모델 추론의 병목 | 캐시·후보 검색·모델 단계별 지연 측정 후 개선 | 응답시간 분포와 추천 품질을 함께 확인 |
| 추천의 근거가 불분명해 감시 우려 | 수집·활용 범위의 불투명성 | 데이터 출처·추천 사유 설명과 이용자 제어 제공 | 설명 이해도·거부·신고 지표 확인 |

### Ⅴ. 제언

- 위치·행동 데이터는 목적에 필요한 범위만 수집하고 보존 기간·거부 수단을 명시. 온디바이스 처리는 한 선택지이며 실제 데이터 흐름을 점검해 중앙 서버 전송 여부를 확인
