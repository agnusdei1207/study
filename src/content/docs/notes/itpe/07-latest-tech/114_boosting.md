## 30초 인출

- 본질: **부스팅 (Boosting)** 은 여러 개의 약학습기(Weak Learner)를 순차적으로 연결하여, 이전 학습기가 잘못 예측한 잔차(Residual)나 오분류 데이터에 가중치를 집중 부여함으로써 모델의 편향(Bias)을 체계적으로 감소시키는 직렬 앙상블 기법
- 메커니즘: 현재 앙상블 모델 $F_{m-1}(x)$의 손실 함수(Loss Function)에 대한 음의 그래디언트(Pseudo-Residual)를 계산하고, 새로운 약학습기 $h_m(x)$를 이에 적합(Fitting)시킨 뒤 수축률(Shrinkage) $\eta$를 곱하여 누적 가산 갱신
- 통찰: 순차적 오차 보정 특성상 훈련 데이터 내의 극단적 이상치나 라벨 노이즈에 과적합(Overfitting)되기 쉬우므로 조기 종료(Early Stopping)와 $L_1/L_2$ 정규화 및 서브샘플링 결합 통제 필수

<details><summary>핵심 용어</summary>

- **부스팅 (Boosting)** : 약한 분류기들을 순차적으로 학습시켜 이전 단계의 오차를 지속적으로 보정해 나가는 강분류기 생성 앙상블.
- **의사 잔차 (Pseudo-Residual)** : 임의의 미분 가능한 손실 함수에서 현재 앙상블 예측값에 대한 음의 그래디언트($-\frac{\partial L}{\partial F}$).
- **수축률 (Shrinkage / Learning Rate, $\eta$)** : 각 단계에서 추가되는 개별 트리의 기여도를 축소하여 과적합을 방지하는 정규화 계수.
- **XGBoost (Extreme Gradient Boosting)** : 손실 함수의 2차 테일러 전개(헤시안 $H$)와 트리 복잡도 정규화 페널티를 목적함수에 내장한 고속 부스팅.
- **LightGBM** : GOSS(단면 기울기 기반 샘플링)와 EFB(배타적 특성 묶음) 및 리프 중심(Leaf-wise) 분할로 대규모 데이터를 초고속 처리하는 알고리즘.

</details>

## 2~4교시 25점 답안

## Ⅰ. 부스팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **부스팅 (Boosting)** 은 오답에 가중치를 부여하거나 손실 함수의 음의 그래디언트(잔차)를 순차적으로 학습하는 약학습기들을 가중 선형 결합하여 강력한 예측 모델을 완성하는 직렬 앙상블 기법 |
| 목적 | 단일 약학습기의 높은 편향(Bias)과 과소적합(Underfitting) 문제를 단계적 잔차 보정으로 극복하여 예측 정확도 극대화 |

## Ⅱ. 부스팅의 핵심 알고리즘 원리 및 수학적 특징

| 수학적 원리 및 수식 | 수식 표현 | 공학적 의미 및 특징 |
|---|---|---|
| **가법 모델 (Additive Model)** | $F_M(x) = \sum_{m=1}^M \eta \cdot h_m(x)$ | 이전 단계의 트리를 고정한 채 새로운 트리 $h_m(x)$를 덧셈 형태로 점진적 누적 |
| **의사 잔차 (Pseudo-Residual)** | $r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$ | 함수 공간에서의 경사하강법(Gradient Descent in Function Space) 구현 |
| **손실 함수 2차 근사 (XGBoost)** | $\tilde{\mathcal{L}}^{(m)} \approx \sum_i [g_i f_m(x_i) + \frac{1}{2} h_i f_m^2(x_i)] + \Omega(f_m)$ | 1차 그래디언트($g_i$)와 2차 헤시안($h_i$)을 동시 활용하여 정확하고 빠른 최적 분할점 탐색 |
| **정규화 목적함수 ($\Omega(f)$)** | $\Omega(f) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$ | 리프 노드 개수($T$)와 리프 가중치($w$)의 $L_2$ 노름을 직접 규제하여 과적합 원천 차단 |

## Ⅲ. 그래디언트 부스팅(GBM)의 잔차 적합 및 손실 최적화 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             그래디언트 부스팅 (GBM) 순차 학습 파이프라인                │
└────────────────────────────────────────────────────────────────────────┘
 [ 훈련 데이터 (X, y) ] ──> [ 0단계: 기본 초기값 F_0(x) 설정 (상수값: 평균/로그오즈) ]
                                   │
 ┌─────────────────────────────────┴────────────────────────────────────┐
 │ 순차적 부스팅 반복 루프 (m = 1 to M)                                 │
 │                                                                      │
 │  [ 1단계: 음의 그래디언트(의사 잔차) 계산 ]                          │
 │   r_im = - [ ∂L(y_i, F(x_i)) / ∂F(x_i) ] (현재 모델 F_{m-1} 기준)   │
 │                                                                      │
 │  [ 2단계: 약학습기(회귀 트리) 적합 ]                                 │
 │   데이터 (x_i, r_im)에 대해 새 트리 h_m(x)를 학습 (잔차 패턴 학습)   │
 │                                                                      │
 │  [ 3단계: 최적 승수 및 수축률(η) 적용 ]                             │
 │   F_m(x) = F_{m-1}(x) + η * h_m(x) (0 < η ≤ 0.1)                     │
 │                                                                      │
 │  [ 4단계: 검증셋 손실(Validation Loss) 평가 ] ──> 조기 종료 조건 검사│
 └─────────────────────────────────┬────────────────────────────────────┘
                                   │
                                   ▼
 [ 최종 완성된 강분류기 앙상블 모델: F_M(x) ]
```

| 프로세스 단계 | 상세 작업 내용 | 제어 하이퍼파라미터 |
|---|---|---|
| **초기 예측자 설정** | 손실 함수를 최소화하는 단일 상수값 $F_0(x) = \arg\min_c \sum L(y_i, c)$ 도출 | Initial Prediction |
| **의사 잔차 산출** | MSE 손실 시 $y_i - F(x_i)$, 로지스틱 손실 시 $y_i - p_i$ 잔차 벡터 생성 | Objective Function |
| **트리 분할 및 성장** | 잔차를 목적변수로 삼아 리프 분할 최적화 수행 | Max Depth, Min Child Weight |
| **수축률 갱신** | 학습률 $\eta$를 곱해 천천히 수렴시켜 과적합을 억제하며 누적 합산 | Learning Rate ($\eta$) |

## Ⅳ. 부스팅 알고리즘 진화 비교

| 비교 항목 | AdaBoost | GBM (Gradient Boosting) | XGBoost | LightGBM | CatBoost |
|---|---|---|---|---|---|
| **오차 보정 방식** | 데이터 가중치 재분배 | 손실의 1차 음의 그래디언트 | 1차+2차 헤시안 테일러 근사 | 히스토그램 기반 GOSS 분할 | 순서형 부스팅 (Ordered) |
| **트리 분할 방식** | Level-wise (균형 분할) | Level-wise (균형 분할) | Level-wise (깊이 우선) | Leaf-wise (리프 중심 비대칭) | Symmetric Tree (대칭 분할) |
| **연산 속도** | 느림 | 매우 느림 (CPU 순회) | 빠름 (병렬 프리소팅) | 극도로 빠름 (히스토그램 기반) | 빠름 (GPU 최적화) |
| **범주형 변수 처리** | 원-핫 인코딩 필수 | 원-핫 인코딩 필수 | 수치형 변환 필요 | 범주형 정렬 자체 분할 | 타깃 인코딩 자동 최적화 |
| **과적합 규제** | 없음 | 조기 종료, 학습률 | $\gamma, \lambda, \alpha$ 정규화 내장 | $\min\_data\_in\_leaf$ 규제 | 타깃 누수 방지 내장 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 잘못 라벨링된 노이즈나 극단적 이상치(Outlier)에 대해 후속 트리가 막대한 가중치를 부여하여 과적합 발생 | 후버 손실(Huber Loss) 또는 절대오차(MAE) 등 강건한(Robust) 손실 함수를 채택하고 샘플링 비율(Subsample)을 0.8 수준으로 규제 |
| 트리 개수($M$)가 증가함에 따라 직렬 연산으로 인한 훈련 시간 급증 및 서비스 추론 레이턴시 증가 | 히스토그램 기반 binning을 사용하는 LightGBM으로 전환하고 검증 손실 개선 정체 시 즉시 훈련을 멈추는 Early Stopping(patience=50) 강제 |
| Leaf-wise 분할을 사용하는 최신 부스팅 알고리즘에서 소규모 데이터셋 훈련 시 깊은 비대칭 분기로 과적합 | 최대 리프 개수(`num_leaves`)를 깊이 기준 $2^{\text{depth}}$보다 엄격히 작게 제한하고 최소 리프 데이터 수(`min_child_samples`) 상향 |

## Ⅵ. 제언

정형 데이터 머신러닝 파이프라인에서 최고 수준의 정확도와 실시간 서빙 성능을 달성하기 위해 GPU 가속 LightGBM과 Optuna 하이퍼파라미터 최적화(AutoML) 연계 아키텍처 구축 권고.

```text
[ 정형 비즈니스 데이터 스트림 (수백만 행) ]
                     │
                     ▼
┌────────────────────────────────────────────────────────┐
│ 자동 피처 엔지니어링 & 타깃 인코딩                     │
└────────────────────┬───────────────────────────────────┘
                     │
                     ▼
┌────────────────────────────────────────────────────────┐
│ Optuna 기반 베이지안 최적화 하이퍼파라미터 탐색기      │
│  - 파라미터 공간: lr(0.01~0.1), num_leaves, subsample │
│  - 평가 척도: 5-Fold Stratified K-Fold 검증셋 AUPRC    │
│  - 조기 종료(Early Stopping: 50 라운드) 결합           │
└────────────────────┬───────────────────────────────────┘
                     │ 최적 파라미터 확정
                     ▼
┌────────────────────────────────────────────────────────┐
│ GPU 가속 LightGBM 최종 모델 학습 및 C++ 컴파일         │
│  - Treelite 엔진으로 컴파일 ──> 추론 지연 1ms 미만 달성│
└────────────────────────────────────────────────────────┘
```

| 구분 | 기본 Scikit-Learn GBM | 제언: GPU 가속 LightGBM + Optuna AutoML |
|---|---|---|
| **학습 소요 시간** | 1시간 이상 소요 (단일 코어 병목) | 1~2분 내 수백만 행 초고속 분산 학습 |
| **과적합 통제** | 고정 반복 수로 과적합 빈번 | Early Stopping 및 K-Fold 교차 검증 자동화 |
| **추론 속도** | Python 객체 오버헤드로 수십 ms | C++ 컴파일 서빙으로 0.1ms 달성 |
| **피처 처리** | 수동 원-핫 인코딩으로 차원 폭증 | 고유 범주형 분할 알고리즘으로 메모리 절감 |
