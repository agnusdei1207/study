## 연관 키워드

- 부스팅(Boosting), 그래디언트 부스팅(GBM, Gradient Boosting Machine), 의사 잔차(Pseudo-Residual), 수축률(Shrinkage)
- 조기 종료(Early Stopping), 손실 함수(Loss Function), 과적합(Overfitting), 편향(Bias)
- AdaBoost, XGBoost, LightGBM, CatBoost, 배깅(Bagging)

## Ⅰ. 부스팅(Boosting)의 개요

- 핵심 요약 : 앞 모델이 틀린 부분을 다음 모델이 보정하도록 약한 학습기를 순차로 더해 강한 모델을 만드는 직렬 앙상블 기법.
- 개념 : **부스팅** (Boosting)은 오답에 가중치를 주거나 손실 함수의 **음의 그래디언트** (잔차에 해당하는 방향)를 순차적으로 학습하는 약한 학습기들을 더해 강력한 예측 모델을 완성하는 직렬 앙상블 기법이다.
- 배경 및 필요성 : 순차 보정은 잡음이나 극단적 이상치에도 집중하므로 과적합이 쉽게 생기고, 따라서 조기 종료와 정규화, 표본 샘플링을 함께 통제해야 한다.
- 주요 목적 : 단일 약한 학습기의 높은 편향과 과소적합을 단계별 보정으로 줄여 예측 정확도를 높이는 것.

## Ⅱ. 부스팅(Boosting)의 특징 및 장점

- 핵심 요약 : 순차 보정과 가법 모델 구조가 편향 감소와 높은 예측 정확도로 이어지는 방식.

1. 순차 보정 : 이전 단계의 오차를 다음 학습기가 학습 → 체계적인 편향 감소와 정확도 향상.
2. 가법 모델 : 새 학습기를 기존 모델에 더하는 방식 → 단계별 기여도를 수축률로 조절하여 안정적 학습.
3. 손실 함수 유연성 : 목적에 맞는 손실 함수를 바꿔 쓸 수 있음 → 회귀, 분류, 순위 문제에 공통 적용.

## Ⅲ. 부스팅(Boosting)의 구조 (흐름)

- 핵심 요약 : 의사 잔차 계산, 약한 학습기 적합, 수축률 적용, 검증 손실 확인을 반복하는 순환 구조.
- **의사 잔차** (Pseudo-Residual) : 현재 모델에서 손실 함수의 음의 그래디언트를 계산한 값으로, 함수 공간에서의 경사 하강을 구현한다.
- **수축률** (Shrinkage) : 새 학습기의 기여분에 곱하는 작은 학습률로, 한 단계가 모델을 과하게 바꾸지 않도록 한다.
- **가법 모델** (Additive Model) : 최종 모델이 $F_M(x) = \sum_{m=1}^{M} \eta \cdot h_m(x)$처럼 학습기의 합으로 표현되는 구조.

```text
[ 초기값 F0 (평균 또는 로그 오즈) ]
        ↓
[1단계 의사 잔차 계산]
        ↓
[2단계 약한 학습기 적합]
        ↓
[3단계 수축률 η 적용 후 누적]
        ↓
[4단계 검증 손실 확인]
        ↓ (개선 정체 시)
[조기 종료]
```

```text
[ 손실 2차 근사 (XGBoost 계열) ]
1차 그래디언트 g_i
        +
2차 헤시안 h_i
        ↓
최적 분할점 탐색
```

## Ⅳ. 대표 부스팅 알고리즘의 비교

- 핵심 요약 : 알고리즘마다 오차 보정 방식과 트리 분할 방식이 달라, 데이터 규모와 범주형 변수 처리 방식이 선택 기준이 된다.

| 비교 축 | AdaBoost | GBM | XGBoost | LightGBM | CatBoost |
| --- | --- | --- | --- | --- | --- |
| 오차 보정 | 샘플 가중치 재분배 | 1차 음의 그래디언트 | 1차와 2차 정보 근사 | 히스토그램 기반 분할 | 순서형 부스팅 |
| 트리 분할 | 균형 분할 | 균형 분할 | 균형 분할 | 리프 중심 분할 | 대칭 트리 |
| 연산 특징 | 상대적으로 느림 | 상대적으로 느림 | 병렬 처리에 유리 | 대용량에 빠른 편 | GPU 활용에 유리 |
| 범주형 변수 | 원-핫 인코딩 필요 | 원-핫 인코딩 필요 | 수치 변환 필요 | 범주 자체를 분할 | 타깃 인코딩 자동 처리 |

- 선택 기준 : 대용량 수치 데이터는 LightGBM이나 XGBoost, 범주형 변수가 많으면 CatBoost를 우선 검토한다.

## Ⅴ. 부스팅(Boosting)의 한계와 방안

- 핵심 요약 : 이상치 과가중, 직렬 연산 지연, 소규모 데이터의 과적합을 강건한 손실, 조기 종료, 리프 제한으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 이상치와 라벨 노이즈 과가중 | 후속 트리가 잘못된 샘플에 큰 가중치를 두어 과적합 | 후버 손실(Huber Loss)이나 절대오차 같은 강건한 손실 함수 채택, 표본 샘플링 적용 | 검증 손실, 이상치 비율 |
| 트리 수 증가에 따른 지연 | 직렬 학습으로 훈련 시간이 늘고 추론 지연 증가 | 히스토그램 기반 알고리즘 전환과 검증 손실 정체 시 **조기 종료** (Early Stopping) 적용 | 훈련 시간, 추론 지연 |
| 리프 중심 분할의 과적합 | 소규모 데이터에서 깊은 비대칭 분기가 생겨 과적합 | 리프 개수와 리프당 최소 샘플 수를 엄격히 제한 | 검증 정확도 격차 |

## Ⅵ. 부스팅(Boosting)에 대한 기술사적 제언

- 핵심 요약 : 학습 자동화와 과적합 통제 체계를 기본으로 두고, 추론 효율까지 설계에 포함하는 것이 바람직하다.

1. 데이터 분석 조직은 교차 검증과 조기 종료를 학습 파이프라인의 기본 절차로 고정하여, 반복 횟수를 사람이 임의로 정하지 않도록 해야 한다.
2. 모델 운영 조직은 학습 완료 모델을 추론 전용 형식으로 배포하여, 서비스 지연 목표를 맞추도록 해야 한다.
3. 품질 조직은 학습 데이터의 라벨 오류를 주기적으로 점검하고, 이상치 처리 기준을 문서화하여 재현 가능한 학습 환경을 유지해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 부스팅은 잔차를 순차적으로 보정해 편향을 줄이는 직렬 앙상블 기법이다.
- 시사점 : 정확도는 높지만 과적합과 이상치에 취약하므로, 손실 함수와 조기 종료 같은 통제 장치가 부스팅 성능의 전제가 된다.
