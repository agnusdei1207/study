## 답안 골격
```text
[부스팅] ◀━━ 머리: Ⅶ 내 의견 (순차적 잔차 학습과 그래디언트 최적화로 편향을 극소화하여 정형 데이터 예측 성능을 극대화하는 강력한 앙상블 기법)
 ┃
 ┣━ Ⅰ 개요 ───── 단순 약한 학습기(Weak Learner)의 높은 편향(Bias) 한계 → 이전 모델의 오차를 후속 모델이 순차적으로 보정하는 부스팅 태동
 ┣━ Ⅱ 특징 ───── 순차적(Sequential) 학습 · 오차 가중치 부여/잔차(Residual) 적합 · 편향(Bias) 획기적 감소 · 정형 데이터 최고의 예측력
 ┣━ Ⅲ 구조 ───── 초기 약분류기($h_1$) + 손실 함수의 음의 그래디언트/잔차($r_m$) + 후속 보정 분류기군($h_m$) + 수렴 가중치 합산($F(x)$)
 ┣━ Ⅳ 흐름 ───── ① 초기 기저 모델 학습 → ② 오분류 샘플 식별(가중치 상향 또는 손실 그래디언트 계산) → ③ 잔차에 맞춘 다음 트리 적합 → ④ 학습률($\eta$) 곱하여 모델 누적 합산 → ⑤ 강력한 앙상블 완성
 ┣━ Ⅴ 비교 ───── AdaBoost vs GBM vs XGBoost vs LightGBM (샘플 가중치 조정 vs 손실 경사 하강 vs 2차 테일러 전개+규제화 vs 히스토그램+리프 중심 성장)
 ┗━ Ⅵ 실무 ───── 노이즈 및 이상치에 대한 극심한 과적합 취약성 / 순차 실행에 따른 학습 지연 / 방대한 하이퍼파라미터 튜닝 비용
```

## 한 줄 본질
- 동전 던지기보다 조금 나은 얕은 결정트리(약분류기)를 여러 개 준비하고, 앞선 트리가 틀린 문제만 집중적으로 오답 노트를 만들어 다음 트리에게 풀게 하는 방식으로 약점을 순차 보완 → 최고 수준의 예측 정확도 달성 / 이상치(Outlier)에 민감하게 반응하여 과적합 위험

## 핵심 그림
```text
[부스팅(Boosting)의 순차적 오차 보정 및 누적 앙상블 흐름]

  [훈련 데이터셋] ──> [1단계: 약분류기 h_1] ──> 오답 샘플 가중치 상향 / 잔차 계산
                                                    │
     ┌──────────────────────────────────────────────┘
     ▼
  [2단계: 약분류기 h_2] ──> h_1이 틀린 오답에 집중 학습 ──> 새로운 잔차 계산
                                                              │
     ┌────────────────────────────────────────────────────────┘
     ▼
  [3단계: 약분류기 h_3] ──> h_2까지 해결 못한 잔차에 집중 학습
     │
     └──────────────────────────────┬──────────────────────────────┐
                                    ▼
       최종 앙상블 모델 F(x) = h_1(x) + η·h_2(x) + η·h_3(x) + ...
       (학습률 η를 곱한 가중 합산으로 단일 강분류기(Strong Learner) 구축)
```

## 핵심 용어
- 약한 학습기(Weak Learner): 무작위 추측보다 약간 더 나은 성능(정확도 50%를 살짝 넘는)을 보이는 매우 단순한 모델(깊이 1~3의 얕은 결정트리 스텀프 등)
- 음의 그래디언트(Pseudo-Residuals): 그래디언트 부스팅(GBM)에서 임의의 미분 가능한 손실 함수에 대해 현재 예측치와 실제값의 오차를 나타내는 1차 편미분 벡터($-\frac{\partial L}{\partial F(x)}$)
- 리프 중심 성장(Leaf-wise Tree Growth): LightGBM이 사용하는 트리 분할 방식으로, 레벨 중심(Level-wise)과 달리 손실 감소량이 가장 큰 단일 리프 노드만을 비대칭적으로 쪼개어 연산량을 극적으로 절감하는 기법

## 핵심 통찰
- "배깅은 분산을 잡고, 부스팅은 편향을 잡는다": 배깅은 완벽히 자란 복잡한 트리의 과적합을 평균으로 누그러뜨리고, 부스팅은 바보 같은 단순한 트리들을 단계적으로 쌓아 올려 똑똑하게 만듦
- 최적화 관점에서 부스팅은 '함수 공간에서의 경사하강법': 파라미터를 갱신하는 일반 경사하강법과 달리, 부스팅은 손실 함수의 그래디언트 방향으로 새로운 '함수(트리)' 자체를 더해 나가는 최적화 과정임
- 이상치(Outlier)의 치명타: 앞선 트리가 틀린 오답에 점점 더 높은 가중치를 주다 보면, 데이터에 포함된 극단적인 노이즈나 잘못 라벨링된 이상치에 집착하게 되어 모델 전체가 망가지는 현상이 발생함

## 이웃 토픽과 구분
- 배깅 vs 부스팅: 배깅은 트리를 독립적으로 병렬 학습하여 과적합 방지 / 부스팅은 트리를 순차적으로 종속 학습하여 잔차를 지속 축소

## 문제·원인·대책
- 적용 상황: 금융 신용 대출 연체 확률 예측을 위한 그래디언트 부스팅 모델 운영
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 반복 횟수(n_estimators)가 증가할수록 테스트 손실이 치솟으며 극심한 과적합 발생 | 노이즈 데이터까지 과도하게 잔차 적합을 수행함 | 학습률(Learning Rate)을 0.01로 축소하고 조기 종료(Early Stopping 10회) 적용 | 과적합 억제 및 일반화 ROC-AUC 0.92 달성 |
| 수천만 건 대규모 금융 거래 데이터에서 GBM 학습 시 수 시간의 연산 병목 발생 | 정렬 기반 연속형 특성 분할 지점 전수 탐색 오버헤드 | 연속형 변수를 버킷으로 양자화하는 히스토그램 기반 LightGBM 전환 | 학습 속도 15배 가속 및 메모리 80% 절감 |
| 라벨이 잘못 기재된 극단적 이상치 샘플에 모델이 비정상적으로 가중치를 쏟아부음 | 제곱 오차 손실(MSE)의 이상치 편향 증폭 | 절대 오차(MAE) 또는 후버 손실(Huber Loss)과 같은 강건한 손실 함수로 교체 | 이상치 노이즈에 대한 모델 강건성 확보 |
