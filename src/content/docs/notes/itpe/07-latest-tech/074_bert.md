```text

                   ^           ^             ^            ^           ^
+-------------------------------------------------------------------------+
| 다층 양방향 트랜스포머 인코더 블록 (Multi-Layer Bidirectional Transformer)|
| (모든 단어가 앞뒤 모든 단어와 완전한 Self-Attention 상호작용 수행)    |
+-------------------------------------------------------------------------+
                   ^           ^             ^            ^           ^
[입력층]           |           |             |            |           |
+-------------------------------------------------------------------------+
| Token 임베딩  : [CLS]       [ my ]        [MASK]       [ is ]      [SEP] |
|       +                                                                 |
```

## 핵심 용어
- 마스크 언어 모델(Masked LM, MLM): 입력 문장 내 토큰의 15%를 무작위 선정하여 80%는 [MASK]로 치환, 10%는 엉뚱한 임의 단어로 치환, 10%는 그대로 유지한 뒤 주변 양방향 문맥만으로 원래 단어를 맞추도록 훈련하는 자기지도학습 기법
- 다음 문장 예측(Next Sentence Prediction, NSP): 두 문장 A와 B를 [SEP] 토큰으로 이어 붙여 입력하고, B가 실제로 A 바로 뒤에 이어지는 문장인지(IsNext) 무관한 문장인지(NotNext)를 이진 분류하도록 학습하는 기법
- [CLS] 토큰: 시퀀스의 맨 앞에 삽입되는 특수 토큰으로, 트랜스포머 인코더 레이어를 거치며 문장 전체의 종합적 문맥 정보를 집약하여 문장 분류 태스크의 입력 벡터로 사용

## 핵심 통찰
- 좌에서 우로만 읽는 단방향 모델(GPT)은 문맥의 절반을 버리는 것과 같음: 문장의 의미는 앞선 단어뿐만 아니라 뒤에 오는 단어에 의해서도 결정되므로, 진정한 언어 "이해"에는 양방향 인코더가 수학적으로 필연적
- [MASK] 토큰의 80:10:10 치환 규칙은 천재적인 불일치 완화 장치: 미세조정(Fine-tuning) 단계에는 [MASK]라는 토큰이 절대 등장하지 않으므로, 모델이 [MASK] 기호 자체에 과적합되지 않고 모든 토큰의 문맥 표현을 견고하게 학습하도록 강제
- RoBERTa 연구에서 입증되었듯, NSP 작업은 학습 효과가 미미하여 제거하고, 동적 마스킹(Dynamic Masking)과 더 큰 배치 사이즈를 적용하는 것이 성능을 비약적으로 개선함

## 이웃 토픽과 구분
- BERT vs GPT: BERT는 트랜스포머 인코더 기반으로 양방향 문맥을 참조하여 텍스트 분석·분류(NLU)에 최적화 / GPT는 트랜스포머 디코더 기반으로 좌→우 순차 생성을 수행하여 텍스트 창작·대화(NLG)에 최적화

## 문제·원인·대책
- 적용 상황: 고객센터 장문 상담 내역(3,000자 이상) 분류 모델에 기본 BERT 적용 시 에러 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 입력 텍스트가 512 토큰을 초과하여 핵심 문의 사항이 잘려 나감 | BERT의 절대적 포지션 임베딩(Absolute Position) 및 $O(N^2)$ 어텐션 메모리 한계 | Longformer 또는 BigBird 같은 희소(Sparse) 어텐션 기반 긴 문맥 인코더로 교체 | 최대 4,096 토큰까지 문맥 손실 없이 분류 가능 |
| 한국어 특유의 교착어 특성으로 인해 단어 분절 오류 및 의미 왜곡 | 영문 기반 WordPiece 토크나이저를 한국어 텍스트에 단순 적용 | 한국어 형태소 분석기(Mecab) 결합 및 형태소 단위 분절(Morpheme-level) 사전학습 모델(KoBERT) 도입 | 한국어 문장 분류 정확도 15% 이상 향상 |
| 실시간 검색 서비스에 BERT 서빙 시 CPU 지연시간 과다로 SLA 미달 | 12~24개 깊은 인코더 레이어의 막대한 부동소수점 연산량 | DistilBERT(지식 증류) 적용 및 ONNX Runtime + FP16 양자화 파이프라인 구축 | 모델 크기 40% 감소, 추론 속도 60% 가속 |

## 내 의견
- [RAG 시스템의 고성능 바이인코더(Bi-Encoder) 및 리랭커 백본 활용] 초거대 생성 모델(LLM) 시대에도 텍스트 검색 및 임베딩 품질은 BERT 계열의 인코더 모델이 주도함 → 나라면: 수천억 파라미터 LLM을 검색에 직접 쓰지 않고, BGE(BAAI General Embedding) 등 현대적으로 개선된 BERT 인코더를 지식 베이스 검색과 Cross-Encoder 리랭킹 파이프라인에 배치하여, 1/100의 비용과 10배 빠른 속도로 고품질 문맥 검색 엔진 구축
