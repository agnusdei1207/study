## 연관 키워드

- 파운데이션 모델(Foundation Model), 자기지도학습(Self-supervised Learning), 사전 학습(Pre-training)
- 창발성(Emergence), 동질화(Homogenization), 인컨텍스트 러닝(In-context Learning)
- RAG(Retrieval-Augmented Generation), LoRA(Low-Rank Adaptation), PEFT, 환각(Hallucination)

## Ⅰ. 파운데이션 모델(Foundation Model)의 개요

- 핵심 요약 : 대규모 사전 학습으로 만든 범용 기반 모델을 여러 하류 작업에 재사용하는 AI 체계.
- 개념 : **파운데이션 모델** (Foundation Model, 대규모 사전 학습으로 만든 범용 기반 모델)은 방대한 원시 데이터를 **자기지도학습** (Self-supervised Learning, 데이터 자체에서 학습 신호를 만드는 방식)으로 학습해, 소량의 미세조정이나 프롬프트만으로 여러 작업에 적용되는 모델.
- 배경 및 필요성 : 작업마다 모델을 따로 만들면 데이터와 비용이 중복됨. 기반 모델을 공유하면 개발 비용은 줄지만, 한 모델의 결함이 여러 서비스로 함께 번지는 **동질화** (Homogenization, 여러 응용이 같은 기반 모델의 결함을 공유하는 현상) 위험이 생기므로 모델 다변화와 안전 장치가 함께 필요함.
- 주요 목적 : 작업별 모델 개발을 줄이고 모델 재사용성을 높여, 지능형 에이전트와 멀티모달 서비스의 공통 기반을 제공하는 것.

## Ⅱ. 파운데이션 모델(Foundation Model)의 특징 및 장점

- 핵심 요약 : 범용 사전 학습과 다양한 적응 방식이 결합되어, 작업별 개발 비용을 낮추고 새 기능을 빠르게 만드는 구조.

1. 범용 재사용 : 하나의 기반 모델을 여러 작업에 공유 → 작업별 데이터 수집과 학습 비용 절감.
2. **창발성** (Emergence, 규모가 커질 때 명시적으로 학습하지 않은 능력이 관찰되는 현상) : 파라미터와 데이터 규모가 커지면서 복합 추론 능력이 나타남 → 새로운 응용 서비스의 가능성 확대. 원인은 학계에서 논쟁 중이므로 효과를 보장된 성질로 보지 않음.
3. 적응 방식의 선택 폭 : 프롬프트 지시, 외부 문서 검색, 경량 미세조정 중에서 요구 수준에 맞게 고름 → 운영 비용과 정확도의 균형 조정.
4. 사전 학습 자산 공유 : 공개 가중치나 API 형태로 기반 모델을 빌려 씀 → 기업의 초기 학습 투자 부담 완화.

## Ⅲ. 파운데이션 모델(Foundation Model)의 구조 (흐름)

- 핵심 요약 : 사전 학습, 적응, 응용의 3계층이 가중치를 이어받으며 서빙되는 흐름.
- 사전 학습 계층 : 텍스트, 이미지, 음성, 코드 같은 원시 데이터를 자기지도학습으로 학습함. 구조는 Transformer 계열이 주류이며, 일부 모델은 **혼합 전문가** (MoE, Mixture of Experts, 입력마다 일부 전문가 네트워크만 활성화하는 구조)를 채택함.
- 적응 계층 : **RAG** (Retrieval-Augmented Generation, 외부 문서를 검색해 문맥에 결합하는 방식)으로 최신 지식을 붙이고, **PEFT** (Parameter-Efficient Fine-Tuning, 일부 파라미터만 학습하는 미세조정)의 대표 기법인 **LoRA** (Low-Rank Adaptation, 저순위 행렬로 만든 소형 어댑터)만 갱신함.

```text
[사전 학습 계층]
  대규모 원시 데이터 (텍스트, 이미지, 음성)
        ↓ 자기지도학습
  기반 모델 가중치 확보
        ↓
[적응 계층]
  인컨텍스트 러닝 / RAG / LoRA
        ↓ 서빙 및 API 연계
[응용 계층]
  이상거래 탐지, 판례 분석, 에이전트
```

```text
[기반 모델 (가중치 사전 학습)]
        ↓
  (1) 프롬프트 지시 : 가중치 불변
        ↓ 필요 시 결합
  (2) RAG : 외부 문서를 문맥에 추가
        ↓ 필요 시 결합
  (3) LoRA : 어댑터 가중치만 학습
```

## Ⅳ. 파운데이션 모델(Foundation Model)과 적응 방식의 비교

- 핵심 요약 : 적응 비용은 프롬프트, RAG, PEFT, 전체 미세조정 순으로 커지고, 가중치 변경 범위도 함께 커짐.

| 적응 방식 | 동작 메커니즘 | 컴퓨팅 비용 | 가중치 변경 범위 |
| --- | --- | --- | --- |
| 인컨텍스트 러닝 | 프롬프트에 지시문과 예시를 넣어 추론 유도 | 낮음 (추론 비용 중심) | 없음 (가중치 고정) |
| RAG | 벡터 DB(Database)에서 관련 문서를 찾아 문맥으로 결합 | 낮음~중간 (임베딩·검색 인프라) | 없음 (가중치 고정) |
| PEFT (LoRA) | 원본 가중치를 고정하고 저순위 어댑터만 학습 | 중간 (소규모 장비에서도 가능한 경우 많음) | 소수의 어댑터만 |
| 전체 미세조정 | 모든 파라미터를 역전파로 재학습 | 높음 (대규모 분산 GPU(Graphics Processing Unit) 클러스터) | 전체 파라미터 |

- 선택 기준 : 데이터의 최신성과 민감도, 필요한 정확도, 운영 예산에 따라 방식을 고르고, 비용이 낮은 방식부터 검토함.

## Ⅴ. 파운데이션 모델(Foundation Model)의 한계와 방안

- 핵심 요약 : 결함 전파, 자원 집중, 데이터 권리 불투명성을 안전 필터, 경량화, 데이터 계보 관리로 통제해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 동질화에 따른 결함 전파 | 기반 모델의 **환각** (Hallucination, 사실과 다른 내용을 그럴듯하게 생성하는 현상), 편향, 보안 결함이 모든 하류 서비스에 복제됨 | 기반 모델 복수 운용, 응용 계층 안전 필터(NeMo Guardrails, Llama Guard 등) 적용 | 서비스별 결함 재현율 |
| 자원 집중과 환경 부담 | 대규모 학습·서빙에 필요한 GPU 클러스터와 전력으로 소수 기업에 집중되고 탄소 배출 증가 | 양자화를 통한 경량화, 소형 언어 모델(SLM, Small Language Model) 전이학습 활용 | 추론 단가, 전력 사용량 |
| 학습 데이터의 권리 불투명성 | 출처가 불투명해 IP(Intellectual Property) 침해 소송과 라이선스 분쟁 위험 | EU AI Act(Artificial Intelligence Act, 유럽연합 인공지능법)가 요구하는 학습 데이터 요약 공개, 데이터 계보 추적, 권리 확인된 데이터와 합성 데이터 병행 | 데이터 출처 기록 완결률 |

## Ⅵ. 파운데이션 모델(Foundation Model)에 대한 기술사적 제언

- 핵심 요약 : 기반 모델을 특정 공급자에 맡기지 않고, 데이터 통제와 비용 관리를 갖춘 상시 운영 체계로 내재화해야 함.

1. 기업은 기반 모델의 선정, 검증, 폐기 기준을 담은 거버넌스 정책을 세우고, 민감 데이터가 외부로 전송되는 범위를 명시해야 한다.
2. 운영 단계에서는 사용량에 따른 과금과 자체 서빙 비용을 비교해 적응 방식과 호스팅 위치를 주기적으로 재평가하는 체계가 필요하다.
3. 전문 도메인에서는 사내 데이터로 PEFT를 적용한 모델을 단계적으로 검증하며 도입하되, 평가 데이터를 학습 데이터와 분리해 격리해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 파운데이션 모델은 범용 사전 학습과 적응 계층을 결합한 재사용형 AI 기반임.
- 시사점 : 활용 범위는 모델 성능보다 데이터 주권, 비용 구조, 안전 장치를 함께 설계하는 역량에 따라 정해짐.
