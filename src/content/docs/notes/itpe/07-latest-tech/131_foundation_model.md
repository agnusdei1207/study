## 30초 인출
- **본질:** 파운데이션 모델은 폭넓은 데이터로 사전학습한 뒤 여러 하류 과업에 적응할 수 있는 기반 모델.
- **메커니즘:** 사전학습된 표현·능력을 프롬프트, 검색 연계, 미세조정 등으로 특정 응용에 활용.
- **위험:** 오류·편향·권리 문제가 하류 응용으로 전파될 수 있어 모델과 적용 환경을 함께 평가.

<details><summary>핵심 용어</summary>

- **파운데이션 모델(Foundation Model):** 폭넓은 데이터로 사전학습하고 다양한 하류 과업의 기반으로 활용할 수 있는 모델.
- **사전학습(Pretraining):** 대규모 또는 과업 관련 자료로 모델의 초기 표현·능력을 학습하는 단계.
- **하류 과업(Downstream Task):** 사전학습 모델을 적용·적응해 해결하려는 후속 과업.
- **자기지도학습(Self-Supervised Learning):** 원자료의 일부를 목표로 구성해 별도 수작업 라벨 없이 학습하는 방법.
- **적응(Adaptation):** 프롬프트, 검색 결합, 미세조정 등으로 기반 모델을 특정 응용에 맞추는 과정.
- **동질화 위험(Homogenization Risk):** 다수 응용이 공통 기반 모델을 사용하면서 오류·편향이 넓게 공유될 수 있는 위험.
- **CRFM(Center for Research on Foundation Models):** Stanford HAI의 파운데이션 모델 연구 조직.

</details>

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **파운데이션 모델**은 폭넓은 데이터로 사전학습하고 다양한 하류 과업의 기반으로 활용할 수 있는 모델 |
| 목적 | 공통 기반 모델의 능력을 다양한 응용에서 재사용·적응 |

## Ⅱ. 사전학습과 적응 흐름
```text
폭넓은 학습 데이터
        |
        v
사전학습 모델
        |
        v
하류 과업에 적응
  (프롬프트·검색·미세조정)
        |
        v
과업별 응용 모델·서비스
```

파운데이션 모델은 단일 구조나 학습 목표를 뜻하지 않음. 언어·시각 등 데이터 종류와 적용 방식에 따라 구성·평가 방법이 달라짐.

## Ⅲ. 적용 방식
| 방식 | 변경 범위 | 고려점 |
|---|---|---|
| 프롬프트 | 입력·지시 구성 | 응답 변동성·문맥 길이 |
| 검색 결합(RAG) | 외부 자료를 문맥에 추가 | 출처·검색 품질·최신성 |
| 미세조정 | 학습 자료로 모델 변수 조정 | 데이터 권리·검증·운영 비용 |
| 어댑터·경량 조정 | 일부 추가 변수 학습 | 기반 모델·도구 호환성 |

## Ⅳ. 기회와 위험
| 기회 | 관리할 위험 |
|---|---|
| 공통 기반을 다양한 서비스에 활용 | 공통 결함·편향의 재사용·확산 |
| 데이터·과업별 적응 | 학습자료 출처·이용권리 불확실성 |
| 여러 모달리티·업무 지원 | 과업별 신뢰도·안전성 차이 |
| 외부 모델 서비스 이용 | 공급자 의존·비용·정보 처리 위험 |

## Ⅴ. 거버넌스·운영
```text
모델·데이터 출처 확인
          |
          v
과업·사용자·위험 정의
          |
          v
기준 자료로 성능·안전 평가
          |
          v
배포 후 오류·변화 감시
          |
          v
개선·사용 제한·교체 판단
```

공통 벤치마크만으로 개별 업무 적합성을 확정하지 않고, 실제 사용 맥락·이해관계자·피해 가능성을 반영한 평가와 감독 필요.

## Ⅵ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 응용 서비스가 기반 모델의 버전·제공자·출력에 종속되면 변경 시 영향 범위와 책임 주체가 불명확해질 수 있음 | 모델·데이터·응용을 분리한 인터페이스와 버전 목록을 관리하고, 교체·장애 시 회귀 평가와 대체 절차를 사전 검증 |
