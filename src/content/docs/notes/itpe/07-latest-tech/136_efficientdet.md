## 연관 키워드

- EfficientDet, EfficientNet, BiFPN(Bidirectional Feature Pyramid Network), 복합 스케일링(Compound Scaling)
- 1단계 객체 탐지(One-stage Object Detection), FPN(Feature Pyramid Network), PANet, NAS-FPN
- mAP(mean Average Precision), FLOPs(Floating Point Operations), 연산 융합(Operator Fusion), 소형 객체 검출

## Ⅰ. EfficientDet의 개요

- 핵심 요약 : EfficientNet 백본과 양방향 피처 피라미드, 복합 스케일링을 결합해 객체 탐지의 정확도와 연산 효율을 함께 높인 1단계 탐지기.
- 개념 : **EfficientDet**은 EfficientNet을 백본으로 쓰고, **가중 양방향 피처 피라미드** (BiFPN, Bidirectional Feature Pyramid Network, 여러 해상도의 특징을 양방향으로 가중 융합하는 구조)를 더한 **1단계 객체 탐지** (One-stage Object Detection, 위치 후보 선정과 분류를 한 번의 네트워크 통과로 수행하는 방식) 모델.
- 배경 및 필요성 : 이론상 연산량 (FLOPs, Floating Point Operations, 부동소수점 연산 횟수)이 줄어도 BiFPN의 잦은 텐서 결합이 NPU(Neural Processing Unit) 같은 가속기에서 메모리 대역폭 병목을 만들 수 있음. 그래서 목표 하드웨어에 맞춘 컴파일과 **연산 융합** (Operator Fusion, 여러 연산을 하나의 커널로 묶어 메모리 왕복을 줄이는 최적화)이 함께 필요함.
- 주요 목적 : 연산 복잡도와 메모리 사용량을 줄이면서, 크기가 서로 다른 물체를 고르게 검출하는 **mAP** (mean Average Precision, 클래스별 평균 정밀도의 평균) 정확도를 함께 높이는 것.

## Ⅱ. EfficientDet의 특징 및 장점

- 핵심 요약 : 복합 스케일링, 양방향 융합, 가중 정규화가 맞물려 적은 연산으로 여러 크기의 객체를 탐지하는 구조.

1. **복합 스케일링** (Compound Scaling, 백본, 피라미드, 예측 헤드, 입력 해상도를 계수 하나로 함께 키우는 방법) : 자원 예산에 맞춰 D0부터 D7까지 일관된 비율로 선택 → 모델 크기와 정확도의 균형을 예측 가능하게 조정.
2. 반복 양방향 융합 : 복합 계수 φ에 따라 BiFPN 블록을 3+φ회 반복하며 상향과 하향 경로를 번갈아 결합하고, 기여가 적은 노드를 제거 → 다중 해상도 정보를 적은 비용으로 혼합.
3. 고속 가중 정규화 : Fast Normalized Fusion 방식으로 입력 가중치를 합으로 나누어 정규화 → 지수 연산을 피해 융합 지연 감소.
4. 공유 예측 헤드 : 분류 네트워크와 박스 회귀 네트워크를 모든 피라미드 레벨에서 공유 → 파라미터 수와 연산량 감소.

## Ⅲ. EfficientDet의 구조 (흐름)

- 핵심 요약 : EfficientNet이 여러 해상도의 특징을 만들고, BiFPN이 이를 융합한 뒤, 공유 헤드가 클래스와 위치를 예측하는 3단 구조.
- 백본 : EfficientNet 계열 B0~B7이 P3부터 P7까지 해상도별 특징 맵을 생성함. 숫자가 작을수록 세밀한 해상도를 가짐.
- 입력 해상도 : 복합 계수가 커질수록 입력 영상이 커져 D0은 512픽셀, D7은 1,536픽셀을 사용함.

```text
[입력 영상 (D0 512px ~ D7 1536px)]
        ↓
[EfficientNet 백본]
  P3 ~ P7 다중 해상도 특징 맵
        ↓
[BiFPN 반복 융합 블록]
  하향 경로 후 상향 경로를 반복
        ↓
[공유 예측 헤드]
  분류 (Focal Loss) / 박스 회귀 (Smooth L1)
```

```text
P7 (고수준 의미) → P3 (세부 해상도) : 하향
P3 → P7 : 상향 (세부 정보 전달)
동일 레벨 입력을 출력에 잔차 연결
```

## Ⅳ. EfficientDet의 피라미드 구조 비교

- 핵심 요약 : 단방향 FPN에서 양방향 BiFPN으로 발전하며 연결을 정규화하고 불필요한 노드를 제거하는 방향으로 진화.
- 비교 대상 : 상향 특징을 하향으로 전달하는 **FPN** (Feature Pyramid Network, 다중 해상도 특징을 피라미드로 결합하는 구조)을 기준으로, PANet (Path Aggregation Network), NAS-FPN (NAS로 탐색한 FPN), BiFPN을 비교함.

| 비교 항목 | FPN (Feature Pyramid Network) | PANet (Path Aggregation Network) | NAS-FPN | BiFPN (EfficientDet) |
| --- | --- | --- | --- | --- |
| 연결 방향 | 상향에서 하향으로 단방향 | 하향 후 상향 경로 추가 | 신경망 구조 탐색으로 불규칙 연결 | 양방향 정규 연결 |
| 노드 처리 | 단순 통과 | 단순 합 결합 | 복잡한 비대칭 결합 | 기여가 적은 단일 입력 노드 제거 |
| 특징 가중치 | 동일 가중치 | 동일 가중치 | 비정형 결합 | 학습 가능한 정규화 가중치 |
| 연산 특성 | 보통 | 연산량과 지연 증가 | 불규칙해 하드웨어 비효율 | 잔차 경로를 두되 연산 최소화 |

- 선택 기준 : 정확도와 지연을 함께 보므로, 목표 하드웨어에서 실측한 지연을 기준으로 채택 여부를 정함.

## Ⅴ. EfficientDet의 한계와 방안

- 핵심 요약 : 이론 연산량과 실제 지연의 차이, 고해상도 학습 메모리 부담, 소형 객체 검출 저하를 컴파일 최적화, 학습 기법, 추론 설계로 통제해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 이론 연산량과 실제 지연의 차이 | BiFPN의 잦은 텐서 분기와 결합으로 메모리 대역폭 병목 발생 | TensorRT, OpenVINO 등 텐서 컴파일러로 연산 융합 적용, 메모리 복사 최소화 | 실측 지연, 메모리 대역폭 사용률 |
| 고해상도 모델의 학습 메모리 부담 | D6, D7 입력이 커져 VRAM(Video Random-Access Memory) 부족과 배치 크기 제한 발생 | 그래디언트 누적, FP16 혼합 정밀도 학습, 경량 D0~D3 모델 우선 채택 | 최대 배치 크기, 학습 시간 |
| 소형 객체 검출 성능 저하 | 깊은 단계의 특징 위주라 원거리 작은 물체 정보가 희석됨 | 고해상도 저수준 특징 추가 활용, 타일 분할 슬라이딩 윈도우 추론 병행 | 소형 객체별 정밀도 |

## Ⅵ. EfficientDet에 대한 기술사적 제언

- 핵심 요약 : 응용별 우선순위와 목표 하드웨어의 실측 성능을 기준으로 모델 크기를 정하는 절차를 표준화해야 함.

1. 자율주행, 스마트 관제, 위성 영상 분석처럼 응용마다 실시간성과 정밀도 중 무엇을 우선할지 먼저 정하고, 그 결과로 D 계열의 크기를 고르는 기준이 필요하다.
2. 정확도 경쟁보다 목표 장치에서의 실측 지연과 전력을 기준으로 모델을 선정하는 절차를 조직 표준으로 삼아야 한다.
3. 양자화와 컴파일러 최적화를 학습이 끝난 뒤의 선택 사항으로 두지 않고 기본 파이프라인에 넣어, 엣지 배포가 연구 단계에서 막히지 않도록 해야 한다.

## Ⅶ. 결론

- 핵심 요약 : EfficientDet은 BiFPN과 복합 스케일링으로 탐지 효율을 체계화한 1단계 탐지기이며, 실제 가치는 목표 장치에서의 실행 성능으로 판정됨.
- 시사점 : 이론상 연산량보다 하드웨어 실측 성능이 모델 선택의 기준이 되어야 함.
