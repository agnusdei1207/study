## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 컴퓨터 비전 → 객체 탐지 → EfficientDet

## 30초 인출

- 본질: **EfficientDet은** EfficientNet 백본과 가중 양방향 특징 피라미드·탐지 헤드를 결합한 객체 탐지 모델 계열
- 메커니즘: 영상 입력 → EfficientNet 특징 추출 → BiFPN 다중 규모 융합 → 분류·박스 예측
- 통찰: 한계: 논문 성능 수치가 실제 장치의 지연·작은 객체 성능을 보장하지 않음 → 방안: 목표 영상·하드웨어에서 객체 크기별 정확도와 지연을 함께 측정

<details><summary>핵심 용어</summary>

- **BiFPN** : 여러 해상도의 특징을 양방향으로 융합하고 경로별 가중치를 학습하는 구조
- **복합 스케일링** : 입력 해상도와 백본·특징망·탐지 헤드의 규모를 함께 조정하는 방법
- **탐지 헤드** : 위치 상자와 클래스 점수를 예측하는 부분

</details>

## 2~4교시 25점 답안

## Ⅰ. EfficientDet의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EfficientDet은** EfficientNet 백본과 가중 양방향 특징 피라미드·탐지 헤드를 결합한 객체 탐지 모델 계열 |
| 목적 | 연산·메모리 제약 아래 객체 위치와 분류 정확도의 균형 확보 |

## Ⅱ. 구성요소와 수행 단계

```text
영상 ──> EfficientNet 백본 ──> 규모별 특징 P3…P7
                                   │ 양방향 가중 융합
                                   ▼
                                 BiFPN
                                   │
                           분류·박스 예측 헤드
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 입력·백본 | EfficientNet 계열 백본으로 특징 생성 | 작은 객체의 정보 손실 |
| BiFPN | 양방향 경로로 여러 규모의 특징 융합 | 융합 비용 증가 |
| 탐지 헤드 | 공유된 특징에서 클래스·박스 추정 | 오탐·미탐 균형 |
| 스케일링 | 해상도·깊이·폭을 자원 예산에 맞춰 조정 | 지연·메모리 증가 |

## Ⅲ. 핵심 작동 관계

| 구성 | 특징 변화 | 탐지 결과에 미치는 영향 |
|---|---|---|
| 백본 | 영상의 단계별 표현 추출 | 작은 객체 정보 보존 |
| BiFPN | 여러 규모의 특징 반복 융합 | 객체 크기별 검출 |
| 헤드 | 클래스·박스 예측 | 오탐·위치 오차 |

EfficientDet의 적용 판단은 명칭이나 단일 지표보다 위 단계의 입력·출력 조건과 실제 업무·장치 환경에서 확인한 결과를 기준으로 수행.

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 논문 성능 수치를 실제 장치의 처리 지연으로 그대로 옮기기 어려움 | 대상 영상의 객체 크기·밀도와 하드웨어에서 정확도·지연을 함께 측정 |

## Ⅴ. 제언

우선 목표 장치·영상에서 객체 크기별 검출률과 지연 기준선을 수집.
