- 자율주행차나 스마트폰에서 사물을 찾을 때 모델이 너무 무거우면 실시간 처리가 불가능함 → 서로 다른 크기의 특징 맵들을 영리하게 양방향으로 섞어주는 BiFPN과, 해상도·네트워크 깊이·너비를 한 번에 비례적으로 키우는 복합 스케일링을 적용해 연산량은 1/9로 줄이고 정확도는 극대화한 물체 검출 AI / NPU 하드웨어 가속 최적화 필요

## 핵심 용어
- BiFPN(Bidirectional Feature Pyramid Network): 서로 다른 해상도의 피처 맵 간에 상향식과 하향식 경로를 모두 두고, 중요도에 따라 학습 가능한 가중치를 부여하여 고속 융합하는 차세대 피라미드 모듈
- 복합 스케일링(Compound Scaling): 백본망(EfficientNet), BiFPN 계층 수, 분류기 깊이, 입력 이미지 해상도를 단 하나의 복합 계수 $\phi$에 따라 균형 있게 동시 확장하는 설계 법칙
- 고속 정규화 융합(Fast Normalized Fusion): 소프트맥스 연산의 지연을 피하기 위해, 단순 나눗셈($O = \sum_i \frac{w_i}{\epsilon + \sum_j w_j} \cdot I_i$)을 통해 특징 맵 간의 가중치를 0~1 사이로 고속 정규화하는 기법

## 핵심 통찰
- "모든 피처 맵의 기여도는 같지 않다": 기존 FPN이나 PANet은 서로 다른 스케일의 피처를 합칠 때 1:1로 단순 덧셈을 했으나, EfficientDet은 해상도마다 객체 판별에 미치는 중요도가 다르다는 점에 착안해 가중치를 스스로 학습하게 함
- 불필요한 단일 엣지 노드 제거: 입력 노드에서 다른 엣지와 융합되지 않고 출력으로 직행하는 의미 없는 중간 노드를 과감히 삭제하여 연산량을 대폭 절감함
- D0부터 D7x까지 완벽한 스케일 확장성: 임베디드 엣지 칩셋용 초경량 D0 모델(mAP 34.6, 2.5G FLOPs)부터 초고정밀 클라우드용 D7x 모델(mAP 55.1)까지 단일 공식으로 파생 모델을 체계적으로 생성 가능

## 이웃 토픽과 구분
- EfficientNet vs EfficientDet: EfficientNet은 이미지 전체를 하나로 분류하는 이미지 분류(Classification) 백본 / EfficientDet은 그 EfficientNet을 기반으로 이미지 내 객체의 위치까지 찾아내는 객체 검출(Detection) 모델
