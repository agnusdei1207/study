## 핵심 용어
- 학습률(Learning Rate, $\eta$): 파라미터를 갱신할 때 손실 함수의 기울기(Gradient) 방향으로 한 번에 얼마나 크게 이동할 것인지를 결정하는 가장 중요한 하이퍼파라미터
- 배치 크기(Batch Size): 파라미터를 1회 갱신하기 위해 한 번에 묶어서 모델에 입력하는 데이터 샘플의 묶음 크기(메모리와 그래디언트 분산에 영향)
- HPO(Hyperparameter Optimization): 사람이 일일이 수동으로 값을 바꿔가며 테스트하지 않고, 알고리즘(Optuna, Ray Tune)을 통해 최적의 하이퍼파라미터 조합을 자동 탐색하는 기술

## 핵심 통찰
- "학습률 하나가 모델의 생사를 가름": 학습률이 너무 크면 손실 함수가 발산해 버리고, 너무 작으면 세월아 네월아 학습이 멈추므로, 초반에는 웜업(Warmup)으로 올렸다가 점차 줄이는 스케줄러 설계가 필수
- Random Search와 Grid Search: 일부 하이퍼파라미터에 성능 민감도가 집중된 탐색 공간에서는 무작위 탐색이 같은 예산의 격자 탐색보다 다양한 값을 시험할 수 있음. 우열은 탐색 공간·예산에 따라 검증
- 조기 종료(Early Stopping): 검증 지표의 개선이 일정 기간 멈추면 훈련을 중지할 수 있음. Patience 값은 지표 변동성과 훈련 비용에 따라 선택

## 이웃 토픽과 구분
- 모델 파라미터 vs 하이퍼파라미터: 모델 파라미터(W, b)는 데이터 훈련을 통해 기계가 스스로 찾는 답 / 하이퍼파라미터는 그 답을 잘 찾을 수 있도록 인간이 환경을 조성해 주는 훈련 지침

## 문제·원인·대책
- 아래 사례의 조건·수치는 가상 예시이며 실제 성과가 아님.
- 적용 상황: 대규모 추천 시스템 심층 신경망(DeepFM) 모델 하이퍼파라미터 튜닝
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 학습 시작 10스텝 만에 손실 함수 값이 'NaN'으로 뜨며 발산하여 학습 실패 | 학습률(Learning Rate)이 너무 크게 설정되어 그래디언트 폭주 발생 | 학습률을 1/10로 축소하고 Gradient Clipping 및 Warmup 스케줄러 적용 | 안정적인 손실 수렴 달성 |
| 탐색할 하이퍼파라미터가 8개로 늘어나자 Grid Search 시 수만 번의 학습 필요 | 조합의 수가 지수적으로 폭증하는 차원의 저주(Curse of Dimensionality) | TPE 기반 베이지안 최적화(Optuna) 프레임워크로 탐색 알고리즘 전환 | 50회 탐색만으로 최적 조합 도출 |
| 하이퍼파라미터 튜닝 과정에서 테스트 데이터셋을 반복 참조하여 테스트셋 과적합 | 훈련-검증-테스트 3단계 분리 원칙 위반 및 데이터 누수 | 훈련/검증용 K-Fold Cross-Validation 내에서만 HPO를 수행하고 최종 1회만 테스트 | 객관적이고 신뢰할 수 있는 일반화 성능 검증 |

## 1교시 10점 답안
- **정의:** 학습 시작 전 또는 학습 과정의 외부 절차에서 정하는 설정값. 모델이 데이터로 직접 갱신하는 가중치·편향과 구별.
- **유형:** 학습률·배치 크기 등 최적화 설정, 트리 깊이·은닉층 수 등 모델 용량 설정, 정규화 강도 등 일반화 설정.
- **조정:** 탐색 공간 정의 → 훈련 데이터로 학습 → 별도 검증 데이터로 평가 → 탐색 및 재학습. 테스트 데이터는 최종 평가에 보존.

## 2~4교시 예상문제 (25점)

## 2~4교시 25점 답안
### Ⅰ. 개념과 범위
- 하이퍼파라미터 최적화는 모델 외부의 설정 조합을 검증 성능·연산 예산에 맞춰 선택하는 과정. 파라미터 학습과 구분.
### Ⅱ. 탐색 방식 비교
| 방식 | 원리 | 적용 조건 |
|---|---|---|
| 격자 탐색 | 지정한 조합 전수 평가 | 좁은 이산 탐색 공간 |
| 무작위 탐색 | 분포에서 조합 표본 추출 | 중요한 축이 소수일 때 효율적인 기준선 |
| 베이지안 최적화 | 평가 이력으로 다음 후보 선택 | 평가 비용이 큰 경우 |
| 조기 종료 | 성능이 낮은 실행 중단 | 중간 평가가 가능한 학습 |
### Ⅲ. 운영 절차
- 탐색 범위·평가 지표·자원 예산 설정 → 훈련/검증 분리 또는 교차검증 → 탐색 → 선택 모델 재학습 → 보존한 테스트셋 평가.
### Ⅳ. 유의점
- 검증셋 반복 사용으로 생기는 선택 편향, 데이터 누수, 난수·실험 추적 누락 관리. 탐색 기법 우열은 문제와 예산별 실측 대상.
