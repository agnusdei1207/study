기계학습 → 모델 학습과 평가 → 하이퍼파라미터 탐색·검증

## 30초 인출

- 본질: **하이퍼파라미터** 는 학습 알고리즘이나 모델 구조의 동작을 정하는 설정값
- 메커니즘: 후보 범위를 정하고 훈련 자료로 모델을 학습한 뒤 검증 자료에서 성능을 비교하여 선택
- 구분: 모델 가중치·편향은 훈련으로 갱신되는 파라미터이며, 테스트 자료는 선택된 모델의 최종 평가에 보존

<details><summary>핵심 용어</summary>

- **하이퍼파라미터(Hyperparameter)** : 학습 전에 설정하거나 별도 탐색 절차에서 고르는 모델·학습 설정값.
- **모델 파라미터(Model Parameter)** : 훈련 데이터와 최적화 과정으로 갱신되는 가중치·편향 등.
- **학습률(Learning Rate)** : 경사 기반 최적화에서 파라미터의 갱신 폭을 조절하는 값.
- **HPO(Hyperparameter Optimization)** : 정해진 탐색 공간·평가 지표·자원 예산 아래 설정값 조합을 선택하는 과정.
- **교차검증(Cross-Validation)** : 훈련 자료를 여러 분할로 나눠 학습·검증을 반복하여 후보를 비교하는 방법.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **하이퍼파라미터** 는 학습 알고리즘이나 모델 구조의 동작을 정하는 설정값 |
| 목적 | 주어진 과업과 자원 조건에서 적절한 학습·일반화 성능을 얻을 설정 선택 |

## Ⅱ. 유형과 영향

| 유형 | 예 | 영향 |
|---|---|---|
| 모델 구조 | 트리 최대 깊이·은닉층 수 | 모델의 표현 용량과 계산 비용 |
| 최적화 | 학습률·배치 크기 | 갱신 폭·수렴 양상·자원 사용 |
| 일반화 제어 | 정규화 강도·드롭아웃 비율 | 복잡도와 과적합 억제 수준 |

같은 이름의 값도 모델·알고리즘에 따라 학습 중 조정할 수 있으므로 “사람이 훈련 전에 한 번만 정한다”로 정의하지 않음.

## Ⅲ. 탐색과 평가 절차

```text
과업·평가 지표·자원 예산 정의
           ↓
탐색 공간과 훈련·검증 분할 결정
           ↓
후보 학습 → 검증 점수·비용 기록 → 다음 후보 선택
           ↓
설정 확정·필요 시 재학습 → 보존한 테스트 자료로 최종 평가
```

| 방식 | 후보 선택 | 적합한 조건 |
|---|---|---|
| 격자 탐색 | 지정한 값의 조합을 순서대로 평가 | 작고 이산적인 탐색 공간 |
| 무작위 탐색 | 정한 분포에서 후보를 추출 | 넓은 공간의 기준선과 제한된 예산 |
| 베이지안 최적화 | 과거 평가 결과로 다음 후보를 선택 | 후보 평가 비용이 큰 경우 |
| 조기 종료 | 중간 결과가 낮은 시도를 중단 | 학습 중 성능을 관측할 수 있는 경우 |

방법의 우열은 탐색 공간·평가 예산·성능 변동에 따라 달라지며, 특정 횟수의 탐색이 최적해를 보장하지 않음.

## Ⅳ. 평가 편향과 관리

| 위험 | 발생 경로 | 대응 |
|---|---|---|
| 테스트 자료 누수 | 테스트 점수를 반복 조회해 후보 선택 | 테스트 자료는 최종 평가에만 사용 |
| 검증 자료 과적합 | 많은 후보를 같은 검증 자료에서 반복 비교 | 교차검증·별도 검증 자료와 탐색 횟수 기록 |
| 재현성 부족 | 분할·난수·코드·자원 조건 누락 | 실험별 설정·데이터 버전·평가 지표 보존 |
| 탐색 비용 증가 | 후보·모델 규모 확대 | 자원 예산 설정과 중간 성능 기반 중단 검토 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 검증 점수가 높은 후보가 운영 데이터에서도 우수하다고 단정하기 어려움 | 후보 선택 이후 독립 테스트와 운영 표본을 분리해 검증하고, 성능 저하가 확인된 데이터 구간부터 탐색 범위·모델 구조를 재검토 |
