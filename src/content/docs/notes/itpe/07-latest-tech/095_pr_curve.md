## 지식 로드맵 내 현재 위치
IT 인공지능 → 분류 모델 평가 → 임계값별 양성 예측 품질 → PR 곡선

## 30초 인출
- **본질:** PR 곡선은 분류 임계값을 바꿀 때 양성 예측의 정밀도와 재현율이 어떻게 달라지는지 보여준다.
- **메커니즘:** 점수 임계값별 TP·FP·FN을 계산해 재현율을 가로축, 정밀도를 세로축에 그린다.
- **선택 기준:** 양성 클래스가 희귀한 문제에서는 ROC 곡선과 함께 PR 곡선을 살펴 오탐 부담을 평가한다.

<details><summary>핵심 용어</summary>

- **정밀도(Precision):** 양성으로 예측한 사례 중 실제 양성의 비율(TP/(TP+FP))이다.
- **재현율(Recall):** 실제 양성 중 양성으로 예측한 비율(TP/(TP+FN))이다.
- **ROC(Receiver Operating Characteristic):** 임계값별 재현율과 위양성률의 관계를 나타내는 곡선이다.
- **PR 곡선:** 분류 임계값에 따른 정밀도와 재현율의 관계를 나타낸다.
- **Average Precision(AP):** 재현율 변화에 따른 정밀도를 요약하는 순위 기반 지표다. PR 곡선 아래 면적(AUPRC)과 계산 정의가 항상 같지는 않다.
</details>

## 1교시 10점 답안
### Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | PR 곡선은 분류 임계값에 따른 정밀도와 재현율의 관계를 나타내는 평가 도구다 |
| 목적 | 양성 탐지 성능과 오탐 부담을 함께 살펴 임계값 선택을 돕는다 |

### Ⅱ. 지표와 곡선
임계값을 낮추면 보통 더 많은 사례를 양성으로 예측하므로 재현율과 오탐이 함께 늘 수 있다.

```text
[모델 점수]
     | 임계값 적용
     v
[양성 예측]
     | TP·FP·FN 집계
     +-------------------+
     |                   |
     v                   v
[정밀도 TP/(TP+FP)] [재현율 TP/(TP+FN)]
     |                   |
     +------ 한 점 -------+
              v
         [PR 곡선]
```

### Ⅲ. PR과 ROC 비교
| 구분 | PR 곡선 | ROC 곡선 |
|---|---|---|
| 축 | 재현율·정밀도 | FPR·TPR |
| 음성 사례 영향 | TN은 정밀도·재현율 계산에 직접 들어가지 않음 | FPR에 TN이 들어감 |
| 활용 | 양성 희귀 문제에서 양성 예측의 오탐 부담 확인에 유용 | 양성과 음성의 분리 능력을 폭넓게 확인 |

양성 비율이 달라지면 PR 값과 기준선도 달라질 수 있으므로 데이터 구성과 운영 비용을 함께 기록한다. ROC가 불균형 데이터에서 항상 부정확한 것은 아니며, PR은 양성 예측 품질을 보완해 보여준다.

**제언:** 실제 운영 양성 비율과 오탐·미탐 비용을 반영해 PR과 ROC를 함께 확인하고 임계값을 정한다.

## 2~4교시 25점 답안
## Ⅰ. 개요와 평가 관점
| 구분 | 핵심 |
|---|---|
| 정의 | PR 곡선은 분류 임계값에 따른 정밀도와 재현율의 관계를 나타내는 평가 도구다 |
| 목적 | 양성 탐지 성능과 오탐 부담을 함께 살펴 임계값 선택을 돕는다 |

PR 곡선은 양성으로 판정한 결과의 정밀도와 실제 양성을 찾아낸 재현율을 연결한다. 임계값에 따른 탐지와 오탐 간 절충을 확인하는 데 쓰며, 양성 사례가 희귀한 문제에서 특히 유용하다.

| 상황 | 핵심 확인점 |
|---|---|
| 사기·불량 탐지 | 탐지율을 높일 때 늘어나는 오탐 건수 |
| 서로 다른 데이터 기간 비교 | 양성 비율과 라벨 구성의 변화 |

## Ⅱ. 산출 메커니즘
모델 점수에 여러 임계값을 적용하고 각 시점의 혼동행렬 값을 계산한다. 그 결과 정밀도와 재현율을 좌표로 삼아 곡선을 만든다.

```text
[모델 점수]
     | 임계값 적용
     v
[양성 예측]
     | TP·FP·FN 집계
     +-------------------+
     |                   |
     v                   v
[정밀도 TP/(TP+FP)] [재현율 TP/(TP+FN)]
     |                   |
     +------ 한 점 -------+
              v
         [PR 곡선]
```

AP는 정밀도와 재현율 순위 정보를 요약하는 한 방식이다. AUPRC라고 부르는 면적 지표와 구현별 계산 정의를 확인하고, 선형 보간을 임의로 적용하지 않는다.

## Ⅲ. ROC와의 비교 및 활용
| 항목 | PR | ROC |
|---|---|---|
| 좌표 | Recall, Precision | TPR, FPR |
| 직접 반영하는 오류 | FP는 Precision에, FN은 Recall에 반영 | FP·TN은 FPR, TP·FN은 TPR에 반영 |
| 클래스 비율 영향 | 양성 유병률에 민감 | 비율 변화에 비교적 덜 민감한 분리 관점 |
| 주요 용도 | 양성 예측의 실질적 품질 확인 | 점수의 양·음성 순위 분리 확인 |

클래스 비율 변화 시 PR 성능과 기준선이 변할 수 있다. 따라서 같은 테스트 분포에서 비교하고 양성 기준선(양성 비율), 오탐 건수, 업무 비용을 함께 제시한다.

## Ⅳ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| PR 곡선이나 AP 하나만으로 운영 임계값을 정하면 비용 차이를 놓칠 수 있음 | 검증 데이터에서 오탐·미탐 비용과 처리 용량을 반영해 임계값을 정하고, 기간별 양성 비율 변화에 맞춰 재평가한다. |
