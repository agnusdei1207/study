## 30초 인출

- 본질: **PR (Precision-Recall) 곡선** 은 이진 분류기에서 분류 임계값(Threshold) 변화에 따른 정밀도(Precision)와 재현율(Recall) 간의 트레이드오프 관계를 시각화한 성능 평가 도구
- 메커니즘: 모델의 예측 확률값을 내림차순 정렬한 뒤 임계값을 순차 변경하며 오차행렬(Confusion Matrix)의 TP·FP·FN을 산출하여 재현율 축(X축) 대비 정밀도 축(Y축)에 매핑
- 통찰: 극심한 클래스 불균형(Class Imbalance) 환경에서 ROC 곡선의 위양성 착시(False Positive Illusion)를 배제할 수 있으나 유병률 변화에 민감하므로 비즈니스 오탐·미탐 비용 함수를 결합한 최적 운영 임계값 튜닝 필수

<details><summary>핵심 용어</summary>

- **PR 곡선 (Precision-Recall Curve)** : 재현율을 X축, 정밀도를 Y축으로 설정하여 다양한 결정 임계값에서의 분류기 성능 궤적을 나타낸 그래프.
- **정밀도 (Precision)** : 모델이 양성(Positive)으로 분류한 전체 사례 중 실제 참 양성의 비율 ($\frac{TP}{TP+FP}$).
- **재현율 (Recall / Sensitivity)** : 실제 전체 참 양성 사례 중 모델이 정확히 양성으로 찾아낸 비율 ($\frac{TP}{TP+FN}$).
- **AUPRC (Area Under the PR Curve)** : PR 곡선 하단 면적을 수치화한 지표로 불균형 데이터셋에서 전역 분류 능력을 요약 평가하는 척도.
- **AP (Average Precision)** : 재현율 임계 구간별 정밀도의 가중 평균값을 계산하는 랭킹 평가 지표.

</details>

## 2~4교시 25점 답안

## Ⅰ. PR 곡선의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **PR 곡선** 은 이진 분류 알고리즘에서 결정 임계값의 연속적 변화에 따라 변화하는 정밀도(Precision)와 재현율(Recall)의 상충 관계를 2차원 평면에 시각화한 평가 모델 |
| 목적 | 양성 클래스가 극히 희소한 불균형 데이터 환경에서 음성 클래스 과대평가 왜곡 없이 양성 탐지력과 오탐 부담을 정밀 측정 |

## Ⅱ. PR 곡선의 핵심 지표 산출 공식 및 특성

| 평가 척도 | 수식 표현 | 공학적 의미 및 특성 |
|---|---|---|
| **정밀도 (Precision)** | $Precision = \frac{TP}{TP + FP}$ | 모델이 양성이라 확신한 것 중 진짜의 비율, 모델 예측의 신뢰도 및 오탐(FP) 통제력 대변 |
| **재현율 (Recall)** | $Recall = \frac{TP}{TP + FN}$ | 실제 세상에 존재하는 양성을 빠짐없이 적발한 비율, 미탐(FN) 방지력 및 민감도 대변 |
| **기저선 (Baseline)** | Baseline $= \frac{P}{P + N} = \frac{TP+FN}{TP+FN+FP+TN}$ | 무작위 추측(Random Guess) 시 정밀도는 데이터셋 내 양성 유병률(Prevalence) 수평선에 수렴 |
| **AUPRC 및 AP** | $AP = \sum_n (R_n - R_{n-1}) P_n$ | PR 곡선 아래 면적 지표, 1에 가까울수록 모든 재현율 구간에서 높은 정밀도를 유지하는 우수 모델 |

## Ⅲ. PR 곡선 산출 프로세스 및 임계값 튜닝 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             PR 곡선 산출 및 임계값 최적화 엔지니어링 프로세스          │
└────────────────────────────────────────────────────────────────────────┘
 [ 검증 데이터 예측 확률값 산출 (0.00 ~ 1.00) ]
                       │
                       ▼
 [ 예측 확률값 기준 내림차순 정렬 (Descending Sort) ]
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 임계값(Threshold: t) 순차 순회 (1.0 ──> 0.0)                         │
 │                                                                      │
 │  [ Confusion Matrix 산출 ] ──> TP, FP, FN, TN 계측                  │
 │                                                                      │
 │  ├── Recall 계산:    r(t) = TP / (TP + FN)  ──> X축 좌표              │
 │  └── Precision 계산: p(t) = TP / (TP + FP)  ──> Y축 좌표              │
 └─────────────────────┬────────────────────────────────────────────────┘
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 2차원 평면 플로팅 (Plotting) 및 AP 적분                              │
 │                                                                      │
 │   Precision                                                          │
 │   1.0 ┌─────────\                                                    │
 │       │          \─── 우수 모델 (High AUPRC)                         │
 │       │              \                                               │
 │       │               \──────┐                                       │
 │       │                      \                                       │
 │   y_p ├┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈\─── [기저선: 양성 유병률 수평선]      │
 │   0.0 └────────────────────────────\── Recall                        │
 │       0.0                          1.0                               │
 └──────────────────────────────────────────────────────────────────────┘
```

| 처리 절차 | 상세 수행 내용 | 검증 및 산출물 |
|---|---|---|
| **확률값 정렬** | 분류 모델의 소프트맥스 출력 양성 확률값을 내림차순 정렬 | 정렬된 예측 점수 배열 |
| **혼동행렬 전개** | 각 데이터 포인트의 점수를 임계값으로 설정하여 TP·FP·FN 누적 | 누적 혼동행렬 테이블 |
| **단조감소 보정** | 지그재그 진동하는 정밀도 값을 완화하기 위해 P-R 보간(Interpolation) 적용 | 평활화된(Interpolated) 곡선 |
| **AUPRC 적분** | 재현율 변화량에 따른 정밀도 사다리꼴 적분 또는 직사각형 면적 합산 | 단일 스칼라 AUPRC 지표 |

## Ⅳ. 분류 모델 평가 곡선 비교 (PR Curve vs ROC Curve)

| 비교 항목 | ROC (Receiver Operating Characteristic) | PR (Precision-Recall) 곡선 (본 토픽) |
|---|---|---|
| **축 구성** | X축: FPR ($FP / (TN+FP)$), Y축: TPR ($TP / (TP+FN)$) | X축: Recall ($TP / (TP+FN)$), Y축: Precision ($TP / (TP+FP)$) |
| **TN(참 음성) 반영 여부** | 반영됨 (FPR의 분모에 TN 포함) | 반영 안 됨 (혼동행렬에서 TN 완전 배제) |
| **클래스 불균형 민감도** | 둔감함 (음성 다수 시 FP가 커져도 FPR 왜곡 미미) | 극도로 민감함 (FP 증가 시 정밀도 즉각 폭락) |
| **무작위 분류 기저선** | 대각선 (AUC = 0.5 고정) | 데이터셋의 양성 비율 수평선 ($P / (P+N)$) |
| **주요 적용 도메인** | 클래스 비율이 5:5에 근접한 일반 분류 문제 | 이상 탐지, 금융 사기(FDS), 희귀 질환 진단 (불균형 극심) |
| **곡선의 단조성** | X가 증가하면 Y는 항상 단조 증가 | X가 증가할 때 Y가 진동하며 요동칠 수 있음 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 검증셋의 양성 유병률(Prevalence)에 따라 PR 곡선의 높낮이가 달라져 다른 데이터셋 간 직접 비교 불가 | 양성 비율 변화를 반영한 정규화 기법인 Precision-Recall-Gain 곡선 병행 또는 베이즈 유병률 보정 적용 |
| 재현율 증가 구간에서 정밀도가 요동치며 비단조적(Non-monotonic) 궤적을 그려 최적 임계값 특정 난항 | 사후 최대 정밀도 외피선(Maximum Precision Envelope) 보간 기법을 적용하여 단조 감소 곡선 변환 |
| 단순 AUPRC 면적 최대화 지점만을 채택할 경우 비즈니스 현장의 오탐(FP) 처리 인건비와 미탐(FN) 손실액 간의 비용 격차 무시 | 오탐 비용($C_{FP}$)과 미탐 비용($C_{FN}$)을 매개변수화한 총 기대 손실 비용 함수(Cost Function)를 정의하고 비용 최소화 지점에서 운영 임계값 확정 |

## Ⅵ. 제언

금융 사기(FDS) 및 침해사고 관제 시스템에서 ROC 기반 착시를 차단하고 총 비즈니스 손실을 최소화하는 비용 민감형(Cost-Sensitive) PR 최적화 임계값 거버넌스 프레임워크 구축 권고.

```text
[ 프로덕션 트래픽 및 거래 데이터 입력 ]
                   │
                   ▼
[ 이상거래 탐지 모델 (Scoring Model) ]
                   │ 예측 점수 Score
                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 비용 민감 최적 임계값 결정 엔진 (Cost-Sensitive Threshold Engine)     │
│                                                                        │
│  - 실시간 PR 곡선 및 Confusion Matrix (t) 동적 추적                    │
│  - 비즈니스 손실 함수: Total Cost(t) = C_FP * FP(t) + C_FN * FN(t)     │
│  - 최소 비용 목적함수: argmin_t Total Cost(t) ──> 최적 임계값 t* 확정  │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
         ┌─────────────────────────┴─────────────────────────┐
         ▼ (Score ≥ t*)                                      ▼ (Score < t*)
[ 실시간 이상거래 차단 및 FDS 관제 ]               [ 정상 거래 승인 패스 ]
```

| 구분 | 전통적 ROC-AUC 기반 운영 | 제언: 비용 민감 PR 곡선 기반 최적화 |
|---|---|---|
| **지표 선정** | ROC-AUC 0.99 착시로 조기 배포 | AUPRC 및 Recall별 정밀도 집중 분석 |
| **임계값 결정** | 디폴트 확률 0.5 또는 Youden 지수 | 오탐 인건비 대비 미탐 사기 피해액 최적점 |
| **오탐 관제 부담** | 관제 센터 일일 수만 건 오탐 경보 마비 | 정밀도 90% 이상 유지 가능한 임계값 방어 |
| **운영 재조정** | 모델 배포 후 정적 고정 | 데이터 드리프트 시 유병률 연동 동적 튜닝 |
