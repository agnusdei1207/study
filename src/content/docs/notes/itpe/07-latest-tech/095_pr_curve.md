## 연관 키워드

- PR 곡선, 정밀도, 재현율, 임계값, 클래스 불균형, 유병률, ROC, AUPRC, 기저선, 혼동행렬, 비용 함수

## Ⅰ. PR 곡선의 개요

- 핵심 요약 : 임계값 변화에 따른 정밀도와 재현율의 상충을 보여 주어 불균형 데이터의 양성 탐지 성능을 평가하는 곡선.
- 개념 : 이진 분류에서 결정 임계값을 바꿀 때 **정밀도**(Precision)와 **재현율**(Recall)이 어떻게 변하는지를 2차원 평면에 그린 **PR 곡선**(Precision-Recall Curve).
- 배경 및 필요성 : 양성 사례가 극히 드문 **클래스 불균형**(Class Imbalance) 환경에서는 ROC(Receiver Operating Characteristic) 곡선의 면적이 음성 다수의 영향으로 높게 나와도 양성 탐지가 부실할 수 있다. 다만 PR 곡선도 유병률에 민감하므로 오탐과 미탐의 비용을 반영한 운영 임계값 결정이 함께 필요하다.
- 주요 목적 : 양성 클래스가 희소한 데이터에서 음성 다수의 영향을 배제하고, 양성 탐지력과 오탐 부담을 정밀하게 측정.

## Ⅱ. PR 곡선의 특징 및 장점

- 핵심 요약 : 음성 판정 항목을 계산에서 빼고 양성 측면의 두 지표만 보므로, 희소 양성 환경에서 성능을 정직하게 드러냄.

PR 곡선은 예측 확률을 내림차순으로 정렬한 뒤 임계값을 바꿔 가며 **혼동행렬**(Confusion Matrix)의 TP·FP·FN을 계산하고, 각 임계값의 재현율과 정밀도를 좌표로 찍어 만든다.

1. 정밀도 : TP/(TP+FP) → 양성이라 판정한 것 중 실제 양성의 비율로, 오탐 통제력을 나타냄.
2. 재현율 : TP/(TP+FN) → 실제 양성 중 찾아낸 비율로, 미탐 방지력을 나타냄.
3. **기저선**(Baseline) : 무작위 판정 시 정밀도는 양성 유병률 수준에 머무름 → 곡선이 이 수평선보다 위에 있어야 의미 있는 모델이며, 면적을 나타내는 AUPRC(Area Under the Precision-Recall Curve)로 비교.

```text
[ 검증 데이터 예측 확률 산출 ]
            ↓
[ 확률 값 내림차순 정렬 ]
            ↓
[ 임계값 t를 1.0에서 0.0까지 변경 ]
            ↓
[ 임계값별 혼동행렬 TP·FP·FN 계산 ]
            ↓
[ (재현율, 정밀도) 좌표 기록 ]
            ↓
[ 좌표 연결 후 AUPRC 면적 산출 ]
```

## Ⅲ. PR 곡선의 구조 (흐름)

- 핵심 요약 : 임계값을 올리고 내리는 방향에 따라 정밀도와 재현율이 반대로 움직이는 단일 트레이드오프 구조.

```text
임계값 ↑  →  정밀도 ↑, 재현율 ↓
임계값 ↓  →  재현율 ↑, 정밀도 ↓
```

## Ⅳ. PR 곡선과 ROC 곡선의 비교

- 핵심 요약 : TN(True Negative) 반영 여부가 달라, 불균형 데이터에서 PR 곡선이 양성 탐지 성능 변화에 훨씬 민감함.

| 비교 축 | ROC 곡선 | PR 곡선 |
| --- | --- | --- |
| 축 구성 | X: FPR = FP/(FP+TN), Y: TPR = 재현율 | X: 재현율, Y: 정밀도 |
| TN 반영 | 반영 (FPR의 분모) | 반영 안 됨 |
| 클래스 불균형 민감도 | 둔감 (음성이 많으면 FPR 변화가 작음) | 민감 (FP가 늘면 정밀도가 급락) |
| 무작위 기저선 | 대각선 (AUC 0.5) | 양성 유병률 수평선 |
| 주요 적용 | 양·음성 비율이 비교적 균형인 분류 | 이상 탐지, 금융 사기 탐지(FDS, Fraud Detection System), 희귀 질환 진단 |

## Ⅴ. PR 곡선의 한계와 방안

- 핵심 요약 : 유병률 의존성, 비단조 궤적, 비용 무시가 주요 한계이며 보정과 비용 함수 정의로 제어.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 유병률 변화에 따른 곡선 왜곡 | 검증셋의 양성 비율이 달라지면 곡선 수준이 바뀌어 데이터셋 간 직접 비교 불가 | 유병률 차이를 반영한 PR-Gain 곡선 병행, 유병률 보정 적용 | 데이터셋별 유병률, 보정 전후 비교값 |
| 재현율 구간의 비단조 궤적 | 임계값을 바꿀 때 정밀도가 요동쳐 최적 지점 판단이 어려움 | 보간 정밀도(Interpolated Precision)를 적용해 단조 곡선으로 정리 | 보간 전후 면적 차이 |
| 면적 최대화 기준의 비용 무시 | AUPRC 최대 지점만 고르면 오탐 처리 비용과 미탐 손실액의 차이를 반영하지 못함 | 오탐 비용과 미탐 비용을 넣은 기대 손실 함수를 정의하고 최소 지점에서 운영 임계값 확정 | 총 기대 손실, 오탐·미탐 건수 |

## Ⅵ. PR 곡선에 대한 기술사적 제언

- 핵심 요약 : 지표는 AUPRC와 재현율별 정밀도를 함께 보고, 운영 임계값은 업무 비용으로 정하는 원칙의 확립.

모델 비교는 AUPRC와 재현율 구간별 정밀도를 함께 보고, 운영 임계값은 업무 비용 구조에 맞춰 정하는 것이 바람직하다. 관제 인력의 부담이 큰 업무는 오탐을 억제하는 쪽으로, 누락 손실이 치명적인 업무는 재현율을 우선하는 쪽으로 임계값의 방향을 정해야 한다.

## Ⅶ. 결론

- 핵심 요약 : PR 곡선은 불균형 데이터에서 양성 탐지 성능을 정직하게 보여 주는 평가 도구임.
- 곡선 자체보다 오탐과 미탐의 비용을 반영해 운영 임계값을 확정하는 절차가 실제 운영 결과를 좌우한다.
