## Ⅰ. PR(Precision Recall) 곡선의 개요

- 개념 : 이진 분류 알고리즘에서 결정 임계값의 연속적 변화에 따라 변화하는 **정밀도** (Precision)와 **재현율** (Recall)의 상충 관계를 2차원 평면에 시각화한 평가 모델
- 배경 및 필요성 : 극심한 **클래스 불균형** (Class Imbalance) 환경에서 ROC 곡선의 **위양성 착시** (False Positive Illusion)를 배제할 수 있으나 유병률 변화에 민감하므로 비즈니스 오탐·미탐 비용 함수를 결합한 **최적 운영 임계값** 튜닝 필수
- 핵심 목적 : 양성 클래스가 극히 희소한 불균형 데이터 환경에서 음성 클래스 과대평가 왜곡 없이 양성 탐지력과 오탐 부담을 정밀 측정

## Ⅱ. PR(Precision Recall) 곡선의 핵심 아키텍처 및 동작 메커니즘

PR은 모델의 예측 확률값을 내림차순 정렬한 뒤 임계값을 순차 변경하며 **오차행렬** (Confusion Matrix)의 TP·FP·FN을 산출하여 재현율 축(X축) 대비 정밀도 축(Y축)에 매핑 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             PR 곡선 산출 및 임계값 최적화 엔지니어링 프로세스          │
└────────────────────────────────────────────────────────────────────────┘
 [ 검증 데이터 예측 확률값 산출 (0.00 ~ 1.00) ]
                       │
                       ▼
 [ 예측 확률값 기준 내림차순 정렬 (Descending Sort) ]
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 임계값(Threshold: t) 순차 순회 (1.0 ──> 0.0)                         │
 │                                                                      │
 │  [ Confusion Matrix 산출 ] ──> TP, FP, FN, TN 계측                  │
 │                                                                      │
 │  ├── Recall 계산:    r(t) = TP / (TP + FN)  ──> X축 좌표              │
 │  └── Precision 계산: p(t) = TP / (TP + FP)  ──> Y축 좌표              │
 └─────────────────────┬────────────────────────────────────────────────┘
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 2차원 평면 플로팅 (Plotting) 및 AP 적분                              │
 │                                                                      │
 │   Precision                                                          │
 │   1.0 ┌─────────\                                                    │
 │       │          \─── 우수 모델 (High AUPRC)                         │
 │       │              \                                               │
 │       │               \──────┐                                       │
 │       │                      \                                       │
 │   y_p ├┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈\─── [기저선: 양성 유병률 수평선]      │
 │   0.0 └────────────────────────────\── Recall                        │
 │       0.0                          1.0                               │
 └──────────────────────────────────────────────────────────────────────┘
```

- 정밀도 (Precision) : $Precision = \frac{TP}{TP + FP}$ - 모델이 양성이라 확신한 것 중 진짜의 비율, 모델 예측의 신뢰도 및 오탐(FP) 통제력 대변
- 재현율 (Recall) : $Recall = \frac{TP}{TP + FN}$ - 실제 세상에 존재하는 양성을 빠짐없이 적발한 비율, 미탐(FN) 방지력 및 민감도 대변
- **기저선** (Baseline) : Baseline $= \frac{P}{P + N} = \frac{TP+FN}{TP+FN+FP+TN}$ - 무작위 추측(Random Guess) 시 정밀도는 데이터셋 내 양성 유병률(Prevalence) 수평선에 수렴

## Ⅲ. PR(Precision Recall) 곡선의 세부 구성 요소 및 비교 분석

| 비교 항목 | ROC (Receiver Operating Characteristic) | PR (Precision-Recall) 곡선 (본 토픽) |
|---|---|---|
| **축 구성** | X축: FPR ($FP / (TN+FP)$), Y축: TPR ($TP / (TP+FN)$) | X축: Recall ($TP / (TP+FN)$), Y축: Precision ($TP / (TP+FP)$) |
| **TN(참 음성) 반영 여부** | 반영됨 (FPR의 분모에 TN 포함) | 반영 안 됨 (혼동행렬에서 TN 완전 배제) |
| **클래스 불균형 민감도** | 둔감함 (음성 다수 시 FP가 커져도 FPR 왜곡 미미) | 극도로 민감함 (FP 증가 시 정밀도 즉각 폭락) |
| **무작위 분류 기저선** | 대각선 (AUC = 0.5 고정) | 데이터셋의 양성 비율 수평선 ($P / (P+N)$) |
| **주요 적용 도메인** | 클래스 비율이 5:5에 근접한 일반 분류 문제 | 이상 탐지, 금융 사기(FDS), 희귀 질환 진단 (불균형 극심) |

- PR은 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. PR(Precision Recall) 곡선의 주요 한계점 및 해결 방안

- 데이터셋 양성 유병률(Prevalence) 변화에 따른 PR 곡선 왜곡 :
  - 한계점 : 검증셋의 양성 유병률(Prevalence)에 따라 PR 곡선의 높낮이가 달라져 다른 데이터셋 간 직접 비교 불가.
  - 해결 방안 : 양성 비율 변화를 반영한 정규화 기법인 Precision-Recall-Gain 곡선 병행 또는 베이즈 유병률 보정 적용.
- 재현율 증가 구간에서 정밀도가 요동치는 비단조적(Non-monotonic) 궤적 :
  - 한계점 : 재현율 증가 구간에서 정밀도가 요동치며 비단조적(Non-monotonic) 궤적을 그려 최적 임계값 특정 난항.
  - 해결 방안 : 사후 최대 정밀도 외피선(Maximum Precision Envelope) 보간 기법을 적용하여 단조 감소 곡선 변환.
- 비즈니스 현장의 오탐(FP)과 미탐(FN) 간 손실 비용 격차 무시 :
  - 한계점 : 단순 AUPRC 면적 최대화 지점만을 채택할 경우 비즈니스 현장의 오탐(FP) 처리 인건비와 미탐(FN) 손실액 간의 비용 격차 무시.
  - 해결 방안 : 오탐 비용($C_{FP}$)과 미탐 비용($C_{FN}$)을 매개변수화한 총 기대 손실 비용 함수(Cost Function)를 정의하고 비용 최소화 지점에서 운영 임계값 확정.

## Ⅴ. PR(Precision Recall) 곡선 적용 및 발전을 위한 기술사적 제언

- 지표 선정 중심 엔터프라이즈 고도화 : ROC-AUC 0.99 착시로 조기 배포의 한계를 탈피하고, AUPRC 및 Recall별 정밀도 집중 분석을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 임계값 결정 중심 엔터프라이즈 고도화 : 디폴트 확률 0.5 또는 Youden 지수의 한계를 탈피하고, 오탐 인건비 대비 미탐 사기 피해액 최적점을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 오탐 관제 부담 중심 엔터프라이즈 고도화 : 관제 센터 일일 수만 건 오탐 경보 마비의 한계를 탈피하고, 정밀도를 높게 유지 가능한 임계값 방어를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
