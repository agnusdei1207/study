<details>
<summary>핵심 용어</summary>

- **레그테크(Regulatory Technology, RegTech)** : 조직의 규제 준수 업무에 기술을 적용하는 접근
- **섭테크(Supervisory Technology, SupTech)** : 감독기관의 감독·검사 업무에 기술을 적용하는 접근
- **자금세탁방지(Anti-Money Laundering, AML)** : 자금세탁 위험을 식별·예방·관리하는 통제·절차
- **전자 고객확인(electronic Know Your Customer, e-KYC)** : 전자적 수단을 이용한 고객 신원 확인 절차
- **로봇 프로세스 자동화(Robotic Process Automation, RPA)** : 반복적인 규칙 기반 업무를 소프트웨어 로봇으로 처리하는 자동화 방식
- **자연어처리(Natural Language Processing, NLP)** : 컴퓨터가 사람의 언어 자료를 분석·처리하는 기술 분야
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)** : 시스템이 정해진 방식으로 기능·자료를 요청하고 교환하는 접점
</details>


### Ⅲ. 범위 구분

| 접근 | 수행 주체 | 중심 업무 |
|---|---|---|
| RegTech | 규제 대상 조직 | 준수 의무·통제·보고 |
| SupTech | 감독기관 | 감독·검사·시장 관찰 |

### Ⅳ. 기술·운영 고려사항

| 한계 | 대응 |
|---|---|
| 규제 변경이 시스템 규칙에 늦게 반영될 수 있음 | 공식 원문 확인·업무 영향 분석·변경 승인 절차 |
| 자동 분류·경보의 오탐·누락 | 표본 검증·담당자 판단·이의 처리 |
| 데이터 출처·판정 근거를 추적하기 어려움 | 규칙·모델·자료·결정 이력 기록 |
| 조직 간 데이터 연계로 접근 범위가 넓어질 수 있음 | 목적·권한·보유 기간·전송 보호 통제 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 초기에 규제 판단 전부를 자동화하면 예외·해석 업무가 경직될 수 있음 | 반복적이고 판정 기준이 분명한 확인부터 자동화하고, 법령 해석·예외는 담당자 검토로 남겨 정확성·감사 가능성을 확인하며 확장 |
