## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 인간 능력 지원 → 디지털 휴먼 증강

## 30초 인출

- 본질: **디지털 휴먼 증강은** 센서·소프트웨어·보조 장치로 사람의 인지·감각·신체 활동을 지원하거나 확장하는 기술 적용
- 메커니즘: 사용자 상태·환경 관측 → 개인별 지원 판단 → 정보·물리적 보조 제공 → 사용자 피드백
- 통찰: 한계: 자동 보조가 사용자 의도를 대신 결정하거나 실패 시 위험 확대 → 방안: 중단·수동 전환과 사용자별 안전 시험을 우선 적용

<details><summary>핵심 용어</summary>

- **보조공학** : 활동과 참여를 돕는 제품·서비스·시스템
- **인지 증강** : 정보 탐색·판단·기억 등 인지 작업을 지원하는 기능
- **사용자 통제** : 보조 기능의 범위·중단·수정 권한을 사용자에게 제공하는 원칙

</details>

## 2~4교시 25점 답안

## Ⅰ. 디지털 휴먼 증강의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **디지털 휴먼 증강은** 센서·소프트웨어·보조 장치로 사람의 인지·감각·신체 활동을 지원하거나 확장하는 기술 적용 |
| 목적 | 사용자의 활동 제약을 줄이고 필요한 정보·조작 능력을 보완 |

## Ⅱ. 사용자 통제형 디지털 보조 순환 구조

```text
사용자·환경 상태 ── 필요한 정보 수집 ── 지원 판단
       ▲                                  │
       │                            사용자 선택·승인
       │                                  ▼
       └── 피드백·설정 조정 ← 인지·감각·신체 보조
                                          │ 실패·불편
                                          └─ 중단·수동 전환
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 입력 | 사용자·환경 상태의 필요한 범위 수집 | 민감정보 과다 수집 |
| 판단 | 지원 필요와 강도 결정 | 오탐·사용자 자율성 침해 |
| 보조 | 화면·음성·장치 작동 제공 | 지연·기기 안전 |
| 피드백 | 사용자 수용·실패 사례 반영 | 개인 차이를 무시한 일괄 설정 |

## Ⅲ. 보조공학과 일반 증강 비교

| 구분 | 차이 | 적용 판단 |
|---|---|---|
| 보조공학 | 활동 제약의 완화에 초점 | 접근성·사용자 적합성 우선 |
| 일반 증강 | 편의·생산성 확대에도 적용 | 성과와 안전을 함께 평가 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 지원 기능이 사용자 의도를 대신 결정하거나 실패 시 위험을 키울 수 있음 | 수동 전환·중단 기능과 사용자별 시험을 먼저 확보 |

## Ⅴ. 제언

지원 대상자의 실제 활동에서 실패 시나리오를 먼저 확인하고 사용자 통제권을 기본 조작으로 설계.

## 출제 이력과 검증 출처
