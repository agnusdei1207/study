## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 복합 AI (Composite AI)

## 30초 인출

- 본질: 서로 다른 AI·분석 기법을 과제별로 연결해 단일 기법의 한계를 보완하는 시스템 설계. 과제별 기술의 강점을 결합해 의사결정 품질과 제약 준수 지원.
- 메커니즘: 비정형 인식 → 지식·규칙 검사 → 제약 최적화 → 사람 검토.
- 통찰: 한계: 모듈별 정확도가 높아도 모듈 사이 규칙·데이터 불일치가 결정 오류를 만든다 → 방안: 인식·규칙·최적화의 입출력 계약과 전체 경로의 실패 시험을 함께 수행한다.

<details><summary>핵심 용어</summary>

- **기호 AI:** 규칙·논리·지식 표현을 이용하는 AI 접근
- **복합 AI:** 서로 다른 AI·분석 기법을 과제에 맞게 연결한 시스템

</details>

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 서로 다른 AI·분석 기법을 과제별로 연결해 단일 기법의 한계를 보완하는 시스템 설계. |
| 목적 | 과제별 기술의 강점을 결합해 의사결정 품질과 제약 준수 지원 |

## Ⅱ. 이질적 AI의 역할 분담

```text
비정형 입력 → 신경망 인식·신뢰도
                    ↓ 구조화 결과
              지식·업무 규칙 검사
                    ↓ 허용 후보
              제약 최적화 → 사람 승인
```

1. **설계:** 비정형 데이터 추출, 도메인 규칙 검사, 최적화 문제의 목적함수·제약을 별도 모듈로 명세.
2. **흐름:** 입력 자료·출처 → 신경망 예측과 신뢰도 → 규칙 충돌 표시 → 최적화 후보 → 사람의 승인과 실행 기록.
3. **비교:** 단일 모델 대비 명시적 제약과 다른 데이터 유형을 다루기 쉬우나 통합 오류·지연·유지 비용이 증가 가능.
4. **검증:** 구성 요소별·전체 성능, 규칙 갱신 영향, 실패 시 폴백, 결정 근거와 감사 로그 평가.

## Ⅲ. 앙상블과 복합 AI

| 구분 | 결합 대상 | 핵심 효과 |
|---|---|---|
| 앙상블 | 여러 예측 모델의 출력 | 예측 분산·편향 조정 |
| 복합 AI | 인식·규칙·최적화 등 이질적 기능 | 명시적 제약과 행동 결정 연결 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 언어 모델이 정비 규정을 잘못 인용 — 생성 답변과 승인된 규정의 연결 부족 | 최신 승인 문서 검색과 규칙 검사, 전문가 최종 승인 |
| 대규모 일정 조합을 탐색해야 함 — 예측과 제약 최적화의 문제 성격 차이 | 예측 결과를 정수 계획 등의 입력으로 전달 |
| 부품 교체 권고의 근거가 불명확 — 예측값과 업무 규칙의 연결 부족 | 적용 규칙·입력 자료·판정 경로 기록 |

## Ⅴ. 제언

- 문서 관계 탐색이 중요한 업무에는 그래프 기반 검색과 언어 모델 생성을 결합할 수 있음. 그래프 추출 오류와 답변의 출처 일치 여부를 별도 평가하며 환각의 완전 차단을 전제하지 않음
