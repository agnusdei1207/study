## 지식 로드맵 내 현재 위치

지식 위치: 생성형 AI 응용 → 검색 증강 생성 → **모듈형 RAG 설계**

## 30초 인출

- 본질: **Modular RAG(Modular Retrieval-Augmented Generation)** 는 검색 증강 생성의 기능을 모듈로 나누어 업무에 맞게 조합하는 설계 방식
- 메커니즘: 질문·업무 조건 분석 → 경로·모듈 선택 → 검색 근거 결합 → 응답 평가

<details>
<summary>핵심 용어</summary>

- **검색 증강 생성(Retrieval-Augmented Generation, RAG)** : 외부 자료를 검색해 언어 모델의 응답 문맥으로 제공하는 방식
- **모듈형 검색 증강 생성(Modular Retrieval-Augmented Generation, Modular RAG)** : RAG 기능을 분리해 경로에 따라 조합하는 설계 관점
- **라우팅(Routing)** : 질문·조건에 맞는 검색·처리 경로를 선택하는 기능
- **융합(Fusion)** : 여러 검색 결과를 통합해 후속 처리에 전달하는 과정
- **고급 검색 증강 생성(Advanced RAG)** : 검색 전·중·후의 품질을 높이기 위한 기법을 적용하는 설계 관점

</details>

## 1교시 10점 답안

### Ⅰ. Modular RAG의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **Modular RAG(Modular Retrieval-Augmented Generation)** 는 검색 증강 생성의 기능을 모듈로 나누어 업무에 맞게 조합하는 설계 방식 |
| 목적 | 질의·업무 유형에 맞는 검색·처리 경로 구성과 변경 지원 |

### Ⅱ. 질의별 모듈 구성

```text
질문·업무 맥락
      │
경로 선택
  ┌───┴────────┐
내부 검색   다중 검색·융합
  └────┬───────┘
       ▼
근거 선별·응답 생성
```

### Ⅲ. 모듈 역할

| 모듈 | 역할 |
|---|---|
| 질문 분석·라우팅 | 질문 유형에 따라 처리 경로 선택 |
| 검색·재정렬 | 관련 문서 탐색과 순위 조정 |
| 융합·문맥 구성 | 여러 결과를 응답 근거로 결합 |

**제언:** 기본 경로는 작게 두고 업무 평가로 효과가 확인된 모듈만 추가하는 설계.

## 2~4교시 25점 답안

### Ⅰ. Modular RAG의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **Modular RAG(Modular Retrieval-Augmented Generation)** 는 검색 증강 생성의 기능을 모듈로 나누어 업무에 맞게 조합하는 설계 방식 |
| 목적 | 질의·업무 유형에 맞는 검색·처리 경로 구성과 변경 지원 |

### Ⅱ. 질의별 모듈 구성

```text
질문·업무 맥락
      │
경로 선택
  ┌───┴────────┐
내부 검색   다중 검색·융합
  └────┬───────┘
       ▼
근거 선별·응답 생성
```

모든 질문이 동일한 기능을 거칠 필요는 없으며, 경로별 근거 평가를 거쳐 응답에 활용.

### Ⅲ. 설계 관점과 Advanced RAG 비교

| 구분 | Advanced RAG | Modular RAG |
|---|---|---|
| 중심 질문 | 검색 전후 품질을 어떻게 보강하는가 | 기능을 어떤 모듈로 나누고 연결하는가 |
| 예 | 질의 재작성·재정렬·문맥 압축 | 검색·라우팅·융합·생성·평가 모듈 조합 |
| 관계 | 보강 기법을 모듈로 구현 가능 | Advanced RAG 기법을 경로에 포함 가능 |

```text
질문 분석 ── 검색·재정렬 ── 근거 평가 ── 응답 생성
     └──── 경로 조건에 따라 일부 모듈 선택·생략 ────┘
```

### Ⅳ. 설계·평가와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모듈이 늘면 경로·오류 원인·성능 변화를 파악하기 어려움 | 기본 경로와 모듈 인터페이스를 명시하고 대표 질의의 근거 품질·지연·비용이 개선될 때만 확장 |
