## 답안 골격
```text
[술어 논리] ◀━━ 머리: Ⅶ 내 의견 (지식 기반 인공지능 및 시맨틱 온톨로지 추론의 수학적 기반으로서 1차 술어 논리와 신경망 결합(Neuro-Symbolic) 전략)
 ┃
 ┣━ Ⅰ 개요 ───── 단순 참/거짓만 다루는 명제 논리(Propositional Logic)의 표현력 한계 극복 → 객체 간의 관계와 한정사를 수학적으로 정형화한 술어 논리 대두
 ┣━ Ⅱ 구성요소 ─ 객체(Constant, Variable) + 술어(Predicate) + 함수(Function) + 논리 연결사(∧, ∨, ¬, →, ↔) + 한정사(Quantifier: ∀, ∃)
 ┣━ Ⅲ 분류 ───── 1차 술어 논리(FOL: First-Order Logic, 객체만 한정) vs 고차 술어 논리(Higher-Order Logic, 술어나 함수 자체를 한정)
 ┣━ Ⅳ 추론규칙 ─ 긍정논법(Modus Ponens) · 분해추론(Resolution) · 단일화(Unification) · 스콜렘화(Skolemization)
 ┣━ Ⅴ 비교 ───── 명제 논리(PL) vs 1차 술어 논리(FOL) (단순명제/객체내부구조표현불가/결정가능 vs 객체·관계·한정사표현/높은표현력/반결정가능(Semi-decidable))
 ┗━ Ⅵ 실무 ───── 지식 표현 시 조합 폭증에 따른 지연 / 지식 베이스 불일치(Inconsistency) / 비선형 딥러닝 모델과의 표현 양식 불일치
```
- 필수 키워드: 술어 논리(Predicate Logic) · 1차 술어 논리(FOL) · 전칭 한정사(∀) · 존재 한정사(∃) · 단일화(Unification) · 분해 추론(Resolution) · 지식 베이스
- 기출: 122회 `술어 논리(Predicate Logic)` → Ⅰ~Ⅴ

## 한 줄 본질
- "철수는 사람이다"를 단순히 참(P)으로 뭉개지 않고, '사람(철수)'처럼 대상과 그 대상의 속성·관계를 변수와 기호(∀, ∃)로 쪼개어 컴퓨터가 참과 거짓을 논리적으로 추론하게 만드는 기호 인공지능의 뼈대 언어

## 핵심 그림
```text
[술어 논리(FOL)의 지식 표현 및 단일화 추론 과정]

  [지식 베이스 (KB) 규칙 정의]
  규칙 1: 모든 사람은 죽는다.       -> ∀x ( Man(x) → Mortal(x) )
  규칙 2: 소크라테스는 사람이다.     -> Man(Socrates)
                     │
                     ▼ [단일화 (Unification)]
        치환(Substitution) θ = { x / Socrates }
                     │
                     ▼ [긍정논법 (Modus Ponens) 추론]
  결론 도출: 소크라테스는 죽는다.    -> Mortal(Socrates)
```

## 핵심 용어
- 1차 술어 논리(First-Order Logic): 변수가 개별 객체(Object)만을 가리킬 수 있으며, 술어나 함수 자체를 한정사(∀, ∃)로 수식할 수 없도록 제한한 논리 체계 (계산 가능성과 표현력의 균형)
- 전칭 한정사(Universal Quantifier, ∀): 도메인 내의 '모든' 원소에 대하여 해당 조건이 성립함을 나타내는 기호 (예: ∀x, x는 동물이다)
- 단일화(Unification): 두 개 이상의 서로 다른 논리식을 동일하게 만들기 위해 변수에 적절한 상수나 항(Term)을 치환(Substitution)하는 패턴 매칭 알고리즘

## 핵심 통찰
- "명제 논리의 장벽 돌파": 명제 논리는 "모든 사람은 죽는다"를 표현하려면 세상의 모든 사람에 대해 P1, P2, ... 무한개의 명제를 만들어야 했으나, 술어 논리는 한 줄의 수식 `∀x (Human(x) → Mortal(x))`로 완벽히 정형화함
- 자동 정리 증명(Automated Theorem Proving): 연역적 추론을 기계화하여 분해(Resolution) 반박 증명법을 통해 컴퓨터가 수학적 정리나 논리적 무모순성을 스스로 증명 가능
- 전문가 시스템(Expert System) 및 프롤로그(Prolog)의 토대: 기호주의 인공지능(Symbolic AI)과 온톨로지(OWL), 지식 그래프(Knowledge Graph)의 논리적 추론 엔진으로 동작

## 이웃 토픽과 구분
- 명제 논리 vs 술어 논리: 명제 논리는 문장 전체를 하나의 기호(P, Q)로 보고 진리표를 작성 / 술어 논리는 문장 내부의 주어(상수/변수)와 서술어(술어)를 분리하여 한정사와 함께 복합 관계를 표현

## 문제·원인·대책
- 적용 상황: 의료 진단 전문가 시스템 및 법률 AI의 법조문 판례 논리 추론 엔진 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 수십만 개 법률 조항을 FOL로 변환 시 추론 시간이 무한 루프에 빠짐 | 고차 술어 및 복잡한 중첩 한정사로 인한 반결정 가능성(Semi-decidability) | 표현력을 일부 제한한 기술 논리(Description Logic: SHIQ) 및 Datalog 도입 | 다항 시간(Polynomial Time) 내 결정성 보장 |
| 두 논리 규칙 간의 충돌로 지식 베이스 모순(Contradiction) 발생 | 수작업 규칙 입력 시 예외 조항 누락 및 작업자 간 불일치 | 스콜렘 표준형(Skolem Normal Form) 변환 후 분해 반박(Resolution Refutation) 자동 검증 | 지식 베이스 무결성 100% 유지 |
| 딥러닝 자연어 추출 결과와 기호 논리 엔진 간의 결합 불가 | 벡터 임베딩과 불리언 기호 논리의 데이터 표현 단절 | 신경 기호 인공지능(Neuro-Symbolic AI) 기반의 가변 가중치 논리(Markov Logic) 적용 | 지식 추론의 강건성 및 설명 가능성 동시 확보 |
