## 2~4교시 25점 답안

## Ⅰ. 술어 논리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 개체·속성·관계를 술어·변수·한정자로 표현하는 논리 체계 |
| 목적 | 개체 사이 관계와 적용 범위를 명시하여 규칙 기반 추론 수행 |

## Ⅱ. 양화 표현에서 규칙 적용까지의 추론 구조

```text
개체·관계 사실: Human(socrates)
일반 규칙:     ∀x [Human(x) → Mortal(x)]
                       │ x := socrates 치환
                       ▼
          Human(socrates) → Mortal(socrates)
                       │ 사실과 규칙 결합
                       ▼
                 Mortal(socrates)
```

## Ⅲ. 술어 논리와 명제 논리의 표현 비교

| 구분 | 표현 단위 | 적용 범위 |
|---|---|---|
| 명제 논리 | 참·거짓의 개별 명제 | 개체·관계의 내부 구조 표현 제한 |
| 술어 논리 | 술어·변수·한정자 | ∀·∃로 개체와 관계의 범위 명시 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 일반적인 1차 논리의 유효성 판정은 계산 종료를 보장할 수 없음 | 규칙·도메인·탐색 깊이를 제한하고 추론 결과를 독립 검증 |
| 사실 누락과 개방 세계 가정의 혼동으로 잘못된 결론 가능 | 사실의 출처·완전성과 적용할 세계 가정을 명시 |

## Ⅴ. 제언

지식 그래프나 규칙 엔진에 적용할 때 필요한 관계만 모델링하고 추론 범위와 종료 조건을 먼저 정의.
