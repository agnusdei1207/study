## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 개체·속성·관계를 술어·변수·한정자로 표현하는 논리 체계 |
| 목적 | 관계와 적용 범위의 명시적 표현·추론 |

### Ⅰ. 표현
- P(x), R(x,y), ∀x P(x), ∃x P(x) 등으로 대상과 관계·범위를 명시.

### Ⅱ. 추론

- 변수 치환·단일화와 규칙 적용, 필요 시 절 형식 변환 후 해소 규칙으로 모순 유도.

### Ⅲ. 명제 논리 비교

- 술어 논리는 더 풍부한 관계를 표현하지만 일반적인 1차 논리의 유효성 판정은 결정 가능하지 않음. 증명 절차의 종료 보장과 구분.

### Ⅳ. 실무

- 지식 그래프의 개체·관계 모델, 규칙 엔진의 추론 범위를 제한하고 데이터 품질·개방 세계 가정을 확인.
