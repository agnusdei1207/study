## 연관 키워드

- 술어 논리, 1차 술어 논리(FOL), 양화사, 단일화(Unification), 결의법(Resolution)
- 절 정규형(CNF), 스콜렘화, 호른 절, 기술 논리(Description Logic)
- 반결정성, 지식 베이스, 마르코프 로직 네트워크(MLN)

## Ⅰ. 술어 논리(Predicate Logic)의 개요

- 핵심 요약 : 개체와 속성, 관계를 변수와 양화사로 표현하는 1차 논리 체계로, 지식 베이스와 자동 증명의 기반이 됨.
- 개념 : 개체, 속성, 관계를 변수와 **양화사** (Quantifier)로 표현하는 **1차 술어 논리** (First-Order Logic, FOL) 체계.
- 배경 및 필요성 : 명제 논리는 문장 전체의 참·거짓만 다루어 "모든 사람은 죽는다" 같은 일반 규칙을 표현하지 못함. 전문가 시스템과 지식 베이스가 규칙을 다루려면 개체 내부 구조를 표현하는 논리가 필요함.
- 주요 목적 : 지식 베이스의 의미를 명확히 기술하고, 자동 정리 증명과 연역적 추론을 수행함.

## Ⅱ. 술어 논리(Predicate Logic)의 특징 및 장점

- 핵심 요약 : 개체·술어·함수 표현과 양화사가 일반 규칙을 기술하게 하고, 결의법이 그 규칙으로부터 자동 증명을 가능하게 함.

1. 개체·술어·함수 표현 : 상수, 변수, 술어, 함수로 세계를 구조화 → 하나의 규칙으로 많은 개체에 대한 사실을 기술.
2. **양화사** (∀ 전칭, ∃ 존재) : 규칙이 적용되는 범위를 지정 → "모든 대상"과 "어떤 대상"을 정확히 구분.
3. **결의법** (Resolution) : 질의의 부정을 지식 베이스와 합쳐 모순을 유도 → 질의의 참을 기계적으로 증명.

## Ⅲ. 술어 논리(Predicate Logic)의 구조 (흐름)

- 핵심 요약 : 지식과 질의를 절 집합으로 바꾼 뒤, 단일화와 결의를 반복해 공백절이 나오면 질의가 참임을 증명함.

```text
[ 지식 베이스 + 부정된 질의 ]
          ↓
[ 절 정규형(CNF) 변환 ]
          ↓
[ 단일화(MGU) 후 결의 적용 ]
          ↓
[ 공백절 도출 → 질의 참 입증 ]
```

```text
논리식 구성 요소
  상수·변수 : 개체 지칭
  술어 : 속성 또는 관계 (참·거짓)
  함수 : 개체에서 다른 개체를 반환
  한정자 : ∀ (전칭), ∃ (존재)
```

## Ⅳ. 술어 논리(Predicate Logic)의 비교

- 핵심 요약 : 명제 논리는 결정 가능하지만 표현력이 낮고, 1차 술어 논리는 표현력이 높은 대신 증명이 끝나지 않을 수 있으며, 기술 논리는 그 중간에서 결정 가능성을 확보함.

| 비교 축 | 명제 논리 | 1차 술어 논리 (FOL) | 기술 논리 (Description Logic) |
| --- | --- | --- | --- |
| 기본 단위 | 원자 명제 | 개체, 함수, 술어, 양화사 | 개념, 역할, 개체 |
| 표현력 | 내부 구조 표현 불가 | 일반 수학 체계 표현 가능 | 중간 (FOL의 결정 가능한 부분집합) |
| 추론 결정성 | 결정 가능 | 반결정 가능 (증명 불가 경우 존재) | 결정 가능 (표현력에 따라 복잡도 상이) |
| 계산 복잡도 | 명제 충족 문제(SAT)는 NP-완전 | 일반적으로 결정 불가능 | 표현력에 따라 증가 |
| 대표 활용 | 회로 설계, SAT 솔버 | 정리 증명기, Prolog 계열 | W3C OWL, 온톨로지, 지식 그래프 |

## Ⅴ. 술어 논리(Predicate Logic)의 한계와 방안

- 핵심 요약 : 반결정성에 따른 탐색 중단 불가, 조합 폭발, 이분법적 참·거짓 구조의 한계를 탐색 제한, 규칙 매칭 최적화, 확률 논리 결합으로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 반결정성에 따른 무한 탐색 | 증명되지 않는 질의에서 탐색이 끝나지 않음 | 탐색 깊이 제한, 긍정 호른 절 제약 기반 SLD 분해 적용 | 깊이 제한 도달 건수 |
| 조합 폭발 | 개체와 규칙이 늘면 단일화와 탐색 분기가 급증 | Rete 알고리즘으로 조건 매칭 상태를 캐싱하고 조건 노드 공유 | 규칙 평가 소요 시간 |
| 이분법적 참·거짓 구조 | 불확실한 사실과 확률적 예외를 표현하지 못함 | 마르코프 로직 네트워크(MLN) 또는 확률 소프트 논리(PSL) 결합 | 예측 신뢰도 보정 오차 |

## Ⅵ. 술어 논리(Predicate Logic)에 대한 기술사적 제언

- 핵심 요약 : 추론의 종료를 보장하는 범위에서 논리를 쓰고, 대용량 저장소와 의미 임베딩을 결합해 현실의 예외를 수용하는 방향.

1. 추론 범위 제한 : 지식 기반 시스템을 설계하는 조직은 결정 가능한 논리 부분집합을 기본으로 선택하고, 추론 시간 상한을 서비스 요건에 명시해야 한다.
2. 대용량 저장 : 온톨로지를 운영하는 기관은 트리플 저장소 기반의 그래프 DB를 도입해 질의 성능을 확보하고, 규칙 변경 이력을 함께 관리해야 한다.
3. 예외 대응 : 규칙에 없는 상황은 오류로 멈추기보다, 의미 임베딩을 활용한 대안 추론 경로와 사람의 검토 절차로 처리하는 것이 현실적이다.

## Ⅶ. 결론

- 핵심 요약 : 술어 논리는 개체와 관계를 일반 규칙으로 표현하고 자동 증명하는 지식 표현의 기초 체계임.
- 시사점 : 표현력과 결정 가능성은 서로 맞바꾸는 관계이므로, 응용 목적에 맞는 논리 부분집합을 고르는 것이 설계의 출발점이다.
