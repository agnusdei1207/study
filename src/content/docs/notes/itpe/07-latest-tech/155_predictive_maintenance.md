## 지식 로드맵 내 현재 위치

스마트 제조 → 설비 데이터 → 예지정비

## 30초 인출

- **본질:** 설비 상태 데이터로 고장 가능성과 잔여 유효 수명을 추정해 정비 시점 결정을 지원하는 방식
- **메커니즘:** 설비 센싱 → 상태 진단·고장 가능성 또는 RUL 추정 → 정비 계획
- 통찰: 한계: 고장 기록 부족과 오경보로 예측 결과만으로 정비 시점을 확정하기 어려움 → 방안: 정상 패턴 기반 탐지와 설비별 경보 성능·정비 비용을 검증
- **답안 초점:** 설비 예지정비의 개념과 상태기반정비 및 잔여 유효 수명을 설명하시오.

<details><summary>핵심 용어</summary>

- **예지정비:** 상태 데이터로 고장 가능성을 추정해 정비 판단을 지원하는 방식
- **RUL:** 현재 조건에서 추정한 잔여 유효 수명으로 확정 고장 시각이 아님

---

## 2~4교시 25점 답안

## Ⅰ. 설비 예지정비의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 설비 상태로 고장 가능성 또는 잔여 유효 수명을 추정하여 정비를 지원하는 방식 |
| 목적 | 비계획 중단과 불필요한 교체를 줄이고 정비 우선순위 결정 |

## Ⅱ. 설비 신호에서 정비 결정까지의 구조

```text
진동·온도·전류 ── 신호 처리·특성 추출 ── 상태 평가
                                           │
                            이상 점수 / 고장 유형 / RUL 추정
                                           │ 불확실성·경보 기준
                                           ▼
                          담당자 확인 → 작업 지시·정비 이력
                                           └─ 실제 고장·정비 결과 환류
```

## Ⅲ. 고장 기록 규모에 따른 모델 선택

| 자료 조건 | 후보 방식 | 검증 기준 |
|---|---|---|
| 고장 이력 충분 | 지도학습 기반 고장 분류·RUL | 고장 유형별 사전 경고 시간 |
| 고장 이력 희소 | 정상 패턴 기반 이상 탐지·물리 모델 | 오탐·미탐과 정비 비용 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 희소한 고장 사례로 모델 학습·성능 추정 불안정 | 정상 패턴 기반 탐지와 물리 모델을 비교하고 설비별 검증 |
| 오경보가 잦으면 불필요한 정비와 경보 무시 증가 | 경보 후 담당자 확인, 사전 경고 시간·정비 비용 기준 조정 |

## Ⅴ. 제언

중단 비용이 큰 설비부터 경보 임계값과 확인 절차를 정하고 실제 정비 결과로 모델을 재평가.
