## 답안 골격
```text
[예지정비(PdM)] ◀━━ 머리: Ⅶ 내 의견 (디지털 트윈과 시계열 이상탐지 AI를 융합한 잔여 유효 수명(RUL) 예측 기반 무중단 스마트 팩토리 구현)
 ┃
 ┣━ Ⅰ 개요 ───── 사후 정비(BM)의 가동 중단(Downtime) 손실과 예방 정비(PM)의 과잉 교체 비용 극복 → 설비 상태 센싱 기반 고장 사전 예측(PdM) 패러다임 전환
 ┣━ Ⅱ 특징 ───── 데이터 주도(Data-Driven) · 상태 기반(CBM) · 비파괴 상시 감시 · 잔여 수명(RUL) 정량화 · 정비 비용 최소화
 ┣━ Ⅲ 구조 ───── IoT 센싱 계층(진동, 온도, 초음파, 전류) + 엣지 전처리 계층(FFT 변환) + AI 이상탐지/예측 계층(Autoencoder, LSTM) + ERP/MES 정비 연계 계층
 ┣━ Ⅳ 단계 ───── ① 다종 센서 실시간 수집 → ② 신호 전처리 및 주파수 특징 추출 → ③ 정상 패턴 대비 이상 징후 탐지 → ④ 잔여 유효 수명(RUL) 산출 → ⑤ 최적 부품 교체 일정 자동 발행
 ┣━ Ⅴ 비교 ───── 사후 정비(BM) vs 예방 정비(PM) vs 예지 정비(PdM) (고장발생후수리/최대다운타임 vs 주기적선제교체/과잉비용 vs 센서데이터기반고장예측/적기정비최저비용)
 ┗━ Ⅵ 실무 ───── 산업 현장 고장 데이터 희소성(Normal vs Anomaly 불균형) / 복합 진동 노이즈 환경 / 레거시 설비 센서 부착 한계
```
- 필수 키워드: 예지정비(Predictive Maintenance) · CBM(상태기반정비) · RUL(잔여유효수명) · FFT(고속푸리에변환) · 오토인코더(Autoencoder) · 시계열 이상탐지 · 스마트 팩토리
- 제132회 정보관리기술사 4교시 3번: LangChain을 활용한 설비 예지정비 시스템 구축 방안 중 개념·필요성 포함(공식 Q-Net 문제지 대조). 아래 단독 문항은 예상문제

## 한 줄 본질
- 공장 기계가 부서진 뒤 고치거나 멀쩡한 부품을 달력만 보고 바꾸는 낭비를 끝내고, 진동과 온도의 미세한 떨림을 AI로 감시하여 고장 나기 직전 정확한 타이밍에 부품을 교체하는 지능형 설비 관리

## 핵심 용어
- CBM(Condition-Based Maintenance): 사전에 정해진 달력 주기가 아닌, 센서로 측정한 장비의 물리적 상태(진동, 마모도, 압력)에 기반하여 정비 시점을 결정하는 유지보수 방식
- RUL(Remaining Useful Life): 현재 시점부터 설비나 부품이 허용 가능한 안전 한계치에 도달하여 고장 나기까지 남은 운용 가능 시간(잔여 유효 수명)
- FFT(Fast Fourier Transform): 시간에 따라 급격히 변화하는 복잡한 센서 진동 파형 신호를 주파수 성분별 스펙트럼으로 초고속 분해하여 특정 결함 주파수를 식별하는 알고리즘

## 핵심 통찰
- "정비 패러다임의 4단계 진화": 고장 후 수리하는 1세대 BM(Breakdown) → 일정 주기마다 교체하는 2세대 PM(Preventive) → 센서 임계치 경보를 주는 3세대 CBM → AI로 고장 시점을 예측하는 4세대 PdM
- 산업 데이터의 불균형: 고장 사례가 적은 설비에서는 지도학습용 고장 표본이 부족할 수 있음. 정상 데이터 기반 이상 탐지, 물리 모델, 고장 이력이 있는 경우의 지도학습을 데이터 조건에 맞게 선택
- 다운타임 비용의 극적 절감: 반도체 팹이나 화학 플랜트에서 불시 정지 1시간은 수십억 원의 손실을 유발하므로, 예지정비 도입 시 연간 수백억 원의 Opex 절감 효과 발생

## 이웃 토픽과 구분
- 예방 정비(Preventive Maintenance) vs 예지 정비(Predictive Maintenance): 예방 정비는 기계 상태와 상관없이 '주기(Time-based, 예: 3개월마다)'에 따라 부품을 선제 교체 / 예지 정비는 '센서 데이터와 AI 예측(Condition-based)'을 통해 고장 직전에 필요한 부품만 적기 교체

## 문제·원인·대책
- 아래 사례의 조건·수치는 가상 예시이며 실제 성과가 아님.
- 적용 상황: 제철소 고로 압연 롤러 설비에 AI 기반 예지정비 시스템 도입
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 고장 데이터 부족으로 지도학습 딥러닝 모델의 학습 불가 | 설비 신뢰성이 높아 실제 고장 이력 샘플 극소수 존재 | 정상 진동 데이터 기반 LSTM Autoencoder 재구성 오차 기반 이상 탐지 채택 | 비지도 이상 징후 조기 포착 성공 |
| 공장 내 다른 대형 모터 진동 노이즈가 유입되어 롤러 결함 오경보 빈발 | 광대역 아날로그 센싱 신호에 공진 및 환경 노이즈 혼입 | 웨이블릿 변환(Wavelet Transform) 기반 잡음 제거 및 밴드패스 필터링 적용 | 신호 대 잡음비(SNR) 20dB 개선 및 오경보 90% 차단 |
| 수천 대 센서의 원시(Raw) 진동 데이터 클라우드 전송 시 네트워크 대역폭 고갈 | 초당 수천 Hz의 고주파 가속도 센서 데이터 무압축 전송 | 엣지 컴퓨팅 디바이스에서 로컬 FFT 특징 벡터 추출 후 특징치만 전송 | 네트워크 전송 트래픽 98% 절감 |

## 1교시 예상문제 (10점)
- 설비 예지정비의 개념과 상태기반정비 및 잔여 유효 수명을 설명하시오.

## 1교시 10점 답안
- **정의:** 설비 상태 데이터를 이용해 고장 가능성과 시기를 추정하고 정비 의사결정을 지원하는 방식.
- **구성:** 센서 수집·신호 처리 → 이상 탐지·상태 진단 → RUL 추정 → 정비 계획·피드백.
- **구분:** 주기 기반 예방 정비와 달리 관측 상태를 반영하며, RUL은 정확한 고장 시각이 아닌 조건부 추정치.

## 2~4교시 예상문제 (25점)
- 설비 예지정비 시스템의 구성과 고장 데이터 희소성·오탐 대응을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 목적
- 계획되지 않은 중단과 불필요한 교체를 함께 줄이기 위해 상태 증거로 정비 우선순위 결정.
### Ⅱ. 구조
- 진동·온도·전류 수집 → FFT 등 신호 처리 → 이상·고장 유형 분석 → RUL 불확실성 추정 → 작업 지시·이력 기록.
### Ⅲ. 모델 선택
- 고장 이력이 충분하면 지도학습, 부족하면 정상 패턴 기반 탐지·물리 모델 등 비교. 오토인코더 재구성 오차와 Isolation Forest 이상 점수 구분.
### Ⅳ. 검증
- 설비별 오탐·미탐·사전 경고 시간·정비 비용 평가. 경보 후 사람 확인과 재학습 기준 마련.
