## 연관 키워드

- 예지정비(PdM, Predictive Maintenance), 상태 기반 정비(CBM), 사후 정비(BM), 예방 정비(PM)
- 잔여 수명(RUL, Remaining Useful Life), 이상 탐지(Anomaly Detection), 디지털 트윈(Digital Twin)
- 특징 공학(Feature Engineering), FFT, 비계획 정지(Unplanned Downtime), 오탐, 신호 드리프트(Drift)
- EAM, CMMS, ERP, FMEA, SCADA, PLC

## Ⅰ. 예지정비(Predictive Maintenance)의 개요

- 핵심 요약 : 설비 상태 데이터를 AI로 분석해 고장 시점을 미리 추정하고, 최적 시점에 정비하는 설비 자산 관리 방식.
- 개념 : 진동·온도·전류·음향 같은 설비 상태 데이터를 IoT(Internet of Things) 센서로 상시 수집하고, 머신러닝과 물리 모델로 이상 징후를 조기에 찾아 고장 전에 정비를 수행하는 **예지정비** (PdM, Predictive Maintenance).
- 배경 및 필요성 : 정상 가동 데이터는 대부분이고 고장 데이터는 극히 적어 학습 데이터가 심하게 불균형하므로, 정상 패턴만으로 학습하는 비지도 이상 탐지와 **디지털 트윈** 기반 데이터 보강 체계가 필요해짐.
- 주요 목적 : **비계획 정지** (Unplanned Downtime)를 줄이고, 부품 수명을 충분히 쓰면서 정비 비용과 설비 사고 위험을 낮추는 것.

## Ⅱ. 예지정비(Predictive Maintenance)의 특징 및 장점

- 핵심 요약 : 센서 신호의 열화 추세를 학습해 계획 정비를 가능하게 하여, 돌발 정지와 조기 교체를 함께 줄이는 방식.

1. 상태 기반 열화 탐지 : 센서 신호를 특징값으로 바꿔 정상 기준선에서 벗어나는 추세를 포착 → 고장 전 징후를 미리 알고 계획 정비 가능.
2. 잔여 수명 추정 : **잔여 수명** (RUL, Remaining Useful Life, 고장까지 남은 사용 기간)을 확률로 산출 → 부품을 한계 가까이까지 활용해 조기 교체 축소.
3. 작업 시스템 연계 : 진단 결과를 EAM(Enterprise Asset Management)과 CMMS(Computerized Maintenance Management System)의 작업 지시로 연결 → 정비 대기 시간과 재고 누락 감소.

- 열화 추세를 이용한 판단 흐름은 다음과 같다.

```text
[ 정상 기준선 학습 ]
        ↓
[ 실시간 신호와 편차 계산 ]
        ↓
[ 열화 추세 누적 (건전성 지수) ]
        ↓
[ 잔여 수명 추정 → 정비 시점 결정 ]
```

## Ⅲ. 예지정비(Predictive Maintenance)의 구조 (흐름)

- 핵심 요약 : 센서 수집, 특징 추출, 이상 탐지, 수명 예측, 작업 연계로 이어지는 5단계 파이프라인.
- 구성 요소 : 엣지에서 신호를 전처리하고 **특징 공학** (Feature Engineering)으로 시간 영역 지표(RMS, 첨도)와 주파수 영역 지표(FFT(Fast Fourier Transform), 웨이블릿 변환)를 만든다. 이상 탐지에는 오토인코더 재구성 오차나 Isolation Forest 같은 비지도 기법을 쓰고, 베어링 결함은 BPFO·BPFI 같은 결함 주파수와 대조한다.

```text
[ 1. 센서 신호 수집 ]
  진동·온도·전류·음향
        ↓
[ 2. 특징 추출 ]
  시간 영역: RMS, 첨도
  주파수 영역: FFT, 웨이블릿
        ↓
[ 3. 이상 탐지·진단 ]
  비지도: 오토인코더, Isolation Forest
        ↓
[ 4. 잔여 수명 예측 ]
  시계열 딥러닝 기반 열화 추정
        ↓
[ 5. 정비 작업 연계 ]
  EAM·CMMS 지시, 부품 발주 연계
```

## Ⅳ. 예지정비(Predictive Maintenance)의 비교

- 핵심 요약 : 사후 정비에서 예지 정비로 갈수록 정비 시점이 최적에 가까워지지만, 데이터와 인프라 투자 비용은 함께 커짐.
- 정비 방식 : **사후 정비** (BM, Breakdown Maintenance), **예방 정비** (PM, Preventive Maintenance), **상태 기반 정비** (CBM, Condition-Based Maintenance), 예지 정비(PdM)를 비교한다.

| 비교 축 | 사후 정비 (BM) | 예방 정비 (PM) | 상태 기반 정비 (CBM) | 예지 정비 (PdM) |
| --- | --- | --- | --- | --- |
| 실행 기준 | 설비 고장 발생 | 정해진 시간 또는 가동 주기 | 센서 임계치 초과 | 모델이 예측한 잔여 수명 도달 전 |
| 정비 시점 | 돌발 시점 | 이른 편 (부품 조기 교체) | 고장 임박 시점 | 경제적으로 최적인 시점 |
| 다운타임 | 가장 큼 (라인 정지 연쇄) | 정기 점검 시 발생 | 돌발 중단 완화 | 계획 정비로 비계획 정지 최소화 |
| 부품 활용률 | 한계 초과로 파손 위험 | 낮음 | 적정 | 높음 |
| 요구 기술 | 현장 수리 역량 | 일정 관리 도구 | SCADA(Supervisory Control and Data Acquisition), PLC(Programmable Logic Controller) 경보 설정 | 빅데이터, MLOps(Machine Learning Operations), 신호 처리 |
| 구축 비용 | 낮음 | 낮음 | 중간 (센서와 경보 장치) | 높음 (AI 플랫폼, IoT, 디지털 트윈) |

- 선택 기준 : 설비의 고장 비용과 센서 설치 여건, 데이터 축적 수준에 따라 방식을 고르고, 예지 정비는 고가·고위험 설비부터 적용하는 것이 현실적이다.

## Ⅴ. 예지정비(Predictive Maintenance)의 한계와 방안

- 핵심 요약 : 고장 데이터 부족, 오탐, 센서 신뢰성 저하를 학습 방식, 맥락 정보, 센서 자가 진단으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고장 데이터 희소성 | 고장 사례가 적어 지도 학습이 어려움 → 탐지 성능 불안정 | 정상 데이터만 쓰는 One-Class 학습, 디지털 트윈 기반 합성 고장 신호 증강 | 탐지 재현율, 미탐지 건수 |
| 공정 부하·환경 변화에 따른 오탐 | 신호 왜곡을 설비 이상으로 오판 → 과잉 정비 | 회전수와 작업 오더를 함께 보는 맥락 인식 필터링, FMEA(Failure Mode and Effects Analysis) 연계 교차 검증 | 오탐률, 불필요 정비 건수 |
| 센서 노후화·신호 드리프트 | 센서 자체 오류가 설비 이상으로 보임 | 진동·전류·온도를 결합한 다중 센서 융합 판단, 센서 자가 진단 | 센서 교정 준수율, 드리프트 감지 건수 |

## Ⅵ. 예지정비(Predictive Maintenance)에 대한 기술사적 제언

- 핵심 요약 : 이상 확률 표시를 넘어 처방형 정비와 물리 모델 결합, 자원 연계까지 갖춘 운영 체계로 발전시키는 것이 필요함.

1. 진단에서 처방으로 : 이상 확률 그래프만으로는 현장이 움직이지 않으므로, 교체 시점과 필요 부품을 함께 알려 주는 처방형 알림으로 발전시켜야 한다.
2. 물리 모델과 데이터의 결합 : 통계 패턴만으로는 처음 보는 고장 유형을 설명하기 어려우므로, 설비 역학 모델을 함께 쓰는 하이브리드 진단을 설계 단계부터 포함해야 한다.
3. 정비 자원의 자동 연계 : 부품 재고와 작업 일정을 ERP(Enterprise Resource Planning)와 CMMS가 자동으로 맞물리게 하여 수기 확인을 줄이고, 정비 계획과 생산 계획을 함께 최적화해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 예지정비는 설비 데이터를 고장 예측과 계획 정비로 바꾸는 자산 관리 체계.
- 시사점 : 신호 품질과 오탐 관리가 뒷받침될 때만 비계획 정지 감소 효과가 지속되므로, 센서 데이터의 품질 확보가 도입의 출발점이다.
