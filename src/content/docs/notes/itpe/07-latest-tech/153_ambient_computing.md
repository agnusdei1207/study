## 2~4교시 25점 답안

## Ⅰ. 앰비언트 컴퓨팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 주변 환경의 센서·기기로 사용자 맥락을 감지하고 상황에 맞는 서비스를 제공하는 방식 |
| 목적 | 명시적 조작 부담을 줄이면서 적절한 환경·기기 지원 제공 |

## Ⅱ. 맥락 인식과 사용자 통제의 서비스 구조

```text
환경·기기 센서 ── 필요한 신호만 수집 ── 맥락 해석
                                          │ 정책·권한 확인
                                          ▼
                                 서비스 제안 또는 기기 동작
                                          │ 사용자 승인·취소
                                          ▼
                                   피드백·설정 조정
```

## Ⅲ. 구성 요소와 적용 조건

| 요소 | 역할 | 적용 확인 |
|---|---|---|
| 센서·네트워크 | 위치·환경·상태 입력 | 수집 범위·연결 안정성 |
| 맥락 모델·정책 | 입력 해석과 실행 조건 판단 | 오탐·미탐과 사용자별 규칙 |
| 기기 연동 | 실제 서비스·제어 실행 | Matter 지원 범위와 연동 시험 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 맥락 오인식으로 원치 않는 자동 실행 | 민감 동작은 사용자 승인·취소 경로와 실패 복구 기능 제공 |
| 상시 센싱으로 생활 정보 과다 노출 | 최소 수집·보관 기한 설정과 가능한 로컬 처리 |

## Ⅴ. 제언

스마트홈 적용 시 자동 실행의 위험 수준별 승인 기준을 먼저 정하고 실제 기기 연동·취소 절차를 시험.
