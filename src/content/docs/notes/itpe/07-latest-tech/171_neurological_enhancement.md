## 30초 인출

- 본질: 질병 치료 목적 밖에서 인지·감각·운동 기능의 향상을 추구하는 신경 기술 활용. 치료 목적 밖에서 인지·감각·운동 기능의 향상을 추구.
- 메커니즘: 전기·자기 자극 또는 신경 피드백 → 신경 활동 변화 시도 → 기능·부작용 평가.
- 통찰: 한계: 건강인에서의 단기 과제 향상은 지속 효과와 안전성을 입증하지 못한다 → 방안: 대조군·추적 기간·이상반응을 정하고 독립 감독 아래 효능과 위험을 평가한다.

- **신경 피드백:** 측정한 신경 활동을 이용자에게 되돌려주는 학습 방식

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 질병 치료 목적 밖에서 인지·감각·운동 기능의 향상을 추구하는 신경 기술 활용. |
| 목적 | 치료 목적 밖에서 인지·감각·운동 기능의 향상을 추구 |

## Ⅱ. 자극·피드백과 효과 검증

```text
자극 또는 신경 피드백 → 신경 활동 변화 시도
                              ↓
                      인지·감각·운동 과제 측정
                              ↓
                    대조군·부작용·지속성 평가
```

1. **근거 평가:** 과제별 인지 지표와 대조군, 위약 효과, 효과 지속 기간, 개인별 차이를 검증. 특정 자극법의 일반적 효능 단정 금지.
2. **안전:** 자극 강도·위치·빈도는 임의 처방하지 않고 의료 전문가·연구 심의와 부작용 감시 체계 적용.
3. **윤리:** 직장·학교의 사용 압력, 미성년자·취약집단, 비용 접근성, 장기간 사용의 불확실성 검토.
4. **정보 통제:** 뇌 신호 최소 수집, 목적 외 사용 금지, 이용자의 철회·삭제 절차와 독립 감독.

## Ⅲ. BCI와 신경 향상

| 구분 | 중심 대상 | 평가 질문 |
|---|---|---|
| BCI | 신경 신호를 기기 입력으로 변환 | 명령 정확도·지연 |
| 신경 향상 | 치료 밖 기능 변화 목적 | 효과 지속성·안전·동의 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 자극 중 두피 불편감·두통 등 발생 — 사용자·장치·자극 조건의 차이 | 적격성 확인과 중단 기준, 이상반응 기록 |
| 장기 사용의 효과·안전성 불확실 — 장기·반복 사용 자료 부족 | 임의 사용량을 권장하지 않고 통제된 연구에서 추적 |
| 직장 내 기기 사용 압력과 평가 갈등 — 동의·접근성·성과 평가 규칙 부재 | 자발적 참여와 거부권, 개인정보 처리 기준 수립 |

## Ⅴ. 제언

- 인지 기능 향상 기기의 사용 범위와 실증 수준을 구분하고, 개인의 동의·거부권·신경 데이터 접근·안전성 감시를 제품 및 조직 정책에 반영
