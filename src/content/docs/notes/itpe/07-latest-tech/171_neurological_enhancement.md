## 답안 골격
### 1교시 예상문제 (10점)
신경 향상의 개념과 신경 치료와의 차이, 주요 기술을 설명하시오.

### 1교시 10점 답안
- **정의:** 질병 치료 목적 밖에서 인지·감각·운동 기능의 향상을 추구하는 신경 기술 활용.
- **기술:** 비침습 자극(tDCS·TMS), 신경 피드백, 침습적 신경 조절 등. 적용 대상과 증거 수준은 기술별 차이.
- **구분:** 치료는 특정 질환·손상에 대한 임상 목표, 향상은 건강인에게 기대하는 성능 변화로 이득·위험·동의 판단 기준의 차이.

### 2~4교시 예상문제 (25점)
신경 향상 기술 도입의 효과 검증과 안전·윤리·개인정보 통제 방안을 설명하시오.

### 2~4교시 25점 답안
1. **근거 평가:** 과제별 인지 지표와 대조군, 위약 효과, 효과 지속 기간, 개인별 차이를 검증. 특정 자극법의 일반적 효능 단정 금지.
2. **안전:** 자극 강도·위치·빈도는 임의 처방하지 않고 의료 전문가·연구 심의와 부작용 감시 체계 적용.
3. **윤리:** 직장·학교의 사용 압력, 미성년자·취약집단, 비용 접근성, 장기간 사용의 불확실성 검토.
4. **정보 통제:** 뇌 신호 최소 수집, 목적 외 사용 금지, 이용자의 철회·삭제 절차와 독립 감독.

```text
[신경 향상(Neurological Enhancement)] ◀━━ 머리: Ⅶ 내 의견 (비침습 신경 조절 기술 기반 인지 역량 증강과 신경 윤리(Neuroethics)·인지적 자유(Cognitive Liberty) 보장 체계)
 ┃
 ┣━ Ⅰ 개요 ───── 질병 치료(Therapy)의 경계를 넘어, 건강한 인간의 기억력·집중력·학습 능력·감정 제어를 신경공학 기술로 향상(Enhancement)시키는 패러다임
 ┣━ Ⅱ 분류 ───── 물리적 전기/자기 자극(tDCS, TMS) + 뇌 심부 자극(DBS) + 신경 피드백(Neurofeedback) + 약리학적 향상(스마트 드럭, Nootropics)
 ┣━ Ⅲ 기술 ───── 경두개 직류자극(tDCS) · 경두개 자기자극(TMS) · 폐루프 신경 조절(Closed-loop Neuromodulation) · AI 실시간 뇌파 최적화
 ┣━ Ⅳ 메커니즘 ─ ① 뇌파(EEG) 및 인지 상태 실시간 측정 → ② 타깃 대뇌피질(전두엽 등) 특정 → ③ 미세 전류/자기 펄스 인가 → ④ 시냅스 가소성(LTP) 유도 및 집중력 극대화
 ┣━ Ⅴ 비교 ───── 신경 치료는 진단된 질환·손상의 임상 목표, 신경 향상은 건강인에게 기대하는 성능 변화. 효과·안전성의 근거 수준과 동의·윤리 기준을 별도 평가
 ┗━ Ⅵ 실무 ───── 장기적 뇌 신경 회로 부작용 / 강제적 직무 향상 요구(인지적 강제) / 신경 격차(Neuro-divide)에 따른 사회적 불평등
```
- 필수 키워드: 신경 향상(Neurological Enhancement) · 경두개 직류자극(tDCS) · 경두개 자기자극(TMS) · 신경 가소성(Neuroplasticity) · 폐루프 신경 조절 · 인지적 자유(Cognitive Liberty) · 신경 윤리
- 출제 이력: 공식 문제지 원문과 대조하지 않아 출제 여부를 단정하지 않음.

## 한 줄 본질
- 신경 향상은 질환 치료 목적을 벗어난 인지 기능 변화 시도를 가리키며, 건강한 사람에게서 효과와 장기 안전성은 자극 방식·개인별로 검증 필요

## 핵심 그림
```text
[폐루프(Closed-Loop) 신경 향상 시스템 동작 구조]

   [인간 두뇌 (작업 수행: 집중력/기억력 저하 감지)]
         │                               ▲
         │ (뇌파 신호 실시간 측정)        │ (개인 맞춤형 미세 자극)
         ▼                               │
   ┌─────────────────────────────┐       │
   │ 1. 인지 상태 모니터링 (EEG) │       │
   │    - 세타파/베타파 비율 계산 │       │
   │    - 피로도, 집중도 인덱싱  │       │
   └─────────────┬───────────────┘       │
                 │                       │
                 ▼                       │
   ┌─────────────────────────────────────┴───────────────────────┐
   │ 2. AI 신경 조절 파라미터 최적화 (Neural Modulation AI)     │
   │    - 대상·자극 방식·안전 한계의 연구 계획                   │
   │    - 인지 과제 결과와 부작용의 독립 평가                     │
   └─────────────────────────────────────────────────────────────┘
```

## 핵심 용어
- tDCS(Transcranial Direct Current Stimulation): 두피에 부착한 전극을 통해 1~2mA 수준의 미세한 직류 전류를 흘려보내 신경세포의 막전위를 변화시키고 뇌 피질의 활성도를 조절하는 비침습 자극술
- 신경 가소성(Neuroplasticity): 경험, 학습, 외부 자극에 반응하여 뇌 신경세포 간의 연결 구조와 시냅스 강도가 스스로 재배열되고 변화하는 뇌의 유연한 적응 능력
- 인지적 자유(Cognitive Liberty): 자신의 정신적·인지적 상태를 스스로 통제하고, 외부의 강제적인 신경 조절이나 감시로부터 두뇌를 보호받을 수 있는 기본적 인권

## 핵심 통찰
- 치료에 승인된 사용과 건강한 사람의 능력 향상 목적 사용을 구분. 후자의 효과·안전성을 전자에서 자동 추론할 수 없음
- 인지 과제별 효과와 부작용은 연구 설계에 따라 달라지며 다른 능력 저하를 일반 법칙으로 단정할 근거 없음
- 직장에서의 인지 도핑 강제 위험: 기업이 생산성을 위해 직원들에게 신경 향상 기기 착용을 암묵적으로 강요할 수 있으므로, 거부할 권리인 '신경 자결권'의 확립이 시급함

## 이웃 토픽과 구분
- BCI vs 신경 향상: BCI(Brain Computer Interface)는 뇌파를 읽어 컴퓨터나 로봇을 '조작'하는 인터페이스 기술 / 신경 향상(Neurological Enhancement)은 뇌 자체에 자극을 주어 두뇌의 '성능과 인지력'을 끌어올리는 기술

## 문제·원인·대책
- 적용 상황: e스포츠 선수 및 항공 관제사를 위한 비침습 인지 집중력 향상 웨어러블 도입
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 자극 중 두피 불편감·두통 등 발생 | 사용자·장치·자극 조건의 차이 | 적격성 확인과 중단 기준, 이상반응 기록 | 부작용 빈도와 중단 후 상태를 연구 조건에서 확인 |
| 장기 사용의 효과·안전성 불확실 | 장기·반복 사용 자료 부족 | 임의 사용량을 권장하지 않고 통제된 연구에서 추적 | 인지 효과와 안전성의 지속 여부 확인 |
| 직장 내 기기 사용 압력과 평가 갈등 | 동의·접근성·성과 평가 규칙 부재 | 자발적 참여와 거부권, 개인정보 처리 기준 수립 | 강제 사용 및 불이익 여부 점검 |
