## 30초 인출

- 본질: **합성 데이터(Synthetic Data)** 는 실제 현실에서 직접 채집하지 않고 수학적 통계 모델, 생성 모델(GAN/Diffusion/LLM) 또는 물리 시뮬레이션을 통해 인위적으로 생성된 원본 데이터의 통계적 속성을 모사한 데이터셋
- 메커니즘: 원천 데이터의 결합 확률 분포를 학습하거나 도메인 규칙을 정의한 후 차등 프라이버시(DP) 노이즈를 주입하여 생성하고, 충실도(Fidelity)·유용성(Utility)·프라이버시(Privacy)를 3차원 검증
- 통찰: 합성 데이터를 반복 재학습에 사용할 경우 꼬리 분포가 증발하여 모델 출력이 단순화되는 모델 붕괴(Model Collapse)가 발생하므로 원본 데이터 혼합 비율 통제 및 필터링 필수

<details><summary>핵심 용어</summary>

- **합성 데이터 (Synthetic Data)** : 실제 개인정보나 물리적 수집 제약을 회피하기 위해 알고리즘에 의해 인공적으로 생성된 고품질 데이터셋.
- **충실도 (Fidelity)** : 생성된 합성 데이터가 원본 실제 데이터의 통계적 분포, 상관관계, 다변량 결합 확률을 얼마나 정밀하게 모사하는지 측정하는 척도.
- **유용성 (Utility)** : 합성 데이터로 훈련된 머신러닝 모델이 실제 테스트 데이터셋에서 달성하는 다운스트림 예측 성능 (F1-Score, mAP 등).
- **차등 프라이버시 (Differential Privacy, DP)** : 데이터셋에 단 한 사람의 데이터가 포함되거나 제외되어도 출력 확률 분포의 변화를 엄격히 제한(ε, δ)하는 수학적 프라이버시 보호 기준.
- **모델 붕괴 (Model Collapse)** : 생성 AI가 생성한 합성 데이터만을 재귀적으로 반복 학습할 때 데이터 다양성이 소실되고 생성 능력이 퇴화하는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 합성 데이터의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **합성 데이터(Synthetic Data)** 는 실제 물리적 관측이나 사람으로부터 직접 수집하지 않고, 통계적 모델링, 딥러닝 생성 알고리즘(GAN, VAE, Diffusion, LLM), 또는 3D 물리 시뮬레이터를 통해 가상으로 합성 생성한 대체 데이터셋 |
| 목적 | 민감 개인정보(PII) 유출 위험 원천 차단, 클래스 불균형 및 희귀 케이스(Corner Case) 해소, 데이터 수집·라벨링 비용 절감 |

## Ⅱ. 합성 데이터의 핵심 특징 및 3대 평가 척도 속성

| 구분 | 핵심 3대 평가 척도 | 세부 공학적 검증 메커니즘 |
|---|---|---|
| **충실도 (Fidelity)** | 통계적 분포 유사성 | 원본과 합성 데이터 간의 상호 상관관계 행렬, 쿨백-라이블러 발산(KLD), 바서슈타인 거리 측정 |
| **유용성 (Utility)** | 다운스트림 모델 성능 | 합성 데이터로 훈련한 모델과 실제 데이터로 훈련한 모델 간의 예측 정확도(F1/AUC) 비교 (TSTR 검증) |
| **프라이버시 (Privacy)** | 재식별 위험 차단 | 원본 샘플의 단순 복제(Memorization) 여부 확인, 멤버십 추론 공격(MIA) 방어율, 차등 프라이버시 계수(ε) |

## Ⅲ. 합성 데이터 생성 및 프라이버시 검증 파이프라인

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 엔터프라이즈 합성 데이터 생성 및 검증 파이프라인 ]       │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 1. 원천 데이터 분석 및 기획 ] ───► [ 2. 생성 모델 학습 및 노이즈 주입 ]
  - 민감정보 식별, 스키마 정의       - CTGAN / TabDDPM / LLM Generator
  - 상관관계 및 결측치 프로파일링     - 차등 프라이버시(DP-SGD) 클리핑 및 가우시안 노이즈
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 3. 3차원 품질 및 안전성 검증 게이트 (Quality Gate) ]                 │
│   ├── 충실도 검사: 주성분 분석(PCA), 분포 거리(Wasserstein Distance)     │
│   ├── 유용성 검사: TSTR (Train on Synthetic, Test on Real) 검증        │
│   └── 프라이버시 검사: 최근접 이웃 거리(NNDR), 멤버십 추론 시뮬레이션   │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 ┌──────────────────────────────────┴──────────────────────────────────┐
 │                                                                     │
 ▼ (기준 충족 시)                                                      ▼ (기준 미달 시)
[ 4. 안전한 데이터 개방 및 MLOps 투입 ]                       [ 파라미터 튜닝 및 재생성 ]
- 금융/의료 연구용 데이터셋 공개                              - ε 노이즈 조절, 모드 보정
- 자율주행 시뮬레이터 코너 케이스 주입
```

| 검증 단계 | 공학적 기법 | 합격 판정 기준 |
|---|---|---|
| **분포 충실도** | Wasserstein Distance, KS-Test | 원본 대비 통계적 분포 차이 5% 미만 |
| **작업 유용성** | TSTR (Train on Synthetic, Test on Real) | 실제 데이터 학습 모델 대비 95% 이상 성능 유지 |
| **프라이버시** | Distance to Closest Record (DCR) | 훈련 셋과의 완전 일치 샘플 0건, DP $\epsilon \le 1.0$ |

## Ⅳ. 주요 합성 데이터 생성 기술 유형 비교

| 비교 항목 | 규칙/물리 시뮬레이션 기반 | 딥러닝 생성망 (CTGAN / TabDDPM) | LLM / 에이전트 프롬프트 기반 |
|---|---|---|---|
| **대상 데이터** | 3D 비전, 센서 점군, 제조 CAD | 정형 테이블(Tabular), 시계열 금융 | 비정형 텍스트, 대화 로그, 소스코드 |
| **생성 원리** | 3D 렌더링, 수리적 물리 법칙 계산 | 잠재 공간 확률 분포 학습 및 노이즈 역확산 | 문맥 프롬프트 기반 자기회귀 토큰 생성 |
| **주요 장점** | 물리적 정합도 100%, 코너 케이스 완벽 제어 | 복잡한 컬럼 간 비선형 상관관계 모사 | 사람 수준의 정교한 언어적 뉘앙스 생성 |
| **대표 기술** | NVIDIA Isaac Sim, Unreal Engine | CTGAN, TVAE, TabNet, Synthea | GPT-4o Synthetic Prompts, Nemotron |
| **적용 분야** | 자율주행 시뮬레이션, 로봇 피지컬 AI | 금융 FDS 이상거래, 의료 질환 데이터 | 고객센터 상담 봇 튜닝, 법률 질의 셋 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 생성형 모델이 만든 합성 데이터를 다시 다음 세대 모델의 학습에 재귀적으로 투입할 시 다양성이 소실되는 모델 붕괴 | 실제 인간 생성 데이터(Real Data)의 출처 계보를 태깅하여 학습 셋 내 최소 20% 이상의 골든 원본 데이터 의무 혼합 |
| 생성 모델의 과적합으로 인해 특정 개인의 민감 금융/의료 원본 데이터가 그대로 암기 복제되는 프라이버시 침해 | 차등 프라이버시 경사하강법(DP-SGD)을 적용하여 그래디언트 노름을 클리핑하고 안전한 수학적 노이즈 주입 |

## Ⅵ. 제언

실제 데이터 수집의 한계를 극복하고 모델의 강건성을 확보하기 위해, 희귀한 위험 상황(코너 케이스)을 인위적으로 증강하는 적응형 합성 데이터 루프 구축.

```text
[ 자율주행/제조 현장 실제 데이터 ]
               │ (이상치/사고 데이터 희소성 발생)
               ▼
[ 시뮬레이션 기반 코너 케이스 합성 엔진 ]
   ├── Step 1: 기상 악화(폭우, 안개), 센서 고장, 보행자 무단횡단 시나리오 주입
   ├── Step 2: 3D 가상 렌더링을 통한 10만 건 가상 사고 데이터셋 대량 생성
   └── Step 3: TSTR 프레임워크 기반 자율주행 모델 인식 정확도 검증
               │
               ▼
[ 현실 사고 발생률 80% 사전 예방 및 AI 강건성 극대화 ]
```

| 구분 | 실제 데이터 수집에만 의존 | 제언: 합성 데이터 결합 하이브리드 |
|---|---|---|
| **희귀 사례 확보** | 수백만 km 주행 중 우연한 사고 발생 대기 | 가상 환경에서 무제한 위험 코너 케이스 즉시 합성 |
| **개인정보 침해** | 보행자 얼굴, 차량 번호판 모자이크 비용 발생 | 실제 인물이 존재하지 않아 개인정보 규제 완전 면제 |
| **라벨링 비용** | 수작업 어노테이션에 막대한 외주 비용 소모 | 시뮬레이션 생성과 동시에 정답 3D BBox 자동 완벽 태깅 |
