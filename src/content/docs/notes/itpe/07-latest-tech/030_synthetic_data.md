## 한 줄 본질
- 웹 상의 고품질 인간 텍스트 고갈과 엄격한 개인정보 규제 장벽 극복 → 실제 데이터의 확률적 통계 분포와 물리 법칙을 모사해 인공적으로 대량 합성 → 무제한 학습 데이터 확보 / 합성 데이터를 반복 학습할수록 모델 지능이 퇴화하는 모델 붕괴 위험

## 핵심 용어
- 모델 붕괴(Model Collapse): AI가 생성한 합성 데이터를 다음 세대 AI가 다시 학습하는 과정이 반복되면, 데이터 분포의 양 끝(Tail)이 소실되고 결국 무의미한 결과물만 출력하는 퇴화 현상
- 충실도(Fidelity): 생성된 합성 데이터가 실제 원본 데이터의 상관관계, 공분산, 조건부 확률 분포를 얼마나 정밀하게 재현하는지를 나타내는 지표
- Self-Instruct: 소수의 고품질 인간 작성 시드(Seed) 프롬프트를 바탕으로 LLM 스스로 새로운 작업 지시문과 응답을 대량 생성해 파인튜닝 데이터셋을 구축하는 기법

## 핵심 통찰
- 합성 데이터는 단순한 "모조품"이 아니라, 현실에서 100년에 한 번 일어날까 말까 한 자율주행 악천후 충돌 사고 등 코너 케이스(Corner Case)를 집중 주입할 수 있는 유일한 대안
- 100% 합성 데이터만으로 모델을 학습시키면 현실 감각을 잃고 모델 붕괴가 발생하므로, "소수의 고품질 골든 실데이터 + 대량의 합성 데이터" 혼합 비율 제어가 필수
- 개인정보보호법 상 민감정보(의료/금융) 활용 시, 합성 데이터 생성이 비식별 조치보다 재식별 위험을 원천 차단하는 가장 안전한 수단으로 인정받는 추세

## 이웃 토픽과 구분
- 합성 데이터 vs 가명 데이터: 가명 데이터는 실제 데이터의 식별자를 삭제/대체한 것이라 재식별 위험이 상존 / 합성 데이터는 수학적 모델이 새로 만들어낸 완전히 가상의 데이터이므로 원본 개인이 존재하지 않음

## 문제·원인·대책
- 적용 상황: 희귀 질환 판독 AI 모델 구축을 위한 환자 CT 합성 데이터 학습 실패
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 실제 환자에게 없는 비현실적 병변 생성 | GAN 생성 모델의 사실성(Fidelity) 한계 및 해부학 지식 결여 | 확산 모델(Diffusion) 전환 및 물리/의학적 제약조건(Constraint) 손실 함수 추가 | 해부학적 정합성을 갖춘 고정밀 영상 합성 |
| 합성 데이터만으로 재학습 시 성능 퇴화 | 꼬리 분포(Tail) 정보 유실로 인한 모델 붕괴(Model Collapse) 발생 | 실제 환자 데이터 20% 의무 혼합 및 데이터 필터링 파이프라인 구축 | 모델 다양성 유지 및 성능 퇴보 방지 |
| 생성 데이터 역추적 시 원본 환자 유추 | 과적합으로 인해 특정 훈련 샘플을 그대로 복제(Memorization) | 차분 프라이버시(Differential Privacy, DP-SGD) 노이즈 주입 | 수학적으로 증명 가능한 재식별 방지 보장 |

## 이렇게 출제된다

## 내 의견
- [인간 검증(RLHF)을 결합한 데이터 필터링 파이프라인 구축] 단순히 합성 데이터를 대량으로 찍어내면 저품질 쓰레기 데이터로 인해 파운데이션 모델이 오염됨 → 나라면: 생성된 합성 데이터를 규칙 기반 검증기 및 고성능 LLM 비평가(LLM-as-a-Judge)로 1차 필터링하고, 경계선 데이터만 도메인 전문가가 선별 채점하는 데이터 품질 파이프라인을 운영해 훈련 효율 극대화
