## Ⅰ. 합성 데이터(Synthetic Data)의 개요

- 개념 : 실제 현실 세계의 사건이나 인간의 활동을 직접 측정·수집하여 획득한 데이터가 아니라, 수학적 통계 모델링, 컴퓨터 비전 3D 시뮬레이션, **생성형 AI** (GAN, Diffusion, LLM) 알고리즘을 통해 컴퓨터가 인위적으로 가상 생성하여 실제 데이터의 수학적·통계적 패턴을 완벽히 모사하는 인공 생성 데이터.
- 배경 및 필요성 : 2026년 이후 고품질 공개 인터넷 텍스트 고갈 전망(데이터 절벽), **개인정보보호법** (GDPR, General Data Protection Regulation) 및 저작권 침해 소송 강화, 자율주행·의료 등 **희귀 위험** (Edge-case) 데이터 수집 비용의 극단적 고비용성을 극복하기 위해 대두됨.
- 핵심 목적 : 학습 데이터 수집 및 라벨링 비용·시간 획기적 절감, 프라이버시 침해 리스크 제로화, 희귀 엣지 케이스 증강을 통한 AI 모델의 일반화 및 강건성 극대화.

## Ⅱ. 합성 데이터(Synthetic Data)의 핵심 아키텍처 및 동작 메커니즘

합성 데이터는 원시 데이터의 분포 학습, 다중 기법 기반 생성, 그리고 **3대 핵심 품질** (충실도, 다양성, 프라이버시) 검증 파이프라인을 통해 완성됨.

```text
[ 합성 데이터 엔드투엔드 생성 및 3차원 품질 검증 파이프라인 ]

  [ 실세계 원시 데이터셋 ] ──► [ 통계적 분포 분석 & 민감 정보 식별 ]
                                           │
  +----------------------------------------▼----------------------+
  | 합성 데이터 생성 엔진 (Synthesis Engines)                     |
  |  - [정형 데이터] ── CTGAN, TVAE, 베이지안 네트워크            |
  |  - [비정형 이미지/영상] ── Diffusion, 3D 물리 시뮬레이터(Omniverse)|
  |  - [비정형 텍스트/코드] ── 고성능 Frontier LLM 기반 지식 증류  |
  +----------------------------------------┬----------------------+
                                           │ 대량 합성 데이터셋 산출
                                           ▼
+-----------------------------------------------------------------+
| 3차원 다계층 품질 검증 프레임워크 (3D Quality Validation)       |
|                                                                 |
|  1. 충실도 (Fidelity)  ── Wasserstein 거리, 상관관계 행렬 유사도|
|  2. 다양성 (Diversity) ── 엔트로피, 모드 붕괴(Mode Collapse) 여부|
|  3. 프라이버시 (Privacy)─ 멤버십 추론 공격(MIA) 방어, 재식별 불가|
+--------------------------------┬--------------------------------+
                                 │ 품질 기준 충족 시
                                 ▼
         [ AI 모델 학습 파이프라인 투입 (Pre-training / SFT) ]
```

- **정형 데이터 합성** : CTGAN(Conditional Tabular Generative Adversarial Network) 및 TVAE(Tabular Variational Autoencoder)를 적용하여 테이블 데이터의 복합 분포와 컬럼 간의 조건부 상관관계를 보존하는 가상 레코드 생성.
- **시각 시뮬레이션 합성** : 언리얼 엔진, CARLA 등을 사용하여 폭설, 야간, 역광 등 현실에서 촬영하기 힘든 자율주행 사고 위험 시나리오를 3D 렌더링하고 바운딩 박스를 자동 부여.
- **텍스트 및 추론 데이터 합성** : 최상위 프론티어 LLM(Large Language Model)에게 복잡한 질문과 단계별 추론 과정(CoT, Chain of Thought)을 생성하게 하여 소형 모델(sLM) 학습용 교재(Textbooks) 데이터 구축.
- **프라이버시 보존 메커니즘** : 차분 프라이버시(Differential Privacy, DP-SGD, Differentially Private Stochastic Gradient Descent) 기법을 생성 모델에 결합하여 원본 개별 레코드의 흔적을 수학적으로 완벽 소거.

## Ⅲ. 합성 데이터(Synthetic Data)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 실제 데이터 (Real-world Data) | 합성 데이터 (Synthetic Data) |
| --- | --- | --- |
| **수집 및 라벨링 비용** | 수작업 라벨링 및 정제에 막대한 비용과 수개월 소요 | 소프트웨어 알고리즘으로 수 초 만에 무제한 자동 생성 |
| **개인정보 및 저작권** | GDPR, PII(Personally Identifiable Information) 유출 위험, 저작권 분쟁 상존 | 실제 인물의 정보가 아니므로 법적 규제 리스크 해소 |
| **데이터 다양성** | 다수 클래스에 편향, 희귀 이상치 결핍 | 파라미터 조정을 통해 희귀 클래스(Edge case) 집중 증강 |
| **데이터 정확성 및 환각** | 현실의 참값(Ground Truth) 반영 | 생성 모델의 한계로 인한 비현실적 인공물(Artifact) 가능성 |
| **장기적 재학습 영향** | 모델 성능 유지 및 지속적 개선 | 합성 데이터를 반복 재학습 시 모델 붕괴(Model Collapse) |

- 최신 AI 엔지니어링에서는 실제 데이터를 완전히 대체하기보다는, 검증된 실제 데이터의 핵심 골격 위에 합성 데이터를 적정 비율로 혼합하여 모델의 엣지 케이스 대응력을 극대화함.

## Ⅳ. 합성 데이터(Synthetic Data)의 주요 한계점 및 해결 방안

- 합성 데이터를 반복 자가 학습할 때 모델 성능이 퇴화하는 모델 붕괴(Model Collapse) :
  - 한계점 : 합성 데이터로 학습한 AI가 생성한 데이터를 차세대 AI가 다시 학습하면 데이터 분포의 꼬리(Tail) 부분이 사라져 출력 다양성 상실.
  - 해결 방안 : 일정 비율 이상의 고품질 실제 **골든 데이터셋** (Golden Dataset) 을 필수 유지하고, **Human-in-the-Loop** (HITL, Human in the Loop) 검증 루프 적용.
- 현실 세계 물리 법칙과의 괴리로 인한 시뮬레이션 아티팩트 발생 :
  - 한계점 : 합성된 의료 영상이나 자율주행 이미지에 실제 물리 현상과 불일치하는 기하학적 왜곡이 포함되어 오탐 유발.
  - 해결 방안 : 물리 기반 렌더링(PBR) 기술 결합, **도메인 적응** (Domain Adaptation) 및 판별기 기반 통계적 정합성 필터링.
- 생성 모델의 과적합으로 인한 원본 민감 정보 암기(Memorization) 및 역추출 :
  - 한계점 : 훈련에 사용된 실제 고객의 주민번호나 희귀 질환 정보가 합성 데이터셋에 그대로 복제되어 출력될 위험.
  - 해결 방안 : 차분 프라이버시 엡실론(epsilon) 예산 엄격 통제, **멤버십 추론 공격** (MIA) 모의 테스트 및 유사도 역치 기반 차단.

## Ⅴ. 합성 데이터(Synthetic Data) 적용 및 발전을 위한 기술사적 제언

- LLM 추론 능력 고도화를 위한 초고품질 합성 데이터 파이프라인(Ultra-Data) 내재화 : 복잡한 코딩, 수학 문제에 대해 검증 가능한 정답(Self-Correction)을 포함하는 합성 추론 데이터셋 구축 필요.
- 합성 데이터의 신뢰성 검증을 위한 ISO(International Organization for Standardization)/IEC(International Electrotechnical Commission) 5259 표준 품질 메트릭 도입 : 충실도(Fidelity), 다양성(Diversity), 프라이버시(Privacy)의 3대 정량 지표를 수식화하여 자동화된 품질 리포트 생성.
- 합성 비율 및 생성 출처를 명시하는 데이터 계통(Lineage) 추적성 확보 : AI 모델의 투명성과 사후 감사 대응을 위해 학습 데이터셋 내 합성 데이터의 비율과 사용 알고리즘 버전을 불변 로그로 관리.
