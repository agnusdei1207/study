## 지식 로드맵 내 현재 위치

지식 위치: 데이터 관리·AI 학습 → 대체·보완 자료 생성 → **합성 데이터**

## 30초 인출

- 본질: **합성 데이터(Synthetic Data)** 는 통계 모델·생성 모델·규칙·시뮬레이션으로 만든 인공 데이터
- 메커니즘: 생성 목적·원자료 정의 → 합성 방식 선택·생성 → 품질·편향·개인정보 위험 평가 → 제한 목적에 활용

<details>
<summary>핵심 용어</summary>

- **합성 데이터(Synthetic Data)** : 실제 관측을 그대로 복사하지 않고 모델·규칙·시뮬레이션 등을 통해 생성한 데이터
- **충실도(Fidelity)** : 합성 자료가 실제 자료의 관련 분포·관계를 얼마나 재현하는지 나타내는 특성
- **유용성(Utility)** : 합성 자료가 목표 업무·분석·학습에 제공하는 활용 가치
- **차등 프라이버시(Differential Privacy, DP)** : 개인 자료의 포함 여부가 결과에 미치는 영향을 수학적으로 제한하는 프라이버시 정의
- **모델 붕괴(Model Collapse)** : 생성된 자료에 반복 의존할 때 원자료 분포의 일부 특성이 사라지고 학습 결과가 저하될 수 있는 현상
</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **합성 데이터(Synthetic Data)** 는 통계 모델·생성 모델·규칙·시뮬레이션으로 만든 인공 데이터 |
| 목적 | 수집 비용·접근 제약·희귀 사례 부족을 보완할 자료 제공 |

### Ⅱ. 생성·검증 흐름

```text
업무 목적·원자료 조건 정의
            ↓
통계·생성 모델·규칙·시뮬레이션 선택
            ↓
합성 자료 생성
            ↓
품질·유용성·편향·개인정보 위험 평가
            ↓ 기준 충족
정해진 목적에 제한 활용
```

### Ⅲ. 평가 기준

| 기준 | 확인 내용 |
|---|---|
| 충실도 | 업무에 필요한 분포·관계 재현 |
| 유용성 | 별도 실제 자료에서의 업무·모델 성능 |
| 다양성·편향 | 하위 집단·희귀 사례의 표현 |
| 개인정보 위험 | 원본 기억·재식별·노출 가능성 |

제언: 합성 여부만으로 안전하다고 가정하지 않고 목적별 품질·개인정보 평가를 거치는 활용.

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **합성 데이터(Synthetic Data)** 는 통계 모델·생성 모델·규칙·시뮬레이션으로 만든 인공 데이터 |
| 목적 | 수집 비용·접근 제약·희귀 사례 부족을 보완할 자료 제공 |

### Ⅱ. 생성·검증 흐름

```text
업무 목적·원자료 조건 정의
            ↓
통계·생성 모델·규칙·시뮬레이션 선택
            ↓
합성 자료 생성
            ↓
품질·유용성·편향·개인정보 위험 평가
            ↓ 기준 충족
정해진 목적에 제한 활용
```

### Ⅲ. 생성 방식

| 방식 | 생성 원리 | 주의점 |
|---|---|---|
| 통계·규칙 기반 | 분포·업무 제약에 따른 표본 생성 | 가정·제약이 실제 목적에 맞는지 점검 |
| 생성 모델 기반 | 학습된 자료 특성에 따라 새 표본 생성 | 편향·원본 기억·분포 누락 가능성 |
| 시뮬레이션 기반 | 가상 환경과 조건에서 관측 자료 생성 | 시뮬레이터와 현실의 차이 확인 |

### Ⅳ. 품질·위험 관리

| 한계 | 대응 |
|---|---|
| 통계적 유사성만 높아도 실제 과업에 쓸 수 있다는 보장은 없음 | 독립된 실제 검증 자료로 과업별 유용성 평가 |
| 합성 과정이 원자료의 개인정보 위험을 자동 제거하지 않음 | 위협 모델에 따른 재식별·기억 위험 평가; 필요 시 차등 프라이버시 등 명시적 보호 기법 검토 |
| 생성 편향·희귀 집단 누락이 후속 모델에 전파될 수 있음 | 하위 집단·희귀 사례별 품질과 성능 점검 |
| 생성 자료 반복 학습으로 원자료 분포의 꼬리가 사라질 수 있음 | 실제 자료 출처·비율을 관리하고 반복 생성 자료의 누적 영향을 평가 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 생성 자료의 목표와 검증 기준이 불분명하면 품질·위험 결과를 도입 결정에 연결하기 어려움 | 사용할 업무·검증 자료·품질·개인정보 기준을 먼저 정하고, 기준을 통과한 목적부터 제한 적용 후 확대 여부 결정 |
