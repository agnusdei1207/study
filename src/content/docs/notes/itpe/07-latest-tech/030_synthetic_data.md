## Ⅰ. 합성 데이터(Synthetic Data)의 개요

- 핵심 요약 : 실제 측정 데이터의 통계적 패턴을 모사해 알고리즘으로 생성한 인공 데이터로, 수집 비용과 개인정보 문제를 동시에 줄이는 방법.
- 개념 : 현실에서 직접 수집하지 않고, 통계 모델링, 3D 시뮬레이션, **생성형 AI** (GAN, Diffusion, LLM)로 만든 데이터로서 원본의 분포와 상관관계를 모사하는 인공 생성 데이터.
- 배경 및 필요성 : 학습에 쓸 고품질 공개 데이터가 줄어든다는 우려가 커지고, 개인정보 보호 규제와 저작권 분쟁이 강화되었다. 자율주행 사고 장면 같은 희귀 사례는 수집 비용이 매우 높다. 이 제약을 풀기 위해 합성 데이터가 대안으로 부상함.
- 주요 목적 : 데이터 수집과 라벨링 비용 절감, 실제 개인 정보 노출 위험 감소, 희귀 사례 증강을 통한 모델 강건성 확보.

## Ⅱ. 합성 데이터(Synthetic Data)의 특징 및 장점

- 핵심 요약 : 원본 분포를 학습해 무제한 생성하는 특성이 비용 절감과 희귀 사례 확보로 이어지는 구조.

1. 무제한 생성 : 알고리즘으로 필요한 양만큼 생성 → 수집·정제 기간 단축과 라벨링 비용 감소.
2. 라벨 내장 생성 : 3D 시뮬레이션은 정답 라벨을 생성과 동시에 부여 → 수작업 라벨링 의존도 감소.
3. 희귀 사례 증강 : 조건을 조정해 드문 상황을 집중 생성 → 엣지 케이스에 대한 모델 대응력 향상.
4. 개인정보 리스크 완화 : 실존 인물의 기록이 아니므로 재식별 위험이 낮아짐 → 프라이버시 규제 대응 부담 감소.

## Ⅲ. 합성 데이터(Synthetic Data)의 구조 (흐름)

- 핵심 요약 : 원시 데이터의 분포 학습, 유형별 생성 엔진, 품질 검증의 세 단계를 거쳐 학습 파이프라인에 투입되는 구조.

```text
[ 실세계 원시 데이터 ]
          ↓ 분포 분석·민감 정보 식별
[ 합성 데이터 생성 엔진 ]
          ↓ 대량 합성 데이터셋
[ 3차원 품질 검증 ]
   충실도 / 다양성 / 프라이버시
          ↓ 기준 충족 시
[ AI 모델 학습 투입 ]
```

- **정형 데이터 합성** : CTGAN(Conditional Tabular GAN)이나 TVAE 등으로 컬럼 간 조건부 상관관계를 보존한 가상 레코드를 생성한다.
- **시각 시뮬레이션 합성** : 3D 렌더링 환경에서 야간, 폭설, 역광 등 촬영이 어려운 장면을 만들고 라벨을 자동 부여한다.
- **텍스트·추론 합성** : 상위 LLM이 단계별 추론 과정을 포함한 데이터를 생성하고, 이를 소형 모델 학습에 사용한다.
- **차분 프라이버시** : DP-SGD처럼 학습 과정에 잡음을 더해 개별 원본 레코드의 흔적이 결과에 남지 않도록 제한한다.

## Ⅳ. 합성 데이터(Synthetic Data)와 실제 데이터의 비교

- 핵심 요약 : 합성 데이터는 비용과 법적 부담에서 우위에 있지만, 현실 정합성과 재학습 안정성에서 약점이 있다.

| 비교 항목 | 실제 데이터 | 합성 데이터 |
| --- | --- | --- |
| 수집·라벨링 비용 | 수작업 정제에 큰 비용과 시간 | 알고리즘으로 빠르게 대량 생성 |
| 개인정보·저작권 | 유출과 분쟁 위험 상존 | 실존 기록이 아니어서 위험 낮음 |
| 다양성 | 다수 클래스 편향, 희귀 사례 부족 | 조건 조정으로 희귀 사례 증강 |
| 정확성 | 현실의 정답을 반영 | 생성 모델의 인공물 가능성 |
| 장기 재학습 | 지속 개선에 유리 | 반복 재학습 시 모델 붕괴 위험 |

- 실무에서는 실제 데이터를 대체하기보다, 검증된 실제 데이터를 골격으로 두고 합성 데이터를 적정 비율로 섞는 방식이 일반적이다.

## Ⅴ. 합성 데이터(Synthetic Data)의 한계와 방안

- 핵심 요약 : 모델 붕괴, 물리적 비정합, 원본 기억을 세 축의 통제 장치로 관리해야 한다.

```text
[ 모델 붕괴의 순환 ]

실제 데이터로 학습
      ↓
합성 데이터 생성
      ↓
합성 데이터로 재학습
      ↓ 분포 꼬리 소실 (반복 시)
출력 다양성 저하 → 모델 붕괴

※ 골든 데이터셋 혼합이 이 순환을 끊는다
```

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 모델 붕괴 | 합성 데이터를 반복 학습하면 분포 꼬리가 사라짐 | 고품질 실제 **골든 데이터셋** (Golden Dataset) 일정 비율 유지, **Human-in-the-Loop** 검수 | 실제 데이터 혼합 비율, 출력 다양성 |
| 비현실적 아티팩트 | 물리 법칙과 어긋난 영상·텍스트로 오탐 유발 | 물리 기반 렌더링, 도메인 적응, 판별기 기반 정합성 필터링 | 필터 통과율 |
| 원본 기억과 역추출 | 과적합된 생성 모델이 민감 정보를 그대로 재현 | 차분 프라이버시 예산(epsilon) 관리, **멤버십 추론 공격** (MIA) 모의 점검 | 유사도 임계치 초과 건수 |

## Ⅵ. 합성 데이터(Synthetic Data)의 기술사적 제언

- 핵심 요약 : 합성 데이터는 품질 측정 기준과 출처 추적 체계를 함께 갖출 때 신뢰할 수 있는 학습 자원이 된다.

1. 품질 측정 체계 : 데이터 품질 관리 표준인 **ISO/IEC 5259** 시리즈의 관리 틀을 참고하고, 충실도·다양성·프라이버시를 조직 내 정량 지표로 정의해 자동 리포트로 관리한다.
2. 계통 추적성 : 학습 데이터에 포함된 합성 데이터의 비율과 생성 방법, 도구 버전을 기록해 감사 대응 근거를 남긴다.
3. 실제 데이터 기반 유지 : 골든 데이터셋을 별도로 관리하고, 합성 데이터 투입 전후의 성능 변화를 검증 절차에 포함한다.

## Ⅶ. 결론

- 핵심 요약 : 합성 데이터는 실제 데이터를 완전히 대체하지 않고 보완하는 학습 자원이다.
- 시사점 : 생성 능력보다 검증과 추적 체계가 합성 데이터의 신뢰를 결정하므로, 품질 관리 역량이 핵심 경쟁력이 된다.
