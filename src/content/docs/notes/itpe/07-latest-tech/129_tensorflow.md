## 지식 로드맵 내 현재 위치
최신 기술 → 인공지능 개발 프레임워크 → 텐서 연산·자동 미분 → TensorFlow

## 30초 인출
- **본질:** TensorFlow는 텐서 연산으로 머신러닝 모델을 만들고 학습·실행하는 오픈소스 프레임워크.
- **메커니즘:** Keras 등으로 모델을 구성하고, 자동 미분으로 계산 그래디언트를 구해 학습 변수 갱신.
- **실행:** 대화식 실행과 그래프 기반 최적화를 지원하며 저장·서빙·온디바이스 배포 경로를 제공.

<details><summary>핵심 용어</summary>

- **TensorFlow:** 텐서 연산과 자동 미분을 활용해 머신러닝 모델을 구축·학습·실행하는 프레임워크.
- **텐서(Tensor):** 형상과 자료형을 가진 다차원 수치 데이터 구조.
- **Keras:** 모델·계층·학습 절차를 구성하는 TensorFlow의 고수준 API.
- **자동 미분(Automatic Differentiation):** 실행된 연산을 추적해 지정된 변수에 대한 기울기를 계산하는 기능.
- **GradientTape:** TensorFlow에서 연산을 기록하고 자동 기울기 계산을 요청하는 API.
- **`tf.function`:** TensorFlow 연산을 추적·그래프화해 실행·배포 경로를 구성하는 함수 데코레이터.
- **LiteRT:** TensorFlow Lite에서 발전한 Google의 온디바이스 머신러닝 런타임 명칭.
- **TF Serving(TensorFlow Serving):** 학습된 모델을 서비스 형태로 배포·제공하는 TensorFlow 생태계 구성요소.

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **TensorFlow**는 텐서 연산과 자동 미분을 활용해 머신러닝 모델을 구축·학습·실행하는 프레임워크 |
| 목적 | 모델 계산·학습·실행을 위한 공통 프로그래밍 기반 제공 |

## Ⅱ. 학습 메커니즘
```text
입력 텐서
    |
    v
Keras 모델의 순전파
    |
    v
손실 계산·GradientTape 기울기
    |
    v
옵티마이저의 학습 변수 갱신
    |
    v
반복 학습·모델 저장
```

GradientTape는 기록된 TensorFlow 연산을 따라 역방향으로 기울기를 계산. 옵티마이저는 기울기를 이용해 학습 변수를 갱신.

## Ⅲ. 모델 구성과 실행
| 구성요소 | 역할 |
|---|---|
| 텐서·연산 | 입력·중간값과 모델 계산 표현 |
| Keras 계층·모델 | 재사용 가능한 계산 블록과 모델 구성 |
| Eager 실행 | 연산을 즉시 실행해 결과·오류를 확인 |
| 그래프 실행 | `tf.function` 등으로 연산을 추적해 그래프 실행 경로 구성 |

## Ⅳ. 저장·배포 흐름
```text
모델 학습·평가
      |
      v
검증된 모델 내보내기
      |
      +-- 서버 제공 → TensorFlow Serving 등 배포 방식
      |
      +-- 기기 실행 → 모델 변환·최적화 → LiteRT 런타임
      |
      +-- 기타 표적 → 지원 연산·자료형 호환성 점검
```

모델 변환은 지원되지 않는 연산·자료형이나 양자화 설정에 따라 출력이 달라질 수 있으므로, 대상 장치에서 정확도·성능·자원 사용량 검증 필요.

## Ⅴ. 운영 고려사항
| 항목 | 확인 내용 |
|---|---|
| 재현성 | 모델·데이터·학습 설정·실행 환경의 버전 |
| 성능 | 실제 입력과 대상 하드웨어에서 지연·메모리 측정 |
| 변환 | 연산자 지원, 수치 오차, 양자화 영향 확인 |
| 운영 | 모델 배포·롤백·감시와 장애 대응 절차 |

## Ⅵ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 학습 코드가 정상이어도 저장·변환·대상 기기 실행 단계에서 호환성이나 성능 차이가 생길 수 있음 | 모델 아티팩트와 변환 설정을 버전 관리하고, 배포 전 실제 입력·장치 조합으로 기준 성능·정확도 시험 수행 |
