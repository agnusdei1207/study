## 연관 키워드

- ISA-95, IEC 62264, 기업-제어 시스템 통합(Enterprise-Control System Integration), B2MML
- MES, MOM, ERP, SCM, 기능 계층 모델, 제조 운영 관리
- OT, IT, OPC UA, 이벤트 드리븐 아키텍처(EDA), IEC 62443, DMZ(Demilitarized Zone)

## Ⅰ. ISA-95 기업·제조 통합의 개요

- 핵심 요약 : ERP와 MES 사이의 기능 경계와 데이터 교환 형식을 표준화해 IT와 OT를 잇는 국제 규격.
- 개념 : 기업 자원 계획 시스템인 ERP(Enterprise Resource Planning)와 공장 현장의 MES(Manufacturing Execution System) 사이에서 **기업-제어 시스템 통합** (Enterprise-Control System Integration) 기능 경계와 데이터 교환을 정의한 규격이며, 국제 표준은 IEC(International Electrotechnical Commission) 62264로 채택됨.
- 배경 및 필요성 : ERP의 계획 주기(일·주 단위)와 MES의 현장 실시간 트랜잭션 사이에 시차가 있어 재고와 생산 실적이 어긋나므로, **B2MML** (Business To Manufacturing Markup Language) 기반 공통 객체 모델과 메시지 교환, 재고 조정 체계가 필요함.
- 주요 목적 : IT(Information Technology) 영역과 OT(Operational Technology) 영역의 정보 단절 해소, 이기종 시스템 연동 비용 축소, 실시간 제조 가시성 확보.

## Ⅱ. ISA-95 기업·제조 통합의 특징 및 장점

- 핵심 요약 : 계층별 책임 분리와 공통 객체 모델이 시스템 교체 비용 절감과 실시간 가시성으로 이어지는 구조.

1. 계층별 책임 분리 : Level 4(ERP), Level 3(MOM), Level 0~2(현장 제어)의 책임 경계를 명시 → 시스템 교체 시 영향 범위를 해당 계층 안으로 한정.
2. 공통 객체 모델 : 인력, 설비, 자재, 공정 세그먼트를 정형 객체로 정의 → 시스템마다 반복되는 데이터 맵핑 작업 감소.
3. 표준 메시지 교환 : B2MML 기반 XML 메시지로 생산 일정과 실적을 주고받음 → 이기종 시스템 연동 개발 기간 단축.
4. **MOM** (Manufacturing Operations Management, 제조 운영 관리) 기능 통합 : 생산, 유지보수, 품질, 재고 기능을 Level 3에서 묶음 → 현장 데이터의 실시간 추적성 확보.

## Ⅲ. ISA-95 기업·제조 통합의 구조 (흐름)

- 핵심 요약 : ERP가 내린 생산 계획이 MES를 거쳐 현장 제어로 내려가고, 실적 데이터가 같은 경로를 거슬러 올라가는 양방향 계층 흐름.
- **기능 계층 모델** (Functional Hierarchy) : IT와 OT의 책임 경계를 계층 단위로 나누는 구조.

```text
[ 계층 간 명령과 실적 흐름 ]

Level 4 : ERP / SCM
   ↓ 생산 일정 (B2MML)
Level 3 : MES / MOM
   ↓ 작업 지시 · 공정 파라미터
Level 0~2 : PLC · DCS · SCADA
   ↑ 실적 · 상태 데이터
Level 3 : MES 실적 집계
   ↑ 재고 · 실적 반영
Level 4 : ERP
```

```text
[ Level 3 : MOM 기능 범주 ]

생산 (Production)
   - 작업 지시, 라인 디스패칭
유지보수 (Maintenance)
   - 예방점검, 고장 이력 관리
품질 (Quality)
   - 인라인 검사, SPC
재고 (Inventory)
   - WIP 추적, 로트 추적성
```

## Ⅳ. ISA-95 기업·제조 통합과 ISA-88의 비교

- 핵심 요약 : ISA-95는 기업과 제조 운영 사이의 데이터 교환을, ISA-88은 현장 배치 설비의 제어 로직을 표준화하는 상호 보완 관계.

| 비교 축 | ISA-95 | ISA-88 |
| --- | --- | --- |
| 중점 목표 | 기업 업무(ERP)와 제조 현장(MES) 간 데이터 교환 표준화 | 현장 배치 설비의 제어 로직 모듈화와 레시피 실행 |
| 적용 계층 | Level 3(MOM)과 Level 4(ERP)의 경계 | Level 1~3의 배치 실행 영역 |
| 주요 모델 | 객체 모델(자재, 인력, 설비), 트랜잭션 메시지 모델 | 물리 모델, 절차 모델, 레시피 모델 |
| 데이터 표현 | B2MML(XML 기반 구조화 메시지) | 상태 전이 기반 Phase 실행 모델 |
| 상호 연동 | 생산 일정을 현장 배치 측에 전달 | 전달받은 일정이 마스터 레시피 실행 입력으로 변환 |

- 선택 기준 : 기업 시스템 연계가 목적이면 ISA-95 인터페이스를, 현장 배치 로직의 모듈화가 목적이면 ISA-88을 우선 적용하며, 실무에서는 두 규격을 함께 쓰는 경우가 일반적.

## Ⅴ. ISA-95 기업·제조 통합의 한계와 방안

- 핵심 요약 : 동기화 주기 차이, 레거시 프로토콜 변환 부담, IT-OT 융합에 따른 보안 노출을 이벤트 기반 연계와 망 구획으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| ERP-MES 동기화 주기 불일치 | 배치 중심 ERP와 실시간 MES의 처리 주기 차이로 WIP 재고 수량 오차 발생 | **이벤트 드리븐 아키텍처** (EDA, Event-Driven Architecture) 도입과 트랜잭션 아웃박스 패턴 적용 | WIP 수량 불일치율 |
| 레거시 PLC 프로토콜 변환 부담 | 비표준 프로토콜로 ISA-95 데이터 모델 변환 비용 급증 | 에지 게이트웨이 설치와 **OPC UA** (OPC Unified Architecture) 정보 모델 기반 데이터 가상화 계층 구축 | 변환 오류 건수 |
| IT-OT 융합에 따른 보안 노출 | 현장 제어망이 업무망과 연결되며 외부 공격 경로 증가 | **IEC 62443** 기준의 존·컨덕트(Zone and Conduit) 분리, DMZ 배치, 일방향 보안 게이트웨이 적용 | 비인가 접근 시도 건수 |

## Ⅵ. ISA-95 기업·제조 통합에 대한 기술사적 제언

- 핵심 요약 : 점대점 연계를 메시지 기반 구조로 바꾸고, 공통 의미 구조와 보안 구획을 함께 정비하는 것이 통합의 기본 방향.

1. 기업 시스템과 현장 시스템의 계단식 인터페이스를 줄이고 MQTT, Kafka 같은 메시지 브로커 기반 발행·구독 구조로 전환하는 방향 추진 필요.
2. 시스템마다 다른 테이블 구조를 정리하기 위해 ISA-95 객체 모델을 전사 공통 의미 체계로 먼저 정의하는 작업이 선행 과제.
3. 현장 보안은 업무망 정책을 그대로 옮기지 않고 IEC 62443의 존과 컨덕트 기준으로 망 구획을 먼저 설계하는 절차 정착 필요.

## Ⅶ. 결론

- 핵심 요약 : ISA-95는 ERP와 MES의 경계를 표준 객체와 메시지로 정의해 IT와 OT를 잇는 연동 기반임.
- 시사점 : 연동 방식을 표준화하더라도 데이터 정의와 보안 구획이 함께 정비되어야 통합 효과가 유지됨.
