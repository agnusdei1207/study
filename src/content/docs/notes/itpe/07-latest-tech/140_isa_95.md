- 본질: **ISA-95 기업·제조 통합은** 기업 업무와 제조 운영 사이의 기능·정보 교환 범위를 공통 모델로 정의하는 표준 체계
- 메커니즘: 기업 계획·주문 → 제조 운영 일정·실적 → 현장 실행·설비 데이터 → 생산 실적 환류
- 통찰: 한계: ERP·MES의 실적 기준과 시점이 다르면 같은 주문의 생산량도 불일치 → 방안: 주문·작업 식별자와 수량 단위·기록 시점을 합의하고 연계 시험

## 2~4교시 25점 답안

## Ⅰ. ISA-95 기업·제조 통합의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ISA-95 기업·제조 통합은** 기업 업무와 제조 운영 사이의 기능·정보 교환 범위를 공통 모델로 정의하는 표준 체계 |
| 목적 | ERP·제조 운영·현장 제어 간 책임과 데이터 의미의 일관성 확보 |

## Ⅱ. 기업 계획과 제조 실행의 정보 교환 구조

```text
수준 4  ERP: 주문·생산 계획
               │ 생산 요청·자원 요구
               ▼
수준 3  제조 운영: 상세 일정·작업 지시·실적 집계
               │ 작업 지시       ▲ 상태·실적
               ▼                 │
수준 0~2 현장 제어: 설비·공정 실행
               └─ 실적·품질 정보를 수준 3 거쳐 수준 4에 환류
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 기업 업무 | 주문·계획·재고 요구 전달 | 업무 코드와 현장 코드 불일치 |
| 제조 운영 | 상세 일정·품질·실적 관리 | 계획과 실제 생산 차이 |
| 현장 제어 | 설비 상태·공정 실행 | 제어 데이터의 문맥 부족 |
| 정보 교환 | 자재·설비·인력·성과 의미 모델 정렬 | 시스템 간 메시지 해석 차이 |

## Ⅲ. ISA-95와 ISA-88의 역할 비교

| 구분 | ISA-95 | ISA-88 |
|---|---|---|
| 주된 범위 | 기업 업무와 제조 운영 사이의 기능·정보 모델 | 배치 생산의 설비·절차·레시피 모델 |
| 적용 판단 | 생산 일정·성과·자원 정보를 상위 업무와 연결할 때 | 동일 제품의 배치 실행·기록을 일관되게 할 때 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| ERP와 MES의 데이터 명칭만 맞춰도 생산 실적의 기준·시점이 다를 수 있음 | 주문·작업·실적의 식별자와 단위·시점을 합의한 뒤 인터페이스 시험 |

## Ⅴ. 제언

주문에서 작업과 실적으로 이어지는 공통 식별자와 측정 시점을 우선 정의하고 수준 간 메시지로 검증.
