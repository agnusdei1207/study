## 30초 인출

- 본질: **ISA-95** (IEC 62264)는 기업 경영 관리 시스템(ERP/SCM)과 제조 운영 관리 시스템(MES/MOM) 간의 데이터 교환 및 기능 인터페이스를 체계화한 글로벌 제조 통합 표준
- 메커니즘: 계층 모델(Level 0~4) 정의, 제조 자원 모델(인력·설비·자재·공정)과 MOM 4대 영역(생산·유지보수·품질·재고)을 B2MML 표준 스키마로 연계
- 통찰: ERP의 재무·계획 주기(배치/일 단위)와 MES의 현장 실시간 트랜잭션 간 시차로 재고 정합성 불일치가 발생하므로 공통 객체 모델(B2MML) 기반의 이벤트 드리븐 실시간 연계 및 조정(Reconciliation) 파이프라인 구축 필요

<details><summary>핵심 용어</summary>

- **ISA-95 (IEC 62264)** : 전사 기업 관리 시스템과 생산 제어 시스템 간의 자동화 인터페이스 표준.
- **계층 모델 (Purdue Model 기반)** : Level 0(물리 공정)부터 Level 4(기업 비즈니스 계획)까지 5개 층위 구조.
- **MOM (Manufacturing Operations Management)** : 생산(Production), 유지보수(Maintenance), 품질(Quality), 재고(Inventory)의 Level 3 핵심 4대 기능.
- **B2MML (Business To MES Markup Language)** : ISA-95 데이터 모델을 XML/JSON 스키마로 구현한 사실상 표준 연계 인터페이스.
- **공정 세그먼트 (Process Segment)** : 제품 생산에 필요한 인력, 장비, 자재의 특정 공정 단위 자원 묶음.

</details>

## 2~4교시 예상문제 (25점)

> 스마트 제조 환경에서 IT 영역(ERP)과 OT 영역(MES/DCS)의 수직적 통합을 위한 국제 표준인 ISA-95(IEC 62264)의 계층 구조와 MOM 4대 기능 영역을 설명하고, B2MML 기반 연계 메커니즘 및 현장 적용 시 데이터 동기화 한계 극복 방안을 논하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. ISA-95 기업·제조 통합의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 기업 비즈니스 계획 시스템(ERP/SCM, Level 4)과 공장 현장 제조 운영 관리 시스템(MES/MOM, Level 3) 간의 기능 경계와 데이터 교환을 표준화한 국제 규격(IEC 62264) |
| 목적 | IT 영역과 OT 영역 간 정보 단절 해소, 이기종 시스템 통합 비용 절감 및 실시간 제조 가시성 확보 |

## Ⅱ. ISA-95의 기능 계층 및 자원 모델 특징

| 핵심 구성요소 | 세부 구성 및 영역 | 주요 특징 및 역할 |
|---|---|---|
| **기능 계층 모델 (Functional Hierarchy)** | Level 4(ERP), Level 3(MOM), Level 2(DCS/SCADA), Level 1(PLC/센서), Level 0(물리 공정) | IT와 OT의 책임 경계를 명확히 분리하고 인터페이스 표준 제공 |
| **MOM 4대 기능 범주** | 생산(Production), 유지보수(Maintenance), 품질(Quality), 재고(Inventory) | Level 3 내부에서 세부 일정 계획, 실행 지시, 데이터 수집 및 추적 수행 |
| **제조 자원 4대 객체** | 인력(Personnel), 설비(Equipment), 자재(Material), 공정 세그먼트(Process Segment) | 제조에 투입되는 유무형 자원의 능력(Capability)과 실적(Actual)을 정형화 |

## Ⅲ. ISA-95 수직 통합 체계 및 B2MML 연계 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ ISA-95 기반 기업-제조 수직 통합 및 B2MML 메시지 파이프라인 ]         │
└────────────────────────────────────────────────────────────────────────┘

  [ Level 4: 전사 기업 시스템 (ERP / SCM) ]
   - 수주 관리, 생산 계획(MPS), 마스터 데이터(BOM, Routing), 전사 자재 발주
             │
             │  B2MML (Production Schedule / Material Requirement)
             ▼
  [ Level 3: 제조 운영 관리 (MES / MOM) ]
   ├── 생산 관리 (Production)  : 작업 지시 발행, 라인 디스패칭
   ├── 유지보수 (Maintenance) : 설비 예방점검, 고장 이력 관리
   ├── 품질 관리 (Quality)     : 인라인 검사, SPC, 부적합품 격리
   └── 재고 관리 (Inventory)   : 재공품(WIP) 추적, 로트(Lot) 추적성
             │
             │  OPC UA / 산업용 이더넷 (Process Parameter / State)
             ▼
  [ Level 0~2: 현장 제어 및 물리 설비 (DCS / SCADA / PLC / Sensor) ]
   - 연속/배치 공정 실행, 실시간 피드백 루프, 센서 텔레메트리 스트리밍
```

| 연계 프로세스 | 세부 트랜잭션 흐름 | 사용 B2MML 스키마 |
|---|---|---|
| **생산 일정 전달** | Level 4에서 주간/일간 생산 계획을 수립하여 Level 3로 전송 | ProductionSchedule.xsd |
| **자원 가용성 검증** | Level 3에서 설비 가동 상태, 자재 재고, 작업자 자격을 대조 | EquipmentCapability.xsd |
| **작업 실행 및 제어** | Level 3에서 Level 2로 세부 공정 레시피 및 제어 태그 파라미터 하달 | ProcessSegment.xsd |
| **생산 실적 환류** | 공정 완료 후 실적 수량, 불량 유형, 자재 소진 내역을 Level 4에 보고 | ProductionPerformance.xsd |

## Ⅳ. ISA-95와 ISA-88의 역할 비교 및 연계 관계

| 비교 항목 | ISA-95 (Enterprise-Control Integration) | ISA-88 (Batch Control) |
|---|---|---|
| **중점 목표** | 기업 업무(ERP)와 제조 현장(MES) 간 데이터 교환 표준화 | 현장 배치 설비 제어 로직 모듈화 및 레시피 실행 |
| **적용 계층** | 주로 Level 3(MOM)과 Level 4(ERP)의 경계 영역 | 주로 Level 1~2(PLC/DCS) 및 Level 3(배치 엔진) 영역 |
| **주요 모델** | 객체 모델(자재, 인력, 설비), 트랜잭션 메시지 모델 | 물리 모델, 절차 모델, 레시피 모델(Master/Control) |
| **데이터 표현** | B2MML (XML/JSON 기반 구조화 메시지) | IEC 61131-3, SFC, 상태 전이도(State Machine) |
| **상호 연동** | ISA-95의 Production Schedule이 ISA-88의 Master Recipe 구동 입력으로 변환되어 현장 실행 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 배치 기반 ERP와 실시간 스트리밍 MES 간의 데이터 처리 주기 불일치로 WIP 재고 수량 오차 발생 | 카프카(Kafka) 기반 이벤트 드리븐 아키텍처(EDA) 도입 및 트랜잭션 아웃박스 패턴 기반 실시간 동기화 |
| 플랜트 현장의 수많은 레거시 PLC 및 비표준 프로토콜로 인해 ISA-95 표준 데이터 모델 변환 오버헤드 급증 | 에지 컴퓨팅 게이트웨이 도입 및 OPC UA 정보 모델(Information Model) 기반의 데이터 가상화 계층 구축 |
| IT-OT 네트워크 통합에 따른 현장 제어 시스템(Level 1~2)의 사이버 공격 노출 위험 증가 | IEC 62443 표준 기반의 DMZ(Zone & Conduit) 망 분리 및 일방향 보안 게이트웨이 적용 |

## Ⅵ. 제언

현대 스마트 제조의 민첩성을 극대화하기 위해 기존 전통적 계층형 피라미드 구조에서 탈피하여, ISA-95 정보 모델을 준수하는 통합 네임스페이스(UNS, Unified Namespace) 기반의 이벤트 브로커 아키텍처로 진화 필요.

```text
[ 전통적 피라미드 계층 ]                 [ 제언: UNS 기반 실시간 제조 데이터 허브 ]
  Level 4 (ERP)                             ┌────────────────────────┐
       │                                    │  통합 네임스페이스     │
  Level 3 (MES)                             │  (UNS / MQTT Broker)   │
       │                                    └───────┬────────────────┘
  Level 2 (SCADA)                     ┌─────────────┼─────────────┐
       │                              ▼             ▼             ▼
  Level 0~1 (PLC/Field)          [ ERP / SCM ]  [ MES / MOM ]  [ PLC / Edge ]
```

| 구분 | 전통적 계층형 점대점(Point-to-Point) 연계 | 제언: ISA-95 기반 UNS 이벤트 메시징 |
|---|---|---|
| **연계 구조** | ERP ↔ MES ↔ SCADA 수직 계단식 인터페이스 | 단일 메시지 브로커(MQTT/Kafka)를 통한 Pub/Sub |
| **데이터 모델** | 시스템마다 독자적인 테이블 구조 및 데이터 맵핑 | ISA-95 기반 공통 의미 구조(ISA-95 Hierarchy Namespace) |
| **확장성** | 신규 설비 도입 시 상위 계층 전면 인터페이스 수정 | 토픽 구독만으로 신규 시스템 즉시 연동 가능 |
| **지연 시간** | 배치 동기화에 따른 수시간~수일 지연 | 밀리초(ms) 단위의 실시간 데이터 발행 및 모니터링 |
