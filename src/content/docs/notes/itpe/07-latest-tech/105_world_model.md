## 답안 골격
```text
[월드 모델] ◀━━ 머리: Ⅶ 내 의견 (물리 법칙과 시공간 인과관계를 잠재 공간에서 시뮬레이션하여 에이전트의 상상 기반 계획과 자율주행 안전성을 혁신하는 차세대 지능 기반)
 ┃
 ┣━ Ⅰ 개요 ───── 텍스트 토큰 통계에 갇힌 LLM의 물리 세계 이해 결여 → 현실의 물리 법칙과 행동에 따른 미래 상태를 예측·시뮬레이션하는 월드 모델 태동
 ┣━ Ⅱ 특징 ───── 환경의 잠재 상태 표현(Latent State) · 행동 조건부 미래 예측($s_{t+1} \sim P(s_{t+1}|s_t, a_t)$) · 상상 속 시뮬레이션(Dreaming) · 물리 상식 내재화
 ┣━ Ⅲ 구조 ───── 비전 인코더(V) + 메모리/전이 모델(M, RNN/Transformer) + 제어기(C) + 디퓨전/생성기(시각 복원)
 ┣━ Ⅳ 흐름 ───── ① 센서 관측 데이터 압축(잠재 공간 사상) → ② 에이전트의 가상 행동 주입 → ③ 시공간 물리 법칙 기반 다음 잠재 상태 예측 → ④ 상상 속 시행착오 계획 수립 → ⑤ 현실 세계 안전 실행
 ┣━ Ⅴ 비교 ───── 생성형 비디오 모델 vs 전통 물리 시뮬레이터 vs 월드 모델 (단순 픽셀 연속성 vs 수학적 하드코딩 vs 행동 인과 기반 지능형 잠재 물리 시뮬레이션)
 ┗━ Ⅵ 실무 ───── 장기 예측 시 오차 누적으로 인한 환각 붕괴 / 극심한 학습 연산량 / 물리적 불연속성(충돌/마찰) 표현 한계
```

## 한 줄 본질
- 컵을 밀면 바닥으로 떨어져 깨진다는 물리 법칙을 글자로만 배운 AI는 현실에서 로봇을 움직일 수 없음 → 현실 세계의 시공간 변화를 신경망의 잠재 공간(Latent Space) 안에 압축하고, "내가 이렇게 행동하면 세상이 어떻게 변할까?"를 뇌 속에서 미리 상상(Dreaming)하여 계획하는 물리 엔진 인공지능 / 긴 시간 예측 시 현실 왜곡 발생

## 핵심 용어
- 잠재 공간(Latent Space): 시각적 노이즈(배경의 나뭇잎 흔들림 등)를 버리고 사물의 위치, 속도, 질량 등 본질적인 물리적 상태만을 압축해 놓은 다차원 수학적 벡터 공간
- JEPA(Joint Embedding Predictive Architecture): 얀 르쿤(Yann LeCun)이 제안한 비생성형 월드 모델 구조로, 불필요한 픽셀 단위 복원을 하지 않고 잠재 공간 수준에서 직접 미래 상태를 예측하여 연산 효율 극대화
- 드림(Dreaming / Latent Imagination): 로봇이나 자율주행차가 현실에서 직접 부딪히며 위험하게 학습하지 않고, 신경망 내부의 월드 모델 속에서 수백만 번의 가상 주행을 시뮬레이션하여 정책을 학습하는 기법

## 핵심 통찰
- "단순한 동영상 생성이 아니다": OpenAI의 Sora나 비디오 모델은 보기 좋은 픽셀을 만들어내지만 물리가 깨지는 경우가 많음(유리잔이 깨졌다가 복원됨) → 진정한 월드 모델은 질량 보존, 중력, 인과율(Causality)을 수학적으로 일관되게 유지하는 '행동 조건부 상태 전이'를 목표로 함
- 자율주행의 롱테일(Long-tail) 문제 해결: 실제 도로에서 사고 시나리오를 수집하는 것은 위험하고 불가능하지만, 월드 모델 안에서는 보행자가 갑자기 튀어나오는 극한의 위험 환경을 무한히 생성해 주행 모델을 검증할 수 있음
- 텍스트 다음 토큰 예측의 한계 돌파: 언어는 인간 지능의 극히 일부에 불과하며, 대부분의 상식(Common Sense)은 물리 세계의 시공간적 상호작용에서 나옴 → 월드 모델이 AGI로 가는 진정한 관문으로 평가받는 이유

## 이웃 토픽과 구분
- 3D 물리 엔진(Unreal/Unity) vs 월드 모델: 전통 엔진은 인간이 중력, 마찰 공식을 하드코딩 / 월드 모델은 비디오와 센서 데이터를 보고 AI가 스스로 세계의 작동 규칙을 데이터로부터 학습

## 문제·원인·대책
- 적용 상황: 자율주행 차량의 엔드투엔드(E2E) 안전 주행을 위한 월드 모델 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미래 5초 이상을 예측 시 도로와 건물이 점차 녹아내리거나 사라지는 환각 붕괴 | 다단계 자기회귀 예측 시 발생하는 잠재 오차 누적(Compounding Error) | 픽셀 복원 대신 잠재 임베딩만 예측하는 JEPA 아키텍처 및 확산(Diffusion) 손실 결합 | 10초 이상 장기 물리 일관성 유지 |
| 복잡한 교차로에서 다른 차량들의 돌발 끼어들기를 전혀 예측하지 못함 | 정적인 배경 위주의 학습 데이터셋 편향 | 다중 에이전트 상호작용 궤적 데이터 증강 및 인과적 트랜스포머 어텐션 적용 | 돌발 상황 방어 운전 성공률 92% 달성 |
| 차량 온보드 컴퓨터에서 실시간(30fps)으로 월드 모델을 구동하기에 연산량 과다 | 거대 트랜스포머 백본의 높은 FLOPs 소모 | 시각 잠재 벡터 양자화 및 상태 공간 모델(Mamba/SSM) 기반 선형 복잡도 전이 모델 적용 | 온보드 칩셋 실시간 추론 달성 |
