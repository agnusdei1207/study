## 30초 인출

- 본질: **월드 모델 (World Model)** 은 에이전트가 현실 세계의 물리 법칙, 상태 전이 및 인과 관계를 내부 잠재 공간(Latent Space)에 내재화하여 행동에 따른 미래 결과를 시뮬레이션하고 최적 행동을 계획하는 인공지능 모델
- 메커니즘: 고차원 센서 관측(이미지/라이다)을 저차원 잠재 상태($z_t$)로 압축 인코딩하고, 행동($a_t$) 조건부 상태 전이 확률($P(z_{t+1}|z_t, a_t)$)을 통해 수천 단계의 가상 미래 경로를 상상(Imagination)하여 정책(Policy) 최적화
- 통찰: 다단계 미래 롤아웃(Rollout) 시 잠재 공간 내 복리 오차 누적(Compounding Error)으로 인한 비현실적 환각 위험이 상존하므로 예측 불확실성 앙상블 계측 및 현실 환경 주기적 앵커링(Anchoring) 필수

<details><summary>핵심 용어</summary>

- **월드 모델 (World Model)** : 물리적 환경의 시공간적 동역학(Dynamics)을 학습하여 행동에 따른 미래 상태와 보상을 예측하는 내부 시뮬레이터.
- **잠재 상태 (Latent State, $z_t$)** : 픽셀 단위의 방대한 관측 데이터에서 배경 노이즈를 배제하고 물리 법칙과 상호작용 핵심 정보만 압축한 벡터 표현.
- **상상 롤아웃 (Imagination Rollout)** : 물리 하드웨어를 직접 구동하지 않고 월드 모델 내부에서 수만 번의 가상 시뮬레이션을 초고속 실행하는 강화학습 기법.
- **DreamerV3** : 고정밀 이미지 예측 없이도 마인크래프트 등 복잡한 3D 환경에서 다이아몬드를 수집하는 범용 월드 모델 강화학습 알고리즘.
- **JEPA (Joint-Embedding Predictive Architecture)** : 픽셀 전체를 복원하는 낭비를 없애고 추상화된 임베딩 공간에서 미래 표현만을 예측하는 얀 르쿤(Yann LeCun)의 지능형 아키텍처.

</details>

## 2~4교시 25점 답안

## Ⅰ. 월드 모델의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **월드 모델** 은 에이전트가 현실 물리계의 인과율과 상태 전이 동역학(Dynamics)을 압축된 신경망 내부에 모사하여 가상 시뮬레이션을 통해 행동 결과를 사전 예측하고 계획하는 뇌 인지 모방 모델 |
| 목적 | 현실 환경과의 물리적 충돌 위험 및 시뮬레이터 구축 한계를 극복하고 초고속 가상 상상 학습을 통한 표본 효율성(Sample Efficiency) 극대화 |

## Ⅱ. 월드 모델의 3대 핵심 구성 요소 및 동역학 특징

| 핵심 구성 요소 | 수학적 표현 및 역할 | 기술적 특징 및 공학적 의미 |
|---|---|---|
| **표현 모델 (Representation)** | $z_t \sim q_\theta(z_t \mid z_{t-1}, a_{t-1}, x_t)$ | 고차원 이미지 관측 $x_t$를 불필요한 노이즈를 제거한 저차원 잠재 상태 $z_t$로 압축 인코딩 |
| **전이 모델 (Transition Dynamics)** | $\hat{z}_{t+1} \sim p_\phi(\hat{z}_{t+1} \mid z_t, a_t)$ | 현재 잠재 상태 $z_t$와 가상 행동 $a_t$가 주어졌을 때 다음 잠재 상태 $\hat{z}_{t+1}$의 확률 분포를 예측 |
| **보상/가치 모델 (Reward & Value)** | $\hat{r}_t \sim p_\psi(\hat{r}_t \mid z_t)$, $\hat{v}_t = v_\omega(z_t)$ | 미래 잠재 상태가 에이전트의 목표 달성에 얼마나 유리한지 보상 점수와 상태 가치를 즉시 평가 |
| **정책 액터 (Policy Actor)** | $a_t \sim \pi_\xi(a_t \mid z_t)$ | 잠재 공간 내에서 가치($\hat{v}_t$)를 극대화하는 최적의 행동 시퀀스를 역전파(Backpropagation)로 학습 |

## Ⅲ. 월드 모델의 내부 상상 롤아웃 및 제어 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             월드 모델 (World Model) 내부 상상 및 계획 파이프라인        │
└────────────────────────────────────────────────────────────────────────┘
 [ 실제 환경 관측 (Real Observation x_t) ]
                    │
                    ▼
 [ 1단계: 잠재 표현 인코딩 (Representation Model) ] ──> 잠재 상태 z_t 확정
                    │
 ┌──────────────────┴───────────────────────────────────────────────────┐
 │ 내부 상상 롤아웃 루프 (Imagination Space: 100% 잠재 공간 내 고속 연산) │
 │                                                                      │
 │   z_t ──> [ Actor: 가상 행동 a_t 선택 ]                             │
 │             │                                                        │
 │             ▼                                                        │
 │   [ Transition Model: 물리 법칙 예측 ] ──> 예측 상태 z_{t+1}         │
 │             │                                   │                    │
 │             ├─ [ Reward/Value 예측 ] ───────────┼────────────────┐   │
 │             │                                   │ (H-step 반복)  │   │
 │             ▼                                   ▼                │   │
 │   [ Actor: 가상 행동 a_{t+1} 선택 ] ──> [ 다음 상태 z_{t+2} ]    │   │
 │                                                                  │   │
 │   - 실제 로봇을 움직이지 않고 1초당 수만 개의 가상 미래 경로 시뮬레이션 │   │
 └──────────────────┬───────────────────────────────────────────────────┘
                    │
                    ▼
 [ 2단계: 최적 미래 궤적 선택 (Model Predictive Control / Policy Update) ]
                    │
                    ▼ 제어 신호
 [ 실제 환경 실행 (Real World Action a_t*) ] ──> [ 환경 상태 변화 x_{t+1} ]
```

| 프로세스 단계 | 세부 동작 내용 | 계산 최적화 기법 |
|---|---|---|
| **관측 압축 및 동기화** | 멀티 센서 입력으로부터 결정론적·확률적 잠재 벡터 결합 | RSSM (Recurrent State Space Model) |
| **잠재 공간 내 롤아웃** | GPU 메모리 상에서 물리 엔진 없이 $H$ 스텝(예: 15스텝) 미래 예측 전개 | 병렬 텐서 연산으로 수 밀리초 완결 |
| **경로 가치 최적화** | 상상된 경로들의 기대 보상 합산 및 정책 네트워크 파라미터 갱신 | $\lambda$-return 기반 경사하강법 |
| **실행 및 오차 보정** | 최적 경로의 첫 번째 행동 $a_t^*$만 현실에 실행 후 관측값으로 재보정 | MPC (Model Predictive Control) 닫힌 루프 |

## Ⅳ. 환경 시뮬레이션 기술 비교

| 비교 항목 | 전통 물리 엔진 (MuJoCo / PhysX) | 생성형 비디오 모델 (Sora / Gen-3) | 월드 모델 (World Model - 본 토픽) |
|---|---|---|---|
| **동역학 표현 방식** | 뉴턴 역학 기반 수학 수식 하드코딩 | 픽셀 디퓨전(Diffusion) 생성 | 잠재 공간(Latent Space) 신경망 전이 |
| **행동 조건부 제어** | 완벽한 힘/토크 입력 반영 | 텍스트 프롬프트 기반 (정밀 제어 불가) | 명시적 액션 벡터($a_t$) 조건부 예측 |
| **연산 속도** | 빠름 (CPU 연산 중심) | 극도로 느림 (초당 수 프레임 생성) | 극도로 빠름 (잠재 공간 내 수만 FPS) |
| **현실 세계 일반화** | 접촉 역학, 유체 등 모델링 한계 | 텍스트 기반 외형 일반화 우수 | 센서 데이터로부터 물리 인과율 자가 학습 |
| **주요 활용 목적** | 로봇 공학 시뮬레이션, 게임 | 엔터테인먼트, 영상 콘텐츠 생성 | 자율주행, 체화 AI 에이전트 자율 계획 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 상상 롤아웃 스텝이 길어질수록 잠재 공간의 예측 오차가 누적되어 현실과 완전히 동떨어지는 복리 오차(Compounding Error) | 앙상블 모델을 구성하여 모델 간 분산으로 에피스테믹 불확실성(Uncertainty)을 측정하고 신뢰도 높은 짧은 수평선(Horizon)만 계획 반영 |
| 픽셀 단위 시각 재구성(Autoencoder) 손실에 집중할 경우 배경 나뭇잎 흔들림 같은 무의미한 세부 노이즈에 과적합 | 픽셀 복원을 배제하고 오직 미래 상태의 가치와 행동 결과 예측에만 집중하는 JEPA(Joint-Embedding) 목적함수 전환 |
| 미학습된 돌발 상황(OOD, 예: 갑작스러운 야생동물 출몰)에서 월드 모델이 잘못된 낙관적 경로를 예측하여 충돌 유발 | 예측 불확실성이 임계치를 초과할 경우 즉시 상상 모드를 중단하고 룰 기반 하드웨어 비상 브레이크(Failsafe) 강제 가동 |

## Ⅵ. 제언

자율주행 및 로보틱스 현장에서의 복리 오차를 극복하고 안전성을 보장하기 위해 JEPA 잠재 예측기와 앙상블 불확실성 안전 게이트를 통합한 월드 모델 플래닝 아키텍처 구축 권고.

```text
[ 실시간 라이다/카메라 입력 ]
              │
              ▼
┌────────────────────────────────────────────────────────┐
│ V-JEPA 잠재 인코더 (Feature Extraction without Pixel Loss)│
│  - 배경 잡음 90% 제거, 핵심 물리적 상호작용 객체만 임베딩│
└────────────────────────────┬───────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────┐
│ 앙상블 월드 모델 전이 엔진 (World Model Panel: M=5)    │
│  - 5개 독립 전이 모델이 가상 행동별 미래 상태 병렬 예측│
└────────────────────────────┬───────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────┐
│ 불확실성 계측 안전 게이트 (Uncertainty-Aware Gate)      │
│  ├── 분산(Variance) < 임계치: [ 최적 궤적 자율 주행 승인 ]│
│  └── 분산(Variance) ≥ 임계치: [ OOD 경보 및 감속/정지 ]│
└────────────────────────────────────────────────────────┘
```

| 구분 | 단일 픽셀 재구성 월드 모델 | 제언: JEPA 기반 앙상블 월드 모델 |
|---|---|---|
| **학습 손실** | 픽셀 MSE 손실 (노이즈에 취약) | 표현 공간 잠재 예측 손실 (의미 중심) |
| **오차 누적** | 5스텝 이후 이미지 붕괴 발생 | 20스텝 이상 안정적 물리 궤적 유지 |
| **환각 방어** | 모델이 확신을 갖고 거짓 예측 | 앙상블 분산 측정을 통한 모르는 상태 인지 |
| **연산 효율** | 고비용 디코더 연산 필수 | 디코더 연산 완전 배제로 연산량 60% 절감 |
