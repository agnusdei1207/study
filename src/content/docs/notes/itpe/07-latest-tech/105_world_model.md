## 연관 키워드

- 월드 모델(World Model), 월드 파운데이션 모델(World Foundation Model), 잠재 공간(Latent Space)
- 전이 모델(Transition Model), 롤아웃(Rollout), 상상 학습(Imagination), 모델 예측 제어(MPC, Model Predictive Control)
- 복리 오차 누적(Compounding Error), JEPA(Joint-Embedding Predictive Architecture), 표본 효율성(Sample Efficiency), 앙상블 불확실성

## Ⅰ. 월드 모델의 개요

- 핵심 요약 : 행동의 결과를 모델 내부에서 먼저 예측해 보고 계획을 세우는 세계 내부 모사 모델.
- 개념 : 에이전트가 현실 세계의 인과 법칙과 **상태 전이 동역학**(Dynamics)을 압축된 신경망 안에 모사하여, 가상 시뮬레이션으로 행동의 결과를 미리 예측하고 계획하는 **월드 모델**(World Model).
- 배경 및 필요성 : 미래를 여러 단계 굴려 보는 롤아웃에서는 예측 오차가 쌓여 비현실적인 결과가 나오는 **복리 오차 누적**(Compounding Error)이 생긴다. 따라서 예측 불확실성을 앙상블로 측정하고, 현실 관측으로 주기적으로 보정하는 **앵커링**(Anchoring) 절차가 필요하다.
- 주요 목적 : 실제 환경에서 시험하며 생기는 물리적 충돌 위험을 줄이고, 가상 공간에서 학습하여 **표본 효율성**(Sample Efficiency)을 높이는 것.

## Ⅱ. 월드 모델의 특징 및 장점

- 핵심 요약 : 관측을 압축한 잠재 상태 위에서 행동 조건부 예측을 수행하므로, 실제 로봇을 움직이지 않고도 계획을 검증할 수 있는 구조.

1. 잠재 공간 예측 : 고차원 이미지를 저차원 상태로 압축하여 예측 → 픽셀 단위 연산보다 빠른 상상 계획이 가능.
2. 행동 조건부 예측 : 행동 벡터를 입력으로 받아 다음 상태를 예측 → 같은 상황에서 행동별 결과를 비교 가능.
3. 가상 학습 : 실제 시행 없이 많은 가상 경로를 평가 → 현실 시행 횟수와 파손 위험 감소.

## Ⅲ. 월드 모델의 구조 (흐름)

- 핵심 요약 : 관측을 잠재 상태로 인코딩한 뒤, 전이 모델과 보상 모델로 가상 미래를 굴려 최적 행동을 고르고, 그 결과만 실제로 실행하는 흐름.
- **전이 모델**(Transition Model) : 현재 잠재 상태와 행동을 받아 다음 잠재 상태의 분포를 예측하는 신경망. 물리 법칙을 데이터로부터 학습한다.
- **표현 모델**(Representation Model) : 고차원 관측에서 노이즈를 제거한 잠재 상태를 만드는 인코더.
- **보상·가치 모델**(Reward & Value) : 미래 상태가 목표에 얼마나 가까운지를 점수로 평가한다.

```text
[ 실제 관측 ]
      ↓
표현 모델 (잠재 상태 z_t)
      ↓
[ 상상 롤아웃 (잠재 공간) ]
행동 선택 → 전이 모델
   → 보상·가치 평가 반복
      ↓ 가상 궤적 여러 개 생성
      ↓
최적 궤적 선택 (MPC 등)
      ↓
실제 행동 1단계 실행
```

## Ⅳ. 월드 모델과 시뮬레이션 기술의 비교

- 핵심 요약 : 물리 엔진은 법칙을 직접 입력하고, 생성형 비디오 모델은 외형을 만들며, 월드 모델은 행동에 따른 인과를 잠재 공간에서 학습한다.

| 비교 항목 | 전통 물리 엔진 (예: MuJoCo, PhysX) | 생성형 비디오 모델 (예: Sora, Gen-3) | 월드 모델 |
| --- | --- | --- | --- |
| 동역학 표현 | 뉴턴 역학 수식을 사람이 설계 | 픽셀 확산 생성 | 잠재 공간 신경망 전이 |
| 행동 조건부 제어 | 힘과 토크를 직접 입력 | 텍스트 프롬프트 중심, 정밀 제어 어려움 | 행동 벡터를 조건으로 예측 |
| 연산 속도 | 빠름 (CPU 중심) | 느림 (프레임 생성 비용 큼) | 잠재 공간에서 빠른 상상 연산 |
| 일반화 | 접촉·유체 등 모델링 한계 | 외형 일반화 우수 | 센서 데이터로부터 인과 학습 |

- 선택 기준 : 물리 법칙이 명확하면 물리 엔진, 외형 생성이 목적이면 비디오 모델, 행동 계획이 목적이면 월드 모델을 고려한다.

## Ⅴ. 월드 모델의 한계와 방안

- 핵심 요약 : 롤아웃 오차 누적, 픽셀 손실의 과적합, 학습 밖 상황의 낙관적 예측을 짧은 계획 범위, 목적 함수 전환, 비상 정지로 통제.

```text
[ 불확실성 감시 흐름 ]

상상 롤아웃 예측
      ↓
앙상블 분산 측정
      ↓
임계치 초과 여부 판단
      ↓ 초과 시
상상 중단 → 규칙 기반 비상 제동
```

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 상상 롤아웃이 길어질수록 오차 누적 | 예측 오차가 단계마다 쌓여 현실과 괴리 | 앙상블로 불확실성을 측정하고 신뢰도 높은 짧은 구간만 계획에 반영 | 롤아웃 유효 길이 |
| 픽셀 복원 손실에 따른 무의미한 세부 과적합 | 배경 잡음까지 재현하느라 행동 판단 정보가 희석 | 픽셀 복원 대신 미래 상태의 가치 예측에 집중하는 JEPA 계열 목적 함수 채택 | 행동 예측 정확도 |
| 학습 밖 돌발 상황의 낙관적 오예측 | OOD 상황에서 잘못된 경로를 안전하다고 판단 → 충돌 | 불확실성이 임계치를 넘으면 상상 모드를 중단하고 규칙 기반 비상 제동 가동 | 임계치 초과 횟수 |

## Ⅵ. 월드 모델에 대한 기술사적 제언

- 핵심 요약 : 예측의 정확도보다 모델이 모르는 상황을 알아채고 물러서는 체계를 먼저 갖추어, 월드 모델을 안전 장치 안에서 운영하는 방향.

1. 연구 조직이 학습 목적 함수를 픽셀 손실에서 잠재 공간 예측 손실로 옮기는 기준을 세우고, 장기 예측 안정성을 평가 항목으로 정한다.
2. 시스템 안전 조직이 불확실성 임계치와 비상 제동 조건을 정의하고, 현장 시험 전 가상 검증 통과를 필수 절차로 둔다.
3. 운영 조직이 예측 오차와 실제 궤적의 차이를 상시 기록하여 재학습 주기를 정하고, 현실 관측으로 주기적 보정을 수행한다.

## Ⅶ. 결론

- 핵심 요약 : 월드 모델은 행동의 결과를 머릿속에서 먼저 굴려 보는 내부 시뮬레이터를 학습으로 얻는 기술.
- 시사점 : 상상이 현실을 대신할 수 없으므로, 불확실성 감시와 현실 보정 장치가 함께 설계되어야 실용 가치가 생긴다.
