### Ⅱ. 실제 대상과 가상 표현의 관계

```text
실제 대상·공정
      │ 관측 자료 전달
      ▼
데이터 연결·정합화
      │ 상태 정보 반영
      ▼
디지털 트윈 모델
      │ 분석·시나리오 결과
      ▼
운영자 판단·업무 결정
```

### Ⅲ. 적용과 주의점

| 활용 | 확인할 요소 |
|---|---|
| 설비 운영 | 상태 변화·점검 우선순위 |
| 공정 분석 | 조건별 결과 비교 |
| 설계·운영 | 모델 가정·자료 갱신 주기 |

모든 디지털 트윈이 실시간 양방향 연결이나 자동 제어를 갖는 것은 아님.

**제언:** 결정 위험도에 맞춰 모델 가정·자료 품질·갱신 주기를 검증하는 운영 설계.

## 2~4교시 25점 답안

### Ⅰ. 디지털 트윈의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **디지털 트윈(Digital Twin)** 은 실제 대상의 자료와 모델을 연결해 상태·거동을 분석하는 가상 표현 |
| 목적 | 실제 대상의 이해·분석과 운영·설계 의사결정 지원 |

### Ⅱ. 구성 요소와 정보 흐름

```text
실제 대상·공정
      │ 관측 자료 전달
      ▼
데이터 연결·정합화
      │ 상태 정보 반영
      ▼
디지털 트윈 모델
      │ 분석·시나리오 결과
      ▼
운영자 판단·업무 결정
```

| 구성 | 역할 |
|---|---|
| 실제 대상 | 물리 설비·제품·공정 |
| 자료 연결 | 센서·업무 시스템의 관측 정보 전달·정합화 |
| 가상 모델 | 대상의 상태·특성·거동을 표현 |
| 업무 응용 | 조회·예측·시나리오 분석과 의사결정 지원 |

실제 조치가 트윈 모델에서 물리 대상에 자동 전달되는지 여부는 구현·안전 요구에 따라 달라짐.

### Ⅲ. 유사 기술 구분과 제조 적용

| 유형 | 핵심 역할 | 실제 자료와의 관계 |
|---|---|---|
| 3D 모델 | 형상·공간 표현 | 설계 자료 중심일 수 있음 |
| 시뮬레이션 | 조건별 거동 계산 | 입력 조건에 따른 결과 분석 |
| 디지털 트윈 | 실제 상태 자료와 모델을 연계 | 갱신 방식·주기는 구현별로 다름 |

ISO 23247은 제조 분야 참조 프레임워크로, 특정 제품·기술 구현을 하나로 강제하는 규정이 아님.

| 제조 적용 | 업무 활용 |
|---|---|
| 설비 운영 | 상태 추세 분석과 점검 우선순위 지원 |
| 공정 개선 | 조건별 시뮬레이션 결과 비교 |
| 품질 분석 | 공정·검사 자료를 연결한 원인 탐색 |
| 수명주기 | 필요한 설계·생산·검사·정비 정보의 연계 |

### Ⅳ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 단위·시각·품질이 맞지 않는 현장 자료가 모델에 반영되면 분석 신뢰도가 떨어질 수 있음 | 자료 출처·단위·시각·갱신 주기를 관리하고 모델 결과를 현장 관측과 검증 |
| 검증되지 않은 모델 결과를 자동 제어에 쓰면 물리 설비에 오류가 전달될 수 있음 | 사람 승인·안전 인터록·복구 절차를 포함한 제한 운전부터 시험하고 근거에 따라 제어 범위 확대 |
