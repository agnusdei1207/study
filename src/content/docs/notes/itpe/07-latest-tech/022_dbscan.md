## 30초 인출

- 본질: **DBSCAN(Density-Based Spatial Clustering of Applications with Noise)** 은 사전에 군집 수(K)를 지정하지 않고, 데이터 포인트의 국소 밀도(Density)와 공간적 근접성을 기반으로 복잡한 기하학적 형태의 군집을 형성하고 이상치(Noise)를 분리하는 비지도 군집화 알고리즘
- 메커니즘: 반경(Eps) 내 최소 이웃 수(MinPts)를 만족하는 핵심점(Core)을 찾고, 밀도 도달 가능성(Density-reachable)을 따라 연결된 이웃들을 하나의 군집으로 확장하며 비연결점은 노이즈로 처리
- 통찰: 군집 간 밀도 편차가 심하거나 고차원 공간에서 단일 Eps 적용 시 군집 분할이 왜곡되므로 K-거리 그래프를 통한 엘보우(Elbow) 탐색 및 차원 축소(PCA) 선행 필수

<details><summary>핵심 용어</summary>

- **DBSCAN** : 밀도 기반 공간 군집화 알고리즘으로 노이즈 처리와 임의 형상 군집 탐색에 특화.
- **Eps (Epsilon, ε)** : 특정 데이터 포인트를 중심으로 이웃을 탐색하기 위한 유클리디언 공간상의 반경 거리.
- **MinPts (Minimum Points)** : 핵심점이 되기 위해 반경 Eps 내에 포함되어야 하는 최소 데이터 포인트 수(자기 자신 포함).
- **핵심점 (Core Point)** : 반경 Eps 내에 MinPts 이상의 이웃 데이터를 포함하고 있는 군집 중심 포인트.
- **경계점 (Border Point)** : 반경 Eps 내 이웃 수는 MinPts 미만이나, 다른 핵심점의 Eps 반경 내에 포함된 포인트.
- **노이즈점 (Noise Point)** : 핵심점도 아니고 어떤 핵심점의 이웃 반경에도 도달할 수 없는 고립된 이상치 포인트.

</details>

## 2~4교시 25점 답안

## Ⅰ. DBSCAN의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **DBSCAN** 은 데이터 공간 상에서 데이터가 조밀하게 모여 있는 고밀도 영역을 동일한 군집으로 묶고, 밀도가 낮은 희소 영역의 데이터를 노이즈(이상치)로 식별하여 제거하는 비지도학습 군집화 알고리즘 |
| 목적 | 기하학적 비선형(원형, 초승달형) 군집의 정확한 탐색, 사전에 군집 개수(K)를 지정해야 하는 한계 극복 및 이상치 노이즈의 강건한 필터링 |

## Ⅱ. DBSCAN의 3대 포인트 분류 및 기하학적 특징

| 구분 | 포인트 유형 | 판정 수학적 기준 | 공학적 역할 및 특징 |
|---|---|---|---|
| **핵심점 (Core)** | 군집의 내부 중심 | `|N_Eps(p)| >= MinPts` | 군집 형성의 시작점이자 밀도 전파의 허브 역할 수행 |
| **경계점 (Border)** | 군집의 외곽 테두리 | `|N_Eps(p)| < MinPts` and `p ∈ N_Eps(core)` | 군집의 외부 경계선을 구성하며 군집 간 경계 확장을 정지시킴 |
| **노이즈 (Noise)** | 이상치 및 아웃라이어 | `p` is neither Core nor Border | 어떤 군집에도 속하지 않는 결함 데이터 및 사기 이상치로 분류 |

## Ⅲ. DBSCAN 군집 확장 메커니즘 및 밀도 도달성 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ DBSCAN 밀도 기반 군집 형성 메커니즘 ]                │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 핵심점 p ] ──(Eps 반경 내 MinPts 충족)──► [ 직접 밀도 도달 가능: q ]
                                                        │
                                                        ▼ (연속적 전파)
 [ 핵심점 p ] ───► [ 핵심점 q ] ───► [ 핵심점 r ] ───► [ 경계점 s ]
  (p에서 s는 밀도 도달 가능(Density-reachable) 관계 성립, 단방향)
                                    │
                                    ▼ (양방향 연결성)
 [ 핵심점 p ] ◄───► [ 매개 핵심점 o ] ◄───► [ 핵심점 q ]
  (p와 q는 공통 핵심점 o를 통해 밀도 연결성(Density-connected) 성립, 동일 군집 확정)
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 전체 공간 순회 및 군집 할당 파이프라인 ]                              │
│  1. 미방문 임의 점 선택 ──> Eps 반경 내 이웃 카운트                    │
│  2. Core 판정 시 ──> 신규 군집 ID 생성 후 Queue에 이웃 삽입 및 확장     │
│  3. Border 판정 시 ──> 방문 표시 후 부모 Core 군집에 귀속               │
│  4. Noise 판정 시 ──> 임시 이상치 태깅 (추후 타 Core 확장에 흡수 가능)   │
└────────────────────────────────────────────────────────────────────────┘
```

| 밀도 개념 | 수학적 정의 | 군집 형성 시 의미 |
|---|---|---|
| **직접 밀도 도달** | $q \in N_\epsilon(p)$ 이고 $|N_\epsilon(p)| \ge \text{MinPts}$ | 핵심점 $p$에서 반경 내에 점 $q$가 직접 포함됨 |
| **밀도 도달 가능** | $p_1 \to p_2 \to \dots \to p_n$ 직접 도달 체인 존재 | 다단계 핵심점을 거쳐 도달 가능한 모든 점들을 포섭 |
| **밀도 연결성** | 공통 핵심점 $o$에 대해 $p$와 $q$가 모두 밀도 도달 가능 | 비대칭적 도달성을 극복하고 대칭적 동일 군집으로 병합 |

## Ⅳ. K-Means vs DBSCAN 비교

| 비교 항목 | K-Means 군집화 | DBSCAN 군집화 |
|---|---|---|
| **군집 개수(K) 설정** | 필수 (사용자가 K를 사전에 추정 입력) | 불필요 (데이터 밀도에 따라 자동 결정) |
| **군집 형상** | 볼록한 구형(Convex Spherical) 형태에 한정 | 초승달, 도넛 등 임의의 복잡한 비선형 형상 지원 |
| **이상치(Noise) 처리** | 모든 데이터를 억지로 특정 군집에 강제 할당 | 밀도 미달 데이터를 명시적 노이즈(-1)로 격리 |
| **시간 복잡도** | $O(N \cdot K \cdot I)$ (대규모 데이터에 매우 빠름) | $O(N \log N)$ (Kd-tree 활용 시), 최악 $O(N^2)$ |
| **하이퍼파라미터** | 클러스터 수 K | 탐색 반경 Eps, 최소 포인트 수 MinPts |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 데이터셋 내에 고밀도 군집과 저밀도 군집이 혼재할 경우 단일 Eps로 두 군집을 동시 포착 불가 | 밀도 변화에 적응적으로 다중 스케일 계층을 탐색하는 OPTICS 또는 HDBSCAN 알고리즘으로 전환 |
| 10차원 이상의 고차원 공간에서 거리 측정의 변별력이 소실되는 차원의 저주(Curse of Dimensionality) | 군집화 수행 전 PCA, t-SNE, UMAP 또는 오토인코더를 통한 2~3차원 매니폴드 축소 선행 |

## Ⅵ. 제언

DBSCAN의 핵심 파라미터(Eps, MinPts)를 시행착오 없이 객관적으로 도출하기 위해 K-Nearest Neighbor 거리 그래프의 엘보우(Elbow) 포인트 자동 탐색 파이프라인 구축.

```text
[ 다차원 센서/로그 원천 데이터 ]
               │
               ▼
[ StandardScaler 정규화 및 UMAP 차원 축소 ]
               │
               ▼
[ K-거리(K-Distance) 그래프 정렬 및 미분 ]
   ├── Step 1: k = 2 * dim 설정 후 각 점의 k번째 최근접 이웃 거리 계산
   ├── Step 2: 오름차순 정렬 후 곡선의 곡률(Curvature) 최대 변곡점 자동 탐색
   └── Step 3: 최적 Eps* 값 및 MinPts* 파라미터 확정
               │
               ▼
[ DBSCAN 실행 및 노이즈(이상치) 실시간 FDS 차단 ]
```

| 구분 | 엔지니어의 주관적 파라미터 감 | 제언: K-거리 엘보우 자동화 |
|---|---|---|
| **Eps 결정** | 임의의 값 대입 후 시각화 확인 반복 | 2차 미분 곡률 최대 변곡점 기반 수학적 자동 결정 |
| **이상치 분리** | 정상 데이터가 노이즈로 과도하게 오분류 | 최적 밀도 임계치 도출로 정상 군집 보존 극대화 |
| **자동화 파이프라인** | 실시간 배치 파이프라인 적용 불가 | 신규 배치 유입 시마다 적응형 재계산 지원 |
