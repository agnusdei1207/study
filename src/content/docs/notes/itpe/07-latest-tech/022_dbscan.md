## Ⅰ. DBSCAN의 개요

- 개념 : **Density-Based Spatial Clustering of Applications with Noise** 의 약어로, 데이터 공간에서 특정 **반경** (Epsilon, eps) 내에 **최소 샘플 수** (MinPts) 이상의 데이터가 밀집되어 있는 영역을 하나의 군집으로 지속 확장하며, 밀도가 낮은 영역의 데이터를 노이즈(이상치)로 자동 분류하는 **밀도 기반 비지도 군집화** (Clustering) 알고리즘.
- 배경 및 필요성 : 전통적인 **K-Means** 알고리즘은 사전에 군집 수(K)를 지정해야 하고, 구형(Spherical) 형태의 군집만 탐색 가능하며, 이상치에 극도로 취약한 치명적 한계가 존재하여 비선형 기하학적 형태의 복잡한 데이터 군집화를 위해 개발됨.
- 핵심 목적 : 사전 군집 수 지정 없는 자율 군집 탐색, 초승달·도넛 등 임의의 복잡한 기하학적 형상 군집화, 이상치(Noise)의 수학적 분리 및 노이즈 필터링.

## Ⅱ. DBSCAN의 핵심 아키텍처 및 동작 메커니즘

DBSCAN은 데이터 포인트를 핵심(Core), 경계(Border), 노이즈(Noise)의 3가지 유형으로 분류하고, **밀도 도달 가능성** (Density-Reachability)을 따라 군집을 연결 확장함.

```text
[ DBSCAN 데이터 포인트 3대 분류 및 군집 확장 메커니즘 ]

                 (MinPts = 4, 반경 = eps 기준)
                        
                        *  *
                     *   Core (이웃 >= 4)
                        *  *  \
                             \  eps
                              ▼
                           Border (Core의 eps 내 존재, 자체 이웃 < 4)
                           
            * (Noise Point : eps 내 어떤 Core에도 도달 불가)
```

```text
[ 세부 동작 단계 파이프라인 ]

1. 미방문 포인트 p 선택 ──► 반경 eps 내의 이웃 포인트 집합 N_eps(p) 탐색
        │
        ▼
2. 이웃 수 검사 : |N_eps(p)| >= MinPts ?
   - YES : p를 'Core Point'로 지정 ──► 신규 군집 C 생성 ──► 이웃 포인트들 큐(Queue)에 삽입
   - NO  : p를 임시 'Noise Point'로 표기 (추후 다른 Core의 Border가 될 수 있음)
        │
        ▼
3. 군집 확장 (Density-Connected)
   - 큐에서 포인트 q를 꺼내 Core 여부 확인 후 그 이웃들을 큐에 재귀적 병합
        │
        ▼
4. 모든 포인트가 방문될 때까지 반복 ──► 최종 Cluster들과 잔여 Noise 확정
```

- **핵심 포인트(Core Point)** : 반경 `eps` 내에 자신을 포함하여 최소 `MinPts`개 이상의 이웃이 존재하는 밀집 포인트.
- **경계 포인트(Border Point)** : `eps` 내 이웃 수는 `MinPts` 미만이지만, 어떤 핵심 포인트의 `eps` 반경 내에 속하는 포인트.
- **노이즈 포인트(Noise Point)** : 핵심 포인트도 아니고 경계 포인트에도 속하지 못하는 고립된 이상치.
- **밀도 연결성(Density-Connected)** : 포인트 p와 q 사이에 연속된 핵심 포인트 체인이 존재하여 밀도적으로 서로 도달 가능한 경우 동일 군집으로 병합.

## Ⅲ. DBSCAN의 세부 구성 요소 및 비교 분석

| 비교 항목 | K-Means | 계층적 군집화 (Hierarchical) | DBSCAN |
| --- | --- | --- | --- |
| **군집 수(K) 사전 지정** | 필수 (사전 K값 지정 필요) | 불필요 (덴드로그램 절단 지점 선택) | 불필요 (밀도에 따라 자동 결정) |
| **군집 형성 형태** | 원형, 볼록한 구형(Convex)에 한정 | 연결 방식에 따라 다양함 | 초승달, 링, 선형 등 임의의 기하학적 형태 |
| **이상치(Noise) 처리** | 이상치도 반드시 특정 군집에 강제 할당 | 덴드로그램 말단에서 식별 가능 | 노이즈 라벨(-1)로 명확히 분리 격리 |
| **시간 복잡도** | O(N * K * I) - 매우 빠름 | O(N^3) 또는 O(N^2 log N) - 느림 | 공간 색인 시 O(N log N), 최악 O(N^2) |
| **하이퍼파라미터** | K (클러스터 개수) | 거리 척도, 연결 방식 (Ward, Complete) | eps (탐색 반경), MinPts (최소 포인트 수) |

- 군집의 형태가 비선형이거나 데이터 내에 잡음(Noise)이 다수 섞여 있는 공간 데이터 분석에는 K-Means보다 DBSCAN이 압도적으로 우수함.

## Ⅳ. DBSCAN의 주요 한계점 및 해결 방안

- 서로 다른 밀도를 가진 군집들이 혼재된 데이터셋에서의 성능 저하 :
  - 한계점 : 단일한 고정 `eps` 파라미터를 전체 공간에 적용하므로, 밀도가 높은 군집에 맞추면 성긴 군집이 노이즈로 유실되고 성긴 군집에 맞추면 밀집 군집들이 하나로 뭉침.
  - 해결 방안 : 계층적 밀도 기반 군집화인 **HDBSCAN** (Hierarchical DBSCAN) 또는 **OPTICS** 알고리즘을 도입하여 가변 밀도 군집 처리.
- 고차원 데이터에서의 거리 집중(Distance Concentration) 및 차원의 저주 :
  - 한계점 : 차원이 증가할수록 모든 점 간의 유클리드 거리가 비슷해져 밀도의 고저 차이가 사라지고 모든 데이터가 노이즈로 판정.
  - 해결 방안 : PCA, UMAP, t-SNE 등을 통한 고차원 특징의 2~10차원 축소 후 적용 및 코사인 유사도 거리 척도 활용.
- 대규모 데이터셋(N > 100,000) 처리 시 메모리 및 연산 병목 :
  - 한계점 : 공간 인덱스가 없으면 O(N^2) 거리 계산으로 인해 연산 속도가 급격히 저하됨.
  - 해결 방안 : KD-Tree, Ball-Tree 등 **공간 분할 트리 색인** 을 필히 적용하고 분산 환경(Apache Spark GraphX) 기반 분산 DBSCAN 채택.

## Ⅴ. DBSCAN 적용 및 발전을 위한 기술사적 제언

- K-거리 그래프(K-distance Graph)를 활용한 최적 하이퍼파라미터 자동 산출 파이프라인 수립 : `MinPts = 2 * 차원수`로 기본 설정하고, K-거리 그래프의 급격한 굴곡(Elbow Point)을 수학적으로 탐지하여 `eps`를 자동 튜닝해야 함.
- GPS 궤적 분석 및 물류 배송 거점 클러스터링의 핵심 알고리즘으로 활용 : 위도·경도 공간 데이터의 불규칙한 이동 경로 분석 및 차량 정체 구역 추출에 하버사인(Haversine) 거리 기반 DBSCAN 우선 적용.
- 제조 반도체 웨이퍼 결함 및 사이버 침입 탐지의 1차 이상치 필터링 엔진 구축 : 정상 패턴 군집에 속하지 못하는 노이즈 라벨(-1)을 실시간 격리하여 제로데이 공격 및 희귀 결함을 사전 차단.
