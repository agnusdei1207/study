## 연관 키워드

- DBSCAN, 밀도 기반 군집화, eps, MinPts, 핵심 포인트, 경계 포인트, 노이즈 포인트
- 밀도 도달 가능성, K-Means, HDBSCAN, OPTICS, 차원의 저주, 공간 색인

## Ⅰ. DBSCAN의 개요

- 핵심 요약 : 밀도가 충분한 영역을 군집으로 넓혀 가고 희박한 점을 노이즈로 분리하는 밀도 기반 비지도 군집화.
- 개념 : 반경(eps) 안에 최소 샘플 수(MinPts) 이상의 점이 모인 영역을 군집으로 확장하고, 어느 군집에도 속하지 못한 점을 노이즈로 분류하는 **밀도 기반 군집화** (DBSCAN, Density-Based Spatial Clustering of Applications with Noise) 알고리즘.
- 배경 및 필요성 : 대표적인 **K-Means**는 군집 수 K를 미리 지정해야 하고, 구형 군집만 잘 찾으며, 이상치에 취약하므로 복잡한 형태의 데이터에 맞지 않음.
- 주요 목적 : 군집 수를 미리 정하지 않는 자율 탐색, 임의 형태의 군집 탐지, 이상치의 분리와 제거.

## Ⅱ. DBSCAN의 특징 및 장점

- 핵심 요약 : 점의 밀도만으로 군집을 정의해, 모양과 개수에 제약이 없고 노이즈가 자연스럽게 분리되는 방식.

1. 임의 형태 군집 : 점들이 밀도로 이어져 있으면 초승달, 고리 같은 모양도 하나의 군집으로 인식 → 구형 가정 없이 복잡한 공간 데이터 처리.
2. 군집 수 자동 결정 : 밀도 조건만으로 군집이 결정 → 사전 지식 없이 탐색 가능.
3. 노이즈 자동 분리 : 밀도가 낮은 점을 노이즈 라벨(-1)로 표시 → 이상치를 별도 처리하는 전처리 비용 감소.

```text
[ DBSCAN 점의 3가지 유형 ]

Core (eps 안 이웃 수 ≥ MinPts)
   ↑ eps 반경 안에 포함
Border (이웃 수는 부족, Core에 연결)

Noise (어떤 Core에도 도달 불가)
```

## Ⅲ. DBSCAN의 구조 (흐름)

- 핵심 요약 : 방문하지 않은 점에서 시작해 밀도 조건을 만족하는 점을 큐로 확장하며 군집을 키우는 반복 절차.

```text
[ 군집 확장 절차 ]

1. 미방문 점 p 선택
          ↓
2. eps 안 이웃 수 검사
          ↓ 이웃 수 ≥ MinPts
3. p를 Core로 지정, 새 군집 생성
          ↓
4. 이웃을 큐에 넣고 Core 여부를 반복 확인
          ↓
5. 모든 점 방문 후 군집과 노이즈 확정
```

- **밀도 도달 가능성** (Density-Reachability) : Core 점 체인을 따라 다른 점에 도달할 수 있으면 같은 군집으로 묶음.

## Ⅳ. DBSCAN의 비교

- 핵심 요약 : 군집 수 자동 결정과 임의 형태 탐지에서는 DBSCAN이 우위이고, 계산 비용과 가변 밀도 처리에서는 한계가 있음.

| 비교 항목 | K-Means | 계층적 군집화 | DBSCAN |
| --- | --- | --- | --- |
| 군집 수 지정 | K를 사전에 지정해야 함 | 덴드로그램 절단 지점으로 결정 | 밀도 조건으로 자동 결정 |
| 군집 형태 | 볼록한 구형에 한정 | 연결 방식에 따라 다양 | 임의의 기하 형태 |
| 이상치 처리 | 특정 군집에 강제 배정 | 말단에서 식별 가능 | 노이즈 라벨로 분리 |
| 시간 복잡도 | O(N·K·I), 빠름 | O(N²) 이상, 느림 | 공간 색인 사용 시 평균 O(N log N) |
| 하이퍼파라미터 | K | 거리 척도, 연결 방식 | eps, MinPts |

- 군집 형태가 비선형이거나 노이즈가 많은 공간 데이터에서는 K-Means보다 DBSCAN이 적합함.

## Ⅴ. DBSCAN의 한계와 방안

- 핵심 요약 : 가변 밀도, 고차원, 대규모 데이터 문제를 알고리즘 변형, 차원 축소, 공간 색인으로 해결.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 밀도가 서로 다른 군집의 혼재 | 단일 eps를 전체에 적용하면 성긴 군집은 노이즈, 밀집 군집은 병합 | **HDBSCAN** (Hierarchical DBSCAN) 또는 **OPTICS** (Ordering Points To Identify the Clustering Structure) 적용 | 노이즈 비율, 군집 안정성 |
| 고차원에서의 거리 집중 | 차원이 커지면 점 간 거리가 비슷해져 밀도 차이가 사라짐 | PCA, UMAP 등으로 차원 축소 후 적용, 코사인 거리 활용 | 차원 축소 후 노이즈 비율 |
| 대규모 데이터의 연산 병목 | 공간 색인이 없으면 거리 계산이 전체 쌍으로 늘어남 | KD-Tree, Ball-Tree 같은 **공간 분할 트리** 색인 적용, 분산 구현 검토 | 군집화 소요 시간 |

## Ⅵ. DBSCAN에 대한 기술사적 제언

- 핵심 요약 : eps 산정 절차, 위치 데이터 적용, 이상 탐지 필터를 실무 활용의 세 방향으로 제시.

1. eps 자동 산정 절차 : K-거리 그래프를 그려 급격히 꺾이는 지점(Elbow Point)을 찾아 eps를 정하고, MinPts는 차원 수에 비례한 기본값에서 출발해 검증함.
2. 위치 데이터 분석에의 적용 : 위도·경도 데이터는 하버사인 거리 기반으로 계산해 차량 정체 구역이나 배송 거점을 추출하는 데 우선 적용함.
3. 이상 탐지 1차 필터 : 정상 패턴 군집에 속하지 못한 노이즈 점을 실시간으로 분리해 희귀 결함이나 비정상 트래픽을 2차 분석 대상으로 넘기는 구조로 운영함.

## Ⅶ. 결론

- 핵심 요약 : DBSCAN은 밀도만으로 군집과 노이즈를 동시에 판정하는 군집화 기법.
- 시사점 : 군집 수를 모르거나 이상치가 많은 데이터일수록 가치가 높으며, eps 설정과 고차원 처리가 실무 성패를 가름.
