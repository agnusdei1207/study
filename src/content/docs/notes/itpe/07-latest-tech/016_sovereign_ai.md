## 30초 인출

- 본질: **소버린 AI(Sovereign AI)** 는 글로벌 빅테크에 대한 기술·인프라 종속을 탈피하고, 국가와 기업이 자체적인 데이터 주권, 연산 인프라, 파운데이션 모델 및 비즈니스 거버넌스를 독립적으로 통제·운영하는 전략적 체계
- 메커니즘: 자국어·도메인 특화 데이터 구축 후 국산 NPU/가속기 기반 데이터센터에서 오픈웨이트 파운데이션 모델을 독자 학습·배포하여 문화적 맥락 보존 및 공급망 자립 달성
- 통찰: 모든 스택의 100% 국산화는 막대한 자본과 엔지니어링 한계에 직면하므로 국산 NPU와 오픈웨이트 모델을 결합한 실리적 하이브리드 소버린 생태계 구축 필수

<details><summary>핵심 용어</summary>

- **소버린 AI (Sovereign AI)** : 국가 또는 조직이 디지털 주권을 보호하기 위해 AI 인프라, 데이터, 모델, 인력을 독자적으로 통제하는 역량.
- **데이터 주권 (Data Sovereignty)** : 생성된 데이터가 생성 주체의 법률적 관할권 내에 머물며 타국 법률의 역외 적용을 받지 않도록 통제하는 권리.
- **오픈웨이트 모델 (Open-weight Model)** : 파라미터 가중치가 공개되어 자국 내 온프레미스 인프라에 독자 구축 및 미세조정이 가능한 모델 (Llama, Mistral 등).
- **국산 NPU 가속기** : 외산 GPU 의존성을 낮추기 위해 개발된 고효율 저전력 인공지능 추론·학습용 반도체 (Rebellions, FuriosaAI, Sapeon).
- **문화적 정렬 (Cultural Alignment)** : 서구 중심 빅테크 모델의 편향에서 벗어나 자국의 고유한 역사, 법률, 윤리, 언어적 뉘앙스를 충실히 반영하는 모델 정렬.

</details>

## 2~4교시 25점 답안

## Ⅰ. 소버린 AI의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **소버린 AI(Sovereign AI)** 는 국가나 특정 조직이 외산 빅테크의 클라우드 및 알고리즘 종속에서 벗어나, 자체 인프라, 고유 언어·문화 데이터, 독자적 AI 모델 및 법제 거버넌스를 주체적으로 소유·통제하는 전략적 기술 패러다임 |
| 목적 | 국가 안보 및 데이터 주권 수호, 핵심 산업 기밀의 해외 유출 방지, 자국 고유의 언어·문화 정체성 보존 및 AI 공급망 리스크 완화 |

## Ⅱ. 소버린 AI의 4대 핵심 축 및 추진 필요성 특징

| 구분 | 4대 핵심 축 | 상세 구축 전략 및 특징 |
|---|---|---|
| **데이터 주권 (Data)** | 자국 영토 내 데이터 격리 | 공공·금융·의료 데이터를 국경 내 보관하고, 한국어 어휘 및 법률 특화 고품질 코퍼스 구축 |
| **인프라 자립 (Infra)** | 국산 NPU 및 소버린 클라우드 | 외산 엔비디아 GPU 종속 완화를 위한 국산 AI 반도체 실증 및 공공 전용 AIDC 인프라 확보 |
| **모델 주권 (Model)** | 자국어 최적화 독자 파운데이션 | 글로벌 모델의 편향성을 배제하고 자국 법률·행정·역사적 맥락을 정확히 이해하는 독자 SLM/LLM 개발 |
| **거버넌스 주권 (Gov)** | 국가 법제 및 AI 윤리 통제 | 인공지능기본법, 개인정보보호법 기반의 독자적 규제·진흥 균형 체계 수립 및 글로벌 규범 선도 |

## Ⅲ. 소버린 AI 프레임워크 및 국가·기업별 구축 아키텍처

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 국가 및 엔터프라이즈 소버린 AI 프레임워크 ]          │
└────────────────────────────────────────────────────────────────────────┘
                                    │
┌────────────────────────────────────────────────────────────────────────┐
│ [ 4. 소버린 거버넌스 및 정책 ] : 인공지능기본법, 공공 보안인증(CSAP), 윤리 기준 │
├────────────────────────────────────────────────────────────────────────┤
│ [ 3. 소버린 모델 계층 ] : 자국어 특화 파운데이션 모델, 오픈소스 sLLM 파인튜닝│
├────────────────────────────────────────────────────────────────────────┤
│ [ 2. 소버린 데이터 계층 ] : 행정/법률/역사 데이터 패브릭, 도메인 벡터 DB    │
├────────────────────────────────────────────────────────────────────────┤
│ [ 1. 소버린 인프라 계층 ] : 국산 NPU 팜, 국내 소버린 전용 AIDC, 무손실 패브릭│
└────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 소버린 AI 서비스 실행 루프 ]                                          │
│  공공/국방/금융 민감 데이터 ──> 온프레미스 sLLM 추론 ──> 영내 데이터 완전 격리 │
└────────────────────────────────────────────────────────────────────────┘
```

| 프레임워크 계층 | 핵심 구축 기술 | 도입 효과 및 통제 방안 |
|---|---|---|
| **소버린 인프라** | 국내 CSP 망 분리 클라우드, 국산 추론 NPU | 데이터 역외 전송 차단, 칩 수급 제재(Embargo) 위험 차단 |
| **소버린 데이터** | 한국어 고문헌/행정문서 디지털화, PII 필터링 | 저작권 분쟁 배제, 한국 문화 맥락에 부합하는 정렬 데이터 확보 |
| **소버린 모델** | 오픈웨이트 Llama/Mistral 기반 파인튜닝 | 외산 API 비용 절감 및 독자 지적재산권(IP) 확보 |
| **소버린 정책** | AI 영향평가, 보안 인증(CSAP 하 상향) | 국가 중요 시스템 내 무단 백도어 및 악의적 접근 차단 |

## Ⅳ. 글로벌 빅테크 종속형 AI vs 소버린 AI 비교

| 비교 항목 | 글로벌 빅테크 종속형 AI (BigTech AI) | 소버린 AI (Sovereign AI) |
|---|---|---|
| **인프라 위치** | 해외 글로벌 하이퍼스케일러 클라우드 | 국내 관할권 내 온프레미스 또는 로컬 클라우드 |
| **데이터 흐름** | 해외 데이터센터로 질의 및 데이터 전송 | 국가/기업 방화벽 내부에서 데이터 전량 완결 처리 |
| **문화적 이해도** | 영미권 시각에 편향된 역사·사회적 답변 | 자국 고유의 문화, 미풍양속, 법령 체계 정밀 반영 |
| **서비스 연속성** | 공급사의 API 정책 변경 및 일방적 중단 위험 | 자체 가중치 및 인프라 보유로 무기한 서비스 연속성 보장 |
| **비용 구조** | 사용량 기반 외화 유출 및 지속적 API 종속 | 초기 인프라 투자 후 안정적인 고정 운영비 구조 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 수조 원 규모의 GPU 인프라와 초거대 모델을 단독 개발할 경우 국가적 재정 및 자원 소모 극심 | 오픈웨이트(Open-weight) 모델을 기반으로 도메인 특화 튜닝을 수행하고 국산 NPU를 추론에 우선 투입 |
| 폐쇄적인 자국 모델 고집 시 글로벌 최첨단 SOTA(State-of-the-Art) 모델과의 성능 격차 심화 | 비민감 일반 태스크는 글로벌 상용 API를 활용하고, 핵심 공공·보안 태스크는 소버린 AI를 적용하는 하이브리드 라우팅 채택 |

## Ⅵ. 제언

국가적 자원 낭비를 방지하기 위해 민간-공공 협력(PPP) 모델을 활성화하고, 국산 NPU와 오픈소스 sLLM을 결합한 턴키형 소버린 AI 어플라이언스 확산 체계 구축.

```text
[ 공공기관 / 국방 / 금융 고객 ]
                │ (민감 데이터 처리 요청)
                ▼
[ 턴키형 소버린 AI 어플라이언스 (Sovereign AI Box) ]
   ├── Step 1: 국산 NPU 카드 탑재 저전력 온프레미스 랙 서버
   ├── Step 2: 자국어 특화 7B~14B 경량 sLLM 및 도메인 RAG 엔진 내장
   └── Step 3: 외부 인터넷 연결이 완전 차단된 에어갭(Air-Gapped) 환경 구동
                │
                ▼
[ 완벽한 데이터 주권 수호 및 외화 유출 방지 달성 ]
```

| 구분 | 전면 외산 의존형 구축 | 제언: 턴키형 소버린 AI 어플라이언스 |
|---|---|---|
| **망 분리 대응** | 외부 인터넷 연결 필수로 망 분리 위반 | 에어갭 폐쇄망 환경 완벽 구동 지원 |
| **비용 구조** | 달러 결제 API 호출로 외화 유출 심화 | 국산 하드웨어 기반 1회성 라이선스 및 고정비 절감 |
| **기술 자립** | 알고리즘 블랙박스로 수정 권한 부재 | 모델 가중치 및 소스코드 완전 보유로 맞춤형 고도화 가능 |
