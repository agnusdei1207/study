## 한 줄 본질
- 글로벌 빅테크의 AI 기술 독점과 데이터 역외 유출로 인한 디지털 종속 위기 → 자국의 언어·역사·법률 데이터와 국산 인프라를 바탕으로 독자적인 AI 파운데이션 모델을 확보 → 문화적 주권 및 경제 안보 수호 / 천문학적 컴퓨팅 투자비 대비 모델 성능 격차 발생

## 핵심 그림
```text
+-------------------------------------------------------------------+
|               소버린 AI (Sovereign AI) 4대 핵심 기둥               |
+-------------------------------------------------------------------+
| 1. 데이터 주권 (Data)      : 공공/문화 데이터 역외 반출 차단,     |
|                              한국어·도메인 고품질 코퍼스 구축      |
+-------------------------------------------------------------------+
| 2. 인프라 주권 (Infra)     : 국가 거점 AI데이터센터(AIDC),         |
|                              국산 AI 반도체(NPU/PIM) 인프라 자립   |
+-------------------------------------------------------------------+
| 3. 모델 주권 (Model)       : 오픈웨이트 기반 도메인 파운데이션 모델,|
|                              자국 법률·윤리 가치관 정렬(Alignment) |
+-------------------------------------------------------------------+
| 4. 거버넌스 주권 (Gov)     : 인공지능기본법, 독자 안전성 평가(CAT) |
+-------------------------------------------------------------------+
```

## 핵심 용어
- 데이터 주권(Data Sovereignty): 특정 국가 내에서 생성된 디지털 데이터는 해당 국가의 법률과 관할권의 지배를 받아야 한다는 원칙
- 오픈웨이트 모델(Open-weight Model): 모델의 가중치 파라미터가 공개되어 국가나 기업이 자체 서버(On-premise)에서 완전한 제어권을 갖고 미세조정할 수 있는 모델
- 국산 NPU(Neural Processing Unit): 외산 GPU(Nvidia 등) 종속을 탈피하기 위해 국내 기술로 설계·생산하는 고효율 신경망 연산 가속 칩

## 핵심 통찰
- 소버린 AI는 단순한 "국산화 애국주의"가 아니라, 외교적 분쟁이나 공급망 제재 발생 시 국가 핵심 인프라가 마비되는 것을 막는 "안보 필수재"
- 전 세계 모든 지식을 담은 범용 빅테크 모델과 1:1로 자본력 경쟁을 하는 것은 불가능 → 자국어, 현지 법률, 공공 행정, 국방 등 로컬 도메인 특화로 경쟁력 집중이 합리적
- 완전한 독자 개발(from scratch)보다는 LLaMA 등 오픈 모델을 기반으로 자국 데이터를 활용해 사후 학습(Post-training)하는 실리적 노선이 확산 중

## 이웃 토픽과 구분
- 소버린 AI vs 오픈소스 AI: 오픈소스 AI는 소스/가중치의 자유로운 공유와 생태계 중심 / 소버린 AI는 국가 안보와 데이터 통제권을 목표로 자국 영토 내에서 인프라와 권한을 배타적으로 통제하는 전략

## 문제·원인·대책
- 적용 상황: 정부 공공 행정 서비스에 외산 클라우드 LLM 도입 검토 시 안보 우려
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 공공 행정 기밀의 해외 클라우드 유출 위험 | 외산 상용 LLM API 호출 시 미국 등 해외 리전으로 데이터 전송 | 에어갭(Air-gapped) 온프레미스 인프라에 소버린 LLM 구축 | 국가 핵심 기밀의 물리적 역외 유출 원천 차단 |
| 한국 역사·문화적 맥락의 왜곡 응답 | 외산 모델의 서구권 중심 학습 데이터 편향 | 국립국어원 등 공공 한국어 코퍼스 기반 도메인 SFT/DPO 수행 | 한국 역사·법률·사회적 가치관에 부합하는 정렬 달성 |
| 엔비디아 GPU 수급난 및 가격 폭등 | 외산 특정 하드웨어에 대한 절대적 의존 | 국산 NPU(사피온, 리벨리온 등) 실증 사업 및 소프트웨어 스택 지원 | 추론 인프라 비용 절감 및 하드웨어 공급망 리스크 분산 |

## 내 의견
- [원천 모델 전면 개발보다 '오픈웨이트 + 국산 NPU' 연합 생태계 구축] 수조 원의 사전 학습(Pre-training) 비용을 전액 국비로 감당하기는 비효율적임 → 나라면: 글로벌 고성능 오픈웨이트 모델을 베이스로 삼아, 정부 주도로 정제한 공공 데이터를 주입하고, 국산 NPU에 최적화된 컴파일러 스택(ONNX, Triton)을 지원하는 하드웨어-소프트웨어 풀스택 컨소시엄 육성
