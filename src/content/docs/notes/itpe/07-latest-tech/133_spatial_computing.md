지식 위치: 최신기술 → 실감 인터페이스 → **공간 컴퓨팅**

## 30초 인출

- 본질: **공간 컴퓨팅은** 물리 공간의 위치·형상과 디지털 콘텐츠를 결합하여 사용자가 공간 안에서 상호작용하는 컴퓨팅 방식
- 메커니즘: 센서 관측 → 위치·공간 추정 → 콘텐츠 배치·가림 처리 → 시선·손·음성 입력 → 화면·음향 출력
- 통찰: 한계: 추적 정확도만 보면 현장 입력 피로·주변인 노출을 놓침 → 방안: 대표 작업에서 위치 오차·완료시간·피로·촬영 범위를 함께 측정

<details><summary>핵심 용어</summary>

- **공간 추적** : 기기·사용자의 위치와 방향 추정
- **공간 매핑** : 주변 표면과 물체의 위치·형상 표현
- **가림 처리** : 실제 물체와 가상 콘텐츠의 앞뒤 관계 표현
- **공간 입력** : 시선·손동작·음성 등의 상호작용 신호

</details>

## 2~4교시 25점 답안

## Ⅰ. 공간 컴퓨팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **공간 컴퓨팅은** 물리 공간의 위치·형상과 디지털 콘텐츠를 결합하여 사용자가 공간 안에서 상호작용하는 컴퓨팅 방식 |
| 목적 | 작업 공간의 맥락을 반영한 정보 배치와 직관적인 상호작용 지원 |

## Ⅱ. 처리 구조

```text
카메라·관성 센서 입력
        ↓
기기 위치·주변 공간 추정
        ↓
콘텐츠 위치 결정·가림 처리
        ↓
시선·손·음성 입력 해석
        ↓
영상·음향 출력 및 상태 갱신
```

| 단계 | 오류가 미치는 영향 | 확인 방법 |
|---|---|---|
| 추적 | 가상 객체 위치의 흔들림 | 이동·조명 변화 중 정합 오차 측정 |
| 입력 | 의도와 다른 선택 | 시선과 손동작의 확인 절차 시험 |
| 출력 | 지연과 피로 | 작업시간별 지연·사용성 평가 |

## Ⅲ. 화면 중심 인터페이스와의 차이

| 기준 | 화면 중심 | 공간 컴퓨팅 |
|---|---|---|
| 기준 좌표 | 창·화면 내부 | 사용자·기기·주변 공간 |
| 입력 | 포인터·터치 중심 | 시선·손·음성 등 공간 입력 |
| 정보 배치 | 제한된 화면 영역 | 시야와 실제 공간을 고려한 배치 |

공간 컴퓨팅이 모든 작업에서 기존 화면보다 유리한 것은 아님. 긴 문서 입력·정밀 조작 등은 작업별 입력 방식 비교가 필요.

**운영과 정보 보호**

| 위험 | 검증·대응 |
|---|---|
| 주변인·공간 촬영 | 필요한 센서 데이터와 앱 권한의 범위 확인 |
| 눈·손 입력 기록 | 저장·전송·삭제 정책과 접근 통제 확인 |
| 장시간 사용 피로 | 기기 무게·시야·입력 방식의 작업별 시험 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 추적 정확도만 평가하면 현장 작업의 입력 피로와 주변인 노출을 놓칠 수 있음 | 대표 작업을 정해 위치 오차·완료시간·피로·촬영 범위를 함께 측정한 뒤 적용 영역 결정 |

## Ⅴ. 제언

우선 한 현장 작업의 추적·입력·촬영 허용 기준을 사용자와 함께 정함.

## 출제 이력과 검증 출처

- 확인한 제132~140회 정보관리기술사 공식 문제지에서 표제어 직접 출제 미확인; 그 밖의 회차는 원문 미대조
