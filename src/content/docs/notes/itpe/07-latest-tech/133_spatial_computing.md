## 30초 인출
- 본질: 컴퓨터 화면의 2차원 사각 프레임 한계를 벗어나 물리적 3차원 공간 자체를 사용자 인터페이스(UI)로 삼아 디지털 객체와 현실 공간을 실시간 결합·상호작용하는 컴퓨팅 패러다임
- 메커니즘: 센서 융합(LiDAR/카메라/IMU) → 실시간 공간 매핑 및 6DoF SLAM 추적 → 시선/제스처/음성 멀티모달 입력 인식 → 3차원 광학 투과/비디오 패스스루 렌더링 및 공간 음향 출력
- 통찰: 정밀 공간 매핑 이면에 상시 카메라/센서 구동에 따른 주변인 프라이버시 침해 및 장시간 착용 피로도(시각 피로, VIMS)가 상존하므로 엣지 온디바이스 익명화 처리와 인체공학적 경량화 설계 필수

<details><summary>핵심 용어</summary>

- **공간 컴퓨팅(Spatial Computing):** 물리적 현실 세계의 기하학적 형상과 좌표를 인식하여 디지털 콘텐츠를 현실 공간에 융합하고 자연스럽게 상호작용하는 차세대 컴퓨팅 기술
- **6DoF SLAM:** 카메라와 IMU 센서 데이터를 융합하여 기기의 3차원 위치(X, Y, Z)와 회전(Roll, Pitch, Yaw)을 실시간 추정하고 주변 환경 지도를 생성하는 기술
- **오클루전(Occlusion, 가림 처리):** 현실의 실제 물체 뒤로 가상 객체가 지나갈 때 현실 물체에 의해 가상 객체가 자연스럽게 가려지도록 깊이(Depth)를 실시간 연산하는 기술
- **패스스루(Pass-through):** HMD 외부에 장착된 초저지연 카메라를 통해 현실 세계의 고해상도 영상을 디스플레이로 실시간 전송하여 보여주는 비디오 혼합현실 기술
- **시선 추적(Eye Tracking) & 핀치 제스처:** 착용자의 동공 움직임을 적외선 카메라로 추적하여 대상을 타깃팅하고 엄지와 검지를 맞부딪히는 미세 손동작으로 선택하는 차세대 공간 입력 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 공간 컴퓨팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 물리적 3차원 현실 공간의 좌표, 표면, 깊이 정보를 센서로 인식하고 디지털 콘텐츠를 동일 공간 좌표계에 영속적으로 배치하여 상호작용하는 기술 체계 |
| 목적 | 2차원 화면(모니터, 스마트폰) 경계 탈피, 현실 공간 맥락 기반 정보 직관화, 작업 생산성 극대화 및 자연스러운 인간-컴퓨터 상호작용(Natural HCI) 제공 |

## Ⅱ. 공간 컴퓨팅의 핵심 특징

| 특징 영역 | 주요 특성 | 기술적 구현 내용 |
|---|---|---|
| **공간 앵커링** | 물리 좌표계 기반 가상 객체 영속 배치 | Spatial Anchor를 통해 현실 벽면, 테이블에 가상 윈도우 고정 및 세션 간 위치 복원 |
| **물리 법칙 융합** | 현실 물리 법칙과의 정밀한 상호작용 | 깊이 센싱 기반 오클루전(Occlusion), 가상 광원과 현실 그림자 일치(Realistic Lighting) |
| **내추럴 인터랙션** | 마우스·컨트롤러 없는 인체 중심 입력 | 눈동자 시선(Eye Gaze) 타깃팅, 손가락 핀치(Pinch) 클릭, 음성 명령의 유기적 결합 |
| **공간 음향 (Spatial Audio)** | 거리와 방향이 반영된 지향성 입체 음향 | 머리 전달 함수(HRTF) 및 실내 공간 음향 반사율 연산 기반 음원 위치 시뮬레이션 |

## Ⅲ. 공간 컴퓨팅 시스템 아키텍처 및 처리 프로세스

### 1. 공간 컴퓨팅 엔드투엔드 시스템 아키텍처
```text
+-----------------------------------------------------------------------------------+
|                        공간 컴퓨팅 하드웨어 및 소프트웨어 스택                    |
+-----------------------------------------------------------------------------------+
|  [센싱 및 공간 인지 계층 (Sensing & Spatial Perception)]                          |
|    - 센서 군: 고해상도 패스스루 카메라, LiDAR 스캐너, 적외선 시선 추적기, IMU     |
|    - 6DoF Visual-Inertial SLAM (실시간 기기 3D 포즈 추적)                         |
|    - 3D 공간 메싱(Spatial Meshing) 및 시맨틱 세그멘테이션 (바닥, 벽, 가구 인식)  |
+-----------------------------------------------------------------------------------+
                               │ (실시간 공간 좌표계 & 깊이 버퍼)
                               ▼
+-----------------------------------------------------------------------------------+
|  [공간 인터랙션 및 입력 해석 계층 (Interaction & Input Intelligence)]              |
|    - 시선 추적 파이프라인 (Eye Tracking: 초당 90Hz 이상 시선 포인팅 계산)        |
|    - 컴퓨터 비전 기반 손 추적 (Hand Tracking: 25개 손가락 관절 좌표 실시간 추정) |
|    - 멀티모달 제스처 인식 엔진 (Pinch, Drag, Zoom, Virtual Typing)               |
+-----------------------------------------------------------------------------------+
                               │ (이벤트 스트림 및 물리 엔진 연동)
                               ▼
+-----------------------------------------------------------------------------------+
|  [실시간 공간 렌더링 및 오디오 계층 (Spatial Rendering & Audio)]                  |
|    - 초저지연 패스스루 파이프라인 (Photon-to-Motion 지연 12ms 이내 달성)          |
|    - 3D 공간 렌더링 엔진 (오클루전 섀도잉, 시선 유도 렌더링: Foveated Rendering)  |
|    - 공간 음향 합성기 (HRTF 기반 음향 반사 및 회절 실시간 시뮬레이션)            |
+-----------------------------------------------------------------------------------+
```

### 2. 공간 인터랙션 처리 파이프라인
```text
[공간 센싱] ──────> [좌표계 일치] ──────> [사용자 의도] ──────> [공간 렌더링]
  LiDAR / IMU        물리-디지털 메싱       시선 응시 + 핀치        오클루전 / 섀도우
  (실시간 매핑)      (Spatial Anchor)       (타깃팅 및 선택)        (초저지연 12ms 출력)
```

## Ⅳ. 전통적 2D 컴퓨팅 대비 비교 및 핵심 기술 체계

### 1. 전통적 2D 화면 컴퓨팅 vs 공간 컴퓨팅 비교
| 비교 항목 | 전통적 2D 화면 컴퓨팅 | 3D 공간 컴퓨팅 (Spatial Computing) |
|---|---|---|
| **디스플레이 영역** | 고정된 물리적 디스플레이(모니터, 폰) 화면 | 사용자 시야각(FoV) 전방의 무한 3차원 물리 공간 |
| **좌표계 체계** | 2차원 평면 픽셀 좌표계 (X, Y) | 물리 세계와 결합된 3차원 월드 좌표계 (X, Y, Z, Roll, Pitch, Yaw) |
| **입력 도구** | 키보드, 마우스, 터치스크린 | 시선(Eye), 손동작(Gesture), 공간 음성(Voice), 햅틱 |
| **객체 관계성** | 가상 창들의 Z-Order(단순 레이어 겹침) | 실제 가구 및 벽면과의 물리적 오클루전 및 반사광 일치 |
| **적용 영역** | 문서 작성, 2D 웹 브라우징 | 디지털 트윈 협업, 원격 수술 보조, 몰입형 공간 설계 |

### 2. 공간 컴퓨팅 핵심 구현 기술 체계
| 기술 요소 | 핵심 기능 및 역할 | 성능 요구 기준 및 핵심 알고리즘 |
|---|---|---|
| **Visual-Inertial SLAM** | 기기의 절대 위치 및 공간 구조 동시 파악 | 오차 범위 1cm 미만, EKF(확장 칼만 필터) 및 번들 조정 |
| **Foveated Rendering** | 시선이 머무는 중심와만 고해상도 렌더링 | GPU 렌더링 연산량 50% 이상 절감, 시선 추적 지연 < 5ms |
| **비디오 패스스루** | 현실 세계를 카메라로 캡처해 디스플레이 표출 | Photon-to-Motion 지연 12ms 이하 (멀미 현상 원천 차단) |
| **동적 오클루전** | 현실 물체 뒤 가상 객체 가림 처리 | 실시간 깊이 맵(ToF/LiDAR) 추출 및 Z-버퍼 마스킹 연산 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **상시 카메라 센싱에 따른 사생활 침해**<br />HMD 외부 카메라가 사용자의 사적 공간 및 주변인의 얼굴/신원을 무단 촬영·유출할 위험 | 하드웨어 레벨의 암호화 엔클레이브(Secure Enclave) 처리, 원시 영상 외부 반출 금지 및 온디바이스 특징점(Feature) 추출 후 즉각 파기 |
| **시각 피로 및 시각유발 어지럼증(VIMS)**<br />가상 객체 초점 거리와 물리적 디스플레이 거리 불일치(초점-조절 불일치, VAC)로 두통 유발 | 가변 초점 렌즈(Varifocal Lens) 채택, 12ms 이내의 초저지연 패스스루 유지 및 동공 간 거리(IPD) 자동 모터 보정 |
| **배터리 지속 시간 및 디바이스 중량 한계**<br />고성능 듀얼 칩셋과 다중 센서 가동으로 발열 폭증 및 착용감 저하로 장시간 연속 사용 곤란 | 외장 배터리 팩 분리 설계, 경량 티타늄/마그네슘 하우징 적용 및 엣지 클라우드 오프로딩 렌더링 도입 |

## Ⅵ. 제언

공간 컴퓨팅은 단순한 엔터테인먼트 기기를 넘어 제조, 의료, 건축 등 산업 전반의 '디지털 트윈 기반 엔터프라이즈 워크스페이스'로의 진화 필수.

```text
[소비자 몰입형 미디어] ──> [협업형 가상 오피스] ──> [디지털 트윈 원격 관제 및 텔레오퍼레이션]
       (B2C)                         (B2B)                               (B2B2C 산업 융합)
```

| 진화 단계 | 1세대 공간 컴퓨팅 (XR 기기) | 2세대 공간 컴퓨팅 (지능형 공간 OS) |
|---|---|---|
| **주요 인터랙션** | 전용 핸드헬드 컨트롤러 중심 | 시선, 무자각 손가락 핀치, AI 공간 에이전트 결합 |
| **공간 이해도** | 단순 평면(바닥, 벽) 인식 | 물리 객체의 속성과 3D 볼륨 완전 인식(시맨틱 3D) |
| **에코시스템** | 독립형 VR/AR 앱 스토어 | 공간 멀티태스킹 OS(visionOS, Android XR) 및 WebXR 연계 |
