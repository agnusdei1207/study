## 30초 인출

- 본질: **블록체인 플랫폼 성능·보안은** 분산원장의 합의·실행·저장 구조를 처리 성능과 위협 대응 측면에서 평가·개선하는 활동
- 메커니즘: 요구·위협 정의 → 합의·실행·저장 구조 선택 → 부하·장애·보안 시험 → 운영 감시

<details><summary>핵심 용어</summary>

- **처리량** : 단위 시간에 최종 확정되는 거래의 수
- **최종성** : 거래 결과가 되돌려지지 않는 것으로 취급되는 조건
- **스마트 계약** : 원장 상태를 정해진 규칙에 따라 갱신하는 프로그램

</details>
