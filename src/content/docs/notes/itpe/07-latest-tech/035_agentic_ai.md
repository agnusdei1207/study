## 지식 로드맵 내 현재 위치

지식 위치: 생성형 AI → 목표 지향 실행 → 모델·계획·도구 통합 → **에이전틱 AI**

## 30초 인출

- 본질: **에이전틱 AI(Agentic AI)** 는 목표에 따라 계획을 세우고 도구·시스템과 상호작용해 여러 단계의 작업을 수행하는 AI 시스템
- 메커니즘: 목표 해석 → 행동·도구 실행 → 결과 관측 → 계획 갱신·종료

<details>
<summary>핵심 용어</summary>

- **에이전틱 AI(Agentic AI)** : 목표 지향 계획과 도구·환경 상호작용을 통해 작업을 수행하는 AI 시스템 접근
- **AI 에이전트(AI Agent)** : 관측한 상태를 바탕으로 목표를 위한 행동을 선택하는 시스템
- **ReAct(Reasoning and Acting)** : 추론과 행동을 번갈아 수행하고 관측 결과를 다음 단계에 반영하는 패턴
- **도구 호출(Tool Call)** : 정해진 인터페이스를 통해 외부 검색·API·업무 기능을 실행하도록 요청하는 동작
- **인간 개입(Human-in-the-Loop, HITL)** : 중요한 판단·행동을 사람이 검토·승인하거나 넘겨받는 통제 방식
</details>
