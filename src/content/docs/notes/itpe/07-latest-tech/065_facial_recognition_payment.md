## 연관 키워드

- 안면인식 결제(Facial Recognition Payment), 생체인식(Biometrics), 라이브니스 검출(PAD)
- 1:1 매칭, 1:N 매칭, 폐기 가능한 생체인식(Cancelable Biometrics), FIDO
- 제시 공격(Presentation Attack), 오수락률(FAR), 오거부율(FRR), 폴백(Fallback)
- 이상금융거래 탐지(FDS), 구조광, 비행시간 센서(ToF)

## Ⅰ. 안면인식 결제 서비스의 개요

- 핵심 요약 : 얼굴 특징을 등록 템플릿과 비교해 본인을 확인하고, 그 결과로 결제를 승인하는 카드 없는 생체인식 지급 서비스.
- 개념 : 카메라와 3D 센서로 얼굴 특징을 추출해 사전에 등록된 암호화 템플릿과 비교·검증한 뒤, 결제망과 연동해 승인하는 **안면인식 결제** (Facial Recognition Payment) 서비스.
- 배경 및 필요성 : 생체 정보는 유출되면 재발급할 수 없고 사진이나 딥페이크 같은 위조 공격에 노출되므로, 위조 탐지와 템플릿 보호 기술을 함께 적용해야 함.
- 주요 목적 : 카드나 스마트폰 없이 결제하는 마찰 없는 사용자 경험 제공과 실물 카드의 도난·복제 위험 제거.

## Ⅱ. 안면인식 결제 서비스의 특징 및 장점

- 핵심 요약 : 얼굴이라는 상시 소지 수단과 위조 탐지, 템플릿 보호가 결합되어 편의성과 보안을 함께 확보하는 방식.

1. 무소지 인증 : 카드와 휴대폰 없이 얼굴만으로 본인 확인 → 결제 대기 시간 단축과 분실 위험 감소.
2. 위조 탐지 : 깜빡임, 혈류 변화, 적외선 반사를 함께 분석하는 **라이브니스 검출** (PAD, Presentation Attack Detection) → 사진과 가면 공격을 원천 차단.
3. 템플릿 보호 : 원본 이미지를 저장하지 않고 변환된 특징 벡터만 보관 → 유출 시 변환 키를 바꾸어 재발급 가능.

## Ⅲ. 안면인식 결제 서비스의 구조 (흐름)

- 핵심 요약 : 위조 탐지를 먼저 통과한 얼굴만 특징 추출과 매칭을 거치고, 승인 토큰이 결제사에 전달되는 순차 구조.
- **1:N 매칭** (One-to-Many Matching) : 입력 얼굴 하나를 데이터베이스 내 전체 등록 템플릿과 비교해 신원을 찾는 방식.
- **FIDO** (Fast IDentity Online) : 생체 인증 결과를 서버에 원본으로 보내지 않고 기기 기반 암호 서명으로 대신 전달하는 인증 표준 계열.

```text
[ 결제 처리 흐름 ]

안면 영상 획득 (RGB, 적외선, 3D 센서)
      ↓
위조 공격 탐지 (라이브니스 검출)
      ↓ 통과한 얼굴만 진행
특징 추출과 템플릿 변환
      ↓
생체 인증 엔진 (1:N 매칭)
      ↓ 일치 시
결제 승인 토큰 발급 (FDS 병행 검사)
      ↓
결제 완료와 사용자 알림
```

```text
[ 위조 방어 계층 ]

1계층 : 3D 구조광, ToF 깊이 측정
2계층 : 혈류 변화(rPPG), 적외선 반사 분석
3계층 : 템플릿 변환 저장 (원본 미보관)
```

## Ⅳ. 1:1 매칭과 1:N 매칭의 비교

- 핵심 요약 : 1:1 매칭은 본인 주장과 대조하는 빠른 방식이고, 1:N 매칭은 신원을 찾는 방식이어서 오인식 누적과 중앙 저장소 위험이 커짐.

| 비교 축 | 1:1 매칭 (스마트폰 얼굴 인증) | 1:N 매칭 (매장 결제 단말) |
| --- | --- | --- |
| 입력 데이터 | 얼굴과 본인 주장 식별자 | 얼굴만 입력 |
| 비교 대상 | 특정 사용자의 단일 템플릿 | 등록된 전체 템플릿 |
| 응답 속도 | 매우 빠름 | 후보 탐색만큼 지연 증가 |
| 오인식 위험 | 1회 비교로 고정 | 등록 인원이 늘수록 누적 증가 |
| 데이터 위치 | 사용자 기기 내 격리 저장 | 중앙 서버 저장소 필요 |

- 선택 기준 : 본인 확인이 목적이면 1:1 매칭이 안전하고, 얼굴만으로 결제 주체를 찾아야 하면 1:N 매칭을 쓰되 템플릿 보호와 위조 탐지를 강화해야 함.

## Ⅴ. 안면인식 결제 서비스의 한계와 방안

- 핵심 요약 : 제시 공격, 생체정보의 비가역성, 환경 변화에 따른 거부율을 위조 탐지, 템플릿 보호, 대체 인증으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 제시 공격 (사진, 영상, 가면, 딥페이크) | 2D 기반 인식은 위조물을 실제 얼굴로 오인 | 3D 적외선 구조광과 혈류 분석을 결합한 **PAD** 모듈 탑재, ISO/IEC 30107-3 기준 시험 | 위조 공격 차단율 |
| 생체정보의 비가역성 | 중앙 저장소 유출 시 평생 신원 도용 위험 | 원본 템플릿을 비가역 변환해 저장하는 **폐기 가능한 생체인식** 적용 | 템플릿 재발급 소요 시간 |
| 환경·외형 변화 | 조명, 노화, 표정 변화로 **오거부율** (FRR, False Rejection Rate) 증가 | 적응형 템플릿 갱신, 반복 실패 시 PIN이나 카드로 즉시 전환하는 **폴백** | 오거부율, 결제 대기 시간 |

## Ⅵ. 안면인식 결제 서비스에 대한 기술사적 제언

- 핵심 요약 : 위조 방어, 템플릿 보호, 부정 거래 통제를 세트로 설계해 안면인식 결제를 편의 기능이 아닌 신뢰 가능한 결제 수단으로 정착.

1. 결제사와 가맹점은 위조 탐지 모듈의 시험 기준 충족 여부를 도입 조건으로 두고, 모듈을 주기적으로 재검증하는 절차를 운영하는 것이 바람직하다.
2. 개인정보 처리자는 얼굴 원본을 보관하지 않고 변환 템플릿만 남기며, 수집 목적과 보관 기간을 고지하고 별도 동의를 받는 체계를 갖추어야 한다.
3. 고액 결제나 평소와 다른 거래 패턴은 얼굴 인증 외에 추가 인증을 거치도록 이상금융거래 탐지와 연계하면, 생체 일치만으로 생기는 오남용을 줄일 수 있다.

## Ⅶ. 결론

- 핵심 요약 : 안면인식 결제는 얼굴을 결제 수단으로 전환하는 생체인식 지급 기술로, 편의성과 위조 방어 사이의 균형이 핵심.
- 시사점 : 생체정보는 바꿀 수 없으므로 위조 탐지와 템플릿 보호를 기본값으로 두고 편의성을 확장하는 순서가 지속 가능한 도입 방향이다.
