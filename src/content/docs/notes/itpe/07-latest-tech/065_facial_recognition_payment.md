## Ⅰ. 안면인식 결제 서비스(Facial Recognition Payment)의 개요

- 개념 : 사용자의 **안면 특징 벡터** 를 광학 카메라 및 3D 센서로 추출하여 사전 등록된 **암호화 템플릿** 과 비교·검증한 뒤 금융 결제망과 연동하여 결제를 승인하는 생체인식 기반 지급결제 서비스
- 배경 및 필요성 : 생체 정보는 유출 시 재발급이 불가하고 사진·딥페이크 위조 공격에 취약하므로 다중 스펙트럼 3D 라이브니스(PAD)와 **폐기 가능한 생체인식** (Cancelable Biometrics) 결합 필수
- 핵심 목적 : 카드·스마트폰 소지 불필요에 따른 **무마찰** (Frictionless) 사용자 경험 제공 및 실물 카드 도난·복제 위험 배제

## Ⅱ. 안면인식 결제 서비스(Facial Recognition Payment)의 핵심 아키텍처 및 동작 메커니즘

안면인식 결제 서비스는 안면 영상 획득 및 위조 검출(PAD) → 생체 템플릿 추출 및 **1:N 매칭** → **FIDO 토큰** 기반 결제 승인 요청 → 카드사/은행 결제 완료 및 거래 알림 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 안면인식 결제 서비스 엔드투엔드 처리 및 보안 파이프라인 ]         │
└────────────────────────────────────────────────────────────────────────┘
      │
      ▼
 [ Step 1: 안면 데이터 획득 ] ── RGB + IR(적외선) + 3D ToF 센서 복합 촬영
      │
      ▼
 [ Step 2: 위조 공격 탐지 (PAD) ] ─ ISO/IEC 30107-3 다중 스펙트럼 라이브니스 검증
      │                              (가짜 사진/영상/3D 마스크/딥페이크 즉각 드롭)
      ▼
 [ Step 3: 특징 추출 및 템플릿 암호화 ] ─ 딥러닝 기반 128/512차원 특징 벡터 추출
      │                                   (Cancelable Biometrics 변환 적용)
      ▼
 [ Step 4: 생체 인증 엔진 (1:N 매칭) ] ── 대규모 등록 템플릿 DB 내 유클리디안 거리 비교
      │                                    (낮은 오수락률(FAR) 기준으로 판정)
      ▼
 [ Step 5: FIDO 토큰 발급 및 결제 승인 ] ─ 카드사/PG사로 일회용 가상 결제 토큰 전송
      │                                    (FDS 이상금융거래 탐지 시스템 병행)
      ▼
 [ Step 6: 결제 완료 및 영수증 푸시 ] ── 사용자 스마트폰으로 결제 내역 즉시 통보
```

- 위조 방어 : **라이브니스 검출** (PAD) - 동공 깜빡임, 혈류 미세 변화(rPPG), 적외선 반사율을 복합 분석하여 2D 사진 및 실리콘 마스크 원천 차단
- 3D 공간 센싱 : **구조광** 및 **ToF** (Time-of-Flight) - 수만 개의 적외선 도트 프로젝터로 얼굴 표면의 깊이(Depth) 굴곡을 입체적으로 측정하여 오인식률 극소화
- 비가역 암호화 : **생체 템플릿 토큰화** - 얼굴 원본 이미지를 즉시 파기하고 일방향 해시 함수로 변환된 특징점 벡터만을 하드웨어 보안 모듈(HSM)에 저장

## Ⅲ. 안면인식 결제 서비스(Facial Recognition Payment)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 1:1 매칭 인증 (예: 스마트폰 Face ID) | 1:N 매칭 식별 (예: 매장 키오스크 페이스페이) |
|---|---|---|
| **입력 데이터** | 안면 정보 + 본인 주장 ID (전화번호/QR) | 오직 안면 정보 단독 입력 |
| **비교 대상** | 특정 사용자의 등록된 단일 템플릿 | 데이터베이스 내 수만~수백만 명 전체 템플릿 |
| **인증 지연 시간** | 수십 밀리초(ms) 이내 초고속 완료 | 후보군 탐색으로 수백 ms ~ 수 초 소요 |
| **누적 오인식 위험**| 1회 비교로 오인식 확률이 고정됨 | 템플릿 수 N이 증가할수록 전체 오인식률 누적 증가 |
| **데이터 집중도** | 사용자 로컬 기기 내 격리 저장(Secure Enclave) | 중앙 집중식 서버 템플릿 저장소 필수 |

- 안면인식 결제 서비스는 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 안면인식 결제 서비스(Facial Recognition Payment)의 주요 한계점 및 해결 방안

- 사진·영상·딥페이크 기반 위변조 제시 공격(Presentation Attack) 위협 :
  - 한계점 : 사진, 고화질 태블릿 영상, 정교한 3D 실리콘 가면 및 실시간 딥페이크(Deepfake)를 이용한 제시 공격(Presentation Attack) 위협.
  - 해결 방안 : 3D 적외선 구조광 및 광혈류측정(rPPG) 센서를 결합하고 **ISO/IEC 30107-3** 레벨 2 이상을 획득한 하드웨어 일체형 PAD 모듈 탑재.
- 생체정보의 비가역적 특성으로 인한 영구적 신원 도용 위험 :
  - 한계점 : 패스워드와 달리 생체 정보는 유출 시 평생 변경·재발급이 불가능하여 중앙 DB 해킹 시 치명적인 신분 도용 피해 발생.
  - 해결 방안 : 원본 생체 템플릿을 비가역 함수로 왜곡 저장하여 유출 시 변환 키만 교체하는 폐기 가능한 생체인식 (Cancelable Biometrics) 기술 적용.
- 환경·외형 변화에 따른 오거부율(FRR) 증가 및 결제 대기열 정체 :
  - 한계점 : 조명 변화, 노화, 성형, 표정 변화 등으로 인한 오거부율(FRR) 증가 및 결제 대기열 정체.
  - 해결 방안 : 2D/3D 적응형 템플릿 갱신 파이프라인 수립 및 2회 인증 실패 시 PIN 번호나 카드 태깅으로 즉시 전환되는 **폴백** (Fallback) 보장.

## Ⅴ. 안면인식 결제 서비스(Facial Recognition Payment) 적용 및 발전을 위한 기술사적 제언

- 위조 취약성 중심 엔터프라이즈 고도화 : 스마트폰 사진 제시만으로 뚫림의 한계를 탈피하고, 3D 적외선 및 혈류 분석으로 위조 원천 방어를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 정보 보존 중심 엔터프라이즈 고도화 : 원본 이미지 또는 단순 특징점 저장의 한계를 탈피하고, 일방향 비가역 템플릿으로 유출 시 재발급 가능을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 부정 결제 방지 중심 엔터프라이즈 고도화 : 생체 일치 시 무조건 자동 승인의 한계를 탈피하고, FDS 연계로 평소와 다른 고액 결제 시 2차 인증을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
