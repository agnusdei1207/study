## 30초 인출

- 본질: **안면인식 결제 서비스** 는 사용자의 고유한 얼굴 생체 특징을 3D 센서로 계측하여 사전 등록된 템플릿과 대조 인증하고 결제 토큰과 연계하여 무접촉으로 대금을 결제하는 핀테크 서비스
- 메커니즘: 안면 영상 획득 및 위조 검출(PAD) → 생체 템플릿 추출 및 1:N 매칭 → FIDO 토큰 기반 결제 승인 요청 → 카드사/은행 결제 완료 및 거래 알림
- 통찰: 생체 정보는 유출 시 재발급이 불가하고 사진·딥페이크 위조 공격에 취약하므로 다중 스펙트럼 3D 라이브니스(PAD)와 폐기 가능한 생체인식(Cancelable Biometrics) 결합 필수

<details><summary>핵심 용어</summary>

- **안면인식 결제(Face Pay)** : 실물 카드나 스마트폰 소지 없이 단말기 카메라를 응시하는 것만으로 신원을 확인하고 결제하는 시스템.
- **제시 공격 탐지(PAD)** : 사진, 동영상 화면, 3D 실리콘 마스크 등으로 생체인식 센서를 기만하려는 스푸핑(Spoofing) 시도를 식별·차단하는 기술.
- **ISO/IEC 30107-3** : 생체인식 시스템의 제시 공격 탐지(PAD) 성능 평가 및 시험 기준을 규정한 국제 표준.
- **폐기 가능한 생체인식(Cancelable Biometrics)** : 생체 특징 데이터를 일방향 비가역 변환하여 저장함으로써 유출 시에도 변환 파라미터를 변경해 재발급할 수 있는 암호화 기법.
- **FIDO(Fast Identity Online)** : 공개키 암호화 기반으로 생체 인증 결과만을 서명 검증하여 생체 원문의 서버 전송을 배제하는 글로벌 표준 인증 프로토콜.

</details>

## 2~4교시 25점 답안

## Ⅰ. 안면인식 결제 서비스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **안면인식 결제 서비스** 는 사용자의 안면 특징 벡터를 광학 카메라 및 3D 센서로 추출하여 사전 등록된 암호화 템플릿과 비교·검증한 뒤 금융 결제망과 연동하여 결제를 승인하는 생체인식 기반 지급결제 서비스 |
| 목적 | 카드·스마트폰 소지 불필요에 따른 무마찰(Frictionless) 사용자 경험 제공 및 실물 카드 도난·복제 위험 배제 |

## Ⅱ. 안면인식 결제의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **위조 방어** | 라이브니스 검출 (PAD) | 동공 깜빡임, 혈류 미세 변화(rPPG), 적외선 반사율을 복합 분석하여 2D 사진 및 실리콘 마스크 원천 차단 |
| **3D 공간 센싱** | 구조광 및 ToF(Time-of-Flight) | 수만 개의 적외선 도트 프로젝터로 얼굴 표면의 깊이(Depth) 굴곡을 입체적으로 측정하여 오인식률 극소화 |
| **비가역 암호화** | 생체 템플릿 토큰화 | 얼굴 원본 이미지를 즉시 파기하고 일방향 해시 함수로 변환된 특징점 벡터만을 하드웨어 보안 모듈(HSM)에 저장 |
| **결제 분리** | 인증과 결제의 디커플링 | 안면 일치 여부는 단순 신원 확인 수단으로만 사용하고, 실제 승인은 일회용 결제 토큰(Token) 기반으로 처리 |

## Ⅲ. 안면인식 결제 아키텍처 및 트랜잭션 처리 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 안면인식 결제 서비스 엔드투엔드 처리 및 보안 파이프라인 ]         │
└────────────────────────────────────────────────────────────────────────┘
      │
      ▼
 [ Step 1: 안면 데이터 획득 ] ── RGB + IR(적외선) + 3D ToF 센서 복합 촬영
      │
      ▼
 [ Step 2: 위조 공격 탐지 (PAD) ] ─ ISO/IEC 30107-3 다중 스펙트럼 라이브니스 검증
      │                              (가짜 사진/영상/3D 마스크/딥페이크 즉각 드롭)
      ▼
 [ Step 3: 특징 추출 및 템플릿 암호화 ] ─ 딥러닝 기반 128/512차원 특징 벡터 추출
      │                                   (Cancelable Biometrics 변환 적용)
      ▼
 [ Step 4: 생체 인증 엔진 (1:N 매칭) ] ── 대규모 등록 템플릿 DB 내 유클리디안 거리 비교
      │                                    (False Acceptance Rate < 0.0001% 판정)
      ▼
 [ Step 5: FIDO 토큰 발급 및 결제 승인 ] ─ 카드사/PG사로 일회용 가상 결제 토큰 전송
      │                                    (FDS 이상금융거래 탐지 시스템 병행)
      ▼
 [ Step 6: 결제 완료 및 영수증 푸시 ] ── 사용자 스마트폰으로 결제 내역 즉시 통보
```

| 처리 단계 | 핵심 엔지니어링 기술 | 공학적 신뢰성 기준 |
|---|---|---|
| **영상 수집** | 3D Depth 센서, 적외선 IR 카메라 | 조도 변화 및 안경·마스크 착용 시 강건성 확보 |
| **위조 검증** | ISO/IEC 30107-3 공인 PAD 알고리즘 | APCER(공격 제시 분류 오류율) 1% 미만 달성 |
| **특징 매칭** | ArcFace / CosFace 딥러닝 임베딩 | FAR(오인식률) 0.0001% 이하, FRR(오거부율) 1% 이하 |
| **결제 승인** | FIDO 얼라이언스 표준, EMV Tokenization | 원본 생체 데이터의 금융망 외부 전송 원천 차단 |

## Ⅳ. 1:1 인증과 1:N 식별 비교

| 비교 항목 | 1:1 매칭 인증 (예: 스마트폰 Face ID) | 1:N 매칭 식별 (예: 매장 키오스크 페이스페이) |
|---|---|---|
| **입력 데이터** | 안면 정보 + 본인 주장 ID (전화번호/QR) | 오직 안면 정보 단독 입력 |
| **비교 대상** | 특정 사용자의 등록된 단일 템플릿 | 데이터베이스 내 수만~수백만 명 전체 템플릿 |
| **인증 지연 시간** | 수십 밀리초(ms) 이내 초고속 완료 | 후보군 탐색으로 수백 ms ~ 수 초 소요 |
| **누적 오인식 위험**| 1회 비교로 오인식 확률이 고정됨 | 템플릿 수 N이 증가할수록 전체 오인식률 누적 증가 |
| **데이터 집중도** | 사용자 로컬 기기 내 격리 저장(Secure Enclave) | 중앙 집중식 서버 템플릿 저장소 필수 |
| **프라이버시 위험**| 로컬 완결형으로 상대적 안전 | 중앙 침해 시 대규모 개인정보 유출 위험 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 사진, 고화질 태블릿 영상, 정교한 3D 실리콘 가면 및 실시간 딥페이크(Deepfake)를 이용한 제시 공격(Presentation Attack) 위협 | 3D 적외선 구조광 및 광혈류측정(rPPG) 센서를 결합하고 ISO/IEC 30107-3 레벨 2 이상을 획득한 하드웨어 일체형 PAD 모듈 탑재 |
| 패스워드와 달리 생체 정보는 유출 시 평생 변경·재발급이 불가능하여 중앙 DB 해킹 시 치명적인 신분 도용 피해 발생 | 원본 생체 템플릿을 비가역 함수로 왜곡 저장하여 유출 시 변환 키만 교체하는 폐기 가능한 생체인식(Cancelable Biometrics) 기술 적용 |
| 조명 변화, 노화, 성형, 표정 변화 등으로 인한 오거부율(FRR) 증가 및 결제 대기열 정체 | 2D/3D 적응형 템플릿 갱신 파이프라인 수립 및 2회 인증 실패 시 PIN 번호나 카드 태깅으로 즉시 전환되는 폴백(Fallback) 보장 |

## Ⅵ. 제언

다중 스펙트럼 3D 센서 기반 PAD 검증과 FIDO 비가역 토큰화를 결합하고, FDS(이상거래탐지시스템)를 연동한 3계층 안면인식 결제 보안 거버넌스 구축.

```text
[ 결제 단말기 3D ToF + IR 카메라 ]
              │
              ▼
[ 1계층: 하드웨어 일체형 PAD 엔진 ] ── (생체 신호 판정: 사진/가면/딥페이크 1차 차단)
              │
              ▼
[ 2계층: FIDO 토큰화 인증 서버 ] ───── (Cancelable Biometrics 비가역 매칭)
              │
              ▼ (인증 성공 시 일회용 가상 결제 토큰 생성)
[ 3계층: 금융사 FDS 이상 거래 탐지 ] ── (과거 결제 패턴, 위치 이상치 분석)
              │
              ▼
    [ 안전한 최종 결제 승인 ]
```

| 구분 | 레거시 단순 2D RGB 카메라 결제 | 제언: 3D ToF + FIDO 토큰화 결제 |
|---|---|---|
| **위조 취약성** | 스마트폰 사진 제시만으로 뚫림 | 3D 적외선 및 혈류 분석으로 위조 원천 방어 |
| **정보 보존** | 원본 이미지 또는 단순 특징점 저장 | 일방향 비가역 템플릿으로 유출 시 재발급 가능 |
| **부정 결제 방지** | 생체 일치 시 무조건 자동 승인 | FDS 연계로 평소와 다른 고액 결제 시 2차 인증 |
