## 30초 인출

- **본질:** 안면인식 결제 서비스는 얼굴 비교로 이용자를 확인하고 별도 결제 승인 절차에 연결하는 서비스.
- **메커니즘:** 등록·동의 → 얼굴 제시·위조 탐지 → 템플릿 비교 → 거래 승인·영수증.
- **핵심:** 얼굴 일치와 결제 승인은 다른 판단. 오인식·동의 철회·대체 결제 경로 필요.

<details>
<summary>핵심 용어</summary>

- **안면인식 결제 서비스**: 얼굴 특징 비교를 본인 확인에 이용하고 결제 승인 절차와 연계하는 서비스.
- **생체 템플릿**: 얼굴 영상에서 추출한 비교용 특징 표현.
- **PAD(Presentation Attack Detection)**: 사진·영상 등으로 생체인식 장치를 속이는 제시 공격을 탐지하는 기술.
- **1:1 인증**: 주장한 신원에 연결된 템플릿과 제시한 얼굴을 비교하는 방식.
- **1:N 식별**: 다수의 등록 템플릿에서 제시한 얼굴과 일치할 후보를 찾는 방식.

## 2~4교시 25점 답안

## Ⅰ. 안면인식 결제 서비스의 정의와 목적

| 구분 | 내용 |
|---|---|
| 정의 | **안면인식 결제 서비스**는 얼굴 비교로 이용자를 확인한 뒤 결제 승인 절차에 연결하는 서비스 |
| 목적 | 간편한 본인 확인과 안전한 거래 처리 |

얼굴 일치 판단만으로 거래의 금액·결제수단·승인을 확정하지 않는 분리 필요.

## Ⅱ. 등록과 거래 처리 구조

```text
이용자 등록·동의
    ↓ 생체 템플릿 보호
결제 시 얼굴 제시
    ↓ PAD·템플릿 비교
본인 확인
    ↓ 별도 거래 승인
결제 처리·영수증
```

| 단계 | 확인할 사항 |
|---|---|
| 등록 | 동의 범위·보유기간·대체 수단 |
| 비교 | 품질·위조 탐지·일치 기준 |
| 승인 | 결제수단·금액·거래 의사 |
| 사후 | 영수증·취소·이의제기 |

## Ⅲ. 얼굴 비교 방식과 위험

```text
얼굴 비교
  ├─ 1:1 인증 ─ 제시한 계정의 템플릿 비교
  └─ 1:N 식별 ─ 등록 집합에서 후보 탐색
        ↓
   검색 규모·오인식 기준 검토
```

| 위험 | 대응 |
|---|---|
| 사진·영상 제시 공격 | PAD 시험과 필요 시 추가 확인 |
| 오인식·인식 실패 | 임계값·환경별 성능 시험, 대체 결제 |
| 템플릿 유출 | 최소 수집·접근 제한·보유기간 관리 |
| 얼굴 일치의 과신 | 결제 승인을 별도 단계로 유지 |

ISO/IEC 30107-3은 PAD의 시험·보고를 다루며 결제 서비스 전체의 안전성을 인증하는 규격은 아님.

## Ⅳ. 운영과 이용자 보호

```text
동의·등록
    ↓ 거래 시 비교·승인

    ↓ 취소·환불·이의제기
템플릿 삭제·동의 철회
```

| 운영 항목 | 확인 기준 |

| 선택권 | 대체 인증·결제 가능성 |
| 분쟁 | 비교 결과와 거래 승인 기록 분리 |
| 성능 | 이용 환경별 완료율·오인식·복구 시간 |

## Ⅴ. 한계와 제언

|---|---|
