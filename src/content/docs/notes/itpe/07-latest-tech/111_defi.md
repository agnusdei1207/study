## 30초 인출

- 본질: **DeFi (Decentralized Finance)** 는 은행, 증권사 등 중앙 집중식 금융 중개 기관 없이 퍼블릭 블록체인 상의 스마트 계약(Smart Contract)을 통해 예금, 대출, 환전, 파생상품 등 금융 서비스를 P2P로 자동 실행하는 탈중앙화 금융 생태계
- 메커니즘: 사용자 지갑 서명 → AMM(자동 시장 조성자) 유동성 풀(Liquidity Pool) 상호작용 → 온체인 알고리즘 수식($x \times y = k$) 기반 실시간 자산 교환 및 정산 완결
- 통찰: 스마트 계약 코드 취약점(재진입 공격)과 플래시론(Flash Loan)을 악용한 오라클 시세 조작 위험이 존재하므로 다중 시간가중평균가격(TWAP) 오라클 적용 및 정적 코드 감사 체계 구축 필수

<details><summary>핵심 용어</summary>

- **DeFi (Decentralized Finance)** : 정부나 금융기관의 통제 없이 분산 원장과 스마트 계약 코드로만 운영되는 프로그래머블 금융 프로토콜.
- **AMM (Automated Market Maker)** : 전통적 호가창(Order Book) 없이 유동성 풀에 예치된 토큰 비율의 수학적 함수($x \times y = k$)로 가격을 자동 결정하는 교환 알고리즘.
- **유동성 풀 (Liquidity Pool)** : 유동성 공급자(LP)들이 스마트 계약에 예치한 암호화폐 자산 묶음으로 거래자들의 무중단 스왑을 지원하는 기금.
- **비영구적 손실 (Impermanent Loss)** : 단순 자산 보유 대비 AMM 풀 예치 시 상대적 자산 가격 변동으로 인해 일시적으로 발생하는 기회 손실.
- **플래시론 (Flash Loan)** : 단일 블록 트랜잭션 내에서 대출과 상환이 동시 완결되는 조건으로 담보 없이 막대한 자금을 무담보 차입하는 DeFi 고유 대출 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. DeFi의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **DeFi** 는 중앙 중개자(은행, 중개소)의 개입 없이 퍼블릭 블록체인의 분산 원장과 튜링 완전한 스마트 계약을 기반으로 대출, 결제, 거래, 파생상품을 제공하는 개방형 금융 서비스 체계 |
| 목적 | 금융 중개 수수료 절감, 금융 소외 계층의 무허가성(Permissionless) 접근 보장 및 금융 레고 블록 형태의 결합성(Composability) 실현 |

## Ⅱ. DeFi의 4대 핵심 서비스 유형 및 특징

| 서비스 유형 | 대표 프로토콜 | 핵심 메커니즘 및 기술 특징 |
|---|---|---|
| **탈중앙화 거래소 (DEX)** | Uniswap, Curve | 호가창 대신 유동성 풀 기반 AMM(상수곱 수식)을 통한 실시간 P2P 토큰 스왑 |
| **대출 및 차입 (Lending)** | Aave, Compound | 과담보(Over-collateralization) 기반 암호화폐 예치 대출 및 실시간 이자율 자동 산정 |
| **스테이블코인 (Stablecoin)** | DAI, USDC | 법정화폐 담보, 암호자산 과담보 또는 알고리즘 소각/발행을 통한 1달러 페깅(Pegging) |
| **유동성 스테이킹 (Liquid Staking)** | Lido | PoS 검증을 위해 묶인 지분을 토큰화(stETH)하여 디파이 생태계 내 재투자 유동성 공급 |

## Ⅲ. DeFi 유동성 풀 및 AMM 동작 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             DeFi 상수곱 AMM (Constant Product Market Maker) 구조       │
└────────────────────────────────────────────────────────────────────────┘
 [ 유동성 공급자 (LP) ] ────────── 자산 쌍 1:1 예치 ────────┐
                                                             │
                                                             ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 스마트 계약 유동성 풀 (Liquidity Pool: Token X & Token Y)             │
 │                                                                      │
 │  상수곱 공식: x * y = k (k는 거래 전후 항상 불변)                     │
 │   - x: 풀 내 토큰 X 보유량 / y: 풀 내 토큰 Y 보유량                  │
 │                                                                      │
 │  [ 거래 실행 메커니즘 ]                                              │
 │   트레이더가 Δx 만큼의 토큰 X를 풀에 투입:                            │
 │   (x + Δx) * (y - Δy) = k ──> 교환 수령 토큰: Δy = y - (k / (x + Δx)) │
 └──────────────────────────────┬───────────────────────────────────────┘
                                │
                                ▼
 [ 토큰 스왑 요청 (Swap Order) ] ──> [ 트레이더에게 Δy 지급 및 수수료 적립 ]
```

| 프로세스 단계 | 세부 수행 내용 | 공학적 파라미터 |
|---|---|---|
| **유동성 예치** | 토큰 X와 Y를 현재 시장 가치 1:1 비율로 스마트 계약에 락업 | LP 토큰 발행 |
| **가격 산정** | 오더북 없이 풀 내 잔고 비율($y/x$)에 의해 한계 가격(Marginal Price) 자동 결정 | 슬리피지(Slippage) 관리 |
| **스왑 체결** | 가스비(Gas)와 거래 수수료(0.3%)를 차감하고 즉시 지갑 간 자산 이전 | 트랜잭션 완결성(Finality) |
| **차익 거래(Arbitrage)** | 외부 거래소와 가격 격차 발생 시 차익 거래 봇이 유입되어 가격 균형 회복 | 시장 가격 자동 동기화 |

## Ⅳ. 금융 시스템 패러다임 비교 (전통 금융 vs CeFi vs DeFi)

| 비교 항목 | 전통 금융 (TradFi) | 중앙화 가상자산 금융 (CeFi) | 탈중앙화 금융 (DeFi - 본 토픽) |
|---|---|---|---|
| **중개자** | 상업은행, 증권사, 중앙은행 | 가상자산 거래소 (업비트, 바이낸스) | 무인 스마트 계약 코드 |
| **자산 수탁 (Custody)** | 금융기관 완전 위탁 (수탁) | 거래소 중앙 지갑 위탁 (사설 키 미보유) | 사용자 개인 지갑 자체 보관 (Non-custodial) |
| **신원 확인 (KYC)** | 엄격한 실명 확인 필수 | 거래소 회원가입 KYC 필수 | 불필요 (지갑 주소 기반 무허가성) |
| **거래 투명성** | 폐쇄형 원장 (내부 감사만 가능) | 거래소 내부 오프체인 DB 기록 | 100% 온체인 공개 및 실시간 검증 |
| **시스템 결합성** | 각 금융사 전산망 단절 (API 폐쇄적) | 거래소 간 API 부분 연계 | 오픈소스 스마트 계약 간 자유로운 조립 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 스마트 계약 소스코드의 취약점(재진입성, 정수 오버플로우)을 노린 해킹으로 인한 예치 자산 탈취 위험 | CertiK, OpenZeppelin 등 복수 전문 기관의 공식 코드 오디트(Audit) 의무화 및 형식 검증(Formal Verification) 적용 |
| 단일 탈중앙화 거래소의 스팟 시세를 참조하는 프로토콜을 노린 플래시론 기반 가격 오라클 조작 공격 | 체인링크(Chainlink) 등 탈중앙화 오라클 네트워크(DON)와 시간가중평균가격(TWAP)을 결합하여 순간 가격 왜곡 방어 |
| 대규모 거래 유입 시 발생하는 이더리움 메인넷 가스비 폭증 및 느린 트랜잭션 처리 속도(TPS) 병목 | 옵티미스틱 롤업(Arbitrum, Optimism) 및 영지식 롤업(ZK-Rollup) 등 레이어 2(L2) 스케일링 네트워크로 마이그레이션 |

## Ⅵ. 제언

제도권 금융 수용과 대규모 기관 투자자 유치를 위해 컴플라이언스(DID 기반 영지식 증명 KYC)와 실물자산(RWA)을 결합한 제도권 연계형 하이브리드 DeFi 거버넌스 구축 권고.

```text
[ 기관 및 개인 투자자 ]
           │
           ▼
┌────────────────────────────────────────────────────────┐
│ 영지식 신원 인증 게이트 (ZK-KYC & AML Compliance)     │
│  - 개인정보 노출 없이 규제 적격 투자자 자격만 온체인 증명│
└──────────────────────────┬─────────────────────────────┘
                           │ 인증된 지갑 서명
                           ▼
┌────────────────────────────────────────────────────────┐
│ 기관급 허가형 DeFi 풀 (Permissioned RWA DeFi Core)      │
│  - 실물 채권/부동산 토큰화(RWA) 자산 담보 풀 운영      │
│  - 다중 체인링크 TWAP 오라클 시세 피드 결합            │
│  - 비상시 자금 동결 가능한 다중서명(Multi-Sig) 거버넌스 │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
             [ 안전하고 투명한 온체인 이자 분배 ]
```

| 구분 | 초기 무규제 DeFi (Wild West) | 제언: 제도권 연계형 RWA 하이브리드 DeFi |
|---|---|---|
| **규제 준수** | 익명성으로 자금세탁(AML) 취약 | 영지식 증명(ZK) 기반 글로벌 자금세탁 방지 |
| **담보 자산** | 변동성 극심한 알트코인 담보 | 미국 국채, 상업용 부동산 등 안전 RWA 담보 |
| **오라클 보안** | 단순 AMM 스팟 가격 참조 | 체인링크 분산 오라클 + TWAP 다중 검증 |
| **비상 대응** | 코드 오류 시 복구 불가 | 타임락(Timelock) 및 서킷 브레이커 탑재 |
