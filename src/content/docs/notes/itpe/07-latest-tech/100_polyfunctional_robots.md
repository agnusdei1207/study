## 지식 로드맵 내 현재 위치
IT 인공지능 → 로봇 자동화 → 범용·다중 과업 로봇 → 다기능 로봇

## 30초 인출
- **본질:** 다기능 로봇은 여러 작업을 수행하도록 하드웨어와 제어·지능을 구성한 로봇을 가리킨다.
- **메커니즘:** 센서로 환경을 파악하고, 작업에 맞는 도구·동작을 선택해 제어기로 실행한다.
- **적용:** 작업 전환성뿐 아니라 성공률, 안전, 통합·유지 비용을 전용 설비와 비교한다.

<details><summary>핵심 용어</summary>

- **다기능 로봇(Polyfunctional Robot):** 여러 작업을 수행하도록 로봇 하드웨어와 제어·지능을 구성한 로봇이다.
- **다기능 로봇:** 복수의 작업이나 도구를 수행하도록 설계된 로봇을 설명하는 용어다. 단일 국제 표준 분류로 전제하지 않는다.
- **모바일 매니퓰레이터:** 이동 기반부와 로봇 팔을 결합해 위치 이동과 물체 조작을 수행한다.
- **엔드이펙터:** 로봇 팔 끝에서 파지·가공 등 작업을 수행하는 장치다.
- **작업 일반화:** 학습·설계한 작업 경험을 새로운 조건이나 작업에 적용하는 능력이다.
</details>

## 2~4교시 25점 답안
## Ⅰ. 개념과 적용 배경
| 구분 | 핵심 |
|---|---|
| 정의 | 다기능 로봇은 여러 작업을 수행하도록 로봇 플랫폼과 도구·제어를 구성한 시스템이다 |
| 목적 | 작업 변경 때 설비 재구성을 줄이고 다양한 작업에 대응한다 |

다기능 로봇은 복수의 과업을 수행하거나 도구·동작을 바꿀 수 있도록 구성된 로봇 시스템을 뜻한다. 용어의 범위는 문맥에 따라 달라질 수 있으며 휴머노이드 형상이나 파운데이션 모델 탑재를 필수 조건으로 보지 않는다.

| 유형 | 설계 초점 | 적용상 장점 |
|---|---|---|
| 전용 로봇 | 정해진 반복 과업 | 반복성과 처리량 |
| 재구성 가능한 로봇 | 도구·프로그램 교체 | 제품·작업 변화 대응 |
| 다기능 로봇 시스템 | 여러 과업과 환경 연계 | 작업 범위 확대 가능성 |

## Ⅱ. 인식·계획·실행 구조
```text
[센서 관측]     [작업 지시]
      |               |
      +-------+-------+
              v
        [인식·작업 계획]
              | 도구·동작 선택
              v
    [로봇 팔·엔드이펙터]
              | 동작 실행
              v
         [작업 환경]
              | 결과 관측
              +-----------> [센서 관측]
```

| 구성 | 역할 |
|---|---|
| 센서·인식 | 작업물, 위치, 주변 상태 추정 |
| 계획·제어 | 목표 동작과 실행 경로 결정 |
| 로봇 본체·도구 | 이동·조작 등 물리 작업 수행 |
| 안전 계층 | 제한 영역·속도·정지 조건 감시 |

## Ⅲ. 도입 효과와 적용 과제
| 평가 관점 | 검토 사항 |
|---|---|
| 유연성 | 전환 가능한 실제 작업 수와 재설정 시간 |
| 생산성 | 사이클 시간, 가동률, 예외 발생률 |
| 경제성 | 장비·통합·도구·교육·유지 비용 |
| 안전성 | 사람과의 동선, 위험 평가, 안전 정지 검증 |
| 신뢰성 | 작업별 성공률, 실패 복구와 수동 전환 |

다기능성이 항상 경제성을 높이지는 않는다. 작업마다 처리량이 중요한 고정 공정은 전용 설비가 더 적합할 수 있으며, 새로운 작업은 실제 환경에서 별도 검증해야 한다.

## Ⅳ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 다기능 로봇의 유연성이 실제로 필요한 작업군이 분명하지 않음 | 제품 전환이 잦고 공통 설비를 활용할 수 있는 과업부터 선정해 전용 자동화와 작업 전환 부담을 비교한다. |
