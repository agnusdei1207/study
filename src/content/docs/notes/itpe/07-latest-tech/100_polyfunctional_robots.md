## 답안 골격
```text
[다기능 로봇] ◀━━ 머리: Ⅶ 내 의견 (단일 목적 자동화 설비의 유연성 한계를 파운데이션 모델과 모듈형 하드웨어로 극복하여 다품종 변종 작업에 즉시 적응하는 피지컬 AI 체계)
 ┃
 ┣━ Ⅰ 개요 ───── 단일 작업만 수행하는 전통 전용 로봇(용접/도장)의 라인 전환 비용 폭증 → 파운데이션 모델과 범용 하드웨어 기반 다기능 로봇 태동
 ┣━ Ⅱ 특징 ───── 다중 태스크 일반화(Multi-task) · 범용 신체 폼팩터(휴머노이드/모바일 매니퓰레이터) · 도구 자율 교체 · 환경 적응성
 ┣━ Ⅲ 구조 ───── 범용 기구학적 신체(Body/Actuator) + 멀티모달 센서군(Vision/Tactile/LiDAR) + VLA 인지-계획 두뇌 + 모듈형 엔드이펙터
 ┣━ Ⅳ 흐름 ───── ① 새로운 작업 지시 수신 → ② 작업 환경 3D 매핑 및 사물 식별 → ③ 필요 도구 자율 결합 → ④ VLA 기반 액션 시퀀스 생성 및 조작 → ⑤ 다음 이종 태스크로 즉시 전이
 ┣━ Ⅴ 비교 ───── 산업용 전용 로봇(Single-purpose) vs 협동 로봇(Cobot) vs 다기능 로봇(Polyfunctional) (고정 단일작업 vs 안전 펜스 없는 반복작업 vs 범용 다중작업 자율 수행)
 ┗━ Ⅵ 실무 ───── 배터리 수명 및 연속 가동 시간 제약 / 다중 태스크 전환 시 보정 오차 누적 / 작업자 공존 환경 안전 표준 미비
```

## 한 줄 본질
- 공장에서 나사 하나 조이는 로봇, 박스 옮기는 로봇을 따로 사서 깔면 제품 설계가 바뀔 때마다 수백억 원의 설비를 고철로 버려야 함 → 사람처럼 두 팔과 다리를 갖고 시각-언어-행동 파운데이션 모델을 탑재하여 박스 운반, 부품 조립, 품질 검사를 한 대의 기계가 모두 수행 → 극단적 라인 유연성 확보 / 비싼 도입 비용과 배터리 구동 시간 한계

## 핵심 용어
- 모바일 매니퓰레이터(Mobile Manipulator): 이동 가능한 자율주행 대차(AMR) 위에 다관절 로봇 팔(Manipulator)을 결합하여, 공간 이동과 물체 조작을 동시에 수행하는 다기능 로봇의 대표적 형태
- 퀵 체인저(Automatic Tool Changer): 로봇 팔 끝(엔드이펙터)에 부착된 공구를 작업에 따라 공압 흡착기, 2핑거 집게, 전동 드라이버 등으로 스스로 갈아 끼우는 하드웨어 메커니즘
- Sim-to-Real: 가상 물리 시뮬레이터(Isaac Sim 등)에서 수백만 번의 다중 태스크를 강화학습으로 초고속 훈련시킨 후, 실제 물리 로봇에 가중치를 배포하는 기술

## 핵심 통찰
- "소프트웨어가 하드웨어의 형태를 바꾼다": 과거에는 특정 작업을 가장 빠르게 하기 위해 기계의 형태를 그 작업에 맞췄으나, 이제는 AI 모델이 워낙 범용화되었기 때문에 인간의 도구와 작업 공간에 맞춰 로봇의 신체도 인간형(Humanoid)이나 양팔 로봇으로 수렴함
- 경제적 분기점(Payback Period)의 극적 단축: 단일 목적 로봇은 공장 가동률이 떨어지면 유휴 설비가 되지만, 다기능 로봇은 주간에는 조립을 하고 야간에는 청소와 재고 실사를 수행하여 설비 종합 효율(OEE)을 극대화함
- 안전(Safety)의 패러다임 변화: 쇠창살 펜스 안에 가두고 돌리던 산업 로봇과 달리, 다기능 로봇은 사람과 같은 통로를 지나다니므로 충돌 시 즉각 힘을 빼는 직동형 액추에이터(Quasi-Direct Drive)와 비전 기반 동적 세이프티 존 기술이 핵심

## 이웃 토픽과 구분
- 협동 로봇(Cobot) vs 다기능 로봇: 협동 로봇은 안전 펜스를 없앤 고정식 단일 관절 팔 / 다기능 로봇은 이동성과 양팔, 도구 자율 교체, 파운데이션 모델 두뇌를 결합하여 완전히 다른 작업들을 연속 수행하는 범용 로봇

## 문제·원인·대책
- 적용 상황: 물류 물동량 피크 시 분류 작업과 상하차 작업을 단일 다기능 로봇으로 교대 수행
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 배터리 1회 충전 시 연속 가동 시간이 2시간에 불과하여 작업 공백 발생 | 다관절 고출력 모터 및 고성능 AI 온보드 컴퓨터의 높은 전력 소비 | 자율 도킹 스테이션 기반 초고속 배터리 스와핑(Battery Swap) 메커니즘 적용 | 24시간 무중단 연속 작업 실현 |
| 박스를 집다가 미끄러져 떨어뜨리거나 파손하는 파지 실패 발생 | 물체 표면 마찰력 및 무게 중심에 대한 촉각 피드백 부재 | 그리퍼 손끝 광학 기반 촉각 센서(GelSight) 및 그립력 실시간 제동 제어 도입 | 비정형 물체 파지 성공률 99.2% 달성 |
| 사람과 마주쳤을 때 경로를 비켜주지 못하고 제자리에 멈춰 서서 병목 유발 | 2D 평면 라이다 기반 정적 장애물 회피 알고리즘의 한계 | 3D 비전 기반 인간 의도 예측 모델 및 양보 보행 시뮬레이션 적용 | 작업장 내 통행 정체 80% 해소 |
