## 30초 인출

<details>
<summary>핵심 용어</summary>

- **행동인터넷(Internet of Behavior, IoB)** : 디지털 서비스·기기 자료로 행동 양상을 분석하고 서비스·개입에 반영하는 개념적 접근
- **사물인터넷(Internet of Things, IoT)** : 센서·기기·사물을 네트워크로 연결해 상태·자료를 교환하는 기술 체계
- **디지털 흔적(Digital Trace)** : 서비스·기기 이용 중 생성되는 위치·이용·상호작용 자료
- **행동 분석(Behavior Analytics)** : 관측 자료에서 행동 양상·연관성을 찾는 분석
- **넛지(Nudge)** : 선택을 금지하지 않고 선택 환경을 조정해 특정 행동 가능성을 높이는 개입 방식

### Ⅲ. 시스템 구성

| 단계 | 주요 기능 |
|---|---|
| 자료 발생 | 앱·센서·웨어러블·온라인 서비스의 상호작용 기록 |
| 분석 | 자료 연계·패턴 분석·예측 |
| 적용 | 맞춤 안내·업무 개선·서비스 개입 |
| 평가 | 개입 효과·오류·부작용 확인 |

### Ⅳ. 활용 위험과 통제

| 한계 | 대응 |
|---|---|
| 관측 자료만으로 행동 의도·성향을 확정하기 어려움 | 분석 결과의 불확실성을 표시하고 불이익 결정에 단독 사용 제한 |
| 수집·연계가 확대되어 감시·목적 외 이용으로 이어질 수 있음 | 목적·범위·보유·접근을 한정하고 이용자 선택·삭제 절차 제공 |
| 개입 설계가 이용자 선택을 과도하게 유도할 수 있음 | 선택·거부 경로를 보장하고 개입 효과·부작용 평가 |
| 결합 자료가 민감한 행동을 드러낼 수 있음 | 최소 수집·접근 통제·안전한 저장·전송 적용 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 관측 행동에서 의도·성향을 과도하게 추론하면 서비스 지원이 이용자 평가·불이익으로 변질될 수 있음 | 우선 지원할 행동 과업만 정의하고, 민감도와 결정 영향을 검토해 평가·지원 목적과 제한된 사용 범위를 문서화 |
