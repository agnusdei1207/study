## 30초 인출

- 본질: **전문가 혼합(Mixture of Experts, MoE)** 은 라우터가 입력별 전문가를 선택해 일부 하위망만 계산하는 신경망 구조
- 메커니즘: 토큰 표현 → 라우터 점수·전문가 선택 → 선택 전문가 처리 → 출력 가중 결합
- 통찰: 한계: 일부 전문가에 토큰이 몰리면 병렬 처리와 통신 병목 발생 → 방안: 라우팅 분포·전문가 부하를 측정해 균형 조정

<details>
<summary>핵심 용어</summary>

- **전문가 혼합(Mixture of Experts, MoE)** : 입력에 따라 하위 전문가 일부를 선택적으로 활성화하는 신경망 구조
- **전문가(Expert)** : 입력 일부를 처리하는 학습 가능한 하위 신경망
- **라우터(Router)** : 각 입력을 처리할 전문가를 점수화·할당하는 구성요소
- **희소 활성화(Sparse Activation)** : 전체 전문가 중 일부만 입력별로 계산하는 방식
- **부하 균형(Load Balancing)** : 입력이 일부 전문가에 집중되지 않도록 배분 상태를 조정하는 것
- **All-to-All 통신(All-to-All Communication)** : 분산 장치 사이에 입력 토큰을 전문가 담당 장치로 교환하는 통신 패턴
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **전문가 혼합(Mixture of Experts, MoE)** 은 라우터가 입력별 전문가를 선택해 일부 하위망만 계산하는 신경망 구조 |
| 목적 | 전체 모델 용량과 입력별 활성 계산량을 분리해 조건부 계산 제공 |

### Ⅱ. 토큰 라우팅 구조

```text
토큰 표현
   ↓
라우터 점수 산출
   ↓ 상위 전문가 선택
선택된 전문가 계산
   ↓
출력 결합
```

### Ⅲ. 논리 구성

| 구성 | 기능 |
|---|---|
| 라우터 | 토큰별 전문가 점수 계산·할당 |
| 전문가 묶음 | 할당된 토큰에 대한 하위망 계산 |
| 출력 결합 | 선택된 전문가 결과를 합성해 후속 계층으로 전달 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 일부 전문가에 토큰 집중·드롭 발생 | 전문가별 부하·용량 제한을 측정하고 라우팅 균형 조정 |
| 장치 간 토큰 교환으로 All-to-All 지연 | 목표 장치에서 전문가 배치와 통신량을 함께 최적화 |
| 희소 활성화의 실제 자원 이점 불확실 | 밀집 모델 기준선과 종단 간 지연·메모리·처리량 비교 |

희소 활성화는 매 입력에서 계산하는 전문가 수를 줄일 수 있으나 실제 지연·메모리 이점은 전문가 배치와 통신 구조에 따라 달라짐. 부하 균형 보조 손실 등은 널리 쓰이는 선택 기법이지 모든 MoE의 필수 구성은 아님.

### Ⅴ. 제언

목표 장치·요청량에서 밀집 모델과 종단 간 처리량·지연·메모리를 같은 조건으로 측정해 채택 여부 결정.
