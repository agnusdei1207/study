## 답안 골격
### 1교시 예상문제 (10점)
생성형 AI가 미디어 제작에 활용되는 단계와 C2PA 콘텐츠 출처 정보의 역할을 설명하시오.

### 1교시 10점 답안
- **정의:** 텍스트·영상·음성 생성 모델을 기획, 초안 제작, 편집, 배포에 적용하는 제작 방식.
- **흐름:** 사람의 요구·원본 준비 → 모델 생성·편집 → 저작권·품질·안전 검수 → 배포와 출처 정보 연결.
- **구분:** C2PA는 서명된 출처·편집 이력의 검증 체계이며 워터마크, 진실성 판정, 저작권 허락의 자동 보장은 아님.

### 2~4교시 예상문제 (25점)
AI 미디어 제작 파이프라인의 기술 구조와 딥페이크·권리 위험에 대한 대응책을 설명하시오.

### 2~4교시 25점 답안
1. **구조:** 승인된 입력 자료 → 생성 모델 → 인물·음성·장면 편집 → 사람 검수 → 출처 메타데이터 서명 → 유통 모니터링.
2. **기술:** 텍스트·이미지·오디오·비디오 모델의 각 강점과 일관성 제약, 파일의 출처 표시와 탐지 기술의 상호보완적 활용.
3. **위험:** 학습·생성물의 권리 귀속, 인물 동의, 합성 음성 사칭, 원본 손실·메타데이터 제거 가능성.
4. **통제:** 사용 허락 기록, 고위험 콘텐츠의 인적 승인, 출처 표시의 유지 여부 점검, 신고·정정 절차와 평가 지표 설정.

```text
[AI 미디어·콘텐츠 빅뱅] ◀━━ 머리: Ⅶ 내 의견 (멀티모달 생성형 AI 기반 제작 파이프라인 혁신과 C2PA 표준 기반 출처 인증 생태계 구축)
 ┃
 ┣━ Ⅰ 개요 ───── 텍스트, 이미지, 음성, 비디오를 망라하는 생성형 AI(Generative AI)의 급격한 발전으로 미디어·엔터테인먼트 창작 및 소비 생태계의 패러다임 대전환
 ┣━ Ⅱ 동인 ───── 확산 모델(Diffusion)의 고도화 · 비디오 생성 AI(Sora, Runway) 등장 · 음성 합성(TTS/보이스클로닝) 정밀화 · 텍스트-투-미디어 멀티모달 융합
 ┣━ Ⅲ 변화 ───── 창작 민주화(누구나 크리에이터) + 제작비용/시간의 지수적 절감 + 초개인화 인터랙티브 콘텐츠 + 버추얼 휴먼/가상 스튜디오 확산
 ┣━ Ⅳ 기술 ───── DiT(Diffusion Transformer) · NeRF/3D 가우시안 스플래팅 · 제로샷 음성 복제 · 실시간 렌더링 AI · C2PA 디지털 워터마킹
 ┣━ Ⅴ 비교 ───── 전통적 미디어 제작 vs AI 기반 미디어 제작 (대규모자본·인력/수개월제작/단방향고정 vs 1인프롬프트/수분단위실시간/양방향초개인화)
 ┗━ Ⅵ 실무 ───── 저작권(Copyright) 및 학습 데이터 공정이용 분쟁 / 딥페이크 가짜뉴스 및 사기 / 창작자 일자리 위협 및 윤리적 갈등
```

## 한 줄 본질
- 생성형 AI는 영상·음성·이미지 제작의 일부 단계를 자동화하지만, 기획·권리 확인·품질 검토·배포 책임이 함께 필요함

## 핵심 용어
- DiT(Diffusion Transformer): 확산 모델의 잡음 제거 네트워크에 트랜스포머 구조를 사용하는 모델 계열. 물리 법칙 준수를 자동 보장하지 않음
- 합성 미디어(Synthetic Media): 실제 촬영이나 사람의 육성 없이 인공지능 알고리즘에 의해 전적으로 생성되거나 실시간 변형된 텍스트, 이미지, 비디오, 오디오 콘텐츠
- C2PA(Coalition for Content Provenance and Authenticity): 어도비, 마이크로소프트, 구글 등이 주도하는 오픈 기술 표준으로, 미디어 콘텐츠의 원본 출처, 생성 주체, 편집 이력을 암호학적 서명으로 기록하는 디지털 출처 인증 표준

## 핵심 통찰
- 제작 단계별 비용 변화는 콘텐츠 길이·품질·권리 처리에 따라 달라지므로 실제 제작 공수와 수정 횟수로 평가해야 함
- 미디어의 개인화(Hyper-Personalization): 모두가 똑같은 결말의 영화를 보는 것이 아니라, 시청자의 감정과 반응에 따라 줄거리와 배우의 대사가 실시간으로 바뀌는 인터랙티브 미디어의 탄생
- C2PA 서명은 출처·편집 이력의 무결성을 검증하는 수단이며 콘텐츠의 진실성이나 모든 딥페이크 탐지를 보장하지 않음. 워터마크는 별도 수단

## 이웃 토픽과 구분
