생성형 AI → 미디어 제작 → 출처·권리 검증

## 30초 인출

- 본질: 생성형 AI는 영상·음성·이미지 제작의 일부 단계를 자동화하지만, 기획·권리 확인·품질 검토·배포 책임이 함께 필요함
- 메커니즘: AI 생성·편집 결과를 사람의 권리·품질 검토와 C2PA 출처 검증 절차에 연결
- 통찰: 한계: 출처 서명만으로 콘텐츠의 진실성과 권리 허락이 보장되지 않는다 → 방안: 생성 전 권리를 확인하고 사람 검수·출처 서명·배포 후 이의 처리까지 연결한다.

<details><summary>핵심 용어</summary>

- **C2PA:** 서명된 출처·편집 이력을 표현하고 검증하는 콘텐츠 증명 규격

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 생성형 AI를 미디어 제작·유통 단계에 적용하는 동향 |
| 목적 | 제작 효율과 콘텐츠 출처·권리의 함께 관리 |

## Ⅱ. 생성물의 권리·출처 관리

```text
승인된 입력·권리 확인 → AI 생성·편집
                          ↓ 사람의 품질·안전 검수
                       출처 정보 서명
                          ↓
                    배포·정정 절차
```

- **구조:** 승인된 입력 자료 → 생성 모델 → 인물·음성·장면 편집 → 사람 검수 → 출처 메타데이터 서명 → 유통 모니터링.
- **기술:** 텍스트·이미지·오디오·비디오 모델의 각 강점과 일관성 제약, 파일의 출처 표시와 탐지 기술의 상호보완적 활용.

## Ⅲ. 출처 증명과 콘텐츠 심사의 역할

| 구분 | 확인하는 내용 | 보장하지 않는 내용 |
|---|---|---|
| C2PA 출처 정보 | 서명된 생성·편집 이력 | 사실의 진실성·이용 허락 |
| 사람 검수 | 권리·품질·안전 판단 | 이후 유통 중 메타데이터 보존 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 출처 서명만으로 콘텐츠의 진실성과 권리 허락이 보장되지 않는다 | 생성 전 권리를 확인하고 사람 검수·출처 서명·배포 후 이의 처리까지 연결한다 |

## Ⅴ. 제언

- 배포 전에 권리 허락과 사람 검수를 우선 통과시키고 출처 서명은 유통 이력 확인에 사용한다.
