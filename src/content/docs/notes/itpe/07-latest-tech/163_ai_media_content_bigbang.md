생성형 AI → 미디어 제작 → 출처·권리 검증

## 30초 인출

- **본질:** 생성형 AI는 영상·음성·이미지 제작의 일부 단계를 자동화하지만, 기획·권리 확인·품질 검토·배포 책임이 함께 필요함
- **메커니즘:** AI 생성·편집 결과를 사람의 권리·품질 검토와 C2PA 출처 검증 절차에 연결
- **답안 초점:** 생성형 AI가 미디어 제작에 활용되는 단계와 C2PA 콘텐츠 출처 정보의 역할을 설명하시오.
- **학습 단계:** 관련 핵심 토픽의 활용 사례·동향을 연결하는 응용 주제

- **C2PA:** 서명된 출처·편집 이력을 표현하고 검증하는 콘텐츠 증명 규격

## 1교시 예상문제 (10점)

> 생성형 AI가 미디어 제작에 활용되는 단계와 C2PA 콘텐츠 출처 정보의 역할을 설명하시오. (예상·10점)

---

## 1교시 10점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 생성형 AI를 미디어 제작·유통 단계에 적용하는 동향 |
| 목적 | 제작 효율과 콘텐츠 출처·권리의 함께 관리 |

- **흐름:** 사람의 요구·원본 준비 → 모델 생성·편집 → 저작권·품질·안전 검수 → 배포와 출처 정보 연결.
- **구분:** C2PA는 서명된 출처·편집 이력의 검증 체계이며 워터마크, 진실성 판정, 저작권 허락의 자동 보장은 아님.

## 2~4교시 예상문제 (25점)

> AI 미디어 제작 파이프라인의 기술 구조와 딥페이크·권리 위험에 대한 대응책을 설명하시오. (예상·25점)

---

## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 생성형 AI를 미디어 제작·유통 단계에 적용하는 동향 |
| 목적 | 제작 효율과 콘텐츠 출처·권리의 함께 관리 |

1. **구조:** 승인된 입력 자료 → 생성 모델 → 인물·음성·장면 편집 → 사람 검수 → 출처 메타데이터 서명 → 유통 모니터링.
2. **기술:** 텍스트·이미지·오디오·비디오 모델의 각 강점과 일관성 제약, 파일의 출처 표시와 탐지 기술의 상호보완적 활용.
3. **위험:** 학습·생성물의 권리 귀속, 인물 동의, 합성 음성 사칭, 원본 손실·메타데이터 제거 가능성.
4. **통제:** 사용 허락 기록, 고위험 콘텐츠의 인적 승인, 출처 표시의 유지 여부 점검, 신고·정정 절차와 평가 지표 설정.
