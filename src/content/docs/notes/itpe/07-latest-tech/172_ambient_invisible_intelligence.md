## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 공간에 분산된 센서·연산·서비스가 이용자의 명시적 조작을 줄이며 상황에 맞는 지원을 제공하는 설계 개념. |
| 목적 | 상황에 맞는 공간 기능을 제공하고 명시적 조작 부담을 줄임 |

### Ⅱ. 핵심 구조와 적용

```text
동의·센싱 → 맥락 추정 → 정책·권한 판단 → 제어·되돌리기
```

1. **범위:** 조명·공조 등 저위험 자동화부터 적용하고 안전 영향이 큰 제어는 이용자 확인과 수동 우선권 마련.
2. **처리:** 센서 데이터 최소화 → 맥락 추정과 불확실성 표시 → 명시적 정책 엔진 → 제어·되돌리기·기록.
3. **연동:** Matter·Thread 등은 기기 연동 수단 중 일부이며 분산 합의 프로토콜과 목적이 다름. 제조사·기기별 기능 지원 범위 시험.
4. **통제:** 동의·고지, 현장 처리, 사용 중지 스위치, 오동작·장애 시 안전 상태, 지연·오탐·수동 개입 비율의 평가.

### Ⅲ. 유사 개념과 구분

- 앰비언트 컴퓨팅 vs 앰비언트 인비저블 인텔리전스: 앰비언트 컴퓨팅이 '사물인터넷 기기들의 상호 연결 인프라'에 초점을 맞춘다면 / 인비저블 인텔리전스는 '생성형 온디바이스 AI와 비가시 센싱이 결합된 자율적 판단 지능'에 초점

### Ⅳ. 문제·원인·대책

- 적용 상황: 최고급 프리미엄 무인 호텔 객실에 인비저블 지능형 공간 제어 시스템 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 정지 상태를 수면으로 오판해 조명이 꺼짐 | 단일 센서 신호로 의도 추론 | 복수 신호 확인과 사용자 취소·수동 제어 제공 | 오작동률과 취소 소요 시간 측정 |
| 허브 장애 시 공간 제어 중단 | 중앙 제어 지점 의존 | 핵심 기능의 로컬 수동 제어와 장애 복구 경로 설계 | 네트워크·허브 장애에서 기능 유지 범위 시험 |
| 비접촉 센서의 생활·건강 정보 노출 | 원시 데이터의 과도한 수집·전송 | 최소 수집, 로컬 처리, 접근 권한과 보존 기간 설정 | 원시·파생 데이터의 노출 경로 점검 |

### Ⅴ. 제언

- 응답 지연과 개인정보 요구를 기준으로 로컬 처리 범위를 정하고, 추론 결과가 불확실할 때는 위험한 자동 제어를 보류. 모델 크기·성능·오프라인 동작은 대상 장치에서 측정
