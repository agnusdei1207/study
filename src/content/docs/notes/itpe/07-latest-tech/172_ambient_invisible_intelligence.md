## 30초 인출

- 본질: **앰비언트 인비저블 인텔리전스** (Ambient Invisible Intelligence)는 하드웨어와 UI 화면이 공간 환경 속으로 완전히 은닉되어 사용자가 기기의 존재를 의식하지 못하는 상태에서 맥락(Context)을 자율 감지하고 조율하는 비가시적 공간 지능 기술
- 메커니즘: 비침해 센서(Wi-Fi CSI, mmWave 레이더) 공간 스캔 → 엣지 AI 기반 인간 행동 및 활력 징후 무자각 추론 → 지능형 공간 액추에이터(공조, 조명, 음향) 자율 제어 → 사용자 피드백 무마찰 수렴
- 통찰: 보이지 않는 자동화로 인해 오작동 발생 시 원인을 파악할 수 없는 통제권 상실 불안이 야기되므로 햅틱/음향 기반의 은은한 상태 알림(Calm Feedback)과 물리적 수동 오버라이드(Manual Override) 체계 구축 필요

<details><summary>핵심 용어</summary>

- **인비저블 인텔리전스 (Invisible Intelligence)** : 디스플레이나 물리 버튼 등 가시적 인터페이스가 완전히 배제된 채 배경에서 구동되는 지능.
- **Wi-Fi CSI (Channel State Information)** : 와이파이 전파가 실내 물체나 인체에 반사·굴절되는 물리 신호 왜곡을 분석하여 카메라 없이 호흡, 낙상, 재실을 감지하는 기술.
- **공간 컴퓨팅 (Spatial Computing)** : 컴퓨터의 입출력 경계를 화면에서 물리적 3차원 공간 전체로 확장하는 컴퓨팅 패러다임.
- **수동 오버라이드 (Manual Override)** : 인비저블 AI의 자율 제어를 사용자가 언제든 즉시 중단하고 물리적으로 제어권을 회수할 수 있는 안전장치.
- **맥락 인식 (Context-Awareness)** : 센서 융합을 통해 사용자의 위치, 자세, 활동, 감정, 생체 신호를 종합적으로 판단하는 기능.

</details>

## 2~4교시 예상문제 (25점)

> 인공지능과 사물인터넷(IoT)이 공간 속으로 완전히 융합되는 '앰비언트 인비저블 인텔리전스(Ambient Invisible Intelligence)'의 개념과 4대 핵심 특징을 설명하고, 비침해식 센싱(Wi-Fi CSI, 레이더) 기반 시스템 아키텍처 및 통제권 상실 불안 극복을 위한 HMI 설계 방안을 논하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 앰비언트 인비저블 인텔리전스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 디스플레이, 키보드 등 물리적 인터페이스를 완전히 제거하고, 생활 공간(벽면, 바닥, 천장, 가구) 내에 초소형 센서와 엣지 AI를 내장하여 인간의 개입 없이 최적의 환경을 선제적으로 조성하는 비가시적 지능형 공간 기술 |
| 목적 | 전자기기 조작 스트레스(Technostress)의 제로화, 노약자·환자의 무자각 헬스케어 모니터링 및 에너지 소비 자동 최적화 |

## Ⅱ. 앰비언트 인비저블 인텔리전스의 4대 핵심 속성 및 특징

| 핵심 속성 | 공학적 메커니즘 | 주요 특징 및 효과 |
|---|---|---|
| **비가시성 (Invisibility)** | 센서와 칩의 초소형화 및 벽체·가구 매립 설계 | 기기의 시각적 노출 배제, 일상 공간의 심미성 완전 보존 |
| **비침해성 (Non-intrusiveness)**| 카메라 대신 Wi-Fi CSI 전파 왜곡 및 레이더 센싱 | 프라이버시 침해(나체, 사생활 노출) 없는 24시간 안전 감시 |
| **자율 선제성 (Autonomy)** | 사용자 루틴 학습 및 환경 변화 사전 예측 | 추위를 느끼기 전 외기 온도와 체온을 분석하여 바닥 난방 가동 |
| **상황 순응성 (Adaptability)** | 사용자의 활동 변화(독서, 수면, 대화) 실시간 적응 | 공간 내 조도, 색온도, BGM 볼륨의 무자각 연속적 미세 조율 |

## Ⅲ. 비가시적 지능 공간 엔드투엔드 파이프라인

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 앰비언트 인비저블 인텔리전스 센싱-추론-액추에이션 파이프라인 ]       │
└────────────────────────────────────────────────────────────────────────┘

  [ 물리 생활 공간 (거실, 침실, 차량 실내) ]
                 │
                 ▼ (카메라 없는 비침해 RF/환경 센싱)
  [ 1단계: 비가시적 공간 센싱 매트릭스 (Invisible Sensing) ]
   ├── Wi-Fi CSI 수신: 실내 전파 다중 경로(Multi-path) 왜곡 감지
   ├── 60GHz mmWave 레이더: 흉벽 미세 진동 측정 (비접촉 호흡/심박수)
   └── 환경 센서 어레이: 실내 공기질(TVOC, CO2), 조도, 온습도
                 │
                 ▼
  [ 2단계: 온디바이스 엣지 AI 맥락 추론 (Edge Context Engine) ]
   ├── 1D-CNN + 비전 트랜스포머: 전파 패턴 기반 자세 인식 (앉음/누움/낙상)
   └── 다중 센서 융합: 사용자 맥락 추정 ("수면 진입 상태", 신뢰도 96%)
                 │
                 ▼ (Matter / BACnet 표준 빌딩 자동화 프로토콜)
  [ 3단계: 무자각 공간 액추에이션 (Unobtrusive Actuation) ]
   ┌───────────────────┬───────────────────┬───────────────────┐
   ▼                   ▼                   ▼                   ▼
 [ 서큘레이터 공조 ]   [ 스마트 윈도우 ]   [ 은닉형 간접 조명 ] [ 백색 소음기 ]
 (수면 기류 형성)      (소음 차단 블라인드) (30분에 걸쳐 서서히 소등) (수면 주파수 재생)
                 │                   │                   │                   │
                 └───────────────────┴─────────┬─────────┴───────────────────┘
                                               ▼
  [ 4단계: 캄 피드백 및 수동 오버라이드 (Calm Feedback & Safe Recovery) ]
   - 사용자가 스위치 터치 시 즉각 수동 우선 모드 전환 및 AI 규칙 자동 보정
```

| 파이프라인 단계 | 엔지니어링 처리 내용 | 적용 핵심 기술 |
|---|---|---|
| **비가시 센싱** | 전파 신호의 진폭 감쇄 및 위상 변화(CSI Matrix) 추출 | OFDM 통신 채널 상태 정보 |
| **신호 전처리** | 인체 호흡(0.2~0.5Hz) 및 심박(0.8~2.0Hz) 대역 통과 필터링 | 밴드패스 필터, 주성분 분석(PCA) |
| **맥락 추론** | 실시간 RF 신호 시계열을 심층 학습 모델로 행동 분류 | ResNet-1D, 온디바이스 NPU |
| **공간 조율** | 쾌적 지수(PMV) 방정식에 기반한 공조·조명 다변수 최적 제어 | ASHRAE 표준, 비례적분미분(PID) |
| **피드백 수렴** | 사용자의 거부 반응(불 켜기 등)을 감지하여 트리거 가중치 역환류 | 강화학습 보상 함수 업데이트 |

## Ⅳ. 가시적 AI (Visible AI) vs 앰비언트 인비저블 인텔리전스 비교

| 비교 항목 | 가시적 AI (Visible AI) | 앰비언트 인비저블 인텔리전스 (Invisible AI) |
|---|---|---|
| **물리적 인터페이스**| 스마트폰 화면, AI 스피커, 태블릿 디스플레이 | 완전 은닉형 무(Zero) 인터페이스 |
| **상호작용 방식** | 음성 명령 발화, 화면 터치, 버튼 클릭 | 무자각 재실 감지, 생체 신호 반사, 자세 인지 |
| **동작 트리거** | 사용자의 능동적 명령("헤이 구글, 불 켜줘") | 공간 맥락에 따른 수동적·자율적 선제 트리거 |
| **프라이버시 감정** | 카메라/마이크 노출로 상시 감시 불안 존재 | 카메라 없는 RF 전파 감지로 심리적 안정감 제공 |
| **사용자 주의력** | 화면 주시 및 알림 청취 필요 (주의 분산) | 캄 테크(Calm Tech) 지향, 주의력 소모 제로 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 화면과 음성 안내가 없어 사용자가 시스템의 작동 상태나 제어 의도를 알지 못하는 '블랙박스 통제권 상실 불안' 발생 | 은은한 간접 조명의 색온도 변화나 부드러운 차임벨 등 주의를 빼앗지 않는 캄 피드백(Calm Feedback)을 제공하고 물리 벽면 스위치 터치 시 100% 수동 오버라이드 보장 |
| 거주자가 단순히 침대에 누워 영화를 보는데 수면으로 오판하여 실내 조명을 완전 소등하는 맥락 오인식 위험 | 다중 센서 융합(스마트폰 충전 상태, 동공 깜빡임, RF 호흡수)의 교차 검증 게이트를 구축하고 명령 번복 시 1주일간 해당 시간대 자동화 유예 |
| 댁내 전체에 설치된 초소형 센서들의 유지보수(배터리 교체, 고장 탐지) 난제 | 빛, 실내 전파, 진동 에너지를 자체 수확하는 에너지 하베스팅(Energy Harvesting) 소자 적용 및 메시 네트워크 기반 자가 진단(Heartbeat) 프로토콜 구축 |

## Ⅵ. 제언

인비저블 지능 공간의 신뢰성을 확립하기 위해, AI가 모든 것을 은밀히 통제하지 않고 인간에게 궁극적 주도권을 부여하는 '인간 중심 가변 자율성(Adjustable Autonomy)' 거버넌스 구축 필요.

```text
[ 인비저블 AI 맥락 감지 ]
            │
            ▼
[ 자율성 수준 동적 조정 매트릭스 (Adjustable Autonomy) ]
   ├── 레벨 1 (단순 환경): 조도·온습도 미세 조절 ──> [ 100% 완전 자율 실행 ]
   │
   ├── 레벨 2 (주의 필요): 수면 모드 전환, 외출 공조 ──> [ 캄 피드백 후 지연 실행 ]
   │                                                         (거부 동작 없을 시 1분 후 적용)
   │
   └── 레벨 3 (고위험/안전): 가스 밸브, 도어록, 전력 차단 ──> [ 물리적 확인 필수 ]
            │
            ▼
[ 사용자 불안감 제로화 및 인간-공간 지능의 완벽한 조화 달성 ]
```

| 구분 | 무조건적 완전 자율 자동화 | 제언: 가변 자율성 기반 인비저블 공간 |
|---|---|---|
| **제어 투명성** | 사용자가 모르는 사이에 모든 것이 변경 | 위험도에 따른 차등 사전 예고 메커니즘 |
| **오류 복구** | 오작동 시 모바일 앱을 찾아 설정을 취소 | 벽면 물리 스위치 한 번으로 즉시 수동 복구 |
| **센서 방식** | 사생활 노출 우려의 광학 카메라 | RF 전파 및 비침해 센서 중심 구성 |
| **시스템 신뢰** | 기계에 대한 거부감 및 조작 불안 증대 | 조용히 배려받는 편안한 거주 경험 보장 |
