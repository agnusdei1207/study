## 연관 키워드

- 제조실행시스템(MES), 제조운영관리(MOM), 전사적 자원관리(ERP), 감시 제어 시스템(SCADA), ISA-95
- 생산시점 데이터 관리(POP), 설비종합효율(OEE), 재공품(WIP), 로트 계보 추적(Lot Genealogy)
- 컴포저블 MES(Composable MES), OPC UA, B2MML, 공장 제어망(OT), 정보기술(IT), 데이터 다이오드

## Ⅰ. 제조실행시스템의 개요

- 핵심 요약 : 상위 계획과 하위 설비 제어를 잇고, 현장의 작업·품질·추적을 실시간으로 관리하는 **제조운영관리** (MOM, Manufacturing Operations Management) 시스템.
- 개념 : 전사적 자원관리(ERP, Enterprise Resource Planning)의 생산 계획과 PLC(Programmable Logic Controller), SCADA(Supervisory Control and Data Acquisition)의 설비 제어 사이에서 작업 지시, 자원 관리, 품질 분석, 공정 추적을 수행하는 **제조실행시스템** (MES, Manufacturing Execution System).
- 배경 및 필요성 : 다품종 소량 생산에서 공정이 바뀔 때마다 레거시 구조는 개발과 전환이 지연되어 병목이 된다. 표준 연계 방식인 **OPC UA** (OPC Unified Architecture, 설비와 시스템 간 데이터 교환 표준)와 모듈형 구조로 옮겨야 변경 비용을 낮출 수 있다.
- 주요 목적 : 생산 리드타임 단축, **재공품** (WIP, Work in Progress) 최소화, 불량률 감소, **설비종합효율** (OEE, Overall Equipment Effectiveness) 향상.

## Ⅱ. 제조실행시스템의 특징 및 장점

- 핵심 요약 : 계층 연계, 로트 단위 추적, 현장 즉시 수집이 생산 통제력과 불량 대응 속도 향상으로 이어지는 구조.

1. **계층 연계성** (제조운영 계층으로서 기업 계층과 공장 제어 계층 사이를 잇는 위치) : 수주 계획을 작업 지시로 내리고 설비 실적을 다시 올림 → 계획과 현장 사이의 단절 해소.
2. **로트 계보 추적** (Lot Genealogy, 자재 투입부터 완제품까지 이력을 양방향으로 기록하는 방식) : 로트 단위 이력을 남김 → 불량 발생 시 영향 범위를 즉시 격리.
3. **생산시점 데이터 관리** (POP, Point of Production, 현장에서 발생하는 생산 데이터를 그 시점에 수집하는 방식) : 바코드, RFID, PLC 신호로 작업 시작·완료·비가동 사유를 실시간 수집 → 가동 현황 가시화와 원인 분석 속도 향상.
4. **컴포저블 구조** (Composable Architecture, 기능을 독립 모듈로 나눠 조합하는 구조) : 공정별 모듈 교체와 무중단 배포 가능 → 라인 변경 대응 기간 단축.

## Ⅲ. 제조실행시스템의 구조 (흐름)

- 핵심 요약 : ERP 계획을 MES가 작업 지시로 바꿔 설비 계층에 내리고, 현장 실적을 다시 상위로 환류하는 계층 구조.
- **ISA-95** (International Society of Automation이 제정한 기업-제어 통합 계층 모델) : Level 4 경영, Level 3 제조운영, Level 2 감시 제어, Level 1 직접 구동, Level 0 물리 공정으로 나누는 기준. MES는 기업 계층과 공장 제어 계층 사이의 Level 3에 위치한다.
- 계층 간 인터페이스 : 상위로는 B2MML(Business To Manufacturing Markup Language, 기업 시스템과 제조 시스템 간 데이터 교환용 XML 스키마)로 생산 오더와 마스터 데이터를 주고받고, 하위로는 OPC UA로 작업 지시와 운전 레시피를 내린다.
- 하위 제어 : HMI(Human-Machine Interface)를 갖춘 SCADA가 라인 상태를 가시화하고, DCS(Distributed Control System)와 PLC가 기계를 직접 구동한다.

```text
[ Level 4: 전사 경영 (ERP) ]
          ↓  생산 오더·마스터 데이터
[ Level 3: 제조운영관리 (MES) ]
          ↓  작업 지시·운전 레시피
[ Level 2: 감시 제어 (SCADA/HMI) ]
          ↓
[ Level 1: 직접 구동 (PLC/DCS) ]
          ↓
[ Level 0: 물리 생산 공정 (설비) ]
```

```text
[ ERP 생산 계획 수신 ]
          ↓
[ 작업 오더 발행·자원 배정 ]
          ↓
[ 설비·센서 데이터 수집 (POP) ]
          ↓
[ 재공·로트 추적 ]
          ↓
[ 실적 환류 → 상위 계층 ]
```

## Ⅳ. 제조실행시스템과 ERP·SCADA의 비교

- 핵심 요약 : ERP는 기업 자원을 주기 단위로 계획하고, MES는 공장 안에서 준실시간으로 실행하며, SCADA는 밀리초 단위로 설비를 감시·제어하는 역할 분담.

| 비교 항목 | 전사적 자원관리 (ERP) | 제조실행시스템 (MES) | 감시 제어 시스템 (SCADA) |
| --- | --- | --- | --- |
| ISA-95 계층 | Level 4 (기업 경영) | Level 3 (제조운영) | Level 2 (감시 제어) |
| 시간 관리 주기 | 월·주·일 단위 (비실시간) | 시·분·초 단위 (준실시간) | 밀리초 단위 (실시간 제어) |
| 관리 대상 | 재무, 수주, 구매, 인사 | 작업 오더, 공정, 자원, 재공, 품질 | 설비 신호, 센서 계측값, 경보 |
| 핵심 목적 | 전사 자원 최적화 | 공장 내 생산 실행과 품질 관리 | 공정 안전 감시와 기계 제어 |
| 표준 인터페이스 | B2MML, Web API | OPC UA, MQTT | Modbus, Profibus, EtherCAT |

- 선택 기준 : 계획 단위의 의사결정이 필요하면 ERP, 공장 내 실행과 추적이 필요하면 MES, 설비 직접 제어가 필요하면 SCADA 계층의 기능을 우선 검토한다.

## Ⅴ. 제조실행시스템의 한계와 방안

- 핵심 요약 : 레거시 구조의 변경 지연, 프로토콜 파편화, 보안 경계 취약성을 모듈화, 표준 연계, 경계 방어로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 레거시 모놀리식 구조 | 단일 덩어리 소프트웨어라 라인 변경 때 전체 재배포와 가동 중단 위험 | **컴포저블 MES** (Composable MES, 공정별 독립 모듈을 API로 결합)로 점진 전환 | 라인 변경 리드타임 |
| 이종 PLC 프로토콜 파편화 | 제조사별 독자 프로토콜로 데이터 사일로 형성과 인터페이스 유지보수 비용 증가 | 설비 단에 OPC UA 게이트웨이를 두고 통합 정보 모델 적용 | 연동 설비 비율 |
| IT(Information Technology)·OT(Operational Technology) 연계 보안 | 외부 공격과 랜섬웨어가 상위망을 거쳐 생산 제어망으로 침투 | **ISA/IEC 62443** 기준의 DMZ(비무장 지대) 구축, 산업용 방화벽과 **데이터 다이오드** (단방향으로만 데이터를 보내는 장치) 배치 | 보안 점검 적합률 |

## Ⅵ. 제조실행시스템 적용을 위한 기술사적 제언

- 핵심 요약 : 모듈형 아키텍처, 표준 연계, 보안 경계를 한 묶음으로 설계해 MES를 현장 변화에 견디는 운영 플랫폼으로 내재화할 필요.

1. 공정 단위 점진 전환 : 전체 재구축보다 변경 빈도가 높은 공정부터 모듈로 분리하고, 공정별 리드타임 변화를 확인하며 범위를 넓히는 방식이 현실적이다.
2. 표준 인터페이스 우선 조달 : 신규 설비 도입 조건에 OPC UA 지원을 명시하면 설비별 드라이버를 따로 개발하는 비용을 줄일 수 있다.
3. IT-OT 경계 거버넌스 : 생산 정보 전송에 필요한 경로만 허용하는 경계 정책을 제조 보안 조직과 정보 조직이 공동으로 정하고 주기적으로 점검하는 체계가 필요하다.

## Ⅶ. 결론

- 핵심 요약 : 제조실행시스템은 계획과 현장을 실시간으로 잇는 제조운영관리의 중추.
- 시사점 : 생산 통제력은 표준 연계와 모듈형 구조, 경계 보안이 함께 갖춰질 때 유지되므로, 이 세 요소를 동시에 설계하는 조직이 공장 변화에 빠르게 대응.
