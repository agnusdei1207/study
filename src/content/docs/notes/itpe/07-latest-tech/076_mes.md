## Ⅰ. 제조실행시스템(Manufacturing Execution System, MES)의 개요

- **개념** : 상위 사업 계획(ERP)과 하위 공정 제어(PLC/SCADA)를 유기적으로 연결하여 생산 현장의 작업 지시, 자원 최적화, 품질 분석 및 공정 추적을 실시간으로 수행하는 제조운영관리(MOM) 시스템
- **배경 및 필요성** : 레거시 모놀리식 구조로 인해 다품종 소량 생산 공정 변경 시 병목이 발생하므로 OPC UA 표준 연계와 마이크로서비스 기반 컴포저블(Composable) MES 전환 필수
- **핵심 목적** : 생산 리드타임 단축, 공정 재공품(WIP) 최소화, 불량률 감소 및 현장 가동률 실시간 가시화(POP)를 통한 설비종합효율(OEE) 극대화

## Ⅱ. 제조실행시스템(Manufacturing Execution System, MES)의 핵심 아키텍처 및 동작 메커니즘

제조실행시스템은(는) ERP 생산 계획 수신 → 작업 오더 발행 및 자원 스케줄링 → 설비 PLC/센서 데이터 실시간 수집(POP) → 재공(WIP) 및 랏(Lot) 계보 추적 → 실적 환류 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ ISA-95 표준 5계층 구조 및 MES 엔드투엔드 생산 흐름 ]           │
└────────────────────────────────────────────────────────────────────────┘
 [ Level 4: 전사 경영 관리 (ERP) ] ── (수주, 자재 소요량 계획 MRP, 출하 관리)
         │ (생산 오더 및 자재 마스터 데이터 전송: B2MML 표준 XML/JSON)
         ▼
 [ Level 3: 제조운영관리 (MES / MOM) ] ◄── (공장 운영의 최적화 허브)
   ├── 1. 생산 스케줄링 (Dispatching): 설비별 작업 순서 최적화
   ├── 2. 자원 배분 및 추적: 작업자 배정, 금형/툴링 상태 확인
   ├── 3. 품질 및 공정 관리: 실시간 SPC(통계적 공정 관리), 검사 데이터 집계
   └── 4. 제품 계보(Lot Tracking): 자재 투입-가공-검사 이력 디지털 기록
         │ (작업 지시 및 운전 레시피 하달: OPC UA / 산업용 이더넷)
         ▼
 [ Level 2: 공정 감시 및 제어 (SCADA / HMI) ] ── (라인 상태 가시화 및 알람 제어)
         │
         ▼
 [ Level 1: 센싱 및 직접 구동 (PLC / DCS) ] ──── (래더 로직 기반 기계 직접 제어)
         │
         ▼
 [ Level 0: 물리 생산 공정 (Physical Process) ] ─ (사출기, CNC 머신, 프레스 설비)
```

- **표준 계층성** : ISA-95 Level 3 위상 - 기업 비즈니스 계층(Level 4)과 공장 제어 계층(Level 1~2) 간의 단절을 메우는 브리지 역할 수행
- **전방향 추적성** : 랏 계보 추적 (Lot Genealogy) - 원자재 투입 로트부터 반제품, 완제품 시리얼까지 양방향 추적(Trace & Track)하여 불량 원인 즉각 격리
- **현장 즉시성** : 생산시점 데이터 관리 (POP) - 바코드 스캐너, RFID, PLC 신호를 통해 작업 시작, 완료, 비가동 사유를 초 단위 실시간 수집

## Ⅲ. 제조실행시스템(Manufacturing Execution System, MES)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 전사적 자원관리 (ERP) | 제조실행시스템 (MES) | 감시 제어 시스템 (SCADA) |
|---|---|---|---|
| **ISA-95 계층** | Level 4 (기업 경영 관리) | Level 3 (제조운영관리) | Level 2 (공정 감시 및 제어) |
| **시간 관리 주기** | 월, 주, 일 단위 (비실시간) | 시, 분, 초 단위 (준실시간) | 밀리초(ms) 단위 (하드 리얼타임) |
| **관리 대상** | 재무, 회계, 수주, 구매, 인사 | 작업 오더, 공정, 자원, 재공, 품질 | 설비 가동 신호, 센서 계측값, 경보 |
| **핵심 목적** | 전사 자원 최적화 및 수익 관리 | 공장 내 생산 실행 및 품질 극대화 | 공정 안전 감시 및 기계 직접 제어 |
| **표준 인터페이스**| B2MML, Web API, RESTful | OPC UA, MQTT, 산업용 통신 | Modbus, Profibus, EtherCAT |

- 제조실행시스템은(는) 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 제조실행시스템(Manufacturing Execution System, MES)의 주요 한계점 및 해결 방안

- **레거시 모놀리식 MES의 라인 변경 대응 지연 및 시스템 다운 위험** :
  - **한계점** : 수십 년간 C/C++ 기반 온프레미스 단일 바이너리로 구축된 레거시 모놀리식 MES로 인해 다품종 소량 생산 라인 변경 시 개발 지연 및 전체 시스템 다운 위험.
  - **해결 방안** : 기능을 공정별 독립 컨테이너 모듈로 분할하고 API로 결합하는 클라우드 네이티브 컴포저블 MES(Composable MES) 아키텍처로 점진적 전환.
- **이종 PLC 간 독자 통신 프로토콜 파편화로 인한 데이터 사일로** :
  - **한계점** : 공장 내 이종 PLC(지멘스, 미쓰비시, LS 등) 간 독자 통신 프로토콜 파편화로 인한 데이터 사일로 및 비표준 인터페이스 유지보수 비용 폭증.
  - **해결 방안** : 스마트 팩토리 표준 프로토콜인 OPC UA(IEC 62541) 게이트웨이를 설비 단에 구축하여 통합 정보 모델링(Information Model) 적용.
- **공장 제어망(OT)과 상위 MES(IT) 연계 시 랜섬웨어 침투 보안 위협** :
  - **한계점** : 공장 내부 제어망(OT)과 상위 MES(IT) 연계 시 랜섬웨어 및 외부 사이버 위협이 생산 설비로 침투하는 보안 위협.
  - **해결 방안** : ISA/IEC 62443 표준 기반의 IT-OT 경계망(DMZ) 구축, 산업용 방화벽 및 데이터 다이오드(단방향 보안 게이트웨이) 배치.

## Ⅴ. 제조실행시스템(Manufacturing Execution System, MES) 적용 및 발전을 위한 기술사적 제언

- **라인 변경 대응 중심 엔터프라이즈 고도화** : 소스 코드 전체 재컴파일 및 공장 중단의 한계를 탈피하고, 해당 공정 MSA 모듈만 독립 무중단 배포를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- **설비 연동성 중심 엔터프라이즈 고도화** : 설비마다 개별 드라이버 수기 개발의 한계를 탈피하고, OPC UA 표준 드라이버로 플러그앤플레이를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- **장애 격리성 중심 엔터프라이즈 고도화** : 단일 모듈 버그 시 공장 전체 셧다운의 한계를 탈피하고, 컨테이너 격리로 장애 국소화 및 자동 복구를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
