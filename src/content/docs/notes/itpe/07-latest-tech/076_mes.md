## 30초 인출

- 본질: **제조실행시스템(MES)** 은 기업의 상위 생산 계획(ERP)과 하위 현장 설비 제어(PLC/SCADA) 사이에서 실시간 작업 지시, 공정 진행 추적, 자원 배분, 품질 검사를 통합 관리하는 제조운영관리(MOM) 핵심 시스템
- 메커니즘: ERP 생산 계획 수신 → 작업 오더 발행 및 자원 스케줄링 → 설비 PLC/센서 데이터 실시간 수집(POP) → 재공(WIP) 및 랏(Lot) 계보 추적 → 실적 환류
- 통찰: 레거시 모놀리식 구조로 인해 다품종 소량 생산 공정 변경 시 병목이 발생하므로 OPC UA 표준 연계와 마이크로서비스 기반 컴포저블(Composable) MES 전환 필수

<details><summary>핵심 용어</summary>

- **제조실행시스템(MES)** : 공장 내 생산 활동의 시작부터 완성품 출하까지 전 공정을 실시간 제어·최적화하는 정보시스템.
- **ISA-95** : 기업 경영 계층(ERP, Level 4)과 제조 운영 계층(MES, Level 3) 및 제어 계층(SCADA/PLC, Level 0~2) 간의 통합 표준 아키텍처.
- **MESA-11** : 국제제조실행시스템협회(MESA)에서 정의한 공정 관리, 자원 배분, 문서 관리, 품질 관리 등 11대 핵심 기능군.
- **추적성(Traceability / Genealogy)** : 원자재 입고부터 가공, 조립, 검사까지 제품의 전체 생산 이력과 랏(Lot) 정보를 양방향으로 역추적하는 역량.
- **설비종합효율(OEE)** : 설비의 가동률(Availability), 성능 효율(Performance), 양품률(Quality)을 곱하여 생산 생산성을 정량 평가하는 대표 지표.

</details>

## 2~4교시 예상문제 (25점)

> 스마트 제조 및 인더스트리 4.0 환경에서 공정 최적화의 중추인 제조실행시스템(MES)의 개념과 ISA-95 5계층 아키텍처를 설명하고, MESA-11 핵심 기능 및 레거시 MES의 한계 극복을 위한 차세대 컴포저블(Composable) MES 구축 방안을 논하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 제조실행시스템(MES)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **제조실행시스템(MES)** 은 상위 사업 계획(ERP)과 하위 공정 제어(PLC/SCADA)를 유기적으로 연결하여 생산 현장의 작업 지시, 자원 최적화, 품질 분석 및 공정 추적을 실시간으로 수행하는 제조운영관리(MOM) 시스템 |
| 목적 | 생산 리드타임 단축, 공정 재공품(WIP) 최소화, 불량률 감소 및 현장 가동률 실시간 가시화(POP)를 통한 설비종합효율(OEE) 극대화 |

## Ⅱ. MES의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 엔지니어링 메커니즘 |
|---|---|---|
| **표준 계층성** | ISA-95 Level 3 위상 | 기업 비즈니스 계층(Level 4)과 공장 제어 계층(Level 1~2) 간의 단절을 메우는 브리지 역할 수행 |
| **전방향 추적성**| 랏 계보 추적 (Lot Genealogy) | 원자재 투입 로트부터 반제품, 완제품 시리얼까지 양방향 추적(Trace & Track)하여 불량 원인 즉각 격리 |
| **현장 즉시성** | 생산시점 데이터 관리 (POP) | 바코드 스캐너, RFID, PLC 신호를 통해 작업 시작, 완료, 비가동 사유를 초 단위 실시간 수집 |
| **통합 기능군** | MESA-11 표준 프레임워크 | 작업 스케줄링, 자원 할당, 문서 관리, 작업자 노무 관리, 데이터 수집, 품질 분석 등 11개 기능군 결합 |

## Ⅲ. ISA-95 5계층 아키텍처 및 MES 생산 실행 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ ISA-95 표준 5계층 구조 및 MES 엔드투엔드 생산 흐름 ]           │
└────────────────────────────────────────────────────────────────────────┘
 [ Level 4: 전사 경영 관리 (ERP) ] ── (수주, 자재 소요량 계획 MRP, 출하 관리)
         │ (생산 오더 및 자재 마스터 데이터 전송: B2MML 표준 XML/JSON)
         ▼
 [ Level 3: 제조운영관리 (MES / MOM) ] ◄── (공장 운영의 최적화 허브)
   ├── 1. 생산 스케줄링 (Dispatching): 설비별 작업 순서 최적화
   ├── 2. 자원 배분 및 추적: 작업자 배정, 금형/툴링 상태 확인
   ├── 3. 품질 및 공정 관리: 실시간 SPC(통계적 공정 관리), 검사 데이터 집계
   └── 4. 제품 계보(Lot Tracking): 자재 투입-가공-검사 이력 디지털 기록
         │ (작업 지시 및 운전 레시피 하달: OPC UA / 산업용 이더넷)
         ▼
 [ Level 2: 공정 감시 및 제어 (SCADA / HMI) ] ── (라인 상태 가시화 및 알람 제어)
         │
         ▼
 [ Level 1: 센싱 및 직접 구동 (PLC / DCS) ] ──── (래더 로직 기반 기계 직접 제어)
         │
         ▼
 [ Level 0: 물리 생산 공정 (Physical Process) ] ─ (사출기, CNC 머신, 프레스 설비)
```

| MESA-11 기능 분류 | 핵심 기능 모듈 | 공학적 산출물 및 관리 지표 |
|---|---|---|
| **실행 및 스케줄링** | 자원 할당(Resource), 작업 지시(Dispatching), 상세 일정 | 설비별 간트차트, 작업 지시서 |
| **공정 및 데이터** | 데이터 수집(Collection), 공정 관리(Process), 재공 관리 | 실시간 설비 가동 로그, WIP 현황판 |
| **품질 및 유지보수**| 품질 관리(Quality), 설비 보전(Maintenance) | 관리도(X-bar R), MTBF/MTTR 지표 |
| **성과 및 이력** | 생산 이력 추적(Traceability), 성과 분석(Performance) | Lot 추적 계보도, OEE 대시보드 |

## Ⅳ. ERP, MES, SCADA 비교

| 비교 항목 | 전사적 자원관리 (ERP) | 제조실행시스템 (MES) | 감시 제어 시스템 (SCADA) |
|---|---|---|---|
| **ISA-95 계층** | Level 4 (기업 경영 관리) | Level 3 (제조운영관리) | Level 2 (공정 감시 및 제어) |
| **시간 관리 주기** | 월, 주, 일 단위 (비실시간) | 시, 분, 초 단위 (준실시간) | 밀리초(ms) 단위 (하드 리얼타임) |
| **관리 대상** | 재무, 회계, 수주, 구매, 인사 | 작업 오더, 공정, 자원, 재공, 품질 | 설비 가동 신호, 센서 계측값, 경보 |
| **핵심 목적** | 전사 자원 최적화 및 수익 관리 | 공장 내 생산 실행 및 품질 극대화 | 공정 안전 감시 및 기계 직접 제어 |
| **표준 인터페이스**| B2MML, Web API, RESTful | OPC UA, MQTT, 산업용 통신 | Modbus, Profibus, EtherCAT |
| **사용자** | 경영진, 구매/영업/기획 담당자 | 공장장, 생산 관리자, 품질 엔지니어 | 현장 오퍼레이터, 설비 보전 담당자 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 수십 년간 C/C++ 기반 온프레미스 단일 바이너리로 구축된 레거시 모놀리식 MES로 인해 다품종 소량 생산 라인 변경 시 개발 지연 및 전체 시스템 다운 위험 | 기능을 공정별 독립 컨테이너 모듈로 분할하고 API로 결합하는 클라우드 네이티브 컴포저블 MES(Composable MES) 아키텍처로 점진적 전환 |
| 공장 내 이종 PLC(지멘스, 미쓰비시, LS 등) 간 독자 통신 프로토콜 파편화로 인한 데이터 사일로 및 비표준 인터페이스 유지보수 비용 폭증 | 스마트 팩토리 표준 프로토콜인 OPC UA(IEC 62541) 게이트웨이를 설비 단에 구축하여 통합 정보 모델링(Information Model) 적용 |
| 공장 내부 제어망(OT)과 상위 MES(IT) 연계 시 랜섬웨어 및 외부 사이버 위협이 생산 설비로 침투하는 보안 위협 | ISA/IEC 62443 표준 기반의 IT-OT 경계망(DMZ) 구축, 산업용 방화벽 및 데이터 다이오드(단방향 보안 게이트웨이) 배치 |

## Ⅵ. 제언

표준 OPC UA 통신 미들웨어 기반 위에 공정별 마이크로서비스(MSA)를 결합하여 라인 변경에 유연하게 대응하는 클라우드 네이티브 스마트 MES 아키텍처 구축.

```text
[ 레거시/신규 이종 설비 (PLC / Sensors) ]
                    │
                    ▼
[ 설비 에지 계층: OPC UA 산업용 통합 게이트웨이 ]
   ├── 이종 프로토콜(Modbus, Profinet 등)을 OPC UA 표준 노드로 통합 변환
   └── IEC 62443 기반 IT/OT 완충 DMZ 및 단방향 보안 채널 통과
                    │
                    ▼
[ 컴포저블 스마트 MES 플랫폼 (Kubernetes MSA) ]
   ├── 마이크로서비스 1: 동적 작업 오더 스케줄러 (Line Re-balancing)
   ├── 마이크로서비스 2: 실시간 Lot 계보 추적기 (Graph DB 기반)
   ├── 마이크로서비스 3: AI 기반 이상 품질 탐지기 (SPC 자동화)
   └── 마이크로서비스 4: 실시간 OEE 연산 엔진
                    │
                    ▼
[ ERP 연동 및 공장 전체 통합 관제 대시보드 표출 ]
```

| 구분 | 레거시 모놀리식 온프레미스 MES | 제언: 컴포저블 클라우드 네이티브 MES |
|---|---|---|
| **라인 변경 대응** | 소스 코드 전체 재컴파일 및 공장 중단 | 해당 공정 MSA 모듈만 독립 무중단 배포 |
| **설비 연동성** | 설비마다 개별 드라이버 수기 개발 | OPC UA 표준 드라이버로 플러그앤플레이 |
| **장애 격리성** | 단일 모듈 버그 시 공장 전체 셧다운 | 컨테이너 격리로 장애 국소화 및 자동 복구 |
