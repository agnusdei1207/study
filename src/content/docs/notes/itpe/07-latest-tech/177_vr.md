## 30초 인출

- 본질: 이용자의 자세와 입력에 반응하는 가상 환경을 실시간 제시하는 XR 방식. 동작에 반응하는 가상 환경으로 훈련과 체험 지원.
- 메커니즘: 자세·입력 추적 → 장면 렌더링 → 화면·음향 출력 → 반응.
- 통찰: 한계: 높은 해상도만으로 몰입감과 사용 안전을 보장할 수 없다 → 방안: 추적 오차·화면 지연·프레임률과 이용자 피로를 같은 시나리오에서 측정한다.

- **자세 추적:** 이용자의 위치·방향 변화에 맞춰 장면을 갱신하는 입력 처리

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 이용자의 자세와 입력에 반응하는 가상 환경을 실시간 제시하는 XR 방식. |
| 목적 | 동작에 반응하는 가상 환경으로 훈련과 체험 지원 |

## Ⅱ. 자세 추적과 장면 갱신

```text
머리·손 자세 추적 → 시점 예측
                        ↓
                  양안 장면·음향 렌더링
                        ↓
                   HMD 출력·사용자 반응
                        └→ 다음 자세 추적
```

1. **요구:** 훈련 과제, 필요한 동작 정확도, 공간 범위와 실제 위험 행동의 대체 범위 정의.
2. **구조:** 인사이드 아웃 또는 외부 추적 → 장면 엔진 → 시야·시차에 맞는 렌더링과 오디오 → 컨트롤러/손 동작 피드백.
3. **위험:** 추적 손실·지연·프레임 흔들림·광학 설정과 이동 방식이 멀미와 충돌 위험에 영향. 단일 지연 수치만으로 안전 판정 불가.
4. **평가:** 장치별 프레임·지연 분포, 오류·멀미 설문, 과제 수행·현장 전이 효과와 접근성 측정.

## Ⅲ. VR과 AR의 장면 구성

| 구분 | VR | AR |
|---|---|---|
| 장면 기준 | 가상 환경 중심 | 현실 공간에 가상 정보 정합 |
| 핵심 검증 | 추적·프레임·멀미 | 공간 정합·가림·지연 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 훈련 중 어지러움·불편감 — 지연·프레임 불안정·가상 이동 방식 등 복합 원인 | 렌더링 안정화와 노출 시간·휴식 조건 조정 |
| 조작 감각과 실제 훈련 과제가 다름 — 햅틱·도구 입력의 표현 범위 제한 | 과제에 필요한 피드백을 선택하고 실제 훈련 결과와 비교 |
| 실제 벽·장애물과 충돌 — 가상 환경과 물리 공간 경계 불일치 | 안전 구역 표시와 감독·중단 절차 적용 |

## Ⅴ. 제언

- 3D 가우시안 스플래팅 등 실사 장면 표현은 훈련 목적에 따라 검토하되, 대상 HMD의 프레임·지연·충돌 표현·현장 변경 반영을 시험해 적용 여부 결정
