## 핵심 용어
- E-T-P(Tom Mitchell 정의): 어떤 태스크 $T$에 대해 경험 $E$를 통해 측정한 성능 $P$가 개선될 때 기계학습이라 정의
- 편향-분산 트레이드오프: 단순 모델일수록 편향(오차)이 커지고, 복잡 모델일수록 분산(변동성)이 커지는 상충 관계
- 데이터 누수(Data Leakage): 모델 학습 시점에 사용할 수 없는 미래 정보나 타깃 정보가 입력 특성에 섞여 들어가는 현상

## 핵심 통찰
- 기계학습의 본질은 학습 데이터 암기가 아니라 보지 못한 검증 데이터에 대한 일반화(Generalization) 능력
- 복잡한 최신 딥러닝 알고리즘을 무작정 쓰는 것보다 양질의 데이터와 도메인 특성 공학(Feature Engineering)이 실무 성패를 좌우
- 배포 이후 시간이 흐르면 현실 세계의 데이터 분포가 바뀌는 개념 드리프트(Concept Drift)가 필연적으로 발생하므로 지속적 모니터링 체계 수반

## 이웃 토픽과 구분
- 기계학습 vs 딥러닝: 기계학습은 인간이 특성(Feature)을 직접 추출·선별 / 딥러닝은 심층 인공신경망이 데이터로부터 특성을 계층적으로 자동 표현 학습(Representation Learning)

## 문제·원인·대책
- 적용 상황: 고객 이탈 예측 ML 모델 구축 후 운영 환경에서 적중률 급감
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 학습 시 99% 정확도, 운영 시 60% 급락 | 데이터 전처리 시 테스트셋 정보 유입(Data Leakage) | 교차 검증(K-Fold) 파이프라인 격리 및 엄격한 시계열 분할(Split) | 데이터 누수 방지 및 현실적 일반화 성능 측정 |
| 배포 수개월 후 예측 성능 지속 퇴화 | 고객 소비 패턴 및 거시 경제 환경 변화(Concept Drift) | 일간 예측 성능 모니터링 및 KS-Test 기반 드리프트 감지 시 재학습 | 변화된 패턴에 맞는 모델 신선도 유지 |
| 복잡한 모델로 인한 학습 오버피팅 | 파라미터 과다 및 정규화 부재로 학습 데이터 노이즈까지 암기 | L1/L2 규제(Regularization), 드롭아웃, 특성 수 축소 | 모델 복잡도 억제 및 검증 손실(Validation Loss) 안정화 |
