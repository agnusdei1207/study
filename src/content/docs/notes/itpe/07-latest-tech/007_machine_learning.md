## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 학습 방법 → 데이터에서 규칙 학습 → **기계학습**

## 30초 인출

- 본질: **기계학습(Machine Learning)** 은 경험을 바탕으로 과업 수행 규칙을 학습하는 방법
- 메커니즘: 학습 데이터 → 모델 조정 → 새 데이터 예측 → 평가지표로 성능 확인

<details>
<summary>핵심 용어</summary>

- **기계학습(Machine Learning)** : 경험 데이터에 따라 과업 성능이 개선되도록 예측 규칙을 학습하는 방법
- **일반화(Generalization)** : 학습에 쓰지 않은 데이터에서도 학습한 관계를 적용하는 능력
- **데이터 누수(Data Leakage)** : 예측 시점에 알 수 없는 정보가 학습 자료나 전처리에 섞이는 오류
- **지도학습(Supervised Learning)** : 입력과 정답 쌍으로 예측 관계를 학습하는 유형
- **비지도학습(Unsupervised Learning)** : 정답 레이블 없이 자료의 구조를 찾는 유형
- **강화학습(Reinforcement Learning)** : 환경과의 상호작용에서 얻은 보상으로 행동을 학습하는 유형
- **과적합(Overfitting)** : 학습 자료의 우연한 특성까지 맞춰 새 자료에서 성능이 떨어지는 상태
- **개념 드리프트(Concept Drift)** : 운영 중 입력과 정답의 관계가 변하는 현상
</details>

### Ⅱ. 학습 메커니즘

```text
과업·평가지표
       ↓
경험 데이터로 모델 학습
       ↓
새 입력의 결과 예측
       ↓
평가지표로 성능 확인
```

| 학습 유형 | 학습 신호 | 대표 과업 |
|---|---|---|

### Ⅲ. 개발·운영 절차

```text
과업·평가 기준 설정
        ↓
자료 수집·분할·전처리
        ↓
모델 학습·검증
        ↓
최종 시험 자료 평가
        ↓
배포 후 성능 관찰
```

### Ⅳ. 일반화 저해 요인과 대응

| 한계 | 발생 원인 | 대응 |
|---|---|---|
| **데이터 누수(Data Leakage)** | 예측 시점에 없는 정보가 학습 자료에 포함 | 시점 기준 분할과 학습 자료 안에서의 전처리 |
| **과적합(Overfitting)** | 모델이 학습 자료의 우연한 잡음까지 학습 | 검증 성능에 따른 복잡도·규제·종료 시점 조정 |
| **개념 드리프트(Concept Drift)** | 운영 중 입력과 정답의 관계 변화 | 운영 자료·정답 성능 관찰과 재학습 검토 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 실험마다 데이터·전처리·평가 조건이 다르면 모델 간 결과 비교가 어려움 | 분할·전처리·평가지표를 기록하고 같은 조건으로 실험을 비교하는 절차 마련 |
