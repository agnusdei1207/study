## 답안 골격
```text
[CNN] ◀━━ 머리: Ⅶ 내 의견 (가중치 공유와 국소 수용영역 기반의 격자 공간 불변성 추출 신경망)
 ┃
 ┣━ Ⅰ 개요 ───── 완전연결계층(FC)의 2차원 공간 기하학 정보 파괴 및 파라미터 폭증 → 합성곱 필터로 공간적 특징 불변성 유지
 ┣━ Ⅱ 특징 ───── 국소 수용영역(Local Receptive Field) · 가중치 공유(Weight Sharing) · 이동 불변성(Translation Invariance) · 차원 축소
 ┣━ Ⅲ 구조 ───── 입력 계층 + 합성곱 계층(Conv, 필터/스트라이드/패딩) + 활성화(ReLU) + 풀링 계층(Pooling) + 완전연결 계층(FC)
 ┣━ Ⅳ 흐름 ───── ① 원시 이미지 입력 → ② 2D 커널 합성곱 연산(특징 맵 생성) → ③ 비선형 활성화(ReLU) → ④ 서브샘플링(Max Pooling) → ⑤ 분류(Softmax)
 ┣━ Ⅴ 비교 ───── 완전연결신경망(FCN) vs 합성곱신경망(CNN) vs 비전 트랜스포머(ViT) (공간 파괴/파라미터 폭증 vs 국소 특징/가중치 공유 vs 전역 어텐션)
 ┗━ Ⅵ 실무 ───── 망이 깊어질 때의 기울기 소실(Vanishing Gradient) / 커널 크기·스트라이드 설정 난점 / 적대적 공격(Adversarial Attack) 취약
```

- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 계층별(Conv-ReLU-Pool-FC) 파이프라인 구조도 → Ⅴ FCN vs CNN vs ViT 비교표 / 25점 = Ⅰ~Ⅶ 전개, 합성곱 연산 출력 크기 수식 계산과 ResNet 숏컷(Skip Connection) 원리 집중

## 한 줄 본질
- 2차원 이미지를 1차원 벡터로 평탄화할 때 발생하는 인접 픽셀 간 공간 상관관계 파괴와 파라미터 폭증 문제 → 작은 커널(필터)을 슬라이딩하며 가중치를 공유(Weight Sharing)하는 합성곱 연산과 풀링을 통해 위치가 바뀌어도 동일한 특징을 감지하는 공간 불변성 확보 / 전역적 맥락 파악 능력은 트랜스포머 대비 열세

## 핵심 용어
- 가중치 공유(Weight Sharing): 동일한 커널(필터) 파라미터를 이미지 전체 영역에 슬라이딩하며 반복 적용함으로써, 학습해야 할 파라미터 수를 획기적으로 줄이고 위치 이동에 무관한 특징을 검출하는 메커니즘
- 스트라이드(Stride) 및 패딩(Padding): 스트라이드는 필터가 이동하는 보폭(픽셀 수)이며, 패딩은 외곽에 0을 덧대어 합성곱 연산 후에도 입력과 동일한 공간 해상도를 유지하도록 경계를 보존하는 기법
- 맥스 풀링(Max Pooling): 특정 윈도우 내에서 가장 큰 값만을 추출하여 특징 맵의 해상도를 절반으로 줄임으로써, 사소한 픽셀 이동에 영향을 받지 않는 위치 불변성을 확보하고 연산량을 감축하는 기법

## 핵심 통찰
- CNN의 본질적인 귀납적 편향(Inductive Bias)은 "국소성(Locality)"과 "이동 불변성(Translation Invariance)": 인간의 시각 피질처럼 가까운 픽셀끼리 의미가 있고, 고양이가 좌측 상단에 있든 우측 하단에 있든 고양이임을 알아채는 구조적 장점
- 출력 크기 계산 공식은 시험 및 설계의 절대 공식: $O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1$ (W: 입력 크기, K: 커널 크기, P: 패딩, S: 스트라이드)
- 신경망이 깊어질수록 특징 맵이 소멸하는 한계는 ResNet의 $H(x) = F(x) + x$ 잔차 연결(Residual Shortcut)이 등장하며 극복되었고, 이는 현대 딥러닝 전반의 기초 인프라로 정착

## 이웃 토픽과 구분
- CNN vs Vision Transformer(ViT): CNN은 강한 국소적 귀납 편향으로 적은 데이터에서도 잘 학습 / ViT는 귀납 편향 없이 전역 어텐션만으로 학습하여 대규모 데이터셋(JFT-300M 등)에서 CNN의 한계를 돌파

## 문제·원인·대책
- 적용 상황: 반도체 웨이퍼 결함 탐지 비전 모델에서 미세 크랙 탐지 실패
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미세 크랙의 얇은 선형 특징이 풀링 계층을 거치며 소멸 | Max Pooling의 과도한 다운샘플링으로 인한 공간 고해상도 정보 유실 | Dilated(Atrous) Convolution 도입으로 해상도 축소 없이 수용영역(Receptive Field) 확장 | 1픽셀 단위의 미세 균열 검출 정밀도 99.2% 달성 |
| 모델이 깊어짐에 따라 역전파 기울기가 사라져 학습 정체(Vanishing Gradient) | 연속된 계층 곱셈으로 인한 기울기 감쇠 | ResNet 스타일 Skip Connection(잔차 연결) 및 배치 정규화(BatchNorm) 적용 | 100층 이상의 초심층 네트워크에서도 안정적 수렴 |
| 실시간 임베디드 카메라에서 CNN 추론 지연시간 500ms 초과 | 2D 표준 합성곱의 막대한 채널 간 연산량($K \times K \times C_{in} \times C_{out}$) | 깊이별 분리 합성곱(Depthwise Separable Conv, MobileNet 구조) 도입 | 모델 파라미터 및 연산량 85% 감축, 30fps 실시간 처리 |
