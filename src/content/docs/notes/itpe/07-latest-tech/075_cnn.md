## 연관 키워드

- 합성곱 신경망(CNN), 합성곱 연산(Convolution), 커널(Kernel), 수용 영역(Receptive Field), 가중치 공유, 풀링(Pooling)
- 이동 등변성, 특징 맵, 완전연결 계층(FC), 특징 피라미드 네트워크(FPN), 확장 합성곱(Dilated Convolution), 스킵 연결
- 공간 변환 네트워크(STN), 비전 트랜스포머(ViT), 귀납적 편향

## Ⅰ. 합성곱 신경망의 개요

- 핵심 요약 : 격자형 데이터의 국소 특징을 공유 가중치 필터로 추출하는 딥러닝 구조.
- 개념 : 입력의 공간 격자 구조를 유지한 채 **커널** (Kernel, 학습되는 가중치 필터)을 이동시키며 합성곱 연산으로 국소 특징을 계층적으로 추출하는 **합성곱 신경망** (CNN, Convolutional Neural Network).
- 배경 및 필요성 : **완전연결 계층** (FC, Fully Connected Layer)은 이미지를 1차원으로 펼치며 공간 위치 정보를 버리고, 입력 크기에 비례해 파라미터가 불어난다. 이 학습 비용과 과적합 부담을 줄이려면 국소 연결과 가중치 공유를 갖춘 합성곱 구조가 필요하다.
- 주요 목적 : 공간 위상을 보존하면서 적은 파라미터로 이동에 강한 이미지 특징 표현을 얻는 것.

## Ⅱ. 합성곱 신경망의 특징 및 장점

- 핵심 요약 : 가중치 공유와 국소 수용 영역이 파라미터 절감과 공간 특징 보존으로 이어지는 구조.

1. **가중치 공유** (Weight Sharing, 같은 필터를 입력 전 영역에 재사용하는 방식) : 위치마다 가중치를 따로 두지 않고 하나의 필터를 슬라이딩 → 파라미터 수와 과적합 위험 감소.
2. **수용 영역** (Receptive Field, 한 출력 값이 참조하는 입력의 범위) : 인접 픽셀의 상관관계를 먼저 학습 → 선, 모서리, 질감 같은 저수준 특징에서 고수준 특징으로 계층 확장.
3. **이동 등변성** (Translation Equivariance, 입력이 이동하면 특징 맵도 같은 방향으로 이동) : 객체 위치가 바뀌어도 같은 필터가 반응 → 위치와 무관하게 같은 패턴을 인식.
4. **풀링** (Pooling, 영역 안의 대표값만 남겨 해상도를 줄이는 연산) : 작은 위치 변화에 둔감한 불변성 확보 → 연산량과 메모리 사용 감소.

## Ⅲ. 합성곱 신경망의 구조 (흐름)

- 핵심 요약 : 합성곱, 활성화, 풀링을 블록 단위로 반복해 특징 맵을 쌓고, 마지막 분류 헤드에서 판정하는 계층 구조.
- 합성곱 계층 : K×K 커널을 스트라이드 S, 패딩 P로 이동시키며 내적을 취하는 단계. 출력 크기는 O = floor((W - K + 2P) / S) + 1로 정해진다.
- 활성화 계층 : **활성화 함수** (Activation Function)인 ReLU(Rectified Linear Unit)로 음수 응답을 0으로 잘라 비선형성을 부여한다.
- 풀링 계층 : 2×2 영역의 최댓값을 취하는 최대 풀링으로 해상도를 절반으로 줄인다.
- 분류 헤드 : **전역 평균 풀링** (GAP, Global Average Pooling) 또는 완전연결 계층 뒤에 Softmax를 두어 클래스 확률을 낸다.

```text
[ 입력 이미지 (C × H × W) ]
          ↓
[ 1. 합성곱 계층 (K×K 커널) ]
          ↓
[ 2. 활성화 계층 (ReLU) ]
          ↓
[ 3. 풀링 계층 (Max Pooling) ]
          ↓   (블록을 N회 반복)
[ 4. 심층 특징 맵 ]
          ↓
[ 5. 분류 헤드 (GAP → FC → Softmax) ]
```

```text
입력 3×3 영역 × 커널 3×3
          ↓  원소별 곱의 합 + 편향
특징 맵의 한 칸 값
          ↓  커널을 스트라이드만큼 이동 반복
완성된 특징 맵 (선·질감 응답 지도)
```

## Ⅳ. 합성곱 신경망과 대안 구조의 비교

- 핵심 요약 : 지역성과 격자 구조가 강한 데이터에서는 합성곱 구조가 데이터 효율과 연산 효율에서 유리하고, 전역 문맥이 중요하면 **비전 트랜스포머** (ViT, Vision Transformer)가 대안이 됨.

| 비교 항목 | 완전연결 신경망 (MLP) | 합성곱 신경망 (CNN) | 비전 트랜스포머 (ViT) |
| --- | --- | --- | --- |
| 입력 처리 | 1차원 벡터로 평탄화 | 2D·3D 격자 구조 유지 | 이미지를 패치 토큰으로 분할 |
| **귀납적 편향** (Inductive Bias, 모델이 미리 가정하는 구조적 성질) | 거의 없음 | 강함 (국소성, 이동 등변성) | 약함 (전역 어텐션 학습) |
| 데이터 요구량 | 적으면 과적합 | 비교적 적은 데이터로 일반화 | 대규모 데이터 사전학습 필요 |
| 장거리 의존성 | 파라미터 증가로 모델링 난항 | 층을 깊게 쌓아 수용 영역 확장 | 한 층에서 전역 참조 가능 |
| 연산 특성 | 입력·출력 곱에 비례하는 파라미터 | 커널 공유로 경량 | 패치 수의 제곱에 비례하는 어텐션 비용 |

- 선택 기준 : 데이터가 제한적이고 국소 패턴이 핵심이면 합성곱 구조를, 대규모 사전학습 자원이 있고 전역 문맥이 중요하면 비전 트랜스포머를 검토한다.

## Ⅴ. 합성곱 신경망의 한계와 방안

- 핵심 요약 : 풀링에 따른 정보 손실, 고정 수용 영역, 기하 변형 취약성을 다중 해상도 융합, 확장 연산, 변환 모듈로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 픽셀 단위 정밀 좌표 손실 | 반복 풀링과 스트라이드로 미세 결함의 위치 정보 소실 | **특징 피라미드 네트워크** (FPN, Feature Pyramid Network)의 스킵 연결로 고해상도 특징 융합 | 픽셀 단위 검출 정확도 |
| 고정 수용 영역 | 전역 문맥과 장거리 상관관계 포착 불가 | **확장 합성곱** (Dilated Convolution, 필터 사이 간격으로 수용 영역 확장) 또는 어텐션 결합 | 분할 경계 정확도 |
| 스케일·회전 변형 | 기하 변형 시 이동 등변성만으로는 인식 성능 급락 | **공간 변환 네트워크** (STN, Spatial Transformer Network)로 입력을 학습된 변환으로 정렬 | 변형 데이터셋 정확도 |

## Ⅵ. 합성곱 신경망 적용을 위한 기술사적 제언

- 핵심 요약 : 과제의 공간 특성에 맞춰 구조를 고르고, 정확도와 운영 비용을 함께 보는 도입 체계 확립 필요.

1. 과제 특성 기준의 구조 선택 : 현장 검사처럼 데이터가 제한적이고 국소 결함이 중요한 영역은 합성곱 구조를 기본으로 두고, 전역 문맥이 핵심인 과제에서만 대안 구조를 검토하는 기준을 마련한다.
2. 장애 대비 성능 검증 : 해상도 손실과 변형 취약성이 실제 불량 검출에 미치는 영향을 과제별 시험 데이터로 먼저 측정한 뒤 보완 모듈 도입 여부를 정하는 절차가 필요하다.
3. 엣지 배포 고려 설계 : 설비 단말에 올리는 경우 확장 합성곱과 깊이별 분리 합성곱 같은 연산 절감 기법을 설계 단계부터 반영하는 것이 효율적이다.

## Ⅶ. 결론

- 핵심 요약 : 합성곱 신경망은 공간 격자 구조를 활용해 적은 파라미터로 이미지 특징을 추출하는 기본 아키텍처.
- 시사점 : 국소 패턴이 중요한 과제에서 여전히 효율적인 기반이며, 전역 문맥과 기하 변형을 다루는 보완 구조와 결합해 쓰는 방향으로 발전.
