## Ⅰ. 합성곱 신경망(Convolutional Neural Network, CNN)의 개요

- **개념** : 입력 데이터의 공간적 격자 구조(Grid Topology)를 보존하면서, 공유 가중치를 갖는 커널 필터를 적용하여 국소적 공간 특징을 계층적으로 추출하는 딥러닝 아키텍처
- **배경 및 필요성** : 연속된 풀링으로 인한 세부 공간 좌표 손실과 국소 수용 영역 한계가 존재하므로 스킵 연결 기반 피라미드 구조(FPN) 및 확장 합성곱(Dilated Conv) 결합 필수
- **핵심 목적** : 완전연결 계층(FC)의 1차원 플래튼(Flatten)으로 인한 2D 공간 위상 정보 파괴 및 파라미터 폭증 문제를 해결하고, 이동 등변성을 보장하는 고효율 이미지 특징 표현 획득

## Ⅱ. 합성곱 신경망(Convolutional Neural Network, CNN)의 핵심 아키텍처 및 동작 메커니즘

합성곱 신경망은(는) 입력 이미지에 학습 가능한 2D/3D 커널 합성곱 적용 → 활성화 함수(ReLU) 비선형 변환 → 서브샘플링(Pooling)을 통한 특징 압축 → 완전연결 계층(FC) 또는 GAP를 통한 최종 분류·분할 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 합성곱 신경망(CNN) 기본 레이어 파이프라인 및 연산 흐름 ]          │
└────────────────────────────────────────────────────────────────────────┘
 [ 입력 이미지 X: (C × H × W) ] (예: RGB 3채널 224×224 이미지)
                │
                ▼
 [ 1. 합성곱 계층 (Conv Layer) ] ── (K×K 커널, Stride S, Padding P)
   ├── 국소 픽셀 내적: Feature(i, j) = Σ Σ X(i+m, j+n) * W(m, n) + b
   └── 출력 크기: O = floor((W - K + 2P) / S) + 1
                │
                ▼
 [ 2. 활성화 계층 (ReLU / GELU) ] ─ 비선형 활성화 함수 적용 (음수 0 클리핑)
                │
                ▼
 [ 3. 풀링 계층 (Max Pooling) ] ─── 2×2 영역 최대값 추출 (해상도 1/2 다운샘플링)
                │
                ▼ (Conv + ReLU + Pooling 블록 N회 반복 누적)
 [ 4. 심층 추상화 특징 맵 ] ────── (고차원 시맨틱 특징 맵 획득)
                │
                ▼
 [ 5. 분류/회귀 헤드 계층 ] ────── Global Average Pooling(GAP) 또는 FC Layer
                │
                ▼
 [ 최종 분류 확률 출력 (Softmax) ] ──> [ 정상품 vs 불량품 판정 ]
```

- **파라미터 절감** : 가중치 공유 (Weight Sharing) - 위치마다 독립적인 가중치를 두지 않고 단일 필터를 전 영역에 슬라이딩하여 파라미터 수 및 과적합 대폭 감축
- **위상 보존** : 국소 수용 영역 (Local Receptive Field) - 인접한 픽셀 간의 국소적 상관관계(Local Connectivity)를 집중 학습하여 선, 면, 질감 등 공간적 맥락 추출
- **공간 변환성** : 이동 등변성 및 불변성 - 객체가 영상의 어느 위치로 이동해도 동일한 특징 맵이 반응(등변성)하며, 풀링을 통해 미세한 회전·위치 변화에 둔감(불변성)

## Ⅲ. 합성곱 신경망(Convolutional Neural Network, CNN)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 완전연결 신경망 (ANN / MLP) | 합성곱 신경망 (CNN) | 비전 트랜스포머 (ViT) |
|---|---|---|---|
| **입력 데이터 처리** | 1차원 평탄화 벡터로 직렬화 | 2D/3D 이미지 텐서 격자 구조 유지 | 이미지를 16×16 패치 토큰으로 분할 |
| **귀납적 편향 (Bias)** | 거의 없음 (모든 연결 학습 필요) | 매우 강함 (국소성, 이동 등변성) | 거의 없음 (전역 어텐션 학습) |
| **데이터 요구량** | 데이터 적을 시 과적합 발생 | 적은 데이터로도 우수한 일반화 | 초대규모 데이터셋(JFT-300M) 필수 |
| **장거리 의존성** | 파라미터 폭증으로 장거리 모델링 난항 | 레이어를 깊게 쌓아야 수용 영역 확장 | 단일 레이어에서 이미지 전체 전역 참조 |
| **연산 복잡도** | O(In × Out) 파라미터 폭증 | 커널 공유로 O(H × W × K^2) 경량 | 패치 수에 비례한 O(N^2) 어텐션 복잡도 |

- 합성곱 신경망은(는) 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 합성곱 신경망(Convolutional Neural Network, CNN)의 주요 한계점 및 해결 방안

- **반복적 다운샘플링으로 인한 픽셀 단위 정밀 좌표 정보 손실** :
  - **한계점** : 반복적인 풀링 및 스트라이드 다운샘플링으로 인해 미세 결함 검출에 필수적인 픽셀 단위 정밀 좌표 정보가 손실되는 해상도 저하.
  - **해결 방안** : 하위 계층의 고해상도 특징 맵과 상위 계층의 풍부한 시맨틱 특징 맵을 스킵 연결로 융합하는 U-Net 및 특징 피라미드 네트워크(FPN) 도입.
- **고정된 수용 영역(Receptive Field)으로 인한 전역적 문맥 포착 한계** :
  - **한계점** : 고정된 크기의 수용 영역(Receptive Field)으로 인해 이미지 전체의 전역적 문맥(Global Context)이나 장거리 픽셀 간 상관관계 포착 불가.
  - **해결 방안** : 필터 내부에 빈 공간을 두어 파라미터 증가 없이 수용 영역을 수배 확장하는 팽창 합성곱(Atrous/Dilated Convolution) 및 셀프 어텐션 융합.
- **객체의 스케일·회전 변형 발생 시 패턴 인식 성능 급락** :
  - **한계점** : 객체의 스케일 변화, 큰 각도의 회전, 원근 왜곡 발생 시 CNN 고유의 이동 등변성만으로는 패턴 인식 성능이 급락하는 한계.
  - **해결 방안** : 입력 이미지의 기하학적 변형 파라미터를 스스로 추론하여 샘플링 그리드를 동적으로 왜곡 보정하는 공간 변환 네트워크(STN) 결합.

## Ⅴ. 합성곱 신경망(Convolutional Neural Network, CNN) 적용 및 발전을 위한 기술사적 제언

- **미세 결함 검출 중심 엔터프라이즈 고도화** : 풀링 손실로 1픽셀 결함 검출 실패의 한계를 탈피하고, FPN 스킵 연결로 미세 크랙 99% 포착을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- **연산 효율성 중심 엔터프라이즈 고도화** : 표준 3D 합성곱으로 연산량 과다의 한계를 탈피하고, 뎁스와이즈 분리로 FLOPs 70% 감축을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- **전역 문맥 수용 중심 엔터프라이즈 고도화** : 작은 커널로 전체 조망 부재의 한계를 탈피하고, 7×7 대형 커널로 ViT급 넓은 시야 확보를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
