## 30초 인출

- 본질: **합성곱 신경망(CNN)** 은 국소 수용 영역(Receptive Field)을 갖는 공유 필터의 합성곱(Convolution)과 풀링(Pooling) 연산을 통해 격자형 이미지의 공간적 기하 패턴을 추출하는 대표적인 비전 딥러닝 신경망
- 메커니즘: 입력 이미지에 학습 가능한 2D/3D 커널 합성곱 적용 → 활성화 함수(ReLU) 비선형 변환 → 서브샘플링(Pooling)을 통한 특징 압축 → 완전연결 계층(FC) 또는 GAP를 통한 최종 분류·분할
- 통찰: 연속된 풀링으로 인한 세부 공간 좌표 손실과 국소 수용 영역 한계가 존재하므로 스킵 연결 기반 피라미드 구조(FPN) 및 확장 합성곱(Dilated Conv) 결합 필수

<details><summary>핵심 용어</summary>

- **합성곱 신경망(CNN)** : 시각 피질의 수용장 개념을 모사하여 이미지의 공간적 위상 관계를 보존하며 특징을 추출하는 신경망.
- **합성곱(Convolution)** : 입력 행렬 위를 커널(필터)이 스트라이드 간격으로 슬라이딩하며 요소별 곱셈-누적(MAC)을 수행하는 연산.
- **가중치 공유(Weight Sharing)** : 동일한 커널 필터를 이미지 전체 영역에 반복 재사용하여 모델 파라미터 수를 획기적으로 줄이는 설계.
- **이동 등변성(Translation Equivariance)** : 입력 이미지 내 객체의 위치가 이동하면 추출되는 특징 맵 상의 활성화 위치도 동일하게 이동하는 성질.
- **특징 피라미드(FPN, Feature Pyramid Network)** : 상위 계층의 풍부한 의미론적 정보와 하위 계층의 정밀한 공간 해상도를 스킵 연결로 융합하는 구조.

</details>

## 2~4교시 25점 답안

## Ⅰ. 합성곱 신경망(CNN)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **합성곱 신경망(CNN)** 은 입력 데이터의 공간적 격자 구조(Grid Topology)를 보존하면서, 공유 가중치를 갖는 커널 필터를 적용하여 국소적 공간 특징을 계층적으로 추출하는 딥러닝 아키텍처 |
| 목적 | 완전연결 계층(FC)의 1차원 플래튼(Flatten)으로 인한 2D 공간 위상 정보 파괴 및 파라미터 폭증 문제를 해결하고, 이동 등변성을 보장하는 고효율 이미지 특징 표현 획득 |

## Ⅱ. 합성곱 신경망(CNN)의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **파라미터 절감** | 가중치 공유 (Weight Sharing) | 위치마다 독립적인 가중치를 두지 않고 단일 필터를 전 영역에 슬라이딩하여 파라미터 수 및 과적합 대폭 감축 |
| **위상 보존** | 국소 수용 영역 (Local Receptive Field) | 인접한 픽셀 간의 국소적 상관관계(Local Connectivity)를 집중 학습하여 선, 면, 질감 등 공간적 맥락 추출 |
| **공간 변환성** | 이동 등변성 및 불변성 | 객체가 영상의 어느 위치로 이동해도 동일한 특징 맵이 반응(등변성)하며, 풀링을 통해 미세한 회전·위치 변화에 둔감(불변성) |
| **계층적 추상화** | 심층 표현 학습 (Deep Feature Hierarchy) | 초기 계층(에지, 경계선) → 중간 계층(질감, 부품 패턴) → 고차 계층(전체 객체 의미) 순으로 점진적 지식 추상화 |

## Ⅲ. CNN 아키텍처 및 특징 맵 연산 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 합성곱 신경망(CNN) 기본 레이어 파이프라인 및 연산 흐름 ]          │
└────────────────────────────────────────────────────────────────────────┘
 [ 입력 이미지 X: (C × H × W) ] (예: RGB 3채널 224×224 이미지)
                │
                ▼
 [ 1. 합성곱 계층 (Conv Layer) ] ── (K×K 커널, Stride S, Padding P)
   ├── 국소 픽셀 내적: Feature(i, j) = Σ Σ X(i+m, j+n) * W(m, n) + b
   └── 출력 크기: O = floor((W - K + 2P) / S) + 1
                │
                ▼
 [ 2. 활성화 계층 (ReLU / GELU) ] ─ 비선형 활성화 함수 적용 (음수 0 클리핑)
                │
                ▼
 [ 3. 풀링 계층 (Max Pooling) ] ─── 2×2 영역 최대값 추출 (해상도 1/2 다운샘플링)
                │
                ▼ (Conv + ReLU + Pooling 블록 N회 반복 누적)
 [ 4. 심층 추상화 특징 맵 ] ────── (고차원 시맨틱 특징 맵 획득)
                │
                ▼
 [ 5. 분류/회귀 헤드 계층 ] ────── Global Average Pooling(GAP) 또는 FC Layer
                │
                ▼
 [ 최종 분류 확률 출력 (Softmax) ] ──> [ 정상품 vs 불량품 판정 ]
```

| 연산 하이퍼파라미터 | 세부 동작 및 수식 | 공학적 효과 |
|---|---|---|
| **커널 크기 (K)** | 주로 3×3, 5×5 등 작은 홀수 정방형 필터 | 3×3 필터를 2회 쌓는 것이 5×5 필터 대비 연산량 절감 및 비선형성 증대 |
| **스트라이드 (Stride, S)**| 필터가 이동하는 픽셀 보폭 (주로 1 또는 2) | Stride 2 적용 시 풀링 레이어 없이도 특징 맵 해상도 다운샘플링 가능 |
| **패딩 (Padding, P)** | 입력 가장자리에 0을 채우는 제로 패딩 | 합성곱 연산 후에도 특징 맵 크기 유지(Same Padding) 및 외곽 정보 손실 방지 |
| **최대 풀링 (Max Pooling)**| 윈도우 내 가장 지배적인 활성화 값만 유지 | 노이즈 억제 및 사소한 위치 왜곡에 대한 공간적 불변성(Invariance) 제공 |

## Ⅳ. 완전연결망(ANN), 합성곱망(CNN), 비전 트랜스포머(ViT) 비교

| 비교 항목 | 완전연결 신경망 (ANN / MLP) | 합성곱 신경망 (CNN) | 비전 트랜스포머 (ViT) |
|---|---|---|---|
| **입력 데이터 처리** | 1차원 평탄화 벡터로 직렬화 | 2D/3D 이미지 텐서 격자 구조 유지 | 이미지를 16×16 패치 토큰으로 분할 |
| **귀납적 편향 (Bias)** | 거의 없음 (모든 연결 학습 필요) | 매우 강함 (국소성, 이동 등변성) | 거의 없음 (전역 어텐션 학습) |
| **데이터 요구량** | 데이터 적을 시 과적합 발생 | 적은 데이터로도 우수한 일반화 | 초대규모 데이터셋(JFT-300M) 필수 |
| **장거리 의존성** | 파라미터 폭증으로 장거리 모델링 난항 | 레이어를 깊게 쌓아야 수용 영역 확장 | 단일 레이어에서 이미지 전체 전역 참조 |
| **연산 복잡도** | O(In × Out) 파라미터 폭증 | 커널 공유로 O(H × W × K^2) 경량 | 패치 수에 비례한 O(N^2) 어텐션 복잡도 |
| **주요 활용 분야** | 정형 데이터 테이블 분석 | 제조 불량 검출, 실시간 객체 추적 | 초대규모 멀티모달 파운데이션 백본 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 반복적인 풀링 및 스트라이드 다운샘플링으로 인해 미세 결함 검출에 필수적인 픽셀 단위 정밀 좌표 정보가 손실되는 해상도 저하 | 하위 계층의 고해상도 특징 맵과 상위 계층의 풍부한 시맨틱 특징 맵을 스킵 연결로 융합하는 U-Net 및 특징 피라미드 네트워크(FPN) 도입 |
| 고정된 크기의 수용 영역(Receptive Field)으로 인해 이미지 전체의 전역적 문맥(Global Context)이나 장거리 픽셀 간 상관관계 포착 불가 | 필터 내부에 빈 공간을 두어 파라미터 증가 없이 수용 영역을 수배 확장하는 팽창 합성곱(Atrous/Dilated Convolution) 및 셀프 어텐션 융합 |
| 객체의 스케일 변화, 큰 각도의 회전, 원근 왜곡 발생 시 CNN 고유의 이동 등변성만으로는 패턴 인식 성능이 급락하는 한계 | 입력 이미지의 기하학적 변형 파라미터를 스스로 추론하여 샘플링 그리드를 동적으로 왜곡 보정하는 공간 변환 네트워크(STN) 결합 |

## Ⅵ. 제언

현대화된 뎁스와이즈 분리 합성곱(Depthwise Separable Conv) 기반의 ConvNeXt 백본에 FPN 스킵 연결을 결합하여 경량성과 고해상도 검출을 양립한 산업용 비전 검사 아키텍처 구축.

```text
[ 고해상도 제조 부품 이미지 (1024 × 1024) ]
                     │
                     ▼
[ ConvNeXt 백본 네트워크 (Depthwise Separable 7×7 Conv) ]
   ├── Stage 1 (1/4 축소): 저수준 국소 에지/선 특징 추출 ──────┐
   ├── Stage 2 (1/8 축소): 부품 텍스처/홀 패턴 추출 ────────┤
   └── Stage 3 (1/16 축소): 고차원 제품 구조 의미론 추출 ────┤ (스킵 연결)
                     │                                         │
                     ▼                                         ▼
[ 특징 피라미드 네트워크 (FPN, Feature Pyramid Network) ] ◄────┘
   ├── Top-Down 경로를 통해 고차원 의미론을 저수준 고해상도 맵으로 역전파
   └── 픽셀 단위 미세 크랙(Crack)과 대형 스크래치를 다중 스케일로 동시 검출
                     │
                     ▼
[ 마이크로초 단위 산업 현장 실시간 불량 판정 ]
```

| 구분 | 레거시 순차형 CNN (VGG/ResNet) | 제언: ConvNeXt + FPN 아키텍처 |
|---|---|---|
| **미세 결함 검출** | 풀링 손실로 1픽셀 결함 검출 실패 | FPN 스킵 연결로 미세 크랙 99% 포착 |
| **연산 효율성** | 표준 3D 합성곱으로 연산량 과다 | 뎁스와이즈 분리로 FLOPs 70% 감축 |
| **전역 문맥 수용** | 작은 커널로 전체 조망 부재 | 7×7 대형 커널로 ViT급 넓은 시야 확보 |
