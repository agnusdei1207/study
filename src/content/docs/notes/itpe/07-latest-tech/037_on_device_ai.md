## 핵심 용어
- NPU(Neural Processing Unit): 딥러닝 연산의 핵심인 대규모 행렬 곱셈(MAC, Multiply-Accumulate) 연산을 저전력으로 고속 병렬 처리하는 전용 반도체
- 가지치기(Pruning): 신경망 가중치 중 출력에 미치는 영향도가 미미한 가중치 연결을 0으로 만들어 연산량과 저장 공간을 줄이는 경량화 기법
- 하이브리드 AI(Hybrid AI): 일상적인 요약·검색·개인정보 작업은 온디바이스에서 처리하고, 복합 추론이나 대규모 지식이 필요한 작업만 클라우드 초대형 LLM으로 토스하는 협업 구조

## 핵심 통찰
- 온디바이스 AI의 핵심 경쟁력은 "지능의 크기"가 아니라, 스마트폰·가전·로봇 단말의 물리적 한계(발열 스로틀링, 배터리 용량, LPDDR 메모리 대역폭) 안에서 얼마나 효율적으로 구동되는가에 있음
- 사용자의 민감한 개인정보(사진, 통화 녹음, 건강 데이터)가 단말 밖으로 한 바이트도 나가지 않는다는 점이 규제(GDPR, 개인정보보호법) 대응의 강력한 무기
- 모델 압축 기술(AWQ 4-bit)의 발전으로 8GB RAM 스마트폰에서도 3B~7B 규모의 언어 모델이 초당 15토큰 이상으로 실시간 생성 가능

## 이웃 토픽과 구분
- 온디바이스 AI vs 엣지 컴퓨팅(Edge Computing): 엣지 컴퓨팅은 통신 기지국·공장 로컬 서버 등 단말과 클라우드 사이의 중간 거점을 포함하는 포괄적 인프라 개념 / 온디바이스 AI는 스마트폰·PC·자동차 등 최종 기기(End-device) 단말 자체에서의 구동에 집중
