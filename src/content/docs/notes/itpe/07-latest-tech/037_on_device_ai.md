## 지식 로드맵 내 현재 위치

지식 위치: AI 모델 배포 → 사용자 단말 추론 → **온디바이스 AI**

## 30초 인출

- 본질: **온디바이스 AI(On-Device AI)** 는 최종 사용자 기기에서 AI 추론을 수행하는 배치 방식
- 메커니즘: 단말 입력 → 경량화 모델·가속기 추론 → 단말 결과 제공 → 성능·자원 관찰
- 통찰: 한계: 서버 기준 품질만으로 배치하면 단말 메모리·전력·지연 한계를 놓침 → 방안: 목표 기기에서 품질과 자원 소모 함께 측정

<details>
<summary>핵심 용어</summary>

- **온디바이스 AI(On-Device AI)** : 스마트폰·PC·차량 등 사용자 기기에서 AI 추론을 수행하는 배치 방식
- **신경망처리장치(Neural Processing Unit, NPU)** : 신경망 계산에 특화된 연산을 지원하는 프로세서
- **양자화(Quantization)** : 모델 수치 표현 정밀도를 낮춰 메모리·계산 요구를 줄이는 방법
- **하이브리드 AI(Hybrid AI)** : 단말과 서버·클라우드가 처리 역할을 나누는 구조
- **모델 런타임(Model Runtime)** : 기기 하드웨어에서 모델 연산을 실행·최적화하는 소프트웨어 계층
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **온디바이스 AI(On-Device AI)** 는 최종 사용자 기기에서 AI 추론을 수행하는 배치 방식 |
| 목적 | 네트워크 왕복을 줄이고 기기 환경에서 즉시 처리하는 과업 지원 |

### Ⅱ. 단말 추론 구조

```text
단말 입력·정책 확인
         ↓
기기 내 모델·런타임 실행
         ↓
응답·제어 결과 제공
         ↓
품질·지연·전력 관찰
```

### Ⅲ. 핵심 구현 기술

| 기술 | 목적 | 확인 사항 |
|---|---|---|
| 양자화·증류 | 저장·연산 자원 요구 조정 | 정확도·하드웨어 호환 |
| CPU·GPU·NPU | 기기별 추론 계산 | 처리량·전력·발열 |
| 런타임 최적화 | 연산자·메모리·가속기 실행 조정 | 기기별 성능 편차 |
| 하이브리드 처리 | 과업별 단말·서버 분담 | 전송 조건·권한·대체 경로 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 기기별 연산·메모리·배터리 제약 | 목표 기기군에서 품질·지연·전력 시험 |
| 단말 저장 정보·앱 권한 노출 | 로컬 저장·접근·로그·업데이트 보호 |
| 서버 전환 시 민감자료 전송 | 전환 조건·동의·최소 정보 전송 정책 설정 |

### Ⅴ. 제언

민감도·연결성·지연 요구·기기 자원으로 과업을 분류하고 제한 실증의 품질·비용으로 처리 위치 결정.
