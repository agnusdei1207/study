## 30초 인출

- 본질: **시계열 이상치 탐지** 는 시간 순서로 기록되는 연속 데이터 스트림에서 정상 패턴(추세, 계절성, 주기)을 벗어나는 비정상적인 데이터 포인트, 문맥적 일탈, 또는 집단 패턴을 감지하는 기계학습 및 딥러닝 기술
- 메커니즘: 슬라이딩 윈도우 기반 스트림 수집 → 딥러닝 재구성/예측 모델(TranAD, Autoencoder)을 통한 이상 점수(Anomaly Score) 산출 → 극단값 이론(EVT/SPOT) 기반 동적 임계치 판정 → 실시간 경보
- 통찰: 계절성 및 부하 변동에 고정 임계치를 적용하면 경보 피로(Alert Fatigue)가 발생하므로 스트리밍 극단값 이론(SPOT)과 다변량 상호의존성 그래프 신경망(GDN) 결합 필수

<details><summary>핵심 용어</summary>

- **시계열 이상치 탐지** : 시계열 데이터의 시간적 의존성과 상관관계를 학습하여 비정상적인 거동을 감지하는 분석 체계.
- **점 이상(Point Anomaly)** : 특정 시점의 데이터 값이 정상 분포 범위를 급격히 벗어난 단발성 스파이크.
- **문맥 이상(Contextual Anomaly)** : 값 자체는 정상 범위이나 특정 시간대나 계절, 운전 맥락에 비추어 비정상적인 상태.
- **집단 이상(Collective Anomaly)** : 개별 데이터 포인트는 정상이지만 일련의 연속된 시계열 시퀀스가 비정상 패턴을 형성하는 경우.
- **SPOT(Streaming Peaks Over Threshold)** : 극단값 이론(EVT)을 적용하여 정규분포 가정이 맞지 않는 스트림 데이터에서 동적 임계치를 자율 산출하는 알고리즘.

</details>

## 2~4교시 25점 답안

## Ⅰ. 시계열 이상치 탐지의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **시계열 이상치 탐지** 는 시간 축에 따라 발생하는 연속 데이터 스트림에서 시계열의 고유한 추세(Trend)와 주기성(Seasonality)을 분석하여 정상 상태를 벗어난 패턴을 실시간 식별하는 분석 기법 |
| 목적 | 제조 설비 고장 사전 예측(예지보전), IT 시스템 서비스 장애 선제 감지, 금융 거래 사기(FDS) 실시간 차단 및 무중단 운영 달성 |

## Ⅱ. 시계열 이상치의 3대 유형 및 특징

| 구분 | 이상치 유형 | 핵심 특징 및 대표 실사례 |
|---|---|---|
| **점 이상 (Point)** | 글로벌/국소 스파이크 | 특정 단일 시점의 센서 값이 정상 범위를 급격히 벗어난 현상 (예: 배관 유압의 순간 폭증) |
| **문맥 이상 (Contextual)** | 맥락적 조건 불일치 | 수치 자체는 연간 정상 범위이나 특정 시간대에 부적합 (예: 한겨울 심야 시간대 서버실 냉각 팬 전력 소모 급증) |
| **집단 이상 (Collective)** | 시퀀스 패턴 일탈 | 개별 센서 값은 임계치 이내이나 연속된 파형의 형태나 주기가 비정상 (예: 심전도 부정맥 파형, 진동 주파수 패턴 왜곡) |

## Ⅲ. 시계열 이상치 탐지 아키텍처 및 딥러닝 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 시계열 딥러닝 기반 실시간 이상 탐지 파이프라인 ]              │
└────────────────────────────────────────────────────────────────────────┘
      │
      ▼
 [ Phase 1: 시계열 스트림 수집 및 전처리 ]
   ├── 센서 데이터 유입 (IoT Edge, Kafka) 및 결측치 보간
   └── 슬라이딩 윈도우(Sliding Window) 분할 및 Z-Score / MinMax 정규화
      │
      ▼
 [ Phase 2: 딥러닝 복원 및 예측 모델 (TranAD / Anomaly Transformer) ]
   ├── 정상 시계열 데이터만을 학습하여 정상 패턴의 잠재 공간(Latent Space) 형성
   └── 모델을 통해 현재 윈도우의 복원값(X_hat) 또는 다음 시점 예측값 산출
      │
      ▼
 [ Phase 3: 이상 점수(Anomaly Score) 산출 ]
   ├── 재구성 오차 계산: Score(t) = ||X(t) - X_hat(t)||^2
   └── 정상 상태에서는 오차 최소화, 이상 발생 시 오차 급증
      │
      ▼
 [ Phase 4: 동적 임계치 판정 및 알람 (Dynamic Thresholding) ]
   ├── 극단값 이론(EVT) 기반 SPOT 알고리즘으로 동적 임계치(Th_t) 실시간 갱신
   └── Score(t) > Th_t 초과 시 이상 경보 발령 및 담당자 대시보드 전송
```

| 파이프라인 단계 | 엔지니어링 세부 기법 | 공학적 중요성 |
|---|---|---|
| **윈도우 분할** | 고정/가변 크기 슬라이딩 윈도우 | 시간적 인과관계 및 단기 의존성 보존 |
| **신경망 복원** | Autoencoder, LSTM-VAE, TranAD | 다변량 센서 간의 비선형 상호연관성 모델링 |
| **오차 정규화** | Mahalanobis Distance, Cosine Distance | 센서별 측정 단위 및 분산 차이 보정 |
| **동적 임계치** | SPOT (Streaming Peaks Over Threshold) | 계절적 기저치 상승에 따른 오탐 원천 차단 |

## Ⅳ. 전통 통계, 전통 머신러닝, 딥러닝 기반 탐지 비교

| 비교 항목 | 전통 통계 기법 (ARIMA, 3-Sigma) | 전통 머신러닝 (Isolation Forest) | 최신 딥러닝 (TranAD, GDN) |
|---|---|---|---|
| **다변량 지원** | 단변량 위주 (다변량 시 연산 불가) | 다변량 지원 가능 (차원 증가 시 저하) | 수백 개 센서의 다변량 상관성 모델링 |
| **시간 순서 반영** | 시간 축 명시적 고려 (시차 상관) | 시간 순서 정보 손실 (점 단위 분포) | 어텐션 및 순환 구조로 시간 축 완벽 보존 |
| **비선형성 표현** | 선형 시계열에 국한 | 초평면 분할 기반 비선형성 지원 | 심층 신경망 기반 고차원 비선형 표현 |
| **학습 데이터 요구**| 적은 데이터로 빠른 통계 산출 | 보통 수준의 정형 데이터 | 대규모 정상 학습 데이터 필요 (GPU 요구) |
| **주요 한계** | 복잡한 계절성 및 돌발 패턴 오탐 | 집단 이상(Collective) 탐지 불가 | 모델 설명력(XAI) 부재 및 연산 자원 소모 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 주간/야간, 계절성 또는 정상적인 설비 부하 변동 시 고정된 정적 임계치(3-Sigma 등)로 인해 수천 건의 오탐(False Positive)과 경보 피로(Alert Fatigue) 발생 | 데이터의 꼬리(Tail) 분포를 통계적으로 추정하는 극단값 이론 기반의 SPOT(Streaming Peaks Over Threshold) 알고리즘을 적용하여 실시간 동적 임계치 자동 조정 |
| 수백 개 이종 센서 간의 물리적 연결 관계를 무시하고 단일 센서 값만 분석할 때 다변량 상관관계 붕괴 이상 감지 실패 | 센서 간의 인과적 토폴로지를 방향성 그래프로 구성하고 노드 간 편차를 학습하는 그래프 편차 네트워크(GDN, Graph Deviation Network) 도입 |
| 딥러닝 기반 이상 탐지 모델이 산출한 이상 점수의 블랙박스 특성으로 인해 현장 엔지니어가 원인 센서를 특정하지 못하는 대응 지연 | Integrated Gradients 및 SHAP 기법을 연동하여 이상 점수에 가장 크게 기여한 상위 3개 센서 피처를 시각화하는 XAI 파이프라인 결합 |

## Ⅵ. 제언

트랜스포머 기반의 TranAD 신경망과 극단값 이론 기반의 SPOT 동적 임계치를 결합하고, XAI 기여도 분석을 내재화한 엔터프라이즈 실시간 이상 탐지 플랫폼 구축.

```text
[ 다변량 산업 센서 스트림 (Kafka) ] ──> [ TranAD 딥러닝 복원 엔진 ]
                                                 │
                                                 ▼ (재구성 오차 벡터 산출)
[ 이상 점수 산출 및 SPOT 동적 임계치 엔진 ]
   ├── SPOT 알고리즘: 극단값 이론(EVT) 기반 실시간 동적 Th_t 산출
   └── Score(t) > Th_t 충족 시 즉각 알람 트리거 (오탐률 90% 감축)
                                                 │
                                                 ▼
[ XAI 센서 기여도 분석 엔진 ]
   ├── 이상 발생에 기여한 주원인 센서 Top-3 식별 (예: 1번 펌프 베어링 온도)
   └── 현장 정비 담당자 모바일 앱으로 원인 분석 리포트 즉시 발송
```

| 구분 | 고정 임계치 기반 레거시 룰 | 제언: TranAD + SPOT 동적 플랫폼 |
|---|---|---|
| **임계치 관리** | 엔지니어가 수작업으로 상/하한선 설정 | 스트리밍 데이터 기반 자율 적응형 갱신 |
| **경보 피로도** | 정상 공정 변경 시 수백 건 알람 폭증 | 통계적 극단값 기반으로 진짜 장애만 선별 |
| **원인 분석** | 전체 센서를 엔지니어가 일일이 확인 | XAI 기여도 기반 1분 이내 원인 센서 특정 |
