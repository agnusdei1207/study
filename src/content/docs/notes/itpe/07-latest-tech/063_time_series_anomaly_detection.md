## 연관 키워드

- 시계열 이상치 탐지(Time Series Anomaly Detection), 이상 점수(Anomaly Score), 동적 임계치
- 극단값 이론(EVT), SPOT(Streaming Peaks Over Threshold), 경보 피로(Alert Fatigue)
- 오토인코더(Autoencoder), TranAD, 그래프 편차 네트워크(GDN)
- 점 이상, 문맥 이상, 설명 가능한 인공지능(XAI), SHAP

## Ⅰ. 시계열 이상치 탐지의 개요

- 핵심 요약 : 시간 축을 따르는 데이터 흐름에서 정상 패턴을 학습하고, 그 범위를 벗어난 이상을 실시간으로 식별하는 분석 기법.
- 개념 : 시계열의 **추세** (Trend)와 **주기성** (Seasonality)을 분석해 정상 상태를 정의하고, 그로부터 벗어난 패턴을 실시간으로 찾아내는 **시계열 이상치 탐지** (Time Series Anomaly Detection) 기법.
- 배경 및 필요성 : 계절성과 부하 변동이 있는 데이터에 고정 임계치를 적용하면 정상 변동까지 경보로 울려 **경보 피로** (Alert Fatigue)가 생기므로, 데이터 분포에 맞춰 임계치를 자동 조정하는 방법이 필요해짐.
- 주요 목적 : 설비 고장의 사전 감지(예지보전), IT 서비스 장애의 선제 탐지, 금융 거래 이상 차단을 통한 무중단 운영.

## Ⅱ. 시계열 이상치 탐지의 특징 및 장점

- 핵심 요약 : 시간 구조를 보존한 재구성 오차와 분포 기반 동적 임계치가 결합되어 오탐을 줄이고 실시간 판단을 가능하게 하는 방식.

1. 재구성 기반 학습 : 정상 데이터만으로 정상 패턴을 학습 → 라벨이 적은 현장에서도 이상을 정의할 수 있음.
2. 동적 임계치 : **극단값 이론** (EVT, Extreme Value Theory) 기반으로 꼬리 분포를 추정하여 임계치를 실시간 갱신 → 계절성 변화에 따른 오탐 감소.
3. 다변량 상관 분석 : 여러 센서의 관계를 함께 학습 → 개별 값은 정상이어도 관계가 깨진 이상을 포착.

## Ⅲ. 시계열 이상치 탐지의 구조 (흐름)

- 핵심 요약 : 스트림 수집에서 시작해 이상 점수 산출, 동적 임계치 판정, 경보로 이어지는 4단계 파이프라인.
- **이상 점수** (Anomaly Score) : 현재 윈도우의 실제 값과 모델의 복원값 차이로 계산한 이상 정도의 수치.
- **점 이상** (Point Anomaly) : 특정 단일 시점의 값이 정상 범위를 급격히 벗어나는 스파이크 유형.
- **문맥 이상** (Contextual Anomaly) : 값 자체는 정상 범위여도 특정 시간대나 조건에서 부적합한 유형.

```text
[ 실시간 이상 탐지 파이프라인 ]

Phase 1. 스트림 수집과 전처리
      ↓ 슬라이딩 윈도우 분할, 정규화
Phase 2. 딥러닝 복원 모델
      ↓ 정상 패턴 학습 후 복원값 산출
Phase 3. 이상 점수 산출
      ↓ 복원 오차 계산
Phase 4. 동적 임계치 판정
      ↓ 임계치 초과 시
경보 발령과 담당자 전달
```

```text
[ 정상과 이상의 판정 원리 ]

정상 상태 : 복원 오차가 작음 → 임계치 이하
이상 상태 : 복원 오차가 급증 → 임계치 초과
임계치 : 극단값 이론으로 실시간 재추정
```

## Ⅳ. 통계, 머신러닝, 딥러닝 기법의 비교

- 핵심 요약 : 단변량 통계는 빠르지만 비선형과 다변량에 약하고, 딥러닝은 다변량 상관을 잘 잡는 대신 학습 데이터와 연산 자원을 많이 요구.

| 비교 축 | 통계 기법 (ARIMA, 3-Sigma) | 머신러닝 (Isolation Forest) | 딥러닝 (TranAD, GDN) |
| --- | --- | --- | --- |
| 다변량 지원 | 단변량 위주 | 가능하나 차원이 커지면 성능 저하 | 다수 센서의 상관성 모델링 |
| 시간 순서 반영 | 시차 상관으로 반영 | 점 단위 분포 중심으로 순서 정보 약함 | 순환 구조나 어텐션으로 반영 |
| 비선형성 | 선형 시계열에 국한 | 분할 기반으로 일부 지원 | 심층 신경망으로 고차원 표현 |
| 학습 데이터 요구 | 적은 데이터로 빠른 산출 | 보통 수준의 정형 데이터 | 대규모 정상 데이터와 GPU 필요 |

- 선택 기준 : 센서 수가 적고 선형 패턴이 강하면 통계 기법으로 충분하고, 센서 간 상관이 중요하고 정상 데이터가 충분하면 딥러닝 기법을 검토함.

## Ⅴ. 시계열 이상치 탐지의 한계와 방안

- 핵심 요약 : 정적 임계치의 오탐, 센서 간 상관 무시, 점수의 블랙박스 특성을 동적 임계치, 그래프 기반 모델, 설명 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 정적 임계치의 오탐과 경보 피로 | 주야간, 계절 변동을 고정 기준이 반영하지 못함 | **SPOT** (Streaming Peaks Over Threshold) 기반 동적 임계치 자동 갱신 | 오탐률, 경보 처리 시간 |
| 센서 간 상관 무시 | 개별 센서만 보면 관계 붕괴형 이상을 놓침 | 센서 간 인과 구조를 그래프로 두고 노드별 편차를 학습하는 **GDN** (Graph Deviation Network) | 다변량 이상 탐지 재현율 |
| 점수의 블랙박스 특성 | 원인 센서를 특정하지 못해 현장 대응이 지연됨 | **SHAP** (SHapley Additive exPlanations) 등 기여도 기법과 **XAI** (Explainable Artificial Intelligence) 시각화 | 원인 규명 소요 시간 |

## Ⅵ. 시계열 이상치 탐지에 대한 기술사적 제언

- 핵심 요약 : 임계치 운영, 경보 체계, 원인 분석을 함께 설계해 이상 탐지를 사람의 수작업 감시에서 근거 기반 운영으로 전환.

1. 운영 조직은 고정 임계치를 엔지니어가 수작업으로 조정하는 방식에서 벗어나, 스트리밍 데이터로 임계치가 자율 갱신되는 체계를 단계적으로 도입하는 것이 좋다.
2. 정상 공정이 바뀔 때 알람이 폭증하지 않도록 경보를 통계적 극단값 기준으로 선별하고, 경보 피로도를 주기적으로 측정하여 기준을 보정해야 한다.
3. 이상 점수에 기여한 센서를 설명 기법으로 함께 제시하면, 현장 엔지니어가 원인 센서를 빠르게 좁힐 수 있어 대응 시간이 줄어든다.

## Ⅶ. 결론

- 핵심 요약 : 시계열 이상치 탐지는 정상 패턴의 학습과 동적 임계치의 결합으로 실시간 이상을 식별하는 운영 기술.
- 시사점 : 탐지 정확도만큼 오탐 관리와 설명 가능성이 현장 채택을 결정하므로, 경보 운영 체계까지 함께 설계해야 실효성이 확보된다.
