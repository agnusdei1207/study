## 지식 로드맵 내 현재 위치

지식 위치: 데이터 분석 → 시간 의존 데이터 → **시계열 이상치 탐지**

## 30초 인출

- 본질: **시계열 이상치 탐지**는 시간 순서·상황 맥락에서 정상 패턴과 다른 관측이나 구간을 찾는 분석
- 메커니즘: 시간 맥락 구성 → 이상 점수 산출 → 검증된 기준으로 경보 → 실제 결과로 임계값 점검

<details>
<summary>핵심 용어</summary>

- **점 이상(Point Anomaly)** : 한 시점의 관측이 주변 정상 패턴에서 벗어난 경우
- **문맥 이상(Contextual Anomaly)** : 값 자체보다 시간·운전 조건에 비추어 비정상인 관측
- **집단 이상(Collective Anomaly)** : 개별 값은 정상 범위여도 연속 구간의 조합·순서가 비정상인 경우
- **재구성 오차(Reconstruction Error)** : 입력과 모델 복원값의 차이로, 이상 점수에 활용할 수 있는 값
- **SPOT(Streaming Peaks Over Threshold)** : 극단값 이론을 이용해 데이터 스트림의 임계값을 추정하는 방법

</details>
