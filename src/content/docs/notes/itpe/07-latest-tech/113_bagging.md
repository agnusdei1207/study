## 30초 인출

- 본질: **배깅 (Bagging, Bootstrap Aggregating)** 은 원본 훈련 데이터셋으로부터 복원 추출(Bootstrap)을 통해 복수의 서브 데이터셋을 생성하고, 개별 약분류기를 독립적으로 병렬 학습시킨 후 그 결과를 다수결 투표(Voting)나 평균(Averaging)으로 집계(Aggregating)하여 모델의 분산(Variance)을 감소시키는 앙상블 기법
- 메커니즘: 크기 $N$의 원본 데이터에서 복원 추출하여 약 63.2%의 표본으로 $B$개의 독립 결정트리(Decision Tree)를 병렬 훈련하고, 약 36.8%의 미추출 데이터(OOB, Out-Of-Bag)로 모델을 자체 검증한 후 예측치 앙상블 집계
- 통찰: 개별 결정트리 간 상관계수($\rho$)가 높을 경우 분산 감소 효과가 상쇄되므로 노드 분할 시 특성(Feature)을 무작위 추출하는 랜덤 포레스트(Random Forest) 기법의 병용 필수

<details><summary>핵심 용어</summary>

- **배깅 (Bagging)** : Bootstrap Aggregating의 약칭으로 복원 추출 표본 생성과 예측 집계를 결합한 분산 감소 앙상블 알고리즘.
- **부트스트랩 (Bootstrap)** : 크기가 $N$인 원본 데이터셋에서 중복을 허용하여 크기 $N$의 새로운 표본 집합을 무작위 복원 추출하는 통계적 리샘플링 기법.
- **OOB (Out-Of-Bag)** : 부트스트랩 복원 추출 과정에서 한 번도 선택되지 않고 제외된 약 36.8%($\lim_{N \to \infty} (1 - 1/N)^N \approx e^{-1}$)의 데이터 표본.
- **분산 감소 (Variance Reduction)** : 모델이 학습 데이터의 사소한 변동에 민감하게 과적합(Overfitting)되는 불안정성을 앙상블 평균을 통해 낮추는 원리.
- **랜덤 포레스트 (Random Forest)** : 배깅에 각 분할 노드별 특성 서브셋 무작위 선택(Feature Randomness)을 추가 결합하여 트리 간 상관도를 극도로 낮춘 알고리즘.

</details>

## 2~4교시 25점 답안

## Ⅰ. 배깅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **배깅 (Bagging)** 은 원본 데이터에서 복원 추출한 여러 부트스트랩 표본마다 고분산 약학습기(주로 과적합된 깊은 결정트리)를 독립적으로 병렬 학습시킨 후 결과를 집계(다수결 투표/평균)하는 앙상블 기법 |
| 목적 | 단일 결정트리의 과적합 및 높은 분산(Variance) 오류를 획기적으로 낮추어 일반화 성능과 예측 안정성 확보 |

## Ⅱ. 배깅의 핵심 알고리즘 및 수학적 분산 감소 특징

| 수학적 원리 및 메커니즘 | 수식 표현 및 증명 | 공학적 의미 및 특징 |
|---|---|---|
| **부트스트랩 미선택 확률** | $P(\text{Not Selected}) = \left(1 - \frac{1}{N}\right)^N \approx e^{-1} \approx 0.368$ | 데이터 크기 $N$이 충분히 클 때 약 36.8%의 데이터는 OOB로 남아 별도 검증셋으로 활용 |
| **앙상블 분산 감소 공식** | $\text{Var}\left(\frac{1}{B}\sum_{i=1}^B X_i\right) = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$ | 트리 수 $B \to \infty$로 증가 시 분산은 $\rho \sigma^2$로 수렴, 트리 간 상관계수 $\rho$를 낮추는 것이 핵심 |
| **편향-분산 트레이드오프** | $\text{Bias}(\text{Ensemble}) \approx \text{Bias}(\text{Base})$, $\text{Var} \ll \text{Var}(\text{Base})$ | 개별 모델의 편향(Bias)은 유지한 채 오직 분산(Variance)만을 독립적으로 대폭 감소 |
| **병렬 학습 가능성** | $\mathcal{M}_b \perp \mathcal{M}_{b'}$ ($b \ne b'$) | 개별 모델 간 상호 의존성이 전혀 없어 멀티코어 CPU/GPU 클러스터에서 100% 병렬 훈련 |

## Ⅲ. 배깅의 부트스트랩 샘플링-병렬 학습-집계 파이프라인

```text
┌────────────────────────────────────────────────────────────────────────┐
│             배깅 (Bootstrap Aggregating) 엔드투엔드 파이프라인          │
└────────────────────────────────────────────────────────────────────────┘
 [ 원본 학습 훈련 데이터셋 (Original Dataset: N개 샘플) ]
                          │
       ┌──────────────────┼──────────────────┐ 복원 추출 (Bootstrap)
       ▼ (중복 허용 N개)  ▼ (중복 허용 N개)  ▼ (중복 허용 N개)
 ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
 │ Bootstrap D_1 │  │ Bootstrap D_2 │  │ Bootstrap D_B │
 └───────┬───────┘  └───────┬───────┘  └───────┬───────┘
         │ (독립 병렬)      │ (독립 병렬)      │ (독립 병렬)
         ▼                  ▼                  ▼
 ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
 │ 개별 분류기 1 │  │ 개별 분류기 2 │  │ 개별 분류기 B │  (예: Fully Grown Tree)
 │ Model M_1     │  │ Model M_2     │  │ Model M_B     │
 └───────┬───────┘  └───────┬───────┘  └───────┬───────┘
         │                  │                  │
         └──────────────────┼──────────────────┘
                            │ 집계 (Aggregating)
                            ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 결합 집계 엔진 (Ensemble Aggregator)                                 │
 │  - 분류(Classification): 다수결 투표 (Majority Voting: Mode(y_1..y_B)) │
 │  - 회귀(Regression): 단순 산술 평균 (Averaging: (1/B) * Σ y_b)       │
 └──────────────────────────┬───────────────────────────────────────────┘
                            │
                            ▼
 [ 최종 일반화된 강건한 예측 결과 (Ensemble Prediction) ]
```

| 파이프라인 단계 | 상세 처리 내용 | 활용 알고리즘 및 검증 |
|---|---|---|
| **부트스트랩 리샘플링** | 균등분포 난수를 발생시켜 원본과 동일한 크기 $N$의 표본 데이터셋 $B$벌 생성 | 중복 샘플링 허용 |
| **약학습기 병렬 학습** | 가지치기(Pruning)를 하지 않은 과적합 상태의 결정트리들을 각 코어에 분산 훈련 | DecisionTree, CART |
| **OOB 평가** | 각 모델별로 학습에 사용되지 않은 36.8% OOB 데이터를 모아 모델 성능 자체 검증 | 별도 K-Fold 분할 불필요 |
| **결과 집계** | 테스트 데이터 입력 시 $B$개 모델의 출력을 수집하여 소프트/하드 보팅 수행 | Soft Voting (확률 평균) |

## Ⅳ. 앙상블 학습 기법 비교

| 비교 항목 | 배깅 (Bagging - 본 토픽) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|---|---|---|---|
| **학습 방식** | 병렬 독립 학습 (Parallel) | 순차적 직렬 학습 (Sequential) | 이종 모델 병렬 + 메타 모델 학습 |
| **오차 감소 초점** | 분산(Variance) 감소 (과적합 완화) | 편향(Bias) 감소 (과소적합 극복) | 예측력 극대화 (편향 및 분산 모두 감소) |
| **데이터 샘플링** | 복원 추출 (동일 가중치) | 이전 모델 오분류 데이터 가중치 부여 | 교차 검증 기반 예측값으로 메타 셋 생성 |
| **이상치(Outlier) 민감도** | 둔감함 (극소수 이상치 영향 희석) | 극도로 민감함 (이상치에 가중치 집중) | 중간 |
| **대표 알고리즘** | BaggingClassifier, Random Forest | AdaBoost, GBM, XGBoost, LightGBM | StackingClassifier |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 특정 강한 특성(Dominant Feature)이 존재할 경우 모든 부트스트랩 트리가 동일한 최상단 분할을 수행하여 트리 간 상관계수($\rho$)가 증가하고 분산 감소 실패 | 분할 노드마다 전체 $p$개 특성 중 무작위로 $m \approx \sqrt{p}$개만 선택하여 트리의 다양성을 강제 확보하는 랜덤 포레스트(Random Forest)로 전환 |
| 수백 개의 결정트리를 앙상블함에 따라 단일 결정트리가 가지던 의사결정 경로의 시각적 설명가능성(Interpretability) 완전 상실 | SHAP(Shapley Additive Explanations) 및 순열 특성 중요도(Permutation Feature Importance) 기법을 결합하여 설명가능성(XAI) 보완 |
| 고차원 희소 데이터(텍스트 TF-IDF, 유전체 데이터)에서 복원 추출 시 분산 감소 효과가 미미하고 연산 메모리 급증 | 연속형 특징에 적합한 특성 서브스페이스 샘플링(Random Subspace Method) 병행 및 트리 깊이 사전 제한(Max Depth 규제) 적용 |

## Ⅵ. 제언

프로덕션 MLOps 환경에서 모델의 분산 과적합을 방지하고 빠른 배포를 달성하기 위해 OOB 자동 조기 종료와 GPU 가속 기반 앙상블 파이프라인 구축 권고.

│                                                        │
│  ┌──────────────────────────────────────────────────┐  │

| **블랙박스 해소** | 내부 판단 근거 제공 불가 | 트리 앙상블 전용 TreeSHAP 즉시 산출 |
