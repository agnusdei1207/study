## 답안 골격
```text
[배깅] ◀━━ 머리: Ⅶ 내 의견 (복원 추출과 병렬 독립 모델 앙상블로 편향 증가 없이 분산을 획기적으로 낮추는 과적합 방지 알고리즘)
 ┃
 ┣━ Ⅰ 개요 ───── 단일 결정트리의 높은 분산(Variance) 및 과적합(Overfitting) 취약성 → 부트스트랩 복원 추출과 예측 집계를 결합한 배깅 태동
 ┣━ Ⅱ 특징 ───── 부트스트랩 샘플링(복원 추출) · 모델 병렬 독립 학습 · 분산(Variance) 감소 효과 · OOB(Out-of-Bag) 자체 검증 지원
 ┣━ Ⅲ 구조 ───── 원본 훈련 데이터 + 복원 추출 샘플러($D_1, \dots, D_B$) + 기저 분류기군(Weak Learners) + 집계기(보팅/평균)
 ┣━ Ⅳ 흐름 ───── ① 원본 데이터 $N$개에서 중복 허용 $N$개 복원 추출 → ② $B$개의 독립 서브셋 생성 → ③ 각 서브셋별 결정트리 병렬 학습 → ④ 분류: 다수결 투표 / 회귀: 산술 평균 집계
 ┣━ Ⅴ 비교 ───── 배깅(Bagging) vs 부스팅(Boosting) vs 보팅(Voting) (복원추출+병렬+분산감소 vs 오차가중+순차+편향감소 vs 서로 다른 이종 모델 결합)
 ┗━ Ⅵ 실무 ───── 트리 간 상관관계(Correlation) 발생 시 분산 감소 한계 / 해석력(Explainability) 상실 / 대규모 트리 메모리 점유
```

## 한 줄 본질
- 하나의 깊은 결정트리는 훈련 데이터에 너무 민감해서 데이터가 조금만 바뀌어도 예측이 출렁거림(고분산) → 복원 추출로 여러 개의 서로 다른 가상 데이터셋을 만들고 각각 트리를 병렬로 키워 평균을 냄 → 과적합 없는 견고한 일반화 달성 / 모델 내부 해석 불가능

## 핵심 그림
```text
[배깅(Bootstrap Aggregating)의 데이터 복원 추출 및 병렬 집계 구조]

                 [원본 훈련 데이터셋 D (N개 샘플)]
                                 │
     ┌───────────────────────────┼───────────────────────────┐
     ▼ (복원 추출: Bootstrapping) ▼ (복원 추출)               ▼ (복원 추출)
  [샘플 D_1 (N개)]            [샘플 D_2 (N개)]            [샘플 D_B (N개)]
     │ (63.2% 포함 / 36.8% OOB)  │                           │
     ▼                           ▼                           ▼
  [결정트리 모델 1]           [결정트리 모델 2]           [결정트리 모델 B]
  (병렬 독립 훈련)            (병렬 독립 훈련)            (병렬 독립 훈련)
     │                           │                           │
     └───────────────────────────┼───────────────────────────┘
                                 ▼ (집계: Aggregating)
                     [분류: 다수결 투표 / 회귀: 산술 평균]
                                 │
                                 ▼
                         [최종 앙상블 예측]
```

## 핵심 용어
- 부트스트랩(Bootstrapping): 크기가 $N$인 원본 데이터셋에서 중복을 허용하여 다시 $N$개의 표본을 무작위 복원 추출하는 통계적 샘플링 기법
- OOB(Out-of-Bag): 부트스트랩 복원 추출 시 한 번도 선택되지 않고 남는 약 36.8%($(1 - 1/N)^N \approx 1/e$)의 샘플로, 별도의 검증 세트 없이 모델 성능을 자체 평가하는 데 쓰임
- 분산 감소(Variance Reduction): 서로 독립인 $B$개의 모델을 평균하면 전체 분산이 이론상 $\frac{1}{B}\sigma^2$로 줄어들어 극심한 과적합을 방지하는 수학적 원리

## 핵심 통찰
- "결정트리의 약점이 배깅의 무기가 된다": 결정트리는 데이터의 작은 변화에도 형태가 크게 요동치는 불안정한(Unstable) 모델이지만, 배깅은 바로 그 불안정성 덕분에 트리 간의 다양성이 확보되어 평균을 냈을 때 오차가 상쇄됨
- 배깅에서 랜덤 포레스트(Random Forest)로의 진화: 단순 배깅은 모든 트리가 동일한 강력한 변수 하나에 쏠려 트리 간 상관관계(Correlation)가 높아지는 한계가 있음 → 랜덤 포레스트는 분기마다 변수 후보군도 무작위 선별(Feature Bagging)하여 트리들을 완벽히 탈상관화(Decorrelation)함
- 완전 병렬 처리 가능: 부스팅과 달리 각 모델이 이전 모델의 오차에 의존하지 않으므로, 수백 개의 트리를 분산 서버나 멀티코어 CPU에서 완벽하게 병렬 학습시킬 수 있음

## 이웃 토픽과 구분
- 배깅 vs 부스팅: 배깅은 복원 추출 데이터로 독립 병렬 학습하여 분산(과적합)을 줄임 / 부스팅은 이전 트리의 오차에 가중치를 부여해 순차 학습하여 편향(과소적합)을 줄임

## 문제·원인·대책
- 적용 상황: 의료 환자 심장 질환 발병 여부 예측 모델 구축 시 단일 트리의 과적합 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 단일 결정트리의 훈련 정확도는 99%이나 테스트 데이터 정확도가 65%로 급락 | 과도하게 깊은 트리 생성을 통한 훈련 데이터 노이즈 과적합(고분산) | 부트스트랩 샘플 100개를 결합한 배깅 앙상블(랜덤 포레스트) 적용 | 테스트 일반화 정확도 89%로 향상 |
| 특정 핵심 변수(혈압)가 너무 지배적이어서 모든 배깅 트리의 첫 노드가 동일해짐 | 기저 트리 간의 높은 상관성(Correlation)으로 인한 분산 감소 효과 상쇄 | 분기 노드 분할 시 전체 특성 중 $\sqrt{p}$개만 무작위 추출하는 특성 배깅 적용 | 트리 간 다양성 확보 및 분산 추가 40% 저감 |
| 수백 개 트리를 앙상블하자 특정 환자의 질환 예측 근거를 의사에게 설명 불가 | 앙상블의 블랙박스화에 따른 모델 해석력 상실 | SHAP(Shapley Additive exPlanations) 및 특성 중요도(MDI) 사후 해석 체계 결합 | 의료진에 신뢰성 있는 변수 기여도 제시 |

## 내 의견
- [TabNet 및 Gradient Boosting 전성시대에도 배깅이 필수적인 이유] 최근 정형 데이터에서 XGBoost나 LightGBM이 유행하지만, 노이즈가 극심하고 이상치가 많은 센서/금융 데이터에서는 여전히 배깅(랜덤 포레스트)이 하이퍼파라미터 튜닝 없이 가장 안정적인 베이스라인을 제공함 → 나라면: 불균형 사기 탐지 파이프라인에서 언더샘플링과 배깅을 결합한 Balanced-Bagging을 1차 베이스라인으로 구축하여 오버피팅을 원천 방지하고 빠른 운영 안정성을 확보
