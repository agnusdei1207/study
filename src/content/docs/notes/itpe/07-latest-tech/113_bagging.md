## 연관 키워드

- 배깅(Bagging), 부트스트랩(Bootstrap), 앙상블(Ensemble), 결정트리(Decision Tree)
- OOB(Out-Of-Bag), 랜덤 포레스트(Random Forest), 편향-분산 트레이드오프(Bias-Variance Tradeoff)
- 부스팅(Boosting), 스태킹(Stacking), SHAP(SHapley Additive exPlanations)

## Ⅰ. 배깅(Bagging)의 개요

- 핵심 요약 : 복원 추출한 표본마다 독립 모델을 병렬 학습해 집계함으로써 분산을 줄이는 앙상블 기법.
- 개념 : **배깅** (Bagging, Bootstrap Aggregating)은 원본 데이터에서 **부트스트랩** (Bootstrap, 복원 추출) 표본을 여러 개 만들고, 각 표본마다 과적합되기 쉬운 모델을 독립적으로 학습시킨 뒤 예측을 다수결 또는 평균으로 집계하는 앙상블 기법이다.
- 배경 및 필요성 : 트리 사이의 상관이 높으면 여러 트리를 묶어도 분산 감소 효과가 줄어들므로, 분할 시 특성을 무작위로 골라 트리 간 다양성을 확보하는 **랜덤 포레스트** (Random Forest) 방식을 함께 쓰는 것이 필요하다.
- 주요 목적 : 단일 결정트리의 과적합과 높은 분산을 낮춰 일반화 성능과 예측 안정성을 확보하는 것.

## Ⅱ. 배깅(Bagging)의 특징 및 장점

- 핵심 요약 : 독립 병렬 학습과 집계가 분산 감소와 안정적 예측으로 이어지는 구조.

1. 병렬 독립 학습 : 표본마다 모델을 따로 학습 → 학습 시간을 병렬 자원으로 나눠 단축.
2. 분산 감소 : 여러 모델의 예측을 평균하거나 투표 → 특정 표본의 잡음에 흔들리는 예측 완화.
3. 내장 검증 : 표본에 뽑히지 않은 **OOB** (Out-Of-Bag, 약 36.8%의 미추출 데이터) 로 별도 검증셋 없이 성능 추정 → 데이터 절약.

## Ⅲ. 배깅(Bagging)의 구조 (흐름)

- 핵심 요약 : 원본 데이터를 복원 추출로 나눠 병렬 학습한 뒤 집계하는 단방향 파이프라인.
- 복원 추출 : 원본 N개에서 중복을 허용해 N개를 뽑으면 약 63.2%의 고유 샘플이 포함되고 나머지가 OOB가 된다.
- 집계 : 분류는 다수결 투표, 회귀는 산술 평균으로 최종 예측을 낸다.

```text
[ 원본 데이터 (N개) ]
   ↓ 복원 추출 (부트스트랩)
[ D1 ]    [ D2 ]    [ DB ]
   ↓         ↓         ↓  병렬 학습
[ 모델1 ]  [ 모델2 ]  [ 모델B ]
   ↓         ↓         ↓
[ 집계: 다수결 / 평균 ]
   ↓
[ 최종 예측 ]
```

```text
[ 부트스트랩 표본 구성 ]
원본 N개 → 복원 추출 N개
        ↓
고유 샘플 약 63.2% 포함
        ↓
미추출 약 36.8% = OOB 검증용
```

- 분산 감소 : 트리 간 상관계수 ρ가 낮을수록 평균의 분산이 줄어든다. 식은 $\text{Var} = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$이며, $B$가 커지면 분산은 $\rho\sigma^2$에 수렴한다.
- 편향 유지 : 개별 모델의 편향은 거의 그대로 두고 분산만 낮추는 것이 배깅의 핵심 특성이다.

## Ⅳ. 배깅, 부스팅, 스태킹의 비교

- 핵심 요약 : 배깅은 분산을, 부스팅은 편향을 줄이는 방향이고, 스태킹은 이종 모델의 결합으로 예측력을 높인다.

| 비교 축 | 배깅 | 부스팅 | 스태킹 |
| --- | --- | --- | --- |
| 학습 방식 | 병렬 독립 학습 | 순차 학습 | 이종 모델 학습 후 메타 모델 결합 |
| 주된 감소 대상 | 분산 | 편향 | 편향과 분산 모두 목표 |
| 표본 처리 | 복원 추출, 동일 가중치 | 오분류 샘플에 가중치 부여 | 교차 검증 예측값으로 메타 데이터 구성 |
| 이상치 민감도 | 둔감 | 민감 | 중간 |

- 선택 기준 : 과적합이 문제이고 병렬 자원이 충분하면 배깅, 과소적합이 문제이면 부스팅을 우선 검토한다.

## Ⅴ. 배깅(Bagging)의 한계와 방안

- 핵심 요약 : 상관 증가, 설명력 저하, 고차원 데이터의 비효율을 무작위 특성 선택, 설명 기법, 규제로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 지배적 특성에 의한 상관 증가 | 강한 특성이 모든 트리의 첫 분할을 같게 만들어 분산 감소가 실패 | 분할마다 무작위로 일부 특성만 고르는 **랜덤 포레스트**로 전환 | 트리 간 예측 상관, OOB 오차 |
| 설명가능성 저하 | 수백 개 트리를 묶어 단일 의사결정 경로를 보기 어려움 | **SHAP**(SHapley Additive exPlanations, 특성별 기여도 산출)과 순열 중요도 병행 | 특성 기여도 안정성 |
| 고차원 희소 데이터의 비효율 | 텍스트 TF-IDF처럼 특성이 많은 데이터에서 분산 감소 효과가 미미하고 메모리 사용이 급증 | 특성 서브스페이스 샘플링과 트리 깊이 제한 적용 | 학습 메모리 사용량, 검증 오차 |

## Ⅵ. 배깅(Bagging)에 대한 기술사적 제언

- 핵심 요약 : 모델 규모보다 재현 가능한 학습 절차와 설명 체계를 먼저 세우는 것이 바람직하다.

1. 데이터 분석 조직은 OOB 오차 곡선을 학습 파이프라인에 기록하여, 트리 수를 고정값이 아닌 성능 변화에 따라 정하도록 해야 한다.
2. 모델 운영 조직은 예측 서비스의 지연 시간 목표를 정하고, 학습 완료 모델을 추론 전용 형식으로 변환해 서비스 부하를 관리해야 한다.
3. 리스크 관리 조직은 예측 근거를 특성 기여도로 기록하고, 설명이 필요한 의사결정에는 설명 결과를 함께 보관하도록 정책을 세워야 한다.

## Ⅶ. 결론

- 핵심 요약 : 배깅은 독립 학습과 집계로 분산을 줄여 과적합에 강한 앙상블 기법이다.
- 시사점 : 배깅의 효과는 트리 간 다양성에 달려 있으므로, 모델 수보다 상관을 낮추는 설계가 성능과 안정성을 좌우한다.
