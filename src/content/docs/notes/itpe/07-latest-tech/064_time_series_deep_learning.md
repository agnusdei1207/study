## 지식 로드맵 내 현재 위치

지식 위치: 기계학습 → 순서형 자료 예측·분류 → **시계열 딥러닝**

## 30초 인출

- 본질: **시계열 딥러닝** 은 시간 순서가 있는 자료에서 예측·분류에 유용한 패턴을 신경망으로 학습하는 방법
- 메커니즘: 과거 구간·사용 가능한 보조 변수 입력 → 시간 특성 학습 → 미래 구간 추정·검증
- 통찰: 한계: 미래에야 알 수 있는 변수를 학습 입력에 섞으면 예측 성능 과대평가 → 방안: 예측 시점 기준으로 자료를 분할하고 단순 기준모델과 비교

<details>
<summary>핵심 용어</summary>

- **시계열(Time Series)** : 시간 순서에 따라 관측·기록된 자료
- **순환 신경망(Recurrent Neural Network, RNN)** : 순차 입력을 상태 갱신으로 처리하는 신경망 계열
- **장단기 메모리(Long Short-Term Memory, LSTM)** : 게이트로 정보의 유지·갱신을 조절하는 RNN 구조
- **시간 합성곱 신경망(Temporal Convolutional Network, TCN)** : 시간 방향 합성곱으로 과거 구간 특징을 계산하는 신경망
- **트랜스포머(Transformer)** : 어텐션으로 입력 시점 간 관계를 계산하는 신경망 구조
- **패칭(Patching)** : 여러 연속 시점을 하나의 구간 표현으로 묶는 방법
- **채널 독립 처리(Channel Independence)** : 다변량 시계열 각 변수를 별도 채널로 모델링하는 설계 선택
- **평균절대오차(Mean Absolute Error, MAE)** : 실제값과 예측값 차이의 절대값 평균
- **평균제곱근오차(Root Mean Squared Error, RMSE)** : 제곱 오차 평균의 제곱근

## 2~4교시 25점 답안

### Ⅰ. 시계열 딥러닝의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **시계열 딥러닝** 은 시간 순서가 있는 자료에서 예측·분류에 유용한 패턴을 신경망으로 학습하는 방법 |
| 목적 | 과거 관측·관련 변수에서 미래값이나 상태를 추정 |

### Ⅱ. 시계열 특성과 자료 구성

```text
예측 시점 t의 이용 가능 자료 ──> 과거 구간·외생 변수 구성
                                      │ 시간순 학습·검증 분할
                                      ▼
                               시계열 모델 ──> t 이후 예측
                                                   │
                                           실제값·기준모델과 비교
```

| 특성 | 모델링·평가 관점 |
|---|---|
| 추세·계절성 | 시간대·주기별 패턴과 변화 여부 반영 |
| 자기상관 | 과거 값·상태가 이후 관측과 연결될 가능성 |
| 외생 변수 | 예측 시점에 실제 이용 가능한 변수만 입력 |
| 시간 누수 | 미래 자료가 학습·전처리·검증에 섞이지 않게 분할 |

### Ⅲ. 모델 구조와 예측

```text
과거 시계열·관련 변수
          │ 시간순 정렬·결측 점검
          ▼
학습된 시계열 모델
          │ 미래 구간 추정
          ▼
예측값 ── 실제 관측과 비교·재평가
```

| 구조 | 계산 특성 | 주의점 |
|---|---|---|
| RNN·LSTM | 순차 상태 갱신 | 긴 순차 계산·학습 안정성 |
| TCN | 시간 방향 합성곱 | 입력 길이·수용 구간 설정 |
| Transformer | 어텐션 기반 관계 계산 | 자료량·연산비용·기준 대비 이득 |
| PatchTST | 시점을 패치로 묶고 채널 독립 처리를 제안한 구조 | 특정 데이터에서의 설계 사례이며 보편적 최적 모델은 아님 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 무작위 분할은 미래 자료 누수로 실제 운영 성능을 과대평가할 수 있음 | 시간순 검증과 예측 시점에 이용 가능한 변수만 사용 |
| 복잡한 모델이 단순 기준선보다 나은지 불명확할 수 있음 | 계절 기준선과 비교하고 예측 구간별 MAE·RMSE 및 운영 비용이 개선된 과업에 적용 |

### Ⅴ. 제언

예측 시점별 이용 가능 변수를 먼저 고정하고 계절 기준선 대비 구간별 오차·운영 비용 개선 여부로 모델 선택.
