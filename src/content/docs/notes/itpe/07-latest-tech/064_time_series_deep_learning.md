## 한 줄 본질
- 수동으로 계절성 차분과 파라미터를 맞춰야 했던 통계적 시계열(ARIMA)의 비선형 복잡도 한계 → 신경망을 통해 시간의 흐름에 따른 특징을 자동으로 추출하여 수백 스텝 앞의 미래를 예측 → 정밀한 수요 예측과 이상 감지 달성 / 최근 단순 선형 모델보다도 예측력이 떨어질 수 있는 트랜스포머 과적합 문제 제기

## 핵심 그림
```text
[시계열 딥러닝의 진화와 PatchTST 아키텍처]
1. 1세대 (RNN/LSTM): 순차 처리 은닉 상태 갱신 (장거리 의존성 소실, 병렬 불가)
2. 2세대 (TCN): 인과적 팽창 합성곱(Dilated Conv)으로 수용 영역 확장
3. 3세대 (PatchTST - 최신 트랜스포머 표준):
   [다변량 시계열 입력 (M개 변수, L 길이)]
                     |
                     v
   [채널 독립성 (Channel Independence)] : 각 변수를 독립 단변량으로 분리
                     |
                     v
   [패칭 (Patching)] : 인접한 시점을 묶어 의미 있는 토큰(Patch)으로 분할
   [---Patch 1---][---Patch 2---][---Patch 3---]
                     |
                     v
   [바닐라 트랜스포머 인코더 (Self-Attention)]
                     |
                     v
   [선형 헤드 (Linear Head)] ===> [미래 H 스텝 예측 출력]
```

## 핵심 용어
- 패칭(Patching): 단일 시점(Point) 단위로 토큰을 만들면 노이즈가 심하고 계산량이 급증하므로, 인접한 시간 구간(예: 16개 시점)을 묶어 하나의 패치 벡터로 임베딩하는 최신 시계열 기법
- 채널 독립성(Channel Independence): 다변량 시계열을 다룰 때 모든 변수를 한꺼번에 섞어 어텐션을 계산하지 않고, 각 채널(변수)별로 가중치를 공유하는 독립 인코더를 통과시켜 과적합을 방지하는 설계
- TCN(Temporal Convolutional Network): 미래 정보 누설을 막는 인과적 합성곱(Causal Conv)과 필터 간격을 넓히는 팽창 합성곱(Dilated Conv)을 결합해 긴 과거 시점을 병렬 처리하는 CNN 구조

## 핵심 통찰
- 시계열 딥러닝 분야에서 "Are Transformers Effective for Time Series?(AAAI 2023)" 논문이 단순 1계층 선형 모델(DLinear)이 복잡한 트랜스포머 모델들을 압도한다고 폭로하며 거대한 패러다임 전환이 발생
- 단일 시점(Point) 단위의 셀프 어텐션은 시계열의 고유한 지역적 의미를 포착하지 못하므로, "패치(Patch)" 단위 분할과 "시계열 분해(Trend-Seasonality Decomposition)"를 결합해야만 트랜스포머가 선형 모델을 이길 수 있음
- 전력 수요, 주가, 센서 메트릭 등 도메인에 따라 잡음비(SNR)가 천차만별이므로, 복잡한 딥러닝을 고집하기 전에 선형 베이스라인(DLinear, N-BEATS)과의 비교 검증이 필수

## 이웃 토픽과 구분
- 시계열 딥러닝 vs 자연어 처리 트랜스포머: NLP는 단어 하나하나의 이산적 토큰이 독립된 의미를 가짐 / 시계열 딥러닝은 개별 수치 자체는 의미가 없고 연속된 구간의 변화율과 계절성이 의미를 형성

## 문제·원인·대책
- 적용 상황: 가상발전소(VPP) 24시간 후 전력 발전량 예측을 위해 Informer 모델 도입 후 성능 저하
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 복잡한 트랜스포머를 썼는데 단순 이동평균(Linear)보다 오차가 큼 | 시계열 데이터의 포인트 단위 어텐션 연산 시 고주파 노이즈 과적합 | PatchTST(서브시리즈 패칭 + 채널 독립) 아키텍처로 교체 | 예측 오차(MSE) 25% 개선 |
| 과거 데이터의 평균/분산과 최근 실시간 데이터의 통계량 불일치 | 계절적 기온 상승에 따른 시계열 분포 변화(Distribution Shift) | RevIN(Reversible Instance Normalization) 정규화 계층 삽입 | 도메인 시프트 환경에서도 예측 일관성 유지 |
| 예측 범위가 24시간에서 7일로 늘어날수록 급격한 성능 붕괴 | 순차 자기회귀 생성 시 오차가 누적되는 자가 회귀 오류 | 직접 다중 스텝 예측(Direct Multi-step) 선형 헤드 투영 적용 | 장기 예측 오차 누적 차단 |

## 내 의견
- [RevIN 정규화와 경량 DLinear/PatchTST 앙상블 파이프라인 구축] 무거운 거대 시계열 모델은 현장 엣지 게이트웨이에서 실시간 재학습이 불가능함 → 나라면: 입력단에 RevIN을 두어 계절성 드리프트를 제거하고, 연산량이 극도로 적은 DLinear와 복합 비선형 패턴을 잡는 PatchTST를 앙상블하는 하이브리드 파이프라인을 구축하여 최소한의 컴퓨팅 자원으로 최고 수준의 장기 예측 안정성 달성
