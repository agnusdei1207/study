## 연관 키워드

- 시계열 딥러닝(Time Series Deep Learning), 패칭(Patching), 채널 독립성(Channel Independence)
- 가역적 인스턴스 정규화(RevIN), 인과적 마스킹(Causal Masking), 예측 지평(Horizon)
- PatchTST, Informer, TCN, LSTM
- 데이터 누수(Look-ahead Bias), 워크포워드 검증, 비정상성(Non-stationarity)

## Ⅰ. 시계열 딥러닝의 개요

- 핵심 요약 : 과거 관측치와 외생 변수에서 비선형 시간 의존성과 다변량 상관을 심층 신경망으로 추출해 미래 값을 예측하는 기술.
- 개념 : 과거 시점까지 누적된 관측치와 **외생 변수** (Exogenous Variables)로부터 비선형 시간 의존성을 심층 신경망으로 학습해 미래의 수치나 상태를 예측하는 **시계열 딥러닝** (Time Series Deep Learning) 기술.
- 배경 및 필요성 : 시점 단위로 어텐션을 계산하면 시간적 의미가 흐려지고 연산량이 시퀀스 길이의 제곱으로 늘어나므로, 연속 구간을 묶는 **패칭** (Patching)과 변수를 독립 채널로 다루는 **채널 독립성** (Channel Independence) 설계가 필요해짐.
- 주요 목적 : 선형 통계 기법(ARIMA, Holt-Winters)의 한계를 넘어 긴 예측 지평에서도 정확도를 확보.

## Ⅱ. 시계열 딥러닝의 특징 및 장점

- 핵심 요약 : 패치 단위 토큰화와 정규화가 연산 효율과 분포 안정성을 확보하고, 이것이 장기 예측 정확도로 이어지는 구조.

1. 패치 토큰화 : 인접한 타임스텝을 묶어 한 토큰으로 입력 → 토큰 수가 줄어 연산 부담이 낮아지고 국소 의미가 보존됨.
2. 채널 독립 학습 : 다변량 입력을 채널별 단변량 시계열로 분리해 처리 → 변수 간 과적합을 줄이고 채널 수 증가에 유연하게 대응.
3. 가역적 정규화 : 입력마다 평균과 분산을 제거하고 예측 후 복원 → 분포가 이동하는 데이터에서도 예측 편향을 완화.

## Ⅲ. 시계열 딥러닝의 구조 (흐름)

- 핵심 요약 : 정규화, 패칭, 트랜스포머 인코딩, 예측 헤드를 거쳐 다변량 미래 값을 일괄 생성하고 원래 척도로 복원하는 구조.
- **가역적 인스턴스 정규화** (RevIN, Reversible Instance Normalization) : 입력 구간별 통계치를 제거했다가 출력 단계에서 되돌리는 정규화 층.
- **인과적 마스킹** (Causal Masking) : 미래 시점 정보가 과거 예측에 새어 들지 않도록 시간 방향을 단방향으로 제한하는 장치.

```text
[ PatchTST 연산 흐름 ]

다변량 입력 (M개 채널, L개 과거 시점)
      ↓ 인스턴스별 평균·분산 제거
가역적 정규화 (RevIN)
      ↓ 채널별 단변량 시계열로 분리
채널 독립 처리
      ↓ 인접 P개 시점을 한 토큰으로 묶음
패칭 (Patching)
      ↓ 임베딩 후 패치 토큰 간 어텐션
트랜스포머 인코더
      ↓ 미래 H개 시점 일괄 예측
예측 헤드와 정규화 역변환
```

```text
[ 장기 의존성 확보 경로 ]

순환 게이트 : LSTM, GRU (순차 갱신)
팽창 합성곱 : TCN (병렬 처리, 수용 영역 확장)
셀프 어텐션 : 패치 토큰 간 거시적 관계 계산
추세·계절 분해 : 이동 평균과 푸리에 블록 분리
```

## Ⅳ. 순환 신경망, 합성곱, 어텐션 계열 비교

- 핵심 요약 : 순차 구조는 병렬화가 어렵고, 점 단위 어텐션은 토큰 잡음에 취약해 패치 단위 어텐션으로 발전하는 흐름.

| 비교 축 | 순환 신경망 (LSTM, GRU) | 시간 합성곱 (TCN) | 포인트 어텐션 (Informer) | 패치 트랜스포머 (PatchTST) |
| --- | --- | --- | --- | --- |
| 시간 모델링 | 은닉 상태를 순차 갱신 | 팽창 인과 합성곱 | 희소화된 자기 주의 집중 | 패치 단위 어텐션 |
| 학습 병렬성 | 시점별 직렬 연산으로 제한 | 병렬화 가능 | 병렬화 가능 | 병렬화 가능 |
| 연산 부담 | 시퀀스 길이에 비례, GPU 활용 저조 | 커널 크기에 비례 | 점 단위 토큰으로 중간 수준 | 패치 수 기준으로 축소 |
| 장기 예측 | 길어질수록 오차 누적 | 수용 영역 한계 | 점 단위 토큰 잡음에 취약 | 장기 벤치마크에서 우수한 성능 보고 |

- 선택 기준 : 시퀀스가 짧고 자원이 제한되면 순환 신경망이나 합성곱으로 충분하고, 긴 지평과 다변량 예측이 중요하면 패치 트랜스포머 계열을 검토함.

## Ⅴ. 시계열 딥러닝의 한계와 방안

- 핵심 요약 : 검증 시 미래 정보 누수, 토큰화 비용, 분포 변화를 시간 순서 검증, 패칭, 정규화로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 미래 데이터 누수 (Look-ahead Bias) | 무작위 교차검증이나 전체 데이터 기반 스케일러 피팅으로 실전 성능 과대평가 | 시간 순서를 지키는 **워크포워드 검증** (Walk-forward Validation), 폴드별 학습 데이터로만 스케일러 피팅 | 검증과 실전 성능 격차 |
| 타임스텝 단위 토큰화의 비용 | 시점별 토큰이 많아 연산과 메모리 급증, 국소 의미 부족 | 인접 시점을 묶는 패칭 적용 | 학습 시간, 메모리 사용량 |
| 비정상성에 따른 분포 드리프트 | 평균과 분산이 시간에 따라 변해 예측 오차 증가 | RevIN으로 입력별 통계 제거와 복원 | 드리프트 감지 주기, 예측 오차 추이 |

## Ⅵ. 시계열 딥러닝에 대한 기술사적 제언

- 핵심 요약 : 검증 체계, 지평별 성능 관리, 학습 인프라를 함께 정비해 시계열 딥러닝을 실험용 모델이 아닌 운영 예측 체계로 정착.

1. 모델 평가는 무작위 분할 대신 워크포워드 방식으로 설계하고, 예측 지평별 오차를 따로 기록하여 장기 예측의 신뢰 구간을 점검하는 것이 바람직하다.
2. 장기 예측을 도입하는 조직은 업무별 예측 지평 요구를 먼저 정의하고, 지평이 길어질수록 오차가 어떻게 쌓이는지 주기적으로 측정해야 한다.
3. 학습 인프라는 패치 기반 병렬 학습과 GPU 자원 관리를 표준화하고, 정규화 방식이 분포 변화에 맞게 동작하는지 모니터링 체계에 포함하는 것이 좋다.

## Ⅶ. 결론

- 핵심 요약 : 시계열 딥러닝은 패치 토큰화와 가역 정규화로 장기 다변량 예측을 가능하게 한 신경망 예측 기술.
- 시사점 : 모델 구조만큼 시간 순서를 지키는 검증 설계가 신뢰성을 좌우하므로, 평가 체계와 모델 선택을 함께 관리해야 한다.
