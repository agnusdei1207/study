## 30초 인출
- 본질: 1,750억 개의 파라미터를 기반으로 대규모 웹 코퍼스를 자기회귀(Autoregressive) 사전 학습하여, 가중치 업데이트 없이 프롬프트 입력만으로 다양한 다운스트림 과업을 수행하는 초거대 언어 모델
- 메커니즘: 대규모 텍스트 토큰화(BPE) → 트랜스포머 디코더 기반 다음 토큰 예측(Next-Token Prediction) 사전 학습 → 인컨텍스트 러닝(Few-shot / Zero-shot 프롬프팅) → 확률적 텍스트 생성
- 통찰: 통계적 다음 토큰 예측 특성으로 인한 환각(Hallucination) 및 편향 문제가 내재하므로 검색 증강 생성(RAG) 연계 및 인간 피드백 기반 강화학습(RLHF) 정렬 체계 필수

<details><summary>핵심 용어</summary>

- **GPT-3(Generative Pre-trained Transformer 3):** OpenAI가 2020년 발표한 1,750억 개 파라미터 규모의 디코더 전용 자기회귀 트랜스포머 언어 모델
- **인컨텍스트 러닝(In-context Learning):** 모델의 가중치를 역전파로 갱신하지 않고, 입력 프롬프트에 제공된 지시문과 몇 가지 예시(Context)만으로 새로운 과업의 규칙을 학습·수행하는 현상
- **자기회귀 모델(Autoregressive Model):** 이전 시점까지 생성된 토큰 시퀀스 $P(w_t | w_1, w_2, ..., w_{t-1})$를 조건부 확률로 삼아 다음 토큰을 순차적으로 생성하는 방식
- **퓨샷 프롬프팅(Few-shot Prompting):** 과업 수행 전 프롬프트에 1~5개의 질의-응답 예시 데모를 주입하여 모델의 출력 형식과 정확도를 유도하는 프롬프트 엔지니어링 기법
- **RLHF(Reinforcement Learning from Human Feedback):** 인간의 선호도 평가 데이터를 보상 모델(Reward Model)로 학습시켜 언어 모델의 유용성, 진실성, 무해성을 정렬(Alignment)하는 기법

</details>

## 2~4교시 25점 답안

## Ⅰ. GPT-3의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 1,750억 개의 매개변수와 3,000억 개 이상의 토큰 데이터셋을 활용해 사전 학습된 트랜스포머 디코더 기반의 자기회귀적 초거대 생성 언어 모델 |
| 목적 | 과업별 파인튜닝(Fine-tuning) 의존성을 탈피하고, 자연어 프롬프트 인터페이스를 통해 번역, 요약, 질의응답, 코딩 등 범용 자연어 처리 수행 |

## Ⅱ. GPT-3의 핵심 특징

| 특징 영역 | 주요 특성 | 기술적 구현 내용 |
|---|---|---|
| **스케일링 법칙 실증** | 파라미터 175B 대규모 확장 | 모델 크기, 데이터양, 연산량 증가에 따라 교차 엔트로피 손실이 멱법칙(Power-law)으로 감소함을 증명 |
| **인컨텍스트 러닝** | 무학습(Gradient-free) 과업 수행 | 가중치 고정 상태에서 프롬프트 내 Few-shot 예시 맥락만으로 즉각적인 추론 수행 |
| **단일 범용 인터페이스** | 자연어 프롬프트 기반 태스크 통합 | 분류, 개체명 인식, 대화 등 상이한 NLP 과업을 '자연어 텍스트 입출력' 단일 포맷으로 일원화 |
| **창발적 능력 발현** | 수치 연산 및 논리적 추론 가능 | 파라미터 임계치 돌파를 통해 명시적으로 훈련되지 않은 3자리 덧셈, 간단한 파이썬 코드 생성 능력 발현 |

## Ⅲ. GPT-3 시스템 아키텍처 및 텍스트 생성 프로세스

### 1. 트랜스포머 디코더 기반 아키텍처
```text
+-----------------------------------------------------------------------------------+
|                           GPT-3 175B 아키텍처 세부 구성                           |
+-----------------------------------------------------------------------------------+
|  [입력 프롬프트 텍스트] (Prompt Text: System Prompt + Few-shot Demos + Query)      |
|       │                                                                           |
|       ▼                                                                           |
|  [BPE 토크나이저] (Byte-Pair Encoding, 어휘 사전 크기: 50,257 토큰)                |
|       │                                                                           |
|       ▼                                                                           |
|  [토큰 임베딩 + 학습 가능한 위치 인코딩 (Positional Encoding)] (d_model = 12,288)  |
|       │                                                                           |
|       ▼                                                                           |
|  [96개 트랜스포머 디코더 레이어 (96 Layers, 96 Attention Heads)]                  |
|    +----------------------------------------------------------------------------+ |
|    | [Masked Multi-Head Self-Attention]                                         | |
|    |   - 미래 토큰 참조를 차단하는 인과적 마스킹 (Causal Masking) 적용          | |
|    |   - Sparse Attention 패턴 일부 도입 (메모리 절감)                          | |
|    +----------------------------------------------------------------------------+ |
|    | [Layer Normalization & Residual Connection]                                | |
|    +----------------------------------------------------------------------------+ |
|    | [Position-wise Feed-Forward Network] (d_ff = 4 * 12,288 = 49,152)          | |
|    +----------------------------------------------------------------------------+ |
|       │ (자기회귀 루프: 반복 생성)                                                |
|       ▼                                                                           |
|  [선형 투영 및 Softmax 계층] ──> 다음 토큰 확률 분포 산출 ──> 샘플링 (Top-p, Temp) |
+-----------------------------------------------------------------------------------+
```

### 2. 인컨텍스트 러닝(In-context Learning) 동작 프로세스
```text
[프롬프트 구성]
  Task: 한국어-영어 번역 (지시문)
  예시 1: 사과 -> Apple (Shot 1)
  예시 2: 바나나 -> Banana (Shot 2)
  입력: 딸기 -> [?] (Target)
        │
        ▼ (가중치 갱신 없이 어텐션 메커니즘을 통한 문맥 내 패턴 유추)
  출력 생성: Strawberry (Next Token Generation)
```

## Ⅳ. 인컨텍스트 프롬프팅 방식 비교 및 전통적 파인튜닝과의 비교

### 1. 프롬프팅 방식(Zero-shot vs One-shot vs Few-shot) 비교
| 프롬프팅 방식 | 입력 구성 형태 | 장점 | 한계 및 특징 |
|---|---|---|---|
| **Zero-shot** | 과업 지시문 + 대상 입력값만 제공 | 프롬프트 토큰 절감, 가장 자연스러운 질의 | 복잡한 서식 요구나 고난도 추론 시 정확도 저하 |
| **One-shot** | 지시문 + 단 1개의 입출력 예시 데모 | 과업 포맷에 대한 최소한의 가이드 제공 | 도메인 특화 태스크의 경우 정확도 부족 |
| **Few-shot** | 지시문 + 2~5개 이상의 입출력 예시 데모 | 별도 모델 학습 없이 최상위 수준의 성능 도출 | 컨텍스트 윈도우(2,048 토큰) 소모 증가, 비용 상승 |

### 2. 전통적 파인튜닝(Fine-tuning) 패러다임 대비 비교
| 비교 항목 | 전통적 사전학습-미세조정 (BERT, RoBERTa) | GPT-3 인컨텍스트 러닝 (Prompting) |
|---|---|---|
| **가중치 업데이트** | 다운스트림 데이터셋으로 전체/일부 가중치 역전파 갱신 | 모델 가중치 완전 고정 (추론만 수행, 0% 갱신) |
| **과업별 인스턴스** | 과업마다 별도의 튜닝된 가중치 모델 파일 저장·관리 | 단일 대규모 모델 API 접점으로 모든 과업 범용 서빙 |
| **필요 데이터량** | 과업당 수천~수만 건의 정밀 라벨링 데이터셋 필요 | 수 건의 예시(Few-shot) 또는 지시문(Zero-shot)만으로 충분 |
| **컴퓨팅 인프라** | 재학습을 위한 고성능 GPU 인프라 필수 | 프롬프트 엔지니어링 및 추론 API 호출 인프라 중심 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **환각(Hallucination) 및 통계적 허위 정보 생성**<br />사실 여부와 무관하게 통계적으로 그럴듯한 거짓 문장을 생성하여 신뢰성 훼손 | 검색 증강 생성(RAG)을 통한 외부 최신 신뢰 소스 연계, 인용구 강제 및 자기 검증(Self-Consistency) 기법 적용 |
| **지시 불이행 및 인간 의도와의 불일치(Alignment 문제)**<br />단순 다음 토큰 예측 학습으로 인해 사용자의 명령을 따르기보다 문장을 무작위로 이어 쓰는 현상 발생 | 지시 튜닝(Instruction Tuning) 및 인간 피드백 기반 강화학습(RLHF, DPO)을 통한 InstructGPT/ChatGPT 모델로 고도화 |
| **프롬프트 주입(Prompt Injection) 및 보안 취약점**<br />악의적인 시스템 탈옥(Jailbreak) 프롬프트를 통해 유해 콘텐츠 생성 및 데이터 유출 | NeMo Guardrails 등 LLM 방화벽 도입, 시스템 프롬프트와 사용자 입력의 엄격한 분리 격리 및 입력 필터링 |

## Ⅵ. 제언

GPT-3는 단일 모델의 성능을 넘어 생성형 AI 생태계의 패러다임을 열었으며, 향후 RAG, 에이전트 도구 호출(Tool Calling), 경량 파인튜닝(PEFT)과 결합된 복합 에코시스템으로 발전 필수.

```text
[GPT 기반 백본 엔진] ──> [지능형 에이전트 프레임워크 (LangChain / ReAct)] ──> [외부 API / Tool 호출]
         │
         ▼
[엔터프라이즈 RAG 벡터 DB 결합 (최신 지식 및 사실성 보장)]
```

| 진화 단계 | 1세대 거대 언어 모델 (GPT-3) | 최신 복합 지능 시스템 (GPT-4 / 에이전트) |
|---|---|---|
| **모델 구조** | 순수 단일 밀집(Dense) 언어 모델 | 멀티모달(Vision, Audio) + MoE(Mixture of Experts) |
| **추론 방식** | 단발성 프롬프트 텍스트 출력 | 다단계 사고(CoT), 계획 수립 및 외부 도구 자동 실행 |
| **정렬 수준** | 사전학습 위주 (원시 모델) | RLHF, DPO, 거버넌스 가드레일이 정밀 결합된 안전 AI |
