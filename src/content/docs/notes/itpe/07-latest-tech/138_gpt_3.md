## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 대규모 언어 모델 → GPT-3

## 30초 인출

- 본질: **GPT-3은** 다음 토큰 예측으로 사전학습한 자기회귀 Transformer 언어 모델
- 메커니즘: 대규모 텍스트 사전학습 → 프롬프트에 지시·예시 배치 → 이전 토큰을 조건으로 다음 토큰 생성
- 통찰: 한계: 문맥 내 학습을 실시간 가중치 갱신·사실 검증으로 오해할 수 있음 → 방안: 근거가 필요한 업무에 출처 확인과 출력 검증을 붙임

<details><summary>핵심 용어</summary>

- **자기회귀** : 앞선 토큰들을 조건으로 다음 토큰을 차례로 예측하는 방식
- **문맥 내 학습** : 가중치 갱신 없이 입력 문맥의 예시를 이용해 과제 형식을 따르는 현상
- **퓨샷 프롬프팅** : 입력에 적은 수의 예시를 포함하여 응답을 유도하는 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. GPT-3의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **GPT-3은** 다음 토큰 예측으로 사전학습한 자기회귀 Transformer 언어 모델 |
| 목적 | 문맥에 제시된 지시와 예시를 이용해 여러 텍스트 과제를 생성 방식으로 수행 |

## Ⅱ. 구성요소와 수행 단계

```text
사전학습된 GPT-3 가중치(고정)
           │
프롬프트: 지시·예시·질문 ──> 이전 토큰의 문맥
                                   │ 자기회귀 생성
                                   ▼
                              다음 토큰·응답
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 사전학습 | 텍스트의 다음 토큰 예측으로 매개변수 학습 | 자료의 편향·저작권·품질 문제 |
| 문맥 구성 | 지시와 예시를 입력 토큰에 배치 | 예시 선택에 따른 응답 변동 |
| 생성 | 이전 토큰을 조건으로 순차 출력 | 사실성 보장 부재 |
| 검증 | 외부 근거와 업무 규칙으로 결과 확인 | 허위 정보·민감정보 노출 |

## Ⅲ. 핵심 작동 관계

| 방식 | 모델 가중치 | 과업 정보의 위치 |
|---|---|---|
| 사전학습 | 텍스트로 갱신 | 학습된 매개변수 |
| 문맥 내 예시 | 추론 중 고정 | 프롬프트 토큰 |
| 미세조정 | 별도 학습으로 갱신 | 과업 자료·매개변수 |

GPT-3의 적용 판단은 명칭이나 단일 지표보다 위 단계의 입력·출력 조건과 실제 업무·장치 환경에서 확인한 결과를 기준으로 수행.

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 문맥 내 학습을 실시간 가중치 갱신이나 검증된 사실 검색으로 오해할 위험 | 근거가 필요한 업무에는 출처 확인과 출력 검증 절차를 붙임 |

## Ⅴ. 제언

우선 근거가 필요한 응답과 창작 초안을 구분해 출력 검증 기준을 정함.
