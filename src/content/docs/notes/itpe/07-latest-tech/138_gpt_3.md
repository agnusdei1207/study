## 핵심 용어
- 인-컨텍스트 러닝(In-Context Learning, ICL): 모델의 파라미터를 미분하여 가중치를 바꾸지 않고, 입력 프롬프트의 문맥(Context) 안에 작업 지시어와 몇 가지 예시를 제시하는 것만으로 새로운 작업을 유추하여 수행하는 창발적 능력
- 퓨샷 러닝(Few-Shot Learning): 모델에게 질문을 던지기 전, 입력과 출력의 쌍으로 구성된 소수(보통 2~5개)의 예시를 프롬프트에 제공하여 답변 형식과 작업 의도를 맞추는 기법
- 디코더 전용(Decoder-only) 구조: 양방향 문맥을 보는 인코더(BERT)와 달리, 오직 이전 단어들만을 참고하여 다음 단어를 하나씩 순차적으로 예측(Autoregressive)해 나가는 트랜스포머 아키텍처

## 핵심 통찰
- "언어 모델은 퓨샷 학습자이다(Language Models are Few-Shot Learners)": 브라운(Brown) 등의 2020년 기념비적 논문 제목처럼, 모델 규모가 1,750억 개에 도달하자 별도의 지도학습 파인튜닝 없이도 프롬프트만으로 대부분의 벤치마크를 정복하는 패러다임 전환이 일어남
- 파인튜닝 지옥 탈출: 태스크마다 수만 장의 라벨링 데이터와 모델 체크포인트를 관리하던 엔지니어링 병목을 없애고, 단일 거대 파운데이션 모델 하나로 모든 자연어 처리를 통합 처리할 수 있는 길을 염
- 미완의 거인(InstructGPT의 필요성): 순수 GPT-3는 인터넷 텍스트의 다음 단어를 확률적으로 채우는 단순 자동완성기에 불과했기 때문에, 거짓말을 천연덕스럽게 하거나 혐오 발언을 쏟아내는 문제가 있어 이후 RLHF를 적용한 InstructGPT와 ChatGPT로 진화하게 됨

## 이웃 토픽과 구분
- BERT vs GPT-3: BERT는 인코더 기반 3.4억 파라미터로 하류 작업별 파인튜닝 필수 / GPT-3는 디코더 기반 1,750억 파라미터로 파인튜닝 없이 프롬프트만으로 태스크 수행
