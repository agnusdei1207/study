## 지식 로드맵 내 현재 위치

지식 위치: AI 모델 운영 → 전 생애주기 관리·거버넌스 → **모델옵스(ModelOps)**

## 30초 인출

- 본질: **모델옵스(ModelOps)** 는 조직이 사용하는 모델의 등록·평가·승인·운영·변경을 전 생애주기 관점에서 관리하는 실무 접근
- 메커니즘: 모델·용도 등록 → 위험·품질 평가 → 승인·배포 → 운영 관찰 → 변경 재평가·폐기

<details>
<summary>핵심 용어</summary>

- **모델옵스(ModelOps)** : 조직 모델의 등록·통제·운영·변경을 생애주기 관점에서 관리하는 접근
- **기계학습 운영(Machine Learning Operations, MLOps)** : 기계학습 개발·배포·운영 과정을 자동화·관리하는 실무 접근
- **모델 레지스트리(Model Registry)** : 모델 버전·용도·소유자·평가와 승인 상태를 기록하는 저장소
- **모델 드리프트(Model Drift)** : 운영 환경 변화로 입력 특성이나 모델 성능이 달라지는 현상
- **챔피언-챌린저(Champion-Challenger)** : 기존 모델과 후보 모델을 비교 평가해 전환 여부를 판단하는 방식
</details>

```text
승인·배포
          ↓
운영 성능·변화 관찰
          ↓
재평가·개선 또는 폐기
```

| 구분 | MLOps | ModelOps |
|---|---|---|
| 중심 | ML 개발·학습·배포 과정 | 조직 모델의 목록·통제·운영 관리 |
| 관계 | 자동화된 모델 수명주기 실행 기반 | 그 실행을 조직 책임·위험·감사와 연결하는 관점 |

### Ⅲ. 관리 기록과 통제

| 관리 항목 | 기록·통제 |
|---|---|
| 모델 등록 | 버전·용도·소유자·의존성 |
| 검증·승인 | 평가 근거·위험 검토·승인 이력 |
| 운영 모니터링 | 품질·비용·입력 변화·사고 기록 |
| 변경·폐기 | 재평가 결과·배포 전환·종료 사유 |

### Ⅳ. 적용 시 고려

| 상황 | 운영 판단 |
|---|---|
| 영향이 큰 의사결정에 모델을 사용 | 독립 검토·승인·사람 감독 수준 강화 |
| 여러 개발 조직이 모델을 공급 | 공통 식별자·기록 형식·변경 이력 연계 |
| 운영 결과가 변하거나 업무 맥락이 변함 | 원인 조사 후 재평가·재학습·사용 제한 검토 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모든 모델에 동일한 승인 절차를 적용하면 위험도와 업무 영향 차이를 반영하기 어려움 | 모델의 의사결정 영향·자율 실행·데이터 민감도에 따라 통제 수준을 분류하고, 영향이 큰 모델부터 독립 검토와 배포 승인 근거를 강화 |
