## 답안 골격
### 1교시 예상문제 (10점)
4차 산업혁명의 개념과 CPS 기반 산업 시스템의 핵심 구조를 설명하시오.

### 1교시 10점 답안
- **정의:** 센서·네트워크·데이터 분석과 자동화를 연결해 물리적 운영과 디지털 모델을 통합하는 산업 변화의 관점.
- **구조:** 설비·센서 → 통신·데이터 플랫폼 → 분석·예측 → 사람 또는 제어기의 의사결정 → 현장 피드백.
- **특징:** 연결성·데이터 기반 지능화·분야 간 융합. 기술 채택과 경제·고용 효과는 산업별 검증 필요.

### 2~4교시 예상문제 (25점)
제조 현장의 4차 산업혁명 도입을 CPS 관점에서 설계하고 OT 안전·보안 및 성과 평가 방안을 제시하시오.

### 2~4교시 25점 답안
1. **과제 정의:** 설비 가동·품질·에너지 중 우선 문제와 기준선 지표를 정하고 데이터 수집 가능성 평가.
2. **구성:** 센서와 현장 제어 → 엣지·산업망 → 데이터 통합·디지털 모델 → 예지·최적화 → 작업자 승인·제어 피드백.
3. **통제:** OT 망 분리·접근권한·패치 절차, 안전 제어와 AI 권고의 분리, 장애 시 수동 운용·복구 시험.
4. **평가:** 생산성·불량률·정지 시간·에너지와 투자 비용을 현장 실험으로 비교하고 노동 전환 교육 병행.

```text
[4차 산업혁명] ◀━━ 머리: Ⅶ 내 의견 (사이버-물리 시스템(CPS)과 초지능 인공지능 기반의 산업 전반 자율 최적화 및 신성장 동력 확보 전략)
 ┃
 ┣━ Ⅰ 개요 ───── 1차(증기기관), 2차(전기/대량생산), 3차(컴퓨터/인터넷 정보화)를 거쳐, 물리적 세계와 디지털 공간이 실시간 융합되는 산업 대변혁
 ┣━ Ⅱ 3대특징 ── 초연결성(Hyper-Connectivity: IoT, 5G) · 초지능성(Hyper-Intelligence: AI, Big Data) · 초융합성(Hyper-Convergence: CPS, 메타버스)
 ┣━ Ⅲ 구조 ───── 물리 공간(Physical: 센서, 설비, 모빌리티) + 디지털 가상 공간(Cyber: 클라우드, 디지털 트윈, AI) + 상호작용(센싱 ↔ 자율제어 루프)
 ┣━ Ⅳ 핵심기술 ─ ICBMA(IoT, Cloud, Big Data, Mobile/5G, AI) + 로보틱스 + 블록체인 + 디지털 트윈 + 3D 프린팅
 ┣━ Ⅴ 발전계보 ─ 1차(증기/기계화) → 2차(전기/대량생산) → 3차(IT/자동화) → 4차(CPS/지능화·자율화)
 ┗━ Ⅵ 실무 ───── 일자리 양극화(자동화 대체) / 사이버-물리 융합 공격(OT 보안 취약점) / 디지털 격차에 따른 국가·기업 간 양극화
```

## 한 줄 본질
- 4차 산업혁명은 디지털·물리 기술의 결합이 산업과 사회에 미치는 변화를 설명하는 개념으로, 적용 수준과 자동화 범위는 산업별로 다름

## 핵심 용어
- 사이버-물리 시스템(CPS: Cyber-Physical System): 물리적 현실 세계의 다양한 기계, 설비, 인프라를 네트워크로 가상 공간에 실시간 연결하고, 컴퓨팅 연산과 AI를 통해 물리 세계를 지능적으로 제어하는 시스템
- 초연결(Hyper-Connectivity): 사람과 사람의 연결을 넘어, 5G와 사물인터넷(IoT)을 통해 모든 사물(Things)과 공간, 데이터가 실시간으로 소통하는 상태
- CPS 5C 아키텍처: 공장 지능화를 위한 5단계 구조로, Connection(센싱) → Conversion(데이터정보화) → Cyber(디지털트윈) → Cognition(지능인지) → Configuration(자율제어피드백)

## 핵심 통찰
- 기존 자동화와 데이터 기반 최적화의 결합이 중요하나 4차 산업혁명의 모든 시스템이 완전 자율 제어를 수행하는 것은 아님
- 데이터가 자본이 되는 플랫폼 경제: 물리적 공장 설비의 감가상각보다, 장비에서 뿜어져 나오는 데이터를 흡수하여 예측 모델을 만드는 소프트웨어 플랫폼 기업이 밸류체인을 지배
- IT(정보기술)와 OT(운영기술)의 융합 보안: 가상 공간의 랜섬웨어가 이제는 제철소 고로를 멈추고 전력망을 다운시키는 물리적 파괴로 이어지므로, 사이버-물리 통합 제로트러스트 보안이 국가 안보 과제로 부상

## 이웃 토픽과 구분
- 3차 산업혁명 vs 4차 산업혁명: 디지털 정보화·자동화의 확산과 CPS·IoT·AI를 이용한 물리·디지털 운영의 연결 강화라는 개념적 구분. 모든 현장의 완전 자율화가 필수 요건은 아님

## 문제·원인·대책
- 적용 상황: 국가 핵심 제조 산업단지 4차 산업혁명 스마트 팩토리 고도화
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 원격 분석 지연이 제어 주기를 넘김 | 중앙 처리와 현장 제어의 시간 요구 불일치 | 안전 제어는 현장에 유지하고 분석 기능만 엣지·클라우드에 배치 | 제어 주기와 장애 시 안전 상태 시험 |
| IT와 제어망 연결로 공격 경로 증가 | 구역·경계 및 원격 접근 통제 부족 | IEC 62443을 참고해 구역·통로·계정 통제 설계 | 침입 경로와 복구 절차 검증 |
| 자동화 도입 뒤 직무 변화와 갈등 | 작업 역할·교육 계획 부족 | 현장 참여와 역할별 재교육 계획 수립 | 품질·안전·고용 지표를 도입 전후 비교 |

- 제조 현장의 센서·제어·분석을 연결하되 사람의 감독과 안전 정지를 포함한 단계적 자동화 적용. 도입 효과는 생산성뿐 아니라 결함·안전·운영비를 함께 측정
