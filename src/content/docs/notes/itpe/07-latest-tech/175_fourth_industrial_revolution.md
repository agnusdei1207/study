## 30초 인출

- 본질: 센서·네트워크·데이터 분석과 자동화를 연결해 물리적 운영과 디지털 모델을 통합하는 산업 변화의 관점. 물리 설비와 디지털 분석을 연결해 산업 운영을 개선.
- 메커니즘: 현장 센싱 → 데이터·모델 분석 → 작업자 또는 제어기 판단 → 피드백.
- 통찰: 한계: 설비 데이터만 모으면 물리 공정의 개선으로 이어지지 않는다 → 방안: 현장 목표와 데이터·모델·제어 책임을 묶어 작업 결과를 다시 측정한다.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 센서·네트워크·데이터 분석과 자동화를 연결해 물리적 운영과 디지털 모델을 통합하는 산업 변화의 관점. |
| 목적 | 물리 설비와 디지털 분석을 연결해 산업 운영을 개선 |

## Ⅱ. 물리 설비와 디지털 피드백

```text
설비·센서 → 통신·데이터 플랫폼
                    ↓ 상태 분석·예측
            작업자 판단 또는 제어기 조치
                    ↓ 물리 공정 변화
                 현장 재측정
```

1. **과제 정의:** 설비 가동·품질·에너지 중 우선 문제와 기준선 지표를 정하고 데이터 수집 가능성 평가.
2. **구성:** 센서와 현장 제어 → 엣지·산업망 → 데이터 통합·디지털 모델 → 예지·최적화 → 작업자 승인·제어 피드백.
3. **통제:** OT 망 분리·접근권한·패치 절차, 안전 제어와 AI 권고의 분리, 장애 시 수동 운용·복구 시험.
4. **평가:** 생산성·불량률·정지 시간·에너지와 투자 비용을 현장 실험으로 비교하고 노동 전환 교육 병행.

## Ⅲ. 정보화와 물리·디지털 연결

| 구분 | 중심 변화 | 운영 확인 |
|---|---|---|
| 정보화·자동화 | 개별 공정의 디지털 처리 | 업무 처리 성능 |
| 4차 산업혁명 관점 | 센싱·분석·제어의 연결 | 물리 공정의 실제 개선 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 원격 분석 지연이 제어 주기를 넘김 — 중앙 처리와 현장 제어의 시간 요구 불일치 | 안전 제어는 현장에 유지하고 분석 기능만 엣지·클라우드에 배치 |
| IT와 제어망 연결로 공격 경로 증가 — 구역·경계 및 원격 접근 통제 부족 | IEC 62443을 참고해 구역·통로·계정 통제 설계 |
| 자동화 도입 뒤 직무 변화와 갈등 — 작업 역할·교육 계획 부족 | 현장 참여와 역할별 재교육 계획 수립 |

## Ⅴ. 제언

- 제조 현장의 센서·제어·분석을 연결하되 사람의 감독과 안전 정지를 포함한 단계적 자동화 적용. 도입 효과는 생산성뿐 아니라 결함·안전·운영비를 함께 측정
