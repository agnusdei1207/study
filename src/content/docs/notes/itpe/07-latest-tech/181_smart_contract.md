## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 스마트 계약(Smart Contract)

## 30초 인출

- 본질: 온체인 트랜잭션 호출에 따라 미리 정한 코드를 실행하고 원장 상태를 변경하는 프로그램. 합의된 원장에 조건부 실행 결과를 기록하고 참여자 간 상태를 공유.
- 메커니즘: 코드 배포 → 서명된 호출 → 실행 → 합의된 상태 반영.
- 통찰: 한계: 합의된 코드 실행도 외부 데이터의 진실성과 코드 취약점을 해결하지 못한다 → 방안: 오라클 출처와 계약 불변식을 시험하고 관리자 권한·비상 중지를 분리한다.

<details><summary>핵심 용어</summary>

- **스마트 계약:** 블록체인에서 호출에 따라 코드와 상태를 실행·갱신하는 프로그램
- **오라클:** 온체인 코드가 외부 데이터를 사용할 때 연결하는 데이터 공급 경로

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 온체인 트랜잭션 호출에 따라 미리 정한 코드를 실행하고 원장 상태를 변경하는 프로그램. |
| 목적 | 합의된 원장에 조건부 실행 결과를 기록하고 참여자 간 상태를 공유 |

## Ⅱ. 호출에서 원장 상태 변경까지

```text
서명된 호출 → 스마트 계약 코드 실행
              ↑ 외부 사실은 오라클 입력
              ↓ 조건·가스·불변식 검사
          합의된 원장 상태 갱신
```

1. **업무 구분:** 법률상 보험 계약과 온체인 지급 로직의 관계를 문서화하고 예외·분쟁 처리 절차 정의.
2. **구조:** 가입·지급 조건을 스마트 계약에 표현, 외부 사고 데이터는 출처가 검증된 오라클로 입력, 지급은 트랜잭션으로 기록.
3. **취약점:** 외부 호출 전 상태 갱신 누락의 재진입, 오류·조작된 오라클, 프록시 관리자 키 탈취와 로직 교체의 신뢰 위험.
4. **검증:** 불변식·단위·퍼즈·감사 시험, 다중 자료원 확인, 관리자 권한 분리·시간 지연·비상 중지와 모니터링.

## Ⅲ. 스크립트와 스마트 계약의 실행 범위

| 구분 | 비트코인 스크립트 | 범용 스마트 계약 |
|---|---|---|
| 주된 역할 | 거래 지출 조건 검증 | 호출에 따른 상태 갱신 로직 |
| 운영 위험 | 조건식 검증 | 외부 입력·코드 취약점·관리 권한 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 배포 코드 취약점의 수정·이주 난항 — 배포 코드 자체는 직접 변경하기 어려움 | 프록시 업그레이드 또는 새 계약 이주와 관리자 권한·승인 절차 설계 |
| 단일 외부 API 오류로 허위 결항 정보를 입력 — 소수 오라클·출처 의존 | 다중 출처 대조, 이상치 탐지, 분쟁·중지 절차 마련 |
| 외부 호출 전 잔액 갱신 누락으로 재진입 — 상태 변경 순서 결함 | Checks-Effects-Interactions, 재진입 방지, 외부 호출·상속 경로 보안 검토 |

## Ⅴ. 제언

- [위험 기반 검증] 핵심 불변식의 형식 검증, 정적 분석, 독립 감사, 퍼즈 시험, 배포 후 모니터링 및 비상 중지 절차의 결합. 형식 검증의 보증 범위는 명세와 환경 가정으로 한정
