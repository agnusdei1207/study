- **인공협의지능(Artificial Narrow Intelligence, ANI)** : 특정 과제나 제한된 목적에 맞춰 설계·평가되는 AI

- **평가 범위(Evaluation Scope)** : 시험에 포함한 과제·환경·전이 조건의 명시적 경계

### Ⅰ. 인공일반지능의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **인공일반지능(Artificial General Intelligence, AGI)** 은 여러 인지 과제와 상황에 걸쳐 능력을 일반화하는 AI 개념 |
| 목적 | 특정 과제에 한정되지 않는 능력 범위와 전이 가능성의 연구·평가 |

### Ⅱ. ANI와 AGI 개념의 구분

```text
과제 범위의 폭
  좁음 ─────────────── 넓음
   │                      │
특정 과제 성능       여러 과제·새 상황
          수행 수준도 함께 평가
```

```text
ANI  특정 과제·제한된 목적에 맞춘 능력
 │
 └── 구분 축: 수행 범위와 새로운 과제에 대한 일반화
       AGI  여러 과제·상황에 걸친 일반성을 지향하는 개념
```

| 구분 | ANI | AGI 개념 |
|---|---|---|
| 과제 범위 | 특정 기능·도메인 중심 | 여러 인지 과제와 환경을 포괄하는 방향 |
| 평가 | 정의된 과업의 기준 적용 | 범위·수준·전이 조건을 함께 정의할 필요 |
| 상태 | 실제 시스템에서 널리 쓰이는 과제별 AI | 합의된 정의·단일 판정 기준 없음 |

### Ⅲ. 능력 평가

DeepMind의 Levels of AGI는 수행 수준과 과제 범위의 폭을 별도 축으로 다루는 연구 프레임워크 제안. 합의된 산업 표준이나 인증 절차로 해석하지 않음.

```text
평가 설계
   │
   ├─ 과제·환경 범위 ── 다양성, 새 상황, 도메인 전이
   ├─ 수행 수준     ── 정확성, 일관성, 신뢰성
   └─ 실패 영향     ── 오류 조건, 감독 필요성, 회복 가능성
```

| 평가 축 | 확인 항목 |
|---|---|
| 범위 | 과제 종류·도메인·환경을 명시했는가 |
| 깊이 | 과제별 성능과 반복 시 일관성을 측정했는가 |
| 일반화 | 학습에 없던 조건에서 전이 성능을 확인했는가 |
| 위험 | 오류 영향·감독 조건·한계를 함께 보고했는가 |

### Ⅳ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| AGI라는 포괄적 명칭이 검증된 능력 범위보다 앞설 수 있음 | 조달·운영 평가에서는 과제별 시험 결과, 전이 조건, 감독 필요성과 실패 한계를 명시하고 해당 근거로 적용 범위를 결정 |
