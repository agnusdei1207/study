 ┣━ Ⅰ 개요 ───── 주피터 노트북 내 수동 모델링과 운영 배포 간 장벽(기술 부채) → CI/CD/CT 기반 ML 라이프사이클 완전 자동화
 ┣━ Ⅱ 특징 ───── 데이터·코드·모델 버전 관리 · 지속적 학습(CT) · 모델 레지스트리 · 데이터/개념 드리프트 감지 · 피처 스토어

 ┗━ Ⅵ 실무 ───── 데이터 드리프트에 따른 운영 성능 저하 / 재현 불가능한 파이프라인 / 실험 관리 파편화에 따른 추적 실패

## 한 줄 본질
- 모델 코드가 전체 머신러닝 시스템의 극히 일부분에 불과하며 주변 인프라와 데이터 파이프라인의 숨겨진 기술 부채로 인해 운영 배포가 좌절되는 현상 → 데이터, 코드, 모델 가중치를 유기적으로 엮어 지속적 훈련(CT)과 배포(CD)를 자동화하는 통합 엔지니어링 프레임워크 / 데이터셋 변경 시 재현성 상실 및 드리프트 모니터링 복잡성 수반

## 핵심 용어
- 지속적 훈련(Continuous Training, CT): 기존 DevOps의 CI/CD에 더해, 서비스 운영 중 새로운 실시간 데이터가 유입되거나 모델 성능이 기준치 이하로 떨어졌을 때 모델을 자동으로 재학습시키고 검증하는 MLOps 고유의 특성
- 피처 스토어(Feature Store): 머신러닝 학습(오프라인)과 실시간 추론(온라인)에 사용되는 특징 데이터를 중앙에서 단일 정의·저장·서빙하여, 훈련-서빙 간 왜곡(Training-Serving Skew)을 방지하는 전용 저장소
- 데이터 드리프트(Data Drift): 시간 경과나 외부 환경 변화에 따라 모델에 입력되는 운영 데이터의 통계적 분포($P(X)$)가 학습 당시의 분포와 달라져 모델 예측 정확도가 붕괴하는 현상

## 핵심 통찰
- "머신러닝 코드의 비중은 전체 시스템의 5% 미만"(Sculley et al., NIPS 2015): 데이터 검증, 특징 추출, 리소스 관리, 서빙 인프라, 모니터링 등 나머지 95%의 배관 공사를 자동화하는 것이 MLOps의 존재 이유
- MLOps 성숙도의 분수령은 "구글 Level 1(파이프라인 자동화)"과 "Level 2(CI/CD/CT 파이프라인 완전 자동화)": 모델 하나를 수동으로 말아 올리는 것은 과학 연구이고, 파이프라인 자체를 자동으로 빌드하고 배포하는 것이 엔지니어링
- 모델 성능 모니터링은 정답(Ground Truth)이 늦게 도착하는 경우가 대부분(예: 대출 연체 여부는 수개월 뒤 판명) → 실제 레이블 없이 입력 피처의 드리프트(PSI, KS-Test)를 선행 감지하는 조기 경보 체계가 핵심

## 이웃 토픽과 구분
- MLOps vs DevOps: DevOps는 결정론적(Deterministic) 소스 코드와 바이너리의 변경을 다룸 / MLOps는 비결정론적(Probabilistic) 데이터의 지속적 유입과 그에 따른 모델 행동 변화(CT)를 다룸

## 문제·원인·대책
- 적용 상황: 이커머스 추천 모델이 배포 후 첫 달은 우수했으나 3개월 뒤 매출 기여도 급락
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 계절 변화로 인한 소비자 구매 패턴 변화로 추천 적중률 30% 하락 | 공변량 변화(Covariate Shift / Data Drift) 발생 및 수동 재학습 지연 | 인구밀도 변화 지수(PSI > 0.25) 초과 시 자동 재학습 파이프라인(CT) 트리거 연동 | 데이터 변화 실시간 추종 및 적중률 즉각 회복 |
| 개발 환경 주피터 노트북에서는 95% 성능이 나오던 모델이 운영 배포 시 60%로 급락 | 학습 시 미래 데이터를 참조한 데이터 누수(Data Leakage) 및 서빙 피처 불일치 | Feast 기반 피처 스토어 도입 및 시점 기준(Point-in-time) 정확한 피처 조인 강제 | Training-Serving Skew 제로화 달성 |
| 과거 배포했던 우수 모델 가중치가 어떤 데이터셋과 코드로 생성되었는지 추적 불가 | 데이터 버전 관리 부재 및 연구원 로컬 파일 저장 관행 | DVC(Data Version Control)와 MLflow 모델 레지스트리를 연동한 계보(Lineage) 추적 | 모델 버전별 데이터-코드-하이퍼파라미터 100% 재현성 보장 |
