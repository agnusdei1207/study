## 답안 골격
### 1교시 예상문제 (10점)
디지털 사이니지의 구성과 인쇄 옥외광고 대비 운영상 특징을 설명하시오.

### 1교시 10점 답안
- **정의:** 네트워크에 연결된 디스플레이를 통해 장소·시간에 맞는 안내 또는 광고를 편성·표시하는 매체.
- **구성:** 콘텐츠 관리 시스템(CMS) → 편성·배포망 → 미디어 플레이어·디스플레이 → 재생 상태 수집.
- **차이:** 인쇄 매체 대비 원격 갱신·시간대별 편성이 용이하나 전원·통신·밝기·장애 대응이 추가 요구.

### 2~4교시 예상문제 (25점)
공공장소 디지털 사이니지의 아키텍처와 개인정보·접근성·장애 대응 방안을 설명하시오.

### 2~4교시 25점 답안
1. **설계:** 중앙 CMS에서 검수·편성한 콘텐츠를 서명·배포하고 단말은 캐시와 재생 일정에 따라 표시.
2. **운영:** 단말 상태·콘텐츠 버전·재생 결과 모니터링, 통신 단절 시 승인된 안내의 로컬 재생과 원격 복구.
3. **위험:** 카메라 기반 시청자 분석의 개인정보, 빛 공해·시각 접근성, 악성 콘텐츠 삽입과 화면 고장.
4. **통제:** 필요한 범위의 비식별 통계, 촬영 고지·보존 최소화, 밝기·자막 기준, 콘텐츠 승인·롤백과 현장 점검.

```text
[디지털 사이니지] ◀━━ 머리: Ⅶ 내 의견 (비전 AI 기반 시청자 분석과 프로그래매틱 DOOH 연동을 통한 양방향 지능형 옥외 미디어 플랫폼 전환)
 ┃
 ┣━ Ⅰ 개요 ───── 전통적 정적 인쇄 옥외 광고판의 한계를 극복하고, 디스플레이와 네트워크를 결합하여 실시간 동적 정보 및 광고를 전달하는 디지털 미디어
 ┣━ Ⅱ 특징 ───── 원격 중앙 제어 · 동적 멀티미디어(영상/인터랙션) · 실시간 편성 스케줄링 · 타깃 맞춤형 표출 · 효과 측정성(Metrics)
 ┣━ Ⅲ 구조 ───── 하드웨어(디스플레이, 미디어 플레이어) + 네트워크(5G, 유무선 IP) + 소프트웨어/플랫폼(CMS: 콘텐츠관리시스템) + 센서/AI(카메라, 안면인식)
 ┣━ Ⅳ 진화단계 ─ 1세대 독립형(USB 수동재생) → 2세대 네트워크형(원격 CMS 편성) → 3세대 인터랙티브형(터치/센서반응) → 4세대 지능형(AI 기반 pDOOH, 맥락 광고)
 ┣━ Ⅴ 비교 ───── 전통 옥외광고(OOH) vs 디지털 사이니지(DOOH) (인쇄물교체비용과다/단방향고정/효과측정불가 vs 원격즉시편성/동영상·양방향/AI시청자수정량측정)
 ┗━ Ⅵ 실무 ───── 유동인구 안면 촬영에 따른 개인정보보호법 위반 논란 / 야간 과도한 눈부심 및 빛 공해 / 윈도우 블루스크린(BSOD) 노출 사고
```
- 필수 키워드: 디지털 사이니지 · DOOH(Digital Out-Of-Home) · 프로그래매틱 DOOH(pDOOH) · CMS(콘텐츠관리시스템) · 미디어 플레이어 · 시청자 분석(Audience Measurement) · 안면 인식
- 출제 이력: 제98·107회 공식 문제지 원문 미확보. 아래 문항은 예상문제임.

## 한 줄 본질
- 디지털 사이니지는 공공·상업 공간의 디스플레이에 콘텐츠를 일정과 상황에 따라 표시하는 시스템. 카메라 기반 사람 분석은 선택 기능이며 별도 권한·개인정보 검토 필요

## 핵심 그림
```text
[지능형 디지털 사이니지(DOOH) 시스템 구성 및 실시간 광고 송출 흐름]

   ┌─────────────────────────────────────────────────────────────┐
   │ [중앙 클라우드 CMS & pDOOH 광고 플랫폼]                    │
   │  - 콘텐츠 편성 및 원격 스케줄링 배포                        │
   │  - DSP/SSP 연동 프로그래매틱 실시간 광고 입찰 (RTB)         │
   └──────────────────────────────┬──────────────────────────────┘
                                  │ (5G / 보안 VPN 통신)
                                  ▼
   ┌─────────────────────────────────────────────────────────────┐
   │ [현장 디지털 사이니지 단말 (옥외 전광판, 지하철 스크린)]    │
   │                                                             │
   │  [미디어 플레이어 (Edge SoC)]                               │
   │  - 하드웨어 비디오 디코딩, 와치독(Watchdog) 자동 복구      │

   │                                                             │
   │  [AI 비전 센서 모듈 (Edge Vision AI)]                      │
   │  - 보행자 시선 체류 시간, 연령/성별 비식별 실시간 추정     │
```

## 핵심 용어
- DOOH(Digital Out-Of-Home): 지하철, 쇼핑몰, 공항, 빌딩 외벽 등 집 밖의 공공장소에 설치된 네트워크 기반 디지털 옥외 디스플레이 미디어
- pDOOH(Programmatic DOOH): 타깃 유동인구 특성, 날씨, 시간대 등 실시간 조건에 따라 광고 인벤토리를 애드테크 플랫폼을 통해 자동화된 실시간 입찰(RTB) 방식으로 구매·송출하는 기술
- 와치독 타이머(Watchdog Timer): 사이니지 미디어 플레이어의 OS가 멈추거나 블루스크린(BSOD)이 뜰 경우, 시스템 상태를 주기적으로 감시하여 자동으로 단말을 강제 재부팅시키는 하드웨어 안전장치

## 핵심 통찰
- "감(Feel)으로 집행하던 옥외 광고의 데이터화": 과거에는 강남역 간판 광고를 몇 명이 보았는지 알 수 없었으나, 엣지 AI 카메라를 통해 노출 수, 시선 고정 시간(Dwell Time), 연령 분포를 분 단위로 정량 측정
- 실시간 맥락 기반 트리거링(Contextual Trigger): 미세먼지가 심한 날에는 공기청정기 광고를, 비가 오면 배달 앱 광고를, 폭염에는 시원한 음료 광고를 CMS가 API와 연동하여 자동으로 즉시 교체 편성
- 얼굴 영상을 저장하지 않더라도 개인을 식별할 수 있는 추론값이나 추적 정보가 생성되는지 검토 필요. 원본 삭제만으로 적법성이 자동 확보되지는 않음

## 이웃 토픽과 구분
- 키오스크(Kiosk) vs 디지털 사이니지: 키오스크는 음식 주문이나 티켓 발권 등 사용자가 직접 터치하여 거래를 완결하는 '개인 목적성 무인 단말기' / 디지털 사이니지는 다수의 대중을 상대로 정보와 광고를 브로드캐스팅하는 '공공 디스플레이 미디어'

## 문제·원인·대책
- 적용 상황: 대도시 지하철 500개 역사 디지털 사이니지 광고 네트워크 운영
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 화면 장애가 오래 방치 | 단말 상태 관측과 복구 경로 부족 | 상태 점검·알림, 와치독과 현장 복구 절차 | 장애 탐지·복구 시간 측정 |
| 이용객 영상 처리에 따른 사생활 우려 | 촬영 목적·보존·파생 정보의 통제 부족 | 영상 수집 필요성을 먼저 평가하고 최소 수집·권한·보존 정책 적용 | 개인정보 흐름과 이용자 고지 점검 |
| 다수 단말에 대용량 콘텐츠 동시 배포 | 배포 시간·캐시 정책 부재 | 분할 배포·캐시·예약 다운로드 설계 | 피크 대역폭과 콘텐츠 최신성 측정 |

## 이렇게 출제된다
- 예상문제: 디지털 사이니지의 구성 요소와 원격 콘텐츠 관리·운영 위험을 설명하시오. 제107회 출제 여부와 문항은 원문 미대조.

## 내 의견
- 생성형 콘텐츠를 현장에 적용하려면 송출 전 권리·사실·안전 검토와 문제 발생 시 이전 콘텐츠로 돌아가는 절차 필요. 개인 분석보다 시간·날씨 같은 비개인 맥락부터 적합성 평가
