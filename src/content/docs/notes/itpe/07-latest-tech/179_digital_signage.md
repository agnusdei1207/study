## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 디지털 사이니지(Digital Signage)

## 30초 인출

- 본질: 네트워크에 연결된 디스플레이를 통해 장소·시간에 맞는 안내 또는 광고를 편성·표시하는 매체. 장소·시간에 맞춘 정보와 광고를 원격 편성·표시.
- 메커니즘: 콘텐츠 제작·승인 → 편성·배포 → 단말 재생 → 상태 감시.
- 통찰: 한계: 콘텐츠를 원격 배포해도 현장 단말이 재생하지 않으면 안내 효과가 없다 → 방안: 승인·편성·단말 수신·실제 재생 로그를 연결해 누락을 감시한다.

<details><summary>핵심 용어</summary>

- **디지털 사이니지:** 디지털 화면에 정보·광고를 편성해 표시하는 매체
- **CMS:** 콘텐츠 제작·승인·배포 일정을 관리하는 시스템

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 네트워크에 연결된 디스플레이를 통해 장소·시간에 맞는 안내 또는 광고를 편성·표시하는 매체. |
| 목적 | 장소·시간에 맞춘 정보와 광고를 원격 편성·표시 |

## Ⅱ. 편성에서 현장 재생까지

```text
콘텐츠 제작·승인 → CMS 편성
                         ↓ 네트워크 배포
                    플레이어·디스플레이
                         ↓ 재생·오류 로그
                       중앙 감시·재배포
```

1. **설계:** 중앙 CMS에서 검수·편성한 콘텐츠를 서명·배포하고 단말은 캐시와 재생 일정에 따라 표시.
2. **운영:** 단말 상태·콘텐츠 버전·재생 결과 모니터링, 통신 단절 시 승인된 안내의 로컬 재생과 원격 복구.
3. **위험:** 카메라 기반 시청자 분석의 개인정보, 빛 공해·시각 접근성, 악성 콘텐츠 삽입과 화면 고장.
4. **통제:** 필요한 범위의 비식별 통계, 촬영 고지·보존 최소화, 밝기·자막 기준, 콘텐츠 승인·롤백과 현장 점검.

## Ⅲ. 키오스크와 디지털 사이니지

| 구분 | 키오스크 | 디지털 사이니지 |
|---|---|---|
| 중심 동작 | 개인의 입력·거래 완결 | 편성 콘텐츠의 다수 대상 표시 |
| 운영 지표 | 거래 성공·오류 | 실제 재생·표시 상태 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 화면 장애가 오래 방치 — 단말 상태 관측과 복구 경로 부족 | 상태 점검·알림, 와치독과 현장 복구 절차 |
| 이용객 영상 처리에 따른 사생활 우려 — 촬영 목적·보존·파생 정보의 통제 부족 | 영상 수집 필요성을 먼저 평가하고 최소 수집·권한·보존 정책 적용 |
| 다수 단말에 대용량 콘텐츠 동시 배포 — 배포 시간·캐시 정책 부재 | 분할 배포·캐시·예약 다운로드 설계 |

## Ⅴ. 제언

- 생성형 콘텐츠를 현장에 적용하려면 송출 전 권리·사실·안전 검토와 문제 발생 시 이전 콘텐츠로 돌아가는 절차 필요. 개인 분석보다 시간·날씨 같은 비개인 맥락부터 적합성 평가
