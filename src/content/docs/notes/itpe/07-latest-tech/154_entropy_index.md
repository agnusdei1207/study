## 30초 인출

- 본질: **엔트로피 지수** (Entropy Index)는 정보 이론에서 확률 변수의 불확실성이나 무질서도를 수치화한 척도로서, 머신러닝 의사결정나무(ID3, C4.5)에서 최적의 분할 속성을 선택하는 정보 획득량(Information Gain)의 기초 지표
- 메커니즘: 클래스별 확률 분포 $p_i$에 대해 $H(S) = -\sum p_i \log_2 p_i$ 계산 → 부모 노드와 자식 노드의 엔트로피 차이(정보 획득량) 산출 → 정보 이득이 최대화되는 분기점 선정
- 통찰: 고객 ID나 주민번호처럼 고유값이 많은 속성일수록 엔트로피가 0으로 급감하여 과적합되는 다치 속성 편향이 발생하므로 분할 정보량으로 정규화한 정보 이득률(Gain Ratio) 적용 필요

<details><summary>핵심 용어</summary>

- **섀넌 엔트로피 (Shannon Entropy)** : 어떤 시스템 내 정보의 평균 불확실성(Uncertainty)을 나타내는 정보 이론의 핵심 척도 ($H(S)$).
- **정보 획득량 (Information Gain)** : 특정 속성으로 데이터를 분할했을 때 감소하는 엔트로피의 양 ($IG = H_{parent} - H_{children}$).
- **정보 이득률 (Gain Ratio)** : C4.5 알고리즘에서 다치 속성의 과적합을 방지하기 위해 분할 자체의 엔트로피(Split Info)로 나눈 정규화 지표.
- **불순도 (Impurity)** : 한 데이터 집합 내에 서로 다른 클래스의 샘플들이 얼마나 무질서하게 혼합되어 있는지를 나타내는 정도.
- **교차 엔트로피 (Cross-Entropy)** : 실제 정답 확률 분포와 모델 예측 확률 분포 간의 차이를 측정하는 신경망의 대표적 손실 함수.

</details>

## 2~4교시 25점 답안

## Ⅰ. 엔트로피 지수의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 클로드 섀넌의 정보 이론에 기반하여 데이터 집합 내 클래스 확률 분포의 불확실성 및 정보량 기댓값을 로그 함수($-\sum p_i \log_2 p_i$)로 수치화한 불순도 척도 |
| 목적 | 데이터 분할 시 무질서도를 최소화하고 순도(Purity)를 극대화하는 최적의 분기 피처를 탐색하여 분류 모델의 예측 정확도 향상 |

## Ⅱ. 엔트로피 지수의 수학적 원리 및 핵심 특징

| 분석 관점 | 수학적 수식 및 정의 | 특징 및 엔지니어링 의미 |
|---|---|---|
| **엔트로피 수식** | $H(S) = -\sum_{i=1}^{c} p_i \log_2 p_i$ | 이진 분류 기준 완전 균등($p=0.5$) 시 최댓값 1, 완전 동질($p=1$) 시 최솟값 0 |
| **정보 획득량 (IG)** | $IG(S, A) = H(S) - \sum_{v \in Values(A)} \frac{\|S_v\|}{\|S\|} H(S_v)$ | 속성 A로 분할한 후 감소된 엔트로피의 크기 (분할 효율성 지표) |
| **분할 정보량 (SplitInfo)** | $SplitInfo_A(S) = -\sum_{v} \frac{\|S_v\|}{\|S\|} \log_2 \frac{\|S_v\|}{\|S\|}$ | 속성 A가 데이터를 얼마나 많은 조각으로 잘게 쪼개는지를 나타내는 엔트로피 |
| **정보 이득률 (GR)** | $GainRatio(S, A) = \frac{IG(S, A)}{SplitInfo_A(S)}$ | 잘게 쪼개는 속성에 페널티를 부여하여 다치 속성 과적합 원천 차단 |

## Ⅲ. 의사결정나무의 정보 획득량 계산 및 분할 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 엔트로피 기반 의사결정나무(ID3 / C4.5) 분할 및 트리 성장 파이프라인 ]│
└────────────────────────────────────────────────────────────────────────┘

  [ 부모 노드 데이터 집합 S (총 N개: 양성 $p_+$, 음성 $p_-$) ]
   - 부모 엔트로피 계산: $H(S) = - (p_+ \log_2 p_+ + p_- \log_2 p_-)$
                     │
                     ▼
  [ 후보 속성군 ($A_1, A_2, \dots, A_k$)별 가상 분할 시뮬레이션 ]
   ├── 후보 속성 $A_1$ 분할 ──> 자식 노드 $S_{11}, S_{12}$ 생성
   │    └── 가중치 적용 잔여 엔트로피 $E(S, A_1) = \sum \frac{|S_{1v}|}{|S|} H(S_{1v})$
   │    └── 정보 획득량 도출: $IG(S, A_1) = H(S) - E(S, A_1)$
   │
   └── 후보 속성 $A_2$ 분할 ──> 자식 노드 $S_{21}, S_{22}, S_{23}$ 생성
        └── 동일 방식으로 $IG(S, A_2)$ 계산
                     │
                     ▼
  [ 최적 분기 속성 선정: $\arg\max_A [IG(S, A)]$ 또는 $\arg\max_A [GR(S, A)]$ ]
                     │
                     ▼
  [ 노드 분기 실행 및 정지 조건(Stopping Criteria) 검증 ]
   ├── 모든 샘플이 동일 클래스인 경우 ──> Leaf 노드 확정
   ├── 잔여 엔트로피가 0이거나 깊이 한계 도달 ──> 분기 중단
   └── 그 외의 경우 ──> 하위 자식 노드에서 1단계 재귀 호출
```

| 계산 단계 | 실례 데이터 적용 ($N=14$, Yes=9, No=5) | 수식 및 계산 결과 |
|---|---|---|
| **부모 엔트로피** | 전체 데이터 14건 중 Yes 9건, No 5건 | $H(S) = -(9/14 \log_2 9/14 + 5/14 \log_2 5/14) \approx 0.940$ |
| **자식 엔트로피** | '바람' 속성 분할 (약함: 8건중 6Y/2N, 강함: 6건중 3Y/3N) | $H(약함) = 0.811$, $H(강함) = 1.000$ |
| **가중 평균 엔트로피** | 바람 속성에 따른 분할 후 잔여 불순도 합 | $E(S, 바람) = (8/14 \times 0.811) + (6/14 \times 1.0) \approx 0.892$ |
| **정보 획득량 산출** | 부모 불순도와 자식 불순도의 차이 | $IG(S, 바람) = 0.940 - 0.892 = 0.048$ |

## Ⅳ. 엔트로피 vs 지니 지수 vs 정보 이득률 비교

| 비교 항목 | 엔트로피 (Entropy) | 지니 지수 (Gini Index) | 정보 이득률 (Gain Ratio) |
|---|---|---|---|
| **기반 수식** | $-\sum p_i \log_2 p_i$ | $1 - \sum p_i^2$ | $IG(S, A) / SplitInfo(S, A)$ |
| **연산 복잡도** | 로그($\log_2$) 연산으로 상대적 높음 | 단순 사칙연산(제곱)으로 매우 빠름 | 엔트로피 연산 2회 수행으로 가장 높음 |
| **값의 범위 (이진)**| $0.0 \sim 1.0$ (최대 불확실성 1.0) | $0.0 \sim 0.5$ (최대 불확실성 0.5) | $0.0 \sim 1.0$ (정규화된 비율) |
| **대표 알고리즘** | ID3 | CART (Classification And Regression Tree) | C4.5, C5.0 |
| **다치 속성 편향** | 심각함 (고유값 많을수록 과선호) | 다항 분할 시 편향 존재 (CART는 이진분할로 완화) | 편향 완벽 억제 (분할 정보량 페널티) |
| **분할 방식** | 다자 분할(Multi-way Split) 가능 | 이진 분할(Binary Split) 기본 | 다자 분할 및 연속형 변수 처리 지원 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 고객 식별번호(ID)나 날짜 등 카디널리티가 극단적으로 높은 속성이 최적 분기로 오선택되는 다치 속성 편향 | C4.5의 정보 이득률(Gain Ratio)을 적용하거나 카테고리 피처에 대해 목표 인코딩(Target Encoding) 또는 빈도 인코딩 전처리 적용 |
| 대용량 데이터셋 학습 시 매 노드 분할마다 수천 개의 연속형 임계치에 대한 $\log_2$ 계산으로 심각한 속도 저하 | 지니 불순도 기반 이진 분할 알고리즘(CART/LightGBM)으로 전환하거나 히스토그램 기반 빈(Binning) 양자화 기법 결합 |
| 엔트로피 감소만을 추구하여 리프 노드의 샘플 수가 1~2개로 잘게 쪼개지며 과적합 발생 | 사전 가지치기(Pre-pruning: `max_depth`, `min_samples_leaf` 제한) 및 사후 비용 복잡도 가지치기(Cost-Complexity Pruning) 강제 |

## Ⅵ. 제언

현대 고속 정형 데이터 분석 파이프라인에서는 엔트로피 연산 병목을 극복하기 위해 히스토그램 기반 그래디언트 부스팅(LightGBM)과 비용-복잡도 가지치기 파이프라인 결합 체계 구축 필요.

```text
[ 대규모 학습 데이터 피처 세트 ]
              │
              ▼
[ 피처 히스토그램 양자화 (Binning: 256 Bins) ]
   - 연속형 변수를 256개 불연속 구간으로 압축 (연산 비용 $O(N \cdot K) \rightarrow O(Bin \cdot K)$)
              │
              ▼
[ Level-wise 대신 Leaf-wise 트리 탐색 (Gini / Entropy 분할) ]
   ├── Step 1: 손실 감소량이 최대인 단일 리프 노드만 우선 분기
   ├── Step 2: 정보 이득이 특정 임계치($\gamma$) 미만인 경우 분할 즉시 조기 중단
   └── Step 3: Out-of-Fold 검증 손실을 모니터링하여 조기 종료(Early Stopping)
              │
              ▼
[ 연산 속도 10배 향상 및 일반화 오차 극소화 달성 ]
```

| 구분 | 전통적 ID3 엔트로피 트리 | 제언: 히스토그램 기반 Leaf-wise 부스팅 |
|---|---|---|
| **분할 연산 속도** | 정렬된 전체 값 전수 로그 계산 (매우 느림) | 256개 빈 히스토그램 기반 고속 스캔 |
| **다치 속성 제어** | 분할 정보량(SplitInfo) 수기 조정 | 범주형 피처 전용 정규화 알고리즘 자동 내장 |
| **과적합 방어** | 사후 복잡한 가지치기 수동 적용 | Early Stopping 및 L1/L2 리프 가중치 규제 |
| **대용량 확장성** | 수만 건 데이터에서도 메모리 고갈 | 수천만 건 데이터 분산 병렬 학습 지원 |
