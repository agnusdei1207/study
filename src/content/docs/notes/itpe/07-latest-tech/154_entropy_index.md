## 연관 키워드

- 엔트로피, 정보 이득(IG), 정보 이득률(Gain Ratio), 분할 정보량(SplitInfo)
- 지니 지수(Gini Index), 의사결정나무, ID3, C4.5, CART
- 과적합, 가지치기(Pruning), 다치 속성 편향

## Ⅰ. 엔트로피 지수(Entropy Index)의 개요

- 핵심 요약 : 클래스 분포의 불확실성을 로그로 수치화한 불순도 척도로, 의사결정나무의 분기 기준이 됨.
- 개념 : 클로드 섀넌의 정보 이론에 기반해 데이터 집합 내 클래스 확률 분포의 불확실성을 수치화한 **엔트로피** (Entropy) 불순도 척도.
- 배경 및 필요성 : 고유값이 많은 속성은 엔트로피 감소량이 과도하게 커져 분기 기준으로 잘못 선택되므로, 분할 정보량으로 나눈 **정보 이득률** (Gain Ratio)로 보정할 필요가 있음.
- 주요 목적 : 분할 후 무질서도를 줄이고 순도를 높이는 분기 속성을 찾아 분류 모델의 정확도를 높임.

## Ⅱ. 엔트로피 지수(Entropy Index)의 특징 및 장점

- 핵심 요약 : 엔트로피 감소를 분기 효율로 측정하고, 분할 정보량으로 보정해 편향 없는 분기를 고르는 원리.

1. 엔트로피 : 클래스 분포의 평균 정보량 → 완전 균등일 때 최댓값, 완전 동질일 때 0이 되어 불순도를 직관적으로 측정.
2. **정보 획득량** (IG, Information Gain) : 속성으로 분할한 뒤 줄어든 엔트로피 → 분할 효율을 비교하는 기준.
3. **분할 정보량** (SplitInfo) : 속성이 데이터를 얼마나 잘게 나누는지를 나타내는 엔트로피 → 잘게 나누는 속성에 페널티를 부여.
4. **정보 이득률** (Gain Ratio) : 정보 획득량을 분할 정보량으로 나눔 → 다치 속성의 과선택을 억제.

## Ⅲ. 엔트로피 지수(Entropy Index)의 구조 (흐름)

- 핵심 요약 : 부모 엔트로피를 계산하고 속성별 정보 이득을 비교해 최적 속성으로 분할한 뒤, 정지 조건을 검사하는 재귀 구조.

```text
[ 부모 노드 엔트로피 계산 ]
          ↓
[ 후보 속성별 정보 이득 계산 ]
          ↓
[ 최적 속성으로 분할 ]
          ↓
[ 정지 조건 검사 → 리프 또는 재귀 ]
```

```text
H(S) : 부모 노드 엔트로피
E(S, A) : 속성 A 분할 후 가중 엔트로피
IG = H(S) - E(S, A)
GR = IG / SplitInfo(A)
```

## Ⅳ. 엔트로피 지수(Entropy Index)의 비교

- 핵심 요약 : 엔트로피는 정보 이론적 기준, 지니 지수는 계산이 빠른 이진 기준, 정보 이득률은 다치 편향을 보정한 기준으로 역할이 나뉨.

| 비교 축 | 엔트로피 | 지니 지수 | 정보 이득률 |
| --- | --- | --- | --- |
| 기반 수식 | 로그 기반 불확실성 | 제곱합 기반 불순도 | 정보 획득량을 분할 정보량으로 나눔 |
| 연산 부담 | 로그 연산으로 상대적으로 큼 | 사칙연산 위주로 가벼움 | 엔트로피 계산을 두 번 수행 |
| 이진 분류 최대값 | 1 | 0.5 | 정규화된 비율 |
| 대표 알고리즘 | ID3 | CART | C4.5, C5.0 |
| 다치 속성 편향 | 심함 | 다항 분할에서 편향 존재 | 페널티로 억제 |
| 분할 방식 | 다자 분할 가능 | 이진 분할 기본 | 다자 분할과 연속형 처리 지원 |

## Ⅴ. 엔트로피 지수(Entropy Index)의 한계와 방안

- 핵심 요약 : 다치 속성 편향, 연속형 변수의 계산 부담, 과적합을 정보 이득률, 근사 분할, 가지치기로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 다치 속성 편향 | 고객 ID나 날짜처럼 고유값이 많은 속성이 과도하게 선택되어 일반화 실패 | 정보 이득률 적용, 범주형 피처에 목표 인코딩 또는 빈도 인코딩 전처리 | 검증 데이터 성능 차이 |
| 연속형 변수의 계산 부담 | 분기마다 모든 임계치에 로그 계산을 수행해 대용량 학습이 느려짐 | 지니 기반 이진 분할 사용, 히스토그램 기반 분할(LightGBM 등) 도입 | 노드별 학습 소요 시간 |
| 과적합 | 불순도 감소만 쫓아 리프에 소수 샘플만 남음 | 사전 가지치기(max_depth, min_samples_leaf), 비용 복잡도 가지치기 | 검증 오차, 리프당 평균 샘플 수 |

## Ⅵ. 엔트로피 지수(Entropy Index)에 대한 기술사적 제언

- 핵심 요약 : 분기 기준의 편향과 계산 비용을 라이브러리 수준에서 해결하고, 과적합 통제를 학습 설정의 기본값으로 두는 방향.

1. 범주형 전처리 : 데이터 분석 조직은 고유값이 많은 범주형 피처를 원시 상태로 넣지 않고, 목표 인코딩이나 빈도 인코딩을 거친 뒤 분기 기준을 적용하는 전처리 표준을 두어야 한다.
2. 분할 연산 : 대용량 데이터를 다루는 정보시스템 부서는 전수 로그 계산 대신 히스토그램 기반 분할을 쓰는 라이브러리를 기본으로 채택하는 것이 합리적이다.
3. 과적합 통제 : 모델 개발 조직은 가지치기 설정과 검증 데이터 기반 조기 종료를 학습 파이프라인의 기본 항목으로 포함해, 개발자의 수동 조정에 의존하지 않도록 해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 엔트로피 지수는 분포의 불확실성을 기준으로 분기를 고르는 의사결정나무의 기초 척도임.
- 시사점 : 순도를 높이는 것만으로는 일반화가 보장되지 않으므로, 편향 보정과 가지치기를 함께 적용하는 것이 실무의 전제가 된다.
