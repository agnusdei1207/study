## 답안 골격
```text
[엔트로피 지수] ◀━━ 머리: Ⅶ 내 의견 (의사결정나무 분기 기준으로서 정보 획득량(Information Gain) 최적화 및 다중 분기 편향 극복 방안)
 ┃
 ┣━ Ⅰ 개요 ───── 정보이론(Information Theory)에서 불확실성(Uncertainty)과 무질서도를 정량화하여 머신러닝 의사결정나무의 최적 분할(Split) 기준으로 활용
 ┣━ Ⅱ 수식 ───── H(S) = - ∑ [ p_i * log2(p_i) ] (p_i: 클래스 i에 속할 확률, 0 <= H(S) <= log2(K))
 ┣━ Ⅲ 특성 ───── 순수도(Purity) 최대 시 엔트로피 0 (한 클래스만 존재) · 불확실성 최대 시 엔트로피 1 (클래스 반반 균등 분포)
 ┣━ Ⅳ 분기원리 ─ 정보 획득량(Information Gain) = H(부모노드) - ∑ [ (|S_v| / |S|) * H(S_v) ] → 정보 획득량이 최대가 되는 특성 선택 (ID3 알고리즘)
 ┣━ Ⅴ 비교 ───── 엔트로피 지수(Entropy) vs 지니 계수(Gini Index) (로그연산포함/상대적연산량큼/ID3·C4.5 vs 단순제곱합(1-∑p_i^2)/초고속연산/CART기본탑재)
 ┗━ Ⅵ 실무 ───── 고유값(Unique ID)이 많은 변수 선택 시 정보획득량 과대평가 편향 / 연속형 변수 분할 시 연산 복잡도 / 과적합 발생 위험
```
- 필수 키워드: 엔트로피 지수(Entropy Index) · 섀넌 엔트로피(Shannon Entropy) · 불확실성(Uncertainty) · 순수도(Purity) · 정보 획득량(Information Gain) · 분할 정보량(Split Information) · ID3 · C4.5
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 엔트로피 수학적 정의식 및 그래프 특성 → Ⅳ 정보 획득량 분기 계산 메커니즘 / 25점 = Ⅰ~Ⅶ 전개, ID3의 고유값 편향 문제와 이를 해결하기 위한 C4.5의 정보 획득률(Gain Ratio) 수식 상세 전개

## 한 줄 본질
- 데이터가 얼마나 뒤죽박죽 섞여 있는지(불확실성)를 로그 수식으로 측정한 값으로, 질문(분기)을 던져 이 어지러움을 가장 많이 줄여주는(순수도 극대화) 변수를 찾아내는 의사결정나무의 나침반

```text
[섀넌 엔트로피 지수 분포 곡선 및 정보 획득량(IG) 분할]

    엔트로피 H(p)
      1.0 ┼         ╭───────╮            [부모 노드 엔트로피 H(S)]
          │       ╭╯         ╰╮                    │
      0.5 │     ╭╯             ╰╮                  ▼ (특성 A 기준 분할)
          │   ╭╯                 ╰╮        ┌───────┴───────┐
      0.0 └──┴──────────┬──────────┴──     ▼               ▼
            0.0        0.5        1.0   [자식노드 S1]   [자식노드 S2]
               확률 p (이진 분류)          (순수도 증가 -> 엔트로피 급감)
                                        IG(S, A) = H(S) - H(자식 가중평균)
```

## 핵심 용어
- 섀넌 엔트로피(Shannon Entropy): 확률 변수의 평균 정보량 또는 불확실성을 나타내는 측도로, 클로드 섀넌이 정보이론에서 통신 채널의 비트 수 최소화를 위해 제안한 개념
- 정보 획득량(Information Gain): 특정 변수를 기준으로 데이터를 분할했을 때 부모 노드의 엔트로피 대비 자식 노드들의 가중평균 엔트로피가 얼마나 감소(순수도 향상)했는지를 나타내는 지표
- 정보 획득률(Gain Ratio): 정보 획득량을 분할 자체의 고유 엔트로피(Split Information)로 나누어, 주민등록번호처럼 고유 범주가 무한히 많은 변수로 분기하려는 편향을 페널티로 상쇄시킨 지표 (C4.5)

## 핵심 통찰
- "무질서의 소멸이 곧 학습": 머신러닝 분류는 엔트로피가 1(완전 혼돈)인 상태에서 시작하여, 질문을 거듭하며 각 리프 노드의 엔트로피를 0(단일 클래스 순수)으로 떨어뜨리는 최적화 과정
- 로그2 밑의 의미: 컴퓨터 2진법에서 정보를 표현하기 위해 필요한 '최소 비트 수'를 의미하므로, 엔트로피 1은 1비트의 질문이 더 필요함을 뜻함
- 지니 지수와의 실무적 동등성: 엔트로피가 로그 연산으로 인해 약간의 연산 비용이 더 들 뿐, 실제 의사결정나무 모델의 분할 경계와 정확도 결과는 지니 지수와 98% 이상 일치함

## 이웃 토픽과 구분
- 엔트로피 지수 vs 지니 지수: 엔트로피는 확률의 로그 곱(-∑p*log2(p))을 사용하여 정보이론적 불확실성을 측정 / 지니 지수는 확률 제곱의 합(1-∑p^2)을 사용하여 통계학적 불순도를 측정하므로 로그 연산이 없어 연산 속도가 더 빠름
