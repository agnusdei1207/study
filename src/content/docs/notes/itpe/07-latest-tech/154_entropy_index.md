## 2~4교시 25점 답안

## Ⅰ. 엔트로피 불순도의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 클래스 비율 pᵢ의 불확실성을 H(S)=-∑pᵢlog₂pᵢ로 측정하는 지표 |
| 목적 | 의사결정나무 후보 분할의 정보 획득량 비교 |

## Ⅱ. 부모·자식 노드의 정보 획득량 계산 구조

```text
부모 집합 S: H(S)
   │ 후보 속성 A로 분할
   ├─ 자식 S₁: 비율 |S₁|/|S|, 불순도 H(S₁)
   └─ 자식 S₂: 비율 |S₂|/|S|, 불순도 H(S₂)
           │
           ▼
IG(S,A) = H(S) - Σᵥ [|Sᵥ|/|S| × H(Sᵥ)]
           └─ 후보별 IG 비교 → 분할 선택
```

## Ⅲ. 엔트로피와 지니 불순도 비교

| 기준 | 수식 | 특성 |
|---|---|---|
| 엔트로피 | -∑pᵢlog₂pᵢ | 정보 획득량 계산에 사용 |
| 지니 | 1-∑pᵢ² | 제곱합 기반 불순도; 선택 분할 일치 보장 없음 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| ID처럼 고유값이 많은 속성이 훈련 집합을 잘게 나눠 정보 획득량 과대평가 | 고유 식별자 제외·Gain Ratio 검토·최소 리프 수 제한 |
| 훈련 불순도 감소가 일반화 성능을 보장하지 않음 | 가지치기와 독립 검증 자료의 성능 비교 |

## Ⅴ. 제언

후보 속성의 고유값 분포를 먼저 확인하고 정보 획득량과 검증 성능을 함께 기준으로 분할 결정.
