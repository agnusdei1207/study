## Ⅰ. 엔트로피 지수(Entropy Index)의 개요

- 개념 : 클로드 섀넌의 정보 이론에 기반하여 데이터 집합 내 클래스 확률 분포의 불확실성 및 정보량 기댓값을 로그 함수($-\sum p_i \log_2 p_i$)로 수치화한 불순도 척도.
- 배경 및 필요성 : 다치 속성 편향이 발생하므로 분할 정보량으로 정규화한 정보 이득률(Gain Ratio) 적용 필요.
- 핵심 목적 : 데이터 분할 시 무질서도를 최소화하고 순도(Purity)를 극대화하는 최적의 분기 피처를 탐색하여 분류 모델의 예측 정확도 향상.

## Ⅱ. 엔트로피 지수(Entropy Index)의 핵심 아키텍처 및 동작 메커니즘

엔트로피 지수는 신뢰할 수 있는 데이터 파이프라인과 고도화된 추론 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 엔트로피 기반 의사결정나무(ID3 / C4.5) 분할 및 트리 성장 파이프라인 ]│
└────────────────────────────────────────────────────────────────────────┘

  [ 부모 노드 데이터 집합 S (총 N개: 양성 $p_+$, 음성 $p_-$) ]
   - 부모 엔트로피 계산: $H(S) = - (p_+ \log_2 p_+ + p_- \log_2 p_-)$
                     │
                     ▼
  [ 후보 속성군 ($A_1, A_2, \dots, A_k$)별 가상 분할 시뮬레이션 ]
   ├── 후보 속성 $A_1$ 분할 ──> 자식 노드 $S_{11}, S_{12}$ 생성
   │    └── 가중치 적용 잔여 엔트로피 $E(S, A_1) = \sum \frac{|S_{1v}|}{|S|} H(S_{1v})$
   │    └── 정보 획득량 도출: $IG(S, A_1) = H(S) - E(S, A_1)$
   │
   └── 후보 속성 $A_2$ 분할 ──> 자식 노드 $S_{21}, S_{22}, S_{23}$ 생성
        └── 동일 방식으로 $IG(S, A_2)$ 계산
                     │
                     ▼
  [ 최적 분기 속성 선정: $\arg\max_A [IG(S, A)]$ 또는 $\arg\max_A [GR(S, A)]$ ]
                     │
                     ▼
  [ 노드 분기 실행 및 정지 조건(Stopping Criteria) 검증 ]
   ├── 모든 샘플이 동일 클래스인 경우 ──> Leaf 노드 확정
   ├── 잔여 엔트로피가 0이거나 깊이 한계 도달 ──> 분기 중단
   └── 그 외의 경우 ──> 하위 자식 노드에서 1단계 재귀 호출
```

- **엔트로피 수식** : $H(S) = -\sum_{i=1}^{c} p_i \log_2 p_i$ - 이진 분류 기준 완전 균등($p=0.5$) 시 최댓값 1, 완전 동질($p=1$) 시 최솟값 0.
- **정보 획득량 (IG)** : 속성 A로 분할한 후 감소된 엔트로피의 크기 (분할 효율성 지표).
- **분할 정보량 (SplitInfo)** : 속성 A가 데이터를 얼마나 많은 조각으로 잘게 쪼개는지를 나타내는 엔트로피.
- **정보 이득률 (GR)** : $GainRatio(S, A) = \frac{IG(S, A)}{SplitInfo_A(S)}$ - 잘게 쪼개는 속성에 페널티를 부여하여 다치 속성 과적합 원천 차단.

## Ⅲ. 엔트로피 지수(Entropy Index)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 엔트로피 (Entropy) | 지니 지수 (Gini Index) | 정보 이득률 (Gain Ratio) |
|---|---|---|---|
| **기반 수식** | $-\sum p_i \log_2 p_i$ | $1 - \sum p_i^2$ | $IG(S, A) / SplitInfo(S, A)$ |
| **연산 복잡도** | 로그($\log_2$) 연산으로 상대적 높음 | 단순 사칙연산(제곱)으로 매우 빠름 | 엔트로피 연산 2회 수행으로 가장 높음 |
| **값의 범위 (이진)**| $0.0 \sim 1.0$ (최대 불확실성 1.0) | $0.0 \sim 0.5$ (최대 불확실성 0.5) | $0.0 \sim 1.0$ (정규화된 비율) |
| **대표 알고리즘** | ID3 | CART (Classification And Regression Tree) | C4.5, C5.0 |
| **다치 속성 편향** | 심각함 (고유값 많을수록 과선호) | 다항 분할 시 편향 존재 (CART는 이진분할로 완화) | 편향 완벽 억제 (분할 정보량 페널티) |
| **분할 방식** | 다자 분할(Multi-way Split) 가능 | 이진 분할(Binary Split) 기본 | 다자 분할 및 연속형 변수 처리 지원 |

- 엔트로피 지수는 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 엔트로피 지수(Entropy Index)의 주요 한계점 및 해결 방안

- 카디널리티가 극단적으로 높은 속성에 대한 다치 속성 편향 :
  - 한계점 : 고객 식별번호(ID)나 날짜 등 카디널리티가 극단적으로 높은 속성이 최적 분기로 오선택되는 다치 속성 편향.
  - 해결 방안 : C4.5의 정보 이득률(Gain Ratio)을 적용하거나 카테고리 피처에 대해 목표 인코딩(Target Encoding) 또는 빈도 인코딩 전처리 적용.
- 대규모 연속형 변수 분기 시 로그 연산에 따른 속도 저하 :
  - 한계점 : 대용량 데이터셋 학습 시 매 노드 분할마다 수천 개의 연속형 임계치에 대한 $\log_2$ 계산으로 심각한 속도 저하.
  - 해결 방안 : 지니 불순도 기반 이진 분할 알고리즘(CART/LightGBM)으로 전환하거나 히스토그램 기반 빈(Binning) 양자화 기법 결합.
- 불순도 감소 중심 무제한 분할에 따른 과적합(Overfitting) :
  - 한계점 : 엔트로피 감소만을 추구하여 리프 노드의 샘플 수가 1~2개로 잘게 쪼개지며 과적합 발생.
  - 해결 방안 : 사전 가지치기(Pre-pruning: `max_depth`, `min_samples_leaf` 제한) 및 사후 비용 복잡도 가지치기(Cost-Complexity Pruning) 강제.

## Ⅴ. 엔트로피 지수(Entropy Index) 적용 및 발전을 위한 기술사적 제언

- 분할 연산 속도 향상 및 히스토그램 기반 분할 도입 : 정렬된 전체 값 전수 로그 계산 (매우 느림)의 한계를 탈피하고, 히스토그램 기반 고속 스캔을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 다치 속성 제어 고도화 및 범주형 피처 전용 추진 : 분할 정보량(SplitInfo) 수기 조정의 한계를 탈피하고, 범주형 피처 전용 정규화 알고리즘 자동 내장을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 과적합 방어 고도화 및 Early Stopping 및 추진 : 사후 복잡한 가지치기 수동 적용의 한계를 탈피하고, Early Stopping 및 L1/L2 리프 가중치 규제를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
