## 답안 골격
```text
[실루엣 계수] ◀━━ 머리: Ⅶ 내 의견 (정답 라벨이 없는 비지도 군집 분석에서 군집 내 응집도와 군집 간 분리도를 결합하여 최적의 군집 수 $k$를 결정하는 객관적 평가 지표)
 ┃
 ┣━ Ⅰ 개요 ───── 군집 분석에서 정답 라벨(Ground Truth) 부재로 인한 군집 타당성 평가의 어려움 → 군집 내 거리와 최근접 군집 거리를 비교한 실루엣 계수 도입
 ┣━ Ⅱ 특징 ───── 응집도(Cohesion)와 분리도(Separation) 동시 반영 · 범위 [-1, 1] 정규화 · 최적 군집 수($k$) 결정 지원 · 개별 데이터 및 전체 평균 평가
 ┣━ Ⅲ 구조 ───── 군집 내 평균 거리 $a(i)$ + 가장 가까운 타 군집 평균 거리 $b(i)$ + 실루엣 계수 공식 $s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$
 ┣━ Ⅳ 흐름 ───── ① 대상 샘플 $i$ 선정 → ② 동일 군집 내 타 샘플들과의 평균 거리 $a(i)$ 계산 → ③ 가장 가까운 이웃 군집과의 평균 거리 $b(i)$ 계산 → ④ $s(i)$ 산출 및 전체 샘플 평균
 ┣━ Ⅴ 비교 ───── 엘보우 기법(Elbow Method) vs 둔 지수(Dunn Index) vs 실루엣 계수 (SSE 꺾임점 주관적 판단 vs 최소/최대 극단값 민감 vs 전구간 직관적 정규화 수치 제공)
 ┗━ Ⅵ 실무 ───── $O(N^2)$ 계산 복잡도로 대규모 데이터 연산 병목 / 비구형(Non-globular) 및 밀도 기반 군집 왜곡 / 이상치 민감도
```

## 한 줄 본질
- 군집을 몇 개로 묶어야 잘 묶은 것인지 정답이 없는 환경에서, 데이터가 자기 군집 친구들과 얼마나 가깝고($a$) 남의 군집과는 얼마나 멀리 떨어져 있는지($b$)를 -1에서 1 사이로 정량 계산 → 최적의 군집 수 $k$ 객관적 선정 / 데이터 수가 많을 때 거리 연산량($O(N^2)$) 폭증

## 핵심 그림
```text
[실루엣 계수 s(i)의 기하학적 거리 계산 원리]

      [군집 A (샘플 i가 속한 군집)]                 [군집 B (가장 가까운 이웃 군집)]
   ┌────────────────────────────────┐           ┌────────────────────────────────┐
   │          *    *                │           │           *        *           │
   │      *     \                   │           │               \                │
   │             * (샘플 i) --------┼───────────┼------------>   *               │
   │            /                   │           │               /                │
   │          *    *                │           │           *        *           │
   │                                │           │                                │
   │   a(i): 군집 A 내부 샘플들과의  │           │   b(i): 가장 가까운 타 군집 B의 │
   │         평균 거리 (응집도)     │           │         샘플들과의 평균 거리   │
   └────────────────────────────────┘           └────────────────────────────────┘

   * 실루엣 계수 공식:  s(i) = [ b(i) - a(i) ] / max( a(i), b(i) )
     - s(i) -> 1  : 매우 잘 군집화됨 (b >> a)
     - s(i) -> 0  : 군집 간 경계선에 걸쳐 있음 (b ≈ a)
     - s(i) -> -1 : 잘못된 군집에 할당됨 (a >> b)
```

## 핵심 용어
- $a(i)$ (응집도, Intra-cluster distance): 샘플 $i$로부터 자신이 속한 동일 군집 내 다른 모든 데이터 포인트들까지의 유클리드 평균 거리(작을수록 군집이 촘촘함)
- $b(i)$ (분리도, Nearest-cluster distance): 샘플 $i$로부터 자신이 속하지 않은 다른 군집들 중 가장 가까운 군집에 속한 포인트들까지의 평균 거리(클수록 타 군집과 멀리 떨어짐)
- 실루엣 다이어그램(Silhouette Plot): 군집별로 정렬된 샘플들의 실루엣 계수를 가로 막대그래프로 시각화하여, 특정 군집의 크기가 너무 작거나 계수가 음수인 샘플의 비율을 확인하는 도구

## 핵심 통찰
- 분모에 $\max(a, b)$를 두는 수학적 이유: 단순히 $b - a$만 하면 데이터의 절대적인 거리 척도(단위)에 따라 값이 수백, 수천으로 튀게 되므로, 둘 중 큰 값으로 나누어 값을 반드시 $[-1, 1]$ 구간으로 정규화함
- 엘보우 기법(Elbow Method)과의 완벽한 보완: SSE(오차제곱합)는 군집 수 $k$가 증가할수록 무조건 감소하여 꺾임점(Elbow)을 주관적으로 찍어야 하지만, 실루엣 점수는 최적 $k$에서 명확한 극댓값(Peak)을 형성함
- 구형 군집(Spherical Cluster) 가정의 한계: K-Means처럼 원형으로 뭉치는 군집에는 정확하지만, 초승달 모양(Moons)이나 밀도 기반 군집(DBSCAN)에서는 올바르게 묶였어도 실루엣 계수가 낮게 나오는 왜곡이 발생함

## 이웃 토픽과 구분
- 실루엣 계수 vs 엘보우 기법(SSE): 엘보우 기법은 군집 내 오차만 보며 $k$ 증가 시 단조 감소 / 실루엣 계수는 군집 내 응집도와 군집 간 분리도를 동시에 보며 최적 $k$에서 극대치 도출

| 초승달 형태의 지리적 이동 경로 데이터에서 실루엣 계수가 음수로 나와 군집 실패 판정 | 실루엣 계수의 유클리드 거리 기반 볼록(Convex) 군집 편향 | 밀도 기반 군집(DBSCAN)으로 전환하고 밀도 기반 평가 지표(DBCV) 적용 | 비구형 복잡 군집의 정확한 검증 달성 |
