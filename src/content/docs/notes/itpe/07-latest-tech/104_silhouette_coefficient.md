## 30초 인출

- 본질: **실루엣 계수 (Silhouette Coefficient)** 는 정답 라벨이 없는 비지도 군집화(Clustering)에서 각 데이터 개체가 자신이 속한 군집 내에 얼마나 조밀하게 응집(Cohesion)되어 있고 다른 군집과는 얼마나 멀리 분리(Separation)되어 있는지를 정량화하는 타당성 평가지표
- 메커니즘: 개체 $i$에 대해 동일 군집 내 평균 거리 $a(i)$와 최근접 타 군집과의 평균 거리 $b(i)$를 계산하여 $s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$ 공식을 통해 -1에서 +1 사이 값으로 정규화
- 통찰: 전체 평균 실루엣 점수만으로 군집 수 $k$를 결정하면 개별 군집의 극단적 불균형이나 음수 이상치를 은폐하므로 군집별 실루엣 다이어그램 두께와 음수 비율을 함께 점검하는 다차원 검증 체계 구축 필수

<details><summary>핵심 용어</summary>

- **실루엣 계수 (Silhouette Coefficient)** : 군집 내 응집도와 군집 간 분리도를 동시에 반영하여 클러스터링의 품질을 -1~+1로 수치화한 지표.
- **내부 응집도 ($a(i)$)** : 데이터 포인트 $i$로부터 자신이 속한 동일 군집 내 다른 모든 데이터 포인트들까지의 유클리드 평균 거리.
- **외부 분리도 ($b(i)$)** : 데이터 포인트 $i$로부터 자신이 속하지 않은 타 군집들 중 가장 가까운 이웃 군집 데이터 포인트들과의 평균 거리.
- **실루엣 다이어그램 (Silhouette Diagram)** : 군집별로 각 데이터의 실루엣 계수를 가로 막대 형태로 정렬하여 군집 크기와 칼날 형상을 시각화한 차트.
- **군집 타당성 지표 (Cluster Validity Index)** : 레이블이 없는 환경에서 최적의 클러스터 수 $k$를 결정하기 위해 사용하는 내적 평가 측도.

</details>

## 2~4교시 25점 답안

## Ⅰ. 실루엣 계수의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **실루엣 계수** 는 데이터 개별 포인트가 속한 군집 내의 조밀도(응집도)와 가장 인접한 타 군집과의 격리도(분리도)를 복합 계산하여 군집화의 적절성을 판정하는 비지도 평가 척도 |
| 목적 | 정답 레이블(Ground Truth)이 없는 데이터셋에서 최적의 군집 수 $k$를 객관적으로 결정하고 군집 오할당 데이터 감지 |

## Ⅱ. 실루엣 계수의 수학적 정의 및 해석 특징

| 구성 수식 및 해석 | 수학적 표현 | 기술적 특징 및 의미 |
|---|---|---|
| **응집도 계산 ($a(i)$)** | $a(i) = \frac{1}{\|C_I\| - 1} \sum_{j \in C_I, j \ne i} d(i, j)$ | 클러스터 $C_I$ 내부 데이터들 간의 평균 거리, 값이 작을수록 빽빽하게 뭉쳐 있음을 의미 |
| **분리도 계산 ($b(i)$)** | $b(i) = \min_{J \ne I} \frac{1}{\|C_J\|} \sum_{j \in C_J} d(i, j)$ | 가장 가까운 이웃 군집 $C_J$와의 평균 거리, 값이 클수록 타 군집과 명확히 격리됨을 의미 |
| **실루엣 계수 수식** | $s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$ | 분모의 $\max$ 정규화로 $-1 \le s(i) \le 1$ 범위로 스케일링 |
| **수치 해석 ($s(i) \approx 1$)** | $a(i) \ll b(i)$ 인 경우 | 자신의 군집에 완벽하게 포함되어 있고 타 군집과 멀리 떨어져 있는 최상의 상태 |
| **수치 해석 ($s(i) \approx 0$)** | $a(i) \approx b(i)$ 인 경우 | 두 군집 간의 경계선(Boundary)에 위치하여 모호한 소속 상태 |
| **수치 해석 ($s(i) < 0$)** | $a(i) > b(i)$ 인 경우 | 자신의 군집보다 이웃 군집에 더 가까워 오분류(Misclustered)된 이상치 상태 |

## Ⅲ. 실루엣 계수 산출 체계 및 최적 군집 수 도출 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             실루엣 계수 기반 최적 군집 수(k) 결정 프로세스            │
└────────────────────────────────────────────────────────────────────────┘
 [ 원본 비정형/정형 데이터셋 ] ──> 표준화 전처리 (StandardScaler)
                                         │
                                         ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 후보 군집 수 순회 루프 (k = 2 to K_max)                              │
 │                                                                      │
 │  [ K-Means / GMM 군집화 실행 ] ──> 클러스터 레이블 할당              │
 │                                                                      │
 │  ┌────────────────────────────────────────────────────────────────┐  │
 │  │ 전수 거리 행렬(Pairwise Distance Matrix) 계산                 │  │
 │  │  ├─ 점 i별 내부 평균 거리 a(i) 도출                           │  │
 │  │  ├─ 점 i별 최근접 군집 평균 거리 b(i) 도출                    │  │
 │  │  └─ 개별 실루엣 점수 s(i) 계산: s(i) = (b - a) / max(a, b)    │  │
 │  └───────────────────────────────┬────────────────────────────────┘  │
 │                                  │                                   │
 │  [ 군집별 실루엣 다이어그램 플로팅 및 전체 평균 점수 S_k 집계 ]       │
 └──────────────────────────────────┼───────────────────────────────────┘
                                    │
                                    ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 최적 k* 선정 다면 평가                                               │
 │  - 조건 1: 전체 평균 실루엣 계수(Mean Silhouette)가 최대화되는 지점  │
 │  - 조건 2: 개별 군집의 두께(데이터 수)가 편중되지 않고 균일할 것     │
 │  - 조건 3: 음수(s < 0) 실루엣 계수를 가진 데이터 비율이 최소일 것    │
 └──────────────────────────────────┬───────────────────────────────────┘
                                    │
                                    ▼
                [ 최종 최적화된 군집 모델 배포 및 활용 ]
```

| 프로세스 단계 | 세부 작업 내용 | 주의 사항 |
|---|---|---|
| **거리 척도 정의** | 유클리디안, 맨해튼, 코사인 거리 중 데이터 특성에 맞는 메트릭 선정 | 고차원 데이터 시 차원의 저주 고려 |
| **개체별 점수 산출** | 모든 데이터 쌍의 거리를 바탕으로 $a(i), b(i), s(i)$ 매트릭스 생성 | $O(N^2)$ 계산 복잡도 병목 주의 |
| **다이어그램 시각화** | 군집별로 $s(i)$를 내림차순 정렬하여 수평 막대그래프로 플로팅 | 칼날 끝이 전체 평균선 초과 여부 확인 |
| **최적 $k$ 확정** | 평균 점수 피크 지점과 도메인 업무 해석 가능성을 결합하여 최종 선택 | 단순 수치 최적화 맹신 지양 |

## Ⅳ. 비지도 군집 평가 기법 비교

| 비교 항목 | 엘보우 기법 (Elbow Method) | 던 지수 (Dunn Index) | 실루엣 계수 (본 토픽) | 데이비스-볼딘 (DBI) |
|---|---|---|---|---|
| **평가 원리** | 군집 내 제곱합(WCSS) 감소율 | 최소 군집 간 거리 / 최대 군집 직경 | 개체별 응집도와 분리도 비율 | 군집 간 거리 대비 군집 내 분산 |
| **최적 판정 기준** | 감소 기울기가 꺾이는 팔꿈치점 | 지수가 최대화되는 지점 | 평균 계수가 1에 가까운 최대점 | 지수가 0에 가까운 최소점 |
| **평가 단위** | 전체 군집 단일 스칼라 | 전체 군집 단일 스칼라 | 개별 포인트 ──> 군집 ──> 전체 | 군집 단위 쌍대 비교 합산 |
| **시각적 명확성** | 꺾임점이 완만할 경우 주관 개입 | 직관적이지 않음 | 실루엣 다이어그램으로 완벽 시각화 | 수치 대소만 확인 가능 |
| **계산 복잡도** | $O(N \cdot k)$ (매우 빠름) | $O(N^2)$ (느림) | $O(N^2)$ (쌍대 거리 연산) | $O(k^2)$ (비교적 빠름) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 전체 데이터 수가 $N$개일 때 거리 행렬 계산에 $O(N^2)$의 시간 및 메모리 복잡도가 발생하여 빅데이터 적용 불가 | 미니배치 샘플링 기반 근사 실루엣(Mini-batch Silhouette Score) 적용 및 KD-Tree/FAISS 기반 근접 이웃 가속화 |
| K-Means와 같은 구형(Spherical) 볼록 군집만을 우대하고 초승달형·밀도 기반(DBSCAN) 비선형 군집을 잘못 감점하는 왜곡 | 비선형 다양체(Manifold) 데이터의 경우 커널 PCA/t-SNE로 저차원 임베딩 후 계산하거나 밀도 기반 타당성 지표(DBCV) 병행 |
| 전체 평균 실루엣 값만 보고 군집을 결정할 경우 특정 소형 군집에 음수 계수가 몰려 있어도 발견하지 못하는 착시 | 군집별 실루엣 점수의 표준편차와 음수 개체 비율을 함께 리포팅하는 다이어그램 시각화 감사 의무화 |

## Ⅵ. 제언

수백만 건의 대규모 비즈니스 데이터 군집화 품질을 실시간 검증하기 위해 계층적 서브샘플링과 실루엣 다이어그램 이상치 자동 감시 파이프라인 구축 권고.

```text
[ 대규모 원천 고객 데이터셋 (N > 1,000,000) ]
                      │
                      ▼
┌────────────────────────────────────────────────────────┐
│ 계층적 층화 샘플링 (Stratified Sub-sampling: n = 10,000)│
│  - 군집별 비율을 보존한 고속 서브셋 추출               │
└─────────────────────┬──────────────────────────────────┘
                      │
                      ▼
┌────────────────────────────────────────────────────────┐
│ 병렬 실루엣 엔진 (CUDA/FAISS 가속 기반 고속 계산)       │
│  - 개별 s(i) 산출 및 군집별 지표 분해                  │
└─────────────────────┬──────────────────────────────────┘
                      │
                      ▼
┌────────────────────────────────────────────────────────┐
│ 실루엣 다이어그램 자동 이상치 감사 (Automated Auditor) │
│  ├── 체크 1: 군집별 평균 > 0.5 충족 여부               │
│  ├── 체크 2: 음수 실루엣 비율 < 1% 미만 여부           │
│  └── 체크 3: 군집 크기 불균형 비율 검증                │
└─────────────────────┬──────────────────────────────────┘
                      │ 통과 시
                      ▼
        [ 프로덕션 고객 세그멘테이션 마케팅 적용 ]
```

| 구분 | 전체 데이터 단순 평균 계산 | 제언: 층화 샘플링 + 다이어그램 자동 감사 |
|---|---|---|
| **연산 시간** | 수 시간 소요 및 OOM 크래시 | 수 초 이내 고속 실시간 검증 완료 |
| **이상치 감지** | 개별 데이터 오할당 감지 불가 | 음수 비율 자동 경보로 오할당 즉시 격리 |
| **군집 균형성** | 한 군집으로 쏠리는 현상 은폐 | 군집별 두께 비율 모니터링으로 균형 보장 |
| **파이프라인 연계** | 오프라인 일회성 분석 | MLOps 파이프라인 내 자동 품질 게이트 결합 |
