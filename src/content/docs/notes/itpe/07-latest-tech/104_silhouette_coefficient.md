## 지식 로드맵 내 현재 위치
IT 인공지능 → 비지도 학습 → 군집 타당성 평가 → 실루엣 계수

## 30초 인출
- **본질**: 실루엣 계수는 각 샘플이 자기 군집에는 가깝고 다른 군집에는 얼마나 떨어져 있는지 나타낸다.
- **메커니즘**: 군집 내부 평균거리 `a(i)`와 가장 가까운 다른 군집까지의 평균거리 `b(i)`를 비교한다.
- **해석**: 값은 −1~1 범위이며 높을수록 해당 분할에서 응집·분리가 양호하지만, 최적 군집 수를 자동 보장하지는 않는다.

<details><summary>핵심 용어</summary>

- **실루엣 계수**: Silhouette Coefficient. 응집도와 분리도를 함께 나타내는 군집 평가 지표
- **응집도 a(i)**: 샘플 i에서 같은 군집 샘플까지의 평균 거리다.
- **분리도 b(i)**: 샘플 i에서 다른 군집별 평균 거리 중 가장 작은 값이다.
- **a(i)**: 샘플 `i`와 같은 군집의 다른 샘플 간 평균 거리다.
- **b(i)**: 샘플 `i`와 가장 가까운 다른 군집 샘플 사이의 평균 거리다.
- **실루엣 다이어그램**: 샘플별 계수를 군집별로 시각화해 분포와 음수 값을 확인하는 그래프다.
</details>

## 1교시 10점 답안
### Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **실루엣 계수**는 군집 내부 응집도와 다른 군집과의 분리도를 함께 평가하는 지표 |
| 목적 | 군집 결과와 군집 수의 비교·평가 |

### Ⅱ. 거리와 산출
```text
샘플 i
  ├─ 같은 군집 내 평균 거리: a(i)
  └─ 다른 군집 평균 거리의 최솟값: b(i)
        ↓ 두 거리로 계산
s(i) = (b(i) - a(i)) / max(a(i), b(i))

해석
  ├─ 1에 가까움: 군집 내 응집·군집 간 분리 양호
  ├─ 0 부근: 군집 경계에 위치
  └─ 음수: 다른 군집에 더 가까울 가능성
```

### Ⅲ. 값 해석·활용
| 값 | 해석 |
|---|---|
| 1에 가까움 | 자기 군집에 가깝고 다른 군집과 분리 |
| 0 부근 | 군집 경계 부근일 가능성 |
| 음수 | 다른 군집에 더 가까울 수 있음 |

군집별 분포를 확인하고 여러 `k` 후보를 비교한다. 높은 평균값 하나만으로 최적 `k`를 단정하지 않는다.

**제언:** 평균과 군집별 분포를 함께 살펴 데이터 구조·업무 목적에 맞는 군집 수를 선택한다.

## 2~4교시 25점 답안
## Ⅰ. 개념과 평가 범위
| 구분 | 핵심 |
|---|---|
| 정의 | **실루엣 계수**는 군집 내부 응집도와 다른 군집과의 분리도를 함께 평가하는 지표 |
| 목적 | 군집 결과와 군집 수의 비교·평가 |

실루엣 계수는 레이블 없는 군집 결과에서 각 샘플의 내부 응집도와 최근접 타 군집과의 분리도를 비교한다. 라벨 정답이 없어도 군집 결과를 요약할 수 있지만, 특정 형태의 군집을 선호할 수 있다.

| 평가 수준 | 관찰 대상 |
|---|---|
| 샘플 | 개별 계수의 크기와 부호 |
| 군집 | 계수 분포·크기·음수 비율 |
| 전체 | 샘플 계수의 평균과 군집 간 차이 |

## Ⅱ. 산출 수식과 의미
`a(i)`는 같은 군집의 다른 샘플과의 평균 거리, `b(i)`는 각 타 군집까지의 평균 거리 중 가장 작은 값이다.

```text
샘플 i
  ├─ 같은 군집 내 평균 거리: a(i)
  └─ 다른 군집 평균 거리의 최솟값: b(i)
        ↓ 두 거리로 계산
s(i) = (b(i) - a(i)) / max(a(i), b(i))

해석
  ├─ 1에 가까움: 군집 내 응집·군집 간 분리 양호
  ├─ 0 부근: 군집 경계에 위치
  └─ 음수: 다른 군집에 더 가까울 가능성
```

`s(i) = (b(i) − a(i)) / max(a(i), b(i))`이며 −1에서 1 사이를 갖는다. 값이 클수록 해당 거리 기준에서 군집 배정이 양호하고, 음수이면 다른 군집에 더 가까울 수 있다.

## Ⅲ. 군집 수 비교와 한계
| 항목 | 적용 방법 | 유의점 |
|---|---|---|
| 군집 수 `k` | 같은 전처리·거리척도에서 후보별 평균 비교 | 평균만 최대로 만드는 것이 목표는 아님 |
| 분포 | 군집별 실루엣 다이어그램·음수 비율 점검 | 작은 군집과 이상치 영향을 살핌 |
| 거리척도 | 데이터 특성에 맞는 척도 선택 | 척도와 표준화에 결과가 달라짐 |
| 구조 적합성 | 업무 지식·시각화와 함께 평가 | 비볼록·밀도 기반 구조에서 낮은 점수 가능 |

고전적 평균 실루엣은 서로 다른 크기·밀도의 군집이나 비구형 구조를 충분히 반영하지 못할 수 있다. `k` 선택은 여러 내부 지표와 도메인 타당성을 함께 고려한다.

## Ⅳ. 기술사적 제언
| 한계 | 대응 |
|---|---|
| 실루엣 평균 하나로 군집 수를 결정하면 작은 군집의 낮은 품질이 가려질 수 있음 | 후보별 평균과 군집별 분포를 함께 비교하고, 도메인상 필요한 소규모 군집이 유지되는지 확인해 선택한다. |
