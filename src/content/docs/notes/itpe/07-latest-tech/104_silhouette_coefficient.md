## Ⅰ. 실루엣 계수(Silhouette Coefficient)의 개요

- 개념 : 데이터 개별 포인트가 속한 군집 내의 **조밀도** (응집도)와 가장 인접한 타 군집과의 **격리도** (분리도)를 복합 계산하여 군집화의 적절성을 판정하는 비지도 평가 척도
- 배경 및 필요성 : 전체 평균 실루엣 점수만으로 군집 수 $k$를 결정하면 개별 군집의 극단적 불균형이나 음수 이상치를 은폐하므로 군집별 **실루엣 다이어그램** 두께와 음수 비율을 함께 점검하는 다차원 검증 체계 구축 필수
- 핵심 목적 : **정답 레이블** (Ground Truth)이 없는 데이터셋에서 최적의 군집 수 $k$를 객관적으로 결정하고 군집 오할당 데이터 감지

## Ⅱ. 실루엣 계수(Silhouette Coefficient)의 핵심 아키텍처 및 동작 메커니즘

실루엣 계수는 개체 $i$에 대해 동일 군집 내 평균 거리 $a(i)$와 최근접 타 군집과의 평균 거리 $b(i)$를 계산하여 $s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$ 공식을 통해 -1에서 +1 사이 값으로 정규화 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             실루엣 계수 기반 최적 군집 수(k) 결정 프로세스            │
└────────────────────────────────────────────────────────────────────────┘
 [ 원본 비정형/정형 데이터셋 ] ──> 표준화 전처리 (StandardScaler)
                                         │
                                         ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 후보 군집 수 순회 루프 (k = 2 to K_max)                              │
 │                                                                      │
 │  [ K-Means / GMM(Gaussian Mixture Model) 군집화 실행 ] ──> 클러스터 레이블 할당              │
 │                                                                      │
 │  ┌────────────────────────────────────────────────────────────────┐  │
 │  │ 전수 거리 행렬(Pairwise Distance Matrix) 계산                 │  │
 │  │  ├─ 점 i별 내부 평균 거리 a(i) 도출                           │  │
 │  │  ├─ 점 i별 최근접 군집 평균 거리 b(i) 도출                    │  │
 │  │  └─ 개별 실루엣 점수 s(i) 계산: s(i) = (b - a) / max(a, b)    │  │
 │  └───────────────────────────────┬────────────────────────────────┘  │
 │                                  │                                   │
 │  [ 군집별 실루엣 다이어그램 플로팅 및 전체 평균 점수 S_k 집계 ]       │
 └──────────────────────────────────┼───────────────────────────────────┘
                                    │
                                    ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 최적 k* 선정 다면 평가                                               │
 │  - 조건 1: 전체 평균 실루엣 계수(Mean Silhouette)가 최대화되는 지점  │
 │  - 조건 2: 개별 군집의 두께(데이터 수)가 편중되지 않고 균일할 것     │
 │  - 조건 3: 음수(s < 0) 실루엣 계수를 가진 데이터 비율이 최소일 것    │
 └──────────────────────────────────┬───────────────────────────────────┘
                                    │
                                    ▼
                [ 최종 최적화된 군집 모델 배포 및 활용 ]
```

- **응집도 계산 ($a(i)$)** : 클러스터 $C_I$ 내부 데이터들 간의 평균 거리, 값이 작을수록 빽빽하게 뭉쳐 있음을 의미
- **분리도 계산 ($b(i)$)** : 가장 가까운 이웃 군집 $C_J$와의 평균 거리, 값이 클수록 타 군집과 명확히 격리됨을 의미
- **실루엣 계수 수식** : $s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$ - 분모의 $\max$ 정규화로 $-1 \le s(i) \le 1$ 범위로 스케일링
- 수치 해석 ($s(i) \approx 1$) : $a(i) \ll b(i)$ 인 경우 - 자신의 군집에 완벽하게 포함되어 있고 타 군집과 멀리 떨어져 있는 최상의 상태
- 수치 해석 ($s(i) \approx 0$) : $a(i) \approx b(i)$ 인 경우 - 두 군집 간의 경계선(Boundary)에 위치하여 모호한 소속 상태

## Ⅲ. 실루엣 계수(Silhouette Coefficient)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 엘보우 기법 (Elbow Method) | 던 지수 (Dunn Index) | 실루엣 계수 (본 토픽) | 데이비스-볼딘 (DBI, Davies-Bouldin Index) |
|---|---|---|---|---|
| **평가 원리** | 군집 내 제곱합(WCSS, Within-Cluster Sum of Squares) 감소율 | 최소 군집 간 거리 / 최대 군집 직경 | 개체별 응집도와 분리도 비율 | 군집 간 거리 대비 군집 내 분산 |
| **최적 판정 기준** | 감소 기울기가 꺾이는 팔꿈치점 | 지수가 최대화되는 지점 | 평균 계수가 1에 가까운 최대점 | 지수가 0에 가까운 최소점 |
| **평가 단위** | 전체 군집 단일 스칼라 | 전체 군집 단일 스칼라 | 개별 포인트 ──> 군집 ──> 전체 | 군집 단위 쌍대 비교 합산 |
| **시각적 명확성** | 꺾임점이 완만할 경우 주관 개입 | 직관적이지 않음 | 실루엣 다이어그램으로 완벽 시각화 | 수치 대소만 확인 가능 |

- 실루엣 계수는 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 실루엣 계수(Silhouette Coefficient)의 주요 한계점 및 해결 방안

- 전체 데이터 수 $N$에 대해 거리 행렬 계산 시 $O(N^2)$ 복잡도 폭증 :
  - 한계점 : 전체 데이터 수가 $N$개일 때 거리 행렬 계산에 $O(N^2)$의 시간 및 메모리 복잡도가 발생하여 빅데이터 적용 불가.
  - 해결 방안 : 미니배치 샘플링 기반 근사 실루엣(Mini-batch Silhouette Score) 적용 및 KD(k-dimensional)-Tree/FAISS 기반 근접 이웃 가속화.
- 구형 볼록 군집만을 우대하고 비선형·밀도 기반 군집을 오판하는 왜곡 :
  - 한계점 : K-Means와 같은 구형(Spherical) 볼록 군집만을 우대하고 초승달형·밀도 기반(DBSCAN) 비선형 군집을 잘못 감점하는 왜곡.
  - 해결 방안 : 비선형 다양체(Manifold) 데이터의 경우 커널 PCA(Principal Component Analysis)/t-SNE(t-distributed Stochastic Neighbor Embedding)로 저차원 임베딩 후 계산하거나 밀도 기반 타당성 지표(DBCV, Density-Based Clustering Validation) 병행.
- 전체 평균 점수만 확인 시 소형 군집의 음수 계수 격리 은폐 착시 :
  - 한계점 : 전체 평균 실루엣 값만 보고 군집을 결정할 경우 특정 소형 군집에 음수 계수가 몰려 있어도 발견하지 못하는 착시.
  - 해결 방안 : 군집별 실루엣 점수의 표준편차와 음수 개체 비율을 함께 리포팅하는 다이어그램 시각화 감사 의무화.

## Ⅴ. 실루엣 계수(Silhouette Coefficient) 적용 및 발전을 위한 기술사적 제언

- 연산 시간 중심 엔터프라이즈 고도화 : 수 시간 소요 및 OOM(Out of Memory) 크래시의 한계를 탈피하고, 수 초 이내 고속 실시간 검증 완료를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 이상치 감지 중심 엔터프라이즈 고도화 : 개별 데이터 오할당 감지 불가의 한계를 탈피하고, 음수 비율 자동 경보로 오할당 즉시 격리를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 군집 균형성 중심 엔터프라이즈 고도화 : 한 군집으로 쏠리는 현상 은폐의 한계를 탈피하고, 군집별 두께 비율 모니터링으로 균형 보장을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
