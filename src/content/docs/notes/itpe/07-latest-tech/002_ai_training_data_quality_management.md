## 2~4교시 25점 답안

## Ⅰ. 인공지능 학습용 데이터 품질관리 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 목표 AI의 학습·평가에 적합한 데이터를 확보하고 결함을 확인·개선하는 활동 |
| 목적 | 데이터 오류·편향·누수로 인한 모델 성능과 신뢰 저하의 예방 |

## Ⅱ. 생명주기별 품질관리

```text
목표·품질기준
      │ 기준 적용
      ▼
수집 → 정제 → 가공·라벨링 → 검증 → 모델 평가
  ▲                                      │
  └──────── 오류·분포 변화 환류 ─────────┘
```

| 단계 | 대표 점검 |
|---|---|
| 계획·수집 | 목적·대상·권리·원천과 필요한 표본 범위 |
| 정제 | 형식·범위·결측·중복·오염 데이터 |
| 가공·라벨링 | 라벨 정의·작업자 교육·불일치 검토 |
| 검증·분할 | 대표성·누수·독립 평가자료 유지 |
| 활용 | 오류 유형·하위집단·운영 데이터 변화 |

## Ⅲ. 데이터 유형별 품질 특성

| 구분 | 주요 품질 기준 |
|---|---|
| 원천 자료 | 수집 목적·사용 권리의 명확성과 실제 대상의 대표성 |
| 정제 자료 | 형식·범위·중복·결측 처리 기준 충족 |
| 라벨 자료 | 정의된 기준에 따른 정확·일관된 표기 |
| 평가 자료 | 학습 자료와의 독립성 및 운영 상황 반영 |

데이터 건수 자체가 품질을 뜻하지 않으며, 품질 기준은 대상 과업·사용 맥락·위험에 따라 정해야 함.

## Ⅳ. 품질 결함과 검증 방법

```text
기준·표본 점검 ──→ 형식·중복 자동 검사
       │                    │
       └────────┬───────────┘
                ▼
       라벨 표본·전문가 검토
                │
                ▼
       독립 평가자료의 모델 시험
                │ 오류 분석
                └────────→ 데이터 기준·구축 보완
```

| 결함 | 확인 방법 | 대응 방향 |
|---|---|---|
| 대표성 부족 | 대상·집단·상황별 분포와 누락 구간 확인 | 필요한 표본을 추가 수집하거나 적용 범위를 조정 |
| 라벨 불일치 | 기준 표본 재판정, 작업자 간 일치 분석 | 정의·예시 보완과 불일치 표본 재검수 |
| 평가 누수 | 중복 개체·시간·그룹이 분할 간 공유되는지 확인 | 분할 단위 재설정 및 독립 평가자료 확보 |
| 운영 분포 변화 | 운영 입력·오류 유형의 시계열 비교 | 영향 분석 후 재평가·데이터 갱신 여부 결정 |

## Ⅴ. 실패 요인과 개선 방향

| 한계 | 대응 |
|---|---|
| 평균 품질 지표가 특정 집단의 결함을 가릴 수 있음 | 데이터 특성과 위험에 맞춰 집단·상황별 품질을 별도 검토 |
| 자동 규칙이 의미 오류나 모호한 라벨을 놓칠 수 있음 | 규칙 검사와 표본 사람 검토를 함께 수행 |
| 학습·평가 자료 간 유사 데이터가 성능을 부풀릴 수 있음 | 개체·시간·원천 기준 분할과 중복 검사를 적용 |
| 운영 오류가 구축 데이터 개선으로 연결되지 않을 수 있음 | 운영 오류의 원천·가공 이력을 찾아 재수집·재가공 판단에 반영 |

## Ⅵ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 데이터 구축 산출물만 인수하면 운영 중 결함의 원인을 찾아 개선하기 어려움 | 수집원·가공 이력·품질 결과·모델 오류를 연결해 기록하고, 실제 오류가 확인된 구간부터 재검토하는 운영안을 제안 |
