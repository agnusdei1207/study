## 지식 로드맵 내 현재 위치
IT 인공지능 → 생성형 AI 평가 → 자동 판별자 → LLM-as-a-Judge

## 30초 인출
- **본질:** LLM-as-a-Judge는 언어모델을 이용해 생성 결과를 미리 정한 기준으로 평가하는 방법이다.
- **메커니즘:** 질문·후보 답변·평가 기준을 판별자에 주고 점수 또는 상대 선호를 받는다.
- **추가 단서:** 판별 결과는 편향될 수 있으므로 사람 평가·기준 데이터로 검증한다.

<details><summary>핵심 용어</summary>

- **대규모 언어 모델(Large Language Model, LLM):** 대규모 텍스트 자료를 학습해 언어 입력·출력을 처리하는 모델이다.
- **루브릭(Rubric):** 평가 항목과 각 점수의 판단 기준을 구체화한 채점표다.
- **단일 응답 채점(Pointwise):** 후보 답변 하나를 기준에 따라 평가하는 방식이다.
- **쌍대 비교(Pairwise):** 같은 질문에 대한 두 후보 답변의 상대적 우열을 판단하는 방식이다.
- **위치 편향(Position Bias):** 후보의 제시 순서가 판별자의 선택에 영향을 줄 수 있는 현상이다.
</details>

## 1교시 10점 답안
### Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | LLM-as-a-Judge는 언어모델로 생성 결과를 기준에 따라 자동 평가하는 방법이다 |
| 목적 | 대량의 비정형 응답을 일정한 절차로 선별·비교한다 |

### Ⅱ. 평가·보정 절차
```text
[질문·후보 답변]     [평가 기준·루브릭]
         |                    |
         +---------+----------+
                   v
           [LLM 판별자 평가]
                   | 점수·근거
                   v
         [결과 집계·일관성 점검]
                   | 표본·불일치 검토
                   v
           [사람 평가·기준자료]
```

### Ⅲ. 편향과 대응
| 편향 | 완화 방법 |
|---|---|
| 후보 순서에 따른 위치 편향 | 순서를 바꿔 재평가하고 불일치 사례 점검 |
| 길고 화려한 답변을 선호하는 경향 | 간결성·근거성 기준을 루브릭에 명시 |
| 판별자·생성 모델의 자기 선호 | 모델 출처를 가리고 사람 평가와 비교 |

**제언:** 고위험 평가는 판별 점수만으로 확정하지 않고 사람의 검토 절차를 둔다.

## 2~4교시 25점 답안
## Ⅰ. 개요와 활용 범위
| 구분 | 핵심 |
|---|---|
| 정의 | LLM-as-a-Judge는 언어모델로 생성 결과를 기준에 따라 자동 평가하는 방법이다 |
| 목적 | 대량의 비정형 응답을 일정한 절차로 선별·비교한다 |

LLM-as-a-Judge는 판별 LLM이 답변을 기준에 따라 평가하도록 하는 방법이다. 자동화와 반복 평가에 활용할 수 있지만, 평가 기준의 적합성과 판별자의 신뢰성을 별도로 검증해야 한다.

| 평가 방식 | 활용 | 한계 |
|---|---|---|
| 단일 응답 채점 | 답변을 루브릭에 따라 점수화 | 점수 척도·판별자 간 일관성 |
| 쌍대 비교 | 두 답변의 상대 선호 판정 | 제시 순서·길이 편향 |
| 객관 지표·정답 비교 | 정답이 정해진 항목의 자동 검사 | 개방형 품질을 모두 나타내지 못함 |

## Ⅱ. 평가 프로토콜
```text
[질문·후보 답변]     [평가 기준·루브릭]
         |                    |
         +---------+----------+
                   v
           [LLM 판별자 평가]
                   | 점수·근거
                   v
         [결과 집계·일관성 점검]
                   | 표본·불일치 검토
                   v
           [사람 평가·기준자료]
```

쌍대 비교는 순서 교체 시험으로 위치 민감성을 확인할 수 있으나 편향을 완전히 제거하지는 않는다. 응답의 숨겨진 Chain-of-Thought를 요구하기보다, 판정에 사용한 짧은 근거와 루브릭 항목을 기록한다.

## Ⅲ. 편향·품질 통제
| 편향·위험 | 대응 방안 |
|---|---|
| 위치 편향 | 후보 순서를 교환해 반복 평가하고 불일치율 측정 |
| 장황함 편향 | 길이와 별개로 정확성·근거성·간결성 채점 |
| 자기 선호 편향 | 생성 모델 정보를 가리고 사람 기준 자료와 비교 |
| 점수 불안정·기준 불일치 | 루브릭 예시와 평가셋을 고정하고 판별자 간·인간 간 일치도 측정 |

한 연구에서 GPT-4 판별은 특정 평가 벤치마크의 인간 선호와 80% 이상 일치했으나, 이를 모든 모델·과업의 보장된 정확도로 일반화할 수 없다.

## Ⅳ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 모든 평가 결정을 자동 판별자 점수에 맡기면 주관적 기준과 중대한 오류를 놓칠 수 있음 | 반복 비교가 필요한 저위험 평가에 먼저 사용하고, 기준 정의와 중요한 배포 판단에는 사람 검토를 유지한다. |
