## 30초 인출

- 본질: **다크팩토리(Dark Factory)** 는 현장 상주 인력을 줄이고 자동화 설비·시스템 중심으로 생산하는 제조 운영 방식
- 메커니즘: 생산 지시·자재 투입 → 자동 공정·검사 → 설비 상태 관찰 → 생산·정비 조정

<details>
<summary>핵심 용어</summary>

- **다크팩토리(Dark Factory)** : 작업자 상주를 최소화하고 자동화 설비로 생산을 수행하도록 구성한 제조 운영 방식
- **라이트아웃 제조(Lights-out Manufacturing)** : 사람의 상시 현장 개입 없이 공정 가동을 지향하는 제조 방식; 조명을 실제로 끄는 것이 필수 조건은 아님
- **자율이동로봇(Autonomous Mobile Robot, AMR)** : 환경을 감지하고 이동 경로를 조정하며 작업 공간을 이동하는 로봇
- **예지정비(Predictive Maintenance, PdM)** : 설비 상태 자료를 이용해 고장 위험이나 정비 시점을 추정하는 접근
- **운영기술(Operational Technology, OT)** : 물리 설비·공정을 감시하거나 제어하는 하드웨어·소프트웨어
</details>

```text
생산 지시·자재 투입
```

### Ⅲ. 시스템 구성

| 영역 | 기능 |
|---|---|
| 생산 실행 | 설비·로봇의 작업 제어와 자재 이동 |
| 품질·상태 관찰 | 검사 결과·설비 데이터 수집 |
| 생산 관리 | 작업 지시·실적·재공·일정 관리 |
| 정비·안전 | 고장 감지·복구·작업자 접근 통제 |

### Ⅳ. 위험과 전환 관리

| 한계 | 대응 |
|---|---|
| 장애 시 상주 인력이 없어 복구가 지연될 수 있음 | 원격 진단·비상 출동·복구 절차와 예비 자원 마련 |
| 자동화 설비가 사람·주변 설비에 위해를 줄 수 있음 | 안전 인터록·비상정지·접근 통제와 정비 절차 검증 |
| OT 연결 확대가 공격·장애의 영향 범위를 키울 수 있음 | IT·OT 접근 분리, 자산·통신 관리, 사고 복구 훈련 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 공정별 변동성과 복구 역량을 확인하지 않고 무인화를 확대하면 작업 중단과 안전 부담이 커질 수 있음 | 반복성·예외 빈도·원격 복구 가능성을 기준으로 적합 공정을 고르고, 제한 가동에서 안전·품질·복구 지표를 확인하며 순차 확대 |
