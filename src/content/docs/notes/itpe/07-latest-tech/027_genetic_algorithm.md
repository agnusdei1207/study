## 한 줄 본질
- 수식이 복잡하거나 불연속적인 거대 탐색 공간에서 수학적 최적화 불가 → 후보 해들을 염색체로 인코딩하고 적자생존, 교차, 돌연변이를 반복 수행 → 준최적해(Near-optimal) 도출 / 파라미터 튜닝 부재 시 국소 최적해에 조기 수렴하는 한계

## 핵심 그림
```text
[유전자 알고리즘 진화 주기 (Evolutionary Cycle)]
+-------------------------------------------------------------+
| 1. 초기 개체군 생성 (랜덤 염색체 P_0: [10110], [01001], ...) |
+-------------------------------------------------------------+
                              |
+---------------------------->v
|               +-----------------------------+
|               | 2. 적합도 평가 (Fitness Calc) |
|               +-----------------------------+
|                             |
|               +-----------------------------+
|               | 3. 선택 (Selection)         | (룰렛 휠 / 토너먼트)
|               +-----------------------------+
|                             |
|               +-----------------------------+
|  다음 세대    | 4. 교차 (Crossover)         | (1점/다점/균등 교차)
|  (Generation) +-----------------------------+
|                             |
|               +-----------------------------+
|               | 5. 변이 (Mutation)          | (비트 반전, 전역 탐색)
|               +-----------------------------+

+--- [ 종료조건 미충족 ] <----+----> [ 종료: 최대 세대 도달 / 수렴 ] ===> 최적해 반환
```

## 핵심 용어
- 염색체(Chromosome): 최적화 문제의 하나의 후보 해(Candidate Solution)를 비트열, 실수 벡터, 순열 등으로 부호화(Encoding)한 것
- 룰렛 휠 선택(Roulette Wheel): 적합도 함수 값에 비례하여 원판의 면적을 할당하고, 적합도가 높은 우수 개체가 다음 세대에 선택될 확률을 높이는 기법
- 엘리티즘(Elitism): 교차와 변이 과정에서 최상위 적합도를 가진 우성 개체가 파괴되는 것을 방지하기 위해, 세대마다 최고 해를 변형 없이 그대로 다음 세대로 복제하는 전략

## 핵심 통찰
- 교차(Crossover)는 현재까지 찾은 좋은 해들의 특성을 조합하는 "활용(Exploitation)"이며, 변이(Mutation)는 새로운 영역을 찔러보는 "탐험(Exploration)"임
- 변이 확률을 너무 높게 잡으면 알고리즘이 단순 무작위 탐색(Random Search)으로 퇴화하고, 너무 낮게 잡으면 국소 최적점에 갇혀 조기 수렴 발생
- TSP(외판원 순회)처럼 중복 방문이 불가능한 제약조건이 있는 문제에는 단순 비트 교차가 불가능하므로, 순서 교차(PMX, Order Crossover) 기법을 사용해야 유효한 해 유지

## 이웃 토픽과 구분
- GA vs 경사하강법: 경사하강법은 목적함수가 연속적이고 미분 가능해야 하며 단일 점에서 시작 / GA는 미분 불가능하거나 이산적인 공간에서도 다수 개체군이 병렬로 전역 탐색 수행

## 문제·원인·대책
- 적용 상황: 복잡 물류 배송 경로 최적화(TSP) 문제 풀이 중 국소 최적점 고착
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 세대 초반 특정 우수 개체의 독점으로 다양성 상실 | 룰렛 휠 선택 시 초반 적합도 편차 과다(조기 수렴) | 토너먼트 선택(Tournament Selection) 또는 순위 선택(Rank) 적용 | 개체군 다양성 보존 및 조기 수렴 방지 |
| 교차 연산 후 중복 도시 방문 유효성 오류 | 이진 비트 교차 적용으로 순열 제약조건 위반 | 부분 매핑 교차(PMX) 및 순서 교차(OX) 연산자 적용 | 모든 노드를 정확히 1회만 방문하는 유효 염색체 생성 |
| 세대가 거듭되면서 이전 세대 최고 해 유실 | 무작위 교차와 변이 연산자에 의한 최적 유전자 파괴 | 엘리티즘(Elitism: 상위 1~2개 개체 무조건 보존) 적용 | 세대별 최고 적합도의 단조 증가(Monotonic) 보장 |

## 내 의견
- [국소 탐색 알고리즘과 결합한 밈틱 알고리즘(Memetic Algorithm) 적용] 유전 알고리즘은 전역 탐색(Global Search)에는 탁월하나 최적해 근처에서의 국소 정밀 탐색(Local Search) 수렴 속도가 느림 → 나라면: GA를 통해 유망한 전역 해 영역을 빠르게 좁힌 후, 세대 말기에는 2-opt나 경사하강법 같은 국소 탐색 기법을 결합하는 하이브리드 밈틱 최적화 전략 실행
