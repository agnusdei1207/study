- 메커니즘: 후보 집단 평가 → 부모 선택 → 자손 생성 → 제약·적합도 확인 → 종료 기준까지 반복
- 통찰: 한계: 적합도 높은 해만 남기면 집단 다양성이 줄고 국소 해에 정체 → 방안: 제약을 지키는 변이·선택으로 다양성과 성능 함께 확인

<details>
<summary>핵심 용어</summary>

- **유전자 알고리즘(Genetic Algorithm, GA)** : 후보 해 집단에 선택·교차·변이를 적용해 해를 탐색하는 최적화 기법
- **염색체(Chromosome)** : 후보 해를 비트열·실수 벡터·순열 등으로 표현한 구조
- **적합도 함수(Fitness Function)** : 후보 해의 목적 충족 정도를 점수로 평가하는 함수
- **교차(Crossover)** : 부모 후보의 일부 정보를 결합해 자손을 만드는 연산
- **변이(Mutation)** : 후보 일부를 바꾸어 탐색 다양성을 만드는 연산
- **엘리티즘(Elitism)** : 우수 후보 일부를 다음 세대에 보존하는 방식
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **유전자 알고리즘(Genetic Algorithm, GA)** 은 후보 해 집단에 선택·교차·변이를 반복 적용하는 확률적 최적화 기법 |
| 목적 | 복잡한 탐색 공간에서 목적에 맞는 후보 해 탐색 |

### Ⅱ. 탐색 절차

```text
초기 후보 집단 생성
         ↓
적합도 평가·부모 선택
         ↓
교차·변이로 자손 생성
         ↓
제약 확인·새 세대 구성
         ↓
종료 기준 확인 ── 미충족 시 반복
         ↓ 충족
후보 해 반환
```

### Ⅲ. 문제 표현과 연산

| 설계 요소 | 적용 기준 |
|---|---|
| 염색체 표현 | 문제 해의 구조에 맞는 비트열·실수 벡터·순열 등 선택 |
| 적합도 | 목적 함수와 제약 충족을 함께 평가 |
| 교차·변이 | 표현 형식과 문제 제약을 보존하는 연산 선택 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 빠른 선택 압력으로 다양성 감소·국소 해 정체 | 개체 유사도 감시와 제약을 지키는 변이·선택 조정 |
| 확률적 탐색 결과의 반복 실행 편차 | 같은 계산 예산에서 여러 난수로 품질·안정성 비교 |
| 기준 탐색법보다 나은지 불명확 | 휴리스틱·기존 최적화법과 동일 예산 기준선 비교 |

### Ⅴ. 제언

계산 예산과 종료 기준을 먼저 고정하고 반복 실행의 해 품질·제약 충족률로 채택 여부 결정.
