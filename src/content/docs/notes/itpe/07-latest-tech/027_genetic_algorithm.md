## 30초 인출

- 본질: **유전자 알고리즘(Genetic Algorithm, GA)** 은 다윈의 적자생존과 자연선택 진화 원리를 모방하여 비선형·비연속적 대규모 탐색 공간에서 최적해(Optimal Solution)를 확률적으로 탐색하는 메타휴리스틱 최적화 기법
- 메커니즘: 후보 해를 염색체(Chromosome)로 인코딩한 후 적합도(Fitness) 평가, 룰렛 휠 선택, 교차(Crossover), 돌연변이(Mutation), 엘리티즘 보존을 반복하며 세대(Generation) 진화 수행
- 통찰: 우수 개체로의 조기 수렴으로 인한 국소 최적해(Local Optima) 정체 위험이 상존하므로 적응형 돌연변이율(Adaptive Mutation) 및 섬 모델(Island Model) 분산 탐색 결합 필수

<details><summary>핵심 용어</summary>

- **유전자 알고리즘 (GA)** : 생물학적 유전 법칙과 자연선택을 공학적 최적화 문제에 사상한 집단 기반 확률 탐색 알고리즘.
- **염색체 (Chromosome)** : 문제의 잠재적 해를 표현하는 유전자들의 배열 (이진 스트링, 실수 벡터, 순열 등).
- **적합도 함수 (Fitness Function)** : 특정 염색체가 해결하고자 하는 목적식과 제약조건에 얼마나 부합하는지를 수치화하는 평가 척도.
- **교차 (Crossover)** : 두 부모 염색체의 유전자 일부를 교환하여 부모의 우수한 특성을 결합한 자손 염색체를 생성하는 유전 연산.
- **돌연변이 (Mutation)** : 유전자의 일부를 무작위로 변형하여 집단의 유전적 다양성을 유지하고 지역 최적해 탈출을 유도하는 연산.
- **엘리티즘 (Elitism)** : 세대 교체 시 가장 우수한 적합도를 가진 최상위 개체를 변형 없이 다음 세대에 그대로 보존하는 전략.

</details>

## 2~4교시 25점 답안

## Ⅰ. 유전자 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **유전자 알고리즘(Genetic Algorithm, GA)** 은 자연의 생물학적 진화 과정(자연선택, 유전, 돌연변이)을 모방하여 미분이 불가능하거나 탐색 공간이 방대한 NP-Hard 복합 최적화 문제에서 전역 최적해에 근접한 준최적해를 확률적으로 탐색하는 메타휴리스틱 알고리즘 |
| 목적 | 전역 탐색 공간의 효율적 탐험, 전통적 수리 계획법(경사하강법)의 국소 최솟값(Local Minima) 함정 탈출, 복잡한 제약조건 최적화 해결 |

## Ⅱ. 유전자 알고리즘의 핵심 특징 및 자연선택 진화 속성

| 구분 | 유전자 알고리즘의 특징 | 세부 공학적 메커니즘 및 속성 |
|---|---|---|
| **집단 기반 탐색 (Population-based)** | 다중 포인트 동시 탐색 | 단일 점 탐색이 아닌 수십~수백 개의 후보 해 집단을 동시에 유지하며 병렬 탐색 수행 |
| **블라인드 탐색 (Derivative-free)** | 목적함수의 도함수 불필요 | 목적식의 미분 가능성, 연속성 조건이 필요 없으며 순수 적합도 값(Fitness)만으로 평가 |
| **확률적 전이 규칙 (Stochastic)** | 확률적 연산자 적용 | 고정된 결정론적 규칙이 아닌 선택 확률, 교차율, 돌연변이율 등 확률적 매개변수 기반 전이 |
| **유전자 표현성 (Encoding)** | 문제 도메인의 유전자 사상 | 외판원 문제(TSP), 신경망 구조 탐색(NAS) 등 복잡한 구조를 순열 또는 실수 벡터로 유연하게 인코딩 |

## Ⅲ. 유전자 알고리즘 진화 연산 아키텍처 및 세대 전이 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 유전자 알고리즘 진화 연산 라이프사이클 ]              │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 1. 초기 개체군 생성 (Initial Population) ] : 무작위 N개 염색체 생성
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 2. 적합도 평가 (Fitness Evaluation) ] ──> 목적함수 기반 점수 산출     │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 ┌──────────────────────────────────┴──────────────────────────────────┐
 │                                                                     │
 ▼                                                                     ▼
[ 3. 우수 개체 보존 (Elitism) ]                               [ 4. 부모 선택 (Selection) ]
- 상위 5% 최우수 개체 다음 세대 직행                           - 룰렛 휠 / 토너먼트 선택
 └──────────────────────────────────┬──────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 5. 유전 연산자 적용 (Genetic Operators) ]                             │
│   ├── 교차 (Crossover: 확률 P_c = 0.8) ──> 부모 유전자 조합 자손 생성   │
│   └── 변이 (Mutation: 확률 P_m = 0.01) ──> 무작위 비트 반전 다양성 확보 │
└────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 6. 신규 세대 구성 및 종료 조건 판정 (Termination Check) ]            │
│   ├── (최대 세대 수 도달 or 적합도 수렴 시) ──> [ 최적 염색체 최종 반환 ]│
│   └── (미충족 시) ─────────────────────────> [ 2단계로 루프 회귀 ]      │
└────────────────────────────────────────────────────────────────────────┘
```

| 진화 단계 | 핵심 공학 기법 | 주요 역할 및 통제 변수 |
|---|---|---|
| **선택 (Selection)** | 룰렛 휠(Roulette Wheel), 토너먼트(Tournament) | 적합도가 높은 우수 개체가 부모로 선택될 확률 가중 |
| **교차 (Crossover)** | 1점 교차, 2점 교차, 균일 교차(Uniform) | 두 부모의 우량 유전자 블록(Building Block) 재조합 |
| **변이 (Mutation)** | 비트 반전(Bit Flip), 가우시안 섭동(Gaussian) | 미탐색 영역을 자극하여 유전적 고착화(Stagnation) 방지 |
| **대체 (Replacement)** | 세대 교체(Generational), 엘리티즘 보존 | 해 품질의 퇴보를 방지하고 탐색 단조 증가성 보장 |

## Ⅳ. 주요 유전 연산자(Selection vs Crossover vs Mutation) 비교

| 비교 항목 | 선택 (Selection) | 교차 (Crossover) | 변이 (Mutation) |
|---|---|---|---|
| **주요 역할** | 우량 개체 보존 및 유전 압력 부여 | 부모 형질 결합을 통한 유망 영역 탐색 | 미탐색 영역 자극 및 다양성 보존 |
| **동작 메커니즘** | 적합도 비례 확률적 샘플링 | 염색체 교차 분할 지점 스왑(Swap) | 유전자 값의 무작위 반전/치환 |
| **영향력** | 탐색 방향의 수렴 속도 결정 | 전역 탐색의 주된 동력 (Exploitation) | 국소 최적해 탈출 동력 (Exploration) |
| **연산자 확률** | 필수 적용 (1.0) | 통상 0.6 ~ 0.9 (높은 확률) | 통상 0.001 ~ 0.05 (낮은 확률) |
| **오류 시 위험** | 조기 수렴(너무 높음) / 방황(너무 낮음) | 우수 유전자 파괴(파괴적 교차) | 무작위 무작정 탐색(Random Search) 전락 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 세대 초기에 압도적인 적합도를 가진 소수 슈퍼 개체가 개체군 전체를 지배하여 국소 해에 갇히는 조기 수렴 | 적합도 순위 기반 선택(Rank Selection) 도입 및 개체 간 유사도를 측정하여 공유 패널티를 부여하는 피트니스 공유(Fitness Sharing) 적용 |
| 복잡한 제약조건(예: 외판원 문제의 중복 방문 금지) 위반으로 유효하지 않은 염색체 생성 | 순서 교차(Order Crossover: OX) 및 부분 일치 교차(PMX) 등 도메인 특화 연산자 채택 |

## Ⅵ. 제언

신경망 하이퍼파라미터 탐색(AutoML) 및 복잡한 물류 배차 최적화를 위해 개체군을 격리된 하위 군집으로 나누어 진화시키는 섬 모델(Island Model) 분산 유전자 알고리즘 구축.

```text
[ 섬 1 (Island A 개체군) ] ◄──(이민: Migration)──► [ 섬 2 (Island B 개체군) ]
            │                                             │
      (독자적 진화)                                 (독자적 진화)
            │                                             │
            ▼                                             ▼
[ 섬 3 (Island C 개체군) ] ◄──(이민: Migration)──► [ 섬 4 (Island D 개체군) ]
            │
            ▼ (주기적 상위 개체 교환을 통한 다양성 유지)
[ 전역 최적 신경망 구조(NAS) 도출 및 학습 수렴 속도 50% 향상 ]
```

| 구분 | 단일 거대 개체군 진화 | 제언: 분산 섬 모델 (Island Model) |
|---|---|---|
| **수렴 특성** | 단일 국소 최적해로 조기 수렴 빈발 | 각 섬마다 서로 다른 유망 영역을 독립 탐색 |
| **유전 다양성** | 세대 진행에 따라 급격히 소실 | 주기적 이민(Migration)을 통해 신선한 유전 형질 수혈 |
| **컴퓨팅 효율** | 단일 스레드 병목 발생 | 멀티 코어 및 분산 클라우드 환경에서 완벽한 병렬 처리 |
