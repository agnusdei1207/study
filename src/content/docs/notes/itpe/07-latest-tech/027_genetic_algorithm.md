## 연관 키워드

- 유전자 알고리즘(Genetic Algorithm), 메타휴리스틱(Meta-heuristic), 진화 연산
- 염색체(Chromosome), 적합도 함수(Fitness Function), 선택·교차·변이 연산
- 엘리티즘(Elitism), 조기 수렴(Premature Convergence), 파레토 해(Pareto Optimal)
- 룰렛 휠(Roulette Wheel), 토너먼트 선택, PMX, 아일랜드 모델(Island Model)

## Ⅰ. 유전자 알고리즘(Genetic Algorithm)의 개요

- 핵심 요약 : 자연선택 원리를 모사해 넓고 복잡한 탐색 공간에서 근사 최적해를 찾는 진화 연산 기반 메타휴리스틱.
- 개념 : 생물의 자연선택과 적자생존 원리를 모사하여, 세대(Generation)마다 선택·교차·변이 연산으로 후보 해 집단을 진화시키는 **진화 연산 메타휴리스틱** (Meta-heuristic) 기법.
- 배경 및 필요성 : 외판원 순회 문제(TSP, Traveling Salesperson Problem)처럼 조합이 폭증하는 문제는 전수 탐색이 어렵고, 경사하강법은 미분 가능성을 요구하며 **국소 최적점** (Local Minimum)에 갇히기 쉬움. 이에 확률적 전역 탐색이 필요해짐.
- 주요 목적 : 복잡한 제약 조건 아래에서 최적해를 근사 탐색하고, 국소 최적점을 벗어나며, 다목적 최적화에서 **파레토 해** (Pareto Optimal) 집합을 얻는 것.

## Ⅱ. 유전자 알고리즘(Genetic Algorithm)의 특징 및 장점

- 핵심 요약 : 후보 해 집단을 병렬로 탐색하고 확률적 연산으로 다양성을 유지하여, 미분 정보 없이도 전역 탐색이 가능한 구조.

1. 집단 기반 병렬 탐색 : 다수의 후보 해가 공간을 동시에 탐색 → 단일 시작점에 의존하는 방법보다 국소 최적점 고착 위험 감소.
2. 미분 불필요 : 목적 함수를 수치로만 평가하면 되므로 비선형·불연속 문제에도 적용 가능.
3. 확률적 변이 : 낮은 확률의 무작위 변경으로 새로운 해 영역을 탐색 → 전역 최적해에 접근할 기회 확보.
4. 다목적 최적화 확장 : 여러 목표를 동시에 고려한 개체 집합을 유지 → 파레토 해 집합 도출.

## Ⅲ. 유전자 알고리즘(Genetic Algorithm)의 구조 (흐름)

- 핵심 요약 : 초기 집단 생성, 적합도 평가, 선택, 교차, 변이를 순환하는 세대 반복 구조.

```text
[ 유전자 알고리즘 세대 진화 흐름 ]

초기 집단 생성 (Population Initialization)
          ↓
적합도 평가 (Fitness Evaluation)
          ↓
종료 조건 만족? ──Yes──► 최적 해 출력
          │ No
          ↓
선택 (Selection) → 교차 (Crossover)
          ↓
변이 (Mutation)
          ↓
다음 세대 집단 구성 → 적합도 평가로 복귀
```

- **염색체** (Chromosome) : 최적화할 파라미터 조합을 이진 문자열, 정수 순열, 실수 벡터로 인코딩한 개체.
- **적합도 함수** (Fitness Function) : 각 후보 해가 목표에 얼마나 부합하는지 수치로 평가하는 척도.
- **엘리티즘** (Elitism) : 세대 교체 과정에서 최상위 개체를 손실 없이 다음 세대로 그대로 이관하는 기법.

```text
[ 연산자별 대표 기법 ]

선택 ── 룰렛 휠 / 토너먼트 / 엘리티즘
교차 ── 단일점·다중점 / 균일 / PMX(순열용)
변이 ── 비트 반전 / 스왑 / 가우시안
```

## Ⅳ. 유전자 알고리즘(Genetic Algorithm)의 비교

- 핵심 요약 : 연산자 종류에 따라 수렴 속도와 다양성의 균형이 달라지므로, 문제 구조에 맞는 기법을 고른다.

| 연산자 | 대표 기법 | 동작 방식 | 장단점 |
| --- | --- | --- | --- |
| 선택 | 룰렛 휠 | 적합도에 비례한 면적으로 확률 추첨 | 직관적이나 조기 수렴 위험 |
| 선택 | 토너먼트 | K개를 무작위 추출해 최상위 1개 선택 | 계산이 가볍고 선택 압력 조절 용이 |
| 교차 | 단일점·다중점 | 교차점 기준으로 유전자를 잘라 교환 | 구조적 블록 보존에 유리 |
| 교차 | 균일 교차 | 자리마다 동전 던지기로 부모 결정 | 다양성 높으나 좋은 블록이 깨질 수 있음 |
| 교차 | PMX | 순열 중복을 막는 매핑으로 교환 | TSP 등 비정상 순열 생성 방지 |
| 변이 | 비트 반전·스왑·가우시안 | 일정 확률로 유전자 무작위 변경 | 국소 최적해 탈출 기제 |

- 경사하강법은 단일 시작점에서 경사를 따라 내려가고, 유전자 알고리즘은 다수 후보가 전 공간을 동시에 탐색하는 차이가 있다.

## Ⅴ. 유전자 알고리즘(Genetic Algorithm)의 한계와 방안

- 핵심 요약 : 조기 수렴, 제약 위반 해, 연산 부담이라는 세 한계를 연산자 설계와 병렬화로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 조기 수렴 | 초기에 우세한 개체가 집단을 장악 → 국소 최적점 고착 | 적합도 스케일링, **아일랜드 모델** (Island Model)로 집단 분리 후 이민 | 세대별 집단 다양성 |
| 제약 위반 해 다발 | 교차·변이 후 무효 해 생성 → 탐색 낭비 | **패널티 함수** (Penalty Function) 설계, 도메인 특화 수리 연산자 적용 | 무효 해 비율 |
| 연산 시간 증가 | 집단 크기와 시뮬레이션 평가 비용 증가 | 적합도 평가 병렬화(GPU·멀티코어), 소규모 집단 반복 적용 | 세대당 평가 시간 |

## Ⅵ. 유전자 알고리즘(Genetic Algorithm)의 기술사적 제언

- 핵심 요약 : 유전자 알고리즘은 단독 해법보다 다른 학습·탐색 기법과 결합하는 구성 요소로 도입하는 것이 바람직하다.

1. 하이브리드 탐색 : 전역 탐색은 유전자 알고리즘이 맡고, 세대 말에는 담금질 기법(Simulated Annealing)이나 지역 탐색으로 정밀 수렴을 보완하는 **멤틱 알고리즘** (Memetic Algorithm) 구조를 검토한다.
2. 신경망 구조 탐색 : 딥러닝 모델의 레이어 수와 채널 구성을 염색체로 두는 **신경망 아키텍처 탐색** (NAS, Neural Architecture Search)에 적용해 설계 공수를 줄인다.
3. 물류·설계 최적화 : 차량 경로 문제(VRP, Vehicle Routing Problem)나 반도체 배치 같은 현장 문제에서 인코딩과 적합도 함수를 도메인 전문가와 함께 설계한다.

## Ⅶ. 결론

- 핵심 요약 : 유전자 알고리즘은 진화 원리로 넓은 탐색 공간의 근사 최적해를 찾는 메타휴리스틱이다.
- 시사점 : 인코딩과 적합도 함수 설계가 성능을 좌우하므로, 문제 정의 단계의 설계 역량이 알고리즘 선택보다 중요하다.
