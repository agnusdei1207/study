<summary>핵심 용어</summary>

- **유전자 알고리즘(Genetic Algorithm, GA)** : 후보 해 집단에 선택·교차·변이를 적용해 해를 탐색하는 최적화 기법
- **염색체(Chromosome)** : 후보 해를 비트열·실수 벡터·순열 등으로 표현한 구조
- **적합도 함수(Fitness Function)** : 후보 해의 목적 충족 정도를 점수로 평가하는 함수
- **교차(Crossover)** : 부모 후보의 일부 정보를 결합해 자손을 만드는 연산
- **변이(Mutation)** : 후보 일부를 바꾸어 탐색 다양성을 만드는 연산
- **엘리티즘(Elitism)** : 우수 후보 일부를 다음 세대에 보존하는 방식
