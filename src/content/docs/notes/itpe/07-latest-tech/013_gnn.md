 ┃
 ┣━ Ⅰ 개요 ───── 유클리드 격자 데이터 한계 → 노드와 엣지로 표현되는 비유클리드 위상 관계 학습

## 한 줄 본질
- 행렬 형태의 정형/이미지 데이터만 다루는 CNN의 공간적 제약 극복 → 그래프 위상 구조에서 이웃 노드들의 정보를 집약(Message Passing)하여 관계적 특징을 학습 → 복잡한 네트워크 패턴 포착 / 계층이 깊어질수록 모든 노드 임베딩이 균일화되는 오버스무딩 발생

## 핵심 그림
```text
[GNN 메시지 패싱 (Message Passing) 원리]
  이웃 노드 (u ∈ N(v))                  중심 노드 (v)
       [ u_1 ] ----\
                    \
       [ u_2 ] -----> [ Aggregate 함수 ] ====> [ Update 함수 ] ====> h_v^(k)
                    /   (Mean, Max, Sum)       (MLP / GRU)          (새로운 노드 v 임베딩)
       [ u_3 ] ----/                              ^
                                                  |
                                             h_v^(k-1) (이전 상태)
```

## 핵심 용어
- 메시지 패싱(Message Passing): 각 노드가 연결된 이웃 노드들로부터 특성 벡터를 전송받아 집약하고 자신의 상태를 업데이트하는 핵심 연산
- 오버스무딩(Over-smoothing): GNN 층(Layer)을 여러 개 깊게 쌓을수록 노드 간 임베딩 벡터가 서로 비슷해져 구별 능력을 상실하는 현상
- GAT(Graph Attention Network): 이웃 노드의 메시지를 단순히 평균 내지 않고, 셀프 어텐션(Self-Attention) 메커니즘으로 이웃별 중요도 가중치를 동적으로 계산하는 모델

## 핵심 통찰
- CNN은 격자형(Grid) 데이터의 국소 불변성을 활용하는 GNN의 특수한 1차원/2차원 케이스에 해당
- 일반 딥러닝과 달리 층을 3~4개 이상 깊게 쌓으면 오버스무딩으로 인해 오히려 성능이 급락하므로, 얕은 레이어에 잔차 연결(Skip Connection)을 두는 것이 정석
- 전체 그래프를 한 번에 GPU 메모리에 올리는 풀배치 학습은 대규모 서비스에서 불가능 → GraphSAGE처럼 고정 크기 이웃 샘플링 미니배치가 필수

## 이웃 토픽과 구분
- GNN vs CNN: CNN은 고정된 크기의 격자 구조(Grid)에서 합성곱을 수행 / GNN은 정점마다 연결된 이웃의 수가 제각각인 비정형 비유클리드(Non-Euclidean) 그래프에서 합성곱을 수행

## 문제·원인·대책
- 적용 상황: 수억 명 사용자 대상 금융 사기(FDS) 이상 거래 그래프 탐지
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 계층 심화 시 노드 임베딩 구별 불가 | 4개 층 이상 중첩으로 인한 오버스무딩(Over-smoothing) | 잔차 연결(Residual Connection) 및 DropEdge(간선 무작위 제거) | 노드 고유성 보존 및 심층 레이어 학습 안정화 |
| 수천만 노드 그래프에서 OOM(Out Of Memory) | 풀배치 인접 행렬 연산 시 메모리 한도 초과 | GraphSAGE 기반 이웃 노드 균일 무작위 샘플링 | 고정 크기 미니배치 처리로 대규모 그래프 확장성 확보 |
| 차명 계좌 사기 노드와 정상 노드 혼동 | 모든 이웃 노드를 동일한 가중치로 평균 집약 | GAT(Graph Attention Network) 적용 | 사기 의심 엣지에 높은 어텐션 가중치 부여로 탐지율 제고 |
