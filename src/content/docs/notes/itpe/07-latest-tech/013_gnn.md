## 연관 키워드

- GNN(Graph Neural Network), 노드(Node), 엣지(Edge), 메시지 전달(Message Passing)
- GCN(Graph Convolutional Network), GAT(Graph Attention Network), GraphSAGE, GIN(Graph Isomorphism Network)
- 오버스무딩(Over-smoothing), 노드 분류, 링크 예측, GraphRAG, FDS, AML

## Ⅰ. GNN의 개요

- 핵심 요약 : 노드와 엣지로 이루어진 그래프 데이터에서 노드 특성과 연결 관계를 함께 학습하는 신경망.
- 개념 : 노드(Node)와 엣지(Edge)로 표현되는 그래프 구조 데이터를 입력받아, 이웃 노드 사이의 메시지 전달을 통해 노드 특성과 위상 관계를 동시에 학습하는 딥러닝 아키텍처 (**GNN**, Graph Neural Network).
- 배경 및 필요성 : 격자 구조의 이미지나 순차 구조의 텍스트와 달리 소셜 네트워크, 분자 구조, 금융 거래망, 지식 그래프는 불규칙한 연결 구조이므로 이를 직접 다루는 신경망이 필요해짐.
- 핵심 목적 : 노드 분류, 링크 예측, 그래프 분류 같은 관계 기반 과제의 정확도 향상.

## Ⅱ. GNN의 특징 및 장점

- 핵심 요약 : 이웃 정보를 집계하는 구조와 순서에 무관한 집계 함수가 관계 추론의 정확도와 적용 범위를 넓히는 방식.

1. **메시지 전달** (Message Passing) : 이웃 노드의 정보를 모아 자신의 표현을 갱신 → 연결 구조가 표현 학습에 직접 반영되어 관계 추론 정확도 향상.
2. 순열 불변 집계 : Sum, Mean, Max 같은 대칭 함수를 사용 → 이웃의 입력 순서가 바뀌어도 결과가 같아 학습이 안정적임.
3. 다양한 과제 적용 : 노드 분류, 링크 예측, 그래프 분류를 같은 구조로 수행 → 금융, 분자, 지식 그래프 등 여러 도메인에 재사용 가능.

## Ⅲ. GNN의 구조 (흐름)

- 핵심 요약 : 이웃 메시지를 집계하고 자신의 이전 상태와 결합하는 과정을 여러 층으로 쌓아 넓은 범위의 구조를 수용하는 구조.

```text
[ 메시지 전달 (Message Passing) ]

이웃 노드들의 이전 상태
   ↓
집계 (Aggregate) : Sum, Mean, Max
   ↓
갱신 (Update) : 자신의 이전 상태와 결합
   ↓
새로운 노드 임베딩
```

```text
[ 층을 쌓은 K-홉 이웃 확장 ]

1층 : 직접 연결된 이웃 정보 수용
   ↓
2층 : 이웃의 이웃 정보 수용
   ↓
K층 : K단계 떨어진 노드의 구조 정보 수용
```

- 노드 임베딩 활용 : 최종 임베딩은 분류기에 넣어 노드를 분류하거나, 두 노드 임베딩의 내적으로 링크 존재 확률을 예측하고, Readout 함수로 그래프 전체를 요약하는 데 쓰임.

## Ⅳ. GNN 모델 비교

- 핵심 요약 : 집계 방식이 이웃 가중치의 고정 여부, 샘플링 여부, 그래프 구조 판별 능력을 결정하므로 과제와 규모에 맞춰 고름.

| 모델 | 집계 방식 | 특징 | 한계 |
| --- | --- | --- | --- |
| **GCN** (Graph Convolutional Network) | 차수 기반 정규화 가중치로 이웃 특징을 평균 집계 | 계산 효율이 높아 GNN 입문용으로 널리 쓰임 | 모든 이웃에 고정 가중치를 부여함 |
| **GAT** (Graph Attention Network) | 셀프 어텐션으로 이웃별 중요도를 동적으로 계산 | 이웃마다 다른 가중치를 학습, 미학습 노드에도 적용 가능 | 어텐션 계산으로 메모리와 연산 부담 증가 |
| **GraphSAGE** (Sample and Aggregate) | 고정 크기의 이웃을 샘플링한 뒤 평균, Pool, LSTM(Long Short-Term Memory)으로 집계 | 대규모 그래프를 미니배치로 학습 가능 | 샘플링 과정에서 중요한 이웃이 빠질 수 있음 |
| **GIN** (Graph Isomorphism Network) | Sum 집계와 다층 퍼셉트론(MLP, Multilayer Perceptron) 결합 | 그래프 구조를 구별하는 능력이 강함 | 노드 단위보다 그래프 단위 분류에 특화됨 |

- 전역 그래프를 메모리에 한 번에 올리기 어려운 대규모 서비스에서는 샘플링 기반 방식이 실무에서 자주 선택됨.

## Ⅴ. GNN의 한계와 방안

- 핵심 요약 : 깊은 층의 표현 소실, 허브 노드의 연산 폭증, 동적·이종 그래프의 복잡도를 구조적 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 오버스무딩(Over-smoothing) | 층을 깊게 쌓으면 메시지가 반복 전달되어 노드 표현이 평균으로 수렴해 구별 불가 | 잔차 연결(Residual Connection), DropEdge 방식의 무작위 엣지 제거, 초기 입력을 보존하는 구조 | 노드 임베딩 분산, 검증 정확도 |
| 허브 노드로 인한 이웃 폭발 | 엣지가 많은 노드의 K-홉 확장 연산이 급증해 메모리 부족 발생 | 고정 수의 이웃만 추출하는 샘플링, 그래프 분할 기반 Cluster-GCN 학습 | 배치당 메모리 사용량 |
| 동적·이종 그래프 처리 | 엣지가 시간에 따라 생기고 사라지며 노드와 엣지 타입이 여러 개인 경우 학습이 어려움 | 관계 유형별 가중치를 분리하는 RGCN(Relational GCN), 시간 정보를 다루는 TGN(Temporal Graph Network) | 시점별 예측 정확도 |

## Ⅵ. GNN에 대한 기술사적 제언

- 핵심 요약 : 금융 이상거래 탐지에 우선 적용하고, 대규모 처리 인프라와 LLM 연계 구조를 함께 준비하는 방향.

1. 금융 영역의 FDS(Fraud Detection System)와 자금세탁방지(AML, Anti-Money Laundering) 업무에서는 계좌 간 다단계 송금 관계를 다루기 위해 관계 추론에 강한 GNN을 우선 검토하는 것이 필요함.
2. 정보시스템 부서는 수억 노드 규모의 그래프를 처리하기 위해 DGL, PyG 같은 그래프 라이브러리와 분산 학습 파이프라인을 표준화하는 것이 필요함.
3. 비정형 텍스트에서 엔터티와 관계를 추출해 지식 그래프를 만들고, GNN 기반 서브그래프 검색을 LLM 검색 구조에 연계하는 **GraphRAG** 방식이 환각 완화에 유효함.

## Ⅶ. 결론

- 핵심 요약 : GNN은 연결 구조를 학습 신호로 삼아 관계 중심 데이터를 다루는 신경망임.
- 시사점 : 관계 데이터가 핵심인 금융과 지식 영역에서 가치가 크며, 대규모 처리와 오버스무딩 관리가 실무 성패를 가름.
