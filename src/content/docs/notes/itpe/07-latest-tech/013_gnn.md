## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 모델 → 관계 데이터 학습 → 그래프 표현 학습 → **그래프 신경망(GNN)**

## 30초 인출

- 본질: **그래프 신경망(Graph Neural Network, GNN)** 은 노드·엣지의 관계를 따라 이웃 정보를 집약해 그래프 데이터를 학습하는 신경망
- 메커니즘: 이웃 정보 수집 → 메시지 계산·집약 → 노드 표현 갱신 → 과업별 예측

<details>
<summary>핵심 용어</summary>

- **그래프 신경망(Graph Neural Network, GNN)** : 그래프 연결 구조와 노드·엣지 정보를 학습에 반영하는 신경망
- **메시지 패싱(Message Passing)** : 각 노드가 이웃 정보를 모아 자신의 표현을 갱신하는 계산 구조
- **GCN(Graph Convolutional Network)** : 정규화된 이웃 정보를 집약해 노드 표현을 갱신하는 그래프 합성곱 모델
- **GAT(Graph Attention Network)** : 어텐션 가중치로 이웃별 중요도를 달리 반영하는 모델
- **GraphSAGE** : 이웃을 샘플링하고 집약해 대규모 그래프의 노드 표현을 학습하는 유도적 방법
- **오버스무딩(Over-smoothing)** : 층이 깊어지면서 노드 표현 간 차이가 줄어 구별력이 약해지는 현상
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **그래프 신경망(Graph Neural Network, GNN)** 은 그래프 연결 구조와 노드·엣지 정보를 학습에 반영하는 신경망 |
| 목적 | 개체 간 관계를 반영한 노드·엣지·그래프 표현 학습 |

### Ⅱ. 그래프 구성 정보

| 구성 | 학습에서의 역할 |
|---|---|
| 노드 | 개체와 개체별 속성 표현 |
| 엣지 | 개체 사이 연결·관계 표현 |
| 인접 관계 | 각 노드가 정보를 주고받을 이웃 결정 |

### Ⅲ. 메시지 패싱 절차

```text
이웃 노드·엣지 정보
          ↓
메시지 계산·집약 ──┐
                    ├→ 중심 노드 표현 갱신
중심 노드의 이전 표현 ┘
          ↓
과업별 노드·엣지·그래프 예측
```

### Ⅳ. 주요 모델과 적용 고려

| 모델·현상 | 핵심 작동·검토 사항 |
|---|---|
| **GCN(Graph Convolutional Network)** | 정규화한 이웃 정보를 집약해 노드 표현 갱신 |
| **GAT(Graph Attention Network)** | 어텐션 가중치로 이웃별 기여도를 반영 |
| **GraphSAGE** | 이웃 샘플링·집약으로 대규모 그래프 학습 지원 |
| **오버스무딩(Over-smoothing)** | 층이 깊어질수록 노드 표현이 비슷해질 수 있으므로 깊이별 검증 성능 확인 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 그래프 규모와 연결 분포가 달라지면 전체 이웃 계산 비용과 예측 성능이 함께 달라질 수 있음 | 대표 그래프 표본에서 샘플 수·층 수별 비용과 성능을 비교하고, 검증 결과에 맞는 집약 설정을 선택 |
