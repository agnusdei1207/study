## 30초 인출

- 본질: **GNN(Graph Neural Network, 그래프 신경망)** 은 격자 구조가 아닌 비유클리드 공간의 복잡한 노드(Node)와 엣지(Edge) 위상 구조를 반영하여 관계형 그래프 데이터의 임베딩 표현을 학습하는 딥러닝 아키텍처
- 메커니즘: 인접 노드 간 메시지를 계산(Message), 집약(Aggregate), 갱신(Update)하는 메시지 패싱(MPNN)을 반복하여 노드·링크·서브그래프 단위의 예측 수행
- 통찰: 신경망 층이 깊어질수록 모든 노드 임베딩이 평균화되어 변별력을 상실하는 오버스무딩(Over-smoothing)이 발생하므로 잔차 연결(Residual), JK-Net 및 드롭엣지(DropEdge) 결합 필수

<details><summary>핵심 용어</summary>

- **GNN (Graph Neural Network)** : 점(노드)과 선(엣지)으로 이루어진 비유클리디언 관계형 데이터를 학습하는 신경망 모델.
- **메시지 패싱 (Message Passing)** : 중심 노드가 인접 이웃 노드들의 특징 벡터를 모아서(Aggregate) 자신의 특징 벡터를 갱신(Update)하는 계산 패러다임.
- **GCN (Graph Convolutional Network)** : 정규화된 라플라시안 인접 행렬을 이용하여 고정된 이웃의 평균적 정보를 전파하는 1차 근사 합성곱 모델.
- **GAT (Graph Attention Network)** : 셀프 어텐션(Self-Attention) 메커니즘을 적용하여 이웃 노드별로 중요도 가중치를 동적으로 부여하는 모델.
- **GraphSAGE** : 전체 인접 행렬 연산 대신 균일 이웃 샘플링(Neighbor Sampling)과 집약 함수를 통해 미지의 대규모 그래프에도 일반화 가능한 귀납적(Inductive) 학습 모델.
- **오버스무딩 (Over-smoothing)** : GNN 레이어가 깊어질수록 반복된 이웃 집약으로 인해 노드 간 표현 벡터가 하나의 값으로 수렴되어 성능이 급락하는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. GNN의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **GNN(Graph Neural Network)** 은 텍스트나 이미지 같은 정형 격자(Grid) 구조를 벗어난 비유클리디언 공간의 복잡한 그래프 토폴로지(노드·엣지·속성)를 신경망 연산에 직접 매핑하여 임베딩을 학습하는 딥러닝 기술 |
| 목적 | 소셜 네트워크, 분자 구조, 지식 그래프, 금융 이상거래(FDS) 등 복합 관계형 데이터의 노드 분류, 링크 예측 및 그래프 수준 판별 수행 |

## Ⅱ. GNN의 핵심 특징 및 비유클리드 데이터 처리 속성

| 구분 | 핵심 특징 | 세부 공학적 메커니즘 |
|---|---|---|
| **비유클리드 공간 적응** | 불규칙한 위상 구조 수용 | 노드마다 이웃 수가 상이하고 위치 좌표가 없는 비대칭 관계형 위상을 완벽히 모델링 |
| **순열 불변성 (Permutation)** | 노드 순서와 무관한 일관성 | 노드의 입력 인덱스 순서가 바뀌어도 그래프 전체의 출력 임베딩 값은 불변(Invariance) 보장 |
| **공간적 지역성 (Locality)** | K-Hop 이웃 정보의 단계적 집약 | 층(Layer)을 쌓을 때마다 1-hop, 2-hop으로 정보 수용장(Receptive Field)을 점진적 확장 |
| **귀납적 학습 (Inductive)** | 미지의 신규 노드 일반화 | GraphSAGE 등을 통해 학습 시점에 없던 새로운 노드와 그래프 구조에도 즉각 임베딩 추론 가능 |

## Ⅲ. GNN 메시지 패싱(MPNN) 아키텍처 및 계층별 연산 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ GNN 메시지 패싱 (MPNN) 메커니즘 프레임 ]             │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 1. 이웃 노드 메시지 생성 ]         │ [ 2. 순열 불변 집약 (Aggregate) ]
    m_v^(k) = MSG(h_u^(k-1), e_uv)  │    M_v^(k) = AGG({m_v^(k) | u ∈ N(v)})
    (이웃 u의 상태와 엣지 특징 결합)   │    (Sum, Mean, Max, Attention 등)
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 3. 중심 노드 상태 갱신 (Update) ]                                    │
│    h_v^(k) = UPDATE(h_v^(k-1), M_v^(k))                                │
│    (중심 노드의 이전 상태와 집약된 이웃 메시지를 비선형 결합)          │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 ┌──────────────────────────────────┴──────────────────────────────────┐
 │                                                                     │
 ▼                                                                     ▼
[ 노드 수준 과업 (Node Task) ]                                [ 링크/그래프 수준 과업 ]
- 노드 분류 (고객 이탈, 이상 계정)                            - 링크 예측 (친구 추천, 약물 상호작용)
- 소프트맥스 분류기 연결                                      - Readout 풀링 기반 분자 독성 분류
```

| 연산 단계 | 수학적 표현식 | 공학적 의미 및 역할 |
|---|---|---|
| **Message** | $m_{uv}^{(k)} = M_k(h_u^{(k-1)}, h_v^{(k-1)}, e_{uv})$ | 인접 노드 u가 중심 노드 v로 보낼 특징 신호 계산 |
| **Aggregate** | $a_v^{(k)} = \bigoplus_{u \in \mathcal{N}(v)} m_{uv}^{(k)}$ | 순서에 무관한 대칭 함수(합/평균/최댓값)를 통한 메시지 결합 |
| **Update** | $h_v^{(k)} = U_k(h_v^{(k-1)}, a_v^{(k)})$ | 중심 노드의 기존 표현과 결합 메시지를 통과시켜 다음 층 임베딩 산출 |
| **Readout** | $h_G = R(\{h_v^{(K)} \mid v \in V\})$ | 전체 노드 임베딩을 풀링(Pooling)하여 단일 그래프 표현 벡터 도출 |

## Ⅳ. 주요 GNN 모델 비교

| 비교 항목 | GCN (Kipf & Welling) | GAT (Veličković et al.) | GraphSAGE (Hamilton et al.) |
|---|---|---|---|
| **이웃 반영 방식** | 정규화된 차수(Degree) 기반 평균 | Self-Attention 기반 동적 가중치 | 고정 크기 무작위 이웃 샘플링 |
| **가중치 특성** | 고정된 토폴로지 구조 가중치 | 노드 간 유사도에 따른 가변 가중치 | 집약 함수(LSTM, Pooling) 가변 학습 |
| **학습 방식** | 주로 Transductive (전체 그래프 필요) | Transductive 및 Inductive | 완벽한 Inductive (미지의 노드 적응) |
| **연산 복잡도** | $O(|E|Fd)$ (빠름) | $O(|V|FF' + |E|F')$ (상대적 높음) | $O(\prod S_k)$ (샘플 수 제어 가능) |
| **적합한 환경** | 중소 규모 고정 그래프, 학술 인용망 | 이웃 간 상대적 영향도가 다른 소셜망 | 거대 웹 그래프, 금융 이상거래 탐지 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 레이어가 4~5개 이상 깊어질 경우 모든 노드의 표현이 동일해져 구별력을 잃는 오버스무딩(Over-smoothing) | ResNet 유사 잔차 연결(Residual Connection), JK-Net(Jumping Knowledge), DropEdge(학습 중 무작위 엣지 제거) 기법 결합 |
| 실시간 수억 개 노드를 갖는 초대규모 그래프의 전체 인접 행렬 메모리 적재 불가(OOM) | 서브그래프 분할 미니배치 학습(Cluster-GCN) 및 분산 그래프 샘플링 프레임워크(PyG/DGL) 구축 |

## Ⅵ. 제언

금융 FDS 및 지능형 추천 시스템 구축 시 정형 테이블 피처와 GNN 관계 임베딩을 결합하는 멀티모달 하이브리드 추론 파이프라인 구축.

```text
[ 이기종 그래프 데이터 (고객-계좌-기기-IP) ]
                    │
                    ▼
[ GraphSAGE 기반 이웃 샘플링 임베딩 엔진 ]
   ├── Step 1: K-Hop 관계망에서 서브그래프 추출
   ├── Step 2: GAT 어텐션 기반 자금 세탁 위험 엣지 가중치 계산
   └── Step 3: 128차원 관계형 노드 임베딩 벡터 추출
                    │
                    ▼
[ Tabular Feature (거래금액, 시간) + GNN 임베딩 결합 ] ──> [ XGBoost/LightGBM 실시간 FDS 차단 ]
```

| 구분 | 전통적 테이블 기반 분석 | 제언: GNN 결합 하이브리드 파이프라인 |
|---|---|---|
| **분석 대상** | 단일 거래의 수치 및 통계적 피처에 국한 | 거래 주체 간 다차원 복잡 관계망 및 자금 흐름 추적 |
| **대포통장 탐지** | 점조직 형태로 분산 송금 시 탐지 불가 | 은닉된 공모 집단의 순환 그래프 토폴로지 탐지 |
| **설명가능성** | 룰 기반 차단으로 오탐 원인 규명 곤란 | GNNExplainer를 통한 핵심 위험 엣지 경로 시각화 |
