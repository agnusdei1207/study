## 30초 인출

- 본질: **스파이킹 신경망(SNN)** 은 생물학적 뇌의 신경망 동작을 모사하여 이산적인 스파이크 신호의 발생 시점과 빈도로 정보를 처리하는 제3세대 인공신경망 아키텍처
- 메커니즘: 시냅스 가중치 기반 입력 스파이크 통합 → 막전위 누적 및 시간 누설(LIF) → 임계 전위 도달 시 스파이크 발화 및 막전위 재설정
- 통찰: 계단형 발화 함수의 비미분성으로 역전파 직접 학습이 곤란하므로 대리 기울기(Surrogate Gradient) 기법 적용 및 뉴로모픽 코프로세서 매핑을 통한 초저전력 온디바이스 추론 구현

<details><summary>핵심 용어</summary>

- **스파이킹 신경망(Spiking Neural Network, SNN)** : 시간 축 상의 이산적 스파이크 펄스로 연산을 수행하는 제3세대 인공신경망 모델.
- **누설 적분 발화(Leaky Integrate-and-Fire, LIF)** : 유입 스파이크를 누적하면서 시간에 따라 전하가 누설되고 임계치에서 발화하는 뉴런 모델.
- **대리 기울기(Surrogate Gradient)** : 불연속적인 스파이크 발화 함수의 미분 불가능 문제를 극복하기 위해 역전파 시 연속형 함수로 근사하는 학습 기법.
- **뉴로모픽 칩(Neuromorphic Chip)** : 인간 뇌의 대규모 병렬성 및 이벤트 기반 초저전력 연산을 하드웨어로 구현한 반도체.
- **DVS(Dynamic Vision Sensor)** : 프레임 단위가 아닌 조도 변화 픽셀만 스파이크 형태로 비동기 출력하는 이벤트 기반 센서.

</details>

## 2~4교시 25점 답안

## Ⅰ. 스파이킹 신경망(SNN)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **스파이킹 신경망(SNN)** 은 뇌의 신경계를 모사하여 연속적인 실수값 대신 시간에 따른 이산적 스파이크(Spike) 신호 펄스를 기반으로 정보를 처리하는 제3세대 인공신경망 |
| 목적 | 이벤트 구동(Event-driven) 처리를 통한 연산 에너지 대폭 절감 및 시계열 센서 데이터의 고해상도 시공간적(Spatio-Temporal) 동역학 모델링 |

## Ⅱ. 스파이킹 신경망(SNN)의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **정보 표현** | 시간 부호화(Time Coding) | 스파이크 도달 시점(Time-to-First-Spike), 위상, 발화 빈도를 통한 복합 정보 인코딩 |
| **연산 특성** | 비동기 이벤트 구동 | 신호 발생 픽셀·뉴런만 활성화되어 유휴 상태(Idle) 시 전력 소비를 극단적으로 최소화 |
| **하드웨어 친화** | 덧셈 기반 누적 연산 | 연속 행렬 곱셈(MAC) 대신 스파이크 수신 시 가중치 덧셈(Accumulate) 연산만 수행 |
| **생물학적 타당성** | 시공간적 국소성(Locality) | 시냅스 가소성(STDP) 등 국소적 규칙에 기반한 자율적 신경망 가중치 조정 가능 |

## Ⅲ. 스파이킹 신경망의 LIF 뉴런 동작 및 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 스파이킹 신경망(SNN) LIF 뉴런 아키텍처 및 처리 흐름 ]         │
└────────────────────────────────────────────────────────────────────────┘
      │
      ▼
 [ 입력 스파이크 펄스열 ] (Input Spike Train: x_i(t) ∈ {0, 1})
      │
      ▼
 [ 시냅스 가중치 전달 ] ── (W_ij 곱셈 생략, 스파이크 도달 시 W_ij 덧셈 적분)
      │
      ▼
 [ 막전위 누적 및 누설 ] ── dV(t)/dt = -(V(t) - V_rest)/τ + Σ W_ij * x_i(t)
      │                   (시간 경과에 따른 감쇠 Leaky 특성 반영)
      ▼
 [ 임계치 비교 게이트 ]
      ├─ V(t) < V_threshold ──> [ 전위 유지 및 감쇠 ] (스파이크 미발화)
      │
      └─ V(t) ≥ V_threshold ──> [ 스파이크 발화 ] (Spike Fire: S(t) = 1)
                                      │
                                      ▼
                                [ 막전위 리셋 & 불응기 ] (V(t) <- V_reset)
```

| 처리 단계 | 세부 동작 메커니즘 | 공학적 의미 |
|---|---|---|
| **스파이크 입력** | 시간 축 상에서 0 또는 1의 바이너리 펄스 유입 | 부동소수점 데이터 전송 대비 버스 대역폭 절약 |
| **누설 적분(LIF)** | 누적 막전위가 시상수(τ)에 따라 기준 전위로 감쇠 | 과거 입력의 시간적 메모리 효과 및 잡음 필터링 |
| **스파이크 발화** | 막전위가 임계값 초과 시 다음 뉴런으로 즉시 신호 방출 | 임계값 조절을 통한 신경망 활성화 희소성(Sparsity) 제어 |
| **전위 초기화** | 발화 직후 재설정 전위로 복귀 및 일정 시간 불응기(Refractory) | 연쇄적 과발화 방지 및 에너지 효율 극대화 보장 |

## Ⅳ. 전통 인공신경망(ANN)과 스파이킹 신경망(SNN) 비교

| 비교 항목 | 전통 인공신경망 (ANN, 2세대) | 스파이킹 신경망 (SNN, 3세대) |
|---|---|---|
| **정보 전달 형태** | 연속적인 부동소수점(Float) 활성화 값 | 시간에 분산된 이산적 이진 스파이크(0/1) 펄스 |
| **기본 연산 단위** | 곱셈-누적(MAC, Multiply-Accumulate) 연산 | 덧셈 기반 누적(AC, Accumulate) 연산 |
| **시간 축 처리** | 정적 프레임 처리 (RNN 제외 시 시간 축 부재) | 본질적인 시간 축 동역학(Temporal Dynamics) 내재 |
| **에너지 효율** | 모든 뉴런 상시 연산으로 전력 소모 높음 | 이벤트 발생 시에만 동작하는 비동기 초저전력 |
| **학습 알고리즘** | 미분 기반 역전파(Backpropagation) 표준화 | 발화 함수 비미분성으로 대리 기울기 및 변환 기법 활용 |
| **구동 하드웨어** | GPU, NPU, TPU | Loihi 2, TrueNorth, BrainScaleS 등 뉴로모픽 칩 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 계단형 발화 함수의 비미분성으로 인한 표준 오차역전파 직접 적용 불가 및 학습 수렴 속도 저하 | 활성화 함수의 역전파 단계에서 평활화된 시그모이드 또는 삼각함수로 기울기를 근사하는 대리 기울기(Surrogate Gradient) 기법 적용 및 사전 학습된 ANN의 SNN 변환 파이프라인 수립 |
| 표준 GPU 환경에서 스파이크의 높은 희소성(Sparsity) 연산 효율 미비 및 하드웨어 가속 한계 | 비동기 크로스바 스위치와 온칩 SRAM 기반의 뉴로모픽 전용 가속기(Loihi, Akida) 활용 및 사건 기반 컴파일러 최적화 수행 |
| 스파이크 인코딩 과정(Rate Coding, Latency Coding)에서 발생하는 지연 시간 및 정보 손실 위험 | 다중 스파이크 위상 부호화(Phase Coding) 도입 및 DVS 등 네이티브 이벤트 기반 센서와의 직접 인터페이싱 구조 설계 |

## Ⅵ. 제언

에지 센서 단의 이벤트 기반 DVS(Dynamic Vision Sensor)와 온디바이스 뉴로모픽 SNN 프로세서를 결합한 실시간 초저전력 인지 아키텍처 수립.

```text
[ DVS 이벤트 센서 ] ──(비동기 픽셀 스파이크)──> [ SNN 전용 뉴로모픽 가속기 ]
                                                        │
                                                        ├─ 1단계: 온칩 대리 기울기 경량 추론
                                                        ├─ 2단계: 덧셈(AC) 전용 크로스바 가속
                                                        └─ 3단계: 임계치 초과 이벤트만 알람 송출
                                                        │
                                                        ▼
                                         [ 초저전력 상시 감시 IoT 에지 노드 ]
```

| 구분 | 기존 클라우드 GPU 기반 ANN 시스템 | 제언: DVS 센서 + SNN 뉴로모픽 에지 |
|---|---|---|
| **전력 소비** | 수십~수백 와트(W) 수준 상시 전력 소모 | 밀리와트(mW) 미만의 마이크로와트급 동작 가능 |
| **데이터 전송** | 대용량 고해상도 이미지 프레임 스트리밍 | 상태 변화 픽셀 이벤트만 비동기 희소 전송 |
| **응답 지연** | 프레임 수집 및 네트워크 왕복 지연 수십 ms | 마이크로초(μs) 단위의 즉각적 엣지 이벤트 반응 |
