## Ⅰ. 스파이킹 신경망(Spiking Neural Network, SNN)의 개요

- 개념 : 생물학적 뇌 신경계의 뉴런이 연속적인 수치 대신 시냅스를 통해 스파이크(Spike / 활동전위) 신호의 발생 타이밍과 빈도로 정보를 전달하는 메커니즘을 모사하여, 0과 1의 이진 펄스 이벤트를 비동기적으로 처리함으로써 극저전력 연산을 구현하는 3세대 인공신경망 아키텍처.
- 배경 및 필요성 : 2세대 인공신경망(ANN/DNN)의 부동소수점 곱셈-누적(MAC) 연산과 폰 노이만 구조의 메모리 병목으로 인한 막대한 전력 소모 한계를 극복하고, 초저전력 엣지 디바이스 및 뉴로모픽(Neuromorphic) 컴퓨팅을 실현하기 위해 대두됨.
- 핵심 목적 : 연산 에너지 소모량의 비약적 절감(밀리와트 단위 구동), 이벤트 기반 비동기 초저지연 신호 처리, 시간적 역학(Temporal Dynamics) 학습.

## Ⅱ. 스파이킹 신경망(SNN)의 핵심 아키텍처 및 동작 메커니즘

SNN은 뉴런 내부의 막전위(Membrane Potential)가 입력을 누적하다가 임계치(Threshold)를 초과할 때만 이진 스파이크를 방출하고 리셋되는 LIF(Leaky Integrate-and-Fire) 모델로 동작함.

```text
[ LIF 뉴런 모델 및 스파이크 이벤트 기반 연산 메커니즘 ]

  입력 스파이크 열 S_i(t)
          │
          ▼  가중치 곱 w_ij
  +---------------------------------------------------------------+
  | LIF (Leaky Integrate-and-Fire) 뉴런                           |
  |                                                               |
  |  1. 누적 (Integrate) : 입력 스파이크에 따라 막전위 V(t) 상승   |
  |  2. 누설 (Leak)      : 입력이 없으면 전위가 기저 상태로 감쇠  |
  |  3. 발화 (Fire)      : V(t) >= V_th 이면 스파이크 S(t)=1 방출  |
  |  4. 리셋 (Reset)     : 발화 직후 V(t) = V_reset 및 불응기 진입|
  +--------------------------------┬------------------------------+
                                   │ 스파이크 펄스 방출
                                   ▼
  +---------------------------------------------------------------+
  | 뉴로모픽 칩셋 연산 (Neuromorphic Event-Driven Computing)      |
  |  - 스파이크 발생 시에만 덧셈(Addition) 연산 수행 (AC 연산)    |
  |  - 스파이크가 없으면 연산 유휴 (Zero Dynamic Power)          |
  +---------------------------------------------------------------+
```

- **LIF(Leaky Integrate-and-Fire) 뉴런 수식** : 막전위는 `tau * dV/dt = -(V - V_rest) + R * I(t)`로 표현되며, 누설 감쇠와 전하 축적이 동시에 일어남.
- **이벤트 기반 연산(Event-Driven)** : 모든 뉴런이 매 클록마다 계산되는 ANN과 달리, 스파이크가 도착하는 순간에만 연산이 트리거되어 대기 전력 소모 극소화.
- **덧셈 기반 연산(Addition-only)** : 0 또는 1의 이진 스파이크를 전달하므로 무거운 곱셈(Multiply) 없이 단순 덧셈(Accumulate)만으로 시냅스 가중치 결합.
- **시간 정보 코딩(Spike Coding)** : 정보의 크기를 스파이크의 빈도(Rate Coding) 또는 최초 스파이크 도착 시간(Time-to-First-Spike / Temporal Coding)으로 인코딩.

## Ⅲ. 스파이킹 신경망(SNN)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 1세대 신경망 (Perceptron) | 2세대 신경망 (ANN / DNN) | 3세대 신경망 (SNN) |
| --- | --- | --- | --- |
| **신호 표현 방식** | 계단 함수 기반 이진 출력 (0 or 1) | 연속적인 실수 값 (Float32 / Float16) | 시간 축 상의 이진 스파이크 열 (Spike Train) |
| **활성화 함수** | Step Function | Sigmoid, ReLU, GELU | LIF, IF (임계치 초과 시 스파이크 방출) |
| **연산자 유형** | 단순 선형 결합 | 곱셈 및 누적 (MAC 연산자) | 이벤트 발생 시 단순 덧셈 (Accumulate 연산자) |
| **시간 축 반영** | 정적 (시간 개념 없음) | 순차 모델(RNN)에서 제한적 반영 | 신경망 자체에 물리적 시간 역학(Temporal) 내재 |
| **에너지 효율성** | 낮음 | 매우 낮음 (수백 와트 GPU 필요) | 극도로 우수 (밀리와트~마이크로와트 단위) |
| **대표 하드웨어** | 초기 전산기 | 범용 GPU, 텐서 NPU | 뉴로모픽 칩 (Intel Loihi, IBM TrueNorth) |

- ANN이 공간적 패턴 인식에 최적화된 고전력 실수 연산망이라면, SNN은 생체 뇌의 에너지 효율성과 시간적 인지 메커니즘을 모사한 초저전력 미래망임.

## Ⅳ. 스파이킹 신경망(SNN)의 주요 한계점 및 해결 방안

- 스파이크 발화 함수의 불연속성으로 인한 역전파(Backpropagation) 미분 불가 :
  - 한계점 : 계단 함수 형태의 스파이크 방출은 미분값이 0 또는 무한대가 되어 전통적 경사하강법 적용 불가.
  - 해결 방안 : 역전파 시에만 계단 함수를 부드러운 시그모이드나 아크탄젠트로 근사 미분하는 **대리 기울기** (Surrogate Gradient) 기법 적용.
- 폰 노이만 구조(CPU/GPU) 하드웨어에서의 SNN 시뮬레이션 비효율성 :
  - 한계점 : 범용 GPU는 조밀한 행렬 곱셈에 특화되어 있어 SNN의 비동기 희소 펄스를 시뮬레이션할 때 오히려 속도가 느림.
  - 해결 방안 : 시냅스와 뉴런이 물리적으로 통합된 **뉴로모픽 하드웨어** (Loihi 2, BrainScaleS) 전용 가속기 도입.
- 대규모 벤치마크 및 학습 프레임워크 생태계의 성숙도 부족 :
  - 한계점 : PyTorch 중심의 딥러닝에 비해 SNN 전용 라이브러리와 사전 학습 가중치가 부족함.
  - 해결 방안 : 기존 학습된 ANN 가중치를 SNN으로 손실 없이 변환하는 **ANN-to-SNN 변환** 기법 및 SpikingJelly 오픈소스 채택.

## Ⅴ. 스파이킹 신경망(SNN) 적용 및 발전을 위한 기술사적 제언

- 이벤트 기반 카메라(DVS)와 SNN의 엣지 센싱 결합 우선 추진 : 픽셀의 밝기 변화만 마이크로초 단위로 전송하는 동적 비전 센서(DVS)와 SNN을 결합하여 고속 자율주행 회피 센서 구축.
- ANN-SNN 하이브리드 아키텍처 도입 : 특징 추출은 고성능 딥러닝(CNN)이 담당하고, 시간적 패턴 분류 및 저전력 상시 대기 모드는 SNN이 처리하는 듀얼 코어 설계.
- 신체 삽입형 의료 기기 및 초소형 IoT 센서 표준 칩셋 채택 : 배터리 교체가 불가능한 심장 박동기, 스마트 렌즈 등에 SNN 뉴로모픽 프로세서를 탑재하여 장기 가동성 확보.
