<details>
<summary>핵심 용어</summary>

- **스파이킹 신경망(Spiking Neural Network, SNN)** : 시간·발화 사건을 신경망 계산에 반영하는 모델 구조
- **스파이크(Spike)** : 뉴런이 발화 조건을 충족했을 때 내보내는 이산 신호
- **누설 적분 발화(Leaky Integrate-and-Fire, LIF)** : 입력을 누적하고 시간에 따라 누설시키며 임계값에서 발화하는 뉴런 모델
- **대리 기울기(Surrogate Gradient)** : 불연속 발화 함수의 기울기를 근사해 학습하는 방법
- **뉴로모픽 하드웨어(Neuromorphic Hardware)** : 신경계의 사건 기반 처리를 참고해 설계한 계산 하드웨어
- **인공 신경망(Artificial Neural Network, ANN)** : 일반적으로 층별 연속 활성값 계산을 이용하는 신경망 계열

| 요소 | 동작 |
|---|---|
| 시냅스 | 입력 스파이크에 연결 가중치를 적용 |
| 막전위 | 입력 영향을 시간에 따라 누적·감쇠 |
| 임계값·초기화 | 발화 여부와 발화 후 상태 결정 |
| 네트워크 연결 | 층·회로 간 사건 신호 전달 |

### Ⅳ. 학습·하드웨어 적용

| 접근·조건 | 적용·확인 |
|---|---|
| 대리 기울기 | 발화 함수 기울기를 근사해 역전파 학습 |
| ANN-to-SNN 변환 | 변환 후 정확도·발화 횟수·지연 평가 |
| 뉴로모픽 하드웨어 | 이벤트 연산 지원 여부와 도구 체인 확인 |
| 비교 기준 | 목표 과업에서 정확도·에너지·지연을 기존 구현과 비교 |

사건 기반 구조만으로 에너지·속도 우위를 보장하지 않음. 결과는 인코딩·네트워크·학습·하드웨어 구현에 따라 달라짐.

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 시간 사건의 이점이 없는 과업에서는 SNN 구현 복잡도가 성능 개선으로 이어지지 않을 수 있음 | 시간 정보가 중요한 과업을 우선 선정하고, 목표 센서·하드웨어에서 ANN 기준선과 정확도·지연·에너지 측정 비교 |
