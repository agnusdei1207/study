<details>
<summary>핵심 용어</summary>

- **스파이킹 신경망(Spiking Neural Network, SNN)** : 시간·발화 사건을 신경망 계산에 반영하는 모델 구조
- **스파이크(Spike)** : 뉴런이 발화 조건을 충족했을 때 내보내는 이산 신호
- **누설 적분 발화(Leaky Integrate-and-Fire, LIF)** : 입력을 누적하고 시간에 따라 누설시키며 임계값에서 발화하는 뉴런 모델
- **대리 기울기(Surrogate Gradient)** : 불연속 발화 함수의 기울기를 근사해 학습하는 방법
- **뉴로모픽 하드웨어(Neuromorphic Hardware)** : 신경계의 사건 기반 처리를 참고해 설계한 계산 하드웨어
- **인공 신경망(Artificial Neural Network, ANN)** : 일반적으로 층별 연속 활성값 계산을 이용하는 신경망 계열
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **스파이킹 신경망(Spiking Neural Network, SNN)** 은 시간에 따라 발생하는 이산 스파이크 신호로 정보를 처리하는 신경망 |
| 목적 | 시간 정보·사건 입력이 중요한 과업의 신경망 표현·처리 |

### Ⅱ. LIF 뉴런 동작

```text
입력 스파이크
      ↓ 시냅스 가중치 반영
막전위 누적·시간 누설
      ↓ 임계값 비교
미달: 상태 유지·누설
초과: 스파이크 출력·전위 초기화
      └──── 다음 입력에서 반복
```

### Ⅲ. 뉴런·네트워크 요소

| 요소 | 동작 |
|---|---|
| 시냅스 | 입력 스파이크에 연결 가중치를 적용 |
| 막전위 | 입력 영향을 시간에 따라 누적·감쇠 |
| 임계값·초기화 | 발화 여부와 발화 후 상태 결정 |
| 네트워크 연결 | 층·회로 간 사건 신호 전달 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 시간 정보가 약한 과업에서 SNN 복잡도가 이득을 상쇄 | 시간 사건이 중요한 과업을 먼저 선정하고 ANN과 동일 조건 비교 |
| 발화 함수의 비미분성과 학습 어려움 | 대리 기울기 또는 ANN-to-SNN 변환 후 정확도·발화 횟수 평가 |
| 사건 기반 구조만으로 실제 에너지·속도 우위 불확실 | 목표 센서·하드웨어에서 인코딩을 포함한 에너지·지연 측정 |

### Ⅴ. 제언

시간 정보가 중요한 센서 과업부터 고르고 목표 장치에서 정확도·지연·에너지를 ANN 기준선과 비교.
