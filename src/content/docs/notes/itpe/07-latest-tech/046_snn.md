## 연관 키워드

- 스파이킹 신경망(SNN, Spiking Neural Network), 스파이크(Spike), LIF(Leaky Integrate-and-Fire), 뉴로모픽(Neuromorphic) 컴퓨팅
- 이벤트 기반 연산(Event-Driven Computing), 대리 기울기(Surrogate Gradient), ANN-to-SNN 변환, DVS(Dynamic Vision Sensor)

## Ⅰ. 스파이킹 신경망의 개요

- 핵심 요약 : 뉴런이 임계치를 넘을 때만 스파이크를 내보내 이벤트 단위로 계산하는 저전력 뉴로모픽 신경망 방식.
- 개념 : 생물 뇌의 뉴런이 **스파이크** (Spike, 활동전위)의 발생 시점과 빈도로 정보를 전달하는 방식을 모사한 **스파이킹 신경망** (SNN, Spiking Neural Network).
- 배경 및 필요성 : 인공신경망(ANN, Artificial Neural Network)과 심층 신경망(DNN, Deep Neural Network)은 곱셈-누적(MAC, Multiply-Accumulate) 연산과 폰 노이만 구조의 메모리 병목으로 전력 소모가 커, 엣지 기기에서 상시 구동하기 어려움.
- 주요 목적 : 연산 에너지 절감, 이벤트 기반 저지연 처리, 시간 축 정보의 학습으로 초저전력 **뉴로모픽** (Neuromorphic) 컴퓨팅 실현.

## Ⅱ. 스파이킹 신경망의 특징 및 장점

- 핵심 요약 : 이벤트 기반 희소 연산과 덧셈 중심 연산이 저전력과 저지연으로 이어지는 방식.

1. **이벤트 기반 연산** (Event-Driven Computing) : 스파이크가 도착할 때만 뉴런을 갱신 → 대기 전력이 거의 없어 상시 센싱에 유리.
2. 덧셈 중심 연산 : 0과 1의 스파이크만 전달 → 곱셈 없이 누적(AC, Accumulate) 연산만 수행해 연산 소모 감소.
3. 시간 역학 내재 : 막전위의 누설과 발화 타이밍이 신경망에 포함 → 시계열 신호 처리에 적합.

## Ⅲ. 스파이킹 신경망의 구조 (흐름)

- 핵심 요약 : 막전위가 입력을 누적하다 임계치에서 스파이크를 내고 리셋되는 **LIF** (Leaky Integrate-and-Fire) 뉴런이 기본 단위.
- 막전위 식은 tau * dV/dt = -(V - V_rest) + R * I(t)로 표현되며, 누설과 전하 축적이 동시에 일어남.

```text
[ LIF 뉴런 동작 ]

입력 스파이크 (가중치 곱)
   ↓
누적 (Integrate): 막전위 상승
   ↓
누설 (Leak): 입력 없으면 감쇠
   ↓
발화 (Fire): 임계치 도달 시 스파이크
   ↓
리셋 (Reset): 막전위 초기화, 불응기
```

```text
[ 이벤트 기반 처리 ]

스파이크 도착
   ↓
해당 시냅스 가중치만 덧셈
   ↓ 임계치 초과 시
다음 층으로 스파이크 전달
   ↓ 스파이크가 없으면
연산 유휴 (대기 전력 거의 없음)
```

- 정보 부호화 방식 : 발화율 부호화 (Rate Coding)는 스파이크 빈도로, 시간 부호화 (Temporal Coding)는 최초 스파이크 도착 시간으로 값을 표현.

## Ⅳ. 스파이킹 신경망과 기존 신경망의 비교

- 핵심 요약 : 연속 실수 연산 중심의 ANN에서, 시간 축을 가진 이진 스파이크 연산 중심의 SNN으로 신호 표현이 전환된 구조.
- 범용 GPU(Graphics Processing Unit)는 고전력 실수 연산에 맞춰져 있어, 저전력 목표에서는 SNN과 대비되는 특성을 보인다.

| 비교 축 | 퍼셉트론 (1세대) | 인공신경망 (2세대) | 스파이킹 신경망 (3세대) |
| --- | --- | --- | --- |
| 신호 표현 | 계단 함수 기반 이진 출력 | 연속 실수 값 | 시간 축 이진 스파이크 열 |
| 활성화 방식 | 계단 함수 | 시그모이드, ReLU, GELU | LIF, IF 임계치 발화 |
| 연산 유형 | 단순 선형 결합 | 곱셈과 누적 (MAC) | 이벤트 발생 시 덧셈 (AC) |
| 시간 축 반영 | 없음 | 순환 모델에서 제한적 | 신경망 자체에 내재 |
| 에너지 효율 | 낮음 | 높은 전력 필요 | 매우 우수 |
| 대표 하드웨어 | 초기 전산기 | 범용 GPU, AI 가속기 | 뉴로모픽 칩 (Intel Loihi, IBM TrueNorth) |

## Ⅴ. 스파이킹 신경망의 한계와 방안

- 핵심 요약 : 미분 불가능성, 범용 하드웨어 비효율, 생태계 미성숙을 대리 기울기, 뉴로모픽 칩, 변환 기법으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 역전파 적용 곤란 | 계단형 스파이크는 미분값이 0 또는 무한대라 경사하강법을 쓸 수 없음 | **대리 기울기** (Surrogate Gradient)로 역전파 때만 부드러운 함수로 근사 | 학습 정확도 |
| 범용 하드웨어 비효율 | GPU는 조밀한 행렬 연산에 특화되어 희소한 스파이크 시뮬레이션이 느림 | 뉴로모픽 칩(Intel Loihi 2 등) 전용 가속기 도입 | 스파이크당 소모 에너지 |
| 생태계 미성숙 | 전용 라이브러리와 사전학습 가중치가 부족 | **ANN-to-SNN 변환** 기법과 SpikingJelly 같은 오픈소스 프레임워크 활용 | 변환 후 정확도 손실률 |

## Ⅵ. 스파이킹 신경망에 대한 기술사적 제언

- 핵심 요약 : 고성능 ANN과 저전력 SNN을 역할별로 나누고, 이벤트 센서와 결합한 엣지 적용을 먼저 검증하는 방향.

1. 자율주행의 고속 회피처럼 빠른 변화 감지가 필요한 영역에서는 DVS 센서와 SNN을 결합한 엣지 센싱 구조를 우선 검증하는 것이 바람직하다.
2. 특징 추출은 합성곱 신경망(CNN, Convolutional Neural Network)이 맡고, 시간 패턴 분류와 상시 대기는 SNN이 맡는 하이브리드 설계를 표준 검토 항목으로 두는 것이 좋다.
3. 배터리 교체가 어려운 장치에는 뉴로모픽 칩셋을 시범 적용해 장기 가동성과 전력 특성을 실측으로 검증해야 한다.

## Ⅶ. 결론

- 핵심 요약 : SNN은 생체 뇌의 이벤트 방식을 빌린 초저전력 연산 패러다임으로, ANN을 대체하기보다 보완하는 위치.
- 엣지와 저전력 영역에서 실효성이 먼저 입증될 것이며, 범용 연산으로의 확장 여부는 하드웨어와 개발 생태계의 성숙도에 달림.
