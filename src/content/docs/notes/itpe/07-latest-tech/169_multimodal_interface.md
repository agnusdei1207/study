## 지식 로드맵 내 현재 위치

최신 기술 → 기술 개념·적용 → 멀티모달 인터페이스(Multi-Modal Interface)

## 30초 인출

- 본질: 음성·영상·동작·촉각 등 복수 입출력 채널을 결합해 사용자의 의도와 기기 반응을 연결하는 인터페이스. 여러 입력 수단을 결합해 사용자 의도를 해석하고 접근성을 높임.
- 메커니즘: 입력 수집·동기화 → 특징 추출 → 모달리티 융합 → 의도 판정·피드백.
- 통찰: 한계: 센서의 시간차나 결손을 무시한 융합은 의도를 잘못 판정한다 → 방안: 입력별 신뢰도·시간 정렬을 확인하고 고위험 명령에는 재확인과 폴백을 둔다.

<details><summary>핵심 용어</summary>

- **모달리티:** 음성·영상·동작 등 하나의 입력 또는 출력 채널
- **초기·후기 융합:** 특징을 먼저 합치는 방식과 모달리티별 판단을 나중에 합치는 방식

</details>

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 음성·영상·동작·촉각 등 복수 입출력 채널을 결합해 사용자의 의도와 기기 반응을 연결하는 인터페이스. |
| 목적 | 여러 입력 수단을 결합해 사용자 의도를 해석하고 접근성을 높임 |

## Ⅱ. 입력 융합과 명령 확인

```text
음성 ──특징·시각 정렬──┐
영상 ──특징·시각 정렬──┼→ 융합·신뢰도 → 의도 판단
동작 ──특징·시각 정렬──┘                 ↓
                               기기 반응·사용자 확인
```

1. **요구:** 음성·시선·제스처 입력을 도로 주행 맥락과 연결하되 운전 주의 분산과 명령 오작동 방지 우선.
2. **구조:** 센서별 수집과 동기화 → 잡음·가림 보정 → 맥락 융합 → 신뢰도 판단 → 고위험 명령 재확인·청각/시각 피드백.
3. **문제:** 소음·조도·동작의 시간 불일치와 일부 센서 결손, 사용자의 개인차와 연산 지연.
4. **통제:** 모달리티별 폴백, 지연·오인식률 시험, 민감 영상의 현장 처리·최소 저장, 접근성 평가.

## Ⅲ. 입력 융합 방식

| 구분 | 결합 시점 | 강점·제약 |
|---|---|---|
| 초기 융합 | 특징 추출 후 | 입력 상호작용 포착, 동기화 부담 |
| 후기 융합 | 모달리티별 예측 후 | 결손 입력에 유연, 상호작용 반영 제한 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 차량 소음으로 음성 명령 오인식 — 단일 음성 입력의 환경 의존 | 소음 억제와 다른 입력의 보완 가능성을 시험 |
| 대화 중 손짓이 명령으로 오인식 — 명령 의도와 일상 동작 구분 부족 | 명시적 호출어·확인 동작·위험 기능 승인 적용 |
| 음성·영상 동시 처리로 반응 지연 — 센서 동기화와 추론 비용 | 필요한 입력만 활성화하고 경량 모델·장치 성능 평가 |

## Ⅴ. 제언

- 차량용 멀티모달 기능은 운전자의 주의 분산, 음성·영상의 개인정보 처리, 오인식 시 안전한 복귀를 우선 설계. 모델 선택은 지연·정확도·오프라인 동작 시험 후 결정
