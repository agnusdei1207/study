## 30초 인출

- 본질: **데이터 차원 축소** (Dimensionality Reduction)는 고차원 데이터 공간에서 내재된 정보 손실을 최소화하면서 변수의 개수를 줄여 '차원의 저주'를 해결하는 특성 엔지니어링 기법
- 메커니즘: 특성 선택(Filter/Wrapper/Embedded) 및 특성 추출(선형 PCA/LDA, 비선형 t-SNE/UMAP/오토인코더) 기법을 통해 잠재 저차원 매니폴드 공간으로 투영
- 통찰: 전체 데이터셋에 차원 축소 변환기를 사전 적합할 경우 테스트 데이터 정보가 훈련 단계로 유입되는 데이터 누수(Data Leakage)가 발생하므로 교차 검증 파이프라인 내 훈련 분할 전용 적합 체계 구축 필요

<details><summary>핵심 용어</summary>

- **차원의 저주 (Curse of Dimensionality)** : 차원이 증가함에 따라 데이터 공간의 부피가 기하급수적으로 증가하여 데이터가 희소해지고 거리 척도가 왜곡되는 현상.
- **특성 선택 (Feature Selection)** : 원본 변수 중 타깃 예측에 가장 유용한 부분집합만을 선별하여 원래 변수의 물리적 의미를 보존하는 기법.
- **특성 추출 (Feature Extraction)** : 원본 변수들의 선형·비선형 결합을 통해 새로운 저차원 직교 좌표계를 생성하는 압축 기법.
- **PCA (주성분 분석)** : 데이터의 분산(Variance)이 최대가 되는 직교 기저 벡터(고유벡터)를 찾아 선형 투영하는 무지도 차원 축소 알고리즘.
- **데이터 누수 (Data Leakage)** : 모델 훈련 시점에 테스트 데이터셋의 통계 정보(평균, 분산, 주성분 등)가 의도치 않게 학습 파이프라인에 반영되는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 차원 축소의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 원본 고차원 피처 공간의 내재적 분산과 기하학적 구조를 보존하면서, 중요하지 않은 중복·노이즈 변수를 제거하여 저차원 공간으로 변환하는 특성 엔지니어링 기술 |
| 목적 | 차원의 저주 극복을 통한 연산 복잡도 감소, 다중공선성(Multicollinearity) 해소, 과적합 방지 및 데이터 시각화 용이성 확보 |

## Ⅱ. 데이터 차원 축소의 핵심 원리 및 기법 분류 특징

| 분류 영역 | 세부 기법 | 작동 원리 및 핵심 특징 |
|---|---|---|
| **특성 선택 (Selection)** | Filter, Wrapper, Embedded | 원본 변수 자체를 선별하여 도메인 해석 가능성(Interpretability) 완전 보존 |
| **선형 특성 추출 (Linear)** | PCA (주성분 분석), LDA (선형 판별 분석) | 고유값 분해(EVD) 또는 SVD 기반 직교 투영, 연산 효율 우수하나 비선형 왜곡 한계 |
| **비선형 매니폴드 (Non-linear)** | t-SNE, UMAP, Kernel PCA | 고차원 이웃 간 국소적/전역적 기하 거리를 저차원 확률 분포로 보존, 고차원 군집 시각화 특화 |
| **딥러닝 기반 추출** | 오토인코더 (Autoencoder), VAE | 인코더-디코더 병목 계층(Bottleneck)의 잠재 벡터(Latent Vector)를 통한 비선형 압축 |

## Ⅲ. 차원 축소 파이프라인 및 데이터 누수 방지 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 데이터 누수(Data Leakage) 방지를 위한 차원 축소 및 ML 파이프라인 ]   │
└────────────────────────────────────────────────────────────────────────┘

  [ 원천 고차원 데이터셋 ($X \in \mathbb{R}^{N \times D}$) ]
                     │
                     ▼ (엄격한 분할: 데이터 유출 차단)
      ┌──────────────────────────────┬──────────────────────────────┐
      ▼                              ▼                              ▼
  [ 훈련 데이터 ($X_{train}$) ]   [ 검증 데이터 ($X_{val}$) ]   [ 테스트 데이터 ($X_{test}$) ]
      │                              │                              │
      ▼                              │                              │
  [ 스케일러 & 차원 축소기 적합 ]     │                              │
  (StandardScaler + PCA Fit)         │                              │
      │                              │                              │
      ├──────────────────────────────┼──────────────────────────────┤
      ▼ (동일 변환기 Transform 적용) ▼                              ▼
  [ 저차원 훈련 데이터 ]         [ 저차원 검증 데이터 ]         [ 저차원 테스트 데이터 ]
  ($Z_{train} \in \mathbb{R}^{d}$) ($Z_{val} \in \mathbb{R}^{d}$) ($Z_{test} \in \mathbb{R}^{d}$)
      │                              │                              │
      ▼ (모델 훈련)                  ▼ (하이퍼파라미터 튜닝)        ▼ (최종 일반화 성능 평가)
  [ ML / DL 모델 학습 ] ─────────> [ 분산 보존율 검증 ] ─────────> [ 신뢰 가능한 최종 지표 ]
```

| 파이프라인 단계 | 엔지니어링 세부 수행 활동 | 통제 포인트 및 산출물 |
|---|---|---|
| **1. 데이터 분할** | 원천 데이터를 Train/Validation/Test 세트로 완벽 분리 | 계층적 K-Fold 분할 인덱스 |
| **2. 변환기 적합** | $X_{train}$ 데이터만으로 스케일러($\mu, \sigma$)와 PCA 고유벡터($V_k$) 계산 | Pipeline Fit 객체 |
| **3. 데이터 투영** | 학습된 변환기를 사용하여 $X_{val}, X_{test}$를 저차원 공간으로 변환 | $Z = X \cdot V_k$ 변환 행렬 |
| **4. 차원수 결정** | 주성분 누적 설명 분산 비율(Explained Variance Ratio $\ge 85\sim 95\%$) 확인 | 엘보우 차트(Elbow Plot) |
| **5. 모델 검증** | 차원 축소된 데이터로 최종 분류/회귀 알고리즘 학습 및 오차 평가 | 일반화 검증 오차(Test RMSE) |

## Ⅳ. 특성 선택 vs 선형 특성 추출 vs 비선형 매니폴드 비교

| 비교 항목 | 특성 선택 (Filter/Wrapper) | 선형 특성 추출 (PCA) | 비선형 매니폴드 (UMAP/t-SNE) |
|---|---|---|---|
| **변수 의미 보존** | 원본 변수 식별자 유지 (해석성 최상) | 변수들의 선형 결합으로 해석 난해 | 복합 비선형 매핑으로 축 의미 소실 |
| **연산 복잡도** | Filter는 낮음, Wrapper는 매우 높음 | $O(D^3)$ 또는 $O(D^2 N)$ 수준 | $O(N \log N)$ 내외로 대용량 시 부담 |
| **비선형성 반영** | 상호작용 검증 시 모델에 따라 가능 | 불가능 (선형 초평면 투영만 가능) | 매우 우수 (곡면 구조 완벽 보존) |
| **신규 데이터 투영** | 신규 데이터 즉시 필터링 가능 | 변환 행렬 곱으로 즉시 투영 ($Z=XW$) | t-SNE는 불가(재학습 필요), UMAP 가능 |
| **주요 활용 목적** | 비즈니스 KPI 도출, 의사결정 모델 | 차원 축소 전처리, 다중공선성 해소 | 고차원 임베딩 벡터 시각화, 군집 탐색 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 교차 검증 수행 전 전체 데이터셋에 대해 PCA를 사전 실행하여 검증 데이터 정보가 유출되는 데이터 누수 발생 | Scikit-Learn의 `Pipeline` 객체를 구성하여 교차 검증의 각 Fold 내부에서만 차원 축소기가 적합(fit)되도록 아키텍처 강제 |
| PCA 수행 시 분산이 큰 축이 반드시 타깃 레이블 분류에 유용한 축이라는 보장이 없어 유의미한 정보 손실 위험 | 지도학습 기반의 LDA(Linear Discriminant Analysis)를 병용하거나 타깃 상관성을 반영하는 PLS(Partial Least Squares) 기법 적용 |
| 특성 추출로 생성된 잠재 주성분의 비즈니스적 물리 의미 해석 불가능으로 현업 적용 저항 | L1 규제화 기반 Sparse PCA 도입 또는 SHAP/LIME 모델 해석 기법을 결합하여 원본 변수 기여도 역추적 체계 제공 |

## Ⅵ. 제언

데이터 분석 및 머신러닝 운영(MLOps) 시 차원 축소 전처리의 재현성과 무결성을 보장하기 위해, 자동화된 파이프라인 내에서 차원 축소-모델 학습-누수 모니터링을 단일 아티팩트로 관리하는 엔지니어링 체계 구축 필요.

```text
[ 데이터 수집 파이프라인 ]
            │
            ▼
[ MLOps 전처리 파이프라인 (Scikit-Learn Pipeline / Feast) ]
   ├── Step 1: 결측치 대체 및 원-핫 인코딩
   ├── Step 2: 훈련 데이터셋 단독 기준 RobustScaler 정규화
   ├── Step 3: 누적 분산 90% 보존 타깃 주성분 분석(PCA) 적합
   └── Step 4: 머신러닝 분류기(XGBoost / LightGBM) 결합
            │
            ▼
[ MLflow 모델 레지스트리 단일 파이프라인 패키징 서빙 ]
   - 신규 추론 데이터 유입 시 저장된 변환기로만 실시간 추론 실행
```

| 구분 | 비표준 수기 전처리 | 제언: MLOps 파이프라인 패키징 |
|---|---|---|
| **누수 통제** | 분석가의 실수로 전역 fit 호출 빈번 | Pipeline 객체 내부 격리로 누수 원천 차단 |
| **배포 환경** | 전처리 코드와 추론 모델 별도 배포 | 전처리+차원축소+모델을 단일 직렬화 파일 배포 |
| **차원 유지보수** | 데이터 변경 시 주성분 수동 재계산 | 분산 임계치 설정 기반 차원 수 자동 적응 |
| **서빙 지연** | 복잡한 고차원 연산으로 추론 지연 | 저차원 축소 벡터 서빙으로 추론 레이턴시 50% 단축 |
