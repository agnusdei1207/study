## 30초 인출

- 본질: **데이터 차원 축소은** 원자료의 변수 수나 표현 좌표를 줄여 분석에 필요한 정보를 간결하게 표현하는 방법
- 메커니즘: 원자료 표준화·분할 → 특성 선택 또는 특성 추출 → 정보 손실·모델 성능 검증
- 통찰: 한계: 전체 자료로 PCA를 적합하면 평가 정보가 훈련에 누수 → 방안: 훈련 분할에서만 변환기를 적합하고 검증·시험 자료에 동일하게 적용

<details><summary>핵심 용어</summary>

- **특성 선택** : 원래 변수 중 필요한 일부를 남기는 방법
- **특성 추출** : 원래 변수를 조합해 새 좌표·표현을 만드는 방법
- **PCA** : 분산을 많이 보존하는 직교 축으로 자료를 투영하는 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 차원 축소의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 차원 축소은** 원자료의 변수 수나 표현 좌표를 줄여 분석에 필요한 정보를 간결하게 표현하는 방법 |
| 목적 | 중복·잡음 특성을 줄이고 계산·시각화·일반화 조건 개선 |

## Ⅱ. 훈련 분할 기반 차원 축소·평가 구조

```text
원자료 ── 훈련/검증/시험 분리
           │ 훈련만 사용
           ▼
       표준화·차원 축소기 적합 ── 선택 변수 또는 투영 축
           │                         │ 동일 변환 적용
           ▼                         ▼
       축소 훈련 자료           축소 검증·시험 자료
           └──────── 모델 학습·성능/정보 손실 평가 ────┘
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 자료 준비 | 훈련·평가 자료 분리와 척도 확인 | 전체 자료로 변환기를 학습하는 누수 |
| 특성 선택 | 필터·모델 기반 변수 선별 | 상호작용 정보 누락 |
| 특성 추출 | PCA 등 새 좌표 생성 | 축 해석 어려움 |
| 검증 | 분산 보존·재구성·과제 성능 확인 | 분산이 곧 예측 유용성이라는 오해 |

## Ⅲ. 특성 선택과 특성 추출 비교

| 구분 | 차이 | 적용 판단 |
|---|---|---|
| 특성 선택 | 원래 변수의 의미 유지 | 선택되지 않은 변수 정보 손실 |
| 특성 추출 | 압축된 새 표현 생성 | 해석·역변환의 어려움 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 전체 데이터에 PCA를 먼저 맞추면 평가 자료 정보가 훈련에 섞임 | 훈련 분할에서만 변환기를 적합하고 같은 변환을 검증·시험 자료에 적용 |

## Ⅴ. 제언

자료 분할을 먼저 고정한 뒤 차원 수별 과제 성능과 정보 손실을 함께 비교하여 축소 범위를 결정.
