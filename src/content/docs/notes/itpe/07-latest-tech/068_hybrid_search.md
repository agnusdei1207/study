## 지식 로드맵 내 현재 위치

지식 위치: 정보 검색 → 어휘·의미 검색 결합 → **하이브리드 검색**

## 30초 인출

- 본질: **하이브리드 검색(Hybrid Search)** 은 어휘 일치와 벡터 의미 유사도를 결합하는 검색 방식
- 메커니즘: 같은 질의로 후보 검색 → 각 순위 산출 → 순위 융합 → 필요 시 재순위화

<details>
<summary>핵심 용어</summary>

- **하이브리드 검색(Hybrid Search)** : 어휘 검색과 벡터 검색 결과를 결합하는 검색 방식
- **BM25(Okapi Best Matching 25)** : 용어 빈도·역문서 빈도·문서 길이를 반영하는 어휘 검색 순위 함수
- **밀집 벡터 검색(Dense Vector Search)** : 질의·문서 임베딩의 유사도로 후보를 찾는 방식
- **RRF(Reciprocal Rank Fusion)** : 검색 결과의 순위를 결합해 후보를 재정렬하는 방법
- **재순위화(Reranking)** : 초기 후보를 더 정밀한 관련성 모델로 다시 점수화하는 단계

</details>

## 1교시 10점 답안

### Ⅰ. 하이브리드 검색의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **하이브리드 검색(Hybrid Search)** 은 어휘 일치와 벡터 의미 유사도를 결합하는 검색 방식 |
| 목적 | 정확한 용어와 의미상 유사한 문서를 함께 탐색해 검색 누락 완화 |

### Ⅱ. 검색·융합 흐름

```text
사용자 질의
   ├─ BM25 어휘 검색 ── 후보 순위 ─┐
   └─ 벡터 검색 ────── 후보 순위 ─┴─ RRF 융합 ── 최종 후보
```

BM25는 용어 일치, 벡터 검색은 임베딩 공간의 의미 유사성 단서를 활용. RRF는 검색기별 원점수가 아닌 순위 정보를 결합.

### Ⅲ. 두 검색 단서

| 방식 | 강점 | 주의점 |
|---|---|---|
| 어휘 검색 | 제품 코드·고유명사·정확 용어 | 동의어·다른 표현 누락 가능 |
| 벡터 검색 | 표현이 다른 의미상 유사 문서 | 숫자·식별자의 정확 일치가 약할 수 있음 |

**제언:** 정답 질의와 검색 로그를 이용해 어휘·벡터 검색의 기여를 비교하는 평가.

## 2~4교시 25점 답안

### Ⅰ. 하이브리드 검색의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **하이브리드 검색(Hybrid Search)** 은 어휘 일치와 벡터 의미 유사도를 결합하는 검색 방식 |
| 목적 | 정확한 용어와 의미상 유사한 문서를 함께 탐색해 검색 누락 완화 |

### Ⅱ. 검색·융합 흐름

```text
사용자 질의
   ├─ BM25 어휘 검색 ── 후보 순위 ─┐
   └─ 벡터 검색 ────── 후보 순위 ─┴─ RRF 융합 ── 최종 후보
```

### Ⅲ. 융합과 평가

```text
각 검색기의 순위
       │ RRF: 순위 역수 점수 결합
       ▼
통합 후보 순위
       │ 선택적 재순위화
       ▼
최종 검색 결과
```

대표적인 RRF 점수는 `RRF(d) = Σᵢ 1 / (k + rankᵢ(d))` 형태. 상수·후보 수는 실제 질의셋에서 검증.

| 평가 단계 | 지표·확인 항목 |
|---|---|
| 후보 검색 | Recall@k, 코드·고유명사 질의 적중 |
| 순위 품질 | nDCG·MRR 등 관련 문서 순위 |
| 근거 활용 | 응답의 자료 적합성·인용 정확성 |
| 운영 | 지연·색인 갱신·저장·연산 비용 |

### Ⅳ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 검색 기법을 동시에 추가하면 어느 단계가 품질을 높였는지 분리하기 어려움 | 어휘 검색·벡터 검색·융합·재순위화를 단계별로 추가하고, 각 단계의 기여가 확인된 구성만 운영에 남김 |
