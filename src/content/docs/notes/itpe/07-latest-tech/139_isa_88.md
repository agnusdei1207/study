## 지식 로드맵 내 현재 위치

지식 위치: 스마트 제조 → 배치 생산 → ISA-88

## 30초 인출

- 본질: **ISA-88 배치 제어은** 배치 생산에서 설비·공정·절차와 레시피를 공통 모델로 표현하는 표준 체계
- 메커니즘: 제품 요구·레시피 설정 → 절차 단위 실행 → 설비 단위 제어 → 배치 기록
- 통찰: 한계: 레시피 버전과 설비 매핑이 어긋나면 배치 재현성 저하 → 방안: 마스터·제어 레시피 승인 후 시험 배치로 설비 매핑 검증

<details><summary>핵심 용어</summary>

- **물리 모델** : 기업·사이트·영역·공정셀·유닛 등 설비의 계층 표현
- **절차 모델** : 프로시저·유닛 프로시저·작업·단계의 배치 실행 구조
- **레시피** : 제품을 만들기 위한 원료·공정·설비 요구의 기술

</details>

## 2~4교시 25점 답안

## Ⅰ. ISA-88 배치 제어의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ISA-88 배치 제어은** 배치 생산에서 설비·공정·절차와 레시피를 공통 모델로 표현하는 표준 체계 |
| 목적 | 제품 제조 절차와 설비 제어의 역할을 구분하여 배치 운영의 일관성 확보 |

## Ⅱ. 레시피·절차·설비의 배치 실행 구조

```text
마스터 레시피(제품별 제조 조건)
        │ 배치별 인스턴스 생성
        ▼
제어 레시피 ── 절차 → 유닛 절차 → 작업 → 단계
                         │          │
                         └─ 유닛 배정 ─┘
                                ▼
                        설비 제어와 배치 기록
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 물리 모델 | 실제 설비 자산과 제어 경계 정의 | 제품 절차와 설비를 혼동 |
| 절차 모델 | 프로시저에서 단계까지 실행 구조 분해 | 예외 경로 누락 |
| 레시피 | 일반·사이트·마스터·제어 레시피 관리 | 버전·승인 불일치 |
| 배치 기록 | 실행 조건과 결과를 추적 | 규정·품질 판단 근거 부족 |

## Ⅲ. ISA-88과 ISA-95의 역할 비교

| 구분 | ISA-88 | ISA-95 |
|---|---|---|
| 주된 범위 | 배치 생산의 설비·절차·레시피 모델 | 기업 업무와 제조 운영 사이의 정보 교환 |
| 적용 판단 | 동일 제품의 배치 실행·기록을 일관되게 할 때 | 생산 일정·성과·자원 정보를 상위 업무와 연결할 때 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 레시피 버전과 현장 설비 구성이 어긋나면 배치 간 재현성 저하 | 마스터·제어 레시피의 승인과 설비 매핑을 시험 배치에서 검증 |

## Ⅴ. 제언

제품별 마스터 레시피의 승인 기준을 먼저 정하고 설비 매핑과 배치 기록을 시험 생산에서 추적.
