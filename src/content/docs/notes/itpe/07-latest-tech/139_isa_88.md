## 30초 인출

- 본질: **ISA-88** (IEC 61512)은 화학·제약·식품 등 배치 공정에서 설비 능력과 제조 절차를 분리하여 모듈화 제어 및 재사용성을 표준화한 글로벌 배치 제어 규격
- 메커니즘: 물리 모델(Enterprise~Control Module), 절차 모델(Procedure~Phase), 레시피 모델(General~Control)의 3축 구조를 바탕으로 제어 로직과 제조 파라미터 매핑 실행
- 통찰: 다품종 소량 생산 전환 시 레시피 파라미터와 현장 PLC/DCS 설비 제어 모듈 간 태그 매핑 오류로 배치 재현성 저하가 발생하므로 마스터 레시피 버전 동기화와 전자 배치 기록(EBR) 기반 실시간 추적 체계 구축 필요

<details><summary>핵심 용어</summary>

- **ISA-88 (IEC 61512)** : 배치 공정 자동화 시스템 설계를 위한 물리 모델, 절차 모델, 레시피 모델 표준화 규격.
- **물리 모델 (Physical Model)** : Enterprise, Site, Area, Process Cell, Unit, Equipment Module, Control Module로 이어지는 설비 계층 구조.
- **절차 모델 (Procedural Model)** : Procedure, Unit Procedure, Operation, Phase로 구성된 순차 제어 실행 구조.
- **레시피 (Recipe)** : 특정 제품 배치를 제조하기 위해 필요한 원료, 공정 조건, 절차 및 장비 요구사항의 기술서.
- **전자 배치 기록 (EBR)** : 배치 생산 전 과정의 실제 파라미터, 실행 이력, 작업자 승인을 디지털로 저장하는 규제 준수 기록 체계.

</details>

## 2~4교시 예상문제 (25점)

> 스마트 팩토리 배치 생산 라인의 자동화와 유연성 확보를 위한 국제 표준인 ISA-88(IEC 61512)의 3대 핵심 모델(물리, 절차, 레시피)과 제어 메커니즘을 설명하고, ISA-95와의 연계 아키텍처 및 실제 공정 적용 시 엔지니어링 한계와 해결 방안을 논하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. ISA-88 배치 제어의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 화학·제약·식품 등 배치(Batch) 생산에서 설비의 물리적 구조와 제조 절차(레시피)를 분리하여 모듈 단위로 표준화한 국제 배치 제어 규격(IEC 61512) |
| 목적 | 제조 공정과 설비 제어 로직의 결합도 분리를 통한 다품종 유연 생산 지원, 엔지니어링 비용 절감 및 배치 품질 재현성 확보 |

## Ⅱ. ISA-88의 3대 핵심 모델 및 아키텍처 특징

| 핵심 모델 | 세부 구성 계층 | 주요 특징 및 역할 |
|---|---|---|
| **물리 모델 (Physical Model)** | Enterprise → Site → Area → Process Cell → Unit → Equipment Module → Control Module | 공장 전체 자산을 7개 계층으로 구조화, Unit 단위로 독립적인 제어 경계 설정 |
| **절차 모델 (Procedural Model)** | Procedure → Unit Procedure → Operation → Phase | 생산 절차를 4단계로 모듈화, Phase가 Equipment Module/Phase와 직접 통신 수행 |
| **레시피 모델 (Recipe Model)** | General Recipe → Site Recipe → Master Recipe → Control Recipe | 제품 사양에서 공장별·설비별 세부 파라미터로 구체화되는 4단계 계층 관리 체계 |

## Ⅲ. ISA-88 배치 제어 체계 및 레시피 구동 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ ISA-88 기반 배치 제어 아키텍처 및 레시피 구동 체계 ]                 │
└────────────────────────────────────────────────────────────────────────┘

  [ 레시피 모델 (Recipe Model) ]            [ 물리 모델 (Physical Model) ]
  ┌─────────────────────────┐              ┌─────────────────────────┐
  │ General / Site Recipe   │              │ Process Cell            │
  └────────────┬────────────┘              └────────────┬────────────┘
               ▼                                        ▼
  ┌─────────────────────────┐  유닛 자원 할당  ┌─────────────────────────┐
  │ Master Recipe           │ ────────────>│ Unit                    │
  └────────────┬────────────┘              └────────────┬────────────┘
               ▼ 배치 인스턴스 생성                     ▼
  ┌─────────────────────────┐  명령·상태 피드백┌─────────────────────────┐
  │ Control Recipe          │ <───────────>│ Equipment Module        │
  │ (Procedure/Phase)       │              │ (Heater, Agitator 등)   │
  └────────────┬────────────┘              └────────────┬────────────┘
               │ Phase 명령 실행                        ▼
               ▼                           ┌─────────────────────────┐
  ┌─────────────────────────┐              │ Control Module          │
  │ 전자 배치 기록 (EBR)    │ <─────────── │ (Valve, Sensor, Motor)  │
  │ (감사 추적 및 품질 데이터)│    실측 데이터 └─────────────────────────┘
  └─────────────────────────┘
```

| 실행 단계 | 처리 내용 | 주요 산출물 및 제어 기준 |
|---|---|---|
| **레시피 해석** | 마스터 레시피 기반 생산 계획에 맞춰 특정 라인용 제어 레시피 생성 | 제어 레시피 파라미터 시트 |
| **자원 할당** | 공정 셀 내 가용 Unit(반응기, 혼합기 등) 상태 확인 및 점유 | Unit 점유 락(Allocation Lock) |
| **Phase 구동** | 절차 모델의 최하위 Phase가 설비 모듈의 장비 Phase를 트리거 | PLC/DCS 제어 시그널 |
| **상태 전이** | Running, Paused, Holding, Aborting 등 ISA-88 상태 전이 모델 준수 | 장비 상태 머신 전이 로그 |
| **데이터 수집** | 온도, 압력, 투입량 실측 데이터 및 예외 알람을 전자 배치 기록에 저장 | 전자 배치 기록(EBR) |

## Ⅳ. ISA-88과 ISA-95의 계층적 연계 및 비교

| 비교 항목 | ISA-88 (Batch Control) | ISA-95 (Enterprise-Control System Integration) |
|---|---|---|
| **표준 성격** | ANSI/ISA-88, IEC 61512 | ANSI/ISA-95, IEC 62264 |
| **주요 영역** | 레벨 1~2(제어·센서) 및 레벨 3(배치 실행) 중심 | 레벨 3(MES/MOM)과 레벨 4(ERP/SCM) 인터페이스 중심 |
| **핵심 목적** | 배치 설비 제어 모듈화 및 레시피 실행 표준화 | 비즈니스 업무와 제조 운영 시스템 간 트랜잭션 표준화 |
| **데이터 모델** | 물리·절차·레시피 모델, Phase 상태 머신 | 자원(Personnel, Material, Equipment), 생산 일정·성과 모델 |
| **상호 관계** | ISA-95 B2MML(Business To MES Markup Language)을 통해 상위 생산 오더를 수신하여 ISA-88 제어 레시피로 분해 구동 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| PLC/DCS 벤더별 상태 머신(State Model) 구현 파편화로 이기종 설비 간 Phase 연동 지연 및 락 경합 발생 | PackML(PackTags) 및 OPC UA 정보 모델 기반의 장비 인터페이스 표준화로 벤더 중립적 제어 통신 규격 적용 |
| 마스터 레시피 버전 변경 시 현장 PLC 태그와의 불일치로 인한 오투입 및 배치 폐기 위험 | 레시피 라이프사이클 관리(RLM) 및 전자 서명(21 CFR Part 11) 기반의 변경 승인·배포 자동 검증 파이프라인 수립 |
| 비선형 공정 및 다중 공유 유닛(Shared Units) 환경에서 교착 상태(Deadlock) 발생 위험 | 동적 자원 예약 알고리즘 및 유닛 점유 매트릭스 사전 시뮬레이션 기반 자동 예외 처리 로직 결합 |

## Ⅵ. 제언

배치 공정의 민첩성과 규제 준수를 달성하기 위해 ISA-88 기반 레시피 라이프사이클 관리와 MES-DCS 수직 통합 체계를 구축하고, 무결점 전자 배치 기록(EBR)을 통한 실시간 배치 릴리즈 체계로의 전환 필요.

```text
[ ERP 생산 오더 (ISA-95) ]
            │
            ▼
[ MES / MOM (레시피 라이프사이클 관리) ]
   ├── Step 1: 마스터 레시피 승인 및 21 CFR Part 11 전자 서명
   ├── Step 2: 생산 라인별 가용 유닛 매핑 및 제어 레시피 변환
   └── Step 3: OPC UA 기반 제어 레시피 자동 다운로드
            │
            ▼
[ ISA-88 DCS/PLC 배치 엔진 (상태 머신 구동) ]
   ├── Unit 1 (원료 투입) ──> Unit 2 (가열·반응) ──> Unit 3 (여과·패키징)
            │
            ▼
[ 실시간 전자 배치 기록(EBR) 자동 생성 및 예외 검토(Review by Exception) ]
```

| 구분 | 전통적 포인트 제어 방식 | 제언: ISA-88/95 수직 통합 체계 |
|---|---|---|
| **레시피 변경** | PLC 로직 수기 하드코딩 재작업 | 마스터 레시피 파라미터 변경만으로 즉시 적용 |
| **설비 재사용성** | 설비 변경 시 제어 로직 전면 재개발 | 표준화된 Phase 모듈 재조립으로 즉각 대응 |
| **품질 검증** | 공정 종료 후 수기 배치 기록 검토 | 실시간 EBR 기반 이상치 예외 검토(Review by Exception) |
| **상위 연계** | 중간 DB를 통한 비표준 배치 데이터 교환 | B2MML 및 OPC UA 기반 실시간 양방향 수직 연계 |
