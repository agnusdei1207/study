## 연관 키워드

- ISA-88, IEC 61512, 배치 제어(Batch Control), 물리 모델, 절차 모델, 레시피 모델
- 마스터 레시피(Master Recipe), 제어 레시피(Control Recipe), Phase, Unit, Equipment Module, Control Module
- 전자 배치 기록(EBR), PackML, OPC UA, 레시피 라이프사이클 관리, 21 CFR Part 11, 교착 상태(Deadlock)

## Ⅰ. ISA-88 배치 제어의 개요

- 핵심 요약 : 설비의 물리 구조와 제조 절차를 분리해 배치(Batch) 생산을 모듈 단위로 표준화하는 국제 규격.
- 개념 : 화학·제약·식품 등 **배치 제어** (Batch Control) 영역에서 ISA(International Society of Automation)-88은 설비 구조와 제조 절차(레시피)를 분리하여 모듈 단위로 표준화한 규격이며, 국제 표준은 IEC(International Electrotechnical Commission) 61512로 채택됨.
- 배경 및 필요성 : 다품종 소량 생산으로 전환하면 레시피 파라미터와 PLC(Programmable Logic Controller)·DCS(Distributed Control System) 제어 로직 사이의 태그 매핑 오류가 늘어 배치 재현성이 떨어지므로, 마스터 레시피 버전 관리와 **전자 배치 기록** (EBR, Electronic Batch Record) 기반 추적 체계가 필요함.
- 주요 목적 : 공정 로직과 설비 제어의 결합도 축소, 다품종 유연 생산 지원, 엔지니어링 재작업 감소와 배치 품질 재현성 확보.

## Ⅱ. ISA-88 배치 제어의 특징 및 장점

- 핵심 요약 : 물리·절차·레시피를 계층으로 분리한 모델이 설비 재사용과 레시피 변경의 용이성으로 이어지는 구조.

1. 계층형 물리 모델 : 공장 자산을 Enterprise부터 Control Module까지 7단계로 구조화하고 Unit을 독립 제어 경계로 설정 → 설비 변경의 영향 범위가 Unit 안으로 한정되어 재설계 비용 감소.
2. 절차 모델 : Procedure, Unit Procedure, Operation, Phase의 4단계로 생산 절차를 모듈화 → 동일한 Phase를 여러 레시피에서 재사용.
3. 레시피 분리 : General Recipe에서 Control Recipe까지 4단계로 구체화 → 제품 사양이 바뀌어도 **마스터 레시피** (Master Recipe) 파라미터 수정만으로 반영.
4. Phase 기반 실행 : Phase가 Equipment Module과 명령·상태를 직접 주고받음 → 공정 상태를 일관된 기준으로 추적.

## Ⅲ. ISA-88 배치 제어의 구조 (흐름)

- 핵심 요약 : 레시피 계층이 Unit에 자원을 할당받아 Phase 명령으로 설비를 구동하고, 실측 데이터가 EBR로 돌아오는 순환 흐름.
- **물리 모델** (Physical Model) : Unit 단위로 독립 제어 경계를 설정하는 계층 구조.
- **레시피 모델** (Recipe Model) : 제품 사양에서 설비별 파라미터로 내려가는 4단계 관리 체계.

```text
[ 물리 모델 계층 ]

Enterprise (기업)
   ↓
Site (사이트)
   ↓
Area (영역)
   ↓
Process Cell (공정 셀)
   ↓
Unit (유닛) : 독립 제어 경계
   ↓
Equipment Module → Control Module
```

```text
[ 레시피 실행 흐름 ]

Master Recipe (마스터 레시피)
   ↓ 배치 인스턴스 생성
Control Recipe (제어 레시피)
   ↓ Phase 명령
Equipment Module (설비 모듈)
   ↓ 실측 데이터
전자 배치 기록 (EBR)
```

## Ⅳ. ISA-88 배치 제어와 기존 방식의 비교

- 핵심 요약 : 모듈형 배치 제어는 레시피와 설비 로직을 분리해 변경 비용과 추적 부담을 줄이는 방식.

| 비교 축 | ISA-88 모듈형 배치 제어 | 제어 로직 하드코딩 방식 |
| --- | --- | --- |
| 제어 로직 단위 | Phase 모듈 재사용 | 설비별 개별 로직 작성 |
| 레시피 변경 | 마스터 레시피 파라미터 수정 | PLC 프로그램 수정과 재배포 |
| 설비 변경 대응 | Unit 범위 안에서 모듈 재조립 | 관련 로직 전면 재작성 |
| 추적성 | 상태와 실측 값을 EBR로 표준 수집 | 담당자별 수기 기록 의존 |
| 품질 재현성 | 레시피 버전 기준으로 동일 실행 | 작업자와 로직에 따라 편차 발생 |

- 선택 기준 : 제품 종류가 자주 바뀌고 설비 변경이 잦은 공정일수록 모듈형 구조의 효과가 큼. 기업 계획 측과의 연계는 ISA(International Society of Automation)-95 인터페이스가 맡음.

## Ⅴ. ISA-88 배치 제어의 한계와 방안

- 핵심 요약 : 벤더 간 상태 머신 차이, 레시피 버전 불일치, 공유 자원 교착을 표준 인터페이스와 자동 검증으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 이기종 상태 머신 파편화 | 벤더마다 Phase 상태 구현이 달라 설비 간 연동 지연 발생 | **PackML** (Packaging Machine Language)과 **OPC UA** (OPC Unified Architecture) 정보 모델로 장비 인터페이스 표준화 | Phase 연동 지연 시간 |
| 레시피 버전 불일치 | 마스터 레시피 변경 후 현장 태그가 맞지 않아 오투입과 배치 폐기 발생 | 레시피 라이프사이클 관리와 변경 승인 자동 검증, 전자 기록·서명 요건(21 CFR Part 11) 준수 | 변경 후 오류 건수 |
| 공유 유닛 교착 | 다중 공유 유닛에서 자원 점유 순서가 엇갈려 **교착 상태** (Deadlock) 발생 | 자원 예약 알고리즘과 유닛 점유 상태의 사전 시뮬레이션으로 예외 처리 자동화 | 교착 발생 횟수 |

## Ⅵ. ISA-88 배치 제어에 대한 기술사적 제언

- 핵심 요약 : 레시피 관리 체계와 설비 제어 모듈화를 함께 추진해야 규격의 효과가 지속됨.

1. 제조 기업은 제품 변경이 PLC 로직 재작성이 아니라 마스터 레시피 파라미터 수정으로 끝나도록 레시피 관리 체계를 먼저 정비할 필요가 있다.
2. 설비 엔지니어링 조직은 표준 Phase 모듈 라이브러리를 사내에 축적해 신규 설비 도입 시 모듈 재조립 중심으로 설계하는 방식 정착 필요.
3. 품질 조직은 배치 기록을 사후에 전수 검토하는 대신 EBR 기반의 예외 중심 검토(Review by Exception) 체계로 전환하는 방향 추진 필요.

## Ⅶ. 결론

- 핵심 요약 : ISA-88은 공정과 설비를 분리해 배치 생산을 재사용 가능한 모듈로 바꾸는 규격임.
- 시사점 : 규격의 효과는 레시피 버전 관리와 추적 체계가 함께 갖춰질 때 지속되므로, 설비 표준화와 데이터 관리를 한 축으로 묶어 추진하는 것이 실효적.
