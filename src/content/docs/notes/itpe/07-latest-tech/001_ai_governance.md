## 지식 로드맵 내 현재 위치

07 최신 기술 → 인공지능 → AI 시스템의 책임 있는 기획·개발·도입·운영을 위한 관리

## 30초 인출

- 본질: **AI 거버넌스**는 AI의 가치와 위험을 조직의 책임·정책·통제로 관리하는 체계
- 메커니즘: 원칙·책임을 정하고, 사용 맥락별 위험을 평가한 뒤, 생명주기 단계마다 승인·감시·개선을 수행
- 핵심 관계: `책임·정책 → 위험평가 → 통제·승인 → 운영감시 → 개선`

<details>
<summary>핵심 용어</summary>

| 용어 | 설명 |
|---|---|
| **AI 거버넌스(AI Governance)** | 조직의 AI 사용에서 의사결정 권한·책임과 위험 통제를 정하는 관리 체계 |
| **AI RMF(Artificial Intelligence Risk Management Framework)** | NIST의 AI 위험 관리 프레임워크로 Govern·Map·Measure·Manage 기능을 제시 |
| **AIMS(Artificial Intelligence Management System)** | ISO/IEC 42001이 요구사항을 규정하는 AI 관리시스템 |
| **TEVV(Testing, Evaluation, Verification and Validation)** | AI 시스템의 성능·위험·요구 적합성을 시험·평가·검증·확인하는 활동 |
| **고영향 인공지능** | 국내 인공지능기본법에서 사람의 생명·신체·기본권에 중대한 영향을 미칠 수 있어 별도 의무 적용을 검토하는 법정 개념 |

</details>

```text

                                      │
```

| 구성 | 확인할 내용 |

## 2~4교시 25점 답안

## Ⅰ. AI 거버넌스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 조직의 AI 사용에서 의사결정 권한·책임과 위험 통제를 정하는 관리 체계 |
| 목적 | AI 활용 가치의 확보와 수용하기 어려운 위험의 예방·완화 |

## Ⅱ. 책임과 통제의 구성

```text
원칙·정책
   │ 정하는 기준
   ▼
책임자·승인자 ── 역할 분담 ── 각 생명주기 활동
                                      │
                                      ▼
                           평가·승인·운영 증적
```

| 구성 | 기능 |
|---|---|
| 원칙·정책 | 목적과 위험 기준 설정 |
| 책임·권한 | AI 시스템별 소유자·검토자·승인자 지정 |
| 생명주기 통제 | 각 단계의 평가·승인·운영 확인 |
| 증적·개선 | 판단 근거와 변경 이력 보존 및 재평가 |

## Ⅲ. 생명주기 위험관리

```text
사용 목적·대상 확인
        │
        ▼
영향·위험 평가 ──→ 필요한 통제와 평가 기준 결정
        │                         │
        └──────────┬──────────────┘
                   ▼
             검증·승인 결정
                   │
                   ▼
       운영 감시·사고 대응·변경 재평가
                   │ 결과 반영
                   └────────→ 정책·통제 개선
```

| 단계 | 핵심 확인 |
|---|---|
| 기획 | 사용 목적·대상·책임자와 적용 규정 |
| 개발·조달 | 데이터 권리·품질, 모델·공급자 위험, 요구사항 추적 |
| 검증·배포 | 성능·안전·보안·공정성 등 목적에 맞는 평가와 승인 근거 |
| 운영·변경 | 성능 변화·사고·오용 감시, 변경 시 영향 재평가 |
| 종료 | 접근권한·데이터·모델 처리와 기록 보존 조건 |

## Ⅳ. 프레임워크를 조직 통제로 연결

| 참조체계 | 답안에서의 역할 | 적용 시 확인 |
|---|---|---|
| NIST AI RMF | Govern·Map·Measure·Manage로 위험관리 기능 구성 | 조직·사용 맥락에 맞춘 자율 적용 범위 |
| ISO/IEC 42001 | AI 관리시스템의 요구사항과 지속 개선 틀 | 조직의 범위·정책·운영 통제와 증적 |
| 국내 인공지능기본법 | 국내 적용 대상과 법정 의무 확인의 기준 | 정의·대상·시행 규정의 현행 원문 |

프레임워크는 조직별 위험 판단을 돕는 참조 기준이며, 하나의 목록만으로 AI 시스템의 안전이나 법적 적합성이 자동 보장되는 것은 아님.

## Ⅴ. 운영상 한계와 개선 방향

| 한계 | 대응 |
|---|---|
| 외부 도구·현업 사용이 자산 목록에서 빠질 가능성 | 조달·개발·배포 절차와 AI 사용 목록을 연결하고 책임자 확인 |
| 평균 성능만으로 특정 사용자·환경의 위해가 가려질 가능성 | 사용 맥락과 영향 집단에 맞춘 평가 사례를 포함하고 결과 검토 |
| 배포 뒤 모델·데이터·사용 방식의 변경 누락 | 변경 이력과 운영 감시를 재평가·승인 절차에 연결 |
| 문서상 통제와 실제 운영 간 간극 | 표본 점검으로 승인 조건·운영 기록·사고 대응의 일치 확인 |

## Ⅵ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 여러 조직과 공급자가 관여하면 위험 판단과 변경 책임이 분산될 수 있음 | 주요 AI 사용 사례부터 책임자·승인권자·재평가 조건을 하나의 등록부에서 관리하고, 변경 시 관련 부서가 함께 확인하는 운영 절차를 제안 |
