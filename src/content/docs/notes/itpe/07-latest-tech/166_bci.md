## 지식 로드맵 내 현재 위치

인간·컴퓨터 상호작용 → 신경 신호 → BCI

## 30초 인출

- **본질:** BCI는 측정 가능한 신경 신호의 특정 패턴을 해석해 외부 기기 제어 입력으로 바꾸는 인터페이스이며, 임의의 생각을 모두 읽는 기술은 아님
- **메커니즘:** 신경 신호 수집 → 잡음 처리 → 의도 디코딩 → 기기 제어와 피드백
- **답안 초점:** 뇌-컴퓨터 인터페이스(BCI)의 구성과 침습형·비침습형의 차이를 설명하시오.

<details><summary>핵심 용어</summary>

- **BCI:** 측정한 신경 신호를 외부 기기 제어 입력으로 변환하는 인터페이스
- **디코딩:** 신호의 특정 패턴을 이용해 의도한 명령을 추정하는 과정

</details>

## 1교시 예상문제 (10점)

> 뇌-컴퓨터 인터페이스(BCI)의 구성과 침습형·비침습형의 차이를 설명하시오. (예상·10점)

---

## 1교시 10점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 신경 신호를 해석해 외부 기기 입력으로 바꾸는 인터페이스 |
| 목적 | 운동 기능 보조와 신경 기반 기기 제어 |

- **구성:** 신호 획득 → 잡음 제거·특징 추출 → 디코더 학습 → 장치 제어 → 사용자 피드백·재보정.
- **비교:** 침습형은 수술·장기 안전 관리가 필요한 전극 사용, 비침습형은 EEG 등 외부 센서로 신호 측정하되 잡음·공간 분해능 제약.

## 2~4교시 예상문제 (25점)

> 보조기기 제어용 BCI의 설계, 성능 평가와 안전·개인정보 위험 통제를 설명하시오. (예상·25점)

---

## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 신경 신호를 해석해 외부 기기 입력으로 바꾸는 인터페이스 |
| 목적 | 운동 기능 보조와 신경 기반 기기 제어 |

1. **요구:** 대상자의 운동 기능·잔여 신호·사용 환경과 수행할 명령의 수·오류 허용도를 정의.
2. **처리:** 센서 선택 → 신호 전처리 → 개인별 학습·보정 → 디코딩 → 명령 확인과 장치 피드백의 폐루프.
3. **평가:** 분류 정확도 외 오작동, 명령 지연, 재보정 빈도, 장기간 사용성·피로와 환경 변화의 영향 측정.
4. **통제:** 침습형의 수술·감염·재료 안정성, 비침습형의 착용 부담, 신경 데이터 최소 수집·암호화·동의 및 임상 감독.
