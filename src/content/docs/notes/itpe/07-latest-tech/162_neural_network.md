## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 가중합·비선형 활성화 함수를 층으로 연결한 학습 모델 |
| 목적 | 입력과 출력 사이의 복잡한 관계 학습 |

1. **모델:** 각 층에서 z=Wx+b, a=φ(z)를 계산하고 최종 출력과 정답 차이를 손실로 정의하는 함수 근사 구조.
2. **학습:** 자동 미분의 계산 그래프에 따라 손실을 각 매개변수로 미분하고, 학습률을 적용해 반복 갱신. 검증 데이터는 갱신에 사용하지 않는 분리 원칙.
3. **문제·대책:** 깊은 층의 기울기 소실에는 적절한 활성화·초기화·잔차 연결, 과적합에는 데이터 분할·정규화·조기 종료와 증강을 검토. 배치 정규화의 효과와 위치는 아키텍처에 종속.
4. **평가:** 독립 시험 집합과 과제별 지표, 오류 유형·편향, 데이터 분포 변화에 대한 성능 확인.
