## 지식 로드맵 내 현재 위치

기계학습 → 인공신경망 → 순전파·역전파

## 30초 인출

- 본질: 가중합과 비선형 활성화 함수를 층으로 연결하고 역전파로 매개변수를 학습하는 모델
- 메커니즘: 순전파 예측 → 손실 계산 → 역전파 기울기 → 최적화기의 가중치 갱신
- 통찰: 한계: 훈련 손실 감소만으로 일반화와 깊은 층의 안정적 학습을 보장할 수 없다 → 방안: 기울기·검증 손실을 관찰하고 초기화·잔차 연결·정규화와 독립 시험으로 확인한다.

<details><summary>핵심 용어</summary>

- **순전파:** 입력에서 층별 연산을 거쳐 예측을 구하는 과정
- **역전파:** 손실의 기울기를 연쇄 법칙으로 각 매개변수까지 계산하는 과정

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 가중합·비선형 활성화 함수를 층으로 연결한 학습 모델 |
| 목적 | 입력과 출력 사이의 복잡한 관계 학습 |

## Ⅱ. 순전파와 역전파의 학습 고리

```text
입력 → 가중합·활성화 층 → 예측
                           ↓ 정답과 비교
                          손실
                           ↓ 연쇄법칙 역전파
                       층별 가중치 갱신
```

- **모델:** 각 층에서 z=Wx+b, a=φ(z)를 계산하고 최종 출력과 정답 차이를 손실로 정의하는 함수 근사 구조.
- **학습:** 자동 미분의 계산 그래프에 따라 손실을 각 매개변수로 미분하고, 학습률을 적용해 반복 갱신. 검증 데이터는 갱신에 사용하지 않는 분리 원칙.

## Ⅲ. 학습 실패 유형과 조정 수단

| 현상 | 관련 요인 | 조정 방향 |
|---|---|---|
| 깊은 층의 기울기 소실 | 연쇄 미분의 신호 약화 | 초기화·활성화·잔차 연결 검토 |
| 검증 손실 증가 | 학습 자료 과적합 | 정규화·조기 종료·데이터 분할 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 훈련 손실 감소만으로 일반화와 깊은 층의 안정적 학습을 보장할 수 없다 | 기울기·검증 손실을 관찰하고 초기화·잔차 연결·정규화와 독립 시험으로 확인한다 |

## Ⅴ. 제언

- 깊은 층의 학습 안정성과 일반화 오류를 분리 관찰해 과제별로 가장 큰 실패 원인부터 조정한다.
