## 연관 키워드

- 신경망(Neural Network), 인공 뉴런(Artificial Neuron), 가중치(Weight), 편향(Bias), 활성화 함수(Activation Function)
- 순전파(Forward Pass), 역전파(Backpropagation), 손실 함수(Loss Function), 경사하강법(Gradient Descent)
- 기울기 소실(Vanishing Gradient), ReLU, GELU, 잔차 연결(Residual Connection), 드롭아웃(Dropout)
- 과적합(Overfitting), 조기 종료(Early Stopping), Grad-CAM, SHAP, XAI

## Ⅰ. 신경망(Neural Network)의 개요

- 핵심 요약 : 가중치로 연결된 뉴런 층이 비선형 활성화와 역전파 학습을 거쳐 입력과 출력의 복합 관계를 근사하는 기계학습 모델.
- 개념 : 생물 신경망을 단순화한 **인공 뉴런** (Artificial Neuron)이 여러 층으로 연결되고, 각 연결의 **가중치** (Weight)와 비선형 **활성화 함수** (Activation Function)를 통해 입력과 출력 사이의 관계를 학습하는 모델.
- 배경 및 필요성 : 층이 깊어지면 **기울기 소실** (Vanishing Gradient)이 생겨 입력층 쪽 학습이 멈추고, 파라미터가 많아 과적합이 쉽게 발생하므로, 활성화 함수 선택, 초기화, 잔차 연결, 정규화를 함께 설계할 필요가 있음.
- 주요 목적 : 이미지, 음성, 언어처럼 전통적 선형 모델로 풀기 어려운 고차원 비선형 문제에서 특징을 자동으로 추출하고 분류·예측하는 것.

## Ⅱ. 신경망(Neural Network)의 특징 및 장점

- 핵심 요약 : 층마다 비선형 변환을 쌓아 특징을 단계적으로 추출하므로, 사람이 특징을 설계하지 않아도 복잡한 패턴을 학습하는 특징.

1. 특징의 자동 추출 : 층이 낮은 단계의 선 같은 특징에서 높은 단계의 객체 개념까지 순서대로 표현 → 수작업 특징 설계 부담 감소.
2. 비선형 표현력 : 활성화 함수가 선형 결합을 깨뜨려 복잡한 경계를 표현 → 선형 모델이 풀지 못하는 문제에 적용 가능.
3. 오차 기반 학습 : 역전파로 출력 오차를 각 가중치에 나눠 전달 → 대량 데이터에서 파라미터를 자동 조정.

- 한 번의 학습 반복에서 순전파와 역전파가 번갈아 일어나는 흐름은 다음과 같다.

```text
[ 입력 X → 은닉층 → 출력 ŷ ] 순전파
        ↓
[ 손실 함수 L(y, ŷ) 계산 ]
        ↓
[ 연쇄 법칙으로 기울기 역전파 ]
        ↓
[ 옵티마이저로 가중치 갱신 ]
```

## Ⅲ. 신경망(Neural Network)의 구조 (흐름)

- 핵심 요약 : 입력층, 은닉층, 출력층이 가중합과 활성화를 반복하고, 손실에서 출발한 기울기가 역방향으로 흐르는 구조.
- 뉴런 계산 : 각 뉴런은 입력의 가중합에 편향을 더한 $z = W^T X + b$를 계산하고, 활성화 함수 $a = \sigma(z)$를 거쳐 다음 층으로 보낸다.
- 역전파 : 출력층의 기울기는 손실에서 가중치까지의 미분을 연쇄 법칙으로 곱해 구하며, 같은 방식으로 하위 층의 기울기를 차례로 구한다.

```text
[ 입력 X ]
        ↓ z1 = W1·X + b1, a1 = σ(z1)
[ 은닉층 1 ]
        ↓ z2 = W2·a1 + b2, a2 = σ(z2)
[ 은닉층 2 ]
        ↓ ŷ = σ(Wo·a2 + bo)
[ 출력층 ] → 손실 L 계산
        ↑ 기울기 역전파 (연쇄 법칙)
```

- 파라미터 갱신 : 계산된 기울기에 학습률을 곱해 가중치를 빼는 **경사하강법** (Gradient Descent) 방식으로 갱신하며, 실제로는 모멘텀과 적응형 학습률을 쓰는 옵티마이저를 사용한다.

## Ⅳ. 신경망(Neural Network)의 비교

- 핵심 요약 : 시그모이드는 기울기가 쉽게 줄고, 렐루는 계산이 가볍지만 음수 영역에서 뉴런이 죽을 수 있으며, 젤루는 두 문제를 완화하는 방식으로 트랜스포머 계열에서 널리 쓰임.

| 비교 축 | 시그모이드 (Sigmoid) | 렐루 (ReLU, Rectified Linear Unit) | 젤루 (GELU, Gaussian Error Linear Unit) |
| --- | --- | --- | --- |
| 수식 | 1 / (1 + e^(-z)) | max(0, z) | z × Φ(z) (Φ는 표준정규분포 누적 함수) |
| 출력 범위 | 0 ~ 1 (항상 양수) | 0 이상 | 음수 영역 일부 허용, 완만하게 변화 |
| 도함수 최댓값 | 0.25 | 1 (양수 영역) | 연속적으로 미분 가능 |
| 기울기 소실 | 층이 깊어질수록 심각 | 양수 영역에서 기울기 유지 | 음수 영역에서도 미세한 기울기 유지 |
| 뉴런 사멸 | 해당 없음 | 음수 입력이 계속되면 뉴런이 영구히 비활성화 | 부드러운 통과로 완화 |
| 대표 활용 | 로지스틱 회귀, 이진 분류 출력층 | CNN(Convolutional Neural Network), ResNet 계열 | BERT(Bidirectional Encoder Representations from Transformers), GPT 계열 트랜스포머 |

- 선택 기준 : 이진 분류의 출력층에는 시그모이드를, 은닉층에는 렐루나 젤루를 쓰는 것이 일반적이며, 트랜스포머 구조에서는 젤루 계열 변형이 주로 채택된다.

## Ⅴ. 신경망(Neural Network)의 한계와 방안

- 핵심 요약 : 기울기 소실, 과적합, 설명 불가능성을 활성화·초기화·잔차 연결, 정규화와 조기 종료, 설명 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기울기 소실 | 시그모이드 미분값이 층마다 곱해져 입력층 기울기가 0에 가까워짐 | 렐루·젤루 활성화, He·Xavier 초기화, **잔차 연결** (Residual Connection)으로 입력을 출력에 직접 전달 | 층별 기울기 크기 |
| 과적합 | 깊고 큰 모델이 훈련 데이터의 잡음까지 암기 | **드롭아웃** (Dropout)으로 뉴런을 무작위로 끄고, L2 가중치 감쇠와 검증 손실 기준 **조기 종료** (Early Stopping) 적용 | 훈련과 검증 손실의 격차 |
| 블랙박스 문제 | 수많은 비선형 가중치 때문에 판단 근거를 사람이 역추적하기 어려움 | **Grad-CAM**으로 주목 영역을 시각화하고, 설명 가능 AI(XAI, Explainable Artificial Intelligence) 기법으로 SHAP(SHapley Additive exPlanations)과 SHAP(SHapley Additive exPlanations)과 LIME(Local Interpretable Model-agnostic Explanations)으로 입력별 기여도 분석 | 설명 기법 적용률, 설명 검토 건수 |

## Ⅵ. 신경망(Neural Network)에 대한 기술사적 제언

- 핵심 요약 : 활성화와 초기화를 표준 설정으로 고정하고, 설명 가능성과 검증 절차를 모델 운영의 필수 요소로 포함해야 함.

1. 표준 학습 설정의 고정 : 활성화 함수와 초기화 방식을 팀의 기본 레시피로 정해 두고, 실험마다 달라지는 변수를 줄여 재현성을 확보해야 한다.
2. 설명 가능성의 운영 포함 : 의료·금융처럼 판단 근거가 필요한 영역에서는 Grad-CAM이나 SHAP 결과를 검토 기록과 함께 보관해야 한다.
3. 과적합 감시 체계 : 검증 데이터의 손실과 정확도를 학습 중 상시 기록하고, 격차가 커지면 학습을 멈추는 기준을 사전에 정의해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 신경망은 가중치와 비선형 활성화로 복잡한 입출력 관계를 학습하는 모델이며, 학습 안정성은 활성화, 초기화, 잔차 연결의 조합에서 나옴.
- 시사점 : 모델의 성능보다 학습을 안정적으로 재현하고 판단 근거를 설명할 수 있는지가 실제 도입의 기준이 되므로, 설계 단계에서 이 두 가지를 함께 확보해야 한다.
