## Ⅰ. LoRA / PEFT의 개요

- 개념 : 사전학습된 거대 신경망의 원본 가중치를 완전 동결하고 가중치 변화량($\Delta W$)만을 랭크 $r$의 저순위 분해 행렬($B \times A$)로 우회 학습하는 **파라미터 효율적 미세조정** (PEFT, Parameter-Efficient Fine-Tuning) 기술
- 배경 및 필요성 : 과업별 어댑터 파편화로 인한 서빙 VRAM(Video Random-Access Memory) 낭비 및 추론 지연이 발생하므로 단일 베이스 모델 위에서 요청별 어댑터를 실시간 교체하는 **S-LoRA**(Serving LoRA, Low-Rank Adaptation) 멀티 테넌트 서빙 체계 구축 필수
- 핵심 목적 : 수십 GB 이상의 **옵티마이저 메모리** (Adam State) 오버헤드 절감 및 단일 GPU(Graphics Processing Unit) 기반 엔터프라이즈 LLM(Large Language Model) 맞춤화 실현

## Ⅱ. LoRA / PEFT의 핵심 아키텍처 및 동작 메커니즘

LoRA / PEFT는 거대 가중치 행렬의 갱신량 $\Delta W$를 두 개의 **저랭크 행렬곱** $B \times A$ ($r \ll d$)로 분해하고 **스케일링 계수** $\alpha/r$을 곱하여 기존 고정 가중치와 합산 추론 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             LoRA 및 QLoRA 신경망 순전파(Forward) 아키텍처              │
└────────────────────────────────────────────────────────────────────────┘
                    [ 입력 텐서 (Input Token Vector: x) ]
                                    │
                  ┌─────────────────┴─────────────────┐
                  ▼                                   ▼
   ┌─────────────────────────────┐     ┌─────────────────────────────┐
   │ 동결된 원본 가중치 (Frozen)  │     │ 저순위 다운프로젝션 행렬 A  │
   │ W_0 ∈ R^(d × k)             │     │ A ∈ R^(r × k)               │
   │ [QLoRA 시: 4-bit NF4 양자화]│     │ (가우시안 랜덤 초기화)      │
   └──────────────┬──────────────┘     └──────────────┬──────────────┘
                  │                                   │ (r 차원 축소 텐서)
                  │                                   ▼
                  │                    ┌─────────────────────────────┐
                  │                    │ 저순위 업프로젝션 행렬 B    │
                  │                    │ B ∈ R^(d × r)               │
                  │                    │ (0으로 초기화)              │
                  │                    └──────────────┬──────────────┘
                  │                                   │
                  │                                   ▼
                  │                    ┌─────────────────────────────┐
                  │                    │ 스케일링 계수 적용 (α / r)  │
                  │                    └──────────────┬──────────────┘
                  │                                   │
                  └─────────────────┬─────────────────┘
                                    ▼ (Vector Addition)
                     [ 출력 텐서 h = W_0 x + (α/r)BAx ]
```

- **저순위 행렬 분해** : $h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} B A x$ - $d \times k$ 크기의 $\Delta W$를 $B(d \times r)$와 $A(r \times k)$로 분해 ($r \ll \min(d, k)$)
- **가중치 초기화 규칙** : $A \sim \mathcal{N}(0, \sigma^2)$, $B = 0$ - 학습 시작 시점에 $\Delta W = 0$을 보장하여 초기 출력이 사전학습 모델과 동일하게 출발
- **스케일링 계수 ($\alpha$)** : Scaling Factor $= \frac{\alpha}{r}$ - 랭크 $r$ 변경 시에도 학습률(Learning Rate)을 재조정하지 않도록 하이퍼파라미터 안정화

## Ⅲ. LoRA / PEFT의 세부 구성 요소 및 비교 분석

| 비교 항목 | Full Fine-Tuning | Adapter Tuning | Prefix / Prompt Tuning | LoRA / QLoRA (본 토픽) |
|---|---|---|---|---|
| **학습 파라미터 비율** | 전체 가중치 | 소수 비율 (계층 사이 삽입) | 극소수 (가상 토큰) | 소수 비율 (저순위 행렬) |
| **VRAM 메모리 부담** | 극도로 높음 (80GB x 8) | 중간 (단일 GPU 가능) | 낮음 | 매우 낮음 (24GB 단일 GPU) |
| **추론 지연** (Latency) | 지연 없음 (원본 유지) | 순차 연산 추가로 지연 발생 | 입력 시퀀스 길이 단축 유발 | 가중치 병합으로 지연 전무 |
| **모델 서빙 유연성** | 과업별 전체 모델 복제 | 어댑터 분리 서빙 | 프롬프트 벡터 분리 | 단일 베이스 + 다중 LoRA 스왑 |

- LoRA / PEFT는 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. LoRA / PEFT의 주요 한계점 및 해결 방안

- 수십 개 어댑터 동시 서빙 시 동적 병합/해제 지연 및 메모리 단편화 :
  - 한계점 : 수십 개의 LoRA 어댑터를 동시 서빙할 때 매번 베이스 가중치에 병합/해제하는 과정에서 발생하는 지연과 메모리 단편화.
  - 해결 방안 : S-LoRA 및 Punica 기반 배치 추론 엔진을 도입하여 비병합 상태의 어댑터를 동일 GPU 텐서 코어에서 동적 멀티플렉싱.
- 최적 랭크 $r$과 스케일 $\alpha$ 탐색을 위한 반복 실험 비용 :
  - 한계점 : 베이스 모델과 과업 복잡도에 최적화된 랭크 $r$과 스케일 $\alpha$ 탐색을 위한 반복 실험 비용.
  - 해결 방안 : 학습 중 유효 특이값을 자동 측정하여 계층별 최적 랭크를 동적으로 할당하는 AdaLoRA 알고리즘 적용.
- QLoRA의 4-bit 양자화 오차로 인한 복합 추론 성능 하락 :
  - 한계점 : QLoRA의 4-bit 양자화 오차로 인해 복잡한 코드 생성 및 정밀 수치 추론 태스크에서 성능 하락 발생.
  - 해결 방안 : 다운프로젝션과 업프로젝션 잔차를 16-bit로 보정하는 QDyLoRA 기법 및 핵심 계층(Attention Projections) 선택적 적용.

## Ⅴ. LoRA / PEFT 적용 및 발전을 위한 기술사적 제언

- GPU 인프라 비용 절감 및 최적화 체계 구축 : 과업 수 × 70B 모델 인스턴스 (수십 대 필요)의 한계를 탈피하고, 70B 베이스 1대 + 어댑터 캐싱 (1~2대로 통합)를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 모델 스왑 시간 중심 엔터프라이즈 고도화 : 모델 재로딩 시 수십 초~수 분 소요의 한계를 탈피하고, 수 밀리초(ms) 단위 CUDA(Compute Unified Device Architecture) 커널 스왑을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 스토리지 용량 중심 엔터프라이즈 고도화 : 과업당 수십 GB 중복 저장의 한계를 탈피하고, 과업당 수십 MB 어댑터 파일만 보관을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
