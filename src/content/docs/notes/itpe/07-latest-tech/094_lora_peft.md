## 연관 키워드

- LoRA, PEFT, QLoRA, 저순위 분해, 스케일링 계수, 어댑터, 동결, 옵티마이저, S-LoRA, AdaLoRA

## Ⅰ. LoRA / PEFT의 개요

- 핵심 요약 : 원본 가중치를 동결하고 변화량만 저순위 행렬로 학습해 대형 모델을 적은 자원으로 맞춤화하는 기법.
- 개념 : 사전학습 모델의 가중치를 동결하고 가중치 변화량(ΔW)을 저순위 행렬 두 개의 곱(B×A)으로 근사해 학습하는 **PEFT**(Parameter-Efficient Fine-Tuning, 파라미터 효율적 미세조정)의 대표 기법 **LoRA**(Low-Rank Adaptation).
- 배경 및 필요성 : 모델 전체를 미세조정하면 옵티마이저 상태까지 메모리에 올라가 부담이 크고, 과업마다 모델 복제본을 두면 저장과 서빙 비용이 불어난다.
- 주요 목적 : 학습 파라미터를 줄여 단일 GPU 수준에서 LLM(Large Language Model) 맞춤화를 가능하게 하고, 과업별 변경분을 작은 어댑터로 분리 관리.

## Ⅱ. LoRA / PEFT의 특징 및 장점

- 핵심 요약 : 저랭크 분해와 0 초기화 설계가 학습 자원을 줄이면서 학습 시작 시점의 출력을 원본과 같게 보장.

1. **저순위 분해**(Low-Rank Decomposition) : d×k 크기의 ΔW를 B(d×r)와 A(r×k)의 곱으로 표현(r ≪ min(d, k)) → 학습 파라미터 수가 크게 줄어 메모리 부담 완화.
2. 0 초기화 : B를 0으로 시작해 학습 초기에 ΔW=0 → 사전학습 모델과 같은 출발점에서 안정적으로 학습.
3. **스케일링 계수**(α/r) : 랭크 r을 바꿔도 ΔW의 크기가 급변하지 않도록 조정 → 랭크 변경 시 학습률을 매번 다시 맞출 부담 감소.
4. 가중치 병합 : 학습 후 BA를 W₀에 합치면 추론 경로가 원본과 같아짐 → 추가 지연 없이 원래 속도로 서빙.

## Ⅲ. LoRA / PEFT의 구조 (흐름)

- 핵심 요약 : 입력이 동결 가중치 경로와 저순위 경로를 거쳐 합산되는 구조이며, 어댑터 단위로 과업을 교체하는 서빙이 가능.

```text
입력 x
  ↓
[ 저순위 경로 A (r×k) ]
  ↓
[ 업 행렬 B (d×r) ]
  ↓
[ 스케일 α/r 적용 ]
  ↓
[ 동결 W₀x 와 합산 ]
  ↓
출력 h = W₀x + (α/r)BAx
```

```text
[ 단일 베이스 모델 (동결) ]
        ↓ 요청별 어댑터 선택
[ 과업 A 어댑터 ]   [ 과업 B 어댑터 ]
```

## Ⅳ. LoRA / PEFT와 대안 기법의 비교

- 핵심 요약 : 학습 파라미터와 메모리는 줄이면서 병합으로 추론 지연은 막는 것이 LoRA의 차별점이다.

비교 대상은 전체 미세조정(Full Fine-Tuning), 계층 사이에 모듈을 넣는 어댑터 튜닝(Adapter Tuning), 가상 토큰을 학습하는 프리픽스·프롬프트 튜닝(Prefix/Prompt Tuning)이다. QLoRA(Quantized Low-Rank Adaptation)는 동결 가중치를 4-bit로 양자화해 LoRA를 적용하는 변형이다.

| 비교 축 | Full Fine-Tuning | Adapter Tuning | Prefix/Prompt Tuning | LoRA / QLoRA |
| --- | --- | --- | --- | --- |
| 학습 파라미터 | 전체 가중치 | 소수 (계층 사이 모듈) | 극소수 (가상 토큰) | 소수 (저순위 행렬) |
| 메모리 부담 | 가장 큼 | 중간 | 낮음 | 낮음 (QLoRA는 더 낮음) |
| 추론 지연 | 없음 | 모듈 추가 연산으로 지연 | 입력 길이 증가 | 병합 시 지연 없음 |
| 서빙 유연성 | 과업별 전체 모델 복제 | 모듈 분리 서빙 | 프롬프트 벡터 분리 | 단일 베이스와 어댑터 교체 |

## Ⅴ. LoRA / PEFT의 한계와 방안

- 핵심 요약 : 다중 어댑터 서빙 지연, 랭크 탐색 비용, 양자화 오차가 주요 한계이며 각각 서빙 구조와 실험 설계로 제어.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 다중 어댑터 동시 서빙 지연 | 요청마다 베이스 가중치에 병합·해제하면 교체 지연과 메모리 단편화 발생 | S-LoRA 계열의 비병합 배치 서빙으로 여러 어댑터를 동일 GPU에서 다중화 | 어댑터 교체 지연, GPU 메모리 점유율 |
| 최적 랭크·α 탐색 비용 | 과업마다 랭크와 스케일을 반복 실험해야 함 | 계층별 중요도에 따라 랭크를 배분하는 AdaLoRA 계열 적용 | 실험 횟수, 검증셋 성능 |
| QLoRA 양자화 오차 | 정밀 수치 추론이나 코드 생성에서 성능 저하 가능 | 핵심 계층(어텐션 투영)에 선택 적용, 과업별 검증셋으로 확인 | 과업별 정확도 차이 |

## Ⅵ. LoRA / PEFT에 대한 기술사적 제언

- 핵심 요약 : 베이스 모델은 공유 자산으로 두고 어댑터를 버전 관리하는 운영 체계로 맞춤화 비용을 낮추는 방향.

대규모 베이스 모델은 조직 공용 자산으로 한 벌만 관리하고, 과업별 어댑터는 레지스트리에 등록해 평가 게이트를 통과한 것만 배포하는 체계가 바람직하다. 이렇게 하면 과업마다 모델을 복제하던 저장과 서빙 비용을 줄이면서도 과업별 품질을 독립적으로 관리할 수 있다.

## Ⅶ. 결론

- 핵심 요약 : LoRA는 원본을 건드리지 않고 작은 변화량만 학습하는 대표적인 PEFT 기법임.
- 베이스 모델 공유와 어댑터 분리 운영을 함께 설계할 때 맞춤화의 경제성이 실현되며, 그 효과는 서빙 구조에 따라 크게 달라진다.
