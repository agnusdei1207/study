- 제아무리 뛰어난 전문가 한 명도 맹점이 있듯이, 단일 AI 모델 하나에 의존하면 특정 데이터에 속아 오판하기 쉬움 → 서로 다른 시각과 장단점을 가진 여러 모델들의 의견을 모아(투표, 가중합, 메타 회귀) 종합 판정 → 압도적인 일반화 성능 달성 / 연산 비용과 블랙박스화 심화

## 핵심 용어
- 콩도르세 배심원 정리(Condorcet's Jury Theorem): 개별 판정자의 정확도가 50%를 초과($p > 0.5$)하고 상호 독립적이라면, 판정자 수($N$)가 무한히 늘어날 때 다수결 투표의 정답 확률은 100%로 수렴한다는 통계학적 정리
- 스태킹(Stacking): 여러 기저 모델들이 예측한 출력값들을 새로운 입력 특성(Feature)으로 삼아, 최종 메타 모델(Meta-Learner)이 이를 결합하여 학습하는 2단계 앙상블 기법
- 모델 다양성(Model Diversity): 앙상블을 구성하는 개별 모델들이 서로 다른 알고리즘 원리, 다른 서브셋, 다른 특성을 학습하여 오류의 상관관계를 최소화하는 성질

## 핵심 통찰
- "앙상블의 생명은 정확도가 아니라 '다양성(Diversity)'": 정확도 90%인 똑같은 모델 3개를 합치는 것은 아무런 이득이 없으며, 서로 다른 방식으로 80%를 맞히는 모델 3개를 합쳤을 때 비로소 95%로 도약함
- 소프트 보팅(Soft Voting) vs 하드 보팅(Hard Voting): 단순 라벨 다수결(Hard)보다 각 모델이 출력한 확률값(Confidence)의 평균을 내는 Soft Voting이 훨씬 더 많은 정보를 보존하여 성능이 우수함
- 스태킹 시 데이터 누수(Data Leakage)의 함정: 훈련 데이터로 기저 모델을 학습시키고 그 예측값으로 메타 모델을 훈련하면 100% 과적합되므로, 반드시 K-Fold 교차 검증의 Out-of-Fold(OOF) 예측값으로 메타 특성을 생성해야 함

## 이웃 토픽과 구분
- 단일 모델 최적화 vs 앙상블 학습: 단일 모델은 하이퍼파라미터 튜닝으로 국소 최적해 추구 / 앙상블 학습은 서로 다른 오차 분포를 갖는 모델들을 통계적으로 상쇄시켜 전역 성능 향상
