## 30초 인출

- 본질: **앙상블 학습 (Ensemble Learning)** 은 단일 머신러닝 알고리즘의 예측 한계와 오차를 극복하기 위해 복수의 서로 다른 기초 학습기(Base Learners)를 유기적으로 결합하여 집단 지성 형태로 편향(Bias)과 분산(Variance)을 동시에 통제하는 메타 머신러닝 기법
- 메커니즘: 데이터 다양성(부트스트랩) 또는 알고리즘 다양성(이종 모델)을 부여하여 개별 모델을 학습시키고, 다수결 투표(Voting), 잔차 순차 보정(Boosting), 메타 학습기 결합(Stacking)을 통해 최종 예측 도출
- 통찰: 모델 간 예측 상관관계가 높으면 앙상블 결합 효과가 상쇄되고 스태킹 시 데이터 누수(Data Leakage)로 과적합되므로 모델 다양성 지표 모니터링과 K-Fold 기반 OOF(Out-Of-Fold) 메타 셋 생성 체계 구축 필수

<details><summary>핵심 용어</summary>

- **앙상블 학습 (Ensemble Learning)** : 여러 약학습기(Weak Learner)의 출력을 종합하여 고성능 강학습기(Strong Learner)를 구축하는 모델 결합 프레임워크.
- **다양성 (Diversity)** : 앙상블을 구성하는 개별 모델들이 서로 다른 오류 분포와 결정 경계를 가지도록 유도하는 성질.
- **보팅 (Voting)** : 동일한 데이터셋에 대해 서로 다른 알고리즘(SVM, 로지스틱, 트리 등)을 독립 학습시켜 투표로 결정하는 기법 (하드/소프트 보팅).
- **스태킹 (Stacking)** : 1단계 기초 모델들의 예측 결과를 새로운 독립 변수 피처로 삼아 2단계 메타 모델(Meta Learner)이 최종 예측을 재학습하는 기법.
- **OOF (Out-Of-Fold)** : 스태킹 학습 시 데이터 누수를 차단하기 위해 K-Fold 교차 검증의 검증 폴드 예측값만을 모아 2단계 메타 훈련셋으로 구축하는 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. 앙상블 학습의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **앙상블 학습** 은 복수의 약학습기(Weak Learners)를 훈련시킨 후 이들의 예측 결과를 결합 규칙(투표, 평균, 가중 합산, 메타 모델)을 통해 하나로 통합함으로써 단일 모델 대비 높은 정확도와 안정성을 달성하는 머신러닝 방법론 |
| 목적 | 단일 알고리즘이 내재한 가설 공간 탐색 한계를 극복하고 모델의 편향(Bias)과 분산(Variance)을 동시에 최소화하여 일반화 오차 극소화 |

## Ⅱ. 앙상블 학습의 3대 핵심 결합 원리 및 특징

| 이론적 원리 | 수학적/통계적 근거 | 앙상블 설계 특징 |
|---|---|---|
| **콩도르세 배심원 정리** | $P_n = \sum_{k=\lfloor n/2 \rfloor + 1}^n \binom{n}{k} p^k (1-p)^{n-k}$ | 개별 모델의 정확도 $p > 0.5$이고 상호 독립일 때 모델 수 $n \to \infty$이면 집단 정답률은 100% 수렴 |
| **편향-분산 분해** | $\text{Error} = \text{Bias}^2 + \text{Variance} + \text{Noise}$ | 배깅은 분산($\text{Var}$) 감소에 특화, 부스팅은 편향($\text{Bias}$) 감소에 특화 |
| **모델 다양성 (Diversity)** | $E = \bar{E} - \bar{A}$ (Krogh-Vedelsby 이론) | 앙상블 오차 $E$는 개별 모델 평균 오차 $\bar{A}$에서 상호 다양성(모호성 $\bar{A}$)을 뺀 것과 동일 |
| **결합 기법 다양성** | 단순 통계 집계 vs 메타 머신러닝 학습 | 선형적 단순 결합(보팅/배깅)부터 비선형 계층 결합(스태킹)까지 폭넓은 스펙트럼 |

## Ⅲ. 앙상블 학습의 3대 패러다임 아키텍처

```text
┌────────────────────────────────────────────────────────────────────────┐
│             앙상블 학습 (배깅 vs 부스팅 vs 스태킹) 구조 비교           │
└────────────────────────────────────────────────────────────────────────┘
 [1. 배깅 (Bagging): 병렬 독립 표본 추출 및 단순 집계]
    원본 데이터 ──┬──> [부트스트랩 1] ──> [트리 1] ──┐
                  ├──> [부트스트랩 2] ──> [트리 2] ──┼──> [다수결 투표 / 평균]
                  └──> [부트스트랩 B] ──> [트리 B] ──┘

 [2. 부스팅 (Boosting): 순차적 잔차 보정 및 가중치 누적]
    원본 데이터 ──> [모델 1] ──(잔차/오차)──> [모델 2] ──(잔차)──> [모델 M]
                       │                          │                   │
                       └─────────────┬────────────┴───────────────────┘
                                     ▼ 가중 선형 결합 (Σ η * h_m)
                                [최종 강학습기]

 [3. 스태킹 (Stacking): K-Fold OOF 기반 2단계 메타 모델링]
    훈련 데이터 ──┬──> [Base Model A (XGBoost)] ──> OOF 예측 피처 A ──┐
                  ├──> [Base Model B (RandomForest)] ──> OOF 피처 B ─┼──> [메타 모델]
                  └──> [Base Model C (LightGBM)] ──> OOF 피처 C ─────┘    (예: Lasso)
```

| 앙상블 유형 | 기초 모델(Base Model) 구성 | 데이터 샘플링 방식 | 주된 오류 감소 효과 |
|---|---|---|---|
| **보팅 (Voting)** | 서로 다른 이종 알고리즘 (SVM, KNN, Tree) | 전체 원본 데이터 동일 사용 | 분산 및 편향 완화 |
| **배깅 (Bagging)** | 동일한 고분산 동종 알고리즘 (결정트리) | 복원 추출(Bootstrap: 63.2%) | 분산(Variance) 대폭 감소 |
| **부스팅 (Boosting)** | 동일한 고편향 동종 알고리즘 (약한 트리) | 이전 모델 오답 가중치 부여 | 편향(Bias) 대폭 감소 |
| **스태킹 (Stacking)** | 고성능 이종 모델 앙상블 묶음 | K-Fold 교차 검증 OOF 생성 | 전체 일반화 예측력 극대화 |

## Ⅳ. 앙상블 기법 비교

| 비교 항목 | 보팅 (Voting) | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|---|---|---|---|---|
| **모델 동종 여부** | 이종(Heterogeneous) 모델 | 동종(Homogeneous) 모델 | 동종(Homogeneous) 모델 | 주로 고성능 이종 모델 |
| **학습 순서** | 병렬 독립 학습 | 병렬 독립 학습 | 순차 직렬 학습 | 2단계(Level-0, Level-1) 계층 |
| **결합 방식** | 다수결 투표, 가중치 평균 | 단순 평균, 다수결 투표 | 수축률 가중 선형 합산 | 메타 회귀/분류 모델 학습 |
| **과적합 위험** | 낮음 | 매우 낮음 | 비교적 높음 (이상치 민감) | 높음 (OOF 미적용 시 누수) |
| **계산 비용** | 낮음~중간 | 중간 (병렬 처리 용이) | 높음 (직렬 처리 병목) | 극도로 높음 (K-Fold 반복) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 스태킹(Stacking) 구현 시 1단계 모델이 전체 훈련 데이터로 예측한 값을 그대로 메타 모델 훈련 피처로 쓰면 데이터 누수(Data Leakage)로 인한 치명적 과적합 발생 | K-Fold 교차 검증을 통해 학습에 참여하지 않은 검증 폴드의 예측값만을 결합하는 OOF(Out-Of-Fold) 데이터셋 구축을 강제화 |
| 수십 개의 이종 모델을 앙상블함에 따라 프로덕션 환경에서 추론 메모리 점유율과 서빙 레이턴시가 수십 배 폭증 | 지식 증류(Knowledge Distillation) 기법을 적용하여 거대 앙상블 모델의 예측 지식을 단일 경량 신경망(Student)으로 압축 전이 |
| 앙상블에 참여하는 개별 트리 모델 간의 결정 경계가 유사하여 모델 간 상관계수가 높을 때 결합 이득이 0에 수렴하는 비효율 | 모델별로 훈련 피처 집합을 다르게 샘플링하거나 배깅(Bagging)과 부스팅(Boosting)의 이종 결합을 유도하여 상관도 저감 |

## Ⅵ. 제언

데이터 누수를 원천 차단하고 최고 수준의 예측 정확도를 달성하기 위해 OOF 파이프라인 기반 자동 스태킹 및 지식 증류 경량화 엔지니어링 아키텍처 구축 권고.

```text
[ 훈련 데이터셋 (Train Data) ]
             │
             ▼
┌────────────────────────────────────────────────────────┐
│ K-Fold Out-Of-Fold (OOF) 생성 파이프라인 (Level-0)     │
│                                                        │
│  [ Fold 1 ]  [ Fold 2 ]  [ Fold 3 ]  [ Fold 4 ]  [ Fold 5 ]│
│     │           │           │           │           │  │
│  Base Model 1 (LightGBM) ──> OOF 검증 예측 벡터 P_1    │
│  Base Model 2 (CatBoost) ──> OOF 검증 예측 벡터 P_2    │
│  Base Model 3 (XGBoost)  ──> OOF 검증 예측 벡터 P_3    │
└────────────────────────────┬───────────────────────────┘
                             │ OOF 예측 피처셋 [P_1, P_2, P_3] 결합
                             ▼
┌────────────────────────────────────────────────────────┐
│ Level-1 메타 학습기 (Meta Learner: ElasticNet / Ridge)  │
│  - 단순 선형 정규화 모델로 과적합 방지 및 최적 가중치 도출│
└────────────────────────────┬───────────────────────────┘
                             │
                             ▼
┌────────────────────────────────────────────────────────┐
│ 프로덕션 지식 증류 (Knowledge Distillation) 서빙       │
│  - 앙상블 Soft Label ──> 단일 경량 모델 훈련 ──> 서빙  │
└────────────────────────────────────────────────────────┘
```

| 구분 | 단순 모델 평균(Simple Averaging) | 제언: OOF 스태킹 + 지식 증류 파이프라인 |
|---|---|---|
| **예측 성능** | 상위 모델과 하위 모델 단순 상쇄 | 메타 학습기가 모델별 장단점을 가중 최적화 |
| **데이터 누수** | 검증 데이터 오염 위험 | OOF 검증셋 완벽 분리로 누수 제로 |
| **서빙 레이턴시** | 모든 모델 동시 추론으로 지연 극심 | 지식 증류 단일 모델 서빙으로 1ms 완결 |
| **운영 유지보수** | 다수 모델 동시 관리 부담 | 파이프라인 자동화 및 단일 서빙 아티팩트 관리 |
