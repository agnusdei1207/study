## 연관 키워드

- 앙상블 학습(Ensemble Learning), 약학습기(Weak Learner), 배깅(Bagging), 부스팅(Boosting), 스태킹(Stacking), 보팅(Voting)
- 편향(Bias), 분산(Variance), OOF(Out-Of-Fold), 데이터 누수(Data Leakage), 모델 다양성(Diversity), 지식 증류(Knowledge Distillation)

## Ⅰ. 앙상블 학습의 개요

- 핵심 요약 : 여러 약한 학습기의 예측을 결합해 단일 모델보다 정확하고 안정적인 결과를 얻는 머신러닝 방법론.
- 개념 : 단독으로는 성능이 제한적인 여러 **약학습기**(Weak Learner)를 학습시킨 뒤, 투표·평균·가중 합산·메타 모델 같은 결합 규칙으로 하나의 예측을 만드는 방법론(**앙상블 학습**, Ensemble Learning).
- 배경 및 필요성 : 단일 모델은 복잡도를 높이면 분산이 커지고 단순하게 두면 편향이 커져, 한쪽을 줄이면 다른 쪽이 늘어나는 한계가 있다. 이를 넘으려면 여러 모델의 오차를 서로 상쇄시키는 결합 구조가 필요하다. 다만 결합 이득은 모델끼리 예측이 서로 다를 때만 생기므로, 모델 간 상관을 점검하는 절차가 선행 비용으로 따른다.
- 주요 목적 : 편향과 분산을 함께 낮춰 새 데이터에 대한 일반화 오차를 줄이는 것.

## Ⅱ. 앙상블 학습의 특징 및 장점

- 핵심 요약 : 데이터와 알고리즘의 다양성을 결합 규칙으로 묶어 오차를 상쇄하므로, 정확도와 안정성을 함께 얻는다.

1. 데이터 다양성 : 원본을 복원 추출한 **부트스트랩**(Bootstrap, 중복을 허용해 뽑은 학습 표본)으로 모델마다 다른 데이터를 학습 → 모델 간 예측 편차가 생겨 결합 시 오차가 상쇄됨.
2. 알고리즘 다양성 : 성격이 다른 모델을 섞어 학습 → 서로 다른 결정 경계가 보완되어 결합 이득이 커짐.
3. 순차 보정 : 앞 단계 모델이 남긴 잔차를 다음 모델이 학습 → 체계적 오차가 줄어 편향이 낮아짐.
4. 메타 결합 : 개별 모델의 출력을 다시 학습 데이터로 삼는 상위 모델이 모델별 장단점을 가중 → 단일 결합 규칙보다 상황에 맞는 조합이 가능해짐.

## Ⅲ. 앙상블 학습의 구조 (흐름)

- 핵심 요약 : 병렬 집계의 배깅, 순차 보정의 부스팅, 2단계 메타 결합의 스태킹이 결합 방식으로 구분되는 세 가지 흐름.
- **배깅**(Bagging, Bootstrap Aggregating) : 표본을 나눠 모델을 병렬로 독립 학습한 뒤 결과를 평균하거나 투표로 집계. 분산을 줄이는 데 특화되어 있다.
- **부스팅**(Boosting) : 이전 모델의 오차를 다음 모델이 집중 학습하도록 순차 구성하고, 모델 출력을 가중 합산. 편향을 줄이는 데 특화되어 있다.
- **스태킹**(Stacking) : 기반 모델들의 K-Fold 교차 검증 결과로 만든 **OOF**(Out-Of-Fold, 학습에 쓰이지 않은 폴드에서 얻은 예측값) 데이터를 입력으로 삼아 메타 모델을 학습.
- 오차 분해 : Error = Bias² + Variance + Noise. 배깅은 분산 항을, 부스팅은 편향 항을 주로 낮춘다.

```text
[ 배깅: 병렬 독립 학습 ]

원본 데이터
   ↓ 부트스트랩 복원 추출
[모델 1] [모델 2] ... [모델 B]
   ↓ 다수결 투표 또는 평균
최종 예측
```

```text
[ 부스팅: 순차 잔차 보정 ]

원본 데이터
   ↓
모델 1 예측 → 잔차 계산
   ↓
모델 2가 잔차를 보정
   ↓
... 모델 M
   ↓ 가중 합산
최종 강학습기
```

```text
[ 스태킹: 2단계 메타 결합 ]

훈련 데이터
   ↓ K-Fold로 OOF 예측 생성
[Level-0] 모델 A, 모델 B, 모델 C
   ↓ OOF 예측값을 피처로 결합
[Level-1] 메타 모델
   ↓
최종 예측
```

## Ⅳ. 앙상블 학습의 비교

- 핵심 요약 : 학습 순서와 결합 방식이 과적합 위험과 운영 복잡도를 결정하므로, 목적에 따라 방식을 고른다.

| 비교 축 | 보팅 (Voting) | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
| --- | --- | --- | --- | --- |
| 모델 구성 | 이종 모델 | 동종 모델 | 동종 모델 | 주로 이종 모델 |
| 학습 순서 | 병렬 독립 | 병렬 독립 | 순차 직렬 | 2단계 계층 |
| 결합 방식 | 투표 또는 가중 평균 | 평균 또는 투표 | 가중 선형 합산 | 메타 모델 학습 |
| 주된 효과 | 개별 강점 결합 | 분산 감소 | 편향 감소 | 모델 조합 최적화 |
| 과적합 위험 | 낮음 | 매우 낮음 | 이상치에 민감해 높아질 수 있음 | 누수 방지가 없으면 높음 |

- 선택 기준 : 분산이 문제인지 편향이 문제인지, 그리고 추론 시 모델을 몇 개까지 동시에 서빙할 수 있는지에 따라 방식을 정한다.

## Ⅴ. 앙상블 학습의 한계와 방안

- 핵심 요약 : 데이터 누수, 추론 비용 증가, 모델 상관 문제를 OOF 검증, 지식 증류, 다양성 확보로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 데이터 누수 | 전체 훈련 데이터로 만든 예측값을 메타 모델에 넣으면 과적합 발생 | OOF 예측값만 메타 피처로 사용 | 검증 점수와 운영 점수의 차이 |
| 추론 비용 증가 | 다수 모델을 동시에 서빙해 메모리와 지연 시간 증가 | **지식 증류**(Knowledge Distillation, 큰 모델의 예측을 작은 모델이 모방하도록 학습) 적용 | 추론 지연, 메모리 사용량 |
| 모델 상관 높음 | 모델들의 결정 경계가 비슷해 결합 이득 감소 | 피처 샘플링 차이 확대, 배깅과 부스팅의 이종 결합 | 모델 간 예측 상관계수 |
| 이상치 민감 | 부스팅이 잔차를 쫓아 잡음까지 학습 | 강건한 손실 함수 사용, 학습률 조정 | 검증 손실 추이 |

## Ⅵ. 앙상블 학습에 대한 기술사적 제언

- 핵심 요약 : 앙상블을 모델 조합 기법이 아니라 검증과 서빙 비용까지 포함한 운영 설계로 다뤄야 적용 효과가 유지됨.

1. 데이터 조직은 OOF 기반 검증 절차를 표준 파이프라인에 포함해, 누수 방지를 프로젝트마다 다시 고민하지 않도록 공통 규칙으로 관리해야 한다.
2. 서비스 조직은 정확도 향상분과 추론 비용 증가분을 함께 비교해 앙상블 적용 범위를 정하고, 비용이 큰 경우 지식 증류를 전제로 설계해야 한다.
3. 거버넌스 측면에서는 모델 다양성과 성능 지표를 정기 점검하는 모델 리뷰 체계를 두어, 앙상블이 단일 모델의 성능 정체를 가리지 않도록 관리해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 앙상블 학습은 다양성과 결합 규칙으로 오차를 줄이는 기법이며, 그 이득은 누수 방지와 운영 비용 관리 위에서만 유지됨.
- 시사점 : 모델의 복잡도를 무작정 키우기보다 결합 구조를 설계하는 쪽이 일반화 성능을 안정적으로 얻는 길이다.
