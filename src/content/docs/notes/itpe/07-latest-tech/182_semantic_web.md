## 핵심 용어
- RDF(Resource Description Framework): 웹 상의 모든 자원(Resource)에 대해 '주어(Subject) - 술어(Predicate) - 목적어(Object)'의 3개 항목(Triple)으로 의미와 관계를 기술하는 표준 데이터 모델
- OWL(Web Ontology Language): 클래스, 속성 간의 포함 관계, 대칭성, 전이성, 서로소(Disjoint) 관계 등을 수학적으로 엄밀히 정의하여 컴퓨터가 새로운 사실을 연역 추론할 수 있게 만든 온톨로지 언어
- SPARQL: RDF 그래프 데이터베이스(Triple Store)에 저장된 의미 데이터를 SQL처럼 질의하고 추출하기 위한 W3C 표준 시맨틱 질의 언어

## 핵심 통찰
- "텍스트 웹에서 데이터 웹으로의 대전환": 웹페이지라는 문서를 검색하던 시대에서, 웹페이지 안에 담긴 데이터 조각(Entity)과 엔티티 간의 관계를 직접 컴퓨터가 탐색하는 LOD(Linked Open Data) 시대로 도약
- 비정형 자료의 구조화: LLM으로 후보 관계를 추출할 수 있으나 개체 식별, 출처 연결, 사실 검증 및 온톨로지 제약 검사 필요
- 구글 지식 패널(Knowledge Graph)의 모태: 구글 검색창에 인물을 치면 오른쪽에 출생지, 가족, 직업이 박스로 정리되어 나오는 기술이 바로 시맨틱 웹 온톨로지와 RDF 트리플의 결정체

## 이웃 토픽과 구분
- HTML과 RDF: HTML에도 제목·목록·문서 구조를 나타내는 의미 요소가 있으며, RDF는 웹 자원 간의 관계를 트리플로 표현하고 공유 어휘·추론에 활용
