## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 웹 자원의 식별자와 관계를 기계 처리 가능한 형태로 표현해 데이터 연결·질의·추론을 지원하는 기술 체계. |
| 목적 | 웹 자원의 관계를 기계 처리 가능한 형태로 연결·질의 |

### Ⅱ. 핵심 구조와 적용

```text
IRI 식별 → RDF 관계 기술 → 어휘·온톨로지 → SPARQL 질의
```

1. **요구:** 기관별 같은 개념의 정의·유효기간과 식별자 충돌을 확인하고 공유 범위를 결정.
2. **모델:** 자원에 안정적 IRI 부여 → RDF 트리플 작성 → RDFS·OWL로 클래스·속성과 제약 정의 → SPARQL 엔드포인트에서 질의.
3. **연계:** 용어 매핑과 출처·버전 기록, 데이터 공개 조건 및 접근권한 설정. 자연어 추출 결과는 전문가 검토 후 반영.
4. **검증:** 식별자 중복, 스키마 충돌, 추론 일관성, 대표 질의 성능과 출처 추적 가능성 시험.

### Ⅲ. 유사 개념과 구분

- HTML과 RDF: HTML에도 제목·목록·문서 구조를 나타내는 의미 요소가 있으며, RDF는 웹 자원 간의 관계를 트리플로 표현하고 공유 어휘·추론에 활용

### Ⅳ. 문제·원인·대책

- 적용 상황: 국가 공공 행정 지식 포털의 시맨틱 웹 및 LOD 기반 오픈데이터 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 부처마다 동일 용어의 기준이 달라 통합 검색 실패 | 제도·기관별 상이한 정의와 식별자 | 용어 정의·유효기간 명시, SKOS 매핑 및 충돌 검토 | 연결 정확도·모호성 측정 |
| 문서의 RDF 변환 비용 과다 | 추출과 식별자 정합에 전문 검토 필요 | LLM 후보 추출 후 출처·개체 정합·표본 검증 | 정밀도·재현율과 검수 공수 측정 |
| 대용량 RDF 조인 질의 지연 | 그래프 패턴·인덱스·데이터 분포의 영향 | 질의 계획과 인덱싱 최적화, 필요한 경우 분산 처리 | 기준 질의의 응답시간 검증 |

### Ⅴ. 제언

- [GraphRAG와 온톨로지의 결합] LLM 추출 후보에 원문 출처와 신뢰도를 부여하고 온톨로지 제약·전문가 검수를 거쳐 그래프에 반영. SPARQL 결과와 근거를 응답에 함께 제공하되 추출·검색 오류 모니터링
