## 30초 인출

- 본질: 컴퓨터가 웹 문서에 포함된 정보의 의미(Semantics)를 해석하고, 기계 간 자율적인 데이터 공유·통합·추론을 가능하게 하는 메타데이터 기반의 지능형 차세대 웹 아키텍처.
- 메커니즘: URI/IRI 고유 식별 → RDF 트리플(주어-술어-목적어) 그래프 모델링 → RDFS/OWL 온톨로지 어휘 정의 → SPARQL 엔드포인트 질의 및 추론 엔진 지식 확장.
- 통찰: 수작업 온톨로지 구축 비용과 의미 충돌 병목을 극복하기 위해 거대언어모델(LLM) 기반의 지식 그래프 자동 추출과 GraphRAG 연동을 통한 하이브리드 추론 체계 구축 필수.

<details><summary>핵심 용어</summary>

- **RDF(Resource Description Framework) :** 웹 상의 자원을 주어(Subject), 술어(Predicate), 목적어(Object)의 3요소(트리플)로 표현하는 표준 데이터 모델.
- **OWL(Web Ontology Language) :** 클래스 간의 관계, 동등성, 대칭성, 이행성 등 풍부한 의미론적 공리(Axiom)를 기술하여 논리적 추론을 지원하는 언어.
- **SPARQL :** RDF 그래프 형태의 데이터베이스(Triple Store)에서 복합 패턴 매칭을 통해 데이터를 추출하는 표준 그래프 질의 언어.
- **LOD(Linked Open Data) :** 웹 상에 공개된 정형 데이터를 URI와 RDF 링크로 상호 연결하여 하나의 거대한 글로벌 웹 데이터베이스를 구축하는 운동.

</details>

## Ⅰ. 시맨틱 웹(Semantic Web)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 웹 상의 정보 자원에 컴퓨터가 이해할 수 있는 표준화된 의미(Semantic) 메타데이터를 부여하여 기계가 자율적으로 정보 처리, 연계, 논리적 추론을 수행하도록 구축한 지능형 분산 웹. |
| 목적 | 인간 중심의 텍스트 브라우징 한계 극복, 이종 시스템 간 데이터 상호운용성(Interoperability) 확보, 지능형 에이전트의 자동화된 의사결정 지원. |

## Ⅱ. 시맨틱 웹의 핵심 특징 및 기본 설계 철학

### 1. 시맨틱 웹의 4대 핵심 특징

- **기계 가독성(Machine Processability) :** 단순 화면 렌더링 목적의 마크업을 넘어 데이터의 실제 의미와 관계를 기계가 직접 파싱 및 처리 가능.
- **트리플 기반 지식 표현 :** 모든 실세계 지식을 주어-술어-목적어의 그래프 간선 구조로 정규화하여 무한 확장성 보장.
- **개방 세계 가정(Open World Assumption) :** 현재 지식베이스에 존재하지 않는 명제가 '거짓'이 아닌 '아직 알려지지 않은 참'일 수 있음을 전제하는 유연한 논리 체계.
- **비단조 추론(Non-Monotonicity) 수용성 :** 새로운 사실이 웹 상에 지속적으로 추가됨에 따라 기존 추론 결과를 동적으로 보완 및 갱신.

### 2. 전통적 웹(Web 1.0/2.0)과의 근본적 패러다임 차이

- **기존 웹의 한계 :** HTML 태그는 시각적 배치(Presentation) 정보만 제공하여 키워드 매칭 검색 시 동음이의어와 다의어 왜곡 발생.
- **시맨틱 웹의 가치 :** 개념 식별자(URI) 기반으로 자원을 명확히 구분하여 지능적 컨텍스트 검색 및 지식 융합 달성.

## Ⅲ. 시맨틱 웹 아키텍처(Layer Cake) 및 프로세스

### 1. W3C 시맨틱 웹 레이어 케이크 아키텍처

```text
+-------------------------------------------------------------------------------+
| [Trust & Cryptography] 디지털 서명, 데이터 출처 신뢰성 검증, 블록체인 연계   |
+-------------------------------------------------------------------------------+
                                      ▲
| [Logic & Proof]        규칙 기반 추론 엔진, 형식 논리 검증 (SWRL, RIF)       |
+-------------------------------------------------------------------------------+
                                      ▲
| [Ontology Layer]       어휘 및 공리 정의: OWL (Web Ontology Language)          |
+-------------------------------------------------------------------------------+
                                      ▲
| [Schema & Query Layer] 스키마 구조: RDF Schema (RDFS) / 질의 언어: SPARQL      |
+-------------------------------------------------------------------------------+
                                      ▲
| [Data Model Layer]     자원 기술 프레임워크: RDF (Resource Description)       |
+-------------------------------------------------------------------------------+
                                      ▲
| [Syntax Layer]         문법 및 네임스페이스: XML, JSON-LD, Turtle              |
+-------------------------------------------------------------------------------+
                                      ▲
| [Identifier & Char]    고유 식별자 및 문자셋: URI / IRI, Unicode             |
+-------------------------------------------------------------------------------+
```

### 2. 계층별 세부 기술요소 및 역할

| 계층 | 주요 표준 규격 | 핵심 엔지니어링 역할 |
|---|---|---|
| **URI / IRI** | RFC 3986, RFC 3987 | 웹 상의 모든 물리적/개념적 자원에 전역적으로 유일한 식별 주소 부여. |
| **RDF / JSON-LD** | W3C RDF 1.1, JSON-LD | 주어-술어-목적어로 구성된 방향성 그래프 모델링 및 웹 직렬화. |
| **RDFS / OWL** | RDF Schema, OWL 2 DL | 자원의 클래스 계층 구조, 프로퍼티 도메인/범위 지정 및 추론 규칙 명세. |
| **SPARQL** | SPARQL 1.1 Query/Update | 대규모 트리플 저장소(Triple Store) 대상의 정밀 그래프 패턴 매칭 질의 수행. |
| **Rule & Proof** | SWRL, RIF, Jena Rules | 온톨로지 공리만으로 표현하기 어려운 조건부 비즈니스 로직 연역 추론. |

## Ⅳ. 기존 문서 웹(HTML)과 시맨틱 웹(RDF/OWL) 비교

| 비교 항목 | 전통적 문서 웹 (HTML) | 시맨틱 웹 (RDF / OWL) |
|---|---|---|
| **데이터 단위** | 사람을 위한 문서(Document) 단위 | 기계를 위한 자원(Resource) 및 개체(Entity) 단위 |
| **링크 메커니즘** | 단순 비방향 하이퍼링크 (`<a href>`) | 명확한 의미가 명시된 관계 간선 (Typed Relationship) |
| **데이터 구조** | 비정형 또는 반정형 텍스트 | 정형화된 그래프(Knowledge Graph) 및 트리플 |
| **검색 방식** | 단순 문자열 키워드 매칭 및 역색인 | 개념 식별자 기반 시맨틱 검색 및 논리적 추론 질의 |
| **상호운용성** | 인간 브라우저 화면 해석 의존 | 기계 간 표준 API 및 SPARQL 엔드포인트 연계 |
| **추론 가능 여부** | 불가능 (단순 텍스트 파싱) | 가능 (상속, 동치, 대칭, 역관계 등 자동 유추) |

## Ⅴ. 시맨틱 웹의 엔지니어링 한계와 해결 방안

| 한계 | 방안 |
|---|---|
| **수작업 온톨로지 구축의 높은 비용 및 확장성 한계**<br />- 도메인 전문가의 수작업 모델링으로 인해 지식베이스 구축 시간과 비용 폭증. | **LLM 기반 개체명 인식(NER) 및 트리플 자동 생성**<br />- 생성형 AI 모델을 활용하여 비정형 문서에서 지식 트리플 자동 추출.<br />- 추출된 트리플에 신뢰도 점수를 부여하고 휴먼 인 더 루프(HITL) 검증 결합. |
| **대규모 RDF 트리플 조인 연산 시 쿼리 성능 급락**<br />- 복잡한 다자간(N-way) 조인이 요구되는 SPARQL 쿼리 실행 시 Triple Store 메모리 병목. | **속성 그래프(Property Graph) 및 분산 그래프 DB 전환**<br />- RDF를 Neo4j, TigerGraph 등 레이블 기반 속성 그래프(LPG) 모델로 변환.<br />- 빈번한 쿼리 경로에 대해 사전 인덱싱 및 그래프 파티셔닝 적용. |
| **데이터 생성 기관별 어휘 불일치 및 스키마 충돌**<br />- 동일한 대상을 두고 기관마다 상이한 URI와 온톨로지 네임스페이스를 사용하여 연계 단절. | **SKOS(Simple Knowledge Organization) 및 글로벌 LOD 정합**<br />- `owl:sameAs` 또는 `skos:exactMatch`를 활용한 개체 정합(Entity Resolution) 자동화.<br />- Wikidata, DBpedia 등 신뢰도 높은 공공 LOD 허브를 상위 개념으로 참조 매핑. |

## Ⅵ. 현대적 AI 아키텍처와의 융합을 위한 제언

시맨틱 웹의 정밀한 결정론적 지식 표현을 거대언어모델(LLM)과 결합하여 환각 현상(Hallucination)을 억제하는 지식 그래프 검색 증강 생성(GraphRAG) 아키텍처 필수 구축.

```text
[자연어 질의] ──► [LLM 엔티티 추출] ──► [SPARQL / Cypher 쿼리] ──► [온톨로지 그래프 추론]
                                                                        │
[최종 사실 근거 답변] ◄── [신뢰성 검증] ◄── [LLM 답변 합성 (RAG)] ◄───┘ (정형 지식 서브그래프)
```

| 엔지니어링 지표 | 목표 기준치 | 검증 방안 |
|---|---|---|
| **트리플 일관성** | 온톨로지 논리적 모순율 0% | HermiT / Pellet 추론기 기반 정합성 검증 |
| **SPARQL 응답성** | 복합 조인 쿼리 응답 200ms 이하 | 쿼리 플래너 최적화 및 인메모리 캐싱 |
| **지식 정합 정확도** | 이종 데이터 간 Entity Linking 정확도 95% 이상 | 골든 데이터셋 대조 F1-Score 평가 |
