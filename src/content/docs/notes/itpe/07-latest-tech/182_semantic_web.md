## 핵심 용어
- RDF(Resource Description Framework): 웹 상의 모든 자원(Resource)에 대해 '주어(Subject) - 술어(Predicate) - 목적어(Object)'의 3개 항목(Triple)으로 의미와 관계를 기술하는 표준 데이터 모델
- OWL(Web Ontology Language): 클래스, 속성 간의 포함 관계, 대칭성, 전이성, 서로소(Disjoint) 관계 등을 수학적으로 엄밀히 정의하여 컴퓨터가 새로운 사실을 연역 추론할 수 있게 만든 온톨로지 언어
- SPARQL: RDF 그래프 데이터베이스(Triple Store)에 저장된 의미 데이터를 SQL처럼 질의하고 추출하기 위한 W3C 표준 시맨틱 질의 언어

## 핵심 통찰
- "텍스트 웹에서 데이터 웹으로의 대전환": 웹페이지라는 문서를 검색하던 시대에서, 웹페이지 안에 담긴 데이터 조각(Entity)과 엔티티 간의 관계를 직접 컴퓨터가 탐색하는 LOD(Linked Open Data) 시대로 도약
- 수작업 시맨틱 태깅의 비극과 LLM을 통한 부활: 시맨틱 웹의 이상은 위대했으나 전 세계 웹 문서를 사람이 일일이 RDF로 태깅할 수 없어 실패했던 것을, 오늘날 거대 언어 모델(LLM)이 비정형 텍스트에서 지식 그래프를 자동 추출함으로써 화려하게 부활시킴
- 구글 지식 패널(Knowledge Graph)의 모태: 구글 검색창에 인물을 치면 오른쪽에 출생지, 가족, 직업이 박스로 정리되어 나오는 기술이 바로 시맨틱 웹 온톨로지와 RDF 트리플의 결정체

## 이웃 토픽과 구분
- HTML 웹 vs 시맨틱 웹: HTML 웹은 `<h1>제목</h1>`처럼 화면에 어떻게 '보여줄 것인가(Presentation)'만 정의 / 시맨틱 웹은 `<author>홍길동</author>`처럼 그 데이터가 무엇을 '의미하는가(Meaning)'를 정의

- 적용 상황: 국가 공공 행정 지식 포털의 시맨틱 웹 및 LOD 기반 오픈데이터 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 부처마다 동일한 용어(예: '청년', '저소득층')의 기준이 달라 통합 검색 실패 | 부처별 고유 이기종 DB 스키마 사일로화 | 국가 공통 표준 온톨로지(OWL) 구축 및 용어 매핑(SKOS) 적용 | 부처 간 공공 데이터 상호운용성 100% 확보 |
| 수백만 건 공공 문서를 RDF 트리플로 수작업 변환 시 천문학적 비용 소요 | 전문 온톨로지스트 수작업 메타데이터 입력의 한계 | LLM 정보 추출(Information Extraction) 파이프라인 기반 자동 RDF 트리플 변환 | 메타데이터 구축 공수 90% 절감 |
| 수억 개 RDF 트리플 복합 조인 질의 시 SPARQL 쿼리 타임아웃 발생 | 그래프 트리플 스토어의 분산 인덱싱 한계 | HDT(Header-Dictionary-Triples) 이진 압축 인덱싱 및 분산 그래프 DB 전환 | 복합 질의 응답 시간 100ms 이내 단축 |
