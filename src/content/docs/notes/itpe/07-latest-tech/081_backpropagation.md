## 연관 키워드

- 역전파(Backpropagation), 연쇄 법칙(Chain Rule), 국소 기울기(Local Gradient), 계산 그래프(Computational Graph), 자동 미분(Automatic Differentiation)
- 경사 하강법, 옵티마이저(Optimizer), 기울기 소실(Vanishing Gradient), 기울기 폭주(Exploding Gradient), 기울기 클리핑(Gradient Clipping)
- 활성화 체크포인팅(Activation Checkpointing), ZeRO, 혼합 정밀도, FlashAttention, 1F1B, 수치 미분, 기호 미분

## Ⅰ. 역전파의 개요

- 핵심 요약 : 출력 오차를 입력 방향으로 연쇄 법칙에 따라 전파해, 모든 가중치의 기울기를 한 번의 역방향 계산으로 구하는 알고리즘.
- 개념 : 예측값과 정답의 차이인 손실을 출력층에서 입력층 방향으로 전파하며 **연쇄 법칙** (Chain Rule, 합성 함수의 미분을 각 단계 미분의 곱으로 계산하는 규칙)으로 각 가중치의 기울기를 구하는 **역전파** (Backpropagation) 알고리즘.
- 배경 및 필요성 : 층이 깊어지면 연쇄 곱 때문에 기울기 소실과 기울기 폭주가 생기고, 역전파에 쓰일 순전파 중간값을 메모리에 보관해야 하므로 GPU 메모리 병목이 발생한다. 따라서 활성화 함수 변경, 잔차 연결, 메모리 절약 기법을 함께 적용해야 한다.
- 주요 목적 : 파라미터마다 순전파를 다시 실행하는 수치 미분의 비용을 피하고, 한 번의 역방향 계산으로 모든 파라미터의 편미분을 얻어 가중치를 갱신하는 것.

## Ⅱ. 역전파의 특징 및 장점

- 핵심 요약 : 연쇄 법칙의 재사용과 계산 그래프 구조가 전체 기울기를 한 번의 역방향 패스로 얻게 하는 효율의 원천.

1. **연쇄 법칙 재사용** : 각 노드의 **국소 기울기** (Local Gradient, 노드 입력에 대한 출력의 미분값)와 상위에서 유입된 기울기를 곱해 하위로 전달 → 중복 계산 없이 모든 파라미터의 기울기 산출.
2. **계산 그래프** (Computational Graph, 연산을 노드와 간선으로 나타낸 그래프) : 순전파 연산의 역방향 위상 정렬로 전파 순서를 결정 → 임의의 연산 구조에서도 기울기 계산 가능.
3. **자동 미분** (Automatic Differentiation, 연산 기록을 바탕으로 미분값을 자동 계산하는 방식) : 역방향 모드(Reverse-mode) 자동 미분으로 파라미터 수에 비례하는 비용에 전체 기울기 계산 → 대규모 모델 학습의 기반.
4. **옵티마이저 분리** : 역전파는 기울기 계산만 담당하고 가중치 갱신은 옵티마이저(Optimizer)가 맡음 → 계산 엔진과 갱신 알고리즘을 독립적으로 교체.

## Ⅲ. 역전파의 구조 (흐름)

- 핵심 요약 : 순전파에서 중간 활성화를 보관하고, 역방향으로 국소 기울기를 곱해 파라미터 기울기와 하위 층 기울기를 만드는 2단계 흐름.
- 순전파 : 입력과 가중치로 z = W·a_prev + b와 활성화 a = σ(z)를 계산하고, 역전파에 필요한 값을 캐시에 보관한다.
- 역방향 : 상위에서 받은 기울기 da에 활성화 함수의 도함수 σ'(z)를 곱해 dz를 만든 뒤, dW = dz · a_prev^T로 가중치 기울기를 얻고 da_prev = W^T · dz로 하위 층에 전달한다.

```text
[ 입력 a_prev ]
      ↓  순전파: z = W·a_prev + b
[ 활성화 a = σ(z) ] → 다음 층
      ↑  역전파: 상위 기울기 da 유입
[ dz = da × σ'(z) ]
      ↓  국소 기울기 곱
[ dW = dz · a_prev^T ] → 옵티마이저
[ da_prev = W^T · dz ] → 하위 층
```

```text
순전파: 활성화 값 저장 (메모리 사용 증가)
      ↓
역전파: 저장된 값으로 기울기 계산
      ↓
체크포인팅: 일부만 저장, 필요 시 재계산
            (메모리 감소, 연산 증가)
```

## Ⅳ. 수치 미분, 기호 미분, 자동 미분의 비교

- 핵심 요약 : 수치 미분은 파라미터 수만큼 순전파를 반복해 비효율적이고, 기호 미분은 수식이 커지면 폭증하며, 역방향 자동 미분이 학습에 적합한 방식.

| 비교 항목 | 수치 미분 (Numerical Differentiation) | 기호 미분 (Symbolic Differentiation) | 역방향 자동 미분 (Reverse-mode AD, 역전파) |
| --- | --- | --- | --- |
| 동작 방식 | 함수값의 차분으로 기울기를 근사 | 수식을 대수 규칙으로 전개 | 계산 그래프에서 연쇄 법칙을 누적 적용 |
| 계산 비용 | 파라미터마다 순전파 재실행 | 수식 크기에 따라 급격히 증가 | 순전파 1회와 역전파 1회로 전체 기울기 산출 |
| 수치 특성 | 반올림과 절단 오차 발생 | 해석적 해를 얻을 수 있음 | 부동소수점 오차 범위 내의 정확한 기울기 |
| 제어 흐름 지원 | 가능 | 분기와 반복문 처리가 어려움 | 동적 계산 그래프로 분기와 반복 지원 |

- 선택 기준 : 대규모 신경망 학습에서는 비용과 제어 흐름 지원을 고려해 역방향 자동 미분을 사용하며, 수치 미분은 기울기 구현 검증용으로 쓰이기도 한다.

## Ⅴ. 역전파의 한계와 방안

- 핵심 요약 : 기울기 소실과 폭주, 중간 활성화 메모리 부담을 활성화 함수, 정규화, 체크포인팅, 분산 메모리 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기울기 소실 | 연쇄 곱으로 앞쪽 은닉층의 기울기가 0에 수렴해 학습 정체 | GELU와 ReLU 같은 활성화 함수, 잔차 연결, He 가중치 초기화 | 층별 기울기 크기 |
| 중간 활성화 메모리 병목 | 역전파까지 모든 층의 활성화를 GPU 메모리에 유지해야 함 | **활성화 체크포인팅** (Activation Checkpointing, 일부만 저장하고 필요할 때 순전파를 부분 재계산하는 기법), **ZeRO** (Zero Redundancy Optimizer, 상태를 장치마다 중복 없이 나누는 기법) | 피크 메모리 사용량 |
| **기울기 폭주** (Exploding Gradient) | 기울기가 비정상적으로 커져 가중치가 NaN으로 발산 | **기울기 클리핑** (Gradient Clipping, 기울기 노름이 임계값을 넘으면 크기를 제한하는 기법), LayerNorm 적용 | 기울기 노름 추이, NaN 발생 횟수 |

## Ⅵ. 역전파 기반 학습의 기술사적 제언

- 핵심 요약 : 역전파의 연산 효율을 살리면서 메모리와 분산 실행의 병목을 함께 줄이는 최적화 체계 필요.

1. 메모리 최적화 우선 적용 : 혼합 정밀도(BF16, FP16)와 **FlashAttention** (어텐션 연산을 GPU 메모리 계층에 맞춰 재구성해 중간 행렬 저장을 줄이는 기법)을 학습 파이프라인의 기본 설정으로 두어 활성화 메모리 절감을 먼저 확보한다.
2. 분산 학습 파이프라인 설계 : 모델을 여러 장치에 나눠 학습할 때 **1F1B** (One Forward, One Backward, 순전파와 역전파를 번갈아 수행해 장치 유휴 시간을 줄이는 스케줄)를 적용해 GPU 유휴 구간을 줄인다.
3. 학습 안정성 점검 : 기울기 노름과 손실 곡선을 모니터링 항목으로 등록해 발산 징후를 조기에 감지하고, 재개 또는 중단 기준을 사전에 정한다.

## Ⅶ. 결론

- 핵심 요약 : 역전파는 연쇄 법칙을 계산 그래프 위에서 재사용해 모든 가중치의 기울기를 효율적으로 구하는 딥러닝 학습의 핵심 알고리즘.
- 시사점 : 모델이 커질수록 계산보다 메모리와 분산 실행이 병목이 되므로, 역전파 자체의 정확성과 함께 메모리 관리 기법을 설계 단계에서 함께 고려해야 한다.
