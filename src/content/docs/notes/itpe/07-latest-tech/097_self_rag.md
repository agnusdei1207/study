## Ⅰ. Self-RAG의 개요

- 개념 : **Self-RAG**(Self-Reflective Retrieval-Augmented Generation)는 대규모 언어모델(LLM, Large Language Model)에 **반성 토큰**을 학습시켜 검색 필요성, 검색 문서 관련성, 생성 내용의 근거 지지와 유용성을 평가하면서 답변을 생성하는 방법.
- 배경 : 검색 증강 생성(RAG, Retrieval-Augmented Generation)에서 항상 일정 수의 문서를 검색하면 불필요한 검색과 관련 없는 문서가 답변 품질을 낮추는 문제 발생.
- 목적 : 필요한 시점의 검색과 근거 평가로 사실성·인용 정확도를 개선. 학습된 평가가 사실의 수학적 증명이나 환각의 완전 제거를 의미하지 않음.

## Ⅱ. 학습과 추론 메커니즘

```text
학습: 비평 모델로 반성 토큰 주석 생성
      → 생성 모델에 문장 생성과 반성 토큰 예측 학습
추론: 질의·이전 생성 내용 → 검색 필요성 예측
      → 필요 시 문서 검색 → 문서별 후보 세그먼트 생성
      → 관련성·지지성·유용성 점수 → 후보 선택·반복
```

- **Retrieve** : 다음 세그먼트 생성에 검색이 필요한지 예측. 매 일반 토큰마다 무조건 외부 검색을 실행한다는 의미가 아님.
- **IsRel** : 검색 문서가 질의와 관련 있는지 평가.
- **IsSup** : 생성 세그먼트의 주장이 문서에 의해 지지되는지 평가. 문서 자체의 진실성을 별도로 보증하지 않음.
- **IsUse** : 생성 결과의 유용성을 평가. 문서 지지 여부와 사용자에게 유용한 답변인지 구분.
- **세그먼트 단위 빔 탐색** : 후보의 생성 확률과 반성 토큰 점수를 조합하여 선택. 반성 점수의 가중치와 검색 임계값으로 추론 동작 조정.

## Ⅲ. 고정 검색 RAG와의 비교

| 관점 | 고정 검색 RAG | Self-RAG |
|---|---|---|
| 검색 | 입력마다 정해진 검색 실행 | 반성 토큰과 임계값으로 검색 필요성 판단 |
| 모델 | 일반 생성 모델과 검색기 조합 가능 | 반성 토큰을 학습한 생성 모델 필요 |
| 근거 평가 | 별도 평가기·프롬프트를 추가할 수 있음 | 생성 모델 내부의 학습된 비평 활용 |
| 품질 | 검색기·문서·생성기의 품질에 의존 | 동일한 의존성과 반성 평가의 오류 가능성 존재 |

- 원 논문에서 비평 데이터 생성에 사용한 모델을 모든 구현의 필수 서비스로 일반화하지 않도록 구분. 추론 시 외부 비평 모델을 매번 호출하는 구조와도 구별.
- 참고 : [Self-RAG 원 논문](https://arxiv.org/abs/2310.11511).

## Ⅳ. Self-RAG의 한계점 및 해결 방안

- 추가 학습 비용 : 반성 토큰과 근거 평가 데이터의 품질을 검증하고 파인튜닝 환경 및 라이선스 확인.
- 추론 지연 : 문서 수, 검색 임계값, 빔 폭과 비평 가중치를 업무별 평가셋에서 조정.
- 잘못된 근거와 자기평가 : 검색 자료의 출처·최신성 및 실제 인용 일치 여부를 별도로 확인. 근거 부족 시 답변 보류·추가 검색·사람 검토 정책 적용.

## Ⅴ. Self-RAG 적용을 위한 제언

- 같은 질의·검색 자료·평가 기준으로 기존 RAG와 비교하여 품질 개선과 추가 비용을 함께 측정.
- 고위험 업무에서는 반성 점수를 확정적 사실 판정으로 취급하지 않고 출처 검증과 사람의 판단 절차를 결합.
