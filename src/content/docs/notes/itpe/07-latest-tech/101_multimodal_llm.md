- **본질**: 멀티모달 LLM은 언어와 이미지·음성 등 여러 모달리티를 함께 처리하는 언어 모델 계열이다.
- **메커니즘**: 모달리티별 표현을 공통 모델 입력에 연결해 언어 지시와 결합하여 처리한다.
- **한계**: 구조는 모델마다 다르며, 시각적 환각과 해상도·처리량·비용을 검증해야 한다.

<details><summary>핵심 용어</summary>

- **멀티모달 LLM**: Multimodal Large Language Model(MLLM). 언어와 비언어 입력을 함께 처리하는 모델
- **대규모 언어 모델(Large Language Model, LLM)**: 대규모 자료로 학습해 언어 입력·출력을 처리하는 모델이다.
- **비전 인코더**: 이미지에서 모델 입력으로 쓸 표현을 추출하는 모듈이다.
- **프로젝터**: 비전 표현을 언어 모델의 표현 공간에 맞추는 연결 모듈의 한 종류다.
- **시각적 환각**: 이미지에 근거가 없는 사물·속성을 모델이 답변에 포함하는 오류다.

## 2~4교시 25점 답안
## Ⅰ. 개념과 필요성
| 구분 | 핵심 |
|---|---|
| 정의 | **멀티모달 LLM**은 언어·이미지·음성 등 복수 모달리티를 결합해 처리하는 언어 모델 |
| 목적 | 시각·음성 정보를 언어 이해와 함께 처리 |

멀티모달 LLM은 언어와 이미지·음성 등 둘 이상의 모달리티를 함께 다룬다. 텍스트 질의에 이미지 내용을 결합해 답하거나 음성 입력을 처리하는 과업에 활용할 수 있다.

| 모델 유형 | 입력·처리 범위 |
|---|---|
| 텍스트 전용 LLM | 텍스트를 중심으로 처리 |
| 결합형 MLLM | 전용 인코더의 표현을 언어 모델에 연결하는 구성 가능 |
| 통합형 MLLM | 여러 모달리티를 보다 통합된 방식으로 학습·처리하는 구성 가능 |

## Ⅱ. 인코더·언어 모델 연결
```text
이미지·음성 입력
    ↓ 모달리티별 인코딩
비언어 표현
    ↓ 언어 지시와 결합
멀티모달 LLM
    ↓ 생성
응답
```

비전 인코더가 시각 특징을 만들고 프로젝터가 이를 언어 모델 표현에 맞추는 방식은 대표적 결합형 구조다. 모델에 따라 별도 인코더, 토큰 연결, 공동 학습 방식이 달라지므로 구현별 구조를 확인한다.

## Ⅲ. 품질·운영 고려사항
| 관점 | 위험·제약 | 확인 방법 |
|---|---|---|
| 인식 품질 | 작은 글자·복잡한 장면의 오독 | 해상도·장면별 검증셋 평가 |
| 근거성 | 이미지에 없는 내용의 생성 | 답변 근거 대조와 오류 사례 수집 |
| 자원 | 고해상도·긴 영상 입력의 처리 비용 | 해상도·프레임·토큰 정책 측정 |
| 개인정보 | 민감한 이미지·음성의 유출 | 저장·전송·접근 통제 검토 |

멀티모달 처리가 추가되어도 지각 오류나 환각이 사라지는 것은 아니다. 의료·안전 등 고위험 업무에서는 전문 검토와 책임 체계를 유지한다.

## Ⅳ. 기술사적 제언
