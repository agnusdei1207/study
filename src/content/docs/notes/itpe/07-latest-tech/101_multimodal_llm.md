## 연관 키워드

- 멀티모달 LLM(MLLM, Multimodal Large Language Model), LLM(Large Language Model), 모달리티(Modality)
- ViT(Vision Transformer), 정렬 프로젝터(Projector), Q-Former, 교차 모달 이해
- 시각적 환각(Visual Hallucination), Visual Grounding, VQA(Visual Question Answering), 토큰 압축, OCR(Optical Character Recognition)

## Ⅰ. 멀티모달 LLM의 개요

- 핵심 요약 : 텍스트, 이미지, 음성, 영상을 하나의 언어 모델에서 함께 이해하고 생성하는 대형 신경망 방식.
- 개념 : 텍스트, 이미지, 음성, 영상 등 여러 **모달리티**(Modality)의 입력을 공통 표현 공간에 사상하여 교차 모달 이해와 생성 추론을 수행하는 **멀티모달 LLM**(Multimodal Large Language Model) 구조.
- 배경 및 필요성 : 텍스트만 다루는 모델은 물리 세계의 시각 정보를 읽지 못하고, 이미지에 없는 객체를 그럴듯하게 지어내는 **시각적 환각**(Visual Hallucination)이 발생한다. 또한 고해상도 입력은 토큰 수를 급증시키므로, 시각 근거를 좌표로 검증하는 방식과 토큰 압축 기법이 함께 필요하다.
- 주요 목적 : 차트·문서·영상 같은 복합 현실 업무를 한 모델로 처리하여 텍스트 중심 한계를 넘는 것.

## Ⅱ. 멀티모달 LLM의 특징 및 장점

- 핵심 요약 : 모달리티별 인코더와 정렬 계층을 거쳐 하나의 언어 모델이 모든 입력을 같은 토큰 공간에서 다루는 구조.

1. 교차 모달 추론 : 이미지 토큰과 텍스트 토큰을 같은 셀프 어텐션에서 처리 → 그림과 질문을 함께 근거로 삼는 답변 가능.
2. 자연스러운 대화 인터페이스 : 사용자 질문과 시각 입력을 한 대화 흐름에 묶음 → 별도 OCR 후처리 없이 문서 질의 응답 가능.
3. 모듈 재사용 : 사전학습된 비전 인코더와 LLM을 프로젝터로 연결하여 개발 → 처음부터 학습하는 것보다 개발 부담 감소.

```text
[ 모달리티 통합 흐름 ]

이미지 / 음성 / 영상 / 텍스트
      ↓ 모달리티별 인코더
공통 임베딩 (정렬 프로젝터)
      ↓
LLM 디코더 (단일 생성)
```

## Ⅲ. 멀티모달 LLM의 구조 (흐름)

- 핵심 요약 : 모달리티별 인코더가 추출한 임베딩을 정렬 프로젝터가 언어 모델의 토큰 공간으로 옮겨 하나의 디코더에서 융합하는 흐름.
- **정렬 프로젝터**(Projector) : 시각 벡터를 언어 모델의 임베딩 차원으로 투영하는 계층. 선형 MLP(Multilayer Perceptron) 또는 **Q-Former** 같은 교차 어텐션 구조로 구현.
- **ViT**(Vision Transformer) : 이미지를 패치로 나누어 패치별 특징 벡터를 추출하는 시각 인코더.

```text
[ 이미지 입력 ]          [ 텍스트 질의 ]
      ↓                       ↓
ViT (패치 특징 추출)     텍스트 토크나이저
      ↓                       │
정렬 프로젝터 (차원 투영)      │
      ↓                       │
시각 토큰 + 텍스트 토큰 (시퀀스 결합)
                  ↓
LLM 디코더 (셀프 어텐션)
                  ↓
텍스트 답변 생성
```

## Ⅳ. 멀티모달 LLM의 비교 분석

- 핵심 요약 : 파이프라인 연계형은 구현이 쉽지만 공간 정보를 잃고, 네이티브 통합형은 성능이 좋지만 개발 부담이 가장 크다.

| 비교 항목 | 파이프라인 연계형 | 인코더-프로젝터 결합형 (LLaVA형) | 네이티브 통합형 (GPT-4o, Gemini 계열) |
| --- | --- | --- | --- |
| 구조 형태 | OCR·캡셔닝 결과를 텍스트 LLM에 전달 | 독립 비전 인코더 + 프로젝터 + LLM | 처음부터 여러 모달리티를 함께 사전학습 |
| 시각 이해력 | 텍스트 변환 중 공간 정보 손실 | 객체와 공간 관계 파악 가능 | 세밀한 공간 추론과 음성 이해 |
| 추론 속도 | 앞단 모듈 직렬 실행으로 지연 누적 | 프로젝터 연산 부담 작음 | 통합 처리로 저지연 실시간 응답 |
| 개발 난이도 | 낮음 (기존 모델 조립) | 중간 (오픈 모델 튜닝 가능) | 매우 높음 (대규모 데이터와 연산 필요) |

- 선택 기준 : 공간 정밀도, 응답 지연, 자체 구축 여력을 기준으로 적용 방식을 정한다.

## Ⅴ. 멀티모달 LLM의 한계와 방안

- 핵심 요약 : 시각 환각, 토큰 폭증, 미세 텍스트 판독 실패를 근거 좌표 검증, 토큰 축약, 고해상도 분할 처리로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 시각적 환각 | 이미지에 없는 객체·텍스트를 생성 → 잘못된 판단 | 시각 선호 정렬 학습과 Visual Grounding(답변마다 영역 좌표 출력) | 환각 응답 비율 |
| 고해상도 입력의 토큰 폭증 | 시각 토큰 증가 → 컨텍스트 초과와 지연 | 유사 토큰 병합(토큰 풀링), 중요 영역만 고해상도 처리 | 입력당 토큰 수, 지연 시간 |
| 도면·표의 미세 텍스트 판독 실패 | 해상도 축소로 글자 인식률 저하 | OCR 전용 보조 인코더 병렬 결합, 슬라이딩 윈도우 인코딩 | 수치 판독 정확도 |

## Ⅵ. 멀티모달 LLM에 대한 기술사적 제언

- 핵심 요약 : 정확도와 근거 추적, 비용 통제를 함께 설계하여 멀티모달 기능을 업무 시스템에 믿고 쓸 수 있는 수준으로 올리는 방향.

1. 문서 처리 부서가 원본 해상도를 유지하는 타일링 입력 체계를 도입하여 표와 도면의 수치를 오독하지 않도록 한다.
2. 인공지능 개발 조직이 답변마다 근거 영역을 함께 제시하도록 평가 기준을 정하고, 근거 없는 답변을 걸러내는 검증 단계를 운영한다.
3. 플랫폼 운영 부서가 입력 토큰을 측정하여 중요 영역만 압축하는 정책을 세우고, 비용과 정확도를 함께 보는 대시보드를 갖춘다.

## Ⅶ. 결론

- 핵심 요약 : 멀티모달 LLM은 텍스트 모델에 눈과 귀를 더해 실제 문서와 현장 자료를 다루게 하는 통합 추론 구조.
- 시사점 : 시각 근거를 검증할 수 있는 체계가 함께 있어야 실무 활용 가치가 생기므로, 모델 선택보다 근거 추적 설계가 먼저 판단되어야 한다.
