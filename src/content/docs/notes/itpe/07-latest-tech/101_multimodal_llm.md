## 30초 인출

- 본질: **멀티모달 LLM (MLLM)** 은 텍스트뿐만 아니라 이미지, 비디오, 음성 등 복수의 이종 모달리티 데이터를 단일 언어모델의 인지 공간에 통합하여 복합 추론 및 상호 변환을 수행하는 차세대 인공지능 모델
- 메커니즘: 모달리티별 사전학습 인코더(ViT, Whisper 등)로 추출한 임베딩을 정렬 프로젝터(MLP/Q-Former)를 통해 LLM 토큰 임베딩 공간으로 투영한 후 단일 자기회귀 디코더에서 융합 생성
- 통찰: 이미지에 실재하지 않는 객체를 날조하는 시각적 환각(Visual Hallucination)과 고해상도 입력에 따른 토큰 폭증 병목이 심각하므로 시각 접지(Grounding) 검증과 동적 패치 압축 기법 구축 필수

<details><summary>핵심 용어</summary>

- **MLLM (Multimodal Large Language Model)** : 텍스트와 비정형 시각·음성 신호를 상호 교차 이해하고 텍스트 또는 멀티모달로 응답하는 초거대 인공지능.
- **비전 인코더 (Vision Encoder)** : 입력 이미지를 패치(Patch) 단위로 분할하여 고차원 시각 피처 벡터를 추출하는 ViT(Vision Transformer) 기반 신경망.
- **프로젝터 (Multimodal Projector)** : 비전 인코더의 특징 벡터 차원을 LLM의 텍스트 토큰 임베딩 차원에 일치시키는 선형 레이어(MLP) 또는 어텐션 모듈.
- **네이티브 옴니 (Native Omni Model)** : 별도의 인코더 결합 방식이 아닌 모든 모달리티를 처음부터 단일 토크나이저와 트랜스포머로 통합 사전학습한 모델(예: GPT-4o).
- **시각적 환각 (Visual Hallucination)** : 이미지 내에 없는 사물, 텍스트, 색상 속성을 모델이 존재하는 것처럼 거짓 서술하는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 멀티모달 LLM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **멀티모달 LLM** 은 텍스트, 이미지, 음성, 비디오 등 다양한 양식(Modality)의 입력을 공통 표현 공간(Shared Latent Space)에 사상하여 교차 모달 이해 및 생성 추론을 수행하는 대형 신경망 아키텍처 |
| 목적 | 텍스트 단일 모달의 물리적 세계 인식 한계를 극복하고 시각 문서 이해(VQA), 차트 분석, 비디오 추론 등 복합 현실 업무 자동화 달성 |

## Ⅱ. 멀티모달 LLM의 핵심 아키텍처 및 정렬 특징

| 아키텍처 구성 요소 | 핵심 기능 및 동작 원리 | 공학적 특징 |
|---|---|---|
| **모달리티별 인코더** | ViT(이미지), Audio Spectrogram Transformer(음성) | 로우 데이터(Raw Data)로부터 고수준 의미적 표현 벡터 추출 |
| **정렬 프로젝터 (Projector)** | Linear MLP 또는 Cross-Attention Q-Former | 시각 벡터를 언어모델의 단어 임베딩 차원(Hidden Dimension)으로 투영 |
| **언어모델 백본 (LLM Backbone)** | Llama, Mistral 등 사전학습 디코더 트랜스포머 | 시각 가상 토큰(Visual Soft Tokens)을 텍스트 토큰과 동등하게 어텐션 |
| **2단계 학습 전략** | 1단계: 프로젝터 사전정렬 ──> 2단계: 시각 지시 튜닝 | 베이스 LLM 가중치는 동결한 채 프로젝터와 LoRA 어댑터만 미세조정 |

## Ⅲ. 멀티모달 LLM의 입력-정렬-생성 파이프라인

```text
┌────────────────────────────────────────────────────────────────────────┐
│             멀티모달 LLM (MLLM) 종단간 추론 아키텍처                  │
└────────────────────────────────────────────────────────────────────────┘
 [ 입력 이미지 (Image) ]                       [ 사용자 텍스트 질의 (Prompt) ]
            │                                                 │
            ▼                                                 ▼
 ┌─────────────────────────┐                       ┌─────────────────────────┐
 │ Vision Transformer (ViT)│                       │ 텍스트 토크나이저       │
 │ - 14x14 패치 분할       │                       │ (Byte-Pair Encoding)    │
 │ - 패치별 특징 추출      │                       └────────────┬────────────┘
 └──────────┬──────────────┘                                    │
            │ Image Feature Vectors (H_v)                       │ Text Tokens (T_q)
            ▼                                                   │
 ┌─────────────────────────────────────────┐                    │
 │ 멀티모달 프로젝터 (MLP / Cross-Attention)│                    │
 │ - 차원 투영: d_vision ──> d_llm         │                    │
 └──────────┬──────────────────────────────┘                    │
            │ Visual Token Embeddings (V_1...V_n)               │
            └───────────────────────┬───────────────────────────┘
                                    │ Concatenation (시퀀스 결합)
                                    ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ LLM 트랜스포머 백본 (Self-Attention Layer)                            │
 │                                                                      │
 │  Input: [ <image>, V_1, V_2, ..., V_n, </image>, "이 차트를 분석하라" ]│
 │                                                                      │
 │  - 멀티-헤드 셀프 어텐션을 통한 비전 토큰과 텍스트 토큰 간 상호작용   │
 │  - 인과적 마스킹(Causal Masking) 기반 다음 단어 확률 예측            │
 └──────────────────────────────────┬───────────────────────────────────┘
                                    │
                                    ▼
                [ 최종 텍스트 답변 생성 (Multimodal Output) ]
```

| 파이프라인 단계 | 처리 내용 | 주요 기술 스택 |
|---|---|---|
| **입력 전처리** | 고해상도 이미지를 고정 크기 그리드 패치로 슬라이싱 및 정규화 | OpenCV, TorchVision |
| **특징 추출** | 사전학습된 CLIP-ViT-L/14 등을 통과하여 시각 토큰 열 생성 | CLIP, SigLIP |
| **공간 투영 정렬** | 2계층 비선형 활성화 MLP를 통해 언어 임베딩 크기로 변환 | GeLU 활성화 함수 |
| **통합 생성 디코딩** | 시각 토큰을 소프트 프롬프트처럼 취급하여 KV 캐시 생성 및 텍스트 디코딩 | FlashAttention-2, vLLM |

## Ⅳ. 멀티모달 결합 방식 비교

| 비교 항목 | 파이프라인 연계형 (Pipeline) | 인코더-프로젝터 결합형 (LLaVA형) | 네이티브 옴니 통합형 (GPT-4o/Gemini) |
|---|---|---|---|
| **구조 형태** | OCR/Captioning + 텍스트 LLM | 독립 비전 인코더 + MLP + LLM | 처음부터 모든 모달리티 단일 사전학습 |
| **시각 이해력** | 텍스트 변환 과정에서 공간 정보 소실 | 세부 물체 인식 및 공간 관계 파악 | 초정밀 공간 추론 및 음성 억양 파악 |
| **추론 속도** | 앞단 모듈 직렬 실행으로 지연 누적 | 프로젝터 연산 오버헤드 미미 | 통합 토크나이저로 초저지연 실시간 처리 |
| **개발 난이도** | 매우 낮음 (기존 모델 단순 조립) | 중간 (오픈소스 기반 튜닝 가능) | 극도로 높음 (막대한 데이터 및 컴퓨팅) |
| **적용 사례** | 단순 영수증 OCR 처리 | 오픈소스 LLaVA, CogVLM | 실시간 통역, 음성-비전 상호작용 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 이미지 내에 존재하지 않는 객체나 텍스트를 그럴듯하게 날조하는 시각적 환각(Visual Hallucination) 발생 | DPO 기반 시각 선호 정렬(RLAIF-V) 적용 및 세부 패치별 객체 바운딩 박스를 함께 출력시키는 Visual Grounding 강제 |
| 4K/8K 고해상도 이미지 또는 긴 동영상 입력 시 시각 토큰 수가 수천 개로 폭증하여 컨텍스트 초과 및 추론 지연 | 유사한 시각 토큰을 병합하는 토큰 풀링(Token Pooling) 기법과 중요 영역만 고해상도로 보는 동적 고화질 패칭(Dynamic AnyRes) 적용 |
| 도면, 금융 표, 차트 내 극미세 텍스트와 좌표 수치 판독 시 해상도 축소로 인한 인식률 급락 | OCR 전용 보조 인코더를 병렬 결합하는 듀얼 비전 인코더 구조 및 고해상도 슬라이딩 윈도우 인코딩 도입 |

## Ⅵ. 제언

산업 현장의 고해상도 도면 및 비정형 문서 분석을 위해 동적 해상도 분할(AnyRes)과 비주얼 그라운딩 검증기를 결합한 고신뢰 MLLM 서빙 아키텍처 구축 권고.

```text
[ 초고해상도 이미지 입력 (예: 4096 x 3072 도면) ]
                       │
                       ▼
┌────────────────────────────────────────────────────────┐
│ 동적 해상도 분할기 (Dynamic AnyRes Grid Splitter)       │
│  - 원본을 축소한 글로벌 썸네일 1장 + 고해상도 타일 4~9장│
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ SigLIP 듀얼 인코더 & 지능형 토큰 압축기 (Token Pruning) │
│  - 배경 무의미 패치 60% 필터링 (토큰 비용 절감)        │
└──────────────────────────┬─────────────────────────────┘
                           │ 압축된 시각 토큰
                           ▼
┌────────────────────────────────────────────────────────┐
│ 멀티모달 LLM 백본 + 비주얼 그라운딩 검증 게이트        │
│  - 텍스트 답변 생성 시 참조한 바운딩 박스 좌표 동시 표기│
│  - 검증기(Verifier) 신뢰도 미달 시 재추론 인터록      │
└────────────────────────────────────────────────────────┘
```

| 구분 | 고정 해상도 다운샘플링 MLLM | 제언: 동적 타일링 + 그라운딩 결합 MLLM |
|---|---|---|
| **미세 텍스트 인식** | 해상도 뭉개짐으로 오독 발생 | 원본 해상도 타일링으로 100% 인식 |
| **토큰 효율성** | 모든 픽셀을 토큰화하여 낭비 | 중요 객체 영역만 선별 압축하여 50% 절감 |
| **환각 방지** | 블랙박스 텍스트 생성 | 텍스트마다 이미지 근거 좌표(Box) 매핑 |
| **문서 처리 품질** | 일반 사진 캡셔닝 국한 | 복잡 도면, 의료 영상, 재무제표 판독 완결 |
