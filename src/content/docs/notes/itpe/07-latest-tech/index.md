## 8과목 전체 로드맵과 현재 위치

```text
                    [01 IT 경영전략]
               전략·거버넌스·투자·서비스
                         │
       ┌─────────────────┼─────────────────┐
       ▼                 ▼                 ▼
[02 SW 공학]        [03 데이터]       [04 컴퓨터시스템]
개발·품질·PM        DB·분석·AI데이터   CA·OS·알고리즘
       │                 │                 │
       └────────────┬────┴────┬────────────┘
                    ▼         ▼
              [05 네트워크] ─── [06 보안]
              연결·전송·제어     보호·복원·신뢰
                    │             │
                    └──────┬──────┘
                           ▼
                 [07 최신기술 ◀ 현재 과목]
                 AI·에이전트·블록체인·융합
                           │
                           ▼
                    [08 법률·정책·윤리]
                  규제·표준·책임·준거성
```

- 현재 과목 역할: 앞선 과목의 기반기술을 AI·에이전트·산업 서비스로 조합하고 가치·위험·운영 모델까지 연결
- 연계 축: `03 데이터 품질 → 07 모델 학습·평가 → 06 보안·신뢰 → 01 거버넌스 → 08 법·윤리`

## 07 최신기술 확대 지도

```text
                       [문제·가치 정의]
                  AX · 산업서비스 · 사용자 요구
                              │
                              ▼
                     [데이터·표현 기반]
           품질·라벨링·합성데이터 · Embedding · Graph
                              │
                              ▼
                      [모델 학습·정렬]
       ML/DL · Transformer · Foundation Model · RLHF/DPO
                              │
              ┌───────────────┴────────────────┐
              ▼                                ▼
       [추론·검색·에이전트]                [평가·신뢰]
  RAG/GraphRAG · LRM · Agentic AI     혼동행렬·PR/ROC · 위험·윤리
              │                                │
              └───────────────┬────────────────┘
                              ▼
                        [운영·거버넌스]
             MLOps/LLMOps/ModelOps · AI Governance
                              │
                              ▼
                       [디지털 융합 서비스]
             Physical AI · Digital Twin · FinTech · XR
```

선의 의미: 데이터와 모델이 추론 서비스를 만들고, 평가·신뢰 결과가 운영·거버넌스 정책으로 환류되어 산업 적용을 통제하는 생명주기

### 30초 인출

```text
가치 → 데이터 → 모델 → 추론/에이전트 → 평가/신뢰 → 운영/거버넌스 → 융합

만들기: 품질·학습·정렬
쓰  기: RAG·Agent·Physical AI
재  기: 혼동행렬·PR/ROC·benchmark
지키기: Risk·Trust·Security·Governance
돌리기: MLOps·LLMOps·ModelOps
```

## 전체 키워드 보존과 누적 회독

| 단계 | 의미 | 누적 회독 |
|---|---|---|
| **기초** | 핵심 코어의 기본 개념 | 기초 |
| **서브** | 코어와 함께 이해할 주요 주변 요소 | 기초+서브 |
| **응용** | 코어를 전제로 한 파생·적용 요소 | 기초+서브+응용 |

전체 키워드를 보존하고 회독 범위만 누적 확장한다.
