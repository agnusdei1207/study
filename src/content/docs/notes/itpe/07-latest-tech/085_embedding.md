## 연관 키워드

- 임베딩(Embedding), 밀집 벡터, 분포 가설, Word2Vec, 문맥 임베딩
- 코사인 유사도, 서브워드 토큰화, OOV, 허브니스, RAG, 벡터 양자화

## Ⅰ. 임베딩(Embedding)의 개요

- 핵심 요약 : 단어·문서·이미지 같은 이산 대상을 의미 관계가 거리로 보존되는 연속 실수 벡터로 바꾸는 기술.
- 개념 : 단어, 문서, 이미지 등 이산 심볼을 의미적 유사도와 문맥 관계가 보존되는 고정 길이의 **밀집 벡터** (Dense Vector, 대부분 값이 0이 아닌 실수 벡터)로 변환하는 표현 학습 기술.
- 배경 및 필요성 : 단어마다 벡터 하나를 고정하는 정적 임베딩은 동음이의어를 구분하지 못하고, 학습 사전에 없는 **미등록 어휘** (OOV, Out-Of-Vocabulary)를 처리하지 못하는 한계가 있음. 이를 보완하려고 **서브워드 토큰화** (BPE, Byte-Pair Encoding)와 문맥을 양방향으로 읽는 **문맥 임베딩** (BERT, Bidirectional Encoder Representations from Transformers)이 쓰이게 됨.
- 주요 목적 : 희소 표현의 차원 문제 완화, 의미 기반 유사도 계산, 딥러닝 모델의 수치 입력 제공.

## Ⅱ. 임베딩(Embedding)의 특징 및 장점

- 핵심 요약 : 분포 가설에 따라 문맥이 비슷한 대상을 가까운 벡터로 배치하여, 거리 계산만으로 의미 검색과 유추가 가능해지는 표현 방식.

1. 차원 축소 : 어휘 수만큼 길어지는 희소 원-핫 벡터를 짧은 밀집 벡터로 압축 → 연산량과 저장 비용 감소.
2. 의미 거리 보존 : 의미가 가까운 대상일수록 벡터 간 각도가 작음 → **코사인 유사도** (Cosine Similarity) 기반 검색 가능.
3. 벡터 연산에 의한 유추 : 벡터 간 덧셈과 뺄셈으로 관계를 표현 (King - Man + Woman ≈ Queen) → 관계 추론 기능 확보.
4. **전이 학습** (Transfer Learning) : 대규모 말뭉치에서 사전 학습한 임베딩을 다른 과업에 재사용 → 적은 데이터로도 성능 확보.

## Ⅲ. 임베딩(Embedding)의 구조 (흐름)

- 핵심 요약 : 문맥 예측으로 단어 벡터를 학습하는 Word2Vec 계열과, 트랜스포머 인코더가 문맥별 벡터를 만드는 계열의 두 흐름.
- **분포 가설** (Distributional Hypothesis) : 비슷한 문맥에 나타나는 단어는 비슷한 의미를 가진다는 가정으로, 임베딩 학습의 출발점.
- **Word2Vec** : 중심어로 문맥을 예측(Skip-gram)하거나 문맥으로 중심어를 예측(CBOW, Continuous Bag of Words)하여 단어 벡터를 학습하는 방법.

```text
[ CBOW ]
문맥 단어들 (앞뒤 window)
          ↓ 평균 투영 (입력 행렬)
[ 은닉 표현 ]
          ↓ 출력 행렬
중심 단어 예측
```

```text
[ 문맥 임베딩 ]

입력 토큰 시퀀스
          ↓
트랜스포머 인코더 (셀프 어텐션)
          ↓
토큰마다 문맥을 반영한 벡터
          ↓
문장·문서 벡터 (풀링 또는 CLS 토큰 사용)
```

- 임베딩 행렬 : 어휘 크기 V와 벡터 차원 D로 정의되는 룩업 테이블로, 토큰 번호를 벡터로 바꾸는 역할.

## Ⅳ. 임베딩(Embedding) 세대별 비교

- 핵심 요약 : 빈도 기반 희소 표현에서 정적 밀집 임베딩을 거쳐 문맥 임베딩으로 발전하며, 의미 구분 능력이 향상됨.

| 발전 단계 | 대표 모델 | 기술적 메커니즘 | 문맥 반영 | 주요 한계 |
| --- | --- | --- | --- | --- |
| 1세대 통계 기반 희소 표현 | BoW(Bag of Words), TF-IDF(Term Frequency-Inverse Document Frequency) | 단어 빈도와 역문서 빈도 집계 | 미반영 (순서 무시) | 동음이의어 구분 불가, 차원 증가 |
| 2세대 정적 밀집 임베딩 | Word2Vec, GloVe, FastText | 동시 발생 통계와 윈도우 학습 | 미반영 (단어당 고정 벡터) | 같은 단어의 다른 의미를 구분 못 함 |
| 3세대 동적 문맥 임베딩 | ELMo, BERT, RoBERTa | 양방향 트랜스포머의 셀프 어텐션 | 반영 (문맥별 벡터) | 입력 길이 제한, 연산 비용 |

- 선택 기준 : 질의가 키워드 일치 중심인지 문맥 의미 중심인지, 그리고 추론 비용을 감당할 수 있는지에 따라 세대를 고름.

## Ⅴ. 임베딩(Embedding)의 한계와 방안

- 핵심 요약 : 미등록 어휘, 벡터 공간의 허브니스, 사전 의미와 검색 목적의 불일치를 서브워드, 정규화, 도메인 적응으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 미등록 어휘 (OOV) | 사전에 없는 단어는 벡터를 얻지 못해 정보 유실 | 서브워드 토큰화 적용, FastText식 문자 n-gram 결합 | OOV 토큰 비율 |
| **허브니스** (Hubness) | 고차원에서 일부 벡터가 여러 질의의 최근접 이웃으로 반복 등장 | 벡터 정규화와 주성분 분석(PCA, Principal Component Analysis) 기반 화이트닝 | 최근접 이웃 분포 편향도 |
| 사전 의미와 검색 목적의 불일치 | 일반 유사도가 검색 증강 생성(RAG, Retrieval-Augmented Generation)의 정답 기준과 어긋남 | 대조 학습 기반 도메인 어댑터 파인튜닝, 재순위화 모델(Reranker) 병용 | 검색 정확도 (Recall, nDCG) |

## Ⅵ. 임베딩(Embedding)에 대한 기술사적 제언

- 핵심 요약 : 키워드 검색과 의미 검색을 함께 쓰는 하이브리드 검색과 도메인 평가 체계를 갖춰 임베딩을 검색 품질 관리 대상으로 다루는 방향.

1. 검색 시스템 설계 단계에서 밀집 임베딩과 희소 검색을 결합하는 하이브리드 구조를 기본으로 채택하여 고유명사와 문맥 질의를 함께 처리하는 것이 필요함.
2. 데이터 팀은 도메인 질의와 정답 쌍으로 평가 세트를 구축하고, 임베딩 모델 교체 시 이 세트로 회귀 테스트를 수행하는 체계를 갖추는 것이 바람직함.
3. 인프라 측면에서는 벡터 양자화(Vector Quantization) 등 저장 방식의 압축 수준과 검색 지연을 함께 측정해 비용과 정확도의 균형점을 정하는 것이 현실적임.

## Ⅶ. 결론

- 핵심 요약 : 임베딩은 데이터의 의미를 거리로 바꿔 검색과 생성형 AI의 기반이 되는 표현 기술.
- 시사점 : 임베딩 품질은 모델 성능만이 아니라 평가 데이터와 검색 구조에 따라 결정되므로, 운영 단계의 측정 체계가 핵심 과제임.
