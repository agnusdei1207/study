<summary>핵심 용어</summary>

- **GraphRAG(Graph-based Retrieval-Augmented Generation)** : 지식 그래프와 검색을 결합해 생성 모델의 입력 문맥을 구성하는 접근
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)** : 외부 자료를 검색해 생성 모델의 응답 문맥에 제공하는 방식
- **지식 그래프(Knowledge Graph)** : 개체를 노드, 개체 간 관계를 연결로 표현한 구조화 지식
- **커뮤니티 요약(Community Summary)** : 그래프에서 관련된 개체 집단의 정보·관계를 요약한 자료
- **Local Search** : 질의 관련 개체·관계와 원문 근거를 중심으로 찾는 검색 방식
- **Global Search** : 그래프 집단의 요약을 종합해 자료 모음 전체에 관한 질문을 처리하는 검색 방식

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **GraphRAG(Graph-based Retrieval-Augmented Generation)** 는 문서에서 만든 지식 그래프와 검색 문맥을 생성 응답에 활용하는 RAG 접근 |
| 목적 | 개체 간 관계와 문서 집합의 주제를 검색·응답 근거에 반영 |

### Ⅱ. 인덱싱·질의 흐름

```text
원문 문서
    ↓ 개체·관계 추출
지식 그래프 구성
    ↓ 집단·요약 구성
그래프·원문 인덱스
    ↓ 질문별 검색
근거 문맥 구성 → 생성 응답
```

### Ⅲ. 기본 검색 관점

| 검색 관점 | 중심 자료 | 질문 유형 |
|---|---|---|
| Local Search | 질의 관련 개체·관계·원문 | 특정 항목·연결 관계 |
| Global Search | 그래프 집단 요약 | 코퍼스 전반의 주제·경향 |

제언: 관계·전역 요약 질의가 실제로 있는 자료 모음에 그래프 인덱싱을 선택 적용.

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **GraphRAG(Graph-based Retrieval-Augmented Generation)** 는 문서에서 만든 지식 그래프와 검색 문맥을 생성 응답에 활용하는 RAG 접근 |
| 목적 | 개체 간 관계와 문서 집합의 주제를 검색·응답 근거에 반영 |

### Ⅱ. 인덱싱·질의 흐름

```text
원문 문서
    ↓ 개체·관계 추출
지식 그래프 구성
    ↓ 집단·요약 구성
그래프·원문 인덱스
    ↓ 질문별 검색
근거 문맥 구성 → 생성 응답
```

### Ⅲ. 구성요소

| 구성 | 역할 |
|---|---|
| 원문·청크 | 검색·인용에 활용할 원본 문맥 보존 |
| 개체·관계 그래프 | 문서에 나타난 항목과 연결 구조화 |
| 커뮤니티 요약 | 관계 집단 단위의 요약 문맥 구성 |

### Ⅳ. 검색 방식과 운영

| 방식 | 검색 문맥 | 적용 질문 |
|---|---|---|
| Local Search | 관련 개체·관계와 원문 청크 | 특정 항목의 관계·세부 사실 |
| Global Search | 커뮤니티 요약을 단계별로 종합 | 문서 모음 전체의 주제·경향 |

| 운영 쟁점 | 확인 내용 |
|---|---|
| 추출 품질 | 관계 누락·오류와 원문 근거 일치 |
| 비용·갱신 | 그래프·요약 생성, 수정 후 재인덱싱 부담 |
| 질의 선택 | 질문 유형에 맞는 검색 경로와 근거성 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 그래프 인덱싱을 추가해도 기존 검색보다 답변 근거성이 나아지는지 불분명할 수 있음 | 관계 질의와 전체 요약 질의별 평가셋을 만들고, 기존 검색 기준선과 근거 품질·비용을 비교해 적용 범위 결정 |
