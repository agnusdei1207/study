## Ⅰ. GraphRAG의 개요

- 개념 : 비정형 텍스트 코퍼스로부터 대규모 언어 모델(LLM)을 활용하여 엔터티(Entity), 관계(Relationship), 핵심 주장을 추출하여 **지식 그래프** (Knowledge Graph)를 구축한 후, 그래프 군집화(Leiden 알고리즘) 및 계층적 커뮤니티 요약(Community Summary)을 사전 생성하여, 거시적 전체론적 질의(Global Search)와 복합 다단계 관계 추론(Local Search)을 동시에 지원하는 차세대 **RAG** 아키텍처.
- 배경 및 필요성 : 기존의 벡터 기반 **나이브 RAG**는 개별 텍스트 청크 간의 의미적 유사도 검색에만 의존하여, "이 데이터셋 전체의 핵심 주제는 무엇인가?"와 같은 **포괄적 질의** (Sensemaking)에 실패하고 다중 문서 간의 연결된 관계(Multi-hop)를 추론하지 못하는 근본적 한계를 극복하기 위해 마이크로소프트에 의해 제안됨.
- 핵심 목적 : 전체 코퍼스 차원의 거시적 인사이트 요약, 복합 연결 엔터티 간의 정밀한 다단계 추론, 환각 억제 및 지식 네트워크 시각화 제공.

## Ⅱ. GraphRAG의 핵심 아키텍처 및 동작 메커니즘

GraphRAG는 지식 그래프 인덱싱 단계와 글로벌/로컬 듀얼 검색 서빙 파이프라인의 2단계로 동작함.

```text
[ GraphRAG 인덱싱 파이프라인 및 듀얼 검색 아키텍처 ]

[1. 오프라인 지식 그래프 구축 및 계층 요약]
원시 문서 ──► 청킹 ──► LLM 엔터티/관계 추출 ──► 지식 그래프(KG) 생성
                                                       │
                                                       ▼
                                            [ Leiden 그래프 군집화 ]
                                                       │
                                                       ▼
                                     [ 계층적 커뮤니티 요약문 생성 (C0, C1, C2) ]

[2. 온라인 듀얼 검색 메커니즘]
                  사용자 질의 (User Query)
                             │
         ┌───────────────────┴───────────────────┐
         │ 포괄적 거시 질의                        │ 구체적 엔터티 질의
         ▼                                       ▼
+-----------------------------------+   +-----------------------------------+
| 글로벌 검색 (Global Search)        |   | 로컬 검색 (Local Search)          |
|  - 계층별 커뮤니티 요약문들 스캔  |   |  - 특정 엔터티 식별 ──► 이웃 탐색 |
|  - Map-Reduce 방식으로 전역 종합  |   |  - 서브그래프 + 원본 청크 결합   |
+-----------------┬-----------------+   +-----------------┬-----------------+
                  │ 사실적 종합 답변                        │ 정밀 관계 답변
                  └───────────────────► [ LLM 생성 ] ◄─────┘
```

- **엔터티 및 관계 추출(Entity-Relation Extraction)** : 원시 텍스트에서 사람, 조직, 기술, 장소 등의 노드와 이들 간의 서술어(Edge)를 LLM을 통해 정형 튜플로 추출.
- **Leiden 커뮤니티 탐색 알고리즘** : 밀접하게 연결된 엔터티 노드들을 계층적 클러스터(Community)로 묶어 거시적 주제 그룹 형성.
- **계층적 커뮤니티 요약(Community Summarization)** : 각 커뮤니티에 속한 엔터티와 관계들을 종합하여 LLM으로 사전 요약 리포트를 생성 및 저장.
- **글로벌 검색(Global Search)** : 전체 코퍼스를 관통하는 질문에 대해 사전 생성된 커뮤니티 요약문들을 Map-Reduce 방식으로 병렬 취합하여 종합 답변 생성.
- **로컬 검색(Local Search)** : 특정 엔터티에 대한 구체적 질문 시 관련 노드와 1~2홉(hop) 이웃 노드, 연결된 원본 텍스트 청크를 결합하여 심층 답변 도출.

## Ⅲ. GraphRAG의 세부 구성 요소 및 비교 분석

| 비교 항목 | 전통적 Vector RAG | 지식 그래프 (Traditional KG) | GraphRAG (Microsoft) |
| --- | --- | --- | --- |
| **데이터 표현 방식** | 고차원 임베딩 벡터 공간 | 정형 트리플 (RDF/OWL 온톨로지) | 비정형 텍스트 + 지식 그래프 + 커뮤니티 요약 |
| **검색 메커니즘** | 코사인 유사도 기반 Top-k 청크 추출 | SPARQL / Cypher 그래프 쿼리 | 커뮤니티 요약 Map-Reduce 및 서브그래프 탐색 |
| **전체 코퍼스 요약** | 불가능 (일부 유사 청크만 검색됨) | 복잡한 규칙 기반 질의 필요 | 완벽 지원 (Global Search 기반 거시 요약) |
| **다단계 추론 (Multi-hop)**| 검색된 청크 간 연결이 끊겨 취약 | 그래프 경로 탐색으로 우수함 | 지식 그래프 엣지 탐색으로 매우 우수함 |
| **사전 인덱싱 비용** | 낮음 (임베딩 모델 연산만 소요) | 높음 (수작업 온톨로지 설계 공수) | 높음 (LLM을 통한 엔터티 추출 및 요약 토큰 소모) |

- 일반적인 키워드/유사도 질의에는 Vector RAG가 빠르고 저렴하지만, 전체 데이터셋의 주제를 조망하거나 복잡한 상관관계를 밝혀야 하는 엔터프라이즈 분석에는 GraphRAG가 필수적임.

## Ⅳ. GraphRAG의 주요 한계점 및 해결 방안

- 오프라인 지식 그래프 구축 및 커뮤니티 요약 시 막대한 LLM 토큰 비용 소모 :
  - 한계점 : 수만 페이지의 문서를 인덱싱할 때 모든 청크에 대해 LLM 엔터티 추출과 요약을 수행하므로 수백만 원 이상의 초기 API 비용 발생.
  - 해결 방안 : 엔터티 추출 단계에 고성능 오픈소스 소형 모델(sLM)을 적용하고, 문서 변경 시 변경분만 갱신하는 **증분 인덱싱** (Incremental Indexing) 파이프라인 수립.
- 동음이의어 및 엔터티 불일치로 인한 그래프 오염(Entity Resolution 실패) :
  - 한계점 : 동일한 인물이나 기업이 다른 명칭으로 표기될 때 별개의 노드로 분리되어 관계 단절 발생.
  - 해결 방안 : **엔터티 링킹** (Entity Linking) 알고리즘 및 임베딩 유사도 기반의 노드 병합(Deduplication) 프로세스 강제.
- 그래프 데이터베이스(Neo4j 등)와 벡터 인덱스 간의 복합 인프라 운영 복잡도 :
  - 한계점 : 그래프 DB와 벡터 DB를 이원화하여 동기화 지연 및 운영 오버헤드 증가.
  - 해결 방안 : PostgreSQL(pgvector + Apache AGE)과 같은 하이브리드 멀티모델 DB를 채택하여 단일 인프라에서 그래프와 벡터 동시 처리.

## Ⅴ. GraphRAG 적용 및 발전을 위한 기술사적 제언

- 엔터프라이즈 복합 지식 도메인(M&A 감사, 법률 소송, 연구 논문) 우선 구축 : 수백 건의 계약서와 보고서 간의 숨겨진 지배 구조나 리스크를 추적하는 도메인에 GraphRAG 선제 도입.
- Vector RAG와 GraphRAG의 지능형 하이브리드 라우터(Router) 설계 : 단순 단답형 사실 질의는 가벼운 Vector RAG로, "주요 위험 요인 종합 요약"은 GraphRAG로 분기하여 비용 최적화.
- 생성된 지식 그래프의 전사 자산화 및 지식 맵(Knowledge Map) 시각화 연계 : AI 추론용에 머무르지 않고 임직원이 사내 지식 네트워크를 탐색할 수 있는 인터랙티브 그래프 UI 제공.
