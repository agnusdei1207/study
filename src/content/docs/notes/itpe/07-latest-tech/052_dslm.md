## 30초 인출

- 본질: **도메인 특화 언어모델(DSLM)** 은 금융, 법률, 의료 등 특정 산업 영역의 전문 용어와 지식 체계를 계속 사전학습(CPT) 및 정밀 미세조정(SFT)하여 해당 도메인 작업에 최적화한 인공지능 모델
- 메커니즘: 도메인 코퍼스 정제 및 토크나이저 확장 → 계속 사전학습(CPT) → 도메인 태스크 인스트럭션 튜닝(SFT/PEFT) → RAG 검색 증강 엔진 결합
- 통찰: 도메인 계속 학습 시 범용 상식 능력이 손실되는 치명적 망각(Catastrophic Forgetting)이 발생하므로 일반 코퍼스 혼합 리플레이와 PEFT 기법을 결합한 하이브리드 아키텍처 수립

<details><summary>핵심 용어</summary>

- **도메인 특화 언어모델(DSLM)** : 특정 산업 또는 전문 업무 영역의 지식과 언어적 맥락에 집중적으로 적응된 언어모델.
- **계속 사전학습(Continued Pre-training, CPT)** : 범용 사전학습 가중치를 기반으로 대규모 전문 도메인 코퍼스를 비지도 마스크드/인과적 언어모델링으로 추가 학습하는 기법.
- **치명적 망각(Catastrophic Forgetting)** : 새로운 전문 지식을 집중 학습하는 과정에서 기존에 습득한 일반 지식이나 추론 능력을 상실하는 현상.
- **매개변수 효율적 미세조정(PEFT)** : 전체 모델을 동결(Freeze)하고 소수의 저순위 어댑터(LoRA/QLoRA) 파라미터만 학습하여 비용과 망각을 줄이는 기술.
- **RAFT(Retrieval Augmented Fine-Tuning)** : 도메인 문맥 문서 내에서 정답 증거를 추출하고 무관한 방해 문서를 걸러내도록 모델을 미세조정하는 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. 도메인 특화 언어모델(DSLM)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **도메인 특화 언어모델(DSLM)** 은 의료, 금융, 법률, 제조 등 특정 산업 분야의 전문 코퍼스와 도메인 지식 체계를 기반으로 사전학습 또는 미세조정하여 해당 영역의 작업 수행력을 극대화한 언어모델 |
| 목적 | 범용 대형 모델 대비 환각(Hallucination) 대폭 억제, 도메인 전문 용어 이해도 증대, 온프레미스 경량 배포를 통한 기업 기밀 보호 및 운영 TCO 절감 |

## Ⅱ. 도메인 특화 언어모델의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **어휘 최적화** | 도메인 토크나이저 확장 | 의학 용어, 법률 조항, 금융 기호 등 전문 어휘를 서브워드로 분할하지 않고 단일 토큰으로 인코딩하여 토큰 효율성 향상 |
| **심층 지식 체계** | 계속 사전학습(CPT) 주입 | 도메인 내부 지침, 학술 논문, 판례집 등 대규모 미가공 코퍼스를 대량 주입하여 잠재 공간(Latent Space) 내 전문 지식 정렬 |
| **파라미터 효율성** | 경량 PEFT 기법 적용 | 7B~14B급 소형 모델(sLLM)에 LoRA, QLoRA 기법을 적용하여 단일 워크스테이션 또는 프라이빗 에지 인프라에서 경제적 서빙 |
| **검색 시너지** | RAG 기반 동적 지식 결합 | 고정된 가중치 지식에 의존하지 않고 기업 내부 실시간 규정집 및 ERP 문서를 검색 엔진과 연동(RAFT)하여 최신성 담보 |

## Ⅲ. DSLM 구축 파이프라인 및 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 도메인 특화 언어모델(DSLM) 엔드투엔드 구축 파이프라인 ]         │
└────────────────────────────────────────────────────────────────────────┘
      │
      ▼
 [ 도메인 데이터 수집·정제 ] ── 비정형 전문 문서(PDF/DOCX) 파싱, 민감정보(PII) 비식별화
      │
      ▼
 [ 토크나이저 어휘 확장 ] ─── BPE/WordPiece 기반 도메인 전문 토큰 추가 및 임베딩 확장
      │
      ▼
 [ 계속 사전학습 (CPT) ] ──── 도메인 비지도 코퍼스 학습 (일반 코퍼스 15% Replay 혼합)
      │
      ▼
 [ 지도 미세조정 (SFT) ] ──── QA, 요약, 추출 등 도메인 태스크 인스트럭션-응답 튜닝 (LoRA)
      │
      ▼
 [ 도메인 정렬 (Alignment) ] ── 도메인 안전 규정 및 윤리 기준 반영 (DPO/KTO 학습)
      │
      ▼
 [ 평가 및 경량 서빙 ] ───── 지연 시간 최적화(vLLM, TensorRT-LLM, AWQ 양자화 배포)
```

| 파이프라인 단계 | 핵심 엔지니어링 활동 | 주요 산출물 및 관리 지표 |
|---|---|---|
| **데이터 전처리** | OCR 텍스트 정제, 마크다운 구조화, 중복 제거(Dedup) | 정제된 도메인 코퍼스 (수십~수백 GB) |
| **토크나이저 확장** | 전문 도메인 어휘 Vocab 추가 (토큰 압축비 개선) | 확장된 토크나이저 모델 파일 |
| **계속 사전학습** | FSDP/DeepSpeed 기반 분산 CPT 수행 | 도메인 베이스 가중치(Checkpoint) |
| **태스크 미세조정** | 합성 데이터 생성(Evol-Instruct) 및 고품질 멀티턴 SFT | LoRA 어댑터 가중치, 평가 벤치마크 |
| **경량화 서빙** | W4A16 양자화, PagedAttention 기반 메모리 최적화 | 온프레미스 고속 서빙 API 엔드포인트 |

## Ⅳ. DSLM 구축 기법 간 비교

| 비교 항목 | 계속 사전학습 (CPT) | 지도 미세조정 (SFT/PEFT) | 검색 증강 생성 (RAG) | 하이브리드 (RAFT) |
|---|---|---|---|---|
| **지식 주입 방식** | 파라미터 내재화 (기초 지식) | 작업 수행 형식 및 스타일 주입 | 외부 문서 실시간 컨텍스트 주입 | 검색 문맥 해석 능력 직접 튜닝 |
| **컴퓨팅 비용** | 높음 (수십~수백 GPU-Days) | 보통 (수 GPU-Hours~Days) | 낮음 (임베딩 및 인덱싱 위주) | 보통 (SFT 수준의 연산량) |
| **최신성 반영** | 재학습 전까지 정적 | 재학습 전까지 정적 | 실시간 즉시 반영 가능 | 실시간 즉시 반영 가능 |
| **환각 억제력** | 보통 (지식 표현 개선) | 보통 (출력 형식 고정) | 높음 (검색 근거 기반 생성) | 매우 높음 (오도 문서 필터링) |
| **적합한 과업** | 전문 어휘/개념 체계 흡수 | 기업 고유 보고서 양식 준수 | 실시간 규정/약관/매뉴얼 검색 | 복잡한 도메인 추론 및 근거 제시 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 대규모 전문 도메인 코퍼스만 집중 학습 시 기존 범용 상식 및 언어 추론 능력이 급락하는 치명적 망각(Catastrophic Forgetting) 발생 | CPT 학습 데이터셋 구성 시 일반 도메인 고품질 코퍼스(Wikipedia, C4 등)를 15~20% 의무적으로 혼합(Replay Buffer)하고 베이스 모델 가중치를 보존하는 LoRA 어댑터 튜닝 적용 |
| 실시간으로 개정되는 법령, 의학 가이드라인, 금융 이자율 등의 최신 변경 사항을 파라미터 가중치에 즉각 반영 불가 | 도메인 특화 모델의 전문 문맥 이해 역량과 고성능 벡터 DB를 결합한 하이브리드 RAG 아키텍처 및 검색 증강 미세조정(RAFT) 파이프라인 결합 |
| 고품질 도메인 인스트럭션 데이터의 수기 라벨링 비용 과다 및 전문가 부족에 따른 데이터 병목 | 거대 상위 LLM(Claude, GPT-4)을 활용한 시드 데이터 기반의 도메인 맞춤형 합성 데이터(Self-Instruct) 자동 증강 파이프라인 구축 |

## Ⅵ. 제언

도메인 지식의 내재화(CPT)와 실시간 최신 정보 검색(RAG)을 유기적으로 연계하는 하이브리드 듀얼 엔진 아키텍처 구축.

```text
[ 사용자 전문 질의 (법률/금융/의료) ]
                 │
                 ▼
[ 도메인 지능 라우터 (Domain Router) ]
   ├── 실시간 최신 규정 검색 필요 시 ──> [ 엔터프라이즈 하이브리드 RAG ]
   │                                           │ (도메인 특화 청킹 & 리랭킹)
   │                                           ▼
   └── 도메인 추론 및 서식 생성 수행 ──> [ 경량 DSLM 추론 엔진 (sLLM 8B) ]
                                               │ (CPT 기반 전문 어휘 이해 완비)
                                               ▼
                                  [ 고신뢰 검증된 전문 답변 출력 ]
```

| 구분 | 범용 LLM 단독 프롬프팅 | 제언: DSLM + 도메인 RAG 융합 |
|---|---|---|
| **도메인 적합도** | 일반적 답변, 전문 용어 오해 | 산업 고유 전문 어휘 및 맥락 완벽 반영 |
| **데이터 보안** | 퍼블릭 클라우드 API 유출 위험 | 폐쇄망 온프레미스 자체 완결 구동 |
| **운영 비용** | 토큰당 과금으로 장기적 TCO 급증 | 고정 GPU 인프라 기반 경량 모델 고속 처리 |
