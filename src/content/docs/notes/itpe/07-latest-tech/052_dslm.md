## Ⅰ. 도메인 특화 언어모델(DSLM)의 개요

- 개념 : 일반 인터넷 텍스트로 학습된 **범용 파운데이션 모델** (General LLM)을 기반으로, 의료, 법률, 금융, 반도체, 세무 등 특정 전문 산업 도메인의 **특화 코퍼스** (Domain Corpus)와 전문 용어 사전을 집중 학습(DAPT / TAPT)시켜, 해당 산업의 전문적 지식 추론, 규제 준수, 고유 업무 프로세스에 최적화한 맞춤형 언어 모델.
- 배경 및 필요성 : 범용 LLM은 전문적인 법률 판례나 의학 용어에 대한 깊이 있는 이해 부족으로 심각한 환각을 발생시키며, 천문학적인 서빙 비용, 사내 기밀 유출 위험, 엄격한 산업 규제 컴플라이언스 준수 한계를 극복하기 위해 엔터프라이즈 맞춤형 **DSLM** 으로 전환됨.
- 핵심 목적 : 전문 산업 태스크 정확도 극대화, **환각** (Hallucination) 억제, 단일 GPU 기반 사내 **온프레미스 경량 서빙** (비용 최적화), 기업 고유의 지적재산권(IP) 자산화.

## Ⅱ. 도메인 특화 언어모델(DSLM)의 핵심 아키텍처 및 동작 메커니즘

DSLM은 도메인 코퍼스 정제, 전문 토크나이저 확장, 계속 사전학습(DAPT), 도메인 지시 튜닝(SFT)의 **4단계 엔지니어링 파이프라인** 으로 구축됨.

```text
[ DSLM 구축 4단계 전문화 파이프라인 ]

  [ 오픈소스 파운데이션 모델 가중치 (Llama 3, Qwen 2.5) ]
                             │
  +--------------------------▼------------------------------------+
  | 1. 도메인 데이터 인제스트 및 토크나이저 확장 (Token Adaptation)|
  |  - 전문 문서 (의학 논문, 법률 판례, 사내 매뉴얼) 정제         |
  |  - 전문 용어 분절 방지를 위한 어휘집(Vocabulary) 확장 결합   |
  +--------------------------┬------------------------------------+
                             │
                             ▼
  +---------------------------------------------------------------+
  | 2. 도메인 적응 사전학습 (DAPT, Domain-Adaptive Pre-training)  |
  |  - 수십억 토큰 규모의 비지도 도메인 코퍼스 계속 학습          |
  |  - 전문 분야의 문맥 및 관계적 지식을 모델 가중치에 직접 내재화 |
  +--------------------------┬------------------------------------+
                             │ 전문 지식 내재화된 베이스 모델
                             ▼
  +---------------------------------------------------------------+
  | 3. 도메인 태스크 지도 미세조정 (Task-Adaptive SFT)            |
  |  - 전문가 작성 Q&A, 진단 요약, 계약서 검토 등 정형 데이터셋   |
  |  - 파라미터 효율적 미세조정 (LoRA / QLoRA) 적용               |
  +--------------------------┬------------------------------------+
                             │
                             ▼
  +---------------------------------------------------------------+
  | 4. 도메인 가치 정렬 및 추론 최적화 (Alignment & Serving)      |
  |  - 도메인 윤리 및 컴플라이언스 정렬 (DPO)                     |
  |  - 프라이빗 RAG 결합 및 AWQ 양자화 온프레미스 서빙            |
  +---------------------------------------------------------------+
```

- **토크나이저 확장(Tokenizer Adaptation)** : 의학/법률 용어(예: "심근경색", "불법행위책임")가 단어 단위로 쪼개져 토큰이 낭비되는 문제를 방지하기 위해 도메인 고유 단어를 사전에 추가.
- **계속 사전학습(Continued Pre-training / DAPT)** : 레이블 없는 전문 문서를 마스크드 언어 모델(MLM) 또는 다음 토큰 예측 방식으로 추가 학습시켜 도메인 지식 체화.
- **도메인 지도 미세조정(SFT)** : 현직 의사, 변호사 등 전문가가 검증한 고품질 인스트럭션 데이터셋을 통해 실제 업무 양식대로 답변하도록 정렬.
- **프라이빗 RAG와의 하이브리드 결합** : DSLM은 전문 도메인의 언어적 이해와 추론을 담당하고, 수시로 개정되는 최신 법령/약관은 벡터 DB 검색으로 주입.

## Ⅲ. 도메인 특화 언어모델(DSLM)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 범용 거대 LLM (General LLM) | 순수 RAG 시스템 (Vanilla RAG) | 도메인 특화 모델 (DSLM + RAG) |
| --- | --- | --- | --- |
| **전문 용어 이해도**| 일반적 상식 수준, 뉘앙스 오해석 | 검색은 되나 LLM이 문맥 오독 가능 | 도메인 전문 지식과 어투 완벽 체화 |
| **지식 최신성** | 사전학습 시점에 동결 | 외부 검색을 통해 즉각 최신화 | RAG 결합으로 최신 지식 즉각 반영 |
| **사내 데이터 보안**| 퍼블릭 API 호출 시 유출 리스크 | 사내 벡터 DB 구축으로 우수함 | 완벽한 사내 에어갭(Air-Gapped) 구동 |
| **서빙 비용 (TCO)** | 매우 높음 (토큰당 누적 과금) | 중간 (벡터 DB + 상용 API 비용) | 최저 (단일 사내 GPU 서버로 완결) |
| **환각 발생률** | 전문 분야 질의 시 환각 빈번 | 검색 문맥에 의존하나 여전히 발생 | 도메인 지식 가중치와 검색 근거로 극소화 |

- DSLM은 범용 LLM의 한계와 순수 RAG의 단점을 상호 보완하는 엔터프라이즈 AI의 최종 완성형 아키텍처로 자리잡음.

## Ⅳ. 도메인 특화 언어모델(DSLM)의 주요 한계점 및 해결 방안

- 도메인 코퍼스 집중 학습 시 범용 상식 및 언어 추론 능력이 상실되는 치명적 망각 :
  - 한계점 : 의료 DSLM이 의학 질문은 잘 풀지만 기본적인 문장 요약이나 타 도메인 질문에서 횡설수설하는 현상.
  - 해결 방안 : 계속 사전학습 단계에서 일반 코퍼스를 일정 비율로 혼합 학습하고 가중치 보존 **PEFT** (LoRA) 기법 채택.
- 전문 도메인 데이터 라벨링에 소요되는 천문학적 비용과 전문가 리소스 부족 :
  - 한계점 : 의사, 변호사, 금융 애널리스트 등 고임금 전문가의 수작업 검수 병목.
  - 해결 방안 : 고성능 프론티어 LLM을 활용한 고품질 도메인 합성 데이터(Synthetic Data) 생성 및 전문가 샘플링 검수.
- 수시로 개정되는 도메인 규제 및 법률 변경 사항의 모델 반영 지연 :
  - 한계점 : 모델 가중치는 한 번 학습되면 고정되므로 어제 바뀐 법령을 즉각 알지 못함.
  - 해결 방안 : 도메인 DSLM을 RAG 시스템의 추론 백본으로 활용하여 최신 데이터는 프롬프트에 동적 증강.

## Ⅴ. 도메인 특화 언어모델(DSLM) 적용 및 발전을 위한 기술사적 제언

- 전문 용어 토크나이저 최적화 파이프라인 표준화 : 도메인 텍스트 인제스트 시 어휘집(Vocab) 확장을 선행하여 토큰 생성 속도 향상 및 VRAM 메모리 절감.
- 사내 비공개 자산(특허, R&D 문서, 승인 결재문)을 활용한 독자적 기업 DSLM 구축 : 외부 유출이 불가능한 핵심 노하우를 모델 가중치로 자산화하여 독점적 기술 장벽 형성.
- 도메인 전문가 평가단 기반의 객관적 벤치마크(Korean MedQA, Legal-Bench) 수립 : 학술용 지표(BLEU, ROUGE)를 지양하고 실제 전문직 국가자격시험 문제를 활용한 정량 평가 체계 정립.
