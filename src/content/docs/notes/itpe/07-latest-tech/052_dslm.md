## 30초 인출

- 본질: **도메인 특화 언어모델(Domain-Specific Language Model, DSLM)** 은 특정 분야의 자료·용어·과제에 맞게 적응한 언어 모델
- 메커니즘: 전문 자료·업무 요구 확인 → 추가 학습·검색 방식 선택 → 기준 모델과 비교 평가

<details>
<summary>핵심 용어</summary>

- **도메인 특화 언어모델(Domain-Specific Language Model, DSLM)** : 특정 분야의 언어·지식·업무 과제에 맞춰 적응한 언어 모델
- **계속 사전학습(Continued Pretraining)** : 기존 사전학습 모델을 도메인 말뭉치로 추가 학습하는 방법
- **지도 미세조정(Supervised Fine-Tuning, SFT)** : 입력·기대 응답 예시로 특정 업무 행동을 추가 학습하는 방법
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)** : 전체 모델 대신 일부 매개변수를 조정하는 기법군
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)** : 외부 자료를 검색해 모델 입력 문맥으로 제공하는 방식
- **도메인 코퍼스(Domain Corpus)** : 특정 산업·업무에서 쓰이는 문서와 텍스트 자료 모음

|---|---|

| 목적 | 전문 업무의 지식 활용과 응답 적합도 개선 |

### Ⅱ. 구축·평가 흐름

```text
업무 요구·평가 기준 정의
          │
전문 자료의 권리·품질 확인
          │
학습 적응 또는 외부 검색 방식 선택
          │
기준 모델과 품질·비용 비교
          │
```

```text
접근 방식       모델·자료에 미치는 변화
계속 사전학습   도메인 말뭉치의 언어 패턴을 추가 학습
미세조정        업무 예시로 출력 행동·과업 수행을 조정
RAG             검색 근거를 입력 문맥에 제공
```

도메인 토크나이저 추가나 계속 사전학습은 필수 단계가 아니며, 모델 구조·자료 특성과 실제 평가 결과에 따라 선택.

### Ⅲ. 범용 모델과 비교·선택

| 판단축 | 도메인 특화 모델 | 범용 모델 |
|---|---|---|
| 초점 | 특정 분야의 언어·과업 | 폭넓은 과제·분야 |
| 기대 이점 | 업무 용어·형식 적합도 향상 가능성 | 다양한 업무에 재사용 가능성 |
| 주요 부담 | 도메인 밖 일반화·갱신·유지 비용 검증 | 전문 근거·업무 흐름의 추가 결합 |
| 평가 기준 | 업무 대표성·정확도·운영 비용 | 동일 질의·조건에서 비교 기준선 |

### Ⅳ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 특화 모델의 성능 향상과 유지 비용을 일반 모델과 공정하게 비교하기 어려움 | 전문 질의·일반 회귀 질의를 포함한 평가셋을 구성하고, 기준 모델보다 개선 효과가 확인된 업무에 한해 특화 모델을 채택 |
