## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 모델 성능 진단 → 일반화 실패 → **과적합**

## 30초 인출

- 본질: **과적합(Overfitting)** 은 모델이 학습 자료의 우연한 특성까지 맞춰 새 자료에서 성능이 떨어지는 상태
- 메커니즘: 훈련 손실은 계속 감소하지만 검증 손실이 정체·상승하는 시점에서 복잡도·규제·종료 시점 조정

<details>
<summary>핵심 용어</summary>

- **과적합(Overfitting)** : 학습 자료의 우연한 특성까지 맞춰 새 자료에서 성능이 떨어지는 상태
- **과소적합(Underfitting)** : 모델이 자료의 주요 패턴을 충분히 표현하지 못하는 상태
- **일반화(Generalization)** : 학습에 쓰지 않은 자료에 학습한 관계를 적용하는 능력
- **조기 종료(Early Stopping)** : 검증 성능이 더 이상 개선되지 않을 때 학습을 중단하는 방법
- **정규화(Regularization)** : 모델 복잡도에 제약을 주어 과적합을 완화하는 기법
</details>

## 1교시 10점 답안

### Ⅰ. 과적합의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **과적합(Overfitting)** 은 학습 자료의 우연한 특성까지 맞춰 새 자료에서 성능이 떨어지는 상태 |
| 목적 | 학습 성능과 **일반화(Generalization)** 성능의 차이를 확인해 과적합 조기 탐지 |

### Ⅱ. 성능 변화 징후

```text
학습 진행
    ↓
훈련 손실 감소 · 검증 손실 감소
    ↓ 학습 지속
훈련 손실 감소 · 검증 손실 정체·상승
    ↓
일반화 성능 저하 징후
```

### Ⅲ. 과소적합과 구별

| 상태 | 훈련 성능 | 검증 성능 | 해석 |
|---|---|---|---|
| **과소적합(Underfitting)** | 낮음 | 낮음 | 모델이 패턴을 충분히 학습하지 못한 상태 |
| 과적합 | 높음 | 낮아지거나 악화 | 훈련 자료에 지나치게 맞춘 상태 |

제언: 훈련·검증 성능을 함께 기록하고 과적합 징후가 나타나는 시점에서 복잡도·종료 기준 조정.

## 2~4교시 25점 답안

### Ⅰ. 과적합의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **과적합(Overfitting)** 은 학습 자료의 우연한 특성까지 맞춰 새 자료에서 성능이 떨어지는 상태 |
| 목적 | 학습 성능과 **일반화(Generalization)** 성능의 차이를 확인해 과적합 조기 탐지 |

### Ⅱ. 성능 변화 징후

```text
학습 진행
    ↓
훈련 손실 감소 · 검증 손실 감소
    ↓ 학습 지속
훈련 손실 감소 · 검증 손실 정체·상승
    ↓
일반화 성능 저하 징후
```

### Ⅲ. 과소적합과 구별

| 상태 | 훈련 성능 | 검증 성능 | 해석 |
|---|---|---|---|
| **과소적합(Underfitting)** | 낮음 | 낮음 | 모델이 패턴을 충분히 학습하지 못한 상태 |
| 적절한 적합 | 높음 | 높음 | 새 자료에서도 학습 관계가 유지되는 상태 |
| **과적합(Overfitting)** | 높음 | 낮아지거나 악화 | 훈련 자료에 지나치게 맞춘 상태 |

### Ⅳ. 원인별 개선

| 한계 원인 | 대응 |
|---|---|
| 훈련 자료 부족·편향 | 대표 표본을 보강하고 검증 자료와의 분포 차이 확인 |
| 모델 복잡도 과다 | 특성·모델 복잡도 조정과 **정규화(Regularization)** 적용 |
| 학습 과다 | 검증 성능에 따른 **조기 종료(Early Stopping)** |
| 평가 자료 오염 | 학습·검증·시험 자료 분리와 학습 자료 안에서의 전처리 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모델 선택 때 시험 자료를 반복 확인하면 그 자료에도 과적합할 수 있음 | 시험 자료는 최종 확인용으로 보관하고 복잡도·규제 선택은 검증 자료에서 수행 |
