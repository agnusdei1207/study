## 30초 인출

- 본질: **오버피팅(Overfitting, 과적합)** 은 머신러닝 모델이 훈련 데이터의 무작위 노이즈와 지엽적 특성까지 과도하게 암기하여 미지의 검증·테스트 데이터에 대한 일반화 성능이 급격히 저하되는 현상
- 메커니즘: 모델 파라미터 수 및 에포크(Epoch) 증가에 따라 훈련 손실(Training Loss)은 지속 감소하나 검증 손실(Validation Loss)이 변곡점을 지나 다시 상승하는 분기점 발생
- 통찰: 높은 분산(High Variance)을 억제하지 못하면 실 배포 시 심각한 오작동이 유발되므로 L1/L2 가중치 규제, 드롭아웃, 조기 종료(Early Stopping) 및 K-Fold 교차검증 결합 필수

<details><summary>핵심 용어</summary>

- **오버피팅 (Overfitting)** : 훈련 데이터 오차는 극소화되나 새로운 데이터에 대한 예측 오차가 크게 증가하는 고분산(High Variance) 상태.
- **편향-분산 트레이드오프 (Bias-Variance Tradeoff)** : 모델 복잡도 증가 시 편향 오차는 줄어들고 분산 오차는 커져 총 오차가 U자형 곡선을 그리는 통계적 성질.
- **가중치 규제 (Weight Regularization)** : 손실 함수에 가중치 크기에 비례하는 페널티 항을 추가하여 모델 가중치를 축소하는 기법 (L1 Lasso, L2 Ridge).
- **드롭아웃 (Dropout)** : 딥러닝 신경망 학습 시 매 에포크마다 무작위로 일부 뉴런을 비활성화하여 특정 뉴런 간의 상호 적응을 방지하는 정규화 기법.
- **조기 종료 (Early Stopping)** : 검증 손실(Validation Loss)이 더 이상 개선되지 않고 연속 N 에포크 동안 증가할 때 학습을 선제적으로 중단하는 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. 오버피팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **오버피팅(Overfitting)** 은 기계학습 모델의 복잡도가 데이터의 본질적 신호보다 과도하여 훈련 세트의 노이즈와 이상치까지 학습함으로써 미지의 평가 세트에 대한 일반화(Generalization) 능력을 상실하는 현상 |
| 목적 | 훈련 오차와 일반화 오차 간의 격차 최소화, 노이즈 암기 방지 및 실 운영 환경에서의 신뢰성 있는 추론 예측력 보장 |

## Ⅱ. 오버피팅의 핵심 특징 및 편향-분산 트레이드오프 속성

| 구분 | 오버피팅의 특징 | 통계학적 및 공학적 세부 원리 |
|---|---|---|
| **고분산 저편향 (High Variance)** | 데이터 변화에 대한 극단적 민감도 | 훈련 셋의 사소한 변동에도 가중치 파라미터가 크게 변동하여 예측 분산 극대화 |
| **학습 곡선의 다이버전스** | 훈련/검증 손실 간 격차 확대 | 에포크 진행에 따라 훈련 손실은 0에 수렴하나 검증 손실은 특정 시점 이후 반등 |
| **복잡한 결정 경계** | 극단적인 비선형 굴곡 형성 | 입력 특징 공간에서 모든 이상치를 감싸기 위해 결정 경계가 비정상적으로 구불구불해짐 |
| **파라미터 과다 (Over-parameterized)** | 모델 자유도(DoF)의 과잉 | 데이터 샘플 수 대비 은닉층, 뉴런 수, 다항식 차수가 과도하여 모든 샘플 단순 암기 |

## Ⅲ. 오버피팅 발생 메커니즘 및 학습 곡선 분석 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│               [ 에포크 진행에 따른 손실 곡선 및 오버피팅 분기점 ]          │
└────────────────────────────────────────────────────────────────────────┘
 손실 (Loss)
    ▲
    │ \                                   / 검증 손실 (Validation Loss)
    │  \     과소적합 (Underfitting)     /  ──> 과적합 (Overfitting) 구간
    │   \         구간                  /
    │    \                             /
    │     \         최적 지점 (Optimal)
    │      \───────● (Early Stopping)
    │       \     /  \
    │        ────/─────\─────────────────── 훈련 손실 (Training Loss)
    │           /       \
    └──────────┴─────────────────────────► 학습 반복 (Epochs / Model Complexity)
```

| 진단 단계 | 손실 변화 추이 | 공학적 원인 및 판정 |
|---|---|---|
| **과소적합 (초기)** | 훈련 손실 높음, 검증 손실 높음 | 모델 표현력 부족으로 데이터의 내재적 패턴 미학습 |
| **적정 적합 (최적)** | 훈련 손실 낮음, 검증 손실 최저점 | 데이터의 본질 신호만 정확히 포착, 일반화 성능 극대화 |
| **과적합 (후기)** | 훈련 손실 극소화, 검증 손실 재상승 | 훈련 셋의 노이즈와 특이치를 학습하여 검증 오차 발산 |

## Ⅳ. 과소적합 vs 적정 적합 vs 과적합 비교

| 비교 항목 | 과소적합 (Underfitting) | 적정 적합 (Good Fit) | 과적합 (Overfitting) |
|---|---|---|---|
| **편향 및 분산** | 고편향, 저분산 (High Bias) | 저편향, 적정 분산 (Balanced) | 저편향, 고분산 (High Variance) |
| **결정 경계** | 지나치게 단순한 선형/평면 | 부드러운 완만한 곡면 | 데이터 점을 억지로 잇는 복잡한 요철 |
| **훈련/테스트 정확도** | 훈련 60%, 테스트 58% | 훈련 95%, 테스트 93% | 훈련 99.9%, 테스트 65% |
| **주요 원인** | 파라미터 부족, 과도한 규제, 조기 중단 | 적절한 아키텍처와 정규화 기법 적용 | 파라미터 과다, 데이터 부족, 과도한 에포크 |
| **대응 방향** | 모델 복잡도 증대, 규제 완화 | 하이퍼파라미터 동결 및 모델 저장 | 정규화, 드롭아웃, 데이터 증강, 조기 종료 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 수집 데이터셋 규모가 제한적일 경우 모델 파라미터가 훈련 셋을 100% 암기 | Mixup, CutMix 등 도메인 특화 데이터 증강(Augmentation) 적용 및 전이학습(Transfer Learning) 결합 |
| 고정된 에포크 수치 설정으로 인해 최적 검증 손실 구간을 지나 과적합으로 진입 | 검증 손실의 개선 정체를 감시하는 EarlyStopping 콜백(Patience=5) 및 최적 가중치 ModelCheckpoint 자동 저장 |

## Ⅵ. 제언

데이터 준비부터 모델 훈련 및 검증에 이르는 전 과정에 걸쳐 다계층 정규화 기법(Multi-layer Regularization)을 결합한 오버피팅 원천 차단 파이프라인 구축.

```text
[ 원천 훈련 데이터셋 ] ──> [ 데이터 증강 (Augmentation) ]
                                      │
                                      ▼
[ 신경망 아키텍처 설계 ] ──> [ Batch Normalization + Dropout (p=0.3) ]
                                      │
                                      ▼
[ 손실 함수 및 옵티마이저 ] ─> [ L2 Weight Decay (AdamW) 적용 ]
                                      │
                                      ▼
[ 훈련 루프 (Training Loop) ] ─> [ Early Stopping 기반 최적 검증 가중치 복원 ]
```

| 구분 | 정규화 부재 기존 모델 | 제언: 다계층 정규화 파이프라인 |
|---|---|---|
| **가중치 제어** | 극단적으로 큰 가중치 발생 | L2 Weight Decay로 가중치 노름(`||w||`) 억제 |
| **뉴런 협력** | 특정 뉴런 간 과도한 동조화(Co-adaptation) | Dropout을 통한 독립적 피처 학습 유도 |
| **종료 타이밍** | 사전에 정한 100 Epoch 무조건 완주 | 검증 손실 최저점에서 자동 조기 정지 |
