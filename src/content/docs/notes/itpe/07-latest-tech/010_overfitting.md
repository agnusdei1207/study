## 답안 골격
```text
[오버피팅] ◀━━ 머리: Ⅶ 내 의견 (검증 손실 기반 조기 종료와 드롭아웃·L2 규제의 복합 파이프라인 자동화)
 ┃
 ┣━ Ⅰ 개요 ───── 학습 오차 최소화 과몰입 → 학습 데이터의 노이즈까지 암기하여 일반화 성능 상실
 ┣━ Ⅱ 특징 ───── 고분산(High Variance) · 저편향(Low Bias) · 학습 손실(↓)과 검증 손실(↑)의 다이버전스
 ┣━ Ⅲ 구조 ───── 원인(모델복잡도/데이터부족/노이즈) + 탐지(학습곡선) + 대책(데이터/모델/학습기법)
 ┣━ Ⅳ 흐름 ───── ① 학습 진행 → ② 훈련 손실 지속 감소 → ③ 검증 손실 반등(변곡점) → ④ 과적합 발생
 ┣━ Ⅴ 비교 ───── 과소적합(Underfitting, 고편향) vs 적합(Good Fit) vs 과적합(Overfitting, 고분산)
 ┗━ Ⅵ 실무 ───── 테스트셋 오염 / 과도한 규제로 인한 과소적합 퇴보 / 에포크(Epoch) 수치 선정
```
- 필수 키워드: 편향-분산 트레이드오프 · 일반화 손실 · 조기 종료(Early Stopping) · 드롭아웃(Dropout) · L1/L2 규제 · 데이터 증강
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 학습 곡선 그래프(Loss 다이어그램) → Ⅵ 데이터/모델/학습 차원 3대 대책 / 25점 = Ⅰ~Ⅶ 전개, Ⅴ 언더피팅과의 4대 축 비교와 정규화 수식 집중
- 기출: 139회 1교시 8번 `과적합(Overfitting)과 과소적합(Underfitting)의 발생 원인과 해결 방안` → Ⅲ·Ⅴ·Ⅵ

## 한 줄 본질
- 훈련 데이터의 무작위 노이즈와 특이점까지 모델 파라미터가 과도하게 학습 → 새로운 검증 데이터에 대한 오차 급증 및 일반화 실패 / 모델 표현력과 규제 강도 간의 세밀한 절충(Trade-off) 튜닝 필요

## 핵심 그림
```text
[학습 곡선과 과적합 발생 지점]
    Loss ^
         | \
         |  \      검증 손실 (Validation Loss)
         |   \       /--------->  [과적합 영역: 고분산]
         |    \     /
         |     \---/ <--- 최적 정지 지점 (Early Stopping Point)
         |      \       
         |       \-----------------> 학습 손실 (Training Loss)
         +---------------------------------------------> Epochs
```

## 핵심 용어
- 조기 종료(Early Stopping): 검증 손실(Validation Loss)이 일정 에포크(Patience) 동안 개선되지 않으면 학습을 즉시 중단하는 기법
- 드롭아웃(Dropout): 신경망 순전파 학습 시 무작위로 일정 비율(예: 20~50%)의 뉴런 연결을 비활성화하여 특정 뉴런에 대한 의존도를 분산시키는 기법
- L2 가중치 감쇠(Weight Decay): 손실 함수에 가중치 제곱합에 비례하는 페널티($\frac{1}{2}\lambda \|w\|^2$)를 더해 가중치 크기가 과도하게 커지는 것을 억제

## 핵심 통찰
- 과적합은 모델이 "너무 똑똑해서" 데이터의 본질적 패턴뿐만 아니라 우연히 섞인 잡음(Noise)까지 규칙으로 외워버릴 때 발생
- 데이터를 늘리는 것(Data Augmentation)이 과적합을 해결하는 가장 근본적이고 부작용이 없는 최우선 처방
- 정규화(Regularization)를 너무 강하게 걸면 모델이 데이터의 복잡한 실제 패턴마저 학습하지 못하는 언더피팅(과소적합)으로 역행

## 이웃 토픽과 구분
- 과적합 vs 과소적합: 과소적합은 모델이 너무 단순해 훈련 데이터조차 제대로 학습하지 못한 고편향(High Bias) 상태 / 과적합은 훈련 데이터에만 지나치게 맞춰진 고분산(High Variance) 상태

## 문제·원인·대책
- 적용 상황: 이미지 분류 심층 신경망 학습 중 테스트 셋 정확도 급락
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 학습 정확도 99% 대비 검증 정확도 65% | 모델 파라미터 대비 훈련 데이터셋 수량 부족 | CutMix, Mixup 등 데이터 증강(Data Augmentation) 적용 | 데이터 다양성 확보 및 표본 수 가상 확대 |
| 특정 특성 가중치 폭증으로 인한 왜곡 | 복잡한 신경망 구조 내 가중치 폭주 | L2 정규화(Weight Decay) 및 배치 정규화(BatchNorm) 적용 | 가중치 분포 균등화 및 이상치 영향력 억제 |
| 과도한 에포크 학습으로 노이즈 암기 | 고정된 에포크 수치 반복 수행 | EarlyStopping 콜백(Patience=5) 설정 | 검증 손실 최저점 모델 가중치 자동 보존 |
