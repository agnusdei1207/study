## 30초 인출

- 본질: **피지컬 AI(Physical AI)** 는 컴퓨터 화면 내부의 가상 정보 처리를 넘어 실제 물리적 세계의 역학 법칙을 이해하고, 센서와 액추에이터(로봇, 모빌리티)를 통해 물리적 환경과 직접 상호작용하는 체화된 인공지능(Embodied AI) 기술
- 메커니즘: 멀티모달 센서(RGB-D, LiDAR, IMU, 촉각) 입력 후 시각-언어-행동(VLA) 파운데이션 모델을 거쳐 관절 모터 토크와 궤적 명령을 실시간 폐루프(Closed-loop) 제어로 전송
- 통찰: 가상 시뮬레이션과 현실 물리 환경 간의 시뮬투리얼 갭(Sim2Real Gap)으로 인한 오작동 위험이 크므로 도메인 랜덤화(Domain Randomization) 및 실시간 안전 가드레일 제어기 결합 필수

<details><summary>핵심 용어</summary>

- **피지컬 AI (Physical AI)** : 물리적 실체를 갖춘 로봇 및 기계 장치에 지능을 부여하여 물리 법칙을 이해하고 현실 환경을 조작하는 AI.
- **체화된 인공지능 (Embodied AI)** : 물리적 몸체(센서, 모터)를 가지고 환경과 물리적으로 상호작용하며 경험을 축적하는 인공지능 패러다임.
- **VLA 모델 (Vision-Language-Action)** : 시각 정보와 자연어 지시를 입력받아 로봇 팔의 모터 조작 각도나 이동 좌표 등 물리적 행동을 직접 출력하는 모델.
- **Sim2Real (Simulation to Real)** : 물리 엔진 기반의 디지털 가상 환경(Omniverse 등)에서 대규모 학습 후 실제 물리 로봇으로 전이하는 기술.
- **도메인 랜덤화 (Domain Randomization)** : 시뮬레이션 시 마찰계수, 조명, 물체 질량을 무작위로 교란시켜 현실 세계의 노이즈에 강건하도록 학습시키는 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. 피지컬 AI의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **피지컬 AI(Physical AI)** 는 시각, 청각, 촉각 등의 멀티모달 센서로 물리 세계의 3차원 공간과 물리 법칙(중력, 마찰, 관성)을 실시간 인식하고, 로봇 하드웨어 및 액추에이터를 정밀 제어하여 물리적 과업을 자율 수행하는 체화형 인공지능 |
| 목적 | 인간 노동력의 물리적 한계 극복, 위험 산업 현장(건설, 원자력, 재난) 자율화, 휴머노이드 로봇 상용화 및 현실 세계의 자동화 혁신 |

## Ⅱ. 피지컬 AI의 핵심 특징 및 소프트웨어 AI 대비 속성

| 구분 | 피지컬 AI의 핵심 특징 | 세부 공학적 메커니즘 및 속성 |
|---|---|---|
| **물리 법칙 이해 (Physics-aware)** | 현실 세계 역학 모델링 | 질량, 중력, 마찰력, 충돌 역학을 신경망에 사전 학습하여 물체 조작 시 파손 방지 |
| **체화성 (Embodiment)** | 물리적 신체와의 결합 | 소프트웨어 모델이 독립된 알고리즘이 아닌 특정 기구학적 로봇 바디와 일체화되어 작동 |
| **실시간 하드 실시간성** | 초저지연 폐루프 제어 | 지연시간 발생 시 물리적 충돌 및 전도 사고가 발생하므로 수 밀리초(ms) 단위 결정론적 제어 필수 |
| **비가역성 (Irreversibility)** | 실제 세계의 되돌릴 수 없는 결과 | 텍스트 생성 오류와 달리 로봇의 오작동은 인명 피해, 기물 파손 등 되돌릴 수 없는 물리적 손실 유발 |

## Ⅲ. 피지컬 AI 아키텍처 및 센서-모델-액추에이터 폐루프 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 피지컬 AI 인식-추론-제어 폐루프 아키텍처 ]             │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 1. 멀티모달 물리 센싱 (Perception) ]
  - RGB-D 카메라, 3D LiDAR, 관성 센서(IMU), 그리퍼 촉각(Tactile) 센서
                                    │
                                    ▼ (고속 센서 융합)
┌────────────────────────────────────────────────────────────────────────┐
│ [ 2. 월드 모델 및 공간 인지 계층 (Spatial AI & World Model) ]          │
│  - 3D 가우시안 스플래팅 / NeRF 기반 3차원 공간 복원                    │
│  - 장애물 및 조작 대상 물체의 6자유도(6-DoF) 포즈 추정                │
└────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 3. VLA 파운데이션 모델 추론 (Vision-Language-Action) ]                │
│  - 사용자 자연어 지시("빨간 사과를 바구니에 담아") + 시각 피처 인코딩 │
│  - 시퀀스 제어 토큰 출력 ──> 엔드이펙터 궤적 및 조인트 모터 각도 생성  │
└────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 4. 저지연 물리 제어 및 안전 감시 계층 (Action & Safety Gate) ]         │
│  - 관절 서보 모터(Actuator) 토크 제어 (1kHz 제어 루프)                 │
│  - 가상 안전 펜스(Geofencing), 충돌 감지 비상 정지 인터록(Interlock)   │
└────────────────────────────────────────────────────────────────────────┘
```

| 아키텍처 계층 | 핵심 기술 컴포넌트 | 공학적 기여 및 역할 |
|---|---|---|
| **물리 센싱** | Event-based Camera, F/T(힘/토크) 센서 | 초고속 모션 블러 없는 시각 인지 및 접촉 면 압력 피드백 |
| **월드 모델** | 3D Occupancy Grid, Physics Engine | 시야각(FoV) 바깥의 가려진 물리적 공간까지 추론 및 상상 |
| **행동 모델** | OpenVLA, RT-2, Diffusion Policy | 복잡한 로봇 궤적을 텍스트 토큰처럼 자연스럽게 생성 |
| **액추에이터 제어** | 로봇 운영체제(ROS 2), EtherCAT | 마이크로초 단위의 지터(Jitter) 없는 결정론적 모터 제어 |

## Ⅳ. 가상 소프트웨어 AI(생성형 AI) vs 피지컬 AI 비교

| 비교 항목 | 가상 소프트웨어 AI (LLM / 생성형 AI) | 피지컬 AI (Physical AI / Embodied) |
|---|---|---|
| **작동 환경** | 서버, 클라우드, 브라우저 가상 공간 | 현실 물리 세계 (공장, 도로, 병원, 가정) |
| **입력 및 출력** | 텍스트, 코드, 이미지 / 텍스트, 비디오 | 센서 신호(점군, 관성) / 관절 각도, 모터 토크 |
| **실패 비용** | 잘못된 텍스트 출력 (새로고침 가능) | 하드웨어 파손, 인명 사상 사고 (비가역적) |
| **시간 제약** | 수초 내외의 소프트 실시간성 허용 | 수 밀리초(ms) 단위의 엄격한 하드 실시간성 |
| **데이터 수집** | 인터넷 크롤링을 통한 무제한 수집 | 현실 물리 로봇 실험으로 데이터 수집 극난 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 가상 물리 엔진 시뮬레이션에서 완벽히 작동하던 정책이 실제 로봇 투입 시 마찰력 차이로 실패하는 Sim2Real 갭 | 물리 파라미터(마찰, 질량, 센서 노이즈)를 광범위하게 변동시키는 도메인 랜덤화(Domain Randomization) 적용 |
| 신경망의 예기치 않은 추론 튀김 현상으로 인한 로봇 관절의 급격한 이상 구동 및 충돌 위험 | 딥러닝 출력단에 물리적 한계 각도 및 각속도를 강제 제한하는 제어이론 기반 안전 필터(Safety Filter) 결합 |

## Ⅵ. 제언

실제 물리 로봇 파손 없이 수억 시간의 데이터를 축적하기 위해 GPU 기반 대규모 병렬 시뮬레이션과 디지털 트윈을 결합한 Sim2Real 파이프라인 구축.

```text
[ 물리 엔진 기반 대규모 가상 시뮬레이터 (NVIDIA Isaac Sim) ]
   ├── Step 1: 10,000개 로봇 가상 병렬 환경에서 강화학습 수행
   ├── Step 2: 도메인 랜덤화 (마찰계수 ±50%, 무게중심 오차, 카메라 왜곡 주입)
   └── Step 3: Sim2Real 전이 학습 및 잔차 정책(Residual Policy) 보정
                 │
                 ▼ (가중치 배포)
[ 실제 물리 로봇 (휴머노이드 / 다관절 매니퓰레이터) 무결점 현장 투입 ]
```

| 구분 | 현실 로봇 직접 수기 학습 | 제언: 대규모 Sim2Real 파이프라인 |
|---|---|---|
| **학습 시간** | 수년 소요 및 로봇 모터 마모 발생 | 가상 병렬 가속으로 수시간 내 100만 시간 학습 |
| **비용 및 안전** | 충돌 사고로 인한 수억 원 파손 위험 | 가상 충돌로 하드웨어 손상 및 안전사고 제로 |
| **일반화 성능** | 특정 환경 실험실에만 과적합 | 도메인 랜덤화로 거친 야외 현장 적응력 극대화 |
