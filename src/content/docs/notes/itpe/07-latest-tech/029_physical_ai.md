## 연관 키워드

- 피지컬 AI(Physical AI), 체화된 인공지능(Embodied AI), 로봇 파운데이션 모델
- VLA(Vision-Language-Action), 월드 모델(World Model), 디지털 트윈(Digital Twin)
- Sim-to-Real 간극, 도메인 무작위화, 임피던스 제어(Impedance Control)
- ISO 10218, ISO/TS 15066, 비상 정지(E-stop), 협동 로봇

## Ⅰ. 피지컬 AI(Physical AI)의 개요

- 핵심 요약 : 센서로 물리 세계를 인지하고 로봇 등 물리 장치로 직접 행동하는 체화된 인공지능.
- 개념 : 화면과 텍스트에 갇힌 AI를 넘어, 카메라·라이다(LiDAR)·촉각 센서로 현실을 인지하고 물리 법칙을 반영해 로봇 팔·휴머노이드·자율주행체 등 액추에이터로 행동하는 **체화된 인공지능** (Embodied AI).
- 배경 및 필요성 : 생성형 AI로 디지털 지식 작업의 자동화는 크게 진전되었으나, 제조·물류·건설·돌봄 같은 물리 노동의 자동화는 여전히 어렵다. 이에 시각·언어·행동을 하나의 모델로 묶는 **VLA** (Vision-Language-Action) 모델이 주목받게 됨.
- 참고 발표 : NVIDIA는 2025년 3월 휴머노이드용 오픈 파운데이션 모델 **GR00T N1**을 공개했으며, 이를 VLA 접근의 대표 사례로 볼 수 있다. 후속 버전의 세부 사양은 공식 릴리스 노트를 기준으로 확인이 필요하다.
- 주요 목적 : 물리 세계와 상호작용하는 범용 로봇 지능 구현, 위험 작업의 인력 대체, 생산성 확장.

## Ⅱ. 피지컬 AI(Physical AI)의 특징 및 장점

- 핵심 요약 : 인지, 계획, 제어를 계층으로 나눈 구조가 실시간성과 안전성을 함께 확보하는 방식.

1. 멀티모달 인지 : 카메라 영상, 깊이 정보, 촉각 신호를 함께 입력 → 물체 위치와 접촉 상태를 종합 판단.
2. 자연어 지시 수행 : VLA가 언어 지시와 시각 정보를 함께 처리 → 사전 프로그래밍 없이 새로운 작업 지시 대응.
3. 계층적 제어 : 느린 고수준 계획과 빠른 저수준 관절 제어를 분리 → 판단 품질과 실시간성을 동시에 확보.
4. 임피던스 제어 : 접촉 시 힘을 유연하게 흡수 → 대상물 파손과 인명 상해 위험 감소.

## Ⅲ. 피지컬 AI(Physical AI)의 구조 (흐름)

- 핵심 요약 : 물리 인지에서 월드 모델과 VLA 계획을 거쳐 모터 제어로 내려오는 4단계 계층 구조.

```text
[ 피지컬 AI 4단계 아키텍처 ]

1. 멀티모달 물리 인지
   (RGB-D 카메라, LiDAR, IMU, 촉각)
          ↓ 점군·영상 스트림
2. 공간·물리 월드 모델
   (3D 공간 복원, 중력·마찰 추론)
          ↓ 시각 문맥 + 자연어 지시
3. VLA 파운데이션 모델
   (행동 계획, 말단 궤적 생성)
          ↓ 목표 자세·그립 명령
4. 실시간 모터 제어
   (임피던스 제어, 충돌 시 반사 반응)
```

- **월드 모델** (World Model) : 물체를 놓치면 떨어지는 등 물리 상호작용의 인과를 예측하는 신경망.
- VLA(Vision-Language-Action) : 시각-언어 사전 학습 백본 위에 로봇 관절·자세 행동 토큰을 출력하도록 정렬한 모델.
- GR00T N1은 이해를 담당하는 시각-언어 모듈(System 2)과 실시간 동작을 생성하는 확산 트랜스포머(System 1)를 나눈 **이중 시스템** (Dual-system) 구조를 채택했다.

## Ⅳ. 피지컬 AI(Physical AI)와 디지털 AI의 비교

- 핵심 요약 : 실패의 비용과 요구 지연 시간이 달라, 피지컬 AI는 소프트웨어 AI보다 엄격한 안전 설계가 필요하다.

| 비교 항목 | 디지털 AI | 피지컬 AI |
| --- | --- | --- |
| 운영 환경 | 클라우드, 모바일 화면 | 중력·마찰이 작용하는 실제 공간 |
| 입출력 | 텍스트·이미지 입력, 텍스트·코드 출력 | 센서 입력, 모터 토크·궤적 출력 |
| 실패의 영향 | 오답과 환각 (정보 수준) | 충돌, 설비 파손, 인명 상해 |
| 데이터 수집 | 웹 크롤링으로 대량 확보 가능 | 로봇 조작 데이터 확보가 어려움 |
| 지연 시간 요구 | 수 초 이내 응답 허용 | 밀리초 단위의 결정론적 제어 |

## Ⅴ. 피지컬 AI(Physical AI)의 한계와 방안

- 핵심 요약 : 시뮬레이션과 현실의 차이, 데이터 부족, 안전 문제를 시뮬레이션 학습과 하드웨어 안전장치로 통제.

```text
[ 시뮬레이션에서 실물로 가는 학습 경로 ]

가상 환경 학습
      ↓ 도메인 무작위화 (마찰·조명 변화)
정책 일반화
      ↓ 실물 소량 데이터 미세 조정
실물 로봇 배치
      ↓ 안전 가드·비상 정지 상시 적용
```

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| Sim-to-Real 간극 | 시뮬레이터에서 학습한 정책이 실제 마찰·조명 차이로 실패 | **도메인 무작위화** (Domain Randomization), 실물 소량 데이터로 미세 조정 | 실물 성공률 |
| 로봇 데이터 부족 | 인터넷 텍스트와 달리 조작 데이터 수집량이 적음 | 원격 조종(Teleoperation) 데이터 구축, 합성 데이터 활용 | 데이터 에피소드 수 |
| 물리적 안전 위험 | 모델의 비결정적 출력이 과도한 동작을 유발 | 하드웨어 안전 가드, 토크 제한, **비상 정지** (E-stop) 회로 | 충돌 감지 횟수, 정지 응답 시간 |

## Ⅵ. 피지컬 AI(Physical AI)의 기술사적 제언

- 핵심 요약 : 시뮬레이션 인프라, 온로봇 추론, 국제 안전 규격을 함께 갖춰야 피지컬 AI가 현장에 안전하게 들어갈 수 있다.

1. 시뮬레이션 선행 투자 : 물리 시뮬레이션 플랫폼을 먼저 마련해 실물 파손 없이 대량의 병렬 학습 환경을 확보한다.
2. 온로봇 추론 : 네트워크가 끊겨도 로봇이 자체 연산으로 정지하거나 작업을 마칠 수 있도록 엣지 가속기를 탑재한다.
3. 안전 규격 준수 : 산업용 로봇 안전 규격인 **ISO 10218** 시리즈와 협동 로봇 기준인 **ISO/TS 15066**에 맞춰 감속 구역과 접촉력 제한을 설계 단계부터 반영한다.

## Ⅶ. 결론

- 핵심 요약 : 피지컬 AI는 소프트웨어 지능이 물리적 신체를 얻어 현실 법칙 아래에서 행동하는 영역이다.
- 시사점 : 모델 성능보다 안전 설계와 데이터 확보 역량이 실제 도입 속도를 좌우한다.
