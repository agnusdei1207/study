## 지식 로드맵 내 현재 위치

지식 위치: AI 응용 시스템 → 센서·모델·구동기 결합 → **피지컬 AI**

## 30초 인출

- 본질: **피지컬 AI(Physical AI)** 는 물리 환경을 인식하고 장치의 행동으로 환경과 상호작용하는 AI 시스템
- 메커니즘: 센서 관측 → 상태·목표 해석 → 안전 제약 아래 행동 결정 → 구동 → 결과 재관측
- 통찰: 한계: 관측 오류나 지연된 제어가 실제 장치의 위험 행동으로 연결 → 방안: 행동 전 안전 제약 확인과 실행 결과 재관측

<details>
<summary>핵심 용어</summary>

- **피지컬 AI(Physical AI)** : 인공지능을 로봇·자율 시스템 등 물리 장치와 연결해 실제 환경에서 인식·판단·행동하는 시스템
- **체화된 인공지능(Embodied AI)** : 몸체·센서·행동 수단을 통해 환경과 상호작용하는 인공지능
- **비전·언어·행동 모델(Vision-Language-Action Model, VLA)** : 시각·언어 입력을 로봇 행동 출력과 연결하는 모델 계열
- **시뮬레이션-현실 전이(Simulation-to-Real, Sim2Real)** : 시뮬레이션에서 학습·평가한 정책을 실제 환경에 적용하는 과정
- **폐루프 제어(Closed-loop Control)** : 실행 결과를 다시 관측해 다음 제어 입력을 조정하는 방식
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **피지컬 AI(Physical AI)** 는 물리 환경을 인식하고 장치의 행동으로 환경과 상호작용하는 AI 시스템 |
| 목적 | 로봇·자율 시스템이 물리 환경의 변화에 맞춰 과업 수행 |

### Ⅱ. 폐루프 동작

```text
물리 환경
    ↓ 센서 관측
상태 인식·목표 판단
    ↓ 안전 조건 확인
제어 명령·장치 행동
    ↓ 환경 변화
센서로 결과 재관측
    └──── 상태 판단으로 환류
```

### Ⅲ. 시스템 구성

| 계층 | 주요 기능 |
|---|---|
| 인식 | 카메라·거리·힘 등 관측값 처리 |
| 판단·계획 | 목표와 상태에 맞는 행동 생성 |
| 안전·제어 | 허용 범위 확인, 장치 명령 조정 |
| 실행·관측 | 구동기 작동과 결과 피드백 수집 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 시뮬레이터와 현실의 센서·물리 조건 차이 | 센서 오차·환경 변화·실패 조건을 시뮬레이션과 실물에서 비교 시험 |
| 지연·오인식으로 위험한 물리 행동 발생 | 행동 전 안전 제약, 비상 정지와 결과 재관측 적용 |
| 제한 시험 결과의 다른 환경 일반화 불확실 | 작동 조건·금지 상태를 명시하고 검증된 영역부터 제한 운용 |

### Ⅴ. 제언

허용 환경·속도·작업 범위를 먼저 정하고 실물 안전 정지 검증을 통과한 영역부터 운영 확대.
