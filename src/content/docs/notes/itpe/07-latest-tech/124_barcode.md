## 지식 로드맵 내 현재 위치
최신 기술 → 자동 식별·데이터 수집 → 광학 판독 식별자 → 1차원 바코드

## 30초 인출
- **본질:** 바코드는 데이터를 인쇄된 기호로 표현해 스캐너가 읽도록 한 자동 식별 수단.
- **메커니즘:** 바와 공백의 폭·배열을 광학적으로 읽어 심볼로지를 따라 데이터로 복호.
- **검증:** GTIN-13의 체크 디지트는 번호의 입력·판독 오류 검출을 돕지만 인증·보안을 제공하지 않음.

<details><summary>핵심 용어</summary>

- **바코드(Barcode):** 기계 판독 가능한 기호로 식별자나 데이터를 표시하는 데이터 캐리어.
- **1차원 심볼로지(Linear Symbology):** 바와 공백의 폭 패턴으로 데이터를 가로 방향에 표현하는 바코드 방식.
- **EAN-13:** GTIN-13을 표현하는 GS1 바코드 심볼로지.
- **GTIN(Global Trade Item Number):** 거래 품목을 식별하기 위해 GS1 체계에서 부여하는 식별번호.
- **체크 디지트(Check Digit):** 번호 구성의 오류를 검출하도록 계산해 붙이는 확인 숫자.
- **콰이어트 존(Quiet Zone):** 주변 인쇄 요소와 심볼 경계를 구분하도록 두는 빈 공간.
- **2차원 심볼로지(2D Symbology):** 가로·세로 방향의 기호 배열로 데이터를 나타내는 바코드 방식.

</details>

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **바코드**는 식별자·데이터를 기계 판독 가능한 기호로 표현한 데이터 캐리어 |
| 목적 | 데이터 입력을 자동화해 식별·거래 처리의 속도와 일관성 향상 |

## Ⅱ. 심볼의 구성과 판독
```text
여백 | 시작 패턴 | 데이터 구간 | 종료 패턴 | 여백
                      |
                      v
광학 스캐너가 바·공백의 반사 차이 판독
                      |
                      v
심볼 규칙에 따라 식별 데이터 복호
```

심볼로지에 따라 시작·종료 패턴, 문자 인코딩, 허용 데이터가 다름. 스캐너는 읽은 패턴을 복호해 애플리케이션으로 전달.

## Ⅲ. GTIN-13과 체크 디지트
| 항목 | 역할 |
|---|---|
| GTIN-13 숫자열 | 거래 품목 식별 키의 13자리 표현 |
| 앞 12자리 | 식별번호의 데이터 부분 |
| 마지막 자리 | GS1 규칙에 따라 앞자리로부터 계산하는 체크 디지트 |
| 검증 의미 | 숫자열 구성 오류 검출 보조; 제품 진위·데이터 보안 보장은 아님 |

체크 디지트는 표준 계산 규칙에 따라 생성·검증. EAN-13을 읽었다는 사실만으로 해당 물품의 진위나 DB 정보의 최신성이 확인되는 것은 아님.

## Ⅳ. 심볼로지 선택
| 선택 축 | 1차원 | 2차원 |
|---|---|---|
| 데이터 배치 | 선형 배열 | 면적을 활용한 배열 |
| 사용 사례 | 유통 품목 식별 등 표준화된 키 판독 | 제조·물류 정보 또는 링크 등 추가 데이터 표현 |
| 운영 고려 | 인쇄 품질, 방향, 여백, 스캐너 호환성 | 인쇄·표시 품질, 지원 리더기, 데이터 규격 |

## Ⅴ. 도입·운영 관리
```text
업무 데이터·식별 기준
          |
          v
표준 심볼로지·인쇄 규격
          |
          v
스캐너·업무 시스템 연계
          |
          v
판독 품질·오류 처리 확인
```

검증은 실제 프린터·재질·거리·각도·조명 조건에서 수행. 식별번호와 업무 레코드의 등록·변경·권한 관리도 스캐너와 별도로 운영.

## Ⅵ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 동일 심볼을 채택해도 인쇄·표시 품질과 리더기 환경 차이로 판독 실패가 남을 수 있음 | 사용 환경별 시료로 적합성을 시험하고, 불량 라벨 재발급·수동 확인·식별 데이터 정정 절차를 함께 마련 |
