## 30초 인출

- 본질: **바코드 (Barcode)** 는 굵기가 서로 다른 흑색 바(Bar)와 백색 공백(Space)의 평행선 조합을 1차원 선형으로 배열하여 품목 식별 데이터(GTIN)를 광학적으로 표현하고 자동 인식하는 AIDC(자동식별·데이터수집) 표준 데이터 캐리어
- 메커니즘: 광학 레이저/CCD 스캐너 조사 → 흑백 반사율 차이에 따른 아날로그 전압 신호 변환 → 디지털 펄스 해석 및 모듈러-10(Modulo-10) 체크디지트 검증 후 POS 연계
- 통찰: 1차원 바코드의 협소한 데이터 용량(20자 내외)과 심볼 훼손 시 복원 불능 한계를 극복하기 위해 GS1 글로벌 표준 2D 바코드(QR/DataMatrix) 전환 체계 구축 필수

<details><summary>핵심 용어</summary>

- **바코드 (Barcode)** : 기계가 판독할 수 있도록 굵기가 다른 선과 여백의 패턴으로 문자나 숫자를 표현한 1차원 광학 식별 기호.
- **EAN-13 (European Article Number)** : 전 세계 유통 상품 식별을 위해 국가코드(3), 제조업체코드(4~6), 상품품목코드(3~5), 체크디지트(1) 총 13자리로 구성된 국제 표준 심볼로지.
- **콰이어트 존 (Quiet Zone)** : 스캐너가 바코드의 시작과 끝을 명확히 인식할 수 있도록 심볼 좌우 양단에 확보해야 하는 최소 여백 공간.
- **체크디지트 (Check Digit)** : 스캔 오독이나 키보드 오입력을 검출하기 위해 가중치(1과 3)를 교차 곱하여 산출하는 모듈러-10 기반 수학적 검증 숫자.
- **GS1 Digital Link** : 1차원 바코드를 웹 URI 기반 2차원 QR 코드로 진화시켜 단일 스캔으로 POS 결제와 웹 상품 정보를 동시 제공하는 차세대 표준.

</details>

## 2~4교시 25점 답안

## Ⅰ. 바코드의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **바코드** 는 다양한 너비의 흑색 바(빛을 흡수)와 백색 스페이스(빛을 반사)의 조합을 선형으로 인쇄하여 영숫자 및 제품 식별 코드를 광학 스캐너가 자동 판독할 수 있도록 부호화한 1차원 심볼로지 |
| 목적 | 수작업 키인(Key-in) 입력 오류를 원천 방지하고 유통(POS), 재고 관리, 물류 트래킹의 속도와 정확성을 비약적으로 향상 |

## Ⅱ. 1차원 바코드의 심볼 구조 및 체크디지트 검증 특징

| 심볼 구성 요소 | 물리적 형태 및 배치 | 공학적 기능 및 특징 |
|---|---|---|
| **콰이어트 존 (Quiet Zone)** | 심볼 좌우 양 끝의 인쇄 없는 여백 | 주변 글자나 그래픽과의 간섭을 차단하고 스캐너의 판독 시작/종료 기준선 제공 (최소 모듈 폭의 10배 이상 필수) |
| **시작/종료 가드 패턴** | 양단에 위치한 가늘고 긴 흑-백-흑 선 | 스캐너에게 심볼의 양 끝 경계를 알리고 전방향 정역(양방향) 스캔 지원 |
| **중앙 가드 패턴 (Center Guard)** | 심볼 한가운데 위치한 백-흑-백-흑-백 선 | 13자리 숫자를 좌측 6자리와 우측 6자리로 분할하여 부분 스캔 및 판독 안정성 제고 |
| **모듈러-10 체크디지트** | EAN-13의 13번째 맨 마지막 자리 숫자 | 홀수/짝수 자리별 가중치($\times 1, \times 3$) 합산 후 10의 배수로 떨어지도록 검산하여 오독률 극소화 |

## Ⅲ. 바코드 광학 판독 및 디코딩 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             1차원 바코드 (EAN-13) 스캔 및 디코딩 파이프라인             │
└────────────────────────────────────────────────────────────────────────┘
 [ 레이저 / LED 빔 조사 (Laser Light Emission) ]
                       │
                       ▼
 [ 바코드 표면 반사광 수신 (Photodiode Sensor) ]
  - 흑색 바: 빛 흡수 ──> 낮은 전압 / 백색 공백: 빛 반사 ──> 높은 전압
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 아날로그 파형 수신 및 이진 구형파(Square Wave) 변환                   │
 │                                                                      │
 │   Voltage                                                            │
 │     High ──┐    ┌──┐    ┌──┐      (백색 공백: 1)                     │
 │      Low   └───┘  └───┘  └──────  (흑색 바: 0)                       │
 └─────────────────────┬────────────────────────────────────────────────┘
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 펄스 폭 측정 및 디코딩 (T-Counter & Character Decode)                │
 │  - 각 바와 스페이스의 상대적 폭 비율(1T, 2T, 3T, 4T) 정밀 계측       │
 │  - EAN-13 문자셋 매핑 테이블 참조 ──> 12자리 원천 데이터 복원         │
 └─────────────────────┬────────────────────────────────────────────────┘
                       │
                       ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 모듈러-10 체크디지트 검증 (Modulo-10 Validation)                     │
 │  - 공식: Sum = (홀수자리 합) * 1 + (짝수자리 합) * 3                  │
 │  - Check Digit = (10 - (Sum % 10)) % 10                              │
 │  - 13번째 수신 숫자와 계산 결과 1:1 일치 확인                         │
 └─────────────────────┬────────────────────────────────────────────────┘
                       │ 검증 성공
                       ▼
 [ POS / ERP 시스템으로 상품 코드 전송 (Price Look-Up & 결제 완결) ]
```

| 검증 단계 | 계산 규칙 및 절차 | 예시 검증 (880123456789 + CD) |
|---|---|---|
| **홀수 자리 합산** | 1, 3, 5, 7, 9, 11번째 자리 합산 | $8 + 0 + 2 + 4 + 6 + 8 = 28$ |
| **짝수 자리 합산** | 2, 4, 6, 8, 10, 12번째 자리 합산 후 $\times 3$ | $(8 + 1 + 3 + 5 + 7 + 9) \times 3 = 33 \times 3 = 99$ |
| **총합 산출** | 홀수합 + 짝수합 | $28 + 99 = 127$ |
| **체크디지트 계산** | 10에서 1의 자리를 뺌 | $(10 - (127 \pmod{10})) \pmod{10} = (10 - 7) = 3$ |

## Ⅳ. 자동인식 식별자 기술 비교 (1D 바코드 vs 2D QR vs RFID)

| 비교 항목 | 1차원 바코드 (EAN/UPC) | 2차원 바코드 (QR코드) | 전자태그 (RFID) |
|---|---|---|---|
| **데이터 축** | 수평 1차원 선형 패턴 | 수평/수직 2차원 매트릭스 | 무선 RF 칩셋 메모리 |
| **저장 용량** | 숫자 13~20자 내외 (단순 ID) | 수천 자 (URL, 이력, 제원) | 수 KB (데이터 읽기/쓰기 가능) |
| **인식 거리 및 각도** | 수십 cm 이내, 레이저 라인 정렬 | 1m 이내, 360도 전방향 | 수 m ~ 수십 m, 비가시선(NLOS) |
| **동시 다중 인식** | 불가 (1회 1개 스캔) | 제한적 (동시 2~3개) | 가능 (초당 수백 개 일괄 리딩) |
| **손상 시 복원력** | 전무 (선 하나 찢기면 판독 불가) | 최상 (리드-솔로몬 최대 30% 복원) | 내구성 우수 (물리 파손 전까지) |
| **태그 개당 단가** | 거의 0원 (인쇄 잉크 비용) | 거의 0원 (인쇄 잉크 비용) | 수십~수백 원 (칩 및 안테나 비용) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 단순 식별 번호만 저장 가능하여 유통기한, 제조일자, 원산지 등 세부 이력 추적 정보 표현 불가 | 상품 식별자(GTIN)와 추가 속성(유통기한, 로트번호)을 결합 인코딩하는 GS1 DataMatrix 또는 GS1 QR코드로 전면 전환 |
| 인쇄 번짐, 라벨 훼손, 곡면 부착 시 스캐너의 펄스 폭 오판독으로 인한 계산대 판독 마비(No-Read) | ISO/IEC 15416 기반 인쇄 품질 검증기(Verifier)를 도입하여 심볼 콘트라스트(SC)와 모듈레이션 등급 관리 |
| 위조 바코드 복제 및 스캔을 통한 계산대 가격 바꿔치기(Sweethearting) 사기 범죄 취약 | 체크디지트 검증을 넘어 POS 백엔드 상품 마스터 DB와 중량 센서(Scale) 실측값을 교차 대조하는 검증 로직 결합 |

## Ⅵ. 제언

글로벌 유통 표준 변화(GS1 Sunrise 2027)에 선제 대응하기 위해 1차원 바코드를 웹 링크와 결합된 2차원 GS1 Digital Link 체계로 전환하는 차세대 스마트 패키징 아키텍처 구축 권고.

```text
[ 단일 2차원 GS1 Digital Link 심볼 인쇄 (QR / DataMatrix) ]
  - URI 구조: https://id.brand.com/01/{GTIN}/10/{LOT}/17/{EXP}
                          │
         ┌────────────────┴────────────────┐
         ▼ (스캐너 유형에 따른 분기)        ▼
 [ POS 광학 이미지 스캐너 ]      [ 소비자 스마트폰 카메라 스캔 ]
         │                                 │
         ▼ (Application Identifier 파싱)   ▼ (HTTPS 웹 접속)
 ┌──────────────────────────────┐ ┌──────────────────────────────┐
 │ 유통 매장 POS 시스템        │ │ 브랜드 고객 경험 웹 포털     │
 │  - GTIN: 자동 상품 결제      │ │  - 유통기한 및 신선도 확인   │
 │  - LOT/EXP: 유통기한 경과    │ │  - 정품 인증 및 리콜 안내    │
 │    상품 자동 판매 차단        │ │  - 원산지 ESG 탄소발자국 조회│
 └──────────────────────────────┘ └──────────────────────────────┘
```

| 구분 | 레거시 1차원 바코드 (EAN-13) | 제언: 차세대 GS1 Digital Link (2D) |
|---|---|---|
| **저장 데이터** | 고정된 13자리 상품 식별자 | 상품 식별자 + 로트번호 + 유통기한 + URL |
| **유통기한 차단** | 계산대 수기 확인 (기한 경과 판매 사고) | POS에서 유통기한 파싱하여 판매 자동 차단 |
| **소비자 소통** | 단순 번호로 소비자 정보 확인 불가 | 스마트폰 기본 카메라로 상세 스토리텔링 제공 |
| **산업 표준화** | 점진적 퇴역 예정 | 글로벌 GS1 2027 권고 공식 차세대 표준 |
