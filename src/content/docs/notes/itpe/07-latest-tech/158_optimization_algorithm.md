## 연관 키워드

- 최적화 알고리즘(Optimization Algorithm), 경사하강법(Gradient Descent), SGD(Stochastic Gradient Descent)
- 모멘텀(Momentum), RMSprop, Adam, AdamW, 학습률 스케줄러
- 가중치 감쇠(Weight Decay), L2 정규화, 안장점(Saddle Point), 국소 최솟값(Local Minima)
- 그래디언트 클리핑(Gradient Clipping), 워밍업(Warmup), 코사인 감쇠(Cosine Annealing), EMA

## Ⅰ. 최적화 알고리즘(Optimization Algorithm)의 개요

- 핵심 요약 : 손실 함수의 기울기 정보를 이용해 가중치를 조금씩 갱신하여 손실을 줄이는 수치 알고리즘.
- 개념 : **역전파** (Backpropagation)로 구한 손실 함수의 기울기를 활용하는 **경사하강법** (Gradient Descent) 계열로, 목적 함수가 목적 함수가 작아지는 방향으로 신경망 가중치 $\theta$를 반복 갱신하는 알고리즘.
- 배경 및 필요성 : 단순한 L2 규제를 **Adam**(Adaptive Moment Estimation)에 그대로 더하면 적응형 학습률과 섞여 **가중치 감쇠** 효과가 왜곡되므로, 감쇠를 기울기 갱신과 분리한 **AdamW** 방식이 필요해짐.
- 주요 목적 : **안장점** (Saddle Point)과 **국소 최솟값** (Local Minima)에서 벗어나고, 수렴 속도를 높이며, 검증 데이터에 대한 일반화 성능을 확보하는 것.

## Ⅱ. 최적화 알고리즘(Optimization Algorithm)의 특징 및 장점

- 핵심 요약 : 기울기의 방향과 크기를 파라미터별로 조절하는 계보를 따라, 수렴 안정성과 일반화를 함께 확보하는 방식으로 발전.

1. 방향 보정(모멘텀) : 과거 기울기를 누적한 관성을 반영 → 좁은 골짜기에서의 진동을 줄이고 수렴 방향을 유지.
2. 파라미터별 보폭 조정 : 기울기 제곱의 누적 평균으로 학습률을 나눔 → 자주 변하는 가중치는 작은 보폭, 드물게 변하는 가중치는 큰 보폭을 적용.
3. 감쇠 분리 : 가중치 감쇠를 손실 함수가 아닌 갱신식에 직접 적용 → 적응형 학습률과 충돌하지 않아 정규화 효과가 의도대로 작동.

- 기울기 기반 갱신 흐름은 다음과 같다.

```text
[ 미니배치 입력 → 손실 L(θ) ]
        ↓
[ 역전파로 기울기 g_t 계산 ]
        ↓
[ 1차 모멘트 m_t (방향) ]
[ 2차 모멘트 v_t (보폭) ]
        ↓
[ 바이어스 보정 후 파라미터 갱신 ]
```

## Ⅲ. 최적화 알고리즘(Optimization Algorithm)의 구조 (흐름)

- 핵심 요약 : 1차 모멘트로 방향을 잡고 2차 모멘트로 보폭을 조절한 뒤, 감쇠를 별도 항으로 분리하는 AdamW 갱신 구조.
- 구성 요소 : 1차 모멘트 $m_t$는 기울기의 지수 이동 평균이고, 2차 모멘트 $v_t$는 기울기 제곱의 지수 이동 평균이다. 초기 단계에서 0으로 편향되는 값은 바이어스 보정으로 보정한다.

```text
[ 1. 기울기 g_t = ∇L(θ_t) ]
        ↓
[ 2. 1차 모멘트 m_t = β1·m + (1-β1)·g ]
[ 2. 2차 모멘트 v_t = β2·v + (1-β2)·g² ]
        ↓
[ 3. 바이어스 보정: m̂, v̂ ]
        ↓
[ 4. 파라미터 갱신 ]
  θ_{t+1} = θ_t - η·λ·θ_t
          - η·m̂/(√v̂+ε)
```

- 단계 4의 첫 번째 항 $\eta \lambda \theta_t$가 가중치 감쇠를 담당하며, 기울기 기반 항과 독립적으로 계산된다.

## Ⅳ. 최적화 알고리즘(Optimization Algorithm)의 비교

- 핵심 요약 : SGD는 일반화에 강하지만 수렴이 느리고, Adam은 빠르지만 정규화가 어긋나기 쉬우며, AdamW는 그 간극을 분리 감쇠로 메운 방식.

| 비교 축 | SGD + 모멘텀 | RMSprop | Adam | AdamW |
| --- | --- | --- | --- | --- |
| 핵심 메커니즘 | 속도 벡터(관성) 반영 | 기울기 제곱의 이동 평균으로 보폭 조정 | 1차와 2차 모멘트 결합 | Adam에 가중치 감쇠 분리 |
| 학습률 조정 | 전역 학습률과 스케줄러 중심 | 파라미터별 자동 조정 | 파라미터별 자동 조정 | 파라미터별 자동 조정 |
| 주요 하이퍼파라미터 | 학습률, 모멘텀 계수 | 학습률, 감쇠율, 엡실론 | 학습률, β1, β2, 엡실론 | 학습률, β1, β2, 엡실론, 감쇠 계수 |
| 가중치 감쇠 | L2 정규화와 동일하게 작동 | L2 정규화 시 스케일 왜곡 | L2 정규화 시 왜곡 큼 | 분리되어 의도대로 작동 |
| 일반화 경향 | 튜닝 시 강함, 수렴은 느림 | 중간 | 일반화에서 SGD에 뒤지는 경우 보고 | 트랜스포머와 LLM(Large Language Model) 학습에서 널리 채택 |

- 선택 기준 : 수렴 속도가 중요하고 모델이 트랜스포머 계열이면 AdamW가 일반적이고, 최종 일반화 성능을 튜닝으로 끌어내야 하는 비전 계열 모델에서는 SGD 모멘텀을 함께 검토한다.

## Ⅴ. 최적화 알고리즘(Optimization Algorithm)의 한계와 방안

- 핵심 요약 : 정규화 왜곡, 초기 학습 불안정, 후반부 진동을 감쇠 분리, 워밍업, 학습률 감쇠와 가중치 평균으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| Adam과 L2 정규화 결합 시 감쇠 왜곡 | 기울기가 큰 가중치는 덜 감쇠되고 작은 가중치는 과하게 감쇠 | 손실 함수에 L2 항을 넣지 않고 갱신식에서 감쇠를 직접 적용하는 AdamW 사용 | 검증 손실과 학습 손실의 격차 |
| 초기 큰 학습률에 따른 기울기 폭주 | 가중치가 크게 흔들려 학습이 붕괴 | 선형 **워밍업** (Warmup)을 초기 수천 스텝에 적용하고, 그래디언트 클리핑(노름 기준 1.0 등) 병행 | 손실 스파이크 횟수 |
| 고정 학습률에 따른 골짜기 진동 | 최적점 주변에서 수렴하지 못하고 맴돎 | 학습률 스케줄러인 **코사인 감쇠** (Cosine Annealing) 적용, 지수 이동 평균(EMA, Exponential Moving Average) 가중치 유지 | 검증 손실 수렴 곡선 |

## Ⅵ. 최적화 알고리즘(Optimization Algorithm)에 대한 기술사적 제언

- 핵심 요약 : 학습 초기 안정화, 감쇠 분리, 후반 스케줄링을 기본 설정으로 고정하고 실험 기록으로 검증하는 체계를 갖추는 것이 필요함.

1. 학습 초기 안정화 설정 : 대형 모델 학습 레시피에 워밍업 구간을 기본으로 포함하여 초기 발산에 따른 재학습 비용을 줄여야 한다.
2. 정규화 방식의 명시 : 팀의 표준 옵티마이저 설정에 가중치 감쇠 방식을 명확히 적고, L2 정규화와 분리 감쇠를 혼용하지 않도록 코드 리뷰 항목에 포함해야 한다.
3. 실험 기록의 표준화 : 학습률 스케줄, 감쇠 계수, 검증 지표를 모든 실험에서 같은 형식으로 기록하여 옵티마이저 선택을 재현 가능하게 해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 최적화 알고리즘은 기울기를 방향과 보폭으로 나누어 갱신하는 기법이며, 현재 대형 모델에서는 AdamW가 표준에 가깝다.
- 시사점 : 옵티마이저 자체보다 워밍업, 감쇠 방식, 스케줄러의 조합이 학습 안정성을 좌우하므로, 이 조합을 기준 설정으로 관리하는 것이 중요하다.
