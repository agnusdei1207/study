## 1교시 10점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 손실 기울기로 모델 매개변수를 반복 갱신하는 방법군 |
| 목적 | 학습 손실 감소와 일반화 성능 개선 |

- **목적:** 손실 함수의 기울기로 가중치를 반복 갱신해 모델을 학습.
- **SGD:** 미니배치 기울기 방향 갱신. **Adam:** 기울기의 1·2차 이동평균으로 파라미터별 갱신 크기 조정.
- **AdamW:** Adam의 적응형 갱신과 가중치 감쇠를 분리. L2 페널티를 Adam 기울기에 더하는 방식과 일반적으로 동치가 아님.

## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 손실 기울기로 모델 매개변수를 반복 갱신하는 방법군 |
| 목적 | 학습 손실 감소와 일반화 성능 개선 |

### Ⅰ. 공통 갱신
- 손실 계산 → 역전파 기울기 산출 → 옵티마이저 상태 갱신 → 파라미터 갱신의 반복.

### Ⅱ. 방식

- Momentum은 과거 갱신 방향 반영, RMSprop은 제곱 기울기 이동평균, Adam은 1·2차 모멘트 결합.

### Ⅲ. AdamW

- 가중치 감쇠 항을 적응형 기울기 갱신과 분리하여 Adam에 더한 L2 페널티와 감쇠의 차이를 해소.

### Ⅳ. 실험 관리

- 웜업·학습률 감쇠·배치 크기는 모델·예산별 탐색. 검증 손실·수렴 시간·일반화와 난수별 안정성 비교.
