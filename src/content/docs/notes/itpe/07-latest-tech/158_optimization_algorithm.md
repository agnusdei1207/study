## 지식 로드맵 내 현재 위치

기계학습 → 손실 최소화 → 최적화 알고리즘

## 30초 인출

- **본질:** 손실 함수의 기울기를 이용하여 학습률과 갱신 규칙에 따라 모델 매개변수를 반복 조정하는 절차
- **메커니즘:** 손실 계산 → 역전파 기울기 → 옵티마이저 상태·학습률 반영 → 매개변수 갱신
- 통찰: 한계: Adam에 L2 페널티를 더하면 적응형 갱신과 감쇠가 결합되어 의도한 정규화 효과가 달라짐 → 방안: AdamW로 감쇠를 분리하고 학습률·감쇠율을 검증 손실로 조정
- **답안 초점:** 딥러닝 최적화에서 SGD·Adam·AdamW의 차이를 설명하시오.

<details><summary>핵심 용어</summary>

- **SGD:** 미니배치 기울기에 따라 매개변수를 갱신하는 방법
- **AdamW:** 적응형 기울기 갱신에서 가중치 감쇠를 분리한 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. 딥러닝 최적화 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 손실 기울기와 갱신 규칙으로 모델 매개변수를 반복 조정하는 방법군 |
| 목적 | 학습 손실을 줄이고 검증 자료에서 일반화 성능 확보 |

## Ⅱ. 손실·기울기·모멘트의 매개변수 갱신 구조

```text
미니배치 → 손실 계산 → 역전파 기울기 gₜ
                            │
             ┌──────────────┼──────────────┐
             │ SGD: gₜ       │ Adam: 1·2차 모멘트
             └──────────────┼──────────────┘
                            ▼
                    학습률 적용·매개변수 갱신
                            │ AdamW: 별도 가중치 감쇠
                            └─ 다음 미니배치·검증 손실로 반복
```

## Ⅲ. SGD·Adam·AdamW 비교

| 방식 | 갱신 특성 | 검토 항목 |
|---|---|---|
| SGD·Momentum | 기울기와 과거 방향 반영 | 학습률·수렴 속도 |
| Adam | 1·2차 모멘트로 적응형 갱신 | 과적합·일반화 |
| AdamW | Adam 갱신과 가중치 감쇠 분리 | 감쇠율·학습률의 독립 조정 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| Adam의 L2 페널티가 적응형 갱신과 결합되어 감쇠 효과 왜곡 | AdamW의 분리형 감쇠 사용 및 감쇠율 별도 탐색 |
| 빠른 훈련 손실 감소가 일반화 우위를 보장하지 않음 | 동일 예산·난수 조건의 검증 손실과 수렴 시간 비교 |

## Ⅴ. 제언

학습률 일정과 평가 예산을 먼저 고정하고 후보별 검증 성능·안정성을 기준으로 선택.
