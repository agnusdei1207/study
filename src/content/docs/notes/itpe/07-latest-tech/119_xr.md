## 30초 인출
- **본질:** XR(Extended Reality)은 현실과 가상 환경을 오가며 경험하는 실감형 기술의 총칭.
- **메커니즘:** 감지한 사용자의 위치·행동에 맞춰 디지털 장면을 현실에 겹치거나 가상 환경으로 구성.
- **구분:** VR은 가상 환경 중심, AR은 현실 위 정보 중첩, MR은 현실과 가상 객체의 공간 상호작용에 초점.

<details><summary>핵심 용어</summary>

- **XR(Extended Reality, 확장현실):** VR·AR·MR을 포괄하는 현실·가상 경험 기술의 범주.
- **VR(Virtual Reality, 가상현실):** 사용자의 시야를 가상 환경으로 구성하는 실감형 경험.
- **AR(Augmented Reality, 증강현실):** 실제 장면 위에 디지털 정보를 겹쳐 보여 주는 방식.
- **MR(Mixed Reality, 혼합현실):** 실제 환경과 가상 객체가 공간을 인식하며 함께 동작하는 방식.
- **현실-가상 연속체(Reality-Virtuality Continuum):** 현실 환경에서 가상 환경까지 실감형 디스플레이를 배치해 설명하는 관점.
- **6DoF(Six Degrees of Freedom, 6자유도):** 위치의 세 축 이동과 회전의 세 축을 함께 추적하는 표현.
- **SLAM(Simultaneous Localization and Mapping, 동시적 위치추정 및 지도작성):** 센서 정보를 이용해 기기 위치와 주변 지도를 함께 추정하는 기술.
- **OpenXR:** 여러 XR 기기와 응용프로그램 사이의 공통 API를 제공하는 개방형 표준.
- **WebXR Device API:** 웹 응용프로그램이 XR 기기 기능에 접근하도록 정의한 웹 API.

</details>

### Ⅰ. 개요

|---|---|
| 정의 | **XR**은 현실·가상 환경을 활용해 사용자의 감각 경험을 구성하는 실감형 기술의 총칭 |

### Ⅱ. 현실-가상 연속체
현실과 완전한 가상 환경 사이에 다양한 혼합 방식이 놓이며, XR은 이 경험 범주를 포괄하는 이름.

```text
현실 환경
   |
   +-- AR: 현실 장면 위에 정보 중첩
   |
   +-- MR: 현실 장면과 가상 객체의 공간 상호작용
   |
   +-- VR: 가상 환경 중심의 시야 구성
   |
가상 환경
<------ 현실-가상 연속체; XR은 전체 범주 ------>
```

### Ⅲ. 주요 방식
| 방식 | 경험의 중심 | 대표적 상호작용 |
|---|---|---|
| **VR** | 가상 환경 | 가상 공간 안에서 이동·조작 |
| **AR** | 실제 장면 | 현실 위 디지털 정보 확인 |
| **MR** | 실제 공간과 가상 객체 | 공간 인식에 따른 가림·배치·조작 |

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **XR**은 현실·가상 환경을 활용해 사용자의 감각 경험을 구성하는 실감형 기술의 총칭 |
| 목적 | 상황에 맞는 현실 정보와 디지털 정보의 직관적 결합 |

## Ⅱ. 개념과 연속체
**현실-가상 연속체**는 현실 환경과 가상 환경 사이에 다양한 혼합현실이 놓이는 관점. XR은 실무에서 이와 같은 실감형 경험 범주를 포괄하는 표현.

```text
현실 환경
   |
   +-- AR: 현실 장면 위에 정보 중첩
   |
   +-- MR: 현실 장면과 가상 객체의 공간 상호작용
   |
   +-- VR: 가상 환경 중심의 시야 구성
   |
가상 환경
<------ 현실-가상 연속체; XR은 전체 범주 ------>
```

## Ⅲ. 유형별 경험과 선택
| 유형 | 현실 장면 | 가상 요소의 역할 | 적합한 경험 |
|---|---|---|---|
| **VR** | 주로 가려지거나 대체 | 가상 환경 자체를 구성 | 모의훈련·가상 탐색 |
| **AR** | 계속 관찰 | 현실 위에 정보 표시 | 안내·현장 정보 확인 |
| **MR** | 공간 인식에 활용 | 현실과 함께 배치·상호작용 | 공간 작업·협업 |

유형은 기기의 이름보다 이용자가 현실을 얼마나 보는지, 가상 객체가 공간과 어떻게 상호작용하는지로 구분.

## Ⅳ. 시스템 구성과 작동
| 구성 | 역할 |
|---|---|
| 센서·추적 | 머리·손의 위치와 주변 공간을 추정 |
| 처리·응용 | 추적 정보와 콘텐츠 규칙을 결합해 장면 계산 |
| 표시 장치 | 광학 투과 또는 카메라 영상 등 기기 방식에 맞게 장면 표시 |
| 입력·상호작용 | 시선·손·컨트롤러 등으로 선택·조작 제공 |

```text
사용자 움직임
      |
      v
센서·공간 추정
      |
      v
응용프로그램의 장면 계산
      |
      v
디스플레이에 장면 표시
      |
      v
사용자 반응·다음 움직임
```

장치가 움직임을 감지하고 장면을 갱신하는 지연·정합성은 몰입감과 사용성에 영향. 허용 지연은 기기·사용 사례·측정 조건에 따라 달라지므로 보편 임계값으로 단정하지 않음.

## Ⅴ. 상호운용성과 적용 고려사항
| 고려축 | 확인 항목 |
|---|---|
| 기기·응용 호환 | 대상 기기와 런타임에서 지원되는 기능 및 API 확인 |
| 공간·표시 품질 | 추적 정확도, 장면 정합, 표시 방식 및 사용 환경 검증 |
| 안전·개인정보 | 카메라·공간 데이터의 수집 목적, 저장·전송, 접근 권한 검토 |
| 운영 적합성 | 착용성, 접근성, 장시간 사용 조건 및 현장 작업성 평가 |

**OpenXR**은 여러 XR 기기에서 응용프로그램의 이식성을 높이기 위한 API 표준이며, **WebXR Device API**는 웹 콘텐츠의 XR 기기 접근을 위한 API. 각 표준의 지원 범위와 구현 상태는 대상 플랫폼에서 확인.

## Ⅵ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 기기·사용 사례마다 추적 성능, 표시 방식, 데이터 처리 조건이 달라 일률적인 구성이 어려움 | 요구 경험과 현장 위험을 먼저 정리하고, 소규모 실증에서 사용성·정합성·개인정보 처리 결과를 확인한 뒤 기기와 표준 API를 선정 |
