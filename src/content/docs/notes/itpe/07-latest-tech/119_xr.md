## 연관 키워드

- 확장현실(XR, eXtended Reality), 가상현실(VR), 증강현실(AR), 혼합현실(MR)
- 사이버 멀미(Cyber Sickness), 모션-투-포톤(MTP, Motion-to-Photon), 포비티드 렌더링(Foveated Rendering)
- 슬램(SLAM), 정합(Registration), 비동기 타임워프(ATW), 스플릿 렌더링(Split Rendering), OpenXR, MEC

## Ⅰ. XR의 개요

- 핵심 요약 : 현실과 가상을 융합해 몰입과 상호작용을 높이는 기술을 아우르는 가상융합 기술.
- 개념 : 가상현실(VR, Virtual Reality), 증강현실(AR, Augmented Reality), 혼합현실(MR, Mixed Reality)을 포괄하여, 컴퓨터 그래픽으로 만든 가상 정보와 물리 세계를 결합해 감각적 상호작용과 공간 몰입을 극대화하는 **확장현실**(XR, eXtended Reality).
- 배경 및 필요성 : 기기 무게와 발열, 배터리 한계가 있고, 머리 움직임이 화면에 반영되기까지의 지연인 **모션-투-포톤**(MTP, Motion-to-Photon) 지연이 길면 **사이버 멀미**(Cyber Sickness, 시각과 몸의 감각이 어긋나 생기는 어지럼증)가 생긴다. 이를 줄이려면 기지국 인근 서버에서 연산을 나누는 **MEC**(Multi-access Edge Computing) 연계와 시선 추적 기반 렌더링이 필요하다.
- 주요 목적 : 2차원 화면의 정보 전달 한계를 넘어 원격 협업, 고위험 모의훈련, 제조·의료 현장의 생산성을 높이는 것.

## Ⅱ. XR의 특징 및 장점

- 핵심 요약 : 공간 인지와 실시간 렌더링이 결합되어 가상 객체가 실제 공간에 고정되는 몰입감을 만드는 구조.

1. **슬램**(SLAM, Simultaneous Localization and Mapping, 자기 위치 추정과 주변 지도 작성을 동시에 수행하는 기술) : 6자유도 위치를 추적 → 가상 객체를 현실 공간에 고정.
2. **정합**(Registration, 가상 객체를 현실 좌표에 맞춰 겹치는 처리) : 객체 위치를 실제 물체에 맞춤 → 현실과 가상이 어긋나지 않음.
3. **포비티드 렌더링**(Foveated Rendering, 시선이 머무는 영역만 고해상도로 그리는 기법) : 주변부 연산을 줄임 → 렌더링 부하와 지연 감소.
4. **OpenXR**(크로노스 그룹이 제정한 개방형 XR 표준 API) : 기기 간 공통 인터페이스 제공 → 콘텐츠 이식성 향상.

## Ⅲ. XR의 구조 (흐름)

- 핵심 요약 : 공간 인지, 분산 렌더링, 시각 보정의 세 계층이 순서대로 이어져 지연을 줄이는 파이프라인.
- **비동기 타임워프**(ATW, Asynchronous Timewarp, 렌더링이 늦어도 최신 머리 위치로 프레임을 보정하는 기법) : 표시 직전에 영상을 보정해 지연에 따른 어긋남을 줄임.
- **스플릿 렌더링**(Split Rendering, 무거운 렌더링을 서버로 나누고 단말은 표시에 집중하는 구조) : 단말 부하를 외부 연산으로 옮김.

```text
[ XR 종단간 처리 흐름 ]

사용자 머리·손 움직임
   ↓
[1단계] 공간 인지와 추적
   ↓ 6DoF 포즈, 공간 메쉬
[2단계] 엣지 연산과 렌더링
   ↓ 인코딩 영상 스트림
[3단계] 표시와 시각 보정
   ↓
사용자 인지와 상호작용
```

```text
[ 현실과 가상의 연속선 ]

현실 환경
   ↓ 가상 정보 오버레이
증강현실 (AR)
   ↓ 가상 객체가 현실 공간과 상호작용
혼합현실 (MR)
   ↓ 외부 시야 차단
가상현실 (VR)
```

## Ⅳ. XR의 비교

- 핵심 요약 : VR, AR, MR은 외부 시야를 얼마나 유지하느냐와 현실과 상호작용하는 방식에서 갈린다.

| 비교 축 | VR (가상현실) | AR (증강현실) | MR (혼합현실) |
| --- | --- | --- | --- |
| 외부 시야 | 완전 차단 | 현실 시야 유지 | 현실 시야에 가상을 융합 |
| 공간 상호작용 | 가상 객체끼리 상호작용 | 현실 위에 단순 오버레이 | 현실 표면과 가상 객체가 상호작용 |
| 주요 기기 형태 | 외부 빛을 막는 HMD(Head Mounted Display) | 광학 투과형 스마트 안경 | 비디오 투과형 HMD |
| 핵심 기술 | 고해상도 디스플레이, 룸스케일 추적 | 도파관(Waveguide) 광학계 | 공간 인식, 실시간 깊이 센싱 |

- 선택 기준 : 현실 시야 유지 필요성, 작업 시간, 공간 인식 요구 수준에 따라 기기 형태를 정한다. XR은 이 셋을 모두 포괄하는 상위 개념이다.

## Ⅴ. XR의 한계와 방안

- 핵심 요약 : 사이버 멀미, 무게와 발열, SDK 파편화를 지연 보정, 스플릿 렌더링, 개방 표준으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 사이버 멀미 | MTP 지연으로 시각과 전정 감각이 어긋나 어지럼과 구토 유발 | 하드웨어 파이프라인에 ATW 보정을 내장하고 시선 추적 포비티드 렌더링으로 지연 단축 | MTP 지연 시간, 사용 중단율 |
| 무게·발열·배터리 | 고해상도 패널과 GPU 부하로 발열과 짧은 사용 시간이 생겨 교대 근무 현장에 부적합 | 연산부를 MEC 서버로 분리하고 단말은 디코딩에 집중하는 스플릿 렌더링 채택 | 연속 사용 시간, 단말 표면 온도 |
| SDK 파편화 | 제조사별 독자 SDK로 인해 콘텐츠 이식과 개발 비용 급증 | OpenXR과 W3C의 WebXR Device API 기반 크로스 플랫폼 개발 | 플랫폼별 포팅 공수 |

## Ⅵ. XR에 대한 기술사적 제언

- 핵심 요약 : 기기 경량화, 지연 관리, 개방 표준을 함께 풀어야 XR이 현장 도구로 정착할 수 있음.

1. 제조 기업은 단말의 무게와 발열을 줄이기 위해 연산을 엣지 서버로 분리하는 구조를 전제로 현장 장비를 기획해야 한다.
2. 정보기술 부서는 MEC 기반 저지연 네트워크와 렌더링 서버를 공통 인프라로 구축하고, 콘텐츠 개발팀이 OpenXR 같은 표준 인터페이스를 따르도록 개발 지침을 마련해야 한다.
3. 안전과 보건을 담당하는 기관은 장시간 사용 시 멀미와 피로를 점검하는 기준을 현장 가이드에 반영해, 업무용 XR이 작업자 건강을 해치지 않도록 해야 한다.

## Ⅶ. 결론

- 핵심 요약 : XR은 현실과 가상을 잇는 상위 개념이며, 지연과 연산 부담을 분산하는 구조가 현장 활용의 전제임.
- 시사점 : 기기 성능보다 지연 관리와 표준 준수가 실사용 가치를 좌우하므로, 단말과 인프라를 함께 설계해야 한다.
