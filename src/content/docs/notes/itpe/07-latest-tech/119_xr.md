## Ⅰ. XR(eXtended Reality)의 개요

- **개념** : 컴퓨터 그래픽스로 구현된 디지털 가상 정보와 물리적 현실 세계를 융합하여 인간의 오감 상호작용과 공간적 몰입감을 극대화하는 VR, AR, MR 포괄 가상융합 기술
- **배경 및 필요성** : 기기 무게, 발열, 배터리 한계와 모션-투-포톤(MTP) 지연에 따른 사이버 멀미(Cyber Sickness)가 존재하므로 5G/6G MEC 기반 분산 렌더링과 시선 추적 기반 포비티드 렌더링(Foveated Rendering) 구축 필수
- **핵심 목적** : 2차원 평면 스크린의 정보 전달 한계를 극복하고 시공간 제약 없는 원격 협업, 고위험 모의훈련 및 제조·의료 현장의 생산성 혁신 달성

## Ⅱ. XR(eXtended Reality)의 핵심 아키텍처 및 동작 메커니즘

XR은 공간 센서(LiDAR/RGB 카메라) 및 6DoF 슬램(SLAM)으로 물리 환경을 매핑하고, GPU 렌더링 엔진으로 현실-가상 객체 정합(Registration)을 거쳐 광학/비디오 패스스루 디스플레이로 초저지연 표출 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             XR (eXtended Reality) 종단간 실시간 처리 파이프라인        │
└────────────────────────────────────────────────────────────────────────┘
 [ 물리 환경 & 사용자 움직임 (User Head/Hand Motion) ]
                         │
                         ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 1단계: 공간 인지 및 추적 계층 (Spatial Sensing & 6DoF Tracking)       │
 │  - Inside-out 카메라 + IMU 센서 ──> VIO(Visual Inertial Odometry)     │
 │  - 실시간 공간 3D 메쉬 생성: LiDAR 깊이 맵 + 공간 앵커(Spatial Anchor) │
 └───────────────────────┬──────────────────────────────────────────────┘
                         │ 6DoF 포즈 좌표 & 공간 메쉬 데이터
                         ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 2단계: 장면 계산 및 분산 렌더링 계층 (Compute & Split Rendering)      │
 │  - 5G/6G MEC 엣지 서버: 무거운 물리 엔진 연산 및 8K 가상 그래픽 렌더링 │
 │  - 시선 추적(Eye-tracking) 센서 연동 포비티드 렌더링(Foveated) 적용  │
 └───────────────────────┬──────────────────────────────────────────────┘
                         │ 인코딩된 비디오 스트림 전송
                         ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ 3단계: 디스플레이 표출 계층 (Display & Time-Warp Correction)          │
 │  - 비동기 타임워프(ATW) / 스페이스워프(ASW)로 MTP 지연 보정 │
 │  - 마이크로 OLED 패널 광학 투과 또는 비디오 패스스루(VST) 표출        │
 └───────────────────────┬──────────────────────────────────────────────┘
                         │ 시각 피드백
                         ▼
 [ 사용자 인지 및 핸드 트래킹/햅틱 피드백 상호작용 (Next Interaction) ]
```

- **현실 환경 (Real World)** : 아날로그 물리 세계 - 센서와 카메라로 디지털 캡처되는 원천 물리 공간
- **증강현실 (AR: Augmented)** : 현실 기반 + 가상 텍스트/객체 오버레이 - 스마트 글래스를 통해 현실 시야를 유지한 채 작업 가이드 표출
- **증강가상 (AV: Augmented Virtuality)** : 가상 기반 + 실시간 현실 객체 비디오 결합 - 가상 회의실 내에 실제 사용자 웹캠 비디오 스트림을 합성
- **가상현실 (VR: Virtual)** : 현실 차단 + 100% 디지털 합성 환경 - HMD(Head Mounted Display)로 외부 빛을 완전 차단한 몰입형 시뮬레이션

## Ⅲ. XR(eXtended Reality)의 세부 구성 요소 및 비교 분석

| 비교 항목 | VR (가상현실) | AR (증강현실) | MR (혼합현실) | XR (확장현실 - 본 토픽) |
|---|---|---|---|---|
| **시야각 차폐** | 외부 시야 완전 차단 | 현실 시야 유지 (광학 투과) | 현실 시야에 공간적 융합 | 사용 과업에 따라 가변 조절 |
| **공간 상호작용** | 가상 물체끼리만 상호작용 | 단순 현실 위 오버레이 | 현실 벽/테이블과 가상 상호작용 | 디지털 트윈 기반 물리-가상 동기화 |
| **주요 하드웨어** | Meta Quest, HTC Vive | 스마트 안경 (XREAL, HoloLens) | Apple Vision Pro (VST 방식) | 모든 차세대 공간 컴퓨팅 디바이스 |
| **핵심 기술** | 고해상도 HMD, 룸스케일 센서 | 웨이브가이드(Waveguide) 광학계 | 공간 음향, 실시간 깊이 센싱 | OpenXR 표준, 5G MEC 분산 처리 |

- XR은 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. XR(eXtended Reality)의 주요 한계점 및 해결 방안

- **감각과 시각 프레임 간 시차(MTP Latency > 20ms)로 인한 사이버 멀미** :
  - **한계점** : 신체 전정기관의 감각과 시각적 프레임 간의 시차(MTP Latency > 20ms)로 인해 어지럼증과 구토를 유발하는 사이버 멀미.
  - **해결 방안** : 비동기 타임워프(ATW) 알고리즘을 하드웨어 파이프라인에 내장하고 시선 추적 포비티드 렌더링으로 렌더링 지연을 단축.
- **고화질 패널 구동에 따른 발열, 무거운 무게 및 짧은 배터리 지속 시간** :
  - **한계점** : 고화질 4K 패널 및 GPU 고속 연산에 따른 기기 발열, 무거운 무게(500g 이상) 및 짧은 배터리 지속 시간(2시간).
  - **해결 방안** : 배터리 및 무거운 렌더링 연산부를 허리 포켓이나 5G 초저지연 MEC 엣지 클라우드로 외재화하는 스플릿 렌더링(Split Rendering) 채택.
- **기기 제조사별 독자 SDK 파편화로 인한 콘텐츠 호환성 및 개발 비용 급증** :
  - **한계점** : 기기 제조사(Meta, Apple, Google)별 독자 SDK 파편화로 인한 콘텐츠 개발 및 상호 호환성 비용 급증.
  - **해결 방안** : 크로노스 그룹의 개방형 표준 API인 OpenXR과 웹 표준 WebXR Device API 기반의 크로스 플랫폼 프레임워크 전면 준수.

## Ⅴ. XR(eXtended Reality) 적용 및 발전을 위한 기술사적 제언

- **기기 무게 및 발열 중심 엔터프라이즈 고도화** : 배터리/AP 일체형으로 무겁고 발열 심각의 한계를 탈피하고, 연산부 외재화로 초경량화(선글라스 형태)를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- **그래픽 충실도 중심 엔터프라이즈 고도화** : 모바일 GPU 수준의 저품질 그래픽의 한계를 탈피하고, 서버급 RTX GPU 활용으로 실사급 트윈 구현을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- **배터리 지속력 중심 엔터프라이즈 고도화** : 1.5~2시간 (현장 교대근무 부적합)의 한계를 탈피하고, 저전력 디코딩만 수행하여 6시간 이상 연속 작업을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
