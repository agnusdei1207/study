## 지식 로드맵 내 현재 위치

## 30초 인출

- 본질: **의사결정나무(Decision Tree)** 는 입력 특성에 조건을 적용해 자료를 나누고 잎에서 예측하는 지도학습 모델
- 메커니즘: 분할 기준 평가 → 조건 선택 → 자식 노드 분할 반복 → 정지 조건에서 잎의 예측 결정

<details>
<summary>핵심 용어</summary>

- **의사결정나무(Decision Tree)** : 특성 조건으로 자료를 재귀 분할해 분류·회귀 결과를 예측하는 모델
- **엔트로피(Entropy)** : 클래스 분포의 불확실성을 나타내는 값
- **지니 불순도(Gini Impurity)** : 노드 안의 클래스가 섞인 정도를 나타내는 값
- **가지치기(Pruning)** : 트리의 일부 가지를 제한·제거해 복잡도를 조정하는 방법
- **정보 이득(Information Gain)** : 분할 전후 엔트로피 감소량으로 분할 효과를 평가하는 기준
</details>

### Ⅱ. 분할·예측 구조

```text
전체 학습 자료(루트)
```

### Ⅲ. 주요 분할 기준

| 기준 | 의미·계산 | 선택 방향 |
|---|---|---|
| 엔트로피 | $-\sum p_i\log_2 p_i$; 클래스 불확실성 | 자식 노드의 가중 엔트로피 감소 |
| 지니 불순도 | $1-\sum p_i^2$; 클래스 혼합 정도 | 자식 노드의 가중 지니 감소 |
| 회귀 분할 | 분산·제곱 오차 등 감소 | 자식 노드의 가중 오차 감소 |

### Ⅳ. 과적합과 복잡도 제어

| 방법 | 적용 시점 | 조정 요소 |
|---|---|---|
| 사전 제한 | 분할 학습 중 | 최대 깊이·최소 분할 표본·최소 잎 표본 |
| 사후 가지치기 | 트리 생성 후 | 검증 성능과 복잡도를 고려한 하위 가지 제거 |
| 모델 평가 | 학습·선택 단계 | 교차검증 등으로 일반화 성능·안정성 확인 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 예측 점수만 최적화하면 업무에 필요한 설명 수준을 넘어서 트리가 복잡해질 수 있음 | 사용 목적별 설명 요구를 정하고 검증 성능과 이해 가능한 깊이를 함께 만족하는 트리를 선택 |
