## 지식 로드맵 내 현재 위치

지식 위치: 지도학습 → 규칙·조건 기반 예측 → **의사결정나무**

## 30초 인출

- 본질: **의사결정나무(Decision Tree)** 는 입력 특성에 조건을 적용해 자료를 나누고 잎에서 예측하는 지도학습 모델
- 메커니즘: 분할 기준 평가 → 조건 선택 → 자식 노드 분할 반복 → 정지 조건에서 잎의 예측 결정
- 통찰: 한계: 분할을 깊게 반복하면 학습 자료의 잡음까지 따르는 과적합 → 방안: 깊이·잎 크기를 제한하고 검증 자료에서 성능 확인

<details>
<summary>핵심 용어</summary>

- **의사결정나무(Decision Tree)** : 특성 조건으로 자료를 재귀 분할해 분류·회귀 결과를 예측하는 모델
- **엔트로피(Entropy)** : 클래스 분포의 불확실성을 나타내는 값
- **지니 불순도(Gini Impurity)** : 노드 안의 클래스가 섞인 정도를 나타내는 값
- **가지치기(Pruning)** : 트리의 일부 가지를 제한·제거해 복잡도를 조정하는 방법
- **정보 이득(Information Gain)** : 분할 전후 엔트로피 감소량으로 분할 효과를 평가하는 기준
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **의사결정나무(Decision Tree)** 는 입력 특성에 조건을 적용해 자료를 나누고 잎에서 예측하는 지도학습 모델 |
| 목적 | 분류·회귀 예측과 판단 경로의 가시적 표현 |

### Ⅱ. 분할·예측 구조

```text
전체 학습 자료(루트)
          ↓ 분할 조건 선택
특성 조건으로 자료 분기
      ┌───┴───┐
   하위 노드  하위 노드
      ↓ 반복 분할
정지 조건 충족 시 잎 노드
          ↓
분류 결과 또는 수치 예측
```

### Ⅲ. 주요 분할 기준

| 기준 | 의미·계산 | 선택 방향 |
|---|---|---|
| 엔트로피 | $-\sum p_i\log_2 p_i$; 클래스 불확실성 | 자식 노드의 가중 엔트로피 감소 |
| 지니 불순도 | $1-\sum p_i^2$; 클래스 혼합 정도 | 자식 노드의 가중 지니 감소 |
| 회귀 분할 | 분산·제곱 오차 등 감소 | 자식 노드의 가중 오차 감소 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 깊은 분할로 훈련 잡음까지 학습 | 최대 깊이·최소 잎 표본을 제한하고 사후 가지치기 |
| 훈련 성능만으로 복잡한 트리를 선택 | 교차검증으로 일반화 성능·안정성 확인 |
| 예측 점수만 최적화하면 설명 가능 수준을 넘어선 복잡도 | 사용 목적의 설명 요구와 검증 성능을 함께 만족하는 깊이 선택 |

### Ⅴ. 제언

업무의 설명 요구를 먼저 정하고 그 범위에서 검증 성능이 안정적인 가장 단순한 트리를 선택.
