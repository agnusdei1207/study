## 연관 키워드

- 의사결정나무(Decision Tree), 분류(Classification), 회귀(Regression)

- CART, C4.5, ID3, CHAID, 가지치기(Pruning), 오버피팅(Overfitting)
- 랜덤 포레스트(Random Forest), 설명가능성(XAI, Explainable Artificial Intelligence)

## Ⅰ. 의사결정나무(Decision Tree)의 개요

- 핵심 요약 : 특성값을 기준으로 데이터를 반복 분할해 사람이 읽을 수 있는 규칙 트리로 예측하는 지도학습 알고리즘.
- 개념 : 입력 특성을 기준값으로 반복 분할(Recursive Binary Splitting)하여 계층적 규칙을 만들고, 리프 노드(Leaf Node)에서 **분류** (Classification) 또는 **회귀** (Regression)를 수행하는 지도학습 모델.
- 배경 및 필요성 : 딥러닝과 복잡한 앙상블은 내부 동작을 설명하기 어려운 블랙박스 특성을 가지지만, 금융 심사 등 규제 영역에서는 판단 근거의 설명이 필수적이다. 의사결정나무는 IF-THEN 형태의 규칙을 그대로 제공해 이 요구에 부응한다.
- 주요 목적 : 분할 후 불순도를 줄이고, 해석 가능한 규칙을 도출하며, 랜덤 포레스트나 GBDT(Gradient Boosting Decision Tree) 같은 앙상블의 기본 학습기로 쓰이는 것.

## Ⅱ. 의사결정나무(Decision Tree)의 특징 및 장점

- 핵심 요약 : 규칙이 명시적으로 드러나는 구조가 설명가능성과 빠른 학습으로 이어지는 모델.

1. 화이트박스 규칙 : 분기 조건을 그대로 IF-THEN으로 읽을 수 있음 → 심사·진단 근거를 사람에게 설명 가능.
2. 전처리 부담 감소 : 정규화나 스케일링 없이도 분할 기준만 찾으면 되므로 데이터 준비 공수 축소.
3. 탐욕적 분할 : 루트에서 각 노드마다 최적 분할을 고르는 방식 → 학습 속도가 빠르고 구현이 단순함.
4. 비선형 관계 포착 : 특성 간 상호작용을 분기 경로로 표현 → 복잡한 조건 조합의 규칙화.

## Ⅲ. 의사결정나무(Decision Tree)의 구조 (흐름)

- 핵심 요약 : 루트에서 리프로 내려갈수록 불순도가 줄어드는 계층 구조이며, 분할 기준은 불순도 감소량으로 정한다.

```text
[ 루트 노드 : 나이 <= 30 ? ]
          │
   YES ◄──┴──► NO
    ↓            ↓
[ 내부 노드 ]  [ 리프 노드 ]
소득 <= 5천만?  대출 승인
    ↓
[ 리프 ] 거절 / 승인
```

```text
[ 불순도 계산 ]

지니 계수 : Gini = 1 - Σ p_i²
엔트로피  : Entropy = -Σ p_i log2(p_i)
정보 이득 : 부모 불순도 - 자식 가중 평균
```

- **정보 이득** (Information Gain) : 분할 후 감소한 불순도 양으로, 값이 최대가 되는 분할점을 선택한다.
- **회귀 트리** (Regression Tree) : 분류의 불순도 대신 분산이나 평균제곱오차(MSE, Mean Squared Error) 감소량으로 분할한다.
- **가지치기** (Pruning) : 노이즈까지 학습하는 과적합을 억제하기 위해 트리 성장을 제한하거나 하위 노드를 잘라낸다.

## Ⅳ. 의사결정나무(Decision Tree)의 비교

- 핵심 요약 : 알고리즘마다 분할 기준과 분기 형태가 달라, 현대 라이브러리는 이진 분할을 하는 CART를 표준으로 쓴다.

| 알고리즘 | 개발 연도 | 분할 기준 | 분기 형태 | 특징 |
| --- | --- | --- | --- | --- |
| ID3 | 1986 (Quinlan) | 정보 이득 | 다지 분할 | 범주형만 처리, 결측치 처리 불가 |
| C4.5 / C5.0 | 1993 (Quinlan) | 정보 이득비 | 다지 분할 | 연속형 지원, 결측치 처리, 사후 가지치기 |
| CART | 1984 (Breiman 외) | 지니 계수 / 분산 감소 | 항상 이진 분할 | 분류·회귀 모두 지원, 라이브러리 표준 |
| CHAID | 1980 (Kass) | 카이제곱 검정 | 다지 분할 | 통계적 유의성 기반, 마케팅 세분화에 활용 |

- CART는 이진 분기로 복잡도가 낮아 현대 머신러닝 라이브러리의 기본 구현으로 채택되어 있다.

## Ⅴ. 의사결정나무(Decision Tree)의 한계와 방안

- 핵심 요약 : 과적합, 높은 분산, 축 정렬 분할의 한계를 가지치기와 앙상블, 특성 변환으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 과적합 | 끝까지 성장한 트리가 노이즈를 학습 → 테스트 성능 급락 | 최대 깊이·최소 분할 샘플 수 제한, 비용-복잡도 **사후 가지치기** (Pruning) | 검증 세트 정확도 |
| 높은 분산 | 샘플 몇 개 변화에도 분할 구조가 바뀜 → 일관성 저하 | **배깅** (Bagging) 기반 랜덤 포레스트, 부스팅 앙상블 적용 | 예측 분산, 교차 검증 편차 |
| 축 정렬 분할의 한계 | 대각선 경계를 계단식 노드로 근사 → 노드 수 증가 | 주성분 분석(PCA, Principal Component Analysis) 등 좌표 회전, 선형 결합 분할 | 트리 깊이, 노드 수 |
| 피처 중요도 편향 | 범주 수가 많은 변수가 과대평가됨 | 순열 중요도(Permutation Importance), SHAP 값 교차 검증 | 중요도 순위 안정성 |

## Ⅵ. 의사결정나무(Decision Tree)의 기술사적 제언

- 핵심 요약 : 해석이 필요한 영역에서는 트리를 설명 도구로 쓰고, 정형 데이터의 예측 성능은 트리 앙상블로 확보하는 방향이 합리적이다.

1. 설명 모델 활용 : 딥러닝 모델의 입출력을 얕은 트리로 근사하는 **대리 모델** (Surrogate Model)을 만들어 고규제 도메인의 판단 규칙을 시각화한다.
2. 정형 데이터 우선 전략 : 이미지나 자연어를 제외한 대부분의 업무 데이터는 **그래디언트 부스팅** (GBDT) 계열을 먼저 검토하고, 신경망은 성능 우위가 입증된 영역에 한정한다.
3. 특성 중요도 검증 체계 : 불순도 기반 중요도 대신 순열 중요도와 SHAP을 함께 보는 검증 절차를 모델 승인 기준에 포함한다.

## Ⅶ. 결론

- 핵심 요약 : 의사결정나무는 규칙으로 설명되는 가장 기본적인 지도학습 모델이다.
- 시사점 : 단일 트리의 한계는 앙상블과 가지치기로 보완하고, 설명 책임이 필요한 업무에서는 트리 규칙을 감사 자료로 남기는 것이 중요하다.
