## 30초 인출

- 본질: **의사결정나무(Decision Tree)** 는 원천 데이터의 특징(Feature) 공간을 if-then 규칙 기반의 계층적 트리 구조로 재귀 분할(Recursive Partitioning)하여 분류와 회귀를 수행하는 대표적 화이트박스 머신러닝 모델
- 메커니즘: 루트 노드에서 시작하여 지니 불순도(Gini) 또는 정보 이득(Information Gain)이 최대화되는 최적 분할 기준을 탐욕적(Greedy)으로 결정하고 리프 노드에서 클래스 다수결 판정
- 통찰: 과도하게 깊은 트리는 훈련 데이터의 노이즈까지 암기하여 과적합을 유발하므로 사전 가지치기(max_depth) 및 비용-복잡도 사후 가지치기(CCP) 결합 필수

<details><summary>핵심 용어</summary>

- **의사결정나무 (Decision Tree)** : 데이터 특징 조건에 따라 이진 분기를 거쳐 최종 예측에 도달하는 계층적 트리 알고리즘 (CART, C4.5, ID3).
- **지니 불순도 (Gini Impurity)** : 집합 내에서 무작위로 선택한 두 항목이 서로 다른 클래스에 속할 확률 (`1 - Σ p_i^2`).
- **엔트로피 (Entropy)** : 데이터 분포의 정보학적 무질서도와 불확실성을 나타내는 지표 (`-Σ p_i log2(p_i)`).
- **정보 이득 (Information Gain)** : 분할 전 부모 노드의 엔트로피에서 분할 후 자식 노드들의 가중 평균 엔트로피를 뺀 불확실성 감소량.
- **가지치기 (Pruning)** : 트리의 최대 깊이(Max Depth)를 제한하거나 불필요한 분기를 제거하여 모델 복잡도를 줄이고 일반화 성능을 향상시키는 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. 의사결정나무의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **의사결정나무(Decision Tree)** 는 다차원 입력 데이터의 특징 공간을 축에 수직인 초평면으로 반복 분할하여 규칙들의 계층적 트리 형태로 표현하는 직관적인 지도학습 분류·회귀 알고리즘 |
| 목적 | 인간이 직관적으로 이해할 수 있는 if-then 규칙 도출, 높은 설명가능성(XAI) 확보 및 비선형 패턴의 효율적 분류 |

## Ⅱ. 의사결정나무의 핵심 특징 및 분할 척도 속성

| 구분 | 핵심 특징 | 세부 공학적 메커니즘 및 속성 |
|---|---|---|
| **화이트박스 모델** | 뛰어난 설명가능성 (Explainability) | 예측이 도출된 경로(Root to Leaf)가 명확하여 의료, 금융, 법률 등 규제 도메인에 최적 |
| **비모수적 모델 (Non-parametric)** | 데이터 분포 가정 불필요 | 데이터의 정규성, 선형성을 가정하지 않으며 특성 스케일링(정규화/표준화) 없이도 정상 작동 |
| **탐욕적 분할 (Greedy)** | 국소 최적 분기 선택 | 현재 단계에서 순수도(Purity)를 가장 크게 개선하는 최선의 분기를 선택하되 전역 최적은 미보장 |
| **고분산 취약성** | 데이터 변동 민감도 | 학습 데이터의 작은 변화에도 트리 구조 전체가 크게 요동치는 불안정성(High Variance) 내포 |

## Ⅲ. 의사결정나무 분할 메커니즘 및 공간 분할 도해

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 의사결정나무 공간 분할 및 트리 구조 매핑 ]            │
└────────────────────────────────────────────────────────────────────────┘
 [ 2차원 특징 공간 분할 ]                      [ 계층적 의사결정 트리 ]
      x2 ▲
         │     R2 (클래스 B)                     [ 루트 노드: x1 <= 50 ? ]
         │┌──────────────────┐                            /        \
         ││                  │                        (Yes)        (No)
      30 ┼┼──────┬───────────┤                        /                \
         ││  R1  │    R3     │             [ x2 <= 30 ? ]        [ 잎 노드: R2 ]
         ││(클래스│(클래스 B) │                /        \           (클래스 B)
         ││  A)  │           │             (Yes)        (No)
         └┴──────┴───────────┴──► x1       /                \
                 50                 [ 잎 노드: R1 ]   [ 잎 노드: R3 ]
                                      (클래스 A)        (클래스 B)
```

| 트리 구성요소 | 역할 및 정의 | 공학적 판정 기준 |
|---|---|---|
| **루트 노드 (Root Node)** | 전체 데이터셋이 위치한 최상위 시작 노드 | 전체 특성 중 정보 이득(Information Gain)이 가장 큰 최적 특성 선택 |
| **내부 노드 (Internal Node)** | 특정 특성의 임계값 조건으로 분기하는 중간 노드 | 자식 노드들의 불순도 가중합을 최소화하는 기준점 선정 |
| **리프 노드 (Leaf Node)** | 더 이상 분기하지 않는 최종 종단 노드 | 최종 분류 클래스 결정(다수결) 또는 연속값 평균 예측 |

## Ⅳ. 주요 불순도 분할 기준 척도 비교

| 비교 항목 | 엔트로피 (Entropy, ID3/C4.5) | 지니 불순도 (Gini, CART) | 분산 감소량 (Variance Reduction) |
|---|---|---|---|
| **적용 과업** | 다중 클래스 분류 | 이진 및 다중 클래스 분류 | 수치 예측 회귀 나무 (Regression Tree) |
| **수학적 공식** | $H(S) = -\sum_{i=1}^c p_i \log_2 p_i$ | $Gini(S) = 1 - \sum_{i=1}^c p_i^2$ | $Var(S) = \frac{1}{N}\sum (y_i - \bar{y})^2$ |
| **연산 복잡도** | 로그($\log_2$) 연산 포함으로 상대적 느림 | 단순 제곱 연산으로 계산 속도 매우 빠름 | 제곱 오차 합산으로 빠름 |
| **특징 및 편향** | 다치 속성(값 종류가 많은 특성) 분할 선호 | 균형 잡힌 이진 분할(Binary Split) 지향 | 분산이 최소화되는 분할점 탐색 |
| **최대 불순도** | 이진 분류 시 1.0 (균등 5:5일 때) | 이진 분류 시 0.5 (균등 5:5일 때) | 데이터 산포도에 따라 가변 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 트리가 제한 없이 깊어질 경우 훈련 데이터의 이상치까지 100% 분할하여 심각한 과적합 발생 | 최대 깊이(max_depth), 최소 리프 샘플(min_samples_leaf)을 제한하는 사전 가지치기 및 비용-복잡도 사후 가지치기(ccp_alpha) 적용 |
| 단일 결정 트리의 구조적 불안정성으로 데이터 사소한 변화에도 예측 편차가 극심 | 여러 개의 트리를 병렬 결합하는 배깅(Random Forest) 및 순차 오차 보정 부스팅(XGBoost, LightGBM)으로 앙상블 확장 |

## Ⅵ. 제언

단일 트리의 과적합을 방지하고 설명가능성과 예측 정확도를 동시에 확보하기 위해, 비용-복잡도 가지치기(Cost-Complexity Pruning) 기반의 최적 트리 정밀화 파이프라인 구축.

```text
[ 완전 성장 트리 (Fully-Grown Tree) 생성 ]
                   │
                   ▼
[ 사후 가지치기 파이프라인 (Cost-Complexity Pruning) ]
   ├── Step 1: 비용 복잡도 함수 R_α(T) = R(T) + α|T| 정의
   ├── Step 2: α (Alpha) 파라미터 변화에 따른 부분 트리 시퀀스 생성
   └── Step 3: 5-Fold 교차검증을 통한 검증 점수 최고점 α* 도출
                   │
                   ▼
[ 최적 가지치기 완료 트리 확정 및 비즈니스 XAI 룰셋 배포 ]
```

| 구분 | 무제한 성장 트리 (Overfitted) | 제언: 비용-복잡도 가지치기 적용 트리 |
|---|---|---|
| **트리 깊이** | 깊이 20 이상 (노이즈까지 잎 노드 생성) | 깊이 4~5 내외의 핵심 분기만 유지 |
| **일반화 성능** | 훈련 100%, 테스트 65% (심각한 격차) | 훈련 92%, 테스트 90% (안정적 일반화) |
| **해석 용이성** | 수백 개 규칙으로 인간 해석 불가능 | 10개 내외의 명료한 if-then 비즈니스 규칙 추출 |
