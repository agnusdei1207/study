## 답안 골격
```text
[의사결정나무] ◀━━ 머리: Ⅶ 내 의견 (사전/사후 가지치기 기반 과적합 방지와 XAI 설명 가능 모델로서의 활용)
 ┃
 ┣━ Ⅰ 개요 ───── 블랙박스 모델의 설명 난해성 극복 → if-then 규칙 기반의 직관적 계층 트리 분류/회귀
 ┣━ Ⅱ 특징 ───── 뛰어난 설명가능성(White-box) · 스케일링 불필요 · 비선형 관계 분할 · 과적합 취약성
 ┣━ Ⅲ 구조 ───── 뿌리 노드(Root) + 중간 노드(Internal) + 잎 노드(Leaf) + 가지(Branch) + 불순도 지표
 ┣━ Ⅳ 흐름 ───── ① 최적 분할 변수 탐색 → ② 불순도 감소 최대화 분기 → ③ 재귀적 트리 분할 → ④ 가지치기(Pruning)
 ┣━ Ⅴ 비교 ───── CART(지니 계수, 이진트리) vs C4.5(정보이득비, 다지분할) vs ID3(정보이득, 범주형)
 ┗━ Ⅵ 실무 ───── 트리 깊이 증가에 따른 과적합 / 축에 평행한(Axis-aligned) 분할 한계 / 데이터 변동 민감도
```
- 필수 키워드: 지니 계수(Gini Index) · 엔트로피(Entropy) · 정보 획득량 · CART · C4.5 · 가지치기(Pruning) · 화이트박스
- 기출: 126회 `엔트로피 지수와 지니 지수 비교` → Ⅲ·Ⅴ, 130회 `의사결정나무와 앙상블 비교` → Ⅰ·Ⅴ

## 한 줄 본질
- 복잡한 다변량 함수 추론의 설명력 부재 해결 → 데이터의 불순도(Impurity)를 가장 크게 낮추는 질문을 재귀적으로 던져 트리 구조로 공간 분할 → 직관적 규칙 해석(XAI) 달성 / 트리가 깊어질수록 학습 데이터에 극단적으로 과적합

## 핵심 그림
```text
[의사결정나무 계층 구조 및 분할 원리]
                    [ Root Node: 소득 > 5천만원? ]
                           /              \
                    (Yes) /                \ (No)
                         v                  v
       [ Internal Node: 부채비율 < 30%? ]   [ Leaf Node: 대출 거절 ]
                 /              \
          (Yes) /                \ (No)
               v                  v
     [ Leaf: 대출 승인 ]     [ Leaf: 심사 보류 ]
```

## 핵심 용어
- 지니 불순도(Gini Impurity): $1 - \sum p_i^2$. 특정 노드에서 무작위로 선택된 샘플이 잘못 분류될 확률을 측정하며, CART 알고리즘의 기본 분할 기준
- 정보 이득(Information Gain): 부모 노드의 엔트로피에서 자식 노드들의 가중 평균 엔트로피를 뺀 값으로, 불순도가 얼마나 크게 감소했는지를 나타내는 척도
- 가지치기(Pruning): 트리의 깊이가 과도해져 발생하는 과적합을 방지하기 위해 불필요하거나 중요도가 낮은 하위 서브트리를 제거하는 기법

## 핵심 통찰
- 의사결정나무는 입력 변수의 스케일에 영향을 전혀 받지 않으므로, 정규화(Standardization)나 이상치 제거 같은 사전 처리가 필요 없음
- 단일 나무(Single Tree)는 데이터의 미세한 변화에도 트리 구조 전체가 뒤흔들리는 높은 분산(High Variance) 불안정성을 지님
- 이러한 단일 나무의 약점을 극복하기 위해 다수의 나무를 투표(Voting)로 결합한 것이 랜덤 포레스트(Random Forest) 앙상블 기법

## 이웃 토픽과 구분
- 의사결정나무 vs 랜덤 포레스트: 의사결정나무는 단일 모델로 해석력이 극대화되나 과적합에 취약 / 랜덤 포레스트는 다수의 나무를 배깅(Bagging)해 일반화 성능을 극대화하나 해석력(블랙박스화) 희생

## 문제·원인·대책
- 적용 상황: 신용카드 발급 심사 의사결정나무 모델의 과적합 및 일반화 오류
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 트리가 리프 노드 샘플 1개까지 분기(과적합) | 분기 종료 조건(Stopping Criteria) 부재 | 최대 깊이(max_depth) 제한 및 최소 샘플 분할(min_samples_split) 설정 | 트리 크기 억제 및 사전 가지치기(Pre-pruning) 달성 |
| 사후 일반화 검증 성능 저하 | 훈련셋 노이즈까지 반영된 복잡한 가지 구조 | 비용-복잡도 가지치기(ccp_alpha, Cost-Complexity Pruning) 적용 | 검증 손실을 최소화하는 최적 서브트리 보존 |
| 대각선 형태의 선형 데이터 분할 실패 | 특성 축에 평행하게만 직사각형으로 영역 분할 | PCA(주성분 분석)를 통한 축 회전 또는 특성 간 결합 변수 생성 | 다차원 비선형 경계면에 대한 표현력 보완 |

## 이렇게 출제된다
- 제126회 1교시: "의사결정나무의 불순도 측정 지표인 엔트로피 지수(Entropy Index)와 지니 지수(Gini Index)를 비교 설명하시오." → 요구 포인트: Ⅲ 불순도 개념 + Ⅴ 지표별 수식 및 특성 비교
- 제130회 2교시: "의사결정나무(Decision Tree)의 분할 기준과 가지치기(Pruning) 기법을 설명하시오." → 요구 포인트: Ⅳ 분할 절차 + 사전/사후 가지치기 기법

## 내 의견
- [설명 가능성(XAI)이 절대적인 규제 도메인의 1차 기준 모델 활용] 딥러닝이나 부스팅이 성능은 뛰어나나 금융·의료 현장에서는 거절 사유를 명시적으로 설명할 의무가 존재함 → 나라면: 감사 보고서 제출 및 고객 통보가 필요한 규제 영역에는 사전 가지치기가 엄격히 적용된 CART 의사결정나무를 베이스라인으로 적용해 완벽한 법적 설명권 보장
