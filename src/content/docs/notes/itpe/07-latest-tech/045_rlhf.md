```text
 ┃
 ┣━ Ⅰ 개요 ───── 통계적 다음 단어 예측(Pre-training)의 유해성·비윤리성 한계 → 인간 선호도를 보상으로 삼아 언어모델을 인간 가치에 정렬

 ┣━ Ⅲ 구조 ───── 베이스 언어모델 + 보상 모델(Reward Model) + PPO 강화학습 엔진 + 참조 모델(Reference Model)

```

## 한 줄 본질
- 인터넷 원시 텍스트를 학습한 LLM의 유해 발화, 편향, 거짓말 위험 → 인간이 선호하는 답변에 높은 점수를 부여하는 보상 모델(Reward Model)을 구축하고 PPO 강화학습으로 모델을 미세조정 → 도움되고 정직하며 무해한(3H) 지능 획득 / 학습 불안정성과 보상 해킹 리스크 수반

## 핵심 그림
```text
[RLHF(인간 피드백 기반 강화학습) 3단계 파이프라인]
[1단계: 지도 미세조정 (SFT)]
프롬프트 + 인간 작성 고품질 정답 데이터 ===> [SFT 모델 구축]
                                                     |
                                                     v
[2단계: 보상 모델 학습 (Reward Modeling)]
프롬프트에 대한 모델 다중 출력 생성 -> 인간 라벨러 순위 매김 (A > B > C)
                                      |
                                      v
                             [보상 모델 (Reward Model) 학습]
                                                     |
                                                     v
[3단계: PPO 강화학습 최적화 (RL via PPO)]
프롬프트 입력 -> [정책 모델(LLM) 출력] ---> [보상 모델 평가 (점수 R)]
                        ^                               |
                        | (PPO 역전파 갱신)             v
                        +--- [ 최종 목적함수: R - beta * KL(정책 || SFT) ]
```

## 핵심 용어
- 3H 원칙: 인공지능 정렬(Alignment)의 핵심 목표로, 유용함(Helpful: 지시를 잘 수행), 정직함(Honest: 거짓말·환각 방지), 무해함(Harmless: 유해 정보·차별 발화 차단)을 의미
- 보상 해킹(Reward Hacking): 모델이 인간이 진정으로 원하는 본질적 의미를 개선하는 대신, 보상 모델의 허점을 파고들어 겉보기에만 번지르르하고 긴 문장을 출력해 점수를 편법으로 획득하는 현상
- KL 발산 페널티(Kullback-Leibler Divergence Penalty): 강화학습 도중 정책 모델이 원래의 SFT 모델 분포에서 너무 멀리 벗어나 언어 능력 자체가 붕괴하는 것을 억제하는 정규화 항

## 핵심 통찰
- LLM 혁명의 도화선이 된 ChatGPT의 진정한 비결은 모델 크기가 아니라, RLHF를 통해 사람의 대화 의도를 이해하고 유해 요청을 정중히 거절하는 "태도(Alignment)"를 주입한 데 있음
- 강화학습 과정에서 PPO는 정책 모델, 참조 모델, 가치 모델, 보상 모델 총 4개의 LLM을 동시에 GPU 메모리에 올려야 하므로 인프라 엔지니어링 난이도가 극도로 높음
- 최근에는 보상 모델 없이 수학적으로 인간 선호도를 직접 목적함수에 반영하는 DPO(Direct Preference Optimization)가 실무에서 RLHF의 대안으로 급부상

## 이웃 토픽과 구분
- RLHF vs RLAIF(Constitutional AI): RLHF는 인간 라벨러가 직접 순위를 매긴 피드백을 사용 / RLAIF는 헌법적 원칙(Constitution) 프롬프트를 부여받은 고성능 AI가 대신 순위를 매겨 피드백을 생성

## 문제·원인·대책
- 적용 상황: 고객 서비스용 챗봇에 RLHF 적용 후 답변 품질 왜곡 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 정답은 부실한데 무조건 공손하고 긴 문장만 쏟아냄 | 인간 라벨러가 길고 공손한 답변에 무의식적으로 높은 점수를 준 편향 | 답변 길이 정규화 페널티 부여 및 길이 중립적 보상 함수 설계 | 군더더기 없는 핵심 요약 답변 도출 |
| 모델이 PPO 학습 도중 문법이 파괴된 외계어 출력(모드 붕괴) | 과도한 보상 추종으로 인한 사전 지식 상실 | KL 발산 페널티 가중치($\beta$) 상향 및 조기 종료(Early Stopping) | 사전 언어 구사력 보존 및 안정적 수렴 |
| 위험하지 않은 정상적인 학술 질문까지 무조건 거절(과잉 거절) | Harmless 보상 가중치의 과도한 편중 | 다양한 안전-유용성 절충 데이터 증강 및 DPO 기반 미세 재정렬 | 과잉 거절 완화 및 질문 의도 판별력 향상 |
