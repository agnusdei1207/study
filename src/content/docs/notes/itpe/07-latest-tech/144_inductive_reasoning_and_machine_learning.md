## 2~4교시 25점 답안

## Ⅰ. 귀납적 추론과 머신러닝의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **귀납적 추론과 머신러닝은** 유한한 학습 사례에서 예측 규칙을 선택해 새로운 입력으로 일반화하는 학습 원리 |
| 목적 | 관측 자료의 패턴을 이용해 미관측 사례의 예측 가능성 확보 |

## Ⅱ. 귀납적 편향에서 일반화 평가까지의 구조

```text
가설 공간 + 귀납적 편향(모델 구조·제약)
                 │ 후보 규칙의 범위 결정
                 ▼
훈련 자료 ── 손실 최소화 ── 선택된 모델
                                │ 미관측 사례 예측
                                ▼
                      독립 검증·분포 변화 평가
                                └─ 실패 유형 → 가설 공간·제약 재설계
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 문제 설정 | 예측 대상과 자료 분포 정의 | 잘못된 목표 변수 |
| 가설 공간 | 모델 구조·특성·제약 선택 | 과도한 자유도 또는 표현 부족 |
| 학습 | 훈련 손실을 기준으로 가설 선택 | 훈련 자료 과적합 |
| 평가 | 독립 자료와 분포 변화에서 일반화 확인 | 자료 누수·평가 편향 |

## Ⅲ. 가설 제약 강도에 따른 일반화 비교

| 구분 | 차이 | 적용 판단 |
|---|---|---|
| 약한 제약 | 복잡한 관계 표현 가능 | 작은 자료에서 과적합 위험 |
| 강한 제약 | 표본 효율과 해석 가능성 향상 가능 | 필요한 관계를 표현하지 못할 위험 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 훈련 손실 감소를 일반화 성능의 증거로 오해 | 자료 분할·교차검증과 운영 자료의 분포 변화 점검 |

## Ⅴ. 제언

가설 공간 선택 전에 배포 대상의 분포와 검증 분할 기준을 확정하고 훈련·검증 성능 차이를 추적.
