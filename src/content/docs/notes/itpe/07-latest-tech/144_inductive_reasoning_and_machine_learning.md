## 한 줄 본질
- 기계학습은 유한한 관측 데이터로 가설을 선택하여 새 사례에 일반화하는 귀납적 과정. 모델의 구조와 학습 기준에는 어떤 형태로든 귀납적 편향이 반영됨

## 핵심 용어
- 톰 미첼의 귀납적 편향 정리(Mitchell's Theorem): "학습기가 사전에 어떠한 편향(가정)도 가지고 있지 않다면, 관측되지 않은 새로운 데이터를 관측된 훈련 데이터보다 더 잘 예측할 수 있는 합리적인 근거가 전혀 존재하지 않는다"
- 제약 편향(Restriction Bias): 모델이 탐색할 수 있는 가설 공간($\mathcal{H}$)의 형태 자체를 미리 제한하는 것(예: "오직 1차 직선만 찾겠다", "국소 픽셀만 보는 CNN 구조만 쓰겠다")
- 선호 편향(Preference Bias): 가설 공간 내에서 특정 성질을 가진 가설을 더 우선시하는 것(예: 오컴의 면도날에 따라 "오차는 비슷하다면 더 단순하고 가중치가 작은 모델을 고르겠다")

## 핵심 통찰
- "전통 프로그래밍과 기계학습의 수학적 역전": 전통 프로그래밍은 `데이터 + 규칙 = 결과`의 연역적 패러다임이지만, 기계학습은 `데이터 + 결과 = 규칙`을 스스로 뽑아내는 귀납적 패러다임임
- 딥러닝 아키텍처는 사실 '귀납적 편향의 디자인': CNN은 이미지의 '이동 불변성(Translation Invariance)'이라는 편향을 넣은 것이고, RNN/트랜스포머는 '시퀀스 순서와 주의 집중'이라는 편향을 넣은 것이며, GNN은 '그래프 치환 불변성'을 넣은 것임
- 일반화 평가: 훈련 오차만 낮추기보다 보지 않은 데이터에서의 오류를 측정. 정규화·데이터 증강·교차검증 등의 필요성은 데이터 규모와 모델에 따라 판단

## 이웃 토픽과 구분
- 연역적 지식 기반 시스템(Expert System) vs 귀납적 기계학습: 전문가 시스템은 인간의 if-then 규칙을 그대로 실행하여 확정적 결론 도출 / 기계학습은 데이터 통계로부터 함수를 근사하여 확률적 예측 수행

## 1교시 예상문제 (10점)

## 1교시 10점 답안
- **귀납적 추론:** 유한한 훈련 사례에서 보지 않은 입력에 적용할 규칙·함수를 학습하는 과정.
- **귀납적 편향:** 가능한 가설 중 일부를 우선하거나 제한하는 모델 구조·특징·정규화 등의 가정.
- **검증:** 훈련 적합도만으로 일반화가 보장되지 않으므로 독립 데이터와 분포 변화에서 평가.

## 2~4교시 예상문제 (25점)
- 가설 공간과 귀납적 편향이 머신러닝의 일반화에 미치는 영향을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 학습의 성격
- 관측 사례에 맞는 가설을 탐색하고 미관측 사례의 결과를 추정하는 귀납적 과정.
### Ⅱ. 가설 공간
- 선형 모델·트리·신경망 등 함수 집합과 특징 표현이 학습 가능한 패턴의 범위 설정.
### Ⅲ. 귀납적 편향
- 모델 구조, 규제, 손실 함수, 데이터 증강이 선택을 유도. 편향이 과하면 과소적합, 제약이 부족하면 과적합 가능.
### Ⅳ. 실무 검증
- 데이터 분리·교차검증·외부 검증, 분포 이동과 공정성 평가로 일반화 가정의 범위 확인.
