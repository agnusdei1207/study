## 30초 인출

- 본질: **멀티모달 AI(Multimodal AI)** 는 텍스트, 이미지, 음성, 비디오 등 서로 다른 이종(Heterogeneous) 데이터 양식(Modality)을 공통 잠재 공간에 투영하여 상호 정렬·융합하고 종합적으로 이해·생성하는 인공지능 기술
- 메커니즘: 모달리티별 인코더(ViT, Whisper, BERT) 특징 추출 → 크로스 어텐션(Cross-Attention) 및 대조 학습(CLIP/InfoNCE) 기반 잠재 공간 정렬 → 융합 추론 및 다감각 출력 생성
- 통찰: 특정 모달리티에 편향되어 환각(Hallucination)이 발생하는 모달리티 붕괴 위험이 존재하므로 모달리티 드롭아웃과 시각 선호도 정렬(RLHF-V) 결합 필수

<details><summary>핵심 용어</summary>

- **멀티모달 AI** : 2개 이상의 서로 다른 데이터 모달리티를 동시에 수용하여 교차 추론과 생성을 수행하는 인공지능.
- **교차 모달 정렬(Cross-Modal Alignment)** : 텍스트와 이미지 등 이종 데이터 간의 의미적 대응 관계를 공통 벡터 공간 상에 가깝게 배치하는 학습 기법.
- **CLIP(Contrastive Language-Image Pre-training)** : 수억 쌍의 이미지-텍스트 쌍을 대조 학습(Contrastive Learning)으로 정렬하여 제로샷 분류를 지원하는 모델.
- **Q-Former(Querying Transformer)** : 가변 길이의 시각 특징을 고정된 개수의 학습 가능한 쿼리 토큰으로 압축하여 언어모델에 전달하는 가교 어댑터.
- **시각적 환각(Visual Hallucination)** : 멀티모달 모델이 입력 이미지에 실재하지 않는 객체나 속성을 언어적 사전 편향에 의해 그럴듯하게 잘못 서술하는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 멀티모달(Multimodal AI)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **멀티모달 AI(Multimodal AI)** 는 텍스트, 시각(이미지/비디오), 청각(음성/오디오), 센서 데이터 등 서로 다른 이종 모달리티를 통합 인코딩하여 상호 연관성을 추론하고 생성하는 인공지능 |
| 목적 | 단일 모달리티(Unimodal)의 정보 표현 한계 극복, 인간과 유사한 다감각적 물리 세계 인지(Embodied AI) 및 고신뢰 복합 태스크 자동화 |

## Ⅱ. 멀티모달 AI의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **표현 통합성** | 공통 잠재 공간 (Joint Latent Space) | 텍스트 임베딩과 이미지 패치 임베딩을 동일 차원의 벡터 공간에 매핑하여 코사인 유사도로 상호 비교 |
| **상호 전이성** | 제로샷 교차 전이 (Cross-Modal Transfer)| 텍스트로만 학습된 지식을 시각적 이미지 분류에 즉시 적용하거나 음성 질의에 비전 검색으로 응답 |
| **융합 유연성** | 계층별 융합 파이프라인 | 입력단(Early), 특징단(Cross-Attention), 의사결정단(Late) 중 과업 특성에 최적화된 결합 시점 선택 |
| **통일 토큰화** | 통합 시퀀스 표현 (Any-to-Any) | 이미지를 16x16 패치 토큰으로, 오디오를 스펙트로그램 토큰으로 변환하여 트랜스포머 단일 백본 처리 |

## Ⅲ. 멀티모달 융합 아키텍처 및 3대 결합 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 멀티모달 3대 정보 융합 아키텍처 및 처리 체계 ]                │
└────────────────────────────────────────────────────────────────────────┘
 [ 텍스트 입력 ]                [ 이미지 입력 ]                [ 오디오 입력 ]
        │                              │                              │
        ├──────────────────────────────┼──────────────────────────────┤
        ▼ (원시 결합: Concatenation)   ▼                              ▼
 ┌────────────────────────────────────────────────────────────────────────┐
 │ 1. 조기 융합 (Early Fusion): 초기 다감각 원시 토큰 통합 임베딩           │
 └─────────────────────────────────────┬──────────────────────────────────┘
                                       ▼
        ┌──────────────────────────────────────────────────────┐
        │ 2. 중간 융합 (Intermediate / Cross-Attention Fusion)  │
        │   - ViT 비전 인코더  ──(Q-Former / Cross-Attn)──┐    │
        │   - LLM 언어 백본    ◄───────────────────────────┘    │
        └──────────────────────────────┬───────────────────────┘
                                       ▼
        ┌──────────────────────────────────────────────────────┐
        │ 3. 후기 융합 (Late Fusion): 개별 모달리티 판정 후 앙상블 │
        │   - Text 분류기 + Vision 분류기 가중 합산 / Voting     │
        └──────────────────────────────┬───────────────────────┘
                                       ▼
                       [ 복합 상황 인지 및 멀티모달 생성 ]
```

| 융합 단계 | 결합 위치 및 주요 기법 | 장단점 및 특징 |
|---|---|---|
| **조기 융합 (Early)** | 입력 레이어에서 직접 연결 | 모달리티 간 저수준 상호작용 탁월하나 차원 불일치 정렬 난항 |
| **중간 융합 (Intermediate)** | 트랜스포머 내부 Cross-Attention | 고수준 의미 교환 최적, 현대 LMM(GPT-4o, LLaVA)의 표준 |
| **후기 융합 (Late)** | 개별 모델의 최종 출력 확률 결합 | 개별 유니모달 모델 재사용 용이하나 모달리티 간 시너지 제한 |

## Ⅳ. 조기 융합, 중간(Cross-Attention) 융합, 후기 융합 비교

| 비교 항목 | 조기 융합 (Early Fusion) | 중간 융합 (Cross-Attention) | 후기 융합 (Late Fusion) |
|---|---|---|---|
| **융합 시점** | 모델 입력 단계 (원시 특징 레벨) | 모델 내부 은닉 계층 (특징 맵 레벨) | 모델 출력 단계 (결정/확률 레벨) |
| **상호작용 표현력** | 저수준 상관관계 포착 우수 | 고수준 의미적 상관관계 극대화 | 모달리티 간 상호작용 거의 없음 |
| **모델 결합도** | 단일 통합 모델 필수 | 어댑터(Q-Former) 기반 유연 결합 | 개별 독립 모델 앙상블 |
| **연산 복잡도** | 시퀀스 길이 증가로 연산량 급증 | 어텐션 프로젝션으로 연산 최적화 | 개별 모델 추론 연산 합산 |
| **데이터 동기화** | 엄격한 시간/위치 동기화 요구 | 부분적 비동기 허용 | 동기화 요구 낮음 |
| **대표 모델** | ImageBind, Gato | LLaVA, Flamingo, BLIP-2 | 멀티모달 앙상블 감성분석 시스템 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 텍스트 데이터의 압도적 학습량으로 인해 이미지를 잘못 보고도 언어적 사전 편향만으로 거짓을 서술하는 시각적 환각(Visual Hallucination) 발생 | DPO(Direct Preference Optimization)를 시각 정렬에 적용한 RLHF-V 파이프라인 구축 및 세부 바운딩 박스를 좌표로 출력하는 비주얼 그라운딩 강제화 |
| 고해상도 이미지(4K)나 긴 비디오 입력 시 패치 토큰 수가 수천 개로 폭증하여 LLM 컨텍스트 윈도우와 메모리를 잠식 | Q-Former, Perceiver Resampler 등 압축 어댑터를 적용하여 수천 개의 비전 패치를 32~64개의 핵심 시맨틱 쿼리 토큰으로 압축 |
| 학습 데이터셋 내 특정 모달리티의 품질 저하 시 모델 전체 성능이 함께 붕괴되는 모달리티 의존 편향 발생 | 훈련 중 무작위로 특정 모달리티 입력을 차단하는 모달리티 드롭아웃(Modality Dropout) 기법을 적용하여 단독 모달리티 강건성 확보 |

## Ⅵ. 제언

Q-Former 기반 시각 토큰 압축 어댑터와 시각 선호도 정렬(RLHF-V)을 결합하여 환각을 억제하는 고신뢰 멀티모달 LMM 파운데이션 아키텍처 구축.

```text
[ 고해상도 멀티모달 입력 (이미지 + 텍스트) ]
                     │
                     ├──────────────────────────┐
                     ▼                          ▼
     [ ViT 비전 인코더 (2048 패치) ]     [ 텍스트 인스트럭션 ]
                     │                          │
                     ▼                          │
     [ Q-Former 토큰 압축 어댑터 ]               │
     (32개 핵심 시맨틱 토큰으로 압축)             │
                     │                          │
                     └─────────────┬────────────┘
                                   ▼
          [ 파운데이션 LLM 백본 (Cross-Attention 융합) ]
                                   │
                                   ▼
          [ RLHF-V / DPO 시각 선호도 정렬 게이트웨이 ]
          (이미지 사실성 검증 및 텍스트 환각 필터링)
                                   │
                                   ▼
              [ 객체 위치 기반 고신뢰 멀티모달 응답 ]
```

| 구분 | 레거시 단순 프로젝션 LMM | 제언: Q-Former + RLHF-V 정렬 LMM |
|---|---|---|
| **토큰 효율성** | 이미지당 수천 토큰 소모로 OOM | 32개 쿼리 토큰으로 90% 이상 절감 |
| **시각 환각률** | 존재하지 않는 사물 언급 빈발 | DPO 시각 정렬을 통해 환각 80% 감축 |
| **추론 속도** | 긴 시퀀스로 인한 지연 발생 | 경량 어댑터 기반으로 실시간 스트리밍 |
