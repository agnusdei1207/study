## 30초 인출

- 본질: **Transformer**는 어텐션으로 입력 요소 간 관계를 계산하는 신경망 구조
- 메커니즘: 토큰 표현 → Q·K 유사도와 V 가중 결합 → 피드포워드 변환

<details>
<summary>핵심 용어</summary>

- **Transformer** : 어텐션과 위치 표현을 이용해 입력 시퀀스의 관계를 처리하는 신경망 구조
- **셀프 어텐션(Self-Attention)** : 한 시퀀스 안의 각 요소가 다른 요소의 정보를 가중 결합하는 연산
- **Q·K·V(Query, Key, Value)** : Query는 현재 조회 표현, Key는 비교 표현, Value는 가중 결합할 정보 표현
- **멀티헤드 어텐션(Multi-Head Attention)** : 여러 어텐션 계산 결과를 병렬로 결합하는 구조
- **위치 인코딩(Positional Encoding)** : 토큰 순서 정보를 표현에 반영하는 방법
- **전문가 혼합(Mixture of Experts, MoE)** : 라우터가 입력에 따라 일부 전문가 모듈을 선택하는 모델 구조
- **조건부 희소성(Conditional Sparsity)** : 입력마다 일부 모듈만 활성화하는 계산 특성

</details>

## 1교시 10점 답안

### Ⅰ. Transformer의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **Transformer**는 어텐션으로 입력 요소 간 관계를 계산하는 신경망 구조 |
| 목적 | 순환 계산 없이 시퀀스 문맥을 학습하고 과제별 표현을 구성 |

### Ⅱ. 셀프 어텐션

```text
입력 표현 X
    │ 선형 변환
    ├── Q(Query) · K(Key) 비교
    │       │ 점수 정규화
    │       ▼
    └── V(Value) 가중 결합
            │
            ▼
       문맥 표현 생성
```

셀프 어텐션은 `softmax(QKᵀ/√dₖ)V`로 표현하며, 점수는 각 Query가 Key를 얼마나 참조할지 계산.

### Ⅲ. 핵심 구성

| 구성 | 역할 |
|---|---|
| 위치 정보 | 순서·위치 정보 반영 |
| 멀티헤드 어텐션 | 서로 다른 관계 표현을 병렬 계산 |
| 피드포워드·잔차·정규화 | 표현 변환과 학습 안정화 지원 |

**제언:** 구조와 계산 특성을 과제의 시퀀스 길이·품질·자원 조건에 맞춰 평가하는 설계.

## 2~4교시 25점 답안

### Ⅰ. Transformer의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **Transformer**는 어텐션으로 입력 요소 간 관계를 계산하는 신경망 구조 |
| 목적 | 순환 계산 없이 시퀀스 문맥을 학습하고 과제별 표현을 구성 |

### Ⅱ. 주요 구성요소

| 구성 | 역할 |
|---|---|
| 토큰 임베딩 | 입력 토큰을 벡터로 표현 |
| 위치 표현 | 토큰 순서·위치 반영 |
| 인코더·디코더 | 입력 표현과 출력 생성 기능 구성 |
| 멀티헤드 어텐션 | 여러 관계의 문맥 표현 계산 |
| 피드포워드·잔차·정규화 | 표현 변환과 학습 안정화 지원 |

```text
토큰·위치 표현
      │
멀티헤드 어텐션
      │ 잔차 연결·정규화
피드포워드 변환
      │ 잔차 연결·정규화
문맥 표현 또는 다음 토큰 점수
```

### Ⅲ. 셀프 어텐션 계산

```text
입력 표현 X
    │ 선형 변환
    ├── Q(Query) · K(Key) 비교
    │       │ 점수 정규화
    │       ▼
    └── V(Value) 가중 결합
            │
            ▼
       문맥 표현 생성
```

각 토큰의 Query와 모든 Key를 비교해 가중치를 구하고, 그 가중치로 Value를 합산. 여러 헤드의 출력을 결합해 다음 계층에 전달.

### Ⅳ. 계산 특성과 기술사적 제언

| 한계·특성 | 대응 방향 |
|---|---|
| 표준 전역 어텐션의 점수 행렬은 시퀀스 길이에 따라 계산량·메모리가 대체로 제곱 규모로 증가 | 실제 입력 길이·하드웨어에서 정확도·지연·메모리를 측정하고 전체·희소·메모리 효율 방식 선택 |
| 메모리 효율 커널은 중간 저장을 줄일 수 있으나 기본 전역 어텐션의 상호작용 구조와 계산 복잡도가 자동으로 선형화되지는 않음 | 모델·커널별 구현 조건을 분리해 벤치마크하고 배포 규모에서 검증 |
