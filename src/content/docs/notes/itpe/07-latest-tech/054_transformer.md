## Ⅰ. 트랜스포머(Transformer)의 개요

- 핵심 요약 : 순차 처리를 배제하고 모든 토큰 간 관계를 병렬로 계산하는 셀프 어텐션 기반의 신경망 구조.
- 개념 : 순환 구조를 버리고 입력 시퀀스 안의 모든 토큰이 서로를 동시에 참조하는 **셀프 어텐션** (Self-Attention) 메커니즘을 핵심으로 설계된 신경망 아키텍처 (**트랜스포머** (Transformer)).
- 배경 및 필요성 : **순환 신경망** (RNN, Recurrent Neural Network)은 이전 시점의 은닉 상태를 순서대로 넘겨받아 병렬 학습이 어렵고, 문장이 길어질수록 초기 정보가 소실되는 장기 의존성 문제가 컸음. 이 한계를 어텐션 중심 구조로 해결하는 방향이 2017년 구글 연구진의 "Attention Is All You Need" 논문으로 제시됨.
- 주요 목적 : 시퀀스의 전역 문맥 모델링, GPU 분산 병렬 학습 효율 극대화, 자연어 처리를 넘어 비전과 로봇 제어까지 단일 백본으로 통합.

## Ⅱ. 트랜스포머(Transformer)의 특징 및 장점

- 핵심 요약 : 병렬 어텐션과 위치 정보 주입이 전역 문맥 처리와 대규모 병렬 학습이라는 장점으로 연결되는 구조.

1. **Query, Key, Value** : 입력을 세 벡터로 투영하여 질의와 대상의 유사도를 계산 → 유사도를 가중치로 내용을 합산해 문맥 표현 생성.
2. **스케일드 닷 프로덕트 어텐션** (Scaled Dot-Product Attention) : 내적 값을 차원 크기의 제곱근으로 나눠 소프트맥스의 기울기 소실을 방지 → 안정적 학습.
3. **멀티헤드 어텐션** (MHA, Multi-Head Attention) : 여러 헤드가 서로 다른 표현 공간을 병렬로 학습 → 문법, 의미, 수식 관계를 동시에 포착.
4. **위치 인코딩** (Positional Encoding) : 순차 처리가 없으므로 토큰의 순서 정보를 주입 → 병렬 처리를 유지하면서 어순 인식 가능.

## Ⅲ. 트랜스포머(Transformer)의 구조 (흐름)

- 핵심 요약 : 어텐션 블록과 피드포워드 블록을 잔차 연결로 쌓은 구조이며, 어텐션 내부는 Q, K, V의 가중 합으로 계산되는 흐름.

```text
[ 트랜스포머 인코더 블록의 흐름 ]

입력 토큰 + 위치 인코딩
          ↓
멀티헤드 셀프 어텐션
          ↓
잔차 연결 + 정규화
          ↓
피드포워드 네트워크
          ↓
잔차 연결 + 정규화
```

- **잔차 연결** (Residual Connection) : 입력을 하위 층의 출력에 더해 깊은 층의 학습 안정화.
- **층 정규화** (Layer Normalization) : 층마다 값의 분포를 고르게 맞춰 학습 수렴을 돕는 정규화 기법.

```text
[ 스케일드 닷 프로덕트 어텐션 계산 ]

입력 X → Q = X·W_Q, K = X·W_K, V = X·W_V
          ↓
유사도 S = Q·K^T / sqrt(d_k)
          ↓
가중치 A = Softmax(S + 마스크)
          ↓
출력 = A·V (문맥 표현)
```

## Ⅳ. 인코더-디코더, 인코더 전용, 디코더 전용의 비교

- 핵심 요약 : 세 계열은 어텐션 마스킹과 학습 목표가 달라 용도가 갈리며, 생성형 AI는 디코더 전용 구조로 수렴함.

| 비교 항목 | 인코더-디코더 (T5 계열) | 인코더 전용 (BERT 계열) | 디코더 전용 (GPT, Llama 계열) |
| --- | --- | --- | --- |
| 어텐션 마스킹 | 인코더는 양방향, 디코더는 인과 마스크 | 모든 토큰 간 양방향 어텐션 | 미래 토큰을 가리는 **인과 마스크** (Causal Mask) |
| 주요 학습 목표 | 입력을 출력으로 변환하는 시퀀스 변환 (번역, 요약) | **마스크드 언어 모델** (MLM, Masked Language Model) | 다음 토큰 예측 (Next-Token Prediction) |
| 장점 | 입력과 출력이 다른 변환 작업에 최적화 | 문맥 전체에 대한 양방향 이해 | 자유로운 생성, 인컨텍스트 학습 |
| 단점 | 구조가 복합적이어서 서빙 복잡도 증가 | 텍스트 생성에 부적합 | 이전 토큰만 참조하는 단방향 제약 |
| 대표 모델 | T5, BART | BERT, RoBERTa | GPT 계열, Llama 계열, Claude, DeepSeek-V3 |

- 현대 생성형 AI는 구조가 단순하고 확장성(Scaling Law)이 뛰어난 **디코더 전용 구조** (Decoder-only)로 수렴함.

## Ⅴ. 트랜스포머(Transformer)의 한계와 방안

- 핵심 요약 : 길이에 따른 연산 폭증, 추론 시 캐시 대역폭 병목, 학습 길이를 넘는 위치 외삽 문제를 연산 최적화와 압축 어텐션, 위치 임베딩 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 시퀀스 길이에 따른 O(N²) 연산·메모리 폭증 | 컨텍스트가 길어질수록 어텐션 행렬이 급증 → GPU 메모리 고갈 | 고대역폭 메모리 접근을 줄이는 **FlashAttention** 적용, 긴 문맥을 나눠 처리하는 RingAttention | 처리 지연 시간, 메모리 사용량 |
| 추론 시 KV 캐시 대역폭 병목 | 생성된 토큰의 Key, Value를 캐싱 → 동시 사용자가 많을 때 메모리 대역폭 고갈 | **그룹 쿼리 어텐션** (GQA, Grouped-Query Attention), **잠재 어텐션** (MLA, Multi-head Latent Attention) 같은 압축 어텐션 채택 | 토큰당 캐시 크기, 처리량 |
| 위치 외삽의 한계 | 학습된 길이를 넘는 입력에서 어텐션 품질이 급락 | 복소수 회전을 이용한 **RoPE** (Rotary Position Embedding)와 주파수 보간 기법(YaRN) 적용 | 학습 길이 밖 질의의 성능 저하율 |

## Ⅵ. 트랜스포머(Transformer)에 대한 기술사적 제언

- 핵심 요약 : 커널 수준의 연산 최적화, 캐시 효율을 고려한 모델 선정, 멀티모달 통합을 기반 전략으로 삼아 트랜스포머를 장기 운영 자산으로 관리.

1. 학습과 서빙 인프라를 설계할 때 FlashAttention과 같은 커널 최적화를 기본 구성으로 두고, 하드웨어 메모리 계층을 고려하는 소프트웨어 스택을 함께 갖추는 것이 실용적이다.
2. 긴 컨텍스트 서비스가 늘어나는 조직은 KV 캐시 효율을 모델 선정 기준에 포함하여, 같은 장비에서 더 많은 동시 요청을 처리하도록 설계하는 것이 바람직하다.
3. 텍스트 토큰과 시각 패치 토큰을 하나의 트랜스포머에서 처리하는 멀티모달 통합 방향은 비전과 로봇 제어를 아우르는 단일 기반 모델 전략으로 검토할 가치가 있다.

## Ⅶ. 결론

- 핵심 요약 : 셀프 어텐션을 병렬로 확장한 트랜스포머는 현대 생성형 AI의 공통 백본으로 자리 잡은 구조.
- 시사점 : 아키텍처 자체보다 어텐션 연산의 메모리 효율과 서빙 최적화가 다음 경쟁 지점이 되는 흐름.
