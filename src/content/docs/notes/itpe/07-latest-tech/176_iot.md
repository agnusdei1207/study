## 연관 키워드

- 사물인터넷(IoT, Internet of Things), 센서(Sensor), 액추에이터(Actuator)
- MQTT, CoAP, DTLS, 저전력 광역망(LPWAN), PSM, eDRX
- 신뢰 루트(RoT, Root of Trust), 경량 암호, PUF, FOTA, A/B 듀얼 뱅크
- 지수 백오프(Exponential Backoff), 멱등성(Idempotency), 벽돌화(Bricking)

## Ⅰ. 사물인터넷의 개요

- 핵심 요약 : 센서와 액추에이터를 네트워크로 연결해 데이터를 공유하고 자율 제어를 수행하는 지능형 인프라.
- 개념 : 유무선 통신망으로 연결된 사물들이 **센서** (Sensor, 물리량을 전기 신호로 바꾸는 장치)와 **액추에이터** (Actuator, 전기 신호를 기계적 동작으로 바꾸는 장치)를 통해 데이터를 주고받고, 클라우드와 엣지 플랫폼을 연계해 인지와 제어를 수행하는 **사물인터넷** (IoT, Internet of Things) 인프라.
- 배경 및 필요성 : 대규모 단말이 늘면서 배터리 소모와 보안 취약점이 병목이 되므로, **신뢰 루트** (RoT, Root of Trust, 기기 신뢰의 출발점이 되는 하드웨어 보안 요소)와 **저전력 절전 모드** (PSM, Power Saving Mode)를 결합한 기기 생애주기 관리가 필수.
- 주요 목적 : 실시간 원격 상태 감시, 분산 자산 관리, 공정 최적화, 스마트홈·스마트시티·스마트팩토리 같은 융합 서비스 제공.

## Ⅱ. 사물인터넷의 특징 및 장점

- 핵심 요약 : 계층별 역할 분담과 경량 프로토콜이 저전력 장기 운영과 대규모 연결을 가능하게 하는 구조.

1. 계층 분리 : 디바이스, 네트워크, 플랫폼, 서비스 계층으로 나눔 → 단말을 바꾸지 않고 상위 서비스를 확장.
2. 경량 메시지 프로토콜 : **MQTT** (Message Queuing Telemetry Transport, 발행·구독 기반 경량 메시지 프로토콜), **CoAP** (Constrained Application Protocol, 제약 장치용 웹 전송 프로토콜) 활용 → 적은 대역폭과 전력으로 데이터 전송.
3. 저전력 광역망 : **저전력 광역망** (LPWAN, Low-Power Wide-Area Network, 낮은 전력으로 장거리 통신하는 무선망) 활용 → 배터리 기기의 장기 운용.
4. 하드웨어 보안 부팅 : 신뢰 칩 기반 부팅 검증 → 위조 기기와 악성 코드 실행 차단.

## Ⅲ. 사물인터넷의 구조 (흐름)

- 핵심 요약 : 디바이스에서 네트워크와 플랫폼을 거쳐 서비스까지 올라가는 4계층 구조와 데이터 흐름의 이중 구조.

```text
[ IoT 4계층 구조 (하위 → 상위) ]

서비스 계층
  (스마트 팩토리·헬스케어·에너지 관리)
      ↑
플랫폼 계층
  (데이터 수집·브로커·시계열 저장)
      ↑
네트워크 계층
  (LPWAN·셀룰러·Wi-Fi)
      ↑
디바이스 계층
  (센서·액추에이터·저전력 칩)
```

```text
[ 데이터 흐름 경로 ]

센서 계측 (물리 신호 → 디지털 값)
      ↓
게이트웨이 (프로토콜 변환·압축)
      ↓
브로커 (발행·구독 중계)
      ↓
스트림 저장 및 분석
      ↓
임계치 초과 시 이벤트 알림
```

- 디바이스 계층 : 센서와 저전력 칩이 신호를 샘플링하고, 보안 칩이 부팅 시점의 무결성을 확인.
- 네트워크 계층 : NB-IoT(Narrowband Internet of Things), LoRaWAN, 6LoWPAN(IPv6 over Low-Power Wireless Personal Area Networks) 등으로 패킷을 압축하고 저전력 라우팅을 수행.
- 플랫폼 계층 : 메시지 브로커, 시계열 데이터베이스, 디바이스 관리와 **FOTA** (Firmware Over-the-Air, 무선으로 펌웨어를 원격 갱신하는 기술) 기능을 담당.
- 서비스 계층 : 규칙 엔진, 시각화 대시보드, ML(Machine Learning) 추론 엔진을 통해 분석 결과를 전달하고 원격 명령을 하달.

## Ⅳ. MQTT와 CoAP의 비교

- 핵심 요약 : 지속 연결과 신뢰 전송을 우선하는 MQTT와 비연결형 경량 요청·응답을 우선하는 CoAP가 용도별로 나뉘는 구조.

| 비교 축 | MQTT (Message Queuing Telemetry Transport) | CoAP (Constrained Application Protocol) |
| --- | --- | --- |
| 전송 계층 | TCP (Transmission Control Protocol) | UDP (User Datagram Protocol) |
| 통신 구조 | 발행·구독 방식, 중앙 브로커 중계 | 클라이언트·서버 요청·응답, P2P(Peer-to-Peer) 지원 |
| 헤더 크기 | 최소 2바이트 | 고정 4바이트 (옵션 필드에 따라 가변) |
| 서비스 품질 | QoS 0(최대 1회), QoS 1(최소 1회), QoS 2(정확히 1회) | 확인 메시지(Confirmable)와 비확인 메시지(Non-Confirmable) |
| 상태 관리 | 연결 지향 (Keep-Alive로 세션 유지) | 비연결형 (무상태 트랜잭션) |
| 보안 | TLS(Transport Layer Security) 기반 암호화 | DTLS(Datagram Transport Layer Security) 기반 암호화 |
| 주요 적용 | 지속적 상태 스트리밍, 대규모 데이터 모니터링 | 초저전력 배터리 노드, 간헐적 보고와 직접 제어 |

- 선택 기준 : 연결 유지 비용, 메시지 신뢰성 요구, 단말 전력 예산을 기준으로 두 프로토콜 중 하나를 고르고, 혼합 구성도 검토.

## Ⅴ. 사물인터넷의 한계와 방안

- 핵심 요약 : 배터리 소진, 암호 연산 부재, 펌웨어 무결성 실패를 절전 설계, 경량 암호, 이중 뱅크 갱신으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 배터리 조기 소진 | 잦은 폴링과 무선 송수신 유지로 배터리가 빨리 소모되어 현장 교체 부담 증가 | 3GPP 표준 PSM과 **eDRX** (extended Discontinuous Reception, 수신 대기 주기를 늘려 절전하는 기능) 파라미터 최적화, 임계치 초과 시에만 전송하는 이벤트 기반 구동 | 단말당 배터리 수명, 전송 횟수 |
| 암호 연산 부재 | 단말의 연산과 메모리 제약으로 RSA(Rivest-Shamir-Adleman) 같은 무거운 암호를 쓸 수 없어 패킷 노출 위험 | **경량 암호** (Lightweight Cryptography, 연산과 메모리가 제한된 기기용 암호 알고리즘) 적용, 국내 표준 경량 암호 LEA(Lightweight Encryption Algorithm)와 HIGHT, 경량 해시 LSH(Lightweight Secure Hash) 도입, 칩 고유 특성을 이용하는 **PUF** (Physically Unclonable Function) 내장 보안 칩 채택 | 암호 적용 단말 비율 |
| 펌웨어 업데이트 실패와 변조 | 배포 중 패킷 유실로 단말이 동작하지 않는 벽돌화(Bricking)와 악성 펌웨어 주입 위험 | **A/B 듀얼 뱅크** (두 펌웨어 영역을 번갈아 쓰는 구조)로 실패 시 자동 복원, ECDSA(Elliptic Curve Digital Signature Algorithm) 전자 서명 검증 후 설치 | 업데이트 실패율, 서명 검증 실패 건수 |

## Ⅵ. 사물인터넷에 대한 기술사적 제언

- 핵심 요약 : 저전력 설계, 재접속 부하 제어, 메시지 중복 처리를 표준 요건으로 두는 운영 체계가 신뢰성을 좌우.

배터리 교체 비용을 줄이려면 제품 기획 단계에서 보고 주기별 전력 예산을 계산하고, 단일 배터리로 목표 수명을 보장하는 설계 기준을 두어야 한다.

기지국 단절 후 기기들이 동시에 재접속을 시도하면 네트워크가 과부하되므로, 재시도 간격을 점차 늘리는 **지수 백오프** (Exponential Backoff)와 무작위 지연을 기본 펌웨어 기능으로 넣는 것이 바람직하다.

QoS 1 이상에서는 같은 메시지가 두 번 도착할 수 있으므로, 메시지 ID 기반 중복 제거로 **멱등성** (Idempotency, 같은 요청을 여러 번 처리해도 결과가 같은 성질)을 확보해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 사물인터넷은 경량 통신, 저전력 설계, 하드웨어 보안을 결합한 대규모 연결 인프라.
- 시사점 : 연결 대수보다 단말 수명과 업데이트 무결성을 관리하는 역량이 장기 운영의 성패를 결정.
