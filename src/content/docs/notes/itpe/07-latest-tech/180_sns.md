 ┣━ Ⅰ 개요 ───── 온라인 공간에서 사용자 간의 인맥(Social Graph) 형성과 정보 공유, 상호작용을 매개하는 웹 2.0 기반의 대표적 소셜 미디어 플랫폼

 ┗━ Ⅵ 실무 ───── 확증 편향 및 필터 버블(Filter Bubble) / 악성 가짜뉴스 유포 / 플랫폼 독점에 따른 사용자 데이터 및 팔로워 락인(Lock-in)

## 한 줄 본질
- 사람들 사이의 친구 관계와 관심사를 컴퓨터 거미줄(소셜 그래프)로 엮어, 내가 좋아할 만한 글과 숏폼 영상을 끝없이 추천하며 전 세계 사람들을 6단계 안에 연결하는 디지털 광장

## 핵심 용어
- 소셜 그래프(Social Graph): SNS 상에서 개인(노드)들과 그들 간의 친구, 팔로우, 좋아요 등 사회적 관계(엣지)를 수학적 네트워크 그래프로 표현한 모델
- 좁은 세상 효과(Small-World Phenomenon): 임의의 두 사람이 몇 단계(평균 6단계 미만)의 인맥만 거치면 모두 서로 연결될 수 있다는 사회 연결망의 고밀도 클러스터링 특성
- 페디버스(Fediverse): Federation(연합)과 Universe(우주)의 합성어로, 단일 기업이 통제하지 않고 ActivityPub 표준 통신 규약을 통해 서로 다른 수천 개의 독립 서버들이 자유롭게 소통하는 탈중앙 SNS 연합체

## 핵심 통찰
- "소셜 그래프에서 엔터테인먼트 그래프로의 패러다임 이동": 페이스북처럼 '내가 아는 사람(친구)'의 소식을 보던 시대는 가고, 틱톡처럼 알고리즘이 '내가 좋아할 만한 전 세계 낯선 이의 숏폼'을 배달하는 관심사 기반 AI 피드로 대전환
- 도파민 루프와 필터 버블(Filter Bubble): 사용자의 체류 시간(Watch Time)을 극대화하려는 추천 알고리즘이 자극적인 콘텐츠와 한쪽으로 치우친 정치적 확증 편향을 강화하는 부작용 야기
- 탈중앙화 프로토콜(ActivityPub / AT Protocol)의 부상: 트위터 인수 사태 이후 계정 영구 삭제나 일방적 정책 변경을 피하기 위해, 이메일처럼 서버가 달라도 서로 팔로우할 수 있는 오픈 소셜 웹 표준이 각광받음

## 이웃 토픽과 구분
- 커뮤니티(게시판) vs SNS: 커뮤니티는 특정 주제 게시판 중심의 익명 비동기 글타래 / SNS는 '개인 프로필(Identity)'과 '친구/팔로우 관계망(Social Graph)'을 중심으로 피드가 동적으로 생성되는 사용자 중심 네트워크

## 문제·원인·대책
- 적용 상황: 수억 건의 실시간 피드가 쏟아지는 글로벌 SNS 플랫폼 피드 배포 인프라
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 유명 인플루언서(팔로워 5,000만 명)가 글 작성 시 팬아웃(Fan-out) 부하로 서버 마비 | 모든 팔로워의 피드 수신함에 글을 복제해 넣는 쓰기 시점 팬아웃(Fan-out-on-write) 병목 | 하이브리드 팬아웃 적용 (일반 유저는 쓰기 시 팬아웃, 슈퍼스타는 읽기 시 팬아웃 풀링) | 피크 타임 DB 쓰기 부하 85% 절감 |
| 자극적인 가짜뉴스와 혐오 발언이 피드 상위에 노출되어 사회적 물의 | 체류 시간(Engagement)에만 과도한 가중치를 둔 추천 모델의 결함 | 팩트체크 외부 신뢰도 점수 반영 및 비자발적 공유 패턴 다운랭킹(Down-ranking) 패널티 | 유해 가짜뉴스 확산율 70% 차단 |
| 플랫폼 정책 변경 시 크리에이터가 축적한 팔로워 네트워크를 잃어버릴 위험 | 빅테크 플랫폼의 폐쇄적 데이터 독점 및 종속(Lock-in) | ActivityPub 프로토콜 지원 및 탈중앙 계정 이동(DID 기반 데이터 이식) 기능 제공 | 크리에이터 데이터 주권 및 이식성 보장 |
