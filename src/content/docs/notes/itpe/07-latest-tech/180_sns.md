## 답안 골격
### 1교시 예상문제 (10점)
SNS의 핵심 구성과 소셜 그래프·피드 랭킹의 역할을 설명하시오.

### 1교시 10점 답안
- **정의:** 개인 프로필과 관계망을 중심으로 게시·공유·대화를 지원하는 온라인 서비스.
- **구성:** 이용자·관계 그래프 → 게시물 수집·배포 → 후보 생성·랭킹 → 노출·상호작용.
- **구분:** ActivityPub 기반 연합과 AT Protocol 기반 연합은 별도 규약이며 계정·게시물 이전 범위는 구현과 정책에 종속.

### 2~4교시 예상문제 (25점)
대규모 SNS 피드의 배포·추천 구조와 유해정보·이식성 위험의 대응 방안을 설명하시오.

### 2~4교시 25점 답안
1. **피드 구성:** 그래프·관심사로 후보 생성 → 관련성·안전성·다양성 랭킹 → 접근 권한 검사 → 피드 제공.
2. **배포:** 일반 계정은 쓰기 시 팬아웃, 대형 계정은 읽기 시 팬아웃 등 게시량·구독자 수에 따른 혼합 전략.
3. **위험:** 악성 정보 증폭, 필터 버블, 허위 계정, 계정·관계망 잠금과 이용자 데이터 오남용.
4. **통제:** 게시물 검증·신고·이의 제기, 추천 다양성, 관계·게시물 내보내기와 이전 시험, 노출·오탐·지연의 측정.

```text
 ┃
 ┣━ Ⅰ 개요 ───── 온라인 공간에서 사용자 간의 인맥(Social Graph) 형성과 정보 공유, 상호작용을 매개하는 웹 2.0 기반의 대표적 소셜 미디어 플랫폼
 ┣━ Ⅱ 이론기반 ─ 좁은 세상 효과(Small World) · 6단계 분리 법칙 · 약한 유대의 힘(Granovetter) · 멱함수 분포(Power-Law/척도 없는 네트워크)
 ┣━ Ⅲ 구조 ───── 사용자 프로파일 + 소셜 그래프(친구/팔로우 관계) + 피드 인제스트 및 랭킹 엔진 + 실시간 메시징(WebSocket) + 광고/커머스 엔진
 ┣━ Ⅳ 피드추천 ─ 후보 생성(그래프·협업 필터링) → 다목적 랭킹(관련성·안전성·다양성) → 사용자 피드백 반영
 ┣━ Ⅴ 비교 ───── 1세대 관계형 SNS(페이스북) vs 2세대 관심사/숏폼 SNS(인스타그램, 틱톡) vs 3세대 탈중앙 SNS(마스토돈, 블루스카이)
 ┗━ Ⅵ 실무 ───── 확증 편향 및 필터 버블(Filter Bubble) / 악성 가짜뉴스 유포 / 플랫폼 독점에 따른 사용자 데이터 및 팔로워 락인(Lock-in)
```
- 필수 키워드: SNS · 소셜 그래프(Social Graph) · 좁은 세상(Small World) · 척도 없는 네트워크(Scale-Free) · 피드 랭킹 알고리즘 · 페디버스(Fediverse) · ActivityPub · AT Protocol
- 출제 이력: 93회·99회 공식 문제지 원문 미대조. 해당 회차의 실제 문항·표현 미확인

## 핵심 용어
- 소셜 그래프(Social Graph): SNS 상에서 개인(노드)들과 그들 간의 친구, 팔로우, 좋아요 등 사회적 관계(엣지)를 수학적 네트워크 그래프로 표현한 모델
- 좁은 세상 효과(Small-World Phenomenon): 일부 네트워크에서 군집성과 짧은 평균 경로가 함께 나타나는 특성. '6단계'는 모든 SNS의 보편적 경로 길이가 아닌 연구·비유의 맥락
- 페디버스(Fediverse): Federation(연합)과 Universe(우주)의 합성어로, 단일 기업이 통제하지 않고 ActivityPub 표준 통신 규약을 통해 서로 다른 수천 개의 독립 서버들이 자유롭게 소통하는 탈중앙 SNS 연합체

## 핵심 통찰
- "소셜 그래프에서 엔터테인먼트 그래프로의 패러다임 이동": 페이스북처럼 '내가 아는 사람(친구)'의 소식을 보던 시대는 가고, 틱톡처럼 알고리즘이 '내가 좋아할 만한 전 세계 낯선 이의 숏폼'을 배달하는 관심사 기반 AI 피드로 대전환
- 도파민 루프와 필터 버블(Filter Bubble): 사용자의 체류 시간(Watch Time)을 극대화하려는 추천 알고리즘이 자극적인 콘텐츠와 한쪽으로 치우친 정치적 확증 편향을 강화하는 부작용 야기
- 연합형 소셜 프로토콜: ActivityPub과 AT Protocol은 다른 연합 모델이며, 서버 간 상호작용·계정 이동의 실제 범위는 각 규약과 구현별 확인 대상

## 이웃 토픽과 구분
- 커뮤니티(게시판) vs SNS: 커뮤니티는 특정 주제 게시판 중심의 익명 비동기 글타래 / SNS는 '개인 프로필(Identity)'과 '친구/팔로우 관계망(Social Graph)'을 중심으로 피드가 동적으로 생성되는 사용자 중심 네트워크

## 문제·원인·대책
- 적용 상황: 수억 건의 실시간 피드가 쏟아지는 글로벌 SNS 플랫폼 피드 배포 인프라
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 유명 계정의 게시 시 팬아웃 부하 급증 | 모든 팔로워의 수신함에 복제하는 쓰기 시점 팬아웃 | 일반 계정은 쓰기 시점, 대형 계정은 읽기 시점 팬아웃을 조합하고 부하 시험 | 피크 쓰기량·피드 지연 측정 |
| 유해 게시물이 상위에 노출 | 참여도에 치우친 랭킹과 검수 한계 | 신고·검증·랭킹 제한·이의 제기 절차 병행 | 유해 노출률과 오탐률 측정 |
| 계정 이전 시 관계·게시물 손실 | 서비스별 상이한 신원·데이터 모델 | 지원 프로토콜의 계정 이동·내보내기 범위 확인 및 이전 시험 | 이전 가능한 데이터 범위와 실패율 확인 |
