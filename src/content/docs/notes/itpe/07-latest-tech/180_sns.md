## 30초 인출

- 본질: 개인 프로필과 관계망을 중심으로 게시·공유·대화를 지원하는 온라인 서비스. 관계망을 통한 게시·공유·대화 지원.
- 메커니즘: 프로필·관계망 → 게시물 수집 → 배포·랭킹 → 권한 검사·노출.
- 통찰: 한계: 관계망만 따라 일괄 복제하면 대형 계정의 게시 시 팬아웃 부하가 폭증한다 → 방안: 계정 규모에 따라 쓰기·읽기 시점 배포를 나누고 피드 지연을 측정한다.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 개인 프로필과 관계망을 중심으로 게시·공유·대화를 지원하는 온라인 서비스. |
| 목적 | 관계망을 통한 게시·공유·대화 지원 |

## Ⅱ. 관계망 기반 피드 배포

```text
게시물 + 팔로우 그래프
       ├─ 일반 계정 → 쓰기 시점 팬아웃
       └─ 대형 계정 → 읽기 시점 후보 조회
                     ↓ 권한·랭킹 검사
                   이용자 피드 노출
```

1. **피드 구성:** 그래프·관심사로 후보 생성 → 관련성·안전성·다양성 랭킹 → 접근 권한 검사 → 피드 제공.
2. **배포:** 일반 계정은 쓰기 시 팬아웃, 대형 계정은 읽기 시 팬아웃 등 게시량·구독자 수에 따른 혼합 전략.
3. **위험:** 악성 정보 증폭, 필터 버블, 허위 계정, 계정·관계망 잠금과 이용자 데이터 오남용.
4. **통제:** 게시물 검증·신고·이의 제기, 추천 다양성, 관계·게시물 내보내기와 이전 시험, 노출·오탐·지연의 측정.

## Ⅲ. 게시판과 관계망 피드

| 구분 | 게시판 | SNS 피드 |
|---|---|---|
| 조직 축 | 주제·글타래 | 개인 프로필·관계 그래프 |
| 전달 방식 | 주제별 조회 | 팔로우 관계와 랭킹에 따른 배포 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 유명 계정의 게시 시 팬아웃 부하 급증 — 모든 팔로워의 수신함에 복제하는 쓰기 시점 팬아웃 | 일반 계정은 쓰기 시점, 대형 계정은 읽기 시점 팬아웃을 조합하고 부하 시험 |
| 유해 게시물이 상위에 노출 — 참여도에 치우친 랭킹과 검수 한계 | 신고·검증·랭킹 제한·이의 제기 절차 병행 |
| 계정 이전 시 관계·게시물 손실 — 서비스별 상이한 신원·데이터 모델 | 지원 프로토콜의 계정 이동·내보내기 범위 확인 및 이전 시험 |

## Ⅴ. 제언

- [상호운용성 기반 이전 정책] 계정·팔로워·게시물의 이전 가능 범위를 사용 프로토콜과 서버 구현별로 명시하고, 내보내기와 복원 시험 및 동의·권한 관리 병행
