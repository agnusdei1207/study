## 30초 인출

- 본질: **딥페이크(Deepfake)** 는 오토인코더(Autoencoder), GAN 및 확산 모델(Diffusion)을 활용하여 특정 인물의 얼굴 표정, 음성, 신체 동작을 정교하게 합성·변조하는 딥러닝 기반 미디어 위조 기술
- 메커니즘: 인코더를 통한 잠재 공간 얼굴 특징 추출 후 타깃 인코더-디코더 매핑으로 픽셀 및 주파수를 합성하고, 탐지 측면에서는 rPPG 생체 신호 및 C2PA 출처 검증 수행
- 통찰: 생성 모델의 비약적 진화로 시각적 아티팩트 기반 탐지가 무력화되고 있으므로 능동적 암호학 워터마크(C2PA)와 실시간 라이브니스(Liveness) 검증 결합 필수

<details><summary>핵심 용어</summary>

- **딥페이크 (Deepfake)** : 딥러닝(Deep Learning)과 가짜(Fake)의 합성어로, 고도의 사실성을 가진 가짜 영상·음성을 생성하는 기술.
- **rPPG (remote Photoplethysmography)** : 안면 피부 표면의 미세한 색상 변화를 비접촉식으로 감지하여 심장 박동 등 생체 신호 진위를 판별하는 기술.
- **C2PA (Coalition for Content Provenance and Authenticity)** : 미디어 생성·편집 시 암호화 서명된 메타데이터(출처 및 변경 이력)를 삽입하는 글로벌 표준 규격.
- **라이브니스 탐지 (Liveness Detection)** : 영상 속 인물이 사전 녹화본이나 가면이 아닌 실제 살아있는 생체인지를 판별하는 챌린지-응답 검증 기법.
- **보이지 않는 워터마크 (Invisible Watermark)** : 인간의 눈에는 보이지 않으나 디코더 알고리즘으로 모델 정보와 생성 주체를 입증하는 암호학적 신호 (SynthID 등).

</details>

## 2~4교시 25점 답안

## Ⅰ. 딥페이크의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **딥페이크(Deepfake)** 는 딥러닝 기반의 오토인코더, GAN, 확산 모델 등을 이용하여 특정 인물의 안면, 표정, 제스처, 목소리를 정밀하게 추출·합성하여 실제와 구별하기 어려운 가짜 미디어를 제작하는 기술 |
| 목적 | 엔터테인먼트, 가상 인간(Virtual Human), 교육 콘텐츠 제작 등 긍정적 활용 및 사이버 사기, 여론 조작, 명예훼손 등 역기능 대응 통제 |

## Ⅱ. 딥페이크의 핵심 특징 및 공격 벡터 속성

| 구분 | 핵심 특징 | 세부 공학적 속성 |
|---|---|---|
| **초고정밀 사실성** | 인간 인지 한계 초월 | 4K/8K 초고해상도 얼굴 디테일, 미세 표정 주름, 입술 움직임(Lip-sync)의 완벽한 동기화 |
| **적은 데이터 적응** | Zero-Shot / Few-Shot 합성 | 단 몇 장의 사진이나 3초 분량의 음성 샘플만으로 타깃 인물의 음색과 안면 특징 복제 가능 |
| **실시간 스트리밍** | 런타임 화상 사칭 | GPU 연산 가속을 통해 줌, 영상통화 등 실시간 비디오 스트림에서 실시간 안면 변환 수행 |
| **사회적 파급력** | 피싱(CEO Fraud) 및 여론 왜곡 | 최고경영자 사칭을 통한 거액 송금 유도, 선거철 가짜뉴스 유포 등 사회적 신뢰 붕괴 초래 |

## Ⅲ. 딥페이크 생성 메커니즘 및 다계층 탐지·대응 아키텍처

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 딥페이크 생성 및 능동/수동 탐지 아키텍처 ]             │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 1. 딥페이크 생성 파이프라인 ]      │  [ 2. 다계층 탐지 및 검증 파이프라인 ]
 원본 소스 A (표정) + 타깃 B (외모)   │  인입된 미디어 스트림 (Video/Audio)
        │                           │              │
        ▼                           │              ▼
 [ 잠재 공간(Latent) 특징 사상 ]    │  [ 1계층: 생체 신호 분석 (rPPG) ]
 - 공통 인코더 ──> 타깃 디코더 합성  │   - 안면 미세 혈류 박동 및 안구 깜빡임 검증
        │                           │              │
        ▼                           │              ▼
 [ 픽셀 융합 및 포아송 블렌딩 ]      │  [ 2계층: 주파수/아티팩트 분석 ]
        │                           │   - FFT(고속 푸리에 변환) 기반 고주파 왜곡 탐지
        ▼                           │              │
 [ 초사실적 딥페이크 영상 출력 ] ───┼─────────────►▼
                                    │  [ 3계층: 암호학 출처 검증 (C2PA) ]
                                    │   - 매니페스트 디지털 서명 및 카메라 원본 검증
                                    │              │
                                    │              ▼
                                    │  [ 종합 진위 판정 및 자동 차단 게이트 ]
```

| 파이프라인 단계 | 핵심 공학 기술 | 주요 역할 및 판별 원리 |
|---|---|---|
| **안면 특징 추출** | Dlib, MediaPipe 안면 랜드마크 68개 포인트 | 눈, 코, 입 윤곽의 공간 좌표 및 포즈 추정 |
| **잠재 특징 변환** | Shared Encoder - Target Decoder 구조 | 소스의 표정과 움직임을 타깃의 외형 잠재 벡터에 합성 |
| **생체 신호 판별** | rPPG (원격 광용적맥파 측정) | 진짜 인간 피부의 주기적 헤모글로빈 흡수율 변화 추정 |
| **암호학 출처 증명** | C2PA Content Credentials 매니페스트 | 촬영-편집-배포의 전 생애주기 해시 서명 체인 검증 |

## Ⅳ. 딥페이크 탐지 기법 비교

| 비교 항목 | 생체 신호 기반 (rPPG / Eye-blink) | 주파수/AI 탐지 기반 (FFT / CNN) | 암호학적 출처 기반 (C2PA) |
|---|---|---|---|
| **접근 방식** | 수동적 탐지 (생물학적 불일치 포착) | 수동적 탐지 (수학적·통계적 흔적 포착) | 능동적 검증 (콘텐츠 계보 서명 확인) |
| **주요 대상** | 심장 박동(맥파), 불규칙 눈 깜빡임 | 생성 모델 특유의 업샘플링 격자 노이즈 | 촬영 기기 및 편집 소프트웨어 서명 |
| **위조 적응력** | 생성 모델이 혈류 신호까지 모사 시 취약 | 신규 생성 모델 등장 시 탐지율 급락 | 메타데이터 삭제 시 검증 불능 |
| **연산 비용** | 영상 프레임 시계열 분석으로 중간 | 딥러닝 추론으로 상대적 높음 | 공개키 암호 검증으로 극히 빠름 |
| **적합한 환경** | 금융권 비대면 실명 인증, 영상 면접 | SNS 업로드 영상 자동 필터링 | 뉴스 언론 보도, 법적 증거물 채택 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 생성 모델의 품질 향상으로 사람의 육안은 물론 단일 AI 판별 모델의 정확도가 급격히 하락 | 영상 FFT 주파수 분석, rPPG 맥박 감지, 음성 위조 탐지를 앙상블한 멀티모달 진위 판정 체계 구축 |
| 온라인 플랫폼 재인코딩(압축, 해상도 저하) 시 C2PA 메타데이터가 손실되거나 삭제되는 취약점 | 메타데이터 방식과 더불어 영상 압축에도 강건한 잠재 공간 비가시적 워터마크(Invisible Watermark) 기술 병행 |

## Ⅵ. 제언

사후 탐지에만 의존하는 수동적 방어의 한계를 극복하기 위해, 콘텐츠 생성 시점의 워터마크 삽입과 금융권 본인 확인 시 챌린지-응답 라이브니스 인증을 결합한 3중 신뢰 검증망 구축.

```text
[ 비대면 금융 거래 요청 ]
           │
           ▼
[ 능동적 챌린지-응답 라이브니스 (Liveness) 검증 ]
   ├── Step 1: 무작위 지시 수행 ("오른쪽으로 고개를 돌리며 숫자 7을 말하세요")
   ├── Step 2: 3D 심도(ToF) 센서 및 rPPG 생체 신호 일치도 검증
   └── Step 3: 실시간 오디오-비디오 립싱크 타이밍 정밀 대조
           │
           ▼ (통과 시)
[ 안전한 금융 트랜잭션 승인 및 위조 시도 원천 차단 ]
```

| 구분 | 단순 사진/신분증 제출 방식 | 제언: 능동적 다중 생체 인증 체계 |
|---|---|---|
| **위조 방어** | 고화질 딥페이크 영상으로 통과 가능 | 무작위 동적 챌린지로 사전 녹화 영상 완전 무력화 |
| **생체 확인** | 정적인 2D 이미지 기반 판정 | ToF 3D 깊이 정보 및 맥박 헤모글로빈 동시 감지 |
| **출처 보증** | 출처 위변조 확인 불가 | C2PA 기반 촬영 단말기 보안 하드웨어 서명 검증 |
