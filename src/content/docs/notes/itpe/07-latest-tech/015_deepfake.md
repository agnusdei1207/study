<summary>핵심 용어</summary>

- **딥페이크(Deepfake)** : 딥러닝 기반 기법으로 사람의 얼굴·음성 등 미디어를 합성·변형한 콘텐츠
- **생성적 적대 신경망(Generative Adversarial Network, GAN)** : 생성기와 판별기를 경쟁적으로 학습시키는 생성 모델 구조
- **원격 광용적맥파(remote Photoplethysmography, rPPG)** : 영상의 미세한 피부색 변화로 맥박 등 생체 신호를 추정하는 방법
- **C2PA(Content Credentials)** : 디지털 콘텐츠의 생성·편집 이력 등 출처 정보를 서명된 매니페스트로 기록·검증하는 규격; 콘텐츠의 사실 여부를 보증하지는 않음
- **라이브니스 탐지(Liveness Detection)** : 인증 대상이 실제로 현재 상호작용 중인지를 확인하는 생체 인증 절차

### Ⅱ. 생성과 확인의 기본 구조

```text
사람의 얼굴·음성 자료
          ↓ 학습·특징 추출
생성 모델의 합성·변환
          ↓
합성 미디어
          ↓ 진위 확인
생체·시각 단서 + 출처 이력
          ↓
증거 종합·추가 확인
```

### Ⅲ. 확인 단서

| 단서 | 확인 대상 |
|---|---|
| 생체·시간 | 얼굴 움직임·음성과 화면의 시간 일관성 |
| 합성 흔적 | 경계·질감·주파수 등 생성 과정의 흔적 |
| 출처 정보 | 메타데이터와 **C2PA(Content Credentials)** 매니페스트 검증 |

제언: 자동 탐지 결과를 단독 판정으로 삼지 않고 생체·출처 정보를 교차 확인하는 절차.

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|

| 목적 | 미디어 생성·변형의 활용과 진위 확인에 필요한 기술적 관점 파악 |

### Ⅱ. 생성과 확인의 기본 구조

```text
사람의 얼굴·음성 자료
          ↓ 학습·특징 추출
생성 모델의 합성·변환
          ↓
합성 미디어
          ↓ 진위 확인
생체·시각 단서 + 출처 이력
          ↓
증거 종합·추가 확인
```

### Ⅲ. 생성 방식과 결과

| 접근 | 핵심 작동 | 결과 예 |
|---|---|---|
| 얼굴 교체 | 대상 얼굴 특징을 영상 프레임에 합성 | 얼굴·표정 변환 |
| 음성 합성 | 화자 음성 특징으로 발화 생성·변환 | 특정인 음성처럼 들리는 콘텐츠 |
| 생성형 모델 | 학습된 분포를 바탕으로 미디어 생성 | 실제 장면처럼 보이는 합성 미디어 |

### Ⅳ. 탐지 한계와 다층 대응

| 한계 | 대응 |
|---|---|
| 생성 기법 변화로 특정 아티팩트에 의존한 탐지가 약해질 수 있음 | 서로 다른 생체·시각 단서를 결합하고 새로운 생성 유형으로 평가 |
| **C2PA(Content Credentials)** 출처 정보만으로 내용의 사실 여부를 판단할 수 없음 | 매니페스트의 서명·이력을 검증하고 별도 사실 확인과 함께 해석 |
| 본인 사칭이 인증·거래로 이어질 수 있음 | 라이브니스 확인과 별도 채널 승인 등 거래 통제 적용 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 단일 탐지 점수만으로 인증·게시 여부를 자동 결정하면 오탐·우회 위험을 통제하기 어려움 | 사용 맥락별 증거 기준을 정하고, 불확실하거나 영향이 큰 경우 사람의 재확인 절차로 이관 |
