## 30초 인출

- **본질:** 명시한 원칙에 따라 AI가 답변을 비판·수정하고 선호 평가를 생성해 학습에 활용하는 정렬 방식
- **메커니즘:** 원칙 기반 답변 비판·수정의 지도학습 → AI 선호 평가·보상 모델·강화학습
- **답안 초점:** Constitutional AI의 두 학습 단계와 RLAIF의 역할을 설명하시오.

<details><summary>핵심 용어</summary>

- **Constitutional AI:** 명시한 원칙으로 AI의 답변 비판·수정과 선호 평가를 학습에 활용하는 방식
- **RLAIF:** 사람 대신 AI가 생성한 선호 피드백을 강화학습에 활용하는 방법

</details>

## 1교시 10점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 명시한 원칙으로 AI의 비판·수정·선호 평가를 학습에 활용하는 정렬 방식 |
| 목적 | 유해 응답 평가 부담 완화와 원칙의 명문화 |

- **1단계:** 초기 답변 생성 → 원칙에 따른 비판·수정 → 수정 답변으로 지도 미세조정.
- **2단계:** 원칙을 참고한 AI의 선호 비교 → 보상 모델 학습 → 강화학습. 원 논문의 RLAIF 과정과 DPO 같은 별도 선호 최적화 알고리즘 구별.

## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 명시한 원칙으로 AI의 비판·수정·선호 평가를 학습에 활용하는 정렬 방식 |
| 목적 | 유해 응답 평가 부담 완화와 원칙의 명문화 |

1. **목적:** 유해 질문의 사람 직접 평가 부담을 줄이면서 평가 기준을 명문화하는 정렬 설계.
2. **구조:** 원칙 집합 → AI 비판·수정 데이터의 지도학습 → AI 선호 비교와 보상 모델 → 정책 강화학습. 사람의 초기 모델·원칙 설계와 최종 평가 역할은 계속 필요.
3. **비교:** RLHF는 사람 선호 데이터에 더 직접 의존, RLAIF는 AI 피드백으로 일부 평가를 확장. 어느 쪽도 편향·탈옥·문화별 규범 충돌의 자동 해결을 보장하지 않음.
4. **검증:** 원칙 충돌의 우선순위, 도움됨·무해함의 균형, 다국어·우회 공격·과잉 거절 평가와 이의 제기 절차.
