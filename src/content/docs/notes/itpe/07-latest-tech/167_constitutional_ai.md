```text
 ┃
 ┣━ Ⅰ 개요 ───── 인간 피드백 강화학습(RLHF)의 막대한 비용, 라벨러 주관적 편향, 유해 작업 노출 한계를 극복하기 위해 제안된 헌법 기반 AI 정렬(Alignment) 기법
 ┣━ Ⅱ 특징 ───── 원칙 중심(Rule-based Constitution) · 인간 피드백 대체(RLAIF) · 자율 비판 및 수정(Critique & Revision) · 확장성(Scalability) · 투명성
 ┣━ Ⅲ 구조 ───── 명문화된 헌법(Constitution) + 1단계 지도학습 정제(Critique/Revision SFT) + 2단계 강화학습(RLAIF: AI 피드백 기반 보상 모델)
 ┣━ Ⅳ 메커니즘 ─ ① 유해 프롬프트에 대한 원시 답변 생성 → ② 헌법 원칙 기반 AI의 비판(Critique) → ③ 헌법에 맞춘 답변 수정(Revision) 및 파인튜닝 → ④ AI가 선택한 선호도 데이터로 보상 모델 학습 및 PPO 강화학습
 ┣━ Ⅴ 비교 ───── RLHF vs Constitutional AI (RLAIF) (인간작업자직접평가/고비용/심리적외상/라벨편향 vs 명문화헌법원칙/AI피드백/저비용초고속/일관된규범준수)
 ┗━ Ⅵ 실무 ───── 헌법 원칙 간의 상충(도움됨 vs 무해함 트레이드오프) / 모호한 헌법 조항으로 인한 탈옥(Jailbreak) / AI 피드백 편향의 자기 강화(Self-reinforcing bias)
```

## 한 줄 본질
- 수천 명의 인간 알바생에게 욕설과 폭력을 읽히며 좋은 답변을 고르게 하던 낡은 방식(RLHF) 대신, 몇 줄의 'AI 헌법 원칙'을 주고 AI가 스스로 자기 글을 비판·수정하며 바르게 자라도록 훈련시키는 자율 정렬 기술

## 핵심 그림
```text
[Constitutional AI 2단계 훈련 파이프라인 (SFT & RLAIF)]

   [1단계: 지도학습 정제 (SL Phase)]
   유해 프롬프트 ──► [원시 LLM] ──► 유해 답변 생성
                                           │
   헌법(Constitution) ─────────────────────┼──► [AI 비판 (Critique)]
   "해당 답변의 유해한 점을 헌법에 비추어 지적하라" │
                                           ▼
                                 [AI 수정 (Revision)]
                                 "헌법에 맞게 안전하고 유용한 답변으로 고쳐라"
                                           │
                                           ▼ (수정된 데이터셋 구축)
                                 [Supervised Fine-Tuning (SFT)]
                                           │
   [2단계: 강화학습 단계 (RLAIF Phase)]    │
                                           ▼
   답변 A, B 생성 ──► [피드백 AI] ──► 헌법 기반 선호도 판정 (A > B)
                                           │
                                           ▼
   [보상 모델 (Reward Model) 학습] ──► [PPO / DPO 강화학습 정책 최적화]
```

## 핵심 용어
- 헌법(Constitution): UN 세계인권선언, 애플 서비스 약관, 딥마인드 원칙 등에서 추출한 수십 개의 짧은 자연어 규칙들의 모음 (예: "가장 도움이 되면서도 절대 위법하거나 유해하지 않아야 한다")
- 비판 및 수정(Critique and Revision): 모델이 생성한 초기 답변에 대해 시스템이 헌법 조항을 들이밀며 어떤 규칙을 어겼는지 스스로 반성(Critique)하게 하고, 이를 준수한 새로운 답변(Revision)으로 고쳐 쓰게 하는 과정
- RLAIF(Reinforcement Learning from AI Feedback): 인간의 선호도 레이블 대신, 헌법 원칙을 프롬프트로 받은 고성능 AI가 두 답변 중 어느 것이 우수한지 판정하여 보상 모델을 훈련시키는 강화학습 기법

## 핵심 통찰
- "인간 레이블러의 심리적 외상 종식": RLHF를 위해 케냐 등지의 저임금 노동자들에게 테러, 아동 학대 등 극단적 유해 콘텐츠를 하루 종일 검수하게 하던 비윤리적 착취 문제를 근원적으로 해결
- 투명하고 수정 가능한 거버넌스: 모델의 행동 양식이 블랙박스 인간 평가자의 모호한 선호도가 아니라, 사람이 읽을 수 있는 명문화된 헌법 텍스트로 정의되므로 사회적 합의에 따라 헌법만 개정하면 즉시 모델 행동 교정 가능
- 도움됨(Helpfulness)과 무해함(Harmlessness)의 황금 균형: 지나치게 방어적으로 변해 모든 질문에 "답변할 수 없습니다"를 남발하는 거절 편향(Refusal Bias)을 헌법의 비례성 원칙으로 정밀 제어

## 이웃 토픽과 구분
- RLHF vs RLAIF: RLHF는 인간(Human)이 두 모델의 답변을 보고 점수를 매겨 보상 모델을 학습 / RLAIF는 헌법 프롬프트를 장착한 AI가 직접 평가자가 되어 보상 모델을 학습

## 문제·원인·대책
- 적용 상황: 글로벌 금융/공공 기관용 초거대 생성 언어 모델 안전성 배포 프로젝트
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 모델이 단순한 의학/법률 상식 질문조차 "위험하다"며 답변을 거절하는 과잉 방어 | 무해함(Harmlessness)에만 가중치를 둔 단편적 RLHF 패널티 | 헌법에 "선의의 탐구에는 최대한 도움을 주되 위험 요소만 최소 분리 안내하라"는 조항 신설 | 정당한 질의 거절률 80% 감소 |
| 복잡한 다단계 역할극(Jailbreak) 프롬프트에 헌법 방어선이 뚫림 | 헌법 원칙이 단문 위주로 작성되어 문맥 우회 공격에 취약 | 적대적 탈옥 공격 프롬프트를 헌법 비판 데이터셋에 자동 포함하는 레드팀 루프 가동 | 적대적 공격 방어율 99.5% 달성 |
| RLAIF 평가 AI 자체의 숨은 편향이 학습된 모델에 대물림 증폭 | 단일 AI 모델의 평가 피드백 독점 | 다종의 독립 파운데이션 모델 앙상블 평가 및 다수결 피드백 판정 체계 적용 | 평가 편향 오차 65% 상쇄 |
