## 30초 인출

- 본질: **큐비트** (Qubit: Quantum Bit)는 0과 1의 이진 상태뿐만 아니라 양자역학적 중첩(Superposition)과 얽힘(Entanglement)을 활용하여 복소수 확률 진폭으로 정보를 표현하는 양자 컴퓨팅의 기본 정보 단위
- 메커니즘: 초기 기저 상태 $|0\rangle$ 설정 → 아다마르(H) 및 위상 게이트를 통한 중첩 형성 → CNOT 게이트 기반 다중 큐비트 얽힘 → 양자 간섭(Interference) 증폭 후 기저 측정
- 통찰: 외부 환경 열잡음 및 결맞음 시간(Coherence Time) 한계로 연산 도중 양자 정보가 소실되므로 표면 코드(Surface Code) 기반 양자 오류 정정(QEC)과 논리 큐비트(Logical Qubit) 구현 체계 구축 필요

<details><summary>핵심 용어</summary>

- **큐비트 (Quantum Bit)** : 상태 $|0\rangle$과 $|1\rangle$의 선형 결합($\alpha|0\rangle + \beta|1\rangle$)으로 표현되는 양자 정보의 최소 단위.
- **중첩 (Superposition)** : 하나의 큐비트가 0과 1의 상태를 동시에 확률적으로 지닐 수 있는 양자역학적 성질.
- **얽힘 (Entanglement)** : 두 개 이상의 큐비트가 공간적으로 분리되어 있어도 하나의 상태가 결정되면 즉시 다른 상태가 결정되는 비분리 상관관계.
- **블로흐 구면 (Bloch Sphere)** : 단일 큐비트의 순수 상태를 3차원 구면 위의 단위 벡터 좌표($\theta, \phi$)로 시각화한 기하학적 모델.
- **결맞음 시간 (Coherence Time)** : 양자 상태가 외부 간섭 없이 중첩과 얽힘을 유지할 수 있는 물리적 지속 시간 ($T_1, T_2$).

</details>

## 2~4교시 25점 답안

## Ⅰ. 큐비트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 0 또는 1 중 하나의 상태만을 가지는 고전 비트와 달리, 양자역학의 중첩(Superposition)과 얽힘(Entanglement) 현상을 이용하여 두 상태의 복소수 확률 진폭 선형 결합($\|\psi\rangle = \alpha\|0\rangle + \beta\|1\rangle$)을 표현하는 차세대 정보 단위 |
| 목적 | $N$개 큐비트 연산 시 $2^N$개의 상태를 동시 병렬 처리함으로써 암호 해독(쇼어 알고리즘), 신약/신소재 분자 시뮬레이션의 계산 복잡도 기하급수적 단축 |

## Ⅱ. 큐비트의 3대 양자역학적 특성 및 블로흐 구면 특징

| 핵심 특성 | 물리적 수학 공식 | 주요 특징 및 역할 |
|---|---|---|
| **양자 중첩 (Superposition)** | $\|\psi\rangle = \alpha\|0\rangle + \beta\|1\rangle$ ($\|\alpha\|^2 + \|\beta\|^2 = 1$) | 단일 큐비트에 두 상태가 공존, 아다마르(Hadamard) 게이트로 50:50 중첩 상태 생성 |
| **양자 얽힘 (Entanglement)** | $\|\Phi^+\rangle = \frac{1}{\sqrt{2}}(\|00\rangle + \|11\rangle)$ | 개별 큐비트의 텐서 곱으로 분해 불가능한 상태, 초공간적 동시 정보 전달 및 텔레포테이션 |
| **양자 간섭 (Interference)** | 보강 간섭(Constructive) / 상쇄 간섭(Destructive) | 정답 경로의 확률 진폭은 증폭하고 오답 경로는 상쇄 소거하여 측정 시 정답 도출 |
| **블로흐 구면 (Bloch Sphere)** | $\|\psi\rangle = \cos(\theta/2)\|0\rangle + e^{i\phi}\sin(\theta/2)\|1\rangle$ | 큐비트의 순수 양자 상태를 3차원 단위 구면의 각도 좌표($\theta, \phi$)로 완전 매핑 |

## Ⅲ. 큐비트 상태 제어 회로 및 확률적 측정 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 단일 및 다중 큐비트 연산(Quantum Circuit) 및 파동함수 붕괴 프로세스 ] │
└────────────────────────────────────────────────────────────────────────┘

  [ 1. 양자 기저 상태 초기화 (Initialization) ]
   - 절대영도(-273.15℃) 희석냉동기 환경에서 $|0\rangle$ 상태 준비
                 │
                 ▼
  [ 2. 아다마르(H) 게이트 적용 ──> 양자 중첩 생성 ]
   - $|0\rangle \xrightarrow{H} \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$
                 │
                 ▼
  [ 3. 제어-NOT(CNOT) 게이트 적용 ──> 벨 상태(양자 얽힘) 합성 ]
   - 제어 큐비트 $q_0$가 1일 때 타깃 큐비트 $q_1$ 반전: $|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$
                 │
                 ▼
  [ 4. 알고리즘 오라클 및 위상 킥백 연산 (간섭 제어) ]
   - 양자 위상 조작을 통해 최적 해의 확률 진폭 극대화
                 │
                 ▼
  [ 5. 투영 측정 (Projective Measurement: Z-Basis) ]
   ├── 확률 $|\alpha|^2$로 상태 0 관측 (파동함수 붕괴)
   └── 확률 $|\beta|^2$로 상태 1 관측
                 │
                 ▼
  [ 최종 고전 디지털 비트(0 또는 1)로 판독 출력 ]
```

| 연산 단계 | 하드웨어 제어 동작 | 핵심 제어 매개변수 |
|---|---|---|
| **초기화** | 극저온 마이크로웨이브 펄스로 큐비트를 바닥 상태(Ground State)로 냉각 | 열잡음 제거, $T \approx 10\text{mK}$ |
| **단일 큐비트 게이트** | 특정 주파수와 위상의 RF 펄스를 인가하여 블로흐 구면 축 회전 | X, Y, Z, Hadamard, Phase 회전각 |
| **2-큐비트 게이트** | 인접 큐비트 간 커플러(Coupler) 활성화로 양자 얽힘 형성 | CNOT, CZ 게이트 충실도(Fidelity) |
| **측정 및 판독** | 공진기(Resonator)의 전파 투과 위상 변화를 저잡음 증폭기(TWPA)로 검출 | 상태 판독 분별도(Readout Fidelity $\ge 99\%$) |

## Ⅳ. 고전 비트 vs 물리 큐비트 vs 논리 큐비트 비교

| 비교 항목 | 고전 비트 (Classical Bit) | 물리 큐비트 (Physical Qubit) | 논리 큐비트 (Logical Qubit) |
|---|---|---|---|
| **정보 단위** | 0 또는 1 (상호 배타적) | 중첩 상태 ($\alpha\|0\rangle + \beta\|1\rangle$) | 오류 정정 코드로 묶인 복합 큐비트 |
| **표현 공간** | $N$ 비트 = $N$개 상태 중 1개 | $N$ 큐비트 = $2^N$개 상태 동시 중첩 | 결맞음 오류가 제거된 완벽한 양자 상태 |
| **물리적 소자** | 실리콘 트랜지스터 (CMOS) | 초전도 조셉슨 접합, 이온 트랩 | 1,000~10,000개의 물리 큐비트 어레이 |
| **오류율** | $10^{-17}$ 이하 (오류 무시 가능) | $10^{-3} \sim 10^{-2}$ (극도로 높음, NISQ) | $10^{-12}$ 이하 (내결함성 FTQC 달성) |
| **복제 가능성**| 데이터 무한 복제 가능 | 양자 복제 불가능 정리 (No-Cloning) | 신드롬 측정으로 오류만 복구 (상태 비파괴) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 주변 환경의 미세한 전자기파·열잡음으로 인해 수십 마이크로초($\mu s$) 내에 중첩이 파괴되는 결맞음(Decoherence) 발생 | 10mK 극저온 희석 냉동기 유지 및 차폐 챔버 구축, 펄스 타이밍 동적 디커플링(Dynamical Decoupling) 기법 적용 |
| 양자 복제 불가능성(No-Cloning Theorem)으로 인해 고전적인 패리티 비트 복제 방식의 오류 정정 적용 불가 | 양자 상태를 파괴하지 않고 위상 반전(Phase-flip)과 비트 반전(Bit-flip) 신드롬만 측정하는 2차원 표면 코드(Surface Code) 적용 |
| 쇼어 알고리즘 등 실용 양자 암호 해독을 위해 수천 개의 논리 큐비트가 필요하나 물리 큐비트 집적도 한계 직면 | 마이크로웨이브 광자 링크 기반의 모듈러 분산 양자 컴퓨팅(QPU간 네트워킹) 및 중성 원자 셔틀링 기술 개발 |

## Ⅵ. 제언

현재의 NISQ(Noisy Intermediate-Scale Quantum) 한계를 극복하고 실용적 양자 우위를 달성하기 위해, 하이브리드 고전-양자 알고리즘(VQE/QAOA)을 우선 상용화하고 궁극적으로 내결함성 양자 컴퓨팅(FTQC) 로드맵으로 이행 필요.

```text
[ 복잡한 최적화/분자 구조 문제 ]
                 │
                 ▼
[ 고전 컴퓨터 (Classical HPC / CPU) ]
   ├── 파라미터 초기화 및 양자 회로 컴파일
   │             │
   │             ▼ (회로 파라미터 전달)
   │    [ 양자 프로세서 (QPU: NISQ 칩) ]
   │       └── 짧은 회로 깊이로 상태 계산 및 기대치 측정
   │             │
   │             ▼ (측정 결과 반환)
   └── 고전 최적화기 (COBYLA 등) 기반 가중치 업데이트 (반복 루프)
                 │
                 ▼ (수렴 완료 시)
[ 최적 해 도출 (VQE: 변분 양자 고유값 해석) ]
```

| 구분 | 초기 NISQ 단독 구동 | 제언: VQE 하이브리드 양자-고전 플랫폼 |
|---|---|---|
| **회로 깊이** | 깊은 회로 구동 시 노이즈로 연산 실패 | 얕은 회로(Shallow Circuit) 반복으로 노이즈 최소화 |
| **오류 정정** | 완전한 양자 오류 정정 필수 (구현 불가) | 고전 최적화 알고리즘이 양자 잡음을 보정 흡수 |
| **실용 시점** | FTQC 상용화까지 10년 이상 소요 | 현재 가용 100~1,000 큐비트 수준에서 즉시 실증 |
| **적용 분야** | 이론적 암호 해독 위주 | 배터리 양극재 분자 시뮬레이션, 금융 포트폴리오 최적화 |
