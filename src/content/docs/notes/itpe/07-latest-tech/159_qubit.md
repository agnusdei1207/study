```text
 ┃
 ┣━ Ⅰ 개요 ───── 0 또는 1의 확정적 비트(Bit)를 사용하는 고전 컴퓨터의 한계를 넘어, 중첩(Superposition)과 얽힘(Entanglement)을 활용하는 양자 컴퓨터의 기본 정보 단위
 ┣━ Ⅱ 특성 ───── 양자 중첩(|Ψ⟩ = α|0⟩ + β|1⟩) · 양자 얽힘(Bell State) · 양자 간섭(Quantum Interference) · 복제 불가능성(No-Cloning Theorem)
 ┣━ Ⅲ 표현 ───── 블로흐 구면(Bloch Sphere, 3차원 단위 구면 상의 극각 θ와 방위각 φ) + 상태 벡터(Dirac 브라-켓 표기법)
 ┣━ Ⅳ 구현방식 ─ 초전도(Superconducting, 조셉슨 접합) + 이온 트랩(Trapped Ion, 레이저 전자기장) + 중성 원자(Neutral Atom, 광학 핀셋) + 광자(Photonic)
 ┣━ Ⅴ 비교 ───── 고전 비트(Bit) vs 양자 비트(Qubit) (각 비트 0 또는 1 / 큐비트의 중첩 상태와 간섭 / N큐비트의 상태 벡터는 2^N개 기저 진폭으로 표현)
 ┗━ Ⅵ 실무 ───── 결맞음·게이트 오류·측정 오류 관리 / 구현 방식별 냉각·제어 조건 / 오류 정정 자원
```
- 필수 키워드: 큐비트(Qubit) · 양자 중첩(Superposition) · 양자 얽힘(Entanglement) · 블로흐 구면(Bloch Sphere) · 결맞음(Coherence) · 조셉슨 접합 · NISQ · 양자 오류 정정(QEC)

## 한 줄 본질
- |0⟩과 |1⟩의 중첩을 나타내는 양자 정보 단위. 여러 큐비트의 상태 공간은 지수적으로 커지지만 측정으로 모든 결과를 한꺼번에 읽을 수 없으며 알고리즘의 간섭 설계가 성능을 좌우

## 핵심 그림
```text
[블로흐 구면(Bloch Sphere) 상의 큐비트 상태 표현]

                      |0⟩ (북극: Z축 +1)
                       │
                       │     / |Ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩
                       │   /
                       │ / θ (극각)
                       ├───────► Y축
                      /│\
                     / │ \  φ (방위각)
                    /  │  \
                   X축 │
                       │
                      |1⟩ (남극: Z축 -1)
       * 임의의 점 표면: |α|^2 + |β|^2 = 1 (확률 보존)
```

## 핵심 용어
- 양자 중첩(Superposition): 하나의 큐비트가 관측되기 전까지 0의 상태와 1의 상태에 각각 확률 진폭(α, β)을 가지고 동시에 존재하는 양자역학적 중첩 상태
- 양자 얽힘(Entanglement): 복수 큐비트의 결합 상태를 각 큐비트의 독립 상태로 분해할 수 없는 상관관계. 측정 결과의 상관성만으로 초광속 정보 전달은 불가
- 양자 결맞음 시간(Coherence Time): 큐비트가 외부 환경(열, 진동, 전자파)의 간섭 없이 양자 중첩 및 위상 상태를 유지할 수 있는 유효 시간 (T1 이완 시간, T2 탈위상 시간)

## 핵심 통찰
- 상태 공간과 측정: N큐비트 순수 상태는 2^N개의 기저 진폭으로 표현하지만 한 번 측정하면 그중 한 결과를 얻음. 양자 속도 향상은 문제별 알고리즘과 간섭 구성에 달림
- 관측과 간섭: 알고리즘에 따라 원하는 결과의 측정 확률을 높이도록 진폭을 간섭시킨 뒤 측정. 모든 문제의 정답을 한 번에 얻는 방식은 아님
- 오류 정정의 한계: 물리 큐비트 오류를 줄이기 위해 여러 물리 큐비트에 논리 정보를 인코딩. 필요한 수와 달성 가능한 논리 오류율은 코드·물리 오류율·회로 조건에 따라 달라짐

## 이웃 토픽과 구분
- 물리 큐비트(Physical Qubit) vs 논리 큐비트(Logical Qubit): 물리 큐비트는 실제 하드웨어 정보 단위 / 논리 큐비트는 오류 정정 코드로 인코딩한 정보 단위이며 논리 오류가 남을 수 있음

## 1교시 예상문제 (10점)
- 큐비트의 중첩과 얽힘을 고전 비트와 비교하시오.

## 1교시 10점 답안
- **정의:** |ψ⟩=α|0⟩+β|1⟩, |α|²+|β|²=1인 양자 정보 단위. 측정 결과는 0 또는 1.
- **얽힘:** 복수 큐비트의 상태를 각 큐비트의 독립 상태로 분해할 수 없는 상관관계.
- **차이:** N큐비트 상태는 2^N개의 기저 진폭으로 표현하지만 한 번의 측정으로 2^N개 결과를 모두 읽는 것은 불가.

## 2~4교시 예상문제 (25점)
- 큐비트의 상태 표현과 연산·측정 원리 및 오류 정정 과제를 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 상태 표현
- 블로흐 구면은 순수한 단일 큐비트의 상대 진폭·위상을 표현. 여러 큐비트는 텐서곱 상태와 얽힘으로 표현.
### Ⅱ. 연산과 측정
- 양자 게이트는 진폭을 변환하고 간섭을 이용해 특정 결과의 확률을 높임. 측정은 확률에 따라 한 결과 제공.
### Ⅲ. 구현
- 초전도·이온 트랩·중성 원자·광자 등 방식별 제어·연결성·오류·환경 조건이 다름.
### Ⅳ. 오류 정정
- 물리 큐비트 여러 개에 논리 상태를 인코딩하고 오류 신드롬을 반복 측정. 논리 오류율과 자원 요구는 코드·장치 조건별 평가.
