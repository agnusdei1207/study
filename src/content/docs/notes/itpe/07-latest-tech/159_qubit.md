## 2~4교시 25점 답안

## Ⅰ. 큐비트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 기저 상태 0·1의 복소 진폭 중첩으로 표현하는 양자 정보 단위 |
| 목적 | 게이트·간섭·측정을 통한 양자 정보 처리 |

## Ⅱ. 중첩 상태의 게이트 연산과 측정 구조

```text
초기 상태 |0⟩ ── 게이트 ── α|0⟩ + β|1⟩
                              │ 후속 게이트로 진폭·위상 간섭
                              ▼
                         측정 기준 선택
                         ├─ 결과 0: 확률 |α|²
                         └─ 결과 1: 확률 |β|²
                    한 번의 측정은 한 결과만 제공
```

## Ⅲ. 구현 방식과 평가 조건

| 구현 방식 | 물리적 정보 표현 | 주요 검토 항목 |
|---|---|---|
| 초전도·이온 트랩 | 제어 가능한 물리 상태 | 결맞음·게이트 오류·연결성 |
| 중성 원자·광자 | 원자 배열·광학 상태 | 제어·측정·확장 자원 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 단일 측정에서 모든 중첩 진폭을 읽을 수 없음 | 목적 결과의 확률을 높이는 간섭 회로 설계와 반복 측정 |
| 물리 큐비트 오류가 계산 결과에 누적 | 논리 상태 인코딩·오류 신드롬 반복 측정과 자원·논리 오류율 평가 |

## Ⅴ. 제언

알고리즘의 요구 정확도와 회로 깊이를 먼저 정하고 구현별 오류율·논리 큐비트 자원을 비교.
