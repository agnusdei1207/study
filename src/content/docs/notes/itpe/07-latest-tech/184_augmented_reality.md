## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 현실 환경과 가상 정보를 결합하고 실시간으로 상호작용하며 3차원 위치를 정합하는 기술. |
| 목적 | 현실 공간에 정합된 가상 정보로 작업과 탐색 지원 |

## Ⅱ. 현실 좌표와 가상 객체의 정합

```text
카메라·IMU → 자세·공간 지도 추정
                    ↓ 현실 좌표계 앵커
가상 작업 안내 → 위치·깊이 정합 → 화면 출력
                                    ↓ 추적 상실 시 재보정
```

1. **요구:** 부품 안내의 위치 정확도, 양손 작업, 시야 확보와 장시간 사용 안전성 정의.
2. **구조:** 센서 융합·SLAM → 공간 앵커 → 안내 객체 렌더링 → 깊이 정보에 따른 폐색 → 광학 또는 비디오 투과 디스플레이.
3. **비교:** 광학 투과는 현실 직접 관찰의 장점과 대비·차광 제약, 비디오 투과는 합성·폐색 제어의 장점과 카메라 지연·왜곡 제약.
4. **검증:** 저조도·반사·가림·이동 조건별 추적 오차, 지연, 작업 오류 및 피로 측정과 추적 상실 시 안전한 복구 절차.

## Ⅲ. 마커 기반과 마커리스 AR

| 구분 | 마커 기반 | 마커리스 |
|---|---|---|
| 기준 | 인쇄된 인식 패턴 | 자연 특징·평면·공간 지도 |
| 제약 | 마커 가림·배치 | 추적 오차·조도·연산량 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 작업자 이동 시 가이드의 위치 떨림 — 특징점 매칭과 자세 추정 오차 | 카메라·IMU 융합, 앵커 재보정, 지연 측정 |
| 손이 가상 객체 뒤에 잘못 표시 — 깊이·폐색 정보 부족 | 깊이 센서 또는 영상 기반 메쉬와 렌더링 순서 조정 |
| 저조도에서 추적 상실 — 시각 특징점 감소 | 보조 조명·적외선·재위치 추정 절차 도입 |

## Ⅴ. 제언

- [산업 AR의 우선순위] 광원 일치보다 공간 정합·가림·작업 안전을 먼저 검증하고, 정확도와 지연 목표 충족 후 장면별 광원 추정·렌더링 적용
