## 30초 인출

- 본질: 인간의 뇌 신경세포(Neuron)와 시냅스(Synapse)의 정보 처리 방식을 수학적으로 모델링하여, 입력 신호의 가중합과 비선형 활성화 함수를 통해 데이터 간의 복잡한 비선형 관계를 학습하는 기계학습 모델.
- 메커니즘: 입력층 데이터 수신 $\rightarrow$ 가중합 및 편향 가산($z = Wx + b$) $\rightarrow$ 비선형 활성화 함수 통과($a = \sigma(z)$) $\rightarrow$ 순전파 출력 및 손실 산출 $\rightarrow$ 오차역전파 기반 가중치 갱신.
- 통찰: 단층 퍼셉트론의 XOR 선형 분리 불가 한계는 다층 퍼셉트론(MLP)으로 해결되었으나 망 심층화 시 기울기 소실 및 활성화 포화가 발생하므로 불포화 활성화 함수(GELU) 및 배치 정규화(BatchNorm) 결합 필수.

<details><summary>핵심 용어</summary>

- **인공신경망(ANN, Artificial Neural Network):** 노드(인공 뉴런)들이 유향 엣지(시냅스 가중치)로 연결되어 비선형 결정 경계를 형성하는 계산 아키텍처.
- **인공 뉴런(Perceptron):** 다수의 입력 신호에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 거쳐 단일 출력을 내보내는 기본 정보 처리 단위.
- **가중치(Weight)와 편향(Bias):** 신호의 전달 강도를 조절하는 시냅스 결합 강도(Weight)와 활성화 기준 임계값을 제어하는 편향 파라미터(Bias).
- **활성화 함수(Activation Function):** 뉴런의 선형 결합 결과에 비선형성을 부여하여 다층 신경망이 복잡한 함수를 근사하도록 만드는 변환 함수.
- **피드포워드 신경망(FFNN, Feedforward Neural Network):** 정보가 입력층에서 은닉층을 거쳐 출력층으로 순방향으로만 흐르고 순환 루프가 없는 신경망 구조.
</details>

## 2~4교시 25점 답안

## Ⅰ. 인간 뇌 신경계의 수학적 모델링, 인공신경망(ANN)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 생물학적 뉴런의 시냅스 결합과 신호 전달 원리를 모방하여, 노드 간 연결 가중치와 비선형 활성화 함수를 통해 데이터 패턴을 학습하는 계산 모델 |
| 목적 | 단일 선형 모델로 해결 불가능한 비선형 분류 및 회귀 문제 해결, 고차원 데이터의 잠재 특징 표현 학습 |

- 단층 퍼셉트론(Single-Layer Perceptron)의 선형 분리 한계(XOR 문제)를 은닉층을 둔 다층 퍼셉트론(MLP)과 비선형 활성화 함수 도입으로 극복.
- 현대 심층 딥러닝(Deep Learning), 합성곱 신경망(CNN), 트랜스포머(Transformer)의 수학적 기초를 구성하는 핵심 원천 모델.

## Ⅱ. 인공신경망의 핵심 구성요소 및 특징

| 핵심 구성요소 | 수학적 표현 | 역할 및 기능 |
|---|---|---|
| 입력 뉴런 ($x_i$) | 벡터 $X = [x_1, x_2, \dots, x_n]^T$ | 관측된 원시 데이터 피처를 수신하여 다음 계층으로 전달 |
| 가중치 ($w_{ij}$) | 행렬 $W$ ($w_{ij} \in \mathbb{R}$) | 이전 계층 뉴런 $j$에서 다음 뉴런 $i$로 전달되는 신호의 중요도 및 시냅스 강도 |
| 편향 ($b_i$) | 스칼라 또는 벡터 $b_i \in \mathbb{R}$ | 뉴런의 기본 활성화 임계치를 조정하여 결정 경계를 원점에서 이동시키는 역할 |
| 가중합 ($z_i$) | $z_i = \sum_{j=1}^n w_{ij} x_j + b_i$ | 입력 신호와 가중치의 내적에 편향을 더한 선형 대수적 결합 값 |
| 활성화 함수 ($f$) | $a_i = f(z_i)$ | 선형 결합 결과에 비선형성을 부여하여 비선형 결정 경계 형성 |

| 아키텍처 특징 | 세부 내용 | 구현 메커니즘 |
|---|---|---|
| 범용 근사 능력 | 유한한 수의 뉴런을 가진 단 하나의 은닉층만으로도 임의의 연속 함수 근사 가능 | Cybenko Universal Approximation Theorem 성립 |
| 분산 표상 (Distributed) | 특정 개념이 단일 뉴런이 아닌 전체 네트워크 뉴런들의 활성화 패턴으로 분산 저장 | 다층 텐서의 가중치 행렬 전반에 지식 임베딩 |
| 데이터 기반 적응성 | 명시적 알고리즘 규칙 작성 없이 훈련 데이터와 오차 피드백으로 파라미터 자체 최적화 | 경사하강법 기반 파라미터 최적화 루프 |

## Ⅲ. 피드포워드 신경망(FFNN) 연산 체계 및 순전파·역전파 프로세스

```text
+-------------------------------------------------------------------------------------------------+
|                       Feedforward Neural Network & Backpropagation Flow                         |
+-------------------------------------------------------------------------------------------------+
  [Input Layer]             [Hidden Layer (MLP)]               [Output Layer]
      x_1 ──(w11)──┐            z1 = W1*x + b1
                   ├──> ( h_1 ) ── a1 = f(z1) ──(w'11)──┐
      x_2 ──(w12)──┤                                    ├──> ( y_hat ) ──> Loss(y, y_hat)
                   └──> ( h_2 ) ── a2 = f(z2) ──(w'12)──┘                       |
                                                                                |
  [Forward: Activation Propagation ============================================>]
                                                                                |
  [<============================================ Backward: Gradient Propagation via Chain Rule]
   dL/dW1 = dz1 * x^T           dz1 = (W'^T * d_out) * f'(z1)     d_out = dL/dy_hat
```

| 프로세스 구분 | 주요 수행 단계 | 세부 연산 내용 |
|---|---|---|
| 피드포워드 (순전파) | 1. 선형 변환 | 은닉층 가중합 행렬 연산 수행: $Z^{[1]} = W^{[1]} X + b^{[1]}$ |
| | 2. 비선형 활성화 | 활성화 함수 적용하여 특징 추출: $A^{[1]} = \sigma(Z^{[1]})$ |
| | 3. 최종 예측 및 손실 | 출력 계층 연산($\hat{Y} = \text{Softmax}(Z^{[2]})$) 후 손실 함수 $L(Y, \hat{Y})$ 산출 |
| 역전파 (학습) | 4. 출력단 오차 계산 | 손실 함수를 출력 뉴런 값으로 미분: $\delta^{[2]} = \nabla_{\hat{Y}} L$ |
| | 5. 연쇄 법칙 전파 | 가중치 전치 행렬과 활성화 도함수 곱 연산: $\delta^{[1]} = (W^{[2]})^T \delta^{[2]} \odot f'(Z^{[1]})$ |
| | 6. 가중치 갱신 | 각 계층별 가중치 기울기 도출 후 경사하강법 적용: $W \leftarrow W - \alpha \nabla_W L$ |

## Ⅳ. 활성화 함수의 종류 및 비선형 특성 비교

| 활성화 함수 | 수학 공식 및 출력 범위 | 주요 장점 | 구조적 단점 및 주의점 |
|---|---|---|---|
| Sigmoid | $f(z) = \frac{1}{1 + e^{-z}}$, $(0, 1)$ | 출력을 확률 값으로 직관적 해석 가능 | $|z|$가 클 때 기울기 소실(Vanishing Gradient), 비원점 중심(Non-zero Centered) |
| Tanh (쌍곡탄젠트) | $f(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$, $(-1, 1)$ | 원점 중심(Zero-centered)으로 수렴 속도 향상 | 여전히 $|z|$가 커질 때 양극단 포화로 기울기 소실 발생 |
| ReLU | $f(z) = \max(0, z)$, $[0, \infty)$ | 연산 단순($O(1)$), 양수 영역에서 기울기 소실 완전 해소 | $z < 0$ 구간에서 뉴런이 영구 비활성화되는 Dying ReLU 발생 |
| GELU | $f(z) = z \cdot \Phi(z)$, $(-0.17, \infty)$ | 입력값의 크기에 따른 확률적 드롭아웃 효과, 매끄러운 곡선 | 초월함수 연산 비용 소요, 현대 트랜스포머(BERT/GPT) 표준 채택 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| Sigmoid/Tanh 사용 시 다층 신경망에서 역전파 기울기가 사라지는 기울기 소실(Vanishing Gradient) | 불포화 활성화 함수인 ReLU/GELU 적용, He/Xavier 정규 분포 가중치 초기화 기법 적용 |
| ReLU 음수 입력 영역에서 기울기가 0이 되어 가중치 갱신이 영구 중단되는 Dying ReLU 현상 | 음수 영역에 작은 기울기를 부여하는 LeakyReLU($\max(0.01z, z)$) 또는 ELU/GELU 활성화 함수로 대체 |
| 파라미터 수 대비 훈련 데이터 부족 시 노이즈까지 과도하게 암기하는 과적합(Overfitting) | 은닉 뉴런의 일부를 확률적으로 비활성화하는 드롭아웃(Dropout) 및 가중치 감쇄(L2 Regularization) 적용 |

## Ⅵ. 제언

인공신경망은 단순 MLP 구조를 넘어 어텐션 및 잔차 연결과 융합되며 생성형 AI 및 고성능 딥러닝의 근간 아키텍처로 진화.

```text
[Universal Approximator (ANN)] ---> [Residual & LayerNorm] ---> [Transformer / Modern DNN]
  - Multi-Layer Perceptron             - Skip Connection Path      - Self-Attention Blocks
  - Non-linear Activation (GELU)       - Stable Gradient Flow      - Multi-Head Projection
```

| 연구 및 개발 관점 | 최적화 실행 방안 | 기술적 기대효과 |
|---|---|---|
| 수치 안정성 | 계층 정규화(Layer Normalization) 및 가중치 클리핑 적용 | 심층 신경망 학습 중 내부 공변량 변화(Internal Covariate Shift) 억제 |
| 구조적 확장 | 완전 연결(Dense) 계층의 희소화(Sparse) 및 MoE(Mixture of Experts) 연계 | 파라미터 폭증 대비 연산량 최적화 및 서빙 속도 개선 |
