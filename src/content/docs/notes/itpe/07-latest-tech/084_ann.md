## 지식 로드맵 내 현재 위치
IT 인공지능 → 머신러닝 → 인공신경망 → 퍼셉트론·다층 퍼셉트론

## 30초 인출
- **본질:** 인공신경망은 가중합과 활성화 함수로 입력에서 출력을 계산하는 연결형 모델이다.
- **메커니즘:** 학습 자료에 대한 손실의 기울기로 가중치와 편향을 조정한다.
- **추가 단서:** 비선형 활성화가 있는 은닉층은 선형 분류기보다 다양한 결정경계를 표현할 수 있다.

<details><summary>핵심 용어</summary>

- **인공신경망(Artificial Neural Network, ANN):** 연결된 계산 단위가 가중합과 활성화 함수로 입력을 출력에 매핑하는 모델이다.
- **인공 뉴런:** 입력의 가중합에 편향을 더하고 활성화 함수를 적용해 출력을 계산하는 기본 단위다.
- **편향(Bias):** 뉴런의 가중합에 더해져 활성화 기준을 조정하는 학습 매개변수다.
- **활성화 함수:** 뉴런의 가중합을 비선형 출력으로 바꾸는 함수다.
- **다층 퍼셉트론(MLP):** 입력·은닉·출력 층을 연결한 순방향 신경망이다.
</details>

## 1교시 10점 답안
### Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | 인공신경망은 뉴런 연산을 층으로 연결해 입력에서 출력을 학습하는 모델이다 |
| 목적 | 데이터에 있는 복잡한 입력·출력 관계를 근사한다 |

### Ⅱ. 뉴런과 다층 구조
```text
[입력 x]
   | 가중합 z = Wx + b
   v
[뉴런]
   | 비선형 활성화 f(z)
   v
[은닉 표현]
   | 출력층 계산
   v
[예측 y]
```

단층 퍼셉트론은 선형 결정경계만 표현하므로 XOR처럼 선형 분리되지 않는 문제를 풀 수 없다. 비선형 은닉층을 둔 MLP는 여러 영역을 조합해 이를 표현할 수 있다.

### Ⅲ. 활성화 함수 비교
| 함수 | 출력·특성 | 유의점 |
|---|---|---|
| Sigmoid | `(0,1)` 범위 | 포화 영역에서 기울기 작아질 수 있음 |
| Tanh | `(-1,1)` 범위 | 포화 영역에서 기울기 작아질 수 있음 |
| ReLU | `max(0,z)` | 음수 영역에서 출력·기울기 0 |

**제언:** 과업과 네트워크 구조에 맞는 활성화 함수를 선택하고 검증 성능을 비교한다.

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | 인공신경망은 뉴런 연산을 층으로 연결해 입력에서 출력을 학습하는 모델이다 |
| 목적 | 데이터에 있는 복잡한 입력·출력 관계를 근사한다 |

인공신경망은 가중치·편향·활성화 함수로 연결된 계산 모델이다. 입력층·은닉층·출력층 구조와 학습 방법은 과업에 따라 달라진다.

| 구성 | 역할 |
|---|---|
| 입력층 | 자료를 모델에 전달 |
| 은닉층 | 가중합·활성화로 내부 표현 계산 |
| 출력층 | 과업에 맞는 예측값 계산 |

## Ⅱ. 뉴런 구조와 표현
```text
[입력 x]
   | 가중합 z = Wx + b
   v
[뉴런]
   | 비선형 활성화 f(z)
   v
[은닉 표현]
   | 출력층 계산
   v
[예측 y]
```

층을 여러 개 쌓고 비선형성을 적용하면 단일 선형 변환으로 표현할 수 없는 결정경계를 학습할 수 있다.

## Ⅲ. XOR 문제와 활성화 함수
| 구조·함수 | 특성 |
|---|---|
| 단층 퍼셉트론 | 하나의 선형 결정경계로 XOR를 분리하지 못함 |
| MLP 은닉층 | 비선형 변환을 조합해 XOR를 표현 가능 |
| Sigmoid | `(0,1)`, 포화 시 기울기 감소 |
| Tanh | `(-1,1)`, 포화 시 기울기 감소 |
| ReLU | `max(0,z)`, 계산 단순하나 음수 입력 영역에서 뉴런 비활성 가능 |

## Ⅳ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 모델이 학습 자료의 노이즈를 외우거나 활성화 선택에 따라 학습이 불안정할 수 있음 | 검증 자료로 일반화 성능을 감시하고, 초기화·활성화·정규화 조합을 과업에 맞게 비교한다. |
