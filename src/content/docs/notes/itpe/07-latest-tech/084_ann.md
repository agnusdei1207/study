## Ⅰ. 인공신경망(Artificial Neural Network)의 개요

- 개념 : 생물학적 뉴런의 시냅스 결합과 신호 전달 원리를 모방하여, 노드 간 **연결 가중치** 및 비선형 **활성화 함수** 적용을 통해 데이터 패턴을 학습하는 계산 모델
- 배경 및 필요성 : 단층 퍼셉트론의 XOR 선형 분리 불가 한계는 **다층 퍼셉트론** (MLP)으로 해결되었으나 망 심층화 시 **기울기 소실** 및 활성화 포화가 발생하므로 불포화 활성화 함수(GELU) 및 **배치 정규화** (BatchNorm) 결합 필수.
- 핵심 목적 : 단일 선형 모델로 해결 불가능한 비선형 분류 및 회귀 문제 해결, 고차원 데이터의 잠재 특징 표현 학습

## Ⅱ. 인공신경망(Artificial Neural Network)의 핵심 아키텍처 및 동작 메커니즘

인공신경망은 입력층 데이터 수신 $\rightarrow$ 가중합 및 편향 가산($z = Wx + b$) $\rightarrow$ 비선형 활성화 함수 통과($a = \sigma(z)$) $\rightarrow$ **순전파** 출력 및 손실 산출 $\rightarrow$ **오차역전파** 기반 가중치 갱신 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
+-------------------------------------------------------------------------------------------------+
|                       Feedforward Neural Network & Backpropagation Flow                         |
+-------------------------------------------------------------------------------------------------+
  [Input Layer]             [Hidden Layer (MLP)]               [Output Layer]
      x_1 ──(w11)──┐            z1 = W1*x + b1
                   ├──> ( h_1 ) ── a1 = f(z1) ──(w'11)──┐
      x_2 ──(w12)──┤                                    ├──> ( y_hat ) ──> Loss(y, y_hat)
                   └──> ( h_2 ) ── a2 = f(z2) ──(w'12)──┘                       |
                                                                                |
  [Forward: Activation Propagation ============================================>]
                                                                                |
  [<============================================ Backward: Gradient Propagation via Chain Rule]
   dL/dW1 = dz1 * x^T           dz1 = (W'^T * d_out) * f'(z1)     d_out = dL/dy_hat
```

- **입력 뉴런 ($x_i$)** : 벡터 $X = [x_1, x_2, \dots, x_n]^T$ - 관측된 원시 데이터 피처를 수신하여 다음 계층으로 전달
- **가중치 ($w_{ij}$)** : 행렬 $W$ ($w_{ij} \in \mathbb{R}$) - 이전 계층 뉴런 $j$에서 다음 뉴런 $i$로 전달되는 신호의 중요도 및 시냅스 강도
- **편향 ($b_i$)** : 스칼라 또는 벡터 $b_i \in \mathbb{R}$ - 뉴런의 기본 활성화 임계치를 조정하여 결정 경계를 원점에서 이동시키는 역할
- **가중합 ($z_i$)** : $z_i = \sum_{j=1}^n w_{ij} x_j + b_i$ - 입력 신호와 가중치의 내적에 편향을 더한 선형 대수적 결합 값
- **활성화 함수 ($f$)** : $a_i = f(z_i)$ - 선형 결합 결과에 비선형성을 부여하여 비선형 결정 경계 형성

## Ⅲ. 인공신경망(Artificial Neural Network)의 세부 구성 요소 및 비교 분석

| 활성화 함수 | 수학 공식 및 출력 범위 | 주요 장점 | 구조적 단점 및 주의점 |
|---|---|---|---|
| Sigmoid | $f(z) = \frac{1}{1 + e^{-z}}$, $(0, 1)$ | 출력을 확률 값으로 직관적 해석 가능 | $\lvert z\rvert$가 클 때 기울기 소실(Vanishing Gradient), 비원점 중심(Non-zero Centered) |
| Tanh (쌍곡탄젠트) | $f(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$, $(-1, 1)$ | 원점 중심(Zero-centered)으로 수렴 속도 향상 | 여전히 $\lvert z\rvert$가 커질 때 양극단 포화로 기울기 소실 발생 |
| ReLU | $f(z) = \max(0, z)$, $[0, \infty)$ | 연산 단순($O(1)$), 양수 영역에서 기울기 소실 완전 해소 | $z < 0$ 구간에서 뉴런이 영구 비활성화되는 Dying ReLU 발생 |

- 인공신경망은 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 인공신경망(Artificial Neural Network)의 주요 한계점 및 해결 방안

- 포화 활성화 함수 사용에 따른 심층망 역전파 기울기 소실 :
  - 한계점 : Sigmoid/Tanh 사용 시 다층 신경망에서 역전파 기울기가 사라지는 기울기 소실(Vanishing Gradient).
  - 해결 방안 : 불포화 활성화 함수인 ReLU/GELU 적용, He/Xavier 정규 분포 가중치 초기화 기법 적용.
- 음수 영역 입력 시 뉴런 가중치 갱신이 중단되는 Dying ReLU 현상 :
  - 한계점 : ReLU 음수 입력 영역에서 기울기가 0이 되어 가중치 갱신이 영구 중단되는 Dying ReLU 현상.
  - 해결 방안 : 음수 영역에 작은 기울기를 부여하는 LeakyReLU($\max(0.01z, z)$) 또는 ELU/GELU 활성화 함수로 대체.
- 파라미터 수 대비 데이터 부족 시 노이즈 암기에 따른 과적합 :
  - 한계점 : 파라미터 수 대비 훈련 데이터 부족 시 노이즈까지 과도하게 암기하는 과적합(Overfitting).
  - 해결 방안 : 은닉 뉴런의 일부를 확률적으로 비활성화하는 드롭아웃(Dropout) 및 가중치 감쇄(L2 Regularization) 적용.

## Ⅴ. 인공신경망(Artificial Neural Network) 적용 및 발전을 위한 기술사적 제언

- 연구 및 개발 관점 중심 엔터프라이즈 고도화 : 최적화 실행 방안의 한계를 탈피하고, 기술적 기대효과를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 수치 안정성 중심 엔터프라이즈 고도화 : 계층 정규화(Layer Normalization) 및 가중치 클리핑 적용의 한계를 탈피하고, 심층 신경망 학습 중 내부 공변량 변화(Internal Covariate Shift) 억제를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 구조적 확장 중심 엔터프라이즈 고도화 : 완전 연결(Dense) 계층의 희소화(Sparse) 및 MoE(Mixture of Experts) 연계의 한계를 탈피하고, 파라미터 폭증 대비 연산량 최적화 및 서빙 속도 개선을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
