## 한 줄 본질
- 직렬 연산 중심의 폰 노이만 컴퓨터가 시각·음성·패턴 인식 등 비정형 직관 처리에 극도로 취약한 한계 → 생물학적 뉴런의 시냅스 결합 강도를 수학적 가중치($W$)와 비선형 활성화 함수로 모형화하여 병렬 연결 → 복잡한 다차원 입력 공간의 비선형 결정 경계(Decision Boundary)를 자율 학습 / 과적합 및 설명 불가능한 블랙박스 한계 수반

## 핵심 그림
```text
[단일 인공 뉴런(Perceptron)의 수학적 연산 모델]

  [입력값 x_i]        [가중치 w_i]
      x_1 -----------> ( * w_1 ) ---\
                                     \
      x_2 -----------> ( * w_2 ) -----> [ 가중합(Net Input) ] ---> [ 활성화 함수 ] ---> [ 출력 y ]
                                     /    z = Σ(w_i * x_i) + b       y = f(z)
      x_n -----------> ( * w_n ) ---/                                (Sigmoid/ReLU)
                                     ^
  [편향 bias]                        |
      b -----------------------------/
```

## 핵심 용어
- 인공 뉴런(Artificial Neuron): 다수의 입력 신호($x_i$)에 가중치($w_i$)를 곱해 모두 합산한 뒤, 역치 역할을 하는 편향($b$)을 더해 활성화 함수를 거쳐 최종 출력 신호를 내보내는 기본 연산 단위
- 편향(Bias, $b$): 가중합 곡선을 원점으로부터 좌우로 평행 이동시켜 활성화 함수가 0이 아닌 임의의 임계값에서 켜지도록 조절하는 파라미터
- 활성화 함수(Activation Function): 선형 가중합($\Sigma w_i x_i + b$) 결과를 비선형 출력 공간으로 변환하여, 신경망이 선형 평면뿐만 아니라 굽어지고 닫힌 복잡한 비선형 결정 경계를 형성할 수 있게 만드는 핵심 수학적 장치

## 핵심 통찰
- 신경망 역사의 제1차 암흑기는 "단층 퍼셉트론의 XOR 문제(Minsky & Papert, 1969)": 직선 하나로는 XOR 평면을 둘로 가를 수 없었음 → 은닉층(Hidden Layer)을 딱 하나만 추가하면 공간 왜곡을 통해 XOR을 완벽히 해결할 수 있다는 사실이 MLP와 역전파의 출발점
- 신경망의 표현력은 은닉 뉴런의 수에 비례하지만, 너무 많으면 학습 데이터의 노이즈까지 통째로 외워버리는 과적합(Overfitting) 발생 → 검증 데이터셋 기반 조기 종료(Early Stopping)와 가중치 규제(L2 Regularization)의 균형점이 실무 모델의 생명
- 폰 노이만 구조와 달리 메모리와 연산기가 분리되어 있지 않고, "가중치(Weight)가 곧 메모리이자 연산기": 시냅스 결합 위치에 데이터가 저장되고 즉시 곱해지는 초병렬 인메모리 컴퓨팅 패러다임

## 이웃 토픽과 구분
- 단층 퍼셉트론 vs 다층 퍼셉트론(MLP): 단층 퍼셉트론은 선형 분리 가능한 AND/OR 연산만 가능 / MLP는 비선형 은닉층을 두어 XOR 및 임의의 복잡 곡선 분류 가능

## 문제·원인·대책
- 적용 상황: 센서 신호 기반 공정 불량 이진 분류 신경망 훈련 중 오분류 지속
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 특정 특성값(온도: 0~1000)이 다른 특성값(압력: 0~1)보다 너무 커서 가중치 편향 왜곡 | 입력 특성 간 스케일 불일치로 인한 손실 함수 지형 찌그러짐 | 표준화(Z-score Normalization) 또는 Min-Max 스케일링 전처리 | 그래디언트 진동 제거 및 학습 수렴 속도 10배 향상 |
| 훈련 세트 손실은 0에 가까우나 테스트 세트 손실이 치솟는 과적합 발생 | 은닉 뉴런 수가 과다하여 노이즈를 학습하고 가중치 절대값이 과도하게 비대화 | L2 가중치 감쇠(Weight Decay) 및 드롭아웃(Dropout 0.2) 적용 | 가중치 크기 억제 및 테스트 일반화 정확도 18% 향상 |
| 학습률이 너무 커서 손실 함수가 수렴하지 않고 무한대로 발산 | 고정된 학습률(Fixed Learning Rate) 설정의 취약점 | 학습률 감쇠(Learning Rate Decay) 및 Cosine Annealing 스케줄러 도입 | 전역 최적해 부근에서 안정적인 미세 수렴 달성 |

## 내 의견
- [임베디드 제어 시스템을 위한 고정소수점(Fixed-Point) 신경망 양자화 적용] 마이크로컨트롤러(MCU) 환경에서는 부동소수점(FP32) 연산기가 없어 복잡한 인공신경망 추론 시 막대한 지연 발생 → 나라면: 학습 후 양자화(PTQ)를 통해 가중치와 활성화 함수를 8비트 정수(INT8)로 변환하고 룩업 테이블(LUT) 기반 활성화 연산으로 대체하여, 연산 메모리를 75% 절감하고 저가형 센서 칩에서도 10ms 내 실시간 불량 판정 구현
