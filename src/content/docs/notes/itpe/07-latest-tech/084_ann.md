## 연관 키워드

- 인공신경망(Artificial Neural Network), 가중치, 편향, 활성화 함수, 다층 퍼셉트론
- 순전파, 오차역전파, 기울기 소실, Dying ReLU, 드롭아웃, 배치 정규화

## Ⅰ. 인공신경망(Artificial Neural Network)의 개요

- 핵심 요약 : 뉴런 간 연결을 모방해 가중치와 비선형 활성화 함수로 데이터 패턴을 학습하는 계산 모델.
- 개념 : 생물학적 뉴런의 신호 전달을 모방해 노드 간 **가중치** (Weight, 입력 신호의 연결 강도)와 **활성화 함수** (Activation Function, 선형 결합에 비선형성을 주는 함수)를 조합하여 패턴을 학습하는 계산 모델.
- 배경 및 필요성 : 단층 퍼셉트론은 XOR(Exclusive OR)처럼 선형으로 분리되지 않는 문제를 풀 수 없어 **다층 퍼셉트론** (MLP, Multilayer Perceptron)이 등장함. 다만 층을 깊게 쌓으면 **기울기 소실** (Vanishing Gradient) 문제가 생기므로 비포화 활성화 함수와 **배치 정규화** (Batch Normalization) 병용이 전제됨.
- 주요 목적 : 선형 모델로 해결할 수 없는 비선형 분류·회귀 문제 해결, 고차원 데이터의 특징 표현 학습.

## Ⅱ. 인공신경망(Artificial Neural Network)의 특징 및 장점

- 핵심 요약 : 층 구조, 비선형 변환, 역전파 학습이 결합해 사람이 규칙을 정하지 않아도 특징을 스스로 학습하는 원리.

1. 층 구조 (입력·은닉·출력) : 층마다 선형 변환과 비선형 변환을 반복 → 저수준에서 고수준으로 이어지는 계층적 특징 추출.
2. 비선형 결정 경계 : 활성화 함수가 비선형성을 더함 → 선형 모델이 풀지 못하는 복잡한 분류 문제 처리.
3. 오차역전파 학습 : 출력 오차를 연쇄 법칙으로 앞 층에 전달 → 가중치를 자동 보정하여 사람이 규칙을 설계하지 않아도 됨.
4. 범용 근사 능력 : 충분한 은닉 뉴런과 비선형성이 있으면 복잡한 함수를 근사할 수 있음 → 음성·영상 등 비정형 데이터에 폭넓게 적용.

## Ⅲ. 인공신경망(Artificial Neural Network)의 구조 (흐름)

- 핵심 요약 : 입력에서 출력으로 가는 순전파와 오차를 거슬러 가중치를 고치는 역전파가 반복되는 학습 루프.
- **순전파** (Forward Propagation) : 입력을 층 단위로 가중합과 활성화를 거쳐 출력과 손실을 산출하는 과정.
- **오차역전파** (Backpropagation) : 손실의 기울기를 출력에서 입력 방향으로 연쇄 법칙에 따라 전달해 가중치를 갱신하는 과정.

```text
[ 입력층 x ]
      ↓ 가중합 z = Wx + b
[ 은닉층 ]
      ↓ 활성화 a = f(z)
[ 출력층 ŷ ]
      ↓ 손실 L(y, ŷ) 산출
[ 순전파 완료 ]
```

```text
[ 역전파 흐름 ]

손실의 기울기 (dL/dŷ)
          ↓ 연쇄 법칙
층별 기울기 전달 (앞 층 방향)
          ↓
가중치 갱신 (경사 하강)
          ↓
다음 배치에서 손실 재계산
```

- 가중합 : 입력 벡터와 가중치 행렬의 내적에 편향을 더한 선형 결합 값.
- 편향 : 뉴런의 활성화 임계치를 조정하여 결정 경계를 원점에서 이동시키는 항.

## Ⅳ. 인공신경망(Artificial Neural Network)의 활성화 함수 비교

- 핵심 요약 : 포화 구간이 있는 함수는 기울기 소실에 취약하고, 비포화 함수는 계산이 단순하나 죽은 뉴런 문제를 함께 봐야 함.

| 활성화 함수 | 출력 범위 | 장점 | 주의점 |
| --- | --- | --- | --- |
| Sigmoid | (0, 1) | 출력을 확률 값으로 해석 가능 | 입력 절댓값이 크면 기울기 소실, 출력이 원점 중심이 아님 |
| Tanh (쌍곡탄젠트) | (-1, 1) | 원점 중심이라 수렴이 Sigmoid보다 빠른 편 | 양극단 포화로 여전히 기울기 소실 발생 |
| **ReLU** (Rectified Linear Unit) | [0, ∞) | 계산이 단순하고 양수 구간에서 기울기 유지 | 음수 구간에서 **Dying ReLU** (뉴런이 영구 비활성화되는 현상) 발생 |

- 선택 기준 : 출력의 해석 방식(확률 여부), 층의 깊이, 학습 안정성 요구에 따라 함수를 고르고, 은닉층에는 비포화 계열을 기본으로 둠.

## Ⅴ. 인공신경망(Artificial Neural Network)의 한계와 방안

- 핵심 요약 : 기울기 소실, 죽은 뉴런, 과적합을 활성화 함수 교체, 초기화·정규화, 드롭아웃으로 나눠 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기울기 소실 | 포화 함수가 깊은 층에서 기울기를 줄여 하위 층 학습 정체 | ReLU·GELU(Gaussian Error Linear Unit) 같은 비포화 함수, He·Xavier 초기화 | 층별 기울기 크기 |
| Dying ReLU | 음수 입력 구간에 머문 뉴런의 기울기가 0이 되어 갱신 중단 | LeakyReLU나 ELU로 대체 | 비활성 뉴런 비율 |
| 과적합 (Overfitting) | 파라미터 수 대비 데이터가 부족해 노이즈까지 암기 | **드롭아웃** (Dropout, 학습 중 뉴런 일부를 무작위로 끔), L2 정규화 | 학습 손실과 검증 손실의 격차 |

## Ⅵ. 인공신경망(Artificial Neural Network)에 대한 기술사적 제언

- 핵심 요약 : 학습 안정성 진단과 재현 가능한 실험 체계를 갖춰 신경망을 검증 가능한 모델로 운영하는 방향.

1. 모델 개발 단계에서 기울기 크기와 검증 손실 격차를 학습 로그의 기본 항목으로 포함하여 학습 이상을 조기에 발견하는 것이 바람직함.
2. 연구 조직은 초기화, 정규화 설정과 하이퍼파라미터를 표준 템플릿으로 고정하여 실험 결과를 재현할 수 있도록 관리하는 것이 필요함.
3. 서비스 단계에서는 정확도와 추론 지연의 균형을 기준으로 가지치기나 양자화 같은 경량화 기법을 검토하는 것이 현실적임.

## Ⅶ. 결론

- 핵심 요약 : 인공신경망은 가중치와 비선형 활성화로 복잡한 패턴을 학습하는 현대 AI의 기본 계산 구조.
- 시사점 : 층을 깊게 쌓을수록 학습 안정성 기법이 성능을 좌우하며, 이 구조가 CNN(Convolutional Neural Network)과 Transformer 같은 이후 아키텍처의 토대가 됨.
