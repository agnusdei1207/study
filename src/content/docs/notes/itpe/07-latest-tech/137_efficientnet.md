## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 영상 분류 → CNN 효율화 → EfficientNet

## 30초 인출

- 본질: **EfficientNet은** 기준 CNN의 깊이·폭·입력 해상도를 균형 있게 확장한 영상 분류 모델 계열
- 메커니즘: 기준망 B0 선택 → 자원 예산 설정 → 깊이·폭·해상도 복합 확장 → 정확도·지연 검증

<details><summary>핵심 용어</summary>

- **기준망 B0** : 효율적 블록을 바탕으로 탐색한 EfficientNet의 시작 모델
- **복합 스케일링** : 깊이·폭·해상도를 단일 자원 계수로 함께 확장하는 방법
- **MBConv** : 깊이별 합성곱을 사용하는 모바일 역병목 블록

</details>

## 2~4교시 25점 답안

## Ⅰ. EfficientNet의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EfficientNet은** 기준 CNN의 깊이·폭·입력 해상도를 균형 있게 확장한 영상 분류 모델 계열 |
| 목적 | 주어진 연산 자원에서 정확도와 계산 비용의 균형 개선 |

## Ⅱ. 구성요소와 수행 단계

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 기준망 | 연산 효율을 고려한 B0 선택 | 기준망이 달라지면 확장 효과도 변화 |
| 깊이 | 계층 수 확장 | 지나친 깊이의 학습·지연 부담 |
| 폭 | 채널 수 확장 | 파라미터·메모리 증가 |
| 해상도 | 입력 크기 확장 | 연산량·지연 증가 |

## Ⅲ. 핵심 작동 관계

```text
기준망 B0 선택 → 자원 예산 설정 → 깊이·폭·해상도 복합 확장 → 정확도·지연 검증
```

EfficientNet의 적용 판단은 명칭이나 단일 지표보다 위 단계의 입력·출력 조건과 실제 업무·장치 환경에서 확인한 결과를 기준으로 수행.

## Ⅳ. 단일 축 확장과 복합 스케일링 비교

| 방식 | 조정 변수 | 판단 기준 |
|---|---|---|
| 단일 축 확장 | 깊이·폭·해상도 중 하나 | 나머지 축이 병목이 되면 자원 증가 대비 정확도 이득이 제한될 수 있음 |
| EfficientNet 복합 스케일링 | 세 축을 정해진 비율로 함께 확장 | 연산 예산 안에서 정확도와 실제 장치 지연을 함께 측정 |
