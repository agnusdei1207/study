## 연관 키워드

- EfficientNet, 복합 스케일링(Compound Scaling), MBConv(Mobile Inverted Bottleneck Convolution), SE(Squeeze-and-Excitation)
- MNAS(Mobile Neural Architecture Search), 깊이별 합성곱(Depthwise Convolution), EfficientNetV2, Fused-MBConv
- 점진적 학습(Progressive Learning), 확률적 깊이(Stochastic Depth), 라벨 스무딩(Label Smoothing)

## Ⅰ. EfficientNet의 개요

- 핵심 요약 : 깊이, 너비, 해상도를 고정 비율로 함께 키우는 복합 스케일링으로, 적은 연산에서 높은 정확도를 노린 합성곱 신경망 계열.
- 개념 : 네트워크의 깊이(Depth), 너비(Width), 해상도(Resolution)를 따로 늘리지 않고 고정 비율로 함께 키우는 **복합 스케일링** (Compound Scaling, 세 차원을 하나의 계수로 균형 있게 확장하는 방법)을 적용한 합성곱 신경망(CNN, Convolutional Neural Network) 계열.
- 배경 및 필요성 : 한 차원만 키우면 정확도가 일찍 포화되고 연산이 비효율적으로 늘어남. 그래서 차원 간 균형을 수식으로 정하고, 목표 장치에 맞춘 컴파일을 함께 고려해야 함.
- 주요 목적 : 제한된 연산 자원 안에서 파라미터 낭비를 줄이고 모델 용량을 체계적으로 조정하여, 같은 정확도에서 더 작고 빠른 모델을 얻는 것.

## Ⅱ. EfficientNet의 특징 및 장점

- 핵심 요약 : 스케일링 수식, MBConv 블록, SE 채널 주의가 결합되어 정확도 대비 연산 효율을 높인 구조.

1. 계수 기반 확장 : 계수 φ 하나로 깊이는 α의 φ 제곱, 너비는 β의 φ 제곱, 해상도는 γ의 φ 제곱만큼 키움 → 연산량 증가를 대략 2의 φ 제곱 배 수준으로 통제해 자원 예산을 맞추기 쉬움.
2. **MBConv** (Mobile Inverted Bottleneck Convolution, 채널을 넓혔다 줄이는 역잔차 병목 구조의 합성곱 블록) : 채널 확장, 깊이별 연산, 채널 축소로 이어지는 구조 → 파라미터와 연산량을 줄이면서 표현력 유지.
3. **SE** (Squeeze-and-Excitation, 채널별 중요도를 학습해 가중치를 다시 조정하는 모듈) : 채널 주의 메커니즘으로 불필요한 채널을 억제 → 추가 연산 비용이 작고 정확도가 향상됨.
4. 기준 모델 탐색 : **MNAS** (Mobile Neural Architecture Search, 정확도와 모바일 지연을 함께 고려해 구조를 자동 탐색하는 방법)로 찾은 B0을 기준으로 확장 → 모든 계열이 같은 설계 원칙을 공유.

## Ⅲ. EfficientNet의 구조 (흐름)

- 핵심 요약 : B0 기준 구조에서 MBConv 블록이 스테이지별로 반복되고, 블록 내부는 확장, 깊이별 연산, 주의, 축소 순서로 흐르는 구조.
- 블록 내부 : **깊이별 합성곱** (Depthwise Convolution, 채널마다 독립적으로 공간 연산을 수행하는 합성곱)을 중심에 두고, 앞뒤를 1x1 합성곱으로 감쌈. 활성화 함수는 Swish를 사용함.

```text
[입력 224x224x3 (B0 기준)]
        ↓
[시작 합성곱 3x3]
        ↓
[MBConv 블록 반복 (7개 스테이지)]
        ↓
[1x1 합성곱 → 풀링 → 완전 연결층]
        ↓
[1,000개 클래스 분류 출력]
```

```text
입력 텐서 (H x W x C)
        ↓
1x1 합성곱 : 채널 확장
        ↓
깊이별 합성곱 (3x3 또는 5x5)
        ↓
SE 블록 : 채널 중요도 재조정
        ↓
1x1 합성곱 : 채널 축소 (선형)
        ↓ 입출력 크기가 같을 때만
출력 = 입력 + 변환 결과
```

## Ⅳ. EfficientNet의 확장 방식 비교

- 핵심 요약 : 깊이, 너비, 해상도를 각각 확장하면 한계가 빨리 오지만, 세 차원을 복합 스케일링으로 함께 확장하면 효율이 높아짐.
- 비교 대상 : 깊이를 키우는 잔차 네트워크(ResNet, Residual Network) 계열, 너비를 키우는 와이드 잔차 네트워크(WideResNet, Wide Residual Network) 계열, 해상도만 키우는 방식, 그리고 복합 스케일링을 비교함.

| 비교 방식 | 확장 대상 | 장점 | 한계 |
| --- | --- | --- | --- |
| 깊이 확장 (ResNet) | 레이어 수 | 복잡한 특징을 포착할 수 있음 | 깊어질수록 그래디언트 소실과 성능 포화 |
| 너비 확장 (WideResNet) | 채널 수 | 병렬 연산에 유리함 | 채널만 키우면 얕은 특징에 머물러 한계 도달 |
| 해상도 확장 | 입력 픽셀 크기 | 미세한 시각 패턴 검출에 유리함 | 연산량 급증 대비 수용 영역 부족으로 포화 |
| 복합 스케일링 (EfficientNet) | 깊이, 너비, 해상도 동시 | 세 요소가 서로 보완되어 효율 극대화 | 하이퍼파라미터 탐색이 복잡함 |

- 선택 기준 : 장치의 연산 예산이 정해지면 계수 φ를 정하고, 지연 한계가 엄격하면 B0부터 B3 계열을 고름.

## Ⅴ. EfficientNet의 한계와 방안

- 핵심 요약 : 고해상도 모델의 지연, 깊이별 연산의 하드웨어 비효율, 규모에 따른 학습 규제 문제를 경량 모델 선택, 컴파일러 융합, 규제 조절로 통제해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고해상도 모델(B6, B7)의 추론 지연 | 큰 입력 해상도로 메모리 접근이 급증해 모바일과 임베디드 실시간 처리가 어려움 | 엣지 장치에서는 B0~B3 우선 채택, Fused-MBConv를 적용한 EfficientNetV2 검토 | 입력당 추론 지연 |
| 깊이별 합성곱의 하드웨어 비효율 | 연산 강도가 낮아 GPU(Graphics Processing Unit)에서 메모리 대역폭 병목 발생 | TensorRT를 통한 수직 레이어 융합과 커널 튜닝 | 계층별 실행 시간 |
| 규모 확대에 따른 학습 규제 문제 | 모델이 커질수록 과적합 위험과 학습 시간이 증가 | 확률적 깊이(Stochastic Depth), AutoAugment, 라벨 스무딩을 모델 규모에 맞춰 조절 | 검증 정확도 격차, 총 학습 시간 |

## Ⅵ. EfficientNet에 대한 기술사적 제언

- 핵심 요약 : 블록 구조, 학습 절차, 모델 선택 기준을 하드웨어와 학습 비용을 함께 고려하도록 표준화해야 함.

1. 핵심 블록은 깊이별 합성곱 위주의 MBConv에서 표준 합성곱을 결합한 Fused-MBConv (Fused Mobile Inverted Bottleneck Convolution, 초기 단계에 표준 합성곱을 쓰는 블록)로 전환하는 방향을 검토하는 것이 학습 속도 측면에서 유리하다.
2. 대형 모델 학습은 이미지 크기를 단계적으로 키우는 **점진적 학습** (Progressive Learning, 학습 과정에서 입력 해상도를 점차 늘리는 방법)을 적용해 학습 시간을 줄이는 방향으로 설계해야 한다.
3. 모델 선택은 가장 높은 정확도의 계열이 아니라, 목표 장치의 지연 예산 안에서 가장 정확한 계열을 고르는 기준을 팀의 표준으로 삼는 것이 실무적이다.

## Ⅶ. 결론

- 핵심 요약 : EfficientNet은 깊이, 너비, 해상도를 균형 있게 키우는 복합 스케일링으로 연산 효율과 정확도를 함께 잡은 CNN 계열임.
- 시사점 : 모델 크기를 임의로 키우기보다 자원 예산에 맞춰 차원을 함께 조정하는 설계 원칙이 이후 탐지 모델의 기준이 됨.
