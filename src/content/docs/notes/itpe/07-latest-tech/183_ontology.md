## 답안 골격
### 1교시 예상문제 (10점)
온톨로지의 정의와 클래스·인스턴스·속성·공리의 역할을 설명하시오.

### 1교시 10점 답안
- **정의:** 특정 도메인의 개념·관계·규칙을 명시적으로 공유하기 위한 지식 명세.
- **구성:** 클래스는 범주, 인스턴스는 개체, 속성은 개체·값의 관계, 공리는 범주와 관계에 대한 논리 조건.
- **추론:** OWL의 공리를 통해 명시되지 않은 일부 관계를 도출하며, 열린 세계 가정에서는 사실의 부재를 곧 거짓으로 해석하지 않음.

### 2~4교시 예상문제 (25점)
이종 의료 데이터 통합을 위한 온톨로지 설계·추론·버전 관리 방안을 설명하시오.

### 2~4교시 25점 답안
1. **개념 수집:** 의료 전문가와 용어 정의·식별자·동의어·범위를 합의하고 기존 표준 어휘 재사용 여부 검토.
2. **모델링:** 클래스·속성·공리로 질환·검사·증상의 관계를 표현하고 OWL 2 프로파일을 질의·성능 요구에 맞게 선택.
3. **검증:** 모순·순환·잘못된 포함 관계를 추론기로 검사하고 예시 질의·원자료와의 정합성 확인.
4. **운영:** 용어 변경·버전·매핑 근거·출처를 기록하고 대용량 추론 비용과 전문가 승인 절차 관리.

```text
[온톨로지(Ontology)] ◀━━ 머리: Ⅶ 내 의견 (공유된 개념화의 명시적 정형 명세(Gruber)와 지식 그래프 기반의 지능형 지식 표현 및 추론 체계 정립)
 ┃
 ┣━ Ⅰ 개요 ───── 특정 도메인 내의 객체, 개념, 그리고 개념들 간의 관계를 컴퓨터가 처리할 수 있도록 정형화(Formal)하여 표현한 공유된 지식 모델
 ┣━ Ⅱ 정의요소 ─ 개념화(Conceptualization) · 명시적(Explicit) · 정형적(Formal) · 공유된(Shared). 'formal/shared'는 Gruber 원문 이후 확장된 널리 쓰이는 정의
 ┣━ Ⅲ 구성요소 ─ 클래스(Class/Concept) + 인스턴스(Instance/Individual) + 속성(Property/Relation) + 공리(Axiom/제약규칙)
 ┣━ Ⅳ 언어/도구 ─ 표현 언어: RDFS, OWL 2(EL·QL·RL 프로파일) / 모델링 도구: Protégé / 추론 엔진: HermiT 등
 ┣━ Ⅴ 비교 ───── 관계형 스키마(테이블·제약·질의) vs OWL 온톨로지(개념·관계·논리 공리·추론). DB도 규칙·질의로 파생 정보를 계산 가능하며 세계 가정은 시스템별 차이
 ┗━ Ⅵ 실무 ───── 온톨로지 구축 시 도메인 전문가 간 합의 도출 난항 / 온톨로지 규모 확장에 따른 추론 지연 / 지식 변화에 따른 동적 버전 관리 한계
```

## 한 줄 본질
- 특정 분야의 개념·관계·공리를 명시하여 데이터를 공유하고 정해진 논리 범위에서 추론하도록 하는 지식 모델

## 핵심 그림
```text
[온톨로지(Ontology) 핵심 구성요소 및 추론 메커니즘]

   [클래스 계층 (Class Hierarchy)]
          ┌─────────────┐
          │  동물 (Animal)│
          └──────▲──────┘
                 │ is-a (상속 관계)
          ┌──────┴──────┐
          │  사람 (Human) │ ◄──── [공리 Axiom: 모든 사람은 심장을 가진다]
          └──────▲──────┘
                 │ type-of (인스턴스 관계)
   [인스턴스]  (소크라테스)
                 │
                 ▼ [추론 엔진 (Reasoning Engine: Pellet / HermiT)]
   [새로운 지식 자동 연역]: "소크라테스는 동물이며, 심장을 가지고 있다!"
```

## 핵심 용어
- 공유된 개념화의 명시적 정형 명세(Explicit Formal Specification of a Shared Conceptualization): Gruber의 '개념화의 명시적 명세' 정의를 후속 문헌이 formal/shared로 확장한 표현
- 공리(Axiom): 온톨로지 내에서 언제나 참으로 전제되는 논리적 규칙이나 제약 조건으로, 새로운 암묵적 지식을 연역적으로 도출(추론)하는 기준 (예: A가 B의 부모이면, B는 A의 자식이다)
- 열린 세계 가정(OWA: Open World Assumption): 온톨로지의 핵심 철학으로, 지식 베이스에 어떤 사실이 기록되어 있지 않다고 해서 그것을 '거짓'으로 단정하지 않고 단지 '아직 모르는 것'으로 취급하는 논리 체계

## 핵심 통찰
- "단순한 사전(Taxonomy)을 넘어선 지능적 추론(Reasoning)": 단순한 분류표는 계층만 보여주지만, 온톨로지는 공리(Axiom)를 장착하여 입력하지 않은 사실도 컴퓨터가 삼단논법으로 스스로 깨닫게 만듦
- 세계 가정의 차이: OWL의 열린 세계 가정에서는 사실의 부재만으로 거짓을 결론내리지 않음. 관계형 DB의 질의·업무 규칙에 쓰이는 닫힌 세계 가정과 구분하되, DB 전체를 단일 논리로 단정하지 않을 것
- 설명 논리의 표현력·계산 비용 절충: OWL 2 프로파일을 목적에 맞게 선택하면 추론 복잡도를 제한할 수 있으나 모든 규모·질의의 실시간 처리 보장은 아님

## 이웃 토픽과 구분
- 분류 체계(Taxonomy) vs 온톨로지(Ontology): 분류 체계는 범주 간 계층 관계에 초점, 온톨로지는 필요에 따라 추가 관계·속성·공리까지 명시. 인과관계의 도입과 추론 가능 범위는 모델에 종속
