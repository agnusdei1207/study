## 30초 인출

- 본질: 특정 도메인의 개념·관계·규칙을 명시적으로 공유하기 위한 지식 명세. 도메인 개념과 관계를 공유하고 논리 검사·추론 지원.
- 메커니즘: 개념·관계 정의 → 공리 기술 → 논리 검사·추론 → 버전 관리.
- 통찰: 한계: 공리를 추가해도 실제 도메인 정의와 어긋나면 잘못된 추론이 나온다 → 방안: 전문가와 개념 경계를 합의하고 모순 검사·대표 질의·버전 검토를 거친다.

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 특정 도메인의 개념·관계·규칙을 명시적으로 공유하기 위한 지식 명세. |

## Ⅱ. 개념·관계와 논리 추론

```text
클래스·인스턴스 ──속성── 관계
       │                     │
       └────── 공리·제약 ──────┘
                  ↓ 추론기
            일관성 검사·새 관계 도출
```

1. **개념 수집:** 의료 전문가와 용어 정의·식별자·동의어·범위를 합의하고 기존 표준 어휘 재사용 여부 검토.
2. **모델링:** 클래스·속성·공리로 질환·검사·증상의 관계를 표현하고 OWL 2 프로파일을 질의·성능 요구에 맞게 선택.
3. **검증:** 모순·순환·잘못된 포함 관계를 추론기로 검사하고 예시 질의·원자료와의 정합성 확인.
4. **운영:** 용어 변경·버전·매핑 근거·출처를 기록하고 대용량 추론 비용과 전문가 승인 절차 관리.

## Ⅲ. 분류 체계와 온톨로지

| 구분 | 분류 체계 | 온톨로지 |
|---|---|---|
| 표현 | 범주 계층 | 클래스·속성·공리 |
| 검증 | 포함 관계 | 논리 일관성·추론 결과 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 대규모 추론 시 메모리·시간 초과 — 공리 표현력과 데이터량 증가 | 필요한 추론 유형에 맞춰 OWL 2 EL·QL·RL 프로파일 선택·벤치마크 |
| 병원별 용어 충돌 — 정의·식별자·버전 차이 | 공통 어휘와 매핑 규칙의 전문가 검토 및 변경 이력 관리 |
| 논문 지식 갱신 지연 — 수작업 추출·검증 병목 | 자동 추출 후보에 출처·신뢰도 부여 후 전문가 승인 |

- [도메인 어휘 거버넌스] 상위 온톨로지 적용 여부를 기존 표준·도메인 요구에 따라 결정하고, 개념 정의·식별자·버전·매핑 근거를 지속 관리
