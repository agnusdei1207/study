## 30초 인출

- 본질: **메타버스(Metaverse)** 는 사용자가 디지털 공간에서 콘텐츠·다른 사용자와 상호작용하는 환경
- 메커니즘: 사용자 입력·공간 인식 → 디지털 장면 구성 → 다른 사용자와 상태 동기화 → 공동 활동

<details>
<summary>핵심 용어</summary>

- **메타버스(Metaverse)** : 사용자가 지속적 디지털 공간에서 콘텐츠·다른 사용자와 상호작용하는 환경
- **ASF(Acceleration Studies Foundation) 유형** : 메타버스 로드맵의 증강현실·라이프로깅·거울세계·가상세계 분류
- **XR(Extended Reality)** : 가상·증강·혼합 현실 기술을 아우르는 표현
- **공간 컴퓨팅(Spatial Computing)** : 3차원 공간·객체를 인식해 디지털 정보와 상호작용하는 컴퓨팅 방식
</details>

## 1교시 10점 답안

### Ⅰ. 메타버스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **메타버스(Metaverse)** 는 사용자가 디지털 공간에서 콘텐츠·다른 사용자와 상호작용하는 환경 |
| 목적 | 현실·디지털 경험을 연결해 소통·협업·활동 공간 제공 |

### Ⅱ. 상호작용 구조

```text
사용자 입력·공간 인식
        ↓

        ↓
네트워크 상태 동기화
        ↓
다른 사용자·콘텐츠와 공동 활동
```

### Ⅲ. ASF의 4대 유형

| 유형 | 핵심 관계 | 예시 |
|---|---|---|
| 증강현실 | 현실 공간에 디지털 정보 추가 | 위치 기반 안내 |
| 라이프로깅 | 개인 활동의 기록·공유 | 활동 기록 서비스 |
| 거울세계 | 현실 장소·정보의 디지털 재현 | 디지털 지도 |
| 가상세계 | 독립된 디지털 공간의 상호작용 | 온라인 가상공간 |

제언: 서비스가 해결할 이용자 과업을 정한 뒤 유형과 상호작용 방식을 선택.

## 2~4교시 25점 답안

### Ⅰ. 메타버스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **메타버스(Metaverse)** 는 사용자가 디지털 공간에서 콘텐츠·다른 사용자와 상호작용하는 환경 |
| 목적 | 현실·디지털 경험을 연결해 소통·협업·활동 공간 제공 |

| 특징 | 설명 |
|---|---|
| 지속성 | 사용자가 접속하지 않아도 공간과 활동 상태가 이어짐 |
| 상호작용 | 사용자·콘텐츠·환경이 실시간으로 반응 |
| 몰입감 | **XR(Extended Reality)** 기기와 **공간 컴퓨팅(Spatial Computing)** 으로 3차원 경험을 제공 |

### Ⅱ. 상호작용 구조

```text
사용자 입력·공간 인식
        ↓
디지털 장면·아바타 구성
        ↓
네트워크 상태 동기화
        ↓
다른 사용자·콘텐츠와 공동 활동
```

### Ⅲ. 기반 기술과 역할

| 기술 | 역할 |
|---|---|
| XR·공간 컴퓨팅 | 사용자·공간·객체의 인식과 표시 |
| 3D 엔진·디지털 자산 | 장면·객체의 구성과 렌더링 |
| 네트워크·클라우드 | 상태 동기화와 공동 활동 지원 |

### Ⅳ. 적용 한계와 대응

| 한계 | 대응 |
|---|---|
| 지연·기기 무게로 인한 피로와 멀미 | 지연을 줄이고 착용성·시각적 편안함을 시험 |
| 괴롭힘·사생활 침해 | 신고·차단과 개인 안전 경계, 명확한 운영 원칙 적용 |
| 플랫폼 간 자산 호환 부족 | 개방형 자산 형식과 상호운용 규격 검토 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 서로 다른 이용 목적에 같은 상호작용 방식을 적용하면 사용성이 떨어질 수 있음 | 대표 과업 하나로 프로토타입을 시험하고 이용자 반응에 따라 기능 범위 확대 여부를 결정 |
