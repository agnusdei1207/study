## 지식 로드맵 내 현재 위치

지식 위치: 기계학습·대규모 언어모델 → 사전학습 모델 적응 → **파인튜닝**

## 30초 인출

- 본질: **파인튜닝(Fine-tuning)** 은 사전학습 모델을 과업 관련 자료로 추가 학습해 동작을 조정하는 방법
- 메커니즘: 목표·기준선 정의 → 학습 자료 구성 → 전체·일부 매개변수 추가 학습 → 별도 평가·배포

<details>
<summary>핵심 용어</summary>

- **파인튜닝(Fine-tuning)** : 사전학습 모델을 특정 과업·자료로 추가 학습해 모델 동작을 조정하는 방법
- **지도 미세조정(Supervised Fine-Tuning, SFT)** : 입력과 기대 출력 예시를 사용해 지도 학습하는 방식
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)** : 전체 모델보다 일부 추가 매개변수를 학습하는 기법군
- **저순위 적응(Low-Rank Adaptation, LoRA)** : 저차원 매개변수를 추가해 모델을 효율적으로 조정하는 PEFT 방법
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)** : 외부 자료를 검색해 응답 문맥에 제공하는 방식
- **RAFT(Retrieval-Augmented Fine-Tuning)** : 관련·방해 문서를 포함한 검색 문맥에서 근거 활용을 학습하는 접근
</details>

과업·성공 기준 설정

### Ⅲ. 파인튜닝 유형

| 유형 | 학습 신호·특징 | 적용 관점 |
|---|---|---|
| SFT | 입력·기대 출력 예시 | 응답 형식·과업 수행 조정 |
| PEFT·LoRA | 일부 추가 매개변수 학습 | 학습 자원·배포 편의 조정 |
| 선호 기반 조정 | 응답 비교·선호 자료 | 선호 방향의 정책 조정 |
| RAFT | 검색 문맥·관련·방해 자료 | RAG 환경의 근거 활용 학습 |

### Ⅳ. 적용·평가 판단

| 검토 축 | 확인 항목 |
|---|---|
| 자료 품질 | 대표성·권리·중복·오염·민감정보 |
| 성능 | 별도 평가셋의 품질·일반화·회귀 |
| 시스템 | 학습·추론 비용·지연·버전 관리 |
| 대안 비교 | 프롬프트·검색·도구 방식과 개선 효과 비교 |

파인튜닝은 외부 자료를 자동 갱신하지 않으며, RAG도 검색·생성 오류 가능성이 있어 적용 요구에 따른 구분 필요.

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 갱신되는 사실 지식과 안정적인 출력 행동을 같은 방식으로 해결하려 하면 유지 비용이 커질 수 있음 | 최신 근거가 핵심이면 검색 우선, 반복되는 출력 행동 개선이 핵심이면 파인튜닝을 검토하고 각각의 품질·비용 기준선으로 선택 |
