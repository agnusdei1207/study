## Ⅰ. 파인튜닝(Fine-tuning)의 개요

- 개념 : 대규모 코퍼스로 사전 학습(Pre-training)된 파운데이션 모델(Foundation Model)의 가중치를 기반으로, 특정 도메인(의료, 법률, 금융 등)이나 다운스트림 작업(분류, 요약, 질의응답)에 특화된 데이터셋을 투입하여 모델의 전체 또는 일부 파라미터를 추가 미세조정하는 전이 학습(Transfer Learning) 기술.
- 배경 및 필요성 : 제로베이스 사전 학습은 수십억 원 이상의 천문학적 GPU 비용과 수개월의 시간이 소요되므로, 이미 언어적 상식과 구조를 습득한 모델을 가져와 목표 작업에 빠르게 적응시키는 파인튜닝이 엔터프라이즈 AI 구현의 표준 방법론으로 안착함.
- 핵심 목적 : 특정 도메인 용어 및 고유 어투 체화, 정형화된 출력 포맷 준수, 제로샷/퓨샷 대비 월등한 작업 성능 달성, 추론 시 프롬프트 토큰 길이 단축.

## Ⅱ. 파인튜닝(Fine-tuning)의 핵심 아키텍처 및 동작 메커니즘

파인튜닝은 모델의 모든 가중치를 갱신하는 풀 파인튜닝(Full Fine-tuning)과 저차원 행렬만을 삽입하는 파라미터 효율적 기법(PEFT / LoRA)으로 구분됨.

```text
[ LoRA (Low-Rank Adaptation) 핵심 동작 메커니즘 ]

                       입력 벡터 (x, 차원 d)
                                 │
                 ┌───────────────┴───────────────┐
                 │                               │
                 ▼                               ▼
  +-----------------------------+ +-----------------------------+
  | 기존 사전학습 가중치 (W_0)  | | 다운샘플링 행렬 (A) : d x r |
  |   (크기 d x k, 완전 동결)   | |  - Gaussian 초기화          |
  +-----------------------------+ +--------------┬--------------+
                 │                               │ (차원 r, r << d)
                 │                               ▼
                 │                +-----------------------------+
                 │                | 업샘플링 행렬 (B) : r x k   |
                 │                |  - 0 (Zero) 초기화          |
                 │                +--------------┬--------------+
                 │                               │
                 │                               ▼
                 │                저차원 적응 델타 (ΔW = B · A)
                 │                               │
                 └──────────────►(+)◄────────────┘
                                  │
                                  ▼
                     출력 벡터 h = W_0·x + ΔW·x
```

- **Full Fine-Tuning(FFT)** : 모델의 모든 계층 파라미터를 역전파를 통해 업데이트하므로 성능 상한선은 높으나 막대한 VRAM 메모리와 전체 가중치 복사본 저장 공간 필요.
- **LoRA(Low-Rank Adaptation)** : 원래 가중치 `W_0`는 동결하고, 가중치 변화량 `Delta W`를 랭크(Rank r)가 매우 작은 두 저차원 행렬 `B`와 `A`의 곱으로 분해 학습하여 학습 파라미터 수를 크게 감축.
- **QLoRA(Quantized LoRA)** : 사전 학습된 기본 모델을 4비트 정규 부동소수점(NF4)으로 양자화하여 동결하고, 그 위에 16비트 LoRA 어댑터를 올려 단일 상용 GPU에서도 대형 모델 파인튜닝 가능.
- **병합(Merge & Deploy)** : 학습 완료 후 분리된 `Delta W`를 기존 가중치 `W_0`에 단순 행렬 덧셈으로 병합하여 추론 시 추가적인 지연 시간(Zero Latency Overhead) 없이 서빙.

## Ⅲ. 파인튜닝(Fine-tuning)의 세부 구성 요소 및 비교 분석

| 파인튜닝 방식 | 학습 대상 파라미터 비율 | GPU 메모리(VRAM) 요구량 | 장점 | 단점 및 병목 |
| --- | --- | --- | --- | --- |
| **풀 파인튜닝 (Full Fine-tuning)** | 전체 (모든 파라미터 갱신) | 모델 크기 대비 매우 큼 (대용량 GPU 메모리) | 태스크 적응력과 성능 상한선 최고 | 치명적 망각(Catastrophic Forgetting), 막대한 인프라 비용 |
| **LoRA (Low-Rank Adaptation)** | 소수 비율 (어댑터만 갱신) | 모델 크기 수준 | VRAM 대폭 절감, 태스크별 어댑터 교체 서빙 가능 | 하이퍼파라미터(r, alpha) 튜닝 필요 |
| **QLoRA (4-bit Quantized LoRA)** | 소수 비율 (4bit 백본 + LoRA) | 단일 GPU에서도 대형 모델 튜닝 가능 | 극도의 비용 절감, 일반 데스크톱 학습 가능 | 4비트 양자화로 인한 미세한 양자화 오차 존재 |
| **프롬프트 튜닝 (Prompt Tuning)** | 극소수 (가상 소프트 토큰만) | 매우 낮음 | 극도로 가벼움, 모델 불변 | 복합 추론이나 도메인 스타일 체화 성능 부족 |

- 실무 엔터프라이즈 환경에서는 인프라 가성비와 안정성을 고려하여 LoRA 및 QLoRA가 사실상의 표준 기법으로 전면 채택됨.

## Ⅳ. 파인튜닝(Fine-tuning)의 주요 한계점 및 해결 방안

- 기존의 범용 지식과 상식 추론 능력을 상실하는 치명적 망각(Catastrophic Forgetting) :
  - 한계점 : 특정 전문 도메인 데이터로만 집중 파인튜닝할 경우 모델의 기본 코딩이나 번역 능력이 망가지는 현상.
  - 해결 방안 : 기본 가중치를 고정하는 **PEFT** (LoRA) 기법 적용 및 학습 데이터에 일반 대화 데이터셋 일부를 혼합 **리플레이** (Experience Replay).
- 지식의 최신성(Recency) 부재 및 환각(Hallucination) 잔존 :
  - 한계점 : 파인튜닝은 데이터의 통계적 패턴과 스타일을 학습할 뿐, 수시로 변경되는 사실적 지식을 기억하는 데는 비효율적임.
  - 해결 방안 : 파인튜닝은 태스크 형식과 도메인 어투 습득에 집중하고, 최신 사실 지식은 RAG(검색 증강 생성)에 위임하는 하이브리드 아키텍처 구축.
- 고품질 지도학습 데이터셋(SFT Data) 구축에 수반되는 높은 라벨링 비용 :
  - 한계점 : 수만 건의 정제된 입력-출력 쌍을 사람이 수작업 작성하는 데 막대한 시간과 예산 소요.
  - 해결 방안 : 고성능 프론티어 LLM을 활용한 고품질 합성 데이터(Synthetic Data) 생성 및 **Self-Instruct** 기법 적용.

## Ⅴ. 파인튜닝(Fine-tuning) 적용 및 발전을 위한 기술사적 제언

- RAG와 파인튜닝의 역할 분담(Decoupling) 아키텍처 원칙 확립 : '새로운 지식 업데이트는 RAG', '응답 포맷 및 도메인 스타일 정렬은 파인튜닝'으로 명확히 R&R을 정의하여 중복 투자 방지.
- 단일 GPU 환경의 QLoRA 표준 파이프라인 수립 : 고가의 H100 클러스터 없이도 사내 A100/RTX 4090 인프라에서 즉시 파인튜닝을 수행할 수 있는 사내 MLOps 템플릿화.
- 배포 전 회귀 평가(Regression Testing) 스위트 자동화 : 파인튜닝 후 도메인 성능 향상뿐만 아니라 안전성 가이드라인 준수 및 범용 벤치마크 점수 유지 여부를 평가하는 자동 검증 파이프라인 구축.
