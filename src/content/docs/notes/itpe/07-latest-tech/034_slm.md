## 지식 로드맵 내 현재 위치

지식 위치: 언어 모델 → 자원·업무 요구별 모델 구성 → **소형 언어 모델(sLM)**

## 30초 인출

- 본질: **소형 언어 모델(Small Language Model, sLM)** 은 제한된 자원·업무 범위에 맞춰 선택·구성하는 상대적으로 작은 언어 모델
- 메커니즘: 업무 요구 설정 → 후보 모델·배치 환경 선정 → 필요 시 증류·양자화·검색 결합 → 품질·비용 검증

<details>
<summary>핵심 용어</summary>

- **소형 언어 모델(Small Language Model, sLM)** : 상대적으로 적은 자원·업무 범위를 고려해 선택·구성하는 언어 모델; 보편적인 크기 기준이 하나로 정해져 있지는 않음
- **지식 증류(Knowledge Distillation)** : 교사 모델의 출력·정보를 이용해 학생 모델을 학습하는 방식
- **양자화(Quantization)** : 가중치·활성값의 표현 정밀도를 낮춰 저장·계산 자원 요구를 줄이는 방법
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)** : 모델 전체 대신 일부 추가 매개변수를 학습하는 기법군
- **저순위 적응(Low-Rank Adaptation, LoRA)** : 저차원 행렬을 추가해 효율적으로 모델을 업무에 적응시키는 PEFT 기법
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)** : 외부 자료를 검색해 언어 모델 입력 문맥에 제공하는 방식
</details>

업무·품질 기준

### Ⅲ. 경량화·적응 방법

| 방법 | 작동 원리 | 확인 사항 |
|---|---|---|
| 지식 증류 | 교사 모델 출력으로 학생 모델 학습 | 교사 오류·능력 손실 |
| 양자화 | 수치 정밀도를 낮춰 저장·계산량 조정 | 정확도·하드웨어 지원 |
| PEFT·LoRA | 일부 추가 매개변수로 업무 적응 | 자료 품질·업무별 성능 |
| RAG | 관련 자료를 검색해 입력 문맥 보완 | 검색 근거·권한·최신성 |

### Ⅳ. 과업별 평가·운영

| 점검 축 | 확인 내용 |
|---|---|
| 업무 적합성 | 실제 요청 분포와 품질 기준 |
| 시스템 비용 | 목표 장치의 지연·메모리·전력 |
| 위험·신뢰 | 근거 정확성·민감정보·실패 시 처리 |
| 배포 경로 | sLM 응답, 상위 모델 이관 조건, 운영 관찰 |

작은 모델이 모든 과업에서 더 빠르거나 저렴하다고 단정할 수 없음. 목표 장치·요청량·모델 실행 방식에서 종단 간 측정 필요.

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 모든 요청을 같은 크기의 모델이 처리하면 단순 과업의 비용과 복합 과업의 품질 문제가 함께 남을 수 있음 | 실제 요청군별 품질 기준을 정하고, sLM 우선 처리와 상위 모델 이관을 비교 평가해 라우팅 조건 결정 |
