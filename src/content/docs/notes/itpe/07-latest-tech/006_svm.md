- **SVM(Support Vector Machine)** : 분류·회귀에 쓰이는 최대 마진 기반 지도학습 모델
- **서포트 벡터(Support Vector)** : 결정면의 위치에 영향을 주는 경계 가까이의 학습 표본
- **마진(Margin)** : 결정면과 가장 가까운 표본 사이의 거리; 선형 마진 폭은 $2/\|w\|$
- **하드 마진(Hard Margin)** : 선형 분리 가능한 학습 자료를 오분류 없이 분리하는 방식
- **소프트 마진(Soft Margin)** : 일부 마진 위반을 허용하고 그 비용을 최적화하는 방식
- **규제 매개변수 C** : 소프트 마진에서 마진 위반 비용과 넓은 마진 사이의 균형을 조절하는 값

## 1교시 10점 답안

### Ⅰ. SVM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SVM(Support Vector Machine)** 은 분류·회귀를 위한 최대 마진 기반 지도학습 모델 |
| 목적 | 새 표본의 클래스 또는 값을 안정적으로 예측할 결정 기준 마련 |

### Ⅱ. 최대 마진 원리

```text
양성 경계면 (+1)
        │ 마진
결정 초평면
        │ 마진
음성 경계면 (-1)
```

| 핵심 요소 | 뜻 |
|---|---|
| **마진(Margin)** | 결정 초평면과 가장 가까운 학습 표본 사이의 거리 |
| **서포트 벡터(Support Vector)** | 최대 마진 결정면의 위치에 영향을 주는 경계 가까이의 표본 |

### Ⅲ. 오차 허용 방식

| 방식 | 제약 | 적용 판단 |
|---|---|---|
| **하드 마진(Hard Margin)** | 선형 분리 가능한 자료의 오분류 불허 | 이상치가 적고 완전 분리가 가능한 경우 |
| **소프트 마진(Soft Margin)** | 마진 위반을 허용하고 비용 조정 | 잡음·이상치가 있어 완전 분리가 어려운 경우 |

제언: 자료의 분리 가능성과 이상치 영향을 확인한 뒤 마진 방식을 선택하고 검증 자료에서 성능 확인.

## 2~4교시 25점 답안

### Ⅰ. SVM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SVM(Support Vector Machine)** 은 분류·회귀를 위한 최대 마진 기반 지도학습 모델 |
| 목적 | 새 표본의 클래스 또는 값을 안정적으로 예측할 결정 기준 마련 |

### Ⅱ. 최대 마진 원리

```text
양성 경계면 (+1)
        │ 마진
결정 초평면
        │ 마진
음성 경계면 (-1)
```

선형 결정면을 기준으로 양쪽 경계면까지의 폭은 $2/\|w\|$이며, 경계면 가까이의 **서포트 벡터(Support Vector)** 가 결정면에 영향을 주는 학습 표본.

| 핵심 요소 | 뜻 |
|---|---|
| **마진(Margin)** | 결정 초평면과 가장 가까운 학습 표본 사이의 거리 |
| **서포트 벡터(Support Vector)** | 최대 마진 결정면의 위치에 영향을 주는 경계 가까이의 표본 |

### Ⅲ. 하드 마진과 소프트 마진

| 구분 | 하드 마진 | 소프트 마진 |
|---|---|---|
| 분류 조건 | 모든 학습 데이터를 정확히 분리 | 일부 오분류 허용 |
| 결정 기준 | 마진 최대화 | 마진과 오류의 균형 |
| 적용 | 선형 분리 가능·이상치 영향이 작을 때 | 잡음·이상치로 완전 분리가 어려울 때 |
| 조정 변수 | 별도 마진 위반 비용 없음 | 슬랙 변수·규제 매개변수 **C** |

**C** 는 마진 위반에 부여하는 비용과 넓은 마진 사이의 균형을 조정하는 변수.

### Ⅳ. 선택 시 고려사항

| 자료 상태 | 선택·조정 기준 |
|---|---|
| 선형 분리가 가능하고 이상치가 적음 | 하드 마진을 적용할 수 있는지 확인 |
| 이상치 때문에 완전 분리가 어려움 | 소프트 마진으로 오류를 허용 |
| 훈련 오류와 일반화 성능의 균형 필요 | C를 조정하고 검증 데이터로 성능 확인 |
| 특성 단위 차이로 경계가 왜곡됨 | 학습 전에 특성 스케일을 맞춤 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 자료에 이상치가 포함되면 완전 분리를 요구하는 경계가 불안정해질 수 있음 | 검증 자료로 소프트 마진과 C를 비교한 뒤 운영 조건에 맞는 조합 선택 |
