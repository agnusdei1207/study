## 답안 골격
```text
[SVM] ◀━━ 머리: Ⅶ 내 의견 (스케일링 전처리와 커널 트릭 하이퍼파라미터(C, gamma) 베이지안 최적화)
 ┃
 ┣━ Ⅰ 개요 ───── 데이터 분류 경계 모호성 해소 → 마진(Margin)을 최대화하는 최적 결정 초평면 도출
 ┣━ Ⅱ 특징 ───── 구조적 위험 최소화(SRM) · 서포트 벡터만으로 모델 결정(메모리 효율) · 고차원 공간 강건성
 ┣━ Ⅲ 구조 ───── 결정 초평면(w·x + b = 0) + 서포트 벡터 + 마진(2/||w||) + 슬랙 변수(ξ)
 ┣━ Ⅳ 흐름 ───── ① 특성 스케일링 → ② 공간 매핑(커널 함수) → ③ 라그랑주 승수법 최적화 → ④ 초평면 결정
 ┣━ Ⅴ 비교 ───── 하드 마진 SVM vs 소프트 마진 SVM (노이즈 불허 vs 슬랙 허용)
 ┗━ Ⅵ 실무 ───── 비선형 분류 한계 / 특성 단위 차이 왜곡 / 대규모 데이터 연산 비용 O(N^2~N^3)
```
- 필수 키워드: 결정 초평면 · 서포트 벡터 · 마진 최대화 · 하드/소프트 마진 · 슬랙 변수 · 커널 트릭(RBF) · C/gamma
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 초평면 및 마진 구조도 → Ⅴ 하드 vs 소프트 마진 비교 / 25점 = Ⅰ~Ⅶ 전개, 마진 수식($2/\|w\|$)과 커널 트릭 매핑 원리 집중
- 기출: 132회 2교시 2번 `선형 서포트 벡터 머신의 마진 분류 방법 2가지(하드 vs 소프트)` → Ⅲ·Ⅴ

## 한 줄 본질
- 단순 경험적 오차 최소화는 새로운 데이터에 대한 일반화 성능 저하 → 클래스 간 여백(마진)을 최대로 넓히는 결정 초평면을 구성 → 과적합 방지 및 높은 일반화 / 표본 수가 수십만 건 이상일 때 연산 복잡도 급증

## 핵심 그림
```text
      x_2 ^                   [ 소프트 마진 SVM 구조 ]
          |        + (클래스 1)
          |     +      +   [x_+] 서포트 벡터
          |   --------------------  초평면 +1: w·x + b = +1
          |      +   \       /
          |           \  M  /       마진 폭 M = 2 / ||w||
          |============\===/============ 결정 초평면: w·x + b = 0
          |             \ /
          |   --------------------  초평면 -1: w·x + b = -1
          |         -  [x_-] 서포트 벡터
          |      -         - (클래스 2)
          +-----------------------------------> x_1
```

## 핵심 용어
- 서포트 벡터(Support Vector): 결정 초평면에 가장 가까이 위치하여 초평면의 위치와 기울기를 결정짓는 경계 샘플 데이터
- 마진(Margin): 양성 서포트 벡터와 음성 서포트 벡터 사이의 거리($2/\|w\|$)로, 마진을 최대화하는 것이 목적
- 커널 트릭(Kernel Trick): 저차원 공간에서 선형 분리가 불가능한 데이터를 고차원 특징 공간으로 계산 부하 없이 매핑하는 수학적 기법(RBF, 다항 커널 등)

## 핵심 통찰
- 전체 데이터셋 중 오직 서포트 벡터만이 모델을 지탱 → 경계 밖의 나머지 데이터가 아무리 추가되어도 결정 경계는 불변
- 하드 마진은 단 하나의 이상치(Outlier)에도 초평면 형성에 실패하거나 과적합 발생 → 슬랙 변수($\xi$)와 규제 매개변수 $C$를 두는 소프트 마진이 실무 정석
- 거리 기반 알고리즘이므로 입력 특성 간의 스케일 차이가 나면 특정 변수가 마진을 지배 → StandardScaler 전처리 필수

## 이웃 토픽과 구분
- SVM vs 로지스틱 회귀: 로지스틱 회귀는 모든 데이터 포인트를 확률적으로 고려해 조건부 우도를 최대화 / SVM은 경계선 근처의 서포트 벡터만을 사용해 마진을 기하학적으로 최대화

## 문제·원인·대책
- 적용 상황: 고차원 유전자 발현 데이터 기반 질병 분류 모델 구축 시 과적합 및 성능 저하
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 이상치로 인한 분류 경계 왜곡 | 하드 마진 적용으로 모든 샘플의 완벽 분리를 강제 | 소프트 마진 전환 및 슬랙 변수 허용($C$ 값 감소) | 이상치 영향력 억제 및 일반화 성능 개선 |
| 2차원 평면 선형 분리 불가 | 클래스 간 데이터 분포가 비선형(원형/도넛형) 형태 | RBF(방사기저함수) 커널 트릭 적용 | 무한 차원 매핑을 통한 비선형 분리 경계 도출 |
| 데이터 스케일 불균형으로 마진 왜곡 | 단위가 큰 특정 특성이 거리 계산을 독점 | 학습 전 표준화(StandardScaler) 및 MinMax 정규화 | 모든 특성이 균등한 기여도로 초평면 형성에 참여 |

## 이렇게 출제된다
- 제132회 2교시 2번: "머신러닝의 분류 모델인 서포트 벡터 머신(Support Vector Machine) 중 선형 서포트 벡터 머신의 마진(Margin) 분류 방법 2가지를 설명하시오." → 요구 포인트: Ⅴ 하드 마진(오분류 불허) vs 소프트 마진(슬랙 변수 도입)

## 내 의견
- [대규모 정형 데이터 환경에서 LightGBM 대비 학습 비용 고려] SVM은 고차원 텍스트·생체 데이터에서 강력하나, 표본 수 $N$에 대해 $O(N^2 \sim N^3)$의 연산 복잡도를 가져 백만 건 이상의 정형 데이터셋에서는 비효율적 → 나라면: 수만 건 미만의 고차원 특성 분류에 한정하여 SVM을 채택하고, 대규모 테이블 데이터에는 트리 기반 앙상블로 이원화하여 인프라 비용 절감
