## 30초 인출

- 본질: **SVM(Support Vector Machine)** 은 클래스 간의 분리 경계면과 데이터 간의 최단 거리인 마진(Margin)을 최대화하여 미지의 데이터에 대한 일반화 성능을 극대화하는 지도학습 알고리즘
- 메커니즘: 결정 초평면에 가장 인접한 서포트 벡터를 기준으로 마진 폭(2/||w||)을 최대화하는 2차 계획법 최적화를 수행하며, 비선형 데이터는 커널 트릭을 통해 고차원 공간으로 매핑 분리
- 통찰: 이상치에 취약한 하드 마진의 과적합 문제를 해결하기 위해 슬랙 변수와 규제 하이퍼파라미터(C)를 도입한 소프트 마진 및 RBF 커널 감마 파라미터 교차검증 필수

<details><summary>핵심 용어</summary>

- **서포트 벡터 (Support Vector)** : 결정 초평면(Decision Hyperplane)의 위치와 기울기를 결정짓는 데 관여하는 마진 경계선 상의 가장 가까운 학습 데이터 포인트.
- **마진 (Margin)** : 결정 초평면과 서포트 벡터 사이의 수직 거리로, 두 클래스 간의 분리 대역 폭 (`2 / ||w||`).
- **하드 마진 (Hard Margin)** : 모든 학습 데이터가 오분류 없이 마진 바깥쪽에 완벽하게 선형 분리되도록 강제하는 제약 조건.
- **소프트 마진 (Soft Margin)** : 이상치나 노이즈로 인한 비선형 분포 시 슬랙 변수(ξ)를 통해 마진 침범 및 오분류를 일부 허용하는 방식.
- **커널 트릭 (Kernel Trick)** : 저차원 공간의 비선형 데이터를 고차원 특징 공간으로 명시적 좌표 변환 없이 내적 연산만으로 고차원 선형 분리를 수행하는 기법 (RBF, Polynomial 등).

</details>

## 2~4교시 25점 답안

## Ⅰ. SVM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SVM(Support Vector Machine)** 은 서로 다른 클래스의 데이터 포인트 집합을 가장 큰 여백(Margin)으로 갈라놓는 최적의 결정 초평면(Optimal Hyperplane)을 찾는 지도학습 기반 기계학습 모델 |
| 목적 | 구조적 위험 최소화(SRM) 원칙에 입각하여 과적합을 방지하고 새로운 테스트 데이터에 대한 일반화 예측 정확도 극대화 |

## Ⅱ. SVM의 핵심 특징 및 최적화 속성

| 구분 | 핵심 특징 | 수학적 및 공학적 세부 원리 |
|---|---|---|
| **최대 마진 원리** | 일반화 오차 최소화 | 결정면과 데이터 간 거리 마진 `2 / ||w||`를 최대화하여 `1/2 ||w||^2` 최소화 문제로 공식화 |
| **서포트 벡터 의존성** | 모델 희소성(Sparsity) | 전체 데이터가 아닌 마진 경계 상의 소수 서포트 벡터만으로 경계 결정, 데이터 압축 효과 |
| **볼록 최적화 (Convex)** | 전역 최적해(Global Optima) 보장 | 목적함수가 2차 형식(Quadratic)이고 제약식이 선형이므로 지역 최솟값(Local Minima) 배제 |
| **커널 트릭 (Kernel Trick)** | 고차원 비선형 확장 | 메르서 정리(Mercer's Theorem)에 기반하여 내적 연산 `K(x, z) = <Φ(x), Φ(z)>`으로 계산 복잡도 억제 |

## Ⅲ. SVM 결정 초평면 아키텍처 및 커널 공간 변환 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ SVM 선형 결정 초평면 및 마진 구조 ]                 │
└────────────────────────────────────────────────────────────────────────┘
                                    ▲ x2
                                    │
                  [ +1 클래스 ]      │
                     o              │        /  양성 경계면 (w·x + b = +1)
                 o      (o) <───────┼───────/─  서포트 벡터 (Support Vector)
                     o     \        │      /
                            \       │     /
                             ───────┼────/───  최적 결정 초평면 (w·x + b = 0)
                            / 마진   │   /
                 (x) <──────        │  /
             x       x              │ /        음성 경계면 (w·x + b = -1)
          [ -1 클래스 ]             │/
 ───────────────────────────────────┼───────────────────────────► x1
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 비선형 데이터의 커널 트릭 (Kernel Trick) 고차원 매핑 메커니즘 ]        │
│                                                                        │
│   저차원 비선형 입력 공간 (2D)               고차원 선형 분리 공간 (3D)  │
│   [동심원 형태의 비선형 분포] ──(Φ(x) 변환)──> [초평면으로 선형 분리 가능]   │
│   계산: Φ(x) 직접 계산 대신 커널 함수 K(x_i, x_j) = exp(-γ||x_i-x_j||^2) 내적 대체 │
└────────────────────────────────────────────────────────────────────────┘
```

| 수학적 구성요소 | 수식 정의 | 공학적 의미 및 역할 |
|---|---|---|
| **결정 초평면** | `w·x + b = 0` | 클래스(+1, -1)를 분할하는 d-1 차원의 판별식 |
| **마진 너비** | `Margin = 2 / ||w||` | 경계선 사이의 물리적 거리, w 크기가 작을수록 마진 확대 |
| **목적 함수 (라그랑주)** | `min 1/2 ||w||^2` s.t. `y_i(w·x_i + b) >= 1` | 제약조건을 만족하며 마진을 극대화하는 볼록 2차 최적화 |
| **KKT 조건** | `α_i [ y_i(w·x_i + b) - 1 ] = 0` | 서포트 벡터(`α_i > 0`)만이 결정 평면 도출에 기여함을 입증 |

## Ⅳ. 하드 마진과 소프트 마진 비교

| 비교 항목 | 하드 마진 (Hard Margin) | 소프트 마진 (Soft Margin) |
|---|---|---|
| **분류 허용 기준** | 모든 데이터를 100% 완벽하게 분리 | 일부 오분류 및 마진 내부 침범 허용 |
| **슬랙 변수 (ξ)** | `ξ_i = 0` (불허) | `ξ_i >= 0` (마진 위반 정도 허용) |
| **최적화 목적식** | `min 1/2 ||w||^2` | `min 1/2 ||w||^2 + C Σ ξ_i` |
| **규제 변수 C 효과** | 미사용 | C 증가: 오차 징벌 강화(과적합) / C 감소: 마진 확대(과소적합) |
| **이상치 민감도** | 극도로 취약 (단 1개 이상치로 경계 왜곡) | 이상치 잡음에 강건(Robust)한 경계 생성 |
| **실제 적용 환경** | 노이즈 없는 엄격한 선형 분리 가능 데이터 | 실세계의 노이즈 포함 복잡 비선형 데이터 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 훈련 데이터 수(N) 증가 시 라그랑주 쌍대 문제 해결 시간 복잡도가 $O(N^2 \sim N^3)$로 급증 | 대규모 데이터를 작은 청크로 분할하여 최적화하는 SMO(Sequential Minimal Optimization) 기법 적용 및 선형 LinearSVM 근사 라이브러리 채택 |
| 특성(Feature)별 스케일 단위 차이가 극심할 경우 거리 기반 마진 계산이 특정 축으로 왜곡 | 학습 전 StandardScaler 또는 MinMaxScaler를 필수 적용하여 모든 차원의 스케일을 정규화 |

## Ⅵ. 제언

실무 머신러닝 파이프라인에서 데이터 스케일링을 선행하고, 하이퍼파라미터(C, γ)의 그리드 서치(Grid Search) 및 층화 K-Fold 교차검증을 통한 최적 커널 파라미터 자동 탐색 구조 구축.

```text
[ 원천 특징 데이터 ]
         │
         ▼
[ StandardScaler 정규화 파이프라인 ]
         │
         ▼
[ 하이퍼파라미터 공간 탐색기 (GridSearchCV) ]
   ├── RBF 커널: C (0.1 ~ 100) × γ (0.001 ~ 1)
   └── Stratified K-Fold (k=5) 기반 교차검증
         │
         ▼
[ 최적 C*, γ* 기반 서포트 벡터 추출 및 최종 추론 모델 확정 ]
```

| 구분 | 기본 선형 SVM 모델 | 제언: RBF 커널 + 튜닝 파이프라인 |
|---|---|---|
| **비선형 적응** | 복잡한 곡면 경계 분리 불가 | 고차원 힐베르트 공간 투영으로 복잡한 비선형 결정 경계 형성 |
| **노이즈 제어** | 고정 마진으로 이상치 오버피팅 발생 | 규제 매개변수 C 튜닝으로 마진 폭과 분류 오차의 최적 절충 |
| **일반화 성능** | 단순 데이터에만 유효 | 교차검증을 통한 미지의 테스트 셋 F1-Score 극대화 |
