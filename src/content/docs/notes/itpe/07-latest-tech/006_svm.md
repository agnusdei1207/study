## Ⅰ. SVM(Support Vector Machine)의 개요

- 개념 : 고차원 특징 공간에서 서로 다른 두 클래스를 완벽히 분리하는 무수히 많은 **초평면** (Hyperplane) 중, 클래스 간의 거리인 **마진** (Margin)을 최대화(Max-Margin)하는 최적의 **결정 경계** (Optimal Decision Boundary)를 도출하는 지도학습 알고리즘.
- 배경 및 필요성 : **경험적 위험 최소화** (ERM)에 의존하는 일반 신경망의 과적합 문제를 극복하기 위해, 통계적 학습 이론 기반의 **구조적 위험 최소화** (SRM) 원칙을 적용하여 우수한 일반화 성능을 보장하고자 고안됨.
- 핵심 목적 : 일반화 오차 최소화, 이상치에 강건한 결정 경계 형성, 커널 트릭(Kernel Trick)을 통한 비선형 분류 및 회귀(SVR) 문제의 수학적 해결.

## Ⅱ. SVM(Support Vector Machine)의 핵심 아키텍처 및 동작 메커니즘

SVM은 결정 경계에 가장 가까이 위치한 **서포트 벡터** (Support Vector)들만을 기준으로 마진을 계산하며, 비선형 공간은 고차원 재생 핵 힐베르트 공간(RKHS)으로 매핑하여 선형 분리함.

```text
[ 선형 최대 마진 결정 경계 및 서포트 벡터 구조 ]

                    특징 2 (X2)
                         ▲
                         │       Class A (+)
                         │        +    +     + (Support Vector)
                         │          +    +   /
        Negative Plane ──┼──────────────────/───── w·x - b = -1
                         │                 /
        Decision Boundary┼────────────────/─────── w·x - b = 0  (최적 결정 초평면)
                         │               /  ▲
        Positive Plane ──┼──────────────/───┼───── w·x - b = +1
                         │             /    │ 마진 (Margin = 2 / ||w||)
                         │   - (Support     │
                         │      Vector)     ▼
                         │     -    -    -   Class B (-)
                         +──────────────────────────► 특징 1 (X1)
```

- **초평면 수식** : 결정 경계는 `w·x - b = 0`으로 정의되며, 클래스는 `y_i(w·x_i - b) >= 1`의 제약식을 만족해야 함.
- **마진 최대화** : 마진 크기인 `2 / ||w||`를 최대화하는 문제는 목적 함수 `(1/2)||w||^2`을 최소화하는 볼록 2차 계획법(Convex Quadratic Programming)으로 귀결.
- **소프트 마진과 슬랙 변수(xi)** : 이상치 허용을 위해 슬랙 변수 `xi`와 정규화 하이퍼파라미터 `C`를 도입하여 마진 최대화와 분류 오류 간의 절충점 제어.
- **커널 트릭(Kernel Trick)** : 저차원에서 선형 분리가 불가능한 데이터를 명시적 좌표 변환 없이 내적 계산 `K(x, z) = phi(x)·phi(z)`만으로 고차원에서 선형 분리.

## Ⅲ. SVM(Support Vector Machine)의 세부 구성 요소 및 비교 분석

| 커널 함수 종류 | 수학적 표현식 | 주요 특징 및 적합 도메인 | 하이퍼파라미터 |
| --- | --- | --- | --- |
| **선형 커널 (Linear)** | `K(x, z) = x^T · z` | 특징 차원이 매우 큰 고차원 희소 데이터에 적합 (속도 최우수) | C |
| **RBF / 가우시안 (Radial Basis)** | `K(x, z) = exp(-gamma * \|\|x - z\|\|^2)` | 무한 차원 매핑 효과, 비선형 데이터 분류의 기본 표준 커널 | C, gamma |
| **다항식 커널 (Polynomial)** | `K(x, z) = (gamma * x^T · z + r)^d` | 특징 간의 상호작용 차수를 반영하는 이미지 및 신호 처리 | C, gamma, degree(d), coef0 |
| **시그모이드 (Sigmoid)** | `K(x, z) = tanh(gamma * x^T · z + r)` | 다층 퍼셉트론(MLP) 인공신경망의 활성화 함수 모사 | C, gamma, coef0 |

- 선형 커널은 텍스트 분류와 같이 특징 수가 샘플 수보다 많은 경우에 적합하며, RBF 커널은 특징 수가 적고 복잡한 비선형 경계가 필요한 경우 탁월한 성능을 발휘함.

## Ⅳ. SVM(Support Vector Machine)의 주요 한계점 및 해결 방안

- 대용량 데이터셋(N > 100,000) 학습 시 O(N^2)~O(N^3)의 계산 복잡도로 인한 메모리 병목 :
  - 한계점 : 데이터 수가 증가할수록 그람 행렬(Gram Matrix) 연산 및 최적화 시간이 기하급수적으로 폭증하여 대규모 데이터 처리 불가.
  - 해결 방안 : 전체 문제를 작은 서브셋으로 분할 최적화하는 **SMO** (Sequential Minimal Optimization) 알고리즘 적용 및 선형 근사 SGDClassifier 활용.
- 노이즈 및 이상치에 따른 하이퍼파라미터(C, gamma)의 극심한 민감도 :
  - 한계점 : 하이퍼파라미터 설정에 따라 결정 경계가 요동치며 과적합(Overfitting) 또는 과소적합(Underfitting)이 쉽게 발생.
  - 해결 방안 : **베이지안 최적화** (Bayesian Optimization) 또는 무작위 탐색(Random Search) 기반의 K-Fold 교차 검증 파이프라인 자동화.
- 본질적인 이진 분류기로서 다중 클래스(Multi-class) 분류 시의 비효율성 :
  - 한계점 : K개의 클래스를 분류하기 위해 다수의 이진 SVM 모델을 조합해야 하므로 추론 및 훈련 리소스 낭비.
  - 해결 방안 : **One-vs-Rest** (OvR) 전략을 기본 채택하여 모델 개수를 K개로 억제하거나 계층형 트리 분류기 결합.

## Ⅴ. SVM(Support Vector Machine) 적용 및 발전을 위한 기술사적 제언

- 특징 : 스케일링(Feature Scaling)의 필수적 전처리 파이프라인 강제 : 거리 기반으로 마진을 계산하는 알고리즘 특성상 StandardScaler, MinMaxScaler를 미적용할 경우 특정 특성에 경계가 종속되므로 자동 스케일러 파이프라인 필수화.
- 고차원 임베딩 벡터의 경량 최종 분류 헤드(Classifier Head)로의 재조명 : 거대 딥러닝 백본(ResNet, BERT)에서 추출된 고차원 잠재 벡터를 소프트맥스 대신 선형 SVM으로 분류하여 마진 최대화 이점 획득.
- SHAP 및 서포트 벡터 가중치 시각화를 통한 XAI 신뢰성 확보 : 결정 경계를 구성하는 서포트 벡터 샘플의 기여도를 분해하여 금융 신용평가, 의료 진단 등 설명가능성이 필수적인 도메인에 적용.
