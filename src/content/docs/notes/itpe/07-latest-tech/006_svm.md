## 연관 키워드

- SVM, 초평면(Hyperplane), 마진(Margin), 서포트 벡터(Support Vector), 커널 트릭(Kernel Trick)
- 소프트 마진, 슬랙 변수, RBF 커널, SMO, One-vs-Rest, 구조적 위험 최소화

## Ⅰ. SVM(Support Vector Machine)의 개요

- 핵심 요약 : 두 클래스를 가르는 무수한 초평면 중 마진을 최대화하는 결정 경계를 찾는 지도학습 알고리즘.
- 개념 : 고차원 특징 공간에서 두 클래스를 분리하는 **초평면** (Hyperplane) 중, 클래스 사이 거리인 **마진** (Margin)을 최대로 하는 **최적 결정 경계** (Optimal Decision Boundary)를 도출하는 **SVM** (Support Vector Machine) 지도학습 알고리즘.
- 배경 및 필요성 : 경험적 위험 최소화(ERM)에 기대는 일반 신경망은 과적합 위험이 있어, 통계적 학습 이론의 **구조적 위험 최소화** (Structural Risk Minimization) 원칙으로 일반화 성능을 확보하려는 목적으로 고안됨.
- 주요 목적 : 일반화 오차 최소화, 이상치에 강건한 경계 형성, 커널 트릭을 통한 비선형 분류와 회귀(SVR, Support Vector Regression) 문제 해결.

## Ⅱ. SVM(Support Vector Machine)의 특징 및 장점

- 핵심 요약 : 마진 최대화 원리와 커널 트릭이 결합되어, 적은 수의 경계 샘플로 일반화가 좋은 비선형 분류기를 만드는 방식.

1. **서포트 벡터** (Support Vector) : 결정 경계에 가장 가까운 샘플만으로 마진을 계산 → 대부분의 데이터를 무시하고도 경계를 결정하므로 경계 구조가 단순해짐.
2. **마진 최대화** (Max-Margin) : 마진 2/‖w‖를 최대화하는 문제가 (1/2)‖w‖²를 최소화하는 볼록 2차 계획법으로 귀결 → 전역 최적해 보장.
3. **커널 트릭** (Kernel Trick) : 고차원 내적 K(x, z) = φ(x)·φ(z)를 명시적 좌표 변환 없이 계산 → 비선형 경계를 낮은 계산 비용으로 학습.
4. **소프트 마진** (Soft Margin) : 슬랙 변수 ξ와 정규화 파라미터 C로 마진과 오분류의 절충을 조절 → 노이즈가 섞인 데이터에서도 안정적 경계 확보.

## Ⅲ. SVM(Support Vector Machine)의 구조 (흐름)

- 핵심 요약 : 서포트 벡터로 마진을 정하는 선형 학습 흐름과, 커널로 비선형 공간을 선형처럼 다루는 흐름의 결합.
- 결정 경계는 w·x − b = 0으로 정의되며, 학습 샘플은 y_i(w·x_i − b) ≥ 1 제약을 만족해야 함.

```text
[ 최대 마진 학습 흐름 ]

학습 데이터 입력
   ↓
서포트 벡터(경계 근접 샘플) 식별
   ↓
마진 2/‖w‖ 최대화 (볼록 2차 계획)
   ↓
결정 경계 w·x − b = 0 확정
```

```text
[ 비선형 데이터 처리 흐름 ]

저차원에서 선형 분리 불가
   ↓
커널 함수 K(x, z)로 내적 계산
   ↓
고차원 공간에서 선형 분리
   ↓
원래 공간에서는 비선형 경계로 보임
```

## Ⅳ. SVM(Support Vector Machine)의 비교

- 핵심 요약 : 커널 선택은 데이터 차원과 비선형성의 정도에 따라 결정되며, RBF는 비선형 분류의 기본 선택지로 쓰임.

| 커널 함수 | 수식 | 주요 특징과 적합 도메인 | 하이퍼파라미터 |
| --- | --- | --- | --- |
| 선형 (Linear) | K(x, z) = xᵀz | 특징 차원이 매우 큰 희소 데이터, 학습 속도 최우수 | C |
| RBF / 가우시안 (Radial Basis Function) | K(x, z) = exp(−γ‖x − z‖²) | 무한 차원 매핑 효과, 비선형 분류의 기본 커널 | C, γ |
| 다항식 (Polynomial) | K(x, z) = (γxᵀz + r)^d | 특징 간 상호작용 차수를 반영하는 영상·신호 처리 | C, γ, d, r |
| 시그모이드 (Sigmoid) | K(x, z) = tanh(γxᵀz + r) | 다층 퍼셉트론의 활성화 함수를 모사 | C, γ, r |

- 선형 커널은 텍스트 분류처럼 특징 수가 샘플 수보다 많은 경우에 적합하고, RBF 커널은 특징 수가 적고 복잡한 경계가 필요한 경우에 강점을 보임.

## Ⅴ. SVM(Support Vector Machine)의 한계와 방안

- 핵심 요약 : 대용량 학습의 계산 비용, 하이퍼파라미터 민감도, 다중 클래스 비효율을 근사 기법과 자동 탐색으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 대용량 데이터의 계산 병목 | 학습 복잡도가 샘플 수에 대해 O(N²)~O(N³) 수준이라 데이터 증가 시 시간·메모리 급증 | 부분 문제로 나눠 푸는 **SMO** (Sequential Minimal Optimization) 적용, 대용량에는 선형 근사 SGDClassifier 활용 | 학습 시간, 메모리 사용량 |
| 하이퍼파라미터 민감도 | C와 γ 설정에 따라 경계가 요동쳐 과적합 또는 과소적합 발생 | **베이지안 최적화** (Bayesian Optimization)나 무작위 탐색을 K-Fold 교차 검증과 결합한 자동 튜닝 | 교차 검증 점수 분산 |
| 본질적인 이진 분류기 | K개 클래스 분류에 다수의 이진 SVM을 조합해야 해 자원 낭비 | **One-vs-Rest** (OvR) 전략으로 모델 수를 K개로 제한하거나 계층형 트리 결합 | 추론 지연, 모델 수 |

## Ⅵ. SVM(Support Vector Machine)에 대한 기술사적 제언

- 핵심 요약 : 전처리 파이프라인의 스케일링 강제, 딥러닝 백본과의 결합, 설명가능성 확보를 SVM 운영의 기본 원칙으로 삼는 방향.
- 스케일링 : 거리 기반으로 마진을 계산하므로 StandardScaler나 MinMaxScaler를 파이프라인 단계에 고정하여 특정 특성에 경계가 치우치는 일을 방지해야 함.
- 분류 헤드 : 거대 백본(ResNet, BERT)에서 추출한 고차원 임베딩을 소프트맥스 대신 선형 SVM으로 분류하는 구성은 경량 분류 헤드로서 여전히 유효함.
- 설명가능성 : **SHAP** (SHapley Additive exPlanations)으로 서포트 벡터 샘플의 기여도를 분해해 금융 신용평가나 의료 진단처럼 설명이 필수인 도메인에 적용.

## Ⅶ. 결론

- 핵심 요약 : SVM은 마진 최대화와 커널 트릭으로 일반화 성능을 확보하는 고전적이면서 여전히 쓰이는 분류기.
- 시사점 : 대규모 데이터에는 근사 기법을, 임베딩 기반 분류에는 헤드로서의 활용을 고려하면 적용 범위를 넓힐 수 있음.
