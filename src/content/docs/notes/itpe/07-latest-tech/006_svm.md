## 30초 인출

- 본질: **SVM(서포트 벡터 머신)**은 두 클래스 사이의 간격이 넓은 분류 경계를 찾는 모델이다.
- 메커니즘: 경계에 가까운 서포트 벡터를 기준으로 마진을 정하고, 오류 허용 여부에 따라 하드·소프트 마진을 선택한다.

<details><summary>핵심 용어</summary>

- **서포트 벡터(Support Vector)**: 분류 경계에 가까워 초평면의 위치를 결정하는 학습 데이터다.
- **마진(Margin)**: 분류 경계와 가까운 데이터 사이의 간격이다.
- **하드 마진**: 모든 학습 데이터를 오류 없이 분리하도록 요구하는 방법이다.
- **소프트 마진**: 일부 오분류를 허용해 마진과 오류 사이의 균형을 조절하는 방법이다.

</details>

## 1교시 10점 답안

### 1. 정의·목적

- 정의: **SVM(서포트 벡터 머신)** 은 두 클래스 사이의 간격이 가장 넓은 경계를 찾는 분류 모델이다.
- 목적: 경계에 가까운 데이터인 서포트 벡터를 기준으로 분류 성능을 높인다.

### 2. 핵심 구조

| 핵심 용어 | 역할·의미 |
|---|---|
| 서포트 벡터(Support Vector) | 결정 초평면에 가장 가까이 위치하여 초평면의 위치와 기울기를 결정짓는 경계 샘플 데이터 |
| 마진(Margin) | 양성 서포트 벡터와 음성 서포트 벡터 사이의 거리($2/\|w\|$)로, 마진을 최대화하는 것이 목적 |
| 소프트 마진 | 일부 오분류를 허용해 이상치에 대한 민감도를 줄이는 방법 |

### 3. 제언

이상치가 있는 데이터에는 소프트 마진을 검토하고 규제 매개변수 C를 검증 데이터로 조정한다.

## 2~4교시 25점 답안

## Ⅰ. 개요와 핵심 용어

**SVM(서포트 벡터 머신)** 은 두 클래스 사이의 간격이 가장 넓은 경계를 찾는 분류 모델이다. 선형 SVM에서는 오분류 허용 여부에 따라 하드 마진과 소프트 마진을 구분한다.

| 핵심 용어 | 역할·의미 |
|---|---|
| 서포트 벡터(Support Vector) | 결정 초평면에 가장 가까이 위치하여 초평면의 위치와 기울기를 결정짓는 경계 샘플 데이터 |
| 마진(Margin) | 양성 서포트 벡터와 음성 서포트 벡터 사이의 거리($2/\|w\|$)로, 마진을 최대화하는 것이 목적 |
| 하드 마진 | 모든 학습 데이터를 정확히 분리하도록 요구하는 방법 |
| 소프트 마진 | 일부 오분류를 허용하고 마진 크기와 분류 오류를 함께 조절하는 방법 |

## Ⅱ. 핵심 구조와 작동

| 구분 | 하드 마진 | 소프트 마진 |
|---|---|---|
| 분류 조건 | 모든 학습 데이터를 정확히 분리 | 일부 오분류 허용 |
| 결정 기준 | 마진 최대화 | 마진과 오류의 균형 |
| 적용 | 선형 분리가 가능하고 이상치가 적을 때 | 잡음·이상치로 완전 분리가 어려울 때 |
| 조정 변수 | 별도 오분류 허용 변수 없음 | 슬랙 변수와 규제 매개변수 C |

하드 마진은 완전 분리를 요구하므로 이상치에 취약하다. 소프트 마진은 슬랙 변수로 오류를 허용하며, C로 오류에 대한 제약 수준을 조절한다.

## Ⅲ. 적용 문제와 대응

| 관찰 현상 | 마진 선택·조정 |
|---|---|
| 선형 분리가 가능하고 이상치가 적음 | 하드 마진을 적용할 수 있는지 확인 |
| 이상치 때문에 완전 분리가 어려움 | 소프트 마진으로 오류를 허용 |
| 훈련 오류와 일반화 성능의 균형 필요 | C를 조정하고 검증 데이터로 성능 확인 |
| 특성 단위 차이로 경계가 왜곡됨 | 학습 전에 특성 스케일을 맞춤 |

## Ⅳ. 제언

| 문제 | 제언 |
|---|---|
| 이상치가 있는 데이터에 하드 마진을 그대로 적용하면 경계가 흔들릴 수 있음 | 소프트 마진을 검토하고 C를 검증 데이터로 조정 |
