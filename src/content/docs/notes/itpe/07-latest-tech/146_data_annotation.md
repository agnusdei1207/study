## 한 줄 본질
- 인공지능이 사물을 정확히 이해하도록 원천 이미지·영상 데이터 속 객체에 이름표(메타데이터)를 달아주는 작업으로, 정밀도와 라벨링 비용 간의 트레이드오프를 오토 라벨링으로 극복하는 AI 필수 공정

## 핵심 용어
- 바운딩 박스(Bounding Box): 객체를 감싸는 최소 크기의 직사각형 좌표(xmin, ymin, xmax, ymax)를 지정하여 객체의 위치와 클래스를 식별하는 가장 범용적인 기법
- 시맨틱 분할(Semantic Segmentation): 이미지 내의 모든 픽셀을 개별 클래스로 분류하는 기법으로, 객체 간의 경계를 픽셀 단위로 정확히 분할
- 능동 학습(Active Learning): 모델이 예측 확신도(Confidence)가 낮은 모호한 데이터만 선별하여 인간 작업자에게 라벨링을 요청함으로써 라벨링 비용을 최소화하는 기법

## 핵심 통찰
- "데이터 중심 AI(Data-Centric AI)의 출발점": 모델 알고리즘 튜닝보다 100건의 오라벨링 정제와 고품질 어노테이션이 모델 성능을 비약적으로 끌어올림
- 오토 라벨링(Auto-Labeling)과 HITL의 융합: Foundation 모델이 1차 라벨링을 수행하고 인간 검수자가 수정(Review)만 담당하여 비용 70% 절감
- 일관성 검증 메트릭 도입: 작업자 간 라벨링 일치도를 측정하는 교집합 비율(IoU: Intersection over Union)과 Fleiss' Kappa 통계치를 통한 품질 관리 필수

## 이웃 토픽과 구분
- 데이터 어노테이션 vs 데이터 증강(Data Augmentation): 어노테이션은 원천 데이터에 정답 라벨(Ground Truth)을 부여하는 작업 / 증강은 회전, 반전, 노이즈 추가 등으로 데이터 수량과 다양성을 뻥튀기하는 작업

## 문제·원인·대책
- 적용 상황: 자율주행 차량 학습용 수백만 장 도로 이미지 어노테이션 프로젝트 수행
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 작업자마다 표지판 모서리 지정 기준이 달라 모델 경계 인식률 저하 | 표준 작업 지침서 부재 및 주관적 경계 해석 | 픽셀 단위 라벨링 가이드라인 수립 및 다수 작업자 교차 검증(Cross-validation) | 라벨링 일치도(IoU) 0.9 이상 달성 |
| 수작업 인건비 폭증 및 전체 개발 일정 지연 | 100% 수작업 크라우드소싱 의존 | 초경량 검출 모델 기반 사전 라벨링(Pre-labeling) 후 인간 검수 체계 전환 | 작업 공수 60% 단축 및 납기 준수 |
| 야간·폭우 등 희귀 도로 상황 데이터 라벨 부족 | 주간 일반 주행 데이터 위주의 수집 편향 | 능동 학습 기반 불확실성 샘플링 및 생성형 AI 기반 합성 데이터(Synthetic Data) 보강 | 악천후 객체 인식 재현율(Recall) 25% 향상 |

## 내 의견
- [기초 모델(Foundation Model) 기반 제로샷 세그멘테이션과 능동 학습의 통합] 메타의 SAM(Segment Anything Model)과 같은 고성능 파운데이션 비전 모델을 어노테이션 파이프라인에 전면 배치해야 함 → 나라면: 작업자가 점 하나만 찍어도 객체 외곽 전체가 자동 폴리곤으로 따지는 SAM 기반 인터랙티브 라벨링 툴을 도입하고, 신뢰도가 0.85 이하인 엣지 케이스만 전문 도메인 검수자에게 라우팅하는 지능형 MLOps 데이터 파이프라인을 구축하여 비용을 80% 절감하고 품질 균일성을 극대화
