## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 학습 데이터 → 데이터 어노테이션

## 30초 인출

- 본질: **데이터 어노테이션은** 원천 자료에 분류·경계·관계 등 학습·평가에 필요한 의미 정보를 부여하는 작업
- 메커니즘: 작업 정의·지침 수립 → 표본 라벨링 → 검수·의견 조정 → 데이터셋 확정·버전 관리
- 통찰: 한계: 모호한 사례의 판정 차이가 라벨 일관성과 모델 평가를 왜곡 → 방안: 골드셋의 불일치 유형을 검수하고 지침·예외 기준 개정

<details><summary>핵심 용어</summary>

- **라벨링 지침** : 클래스·경계·모호 사례의 판정 기준
- **상호 주석 일치도** : 여러 작업자가 같은 자료에 부여한 표식의 일치 수준
- **골드셋** : 작업·검수 품질을 확인하기 위한 기준 표본

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 어노테이션의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 어노테이션은** 원천 자료에 분류·경계·관계 등 학습·평가에 필요한 의미 정보를 부여하는 작업 |
| 목적 | 모델 목표에 맞는 정답 자료와 검증 가능한 품질 기준 확보 |

## Ⅱ. 지침·주석·검수의 품질 순환 구조

```text
과제·클래스 정의 → 라벨링 지침·골드셋
                         │ 작업자 교육
                         ▼
원천 자료 ── 복수 작업자 주석 ── 불일치 검수·합의
                                   │ 모호 사례
                                   └────→ 지침 개정 ─┐
                                                    │
                         확정 라벨·지침 버전 연결 ←──┘
```

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 요구 정의 | 모델 과제와 주석 단위 명시 | 모호한 클래스 경계 |
| 지침·교육 | 예시와 예외 기준 공유 | 작업자 해석 차이 |
| 작업·검수 | 이중 주석·표본 검수·의견 조정 | 속도 중심 작업의 오류 |
| 확정·추적 | 원본·라벨·지침의 버전 연결 | 수정 이력·동의 범위 누락 |

## Ⅲ. 자동 주석과 사람 주석 비교

| 구분 | 차이 | 적용 판단 |
|---|---|---|
| 자동 주석 | 기존 모델로 초기 표식 제안 | 오류를 사람 검수로 확인 |
| 사람 주석 | 맥락과 예외를 직접 판정 | 작업자 편차·비용 관리 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모호 사례가 지침 없이 작업자마다 다르게 표시되어 모델 평가 왜곡 | 대표 예외를 골드셋에 넣고 불일치 유형을 지침 개정에 반영 |

## Ⅴ. 제언

모델 오류에 영향이 큰 라벨부터 골드셋과 이중 주석 비율을 정하고 지침 버전별 품질 변화를 추적.

## 출제 이력과 검증 출처

- 확인한 제132~140회 정보관리기술사 공식 문제지에서 표제어 직접 출제 미확인; 그 밖의 회차는 원문 미대조
- [NIST 데이터 주석 연구](https://www.nist.gov/publications/human-loop-technical-document-annotation-developing-and-validating-system-provide)
