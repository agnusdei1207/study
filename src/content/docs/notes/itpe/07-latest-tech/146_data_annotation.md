## 30초 인출

- 본질: **데이터 어노테이션** (Data Annotation)은 인공지능 지도학습 및 정렬(Alignment)을 위해 이미지·텍스트·음성 등 비정형 원천 데이터에 레이블, 바운딩 박스, 시맨틱 태그 등 정답 메타데이터를 주석하는 공학적 가공 기술
- 메커니즘: 원천 수집 및 정제 → 라벨링 가이드라인 수립 → 자동 사전 라벨링(Auto-labeling) → 인간 검수(HITL) 및 상호 일치도(IAA) 평가 → 데이터셋 패키징
- 통찰: 작업자의 주관적 편차로 인한 라벨 노이즈가 모델의 일반화 성능을 저하시키므로 골드 표준셋 기반 상호 일치도(Fleiss' Kappa) 검증과 능동 학습(Active Learning) 파이프라인 구축 필요

<details><summary>핵심 용어</summary>

- **데이터 어노테이션 (Data Annotation)** : AI 모델이 학습할 수 있도록 원천 데이터에 정답(Ground Truth) 속성을 부여하는 작업.
- **바운딩 박스 (Bounding Box)** : 컴퓨터 비전에서 객체의 위치를 직사각형 좌표값(X, Y, W, H)으로 지정하는 기법.
- **시맨틱 세그멘테이션 (Semantic Segmentation)** : 이미지 내의 모든 픽셀을 해당 클래스별로 분할하여 의미를 부여하는 정밀 주석.
- **상호 주석 일치도 (IAA)** : 다수 작업자가 동일 데이터에 부여한 라벨의 일관성을 측정하는 통계 지표(Cohen's / Fleiss' Kappa).
- **인간 개입 루프 (HITL)** : 모델이 확신하지 못하는 경계 데이터를 인간 전문가가 선별 검수하여 모델을 재학습시키는 협업 체계.

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 어노테이션의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 텍스트, 이미지, 음성, 비디오 등 비정형 원천 데이터에 모델 학습 목적에 부합하는 클래스, 위치, 감성, 인과 관계 등의 메타데이터(Ground Truth)를 주석하는 정형화 작업 |
| 목적 | 고품질 지도학습 및 정렬 데이터셋 구축을 통한 AI 모델 예측 정확도 향상, 환각(Hallucination) 감소 및 데이터 품질 거버넌스 확보 |

## Ⅱ. 데이터 어노테이션의 모달리티별 유형 및 특징

| 데이터 모달리티 | 핵심 주석 기법 | 주요 특징 및 활용 분야 |
|---|---|---|
| **컴퓨터 비전 (Vision)** | Bounding Box, Polygon, Semantic/Instance Segmentation, Keypoint | 자율주행(차량·보행자 객체 인식), 의료 영상(종양 영역 정밀 마스킹) |
| **자연어 처리 (NLP)** | 개체명 인식(NER), 구문 분석, 감성 태깅, 의도(Intent) 분류 | 챗봇 대화 의도 파악, 금융 계약서 핵심 엔티티 추출, 감성 분석 |
| **음성 및 오디오 (Audio)** | 음소 전사(STT Transcription), 화자 분리(Diarization), 소음 태깅 | 음성 인식 엔진 학습, 고객센터 콜센터 상담 화자별 음성 분리 |
| **생성형 AI 정렬 (LLM)** | RLHF 선호도 랭킹, 지시-응답 쌍(Instruction-Response Pair), 안전성 주석 | 초거대 언어모델의 인간 가치 정렬 및 유해성/환각 필터링 |

## Ⅲ. 데이터 어노테이션 파이프라인 및 품질 관리 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ Human-in-the-Loop 기반 고품질 데이터 어노테이션 파이프라인 ]         │
└────────────────────────────────────────────────────────────────────────┘

  [ 원천 데이터 수집 및 비식별화 (Raw Data) ]
                 │
                 ▼
  [ 라벨링 가이드라인 및 골드셋(Gold Set) 정의 ]
                 │
                 ▼
  [ 1차: AI 모델 기반 자동 사전 라벨링 (Pre-annotation) ]
                 │
                 ├─────────────────────────────────┐
                 ▼ (불확실성 낮음: 신뢰도 > 95%)     ▼ (불확실성 높음: 애매한 케이스)
  [ 자동 승인 (Auto-Approval) ]           [ 2차: 인간 작업자 라벨링 (HITL) ]
                 │                                 │
                 │                                 ▼
                 │                      [ 교차 라벨링 및 IAA 측정 ]
                 │                      (Cohen's / Fleiss' Kappa)
                 │                                 │
                 │                        (불일치 발생 시)
                 │                                 ▼
                 │                      [ 3차: 도메인 전문가 최종 중재 ]
                 │                                 │
                 └────────────────┬────────────────┘
                                  ▼
  [ 최종 품질 검수 (QA) 및 데이터셋 버전 패키징 (DVC / Data Sheets) ]
```

| 프로세스 단계 | 세부 작업 내용 | 핵심 산출물 및 품질 관리 지표 |
|---|---|---|
| **요구사항 정의** | AI 모델 태스크에 따른 라벨 체계(Ontology) 설계 | 라벨링 표준 가이드라인 V1.0 |
| **골드셋 구축** | 전문가가 완벽하게 주석한 표준 벤치마크 데이터셋 제작 | 골드 스탠다드셋 (전체의 5~10%) |
| **사전 라벨링** | 가벼운 사전 학습 모델을 통해 1차 초안 라벨 자동 생성 | 모델 확신도(Confidence Score) |
| **교차 주석** | 동일 데이터를 2인 이상의 작업자에게 독립 배정하여 작업 | 상호 일치도(Kappa $\ge 0.8$) |
| **품질 검수** | 합의 알고리즘(Majority Voting) 및 전문가 에스컬레이션 | 최종 데이터 시트(Data Sheets) |

## Ⅳ. 수동 라벨링 vs 자동 라벨링 vs 능동 학습 비교

| 비교 항목 | 수동 라벨링 (Manual) | 자동 라벨링 (Auto-Labeling) | 능동 학습 (Active Learning) |
|---|---|---|---|
| **작업 방식** | 인간 작업자가 전수 직접 수기 입력 | 사전 학습 모델이 전체 전수 자동 주석 | 불확실성이 높은 데이터만 인간이 선별 주석 |
| **구축 비용** | 매우 높음 (인건비 비례) | 매우 낮음 (컴퓨팅 자원만 소모) | 최소 비용으로 최대 효율 달성 |
| **라벨 품질** | 숙련도 편차 크며 피로도에 취약 | 모델 편향(Bias) 전이 위험 존재 | 고품질 유지 (인간 전문가 검수 집중) |
| **구축 속도** | 매우 느림 | 극히 빠름 | 점진적이며 반복적인 개선 가능 |
| **적합 대상** | 복잡한 도메인 지식(의료, 법률) | 대규모 정형 패턴 단순 분류 | 데이터는 방대하나 라벨링 예산이 한정된 환경 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 작업자 간 주관적 해석 차이로 인한 라벨 노이즈(Label Noise) 발생 및 모델 성능 왜곡 | 모호 사례 중심의 FAQ 및 엣지 케이스 시각 자료가 포함된 상세 지침 갱신과 주기적인 골드셋 자격 테스트(Qualification Test) 시행 |
| 라벨링 작업의 인건비 및 소요 시간 기하급수적 증가로 인한 프로젝트 일정 지연 | 사전 라벨링(Pre-annotation) 모델 도입 및 신뢰도 기반 필터링을 결합한 하이브리드 자동화 파이프라인 적용 |
| 개인정보(주민번호, 얼굴 등) 및 기업 기밀 데이터 노출에 따른 컴플라이언스 위반 위험 | 데이터 업로드 전 전처리 단계에서 자동 블러링 및 가명화(De-identification) 도구 의무 적용과 폐쇄형 온프레미스 라벨링 툴 구축 |

## Ⅵ. 제언

데이터 중심 AI(Data-Centric AI) 패러다임에 맞춰 모델 수정보다 데이터 품질을 우선 관리할 수 있도록, 불확실성 기반 능동 학습과 DVC 기반의 데이터셋 버전 추적 체계 구축 필요.

```text
[ 대규모 미라벨 데이터 풀 ]
            │
            ▼
[ 불확실성 샘플링 (Uncertainty Sampling: Entropy 기반) ]
   ├── 모델 확신도가 낮은 최상위 5% 데이터 선별
   │
   ▼
[ 전문가 집중 어노테이션 및 가이드라인 정밀 보완 ]
   │
   ▼
[ 모델 재학습 및 검증 손실(Loss) 수렴 확인 ]
   │
   ▼
[ DVC (Data Version Control) 기반 데이터-모델 계보(Lineage) 자동 태깅 ]
```

| 구분 | 모델 중심 접근 (Model-Centric) | 제언: 데이터 중심 접근 (Data-Centric) |
|---|---|---|
| **성능 개선 주안점** | 고정된 데이터셋에서 신경망 아키텍처 튜닝 | 고정된 모델에서 데이터 라벨 무결성 지속 개선 |
| **라벨링 검수** | 프로젝트 초기 1회성 검수 | 학습 손실 역추적을 통한 이상 라벨 상시 정제 |
| **작업 대상** | 전체 데이터 무작위 무차별 라벨링 | 불확실성이 높은 고가치 경계 표본 선별 라벨링 |
| **추적성** | 소스코드 위주 Git 버전 관리 | 원천 데이터-라벨-모델 가중치 간 통합 계보 관리 |
