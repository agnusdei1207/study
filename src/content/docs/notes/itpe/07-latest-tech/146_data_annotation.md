## 답안 골격
```text
[데이터 어노테이션] ◀━━ 머리: Ⅶ 내 의견 (AI-in-the-loop 기반 자동 라벨링 및 능동 학습 파이프라인 구축을 통한 고품질 학습 데이터 확보 전략)
 ┃
 ┣━ Ⅰ 개요 ───── 지도학습(Supervised Learning)의 고성능 모델 달성을 위한 핵심 병목인 원천 데이터 레이블링 비용·시간 극복 필요성 대두
 ┣━ Ⅱ 특징 ───── 정밀성(타깃 객체 경계 정확도) · 일관성(작업자 간 라벨링 일치도) · 확장성(자동화 도구 연동) · 다양성(엣지 케이스 확보)
 ┣━ Ⅲ 유형 ───── 바운딩 박스(Bounding Box) + 폴리곤(Polygon) + 시맨틱 분할(Semantic Segmentation) + 인스턴스 분할(Instance Segmentation) + 키포인트(Keypoint)
 ┣━ Ⅳ 기법 ───── 크라우드소싱 라벨링 · 휴먼인더루프(HITL) · 사전학습 모델 기반 오토 라벨링(Auto-labeling) · 능동 학습(Active Learning)
 ┣━ Ⅴ 비교 ───── 바운딩 박스 vs 폴리곤 vs 시맨틱 세그멘테이션 (단순 사각형/낮은비용/배경포함 vs 다각형 정밀외곽/중간비용 vs 픽셀단위분류/최고비용/정밀자율주행)
 ┗━ Ⅵ 실무 ───── 작업자 간 라벨 편차(Inter-annotator disagreement) / 장시간 수작업에 따른 휴먼 에러 / 클래스 불균형(Class Imbalance)
```
- 필수 키워드: 데이터 어노테이션(Data Annotation) · 바운딩 박스 · 폴리곤 · 시맨틱 분할 · 인스턴스 분할 · 오토 라벨링 · 능동 학습(Active Learning) · HITL(Human-in-the-Loop)
- 제134회 정보관리기술사 1교시 6번: 이미지 데이터 어노테이션 유형과 기법(공식 Q-Net 문제지 대조)

## 한 줄 본질
- 인공지능이 사물을 정확히 이해하도록 원천 이미지·영상 데이터 속 객체에 이름표(메타데이터)를 달아주는 작업으로, 정밀도와 라벨링 비용 간의 트레이드오프를 오토 라벨링으로 극복하는 AI 필수 공정

   [1. 바운딩 박스]        [2. 폴리곤]           [3. 시맨틱 분할]

   │ │  Car    │ │        │  /  Car \   │        │ ██Car███    │

   └─────────────┘        └─────────────┘        └─────────────┘

## 핵심 용어
- 바운딩 박스(Bounding Box): 객체를 감싸는 최소 크기의 직사각형 좌표(xmin, ymin, xmax, ymax)를 지정하여 객체의 위치와 클래스를 식별하는 가장 범용적인 기법
- 시맨틱 분할(Semantic Segmentation): 이미지 내의 모든 픽셀을 개별 클래스로 분류하는 기법으로, 객체 간의 경계를 픽셀 단위로 정확히 분할
- 능동 학습(Active Learning): 모델 학습에 유용할 것으로 예상되는 표본을 선택해 사람에게 라벨을 요청하는 기법. 불확실성 외의 선택 기준도 가능하며 비용 절감은 검증 필요

## 핵심 통찰
- "데이터 중심 AI(Data-Centric AI)의 출발점": 모델 알고리즘 튜닝보다 100건의 오라벨링 정제와 고품질 어노테이션이 모델 성능을 비약적으로 끌어올림
- 오토 라벨링과 사람 검수의 결합: 모델이 제안한 라벨을 사람이 확인·수정할 수 있음. 실제 비용과 오류율은 작업 유형·모델 품질에 따라 측정
- 일관성 검증: 바운딩 박스·분할에는 IoU를, 범주형 다중 평가자 라벨에는 Fleiss' Kappa 등을 작업 유형에 맞춰 사용

## 이웃 토픽과 구분
- 데이터 어노테이션 vs 데이터 증강(Data Augmentation): 어노테이션은 원천 데이터에 정답 라벨(Ground Truth)을 부여하는 작업 / 증강은 회전, 반전, 노이즈 추가 등으로 데이터 수량과 다양성을 뻥튀기하는 작업

## 문제·원인·대책
- 아래 사례의 조건·수치는 가상 예시이며 실제 성과가 아님.
- 적용 상황: 자율주행 차량 학습용 수백만 장 도로 이미지 어노테이션 프로젝트 수행
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 작업자마다 표지판 모서리 지정 기준이 달라 모델 경계 인식률 저하 | 표준 작업 지침서 부재 및 주관적 경계 해석 | 픽셀 단위 라벨링 가이드라인 수립 및 다수 작업자 교차 검증(Cross-validation) | 라벨링 일치도(IoU) 0.9 이상 달성 |
| 수작업 인건비 폭증 및 전체 개발 일정 지연 | 100% 수작업 크라우드소싱 의존 | 초경량 검출 모델 기반 사전 라벨링(Pre-labeling) 후 인간 검수 체계 전환 | 작업 공수 60% 단축 및 납기 준수 |
| 야간·폭우 등 희귀 도로 상황 데이터 라벨 부족 | 주간 일반 주행 데이터 위주의 수집 편향 | 능동 학습 기반 불확실성 샘플링 및 생성형 AI 기반 합성 데이터(Synthetic Data) 보강 | 악천후 객체 인식 재현율(Recall) 25% 향상 |

## 1교시 예상문제 (10점)
- 데이터 어노테이션의 개념과 품질 관리 방법을 설명하시오.

## 1교시 10점 답안
- **정의:** 학습·평가 목적에 맞춰 원천 데이터에 클래스·영역·관계 등 의미 정보를 부여하는 과정.
- **유형:** 분류 라벨, 객체 상자·분할 마스크, 문장 개체명·관계, 음성 전사 등.
- **품질:** 라벨 지침·표본 이중 검수·불일치 조정·계층별 일관성 점검과 데이터 계보 관리.

## 2~4교시 예상문제 (25점)
- AI 데이터 어노테이션의 절차와 품질·비용 관리 방안을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 목적
- 모델 입력에 대응하는 정답·평가 기준을 생성하되 작업 지침과 사용 목적을 명확히 정의.
### Ⅱ. 작업 절차
- 표본 선정 → 라벨 체계·예외 지침 작성 → 작업자 교육 → 어노테이션 → 다중 검수·조정 → 버전 기록.
### Ⅲ. 품질 지표
- 분류 일치도는 Kappa 등, 탐지 영역 겹침은 IoU 등 과제에 맞는 지표 사용. 검수 표본은 희귀·애매 사례를 포함.
### Ⅳ. 효율화
- 사전 라벨링·능동학습으로 검토 후보를 제시하되 자동 결과의 오류·편향을 사람 검수로 확인.
