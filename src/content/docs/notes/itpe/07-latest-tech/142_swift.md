## 한 줄 본질
- SWIFT는 금융기관 간 표준화된 금융 메시지를 전달하는 네트워크. 메시지 전송과 실제 자금의 청산·결제는 별도 과정이며 경로는 지급 방식에 따라 다름

## 핵심 용어
- BIC(Business Identifier Code, SWIFT 코드): ISO 9362에 따라 전 세계 금융기관을 고유하게 식별하는 8자리 또는 11자리의 영문 코드(은행코드 4자 + 국가 2자 + 지역 2자 + 지점 3자)
- ISO 20022: 금융 메시지의 공통 비즈니스 모델과 데이터 사전을 정의하는 국제 표준. SWIFT의 일부 지급 메시지에서 구조화된 MX 형식을 사용하며 범위·필드·전환 일정은 서비스별로 확인
- SWIFT CSP(Customer Security Programme): SWIFT 이용기관이 자사 환경을 보호하도록 필수·권고 통제와 독립 평가·준수 증명을 요구하는 프로그램. 필수 통제 수와 적용 범위는 해당 연도 CSCF 문서로 확인

## 핵심 통찰
- "SWIFT는 돈을 보내는 망이 아니라 '메시지(Message)'를 보내는 망이다": SWIFT 시스템 자체에는 1원도 들어있지 않으며, 오직 암호화된 지급 지시 메시지만 안전하게 전달함 → 실제 돈의 정산은 양 은행 간에 사전에 터놓은 상대방 당좌예금 계좌(Nostro/Vostro)의 장부 차감으로 이루어짐
- SWIFT 접근 제한은 특정 금융기관의 국제 금융 메시지 전달에 큰 영향을 줄 수 있음. 실제 지급 가능성과 영향은 대체 경로·청산 체계·제재 범위에 따라 다름
- 국제 송금의 수수료·도착 시간은 통화·중계은행·서비스에 따라 달라짐. CIPS·SPFS·디지털 자산 기반 지급 방식은 참여 범위와 청산 구조를 각각 구분해 비교

## 이웃 토픽과 구분
- SWIFT는 금융 메시징 인프라이고 분산원장 기반 지급은 자산 이전·정산 방식에 따라 구조가 다름. 어느 방식이든 최종 수취인의 법정통화 지급에는 별도 기관·규정이 관여할 수 있음

## 1교시 예상문제 (10점)
- SWIFT의 역할과 ISO 20022 금융 메시지의 의미를 설명하시오.

## 1교시 10점 답안
- **정의:** 금융기관이 표준화된 메시지를 안전하게 교환하는 네트워크·표준 체계. 메시지 전송 자체가 자금 결제 완료를 뜻하지 않음.
- **ISO 20022:** 금융 업무 정보를 구조화된 공통 데이터 모델과 메시지로 표현.
- **통제:** 참여 기관의 인증·접근 통제, 메시지 검증, SWIFT CSP 기반 환경 보호와 정산 경로 확인.

## 2~4교시 예상문제 (25점)
- SWIFT 금융 메시지 전송 구조와 ISO 20022 전환 및 보안 통제를 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 업무 경계
- 송금 지시·상태 등 금융 전문을 기관 간 전달하고, 실제 자금 이동은 계좌·청산·결제 체계에서 수행.
### Ⅱ. 메시지 경로
- 발신 기관의 전문 생성·검증 → 네트워크 전달 → 수신 기관의 처리·응답 → 별도 결제 상태 대조.
### Ⅲ. 표준 전환
- MT와 ISO 20022 메시지의 필드·의미 매핑, 데이터 품질·주소 구조, 공존 기간의 변환 손실 점검.
### Ⅳ. 보안·운영
- 엔드포인트 보호, 접근권한·승인 분리, 거래 모니터링과 CSP 버전별 통제 항목 확인. 메시지 수신과 결제 완료 상태를 구분.

## 이렇게 출제된다
- 예상문제: SWIFT의 금융 전문 전송 구조와 ISO 20022 전환·보안 통제를 설명하시오. 제120회 직접 출제 여부와 원문은 미확인

## 내 의견
- 제언: 국제 지급망 전환은 참여기관·규제·유동성·청산 책임을 먼저 확인. ISO 20022 데이터와 다른 결제망을 연계하려면 메시지 의미와 결제 확정 시점을 실증
