 ┣━ Ⅲ 구조 ───── 금융기관 단말(Alliance Gateway) + SWIFTNet 보안 전용망 + 메시지 스위칭/검증 센터 + 고객보안프로그램(CSP)

- 기출: 120회 `SWIFT` → Ⅰ~Ⅴ

## 한 줄 본질
- 한국의 은행에서 미국의 은행으로 돈을 보낼 때, 돈 자체가 인터넷으로 날아가는 것이 아니라 "A 은행의 고객 B가 C 은행의 고객 D에게 1만 달러를 보내라고 승인했음"이라는 위조 불가능한 암호화 전문을 안전하게 배달해 주는 전 세계 금융망의 우체국 / 직접 돈을 정산하는 것은 환거래 계좌임

## 핵심 용어
- BIC(Business Identifier Code, SWIFT 코드): ISO 9362에 따라 전 세계 금융기관을 고유하게 식별하는 8자리 또는 11자리의 영문 코드(은행코드 4자 + 국가 2자 + 지역 2자 + 지점 3자)
- ISO 20022: 텍스트 줄글 형태였던 기존의 낡은 레거시 MT 전문을 구조화된 XML(MX) 포맷으로 전면 전환하여, 송금 목적, 세무 정보, 최종 수취인 상세 데이터를 완벽히 전송하는 금융 통신 국제 표준
- SWIFT CSP(Customer Security Programme): 2016년 방글라데시 중앙은행의 SWIFT 단말 해킹(8,100만 달러 탈취) 사건 이후 제정된 강제 보안 프레임워크로, 32개 필수 보안 통제(네트워크 격리, 다중인증 등)를 매년 의무 감사받도록 강제함

## 핵심 통찰
- "SWIFT는 돈을 보내는 망이 아니라 '메시지(Message)'를 보내는 망이다": SWIFT 시스템 자체에는 1원도 들어있지 않으며, 오직 암호화된 지급 지시 메시지만 안전하게 전달함 → 실제 돈의 정산은 양 은행 간에 사전에 터놓은 상대방 당좌예금 계좌(Nostro/Vostro)의 장부 차감으로 이루어짐
- 금융 핵무기(Financial Nuclear Weapon): 러시아-우크라이나 전쟁 당시 러시아 주요 은행들이 SWIFT에서 퇴출당하자 해외 무역 대금 결제와 송금이 전면 마비되었을 만큼, 글로벌 기축통화 체제를 지탱하는 절대적인 금융 인프라임
- 탈SWIFT와 블록체인의 도전: 비싼 중계 수수료(건당 수만 원)와 2~3일의 송금 지연, 미국의 금융 제재 무기화에 반발하여, 중국 CIPS, 러시아 SPFS, 그리고 리플(Ripple)이나 mBridge 같은 CBDC/블록체인 기반의 대안 결제망이 급부상 중임

## 이웃 토픽과 구분
- SWIFT vs 블록체인 송금(Ripple/Stellar): SWIFT는 환거래은행 계좌 정산에 의존하는 중앙 통신망 / 블록체인 송금은 중간 은행 없이 분산 원장 상에서 암호화폐나 스테이블코인으로 수 초 만에 가치 자체를 즉각 전송

## 문제·원인·대책
- 적용 상황: 시중 은행의 SWIFT 송금 시스템 운영 중 악성코드 감염 및 부정 송금 위협
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 내부 직원의 PC가 악성코드에 감염되어 SWIFT 단말을 통해 허위 지급 승인 전문이 발송될 위험 | 단말기 접근 통제 미흡 및 2단계 인증 부재 | SWIFT CSP 의무 준수(망분리 전용 세그먼트, 하드웨어 OTP 기반 2FA, HSM 키 격리) | 비인가 허위 전문 생성 원천 차단 |
| 수취인 이름 스펠링 하나가 틀려 해외 환거래 은행에서 송금이 묶이고 1주일간 행방불명 | MT 전문의 비구조화된 텍스트 필드 포맷 한계 | 구조화된 XML 기반 ISO 20022(pacs.008) 전환 및 gpi 사전 계좌 확인(Pre-validation) 도입 | 송금 반송 및 정체 80% 감소 |
| 해외 송금 시 중계 은행들이 떼어가는 수수료를 사전에 알 수 없어 고객 민원 빈발 | 다단계 중계 은행 체인 간 수수료 불투명성 | SWIFT gpi 추적기(Tracker) 연동을 통한 실시간 위치 및 수수료 투명 공개 | 송금 소요 시간 당일 처리 및 민원 해소 |

## 이렇게 출제된다
- 제120회 1교시: "국가 간 금융 거래의 핵심 인프라인 SWIFT의 개념, 동작 메커니즘(전문 전송과 환거래 정산), ISO 20022 표준 전환 및 사이버 보안 통제(SWIFT CSP)를 설명하시오." → 요구 포인트: Ⅰ 전문 중계망 정의 + Ⅲ 환거래 계좌 연계 구조 + Ⅵ ISO 20022 및 CSP 보안

## 내 의견
- [SWIFT 망과 국가 간 CBDC(mBridge) 연계를 위한 인터레저 게이트웨이 구축] 지정학적 갈등과 블록체인의 부상으로 SWIFT 독점 체제는 서서히 다극화된 디지털 자산 결제망으로 전환될 것임 → 나라면: 기존 SWIFT의 ISO 20022 표준 메시징 인프라는 그대로 유지하면서도, 실제 최종 자금 결제는 환거래 은행 대신 BIS가 주도하는 다자간 CBDC 플랫폼(mBridge)의 스마트 계약과 인터레저 프로토콜(ILP)로 연동하는 '하이브리드 차세대 외환 결제 게이트웨이'를 선제 구축
