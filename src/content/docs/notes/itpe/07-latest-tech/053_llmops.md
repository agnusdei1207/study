## 지식 로드맵 내 현재 위치

지식 위치: AI 서비스 운영 → 모델·검색·프롬프트 관리 → **대규모 언어모델 운영(LLMOps)**

## 30초 인출

- 본질: **대규모 언어모델 운영(Large Language Model Operations, LLMOps)** 은 언어 모델 기반 기능을 개발·평가·배포·운영하는 관리 방식
- 메커니즘: 변경 관리 → 평가·승인 → 배포 → 품질·비용·오류 추적 → 개선

<details>
<summary>핵심 용어</summary>

- **대규모 언어모델(Large Language Model, LLM)** : 대량의 텍스트 자료로 학습해 언어 과제를 수행하는 모델 계열
- **대규모 언어모델 운영(Large Language Model Operations, LLMOps)** : LLM 기반 서비스의 개발·평가·배포·운영을 반복 가능하게 관리하는 방식
- **기계학습 운영(Machine Learning Operations, MLOps)** : 기계학습 모델·자료의 개발부터 배포·운영까지 관리하는 실천·도구
- **추적(Tracing)** : 한 요청의 검색·모델·도구 호출과 결과를 단계별로 연결해 기록하는 방법
- **회귀 평가(Regression Evaluation)** : 시스템 변경 전후의 품질·동작 변화를 같은 시험으로 비교하는 평가
- **LLM-as-a-Judge** : 언어 모델을 응답 평가 보조자로 사용하고 기준 사례·사람 검토로 결과를 점검하는 접근

</details>

### Ⅱ. 관리 흐름

```text
모델·프롬프트·자료 변경
          │
평가·보안·회귀 확인
          │
승인된 버전 배포
          │
요청·검색·응답 추적
          │
오류·비용·사용자 영향 검토
          └──── 개선 요구로 환류
```

### Ⅲ. 관리 대상

| 대상 | 확인 내용 |
|---|---|

| 품질 | 정확성·근거성·안전성 평가 |
| 운영 | 오류·지연·사용량·비용 추적 |

**제언:** 대표 평가셋과 배포 기준으로 모델·프롬프트 변경을 함께 통제하는 운영체계.

```text
요청 → 검색·도구 호출 → 모델 응답 → 사용자·업무 결과
  └──────────── 단계별 추적·오류 연결 ────────────┘
```

| 관측 축 | 기록·평가 예 |
|---|---|
| 품질 | 근거 충실성·업무 적합성·정책 위반 |
| 서비스 | 오류율·응답 지연·처리량 |
| 비용 | 토큰 사용량·검색·외부 호출 |
| 변경 | 모델·프롬프트·자료 버전과 회귀 결과 |

### Ⅳ. 개인정보·변경 위험과 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 프롬프트·응답 로그에 민감정보가 포함되거나 과도하게 보존될 수 있음 | 수집 목적·필드·접근권한·보유기간을 정하고 마스킹·삭제 절차를 시험 |
| 자동 평가나 언어 모델 평가자의 판정이 실제 품질을 대변하지 못할 수 있음 | 대표 기준 사례와 사람 검토를 병행하고 평가 방식의 편향·불일치를 주기적으로 확인 |
