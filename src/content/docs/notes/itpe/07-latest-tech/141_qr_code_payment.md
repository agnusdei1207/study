## 지식 로드맵 내 현재 위치

지식 위치: 금융·결제 → 모바일 결제 → QR코드 결제

## 30초 인출

- 본질: **QR코드 결제은** QR에 담긴 결제 정보나 식별자를 읽어 결제 요청·승인 절차로 연결하는 방식
- 메커니즘: QR 생성 → 고객·가맹점의 스캔 → 거래 정보 확인 → 결제 승인 → 결과 통지

<details><summary>핵심 용어</summary>

- **MPM** : 가맹점이 제시한 QR을 소비자 앱이 읽는 방식
- **CPM** : 소비자 앱의 QR을 가맹점 단말이 읽는 방식
- **동적 QR** : 거래별 금액·식별자 등 정보를 새로 담는 코드

</details>

## 1교시 10점 답안

### Ⅰ. QR코드 결제의 개요

| 구분 | 핵심 |
|---|---|

|---|---|
| MPM | 가맹점 코드 제시 → 고객 앱 스캔 |


- 제언: 코드 진위 확인과 앱의 수취인·금액 재확인을 결제 승인 전에 적용

| 단계·구성 | 작동·역할 | 검토할 한계 |
|---|---|---|
| 코드 생성 | 거래·가맹점·고객 식별 범위 결정 | 정적 코드의 교체·재사용 |
| 스캔 | MPM과 CPM의 스캔 주체 구분 | 위조 코드·화면 캡처 |

| 승인·통지 | 결제망 인증과 승인 결과 연계 | 결과 중복·취소 처리 |

## Ⅲ. 핵심 작동 관계

```text
QR 생성 → 고객·가맹점의 스캔 → 거래 정보 확인 → 결제 승인 → 결과 통지
```

## Ⅳ. 비교와 선택 기준

| 구분 | 차이 | 적용 판단 |
|---|---|---|
| MPM | 고객이 가맹점 코드 스캔 | 게시된 코드의 바꿔치기 확인 |
| CPM | 가맹점이 고객 코드 스캔 | 소비자 코드의 노출·재사용 제한 |
