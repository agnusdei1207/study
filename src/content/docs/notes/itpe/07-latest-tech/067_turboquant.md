## 30초 인출

- 본질: **TurboQuant**는 고차원 벡터의 저장량을 줄이고 내적 추정을 지원하는 온라인 양자화 방법
- 메커니즘: 무작위 회전 → 좌표별 스칼라 양자화 → 1비트 QJL 잔차로 내적 추정의 편향 보정

<details>
<summary>핵심 용어</summary>

- **TurboQuant** : 벡터의 기하 왜곡을 줄이면서 온라인 압축을 수행하도록 제안된 양자화 방법
- **벡터 양자화(Vector Quantization)** : 연속 벡터를 낮은 비트 표현으로 바꾸는 압축 방법
- **PolarQuant** : 무작위 회전 좌표의 분포 특성을 이용해 벡터를 압축하는 TurboQuant 구성 기법
- **QJL(Quantized Johnson–Lindenstrauss)** : 1비트 잔차 표현과 보정 추정으로 내적 추정 편향을 줄이는 방법
- **KV 캐시(Key-Value Cache)** : 생성 중 재사용하는 어텐션의 Key·Value 표현을 저장하는 메모리

## 2~4교시 25점 답안

### Ⅰ. TurboQuant의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **TurboQuant**는 고차원 벡터의 저장량을 줄이고 내적 추정을 지원하는 온라인 양자화 방법 |
| 목적 | KV 캐시·벡터 검색에서 큰 벡터 표현의 메모리 부담 완화 |

### Ⅱ. 압축·잔차 보정 원리

```text
고차원 입력 벡터
      │ 무작위 회전
      ▼
좌표별 스칼라 양자화
      │ 압축 표현·잔차
      ▼
1비트 QJL 잔차 보정
      │
압축 벡터의 내적 추정
```

무작위 회전은 좌표의 분포를 다루기 쉽게 만들어 좌표별 양자화를 돕고, QJL은 양자화 오차에 따른 내적 추정 편향을 보정하는 구성. 논문은 품질 결과를 실험 조건별로 보고하므로 모든 모델의 무손실·고속을 보장하는 것으로 일반화하지 않음.

### Ⅲ. 적용 대상과 유사 기법 구분

| 기법·대상 | 저장 내용 | 판단 기준 |
|---|---|---|
| TurboQuant | 고차원 벡터·KV 표현 | 내적 왜곡·검색 회수·메모리 평가 |
| 가중치 양자화 | 모델 파라미터 | 가중치 정확도·모델 메모리·추론 평가 |
| 일반 KV 캐시 양자화 | 추론 중 Key·Value 상태 | 데이터 형식·커널·하드웨어별 검증 |

KV 캐시 압축과 모델 가중치 압축은 최적화 대상이 서로 다른 문제.

### Ⅳ. 평가와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 압축 오차가 벡터 검색 순위나 어텐션 결과에 영향을 줄 수 있음 | 대상 자료·모델에서 검색 회수·생성 품질을 기준 구현과 비교 |
| 연구 벤치마크의 속도·정확도 결과가 운영 환경과 다를 수 있음 | 실제 하드웨어·배치·문맥 길이에서 메모리·지연·품질을 재측정 |
