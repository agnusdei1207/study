## 답안 골격
```text
[지니 지수] ◀━━ 머리: Ⅶ 내 의견 (CART 알고리즘의 최적 이진 분기 기준으로서 초고속 불순도 연산 및 비용-복잡도 가지치기 최적화)
 ┃
 ┣━ Ⅰ 개요 ───── 집합 내 데이터의 불순도(Impurity)를 측정하는 통계적 지표로, 머신러닝 CART(Classification and Regression Trees)의 분할 기준으로 널리 활용
 ┣━ Ⅱ 수식 ───── Gini(S) = 1 - ∑ [ p_i^2 ] (p_i: 클래스 i에 속할 확률, 이진 분류 시 0 <= Gini <= 0.5)
 ┣━ Ⅲ 특성 ───── 순수도 최대 시 지니 지수 0 (모든 샘플이 단일 클래스) · 불순도 최대 시 지니 지수 0.5 (클래스가 5:5로 완벽히 섞임)
 ┣━ Ⅳ 분할원리 ─ 지니 불순도 감소량(ΔGini) = Gini(부모) - [ (|S_L|/|S|)*Gini(S_L) + (|S_R|/|S|)*Gini(S_R) ] → 불순도 감소가 최대인 지점에서 이진 분할
 ┣━ Ⅴ 비교 ───── 지니 지수 vs 엔트로피 지수 (제곱합연산/초고속수렴/CART vs 로그연산/상대적고비용/ID3·C4.5)
 ┗━ Ⅵ 실무 ───── 범주형 변수의 이진 분기 조합 탐색 비용(2^(k-1)-1) / 연속형 변수 정렬 오버헤드 / 과적합 발생 방지를 위한 가지치기(Pruning)
```
- 필수 키워드: 지니 지수(Gini Index) · 불순도(Impurity) · 순수도(Purity) · CART · 이진 분할(Binary Split) · 지니 감소량(Gini Gain) · 가지치기(Pruning)

## 한 줄 본질
- 클래스 분포에서 독립적으로 뽑은 두 레이블이 다를 확률을 제곱합으로 계산하고, 이를 줄이는 이진 분할을 선택하는 CART의 분류 불순도 지표

[지니 지수(Gini) 분포 곡선 및 CART 이진 노드 분할 원리]

## 핵심 용어
- 지니 불순도(Gini Impurity): 노드의 클래스 분포에서 독립적으로 추출한 두 레이블이 다를 확률인 1-∑pᵢ². 분류 오차율 1-max(pᵢ)와 구분
- CART(Classification and Regression Trees): 이진 분할을 반복하는 트리 알고리즘. 분류에서는 지니·엔트로피 등을, 회귀에서는 제곱오차 등 연속형 목표의 기준을 사용
- 지니 중요도(Gini Importance): 랜덤 포레스트 등 앙상블 트리에서 특정 특성이 노드를 분할할 때 감소시킨 총 지니 불순도의 합을 측정하여 계산한 특성 중요도(Mean Decrease in Impurity)

## 핵심 통찰
- 계산 특성: 지니 불순도는 확률의 제곱합을 사용하며 엔트로피는 로그를 사용. 실제 학습 시간 차이는 분할 탐색과 구현의 영향도 받아 실측 필요
- 두 지표의 관계: 모두 클래스가 순수할 때 0이며 분포가 고르게 섞일수록 커지지만 서로 다른 함수이므로 동일한 분할을 보장하지 않음
- 이진 분할의 안정성: 다중 분할을 허용하는 C4.5와 달리 CART는 언제나 이진 분할(Binary Split)만 고집하여 트리의 깊이는 깊어지지만 데이터 희소화(Data Fragmentation)를 방지함

## 이웃 토픽과 구분
- 지니 계수(경제학) vs 지니 지수(머신러닝): 경제학 지니 계수는 로렌츠 곡선을 기반으로 소득 불평등도를 0~1로 측정 / 머신러닝 지니 지수는 데이터 집합 내 클래스 혼합 불순도를 0~0.5(이진분류 기준)로 측정

## 1교시 예상문제 (10점)
- CART의 지니 불순도와 분할 기준을 설명하시오.

## 1교시 10점 답안
- **정의:** 노드의 클래스 비율 pᵢ에 대해 G(S)=1-∑pᵢ²인 분류 불순도. 독립적으로 뽑은 두 레이블이 다를 확률.
- **분할:** 부모 불순도에서 자식 불순도의 표본수 가중평균을 뺀 감소량을 크게 하는 이진 분할 선택.
- **구분:** 단순 오분류율 1-max(pᵢ)와 다른 지표이며 회귀 CART는 별도 손실 기준 사용.

## 2~4교시 예상문제 (25점)
- 지니 불순도의 계산 원리와 엔트로피와의 차이, 적용상 편향을 설명하시오.

## 2~4교시 25점 답안
### Ⅰ. 수식
- G(S)=1-∑pᵢ². 이진 분류 p=0.5에서 최댓값 0.5, 순수 노드에서 0.
### Ⅱ. 분할
- ΔG=G(부모)-∑자식 가중치×G(자식). 후보 특성·임계값을 평가해 감소량이 큰 분할 선택.
### Ⅲ. 엔트로피 비교
- 엔트로피는 -∑pᵢlog₂pᵢ, 지니는 제곱합. 두 기준의 분할 결과나 속도가 항상 같거나 한쪽이 우월하지 않음.
### Ⅳ. 운영
- 과적합에는 리프 최소 크기·가지치기, 불균형에는 비용·재현율 확인, 변수 중요도 편향에는 순열 중요도 교차 검증.
