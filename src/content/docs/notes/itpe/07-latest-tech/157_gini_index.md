- **메커니즘:** G(S)=1−∑pᵢ²와 자식 노드의 가중평균으로 분할의 불순도 감소 계산
- 통찰: 한계: 훈련 지니 감소만 추구하면 작은 잎과 불균형 클래스의 오분류를 간과 → 방안: 최소 리프 수·가지치기와 클래스별 재현율을 검증
- **답안 초점:** CART의 지니 불순도와 분할 기준을 설명하시오.

## 2~4교시 25점 답안

## Ⅰ. 지니 불순도의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 클래스 비율의 제곱합으로 G(S)=1-∑pᵢ²를 계산하는 분류 불순도 |
| 목적 | CART 의사결정나무에서 후보 이진 분할 평가 |

## Ⅱ. 부모·자식 노드의 지니 감소량 계산 구조

```text
부모 노드 S: G(S)
   │ 후보 특성·임계값으로 이진 분할
   ├─ 왼쪽 S_L: |S_L|/|S| × G(S_L)
   └─ 오른쪽 S_R: |S_R|/|S| × G(S_R)
            │
            ▼
ΔG = G(S) - [가중 왼쪽 지니 + 가중 오른쪽 지니]
            └─ 후보별 ΔG 비교 → 분할 선택
```

## Ⅲ. 지니와 엔트로피의 분할 기준 비교

| 기준 | 수식 | 해석 |
|---|---|---|
| 지니 | 1-∑pᵢ² | 다른 레이블을 뽑을 불순도 |
| 엔트로피 | -∑pᵢlog₂pᵢ | 클래스 분포의 정보 불확실성 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 훈련 불순도 감소가 작은 잎의 과적합으로 이어질 수 있음 | 최소 리프 수·가지치기와 검증 성능 비교 |
| 불균형 클래스의 오류가 전체 불순도에 가려질 수 있음 | 클래스별 재현율·오분류 비용 함께 평가 |

## Ⅴ. 제언

분할 기준의 차이보다 리프 크기와 클래스별 오류 목표를 먼저 정하고 검증 자료에서 비교.
