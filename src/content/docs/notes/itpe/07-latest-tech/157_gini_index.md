## 30초 인출

- 본질: **지니 지수** (Gini Impurity)는 데이터 집합에서 무작위로 추출한 두 개의 원소가 서로 다른 클래스에 속할 확률($1 - \sum p_i^2$)을 계산하여 노드의 순도(Purity)를 측정하는 CART 알고리즘의 핵심 분할 지표
- 메커니즘: 부모 노드의 지니 불순도 산출 → 후보 속성별 이진 분할(Binary Split) 시뮬레이션 → 가중 자식 불순도 차감으로 지니 감소량($\Delta Gini$) 최대화 분기점 결정
- 통찰: 클래스 불균형 환경에서 다수 클래스를 과도하게 분리하는 편향과 연속형 피처의 정렬 비용이 발생하므로 클래스 가중치 부여 및 히스토그램 기반 고속 분할(LightGBM) 파이프라인 구축 필요

<details><summary>핵심 용어</summary>

- **지니 불순도 (Gini Impurity)** : 데이터 집합 내 원소들이 무작위로 분류되었을 때 오분류될 확률을 나타내는 지표 ($1 - \sum p_i^2$).
- **CART (Classification And Regression Tree)** : 레오 브레이먼(Leo Breiman)이 제안한 지니 불순도 기반의 대표적 이진 분할 의사결정나무 알고리즘.
- **이진 분할 (Binary Split)** : 다치 속성도 항상 두 개의 하위 자식 노드(Left, Right)로만 분기하여 조합 폭발을 억제하는 기법.
- **지니 감소량 (Gini Gain)** : 부모 노드의 지니 불순도에서 분할 후 두 자식 노드의 가중 평균 불순도를 차감한 순수 불순도 개선량.
- **클래스 불균형 (Class Imbalance)** : 정상 데이터와 이상/사기 데이터 간의 비율이 극단적으로 치우쳐 소수 클래스 판별력이 저하되는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 지니 지수의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 집합 내에서 임의로 선택한 데이터 항목이 무작위로 레이블링되었을 때 잘못 분류될 확률을 각 클래스 비율의 제곱합 차감($1 - \sum_{i=1}^c p_i^2$)으로 측정한 불순도 척도 |
| 목적 | 로그 연산 배제를 통한 의사결정나무 분할 속도 최적화, 노드 순도 극대화 및 고속 앙상블(Random Forest, GBM) 학습 지원 |

## Ⅱ. 지니 불순도의 수학적 메커니즘 및 핵심 특징

| 핵심 요소 | 수식 및 원리 | 주요 특징 및 공학적 의미 |
|---|---|---|
| **지니 불순도 수식** | $Gini(S) = 1 - \sum_{i=1}^{c} p_i^2 = \sum_{i \neq j} p_i p_j$ | 모든 샘플이 단일 클래스일 때 0 (완전 순수), 균등 분포 시 최댓값 ($1 - 1/c$) |
| **이진 지니 수식** | $Gini(S) = 2p(1 - p)$ | 이진 분류($c=2$) 환경에서 $p=0.5$일 때 최댓값 0.5 도출 |
| **이진 분할 강제** | 특정 임계값 $x \le \theta$ 기준으로 좌/우 2개 노드 분할 | C4.5의 다자 분할과 달리 다치 속성 편향을 원천 차단 |
| **지니 개선량 ($\Delta G$)** | $\Delta G(S, A) = Gini(S) - \left( \frac{\|S_L\|}{\|S\|} Gini(S_L) + \frac{\|S_R\|}{\|S\|} Gini(S_R) \right)$ | 분할을 통해 감소된 불순도의 양으로 분기 우선순위 결정 기준 |

## Ⅲ. CART 의사결정나무의 이진 분할 및 지니 감소량 계산 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ CART 알고리즘의 지니 불순도 기반 이진 분기 파이프라인 ]               │
└────────────────────────────────────────────────────────────────────────┘

  [ 부모 노드 데이터셋 S (양성 $N_1$, 음성 $N_2$, 총 $N$) ]
   - 부모 지니 계산: $Gini(S) = 1 - \left[ (N_1/N)^2 + (N_2/N)^2 \right]$
                    │
                    ▼
  [ 모든 입력 피처 ($X_1, X_2, \dots, X_m$) 및 임계치($\theta$) 정렬 스캔 ]
   ├── 피처 $X_1 \le \theta_1$ 분할 시뮬레이션
   │    ├── 좌측 자식 ($S_L$): 크기 $N_L$, 불순도 $Gini(S_L)$
   │    └── 우측 자식 ($S_R$): 크기 $N_R$, 불순도 $Gini(S_R)$
   │    └── 가중 자식 불순도 $G_{split} = \frac{N_L}{N} Gini(S_L) + \frac{N_R}{N} Gini(S_R)$
   │    └── 지니 개선도: $\Delta G = Gini(S) - G_{split}$
   │
   └── 타 피처 및 타 임계치들에 대해 $\Delta G$ 전수 반복 계산
                    │
                    ▼
  [ 최적 분할 조건 선정: $\arg\max_{X_j, \theta_k} \Delta G(S, X_j, \theta_k)$ ]
                    │
                    ▼
  [ 이진 분기 실행 및 정지 조건(Stopping Criteria) 검증 ]
   - 최소 샘플 수($min\_samples\_split$) 미달 또는 $Gini=0$ 시 리프 노드 확정
```

| 계산 단계 | 실례 계산 (전체 $N=10$, 양성 6, 음성 4) | 수치 계산 및 결과 |
|---|---|---|
| **부모 지니 불순도** | $p_1 = 0.6, p_2 = 0.4$ | $Gini(S) = 1 - (0.6^2 + 0.4^2) = 1 - (0.36 + 0.16) = 0.48$ |
| **좌측 자식 ($S_L$)** | $N_L = 5$ (양성 4, 음성 1) | $Gini(S_L) = 1 - ((4/5)^2 + (1/5)^2) = 1 - (0.64 + 0.04) = 0.32$ |
| **우측 자식 ($S_R$)** | $N_R = 5$ (양성 2, 음성 3) | $Gini(S_R) = 1 - ((2/5)^2 + (3/5)^2) = 1 - (0.16 + 0.36) = 0.48$ |
| **분할 후 가중 지니** | 좌우 자식 노드 샘플 수 비율 가중 합 | $G_{split} = (5/10 \times 0.32) + (5/10 \times 0.48) = 0.16 + 0.24 = 0.40$ |
| **최종 지니 개선량** | 부모 지니에서 가중 지니 차감 | $\Delta G = 0.48 - 0.40 = 0.08$ |

## Ⅳ. 지니 지수 vs 섀넌 엔트로피 vs 거시경제 지니 계수 비교

| 비교 항목 | 지니 불순도 (Gini Impurity) | 섀넌 엔트로피 (Entropy) | 경제학 지니 계수 (Gini Coefficient) |
|---|---|---|---|
| **학문 분야** | 머신러닝 (의사결정나무) | 정보 이론 및 머신러닝 | 거시 경제학 및 통계학 |
| **수학 공식** | $1 - \sum p_i^2$ | $-\sum p_i \log_2 p_i$ | 로렌츠 곡선과 대각선 면적 비율 ($A / (A+B)$) |
| **연산 비용** | 매우 낮음 (단순 곱셈/뺄셈) | 높음 ($\log_2$ 초월함수 연산) | 중간 (누적 분포 면적 적분) |
| **값의 범위** | 이진 기준 $0.0 \sim 0.5$ | 이진 기준 $0.0 \sim 1.0$ | $0.0 \sim 1.0$ (0은 완전 평등, 1은 불평등) |
| **대표 활용** | CART, Random Forest, XGBoost | ID3, C4.5, 딥러닝 손실 함수 | 국가별 소득 불평등 지수 측정 |
| **분할 결과 차이** | 대부분 엔트로피와 98% 유사한 분기점 생성 (성능 차이 미미) | 불순도 곡선이 지니보다 약간 더 뾰족함 | 분류 모델 분할 지표로 직접 사용 불가 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 정상 99% 대 불량 1%와 같은 클래스 불균형 환경에서 다수 클래스만 한쪽으로 몰아넣는 편향 발생 | 손실 함수에 클래스 역빈도 가중치를 부여하는 `class_weight='balanced'` 설정 또는 SMOTE 오버샘플링 결합 |
| 대규모 연속형 피처가 존재할 때 매 분기마다 모든 고유값 정렬($O(N \log N)$)로 인한 심각한 I/O 병목 | 히스토그램 기반의 구간화(Histogram Binning) 기법을 적용하여 연속형 값을 이산화하는 LightGBM/XGBoost 채택 |
| 지니 불순도 감소만을 목적으로 트리를 깊게 성장시킬 경우 훈련 데이터에 대한 과적합(Overfitting) 초래 | 최소 리프 샘플 수 제한, 최대 깊이(Max Depth) 통제 및 사전/사후 비용 복잡도 가지치기(ccp_alpha) 적용 |

## Ⅵ. 제언

현대 빅데이터 실무 파이프라인에서는 개별 트리의 지니 연산보다, 약한 학습기(Weak Learner)를 묶는 랜덤 포레스트 및 그래디언트 부스팅의 앙상블 거버넌스 체계 구축 필요.

```text
[ 대규모 원천 학습 데이터 ]
            │
            ▼
[ 부트스트랩 샘플링 (Bagging) & 피처 무작위 선택 ]
   ├── 트리 1: 지니 불순도 기반 서브트리 학습 (Max Features = $\sqrt{D}$)
   ├── 트리 2: 지니 불순도 기반 서브트리 학습
   └── 트리 N: 지니 불순도 기반 서브트리 학습
            │
            ▼
[ OOB (Out-of-Bag) 에러 자동 검증 및 다수결 투표 (Majority Voting) ]
            │
            ▼
[ 단일 지니 트리의 분산(Variance) 오류 극복 및 초고속 일반화 추론 ]
```

| 구분 | 단일 CART 지니 의사결정나무 | 제언: 지니 기반 랜덤 포레스트 앙상블 |
|---|---|---|
| **과적합 위험** | 노이즈 데이터까지 과적합될 위험 높음 | 무작위 배깅(Bagging)으로 분산(Variance) 억제 |
| **안정성** | 데이터 소량 변경 시 트리 구조 급변 | 수백 개 트리의 평균으로 극도의 예측 안정성 확보 |
| **피처 중요도** | 특정 단일 속성에 편향된 중요도 도출 | MDI(Mean Decrease in Impurity) 전역 집계 제공 |
| **하이퍼파라미터** | 가지치기(Pruning) 파라미터 튜닝 복잡 | 트리 개수($n\_estimators$) 설정만으로 준수한 성능 |
