## 30초 인출

- 본질: **변분 오토인코더(VAE)** 는 입력을 고정된 벡터가 아닌 확률 분포의 모수(평균과 분산)로 압축하고, 잠재 공간에서 무작위 표본을 추출하여 원본과 유사하면서도 새로운 데이터를 합성하는 확률론적 생성 모델
- 메커니즘: 인코더를 통한 잠재분포 모수(μ, σ) 추정 → 재파라미터화 트릭(z = μ + σ ⊙ ε)으로 역전파 경로 확보 → 디코더를 통한 데이터 복원 → ELBO(재구성 오차 + KL 발산) 최적화
- 통찰: L2 재구성 손실로 인한 이미지 블러(Blurriness) 현상과 사후 붕괴(Posterior Collapse) 한계가 있으므로 KL 어닐링과 이산 벡터 양자화(VQ-VAE) 기법 도입 필수

<details><summary>핵심 용어</summary>

- **변분 오토인코더(VAE)** : 데이터의 잠재 확률 분포를 모델링하여 새로운 샘플을 생성하는 비지도 학습 기반 신경망.
- **재파라미터화 트릭(Reparameterization Trick)** : 확률적 샘플링의 비미분성 문제를 표준 정규 분포 잡음(ε)의 선형 변환으로 치환하여 오차역전파를 가능하게 하는 기법.
- **증거 하한(ELBO, Evidence Lower Bound)** : 직접 계산이 불가능한 데이터의 주변 로그 우도(Marginal Log-Likelihood)를 최대화하기 위해 최적화하는 수식.
- **KL 발산(Kullback-Leibler Divergence)** : 근사 사후 분포 q(z|x)가 사전 정규 분포 p(z)와 얼마나 유사한지 측정하여 잠재 공간을 정규화하는 손실항.
- **사후 붕괴(Posterior Collapse)** : 학습 중 KL 발산이 0으로 수렴하면서 디코더가 잠재 변수 z를 무시하고 자체 사전 지식만으로 생성하는 학습 실패 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 변분 오토인코더(VAE)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **변분 오토인코더(VAE)** 는 관측 데이터를 고정된 단일 벡터 대신 확률 분포의 모수(평균 μ, 분산 σ)로 인코딩하고, 재파라미터화 트릭을 통해 미분 가능한 방식으로 새로운 데이터를 복원·생성하는 확률론적 생성 모델 |
| 목적 | 잠재 공간(Latent Space)을 연속적이고 정규화된 분포로 구조화하여 데이터 간의 매끄러운 의미론적 보간(Interpolation) 및 무작위 샘플링을 통한 신규 데이터 합성 |

## Ⅱ. 변분 오토인코더(VAE)의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **잠재 공간 모델링** | 확률론적 잠재 분포 매핑 | 입력을 특정 점(Point)이 아닌 가우시안 확률 분포 파라미터로 매핑하여 빈 공간(Hole) 없는 잠재 공간 형성 |
| **미분 가능 샘플링** | 재파라미터화 트릭 | 무작위 노이즈 ε ~ N(0, I)를 도입하여 샘플링 연산의 비미분성을 우회하고 엔드투엔드 역전파 달성 |
| **다목적 최적화** | 이중 손실 함수 (ELBO) | 원본과 똑같이 복원하려는 재구성 손실과 잠재 공간을 표준 정규분포로 묶어두는 정규화 손실의 균형 유지 |
| **해석 가능성** | 잠재 공간 연속성·완전성 | 잠재 벡터 z의 값을 조금씩 변경할 때 생성되는 이미지 속성(표정, 안경, 회전각 등)이 연속적으로 변환 |

## Ⅲ. VAE의 구조 및 재파라미터화 학습 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 변분 오토인코더(VAE) 아키텍처 및 재파라미터화 연산 흐름 ]       │
└────────────────────────────────────────────────────────────────────────┘
 [ 입력 데이터 X ]
         │
         ▼
 [ 인코더 신경망 q_φ(z|X) ] ── (가중치 φ 학습)
         │
         ├──────────────────────────┐
         ▼                          ▼
 [ 평균 벡터 (μ) ]           [ 로그 분산 벡터 (log σ²) ]
         │                          │
         │                          ▼
         │                 [ 표준편차 (σ = exp(0.5 * log σ²)) ]
         │                          │
         │       [ 표준정규 잡음 ε ~ N(0, I) ] (비미분 확률 노이즈 외부 주입)
         │                          │
         └─────────────┬────────────┘
                       ▼
         [ 재파라미터화 트릭: z = μ + σ ⊙ ε ] (미분 가능한 결정론적 연산)
                       │
                       ▼
         [ 디코더 신경망 p_θ(X|z) ] ── (가중치 θ 학습)
                       │
                       ▼
         [ 복원된 데이터 X_hat ]
```

| 손실 함수 구성 | 세부 수식 및 역할 | 공학적 의미 |
|---|---|---|
| **재구성 손실 (Reconstruction Loss)** | -E_{q_φ(z|x)}[log p_θ(x|z)] (MSE 또는 Cross-Entropy) | 복원된 데이터 X_hat과 원본 X 간의 픽셀 단위 일치도 극대화 |
| **정규화 손실 (KL Divergence)** | D_KL(q_φ(z|x) || p(z)) where p(z) ~ N(0, I) | 사후 확률 분포를 표준 가우시안 분포에 근접시켜 공간 조밀화 |
| **전체 손실 (ELBO 최대화)** | Loss = Reconstruction Loss + β * KL Divergence | 두 목표 간의 상충(Trade-off)을 가중치 파라미터 β로 조절 |

## Ⅳ. 전통 오토인코더(AE), VAE, GAN 비교

| 비교 항목 | 전통 오토인코더 (AE) | 변분 오토인코더 (VAE) | 생성적 적대 신경망 (GAN) |
|---|---|---|---|
| **학습 목적** | 고차원 입력 데이터 압축 및 복원 | 데이터 확률 분포 학습 및 신규 생성 | 생성자와 판별자 간의 적대적 경쟁 학습 |
| **잠재 공간** | 불연속적, 빈 공간(Hole) 다수 존재 | 연속적이고 정규화된 가우시안 공간 | 무작위 잠재 노이즈 벡터 입력 |
| **신규 샘플 생성** | 불가능 (압축 벡터의 복원에 국한) | 가능 (잠재 공간 샘플링 기반 생성) | 매우 탁월 (실사 수준의 고해상도 생성) |
| **수학적 기반** | 단순 비선형 차원 축소 | 변분 추론(Variational Inference) | 게임 이론 (Minimax Game) |
| **생성물 선명도** | N/A (복원 데이터만 존재) | 상대적으로 흐릿함 (Blurry) | 매우 선명하고 디테일 우수 |
| **학습 안정성** | 매우 안정적 | 매우 안정적 (ELBO 수렴 보장) | 불안정 (모드 붕괴, 기울기 소실 발생) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 픽셀 단위 평균제곱오차(MSE)를 재구성 손실로 사용할 때 모든 가능한 상태의 평균으로 수렴하여 이미지가 흐려지는 블러(Blurriness) 현상 발생 | VGG/ResNet 사전 학습 모델의 특징 맵 거리를 측정하는 지각적 손실(Perceptual Loss) 결합 및 적대적 판별자(Discriminator)를 결합한 VAE-GAN 하이브리드 구조 적용 |
| 디코더의 표현력이 지나치게 강력할 경우 잠재 변수 z를 무시하고 자체 사전 확률만으로 복원하는 사후 붕괴(Posterior Collapse) 발생 | 학습 초기에는 KL 발산 가중치를 0에서 점진적으로 증가시키는 KL 어닐링(KL Annealing) 기법 및 최소 정보량을 강제하는 Free Bits 적용 |
| 연속형 가우시안 잠재 변수 가정으로 인해 텍스트나 이산적 코드 구조와 같은 이산 데이터 표현 한계 | 코드북(Codebook) 기반 이산 잠재 공간을 정의하고 스트레이트 스루 추정기(STE)로 학습하는 VQ-VAE(Vector Quantized-VAE) 도입 |

## Ⅵ. 제언

이산 벡터 양자화(Vector Quantization) 기반의 VQ-VAE-2 구조를 채택하여 블러 현상을 원천 배제하고 잠재 공간의 위계적 표현력을 극대화한 아키텍처 구축.

```text
[ 고해상도 원본 이미지 ]
           │
           ▼
[ 인코더 계층 (Top / Bottom 계층화) ]
           │
           ▼
[ 이산 코드북 양자화 (Vector Quantization) ] ── (연속 잠재 벡터를 가장 가까운 코드북 인덱스로 치환)
           │
           ▼
[ 오토리그레시브 트랜스포머 사전 모델 ] ───── (양자화된 이산 토큰의 사전 확률 학습)
           │
           ▼
[ 디코더 계층 ] ───> [ 픽셀 뭉개짐 없는 초고해상도 실사 이미지 생성 ]
```

| 구분 | 연속형 표준 VAE | 제언: 이산형 VQ-VAE-2 + 트랜스포머 |
|---|---|---|
| **잠재 공간 형태** | 연속적인 가우시안 정규 분포 | 유한한 이산 벡터 코드북(Codebook) 인덱스 |
| **사후 붕괴 위험** | KL 발산 과다 시 잠재 변수 무시 발생 | 코드북 치환 메커니즘으로 사후 붕괴 원천 차단 |
| **생성 선명도** | 고주파 텍스처 손실 및 블러 발생 | GAN 수준의 초고해상도 디테일 및 텍스처 복원 |
