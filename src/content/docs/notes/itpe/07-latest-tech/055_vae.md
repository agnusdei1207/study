## 30초 인출

- 본질: **변분 오토인코더(Variational Autoencoder, VAE)** 는 입력의 잠재분포를 학습해 복원과 표본 생성을 수행하는 확률 생성 모델
- 메커니즘: 인코더가 분포 모수 추정 → 재파라미터화 표본 추출 → 디코더 복원 → ELBO 최적화

<details>
<summary>핵심 용어</summary>

- **변분 오토인코더(Variational Autoencoder, VAE)** : 입력별 잠재분포를 학습해 데이터 복원·생성을 수행하는 생성 모델
- **잠재변수(Latent Variable)** : 관측 자료의 주요 특성을 압축해 나타내는 모델 내부 변수
- **재파라미터화 트릭(Reparameterization Trick)** : 무작위 표본을 분포 모수와 독립된 노이즈 식으로 나타내 미분 가능한 학습을 돕는 방법
- **ELBO(Evidence Lower Bound)** : 데이터 로그우도의 하한으로, VAE가 최대화하는 학습 목적함수
- **KL 발산(Kullback–Leibler Divergence)** : 근사 사후분포와 사전분포 간 차이를 재는 정보량 척도

### Ⅰ. 변분 오토인코더의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **변분 오토인코더(Variational Autoencoder, VAE)** 는 입력별 잠재분포를 학습해 데이터 복원·생성을 수행하는 확률 생성 모델 |
| 목적 | 데이터의 잠재 표현과 표본 생성이 가능한 분포 학습 |

### Ⅱ. 인코더·샘플링·디코더

```text
입력 x
  │
인코더 ── 평균 μ·분산 σ² 추정
  │
z = μ + σ⊙ε  (ε: 표준정규 노이즈)
  │
디코더 ── 복원 분포·표본
```

### Ⅲ. 학습 목적

| 항 | 역할 |
|---|---|

| KL 정규화 | 잠재분포가 사전분포와 지나치게 멀어지지 않도록 조정 |

## 2~4교시 25점 답안

### Ⅰ. 변분 오토인코더의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **변분 오토인코더(Variational Autoencoder, VAE)** 는 입력별 잠재분포를 학습해 데이터 복원·생성을 수행하는 확률 생성 모델 |
| 목적 | 데이터의 잠재 표현과 표본 생성이 가능한 분포 학습 |

### Ⅱ. 잠재분포 학습 구조

```text
입력 x
  │
인코더 ── 평균 μ·분산 σ² 추정
  │
z = μ + σ⊙ε  (ε: 표준정규 노이즈)
  │
디코더 ── 복원 분포·표본
```

인코더의 근사 사후분포는 `qφ(z|x)`, 디코더의 생성분포는 `pθ(x|z)`로 표기. 일반 오토인코더의 고정 잠재 벡터와 달리 입력별 분포를 추정하며, 재파라미터화 식은 무작위성 ε와 학습할 모수를 분리해 기울기 기반 학습을 가능하게 함.

### Ⅲ. ELBO 목적함수

```text
ELBO 최대화
  ├─ 재구성 로그우도 증가 ── 입력 설명력 향상
  └─ KL(qφ(z|x) || p(z)) 감소 ── 잠재분포 정규화
```

최소화 손실로 표현할 때는 음의 재구성 로그우도와 KL 항의 합. 최대화 목적과 최소화 손실의 부호를 혼동하지 않도록 구분.

| 항목 | 학습에서 맡는 역할 |
|---|---|
| 재구성 항 | 관측 자료와 복원 분포의 적합도 반영 |
| KL 항 | 근사 사후분포와 사전분포 간 차이 조절 |

### Ⅳ. 적용 한계와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 재구성 오차가 낮아도 표본의 의미·품질이 충분하다고 단정하기 어려움 | 과업별 표본 평가와 잠재공간 활용 시험을 함께 설계 |
| KL 항이 과도하면 잠재변수 정보가 약해질 수 있음 | 잠재표현의 사용 목적에 맞춰 재구성·정규화 균형과 대표 표본을 점검 |
| 복원 성능만으로 이상 탐지를 판정하면 오탐·미탐을 놓칠 수 있음 | 정상·이상 자료를 분리해 임계값과 업무별 오류 영향을 검증 |
