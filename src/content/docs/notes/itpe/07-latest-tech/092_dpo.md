## 30초 인출

- 본질: **DPO (Direct Preference Optimization)** 는 별도의 보상 모델 훈련과 복잡한 강화학습(PPO) 루프 없이 선호·비선호 응답 쌍 데이터셋으로 언어모델 정책을 직접 최적화하는 사후 정렬 기법
- 메커니즘: 브래들리-테리(Bradley-Terry) 선호 모델의 최적 해를 수학적으로 재매개변수화하여 정책 모델과 고정 참조 정책 간의 로그 확률 비율 차이를 이진 교차 엔트로피 손실로 계산 후 역전파
- 통찰: 명시적 보상 모델은 생략되나 참조 모델 유지에 따른 GPU 메모리 부담과 분포 이탈 데이터에 대한 과적합 위험이 상존하므로 LoRA 결합 및 동적 베타 계수 스케줄링 적용 필수

<details><summary>핵심 용어</summary>

- **DPO (Direct Preference Optimization)** : 보상 모델링과 강화학습 없이 선호 데이터셋으로 언어모델을 직접 지도학습 형태로 정렬하는 알고리즘.
- **브래들리-테리 모델 (Bradley-Terry Model)** : 두 대상 간의 쌍대 비교 선호 확률을 내재된 잠재 보상 점수의 로지스틱 함수로 모델링하는 확률 모형.
- **참조 정책 (Reference Policy, $\pi_{ref}$)** : 정책 모델의 파라미터가 초기 SFT 모델에서 지나치게 이탈하는 현상을 억제하기 위한 고정 기준 언어모델.
- **선호 쌍 (Preference Pair)** : 동일한 프롬프트 $x$에 대해 사람이 더 선호하는 승자 응답($y_w$)과 비선호하는 패자 응답($y_l$)의 데이터 쌍.
- **KL 발산 제약 (KL Divergence Constraint)** : 최적화 중 언어모델이 기존 언어 능력 및 사실성을 상실하지 않도록 참조 정책과의 정보 격차를 제한하는 정규화 기법.

</details>

## 2~4교시 25점 답안

## Ⅰ. DPO의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **DPO (Direct Preference Optimization)** 는 강화학습 기반 보상 모델 훈련 없이 인간 선호 응답 쌍을 이용해 언어모델 정책을 직접 최적화하는 폐쇄형 목적함수 기반 선호 정렬 기술 |
| 목적 | 복잡한 PPO 파이프라인의 학습 불안정성 극복 및 GPU 메모리·연산 비용 절감을 통한 LLM 정렬 효율 극대화 |

## Ⅱ. DPO의 핵심 수식 및 알고리즘 특징

| 특징 요소 | 핵심 수식 및 원리 | 기술적 구현 특징 |
|---|---|---|
| **수학적 재매개변수화** | $r(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{ref}(y \mid x)}$ | 보상 함수 $r(x,y)$를 정책 모델과 참조 모델의 로그 우도 비율로 대수적 치환 |
| **DPO 손실 함수** | $\mathcal{L}_{DPO} = -\mathbb{E}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{ref}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{ref}(y_l \mid x)}\right)\right]$ | 선호 응답 $y_w$와 비선호 응답 $y_l$ 간의 암묵적 보상 차이를 시그모이드 교차 엔트로피로 최소화 |
| **보상 모델 생략** | 별도의 Reward Model(RM) 아키텍처 불필요 | RM 훈련 오차 전파 방지 및 학습 파이프라인의 단일 지도학습화 |
| **PPO 루프 제거** | Value Network, Rollout Sampling 제거 | 정책 경사 추정 시 발생하는 고분산(High Variance) 및 초매개변수 민감도 제거 |

## Ⅲ. DPO 학습 체계 및 파이프라인

```text
┌────────────────────────────────────────────────────────────────────────┐
│             DPO (Direct Preference Optimization) 학습 구조              │
└────────────────────────────────────────────────────────────────────────┘
 [ 프롬프트 x, 선호 응답 y_w, 비선호 응답 y_l ]
                        │
       ┌────────────────┴────────────────┐
       ▼                                 ▼
┌──────────────────────────────┐  ┌──────────────────────────────┐
│ 학습 대상 정책 모델 (π_θ)      │  │ 고정 참조 정책 모델 (π_ref)   │
│ (Active Policy Model)        │  │ (Frozen Reference SFT Model) │
└──────────────┬───────────────┘  └──────────────┬───────────────┘
               │                                 │
               ▼                                 ▼
┌──────────────────────────────┐  ┌──────────────────────────────┐
│ log π_θ(y_w|x)               │  │ log π_ref(y_w|x)             │
│ log π_θ(y_l|x)               │  │ log π_ref(y_l|x)             │
└──────────────┬───────────────┘  └──────────────┬───────────────┘
               │                                 │
               └────────────────┬────────────────┘
                                │
                                ▼
 ┌─────────────────────────────────────────────────────────────┐
 │ 암묵적 보상 마진 계산:                                       │
 │ Δr = β * [ log(π_θ(y_w)/π_ref(y_w)) - log(π_θ(y_l)/π_ref(y_l)) ] │
 └──────────────────────────────┬──────────────────────────────┘
                                │
                                ▼
 ┌─────────────────────────────────────────────────────────────┐
 │ DPO Loss 계산: L = - log σ(Δr)                              │
 └──────────────────────────────┬──────────────────────────────┘
                                │ Backpropagation (역전파)
                                ▼
                 [ π_θ 가중치 갱신 (Gradient Update) ]
```

| 학습 처리 단계 | 상세 동작 내용 | 엔지니어링 고려사항 |
|---|---|---|
| **입력 데이터 로딩** | 동일 프롬프트에 대한 정답 쌍 $(x, y_w, y_l)$ 배치 구성 | 선호도 판별의 모호성 배제 및 데이터 정제 필수 |
| **로그 우도 추론** | 활성 모델 $\pi_\theta$와 동결 모델 $\pi_{ref}$에서 토큰별 로그 우도 병렬 산출 | 참조 모델 가중치 동결 및 추론 모드(Eval mode) 적용 |
| **암묵적 보상 차이 산출** | $\beta$ 하이퍼파라미터를 곱하여 참조 모델 대비 승자·패자 마진 계산 | $\beta$ 값이 너무 크면 과적합, 작으면 정렬 효과 미미 |
| **손실 함수 역전파** | 시그모이드 이진 분류 손실을 정책 모델 $\pi_\theta$에만 역전파 | 옵티마이저 가중치 감쇠(Weight Decay) 및 클리핑 적용 |

## Ⅳ. LLM 정렬 기법 비교 (RLHF-PPO vs DPO vs KTO vs ORPO)

| 비교 항목 | RLHF (PPO) | DPO (본 토픽) | KTO (Kahneman-Tversky) | ORPO (Odds Ratio) |
|---|---|---|---|---|
| **보상 모델 유무** | 별도 RM 필수 | 불필요 (암묵적 보상) | 불필요 | 불필요 |
| **참조 모델 유무** | 필수 ($\pi_{ref}$) | 필수 ($\pi_{ref}$) | 필수 ($\pi_{ref}$) | 불필요 (SFT 손실과 통합) |
| **필요 데이터 형태** | 선호 쌍 $(y_w, y_l)$ | 선호 쌍 $(y_w, y_l)$ | 단일 응답 + 불리언(True/False) | 선호 쌍 $(y_w, y_l)$ |
| **학습 안정성** | 매우 낮음 (발산 빈번) | 높음 (지도학습과 유사) | 높음 | 매우 높음 |
| **GPU 메모리 요구** | 극도로 높음 (4개 모델 동시 로딩) | 중간 (2개 모델 로딩) | 중간 (2개 모델 로딩) | 낮음 (단일 모델 로딩) |
| **이론적 근거** | 마르코프 결정 과정 (MDP) | 브래들리-테리 닫힌 해 | 전망 이론 (Prospect Theory) | 승산비(Odds Ratio) 페널티 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 고정 참조 정책 모델($\pi_{ref}$) 동시 상주로 인한 GPU VRAM 점유 및 단일 노드 학습 한계 | 참조 모델을 양자화(4-bit/8-bit)하여 고정하거나 LoRA 어댑터를 분리 장착하여 기본 베이스 모델 단일 공유 |
| 학습 데이터셋 내 분포 외(OOD) 선호 쌍 주입 시 손실 함수 포화 및 비선호 응답 우도 폭락 현상 | 선호 마진 기반 정규화 기법인 cDPO(Conservative DPO) 도입 및 라벨 노이즈 완화 정규화 항 추가 |
| 하이퍼파라미터 $\beta$에 대한 높은 민감도로 인한 언어모델 생성 다양성 저하 및 반복 출력 발생 | 코사인 감쇠 기반 동적 $\beta$ 스케줄러 적용 및 평가 벤치마크 기반 조기 종료(Early Stopping) 구현 |

## Ⅵ. 제언

단일 GPU 인프라 환경에서 DPO 적용 시 발생하는 메모리 병목을 극복하기 위해 LoRA 기반 베이스 모델 공유 아키텍처와 동적 $\beta$ 제어 루프를 결합한 효율적 정렬 파이프라인 구축 권고.

```text
[ 기본 고정 LLM 베이스 모델 (예: Llama-3-8B Base 4-bit NF4) ] ── 메모리 1회 로딩
          │
          ├─────────────────────────┬─────────────────────────┐
          ▼                         ▼                         ▼
 [ Forward: 참조 정책 π_ref ]   [ Active LoRA 어댑터 π_θ ]   [ 동적 β 스케줄러 ]
 (LoRA 미적용 기본 가중치 통과)  (학습 가능한 저순위 행렬 통과) (Epoch 기반 점진적 감쇄)
          │                         │                         │
          └────────────┬────────────┘                         │
                       ▼                                      ▼
             [ DPO Loss 엔진 ] <──────────────────────────────┘
                       │
                       ▼ Gradient Update (LoRA 파라미터만 갱신)
```

| 비교 항목 | 전통적 DPO 구현 (풀 파인튜닝) | 제언: QLoRA 결합 단일 베이스 공유 DPO |
|---|---|---|
| **GPU 필요 사양** | 80GB A100/H100 4~8장 필수 | 24GB RTX 4090 / A10G 1~2장으로 학습 가능 |
| **모델 상주 개수** | 16-bit 모델 2벌 독립 로드 | 4-bit 기본 모델 1벌 + 수 MB LoRA 가중치 |
| **학습 안정성** | 과적합 및 망각(Catastrophic Forgetting) 위험 | 기본 베이스 사전 지식 보존 및 안정적 수렴 |
| **배포 용이성** | 전체 수십 GB 모델 재패키징 | 최종 산출물로 수십 MB LoRA 어댑터만 배포 |
