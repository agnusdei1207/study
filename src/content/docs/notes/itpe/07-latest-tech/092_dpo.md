## 연관 키워드

- DPO, 선호 정렬, 보상 모델, 참조 모델, 암묵적 보상, 베타 계수, RLHF, PPO, KTO, ORPO, LoRA

## Ⅰ. DPO의 개요

- 핵심 요약 : 별도 보상 모델 없이 선호 응답 쌍으로 언어모델 정책을 직접 최적화하는 선호 정렬 기법.
- 개념 : 프롬프트에 대한 선호 응답과 비선호 응답의 쌍으로 정책 모델을 직접 최적화하는 **DPO** (Direct Preference Optimization), 즉 **선호 정렬**(Preference Alignment)의 한 방식.
- 배경 및 필요성 : 인간 피드백 기반 강화학습 RLHF(Reinforcement Learning from Human Feedback)는 보상 모델을 따로 학습하고 PPO(Proximal Policy Optimization) 강화학습을 돌려야 해 학습이 불안정하고 GPU 자원 부담이 크다.
- 주요 목적 : 보상 모델 없이 지도학습에 가까운 단일 단계로 선호 정렬을 수행해 학습 안정성과 자원 효율을 확보.

## Ⅱ. DPO의 특징 및 장점

- 핵심 요약 : 보상 모델을 생략하고 정책 모델과 참조 모델의 확률 차이만으로 선호를 학습하는 구조가 학습 단순화와 안정성으로 이어짐.

DPO는 브래들리-테리(Bradley-Terry) 선호 모델의 보상 함수를 정책 모델에 대한 식으로 바꾸어, 보상 모델 없이 선호 데이터만으로 최적화한다. 학습 대상은 **참조 모델**(Reference Model, 학습 전 고정된 기준 정책)과 비교되는 정책 모델이다.

1. **암묵적 보상**(Implicit Reward) : 정책과 참조 모델의 로그 확률 비율에 베타 계수(β)를 곱해 보상을 표현 → 별도 보상 모델 학습이 사라져 파이프라인 단계 축소.
2. 이진 교차 엔트로피 손실 : 선호 응답과 비선호 응답의 암묵적 보상 차이를 시그모이드로 최적화 → 지도학습과 유사한 안정적 수렴.
3. 고정 참조 모델 : 기준 분포를 고정해 정책이 원래 언어 능력에서 과도하게 멀어지는 것을 억제 → 기존 지식 보존.

```text
[ 입력: 프롬프트 x, 선호 y_w, 비선호 y_l ]
                    ↓
[ 정책 π_θ 의 log 확률 계산 ]
[ 참조 π_ref 의 log 확률 계산 ]
                    ↓
[ 암묵적 보상 차이 Δr 계산 ]
                    ↓
[ 손실 L = -log σ(Δr) 계산 ]
                    ↓
[ π_θ 가중치 역전파 갱신 ]
```

## Ⅲ. DPO의 구조 (흐름)

- 핵심 요약 : DPO는 RLHF의 보상 모델과 강화학습 단계를 하나의 손실 최적화로 대체한 흐름이다.

```text
RLHF
  선호 데이터 → 보상 모델 학습 → PPO 강화학습 → 정책
DPO
  선호 데이터 → 손실 직접 최적화 → 정책
```

## Ⅳ. DPO와 대안 기법의 비교

- 핵심 요약 : 보상 모델과 참조 모델의 필요 여부가 학습 비용과 안정성을 가르는 기준이다.

| 비교 축 | RLHF (PPO) | DPO | KTO | ORPO |
| --- | --- | --- | --- | --- |
| 보상 모델 | 별도 필요 | 불필요 (암묵적 보상) | 불필요 | 불필요 |
| 참조 모델 | 필요 | 필요 | 필요 | 불필요 (SFT 손실과 통합) |
| 필요 데이터 | 선호 쌍 | 선호 쌍 | 단일 응답과 좋음·나쁨 라벨 | 선호 쌍 |
| 학습 안정성 | 발산하기 쉬움 | 지도학습에 가까움 | 상대적으로 안정 | 안정적 |
| GPU 메모리 부담 | 가장 큼 (정책·참조·보상·가치 모델 동시 운용) | 중간 (정책과 참조 모델) | 중간 | 상대적으로 낮음 |

## Ⅴ. DPO의 한계와 방안

- 핵심 요약 : 참조 모델의 메모리 점유, 선호 데이터 분포 이탈, 베타 계수 민감도가 주요 한계이며 각각 제어 수단이 있음.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 참조 모델 메모리 점유 | 정책과 참조 모델이 GPU에 동시에 상주해 단일 노드 학습 부담 | 참조 모델을 양자화해 고정, LoRA 어댑터로 베이스 모델 공유 | GPU 메모리 사용량 |
| 선호 데이터 분포 이탈 | 기준 분포를 벗어난 쌍이 섞이면 손실이 포화되고 비선호 응답 확률이 과도하게 낮아짐 | 보수적 DPO(cDPO, Conservative DPO) 같은 노이즈 완화 정규화, 데이터 검수 | 선호 일치율, 평가셋 성능 변화 |
| 베타 계수 민감도 | β 값에 따라 출력 다양성이 줄고 반복 출력이 늘어남 | β 값 탐색과 평가셋 기반 조기 종료 | 생성 다양성, 반복 출력 비율 |

## Ⅵ. DPO에 대한 기술사적 제언

- 핵심 요약 : 선호 데이터 품질 관리와 평가 자동화를 함께 갖춘 상시 정렬 체계로 DPO를 운용하는 것이 바람직함.

선호 데이터의 수집과 검수 절차를 먼저 정비해야 DPO의 손실 최적화가 의미를 갖는다. 초기에는 소수의 범용 GPU에서 LoRA 기반 DPO 실험으로 시작하고, 정렬 결과를 자동 평가와 묶어 재학습 주기를 관리하는 점진적 도입이 현실적이다.

## Ⅶ. 결론

- 핵심 요약 : DPO는 보상 모델을 생략해 선호 정렬을 단일 최적화 단계로 단순화한 기법임.
- 학습 안정성과 자원 효율을 얻는 대신 참조 모델 관리와 데이터 품질에 대한 책임이 커지므로, 데이터 체계와 함께 설계할 때 효과가 드러난다.
