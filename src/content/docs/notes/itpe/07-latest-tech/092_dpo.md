## 지식 로드맵 내 현재 위치
IT 인공지능 → 거대 언어모델 사후학습 → 선호 정렬 → DPO

## 30초 인출
- **본질:** DPO는 선호 응답 쌍으로 정책 모델을 직접 최적화하는 정렬 방법이다.
- **메커니즘:** 선호·비선호 응답의 정책 대 참조 정책 로그확률 차이에 로지스틱 손실을 적용한다.
- **추가 단서:** 명시적 보상 모델과 PPO 갱신 루프를 생략하지만, 참조 정책과 선호 데이터는 계속 필요하다.

<details><summary>핵심 용어</summary>

- **DPO(Direct Preference Optimization):** 선호·비선호 응답 쌍과 참조 정책을 이용해 정책 모델을 직접 최적화하는 방법이다.
- **선호 쌍(Preference Pair):** 같은 프롬프트에 대한 선호 응답과 비선호 응답의 쌍이다.
- **정책 모델(Policy Model):** 선호 데이터로 갱신하는 언어모델이다.
- **참조 정책(Reference Policy):** 정책이 지나치게 이탈하지 않도록 로그확률 비교에 사용하는 고정 모델이다.
- **암묵적 보상(Implicit Reward):** 정책과 참조 정책의 로그확률 비율로 나타내는 선호 점수 해석이다.
</details>

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | DPO는 선호 응답 쌍을 이용해 정책 모델을 직접 정렬하는 최적화 방법이다 |
| 목적 | 명시적 보상 모델과 PPO 절차 없이 선호 정보를 정책 학습에 반영한다 |

전통적 RLHF는 선호 자료로 보상 모델을 학습한 뒤, 정책을 강화학습으로 갱신하는 접근을 사용한다. DPO는 KL 제약 선호 최적화의 해를 재매개변수화해 선호 쌍에 대한 직접 정책 손실로 바꾼다.

| 방식 | 학습 신호·구성 |
|---|---|
| SFT | 입력·정답 예시의 다음 토큰 우도 |
| RLHF(PPO) | 보상 모델 점수와 정책 최적화 루프 |
| DPO | 선호 쌍과 참조 정책을 이용한 직접 선호 최적화 |

## Ⅱ. 학습 구조
```text
[선호 쌍: 입력 x, 선호 y_w, 비선호 y_l]
                       |
                       v
[현재 정책 π_θ] ------> [응답별 로그확률]
                               |
[고정 참조 정책 π_ref] -> [참조 로그확률]
                               |
                               v
                       [DPO 선호 손실]
                               | 기울기 갱신
                               v
                       [새 정책 π_θ]
```

## Ⅲ. 목적함수와 적용 특성
선호 응답을 `y_w`, 비선호 응답을 `y_l`이라 하면 대표적인 DPO 손실은 다음과 같다.

`L_DPO = −E[log σ(β × ((log πθ(y_w|x) − log πref(y_w|x)) − (log πθ(y_l|x) − log πref(y_l|x))))]`

| 항목 | 의미 |
|---|---|
| `πθ` | 선호 데이터로 학습하는 정책 |
| `πref` | 로그확률 차이를 비교하는 고정 참조 정책 |
| `β` | 선호 최적화와 참조 정책의 상대적 관계에 영향을 주는 계수 |
| `σ` | 선호 쌍에 대한 로지스틱 변환 |

DPO는 별도의 학습 보상 모델·PPO 정책 갱신을 요구하지 않지만, 참조 정책의 점수 계산 또는 사전 계산과 선호 쌍 품질은 필요하다. 학습 메모리·안정성 이점은 구현·모델·데이터에 따라 달라진다.

## Ⅳ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 선호쌍을 모으기 전에 DPO가 적합한 과업인지 알기 어려움 | 응답 선호가 분명히 정의되는 과업을 골라 SFT 기준선과 비교하고, 라벨링 비용에 견줄 품질 개선이 확인될 때 적용한다. |
