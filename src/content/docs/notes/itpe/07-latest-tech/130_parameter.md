## 지식 로드맵 내 현재 위치
최신 기술 → 인공지능 기초 → 모델의 학습 변수 → 파라미터

## 30초 인출
- **본질:** 파라미터는 학습 과정에서 목적에 맞게 조정되는 모델 내부의 값.
- **메커니즘:** 입력과 파라미터로 예측을 계산하고, 손실의 기울기로 파라미터를 갱신.
- **구분:** 하이퍼파라미터는 학습 절차·설정을 제어하는 값으로 보통 학습 전 정하거나 탐색.

<details><summary>핵심 용어</summary>

- **파라미터(Parameter):** 학습 과정에서 목적 함수에 따라 조정되는 모델 내부의 값.
- **가중치(Weight):** 입력 성분이 모델 계산에 미치는 영향을 조절하는 파라미터.
- **편향(Bias):** 입력 가중합에 더해 모델 출력을 조절하는 파라미터.
- **손실 함수(Loss Function):** 예측과 목표의 차이를 수치화해 학습 상태를 평가하는 함수.
- **역전파(Backpropagation):** 계산 그래프를 따라 손실의 기울기를 모델 변수에 전달하는 미분 계산.
- **옵티마이저(Optimizer):** 기울기와 설정을 사용해 학습 변수를 갱신하는 알고리즘.
- **하이퍼파라미터(Hyperparameter):** 학습률·배치 크기처럼 학습 절차나 모델 구성을 제어하는 설정값.

</details>

## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **파라미터**는 학습 과정에서 목적 함수에 따라 조정되는 모델 내부의 값 |
| 목적 | 입력과 목표 사이의 관계를 학습해 예측 함수를 구성 |

## Ⅱ. 예측과 갱신
```text
입력·현재 파라미터
        |
        v
모델 예측
        |
        v
손실·기울기 계산
        |
        v
옵티마이저의 파라미터 갱신
        +------> 다음 예측·학습 반복
```

단순 선형 계산은 `y = Wx + b`로 나타낼 수 있으며, 다층 모델은 여러 변환과 비선형 함수를 조합. 학습 시 기울기 기반 최적화 등으로 파라미터를 조정.

## Ⅲ. 대표 파라미터
| 값 | 역할 | 예 |
|---|---|---|
| 가중치 `W` | 입력·은닉 표현의 영향 조절 | 계층 간 행렬 |
| 편향 `b` | 가중합에 오프셋 제공 | 뉴런별 상수 |
| 기타 학습 변수 | 모델 구조별 내부 상태 조정 | 정규화 계층의 학습 변수 |

## Ⅳ. 파라미터와 하이퍼파라미터
| 구분 | 파라미터 | 하이퍼파라미터 |
|---|---|---|
| 예 | 가중치·편향 | 학습률·배치 크기·계층 수 |
| 결정 | 목적 함수와 학습 알고리즘에 따라 조정 | 개발자가 정하거나 탐색 절차로 선택 |
| 영향 | 학습된 예측 함수를 구성 | 모델 구조·학습 과정·자원 사용에 영향 |

하이퍼파라미터도 자동 탐색할 수 있지만 파라미터와 역할은 구별. 실제 프레임워크에는 학습 불가능한 상태 변수도 있으므로 모든 내부 변수를 학습 파라미터로 부르지 않음.

## Ⅴ. 모델 용량과 운영
| 검토 항목 | 고려 사항 |
|---|---|
| 파라미터 규모 | 저장·메모리·추론 연산 부담 |
| 학습 적합성 | 데이터·모델 구조·최적화 설정의 조합 |
| 일반화 | 학습 자료와 별도 평가 자료의 성능 비교 |
| 배포 | 정밀도·압축·장치 제약에 따른 품질 영향 |

파라미터 수만으로 모델의 일반화 능력이나 성능을 단정할 수 없음. 데이터 규모·분포, 구조, 학습 방식과 정규화 등 함께 검토.

## Ⅵ. 기술사적 제언
