## 30초 인출
- 본질: 머신러닝 및 딥러닝 모델이 학습 데이터로부터 손실 함수(Loss Function)를 최소화하기 위해 역전파 알고리즘을 통해 스스로 값을 갱신·결정하는 내부 가중치(Weights)와 편향(Biases)
- 메커니즘: 순전파(Forward Propagation) 연산 → 손실 계산 → 연쇄 법칙(Chain Rule) 기반 그래디언트 역전파(Backpropagation) → 옵티마이저 가중치 갱신(W := W - η∇L)
- 통찰: 거대 파라미터 증가는 표현력을 극대화하지만 기하급수적 VRAM 점유와 과적합 위험을 야기하므로 가중치 양자화(INT4/INT8) 및 저순위 적응(LoRA) 기반 효율화 체계 필수

<details><summary>핵심 용어</summary>

- **파라미터(Parameter):** 훈련 데이터에 의해 모델 내부에서 스스로 학습·조정되는 변수로, 인공신경망의 가중치(Weight)와 편향(Bias)이 대표적
- **가중치(Weight, W):** 입력 신호가 다음 뉴런의 활성화에 미치는 영향력(중요도)을 조절하는 행렬 변수
- **편향(Bias, b):** 뉴런이 얼마나 쉽게 활성화(Activation)되는지를 조절하는 오프셋(Offset) 상수 변수
- **역전파(Backpropagation):** 출력층의 오차를 입력층 방향으로 거슬러 올라가며 연쇄 법칙을 통해 각 파라미터별 편미분(Gradient)을 계산하는 알고리즘
- **하이퍼파라미터(Hyperparameter):** 학습률, 배치 크기, 레이어 수 등 학습 시작 전 연구자가 수동 설정하거나 자동 탐색해야 하는 모델 외부 제어 변수

</details>

## 2~4교시 25점 답안

## Ⅰ. 파라미터의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 머신러닝·딥러닝 모델이 주어진 학습 데이터의 패턴을 반영하여 손실을 최소화하도록 학습(Optimization) 과정에서 지속적으로 갱신되는 모델 내부의 핵심 변수 |
| 목적 | 입력 특성(Features)과 타깃 레이블(Labels) 간의 비선형 함수 관계를 모델 내부 행렬로 근사화하여 미학습 데이터에 대한 일반화 예측 수행 |

## Ⅱ. 파라미터의 핵심 특징

| 특징 영역 | 주요 특성 | 기술적 구현 내용 |
|---|---|---|
| **데이터 종속성** | 데이터 기반 자가 학습(Data-driven) | 연구자가 직접 값을 지정하지 않고, 데이터의 통계적 분포와 오차 역전파를 통해 자동 결정 |
| **모델 용량 결정** | 파라미터 수가 모델 표현력(Capacity) 지배 | 파라미터 수가 증가할수록 복잡한 데이터 매니폴드를 표현 가능하나, 메모리 요구량 증가 |
| **지속적 갱신성** | 에포크(Epoch) 및 미니배치 단위 업데이트 | 경사하강법 계열 옵티마이저(SGD, Adam 등)를 통해 손실 함수의 전역 최소점을 향해 수렴 |
| **포맷 및 정밀도** | 부동소수점 데이터 타입 기반 저장 | 통상 FP32(단정밀도)로 학습되며, 추론 시 FP16, BF16, INT8, INT4 등으로 양자화 변환 |

## Ⅲ. 파라미터의 수학적 갱신 메커니즘 및 학습 프로세스

### 1. 파라미터 순전파 및 역전파 갱신 파이프라인
```text
+-----------------------------------------------------------------------------------+
|                        신경망 파라미터 학습 및 갱신 메커니즘                      |
+-----------------------------------------------------------------------------------+
|  [순전파 (Forward Pass)]                                                          |
|    입력 X ───> [선형 변환: Z = W · X + b] ───> [활성화: A = σ(Z)] ───> 예측 y_hat  |
|                                                                     │             |
|                                                                     ▼             |
|                                                     [손실 계산: L(y, y_hat)]      |
|                                                                     │             |
|  [역전파 (Backward Pass)]                                           ▼             |
|    가중치 그래디언트: ∂L/∂W = (∂L/∂y_hat) · (∂y_hat/∂Z) · (∂Z/∂W) = δ · X^T       |
|    편향 그래디언트:   ∂L/∂b = (∂L/∂y_hat) · (∂y_hat/∂Z) · (∂Z/∂b) = δ             |
|                               │                                                   |
|                               ▼                                                   |
|  [파라미터 갱신 (Parameter Update: 경사하강법)]                                   |
|    가중치 갱신: W_{t+1} = W_t - η · (∂L/∂W)                                       |
|    편향 갱신:   b_{t+1} = b_t - η · (∂L/∂b)   (단, η는 하이퍼파라미터인 학습률)    |
+-----------------------------------------------------------------------------------+
```

### 2. 신경망 레이어 내 파라미터 상세 구조
```text
[뉴런 입력: x_1, x_2, ..., x_n]
        │
        ├── (각 입력에 대응하는 가중치 파라미터 W 곱셈) ──> [Σ w_i * x_i]
        │                                                          │
        └── (뉴런 활성화 임계값을 조정하는 편향 파라미터 b 덧셈) ──> [ + b ]
                                                                   │
                                                                   ▼
                                                       [활성화 함수: σ(z)]
                                                                   │
                                                                   ▼
                                                             [출력값 a]
```

## Ⅳ. 파라미터 vs 하이퍼파라미터 비교 및 대규모 모델 경량화

### 1. 파라미터 vs 하이퍼파라미터 핵심 비교
| 비교 항목 | 파라미터 (Parameter) | 하이퍼파라미터 (Hyperparameter) |
|---|---|---|
| **정의** | 훈련 과정에서 데이터로부터 직접 도출되는 모델 내부 변수 | 모델 학습 방법 및 구조를 통제하기 위해 외부에서 설정하는 값 |
| **결정 주체** | 최적화 알고리즘 (Backpropagation, Optimizer) | 연구자, 엔지니어, AutoML (Bayesian, Random Search) |
| **대표 예시** | 가중치(Weights), 편향(Biases), 정규화 계수(Gain/Bias) | 학습률(LR), 배치 크기, 에포크, 은닉층 수, 모멘텀, 드롭아웃 비율 |
| **저장 위치** | 체크포인트 파일 (`model.pt`, `saved_model.pb`) | 설정 파일 (`config.json`, YAML), 학습 스크립트 인자 |
| **과적합 연관성** | 파라미터 과다 시 학습 데이터 암기(과적합) 발생 | 정규화 하이퍼파라미터(L2, 드롭아웃)로 과적합 제어 |

### 2. 거대 파라미터 모델의 경량화 기술 체계
| 경량화 기법 | 동작 메커니즘 | 파라미터 효율성 효과 |
|---|---|---|
| **가중치 양자화 (Quantization)** | FP32(32비트) 파라미터를 FP16, INT8, INT4로 비트폭 축소 | 메모리 사용량 1/2 ~ 1/8 절감, 메모리 대역폭 병목 해소 |
| **가중치 가지치기 (Pruning)** | 0에 가까운 무의미한 가중치 연결을 구조적/비구조적으로 제거 | 파라미터 수 50~90% 감축, 희소(Sparse) 텐서 연산 가속 |
| **지식 증류 (Knowledge Distillation)** | 거대 Teacher 모델의 출력 로짓(Soft Label)을 소형 Student가 모방 | Student 모델 파라미터 규모를 1/10 수준으로 압축 |
| **저순위 적응 (LoRA)** | 원본 가중치 행렬 $W$를 고정하고 저순위 행렬 $A \times B$만 학습 | 학습 대상 파라미터 수를 0.1% 미만으로 축소 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **스케일링 법칙(Scaling Law)에 따른 하드웨어 장벽**<br />파라미터 수가 수천억 개(LLM)로 폭증하여 단일 GPU 메모리 탑재 불가 및 학습 비용 폭등 | 텐서 병렬화(Megatron-LM), 파이프라인 병렬화, ZeRO(Zero Redundancy Optimizer) 기반 분산 메모리 샤딩 기법 적용 |
| **기울기 소실(Vanishing) 및 폭발(Exploding)**<br />심층 신경망에서 역전파 진행 중 파라미터 그래디언트가 0으로 수렴하거나 무한 발산 | 잔차 연결(Residual Connection), 배치 정규화(BatchNorm)/레이어 정규화(LayerNorm) 및 그래디언트 클리핑(Clipping) 적용 |
| **파라미터 재현성 상실 리스크**<br />파라미터 가중치 파일만 단독 보관 시 초기 시드, 전처리 파이프라인 누락으로 동일 성능 재현 불가 | 모델 아티팩트에 데이터 버전(DVC), 하이퍼파라미터 설정(YAML), 랜덤 시드, 런타임 이미지를 일체화한 Model Registry(MLflow) 체계 구축 |

## Ⅵ. 제언

파라미터의 양적 팽창 위주 패러다임에서 파라미터당 정보 효율성을 극대화하는 '고효율 아키텍처 및 MoE(Mixture of Experts)' 중심으로의 진화가 필수적임.

```text
[고밀도 거대 파라미터 (Dense 100B+)] ──> [희소 활성화 파라미터 (MoE: 라우터 기반 선별 활성화)]
                 │
                 ▼
    [엣지 디바이스 온디바이스 파라미터 (양자화 SLM 1B~7B)]
```

| 진화 패러다임 | 밀집 파라미터 (Dense Model) | 희소 전문가 파라미터 (MoE Model) |
|---|---|---|
| **연산 방식** | 모든 토큰에 대해 전체 가중치 파라미터 연산 | 라우팅 네트워크가 특정 토큰에 최적인 전문가(Expert) 파라미터만 선별 활성화 |
| **서빙 효율성** | 파라미터 규모에 정비례하여 연산량(FLOPs) 증가 | 파라미터 용량 대비 실제 추론 FLOPs를 1/5 이하로 절감 |
| **확장 전략** | 무제한 클러스터 인프라 증설 | 활성 파라미터 최소화로 단일 노드 다중 서빙 구현 |
