## 연관 키워드

- 파라미터(Parameter), 가중치(Weight), 편향(Bias), 하이퍼파라미터(Hyperparameter)
- 경사하강법, 역전파(Backpropagation), 학습률, 과적합(Overfitting)
- 가중치 양자화(Quantization), LoRA(Low-Rank Adaptation), VRAM(Video Random-Access Memory)
- 텐서 병렬화, ZeRO(Zero Redundancy Optimizer), 재현성, 모델 레지스트리

## Ⅰ. 파라미터의 개요

- 핵심 요약 : 학습 과정에서 손실을 줄이도록 데이터로부터 갱신되는 모델 내부의 변수 집합.
- 개념 : 머신러닝과 딥러닝 모델이 입력 특성과 타깃 레이블 사이의 관계를 근사하기 위해 가진 가중치(Weight)와 **편향**(Bias) 등 내부 변수로, 학습 과정에서 자동으로 갱신됨.
- 배경 및 필요성 : 파라미터를 늘리면 표현력은 커지지만 **VRAM**(Video Random-Access Memory) 점유와 과적합 위험이 함께 커지므로, **가중치 양자화**(INT8, INT4 등)와 **LoRA**(Low-Rank Adaptation, 저순위 적응) 같은 경량화 계층이 필요함.
- 주요 목적 : 학습 데이터에서 보지 못한 입력에 대해서도 예측이 가능하도록 함수 관계를 행렬 형태로 근사하는 것.

## Ⅱ. 파라미터의 특징 및 장점

- 핵심 요약 : 데이터 기반 자동 결정, 용량에 따른 표현력, 반복 갱신, 정밀도 변환이 결합된 학습 구조.

1. 데이터 기반 자동 결정 : 연구자가 값을 지정하지 않고 손실의 역전파로 학습 → 사람이 규칙을 설계하는 부담 감소.
2. 용량 결정 : 파라미터 수가 모델의 표현력을 좌우 → 복잡한 패턴 표현이 가능하지만 메모리 요구량이 함께 증가.
3. 반복 갱신 : **경사하강법**(Gradient Descent) 계열 옵티마이저로 미니배치 단위 갱신 → 손실의 최소점 근처로 수렴.
4. 정밀도 변환 : 학습은 보통 FP32로 수행하고 추론 시 FP16, BF16, INT8 등으로 변환 → 저장 공간과 연산 비용 절감.

## Ⅲ. 파라미터의 구조 (흐름)

- 핵심 요약 : 순전파로 예측을 만들고, 손실에 대한 역전파로 그래디언트를 구해, 학습률만큼 파라미터를 갱신하는 순환.

```text
[ 파라미터 갱신 순환 ]

순전파: 입력 X → Z = WX + b → 예측 ŷ
        ↓
손실 계산 L(y, ŷ)
        ↓
역전파: 그래디언트 ∂L/∂W, ∂L/∂b 계산
        ↓
갱신: W ← W - η·∂L/∂W (η는 학습률)
```

```text
[ 메모리 부담의 구성 ]

파라미터 수 × 자료형 크기 (바이트)
        ↓
추론 시 가중치 저장 공간
        ↓
학습 시 그래디언트와 옵티마이저 상태 추가
```

## Ⅳ. 파라미터와 하이퍼파라미터의 비교

- 핵심 요약 : 파라미터는 데이터로부터 학습되는 내부 변수이고, 하이퍼파라미터는 학습 방식을 외부에서 정하는 설정값이라는 점에서 구분됨.

| 비교 항목 | 파라미터 (Parameter) | 하이퍼파라미터 (Hyperparameter) |
| --- | --- | --- |
| 정의 | 학습 과정에서 데이터로부터 도출되는 모델 내부 변수 | 학습 방법과 구조를 통제하기 위해 외부에서 설정하는 값 |
| 결정 주체 | 최적화 알고리즘 (역전파, 옵티마이저) | 연구자, 엔지니어, 자동 튜닝 도구 |
| 대표 예시 | 가중치, 편향, 정규화 계층의 스케일 값 | 학습률, 배치 크기, 에포크 수, 은닉층 수, 드롭아웃 비율 |
| 저장 위치 | 체크포인트 파일 | 설정 파일, 학습 스크립트 인자 |
| 과적합과의 관계 | 파라미터가 과다하면 학습 데이터를 암기할 위험 | 정규화 계열 설정으로 과적합을 제어 |

## Ⅴ. 파라미터의 한계와 방안

- 핵심 요약 : 규모 확대에 따른 하드웨어 장벽, 기울기 불안정, 재현성 상실을 분산 학습, 구조적 안정화, 아티팩트 통합 관리로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 규모 확대에 따른 하드웨어 장벽 | 파라미터가 대규모로 늘어 단일 GPU 메모리에 올리지 못하고 학습 비용 급증 | 텐서 병렬화(Megatron-LM), 파이프라인 병렬화, ZeRO 기반 메모리 샤딩 | GPU 메모리 사용률, 학습 처리량 |
| 기울기 소실과 폭발 | 깊은 신경망에서 역전파 기울기가 0으로 수렴하거나 발산 | 잔차 연결, 배치 정규화(BatchNorm)·레이어 정규화(LayerNorm), 그래디언트 클리핑 | 손실 곡선의 안정성 |
| 학습 결과의 재현성 상실 | 가중치 파일만 보관하면 시드와 전처리 조건이 빠져 결과 재현 불가 | 데이터 버전(DVC), 설정 파일(YAML), 랜덤 시드, 런타임 이미지를 모델 레지스트리(MLflow)에 함께 기록 | 재현 성공률 |

## Ⅵ. 파라미터에 대한 기술사적 제언

- 핵심 요약 : 파라미터 규모를 성능 지표와 함께 비용 상한으로 관리하고, 학습 결과를 재현 가능한 아티팩트로 남기는 방향.

1. 모델 개발 조직은 파라미터 수를 늘리기 전에 같은 성능을 낼 수 있는 경량 구조와 양자화 후보를 비교하여, 메모리와 비용의 상한을 먼저 정해야 한다.
2. 인프라 조직은 학습과 서빙의 비용을 실험 단위로 추적하여, 규모 확대 투자의 판단 근거를 성능 대비 비용으로 남겨야 한다.
3. 연구 조직은 가중치와 학습 조건을 하나의 아티팩트로 기록하여, 결과의 재현과 사후 감사가 가능한 상태를 유지해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 파라미터는 학습으로 갱신되는 모델의 지식 저장소이며, 그 규모가 성능과 비용을 함께 결정하는 변수.
- 시사점 : 실운영에서는 파라미터 규모 경쟁보다 메모리 부담 관리와 학습 재현성 확보가 더 중요한 과제가 됨.
