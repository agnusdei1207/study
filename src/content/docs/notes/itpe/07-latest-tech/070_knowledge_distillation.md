## 연관 키워드

- 지식 증류(Knowledge Distillation), 교사 모델(Teacher Model), 학생 모델(Student Model)
- 온도 스케일링(Temperature Scaling), 소프트 타깃(Soft Target), 암묵적 지식(Dark Knowledge)
- KL 발산(KL Divergence), 교차 엔트로피(Cross-Entropy), TAKD(Teacher Assistant Knowledge Distillation)
- FitNets, 특징 맵 증류, 관계 기반 증류
- 양자화(Quantization), 가지치기(Pruning), 추론 지연(Latency)

## Ⅰ. 지식 증류(Knowledge Distillation)의 개요

- 핵심 요약 : 고성능 대형 모델의 출력 분포를 소형 모델이 모방하도록 학습시켜, 적은 연산으로 비슷한 성능을 얻는 모델 압축 기법.
- 개념 : 파라미터가 큰 **교사 모델** (Teacher Model)의 지식을 작은 **학생 모델** (Student Model)에 전이하여, 연산량을 줄이면서도 유사한 성능을 내도록 학습시키는 **지식 증류**(Knowledge Distillation) 기법.
- 배경 및 필요성 : 교사와 학생 모델의 용량 차이가 지나치게 크면 학생이 지식을 흡수하지 못해 학습이 수렴하지 않으므로, 중간 크기의 조교 모델을 거치는 **TAKD** (Teacher Assistant Knowledge Distillation, 조교 모델을 단계적으로 두는 증류)와 중간 표현 정렬을 함께 고려해야 한다.
- 주요 목적 : 모델의 파라미터 크기와 **추론 지연** (Latency, 입력부터 출력까지 걸리는 시간)을 줄여 모바일과 에지 디바이스에서 실시간 추론을 가능하게 하는 것.

## Ⅱ. 지식 증류(Knowledge Distillation)의 특징 및 장점

- 핵심 요약 : 정답 레이블만이 아니라 교사의 출력 분포를 학습 신호로 쓰면서, 학생 모델이 적은 용량으로 교사의 판단 방식을 닮는 구조.

1. 소프트 타깃 학습 : 교사가 내는 클래스별 확률 분포를 목표로 삼음 → 정답 외 오답 간 유사성 정보까지 전달되어 학습 신호가 풍부해짐.
2. **암묵적 지식** (Dark Knowledge, 오답 클래스 간의 상대적 확률 구조) : 고양이 사진에서 호랑이의 확률이 자동차보다 높다는 정보를 학생이 학습 → 일반화 성능 향상.
3. **온도 스케일링** (Temperature Scaling, 로짓을 온도 T로 나눠 분포를 부드럽게 만드는 기법) : 높은 확률 클래스로의 쏠림을 완화 → 소수 클래스의 정보량 보존.
4. 독립된 소형 아키텍처 : 학생 모델을 처음부터 가볍게 설계할 수 있어 추론 환경에 맞춘 최적화가 가능.

## Ⅲ. 지식 증류(Knowledge Distillation)의 구조 (흐름)

- 핵심 요약 : 같은 입력을 교사와 학생에 넣고, 온도를 적용한 분포 차이(소프트 손실)와 정답 차이(하드 손실)를 가중 합산해 학생만 갱신하는 구조.
- **소프트 손실과 하드 손실의 결합** : 교사 분포와 학생 분포의 KL 발산을 소프트 손실로, 정답 레이블과의 교차 엔트로피를 하드 손실로 두고 두 값을 가중 합산한다.
- **학생 가중치 갱신** : 교사 가중치는 동결하고, 합산 손실의 역전파로 학생 가중치만 갱신한다.

```text
[ 입력 데이터 X ]
      ↓
[ 교사 모델 ] 가중치 동결
  Softmax(z_T / T) → 교사 분포 p_T
      ↓
[ 학생 모델 ] 학습 중
  Softmax(z_S / T) → 학생 분포 q_S
      ↓
[ 소프트 손실 T² · KL(p_T ‖ q_S) ]
      ↓
[ 하드 손실 교차 엔트로피 (정답 Y) ]
      ↓
[ 전체 손실 α·소프트 + (1−α)·하드 ]
      ↓
[ 학생 가중치 역전파 갱신 ]
```

## Ⅳ. 지식 증류(Knowledge Distillation)의 비교

- 핵심 요약 : 증류는 구조를 새로 만드는 압축이고, 양자화와 가지치기는 기존 구조의 정밀도나 연결을 줄이는 압축이라 적용 시점과 성능 보존 방식이 다르다.

| 비교 축 | 지식 증류 | 양자화 | 가지치기 |
| --- | --- | --- | --- |
| 동작 원리 | 대형 모델의 지식을 소형 모델이 재학습 | 가중치의 비트 정밀도를 낮춤 (예: FP16에서 INT4) | 중요도가 낮은 가중치와 연결을 제거 |
| 모델 구조 | 새로운 소형 신경망 채택 | 기존 구조 유지 | 희소 행렬 형태로 구조가 바뀜 |
| 적용 시점 | 학습 단계 | 학습 후 (PTQ) 또는 학습 중 (QAT) | 학습 중 또는 미세 조정 단계 |
| 성능 보존 | 교사 수준에 근접하기 어려운 경우가 있음 | 손실이 작은 편 | 희소도를 높이면 성능이 급락할 위험 |

- 선택 기준 : 구조 자체를 줄여야 하는지, 기존 모델을 그대로 쓰면서 정밀도만 낮출 수 있는지에 따라 기법을 고름.

## Ⅴ. 지식 증류(Knowledge Distillation)의 한계와 방안

- 핵심 요약 : 용량 격차, 출력 로짓만 전달되는 정보 손실, 교사 편향의 전이를 단계적 증류, 중간 표현 정렬, 정답 데이터 가중으로 통제.

```text
[ 교사 모델 (예시: 70B) ]
      ↓ 1단계 지식 전이
[ 조교 모델 (예시: 14B) ]
      ↓ 2단계 지식 전이
[ 학생 모델 (예시: 1B) ]
```

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 교사와 학생의 용량 격차 | 격차가 크면 학생의 표현력이 부족해 학습이 수렴하지 않음 | 중간 크기의 조교 모델을 단계적으로 개입시키는 **TAKD** 적용 | 학생 검증 손실 수렴 여부 |
| 출력 로짓만 전달 | 최종 출력만 모방하면 교사 내부의 중간 추론 맥락을 학습하지 못함 | 중간 은닉층의 특징 맵을 맞추는 **FitNets**와 관계 기반 증류를 병행 | 과업별 정확도 차이 |
| 교사 편향과 환각의 전이 | 교사의 편향과 오류가 학생에게 그대로 전이되고 증폭될 수 있음 | 검증된 정답 데이터의 하드 손실 가중치를 높이고 데이터 정제 단계를 앞에 배치 | 편향 평가 지표, 오답률 |

## Ⅵ. 지식 증류(Knowledge Distillation)에 대한 기술사적 제언

- 핵심 요약 : 학생 모델의 설계 목표를 지연, 크기, 정확도로 구분해 증류와 양자화를 함께 쓰는 단계별 최적화 체계.

1. 모델 개발 팀은 교사와 학생의 용량 차이를 사전에 측정하고, 격차가 클 때는 조교 모델을 포함한 증류 단계를 설계하는 것이 바람직하다.
2. 서빙 팀은 학생 모델을 온디바이스 추론 환경의 실제 하드웨어에서 지연 시간과 메모리 사용량을 측정하고, 필요하면 양자화를 결합하여 목표 크기에 맞춘다.
3. 데이터 거버넌스 조직은 교사 모델이 학습한 데이터의 편향을 점검하고, 학생 학습에 쓰는 정답 데이터의 품질 기준을 정해 편향 전이를 막는다.

## Ⅶ. 결론

- 핵심 요약 : 지식 증류는 대형 모델의 판단 방식을 소형 모델에 옮겨 추론 비용과 지연을 낮추는 학습 기반 압축 기법이다.
- 시사점 : 증류의 성패는 교사 모델의 품질과 용량 설계에 달려 있어, 모델 선택과 데이터 검증이 압축 기법보다 먼저 이루어져야 한다.
