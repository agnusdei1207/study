## 30초 인출

- 본질: **지식 증류(Knowledge Distillation)** 는 한 모델의 출력·표현을 다른 모델의 학습 신호로 활용하는 학습 기법
- 메커니즘: 교사 신호 생성 → 학생 출력과 비교 → 증류 손실 계산 → 학생 모델 갱신

<details>
<summary>핵심 용어</summary>

- **지식 증류(Knowledge Distillation)** : 교사 모델의 출력·표현을 학생 모델 학습에 사용하는 기법
- **교사 모델(Teacher Model)** : 학습 목표가 될 출력·표현 신호를 제공하는 모델
- **학생 모델(Student Model)** : 교사 신호·정답을 이용해 학습하는 모델
- **소프트 타깃(Soft Target)** : 후보 간 상대 점수 정보를 포함한 확률분포 형태의 모델 출력
- **온도(Temperature)** : Softmax 분포를 평탄화·첨예화하는 조정값
- **KL 발산(Kullback–Leibler Divergence)** : 교사·학생 확률분포의 차이를 측정하는 정보량 척도
- **교차 엔트로피(Cross-Entropy, CE)** : 예측 분포와 정답 분포 사이의 분류 손실

## 2~4교시 25점 답안

### Ⅰ. 지식 증류의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **지식 증류(Knowledge Distillation)** 는 한 모델의 출력·표현을 다른 모델의 학습 신호로 활용하는 학습 기법 |
| 목적 | 목표 과업의 지식을 다른 모델 구조·규모에 전달해 학습 지원 |

### Ⅱ. 교사·학생 학습 관계

```text
같은 학습 입력
   ├─ 교사 모델 ── 소프트 출력·표현 ─┐
   └─ 학생 모델 ── 예측 출력 ────────┴─ 증류 손실
                                          │ 기울기
                                          ▼
                                    학생 모델 갱신
```

학생 모델이 작을 수 있으나 크기 차이는 필수 조건이 아니며, 같은 구조·과업 간 증류도 가능.

### Ⅲ. 소프트 타깃과 증류 유형

```text
교사 로짓 ── 온도 적용 Softmax ── 교사 분포 ─┐
학생 로짓 ── 온도 적용 Softmax ── 학생 분포 ─┴─ KL 손실
정답 레이블 ──────────────────────────────── 교차 엔트로피
                         두 손실을 과업에 맞게 결합
```

예시 손실은 `L = ατ² KL(p_teacher,τ || p_student,τ) + (1−α) CE(y, p_student,1)`. 온도 τ와 가중치는 구현·과업별 조정값이며 고정 표준값이 아님.

| 증류 유형 | 전달 신호 | 학습 초점 |
|---|---|---|
| 응답 기반 | 최종 출력·확률분포 | 교사 예측 패턴 |
| 특징 기반 | 중간층 표현 | 내부 특징 정렬 |
| 관계 기반 | 표본·토큰·특징 간 관계 | 거리·유사도·어텐션 정렬 |

### Ⅳ. 평가·기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 목표 장치·과업 조건이 정해지지 않으면 증류 신호 선택이 어려움 | 배포 제약과 필수 품질을 먼저 정하고 출력 기반 증류를 기준선으로 추가 신호의 이득 시험 |
| 교사 모델의 편향·오류가 학생에게 전달될 수 있음 | 정답·독립 평가자료로 품질·편향을 확인하고 운영 대상에 맞는 회귀시험 추가 |
