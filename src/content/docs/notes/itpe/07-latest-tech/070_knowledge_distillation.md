```text
 ┃
 ┣━ Ⅰ 개요 ───── 거대 모델(Teacher)의 높은 연산 비용·서빙 한계 → 경량 모델(Student)로 지식을 압축 이전하여 경량화
 ┣━ Ⅱ 특징 ───── 교사-학생 구조 · 부드러운 확률분포(Soft Target) 활용 · 암묵적 지식(Dark Knowledge) 전이 · 추론 속도 대폭 향상
 ┣━ Ⅲ 구조 ───── 교사 모델(Teacher) + 온도 매개변수(Temperature, T) + 학생 모델(Student) + 복합 손실함수(KL Divergence + CE)
 ┣━ Ⅳ 흐름 ───── ① 입력 데이터 주입 → ② 교사 모델 로짓 산출 및 Softmax(T) 적용 → ③ 학생 모델 예측 로짓 산출 → ④ 증류 손실 및 하드 레이블 손실 결합 역전파
 ┣━ Ⅴ 비교 ───── 가지치기(Pruning) vs 양자화(Quantization) vs 지식 증류 (가중치 제거 vs 비트 정밀도 축소 vs 모델 구조 자체를 작게 재학습)
 ┗━ Ⅵ 실무 ───── 학생 모델 용량 한계로 인한 지식 누락 / 증류 학습 시 추가 GPU 자원 소모 / 교사 모델의 편향·오류 전이
```

## 한 줄 본질
- 수백억 파라미터 거대 모델은 뛰어난 성능을 보이지만 엣지 기기나 모바일에서 실시간 추론 불가 → 정답(One-hot) 레이블 대신 교사 모델의 부드러운 확률 분포(Soft Target)를 정답지로 삼아 작은 학생 모델을 학습시킴 → 연산량과 메모리는 1/10로 줄이면서 원본 모델 성능의 90% 이상 유지 / 학생 모델의 파라미터 용량 한계로 인한 복잡한 추론 능력 감소

## 핵심 그림
```text
[지식 증류(Knowledge Distillation) 아키텍처 및 손실 결합]

                            [입력 데이터 (X)]
                                    |
           +------------------------+------------------------+
           |                                                 |
           v                                                 v
+-----------------------+                         +-----------------------+
|  교사 모델 (Teacher)  |                         |  학생 모델 (Student)  |
|  - 대규모 (고성능)    |                         |  - 소규모 (경량/초고속)|
|  - 가중치 고정(Freeze)|                         |  - 학습 대상          |
+-----------------------+                         +-----------------------+
           |                                                 |
           v [Logits: Z_t]                                   v [Logits: Z_s]
+-----------------------+                         +-----------------------+
| Softmax with Temp (T) |                         | Softmax with Temp (T) |
|   p_t = exp(Z_t/T)    |                         |   q_s = exp(Z_s/T)    |
+-----------------------+                         +-----------------------+
           |                                                 |
           \                       [증류 손실]               /
            \-----> [ KL Divergence Loss: L_KD(p_t, q_s) ] <-/
                                    |
                                    v (가중합)
                        +-----------------------+ <--- [ 학생 모델 일반 Softmax ]
                        | 최종 손실: L_Total    |      [ + 실제 정답 레이블 (y) ]
                        | α*L_KD + (1-α)*L_CE   | <--- [ Cross-Entropy: L_CE    ]
                        +-----------------------+
                                    |
                                    v (학생 모델 가중치 역전파 갱신)
```

## 핵심 용어
- 소프트 타깃(Soft Target): 클래스 간 유사도 정보를 담고 있는 연속적 확률 분포로, 예를 들어 자동차 사진에 대해 "자동차 0.85, 트럭 0.14, 당근 0.01"과 같이 오답 클래스 간의 상관관계를 전달
- 암묵적 지식(Dark Knowledge): 단순 One-hot 라벨("자동차=1, 나머지=0")에서는 버려지는 "자동차가 트럭과 더 닮았고 당근과는 전혀 닮지 않았다"는 클래스 간 기하학적 유사도 정보
- 온도(Temperature, T): Softmax 함수 분모에 도입되어 로짓을 평활화(Softening)하는 하이퍼파라미터로, T가 클수록 극단적 확률 차이가 완화되어 암묵적 지식이 풍부하게 노출됨

## 핵심 통찰
- 일반적인 지도학습의 One-hot 벡터는 엔트로피가 0에 가까워 정보량이 매우 적음 → 지식 증류의 핵심은 교사 모델이 수십억 개의 데이터를 보며 학습한 "오답 클래스들의 미세한 확률 비율"을 전수하는 데 있음
- 교사와 학생의 체급 차이가 너무 크면(예: 70B 모델에서 곧바로 1B 모델로 증류) 학생이 교사의 지식을 수용하지 못하고 발산 → 중간 크기의 조교 모델(Teacher Assistant, 70B → 13B → 1B)을 거치는 단계적 증류가 필수적
- 최종 출력값만 맞추는 응답 기반(Response-based) 증류를 넘어, 중간 히든 레이어의 어텐션 맵과 특징 텐서를 맞추는 특징 기반(Feature-based) 증류를 병행해야 복잡한 추론 능력 보존 가능

## 이웃 토픽과 구분
- 지식 증류 vs 모델 가지치기(Pruning): 가지치기는 기존 신경망에서 불필요한 뉴런/가중치를 잘라내는 기법 / 지식 증류는 작은 신경망을 새로 정의하고 큰 신경망의 출력을 흉내 내도록 재학습시키는 기법

## 문제·원인·대책
- 적용 상황: 클라우드 LLM(70B)을 스마트폰 탑재용 온디바이스 모델(3B)로 단일 단계 증류 중 심각한 성능 저하 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 학생 모델이 교사의 지식을 따라가지 못해 언어 이해 벤치마크 40% 폭락 | 교사-학생 간 모델 파라미터 용량 격차가 너무 커서 로짓 분포 수렴 실패 | 14B 크기의 보조 모델(Teacher Assistant)을 둔 2단계 단계적 증류 적용 | 최종 3B 모델 성능 원본 대비 88%까지 회복 |
| 증류 후 학생 모델이 교사의 환각(Hallucination) 및 편향된 응답까지 그대로 복제 | 교사 모델의 오류 확률 분포를 무비판적으로 목적함수에 반영 | 고품질 골든 데이터셋 기반의 정답 레이블 크로스 엔트로피 손실 가중치($1-\alpha$) 상향 | 학생 모델의 사실 일치도 및 무결성 제고 |
| 증류 학습 시 교사 모델의 포워드 연산 비용으로 인한 GPU 렌탈비 폭증 | 대규모 학습 데이터셋 전체에 대해 매 에포크마다 교사 추론 반복 | 교사 모델의 소프트 라벨(Logits)을 사전 생성하여 오프라인 벡터 캐싱 후 학생만 반복 학습 | 증류 학습 시간 70% 단축 및 GPU 비용 절감 |
