## 30초 인출

- 본질: **지식 증류(Knowledge Distillation)** 는 대규모 교사 모델(Teacher Model)이 보유한 암묵적 지식(Dark Knowledge)을 경량화된 학생 모델(Student Model)로 이전하여 작은 크기로도 고성능을 유지하게 만드는 모델 압축 기술
- 메커니즘: 동일 입력을 교사/학생 모델에 투입 → 온도(T) 스케일링을 통한 소프트 타깃 확률 분포 생성 → KL 발산 손실(소프트)과 정답 레이블 교차 엔트로피(하드) 결합 역전파 → 학생 모델 가중치 갱신
- 통찰: 교사와 학생 모델 간 용량 격차가 과도할 때 지식 전이가 실패하므로 중간 조교 모델을 거치는 단계적 증류(TAKD) 및 특징 맵(Feature) 정렬 결합 필수

<details><summary>핵심 용어</summary>

- **지식 증류(Knowledge Distillation)** : 대형 딥러닝 모델의 출력 분포를 지도 신호로 삼아 소형 모델을 학습시키는 기법.
- **소프트 타깃(Soft Target)** : 단순 원핫(One-Hot) 정답이 아닌, 오답 클래스 간의 상대적 유사도와 암묵적 지식을 포함하는 확률 분포.
- **온도(Temperature, T)** : Softmax 활성화 함수에서 로짓을 나누어 극단적인 확률 차이를 부드럽게 평탄화(Smoothing)하는 하이퍼파라미터.
- **암묵적 지식(Dark Knowledge)** : 정답 클래스 이외의 다른 클래스들이 갖는 미세한 확률적 상관관계 정보.
- **교사 조교(Teacher Assistant, TA)** : 거대 모델과 초소형 모델 사이의 성능 격차를 메우기 위해 중간 매개자로 투입되는 중간 규모 모델.

</details>

## 2~4교시 25점 답안

## Ⅰ. 지식 증류(Knowledge Distillation)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **지식 증류(Knowledge Distillation)** 는 대규모 파라미터를 가진 고성능 교사 모델(Teacher)의 지식을 경량화된 소형 학생 모델(Student)로 전이시켜 적은 연산량으로도 유사한 성능을 내도록 학습시키는 모델 압축 기술 |
| 목적 | 딥러닝 모델의 파라미터 크기 및 추론 지연(Latency)을 획기적으로 감축하여 모바일, 에지 디바이스 등 저전력 환경에서의 실시간 서빙 실현 |

## Ⅱ. 지식 증류의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **정보 풍부성** | 암묵적 지식 (Dark Knowledge) | "고양이" 사진에 대해 "호랑이" 10%, "자동차" 0.001%라는 오답 간 상대적 유사성 정보를 온전히 전달 |
| **분포 평탄화** | 온도 스케일링 (Temperature T) | 로짓(Logit)을 T로 나누어 특정 클래스로의 확률 집중을 완화하고 소수 클래스의 정보량을 보존 |
| **이중 손실 결합**| 하드 손실과 소프트 손실의 조화 | 실제 정답 레이블(Hard Target)과의 교차 엔트로피와 교사 모델의 소프트 타깃과의 KL 발산을 가중 합산 |
| **구조 독립성** | 이종 아키텍처 간 지식 전이 | 교사는 트랜스포머(ViT), 학생은 경량 합성곱(CNN) 등 서로 다른 구조 간에도 자유롭게 지식 증류 가능 |

## Ⅲ. 지식 증류 아키텍처 및 손실 함수 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 지식 증류(Knowledge Distillation) 학습 파이프라인 ]           │
└────────────────────────────────────────────────────────────────────────┘
 [ 입력 데이터 X ]
         │
         ├─────────────────────────────────────────┐
         ▼                                         ▼
 [ 교사 모델 (Teacher Model) ]             [ 학생 모델 (Student Model) ]
   - 사전 학습 완료 (동결 가중치)            - 경량 모델 (학습 진행 가중치)
   - 로짓 출력 z_T                           - 로짓 출력 z_S
         │                                         │
         ▼ (온도 T 적용)                           ▼ (온도 T 적용)
 [ Softmax(z_T / T) ]                      [ Softmax(z_S / T) ]
   - 교사 확률 분포 p_T                      - 학생 확률 분포 q_S
         │                                         │
         └────────────────────┬────────────────────┘
                              ▼
           [ 1. 소프트 증류 손실: L_soft = T² * KL(p_T || q_S) ]
                              │
                              │      [ 정답 레이블 Y (One-Hot) ]
                              │                   │
                              │                   ▼
                              │      [ 2. 하드 정답 손실: L_hard = CE(Y, Softmax(z_S / 1)) ]
                              ▼                   │
 ┌────────────────────────────────────────────────┴────────────────────────┐
 │ [ 전체 최적화 손실 ]: Loss = α * L_soft + (1 - α) * L_hard               │
 └────────────────────────────────────┬────────────────────────────────────┘
                                      │ (오차역전파 Backpropagation)
                                      ▼
                      [ 학생 모델 가중치 갱신 ]
```

| 손실 함수 요소 | 수식 및 메커니즘 | 공학적 의미 |
|---|---|---|
| **소프트 손실 (L_soft)** | T^2 * Σ p_T(i) * log(p_T(i) / q_S(i)) | 교사 모델의 예측 확률 분포를 학생이 모방하도록 유도 |
| **스케일 보정 (T^2)** | 역전파 시 1/T^2로 줄어드는 기울기 크기 보정 | 하드 손실과의 그라디언트 스케일 균형 유지 |
| **하드 손실 (L_hard)** | - Σ Y(i) * log q_S(i) (where T=1) | 실제 참값(Ground Truth) 레이블에 대한 정답 적중률 유지 |

## Ⅳ. 모델 경량화 3대 기법 비교

| 비교 항목 | 지식 증류 (Distillation) | 양자화 (Quantization) | 가지치기 (Pruning) |
|---|---|---|---|
| **동작 원리** | 대형 모델 지식을 소형 모델에 재학습 | 가중치 비트 정밀도 축소 (FP16→INT4) | 중요도 낮은 시냅스/뉴런 가중치 제거 |
| **모델 아키텍처**| 완전히 새로운 소형 신경망 채택 | 기존 아키텍처 구조 그대로 유지 | 희소 행렬(Sparse Matrix)로 구조 변형 |
| **적용 시점** | 모델 학습 단계 (Training Phase) | 학습 후(PTQ) 또는 학습 중(QAT) | 학습 중 또는 미세조정 단계 |
| **성능 보존율** | 우수 (소형 모델 잠재력 극대화) | 매우 우수 (1~2% 내외 미미한 손실) | 희소도 증가 시 성능 급락 위험 |
| **하드웨어 제약**| 표준 NPU/GPU 어디서나 즉시 구동 | 하드웨어의 저비트 정수 연산 지원 필요 | 하드웨어의 희소 가속(Sparse Core) 필요 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 교사 모델(예: 70B)과 학생 모델(예: 1B) 간의 파라미터 용량 차이가 지나치게 클 경우 학생의 표현력 부족으로 학습 수렴 실패 | 중간 규모의 조교 모델(Teacher Assistant, 예: 14B)을 단계별로 개입시키는 점진적 지식 증류(TAKD, Progressive Distillation) 체계 도입 |
| 최종 출력 로짓(Response-based)만 증류할 경우 교사 모델 내부 레이어의 풍부한 추론 맥락과 중간 표현 학습 불가 | 중간 은닉층의 특징 맵(Feature Map)을 정렬하는 FitNets 및 어텐션 맵 유사도를 맞추는 관계 기반(Relation-based) 증류 병행 |
| 교사 모델 자체가 학습 데이터의 편향이나 잘못된 환각을 포함하고 있을 경우 학생 모델에 고스란히 편향이 전이·증폭 | 신뢰도 높은 골든 정답 데이터셋에 대한 하드 손실(L_hard) 가중치 α를 상향 조정하고 데이터 클렌징 게이트웨이 결합 |

## Ⅵ. 제언

조교 모델을 활용한 점진적 다단계 지식 증류(TAKD)와 학습 후 활성화 인식 양자화(AWQ)를 결합하여 온디바이스 sLLM을 구현하는 복합 경량화 파이프라인 구축.

```text
[ 초대형 교사 모델 (LLM 70B) ]
               │
               ▼ (1단계: 특징 맵 및 소프트 로짓 증류)
[ 중간 조교 모델 (Teacher Assistant 14B) ]
               │
               ▼ (2단계: 점진적 하위 지식 증류)
[ 초경량 학생 모델 (Student sLLM 3B) ]
               │
               ▼ (3단계: 4비트 양자화 AWQ 적용)
[ W4A16 온디바이스 AI 패키징 (1.8GB 메모리 점유) ] ──> [ 모바일/에지 실시간 구동 ]
```

| 구분 | 단순 단일 지식 증류 | 제언: 점진적 다단계 증류 + 양자화 |
|---|---|---|
| **학습 안정성** | 용량 격차로 인한 정보 손실 심화 | 조교 모델을 통한 매끄러운 지식 전이 |
| **추론 속도** | FP16 구동으로 모바일 서빙 한계 | 4비트 정수화로 NPU 추론 속도 4배 향상 |
| **최종 모델 크기** | 3B FP16 기준 약 6GB (RAM 초과) | 양자화 결합으로 1.8GB 이하 압축 달성 |
