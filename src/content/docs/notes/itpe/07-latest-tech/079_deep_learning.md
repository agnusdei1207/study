## 연관 키워드

- 딥러닝(Deep Learning), 은닉층(Hidden Layer), 인공신경망(ANN), 순전파(Forward Propagation), 역전파(Backpropagation), 옵티마이저(Optimizer)
- 기울기 소실(Vanishing Gradient), 과적합(Overfitting), 잔차 연결(Residual Connection), 드롭아웃(Dropout)
- 특징 엔지니어링(Feature Engineering), 종단간 표현 학습, 스케일링 법칙(Scaling Law), 설명 가능 인공지능(XAI), 지식 증류, 양자화

## Ⅰ. 딥러닝의 개요

- 핵심 요약 : 다중 은닉층으로 원시 데이터의 추상 특징을 자동 학습하는 인공신경망 기반 기계학습 모델.
- 개념 : 2개 이상의 은닉층을 쌓아 원시 데이터에서 고차원 추상 특징을 계층적으로 학습하는 **딥러닝** (Deep Learning, 다층 구조의 인공신경망(ANN, Artificial Neural Network) 기반 기계학습 방법).
- 배경 및 필요성 : 층이 깊어질수록 **기울기 소실** (Vanishing Gradient, 학습 신호가 앞쪽 층까지 전달되지 못하는 현상), **과적합** (Overfitting, 학습 데이터에만 맞춰져 새 데이터에서 성능이 떨어지는 현상), 연산 비용 증가가 생긴다. 따라서 구조 개선, 정규화, 경량화를 함께 설계하는 방식이 필요하다.
- 주요 목적 : 사람이 직접 설계하던 **특징 엔지니어링** (Feature Engineering, 입력 특징을 사람이 수작업으로 정의하는 작업)의 한계 극복, 복잡한 비선형 관계 모델링, 영상과 언어 같은 비정형 데이터의 고정밀 인지와 생성.

## Ⅱ. 딥러닝의 특징 및 장점

- 핵심 요약 : 종단간 표현 학습, 보편 근사 능력, 규모 확장성이 자동 특징 추출과 고성능으로 이어지는 특성.

1. **종단간 표현 학습** (End-to-End Representation Learning, 입력에서 출력까지 특징을 함께 학습하는 방식) : 선과 모서리에서 객체와 의미로 층마다 추상화 → 수작업 특징 설계 없이 복잡한 패턴 포착.
2. **범용 근사 정리** (Universal Approximation Theorem, 충분한 뉴런과 비선형 활성화 함수로 연속 함수를 임의 정밀도로 근사할 수 있다는 이론) : 복잡한 비선형 관계의 모델링 가능 → 문제 유형에 대한 표현력 확보.
3. **스케일링 법칙** (Scaling Law, 데이터, 파라미터, 연산량 증가에 따라 성능이 예측 가능하게 향상되는 경향) : 데이터와 모델을 키울수록 성능이 계속 개선 → 대규모 학습 투자의 근거 제공.
4. **연쇄 법칙 기반 최적화** (Chain Rule-based Optimization, 출력 오차를 역방향으로 전파해 모든 가중치의 기울기를 계산하는 방식) : 자동 미분 엔진으로 전체 파라미터를 효율적으로 갱신 → 대규모 모델 학습 가능.

## Ⅲ. 딥러닝의 구조 (흐름)

- 핵심 요약 : 순전파로 예측과 손실을 구하고, 역전파로 기울기를 계산한 뒤, 옵티마이저로 가중치를 반복 갱신하는 학습 루프.
- 순전파 : 입력에 가중치와 활성화 함수를 차례로 적용해 출력과 손실을 계산한다. 활성화 함수로는 ReLU(Rectified Linear Unit)가 널리 쓰인다.
- 역전파 : 연쇄 법칙으로 손실의 기울기를 출력층에서 입력층 방향으로 계산한다.
- **옵티마이저** (Optimizer, 기울기를 이용해 가중치를 갱신하는 알고리즘) : SGD(Stochastic Gradient Descent, 확률적 경사 하강법), Adam 등이 대표적이다.

```text
[ 입력 X ]
      ↓  순전파: z = Wa + b, a = 활성화(z)
[ 예측값 Y_hat ] → [ 손실 L(Y, Y_hat) ]
      ↓  역전파: 연쇄 법칙으로 기울기 계산
[ 층별 기울기 dL/dW ]
      ↓  옵티마이저 적용
[ 가중치 갱신 ] → 손실이 수렴할 때까지 반복
```

```text
[ 입력층 X ]
      ↓
[ 은닉층 1 (ReLU) ]
      ↓
[ 은닉층 2 (ReLU) ]
      ↓
[ 출력층 (Softmax) ]
```

## Ⅳ. 전통적 머신러닝과 딥러닝의 비교

- 핵심 요약 : 정형 데이터와 해석이 중요한 문제에서는 전통적 기법이, 비정형 데이터와 대규모 자원이 있는 문제에서는 딥러닝이 유리.

| 비교 항목 | 전통적 머신러닝 (Classical ML) | 딥러닝 (Deep Learning) |
| --- | --- | --- |
| 특징 추출 방식 | 전문가의 수작업 특징 설계 | 다층 신경망의 종단간 자동 학습 |
| 데이터 의존성 | 소규모 정형 데이터에 적합 | 대규모 비정형 데이터(이미지, 텍스트, 음성)에 필수 |
| 성능 확장성 | 데이터가 늘어도 일정 수준에서 포화 | 데이터와 모델 규모 확장 시 성능 지속 개선 |
| 하드웨어 요구 | 일반 CPU로 학습 가능 | GPU(Graphics Processing Unit)나 TPU(Tensor Processing Unit) 가속 필요 |
| **설명 가능 인공지능** (XAI, Explainable Artificial Intelligence) | 의사결정나무처럼 상대적으로 직관적 | 파라미터가 방대해 블랙박스에 가까움 |
| 대표 알고리즘 | SVM, Random Forest, XGBoost | CNN, RNN/LSTM, Transformer, Diffusion |

- 선택 기준 : 데이터 규모가 작고 설명이 필요하면 전통적 기법을, 비정형 데이터와 충분한 연산 자원이 있으면 딥러닝을 우선 검토한다.

## Ⅴ. 딥러닝의 한계와 방안

- 핵심 요약 : 기울기 소실, 과적합, 블랙박스 문제를 구조 설계, 정규화, 설명 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기울기 소실 | 층이 깊어질수록 역전파 기울기가 0에 수렴해 앞쪽 층이 학습되지 않음 | ReLU 계열 활성화 함수, **잔차 연결** (Residual Connection, 입력을 출력에 더해 기울기 경로를 확보하는 구조), He 초기화 | 층별 기울기 크기 |
| 과적합 | 파라미터 수에 비해 데이터가 부족하거나 편향되어 일반화 실패 | **드롭아웃** (Dropout), 데이터 증강, 가중치 감쇠(Weight Decay), 조기 종료(Early Stopping) | 학습·검증 손실 차이 |
| 블랙박스 해석 불가 | 수많은 파라미터의 상호작용을 사람이 설명하기 어려움 | Grad-CAM, SHAP(Shapley Additive Explanations), 어텐션 맵 시각화 등 XAI 기법 통합 | 설명 검토 건수 |

## Ⅵ. 딥러닝 적용을 위한 기술사적 제언

- 핵심 요약 : 성능 중심의 실험에서 벗어나 추론 효율, 신뢰성 검증, 설명 가능성을 함께 갖춘 운영 기준으로 딥러닝을 관리할 필요.

1. 추론 효율화 : 양자화(AWQ, GPTQ)와 **지식 증류** (Knowledge Distillation, 큰 교사 모델의 출력을 작은 학생 모델이 모방하도록 학습하는 기법)를 배포 목표에 맞춰 적용해 GPU 메모리 비용과 엣지 배포 제약을 낮춘다.
2. 미션 크리티컬 신뢰성 검증 : 의료, 금융, 국방처럼 오동작 비용이 큰 영역은 적대적 공격(Adversarial Attack)에 대한 내성 점검과 **불확실성 추정** (Monte Carlo Dropout, 추론 시에도 드롭아웃을 켜서 예측의 분산을 측정하는 기법)을 도입 승인 조건으로 둔다.
3. 엔지니어링 기준 정립 : 데이터 품질, 모델 평가, 설명 기록을 개발 표준에 포함해 실험 결과가 운영 기준으로 이어지도록 한다.

## Ⅶ. 결론

- 핵심 요약 : 딥러닝은 다층 신경망으로 특징 학습을 자동화하는 기계학습의 핵심 방법.
- 시사점 : 성능 이득은 데이터와 연산 규모에 비례해 커지지만, 해석과 신뢰성 확보 없이는 운영에 쓰기 어려우므로 효율화와 검증 체계를 함께 갖추는 것이 전제된다.
