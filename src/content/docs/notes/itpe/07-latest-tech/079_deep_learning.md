## 핵심 용어
- 표현 학습(Representation Learning): 개발자가 도메인 규칙을 코딩하지 않고, 신경망 스스로 원시 입력 데이터 속에 내재된 유의미한 잠재 표현(Latent Representation)을 발굴하는 학습 패러다임
- 범용 근사 정리(Universal Approximation Theorem): 하나의 은닉층과 적절한 비선형 활성화 함수를 가진 피드포워드 신경망은 충분한 뉴런이 주어질 때 임의의 연속 함수를 원하는 정확도로 근사할 수 있다는 수학적 정리
- 연쇄 법칙(Chain Rule): 합성함수의 미분 법칙으로, 최종 출력의 손실(Loss)로부터 각 은닉층의 가중치까지 오차를 역방향으로 전파하며 편미분 값을 효율적으로 계산하는 역전파 알고리즘의 기초

## 핵심 통찰
- 딥러닝 혁명의 진정한 이유는 "망을 깊게(Deep) 쌓을수록 필요한 뉴런 수가 지수적으로 줄어든다"는 점: 얕은 망으로 복잡한 비선형 함수를 표현하려면 무한대에 가까운 뉴런이 필요하지만, 층을 겹치면 계층적 재사용이 가능해져 파라미터 효율성이 극대화됨
- 비선형 활성화 함수(Activation Function)가 없는 신경망은 100층을 쌓아도 단일 선형 행렬곱($y = W_{total}x$)으로 축약됨 → 비선형성을 주입하는 ReLU와 GELU가 딥러닝 표현력의 원천
- 모델의 성능은 "알고리즘의 정교함"보다 "신경망 크기 $\times$ 데이터 규모 $\times$ 연산량(Compute)"에 의해 결정된다는 쓴 교훈(The Bitter Lesson)이 생성형 AI 시대까지 관통하는 제1원리

## 이웃 토픽과 구분
- 전통 머신러닝 vs 딥러닝: 머신러닝은 데이터 크기가 커지면 성능이 평탄화(Plateau) / 딥러닝은 데이터와 모델 크기가 커질수록 성능이 지속적으로 우상향(Scaling Law)

## 문제·원인·대책
- 적용 상황: 금융 거래 사기 탐지(FDS) 모델을 50층 심층 신경망으로 구축 중 학습 실패
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 은닉층이 깊어질수록 역전파 초입에서 미분값이 0에 수렴하여 앞단 학습 중단 | Sigmoid/Tanh 함수의 도함수 최댓값이 0.25에 불과하여 연쇄 곱셈 시 지수적 감쇠 | ReLU 또는 Leaky ReLU 활성화 함수 적용 및 He 가중치 초기화 도입 | 기울기 소실 해결 및 심층 레이어 정상 수렴 |
| 학습 데이터에는 정확도 99%를 보이나 실제 운영 환경에서 60%로 급락 | 복잡한 파라미터 수에 비해 데이터가 부족하여 노이즈까지 암기(과적합) | 드롭아웃(Dropout p=0.3), 가중치 감쇠(Weight Decay), 조기 종료(Early Stopping) 결합 | 검증 오차 감소 및 일반화 성능 25% 향상 |
| 심층 레이어 간 입력 데이터 분포가 계속 뒤흔들려 학습 속도 극단적 저하 | 내부 공변량 변화(Internal Covariate Shift) 현상 발생 | 배치 정규화(Batch Normalization) 및 층 정규화(Layer Normalization) 적용 | 학습 수렴 속도 5배 가속 및 안정적 학습률 적용 가능 |

## 내 의견
- [설명가능 인공지능(XAI)과 딥러닝 거버넌스의 필수적 결합] 딥러닝의 압도적 예측 성능에도 불구하고, 금융·의료·국방 등 고위험(High-Risk) 영역에서는 "왜 이런 결론을 내렸는지" 증명하지 못하면 도입 불가 → 나라면: 딥러닝 모델 출력단에 SHAP, LIME 및 어텐션 롤아웃(Attention Rollout) 분석 파이프라인을 의무화하여 예측 기여도 피처를 시각화 보고서로 자동 생성하는 신뢰성 보증 체계 구축
