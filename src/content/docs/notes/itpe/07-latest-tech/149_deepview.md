## 연관 키워드

- 딥뷰(DeepView), ETRI, 시각지능, 지능형 영상 분석, CCTV
- 다중 객체 추적, 재식별(Re-ID), 이상 행동 인식, 자연어 영상 검색
- 엣지 AI, 오경보, 비식별화, 개인정보 보호

## Ⅰ. ETRI 딥뷰(DeepView)의 개요

- 핵심 요약 : 영상 속 사람·차량의 속성과 동선, 이상 행동을 이해해 관제 업무를 돕는 ETRI의 시각지능 플랫폼.
- 개념 : 영상을 분석해 사람과 차량의 속성, 이동 경로, 복합 위험 행동을 인식하고 검색할 수 있게 하는 **시각지능** (Visual Intelligence) 기술 플랫폼.
- 배경 및 필요성 : 야간이나 악천후에는 그림자와 가림(Occlusion)으로 관제 **오경보** (False Alarm)가 늘고, 요원이 수많은 화면을 육안으로 보면 피로로 사각지대가 생김. 이 때문에 오경보를 걸러내는 시공간 맥락 판단 계층이 필요함.
- 주요 목적 : 육안 감시의 사각지대 축소, 실종자·수배차량 탐색 시간 단축, 도심 안전 이상 징후의 신속 대응.
- 실증 현황 : 대전시와 ETRI의 2021년 실증에서 쓰러짐 등 이상 행동 탐지에 적용되었고, 2023년에는 CCTV 기반 불법 현수막 탐지 실증사업에 활용됨 (ETRI 및 보도 기준).

## Ⅱ. ETRI 딥뷰(DeepView)의 특징 및 장점

- 핵심 요약 : 시간 축을 함께 보는 추적과 재식별, 행동 인식, 자연어 검색이 관제 인력의 탐색 부담을 줄이는 방식.

1. **다중 객체 추적** (Multi-Object Tracking) : DeepSORT, ByteTrack 계열 추적으로 겹침이 생겨도 같은 대상의 ID 유지 → 교차로 같은 혼잡 장면에서도 추적 끊김 감소.
2. **재식별** (Re-ID, Re-Identification) : 복장과 체형의 외형 임베딩을 **코사인 유사도**로 매칭 → 여러 카메라에 걸친 이동 궤적을 이어 붙임.
3. 이상 행동 인식 : 관절 골격의 움직임 시퀀스를 분석해 쓰러짐, 폭력, 월담, 배회를 판정 → 단순 움직임 감지보다 오경보가 적음.
4. 자연어 영상 검색 : 시각-언어 모델을 연계해 "빨간 가방을 멘 남성" 같은 질의로 대량의 영상을 검색 → 사후 조사 시간 단축.

## Ⅲ. ETRI 딥뷰(DeepView)의 구조 (흐름)

- 핵심 요약 : 영상 수집, 객체와 속성 추출, 행동 분석, 시공간 색인의 순서로 흐르며 색인이 알림과 검색의 공통 기반이 됨.

```text
[ CCTV 스트림 (RTSP 등 표준 프로토콜) ]
          ↓
[ 디코딩 · 객체 검출 · 속성 추출 ]
          ↓
[ 객체 추적 · 이상 행동 분석 ]
          ↓
[ 시공간 색인 (지식 그래프) ]
          ↓
[ 이상 징후 알림 또는 사후 검색 ]
```

```text
사건 한 건의 기록 예
  시각 : 14:02:11
  장소 : A골목
  대상 : 사람 (복장 속성 포함)
  사건 : 쓰러짐 (알림 연계)
```

## Ⅳ. ETRI 딥뷰(DeepView)의 비교

- 핵심 요약 : 픽셀 변화를 보는 전통 모션 감지, 한 장면만 보는 단일 객체 탐지보다 시공간 맥락을 함께 보는 점이 차별점.

| 비교 축 | 전통 모션 감지 (CCTV VMD) | 단일 프레임 객체 탐지 | 딥뷰 플랫폼 |
| --- | --- | --- | --- |
| 분석 단위 | 픽셀 변화량 | 정지 영상 한 장 | 시공간 연속 시퀀스 |
| 인식 범위 | 움직임 유무 | 사람·차량 등 클래스 | 복장 속성, 행위, 광역 재식별 |
| 오경보 특성 | 바람, 나뭇가지, 동물에 취약 | 정적 물체 오탐 존재 | 시공간 맥락으로 오경보 억제 |
| 검색 방식 | 시간대별 타임라인 탐색 | 프레임 단위 탐색 | 자연어와 이미지 기반 검색 |
| 카메라 연계 | 개별 카메라 독립 분석 | 개별 카메라 독립 분석 | 다중 카메라 간 동선 연결 |

## Ⅴ. ETRI 딥뷰(DeepView)의 한계와 방안

- 핵심 요약 : 악천후 화질, 대용량 전송, 개인정보 문제를 엣지 처리, 신호 보강, 비식별화와 접근 통제로 해결.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 저조도·악천후 화질 저하 | 야간, 역광, 눈·비에서 객체 오인식과 오경보 급증 | 저조도 개선 신경망 전처리, **적외선** (IR) 열화상 센서 융합 | 오경보율 |
| 대용량 영상 중앙 전송 | 수천 채널 영상을 중앙으로 보내 대역폭과 GPU 부하 포화 | 에지 카메라에서 1차 검출 후 이상 구간의 메타데이터만 본청 전송 | 채널당 전송량, 이벤트 지연 |
| 개인정보 수집 문제 | 불특정 시민의 얼굴·차량번호 상시 수집이 「개인정보 보호법」 위반 우려를 낳음 | 화면 표출 시 자동 비식별(블러) 처리, 마스킹 해제는 영장에 기반한 수사로 제한 | 비식별 처리율, 접근 로그 감사 결과 |

## Ⅵ. ETRI 딥뷰(DeepView)에 대한 기술사적 제언

- 핵심 요약 : 엣지 처리와 이벤트 기반 전송, 비식별화 원칙을 운영 기준으로 세워 관제 효율과 권리 보호를 함께 확보하는 방향.

1. 전송 구조 : 관제 기관은 상시 영상 전송 대신 이벤트 발생 구간의 메타데이터 중심 전송을 기본 방식으로 채택하는 것이 바람직하다. 대역폭과 서버 자원 부담을 함께 줄일 수 있다.
2. 추적 운영 : 지자체 관제 조직은 다음 출현 카메라를 지도 기반으로 자동 전환하는 기능을 도입해 모니터 요원의 수동 화면 전환 부담을 덜어야 한다.
3. 개인정보 통제 : 관제 기관은 비식별 처리를 기본값으로 두고, 원본 복원 권한의 발동 조건과 기록을 법령에 맞게 정해 감사 가능하게 운영해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 딥뷰는 영상을 사건 단위의 시공간 데이터로 바꿔 관제를 돕는 시각지능 플랫폼임.
- 시사점 : 기술 성능보다 오경보 억제와 개인정보 통제가 실제 도입의 문턱이 되므로, 기능 확장과 함께 권한 통제 체계를 같이 설계해야 한다.
