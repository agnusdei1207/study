## 연관 키워드

- 휴머노이드 로봇(Humanoid Robot), 피지컬 AI(Physical AI), VLA(Vision-Language-Action)
- 전신 제어(WBC, Whole-Body Control), ZMP(Zero Moment Point), 준직구동(QDD, Quasi-Direct Drive)
- 직렬 탄성 액추에이터(SEA, Series Elastic Actuator), 배터리 핫스왑(Hot-swap), ISO 10218

## Ⅰ. 휴머노이드 로봇(피지컬 AI 국가 프로젝트)의 개요

- 핵심 요약 : 사람이 쓰는 기존 작업 환경을 바꾸지 않고 공구를 다루는 두 다리 로봇을 피지컬 AI 전략 과제로 키우는 흐름.
- 개념 : **휴머노이드 로봇** (Humanoid Robot)은 두 다리로 보행하고 양팔과 다관절 손(Dexterous Hand)으로 사람용 도구를 직접 다루는 로봇이며, 인식과 판단을 담당하는 **피지컬 AI** (Physical AI) 모델이 결합된 지능형 로봇이다.
- 배경 및 필요성 : 이족 보행은 넘어짐(Fall-over) 위험이 있고 배터리 지속 시간도 짧아, 현장 교체가 가능한 배터리 체계와 넘어짐 회복 제어가 함께 갖춰져야 현장 투입이 가능하다. 국내에서는 2026년 하반기 경제성장전략에서 피지컬 AI를 국가전략산업으로 지정했다(정부 발표 기준).
- 주요 목적 : 생산인구 감소에 따른 제조·물류 현장의 인력 공백을 메우고, 위험 작업을 대체하며, 범용 피지컬 AI 플랫폼의 기술 주도권을 확보하는 것.

## Ⅱ. 휴머노이드 로봇(피지컬 AI 국가 프로젝트)의 특징 및 장점

- 핵심 요약 : 기존 환경 호환성과 계층형 제어가 현장 적용 범위와 작업 유연성으로 이어지는 구조.

1. 기존 환경 호환 : 사람과 같은 신체 형상으로 기존 계단, 공구, 카트를 그대로 사용 → 설비 개조 비용 없이 투입 가능.
2. 계층형 제어 : 고수준 추론, 중간 수준 전신 제어, 저수준 구동을 나눠 맡김 → 판단 지연과 균형 제어를 분리해 안정성 확보.
3. 범용 작업 : 시각 정보와 언어 지시를 함께 해석 → 작업 종류가 바뀌어도 재설계 없이 대응 범위를 넓힘.

## Ⅲ. 휴머노이드 로봇(피지컬 AI 국가 프로젝트)의 구조 (흐름)

- 핵심 요약 : 두뇌 역할의 VLA 모델, 소뇌 역할의 전신 제어기, 척수 역할의 구동기로 이어지는 3계층 폐루프 구조.
- **VLA** (Vision-Language-Action) 모델 : 시각과 언어 입력을 받아 작업 단계와 목표 궤적을 산출하는 상위 파운데이션 모델.
- **전신 제어** (WBC, Whole-Body Control) : 균형 유지와 양팔 작업을 한꺼번에 풀어 관절별 토크 명령을 계산하는 중위 제어기.
- **준직구동 액추에이터** (QDD, Quasi-Direct Drive) : 감속비를 낮춘 구동 방식으로 역구동성과 충격 흡수를 확보하는 관절 구동기.

```text
[ 작업 지시: 렌치를 가져와 볼트 조이기 ]
                  ↓
[ 상위 계층: VLA 파운데이션 모델 ]
  시각 인식, 작업 분해, 목표 궤적 산출
                  ↓
[ 중위 계층: 전신 제어기 (WBC) ]
  균형 유지와 양팔 작업 동시 계산
                  ↓
[ 하위 계층: 관절 구동기 ]
  전류 제어, 토크 명령 실행
                  ↓
[ 실제 물리 환경 (접촉·외력) ]
                  ↓ (센서 피드백)
[ 관절 센서·힘 센서 → 상위 계층 ]
```

```text
[ 계층별 제어 주기 ]
상위: 작업 계획 (저주기)
        ↓
중위: 전신 균형·궤적 (중주기)
        ↓
하위: 관절 토크 (고주기)
```

## Ⅳ. 휴머노이드 로봇과 다른 로봇 형태의 비교

- 핵심 요약 : 바퀴형, 4족형, 협동 로봇은 특정 환경에 강점이 있지만, 사람 환경을 공유하는 범용 작업은 휴머노이드가 유일하게 노린다.

| 비교 축 | 자율이동로봇 (AMR) | 4족 보행 로봇 | 협동 로봇 (Cobot) | 휴머노이드 로봇 |
| --- | --- | --- | --- | --- |
| 이동 방식 | 바퀴 주행 | 4족 보행 | 고정식 | 2족 보행 |
| 물체 조작 | 이송 중심 | 소형 팔 부착 시 제한적 | 단일 팔 정밀 조작 | 양팔과 다관절 손 조작 |
| 환경 적응 | 전용 통로 필요 | 계단 극복 가능 | 전용 작업대 고정 | 기존 작업 환경 공유 |
| 인간 도구 사용 | 불가 | 불가 | 전용 공구 교체 필요 | 사람용 도구 직접 사용 |

- 선택 기준 : 고정된 작업대에는 협동 로봇, 평면 물류에는 AMR, 사람용 설비를 그대로 쓰는 복합 작업에만 휴머노이드를 검토한다.

## Ⅴ. 휴머노이드 로봇(피지컬 AI 국가 프로젝트)의 한계와 방안

- 핵심 요약 : 배터리, 넘어짐, 원가 문제를 배터리 교체 체계, 충격 흡수 구조, 부품 국산화로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 짧은 연속 작업 시간 | 다수 고출력 모터 동시 구동으로 배터리 소모가 큼 | 무인 **배터리 핫스왑**(Hot-swap, 전원을 끄지 않고 배터리 교체) 도킹 체계와 회생 제동 회로 적용 | 연속 가동 시간, 교체 대기 시간 |
| 넘어짐과 충돌 사고 | 발 헛디딤이나 외부 충돌로 전도 발생, 작업자 상해 위험 | 충격 흡수용 **직렬 탄성 액추에이터**(SEA, Series Elastic Actuator) 채택과 넘어짐 시 낙하 완화 제어 | 전도 횟수, 충돌 감지 건수 |
| 고가 부품으로 높은 제조 원가 | 고가 감속기와 정밀 센서 다량 탑재 | 준직구동 방식 등 부품 국산화와 모듈화, 양산 라인 활용 | 대당 부품 원가 |

## Ⅵ. 휴머노이드 로봇(피지컬 AI 국가 프로젝트)에 대한 기술사적 제언

- 핵심 요약 : 학습 인프라, 현장 실증, 안전 기준을 함께 설계해 현장 투입을 단계적으로 여는 것이 바람직하다.

1. 연구 조직은 실제 현장에서 1:1로 학습하는 방식과 시뮬레이션 병렬 학습을 병행하여, 동작 학습에 걸리는 기간을 단축해야 한다.
2. 산업 주관 부처는 현장 실증 사업을 단계별로 확대하고, 실증 결과를 안전 기준과 인증 체계에 환류하는 구조를 마련해야 한다.
3. 안전 담당 조직은 산업용 로봇 안전 표준인 ISO 10218을 기준으로, 사람 접근을 감지하면 속도를 낮추는 안전 로직을 설계 단계부터 포함해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 휴머노이드 로봇은 사람의 환경을 그대로 쓰는 범용 작업 로봇으로, 피지컬 AI 기술 경쟁의 상징적 대상이다.
- 시사점 : 실제 가치는 하드웨어 성능보다 현장 실증과 안전 체계를 얼마나 빨리 갖추는지에 따라 결정되므로, 기술과 안전 기준을 함께 발전시켜야 한다.
