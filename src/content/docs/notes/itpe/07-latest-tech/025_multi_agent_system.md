## 30초 인출

- 본질: **멀티에이전트 시스템(Multi-Agent System, MAS)** 은 여러 자율 에이전트가 상호작용해 공동 목표를 수행하는 시스템
- 메커니즘: 목표·역할 분해 → 에이전트별 실행·정보 교환 → 결과 통합·검증 → 완료 또는 보완

<details>
<summary>핵심 용어</summary>

- **멀티에이전트 시스템(Multi-Agent System, MAS)** : 복수의 자율 에이전트가 상호작용해 공동 목표를 수행하는 시스템
- **분산 문제 해결(Distributed Problem Solving, DPS)** : 복합 문제를 하위 과업으로 나누고 여러 행위자가 협력해 해결하는 방식
- **오케스트레이션(Orchestration)** : 과업 분배·순서·상태·종료 조건을 조정하는 기능
- **공유 작업공간(Shared Workspace)** : 협업 주체가 중간 결과와 작업 상태를 기록·참조하는 공간
- **비평가 에이전트(Critic Agent)** : 다른 에이전트의 산출물을 정해진 기준으로 검토하는 역할의 에이전트
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **멀티에이전트 시스템(Multi-Agent System, MAS)** 은 여러 자율 에이전트가 상호작용해 공동 목표를 수행하는 시스템 |
| 목적 | 복합 과업을 분할하고 역할·정보를 결합해 협력적으로 해결 |

### Ⅱ. 협업 흐름

```text
공동 목표
    ↓ 과업 분할
역할별 에이전트 실행
    ↓ 정보·중간 결과 교환
결과 통합·검토
    ↓
완료 또는 보완 실행
```

### Ⅲ. 주요 구성

| 구성 | 책임 |
|---|---|
| 역할별 에이전트 | 전문 하위 과업 수행과 결과 제출 |
| 오케스트레이터 | 의존성·순서·상태·종료 조건 관리 |
| 통신·공유 작업공간 | 에이전트 간 정보와 중간 산출물 전달 |
| 검증자 | 근거·정확성·정책 준수 확인 |

### Ⅳ. 실행 통제

| 한계 | 대응 |
|---|---|
| 오류 산출물이 다른 작업의 입력으로 전파될 수 있음 | 중요 인계 지점에서 근거·형식·품질 검증 |
| 순환 호출·장기 실행으로 완료되지 않을 수 있음 | 호출·시간 한도, 재시도 횟수, 명시적 종료 조건 설정 |
| 도구 권한이 불필요하게 확대될 수 있음 | 에이전트·작업 단위 최소 권한과 실행 기록 적용 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 에이전트 수 증가가 품질 개선으로 이어지는지 불분명할 수 있음 | 단일 에이전트 기준선과 품질·비용·지연을 비교하고, 독립 검증 가능한 하위 과업에 협업 구성을 한정 |
