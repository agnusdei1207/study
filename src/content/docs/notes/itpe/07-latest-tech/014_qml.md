## 30초 인출

- 본질: **양자머신러닝(QML, Quantum Machine Learning)** 은 중첩, 얽힘, 양자 간섭의 양자역학적 물리 현상을 활용하여 고차원 힐베르트 공간에서 기계학습 모델의 데이터 표현 및 연산 속도를 지수적으로 가속하는 융합 기술
- 메커니즘: 고전 데이터를 양자 상태로 인코딩한 후 파라미터화된 양자 회로(PQC/VQC)를 통과시켜 측정하고, 고전 컴퓨터의 경사하강법으로 회로 파라미터(θ)를 반복 최적화
- 통찰: NISQ(잡음 중간규모 양자) 시대에 회로 깊이 증가에 따른 바렌 플래토(Barren Plateau, 기울기 소실) 현상이 심각하므로 국소 비용 함수 도입과 얕은 회로 기반 양자 커널법 결합 필수

<details><summary>핵심 용어</summary>

- **양자머신러닝 (QML)** : 양자 컴퓨팅 알고리즘을 머신러닝의 분류, 군집화, 최적화 문제에 결합한 하이브리드 컴퓨팅 패러다임.
- **큐비트 (Qubit)** : 0과 1의 상태를 동시에 가질 수 있는 중첩(Superposition) 특성을 가진 양자 정보의 기본 단위.
- **PQC / VQC (Parameterized/Variational Quantum Circuit)** : 회로 내부 게이트의 회전 각도(θ)를 학습 가능한 파라미터로 설정하여 최적화하는 양자 신경망 회로.
- **양자 상태 인코딩 (Quantum State Encoding)** : 고전 특징 벡터를 양자 비트의 진폭(Amplitude) 또는 위상(Angle/Phase)으로 변환하는 입력 사상 기법.
- **바렌 플래토 (Barren Plateau)** : 양자 신경망의 큐비트 수와 층수가 증가할 때 비용 함수의 기울기가 지수함수적으로 0에 수렴하여 학습이 불가능해지는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 양자머신러닝(QML)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **양자머신러닝(QML)** 은 큐비트의 중첩(Superposition)과 얽힘(Entanglement) 특성을 기계학습 알고리즘에 결합하여 고차원 특징 공간 사상 및 선형대수 연산을 지수적으로 가속하는 차세대 하이브리드 컴퓨팅 기술 |
| 목적 | 고전 컴퓨터로 불가능한 초고차원 복잡계 시뮬레이션, 지수적 최적화 탐색 가속, 신약 후보물질 발굴 및 금융 포트폴리오 최적화 |

## Ⅱ. 양자머신러닝의 물리적 원리 및 핵심 특징

| 구분 | 양자 물리 원리 | QML 알고리즘 특징 및 장점 |
|---|---|---|
| **양자 중첩 (Superposition)** | $N$개 큐비트로 $2^N$개 상태 동시 표현 | 지수적 병렬 연산(Quantum Parallelism)으로 대규모 상태 공간 동시 탐색 |
| **양자 얽힘 (Entanglement)** | 공간적 거리를 초월한 큐비트 간 상관관계 | 고전 피처로는 표현할 수 없는 변수 간 비선형 복합 상관관계를 단일 힐베르트 공간에 사상 |
| **양자 간섭 (Interference)** | 파동 함수의 보강 및 상쇄 간섭 | 정답 상태의 확률 진폭은 증폭하고 오답 상태의 확률 진폭은 상쇄하여 탐색 가속 |
| **양자 커널 (Quantum Kernel)** | 고차원 힐베르트 공간 투영 | 고전 입력 $x$를 양자 상태 $|Φ(x)⟩$로 사상하여 고전 SVM 커널 연산을 양자 회로에서 직접 계산 |

## Ⅲ. QML 변분 양자 회로(VQC) 아키텍처 및 하이브리드 최적화 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ 하이브리드 양자-고전(Quantum-Classical) 학습 파이프라인 ]     │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 [ 1. 고전 데이터 입력 (Classical) ] │  [ 2. 양자 상태 임베딩 (State Encoding) ]
  고전 특징 벡터 x = (x1, x2, ..., xn)│   - 각도 인코딩 (Angle) / 진폭 인코딩 (Amplitude)
                                    │   - 초기 상태 |0...0⟩ ──> 양자 상태 |ψ(x)⟩ 준비
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 3. 파라미터화된 양자 회로 (VQC / PQC: Ansatz) ]                      │
│    - 회전 게이트 R_x(θ), R_y(θ), R_z(θ) 층 적용                        │
│    - CNOT 얽힘 게이트 층을 통한 다중 큐비트 간 상관관계 형성           │
│    - 최종 양자 상태 |ψ(x, θ)⟩ = U(θ)|ψ(x)⟩ 생성                        │
└────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 4. 양자 관측 및 고전 최적화 (Measurement & Classical Optimization) ] │
│   - 해밀토니안 기대치 ⟨H⟩ 측정 (파울리 Z 기저 샘플링) ──> 손실 계산     │
│   - 파라미터 시프트 룰(Parameter-Shift Rule) 기반 양자 그래디언트 도출 │
│   - 고전 옵티마이저 (Adam, COBYLA)를 통한 가중치 θ 갱신                │
└────────────────────────────────────────────────────────────────────────┘
```

| 파이프라인 단계 | 핵심 공학 활동 | 산출물 및 특징 |
|---|---|---|
| **상태 인코딩** | 고전 데이터 $x$를 양자 게이트(U_x) 회전 각도로 사상 | 양자 상태 벡터 $|ψ(x)⟩$ |
| **안자츠 (Ansatz)** | 문제 구조에 맞춘 파라미터 회로 템플릿 구성 | 학습 가중치 매트릭스 $U(θ)$ |
| **측정 (Measurement)** | 양자 붕괴를 통한 앙상블 기대치 추정 (Shot 반복) | 실수 스칼라 예측값 $\hat{y}$ |
| **고전 최적화** | 하드웨어 미분 파라미터 시프트 룰 적용 및 손실 최소화 | 갱신된 최적 각도 $θ^*$ |

## Ⅳ. 고전 머신러닝 vs 양자 머신러닝(QML) 비교

| 비교 항목 | 고전 머신러닝 (Classical ML) | 양자 머신러닝 (QML / Hybrid) |
|---|---|---|
| **기본 연산 단위** | 비트 (0 또는 1), 텐서(Tensor) | 큐비트 (0과 1의 블로흐 구면 중첩 상태) |
| **특징 공간 크기** | 고차원 사상 시 차원의 저주 발생 | $N$개 큐비트로 $2^N$ 차원의 힐베르트 공간 즉시 활용 |
| **핵심 알고리즘** | Gradient Descent, Backprop, SVM | VQC(Variational Circuit), QSVM, QGAN |
| **계산 복잡도** | 행렬 반전 $O(N^3)$, 지수적 탐색 시간 | HHL 알고리즘 기반 $O(\log N)$ 행렬 계산 잠재력 |
| **현재 기술 단계** | 완전 상용화 및 대규모 서빙 성숙 | NISQ(잡음형 중간규모) 단계의 하이브리드 실증 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 큐비트 수와 레이어가 증가할수록 비용 함수의 기울기가 지수적으로 0에 수렴하는 바렌 플래토(Barren Plateau) 현상 | 국소 해밀토니안(Local Observable) 측정 기법 채택 및 얕은 회로 구조와 파라미터 초기화 기법 적용 |
| 현행 NISQ 하드웨어의 짧은 결맞음 시간(Coherence Time)과 게이트 에러율로 인한 연산 왜곡 | 양자 에러 완화(ZNE: Zero-Noise Extrapolation) 기술 도입 및 양자-고전 하이브리드 분할 실행 |

## Ⅵ. 제언

현행 NISQ 하드웨어의 제약을 고려하여 전면적 양자 전환 대신, 연산 복잡도가 가장 높은 커널 계산 부문만 양자 가속기로 오프로딩하는 양자 커널 SVM 하이브리드 아키텍처 구축.

```text
[ 초고차원 금융/화학 데이터 ]
             │
             ▼
[ QPU (양자 처리 장치) ] ──> [ 양자 상태 매핑 및 양자 커널 행렬 K_ij 계산 ]
                                           │
                                           ▼ (커널 행렬 전송)
[ 고전 GPU/CPU 클러스터 ] ──> [ 고전 SVM 최적화 알고리즘 (Dual Problem) ]
                                           │
                                           ▼
[ 기존 고전 모델 대비 분류 경계 정확도 및 연산 수렴 속도 향상 ]
```

| 구분 | 완전 고전 머신러닝 | 제언: 양자 커널 오프로딩 하이브리드 |
|---|---|---|
| **커널 사상** | RBF 등 고정된 수학적 커널 함수 의존 | 힐베르트 공간의 복잡한 양자 얽힘 기반 맞춤형 커널 |
| **연산 분담** | CPU/GPU에서 모든 행렬 및 최적화 수행 | 양자 회로는 커널 계산만 전담, 최적화는 안정된 고전 HW 담당 |
| **노이즈 민감도** | 하드웨어 노이즈 없음 | 얕은 깊이 회로 설계로 NISQ 하드웨어 에러 영향 최소화 |
