<summary>핵심 용어</summary>

- **양자머신러닝(Quantum Machine Learning, QML)** : 양자 계산을 데이터 표현이나 학습 모델의 일부에 적용하는 접근

- **매개변수화 양자 회로(Parameterized Quantum Circuit, PQC)** : 조정 가능한 게이트 매개변수를 가진 양자 회로
- **하이브리드 양자·고전 학습(Hybrid Quantum-Classical Learning)** : 양자 회로 계산과 고전 최적화를 결합한 학습 방식
- **바렌 플래토(Barren Plateau)** : 회로 매개변수에 대한 비용 함수 기울기가 매우 작아져 최적화가 어려워지는 현상

### Ⅱ. 하이브리드 학습 구조

```text
고전 입력 자료
      ↓ 인코딩
매개변수화 양자 회로
      ↓ 측정
고전 손실·평가값
      ↓ 최적화기 매개변수 갱신
양자 회로 재실행
```

### Ⅲ. 주요 구성

| 구성 | 역할 |
|---|---|
| 양자 회로 | 입력 상태를 변환하고 측정 가능한 결과 생성 |
| 고전 최적화기 | 손실·측정 결과를 이용해 회로 매개변수 조정 |
| 평가 기준선 | 같은 자료·과업에서 고전 모델과 성능·비용 비교 |

제언: 데이터 인코딩부터 측정·최적화까지 전체 비용을 고전 기준선과 비교하는 검증.

| 목적 | 양자 계산을 활용할 수 있는 학습 문제와 모델을 탐색 |

### Ⅱ. 하이브리드 학습 구조

```text
고전 입력 자료
```

### Ⅲ. 학습 구성요소

| 요소 | 역할·검토점 |
|---|---|
| 자료 인코딩 | 고전 입력을 양자 상태로 준비; 준비 비용 포함 |
| 회로·측정 | 회로 연산 결과를 반복 측정해 고전 값으로 획득 |
| 고전 최적화 | 측정 결과로 손실을 평가하고 회로 매개변수 갱신 |

### Ⅳ. 주요 제약과 적용 판단

| 한계 | 대응·판단 |
|---|---|
| 하드웨어 잡음과 회로 깊이의 영향 | 회로 규모를 제한하고 기기 조건별 측정 변동 평가 |
| **바렌 플래토(Barren Plateau)** 로 기울기 기반 학습이 어려울 수 있음 | 회로 구조·깊이·초깃값별 학습 가능성 비교 |
| 양자 계산의 이점이 과업별로 확인되지 않을 수 있음 | 인코딩·측정·호출 비용까지 포함해 동일 조건의 고전 기준선과 비교 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 양자 회로 성능만 비교하면 데이터 준비와 반복 측정 비용이 드러나지 않음 | 업무 과업별 고전 기준선과 전체 파이프라인 비용을 먼저 측정하고, 재현 가능한 이점이 확인된 후보만 후속 실증에 배정 |
