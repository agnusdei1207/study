## Ⅰ. 양자머신러닝(QML, Quantum Machine Learning)의 개요

- 개념 : 양자역학의 고유한 물리적 원리인 **중첩** (Superposition), **얽힘** (Entanglement), **양자 간섭** (Quantum Interference)을 머신러닝 알고리즘에 융합하여, 고전 컴퓨터로는 불가능한 지수적 고차원 **힐베르트 공간** (Hilbert Space) 탐색과 연산 복잡도 단축을 달성하는 차세대 컴퓨팅 기술.
- 배경 및 필요성 : 무어의 법칙 종식과 초거대 인공지능 모델 학습에 수반되는 막대한 전력·연산 비용의 물리적 한계를 돌파하고, 현재의 노이즈가 존재하는 **중규모 양자 컴퓨팅** (NISQ, Noisy Intermediate-Scale Quantum) 환경에서 **양자 우위** (Quantum Advantage)를 조기 실현하기 위해 부각됨.
- 핵심 목적 : 대규모 선형대수 및 조합 최적화의 지수적 가속, 고차원 복잡 데이터의 양자 커널 매핑, 신약·신소재 분자 구조의 정밀 시뮬레이션.

## Ⅱ. 양자머신러닝(QML, Quantum Machine Learning)의 핵심 아키텍처 및 동작 메커니즘

NISQ 시대의 QML은 **파라미터화된 양자 회로** (PQC, Parameterized Quantum Circuit)를 양자 프로세서(QPU, Quantum Processing Unit)에서 실행하고, 가중치 최적화는 고전 CPU(Central Processing Unit)/GPU(Graphics Processing Unit)가 담당하는 **양자-고전 하이브리드** (Variational Quantum Eigensolver/VQC, Variational Quantum Circuit) 루프로 동작함.

```text
[ NISQ 시대의 하이브리드 양자-고전 머신러닝 루프 (VQC) ]

+-----------------------------------------------------------------+
|               고전 컴퓨터 (Classical Computer / CPU/GPU)        |
|  1. 고전 데이터 입력 (x) ────────────────────────┐              |
|  4. 손실 함수(Loss) 계산 및 옵티마이저 갱신 (Adam)│              |
|     - 파라미터(θ) 업데이트 ──► θ_new = θ - η∇L   │              |
+--------------------------------┬─────────────────┼──────────────+
                                 │ 최적화된 θ 전달 │ 고전 데이터 전달
                                 ▼                 ▼
+-----------------------------------------------------------------+
|               양자 프로세서 (Quantum Processor / QPU)            |
|  2. 양자 상태 준비 (State Preparation / Quantum Embedding)      |
|     - 고전 데이터 x를 큐비트 상태 |ψ(x)⟩로 인코딩 (Amplitude/Angle) |
|  3. 파라미터화된 양자 회로 (PQC / Ansatz U(θ)) 실행              |
|     - 단일 큐비트 회전(RX, RY) 및 다중 큐비트 얽힘(CNOT) 게이트  |
|  4. 양자 측정 (Measurement / Observable ⟨M⟩)                    |
|     - 파동함수 붕괴 후 기댓값 추출 ──► 고전 컴퓨터로 피드백 반환|
+-----------------------------------------------------------------+
```

- **양자 상태 인코딩(Quantum Embedding)** : 고전 데이터를 힐베르트 공간의 양자 상태로 변환 (진폭 인코딩, 각도 인코딩, 양자 커널 맵).
- **변분 양자 회로(VQC / PQC)** : 고전 신경망의 가중치처럼 회전 게이트의 각도 파라미터 `theta`를 조정 가능한 변수로 두고 양자 게이트 연산 수행.
- **양자 측정 및 기댓값 계산** : 해밀토니안 관측량(Observable)을 다수 측정(Shots)하여 손실 함수 값을 고전 공간으로 추출.
- **파라미터 시프트 룰(Parameter-Shift Rule)** : QPU 내부에서 직접 역전파를 수행할 수 없으므로, 회전 각도를 양의 방향과 음의 방향으로 미세 이동시켜 정확한 해석적 기울기(Gradient) 계산.

## Ⅲ. 양자머신러닝(QML, Quantum Machine Learning)의 세부 구성 요소 및 비교 분석

| 분류 유형 (데이터 / 알고리즘) | 입력 데이터 형태 | 처리 알고리즘 | 대표 기술 및 적용 사례 |
| --- | --- | --- | --- |
| **CC (Classical-Classical)** | 고전 데이터 | 고전 컴퓨터 기반 양자 모사 | 양자 영감 알고리즘 (Quantum-inspired), 텐서 네트워크 |
| **CQ (Classical-Quantum)** | 고전 데이터 | 양자 알고리즘 (QPU) | 양자 SVM (QSVM), VQC 분류기, 고전 금융 포트폴리오 양자 최적화 |
| **QC (Quantum-Classical)** | 양자 데이터 (물리/화학) | 고전 머신러닝 알고리즘 | 양자 센서 노이즈 필터링, 양자 오류 정정(QEC) 고전 제어 |
| **QQ (Quantum-Quantum)** | 양자 데이터 (상태 벡터) | 완전 양자 머신러닝 알고리즘 | 완전 내결함성 양자 컴퓨터 기반 양자 위상 추정(QPE), 양자 PCA(Principal Component Analysis) |

- 현재 상용 연구가 가장 활발한 영역은 고전 비즈니스 데이터를 양자 컴퓨터로 가속하는 CQ(Classical-Quantum) 하이브리드 영역임.

## Ⅳ. 양자머신러닝(QML, Quantum Machine Learning)의 주요 한계점 및 해결 방안

- 파라미터 최적화 시 기울기가 지수적으로 소실되는 바렌 고원(Barren Plateaus) 문제 :
  - 한계점 : 큐비트 수와 회로 깊이가 증가할수록 목적 함수의 기울기 분산이 지수적으로 0에 수렴하여 신경망 학습이 완전 마비됨.
  - 해결 방안 : 로컬 비용 함수(Local Cost Function) 설계, 회로 가중치 얕은 초기화(Identity Block), 대칭성을 보존하는 **양자 합성곱 신경망** (QCNN, Quantum Convolutional Neural Network) 도입.
- NISQ 하드웨어의 짧은 결맞음 시간(Coherence Time)과 물리적 게이트 노이즈 :
  - 한계점 : 외부 환경과의 상호작용으로 양자 얽힘이 붕괴되어 깊은 회로를 수행할 수 없고 연산 결과에 심각한 오류 누적.
  - 해결 방안 : **양자 오류 완화** (QEM, Quantum Error Mitigation; Zero-Noise Extrapolation) 기술 적용 및 논리 큐비트 기반의 **내결함성 양자 컴퓨팅** (FTQC, Fault-Tolerant Quantum Computing) 전환.
- 대규모 고전 데이터를 고속으로 양자 상태로 변환하는 QRAM(Quantum Random Access Memory)의 물리적 미구현 :
  - 한계점 : 대용량 빅데이터를 양자 회로에 주입하는 인코딩 시간(O(2^N))이 양자 알고리즘의 속도 향상 이점을 상쇄하는 I/O 병목 발생.
  - 해결 방안 : **텐서 네트워크** (Tensor Network) 기반 사전 압축 기법 활용 및 양자 커널 추정(Quantum Kernel Estimation) 방식 선별 채택.

## Ⅴ. 양자머신러닝(QML, Quantum Machine Learning) 적용 및 발전을 위한 기술사적 제언

- 순수 양자 모델보다 '고전-양자 하이브리드 파이프라인' 아키텍처 선제 구축 : 대규모 특징 추출은 고전 딥러닝(ResNet/Transformer)이 수행하고, 최종 고차원 의사결정 경계만 QPU가 담당하는 계층형 구조 설계.
- 오픈소스 프레임워크(PennyLane, Qiskit Machine Learning) 기반 사내 R&D 파이프라인 수립 : 하드웨어 비종속적인 양자 알고리즘 개발 역량을 조기 내재화하여 차세대 양자 가속기 클라우드 즉각 연동 준비.
- 명확한 양자 우위 도메인(신약 분자 결합, 물류 배송 경로 최적화) 중심의 실증 과제 추진 : 단순 텍스트/이미지 분류 대신 고전 컴퓨터가 풀기 어려운 거대 조합 최적화 및 양자 다체 화학 시뮬레이션 우선 집중.
