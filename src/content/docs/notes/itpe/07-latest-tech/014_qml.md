## 연관 키워드

- 양자머신러닝(QML, Quantum Machine Learning), 큐비트(Qubit), 중첩(Superposition), 얽힘(Entanglement)
- 파라미터화된 양자 회로(PQC, Parameterized Quantum Circuit), VQC(Variational Quantum Circuit), 파라미터 시프트 룰(Parameter-Shift Rule)
- NISQ(Noisy Intermediate-Scale Quantum), 바렌 고원(Barren Plateaus), QCNN, QEM, FTQC
- 양자 우위(Quantum Advantage), 양자 커널, 텐서 네트워크

## Ⅰ. 양자머신러닝의 개요

- 핵심 요약 : 양자 상태의 성질을 머신러닝에 결합해 고전 컴퓨터로 다루기 어려운 고차원 탐색과 최적화를 시도하는 기술.
- 개념 : 중첩(Superposition), 얽힘(Entanglement), 양자 간섭(Quantum Interference)을 머신러닝 알고리즘에 결합해 고차원 상태 공간을 활용하는 기술 (**양자머신러닝**, QML, Quantum Machine Learning).
- 배경 및 필요성 : 대규모 모델 학습에 드는 전력과 연산 비용이 고전 방식의 한계에 가까워지는 가운데, 노이즈가 있는 중규모 양자 컴퓨팅(NISQ, Noisy Intermediate-Scale Quantum) 환경에서 실용적 이점을 먼저 확인하려는 요구가 커짐.
- 핵심 목적 : 대규모 선형대수와 조합 최적화 가속, 고차원 데이터의 양자 커널 매핑, 분자 구조의 시뮬레이션.

## Ⅱ. 양자머신러닝의 특징 및 장점

- 핵심 요약 : 양자 상태 공간을 활용하는 인코딩과 고전 최적화를 결합한 하이브리드 구조가 특정 문제에서 연산 이점을 노리는 방식.

1. 양자 상태 인코딩 : 고전 데이터를 진폭, 각도, 양자 커널 맵으로 큐비트 상태에 옮김 → 고차원 상태 공간에서 데이터 구조를 표현.
2. **파라미터화된 양자 회로** (PQC, Parameterized Quantum Circuit) : 회전 게이트의 각도를 학습 변수로 둠 → 고전 신경망의 가중치와 같은 역할을 수행.
3. 하이브리드 최적화 : 양자 회로는 기댓값을 측정하고 가중치 갱신은 고전 컴퓨터가 맡음 → 현재 하드웨어의 규모 제약 안에서도 학습 가능.

## Ⅲ. 양자머신러닝의 구조 (흐름)

- 핵심 요약 : 고전 컴퓨터가 파라미터를 갱신하고 양자 프로세서가 회로를 실행하여 측정값을 되돌려주는 반복 루프 구조.

```text
[ 하이브리드 변분 양자 회로 학습 루프 ]

고전 컴퓨터 : 데이터 입력, 파라미터 θ 전달
   ↓
양자 프로세서 : 데이터 인코딩, 회로 실행
   ↓
양자 측정 : 기댓값 추출
   ↓
고전 컴퓨터 : 손실 계산, θ 갱신
   ↓
수렴할 때까지 반복
```

```text
[ 고전 데이터의 양자 인코딩 ]

고전 데이터 x
   ↓ 각도 인코딩 또는 진폭 인코딩
양자 상태 |ψ(x)⟩
   ↓ 회전·얽힘 게이트 적용
측정으로 기댓값 추출
```

- 기울기 계산 : QPU 내부에서는 역전파를 직접 수행할 수 없으므로, 파라미터 시프트 룰로 회전 각도를 앞뒤로 조금 옮겨 기울기를 구함.

## Ⅳ. 양자머신러닝의 유형 비교

- 핵심 요약 : 데이터가 고전인지 양자인지, 처리가 고전인지 양자인지에 따라 네 유형으로 나뉘며, 현재 상용 연구는 고전 데이터를 양자로 처리하는 CQ 영역에 집중됨.

| 분류 (데이터 / 처리) | 입력 데이터 | 처리 방식 | 대표 기술 및 적용 사례 |
| --- | --- | --- | --- |
| CC (Classical-Classical) | 고전 데이터 | 고전 컴퓨터로 양자 방식을 모사 | 양자 영감 알고리즘, 텐서 네트워크 |
| CQ (Classical-Quantum) | 고전 데이터 | 양자 회로로 처리 | 양자 SVM(Support Vector Machine), VQC(Variational Quantum Circuit) 분류기, 포트폴리오 최적화 |
| QC (Quantum-Classical) | 양자 데이터 (물리·화학) | 고전 머신러닝으로 처리 | 양자 센서 노이즈 필터링, 양자 오류 정정 제어 |
| QQ (Quantum-Quantum) | 양자 데이터 (상태 벡터) | 완전 양자 알고리즘 | 양자 위상 추정(QPE, Quantum Phase Estimation), 양자 PCA(Principal Component Analysis) |

- 실무 적용 시에는 CQ 하이브리드 방식이 현재 가장 현실적인 선택지임.

## Ⅴ. 양자머신러닝의 한계와 방안

- 핵심 요약 : 기울기 소실, 노이즈, 데이터 인코딩 병목을 회로 설계, 오류 완화, 데이터 압축으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **바렌 고원** (Barren Plateaus) | 큐비트 수와 회로 깊이가 늘수록 기울기가 지수적으로 작아져 학습이 정체 | 전역 대신 국소 비용 함수 설계, 얕은 회로와 초기화 전략, 대칭 구조를 가진 **QCNN**(Quantum Convolutional Neural Network) | 기울기 분산 |
| NISQ 하드웨어의 노이즈 | 결맞음 시간이 짧고 게이트 오류가 누적되어 깊은 회로 실행이 어려움 | **양자 오류 완화** (QEM, Quantum Error Mitigation) 적용, 논리 큐비트 기반 **FTQC**(Fault-Tolerant Quantum Computing) 전환 | 회로 깊이 대비 정확도 |
| 고전 데이터 인코딩 병목 | 대용량 데이터를 양자 상태로 옮기는 비용이 알고리즘의 속도 이점을 상쇄 | 텐서 네트워크 기반 사전 압축, 양자 커널 추정 방식 선별 채택 | 인코딩 시간 대비 성능 |

## Ⅵ. 양자머신러닝에 대한 기술사적 제언

- 핵심 요약 : 하이브리드 구조와 명확한 양자 우위 영역을 기준으로 단계적으로 준비하는 방향.

1. 대규모 특징 추출은 고전 딥러닝이 맡고 최종 의사결정 경계만 QPU가 담당하는 하이브리드 파이프라인을 먼저 구축하는 것이 현실적임.
2. 연구 조직은 PennyLane, Qiskit Machine Learning 같은 하드웨어 비종속 프레임워크로 사내 R&D 기반을 만들어 클라우드 양자 가속기 연동에 대비하는 것이 필요함.
3. 신약 분자 결합이나 물류 경로 최적화처럼 고전 컴퓨터가 풀기 어려운 조합 최적화 영역을 실증 과제로 우선 삼아야 함.

## Ⅶ. 결론

- 핵심 요약 : QML은 양자 상태의 특성을 고전 학습 루프에 결합한 하이브리드 기술이며, 현재는 NISQ의 한계 안에서 특정 영역을 검증하는 단계임.
- 시사점 : 범용 대체 기술이 아니라 특정 최적화와 시뮬레이션 문제의 보조 가속기로 접근하는 것이 현실적임.
