## 지식 로드맵 내 현재 위치

지식 위치: 기계학습 → 순차적 의사결정 → 보상 기반 정책 학습 → **강화학습**

## 30초 인출

- 본질: **강화학습(Reinforcement Learning, RL)** 은 에이전트가 환경과 상호작용해 받은 보상으로 행동 정책을 학습하는 방법
- 메커니즘: 상태 관측 → 정책에 따른 행동 → 환경 전이·보상 → 장기 보상을 반영해 정책 갱신

<details>
<summary>핵심 용어</summary>

- **강화학습(Reinforcement Learning, RL)** : 환경과의 상호작용에서 얻은 보상으로 행동 정책을 학습하는 방법
- **마르코프 결정 과정(Markov Decision Process, MDP)** : 상태·행동·전이·보상으로 순차적 의사결정 문제를 표현하는 모형
- **정책(Policy)** : 상태에 따라 행동을 선택하는 규칙
- **가치 함수(Value Function)** : 상태 또는 상태·행동에서 기대되는 누적 보상의 추정
- **탐험과 활용(Exploration vs. Exploitation)** : 새로운 행동을 시도하는 것과 현재 유망한 행동을 이용하는 것 사이의 균형
- **벨만 방정식(Bellman Equation)** : 현재 보상과 다음 상태의 할인된 가치를 연결해 가치 함수를 재귀적으로 표현하는 관계식

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **강화학습(Reinforcement Learning, RL)** 은 에이전트가 환경과 상호작용해 받은 보상으로 행동 정책을 학습하는 방법 |
| 목적 | 순차적 행동의 장기 결과를 반영하는 정책 학습 |

### Ⅱ. 상호작용 구조

```text
환경 상태·관측
       ↓
에이전트 정책의 행동 선택
       ↓
환경 상태 전이
       ↓
보상·새 상태 반환
       ↓
정책·가치 갱신
       └──── 다음 상태에서 반복
```

### Ⅲ. MDP 구성

| 요소 | 의미 |
|---|---|
| 상태(State) | 환경의 현재 상황 표현 |
| 행동(Action) | 에이전트가 선택할 수 있는 행위 |
| 전이(Transition) | 행동 후 다음 상태로 이동하는 관계 |
| 보상(Reward) | 행동 결과의 바람직함을 나타내는 신호 |

제언: 보상 신호를 실제 목표와 맞추고 위험 행동을 제한하는 학습 환경.

### Ⅲ. MDP와 학습 대상

| 대상 | 의미·역할 |
|---|---|
| 상태·행동 | 의사결정 상황과 선택 가능한 행위 |
| 전이·보상 | 행동 결과로 바뀌는 상태와 즉시 피드백 |
| 정책 | 상태별 행동 선택 규칙 |
| 가치 함수 | 장기 누적 보상의 기대값 추정 |

### Ⅳ. 학습 유형과 적용 고려

| 접근 | 학습 특성 | 검토점 |
|---|---|---|
| 가치 기반 | 행동 가치 추정 후 높은 가치를 선택 | 상태·행동 공간의 크기 |
| 정책 기반 | 정책을 직접 최적화 | 보상 변동과 탐색 안정성 |
| 모델 기반 | 환경 전이 모형을 계획에 활용 | 환경 모형 오차와 현실 차이 |
| 공통 고려 | 탐험·보상 설계 | 안전 제약·보상 편향·평가 기준 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 보상 설계가 실제 목표와 다르면 보상을 높이면서도 원치 않는 행동을 학습할 수 있음 | 실제 업무 목표와 금지 조건을 함께 정의하고, 시뮬레이션·제한 실험에서 정책 결과와 안전 조건을 검증한 뒤 적용 범위를 결정 |
