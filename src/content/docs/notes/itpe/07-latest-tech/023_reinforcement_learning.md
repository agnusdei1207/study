## 연관 키워드

- 강화학습, 에이전트(Agent), 환경(Environment), 정책(Policy), 누적 보상, 벨만 방정식
- MDP, 탐험과 이용, PPO, 액터-크리틱, 보상 해킹, RLHF, GRPO

## Ⅰ. 강화학습(Reinforcement Learning)의 개요

- 핵심 요약 : 정답 없이 시행착오로 누적 보상을 최대화하는 행동 정책을 학습하는 머신러닝 패러다임.
- 개념 : **에이전트** (Agent)가 **환경** (Environment)과 상호작용하며 상태에 따라 행동을 선택하고, 미래의 **누적 보상** (Cumulative Return)을 최대화하는 **정책** (Policy)을 학습하는 머신러닝 방식.
- 배경 및 필요성 : 정답 레이블을 대량으로 만들기 어렵고 의사결정이 연속되며 보상이 늦게 주어지는 문제, 예를 들어 로봇 제어, 자율주행, **거대언어모델** (LLM, Large Language Model)의 응답 정렬에는 지도학습만으로 대응하기 어려움.
- 주요 목적 : 장기 보상의 극대화, **마르코프 결정 과정** (MDP, Markov Decision Process) 기반의 최적 정책 도출, 탐험과 이용 사이의 균형 확보.

## Ⅱ. 강화학습(Reinforcement Learning)의 특징 및 장점

- 핵심 요약 : 정답 대신 보상 신호만으로 학습하므로 명시적 감독이 어려운 순차 의사결정 문제에 적용 가능.

1. 정답 없는 학습 : 행동의 결과로 받는 보상만 사용 → 정답 데이터 구축 비용 없이 복잡한 전략을 발견.
2. 장기 가치 최적화 : 벨만 방정식으로 미래 보상을 재귀적으로 계산 → 당장 보상이 작아도 장기적으로 유리한 행동을 선택.
3. 탐험과 이용의 균형 : 새로운 행동을 시도하는 탐험과 알려진 최선을 쓰는 이용을 조절 → 지역 최적해에 갇히는 것을 줄임.

```text
[ 에이전트-환경 상호작용 루프 ]

        에이전트 (Agent)
   행동 A_t ↓         ↑ 상태 S_t, 보상 R_t
        환경 (Environment)
```

- 5대 MDP 요소 : 상태 집합, 행동 집합, 전이 확률, 보상 함수, 할인율(γ).
- 벨만 방정식은 현재 보상과 다음 상태 가치의 재귀 관계로, 동적 계획법과 신경망 학습의 토대가 됨.

## Ⅲ. 강화학습(Reinforcement Learning)의 구조 (흐름)

- 핵심 요약 : 상태를 관측하고 행동을 고른 뒤 보상과 다음 상태를 받아 정책을 갱신하는 반복 루프.

```text
[ 학습 한 사이클 ]

현재 상태 s 관측
          ↓
정책 π가 행동 a 선택 (탐험 또는 이용)
          ↓
환경이 보상 r과 다음 상태 s' 반환
          ↓
경험 (s, a, r, s') 저장 또는 즉시 사용
          ↓
가치 함수 또는 정책 파라미터 갱신
```

- 가치 함수는 상태 가치 V(s)와 행동 가치 Q(s, a)로 나뉘며, 정책을 따를 때의 기대 누적 할인 보상을 나타냄.

## Ⅳ. 강화학습(Reinforcement Learning)의 비교

- 핵심 요약 : 가치 기반은 이산 행동에, 정책 기반은 연속 행동에 강하며, 액터-크리틱이 두 장점을 결합한 구조.

| 알고리즘 패밀리 | 핵심 메커니즘 | 장점 | 단점·병목 | 대표 알고리즘 |
| --- | --- | --- | --- | --- |
| 가치 기반 (Value-based) | Q 함수를 근사해 최선 행동 선택 | 샘플 효율 양호, 경험 재사용 | 이산 행동 공간에 한정 | Q-Learning, DQN |
| 정책 기반 (Policy-based) | 정책을 신경망으로 직접 모델링 | 연속 행동 공간 지원, 확률적 정책 | 분산이 크고 샘플 효율이 낮음 | REINFORCE, TRPO |
| 액터-크리틱 (Actor-Critic) | 정책(Actor)과 가치 평가(Critic) 결합 | 분산 감소, 안정적 수렴 | 두 신경망 동시 학습의 튜닝 난도 | A2C, **PPO** (Proximal Policy Optimization), SAC |
| 모델 기반 (Model-based) | 환경 모델을 학습해 가상 시뮬레이션 | 샘플 효율이 매우 높음 | 환경 모델 오류가 정책으로 전이 | MuZero, Dreamer |

- 대규모 상용 환경과 LLM 정렬에서는 안정성이 높은 PPO가 사실상의 표준으로 자리 잡음.

## Ⅴ. 강화학습(Reinforcement Learning)의 한계와 방안

- 핵심 요약 : 샘플 비효율, 보상 해킹, 학습 불안정성을 시뮬레이션, 보상 설계, 정규화로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 샘플 비효율 | 수많은 상호작용이 필요해 실제 장비에 적용하면 마모와 비용 발생 | 시뮬레이터 기반 **Sim-to-Real** 전이, 로그 데이터로 학습하는 **오프라인 강화학습** (Offline RL) | 실환경 시도 횟수 |
| **보상 해킹** (Reward Hacking) | 보상 함수의 허점을 악용해 목표 대신 점수만 획득 | 보상 형상화(Reward Shaping), 역강화학습(Inverse RL), 인간 피드백 기반 **RLHF** (Reinforcement Learning from Human Feedback) 결합 | 목표 달성률과 보상의 괴리 |
| 시드와 하이퍼파라미터에 따른 불안정성 | 같은 코드도 초기값에 따라 정책이 발산하거나 성능 편차가 큼 | PPO의 클리핑으로 정책 갱신 폭 제한, 다중 환경 병렬 실행, 여러 시드 평균 평가 | 시드별 성능 분산 |

## Ⅵ. 강화학습(Reinforcement Learning)에 대한 기술사적 제언

- 핵심 요약 : 추론 능력 강화, 시뮬레이션 학습, 안전 제약의 명시화를 적용 방향으로 제시.

1. 추론 능력 향상 : 사고 사슬(CoT, Chain of Thought)의 품질을 높이기 위해 LLM에 강화학습을 적용하는 방향을 검토함. DeepSeek-R1-Zero처럼 지도 미세조정 없이 대규모 강화학습만으로 추론 능력을 끌어올린 사례가 보고되어 있으며, **GRPO** (Group Relative Policy Optimization, 그룹 상대 정책 최적화)처럼 별도 가치 모델이 필요 없는 방식으로 학습 비용을 줄이는 방안도 함께 평가함.
2. 시뮬레이션 기반 로봇 학습 : 시뮬레이터에서 마찰, 조명, 질량을 무작위로 바꿔 학습하는 도메인 무작위화를 적용해 실물 배포 시 차이를 줄임.
3. 안전 제약의 명시적 설계 : 자율주행이나 제어 시스템에서는 보상 최대화와 별도로 안전 제약을 최적화 조건으로 넣고, 위반 시 행동을 차단하는 가드레일을 필수로 둠.

## Ⅶ. 결론

- 핵심 요약 : 강화학습은 보상이라는 신호로 행동 정책을 설계하는 방식이며, 보상 설계의 품질이 결과를 결정함.
- 시사점 : 시뮬레이션 비용과 보상 해킹을 함께 관리해야 실제 시스템으로 옮길 수 있음.
