## 연관 키워드

- AI 디지털교과서(AIDT, AI Digital Textbook), 적응형 학습(Adaptive Learning), 지능형 튜터링(ITS, Intelligent Tutoring System)
- 지식 추적(DKT, Deep Knowledge Tracing), 문항반응이론(IRT, Item Response Theory), 학습 분석(Learning Analytics)
- xAPI(Experience API), LRS(Learning Record Store), CSAP(Cloud Security Assurance Program)
- 비식별화(Pseudonymization), 사람 참여 루프(Human-in-the-Loop), 과정중심평가

## Ⅰ. AI 디지털교과서(AIDT)의 개요

- 핵심 요약 : 교육과정 기반 디지털 교재에 AI 적응형 학습을 결합하여 학생에게는 맞춤 학습을, 교사에게는 학습 분석을 제공하는 지능형 학습 지원 소프트웨어.
- 개념 : 초·중등 교육과정 기반의 디지털 학습자료에 **AI 적응형 학습** (Adaptive Learning, 학습자의 수준에 맞춰 문항과 경로를 조정하는 학습 방식)을 결합한 **AI 디지털교과서** (AIDT, AI Digital Textbook) 소프트웨어.
- 배경 및 필요성 : 교육 현장에서는 일제식 수업의 한계와 학생별 기초학력 격차가 함께 지적되어 왔다. 동시에 대규모 학습 데이터가 쌓이면서 미성년 학생의 개인정보 보호가 필수 조건이 되었다. 교육부는 과목별 단계 도입 계획을 2023년에 발표했으나, 도입 시기와 과목은 정책 조정이 반복되어 현행 일정은 교육부 최신 공지로 확인해야 한다.
- 주요 목적 : 학생 맞춤형 개별 교육을 실현하고, 기초학력 부진을 조기에 발견하며, 교사가 코칭과 소그룹 지도에 집중하도록 역할을 확장하는 것.
- 정책 동향 : 2025년 3월 일부 학년·과목에 교과서 지위로 도입되었으나, 2025년 8월 국회를 통과한 「초·중등교육법」 개정으로 법적 지위가 교과서에서 교육자료로 조정되어 학교별 선택 활용 체계로 전환됨.

## Ⅱ. AI 디지털교과서(AIDT)의 특징 및 장점

- 핵심 요약 : 학습 로그의 표준 수집과 지식 추적 분석이 맞춤형 문항과 교사 리포트로 이어져, 개별화 교육과 교사의 개입을 함께 지원하는 구조.

1. **적응형 코스웨어** (Adaptive Courseware, 진단 결과에 따라 난이도와 경로를 조정하는 학습 콘텐츠) : 문항반응이론과 지식 추적을 결합하여 취약 단원과 개념 결손을 진단 → 난이도를 자동 조정하여 학습 효율 향상.
2. **지능형 튜터링** (ITS, Intelligent Tutoring System, 대화형으로 힌트와 단계별 풀이를 제공하는 학습 시스템) : 오답 원인을 분석해 단계별 풀이를 유도 → 자기주도 학습 지원.
3. **실시간 학습 분석** (Learning Analytics, 학습 데이터를 수집·분석해 진도와 참여도, 취약 개념을 보여주는 기능) : 학급 단위 현황을 교사에게 제공 → 소그룹 맞춤 지도 가능.
4. 표준 학습 기록 : **xAPI** (Experience API, 학습 경험을 주체·행위·대상 형식으로 기록하는 표준) 로그를 **LRS** (Learning Record Store, 학습 기록 저장소)에 적재 → 기기와 플랫폼이 달라도 학습 이력 연계 가능.

## Ⅲ. AI 디지털교과서(AIDT)의 구조 (흐름)

- 핵심 요약 : 학교 단말에서 발생한 학습 행동이 표준 로그로 수집되고, 적응형 엔진의 분석을 거쳐 학생 콘텐츠와 교사 대시보드로 되돌아오는 4계층 구조.
- **학습 로그 수집 흐름** : 학생의 풀이 행동이 xAPI 형식으로 기록되어 LRS와 실시간 큐에 적재된다.
- **분석과 환류 흐름** : 적응형 엔진이 지식 추적과 문항반응 분석을 수행하여 학생 피드백과 교사 리포트를 만든다.

```text
[ 학생 풀이 행동 ]
      ↓ 기기에서 발생
[ xAPI 로그 수집 ]
  예: 3번 문항 45초 만에 오답
      ↓
[ LRS 학습기록 저장 ]
      ↓
[ 적응형 지능 엔진 ]
  지식 추적, 문항반응 분석
      ↓
[ 맞춤 문항과 교사 리포트 ]
```

```text
[ 학교 인프라 계층 ]
  1인 1기기, 교내 무선망, 에지 캐시
            ↑
[ 데이터 수집 계층 ]
  xAPI 수집기, LRS, 스트림 큐
            ↑
[ 적응형 지능 계층 ]
  지식 추적, 문항 분석, 지식 그래프
            ↑
[ 사용자 상호작용 계층 ]
  학생 학습 화면, 교사 대시보드
```

## Ⅳ. AI 디지털교과서(AIDT)의 비교

- 핵심 요약 : 서책형 교과서와 단순 전자책은 같은 내용을 같은 속도로 제공하는 반면, AIDT는 학습자별 진단과 실시간 추적을 전제로 한다.

| 비교 축 | 서책형 교과서 | 단순 전자책 | AI 디지털교과서 |
| --- | --- | --- | --- |
| 콘텐츠 형태 | 정적 텍스트와 인쇄 이미지 | 정적 디지털 화면 | 멀티미디어, 시뮬레이션, 대화형 튜터 |
| 학습자 맞춤도 | 동일 진도 | 맞춤 없음 | 실시간 진단 기반 개별 코스웨어 |
| 학습 추적성 | 추적 불가 | 열람 기록 수준 | 풀이 시간, 오답 패턴, 표준 로그 |
| 교사의 역할 | 단방향 지식 전달자 | 지식 전달자 | 학습 설계자와 멘토 |
| 평가 방식 | 지필 중심 총괄평가 | 지필 평가 보조 | 과정중심평가와 실시간 형성평가 |

- 선택 기준 : 교육 목표가 표준화된 진도 완료인지, 개별 진단과 피드백인지에 따라 교재 형태를 고르고, 데이터 활용 범위를 함께 정함.

## Ⅴ. AI 디지털교과서(AIDT)의 한계와 방안

- 핵심 요약 : 무선망 부하, 미성년 학습 데이터 유출, 튜터 의존에 따른 교사 통제권 약화를 에지 캐시, 비식별화와 공공 클라우드 격리, 교사 편집권 보장으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 동시 접속 시 네트워크 부하 | 학급 단위 동시 접속으로 무선망 트래픽이 몰려 수업이 끊김 | 교내 무선 인프라 증설, 로컬 에지 캐시에 멀티미디어 사전 적재, 오프라인 동기화 | 수업 중 접속 장애 건수 |
| 민감 학습 데이터 유출 | 성적, 풀이 행동, 시선 정보가 민간 기업으로 흘러갈 위험 | 교육청 전용 공공 클라우드(클라우드 보안인증 **CSAP**, Cloud Security Assurance Program)에 격리 보관, 비식별화 처리, 상업적 2차 활용 금지 | 비식별화 처리율, 접근 감사 건수 |
| AI 튜터 의존과 교사 통제권 약화 | 기계적 추천에 과도하게 의존하여 과의존과 수업 주도권 상실 | 교사가 추천 경로를 검토·재구성하는 **사람 참여 루프** (Human-in-the-Loop) 보장, 사용 시간 관리 기준 수립 | 교사 수정 개입률, 과사용 학생 비율 |

## Ⅵ. AI 디지털교과서(AIDT)에 대한 기술사적 제언

- 핵심 요약 : 교사의 수업 주도권과 데이터 보호를 전제로, 표준 학습 기록 체계 위에서 교육적 가치를 확장하는 방향.

1. 교육청과 학교는 AI 추천 경로를 교사가 수정하고 재배열할 수 있는 편집 기능을 필수 요건으로 명시하고, 교사 연수를 편집 역량 중심으로 설계하는 것이 바람직하다.
2. 교육부와 정보화 조직은 벤더별 데이터 사일로를 막기 위해 xAPI 표준과 LRS 연계 규격을 공통 기준으로 정하고, 학습 이력의 이동과 삭제 절차를 함께 마련한다.
3. 교육 연구 조직은 학습 성과를 정답률만으로 판단하지 않고, 협업과 정서적 상호작용 같은 교육 목표를 포함한 평가 틀을 개발하여 기기 중심 학습으로 치우치지 않게 한다.

## Ⅶ. 결론

- 핵심 요약 : AI 디지털교과서는 적응형 학습과 학습 분석으로 개별화 교육을 지원하는 지능형 교재 체계다.
- 시사점 : 효과는 알고리즘 성능보다 교사의 주도권, 데이터 보호, 표준 연계가 얼마나 확보되는지에 따라 결정된다.
