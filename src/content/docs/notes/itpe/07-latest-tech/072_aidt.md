## 한 줄 본질
- 모든 학생에게 동일한 진도와 난이도를 강요하던 종이 교과서의 구조적 한계와 사교육비 격차 심화 → 인공지능 기반 지능형 튜터링(ITS)과 지식 추적(Knowledge Tracing) 알고리즘을 적용하여 학생별 결손 지점을 실시간 진단하고 맞춤형 콘텐츠를 제공 → 한 명의 교사가 다수 학생의 개별 진도를 케어하는 맞춤형 교육 실현 / 학생 개인정보 유출 및 디지털 기기 과의존 위험

## 핵심 용어
- 지능형 튜터링 시스템(Intelligent Tutoring System, ITS): 학생의 문제 풀이 과정과 오답 패턴을 분석하여 교사의 개입 없이도 맞춤형 힌트, 보충 학습, 피드백을 적시에 제공하는 교육 소프트웨어 엔진
- xAPI(Experience API / Tin Can API): 학습자가 취한 모든 행동(동영상 시청 시간, 버튼 클릭, 문제 풀이 시간, 다시 풀기 등)을 "주어 + 동사 + 목적어" 형태의 정형 JSON 스트림으로 기록하는 국제 표준 데이터 규격
- 지식 추적(Knowledge Tracing, KT): 학생의 과거 학습 이력 데이터를 바탕으로 특정 수학 공식이나 개념을 현재 완전히 이해했는지를 시계열 딥러닝(DKT)을 통해 확률적으로 추정하는 핵심 알고리즘

## 핵심 통찰
- AIDT의 본질은 "교사를 대체하는 AI"가 아니라 "교사에게 학생 개개인의 결손 지도를 쥐어주는 보조 도구(Teacher Assistant)": 기술의 성패는 학생 UI보다 "교사용 대시보드"의 직관성과 통찰력에 달려 있음
- 단순 문항 반응 이론(IRT) 기반의 정적 진단을 넘어, 학생의 풀이 속도, 망설임, 시선 데이터를 반영하는 동적 지식 추적(Deep Knowledge Tracing)이 결합되어야 정밀한 개인화 가능
- 공교육 인프라이므로 보안 요건이 극도로 엄격함: CSAP 인증 클라우드 인프라, 틴캔 xAPI 데이터의 비식별화, 유해 콘텐츠 차단 가드레일이 없으면 학교 도입 불가

## 이웃 토픽과 구분
- AIDT vs 에듀테크 코스웨어: 일반 코스웨어는 민간 사교육 시장 중심의 개별 학습 도구 / AIDT는 국가 교육과정(성취기준)을 100% 준수하고 교사의 평가 권한과 직결되는 법적 지위의 공교육 정규 교과서
