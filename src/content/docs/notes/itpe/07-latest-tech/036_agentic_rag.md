## 30초 인출

- 본질: **에이전틱 RAG(Agentic Retrieval-Augmented Generation)** 는 질문·검색 결과에 따라 자료원·질의를 선택하거나 검색을 반복하는 RAG 구조
- 메커니즘: 질문 분석 → 검색 경로 선택 → 문서 평가 → 부족하면 질의 보정·재검색 → 근거 기반 응답

<details>
<summary>핵심 용어</summary>

- **에이전틱 RAG(Agentic Retrieval-Augmented Generation)** : 에이전트가 질문과 검색 결과에 따라 검색 경로·반복 여부를 조정하는 RAG 구조
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)** : 외부 자료를 검색해 언어 모델의 응답 문맥에 제공하는 방식
- **검색 라우터(Retrieval Router)** : 질의에 따라 자료원이나 검색 도구를 선택하는 구성요소
- **질의 재작성(Query Rewriting)** : 검색을 돕도록 질문 표현을 수정하거나 하위 질문으로 나누는 처리
- **검색 평가기(Retrieval Evaluator)** : 검색 자료의 질의 관련성·근거 적합성을 평가하는 구성요소
- **CRAG(Corrective Retrieval-Augmented Generation)** : 검색 결과를 평가해 보정 동작을 선택하는 연구 접근
</details>

### Ⅱ. 검색 평가·보정 흐름

```text
질문 분석·검색 필요 판단
          ↓
자료원·질의 선택
          ↓ 검색
문서 관련성·근거 평가
    ┌─────┴─────┐
 충분            부족
  ↓                ↓
근거 응답      질의 보정·재검색
                  └── 한도 내 반복
```

### Ⅲ. 주요 구성

| 구성 | 역할 |
|---|---|
| 라우터·재작성기 | 검색 여부·자료원·질의 표현 결정 |
| 검색기 | 관련 문서·근거 후보 회수 |
| 평가기 | 검색 자료의 관련성과 충분성 검토 |
| 생성기 | 선택된 근거를 이용해 응답 작성 |

| 목적 | 복합·모호한 질문에 필요한 검색 근거의 적합성 개선 |

### Ⅱ. 검색 평가·보정 흐름

```text
질문 분석·검색 필요 판단
          ↓
자료원·질의 선택
          ↓ 검색
문서 관련성·근거 평가
    ┌─────┴─────┐
```

### Ⅲ. 정적 RAG와의 차이

| 구분 | 정적 RAG | 에이전틱 RAG |
|---|---|---|
| 검색 경로 | 사전 구성된 검색·생성 절차 | 질문·결과에 따라 선택·재시도 가능 |
| 처리 복잡도 | 비교적 단순한 고정 흐름 | 분기·반복·평가 로직 추가 |
| 적용 판단 | 단일 검색으로 충분한 과업 | 자료원 선택·질의 보정이 필요한 과업 |

### Ⅳ. 품질·운영 통제

| 한계 | 대응 |
|---|---|
| 검색 평가가 부정확하면 부적합 문서로 응답 생성 | 질의별 관련성·근거성 평가와 표본 검토 |
| 반복 검색으로 비용·지연이 커질 수 있음 | 재시도·호출·시간 한도와 중단 조건 설정 |
| 여러 자료원에서 권한 밖 문서가 검색될 수 있음 | 사용자 권한을 검색 단계까지 전달하고 자료원별 접근 검사 |
| 보정 실패 시 응답을 계속 만들 수 있음 | 근거 부족 시 불확실성 표시·응답 보류·사람 인계 |

### Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 기존 단일 검색으로 충분한 과업에도 에이전트 반복 처리를 적용하면 복잡도만 증가할 수 있음 | 대표 질의에서 정적 RAG와 보정 검색의 근거 품질·성공률·비용을 비교하고, 반복 검색의 추가 가치가 확인된 과업에 한정 적용 |
