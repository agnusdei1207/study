## 답안 골격
```text
[생성형 AI] ◀━━ 머리: Ⅶ 내 의견 (RAG·Guardrail 기반 환각 억제 및 워터마크 기술 기반 저작권/신뢰성 보장)
 ┃
 ┣━ Ⅰ 개요 ───── 데이터 분류/판별 패러다임 한계 → 학습 데이터의 확률 분포를 모사하여 원본에 없는 신규 콘텐츠 창작
 ┣━ Ⅱ 특징 ───── 확률적 표본 추출(Sampling) · 멀티모달 확장성 · 창발적 능력(Emergent Ability)
 ┣━ Ⅲ 구조 ───── 파운데이션 모델(Transformer/Diffusion) + 파인튜닝(PEFT/RLHF) + 정렬(Alignment) + 서빙
 ┣━ Ⅳ 흐름 ───── ① 대규모 사전학습(Pre-training) → ② 지시미세조정(SFT) → ③ 인간 피드백 정렬(RLHF) → ④ 추론/생성
 ┣━ Ⅴ 비교 ───── 판별형 AI(P(Y|X)) vs 생성형 AI(P(X,Y) 또는 P(X)) vs 피지컬 AI(물리 환경 제어)
 ┗━ Ⅵ 실무 ───── 사실과 다른 환각(Hallucination) / 저작권 및 라이선스 위반 / 프롬프트 인젝션 보안 위협
```
- 필수 키워드: 트랜스포머(Transformer) · 확산 모델(Diffusion) · 창발성(Emergence) · 환각(Hallucination) · RLHF · 워터마크
- 배점 전략: 10점 = Ⅰ 개요 → Ⅴ 판별형 vs 생성형 비교표 → Ⅵ 환각 대응책 / 25점 = Ⅰ~Ⅶ 전개, Ⅲ 계층 구조와 Ⅳ 3단계 학습 파이프라인(사전학습-SFT-RLHF) 집중
- 기출: 136회 4교시 1번 `국내 AI 윤리기준과 생성형 AI` → Ⅰ·Ⅵ, 140회 1교시 9번 `Physical AI와 생성형 AI 비교` → Ⅴ

## 한 줄 본질
- 정해진 레이블을 맞추는 판별형 모델의 표현력 한계 → 대규모 데이터의 다차원 확률 분포를 학습해 조건부 확률 기반으로 새로운 텍스트·이미지·코드를 자율 합성 → 초개인화 생산성 혁신 / 사실 검증 불가능한 환각 및 지적재산권 침해 위험

## 핵심 그림
```text
[판별형 AI vs 생성형 AI 확률 모델]
판별형: 입력 데이터 X가 주어졌을 때 레이블 Y의 사후 확률 P(Y|X) 학습 (분류 경계선)
생성형: 데이터 X 자체의 분포 P(X) 또는 결합 확률 P(X,Y) 학습 (새로운 인스턴스 합성)

[생성형 AI 핵심 기술 스택]
+-------------------------------------------------------------------+
| 응용 서비스: 대화형 봇, 코드 자동 완성, 멀티모달 이미지/영상 생성 |
+-------------------------------------------------------------------+
| 정렬/가드레일: RLHF, DPO, NeMo Guardrails (안전성 및 윤리 준수)    |
+-------------------------------------------------------------------+
| 미세조정 계층: LoRA, QLoRA, 프롬프트 엔지니어링, 도메인 지식 주입 |
+-------------------------------------------------------------------+
| 기반 모델 (Foundation Models):                                    |
|   - 언어/코드: Transformer Decoder-only (GPT-4, Claude, LLaMA)    |
|   - 이미지/영상: Latent Diffusion Models (Stable Diffusion, Sora) |
+-------------------------------------------------------------------+
```

## 핵심 용어
- 창발적 능력(Emergent Ability): 모델 파라미터가 일정 임계점(약 100B 이상)을 넘어서면서 소형 모델에 없던 복합 추론 능력이 급격히 발현되는 현상
- 확산 모델(Diffusion Model): 원본 이미지에 점진적으로 가우시안 노이즈를 더했다가(Forward), 이를 역방향으로 노이즈를 제거(Reverse)하며 이미지를 생성하는 기법
- 모델 정렬(Alignment): 모델의 생성 결과물이 인간의 윤리, 법률, 안전 기준에 부합하도록 행동 양식을 교정하는 작업

## 핵심 통찰
- 생성형 AI의 답변은 "진실"을 알고 말하는 것이 아니라 다음 단어의 "통계적 등장 확률"이 가장 높은 토큰의 나열임 → 환각(Hallucination)은 구조적 특성이며 완전 제거가 불가능하므로 외부 검증기 결합 필수
- 파운데이션 모델 자체 개발은 빅테크의 자본 집약적 영역 → 일반 기업은 오픈소스 sLM에 LoRA 파인튜닝과 RAG를 결합하는 경량화 전략이 합리적
- AI 생성물에 대한 저작권 미인정 판례 확산에 따라 기업용 소스코드 생성 시 오염(Clean Room) 리스크 컴플라이언스 관리 필수

## 이웃 토픽과 구분
- 생성형 AI vs 피지컬 AI: 생성형 AI는 디지털 가상 공간의 비트(Bit)와 지식 콘텐츠를 생성 / 피지컬 AI는 로봇·자율주행차 등 물리적 환경의 원자(Atom)를 인식하고 운동을 제어

## 문제·원인·대책
- 적용 상황: 기업 대고객 상담에 생성형 LLM 적용 후 허위 사실 전달 및 기밀 유출
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 존재하지 않는 할인 정책 확약(환각) | 파라미터 가중치 내 최신 도메인 지식 부재 | RAG 파이프라인 결합 및 시스템 프롬프트 제약(Grounding) | 사실 기반 응답 강제 및 계약상 리스크 차단 |
| 프롬프트 탈옥(Jailbreak)으로 시스템 프롬프트 유출 | 적대적 프롬프트 인젝션 방어 기제 부재 | 입출력 가드레일(Llama Guard) 및 프롬프트 방화벽 구축 | 악의적 시스템 지침 우회 시도 원천 차단 |
| 상용 소프트웨어 라이선스 분쟁 | 오픈소스 GPL 코드가 필터링 없이 생성 코드에 유입 | 라이선스 탐지 스캐너 및 코드 귀속(Attribution) 검증 도구 연동 | 저작권 침해 방지 및 소송 리스크 완화 |

## 이렇게 출제된다
- 제136회 4교시 1번: "국내 인공지능(AI) 윤리기준과 생성형 AI에 대하여 다음을 설명하시오." → 요구 포인트: 생성형 AI의 신뢰성/윤리 이슈 + 3대 원칙 대응
- 제140회 1교시 9번: "Physical AI와 생성형 AI 비교" → 요구 포인트: Ⅴ 동작 영역(가상 vs 물리), 모델 아키텍처, 실시간 제어 요구사항 비교

## 내 의견
- [생성 파이프라인 전주기 워터마크 및 출처 증명 C2PA 표준 의무화] 딥페이크 및 저작권 침해 논란이 사회적 문제로 대두되어 투명성 확보가 시급함 → 나라면: 이미지·음성·텍스트 생성 즉시 눈에 보이지 않는 비가시적 메타데이터 워터마크(SynthID)를 삽입하고, C2PA(콘텐츠 출처 및 진위 확인) 표준 인증을 통해 생성물의 제작 이력을 추적 가능하도록 파이프라인 표준화
