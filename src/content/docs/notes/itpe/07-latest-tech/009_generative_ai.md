## 30초 인출

- 본질: **생성형 AI(Generative AI)** 는 대규모 비지도 데이터의 결합 확률 분포(P(X, Y) 또는 P(X))를 학습하여 프롬프트 조건에 부합하는 새로운 텍스트, 이미지, 음성, 비디오, 코드를 자율 생성하는 인공지능 기술
- 메커니즘: 파운데이션 모델 사전학습(Pre-training) 후 인스트럭션 튜닝과 인간 피드백 강화학습(RLHF)을 거쳐 사용자 프롬프트 조건부 확률 분포로부터 자기회귀 토큰 생성 또는 디노이징 확산 샘플링 수행
- 통찰: 통계적 확률 샘플링에 따른 본질적 환각(Hallucination)과 저작권 침해 리스크가 상존하므로 외부 지식 연계 RAG 파이프라인과 런타임 가드레일 및 워터마크 기술 결합 필수

<details><summary>핵심 용어</summary>

- **생성형 AI (Generative AI)** : 원천 데이터의 통계적 패턴과 확률 분포를 학습하여 새로운 고유 콘텐츠를 생성하는 인공지능.
- **파운데이션 모델 (Foundation Model)** : 방대한 비라벨 데이터로 사전학습되어 미세조정을 통해 다양한 다운스트림 과업에 적응 가능한 대규모 기반 모델.
- **자기회귀 모델 (Autoregressive Model)** : 이전 시점까지 생성된 토큰들을 입력 컨텍스트로 삼아 다음 토큰의 조건부 확률 분포 `P(w_t | w_<t)`를 예측하는 언어 모델.
- **확산 모델 (Diffusion Model)** : 원본 데이터에 가우시안 노이즈를 점진적으로 추가한 후 이를 역방향으로 복원(Denoising)하는 과정을 학습하는 생성 모델.
- **가드레일 (Guardrails)** : LLM 입출력 단에서 유해성, 개인정보(PII), 탈옥(Jailbreak), 환각을 실시간 감지하여 차단하는 안전 필터 프레임워크.

</details>

## 2~4교시 25점 답안

## Ⅰ. 생성형 AI의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 AI(Generative AI)** 는 방대한 멀티모달 데이터의 내재적 확률 분포를 학습하여 사용자의 프롬프트 요구에 따라 기존에 없던 독창적인 텍스트, 코드, 이미지, 오디오, 3D 객체를 생성하는 딥러닝 기술 |
| 목적 | 지식 근로자의 생산성 혁신, 복잡한 소프트웨어 개발 자동화, 창의적 콘텐츠 제작 지원 및 개인화된 서비스 제공 |

## Ⅱ. 생성형 AI의 패러다임 특징 및 판별형 AI 대비 속성

| 구분 | 판별형 AI (Discriminative AI) | 생성형 AI의 특징 (Generative AI) |
|---|---|---|
| **수학적 목적** | 조건부 확률 `P(Y \| X)` 모델링 | 결합 확률 `P(X, Y)` 또는 `P(X)` 모델링 |
| **출력 형태** | 사전에 정의된 클래스 라벨(0 또는 1), 수치 예측값 | 무한한 자유도를 가진 비정형 텍스트, 이미지, 비디오 |
| **학습 데이터** | 라벨이 완비된 대규모 정답 데이터셋 필수 | 인터넷 규모의 라벨 없는 원천 텍스트 자가학습(Self-supervised) |
| **적용 과업** | 질병 판정, 스팸 분류, 사기 탐지(FDS) | 보고서 요약, 소프트웨어 코딩, 가상 인간 합성, 기획서 작성 |

## Ⅲ. 생성형 AI 아키텍처 및 모달리티별 생성 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   [ 생성형 AI 핵심 파이프라인 아키텍처 ]                 │
└────────────────────────────────────────────────────────────────────────┘
                                    │
 ┌──────────────────────────────────┴──────────────────────────────────┐
 │                                                                     │
 ▼                                                                     ▼
[ 1. 텍스트/코드: 자기회귀 Transformer ]      [ 2. 이미지/비디오: 잠재 확산 모델(LDM) ]
 - Self-Attention 기반 문맥 토큰 임베딩       - 오토인코더(VAE)로 픽셀을 잠재 공간 압축
 - 다음 토큰 확률 분포 P(w_t | w_<t) 계산       - Forward: 이미지에 점진적 노이즈 주입
 - 온도(Temperature) 기반 Top-p 샘플링        - Reverse: U-Net 기반 노이즈 예측 및 복원
 └──────────────────────────────────┬──────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [ 모델 정렬 및 안전성 통제 (Alignment & Safety) ]                       │
│  - SFT (Supervised Fine-Tuning) ──> 지시 수행 능력 부여                │
│  - RLHF / DPO ──> 인간 선호도 정렬 및 유해 출력 억제                   │
│  - 입출력 런타임 가드레일 (NeMo Guardrails, Llama Guard)               │
└────────────────────────────────────────────────────────────────────────┘
```

| 생성 모델 계열 | 핵심 알고리즘 | 입력/출력 특성 및 적용 분야 |
|---|---|---|
| **Decoder-Only LLM** | Masked Self-Attention, RoPE | 입력 프롬프트에 연속하여 텍스트 및 코드를 생성 (GPT-4, Claude) |
| **Latent Diffusion** | Cross-Attention, U-Net, VAE | 텍스트 프롬프트를 조건으로 고해상도 이미지/비디오 합성 (Stable Diffusion) |
| **GAN (적대적 신경망)** | 생성자(G)와 판별자(D) Minimax 게임 | 실시간 초해상도 복원, 음성 변조, 얼굴 스왑 합성 |

## Ⅳ. 주요 생성 모델 아키텍처 비교

| 비교 항목 | Transformer (자기회귀) | Diffusion Model (확산 모델) | GAN (적대적 생성망) |
|---|---|---|---|
| **학습 원리** | 이전 토큰 기반 다음 토큰 예측 | 가우시안 노이즈의 점진적 역확산 | 생성자와 판별자의 경쟁적 대립 학습 |
| **주요 장점** | 긴 문맥 이해, 뛰어난 추론·코딩 역량 | 학습 안정성 우수, 압도적 이미지 품질 | 빠른 1-Step 추론 속도, 선명한 에지 |
| **주요 단점** | 연산 복잡도 $O(N^2)$, 환각 발생 | 다단계 디노이징으로 인한 느린 추론 | 모드 붕괴(Mode Collapse), 학습 불안정 |
| **대표 모델** | Llama 3, GPT-4o, DeepSeek | Stable Diffusion 3, Sora, Midjourney | StyleGAN, CycleGAN, BigGAN |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모델의 통계적 확률 생성 특성으로 인한 치명적 거짓 정보(환각) 생성 | 공인된 외부 지식 베이스 검색을 결합하는 RAG 파이프라인 연계 및 CoT(생각의 사슬) 기반 자기검증 적용 |
| 기업 내부 기밀 데이터 및 고객 개인정보가 외부 생성형 AI API로 유출 | 전용 온프레미스 sLLM 도입 및 프롬프트 인입 전 PII(개인식별정보) 자동 마스킹 프록시 게이트웨이 구축 |

## Ⅵ. 제언

무분별한 범용 모델 사용을 지양하고, 기업 내부 데이터 유출을 원천 방지하는 보안 프록시 게이트웨이와 도메인 특화 경량 SLM 중심의 하이브리드 아키텍처 구축.

```text
[ 사용자 프롬프트 ]
         │
         ▼
[ 엔터프라이즈 AI 보안 가드레일 게이트웨이 ]
   ├── Step 1: 주민번호, 소스코드, 기밀 키워드 정규식/NER 자동 마스킹
   ├── Step 2: 프롬프트 인젝션 및 탈옥 패턴 룰셋 스캔
   └── Step 3: 작업 난이도 분석 기반 스마트 라우팅
         │
    ┌────┴─────────────────────────────┐
    ▼ (보안/경량 태스크)                ▼ (고난도 추론 태스크)
[ 사내 온프레미스 sLLM ]           [ 외부 상용 LLM (기업용 전용망) ]
```

| 구분 | 초기 무통제 외부 API 호출 | 제언: 가드레일 결합 하이브리드 아키텍처 |
|---|---|---|
| **보안 통제** | 직원 개인 계정 사용으로 기밀 유출 빈발 | 전사 API 프록시를 통한 PII 마스킹 및 감사 로깅 |
| **비용 관리** | 토큰 사용량 폭증에 따른 비용 예측 불가 | 작업 난이도별 사내 sLLM과 상용 모델 간 동적 라우팅 |
| **정확도 보장** | 범용 지식에 의존하여 사내 업무 오답 발생 | 사내 ERP/Wiki 연동 사내 RAG 기반 사실 기반 답변 |
