## 지식 로드맵 내 현재 위치

지식 위치: 인공지능 → 콘텐츠 생성 모델 → **생성형 AI**

## 30초 인출

- 본질: **생성형 AI(Generative AI)** 는 학습 자료의 패턴을 바탕으로 새 콘텐츠를 만드는 인공지능
- 메커니즘: 학습 자료의 분포 모델링 → 입력 조건 반영 → 텍스트·이미지 등 생성 → 결과 검토
- 통찰: 한계: 그럴듯한 생성 결과에도 사실 오류와 권리 문제가 섞일 수 있음 → 방안: 사용 목적별 사실 확인과 권리 검토 후 결과 확정

<details>
<summary>핵심 용어</summary>

- **생성형 AI(Generative AI)** : 학습 자료의 패턴에 따라 텍스트·이미지·음성 등 새 콘텐츠를 만드는 인공지능
- **자기회귀 모델(Autoregressive Model)** : 이전 출력에 이어 다음 토큰을 순차 생성하는 모델 계열
- **확산 모델(Diffusion Model)** : 노이즈 제거 과정을 학습해 표본을 생성하는 모델 계열
- **환각(Hallucination)** : 근거가 부족하거나 사실과 다른 내용을 그럴듯하게 생성하는 현상
</details>

## 2~4교시 25점 답안

### Ⅰ. 생성형 AI의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 AI(Generative AI)** 는 학습 자료의 패턴을 바탕으로 새 콘텐츠를 만드는 인공지능 |
| 목적 | 입력 조건에 맞는 초안·콘텐츠 생성으로 지식 작업과 창작 지원 |

| 특성 | 의미 |
|---|---|
| 확률적 생성 | 학습한 분포를 바탕으로 다음 출력 후보를 선택 |
| 다중 양식 | 텍스트·이미지·음성 등 여러 콘텐츠 유형을 다룸 |
| 검증 필요 | 자연스러운 출력이 사실성을 보장하지 않음 |

### Ⅱ. 기본 생성 과정

```text
학습 자료의 패턴
        ↓ 모델에 반영
사용자 입력·조건
        ↓ 조건에 따른 생성
새 콘텐츠
        ↓ 사실성·권리 검토
사용 목적에 맞는 결과
```

### Ⅲ. 생성 방식의 예

| 모델 계열 | 생성 방식 | 대표 결과 |
|---|---|---|
| **자기회귀 모델(Autoregressive Model)** | 이전 출력에 이어 다음 토큰을 순차 생성 | 텍스트·코드 |
| **확산 모델(Diffusion Model)** | 노이즈에서 시작해 단계적으로 표본 복원 | 이미지·음성 등 |

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **환각(Hallucination)** ·오정보 | 근거 자료를 확인하고 중요한 결과는 담당자가 검증 |
| 편향·유해 출력 | 사용 목적에 맞는 평가와 검토 절차 마련 |
| 개인정보·저작권 침해 | 학습·입력 자료의 권리와 민감정보 처리 기준 확인 |

### Ⅴ. 제언

사람이 결과를 확인하기 쉬운 초안 업무부터 시험하고 검토 가능성을 확인한 뒤 적용 범위를 확대.
