## 30초 인출

- 본질: **가상물리시스템(CPS)** 은 물리 세계의 센서·액추에이터와 사이버 공간의 계산·통신 프로세스를 긴밀하게 결합하여 실시간으로 물리 공정을 감시하고 지능적으로 제어하는 복합 시스템
- 메커니즘: 센서 데이터 수집(Connection) → 의미 정보 변환(Conversion) → 사이버 가상 모델 분석(Cyber) → 의사결정 인지(Cognition) → 액추에이터 폐루프 제어(Configuration)
- 통찰: 통신 지연이나 사이버 침해가 물리적 폭주 및 인명 피해로 직결되므로 TSN(Time-Sensitive Networking) 기반 확정적 통신과 하드웨어 안전 인터록(Interlock) 구축 필수

<details><summary>핵심 용어</summary>

- **가상물리시스템(Cyber-Physical System, CPS)** : 연산, 네트워크, 물리적 프로세스가 유기적으로 융합된 안전 필수(Safety-Critical) 차세대 임베디드 시스템.
- **폐루프 제어(Closed-Loop Control)** : 센서 계측 결과를 사이버 연산에 반영하고, 산출된 제어 명령을 액추에이터로 피드백하는 양방향 자동 제어 구조.
- **5C 아키텍처** : 제조 CPS 구현을 위한 5단계(Connection, Conversion, Cyber, Cognition, Configuration) 계층 구조.
- **TSN(Time-Sensitive Networking)** : 표준 이더넷 상에서 마이크로초(μs) 단위의 확정적(Deterministic) 저지연 전송을 보장하는 IEEE 802.1 표준군.
- **안전 인터록(Safety Interlock)** : 제어 소프트웨어 오류나 침해 발생 시에도 물리적 한계를 벗어나지 않도록 하드웨어 단에서 강제 차단하는 안전 메커니즘.

</details>

## 2~4교시 25점 답안

## Ⅰ. 가상물리시스템(CPS)의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **가상물리시스템(CPS)** 은 물리적 프로세스를 센서·액추에이터로 관측·조작하고, 이를 통신 네트워크와 임베디드 컴퓨팅 파이프라인에 연결하여 실시간 양방향 피드백 제어를 수행하는 지능형 융합 시스템 |
| 목적 | 물리 세계의 상태를 실시간 가상화하여 최적의 제어 명령을 도출함으로써 생산성 극대화, 자율 안전 제어 및 에너지 효율 최적화 달성 |

## Ⅱ. 가상물리시스템(CPS)의 핵심 특징

| 구분 | 주요 특징 | 기술적 설명 및 메커니즘 |
|---|---|---|
| **제어 루프** | 양방향 폐루프(Closed-Loop) 피드백 | 단순 상태 모니터링을 넘어 가상 연산 결과가 즉시 물리 액추에이터의 실시간 구동으로 전이 |
| **시간 제약** | 실시간 확정성(Determinism) | 정해진 데드라인(Deadline) 이내에 연산과 제어 패킷 전송을 보장하는 하드 리얼타임(Hard Real-Time) 특성 |
| **신뢰 요구** | 안전 필수성(Safety-Critical) | 시스템 오작동 시 대규모 물리적 파괴나 인명 사고로 직결되므로 극도의 기능 안전(ISO 26262, IEC 61508) 요구 |
| **시스템 통합** | 초이종성(Hyper-Heterogeneity) | 아날로그 센서, PLC 제어기, 산업용 이더넷, 클라우드 AI 등 이종 시스템 간 시맨틱 상호운용성 보장 |

## Ⅲ. CPS 체계 및 제조 5C 아키텍처

```text
┌────────────────────────────────────────────────────────────────────────┐
│             [ CPS 양방향 폐루프 및 제조 5C 계층형 아키텍처 ]             │
└────────────────────────────────────────────────────────────────────────┘
      │
 [ Level 5: 구성 (Configuration) ] ── 실시간 자율 재설정, 피드백 제어 및 복원
      ▲                                       │ (제어 명령 하달)
      │                                       ▼
 [ Level 4: 인지 (Cognition) ] ────── 상태 모니터링, 다기준 의사결정(MCDM)
      ▲
      │
 [ Level 3: 사이버 (Cyber) ] ──────── 디지털 트윈 모델링, 시뮬레이션 및 잔존수명(RUL) 예측
      ▲
      │
 [ Level 2: 변환 (Conversion) ] ───── 스마트 센서 데이터 시계열 분석, 특징 추출(Feature)
      ▲
      │
 [ Level 1: 연결 (Connection) ] ───── 설비 플러그앤플레이, 산업용 통신(OPC UA, MQTT)
      │
      ▼
┌────────────────────────────────────────────────────────────────────────┐
│      [ 물리 세계 (Physical Space) ]: 기계 설비, 로봇 암, 센서 및 액추에이터     │
└────────────────────────────────────────────────────────────────────────┘
```

| 5C 단계 | 핵심 역할 및 기능 | 주요 적용 기술 |
|---|---|---|
| **1C. Connection** | 물리 설비와 센서로부터 끊김 없는 데이터 수집 | Fieldbus, Industrial Ethernet, OPC UA |
| **2C. Conversion** | 원시 신호를 유의미한 상태 정보 및 지표로 변환 | 알고리즘 기반 신호 필터링, FFT, 상태 추정 |
| **3C. Cyber** | 대규모 데이터 집약 및 가상 공간 디지털 트윈화 | 머신러닝 모델, RUL 예측 시뮬레이션, 복기 |
| **4C. Cognition** | 상태 분석 결과를 바탕으로 전문가 우선순위 결정 | 전문가 시스템, 다차원 가시화 대시보드 |
| **5C. Configuration** | 가상 모델의 결정을 물리 공정에 폐루프 피드백 | Supervisory Control, PLC 파라미터 자동 재설정 |

## Ⅳ. CPS, IoT, 디지털 트윈(Digital Twin) 비교

| 비교 항목 | 가상물리시스템 (CPS) | 사물인터넷 (IoT) | 디지털 트윈 (Digital Twin) |
|---|---|---|---|
| **핵심 목적** | 물리 공정의 실시간 폐루프 자율 제어 | 사물 간 인터넷 연결 및 데이터 수집 | 물리 자산의 동기화된 가상 시뮬레이션 |
| **상호작용 방향** | 양방향 (물리 ↔ 사이버 실시간 제어) | 주로 단방향 (물리 → 사이버 센싱) | 양방향 (센싱 데이터 ↔ 시뮬레이션 분석) |
| **시간 확정성** | 하드/소프트 실시간 (ms ~ μs 단위) | 비실시간 ~ 소프트 실시간 (초~분) | 주기적 동기화 또는 준실시간 |
| **제어 개입도** | 액추에이터를 통한 물리 환경 직접 조작 | 상태 모니터링 및 사용자 원격 트리거 | 시뮬레이션 검증 후 운영자 확인 기반 반영 |
| **핵심 기술** | 임베디드 OS, 제어 이론, TSN, 안전 인터록 | 센서 네트워크, MQTT, 클라우드 플랫폼 | 3D CAD/CAE, 물리 역학 모델, 실시간 스트리밍 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 무선 통신 지연(Latency) 및 패킷 손실로 인한 제어 타이밍 불일치와 액추에이터 채터링·폭주 위험 | IEEE 802.1 TSN 및 5G URLLC 기반의 확정적 저지연 통신망 구축, 에지 제어기(Edge PLC) 기반 국소 폐루프 우선 분기 |
| 악성 제어 패킷 인젝션 및 OT 프로토콜 위변조 시 물리적 설비 파괴 및 대형 인명 사고 발생 | IEC 62443 산업 사이버 보안 체계 수립, 네트워크 마이크로 세그멘테이션 및 물리적 하드웨어 안전 인터록(Interlock) 강제 배치 |
| 대규모 이종 센서·액추에이터 간 데이터 모델 불일치로 인한 시스템 통합 병목 및 시맨틱 단절 | OPC UA 표준 정보 모델(Information Model) 도입 및 산업용 온톨로지 기반 시맨틱 미들웨어 구축 |

## Ⅵ. 제언

클라우드-에지 계층형 제어 분할 아키텍처를 도입하여, 실시간성이 요구되는 제어 루프는 에지 TSN에서 즉시 처리하고 글로벌 최적화는 클라우드에서 비동기 연계.

```text
[ 클라우드 계층 (Global Optimization) ] ── (AI 대규모 학습 및 주간 최적 운전 스케줄링)
                  │
                  ▼ (설정 파라미터 전달: 비실시간)
[ 에지 계층 (Edge Distributed CPS) ] ───── (TSN 기반 마이크로초 단위 확정적 통신)
   ├── 국소 자율 폐루프 제어 (1ms 이내 고속 피드백)
   └── 물리 안전 인터록 감시 (이상 징후 시 하드웨어 E-Stop 발동)
                  │
                  ▼ (실시간 액추에이터 구동)
[ 물리 설비 현장 (Sensors & Actuators) ]
```

| 구분 | 중앙 클라우드 단독 제어 | 제언: 클라우드-에지 계층형 CPS |
|---|---|---|
| **제어 지연** | 수십~수백 ms (네트워크 변동성 노출) | 1ms 미만의 확정적(Deterministic) 보장 |
| **망 단절 대응** | 통신 장애 시 전체 공정 셧다운 | 에지 독립 운전을 통한 무중단 자율 복원 |
| **안전 보장** | 소프트웨어 기반 타임아웃 차단 | 하드웨어 인터록 연동 페일세이프(Fail-Safe) |
