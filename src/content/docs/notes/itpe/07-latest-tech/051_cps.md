<summary>핵심 용어</summary>

- **가상물리시스템(Cyber-Physical System, CPS)** : 계산·통신 시스템과 물리 요소가 상호작용하는 시스템
- **폐루프 제어(Closed-Loop Control)** : 측정한 상태와 목표의 차이에 따라 제어하고 결과를 다시 측정하는 구조
- **5C 아키텍처(5C Architecture)** : 제조 CPS의 연결·변환·사이버·인지·구성 기능을 다섯 단계로 설명하는 제안 구조
- **디지털 트윈(Digital Twin)** : 실제 대상 자료와 연결해 상태·거동을 분석하는 가상 표현

## 2~4교시 25점 답안

### Ⅰ. 가상물리시스템의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **가상물리시스템(Cyber-Physical System, CPS)** 은 계산·통신 요소와 물리 공정이 결합해 서로 영향을 주는 시스템 |
| 목적 | 물리 상태를 데이터로 파악하고 분석 결과를 운영·제어에 활용하는 기반 |

### Ⅱ. 구성 요소와 피드백

```text
물리 공정·설비
   │ 센서 관측
   ▼
계산·통신 ── 분석·판단
   │ 제어 명령
   ▼
액추에이터·운영 조치
   │ 상태 변화 재측정
   └───────────────┐
                   └── 물리 공정으로 환류
```

| 구성 | 역할 |
|---|---|
| 물리 공정 | 실제 설비·환경·대상 |
| 센서·통신 | 상태 관측과 데이터 전달 |
| 계산·모델 | 분석·예측·의사결정 지원 |
| 액추에이터 | 승인된 제어를 물리 동작으로 반영 |

### Ⅲ. 제조 CPS의 5C 관점

```text
Connection     설비·자료 연결
      │
Conversion     자료를 상태 정보로 변환
      │
Cyber          사이버 모델·분석과 연계
      │
Cognition      상태 해석·의사결정 지원
      │
Configuration  승인된 설정·제어 반영
```

5C는 제조 CPS의 설계 관점을 설명하는 제안 아키텍처이며 모든 CPS에 강제되는 표준 절차는 아님.

### Ⅳ. 안전한 운영과 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 지연·센서 오류·통신 단절이 제어 오작동으로 이어질 수 있음 | 허용 지연·오류 상태·안전 정지 조건을 정의하고 시뮬레이션과 현장 시험으로 검증 |
| 가상 모델의 판단을 확인 없이 실제 설비에 적용할 위험 | 운영자 승인과 안전 인터록을 둔 제한 운전부터 시작하고 검증 결과에 따라 자동화 범위를 조정 |
