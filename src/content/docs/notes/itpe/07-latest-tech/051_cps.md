## Ⅰ. CPS(Cyber Physical System)의 개요

- 개념 : 센서, 액추에이터를 통해 **물리적 세계** (Physical Space)의 다양한 상태와 프로세스를 실시간 계측·제어하고, **사이버 공간** (Cyber Space)의 연산, 통신, 인공지능 엔진과 유기적으로 긴밀히 결합되어 실시간 피드백 루프(Closed-Loop)를 형성하는 차세대 스마트 융합 제어 시스템.
- 배경 및 필요성 : 전통적 **임베디드 시스템** 의 폐쇄성과 단일 장비 제어 한계를 극복하고, 스마트 공장, 자율주행, 스마트 그리드, 스마트 시티 등 물리계와 디지털계가 초연결되어 자율적 판단과 초정밀 실시간 제어를 수행할 필요성이 증대됨.
- 핵심 목적 : 마이크로초 단위의 **실시간 결정론적 제어** (Real-time Determinism), 자율적 상황 판단 및 **자가 치유** (Self-Healing), 물리 시스템의 안전성(Safety)과 생산 효율성 극대화.

## Ⅱ. CPS(Cyber Physical System)의 핵심 아키텍처 및 동작 메커니즘

CPS는 3C 핵심 기술(Computation, Communication, Control)과 Lee 박사의 **5C 계층형 아키텍처** 를 기반으로 동작함.

```text
[ CPS(Cyber Physical System) 5C 계층 아키텍처 ]

+-----------------------------------------------------------------+
| 5. 자율 설정 계층 (Configuration Level)                         |
|  - 사이버 공간의 피드백을 물리 액추에이터로 자율 제어 및 자가 치유 |
+--------------------------------▲--------------------------------+
                                 │ 자율 제어 명령 하달
+--------------------------------┴--------------------------------+
| 4. 인지 및 의사결정 계층 (Cognition Level)                      |
|  - 인공지능 기반 이상 진단, 상태 예측, 최적화 의사결정 지원     |
+--------------------------------▲--------------------------------+
                                 │ 디지털 트윈 시뮬레이션
+--------------------------------┴--------------------------------+
| 3. 사이버 가상화 계층 (Cyber Level)                             |
|  - 물리 자산의 디지털 트윈 복제, 시계열 빅데이터 분석 및 집계    |
+--------------------------------▲--------------------------------+
                                 │ 의미론적 데이터 변환
+--------------------------------┴--------------------------------+
| 2. 데이터 변환 계층 (Conversion Level)                          |
|  - 센서 스트림 데이터 정제, 특징 추출, 엣지 컴퓨팅 분석         |
+--------------------------------▲--------------------------------+
                                 │ 초저지연 패킷 전송 (TSN / 5G)
+--------------------------------┴--------------------------------+
| 1. 물리적 연결 계층 (Connection Level)                          |
|  - 스마트 센서, 액추에이터, IoT 디바이스, 무선 센서 네트워크    |
+-----------------------------------------------------------------+
```

- **3C 핵심 역량** : 초고속 임베디드 연산(Computation), 무손실 초저지연 통신(Communication), 물리적 현실의 능동적 피드백 제어(Control)의 삼위일체 결합.
- **시간 민감형 네트워킹(TSN)** : 표준 이더넷 상에서 패킷 전송 지연 한계(Jitter)를 보장하여 제어 명령의 실시간 결정론(Determinism) 담보.
- **사이버-물리 폐루프(Closed-Loop)** : 물리계 센싱 ──► 사이버계 연산 및 AI 분석 ──► 물리계 액추에이션의 순환 고리가 인간의 개입 없이 밀리초 단위로 자율 완결.
- **기능 안전(Functional Safety)** : 통신 장애나 노드 고장 발생 시 시스템이 즉각 안전 상태(Fail-Safe)로 전이하도록 하드웨어 및 소프트웨어 이중화.

## Ⅲ. CPS(Cyber Physical System)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 전통적 임베디드 시스템 | 사물인터넷 (IoT) | 사이버-물리 시스템 (CPS) |
| --- | --- | --- | --- |
| **핵심 초점** | 독립형 장치 내부의 고정 제어 | 사물 간의 초연결 및 원격 데이터 모니터링 | 연산, 통신, 물리 액추에이션의 실시간 결합 |
| **통신 환경** | CAN, RS-485 등 폐쇄형 전용 버스 | 인터넷 프로토콜 (MQTT, CoAP, HTTP) | TSN, 산업용 이더넷, 5G 특화망, OPC-UA |
| **상호작용 구조** | 단방향 또는 국소 폐루프 제어 | 클라우드로의 단방향 데이터 수집 위주 | 사이버와 물리계 간의 정밀 양방향 Closed-Loop |
| **실시간성 요구** | 높음 (단일 장치 마이크로초 제어) | 낮음 (수초 단위 지연 허용) | 극도로 엄격함 (종단간 실시간 결정론 보장) |
| **주요 적용 사례** | 자동차 ECU, 가전제품 마이컴 | 스마트 홈 조명, 원격 검침(AMI) | 스마트 팩토리, 자율주행, 스마트 그리드 |

- IoT가 물리 세계의 데이터를 클라우드로 '수집·모니터링'하는 데 중점을 둔다면, CPS는 분석된 결과를 바탕으로 물리 세계를 '실시간 능동 제어'하는 데 방점이 찍힘.

## Ⅳ. CPS(Cyber Physical System)의 주요 한계점 및 해결 방안

- 네트워크 지연 및 패킷 손실로 인한 실시간 결정론(Determinism) 붕괴 :
  - 한계점 : 비결정론적 IP 네트워크 환경에서 패킷 지연이 발생할 경우 로봇 충돌이나 전력망 주파수 붕괴 등 치명적 사고 발생.
  - 해결 방안 : **IEEE 802.1 TSN** (시간 민감형 네트워크) 표준 전면 도입 및 통신 지연 상한선 수학적 검증.
- 사이버 침해가 물리적 설비 파괴나 인명 상해로 직결되는 사이버-물리 보안 위협 :
  - 한계점 : 스턱스넷(Stuxnet)처럼 악성코드가 원자로 원심분리기나 발전기 모터를 물리적으로 파괴할 위험.
  - 해결 방안 : **IEC 62443** 산업 제어 시스템 보안 규격 준수, 단방향 보안 게이트웨이 및 PLC 펌웨어 전자서명 강제.
- 이기종 센서 및 레거시 산업 설비와의 데이터 표준화 결여 :
  - 한계점 : 수십 종의 독점 필드버스 프로토콜이 혼재되어 통합 데이터 분석 불가능.
  - 해결 방안 : **OPC-UA** (Open Platform Communications Unified Architecture) 기반 데이터 모델링 표준화.

## Ⅴ. CPS(Cyber Physical System) 적용 및 발전을 위한 기술사적 제언

- 디지털 트윈과의 유기적 결합을 통한 가상 시운전(Virtual Commissioning) 필수화 : 실제 물리 설비에 제어 명령을 내리기 전 디지털 트윈 공간에서 안전성을 1차 검증하는 샌드박스 루프 구축.
- 엣지-클라우드 협업 컴퓨팅 계층화 설계 : 초저지연 액추에이터 제어는 엣지 RTOS에서 마이크로초 단위로 처리하고, 대규모 최적화 및 학습은 클라우드에서 비동기 처리.
- 기능 안전 국제 규격(ISO 26262 ASIL-D, IEC 61508 SIL-3) 준수 설계 : 하드웨어 장애 발생 시에도 물리적 인터락(Interlock)에 의해 시스템이 안전하게 셧다운되도록 다중화 아키텍처 수립.
