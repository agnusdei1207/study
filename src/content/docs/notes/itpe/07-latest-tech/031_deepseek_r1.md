## 지식 로드맵 내 현재 위치

지식 위치: 대규모 언어모델 → 추론 능력 강화 → 강화학습 기반 모델 → **DeepSeek-R1**

## 30초 인출

- 본질: **DeepSeek-R1** 은 강화학습과 지도학습 단계를 결합해 추론 응답을 개선한 언어 모델 계열
- 메커니즘: 기본 모델의 강화학습 실험(R1-Zero) → 콜드스타트 자료·강화학습·선별 지도학습을 결합한 R1

<details>
<summary>핵심 용어</summary>

- **DeepSeek-R1** : 추론 능력 향상을 위해 강화학습과 선별 지도학습을 조합한 언어 모델 계열
- **DeepSeek-R1-Zero** : 지도 미세조정 없이 강화학습부터 적용해 추론 행동을 학습한 모델 실험
- **GRPO(Group Relative Policy Optimization)** : 같은 질문에 대한 응답 집단의 상대적 보상을 이용해 정책을 최적화하는 방법
- **규칙 기반 보상(Rule-based Reward)** : 수학 정답·코드 실행 등 판정 가능한 기준으로 응답을 평가하는 보상
- **지식 증류(Knowledge Distillation)** : 교사 모델의 출력·정보를 이용해 학생 모델을 학습하는 방법
</details>
