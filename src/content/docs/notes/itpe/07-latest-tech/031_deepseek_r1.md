## 연관 키워드

- DeepSeek-R1, 추론 모델(Reasoning Model), 사고 사슬(CoT, Chain of Thought)
- GRPO(Group Relative Policy Optimization), 강화학습(RL, Reinforcement Learning), 규칙 기반 보상
- 콜드스타트(Cold-start), 지식 증류(Distillation), 추론 시간 연산(Inference-time Compute)
- 언어 혼용(Language Mixing), DPO(Direct Preference Optimization), 오픈 가중치(Open-weights)

## Ⅰ. DeepSeek-R1 (강화학습 기반 추론)의 개요

- 핵심 요약 : 정답 검증이 가능한 과제에 강화학습을 적용해 추론 능력을 끌어낸 오픈 가중치 추론 모델.
- 개념 : 소량의 **콜드스타트** (Cold-start) 데이터와 대규모 **강화학습** (RL, Reinforcement Learning)을 결합해, 모델이 스스로 단계별로 사고하고 오류를 고치는 긴 **사고 사슬** (Long CoT)을 형성하도록 한 추론 특화 모델.
- 배경 및 필요성 : 폐쇄형 상용 추론 모델의 높은 비용과 비공개성이 문제로 지적되던 가운데, 수학·코딩처럼 정답을 자동 검증할 수 있는 영역에서는 강화학습만으로도 추론 능력이 향상될 수 있음을 보여주었다.
- 공개 경과 : 2025년 1월 기술 보고서(arXiv)가 공개되었고, 2025년 9월 17일 학술지 Nature에 "DeepSeek-R1 incentivizes reasoning in LLMs through reinforcement learning"으로 게재되었다(Nature 발표 기준).
- 주요 목적 : 추론 시간 연산 확대를 통한 복합 문제 해결력 향상, 증류를 통한 소형 모델로의 추론 능력 이전, 공개 가중치 생태계 확산.

## Ⅱ. DeepSeek-R1 (강화학습 기반 추론)의 특징 및 장점

- 핵심 요약 : 정답 기반 보상과 비평가 없는 학습 알고리즘이 저비용 추론 능력 확보로 이어지는 구조.

1. 규칙 기반 보상 : 수학 정답 검증기와 사고 형식 준수 여부를 보상으로 사용 → 주관적 보상 모델 없이 객관적 학습 신호 확보.
2. GRPO 알고리즘 : 같은 질문에 대한 여러 응답의 상대 보상을 기준으로 정책을 갱신 → 별도 비평가 모델이 필요 없어 메모리 부담 감소.
3. 사고 과정 창발 : 모델이 생각을 길게 전개하고 스스로 검토하는 행동을 학습 → 어려운 문제에서 정답률 향상.
4. 증류 활용 : R1의 추론 데이터로 소형 모델을 미세 조정 → 단일 GPU 환경에서도 추론 성능을 활용 가능.

```text
[ GRPO 한 번의 학습 루프 ]

질문 1개
      ↓ 응답 여러 개 샘플링
규칙 기반 보상 (정답·형식 검증)
      ↓ 그룹 내 상대 점수 정규화
정책 갱신 (비평가 모델 없음)
```

## Ⅲ. DeepSeek-R1 (강화학습 기반 추론)의 구조 (흐름)

- 핵심 요약 : 순수 강화학습 실험(R1-Zero)과 콜드스타트 파이프라인을 거쳐 최종 R1을 만들고, 이를 소형 모델로 증류하는 구조.

```text
[ 기본 베이스 모델 (DeepSeek-V3 Base) ]
          ↓
[ 순수 강화학습 : R1-Zero ]
  규칙 기반 보상 / 자가 반성 창발
          ↓ 언어 혼용 등 문제 노출
[ 콜드스타트 + 대규모 GRPO ]
  소량 정제 CoT 사전 학습 후 강화학습
          ↓ 추론 데이터 합성·거부 샘플링
[ 소형 모델 지식 증류 ]
  Qwen·Llama 기반 모델에 R1 데이터로 SFT
```

- **GRPO** (Group Relative Policy Optimization) : 동일 질문의 응답 묶음 내 상대 보상을 정규화해 정책을 갱신하는 알고리즘으로, PPO(Proximal Policy Optimization)와 달리 비평가 모델을 두지 않는다.
- **규칙 기반 보상** (Rule-based Reward) : 정답 검증기와 `<think>` 태그 형식 준수 여부로 보상을 부여하는 방식.

## Ⅳ. DeepSeek-R1 (강화학습 기반 추론)의 비교

- 핵심 요약 : 학습 알고리즘과 공개 범위에서 상용 추론 모델과 차별되며, 비용과 투명성에서 강점을 가진다.

| 비교 항목 | DeepSeek-V3 (일반 LLM) | OpenAI o1 (상용 추론) | DeepSeek-R1 (오픈 추론) |
| --- | --- | --- | --- |
| 핵심 학습 | 사전 학습, SFT(Supervised Fine-Tuning), RLHF(Reinforcement Learning from Human Feedback) | 추론 시간 연산 중심 (비공개 상세) | 대규모 강화학습(GRPO), 증류 |
| 강화학습 알고리즘 | PPO (비평가 모델 필요) | 비공개 | GRPO (비평가 모델 불필요) |
| 가중치·사고 공개 | 오픈 가중치, 사고 과정 없음 | 폐쇄형, 사고 토큰 비공개 | 가중치 공개, 사고 과정 노출 |
| 적합 작업 | 상식 질의, 창작, 요약 | 복잡한 코딩, 고난도 수학 | 수학, 알고리즘, 논리 검증 |

- 이 모델은 대규모 인적 라벨링 없이도 추론 능력이 학습될 수 있음을 보여 주어, 사전 학습 규모 경쟁에서 추론 연산 규모 경쟁으로 관심을 옮기는 계기가 되었다.

## Ⅴ. DeepSeek-R1 (강화학습 기반 추론)의 한계와 방안

- 핵심 요약 : 언어 혼용, 긴 응답 지연, 정답 없는 과제 적용 한계를 언어 보상, 모델 분기, 선호 정렬로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 언어 혼용과 가독성 저하 | 보상이 언어 일관성을 직접 다루지 않아 다국어 혼합 발생 | 콜드스타트 데이터 주입, 언어 일관성 보상 추가 | 언어 일치율 |
| 긴 추론에 따른 지연 | 단순 질문에도 긴 사고 과정을 생성 → 응답 시간 증가 | 질의 복잡도에 따라 일반 모델과 추론 모델로 분기, 증류 모델 양자화 | 평균 응답 시간, 토큰 수 |
| 정답 없는 과제의 취약성 | 글쓰기·윤리 판단은 규칙형 보상을 설계하기 어려움 | 인간 선호 기반 **DPO** (Direct Preference Optimization) 또는 RLHF 정렬을 결합 | 사람 평가 점수 |
| 프롬프트 민감성 | 지시 문구 변화에 따라 결과 편차 발생 | 표준 프롬프트 템플릿 관리, 평가 세트 회귀 테스트 | 프롬프트 변경 시 정답률 편차 |

## Ⅵ. DeepSeek-R1 (강화학습 기반 추론)의 기술사적 제언

- 핵심 요약 : 정답 검증이 가능한 업무부터 추론 모델을 도입하고, 검증 불가능한 판단은 규칙 엔진과 결합하는 방향이 적절하다.

1. 검증 가능한 업무 우선 : 코드 테스트, 계산, 규정 적합성처럼 결과를 자동 검증할 수 있는 업무에서 강화학습 기반 추론 모델을 먼저 적용한다.
2. 내부 배포 검토 : 공개 가중치를 사내 환경에서 운용할 경우 보안 격리와 라이선스 검토를 선행하고, 소형 증류 모델로 단계적 검증을 진행한다.
3. 결정론적 검증기 결합 : 세무 계산이나 약관 검토에서는 모델의 추론 결과를 규칙 기반 검증기로 한 번 더 확인하는 구조를 설계한다.

## Ⅶ. 결론

- 핵심 요약 : DeepSeek-R1은 정답 기반 강화학습으로 추론 능력을 키울 수 있음을 공개 검증한 모델이다.
- 시사점 : 추론 역량은 데이터 규모만큼 보상 설계와 검증 체계에 좌우되므로, 조직은 검증 가능한 과제를 식별하는 역량을 먼저 갖춰야 한다.
