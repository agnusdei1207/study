## 답안 골격
```text
[DeepSeek-R1] ◀━━ 머리: Ⅶ 내 의견 (GRPO 기반 순수 RL 추론 파이프라인과 고성능 sLM 지식 증류(Distillation) 확산)
 ┃
 ┣━ Ⅰ 개요 ───── 비싼 인간 라벨링(SFT) 한계 → 대규모 강화학습(RL)만으로 모델 스스로 긴 추론(CoT) 능력을 창발
 ┣━ Ⅱ 특징 ───── 비평가(Critic) 없는 GRPO 알고리즘 · 규칙 기반 검증 보상 · 자가 반조(Self-Reflection) 창발 · 증류 효율성
 ┣━ Ⅲ 구조 ───── 베이스 모델(V3) + 순수 RL(R1-Zero) + 다단계 SFT/거절 샘플링 + 지식 증류(Distillation)
 ┣━ Ⅳ 흐름 ───── ① 콜드스타트 데이터 구축 → ② 대규모 GRPO 강화학습 → ③ 거절 샘플링 데이터 정제 → ④ sLM 증류
 ┣━ Ⅴ 비교 ───── 전통 RLHF(PPO 기반) vs DeepSeek GRPO vs 지도 미세조정(SFT)
 ┗━ Ⅵ 실무 ───── 언어 혼용(Language Mixing) 현상 / 가독성 저하 / 검증 불가 영역(작문 등)의 보상 설계 난해
```
- 필수 키워드: 순수 강화학습(Pure RL) · GRPO · 창발적 추론(Aha Moment) · 자가 반조 · 지식 증류(Distillation) · 규칙 기반 보상
- 기출: 미출제. 예상: "대규모 언어모델의 추론 역량 혁신을 이끈 DeepSeek-R1의 순수 강화학습 메커니즘, GRPO 알고리즘, 그리고 기존 RLHF 대비 차별점을 설명하시오."

## 한 줄 본질
- 수작업 인간 정답 데이터(SFT) 구축의 비용과 지능 상한선 한계 → 수학/코드의 정답 여부만을 피드백하는 순수 강화학습(RL)을 통해 모델 스스로 오류를 되짚는 긴 생각의 사슬(Long CoT)을 자율 습득 → 최고 수준의 복합 추론 달성 / 비정형 인문사회 영역의 보상 검증 한계

## 핵심 그림
```text

        |
        v
```

## 핵심 용어
- GRPO(Group Relative Policy Optimization): 기존 PPO와 달리 별도의 가치 신경망(Critic)을 두지 않고, 동일 프롬프트에 대한 여러 출력 그룹의 상대적 점수 차이로 정책을 갱신해 GPU VRAM을 획기적으로 아끼는 알고리즘
- 아하 모먼트(Aha Moment): 학습 도중 모델 스스로 자신의 중간 계산 오류를 인지하고 "Wait, let me rethink this..."라며 풀이 경로를 수정하는 자가 반조 현상이 자발적으로 발생하는 현상
- 테스트 타임 컴퓨트(Test-time Compute): 학습 단계뿐만 아니라 추론(Inference) 단계에서 더 많은 토큰과 연산 시간을 소모할수록 정답률이 지수적으로 향상되는 새로운 스케일링 법칙

## 핵심 통찰
- OpenAI o1이 비공개로 유지하던 추론 모델의 학습 원리가 "순수 강화학습과 테스트 타임 컴퓨팅"임을 전 세계에 증명하고 오픈소스로 전면 공개
- 보상 신경망(Reward Model) 대신 컴파일러(코드 통과 여부)나 수학 정답 비교기 등 "규칙 기반 검증기(Rule-based Verifier)"를 사용하여 보상 해킹을 완벽히 차단한 것이 성공의 핵심
- 대형 모델(671B)이 강화학습으로 터득한 긴 추론 경로(CoT) 데이터를 1.5B~8B 소형 모델에 지도학습으로 지식 증류(Distillation)해도 소형 모델의 추론력이 비약적으로 상승

## 이웃 토픽과 구분
- DeepSeek-R1 vs 전통 LLM: 전통 LLM은 질문이 들어오면 즉시 다음 단어를 출력 / DeepSeek-R1은 최종 답변 전에 수천 토큰 이상의 보이지 않는 `<think>` 추론 과정을 거치며 자가 검증 후 답변

## 문제·원인·대책
- 적용 상황: 순수 강화학습 모델에서 언어 혼용 및 끝없는 생각의 늪(Loop) 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 영어와 중국어가 한 문장에 뒤섞임 | 보상 함수에 언어 일관성 페널티가 누락됨 | 언어 일관성 보상(Language Consistency Reward) 추가 | 지정된 언어로 정갈하게 출력 정렬 |
| `<think>` 토큰만 수만 개 생성하며 멈춤 | 생각의 길이에 대한 조절 장치 부재 | 출력 길이 제한 페널티 및 거절 샘플링(Rejection Sampling) 결합 | 최적 추론 토큰 길이 수렴 및 무한 루프 방지 |
| 주관식 작문 등 정답 없는 태스크 적용 실패 | 규칙 기반 채점기(Rule-based Verifier) 설계 불가 | DPO/RLHF 기반의 인간 선호도 보상 모델과의 하이브리드 결합 | 창의적 글쓰기 및 일반 대화 역량 동시 확보 |

## 이렇게 출제된다
- 미출제. 예상: "사전 지도학습(SFT) 없이 순수 강화학습만으로 추론 능력을 극대화한 DeepSeek-R1의 학습 원리와 GRPO 알고리즘의 특징을 설명하시오." → 요구 포인트: Ⅰ 개념 + Ⅲ R1 파이프라인 + Ⅴ PPO vs GRPO 메커니즘

## 내 의견
- [도메인 특화 추론 모델을 위한 사내 컴파일러 결합 RL 구축] 일반 기업이 수천억 원의 사전 학습을 할 수는 없으나, DeepSeek-R1 증류 모델을 바탕으로 도메인 특화 강화학습을 수행하는 것은 충분히 가능함 → 나라면: SQL 문법 검증기, 회계 정합성 체크기, 법률 판례 검증기를 보상 함수로 두고 사내 sLM에 GRPO를 적용하여 금융/법률 분야의 무환각 복합 추론 엔진 구축
