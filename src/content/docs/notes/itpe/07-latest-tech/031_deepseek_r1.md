## 지식 로드맵 내 현재 위치

지식 위치: 대규모 언어모델 → 추론 능력 강화 → 강화학습 기반 모델 → **DeepSeek-R1**

## 30초 인출

- 본질: **DeepSeek-R1** 은 강화학습과 지도학습 단계를 결합해 추론 응답을 개선한 언어 모델 계열
- 메커니즘: 기본 모델의 강화학습 실험(R1-Zero) → 콜드스타트 자료·강화학습·선별 지도학습을 결합한 R1
- 통찰: 한계: 강화학습 보상만으로 추론을 개선하면 응답 가독성·일관성 저하 가능 → 방안: 콜드스타트·선별 지도학습을 결합하고 독립 과업에서 검증

<details>
<summary>핵심 용어</summary>

- **DeepSeek-R1** : 추론 능력 향상을 위해 강화학습과 선별 지도학습을 조합한 언어 모델 계열
- **DeepSeek-R1-Zero** : 지도 미세조정 없이 강화학습부터 적용해 추론 행동을 학습한 모델 실험
- **GRPO(Group Relative Policy Optimization)** : 같은 질문에 대한 응답 집단의 상대적 보상을 이용해 정책을 최적화하는 방법
- **규칙 기반 보상(Rule-based Reward)** : 수학 정답·코드 실행 등 판정 가능한 기준으로 응답을 평가하는 보상
- **지식 증류(Knowledge Distillation)** : 교사 모델의 출력·정보를 이용해 학생 모델을 학습하는 방법
</details>

## 2~4교시 25점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **DeepSeek-R1** 은 강화학습과 지도학습 단계를 결합해 추론 응답을 개선한 언어 모델 계열 |
| 목적 | 수학·코드 등 다단계 추론 과업의 응답 능력 향상 |

### Ⅱ. R1-Zero와 R1

```text
R1-Zero: 기본 모델 ── 대규모 강화학습 ──> 추론 행동
R1: 콜드스타트 예시 ── 강화학습 ── 선별 지도학습 ──> 추론·표현 보완
                         │
               검증 가능한 보상과 별도 평가 과업
```

| 모델 | 핵심 학습 특징 |
|---|---|
| DeepSeek-R1-Zero | 지도 미세조정 없이 대규모 강화학습을 적용한 실험 |
| DeepSeek-R1 | 콜드스타트 자료·강화학습·선별 지도학습 등을 결합한 학습 |

### Ⅲ. GRPO 원리

```text
질문별 응답 집단 생성
          ↓
응답별 보상 계산
          ↓
집단 안에서 상대적 이점 비교
          ↓
정책 매개변수 갱신
          └──── 다음 학습 반복
```

### Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 주관적 과업에서 보상 정의가 어렵고 보상 해킹 가능 | 정답·형식·코드 실행처럼 판정 가능한 신호를 분리 검증 |
| 강화학습 보상만 추구하면 응답 가독성·일관성 저하 | 콜드스타트·선별 지도학습을 결합하고 별도 평가 |
| 연구 결과를 다른 운영 과업에 그대로 일반화하기 어려움 | 과업별 기준선과 독립 평가 자료로 품질·비용 확인 |

### Ⅴ. 제언

적용 과업별 보상 타당성과 독립 평가 기준선을 먼저 정하고 개선이 확인된 범위에 제한 배포.
