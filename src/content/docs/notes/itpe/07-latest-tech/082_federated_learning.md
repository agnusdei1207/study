## 핵심 용어
- 연합 평균(Federated Averaging, FedAvg): 각 엣지 클라이언트가 로컬 데이터셋으로 여러 에포크(Epoch) 동안 SGD를 수행한 후 얻은 가중치들을, 중앙 서버가 각 클라이언트의 데이터 샘플 수($n_k$)에 비례하여 가중 평균하는 기본 집계 알고리즘
- 비-IID(Non-Independent and Identically Distributed): 사용자마다 스마트폰 사용 습관, 언어, 관심사가 완전히 달라 각 클라이언트가 보유한 로컬 데이터셋의 통계적 분포가 독립적이지 않고 매우 이질적인 현상
- 안전 다자간 계산(Secure Multi-Party Computation, SMC): 각 클라이언트가 자신의 가중치 그래디언트를 다른 클라이언트나 중앙 서버에 날것으로 노출하지 않고, 암호화된 상태에서 오직 최종 합계값만을 서버가 복호화할 수 있도록 보장하는 암호학적 기법

## 핵심 통찰
- "가중치만 보내면 안전하다"는 것은 환각적 오해: 딥러닝 역공학(Model Inversion / Gradient Inversion) 공격을 통하면 중앙 서버에 전송된 가중치 변화량만 역추적하여 원본 환자 얼굴이나 텍스트를 픽셀 단위로 복원 가능 → 차분 프라이버시(DP) 노이즈 주입 또는 동형암호/SMC 결합이 필수
- 연합학습의 가장 큰 공학적 난제는 "통신 병목(Communication Bottleneck)": 수억 대의 스마트폰 무선 업로드 대역폭은 데이터센터 내부 네트워크에 비해 터무니없이 느림 → 가중치 희소화(Sparsification) 및 양자화 전송이 필수
- 데이터가 편향된 Non-IID 환경에서는 단순 평균(FedAvg)을 돌리면 글로벌 모델이 특정 대형 클라이언트 쪽으로 끌려가다 발산하므로, 로컬 업데이트가 글로벌 가중치에서 너무 멀어지지 않도록 규제항을 거는 FedProx 도입이 필수적

## 이웃 토픽과 구분
- 연합학습 vs 분산 딥러닝(Distributed Training): 분산 딥러닝은 단일 데이터센터 안에서 빠른 InfiniBand로 묶인 GPU들이 균일한(IID) 데이터를 쪼개 학습 / 연합학습은 인터넷 망을 통해 흩어진 이종 기기들이 서로 다른(Non-IID) 데이터를 로컬에 가둔 채 학습
