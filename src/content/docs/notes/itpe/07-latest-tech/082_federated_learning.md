## 지식 로드맵 내 현재 위치
IT 인공지능 → 분산 학습 → 데이터 분산형 학습 → 연합학습

## 30초 인출
- **본질:** 연합학습은 여러 참여자가 원본 데이터를 각자 보유한 채 공동 모델을 학습하는 방식이다.
- **메커니즘:** 중앙 모델을 내려보내고 참여자가 로컬 학습한 뒤, 모델 업데이트를 집계해 새 모델을 만든다.
- **추가 단서:** 원본 데이터가 이동하지 않아도 업데이트에서 정보가 드러날 수 있으므로 추가 보호가 필요하다.

<details><summary>핵심 용어</summary>

- **연합 평균(Federated Averaging, FedAvg):** 참여자의 로컬 학습 결과를 표본 수 등을 가중치로 집계하는 기본 연합학습 방법이다.
- **비독립·동일분포 아님(Non-IID):** 참여자마다 데이터의 분포·수량·특성이 서로 다른 상태다.
- **안전 집계(Secure Aggregation):** 프로토콜의 가정 아래 서버가 개별 업데이트 대신 집계 결과만 얻도록 보호하는 방법이다.
- **차분 프라이버시(Differential Privacy):** 한 개인의 자료 포함 여부가 결과에 미치는 영향을 제한하도록 수학적 보장을 제공하는 프라이버시 기준이다.
</details>

## 1교시 10점 답안
### 1. 정의·목적
정의: 연합학습은 원본 데이터를 참여자에게 둔 채 모델을 공동 학습하는 분산 학습 방식이다.
목적: 자료를 중앙에 모으기 어려운 환경에서 여러 기관·기기의 데이터를 활용한다.

### 2. FedAvg 기본 흐름
```mermaid
flowchart TD
    G[서버 글로벌 모델 w_t] -->|선택된 참여자에게 배포| K[참여자 로컬 자료·학습]
    K -->|업데이트 Δw_k 전송| A[서버 집계]
    A -->|참여 자료량 등으로 가중 평균| U[글로벌 모델 w_(t+1)]
    U -->|다음 학습 라운드| G
```

원본 데이터는 참여자 로컬에 남지만, 기본 연합학습만으로 업데이트의 정보 노출이 없어지지는 않는다.

### 3. 보호 방법
| 위험 | 보완 방법 |
|---|---|
| 개별 업데이트 관찰 | 안전 집계 등으로 개별 업데이트 노출 제한 |
| 업데이트로 인한 개인 정보 추론 | 차분 프라이버시 등 추가 보호 검토 |

**제언:** 민감도와 위협 모델을 평가해 프라이버시 보호 수준을 명시한다.

## 2~4교시 25점 답안
## Ⅰ. 개요와 학습 구조
연합학습은 원본 데이터가 분산된 환경에서 공통 모델을 학습한다. 참여자 데이터가 로컬에 남는다는 것은 데이터 수집 방식을 바꾸는 것이며, 그 자체가 완전한 프라이버시 보장을 뜻하지 않는다.

| 방식 | 원본 자료 처리 | 주요 고려사항 |
|---|---|---|
| 중앙집중 학습 | 학습 자료를 중앙 저장·처리 | 자료 이전·집중 보호 필요 |
| 연합학습 | 참여자별 로컬 저장·학습 | 업데이트 보호, 통신, 비IID 자료 |

## Ⅱ. FedAvg 라운드
```mermaid
flowchart TD
    G[서버 글로벌 모델 w_t] -->|선택된 참여자에게 배포| K[참여자 로컬 자료·학습]
    K -->|업데이트 Δw_k 전송| A[서버 집계]
    A -->|참여 자료량 등으로 가중 평균| U[글로벌 모델 w_(t+1)]
    U -->|다음 학습 라운드| G
```

기본 FedAvg는 참여자별 데이터 양에 따라 로컬 모델을 가중 집계하는 방식이다. 구현에 따라 참여자 선택, 로컬 반복 수, 업데이트 전송 표현이 달라질 수 있다.

## Ⅲ. 위험과 보호·운영 방안
| 위험·조건 | 대응 |
|---|---|
| 참여자별 데이터 분포가 달라 학습이 불안정할 수 있음 | 참여자별 자료·성능 편차를 측정하고 집계·개인화 방식을 평가 |
| 개별 업데이트에서 학습 자료가 추론될 수 있음 | 안전 집계로 개별 업데이트 노출을 줄이고 필요 시 차분 프라이버시를 적용 |
| 업데이트 오염 또는 악의적 참여 | 참여자 인증, 업데이트 검증, 이상치·강건 집계 등을 위협모델에 맞춰 사용 |
| 기기 연결 불안정·통신량 | 참여자 표본·전송 빈도·압축을 품질과 비용 기준으로 조정 |

| 보호 기법 | 보호 대상·성격 | 한계 |
|---|---|---|
| 안전 집계 | 서버가 개별 업데이트를 보지 않도록 보호 | 집계 결과 자체에 대한 추론 위험을 모두 해결하지 않음 |
| 차분 프라이버시 | 개인 기여의 영향에 대한 수학적 제한 | 프라이버시 예산과 모델 품질 간 절충 필요 |
| 강건 집계 | 이상하거나 악성인 업데이트 영향 완화 | 공격 유형과 가정에 따라 효능이 다름 |

## Ⅳ. 기술사적 제언
| 문제 | 해결 방안 |
|---|---|
| 데이터가 각 참여자 안에 있다는 이유만으로 연합학습을 개인정보 보호 수단으로 선택할 수 있음 | 먼저 데이터 이동이 필요한 이유와 참여자별 자료·계산 여건을 확인하고, 연합학습이 적합한 업무만 대상으로 선정한다. |
