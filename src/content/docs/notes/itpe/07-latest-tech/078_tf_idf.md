## 연관 키워드

- TF-IDF, 단어 빈도(TF), 역문서 빈도(IDF), 벡터 공간 모델(VSM), 코사인 유사도, 불용어(Stopwords)
- BM25, Dense Embedding, 희소 행렬(Sparse Matrix), 역색인(Inverted Index), 하이브리드 검색, RRF
- 어휘 불일치(Vocabulary Mismatch), 재현율(Recall)

## Ⅰ. TF-IDF의 개요

- 핵심 요약 : 문서 안의 빈도와 말뭉치 안의 희소성을 곱해 단어의 차별적 중요도를 계산하는 통계 기반 가중치 모델.
- 개념 : 단어 빈도와 역문서 빈도를 곱해 문서마다 단어의 중요도를 구하는 **TF-IDF** (Term Frequency-Inverse Document Frequency, 단어 빈도와 역문서 빈도의 곱으로 정의되는 가중치 모델).
- 배경 및 필요성 : 출현 횟수만으로 가중치를 매기면 조사나 "의", "은" 같은 흔한 단어가 높은 점수를 얻는다. 또한 어휘 일치에만 의존해 동의어와 문맥을 구분하지 못하므로, 흔한 단어의 영향을 낮추고 차별적인 단어를 살리는 가중치 체계가 필요해졌다.
- 주요 목적 : 불용어 영향 축소, 문서의 핵심 주제어 추출, 벡터 공간 모델 기반의 문서 분류와 유사도 검색 수행.

## Ⅱ. TF-IDF의 특징 및 장점

- 핵심 요약 : 문서 내 빈도와 말뭉치 내 희소성의 결합이 주제어 선별력과 계산 단순성으로 이어지는 방식.

1. **단어 빈도** (TF, Term Frequency, 문서 안에서 단어가 차지하는 상대 빈도) : 문서의 주제와 직결되는 단어에 높은 값을 부여 → 문서별 핵심어 식별.
2. **역문서 빈도** (IDF, Inverse Document Frequency, 전체 문서 수를 단어 포함 문서 수로 나눈 값의 로그) : 여러 문서에 흔한 단어의 가중치를 낮춤 → 공통어와 불용어의 영향 제거.
3. **벡터 공간 모델** (VSM, Vector Space Model, 문서를 단어 가중치 벡터로 표현하는 모델) : 문서와 질의를 벡터로 놓고 **코사인 유사도** (Cosine Similarity, 두 벡터 사이 각도의 코사인 값) 계산 → 유사 문서 검색 가능.

## Ⅲ. TF-IDF의 구조 (흐름)

- 핵심 요약 : 원시 빈도 행렬에 TF와 IDF를 곱해 가중치 행렬을 만들고, 벡터 간 코사인 유사도로 검색하는 계산 흐름.
- TF(t, d) : 문서 d에서 단어 t의 출현 횟수를 문서 d의 전체 단어 수로 나눈 값. 문서 안에서 많이 나올수록 주제와 밀접하다고 본다.
- IDF(t, D) : log(N ÷ DF(t))로 계산한다. N은 전체 문서 수, DF(t)는 단어 t를 포함하는 문서 수이며, 많은 문서에 나타나는 단어일수록 값이 작아진다.
- TF-IDF(t, d, D) : TF(t, d)와 IDF(t, D)의 곱. 문서 내 빈도와 말뭉치 내 희소성을 함께 반영한다.
- **평활화** (Smoothing, 분모가 0이 되거나 가중치가 과도하게 0으로 떨어지는 것을 막는 보정) : 구현에 따라 IDF 식에 상수를 더해 값을 안정시킨다.

```text
[ 말뭉치 문서 ]
          ↓  토큰화, 형태소 분석, 불용어 제거
[ 단어-문서 행렬 (원시 빈도) ]
          ↓  TF 계산 (문서 내 상대 빈도)
          ↓  IDF 계산 log(N ÷ DF)
[ TF × IDF 가중치 행렬 ]
          ↓  벡터 공간 모델 적용
[ 코사인 유사도 검색 ]
```

```text
예시: 문서 2개 (N = 2)
Doc1: 사과 바나나 / Doc2: 사과 과일

사과   DF=2  IDF=log(2/2)=0       → 가중치 0
바나나 DF=1  IDF=log(2/1)≈0.69
  Doc1의 바나나: TF 0.5 × 0.69 ≈ 0.35
```

## Ⅳ. TF-IDF와 BM25, Dense Embedding의 비교

- 핵심 요약 : TF-IDF는 어휘 기반의 가장 단순한 가중치이고, BM25는 그 한계를 수식으로 보정하며, Dense Embedding은 의미를 벡터로 표현하는 방식.

| 비교 항목 | TF-IDF | BM25 | Dense Embedding |
| --- | --- | --- | --- |
| 모델 성격 | 고전 통계 기반 가방 모델 | 확률적 검색 랭킹 함수 | 신경망 기반 밀집 벡터 표현 |
| 단어 빈도 반영 | 빈도에 비례해 선형 증가 | k1 파라미터로 상한을 두어 포화 | 문맥에 따라 어텐션으로 반영 |
| 문서 길이 정규화 | 별도 후처리가 필요 | b 파라미터로 수식 안에서 보정 | 청크 분할과 고정 차원 표현 |
| 의미·문맥 반영 | 불가 (어휘 일치 기반) | 불가 (어휘 빈도와 길이 기반) | 가능 (동의어, 문맥 유사도) |
| 계산 자원 | 매우 낮음 (CPU로 충분) | 낮음 (역색인과 결합) | 높음 (GPU 추론과 벡터 DB 필요) |

- 선택 기준 : 어휘 일치와 낮은 운영 비용이 중요하면 BM25 계열을, 동의어와 문맥 검색이 중요하면 Dense Embedding을 검토하고, 두 결과를 합쳐 쓰는 하이브리드 구성도 가능하다.

## Ⅴ. TF-IDF의 한계와 방안

- 핵심 요약 : 어휘 불일치, 긴 문서의 빈도 왜곡, 고차원 희소성을 하이브리드 검색, BM25 전환, 인덱스 압축으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 어휘 불일치와 동음이의어·다의어 | 같은 뜻의 다른 단어를 놓쳐 재현율 저하 | **하이브리드 검색** (Hybrid Search, 어휘 검색과 의미 검색 결과를 결합)과 **RRF** (Reciprocal Rank Fusion, 순위 역수를 합산하는 결합 기법) | 재현율 |
| 긴 문서의 빈도 왜곡 | 특정 단어가 반복되면 길이 보정 없이 가중치가 과대 계상 | 빈도 증가에 상한을 두고 평균 문서 길이를 반영하는 **Okapi BM25** 전환 | 검색 정확도 지표 |
| 고차원 희소성 | 어휘 사전 크기만큼 차원이 늘고 대부분 0으로 채워진 **희소 행렬** (Sparse Matrix) 형성 | **역색인** (Inverted Index, 단어에서 문서 목록으로 매핑하는 인덱스)의 압축과 불용어·저빈도어 필터링 | 인덱스 크기, 질의 지연 시간 |

## Ⅵ. TF-IDF 기반 검색 체계를 위한 기술사적 제언

- 핵심 요약 : 어휘 기반 가중치의 장점을 살리되 의미 검색을 단계적으로 결합하고, 사전과 자원을 함께 관리하는 설계 필요.

1. 업무 목적에 맞는 기준 선정 : 로그 검색이나 문서 분류처럼 자원이 제한되고 어휘 일치가 중요한 업무는 TF-IDF나 BM25를 기본 방식으로 두는 것이 비용 효율적이다.
2. 하이브리드 검색의 단계적 도입 : 어휘 검색으로 후보를 좁힌 뒤 임베딩 기반으로 재정렬하는 구성을 검증 데이터로 효과를 측정한 다음 확대하는 순서가 안정적이다.
3. 형태소 사전 거버넌스 : 형태소 분석기 사전과 불용어 목록을 현업과 함께 관리하고 변경 이력을 남겨, 검색 품질을 재현 가능하게 유지한다.

## Ⅶ. 결론

- 핵심 요약 : TF-IDF는 문서 내 빈도와 말뭉치 내 희소성을 곱해 차별 단어를 찾는 기초 가중치 모델.
- 시사점 : 의미 검색이 확산되어도 어휘 기반 가중치는 하이브리드 검색의 한 축으로 남으므로, 목적과 자원에 맞춰 두 방식을 조합하는 설계가 핵심이다.
