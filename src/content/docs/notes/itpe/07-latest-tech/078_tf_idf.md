 ┣━ Ⅱ 특징 ───── 국소 중요도(TF) 비례 · 전역 출현도(DF) 반비례 · 불용어 자동 페널티 · 로그 스케일링 · 희소 행렬(DTM) 표현

## 한 줄 본질
- "은/는/이/가"나 "the"처럼 모든 문서에 흔히 등장하는 불용어가 높은 빈도로 인해 중요한 단어로 오인되는 정보 왜곡 → 현재 문서에서 자주 나오면서도(TF) 다른 문서들에서는 거의 나오지 않는(IDF) 희소한 단어에 높은 가중치를 부여 → 문서의 핵심 키워드를 통계적으로 명확히 추출 / 단어의 순서와 문맥 의미는 파악 불가

## 핵심 그림
```text
[TF-IDF 계산 메커니즘 및 가중치 결정 원리]

      [특정 문서 내 빈도 (TF)]                [전체 문서 내 희소성 (IDF)]
  단어 t가 문서 d에 나타난 횟수             전체 문서 수 N / 단어 t를 포함한 문서 수 df
       tf(t, d) = f(t, d)                    idf(t, D) = log( N / (df(t) + 1) )
               |                                            |
               +--------------------+-----------------------+
                                    |
                                    v (원소별 곱셈: Element-wise Multiply)
                   +---------------------------------+
                   | TF-IDF(t, d, D) = tf(t, d) * idf(t, D) |
                   +---------------------------------+
                                    |
            +-----------------------+-----------------------+
            |                                               |
            v (결과 1: 핵심 키워드)                         v (결과 2: 일반 불용어)
  - 특정 문서에 집중 출현 (TF 높음)               - 모든 문서에 골고루 출현 (df 높음)
  - 다른 문서엔 거의 없음 (IDF 높음)              - 희소성 없음 (IDF -> 0에 수렴)
  ===> [ 매우 높은 가중치 부여 ]                 ===> [ 가중치 0에 가깝게 소거 ]
```

## 핵심 용어
- 단어 빈도(Term Frequency, TF): 특정 문서 $d$ 안에서 단어 $t$가 등장한 횟수로, 문서 내에서 해당 단어가 얼마나 자주 언급되었는지를 나타내는 국소 척도
- 역문서 빈도(Inverse Document Frequency, IDF): 전체 문서 수 $N$을 단어 $t$가 들어있는 문서 수 $df(t)$로 나눈 뒤 로그를 취한 값으로, 흔한 단어일수록 값이 0에 가까워지고 드문 단어일수록 값이 커지는 전역 희소성 척도
- 스무딩(Smoothing): 특정 단어가 말뭉치 전체에서 한 번도 등장하지 않아 분모가 0이 되는 분모 0 오류(Zero Division)를 방지하기 위해 $df(t) + 1$ 또는 $\log(1 + N/df)$ 형태로 1을 더해주는 기법

## 핵심 통찰
- TF-IDF의 수학적 아름다움은 "로그(Log) 함수의 적용": 단어 빈도는 선형적으로 증가하지만 정보량은 체감하므로, 역문서 빈도에 로그를 씌워 극단적인 가중치 폭증을 완만하게 억제
- TF-IDF는 검색 엔진의 시초이자 현재도 유효한 강력한 베이스라인: 의미를 모른다는 한계가 있지만, 연산량이 극도로 가볍고 도메인 특화 고유명사나 코드 식별에는 딥러닝 임베딩보다 정확하게 동작
- 현대 검색 엔진의 표준인 BM25는 본질적으로 TF-IDF에 "문서 길이 정규화(Document Length Normalization)"와 "TF 포화도(Saturation)"를 추가한 진화형 알고리즘

## 이웃 토픽과 구분
- TF-IDF vs Word2Vec: TF-IDF는 문서 단위의 단어 통계 가중치(희소 벡터) / Word2Vec은 주변 단어 문맥을 신경망으로 학습하여 단어의 의미 관계를 다차원 연속 공간에 사상한 밀집 벡터

## 문제·원인·대책
- 적용 상황: 법률 판례 검색 시스템에서 TF-IDF 기반 색인 구축 시 검색 오류 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 문서 길이가 긴 판례가 단순히 단어 수가 많다는 이유로 검색 상위를 독점 | TF-IDF 기본 공식에 문서 길이에 따른 페널티가 없어 긴 문서에 유리 | 코사인 정규화(L2 Norm) 또는 문서 길이를 보정하는 BM25 수식 적용 | 문서 길이 편향 제거 및 실제 관련도 순위화 |
| 어휘 사전에 등록되지 않은 신조어 및 오탈자 검색 시 매칭 실패(OOV) | 단어 표면 일치(Surface Match)에만 의존하는 형태소 역색인의 한계 | 서브워드(Byte-Pair Encoding) 단위 N-gram 역색인 분해 결합 | 신조어 및 오탈자 검색 재현율 85%까지 개선 |
| "손해배상"과 "금전보상"의 의미가 같음에도 다른 단어로 인식하여 누락 | 어휘 간 동의어 및 잠재 의미 관계(Semantic) 미반영 | LSA(잠재 의미 분석) 특이값 분해 또는 임베딩 기반 하이브리드 검색 결합 | 동의어·유의어 검색 누락률 90% 차단 |
