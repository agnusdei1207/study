## 연관 키워드

- 뉴로모픽(Neuromorphic) 칩, 스파이크 신경망(SNN), 스파이크, LIF, STDP, 대리 기울기
- 폰 노이만 병목, 인메모리 연산, 멤리스터, 이벤트 구동, 비 폰 노이만
- Intel Loihi 2, Hala Point, ANN-to-SNN, DVS, Lava

## Ⅰ. 뉴로모픽 칩의 개요

- 핵심 요약 : 뇌의 스파이크 방식을 하드웨어로 옮겨 폰 노이만 병목과 전력 소모를 줄이는 비 폰 노이만 AI 프로세서.
- 개념 : 연산과 기억을 한 곳에서 처리하고 **스파이크** (Spike, 임계값을 넘을 때만 발생하는 신호) 기반으로 동작하도록 CMOS 공정이나 멤리스터 소자로 구현한 **뉴로모픽 칩** (Neuromorphic Chip)으로, 폰 노이만 구조와 다른 비 폰 노이만(Non-von Neumann) 아키텍처를 따름.
- 배경 및 필요성 : 스파이크 신호는 계단 형태로 비연속적이어서 표준 **역전파** (Backpropagation)를 바로 적용하기 어려워, **대리 기울기** (Surrogate Gradient) 학습과 ANN(Artificial Neural Network)-to-SNN(Spiking Neural Network) 변환 도구가 필요함.
- 주요 목적 : **폰 노이만 병목** (Von Neumann Bottleneck)을 완화해 데이터 이동 지연과 에너지 소모를 낮추고, 자율주행·로보틱스·IoT(Internet of Things) 같은 에지 AI를 저전력으로 구동.
- 참고 : Intel은 2024년 4월 발표에서 Loihi 2 칩 1,152개를 묶은 연구용 시스템 Hala Point를 공개했으며, 발표 기준 뉴런 약 11.5억 개, 최대 소비 전력 약 2,600W 규모임.

## Ⅱ. 뉴로모픽 칩의 특징 및 장점

- 핵심 요약 : 이벤트 구동과 인메모리 연산이 저전력과 지연 감소로 이어지는 구조.

1. **이벤트 구동** (Event-Driven) : 입력이 있을 때만 뉴런이 활성화 → 유휴 상태의 전력 소모를 크게 줄임.
2. **인메모리 연산** (PIM, Processing in Memory) : 가중치를 저장하는 메모리 자체에서 곱셈 연산을 수행 → 프로세서와 메모리 사이의 데이터 이동 감소.
3. **시간 기반 부호화** : 스파이크의 발생 시점과 빈도로 정보를 표현 → 연속 센서 스트림 처리에 효율적.
4. **STDP** (Spike-Timing-Dependent Plasticity) 학습 : 스파이크 발생 시간차에 따라 시냅스를 국소적으로 갱신 → 중앙의 전역 역전파 없이 온칩 학습 가능.

## Ⅲ. 뉴로모픽 칩의 구조 (흐름)

- 핵심 요약 : 이벤트 센서의 비동기 스파이크가 시냅스 어레이를 거쳐 뉴런의 임계값 판정으로 발화되는 흐름.
- **LIF** (Leaky Integrate-and-Fire) 뉴런 : 입력 전하를 누적하고 누설시키다가 임계값에 도달하면 발화하는 기본 뉴런 모델.

```text
[ 스파이크 처리 흐름 ]

이벤트 센서 (DVS)
   ↓ 비동기 스파이크 (AER)
시냅스 어레이 (가중치 연산)
   ↓ 가중 전류 유입
LIF 뉴런 (전하 누적 · 누설)
   ↓ 임계값 도달 시
스파이크 발화 후 전위 리셋
   ↓ 다음 코어로 이벤트 전송
```

```text
[ LIF 뉴런의 세 단계 ]

1. 전하 누적 : 막전위 상승
2. 누설 : 입력이 없으면 기저 전위로 감쇠
3. 임계값 비교 : 도달 시 발화 후 리셋
```

## Ⅳ. CPU, GPU, NPU와 뉴로모픽 칩의 비교

- 핵심 요약 : 범용 프로세서와 가속기는 고정 행렬 연산에, 뉴로모픽은 이벤트성 스트림의 저전력 처리에 강점이 있어 용도가 갈림.

| 비교 축 | CPU | GPU | NPU | 뉴로모픽 칩 |
| --- | --- | --- | --- | --- |
| 구조 기반 | 폰 노이만 (직렬 중심) | 폰 노이만 (대규모 병렬) | 폰 노이만 (행렬 연산 특화) | 비 폰 노이만 (생체 모사) |
| 연산 방식 | 순차 명령어 제어 | SIMD·SIMT 병렬 연산 | 고정밀 곱셈·누적 텐서 연산 | 비동기 이벤트 구동 스파이크 연산 |
| 데이터 표현 | 실수형 | 부동소수점 | 양자화된 정수형 | 이진 스파이크와 발생 시점 |
| 메모리 구조 | 캐시와 DRAM 분리 | 전용 고대역폭 메모리 분리 | 온칩 SRAM 중심 | 시냅스 메모리와 뉴런 연산 통합 |
| 전력 소모 | 높음 | 매우 높음 | 높음 | 매우 낮음 |
| 주요 학습 방식 | 역전파 기반 최적화 | 전역 역전파 | 전역 역전파 | STDP, 대리 기울기 기반 학습 |

- 선택 기준 : 행렬 연산 중심의 대규모 학습은 GPU와 NPU, 센서 이벤트를 상시 처리하는 저전력 에지는 뉴로모픽이 맞음. Hala Point 같은 대규모 시스템은 칩 단위의 저전력 특성과 달리 시스템 전체 전력이 크므로 규모별 평가가 필요함.

## Ⅴ. 뉴로모픽 칩의 한계와 방안

- 핵심 요약 : 비미분성으로 인한 학습 곤란, 아날로그 소자의 산포와 드리프트, 소프트웨어 생태계 단절을 학습 기법과 보정 회로, 표준 프레임워크로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 스파이크 함수의 비미분성 | 계단형 함수라 표준 역전파를 그대로 적용할 수 없음 | 대리 기울기 학습과 ANN-to-SNN 변환 파이프라인 적용 | 학습 정확도 차이 |
| 아날로그 소자 산포와 드리프트 | 멤리스터와 **ReRAM** (Resistive Random-Access Memory)의 공정 편차와 온도 변화로 가중치가 흔들림 | 온칩 보정 회로, 디지털과 아날로그를 섞은 혼성 신호(Mixed-Signal) 아키텍처 채택 | 가중치 변화율 |
| 소프트웨어 생태계 단절 | 주류 딥러닝 프레임워크와 호환성이 부족해 모델 이식에 시간이 듦 | Lava, BindsNET 등 SNN 프레임워크 표준화, **ONNX** (Open Neural Network Exchange) 변환 인터페이스 구축 | 모델 이식 소요 기간 |

## Ⅵ. 뉴로모픽 칩에 대한 기술사적 제언

- 핵심 요약 : 엣지에서 이벤트 감시를 맡기고 고성능 연산은 필요할 때만 깨우는 역할 분담이 현실적인 적용 방향.

1. 엣지 기기는 평시에 극저전력 뉴로모픽 감시 회로로 이벤트를 상시 대기하고, 이벤트가 발생할 때만 고성능 연산을 활성화하는 2단계 구조를 채택하는 방향 추진 필요.
2. 센서 단에서는 프레임 단위 버퍼링을 줄이고 스파이크 발생 즉시 트리거하는 파이프라인을 설계하여 반응 지연을 낮추는 절차 정착 필요.
3. 기존 딥러닝 개발 환경과 연결되는 변환 도구와 SNN 프레임워크 표준을 함께 육성하는 산학 생태계 협력 필요.

## Ⅶ. 결론

- 핵심 요약 : 뉴로모픽 칩은 이벤트 기반 저전력 AI를 위한 하드웨어 방향이며, 학습 방식과 소프트웨어 생태계의 성숙이 확산의 관건임.
- 시사점 : 범용 AI 가속기를 대체하기보다 엣지의 이벤트 처리 영역에서 역할을 넓히는 전략이 현실적임.
