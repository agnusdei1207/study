## Ⅰ. 뉴로모픽 칩의 개요

- 개념 : 인간 뇌의 대규모 병렬성, 연산·기억의 통합 구조, **스파이크 기반 이벤트 구동 방식** 을 실리콘 반도체(CMOS/멤리스터)로 집적화한 차세대 비(Non) 폰 노이만 AI 프로세서.
- 배경 및 필요성 : 스파이크 신호의 계단형 비연속성으로 인해 표준 역전파(Backpropagation) 미분 적용이 불가능하므로 대리 기울기(Surrogate Gradient) 기법과 ANN-to-SNN 자동 변환 컴파일러 체계 구축 필요.
- 핵심 목적 : 폰 노이만 병목 해소를 통한 데이터 전송 지연 및 에너지 소모 극소화, 실시간 에지 AI(자율주행, 로보틱스, IoT)의 초저전력 구동 실현.

## Ⅱ. 뉴로모픽 칩의 핵심 아키텍처 및 동작 메커니즘

뉴로모픽 칩은 신뢰할 수 있는 데이터 파이프라인과 고도화된 추론 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 뉴로모픽 칩의 SNN 뉴런-시냅스 연산 및 스파이크 발화 아키텍처 ]       │
└────────────────────────────────────────────────────────────────────────┘

  [ 이벤트 기반 센서 (DVS / DABS) ]
              │ (비동기 스파이크 이벤트 발생: Address Event Representation)
              ▼
  ┌──────────────────────────────────────────────────────────────────────┐
  │ [ 뉴로모픽 코어 어레이 (Mesh NoC 기반 비동기 라우터 연계) ]          │
  │                                                                      │
  │   [ 시냅스 어레이 (SRAM / Memristor Crossbar Array) ]                │
  │    - 가중치 행렬 $W_{ij}$ 곱연산 (Ohm의 법칙 $I = V \times G$)      │
  │    - STDP 규칙에 의한 로컬 가중치 업데이트                           │
  │               │                                                      │
  │               ▼ (가중 전류 유입)                                     │
  │   [ 뉴런 회로 (LIF: Leaky Integrate-and-Fire Core) ]                │
  │    ├── 1. 전하 누적 (Integration): 막전위 $V(t)$ 상승               │
  │    ├── 2. 누입 감쇠 (Leakage): 입력 부재 시 기저 전위로 감쇠        │
  │    └── 3. 임계치 비교 ($V(t) \ge V_{th}$)                           │
  │               │                                                      │
  │         (임계치 돌파 시)                                             │
  │               ▼                                                      │
  │   [ 스파이크 펄스 발화 (Spike Out) ] ──> 전위 리셋 ($V(t) \leftarrow V_{reset}$)
  └───────────────┬──────────────────────────────────────────────────────┘
                  │ AER 패킷 브로드캐스팅
                  ▼
  [ 다음 계층 뉴로모픽 코어로 이벤트 전송 ]
```

- **이벤트 구동 (Event-Driven)** : 입력 신호가 있을 때만 비동기적으로 활성화 - 유휴 상태 전력 소모 제로화, 마이크로와트($\mu W$) 수준 초저전력 달성.
- **인메모리 연산 (PIM/PUM)** : 메모리 내부에 뉴런 연산 로직을 직접 배치 - 프로세서-메모리 간 버스 데이터 병목 및 열 발산 원천 차단.
- **시간-공간 정보 부호화** : 스파이크 펄스의 도달 시간차(Latency/Rate)로 코딩 - 시계열 및 연속 센서 스트림 데이터 처리에 탁월한 에너지 효율성.
- **가소성 기반 자가학습** : STDP 규칙을 통한 시냅스 가중치 국소 갱신 - 중앙 프로세서의 전역 역전파 없이 온칩(On-chip) 실시간 학습 가능.

## Ⅲ. 뉴로모픽 칩의 세부 구성 요소 및 비교 분석

| 비교 항목 | CPU | GPU | NPU (TPU 등) | 뉴로모픽 칩 (Intel Loihi 등) |
|---|---|---|---|---|
| **구조 기반** | 폰 노이만 (직렬) | 폰 노이만 (대규모 병렬) | 폰 노이만 (시스톨릭 어레이) | 비(Non) 폰 노이만 (생체 모사) |
| **연산 방식** | 연속 명령어 제어 | SIMD / SIMT 병렬 연산 | 고정밀 MAC 텐서 연산 | 비동기 이벤트 구동 스파이크 연산 |
| **데이터 표현** | 32/64비트 실수형 | 16/32비트 부동소수점 | INT8/FP8 양자화 행렬 | 시간차 1비트 이진 스파이크 |
| **메모리 구조** | 계층형 캐시/DRAM 분리 | 전용 GDDR/HBM 분리 | 온칩 온보드 SRAM 분리 | 시냅스 메모리-뉴런 연산 통합 (PIM) |
| **전력 소모** | 수십~수백 와트(W) | 수백 와트(W) (300~700W) | 수십~수백 와트(W) | 수 밀리와트(mW) ~ 수 마이크로와트 |
| **주요 학습 알고리즘** | 역전파 기반 최적화 | 전역 역전파(Backprop) | 전역 역전파(Backprop) | STDP, 대리 기울기 기반 역전파 |

- 뉴로모픽 칩은 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 뉴로모픽 칩의 주요 한계점 및 해결 방안

- 스파이크 함수의 비미분성으로 인한 역전파 적용 불가 :
  - 한계점 : 스파이크 함수의 비미분성(Step Function)으로 인해 표준 딥러닝 역전파 학습 적용 불가능.
  - 해결 방안 : 활성화 함수의 불연속점을 연속 함수로 근사하는 대리 기울기(Surrogate Gradient) 기법 및 사전 학습된 ANN을 SNN으로 변환하는 ANN-to-SNN 컴파일러 파이프라인 적용.
- 아날로그 소자 공정 산포 및 가중치 드리프트(Drift) :
  - 한계점 : 아날로그 소자(멤리스터, ReRAM)의 미세 공정 산포 및 온도 변화에 따른 시냅스 가중치 드리프트 발생.
  - 해결 방안 : 온칩 하이브리드 보정 회로 결합 및 디지털-아날로그 혼성 신호(Mixed-Signal) 아키텍처 채택.
- 주류 딥러닝 프레임워크와의 소프트웨어 생태계 단절 :
  - 한계점 : 텐서플로우, 파이토치 등 주류 딥러닝 프레임워크와의 소프트웨어 생태계 호환성 부족.
  - 해결 방안 : Lava(Intel), BindsNET 등 오픈소스 SNN 프레임워크 표준화 및 ONNX 모델 호환 변환 인터페이스 구축.

## Ⅴ. 뉴로모픽 칩 적용 및 발전을 위한 기술사적 제언

- 상시 소비 전력 고도화 및 평시 극저전력 감시 추진 : 지속적인 높은 소모 전력 (배터리 방전)의 한계를 탈피하고, 평시 극저전력 뉴로모픽 감시 후 필요시 활성화를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 반응 지연 시간 절감 및 최적화 체계 구축 : 프레임 버퍼링으로 수십 밀리초(ms) 지연의 한계를 탈피하고, 스파이크 발생 즉시 마이크로초($\mu s$) 단위 트리거를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 발열 및 신뢰성 강화 및 신뢰성 확보 방안 (Fanless) : 고발열로 인한 방열판 및 쿨러 필수의 한계를 탈피하고, 무소음 무팬(Fanless) 소형 임베디드 모듈 구현을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
