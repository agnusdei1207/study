## 한 줄 본질
- CPU와 메모리 사이를 끊임없이 오가는 전송 병목과 전력 낭비를 없애기 위해, 인간 뇌의 뉴런과 시냅스처럼 연산과 저장을 한곳에서 이벤트가 터질 때만 처리하는 초저전력 뇌 모방 칩

## 핵심 용어
- SNN(Spiking Neural Network): 0과 1의 연속적 신호 대신 생체 뇌처럼 시간 축에서 스파이크(전기 펄스) 신호의 타이밍과 빈도로 정보를 인코딩하여 전송하는 3세대 인공신경망
- LIF(Leaky Integrate-and-Fire): 입력 신호 전위를 시간 경과에 따라 일부 누출(Leak)시키며 누적(Integrate)하다가, 임계 전압(Threshold)에 도달하면 스파이크를 방출(Fire)하고 초기화되는 뉴런 수학 모델
- 멤리스터(Memristor): 전류의 흐름 방향과 양에 따라 저항값이 가변적으로 기억되는 소자로, 뇌의 시냅스 연결 강도(가중치)를 단일 나노 소자로 구현하는 비휘발성 저항 소자

## 핵심 통찰
- 이벤트 기반 뉴로모픽 연산은 입력이 드문 작업에서 불필요한 계산을 줄일 수 있음. 칩·센서·정확도 조건이 달라 전력 절감률을 보편적인 수치로 단정할 수 없음
- 일부 뉴로모픽 구조는 뉴런 상태와 시냅스 가중치를 연산 가까이에 배치해 데이터 이동을 줄임. 외부 메모리·통신 병목은 구현에 따라 남음
- 인텔 Loihi 및 IBM TrueNorth의 실증: 초저전력 사물인터넷, 드론 항법, 스마트 센서 등 상시 전원 공급이 불가능한 극한의 엣지 인프라에서 즉각적인 실시간 추론을 가능케 함

## 이웃 토픽과 구분
- 뉴로모픽 칩은 스파이크·이벤트 기반 처리를 주로 연구하고, NPU는 신경망의 텐서 연산 가속에 초점을 둠. 메모리·클럭·소자 구현은 제품마다 다름

## 1교시 10점 답안
- **정의:** 신경세포·시냅스의 연결과 이벤트 기반 신호 처리를 회로 구조에 반영한 컴퓨팅 하드웨어.
- **동작:** 입력 스파이크에 따라 뉴런 상태를 갱신하고 발화 이벤트를 전달. 데이터 이동과 계산을 국소화하도록 설계.
- **적용:** 이벤트 카메라·센서 처리 등에서 지연·전력·정확도를 기존 장치와 동일 조건으로 비교.

## 2~4교시 예상문제 (25점)

## 2~4교시 25점 답안
### Ⅰ. 구조
- 이벤트 입력, 뉴런 상태·시냅스 가중치 저장, 스파이크 라우팅과 출력 계층의 구성.
### Ⅱ. 처리 원리
- 신호가 발생할 때 계산하는 이벤트 구동 방식과 뉴런·시냅스 근처의 국소 연산으로 특정 워크로드의 데이터 이동 감소 추구.
### Ⅲ. 비교
- CPU/GPU는 범용 수치 연산·학습 생태계에 강점, 뉴로모픽 칩은 희소한 이벤트 흐름에 맞는 구조. 항상 전력 우위는 아님.
### Ⅳ. 도입 기준
- 모델 변환·학습 도구·정밀도·센서 연결과 실제 지연·전력·정확도 비교 필요.
