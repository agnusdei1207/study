## 30초 인출

- 본질: **뉴로모픽 칩** (Neuromorphic Chip)은 인간 뇌의 신경세포(뉴런)와 연결부(시냅스)의 전기적 신호 전달 구조를 하드웨어 회로로 모사한 비(Non) 폰 노이만 기반 초저전력 인공지능 반도체
- 메커니즘: 연산과 메모리가 통합된 병렬 코어에서 이벤트 기반 스파이크(SNN) 신호가 발생할 때만 막전위를 적분·발화(LIF)하고 STDP 가소성 규칙으로 시냅스 가중치 갱신
- 통찰: 스파이크 신호의 계단형 비연속성으로 인해 표준 역전파(Backpropagation) 미분 적용이 불가능하므로 대리 기울기(Surrogate Gradient) 기법과 ANN-to-SNN 자동 변환 컴파일러 체계 구축 필요

<details><summary>핵심 용어</summary>

- **뉴로모픽 컴퓨팅 (Neuromorphic Computing)** : 생물학적 뇌의 신경망 구조 및 정보 처리 메커니즘을 모방하는 반도체 컴퓨팅 기술.
- **SNN (Spiking Neural Network)** : 3세대 인공신경망으로, 연속적인 실수값 대신 시간에 따른 스파이크(Spike) 펄스 형태로 정보를 전달.
- **LIF 모델 (Leaky Integrate-and-Fire)** : 누입 전류를 고려하여 입력 스파이크에 따른 전하를 축적하다가 임계치 도달 시 펄스를 방출하는 뉴런 모델.
- **STDP (Spike-Timing-Dependent Plasticity)** : 시냅스 전후 뉴런의 스파이크 발생 시간차에 따라 연결 가중치를 강화하거나 약화시키는 생물학적 학습 규칙.
- **폰 노이만 병목 (Von Neumann Bottleneck)** : 프로세서와 메모리 간의 물리적 분리로 인해 데이터 전송 대역폭과 전력 소모가 급증하는 현상.

</details>

## 2~4교시 25점 답안

## Ⅰ. 뉴로모픽 칩의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 인간 뇌의 대규모 병렬성, 연산·기억의 통합 구조, 스파이크 기반 이벤트 구동 방식을 실리콘 반도체(CMOS/멤리스터)로 집적화한 차세대 비(Non) 폰 노이만 AI 프로세서 |
| 목적 | 폰 노이만 병목 해소를 통한 데이터 전송 지연 및 에너지 소모 극소화, 실시간 에지 AI(자율주행, 로보틱스, IoT)의 초저전력 구동 실현 |

## Ⅱ. 뉴로모픽 칩의 핵심 원리 및 아키텍처 특징

| 핵심 원리 | 동작 메커니즘 | 주요 특징 및 공학적 효과 |
|---|---|---|
| **이벤트 구동 (Event-Driven)** | 입력 신호가 있을 때만 비동기적으로 활성화 | 유휴 상태 전력 소모 제로화, 마이크로와트($\mu W$) 수준 초저전력 달성 |
| **인메모리 연산 (PIM/PUM)** | 메모리 내부에 뉴런 연산 로직을 직접 배치 | 프로세서-메모리 간 버스 데이터 병목 및 열 발산 원천 차단 |
| **시간-공간 정보 부호화** | 스파이크 펄스의 도달 시간차(Latency/Rate)로 코딩 | 시계열 및 연속 센서 스트림 데이터 처리에 탁월한 에너지 효율성 |
| **가소성 기반 자가학습** | STDP 규칙을 통한 시냅스 가중치 국소 갱신 | 중앙 프로세서의 전역 역전파 없이 온칩(On-chip) 실시간 학습 가능 |

## Ⅲ. 뉴로모픽 칩의 신호 처리 체계 및 뉴런-시냅스 구동 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 뉴로모픽 칩의 SNN 뉴런-시냅스 연산 및 스파이크 발화 아키텍처 ]       │
└────────────────────────────────────────────────────────────────────────┘

  [ 이벤트 기반 센서 (DVS / DABS) ]
              │ (비동기 스파이크 이벤트 발생: Address Event Representation)
              ▼
  ┌──────────────────────────────────────────────────────────────────────┐
  │ [ 뉴로모픽 코어 어레이 (Mesh NoC 기반 비동기 라우터 연계) ]          │
  │                                                                      │
  │   [ 시냅스 어레이 (SRAM / Memristor Crossbar Array) ]                │
  │    - 가중치 행렬 $W_{ij}$ 곱연산 (Ohm의 법칙 $I = V \times G$)      │
  │    - STDP 규칙에 의한 로컬 가중치 업데이트                           │
  │               │                                                      │
  │               ▼ (가중 전류 유입)                                     │
  │   [ 뉴런 회로 (LIF: Leaky Integrate-and-Fire Core) ]                │
  │    ├── 1. 전하 누적 (Integration): 막전위 $V(t)$ 상승               │
  │    ├── 2. 누입 감쇠 (Leakage): 입력 부재 시 기저 전위로 감쇠        │
  │    └── 3. 임계치 비교 ($V(t) \ge V_{th}$)                           │
  │               │                                                      │
  │         (임계치 돌파 시)                                             │
  │               ▼                                                      │
  │   [ 스파이크 펄스 발화 (Spike Out) ] ──> 전위 리셋 ($V(t) \leftarrow V_{reset}$)
  └───────────────┬──────────────────────────────────────────────────────┘
                  │ AER 패킷 브로드캐스팅
                  ▼
  [ 다음 계층 뉴로모픽 코어로 이벤트 전송 ]
```

| 처리 단계 | 세부 동작 메커니즘 | 핵심 하드웨어 구성요소 |
|---|---|---|
| **이벤트 인코딩** | 아날로그 센서 신호의 밝기/전압 변화율을 감지하여 펄스로 변환 | DVS(Dynamic Vision Sensor) 카메라 |
| **시냅스 전도** | 스파이크 전압 펄스가 가중치 컨덕턴스를 통과하여 전류 합산 | 멤리스터(ReRAM/PCM), 시냅틱 SRAM |
| **막전위 적분** | 유입 전류를 커패시터에 충전하며 전위 상승 누적 | 아날로그/디지털 적분기 커패시터 |
| **스파이크 발화** | 비교기(Comparator)를 통해 임계 전압 초과 시 1비트 펄스 발생 | 슈미트 트리거, 디지털 펄스 생성기 |
| **불응기 및 리셋** | 발화 즉시 막전위를 리셋 전위로 초기화하고 일정 시간 입력 차단 | 리셋 스위치 회로, 타이머 로직 |

## Ⅳ. 기존 프로세서(CPU, GPU, NPU)와 뉴로모픽 칩 비교

| 비교 항목 | CPU | GPU | NPU (TPU 등) | 뉴로모픽 칩 (Intel Loihi 등) |
|---|---|---|---|---|
| **구조 기반** | 폰 노이만 (직렬) | 폰 노이만 (대규모 병렬) | 폰 노이만 (시스톨릭 어레이) | 비(Non) 폰 노이만 (생체 모사) |
| **연산 방식** | 연속 명령어 제어 | SIMD / SIMT 병렬 연산 | 고정밀 MAC 텐서 연산 | 비동기 이벤트 구동 스파이크 연산 |
| **데이터 표현** | 32/64비트 실수형 | 16/32비트 부동소수점 | INT8/FP8 양자화 행렬 | 시간차 1비트 이진 스파이크 |
| **메모리 구조** | 계층형 캐시/DRAM 분리 | 전용 GDDR/HBM 분리 | 온칩 온보드 SRAM 분리 | 시냅스 메모리-뉴런 연산 통합 (PIM) |
| **전력 소모** | 수십~수백 와트(W) | 수백 와트(W) (300~700W) | 수십~수백 와트(W) | 수 밀리와트(mW) ~ 수 마이크로와트 |
| **주요 학습 알고리즘** | 역전파 기반 최적화 | 전역 역전파(Backprop) | 전역 역전파(Backprop) | STDP, 대리 기울기 기반 역전파 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 스파이크 함수의 비미분성(Step Function)으로 인해 표준 딥러닝 역전파 학습 적용 불가능 | 활성화 함수의 불연속점을 연속 함수로 근사하는 대리 기울기(Surrogate Gradient) 기법 및 사전 학습된 ANN을 SNN으로 변환하는 ANN-to-SNN 컴파일러 파이프라인 적용 |
| 아날로그 소자(멤리스터, ReRAM)의 미세 공정 산포 및 온도 변화에 따른 시냅스 가중치 드리프트 발생 | 온칩 하이브리드 보정 회로 결합 및 디지털-아날로그 혼성 신호(Mixed-Signal) 아키텍처 채택 |
| 텐서플로우, 파이토치 등 주류 딥러닝 프레임워크와의 소프트웨어 생태계 호환성 부족 | Lava(Intel), BindsNET 등 오픈소스 SNN 프레임워크 표준화 및 ONNX 모델 호환 변환 인터페이스 구축 |

## Ⅵ. 제언

실제 상용 시스템 도입을 위해 고정밀 대규모 연산은 NPU/GPU가 담당하고, 상시 대기 및 초저지연 감지는 뉴로모픽 칩이 담당하는 이기종 하이브리드 AI 에지 플랫폼 구축 필요.

```text
[ 환경 센서 입력 (영상, 음향, 진동) ]
                 │
                 ▼
[ 뉴로모픽 에지 센서 칩 (Always-On 모니터링: < 1mW) ]
   ├── 이벤트 감지 및 SNN 초고속 1차 분류
   │
   ├── (정상 상태 유지 시) ──> 저전력 슬립 모드 유지
   │
   └── (이상 징후 / 고위험 객체 포착 시: 웨이크업 인터럽트 발생)
                 │
                 ▼
[ 고성능 메인 NPU/GPU 활성화 (정밀 딥러닝 심층 추론 및 제어 실행) ]
```

| 구분 | 단일 GPU/NPU 상시 구동 | 제언: 뉴로모픽 기반 이기종 하이브리드 |
|---|---|---|
| **상시 소비 전력** | 50W ~ 200W 지속 소모 (배터리 방전) | 평시 1mW 이하 뉴로모픽 감시 후 필요시 활성화 |
| **반응 지연 시간** | 프레임 버퍼링으로 수십 밀리초(ms) 지연 | 스파이크 발생 즉시 마이크로초($\mu s$) 단위 트리거 |
| **발열 및 신뢰성** | 고발열로 인한 방열판 및 쿨러 필수 | 무소음 무팬(Fanless) 소형 임베디드 모듈 구현 |
| **배터리 수명** | 수 시간 내 소진 | 코인 배터리로 수개월~수년 상시 동작 가능 |
