## 30초 인출
- **본질:** 베이지안 최적화는 평가 비용이 큰 블랙박스 함수의 좋은 입력을 적은 실험으로 찾는 최적화 방법.
- **메커니즘:** 관측 결과로 대리 모델을 갱신하고 획득 함수가 제안한 다음 후보를 실제 평가.
- **균형:** 현재 성능이 높아 보이는 후보의 활용과 불확실성이 큰 후보의 탐색을 함께 고려.

<details><summary>핵심 용어</summary>

- **베이지안 최적화(Bayesian Optimization):** 비싼 목적 함수의 평가 횟수를 줄이기 위해 대리 모델과 다음 평가 기준을 반복 사용하는 최적화 방법.
- **목적 함수(Objective Function):** 입력 후보의 성능·비용 등 최적화할 값을 계산하는 함수.
- **대리 모델(Surrogate Model):** 관측한 입력과 평가값으로 아직 측정하지 않은 후보의 목적값을 추정하는 모델.
- **가우시안 프로세스(Gaussian Process, GP):** 함수값의 평균 추정과 불확실성을 함께 표현하는 대리 모델의 한 종류.
- **획득 함수(Acquisition Function):** 예측 성능과 불확실성을 사용해 다음 평가 후보를 선택하는 기준.
- **탐색·활용(Exploration·Exploitation):** 불확실성이 큰 후보의 조사와 유망 후보의 추가 평가 사이의 균형.
- **TPE(Tree-structured Parzen Estimator):** 후보 성능을 기준으로 파라미터 분포를 추정해 탐색을 안내하는 대리 모델 방식.

</details>

## Ⅲ. 대리 모델과 획득 함수
| 요소 | 기능 | 예 |
|---|---|---|
| 대리 모델 | 관측 자료로 미평가 후보의 성능·불확실성 추정 | GP, TPE 등 |
| 획득 함수 | 다음 후보 평가의 기대 이득을 점수화 | Expected Improvement, Upper Confidence Bound |
| 실제 평가 | 후보를 학습·실행해 관측값 추가 | 검증 점수, 실행 시간 등 |

특정 대리 모델과 획득 함수가 모든 탐색 공간에 가장 적합한 것은 아니므로 목적 함수의 특성·차원·범주형 변수·병렬 실행 조건을 고려.

## Ⅳ. 탐색과 활용
| 선택 방향 | 의미 | 유리한 상황 |
|---|---|---|
| 활용 | 예측 성능이 좋은 후보 주변의 추가 탐색 | 성능이 유망하고 불확실성이 낮은 구간 |
| 탐색 | 불확실성이 큰 후보의 평가 | 미측정 영역의 가능성을 확인할 필요가 있는 경우 |
| 균형 | 예측 성능과 불확실성을 함께 고려 | 평가 예산 안에서 개선 가능성과 정보 획득을 조정할 때 |

## Ⅴ. 적용 범위와 유의점
| 조건 | 검토 내용 |
|---|---|
| 평가 비용 | 실험 결과를 얻는 시간·자원과 단순 탐색 비용 비교 |
| 후보 공간 | 연속·이산·범주 변수와 제약 조건의 반영 방법 |
| 평가 변동 | 난수·데이터 분할에 따른 잡음과 반복 측정 필요성 |
| 자원·종료 | 병렬 실험, 중단 기준, 제한 예산 내의 비교 |

베이지안 최적화는 고비용 실험의 후보 선택 방법이지 전역 최적해나 특정 실험 횟수의 성과를 보장하는 알고리즘이 아님. GP 계열의 계산 부담과 TPE 등 대체 모델의 특성도 문제 규모에 맞춰 검토.

## Ⅵ. 기술사적 제언
| 한계 | 해결 방안 |
|---|---|
| 탐색 결과가 불안정한 평가 자료나 부적절한 성능 지표에 끌려갈 수 있음 | 실험 지표·검증 분할·재현 조건을 먼저 고정하고, 최종 후보를 별도 검증 자료로 재평가해 채택 여부 결정 |
