## 연관 키워드

- 베이지안 최적화(Bayesian Optimization), 블랙박스 함수, 대리 모델(Surrogate Model)
- 가우시안 프로세스(GP, Gaussian Process), 획득 함수(Acquisition Function), 기대 개선(EI)
- TPE(Tree-structured Parzen Estimator), 그리드 서치, 랜덤 서치
- 하이퍼파라미터 튜닝, BOHB, SMAC, ASHA

## Ⅰ. 베이지안 최적화의 개요

- 핵심 요약 : 평가 비용이 큰 목적함수를 대리 모델로 추정해 적은 시도로 최적점을 찾는 순차적 최적화 기법.
- 개념 : 미분값을 알 수 없고 한 번의 평가에 많은 시간과 비용이 드는 **블랙박스 함수**(Black-box Function) f(x)에 대해, 확률적 **대리 모델**과 **획득 함수**를 사용해 최대값을 가지는 x*를 최소 시도로 찾는 방법.
- 배경 및 필요성 : 딥러닝 학습처럼 한 번의 실험 비용이 크면 시도 횟수가 곧 비용이 되므로, 이전 결과를 버리지 않고 다음 시도를 고르는 계층이 필요함. 다만 탐색 차원이 커지면 대리 모델의 연산 비용이 늘어 대안 모델을 함께 고려해야 함.
- 주요 목적 : 무차별 탐색으로 낭비되는 실험을 줄이고, 하이퍼파라미터 튜닝의 효율과 최종 성능을 함께 확보하는 것.

## Ⅱ. 베이지안 최적화의 특징 및 장점

- 핵심 요약 : 대리 모델의 예측과 획득 함수의 탐색·활용 균형이 결합되어 적은 평가로 전역 최적점에 수렴하는 방식.

1. 대리 모델 활용 : 관측값으로 목적함수의 평균과 불확실성을 추정 → 실험하지 않은 지점의 기대 성능을 미리 예측.
2. 획득 함수의 균형 : **기대 개선**(EI, Expected Improvement) 등으로 탐색과 활용을 조절 → 불확실한 영역과 유망 영역을 함께 고려.
3. 순차적 갱신 : 평가 결과를 매번 대리 모델에 반영 → 이전 실험이 다음 실험 선택에 누적되어 시도 횟수 절감.

## Ⅲ. 베이지안 최적화의 구조 (흐름)

- 핵심 요약 : 초기 샘플, 대리 모델 갱신, 획득 함수 최대화, 실제 평가, 데이터 누적을 반복하는 순환 구조.

```text
[ 베이지안 최적화 순환 루프 ]

초기 샘플 평가 (소수의 무작위 시도)
        ↓
대리 모델 갱신 (관측값 반영)
        ↓
획득 함수 최대화 (다음 후보 선택)
        ↓
실제 목적함수 평가 (고비용 실험)
        ↓
관측 데이터 누적 후 반복
```

```text
[ 획득 함수의 선택 기준 ]

평균이 높은 지점 → 활용 (좋은 지점 주변)
불확실성이 큰 지점 → 탐색 (미지의 영역)
        ↓
EI 또는 UCB가 두 값을 결합해 다음 후보 결정
```

- 대리 모델(Surrogate Model) : **가우시안 프로세스**(GP, Gaussian Process)가 대표적이며, 관측 데이터로부터 미지 지점의 평균과 분산을 함께 추정함.
- 획득 함수(Acquisition Function) : 다음 평가 지점을 고르는 기준 함수. 기대 개선(EI)은 현재 최고점 대비 개선 기대치를, UCB(Upper Confidence Bound)는 평균에 불확실성 항을 더한 상한을 사용함.

## Ⅳ. 그리드 서치, 랜덤 서치와 베이지안 최적화의 비교

- 핵심 요약 : 그리드와 랜덤은 이전 실험을 활용하지 않는 독립 탐색, 베이지안 최적화는 누적 결과를 활용하는 순차 탐색이라는 점에서 구분됨.

| 비교 항목 | 그리드 서치 (Grid Search) | 랜덤 서치 (Random Search) | 베이지안 최적화 |
| --- | --- | --- | --- |
| 탐색 원리 | 지정된 격자점을 전부 순회 | 탐색 공간에서 무작위 추출 | 이전 결과의 확률 모델로 다음 지점 추천 |
| 이전 실험 활용 | 활용하지 않음 | 활용하지 않음 | 누적 결과를 반영 |
| 고차원 적합성 | 차원이 늘수록 격자 수가 급증해 취약 | 상대적으로 무난함 | 고차원에서는 대리 모델 비용 증가로 변형 기법 필요 |
| 평가 횟수 효율 | 낮음 | 중간 | 높음 (적은 평가로 수렴 기대) |

- 선택 기준 : 평가 비용이 크고 탐색 차원이 비교적 작을수록 베이지안 최적화의 효과가 큼. 평가가 저렴하면 랜덤 서치로도 충분할 수 있음.

## Ⅴ. 베이지안 최적화의 한계와 방안

- 핵심 요약 : 대리 모델 연산 비용, 고차원 탐색 비용, 비유망 실험의 낭비를 대리 모델 대체, 차원 축소, 조기 중단으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| GP 연산 비용 증가 | 관측 수가 늘수록 행렬 연산 비용이 커져 추천 지연 | TPE처럼 밀도 비율로 추정하는 대리 모델 사용 | 추천 지연 시간 |
| 고차원 탐색 공간 | 획득 함수 최적화 비용이 증가하고 탐색 효율 저하 | 중요도 높은 파라미터만 선별, 랜덤 포레스트 기반 SMAC, BOHB 적용 | 목적함수 대비 최적화 비용 비율 |
| 비유망 조합의 전 에포크 학습 | 가망 없는 조합까지 끝까지 학습하여 자원 낭비 | 중간 검증 손실로 조기 중단하는 ASHA 결합 | 조기 중단 비율, GPU 사용 시간 |

## Ⅵ. 베이지안 최적화에 대한 기술사적 제언

- 핵심 요약 : 학습 자원 관리와 대리 모델 선택을 함께 설계하여 베이지안 최적화를 상시 튜닝 체계로 정착시키는 방향.

1. 모델 학습 팀은 비유망 실험을 조기에 끊는 규칙을 튜닝 파이프라인에 기본으로 넣어, GPU 자원이 실패 실험에 묶이는 일을 줄여야 한다.
2. 연구 조직은 탐색 차원이 커지기 전에 중요도가 높은 하이퍼파라미터를 선별하고, 차원 수에 맞는 대리 모델을 고르는 기준을 세워야 한다.
3. 플랫폼 팀은 실험 이력을 공통 저장소에 남겨 이전 탐색 결과가 다음 튜닝에 이어지도록 해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 베이지안 최적화는 이전 실험을 확률 모델로 축적해 고비용 탐색의 낭비를 줄이는 최적화 방법.
- 시사점 : 효과는 대리 모델의 선택과 자원 관리 규칙에 달려 있으므로, 탐색 비용 구조에 맞춘 기법 선택이 실효성을 좌우함.
