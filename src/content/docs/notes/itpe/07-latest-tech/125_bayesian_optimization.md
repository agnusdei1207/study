## Ⅰ. 베이지안 최적화(Bayesian Optimization)의 개요

- 개념 : 함수의 미분값(Gradient)을 알 수 없고 1회 평가에 막대한 시간과 비용이 소요되는 **블랙박스 함수** $f(x)$에 대해, 확률적 대리 모델과 획득 함수를 활용하여 최소의 시도 횟수로 최적점($x^* = \arg\max f(x)$)을 도출하는 순차적 최적화 기술.
- 배경 및 필요성 : 탐색 차원이 20차원 이상으로 증가할 때 가우시안 프로세스의 $O(N^3)$ 큐빅 연산 병목과 차원의 저주가 발생하므로 **TPE** (Tree-structured Parzen Estimator) 대리 모델 전환 및 **가지치기 스케줄러** 결합 필수.
- 핵심 목적 : 딥러닝 모델 훈련 등 고비용 실험에서 **무차별 대입** (Brute-force) 탐색 낭비를 배제하고 하이퍼파라미터 튜닝의 효율성과 성능 극대화.

## Ⅱ. 베이지안 최적화(Bayesian Optimization)의 핵심 아키텍처 및 동작 메커니즘

베이지안 최적화는 신뢰할 수 있는 데이터 파이프라인과 고도화된 추론 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│             베이지안 최적화 (Bayesian Optimization) 순환 탐색 루프      │
└────────────────────────────────────────────────────────────────────────┘
 [ 초기 랜덤 샘플링 평가셋: D_0 = {(x_1, y_1), ..., (x_k, y_k)} ]
                           │
 ┌─────────────────────────┴────────────────────────────────────────────┐
 │ 순차적 최적화 반복 루프 (Iteration t = 1, 2, ..., T)                  │
 │                                                                      │
 │  [ 1단계: 대리 모델(GP) 사후 확률 분포 갱신 ]                        │
 │   기존 관측값 D_{t-1}을 반영하여 f(x)의 사후 평균 μ(x) 및 분산 σ(x) 도출│
 │                                                                      │
 │  [ 2단계: 획득 함수(Acquisition Function: α(x)) 계산 ]              │
 │   전체 탐색 공간에서 α(x) = EI(x) 또는 UCB(x) 프로파일 생성          │
 │                                                                      │
 │  [ 3단계: 다음 평가 지점 추천 (ArgMax α(x)) ]                        │
 │   획득 함수가 최대화되는 지점 x_t* 선택: x_t* = argmax α(x)           │
 │                                                                      │
 │  [ 4단계: 고비용 실제 목적함수 평가 (Real Evaluation) ]               │
 │   x_t* 파라미터로 실제 딥러닝 훈련 수행 ──> 검증 손실 y_t 측정        │
 │                                                                      │
 │  [ 5단계: 관측 데이터셋 갱신: D_t = D_{t-1} ∪ {(x_t*, y_t)} ]         │
 └─────────────────────────┬────────────────────────────────────────────┘
                           │ 최대 예산(T) 도달 시
                           ▼
 [ 최종 전역 최적 하이퍼파라미터 확정: x* = argmax y_t ]
```

- **대리 모델** (Surrogate Model) : 가우시안 프로세스: $f(x) \sim \mathcal{GP}(m(x), k(x, x'))$ - 관측된 데이터 쌍 $\mathcal{D}_{1:t}$를 기반으로 미지의 지점에 대해 정규분포 형태의 평균 $\mu(x)$과 분산 $\sigma^2(x)$을 동시 도출.
- **획득 함수** (Acquisition Function) : 기대 개선(EI): $\mathbb{E}[\max(0, f(x) - f(x^+))]$ - 현재 최고점 $f(x^+)$ 대비 개선 기대치가 높은 영역을 추천하여 탐색과 활용의 수학적 밸런스 달성.

## Ⅲ. 베이지안 최적화(Bayesian Optimization)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 그리드 서치 (Grid Search) | 랜덤 서치 (Random Search) | 베이지안 최적화 (본 토픽) |
|---|---|---|---|
| **탐색 원리** | 지정된 모든 격자점을 전수 순회 | 파라미터 공간 내 균등 무작위 추출 | 이전 결과의 사후 확률 기반 지능형 추천 |
| **이전 실험 활용** | 전혀 활용 안 함 (독립 실행) | 전혀 활용 안 함 (독립 실행) | 누적 반영하여 다음 실험 결정 |
| **차원의 저주 취약성** | 극도로 취약 (차원마다 지수 증가) | 비교적 강건 (연속 공간 탐색 우수) | GP는 20차원 한계, TPE는 고차원 우수 |
| **전역 최적점 도달력** | 격자 간격 사이의 최적점 누락 | 시도 횟수에 비례하여 근사 | 적은 시도로도 전역 최적점에 정밀 수렴 |
| **계산 비용 효율성** | 극도로 비효율적 (낭비 극심) | 중간 (단순하나 무작위성 의존) | 최고 효율 (목적함수 평가 횟수 최소화) |

- 베이지안 최적화는 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 베이지안 최적화(Bayesian Optimization)의 주요 한계점 및 해결 방안

- 가우시안 프로세스(GP) 연산 복잡도 병목 :
  - 한계점 : 대리 모델로 표준 가우시안 프로세스(GP) 사용 시 샘플 수 $N$에 대해 $O(N^3)$의 행렬 역행렬 연산 복잡도 발생.
  - 해결 방안 : 커널 밀도 추정을 사용하여 $O(N \log N)$으로 연산량을 대폭 낮춘 TPE(Tree-structured Parzen Estimator) 알고리즘 적용.
- 고차원 하이퍼파라미터 공간에서의 차원의 저주 :
  - 한계점 : 딥러닝 하이퍼파라미터가 30개 이상으로 증가할 때 획득 함수 최적화 자체의 연산 비용이 목적함수 평가를 압도.
  - 해결 방안 : 중요도가 높은 핵심 파라미터만 선별하는 차원 축소 기법, 베이지안 최적화와 하이퍼밴드를 결합한 BOHB 및 랜덤 포레스트 기반 SMAC 알고리즘 채택.
- 비유망 후보 조합에 대한 전체 에포크 수행 낭비 :
  - 한계점 : 유망하지 않은 하이퍼파라미터 조합임에도 에포크를 끝까지 수행함에 따라 낭비되는 컴퓨팅 자원과 시간.
  - 해결 방안 : 학습 중간 검증 손실을 모니터링하여 가망 없는 모델을 조기에 중단시키는 비동기 연속 반분법(ASHA) 결합.

## Ⅴ. 베이지안 최적화(Bayesian Optimization) 적용 및 발전을 위한 기술사적 제언

- GPU(Graphics Processing Unit) 자원 소모 절감 및 최적화 체계 구축 : 실패할 모델도 에포크 완주 낭비의 한계를 탈피하고, 가망 없는 모델 조기 중단으로 GPU 자원 절감을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 최적 성능 도달 향상 및 이전 지식 누적으로 도입 : 무작위 탐색으로 운에 좌우의 한계를 탈피하고, 이전 지식 누적으로 30회 시도 만에 최고점 달성을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 연산 복잡도 고도화 및 TPE 채택으로 대리 추진 : 연산 오버헤드 없음의 한계를 탈피하고, TPE 채택으로 대리 모델 연산 지연 최소화를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
