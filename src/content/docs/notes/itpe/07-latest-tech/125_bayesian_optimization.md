## 30초 인출

- 본질: **베이지안 최적화 (Bayesian Optimization)** 는 수학적 함수 수식을 알 수 없고 1회 평가 비용이 극도로 비싼 블랙박스 목적함수(Black-box Objective Function)의 최적 해를 확률적 대리 모델과 획득 함수를 통해 최소한의 실험 횟수로 탐색하는 순차적 최적화 기법
- 메커니즘: 기존 평가 데이터로 가우시안 프로세스(GP) 대리 모델(Surrogate Model)을 사후 갱신하고, 미지의 영역(Exploration)과 유망한 영역(Exploitation)을 조율하는 획득 함수(EI / UCB)를 최대화하는 다음 실험 후보 지점($x_{t+1}$)을 추천
- 통찰: 탐색 차원이 20차원 이상으로 증가할 때 가우시안 프로세스의 $O(N^3)$ 큐빅 연산 병목과 차원의 저주가 발생하므로 TPE(Tree-structured Parzen Estimator) 대리 모델 전환 및 가지치기 스케줄러 결합 필수

<details><summary>핵심 용어</summary>

- **베이지안 최적화 (Bayesian Optimization)** : 베이즈 정리를 바탕으로 사전 지식을 갱신하며 블랙박스 함수의 전역 최적점(Global Optimum)을 찾는 알고리즘.
- **대리 모델 (Surrogate Model)** : 실제 목적함수를 대신하여 입력에 대한 평균 예측값과 불확실성(표준편차)을 추정하는 확률 모형 (Gaussian Process, TPE).
- **획득 함수 (Acquisition Function)** : 대리 모델의 예측 평균과 분산을 입력받아 다음 번에 평가할 가장 가치 있는 후보점을 결정하는 효용 함수.
- **기대 개선 (EI, Expected Improvement)** : 현재까지 발견된 최선의 값보다 더 개선될 확률과 그 개선량의 기대치를 동시에 최대화하는 대표 획득 함수.
- **탐색과 활용 (Exploration vs Exploitation)** : 불확실성이 높은 미답사 영역을 탐색하는 것과 현재 높은 값을 보이는 유망한 영역을 집중 공략하는 전략 간의 상충 관계.

</details>

## 2~4교시 25점 답안

## Ⅰ. 베이지안 최적화의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **베이지안 최적화** 는 함수의 미분값(Gradient)을 알 수 없고 1회 평가에 막대한 시간과 비용이 소요되는 블랙박스 함수 $f(x)$에 대해, 확률적 대리 모델과 획득 함수를 활용하여 최소의 시도 횟수로 최적점($x^* = \arg\max f(x)$)을 도출하는 순차적 최적화 기술 |
| 목적 | 딥러닝 모델 훈련 등 고비용 실험에서 무차별 대입(Brute-force) 탐색 낭비를 배제하고 하이퍼파라미터 튜닝의 효율성과 성능 극대화 |

## Ⅱ. 베이지안 최적화의 2대 핵심 요소 및 특징

| 핵심 구성 요소 | 수학적 원리 및 대표 모델 | 공학적 특징 |
|---|---|---|
| **대리 모델 (Surrogate Model)** | 가우시안 프로세스: $f(x) \sim \mathcal{GP}(m(x), k(x, x'))$ | 관측된 데이터 쌍 $\mathcal{D}_{1:t}$를 기반으로 미지의 지점에 대해 정규분포 형태의 평균 $\mu(x)$과 분산 $\sigma^2(x)$을 동시 도출 |
| | TPE (Tree-structured Parzen Estimator) | 목적함수 상위 $\gamma$ 분위수를 기준으로 우수 분포 $l(x)$와 열등 분포 $g(x)$를 분리 추정하여 고차원 지원 |
| **획득 함수 (Acquisition Function)** | 기대 개선(EI): $\mathbb{E}[\max(0, f(x) - f(x^+))]$ | 현재 최고점 $f(x^+)$ 대비 개선 기대치가 높은 영역을 추천하여 탐색과 활용의 수학적 밸런스 달성 |
| | 상한 신뢰 구간(UCB): $\mu(x) + \kappa \cdot \sigma(x)$ | 평균 예측값 $\mu(x)$(활용)에 불확실성 가중치 $\kappa \sigma(x)$(탐색)를 더하여 점수화 |

## Ⅲ. 사전 확률 갱신 및 획득 함수 기반 순환 탐색 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│             베이지안 최적화 (Bayesian Optimization) 순환 탐색 루프      │
└────────────────────────────────────────────────────────────────────────┘
 [ 초기 랜덤 샘플링 평가셋: D_0 = {(x_1, y_1), ..., (x_k, y_k)} ]
                           │
 ┌─────────────────────────┴────────────────────────────────────────────┐
 │ 순차적 최적화 반복 루프 (Iteration t = 1, 2, ..., T)                  │
 │                                                                      │
 │  [ 1단계: 대리 모델(GP) 사후 확률 분포 갱신 ]                        │
 │   기존 관측값 D_{t-1}을 반영하여 f(x)의 사후 평균 μ(x) 및 분산 σ(x) 도출│
 │                                                                      │
 │  [ 2단계: 획득 함수(Acquisition Function: α(x)) 계산 ]              │
 │   전체 탐색 공간에서 α(x) = EI(x) 또는 UCB(x) 프로파일 생성          │
 │                                                                      │
 │  [ 3단계: 다음 평가 지점 추천 (ArgMax α(x)) ]                        │
 │   획득 함수가 최대화되는 지점 x_t* 선택: x_t* = argmax α(x)           │
 │                                                                      │
 │  [ 4단계: 고비용 실제 목적함수 평가 (Real Evaluation) ]               │
 │   x_t* 파라미터로 실제 딥러닝 훈련 수행 ──> 검증 손실 y_t 측정        │
 │                                                                      │
 │  [ 5단계: 관측 데이터셋 갱신: D_t = D_{t-1} ∪ {(x_t*, y_t)} ]         │
 └─────────────────────────┬────────────────────────────────────────────┘
                           │ 최대 예산(T) 도달 시
                           ▼
 [ 최종 전역 최적 하이퍼파라미터 확정: x* = argmax y_t ]
```

| 탐색 절차 | 상세 동작 내용 | 수학적 제어 기법 |
|---|---|---|
| **사전 지식 반영** | 이전 실험 결과들을 결합하여 다변량 정규분포 사후 확률 갱신 | 베이즈 갱신 공식 |
| **미답사 영역 발굴** | 관측 데이터가 없어 분산 $\sigma(x)$가 큰 영역은 획득 함수 점수 상승 | Exploration (탐색) |
| **유망 영역 정밀화** | 이미 높은 성능이 관측되어 평균 $\mu(x)$가 높은 영역 집중 검증 | Exploitation (활용) |
| **비용 최적화** | 실제 함수 평가 횟수를 최소화하면서 전역 최적점 신속 수렴 | 목적함수 호출 최소화 |

## Ⅳ. 하이퍼파라미터 튜닝 기법 비교

| 비교 항목 | 그리드 서치 (Grid Search) | 랜덤 서치 (Random Search) | 베이지안 최적화 (본 토픽) |
|---|---|---|---|
| **탐색 원리** | 지정된 모든 격자점을 전수 순회 | 파라미터 공간 내 균등 무작위 추출 | 이전 결과의 사후 확률 기반 지능형 추천 |
| **이전 실험 활용** | 전혀 활용 안 함 (독립 실행) | 전혀 활용 안 함 (독립 실행) | 100% 누적 반영하여 다음 실험 결정 |
| **차원의 저주 취약성** | 극도로 취약 (차원마다 지수 증가) | 비교적 강건 (연속 공간 탐색 우수) | GP는 20차원 한계, TPE는 고차원 우수 |
| **전역 최적점 도달력** | 격자 간격 사이의 최적점 누락 | 시도 횟수에 비례하여 근사 | 적은 시도로도 전역 최적점에 정밀 수렴 |
| **계산 비용 효율성** | 극도로 비효율적 (낭비 극심) | 중간 (단순하나 무작위성 의존) | 최고 효율 (목적함수 평가 횟수 최소화) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 대리 모델로 표준 가우시안 프로세스(GP) 사용 시 샘플 수 $N$에 대해 $O(N^3)$의 행렬 역행렬 연산 복잡도 발생 | 커널 밀도 추정을 사용하여 $O(N \log N)$으로 연산량을 대폭 낮춘 TPE(Tree-structured Parzen Estimator) 알고리즘 적용 |
| 딥러닝 하이퍼파라미터가 30개 이상으로 증가할 때 획득 함수 최적화 자체의 연산 비용이 목적함수 평가를 압도 | 중요도가 높은 핵심 파라미터만 선별하는 차원 축소 기법(BOHB) 및 랜덤 포레스트 기반 SMAC 알고리즘 채택 |
| 유망하지 않은 하이퍼파라미터 조합임에도 에포크를 끝까지 수행함에 따라 낭비되는 컴퓨팅 자원과 시간 | 학습 중간 검증 손실을 모니터링하여 가망 없는 모델을 조기에 중단시키는 비동기 연속 반분법(ASHA) 결합 |

## Ⅵ. 제언

대규모 LLM 및 딥러닝 모델 튜닝 비용을 절감하기 위해 TPE 대리 모델과 조기 가지치기(ASHA)를 융합한 Optuna 기반 고속 AutoML 파이프라인 구축 권고.

```text
[ 하이퍼파라미터 탐색 공간 정의 (Learning Rate, Batch, LoRA Rank) ]
                             │
                             ▼
┌────────────────────────────────────────────────────────┐
│ Optuna 통합 베이지안 오케스트레이터                     │
│                                                        │
│  [ TPE 샘플러: 사후 확률 기반 유망 조합 추천 ]         │
│               │                                        │
│               ▼ Trial i 파라미터 생성                  │
│  [ GPU 학습 노드 분산 훈련 시작 (Epoch 1 to 100) ]     │
│               │                                        │
│               ▼ 매 에포크 검증 손실 전송               │
│  [ ASHA 가지치기(Pruner) 실시간 감시 ]                 │
│    ├── 하위 50% 성능 ──> [ 가차없이 훈련 조기 강제 중단] │
│    └── 상위 50% 성능 ──> [ 훈련 지속 및 최종 기록 갱신] │
└────────────────────────────────────────────────────────┘
```

| 구분 | 단순 랜덤 서치 병렬 실행 | 제언: TPE + ASHA 결합 베이지안 최적화 |
|---|---|---|
| **GPU 자원 소모** | 실패할 모델도 100 에포크 완주 낭비 | 가망 없는 모델 조기 중단으로 GPU 75% 절감 |
| **최적 성능 도달** | 무작위 탐색으로 운에 좌우 | 이전 지식 누적으로 30회 시도 만에 최고점 달성 |
| **연산 복잡도** | 연산 오버헤드 없음 | TPE 채택으로 대리 모델 연산 지연 0.1초 미만 |
| **확장성** | 단순 스케일 아웃 | 분산 클러스터(Ray) 연동 수백 개 동시 탐색 |
