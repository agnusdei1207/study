---

## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | AI를 생체 분자 예측·후보 탐색 등에 활용하는 접근 |
| 목적 | 실험 대상 선정과 바이오 연구 효율 지원 |

1. **목적:** 방대한 분자·단백질 조합에서 실험 우선순위를 정하고 가설 생성 비용을 낮추는 보조 수단.
2. **파이프라인:** 적법한 데이터 수집·표준화 → 구조/결합/독성 예측 → 불확실성 기반 후보 선정 → 세포·동물 실험 → 재현성과 임상 적합성 검토.
3. **검증:** 데이터 누출 방지 분할, 외부 실험 집합, 활성·선택성·독성 등 복수 지표 평가. AlphaFold 계열 구조 예측과 후보 약효 예측의 다른 목적 구분.
4. **관리:** 민감 유전체 정보 보호, 병원체·합성 가능성의 위해 평가, 실험 실패 결과의 재학습 반영, 규제·의료 전문가 검토.
