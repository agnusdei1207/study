AI 개발 → 학습 데이터 → 데이터 품질·권리

## 30초 인출

- 본질: AI 학습 데이터의 출처·권리·품질·대표성·계보를 관리하여 모델의 성능과 위험을 통제하는 접근
- 메커니즘: 자료 출처·권한 확인 → 정제·라벨·분할 → 품질·오염 평가와 버전 관리
- 통찰: 한계: 데이터 양만 늘리면 권리 문제·오염·집단 편향이 모델에 전파된다 → 방안: 출처·허락·계보를 기록하고 분할·하위 집단 품질을 점검해 갱신한다.

- **합성 데이터:** 시뮬레이션이나 생성 모델 등으로 만든 학습·평가 자료

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 학습 데이터의 출처·권리·품질·계보를 관리하는 접근 |
| 목적 | 모델 학습·평가 자료의 적합성 확보 |

## Ⅱ. 학습 데이터의 품질 경로

```text
출처·이용 권한 → 수집·중복 제거·라벨 검수
                          ↓ 버전·계보 기록
                  학습/검증/시험 분리
                          ↓ 오류·편향 평가
                      데이터 갱신
```

- **입력 관리:** 출처, 수집 조건, 이용 허락, 개인 정보와 민감 정보의 처리 근거 및 보존 기간 기록.
- **품질 관리:** 정규화·중복 제거·라벨 일치도, 하위 집단의 대표성, 오염·유출 탐지와 학습·평가 집합의 분리.

## Ⅲ. 학습 데이터의 관리 축

| 축 | 확인 내용 |
|---|---|
| 권리·계보 | 출처, 허락, 변경·삭제 이력 |
| 품질·대표성 | 중복, 라벨 일치도, 하위 집단 분포 |
| 평가 분리 | 오염·누출 여부, 독립 시험 집합 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 데이터 양만 늘리면 권리 문제·오염·집단 편향이 모델에 전파된다 | 출처·허락·계보를 기록하고 분할·하위 집단 품질을 점검해 갱신한다 |

## Ⅴ. 제언

- 평가 자료의 오염 방지와 이용 권한 확인을 먼저 확정한 뒤 학습 데이터의 양을 확장한다.
