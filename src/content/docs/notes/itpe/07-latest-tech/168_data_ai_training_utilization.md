## 연관 키워드

- AI 학습 데이터, 원천 데이터, 합성 데이터(Synthetic Data), 어노테이션(Annotation), 레이블링
- 데이터 품질(정확성·완전성·대표성·일관성), 중복 제거, PII(Personally Identifiable Information) 마스킹
- 모델 붕괴(Model Collapse), 데이터 오염(Data Contamination), TDM(Text and Data Mining), 데이터 계보

## Ⅰ. 데이터 (AI 학습·활용)의 개요

- 핵심 요약 : 원천 데이터를 정제·검증하고 권리와 개인정보 준수를 확인해 모델에 공급하는 전주기 데이터 공학 체계.
- 개념 : 머신러닝과 파운데이션 모델이 편향 없이 지식을 배울 수 있도록 텍스트, 이미지, 음성 같은 **원천 데이터** (Raw Data)를 수집·정제·가공·검증하고, 저작권과 개인정보 규정을 지키며 공급하는 데이터 공학 체계.
- 배경 및 필요성 : 모델이 다시 생성한 데이터로 학습을 반복하면 희귀 분포가 사라지는 **모델 붕괴** (Model Collapse)가 생기고, 평가용 데이터가 학습에 섞이는 오염도 발생한다. 그래서 고품질 인간 원천 데이터의 비율을 관리하고 오염을 탐지하는 파이프라인이 필요하다.
- 주요 목적 : "Garbage In, Garbage Out"을 막아 일반화 성능을 높이고, 환각을 줄이며, 데이터셋의 법적 위험을 미리 차단하고 재현성을 확보하는 것.

## Ⅱ. 데이터 (AI 학습·활용)의 특징 및 장점

- 핵심 요약 : 데이터 품질의 네 축을 공정 단계마다 점검해, 학습 실패를 줄이고 법적 위험을 사전에 막는 구조.

```text
[ 데이터 품질의 네 축 ]

정확성 : 사실과의 부합
완전성 : 결측과 메타데이터
대표성 : 집단·희귀 사례의 균형
일관성 : 주석 기준의 통일
```

1. 정확성 : 실제 사실과 부합하는 값만 남김 → 라벨 오류가 줄어 모델 정확도 저하를 막음.
2. 완전성 : 결측치를 줄이고 필수 메타데이터를 채움 → 모달리티 누락으로 인한 학습 실패 방지.
3. 대표성 : 집단, 방언, 희귀 사례를 균형 있게 포함 → 특정 집단에 대한 편향과 차별 감소.
4. 일관성 : 같은 대상에 같은 주석 기준을 적용 → 작업자 간 불일치로 인한 학습 불안정 방지.

## Ⅲ. 데이터 (AI 학습·활용)의 구조 (흐름)

- 핵심 요약 : 획득, 정제, 가공, 품질 감사, 계보 등록의 순차 흐름에 권리 확인 게이트가 앞단에서 걸리는 구조.

```text
[ 학습 데이터 공학 파이프라인 ]

원천 데이터 획득
        ↓ 저작권·로봇 배제 확인, PII 마스킹
대규모 정제와 필터링
        ↓
가공과 라벨링 (자동 + 전문가 검수)
        ↓
품질 감사와 벤치마크 오염 검사
        ↓
버전 관리와 계보 등록
```

- **중복 제거** (MinHash LSH) : 대규모 문서에서 유사한 문장과 문서를 군집으로 묶어 중복을 제거한다.
- **휴리스틱·안전성 필터** : 광고성 스팸과 비정상 반복 문자를 걸러내고, 혐오 표현 같은 유해 콘텐츠를 차단한다.
- **상호 일치도 검증** (Kappa) : 여러 작업자의 라벨이 얼마나 일치하는지 측정해 기준의 모호함을 찾는다.
- **계보 등록** : 데이터 해시, 변환 스크립트, 학습 모델 ID를 함께 기록해 결과를 역추적한다.

## Ⅳ. 원천 데이터, 인간 라벨링 데이터, 합성 데이터의 비교

- 핵심 요약 : 비용과 확장성은 합성 데이터가 앞서지만 품질 보증은 인간 라벨링이 맡는 구도라, 셋을 섞어 쓰는 설계가 필요.

| 비교 축 | 실세계 원천 데이터 | 인간 라벨링 데이터 | AI 생성 합성 데이터 |
| --- | --- | --- | --- |
| 구축 비용 | 낮음 (대량 수집) | 매우 높음 (인건비와 시간) | 낮음 (연산 자원 위주) |
| 데이터 품질 | 노이즈와 유해 표현 많음 | 맥락 판단이 반영되어 높음 | 구조는 좋으나 붕괴 위험 |
| 확장성 | 인터넷 텍스트 고갈 우려 | 인력 한계로 제한적 | 사실상 생성 확장 가능 |
| 주요 용도 | 사전학습 | 지도학습 미세조정, 선호 학습 | 희귀 사례 증강, 시뮬레이션 |
| 핵심 위험 | 저작권 분쟁, 개인정보 노출 | 라벨러 편차 | 분포 소실, 환각 증폭 |

- 선택 기준 : 사전학습 규모는 원천 데이터로, 정답 품질이 중요한 미세조정은 인간 라벨링으로, 희귀 사례 보강은 합성 데이터로 나눠 쓴다.

## Ⅴ. 데이터 (AI 학습·활용)의 한계와 방안

- 핵심 요약 : 합성 데이터 반복 학습, 평가셋 오염, 무단 수집에 따른 권리 침해를 혼합 비율 제한, 오염 대조, 권리 메타데이터로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 합성 데이터 반복 학습에 따른 모델 붕괴 | 희귀 분포 소실로 출력이 획일화 | 인간 원천 데이터를 앵커로 유지, 합성 데이터 혼합 비율 제한 | 합성 데이터 비율 |
| 평가 데이터의 학습 혼입 (**데이터 오염**, Data Contamination) | 벤치마크 점수가 실제 능력을 과대평가 | 인제스천 단계에서 평가셋과의 N-gram 대조, 평가셋 주기적 갱신 | 오염 탐지 건수 |
| 무단 크롤링에 따른 저작권 분쟁 | 권리자 동의 없는 수집으로 소송과 규제 위험 | 권리 확인 게이트, 옵트아웃 프로토콜 존중, 라이선스 메타데이터 관리 | 분쟁 건수, 격리 데이터 양 |

## Ⅵ. 데이터 (AI 학습·활용)에 대한 기술사적 제언

- 핵심 요약 : 데이터의 출처와 권리, 품질을 기록하는 계보 체계를 학습 파이프라인의 기본 설계로 삼는 방향.
- 기업은 원천 URL부터 모델 배포까지 이어지는 계보를 자동으로 남겨, 문제가 생겼을 때 해당 데이터를 신속히 격리할 수 있어야 한다.
- 법제도 측면에서는 AI 기본법과 텍스트·데이터 마이닝 관련 규정을 정비해, 수집 허용 범위와 권리자의 거부 수단을 명확히 해야 한다.
- 품질 검증은 모델 배포 뒤의 사후 점검이 아니라 수집 단계에서 작동해야 하며, 이를 조직의 데이터 거버넌스 정책으로 정착시켜야 한다.

## Ⅶ. 결론

- 핵심 요약 : AI 학습 데이터는 양보다 출처와 품질, 권리가 검증된 상태로 공급되는 것이 모델 신뢰의 전제임.
- 데이터 계보와 권리 관리가 갖춰질 때 모델의 성능 향상과 법적 안정성이 함께 확보된다.
