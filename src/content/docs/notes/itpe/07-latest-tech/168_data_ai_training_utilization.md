## 핵심 용어
- 데이터 중심 AI(Data-Centric AI): 앤드류 응(Andrew Ng) 교수가 주창한 패러다임으로, 모델 코드를 고정한 상태에서 데이터의 품질, 일관성, 라벨 정확도를 체계적으로 개선하여 AI 성능을 올리는 접근법
- 합성 데이터(Synthetic Data): 실제 현실 세계에서 수집한 데이터가 아니라, 물리 엔진 시뮬레이션이나 생성형 AI 모델을 통해 디지털 환경에서 인위적으로 생성해 낸 고품질 학습 데이터
- 모델 붕괴(Model Collapse): 차세대 AI 모델들이 인간이 작성한 원본 데이터가 아닌 AI가 생성한 합성 데이터만을 반복적으로 학습할 때, 정보의 꼬리(다양성)가 잘려나가고 생성물이 횡설수설 퇴화하는 현상

## 핵심 통찰
- "2026년 고품질 언어 데이터의 완전 고갈(Data Wall)": 인터넷에 존재하는 인간의 모든 책, 논문, 웹페이지가 LLM 학습에 거의 소진되었으며, 이제는 질 높은 데이터의 '발굴'과 '합성'이 경쟁력의 본질
- 양보다 질(Quality over Quantity): 마이크로소프트의 Phi 모델이 입증했듯, 정제되지 않은 웹 텍스트 1조 토큰보다 엄선된 초등 교과서급 양질의 데이터 1,000억 토큰이 훨씬 똑똑한 모델을 만듦
- 저작권과 공정이용(Fair Use)의 법적 충돌: 뉴욕타임스 소송 등 언론사와 창작자들의 저작권 방어에 맞서, TDM(텍스트·데이터 마이닝) 면책 규정 도입과 데이터 라이선스 계약이 글로벌 표준화됨

## 이웃 토픽과 구분
- 모델 중심 AI vs 데이터 중심 AI: 모델 중심은 "데이터는 고정하고 최신 트랜스포머 알고리즘을 튜닝하자" / 데이터 중심은 "알고리즘은 표준을 쓰고 오라벨링과 노이즈 데이터를 깎아내자"

## 문제·원인·대책
- 적용 상황: 금융 도메인 특화 초거대 언어 모델 사전학습을 위한 10TB 금융 데이터 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 웹 크롤링 데이터 내 고객 계좌번호 및 개인 주민등록번호 대량 포함 | 인터넷 블로그 및 서식 문서 내 민감정보 무단 노출 | 정규표현식 및 RoBERTa 기반 개체명(NER) 실시간 비식별화 마스킹 | 개인정보 노출 위험 제로화 달성 |
| 수집 데이터의 40%가 동일한 금융 상품 광고성 중복 문서로 성능 저하 | 동일 보도자료 및 홍보성 텍스트의 웹 복제 범람 | MinHash 및 국소 민감 해시(LSH) 기반 대규모 중복 문서 필터링 | 학습 토큰 35% 감축 및 훈련 효율화 |
| AI 생성 합성 데이터를 과도하게 학습시켜 모델이 특정 답변만 앵무새처럼 반복 | 인간 데이터 비율 감소로 인한 모델 붕괴(Model Collapse) 현상 | 인간 생성 원본 데이터 30% 의무 혼합 및 합성 데이터 다양성 필터링 | 다양성 지표(Entropy) 95% 유지 |

## 이렇게 출제된다
- 예상 문제: "생성형 AI 시대에 데이터가 모델 성능을 좌우하는 데이터 중심 AI(Data-Centric AI) 관점에서, AI 학습 데이터 생애주기, 데이터 고갈 문제의 대응 방안 및 데이터 저작권 쟁점을 설명하시오." → 요구 포인트: Ⅰ 패러다임 전환 배경 + Ⅱ 수집-정제-큐레이션 전주기 흐름 + Ⅳ 합성데이터 및 모델 붕괴 방지책

## 내 의견
- [사내 데이터 레저버(Data Reservoir) 구축과 데이터 오염 방지용 무결성 감사 파이프라인 도입] 사내 데이터를 LLM 학습에 무분별하게 투입하면 악의적인 직원의 프롬프트 인젝션이나 오염 데이터(Data Poisoning)가 모델에 영구 각인됨 → 나라면: 수집된 모든 사내 지식 문서에 대해 SHA-256 해시 기반의 변경 이력 추적 블록체인 레저를 연동하고, 임베딩 거리 기반 이상치 탐지기로 데이터 오염을 자동 격리하는 엔터프라이즈 데이터 거버넌스 게이트웨이 구축
