## Ⅰ. 데이터 (AI 학습·활용)의 개요

- 개념 : 머신러닝·초거대 파운데이션 모델이 편향 없이 지식을 학습할 수 있도록 **원천 비정형 데이터** (텍스트, 이미지, 음성)를 정제·가공·검증하고, 저작권 및 개인정보보호 컴플라이언스를 준수하여 공급하는 전주기 데이터 공학 체계.
- 배경 및 필요성 : **모델 붕괴** (Model Collapse)와 벤치마크 오염이 발생하므로 고품질 인간 검증 원천 데이터의 비율 통제와 **오염 탐지 파이프라인** 구축 필요.
- 핵심 목적 : "Garbage In, Garbage Out" 방지, 모델의 일반화 정확도 향상, 환각 감소, 데이터셋의 법적 리스크 사전 차단 및 재현성 확보.

## Ⅱ. 데이터 (AI 학습·활용)의 핵심 아키텍처 및 동작 메커니즘

데이터는 신뢰할 수 있는 데이터 파이프라인과 고도화된 추론 메커니즘을 기반으로 동작하며, 세부적인 아키텍처와 핵심 컴포넌트 간 상호작용 프로세스는 다음과 같음.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 고품질 AI 학습용 데이터 수집-정제-검증-계보 통합 엔지니어링 파이프라인 ]│
└────────────────────────────────────────────────────────────────────────┘

  [ 1. 원천 데이터 획득 (Ingestion & Copyright Gate) ]
   - 웹 크롤링 (Common Crawl), 공공 데이터셋, 기업 레거시 로그, 합성 데이터
                 │
                 ▼ (저작권/로봇 배제 표준 Robots.txt 검증 & PII 마스킹)
  [ 2. 대규모 정제 및 필터링 (Deduplication & Cleansing) ]
   ├── MinHash LSH: 대규모 중복 문서 및 유사 문장 클러스터링 제거
   ├── 휴리스틱 필터: 광고, 기계 번역 스팸, 특수문자 비정상 반복 제거
   └── 안전성 필터: 성인물, 폭력, 혐오 표현(Toxicity) 사전 차단
                 │
                 ▼
  [ 3. 데이터 가공 및 어노테이션 (Labeling & Augmentation) ]
   - Auto-labeling ──> 인간 전문가 검수(HITL) ──> 상호 일치도(Kappa) 검증
                 │
                 ▼
  [ 4. 데이터셋 품질 평가 및 벤치마크 오염 방지 (Quality Audit) ]
   - 훈련 데이터 vs 공인 벤치마크(MMLU, GSM8K) 13-gram 겹침 검사
                 │
                 ▼
  [ 5. 버전 관리 및 피처 스토어 카탈로그 (DVC & Feature Store) ]
   - <Datasheet, 데이터 해시, 변환 스크립트, 학습 모델 ID> 통합 계보 등록
```

- **정확성 (Accuracy)** : 실세계 사실(Ground Truth) 및 물리 법칙과의 부합성 - 라벨링 오류율이 증가하면 모델 정확도 저하.
- **완전성 (Completeness)** : **결측치** (Missing Value) 부재 및 필수 메타데이터 충족도 - 모달리티 누락 시 멀티모달 정렬 학습 수렴 실패.
- **대표성 (Diversity)** : 도메인 인구통계, 방언, 희귀 엣지 케이스 포함 균형도 - 특정 집단에 대한 알고리즘적 차별 및 편향성 유발.
- **일관성 (Consistency)** : 동일한 개체 및 상황에 대한 주석 기준의 통일성 - 다수 작업자 간 라벨 불일치 발생 시 손실 함수 진동 초래.

## Ⅲ. 데이터 (AI 학습·활용)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 실세계 원천 데이터 (Raw Data) | 인간 라벨링 데이터 (Human Annotated) | AI 생성 합성 데이터 (Synthetic Data) |
|---|---|---|---|
| **구축 비용** | 낮음 (대량 웹 스크래핑) | 매우 높음 (인건비 및 시간 소모) | 매우 낮음 (GPU 연산만 소모) |
| **데이터 품질** | 낮음 (노이즈, 광고, 비속어 다수) | 매우 높음 (인간의 맥락 판정 반영) | 구조화 우수하나 모델 붕괴 위험 |
| **확장성** | 인터넷 텍스트 고갈 위기 직면 | 인력 한계로 무한 확장 불가 | 사실상 무한대 생성 확장 가능 |
| **주요 용도** | 파운데이션 모델 사전학습(Pre-train) | 지도학습 미세조정(SFT), RLHF | 엣지 케이스 증강, 로봇 시뮬레이션 |
| **핵심 위험** | 저작권 침해 소송, 개인정보 노출 | 라벨러 주관 편차, 휴먼 에러 | 꼬리 분포 소실, 환각 증폭 전이 |

- 데이터는 상기 비교 지표를 바탕으로 비즈니스 요구사항과 운영 인프라 환경을 고려한 최적의 아키텍처를 선정하고, 확장성과 안정성을 균형 있게 확보해야 함.

## Ⅳ. 데이터 (AI 학습·활용)의 주요 한계점 및 해결 방안

- 합성 데이터 반복 재학습에 따른 모델 붕괴(Model Collapse) :
  - 한계점 : AI가 생성한 합성 데이터를 다음 세대 모델이 반복 학습할 때 희귀 데이터 분포가 사라지고 출력이 획일화되는 모델 붕괴(Model Collapse) 발생.
  - 해결 방안 : 고품질 인간 저작 원천 데이터(Human-generated Data)를 핵심 앵커로 유지하고 합성 데이터 혼합 비율을 엄격히 제한(예: 일정 비율 미만).
- 사전학습 코퍼스 내 벤치마크 평가 데이터셋 오염(Data Contamination) :
  - 한계점 : 사전학습 데이터에 공인 성능 평가 데이터셋(GSM8K, HumanEval 등)이 무단 혼입되어 모델의 실제 추론 능력이 왜곡되는 데이터 오염 발생.
  - 해결 방안 : 데이터 인제스천 단계에서 벤치마크 데이터와의 N-gram 및 임베딩 유사도 역대조 필터링 의무화 및 새로운 오프라인 평가셋 주기적 갱신.
- 웹 콘텐츠 무단 크롤링으로 인한 저작권 분쟁 및 법적 리스크 :
  - 한계점 : 저작권자의 명시적 동의 없는 웹 콘텐츠(뉴스, 도서, 블로그) 무단 크롤링으로 인한 저작권 침해 집단 소송 및 규제 리스크.
  - 해결 방안 : AI 기본법 및 공정 이용(Fair Use) 가이드라인 준수, TDM(텍스트·데이터 마이닝) 면책 규정 입법화 및 옵트아웃(Opt-out) 프로토콜 보장.

## Ⅴ. 데이터 (AI 학습·활용) 적용 및 발전을 위한 기술사적 제언

- 출처 추적 고도화 및 원천 URL부터 모델 추진 : 개발자 개인 기억 및 수기 문서 의존의 한계를 탈피하고, 원천 URL부터 모델 배포까지 자동 계보 추적을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 저작권 감사 고도화 및 라이선스 메타데이터를 통해 추진 : 법적 분쟁 발생 시 입증 곤란의 한계를 탈피하고, 라이선스 메타데이터를 통해 침해 데이터 즉시 격리를 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
- 품질 감사 향상 및 인라인 파이프라인에서 품질 도입 : 모델 배포 후 사후 결함 인지의 한계를 탈피하고, 인라인 파이프라인에서 품질 미달 데이터 자동 차단을 체계적으로 추진하여 실무 운영 효율성과 엔지니어링 신뢰성을 극대화해야 함.
