## 답안 골격
### 1교시 예상문제 (10점)
스마트 더스트의 모트 구성과 CCR 역반사 통신 방식을 설명하시오.

### 1교시 10점 답안
- **정의:** 센서·연산·통신·전원을 소형 노드에 결합해 환경을 분산 측정하려는 연구 개념.
- **구성:** MEMS 센서, 처리기, 광학 또는 RF 통신부, 전원·패키징.
- **CCR:** 기지국이 보낸 빛을 역반사 장치가 변조하여 데이터를 전달하는 방식. 가시선이 필요하며 노드의 센싱·처리 전력까지 없어지는 것은 아님.

### 2~4교시 예상문제 (25점)
산림 환경 모니터링에 스마트 더스트 개념을 적용할 때 통신·전력·환경 위험을 평가하시오.

### 2~4교시 25점 답안
1. **적용성:** 필요한 감지 항목, 배치 밀도, 기상 조건과 수명 목표를 정하고 기존 WSN과 비교.
2. **구조:** 소형 센서 노드의 주기적 측정 → 로컬 처리·절전 → 광학 역반사 또는 RF 링크 → 수집 기지국·분석.
3. **제약:** 빛·배터리 공급, 산림 장애물·안개에 따른 링크 손실, 무작위 살포 시 위치·회수와 생태 영향.
4. **검증:** 배치 조건별 수신율·전력 소비·오탐·환경 잔류량을 현장 시험하고 회수·폐기 계획 수립.

## 핵심 용어
- 모트(Mote): 센서·연산·통신·전원 기능을 결합한 소형 노드. 단일 칩·1~2mm³ 크기는 일반적 정의가 아닌 일부 연구 목표
- CCR(Corner Cube Retroreflector): 입사된 빛을 정확히 들어온 방향으로 되돌려 보내는 3면 직각 거울로, MEMS 거울의 미세 진동으로 빛을 깜빡이게 변조하여 자체 송신 전력 없이 데이터를 전송하는 광학 통신 소자
- 에너지 하베스팅(Energy Harvesting): 주변 환경에 버려지는 빛(태양광), 열(열전 효과), 진동(압전 효과), 전자기파 등을 흡수하여 마이크로와트(μW) 단위의 전기를 자체 생산하는 기술

## 핵심 통찰
- 광학 역반사 통신: 기지국의 광원을 변조 반사하면 RF 송신 대비 노드 전력을 줄일 수 있으나 센싱·처리·변조에 전력 필요. 배터리·태양광 등 전원 설계 별도
- 배치와 네트워크: 살포 후 위치·방향·가시선·전원에 따라 연결성이 달라짐. 역반사형 광학 통신은 기지국과의 가시선이 중요하며 자동 메시 형성을 전제할 수 없음
- 군사 정찰에서 환경 재난 방재로: 적진의 탱크 이동 진동을 감지하던 군사용 스마트 더스트가, 대규모 산불 조기 경보, 원전문 위험 누출 감시, 스마트 농업의 토양 영양분 모니터링으로 확장

## 이웃 토픽과 구분
- RFID와 스마트 더스트: 센서 기능이 있는 RFID도 존재. 스마트 더스트는 초소형 분산 센싱의 연구 방향이며 모든 모트가 노드 간 릴레이를 지원하는 것은 아님
