## 30초 인출

- 본질: 센서·연산·통신·전원을 소형 노드에 결합해 환경을 분산 측정하려는 연구 개념. 광범위하거나 접근이 어려운 공간의 측정 범위를 넓힘.
- 메커니즘: 센싱 → 현장 처리·절전 → 광학·RF 전송 → 기지국 수집.
- 통찰: 한계: 초소형 노드가 넓게 퍼지면 전원·링크·회수 조건을 동시에 만족하기 어렵다 → 방안: 기상·밀도별 수신율과 수명을 시험하고 회수·폐기 계획을 배치 전에 정한다.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 센서·연산·통신·전원을 소형 노드에 결합해 환경을 분산 측정하려는 연구 개념. |
| 목적 | 광범위하거나 접근이 어려운 공간의 측정 범위를 넓힘 |

## Ⅱ. 분산 센싱과 수집 경로

```text
센서 모트: 측정 → 로컬 처리·절전
                        ↓ 광학 역반사 또는 RF
                  수집 기지국·분석
                        ↑ 전원·가시선·회수 조건 검증
```

1. **적용성:** 필요한 감지 항목, 배치 밀도, 기상 조건과 수명 목표를 정하고 기존 WSN과 비교.
2. **구조:** 소형 센서 노드의 주기적 측정 → 로컬 처리·절전 → 광학 역반사 또는 RF 링크 → 수집 기지국·분석.
3. **제약:** 빛·배터리 공급, 산림 장애물·안개에 따른 링크 손실, 무작위 살포 시 위치·회수와 생태 영향.
4. **검증:** 배치 조건별 수신율·전력 소비·오탐·환경 잔류량을 현장 시험하고 회수·폐기 계획 수립.

## Ⅲ. RFID와 스마트 더스트

| 구분 | RFID | 스마트 더스트 |
|---|---|---|
| 중심 역할 | 식별·응답, 일부 센싱 | 분산 환경 측정 노드 연구 |
| 검증 | 리더 거리·태그 전력 | 수명·링크·배치·회수 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 소형 노드 조기 방전 — 센싱·연산·통신 전력 예산 부족 | 듀티 사이클·수확 전력·전원 용량 실측 |
| 대량 배치 후 환경 잔류 — 소재와 회수 계획 부재 | 배치량 최소화, 회수 가능 설계, 생태·독성 평가 |
| 안개·연기에 광학 링크 불안정 — 광학 가시선·산란 제약 | 배치·중계점 조정, 필요 시 RF 대체 통신 검토 |

## Ⅴ. 제언

- [적용 가능성 평가] 의료 체내 센싱은 생체 적합성·이동 경로·회수 또는 분해·독성·규제 검증이 선행되어야 하는 별도 연구 분야. 환경 감시 적용 시 설치·유지·회수의 실증 우선
