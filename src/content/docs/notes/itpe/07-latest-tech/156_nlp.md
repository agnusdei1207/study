## 핵심 용어
- NLU(Natural Language Understanding): 입력된 자연어의 형태소, 구문, 의미를 분석하여 화자의 의도(Intent)와 핵심 개체명(Entity)을 정형 데이터로 추출하는 언어 이해 기술
- NLG(Natural Language Generation): 데이터베이스나 시스템 내부의 정형화된 지식 데이터를 바탕으로 문법과 문맥에 맞는 자연스러운 인간의 문장을 생성하는 언어 생성 기술
- 셀프 어텐션(Self-Attention): 문장 내의 모든 단어가 서로에게 얼마나 집중(Attention)해야 하는지를 Query, Key, Value 내적으로 계산하여 단어 간의 장거리 문맥 의존성을 한 번에 파악하는 기술

## 핵심 통찰
- "문맥 없는 단어(Word2Vec)에서 문맥 기반 동음이의어(Transformer)로": 과거에는 '사과(과일)'와 '사과(용서)'가 동일한 벡터였으나, 트랜스포머의 어텐션을 통해 문장 전체 맥락에 따라 벡터가 동적으로 결정됨
- 순차 처리(RNN)의 병목 파괴: 문장을 한 단어씩 순서대로 읽던 RNN을 버리고, 전체 문장을 병렬로 한꺼번에 처리하는 트랜스포머의 등장으로 GPU 대규모 분산 학습이 가능해짐
- 태스크 특화 모델에서 범용 기초 모델(Foundation Model)로: 번역기, 요약기, 챗봇을 따로 만들던 시대에서, 하나의 거대 모델에 프롬프트만 주면 모든 언어 작업을 해내는 LLM 시대로 통합

## 이웃 토픽과 구분
- NLU vs NLG: NLU는 '비정형 텍스트 → 정형화된 의도/데이터'로 변환하는 분석적 과정 / NLG는 '정형화된 데이터/맥락 → 비정형 텍스트 문장'으로 번역하는 표현적 과정

## 문제·원인·대책
- 적용 상황: 금융사 고객 상담 챗봇 시스템 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 미등록 전문 금융 신조어나 오타 입력 시 OOV(Out of Vocabulary) 인식 불가 | 고정 단어 사전 기반 공백 토큰화 한계 | 서브워드 분절 알고리즘(BPE, WordPiece) 적용 | 신조어 및 오타 처리율 98% 달성 |
| 긴 금융 약관 문서 질문 시 문맥을 잊어버리고 엉뚱한 조항 인용 | 기존 RNN/LSTM의 고질적 장기 의존성(Long-term dependency) 소실 | 트랜스포머 긴 문맥 윈도우(FlashAttention, RoPE) 적용 | 32k 이상 장문 문서 문맥 완벽 유지 |
| 챗봇이 없는 대출 상품을 지어내어 확정적으로 안내하는 환각(Hallucination) | LLM의 통계적 다음 단어 확률 생성 메커니즘 한계 | 검색 증강 생성(RAG) 아키텍처 및 출처 메타데이터 검증 도입 | 오정보 제공 사고 0건 달성 |
