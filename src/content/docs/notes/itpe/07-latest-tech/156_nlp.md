## 지식 로드맵 내 현재 위치

인공지능 → 언어 자료 → 자연어 처리

## 30초 인출

- **본질:** 텍스트·음성의 분석·이해·생성을 다루는 기술 영역; NLU는 의미 해석, NLG는 문장 생성
- **메커니즘:** 언어 자료의 토큰화·표현 학습 → 의미 분석 또는 문장 생성 → 결과 검증
- 통찰: 한계: 생성 문장의 유창함이 근거 일치·개인정보 안전을 보장하지 않음 → 방안: 과제별 근거 검증과 민감정보 노출·편향 평가
- **답안 초점:** 자연어 처리에서 NLU와 NLG의 역할을 설명하시오.

<details><summary>핵심 용어</summary>

- **NLU:** 언어 입력의 의미·의도·개체·관계 해석
- **NLG:** 조건과 문맥에 맞는 언어 출력 생성

</details>

## 2~4교시 25점 답안

## Ⅰ. 자연어 처리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 인간 언어의 분석·이해·생성을 다루는 기술 영역 |
| 목적 | 언어 자료의 의미 추출과 과제에 맞는 언어 출력 생성 |

## Ⅱ. 언어 표현에서 이해·생성으로 이어지는 처리 구조

```text
텍스트·음성 → 토큰화·언어 표현
                      ├─ NLU: 의도·개체·관계 해석 ─┐
                      └─ NLG: 조건·문맥 기반 생성 ─┤
                                                    ▼
                                            과제 결과·근거 검증
```

## Ⅲ. 발전 방식과 주요 기능

| 방식 | 표현·처리 특성 | 주요 적용 |
|---|---|---|
| 규칙·통계 | 규칙·빈도·확률 모형 | 형태·구문 분석, 분류 |
| 분산 표현·RNN/LSTM | 문맥을 순차적으로 반영 | 번역·시퀀스 처리 |
| 트랜스포머·사전학습 | 자기 주의와 대규모 학습 | 이해·생성 과제 |

## Ⅳ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 유창한 생성 결과에 근거 없는 내용 포함 가능 | 원문 근거 일치·사실성 평가와 사람 검토 |
| 학습·입력 자료에서 편향 또는 개인정보 노출 | 민감정보 처리 기준과 과제별 편향 시험 |

## Ⅴ. 제언

적용 과제의 정확도와 근거 확인 기준을 먼저 정하고 이해·생성 결과를 별도로 평가.
