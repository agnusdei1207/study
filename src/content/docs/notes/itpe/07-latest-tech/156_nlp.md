## 2~4교시 25점 답안

| 구분 | 핵심 |
|---|---|
| 정의 | 인간 언어의 분석·이해·생성을 다루는 기술 영역 |
| 목적 | 언어 자료의 의미 추출과 적절한 출력 생성 |

### Ⅰ. 개념
- 언어 자료를 기계가 처리 가능한 표현으로 바꾸어 분류·추출·번역·요약·생성을 수행.

### Ⅱ. 발전 흐름

- 규칙·통계 모델 → 분산 표현과 RNN/LSTM → 자기 주의 기반 트랜스포머 및 대규모 사전학습.

### Ⅲ. 기능

- NLU는 의도·개체·관계 추출, NLG는 문맥에 따른 출력 생성. 실제 응용은 두 기능을 연계.

### Ⅳ. 검증

- 태스크별 정확도·근거 일치·편향·개인정보 노출·응답 지연 평가. 긴 문맥 제공만으로 문서 이해를 보장하지 않음.
