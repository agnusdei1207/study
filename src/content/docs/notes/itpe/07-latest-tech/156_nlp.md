## 연관 키워드

- 자연어 처리(NLP, Natural Language Processing), 자연어 이해(NLU), 자연어 생성(NLG)
- 토큰화(Tokenization), 임베딩(Embedding), 트랜스포머(Transformer), 어텐션(Attention)
- 대규모 언어 모델(LLM), 환각(Hallucination), 검색 증강 생성(RAG), 지식 그래프(Knowledge Graph)
- DPO(Direct Preference Optimization), 개인식별정보(PII), 인컨텍스트 학습(In-Context Learning)

## Ⅰ. 자연어 처리(Natural Language Processing)의 개요

- 핵심 요약 : 사람의 언어를 벡터 공간으로 옮겨 의미를 이해하고 문장을 생성하는 인공지능 기술이며, 환각 억제가 실용화의 관건.
- 개념 : 텍스트와 음성 같은 인간의 언어 표현을 컴퓨터가 계산할 수 있는 수치 벡터로 바꾸어, **자연어 이해** (NLU, Natural Language Understanding)와 **자연어 생성** (NLG, Natural Language Generation)을 수행하는 기술. 이를 흔히 **자연어 처리** (NLP, Natural Language Processing)라 부른다.
- 배경 및 필요성 : **대규모 언어 모델** (LLM, Large Language Model)이 사실이 아닌 내용을 그럴듯하게 출력하는 **환각** (Hallucination)이 상용화의 가장 큰 장애물이므로, 외부 문서를 근거로 답하게 하는 **검색 증강 생성** (RAG, Retrieval-Augmented Generation)과 지식 그래프 결합이 필요해짐.
- 주요 목적 : 사람과 컴퓨터 사이의 자연스러운 상호작용 지원, 비정형 텍스트에서 지식을 자동 추출, 번역·요약·대화 에이전트 구현.

## Ⅱ. 자연어 처리(Natural Language Processing)의 특징 및 장점

- 핵심 요약 : 문장을 토큰과 벡터로 다루는 방식이 문맥 이해력과 범용성으로 이어져, 과제별 규칙 작성을 줄이는 특징.

1. 문맥 표현 학습 : 토큰마다 주변 단어와의 관계를 **어텐션** (Attention)으로 계산 → 같은 단어도 문맥에 따라 다른 의미로 해석.
2. 사전학습과 전이 : 대량 말뭉치로 **사전학습** (Pre-training)한 뒤 과제별로 미세조정 → 과제마다 데이터를 새로 만드는 부담 감소.
3. 인컨텍스트 학습 : 모델 가중치를 바꾸지 않고 프롬프트 안의 예시만으로 과제를 수행 → 새 업무 적용 주기 단축.

- 토큰이 벡터로 바뀌어 처리되는 흐름은 다음과 같다.

```text
[ 원문 문장 ]
      ↓
[ 토큰화 (서브워드 분절) ]
      ↓
[ 임베딩 벡터 + 위치 정보 ]
      ↓
[ 어텐션으로 문맥 관계 계산 ]
      ↓
[ 의미 해석 또는 다음 토큰 생성 ]
```

## Ⅲ. 자연어 처리(Natural Language Processing)의 구조 (흐름)

- 핵심 요약 : 토큰화와 임베딩을 거친 공통 트랜스포머 백본 위에서 이해 과제는 인코더, 생성 과제는 디코더가 담당하는 구조.
- 구성 요소 : 서브워드 분절은 **BPE**(Byte-Pair Encoding)와 WordPiece가 대표적이고, 위치 정보는 **RoPE**(Rotary Position Embedding)로 부여한다. 백본은 멀티헤드 셀프 어텐션, 층 정규화와 잔차 연결, 피드포워드 네트워크로 구성된다.

```text
[ 1. 토큰화 + 임베딩 ]
        ↓
[ 2. 트랜스포머 백본 ]
  셀프 어텐션 → 정규화·잔차
        ↓
  과제에 따라 분기
  (분기 1) NLU: 인코더 → 의도 분류, 개체명 인식
  (분기 2) NLG: 디코더 → 다음 토큰 확률, 요약
```

- 이해 과제의 대표 태스크는 의도 분류, 개체명 인식(NER, Named Entity Recognition), 기계 독해이고, 생성 과제는 번역, 요약, 대화 생성이다.

## Ⅳ. 자연어 처리(Natural Language Processing)의 비교

- 핵심 요약 : 규칙 기반에서 통계, 신경망 임베딩, 초거대 모델로 넘어오며 문맥 처리 능력은 커졌지만 계산 비용과 사실성 검증 부담이 함께 커짐.
- 세대 흐름 : 규칙 기반 방식, 통계 모델(N-gram, TF-IDF(Term Frequency-Inverse Document Frequency), HMM(Hidden Markov Model)), 신경망 임베딩(Word2Vec, LSTM(Long Short-Term Memory)), 트랜스포머 기반 초거대 모델 순으로 발전했다.

| 비교 축 | 자연어 이해 (NLU) | 자연어 생성 (NLG) |
| --- | --- | --- |
| 기능 목적 | 텍스트에서 의미, 감성, 의도 추출 | 의미를 유창하고 문법에 맞는 문장으로 표현 |
| 입출력 | 비정형 텍스트 → 라벨·구조화 데이터 | 프롬프트·정형 데이터 → 텍스트 |
| 대표 구조 | 양방향 인코더 (BERT(Bidirectional Encoder Representations from Transformers), RoBERTa) | 자기회귀 디코더 (GPT(Generative Pre-trained Transformer) 계열, LLaMA) |
| 평가 지표 | 정확도, F1 점수, 정확 일치율(EM, Exact Match) | BLEU, ROUGE, 혼잡도(Perplexity) |
| 주요 난제 | 중의성, 은유, 다의어 해소 | 문맥 일관성, 사실성 확보, 환각 억제 |

- 선택 기준 : 결과가 정해진 라벨이면 인코더 기반 이해 모델이, 자유 형식 문장이면 디코더 기반 생성 모델이 유리하다.

## Ⅴ. 자연어 처리(Natural Language Processing)의 한계와 방안

- 핵심 요약 : 환각, 편향과 개인정보 노출, 긴 입력의 계산 비용을 근거 기반 생성, 안전 정렬, 효율적 어텐션으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 환각 (Hallucination) | 확률적으로 그럴듯한 허위 문장 생성 → 잘못된 업무 판단 | RAG로 검증된 사내 문서를 근거로 답하게 하고 출처를 함께 표시 | 근거 인용률, 사실 오류율 |
| 편향과 개인식별정보 노출 | 웹 코퍼스의 혐오 표현과 편향, 개인식별정보(PII, Personally Identifiable Information)의 학습·재출력 | 학습 데이터 정제와 개인정보 탐지, 입출력 가드레일, DPO 기반 안전성 정렬 | 개인정보 탐지 건수, 편향 평가 점수 |
| 긴 문서 처리 비용 | 셀프 어텐션의 계산량이 입력 길이의 제곱에 비례 → 지연과 메모리 부담 | FlashAttention 같은 메모리 효율 구현, 상태 공간 모델(Mamba) 등 대안 구조 검토 | 처리 지연 시간, 메모리 사용량 |

- 대응 방안 설명 : **DPO** (Direct Preference Optimization, 사람의 선호 데이터로 응답을 직접 정렬하는 기법)는 안전하지 않은 응답을 낮추는 데 쓰이며, 가드레일은 학습이 아닌 입출력 단계의 차단 규칙이다.

## Ⅵ. 자연어 처리(Natural Language Processing)에 대한 기술사적 제언

- 핵심 요약 : 사내 근거 데이터 연계, 보안 격리 환경, 비용에 맞춘 모델 규모 선택을 기준으로 실무 도입 체계를 세우는 것이 필요함.

1. 근거 기반 응답 체계 : 모델이 기억한 지식보다 사내에서 검증된 최신 문서를 우선 참조하도록 설계하고, 답변마다 출처를 붙여 사용자가 검증할 수 있게 해야 한다.
2. 데이터 보안 경계 설정 : 기밀 문서가 외부 서비스로 나가지 않도록 전용 클라우드 망이나 온프레미스 환경을 먼저 정하고, 모델 접근 권한을 업무 권한과 연동해야 한다.
3. 모델 규모의 업무별 선택 : 분류·추출처럼 범위가 좁은 과제는 경량 모델로 충분한지 먼저 검증하고, 대형 모델은 추론이 필요한 과제에만 제한적으로 쓰는 것이 운영 비용 측면에서 합리적이다.

## Ⅶ. 결론

- 핵심 요약 : 자연어 처리는 언어를 벡터로 다루는 기술이며, 실용성은 환각을 근거와 정렬로 통제하는 데서 결정됨.
- 시사점 : 생성 능력보다 사실성과 보안을 검증 가능한 구조로 설계하는 조직이 자연어 처리 기술을 업무 성과로 연결할 수 있다.
