- 본질: **핀테크(Financial Technology, FinTech)** 는 정보기술을 활용해 금융 서비스의 제공·이용 방식을 바꾸는 분야
- 메커니즘: 이용자 요청·동의 → 인증·권한 확인 → 금융 데이터·기능 연계 → 금융서비스 제공·감사

<details>
<summary>핵심 용어</summary>

- **핀테크(Financial Technology, FinTech)** : 정보기술을 금융 서비스의 제공·이용·운영에 적용하는 분야
- **오픈뱅킹(Open Banking)** : 이용자 동의와 API 연계를 기반으로 금융 서비스·기관 간 기능을 연결하는 방식
- **금융 마이데이터(Financial MyData)** : 정보주체의 동의·요청에 따라 금융 정보를 전송·통합해 조회·관리하는 서비스 체계
- **응용 프로그램 인터페이스(Application Programming Interface, API)** : 시스템 간 기능·데이터 요청과 응답을 주고받는 접점
- **임베디드 금융(Embedded Finance)** : 비금융 서비스 흐름 안에서 금융 기능을 제공하는 방식
</details>
