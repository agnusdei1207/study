## 지식 로드맵 내 현재 위치

지식 위치: AI 인프라 → 분산 연산·고속 연결 → **AI 슈퍼컴퓨팅 플랫폼**

## 30초 인출

- 본질: **AI 슈퍼컴퓨팅 플랫폼**은 대규모 AI 학습·추론에 필요한 연산·통신·저장 자원을 통합한 기반
- 메커니즘: 자료 공급 ↔ 가속기 계산·동기화 → 모델·결과 저장

<details>
<summary>핵심 용어</summary>

- **인공지능(Artificial Intelligence, AI)** : 자료를 바탕으로 인식·예측·생성 등 지능 과제를 수행하는 기술 계열
- **중앙처리장치(Central Processing Unit, CPU)** : 범용 프로그램·작업을 처리하는 프로세서
- **그래픽처리장치(Graphics Processing Unit, GPU)** : 대규모 병렬 계산을 지원하는 프로세서
- **스케일업(Scale-up)** : 한 서버·랙 안에서 가속기 연결과 자원을 확장하는 방식
- **스케일아웃(Scale-out)** : 네트워크로 여러 서버를 연결해 처리 자원을 확장하는 방식
- **집합 통신(All-reduce)** : 분산 작업자의 값을 결합하고 결과를 각 작업자에 전달하는 통신 연산
- **체크포인트(Checkpoint)** : 장애 이후 작업 복구를 위해 학습 상태를 저장한 시점 자료

</details>

## 2~4교시 25점 답안

### Ⅰ. AI 슈퍼컴퓨팅 플랫폼의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **AI 슈퍼컴퓨팅 플랫폼**은 대규모 AI 학습·추론에 필요한 연산·통신·저장 자원을 통합한 기반 |
| 목적 | 단일 장비의 연산·메모리 한계를 넘어 대규모 모델 작업 지원 |

### Ⅱ. 플랫폼 구성

```text
데이터·모델 ── 병렬 저장장치가 연산 노드에 공급
                         │
                  가속기 연산 노드
                    ├─ 서버·랙 내 연결
                    └─ 서버 간 네트워크
                         │ 분산 계산·동기화
                         ▼
                 모델 갱신·결과 생성
                         │
               체크포인트·결과 저장
```

| 구성 | 역할 |
|---|---|
| CPU·가속기 | 제어·전처리와 병렬 모델 연산 |
| 스케일업 연결 | 서버·랙 내부 가속기 간 통신 |
| 스케일아웃 네트워크 | 여러 서버의 분산 작업 통신 |
| 병렬 저장 | 입력 자료 공급과 체크포인트·결과 보존 |
| 작업 관리·관측 | 자원 배정·성능 확인·장애 대응 |

### Ⅲ. 분산 학습의 계산·통신

```text
자료 분할
   │ 각 작업자가 일부 자료 처리
순전파·역전파
   │ 집합 통신으로 필요한 기울기·상태 결합
매개변수 갱신
   │ 다음 계산에 반영
주기적 체크포인트
```

```text
확장 범위      중심 통신
스케일업   ──  서버·랙 내부 가속기 연결
스케일아웃 ──  서버 간 분산 작업 연결
```

병렬화 방식에 따라 동기화할 값과 빈도가 달라지므로, 구성별 실제 통신 부하를 측정.

### Ⅳ. 설계·운영 기준과 기술사적 제언

| 한계·위험 | 해결 방안 |
|---|---|
| 가속기 수량만으로 학습 작업의 처리시간·확장 효율을 판단하기 어려움 | 대표 모델·자료 규모로 성능 시험을 하고 연산 대기·통신·저장 병목을 분리 측정 |
| 고밀도 배치가 전력·열·장애 복구 한계를 넘을 수 있음 | 시설 한도·냉각·체크포인트·작업 재시작 조건을 함께 검증 |
