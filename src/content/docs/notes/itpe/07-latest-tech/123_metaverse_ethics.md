## Ⅲ. 지향가치
| 가치 | 뜻 |
|---|---|
| 온전한 자아 | 개인의 창의성과 정체성 표현을 존중 |
| 안전한 경험 | 침해·위험으로부터 참여자를 보호하고 안전한 이용 환경 조성 |
| 지속가능한 번영 | 생태계 구성원이 함께 성장하고 혜택을 나누는 방향 |

## Ⅳ. 실천원칙과 고려 영역
| 원칙 | 고려 영역 |
|---|---|
| 진정성·자율성·호혜성 | 정체성 표현, 선택권, 상호 존중 |
| 사생활 존중·개인정보 보호 | 아바타·공간 데이터와 개인 정보의 적절한 처리 |
| 공정성·포용성 | 차별·배제 완화와 다양한 이용자 접근성 |
| 책임성 | 역할별 책임, 신고·대응, 개선 절차 |

| 참여자 | 적용 방향 |
|---|---|

| 운영자 | 신고·차단·분쟁 대응 절차와 투명한 이용 기준 마련 |
| 이용자·창작자 | 타인의 권리·창작물·공간을 존중하고 책임 있는 활동 |
| 공공·지원 주체 | 교육·협력·현장 적용을 돕고 변화에 맞춰 기준을 검토 |


실천윤리는 서비스 특성과 이용자에 맞춰 적용하며, 법령상 의무가 있는 개인정보·청소년 보호 등은 해당 법률·기준을 별도로 준수.
