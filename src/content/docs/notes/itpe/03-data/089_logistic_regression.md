## Ⅰ. 로지스틱 회귀의 개요

- 핵심 요약 : 로지스틱 회귀는 선형 결합을 로짓에 적용해 이진 결과의 조건부 확률을 추정하는 일반화선형모형.
- 개념 : 로지스틱 회귀는 선형 결합을 로짓에 적용해 이진 결과의 조건부 확률을 추정하는 일반화선형모형.
- 배경 및 필요성 : 0/1 결과의 확률·위험요인을 연속 선형회귀로 모델링하면 예측값 범위·오차분포가 부적합.
- 주요 목적 : 설명 가능한 확률분류와 변수효과 추정.

## Ⅱ. 로지스틱 회귀의 특징 및 장점

- 핵심 요약 : Logit 링크: log(p/(1−p))=β₀+βX → 확률을 0~1로 제한; 최대우도 추정: 베르누이 결과 적합도 최대화 → 계수 추정; 오즈비: exp(β) → 다른 변수 고정 시 단위 변화의 오즈비 해석.
