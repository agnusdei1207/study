## 연관 키워드

- 로지스틱 회귀, Logistic Regression, 시그모이드, 승산비, 로짓, 교차 엔트로피, 경사하강법, VIF, SMOTE

## Ⅰ. 로지스틱 회귀의 개요

- 핵심 요약 : 선형 결합을 확률로 변환해 이진 분류를 수행하는 통계·머신러닝 알고리즘.
- 개념 : 독립변수의 선형 결합을 확률로 바꿔 사건의 발생 여부를 추정하는 모델(**로지스틱 회귀**, Logistic Regression).
- 배경 및 필요성 : 선형 회귀의 출력은 무한대로 발산해 확률로 해석할 수 없으므로, **시그모이드**(Sigmoid, 실수 전체를 (0,1) 범위로 압축하는 S자형 함수)가 필요해짐.
- 주요 목적 : 독립변수로부터 사건 발생 확률을 추정하고, 임계값으로 이진 판정을 내리는 것.

## Ⅱ. 로지스틱 회귀의 특징 및 장점

- 핵심 요약 : 확률 출력, 설명 가능한 계수, 볼록 손실이 맞물려 해석이 쉽고 안정적으로 학습되는 분류 모델.

1. 확률 출력 : (0,1) 범위의 확률로 신뢰도를 표현 → 임계값 기반 의사결정이 가능.
2. **승산비** (Odds Ratio, 성공 승산의 비율로 계수를 지수화한 값) : 계수를 지수화해 변수 영향력을 정량 설명 → 해석 가능한 근거 제공.
3. 볼록 손실 : **교차 엔트로피** (Cross-Entropy, 예측 확률과 실제 레이블의 차이를 재는 손실) 는 볼록 함수 → 국소 최적점 없이 안정적으로 수렴.
4. 효율적 학습 : **경사하강법** (Gradient Descent, 손실의 기울기 반대 방향으로 가중치를 갱신하는 최적화) → 대규모 데이터에도 반복 학습 가능.
5. 규제 호환 : L1·L2 규제 → 과적합 억제와 피처 선택.

## Ⅲ. 로지스틱 회귀의 수학적 메커니즘 및 학습 흐름

- 핵심 요약 : 승산, 로짓, 시그모이드로 이어지는 3단 변환과 교차 엔트로피 기반 학습.
- **로짓** (Logit, 승산에 자연로그를 취한 값) : 선형 결합 w^T x + b와 같은 값이 되도록 정의된 변환.

```text
[ 로지스틱 회귀의 변환 흐름 ]

승산 (Odds) : P / (1 - P)
        ↓ (자연로그)
로짓 (Logit) : w^T x + b
        ↓ (역변환)
시그모이드 : P = 1 / (1 + e^(-z))
```

$$\sigma(z) = \frac{1}{1 + e^{-z}} \quad (z = w^T x + b)$$

- 교차 엔트로피 손실 : $-\frac{1}{n}\sum [y_i\ln(\hat y_i)+(1-y_i)\ln(1-\hat y_i)]$, 볼록 함수이므로 안정적으로 최적화됨.
- 승산비 : $e^{w_j}$, 독립변수가 1단위 증가할 때 성공 승산이 변하는 배율.

```text
[ 학습 루프 ]

예측 확률 계산 (시그모이드)
        ↓
교차 엔트로피 손실 계산
        ↓
기울기 계산 후 가중치 갱신
        ↓
손실이 수렴하면 학습 종료
```

## Ⅳ. 로지스틱 회귀의 모델·기법 비교

- 핵심 요약 : 선형 회귀와의 출력·손실 차이, 규제 유형, 클래스 불균형 대응을 기준으로 비교.
- 규제 : L1(Lasso, 피처 선택), L2(Ridge, 가중치 수축), Elastic Net(두 규제의 혼합).
- **SMOTE** (Synthetic Minority Over-sampling Technique, 소수 클래스의 합성 표본을 만드는 오버샘플링 기법) : 클래스 불균형 완화에 쓰이며, 비용 민감 학습과 임계값 조정이 함께 쓰임.

| 항목 | 로지스틱 회귀 | 선형 회귀 |
| --- | --- | --- |
| 출력 형태 | 확률 (0,1) | 실수 (-∞, ∞) |
| 손실 함수 | 교차 엔트로피 (볼록) | MSE (Mean Squared Error, 평균 제곱 오차) |
| 해석력 | 승산비 | 계수 직접 해석 |
| 규제 | L1/L2 적용 | L1/L2 적용 |
| 불균형 대응 | 임계값 조정·SMOTE·비용 민감 학습 | 같은 기법 공통 적용 |

## Ⅴ. 로지스틱 회귀의 한계와 방안

- 핵심 요약 : 비선형성, 다중공선성, 클래스 불균형을 규제·피처 공학·샘플링으로 대응.
- **VIF** (Variance Inflation Factor, 분산팽창계수) : 변수 간 상관으로 계수의 분산이 얼마나 부풀었는지 나타내는 지표.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 비선형 관계 미학습 | 선형 결정 경계 가정 → XOR 같은 복합 패턴 분류 불가 | 다항 피처, 커널 기법, 트리 앙상블 결합 | 정확도, AUC(Area Under the Curve) |
| 다중공선성 | 변수 간 강한 상관 → 계수 분산 급증, 해석 불가 | VIF 10 이상 변수 제거, L1/L2 규제 | VIF, 계수 안정성 |
| 클래스 불균형 | 희귀 클래스 편향 → 재현율 급락 | SMOTE, 비용 민감 학습, 임계값 조정 | Recall, F1, PR-AUC(Precision-Recall AUC) |

## Ⅵ. 로지스틱 회귀에 대한 기술사적 제언

- 핵심 요약 : 규제, 임계값, 설명력을 업무 목적에 맞춰 함께 설계하는 운영 원칙.

1. 고차원 희소 데이터를 다루는 모델에서는 L1 또는 L2 규제를 기본으로 켜 두어 가중치가 과도하게 커지는 현상을 막을 필요가 있다.
2. 임계값을 0.5로 고정하지 않고, ROC(Receiver Operating Characteristic) 곡선과 PR 곡선을 업무별 오류 비용 기준으로 비교해 정하는 것이 바람직하다. 암 진단이나 사기 탐지처럼 두 종류 오류의 비용이 다른 업무에서 특히 중요하다.
3. 신용평가와 의료 예측처럼 설명 책임이 큰 영역에서는 승산비를 변수별로 제시해 판단 근거를 설명할 수 있어야 한다.

## Ⅶ. 결론

- 핵심 요약 : 로지스틱 회귀는 확률 기반 이진 분류의 기본 모델로, 해석력과 규제 호환성이 강점임.
- 시사점 : 시그모이드 변환, 교차 엔트로피 학습, 승산비 해석, 임계값 조정을 함께 설계해야 실무에서 신뢰할 수 있음.
