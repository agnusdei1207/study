## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **로지스틱 회귀분석**

## 30초 인출

- 본질: 로지스틱 회귀는 입력 변수와 사건 발생 확률의 관계를 로짓(로그 오즈) 함수로 모형화하는 통계적 분류 모델
- 메커니즘: 우도를 최대화해 계수를 추정하고, 입력의 선형 결합 z를 시그모이드 p = 1/(1+e^(−z))로 확률로 바꾼 뒤 임계값과 비교해 분류
- 통찰: 계수는 확률의 증가량이 아니라 로그 오즈의 변화이고 오즈비는 인과 효과가 아니므로, 클래스 불균형에서는 정확도 대신 정밀도·재현율로 보고 임계값을 오분류 비용에 맞춰 정함

<details>
<summary>핵심 용어</summary>

- **로지스틱 회귀(Logistic Regression)** : 이진 결과의 확률을 로짓 함수로 모형화하는 회귀
- **로짓(Logit)** : 확률의 로그 오즈 log[p/(1−p)]
- **오즈(Odds)** : 사건이 일어날 확률과 일어나지 않을 확률의 비 p/(1−p)
- **오즈비(Odds Ratio)** : 변수 한 단위 증가 시 오즈에 곱해지는 비율 e^β
- **시그모이드(Sigmoid)** : 실수를 0과 1 사이로 바꾸는 함수
- **최대우도추정** : 관측 자료의 우도를 최대화하는 계수 추정법
- **혼동행렬** : 예측과 실제의 조합을 집계한 표

</details>

## 2~4교시 25점 답안

## Ⅰ. 로지스틱 회귀의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **로지스틱 회귀** 는 입력 변수와 사건 확률의 관계를 로짓 함수로 모형화하는 통계적 분류 모델 |
| 목적 | 입력 조건에 따른 범주 사건의 확률을 추정해 분류·판단 지원 |

## Ⅱ. 특징

| 특징 | 표현 | 해석 |
|---|---|---|
| 확률 출력 | 0과 1 사이의 확률 | 임계값은 오분류 비용에 따라 선택 |
| 선형 예측자 | 설명 변수의 가중합 | 계수는 확률 자체의 증가량이 아님 |
| 계수 해석 | 로짓과 오즈비 | 다른 변수를 고정한 조건부 관계 |

## Ⅲ. 추정·변환·분류

```text
학습 데이터 (X, 이진 결과 y) → 우도를 최대화해 계수 β 추정
새 입력 X → z = β0 + Σ βi·xi = log[p/(1−p)]
          → 시그모이드 p = 1/(1+e^(−z))
          → 임계값과 비교해 분류
```

## Ⅳ. 계수 해석

```text
xi 한 단위 증가, 다른 변수 고정
   → 로짓(로그 오즈)이 βi 만큼 변화
   → 오즈 p/(1−p)는 e^(βi) 배
```

| 항목 | 내용 |
|---|---|
| 모수 추정 | 이진 반응의 우도를 최대화하는 계수 |
| βi | 다른 변수를 고정할 때 xi 한 단위 증가에 따른 로그 오즈 변화 |
| e^βi | 오즈에 곱해지는 비율 |
| 분류 기준 | 확률을 임계값과 비교, 임계값은 비용·목표에 따라 선택 |

오즈비는 확률의 증가 배수나 인과 효과와 다르며, 관찰 자료에서 인과를 말하려면 연구 설계와 교란 변수 통제가 필요. 다범주 결과는 다항 로지스틱 회귀로 확장.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 클래스 불균형에서 정확도만 보면 소수 클래스를 놓침 | 혼동행렬·정밀도·재현율로 평가하고 목표에 맞춰 임계값 결정 |
| 설명 변수 간 강한 상관으로 계수 불확실성 증가 | 상관 구조 확인, 정규화 등 안정화 방법 검증 |
| 운영 분포 변화로 확률 보정·성능 저하 | 시간·집단 분리 검증, 확률 보정과 운영 후 감시 |

## Ⅵ. 제언

임계값을 오분류 비용으로 정하고 불균형 자료는 정밀도·재현율로 평가하며, 운영 중 성능을 감시

```text
확률 추정 → 비용 기반 임계값 → 혼동행렬 평가 → 운영 감시·재보정
```

| 구분 | 정확도·기본 임계값 0.5 | 제언: 비용 기반 임계값 |
|---|---|---|
| 소수 클래스 | 놓침 | 재현율 관리 |
| 운영 | 방치 | 분포 변화 감시 |

## 출제 이력과 검증 출처

- Hosmer·Lemeshow·Sturdivant, Applied Logistic Regression
