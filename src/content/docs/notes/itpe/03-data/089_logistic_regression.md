```text
 ┃
 ┣━ Ⅰ 개요 ───── 종속변수가 범주형(0 또는 1)일 때, 독립변수들의 선형 결합을 시그모이드 함수를 통해 0~1 사이의 발생 확률로 예측하는 통계적 분류 기법
 ┣━ Ⅱ 특징 ───── 이진/다항 분류 · 시그모이드 함수 매핑 · 오즈비(Odds Ratio) 해석력 · 최대우도추정법(MLE) 최적화 · 선형 결정 경계
 ┣━ Ⅲ 구조 ───── 선형 결합($z = W^T X + b$) ➔ 오즈(Odds, $\frac{p}{1-p}$) ➔ 로짓 변환($\ln(\text{Odds})$) ➔ 시그모이드 출력($p = \frac{1}{1 + e^{-z}}$)
 ┣━ Ⅳ 흐름 ───── ① 입력 데이터 수집 및 정규화 → ② 로짓 선형식 구성 → ③ 시그모이드 확률 변환 → ④ 로그 우도 손실(Cross-Entropy) 계산 → ⑤ 경사하강법 가중치 갱신
 ┣━ Ⅴ 비교 ───── 선형 회귀 vs 로지스틱 회귀 (연속형 수치/최소자승법(OLS)/$-\infty \sim \infty$ vs 범주형 확률/최대우도법(MLE)/$0 \sim 1$)
 ┗━ Ⅵ 실무 ───── 데이터 불균형(Class Imbalance)에 따른 임계값(Threshold) 조정 / 다중공선성에 따른 오즈비 왜곡 / L1/L2 규제 적용
```

## 한 줄 본질
- 일반 선형 회귀를 이진 분류에 적용 시 출력이 음수나 1을 초과하는 확률 모순 발생 → 오즈에 로그를 취한 로짓을 선형 모델링하고 역함수인 시그모이드로 변환 → 0~1 확률 보장 및 직관적 오즈비 설명력 / 비선형 복합 관계 표현 한계

## 핵심 그림
```text
[로지스틱 회귀 수식 변환 단계 및 시그모이드 곡선]

 [수학적 변환 파이프라인]
  1. 오즈 (Odds) : 실패 대비 성공 확률의 비 = $\frac{p}{1-p}$  (범위: $0 \sim \infty$)
  2. 로짓 (Logit): 오즈에 자연로그 적용 = $\ln\left(\frac{p}{1-p}\right) = W^T X + b$ (범위: $-\infty \sim \infty$)
  3. 시그모이드 (Sigmoid): $p$에 대해 역정리 = $p = \frac{1}{1 + e^{-(W^T X + b)}}$ (범위: $0 \sim 1$)

 [시그모이드 곡선 매핑]
     p ▲
   1.0 ┼───────────────────---*****
       │                 **
   0.5 ┼───────────────* (Threshold: 기본 0.5)
       │             **
   0.0 ┼*****───────────────────────► z (선형 결합값)
              음수 (-)       양수 (+)
```

## 핵심 용어
- 오즈비(Odds Ratio, $e^{\beta_i}$): 독립변수 $X_i$가 1단위 증가할 때 사건이 발생할 오즈가 몇 배 증가하는지를 나타내는 지표(해석력의 핵심)
- 최대우도추정법(MLE, Maximum Likelihood Estimation): 관측된 표본 데이터의 발생 확률(우도)을 최대로 만드는 회귀 파라미터($W, b$)를 반복 연산으로 찾는 방법

## 핵심 통찰
- 로지스틱 회귀의 강력함은 '정확도'가 아니라 '완벽한 설명력(Interpretability)'에 있음 → 계수 $\beta$에 지수를 취한 오즈비($e^\beta$)를 통해 "나이가 1살 많아질수록 대출 연체 확률이 1.2배 높아진다"는 인과적 해석을 경영진과 금융감독원에 명확히 제시 가능
- 분류 임계값(Threshold)을 무조건 0.5로 고정하면 안 됨 → 암 진단이나 금융 사기(FDS)처럼 위양성(FP)보다 위음성(FN)의 비용이 치명적인 도메인에서는 임계값을 0.2~0.3으로 낮춰 재현율(Recall)을 끌어올려야 함
- 다중공선성이 존재하면 오즈비 부호가 뒤집히는 심각한 오류 발생 → L1 규제(Lasso)를 적용해 불필요한 변수를 0으로 만들거나 VIF 검정 필수

## 이웃 토픽과 구분
- 선형 회귀 vs 로지스틱 회귀: 선형 회귀 = 연속형 수치 예측, 종속변수 제한 없음, OLS(최소자승법) 사용 / 로지스틱 회귀 = 범주형 사건 발생 확률(0~1) 예측, S자 시그모이드 곡선, MLE(최대우도법) 사용

## 문제·원인·대책
- 적용 상황: 시중 은행의 개인 신용대출 부도 예측 모델 심사
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 전체 고객 중 연체율이 1% 미만이라 모든 고객을 '정상'으로 예측해도 정확도가 99%로 나오는 착시 | 극단적 클래스 불균형(Class Imbalance) | SMOTE 오버샘플링 적용 및 비용 민감 손실함수(Focal Loss / Class Weight) 도입 | 연체자 탐지 재현율(Recall) 85% 이상 확보 |
| 부채 비율과 월 소득 변수 간 높은 상관관계로 부채 변수의 회귀 계수가 음수로 산출 | 다중공선성(Multicollinearity)으로 인한 추정 분산 폭증 | 상관 변수 제거 및 L2 릿지(Ridge) 규제 하이퍼파라미터 튜닝 | 변수 계수의 정상적 부호 복원 및 해석 신뢰도 확보 |
