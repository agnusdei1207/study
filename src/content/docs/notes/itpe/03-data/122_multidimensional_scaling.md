자료처리·데이터 → 데이터 분석 → **다차원 척도법(MDS)**

## 30초 인출

- 본질: 다차원 척도법은 대상 간 비유사도를 저차원 공간의 거리로 표현해 유사·비유사 관계를 배치도로 나타내는 분석법
- 메커니즘: 비유사도 행렬과 목표 차원을 정해 초기 좌표를 만들고, 좌표 거리와 입력 비유사도의 차이(Stress)를 줄이도록 좌표를 반복 조정해 배치를 얻음
- 통찰: 좌표축은 회전·반사해도 거리가 같아 축에 임의 의미를 붙일 수 없고 초기값에 따라 지역해에 빠질 수 있으므로, 여러 시작값과 차원 수의 Stress를 비교해 점 사이 상대 거리만 해석

<details>
<summary>핵심 용어</summary>

- **MDS(Multidimensional Scaling)** : 비유사도를 저차원 거리로 표현하는 분석법
- **비유사도 행렬** : 대상 쌍 사이의 차이를 담은 행렬
- **Stress** : 입력 비유사도와 좌표 거리의 차이를 나타내는 적합도 지표
- **Metric MDS** : 비유사도의 수치 크기를 보존
- **Nonmetric MDS** : 비유사도의 순위(단조 관계)를 보존
- **지역해** : 초기값에 따라 도달하는 전역 최적이 아닌 해

</details>

## 2~4교시 25점 답안

## Ⅰ. 다차원 척도법의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **MDS** 는 대상 간 비유사도를 저차원 공간의 거리로 표현하는 분석법 |
| 목적 | 복잡한 대상 간 관계를 배치도로 탐색·해석 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 대상 간 관계 보존 | 변수 축보다 대상 쌍의 비유사도·순서에 초점 |
| 저차원 근사 | 차원을 낮추면 손실이 생겨 Stress 확인 필요 |
| 좌표 방향의 임의성 | 회전·반사·이동해도 거리가 같아 축을 임의 해석하지 않음 |

## Ⅲ. 좌표 배치 절차

```text
비유사도 행렬 → 거리 정의·목표 차원·MDS 유형 선택
   ↓
초기 저차원 좌표 → 좌표 간 거리 산출 → 입력과의 차이(Stress) 계산
   ↓ 좌표 조정 반복
Stress 감소 → 수렴 → 배치·관계 해석
```

여러 시작값과 차원 수를 비교하고 Stress와 관계 보존 정도를 함께 확인하며, 낮은 Stress가 축의 실세계 의미나 군집 경계를 확정하지는 않음.

## Ⅳ. Metric·Nonmetric MDS 비교

| 유형 | 보존하려는 관계 | 결과 해석 |
|---|---|---|
| Metric MDS | 비유사도의 수치 크기 | 좌표 거리와 입력값의 근사 관계 |
| Nonmetric MDS | 비유사도의 순위 | 거리가 순서를 따르는 단조 관계 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 저차원 배치에서 원래 관계 손실 | 입력 거리·차원 수·Stress 제시, 왜곡된 대상 쌍 확인 |
| 회전·반사 가능한 축에 임의 의미 부여 | 상대 거리만 해석, 축 의미는 외부 변수와 별도 검증 |
| 초기값에 따른 지역해 | 여러 초기화의 Stress와 안정적인 대상 관계 비교 |

## Ⅵ. 제언

입력 비유사도의 성격(수치·순위)으로 유형을 정하고, 여러 초기값의 Stress로 안정성을 확인

```text
비유사도 성격 → Metric/Nonmetric → 다중 초기화·차원 비교(Stress) → 상대 거리 해석
```

| 구분 | 단일 실행 결과 해석 | 제언: 다중 초기화 비교 |
|---|---|---|
| 안정성 | 지역해 위험 | 안정 관계 확인 |
| 해석 | 축 의미 부여 | 상대 거리 위주 |
