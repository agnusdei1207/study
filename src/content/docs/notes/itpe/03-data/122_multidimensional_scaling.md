## Ⅰ. 인지적 거리의 시각화, 다차원 척도법(MDS)의 개요

### 가. 다차원 척도법(MDS, Multidimensional Scaling)의 정의
- 객체들 간의 유사도(Similarity) 또는 비유사도(Dissimilarity, 거리) 측정값을 입력으로 받아, 원래 고차원 공간에 존재하는 객체들 사이의 상대적 거리 관계를 **2차원 또는 3차원 저차원 평면 상의 점(Point) 좌표로 시각적으로 배치** 하는 다변량 통계적 차원 축소 기법.
- 소비자의 뇌리에 형성된 브랜드 간의 심리적 포지셔닝 맵(Perceptual Map)을 작성하는 마케팅 조사 및 패턴 인식의 핵심 도구.

## Ⅱ. 계량적 MDS(Metric) vs 비계량적 MDS(Non-metric) 비교

### 가. 두 방법론의 핵심 차이

```text
[ MDS 양대 접근법 비교 ]
(A) 계량적 MDS (Metric MDS)
    - 입력 데이터: 실제 수치적 거리 (비율척도, 등간척도)
    - 목표: 저차원 유클리디안 거리 d_ij가 원래 거리 delta_ij의 수치 자체에 근사하도록 배치

(B) 비계량적 MDS (Non-metric MDS / Shepard-Kruskal)
    - 입력 데이터: 단순 선호도 순위 (서열척도: "A가 B보다 C에 가깝다")
    - 목표: 원래 순위 관계(delta_i < delta_j)가 저차원 거리 순위(d_i < d_j)로 단조 보존(Monotonic)되도록 배치
```

### 나. 상세 비교 매트릭스

| 비교 항목 | 계량적 MDS (Metric MDS) | 비계량적 MDS (Non-metric MDS) |
| :--- | :--- | :--- |
| **입력 척도 유형** | 구간 척도(Interval), 비율 척도(Ratio) | 순서 척도(Ordinal, 서열 데이터) |
| **거리 적합 원리** | $d_{ij} \approx f(\delta_{ij})$ (선형 관계 적합) | $\delta_{ij} < \delta_{kl} \implies d_{ij} \le d_{kl}$ (단조 회귀) |
| **수학적 해법** | B-행렬의 고유값 분해(Classical MDS / PCoA) | 크러스칼 스트레스(Kruskal Stress) 최소화 경사하강법 |
| **적용 사례** | 도시 간 실제 지리적 도로 주행 거리 데이터 | 소비자 설문조사의 스마트폰 브랜드 간 선호도 순위 |

## Ⅲ. MDS 적합도 평가: 스트레스(Stress) 값 평가 기준

### 가. 크러스칼 스트레스(Kruskal's Stress Formula 1) 산식
$$Stress = \sqrt{\frac{\sum_{i < j} (d_{ij} - \hat{d}_{ij})^2}{\sum_{i < j} d_{ij}^2}}$$
($d_{ij}$는 저차원 평면에서의 유클리디안 거리, $\hat{d}_{ij}$는 단조 변환된 거리 근사치).

### 나. 스트레스 값에 따른 적합도 해석 기준

| 스트레스 값 범위 | 적합도(Goodness of Fit) 판정 | 실무적 의미 |
| :--- | :--- | :--- |
| **0.00 (0%)** | 완벽한 적합 (Perfect) | 원래 객체 간 거리 관계가 2차원에 왜곡 없이 100% 보존됨 |
| **$\le$ 0.05 (5%)** | 매우 우수 (Excellent) | 결과 맵을 바탕으로 비즈니스 의사결정 신뢰도 극상 |
| **0.05 ~ 0.10** | 양호 (Good) | 실무 분석에 충분히 유효한 수준 |
| **0.10 ~ 0.20** | 보통 (Fair) | 대략적인 경향성 파악 가능, 국소적 거리 왜곡 주의 |
| **$>$ 0.20 (20%)** | 불량 (Poor) | 차원 축소에 따른 정보 왜곡이 심하여 3차원 확장 검토 필요 |

## Ⅳ. 다차원 척도법(MDS)의 주요 한계점 및 해결 방안

- **거리 행렬 계산 및 고유값 분해의 시간 복잡도($O(N^3)$ 또는 $O(N^2)$)** :
  - **한계점** : 객체 수($N$)가 수만 건 이상으로 증가할 경우 개체 간 거리 행렬 연산과 스트레스(Stress) 함수 최적화에 필요한 메모리 및 연산량이 폭증하여 대규모 데이터 처리 불가.
  - **해결 방안** : 랜드마크 MDS(Landmark MDS: 대표 포인트 샘플링 후 근사 매핑) 적용, Barnes-Hut t-SNE 또는 UMAP과 같은 현대적 그래프 기반 고속 차원 축소 기법으로 대체.
- **국소 최적해(Local Minima) 수렴 및 초기 배치 민감성** :
  - **한계점** : 비계량적 MDS(Non-metric MDS)의 경사하강법 최적화 과정에서 초기 점 배치에 따라 국소 최저점에 갇혀 실제 인지적 구조와 왜곡된 저차원 맵 생성.
  - **해결 방안** : 고전적 주성분 분석(Classical Scaling) 결과를 초기 좌표로 지정, 다중 무작위 시작(Multi-start) 및 모의 담금질(Simulated Annealing) 최적화 결합.
- **저차원(2D/3D) 축의 의미론적 해석(Semantic Interpretability) 부재** :
  - **한계점** : 투영된 결과 축이 통계적 수학 공식에 의한 추상 공간이므로 현업 의사결정자가 비즈니스 축(예: 가격, 품질)으로 직관적 명명 및 해석 곤란.
  - **해결 방안** : 기존 객체 속성과의 상관분석(Property Fitting / Vector Modeling)을 통해 저차원 축에 비즈니스 속성 벡터를 중첩 투영하여 시각화 보완.

## Ⅴ. 데이터 분석 실무 적용 시 제언

- **축(Axis)의 비즈니스적 명명 작업 필수** : MDS 알고리즘이 산출하는 X축과 Y축은 단순한 수학적 상대 좌표일 뿐 물리적 의미가 없으므로, 도출된 2차원 지각도 상에 배치된 개체들의 극단적 분포(예: 좌측은 '저가격', 우측은 '고품질')를 분석하여 도메인 전문가가 축의 비즈니스 명칭을 직접 해석하고 부여해야 함.
- **$O(n^2)$ 메모리 한계 극복** : MDS는 모든 개체 쌍 간의 거리 행렬($n \times n$)을 생성해야 하므로 데이터 건수 $n$이 수만 건을 초과하면 연산이 불가능함. 따라서 빅데이터 환경에서는 Landmark MDS를 적용하여 일부 랜드마크 포인트만 기준으로 삼거나 t-SNE/UMAP으로 대체할 것을 제언함.
