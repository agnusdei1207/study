## 답안 골격
```text
[다차원척도법 (MDS, Multidimensional Scaling)] ◀━━ 머리: Ⅶ 내 의견 (Stress 적합도 기반 차원 결정과 브랜드 포지셔닝 맵 시각화)
 ┃
 ┣━ Ⅰ 개요 ───── 객체 간의 유사성/비유사성(거리) 데이터를 기반으로 고차원의 복잡한 관계를 2차원 또는 3차원 공간상의 점(좌표)으로 축소·시각화하는 비지도 기법
 ┣━ Ⅱ 특징 ───── 원시 속성 없이 거리(행렬)만으로 좌표 복원 · 공간적 지각도(Perceptual Map) 작성 · 적합도 척도로 스트레스(Stress) 값 활용
 ┣━ Ⅲ 구조 ───── 계량적 MDS(Metric: 실제 유클리드 거리 비율 보존) / 비계량적 MDS(Non-metric: 순위 척도(서열) 보존, Shephard 다이어그램)
 ┣━ Ⅳ 흐름 ───── ① 대상 간 유사도/거리 행렬 산출 → ② 저차원(2D) 초기 좌표 임의 배치 → ③ 저차원 거리와 원본 거리 간 오차(Stress) 계산 → ④ 좌표 반복 최적화 → ⑤ 지각도 시각화
 ┣━ Ⅴ 비교 ───── MDS vs PCA vs t-SNE
 ┗━ Ⅵ 실무 ───── 축(Axis)의 의미가 수학적으로 자동 정의되지 않아 해석 주관성 개입 / 고차원 축소 시 국소적 최솟값(Local Minimum) 수렴
```
- 필수 키워드: 다차원척도법(MDS) · 유사도/비유사도 행렬 · 계량적 MDS · 비계량적 MDS · 스트레스(Stress) 값 · 지각도(Perceptual Map) · 차원 축소
- 배점 전략: 10점 = Ⅰ → Ⅲ 계량적 vs 비계량적 비교 및 Stress 판정 기준표 → Ⅴ PCA와의 비교 / 25점 = Ⅰ~Ⅶ, Ⅳ 반복 최적화(ALSCAL/SMACOF) 알고리즘 흐름 및 Ⅵ 마케팅 포지셔닝 맵 활용

## 한 줄 본질
- 수십 개 속성으로 얽힌 객체 간의 심리적 거리나 상대적 유사도를 인간이 직관적으로 이해하기 어려움 → 객체 간의 거리 순서를 2차원 평면 좌표에 최대한 보존하여 시각화 → 잠재적 구조의 공간적 파악 / 축의 의미 해석이 주관적

## 핵심 그림
```text
[다차원척도법(MDS)의 변환 흐름 및 2차원 지각도]

  [1. 입력: 객체 간 거리 행렬]              [2. 출력: 2차원 공간 지각도 (Perceptual Map)]
      A    B    C    D                              ▲ 차원 2 (스포티함)
  A [ 0    2    8    9 ]                            │
  B [ 2    0    7    8 ]                     (A) *  │      * (C)
  C [ 8    7    0    3 ]                            │
  D [ 9    8    3    0 ]              ──────────────┼──────────────► 차원 1 (고급스러움)
                                             (B) *  │
  * Stress = √( Σ(d_ij - d̂_ij)² / Σ d_ij² )         │      * (D)
    (0.05 이하: 우수, 0.15 이상: 부적합)            ▼
```

## 핵심 용어
- 스트레스(Stress) 값: 원본 고차원 거리($d_{ij}$)와 저차원 평면에 투영된 유클리드 거리($\hat{d}_{ij}$) 간의 불일치 정도를 나타내는 0~1 사이의 적합도 손실 함수
- 계량적(Metric) vs 비계량적(Non-metric) MDS: 거리의 절대적 수치 크기를 그대로 유지하려 하는 방식(계량적) vs "A-B가 A-C보다 더 가깝다"는 서열(Rank) 순서만 보존하는 방식(비계량적)

## 핵심 통찰
- PCA는 '데이터의 분산(Variance)'을 최대로 보존하는 선형 변환이지만, MDS는 '점과 점 사이의 거리(Distance)'를 최대로 보존하는 기하학적 변환임
- MDS의 출력 결과물인 2차원 평면의 X축과 Y축에는 아무런 이름표가 붙어있지 않음 → 분석가가 결과 지각도에 배치된 브랜드들의 위치를 보고 "X축은 가격, Y축은 친절도"라고 정성적 도메인 지식으로 해석해야 함
- 설문조사에서 "각 브랜드의 디자인, 성능, 가격 점수를 매기시오"라고 묻기 어려울 때, "브랜드 A와 B가 얼마나 비슷하다고 느끼십니까?"라는 단순 비교 응답만 받아도 MDS를 돌리면 완벽한 포지셔닝 맵 도출 가능

## 이웃 토픽과 구분
- MDS vs PCA: MDS = 객체 간의 상대적 거리/비유사도 행렬이 입력값이며 거리 보존이 목표 / PCA = 원본 수치형 변수 행렬이 입력값이며 직교하는 주성분 축을 찾아 분산 보존이 목표

## 문제·원인·대책
- 적용 상황: 자동차 제조사의 경쟁 차종 간 브랜드 이미지 포지셔닝 분석
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 2차원 MDS 변환 결과 Stress 값이 0.22로 산출되어 결과 왜곡 심각 | 소비자의 평가 기준이 2차원을 넘어 다차원(디자인, 연비, 안전성, 가격)으로 분산 | 3차원 MDS로 확장하거나 비계량적 MDS(Kruskal Stress)로 서열 보존 전환 | Stress 값 0.08로 개선 및 유의미한 군집 구조 식별 |
| 초기 무작위 좌표 배치에 따라 매번 실행할 때마다 지각도 모양이 완전히 달라짐 | 경사하강법 기반 좌표 탐색 시 국소 최솟값(Local Minimum)에 안주 | 주성분 분석(Classical Scaling) 결과를 초기 좌표로 주입(SMACOF) | 일관되고 재현 가능한 최적 지각도 수렴 |

## 이렇게 출제된다
- 제123회: "다차원척도법(MDS, Multidimensional Scaling)의 개념과 유형(계량적, 비계량적)을 설명하고, 모형의 적합도 판정 기준인 스트레스(Stress)의 계산 원리와 해석 기준을 기술하시오." → 요구 포인트: MDS 정의 + 계량적 vs 비계량적 비교표 + Stress 수식 및 판정 기준표(0.05, 0.1, 0.15) + 마케팅 포지셔닝 활용

## 내 의견
- [축 해석의 독단적 주관성 통제] 데이터 분석가가 MDS 지각도를 그려놓고 자신의 직관에 의존하여 임의로 X축과 Y축의 라벨을 붙여 비즈니스 의사결정을 오도하는 위험 상존 → 나라면: MDS 지각도 도출 후 원본 설문 변수들과 MDS 좌표 간의 다변량 회귀분석(속성 피팅, Property Fitting)을 통계적으로 수행하여, 통계적으로 유의한($p < 0.01$) 속성 벡터만을 축 방향으로 객관적 표시

## 찾아볼 것
