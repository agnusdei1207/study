## 30초 인출

- 본질: MOLAP은 분석 데이터를 다차원 큐브 구조로 저장·집계해 다차원 질의에 응답하는 OLAP 방식
- 메커니즘: 시간·지역·상품 같은 차원과 측정값을 정의하고 계층별 집계 범위를 골라 큐브 셀에 사전 집계를 저장하면, 질의가 차원 조건으로 셀을 선택해 집계값을 반환
- 통찰: 차원·계층이 늘면 집계 조합과 저장·갱신 비용이 급증(큐브 폭발)하고 원천 변경 뒤 갱신 전에는 값이 낡으므로, 자주 쓰는 집계부터 산정하고 희소성 처리·부분 집계·ROLAP 연계와 허용 지연을 정함

<details>
<summary>핵심 용어</summary>

- **MOLAP** : 다차원 큐브 구조에 사전 집계를 저장하는 OLAP
- **큐브(Cube)** : 차원·계층·측정값으로 구성한 다차원 구조
- **큐브 폭발** : 차원·계층·집계 수준이 늘수록 집계 조합과 비용이 급증하는 현상
- **희소성(Sparsity)** : 가능한 차원 조합 중 관측값이 없는 셀이 많은 특성
- **Roll-up·Drill-down·Slice·Dice·Pivot** : OLAP 분석 연산
- **ROLAP·HOLAP** : 관계형 기반 / 혼합 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. MOLAP의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **MOLAP** 은 분석 데이터를 다차원 큐브 구조로 저장·집계해 다차원 질의에 응답하는 OLAP 방식 |
| 목적 | 사전 집계와 차원 구조로 반복 분석 질의의 응답 단축 |

## Ⅱ. 특징

| 특징 | 설계 영향 |
|---|---|
| 다차원 큐브 | 차원·계층·측정값으로 분석 셀 구성 |
| 사전 집계 | 응답 단축 대신 저장·갱신 비용 발생 |
| 집계 범위 선택 | 차원 조합이 늘수록 큐브 크기·희소성 증가 |

## Ⅲ. 큐브 구성과 질의

```text
원천 거래 → 차원(시간·지역·상품)·측정값 정의 → 계층별 집계 범위 선택
   → 큐브 셀·사전 집계 저장 → 분석 질의 → 차원 조건으로 셀 선택 → 집계값 반환
```

```text
시간: 일 → 월 → 연  (Roll-up)   /   연 → 월 → 일  (Drill-down)
지역·상품 조건 → 부분 큐브 선택(Slice·Dice)
```

## Ⅳ. 큐브 폭발과 방식 비교

| 연산 | 변화 |
|---|---|
| Roll-up | 상위 수준으로 집계 |
| Drill-down | 하위 수준으로 상세화 |
| Slice·Dice | 한 개·여러 차원 조건으로 부분 큐브 선택 |
| Pivot | 분석 축의 행·열 배치 변경 |

- 큐브 폭발: 차원 값·계층·사전 집계 수준이 늘수록 가능한 집계 조합과 비용이 급증하는 현상이며 모든 조합을 실제로 저장한다는 뜻은 아님
- 희소성: 가능한 조합 중 관측값이 없는 셀이 존재하는 특성이며 비율은 데이터와 차원 구성에 따름

| 구분 | 저장·계산 | 고려 |
|---|---|---|
| MOLAP | 다차원 구조에 집계값을 미리 구성 | 반복 분석에 유리, 저장·갱신 규모 |
| ROLAP | 관계형 스키마에서 질의 시 집계 | 변경·확장에 유연, 질의 부하 평가 |
| HOLAP | 집계 수준에 따라 MOLAP·ROLAP 조합 | 혼합 구조의 일관성·운영 복잡성 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 차원·계층·집계 범위 증가로 저장량·갱신 비용 증가 | 자주 쓰는 집계부터 산정, 희소 데이터 처리·부분 집계·ROLAP 연계 평가 |
| 원천 변경 후 갱신 전 사전 집계가 낡음 | 업무 허용 지연을 정하고 갱신 주기·대사 절차 설정 |

## Ⅵ. 제언

자주 쓰는 차원 조합만 사전 집계하고 나머지는 ROLAP으로 처리하며 갱신 주기와 대사를 운영

```text
질의 빈도 분석 → 핵심 집계 큐브 → 나머지 ROLAP → 갱신 주기·대사
```

| 구분 | 모든 조합 사전 집계 | 제언: 선별 집계 |
|---|---|---|
| 저장·갱신 | 폭증 | 제한 |
| 응답 | 빠름 | 핵심 질의는 빠름 |
