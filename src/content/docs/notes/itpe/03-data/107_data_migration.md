### Ⅰ. 데이터 마이그레이션의 개요

- 핵심 요약 : 데이터를 한 시스템에서 다른 시스템으로 이전하는 과정.
- 개념 : 데이터 마이그레이션은 데이터를 한 시스템에서 다른 시스템으로 이전하는 과정(**데이터 마이그레이션**, Data Migration).
- 배경 및 필요성 : 시스템 교체, 클라우드 이전, 데이터 웨어하우스 구축 등 다양한 상황에서 데이터 마이그레이션이 필요함.
- 주요 목적 : 데이터의 무결성과 일관성을 유지하면서 안전하게 데이터를 이전.

### Ⅱ. 데이터 마이그레이션의 특징 및 장점

- 핵심 요약 : 데이터 추출, 변환, 적재(ETL) 프로세스를 통해 데이터를 새로운 시스템으로 이전.

1. 데이터 추출 : 원본 시스템에서 데이터를 추출.
2. 데이터 변환 : 추출된 데이터를 타겟 시스템에 적합한 형태로 변환.
3. 데이터 적재 : 변환된 데이터를 타겟 시스템에 적재.
