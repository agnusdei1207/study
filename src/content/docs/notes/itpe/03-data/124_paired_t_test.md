## 연관 키워드

- 대응표본 t-검정, Paired T-Test, 차이값(d), 윌콕슨 부호순위 검정(Wilcoxon Signed-Rank Test), 검정력(Statistical Power)
- 차이의 차이 분석(DID), 교차 설계(Crossover Design), 정규성 검정(Shapiro-Wilk)

## Ⅰ. 대응표본 t-검정의 개요

- 핵심 요약 : 동일 대상의 처치 전후 차이 평균이 0인지 판정하는 대표적 모수 검정 기법.
- 개념 : **대응표본 t-검정** (Paired T-Test, 같은 개체를 두 번 측정한 짝지은 값의 차이를 이용하는 t-검정)은 개체별 **차이값** (d, 사후값에서 사전값을 뺀 값)의 평균이 0인지 검정하는 기법.
- 배경 및 필요성 : 개체마다 고유한 차이(개인차)가 처치 효과와 섞이면 독립된 두 집단의 비교로는 효과를 가려내기 어려워 개인차를 상쇄하는 설계가 필요함.
- 주요 목적 : 동일 개체의 전후 변화로 순수 처치 효과의 존재 여부를 유의수준 기준으로 판정.

## Ⅱ. 대응표본 t-검정의 특징 및 장점

- 핵심 요약 : 개체 편차를 차이값으로 상쇄해 같은 표본 크기에서도 처치 효과를 높은 검정력으로 검출하는 구조.

1. 개체 편차 상쇄 : 같은 개체의 전후 차이만 비교 → 개인차가 빠져 처치 효과의 신호가 선명해짐.
2. **검정력** (Statistical Power, 실제 효과가 있을 때 이를 검출할 확률) : 개체 간 분산이 제거되어 같은 표본으로 더 작은 효과도 검출 → 표본 비용 절감.
3. 단일 표본 변환 : 차이값의 평균이 0인지 검정하는 단일 표본 문제로 축약 → 계산 구조가 단순해짐.
4. **윌콕슨 부호순위 검정** (Wilcoxon Signed-Rank Test, 차이의 부호와 순위로 중앙값 차이를 검정하는 비모수 검정) : 정규성이 깨질 때의 대안 → 분포 가정 완화.
5. **교차 설계** (Crossover Design, 같은 개체에 처치 순서를 바꿔 적용하는 실험 설계) : 개체를 공유한 채 두 처치를 비교 → 적은 개체로 비교 가능.

## Ⅲ. 대응표본 t-검정의 구조 (흐름)

- 핵심 요약 : 차이값 도출, 정규성 확인, 검정 방법 선택, 판정으로 이어지는 4단계 절차.
- 검정통계량 : t = d̄ / (s_d / √n), 자유도 df = n − 1 (d̄는 차이값의 평균, s_d는 차이값의 표준편차, n은 개체 수).
- 귀무가설 : 평균 차이 μ_d = 0 (처치 전후 차이 없음).

```text
[ 차이값 도출과 검정 방법 선택 ]

개체별 사후값 - 사전값 = 차이값 d
                |
                v
   정규성 검정 (Shapiro-Wilk)
                |
        +-------+-------+
        |               |
     만족 시          위반 시
        v               v
  대응 t-검정    윌콕슨 부호순위 검정
```

```text
[ 대응표본 → 단일표본 변환 (예시 데이터) ]

개체 1 : 사전 80 → 사후 85 → d = +5
개체 2 : 사전 90 → 사후 92 → d = +2
   ...
개체 n : 사전 75 → 사후 83 → d = +8
                |
                v
   d의 평균이 0인지 단일표본 t-검정
```

## Ⅳ. 대응표본과 독립표본의 비교

- 핵심 요약 : 같은 개체의 전후 비교인지, 서로 다른 두 집단의 비교인지에 따라 개인차 처리와 검정력이 달라짐.
- 선택 기준 : 같은 개체를 두 번 측정할 수 있으면 대응표본, 개체가 달라 짝짓기가 어려우면 독립표본을 사용.

| 비교 축 | 대응표본 t-검정 | 독립표본 t-검정 |
| :--- | :--- | :--- |
| 표본 구조 | 동일 또는 짝지은 개체의 전후 측정 | 서로 독립된 두 집단 |
| 개인차 처리 | 차이값으로 상쇄 | 잔차에 포함 |
| 검정력 | 상대적으로 높음 | 상대적으로 낮음 |
| 주요 가정 | 차이값의 정규성 | 각 집단의 정규성과 등분산성 |

## Ⅴ. 대응표본 t-검정의 한계와 방안

- 핵심 요약 : 정규성 위반, 역사적 요인, 시험 효과를 비모수 검정, 차이의 차이 분석, 교차 설계로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 정규성 위반 | 소표본에서 차이값 분포가 치우치면 t 검정 결과의 신뢰도 저하 | Shapiro-Wilk 검정으로 선행 확인 후 윌콕슨 부호순위 검정 전환, 순열 검정 병행 | 정규성 검정 p값, 검정력 |
| 역사적 요인 | 처치와 무관한 시간 경과 효과가 처치 효과에 섞임 | 대조군을 둔 **차이의 차이 분석** (DID, Difference-in-Differences) 적용 | 처치 효과 분리 여부 |
| 시험 효과 | 반복 측정 자체가 학습 편향을 만듦 | 처치 순서를 균형 있게 배정한 교차 설계와 세척 기간 확보 | 순서 효과 검정 결과 |

## Ⅵ. 대응표본 t-검정에 대한 기술사적 제언

- 핵심 요약 : 튜닝과 실험 효과를 입증할 때 전후 쌍체 비교와 교차 설계를 표준 절차로 두는 것이 신뢰도 확보의 출발점.

1. DB 튜닝 : 튜닝 효과를 주장할 때는 같은 쿼리 집합을 전후에 동일 조건으로 실행하고, 쿼리 단위로 짝지은 차이를 검정하는 절차 필요.
2. UX(User Experience) 실험 : 같은 사용자에게 두 화면을 번갈아 보이는 실험에서는 교차 설계와 세척 기간을 함께 두어 이월 효과를 통제할 필요.
3. 분석 표준 : 차이값의 정규성 검정을 분석 파이프라인의 선행 단계로 두고, 위반 시 윌콕슨 부호순위 검정으로 전환하는 기준을 명문화할 필요.

## Ⅶ. 결론

- 핵심 요약 : 대응표본 t-검정은 동일 집단의 전후 효과를 검증하는 기본 기법이며, 차이값 변환과 정규성 확인이 신뢰도의 핵심.
- 시사점 : 전후 비교 결과는 개인차 제거 설계와 정규성 확인 위에서만 신뢰되므로, 두 조건을 분석 절차의 기본 항목으로 포함하는 것이 바람직.
