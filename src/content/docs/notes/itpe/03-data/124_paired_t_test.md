## 연관 키워드

**대응표본 t-검정(Paired T-Test)**, **차이값(d)**, **윌콕슨(Wilcoxon Signed-Rank)**, **검정력(Power)**, **DID**, **교차 설계(Crossover)**

## Ⅰ. 개요

- 핵심 요약 : **대응표본 t-검정**은 동일 집단의 처치 전후 차이 평균이 0인지 검정하는 모수 검정.
- 목적 : 동일 피험자의 사전-사후 효과 검증.
- 배경 : 개체 간 개인차로 인한 노이즈 제거 필요.
- 특징 : 차이값 단일표본 변환, 검정력 향상, 비모수 대안(윌콕슨).

## Ⅱ. 특징 및 장점

- 핵심 요약 : **개체 편차 제거**로 순수 처치 효과를 높은 검정력으로 검출.
- **개체 편차 상쇄** : 전-후 차이로 개인차 완벽 제거.
- **검정력 향상** : 독립표본 대비 순수 효과 검출.
- **단일표본 변환** : 차이값 $d$의 평균이 0인지 검정.
- **비모수 대안** : 정규성 위반 시 윌콕슨 부호순위.
- **설계 유연성** : 교차 설계(Crossover) 가능.

## Ⅲ. 검정 절차 흐름

- 핵심 요약 : **차이값 도출 → 정규성 검정 → t-검정/윌콕슨 → 해석**.
- 검정통계량 : $t = \bar d / (s_d/\sqrt n)$, $df = n-1$.
- 귀무가설 : $\mu_d = 0$ (처치 전후 차이 없음).

```text
[ 차이값 d의 정규성 검정 흐름 ]

차이값 d = X_post - X_pre 도출
        |
        v
[Shapiro-Wilk 정규성 검정]
        |
   +----+----+
   |         |
(만족)     (위반)
   v         v
[t-검정]  [윌콕슨 부호순위 검정]
```

```text
[ 대응표본 → 단일표본 변환 ]

개체 | 사전 | 사후 | 차이(d)
-----+------+------+---------
 1   |  80  |  85  |   +5
 2   |  90  |  92  |   +2
 n   |  75  |  83  |   +8
 ===> d의 평균이 0인지 단일표본 t-검정
```

## Ⅳ. 대응 vs 독립 비교

- 핵심 요약 : **개체 편차·검정력·설계** 비교.

| 항목 | 대응표본 t-검정 | 독립표본 t-검정 |
|---|---|---|
| 설계 | 동일/짝지은 개체 | 서로 독립된 두 집단 |
| 개인차 처리 | 차이값으로 상쇄 | 잔차에 포함 |
| 검정력 | 높음 | 상대적으로 낮음 |
| 가정 | 차이값 정규성 | 각 집단 정규성·등분산 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **정규성 위반·역사적 요인·시험 효과**를 비모수·DID·교차 설계로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 정규성 위반 | 소표본에서 차이값 비정규 → 검정력 급감 | Shapiro-Wilk 선행, 윌콕슨, 순열 검정 | p값·검정력 |
| 역사적 요인 | 시간 경과 자연 효과 혼입 | DID, A/B 테스트 | 처치 효과 분리 |
| 시험 효과 | 반복 측정 학습 편향 | 라틴 방격 설계, 세척 기간 | 학습 편향 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **튜닝 전후 검증·교차 설계**로 통계적 입증.
- DB 튜닝 : 동일 쿼리 셋 전/후 1:1 매칭으로 효과 입증.
- UX A/B : 교차 설계(Crossover)로 이월 효과 통제.
- 정규성 검정 선행 의무화.

## Ⅶ. 결론

- 핵심 요약 : 대응표본 t-검정은 **동일 집단 전후 효과** 검증의 기본으로 차이값·정규성·교차 설계가 핵심.
- 답안에는 차이값 변환, 검정통계량, 윌콕슨 대안, 한계·대응을 연결.
