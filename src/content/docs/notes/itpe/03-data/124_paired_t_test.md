## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **대응표본 t-검정**

## 30초 인출

- 본질: 대응표본 t-검정은 짝지은 관측값의 차이 평균을 기준값(보통 0)과 비교하는 검정
- 메커니즘: 짝 관계와 차이 방향을 정해 쌍별 차이 D를 계산하고, 차이의 평균·표준오차로 t = (D̄ − μ0)/(s_D/√n), 자유도 n − 1을 구해 신뢰구간·p값·실무적 크기를 해석
- 통찰: 쌍 내부 비교로 공통 변동을 제거하지만 전후 차이에 시간·부하 변화가 섞이면 효과로 오인하므로 같은 조건으로 짝을 만들고 실행 순서를 무작위화하며 차이값의 분포와 쌍 간 독립성을 확인

<details>
<summary>핵심 용어</summary>

- **대응표본 t-검정(Paired t-test)** : 짝지은 관측의 차이 평균을 검정
- **쌍별 차이 D** : 각 쌍에서 두 조건 값의 차이
- **표준오차** : 차이 평균의 표본 간 변동 s_D/√n
- **독립표본 t-검정** : 서로 다른 두 집단의 평균 비교
- **윌콕슨 부호순위 검정** : 쌍별 차이의 순위를 이용하는 비모수 검정
- **효과 크기·신뢰구간** : 평균 차이의 실질적 크기와 불확실성

</details>

## 2~4교시 25점 답안

## Ⅰ. 대응표본 t-검정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **대응표본 t-검정** 은 짝지은 관측값의 차이 평균을 기준값과 비교하는 검정 |
| 목적 | 짝 간 공통 변동을 반영해 두 조건의 평균 차이 평가 |

## Ⅱ. 특징

| 특징 | 검정상 의미 |
|---|---|
| 쌍 내부 비교 | 같은 대상·조건을 묶어 공통 변동을 차이에서 제거 |
| 차이값 중심 가정 | 원자료보다 쌍별 차이의 분포와 쌍 간 독립성이 중요 |
| 효과와 유의성 구분 | 평균 차이·신뢰구간·p값을 함께 보고 |

## Ⅲ. 검정 절차

```text
짝 관계·차이 방향 정의 → 각 쌍의 D = X2 − X1 계산
   ↓ 쌍 간 독립성·차이 분포·이상치 확인
차이 평균 D̄, 표준편차 s_D → 표준오차 s_D/√n
   ↓
t = (D̄ − μ0) / (s_D/√n), 자유도 n − 1 → 신뢰구간·p값·실무적 효과 해석
```

귀무가설은 보통 H0: μ_D = 0이며 기준은 질문에 맞춰 설정. 소표본은 차이값의 정규성을 확인하고, 큰 표본도 이상치와 쌍 간 의존성을 검토.

## Ⅳ. 대응·독립 표본 검정과 대안 비교

| 방법 | 자료 구조 | 선택 기준 |
|---|---|---|
| 대응표본 t-검정 | 같은 대상·조건의 쌍별 차이 | 차이 평균 검정, 쌍 간 독립성·차이 분포 확인 |
| 독립표본 t-검정 | 서로 다른 두 집단 | 짝이 없을 때, 분산이 다르면 Welch |
| 윌콕슨 부호순위 검정 | 쌍별 차이의 부호·순위 | 정규 가정이 어려울 때 위치 차이 검토 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 전후 차이에 시간·부하 변화가 섞여 효과로 오인 | 같은 질의·서버·부하로 짝을 만들고 실행 순서 무작위화 |
| 쌍 간 독립성·차이 분포 가정 누락 | 반복 측정의 상관과 이상치 확인, 필요 시 설계·검정 변경 |
| p값만으로 개선 크기 단정 | 평균 차이와 신뢰구간을 목표·비용과 함께 해석 |

## Ⅵ. 제언

짝을 만들 수 있으면 대응표본으로 설계하고, 조건을 통제해 차이 평균과 신뢰구간을 보고

```text
짝 설계(조건 통제·순서 무작위) → 차이 분포 확인 → t-검정 → 평균 차이·신뢰구간 보고
```

| 구분 | 독립표본으로 처리 | 제언: 대응표본 설계 |
|---|---|---|
| 공통 변동 | 남음 | 제거 |
| 검정력 | 낮음 | 높아질 수 있음 |
