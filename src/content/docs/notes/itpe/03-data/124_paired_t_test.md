## 답안 골격
```text
[대응 표본 t-검정 (Paired t-test)] ◀━━ 머리: Ⅶ 내 의견 (개체 간 편차 제거를 위한 차이값($D$) 정규성 검증과 사전·사후 성능 효과 판정)
 ┃
 ┣━ Ⅰ 개요 ───── 동일한 실험 대상(개체)에 대해 처리 전과 처리 후를 1:1로 짝지어 측정한 두 데이터의 차이값($D = X_{\text{after}} - X_{\text{before}}$)의 평균이 0인지 검정하는 모수 통계 기법
 ┣━ Ⅱ 특징 ───── 개체 간 고유 분산(개인차) 원천 제거 · 검정력(Power) 대폭 향상 · 차이값($D$)의 정규성 가정 준수 필수 · 자유도 $df = n - 1$
 ┣━ Ⅲ 구조 ───── 귀무가설($H_0: \mu_D = 0$) / 대립가설($H_1: \mu_D \neq 0$) / 검정통계량($t = \frac{\bar{D} - \mu_D}{s_D / \sqrt{n}}$) / 자유도($n-1$)
 ┣━ Ⅳ 흐름 ───── ① 짝지은 표본 수집(전·후) → ② 개체별 차이값($D_i$) 산출 → ③ 차이값($D$)의 정규성 검정(Shapiro-Wilk) → ④ t-통계량 계산 → ⑤ p-value 기반 $H_0$ 기각 판정
 ┣━ Ⅴ 비교 ───── 대응 표본 t-검정 vs 독립 표본 t-검정 vs 윌콕슨 부호순위 검정(Wilcoxon Signed-Rank)
 ┗━ Ⅵ 실무 ───── 차이값의 정규성 가정이 깨졌는데도 무리하게 t-검정을 적용해 1종 오류 유발 / 이월 효과(Carryover Effect) 미통제
```
- 필수 키워드: 대응 표본 t-검정 · 짝지은 데이터(Paired) · 차이값($D$) · 정규성 가정 · 검정통계량($t$) · 자유도($n-1$) · 독립 표본 t-검정 · 윌콕슨 부호순위 검정
- 기출: 131회 `대응 표본 t-검정(Paired t-test)과 독립 표본 t-검정(Independent t-test)의 개념, 기본 가정 및 차이점을 비교 설명하시오.` → Ⅰ 정의 + Ⅱ 기본 가정 + Ⅲ 수식 비교 + Ⅴ 상세 비교표

## 한 줄 본질
- 서로 다른 집단을 비교하면 개인차(잡음 분산)가 너무 커서 시스템 변경의 순수한 효과가 묻힘 → 동일 개체의 '전후 차이($D$)'만 발라내어 단일 표본 t-검정으로 단순화 → 적은 표본으로도 높은 검정력 확보 / 사전 측정이 사후에 영향을 주는 이월 효과 통제 필요

## 핵심 그림
```text
[대응 표본 t-검정의 메커니즘: 전후 차이값(D) 추출]

  [개체 ID]    [튜닝 전 (X1)]    [튜닝 후 (X2)]    [차이값 (D = X2 - X1)]
     #1           150 ms            110 ms                -40 ms
     #2           320 ms            280 ms                -40 ms   (개인차 제거!)
     #3            80 ms             50 ms                -30 ms
     ...           ...               ...                   ...
                                               
                                               ▼ 단일 표본 t-검정 수행
                                               D̄ : 차이값들의 평균
                                               s_D : 차이값들의 표준편차
                                               t = (D̄ - 0) / (s_D / √n)
```

## 핵심 용어
- 차이값($D = X_2 - X_1$): 짝지어진 두 관측값의 산술적 차이로, 대응 표본 t-검정에서는 두 원래 변수의 분포가 아니라 '이 차이값들의 집합'이 정규분포를 따라야 함
- 이월 효과(Carryover Effect): 1차 처리의 영향이나 경험이 잔류하여 2차 처리 결과에 인위적인 왜곡을 미치는 실험 오염 현상

## 핵심 통찰
- 대응 표본 t-검정의 수학적 본질은 2개 집단 검정이 아니라 '차이값($D$)이라는 단 1개 변수를 가지고 모평균이 0인지 검정하는 단일 표본 t-검정(One-sample t-test)'과 완전히 동일함
- 독립 표본 t-검정을 쓰면 서버 간 하드웨어 사양 차이 때문에 유의한 차이를 못 잡을 것도, 동일 서버 전후를 짝지어 대응 표본으로 돌리면 오차 분산이 대폭 줄어들어 극소수 표본($n=15$)으로도 확실한 차이를 증명 가능
- 주의할 점은 $X_1$과 $X_2$ 각각이 정규분포를 따를 필요는 전혀 없으며, 오직 '차이값($D$)'만이 정규분포를 따르면 됨

## 이웃 토픽과 구분
- 대응 표본 t-검정 vs 독립 표본 t-검정: 대응 표본 = '동일한 집단'의 처리 전후를 짝지어 비교(표본 간 종속, $df = n-1$) / 독립 표본 = '완전히 다른 두 집단'(예: 남성 vs 여성, A그룹 vs B그룹)의 평균을 비교(표본 간 독립, $df = n_1 + n_2 - 2$)

## 문제·원인·대책
- 적용 상황: 데이터베이스 인덱스 튜닝 전후의 30개 대표 쿼리 응답 시간 개선 효과 검증
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 쿼리별 기본 실행 시간이 10ms부터 5,000ms까지 극단적이라 독립 t-검정 시 $p=0.45$로 기각 실패 | 쿼리 복잡도에 따른 고유 분산이 너무 커서 튜닝 효과가 분산에 묻힘 | 동일 쿼리별 전후를 짝지은 대응 표본 t-검정(Paired)으로 전환 | 쿼리 간 편차 제거 및 $p < 0.001$로 유의한 성능 개선 입증 |
| 차이값($D$)의 히스토그램이 심각하게 치우쳐 정규성 가정($p < 0.01$) 위배 | 소수 특정 쿼리의 락 대기로 인한 비정상 극단 차이값 발생 | 비모수 검정인 윌콕슨 부호순위 검정(Wilcoxon Signed-Rank Test) 적용 | 이상치 왜곡 없는 강건한 통계적 유효성 검증 |

## 이렇게 출제된다
- 제131회: "대응 표본 t-검정(Paired t-test)과 독립 표본 t-검정(Independent t-test)의 개념, 적용 요건, 검정통계량 수식 및 분석 절차를 비교 설명하시오." → 요구 포인트: 대응 표본 t-검정 정의 + 차이값($D$)의 정규성 요건 + t-통계량 수식 유도 + 독립 표본 t-검정과의 4대 축 비교표

## 내 의견
- [A/B 테스트와 전후 비교의 혼용 금지] 실무 엔지니어들이 배포 전후 데이터를 가져와 "A/B 테스트 결과 성능이 좋아졌다"고 보고하는 용어 혼동 만연 → 나라면: 시간의 흐름(계절성, 트래픽 변화)이 개입되는 운영 환경에서는 단순 전후 대응 t-검정만으로 배포 효과를 단정하지 않고, 동시간대 무작위 트래픽을 쪼개는 진정한 독립 표본 A/B 테스트를 병행하도록 실험 가이드라인 정립

## 찾아볼 것
- 대응 표본 데이터가 정규성을 만족하지 못할 때 중위수의 차이를 순위 기반으로 검정하는 윌콕슨 부호순위 검정(Wilcoxon Signed-Rank Test)의 통계량 계산법
