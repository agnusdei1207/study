## 연관 키워드

- 이상치(Outlier), 이상치 탐지(Outlier Detection), IQR, Z-Score, 마할라노비스 거리(Mahalanobis Distance)
- LOF, Isolation Forest, AutoEncoder, 윈저라이징(Winsorizing), FDS

## Ⅰ. 이상치의 개요

- 핵심 요약 : 일반적 분포·패턴에서 현저히 벗어난 관측치로 오류일 수도, 핵심 신호일 수도 있는 값.
- 개념 : 데이터셋의 대부분 관측치가 따르는 일반적인 분포나 패턴에서 현저하게 벗어나 다른 메커니즘에 의해 생성된 것으로 의심되는 극단적·이례적 데이터 값.
- 배경 및 필요성 :
  1. 평균 및 분산 왜곡 : 이상치 1개로 표본 평균 왜곡 및 표준편차 과대 추정.
  2. 선형 모델 파괴 : OLS(Ordinary Least Squares) 회귀분석 시 잔차가 큰 이상치의 레버리지(Leverage)에 의한 회귀선 기울기 왜곡.
  3. 거리 기반 알고리즘 성능 저하 : K-Means, KNN(K-Nearest Neighbors) 등 유클리디안 거리 기반 모델의 군집 중심 왜곡.
- 주요 목적 : 단순 측정 오류(입력 오타, 센서 결함)와 사기(Fraud)·침해 사고·희귀 질환 등 핵심 신호(Signal)의 구분 및 적절한 처리.

## Ⅱ. 이상치의 특징

- 핵심 요약 : 오류와 신호의 이중적 성격, 4대 범주의 탐지 기법과 원인별 처리 전략의 대응.

1. 이중적 성격 : 단순 측정 오류일 수도, 비즈니스 관점에서 가장 핵심적 통찰을 내포하는 신호일 수도 있는 양면성.
2. 통계·모델 영향 : 평균·분산 왜곡, 회귀선 왜곡, 거리 기반 알고리즘 성능 저하.
3. 탐지 기법의 4대 범주 : 통계적 기법, 거리 기반 기법, 밀도 기반 기법, 머신러닝·딥러닝 기법.
4. 처리 전략의 원인 의존성 : 발생 원인 분석 결과에 따라 삭제·대체·클리핑·변환·보존의 선택.

```text
[ 이상치 탐지 방법론 분류 ]
 ├─ 통계적 기법     : Z-Score, IQR 사분위수, 정규분포 가정
 ├─ 거리 기반 기법  : KNN 거리, 이웃과의 평균 거리
 ├─ 밀도 기반 기법  : LOF (국소 밀도 비율 비교)
 └─ 머신러닝/딥러닝 : Isolation Forest (고립 깊이), AutoEncoder (재구성 오차)
```

## Ⅲ. 이상치 탐지·처리의 구조 (흐름)

- 핵심 요약 : 이상치 식별 후 발생 원인 분석에 따라 처리 전략을 선택하는 의사결정 흐름.

```text
[ 이상치 처리 의사결정 트리 ]
 이상치 식별 → 발생 원인 분석
  ├─ 단순 오류 (오타, 센서 고장) : 삭제(Deletion) 또는 대체(Imputation)
  ├─ 자연적 극단값 (VIP 매출)    : 윈저라이징(Winsorizing) 또는 로그 변환
  └─ 탐지 자체가 목적 (FDS)      : 라벨링 후 탐지 모델 특징으로 보존
```

- 이상치 처리 4대 전략 :
  1. 삭제(Trimming/Deletion) : 데이터 오류가 명백하거나 전체 데이터 대비 극소수일 때 행 제거.
  2. 대체(Imputation) : 중위수(Median), 최빈값 또는 KNN·회귀 모델 기반 추정값의 대체.
  3. 윈저라이징(Winsorizing/Capping) : 상위 1% 초과 값의 99 백분위수 변환, 하위 1% 미만 값의 1 백분위수 변환 클리핑.
  4. 변수 변환(Transformation) : 로그(Log), 제곱근(Square Root), Box-Cox 변환을 통한 왜도(Skewness) 축소 및 정규성 확보.

## Ⅳ. 이상치 탐지 기법의 비교

- 핵심 요약 : 단변량 통계의 간편성부터 딥러닝의 비선형 탐지까지 데이터 특성별 기법 선택.

| 분류 | 대표 기법 | 핵심 판정 메커니즘 | 장점 및 적용 환경 | 단점 및 한계 |
|---|---|---|---|---|
| 단변량 통계 | IQR(Interquartile Range) 기법(Box-Plot) | Q1 − 1.5×IQR 미만 또는 Q3 + 1.5×IQR 초과(IQR = Q3 − Q1) | 정규분포 가정 불필요, 비모수적 직관 방식 | 다변량 간 상관관계 반영 불가 |
| 단변량 통계 | Z-Score / Modified Z | Z = (x − μ) / σ의 절대값 3 이상 판정, 중위수 기반 MAD(Median Absolute Deviation) 활용 권장 | 계산 간편, 표준 정규분포 기반 | 이상치 자체가 μ·σ를 왜곡(Masking Effect), 정규분포 가정 필수 |
| 다변량 통계 | 마할라노비스 거리(Mahalanobis Distance) | 공분산 행렬 Σ 반영 거리 D² = (x−μ)ᵀ Σ⁻¹ (x−μ) | 변수 간 상관성을 고려한 다차원 공간 거리 측정 | 다변량 정규성 가정 필요, 고차원에서 역행렬 계산 불안정 |
| 밀도 기반 | LOF(Local Outlier Factor) | 데이터 포인트 주변 k-최근접 이웃의 국소 밀도(Local Reachability Density) 비율 비교 | 밀도가 서로 다른 군집이 혼재한 복합 데이터셋에서 강력 | O(n²)의 높은 연산 복잡도 |
| 트리 기반 | Isolation Forest | 무작위 속성·분할점의 격리 트리 구성 후 고립 깊이(Path Length) 측정 | 평균 깊이가 짧을수록 이상치 판정, O(n log n) 고속·대규모 고차원 최적 | 하이퍼파라미터(트리 수, 샘플 크기) 튜닝 필요 |
| 딥러닝 | AutoEncoder | 입력의 저차원 압축 후 복원 시 재구성 오차(Reconstruction Error) 측정 | 비선형 고차원(이미지, 센서 로그) 이상 탐지 탁월 | 모델 학습 비용 높음, 블랙박스 특성 |

## Ⅴ. 이상치 탐지·처리의 장점과 한계

- 핵심 요약 : 핵심 이벤트 조기 감지의 장점과 다변량 탐지 실패·오탐·실시간 연산 부하의 한계.

- 장점
  1. 사기·침해·설비 이상 등 핵심 이벤트의 조기 감지.
  2. 데이터 품질 개선 및 모델 성능 보호.
  3. 통계·밀도·트리·딥러닝 기반의 다층 기법 선택지.

- 한계점 1 : 단변량 통계 기법(IQR, Z-Score)의 다변량 복합 이상치 탐지 실패
  - 한계점 : 각 피처 개별로는 정상 범위 내이나 변수 간 상관관계상 심각한 이상 패턴(예: 신장 190cm, 체중 35kg)의 다변량 이상치 식별 불가.
  - 해결 방안 : 마할라노비스 거리(Mahalanobis Distance), Isolation Forest, LOF(Local Outlier Factor) 등 다차원 공간의 밀도·거리 기반 알고리즘 적용.
- 한계점 2 : 불균형 데이터셋에서 희귀 정상 이벤트의 오탐(False Positive) 위험
  - 한계점 : 금융 사기 탐지 시스템(FDS, Fraud Detection System), 설비 장애 등 희귀하지만 극도로 중요한 정상 특이치의 이상치 오판·삭제·대체 시 중대한 모델 오작동 유발.
  - 해결 방안 : 도메인 전문가 기반 검증 루프(Human-in-the-loop) 연계, 오토인코더(Autoencoder) 복원 오차 기반 점수화 및 준지도 학습(Semi-supervised) 기법 활용.
- 한계점 3 : 대규모 스트리밍 데이터 환경의 실시간 탐지 연산 오버헤드
  - 한계점 : 고차원 벡터의 실시간 밀도 기반 탐지(LOF) 수행 시 O(N²) 이상의 시간 복잡도로 인메모리 버퍼 오버플로우 및 처리 지연 발생.
  - 해결 방안 : 롤링 윈도우(Sliding Window) 기반 증분(Incremental) 업데이트 모델(Half-Space Trees, RRCF(Robust Random Cut Forest)) 채택, 스트림 처리 프레임워크(Apache Flink) 분산 파이프라인 구축.

## Ⅵ. 이상치 관리를 위한 기술사적 제언

- 핵심 요약 : 도메인 전문가 협업, Robust 모델 채택, 스트리밍 실시간 감지 체계.
- 도메인 전문가와의 협업 필수 : 통계적 이상치가 핵심 신규 고객군 또는 신종 금융 사기 패턴일 수 있어 자동 삭제 파이프라인 적용 전 업무 규칙 기반 화이트리스트 검토 필요.
- Robust 모델 알고리즘 채택 : 이상치의 인위적 가공보다 이상치에 둔감한 비모수적 모델(XGBoost, LightGBM 등 Tree 계열) 또는 Huber Loss, L1 정규화 기반 회귀 모델 채택을 통한 데이터 원형 보존.
- 스트리밍 파이프라인 내 실시간 감지 : 사후 배치 분석 지양, Apache Flink 등 스트리밍 엔진의 Z-Score·Isolation Forest 점수 산출 로직 탑재를 통한 이상치 발생 즉시 알림·차단 조치.

## Ⅶ. 결론

- 핵심 요약 : 이상치 관리는 기법 선택 이전에 원인 판별과 도메인 검증이 선행되어야 하는 영역.
- 요약 : 4대 범주 탐지 기법과 원인별 처리 4대 전략의 의사결정 체계.
- 시사점 : 오탐 방지의 도메인 검증과 Robust 모델·실시간 감지의 병행 필요.
