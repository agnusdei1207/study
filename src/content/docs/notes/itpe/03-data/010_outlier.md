
과목 내 현재 키워드: 03 데이터 → 이상치

## 큰 그림과 30초 인출

```text
[관측 데이터] → 시각화·분포·업무규칙 → 이상 후보 탐지
                                         │
                      ┌──────────────────┼──────────────────┐
                      ▼                  ▼                  ▼
                  입력 오류          정상 극단값        관심 사건
                  수정·제외          강건 처리          별도 탐지·대응
```

- 본질: **대다수 관측 패턴에서 크게 벗어난 값으로, 오류일 수도 있고 사기·고장·희귀현상 같은 핵심 신호일 수도 있는 관측치**
- 암기: `탐-확-분-처-검` = 탐지 → 확인 → 분류 → 처리 → 검증
- 원칙: 알고리즘이 이상 후보를 찾고, 도메인 검토가 의미와 조치를 확정

## 예상문제

> 이상치의 개념과 유형, 탐지기법을 설명하고 이상치·노이즈를 구분하여 분석 목적별 처리 및 운영 고려사항을 논하시오. (25점)

## Ⅰ. 데이터 왜곡이자 희귀 신호인 이상치 개요

- 정의: 이상치는 데이터 집합의 일반적 분포·관계·시간 패턴 또는 업무규칙에서 현저히 벗어나는 관측치
- 영향: 평균·분산·회귀계수·군집 중심 왜곡, 모델 학습 불안정, 품질 저하
- 가치: 금융사기·침입·설비고장처럼 이상 자체가 탐지 대상이면 제거가 아니라 식별·대응해야 함

#### 한줄 요약

- 이상치는 통계적 거리만으로 삭제할 값이 아니라 발생 원인과 분석 목적에 따라 의미가 달라지는 후보임

## Ⅱ. 발생 원인과 맥락에 따른 이상치 유형

| 유형 | 의미 | 예시 | 판단 포인트 |
|---|---|---|---|
| 전역 이상 | 전체 분포에서 멀리 떨어짐 | 비정상적으로 큰 거래액 | 단변량·다변량 거리 |
| 조건부 이상 | 특정 시간·집단·상황에서만 비정상 | 여름의 저온, 야간 대량접속 | 맥락변수·계절성 |
| 집단 이상 | 개별 값은 정상이나 연속·집합 패턴이 비정상 | 짧은 시간의 반복 소액결제 | Sequence·Window |
| 오류 이상 | 측정·입력·연계 오류 | 단위·센서·코드 오류 | 원천·계보·업무규칙 |
| 유효 희귀값 | 실제 발생한 드문 사건 | 설비고장·사기 | 보존·조사·대응 |

## Ⅲ. 통계·거리·밀도·격리 기반 탐지기법

```text
단변량 통계: Z-score / IQR
다변량 거리: Mahalanobis / k-NN distance
국소 밀도:   LOF / DBSCAN
격리·경계:   Isolation Forest / One-Class SVM
시계열:      잔차·Change Point·Window 비교
```

| 기법 | 원리 | 강점 | 한계 |
|---|---|---|---|
| IQR | Q1·Q3와 사분위 범위 경계 | 단순·강건·설명 용이 | 다변량 관계 미반영 |
| Z-score | 평균에서 표준편차 단위 거리 | 계산 간단 | 분포 가정·극단값 영향 |
| Mahalanobis | 공분산을 반영한 다변량 거리 | 변수 상관 반영 | 공분산 추정 민감 |
| LOF | 이웃 대비 국소 밀도 비교 | 지역별 밀도 차이 탐지 | k·거리·고차원 민감 |
| Isolation Forest | 무작위 분할의 짧은 격리경로 | 대규모·다변량 적용 | 점수 기준·해석 필요 |

```text
IQR = Q3 - Q1
하한 = Q1 - 1.5×IQR     상한 = Q3 + 1.5×IQR
```

- IQR 경계는 보편적 삭제선이 아니라 탐색용 후보 기준이며 업무·분포 맥락으로 재판정

## Ⅳ. 이상치 탐지·판정·처리 절차

```text
① 목적·오류비용 정의 → ② 품질·분포·시각화 → ③ 복수 기법으로 후보 탐지
 → ④ 원천·계보·업무 맥락 확인 → ⑤ 오류/극단/관심사건 분류
 → ⑥ 수정·제외·변환·강건모형·별도모델 → ⑦ 영향·재현성 검증
```

| 처리 | 적용 조건 | 주의사항 |
|---|---|---|
| 원천 수정 | 입력·센서·연계 오류가 확인됨 | 수정이력·원본 보존 |
| 삭제 | 오류이며 복구 불가, 영향이 설명됨 | 표본편향·정보손실 검증 |
| 대체·Winsorizing | 극단값 영향 완화가 목적 | 임계값 근거·원값 보존 |
| 변환·강건통계 | 왜도가 크고 유효 극단값 존재 | 역변환·해석 가능성 |
| 별도 모델·경보 | 이상이 관심 사건 | 불균형·오탐/미탐 비용 |

## Ⅴ. 이상치·노이즈·변화점·편향 비교

| 구분 | 이상치 | 노이즈 | 변화점 | 편향 |
|---|---|---|---|---|
| 의미 | 일반 패턴에서 벗어난 관측 | 무작위 측정·전송 오차 | 생성 과정의 구조적 전환 | 표본·측정·모형의 체계적 치우침 |
| 범위 | 개별·조건부·집단 | 전반적 변동 | 시점 전후 구간 | 데이터·결과 전체 |
| 가치 | 오류 또는 희귀 신호 | 주로 제거·완화 대상 | 새로운 상태 신호 | 공정성·일반화 위험 |
| 대응 | 원인별 분류·처리 | 필터·평활·센서개선 | 구간 분리·재학습 | 표본·측정·모형 개선 |

## Ⅵ. 기계적 삭제를 막는 실무 고려사항

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 실제 사기·고장을 삭제 | 통계 경계를 품질오류로 단정 | 원천·도메인 확인, 관심사건 별도 라벨·보존 | 핵심 신호 보호 |
| 특정 집단이 과다 탐지 | 전역 임계값과 대표성 부족 | 집단·맥락별 성능, 오탐/미탐 비용 검증 | 편향 완화 |
| 고차원 탐지 불안정 | 거리집중·불필요 변수 | 변수선택·표현축소·복수기법 안정성 평가 | 탐지 신뢰도 향상 |
| 실시간 경보 폭주 | 임계값·계절성·중복 사건 미반영 | 동적 기준·Window·억제·사건 묶음·피드백 | 운영 가능한 경보 |
| 처리 후 모델효과 불명 | 원본·처리 이력·비교실험 부재 | 원본 보존, Pipeline 버전, 처리 전후 성능 비교 | 재현성·감사성 확보 |

## Ⅶ. 이상점수가 아닌 원인과 행동을 관리하는 결론

- **[후보-판정-조치-피드백의 폐루프]**: 이상점수만 생성하면 오탐이 쌓이고 현업은 경보를 무시하며 모델은 개선되지 않음
- 나라면: 후보마다 원천값·맥락·판정사유·조치결과를 기록하고 이를 탐지모델의 Threshold·Feature·라벨 개선에 환류

#### 한줄 요약

- 이상치 관리의 완성은 많이 삭제하는 것이 아니라 중요한 희귀사건을 놓치지 않으면서 오류를 재발 방지하는 것임

## 1교시 10점 답안 발췌

```text
탐지 → 원천·맥락 확인 → 오류/유효극단/관심사건 분류 → 목적별 처리 → 영향검증
```

| 계열 | 기법 |
|---|---|
| 통계 | IQR·Z-score |
| 거리·밀도 | Mahalanobis·k-NN·LOF |
| 격리·경계 | Isolation Forest·One-Class SVM |

- 차별화: IQR은 삭제선이 아닌 후보 기준이며 후보-판정-조치 피드백을 운영
