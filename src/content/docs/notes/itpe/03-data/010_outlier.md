## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 → **이상치(탐지 기법·노이즈 구분)**

## 30초 인출

- 본질: 이상치는 데이터의 일반적인 분포나 패턴에서 크게 벗어난 관측치이며, 오류로 생긴 불필요한 변동인 노이즈와 구별
- 메커니즘: 통계 기준(IQR·Z-score)이나 밀도·거리·고립 기반 방법으로 벗어난 정도를 계산해 후보를 찾고 원인을 확인해 처리
- 통찰: 이상치는 오류일 수도 있고 중요한 신호일 수도 있으므로 값을 무조건 삭제하지 않고 원인을 확인한 뒤 오류면 수정·제거, 실제 현상이면 유지·별도 분석

<details>
<summary>핵심 용어</summary>

- **이상치(Outlier)** : 다른 관측치와 크게 다른 값이나 패턴
- **노이즈(Noise)** : 측정·입력·전송 과정의 오류로 생긴 불필요한 변동
- **IQR(사분위범위)** : 제3사분위수와 제1사분위수의 차이
- **Z-score** : 값이 평균에서 표준편차 몇 배 떨어졌는지 나타내는 점수
- **LOF(Local Outlier Factor)** : 주변 점의 밀도와 비교해 국소적으로 드문 점을 찾는 방법
- **Isolation Forest** : 무작위 분할로 쉽게 고립되는 관측치를 이상치로 보는 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. 이상치의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **이상치** 는 데이터의 일반적인 분포·패턴에서 크게 벗어난 관측치 |
| 목적 | 분석 왜곡의 방지와 이상 현상의 발견 |

## Ⅱ. 이상치와 노이즈의 차이

| 구분 | 이상치 | 노이즈 |
|---|---|---|
| 의미 | 정상 패턴에서 벗어난 값 | 측정·입력 오류로 생긴 불필요한 변동 |
| 실제 현상 여부 | 실제 현상일 수 있음 | 오류 |
| 처리 | 원인 확인 후 판단 | 제거·보정 |

## Ⅲ. 이상치 유형과 탐지

### 이상치의 세 가지 유형

```text
전역 이상치 : 전체 분포에서 동떨어진 값        예) 나이 250
맥락 이상치 : 상황·시점을 고려할 때만 비정상    예) 한여름 난방 사용량 급증
군집 이상치 : 개별은 정상이나 무리로 볼 때 이상  예) 같은 시각의 소규모 비정상 거래 묶음
```

### 탐지 방법

| 방법 | 원리 | 적합 조건 |
|---|---|---|
| IQR | 사분위 범위를 벗어난 값 | 분포가 치우친 단일 변수 |
| Z-score | 평균에서 표준편차 배수 | 정규분포에 가까운 변수 |
| LOF | 주변 밀도와 비교 | 밀도가 다른 군집 |
| Isolation Forest | 쉽게 고립되는 관측치 | 고차원 데이터 |

## Ⅳ. 처리 방법과 영향

| 원인 | 처리 |
|---|---|
| 입력·측정 오류 | 수정 또는 제거 |
| 실제 현상 | 유지하고 강건한 방법 적용 또는 별도 분석 |
| 판단 불명확 | 도메인 전문가 확인 |

이상치는 평균·분산·회귀 계수를 크게 왜곡하고, 사기 탐지·설비 이상 감지에서는 핵심 신호

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 정상 변동까지 이상치로 삭제 | 삭제 전 원인 확인 |
| 유형별로 탐지 방법이 다름 | 전역은 통계 기준, 맥락은 시점·집단 기준으로 구분 |
| 고차원에서 통계 기준의 한계 | 밀도·고립 기반 방법 활용 |

## Ⅵ. 제언

이상치는 삭제하기 전에 원인을 확인하고, 오류는 수정·제거하며 실제 현상은 유지해 별도로 분석

```text
이상치 후보 → 원인 확인 ─ 입력·측정 오류 → 수정·제거
                        └ 실제 현상 → 유지 + 강건한 분석 또는 별도 분석
```

| 구분 | 일괄 삭제 | 제언: 원인 확인 후 처리 |
|---|---|---|
| 중요한 신호 | 손실 | 보존 |
| 분석 왜곡 | 완화 | 방법으로 통제 |
