## 연관 키워드
- 이상치, 단변량·다변량, IQR, Z점수, 강건통계, 이상탐지

### Ⅰ. 이상치의 개요

- 핵심 요약 : 이상치는 관측 분포나 데이터 생성 맥락에서 다른 값과 현저히 벗어나는 관측값.
-概念 : 관측 분포나 데이터 생성 맥락에서 다른 값과 현저히 벗어나는 관측값(**이상치**, Outlier).
- 배경 및 필요성 : 입력 오류일 수도 있고 희귀하지만 중요한 사건일 수도 있어 분석결과를 왜곡하거나 중요한 위험을 나타냄.
- 주요 목적 : 이상치의 원인·업무 의미를 파악해 보정·보존·격리 판단.

### Ⅱ. 이상치의 특징 및 장점

- 핵심 요약 : 분포 민감성·탐지 방법 다양·맥락 의존은 이상치를 식별하고 목적에 따라 보정하거나 보존하는 데이터 분석 방식.

1. 분포 민감성 : 평균·분산·회귀에 큰 영향 → 강건통계 고려.
2. 탐지 방법 다양 : IQR·Z점수·거리·밀도 기반 → 분포·차원에 맞춤.
3. 맥락 의존 : 통계적 극단과 오류는 동일하지 않음 → 원천 검증 필요.

### Ⅲ. 이상치의 구조 (흐름)

- 핵심 요약 : 분포·업무기준 설정 → 탐지·표시 → 원천·맥락 검증 → 오류 보정 또는 사건 보존 → 민감도 분석.

```text
분포·업무기준 설정
  ↓
탐지·표시
  ↓
원천·맥락 검증
  ↓
오류 보정 또는 사건 보존
  ↓
민감도 분석
```

```text
관측값 → 탐지 규칙(IQR·강건 Z·모델)
                    ↓
오류? ─ 예 → 정정·격리
  └ 아니오 → 희귀사건으로 보존·해석
```

### Ⅳ. 이상치 탐지와 이상치 처리 비교

- 핵심 요약 : 위험 기준 — 이상치 탐지: 오탐·미탐 가능; 이상치 처리: 삭제로 중요한 신호 손실 가능.

| 비교 축 | 이상치 탐지 | 이상치 처리 |
|---|---|---|
| 목적 | 의심 관측값 식별 | 식별된 값의 보정·제거·유지 결정 |
| 위험 | 오탐·미탐 가능 | 삭제로 중요한 신호 손실 가능 |

### Ⅴ. 이상치의 한계와 방안

- 핵심 요약 : 단일 임계값 의존·무조건 삭제 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 단일 임계값 의존 | 분포 비대칭·계절성에서 정상값 오탐 | 구간·계절·집단별 기준과 robust 방법 적용 | 오탐·미탐률 |
| 무조건 삭제 | 희귀 사건·사기·장애 신호 손실 | 원인 확인 전 원자료 보존·분석 민감도 비교 | 제거 후 성능 변화 |
| 고차원 탐지 어려움 | 변수별 정상이어도 조합상 이상일 수 있음 | 도메인지식·다변량 탐지·설명 도구 병행 | 검토된 이상 비율 |

### Ⅵ. 이상치에 대한 제언

- 핵심 요약 : 데이터 분석가는 원본을 보존하고 탐지 근거·조치·변환 이력을 기록하며 제외 전후 결과와 업무 영향 모두 비교.

- 실행 제안 : 분석팀은 의심값 원본과 처리 이력을 보존하고 삭제 전후 추정·예측 결과를 비교 승인.

### Ⅶ. 결론

- 핵심 요약 : 이상치는 자동 삭제 대상이 아니라 품질 오류와 가치 있는 희귀 사건을 구별해야 하는 조사 신호.
- 시사점 : 극단값은 오류일 수도 중요한 희귀사건일 수도 있으므로 탐지와 삭제를 동일시하지 말 것.
