## 연관 키워드

- 이상치(Outlier), 이상치 탐지(Outlier Detection), 사분위수 범위(IQR, Interquartile Range), Z-Score, 마할라노비스 거리(Mahalanobis Distance)
- LOF(Local Outlier Factor), Isolation Forest, AutoEncoder, 윈저라이징(Winsorizing), 부정 거래 탐지 시스템(FDS)

## Ⅰ. 이상치의 개요

- 핵심 요약 : 대다수 관측치의 분포와 패턴에서 현저히 벗어난 값으로, 오류와 핵심 신호의 성격을 동시에 지닌 데이터.
- 개념 : 대부분의 관측치가 따르는 분포나 패턴에서 현저히 벗어나, 생성 메커니즘이 다를 것으로 의심되는 값인 **이상치** (Outlier).
- 배경 및 필요성 :
  1. 통계량 왜곡 : 극단값 하나가 평균과 분산의 추정을 치우치게 함.
  2. 모델 성능 저하 : 회귀선의 기울기와 거리 기반 알고리즘의 판정 왜곡.
  3. 품질 신호 : 오타, 센서 결함 같은 입력 오류의 존재 표시.
- 주요 목적 : 측정 오류와 의미 있는 극단 신호의 구분과, 원인에 맞는 탐지·처리의 수행.

## Ⅱ. 이상치 탐지·처리의 특징 및 장점

- 핵심 요약 : 통계·거리·밀도·학습 기반의 **이상치 탐지** (Outlier Detection) 4대 체계와 원인별 처리 전략이 분석 신뢰성의 방어선.

1. 통계적 기법 : **Z-Score**의 표준편차 배수 판정, **사분위수 범위** (IQR, Interquartile Range)의 경계 판정 → 단변량 데이터의 신속 선별.
2. 거리 기반 기법 : **마할라노비스 거리** (Mahalanobis Distance)의 공분산 반영 거리 측정 → 변수 간 상관을 고려한 판정.
3. 밀도 기반 기법 : **LOF** (Local Outlier Factor)의 국소 밀도 비율 비교 → 밀도가 다른 군집이 섞인 데이터의 탐지.
4. 학습 기반 기법 : **Isolation Forest**의 무작위 분할 고립 깊이 측정, **AutoEncoder**의 재구성 오차 측정 → 고차원·비선형 데이터의 대응.
5. 원인 기반 처리 : 탐지 후 발생 원인을 규명하고 전략을 선택 → 정보 손실과 데이터 오염의 균형 유지.

## Ⅲ. 이상치 탐지·처리의 구조 (흐름)

- 핵심 요약 : 탐지 기법의 4대 범주와, 식별→원인 분석→전략 선택→검증의 처리 의사결정 흐름.

```text
[ 탐지 기법 4대 범주 ]

통계적 기법
  Z-Score, IQR
        ↓
거리·밀도 기반 기법
  마할라노비스 거리, LOF
        ↓
학습 기반 기법
  Isolation Forest, AutoEncoder
```

```text
[ 처리 의사결정 흐름 ]

탐지 기법의 적용과 식별
        ↓
발생 원인 분석
  오류 발생 vs 자연적 신호
        ↓
원인별 처리 전략 선택
        ↓
처리 후 재분석으로 검증
```

- 처리 전략 4종 :
  1. 삭제(Trimming) : 명백한 입력 오류나 극소수 관측치의 제거.
  2. 대체(Imputation) : 중위수나 모델 추정값으로의 치환.
  3. **윈저라이징** (Winsorizing) : 설정한 백분위수 경계 바깥의 값을 경계값으로 절단.
  4. 변수 변환(Transformation) : 로그·제곱근 변환으로 왜도 완화와 정규성 확보.
- 보존 판단 : 부정 거래 탐지 시스템(FDS, Fraud Detection System)처럼 탐지 자체가 목적인 영역에서는 이상치를 분석 변수로 보존.

## Ⅳ. 이상치 탐지 기법들의 비교

- 핵심 요약 : 변수 개수·분포 가정·데이터 규모에 따라 대표 기법의 선택이 갈림.

| 분류 | 대표 기법 | 판정 메커니즘 | 적합 환경 | 한계 |
| --- | --- | --- | --- | --- |
| 단변량 통계 | Z-Score | 평균 대비 표준편차 배수 판정 | 정규분포 근사 데이터 | 극단값에 기준 자체가 왜곡 |
| 단변량 통계 | IQR | 사분위수 경계 밖 판정 | 정규성 가정이 어려운 데이터 | 변수 간 관계 미반영 |
| 다변량 통계 | 마할라노비스 거리 | 공분산 행렬 반영 거리 | 변수 간 상관 데이터 | 다변량 정규성 가정 필요 |
| 밀도 기반 | LOF | 이웃과의 국소 밀도 비율 | 밀도가 다른 군집 혼재 | 연산 부담 |
| 트리 기반 | Isolation Forest | 고립까지의 분할 깊이 | 대규모·고차원 데이터 | 하이퍼파라미터 튜닝 필요 |
| 신경망 기반 | AutoEncoder | 재구성 오차 | 비선형·이미지·센서 로그 | 학습 비용과 해석 곤란 |

- 선택 기준 :
  1. 분석 변수가 단일인지 다중인지, 분포 가정의 성립 여부 확인.
  2. 데이터 규모와 실시간 처리 요구의 검토.
  3. 판정 근거의 설명 가능성 요구 수준 반영.

## Ⅴ. 이상치 탐지·처리의 한계와 방안

- 핵심 요약 : 다변량 미탐지, 희귀 정상 이벤트의 오탐, 고정 기준의 부적합을 다변량 기법·검증 절차·적응형 기준으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 다변량 이상치의 미탐지 | 각 변수는 정상이어도 조합이 이상한 패턴 존재 | 마할라노비스 거리, LOF 같은 다변량 기법 병행 | 다변량 탐지 건수 |
| 희귀 정상 이벤트의 오탐 | 드물지만 중요한 정상값의 오판과 삭제 → 정보 손실 | 도메인 전문가 검증 후 처리, 점수화 기반 보류 | 오탐률 |
| 고정 임계값의 부적합 | 계절·추세 변화에 판정 기준 부동 → 탐지율 저하 | 적응형 임계값과 주기적 재학습 | 재학습 주기별 탐지율 |

## Ⅵ. 이상치에 대한 기술사적 제언

- 핵심 요약 : 판정 협의체, 처리 이력 관리, 실시간 감지 인프라의 조직적 정비 필요.
- 조직 : 통계 담당자와 현업 전문가가 참여하는 이상치 판정 협의체를 상시 운영해 자동 판정의 맹목성 보완.
- 제도 : 이상치 처리 이력과 근거의 기록 절차를 데이터 관리 규정에 편입해 판정의 추적성 확보.
- 인프라 : 실시간 탐지 점수 산출과 알림 체계를 스트리밍 플랫폼에 통합하는 투자 추진.

## Ⅶ. 결론

- 핵심 요약 : 이상치는 제거 대상이 아니라 원인 판별과 활용의 대상인 데이터 자산.
- 탐지 점수와 도메인 판단의 결합이 분석 신뢰성과 신규 인사이트를 동시에 확보함.
