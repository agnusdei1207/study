```text
[이상치] ◀━━ 머리: Ⅶ 내 의견 (일괄 삭제 지양 → 도메인 분리 분석 및 윈저라이징/강건 통계량 적용)
 ┃
 ┣━ Ⅰ 개요 ───── 대부분의 데이터 패턴과 현저히 동떨어진 관측치 → 모델 왜곡 유발 또는 핵심 신호(사기/고장) 제공
 ┣━ Ⅱ 특징 ───── 모수 추정량(평균/분산) 왜곡 · 이상치의 이중성(제거 대상 잡음 vs 탐지 대상 가치)
 ┣━ Ⅲ 구조 ───── 통계적 탐지(Z-score, IQR) / 머신러닝 탐지(Isolation Forest, One-Class SVM, LOF)
 ┣━ Ⅳ 흐름 ───── ① 데이터 분포 시각화(Boxplot) → ② 이상치 진단 → ③ 원인 분석(오류 vs 참값) → ④ 처리(삭제/대체/격리)
 ┣━ Ⅴ 비교 ───── 이상치 탐지 기법 (통계적 IQR vs 거리기반 KNN vs 밀도기반 LOF vs 앙상블 iForest)
 ┗━ Ⅵ 실무 ───── 기계적 삭제로 인한 핵심 정보 손실 / 왜곡된 회귀선 도출 / 실시간 스트림 탐지 지연
```
- 필수 키워드: IQR(사분위수 범위) · Z-Score · Isolation Forest · LOF(Local Outlier Factor) · 윈저라이징(Winsorizing) · 이상치 vs 노이즈
- 배점 전략: 10점 = Ⅰ → Ⅲ 탐지 기법 도식(IQR 수식) → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅲ 탐지 기법 및 처리 방안 비교표
- 기출: 139회 `이상치와 편향의 개념 및 영향/처리 방안` → Ⅰ 개념 + Ⅵ 영향 및 처리 / 136회 `아웃라이어(Outlier)` → Ⅲ 탐지 알고리즘 및 실무 적용

## 한 줄 본질
- 정상 분포의 범위를 벗어나 평균과 회귀선을 심각하게 왜곡시키는 관측값 → 통계적 경계와 트리 격리 알고리즘으로 분리 식별 → 모델 안정성 확보 또는 사기/장애 신호 감지 / 정상 특이 패턴과의 오판 위험 상존

## 핵심 그림
```text
[IQR 기반 이상치 판정 기준 (Box Plot)]
      최솟값         Q1        중앙값(Q2)      Q3         최댓값
        ├───[────────┼───────────]───┤       * 이상치 (Outlier)
   (Q1 - 1.5*IQR)           IQR          (Q3 + 1.5*IQR)
                      <─────────>
                      (Q3 - Q1)
```

## 핵심 용어
- IQR(Interquartile Range): 데이터의 제3사분위수(Q75)에서 제1사분위수(Q25)를 뺀 범위로, $Q1 - 1.5 \times IQR$ 미만이거나 $Q3 + 1.5 \times IQR$ 초과인 값을 이상치로 판정
- Isolation Forest: 데이터를 랜덤하게 분할하는 의사결정나무를 만들 때, 이상치는 정상 데이터보다 몇 번의 분기만으로 빠르게 고립(Isolation)된다는 원리를 이용한 앙상블 탐지 기법

## 핵심 통찰
- 평균(Mean)과 표준편차는 이상치에 극도로 취약함 → 100명 중 1명의 억만장자가 포함되면 평균 소득이 왜곡되므로, 중앙값(Median)과 IQR 같은 비모수 강건 통계량(Robust Statistics)을 사용해야 함
- 이상치는 '버려야 할 쓰레기'가 아닐 수 있음 → 금융 부정 결제(FDS), 네트워크 침입(IDS), 제조 설비 고장 예지에서는 이상치 자체가 가장 귀중한 비즈니스 타겟 신호
- 일괄 삭제는 표본 편향(Sample Selection Bias)을 부름 → 이상치 발생 원인이 단순 오기재인지 실제 극한 현상인지 분리하지 않고 지우면 실제 세계를 반영하지 못함

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 윈저라이징(Winsorization) | 이상치 대체 기법 | 이상치를 삭제하지 않고 상위 99% 또는 95% 백분위수 값으로 치환하여 분산 축소 |
| LOF(Local Outlier Factor) | 밀도 기반 탐지 | 주변 이웃들의 국소 밀도 대비 해당 관측치의 밀도를 비교하여 이상치 점수 산출 |

## 이웃 토픽과 구분
- 이상치 vs 노이즈: 노이즈 = 데이터 수집 과정에서 섞인 무작위적이고 무의미한 측정 오차 / 이상치 = 통계적으로 드물지만 도메인 맥락에서 중대한 원인이나 가치를 지닌 관측값

## 문제·원인·대책
- 적용 상황: 카드사 실시간 해외 이상 부정 결제(FDS) 탐지 시스템
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 정상 해외 출장자의 결제가 차단되어 고객 민원 발생 | 정적 규칙(단순 금액 초과) 기반 이상치 차단 | Isolation Forest 및 시계열 행동 패턴 기반 동적 스코어링 적용 | 오탐(False Positive) 50% 이상 감소 |
| 선형 회귀 모델의 결정계수($R^2$)가 0.1로 급락 | 소수의 극단값 데이터로 인한 회귀선 기울기 왜곡 | RANSAC(RANdom SAmple Consensus) 강건 회귀 적용 | 이상치 제외한 핵심 데이터셋 피팅 |
