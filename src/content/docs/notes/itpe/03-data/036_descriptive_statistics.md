## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **기술통계와 추론통계**

## 30초 인출

- 본질: 기술통계는 관측한 자료의 중심·산포·분포를 요약하는 방법이고, 추론통계는 표본을 근거로 모집단의 모수나 가설을 판단하는 방법
- 메커니즘: 관측값을 평균·중앙값·분산·분위수로 요약하고, 모집단에 대한 질문이 있으면 표본 설계와 가정을 확인해 추정·검정으로 결론과 불확실성을 보고
- 통찰: 표본이 대표성이 없거나 가정이 어긋나면 계산이 정확해도 모집단 결론이 치우치므로 요약 결과와 일반화 결론을 구분하고 자료 분포에 맞는 지표를 선택

<details>
<summary>핵심 용어</summary>

- **기술통계(Descriptive Statistics)** : 관측 자료를 요약·기술하는 통계
- **추론통계(Inferential Statistics)** : 표본으로 모집단에 대해 추정·검정하는 통계
- **중심경향** : 자료의 중심을 나타내는 값(평균·중앙값·최빈값)
- **산포도** : 자료가 흩어진 정도(분산·표준편차·사분위범위)
- **사분위범위(IQR)** : 제3사분위수와 제1사분위수의 차
- **신뢰구간** : 모수가 포함될 것으로 추정하는 구간
- **표본오차** : 표본추출 반복에 따른 추정값의 변동

</details>

## 2~4교시 25점 답안

## Ⅰ. 기술통계와 추론통계의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **기술통계** 는 관측 자료를 요약하고, **추론통계** 는 표본을 근거로 모집단을 추정·검정하는 방법 |
| 목적 | 자료의 특징 파악과 모집단에 대한 불확실성 있는 판단 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 기술통계의 범위 | 관측 자료 안의 중심·산포·분포 요약 |
| 추론통계의 불확실성 | 표본 변동과 모형 가정을 반영한 판단 |
| 해석 범위의 차이 | 자료 요약과 모집단 일반화를 구분 |

## Ⅲ. 요약에서 추론까지

```text
관측값 → 중심·산포·분포 요약 (기술통계)
   │
   └→ 모집단 질문 → 표본 설계·가정 확인 → 추정·검정 → 불확실성·적용 범위 보고 (추론통계)
```

## Ⅳ. 비교

| 구분 | 기술통계 | 추론통계 |
|---|---|---|
| 목적 | 관측 자료의 요약 | 모집단 모수·가설 판단 |
| 대표 방법 | 평균·중앙값·분위수·분산·빈도표·그래프 | 점·구간 추정, 가설검정, 회귀 계수 추정 |
| 결과의 범위 | 관측 자료 안 | 표본 설계·가정이 타당한 범위 |

| 자료 특성 | 적절한 요약 | 주의 |
|---|---|---|
| 범주형 | 개수·비율·최빈값 | 범주 간 거리를 가정하지 않음 |
| 치우친 분포·극단값 | 중앙값·사분위범위 | 평균만으로 판단하지 않음 |
| 대칭에 가까운 수치형 | 평균·표준편차 | 분포 모양·단위도 확인 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 표본 추출 편향 | 모집단·추출 방법·누락 대상 확인 |
| 표본오차 | 점추정치와 함께 신뢰구간 제시 |
| 통계적 유의성과 실질적 중요성의 차이 | 효과 크기·업무 맥락 검토 |
| 관찰 자료의 연관성을 인과로 해석 | 연구 설계·교란 요인 검토 |

## Ⅵ. 제언

먼저 분포를 기술통계로 확인해 이상치와 치우침을 파악하고, 그 결과에 맞는 추론 방법을 선택

```text
기술통계로 분포 확인(평균·중앙값·IQR·그래프) → 가정 검토 → 추정·검정
```

| 구분 | 평균 단독 요약 | 제언: 분포 확인 후 추론 |
|---|---|---|
| 이상치 | 왜곡 | 중앙값·IQR 병행 |
| 추론 | 가정 미확인 | 가정에 맞는 방법 |
