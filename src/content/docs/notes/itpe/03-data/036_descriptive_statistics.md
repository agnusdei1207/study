## 연관 키워드

- 기술통계(Descriptive Statistics), 추론통계(Inferential Statistics), 중심경향도, 산포도, 분포 형태
- 이상치, 강건 통계량(Robust Statistics), 탐색적 데이터 분석(EDA, Exploratory Data Analysis)

## Ⅰ. 기술통계의 개요

- 핵심 요약 : 관측 자료를 수치와 도표로 요약해 중심, 산포, 분포 형태를 파악하는 통계 방법.
- 개념 : 수집한 관측 자료를 평균, 산포도, 분포 형태 같은 요약 지표와 도표로 정리하는 통계 분석(**기술통계**, Descriptive Statistics).
- 배경 및 필요성 : 원자료가 대량이면 분포와 특성을 직접 읽기 어려우므로, 요약 지표로 자료의 현황을 먼저 파악할 필요가 있음.
- 주요 목적 : 자료의 현황을 간결하게 설명하고, 이후 분석과 모델링의 방향을 정하는 것.
- 구분 : 기술통계는 가진 자료 자체를 요약하고, **추론통계**(Inferential Statistics)는 표본으로 모집단에 관한 결론을 추정함.
- 근거 : [NIST 기술통계·탐색적 데이터 분석 개념](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35.htm).

## Ⅱ. 기술통계의 특징 및 장점

- 핵심 요약 : 중심, 산포, 형태를 함께 제시하여 대표값만으로는 보이지 않는 변동과 비대칭을 해석할 수 있게 하는 방식.

1. **중심경향도** : 평균, 중앙값, 최빈값으로 자료가 모이는 전형적 위치를 요약 → 자료의 대표값을 한눈에 전달.
2. **산포도** : 범위, 분산, 표준편차, 사분위범위(IQR, Interquartile Range)로 관측값의 흩어진 정도를 측정 → 값의 변동성을 함께 판단.
3. **분포 형태** : 왜도(Skewness)는 비대칭성, 첨도(Kurtosis)는 꼬리와 극단값의 두께를 나타냄 → 평균이 왜곡되는 상황을 식별.
4. 시각화 결합 : 표, 히스토그램, 상자그림, 산점도로 수치가 놓치는 구조를 드러냄 → 요약 지표와 원자료 해석을 연결.

## Ⅲ. 기술통계의 요약 절차

- 핵심 요약 : 자료 점검에서 시작해 통계량 산출, 분포 시각화, 집단별 해석으로 이어지는 절차.

```text
[ 기술통계 요약 절차 ]
자료·측정 단위 확인
   ↓
결측치·이상치 점검
   ↓
중심·산포 통계량 산출
   ↓
분포 그래프 작성
   ↓
집단·기간별 비교와 해석
```

| 요약 영역 | 대표 지표 | 해석 |
| :--- | :--- | :--- |
| 중심 | 평균, 중앙값, 최빈값 | 전형적인 위치 |
| 산포 | 범위, 분산, 표준편차, IQR | 변동의 크기 |
| 형태 | 왜도, 첨도, 히스토그램 | 비대칭과 꼬리 특성 |
| 관계 | 공분산, 상관계수, 산점도 | 변수 간 동반 변화 |

## Ⅳ. 대표 통계량의 비교

- 핵심 요약 : 평균은 모든 관측값을 반영하고 중앙값은 극단값에 영향을 덜 받으므로, 데이터 특성에 따라 함께 제시하는 것이 원칙.

| 지표 | 장점 | 한계·주의 |
| :--- | :--- | :--- |
| 산술평균 | 전체 관측값을 사용 | 이상치와 왜도에 민감 |
| 중앙값 | 극단값에 비교적 영향을 덜 받음 | 값의 크기 정보를 일부 반영하지 않음 |
| 최빈값 | 범주형 자료에도 활용 가능 | 최빈값이 여러 개이거나 없을 수 있음 |
| 표준편차 | 원자료와 같은 단위로 산포를 해석 | 이상치에 민감 |
| 사분위범위(IQR) | 중앙 50%의 변동을 요약 | 꼬리 부분 정보가 약함 |
| 변동계수(CV, Coefficient of Variation) | 평균 대비 상대 산포를 비교 | 평균이 0에 가깝거나 비율척도가 아니면 부적절 |

- 중앙값과 IQR처럼 극단값의 영향을 덜 받는 지표를 **강건 통계량**(Robust Statistics)이라 부르며, 이상치가 섞인 자료의 요약에 쓰임.

## Ⅴ. 기술통계의 한계와 방안

- 핵심 요약 : 요약 지표 하나에 의존하면 분포 구조, 집단 차이, 이상치 영향을 놓칠 수 있으므로 원자료 확인과 함께 해석해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 같은 요약값의 서로 다른 분포 | 평균과 분산이 같아도 분포 모양이 달라 해석이 왜곡 | 히스토그램, 산점도 등 원자료 시각화를 함께 확인 | 시각화 병행 여부 |
| 왜도와 이상치에 의한 평균 왜곡 | 극단값이 평균을 끌어당겨 대표성을 잃음 | 중앙값과 IQR을 함께 제시하고 이상치 원인 검토 | 이상치 비율 |
| 집계에 따른 하위집단 역전 | 전체 집계와 집단별 방향이 달라지는 **심슨의 역설**(Simpson's Paradox) | 집단별 층화 통계 산출 | 층화 집단별 차이 |
| 측정 단위와 척도 차이 | 단위가 다른 자료의 산포를 직접 비교하면 오해 발생 | 척도 수준을 확인하고 변동계수 같은 상대 지표 선택 | 지표 척도 적합성 점검 |

```text
[ 요약 지표의 한계 통제 ]
대표값만 제시   → 분포 시각화 병행
극단값 영향     → 중앙값·IQR 비교
집단 차이 누락  → 층화 통계 확인
```

## Ⅵ. 기술통계에 대한 기술사적 제언

- 핵심 요약 : 정의된 지표 사전과 재현 가능한 집계, 분포의 변화 감시를 분석 체계에 내재화하는 방향.

1. 데이터 관리 조직은 지표 사전에 산출 기준, 결측치 처리 방법, 모집단 범위, 단위를 기록하여 팀 간 비교의 일관성을 확보해야 한다.
2. 분석 조직은 평균, 중앙값, 분위수와 분포 그래프를 대시보드에 함께 제공하여 단일 요약값에 대한 과신을 줄여야 한다.
3. 운영 조직은 평균과 분산 같은 요약값의 시간 변화를 감시하되, 변동의 원인을 단정하기 전에 데이터 품질과 업무 변화를 먼저 확인해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 기술통계는 데이터 이해의 출발점이며, 수치 요약과 시각화, 집단별 비교가 결합되어야 의미가 완성됨.
- 시사점 : 중심·산포·형태 지표를 함께 보고 평균과 중앙값을 상황에 맞게 고르는 것이 단일 요약의 한계를 줄이는 길임.
