## 답안 골격
```text
[기술통계] ◀━━ 머리: Ⅶ 내 의견 (단순 평균 중심 요약 지양 → 척도 특성에 맞는 분위수·왜도·첨도 복합 EDA 정착)
 ┃
 ┣━ Ⅰ 개요 ───── 대량의 원시 데이터(Raw Data) → 수치적 지표와 시각화를 통해 데이터의 핵심 특징을 요약·기술
 ┣━ Ⅱ 특징 ───── 데이터 요약 및 압축 · 직관적 패턴 전달 · 표본 자체의 특성 기술 (모집단 추론 배제)
 ┣━ Ⅲ 구조 ───── 4대 측정 척도(명목·서열·등간·비율) / 중심경향치 / 산포도 / 형태 통계량(왜도·첨도)
 ┣━ Ⅳ 흐름 ───── ① 데이터 수집 → ② 척도 식별 → ③ 중심경향치(평균/중앙값) 산출 → ④ 산포(분산/IQR) 및 왜도 계산 → ⑤ 시각화(Boxplot/히스토그램)
 ┣━ Ⅴ 비교 ───── 기술통계(Descriptive) vs 추론통계(Inferential)
 ┗━ Ⅵ 실무 ───── 이상치로 인한 평균 착시 / 척도에 맞지 않는 통계량 적용 / 분산 무시로 인한 데이터 왜곡
```
- 필수 키워드: 4대 척도(명목·서열·등간·비율) · 중심경향치(평균·중앙값·최빈값) · 산포도(분산·표준편차·IQR) · 왜도(Skewness) · 첨도(Kurtosis) · EDA
- 배점 전략: 10점 = Ⅰ → Ⅲ 4대 척도 및 통계량 매핑 표 → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅲ 척도 체계도 및 Ⅴ 기술통계 vs 추론통계 비교표
- 기출: 124회 1교시 2번 `통계학의 4가지 척도를 구분하고 다중회귀/로지스틱회귀 비교` → 4대 척도 체계 / 123회 `기술통계와 추론통계`

## 한 줄 본질
- 방대하고 복잡한 수치 데이터를 사람이 한눈에 파악할 수 있도록 중심 위치, 퍼진 정도, 왜곡된 형태라는 소수의 요약 지표로 축약 → 데이터 탐색 및 데이터 품질 검증의 출발점 / 표본 자체의 요약에 국한되어 전체 모집단 일반화 한계

## 핵심 그림
```text
[데이터의 4대 측정 척도와 적합한 기술통계량]

  척도 수준       연산 가능성          중심경향치       적용 예시
  ─────────────────────────────────────────────────────────────────
  명목 (Nominal)  빈도, 최빈값         최빈값(Mode)     성별, 혈액형
  서열 (Ordinal)  순서, 대소           중앙값(Median)   직급, 만족도(리커트)
  등간 (Interval) 덧셈, 뺄셈 (절대0 없음) 산술평균(Mean)   온도(℃), 지능지수(IQ)
  비율 (Ratio)    사칙연산 (절대0 있음)   기하/조화평균     매출액, 체중, 지연시간
```

## 핵심 용어
- 왜도(Skewness): 데이터 분포의 비대칭성을 측정하는 지표로, 양수이면 오른쪽으로 긴 꼬리(평균 > 중앙값), 음수이면 왼쪽으로 긴 꼬리(평균 < 중앙값)를 가짐
- 첨도(Kurtosis): 데이터 분포의 뾰족한 정도와 꼬리의 두께를 나타내며, 정규분포(첨도 3 또는 0) 대비 꼬리가 두꺼운지(Fat-tail) 판정

## 핵심 통찰
- 척도(Scale)에 맞지 않는 계산은 수학적 오류임 → '서열 척도(만족도 1점~5점)'에 산술평균을 내어 3.4점으로 발표하는 것은 엄밀히 통계학적 오류이며 중앙값이 올바름
- 평균 하나만 믿으면 '평균의 함정'에 빠짐 → 연봉 1억 1명과 2천만 원 9명의 평균은 2천8백만 원이지만, 대다수는 평균보다 낮으므로 중앙값(2천만 원)과 IQR을 반드시 병기해야 함
- 기술통계는 머신러닝 피처 엔지니어링의 나침반임 → 왜도가 심한 피처는 로그 변환(Log Transform)으로 정규분포화해야 선형 모델의 성능이 향상됨

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 변동계수 (CV) | 상대적 산포 척도 | 표준편차를 평균으로 나눈 값($\sigma/\mu$)으로, 단위가 다른 두 집단의 산포를 비교 |
| EDA (탐색적 데이터 분석) | 분석 방법론 | 기술통계치와 그래픽(히스토그램, 산점도)을 통해 데이터의 특성을 능동적으로 탐색 |

## 이웃 토픽과 구분
- 기술통계 vs 추론통계: 기술통계 = 눈앞에 있는 데이터의 상태를 요약하고 정리 / 추론통계 = 표본을 바탕으로 눈에 보이지 않는 모집단의 모수를 가설검정하고 추정

## 문제·원인·대책
- 적용 상황: 전자상거래 사용자 체류 시간 데이터 분석
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 체류 시간 평균이 45분으로 나와 앱 사용성이 높다고 오판 | 앱을 켜두고 잠든 극단적 이상치로 인한 산술평균 왜곡 | 중앙값(Median, 3분) 및 사분위수(IQR) 중심으로 대표값 변경 | 실제 유저 체류 실태 정확 파악 |
| 머신러닝 회귀 모델의 잔차 분산이 불안정 | 왜도(Skewness)가 3.5인 극단적 우측 꼬리 매출액 데이터 직접 투입 | 로그 변환($\log(x+1)$)을 통해 정규분포 대칭화 수행 | 회귀 모델 결정계수($R^2$) 향상 |

## 내 의견
- [단일 요약 통계량에 대한 맹신 경계] 앤스컴 콰르텟처럼 평균과 분산이 같은데도 데이터 형상이 완전히 다른 위험 상존 → 나라면: 판다스 `df.describe()` 요약치 확인에 그치지 않고, 반드시 박스플롯(Boxplot)과 왜도·첨도 자동 검증 스크립트를 통합 파이프라인에 포함시켜 데이터 분포의 기하학적 형상을 전수 검증
