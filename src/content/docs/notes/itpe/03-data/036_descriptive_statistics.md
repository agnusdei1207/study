## 연관 키워드

**기술통계**, **중심경향도**, **산포도**, **분포 형태**, **이상치**, **탐색적 데이터 분석**, **강건 통계량**

## Ⅰ. 기술통계 개요

- 핵심 요약 : **기술통계**는 관측 데이터를 수치와 도표로 요약해 데이터의 중심·흩어짐·분포 형태를 파악하는 방법이다.
- 목적 : 대량의 원자료를 이해하기 쉬운 형태로 압축해 현황을 설명하고 추가 분석의 방향을 찾는다.
- 구분 : 기술통계는 관측 자료를 요약하며, **추론통계**는 표본으로부터 모집단에 관한 결론을 추정한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **중심·산포·형태**를 함께 제시하면 대표값뿐 아니라 데이터의 변동과 비대칭성도 해석할 수 있다.
- **중심경향도** : 평균·중앙값·최빈값으로 전형적인 위치를 요약한다.
- **산포도** : 범위·분산·표준편차·사분위범위로 관측값의 흩어진 정도를 나타낸다.
- **분포 형태** : 왜도는 비대칭성, 첨도는 꼬리와 극단값의 특성을 살피는 단서다.
- **시각화 결합** : 표·히스토그램·상자그림·산점도는 수치만으로 놓칠 수 있는 구조를 드러낸다.

## Ⅲ. 기술통계 요약 절차

- 핵심 요약 : **자료 점검 → 요약 통계량 산출 → 분포 시각화 → 집단별 해석** 순서로 수행한다.

```text
[자료·측정 단위 확인]
          ▼
[결측치·이상치 점검]
          ▼
[중심·산포 통계량 산출]
          ▼
[분포 그래프 작성]
          ▼
[집단·기간별 비교 및 해석]
```

| 요약 영역 | 대표 지표 | 해석 |
|---|---|---|
| 중심 | 평균·중앙값·최빈값 | 전형적인 위치 |
| 산포 | 범위·분산·표준편차·IQR | 변동의 크기 |
| 형태 | 왜도·첨도·히스토그램 | 비대칭·꼬리 특성 |
| 관계 | 공분산·상관·산점도 | 변수 간 동반 변화 |

## Ⅳ. 대표 통계량 비교

- 핵심 요약 : **평균은 모든 관측값을 반영**하고, **중앙값은 극단값에 강건**하므로 데이터 특성에 따라 함께 제시한다.

| 지표 | 장점 | 한계·주의 |
|---|---|---|
| 산술평균 | 전체 관측값을 사용 | 이상치·왜도에 민감 |
| 중앙값 | 극단값에 비교적 강건 | 값의 크기 정보를 일부 반영하지 않음 |
| 최빈값 | 범주형 자료에도 활용 가능 | 여러 최빈값 또는 최빈값 부재 가능 |
| 표준편차 | 원자료와 같은 단위로 산포 해석 | 이상치에 민감 |
| 사분위범위(IQR) | 중앙 50%의 변동을 강건하게 요약 | 꼬리 부분 정보가 약함 |
| 변동계수(CV) | 평균 대비 상대 산포 비교 | 평균이 0에 가깝거나 비율척도가 아닌 경우 부적절 |

## Ⅴ. 한계와 방안

- 핵심 요약 : 요약값 하나에 의존하면 **분포 구조·집단 차이·이상치 영향**을 놓칠 수 있다.
- **동일한 통계량의 다른 분포** → 히스토그램·산점도 등 원자료 시각화를 함께 확인한다.
- **왜도와 이상치로 인한 평균 왜곡** → 중앙값·IQR을 함께 제시하고 이상치 원인을 검토한다.
- **집계에 따른 하위집단 역전** → 집단별 층화 통계를 산출해 심슨의 역설 가능성을 점검한다.
- **측정 단위 차이** → 비교 목적과 척도 수준을 확인하고 CV 등 적절한 상대 지표를 선택한다.

```text
대표값만 제시 → 분포 시각화 병행
극단값 영향   → 중앙값·IQR 비교      → 왜곡 없는 데이터 해석
집단 차이 누락 → 층화 통계 확인
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **정의된 지표·재현 가능한 집계·변화 감시**를 분석 파이프라인에 내재화한다.
- 지표 사전에 산출 기준, 결측치 처리, 모집단 범위, 단위를 기록해 팀 간 비교의 일관성을 확보한다.
- 평균·중앙값·분위수와 분포 그래프를 대시보드에서 함께 제공한다.
- 평균·분산 등 분포 요약의 시간 변화를 감시하되, 통계량 변동만으로 원인을 단정하지 말고 데이터 품질과 업무 변화를 확인한다.

## Ⅶ. 결론

- 핵심 요약 : 기술통계는 데이터 이해의 출발점이며 **수치 요약과 시각화, 집단별 비교**를 결합해야 한다.
- 답안에서는 중심·산포·형태 지표를 나누고, 평균과 중앙값의 선택 기준 및 단일 요약의 한계를 대응 방안과 연결한다.
- 관련 개념 : [기술통계와 탐색적 데이터 분석의 개념 정리](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35.htm).
