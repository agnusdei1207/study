## Ⅰ. 데이터의 특성을 요약하는 기술통계(Descriptive Statistics) 개요

### 가. 기술통계의 정의
- 수집된 대규모 데이터를 도표, 그래프, 수치적 요약 지표를 활용하여 데이터의 중심 위치, 흩어진 정도, 분포의 형태 등을 객관적으로 정리·요약·설명하는 통계적 방법론.
- 표본으로부터 모집단의 특성을 확률적으로 추론하는 **추론통계(Inferential Statistics)** 의 선행 필수 단계이자, 탐색적 데이터 분석(EDA)의 핵심 척도.

---

## Ⅱ. 기술통계의 4대 핵심 수치 요약 척도

### 가. 요약 척도 계통도

```text
[ 기술통계 4대 척도 체계 ]
1. 중심경향도 (Central Tendency) : 평균 (산술/기하/조화), 중앙값, 최빈값
2. 산포도 (Dispersion)          : 분산, 표준편차, 사분위범위 (IQR), 변동계수 (CV)
3. 왜도 (Skewness)              : 분포의 비대칭성 방향 및 정도
4. 첨도 (Kurtosis)              : 분포의 꼬리 두께 및 중심 피크의 뾰족한 정도
```

### 나. 세부 척도별 산식 및 비즈니스 특성 비교

| 분류 | 세부 척도 | 산식 및 메커니즘 | 통계적 특성 및 주의점 |
| :--- | :--- | :--- | :--- |
| **중심경향도** | **산술평균 (Mean)** | $\bar{x} = \frac{1}{n} \sum x_i$ | 모든 데이터를 반영하나, 극단적 이상치에 극도로 취약 |
| **중심경향도** | **중앙값 (Median)** | 데이터를 크기순 나열 시 중앙에 위치한 값 | 이상치에 강건(Robust), 소득/부동산 가격 분석에 표준 |
| **중심경향도** | **최빈값 (Mode)** | 데이터 중 가장 빈번하게 출현한 값 | 범주형 데이터(명목척도)의 중심 위치 파악에 유일하게 사용 가능 |
| **산포도** | **표준편차 (SD)** | $s = \sqrt{\frac{1}{n-1}\sum(x_i - \bar{x})^2}$ | 원래 데이터와 동일한 측정 단위 유지, 정규분포 해석의 기본 |
| **산포도** | **사분위범위 (IQR)** | $IQR = Q3 - Q1$ (중앙 50%의 범위) | 이상치에 영향을 받지 않는 강건한 산포 척도 |
| **산포도** | **변동계수 (CV)** | $CV = \frac{s}{\bar{x}} \times 100$ (%) | 단위가 다르거나 평균 차이가 큰 두 데이터셋의 상대적 산포 비교 |
| **비대칭도** | **왜도 (Skewness)** | $\gamma_1 = \frac{E[(X-\mu)^3]}{\sigma^3}$ | $\gamma_1 > 0$ : 오른쪽 꼬리가 김 (평균 > 중앙값), $\gamma_1 < 0$ : 왼쪽 꼬리가 김 |
| **꼬리두께** | **첨도 (Kurtosis)** | $\beta_2 = \frac{E[(X-\mu)^4]}{\sigma^4} - 3$ | 초과첨도 $> 0$ : 정규분포보다 꼬리가 두껍고 뾰족함 (Fat-Tail 리스크) |

## Ⅲ. 왜도에 따른 중심경향도 지표의 상대적 위치

```text
[ 왜도에 따른 평균, 중앙값, 최빈값의 관계 ]
(A) 우측 꼬리 분포 (Positive Skew, 소득 분포) : 최빈값 < 중앙값 < 평균
(B) 대칭 정규 분포 (Zero Skew, 완벽 대칭)     : 최빈값 = 중앙값 = 평균
(C) 좌측 꼬리 분포 (Negative Skew, 시험 점수)  : 평균 < 중앙값 < 최빈값
```

## Ⅳ. 데이터 분석 실무자를 위한 제언

- **평균의 함정(Flaw of Averages) 경계** : 왜도가 심한 플랫폼 사용자 체류 시간, 고객 생애 가치(LTV) 등을 분석할 때 산술평균만 보고 의사결정을 내리면 소수의 헤비 유저로 인해 전체 패턴을 오판하므로, 반드시 5수치 요약(최소, Q1, 중앙값, Q3, 최대)과 상자 그림(Box Plot)을 함께 제시해야 함.
- **파이프라인 내 데이터 드리프트(Data Drift) 감시** : 배치 파이프라인에서 입력 데이터의 평균, 분산, 왜도 등 기술통계 요약값을 주기적으로 저장하여, 분포의 급격한 변동을 감지하는 모니터링 체계를 구축할 것을 제언함.
