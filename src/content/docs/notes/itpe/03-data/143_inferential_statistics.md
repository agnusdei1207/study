## 연관 키워드

**추론통계(Inferential Statistics)**, **점추정/구간추정**, **신뢰구간(Confidence Interval)**, **모수/비모수**, **p-해킹**, **부트스트랩(Bootstrap)**, **FDR**

## Ⅰ. 개요

- 핵심 요약 : **추론통계**는 표본 데이터로 모집단 모수를 추정·검정하는 확률 기반 분석.
- 목적 : 전수 조사 불가 시 과학적 의사결정.
- 배경 : 모집단 전체 조사 불가 → 표본 기반 추론.
- 특징 : 추정(점/구간), 가설검정, 모수/비모수.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **추정·검정·모수/비모수**로 불확실성 정량화.
- **점추정** : 단일 수치 (표본평균).
- **구간추정** : 신뢰구간 (95% CI).
- **가설검정** : H0 vs H1, p-value.
- **모수적** : 정규성 가정 (t, ANOVA, Pearson).
- **비모수적** : 분포 무관 (Wilcoxon, Kruskal-Wallis).

## Ⅲ. 추론 체계 흐름

- 핵심 요약 : **추정(점/구간) + 가설검정** 양대 축.
- 95% CI : "구간 중 95%가 참 모수 포함" (모수는 고정).

```text
[ 추론통계 양대 체계 ]

[추론통계]
   |
   +---> [1. 추정] 점추정 (단일 수치) / 구간추정 (신뢰구간)
   +---> [2. 검정] H0 vs H1, p-value vs alpha
```

```text
[ 모수적 vs 비모수적 ]

모수적 : z, t, ANOVA, Pearson (정규성 가정)
비모수적 : Mann-Whitney, Wilcoxon, Kruskal-Wallis, Spearman
```

## Ⅳ. 점추정 vs 구간추정 비교

- 핵심 요약 : **간결성 vs 불확실성 표현**.

| 항목 | 점추정 | 구간추정 |
|---|---|---|
| 결과 | 단일 수치 | 상한·하한 구간 |
| 불확실성 | 표현 어려움 | 신뢰수준과 함께 표현 |
| 장점 | 간결·직관 | 신뢰도 표현 |
| 한계 | 오차 크기 미표현 | 구간 과도 시 유용성 저하 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **가정 위반·표본 편향·p-해킹**을 비모수·층화 표본·FDR로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 가정 위반 | 정규성 등 미충족 시 p 왜곡 | 적합도 검정, 비모수 검정, 부트스트랩 | p값·CI |
| 표본 편향 | 대표성 상실로 외적 타당도 훼손 | 층화/군집 표본, 사후 가중치 보정 | 대표성 |
| p-해킹 | 무차별 검정으로 가짜 상관 | 사전 등록, 효과 크기·CI 보고, FDR(BH) 교정 | FDR |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **표본 크기 사전 산정·FDR 교정**으로 재현성 확보.
- A/B 테스트 : 오차 한계·유의수준·분산 기반 n 사전 산정.
- FDR 교정 : 벤저미니-호크버그로 가짜 상관 차단.
- 효과 크기·CI 동시 보고.

## Ⅶ. 결론

- 핵심 요약 : 추론통계는 **표본 기반 모수 추정·검정**으로 불확실성 정량화.
- 답안에는 추정/검정, 모수/비모수, 가정·p-해킹 대응을 연결.
