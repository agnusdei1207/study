## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **신뢰도 vs 타당도**

## 30초 인출

- 본질: 신뢰도는 측정 점수의 반복 일관성이고, 타당도는 점수 해석과 사용을 뒷받침하는 증거의 적절성
- 메커니즘: 측정 목적과 개념을 정한 뒤 같은 점수 자료로 신뢰도(재검사·평가자 간·문항 내적 일관성)와 타당도(내용·응답 과정·내부 구조·다른 변수와의 관계) 증거를 각각 수집하고 약한 지점을 고쳐 재평가
- 통찰: 일관되게 틀린 측정도 신뢰도는 높으므로 신뢰도 계수 하나로 합격 처리하지 않고, 타당도는 도구의 고정 속성이 아니라 특정 해석에 대한 증거의 누적이므로 집단·목적이 바뀌면 다시 확인

<details>
<summary>핵심 용어</summary>

- **신뢰도(Reliability)** : 측정 점수가 반복해서 일관되게 나오는 정도
- **타당도(Validity)** : 점수 해석과 사용을 지지하는 증거의 적절성
- **재검사 신뢰도** : 일정 간격을 두고 다시 측정한 점수의 일치
- **평가자 간 일치도** : 복수 평가자가 같은 자료를 채점한 결과의 일치
- **크론바흐 알파** : 문항들이 일관되게 같은 개념을 재는지 나타내는 내적 일관성 지표
- **수렴·판별 타당도** : 관련 개념과는 높은 상관, 무관한 개념과는 낮은 상관을 보이는지 확인

</details>

---

## 2~4교시 25점 답안

## Ⅰ. 신뢰도·타당도의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **신뢰도** 는 점수의 반복 일관성, **타당도** 는 점수 해석·사용을 뒷받침하는 증거의 적절성 |
| 목적 | 측정 오차와 해석의 한계를 확인해 근거 있는 판단 지원 |

## Ⅱ. 특징

| 구별 | 신뢰도 | 타당도 |
|---|---|---|
| 초점 | 점수의 반복 일관성 | 점수 해석·사용의 근거 |
| 대표 증거 | 시간·평가자·문항 간 일치 | 내용·응답 과정·구조·다른 변수와의 관계 |
| 관계 | 일관성이 낮으면 해석이 불안정 | 일관성만 높아도 타당성이 확보되지 않음 |

## Ⅲ. 이중 검증 절차

```text
측정 목적·개념 정의 → 문항·채점·사용 조건 설계
    ↓ 같은 점수 자료
 ├ 신뢰도: 재검사·평가자·문항 간 변동 → 무작위 오차 확인
 └ 타당도: 내용·응답 과정·구조·외부 관계 → 해석 근거 확인
    ↓ 증거가 약한 지점 수정 → 도구 재검토·새 표본 재평가
```

## Ⅳ. 신뢰도 방법과 타당도 증거

| 신뢰도 대상 | 방법 예 | 유의 |
|---|---|---|
| 시간적 안정성 | 일정 간격 재검사 | 기억·학습 효과 |
| 평가자 간 일치 | 복수 평가자 채점 | 평가 기준·표본 특성 명시 |
| 문항 내적 일관성 | 크론바흐 알파 | 문항 수·차원성에 영향받아 단일 기준으로 판정하지 않음 |

| 타당도 증거 | 확인 내용 | 자료 예 |
|---|---|---|
| 내용 | 문항이 측정 영역을 대표하는가 | 명세서·문항 대응, 전문가 검토 |
| 응답 과정·내부 구조 | 의도한 방식으로 응답하고 점수 구조가 이론과 부합하는가 | 인지 면담, 요인 구조 분석 |
| 다른 변수와의 관계 | 관련 개념과 예상한 관계인가 | 수렴·판별·준거 관계 분석 |

| 상황 | 해석 |
|---|---|
| 일관성이 낮음 | 재현이 불안정해 해석 근거가 약함 |
| 일관성은 높으나 개념 대표성 낮음 | 같은 편향을 반복, 타당도 미확보 |
| 여러 증거가 목적에 부합 | 해당 맥락의 해석·사용 근거 강화 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 반복해서 같아도 측정 개념을 대표하지 못함 | 내용·응답 과정·구조·외부 관계 증거 수집 |
| 단일 신뢰도 계수로 도구 품질 합격 처리 | 오차 원인·사용 목적을 함께 검토 |
| 다른 집단에 같은 해석을 무검증 적용 | 집단별 응답 과정·구조·관계 재확인 |

## Ⅵ. 제언

신뢰도와 타당도 증거를 함께 수집하고, 사용 목적·집단이 바뀌면 다시 확인

```text
목적 정의 → 신뢰도 증거 + 타당도 증거 → 약한 지점 수정 → 집단·목적 변경 시 재확인
```

| 구분 | 신뢰도 계수만 확인 | 제언: 두 증거 병행 |
|---|---|---|
| 편향 | 일관된 오류 미발견 | 타당도로 발견 |
| 적용 | 무검증 확대 | 집단별 재확인 |
