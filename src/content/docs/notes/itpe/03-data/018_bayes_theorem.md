## 30초 인출

- 본질: 베이즈 정리는 사건에 대한 사전 믿음을 새로운 증거를 관측한 뒤의 확률(사후확률)로 갱신하는 조건부확률의 관계식
- 메커니즘: 사후확률 P(A|B) = 가능도 P(B|A) × 사전확률 P(A) ÷ 증거 확률 P(B)로 계산
- 통찰: 검사가 정확해도 대상이 드문 사건이면 양성 중 진짜 비율(사후확률)이 낮으므로 검사 정확도만이 아니라 사전확률(기저율)을 함께 반영해 판단

<details>
<summary>핵심 용어</summary>

- **베이즈 정리(Bayes' Theorem)** : 사전확률과 가능도로 사후확률을 계산하는 정리
- **사전확률(Prior)** : 증거를 보기 전 사건의 확률
- **가능도(Likelihood)** : 사건이 참일 때 관측한 증거가 나타날 확률
- **사후확률(Posterior)** : 증거를 관측한 뒤 사건이 참일 확률
- **증거 확률(Evidence)** : 증거가 나타날 전체 확률
- **기저율(Base Rate)** : 사건이 전체에서 차지하는 기본 비율
- **나이브 베이즈** : 특징들이 서로 독립이라고 가정하는 베이즈 분류기

</details>

## 2~4교시 25점 답안

## Ⅰ. 베이즈 정리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **베이즈 정리** 는 사전확률과 가능도로 증거 관측 후의 사후확률을 구하는 조건부확률 관계식 |
| 목적 | 새로운 증거에 따른 확률의 갱신 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 확률 갱신 | 증거가 추가될 때마다 사후확률을 새 사전확률로 사용 |
| 기저율 반영 | 사건의 기본 발생 비율 고려 |
| 분류에 활용 | 나이브 베이즈, 스팸 필터 |

## Ⅲ. 수식과 계산 예

```text
P(A|B) = P(B|A) × P(A) / P(B)
       사후      가능도    사전   증거

예) 질병 유병률 1%, 검사 민감도 99%, 위양성률 5%
    양성일 때 실제 질병일 확률
    = (0.99 × 0.01) / (0.99×0.01 + 0.05×0.99) = 0.0099 / 0.0594 ≈ 16.7%
```

## Ⅳ. 해석과 활용

| 요소 | 값 | 의미 |
|---|---|---|
| 사전확률 | 1% | 검사 전 유병률 |
| 가능도 | 99% | 질병일 때 양성 |
| 사후확률 | 약 16.7% | 양성일 때 실제 질병 |

| 활용 | 내용 |
|---|---|
| 스팸 필터 | 단어 출현으로 스팸 확률 갱신 |
| 의료 진단 | 검사 결과로 진단 확률 갱신 |
| 분류 모델 | 나이브 베이즈 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 기저율을 무시해 양성 결과를 과신 | 사전확률을 함께 제시하고 사후확률로 판단 |
| 사전확률 설정의 주관성 | 과거 자료 기반 사전확률과 민감도 확인 |
| 나이브 베이즈의 독립 가정 위반 | 상관이 큰 특징을 정리하거나 다른 모델 병행 |

## Ⅵ. 제언

검사·예측 결과를 해석할 때 기저율을 반영한 사후확률로 판단하고, 새 증거가 들어오면 사후확률을 다음 사전확률로 갱신

```text
사전확률 → 증거 관측 → 사후확률 → (다음 증거의 사전확률로 사용)
```

| 구분 | 정확도만 확인 | 제언: 사후확률 확인 |
|---|---|---|
| 드문 사건 | 양성 결과 과신 | 실제 확률 |
| 갱신 | 없음 | 증거 반영 |
