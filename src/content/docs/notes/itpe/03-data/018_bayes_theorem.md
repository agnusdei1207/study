## 연관 키워드

- 베이즈 정리(Bayes' Theorem), 사전 확률(Prior Probability), 사후 확률(Posterior Probability)
- 조건부 확률(Conditional Probability), 가능도(Likelihood), 베이즈 갱신(Bayesian Updating)
- 나이브 베이즈 분류기(Naive Bayes Classifier), 베이지안 A/B 테스트(Bayesian A/B Test), 무정보 사전분포(Non-informative Prior)

## Ⅰ. 베이즈 정리의 개요

- 핵심 요약 : 새로운 증거의 관측 결과를 반영해 기존 믿음을 갱신하는 확률 추론의 기본 정리.
- 개념 : 증거 관측 전의 믿음인 **사전 확률**(Prior Probability)을 관측 후의 믿음인 **사후 확률**(Posterior Probability)로 갱신하는 관계를 나타내는 **조건부 확률**(Conditional Probability)의 정리 (**베이즈 정리**, Bayes' Theorem).
- 배경 및 필요성 : 불확실한 상황에서 지식이 쌓이는 과정을 수식으로 표현할 체계가 필요하고, 소량 데이터에 기존 지식을 결합한 추론 수단이 요구됨.
- 주요 목적 : 관측 전의 믿음과 관측 결과를 결합해 관측 후의 믿음을 산출하는 추론의 표준 틀 제공.

## Ⅱ. 베이즈 정리의 특징 및 장점

- 핵심 요약 : 사전 확률의 연쇄적 갱신 구조가 점진적 학습과 소량 데이터 추론을 가능하게 하는 확률 추론의 기반.

1. 갱신 구조 : 증거 관측에 따라 사전 확률이 사후 확률로 교정 → 판단이 데이터에 맞게 보정되는 효과.
2. 연쇄 갱신 : 산출된 사후 확률이 다음 단계의 사전 확률로 전이 (**베이즈 갱신**, Bayesian Updating) → 데이터가 쌓일수록 정교해지는 학습 효과.
3. 사전지식 활용 : 소량 데이터에서도 기존 지식을 확률로 반영 → 신규·희귀 사건 추론의 근거 확보 효과.
4. 직관적 해석 : 결과를 가설이 참일 확률로 해석 → 의사결정 보고에 직결되는 효과.
5. 확장성 : **나이브 베이즈 분류기**(Naive Bayes Classifier)나 베이지안 A/B 테스트(Bayesian A/B Test)로 확장 → 응용 범위가 넓은 효과.

## Ⅲ. 베이즈 정리의 구조 (흐름)

- 핵심 요약 : 사후 확률은 가능도와 사전 확률의 곱을 주변 우도로 나눈 값이며, 갱신이 루프 구조로 반복.

- **가능도**(Likelihood, 가설이 참일 때 증거가 나타날 확률) : 수식에서 사전 확률과 곱해지는 항.
- 주변 우도 : 증거가 나타날 전체 확률로, 사후 확률의 총합이 1이 되게 하는 정규화 상수.

```text
[ 베이즈 정리 수식 구조 ]

사후 확률 P(A|B)
   = 가능도 P(B|A) × 사전 확률 P(A)
     ────────────────────────
         주변 우도 P(B)
```

```text
[ 베이즈 갱신 루프 ]

사전 확률 설정
      ↓  1차 증거 관측
사후 확률 계산
      ↓  사후 확률을 새 사전 확률로 전이
2차 증거 관측
      ↓
갱신된 사후 확률
```

- 나이브 베이즈 분류기 : 모든 특성이 클래스에 대해 조건부 독립이라고 가정해 결합 확률을 곱셈으로 단순화한 분류 모델로, 스팸 필터링과 문서 분류에 활용.

## Ⅳ. 베이즈 정리 구성 요소의 비교

- 핵심 요약 : 사전 확률, 가능도, 주변 우도, 사후 확률은 기호와 역할이 서로 다른 네 구성 요소.

| 구성 요소 | 기호 | 역할 | 스팸 필터 예시 |
| --- | --- | --- | --- |
| 사전 확률 | P(A) | 증거 관측 전의 기저 확률 | 전체 메일 중 스팸 비율 |
| 가능도 | P(B\|A) | 가설이 참일 때 증거가 나타날 확률 | 스팸 메일 중 특정 단어 출현율 |
| 주변 우도 | P(B) | 증거가 나타날 전체 확률 (정규화 상수) | 전체 메일 중 특정 단어 출현율 |
| 사후 확률 | P(A\|B) | 증거가 주어진 뒤 가설이 참일 확률 | 특정 단어 포함 메일이 스팸일 확률 |

- 선택 기준 : 기존 통계가 있으면 그 비율을 사전 확률로 사용하는 것.
- 선택 기준 : 근거가 없으면 **무정보 사전분포**(Non-informative Prior)를 택하고 민감도를 확인하는 것.
- 선택 기준 : 특성 수가 많으면 독립 가정 기반의 나이브 베이즈를 우선 검토하는 것.

## Ⅴ. 베이즈 정리의 한계와 방안

- 핵심 요약 : 사전 확률의 주관성, 고차원 계산 부담, 독립 가정 위배가 한계이며 추정 기법과 진단으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 사전 확률의 주관성 | 분석가의 임의 설정 → 결과 왜곡과 재현성 저하 | **경험적 베이즈**(Empirical Bayes, 과거 자료 기반 사전분포 추정), 민감도 분석 | 사전분포 변경에 따른 결과 차이 |
| 고차원 계산 부담 | 정규화 상수 계산의 다중 적분이 해석적으로 곤란 → 실용성 저하 | **마르코프 연쇄 몬테카를로** (MCMC, Markov Chain Monte Carlo) 샘플링, 변분 추론 근사 | 수렴 진단 값, 계산 시간 |
| 독립 가정 위배 | 특성 간 상관으로 사후 확률의 극단화 → 오분류 증가 | **라플라스 평활화**(Laplace Smoothing), 베이지안 네트워크 구조 모델링 | 오분류율 |

## Ⅵ. 베이즈 정리에 대한 기술사적 제언

- 핵심 요약 : 점 추정치만의 보고를 지양하고 사후 분포와 가정을 함께 기록하는 분석 운영 원칙의 정착.
- 보고 기준 : 분석 조직이 사후 분포의 구간 추정치와 사전분포 가정을 보고 양식에 포함하는 체계 구축.
- 가정 관리 : 데이터 거버넌스 조직이 사전분포 설정 근거를 분석 문서로 남기고 주기적으로 재검토.
- 도구 표준화 : 정보시스템 조직이 확률 추론 라이브러리와 수렴 진단 도구를 표준 분석 플랫폼으로 제공.

## Ⅶ. 결론

- 핵심 요약 : 베이즈 정리는 증거로 믿음을 갱신하는 확률 추론의 수학적 토대.
- 시사점 : 사전분포의 근거 관리와 근사 기법의 진단이 함께할 때 신뢰 가능한 추론 도구가 됨.
