## 지식 로드맵 내 현재 위치
```text
데이터 분석 → 조건부 확률 → 베이즈 정리
```

## 큰 그림과 30초 인출
```text
[사전확률 P(H)] × [가능도 P(E|H)]
                ÷ [증거 P(E)]
                       ↓
               [사후확률 P(H|E)] → 다음 사전확률
```
- 본질: **새로운 증거의 가능도를 반영해 가설의 사전확률을 사후확률로 갱신하는 조건부 확률 규칙**
- 암기: `사전 × 가능도 ÷ 증거 = 사후`
- 주의: 낮은 기저율을 무시하면 높은 민감도의 검사도 사후확률을 과대평가

## 예상문제
> 베이즈 정리의 구성요소와 계산 원리를 설명하고 빈도주의와 비교하여 분류·진단 적용 시 고려사항을 논하시오. (25점)

## Ⅰ. 증거로 믿음을 갱신하는 베이즈 정리 개요
- 정의: 조건부 확률의 곱셈법칙을 이용해 $P(E|H)$를 알고 있을 때 $P(H|E)$를 계산하는 정리
- 목적: 기존 지식과 관측 증거를 결합해 불확실한 가설의 확률을 갱신
- 활용: 스팸분류, 의료진단, 이상탐지, 위험평가, 순차 의사결정

## Ⅱ. 구성요소와 의미
| 요소 | 의미 | 질문 |
|---|---|---|
| $P(H)$ | 사전확률 | 증거 전 가설 가능성은 |
| $P(E|H)$ | 가능도 | 가설이 참일 때 증거 가능성은 |
| $P(E)$ | 증거확률 | 증거 자체의 전체 가능성은 |
| $P(H|E)$ | 사후확률 | 증거 후 가설 가능성은 |

## Ⅲ. 공식과 전확률
```text
P(H|E) = P(E|H)P(H) / P(E)
P(E)   = Σi P(E|Hi)P(Hi)
Posterior ∝ Likelihood × Prior
```
- 서로 배타적이고 전체를 포괄하는 가설 집합으로 증거확률을 계산
- 사후확률은 다음 증거가 들어올 때 새로운 사전확률로 재사용 가능

## Ⅳ. 베이지안 갱신 절차
```text
① 가설 공간 → ② 사전확률 → ③ 관측·가능도 모형
 → ④ 증거확률 정규화 → ⑤ 사후확률 → ⑥ 의사결정·새 증거 갱신
```
| 단계 | 검증 |
|---|---|
| Prior | 기저율·전문가 판단·과거자료 근거 |
| Likelihood | 조건부 독립·분포 가정 |
| Posterior | Calibration·민감도·대안 Prior |

## Ⅴ. 베이지안과 빈도주의 비교
| 구분 | 베이지안 | 빈도주의 |
|---|---|---|
| 모수 | 확률분포로 표현 | 고정된 미지값 |
| 정보 | Prior와 데이터 결합 | 관측 표본의 반복 특성 |
| 결과 | 사후분포·신용구간 | 추정량·신뢰구간·p-value |
| 강점 | 순차 갱신·직관적 확률 | 객관적 절차·장기 오류 통제 |

## Ⅵ. 적용상 고려사항
| 문제 | 원인 | 대책 |
|---|---|---|
| 기저율 오류 | Prior 무시 | 모집단 기저율 명시 |
| Prior 편향 | 주관적 근거 | 복수 Prior 민감도 분석 |
| 과신한 사후확률 | 모델 오지정·의존성 무시 | Calibration·Posterior predictive check |
| 운영환경 변화 | 데이터 Drift | 기간별 재추정·모니터링 |

## Ⅶ. 확률과 행동 기준을 연결하는 결론
- 베이즈 정리는 불확실성을 제거하지 않고 증거에 따라 일관되게 갱신하는 틀
- 사후확률만 제시하지 말고 오탐·미탐 비용과 의사결정 임계값을 함께 설계

## 1교시 10점 답안 발췌
```text
사전확률 × 가능도 ÷ 증거확률 = 사후확률
P(H|E)=P(E|H)P(H)/P(E)
Prior → Evidence → Posterior → Next Prior
```
