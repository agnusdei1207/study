## 연관 키워드

- 베르누이 분포(Bernoulli Distribution), 이항분포(Binomial Distribution), 확률질량함수(PMF)
- 포아송 근사, 정규 근사, 베타-이항 분포, Focal Loss

## Ⅰ. 베르누이·이항분포의 개요

- 핵심 요약 : 성공과 실패 두 결과의 확률을 모델링하는 이산 확률분포로, 한 번의 시행에서 출발해 n회 반복으로 확장.
- 개념 : 한 번의 독립 시행에서 성공 확률이 p이고 결과가 0 또는 1인 분포 (**베르누이 분포**, Bernoulli Distribution), 그리고 n번의 독립 시행에서 성공 횟수를 나타내는 분포 (**이항분포**, Binomial Distribution).
- 배경 및 필요성 : 클릭 여부, 스팸 여부처럼 이진 사건의 확률을 다루는 문제가 많아, 한 번의 시행부터 반복 시행까지 같은 틀로 모델링할 필요가 있음.
- 주요 목적 : 이진 사건의 기댓값과 분산을 계산하고, 근사 기법으로 대규모 데이터에서도 계산 효율을 확보.

## Ⅱ. 베르누이·이항분포의 특징 및 장점

- 핵심 요약 : 단순한 모수 구조와 정확한 확률 계산, 근사 확장이 결합되어 이진 사건 모델링에 적합한 구조.

1. 단순한 모수 구조 : 성공 확률 p와 시행 횟수 n만으로 분포가 정해짐 → 계산과 해석이 간단함.
2. **확률질량함수** (PMF, Probability Mass Function, 이산 값마다 확률을 부여하는 함수) : 이항 계수와 확률을 곱해 정확한 확률을 계산 → 소표본에서 정확한 값 제공.
3. **포아송 근사** (희귀 사건의 분포를 포아송 분포로 근사)와 **정규 근사** (표본이 클 때 정규분포로 근사) : 계산 부담을 줄임 → 대규모 데이터 처리 효율화.
4. 머신러닝 활용 : 이진 교차 엔트로피 손실의 확률 모델 기반 → 이진 분류 모델의 학습 목적 함수로 사용.

## Ⅲ. 확률질량함수와 근사 흐름

- 핵심 요약 : PMF로 정확한 확률을 구하고, 조건에 따라 포아송 또는 정규 근사로 계산을 효율화하는 흐름.
- 베르누이 : $P(X=x) = p^x (1-p)^{1-x}$, $E(X) = p$, $Var(X) = p(1-p)$.
- 이항 : $P(X=k) = C(n,k)\,p^k (1-p)^{n-k}$, $E(X) = np$, $Var(X) = np(1-p)$.

```text
[ 베르누이에서 이항으로 확장 ]

1회 시행 (베르누이)
      ↓ 독립 반복 n회
n회 시행 (이항)
      ↓ 성공 횟수의 합
X = 성공 횟수 (0 ~ n)
```

```text
[ 근사 선택 흐름 ]

n은 크고 p는 작음 (np = λ 일정)
      ↓
포아송 근사 (희귀 사건)

np ≥ 5 이고 n(1-p) ≥ 5
      ↓
정규 근사 (연속성 보정 적용)
```

## Ⅳ. 베르누이와 이항분포의 비교

- 핵심 요약 : 시행 횟수, 확률변수, 조합 항의 유무가 두 분포를 구분하는 핵심.

| 비교 항목 | 베르누이 분포 | 이항분포 |
| :--- | :--- | :--- |
| 시행 횟수 | 1회 (n=1) | n회 독립 시행 |
| 확률변수 | 성공 여부 (0 또는 1) | 총 성공 횟수 (0부터 n까지) |
| 조합 항 | 불필요 | C(n,k) 필요 |
| 기댓값 | p | np |
| 분산 | p(1-p) | np(1-p) |

## Ⅴ. 베르누이·이항분포의 한계와 방안

- 핵심 요약 : 독립성과 p 불변 가정, 희귀 사건의 계산 불안정, 클래스 불균형을 모형 확장과 손실 설계로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 독립성과 p 불변 가정 | 실제 환경에서는 성공 확률이 변하거나 시행끼리 의존 | 성공 확률 자체를 분포로 두는 **베타-이항 분포**, 상태 공간 모델 | 적합도 검정 결과 |
| 희귀 사건의 계산 불안정 | np가 작으면 정규 근사가 부정확하고 팩토리얼 계산에서 오버플로우 발생 | 포아송 근사, 로그 팩토리얼 계산, **Clopper-Pearson 구간** (이항 비율의 정확 신뢰구간) | 신뢰구간 폭 |
| 클래스 불균형 | 이진 교차 엔트로피 손실이 다수 클래스에 치우침 | **Focal Loss** (쉬운 샘플의 손실 가중치를 낮추는 손실 함수), pos_weight 가중치 | F1 점수, PR-AUC(Precision-Recall Area Under the Curve) |

## Ⅵ. 베르누이·이항분포에 대한 기술사적 제언

- 핵심 요약 : 실험의 비율 검정과 이진 분류 모델로 실무에 적용하되, 분포 가정 확인을 함께 수행.

1. 전환율 비교 : 큰 표본의 A/B 테스트에서 전환율 차이는 정규 근사를 이용한 Z 검정으로 판정하는 경우가 많으며, 근사 조건을 먼저 확인하는 절차 필요.
2. 텍스트 분류 : 단어의 존재 유무로 판단하는 스팸 분류는 **베르누이 나이브 베이즈** (Bernoulli Naive Bayes, 단어 존재 여부를 이진 특징으로 쓰는 모델)가 해석이 쉬워 초기 기준선으로 적합.
3. 평가 지표 : 클래스 불균형이 심한 데이터는 정확도 대신 F1 점수와 PR-AUC로 평가하고, Focal Loss 같은 손실 설계를 함께 검토할 필요.

## Ⅶ. 결론

- 핵심 요약 : 베르누이·이항분포는 이진 사건의 확률을 모델링하는 기본 분포이며, PMF와 근사 기법이 실무 계산의 핵심.
- 시사점 : 독립성과 p 불변 가정의 적합 여부를 먼저 따져야 하며, 이를 확인하지 않으면 근사 결과와 모델 결과를 모두 신뢰하기 어려움.
