## 연관 키워드

**파일 시스템(File System)**, **연속/연결/색인 할당**, **i-node**, **저널링(Journaling)**, **XFS**, **Direct I/O**, **익스텐트(Extent)**

## Ⅰ. 개요

- 핵심 요약 : **파일 시스템**은 OS가 보조기억장치에 파일 단위로 데이터를 구조화·저장·관리하는 소프트웨어 계층.
- 목적 : 데이터 영속화, 접근 제어, 무결성.
- 배경 : DBMS 물리 디스크 영속화의 하부 인프라.
- 특징 : 3대 할당 방식, i-node, 저널링, XFS.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **색인 할당·i-node·저널링**으로 직접 접근·무결성 확보.
- **연속 할당** : 순차 I/O 극상, 외부 단편화.
- **연결 할당** : 단편화 해결, 직접 접근 불가.
- **색인 할당** : 직접/순차 접근 모두 고속 (현대 표준).
- **i-node** : 메타데이터+다계층 포인터.
- **저널링** : 크래시 복구, 무결성.

## Ⅲ. 할당 방식 흐름

- 핵심 요약 : **연속 → 연결 → 색인** 할당과 i-node 다계층 구조.
- 익스텐트 기반 할당으로 연속+유연성 동시 확보.

```text
[ 3대 디스크 할당 방식 ]

(A) 연속 할당 : 연속 블록 순차 저장 -> 순차 I/O 극상 / 외부 단편화
(B) 연결 할당 : 블록 포인터 연결 -> 단편화 해결 / 직접 접근 불가
(C) 색인 할당 : i-node에 포인터 집중 -> 현대 표준 (Ext4/XFS)
```

```text
[ i-node 다계층 구조 ]

[i-node 메타데이터]
   +---> 직접 블록 (0~11)
   +---> 단일 간접
   +---> 이중 간접
   +---> 삼중 간접 (PB급 파일)
```

## Ⅳ. 할당 방식 비교

- 핵심 요약 : **I/O 성능·단편화·직접 접근** 비교.

| 항목 | 연속 할당 | 연결 할당 | 색인 할당 |
|---|---|---|---|
| 순차 I/O | 극상 | 중간 | 고속 |
| 직접 접근 | 가능 | 불가 | 가능 |
| 단편화 | 외부 단편화 심각 | 없음 | 없음 |
| 현대 사용 | 제한적 | FAT | Ext4/XFS 표준 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **단편화·크래시·소용량 파일**을 익스텐트·저널링·인덱싱으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 단편화/I/O 트레이드오프 | 연속 할당 외부 단편화, 연결/색인 포인터 오버헤드 | 익스텐트 기반 할당, 디프래그 | I/O 지연 |
| 크래시 메타데이터 불일치 | 비정상 종료 시 고아 블록·파일 손상 | 저널링(JBD2), CoW(ZFS/Btrfs) | 복구 시간 |
| 소용량 파일 i-node 고갈 | i-node 100% 소진, 디렉터리 룩업 병목 | dir_index(HTree), 아카이빙, S3 | i-node 사용률 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **XFS·Direct I/O·익스텐트**로 DBMS 스토리지 최적화.
- DBMS 데이터 파일 : XFS 채택 (병렬 I/O, 저널링 지연 적음).
- Direct I/O (O_DIRECT) : 이중 버퍼링 배제.
- 익스텐트 기반 할당으로 단편화 방지.

## Ⅶ. 결론

- 핵심 요약 : 파일 시스템은 **할당·i-node·저널링**으로 데이터 영속화·무결성 확보.
- 답안에는 3대 할당, i-node, 한계·대응, DBMS 최적화를 연결.
