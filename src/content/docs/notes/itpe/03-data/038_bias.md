## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 품질 → **편향(Bias)**

## 30초 인출

- 본질: 편향은 데이터·모형·의사결정 과정에서 결과가 특정 방향으로 체계적으로 치우치는 현상
- 메커니즘: 문제 정의·표본 선정·측정과 라벨·모형 학습·운영의 각 단계에서 생긴 왜곡이 다음 단계로 전파되며, 집단별 오류를 원인 단계로 역추적해 수정
- 통찰: 전체 평균 성능이 좋아도 일부 집단의 오류가 클 수 있고 표본 수를 늘려도 대표성이 자동 해결되지 않으므로 집단별 지표로 원인 단계를 찾아 그 단계에서 완화

<details>
<summary>핵심 용어</summary>

- **편향(Bias)** : 결과가 특정 방향으로 체계적으로 치우치는 현상
- **표집 편향(Selection Bias)** : 표본이 모집단을 대표하지 못해 생기는 치우침
- **측정·라벨 편향** : 집단별 측정오차나 주관적 라벨링으로 생기는 치우침
- **분산(Variance)** : 학습 데이터가 달라질 때 결과가 변동하는 정도
- **이상치(Outlier)** : 주변 자료와 크게 떨어진 개별 관측값
- **추정량 편향(Estimator Bias)** : 추정량의 기대값과 모수의 차이
- **공정성 지표** : 집단별 오류율·선택률 등의 차이를 재는 지표

</details>

## 2~4교시 25점 답안

## Ⅰ. 편향의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **편향** 은 결과가 특정 방향으로 체계적으로 치우치는 현상 |
| 목적 | 원인과 영향을 찾아 분석·예측 결과의 왜곡과 부당한 영향 감소 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 체계적 방향성 | 우연한 이탈과 달리 특정 방향으로 왜곡이 반복 |
| 단계 간 전파 | 표집·측정의 왜곡이 학습·운영 결과로 이어짐 |
| 집단별 영향 차이 | 전체 평균이 양호해도 일부 집단의 오류가 큼 |

## Ⅲ. 원인과 발생 단계

```text
집단별 오류·업무 피해 확인
      ↓ 원인 단계 역추적
표본 구성 차이?  → 수집·표집 재설계
측정·라벨 차이?  → 측정 기준·검수 수정
목표·운영 차이?  → 목적함수·승인 절차 재검토
```

| 단계 | 대표 원인 | 확인할 근거 |
|---|---|---|
| 문제 정의 | 잘못된 대리 목표 설정 | 의사결정 목적·업무 규칙 |
| 데이터 구성 | 표집·선택·생존 편향 | 모집단과 표본의 차이 |
| 측정·라벨링 | 집단별 측정오차·주관적 라벨 | 측정 절차·라벨 기준 |
| 모형·배포 | 특징 선택·손실함수·사용 맥락 부적합 | 집단별 오류와 업무 영향 |

## Ⅳ. 이상치·분산과의 구별과 완화

| 개념 | 의미 | 구별점 |
|---|---|---|
| 편향 | 결과가 체계적으로 치우침 | 반복·구조적 원인 |
| 분산 | 데이터가 달라질 때 결과가 변동 | 불안정성 |
| 이상치 | 개별 관측값이 크게 떨어짐 | 하나의 이상치가 편향의 충분조건은 아님 |
| 추정량 편향 | 추정량 기대값과 모수의 차이 | 통계적 추정량의 성질 |

| 완화 위치 | 조치 | 주의 |
|---|---|---|
| 사전 처리 | 표집·측정 개선, 누락 자료 보완 | 표본 수 증대만으로 대표성 해결 안 됨 |
| 학습 과정 | 목적함수·특징·가중치 조정 | 공정성 지표 간 상충 |
| 사후·운영 | 결과 검토, 절차 수정, 지속 감시 | 임계값 조정이 항상 공정하지 않음 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 공정성 정의의 차이 | 보호 대상·의사결정 맥락·오류 비용에 따라 기준 명시 |
| 지표 간 상충 | 한 지표 개선이 다른 집단의 불이익을 키우는지 확인 |
| 사회기술적 원인 | 성능 지표뿐 아니라 업무 규칙·이의 제기 경로 검토 |
| 데이터·환경 변화 | 재학습·업무 변경 후 평가 반복 |

## Ⅵ. 제언

집단별 오류 지표를 상시 점검하고 원인 단계에서 수정하는 절차를 운영

```text
수집(표집 점검) → 라벨링(교차 검수) → 학습(집단별 평가) → 운영(집단별 오류 모니터링)
```

| 구분 | 전체 정확도 중심 평가 | 제언: 집단별 지표 병행 |
|---|---|---|
| 소수 집단 | 가려짐 | 드러남 |
| 원인 파악 | 사후 추적 곤란 | 단계별 역추적 |
