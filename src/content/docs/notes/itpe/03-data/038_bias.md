## 연관 키워드

- 편향, 선택편향, 측정편향, 교란, 생존편향, 공정성

## Ⅰ. 편향의 개요

- 핵심 요약 : 편향은 표본·측정·분석·모형 과정의 체계적 오차로 추정이나 예측이 특정 방향으로 왜곡되는 현상.
- 개념 : 편향은 표본·측정·분석·모형 과정의 체계적 오차로 추정이나 예측이 특정 방향으로 왜곡되는 현상.
- 배경 및 필요성 : 비무작위 표본과 데이터 생성·측정 절차가 모집단 대표성과 결론을 훼손할 수 있음.
- 주요 목적 : 추론·예측의 신뢰성과 집단 간 공정성 확보.

## Ⅱ. 편향의 특징 및 장점

- 핵심 요약 : 선택편향: 표본 포함이 결과와 관련 → 모집단 추론 왜곡; 측정편향: 집단·조건별 측정오차 차이 → 비교 불공정; 모형편향: 누락변수·가정오류 → 계수·예측 체계적 오차.

1. 선택편향: 표본 포함이 결과와 관련 → 모집단 추론 왜곡
2. 측정편향: 집단·조건별 측정오차 차이 → 비교 불공정
3. 모형편향: 누락변수·가정오류 → 계수·예측 체계적 오차

## Ⅲ. 편향의 구조 (흐름)

- 핵심 요약 : 모집단·추정량 정의 → 표본·측정·라벨 생성과정 감사 → 편향 경로별 정량화 → 설계·가중치·측정·모형 개선 → 집단별 잔여편향 모니터링.

```text
모집단·추정량 정의
  ↓
표본·측정·라벨 생성과정 감사
  ↓
편향 경로별 정량화
  ↓
설계·가중치·측정·모형 개선
  ↓
집단별 잔여편향 모니터링
```

- 핵심 구성 : 모집단 → 표본틀·측정 → 분석자료 → 추정·예측

```text
모집단 → 표본틀·측정 → 분석자료 → 추정·예측
각 단계의 선택·측정 차이를 검증
```

## Ⅳ. 비교: 무작위표본 / 편의표본

- 핵심 요약 : 추론 기준 — 무작위표본: 표본설계 기반 오차 추정 가능; 편의표본: 대표성 편향 정량화 곤란.

| 비교 기준 | 무작위표본 | 편의표본 |
| --- | --- | --- |
| 선정 | 포함확률이 알려진 무작위 절차 | 접근성·자기선택으로 선정 |
| 추론 | 표본설계 기반 오차 추정 가능 | 대표성 편향 정량화 곤란 |

## Ⅴ. 편향의 한계와 방안

- 핵심 요약 : 선택편향·측정편향 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 선택편향 | 응답·생존·접근 여부에 따른 표본 불균형 | 표본틀 개선·가중치·민감도 분석 | 대표성 격차 |
| 측정편향 | 도구·질문·라벨러별 체계 차이 | 측정 프로토콜·집단별 검증·맹검 적용 | 집단별 오차 |
| 교란 | 공통원인이 처치·결과에 함께 영향 | 인과도식·무작위화·층화 등 설계기반 통제 | 잔여교란 |

## Ⅵ. 편향의 제언

- 핵심 요약 : 분석책임자는 데이터 생성과정·표본틀·측정 규칙을 데이터 계보에 포함하고 집단별 편향 감사를 배포 승인에 반영.
- 실행 제안 : 연구·모델 책임자는 표본선정·측정도구·라벨링·모형 단계별 영향 집단과 편향 진단 자료를 배포심사에 제출.

## Ⅶ. 편향의 결론

- 핵심 요약 : 편향은 표본 수를 늘린다고 자동으로 사라지지 않으므로 설계·측정·모형 전 과정의 체계적 오차를 찾아야 함.
- 시사점 : 편향 관리는 표본 설계부터 모델 배포 후 집단별 성과까지 이어지는 연속적 감사가 필요.
