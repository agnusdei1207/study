## 연관 키워드
- 힙, Heap, 최대 힙, 최소 힙, 힙 정렬, 우선순위 큐, 힙 속성, 힙 성질

### Ⅰ. 힙(Heap)의 개요

- 핵심 요약 : 이진 트리 기반 자료구조로, 부모 노드의 값이 자식 노드보다 항상 작거나 같은 (최소 힙) 또는 크거나 같은 (최대 힙) 속성을 만족하는 완전 이진 트리.
- 개념 : 완전 이진 트리 형태에 부모 노드의 값이 자식 노드보다 항상 작거나 같은 (최소 힙) 또는 크거나 같은 (최대 힙) 속성을 가지는 자료구조(**힙**, Heap).
- 배경 및 필요성 : 우선순위 큐 구현, 힙 정렬, 그래프 알고리즘(다이크스트라 알고리즘 등)에서 우선순위 기반 데이터 처리가 필요함.
- 주요 목적 : 최댓값 또는 최솟값을 빠르게 접근하고, 삽입과 삭제 연산을 효율적으로 수행.

### Ⅱ. 힙의 특징 및 장점

- 핵심 요약 : 힙은 완전 이진 트리 구조와 힙 속성을 통해 최댓값 또는 최솟값에 O(1) 시간에 접근할 수 있고, 삽입과 삭제 연산을 O(log n) 시간에 수행할 수 있음.

1. 힙 속성 : 최대 힙은 부모 노드의 값이 자식 노드의 값보다 크거나 같고, 최소 힙은 부모 노드의 값이 자식 노드의 값보다 작거나 같음 → 루트 노드에 최댓값 또는 최솟값이 위치.
2. 완전 이진 트리 : 모든 레벨이 완전히 채워져 있고, 마지막 레벨은 왼쪽부터 채워짐 → 배열로 효율적으로 저장 가능.
3. 배열 기반 구현 : 배열 인덱스를 이용해 부모와 자식 노드 관계를 표현 → 포인터 오버헤드 없이 메모리 효율적으로 관리.

### Ⅲ. 힙의 구조 (흐름)

- 핵심 요약 : 힙은 완전 이진 트리 구조를 배열로 구현하며, 삽입과 삭제 연산 시 힙 속성을 유지하기 위해 힙화(Heapify) 과정을 수행.

```text
[ 힙의 배열 기반 구조 (완전 이진 트리) ]

         [1] 루트 (최댓값 또는 최솟값)
        /    \
      [2]    [3]
     /   \   /   \
   [4]   [5] [6]   [7]
  / \
[8] [9]
```

```text
[ 삽입 연산 흐름 ]
새로운 원소를 배열의 끝에 추가
   ↓
새로운 원소가 부모보다 크면(최대 힙) 또는 작으면(최소 힙) 부모와 교환
   ↓
루트까지 도달하거나 부모보다 작거나 같을 때까지 반복
```

```text
[ 삭제 연산 흐름 ]
루트 노드(최댓값 또는 최솟값) 제거
   ↓
마지막 원소를 루트로 이동
   ↓
새로운 루트를 자식들과 비교하여 더 큰(최대 힙) 또는 작은(최소 힙) 자식과 교환
   ↓
리프 노드에 도달하거나 힙 속성을 만족할 때까지 반복
```

### Ⅳ. 힙 정렬 vs 다른 정렬 알고리즘 비교

- 핵심 요약 : 힙 정렬은 최악의 경우에도 O(n log n)의 시간 복잡도를 보장하며, 추가 메모리 공간이 거의 필요하지 않음.

| 정렬 알고리즘 | 평균 시간 복잡도 | 최악 시간 복잡도 | 공간 복잡도 | 안정성 |
|---|---|---|---|---|
| 힙 정렬 | O(n log n) | O(n log n) | O(1) | 불안정 |
| 퀵 정렬 | O(n log n) | O(n²) | O(log n) | 불안정 |
| 병합 정렬 | O(n log n) | O(n log n) | O(n) | 안정 |

### Ⅴ. 힙의 한계와 방안

- 핵심 요약 : 힙은 임의 접근이 어렵고, 안정성이 보장되지 않으며, 중복된 값 처리에 주의가 필요함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 임의 검색 비효율 | 특정 원소를 찾기 위해 모든 노드를 순회해야 할 수 있음 | 해시 테이블과 결합하여 검색 속도 향상 | 검색 시간 |
| 안정성 미보장 | 동일한 값의 상대적 순서가 보장되지 않음 | 안정성이 필요한 경우 병합 정렬 등 다른 알고리즘 사용 | 정렬 안정성 |
| 메모리 사용량 | 완전 이진 트리 구조를 배열로 구현하므로 연속된 메모리 공간 필요 | 연결 리스트 기반 힙 구현 고려 | 메모리 사용량 |

### Ⅵ. 힙에 대한 기술사적 제언

- 핵심 요약 : 힙은 우선순위 큐 구현, 힙 정렬, 그래프 알고리즘(다익스트라 알고리즘 등)에서 효율적으로 사용될 수 있음.
- 실행 제언 : 힙을 사용할 때는 삽입과 삭제 연산이 빈번히 발생하는지, 최댓값 또는 최솟값에 빈번하게 접근하는지 등을 고려하여 적절한 자료구조를 선택해야 함.

### Ⅶ. 결론

- 핵심 요약 : 힙은 완전 이진 트리 기반 자료구조로, 힙 속성을 통해 최댓값 또는 최솟값에 빠르게 접근할 수 있으며, 우선순위 큐 구현과 힙 정렬 등에 널리 활용됨.
- 시사점 : 힙은 임의 검색이 비효율적이고 안정성이 보장되지 않으므로, 사용 사례에 적합한지 검토 후 적용해야 함.
