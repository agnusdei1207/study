## 연관 키워드

**옵티마이저(Optimizer)**, **RBO/CBO**, **실행 계획(Execution Plan)**, **카디널리티(Cardinality)**, **선택도(Selectivity)**, **힌트(Hint)**, **히스토그램(Histogram)**

## Ⅰ. 개요

- 핵심 요약 : **옵티마이저**는 SQL을 입력받아 통계정보 기반으로 최적 실행 계획을 생성하는 DBMS 핵심 엔진.
- 목적 : "무엇(What)"만 선언하면 "어떻게(How)"는 옵티마이저가 결정.
- 배경 : 동일 SQL도 접근 경로에 따라 성능 차이가 커 실행 계획 최적화 필요.
- 특징 : RBO(규칙 기반) → CBO(비용 기반)로 진화, 통계정보·비용 모델 활용.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **CBO**는 통계정보와 비용 모델로 데이터 볼륨에 맞는 최적 계획 생성.
- **비용 기반** : I/O·CPU 비용 계산으로 최적 경로 선택.
- **통계 활용** : 테이블·인덱스·컬럼 통계로 카디널리티 예측.
- **적응형** : 데이터 분포·볼륨 변화에 계획 자동 조정.
- **힌트 지원** : 필요 시 개발자가 실행 계획 유도 가능.
- **히스토그램** : 편향된 컬럼 분포 정밀 반영.

## Ⅲ. 내부 메커니즘 및 학습 흐름

- 핵심 요약 : **쿼리 변환 → 비용 예측 → 계획 생성** 3단계로 최적 계획 확정.
- 선택도(Selectivity) = 1/NDV, 카디널리티(Cardinality) = 총 행 수 × 선택도.

```text
[ CBO 내부 처리 프로세스 ]

SQL 입력
   |
   v
[1. 쿼리 변환기] 서브쿼리 언네스팅, 뷰 머징, 조건절 푸시다운
   |
   v
[2. 비용 예측기] 카디널리티, 선택도, Cost 계산
   |
   v
[3. 계획 생성기] 조인 순서·기법·인덱스 조합 탐색
   |
   v
[최적 실행 계획 확정]
```

```text
[ RBO vs CBO ]

RBO : 15개 우선순위 규칙, 통계 미사용, 인덱스 있으면 무조건 사용
CBO : 비용 계산, 통계 필수, 대량 조회 시 Full Scan 선택 가능
```

## Ⅳ. RBO vs CBO 비교

- 핵심 요약 : **통계 활용·비용 모델·적응성**으로 CBO가 표준.

| 항목 | RBO (규칙 기반) | CBO (비용 기반) |
|---|---|---|
| 최적화 기준 | 우선순위 규칙 (Rank 1~15) | I/O·CPU 비용 |
| 통계 활용 | 미사용 | 필수 |
| 인덱스 판단 | 있으면 무조건 사용 | 비용에 따라 선택 |
| 현재 위상 | 레거시 (지원 중단) | 현대 RDBMS 표준 |

- 바인드 피킹·다중 조건 오차·통계 부재는 CBO 한계.

## Ⅴ. 한계와 방안

- 핵심 요약 : **바인드 피킹·비용 추정 오차·통계 부재**를 적응형 공유·확장 통계·스케줄링으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 바인드 피킹 | 최초 파싱 값 기준 계획 캐시 → 후속 쿼리 비효율 | ACS 활성화, 편향 조건 리터럴 사용, SPM 고정 | 실행 계획 안정성 |
| 비용 추정 오차 | 컬럼 독립성 가정으로 다중 조건 오차 증폭 | 확장 통계, 동적 표본추출, 힌트 유도 | 추정 vs 실제 행 수 |
| 통계 부재 | DDL·배치 후 통계 누락으로 최악 계획 | 증분 통계 수집, 심야 수집 스케줄, 통계 잠금 | 통계 수집 성공률 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **힌트 남용 회피·히스토그램 전략·통계 관리**로 안정적 성능.
- 힌트는 긴급 조치용으로 한정, 근본은 통계 갱신·인덱스 재설계.
- 편향 컬럼에 히스토그램 수집 (Frequency/Height-Balanced).
- 배치 직후 증분 통계 수집 프로세스 내재화.

## Ⅶ. 결론

- 핵심 요약 : 옵티마이저는 **통계 기반 비용 최적화 엔진**으로 CBO가 표준, 통계 관리가 핵심.
- 답안에는 RBO/CBO 비교, 내부 3모듈, 카디널리티·선택도, 한계·대응을 연결.
