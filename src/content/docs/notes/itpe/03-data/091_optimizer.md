## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터베이스 성능 → **옵티마이저(RBO·CBO)**

## 30초 인출

- 본질: 옵티마이저는 SQL을 수행할 실행계획 후보를 평가해 결과는 같으면서 자원이 적게 드는 계획을 선택하는 DBMS 구성요소
- 메커니즘: 질의를 동등한 형태로 변환하고 접근 경로와 조인 순서·방식의 후보를 만들어, 통계로 중간 결과 행 수를 추정하고 CPU·I/O 비용을 비교해 계획을 고름
- 통찰: 비용 기반(CBO)은 통계와 추정에 의존하므로 통계가 낡거나 데이터가 편중되면 예상 행 수와 실제가 어긋나 나쁜 계획을 고르며, 실제 행 수와 대조해 통계·질의를 관리

<details>
<summary>핵심 용어</summary>

- **옵티마이저(Optimizer)** : 실행계획을 평가·선택하는 DBMS 구성요소
- **RBO(Rule Based Optimizer)** : 미리 정한 규칙 우선순위로 계획을 선택하는 방식
- **CBO(Cost Based Optimizer)** : 통계와 비용 추정으로 후보를 비교하는 방식
- **카디널리티(Cardinality)** : 연산 결과의 행 수
- **선택도(Selectivity)** : 조건이 통과시키는 행의 비율
- **통계정보** : 옵티마이저가 쓰는 데이터 분포 정보
- **실행계획** : 질의를 처리하는 경로

## 2~4교시 25점 답안

## Ⅰ. 옵티마이저의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **옵티마이저** 는 SQL을 수행할 실행계획 후보를 평가·선택하는 DBMS 구성요소 |
| 목적 | 결과를 유지하면서 적절한 자원으로 실행할 방법 선택 |

## Ⅱ. 특징

| 특징 | 판단 대상 | 결과 |
|---|---|---|
| 논리적 동등성 유지 | 결과가 같은 후보 계획 | 실행 방법만 변경 |
| 비용 추정 | 행 수·접근 경로·조인 순서 | 추정 비용이 작은 후보 선택 |
| 통계 의존 | 데이터 분포·선택도 | 통계 오차가 계획 품질에 영향 |

## Ⅲ. 계획 선택 절차

```text
SQL 파싱 → 결과가 같은 형태로 변환
   ↓ 접근 경로 × 조인 순서·방식 후보 생성
통계·선택도로 중간 결과 행 수 추정 → 후보별 CPU·I/O 비용 비교
   ↓ 선택 계획 실행
실제 행 수·시간 관측 → 추정 오차 점검
```

## Ⅳ. RBO와 CBO 비교

| 비교 기준 | RBO | CBO |
|---|---|---|
| 계획 선택 | 미리 정한 규칙 우선순위 | 통계와 비용 추정으로 후보 비교 |
| 주요 입력 | 질의 형태·적용 규칙 | 통계정보·분포·비용 모델 |
| 데이터 변화 | 데이터량·분포 변화를 직접 반영하기 어려움 | 통계 갱신으로 추정에 반영 |
| 유의점 | 규칙 우선순위가 실제 부하와 맞지 않을 수 있음 | 통계·추정 오차로 실제와 어긋날 수 있음 |

현대 DBMS는 대체로 비용 기반 최적화를 채택하며 세부 기능은 제품별로 달라 DBMS별 특성에 맞춰 실행계획을 분석.

| 확인 항목 | 점검 방법 |
|---|---|
| 추정 정확도 | 예상 행 수와 실제 행 수 비교 |
| 접근 경로 | 인덱스·스캔 선택이 범위·분포에 맞는지 |
| 조인·정렬 | 중간 결과 크기와 메모리·임시 저장 사용 |
| 안정성 | 대표 분포·부하에서 편차·회귀 측정 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 통계가 낡아 예상 행 수와 실제가 다름 | 통계 수집 기준 관리, 추정·실제 행 수 비교 |
| 데이터 편중을 평균 선택도가 가림 | 편중 열의 분포·상관 확인, 통계 표현 조정 |
| 계획 변경 후 실행 시간 회귀 | 변경 전후 계획과 부하 성능 기록·비교 |

## Ⅵ. 제언

통계를 주기적으로 관리하고 대표 질의의 예상·실제 행 수를 점검해 계획 회귀를 감시

```text
통계 수집 관리 → 대표 질의 계획 기록 → 예상·실제 행 수 비교 → 변경 전후 회귀 점검
```

| 구분 | 계획 방치 | 제언: 통계·계획 관리 |
|---|---|---|
| 추정 오차 | 누적 | 점검 |
| 회귀 | 장애 후 발견 | 사전 발견 |
