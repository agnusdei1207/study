## 답안 골격
```text
[ROC 곡선] ◀━━ 머리: Ⅶ 내 의견 (불균형 데이터에서는 ROC-AUC 맹신 지양 → PR(Precision-Recall) 곡선 병행 평가)
 ┃
 ┣━ Ⅰ 개요 ───── 분류 모델의 임계값(Threshold) 변화에 따른 성능 궤적 → TPR과 FPR의 상관관계를 시각화한 평가 도구
 ┣━ Ⅱ 특징 ───── 임계값 독립적 평가 · 2차원 시각화 곡선 · 면적 기반 AUC(Area Under Curve) 단일 지표 요약
 ┣━ Ⅲ 구조 ───── X축: FPR(1 - 특이도) / Y축: TPR(재현율/민감도) / 기준선(대각선 무작위 찍기 0.5) / 면적(AUC)
 ┣━ Ⅳ 흐름 ───── ① 모델의 양성 확률값 도출 → ② 임계값을 1에서 0까지 연속 변경 → ③ 임계값별 (FPR, TPR) 점 산출 → ④ 곡선 작도 및 AUC 계산
 ┣━ Ⅴ 비교 ───── ROC 곡선 vs PR 곡선 (클래스 균형 데이터 vs 극단적 불균형 데이터)
 ┗━ Ⅵ 실무 ───── 음성 데이터가 압도적으로 많을 때 AUC 점수 착시 / 최적 임계값 선정 실패
```
- 필수 키워드: ROC 곡선 · AUC · TPR(민감도) · FPR(1-특이도) · 혼동행렬(Confusion Matrix) · 임계값(Threshold) · Youden's J Index
- 배점 전략: 10점 = Ⅰ → Ⅲ ROC 곡선 도식 및 축 공식 매핑 → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅲ 그래프 도식 및 Ⅴ ROC vs PR 곡선 비교표
- 기출: 135회 `분류 모델 평가 지표` → 혼동행렬 및 ROC/AUC / 102회 `ROC 곡선 분석` → 개념 및 해석

## 한 줄 본질
- 분류 임계값(0.5) 하나에 고정된 단편적 평가의 한계 → 임계값을 0부터 1까지 이동시키며 얻는 민감도(TPR)와 위양성률(FPR)의 궤적 → 모델 자체의 전반적인 변별력을 단일 면적(AUC)으로 객관화

## 핵심 그림
```text
[ROC 곡선과 AUC (Area Under Curve)]

   TPR (민감도)
   1.0 |         ***** (우수한 모델: 좌상단에 붙음, AUC -> 1.0)
       |       *
       |     *
       |    *
       |   *    / (무작위 모델: 대각선, AUC = 0.5)
       |  *   /
       | *  /
   0.0 +──/───────────> FPR (1 - 특이도)
      0.0             1.0

   - TPR (True Positive Rate)  = TP / (TP + FN)  [실제 암환자 중 맞힌 비율]
   - FPR (False Positive Rate) = FP / (FP + TN)  [정상인 중 암이라고 오진한 비율]
```

## 핵심 용어
- AUC(Area Under the Curve): ROC 곡선 아래의 면적으로, 1.0에 가까울수록 완벽한 변별력을 의미하며 0.5는 동전 던지기 수준의 쓸모없는 모델
- Youden's J Index: $J = TPR - FPR = 민감도 + 특이도 - 1$로 정의되며, ROC 곡선에서 대각선으로부터의 수직 거리가 가장 먼 지점을 최적 임계값으로 채택

## 핵심 통찰
- 정확도(Accuracy)는 클래스 불균형에 속음 → 암 환자가 1%일 때 무조건 "정상"이라고만 답해도 정확도는 99%가 되지만, ROC 곡선은 모든 임계값에서의 민감도와 특이도를 보므로 모델의 무능함을 폭로함
- 그러나 ROC 곡선도 극단적 불균형에서는 '착시'를 일으킴 → 정상인이 999,900명이고 환자가 100명일 때, 정상인을 1,000명 오진해도 FPR은 $1000/999900 \approx 0.001$로 여전히 매우 낮아 ROC 곡선은 훌륭해 보임
- 따라서 희귀 질환, 사기 탐지(FDS)처럼 음성이 압도적인 도메인에서는 정밀도(Precision)와 재현율(Recall)만을 축으로 삼는 PR 곡선을 반드시 함께 봐야 함

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 혼동행렬 (Confusion Matrix) | ROC 곡선의 수학적 기초 | TP, FP, FN, TN 4개 칸으로 모델의 예측과 실제 정답을 교차 집계한 행렬 |
| PR AUC (Average Precision) | 불균형 데이터 특화 지표 | 정밀도-재현율 곡선 아래의 면적으로, 소수 양성 클래스 예측 정확성에 집중 |

## 이웃 토픽과 구분
- ROC 곡선 vs PR 곡선: ROC 곡선 = 음성(TN)이 분모에 들어가 클래스 비율 변화에 둔감(안정적) / PR 곡선 = 음성(TN)이 배제되어 소수 클래스 탐지 성능 변화에 매우 민감

## 문제·원인·대책
- 적용 상황: 금융 부정 결제(FDS) 사기 거래 탐지 모델 평가
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| ROC-AUC 0.98 모델을 배포했으나 실제 운영에서 오탐(FP)으로 정상 거래 정지 속출 | 비사기 거래가 99.9%여서 FPR이 극도로 작게 계산되는 ROC 착시 | PR 곡선 및 F1-Score, 정밀도(Precision) 중심 재평가 | 실질 오탐률 80% 감축 |
| 기본 임계값(0.5) 적용으로 인해 암 환자 진단 누락(FN) 발생 | 질병 진단에서는 미탐(FN)의 치명적 비용 미반영 | Youden's J 지수 또는 비용 행렬(Cost Matrix)을 적용해 임계값을 0.2로 하향 | 환자 재현율(Recall) 99% 달성 |
