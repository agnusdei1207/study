## 30초 인출

- 본질: 빅데이터 분석 도구 선정은 업무 요구와 데이터·운영 조건에 맞는 도구를 평가해 고르는 의사결정
- 메커니즘: 업무·데이터·SLO·보안 요구로 평가축과 가중치를 합의하고, 처리 유형별 후보를 대표 워크로드로 PoC해 성능·정확성·운영·TCO를 비교한 뒤 선정하고 운영 지표와 초기 가정을 비교해 재평가
- 통찰: 기능표나 벤치마크 수치만으로는 실제 데이터·동시성·운영 인력비가 빠지므로 실패·재처리·장애 복구까지 포함한 PoC와 수명주기 비용으로 비교

<details>
<summary>핵심 용어</summary>

- **워크로드(Workload)** : 배치·스트림·대화형 질의 같은 실제 처리 부하
- **PoC(Proof of Concept)** : 대표 데이터와 시나리오로 후보를 실제로 시험하는 검증
- **SLO** : 지연·가용성 등 서비스 수준 목표
- **TCO** : 도입·운영·인력·이관을 포함한 총 소유 비용
- **스트림·배치 처리 엔진** : 지속 유입 이벤트 처리 / 대용량 일괄 처리 도구
- **연합 질의 엔진** : 여러 저장소를 하나의 SQL로 질의하는 도구

</details>

## 2~4교시 25점 답안

## Ⅰ. 빅데이터 분석 도구 선정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **분석 도구 선정** 은 업무 요구와 데이터·운영 조건에 맞는 도구를 평가·선정하는 의사결정 |
| 목적 | 요구 성능과 분석 활용을 달성하면서 비용·운영 위험 관리 |

## Ⅱ. 특징

| 특징 | 선택상 의미 |
|---|---|
| 워크로드 우선 | 제품 이름보다 배치·스트림·대화형 질의의 부하와 지연 요구를 먼저 정의 |
| 동일 조건 비교 | 대표 데이터·동시성·장애 시나리오를 같은 조건으로 후보에 적용 |
| 수명주기 비용 | 도입가뿐 아니라 운영 인력·저장·컴퓨팅·이관 비용 평가 |

## Ⅲ. 평가 절차(PoC)

```text
업무·데이터·SLO·보안 요구 → 평가축·가중치 합의
   ↓ 처리 유형별 후보 선정 → 대표 워크로드 PoC
      (실제 형식·규모 데이터 + 대표 질의·동시 사용자, 같은 환경에서 후보별 실행)
   ↓ 정확성·지연·처리량·장애 복구·자원 사용 기록
성능·정확성·운영·TCO 비교 → 선정·예외 기록 → 운영 지표와 초기 가정 비교·재평가
```

PoC에서 실패·재처리와 운영자 개입까지 기록해야 벤치마크와 실제 운영 TCO의 격차를 알 수 있음.

## Ⅳ. 워크로드별 도구 유형과 평가축

| 워크로드 요구 | 우선 검토 유형 | 검증점 |
|---|---|---|
| 지속 유입 이벤트 처리 | 스트림 처리 엔진 | 상태·체크포인트·지연·재처리 |
| 대용량 변환·모델 학습 | 분산 배치 처리 엔진 | 셔플·메모리·확장·작업 재시작 |
| 여러 저장소 탐색 질의 | 분산 SQL·연합 질의 엔진 | 커넥터·푸시다운·원천 부하 |
| 제한된 규모의 대화형 분석 | 단일 노드 엔진·노트북 도구 | 메모리 한계·동시 사용자·재현성 |

도구 유형은 초기 후보군이며 실제 성능을 고정값으로 보장하지 않으므로 데이터와 구성에 맞춰 검증.

| 평가축 | 확인 항목 |
|---|---|
| 워크로드·데이터 | 배치·스트림·SQL·학습, 규모·형식·유입률 |
| 서비스 품질 | 지연·처리량·가용성·복구 |
| 운영·보안 | 권한·감사·연계·기술지원·운영 역량 |
| 비용·종속성 | 라이선스·컴퓨팅·저장·인력·이관비 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 기능표·벤치마크 수치만으로 실제 조건 누락 | 업무 시나리오 PoC와 사전 합의한 평가 기준 |
| 처리량만 평가해 장애 복구·재처리 실패 누락 | 오류·재시작 시나리오를 PoC에 포함 |
| 도입 후 데이터·워크로드 변화 미반영 | 운영 SLO·비용 추이를 기준선과 비교해 재평가 |

## Ⅵ. 제언

요구를 먼저 정량화하고 대표 워크로드 PoC와 TCO로 후보를 비교하며 도입 후에도 재평가

```text
요구 정량화(SLO) → 후보 → 대표 워크로드 PoC(장애 포함) → TCO 비교 → 선정 → 운영 재평가
```

| 구분 | 기능표·벤치마크 비교 | 제언: PoC + TCO |
|---|---|---|
| 실제 조건 | 미반영 | 대표 워크로드 반영 |
| 비용 | 도입가 | 수명주기 비용 |
