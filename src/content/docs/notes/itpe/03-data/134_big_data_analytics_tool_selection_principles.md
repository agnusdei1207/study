## 30초 인출

- 본질: **빅데이터 분석도구 선정**은 업무 요구에 맞는 수집·저장·처리·분석 도구를 고르는 의사결정
- 메커니즘: 데이터·처리특성·서비스 수준·운영역량을 요구사항과 대조하고 검증
- 판단: 제품 이름이나 데이터 크기만으로 정하지 않고 대표 워크로드의 적합성·비용·운영성을 함께 비교

<details>
<summary>핵심 용어</summary>

- **서비스 수준 목표(Service Level Objective, SLO)**: 서비스가 충족해야 할 측정 가능한 신뢰성·성능 목표
- **총소유비용(Total Cost of Ownership, TCO)**: 도입·운영·인력·이관 등 수명주기 비용의 합
- **개념검증(Proof of Concept, PoC)**: 핵심 기술 위험과 요구 적합성을 제한된 범위에서 검증하는 활동

</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 업무 요구와 데이터·운영 조건에 맞는 분석 도구를 평가·선정하는 의사결정 |
| 목적 | 요구 성능과 분석 활용을 달성하면서 비용·운영 위험을 관리 |

### Ⅱ. 평가 기준

| 기준 | 확인 내용 |
|---|---|
| 처리 적합성 | 배치·스트림·대화형 질의 등 처리 형태 |
| 데이터 특성 | 규모, 형식, 유입률, 보존·갱신 요구 |
| 서비스 수준 | 지연, 처리량, 가용성, 복구 목표 |
| 운영 적합성 | 기술 역량, 보안, 상호운용성, 지원성 |
| 경제성 | 인프라·라이선스·인력·이관을 포함한 TCO |

### Ⅲ. 한 줄 제언

제언: 필수 요구와 평가 가중치를 먼저 합의하고, 대표 데이터와 질의로 PoC를 수행해 선정 근거를 기록.

## 2~4교시 25점 답안

## Ⅰ. 빅데이터 분석도구 선정 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 업무 요구와 데이터·운영 조건에 맞는 분석 도구를 평가·선정하는 의사결정 |
| 목적 | 요구 성능과 분석 활용을 달성하면서 비용·운영 위험을 관리 |

## Ⅱ. 요구사항과 평가 기준

| 평가축 | 확인 항목 | 근거 자료 |
|---|---|---|
| 워크로드 | 배치·스트림·대화형 SQL·머신러닝 처리 | 대표 업무 시나리오 |
| 데이터 | 규모·형식·유입률·보존·품질 | 실제 또는 대표 데이터 |
| 서비스 품질 | 지연·처리량·가용성·복구 | SLO·부하 패턴 |
| 운영·보안 | 권한·감사·연계·기술지원·운영역량 | 보안·운영 요구사항 |
| 비용·종속성 | 라이선스·컴퓨팅·저장·인력·이관비 | 수명주기 TCO |

## Ⅲ. 요구에 따른 도구 유형 선택

| 워크로드 요구 | 우선 검토할 도구 유형 | 주요 검증점 |
|---|---|---|
| 지속 유입 이벤트 처리 | 스트림 처리 엔진 | 상태·체크포인트·지연·재처리 |
| 대용량 변환·모델 학습 | 분산 배치 처리 엔진 | 셔플·메모리·확장·작업 재시작 |
| 여러 저장소의 탐색 질의 | 분산 SQL·연합 질의 엔진 | 커넥터 기능·푸시다운·원천 부하 |
| 제한된 규모의 대화형 분석 | 단일 노드 분석 엔진·노트북 도구 | 메모리 한계·동시 사용자·재현성 |

도구 유형은 초기 후보군이며 실제 처리량·지연 성능을 고정값으로 보장하지 않으므로, 데이터와 구성에 맞춘 검증 필요.

## Ⅳ. 선정·검증 절차

| 순서 | 수행 내용 | 산출·판정 |
|---|---|---|
| 요구 정의 | 사용자·데이터·SLO·보안·운영 제약 정리 | 우선순위가 있는 요구 목록 |
| 후보 구성 | 처리 방식과 플랫폼 적합성으로 후보 축소 | 비교 가능한 후보군 |
| PoC | 대표 데이터·질의·장애·확장 시나리오 실행 | 성능·비용·운영 근거 |
| 평가 | 가중치 적용, 위험·종속·이관 부담 대조 | 선정안·대안·예외 |
| 운영 검증 | 실서비스 지표와 비용 추이를 확인 | 지속 개선 기준 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 기능표·벤치마크 수치만으로 선정하면 실제 운영의 데이터 특성·동시성·인력비가 반영되지 않음 | 실제 업무 시나리오 기반 PoC를 수행하고 성능·비용·보안·운영성의 평가기준과 가중치를 사전에 합의 |

## 출제 이력과 검증 출처

- 분석도구의 성능은 제품 버전, 구성, 데이터, 워크로드에 따라 달라지므로 고정 지연시간·데이터 용량 기준은 제시하지 않음.
