## 연관 키워드
- 데이터베이스 복제, 동기식 복제, 비동기식 복제, 반동기식 복제, 단일 리더 복제, 다중 리더 복제, 리더리스 복제

### Ⅰ. 데이터베이스 복제의 개요

- 핵심 요약 : 원본 데이터베이스의 데이터를 하나 이상의 복제본에 실시간 또는 주기적으로 복사하여 데이터 가용성과 내결함성을 높이는 기술.
- 개념 : 원본 데이터베이스의 데이터를 하나 이상의 복제본에 지속적으로 동기화하여 데이터 가용성과 내결함성을 높이는 기술(**데이터베이스 복제**, Database Replication).
- 배경 및 필요성 : 단일 데이터베이스 장애 시 서비스 전체가 중단될 위험이 있으므로, 데이터 중복을 통해 가용성과 읽기 성능을 향상시킬 필요가 있음.
- 주요 목적 : 데이터 가용성 향상, 읽기 성능 향상, 재해 복구 능력 확보.

### Ⅱ. 데이터베이스 복제의 특징 및 장점

- 핵심 요약 : 동기화 방식, 토폴로지, 전송 방식에 따라 다양한 복제 방식이 존재하며, 각각의 특성과 장단점이 있음.

1. **동기식 복제**(Synchronous Replication) : 데이터 쓰기 시 모든 복제본에 즉시 반영 → 강력한 일관성 보장, 쓰기 성능 저하 가능.
2. **비동기식 복제**(Asynchronous Replication) : 쓰기 완료 후 비동기적으로 복제 → 쓰기 성능 우수, 데이터 불일치 가능성.
3. **반동기식 복제**(Semi-Synchronous Replication) : 일부 복제본에만 동기화 적용 → 성능과 일관성의 균형.

### Ⅲ. 데이터베이스 복제의 구조 (흐름)

- 핵심 요약 : 원본 데이터베이스에서 변경 사항을 감지하여 복제본에 전파하는 과정.

```text
[ 동기식 복제 흐름 ]

클라이언트 쓰기 요청
   ↓
마스터 DB에 데이터 쓰기
   ↓
모든 복제본에 데이터 복제 및 확인 응답
   ↓
클라이언트에 커밋 성공 응답
```

```text
[ 비동기식 복제 흐름 ]

클라이언트 쓰기 요청
   ↓
마스터 DB에 데이터 쓰기 및 즉시 커밋
   ↓
비동기적으로 복제본에 데이터 전파
   ↓
클라이언트에 즉시 커밋 성공 응답
```

### Ⅳ. 복제 토폴로지 비교

- 핵심 요약 : 단일 리더, 다중 리더, 리더리스 토폴로지는 각기 다른 쓰기 경로와 충돌 처리 방식을 가짐.

| 비교 항목 | 단일 리더 복제 | 다중 리더 복제 | 리더리스 복제 |
|---|---|---|---|
| 쓰기 경로 | 단일 리더 노드 | 다중 노드에서 쓰기 가능 | 클라이언트가 여러 노드에 직접 쓰기 |
| 충돌 가능성 | 적음 | 높음 (동시 쓰기 시 충돌 가능) | 낮음 (최신 쓰기 우선 또는 충돌 해결 로직 필요) |
| 가용성 | 리더 장애 시 가용성 저하 | 높은 가용성 | 매우 높은 가용성 |
| 데이터 일관성 | 강한 일관성 보장 가능 | 최종 일관성 보장 가능 | 최종 일관성 보장 가능 |

### Ⅴ. 데이터베이스 복제의 한계와 방안

- 핵심 요약 : 복제 지연, 데이터 불일치, 복구 복잡성 등의 한계를 극복하기 위한 다양한 기술과 운영 방안이 있음.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 복제 지연 | 네트워크 지연, 처리량 과부하로 복제 지연 발생 | 비동기 복제 사용 시 지연 시간 모니터링, 네트워크 대역폭 확장 | 복제 지연 시간(Replication Lag) |
| 데이터 불일치 | 동기화 지연으로 인해 복제본 간 데이터 불일치 발생 | 읽기 전용 복제본에 대한 읽기 전용 트랜잭션 사용, 정합성 검사 주기적 수행 | 데이터 불일치 비율 |
| 복구 복잡성 | 노드 장애 시 복구 과정 복잡하고 시간 소요 | 자동 페일오버, 정기적인 백업 및 복구 테스트 | 복구 시간(RTO), 복구 성공률 |

### Ⅵ. 데이터베이스 복제에 대한 기술사적 제언

- 핵심 요약 : 업무 특성과 가용성 요구사항에 적합한 복제 방식을 선택하고, 정기적인 모니터링과 테스트를 통해 데이터 일관성과 가용성을 확보.
- 실행 제언 : 쓰기 성능이 중요한 경우 비동기 복제를, 데이터 일관성이 중요한 경우 동기식 복제를 선택하고, 정기적인 장애 복구 훈련을 통해 복구 절차를 검증할 필요가 있다.

### Ⅶ. 결론

- 핵심 요약 : 데이터베이스 복제는 데이터 가용성과 내결함성을 높이는 중요한 기술로, 적절한 복제 방식과 토폴로지 선택이 중요함.
- 시사점 : 복제 지연과 데이터 불일치를 최소화하기 위해 적절한 동기화 방식과 모니터링 체계를 구축해야 함.
