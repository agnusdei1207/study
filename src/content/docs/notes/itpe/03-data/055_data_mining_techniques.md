## 답안 골격
```text
[데이터 마이닝 기법] ◀━━ 머리: Ⅶ 내 의견 (비즈니스 문제 정의에 따른 기법 앙상블 적용 및 모델 해석 가능성(XAI) 확보)
 ┃
 ┣━ Ⅰ 개요 ───── 비즈니스 목적에 따라 대규모 데이터셋에서 지식을 추출하기 위한 통계·수학·AI 기반 알고리즘 체계
 ┣━ Ⅱ 특징 ───── 목적 지향적(예측/설명) · 지도/비지도 학습 분류 · 정형/비정형 처리 · 알고리즘 다변성
 ┣━ Ⅲ 구조 ───── 분류(Classification) / 회귀(Regression) / 군집화(Clustering) / 연관분석(Association) / 이상탐지(Outlier)
 ┣━ Ⅳ 흐름 ───── ① 문제 유형 식별(목적 변수 유무) → ② 데이터 전처리 및 특성 추출 → ③ 기법 매핑 및 모델링 → ④ 성능 평가(혼동행렬/실루엣)
 ┣━ Ⅴ 비교 ───── 지도 학습 기법 vs 비지도 학습 기법 (목적변수 레이블 존재/성능 명확 vs 레이블 없음/패턴 탐색)
 ┗━ Ⅵ 실무 ───── 차원 과다로 인한 과적합 / 연속형 변수의 무분별한 이산화에 따른 정보 손실
```
- 필수 키워드: 분류(Classification) · 회귀(Regression) · 군집화(Clustering) · 연관규칙(Association Rule) · 의사결정나무 · K-Means · Apriori
- 배점 전략: 10점 = Ⅰ → Ⅲ 기법 분류 매트릭스 도식 → Ⅴ 지도/비지도 비교표 / 25점 = Ⅰ~Ⅶ, Ⅲ 기법별 대표 알고리즘 상세 및 Ⅵ 도메인 적용 사례
- 기출: 129회/130회 `데이터 마이닝의 주요 기법과 특징` → Ⅲ 기법 분류 체계 + 대표 알고리즘 매핑

## 한 줄 본질
- 다양한 데이터 형태와 비즈니스 난제 → 문제 특성(예측, 그룹화, 규칙 도출)에 맞춰 지도·비지도 알고리즘 최적 매핑 → 실행 가능한 패턴 발굴 / 과적합 및 해석 난해성 수반

## 핵심 용어
- Apriori 알고리즘: "한 항목 집합이 빈발하면 그 부분집합도 빈발하다"는 최소 지지도 기반 가지치기(Pruning) 연관 마이닝 기법
- 의사결정나무(Decision Tree): 정보 획득량(Information Gain)이나 지니 계수를 기준으로 데이터를 순차 분할하는 if-then 형태의 직관적 분류 기법

## 핵심 통찰
- 완벽한 만능 기법은 없음(No Free Lunch Theorem) → 데이터의 차원, 노이즈, 선형성 유무에 따라 가장 적합한 기법이 완전히 달라짐
- 비지도 학습(군집, 연관)은 정답 레이블이 없어 '성능 평가'가 주관적임 → 실무에서는 군집 분석 결과를 바탕으로 고객 세그먼트를 정의하고, 이를 지도 학습의 피처나 타깃으로 넘기는 '기법 파이프라이닝'이 일반적
- 딥러닝이 만연해도 정형 테이블 데이터에서는 여전히 트리 기반 앙상블(XGBoost, LightGBM)과 통계 회귀가 속도와 설명력에서 압도적 우위

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 앙상블 기법(Ensemble) | 분류/회귀 마이닝의 성능 고도화 | 여러 개의 약한 학습기(Weak Learner)를 결합(배깅, 부스팅)하여 편향과 분산을 동시 저감 |
| 차원 축소(PCA) | 마이닝 전처리의 핵심 기법 | 고차원 데이터의 변동성을 최대한 보존하면서 직교 축으로 투영해 계산 복잡도 완화 |

## 이웃 토픽과 구분
- 분류(Classification) vs 군집화(Clustering): 분류 = 사전에 정의된 클래스(정답)로 데이터를 배정(지도학습) / 군집화 = 정답 없이 데이터 간 거리를 기반으로 자연스러운 그룹 형성(비지도학습)

## 문제·원인·대책
- 적용 상황: 제조 공정 불량률 예측 및 원인 인자 마이닝
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 신경망 모델로 불량 탐지율 99% 달성했으나 공장 관리자가 원인을 몰라 설비 조치 불가 | 딥러닝 모델의 블랙박스 특성 | 의사결정나무 및 SHAP 기반 피처 기여도 시각화 도입 | 불량 유발 핵심 센서(온도, 압력) 즉시 파악 및 공정 개선 |
| 연관분석 수행 시 수천만 개의 무의미한 규칙이 쏟아져 분석 불가 | 최소 지지도(Minimum Support) 임계값을 너무 낮게 설정 | 최소 지지도 및 최소 향상도(Lift > 1.5) 복합 필터링 적용 | 실효성 있는 교차 판매 규칙 20개로 압축 |

## 이렇게 출제된다
- 제129회: "데이터 마이닝의 주요 분석 기법들을 분류하고, 각 기법의 특징과 적용 사례를 설명하시오." → 요구 포인트: 지도/비지도 기준 분류 매트릭스 + 4대 기법(분류, 회귀, 군집, 연관) 정의 및 대표 알고리즘

## 내 의견
- [화려한 최신 모델 맹신으로 인한 비효율] 단순 로지스틱 회귀나 K-Means로 충분한 비즈니스 문제에 수억 원짜리 LLM이나 딥러닝 클러스터를 도입하여 프로젝트 좌초 → 나라면: 베이스라인 모델로 단순 통계/트리 마이닝 기법을 먼저 구현해 80%의 성능을 수일 내 확보한 후, 추가 비용 대비 성능 개선 여부를 판단하여 고도화 모델 채택

## 찾아볼 것
- FP-Growth 알고리즘이 Apriori의 후보 집합 생성 병목을 트리(FP-Tree) 구조로 해결하는 메커니즘
