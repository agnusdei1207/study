## 연관 키워드

- 정규분포 (Normal Distribution)

## Ⅰ. 정규분포의 개요

- 핵심 요약 : 평균과 분산 두 모수로 결정되는 대칭적 종형 곡선의 연속 확률분포로 자연·사회 현상의 기초 모델.
- 개념 : 확률변수 X가 평균(Mean, μ)과 분산(Variance, σ²) 두 모수로 완전히 결정되며, 평균을 중심으로 좌우 대칭인 종형(Bell-shaped) 확률밀도함수(PDF, Probability Density Function)를 따르는 연속 확률분포. 수학자 칼 프리드리히 가우스(Carl Friedrich Gauss)의 이름에서 가우시안 분포(Gaussian Distribution)라고도 함.
- 배경 및 필요성 : 자연 현상(키, 몸무게, 측정 오차), 사회 현상(시험 점수, 소득 분포), 제조 공정 품질 특성 등 수많은 실측 데이터가 정규분포를 따르거나 근사하므로 통계적 추론의 핵심 기초 모델로 활용.
- 주요 목적 : 표본 통계량의 표본분포 이론 정립, 신뢰구간 추정, 가설검정, 관리도(Control Chart) 등 통계적 품질관리 기반 제공.

## Ⅱ. 정규분포의 특징

- 핵심 요약 : 평균·분산 두 모수, 대칭성, 68-95-99.7 경험 법칙, 중심극한정리에 의한 보편성이 결합된 분포.

1. 두 모수 완전 결정 : 평균 μ(위치 결정)와 표준편차 σ(퍼짐 정도 결정)만으로 분포 형상 완전 규정.
2. 완전한 대칭성 : 평균 μ를 중심으로 좌우 대칭, 왜도(Skewness)=0, 첨도(Kurtosis)=3(초과 첨도=0).
3. 68-95-99.7 경험 법칙(Empirical Rule) :
   - μ ± 1σ 구간 내 데이터 약 68.27%
   - μ ± 2σ 구간 내 데이터 약 95.45%
   - μ ± 3σ 구간 내 데이터 약 99.73%
4. 표준정규분포 변환 : 임의 정규분포 X ~ N(μ, σ²)를 Z = (X-μ)/σ 변환으로 표준정규분포 Z ~ N(0,1)로 표준화.
5. 중심극한정리(Central Limit Theorem) : 독립·동일분포 표본평균의 분포가 표본 크기 n 증가 시 정규분포에 수렴 (모분포 형태 무관).

## Ⅲ. 정규분포의 구조 (흐름)

- 핵심 요약 : 확률밀도함수, 누적분포함수, 표준화 변환, 분위수 계산의 수리적 구조.
- 정규분포 확률밀도함수(PDF)와 누적분포함수(CDF).

```text
[ 정규분포 PDF: f(x) = 1/(σ√2π) * exp(-(x-μ)²/(2σ²)) ]
         ^
    f(x) |           종형 곡선
         |        /\      /\
         |       /  \    /  \
         |      /    \  /    \
         |_____/______\/______\______> x
              μ-σ  μ  μ+σ
        (곡선 아래 면적 = 1, 확률 = 구간 면적)

[ 표준정규분포 CDF: Φ(z) = P(Z ≤ z) ]
         ^
    Φ(z) | 1.0 ──────────────────
         |      ╱
         |    ╱
         |  ╱
         |╱
    0.0  +─────────────────────> z
         -3   -2  -1  0  1  2  3
```

- 표준화 변환과 확률 계산 흐름.

```text
[ 확률 계산 표준화 흐름 ]
X ~ N(μ, σ²)  (임의 정규분포)
    │
    ▼ Z = (X - μ) / σ  (표준화 변환)
Z ~ N(0, 1)  (표준정규분포)
    │
    ▼ P(a ≤ X ≤ b) = P((a-μ)/σ ≤ Z ≤ (b-μ)/σ)
    │
    ▼ 표준정규분포표(CDF Φ(z)) 또는 소프트웨어로 구간 확률 계산
    │
    ▼ 역변환: 분위수 x = μ + z_α * σ
```

## Ⅳ. 정규분포와 다른 연속 분포의 비교

- 핵심 요약 : 대칭적 종형 곡선인 정규분포와 비대칭/중첩 분포들의 형태·용도 비교.

| 비교 항목 | 정규분포(Normal) | 지수분포(Exponential) | 감마분포(Gamma) | t-분포(Student's t) |
|---|---|---|---|---|
| 형태 | 대칭적 종형 (Bell) | 우측 치우침 (Right-skewed) | 형상 모수에 따라 다양 | 정규분포 유사하나 꼬리 두꺼움 |
| 모수 | μ(평균), σ²(분산) | λ(비율) 또는 β(규모) | k(형상), θ(규모) | ν(자유도) |
| 지지역 | (-∞, ∞) | [0, ∞) | [0, ∞) | (-∞, ∞) |
| 주요 용도 | 자연 현상, 측정 오차, 표본평균 | 대기 시간, 고장 간격 | 대기 시간 합, 베이지안 사전분포 | 소표본 평균 검정 (σ 미지) |
| 중심극한정리 | 표본평균 분포의 극한 | - | - | n→∞ 시 정규분포 수렴 |

## Ⅴ. 정규분포의 장점과 한계

- 핵심 요약 : 수리적 편의성과 보편적 적용성의 장점, 꼬리 얇음과 이상치 민감성의 한계.
- 장점
  1. 수리적 조작 용이 : 선형 결합, 합/차, 조건부 분포가 모두 정규분포 유지 (안정성).
  2. 중심극한정리 기반 보편성 : 표본 크기 충분 시 표본평균 분포를 정규분포로 근사 가능.
  3. 풍부한 통계적 도구 : Z-검정, t-검정, ANOVA, 회귀분석, 관리도 등 정규성 가정 하 이론 완비.
- 한계점 1 : 꼬리가 얇아 극단값(이상치) 확률 과소평가
  - 한계점 : 실제 데이터(금융 수익률, 네트워크 트래픽)는 정규분포보다 꼬리가 두꺼운 '팻 테일(Fat Tail)' 특성 보여, VaR(Value at Risk) 등 위험도 과소평가 위험.
  - 해결 방안 : t-분포, 안정 분포(Stable Distribution), 일반화 오차 분포(Generalized Error Distribution) 등 대안 분포 적용, 강건 통계(Robust Statistics) 활용.
- 한계점 2 : 음수 불가능한 데이터(대기시간, 매출액)에 부적합
  - 한계점 : 정규분포는 (-∞, ∞) 지지역을 가져 양수만 가능한 변수에 적용 시 음수 확률 부여.
  - 해결 방안 : 로그정규분포(Log-Normal), 감마분포(Gamma), 베이불분포(Weibull) 등 양수 지지역 분포 적용, Box-Cox 변환으로 정규성 확보 후 분석.
- 한계점 3 : 다변량 정규성 가정의 실무 위배 빈번
  - 한계점 : 다변량 분석(MANOVA, 판별분석, 주성분분석)에서 다변량 정규성 가정 위배 시 추론 신뢰도 저하.
  - 해결 방안 : Mardia 검정 등 다변량 정규성 검정 수행, 위배 시 비모수적 대안(Permutation Test, Bootstrap) 또는 강건 공분산 추정(Minimum Covariance Determinant) 적용.

## Ⅵ. 정규분포에 대한 기술사적 제언

- 핵심 요약 : 정규성 검정 필수화와 대안 분포·강건 통계 병행으로 분석 신뢰도 제고 필요.
- 정규성 가정의 맹목적 적용 지양과 사전 검정 의무화 : Shapiro-Wilk 검정, Anderson-Darling 검정, Q-Q Plot 시각화로 정규성 검증 후, 위배 시 변환(Box-Cox, Yeo-Johnson) 또는 비모수적 대안(Wilcoxon, Kruskal-Wallis) 선택을 표준 분석 프로세스로 정착 필요.
- 금융·위험 관리 영역에서 팻 테일(Fat Tail) 모델링 필수화 : VaR, Expected Shortfall 산출 시 정규분포 가정 대신 t-분포(자유도 4~6) 또는 역사적 시뮬레이션(Historical Simulation), 극값 이론(EVT, Extreme Value Theory) 기반 접근으로 꼬리 위험 적절 반영 필요.
- 베이지안 분석에서의 사전분포 선택 시 정규분포 편의성 남용 경계 : 공액 사전분포(Conjugate Prior) 편의성으로 정규분포를 무비판적 사전분포로 쓰지 말고, 도메인 지식을 반영한 약정보 사전분포(Weakly Informative Prior, 예: Cauchy, Half-Normal) 사용으로 과도한 사전 정보 주입 방지 필요.

## Ⅶ. 결론

- 핵심 요약 : 정규분포는 통계학의 핵심이자 근사 도구이나 꼬리 행동과 지지역 한계 인식이 분석 신뢰도의 전제.
- 요약 : 평균과 분산 두 모수로 결정되는 대칭적 종형 연속 분포로 중심극한정리에 의해 표본평균 분포의 보편적 근사 모델 역할.
- 시사점 : 정규성 검정·변환·대안 분포 선택의 3단계 프로세스, 금융 위험 관리의 팻 테일 모델링, 베이지안 사전분포 신중 선택이 실무 적용의 완성.
