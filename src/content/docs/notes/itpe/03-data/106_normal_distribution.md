## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **정규분포**

## 30초 인출

- 본질: 정규분포는 평균 μ와 분산 σ²로 결정되는 좌우 대칭의 종 모양 연속 확률분포
- 메커니즘: X ~ N(μ, σ²)에서 μ는 중심을, σ는 퍼짐을 정하고 구간의 밀도 아래 면적이 그 구간의 확률이며, Z = (X − μ)/σ로 표준화하면 표준정규분포 N(0,1)에서 확률을 계산
- 통찰: 정규 모집단의 표본평균은 항상 정규분포이고 비정규 모집단도 표본이 크면 근사하지만 원자료가 정규가 되는 것은 아니므로, 개별값의 분포와 표본평균의 분포를 구분해 표준편차와 표준오차를 알맞게 사용

<details>
<summary>핵심 용어</summary>

- **정규분포(Normal Distribution)** : 평균과 분산으로 정해지는 대칭 종 모양 분포
- **표준정규분포** : 평균 0, 분산 1인 정규분포 N(0,1)
- **표준화(Z-score)** : Z = (X − μ)/σ 로 변환한 값
- **확률밀도함수** : 구간 아래 면적이 확률이 되는 함수
- **경험적 법칙(68-95-99.7)** : μ ± 1σ·2σ·3σ 구간의 포함 확률
- **표준오차** : 표본평균의 표준편차 σ/√n

</details>

## 2~4교시 25점 답안

## Ⅰ. 정규분포의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정규분포** 는 평균과 분산으로 결정되는 연속 확률분포 |
| 목적 | 연속형 확률변수의 분포와 통계적 추론을 모형화 |

## Ⅱ. 특징

| 특징 | 곡선에서 보이는 관계 |
|---|---|
| 대칭성 | 평균 μ 좌우 같은 거리의 밀도가 같음 |
| 척도 | σ가 크면 넓고 낮고, 작으면 좁고 높음 |
| 확률 면적 | 전체 면적 1, 구간 면적이 해당 확률 |

## Ⅲ. 밀도와 표준화

```text
X ~ N(μ, σ²)
 ├ μ: 곡선의 중심 이동 / σ: 퍼짐 조절
 └ 구간 [a, b]의 밀도 아래 면적 = P(a ≤ X ≤ b)
        ↓ Z = (X − μ) / σ
Z ~ N(0, 1) 에서 같은 구간의 확률 계산
```

```text
f(x) = 1 / (σ√(2π)) · exp( −(x − μ)² / (2σ²) )
```

## Ⅳ. 표본평균과 경험적 법칙

| 대상 | 정규분포와의 관계 |
|---|---|
| 정규 모집단의 개별값 | 표준화하면 표준정규분포 |
| 정규 모집단의 표본평균 | 표본 크기와 무관하게 정규분포, 퍼짐은 표준오차 σ/√n |
| 비정규 모집단의 표본평균 | 중심극한정리 조건에서 표본이 크면 정규 근사 |

| 구간 | 포함 확률(근사) |
|---|---|
| μ ± σ | 68.27% |
| μ ± 2σ | 95.45% |
| μ ± 3σ | 99.73% |

경험적 법칙은 개별 관측값의 분포에 대한 것이며, 표본평균의 신뢰구간은 표본 설계와 표준오차로 계산.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 비대칭·다봉·두꺼운 꼬리 자료에 정규 모형을 적용해 극단 확률 오판 | 히스토그램·분위수 확인, 변환·강건 방법 검토 |
| 중심극한정리를 원자료 정규성의 보장으로 오해 | 표본평균과 개별값의 분포를 구분 |
| 표본평균에 원자료의 σ를 그대로 사용 | 목적에 맞는 표준오차 계산 |

## Ⅵ. 제언

정규 가정을 쓰기 전에 분포를 확인하고, 평균에 대한 추론에는 표준오차를 사용

```text
분포 확인(히스토그램·분위수) → 정규 적합 → 개별값은 σ, 평균 추론은 σ/√n
```

| 구분 | 무조건 정규 가정 | 제언: 확인 후 적용 |
|---|---|---|
| 극단 확률 | 오판 위험 | 분포 확인으로 보정 |
| 평균 추론 | σ 오용 | 표준오차 사용 |
