## 지식 로드맵 내 현재 위치

데이터 분석 → 확률분포 → 정규분포와 표준화

## 30초 인출

- 본질: **정규분포**는 평균 \(\mu\)와 표준편차 \(\sigma\)로 모양이 정해지는 연속 확률분포
- 메커니즘: 평균을 중심으로 대칭이며, 표준화 \(Z=(X-\mu)/\sigma\)로 표준정규분포 \(N(0,1)\)에 대응
- 활용: 확률·표본 통계량·통계적 추론을 다루며, 자료 자체와 표본평균의 분포를 구분

<details>
<summary>핵심 용어</summary>

| 용어 | 설명 |
|---|---|
| **정규분포(normal distribution)** | 평균과 분산으로 결정되는 연속 확률분포 |
| **표준정규분포(standard normal distribution)** | 평균 0, 분산 1인 정규분포 \(N(0,1)\) |
| **표준점수(z-score)** | 관측값에서 평균을 뺀 뒤 표준편차로 나눈 값 |
| **중심극한정리(Central Limit Theorem, CLT)** | 조건을 만족하는 독립 표본의 표본평균 분포가 표본 크기 증가에 따라 정규분포에 가까워지는 정리 |
| **경험적 법칙(empirical rule)** | 정규분포에서 평균 ±1·2·3 표준편차 안의 비율을 근사하는 규칙 |

</details>

## 1교시 10점 답안

### Ⅰ. 정규분포의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 평균과 분산으로 결정되는 연속 확률분포 |
| 목적 | 연속형 확률변수의 분포와 확률·통계적 추론을 모형화 |

### Ⅱ. 분포의 특성과 표준화

| 특성 | 설명 |
|---|---|
| 모수 | \(\mu\): 위치, \(\sigma^2\): 퍼짐 |
| 모양 | 평균을 중심으로 대칭, 평균·중앙값·최빈값 일치 |
| 표준화 | \(Z=(X-\mu)/\sigma\), 결과는 표준정규 척도로 해석 |

```mermaid
flowchart TD
    A[정규변수 X ~ N(μ, σ²)] --> B[평균 μ를 빼 중심 이동]
    B --> C[표준편차 σ로 나눠 척도 조정]
    C --> D[표준점수 Z ~ N(0, 1)]
    D --> E[표준정규분포로 확률 해석]
```

**제언:** 정규성·표본 설계와 모수 추정 근거를 확인한 뒤 정규분포 기반 확률·추론을 적용

## 2~4교시 25점 답안

### Ⅰ. 정규분포의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 평균과 분산으로 결정되는 연속 확률분포 |
| 목적 | 연속형 확률변수의 분포와 확률·통계적 추론을 모형화 |

### Ⅱ. 확률밀도와 핵심 성질

정규분포 \(X\sim N(\mu,\sigma^2)\)의 확률밀도함수는 다음과 같다.

\[
f(x)=\frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
\]

| 성질 | 설명 |
|---|---|
| 대칭 | \(x=\mu\)를 중심으로 대칭 |
| 대표값 | 평균·중앙값·최빈값이 \(\mu\)에 일치 |
| 전체 확률 | 밀도함수 아래 전체 면적은 1 |
| 꼬리 | 양 끝으로 갈수록 밀도는 0에 가까워지나 유한한 위치에서 0이 되지는 않음 |

### Ⅲ. 표준화와 표본평균

```mermaid
flowchart TD
    A[관측값 X ~ N(μ, σ²)] --> B[Z = (X - μ) / σ]
    B --> C[표준정규분포 N(0, 1)]
    D[독립 표본 X₁ … Xₙ] --> E[표본평균 X̄]
    E --> F[조건을 만족하면 표본 크기 증가에 따라 분포가 정규에 근접]
```

정규 모집단에서는 표본평균의 분포가 표본 크기와 관계없이 정규분포다. 모집단 분포가 정규가 아니어도 중심극한정리는 조건을 만족하는 표본평균의 분포에 관한 근사 결과이며, 원자료 자체가 정규분포가 된다는 뜻은 아니다.

### Ⅳ. 경험적 법칙과 통계적 해석

| 정규분포 구간 | 포함 확률(근사) | 해석 |
|---|---:|---|
| \(\mu\pm\sigma\) | 68.27% | 한 표준편차 안의 값 |
| \(\mu\pm2\sigma\) | 95.45% | 두 표준편차 안의 값 |
| \(\mu\pm3\sigma\) | 99.73% | 세 표준편차 안의 값 |

이 비율은 정규분포를 따르는 개별 관측값의 구간 확률이다. 이를 표본평균의 신뢰구간이나 공정관리 한계와 동일시하지 않는다. 신뢰구간은 표본 설계와 추정량의 표준오차에 따라 별도로 산출한다.

### Ⅴ. 적용 한계와 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 원자료가 비대칭·다봉·두꺼운 꼬리일 때 정규 모형이 분포와 극단 확률을 제대로 표현하지 못할 수 있음 | 그래프·분위수·잔차와 자료 생성 과정을 검토하고 적절한 분포·변환·강건 방법을 선택 |
| 표본이 크다는 이유만으로 독립성·표본 추출 편향 문제가 해소되지는 않음 | 표본 단위·의존 구조·수집 편향을 점검하고 추론 가정을 명시 |

**제언:** 분포 가정과 표본평균 근사를 구별하고 자료·잔차 진단에 근거해 정규 기반 추론을 선택
