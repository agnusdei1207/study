## 연관 키워드
- 정규 분포, 정규 분포의 성질, 중심 극한 정리, 표준 정규 분포, 표준 편차, 평균

### Ⅰ. 정규 분포(Normal Distribution)의 개요

- 핵심 요약 : 데이터가 평균을 중심으로 대칭적으로 분포하는 연속 확률 분포.
- 개념 : 데이터가 평균을 중심으로 대칭적으로 분포하는 연속 확률 분포(**정규 분포**, Normal Distribution).
- 배경 및 필요성 : 많은 자연 현상과 인위적 데이터가 정규 분포를 따르는 경우가 많아, 통계 분석에서 중요한 기초 모델로 사용됨.
- 주요 목적 : 데이터의 분포 특성을 이해하고, 확률 및 통계적 추론을 수행.

### Ⅱ. 정규 분포의 특징 및 장점

- 핵심 요약 : 대칭성, 단일 최댓값, 평균·중앙값·최빈값이 동일, 경험 법칙(68-95-99.7 법칙)의 특징.

1. **대칭성** : 평균을 중심으로 좌우가 대칭 → 데이터의 분포가 대칭적임.
2. **단일 최댓값** : 평균에서 확률 밀도가 최대가 됨 → 가장 빈번하게 나타나는 값이 평균.
3. **평균·중앙값·최빈값이 동일** : 세 가지 중심 경향도가 모두 같은 값 → 데이터의 중심을 명확하게 표현.
4. **경험 법칙**(68-95-99.7 법칙) : 평균 ± 1표준편차 내에 약 68%, ± 2표준편차 내에 약 95%, ± 3표준편차 내에 약 99.7%의 데이터가 포함 → 데이터의 분포 범위를 예측할 수 있음.

### Ⅲ. 정규 분포의 표준화 (표준 정규 분포)

- 핵심 요약 : 어떤 정규 분포든 평균과 표준 편차를 이용해 표준 정규 분포로 변환할 수 있음.
- **표준 정규 분포**(Standard Normal Distribution) : 평균이 0이고 표준 편차가 1인 정규 분포.

$$Z = \frac{X - \mu}{\sigma}$$

여기서 $X$는 원래 값, $\mu$는 평균, $\sigma$는 표준 편차.

### Ⅳ. 정규 분포의 응용
- 핵심 요약 : 신뢰 구간 설정, 가설 검정, 품질 관리 등 다양한 통계 분석에 활용.
- 신뢰 구간 : 모집단의 모수를 특정 범위 내에 포함시킬 확률을 나타냄.
- 가설 검정 : 표본 통계량이 모집단의 모수와 유의미하게 다른지 여부를 판단.

### Ⅴ. 정규 분포의 한계와 방안
- 핵심 요약 : 모든 데이터가 정규 분포를 따르는 것은 아니며, 비대칭 분포나 꼬리가 두꺼운 분포에는 적합하지 않음.
- 대응 방안 : 데이터의 분포 특성을 먼저 확인하고, 정규성 검정(Shapiro-Wilk 검정 등)을 통해 정규성 여부를 확인한 후 적절한 통계 기법을 선택.

### Ⅵ. 기술사적 제언
- 핵심 요약 : 정규 분포는 통계 분석의 기본이 되지만, 모든 데이터가 정규 분포를 따르는 것은 아니므로 데이터의 특성을 먼저 확인해야 함.
- 실행 제안 : 데이터 분석 시 정규성 검정(Shapiro-Wilk 검정 등)을 수행하고, 정규성 가정이 위반되는 경우 비모수 검정 등을 고려할 필요가 있다.

### Ⅶ. 결론
- 핵심 요약 : 정규 분포는 데이터의 분포 특성을 이해하고 통계적 추론을 수행하는 데 중요한 개념.
- 시사점 : 정규 분포의 성질과 한계를 이해하고 적절히 활용하는 것이 데이터 분석의 핵심.
