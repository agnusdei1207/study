 ┣━ Ⅲ 구조 ───── 확률밀도함수($f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$) / 표준정규분포($Z \sim N(0, 1)$) / 왜도($Skewness=0$)와 첨도($Kurtosis=3$)

 ┣━ Ⅴ 비교 ───── 정규분포 vs 표준정규분포 vs t-분포 (일반 모수 분포 vs $\mu=0,\sigma=1$ vs 모분산 미지 시 두꺼운 꼬리 분포)
 ┗━ Ⅵ 실무 ───── 소득·클릭수 등 극단적 우측 꼬리 데이터에 무리한 정규분포 가정 적용 시 예측 붕괴

## 한 줄 본질
- 수많은 독립적인 미세 오차들이 누적되어 형성되는 연속형 데이터의 표준적 형태 → 평균과 분산이라는 두 개의 수치만으로 전체 데이터의 확률적 위치를 표준화(Z)하여 계산 → 모수적 통계 추론 완벽 지원 / 팻 테일(Fat Tail) 이상치 과소평가 위험

## 핵심 용어
- 표준정규분포(Standard Normal Distribution): 평균 $\mu=0$, 분산 $\sigma^2=1$로 변환한 정규분포로, 모든 관측치를 동일 기준의 Z-score로 비교 가능
- 중심극한정리(CLT): 모집단의 분포가 무엇이든 간에 표본의 크기($n$)가 충분히 크면(보통 $n \ge 30$), 표본평균들의 분포는 정규분포에 근사한다는 정리

## 핵심 통찰
- 정규분포는 자연의 법칙이 아니라 '수많은 독립적인 요인이 합쳐졌을 때 나타나는 수학적 결과'임 → 특정 단일 요인이 지배하는 현상(예: 부의 분배, 웹사이트 트래픽)은 정규분포가 아닌 멱함수(Power Law)나 파레토 분포를 따름
- 머신러닝 및 회귀 모델에서 오차가 정규분포를 따른다는 가정을 만족하지 못하면, $R^2$이나 회귀계수의 p-value 가설검정이 모조리 왜곡됨
- $\pm 3\sigma$ 밖의 데이터(0.27%)를 이상치로 간주하는 6시그마 관리 기법은 오직 데이터가 정규분포를 따를 때만 수학적으로 유효함

## 이웃 토픽과 구분
- 정규분포 vs t-분포: 정규분포 = 모분산($\sigma^2$)을 알고 있거나 표본이 충분히 클 때 사용 / t-분포 = 모분산을 몰라 표본분산($s^2$)을 대신 쓰고 표본 크기가 작을 때 사용하는, 양 끝 꼬리가 더 두꺼운 분포

## 내 의견
- [맹목적 정규분포 가정의 폐해] 데이터 분석 실무자가 데이터의 히스토그램도 그려보지 않고 기계적으로 t-test나 ANOVA를 돌려 잘못된 비즈니스 의사결정을 유도하는 사례 빈발 → 나라면: 분석 파이프라인 첫머리에 Shapiro-Wilk 정규성 검정과 Q-Q Plot 생성을 강제하고, $p < 0.05$로 정규성이 기각될 경우 자동으로 비모수 통계 검정(Wilcoxon/Kruskal-Wallis)으로 분기하는 자동화 규칙 적용

## 찾아볼 것
- 표본 크기가 작을 때 정규성을 검정하는 Shapiro-Wilk 검정과 대표본에 적합한 Kolmogorov-Smirnov 검정의 차이
