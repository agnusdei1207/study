## Ⅰ. 통계적 추론의 출발점, 표본추출(Sampling)의 개요

### 가. 표본추출의 정의
- 연구 대상이 되는 모집단(Population) 전체를 조사하는 전수조사의 시간적·비용적 한계를 극복하기 위해, 모집단을 대표할 수 있는 일부 구성 단위(Sample)를 체계적인 절차에 따라 선정하는 통계적 방법.
- 표본의 대표성(Representativeness)을 확보하여 표본 통계량으로부터 모수를 오차 범위 내에서 정확하게 추정하는 것을 목적으로 함.

### 나. 표본오차와 비표본오차

```text
[ 통계적 총 오차의 구성 ]
총 오차 (Total Error) = 표본오차 (Sampling Error) + 비표본오차 (Non-sampling Error)
  - 표본오차   : 모집단의 일부만을 추출했기 때문에 필연적으로 발생하는 오차 (표본 크기 n 증가 시 감소)
  - 비표본오차 : 표본틀 오차, 무응답 오차, 측정 오류, 입력 오타 등 조사 전 과정에서 발생하는 오류 (n 증가 시 오히려 증가 가능)
```

## Ⅱ. 표본추출 방법론의 양대 분류 및 세부 기법

### 가. 확률 표본추출 vs 비확률 표본추출

```text
[ 표본추출 방법론 계통도 ]
+---------------------------------------+---------------------------------------+
|    확률 표본추출 (Probability)        |   비확률 표본추출 (Non-probability)   |
+---------------------------------------+---------------------------------------+
| - 모집단 모든 단위의 추출확률 균일    | - 연구자의 편의, 주관적 판단 개입     |
| - 표본오차 계산 및 모수 추론 가능     | - 표본오차 계산 불가, 탐색적 연구 활용|
| - 단순무작위, 계통, 층화, 군집 추출   | - 편의, 유의(판단), 할당, 눈덩이 추출 |
+---------------------------------------+---------------------------------------+
```

### 나. 4대 확률 표본추출 기법 상세 비교

| 기법 | 추출 절차 및 메커니즘 | 군집/집단 내부 특성 | 집단 간 특성 | 장점 및 주의사항 |
| :--- | :--- | :--- | :--- | :--- |
| **단순 무작위 추출 (SRS)** | 난수표 또는 컴퓨터 난수 생성을 통해 모든 개체에 동일한 추출 확률 부여 | 동질적 모집단 | 구별 없음 | 가장 직관적, 편향 배제 / 모집단 목록(표본틀) 필수, 분산 큼 |
| **계통 추출 (Systematic)** | 개체들을 일렬로 나열한 후 첫 번째를 무작위 선택하고 매 $k = N/n$ 번째 단위 추출 | 순서가 있는 목록 | 구별 없음 | 추출 절차 극도로 간편 / 데이터에 특정 주기성(Periodicity) 존재 시 심각한 편향 발생 |
| **층화 추출 (Stratified)** | 모집단을 상이한 특성의 소집단(층)으로 나누고 각 층에서 무작위 추출 | **집단 내 동질적 (Homogeneous)** | **집단 간 이질적 (Heterogeneous)** | 모집단 특성 완벽 반영, 추정의 분산 최소화(가장 높은 정밀도) / 사전 정보 필요 |
| **군집/집락 추출 (Cluster)** | 모집단을 소집단(군집)으로 나누고 군집 자체를 무작위 추출하여 전수 조사 | **집단 내 이질적 (Heterogeneous)** | **집단 간 동질적 (Homogeneous)** | 광범위한 지리적 조사 비용 대폭 절감 / 군집 간 이질성 존재 시 표본오차 급증 |

## Ⅲ. 머신러닝 데이터셋 구축에서의 샘플링 기법

### 가. 클래스 불균형(Class Imbalance) 해소를 위한 샘플링
- **언더샘플링(Undersampling)** : 다수 클래스(Majority)를 무작위 삭제 $\rightarrow$ 데이터 손실 위험(Tomek Links, Edited Nearest Neighbours로 보완).
- **오버샘플링(Oversampling)** : 소수 클래스(Minority)를 복제하거나 가상 합성 $\rightarrow$ 과적합 위험.
- **SMOTE(Synthetic Minority Over-sampling Technique)** : 소수 클래스 데이터의 KNN 이웃 간 보간(Interpolation)을 통해 새로운 합성 샘플 생성.

### 나. 교차 검증(Cross-Validation)에서의 층화 K-Fold
- 분류 문제에서 각 폴드(Fold) 내의 타깃 레이블 비율이 전체 데이터셋의 클래스 비율과 정확히 일치하도록 강제하는 **Stratified K-Fold** 적용 필수.

## Ⅳ. 빅데이터 파이프라인 관점의 실무 제언

- **저수지 표본추출(Reservoir Sampling) 알고리즘 도입** : 크기 $N$을 미리 알 수 없는 무한 데이터 스트림(Kafka 로그)에서 정확히 $k$개의 균일 무작위 표본을 단 한 번의 순회($O(N)$)와 $O(k)$ 메모리로 추출하기 위해 저수지 샘플링 알고리즘을 파이프라인에 적극 도입할 것.
- **표본틀 오차(Frame Error)의 선제적 통제** : 실세계 데이터 분석 실패의 대부분은 수학적 알고리즘의 오류가 아니라 표본 추출의 바탕이 된 원천 데이터 명부(표본틀)가 모집단을 온전히 포괄하지 못해 발생하는 선택 편향(Selection Bias) 때문임을 인지하고 데이터 수집 단계의 정합성을 엄격히 감시할 것을 제언함.
