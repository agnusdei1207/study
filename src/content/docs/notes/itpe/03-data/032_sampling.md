## 연관 키워드

- 표본추출(Sampling), 모집단(Population), 표본(Sample), 표본틀(Sampling Frame), 대표성(Representativeness)
- 확률 표본추출(Probability Sampling), 비확률 표본추출(Non-probability Sampling)
- 단순 무작위 추출, 계통 추출, 층화 추출, 군집 추출
- 표본오차(Sampling Error), 비표본오차(Non-sampling Error), 저수지 표본추출(Reservoir Sampling)

## Ⅰ. 표본추출의 개요

- 핵심 요약 : 대표성을 갖춘 표본으로 모집단의 모수를 오차 범위 안에서 추정하는 통계 방법.
- 개념 : 모집단(Population) 가운데 일부 구성 단위인 표본(Sample)을 정해진 절차로 선정해 전체 특성을 추정하는 **표본추출** (Sampling).
- 배경 및 필요성 : 전수조사는 시간과 비용 부담이 크고 대상이 방대하면 수행 자체가 어려움 → 일부 표본으로 전체를 추론할 필요.
- 주요 목적 : 표본의 **대표성** (Representativeness) 확보와 표본 통계량을 통한 모수 추정.

## Ⅱ. 표본추출의 특징 및 장점

- 핵심 요약 : 오차를 표본오차와 비표본오차로 분해해 통제하고, 확률·비확률 두 체계로 설계하는 방식.

1. 총오차의 분해 관리 : **표본오차** (Sampling Error)와 **비표본오차** (Non-sampling Error)의 구분 → 통제 대상의 명확화.
2. 표본오차의 정량화 : 표본 크기가 커질수록 감소하는 성질 → 오차 범위와 추정 정밀도의 함께 제시.
3. 비표본오차의 별도 관리 : 표본틀, 무응답, 측정, 입력 오차는 표본 확대로 해소 불가 → 조사 설계와 품질 관리의 병행 필요.
4. **확률 표본추출** (Probability Sampling)의 추론 보장 : 모든 단위의 추출 확률이 알려진 설계 → 모수 추론의 통계적 근거 확보.
5. **비확률 표본추출** (Non-probability Sampling)의 효율 : 편의·판단 기반의 신속·저비용 수행 → 탐색적 조사에의 적합.

## Ⅲ. 표본추출의 구조 (흐름)

- 핵심 요약 : 표본틀을 만드는 설계 절차와 표본오차·비표본오차의 오차 구조가 결합된 체계.
- **표본틀** (Sampling Frame) : 모집단 구성 단위의 목록으로, 추출의 전제가 되는 요소.

```text
[ 표본추출 절차 ]
모집단 정의
   ↓
표본틀 작성
   ↓
추출 방법 선택
   ↓
표본 추출·조사
   ↓
모수 추정
```

```text
[ 총 오차의 구성 ]
총 오차 (Total Error)
   ↓
표본오차 (Sampling Error)
표본 크기가 커지면 감소
   +
비표본오차 (Non-sampling Error)
표본 크기와 무관하게 잔존
```

## Ⅳ. 확률 표본추출 4대 기법의 비교

- 핵심 요약 : 군집 내부와 군집 간 특성 구조, 절차 비용에 따라 기법 선택 기준이 달라짐.

| 기법 | 추출 메커니즘 | 적합한 모집단 구조 | 유의점 |
| :--- | :--- | :--- | :--- |
| **단순 무작위 추출** | 난수로 모든 단위에 같은 추출 확률 부여 | 동질적 모집단 | 표본틀이 필수이고 추정 분산이 큼 |
| **계통 추출** | 나열 후 첫 단위를 선정하고 k = N/n 간격으로 추출 | 순서가 있는 목록 | 데이터에 주기성이 있으면 심각한 왜곡 |
| **층화 추출** | 특성별 층으로 나눈 뒤 각 층에서 무작위 추출 | 층 내 동질·층 간 이질 | 사전 층 정보가 필요 |
| **군집 추출** | 군집을 무작위로 골라 해당 군집을 전수 조사 | 군집 내 이질·군집 간 동질 | 군집 간 이질성이 크면 표본오차 급증 |

- 선택 기준 :
  1. 동질적 모집단과 완비된 표본틀 : 단순 무작위 추출.
  2. 정렬된 목록과 절차의 단순화 필요 : 계통 추출.
  3. 하위 집단 비율의 반영과 정밀도 확보가 중요 : 층화 추출.
  4. 넓은 지역 조사에서 비용 절감이 우선 : 군집 추출.

## Ⅴ. 표본추출의 한계와 방안

- 핵심 요약 : 표본틀 오차, 희귀 클래스 누락, 비표본오차, 대규모 추출 부담을 설계와 추출 알고리즘으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 표본틀 오차·선택 편향 | 목록 누락·자발적 응답으로 추정이 체계적으로 왜곡 | 표본틀 포괄 점검, **성향점수 매칭** (PSM, Propensity Score Matching) 보정 | 표본틀 포괄률, 응답률 |
| 희귀 클래스 누락 | 불균형 데이터의 무작위 추출에서 소수 클래스가 배제 | 층화 추출, 오버샘플링·언더샘플링의 조합 | 클래스별 표본 비율 |
| 비표본오차의 누적 | 무응답·입력 오차가 편향으로 잔존 | 조사 설계 검증, 수집 품질 점검 | 무응답률, 오류율 |
| 대규모 추출 연산 부담 | 전체 셔플이 병목과 메모리 부하를 유발 | **저수지 표본추출** (Reservoir Sampling)로 단일 순회 추출 | 처리 시간, 메모리 사용량 |

## Ⅵ. 표본추출에 대한 기술사적 제언

- 핵심 요약 : 수집 단계 감사, 분석 단계 층화 표준, 파이프라인 내 추출 알고리즘 내장의 체계.

1. 데이터 수집 조직 : 표본틀이 모집단을 온전히 포괄하는지 수집 단계 정합성 감사로 점검 → 선택 편향의 초기 차단.
2. 분석 조직 : 클래스 비율 측정 후 층화 기반 추출과 층화 K-Fold 교차 검증의 표준 채택 → 소수 클래스의 보존.
3. 데이터 엔지니어링 조직 : 크기를 미리 알 수 없는 스트림에 저수지 표본추출을 파이프라인 기본 요소로 내장 → 고정 크기 표본의 유지.

## Ⅶ. 결론

- 핵심 요약 : 표본추출의 성패는 표본틀 설계와 오차 통제에서 결정됨.
- 추론의 신뢰성은 분석 이전의 수집 설계 단계에서 정해지는 성격 → 샘플링 전략이 분석 품질의 선행 조건.
