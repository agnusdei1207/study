## 연관 키워드

- 표본추출(Sampling), 모집단(Population), 대표성(Representativeness)
- 확률·비확률 표본추출, 단순 무작위·계통·층화·군집 추출
- 표본오차(Sampling Error), 표본틀 오차, 저수지 표본추출(Reservoir Sampling)

## Ⅰ. 표본추출의 개요

- 핵심 요약 : 모집단을 대표하는 표본을 체계적으로 선정하여 모수를 추정하는 통계적 방법.
- 개념 : 표본추출(Sampling)은 연구 대상 모집단(Population) 전체 조사의 시간적·비용적 한계 극복을 위해, 모집단을 대표하는 일부 구성 단위(Sample)를 체계적 절차에 따라 선정하는 통계적 방법.
- 배경 및 필요성 : 전수조사의 시간·비용 부담 및 조사 특성상의 수행 불가능.
- 주요 목적 : 표본의 대표성(Representativeness) 확보, 표본 통계량으로부터 모수의 오차 범위 내 정확한 추정.

## Ⅱ. 표본추출의 특징

- 핵심 요약 : 표본오차·비표본오차의 구분과 확률·비확률 추출의 이원 체계.

1. 총 오차(Total Error)의 구성 : 표본오차(Sampling Error)와 비표본오차(Non-sampling Error)의 합.
2. 표본오차 : 모집단 일부 추출에서 필연 발생, 표본 크기 $n$ 증가 시 감소.
3. 비표본오차 : 표본틀 오차, 무응답 오차, 측정 오류, 입력 오타 등 조사 전 과정의 오류, $n$ 증가 시 오히려 증가 가능.
4. 확률 표본추출 : 모집단 모든 단위의 추출확률 균일, 표본오차 계산 및 모수 추론 가능.
5. 비확률 표본추출 : 연구자의 편의·주관적 판단 개입, 표본오차 계산 불가 및 탐색적 연구 활용.

## Ⅲ. 표본추출의 구조 (흐름)

- 핵심 요약 : 총 오차 구성과 확률·비확률 방법론의 계통 구조.

```text
[ 통계적 총 오차의 구성 ]
총 오차 (Total Error) = 표본오차 (Sampling Error) + 비표본오차 (Non-sampling Error)
  - 표본오차   : 일부 추출에서 필연 발생, 표본 크기 n 증가 시 감소
  - 비표본오차 : 표본틀 오차, 무응답, 측정 오류, 입력 오타 등
```

```text
[ 표본추출 방법론 계통도 ]
표본추출
 ├─ 확률 표본추출 (Probability)
 │   ├─ 단순 무작위 추출
 │   ├─ 계통 추출
 │   ├─ 층화 추출
 │   └─ 군집(집락) 추출
 └─ 비확률 표본추출 (Non-probability)
     ├─ 편의 추출
     ├─ 유의(판단) 추출
     ├─ 할당 추출
     └─ 눈덩이 추출
```

## Ⅳ. 4대 확률 표본추출 기법의 비교

- 핵심 요약 : 군집 내부·군집 간 특성 요건과 절차 효율의 기법별 차이.

| 기법 | 추출 절차 및 메커니즘 | 군집 내부 특성 | 군집 간 특성 | 장점 및 주의사항 |
| :--- | :--- | :--- | :--- | :--- |
| 단순 무작위 추출(SRS, Simple Random Sampling) | 난수표·컴퓨터 난수 생성 기반 모든 개체의 동일 추출 확률 부여 | 동질적 모집단 | 구별 없음 | 가장 직관적, 편향 배제 / 모집단 목록(표본틀) 필수, 분산 큼 |
| 계통 추출(Systematic) | 일렬 나열 후 첫 단위 무작위 선택, 매 $k = N/n$번째 단위 추출 | 순서가 있는 목록 | 구별 없음 | 추출 절차 극도로 간편 / 데이터의 특정 주기성(Periodicity) 존재 시 심각한 편향 |
| 층화 추출(Stratified) | 상이한 특성의 소집단(층) 구분 후 각 층에서 무작위 추출 | 집단 내 동질적(Homogeneous) | 집단 간 이질적(Heterogeneous) | 모집단 특성 완벽 반영, 추정 분산 최소화(가장 높은 정밀도) / 사전 정보 필요 |
| 군집·집락 추출(Cluster) | 소집단(군집) 구분 후 군집 자체를 무작위 추출하여 전수 조사 | 집단 내 이질적(Heterogeneous) | 집단 간 동질적(Homogeneous) | 광범위 지리적 조사 비용 대폭 절감 / 군집 간 이질성 존재 시 표본오차 급증 |

## Ⅴ. 표본추출의 장점과 한계

- 핵심 요약 : 비용 절감·추론 가능의 장점과 표본틀 오차·희귀 클래스·대규모 연산 한계.
- 장점
  1. 전수조사 대비 시간·비용의 대폭 절감.
  2. 확률 표본추출 기반 표본오차의 정량적 계산 및 모수 추론 가능.
- 한계점 1 : 표본추출틀 오차(Sampling Frame Error) 및 선택 편향(Selection Bias)
  - 한계점 : 표본틀의 결측 또는 비확률적 편향(자발적 응답, 접근 용이성) 개입 시 추정 모수의 근본적 왜곡.
  - 해결 방안 : 성향점수 매칭(Propensity Score Matching, PSM) 적용, 층화 표본추출(Stratified Sampling) 기반 핵심 하위 집단별 비율 통제.
- 한계점 2 : 극단적 불균형 데이터셋의 희귀 클래스(Rare Event) 누락
  - 한계점 : 단순 무작위 표본추출 적용 시 극히 낮은 빈도의 이상 징후·희귀 질환 타깃 클래스의 표본 완전 배제.
  - 해결 방안 : SMOTE, Borderline-SMOTE 등 오버샘플링(Oversampling) 합성 알고리즘 또는 언더샘플링(Tomek Links)과의 하이브리드 파이프라인 구축.
- 한계점 3 : 분산 빅데이터 환경의 대규모 무작위 추출 연산 오버헤드
  - 한계점 : 수십 억 건 분산 스토리지의 완전 무작위 추출(Full Random Shuffle) 수행 시 클러스터 네트워크 I/O 병목 및 메모리 오버플로우 유발.
  - 해결 방안 : 저수지 표본추출(Reservoir Sampling) 기반 단일 패스 스트리밍 추출, 파티션 단위 청크 샘플링(Bernoulli Sampling) 활용.

## Ⅵ. 표본추출에 대한 기술사적 제언

- 핵심 요약 : 머신러닝 데이터셋·스트리밍 환경의 샘플링 전략과 표본틀 정합성 감시.
- 클래스 불균형(Class Imbalance) 해소 : 다수 클래스 삭제의 언더샘플링(Undersampling, 데이터 손실 위험, Tomek Links·Edited Nearest Neighbours 보완), 소수 클래스 복제·가상 합성의 오버샘플링(Oversampling, 과적합 위험), KNN(K-Nearest Neighbors) 이웃 간 보간(Interpolation) 합성의 SMOTE(Synthetic Minority Over-sampling Technique) 적용.
- 층화 K-Fold 교차 검증(Cross-Validation) : 분류 문제에서 각 폴드(Fold) 내 타깃 레이블 비율을 전체 데이터셋 클래스 비율과 일치시키는 Stratified K-Fold 적용.
- 저수지 표본추출 알고리즘 도입 : 크기 $N$을 미리 알 수 없는 무한 데이터 스트림(Kafka 로그)에서 정확히 $k$개의 균일 무작위 표본을 단 한 번의 순회($O(N)$)와 $O(k)$ 메모리로 추출.
- 표본틀 오차(Frame Error)의 선제적 통제 : 분석 실패의 대부분이 표본틀이 모집단을 온전히 포괄하지 못하는 선택 편향(Selection Bias)에서 기인, 데이터 수집 단계 정합성의 엄격한 감시.

## Ⅶ. 결론

- 핵심 요약 : 대표성 확보와 오차 통제가 표본추출 설계의 핵심.
- 요약 : 확률 표본추출 기법 선택과 비표본오차 통제, 머신러닝 특화 샘플링의 병행.
- 시사점 : 추론 신뢰성은 수집 단계의 표본틀 설계에서 결정, 샘플링 전략이 분석 품질의 선행 조건.
