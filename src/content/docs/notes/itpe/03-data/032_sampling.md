## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **표본추출**

## 30초 인출

- 본질: 표본추출은 모집단 전체 대신 일부 대상을 정해 분석할 자료를 얻는 과정
- 메커니즘: 목표 모집단과 추출틀을 확인하고 확률·비확률 방법과 크기를 정해 추출·조사한 뒤, 비응답과 가중치를 검토하고 설계에 맞는 추정과 오차를 보고
- 통찰: 표본 크기를 키워도 추출틀 누락과 비응답 편향은 사라지지 않으므로 모집단과 추출틀의 차이를 밝히고 설계를 반영한 추정을 하며, 학습데이터에서는 클래스·시점 분포를 표본 설계에 넣음

<details>
<summary>핵심 용어</summary>

- **모집단·표본** : 관심 대상 전체와 그 일부
- **추출틀(Sampling Frame)** : 표본을 뽑을 수 있는 대상 목록
- **확률표본추출** : 각 대상의 포함확률을 알고 무작위로 뽑는 방법
- **비확률표본추출** : 조사자의 판단·편의로 뽑아 포함확률을 알 수 없는 방법
- **층화추출** : 특성별 층에서 각각 뽑는 방법
- **군집추출(집락추출)** : 지역·기관 같은 집단을 선택해 그 안의 대상을 조사하는 방법
- **표본오차** : 표본추출 반복에 따른 추정값의 변동
- **비응답 편향** : 응답 여부가 결과와 관련되어 생기는 치우침

</details>

## 2~4교시 25점 답안

## Ⅰ. 표본추출의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **표본추출** 은 모집단 전체 대신 일부 대상을 정해 분석할 자료를 얻는 과정 |
| 목적 | 제한된 시간·비용으로 모집단의 특성을 추정하거나 분석 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 부분 관찰 | 표본 결과에서 모집단 특성 추정 |
| 선택 확률 | 확률추출의 포함확률이 오차 추정의 근거 |
| 대표성 제약 | 추출틀 누락·비응답은 표본 크기만 늘려서는 해소되지 않음 |

## Ⅲ. 개념 및 절차

```text
목표 모집단 → 추출틀 누락·중복 확인 → 방법·크기 결정
                                        ↓
추정·오차 보고 ← 비응답·가중치 검토 ← 추출·조사
```

| 구분 | 추출 단위 |
|---|---|
| 층화 | 모집단 → 특성별 층 → 각 층에서 대상 추출 |
| 군집 | 모집단 → 집단 → 일부 집단 선택 → 집단 내 대상 조사 |

## Ⅳ. 확률·비확률 표본추출 비교와 AI 학습데이터 적용

| 구분 | 방법 | 추출 원리 | 한계·적합 상황 |
|---|---|---|---|
| 확률 | 단순무작위 | 추출틀에서 무작위 선택 | 목록을 확보한 경우 |
| 확률 | 층화 | 층별 추출 | 소수 집단까지 대표해야 할 때 |
| 확률 | 군집 | 집단 선택 | 대상이 분산되어 비용이 클 때 |
| 확률 | 계통 | 무작위 시작점부터 일정 간격 | 목록 순서에 주기성이 없을 때 |
| 비확률 | 편의 | 접근하기 쉬운 대상 | 모집단과 차이 가능 |
| 비확률 | 판단 | 조사자 기준 | 선택 기준에 따른 치우침 |
| 비확률 | 할당 | 정한 집단별 수 충족 | 집단 안의 무작위성 없음 |

비확률표본의 결과를 모집단 전체의 확률적 추정처럼 해석하지 않음.

| 오차 | 뜻 | 대응 |
|---|---|---|
| 표본오차 | 추출 반복에 따른 변동 | 설계에 맞는 표준오차·구간 |
| 추출틀 누락 | 일부 대상이 뽑힐 수 없음 | 모집단·목록 대조 |
| 비응답 편향 | 응답 여부가 결과와 관련 | 응답률·집단 차이 확인 |

| AI 학습데이터 관점 | 적용 방안 |
|---|---|
| 클래스 불균형 | 클래스별 층화 추출로 소수 클래스 확보 |
| 시점·출처 편중 | 기간·출처별 층화로 분포 반영 |
| 평가 데이터 | 학습과 분리해 모집단 분포를 반영한 표본 구성 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 조사 가능한 대상만 모집단으로 간주 | 목표 모집단과 추출틀의 차이 명시 |
| 설계 효과 무시 | 층·군집·가중치를 반영한 표준오차 계산 |
| 집단별 비응답으로 결과 치우침 | 응답률 확인, 가중치 조정, 한계 보고 |

## Ⅵ. 제언

모집단 특성과 조사 조건에 맞춰 추출 방법을 정하고, 표본 크기보다 추출틀과 대표성을 먼저 점검

```text
집단 간 이질적·집단 내 동질적 → 층화 / 분산·비용 제약 → 군집 / 동질적 → 단순무작위
```

| 구분 | 편의 표본 | 제언: 확률·층화 설계 |
|---|---|---|
| 대표성 | 치우침 가능 | 포함확률 기반 |
| 추정 | 오차 산정 곤란 | 표준오차 산정 |
