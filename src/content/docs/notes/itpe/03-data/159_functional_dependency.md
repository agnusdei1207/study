## Ⅰ. 관계형 정규화의 수학적 토대, 함수적 종속성(FD)의 개요

### 가. 함수적 종속성의 정의
- 관계형 데이터베이스의 릴레이션 $R$에서 속성들의 부분집합 $X$와 $Y$에 대하여, $X$의 값 각각에 대해 시간에 관계없이 항상 $Y$의 값이 오직 하나만 대응될 때, $Y$는 $X$에 함수적으로 종속된다 고 하며, 이를 $X \rightarrow Y$로 표기함.
- 여기서 $X$를 **결정자(Determinant)** , $Y$를 **종속자(Dependent)** 라고 부름.

### 나. 함수적 종속성의 수학적 엄격한 정의
$$\forall t_1, t_2 \in R, \quad t_1[X] = t_2[X] \implies t_1[Y] = t_2[Y]$$
(어떤 두 튜플의 $X$ 속성값이 같다면, 그 두 튜플의 $Y$ 속성값도 반드시 같아야 함).

## Ⅱ. 함수적 종속성의 3대 핵심 유형 분석

```text
[ 함수적 종속성 핵심 3유형 ]
1. 완전 함수 종속 (FFD) : Y가 복합 기본키 전체에 종속됨 (진부분집합에는 종속 안 됨) -> 2NF 목표
2. 부분 함수 종속 (PFD) : Y가 복합 기본키의 일부 속성에만 종속됨 -> 2NF 위반 원인
3. 이행적 함수 종속 (TFD) : X -> Y 이고 Y -> Z 성립 시 X -> Z 종속 발생 -> 3NF 위반 원인
```

### 가. 유형별 상세 비교 및 정규화 연계

| 종속성 유형 | 구체적 정의 및 표기 | 구체적 사례 | 해소를 위한 정규화 단계 |
| :--- | :--- | :--- | :--- |
| **완전 함수 종속 (FFD, Full FD)** | $X$가 복합 속성 집합일 때, $Y$가 $X$의 전체에 종속되며 $X$의 어떠한 진부분집합에도 종속되지 않음 | `(학번, 과목번호) -> 성적` (성적은 둘 다 알아야만 결정됨) | 제2정규형 (2NF) 달성 조건 |
| **부분 함수 종속 (PFD, Partial FD)** | $Y$가 복합 속성 $X$ 전체가 아니라, $X$를 구성하는 일부 속성에 종속됨 | `(학번, 과목번호) -> 학부` (학부는 학번만으로도 결정됨) | 제2정규형 (2NF) 위반 (테이블 분리 필요) |
| **이행적 함수 종속 (TFD, Transitive FD)** | $X \rightarrow Y$이고 $Y \rightarrow Z$가 성립하여 간접적으로 $X \rightarrow Z$가 성립함 | `사번 -> 부서코드`, `부서코드 -> 부서위치` $\implies$ `사번 -> 부서위치` | 제3정규형 (3NF) 위반 (이행 속성 분리 필요) |

## Ⅲ. 암스트롱의 공리 (Armstrong's Axioms)

### 가. 함수적 종속성을 추론하기 위한 6대 공리 체계

| 공리 명칭 | 규칙 수식 | 설명 |
| :--- | :--- | :--- |
| **1. 반사 규칙 (Reflexivity)** | $Y \subseteq X \implies X \rightarrow Y$ | 자신이 포함하고 있는 하위 속성은 당연히 자신이 결정함 |
| **2. 첨가 규칙 (Augmentation)** | $X \rightarrow Y \implies XZ \rightarrow YZ$ | 양변에 동일한 속성 집합 $Z$를 추가해도 종속성 유지됨 |
| **3. 이행 규칙 (Transitivity)** | $X \rightarrow Y \land Y \rightarrow Z \implies X \rightarrow Z$ | 종속 관계는 삼단논법처럼 연결되어 전파됨 |
| **4. 분해 규칙 (Decomposition)** | $X \rightarrow YZ \implies X \rightarrow Y \land X \rightarrow Z$ | 종속자의 속성들을 개별적으로 쪼갤 수 있음 |
| **5. 결합 규칙 (Union)** | $X \rightarrow Y \land X \rightarrow Z \implies X \rightarrow YZ$ | 동일 결정자를 갖는 종속자들을 하나로 묶을 수 있음 |
| **6. 유사이행 (Pseudotransitivity)**| $X \rightarrow Y \land WY \rightarrow Z \implies WX \rightarrow Z$ | 부분적 이행 관계를 결합 치환할 수 있음 |

## Ⅳ. 함수적 종속성(FD) 분석의 주요 한계점 및 해결 방안

- 대규모 엔터프라이즈 환경에서 모든 함수적 종속성 도출의 극심한 복잡도 :
  - 한계점 : 속성 수가 수십~수백 개에 달하는 실무 릴레이션에서 모든 FD와 폐포(Closure)를 수작업으로 식별하는 것은 조합 폭발($2^N$)로 인해 불가능.
  - 해결 방안 : 데이터 프로파일링 기반 자동 종속성 발견 알고리즘(TANE, FASTFD) 활용, 핵심 비즈니스 도메인 규칙 중심으로 FD 식별 범위 압축.
- 데이터 인스턴스에 의존한 FD 유추 시의 **거짓 종속성(False Dependency)** 오류 :
  - 한계점 : 샘플 데이터에서 우연히 $X$의 값이 고유하여 $X \to Y$가 성립하는 것처럼 보이지만 실제로는 비즈니스 규칙상 종속성이 없는 경우 모델 왜곡 발생.
  - 해결 방안 : 데이터 주도(Data-driven) 유추와 비즈니스 주도(Business-driven) 검증의 교차 검증 원칙 수립, 도메인 제약조건 명세서와 일치 확인.
- 복잡한 종속성 다이어그램의 관리 사각지대화 :
  - 한계점 : 시스템 유지보수 중 새로운 기능이 추가될 때 기존 FD 체계가 문서화되지 않아 개발자가 임의로 속성을 추가하면서 부분/이행 함수 종속성 재발.
  - 해결 방안 : 데이터 모델링 도구의 메타데이터 사전과 연계한 종속성 검증 자동화, CI 파이프라인 내 스키마 린트(DDL Validator) 적용.

## Ⅴ. 데이터 아키텍트 관점의 실무 제언

- **폐포(Closure)** 연산을 통한 후보키 자동 도출 : 논리 데이터 모델링 시 엔티티의 모든 후보키를 빠짐없이 도출하기 위해, 도메인 비즈니스 규칙에서 식별된 FD 집합에 암스트롱의 공리를 적용한 속성 폐포($X^+$)를 계산하여 전체 속성을 모두 결정짓는 최소 집합을 주식별자로 엄격히 선정해야 함.
- 물리 모델링 시 불필요한 FD 왜곡 경계 : 성능 튜닝을 위한 반정규화 과정에서 컬럼을 중복 복사할 때 새로운 의도치 않은 함수적 종속성이 발생하여 갱신 이상이 초래되므로, 반정규화된 모든 컬럼에 대해 변경 시 동기화 트리거 또는 트랜잭션 무결성 검증을 명시적으로 수립할 것을 제언함.
