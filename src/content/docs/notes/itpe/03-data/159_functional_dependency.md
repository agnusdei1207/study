## 지식 로드맵 내 현재 위치

자료처리·데이터 → 관계형 데이터 모델링 → **함수적 종속성**

## 30초 인출

- 본질: 함수적 종속성은 릴레이션의 유효한 모든 상태에서 속성 집합 X의 값이 Y의 값을 결정하는 제약 X → Y
- 메커니즘: 업무 규칙에서 종속 집합 F를 도출해 속성 폐포 X⁺를 계산하고, X⁺가 전체 속성을 포함하면 슈퍼키, 최소이면 후보키로 판정한 뒤 2NF·3NF·BCNF 위반 종속을 분해 후보로 삼아 무손실·종속 보존을 검증
- 통찰: 현재 표본의 우연한 일치는 FD가 아니므로 업무 규칙과 반례 가능한 상태로 확정하고, 결정자 누락은 정규화 뒤에도 중복·갱신 이상을 남김

<details>
<summary>핵심 용어</summary>

- **함수적 종속성(FD)** : X 값이 같으면 Y 값도 같다는 제약 X → Y
- **결정자·종속자** : X / Y
- **완전·부분·이행적 종속** : 키 전체에 종속 / 키 일부에 종속 / 다른 속성을 거쳐 종속
- **암스트롱의 공리** : 반사·첨가·이행 규칙(건전하고 완전한 추론 규칙)
- **속성 폐포(X⁺)** : F로부터 X가 결정하는 모든 속성 집합
- **슈퍼키·후보키** : 폐포가 전체 속성인 집합 / 그중 최소인 집합

</details>

## 2~4교시 25점 답안

## Ⅰ. 함수적 종속성의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **함수적 종속성** 은 유효한 모든 상태에서 X의 값이 Y의 값을 결정하는 제약 X → Y |
| 목적 | 속성 간 업무 규칙을 표현해 후보키 판정과 정규화의 근거 제공 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 업무 규칙 기반 | 우연한 값의 일치가 아니라 유효한 모든 상태의 결정 관계 |
| 결정자·종속자 | X가 같으면 Y도 같음 |
| 키·정규화 근거 | 폐포로 키 판정, 이상을 일으키는 종속 분리 |

## Ⅲ. 폐포 계산과 키 판정

```text
X⁺ ← X
F에서 A → B의 A가 X⁺에 포함되면 B를 X⁺에 추가
더 추가할 속성이 없을 때까지 반복
   ↓ X⁺가 전체 속성 포함 → 슈퍼키 → 최소성 검사 → 후보키
   ↓ 2NF·3NF·BCNF 위반 검사 → 분해 후보 → 무손실 조인·FD 보존 별도 검증
```

## Ⅳ. 종속 유형과 암스트롱 공리

| 유형 | 예 | 정규화 관계 |
|---|---|---|
| 완전 함수 종속 | (학번, 과목코드) → 성적 | 복합 키 전체에 종속, 2NF 조건에 부합 |
| 부분 함수 종속 | 학번 → 학생 이름 | 비주요 속성의 부분 종속은 2NF 위반 요인 |
| 이행적 함수 종속 | 학번 → 학과코드, 학과코드 → 학과명 | 3NF에서 제거 대상 |

| 공리 | 의미 |
|---|---|
| 반사 | Y ⊆ X이면 X → Y |
| 첨가 | X → Y이면 XZ → YZ |
| 이행 | X → Y, Y → Z이면 X → Z |

세 규칙은 건전하고 완전하며 분해·결합·의사이행 규칙은 이들로부터 유도됨.

| 정규형 | 기준 |
|---|---|
| 2NF | 후보키 일부에 종속하는 비주요 속성이 없음 |
| 3NF | 비자명 종속의 결정자가 슈퍼키이거나 종속 속성이 주요 속성 |
| BCNF | 비자명 종속의 결정자가 슈퍼키 |

| 종속 예 | 함께 저장할 때 위험 | 검토 |
|---|---|---|
| (학번, 과목코드) → 성적, 학번 → 학생 이름 | 학생 이름 반복 저장의 갱신 이상 | 학생 속성 분리 |
| 학번 → 학과코드, 학과코드 → 학과명 | 학과명 반복·변경 시 불일치 | 학과 속성 분리와 참조 관계 |
| BCNF 분해 중 결정자 종속 분리 | 원래 제약을 조인 없이 확인하기 어려움 | 무손실 결합과 종속 보존 각각 검증 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 업무 규칙의 결정자를 누락해 정규화 뒤에도 중복·이상 잔존 | FD와 후보키를 검증해 분해하고 무손실·제약 보존 확인 |
| 현재 표본의 우연한 일치를 FD로 오인 | 현업 규칙과 반례 가능한 업무 상태로 FD 확정 |

## Ⅵ. 제언

업무 규칙에서 FD를 도출·확정하고 폐포로 키를 판정한 뒤 정규화하며 분해 결과를 검증

```text
업무 규칙 → FD 확정 → 폐포로 후보키 → 정규형 위반 검사 → 분해 → 무손실·보존 검증
```

| 구분 | 표본 데이터로 FD 추정 | 제언: 업무 규칙 기반 |
|---|---|---|
| 정확성 | 우연 일치 위험 | 유효한 모든 상태 |
| 정규화 | 이상 잔존 | 결정자 기준 분해 |
