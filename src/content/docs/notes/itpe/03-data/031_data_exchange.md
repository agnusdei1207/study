## Ⅰ. 데이터 경제의 유통 인프라, 데이터 거래소(Data Exchange) 개요

### 가. 데이터 거래소의 정의
- **데이터 거래소** : 공급자(데이터 판매자)와 수요자(데이터 구매자) 간에 데이터 상품(원천 데이터, 가공 데이터, API(Application Programming Interface), 분석 모델)의 등록, 탐색, 가치평가, 계약 체결, 결제 및 안전한 전송이 이루어지도록 중개하는 공인 플랫폼임.
- 데이터의 자산화를 촉진하고 사일로화된 이종 산업 간 데이터를 융합하여 새로운 비즈니스 부가가치를 창출하는 핵심 유통 허브.

### 나. 데이터 거래소의 법적·정책적 기반
- **데이터 산업진흥 및 이용촉진에 관한 기본법(데이터기본법)** : 데이터 안심구역 지정, 데이터 가치평가 및 품질인증 지원.
- 금융데이터거래소(FinDX), 한국데이터산업진흥원(K-DATA) 데이터스토어 등 공공/민간 거래 플랫폼 활성화.

## Ⅱ. 데이터 거래소의 시스템 아키텍처 및 핵심 기능

### 가. 데이터 거래소 참조 아키텍처

```text
[ 데이터 거래소 종합 플랫폼 구성도 ]
+-------------------------------------------------------------------------+
|                  데이터 마켓플레이스 포털 (카탈로그, 검색, 샘플 미리보기)   |
+-----------------------------------+-------------------------------------+
|        거래 중개 및 거버넌스      |          보안 및 결합 전송          |
| - 스마트 계약 및 라이선스 관리    | - 데이터 안심구역 (Clean Room)      |
| - 가격 책정 및 결제 정산          | - 가명·익명화 필터링 게이트웨이      |
| - 데이터 품질(DQC) 검증 엔진      | - 암호화 전송 및 DRM 워터마킹      |
+-----------------------------------+-------------------------------------+
| [공급자]: 금융, 통신, 유통, 모빌리티  | [수요자]: 핀테크, AI 스타트업, 연구소|
+-----------------------------------+-------------------------------------+
```

### 나. 데이터 거래 상품의 3대 유통 유형

| 상품 유형 | 제공 방식 및 기술 메커니즘 | 장점 | 고려사항 |
| :--- | :--- | :--- | :--- |
| **파일 다운로드형** | 가공 및 비식별 조치된 정적 파일(CSV, Parquet) 일괄 다운로드 | 인프라 구성 단순, 일회성 데이터셋에 적합 | 재배포 및 데이터 유출 통제 어려움, 최신성 결여 |
| **API 연동형** | RESTful API / GraphQL 엔드포인트를 통한 실시간 쿼리 데이터 호출 | 최신 데이터 실시간 수급, 호출 건수별 과금 용이 | 공급자 인프라 가용성(SLA, Service Level Agreement) 및 트래픽 부하 통제 필수 |
| **분석 환경 제공형 (Data Clean Room)** | 데이터를 직접 반출하지 않고 거래소 내 보안 클라우드 컨테이너에서 연산 결과만 반출 | 원천 데이터 유출 원천 차단, 개인정보 컴플라이언스 완벽 준수 | 사용자 도구 제약, 인프라 운영 비용 발생 |

## Ⅲ. 데이터 거래 활성화의 한계점·문제점 및 해결 방안

### 가. 프라이버시 침해 및 재식별 위험
- 해법 : **차분 프라이버시** (Differential Privacy), **동형암호** (Homomorphic Encryption) 기반의 연산 지원, 비정형 데이터 가명처리 자동화.

### 나. 데이터 품질 및 가격 책정의 모호성
- 해법 : **DQC-V/M** 공인 품질인증서 의무 첨부, 데이터 프로파일링 요약 리포트 공개, 동적 경매 알고리즘 도입.

### 다. 사후 불법 유통 및 저작권 침해
- 해법 : 보이지 않는 **디지털 워터마킹** (Digital Watermarking), 블록체인 기반 데이터 NFT(Non-Fungible Token) 소유권 증명 및 사용 이력 감사 로깅.

## Ⅳ. 데이터 유통 생태계 확장을 위한 실무 제언

- 데이터 결합 전문기관과의 파이프라인 연계 : 단일 기업의 데이터 단독 판매는 수요가 제한적이므로, 금융-통신-유통 이종 결합을 거래소 내부에서 원스톱으로 처리할 수 있는 결합-가명화-반출 연계 파이프라인 구축이 필수적임.
- 표준 계약서 및 라이선스 모델 정립 : 단순 영구 구매 외에 조회 건당 과금(Pay-per-query), 기간제 구독(Subscription), 파생 모델 창출 허용 범위 등을 명확히 규정한 표준 스마트 계약 템플릿을 보급할 것을 제언함.
