## 연관 키워드

- 데이터 거래소(Data Exchange), 데이터 마켓플레이스, 데이터 안심구역(Clean Room)
- 데이터 산업진흥 및 이용촉진에 관한 기본법(데이터산업법), 데이터 품질 인증(DQC, Data Quality Certification)
- 디지털 워터마킹(Digital Watermarking), 차분 프라이버시(Differential Privacy), 동형암호(Homomorphic Encryption)

## Ⅰ. 데이터 거래소의 개요

- 핵심 요약 : 데이터 상품의 등록, 계약, 결제, 전송을 중개하는 공신력 있는 유통 플랫폼.
- 개념 : 공급자와 수요자 사이에서 원천 데이터, 가공 데이터, API, 분석 모델 같은 데이터 상품의 등록, 탐색, 가치 평가, 계약, 결제, 안전한 전송을 중개하는 **데이터 거래소**(Data Exchange).
- 배경 및 필요성 : 기업과 기관에 쌓인 데이터가 부서와 산업별로 나뉘어 있어 활용되지 못하는 사일로 문제가 크다. 이 자산을 거래 가능한 형태로 유통하는 구조가 없으면 이종 데이터 결합에서 생기는 새로운 부가가치가 발생하지 않는다.
- 주요 목적 : 데이터를 자산으로 유통하는 허브를 만들어 데이터 경제의 거래 비용을 줄이고 신뢰를 확보하는 것.
- 법적·정책적 기반 : **데이터 산업진흥 및 이용촉진에 관한 기본법**(데이터산업법)은 데이터 안심구역의 지정과 데이터 가치 평가, 품질 인증의 근거를 둔다. 2023년 1월 과학기술정보통신부가 한국도로공사와 한국전력공사 등 기관을 데이터 안심구역으로 지정했다는 것은 파이낸셜뉴스 보도 기준이다. 금융 분야에서는 금융데이터거래소(FinDX)가 운영 중이다.

## Ⅱ. 데이터 거래소의 특징

- 핵심 요약 : 카탈로그, 거래 중개, 보안 전송이라는 세 가지 플랫폼 기능과 참여 주체의 구조.

1. 마켓플레이스 포털 : 카탈로그와 검색, 샘플 미리보기 제공 → 구매자가 상품을 비교하고 검토하는 비용 감소.
2. 거래 중개와 거버넌스 : 계약과 라이선스 관리, 가격 산정과 결제 정산, 품질 검증 → 거래 조건의 투명성 확보.
3. 보안과 결합 전송 : 데이터 안심구역, 가명·익명화 필터링, 암호화 전송, 워터마킹 → 원천 데이터 유출 위험 감소.
4. 참여 주체 : 공급자(금융, 통신, 유통, 모빌리티)와 수요자(핀테크, AI 스타트업, 연구기관) → 다른 산업 간 결합 수요 충족.

## Ⅲ. 데이터 거래소의 구조 (흐름)

- 핵심 요약 : 포털, 거래 중개, 보안 전송의 플랫폼 구성과 등록부터 감사까지의 거래 흐름.

```text
[ 데이터 거래소 플랫폼 구성 ]
마켓플레이스 포털 (카탈로그·검색·샘플)
        ↓
거래 중개·거버넌스     보안·결합 전송
(계약·라이선스·정산)   (안심구역·가명화·암호화)
```

```text
[ 데이터 거래 흐름 ]
공급자 : 상품 등록, 품질 인증
        ↓
수요자 : 카탈로그 탐색, 샘플 검토
        ↓
스마트 계약 체결, 결제 정산
        ↓
안심구역 분석 또는 안전 전송 → 이용 이력 감사
```

## Ⅳ. 데이터 거래 상품 유통 유형의 비교

- 핵심 요약 : 파일 다운로드, API 연동, 분석 환경 제공이라는 세 방식이 원본 통제 수준에서 차이를 보인다.

| 상품 유형 | 제공 방식 | 장점 | 고려사항 |
| --- | --- | --- | --- |
| 파일 다운로드형 | 비식별 조치를 거친 정적 파일(CSV, Parquet) 일괄 제공 | 인프라가 단순하고 일회성 분석에 적합 | 재배포와 유출 통제가 어렵고 최신성이 낮음 |
| API 연동형 | RESTful API나 GraphQL로 실시간 조회 | 최신 데이터를 실시간으로 받고 호출 단위 과금 가능 | 공급자 가용성과 서비스 수준 협약(SLA, Service Level Agreement)을 맞춰야 함 |
| 분석 환경 제공형 | 원천 데이터를 내보내지 않고 안심구역 안에서 분석, 결과만 반출 | 원천 유출을 막고 개인정보 규정 준수가 쉬움 | 사용 도구가 제한되고 인프라 운영 비용 발생 |

## Ⅴ. 데이터 거래소의 장점과 한계

- 핵심 요약 : 데이터의 자산화와 산업 간 결합이 장점이며, 재식별 위험, 품질과 가격의 불투명, 사후 불법 유통이 한계.

- 장점
  1. 데이터를 자산으로 평가하고 거래하는 기반 마련.
  2. 이종 산업 간 결합을 통한 새로운 사업 기회 창출.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 프라이버시 침해와 재식별 | 여러 데이터를 결합하면 개인이 다시 식별될 위험이 커짐 | 차분 프라이버시와 동형암호 기반 연산, 비정형 데이터 가명처리 자동화 | 재식별 위험 점검 결과 |
| 품질과 가격의 불투명 | 상품 품질을 객관적으로 알기 어렵고 적정 가격 산정이 어려움 | 공인 데이터 품질 인증(DQC, Data Quality Certification) 첨부, 프로파일링 요약 리포트 공개, 가격 산정 기준 명시 | 인증 보유 상품 비율 |
| 사후 불법 유통과 저작권 침해 | 구매한 데이터가 허가 없이 재배포됨 | 보이지 않는 디지털 워터마킹, 사용 이력 감사 로그 | 유출 추적 건수 |

## Ⅵ. 데이터 거래소에 대한 기술사적 제언

- 핵심 요약 : 개별 기업 데이터의 한계를 넘도록 결합 전문기관과 연계한 파이프라인을 만들고, 계약 모델을 표준화.

단일 기업이 가진 데이터만으로는 가치가 제한되므로, 금융과 통신, 유통 데이터를 결합하는 과정을 거래소 안에서 처리할 수 있도록 결합, 가명화, 반출을 하나의 파이프라인으로 묶는 것이 바람직하다. 결합 전문기관과 협력하면 원천 데이터를 직접 넘기지 않고도 결합 분석이 가능하다.

계약 방식도 영구 구매 한 가지로는 수요가 다양한 거래를 담기 어렵다. 조회 건당 과금, 기간제 구독, 파생 모델 생성의 허용 범위를 명시하는 표준 계약 양식을 보급하면 협상 비용이 줄고 거래가 활성화된다.

## Ⅶ. 결론

- 핵심 요약 : 데이터 거래소는 프라이버시 보장과 품질 신뢰를 전제로 하는 데이터 경제의 유통 인프라.
- 시사점 : 품질 인증, 워터마킹, 표준 계약의 제도적 기반이 데이터 거래 활성화의 선행 조건이 됨.
