## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 유통 → **데이터 거래소**

## 30초 인출

- 본질: 데이터 거래소는 제공자와 이용자가 데이터 상품을 찾고 이용 조건을 합의해 거래하도록 연결하는 유통 플랫폼
- 메커니즘: 제공자가 권리·품질을 확인해 상품과 샘플을 등록하면 거래소가 검색·계약·접근·정산을 연결하고, 이용자는 샘플을 검토해 이용 범위와 가격을 합의한 뒤 파일·API로 제공받음
- 통찰: 거래소가 모든 데이터의 권리와 품질을 자동 보증하지 않으므로 권리 범위와 품질 정보를 계약과 메타데이터로 명시하고 거래 후 변경·이슈 처리 경로까지 운영

<details>
<summary>핵심 용어</summary>

- **데이터 거래소** : 데이터 상품의 검색·계약·제공·정산을 중개하는 플랫폼
- **데이터 상품** : 데이터 본체에 메타데이터·품질·이용 조건을 함께 구성한 거래 대상
- **메타데이터** : 데이터의 내용·범위·형식·갱신 주기 등을 설명하는 정보
- **샘플 데이터** : 구매 전 내용과 품질을 판단하도록 제공하는 일부 데이터
- **이용 범위** : 이용자가 데이터를 사용·가공·재제공할 수 있는 권리의 한계
- **API 제공** : 데이터 파일 전달 대신 인터페이스로 접근을 허용하는 제공 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 거래소의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 거래소** 는 제공자와 이용자가 데이터 상품을 찾고 이용 조건을 합의해 거래하도록 연결하는 유통 플랫폼 |
| 목적 | 필요한 데이터의 발견·이용 촉진과 거래 조건의 명확화 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 다면 연결 | 제공자·이용자·운영자가 발견부터 사후 처리까지 참여 |
| 조건 기반 거래 | 데이터와 이용 권리·품질·갱신 조건을 함께 확인 |
| 지속적 제공 | 파일 전달 외에 API 접근·버전 변경·사용량 관리 가능 |

## Ⅲ. 거래 절차

```text
제공자: 권리·품질·갱신 조건 확인 → 상품·샘플 등록
            ↓ 거래소: 검색·계약·접근·정산 연결
이용자: 샘플 검토 → 이용 범위·가격 합의
            ↓
파일·API 접근 허용 → 이용 기록·정산 → 품질 이슈·변경 통지·계약 종료
```

| 단계 | 확인할 기준 |
|---|---|
| 발견 | 내용·범위·기간·갱신 주기 |
| 합의 | 이용·가공·재제공 가능 범위 |
| 제공 | 접근 통제·전달 방법·변경 통지 |
| 사후 | 품질 이슈·정산·계약 종료 처리 |

## Ⅳ. 데이터 상품 구성과 지원 기능

| 구성 | 필요한 이유 |
|---|---|
| 데이터 본체·형식 | 분석·연계 가능성 판단 |
| 메타데이터·샘플 | 내용·범위·결측·갱신 상태 파악 |
| 품질·출처 | 신뢰성·재현성 확인 |
| 권리·계약 | 허용된 이용과 책임 범위 확인 |
| 제공 방식 | 파일·API 등 이용 환경 적합성 |

| 지원 기능 | 통제 |
|---|---|
| 카탈로그·검색 | 상품·버전·갱신 이력 관리 |
| 계약·권한 | 이용자별 허용 범위·기간 적용 |
| 전달·API | 사용량·오류·접근 기록 |
| 정산·문의 | 대가·분쟁·품질 요청 이력 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 상품 설명만으로 활용성 판단 어려움 | 샘플·품질·갱신 이력 제공 |
| 권리 범위 모호 | 제공·가공·재제공 조건을 계약에 명시 |
| 거래 후 변경·품질 이슈 누락 | 버전·변경 통지·이슈 처리 경로 운영 |

## Ⅵ. 제언

계약에 이용 목적·권리 귀속·재식별 금지를 명시하고, 원본 유출 위험이 큰 데이터는 원본 반출 없이 분석하는 방식을 검토

```text
등록(품질·권리 확인) → 계약(이용 범위) → 제공(파일·API 또는 반출 없는 분석) → 사후 관리
```

| 구분 | 단순 파일 전달 | 제언: 조건 명시·통제된 제공 |
|---|---|---|
| 권리·유출 | 복제·재제공 위험 | 범위 명시·접근 통제 |
| 품질 | 구매 후 확인 | 샘플·이력으로 사전 확인 |
