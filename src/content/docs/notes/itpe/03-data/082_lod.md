## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 개방·연결 → **링크드 오픈 데이터(LOD)**

## 30초 인출

- 본질: 링크드 오픈 데이터는 공개 데이터를 웹 식별자(URI)와 관계 링크로 연결해 발견·재사용할 수 있게 한 데이터
- 메커니즘: 대상마다 HTTP URI를 붙이고, 조회하면 RDF(주어·서술어·목적어 트리플)로 설명을 제공하며, 다른 URI로 링크를 걸어 SPARQL 등으로 연결된 데이터를 탐색
- 통찰: 공개와 연결만으로 품질·적법성·재사용성이 보장되지 않으므로 어휘를 재사용해 의미 연결을 확보하고 링크의 유효성, 라이선스·개인정보, 최신성을 별도로 점검

<details>
<summary>핵심 용어</summary>

- **LOD(Linked Open Data)** : 개방된 데이터를 URI와 링크로 연결한 웹 데이터
- **URI** : 대상을 식별하는 웹 식별자
- **RDF** : 주어·서술어·목적어 트리플로 관계를 표현하는 모델
- **SPARQL** : RDF 그래프를 질의하는 언어
- **5-Star Open Data** : 공개 수준을 다섯 단계로 나타낸 모델
- **온톨로지·어휘** : 데이터의 의미를 정의한 개념 체계

</details>

## 2~4교시 25점 답안

## Ⅰ. 링크드 오픈 데이터의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **링크드 오픈 데이터** 는 공개 데이터를 웹 식별자와 관계 링크로 연결해 발견·재사용하게 한 데이터 |
| 목적 | 공개 데이터의 식별·탐색·결합 지원 |

## Ⅱ. 특징

| 특징 | 데이터의 모습 | 활용 의미 |
|---|---|---|
| 개방성 | 이용 조건을 밝힌 공개 데이터 | 재사용 범위 확인 |
| 식별성 | 항목마다 조회 가능한 URI | 같은 대상을 안정적으로 참조 |
| 연결성 | 다른 데이터의 URI를 관계로 연결 | 기관·분야를 넘는 탐색 |

## Ⅲ. 구성 원칙과 RDF

```text
기관A의 HTTP URI → 조회 → RDF 설명: (기관A, 관할지역, 지역B)
                                              ↓ 목적어 URI 조회
                                    지역B의 RDF 설명·추가 링크
```

| 순서 | 원칙 | 의미 |
|---|---|---|
| 1 | URI로 대상에 이름 부여 | 참조 지점 제공 |
| 2 | HTTP URI 사용 | 웹에서 조회 가능 |
| 3 | 조회 시 유용한 정보 제공 | RDF 등 표준 표현으로 설명 |
| 4 | 다른 URI로 연결 | 탐색 범위 확장 |

| 트리플 요소 | 예 | 역할 |
|---|---|---|
| 주어 | 기관A의 URI | 설명할 대상 |
| 서술어 | 관할지역의 URI | 대상 사이의 관계 |
| 목적어 | 지역B의 URI | 관계의 대상 또는 값 |

RDF 그래프는 SPARQL로 질의할 수 있으며, 질의 서비스 제공 여부는 제공자의 설계 선택.

## Ⅳ. 5-Star Open Data

| 등급 | 개방 수준 |
|---|---|
| ★ | 웹에 공개 라이선스로 공개 |
| ★★ | 구조화된 기계 판독 데이터 |
| ★★★ | 비독점 개방 형식 |
| ★★★★ | 항목을 URI로 식별 |
| ★★★★★ | 외부 데이터와 링크해 맥락 제공 |

별 등급은 배포 성숙도를 설명하는 단계 모델이며 모든 구축이 특정 형식·엔드포인트를 필수로 요구한다는 뜻은 아님.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| URI·관계 모델이 없으면 의미 연결 곤란 | 기존 어휘 재사용, 식별·관계 정의 문서화 |
| 외부 링크가 잘못되거나 끊김 | 링크 출처·신뢰도·유효성 정기 점검 |
| 공개만으로 품질·적법성·재사용성 미보장 | 라이선스·개인정보·최신성·품질 별도 검토 |

## Ⅵ. 제언

공개할 데이터에 URI와 표준 어휘를 부여해 단계적으로 5-Star 수준을 높이고, 링크와 라이선스를 운영 과정에서 점검

```text
공개(★) → 기계 판독(★★) → 개방 형식(★★★) → URI 식별(★★★★) → 외부 링크(★★★★★)
```

| 구분 | 파일 공개만 | 제언: 식별·링크 단계 확대 |
|---|---|---|
| 재사용 | 수작업 결합 | 링크로 자동 탐색 |
| 품질 | 별도 점검 없음 | 링크·라이선스 점검 |
