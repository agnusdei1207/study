## 연관 키워드

**링크드 오픈 데이터(LOD)**, **5-Star 오픈 데이터**, **URI**, **RDF**, **SPARQL**, **외부 링크**, **지식 그래프**

## Ⅰ. 개요

- 핵심 요약 : **링크드 오픈 데이터(LOD)**는 개방 라이선스와 웹 표준을 이용해 데이터를 식별·표현하고 다른 데이터와 연결하는 방식이다.
- 목적 : 데이터 파일의 공개를 넘어 기계가 처리할 수 있는 구조와 의미적 연결성을 제공한다.
- 배경 : 서로 다른 기관·시스템의 데이터가 고립되어 검색·재사용·통합이 어려운 문제를 줄인다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **URI 식별·RDF 표현·링크 연결**을 통해 데이터의 재사용과 상호운용성을 높인다.
- **식별 가능성** : URI(Uniform Resource Identifier)로 데이터 항목을 참조한다.
- **기계 판독성** : RDF(Resource Description Framework) 트리플로 주체·관계·대상을 표현한다.
- **연결성** : 관련 외부 데이터의 URI를 연결해 탐색 범위를 확장한다.
- **재사용성** : 공개 라이선스와 표준 형식을 통해 데이터 활용을 지원한다.

## Ⅲ. LOD 공개와 활용 흐름

- 핵심 요약 : **데이터 정제 → URI·RDF 모델링 → 웹 공개 → 외부 데이터 연결·질의** 순서로 구축한다.

```text
[데이터·라이선스 정비]
          ▼
[항목 URI 식별]
          ▼
[RDF 트리플·어휘 매핑]
          ▼
[웹 공개·접근 제공]
          ▼
[외부 데이터 링크·SPARQL 질의]
          ▼
[재사용·품질 점검]
```

- SPARQL은 RDF 그래프를 질의하는 표준 언어이며, 제공 방식과 접근 정책은 데이터 게시자가 정한다.
- 외부 연결은 의미와 출처를 확인해 구성하며, 단순 URI 일치가 데이터의 완전한 동일성을 보장하지 않는다.

## Ⅳ. 5-Star 데이터와 기술 요소 비교

- 핵심 요약 : **5-Star는 개방 형식과 링크 수준을 단계화한 성숙도 모델**로, RDF만을 유일한 공개 형식으로 강제하는 법적 등급은 아니다.

| 단계 | 특징 | 예시 |
|---|---|---|
| ★ | 웹에 공개 | 문서·이미지 |
| ★★ | 구조화된 데이터 | 스프레드시트 |
| ★★★ | 비독점 형식 | CSV |
| ★★★★ | 개방 표준 URI로 식별 | RDF 데이터 |
| ★★★★★ | 다른 데이터와 링크 | 외부 URI 연결 |

| 기술 | 역할 |
|---|---|
| URI / HTTP | 식별자 부여와 웹 접근 |
| RDF | 주어·술어·목적어 그래프 표현 |
| RDFS / OWL | 어휘·클래스·관계 의미 기술 |
| SPARQL | RDF 데이터 질의 |
| JSON-LD / Turtle | RDF 표현 문법 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **모델링 비용·데이터 품질·링크 지속성·질의 성능**을 관리해야 지속 가능한 공개가 가능하다.
- **어휘·온톨로지 불일치** → 기존 표준 어휘를 우선 검토하고 매핑 근거와 버전을 관리한다.
- **링크 단절·식별자 변경** → 지속 가능한 URI 정책과 링크 상태 점검을 운영한다.
- **오류·낮은 최신성** → 출처·갱신 시각·품질 책임자를 표시하고 검증 절차를 둔다.
- **복잡한 질의·접근 부담** → 질의 범위·응답 한도·캐시를 관리하고 다운로드 API 등 대안을 제공한다.

```text
어휘 불일치 → 표준 매핑·버전 관리
링크 단절   → 지속 URI·상태 점검     → 신뢰할 수 있는 데이터 연결
질의 부담   → 한도·캐시·대체 API
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **개방성·개인정보 보호·라이선스·데이터 품질**을 함께 검토해 단계적으로 공개한다.
- 민감정보와 재식별 위험을 확인하고, 공개 근거와 라이선스를 명확히 한다.
- 핵심 데이터부터 파일·API 공개를 안정화한 후 연결 데이터로 확장한다.
- 외부 링크의 의미·출처·갱신 상태를 정기적으로 검수한다.

## Ⅶ. 결론

- 핵심 요약 : LOD는 **웹 데이터를 의미적으로 연결하는 공개 방식**이며 표준·식별자·품질·지속 운영이 중요하다.
- 답안에는 URI·RDF·SPARQL의 역할과 5-Star 개념, 어휘 불일치·링크 단절 대응을 제시한다.
