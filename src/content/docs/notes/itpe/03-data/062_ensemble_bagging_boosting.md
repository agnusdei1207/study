## 답안 골격
```text
[앙상블 (배깅·부스팅)] ◀━━ 머리: Ⅶ 내 의견 (과적합 데이터에는 배깅/랜덤포레스트, 고난도 불균형 데이터에는 부스팅(LightGBM) 선택)
 ┃
 ┣━ Ⅰ 개요 ───── 복수의 약한 학습기(Weak Learner)를 결합하여 단일 모델의 한계를 극복하고 예측력과 일반화 성능을 극대화하는 기법
 ┣━ Ⅱ 특징 ───── 편향-분산 트레이드오프 해결 · 집단 지성 원리 · 일반화 오차 감소 · 과적합 억제 vs 계산 복잡도
 ┣━ Ⅲ 구조 ───── 배깅(Bagging, 부트스트랩+애그리게이션) / 부스팅(Boosting, 순차 가중치 갱신) / 스태킹(Stacking, 메타 모델)
 ┣━ Ⅳ 흐름 ───── 배깅: 복원추출 표본 생성 → 병렬 독립 학습 → 다수결/평균 취합 / 부스팅: 초기 학습 → 오차 샘플 가중치 상향 → 순차 잔차 학습
 ┣━ Ⅴ 비교 ───── 배깅 vs 부스팅 (병렬 독립 학습/분산(Variance) 감소 vs 순차 의존 학습/편향(Bias) 감소)
 ┗━ Ⅵ 실무 ───── 부스팅의 이상치 과민 반응(과적합) / 대규모 데이터셋에서 직렬 학습에 따른 학습 시간 지연
```
- 필수 키워드: 약한 학습기(Weak Learner) · 배깅(Bagging) · 부스팅(Boosting) · 부트스트랩(Bootstrap) · 편향(Bias) · 분산(Variance) · XGBoost · LightGBM
- 배점 전략: 10점 = Ⅰ → Ⅲ/Ⅳ 배깅과 부스팅 비교 도식 → Ⅴ 핵심 차이점 비교표 / 25점 = Ⅰ~Ⅶ, Ⅳ 알고리즘(AdaBoost, GBM) 수학적 원리 및 Ⅵ 튜닝 전략
- 기출: 120회/126회 `머신러닝 앙상블 기법 중 배깅과 부스팅을 비교 설명하시오` → Ⅰ 개념 + Ⅲ/Ⅳ 병렬/순차 구조 + Ⅴ 편향/분산 관점 상세 비교

## 한 줄 본질
- 단일 모델이 겪는 높은 분산(과적합)과 높은 편향(과소적합)의 한계 → 병렬 복원추출 다수결(배깅)과 순차적 오차 집중 보정(부스팅)으로 약한 학습기 결합 → 일반화 예측력 극대화 / 모델 해석 난이도 증가

## 핵심 그림
```text
[배깅(Bagging)과 부스팅(Boosting) 메커니즘 비교]

 1. 배깅 (병렬 학습: 분산 감소 목표)
    [원시 데이터] ──부트스트랩──> [D1] [D2] [D3]  (복원추출 표본)
                                    │    │    │
                                    ▼    ▼    ▼
    [약한 학습기(병렬)]           [M1] [M2] [M3]  (독립 결정트리)
                                    └───┬────┘
                                        ▼
    [최종 예측]                   [ 다수결 투표 / 평균 (Aggregation) ]

 2. 부스팅 (순차 학습: 편향 감소 목표)
    [원시 데이터] ──> [모델 1] ──오차 표본 가중치 부여──> [모델 2] ──오차 보정──> [모델 3]
                       (w_1)                             (w_2)                  (w_3)
                         └───────────────────────┬────────────────────────┘
                                                 ▼
                                     [ 가중 결합 최종 예측 ]
```

## 핵심 용어
- 부트스트랩(Bootstrap): 원본 데이터셋에서 중복을 허용하여 동일한 크기의 표본 집합을 무작위로 복원 추출하는 통계 기법
- 편향-분산 트레이드오프(Bias-Variance Tradeoff): 모델의 복잡도가 증가하면 편향(과소적합)은 감소하지만 분산(과적합)은 증가하는 상충 관계

## 핵심 통찰
- 배깅은 '분산(Variance)'을 낮춤 → 각 트리가 서로 다른 표본으로 학습하므로 개별 트리의 노이즈가 다수결 투표 과정에서 상쇄되어 과적합 방지(랜덤 포레스트)
- 부스팅은 '편향(Bias)'을 낮춤 → 앞선 모델이 틀린 어려운 샘플에 가중치를 주어 다음 모델이 집중 학습하므로 복잡한 경계를 기가 막히게 학습하지만, 노이즈나 이상치까지 외워버려 과적합 위험
- 정형 데이터 머신러닝 경진대회(Kaggle)의 90% 이상은 부스팅 계열(XGBoost, LightGBM, CatBoost)이 석권 → 결측치 자동 처리와 비선형 상호작용 포착 능력이 탁월

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 랜덤 포레스트(Random Forest) | 배깅의 대표적 구현체 | 부트스트랩 표본뿐만 아니라 노드 분할 시 피처(Feature)까지 무작위 선택하여 트리 간 상관성 배제 |
| 그래디언트 부스팅(GBM) | 부스팅의 손실함수 최소화 | 손실 함수의 음의 그래디언트(잔차, Residual)를 새로운 약한 학습기의 타깃으로 삼아 점진 최적화 |

## 이웃 토픽과 구분
- 배깅 vs 부스팅: 배깅 = 트리들이 상호 독립적으로 병렬 학습(분산 저감, 이상치에 강함) / 부스팅 = 앞선 트리의 잔차를 학습하는 순차적 직렬 의존(편향 저감, 이상치에 민감)

## 문제·원인·대책
- 적용 상황: 대출 연체 예측 모델 학습 시 과적합 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 부스팅 모델이 학습 데이터에서는 정확도 99%이나 테스트셋에서 70%로 급락 | 이상치까지 완벽히 맞추려다 발생한 과적합 | 트리 깊이 제한(max_depth=3~6) 및 학습률(learning_rate) 축소, 조기 종료(Early Stopping) | 일반화 테스트 정확도 88%로 회복 |
| 수천만 건 데이터에서 부스팅 모델 학습 시간이 수 시간 소요 | 잔차 계산 및 노드 분할의 순차적 직렬 처리 병목 | 히스토그램 기반 LightGBM 전환 및 GPU 가속 부스팅 적용 | 학습 시간 10분 이내로 단축 |

## 이렇게 출제된다
- 제120회/126회: "머신러닝의 앙상블 기법인 배깅(Bagging)과 부스팅(Boosting)의 개념, 동작 방식 및 차이점을 비교 설명하시오." → 요구 포인트: 부트스트랩 정의 + 배깅과 부스팅 다이어그램 + 편향/분산 관점 비교표

## 내 의견
- [부스팅 일변도에서 벗어난 하이브리드 설계] 무조건 XGBoost가 최고라는 생각으로 노이즈가 많은 도메인에 부스팅을 적용했다가 운영 데이터에서 취약성 노출 → 나라면: 센서나 크롤링처럼 노이즈가 심한 데이터는 이상치에 둔감한 랜덤 포레스트(배깅)를 먼저 적용하고, 정제된 금융/로그 데이터에 한해 하이퍼파라미터 규제를 건 부스팅 적용
