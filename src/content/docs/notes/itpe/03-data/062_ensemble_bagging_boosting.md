## 지식 로드맵 내 현재 위치

자료처리·데이터 → 머신러닝 → **앙상블(배깅·부스팅)**

## 30초 인출

- 본질: 앙상블 학습은 여러 예측기를 결합해 하나의 예측을 만들어 단일 예측기의 오차와 변동을 보완하는 학습 방법
- 메커니즘: 배깅은 복원추출한 표본별로 예측기를 독립 학습해 투표·평균으로 집계하고, 부스팅은 앞 단계의 오차·손실을 반영해 다음 예측기를 순차 학습해 결합
- 통찰: 배깅은 불안정한 학습기의 분산을, 부스팅은 편향을 줄이는 경향이 있으나 부스팅은 노이즈에 과적합될 수 있으므로 독립 검증 자료와 조기 종료로 일반화 성능을 확인

<details>
<summary>핵심 용어</summary>

- **앙상블 학습(Ensemble Learning)** : 여러 예측기를 결합해 성능을 높이는 학습
- **배깅(Bagging)** : 복원추출 표본으로 독립 학습한 예측기를 집계하는 방법
- **부스팅(Boosting)** : 이전 예측기의 오차를 반영해 순차적으로 학습하는 방법
- **랜덤 포레스트** : 배깅에 특성 무작위 선택을 더해 트리 간 상관을 낮춘 알고리즘
- **AdaBoost·그래디언트 부스팅** : 가중치 조정 / 손실의 그래디언트를 이용하는 부스팅 알고리즘
- **편향·분산** : 모형의 체계적 오차 / 학습 자료에 따른 변동
- **조기 종료(Early Stopping)** : 검증 성능이 나빠지기 시작하면 학습을 멈추는 기법

</details>

## 2~4교시 25점 답안

## Ⅰ. 앙상블 학습의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **앙상블 학습** 은 여러 예측기를 결합해 하나의 예측을 만드는 학습 방법 |
| 목적 | 예측기의 오차와 변동을 보완해 일반화 성능 개선 |

## Ⅱ. 특징

| 특징 | 학습 영향 |
|---|---|
| 예측기 결합 | 단일 예측기의 오차·변동을 서로 다른 방식으로 보완 |
| 배깅의 독립성 | 표본별 병렬 학습과 집계로 분산 완화 |
| 부스팅의 순차성 | 이전 단계의 손실을 반영해 다음 예측기 학습 |

## Ⅲ. 학습 체계

```text
학습 자료
 ├ 배깅: 복원추출 표본별 독립 예측기 ──→ 투표(분류)·평균(회귀)
 └ 부스팅: 예측기1 → 오차·손실 반영 → 예측기2 → … ──→ 단계별 결합
                        ↓
              검증 자료로 일반화 성능 비교
```

- 랜덤 포레스트: 배깅에 특성 무작위 선택을 더해 트리 간 상관을 낮춤
- 부스팅: 알고리즘에 따라 가중치나 잔차·음의 그래디언트를 이용해 다음 예측기를 학습
- 학습률·기저 모델 복잡도·반복 횟수가 성능과 과적합에 영향

## Ⅳ. 편향·분산 관점의 비교

| 비교축 | 배깅 | 부스팅 |
|---|---|---|
| 결합 방식 | 독립 학습 후 집계 | 앞 결과를 반영한 순차 결합 |
| 주된 개선 | 불안정한 학습기의 분산 감소 | 단계적 보정으로 편향 감소 |
| 병렬성 | 병렬화 유리 | 단계 의존으로 순차 |
| 주의점 | 예측기 상관이 높으면 효과 제한 | 노이즈·설정에 따라 과적합 |
| 예시 | 랜덤 포레스트 | AdaBoost, 그래디언트 부스팅 |

편향·분산의 변화는 기저 학습기와 자료에 따른 경향이며 절대 법칙은 아님.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모델 수 증가에 따른 추론 비용·설명 복잡성 | 단일 모델 기준선과 성능·지연·비용 비교 |
| 부스팅이 노이즈·과도한 반복에 맞춰짐 | 독립 검증, 조기 종료, 복잡도 제한 |
| 검증 중 자료 누수 | 전처리·특성 생성도 학습 구간에 맞춰 분리, 시간 자료는 순서 보존 |

## Ⅵ. 제언

모델의 주된 오차 원인이 분산이면 배깅, 편향이면 부스팅을 우선 검토하고 독립 검증으로 확인

```text
과적합·불안정 → 배깅(랜덤 포레스트) / 과소적합·편향 → 부스팅 → 검증·조기 종료
```

| 구분 | 단일 모델 | 제언: 오차 원인별 앙상블 |
|---|---|---|
| 일반화 | 변동·편향 그대로 | 원인에 맞게 보완 |
| 비용 | 낮음 | 추론 비용 증가 |
