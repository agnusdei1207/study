## 연관 키워드

- 앙상블 학습(Ensemble Learning), 배깅(Bagging), 부스팅(Boosting), 분산·편향(Variance·Bias)
- 부트스트랩(Bootstrap), 순차 학습(Sequential Learning), 검증 데이터(Validation Data)

## Ⅰ. 앙상블 배깅·부스팅의 개요

- 핵심 요약 : 여러 모델의 예측을 결합해 단일 모델의 오차와 불안정성을 줄이는 앙상블 학습 기법.
- 개념 : 여러 기본 학습기(Base Learner)의 예측을 결합하는 **앙상블 학습** (Ensemble Learning) 기법으로, **배깅** (Bagging)과 **부스팅** (Boosting)이 대표 방식이다.
- 구성 : 기본 학습기를 병렬 또는 순차 방식으로 학습하고, 투표·평균·가중 결합으로 최종 예측을 만든다.
- 배경 및 필요성 : 단일 모델은 **분산·편향** (Variance·Bias) 사이에서 트레이드오프를 겪으므로, 여러 모델의 결합으로 오차 구조를 개선할 필요가 있음.
- 주의 : 앙상블이 항상 정확도를 높이는 것은 아니며, 데이터 누수와 과적합을 **검증 데이터** (Validation Data)로 확인해야 한다.

## Ⅱ. 앙상블 배깅·부스팅의 특징 및 장점

- 핵심 요약 : 배깅은 학습기 간 변동을 줄이고, 부스팅은 앞선 학습기의 오차를 순차적으로 보정하는 방식.

1. 배깅 (Bagging, Bootstrap Aggregating) : 복원 추출한 부트스트랩 표본으로 학습기를 독립 학습해 예측을 평균·투표 → 변동 감소와 병렬화 유리.
2. 부스팅 (Boosting) : 이전 단계의 오차나 잔차를 반영해 다음 학습기를 **순차 학습** (Sequential Learning) → 복잡한 결정 경계 표현.
3. 랜덤 포레스트(Random Forest) : 배깅에 특성 무작위 선택을 더해 트리 간 상관을 낮춤 → 결합 효과 강화.

- 편향과 분산의 개선 폭은 데이터와 모델에 따라 달라지므로 절대적 보장으로 보지 않는다.

## Ⅲ. 학습 및 결합 흐름

- 핵심 요약 : 표본과 학습기 구성, 예측 생성, 검증된 결합 순서로 최종 모델을 만든다.

```text
[배깅: 병렬 학습]
[학습 데이터]
      ↓ 복원 추출
[부트스트랩 표본들]
      ↓ 독립 학습
[기본 학습기 병렬 학습]
      ↓
[평균·투표로 결합]
```

```text
[부스팅: 순차 학습]
[학습 데이터]
      ↓
[기본 학습기 1]
      ↓ 오차 산출
[기본 학습기 2 (오차 반영)]
      ↓ 반복
[가중 합산 예측]
```

- 스태킹(Stacking)은 서로 다른 기본 모델의 검증 예측을 메타 모델의 입력으로 사용한다. 훈련 예측을 그대로 쓰면 누수와 과적합 위험이 있다.
- 성능 평가는 학습·튜닝 데이터와 분리된 검증 절차로 수행한다.

## Ⅳ. 배깅과 부스팅 비교

- 핵심 요약 : 학습의 병렬성, 오차 보정 방식, 노이즈 민감도를 기준으로 선택.

| 항목 | 배깅 | 부스팅 |
| --- | --- | --- |
| 학습 관계 | 독립 학습, 병렬화 가능 | 이전 단계에 의존하는 순차 학습 |
| 데이터 활용 | 부트스트랩 표본 | 잔차·가중치 반영 |
| 결합 방식 | 평균·다수결 | 가중 합산 |
| 대표 예 | 배깅 트리, 랜덤 포레스트 | AdaBoost, Gradient Boosting |
| 유의점 | 상관이 높은 학습기면 이득이 제한됨 | 학습률·깊이·반복 횟수 조정 필요 |

## Ⅵ. 앙상블 배깅·부스팅에 대한 기술사적 제언

- 핵심 요약 : 단순 기준모형과 앙상블을 같은 검증 조건에서 비교해 복잡도 증가의 효과를 확인하는 방향.
- 정형 데이터에서 특정 알고리즘이 항상 우수하다고 단정하지 않고, 데이터 특성에 따라 후보를 비교한다.
- 스태킹은 교차검증으로 얻은 외부 표본의 예측을 메타 모델 입력으로 써서 누수를 막는다.
- 모델과 데이터 버전, 학습 파라미터, 성능과 설명 자료를 재현 가능하게 기록한다.

## Ⅶ. 결론

- 핵심 요약 : 배깅과 부스팅은 병렬 분산 감소와 순차 편향 보정이라는 서로 다른 전략의 앙상블이며, 검증 설계와 운영 비용을 함께 보고 선택.
- 시사점 : 학습 구조의 차이를 이해하고 검증 절차와 운영 비용을 함께 설계할 때 앙상블의 효과가 재현된다.
