## 연관 키워드

**5NF(Fifth Normal Form)**, **PJNF**, **조인 종속성(JD)**, **MVD**, **무손실 조인 분해**, **SPJ**

## Ⅰ. 개요

- 핵심 요약 : **5NF**는 모든 비사소한 조인 종속성이 슈퍼키에 의해서만 성립하는 정규형.
- 목적 : 3개 이상 릴레이션 동시 분해 시 가짜 튜플 없는 무손실 조인 보장.
- 배경 : 4NF 이후 순환적 삼항 제약 (SPJ) 해결 필요.
- 특징 : JD, PJNF, 3분해, BCNF까지 정규화 계층.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **조인 종속성 제거**로 다원 분해 시 무손실 보장.
- **조인 종속성(JD)** : $\bowtie(R_1,\dots,R_n)=R$ 성립.
- **3분해** : SPJ 사례에서 3 테이블 동시 조인으로 복원.
- **PJNF** : Projection-Join Normal Form.
- **4NF→5NF** : MVD → JD 제거.
- **무손실 보장** : 가짜 튜플 방지.

## Ⅲ. 조인 종속성 흐름

- 핵심 요약 : **SPJ 삼항 관계**에서 2분해 실패 → 3분해 성공.
- SPJ : 공급자-부품-프로젝트 순환 제약.

```text
[ 5NF 위반 사례: SPJ 삼항 관계 ]

규칙: S가 P 공급 + J가 P 사용 + S가 J 참여
     => S는 J에 P 공급 필수

원본 SPJ (S+P+J 복합키)
   삼성/메모리/갤럭시, SK/메모리/갤럭시, ...

2분해 실패: SK-메모리-아이폰 가짜 튜플 생성
3분해 성공: R1(S,P) ⋈ R2(P,J) ⋈ R3(S,J)
```

```text
[ 정규형 계층 ]

1NF -> 2NF -> 3NF -> BCNF -> 4NF (MVD 제거) -> 5NF (JD 제거)
```

## Ⅳ. 4NF vs 5NF 비교

- 핵심 요약 : **MVD vs JD, 2분해 vs 3분해** 비교.

| 항목 | 4NF | 5NF |
|---|---|---|
| 제거 대상 | 다치 종속성 (MVD) | 조인 종속성 (JD) |
| 분해 수 | 2개 | 3개 이상 |
| 발생 배경 | 독립적 1:N 혼재 | 순환적 삼항 제약 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **JD 판별 복잡도·조인 성능·갱신 난제**를 비용 평가·BCNF 상한·트리거로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| JD 판별 복잡도 | 의미론적 발견 극히 어려움 | 도메인 교차 분석, CASE 검증, 비용 대비 평가 | 모델 정확도 |
| 조인 성능 오버헤드 | 3중 조인으로 OLTP 성능 저하 | BCNF까지 정규화 상한, 5NF는 참조 마스터 한정, 반정규화 | 조인 응답 시간 |
| 갱신 난제 | 3개 이상 테이블 원자적 갱신 | 복합 FK 인덱스, 트리거 캡슐화 | 트랜잭션 성공률 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **BCNF 상한·트리거·학술/실무 타협**.
- 엔터프라이즈 RDBMS : BCNF까지 엄격 정규화 상한.
- 5NF 특수 제약 : 테이블 분해 대신 복합 PK 제약 + 트리거.
- 조인 종속성 실무 식별 어려움 인지.

## Ⅶ. 결론

- 핵심 요약 : 5NF는 **조인 종속성 제거** 정규형으로 학술적 완결성이나 실무는 BCNF 상한.
- 답안에는 JD, SPJ 사례, 4NF 비교, 한계·대응을 연결.
