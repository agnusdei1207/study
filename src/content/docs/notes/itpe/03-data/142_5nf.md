## 지식 로드맵 내 현재 위치

자료처리·데이터 → 관계형 데이터 모델링 → **제5정규형(5NF)**

## 30초 인출

- 본질: 제5정규형은 모든 비자명한 조인 종속이 후보키에 의해 함의되는 정규형(PJNF)
- 메커니즘: 릴레이션을 여러 투영으로 나누어 자연조인한 결과 R′가 업무 규칙상 모든 유효 상태에서 원래 R과 같으면 무손실 분해 후보이고, R′에 허용되지 않은 행이 생기면 조인 종속이 없는 것으로 보아 분해하지 않음
- 통찰: 현재 표본에서 우연히 일치한 것을 조인 종속으로 오인하기 쉬우므로 모든 유효 상태를 다루는 업무 제약으로 확인하고, 과도한 분해로 늘어나는 조회 조인 비용을 함께 평가

<details>
<summary>핵심 용어</summary>

- **제5정규형(5NF, PJNF)** : 모든 비자명한 조인 종속이 후보키로 함의되는 정규형
- **조인 종속(JD)** : R = π_R1(R) ⨝ … ⨝ π_Rn(R)이 성립하는 제약
- **투영(Projection)** : 릴레이션에서 일부 속성만 뽑아 만든 릴레이션
- **자연조인** : 공통 속성이 같은 행을 결합하는 연산
- **무손실 분해** : 분해 후 조인하면 원래 릴레이션을 정확히 복원하는 분해
- **허위 튜플(Spurious Tuple)** : 재조인 시 원래 없던 행이 생기는 현상

</details>

## 2~4교시 25점 답안

## Ⅰ. 제5정규형의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **제5정규형** 은 모든 비자명 조인 종속이 후보키에 의해 함의되는 정규형 |
| 목적 | 키에서 드러나지 않는 다자 관계로 인한 중복·갱신 이상 방지 |

## Ⅱ. 특징

| 특징 | 모델링 의미 |
|---|---|
| 조인 종속 중심 | 다치 종속보다 일반적인 여러 투영의 재결합 관계 검토 |
| 후보키 조건 | 비자명 조인 종속이 후보키로 함의되는지 확인 |
| 업무 규칙 의존 | 현재 자료의 우연한 일치로 모든 유효 상태의 무손실성을 보장할 수 없음 |

## Ⅲ. 투영·재조인과 무손실 판정

```text
원래 관계 R(A, B, C)
  ├ πAB(R) ┐
  ├ πAC(R) ┼ 자연조인 → R′
  └ πBC(R) ┘
R′ = R 이 업무 제약으로 모든 유효 상태에서 성립 → 무손실 분해 후보
R′에 허용되지 않은 행 생성 → 조인 종속 없음, 분해 중단
```

조인 종속 *(R1, …, Rn)은 R = ⨝ π_Ri(R)이라는 구조적 제약이며 단일 표본의 일치와 업무 규칙상 등식 보장을 구분.

## Ⅳ. 제4정규형과의 비교

| 기준 | 4NF | 5NF(PJNF) |
|---|---|---|
| 다루는 종속 | 다치 종속(MVD) | 일반 조인 종속(JD) |
| 판정 | 비자명 MVD의 결정자가 슈퍼키 | 모든 비자명 JD가 후보키로 함의 |
| 범위 | 독립적인 다중값 관계 | 여러 투영의 조인으로 표현되는 관계 |

모든 다치 종속은 조인 종속의 특수한 경우이므로 5NF가 더 일반적인 구조를 다룸.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 표본의 우연한 일치를 조인 종속으로 오인 | 모든 유효 상태를 다루는 업무 제약으로 종속 확인 |
| 무손실 조건 없이 분해해 허용되지 않은 조합 생성 | 투영·재조인 결과를 원래 관계와 비교, 갱신 시 제약 검증 |
| 과도한 분해로 조회 조인 비용 증가 | 대표 질의 실행계획과 갱신 이상 감소 효과 함께 평가 |

## Ⅵ. 제언

업무 규칙으로 조인 종속을 확인한 관계에만 5NF를 적용하고 재조인 검증을 자동화

```text
BCNF·4NF → 다자 관계 이상 확인 → 업무 규칙으로 JD 확인 → 분해 → 재조인 검증
```

| 구분 | 표본 기반 판단 | 제언: 업무 규칙 기반 |
|---|---|---|
| 무손실성 | 우연 일치 위험 | 모든 유효 상태 |
| 비용 | 과분해 | 이상 확인된 곳만 |
