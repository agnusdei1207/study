## 지식 로드맵 내 현재 위치

데이터베이스 → 데이터 모델링·정규화 → 조인 종속성과 제5정규형

## 30초 인출

- 본질: **제5정규형(5NF)은** 키에서 비롯되지 않은 조인 종속성을 제거하는 정규형
- 메커니즘: 관계를 여러 투영 관계로 분해하고, 조인으로 원래 관계를 손실 없이 복원
- 통찰: 모든 조인 종속성(JD)이 후보키에 의해서만 성립하도록 관계를 무손실 분해하여 다자간 연관 관계의 중복과 갱신 이상을 원천 배제함.

<details>
<summary>핵심 용어</summary>

- **제5정규형(Fifth Normal Form, 5NF)** : 모든 비자명 조인 종속성이 후보키에 의해 함의되는 정규형
- **프로젝트-조인 정규형(Project-Join Normal Form, PJNF)** : 5NF와 같은 의미로 쓰이는 명칭
- **조인 종속성(Join Dependency, JD)** : 관계가 여러 투영 관계의 조인과 동일하다는 제약
- **무손실 조인(Lossless Join)** : 분해한 관계를 조인했을 때 원래 관계와 정확히 같아지는 성질

</details>

## 2~4교시 25점 답안

## Ⅰ. 제5정규형의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **제5정규형(5NF)** 은 모든 비자명 조인 종속성이 후보키에 의해 함의되는 정규형 |
| 목적 | 키에서 드러나지 않는 다자 관계의 분해로 인한 중복·갱신 이상 방지 |

## Ⅱ. 제5정규형의 특징

| 특징 | 모델링 의미 |
|---|---|
| 조인 종속성 중심 | 다치 종속성보다 일반적인 여러 투영의 재결합 관계를 검토 |
| 후보키 조건 | 비자명 조인 종속성이 후보키에서 함의되는지 확인 |
| 업무 규칙 의존 | 현재 자료의 우연한 일치만으로 모든 유효 상태의 무손실성을 보장할 수 없음 |

## Ⅲ. 다자 관계의 투영·재조인 체계와 무손실 판정

```text
원래 관계 R(A,B,C)
      ├─ 투영 πAB(R) ─┐
      ├─ 투영 πAC(R) ─┼─ 자연조인 → 후보 복원 관계 R′
      └─ 투영 πBC(R) ─┘
                              ↓
                 업무 규칙상 모든 유효 상태에서 R′=R?
```

### 허용되지 않은 조합이 생기는 분기

```text
재조인 R′와 원래 R 비교
    ├─ R′=R가 업무 제약으로 항상 성립 → 무손실 분해 후보
    └─ R′에 허용되지 않은 행 생성 → 조인 종속성 없음, 분해 중단
```

JD $*(R_1,R_2,\ldots,R_n)$는 $R=\Join_i\pi_{R_i}(R)$라는 구조적 제약임. 단일 표본 인스턴스의 일치와 전사 업무 규칙상 등식 보장을 엄격히 구분 필요.

## Ⅳ. 제4정규형과 제5정규형의 비교

| 기준 | 제4정규형(4NF) | 제5정규형(5NF/PJNF) |
|---|---|---|
| 다루는 종속성 | 다치 종속성(MVD) | 일반 조인 종속성(JD) |
| 판정 관점 | 비자명 MVD의 결정자가 슈퍼키 | 모든 비자명 JD가 후보키에 의해 함의 |
| 범위 | 특정 형태의 독립적인 다중값 관계 | 여러 투영의 조인으로 표현되는 관계 |

모든 다치 종속성은 조인 종속성의 특수한 경우이므로 5NF가 더 일반적인 조인 종속성 구조를 다룸.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 현재 표본의 우연한 일치를 조인 종속성으로 오인 | 모든 유효 상태를 다루는 업무 제약으로 종속성을 확인 |
| 무손실 조건 없는 분해로 허용되지 않은 조합 생성 | 투영·재조인 결과와 원래 관계를 비교하고 갱신 시 제약 검증 |
| 과도한 분해로 조회 조인 비용 증가 | 대표 질의의 실행계획과 갱신 이상 감소 효과를 함께 평가 |

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
3자 이상의 다대다 연관성에서 발생하는 순환적 조인 종속성 존재 여부를 선행 검증하고, 조인 오버헤드와 데이터 무결성 보장 수준을 비교 평가하여 5NF 분해 여부 결정.

### 2. 아키텍처 및 상세 메커니즘
```text
           [ 원본 릴레이션 R(에이전트, 회사, 제품) ]
                (순환적 조인 종속성: *(R1, R2, R3))
                                 │
     ┌───────────────────────────┼───────────────────────────┐
     ▼                           ▼                           ▼
[ R1(에이전트, 회사) ]       [ R2(회사, 제품) ]       [ R3(에이전트, 제품) ]
     │                           │                           │
     └─────────────┬─────────────┘                           │
                   ▼                                         │
        [ R1 ⋈ R2 (임시 조인) ]                              │
                   │                                         │
                   └───────────────────┬─────────────────────┘
                                       ▼
                       [ (R1 ⋈ R2) ⋈ R3 = R (무손실 복원) ]
```

### 3. 기술 유형 및 비교 평가
| 정규형 단계 | 대상 종속성 | 분해 조건 | 제거되는 이상 현상 | 주요 트레이드오프 |
|---|---|---|---|---|
| **BCNF** | 비자명 함수 종속성 (FD) | 모든 결정자 $X$가 슈퍼키 | 단일 속성 결정 관련 이상 | 종속성 보존 손실 가능 |
| **4NF** | 다치 종속성 (MVD) | 모든 $X \twoheadrightarrow Y$에서 $X$가 슈퍼키 | 독립적인 복수 다대다 관계 중복 | 엔터티 개수 증가 |
| **5NF (PJNF)** | 조인 종속성 (JD) | 모든 조인 종속성의 $R_i$가 슈퍼키 | 다자간 순환 연관 관계의 중복 | 3자 조인 성능 저하 |
| **DKNF** | 도메인/키 제약 | 모든 제약이 도메인·키 제약으로 표현 | 모든 논리적 갱신 이상 배제 | 실무적 달성 및 검증 불가 |
