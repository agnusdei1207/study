## 지식 로드맵 내 현재 위치

데이터베이스 → 데이터 모델링·정규화 → 조인 종속성과 제5정규형

## 30초 인출

- 본질: **제5정규형(5NF)**은 키에서 비롯되지 않은 조인 종속성을 제거하는 정규형
- 메커니즘: 관계를 여러 투영 관계로 분해하고, 조인으로 원래 관계를 손실 없이 복원
- 판단: 분해 전 업무 규칙이 실제 조인 종속성을 보장하는지 확인

<details>
<summary>핵심 용어</summary>

- **제5정규형(Fifth Normal Form, 5NF)**: 모든 비자명 조인 종속성이 후보키에 의해 함의되는 정규형
- **프로젝트-조인 정규형(Project-Join Normal Form, PJNF)**: 5NF와 같은 의미로 쓰이는 명칭
- **조인 종속성(Join Dependency, JD)**: 관계가 여러 투영 관계의 조인과 동일하다는 제약
- **무손실 조인(Lossless Join)**: 분해한 관계를 조인했을 때 원래 관계와 정확히 같아지는 성질

</details>

## 2~4교시 25점 답안

## Ⅰ. 제5정규형 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 모든 비자명 조인 종속성이 후보키에 의해 함의되는 정규형 |
| 목적 | 키에서 드러나지 않는 다자 관계의 분해로 인한 중복·갱신 이상 방지 |

## Ⅱ. 조인 종속성과 무손실 분해

```mermaid
flowchart TD
    R[관계 R(A,B,C)] -->|투영| AB[R1(A,B)]
    R -->|투영| AC[R2(A,C)]
    R -->|투영| BC[R3(B,C)]
    AB --> J[세 투영의 조인]
    AC --> J
    BC --> J
    J -->|JD가 성립할 때| R2[원래 관계 복원]
```

JD $*(R_1,R_2,\ldots,R_n)$는 $R=\Join_i\pi_{R_i}(R)$가 성립한다는 제약. 분해는 이 등식이 모든 유효 상태에서 성립할 때 무손실.

## Ⅲ. 제4정규형과 제5정규형

| 기준 | 제4정규형(4NF) | 제5정규형(5NF/PJNF) |
|---|---|---|
| 다루는 종속성 | 다치 종속성(MVD) | 일반 조인 종속성(JD) |
| 판정 관점 | 비자명 MVD의 결정자가 슈퍼키 | 모든 비자명 JD가 후보키에 의해 함의 |
| 범위 | 특정 형태의 독립적인 다중값 관계 | 여러 투영의 조인으로 표현되는 관계 |

모든 다치 종속성은 조인 종속성의 특수한 경우이므로 5NF가 더 일반적인 조인 종속성 구조를 다룸.

## Ⅳ. 분해 타당성과 운영 영향

| 검토 항목 | 확인 방법 |
|---|---|
| 업무 제약 | 다자 관계의 실제 규칙과 유효한 튜플 조합 확인 |
| 무손실성 | 분해된 투영을 조인한 결과가 원래 관계와 일치하는지 검증 |
| 갱신 정확성 | 삽입·삭제·변경 시 관계 제약 보존 여부 확인 |
| 질의 영향 | 자주 쓰는 질의의 조인 수·실행계획·운영 비용 측정 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 이론상 분해 가능해도 실제 업무 제약이 없거나 조인 비용이 크면 재결합 오류와 조회 복잡성 증가 | 업무 규칙으로 JD를 입증한 관계만 분해하고, 무손실 조인·갱신 제약·대표 질의 실행계획을 함께 검증 |
