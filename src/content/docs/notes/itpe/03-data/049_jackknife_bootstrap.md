## 연관 키워드
- 재표집, 잭나이프, 부트스트랩, 표준오차, 신뢰구간, 편향 보정

### Ⅰ. 잭나이프·부트스트랩의 개요

- 핵심 요약 : 잭나이프는 관측값을 하나씩 제외해 통계량을 재계산하고 부트스트랩은 관측자료에서 복원추출한 표본을 반복 구성해 추정량 분포를 근사하는 재표집 방법.
- 개념 : 잭나이프는 관측값을 하나씩 제외해 통계량을 재계산하고 부트스트랩은 관측자료에서 복원추출한 표본을 반복 구성해 추정량 분포를 근사하는 재표집 방법(**잭나이프·부트스트랩**, Jackknife & Bootstrap).
- 배경 및 필요성 : 분포 가정이 어렵거나 분석적 표준오차·구간을 구하기 어려운 통계량이 존재함.
- 주요 목적 : 표본자료로 추정량의 불확실성과 편향을 평가.

### Ⅱ. 잭나이프·부트스트랩의 특징 및 장점

- 핵심 요약 : 잭나이프·부트스트랩·설계 반영은 추정량 분포를 추정하는 재표집 방식.

1. 잭나이프 : leave-one-out 반복 → 계산 단순, 매끄러운 통계량에 유용.
2. 부트스트랩 : 복원추출 반복 → 복잡한 통계량 분포 근사.
3. 설계 반영 : 군집·층화·시계열 의존을 보존 → 잘못된 재표집 방지.

### Ⅲ. 잭나이프·부트스트랩의 구조 (흐름)

- 핵심 요약 : 통계량·표본설계 정의 → 재표집 단위·방법 결정 → 반복 표본·통계량 계산 → 편향·표준오차·구간 산출 → 가정·재표집 안정성 확인.

```text
통계량·표본설계 정의
   ↓
재표집 단위·방법 결정
   ↓
반복 표본·통계량 계산
   ↓
편향·표준오차·구간 산출
   ↓
가정·재표집 안정성 확인
```

```text
원표본 → (잭나이프: 1개씩 제외) / (부트스트랩: n개 복원추출) → 통계량 반복분포 → SE·신뢰구간
```

### Ⅳ. 잭나이프와 부트스트랩 비교

- 핵심 요약 : 적합성 기준 — 잭나이프: 매끄러운 통계량·영향도 평가; 부트스트랩: 분포·표준오차·신뢰구간의 일반적 근사.

| 비교 기준 | 잭나이프 | 부트스트랩 |
|---|---|---|
| 재표집 | 관측값 하나씩 제외 | 원자료에서 복원추출 |
| 적합성 | 매끄러운 통계량·영향도 평가 | 분포·표준오차·신뢰구간의 일반적 근사 |
| 비용·제약 | 반복 수 n으로 상대적 저비용 | 반복횟수 증가에 계산비용 증가 |

### Ⅴ. 잭나이프·부트스트랩의 한계와 방안

- 핵심 요약 : 표본 의존성 무시·희귀사건 표본 부족 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 표본 의존성 무시 | 시계열·군집 구조를 무시한 iid 재표집 | 블록·군집·설계 기반 부트스트랩 | 추정 안정성 |
| 희귀사건 표본 부족 | 관측되지 않은 꼬리·희귀값 재현 불가 | 외삽 한계 명시·모형기반 분석 보완 | 구간 민감도 |
| 재표집 불안정 | 비매끄러운 통계량·작은 표본에서 편향 | 잭나이프·대안 구간·시뮬레이션 비교 | 반복별 분산 |

### Ⅵ. 잭나이프·부트스트랩에 대한 제언

- 핵심 요약 : 분석자는 추정대상과 표본설계에 맞는 재표집 단위를 명시하고 난수 시드·반복 수·구간 산식을 재현 가능하게 보존할 필요가 있다.
- 실행 제안 : 통계 담당자는 표본설계에 맞는 재표집 단위·반복 수·신뢰구간 방법을 명시하고 재현용 시드·코드 보존.

### Ⅶ. 결론

- 핵심 요약 : 재표집은 관측자료가 대표하는 정보의 불확실성을 평가할 뿐 표본 편향이나 모집단 미관측 영역을 자동 해결하지 않음.
- 시사점 : 재표집의 타당성은 원래 표본설계와 의존 구조를 보존하는 데 달려 있음.
