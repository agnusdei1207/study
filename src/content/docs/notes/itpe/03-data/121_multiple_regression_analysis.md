## 30초 인출

- 본질: 다중회귀분석은 여러 설명변수와 하나의 반응변수 사이의 조건부 평균 관계를 선형 모형으로 추정하는 방법
- 메커니즘: 설명변수 행렬 X로 최소제곱(OLS)해 잔차 제곱합이 최소가 되는 계수를 구하고, 잔차·공선성·영향 관측을 진단해 구조 문제가 있으면 변수·모형을 재검토한 뒤 해석하거나 독립 자료로 예측을 검증
- 통찰: 계수는 다른 변수를 모형에 둔 조건부 관계일 뿐 인과가 아니고 공선성·이상 관측에 불안정하므로, 설명과 예측 목적에 따라 검증 근거를 달리하고 학습 범위 밖 예측을 피함

<details>
<summary>핵심 용어</summary>

- **다중회귀분석** : 여러 설명변수로 반응변수를 선형 모형화하는 분석
- **OLS(최소제곱법)** : 잔차 제곱합을 최소화하는 계수 추정법
- **잔차(Residual)** : 실제값과 예측값의 차이
- **VIF** : 설명변수 간 공선성 정도를 나타내는 지표
- **영향 관측** : 계수 추정에 큰 영향을 주는 관측
- **조건부 관계** : 다른 설명변수를 모형에 둔 상태의 관계

## 2~4교시 25점 답안

## Ⅰ. 다중회귀분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **다중회귀분석** 은 여러 설명변수와 반응변수 사이의 조건부 평균 관계를 선형 모형으로 추정하는 방법 |
| 목적 | 변수 간 관계 설명 또는 미관측 반응값 예측 |

## Ⅱ. 특징

| 특징 | 해석 의미 |
|---|---|
| 여러 변수 동시 고려 | 계수는 다른 설명변수를 모형에 둔 조건부 관계 |
| 추정과 진단 구분 | 계수 계산 후 잔차·불확실성·영향 관측 점검 |
| 목적별 평가 | 설명과 예측은 요구하는 검증 근거가 다름 |

## Ⅲ. 추정과 진단 절차

```text
목적·변수 정의 → 설명변수 행렬 X, 반응 Y
   ↓ OLS: Σe² (e = Y − Ŷ) 최소인 β 추정
예측값·잔차 계산 → 잔차 패턴·공선성·영향 관측 진단
   ├ 구조 문제 → 변수·모형 재검토
   └ 수용 가능 → 설명 해석 또는 독립 자료로 예측 검증
```

## Ⅳ. 진단 항목과 목적별 평가

| 점검 대상 | 진단·해석 |
|---|---|
| 평균 구조 | 잔차 대 적합값 그래프로 비선형 패턴 확인 |
| 오차 구조 | 독립성·등분산성 점검(표준오차·추론에 영향) |
| 설명변수 관계 | VIF 등으로 공선성 확인, 단일 임계값으로 변수를 자동 제거하지 않음 |
| 영향 관측 | 잔차와 영향 통계량 확인, 제거는 오류·업무 맥락 검토 후 결정 |

| 목적 | 주요 질문 | 우선 확인 |
|---|---|---|
| 관계 설명 | 조건부 관계를 어떻게 해석할지 | 변수 의미·계수 불확실성·교란 가능성 |
| 값 예측 | 새 관측값을 얼마나 잘 맞히는지 | 분리된 검증 자료·오차 분포·적용 범위 |

오차 정규성은 작은 표본의 정확한 추론에 영향을 줄 수 있으나 설명변수가 정규분포여야 한다는 뜻은 아님.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 관측 자료의 계수를 원인 효과로 단정 | 설계·교란 가능성 확인, 조건부 관계로 해석 범위 한정 |
| 공선성·이상 관측으로 계수 불안정 | VIF·영향 통계량과 업무 맥락 확인, 처리 근거 기록 |
| 학습 자료 밖에 적용해 오차 증가 | 적용 범위 명시, 독립 자료에서 오차·잔차 검증 |

## Ⅵ. 제언

분석 목적을 먼저 정하고 설명은 진단·교란 검토로, 예측은 독립 검증 자료로 평가

```text
목적 정의 → OLS 추정 → 진단 → (설명) 해석 범위 한정 / (예측) 독립 자료 검증
```

| 구분 | 결정계수만 확인 | 제언: 진단 + 목적별 검증 |
|---|---|---|
| 계수 해석 | 인과 오해 | 조건부 관계 |
| 예측 | 학습 성능만 | 독립 자료 검증 |

## 출제 이력과 검증 출처

- Q-net 기출 원문에서 직접 묻는 문항 없음
- Kutner 외, Applied Linear Statistical Models
