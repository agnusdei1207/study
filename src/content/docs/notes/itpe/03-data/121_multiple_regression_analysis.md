데이터베이스 → 통계·데이터 분석 → 회귀분석

## 30초 인출

- 본질: **다중회귀분석은 여러 설명변수와 하나의 반응변수 사이의 조건부 평균 관계를 선형 모형으로 추정하는 방법**
- 메커니즘: 최소제곱으로 계수를 추정하고 잔차·계수 불확실성·영향 관측을 진단해 설명 또는 예측 목적에 맞게 평가
- 통찰: 복수의 독립변수와 종속변수 간의 선형 관계를 추정할 때 선형성·독립성·등분산성·정규성의 4대 오차 가정을 잔차 분석으로 검증하고 다중공선성을 사전 통제 필수

<details><summary>핵심 용어</summary>

- **다중회귀분석 (Multiple Regression Analysis)** : 복수 설명변수와 반응변수의 조건부 평균 관계를 분석하는 회귀 방법
- **OLS (Ordinary Least Squares)** : 잔차 제곱합을 최소화하는 회귀계수 추정법
- **VIF (Variance Inflation Factor)** : 다른 설명변수와의 선형 관계가 계수 분산을 얼마나 키우는지 나타내는 지표
- **잔차 (Residual)** : 관측값과 모형 예측값의 차이

</details>

## 2~4교시 25점 답안

## Ⅰ. 다중회귀분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **다중회귀분석** 은 여러 설명변수와 하나의 반응변수 사이 조건부 평균 관계를 선형 모형으로 추정하는 방법 |
| 목적 | 변수 간 관계 설명 또는 미관측 반응값 예측을 위한 모형화 |

## Ⅱ. 다중회귀분석의 특징

| 특징 | 해석상 의미 |
|---|---|
| 여러 설명변수의 동시 고려 | 한 계수는 다른 설명변수를 모형에 둔 상태의 조건부 평균 관계 |
| 추정과 진단의 구분 | 계수를 계산한 뒤에도 잔차·불확실성·영향 관측을 점검해야 함 |
| 목적에 따른 평가 | 관계 설명과 새 관측값 예측은 요구하는 검증 근거가 다름 |

## Ⅲ. 모형 추정·진단 체계와 OLS 작동 원리

```text
분석 목적·변수 정의 → 관측 자료와 설명변수 행렬 X
                            ↓
                    OLS로 계수 β 추정
                            ↓
       예측값·잔차 계산 → 모형 가정·영향 관측 진단
                            ↓
              설명 해석 또는 독립 자료 예측 검증
```

### 잔차 제곱합 최소화와 진단 분기

```text
X·β → 예측값 Ŷ → Y와의 차이 e=Y−Ŷ
                    ↓
            Σe² 최소인 β 추정
                    ↓
잔차 패턴·공선성·영향 관측 확인
    ├─ 구조 문제 → 변수·모형 재검토
    └─ 수용 가능 → 목적별 해석·독립 검증
```

계수 $\beta_j$는 다른 변수를 모형에 둔 상태에서 $X_j$ 변화와 조건부 평균의 선형 관계 표현. 계수 추정 자체가 인과관계 입증은 아님에 유의.

## Ⅳ. 진단 항목과 설명·예측 목적의 비교

| 점검 대상 | 진단·해석 |
|---|---|
| 평균 구조 | 잔차 대 적합값·설명변수 그래프로 비선형 패턴 확인 |
| 오차 구조 | 설계 맥락에서 독립성·등분산성 점검; 표준오차와 추론에 영향 |
| 설명변수 관계 | VIF 등으로 공선성 정도 확인; 보편적인 단일 임계값으로 변수 자동 제거 금지 |
| 영향 관측 | 잔차와 영향 통계량을 함께 확인; 관측 제거는 데이터 오류·업무 맥락 검토 후 결정 |

| 목적 | 주요 질문 | 우선 확인 |
|---|---|---|
| 관계 설명 | 변수의 조건부 관계를 어떻게 해석할 것인가 | 변수 의미·계수 불확실성·가정·교란 가능성 |
| 값 예측 | 새 관측값을 얼마나 잘 예측하는가 | 분리된 검증 자료·오차 분포·적용 범위 |

오차 정규성은 작은 표본의 정확한 모수 추론에 영향을 줄 수 있으나, 설명변수 자체가 정규분포여야 한다는 의미는 아님.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 관측 자료의 계수를 원인 효과로 단정 | 설계·교란 가능성과 변수 의미를 확인하고 해석 범위를 조건부 관계로 한정 |
| 공선성·이상 관측으로 계수 해석 불안정 | VIF·영향 통계량과 업무 맥락을 함께 확인해 변수·관측 처리 근거 기록 |
| 학습 자료 밖에 예측을 적용해 오차 증가 | 적용 범위를 밝히고 독립 자료에서 예측 오차·잔차를 검증 |

## Ⅵ. 제언

수정 결정계수($Adj-R^2$)와 AIC/BIC를 활용하여 과적합 없는 최적 변수 조합(단계적 회귀/Lasso)을 선정하고 이상치 영향도를 Cook's Distance로 검증.

### 다중회귀분석 모델링 및 잔차 진단 절차

```text
[독립변수 수집 및 스케일링] ──► [다중공선성(VIF) 검사 및 변수 선별]
                                       │
                                       ▼
[최소자승법(OLS) 회귀모형 적합: Y = β0 + β1X1 + ... + βkXk + ε]
                                       │
                                       ▼
[잔차 분석 (Residual Diagnosis)]
  - 선형성: 잔차 산점도 무패턴 검증
  - 등분산성: Breusch-Pagan 검정
  - 정규성: Q-Q Plot / Shapiro 검정
  - 독립성: Durbin-Watson 검정
                                       │
                                       ▼
[수정 결정계수 및 F-검정 통과 → 최종 예측 및 계수 해석]
```

### 선택 근거: 제언: 수정 결정계수 ($Adj-R^2$)

| 구분 | 단순 결정계수 ($R^2$) | 제언: 수정 결정계수 ($Adj-R^2$) |
|---|---|---|
| 변수 추가 왜곡 | 무의미한 변수 추가 시에도 $R^2$ 증가 | 변수 개수 패널티 부여로 과적합 방지 |
| 모델 비교 기준 | 변수 수가 다른 모델 간 비교 불가 | 자유도를 반영하여 객관적 모델 간 비교 가능 |
| 실무 권장도 | 설명력 과장 위험 | 다중회귀 모델의 실질적 설명력 평가 표준 |
