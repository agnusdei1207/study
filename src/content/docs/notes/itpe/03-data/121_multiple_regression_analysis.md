## 30초 인출

- 본질: **다중회귀분석은 여러 설명변수와 하나의 반응변수 사이의 조건부 평균 관계를 선형 모형으로 추정하는 방법**
- 메커니즘: 최소제곱으로 계수를 추정하고 잔차·계수 불확실성·영향 관측을 진단해 설명 또는 예측 목적에 맞게 평가

<details><summary>핵심 용어</summary>

- **다중회귀분석 (Multiple Regression Analysis)** : 복수 설명변수와 반응변수의 조건부 평균 관계를 분석하는 회귀 방법
- **OLS (Ordinary Least Squares)** : 잔차 제곱합을 최소화하는 회귀계수 추정법
- **VIF (Variance Inflation Factor)** : 다른 설명변수와의 선형 관계가 계수 분산을 얼마나 키우는지 나타내는 지표
- **잔차 (Residual)** : 관측값과 모형 예측값의 차이

</details>

## 1교시 10점 답안

### Ⅰ. 다중회귀분석 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 다중회귀분석은 여러 설명변수와 반응변수의 조건부 평균 관계를 선형 모형으로 추정하는 방법 |
| 목적 | 변수 간 관계 설명 또는 미관측 반응값 예측을 위한 모형화 |

### Ⅱ. 모형과 진단

| 단계 | 핵심 내용 |
|---|---|
| 모형 | $Y=\beta_0+\beta_1X_1+\cdots+\beta_pX_p+\epsilon$ |
| 추정 | OLS로 잔차 제곱합을 최소화해 계수 추정 |
| 진단 | 잔차 패턴·분산·독립성, 다중공선성, 영향 관측 확인 |
| 해석 | 계수는 다른 설명변수를 고정한 조건부 관계이며 인과효과로 단정하지 않음 |

## 2~4교시 25점 답안

## Ⅰ. 다중회귀분석 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 다중회귀분석은 여러 설명변수와 반응변수의 조건부 평균 관계를 선형 모형으로 추정하는 방법 |
| 목적 | 변수 간 관계 설명 또는 미관측 반응값 예측을 위한 모형화 |

## Ⅱ. 모형과 계수 추정

| 요소 | 의미 |
|---|---|
| 반응변수 $Y$ | 설명하거나 예측하려는 수치형 결과 |
| 설명변수 $X_j$ | 반응변수와 관련된 입력 특성 |
| 계수 $\beta_j$ | 다른 변수를 고정했을 때 $X_j$ 변화와 조건부 평균의 선형 관계 |
| OLS | $\sum_i (y_i-\hat y_i)^2$ 최소화 |

## Ⅲ. 추론 가정과 진단

| 점검 대상 | 진단·해석 |
|---|---|
| 평균 구조 | 잔차 대 적합값·설명변수 그래프로 비선형 패턴 확인 |
| 오차 구조 | 설계 맥락에서 독립성·등분산성 점검; 표준오차와 추론에 영향 |
| 설명변수 관계 | VIF 등으로 공선성 정도 확인; 보편적인 단일 임계값으로 변수 자동 제거 금지 |
| 영향 관측 | 잔차와 영향 통계량을 함께 확인; 관측 제거는 데이터 오류·업무 맥락 검토 후 결정 |

오차 정규성은 작은 표본에서 정확한 모수 추론에 영향을 주지만, 모든 회귀 목적에 필수인 예측변수 정규성 가정은 아님

## Ⅳ. 적용과 해석상 한계

| 사용 목적 | 해석 원칙 |
|---|---|
| 설명 | 계수는 모형에 포함된 다른 변수를 조건으로 한 관계 |
| 예측 | 검증 자료에서 예측 오차와 적용 범위를 평가 |
| 인과 추론 | 회귀계수만으로 인과성을 보장하지 않으며 연구 설계·교란 통제 필요 |
| 변수 선택 | 도메인 근거·진단·검증 성능을 함께 고려; $R^2$ 하나로 적합성 결론 금지 |

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 관측 상관관계를 원인으로 오해하거나 학습자료 밖에 모형을 적용할 위험 | 분석 목적을 설명·예측으로 먼저 구분하고, 변수의 의미·잔차 진단·독립 검증 결과를 함께 남기는 모델 검토 절차 마련 |
