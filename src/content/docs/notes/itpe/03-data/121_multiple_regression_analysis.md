## 연관 키워드

다중회귀분석, OLS, VIF, R², Adjusted R², 다중공선성, 단계적 선택법, AIC, BIC, 회귀 가정, 편회귀계수

## Ⅰ. 다중회귀분석의 개요

- 핵심 요약 : 둘 이상의 독립변수를 선형으로 결합해 종속변수를 설명하고 예측하는 지도학습 기법.
- 개념 : 여러 독립변수의 선형 결합으로 종속변수를 모델링하는 통계 기법 (**다중회귀분석**, Multiple Regression Analysis).
- 배경 및 필요성 : 단순회귀는 변수 하나만 반영하므로 여러 요인이 얽힌 현상을 설명하지 못하고, 요인을 동시에 통제하지 않으면 잘못된 해석에 이를 위험이 큼. 이 한계를 줄이려면 여러 요인을 함께 넣은 모델이 필요함.
- 주요 목적 : 다변량 인과관계를 정량적으로 설명하고 예측.
- 특징 : 최소제곱 추정, 가정 검증, 변수 선택과 적합도 평가를 거치는 추정 모델.

## Ⅱ. 다중회귀분석의 특징 및 장점

- 핵심 요약 : 다변량 동시 반영, 최소제곱 추정, 가정 검증이 결합돼 각 요인의 효과를 통제된 상태에서 정량화하는 구조.

1. 다변량 동시 반영 : 여러 설명변수를 한 모델에 넣어 각 변수의 고유한 효과를 분리 → 교란 요인을 통제한 상태에서 계수 해석 가능.
2. **OLS** (Ordinary Least Squares, 최소제곱법) : 잔차 제곱합을 최소화하도록 계수를 추정 → 계산 기준이 명확하고 해석이 단순함.
3. **회귀 가정** (선형성, 독립성, 등분산성, 정규성)의 검증 : 가정이 성립하는지 확인 → 계수의 표준오차와 검정 결과를 신뢰할 수 있음.
4. **결정계수** (R², Coefficient of Determination)와 **수정된 결정계수** (Adjusted R², 변수 수 페널티 반영) : 설명력을 수치로 평가 → 모델의 적합도 판단 근거 제공.
5. **단계적 선택법** (Stepwise) : 유의한 변수를 넣고 빼며 **AIC** (Akaike Information Criterion)와 **BIC** (Bayesian Information Criterion)로 설명력과 복잡도의 균형을 비교 → 과도하게 복잡한 모델 방지.

## Ⅲ. 모델 추정 흐름

- 핵심 요약 : 가정 확인, OLS 추정, 적합도 평가, 변수 선택, 진단의 순서로 모델을 세우고 검증함.
- 회귀식 : $Y = \beta_0 + \beta_1 X_1 + \dots + \beta_k X_k + \epsilon$ (ε는 오차항).
- 추정식 : $\hat\beta = (X^T X)^{-1} X^T Y$ (OLS 해).

```text
[ 회귀분석 4대 가정 ]

1. 선형성   : X와 Y의 관계가 직선 형태
2. 독립성   : 오차끼리 자기상관이 없음
3. 등분산성 : 오차의 분산이 일정함
4. 정규성   : 오차가 정규분포를 따름
```

```text
[ 변수 선택법 ]

Forward  : 유의한 변수를 하나씩 추가
Backward : 비유의 변수를 하나씩 제거
Stepwise : 추가와 제거를 번갈아 수행
```

## Ⅳ. 적합도와 변수 선택 비교

- 핵심 요약 : R²는 설명력을 보여 주고, 수정된 R²는 변수 수를 반영해 모델끼리 비교할 때 쓰임.

| 항목 | R² | Adjusted R² |
| --- | --- | --- |
| 정의 | 종속변수 변동 중 모델이 설명하는 비율 | 변수 수에 대한 페널티를 반영한 설명 비율 |
| 변수 추가 시 | 항상 증가하거나 유지 | 무의미한 변수를 넣으면 감소 |
| 용도 | 설명력 확인 | 변수 수가 다른 모델끼리 비교 |

- 변수 선택 기준 : AIC와 BIC는 값이 작을수록 좋은 모델로 보며, BIC는 표본 크기가 클수록 변수 추가에 더 큰 페널티를 줌.
- **다중공선성** (Multicollinearity, 설명변수끼리 강하게 상관된 상태) : **VIF** (Variance Inflation Factor, 분산팽창계수)로 진단하며, 값이 10 이상이면 변수 제거나 조정을 검토함.

## Ⅴ. 한계와 방안

- 핵심 요약 : 다중공선성, 가정 위반, 과적합을 VIF 진단, 강건 표준오차, 교차검증과 규제 기법으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 다중공선성 | 변수 간 강한 상관으로 계수의 분산이 커져 해석이 불안정 | VIF 진단 후 변수 제거, 주성분 회귀(PCR, Principal Component Regression), L1·L2 규제 | VIF |
| 가정 위반 | 이분산이나 자기상관으로 표준오차가 왜곡 | 브로이시-파간 검정(Breusch-Pagan) 진단, 강건 표준오차(Robust SE), 변수 변환 | DW(Durbin-Watson) 통계량, BP 검정 p값 |
| 과적합 | 설명변수가 많아 학습 데이터에만 맞고 예측 오차 증가 | 수정된 R²와 AIC·BIC로 변수 수 통제, 교차검증(CV, Cross-Validation) | CV 오차 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : 계수 해석 원칙, 영향점 진단, 모델의 목적에 맞는 평가 기준을 함께 갖추어야 회귀 결과를 신뢰할 수 있음.

1. 계수 해석 원칙 : **편회귀계수**는 다른 변수를 고정했을 때 해당 변수가 1단위 변할 때의 평균 변화로 읽고, 상호작용이 의심되는 변수쌍에는 교차항을 넣어 효과가 달라지는지 확인한다.
2. 영향점 진단 : 쿡 거리(Cook's Distance)와 지렛대값(Leverage)으로 모델을 좌우하는 관측치를 찾고, 필요하면 RANSAC(RANdom SAmple Consensus) 같은 강건 추정으로 영향을 줄인다.
3. 목적별 평가 : 인과 해석이 목적이면 계수의 신뢰구간과 가정 검증을 우선하고, 예측이 목적이면 교차검증 오차를 기준으로 변수를 고르는 것이 적절하다.

## Ⅶ. 결론

- 핵심 요약 : 다중회귀분석은 여러 요인을 동시에 통제해 인과 관계를 정량화하는 기본 모델로, 가정 검증과 다중공선성 대응이 신뢰성을 좌우함.
- 시사점 : 계수 해석과 예측 성능은 목적에 따라 다른 기준으로 평가해야 하므로, 모델의 쓰임을 먼저 정한 뒤 변수와 검정 절차를 고르는 것이 바람직함.
