## 지식 로드맵 내 현재 위치

자료처리·데이터 → 인덱스·공간 데이터 → **다차원 색인구조**

## 30초 인출

- 본질: 다차원 색인구조는 여러 속성이나 좌표의 공간 관계를 이용해 범위·근접 질의의 후보를 좁히는 색인 구조
- 메커니즘: 공간을 격자·K-D 트리로 분할하거나 객체의 최소 경계 사각형(MBR)을 R-Tree로 계층화해 질의 영역과 겹치는 후보만 찾고, 정제 단계에서 실제 조건을 검사
- 통찰: MBR 겹침은 실제 교차를 뜻하지 않아 후보 탐색(필터)과 정밀 검사(정제)를 나누어야 하며, 겹침이 많거나 차원이 높으면 구분력이 떨어지므로 분포와 질의를 실측해 구조를 고름

<details>
<summary>핵심 용어</summary>

- **다차원 색인** : 여러 속성·좌표를 함께 사용해 범위·근접 질의를 가속하는 색인
- **MBR(Minimum Bounding Rectangle)** : 객체를 감싸는 최소 경계 사각형
- **R-Tree** : 객체의 MBR을 계층적으로 묶은 색인 트리
- **K-D 트리** : 차원을 번갈아 나누며 공간을 분할하는 이진 트리
- **격자 파일(Grid)** : 공간을 격자 셀로 나누어 셀 단위로 저장하는 색인
- **필터·정제 단계** : MBR로 후보를 고르는 단계 / 실제 기하 조건을 검사하는 단계
- **차원의 저주** : 차원이 커질수록 거리·영역의 구분력이 약해지는 현상

</details>

## 2~4교시 25점 답안

## Ⅰ. 다차원 색인구조의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **다차원 색인구조** 는 여러 속성·좌표의 공간 관계로 범위·근접 질의 후보를 좁히는 색인 구조 |
| 목적 | 다차원 조건 검색에서 불필요한 레코드 탐색 감소 |

## Ⅱ. 특징

| 특징 | 검색 영향 |
|---|---|
| 다차원 조건 | 단일 정렬 키 대신 공간 관계·영역 이용 |
| 후보 기반 탐색 | 경계 영역이 과대 포함되어 실제 조건 재검사 필요 |
| 분포 민감 | 차원·편중·갱신 빈도에 따라 탐색 비용 변화 |

## Ⅲ. 유형

| 유형 | 핵심 구조 | 특징 |
|---|---|---|
| 공간 분할 | 격자, K-D 트리로 공간을 구획 | 점 데이터의 위치 관계 탐색에 적합 |
| 객체 분할 | R-Tree 노드에 객체 MBR 저장 | 공간 객체 범위를 계층적으로 좁힘 |

```text
루트 MBR(R0)
 ├ R1 ─ R3(o1) · R4(o2)
 └ R2 ─ R5(o3) · R6(o4)
질의 영역과 겹치는 MBR만 따라 내려가 후보 객체 선택
```

## Ⅳ. 질의 유형과 활용 사례

- MBR은 객체를 감싸는 경계이므로 MBR 겹침만으로 실제 교차를 확정할 수 없음
- 필터 단계는 후보 탐색, 정제 단계는 실제 기하 조건 검사

| 질의 | 색인 활용 |
|---|---|
| 영역 질의 | 질의 영역과 교차하는 셀·MBR을 후보로 선택 |
| 근접 질의 | 거리 기준으로 후보 영역 탐색 후 실제 거리 확인 |

| 활용 사례 | 내용 |
|---|---|
| 지도·위치 서비스 | 특정 영역 안의 시설·이동체 검색 |
| 공간 데이터베이스 | 공간 객체의 교차·포함 질의 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| MBR이 많이 겹치면 탐색 경로 증가 | 분포·질의 유형에 맞춰 노드 구성과 실행계획 확인 |
| 고차원에서 구분력 약화 | 차원·분포·정확도에 맞춰 근사 최근접 색인과 실측 비교 |
| 갱신이 잦으면 유지 비용 증가 | 검색 지연과 삽입·갱신 비용을 함께 측정 |

## Ⅵ. 제언

데이터 차원과 질의 유형으로 색인을 고르고, 후보 탐색과 정제 단계를 나누어 실측으로 검증

```text
저차원 공간 객체 → R-Tree / 점 데이터 → K-D·격자 / 고차원 유사도 → 근사 최근접 색인
```

| 구분 | 단일 속성 색인 조합 | 제언: 공간 색인 |
|---|---|---|
| 영역 질의 | 여러 색인 결합 필요 | 공간 관계로 직접 후보 축소 |
| 유지 | 단순 | 분포에 따른 관리 |
