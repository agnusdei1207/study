## 답안 골격
```text
[PCA (주성분 분석)] ◀━━ 머리: Ⅶ 내 의견 (엘보우 스크리 플롯 기반 차원 축소와 해석 불가능성 해소를 위한 설명력 검증)
 ┃
 ┣━ Ⅰ 개요 ───── 고차원 데이터의 분산(Variance)을 최대한 보존하면서, 서로 직교하는 새로운 기저 축(주성분)으로 선형 변환하는 비지도 차원 축소 기법
 ┣━ Ⅱ 특징 ───── 분산 극대화 · 직교(Orthogonal) 축 생성 · 다중공선성 완전 제거 · 정보 손실 최소화 · 비지도 학습
 ┣━ Ⅲ 구조 ───── 표준화 데이터 / 공분산 행렬($\Sigma$) / 고유벡터(Eigenvector, 축 방향) / 고유값(Eigenvalue, 분산 크기) / 사영 행렬
 ┣━ Ⅳ 흐름 ───── ① 피처 표준화(Z-score) → ② 공분산 행렬 계산 → ③ 고유값·고유벡터 분해(SVD) → ④ 고유값 기준 정렬 및 주성분 수($k$) 결정 → ⑤ 새로운 저차원 공간 투영
 ┣━ Ⅴ 비교 ───── PCA vs t-SNE vs LDA (선형/분산보존 vs 비선형/국소구조시각화 vs 지도학습/클래스분리극대화)
 ┗━ Ⅵ 실무 ───── 변수 스케일 왜곡(사전 표준화 필수) / 스크리 플롯(Scree Plot) 주성분 수 결정 / 축의 도메인 의미 해석 난해
```

## 한 줄 본질
- 고차원 데이터의 다중공선성과 연산량 폭증(차원의 저주) → 데이터의 정보(분산)가 가장 큰 방향으로 직교하는 주성분 벡터를 찾아 사영 → 차원 축소 및 노이즈 제거 / 변수의 도메인 해석력 상실 및 비선형 관계 포착 불가

## 핵심 그림
```text

  X2 ▲        / (PC1: 분산이 최대인 첫 번째 주성분 축)
     │       /  : 고유값 λ1이 최대인 고유벡터 e1 방향
     │   *  / *

     └───────────────────► X1
```

## 핵심 용어
- 고유값(Eigenvalue, $\lambda$): 특정 주성분 축이 데이터의 전체 분산을 얼마나 많이 설명(보유)하고 있는지를 나타내는 척도
- 설명 분산 비율(Explained Variance Ratio): 전체 분산 대비 각 주성분이 설명하는 분산의 비율($\frac{\lambda_i}{\sum \lambda}$)로, 누적 70~90% 지점에서 축소 차원 수($k$) 결정

## 핵심 통찰
- PCA 전 표준화(Standardization)를 생략하면 단위가 큰 변수 하나가 주성분을 독점함 → 연봉(원 단위)과 나이(세 단위)가 있으면 연봉 변수의 분산만 99.9%로 계산되어 나이 정보가 삭제됨
- 주성분 축들은 서로 직교(Orthogonal)하므로 상관계수가 정확히 0임 → 다중공선성(Multicollinearity)으로 인한 회귀 모델 왜곡을 원천 제거하는 완벽한 전처리 도구
- PCA의 치명적 대가는 '설명 가능성의 상실'임 → $PC1 = 0.5 \times \text{키} + 0.8 \times \text{몸무게} - 0.2 \times \text{혈압}$ 처럼 변수들이 섞여 버리므로 금융/의료 규제 심사 모델에는 단독 적용 불가

## 이웃 토픽과 구분
- PCA vs LDA: PCA = 클래스 라벨 없는 비지도 학습으로 데이터 자체의 분산이 최대가 되는 축 탐색 / LDA(Linear Discriminant Analysis) = 클래스 라벨을 활용해 클래스 간 분산은 극대화하고 클래스 내 분산은 최소화하는 지도 학습

## 문제·원인·대책
- 적용 상황: 수백 개 센서 데이터를 활용한 스마트 팩토리 설비 이상 예측 모델 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 센서 간 강한 상관관계로 회귀 계수 부호가 뒤집히고 모델 과적합 발생 | 300개 센서 간 다중공선성 존재 | PCA 수행 후 누적 분산 85%를 만족하는 상위 15개 주성분으로 압축 | 다중공선성 완전 해소 및 추론 연산 속도 10배 향상 |
| PCA 적용 후 특정 센서 변수가 주성분의 99%를 차지하며 다른 센서 무력화 | 센서별 측정 단위(전압 mV vs 온도 ℃) 미표준화 | `StandardScaler`를 파이프라인 첫 단계에 배치해 평균 0, 분산 1 변환 | 모든 센서가 공정한 가중치로 주성분 도출에 기여 |
