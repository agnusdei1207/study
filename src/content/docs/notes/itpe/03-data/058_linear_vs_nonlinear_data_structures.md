## 연관 키워드

- 선형 자료구조, 비선형 자료구조, 배열, 연결리스트, 트리, 그래프

## Ⅰ. 선형·비선형 자료구조의 개요

- 핵심 요약 : 선형 자료구조는 원소가 순차적 선후관계로 연결되고 비선형 자료구조는 계층·망 구조의 다중 관계를 표현.
- 개념 : 선형 자료구조는 원소가 순차적 선후관계로 연결되고 비선형 자료구조는 계층·망 구조의 다중 관계를 표현.
- 배경 및 필요성 : 자료 간 관계와 접근·수정 연산에 맞는 메모리 표현 선택 필요.
- 주요 목적 : 문제의 구조·연산 복잡도·메모리 비용에 맞는 데이터 표현.

## Ⅱ. 선형·비선형 자료구조의 특징 및 장점

- 핵심 요약 : 선형: 배열·리스트·스택·큐 → 순차 처리·간단한 순회; 비선형: 트리·그래프 → 계층·네트워크 관계 표현; 연산 복잡도: 탐색·삽입·삭제 비용이 구현 구조에 의존.

1. 선형: 배열·리스트·스택·큐 → 순차 처리·간단한 순회
2. 비선형: 트리·그래프 → 계층·네트워크 관계 표현
3. 연산 복잡도: 탐색·삽입·삭제 비용이 구현 구조에 의존

## Ⅲ. 선형·비선형 자료구조의 구조 (흐름)

- 핵심 요약 : 관계·연산 요구 분석 → 선형/계층/망 구조 선택 → 메모리·인덱싱 방식 선택 → 복잡도·경계조건 검증.

```text
관계·연산 요구 분석
  ↓
선형/계층/망 구조 선택
  ↓
메모리·인덱싱 방식 선택
  ↓
복잡도·경계조건 검증
```

- 핵심 구성 : 선형: A → B → C

```text
선형: A → B → C
트리:       A
           / \
          B   C
그래프: A—B—C, 다중 경로·순환 가능
```

## Ⅳ. 비교: 선형 구조 / 비선형 구조

- 핵심 요약 : 대표 연산 기준 — 선형 구조: 순회·인덱스 접근·양끝 삽입; 비선형 구조: 탐색·경로·순회·균형관리.

| 비교 기준 | 선형 구조 | 비선형 구조 |
| --- | --- | --- |
| 관계 표현 | 순서가 있는 단일 전후 경로 | 계층·다중 연결·순환 관계 |
| 대표 연산 | 순회·인덱스 접근·양끝 삽입 | 탐색·경로·순회·균형관리 |

## Ⅴ. 선형·비선형 자료구조의 한계와 방안

- 핵심 요약 : 구조 선택 오류·메모리 오버헤드 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 구조 선택 오류 | 관계에 맞지 않는 표현으로 연산 복잡도 증가 | 주요 연산과 규모를 기준으로 자료구조 선정 | 연산 복잡도 |
| 메모리 오버헤드 | 포인터·노드 메타데이터 비용 | 연속배열·압축표현·캐시지역성 비교 | 메모리 사용량 |
| 경계·순환 오류 | 인덱스 범위·순환 참조에서 결함 | 불변식·방문표시·경계 테스트 | 오류 재현률 |

## Ⅵ. 선형·비선형 자료구조의 제언

- 핵심 요약 : 개발자는 자료형 이름보다 조회·갱신 패턴, 최대 규모, 정렬·경로 필요를 기준으로 자료구조와 복잡도 계약을 문서화.
- 실행 제안 : 개발자는 자료구조별 최악 복잡도·메모리·접근 locality를 예상 규모의 벤치마크로 확인.

## Ⅶ. 선형·비선형 자료구조의 결론

- 핵심 요약 : 선형·비선형 분류는 단순한 모양 구분이 아니라 데이터 관계와 지원할 연산을 구조적으로 표현하는 선택.
- 시사점 : 자료구조는 모양보다 관계의 표현력·시간복잡도·메모리 지역성이라는 실제 제약으로 선택.
