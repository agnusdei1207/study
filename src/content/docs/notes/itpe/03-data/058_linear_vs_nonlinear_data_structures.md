## 지식 로드맵 내 현재 위치

자료처리·데이터 → 자료구조 → **선형 vs 비선형 자료구조**

## 30초 인출

- 본질: 선형 자료구조는 요소가 1:1 선후 관계로 나열된 구조이고, 비선형 자료구조는 요소가 1:N·N:M 계층·망 관계로 연결된 구조
- 메커니즘: 선형은 배열·연결 리스트·스택·큐·데크로 순차 접근·입출력을 하고, 비선형은 트리·힙·그래프로 분기 순회를 하며 관계 모양에 맞는 구조를 선택
- 통찰: 구조마다 잘하는 연산이 달라(배열은 접근 O(1), 연결 리스트는 삽입·삭제 O(1)) 데이터의 관계 모양과 주요 연산 패턴으로 구조를 골라야 탐색·표현 비용이 줄어듦

<details>
<summary>핵심 용어</summary>

- **선형 자료구조** : 요소가 하나의 순서로 나열되고 선행자·후속자가 각 최대 하나인 구조
- **비선형 자료구조** : 한 요소가 여러 요소와 연결되는 계층·망 구조
- **스택(Stack)** : 가장 나중에 넣은 것을 먼저 꺼내는 LIFO 구조
- **큐(Queue)** : 가장 먼저 넣은 것을 먼저 꺼내는 FIFO 구조
- **데크(Deque)** : 양쪽 끝에서 삽입·삭제하는 구조
- **트리·그래프** : 계층 관계 구조 / 정점과 간선의 망 구조
- **힙(Heap)** : 부모가 자식보다 우선인 완전 이진 트리 기반 우선순위 구조

</details>

## 2~4교시 25점 답안

## Ⅰ. 선형·비선형 자료구조의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **선형 자료구조** 는 1:1 선후 관계로 나열된 구조, **비선형 자료구조** 는 1:N·N:M 계층·망 관계의 구조 |
| 목적 | 데이터의 관계 모양과 연산 패턴에 맞는 구조 선택으로 탐색·표현 비용 최소화 |

## Ⅱ. 특징

| 특징 | 선형 | 비선형 |
|---|---|---|
| 관계 | 요소당 선행자·후속자 최대 1개 | 여러 자식·간선 연결 |
| 순회 | 처음부터 끝까지 단일 순서 | 깊이·너비 우선 등 분기 순회 |
| 메모리 표현 | 연속 배열 또는 포인터 체인 | 노드 + 다중 포인터·간선 리스트 |

## Ⅲ. 분류와 입출력 원리

```text
자료구조
 ├ 선형: 배열(인덱스 접근) · 연결 리스트(포인터) · 스택(LIFO) · 큐(FIFO) · 데크(양끝)
 └ 비선형: 트리(계층) · 힙(우선순위) · 그래프(망)
```

| 구조 | 대표 연산 | 비용 |
|---|---|---|
| 배열 | 인덱스 접근, 중간 삽입·삭제 | 접근 O(1), 삽입·삭제 O(N) |
| 연결 리스트 | 링크 갱신, 순차 탐색 | 삽입·삭제 O(1)(위치 확보 시), 탐색 O(N) |
| 스택·큐 | 끝점 입출력 | O(1), 내부 직접 접근 불가 |
| 트리·그래프 | 분기 탐색·순회 | 균형 트리 O(log N), 그래프는 정점·간선 수에 비례 |

## Ⅳ. 비교

| 비교축 | 선형 | 비선형 |
|---|---|---|
| 표현하는 관계 | 순서·대기열 | 포함·소속·연결 |
| 탐색 | 순차 탐색 또는 정렬 후 이분 탐색 | 루트·시작 정점에서 분기 탐색 |
| 삽입·삭제 | 이동 또는 링크 갱신 | 연결 재구성, 균형·순환 관리 |
| 활용 | 함수 호출·되돌리기(스택), 작업 대기(큐) | 인덱스·파일 시스템(트리), 경로·네트워크(그래프) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 선형 구조의 비순차 조건 탐색은 O(N) | 트리·해시 기반 인덱스 병행 |
| 계층·망 데이터를 선형으로 저장하면 중복·조인 비용 증가 | 관계 모양에 맞는 트리·그래프 채택 |
| 비선형 구조의 순회·균형 관리 부담 | 표준 라이브러리·정형 알고리즘 활용 |

## Ⅵ. 제언

데이터의 관계 모양과 주요 연산으로 구조를 선택

```text
순서·대기 → 선형(스택·큐) / 계층 → 트리 / 연결망 → 그래프 / 우선순위 → 힙
```

| 구분 | 모두 배열로 저장 | 제언: 관계에 맞는 구조 |
|---|---|---|
| 계층·망 표현 | 중복·탐색 비용 | 직접 표현 |
| 연산 | 특정 연산에 편중 | 연산에 맞는 비용 |
