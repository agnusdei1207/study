## 연관 키워드

**데이터기반행정**, **정부통합데이터분석센터**, **데이터 안심구역**, **CDO(Chief Data Officer)**, **데이터 리터러시**, **공공데이터 공동활용**, **적극행정 면책**

## Ⅰ. 개요

- 핵심 요약 : **데이터기반행정**은 공공데이터를 수집·연계·분석해 과학적 근거로 정책을 수립·집행·평가하는 행정 체계.
- 목적 : 책임성·신뢰성·효율성 극대화, 직관 의존 행정에서 과학적 행정으로 전환.
- 배경 : 관행·직관 의존 행정의 한계 → 데이터 기반 의사결정 필요.
- 법적 기반 : 데이터기반행정 활성화에 관한 법률, 정부통합데이터분석센터, 기본계획 수립.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **4대 추진 영역**으로 칸막이 해소·분석·인프라·역량을 종합 추진.
- **공공데이터 공동활용** : 기관 간 칸막이 해소, 메타데이터 등록 의무화.
- **데이터 분석 및 정책 연계** : 복지 사각지대, 재난 예측, 교통 최적화.
- **인프라 확충** : 통합 분석 플랫폼, 데이터 안심구역.
- **역량·문화 조성** : 데이터 리터러시 교육, 실태평가·인센티브.

## Ⅲ. 거버넌스 및 추진 흐름

- 핵심 요약 : **국가데이터정책위원회 → 분석센터 → 개별 기관** 계층 거버넌스.
- CDO(Chief Data Officer) 지정, 공동활용 데이터 등록, 정책 과제 발굴.

```text
[ 데이터기반행정 추진 거버넌스 ]

[국가데이터정책위원회 / 행정안전부]
   -> 기본계획·실태점검
        |
        v
[정부통합데이터분석센터]
   -> 범정부 분석·활용 지원
        |
   +----+----+
   |         |
   v         v
[개별 공공기관 (중앙부처·지자체)]
   -> CDO 지정, 데이터 등록, 과제 발굴
```

## Ⅳ. 추진 영역 비교

- 핵심 요약 : **공동활용·분석·인프라·역량** 4영역의 과제와 효과 비교.

| 영역 | 주요 과제 | 효과 |
|---|---|---|
| 공공데이터 공동활용 | 칸막이 해소, 메타데이터 등록 | 데이터 접근성 향상 |
| 데이터 분석·정책 연계 | 복지·재난·교통 분석 | 정책 정확도 향상 |
| 인프라 확충 | 통합 플랫폼, 안심구역 | 민간-공공 융합 |
| 역량·문화 조성 | 리터러시 교육, 실태평가 | 조직 데이터 문화 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **칸막이·비표준화·역량 부족**을 법 개정·표준화·교육으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 데이터 칸막이 | 법령 비밀유지·기관 이기주의로 공유 제한 | 법률 개정(의무 공유 확대), 메타데이터 등록 의무화 | 공유 데이터 수 |
| 비표준화·품질 저하 | 상이한 코드 체계, 결측치, 비정형 텍스트 | 표준용어 사전, DQC 인증, 프로파일링 | 품질 인증률 |
| 역량 부족 | 순환보직, 분석 전문성 부재 | 전문직렬 신설, 노코드 BI, 리터러시 교육 | 교육 이수율 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **적극행정 면책·피드백 루프·API 연동**으로 정책 실행력 강화.
- 적극행정 면책 : 가명정보 결합 준수 시 공무원 면책 제도 정착.
- 피드백 루프 : 분석 모델을 행정정보시스템에 API로 직접 연동.
- 데이터 안심구역 확대 : 민간-공공 데이터 융합 환경 조성.
