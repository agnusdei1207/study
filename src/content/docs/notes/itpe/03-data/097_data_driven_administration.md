## 연관 키워드

- 데이터기반행정, 정부통합데이터분석센터, 데이터 안심구역, CDO, 데이터 리터러시, 공공데이터 공동활용, 적극행정 면책

## Ⅰ. 데이터기반행정의 개요

- 핵심 요약 : 공공데이터를 수집·연계·분석해 과학적 근거로 정책을 수립·집행·평가하는 행정 체계.
- 개념 : 공공기관이 보유한 데이터를 수집·가공·분석해 정책 판단의 근거로 삼는 행정 방식(**데이터기반행정**).
- 배경 및 필요성 : 관행과 직관에 의존한 행정의 한계를 넘기 위해 데이터 기반 의사결정이 필요해짐.
- 주요 목적 : 공공기관의 책임성·대응성·신뢰성을 높이고 행정 효율을 개선하는 것.
- 법적 기반 : 「데이터기반행정 활성화에 관한 법률」(현행 법령 기준 2023년 11월 17일 시행)에 근거하며, 범정부 분석을 지원하는 **정부통합데이터분석센터**를 둠. 행정안전부 발표 기준 2026년 1월 29일 이 법을 전면 개정한 「인공지능 및 데이터 기반 행정 활성화에 관한 법률」이 국회 본회의를 통과하여 AI 활용 행정으로 범위가 확장됨.

## Ⅱ. 데이터기반행정의 특징 및 장점

- 핵심 요약 : 4대 추진 영역인 칸막이 해소, 분석 연계, 인프라, 역량을 함께 추진하는 구조.

1. **공공데이터 공동활용** : 기관 간 칸막이를 해소하고 메타데이터 등록을 의무화 → 데이터 접근성 향상.
2. 데이터 분석과 정책 연계 : 복지 사각지대 발굴, 재난 예측, 교통 최적화에 분석 결과를 반영 → 정책 정확도 향상.
3. 인프라 확충 : 통합 분석 플랫폼과 **데이터 안심구역**(민감 데이터를 통제된 환경에서 분석하는 공간) 운영 → 공공과 민간 데이터 융합 기반 마련.
4. 역량과 문화 조성 : **데이터 리터러시** (Data Literacy, 데이터를 읽고 해석해 활용하는 능력)을 교육하고 실태 평가와 인센티브를 연계 → 조직 내 데이터 문화 정착.

## Ⅲ. 데이터기반행정의 거버넌스 및 추진 흐름

- 핵심 요약 : 범정부 분석 센터의 지원 아래 개별 기관이 과제를 발굴하는 계층 거버넌스.
- **CDO** (Chief Data Officer, 기관의 데이터 정책과 활용을 총괄하는 책임자) : 기관별 지정을 통해 공동활용 데이터 등록과 정책 과제 발굴을 책임짐.

```text
[ 데이터기반행정 추진 체계 ]

[기본계획 수립·실태 점검]
         ↓
[정부통합데이터분석센터]
  범정부 분석·활용 지원
         ↓
[개별 공공기관 (중앙부처·지자체)]
  CDO 지정, 데이터 등록, 과제 발굴
```

## Ⅳ. 추진 영역의 비교

- 핵심 요약 : 공동활용, 분석, 인프라, 역량 4개 영역의 주요 과제와 기대 효과를 비교.

```text
[ 추진 영역의 관계 ]

공동활용 (칸막이 해소)
         ↓
분석·정책 연계 (근거 생성)
         ↓
인프라·역량 (지속 기반)
```

| 영역 | 주요 과제 | 기대 효과 |
| --- | --- | --- |
| 공공데이터 공동활용 | 칸막이 해소, 메타데이터 등록 | 데이터 접근성 향상 |
| 데이터 분석·정책 연계 | 복지·재난·교통 분석 | 정책 정확도 향상 |
| 인프라 확충 | 통합 플랫폼, 데이터 안심구역 | 공공과 민간 데이터 융합 기반 |
| 역량·문화 조성 | 리터러시 교육, 실태 평가 | 조직의 데이터 문화 정착 |

## Ⅴ. 데이터기반행정의 한계와 방안

- 핵심 요약 : 칸막이, 비표준화, 역량 부족을 법 개정, 표준화, 교육으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 데이터 칸막이 | 비밀유지 규정과 기관 이기주의로 공유 제한 | 법률 개정으로 의무 공유 확대, 메타데이터 등록 의무화 | 공유 데이터 수 |
| 비표준화·품질 저하 | 상이한 코드 체계, 결측치, 비정형 텍스트 | 표준용어 사전 운영, 데이터 품질 인증, 프로파일링 | 품질 인증 비율 |
| 역량 부족 | 순환보직, 분석 전문성 부재 | 전문직렬 신설, 노코드 BI(Business Intelligence) 도구 활용, 리터러시 교육 | 교육 이수율 |

## Ⅵ. 데이터기반행정에 대한 기술사적 제언

- 핵심 요약 : 적극행정 면책, 피드백 루프, 외부 연동을 갖춰 정책 실행력을 강화하는 방향.

1. **적극행정 면책** (데이터 활용 과정에서 법정 절차를 준수한 공무원의 판단에 책임을 면해 주는 제도) 을 정착시켜, 가명정보 결합 같은 데이터 활용이 위축되지 않도록 할 필요가 있다.
2. 분석 모델의 결과를 행정정보시스템에 API(Application Programming Interface) 방식으로 연동해, 정책 집행 결과가 다시 분석으로 돌아오는 피드백 루프를 만들어야 한다.
3. 민간과 공공의 데이터를 융합하는 환경을 데이터 안심구역 중심으로 넓혀 정책 과제의 범위를 확장할 필요가 있다.

## Ⅶ. 결론

- 핵심 요약 : 데이터기반행정은 과학적 근거에 따라 정책을 운영하는 체계로, 칸막이 해소와 표준화, 역량 확보가 핵심임.
- 시사점 : 4대 추진 영역, 거버넌스, 한계와 대응을 함께 설계해야 행정 전반의 데이터 활용이 지속될 수 있음.
