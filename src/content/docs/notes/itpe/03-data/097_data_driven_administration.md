자료처리·데이터 → 공공 데이터 활용 → **데이터기반행정**

## 30초 인출

- 본질: 데이터기반행정은 공공기관이 데이터를 분석해 정책 수립과 의사결정에 활용하는 행정
- 메커니즘: 정책 문제와 필요한 데이터를 정하고, 요청 기관의 목적·권한과 보유 기관의 제공 조건을 확인해 허용된 항목만 연계하며, 분석·AI 결과를 담당자가 검토해 결정하고 시행 결과로 정정
- 통찰: 부서마다 정의·품질이 다른 데이터를 그대로 결합하면 정책 분석이 왜곡되므로 목적과 품질 기준을 합의해 출처·변환 이력을 남기고, AI 결과도 최종 결정 주체가 검토

- **데이터기반행정** : 데이터 분석을 정책 수립·의사결정에 활용하는 행정

- **처리 근거** : 개인정보를 처리할 수 있는 법적 근거
- **설명 가능성** : 결정의 근거를 설명·검토할 수 있는 성질

## 2~4교시 25점 답안

## Ⅰ. 데이터기반행정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터기반행정** 은 공공기관이 데이터를 분석해 정책 수립과 의사결정에 활용하는 행정 |
| 목적 | 객관적·과학적 행정으로 책임성·대응성·신뢰성 제고 |

## Ⅱ. 특징

| 특징 | 대상 | 관리 조건 |
|---|---|---|
| 근거 기반 | 정책 수립·평가에 쓰는 데이터 | 출처와 품질을 설명할 수 있어야 함 |
| 기관 간 활용 | 서로 다른 기관의 데이터 | 목적·권한·제공 조건 확인 |
| 책임 있는 해석 | 분석 결과와 공적 결정 | 최종 결정 주체·정정 경로 유지 |

## Ⅲ. 추진 절차

```text
정책 문제·필요 데이터 정의
   ↓ 요청 기관의 목적·권한, 보유 기관의 제공 조건 확인
정의·품질·개인정보 처리 근거 대조
   ↓ 허용된 항목만 연계, 변환 이력 보존
분석·AI 결과 → 담당자의 편향·오류 검토
   ↓ 정책 결정·설명 → 시행 결과 평가·정정
```

법령상 공동활용·제공 절차와 개인정보 보호·보안 규정을 준수.

## Ⅳ. 관리 기반과 AI 통제

| 관리 항목 | 내용 |
|---|---|
| 메타데이터·관계도 | 구조·속성·이력과 데이터 간 관계로 탐색·연계 지원 |
| 제공·이용 | 요청 목적·제공 제한 검토, 승인 범위·보유 기간 관리 |
| 품질·책임 | 최신성·정확성·연계성, 소관·활용 기관의 책임 |
| 개인정보 | 처리 근거와 보호 조치 확인 |

| AI 통제 영역 | 적용 내용 |
|---|---|
| 책임성 | AI 결과를 활용해도 최종 권한·책임 주체 명확화 |
| 개인정보 | 목적·처리 근거·최소 이용 범위·안전조치 점검 |
| 편향·투명성 | 데이터·모델의 편향 가능성과 설명·검토 경로 |
| 품질·감독 | 담당자 검토, 오류 정정·이의 제기 절차 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 부서별 정의·품질이 다른 데이터를 바로 결합 | 목적·메타데이터·품질 기준 합의, 출처·변환 이력 보존 |
| 공동활용 목적과 제공 범위 불일치 | 요청 목적·제공 제한·처리 근거를 먼저 확인 |
| AI 결과를 검토 없이 결정에 반영 | 담당자 검토·설명·정정 경로 명시, 시행 결과 평가 |

## Ⅵ. 제언

데이터 결합 전 목적과 품질 기준을 합의하고, AI 활용 결과는 담당자 검토와 사후 정정을 거쳐 반영

```text
목적·권한 확인 → 품질 기준 합의 → 연계(이력 보존) → 분석·AI → 담당자 검토 → 결정 → 결과 평가·정정
```

| 구분 | 부서별 개별 활용 | 제언: 합의된 공동활용 |
|---|---|---|
| 데이터 정합 | 정의 불일치 | 기준 합의 |
| 책임 | 모호 | 결정 주체 명확 |
