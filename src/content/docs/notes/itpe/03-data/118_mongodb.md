## 지식 로드맵 내 현재 위치

자료처리·데이터 → NoSQL → **MongoDB**

## 30초 인출

- 본질: MongoDB는 BSON 문서를 컬렉션 단위로 저장·조회하는 문서형 데이터베이스
- 메커니즘: 함께 읽고 바뀌는 값은 문서에 임베딩하고 독립적으로 변경되거나 커지는 관계는 참조로 두며, Primary의 변경을 oplog로 Secondary에 복제하고 규모가 커지면 샤드 키로 샤딩해 mongos가 질의를 라우팅
- 통찰: 임베딩과 참조 중 무엇이 유리한지는 접근 패턴과 변경 빈도가 정하므로 대표 질의를 부하 시험에 반영하고, 샤드 키가 없는 질의는 전체 샤드로 퍼지므로 필터와 키 접두부를 대조

<details>
<summary>핵심 용어</summary>

- **MongoDB** : BSON 문서를 저장하는 문서형 NoSQL 데이터베이스
- **BSON** : JSON을 확장한 이진 문서 형식
- **임베딩·참조** : 관련 데이터를 한 문서에 포함 / 다른 문서를 식별자로 가리킴
- **복제 세트(Replica Set)** : Primary와 Secondary로 구성한 복제 그룹
- **oplog** : Primary의 변경을 기록해 Secondary가 재생하는 로그
- **mongos·Config server** : 질의 라우터 / 샤딩 메타데이터 저장소
- **read·write concern** : 읽기 일관성과 쓰기 확인 수준 설정

</details>

## 2~4교시 25점 답안

## Ⅰ. MongoDB의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **MongoDB** 는 BSON 문서를 컬렉션 단위로 저장·조회하는 문서형 데이터베이스 |
| 목적 | 가변적인 데이터 구조를 문서 모델로 표현하고 조회에 맞게 저장·확장 |

## Ⅱ. 특징

| 특징 | 설계상 의미 |
|---|---|
| BSON 문서 | 중첩 필드와 배열로 업무 단위 데이터 표현 |
| 접근 패턴 중심 | 함께 읽고 갱신하는 범위로 임베딩·참조 결정 |
| 분산 구성 | 복제 세트(가용성)와 샤딩(규모)의 역할 구분 |

단일 문서 쓰기의 원자성을 활용하되 임베딩이 항상 빠르다거나 참조가 항상 유리하다고 단정하지 않고 접근 패턴과 변경 빈도로 결정.

## Ⅲ. 문서 저장과 샤드 라우팅

```text
조회·갱신 패턴 → 함께 읽고 바뀌는 값 = 임베딩 / 독립 변경·큰 관계 = 참조
    ↓ BSON 문서·컬렉션 저장
Primary ─ oplog → Secondary 복제
    ↓ 규모 증가 시 샤드 키 결정
클라이언트 → mongos ─ 메타데이터 조회 → 대상 샤드(복제 세트)
```

```text
질의에 샤드 키(복합 키 접두부) 있음 → 대상 샤드만 조회
질의에 샤드 키 없음              → 여러 샤드 조회·결과 취합
```

## Ⅳ. 임베딩·참조와 구성요소

| 선택 | 적합한 조건 | 고려사항 |
|---|---|---|
| 임베딩 | 함께 조회되는 종속 데이터 | 배열 증가·문서 크기 상한 관리 |
| 참조 | 독립 조회·갱신, 관계가 커지는 데이터 | 추가 조회·`$lookup` 비용 |

| 구성요소 | 역할 |
|---|---|
| 복제 세트 | Primary 변경을 Secondary가 oplog로 비동기 복제, 일관성·쓰기 확인은 read/write concern으로 선택 |
| 샤드 | 데이터 일부를 보유, 각 샤드는 복제 세트로 운영 |
| mongos | 샤드 키·메타데이터로 질의 라우팅 |
| Config server | 청크 범위 등 샤딩 메타데이터 보관 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 초기 접근 패턴과 실제가 달라 문서 재설계·핫스팟 발생 | 대표 질의·변경을 부하 시험에 반영, 샤드 분포·타깃 질의 비율 확인 |
| 임베딩 배열이 계속 커져 문서 크기·갱신 부담 증가 | 성장·독립 갱신 여부를 측정해 참조로 분리 |
| 샤드 키 없는 질의가 전체 샤드로 확산 | 대표 필터와 키 접두부 대조, 타깃 질의 비율 관측 |

## Ⅵ. 제언

접근 패턴으로 문서 구조를 정하고, 샤드 키는 대표 질의의 필터에 포함되는 필드로 선택

```text
접근 패턴 분석 → 임베딩·참조 결정 → 복제 세트 → 샤드 키 선정 → 타깃 질의 비율 모니터링
```

| 구분 | 관계형 방식 그대로 이식 | 제언: 접근 패턴 기반 모델링 |
|---|---|---|
| 조회 | 조인성 조회 증가 | 문서 단위 조회 |
| 샤딩 | 임의 키 | 필터 기반 키 |
