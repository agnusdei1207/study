## 연관 키워드

- CRUD, 업무기능, 데이터 엔터티, 생성·조회·수정·삭제, 추적성

## Ⅰ. CRUD 매트릭스의 개요

- 핵심 요약 : CRUD 매트릭스는 업무기능과 데이터 엔터티의 생성·조회·수정·삭제 책임 관계를 교차표로 나타낸 분석도구.
- 개념 : CRUD 매트릭스는 업무기능과 데이터 엔터티의 생성·조회·수정·삭제 책임 관계를 교차표로 나타낸 분석도구.
- 배경 및 필요성 : 기능과 데이터 소유의 누락·중복·불명확한 책임을 설계 단계에서 발견할 필요.
- 주요 목적 : 업무기능-데이터 흐름·책임·접근 패턴을 가시화.

## Ⅱ. CRUD 매트릭스의 특징 및 장점

- 핵심 요약 : 행은 기능, 열은 엔터티: 주체별 데이터 처리 식별 → 업무-데이터 추적; C/R/U/D 표시: 생성·조회·수정·삭제 흐름 → 누락·중복 발견; 범위 검토: CRUD 권한·수명주기 → 보안·통합 설계 지원.

1. 행은 기능, 열은 엔터티: 주체별 데이터 처리 식별 → 업무-데이터 추적
2. C/R/U/D 표시: 생성·조회·수정·삭제 흐름 → 누락·중복 발견
3. 범위 검토: CRUD 권한·수명주기 → 보안·통합 설계 지원

## Ⅲ. CRUD 매트릭스의 구조 (흐름)

- 핵심 요약 : 업무기능·엔터티 목록 확정 → 기능별 C/R/U/D 표시 → 미사용 엔터티·기능 탐지 → 기능간 생성·수정·조회 경로 추적 → 권한·통합·테스트 설계 반영.

```text
업무기능·엔터티 목록 확정
  ↓
기능별 C/R/U/D 표시
  ↓
미사용 엔터티·기능 탐지
  ↓
기능간 생성·수정·조회 경로 추적
  ↓
권한·통합·테스트 설계 반영
```

- 핵심 구성 : 업무기능(행) × 엔터티(열) → C/R/U/D 표시 → 공백·중복·소유불명 분석

```text
업무기능(행) × 엔터티(열) → C/R/U/D 표시 → 공백·중복·소유불명 분석
```

## Ⅳ. 비교: CRUD 매트릭스 / ERD

- 핵심 요약 : 활용 기준 — CRUD 매트릭스: 기능 누락·중복·권한·통합 점검; ERD: 데이터 구조·제약 설계.

| 비교 기준 | CRUD 매트릭스 | ERD |
| --- | --- | --- |
| 표현 초점 | 기능이 데이터를 생성·조회·수정·삭제하는가 | 개체·속성·관계·카디널리티 |
| 활용 | 기능 누락·중복·권한·통합 점검 | 데이터 구조·제약 설계 |

## Ⅴ. CRUD 매트릭스의 한계와 방안

- 핵심 요약 : 모호한 표기·과도한 복잡도 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 모호한 표기 | CRUD의 의미·트랜잭션 범위가 사람마다 다름 | 행렬 규칙·업무 단계·시스템 경계 명시 | 미해석 셀 |
| 과도한 복잡도 | 대규모 기능·엔터티에서 매트릭스가 비대 | 도메인·업무영역별 분할·추상화 | 검토 소요시간 |
| 변경 미반영 | 요구·API 변경과 행렬 불일치 | 요구·엔터티 변경관리와 버전 연결 | 최신성 |

## Ⅵ. CRUD 매트릭스의 제언

- 핵심 요약 : 업무분석가는 CRUD 매트릭스를 요구·화면·API·권한·테스트 추적성에 연결하고 무권한 U/D·주인 없는 데이터 엔터티를 검토.
- 실행 제안 : 업무분석가는 엔터티별 무소유·무수정·권한과다 셀을 도메인 담당자와 검토하고 API·테스트 추적성 연결.

## Ⅶ. CRUD 매트릭스의 결론

- 핵심 요약 : CRUD 매트릭스는 데이터 모델을 대신하지 않으며 업무기능과 데이터 생명주기의 책임관계를 검증하는 보조 모델.
- 시사점 : CRUD 결과를 API·권한·테스트 요구와 연결하면 데이터 책임 누락을 조기에 발견.
