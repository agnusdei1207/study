## 연관 키워드

**CRUD 매트릭스**, **업무 프로세스**, **데이터 엔티티**, **생성·조회·수정·삭제**, **추적성**, **영향도 분석**, **데이터 소유권**

## Ⅰ. 개요

- 핵심 요약 : **CRUD 매트릭스**는 업무 기능과 데이터 엔티티 간 생성·조회·수정·삭제 관계를 표로 나타내는 분석 도구다.
- 목적 : 요구 기능과 데이터 모델의 누락·중복을 찾아 시스템 간 데이터 책임과 영향 범위를 파악한다.
- 구성 : 행에는 업무 기능, 열에는 엔티티를 두고 각 교차점에 C·R·U·D를 표시한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **프로세스와 데이터의 추적 관계**를 한눈에 보여 분석·설계·테스트·변경관리를 지원한다.
- **완전성 점검** : 사용되지 않는 엔티티나 데이터 접근이 불분명한 기능을 발견한다.
- **책임 가시화** : 어떤 기능이 핵심 데이터를 생성·수정하는지 보여 데이터 소유권 논의에 도움을 준다.
- **변경 영향 분석** : 엔티티 변경 시 관련 프로세스와 프로그램을 찾는 기준이 된다.
- CRUD 표는 관계를 요약하지만 상세한 조건·순서·권한을 모두 표현하지 않는다.

## Ⅲ. CRUD 매트릭스 작성 흐름

- 핵심 요약 : **업무 기능과 엔티티 목록을 정리하고 교차 관계를 검토**한다.

```text
[업무 기능·시나리오 목록화]
            ▼
[데이터 엔티티 정의]
            ▼
[기능별 C·R·U·D 매핑]
            ▼
[누락·중복·소유권 검토]
            ▼
[요구사항·테스트·변경관리와 연계]
```

| 업무 기능 | 고객 | 주문 | 상품 | 결제 |
|---|---:|---:|---:|---:|
| 회원 등록 | C |  |  |  |
| 상품 조회 |  |  | R |  |
| 주문·결제 | R | C | R | C |
| 취소·환불 | R | U |  | U |

## Ⅳ. 활용 관점 비교

- 핵심 요약 : CRUD 매트릭스는 **요구사항·데이터 구조·운영 책임**을 이어주는 보조 산출물이다.

| 활용 단계 | 확인 내용 | 산출 효과 |
|---|---|---|
| 요구 분석 | 기능별 데이터 생성·사용 여부 | 요구 누락 확인 |
| 데이터 설계 | 엔티티 생성·수정 주체 | 모델·소유권 검토 |
| 테스트 | 기능별 데이터 동작 | 통합 시나리오 도출 |
| 변경관리 | 변경 엔티티와 영향 기능 | 회귀 범위 추적 |

- 모든 엔티티가 반드시 C와 R을 가져야 한다는 식의 고정 규칙은 도메인에 따라 맞지 않을 수 있다. 예를 들어 기준정보는 별도 관리 기능에서 생성될 수 있다.

## Ⅴ. 한계와 방안

- 핵심 요약 : **정적 문서의 노후화·복잡한 흐름 표현 한계·과도한 규칙화**를 관리한다.
- **현행화 지연** → 요구사항·모델·코드 변경 절차에 매트릭스 갱신 책임을 포함한다.
- **조건·순서 표현 부족** → 시퀀스 다이어그램, 상태 모델, 이벤트 흐름 등 보완 산출물을 함께 쓴다.
- **대규모 매트릭스 복잡성** → 도메인·업무 영역별로 분할하고 주요 엔티티와 변경 주체를 우선 검토한다.
- **자동 추출의 오판** → 코드 분석 결과를 설계 의도와 대조하고 수작업 승인 절차를 둔다.

```text
문서 노후화 → 변경 절차에 갱신 연결
흐름 표현 부족 → 보완 모델 병행      → 신뢰할 수 있는 추적성
자동 분석 오류 → 담당자 검토
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **CRUD 관계를 요구사항·데이터 사전·테스트와 연결**해 활용 가능한 관리 정보로 만든다.
- 엔티티별 생성·수정 권한과 기준 원천 시스템을 정해 중복 갱신을 줄인다.
- 저장소·모델링 도구를 연계해 변경 검토를 지원하되 자동 생성물을 검수 가능한 형태로 유지한다.
- 개인정보·감사 중요 데이터는 삭제 정책과 보존 요구를 별도로 표시한다.

## Ⅶ. 결론

- 핵심 요약 : CRUD 매트릭스는 **업무와 데이터의 관계를 추적하는 설계 도구**이며 다른 상세 모델과 함께 사용해야 한다.
- 답안에는 작성 축, 완전성·소유권 검토, 변경 영향 분석과 현행화 방안을 연결한다.
