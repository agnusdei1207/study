## 연관 키워드

- 군집분석(Cluster Analysis), 비지도 학습(Unsupervised Learning), 응집도(Cohesion), 분리도(Separation)
- 분할적(Partitioning)·계층적(Hierarchical)·밀도 기반(Density-Based)·모델 기반(Model-Based) 군집화
- 유클리디안 거리(Euclidean Distance), 코사인 유사도(Cosine Similarity), 실루엣 계수(Silhouette Coefficient), 덴드로그램(Dendrogram), 고차원의 저주(Curse of Dimensionality)

## Ⅰ. 군집분석의 개요

- 핵심 요약 : 레이블 없는 데이터에서 유사도 기반으로 집단을 형성하는 비지도 학습 기법 체계.
- 개념 : 개체 간 유사도와 거리를 기준으로 내부는 유사하고 상호는 상이한 집단으로 묶는 탐색적 분석 기법인 **군집분석** (Cluster Analysis)이며, 정답 레이블을 사용하지 않는 **비지도 학습** (Unsupervised Learning)에 속함.
- 배경 및 필요성 : 레이블 수집 비용이 크고, 고객 세분화·이상 탐지·문서 정리처럼 데이터 구조를 먼저 파악해야 하는 수요 확대.
- 주요 목적 : 군집 내 **응집도** (Cohesion, 같은 군집 개체 간의 유사성) 최대화와 군집 간 **분리도** (Separation, 다른 군집 간의 차이) 최대화.

## Ⅱ. 군집분석의 특징 및 장점

- 핵심 요약 : 사전 레이블 불필요, 4대 방법론과 데이터 유형별 거리 척도의 조합 유연성.

1. 레이블 불필요 : 데이터 분포 자체로 집단 형성 → 레이블링 비용 절감과 신규 패턴 발견.
2. 방법론 다양성 : 분할적·계층적·밀도 기반·모델 기반의 4대 군집화 → 데이터 형태별 선택 가능.
3. 거리 척도의 유연성 : 데이터 유형별 척도 선택 → 분석 신뢰도 향상.
   1. 연속형 수치 : **유클리디안 거리** (Euclidean Distance), 맨해튼 거리, 분산을 반영한 마할라노비스 거리.
   2. 범주형·이진형 : 자카드 유사도, 해밍 거리.
   3. 텍스트·임베딩 벡터 : **코사인 유사도** (Cosine Similarity)의 방향성 비교.
4. 후속 분석 기반 : 군집 소속을 분류·추천·이상 탐지의 파생 변수로 활용 → 분석 파이프라인의 전반부 역할.

## Ⅲ. 군집분석의 구조 (흐름)

- 핵심 요약 : 전처리 → 척도·방법론 선택 → 수행 → 평가 → 해석의 절차와 4대 방법론의 분류 구조.

```text
[ 군집 분석 절차 ]

변수 선정과 스케일링 (표준화)
   ↓
거리 척도·방법론 선택
   ↓
군집 수(K) 후보 탐색
   ↓
군집화 수행
   ↓
평가 지표 검증과 도메인 해석
```

```text
[ 4대 군집화 방법론 ]

분할적   : K-Means, K-Medoids
계층적   : 병합형, 덴드로그램
밀도 기반 : DBSCAN, OPTICS
모델 기반 : GMM (가우시안 혼합)
```

- 평가 지표 구성요소 :

| 평가 지표 | 측정 원리 | 판단 방향 |
| --- | --- | --- |
| **실루엣 계수** (Silhouette Coefficient) | 군집 내 거리와 최근접 타군집 거리의 상대 비교 | 1에 가까울수록 양호 |
| 데이비스-볼딘 지수 | 군집 간 거리 대비 군집 내 분산 비율 | 작을수록 양호 |
| 칼린스키-하라바츠 지수 | 군집 간·군집 내 분산의 비율 | 클수록 양호 |
| 엘보우 기법 | 군집 수별 제곱합 감소의 완만 구간 | 굴곡점을 후보 K로 채택 |

- 계층적 방법의 산출물인 **덴드로그램** (Dendrogram, 병합 과정을 계층 트리로 표현한 도해)은 군집 수 결정과 구조 파악의 시각적 근거.

## Ⅳ. 4대 군집화 방법론의 비교

- 핵심 요약 : 속도(분할적), 시각 탐색(계층적), 임의 형태(밀도 기반), 확률 해석(모델 기반)의 구분.

| 방법론 | 동작 원리 | 장점 | 한계 | 적합 상황 |
| --- | --- | --- | --- | --- |
| 분할적(Partitioning) | 중심 기준 거리의 반복 재할당 | 대용량 고속 처리 | 구형 군집 가정·K 사전 지정 | 균질한 대량 데이터 |
| 계층적(Hierarchical) | 개체에서 출발한 단계적 병합 | 덴드로그램 시각화·K 불필요 | 계산 부담·병합 취소 불가 | 소규모 탐색 분석 |
| 밀도 기반(Density-Based) | 고밀도 연결 영역의 확장 | 임의 형태·노이즈 분리 | 밀도 차가 큰 데이터 취약 | 공간·형태 다양 데이터 |
| 모델 기반(Model-Based) | 확률 분포 혼합 가정과 모수 추정 | 소프트 군집·타원형 표현 | 초기값 민감·분포 가정 필요 | 확률적 소속 해석 필요 |

- 선택 기준 : 규모·속도는 분할적, 형태 자유와 노이즈 처리는 밀도 기반, 확률적 소속은 모델 기반, 시각적 탐색은 계층적 방법 우선.

## Ⅴ. 군집분석의 한계와 방안

- 핵심 요약 : 판정의 주관성, 고차원 거리 왜곡, 이상치·비구형 형태를 다중 지표·차원 축소·방법론 전환으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 군집 수·형태 판정의 주관성 | 지표 판정의 모호성과 구형 구조 편향 | 다중 평가 지표의 교차 확인과 도메인 검증 병행 | 지표 간 판정 일치율 |
| **고차원의 저주** (Curse of Dimensionality) | 차원 증가로 거리가 균등화되어 경계 붕괴 | UMAP(Uniform Manifold Approximation and Projection)·t-SNE(t-distributed Stochastic Neighbor Embedding) 등 선행 차원 축소와 방향성 척도 적용 | 축소 후 실루엣 계수 |
| 이상치·비구형 군집 왜곡 | 중심 기반 방법의 군집 중심 편향 | 중앙값 기반 K-Medoids와 밀도 기반·스펙트럴 방법 전환 | 이상치 비율, 군집 크기 편차 |

## Ⅵ. 군집분석 활용에 대한 기술사적 제언

- 핵심 요약 : 전처리 표준화, 현업 공동 해석, 주기적 재검증의 3축 운영.
- 분석 조직 : 스케일링과 차원 축소를 전처리 표준으로 고정해 척도 왜곡 방지.
- 현업 부서 : 군집별 프로파일링 워크숍으로 집단을 실행 가능한 세그먼트로 정의.
- 운영 조직 : 데이터 분포 변화 감시와 주기적 재군집화로 결과의 유효 기간 관리.

## Ⅶ. 결론

- 핵심 요약 : 군집분석은 방법론·척도·평가 지표의 조합 설계가 품질을 결정하는 탐색 기법임.
- 통계적 분리와 업무 실행 가능성을 함께 충족하는 집단만이 의사결정의 세그먼트가 됨.
