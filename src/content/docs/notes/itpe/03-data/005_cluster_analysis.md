## 지식 로드맵 내 현재 위치

<div class="itpe-topic-path" aria-label="지식 경로"><span>데이터 분석</span><span>비지도학습</span><strong>군집분석</strong></div>

## 큰 그림과 30초 인출

```text
[라벨 없는 데이터] → 전처리·척도화 → 거리·유사도 정의 → 군집화 → 타당성·해석
                                           │
                 ┌─────────────┬───────────┼───────────┐
                 ▼             ▼           ▼           ▼
               계층적        분할기반     밀도기반      신경망
             Dendrogram      K-Means      DBSCAN       SOM
```

- 본질: **정답 라벨 없이 객체 간 유사성을 기준으로 군집 내 동질성과 군집 간 이질성을 확보하는 비지도 학습**
- 판단축: 데이터 형태·거리척도·군집 모양·이상치·군집 수·해석 가능성
- 암기: `전-척-군-평-해` = 전처리 → 척도 → 군집 → 평가 → 해석

## 예상문제

> 군집분석의 개념과 유형, 수행절차를 설명하고 K-Means·DBSCAN·계층적 군집·SOM을 비교하여 적용 고려사항을 논하시오. (25점)

## Ⅰ. 라벨 없이 숨은 구조를 찾는 군집분석 개요

- 정의: 군집분석은 관측치 간 거리·유사도·밀도를 이용하여 유사한 객체는 같은 집단에, 상이한 객체는 다른 집단에 배치하는 비지도 학습기법
- 목적: 고객 세분화, 문서·이미지 그룹화, 패턴 탐색, 이상탐지의 기준집단 도출
- 필요성: 사전 클래스가 없거나 기존 분류가 실제 데이터 구조를 설명하지 못할 때 탐색적 구조 발견 필요

#### 한줄 요약

- 군집은 정답을 맞히는 분류가 아니라 데이터에 내재한 그룹 가설을 만들고 검증하는 과정임

## Ⅱ. 거리와 데이터 표현에 민감한 군집분석 특징

| 특징 | 의미 | 통제사항 |
|---|---|---|
| 비지도성 | 정답 라벨 없이 패턴 탐색 | 업무 해석과 외부 검증 필요 |
| 척도 의존성 | 단위가 큰 변수가 거리를 지배 | 표준화·정규화 |
| 형상 의존성 | 알고리즘마다 가정하는 군집 모양이 다름 | 데이터 분포에 맞는 알고리즘 |
| 초기값 민감성 | 초기 중심에 따라 국소해 가능 | 다중 초기화·안정성 검증 |
| 탐색적 성격 | 유일한 정답 군집이 없을 수 있음 | 복수 지표와 업무 유용성 평가 |

## Ⅲ. 구조 가정에 따른 군집분석 유형

| 유형 | 원리 | 대표기법 | 적합 데이터 |
|---|---|---|---|
| 계층적 | 가까운 군집을 병합하거나 큰 군집을 분할 | Agglomerative, Ward | 계층 관계·소규모 데이터 |
| 분할기반 | 목적함수를 최소화하도록 k개 군집 반복 배정 | K-Means, K-Medoids | 구형·유사 크기 군집 |
| 밀도기반 | 고밀도 연결 영역을 군집으로 확장 | DBSCAN, OPTICS | 임의 형상·잡음 포함 데이터 |
| 확률모형 | 혼합분포의 소속 확률 추정 | GMM | 중첩·타원형 군집 |
| 신경망 | 경쟁학습으로 위상을 보존한 격자 매핑 | SOM | 고차원 시각화·탐색 |

```text
SOM: 입력벡터 → BMU(승자 뉴런) 선택 → 승자·이웃 가중치 갱신 → 2차원 위상지도
```

## Ⅳ. 재현 가능한 군집분석 수행절차

```text
① 목적·분석단위 정의 → ② 결측·이상치·척도화 → ③ 거리·기법·모수 선택
        → ④ 학습·다중실행 → ⑤ 내부·외부·안정성 평가 → ⑥ 프로파일링·활용
```

| 단계 | 핵심 질문 | 산출물 |
|---|---|---|
| 목적 | 군집이 어떤 의사결정을 지원하는가 | 활용 시나리오 |
| 표현 | 어떤 변수·변환·거리가 의미 있는가 | Feature·척도 정의 |
| 모델 | 군집 수·밀도·연결 기준은 무엇인가 | 후보 모델 |
| 평가 | 응집·분리와 재표본 안정성이 충분한가 | Silhouette·안정성 결과 |
| 해석 | 군집별 특성과 조치가 구분되는가 | 군집 프로파일·운영규칙 |

## Ⅴ. K-Means·DBSCAN·계층적 군집·SOM 비교

| 구분 | K-Means | DBSCAN | 계층적 | SOM |
|---|---|---|---|---|
| 핵심원리 | 중심과 제곱거리 최소화 | 밀도 연결 | 거리 기반 병합·분할 | 경쟁학습·위상보존 |
| 군집 수 | k 사전 지정 | 직접 지정 불필요 | 절단 수준으로 결정 | 격자·후속 군집화 |
| 군집 형상 | 구형에 적합 | 임의 형상 가능 | 연결법에 의존 | 2차원 위상 표현 |
| 이상치 | 민감 | 잡음으로 분리 | 거리 왜곡 가능 | 학습·스케일에 민감 |
| 강점 | 단순·확장성 | 잡음·비선형 형상 | 덴드로그램 해석 | 고차원 시각화 |
| 한계 | 초기값·k·스케일 | 밀도 차이·모수 민감 | 계산량·연결법 | 결과 해석·모수 설정 |

## Ⅵ. 군집의 통계적 타당성과 업무 유용성 확보

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 군집이 특정 변수에 종속 | 단위·분산 차이 | 업무 기반 변수선정, 표준화, 거리 민감도 분석 | 거리 왜곡 감소 |
| 군집 수 선택 불안정 | Elbow 한 지표에 의존 | Silhouette·Gap·안정성·업무 유용성 교차검증 | 설명 가능한 k 선정 |
| 고차원에서 거리 구분 약화 | 차원의 저주·불필요 변수 | 변수선택·PCA/표현학습 후 원공간 해석 | 분리도 개선 |
| 이상치를 군집으로 오인 | 오류·희귀집단 혼재 | 원인 확인 후 강건기법·DBSCAN·별도 분석 | 정보손실 방지 |
| 운영 후 군집 의미 변화 | 데이터 분포 변화 | 주기 재학습·군집 매칭·Drift 감시 | 세그먼트 지속성 확보 |

## Ⅶ. 군집 품질보다 의사결정 품질을 검증하는 결론

- **[내부지표-안정성-업무효과의 3중 검증]**: Silhouette가 높아도 군집별 실행전략이 같으면 실무적 가치가 없음
- 나라면: 복수 알고리즘과 재표본으로 안정성을 검증한 뒤 군집별 행동·성과 차이를 시험하고, 운영 중 군집 이동과 분포변화를 감시

#### 한줄 요약

- 좋은 군집은 수학적으로 잘 분리될 뿐 아니라 반복 재현되고 서로 다른 의사결정을 가능하게 함

## 1교시 10점 답안 발췌

```text
라벨 없음 → 전처리·척도화 → 거리/유사도 → 군집화 → 타당성·해석
```

| 기법 | 핵심 |
|---|---|
| K-Means | 중심 기반, k 필요, 구형 군집 |
| DBSCAN | 밀도 기반, 잡음 분리, 임의 형상 |
| 계층적 | 덴드로그램으로 병합관계 표현 |
| SOM | 경쟁학습으로 고차원 위상 2차원 매핑 |

- 차별화: 내부지표만이 아니라 재표본 안정성과 군집별 업무효과를 함께 검증
