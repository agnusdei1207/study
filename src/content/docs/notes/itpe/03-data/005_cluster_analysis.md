## 30초 인출

- 본질: 군집분석은 정답 레이블 없이 유사한 데이터끼리 묶어 집단 구조를 찾아내는 비지도 학습 기법
- 메커니즘: 관측치 사이의 거리·유사도를 기준으로 군집 중심을 반복해서 갱신하거나 계층적으로 병합해 군집을 만들고 실루엣 계수 등으로 품질을 평가
- 통찰: 군집 결과가 변수 단위와 거리 정의에 좌우되므로 변수를 표준화하고 군집 수와 방식을 평가 지표로 비교해 선택

<details>
<summary>핵심 용어</summary>

- **군집분석(Clustering)** : 정답 없이 유사한 데이터끼리 묶는 비지도 학습
- **거리·유사도** : 두 관측치가 얼마나 가깝거나 비슷한지 나타내는 기준
- **K-means** : 지정한 k개 중심과의 거리로 관측치를 배정하고 중심을 반복 갱신하는 분할 방식
- **계층적 군집** : 군집을 합치거나 나누는 관계를 트리(덴드로그램)로 나타내는 방식
- **DBSCAN** : 밀집한 점들을 군집으로 묶고 외딴 점을 잡음으로 분류하는 밀도 기반 방식
- **SOM(Self-Organizing Map)** : 입력 데이터의 위상 관계를 보존하며 격자 위에 군집을 배열하는 신경망 기반 군집 방법
- **실루엣 계수** : 군집 내 응집도와 군집 간 분리도를 −1~1 값으로 나타낸 평가 지표

## 2~4교시 25점 답안

## Ⅰ. 군집분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **군집분석** 은 정답 없이 유사한 데이터끼리 묶어 집단 구조를 찾는 비지도 학습 기법 |
| 목적 | 데이터의 숨은 집단 발견과 세분화 |

## Ⅱ. 분류 분석과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 비지도 | 정답 레이블 없음 |
| 거리 기반 | 유사도 정의가 결과를 좌우 |
| 군집 수 미지 | 군집 수 선택 필요 |

## Ⅲ. K-means의 절차

```text
군집 수 k 지정, 초기 중심 선택
        ↓
각 관측치를 가장 가까운 중심에 배정
        ↓
군집별 평균으로 중심 갱신
        ↓
중심이 변하지 않을 때까지 반복
```

## Ⅳ. 군집 방식의 비교와 SOM

### 군집 방식의 비교

| 구분 | K-means | 계층적 | DBSCAN |
|---|---|---|---|
| 방식 | 중심 기반 분할 | 병합·분할의 계층 | 밀도 기반 |
| 군집 수 | 사전 지정 | 트리 절단으로 결정 | 자동 결정 |
| 군집 모양 | 구형 위주 | 다양 | 임의 모양, 잡음 분리 |
| 대규모 데이터 | 유리 | 불리 | 밀도 계산 비용 |

### SOM의 구성과 신경망 분석과의 차이

| 구분 | 내용 |
|---|---|
| 구성요소 | 입력층, 격자 형태의 경쟁층(출력 뉴런), 뉴런별 가중치 벡터, 이웃 함수 |
| 학습 | 입력과 가장 가까운 뉴런(승자)과 그 이웃의 가중치를 입력 쪽으로 이동 |
| 신경망(지도 학습)과의 차이 | 정답 없이 경쟁 학습으로 군집을 형성하고 위상 관계를 보존, 오차 역전파 없음 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 변수 단위 차이로 특정 변수가 거리를 지배 | 변수 표준화 |
| 군집 수 선택의 어려움 | 실루엣 계수 등 평가 지표 비교 |
| 초기 중심에 따라 결과 변동 | 여러 번 실행해 결과가 안정적인 것을 선택 |

## Ⅵ. 제언

변수를 표준화하고 군집 수와 방식을 평가 지표로 비교해 선택

```text
변수 표준화 → 후보(k·방식) 군집화 → 실루엣 계수 비교 → 해석 가능한 결과 선택
```

| 구분 | 원자료로 단일 실행 | 제언: 표준화·비교 |
|---|---|---|
| 변수 영향 | 단위가 큰 변수가 지배 | 균등 |
| 결과 신뢰 | 낮음 | 지표로 확인 |
