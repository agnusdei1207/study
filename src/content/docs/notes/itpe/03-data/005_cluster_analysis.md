## 지식 로드맵 내 현재 위치

지식 위치: 자료처리·데이터 → 비지도학습 → **군집분석**

## 30초 인출

- 본질: **군집분석은** 정답 레이블 없이 데이터 사이의 유사성에 따라 비슷한 대상을 묶어 구조를 찾는 분석 방법
- 메커니즘: 분석 목적·변수 선택 → 척도·유사도 정의 → 군집 방법 적용 → 군집의 분리·안정성·업무적 의미 검증
- 통찰: 단일 알고리즘의 거리 척도에만 의존하지 않고 데이터의 기하학적 분포와 실루엣 평가 지수를 결합하여 비즈니스 해석력이 담보된 군집 구조 도출 필요

<details>
<summary>핵심 용어</summary>

- **군집분석(Clustering)** : 정답 레이블 없이 유사한 데이터끼리 묶어 집단 구조를 찾는 비지도학습 방법
- **거리·유사도** : 두 대상이 얼마나 가깝거나 비슷한지 나타내는 기준
- **K-means** : 지정한 k개 중심과의 거리로 관측치를 반복 배정하는 분할 방식
- **계층적 군집** : 군집을 합치거나 나누는 관계를 계층 구조로 나타내는 방식
- **DBSCAN(Density-Based Spatial Clustering of Applications with Noise)** : 밀집한 점을 군집으로 찾고 저밀도 점을 잡음으로 구분하는 방식
- **GMM(Gaussian Mixture Model)** : 여러 확률분포의 혼합으로 데이터를 설명하고 군집 소속 확률을 추정하는 모델
- **실루엣 계수(Silhouette Coefficient)** : 군집 안의 가까움과 다른 군집과의 떨어짐을 함께 보는 내부 평가 지표
- **표준화** : 변수의 크기·단위 차이가 거리 계산을 지배하지 않도록 척도를 조정하는 전처리

## 2~4교시 25점 답안

## Ⅰ. 군집분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **군집분석은** 정답 레이블 없이 데이터 사이의 유사성에 따라 비슷한 대상을 묶어 구조를 찾는 분석 방법 |
| 목적 | 데이터의 집단 구조 발견과 대상별 특성 파악 |

## Ⅱ. 군집분석의 특징

| 특징 | 의미 |
|---|---|
| 비지도 탐색 | 정답 레이블 없이 유사성으로 집단 구조 발견 |
| 척도 민감성 | 변수 단위·거리 정의가 군집 결과에 영향 |
| 결과 해석 필요 | 분리도뿐 아니라 표본 안정성·업무 활용성 확인 |

## Ⅲ. 데이터 준비와 군집 수행 체계

```text
분석 변수의 단위 차이 → 거리 계산의 특정 변수 쏠림
                         ↓ 척도 조정
대상 간 거리·유사도 정의 → 군집 방법에 입력
                         ↓
군집 분리도와 표본 변화에 따른 안정성 확인
```

### 군집 수행 절차

```text
분석 목적·변수 선정
    ↓ 척도 조정·거리 선택
군집 방법·매개변수 선택
    ↓ 분리도·안정성 평가
군집 특성 해석·활용
```

## Ⅳ. 주요 군집 방법과 평가 기준 비교

| 확인할 것 | 이유 |
|---|---|
| 분석 목적·변수 | 관련 없는 변수로 묶이면 군집 해석이 흐려짐 |
| 수치·범주형 자료 | 자료형에 맞는 거리·유사도 선택 필요 |
| 변수 단위·분포 | 거리 기반 방법에서는 큰 척도의 변수가 지배할 수 있음 |
| 이상치 | 중심·밀도 판단에 영향을 줄 수 있음 |

| 방법 | 구조·작동 | 적합한 상황 | 한계 |
|---|---|---|---|
| **K-means** | k개 중심과 가까운 점을 반복 배정 | 비교적 둥근 분할 | k 지정·이상치 민감 |
| 계층적 군집 | 거리·연결 기준에 따라 군집 결합·분할 | 단계적 관계 탐색 | 규모·연결 기준 영향 |
| **DBSCAN** | 밀집 영역을 연결하고 저밀도 점 구분 | 비정형 군집·잡음 | 밀도 차이가 큰 데이터 |
| **GMM** | 혼합 확률분포로 소속 확률 추정 | 군집 중첩의 표현 | 분포 가정과 성분 수 |

| 선택 항목 | 검토할 것 |
|---|---|
| 군집 수 k | 여러 k의 분리·안정성·업무적 해석 비교 |
| 거리·밀도 매개변수 | 변수 척도와 관측치 밀도의 영향 |
| 초기값·표본 | 실행·표본 변화에 따른 결과 변동 |

**결과 평가**

| 관점 | 확인할 내용 |
|---|---|
| 내부 평가 | 실루엣 계수, 군집 내 거리와 군집 간 분리 |
| 안정성 | 표본·초기값·기간을 바꿔도 유사한 구조인지 |
| 해석 가능성 | 군집별 대표 특성이 구별되고 업무 목적에 쓰이는지 |

높은 내부 점수만으로 의미 있는 세분화가 보장되지는 않음. 군집은 정답 레이블을 예측한 결과가 아니라 분석 목적에 따른 탐색 결과.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 단위 차이로 거리 왜곡 | 변수 의미를 확인하고 필요한 척도 조정 |
| k나 매개변수 하나에 결과 의존 | 대안 설정·표본에서 안정성 비교 |
| 수치상 분리만 좋고 업무 해석 불가 | 군집 특성·활용 사례와 함께 판정 |

## Ⅵ. 제언

데이터 특성에 부합하는 거리 척도와 군집화 기법(분할/계층/밀도)을 선정하고 실루엣 분석을 통해 최적 군집 수 $K$를 객관적으로 검증하는 프로세스 수립.

### 군집분석 모델링 및 타당성 평가 절차

```text
[데이터 정규화/스케일링] ──► [거리 척도 선정(유클리드/맨해튼/코사인)]
                                       │
                                       ▼
[군집 기법 적용] ◄── K-Means / DBSCAN / 계층적 군집화
       │
       ▼
[타당성 검증: 엘보우 차트 + 실루엣 계수] ──► [도메인 페르소나 매핑]
```

### 선택 근거: 제언: 복합 군집화 및 타당성 검증

| 구분 | K-Means 단독 적용 | 제언: 복합 군집화 및 타당성 검증 |
|---|---|---|
| 군집 형태 한계 | 구형(Spherical) 군집만 탐색 | 밀도 기반(DBSCAN) 결합으로 임의 형태 수용 |
| 최적 군집 수 | 주관적 $K$ 설정 위험 | 엘보우 기법과 실루엣 계수 정량 결합 |
| 이상치 영향 | 이상치에 매우 민감 | 노이즈 격리 및 정규화 사전 처리 적용 |
