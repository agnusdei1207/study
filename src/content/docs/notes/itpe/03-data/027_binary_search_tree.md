## 연관 키워드

- 이진 탐색 트리(BST, Binary Search Tree), 정렬 속성, 중위 순회(In-order Traversal)
- 자가 균형(Self-Balancing), AVL 트리, Red-Black 트리, 회전(Rotation)
- B-Tree / B+Tree, 시간 복잡도 $O(\log n)$, 편향(Skewed) 트리

## Ⅰ. 이진 탐색 트리의 개요

- 핵심 요약 : 정렬 속성 기반으로 탐색·삽입·삭제를 로그 시간에 수행하는 계층형 자료구조.
- 개념 : 이진 탐색 트리(BST, Binary Search Tree)는 모든 노드가 최대 2개의 자식 노드를 가지는 이진 트리(Binary Tree) 구조에서, 모든 노드 $X$에 대해 왼쪽 서브트리의 모든 키값은 $X$보다 작고 오른쪽 서브트리의 모든 키값은 $X$보다 크다는 정렬 속성을 만족하는 계층형 자료구조.
- 배경 및 필요성 : 정렬된 배열의 빠른 탐색 속도($O(\log n)$)와 연결 리스트의 빠른 삽입·삭제 장점의 결합 요구.
- 주요 목적 : 동적 집합에서 탐색, 삽입, 삭제 연산 효율의 동시 확보.

## Ⅱ. 이진 탐색 트리의 특징

- 핵심 요약 : 정렬 속성·중위 순회·균형 의존적 시간 복잡도가 핵심 속성.

1. 중위 순회(In-order Traversal, Left → Root → Right) 수행 시 전체 키값의 오름차순 획득.
2. 균형 상태(Balanced)에서 트리 높이 $h = \lfloor \log_2 n \rfloor$ 유지 시 탐색·삽입·삭제 모두 $O(\log n)$ 보장.
3. 경사 상태(Skewed)에서 정렬 데이터 순차 삽입 시 연결 리스트 형태로의 $O(n)$ 성능 퇴화.
4. 노드 삭제 시 자식 수에 따른 3가지 케이스 분기.
5. 자가 균형(Self-Balancing) 구조 도입 시 회전(Rotation) 기반 $O(\log n)$ 높이 유지.

## Ⅲ. 이진 탐색 트리의 구조 (흐름)

- 핵심 요약 : 정렬 속성 기반 탐색 흐름과 자식 수별 삭제 3대 케이스 분기.

```text
[ BST 정렬 속성 및 탐색 흐름 ]
        [50]
       /    \
    [30]    [70]      탐색 키 40 : 50 → (40 < 50, 왼쪽) → 30 → (40 > 30, 오른쪽) → 40
    /  \    /  \
 [20] [40] [60] [80]
  (왼쪽 서브트리 < 노드 < 오른쪽 서브트리)
```

```text
[ BST 노드 삭제 3대 케이스 ]
Case 1: 자식 없는 리프 노드  ---> 부모 포인터의 NULL 설정 후 메모리 해제
Case 2: 자식 1개인 노드      ---> 삭제 노드의 자식을 부모 노드에 직접 연결
Case 3: 자식 2개인 노드      ---> 오른쪽 서브트리 최소값(Successor) 또는
                                왼쪽 서브트리 최대값(Predecessor)으로 대체
```

```text
[ Case 3: 자식이 2개인 노드 삭제 예시 ]
       [50]                     [50]
      /    \                   /    \
   [30]    [70]   ===>      [40]    [70]   (Successor인 40으로 대체 후
   /  \    /  \             /       /  \    원래 40 노드 삭제)
 [20] [40] [60] [80]      [20]     [60] [80]
```

- 중위 순회와 정렬 속성 : Left → Root → Right 순회 결과의 오름차순 키값 획득.
- 삭제 케이스 분기 : 리프 노드, 자식 1개 노드, 자식 2개 노드의 3대 케이스.

## Ⅳ. 자가 균형 BST 알고리즘의 비교

- 핵심 요약 : 균형 전략과 읽기·쓰기 성능의 상충에 따른 알고리즘 선택.

| 알고리즘 | 균형 조건 및 특성 | 장점 | 단점 및 실무 적용 |
| :--- | :--- | :--- | :--- |
| AVL 트리 | 모든 노드에서 좌우 서브트리의 높이 차이(Balance Factor) $\le 1$ 유지 | 탐색 속도 최고 수준(완전한 균형 보장) | 삽입·삭제 시 빈번한 회전으로 쓰기 비용 증가 → 읽기 위주 룩업 테이블 적합 |
| Red-Black 트리 | 5가지 규칙(Root는 Black, No Double Red, Black-Height 동일 등) 유지 | 회전 최대 2~3회 제한, 삽입·삭제 성능 우수 | AVL 대비 높이 증가로 탐색 미세 저하 → C++ `std::map`, Java `TreeMap` 표준 |
| Splay 트리 | 최근 접근 노드의 회전 기반 루트(Root) 이동(Splaying) | 자주 참조 데이터의 접근 속도 극대화(Locality) | 최악 시간 복잡도 $O(n)$ 발생 가능, 트리 형상의 동적 변동 |

## Ⅴ. 이진 탐색 트리의 장점과 한계

- 핵심 요약 : 로그 시간 동적 연산의 장점과 편향 퇴화·디스크·동시성 한계.
- 장점
  1. 균형 유지 시 탐색·삽입·삭제의 $O(\log n)$ 보장.
  2. 중위 순회 기반 정렬 데이터 조회.
  3. 배열 대비 유연한 동적 크기 변경.
- 한계점 1 : 편향(Degeneracy) 퇴화
  - 한계점 : 정렬 데이터 순차 삽입 시 연결 리스트 형태의 $O(n)$ 퇴화.
  - 해결 방안 : 삽입·삭제 시 균형 계수 측정, 단일 회전(LL, RR) 및 이중 회전(LR, RL) 수행으로 트리 높이 $O(\log n)$ 유지.
- 한계점 2 : 디스크 기반 저장소 비효율
  - 한계점 : 메모리 기반 설계의 디스크 I/O 개입 환경 적용 시 블록 접근 비용 과다.
  - 해결 방안 : 블록(Page) 크기에 맞추어 하나의 노드가 수백 개 자식을 갖는 다원 탐색 트리 B-Tree / B+Tree 확장.
- 한계점 3 : 동시성 환경의 락 경합
  - 한계점 : 멀티스레드 노드 갱신 시 락 경합 발생.
  - 해결 방안 : 락-프리(Lock-Free) Skip List 자료구조 대안 검토.

## Ⅵ. 이진 탐색 트리에 대한 기술사적 제언

- 핵심 요약 : 저장 매체·동시성 환경에 따른 자료구조 선택.
- 메모리 기반 시스템 : 캐시 친화적 Red-Black Tree 등 자가 균형 BST 적용.
- 디스크 기반 데이터베이스 인덱스 : 블록 I/O 최소화를 위한 B-Tree / B+Tree 확장 구조 채택.
- 멀티스레드 환경 : 락-프리(Lock-Free) Skip List 등 락 경합 완화 자료구조 검토.

## Ⅶ. 결론

- 핵심 요약 : BST는 정렬 속성 기반 동적 탐색의 기초, 균형 관리와 저장 매체 특성 반영이 관건.
- 요약 : 정렬 속성·중위 순회·3케이스 삭제·회전 기반 균형 유지의 알고리즘 체계.
- 시사점 : 실무 인덱스 구현은 B-Tree·Skip List 등 환경 적합 변형으로의 확장이 표준.
