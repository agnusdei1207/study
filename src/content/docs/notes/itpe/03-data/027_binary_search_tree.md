## 지식 로드맵 내 현재 위치

자료처리·데이터 → 자료구조·탐색 → **이진 탐색 트리**

## 30초 인출

- 본질: 이진 탐색 트리는 모든 노드에서 왼쪽 서브트리의 키가 노드 키보다 작고 오른쪽 서브트리의 키가 크도록 유지하는 이진 트리
- 메커니즘: 루트부터 키를 비교해 왼쪽 또는 오른쪽으로 내려가며 탐색·삽입·삭제하고, 중위 순회하면 키가 오름차순으로 나옴
- 통찰: 비용이 트리 높이에 비례하므로 정렬된 키가 연속 입력되면 편향 트리가 되어 O(N)으로 퇴보하며, 자가 균형 트리로 높이를 O(log N)에 묶어야 함

<details>
<summary>핵심 용어</summary>

- **트리(Tree)** : 하나의 루트에서 간선으로 노드를 계층적으로 연결한 순환 없는 자료구조
- **이진 탐색 트리(Binary Search Tree)** : 모든 노드에서 왼쪽 서브트리 키 < 노드 키 < 오른쪽 서브트리 키인 이진 트리
- **중위 순회(In-order Traversal)** : 왼쪽 서브트리 → 루트 → 오른쪽 서브트리 순의 순회
- **편향 트리(Skewed Tree)** : 한쪽 방향으로만 노드가 이어져 연결 리스트가 된 트리
- **In-order Successor** : 삭제 대상 노드의 오른쪽 서브트리에서 가장 작은 키를 가진 노드
- **자가 균형 트리(Self-balancing Tree)** : 삽입·삭제마다 회전으로 높이 차를 제한하는 트리(AVL·Red-Black)
- **트라이(Trie)** : 키를 문자·비트 단위 경로로 저장해 접두어 일치로 탐색하는 트리
- **최장 프리픽스 매칭(Longest Prefix Match, LPM)** : 라우팅 테이블에서 목적지 주소와 가장 길게 일치하는 프리픽스를 선택하는 규칙

</details>

## 2~4교시 25점 답안

## Ⅰ. 이진 탐색 트리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **이진 탐색 트리** 는 모든 노드에서 왼쪽 서브트리의 키 < 노드 키 < 오른쪽 서브트리의 키를 유지하는 이진 트리 |
| 목적 | 순차 탐색 O(N)을 키 비교 분기로 줄여 O(log N)에 탐색·삽입·삭제 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 순서 불변식 | 부모-자식 비교만이 아니라 좌우 서브트리 전체에 대소 관계가 재귀적으로 성립 |
| 높이 의존 성능 | 비용이 높이 h에 비례하므로 균형이면 O(log N), 편향이면 O(N) |
| 정렬 출력 | 중위 순회 시 오름차순 키 출력 |

## Ⅲ. 구조와 연산

### 노드 배치

```text
            [ 45 ]
           /      \
       [ 22 ]    [ 68 ]
       /    \    /    \
   [ 11 ] [ 35 ][ 59 ] [ 77 ]
```

### 삽입·삭제

```text
삽입: 루트에서 키 비교 → 작으면 왼쪽, 크면 오른쪽 → 빈 위치에 새 노드 연결
삭제(자식 2개): 오른쪽 서브트리의 최소 키(In-order Successor) 탐색
              → 삭제 위치에 그 키를 복사 → Successor 노드를 제거
```

| 연산 | 평균 | 최악 | 좌우하는 요소 |
|---|---|---|---|
| 탐색·삽입·삭제 | O(log N) | O(N) | 트리 높이 |

## Ⅳ. 트리 유형과 라우팅 테이블 탐색과의 상관관계

| 유형 | 구조 조건 |
|---|---|
| 정 이진 트리(Full) | 모든 노드가 자식 0개 또는 2개 |
| 포화 이진 트리(Perfect) | 모든 내부 노드가 자식 2개이고 리프가 같은 깊이 |
| 완전 이진 트리(Complete) | 마지막 레벨을 제외하고 채워지며 마지막 레벨은 왼쪽부터 채움 |
| 편향 트리(Skewed) | 한 방향으로만 이어진 형태 |

| 비교축 | 이진 탐색 트리 | 라우팅 테이블 탐색(트라이 기반) |
|---|---|---|
| 공통 원리 | 비교마다 탐색 후보를 좁히는 계층적 분기 | 주소 비트를 따라 내려가며 후보를 좁히는 계층적 분기 |
| 판정 방식 | 키 전체의 대소 비교 | 주소 앞쪽 비트부터 일치, 최장 프리픽스 매칭 우선 |
| 성능 제어 | 자가 균형 트리로 높이 제한 | 경로 압축·멀티비트 트라이로 깊이 축소 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 정렬된 키의 연속 입력으로 편향 트리가 되어 O(N) | 자가 균형 트리(AVL·Red-Black)로 높이를 O(log N)에 제한 |
| 포인터 추적으로 캐시 지역성이 낮고 디스크 접근 증가 | 디스크 기반 환경은 B-Tree 계열 사용 |
| 동시 수정 시 회전 중 불변식 파괴 | 노드 단위 세분화 잠금 또는 락프리 구조 |

## Ⅵ. 제언

최악 탐색 시간이 요구되는 동적 환경에는 Red-Black Tree 같은 자가 균형 트리를 적용

```text
정적·소규모 데이터 → 기본 BST
읽기 중심 고속 탐색 → AVL
삽입·삭제 빈번 → Red-Black
```

| 구분 | 기본 BST | 제언: 자가 균형 트리 |
|---|---|---|
| 최악 탐색 | O(N) | O(log N) |
| 쓰기 비용 | 회전 없음 | 삽입·삭제 시 회전 |
| 적합 환경 | 소규모 정적 데이터 | 대규모 동적 데이터 |
