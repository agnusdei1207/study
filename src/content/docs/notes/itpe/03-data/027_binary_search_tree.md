## 30초 인출

- 본질: 트리(Tree)는 계층적 관계의 노드와 간선 구조, 그중 **이진 탐색 트리(Binary Search Tree)** 는 왼쪽 서브트리 키 < 부모 키 < 오른쪽 서브트리 키의 정렬 불변식을 유지하는 이진 트리
- 메커니즘: 루트부터 키 비교로 좌우 분기를 반복해 탐색 범위를 절반씩 축소, 중위 순회(In-order Traversal)로 오름차순 키 인출
- 통찰: 정렬된 데이터 삽입 시 편향 트리로 퇴보하는 O(N) 최악의 시간 복잡도를 방지하기 위해 AVL 트리 및 Red-Black 트리 기반의 자가 균형 메커니즘 적용 필수

<summary>핵심 용어</summary>

- **트리(Tree)** : 하나의 루트에서 간선으로 노드를 계층적으로 연결해 순환 없이 부모-자식 관계를 만드는 비선형 자료구조
- **이진 탐색 트리(Binary Search Tree)** : 모든 노드에서 왼쪽 서브트리의 모든 키 < 부모 키 < 오른쪽 서브트리의 모든 키를 유지하는 이진 트리
- **중위 순회(In-order Traversal)** : 왼쪽 서브트리 → 루트 → 오른쪽 서브트리 순으로 방문해 정렬된 키 순서를 얻는 순회 기법
- **편향 트리(Skewed Tree)** : 정렬된 키의 연속 입력으로 한 방향으로만 노드가 이어져 높이가 노드 수 N과 같아진 트리
- **In-order Successor** : 삭제 대상 노드의 오른쪽 서브트리에서 가장 작은 키를 가진 후계자 노드
- **자가 균형 트리(Self-balancing Tree)** : 삽입·삭제마다 회전으로 높이 차를 제한해 O(log N) 탐색 상한을 보장하는 트리
- **트라이(Trie)** : 키를 문자·비트 단위 경로로 저장해 접두어 일치로 탐색하는 다분기 트리
- **최장 프리픽스 매칭(Longest Prefix Match, LPM)** : 라우팅 테이블에서 목적지 주소와 가장 길게 일치하는 프리픽스 경로를 선택하는 라우팅 판정 기법

## 2~4교시 25점 답안

## Ⅰ. 트리·이진 탐색 트리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **트리(Tree)** 는 루트에서 간선으로 노드를 계층 연결하는 비선형 자료구조, **이진 탐색 트리(Binary Search Tree)** 는 왼쪽 서브트리의 모든 키 < 부모 키 < 오른쪽 서브트리의 모든 키 불변식을 유지하는 이진 트리 |
| 목적 | 선형 구조의 순차 탐색 O(N) 비용을 키 비교 분기로 절반씩 줄인 O(log N) 탐색·삽입·삭제의 실현 |

## Ⅱ. 트리·이진 탐색 트리의 핵심 특징

| 특징 | 의미 |
|---|---|
| 순서 불변식 | 모든 노드에서 좌우 서브트리 전체를 대상으로 한 대소 관계의 재귀적 성립, 단순 부모-자식 비교만으로는 불충분 |
| 높이 의존 성능 | 탐색·삽입·삭제 비용이 루트-리프 경로 길이인 트리 높이 h에 비례, 균형 시 O(log N)·편향 시 O(N) |
| 정렬 데이터 인출 | **중위 순회(In-order Traversal)** 수행 시 오름차순 키 출력의 보장 |
| 비선형 계층 표현 | 조직도·파일 시스템·인덱스 같은 포함·위계 관계의 자연스러운 모델링 |

## Ⅲ. BST 구조와 주요 연산 메커니즘

### BST 전체 노드 배치 구조

```text
            [ 45 ]
           /      \
       [ 22 ]    [ 68 ]
       /    \    /    \
   [ 11 ] [ 35 ][ 59 ] [ 77 ]
```

루트 45 기준 왼쪽 전체가 45 미만, 오른쪽 전체가 45 초과의 재귀 적용이 곧 탐색 가능성의 근거

### 키 비교 기반 삽입·삭제 처리 흐름

```text
삽입: 루트에서 키 비교
    ├─ 새 키 < 노드 키 → 왼쪽 서브트리 이동
    └─ 새 키 > 노드 키 → 오른쪽 서브트리 이동
    └─ 빈 리프 위치 도달 → 신규 노드 연결

삭제: 2자식 노드 대상
    ↓
오른쪽 서브트리의 최소 키 노드(In-order Successor) 탐색
    ↓
삭제 위치로 키 복사
    ↓
원래 Successor 자리의 링크 해제
```

| 연산 | 평균 비용 | 최악 비용 | 핵심 제어 요소 |
|---|---|---|---|
| 탐색 | O(log N) | O(N) | 키 비교와 좌우 분기의 일관성 |
| 삽입 | O(log N) | O(N) | 리프 위치 도달 경로 길이 |
| 삭제 | O(log N) | O(N) | **In-order Successor** 대체 후 서브트리 불변식 유지 |

## Ⅳ. 트리 유형 비교와 라우팅 테이블 탐색과의 상관관계

| 유형 | 구조 조건 | 높이·성능 함의 |
|---|---|---|
| 포화 이진 트리(Full Binary Tree) | 모든 노드가 0 또는 2개의 자식 보유 | 자식 수의 일관성, 노드 수와 용량 계산의 단순화 |
| 완전 이진 트리(Complete Binary Tree) | 마지막 레벨을 제외한 전 노드가 채워지고 마지막 레벨은 왼쪽부터 채움 | 배열 인덱스 표현 가능, 힙의 기반 구조 |
| 편향 트리(Skewed Tree) | 한 방향으로만 노드가 이어진 형태 | 높이 N의 선형 리스트와 동일 성능으로의 퇴보 |

| 비교축 | BST 탐색 | 라우팅 테이블 탐색(트라이 기반) |
|---|---|---|
| 공통 원리 | 키 비교마다 탐색 후보를 절반·분기 단위로 축소하는 계층적 판정 | 비트 단위 프리픽스 일치마다 다음 레벨로 분기하는 계층적 판정 |
| 키 판정 방식 | 전체 키의 대소 비교 | 주소의 왼쪽부터의 비트 일치, **최장 프리픽스 매칭(LPM)** 우선 |
| 균형 제어 | 자가 균형 트리로 높이 상한 확보 | 프리픽스 압축·멀티비트 트라이로 트라이 깊이 축소 |
| 상관관계 | 정렬 불변식·계층 분기·균형 제어라는 같은 탐색 공학의 변형 | 목적지 주소 검색의 최악 성능 제어 목적의 동일성 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 정렬된 키의 연속 입력 시 편향 트리(Skewed Tree)로 퇴보해 탐색·삽입이 O(N) | **자가 균형 트리(Self-balancing Tree)** 도입으로 높이를 O(log N)으로 제한 |
| 노드 포인터 추적에 따른 캐시 지역성 저하와 대량 데이터의 잦은 디스크 접근 | 노드 메모리 풀링 적용, 디스크 블록 단위 접근이 많은 환경의 B-Tree 계열 전환 |
| 다중 스레드의 동시 수정 시 회전 과정에서의 트리 불변식 파괴 | 노드 단위 세분화 잠금(Fine-grained Locking) 또는 락프리 동시성 트리 적용 |

## Ⅵ. 제언

데이터 특성과 최악 탐색시간 요구조건에 따라 기본 BST 대신 Red-Black Tree를 채택하고 인메모리 인덱싱 환경에서는 캐시 라인을 고려한 노드 풀링 적용.

### 트리 구조 선정 및 적용 절차

```text
데이터 특성 및 성능 요구 분석
    ↓
선정 판정
    ├─ 정적 대량 데이터 → 중간값 기준 정렬 후 기본 BST 일괄 빌드
    ├─ 읽기 중심 고속 탐색 → AVL Tree 선정
    └─ 삽입·삭제 빈번한 동적 환경 → Red-Black Tree 선정
    ↓
노드 메모리 풀링 및 동시성 제어 적용
```

### 선택 근거: 제언: Red-Black Tree

| 구분 | 기본 BST | 제언: Red-Black Tree |
|---|---|---|
| 최악 탐색 보장 | 불가 (O(N) 편향 위험) | 보장 (O(log N) 상한 유지) |
| 쓰기 오버헤드 | 추가 회전 비용 없음 | 최대 2~3회 회전으로 비용 제한 |
| 적용 권장 환경 | 소규모 정적 데이터 | 대규모 동적 시스템 인덱스 |
