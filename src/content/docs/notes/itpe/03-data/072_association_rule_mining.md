## Ⅰ. 대규모 트랜잭션 속 상관관계 발견, 연관 규칙 마이닝 개요

### 가. 연관 규칙 마이닝(Association Rule Mining)의 정의
- **연관 규칙 마이닝**은 대규모 거래 데이터베이스(장바구니 트랜잭션 로그 등)에서 한 아이템의 구매가 다른 아이템의 구매에 어떤 영향을 미치는지 조건문 형태($X \rightarrow Y$, "아이템 $X$를 구매한 고객은 아이템 $Y$도 함께 구매한다")로 아이템 간의 숨겨진 연관 관계를 발굴하는 비지도 데이터 마이닝 기법.
- 월마트의 전설적인 "기저귀와 맥주" 사례처럼 교차 판매, 매대 배치, 프로모션 번들링의 정량적 근거를 제공함.

## Ⅱ. 연관 규칙의 3대 핵심 평가 지표

### 가. 지지도, 신뢰도, 향상도 수식 및 비즈니스 의미

```text
[ 연관 규칙 3대 평가 척도 ]
1. 지지도 (Support)     : P(X cap Y)         -> 규칙이 전체 거래에서 얼마나 자주 발생하는가?
2. 신뢰도 (Confidence)  : P(Y|X)              -> X를 샀을 때 Y를 함께 살 확률은 얼마인가?
3. 향상도 (Lift)        : P(X cap Y) / [P(X)*P(Y)] -> 우연히 함께 살 확률 대비 실질적 연관 강도는?
```

| 지표 | 수학적 산식 | 비즈니스 해석 | 판정 기준 |
| :--- | :--- | :--- | :--- |
| **지지도 (Support)** | $Support(X \rightarrow Y) = \frac{\text{freq}(X, Y)}{N} = P(X \cap Y)$ | 전체 거래 중 $X$와 $Y$가 동시에 포함된 거래의 비율 | 규칙의 통계적 중요도 및 최소 빈도 기준 (최소 지지도 미달 시 규칙 버림) |
| **신뢰도 (Confidence)** | $Confidence(X \rightarrow Y) = \frac{\text{freq}(X, Y)}{\text{freq}(X)} = P(Y\|X)$ | $X$를 포함하는 거래 중에서 $Y$도 함께 포함될 조건부 확률 | 규칙의 조건부 확실성 (최소 신뢰도 이상인 규칙만 유효 규칙으로 선정) |
| **향상도 (Lift)** | $Lift(X \rightarrow Y) = \frac{P(X \cap Y)}{P(X) \cdot P(Y)} = \frac{Confidence(X \rightarrow Y)}{Support(Y)}$ | $X$와 $Y$가 독립일 때 대비, $X$의 구매가 $Y$의 구매 확률을 몇 배 증가시키는가 | **Lift > 1 : 양의 상관 (유의미)**, Lift = 1 : 독립 (우연), Lift < 1 : 음의 상관 |

## Ⅲ. 핵심 알고리즘 비교: Apriori vs FP-Growth

### 가. Apriori 알고리즘과 하향 폐쇄성(Apriori Principle)
- **원리** : "한 항목집합이 빈발(Frequent)하면, 그 항목집합의 모든 부분집합도 반드시 빈발하다"는 속성을 역으로 이용하여, **"빈발하지 않은 항목집합을 포함하는 상위 집합은 탐색하지 않고 가지치기(Pruning)"** 함.
- **치명적 병목** : 후보 항목집합(Candidate Itemsets)을 생성하기 위해 데이터베이스를 매 패스(Pass)마다 반복 전수 스캔해야 하므로, 아이템 수가 많을 때 I/O 비용 폭발.

### 나. FP-Growth 알고리즘의 혁신

```text
[ FP-Growth 트리 압축 및 마이닝 ]
[트랜잭션 DB] ---> (DB 2회 스캔만으로 메모리 내 FP-Tree 압축 구성)
                     |
                     v
             [FP-Tree (빈발 패턴 트리)]
                     |
                     v (조건부 FP-Tree 재귀 분할 정복)
         [후보군 생성 없이 빈발 패턴 직접 추출]
```

| 비교 항목 | Apriori 알고리즘 | FP-Growth 알고리즘 |
| :--- | :--- | :--- |
| **후보군(Candidate) 생성** | 각 단계별로 후보 항목집합을 대량 생성 | **후보군 생성을 일체 하지 않음** |
| **DB 스캔 횟수** | 최대 항목 크기 $K$에 비례하여 **$K$회 반복 스캔** | **단 2회 스캔** 으로 FP-Tree 구축 완료 |
| **수행 속도** | 느림 ($O(2^M)$ 공간 및 막대한 I/O) | **Apriori 대비 수십~수백 배 고속** |
| **메모리 요구량** | 적음 | FP-Tree를 메모리에 적재해야 하므로 메모리 필요 |

## Ⅳ. 연관 규칙 마이닝의 주요 한계점 및 해결 방안

- **아이템 수 증가에 따른 지수적 탐색 공간 폭발(Combinatorial Explosion)** :
  - **한계점** : 분석 대상 품목(Item)이 수만~수십만 개로 증가할 경우 후보 항목 집합($2^k$)의 기하급수적 증가로 인한 메모리 고갈(OOM) 및 연산 병목 발생.
  - **해결 방안** : 최소 지지도(Min Support) 동적 가지치기, FP-Growth(FP-Tree) 기반 메모리 압축 구조 활용, Apache Spark 분산 FP-Growth 엔진 도입.
- **희귀 유의미 규칙(Rare Item Problem) 발굴 한계 및 자명한 규칙 편중** :
  - **한계점** : 고정된 최소 지지도 적용 시 빈번한 대중적 상품만 검출되고, 마진율이 높은 롱테일 고가 상품 간의 희귀 연관 규칙 누락.
  - **해결 방안** : 차등 최소 지지도(MS-Apriori: Multiple Support Apriori) 적용, 지지도 대신 리프트(Lift) 및 레버리지(Leverage) 등 다차원 흥미도 측도 복합 필터링.
- **정적 트랜잭션 기반 연관성 분석의 시간적 순서(Temporal Order) 간과** :
  - **한계점** : 단순 동시 구매(Co-occurrence)만 포착하여 A 구매 후 B 구매로 이어지는 인과적·시계열적 순차 패턴(Sequential Pattern) 반영 불가.
  - **해결 방안** : 순차 패턴 마이닝(GSP, PrefixSpan) 알고리즘 결합, 세션 기반 Transformer 추천 모델(SASRec 등)로 전환.

## Ⅴ. 현대 이커머스 및 데이터 실무 관점의 제언

- **향상도(Lift)와 신뢰도(Confidence)의 교차 필터링** : 신뢰도가 90%로 매우 높더라도 원래 아이템 $Y$ 자체의 대중적 인기가 90%라면 향상도는 $1.0$에 불과하여 의미 없는 규칙임. 따라서 반드시 최소 지지도 $\rightarrow$ 최소 신뢰도 $\rightarrow$ **향상도 $> 1.2$** 순서의 엄격한 다단계 필터링 파이프라인을 구축해야 함.
- **순차 패턴 마이닝(Sequential Pattern)으로의 확장** : 단순한 동시 구매 분석에 그치지 않고 시간적 선후 관계를 분석하는 PrefixSpan, GSP 알고리즘을 결합하여 "A 상품 구매 후 3일 이내에 B 상품을 재구매하는 패턴"을 추출하여 리텐션 마케팅에 연계할 것을 제언함.
