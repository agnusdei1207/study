## Ⅰ. 연관 규칙 마이닝의 개요

- 핵심 요약 : 연관 규칙 마이닝은 거래 등 항목집합 자료에서 함께 나타나는 항목 관계를 빈발패턴과 조건부 규칙으로 탐색하는 기법.
- 개념 : 연관 규칙 마이닝은 거래 등 항목집합 자료에서 함께 나타나는 항목 관계를 빈발패턴과 조건부 규칙으로 탐색하는 기법.
- 배경 및 필요성 : 대량 거래에서 조합적으로 나타나는 상품·행동 관계를 찾기 어려움.
- 주요 목적 : 설명 가능한 공출현 패턴을 발견해 진열·추천·업무 규칙 후보 제공.

## Ⅱ. 연관 규칙 마이닝의 특징 및 장점

- 핵심 요약 : 지지도: 전체 거래 중 X∪Y 포함 비율 → 빈도 측정; 신뢰도: support(X∪Y)/support(X) → 조건부 동시출현 비율; 향상도: confidence(X→Y)/support(Y) → 독립기준 대비 연관 강도.

1. 지지도: 전체 거래 중 X∪Y 포함 비율 → 빈도 측정
2. 신뢰도: support(X∪Y)/support(X) → 조건부 동시출현 비율
3. 향상도: confidence(X→Y)/support(Y) → 독립기준 대비 연관 강도

## Ⅲ. 연관 규칙 마이닝의 구조 (흐름)

- 핵심 요약 : 거래를 트랜잭션·항목집합으로 변환 → 최소 지지도 기준 빈발항목집합 탐색 → 빈발집합에서 규칙 생성 → 신뢰도·향상도·도메인 의미 검토 → 검증자료·실험으로 활용성 평가.

```text
거래를 트랜잭션·항목집합으로 변환
  ↓
최소 지지도 기준 빈발항목집합 탐색
  ↓
빈발집합에서 규칙 생성
  ↓
신뢰도·향상도·도메인 의미 검토
  ↓
검증자료·실험으로 활용성 평가
```

- 핵심 구성 : 거래 집합 → 빈발 항목집합 → X→Y 후보 → 지지도·신뢰도·향상도 → 규칙 검증

```text
거래 집합 → 빈발 항목집합 → X→Y 후보 → 지지도·신뢰도·향상도 → 규칙 검증
```

## Ⅳ. 비교: Apriori / FP-Growth

- 핵심 요약 : 비용 기준 — Apriori: 후보 수·반복 DB 스캔 증가 가능; FP-Growth: 트리 메모리·구현 복잡도 고려.

| 비교 기준 | Apriori | FP-Growth |
| --- | --- | --- |
| 탐색 | 빈발 부분집합의 하향폐쇄 성질로 후보 생성·검사 | FP-Tree 압축 후 패턴 성장 |
| 비용 | 후보 수·반복 DB 스캔 증가 가능 | 트리 메모리·구현 복잡도 고려 |

- 핵심 요약 : 기준값 민감·상관을 인과로 오해 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |

| 상관을 인과로 오해 | 공출현만으로 인과 방향·효과 입증 안 됨 | 통제 분석·실험으로 인과 검증 | 실험 uplift |

## Ⅵ. 연관 규칙 마이닝의 제언

- 핵심 요약 : 분석가는 규칙을 후보 가설로 취급하고 기간·상품군별 재현성 및 통제실험 결과가 확인된 경우에만 업무정책 반영.
- 실행 제안 : 분석가는 규칙의 기준기간·최소지지도·향상도와 상품군별 재현성을 확인한 뒤 통제실험으로 효과 판단.

## Ⅶ. 연관 규칙 마이닝의 결론

- 핵심 요약 : 연관 규칙은 동시출현 관계를 요약하는 도구이며 구매행동의 원인이나 추천효과를 단독으로 증명하지 않음.
- 시사점 : 연관 규칙은 행동 가설을 좁히는 탐색 결과이며 효과 입증은 통제된 실험으로 보완.
