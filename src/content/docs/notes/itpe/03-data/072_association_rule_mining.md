## 연관 키워드

**연관 규칙**, **지지도**, **신뢰도**, **향상도**, **Apriori**, **FP-Growth**, **빈발 항목집합**

## Ⅰ. 개요

- 핵심 요약 : **연관 규칙 마이닝**은 거래 자료에서 함께 나타나는 항목 조합과 조건부 패턴을 찾는다.
- 표현 : 규칙 (X \rightarrow Y)는 (X)가 포함된 거래와 (Y)의 동시 출현 관계를 요약한다.
- 활용 : 장바구니 분석, 교차 판매, 서비스 조합 탐색 등에 활용한다.
- 주의 : 연관성은 인과관계를 뜻하지 않으며, 실제 의사결정에는 실험·업무 맥락 검토가 필요하다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **빈발 패턴 탐색**과 **규칙 흥미도 평가**로 대량 거래의 동시 출현 구조를 요약한다.
- **지지도** : 전체 거래 중 (X)와 (Y)가 함께 나타나는 비율로 패턴의 빈도를 나타낸다.
- **신뢰도** : (X)가 나타난 거래 중 (Y)도 나타나는 비율이다.
- **향상도** : 독립 가정에서의 기대 빈도 대비 동시 출현 강도를 나타내며, 1 초과는 양의 연관을 시사한다.
- 이 지표만으로 인과성이나 통계적 유의성이 입증되는 것은 아니다.

## Ⅲ. 마이닝 처리 흐름

- 핵심 요약 : **거래 정제 → 빈발 항목집합 탐색 → 규칙 생성 → 지표·업무 검토**로 수행한다.

```text
[거래 자료·항목 정의]
          ▼
[중복·결측·범위 정제]
          ▼
[빈발 항목집합 탐색]
          ▼
[X → Y 규칙 생성]
          ▼
[지지도·신뢰도·향상도 계산]
          ▼
[업무 타당성·실험 검증]
```

- 임계값은 데이터 규모와 활용 목적에 따라 정하며 고정된 보편 기준은 없다.
- 대규모 거래에서는 후보 폭발을 줄이는 가지치기·압축 탐색을 검토한다.

## Ⅳ. Apriori와 FP-Growth 비교

- 핵심 요약 : **Apriori는 후보 집합 가지치기**, **FP-Growth는 압축 트리 탐색**으로 빈발 패턴을 찾는다.

| 항목 | Apriori | FP-Growth |
|---|---|---|
| 핵심 원리 | 빈발하지 않은 부분집합의 상위집합을 제외 | 거래를 FP-Tree에 압축해 조건부 패턴 탐색 |
| 후보 생성 | 단계별 후보 집합 생성 | 명시적 후보 생성 부담을 줄임 |
| 데이터 접근 | 반복적인 데이터베이스 스캔 가능 | 트리 구성 후 조건부 트리 탐색 |
| 장점 | 개념·구현이 비교적 단순 | 많은 후보가 발생하는 경우 효율적일 수 있음 |
| 유의점 | 후보 수와 반복 스캔 비용 | 트리 메모리와 데이터 구조 영향 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **조합 폭발·희귀 항목 누락·자명한 연관·시간 순서 부재**를 보완한다.
- **후보 조합 폭증** → 최소 지지도와 도메인 제약으로 탐색 공간을 줄이고 FP-Growth 등 대안을 평가한다.
- **희귀하지만 중요한 패턴 누락** → 다중 최소 지지도나 목적별 희귀 패턴 탐색을 검토한다.
- **대중 항목에 따른 높은 신뢰도** → 향상도·레버리지 등 여러 지표를 같이 보되 표본 수와 안정성도 확인한다.
- **시간 순서 미반영** → 순차 패턴 분석이나 세션 기반 분석으로 확장한다.

```text
조합 과다   → 가지치기·탐색 방식 조정
희귀 패턴   → 목적별 지지도 기준     → 해석 가능한 연관 인사이트
시간 정보 누락 → 순차 패턴 분석
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **통계 지표와 업무 검증을 결합**해 규칙을 실제 정책으로 옮긴다.
- 거래 정의, 항목 범주화, 분석 기간, 임계값, 규칙 산출 버전을 기록한다.
- 규칙의 빈도와 기간별 안정성을 확인하고, 추천·진열 변경은 통제된 실험으로 효과를 평가한다.
- 민감한 구매 기록은 접근통제·목적 제한·보유기간을 적용한다.

## Ⅶ. 결론

- 핵심 요약 : 연관 규칙은 **동시 출현 패턴 탐색 기법**이며 지지도·신뢰도·향상도와 업무 맥락을 함께 해석한다.
- 답안에는 지표의 의미, Apriori와 FP-Growth 차이, 희귀 규칙·시간 순서의 한계와 방안을 제시한다.
