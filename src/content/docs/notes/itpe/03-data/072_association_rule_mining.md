## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 마이닝 → **연관규칙분석(지지도·신뢰도·향상도)**

## 30초 인출

- 본질: 연관규칙분석은 거래 자료에서 함께 나타나는 항목 조합의 관계(A → B)를 찾는 분석
- 메커니즘: 최소 지지도 이상의 빈발 항목집합을 찾아 규칙을 만들고, 신뢰도 P(B|A)와 향상도 P(B|A)/P(B)로 규칙의 강도를 평가
- 통찰: 신뢰도는 후행 항목 자체가 흔하면 높게 나오므로 향상도로 기준 빈도와 비교하고, 연관은 인과가 아니므로 다른 기간·집단에서 재현성을 확인

<details>
<summary>핵심 용어</summary>

- **연관규칙(Association Rule)** : 선행 항목집합 A와 후행 항목집합 B의 동시 발생 관계 A → B
- **지지도(Support)** : 규칙이 전체 거래에 나타나는 비율 P(A∩B)
- **신뢰도(Confidence)** : A가 있을 때 B도 있는 조건부 비율 P(B|A)
- **향상도(Lift)** : B의 전체 빈도 대비 A가 있을 때 B의 발생 배율 P(B|A)/P(B)
- **Apriori** : 빈발 집합의 부분집합도 빈발이라는 성질로 후보를 가지치기하는 알고리즘
- **FP-Growth** : FP-Tree로 빈발 패턴을 압축해 후보 생성 없이 탐색하는 알고리즘

</details>

## 2~4교시 25점 답안

## Ⅰ. 연관규칙분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **연관규칙분석** 은 거래 자료에서 항목 간 동시 발생 관계를 찾는 분석 |
| 목적 | 반복되는 항목 조합을 찾아 업무 의사결정에 활용 |

## Ⅱ. 특징

| 특징 | 해석 의미 |
|---|---|
| 동시 발생 탐색 | 거래 항목의 반복 조합 발견 |
| 방향 있는 규칙 | A→B의 조건부 빈도는 B→A와 다를 수 있음 |
| 관찰 자료 기반 | 높은 연관성만으로 인과·정책 효과가 입증되지 않음 |

## Ⅲ. 규칙 도출 절차

```text
거래 자료 → 최소 지지도 이상의 빈발 항목집합 탐색
      ↓
겹치지 않는 A·B로 규칙 A → B 생성
      ↓
신뢰도·향상도 평가 → 다른 기간·집단에서 재현성 확인
```

## Ⅳ. 평가 지표와 알고리즘

| 지표 | 수식 | 해석 |
|---|---|---|
| 지지도 | P(A∩B) | 규칙이 전체 자료에 나타나는 빈도 |
| 신뢰도 | P(B\|A) | A가 있을 때 B도 나타나는 비율 |
| 향상도 | P(B\|A) / P(B) | B의 전체 빈도와 비교한 상대적 발생률 |

- 최소 지지도는 후보 탐색 범위를 줄이고, 신뢰도·향상도는 규칙의 특성을 평가
- 향상도 1이면 A와 B가 독립, 1보다 크면 함께 나타날 가능성이 높음
- 향상도는 교란 요인·표본 불확실성을 통제하지 않으므로 인과의 증거가 아님

| 비교축 | Apriori | FP-Growth |
|---|---|---|
| 원리 | 부분집합 빈발성으로 후보 가지치기 | FP-Tree에 압축해 조건부 패턴 탐색 |
| 후보 생성 | 단계별 후보 집합 구성 | 명시적 후보 생성 감소 |
| 주요 비용 | 여러 차수의 후보·스캔 | FP-Tree 구성·메모리 |
| 선택 | 자료 크기·항목 수·희소성 | 패턴 공유 정도·메모리 한계 |

FP-Growth가 항상 빠르다고 단정하지 않고 자료와 구현으로 비교.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 신뢰도가 후행 항목의 높은 빈도 때문일 수 있음 | 향상도 등 다른 지표와 기준 빈도 검토 |
| 다수 규칙에 우연한 관계 포함 | 최소 빈도·도메인 검토·별도 기간 재검증 |
| 연관을 원인으로 오해 | 통제 실험 없이 정책 효과로 단정하지 않음 |

## Ⅵ. 제언

지지도로 후보를 거르고 향상도로 규칙을 평가하며, 다른 기간·집단에서 재현된 규칙만 업무에 적용

```text
최소 지지도 → 규칙 생성 → 신뢰도·향상도 → 재현성 검증 → 통제 실험 후 적용
```

| 구분 | 신뢰도만 사용 | 제언: 향상도·재현성 병행 |
|---|---|---|
| 흔한 항목 | 과대평가 | 기준 빈도 보정 |
| 적용 | 우연 규칙 포함 | 재검증 규칙만 |
