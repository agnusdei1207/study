## 답안 골격
```text
[연관규칙분석] ◀━━ 머리: Ⅶ 내 의견 (지지도·신뢰도 기반 1차 가지치기 후 향상도(Lift) 중심 실효적 규칙 선별)
 ┃
 ┣━ Ⅰ 개요 ───── 대규모 거래 트랜잭션 데이터베이스에서 항목 간의 동시 발생 패턴과 조건부 연관성($A \rightarrow B$)을 도출하는 비지도 마이닝 기법
 ┣━ Ⅱ 특징 ───── 장바구니 분석(Market Basket Analysis) · 사전 가설 불필요(비지도) · 직관적 규칙 도출 · 지수적 조합 탐색 공간
 ┣━ Ⅲ 구조 ───── 3대 핵심 평가 지표: 지지도(Support) / 신뢰도(Confidence) / 향상도(Lift)
 ┣━ Ⅳ 흐름 ───── ① 트랜잭션 집합 수집 → ② 최소 지지도 기준 빈발 항목 집합(Frequent Itemsets) 도출(Apriori/FP-Growth) → ③ 최소 신뢰도 필터링 → ④ 향상도 평가 및 최종 규칙 채택
 ┣━ Ⅴ 비교 ───── Apriori vs FP-Growth (후보 생성 및 다중 DB 스캔 $O(2^k)$ vs 트리 구조 기반 무후보 생성 및 2회 스캔)
 ┗━ Ⅵ 실무 ───── 최소 지지도 설정 실패 시 수천만 개 무의미 규칙 팽창 / 당연한 규칙(빵 구매 시 우유 구매)의 무가치성
```
- 필수 키워드: 장바구니 분석 · 연관성 규칙($A \rightarrow B$) · 지지도(Support) · 신뢰도(Confidence) · 향상도(Lift) · Apriori · FP-Tree
- 기출: 137회 1교시 13번 `데이터마이닝의 연관 규칙 분석(Association Rule Analysis) 지표를 설명하시오` → Ⅰ 개념 + Ⅲ 지지도/신뢰도/향상도 수식 및 의미 상세

## 한 줄 본질
- 수만 개 상품 간 가능한 모든 조합($2^N$)의 지수적 폭증 한계 → 최소 지지도 기반 하향식 가지치기(Apriori)와 향상도(Lift) 평가로 유의미한 동시 구매 규칙 $A \rightarrow B$ 발굴 → 교차 판매 증대 / 희귀 고가품 규칙 누락

## 핵심 그림
```text
[연관규칙분석 3대 핵심 평가 지표 수식 및 벤다이어그램]

  전체 트랜잭션 수: N
  ┌─────────────────────────────────┐
  │              [ N ]              │
  │    ┌──────────┬──────────┐      │
  │    │  A 만    │  A ∩ B   │  B 만│
  │    │ (n(A)-n) │  n(A∩B)  │      │
  │    └──────────┴──────────┘      │
  └─────────────────────────────────┘

 1. 지지도 (Support): A와 B가 '동시에' 일어날 확률
    Support(A -> B) = P(A ∩ B) = n(A ∩ B) / N

 2. 신뢰도 (Confidence): A가 일어났을 때 'B도 함께' 일어날 조건부 확률
    Confidence(A -> B) = P(B | A) = P(A ∩ B) / P(A) = n(A ∩ B) / n(A)

 3. 향상도 (Lift): A의 구매가 B의 구매 확률을 '얼마나 증가'시켰는가?
    Lift(A -> B) = P(A ∩ B) / (P(A) * P(B)) = Confidence(A -> B) / P(B)
    * Lift > 1 : 양의 상관관계 (A가 B 구매를 유도, 의미 있는 규칙!)
    * Lift = 1 : 독립 (A와 B는 전혀 무관하게 우연히 발생)
    * Lift < 1 : 음의 상관관계 (A를 사면 오히려 B를 안 삼, 대체재)
```

## 핵심 용어
- 향상도(Lift): 품목 A를 구매한 고객이 품목 B를 구매할 확률이, 전체 고객 중 품목 B를 구매할 통상 확률에 비해 몇 배나 높은지를 나타내는 진정한 연관성 판별 지표
- Apriori 원리: "어떤 항목 집합이 빈발(Frequent)하지 않다면, 그 항목 집합을 포함하는 모든 슈퍼셋(Superset) 항목 집합도 절대 빈발할 수 없다"는 가지치기 공리

## 핵심 통찰
- 신뢰도(Confidence)만 보면 함정에 빠짐 → B라는 상품 자체가 워낙 인기 상품(예: 편의점 생수, $P(B) = 0.9$)이면 A를 사든 안 사든 신뢰도가 90%로 높게 나옴
- 따라서 신뢰도가 아무리 높아도 '향상도(Lift)가 1 이하'라면 두 상품은 우연히 같이 팔렸거나 오히려 방해하는 관계이므로 추천하면 안 됨
- 데이터가 커질수록 Apriori 알고리즘은 전체 DB를 수십 번 반복 스캔하므로, 메모리 상에 FP-Tree를 한 번만 구축하는 FP-Growth 알고리즘이 필수적

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| FP-Growth (Frequent Pattern) | Apriori의 후보 생성 병목 극복 | 빈발 항목들을 접두사 공유 트리(FP-Tree)로 압축 구축하여 DB 스캔을 단 2회로 끝내는 고속 알고리즘 |
| 순차 패턴 마이닝(Sequential Pattern) | 시간 축이 추가된 연관규칙 | "A 구매 후 3일 뒤 B 구매"처럼 시간적 선후 인과 관계를 분석하는 확장 기법 |

## 이웃 토픽과 구분
- 연관규칙분석 vs 군집분석: 연관규칙 = 아이템(상품)들 사이의 동시 발생 패턴 탐색 / 군집분석 = 사용자(고객)들 사이의 유사성을 기반으로 그룹화

## 문제·원인·대책
- 적용 상황: 대형마트 상품 진열 및 앱 장바구니 추천 알고리즘 설계
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 신뢰도 95%인 '맥주 $\rightarrow$ 라면' 규칙을 믿고 번들 기획했으나 매출 증가 미미 | 라면 자체가 원래 전체 고객의 95%가 구매하는 필수재(Lift=1.0) | 향상도(Lift) > 1.5 이상인 규칙만 엄선하여 프로모션 재설계 | 교차 판매 매출 28% 순증 |
| 상품 수 10만 개 대상 분석 시 메모리 부족으로 Apriori 프로세스 크래시 | $k$-항목 후보 집합($C_k$) 생성 시 조합 폭증($O(2^N)$) | FP-Growth 전환 및 카테고리별 계층적 연관분석 분할 수행 | 연산 시간 1/100 단축 및 메모리 안정화 |
