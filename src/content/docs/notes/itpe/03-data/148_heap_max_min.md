## Ⅰ. 우선순위 큐의 핵심 엔진, 힙(Heap) 자료구조의 개요

### 가. 힙(Heap)의 정의
- 완전 이진 트리(Complete Binary Tree) 구조를 기반으로 하여, 최댓값 또는 최솟값을 **$O(1)$의 시간 복잡도로 빠르게 찾아내기 위해** 부모 노드와 자식 노드 간의 대소 관계를 일정하게 유지하는 자료구조.
- 최댓값을 루트로 유지하는 **최대 힙(Max Heap)** 과 최솟값을 루트로 유지하는 **최소 힙(Min Heap)** 으로 양분됨.

### 나. 힙의 2대 기본 성립 조건
1. **형태적 속성 (Shape Property)** : 마지막 레벨을 제외한 모든 레벨이 완전히 채워져 있어야 하며, 마지막 레벨의 노드들은 항상 왼쪽부터 순서대로 채워지는 **완전 이진 트리** 여야 함.
2. **힙 속성 (Heap Property)** :
   - 최대 힙 : 모든 부모 노드의 키값 $\ge$ 자식 노드의 키값 ($A[Parent(i)] \ge A[i]$).
   - 최소 힙 : 모든 부모 노드의 키값 $\le$ 자식 노드의 키값 ($A[Parent(i)] \le A[i]$).

## Ⅱ. 힙의 메모리 배열 매핑 및 핵심 연산 알고리즘

### 가. 완전 이진 트리의 1차원 배열(Array) 매핑 규칙

```text
[ 배열 인덱스 기반 힙 표현 (루트 인덱스 = 1 기준) ]
               [1] Root
              /        \
           [2]          [3]
          /   \        /   \
        [4]   [5]    [6]   [7]
- 노드 i의 부모 노드 인덱스   : floor(i / 2)
- 노드 i의 왼쪽 자식 인덱스   : 2 * i
- 노드 i의 오른쪽 자식 인덱스 : 2 * i + 1
* 포인터 없이 순수 산술 연산만으로 부모/자식 간 O(1) 이동 가능!
```

### 나. 힙의 핵심 연산 메커니즘

| 연산 명칭 | 동작 원리 및 과정 | 시간 복잡도 |
| :--- | :--- | :--- |
| **삽입 (Insert)** | 배열의 맨 마지막 위치(완전 이진 트리 끝)에 새 원소를 추가한 후, 부모 노드와 비교하며 위로 교환(Heapify-Up / Swim) | **$O(\log n)$** |
| **삭제 (Extract Min/Max)** | 루트 노드를 꺼내고, 배열의 맨 마지막 노드를 루트로 옮긴 후 자식 노드 중 더 크거나 작은 쪽과 비교하며 아래로 교환(Heapify-Down / Sink) | **$O(\log n)$** |
| **힙 빌드 (Build Heap)** | 임의의 무작위 배열 $n$개를 바닥부터 차례로 Heapify하여 완전한 힙으로 구성 | **$O(n)$** (수학적 급수 증명) |

## Ⅲ. 힙 정렬(Heap Sort)과 우선순위 큐(Priority Queue) 응용

### 가. 힙 정렬의 메커니즘과 복잡도
- $n$개의 데이터로 최대 힙 구성($O(n)$) $\rightarrow$ 루트를 꺼내어 배열 끝과 교환하고 힙 크기를 1씩 줄여가며 재정렬 반복 $\rightarrow$ **최선, 평균, 최악 모두 안정적인 $O(n \log n)$ 시간 복잡도 및 $O(1)$ 제자리 정렬(In-place)** 달성.

### 나. 분산 시스템에서의 핵심 응용
- **다중 스트림 병합 정렬 (K-way Merge)** : 분산 DB에서 정렬된 $K$개의 샤드 결과를 병합할 때 크기 $K$의 최소 힙을 유지하여 $O(N \log K)$로 초고속 스트리밍 정렬 수행.
- **Top-K 실시간 랭킹 탐색** : 수억 건의 데이터 중 상위 100개 최다 검색어를 추출할 때 전체를 정렬하지 않고 크기 100의 최소 힙을 유지하여 단 한 번의 스트림 순회($O(N \log 100)$)로 완료.

## Ⅳ. 시스템 소프트웨어 개발 실무 제언

- **배열 인덱스 0 기반 매핑 최적화** : 현대 프로그래밍 언어(C, Java, Python)는 인덱스가 0부터 시작하므로, `Left Child = 2*i + 1`, `Right Child = 2*i + 2`, `Parent = (i - 1) / 2` 비트 시프트 연산(`(i << 1) + 1`)을 적용하여 CPU 연산 클럭을 극소화할 것.
- **동적 메모리 재할당 오버헤드 방지** : 고속 패킷 스케줄러나 실시간 우선순위 대기열 구현 시 힙 용량이 찰 때마다 배열이 재할당(Realloc)되는 지연을 방지하기 위해, 최대 수용치만큼의 메모리 풀을 사전 할당(Pre-allocation)하는 링 버퍼 힙 구조를 적용할 것을 제언함.
