## 지식 로드맵 내 현재 위치

자료처리·데이터 → 자료구조 → **힙(최대·최소 힙)**

## 30초 인출

- 본질: 힙은 완전 이진 트리 형태를 유지하면서 모든 부모가 자식보다 우선(최대 힙은 크거나 같고 최소 힙은 작거나 같음)인 자료구조
- 메커니즘: 배열에 빈 노드 없이 저장해 i번째 노드의 왼쪽·오른쪽 자식과 부모를 2i+1, 2i+2, ⌊(i−1)/2⌋로 계산하고, 삽입은 끝에 추가해 위로, 루트 추출은 끝 원소를 루트로 옮겨 아래로 재배치
- 통찰: 루트의 극값만 보장하고 전체 정렬은 보장하지 않으므로 최댓값·최솟값을 반복 추출하는 우선순위 큐에 쓰고, 임의 키·범위 탐색은 인덱스·균형 BST와 비용을 비교해 선택

<details>
<summary>핵심 용어</summary>

- **힙(Heap)** : 완전 이진 트리에 부모·자식 우선순위 관계를 유지하는 자료구조
- **최대 힙·최소 힙** : 부모 ≥ 자식 / 부모 ≤ 자식
- **완전 이진 트리** : 마지막 층을 제외하고 채워지고 마지막 층은 왼쪽부터 채우는 트리
- **우선순위 큐** : 우선순위가 가장 높은 원소를 먼저 꺼내는 자료구조
- **힙 정렬** : 힙을 만든 뒤 루트를 반복 추출해 정렬하는 O(n log n) 알고리즘
- **상향·하향 재배치** : 삽입·추출 후 힙 순서를 회복하는 교환 과정

</details>

## 2~4교시 25점 답안

## Ⅰ. 힙의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **힙** 은 완전 이진 트리 형태와 부모·자식 간 우선순위 관계를 유지하는 자료구조 |
| 목적 | 최댓값·최솟값의 빠른 조회와 우선순위 기반 삽입·추출 |

## Ⅱ. 특징

| 특징 | 결과 |
|---|---|
| 완전 이진 트리 | 배열에 빈 노드 없이 저장 |
| 부모·자식 순서 | 루트의 극값만 보장, 전체 정렬은 보장하지 않음 |
| 높이 제한 | 삽입·루트 추출의 재배치가 O(log n) |

## Ⅲ. 배열 구조와 연산

```text
          [90]
         /    \
      [80]    [70]
      /  \    /
   [40] [30] [60]
인덱스:  0    1    2    3    4    5
값   : [90 | 80 | 70 | 40 | 30 | 60]
왼쪽 자식 = 2i+1, 오른쪽 자식 = 2i+2, 부모 = ⌊(i−1)/2⌋
```

```text
삽입: 배열 끝에 추가 → 부모와 비교 → 위반이면 위로 교환
추출: 루트 반환 → 끝 원소를 루트로 이동 → 자식과 비교해 아래로 교환
```

| 불변식 | 의미 |
|---|---|
| 형태 | 마지막 층을 왼쪽부터 채우는 완전 이진 트리 |
| 최대 힙 | 각 부모 ≥ 직접 자식 |
| 최소 힙 | 각 부모 ≤ 직접 자식 |

형제나 서로 다른 서브트리 사이에는 정렬 순서가 없음.

## Ⅳ. 연산 비용과 BST 비교

| 연산 | 처리 | 시간 |
|---|---|---|
| 루트 조회 | 첫 원소 확인 | O(1) |
| 삽입 | 끝에 추가·상향 재배치 | O(log n) |
| 루트 추출 | 끝 원소 이동·하향 재배치 | O(log n) |
| 임의 키 검색 | 순서 정보가 부족해 순회 | O(n) |

| 활용 | 힙의 역할 |
|---|---|
| 우선순위 큐 | 우선순위가 가장 높은 작업을 반복 추출 |
| 상위 k개 유지 | 크기 k의 힙으로 후보 관리 |
| 힙 정렬 | 힙을 만든 뒤 루트를 반복 추출 |

| 판단 | 힙 | 균형 BST |
|---|---|---|
| 우선순위 극값 | 루트에서 확인 | 순서 탐색 필요 |
| 임의 키·범위 검색 | 비효율 | 정렬 순서 활용 |
| 주된 용도 | 우선순위 큐 | 키 탐색·범위 조회 |

우선순위 큐가 반드시 힙으로만 구현되는 것은 아님.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 루트 우선순위만 보장해 임의 값·범위 탐색이 느림 | 극값 반복 추출에는 힙, 임의 탐색에는 인덱스·BST와 비용 비교 |
| 원소의 우선순위 변경 시 위치 탐색 곤란 | 위치 인덱스를 유지하거나 재삽입·지연 삭제 비용 비교 |

## Ⅵ. 제언

극값을 반복해서 꺼내는 요구에는 힙을, 임의 탐색·범위 조회 요구에는 균형 BST·인덱스를 선택

```text
극값 반복 추출 → 힙(우선순위 큐) / 임의 키·범위 탐색 → 균형 BST·인덱스
```

| 구분 | 정렬된 배열로 관리 | 제언: 힙 |
|---|---|---|
| 삽입 | O(n) | O(log n) |
| 극값 추출 | 조회 O(1), 삭제 비용 | O(log n) |
