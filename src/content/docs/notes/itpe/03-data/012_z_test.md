## 연관 키워드

- z-검정(Z-Test), 귀무가설(H0), 대립가설(H1), 유의수준(α), 검정통계량(Test Statistic), 기각역(Rejection Region)
- 표준정규분포, 중심극한정리(CLT), 임계값(Critical Value), 양측 검정, 단측 검정, 효과 크기(Effect Size)

## Ⅰ. z-검정의 개요

- 핵심 요약 : 모분산 기지 또는 대표본 조건에서 표준정규분포를 기준으로 모평균과 비율을 판정하는 모수적 가설검정.
- 개념 : **검정통계량** (Test Statistic)이 표준정규분포를 따른다는 전제 아래 가설의 채택 여부를 판정하는 모수적 가설검정인 **z-검정** (Z-Test).
- 배경 및 필요성 : 표본 데이터만으로 모집단에 대한 주장을 확률적 근거로 판정할 객관적 절차의 필요.
- 주요 목적 : 표준화된 검정통계량과 **임계값** (Critical Value)의 비교를 통한 **귀무가설** ($H_0$, Null Hypothesis)의 기각 여부 결정.

## Ⅱ. z-검정의 특징 및 장점

- 핵심 요약 : 독립 무작위 표본, 정규성 또는 대표본, 모표준편차 기지(既知)의 세 전제 아래 표준화 판정이 이루어지는 구조.

1. 독립 무작위 표본 : 관측치의 독립성과 무작위성 확보 → 편향 없는 판정 근거.
2. 정규성 또는 대표본 : 모집단 정규성이나 중심극한정리(CLT, Central Limit Theorem) 기반의 대표본 조건 → 정규 근사의 타당성.
3. 모표준편차 기지 : 알려진 모표준편차($\sigma$)의 사용 → 자유도 보정 없는 단순 판정.
4. 표준화 통계량 : $Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}}$의 계산 → 기준 분포의 단일화와 판정 절차 표준화.
5. 방향별 검정 지원 : **양측 검정**과 **단측 검정**의 선택 → 분석 질문의 방향성 반영.
6. 비율 검정 확장 : 대표본 이항분포의 정규 근사 → 클릭률·전환율 비교에의 적용.

## Ⅲ. z-검정의 구조 (흐름)

- 핵심 요약 : 가설 수립에서 의사결정까지의 5단계 절차와 기각역 기반의 판정 흐름.

```text
[ z-검정 5단계 절차 ]

1. 가설 수립
   H0 : μ = μ0
      ↓
2. 유의수준 설정
   α = 0.05
      ↓
3. 기각역 결정
   양측 기준 ±1.96
      ↓
4. 검정통계량 계산
   Z = (X̄-μ0) / (σ/√n)
      ↓
5. 의사결정
   |Z| > 1.96 → H0 기각
```

```text
[ 기각역 기반 판정 흐름 ]

대립가설의 방향 확인
        ↓
양측 : |Z|와 임계값 비교
단측 : Z와 한쪽 임계값 비교
        ↓
기각역 안 : 귀무가설 기각
기각역 밖 : 귀무가설 유지
```

- **기각역** (Rejection Region) : 귀무가설을 기각하게 되는 검정통계량 값의 범위.
- **대립가설** ($H_1$, Alternative Hypothesis) : 귀무가설이 기각될 때 채택되는 주장.
- **유의수준** ($\alpha$) : 귀무가설이 참인데 기각하는 제1종 오류의 허용 한계.
- p-값(p-value)의 활용 : 관측된 유의확률과 유의수준의 비교는 기각역 판정과 동일한 결론.

## Ⅳ. 양측 검정과 단측 검정의 비교

- 핵심 요약 : 대립가설의 방향 설정에 따라 기각역 위치와 임계값, 활용 상황이 달라짐.

| 구분 | 양측 검정 | 단측 검정 |
| --- | --- | --- |
| 대립가설 | μ ≠ μ0 | μ > μ0 또는 μ < μ0 |
| 기각역 위치 | 분포의 양쪽 꼬리 | 한쪽 꼬리 |
| 임계값 (α = 0.05) | ±1.96 | 방향에 맞는 ±1.645 |
| 적합한 질문 | 차이의 존재 여부 | 개선 또는 악화의 방향 확인 |
| 주의점 | 방향성 정보의 미제공 | 근거 없는 방향 설정 시 남용 위험 |

- 선택 기준 :
  1. 방향성 가설의 사전 근거 유무 확인.
  2. 탐색적 분석은 양측, 확증적 방향 가설은 단측의 원칙.
  3. 단측 선택은 실험 설계 단계에서의 사전 확정.

## Ⅴ. z-검정의 한계와 방안

- 핵심 요약 : 모분산 기지 가정, 정규 근사 한계, 유의성과 실질성의 혼동을 조건 점검과 보조 지표로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 모분산 기지 가정의 비현실성 | 실무에서 모분산의 미지 → 임의 가정 시 오류율 왜곡 | 표본표준편차와 자유도를 반영하는 대체 검정 전환 | 가정 명시 여부 |
| 정규 근사의 한계 | 소표본·치우친 분포 → 판정 신뢰도 저하 | 정규성 진단 후 **비모수 검정** (Nonparametric Test) 대체 | 정규성 진단 결과 |
| 유의성과 실질성의 혼동 | 대표본에서 미세 차이도 유의 판정 | **효과 크기** (Effect Size)와 신뢰구간의 병행 평가 | 효과 크기 |

## Ⅵ. z-검정에 대한 기술사적 제언

- 핵심 요약 : 실험 설계 표준, 오류율 통제 절차, 보고 양식의 조직적 정비 필요.
- 설계 표준 : 실험 플랫폼 운영 조직이 지표별 검정 절차를 실험 설계서 양식으로 표준화.
- 오류 통제 : 다중 지표·변형 비교 시 제1종 오류 누적을 막는 보정 절차의 판정 파이프라인 내장.
- 보고 표준 : 유의 여부와 함께 효과 크기와 신뢰구간의 병기 리포트 양식 운영.

## Ⅶ. 결론

- 핵심 요약 : z-검정은 대표본과 모분산 기지 조건에서 쓰는 모수적 검정의 기준 기법.
- 전제 조건 점검과 효과 크기 병행이 통계적 의사결정 신뢰성의 조건.
