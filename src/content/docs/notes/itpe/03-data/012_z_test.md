## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **z-검정**

## 30초 인출

- 본질: z-검정은 모집단 분산을 알거나 표본이 충분히 클 때 표본 평균(또는 비율)이 기준값과 다른지 표준정규분포로 판정하는 가설검정
- 메커니즘: 귀무가설에서 검정통계량 z = (표본평균 − 기준값) / 표준오차를 계산해 유의수준의 기각역이나 p값과 비교
- 통찰: 모분산을 모르는 작은 표본에 z-검정을 쓰면 표준오차가 과소 추정되어 결론이 과신되므로 표본 크기와 모분산 지식 여부로 z와 t를 구분

<details>
<summary>핵심 용어</summary>

- **z-검정(z-test)** : 검정통계량이 표준정규분포를 따른다고 보고 수행하는 가설검정
- **귀무가설(H₀)·대립가설(H₁)** : 검정의 기준이 되는 주장과 입증하려는 주장
- **표준오차(Standard Error)** : 표본평균이 표본마다 변동하는 정도. σ/√n
- **z통계량** : 표본통계량과 기준값의 차이를 표준오차로 나눈 값
- **p값** : 귀무가설이 참일 때 관측 결과만큼 극단적인 결과가 나올 확률
- **유의수준(α)** : 참인 귀무가설을 기각하는 오류를 허용하는 기준
- **t-검정** : 모분산을 모를 때 표본분산으로 대체하는 평균 검정
- **중심극한정리** : 표본이 크면 표본평균이 정규분포에 가까워진다는 정리

</details>

## 2~4교시 25점 답안

## Ⅰ. z-검정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **z-검정** 은 검정통계량이 표준정규분포를 따른다고 보고 평균·비율을 기준값과 비교하는 가설검정 |
| 목적 | 표본으로 모집단 평균이 기준과 다른지 통계적으로 판단 |

## Ⅱ. 특징과 적용 조건

| 특징 | 의미 |
|---|---|
| 표준정규분포 사용 | 검정통계량을 z 분포와 비교 |
| 모분산을 알거나 큰 표본 | 표준오차 계산의 전제 |
| 중심극한정리 활용 | 표본이 크면 표본평균이 정규분포에 근사 |

## Ⅲ. 검정 절차

```text
가설 설정 (H₀: μ = μ₀, H₁: μ ≠ μ₀)
        ↓
유의수준 α 결정 (예: 0.05)
        ↓
z = (x̄ − μ₀) / (σ/√n) 계산
        ↓
|z| > 1.96 (α=0.05, 양측) 또는 p < α ?
    ├─ 예 → H₀ 기각
    └─ 아니오 → H₀ 기각하지 못함
```

## Ⅳ. z-검정과 t-검정의 비교

| 구분 | z-검정 | t-검정 |
|---|---|---|
| 모분산 | 알거나 큰 표본 | 모름(표본분산 사용) |
| 분포 | 표준정규분포 | t 분포(자유도 n−1) |
| 표본 크기 | 크거나 분산을 알 때 | 작은 표본에도 사용 |
| 표본이 커질 때 | - | z 분포에 근접 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모분산을 모르는 작은 표본에 z 사용으로 결론 과신 | 이 경우 t-검정 사용 |
| 표본이 크더라도 독립성 위반 | 표본 추출 방법 점검 |
| p값만으로 결론 | 효과 크기와 신뢰구간 함께 제시 |

## Ⅵ. 제언

모분산 지식 여부와 표본 크기로 z와 t를 구분해 선택하고 p값과 함께 신뢰구간을 제시

```text
모분산을 아는가? ─ 예 → z-검정
                 └ 아니오 → 표본이 큼(대략 30 이상) → z 근사 가능 / 작음 → t-검정
```

| 구분 | z만 사용 | 제언: 조건별 선택 |
|---|---|---|
| 작은 표본 | 과신 | t로 보정 |
| 결과 보고 | p값 | p값 + 신뢰구간 |
