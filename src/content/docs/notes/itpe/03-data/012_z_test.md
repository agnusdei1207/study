## 지식 로드맵 내 현재 위치
```text
데이터 분석 → 가설검정 → z-검정
```

## 큰 그림과 30초 인출
```text
[H0·H1] → [α] → [가정 점검] → [z 통계량] → [p-value] → [판정·해석]
                                  └─ σ 기지 또는 대표본 근사
```
- 본질: **표준정규분포로 평균·비율의 차이가 우연한 표본변동인지 판단하는 모수 검정**
- 암기: `가-유-통-판-해` = 가설 → 유의수준 → 통계량 → 판정 → 해석
- 주의: p-value는 귀무가설이 참일 확률이 아님

## 예상문제
> z-검정의 개념·유형·절차를 설명하고 t-검정과 비교하여 적용상 고려사항을 논하시오. (25점)

## Ⅰ. 표준정규분포 기반 z-검정 개요
- 정의: 모집단 분산을 알거나 대표본 근사가 가능할 때 검정통계량을 표준정규분포와 비교하는 가설검정
- 목적: 평균·평균차·비율차가 귀무가설 값에서 유의하게 벗어났는지 판정
- 전제: 무작위·독립 표본과 적절한 분포 가정 또는 중심극한정리

## Ⅱ. 가설검정 구성요소
| 요소 | 의미 | 유의점 |
|---|---|---|
| $H_0$, $H_1$ | 귀무·대립가설 | 단측·양측 사전 결정 |
| $\alpha$ | 1종 오류 허용수준 | 데이터 확인 전 결정 |
| z·p-value | 표준오차 단위 차이·극단 확률 | 효과크기와 별도 해석 |
| 신뢰구간 | 모수의 가능한 범위 | 검정 결과와 병기 |

## Ⅲ. z-검정 유형과 통계량
```text
단일 평균: z=(X̄-μ0)/(σ/√n)
두 평균:   z=(X̄1-X̄2-Δ0)/√(σ1²/n1+σ2²/n2)
단일 비율: z=(p̂-p0)/√(p0(1-p0)/n)
```
| 유형 | 적용 예 | 핵심 |
|---|---|---|
| 단일평균 | 응답시간 SLA | 기준평균 비교 |
| 두 평균 | A/B 처리시간 | 독립집단 평균차 |
| 비율 | 전환율·불량률 | 성공/실패 비율차 |

## Ⅳ. z-검정 수행 절차
```text
① 모수 정의 → ② H0/H1·단측/양측 → ③ α → ④ 가정 점검
 → ⑤ z·p-value → ⑥ 기각 여부 → ⑦ 효과크기·신뢰구간
```
- $p\le\alpha$이면 $H_0$ 기각, 아니면 기각할 근거가 부족함
- 통계량·p-value·신뢰구간·효과크기·표본수를 함께 보고

## Ⅴ. z-검정과 t-검정 비교
| 구분 | z-검정 | t-검정 |
|---|---|---|
| 기준분포 | 표준정규 | 자유도별 t분포 |
| 분산 | 모집단 분산 기지 또는 대표본 | 모집단 분산 미지, 표본분산 추정 |
| 표본 | 대표본 중심 | 소표본 적용 가능 |
| 공통 | 독립성·분포 가정, 효과크기·신뢰구간 확인 | 동일 |

## Ⅵ. 오류와 검정력 중심 고려사항
| 문제 | 원인 | 대책 |
|---|---|---|
| 실무효과 없는 유의성 | 지나치게 큰 표본 | 효과크기·신뢰구간 병기 |
| 다중검정 거짓양성 | 많은 지표 반복검정 | 사전 가설·다중비교 보정 |
| 검정력 부족 | 작은 표본·큰 분산 | 사전 표본수 산정 |
| 가정 위반 | 종속·왜도·이상치 | 설계 보정·강건/비모수 검정 |

## Ⅶ. 통계적·업무적 유의성을 결합하는 결론
- z-검정은 차이 존재를 판정하며 의사결정에는 효과크기·비용·위험을 함께 반영
- 가설을 사전에 고정하고 신뢰구간과 재현성을 검토해 선택적 보고를 방지

## 1교시 10점 답안 발췌
```text
H0/H1 → α → 가정 → z → p-value → 판정 → 효과크기
z=(관측 통계량-귀무값)/표준오차
```
| z-검정 | t-검정 |
|---|---|
| σ 기지 또는 대표본 | σ 미지, 표본분산·자유도 사용 |
