## 연관 키워드

- z-검정(Z-Test), 귀무가설($H_0$), 대립가설($H_1$), 유의수준($\alpha$), 검정통계량, 기각역, 임계값(Critical Value)
- 표준정규분포($N(0,1)$), 중심극한정리(CLT, Central Limit Theorem), t-검정(T-Test), p-value, 효과 크기(Effect Size), 다중 비교(Multiple Testing)

## Ⅰ. z-검정의 개요

- 핵심 요약 : 모분산 인지 또는 대표본 조건에서 표준정규분포 기준으로 모평균·모비율 가설을 검정하는 모수적 기법.
- 개념 : 모집단의 분산($\sigma^2$)이 알려져 있거나 표본 크기·분포·독립성 조건 확인으로 정규 근사가 적절하여 중심극한정리(CLT)에 의해 표본평균의 분포가 정규분포를 따른다고 가정 가능할 때 사용하는 모수적 가설검정 기법, z-검정(Z-Test).
- 배경 및 필요성 : 표본 데이터만으로 모집단 모수에 대한 주장의 타당성을 객관적 확률 근거로 판정할 체계적 절차 필요.
- 주요 목적 : 표준화 검정통계량 $Z$를 표준정규분포 $N(0, 1)$의 임계값과 비교하여 귀무가설($H_0$)의 기각 여부 결정.

## Ⅱ. z-검정의 특징

- 핵심 요약 : 독립 무작위 표본, 정규성(또는 대표본), 모표준편차 인지의 3대 성립 요건과 표준정규분포 기반 판정 구조.

1. 성립 요건 1 : 표본이 모집단으로부터 독립적이고 무작위로 추출(i.i.d., independent and identically distributed)되었을 것.
2. 성립 요건 2 : 모집단이 정규분포를 따르거나 표본 크기 $n$이 대표본($n \ge 30$)일 것.
3. 성립 요건 3 : 모집단의 표준편차($\sigma$)가 알려져 있을 것, 모표준편차 미지 소표본이면 $t$-검정으로 대체.
4. 양측 검정과 단측 검정 모두 지원, 임계값 $\pm Z_{\alpha/2}$ 또는 $Z_{\alpha}$ 기준 판정.
5. 대표본 환경에서 이항분포의 정규 근사를 통한 비율 검정으로 확장 가능(A/B 테스트).

## Ⅲ. z-검정의 구조 (흐름)

- 핵심 요약 : 가설 수립→유의수준 설정→기각역 결정→통계량 계산→의사결정의 5단계 절차.

```text
[ z-검정 5단계 절차 ]
1. 가설 수립
   ── 양측 : H0: mu = mu_0 vs H1: mu != mu_0
   ── 단측 : H0: mu <= mu_0 vs H1: mu > mu_0 (우측)
          ↓
2. 유의수준(alpha) 설정
   ── alpha = 0.05 (신뢰수준 95%) 또는 0.01 (신뢰수준 99%)
          ↓
3. 임계값 및 기각역 결정
   ── alpha = 0.05 양측 검정 : Z_{alpha/2} = ±1.96
          ↓
4. 검정통계량 Z 계산
   ── 표본 데이터의 X-bar 대입
          ↓
5. 의사결정
   ── |Z| > 1.96 또는 p-value < alpha → H0 기각 (유의미한 차이 존재)
```

- 검정 유형별 검정통계량 산식.

```text
[ 단일표본 z-검정 통계량 ]                     [ 두 독립표본 z-검정 통계량 ]
          X-bar - mu_0                                 (X-bar_1 - X-bar_2) - (mu_1 - mu_2)
    Z = -------------------                     Z = ----------------------------------------
          sigma / sqrt(n)                             sqrt( sigma_1^2/n_1 + sigma_2^2/n_2 )
```

## Ⅳ. z-검정과 t-검정의 비교

- 핵심 요약 : 모분산 인지 여부와 표본 크기에 따른 기법 선택, 자유도 반영 여부가 핵심 차이.
- 모평균 검정 기법 선택 기준.

```text
[ 모평균 검정 의사결정 트리 ]
                [모분산 sigma^2을 알고 있는가?]
                         /         \
                      Yes           No
                      /               \
                 [z-검정]       [표본 크기 n >= 30?]
                                  /         \
                               Yes           No
                               /               \
                          [z-검정]          [정규성 만족?]
                       (t-검정도 무방)         /        \
                                            Yes          No
                                            /              \
                                       [t-검정]     [비모수 검정 (Wilcoxon)]
```

| 비교 항목 | z-검정 (Z-Test) | t-검정 (T-Test) |
|---|---|---|
| 기준 확률분포 | 표준정규분포 $N(0, 1)$ | Student $t$-분포 ($df = n-1$) |
| 모분산($\sigma^2$) 조건 | 모분산을 반드시 알거나 대표본($n \ge 30$) | 모분산을 모르며 표본분산($s^2$)으로 대체 |
| 자유도(Degree of Freedom) | 자유도 개념 불필요(단일 표준정규곡선) | 표본 크기 $n$에 따라 $df=n-1$ 곡선 형태 변화 |
| 꼬리(Tail) 두께 | 얇음(극단값 발생 확률 고정) | 두꺼움(표본이 작을수록 분산 불확실성 반영) |
| 현대 실무 적용도 | A/B 테스트 대규모 트래픽 클릭률 검정(비율 검정) | 산업 현장, 임상 시험, 소표본 품질 테스트 |

## Ⅴ. z-검정의 장점과 한계

- 핵심 요약 : 계산 단순성과 대규모 비율 검정 표준성의 장점, 모분산 사전 인지·소표본 왜곡·p-value 함정의 한계.
- 장점
  1. 표준정규분포표 기반의 단순하고 검증 가능한 판정 절차.
  2. 대표본 환경에서의 안정적 근사와 검정 자동화 용이성.
  3. 비율 검정으로의 자연스러운 확장을 통한 웹 서비스 실험 표준화.
- 한계점 1 : 모집단 분산($\sigma^2$) 사전 인지 가정의 비현실성
  - 한계점 : 현실의 IT(Information Technology) 엔지니어링 및 비즈니스 환경에서 모분산의 사전 정확한 인지는 불가능에 가까우며, 임의 가정 시 제1종 오류율 왜곡.
  - 해결 방안 : 모분산을 알 수 없는 소표본 환경에서는 표본표준편차($s$)와 자유도를 반영하는 스튜던트 t-검정(t-Test)으로 전면 대체.
- 한계점 2 : 중심극한정리(CLT) 기반 정규성 근사의 소표본 왜곡
  - 한계점 : $n < 30$인 소표본이거나 심하게 왜곡된(Skewed) 분포에서의 무리한 적용 시 유의확률($p$-value) 신뢰도 상실.
  - 해결 방안 : 샤피로-윌크(Shapiro-Wilk) 검정으로 정규성 사전 검증, 정규성 만족 불가 시 맨-휘트니 U 검정(Mann-Whitney U Test) 등 비모수 검정 적용.
- 한계점 3 : 대규모 빅데이터($n > 100만$) 환경에서의 사소한 차이 과대 유의화(p-value 함정)
  - 한계점 : 표본 크기의 극단적 증가로 분모의 표준오차($\sigma/\sqrt{n}$)가 0에 수렴, 실질적 비즈니스 의미가 없는 미세 차이의 통계적 유의 판정 위험.
  - 해결 방안 : $p$-value 단독 판정 지양, 효과 크기(Effect Size, Cohen's d)와 95% 신뢰구간(CI, Confidence Interval)의 실질적 유의성(Practical Significance) 복합 평가.

## Ⅵ. z-검정에 대한 기술사적 제언

- 핵심 요약 : A/B 테스트 파이프라인 내장과 다중 비교 오류율 통제 체계 구축.
- 대규모 A/B 테스트에서의 z-검정(비율 검정) : 웹·앱 서비스의 클릭률(CTR, Click-Through Rate)과 전환율(CVR, Conversion Rate) 비교 시 수십만 건의 대표본이 동원되므로, 이항분포의 정규 근사를 활용한 두 표본 z-비율 검정(Z-Proportion Test)을 파이프라인에 탑재한 자동 통계 판정 구현.
- 다중 비교(Multiple Testing) 문제 통제 : 여러 변형(A/B/n 테스트)의 동시 z-검정 시 제1종 오류($\alpha$)가 누적 팽창하므로, 본페로니 교정(Bonferroni Correction) 또는 FDR(False Discovery Rate) 통제 기법 병행 필요.

## Ⅶ. 결론

- 핵심 요약 : z-검정은 대표본·모분산 인지 조건의 모수적 검정 표준이나, 조건 위배 시 대체 기법과 실질적 유의성 판단이 수반되어야 하는 기법.
- 요약 : 5단계 절차와 표준정규분포 임계값 비교를 통한 귀무가설 기각 여부의 객관적 판정.
- 시사점 : t-검정·비모수 검정 전환 기준과 효과 크기 기반 복합 평가를 통한 왜곡 없는 통계 의사결정 체계 구축 필요.
