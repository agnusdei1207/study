## 30초 인출

- 본질: 오피니언 마이닝은 텍스트에서 의견의 대상과 그에 대한 평가·감정을 식별하는 분석
- 메커니즘: 문장에서 평가 대상(개체·속성)을 찾아 그것을 평가하는 표현을 연결하고 긍정·부정·중립을 판정해, 속성별 의견을 집계하고 원문과 대조
- 통찰: 한 문장에 상반된 평가가 섞이므로 문서 전체 점수 하나로 합치면 개선 대상이 사라져, 속성 단위로 분석하고 집계 점수가 원문 근거로 되돌아갈 수 있게 관리

- **속성 기반 분석(Aspect-based)** : 속성별로 감성을 판정

## 2~4교시 25점 답안

## Ⅰ. 오피니언 마이닝의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **오피니언 마이닝** 은 텍스트에서 의견의 대상과 평가·감정을 식별하는 분석 |
| 목적 | 비정형 의견을 구조화해 제품·서비스 판단 지원 |

## Ⅱ. 특징

| 특징 | 분석 단위 | 주의 |
|---|---|---|
| 평가 대상 분리 | 개체와 세부 속성 | 같은 문장에 상반된 평가 가능 |
| 문맥 의존 | 부정·반어·비교 표현 | 단어 극성만으로 결론 불가 |
| 근거 추적 | 원문·작성 시점·집계 | 요약 점수에서 원문으로 복귀 가능해야 함 |

## Ⅲ. 분석 절차

```text
리뷰 문장 → 대상·속성 식별 → 평가 표현 연결 → 긍정·부정·중립 판정 → 속성별 집계·원문 대조
```

```text
"화면은 선명하지만 앱은 자주 멈춘다"
  ├ 화면 ─ "선명" → 긍정
  └ 앱 안정성 ─ "자주 멈춤" → 부정
문서 전체 점수 하나로 합치면 개선 대상이 사라짐
```

| 요소 | 확인 정보 | 예 |
|---|---|---|
| 개체 | 평가 대상 | 모바일 앱 |
| 속성 | 개체의 평가 항목 | 로그인·화면·응답속도 |
| 감성 | 속성에 대한 평가 | 긍정·부정·중립 |
| 맥락 | 부정·반어·비교·시점 | "빠르긴 하지만 자주 끊긴다" |

## Ⅳ. 문서 단위와 속성 기반 분석 비교

| 구분 | 문서 단위 | 속성 기반 |
|---|---|---|
| 결과 | 문서 전체 감성 | 속성별 감성 |
| 장점 | 경향 파악이 단순 | 상반된 평가 분리 |
| 유의점 | 복합 의견이 하나의 점수에 묻힘 | 속성 표현과 감성 대상 연결 오류 점검 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 반어·부정 범위·도메인 용법이 단순 사전과 다름 | 문맥 포함 표본을 주기 검토하고 도메인 기준 보완 |
| 학습 자료와 실제 언어의 차이로 품질 저하 | 시간·집단별 평가 자료로 오류 사례 재평가 |
| 집계 점수가 원문 맥락 없이 의사결정에 쓰임 | 원문 근거·분석 버전 연결, 민감한 조치 전 사람 검토 |

## Ⅵ. 제언

속성 기반 분석으로 개선 대상을 분리하고 집계 점수를 원문 근거와 연결해 운영

```text
속성 추출 → 속성별 극성 판정 → 집계 → 원문 근거 연결 → 오류 표본 재평가
```

| 구분 | 문서 단위 점수 | 제언: 속성별 분석 |
|---|---|---|
| 개선 대상 | 불명확 | 속성 단위 파악 |
| 근거 | 점수만 | 원문 연결 |
