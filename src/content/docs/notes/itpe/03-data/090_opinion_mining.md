## 연관 키워드

**오피니언 마이닝(Opinion Mining)**, **감성 분석(Sentiment Analysis)**, **속성 기반(ABSA)**, **VoC**, **BERT**, **LLM**, **NLP**

## Ⅰ. 개요

- 핵심 요약 : **오피니언 마이닝**은 텍스트에 표현된 주관적 의견·감정·태도를 자동 추출·분류하는 NLP 기반 텍스트 마이닝.
- 목적 : 제품 평판, 여론, 고객 VoC(Voice of Customer) 자동 분석.
- 배경 : 소셜 미디어·리뷰 폭증으로 수작업 의견 분석 불가 → 자동화 필요.
- 특징 : 감성 어휘·ML·DL·LLM으로 진화, 문장·문서·속성 단위 분석.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **문맥 이해**와 **속성 단위 분석**으로 세밀한 여론 구조 파악 가능.
- **자동 추출** : 대규모 텍스트에서 의견·감정·태도 자동 분류.
- **속성 기반(ABSA)** : 제품별 세부 속성(배터리, 카메라 등) 단위 감성 분리.
- **문맥 이해** : BERT·LLM으로 부정어 도치·비꼼 해석.
- **실시간 모니터링** : 여론 변화 추적 및 위기 감지.
- **도메인 적응** : 미세조정으로 특정 분야 정밀도 향상.

## Ⅲ. 분석 레벨 및 방법론 흐름

- 핵심 요약 : **문서 → 문장 → 속성** 레벨과 **사전 → ML → DL → LLM** 기술 진화.
- 의견 5요소 : 개체(Target), 속성(Aspect), 극성(Orientation), 표현자(Holder), 시점(Time).

```text
[ 오피니언 5대 구성 요소 (Bing Liu) ]

Opinion = ( g, s, o, h, t )
  g : 대상 개체 (스마트폰 모델)
  s : 세부 속성 (배터리, 카메라)
  o : 극성 (긍정/부정/중립)
  h : 표현자 (작성자)
  t : 시점 (작성일)
```

```text
[ 기술 진화 계통 ]

1세대 : 감성 어휘 사전 (SentiWordNet)
2세대 : ML 분류 (TF-IDF + NB/SVM)
3세대 : 양방향 문맥 DL (BERT, RoBERTa)
4세대 : LLM Zero-shot 감성 분석
```

- 분석 레벨 : 문서(전체 극성) / 문장(주관성·극성) / 속성(세부 평가).
- 언어학적 난제 : 부정어 도치, 반어법·비꼼, 신조어.

## Ⅳ. 분석 접근법 비교

- 핵심 요약 : **사전 기반 vs ML vs DL vs LLM** 및 **분석 레벨** 비교.

| 항목 | 사전 기반 | ML (TF-IDF+SVM) | DL (BERT) | LLM |
|---|---|---|---|---|
| 문맥 이해 | 약함 | 중간 | 강함 | 매우 강함 |
| 비꼼 처리 | 불가 | 제한 | 가능 | 우수 |
| 도메인 적응 | 수동 | 재학습 | 미세조정 | 프롬프트 |
| 비용 | 낮음 | 중간 | 높음 | 높음 |

- 문서/문장/속성 레벨은 분석 목적과 데이터 구조에 따라 선택.

## Ⅴ. 한계와 방안

- 핵심 요약 : **비꼼·도메인 편향·스팸 오염**을 DL·미세조정·필터링으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 비꼼·반어 오판 | 규칙·사전 기반으로 문맥 비꼼 미인식 | BERT/RoBERTa/LLM 도입, 도메인 미세조정 | 정확도, F1 |
| 도메인 편향 | 단어 감성이 도메인별로 상이 | 도메인 적응, ABSA 속성 분리 | 도메인별 F1 |
| 스팸·봇 오염 | 광고성 리뷰로 여론 왜곡 | SimHash 중복 제거, 봇 필터링 | 스팸 탐지율 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **ABSA·시맨틱 필터링·도메인 적응**으로 실무 적용 정밀도 향상.
- ABSA 도입 : 속성별 만족도 매트릭스 산출 (가격·성능·배송 등).
- 스팸 필터링 : 중복 해싱 + 사용자 행태 기반 봇 탐지.
- 도메인 미세조정 : 사내 말뭉치로 모델 지속 개선.

## Ⅶ. 결론
