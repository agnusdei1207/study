## 지식 로드맵 내 현재 위치

자료처리·데이터 → 공간 데이터 → **공간 연산자**

## 30초 인출

- 본질: 공간 연산자는 공간 객체의 관계·거리·형상을 판정하거나 계산하는 연산
- 메커니즘: 좌표계(SRID)와 거리 단위를 확인한 뒤 공간 인덱스의 경계상자(MBR) 중첩으로 후보를 좁히고, 후보에 실제 형상의 위상·거리 연산(ST_Intersects·ST_DWithin 등)을 적용해 결과를 확정
- 통찰: 경계상자 검색은 후보만 줄이는 단계이고 좌표계나 함수를 잘못 고르면 빠른 질의도 틀리므로 SRID·단위를 검증하고 실행계획으로 인덱스 사용과 정밀 판정 단계를 확인

<details>
<summary>핵심 용어</summary>

- **공간 연산자(Spatial Operator)** : 공간 객체 사이의 관계·거리·형상을 다루는 연산
- **SRID** : 좌표계를 식별하는 번호
- **MBR(경계상자)** : 객체를 감싸는 최소 경계 사각형
- **위상 판정** : 교차·포함·내부 같은 공간 관계 판정(ST_Intersects·ST_Contains·ST_Within)
- **거리 연산** : ST_Distance(거리값), ST_DWithin(반경 내 여부)
- **형상 구성** : ST_Buffer·ST_Intersection·ST_Union으로 새 형상 생성
- **공간 인덱스(GiST 등)** : MBR 기반으로 후보를 찾는 인덱스

</details>

## 2~4교시 25점 답안

## Ⅰ. 공간 연산자의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **공간 연산자** 는 공간 객체의 관계·거리·형상 결과를 판정하거나 계산하는 연산 |
| 목적 | 위치·접촉·포함·근접 조건에 맞는 공간 데이터 질의·분석 |

## Ⅱ. 특징

| 특징 | 질의상 의미 |
|---|---|
| 좌표계 의존 | SRID와 거리 단위가 맞아야 결과를 해석 가능 |
| 2단계 판정 | 경계상자 필터는 후보만 좁히고 실제 형상으로 관계 확인 |
| 계획 의존 | 인덱스가 있어도 사용이 보장되지 않아 실행계획 확인 필요 |

## Ⅲ. 질의 처리 절차

```text
질의 geometry·SRID·거리 단위 확인
   ↓ 옵티마이저가 인덱스 사용 여부 평가
공간 인덱스의 MBR 중첩 후보 검색 (거짓 양성 포함 가능)
   ↓
실제 형상으로 ST_Intersects·ST_DWithin 등 정밀 판정
   ↓ 조건을 만족한 객체만 반환
```

## Ⅳ. 연산자 종류

| 종류 | 대표 연산 | 결과 |
|---|---|---|
| 위상 판정 | ST_Intersects, ST_Contains, ST_Within | 관계의 참·거짓 |
| 거리 | ST_Distance, ST_DWithin | 거리값 / 반경 내 여부 |
| 형상 구성 | ST_Buffer, ST_Intersection, ST_Union | 새 공간 형상 |

| 점검 | 기준 |
|---|---|
| 좌표계 | 두 geometry의 SRID 일치, geography는 단위·계산 모형 확인 |
| 연산 선택 | 거리 임계 조건은 ST_DWithin, 정확한 거리값은 ST_Distance |
| 실행계획 | EXPLAIN으로 인덱스 사용 확인 |
| 정확성 | 후보 검색 뒤 정밀 판정 단계 존재 여부 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 좌표계·함수를 잘못 골라 거리·관계 결과 오류 | SRID·단위 검증, 대표 질의 결과 표본 대조 |
| MBR 후보를 최종 관계로 오인 | 정밀 판정 포함 여부 확인, 경계 교차 사례 시험 |
| 인덱스가 있어도 전수 스캔 선택 | 함수·선택도·인덱스 상태 확인, 대표 부하 비교 |

## Ⅵ. 제언

좌표계와 단위를 먼저 통일하고, 후보 검색과 정밀 판정이 실행계획에 모두 나타나는지 확인

```text
SRID·단위 통일 → 연산자 선택 → EXPLAIN으로 인덱스·정밀 판정 확인 → 경계 사례 시험
```

| 구분 | 인덱스 존재만 신뢰 | 제언: 계획·결과 검증 |
|---|---|---|
| 성능 | 전수 스캔 가능 | 사용 여부 확인 |
| 정확성 | 좌표계 오류 | SRID·단위 검증 |

## 출제 이력과 검증 출처

- Q-net 기출 원문에서 직접 묻는 문항 없음
- PostGIS 공식 문서(Spatial Relationships, Spatial Indexing)
