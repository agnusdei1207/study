## 30초 인출

- 본질: 빅데이터는 기존 처리 방식으로 비용·시간·품질 요구를 충족하기 어려운 규모·속도·다양성의 데이터를 다루는 접근
- 메커니즘: 원천 데이터를 배치·스트림으로 수집·저장하고 품질·형식을 변환해 분산 처리한 뒤 분석·서비스로 제공하며, 출처·계보·접근권한·품질 관측을 전 단계에 적용
- 통찰: 데이터가 쌓여도 출처·품질·접근 책임이 없으면 재현과 활용이 어려우므로 업무 목적과 보유 기간을 정해 저장·처리 구조(람다·카파, DW·레이크)를 선택하고 관리 규칙을 파이프라인에 포함

<details>
<summary>핵심 용어</summary>

- **빅데이터(Big Data)** : 규모·속도·다양성 때문에 새로운 처리 방식이 필요한 데이터
- **3V·5V** : Volume·Velocity·Variety (+ Veracity·Value)
- **람다 아키텍처** : 배치 레이어와 실시간 레이어를 분리해 결과를 병합하는 구조
- **카파 아키텍처** : 재생 가능한 이벤트 로그와 단일 스트림 처리 경로를 중심으로 하는 구조
- **데이터 레이크·레이크하우스** : 원천을 보존해 읽을 때 해석하는 저장소 / 쓰기 시 제약도 적용하는 결합 구조
- **스키마 온 리드** : 저장 후 읽을 때 스키마를 적용하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 빅데이터의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **빅데이터** 는 기존 방식으로 비용·시간·품질 요구를 충족하기 어려운 규모·속도·다양성의 데이터를 다루는 접근 |
| 목적 | 수집·저장·처리·분석으로 데이터 활용 가치와 품질 관리 지원 |

## Ⅱ. 특징

| 특성 | 설계 영향 |
|---|---|
| Volume·Velocity | 저장·처리 용량과 유입 지연 목표를 함께 정함 |
| Variety | 정형·반정형·비정형 형식과 해석 시점 구분 |
| Veracity | 출처·품질·편향을 확인해 신뢰성 관리 |
| Value | 처리량이 아니라 업무 의사결정·서비스 효과로 성과 판단 |

## Ⅲ. 처리 체계

```text
업무 목적·보존 기준
 ↓
원천 DB·로그·센서 → 배치/스트림 수집 → 원천 저장 → 품질·형식 변환 → 분산 처리 → 분석·서비스
출처·계보·접근권한·품질 관측 ─── 전 단계에 적용
```

## Ⅳ. 아키텍처와 저장소 비교

| 비교 | 람다 | 카파 |
|---|---|---|
| 철학 | 배치와 실시간 레이어 분리 | 재생 가능한 이벤트 중심의 단일 처리 경로 |
| 재처리 | 보존한 원천을 배치로 재처리 | 이벤트를 같은 경로로 다시 읽음 |
| 복잡도 | 두 경로의 결과 병합·정합성 | 이벤트 보존·재생·상태 관리 |
| 제약 | 배치·저지연 요구가 함께 있을 때 | 이벤트 보존 기간과 순서·중복 처리 설계 |

| 비교 | 전통적 DW | 데이터 레이크·레이크하우스 |
|---|---|---|
| 데이터 형태 | 정형 분석·보고에 최적화된 관리 모델 | 정형·반정형·비정형 원천 보존·탐색 |
| 스키마 시점 | 적재 전 스키마 적용이 일반적 | 원천 보존 후 읽을 때 해석(레이크하우스는 쓰기 시 제약도 가능) |
| 확장성 | 병렬·클라우드 DW도 수평 확장 | 분산 처리 가능하나 편향·네트워크·메타데이터가 효율 제한 |
| 사용자 | 정형 분석·보고 중심 | 탐색·분석·학습 중심(범위는 겹칠 수 있음) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 출처·품질·접근 책임이 없으면 재현·활용 곤란 | 목적·보유기간·품질 규칙·접근 통제를 파이프라인에 포함 |
| 배치·스트림 이중 경로의 집계 기준 불일치 | 공통 이벤트 정의·검증 기준, 병합 결과 대조 |
| 원천 무제한 적재로 저장·질의 비용 증가 | 활용 목적·보존 기간·접근 빈도로 계층화·폐기 |

## Ⅵ. 제언

업무 목적과 지연 요구로 처리 구조를 정하고 거버넌스를 파이프라인에 내장

```text
지연 요구 낮음·정형 분석 → DW / 원천 보존·탐색 → 레이크(하우스) / 실시간 → 스트림(카파) 또는 람다
```

| 구분 | 무제한 적재 후 활용 | 제언: 목적·거버넌스 기반 |
|---|---|---|
| 재현성 | 낮음 | 출처·계보 관리 |
| 비용 | 증가 | 계층화·폐기 |
