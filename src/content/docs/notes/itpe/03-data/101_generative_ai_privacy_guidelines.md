## 연관 키워드

**생성형 AI**, **개인정보보호**, **Privacy by Design**, **차분 프라이버시(Differential Privacy)**, **머신 언러닝(Machine Unlearning)**, **RAG**, **Zero Data Retention**, **LLM**

## Ⅰ. 개요

- 핵심 요약 : **생성형 AI 개인정보보호**는 LLM 라이프사이클 전반의 프라이버시 바이 디자인 원칙 적용.
- 목적 : 동의 없는 개인정보 학습·암기·추론 누출 방지.
- 배경 : 웹 크롤링·프롬프트 데이터 학습으로 개인정보 노출 위험 증대.
- 특징 : 4단계 라이프사이클 통제, 머신 언러닝, RAG 전환.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **라이프사이클 4단계**로 수집·학습·튜닝·서빙 각 단계 통제.
- **Privacy by Design** : 기획부터 개인정보 보호 내재화.
- **PII 탐지·가명처리** : NER·정규식으로 민감정보 필터링.
- **차분 프라이버시** : DP-SGD로 학습 단계 보호.
- **출력 가드레일** : 프롬프트 필터링·출력 마스킹.
- **삭제권 보장** : 머신 언러닝으로 정보주체 권리 행사.

## Ⅲ. AI 라이프사이클 흐름

- 핵심 요약 : **기획 → 수집·학습 → 튜닝 → 서빙** 4단계 통제.
- 단계별 위협 : 웹 스크래핑 PII, 암기 효과, 프롬프트 입력, 출력 유출.

```text
[ 생성형 AI 개인정보보호 4단계 ]

[1. 기획·설계] PIA, 적법 근거 검토
        |
        v
[2. 수집·학습] PII 탐지, 가명처리, 비식별 필터링
        |
        v
[3. 모델 튜닝] 차분 프라이버시, 파인튜닝 격리
        |
        v
[4. 서비스·운영] 프롬프트 필터링, 가드레일, 삭제권 보장
```

## Ⅳ. 단계별 위협·대응 비교

- 핵심 요약 : **수집·학습·프롬프트·출력** 단계별 위협과 대응.

| 단계 | 주요 위협 | 대응 방안 |
|---|---|---|
| 데이터 수집 | PII 무단 수집 | NER·정규식 마스킹, robots.txt 준수 |
| 모델 학습 | 암기 효과 | 차분 프라이버시, 합성 데이터 |
| 프롬프트 입력 | 기밀·PII 입력 | DLP 게이트웨이, 옵트아웃 |
| 출력·서빙 | 프롬프트 인젝션, 유출 | NeMo Guardrails, 출력 마스킹 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **웹 크롤링 PII·인젝션·삭제권**을 필터링·가드레일·RAG로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 웹 크롤링 PII | 방대한 텍스트 내 PII 필터링 실패 → 암기 | NER·정규식 전처리, 차분 프라이버시 | PII 탐지율 |
| 프롬프트 인젝션 | 적대적 공격으로 데이터 유출 | 가드레일, 출력 마스킹 | 차단율 |
| 삭제권 행사 | 가중치에서 특정 정보 선택 제거 불가 | SISA 언러닝, RAG 전환으로 DB 삭제 통제 | 삭제 처리 시간 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **ZDR 계약·RAG 전환·가드레일**로 안전한 AI 도입.
- ZDR (Zero Data Retention) 계약 : 프롬프트·문서가 학습 데이터로 사용되지 않도록 계약 명문화.
- RAG 전환 : 민감 데이터를 가중치에 각인하지 않고 벡터 DB에서 권한 기반 검색.
- 가드레일 배치 : NeMo Guardrails, Llama Guard로 입력/출력 통제.

## Ⅶ. 결론

- 핵심 요약 : 생성형 AI 개인정보보호는 **라이프사이클 전 단계 통제**와 RAG·ZDR이 핵심.
- 답안에는 4단계 체계, 머신 언러닝, 한계·대응, 실무 제언을 연결.
