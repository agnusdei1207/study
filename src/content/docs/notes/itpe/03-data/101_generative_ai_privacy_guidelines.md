## 30초 인출

- 본질: 생성형 AI 개인정보 처리 안내서는 생성형 AI 개발·활용에서 개인정보 보호법의 적용과 안전조치를 생애주기 4단계(목적 설정·전략 수립·학습 및 개발·적용 및 관리)별로 안내하는 개인정보보호위원회의 지침
- 메커니즘: 목적과 처리 근거를 정하고 개발 방식(서비스형 LLM·기성 모델·자체 개발)별로 처리 주체와 위탁·이전 관계를 확인한 뒤, 학습·개발 단계의 안전조치와 적용·관리 단계의 정보주체 권리 보장을 운영하고 변경 시 재검토
- 통찰: 학습·미세조정·입력·출력 단계마다 처리 주체와 목적이 달라지므로 처음 수집 목적만으로 전 과정을 정당화하지 않고, 데이터·모델이 바뀔 때마다 처리 근거와 보호조치를 다시 확인

## 2~4교시 25점 답안

## Ⅰ. 생성형 AI 개인정보 처리 안내서의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 개인정보위가 생성형 AI 개발·활용에서 개인정보 보호법 적용과 안전조치를 생애주기별로 안내한 지침 |
| 목적 | 개인정보 처리의 불확실성을 줄이고 생애주기 전반의 자율적 보호 역량 강화 |

## Ⅱ. 특징

| 특징 | 처리 장면 | 보호상 의미 |
|---|---|---|
| 단계별 재사용 | 학습·미세조정·입력·출력 | 처음 수집 목적만으로 전 과정을 설명하지 못함 |
| 복수 주체 | 개발자·공급자·서비스 운영자 | 각 주체의 처리 범위·책임 확인 |
| 변화 가능성 | 데이터·모델·기능 변경 | 출시 뒤에도 권리·위험 재검토 |

## Ⅲ. 생애주기 4단계

```text
① 목적 설정 → ② 전략 수립(자체 개발 / 기성 모델 / 서비스형 LLM)
   → ③ 학습·개발(수집·가공·접근통제·출력 유출 시험) → ④ 적용·관리(권리 보장·사고·변경)
   ↺ 데이터·기능 변경 시 처리 근거·보호조치 갱신
```

| 단계 | 핵심 관리 내용 |
|---|---|
| 목적 설정 | 처리 목적, 개인정보 유형·출처, 처리 근거·필요성 |
| 전략 수립 | 개발 방식별 위험 완화책 |
| 학습·개발 | 데이터 오염·탈옥 등 위험에 대한 다층 안전조치 |
| 적용·관리 | 정보주체 권리 보장, 운영 결과·사고·변경 관리 |

## Ⅳ. 개발 방식별 위험과 거버넌스

| 방식 | 주요 쟁점 | 점검 방향 |
|---|---|---|
| 서비스형 LLM | 입력의 수집·저장·제공 및 학습 활용 여부 | 계약·처리방침·설정과 실제 데이터 흐름 확인 |
| 기성 모델 활용 | 사전학습·미세조정 자료의 출처와 영향 | 출처·처리 근거·모델 위험·안전조치 검토 |
| 자체 개발 | 학습자료·개발환경·서비스 전 과정 | 접근통제·보유기간·시험·운영 감시 |

| 거버넌스 | 운영 내용 |
|---|---|
| 책임 | CPO와 서비스·모델·데이터 담당자의 역할·승인 경로 |
| 권리 | 처리방침, 권리 요청 접수·검토·회신, 이의제기 |
| 데이터 관리 | 출처·목적·접근·보유·파기·위탁·국외이전 기록 |
| 개선 | 모델·데이터 변경 시 재검토 |

머신 언러닝은 기술적 보완 수단이며 삭제 요구 대응의 법적 요건은 별도로 확인.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 공급·학습·운영의 처리 주체가 달라 책임 누락 | 데이터 흐름·위탁 관계·책임자·변경 이력 기록, 단계별 재검토 |
| 서비스형 모델에 입력한 개인정보의 보관·학습 활용 불명확 | 공급자 계약·설정·처리방침과 실제 전송·보관 범위 확인 |
| 변경 뒤 정보주체 권리 대응 누락 | 변경 승인 시 권리 요청·삭제·정정 경로와 기술적 한계 재점검 |

## Ⅵ. 제언

개발 방식을 정하기 전에 처리 주체와 데이터 흐름을 확인하고, 모델·데이터 변경 때마다 처리 근거와 권리 대응을 재검토

```text
목적·근거 → 방식별 데이터 흐름·위탁 확인 → 안전조치 → 권리 대응 → 변경 시 재검토
```

| 구분 | 최초 수집 목적으로 일괄 활용 | 제언: 단계별 근거·재검토 |
|---|---|---|
| 처리 근거 | 단계별 미확인 | 단계별 확인 |
| 권리 대응 | 변경 후 누락 | 변경 시 점검 |

## 출제 이력과 검증 출처

- Q-net 기출 원문에서 직접 묻는 문항 없음(주제 목록상 시사·트렌드 항목)
- 개인정보보호위원회, 생성형 인공지능(AI) 개발·활용을 위한 개인정보 처리 안내서(2025.8.)
