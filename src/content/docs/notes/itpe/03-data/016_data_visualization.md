## 지식 로드맵 내 현재 위치
```text
데이터 분석 → 분석 결과 전달 → 데이터 시각화
```

## 큰 그림과 30초 인출
```text
[질문·사용자] → [데이터·품질] → [비교축] → [시각 인코딩]
     → [차트·상호작용] → [인지·접근성 검증] → [의사결정]
```
- 본질: **데이터의 관계·패턴·이상을 사람이 빠르게 인지하도록 위치·길이·색·형태로 변환하는 표현 과정**
- 원칙: 질문에 맞는 비교축을 먼저 정하고 장식보다 정확성·인지성·접근성을 우선

## 예상문제
> 데이터 시각화의 목적·절차·시각 인코딩을 설명하고 차트 선정 원칙과 대용량·접근성 고려사항을 논하시오. (25점)

## Ⅰ. 데이터에서 판단으로 연결하는 시각화 개요
- 정의: 수치·범주·관계를 시각적 속성으로 부호화해 탐색·설명·의사결정을 지원하는 활동
- 목적: 비교, 추세, 분포, 구성, 관계, 공간 패턴의 신속한 인지
- 구분: 탐색형은 가설 발견, 설명형은 핵심 메시지 전달에 중점

## Ⅱ. 정확한 시각화를 위한 원칙
| 원칙 | 내용 | 금지 사례 |
|---|---|---|
| 정확성 | 축·단위·집계·표본을 명시 | 잘린 축으로 차이 과장 |
| 단순성 | 데이터 대비 잉크 비율 향상 | 3D·과도한 장식 |
| 일관성 | 색·척도·정렬 규칙 통일 | 화면마다 의미 변경 |
| 접근성 | 색 외 모양·레이블·대체텍스트 | 적록색만으로 구분 |

## Ⅲ. 분석 질문별 차트 선택
| 질문 | 적합 표현 | 핵심 주의 |
|---|---|---|
| 항목 비교 | 막대·점 그래프 | 공통 기준선·정렬 |
| 시간 추세 | 선·영역 | 시간 간격·결측 |
| 분포 | Histogram·Box plot | Bin·이상치 |
| 관계 | 산점도·Heatmap | 중첩·상관/인과 구분 |
| 구성 | 누적막대·Treemap | 항목 수 제한 |
| 공간 | 지도 | 면적 왜곡·정규화 |

## Ⅳ. 시각화 설계 절차
```text
① 사용자·질문 → ② 데이터 수집·품질 → ③ 비교축·지표
 → ④ 인코딩·차트 → ⑤ Prototype → ⑥ 정확성·인지·접근성 검증 → ⑦ 운영
```
- 위치·길이는 정량 비교에 강하고 면적·각도·색상은 정밀 비교에 불리
- Dashboard는 개요→필터→상세의 정보 탐색 흐름으로 구성

## Ⅴ. 탐색형과 설명형 시각화 비교
| 구분 | 탐색형 | 설명형 |
|---|---|---|
| 목적 | 패턴·가설 발견 | 결론·행동 전달 |
| 사용자 | 분석가 | 의사결정자·대중 |
| 구성 | 다중 관점·상호작용 | 핵심 지표·주석·서사 |
| 검증 | 분석 재현성 | 오해 가능성·행동 명확성 |

## Ⅵ. 대용량·실시간 시각화 고려사항
| 문제 | 원인 | 대책 |
|---|---|---|
| 점 중첩 | 대량 원시 데이터 | 집계·Sampling·Density 표현 |
| 지연 | 매번 전체 질의 | 사전 집계·Cache·Progressive rendering |
| 왜곡 | 분모·축·결측 미표시 | 메타데이터·주석·품질 표식 |
| 색각 장벽 | 색상 단독 인코딩 | 대비·패턴·직접 레이블 |

## Ⅶ. 예쁜 그림보다 검증 가능한 판단을 만드는 결론
- 시각화는 결론을 장식하는 단계가 아니라 질문·집계·표현을 검증하는 분석 인터페이스
- 원자료·변환식·필터·갱신시점을 함께 공개해 재현성과 신뢰성을 확보

## 1교시 10점 답안 발췌
```text
질문 → 데이터 품질 → 비교축 → 인코딩 → 차트 → 인지·접근성 검증
비교=막대 / 추세=선 / 분포=Histogram·Box / 관계=산점도
```
