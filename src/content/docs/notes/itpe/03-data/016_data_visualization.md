## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 → **데이터 시각화**

## 30초 인출

- 본질: 데이터 시각화는 데이터의 수치와 관계를 차트·지도 같은 그래픽으로 나타내 패턴과 의미를 빠르게 이해하게 하는 활동
- 메커니즘: 질문과 대상 독자를 정하고 데이터의 성격(비교·추이·분포·관계)에 맞는 차트 유형을 골라 값을 위치·길이·색 등으로 표현
- 통찰: 차트가 화려해도 전달할 메시지와 맞지 않으면 오해를 낳으므로 답하려는 질문에서 출발해 데이터 성격에 맞는 차트를 고르고 축·색을 정직하게 구성

<details>
<summary>핵심 용어</summary>

- **데이터 시각화(Data Visualization)** : 데이터를 그래픽으로 표현하는 활동
- **시각 인코딩(Visual Encoding)** : 위치·길이·면적·색 같은 시각 요소로 값을 나타내는 방법
- **대시보드(Dashboard)** : 여러 지표와 차트를 한 화면에 모은 화면
- **산점도** : 두 수치 변수의 관계를 점으로 나타낸 차트
- **히스토그램** : 수치 값의 구간별 빈도로 분포를 나타낸 차트
- **접근성(Accessibility)** : 색 구분이 어려운 사용자를 포함해 누구나 정보를 이해할 수 있는 정도

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 시각화의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 시각화** 는 데이터를 그래픽으로 표현해 패턴과 의미를 이해하게 하는 활동 |
| 목적 | 복잡한 데이터의 빠른 이해와 의사결정 지원 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 직관적 전달 | 수치 표보다 패턴 파악이 빠름 |
| 목적 지향 | 질문과 독자에 맞춘 표현 |
| 상호작용 | 필터·드릴다운으로 탐색 |

## Ⅲ. 절차와 도구

### 시각화 절차

```text
목적·독자 정의 → 데이터 수집·정제 → 차트 유형 선택 → 시각 인코딩·디자인 → 검토·공유
```

### 도구

| 유형 | 예 | 특징 |
|---|---|---|
| BI 도구 | Tableau, Power BI | 코딩 없이 대시보드 구성 |
| 프로그래밍 라이브러리 | Python(Matplotlib), D3.js | 세밀한 표현과 자동화 |
| 스프레드시트 | Excel | 간단한 분석과 보고 |

## Ⅳ. 방법: 데이터 성격별 차트

| 전달 목적 | 적합한 차트 |
|---|---|
| 범주 비교 | 막대그래프 |
| 시간에 따른 변화 | 선그래프 |
| 분포 | 히스토그램, 상자 그림 |
| 두 변수의 관계 | 산점도 |
| 구성 비율 | 누적 막대, 원(소수 항목) |
| 위치 | 지도 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 메시지와 맞지 않는 차트로 오해 유발 | 질문에서 출발해 데이터 성격별 차트 선택 |
| 축 절단·색 사용으로 왜곡 | 축 기준과 색을 정직하게 구성 |
| 색각 이상 등 접근성 문제 | 색 외에 모양·라벨 병행 |
| 대용량 데이터의 성능 저하 | 집계·샘플링 후 표현 |

## Ⅵ. 제언

답하려는 질문과 독자를 먼저 정하고 데이터 성격에 맞는 차트를 선택해 한 화면에 핵심 메시지 하나를 전달

```text
질문·독자 → 데이터 성격(비교·추이·분포·관계) → 차트 선택 → 핵심 메시지 확인
```

| 구분 | 도구 기능 중심 | 제언: 질문 중심 |
|---|---|---|
| 차트 선택 | 화려함 | 데이터 성격 |
| 메시지 | 흐려짐 | 하나로 집중 |
