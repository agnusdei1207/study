## 연관 키워드

- 데이터 시각화, 시각 인코딩, 차트 선택, 대시보드, 접근성, 오도 방지

## Ⅰ. 데이터 시각화의 개요

- 핵심 요약 : 데이터 시각화는 데이터를 시각적 표현으로 변환해 패턴·비교·추세·예외를 사람이 해석하도록 돕는 방법.
- 개념 : 데이터 시각화는 데이터를 시각적 표현으로 변환해 패턴·비교·추세·예외를 사람이 해석하도록 돕는 방법.
- 배경 및 필요성 : 대규모 수치표만으로 관계·변화·분포를 빠르게 파악하기 어려움.
- 주요 목적 : 정확하고 신속한 데이터 탐색과 의사소통 지원.

## Ⅱ. 데이터 시각화의 특징 및 장점

- 핵심 요약 : 시각 인코딩: 위치·길이·색상으로 값을 표현 → 비교·패턴 인지; 차트 목적 적합화: 시계열·분포·관계에 맞는 도식 선택 → 오해 감소; 맥락 제공: 단위·축·표본·불확실성 표기 → 해석 가능성 강화.

1. 시각 인코딩: 위치·길이·색상으로 값을 표현 → 비교·패턴 인지
2. 차트 목적 적합화: 시계열·분포·관계에 맞는 도식 선택 → 오해 감소
3. 맥락 제공: 단위·축·표본·불확실성 표기 → 해석 가능성 강화

## Ⅲ. 데이터 시각화의 구조 (흐름)

- 핵심 요약 : 질문·독자 정의 → 변수형·비교대상 파악 → 차트·인코딩 선택 → 축·맥락·접근성 검토 → 사용자 해석 평가.

```text
질문·독자 정의
  ↓
변수형·비교대상 파악
  ↓
차트·인코딩 선택
  ↓
축·맥락·접근성 검토
  ↓
사용자 해석 평가
```

- 핵심 구성 : 질문 → 변수·관계 분석

```text
질문 → 변수·관계 분석
       ├ 비교 → 막대·점
       ├ 추세 → 선
       ├ 분포 → 히스토그램·상자그림
       └ 관계 → 산점도
```

## Ⅳ. 비교: 막대그래프 / 선그래프

- 핵심 요약 : 축 처리 기준 — 막대그래프: 0 기준·범주 간격 강조; 선그래프: 시간순 연속축·결측구간 주의.

| 비교 기준 | 막대그래프 | 선그래프 |
| --- | --- | --- |
| 주요 질문 | 범주 간 값 비교 | 시간에 따른 연속 변화 |
| 축 처리 | 0 기준·범주 간격 강조 | 시간순 연속축·결측구간 주의 |
| 오용 위험 | 축 절단으로 차이 과장 | 불균일 시간간격 연결 |

## Ⅴ. 데이터 시각화의 한계와 방안

- 핵심 요약 : 시각적 왜곡·과밀 대시보드 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 시각적 왜곡 | 절단축·면적·색상 스케일이 차이를 과장 | 정직한 축·단위·기준선과 대체표 검토 | 오독률 |
| 과밀 대시보드 | 지표 과다로 핵심 패턴 소실 | 사용자 질문별 계층형 대시보드 구성 | 의사결정 소요시간 |
| 접근성 부족 | 색상만으로 구분하거나 대비가 낮음 | 색각·키보드·대체텍스트·대비 검증 | 접근성 결함 |

## Ⅵ. 데이터 시각화의 제언

- 핵심 요약 : 분석 책임자는 차트에 질문·출처·갱신시각·축 단위를 명시하고 의사결정자와 실제 과업으로 해석 오류를 검증.
- 실행 제안 : 시각화 작성자는 차트마다 단위·기준선·출처·갱신일을 표시하고 사용자 과업 기반 오독 검토 수행.

## Ⅶ. 데이터 시각화의 결론

- 핵심 요약 : 좋은 시각화는 장식을 더하는 일이 아니라 데이터의 구조를 오도 없이 전달하는 설계.
- 시사점 : 시각화의 목적은 인상적인 그림이 아니라 축·단위·불확실성을 보존한 올바른 비교와 판단.
