## 연관 키워드

**샤딩**, **수평 분할**, **샤드 키**, **핫스팟**, **라우팅**, **재분배**, **분산 트랜잭션**

## Ⅰ. 개요

- 핵심 요약 : **샤딩**은 데이터와 부하를 여러 독립 노드에 수평 분산해 단일 노드의 저장·처리 한계를 확장하는 방식이다.
- 목적 : 데이터 저장량과 읽기·쓰기 부하를 여러 노드로 나눠 처리한다.
- 적용 조건 : 단일 노드 확장, 인덱스 튜닝, 캐싱 등으로 요구 성능을 충족하기 어려울 때 복잡성과 운영 비용을 고려해 도입한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **분산 저장과 병렬 처리**로 확장성을 높이지만, 샤드 키 선택이 성능과 운영 난도를 좌우한다.
- **수평 확장** : 노드를 추가해 저장·처리 용량을 늘릴 수 있다.
- **병렬 처리** : 샤드별 쿼리를 동시에 수행할 수 있다.
- **장애 격리** : 장애 영향 범위를 해당 샤드로 제한할 수 있으나, 서비스 전체 가용성은 라우팅·복제·장애조치 설계에 달린다.
- **샤드 키 의존성** : 접근 패턴에 맞지 않는 키는 데이터 편중과 다중 샤드 조회를 일으킨다.

## Ⅲ. 샤딩 구조와 요청 흐름

- 핵심 요약 : **애플리케이션·라우터·샤드 노드**가 키 기반으로 요청을 전달하고 결과를 조합한다.

```text
[애플리케이션 요청]
        ▼
[샤드 키 추출·라우팅]
   ├─ 키 단건 조회 → 대상 샤드
   └─ 범위·집계 질의 → 관련 샤드 병렬 조회
                         ▼
                 [결과 병합·반환]
                         ▼
                 [지표·편중 감시]
```

- 키 결정 시 조회·갱신 패턴, 분포 편향, 확장·재배치 비용, 조인 관계를 함께 고려한다.
- 주문과 주문상세처럼 함께 접근되는 데이터는 같은 분할 기준을 쓸지 검토하되, 특정 고객에 데이터가 쏠리지 않는지 확인한다.

## Ⅳ. 분할 방식 비교

- 핵심 요약 : **균등 분산, 범위 질의, 노드 증설 시 재배치량**을 기준으로 분할 방식을 선택한다.

| 방식 | 원리 | 장점 | 유의점 |
|---|---|---|---|
| 해시 기반 | 키 해시로 샤드 결정 | 데이터 분포를 고르게 만들기 쉬움 | 범위 검색 시 다수 샤드 접근 가능 |
| 범위 기반 | 키 범위별 배치 | 범위 질의와 기간별 관리에 유리 | 순차 입력에 핫스팟 발생 가능 |
| 디렉터리 기반 | 별도 매핑으로 위치 조회 | 유연한 이동·배치 | 매핑 계층의 가용성·일관성 필요 |
| 일관 해싱 | 링·가상 노드로 배치 | 노드 변경 시 이동 범위를 줄일 수 있음 | 균등성·리밸런싱 운영 고려 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **핫스팟·다중 샤드 연산·재분배 위험**은 키 설계와 운영 절차로 낮춘다.
- **키 편중** → 키 분포와 노드별 부하를 분석하고 복합 키·버킷 등 대안을 부하 시험한다.
- **교차 샤드 트랜잭션** → 가능한 한 같은 샤드에 함께 쓰이는 데이터를 배치하고, 분산 트랜잭션 필요성과 보상 처리 방안을 설계한다.
- **전역 집계·정렬** → 사전 집계, 파티션 프루닝, 비동기 분석 저장소를 검토한다.
- **노드 추가·이동 중 정합성 위험** → 복제·검증·전환 순서를 정하고 재시도 및 롤백 절차를 시험한다.

```text
키 편중      → 분포·부하 측정
전역 질의    → 집계·병렬 처리       → 예측 가능한 확장
재분배 위험  → 복제·검증·롤백
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **샤딩 전후 성능과 운영 복잡성**을 측정해 단계적으로 전환해야 한다.
- 먼저 인덱스, 파티셔닝, 캐시, 읽기 복제본 등 덜 복잡한 대안을 검토한다.
- 샤드별 지연·처리량·저장량·오류율과 키 편중 지표를 관찰한다.
- 재샤딩은 온라인 복제, 데이터 검증, 트래픽 전환, 원복 경로를 포함한 변경관리 절차로 수행한다.

## Ⅶ. 결론

- 핵심 요약 : 샤딩은 대규모 부하를 분산하는 확장 기법이며 성공 여부는 **샤드 키·질의 패턴·재분배 운영**에 달려 있다.
- 답안에는 분할 방식별 장단점과 핫스팟, 교차 샤드 연산, 무중단 전환 방안을 연결해 쓴다.
