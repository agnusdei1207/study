## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 웨어하우스 → **로지컬 데이터 웨어하우스(LDW)**

## 30초 인출

- 본질: 로지컬 데이터 웨어하우스는 분산된 원천 데이터를 논리 뷰로 통합해 이용하게 하는 분석 구조
- 메커니즘: 분석가의 질의를 논리 뷰·메타데이터로 받아 연합 질의 엔진이 원천별 계획으로 나누고, 커넥터가 지원하는 필터·프로젝션·집계·조인은 원천에 위임(푸시다운)한 뒤 부분 결과를 연합 계층에서 조합
- 통찰: 성능이 원천의 가용성·응답·네트워크·커넥터 지원에 좌우되므로 실행계획에서 위임 여부와 전송량을 확인하고, 반복 분석은 캐시·사전 적재와 비교해 선택

<details>
<summary>핵심 용어</summary>

- **LDW(Logical Data Warehouse)** : 원천을 복제하지 않고 논리 뷰로 통합해 접근하는 데이터 웨어하우스 구조
- **데이터 가상화·연합 질의** : 여러 원천에 질의를 나눠 실행하고 결과를 합치는 방식
- **커넥터** : 원천과 연합 엔진을 연결하는 구성요소
- **푸시다운(Pushdown)** : 필터·집계 같은 연산을 원천에 위임
- **물리적 DW** : 분석용 저장소에 데이터를 사전 적재하는 웨어하우스
- **메타데이터** : 논리 뷰가 원천 위치·형식을 대응시키는 정보

</details>

## 2~4교시 25점 답안

## Ⅰ. 로지컬 데이터 웨어하우스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **LDW** 는 분산된 원천 데이터를 논리적으로 통합해 이용하게 하는 분석 구조 |
| 목적 | 복제·연계 부담을 줄이고 여러 원천의 통합 분석 지원 |

## Ⅱ. 특징

| 특징 | 분석상 의미 |
|---|---|
| 논리 뷰 제공 | 원천 위치·형식 차이를 가린 통합 조회 관점 |
| 연합 실행 | 질의를 원천별로 나누고 일부 연산을 위임한 뒤 결과 조합 |
| 원천 의존 성능 | 원천 가용성·응답·네트워크·커넥터 지원이 전체에 영향 |

## Ⅲ. 연합 질의와 푸시다운

```text
분석 질의 → 논리 뷰·메타데이터 → 연합 질의 엔진 → 원천별 계획 분해
      원천 A ← 커넥터    원천 B ← 커넥터
           └ 부분 결과 ┘ → 연합 계층의 잔여 조인·집계 → 통합 결과
```

```text
질의 연산(필터·열 선택·집계·조인) → 커넥터·원천의 지원 확인
 ├ 지원 → 원천에 위임 → 줄어든 행·열만 전송
 └ 미지원 → 원천 결과 전송 → 연합 엔진에서 처리
```

실제 위임 범위는 원천·커넥터·연산에 따라 다르므로 실행계획에서 확인.

## Ⅳ. 물리적 DW와 비교

| 관점 | 물리적 DW | 로지컬 DW |
|---|---|---|
| 데이터 위치 | 분석용 저장소에 사전 적재 | 원천에 두고 논리 뷰로 접근(필요 시 캐시·부분 적재) |
| 응답 특성 | 적재 지연 대신 반복 질의 최적화 용이 | 최신 원천 접근, 원천·네트워크 상태 영향 |
| 관리 초점 | 적재 파이프라인·저장 비용 | 질의 계획·원천 부하·접근 제어 |

| 연산 | 위임 시 효과 | 적용 조건 |
|---|---|---|
| 필터 | 불필요한 행 전송 감소 | 원천·커넥터의 조건 연산 지원 |
| 프로젝션 | 필요한 열만 반환 | 열 선택 지원 |
| 집계·조인 | 중간 데이터 이동 감소 가능 | 함수·조인 조건·원천 위치 등 질의별 지원 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 반복 분산 질의가 업무 부하·지연 증가 | 실행계획·원천 부하 관측, 반복 분석은 캐시·사전 적재와 비교 |
| 커넥터가 위임하지 못해 데이터 이동 증가 | 실행계획에서 위임 확인, 지원 범위에 맞춰 질의·원천 조정 |
| 한 원천 장애가 통합 질의 전체로 전파 | 업무 중요도에 따라 캐시·대체 경로·오류 처리 기준 |

## Ⅵ. 제언

자주 쓰는 분석은 사전 적재하고 변동이 큰 원천은 논리 뷰로 접근하는 혼합 구조를 선택

```text
반복·대량 분석 → 물리적 DW(사전 적재) / 최신성·다원천 탐색 → 로지컬 DW / 실행계획으로 위임 확인
```

| 구분 | 모든 데이터를 복제 적재 | 제언: 혼합 구조 |
|---|---|---|
| 적재 부담 | 큼 | 필요한 데이터만 |
| 최신성 | 적재 주기에 종속 | 원천 직접 접근 |
