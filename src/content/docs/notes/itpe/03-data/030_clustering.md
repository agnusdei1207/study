## 답안 골격
```text
[군집화] ◀━━ 머리: Ⅶ 내 의견 (단일 알고리즘 지양 → 데이터 분포 특성별(구형/밀도/격자) 모델 선택 파이프라인 수립)
 ┃
 ┣━ Ⅰ 개요 ───── 레이블 없는 빅데이터 → 데이터 간 유사도/거리 기반으로 유사한 특성을 가진 그룹으로 자동 분할
 ┣━ Ⅱ 특징 ───── 비지도 학습의 대표 기법 · 사전 지식 불필요 · 탐색적 데이터 분석(EDA)의 핵심 도구
 ┣━ Ⅲ 구조 ───── 분할 군집화(K-Means) / 계층 군집화(병합/분할) / 밀도 군집화(DBSCAN) / 확률 모델(GMM)
 ┣━ Ⅳ 흐름 ───── ① 피처 추출 및 표준화 → ② 거리/밀도 척도 정의 → ③ 군집 알고리즘 수행 → ④ 군집 유효성 평가
 ┣━ Ⅴ 비교 ───── 3대 빅데이터 분석기법 (클러스터링 vs 필터링 vs 이상치 탐지)
 ┗━ Ⅵ 실무 ───── 차원의 저주(고차원 거리 왜곡) / 대용량 데이터 연산 복잡도 / 비즈니스 해석 불명확성
```
- 필수 키워드: 비지도 학습 · 군집 내 응집도 · 군집 간 분리도 · DBSCAN · K-Means · GMM · 실루엣 분석
- 기출: 139회 4교시 1번 `빅데이터 분석기법 중 클러스터링, 필터링, 이상치 탐지를 설명하시오.` → Ⅴ 3대 기법 비교 중심

## 한 줄 본질
- 수많은 속성을 가진 미지의 데이터 공간에서 유사한 개체들을 그룹화 → 군집 간 이질성과 군집 내 동질성을 극대화하여 잠재 구조를 발굴 → 고객 분류 및 추천의 기반 마련 / 최적 군집 수 결정의 모호성과 차원의 저주 상존

## 핵심 그림
```text
[군집화 4대 핵심 패러다임과 데이터 형태 매핑]

 [분할 기반 (K-Means)]      [밀도 기반 (DBSCAN)]       [확률 모델 (GMM)]
     **        **                 * * * *                (   *   )
    ****      ****              *         *            (  ***  )
     **        **                 * * * *            (   *   )
  (구형/동일 크기 군집)       (임의 형상 / 노이즈 분리)    (타원형 / 확률적 소프트 할당)
```

## 핵심 용어
- 소프트 클러스터링(Soft Clustering): 한 데이터가 하나의 군집에 배타적으로 속하는 것이 아니라, 여러 군집에 속할 확률(예: 군집A 70%, 군집B 30%)을 부여하는 방식(GMM 등)
- 군집 유효성 지표(CVI): 실루엣 계수, 던 지수(Dunn Index), 데이비스-볼딘 지수(DB Index)처럼 군집화가 얼마나 잘 되었는지 정량 평가하는 수치

## 핵심 통찰
- 군집화는 '목적'이 아니라 후속 분석을 위한 '전처리'인 경우가 많음 → 군집화로 사용자 유형을 먼저 쪼갠 뒤, 군집별로 서로 다른 지도학습 회귀/분류 모델을 붙여야 전체 예측 정확도 상승
- 거리 척도의 선택이 알고리즘보다 중요함 → 연속형 수치에는 유클리디안/맨해튼을 쓰지만, 범주형 데이터에는 자카드(Jaccard), 문서 텍스트에는 코사인(Cosine), 유전자 서열에는 해밍(Hamming) 거리를 매핑해야 함
- 139회 기출처럼 필터링, 이상치 탐지와 긴밀히 연계됨 → 클러스터링으로 묶이지 못하고 튕겨 나간 잔여 데이터(Noise)가 곧 이상치 탐지(Anomaly)의 대상이 됨

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 협업 필터링 (Collaborative Filtering) | 추천 시스템 연계 | 군집화로 유사한 사용자 그룹을 찾고 그 그룹의 선호도를 기반으로 아이템 추천 |
| 스펙트럴 클러스터링 (Spectral) | 비선형 그래프 군집화 | 데이터 간 유사도 그래프의 라플라시안 행렬 고유값을 이용해 복잡한 형태 분할 |

## 이웃 토픽과 구분
- 클러스터링 vs 필터링 vs 이상치 탐지: 클러스터링 = 유사한 것끼리 묶기 / 필터링 = 조건에 맞는 것만 거르기(추천/노이즈 제거) / 이상치 탐지 = 대다수 패턴에서 벗어난 특이점 찾기

## 문제·원인·대책
- 적용 상황: 수억 건의 웹 로그 스트림에서 이상 트래픽 및 봇 클러스터링
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 메모리 부족(OOM)으로 대용량 데이터 군집화 연산 중단 | 전통적 계층적 군집화의 $O(n^2)$ 메모리 복잡도 | BIRCH(균형 반복 트리) 또는 Mini-Batch K-Means 분할 처리 | 대규모 스트림 실시간 군집화 달성 |
| 변수가 100개일 때 모든 데이터 간 거리가 비슷해져 군집화 무의미 | 고차원 공간의 차원의 저주로 인한 거리 수렴 현상 | UMAP 또는 AutoEncoder 기반 비선형 잠재 공간 압축 후 군집화 | 핵심 피처 기반 명확한 군집 분리 |

## 이렇게 출제된다
- 제139회 4교시 1번: "빅데이터 분석기법 중 클러스터링, 필터링, 이상치 탐지를 설명하시오." → 요구 포인트: Ⅲ 클러스터링의 개념·유형 + Ⅴ 필터링 및 이상치 탐지와의 상호보완적 연계 관계 완결

## 내 의견
- [군집화 결과의 비즈니스 설명력 부족] 수학적으로 완벽한 실루엣 점수를 얻었으나 마케팅팀에서 "그래서 이 군집이 무슨 뜻이냐"는 질문에 답하지 못하는 실패 다수 → 나라면: 군집 형성 후 각 군집의 특성을 대표하는 결정 트리(Decision Tree)를 역으로 학습시켜 "연령 20대, 주말 접속률 80% 이상" 같은 자연어 규칙(Rule)으로 자동 변환해 리포팅
