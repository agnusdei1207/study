## 연관 키워드

- 인과관계(Causation), 인과추론(Causal Inference), 잠재 결과 모형(RCM, Rubin Causal Model), 인과 그래프(DAG)
- RCT(Randomized Controlled Trial), PSM(Propensity Score Matching), DID(Difference-in-Differences), IV(Instrumental Variable)
- Uplift Modeling, do-연산자, 반사실(Counterfactual)

## Ⅰ. 인과추론의 개요

- 핵심 요약 : 개입이 결과에 미치는 인과 효과를 규명하는 분석 방법으로, 행동을 바꾸면 어떤 결과가 생기는지에 답하는 기법.
- 개념 : 특정 처치(개입)가 결과 변수에 미친 순수한 효과, 즉 인과관계(Causation)를 추정하는 분석 방법 (**인과추론**, Causal Inference).
- 배경 및 필요성 : 상관에 기반한 예측 모델은 환경이 바뀌면 같은 관계가 유지되지 않아 정책이나 마케팅 의사결정에 그대로 쓰기 어려우므로, 개입 효과를 직접 추정할 필요가 생김.
- 주요 목적 : 처치의 효과를 교란 요인과 분리해 의사결정의 근거를 마련.

## Ⅱ. 인과추론의 특징 및 장점

- 핵심 요약 : 잠재 결과, 인과 그래프, 실험과 준실험 설계가 교란 요인을 격리해 효과를 추정하는 하나의 논리로 연결됨.

1. **잠재 결과 모형** (RCM, Rubin Causal Model, 처치를 받은 경우와 받지 않은 경우의 결과를 비교하는 틀) : 개인 효과를 Y(1)−Y(0)로 정의 → 한 개인의 두 결과를 동시에 관측할 수 없는 반사실 문제를 평균 처치 효과(ATE, Average Treatment Effect) 추정으로 우회.
2. **인과 그래프** (DAG, Directed Acyclic Graph, Judea Pearl이 체계화한 방향성 비순환 그래프) : 교란 변수를 통해 처치와 결과가 이어지는 백도어 경로를 식별하고, do-연산자로 개입 효과를 정의 → 조정해야 할 변수 집합을 결정.
3. **무작위 대조 실험** (RCT, Randomized Controlled Trial, 무작위 배정으로 처치와 대조 집단을 나누는 실험) : 교란 요인이 두 집단에 고르게 분포 → 인과 추정의 기준이 되는 설계.
4. **성향 점수 매칭** (PSM, Propensity Score Matching, 처치 확률이 비슷한 대상끼리 짝지어 비교하는 기법) : 관측된 교란 요인을 통제 → 실험이 어려운 관측 데이터에서도 비교 가능성 확보.
5. **이중차분법** (DID, Difference-in-Differences, 처치 집단과 대조 집단의 전후 변화 차이를 비교하는 방법) : 평행 추세 가정 아래 공통 시간 추세를 제거 → 준실험 환경에서 효과 추정.
6. **도구 변수** (IV, Instrumental Variable, 처치에는 영향을 주지만 결과에는 직접 영향을 주지 않는 변수) : 내생성 문제를 우회 → 숨은 교란이 있어도 효과를 추정할 여지 확보.

## Ⅲ. 인과추론 기법의 구조 (흐름)

- 핵심 요약 : 무작위 배정이 가능한 실험을 기준으로, 실험이 어려우면 관측 데이터 기법으로 넘어가는 네 가지 기법 체계.
- 백도어 경로 : 교란 변수를 거쳐 처치와 결과가 연결되는 경로이며, 조정이나 통제로 차단해야 함.

```text
[ 인과 그래프 (DAG) ]

        [교란 변수 Z]
        /           \
       v             v
  [처치 T] ----> [결과 Y]
```

```text
[ 4대 인과추론 기법 ]

RCT  : 무작위 배정 (실험이 가능할 때)
PSM  : 성향 점수 매칭 (관측 교란 통제)
DID  : 전후 차이 비교 (평행 추세 가정)
IV   : 도구 변수 (내생성 우회)
```

## Ⅳ. 4대 기법의 비교

- 핵심 요약 : 네 기법은 교란을 다루는 메커니즘과 적용 조건이 달라, 데이터 환경에 따라 선택해야 함.

| 기법 | 메커니즘 | 적용 조건 | 한계 |
| --- | --- | --- | --- |
| RCT | 무작위 배정으로 두 집단을 동일하게 구성 | 실험 실행이 가능해야 함 | 윤리 문제, 비용, 실험 환경과 현실의 차이 |
| PSM | 처치 확률이 비슷한 대상끼리 짝지어 비교 | 교란 변수가 관측 데이터에 기록되어 있어야 함 | 기록되지 않은 숨은 교란은 통제 불가 |
| DID | 처치 집단의 전후 변화를 대조 집단과 비교 | 평행 추세 가정이 성립해야 함 | 가정이 깨지면 편향 발생 |
| IV | 처치에만 영향을 주는 도구 변수의 외생적 변동 활용 | 유효한 도구 변수가 존재해야 함 | 적절한 도구 변수 발굴이 어려움 |

## Ⅴ. 인과추론의 한계와 방안

- 핵심 요약 : 숨은 교란, 평행 추세 위반, 고차원 상호작용을 민감도 분석, 사전 추세 검정, 이중 머신러닝으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 숨은 교란 변수 | 관측 데이터에 기록되지 않은 교란으로 효과 추정이 편향 | 도구 변수 활용, 역확률 가중치(IPW, Inverse Probability Weighting), Rosenbaum 민감도 분석 | ATE 추정치의 민감도 |
| 평행 추세 위반 | 처치 전 두 집단의 추세가 달라 DID 결과 왜곡 | 이벤트 스터디(Event Study)로 사전 추세 검정, 합성 대조군(Synthetic Control) 구성 | 사전 추세 검정 결과 |
| 고차원 복합 상호작용 | 많은 교란 변수와 비선형 관계로 모델 적합이 어려움 | 이중 머신러닝(DML, Double Machine Learning), 인과 포레스트(Causal Forest) | 모델 적합도 |

## Ⅵ. 인과추론에 대한 기술사적 제언

- 핵심 요약 : 실험이 어려운 서비스에서는 DID와 합성 대조군을 쓰고, 분석 전에는 인과 그래프로 교란 경로를 명시하는 절차를 표준으로 두는 것이 바람직함.

1. 실험 설계가 어려운 서비스에서는 DID와 합성 대조군을 조합해 처치 시점 전후의 효과를 추정하고, 사전 추세 검정 결과를 함께 보고하는 것이 좋다.
2. 마케팅 대상 선정에는 **업리프트 모델링** (Uplift Modeling, 처치를 받았을 때 행동이 실제로 바뀌는 대상을 추정하는 모델링)을 적용해, 설득 가능한 집단에 집중해 투자하는 것이 효율적이다.
3. 상관 분석 결과를 인과로 보고하지 않도록, 추정 전에 인과 그래프로 교란 경로를 그리고 조정 변수를 문서로 명시하는 분석 절차를 두는 것이 바람직하다.

## Ⅶ. 결론

- 핵심 요약 : 인과추론은 개입 효과를 규명하는 기법으로, 잠재 결과와 인과 그래프 위에서 실험 또는 준실험 설계를 고르는 것이 핵심임.
- 시사점 : 데이터가 많아도 설계 없이는 상관만 얻으므로, 분석 목적에 맞는 설계를 먼저 정하는 것이 인과 결론의 신뢰성을 좌우함.
