## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **인과관계와 인과추론**

## 30초 인출

- 본질: 인과관계는 특정 원인·처치의 변화가 결과에 미치는 효과에 관한 관계
- 메커니즘: 같은 대상의 처치·비처치 결과를 함께 볼 수 없으므로(반사실) 비교집단을 설계해 배정·교란·시간 변화를 점검하고, 집단 결과 차이로 평균처치효과 E[Y(1) − Y(0)]를 추정한 뒤 식별 가정과 민감도를 검증
- 통찰: 시간 선후·공변·비허위성만으로는 인과가 증명되지 않고 관측자료에서는 측정하지 않은 교란이 남으므로, 가능하면 무작위 배정을 하고 아니면 설계별 식별 가정을 명시해 민감도 분석으로 결론의 의존성을 보임

<details>
<summary>핵심 용어</summary>

- **인과효과** : 처치를 바꿨을 때 결과가 달라지는 정도
- **반사실(Counterfactual)** : 실제와 다른 처치를 받았다면 나타났을 결과
- **평균처치효과(ATE)** : E[Y(1) − Y(0)]
- **RCT(무작위 대조 시험)** : 처치를 무작위로 배정해 비교하는 실험
- **차분의 차분(DiD)** : 처치 전후 변화를 집단 간 비교하는 준실험 설계
- **교란요인(Confounder)** : 처치와 결과 모두에 영향을 주는 요인
- **민감도 분석** : 가정이 어긋날 때 결론이 얼마나 달라지는지 확인

</details>

## 2~4교시 25점 답안

## Ⅰ. 인과관계의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **인과관계** 는 원인·처치의 변화가 결과에 미치는 효과에 관한 관계 |
| 목적 | 처치 변경이 결과에 주는 영향을 추정해 의사결정 지원 |

## Ⅱ. 특징

| 특징 | 추론상 의미 |
|---|---|
| 반사실 비교 | 같은 대상의 처치·비처치 결과를 모두 볼 수 없어 대조 근거 필요 |
| 식별 가정 의존 | 관측 집단 차이에는 원래 차이와 시간 변화가 섞임 |
| 개입 중심 해석 | 함께 변함이 아니라 처치를 바꿀 때의 변화를 추정 |

## Ⅲ. 인과효과 식별 절차

```text
처치·대상·결과 지표 정의 → 처치군·비교집단 설계
   ↓ 배정·교란·시간 변화 점검
집단 결과 차이 추정 → 식별 가정·이탈·민감도 검증 → 효과 범위 해석
```

```text
대상 i: 처치 1 → Yi(1) 관측 / 처치 0 → Yi(0) 미관측
개별 효과 Yi(1) − Yi(0)는 직접 계산 불가 → 비교집단으로 평균효과 E[Y(1) − Y(0)] 추정
```

무작위 배정은 평균적으로 비교 가능한 집단을 만들고, 관측자료는 설계별 식별 가정과 교란 통제가 필요.

## Ⅳ. 설계 비교

| 설계 | 비교·추정 | 핵심 가정·점검 |
|---|---|---|
| RCT | 무작위 배정한 처치군·대조군 비교 | 배정·이탈·순응·측정 과정 |
| 매칭·회귀 조정 | 관측 공변량이 유사한 단위 비교 | 측정된 공변량 조건부 교환가능성, 공통 지지 |
| 차분의 차분 | 처치 전후 변화의 집단 간 차이 | 처치가 없었다면 추세가 평행하다는 가정 |

시간 선후·공변·비허위성은 인과 검토의 출발점이며 그것만으로 효과가 식별되지는 않음.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 서비스 변경 후 지표 변화에 자연 추세·사용자 구성 변화 혼재 | 처치·결과·비교집단을 사전 정의, 가능하면 무작위 배정, 아니면 식별 가정 검증 |
| 측정하지 않은 교란 가능성 | 도메인 지식으로 변수·시간순서 검토, 민감도 분석으로 결론 의존성 제시 |
| 배정 후 이탈·불순응으로 비교 훼손 | 배정·참여·측정 누락 추적, 분석 대상과 해석 범위 명시 |

## Ⅵ. 제언

가능하면 무작위 실험으로 검증하고, 불가능하면 설계별 가정을 명시해 민감도 분석과 함께 보고

```text
효과 질문 → 무작위 배정 가능? ─ 예 → RCT / 아니오 → 매칭·DiD 등(가정 명시) → 민감도 분석
```

| 구분 | 상관·사전사후 비교 | 제언: 설계 기반 인과추론 |
|---|---|---|
| 교란 | 혼재 | 설계로 통제 |
| 결론 | 인과 단정 | 가정·민감도 명시 |
