## 30초 인출

- 본질: Text2SQL은 자연어 질문을 SQL 질의로 변환하는 기술
- 메커니즘: 질문의 업무 용어를 스키마의 테이블·컬럼에 연결해 SQL을 생성하고, 문법·권한·비용을 검증한 뒤 제한된 계정으로 실행해 결과를 확인
- 통찰: 문법이 맞아도 의미가 틀릴 수 있고 모델 출력은 신뢰 경계 밖이므로, 카탈로그 정의와 기준 질문으로 의미 정확성을 평가하고 실행 전 권한·행 범위·비용 게이트로 통제

<details>
<summary>핵심 용어</summary>

- **Text2SQL(Text-to-SQL)** : 자연어 질문을 SQL로 변환하는 기술
- **스키마 링킹** : 질문 속 용어를 테이블·컬럼에 연결하는 과정
- **AST(추상 구문 트리)** : SQL을 구조로 파싱해 허용 연산·객체를 검사하는 표현
- **최소 권한 계정** : 필요한 객체·행·열만 접근하는 실행 계정
- **프롬프트 인젝션** : 입력에 섞인 지시로 모델 동작을 조작하는 공격
- **카탈로그** : 테이블·컬럼의 의미와 관계를 정리한 메타데이터

</details>

## 2~4교시 25점 답안

## Ⅰ. Text2SQL의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **Text2SQL** 은 자연어 질문을 SQL 질의로 변환하는 기술 |
| 목적 | SQL을 직접 작성하지 않는 이용자의 데이터 탐색 지원 |

## Ⅱ. 특징

| 특징 | 대상 | 검증이 필요한 이유 |
|---|---|---|
| 자연어 인터페이스 | 업무 질문·동의어 | 표현이 달라도 같은 데이터 의미로 연결해야 함 |
| 스키마 의존 | 테이블·열·조인 관계 | 문법이 맞아도 업무 의미가 틀릴 수 있음 |
| 실행 경계 | 생성 SQL과 실제 DB 권한 | 모델 출력을 그대로 신뢰할 수 없음 |

## Ⅲ. 처리 흐름과 실행 전 게이트

```text
질문 → 업무 용어 해석 → 스키마 링킹 → SQL 생성
   ↓
AST 파싱·허용 연산 확인
 ├ 비허용 객체·민감 열 → 차단
 └ 허용 → 사용자 권한·행 범위·비용 한도 확인
        ├ 초과 → 수정 요청·차단
        └ 통과 → 제한 계정으로 실행 → 결과·SQL·필터 표시·로그 기록
```

| 점검 | 설계 내용 |
|---|---|
| 업무 용어 | 동의어·정의를 카탈로그의 테이블·열에 연결 |
| 조인 관계 | 명시된 키·관계 이용, 불명확하면 사용자 확인 |
| 문법 | 대상 DBMS 방언 파서로 오류 탐지 |
| 의미 정확성 | 기준 질문·정답 SQL로 회귀 평가 |

## Ⅳ. 활용 사례와 보안 통제

| 활용 사례 | 내용 |
|---|---|
| 업무 데이터 조회 | 현업 담당자가 자연어로 매출·재고 현황을 조회 |
| BI·분석 보조 | 분석가가 질의 초안을 생성해 검토 후 사용 |

| 위험 | 통제 |
|---|---|
| 과도한 조회·민감 열 접근 | 사용자별 권한, 허용 뷰·열, 행 범위, 최소 권한 계정 |
| 자원 고갈·장시간 질의 | 실행 시간·반환 행·동시성·비용 제한과 취소 |
| 입력에 섞인 지시 조작 | 지시와 데이터의 경계 설정, 도구 권한 분리, SQL 독립 검증 |
| 결과 오해·환각 설명 | SQL·필터·기간을 이용자에게 표시 |

SELECT 전용 정책만으로는 저장 함수 악용·자원 고갈형 질의·민감 데이터 유출을 막지 못해 DBMS 차원의 권한·실행 경계를 함께 검증.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모호한 용어·스키마로 다른 데이터를 조회 | 카탈로그·조인 관계 보완, 기준 질문 회귀 평가 |
| 생성 SQL이 민감 열·권한 밖 객체 조회 | AST·객체·열 단위 허용 범위 검사, 최소 권한 |
| 장시간 조회로 자원 고갈 | 비용·시간·반환 행 제한, 취소·로그 경로 |

## Ⅵ. 제언

카탈로그로 의미를 고정하고, 생성 SQL은 실행 전 게이트를 통과한 경우에만 제한 계정으로 실행

```text
질문 → 스키마 링킹 → SQL 생성 → 검증 게이트 → 제한 실행 → SQL·근거 표시
```

| 구분 | 생성 SQL 직접 실행 | 제언: 게이트 통과 후 실행 |
|---|---|---|
| 보안 | 권한 밖 조회 위험 | 차단·제한 |
| 신뢰 | 결과 근거 불명 | SQL·필터 공개 |
