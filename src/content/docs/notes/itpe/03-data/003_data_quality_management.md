## 연관 키워드

- 정확성, 완전성, 일관성, 적시성, 유효성, 품질 규칙, 프로파일링

## Ⅰ. 데이터 품질관리의 개요

- 핵심 요약 : 데이터 품질관리는 데이터가 정해진 활용 목적과 품질 기준을 충족하도록 측정·개선·통제하는 전 과정.
- 개념 : 데이터 품질관리는 데이터가 정해진 활용 목적과 품질 기준을 충족하도록 측정·개선·통제하는 전 과정.
- 배경 및 필요성 : 오류·누락·중복·지연 데이터는 분석과 업무처리의 신뢰성을 훼손.
- 주요 목적 : 업무에 적합한 데이터를 지속 공급하고 오류의 발생·전파를 줄임.

## Ⅱ. 데이터 품질관리의 특징 및 장점

- 핵심 요약 : 차원·규칙 정의: 정확성·완전성·일관성 등 측정 기준화 → 주관적 품질을 검증 가능하게 전환; 프로파일링: 분포·결측·중복·참조관계 분석 → 품질 문제의 위치와 원인 파악; 폐쇄루프 개선: 원천 원인 수정 후 재측정 → 반복 오류 방지.

1. 차원·규칙 정의: 정확성·완전성·일관성 등 측정 기준화 → 주관적 품질을 검증 가능하게 전환
2. 프로파일링: 분포·결측·중복·참조관계 분석 → 품질 문제의 위치와 원인 파악
3. 폐쇄루프 개선: 원천 원인 수정 후 재측정 → 반복 오류 방지

## Ⅲ. 데이터 품질관리의 구조 (흐름)

- 핵심 요약 : 업무 중요 데이터 식별 → 품질차원·임계치 정의 → 프로파일링·규칙검사 → 원인분석·정제/원천개선 → 지속 모니터링.

```text
업무 중요 데이터 식별
  ↓
품질차원·임계치 정의
  ↓
프로파일링·규칙검사
  ↓
원인분석·정제/원천개선
  ↓
지속 모니터링
```

- 핵심 구성 : 원천 시스템

```text
원천 시스템
  ↓ 품질 규칙 검사
오류·예외 큐 → 데이터 소유자 조치
  ↑                    ↓
재측정·대시보드 ← 정제·원인 개선
```

## Ⅳ. 비교: 데이터 정제 / 데이터 품질관리

- 핵심 요약 : 효과 기준 — 데이터 정제: 단기 품질수준 향상; 데이터 품질관리: 오류 재발 억제·책임성 확보.

| 비교 기준 | 데이터 정제 | 데이터 품질관리 |
| --- | --- | --- |
| 범위 | 오류 레코드의 수정·제거 | 기준·측정·원인·개선·통제의 지속 과정 |
| 효과 | 단기 품질수준 향상 | 오류 재발 억제·책임성 확보 |

## Ⅴ. 데이터 품질관리의 한계와 방안

- 핵심 요약 : 증상 위주 정제·측정기준 불일치 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 증상 위주 정제 | 원천 생성 규칙은 그대로여서 오류 재발 | 원천 입력·인터페이스 단계에 검증 적용 | 재발률 |
| 측정기준 불일치 | 부서마다 완전성·정확성 정의가 다름 | 데이터 요소별 소유자·용어·산식 합의 | 규칙 합의율 |
| 과도한 규칙 | 업무 맥락을 무시한 임계치로 정상값 차단 | 중요도·위험 기반으로 규칙 운영·예외 승인 | 오탐률·처리시간 |

## Ⅵ. 데이터 품질관리의 제언

- 핵심 요약 : 데이터 거버넌스 조직은 핵심 데이터 요소별 업무 소유자와 관리자를 지정하고 품질 SLA·결함 이력·원천 개선예산을 연계.
- 실행 제안 : 도메인 소유자는 오류 발생 시스템의 입력·변환 규칙을 수정하고 품질대시보드에 재발률과 조치기한을 기록.

## Ⅶ. 데이터 품질관리의 결론

- 핵심 요약 : 품질은 데이터 자체의 고정 속성이라기보다 목적 적합성으로 판단되며, 측정에서 원천 개선까지 닫힌 관리체계가 필요.
- 시사점 : 품질은 절대값이 아니라 사용 목적에 대한 적합성으로 정의되고 원천 개선 책임과 연결되어야 함.
