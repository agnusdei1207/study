## 지식 로드맵 내 현재 위치

자료처리·데이터 → 관계형 데이터 모델링 → **BCNF**

## 30초 인출

- 본질: BCNF는 릴레이션의 모든 비자명한 함수적 종속 X → Y에서 결정자 X가 슈퍼키인 정규형
- 메커니즘: 비자명한 종속의 결정자가 슈퍼키인지 검사해 위반 결정자를 기준으로 릴레이션을 분해하면 무손실 조인은 확보되지만, 분해된 릴레이션에서 일부 원래 종속을 국소적으로 검사하지 못할 수 있음
- 통찰: 3NF는 우변이 주속성이면 비슈퍼키 결정자를 허용하므로 BCNF가 중복을 더 줄이지만 종속 보존을 잃을 수 있으므로, 업무 제약의 보존 요구를 평가해 3NF 유지와 BCNF 분해를 선택하고 분해 후 제약 검증 위치를 정함

<details>
<summary>핵심 용어</summary>

- **BCNF** : 모든 비자명한 함수적 종속의 결정자가 슈퍼키인 정규형
- **슈퍼키(Super Key)** : 행을 유일하게 식별하는 속성 집합
- **주속성·비주속성** : 어떤 후보키에 속하는 속성 / 어떤 후보키에도 속하지 않는 속성
- **3NF** : 결정자가 슈퍼키이거나 우변 속성이 모두 주속성인 정규형
- **무손실 분해** : 분해 후 조인하면 원래 릴레이션을 복원하는 분해
- **종속성 보존** : 분해된 릴레이션에서 원래 함수적 종속을 검사할 수 있는 성질

</details>

## 2~4교시 25점 답안

## Ⅰ. BCNF의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **BCNF** 는 모든 비자명한 함수적 종속에서 결정자가 슈퍼키인 정규형 |
| 목적 | 3NF가 허용하는 비후보키 결정자로 생기는 중복·갱신 이상 감소 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 엄격한 결정자 조건 | 비자명한 X → Y의 X가 반드시 슈퍼키 |
| 3NF와의 차이 | 3NF가 허용하는 우변 주속성 예외를 허용하지 않음 |
| 분해 절충 | 무손실 조인은 확보할 수 있으나 종속성 보존은 별도 검사 |

## Ⅲ. 판정과 분해 예

```text
R(학번, 과목, 교수): (학번, 과목) → 교수, 교수 → 과목
   교수는 슈퍼키가 아님 → BCNF 위반
   ↓ 교수 → 과목 기준 분해
R1(교수, 과목), R2(학번, 교수) → 교수로 무손실 조인
   ↓
(학번, 과목) → 교수는 두 릴레이션에서 국소 검사 불가 → 별도 제약 검증 또는 3NF 유지 검토
```

| 판정 | 조건 | 결과 |
|---|---|---|
| BCNF 위반 후보 | 비자명한 X → Y 존재 | X가 슈퍼키인지 검사 |
| 3NF 예외 | X가 슈퍼키가 아니고 Y가 주속성 | 3NF 허용, BCNF 위반 |
| 분해 후 | 투영된 종속 검사 | 무손실 조인과 종속 보존을 각각 확인 |

## Ⅳ. 3NF·BCNF 비교와 선택

| 항목 | 3NF | BCNF |
|---|---|---|
| 규칙 | X가 슈퍼키이거나 Y가 주속성 | X는 반드시 슈퍼키 |
| 주속성 예외 | 허용 | 불허 |
| 이상현상 | BCNF 위반 종속의 중복이 남을 수 있음 | 해당 중복 감소(다치 종속 등은 별도 검토) |
| 무손실 분해 | 표준 3NF 합성 절차에서 보장 | 분해 알고리즘의 각 단계에서 보장 |
| 종속성 보존 | 보존(합성 절차) | 보존되지 않을 수 있음 |

| 선택 기준 | 3NF 유지 | BCNF 분해 |
|---|---|---|
| 종속성 검증 | 원래 업무 종속을 제약으로 직접 유지 | 분해 후 별도 검증 방식 마련 |
| 갱신 이상 | 중복 이상 감수 여부 검토 | 결정자 슈퍼키 규칙으로 중복 감소 |
| 구현 비용 | 적은 조인으로 제약 적용 | 추가 조인·응용 계층 검증 비용 |

위 사례에서 종속성 보존이 깨지는 것은 해당 종속 때문이며 모든 BCNF 분해의 공통 결과는 아님.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| BCNF 분해가 무손실이어도 일부 종속의 국소 검사 곤란 | 보존 요구를 평가해 3NF·BCNF를 선택하고 제약 검증 위치 지정 |
| 분해로 다중 조인·질의 성능 저하 | 빈번한 조인 질의는 반정규화·머티리얼라이즈드 뷰 검토 |

## Ⅵ. 제언

BCNF 위반을 찾아 분해하되 분해 후 보존되지 않는 종속은 제약·검증 계층에서 보완

```text
3NF 확인 → BCNF 위반 탐지 → 분해(무손실 확인) → 보존되지 않는 종속의 검증 위치 지정 → 성능 시험
```

| 구분 | 기계적 BCNF 분해 | 제언: 보존 요구 평가 후 선택 |
|---|---|---|
| 업무 제약 | 국소 검사 상실 위험 | 검증 위치 지정 |
| 조인 | 증가 | 성능 시험 후 조정 |
