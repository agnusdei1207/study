## 연관 키워드

**점추정(Point Estimation)**, **구간추정(Interval Estimation)**, **신뢰구간(CI)**, **오차 한계(MoE)**, **베이지안 신용구간**, **부트스트랩(Bootstrap)**

## Ⅰ. 개요

- 핵심 요약 : **점추정·구간추정**은 모수를 단일 수치 또는 신뢰구간으로 추정하는 양대 기법.
- 목적 : 모집단 모수(평균, 비율, 분산) 추정.
- 배경 : 표본 기반 모수 추정 필요.
- 특징 : 점추정(단일값), 구간추정(신뢰구간), 신뢰수준·오차 한계.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **점추정(간결) vs 구간추정(불확실성 표현)**.
- **점추정** : 단일 스칼라 수치 ($\hat\theta$).
- **구간추정** : $[\hat\theta - E, \hat\theta + E]$ 신뢰구간.
- **불편성·효율성·일치성** : 점추정 평가 기준.
- **신뢰수준** : 95%, 99%.
- **오차 한계** : Margin of Error.

## Ⅲ. 신뢰구간 산식 흐름

- 핵심 요약 : **모분산 알려짐(z) vs 모름(t)** 신뢰구간 산식.
- $W = 2 \times Z_{\alpha/2} \cdot \sigma/\sqrt n$ (구간 폭).
- 신뢰수준↑ → 폭↑, n↑ → 폭↓.

```text
[ 점추정 vs 구간추정 ]

점추정 : "평균 체류시간은 15.4분"
  - 단일 수치, 표본오차 미반영

구간추정 : "95% 신뢰수준에서 [14.2, 16.6]분"
  - 하한·상한 + 신뢰도
```

```text
[ 모분산 알려짐 vs 모름 ]

알려짐 : CI = X-bar ± 1.96 * sigma/sqrt(n)  (z)
모름   : CI = X-bar ± t * s/sqrt(n)  (t, df=n-1)
```

## Ⅳ. 점 vs 구간 비교

- 핵심 요약 : **결과 형태·오차 표현·평가 기준·용도** 비교.

| 항목 | 점추정 | 구간추정 |
|---|---|---|
| 결과 형태 | 단일 수치 | 신뢰구간 [L,U] |
| 오차 표현 | 없음 | 오차 한계+신뢰수준 |
| 평가 기준 | 불편성·효율성·일치성 | 신뢰수준 충족·폭 |
| 용도 | KPI 보고·파라미터 초기화 | 리스크 관리·A/B 테스트 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **불확실성 은폐·빈도주의 오해·소표본 왜곡**을 CI 병기·베이지안·부트스트랩으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 불확실성 은폐 | 점추정만 보고 → 리스크 간과 | CI 병기 의무화, 시나리오 분석 | CI 폭 |
| 빈도주의 오해 | "모수가 구간에 있을 확률 95%" 오해 | 통계 교육, 베이지안 신용구간 병행 | 해석 정확도 |
| 소표본 왜곡 | 비정규·소표본에서 t-분포 왜곡 | 부트스트랩 백분위수, BCa | 커버리지 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **CI 병기·예측 인터벌·Conformal Prediction**.
- KPI 보고 시 점추정+CI 병기.
- ML 서빙 시 예측 구간 (Conformal Prediction) API 노출.

## Ⅶ. 결론

- 핵심 요약 : 점추정·구간추정은 **모수 추정 양대 기법**으로 불확실성 표현이 핵심.
- 답안에는 산식, 신뢰수준·오차 한계, 한계·대응을 연결.
