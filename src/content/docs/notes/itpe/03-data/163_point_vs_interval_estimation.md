## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **점추정 vs 구간추정**

## 30초 인출

- 본질: 점추정은 모수를 표본에서 계산한 한 값으로, 구간추정은 표본 변동성을 반영한 신뢰구간으로 추정하는 방법
- 메커니즘: 표본 통계량 θ̂가 점추정값이고 신뢰구간은 θ̂ ± 오차한계(임계값 × 표준오차)이며, 신뢰수준이 높아지면 임계값이 커져 구간이 넓어지고 표본이 커지면 표준오차가 줄어 구간이 좁아짐
- 통찰: 신뢰수준은 반복 표집에서 생성한 구간이 모수를 포함하는 비율이지 한 구간이 모수를 포함할 확률이 아니므로, 추정값과 표준오차·신뢰구간을 함께 보고하고 허용 오차한계로 필요한 표본 크기를 먼저 정함

<details>
<summary>핵심 용어</summary>

- **점추정(Point Estimation)** : 모수의 단일 추정값
- **구간추정(Interval Estimation)** : 신뢰수준을 갖는 하한·상한의 범위
- **신뢰수준** : 반복 표집 시 생성 구간이 모수를 포함하는 비율
- **오차한계** : 임계값 × 표준오차
- **불편성·효율성·일치성·충분성** : 좋은 추정량의 성질
- **예측구간** : 미래 관측값이 놓일 범위(모수의 신뢰구간과 구별)

</details>

## 2~4교시 25점 답안

## Ⅰ. 점추정과 구간추정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **점추정** 은 모수를 한 값으로, **구간추정** 은 불확실성을 반영한 구간으로 추정하는 방법 |
| 목적 | 점추정은 대표값 제시, 구간추정은 추정 불확실성 표현 |

## Ⅱ. 특징

| 특징 | 점추정 | 구간추정 |
|---|---|---|
| 결과 | 모수의 단일 추정값 | 절차가 산출한 하한·상한 |
| 불확실성 | 추정값만으로 표본 변동성 확인 불가 | 신뢰수준과 구간 폭으로 정밀도 표현 |
| 해석 | 값 자체 | 신뢰수준은 반복 표집 시 구간의 모수 포함 비율 |

## Ⅲ. 산출 체계

```text
미지 모수 θ → 표본 추출 → 통계량 θ̂ (점추정값)
   └ 표준오차 + 신뢰수준별 임계값 → 오차한계 → 신뢰구간 [L, U]
```

```text
θ̂ ± 오차한계 (= 임계값 × 표준오차)
 ├ 신뢰수준 증가 → 임계값 증가 → 구간 확대
 └ 표본 수 증가 → 표준오차 감소 → 구간 축소
```

- 정규모집단, 알려진 모표준편차 σ: X̄ ± z(α/2)·σ/√n
- σ가 미지인 정규모집단 표본: X̄ ± t(α/2, n−1)·s/√n

## Ⅳ. 추정량 성질과 구간 품질

| 좋은 점추정량 | 판정 |
|---|---|
| 불편성 | E(θ̂) = θ |
| 효율성 | 같은 조건에서 비교 가능한 추정량보다 작은 분산 |
| 일치성 | n이 커지면 θ̂가 θ로 확률수렴 |
| 충분성 | 통계량이 표본의 모수 관련 정보를 모두 보유 |

| 구간추정 평가 | 판정 |
|---|---|
| 포함률 | 반복 표집에서 구간이 참 모수를 포함하는 비율 |
| 구간 폭 | 같은 포함률에서 정밀도와 표본 비용 비교 |

알려진 σ와 단순 독립 표집에서 허용 오차한계 E를 정하면 표본 크기는 n ≥ (z(α/2)·σ/E)²를 올림하며 비응답·복합표본 설계는 별도 반영.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 점추정값 하나로 표본 변동성 파악 곤란 | 추정값과 표준오차·신뢰구간 함께 보고 |
| 신뢰수준을 높이면 구간 폭 증가 | 허용 오차한계를 먼저 정하고 필요한 표본 크기·비용 산정 |
| 표본 선택 편향·가정 위반 시 명목 신뢰수준이 실제 포함률을 보장하지 않음 | 표본 추출 방식과 가정 점검, 적절한 추정 절차 적용 |
| 신뢰구간을 관측값의 예측 범위로 오해 | 모수의 신뢰구간과 미래 관측값의 예측구간을 구분해 표기 |

## Ⅵ. 제언

점추정값은 표준오차·신뢰구간과 함께 보고하고 허용 오차한계에서 표본 크기를 역산

```text
허용 오차한계·신뢰수준 → 표본 크기 산정 → 점추정 + 신뢰구간 보고 → 가정 점검
```

| 구분 | 점추정값만 보고 | 제언: 점추정 + 신뢰구간 |
|---|---|---|
| 불확실성 | 가려짐 | 표시 |
| 표본 크기 | 경험적 | 오차한계 기반 |
