## 연관 키워드

- 독립표본 t-검정(Independent Samples T-Test), Student's t-검정, Welch's t-검정, Levene 검정
- Shapiro-Wilk 검정, Mann-Whitney U 검정, 효과 크기(Effect Size, Cohen's d), 검정력 분석, A/B 테스트

## Ⅰ. 독립표본 t-검정의 개요

- 핵심 요약 : 서로 독립된 두 집단의 평균 차이가 우연인지 실제 효과인지 판정하는 모수적 가설검정 기법.
- 개념 : 서로 독립적으로 추출된 두 집단의 연속형 데이터 평균을 비교해 모집단 평균 차이의 존재를 판정하는 **독립표본 t-검정** (Independent Samples T-Test, 두 독립 집단의 평균을 비교하는 모수적 가설검정).
- 배경 및 필요성 : 단순한 평균 차이는 표본 오차에서 비롯될 수 있어 확률 이론 기반의 검정 절차가 필요하며, 온라인 서비스의 **A/B 테스트** (대조군 Control과 실험군 Treatment를 무작위로 나눠 비교하는 실험)에서는 효과의 통계적 유의성을 객관적으로 입증하는 데 쓰임.
- 주요 목적 : 두 독립 모집단의 평균 차이가 우연인지 실제 효과인지를 유의수준(α) 기준으로 판정.

```text
[ 독립표본 t-검정의 기본 구조 ]

모집단 1 → 표본 1 (n1, 평균)
모집단 2 → 표본 2 (n2, 평균)
                |
                v
H0 : μ1 = μ2 (차이 없음)
H1 : μ1 ≠ μ2 (차이 있음)
                |
                v
  검정통계량 t 산출 → p값 판정
```

## Ⅱ. 독립표본 t-검정의 특징 및 장점

- 핵심 요약 : 세 가지 선행 가정을 전제로 하며, 가정이 깨지면 검정 방법을 바꾸는 구조.

1. **3대 선행 가정** (독립성, 정규성, 등분산성) : 검정 신뢰도의 전제 조건 → 가정 확인 없이 p값을 해석하면 결론이 흔들림.
2. 등분산 여부에 따른 분기 : **Levene 검정** (Levene's Test, 두 집단의 분산이 같은지 확인하는 검정) 결과에 따라 **Student's t-검정** (등분산 가정) 또는 **Welch's t-검정** (이분산 가정, 자유도 보정)을 선택 → 분산 차이에도 검정 신뢰도 유지.
3. **Mann-Whitney U 검정** (순위를 이용하는 비모수 검정, 정규성 위반 시 대안) : 분포 가정 없이 순위로 비교 → 소표본의 비정규 데이터에 대응.
4. **효과 크기** (Effect Size, 차이의 실질적 크기를 표준화한 지표로 Cohen's d 등이 대표적) : 대규모 표본에서 미세한 차이도 유의하게 나오는 문제를 보완 → 실질적 유의성 판단.

```text
[ 사전 검증 파이프라인 ]

1. 독립성 : 두 집단이 상호 배타적인지 확인
2. 정규성 : 집단별 분포 확인 (Shapiro-Wilk)
3. 등분산성 : 분산 동일성 확인 (Levene)
        |
        +-- 등분산 만족 → Student's t-검정
        +-- 등분산 위반 → Welch's t-검정
```

## Ⅲ. 독립표본 t-검정의 구조 (흐름)

- 핵심 요약 : 가설 설정, 선행 가정 검증, 검정 방법 선택, 통계량 산출, 유의성 판정의 5단계 절차.

| 가정 상황 | 검정 명칭 | 검정통계량 t | 자유도(df) |
| :--- | :--- | :--- | :--- |
| 등분산 가정 | Student's t-검정 | (평균1 − 평균2) / (sp × √(1/n1 + 1/n2)) | n1 + n2 − 2 |
| 이분산 가정 | Welch's t-검정 | (평균1 − 평균2) / √(s1²/n1 + s2²/n2) | 근사치 적용 |

※ sp는 두 집단의 합동 표준편차, s1과 s2는 각 집단의 표준편차.

```text
[ 독립표본 t-검정 수행 절차 ]

(1) 가설 설정
    H0 : μ1 = μ2 vs H1 : μ1 ≠ μ2
            |
            v
(2) 선행 가정 검증
    독립성 → 정규성 → 등분산성
            |
            v
(3) 검정 방법 선택
            |
            v
(4) 검정통계량 및 p값 계산
            |
            v
(5) 판정 : p < α면 H0 기각
```

```text
[ 검정 방법 선택 분기 ]

정규성 위반
   → Mann-Whitney U 검정

정규성 만족 + 등분산 만족
   → Student's t-검정

정규성 만족 + 등분산 위반
   → Welch's t-검정
```

## Ⅳ. 대응표본 t-검정과의 비교

- 핵심 요약 : 독립표본은 서로 다른 두 집단을, 짝지은 전후 비교는 같은 개체를 비교한다는 표본 설계 차이가 핵심.
- 비교 대상은 **대응표본 t-검정** (Paired t-Test, 동일 개체의 전후 차이를 검정하는 방법)이며, 표본 설계에 따라 선택이 갈림.

| 비교 항목 | 독립표본 t-검정 | 대응표본 t-검정 |
| :--- | :--- | :--- |
| 표본 구조 | 두 독립 집단 (서로 다른 개체) | 동일 집단의 전후 측정 (같은 개체) |
| 비교 대상 | 집단 간 평균 차이 | 개체별 전후 차이 d의 평균 |
| 검정통계량 | 두 표본 평균 차이를 합동분산으로 표준화 | 차이값 d의 평균을 표준오차로 표준화 |
| 분산 구조 | 두 집단의 분산을 결합 | 개체 간 분산이 제거되어 검정력 우위 |
| 적용 사례 | A/B 테스트, 집단 간 평균 비교 | 약물 투여 전후, 교육 효과 전후 |

## Ⅴ. 독립표본 t-검정의 한계와 방안

- 핵심 요약 : 적용이 간편한 반면 가정 위반과 표본 크기 불균형, 간섭 효과에서 신뢰도가 떨어지므로 가정 확인과 설계 통제로 대응.

1. 적용 용이성 : 검정 절차가 명확하고 통계 소프트웨어에서 기본 제공.
2. 해석 직관성 : 통계량과 p값으로 결과 해석이 간편.
3. 보정 체계 존재 : Welch 검정으로 등분산 가정을 완화 가능.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 정규성·등분산성 위반 | 가정이 깨지면 1종 오류 확률과 검정력이 설계값에서 벗어남 | 등분산 위반 시 Welch 검정을 기본으로 채택, 표본이 비정규적이면 Mann-Whitney U 검정 병행 | 가정 검정 p값, 1종 오류율 |
| 표본 크기 불균형 | 한쪽 집단이 극단적으로 작으면 표준오차가 왜곡되어 검정력 저하 | 사전 **검정력 분석** (Power Analysis, 필요한 최소 표본 크기를 미리 계산하는 분석)과 가능한 한 균형 배분, 순차 검정 프레임워크 적용 | 검정력, 표본 배분 비율 |
| 네트워크 효과와 SUTVA 위반 | 사용자 간 영향이 있으면 **SUTVA** (Stable Unit Treatment Value Assumption, 개체 간 처치 영향이 없다는 가정)가 깨짐 | 사용자 단위 대신 **클러스터 무작위 배정** (Cluster Randomization, 지역이나 네트워크 단위로 집단을 나눠 배정) 적용 | 집단 간 간섭 지표 |

```text
[ 표본 크기 불균형의 영향 ]

균형 배분 (1:1) → 표준오차 최소, 검정력 최대
불균형 배분      → 표준오차 왜곡, 검정력 저하
극단적 불균형   → 유효 표본 감소, 2종 오류 증가
```

## Ⅵ. 독립표본 t-검정에 대한 기술사적 제언

- 핵심 요약 : 효과 크기 병행, 표본 배분 통제, 가정에 따른 검정 전환 기준을 갖춰야 실무 A/B 테스트의 신뢰도를 확보.

1. 효과 크기 병기 : 대규모 트래픽의 A/B 테스트에서는 표본이 커서 미세한 차이도 p값이 매우 작게 나오므로, Cohen's d 같은 효과 크기를 함께 산출해 실질적 가치가 있는 차이인지 판단하는 절차가 필요.
2. 표본 배분 통제 : 두 집단의 표본 크기가 크게 다르면 표준오차가 작은 집단이 결과를 지배하므로, 실험 설계 단계에서 배분 비율을 가능한 균형 있게 정하고 Welch 검정을 기본으로 둘 필요.
3. 검정 전환 기준 : 표본이 소규모이면서 정규성이 기각되면 모수적 검정의 1종 오류 우려가 커지므로, 순위 기반 비모수 검정으로 전환하는 기준을 분석 표준에 미리 명시할 필요.

## Ⅶ. 결론

- 핵심 요약 : 독립표본 t-검정은 두 독립 집단의 평균 차이를 판정하는 표준 모수 기법이며, 가정 검증과 효과 크기 병행이 신뢰도의 핵심.
- 시사점 : 실무 A/B 테스트는 p값만으로 결정하지 않고 효과 크기와 신뢰구간을 함께 보며, 설계 단계의 검정력 분석이 결과 해석의 전제가 됨.
