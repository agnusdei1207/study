## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **독립표본 t-검정**

## 30초 인출

- 본질: 독립표본 t-검정은 서로 독립인 두 모집단의 평균 차이를 표본으로 검정하는 방법
- 메커니즘: 두 집단이 독립인지(같은 대상의 전후 측정이면 대응표본)를 확인하고 분포·이상치·분산 차이를 살펴, 합동분산 또는 Welch 방식으로 표준오차를 구해 t값·자유도로 신뢰구간과 p값을 해석
- 통찰: 분산이 다르거나 등분산을 확신하기 어려우면 합동분산 검정이 부정확하므로 Welch 방식을 우선 검토하고, 반복 측정·군집 자료를 독립으로 취급하지 않으며 평균 차이와 신뢰구간을 함께 보고

<details>
<summary>핵심 용어</summary>

- **독립표본 t-검정** : 서로 독립인 두 집단의 평균 차이를 검정
- **합동분산(Pooled) t-검정** : 두 집단의 분산이 같다고 가정하는 검정
- **Welch t-검정** : 등분산을 가정하지 않고 각 표본분산을 사용하는 검정
- **Welch–Satterthwaite 근사** : Welch 검정의 자유도 근사식
- **표준오차** : 평균 차이의 표본 간 변동
- **효과 크기·신뢰구간** : 평균 차이의 실질적 크기와 불확실성

</details>

## 2~4교시 25점 답안

## Ⅰ. 독립표본 t-검정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **독립표본 t-검정** 은 서로 독립인 두 모집단의 평균 차이를 표본자료로 검정하는 방법 |
| 목적 | 두 집단 평균의 차이가 표본오차만으로 설명되는지 판단 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 집단 간 독립성 | 같은 대상의 전후가 아닌 서로 다른 두 집단 비교 |
| 표준오차 기반 | 평균 차이를 변동성과 표본 크기로 표준화 |
| 분산 가정별 방식 | 합동분산과 Welch의 분모·자유도가 다름 |

## Ⅲ. 검정 절차

```text
두 집단의 표집·실험 설계 확인
 ├ 같은 대상의 짝·반복 측정 → 대응표본 분석
 └ 독립 집단 → 분포·이상치·분산 차이 확인
      ↓ 표준오차 방식 선택
평균 차이 Δ = x̄1 − x̄2 → t = (Δ − Δ0)/SE, 자유도 → 신뢰구간·p값 해석
```

독립성은 설계로 미리 확보해야 하며 표본이 커도 극단값과 군집 의존성은 별도로 검토.

## Ⅳ. 합동분산·Welch 비교

| 선택 | 통계량 | 자유도 |
|---|---|---|
| 합동분산 t | (x̄1 − x̄2 − Δ0) / ( s_p·√(1/n1 + 1/n2) ) | n1 + n2 − 2 |
| Welch t | (x̄1 − x̄2 − Δ0) / √( s1²/n1 + s2²/n2 ) | Welch–Satterthwaite 근사 |

```text
합동분산: s_p² = ( (n1 − 1)·s1² + (n2 − 1)·s2² ) / ( n1 + n2 − 2 )
```

Welch는 개별 표본분산을 사용해 등분산을 전제하지 않으며, 분산 차이가 있거나 확신하기 어려우면 Welch를 우선 검토.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 반복 측정·군집 자료를 독립으로 취급 | 표집·측정 설계를 확인해 짝·군집 구조에 맞는 분석 선택 |
| 분산 차이를 무시한 합동분산 검정 | 분산·표본 크기를 확인하고 Welch 우선 검토 |
| p값만으로 개선 크기 단정 | 평균 차이와 신뢰구간을 업무 기준과 함께 제시 |

## Ⅵ. 제언

설계로 독립성을 확인하고 기본을 Welch로 두어 평균 차이와 신뢰구간을 보고

```text
독립성 확인 → 분포·분산 점검 → Welch(기본) → 평균 차이·신뢰구간 보고
```

| 구분 | 합동분산 일괄 적용 | 제언: Welch 기본 |
|---|---|---|
| 분산 차이 | 오차 왜곡 | 견딤 |
| 보고 | p값 | 차이·신뢰구간 |
