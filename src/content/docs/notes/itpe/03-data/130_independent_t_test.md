## 지식 로드맵 내 현재 위치

데이터베이스 → 통계·데이터 분석 → 두 독립집단 평균 비교

## 30초 인출

- 본질: **독립표본 t-검정**은 서로 다른 두 집단의 모평균 차이를 추론하는 방법
- 메커니즘: 평균 차이를 표준오차로 나누고 t 분포와 비교해 귀무가설을 평가
- 선택: 등분산을 가정하면 합동분산 t, 가정하지 않으면 Welch t 적용

<details>
<summary>핵심 용어</summary>

- **독립표본 t-검정(Independent Samples t-test)**: 서로 독립인 두 모집단의 평균 차이를 검정하는 방법
- **Welch's t-test**: 두 모집단 분산을 같다고 두지 않고 평균 차이를 검정하는 방법
- **합동분산(Pooled Variance)**: 등분산 가정 아래 두 표본분산을 자유도로 가중해 추정한 공통 분산
- **Welch–Satterthwaite 근사**: Welch 검정의 자유도를 표본분산과 표본크기로 근사하는 방법

</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 서로 독립인 두 모집단의 평균 차이를 표본자료로 검정하는 방법 |
| 목적 | 두 집단 평균의 차이가 표본오차만으로 설명 가능한지 판단 |

### Ⅱ. 가정과 검정통계량

| 구분 | 적용 기준 |
|---|---|
| 독립성 | 관측 단위 간 독립 표집·배정 |
| 정규성 | 각 모집단의 정규성 또는 평균 차이의 근사 정규성 |
| 등분산 | 합동분산 t에 필요한 가정; Welch t에는 불필요 |

| 방법 | 검정통계량·자유도 |
|---|---|
| 합동분산 t | $t=(\bar{x}_1-\bar{x}_2)/(s_p\sqrt{1/n_1+1/n_2})$, $df=n_1+n_2-2$ |
| Welch t | $t=(\bar{x}_1-\bar{x}_2)/\sqrt{s_1^2/n_1+s_2^2/n_2}$, 자유도는 Welch–Satterthwaite 근사 |

### Ⅲ. 한 줄 제언

제언: 분석 설계에서 독립 표집과 목표 평균 차이를 먼저 정하고, 분산 가정을 명시한 검정과 효과 추정치를 함께 보고.

## 2~4교시 25점 답안

## Ⅰ. 독립표본 t-검정 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 서로 독립인 두 모집단의 평균 차이를 표본자료로 검정하는 방법 |
| 목적 | 두 집단 평균의 차이가 표본오차만으로 설명 가능한지 판단 |

두 집단 평균 차이의 귀무가설은 $H_0: \mu_1-\mu_2=0$, 대립가설은 문항의 목적에 따라 양측 또는 단측으로 설정.

## Ⅱ. 적용 가정과 확인 사항

| 항목 | 의미 | 실무상 확인 |
|---|---|---|
| 독립성 | 두 집단의 관측치가 서로 독립 | 반복측정·군집 표집 여부 확인 |
| 정규성 | 각 집단 자료가 정규분포에 가깝거나 평균 차이의 표집분포가 근사 정규 | 분포와 이상치 검토, 표본 크기와 설계 고려 |
| 등분산성 | 두 모집단 분산이 같다는 가정 | 합동분산 t를 선택할 때만 필요 |

독립성은 실험·표집 설계에서 확보하는 조건. 큰 표본은 평균의 표집분포를 정규분포에 가깝게 할 수 있지만, 왜도·극단값과 작은 표본의 영향을 별도로 검토.

## Ⅲ. 등분산 가정별 검정통계량

| 선택 | 통계량 | 자유도 |
|---|---|---|
| 합동분산 t | $t=\frac{(\bar{x}_1-\bar{x}_2)-\Delta_0}{s_p\sqrt{1/n_1+1/n_2}}$ | $n_1+n_2-2$ |
| Welch t | $t=\frac{(\bar{x}_1-\bar{x}_2)-\Delta_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}}$ | Welch–Satterthwaite 근사 |

합동분산은 $s_p^2=\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}$로 계산. Welch 방식은 개별 표본분산을 사용해 등분산을 전제하지 않음.

## Ⅳ. 검정 선택과 결과 해석

| 상황 | 선택·해석 |
|---|---|
| 독립 집단, 등분산 가정 타당 | 합동분산 t 검정 적용 |
| 분산 차이를 가정하거나 확신하기 어려움 | Welch t 검정으로 평균 차이 추정 |
| 반복 측정·짝지은 자료 | 독립표본 검정 대신 차이값에 대한 대응표본 분석 |
| 분포가 심하게 비정규·이상치 영향이 큼 | 자료 특성과 추정 목표에 맞는 강건·재표집·순위 기반 방법 검토 |

유의확률만으로 실질적 중요성을 결론내리지 않고, 평균 차이의 추정치·신뢰구간·분석 가정과 함께 해석.

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 가정 확인 없이 기본 옵션을 사용하면 집단 구조나 분산 차이에 맞지 않는 추론 위험 | 분석 표준에 독립성 점검, Welch 적용 기준, 신뢰구간·효과 해석을 포함하고 재현 가능한 분석기록 유지 |
