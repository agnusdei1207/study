## 답안 골격
```text
[독립표본 t-검정 (Independent Two-Sample t-test)] ◀━━ 머리: Ⅶ 내 의견 (등분산성 F-검정 선행에 따른 수식 분기와 A/B 테스트 신뢰구간 평가)
 ┃
 ┣━ Ⅰ 개요 ───── 서로 독립적인 두 모집단으로부터 추출한 표본 데이터를 바탕으로 두 집단의 모평균 사이에 통계적으로 유의미한 차이가 있는지 검정하는 모수 기법
 ┣━ Ⅱ 특징 ───── 3대 기본 가정(독립성, 정규성, 등분산성) · 등분산 여부에 따른 통계량 수식 분기(스튜던트 t vs 웰치의 t) · 자유도 $df = n_1 + n_2 - 2$
 ┣━ Ⅲ 구조 ───── 귀무가설($H_0: \mu_1 = \mu_2$) / 대립가설($H_1: \mu_1 \neq \mu_2$) / 합동분산($s_p^2$, 등분산 시) / 웰치의 자유도(Welch-Satterthwaite, 이분산 시)
 ┣━ Ⅳ 흐름 ───── ① 두 독립 표본 데이터 수집 → ② 정규성 검정(Shapiro-Wilk) → ③ 등분산성 검정(Levene 검정) → ④ 통계량 계산(등분산/이분산 분기) → ⑤ p-value 판정
 ┣━ Ⅴ 비교 ───── 독립표본 t-검정 vs 대응표본 t-검정 vs 맨-휘트니 U 검정(비모수)
 ┗━ Ⅵ 실무 ───── 이분산 상태에서 일반 스튜던트 t-검정 공식 적용 시 1종 오류 급증 / 표본 크기 불균형($n_1 \gg n_2$) 시 검정력 저하
```
- 필수 키워드: 독립표본 t-검정 · 정규성 가정 · 등분산성(Levene 검정) · 합동분산(Pooled Variance) · 웰치의 t-검정(Welch's t-test) · A/B 테스트 · 맨-휘트니 U 검정
- 기출: 131회 `독립 표본 t-검정(Independent t-test)과 대응 표본 t-검정(Paired t-test)의 개념, 기본 가정 및 차이점을 비교 설명하시오.` → Ⅰ 정의 + Ⅱ 3대 기본 가정 + Ⅲ 검정통계량 수식 + Ⅴ 비교표

## 한 줄 본질
- 서로 다른 두 사용자 집단(예: 기존 UI vs 신규 UI)의 평균 지표 차이가 우연인지 실제 효과인지 검증 필요 → 표본평균 차이를 두 집단의 분산 합으로 나눈 t-통계량을 계산하여 판정 → 객관적 A/B 테스트 의사결정 / 등분산성 위배 시 잘못된 결론 도출 위험

## 핵심 그림
```text
[독립표본 t-검정의 판정 파이프라인 및 등분산성 분기]

  [독립된 두 표본 데이터 (Group A, Group B)]
                    │
                    ▼ 1단계: 정규성 검정 (Shapiro-Wilk)
   [정규분포 만족?] ────(No)────► 맨-휘트니 U 검정 (비모수 검정)
                    │ (Yes)
                    ▼ 2단계: 등분산성 검정 (Levene's Test)
   [등분산성 만족?]
          │ (Yes: σ1² = σ2²)                     │ (No: σ1² ≠ σ2²)
          ▼                                       ▼
  [일반 스튜던트 t-검정]                  [웰치의 t-검정 (Welch's t-test)]
  - 합동분산(Sp²) 계산                   - 각 집단 분산 개별 사용
  - 자유도: df = n1 + n2 - 2              - 자유도: Welch-Satterthwaite 근사식
```

## 핵심 용어
- 합동분산(Pooled Variance, $s_p^2$): 두 집단의 모분산이 동일하다는 등분산성 가정이 성립할 때, 두 표본분산을 표본 크기로 가중 평균하여 하나의 분산으로 통합한 값
- 웰치의 t-검정(Welch's t-test): 두 집단의 분산이 서로 다를 때(이분산성) 분산을 통합하지 않고 각각의 분산과 자유도를 보정하여 계산하는 강건한 t-검정 기법

## 핵심 통찰
- 실무 데이터(예: A/B 테스트)에서 두 집단의 분산이 완벽히 같을 확률은 거의 0%임 → 따라서 등분산 검정(Levene)을 생략하고 일반 스튜던트 t-검정을 쓰면 심각한 1종 오류가 발생하므로, 현대 통계학에서는 기본값으로 '웰치의 t-검정'을 쓰는 것을 권장함
- 두 집단의 표본 크기가 극단적으로 다를 때(예: A그룹 100만 명, B그룹 500명) 일반 t-검정을 돌리면 통계량이 심각하게 왜곡되므로 표본 크기 균형(Balancing)이 중요
- 독립표본 t-검정은 '모집단이 서로 다른 개체들로 구성'되어 있어야 하므로,同一 인물이 A안과 B안을 모두 본 데이터에 이를 적용하면 독립성 가정이 깨져 분석 자체가 무효화됨

## 이웃 토픽과 구분
- 독립표본 t-검정 vs 대응표본 t-검정: 독립표본 = 서로 다른 두 집단 간의 평균을 비교(표본 크기 $n_1, n_2$가 달라도 됨) / 대응표본 = 동일한 집단의 처리 전과 처리 후를 1:1로 매칭하여 비교(반드시 $n_1 = n_2$)

## 문제·원인·대책
- 적용 상황: 온라인 커머스 신규 결제 화면(B안)과 기존 화면(A안)의 구매 전환율 비교 A/B 테스트
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| A안과 B안의 분산 차이가 4배 이상 벌어졌음에도 일반 t-검정 적용하여 효과 과대평가 | 등분산성 가정 위배 상태에서 합동분산 공식 기계적 적용 | 웰치의 t-검정(Welch's t-test)으로 전환하여 분산 불일치 보정 | 정확한 p-value 산출로 거짓 개선(1종 오류) 차단 |
| 결제 금액 데이터의 심각한 우측 꼬리 비정규성으로 인해 t-검정 가정 위배 | 소수 고액 결제자의 극단값으로 인한 정규성 붕괴 | 비모수 검정인 맨-휘트니 U 검정(Mann-Whitney U Test) 적용 또는 로그 변환 | 이상치에 강건한 객관적 순위 차이 검증 |

## 내 의견
- [A/B 테스트 플랫폼의 웰치 t-검정 표준화] 실무 데이터 분석가들이 라이브러리 기본값(`equal_var=True`)을 그대로 두고 돌려 잘못된 신규 기능이 배포되는 사고 빈발 → 나라면: 사내 실험 플랫폼(A/B Testing Platform)의 분석 엔진을 `equal_var=False`(웰치의 t-검정)로 영구 고정하고, 표본 수가 충분할 때에도 Cohen's d 효과 크기를 함께 계산해 실질적 비즈니스 영향도 판정 의무화

## 찾아볼 것
- 두 집단의 분산이 동일한지 검정하는 Levene의 검정(Levene's Test)과 Bartlett 검정의 정규성 민감도 차이
