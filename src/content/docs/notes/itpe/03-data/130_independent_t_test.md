## Ⅰ. 서로 다른 두 모집단 평균의 비교, 독립표본 t-검정 개요

### 가. 독립표본 t-검정(Independent Samples T-Test)의 정의
- 서로 독립적으로 추출된 두 개의 표본 집단으로부터 얻은 연속형 데이터의 평균값을 비교하여, 두 집단이 추출된 원래 모집단의 평균 간에 통계적으로 유의미한 차이가 존재하는지 판정하는 모수적 가설검정 기법.
- 온라인 서비스의 표준 A/B 테스트(대조군 Control vs 실험군 Treatment)의 핵심 검증 도구.

---

## Ⅱ. 독립표본 t-검정의 선행 가정 및 검정 절차

### 가. 3대 선행 필수 가정 검증 흐름

```text
[ 독립표본 t-검정 사전 검증 파이프라인 ]
1. 독립성 (Independence)  : 두 그룹의 피험자가 상호 배타적이고 독립적이어야 함 (실험 설계 확인)
2. 정규성 (Normality)     : 두 집단 각각의 데이터가 정규분포를 따라야 함 (Shapiro-Wilk)
3. 등분산성 (Homogeneity) : 두 집단의 모분산이 동일한가? (Levene 검정 수행)
         |
         +---> 등분산 만족 (p >= 0.05) : [Student's t-검정 (합동분산 적용)]
         +---> 등분산 위반 (p < 0.05)  : [Welch's t-검정 (자유도 보정)]
```

### 나. 등분산 vs 이분산 검정통계량 산식 비교

| 가정 상황 | 사용 검정 명칭 | 검정통계량 $t$ 공식 | 자유도 ($df$) |
| :--- | :--- | :--- | :--- |
| **등분산 가정 (Equal Variance)** | **Student's t-검정** | $t = \frac{\bar{X}_1 - \bar{X}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}$ ($s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}$) | $n_1 + n_2 - 2$ |
| **이분산 가정 (Unequal Variance)** | **Welch's t-검정** | $t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$ | $df \approx \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}}$ |

## Ⅲ. 정규성 위반 시 대안: 맨-휘트니 U 검정(Mann-Whitney U Test)

### 가. 비모수 검정으로의 전환 기준
- 두 집단 중 어느 한 집단이라도 표본 크기가 30건 미만이고 Shapiro-Wilk 검정에서 정규성이 기각($p < 0.05$)될 경우, 모수적 t-검정을 수행하면 1종 오류가 급증함.
- **해법** : 원래의 수치 데이터를 모두 순위(Rank)로 변환하여 두 집단의 중앙값 차이를 검정하는 비모수 검정인 **맨-휘트니 U 검정(Wilcoxon Rank-Sum Test)** 을 수행.

---

## Ⅳ. A/B 테스트 및 데이터 사이언스 실무 제언

- **표본 크기 불균형(Imbalanced Sample Size)의 영향 통제** : 대조군 $n_1 = 100,000$명, 실험군 $n_2 = 1,000$명과 같이 극단적 표본 크기 불균형이 발생하면 표준오차가 작은 집단에 의해 왜곡되므로, Welch의 t-검정을 기본으로 적용하고 표본 크기 배분을 가능한 1:1 또는 최소 8:2 이내로 통제해야 함.
- **효과 크기(Effect Size, Cohen's d) 병기의 절대성** : 대규모 트래픽 A/B 테스트에서는 $n$이 수십만 건에 달하여 0.01초의 응답 속도 차이도 $p < 0.0001$로 통계적으로 유의하게 나타남. 그러나 이것이 실제 비즈니스 가치가 있는 차이인지 확인하기 위해 반드시 **코헨의 d(Cohen's d = $(\bar{X}_1 - \bar{X}_2) / s_p$)** 를 함께 산출하여 실질적 유의성을 평가할 것을 제언함.
