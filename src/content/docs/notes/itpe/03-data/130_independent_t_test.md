## 지식 로드맵 내 현재 위치

데이터베이스 → 통계·데이터 분석 → 두 독립집단 평균 비교

## 30초 인출

- 본질: **독립표본 t-검정은** 서로 다른 두 집단의 모평균 차이를 추론하는 방법
- 메커니즘: 평균 차이를 표준오차로 나누고 t 분포와 비교해 귀무가설을 평가
- 통찰: 한계: 집단 독립성·분산 차이를 보지 않고 기본 검정을 쓰면 평균 차이 추론이 어긋남 → 방안: 독립성 점검·Welch 적용 기준·신뢰구간을 분석 절차에 포함

<details>
<summary>핵심 용어</summary>

- **독립표본 t-검정(Independent Samples t-test)** : 서로 독립인 두 모집단의 평균 차이를 검정하는 방법
- **Welch's t-test** : 두 모집단 분산을 같다고 두지 않고 평균 차이를 검정하는 방법
- **합동분산(Pooled Variance)** : 등분산 가정 아래 두 표본분산을 자유도로 가중해 추정한 공통 분산
- **Welch–Satterthwaite 근사** : Welch 검정의 자유도를 표본분산과 표본크기로 근사하는 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. 독립표본 t-검정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **독립표본 t-검정** 은 서로 독립인 두 모집단의 평균 차이를 표본자료로 검정하는 방법 |
| 목적 | 두 집단 평균의 차이가 표본오차만으로 설명 가능한지 판단 |

## Ⅱ. 독립표본 t-검정의 특징

| 특징 | 해석상 의미 |
|---|---|
| 집단 간 독립성 | 같은 대상의 전후 측정이 아닌 서로 다른 두 집단을 비교 |
| 표준오차 기반 추론 | 평균 차이를 변동성과 표본 크기에 맞춰 표준화 |
| 분산 가정별 방식 | 등분산 합동분산 t와 이분산 허용 Welch t의 분모·자유도가 다름 |

## Ⅲ. 독립 집단 판정과 평균 차이 검정 프로세스

```text
두 집단의 표집·실험 설계 확인
    ├─ 같은 대상의 짝·반복 측정 → 대응표본 분석으로 분기
    └─ 독립 집단 → 분포·이상치·분산 차이 확인
                         ↓
                 표준오차 방식 선택
                         ↓
          평균 차이 t값·자유도 계산 → 신뢰구간·p값 해석
```

### 평균 차이 표준화의 하위 계산

```text
집단 1: x̄₁, s₁², n₁ ┐
                     ├─ 평균 차이 Δ=x̄₁−x̄₂
집단 2: x̄₂, s₂², n₂ ┘
                     ↓ 선택한 분산 가정으로 SE 산출
               t=(Δ−Δ₀)/SE → 자유도에 따른 비교
```

독립성은 설계로 확인한다. 표본 크기가 커도 극단값·군집 의존성을 따로 검토한다.

## Ⅳ. 합동분산·Welch t-검정의 비교

| 선택 | 통계량 | 자유도 |
|---|---|---|
| 합동분산 t | $t=\frac{(\bar{x}_1-\bar{x}_2)-\Delta_0}{s_p\sqrt{1/n_1+1/n_2}}$ | $n_1+n_2-2$ |
| Welch t | $t=\frac{(\bar{x}_1-\bar{x}_2)-\Delta_0}{\sqrt{s_1^2/n_1+s_2^2/n_2}}$ | Welch–Satterthwaite 근사 |

합동분산은 $s_p^2=\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}$로 계산. Welch 방식은 개별 표본분산을 사용해 등분산을 전제하지 않음.

반복 측정·짝 자료에는 대응표본 분석을 사용한다. 분산 차이가 있거나 등분산을 확신하기 어려우면 Welch 방식을 검토하고, 평균 차이·신뢰구간·실무 기준을 함께 보고한다.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 반복 측정·군집 자료를 독립으로 취급 | 표집·측정 설계를 확인하고 짝 또는 군집 구조에 맞는 분석 선택 |
| 분산 차이를 무시한 합동분산 검정 | 두 집단 분산과 크기를 확인하고 Welch 검정을 우선 검토 |
| p값만으로 개선의 실제 크기를 단정 | 평균 차이와 신뢰구간을 업무 기준과 함께 제시 |

## Ⅵ. 제언

집단의 의존성과 분산 차이를 놓치면 평균 차이 추론이 흔들린다. 먼저 실험·표집 구조에서 독립성을 확인하고, 분산이 같다고 보기 어려우면 Welch 검정으로 차이와 신뢰구간을 제시한다.
