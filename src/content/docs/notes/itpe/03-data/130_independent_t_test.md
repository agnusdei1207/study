## 연관 키워드

- 독립표본 t-검정

## Ⅰ. 독립표본 t-검정의 개요

- 핵심 요약 : 서로 독립적으로 추출된 두 표본 집단의 평균 차이가 통계적으로 유의미한지를 판정하는 모수적 가설검정 기법
- 개념 : 독립표본 t-검정(Independent Samples T-Test)은 서로 독립적으로 추출된 두 개의 표본 집단으로부터 얻은 연속형 데이터의 평균값을 비교하여, 두 집단이 추출된 원래 모집단의 평균 간에 통계적으로 유의미한 차이가 존재하는지 판정하는 모수적 가설검정 기법
- 배경 : 두 집단의 평균 비교 시 단순 평균 차이만으로는 표본 오차에 의한 차이인지 실제 모집단 차이인지 구분 불가하므로 확률 이론 기반의 검정 절차 필요
- 필요성 : 온라인 서비스의 표준 A/B 테스트(대조군 Control vs 실험군 Treatment)에서 실험 효과의 통계적 유의성을 객관적으로 입증
- 주요 목적 : 두 독립 모집단의 평균 차이가 우연인지 실제 효과인지를 유의수준(α) 기반으로 판정

```text
[ 독립표본 t-검정의 기본 구조 ]
[모집단 1: 평균 μ1] --(표본 추출)--> [표본 1: n1개, 평균 X1]
[모집단 2: 평균 μ2] --(표본 추출)--> [표본 2: n2개, 평균 X2]
                    |
                    v
        [H0: μ1 = μ2 (귀무가설: 차이 없음)]
        [H1: μ1 ≠ μ2 (대립가설: 차이 있음)]
                    |
                    v
        [검정통계량 t 산출 → p-값 판정]
```

## Ⅱ. 독립표본 t-검정의 특징

- 핵심 요약 : 독립성·정규성·등분산성 3대 선행 가정을 전제로 하며, 가정 위반 시 Welch's t-검정 또는 비모수 검정으로 전환
- 특징 1 : 3대 선행 가정 필수 — 독립성(Independence), 정규성(Normality), 등분산성(Homogeneity of Variance) 가정이 검정 신뢰도의 전제 조건
- 특징 2 : 등분산 여부에 따른 분기 — Levene 검정 결과에 따라 Student's t-검정(등분산) 또는 Welch's t-검정(이분산) 선택
- 특징 3 : 비모수적 대안 존재 — 정규성 위반 시 Mann-Whitney U 검정(Mann-Whitney U Test)으로 전환 가능
- 특징 4 : 효과 크기(Effect Size) 병행 필요 — 대규모 표본에서는 미세한 차이도 유의미하게 나타나므로 Cohen's d 등 실질적 유의성 지표 병행

```text
[ 독립표본 t-검정 사전 검증 파이프라인 ]
1. 독립성 (Independence)  : 두 그룹의 피험자가 상호 배타적이고 독립적이어야 함 (실험 설계 확인)
2. 정규성 (Normality)     : 두 집단 각각의 데이터가 정규분포를 따라야 함 (Shapiro-Wilk)
3. 등분산성 (Homogeneity) : 두 집단의 모분산이 동일한가? (Levene 검정 수행)
         |
         +---> 등분산 만족 (p >= 0.05) : [Student's t-검정 (합동분산 적용)]
         +---> 등분산 위반 (p < 0.05)  : [Welch's t-검정 (자유도 보정)]
```

## Ⅲ. 독립표본 t-검정의 구조 (흐름)

- 핵심 요약 : 가설 설정 → 선행 가정 검증 → 검정 선택 → 통계량 산출 → 유의성 판정의 5단계 절차로 구성

```text
[ 독립표본 t-검정 수행 절차 ]
(1) 가설 설정
     H0: μ1 = μ2  vs  H1: μ1 ≠ μ2
         |
         v
(2) 선행 가정 검증
     독립성 확인 → 정규성 검증(Shapiro-Wilk) → 등분산성 검증(Levene)
         |
         v
(3) 검정 방법 선택
     등분산 만족 → Student's t-검정
     등분산 위반 → Welch's t-검정
     정규성 위반 → Mann-Whitney U 검정
         |
         v
(4) 검정통계량 산출 및 p-값 계산
         |
         v
(5) 판정: p < α → 귀무가설 기각 (유의미한 차이 존재)
         p ≥ α → 귀무가설 채택 (유의미한 차이 없음)
```

| 가정 상황 | 사용 검정 명칭 | 검정통계량 t 공식 | 자유도(df) |
| :--- | :--- | :--- | :--- |
| 등분산 가정(Equal Variance) | Student's t-검정 | t = (X̄1 - X̄2) / (sp × √(1/n1 + 1/n2)) | n1 + n2 - 2 |
| 이분산 가정(Unequal Variance) | Welch's t-검정 | t = (X̄1 - X̄2) / √(s1²/n1 + s2²/n2) | 근사치 적용 |

## Ⅳ. 대응표본 t-검정과의 비교

- 핵심 요약 : 독립표본은 서로 다른 두 집단, 대응표본은 동일 집단의 전후 비교라는 표본 설계 차이가 핵심

| 비교 항목 | 독립표본 t-검정 | 대응표본 t-검정(Paired t-Test) |
| :--- | :--- | :--- |
| **표본 구조** | 두 독립 집단(서로 다른 개체) | 동일 집단의 전후 측정(같은 개체) |
| **비교 대상** | 집단 간 평균 차이 | 개체별 전후 차이(d = X1 - X2)의 평균 |
| **검정 통계량** | 두 표본 평균 차이를 합동분산으로 표준화 | 차이값 d의 평균을 표준오차로 표준화 |
| **분산 구조** | 두 집단의 분산 결합 | 개체 간 분산 제거로 검정력 우위 |
| **적용 사례** | A/B 테스트, 남녀 평균 비교 | 약물 투여 전후, 교육 효과 전후 |

## Ⅴ. 독립표본 t-검정의 장점과 한계

- 핵심 요약 : 이해와 적용이 간편한 반면 가정 위반 시 신뢰도 저하와 표본 크기 불균형에 따른 검정력 문제 존재
- 장점 :
  1. 적용 용이성 — 검정 절차가 명확하고 통계 소프트웨어 기본 제공
  2. 해석 직관성 — t-통계량과 p-값으로 결과 해석 간편
  3. 보정 체계 존재 — Welch's t-검정으로 등분산 가정 완화 가능
- 한계점 :
  1. 정규성 및 등분산성 가정 위반 시 검정 신뢰도 추락
     - 해결 방안 : Welch's t-검정을 기본 검정으로 채택, 표본이 비정규적인 경우 비모수 검정인 Mann-Whitney U 검정 병행
  2. 표본 크기 불균형(Unbalanced Sample Size)에 따른 통계적 검정력 저하
     - 해결 방안 : 검정력 분석(Power Analysis: G*Power)을 통한 사전 최소 표본 크기 및 최적 할당 비율 도출, 순차 검정(Sequential Testing) 프레임워크 적용
  3. 네트워크 효과(Network Effect) 및 SUTVA(Stable Unit Treatment Value Assumption) 위반
     - 해결 방안 : 사용자 단위 무작위화 대신 클러스터 단위 무작위화(Cluster Randomization: 지역 단위, 네트워크 서브그래프 단위 분할) 적용

```text
[ 표본 크기 불균형 영향도 ]
[균형 배분: 50:50] --> [표준오차 최소, 검정력 최대]
[불균형 배분: 90:10] --> [표준오차 왜곡, 검정력 저하]
[극단 배분: 99:1] --> [실질적 유효 표본 감소, 2종 오류 급증]
```

## Ⅵ. 독립표본 t-검정에 대한 기술사적 제언

- 핵심 요약 : 효과 크기 병행, 표본 크기 통제, 순차 검정 도입을 통한 실무 A/B 테스트 신뢰도 확보 필요
- 제언 1 : 효과 크기(Effect Size, Cohen's d) 병기의 절대성 — 대규모 트래픽 A/B 테스트에서는 n이 수십만 건에 달하여 미세한 차이도 p < 0.0001로 통계적으로 유의하게 나타나지만, 실제 비즈니스 가치가 있는 차이인지 확인하기 위해 Cohen's d를 함께 산출하여 실질적 유의성 평가 필요
- 제언 2 : 표본 크기 불균형의 영향 통제 — 대조군 n1 = 100,000명, 실험군 n2 = 1,000명과 같은 극단적 표본 크기 불균형이 발생하면 표준오차가 작은 집단에 의해 왜곡되므로 Welch's t-검정을 기본으로 적용하고 표본 크기 배분을 가능한 1:1 또는 최소 8:2 이내로 통제 필요
- 제언 3 : 정규성 위반 시 비모수 검정 전환 기준 명확화 — 두 집단 중 어느 한 집단이라도 표본 크기가 30건 미만이고 Shapiro-Wilk 검정에서 정규성이 기각(p < 0.05)될 경우, 모수적 t-검정을 수행하면 1종 오류가 급증하므로 순위 기반 비모수 검정으로 전환 필요

## Ⅶ. 결론

- 핵심 요약 : 독립표본 t-검정은 A/B 테스트의 핵심 검정 기법이나 가정 검증과 효과 크기 병행이 신뢰도 확보의 핵심
- 요약 : 독립표본 t-검정은 서로 독립적인 두 집단의 평균 차이를 검정하는 표준적 모수적 기법이며, 독립성·정규성·등분산성 가정을 전제로 Student's t-검정 또는 Welch's t-검정이 선택 적용
- 시사점 : 실무 A/B 테스트에서는 통계적 유의성(p-값)만으로 의사결정하지 말고 효과 크기와 신뢰구간을 함께 보고해야 하며, 표본 크기 설계 단계에서 검정력 분석을 통해 적절한 표본 규모와 배분 비율을 사전에 결정하는 체계적 접근이 필요
