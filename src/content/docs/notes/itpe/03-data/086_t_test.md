## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **t-검정(독립표본·대응표본)**

## 30초 인출

- 본질: t-검정은 모분산을 모를 때 표본분산으로 표준오차를 추정해 평균에 관한 가설을 검정하는 방법
- 메커니즘: 표본 관계(한 집단·독립 두 집단·짝지은 관측)를 확인해 t = 평균 차이 ÷ 추정 표준오차를 계산하고, 설계에 맞는 자유도의 t-분포와 비교해 p값·신뢰구간·효과 크기를 해석
- 통찰: 짝지은 자료를 독립표본으로 다루면 표준오차가 왜곡되고 등분산이 불확실하면 pooled 검정이 부정확하므로, 자료의 관계를 먼저 확인해 대응표본 또는 Welch 방식을 선택

<details>
<summary>핵심 용어</summary>

- **t-검정(Student's t-test)** : 표본분산으로 표준오차를 추정해 평균을 검정하는 방법
- **자유도(df)** : 통계량의 분포를 정하는 독립 정보의 수
- **단일표본 t-검정** : 한 집단의 평균을 기준값과 비교
- **독립표본 t-검정** : 서로 독립인 두 집단의 평균을 비교
- **대응표본 t-검정** : 같은 대상의 전후나 짝지은 관측의 평균 차이를 검정
- **Welch t-검정** : 두 집단의 분산이 같다고 가정하지 않는 독립표본 검정
- **효과 크기** : 평균 차이의 실질적 크기

</details>

## 2~4교시 25점 답안

## Ⅰ. t-검정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **t-검정** 은 표본분산으로 표준오차를 추정해 평균에 관한 가설을 검정하는 방법 |
| 목적 | 모분산을 모를 때 평균 차이가 우연한 표본오차만으로 설명되는지 판단 |

## Ⅱ. 특징

| 특징 | 의미 | 주의 |
|---|---|---|
| 모분산 미지 | 표본분산으로 표준오차 추정 | 표본 크기에 따라 불확실성 변화 |
| 자유도 반영 | 설계에 맞는 t-분포 사용 | 단일·독립·대응의 자유도 구별 |
| 평균 차이 판단 | 기준값·집단 간 평균 차이 평가 | p값과 효과 크기 구분 |

## Ⅲ. 검정 선택과 통계량

```text
표본 관계 확인
 ├ 한 집단 vs 기준값 → 단일표본
 ├ 서로 다른 두 집단 → 독립표본 (분산 조건이 불확실하면 Welch)
 └ 같은 대상의 전후·짝 → 쌍별 차이에 대한 단일표본 검정
        ↓
t = 평균 차이 / 추정 표준오차 → 자유도의 t-분포와 비교 → p값·신뢰구간·효과 크기 해석
```

```text
단일표본: t = (x̄ − μ0) / (s / √n), 자유도 n − 1
대응표본: 쌍별 차이 d의 평균 d̄ 에 대해 t = d̄ / (s_d / √n)
```

## Ⅳ. 유형 비교와 가정

| 유형 | 적용 조건 | 통계량의 핵심 |
|---|---|---|
| 단일표본 | 한 모집단 평균과 기준값 비교 | (x̄ − μ0) / (s/√n) |
| 독립표본 | 서로 독립인 두 집단 평균 비교 | 평균 차이 ÷ 두 표본의 표준오차 |
| 대응표본 | 짝지은 관측의 평균 차이 | 쌍별 차이 d를 단일표본처럼 검정 |

| 가정 | 해석과 주의 |
|---|---|
| 독립성 | 표본 추출·실험 설계로 확보, 검정 하나로 보장되지 않음 |
| 정규성 | 작은 표본에서는 분포(대응표본은 쌍별 차이의 분포)를 확인, 큰 표본은 근사하되 이상치 영향 고려 |
| 등분산성 | pooled 독립표본 검정의 가정, 불확실하면 Welch |
| 유의성 | p값을 효과의 크기·업무 중요성과 동일시하지 않음 |

z-검정은 모분산을 알거나 표본이 커서 표준정규분포로 근사할 때 쓰고, 중심극한정리가 표본평균의 정규 근사를 뒷받침.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 짝지은 자료를 독립표본으로 처리해 표준오차 왜곡 | 대상 식별자로 짝을 확인하고 쌍별 차이로 검정 |
| 등분산 미확인 상태의 pooled 검정 | 집단별 분산·표본 수를 확인하고 불확실하면 Welch |
| p값만으로 업무 효과 단정 | 효과 크기·신뢰구간 병행 |

## Ⅵ. 제언

자료의 관계와 분산 조건을 먼저 확인해 검정 유형을 정하고 효과 크기와 신뢰구간을 함께 보고

```text
표본 관계 확인 → 검정 유형 선택 → 가정 점검 → p값 + 효과 크기 + 신뢰구간
```

| 구분 | 유형 확인 없이 적용 | 제언: 관계·가정 확인 |
|---|---|---|
| 표준오차 | 왜곡 위험 | 설계에 맞음 |
| 결론 | p값만 | 효과 크기 병행 |
