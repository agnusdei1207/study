## 답안 골격
```text
[t-검정 (Student's t-test)] ◀━━ 머리: Ⅶ 내 의견 (정규성·등분산성 사전 검정 파이프라인 연계 및 A/B 테스트 의사결정)
 ┃
 ┣━ Ⅰ 개요 ───── 모집단의 표준편차($\sigma$)를 알 수 없을 때, 표본표준편차($s$)를 이용하여 모평균의 차이가 통계적으로 유의미한지 판별하는 가설검정 방법
 ┣━ Ⅱ 특징 ───── 모분산 미지의 소표본($n < 30$) 대응 · 자유도($df$) 기반 t-분포 활용 · 중심극한정리 결합 시 $n \ge 30$도 확장 · 정규성 가정
 ┣━ Ⅲ 구조 ───── 검정통계량($t = \frac{\bar{x} - \mu}{s / \sqrt{n}}$) / 자유도($df = n - 1$) / 귀무가설($H_0$) / 대립가설($H_1$) / 유의수준($\alpha$)
 ┣━ Ⅳ 흐름 ───── ① 가설 수립($H_0, H_1$) → ② 정규성 검정(Shapiro-Wilk) → ③ t-통계량 및 p-value 계산 → ④ 기각역 판정($p < \alpha$) → ⑤ 결론 도출
 ┣━ Ⅴ 비교 ───── t-검정 vs z-검정 vs ANOVA (모분산 미지·소표본 vs 모분산 기지·대규모 표본 vs 3개 이상 집단 평균 비교)
 ┗━ Ⅵ 실무 ───── 단일표본(기준값 비교) vs 독립표본(A/B 테스트) vs 대응표본(배포 전/후 레이턴시 비교)
```
- 필수 키워드: t-검정 · t-분포 · 모분산 미지 · 표본표준편차 · 자유도($df$) · p-value · 독립표본 · 대응표본(Paired)
- 배점 전략: 10점 = Ⅰ → Ⅲ 수식 및 t-분포 도식 → Ⅴ z-검정과의 비교표 / 25점 = Ⅰ~Ⅶ, Ⅵ 3대 유형(단일/독립/대응) 공식 및 실무 A/B 테스트 판정 절차
- 기출: 132회 2교시 1번 `중심극한정리, t-검정, z-검정을 설명하시오.` → Ⅰ t-검정 개념 + Ⅲ t-통계량 수식 + Ⅴ z-검정과의 조건별 비교

## 한 줄 본질
- 모집단의 분산을 알 수 없는 현실 상황에서 z-검정 적용 불가 → 표본 표준편차와 자유도에 따른 두터운 꼬리(Fat Tail)의 t-분포를 적용 → 소표본에서도 엄격한 모평균 차이 유의성 검정 / 정규성 위배 시 1종 오류 급증

## 핵심 그림
```text
[t-검정 통계량 구조 및 3대 검정 유형]

 [t-통계량 산출 구조]
            (표본평균) - (모평균)          $\bar{x} - \mu$
       t = ─────────────────────── = ────────────────
             (표본표준오차)              $s / \sqrt{n}$
             * 자유도 df = n - 1

 [t-검정 3대 유형 분류]
  1. 단일표본 t-검정 (One-sample)
     : 한 집단의 표본평균이 알려진 기준값($\mu_0$)과 같은지 검정
     (예: 신규 캐시 엔진의 응답시간이 SLA 50ms를 만족하는가?)

  2. 독립표본 t-검정 (Two-sample Independent)
     : 서로 다른 두 독립 집단의 평균 차이 검정
     (예: UI 개편 A안 사용자 그룹 vs B안 사용자 그룹의 체류시간 차이)

  3. 대응표본 t-검정 (Paired-sample)
     : 동일 집단의 전/후(Before-After) 변화량 차이 검정
     (예: DB 인덱스 튜닝 전 vs 튜닝 후 동일 쿼리 세트의 실행시간 차이)
```

## 핵심 용어
- 자유도(Degrees of Freedom, $df$): 통계적 추정에서 자유롭게 값을 취할 수 있는 독립적인 관측치의 수($n - 1$)로, 자유도가 커질수록 t-분포는 표준정규분포 $N(0,1)$에 수렴
- p-value(유의확률): 귀무가설($H_0$, 차이가 없다)이 참이라는 전제하에 현재 표본에서 관측된 결과 이상의 극단적인 값이 나타날 확률로, $\alpha(0.05)$보다 작으면 귀무가설 기각

## 핵심 통찰
- 표본 수가 커지면($n \ge 30$) t-검정과 z-검정의 결과는 사실상 같아짐 → 그러나 현실 데이터 과학에서 모분산($\sigma$)을 알고 있는 경우는 0에 수렴하므로 모든 실무 가설검정은 t-검정을 기본으로 사용
- 독립표본 t-검정 수행 전 반드시 '등분산 검정(Levene test)'을 거쳐야 함 → 두 집단의 분산이 다르면 일반 t-검정 대신 자유도를 수정한 '웰치의 t-검정(Welch\'s t-test)'을 적용해야 1종 오류를 방지
- 표본 크기($n$)가 수십만 건으로 너무 커지면, 아주 미미하고 무의미한 차이(예: 로딩속도 0.001ms 차이)도 p < 0.001로 유의하게 나옴 → 효과 크기(Cohen\'s d)를 반드시 병행 확인해야 함

## 이웃 토픽과 구분
- t-검정 vs z-검정: t-검정 = 모분산 모름, 표본표준편차($s$) 사용, t-분포 기준 판정 / z-검정 = 모분산($\sigma$)을 알거나 대규모 표본에서 표준정규분포 기준 판정

## 문제·원인·대책
- 적용 상황: 결제 페이지 신규 UX 적용 후 구매 전환율 향상 여부를 검증하는 A/B 테스트
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| A/B 테스트 표본 20개로 t-검정 후 p < 0.05가 나와 배포했으나 실제 전환율 미개선 | 소표본 데이터의 비정규성(심한 왜곡) 무시 | Shapiro-Wilk 정규성 검정 선행 및 위배 시 비모수 검정(Wilcoxon/Mann-Whitney) 수행 | 가짜 긍정(1종 오류) 제거 및 의사결정 신뢰성 확보 |
| A안과 B안의 표본 분산이 5배 이상 차이나는데 단순 t-검정 수행 | 등분산성 가정 위배로 검정통계량 신뢰 구간 왜곡 | Levene 검정 확인 후 등분산 위배 시 Welch\'s t-test 적용 | 이분산 상황에서도 정밀한 평균 차이 유의성 입증 |

## 이렇게 출제된다
- 제132회 2교시 1번: "중심극한정리, t-검정, z-검정을 설명하시오." → 요구 포인트: t-검정의 정의와 수식 + 모분산 미지 시 표본분산 대체 원리 + 자유도와 t-분포 곡선 특성 + z-검정과의 상호 비교(적용 조건, 통계량 수식)

## 내 의견
- [A/B 테스팅 플랫폼의 맹목적 p-value 통과 배포 방지] 실험 중 p-value를 실시간으로 계속 들여다보며 유의수준을 넘는 순간 실험을 조기 종료하는 'Peeking P-hacking' 사고 만연 → 나라면: 사전 파워 분석(Power Analysis)을 통해 최소 표본 크기($N$)를 확정하고, 조기 종료 시에는 순차 가설 검정(Sequential Testing)이나 알파 소진(Alpha Spending) 보정 알고리즘을 시스템에 강제 내재화

## 찾아볼 것
- 3개 이상의 처리군을 비교할 때 t-검정을 반복하면 1종 오류가 급증하는 문제(Family-wise Error Rate)와 ANOVA/본페로니 보정(Bonferroni Correction)
