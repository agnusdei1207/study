## 연관 키워드

- t-검정, Student t 분포, 자유도, 일표본·독립표본·대응표본, Welch

## Ⅰ. t-검정의 개요

- 핵심 요약 : t-검정은 모분산을 모를 때 표본 표준편차로 표준화하고 자유도에 따른 t 분포로 평균 가설을 검정하는 방법.
- 개념 : t-검정은 모분산을 모를 때 표본 표준편차로 표준화하고 자유도에 따른 t 분포로 평균 가설을 검정하는 방법.
- 배경 및 필요성 : 실제 분석에서는 모표준편차를 모르는 평균 비교가 일반적.
- 주요 목적 : 표본 변동을 반영한 평균 추론·차이 검정.

## Ⅱ. t-검정의 특징 및 장점

- 핵심 요약 : Student t: 표준오차에 표본표준편차 사용 → 모분산 불확실성 반영; 검정 설계: 일표본·독립표본·대응표본 선택 → 비교 구조 반영; Welch t: 등분산 가정 완화 → 분산·표본수 불일치에 대응.

1. Student t: 표준오차에 표본표준편차 사용 → 모분산 불확실성 반영
2. 검정 설계: 일표본·독립표본·대응표본 선택 → 비교 구조 반영
3. Welch t: 등분산 가정 완화 → 분산·표본수 불일치에 대응

## Ⅲ. t-검정의 구조 (흐름)

- 핵심 요약 : 비교대상·독립성 확인 → H₀·H₁·유의수준 설정 → 표본구조별 t통계량·자유도 계산 → p값·신뢰구간 산출 → 효과크기·가정·이상값 해석.

```text
비교대상·독립성 확인
  ↓
H₀·H₁·유의수준 설정
  ↓
표본구조별 t통계량·자유도 계산
  ↓
p값·신뢰구간 산출
  ↓
효과크기·가정·이상값 해석
```

- 핵심 구성 : 질문 → 일표본/독립/대응 설계 → t통계량·자유도 → t분포 → p값·구간

```text
질문 → 일표본/독립/대응 설계 → t통계량·자유도 → t분포 → p값·구간
```

## Ⅳ. 비교: Student t-검정 / z-검정

- 핵심 요약 : 기준분포 기준 — Student t-검정: 자유도 의존 t 분포; z-검정: 표준정규분포.

| 비교 기준 | Student t-검정 | z-검정 |
| --- | --- | --- |
| 표준오차 | 표본 표준편차 사용 | 모표준편차 알려짐 또는 정규근사 |
| 기준분포 | 자유도 의존 t 분포 | 표준정규분포 |
| 대표 상황 | 모분산 미지 평균 비교 | 모분산 알려진 평균·비율 근사 |

## Ⅴ. t-검정의 한계와 방안

- 핵심 요약 : 표본구조 오선택·가정 위반 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 표본구조 오선택 | 대응자료를 독립표본으로 처리하면 SE 오류 | 쌍·집단 독립성 및 Welch 여부 확인 | 설계 오류 |
| 가정 위반 | 작은 표본·심한 왜도·이상값 영향 | 분포·잔차 진단·강건/비모수 대안 검토 | 결론 민감도 |
| 유의성 과해석 | p값만으로 실무 의미·효과 크기 판단 | 효과크기·신뢰구간·다중검정 맥락 보고 | 효과크기 |

## Ⅵ. t-검정의 제언

- 핵심 요약 : 분석자는 독립성·대응 여부와 등분산 전제를 먼저 결정하고 표본구조에 맞는 Welch·대응·일표본 t 검정 및 효과크기 보고.
- 실행 제안 : 통계 담당자는 독립·대응 표본과 등분산 여부를 사전 확인하고 표본구조에 맞는 검정·효과크기 보고.

## Ⅶ. t-검정의 결론

- 핵심 요약 : t-검정의 분포 선택은 모분산 미지와 표본설계에 따른 것이며 작은 표본에서 가정 점검의 중요성이 커짐.
- 시사점 : 표본구조와 분산 조건에 맞는 검정 선택 및 효과크기 보고가 평균 비교의 해석을 결정.
