## 연관 키워드

- 시계열, AR(p), MA(q), 정상성, 자기상관, ACF, PACF

## Ⅰ. 시계열 AR·MA 모델의 개요

- 핵심 요약 : AR(p)는 과거 관측값의 선형결합으로 현재값을 설명하고 MA(q)는 현재·과거 백색잡음의 선형결합으로 설명하는 시계열 모형.
- 개념 : AR(p)는 과거 관측값의 선형결합으로 현재값을 설명하고 MA(q)는 현재·과거 백색잡음의 선형결합으로 설명하는 시계열 모형.
- 배경 및 필요성 : 시간 순서 의존성을 무시한 독립 관측 분석은 예측과 불확실성 추정을 왜곡.
- 주요 목적 : 자기상관 구조를 모형화해 시계열 설명·예측.

## Ⅱ. 시계열 AR·MA 모델의 특징 및 장점

- 핵심 요약 : AR: 과거 값 의존, 정상성 조건 필요 → PACF로 차수 단서; MA: 과거 충격 의존 → ACF로 차수 단서; ARMA: 정상 시계열의 AR·MA 결합 → 잔차 백색성 검증.

1. AR: 과거 값 의존, 정상성 조건 필요 → PACF로 차수 단서
2. MA: 과거 충격 의존 → ACF로 차수 단서
3. ARMA: 정상 시계열의 AR·MA 결합 → 잔차 백색성 검증

## Ⅲ. 시계열 AR·MA 모델의 구조 (흐름)

- 핵심 요약 : 시계열·결측·계절성 확인 → 정상성·변환·차분 검토 → ACF/PACF·정보기준으로 차수 선정 → 계수 추정·잔차 진단 → 시간순 검증·예측 평가.

```text
시계열·결측·계절성 확인
  ↓
정상성·변환·차분 검토
  ↓
ACF/PACF·정보기준으로 차수 선정
  ↓
계수 추정·잔차 진단
  ↓
시간순 검증·예측 평가
```

- 핵심 구성 : 관측 시계열 → 정상성 검토 → AR/MA 차수 식별 → 추정 → 잔차 백색성 → 예측

```text
관측 시계열 → 정상성 검토 → AR/MA 차수 식별 → 추정 → 잔차 백색성 → 예측
```

## Ⅳ. 비교: AR(p) / MA(q)

- 핵심 요약 : 전형적 식별 단서 기준 — AR(p): PACF 절단·ACF 감쇠 (AR); MA(q): ACF 절단·PACF 감쇠 (MA).

| 비교 기준 | AR(p) | MA(q) |
| --- | --- | --- |
| 설명변수 | 과거 관측값 yₜ₋ᵢ | 현재·과거 오차 εₜ₋ⱼ |
| 전형적 식별 단서 | PACF 절단·ACF 감쇠 (AR) | ACF 절단·PACF 감쇠 (MA) |

## Ⅴ. 시계열 AR·MA 모델의 한계와 방안

- 핵심 요약 : 비정상성·차수 과적합 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 비정상성 | 추세·계절성이 정상모형 가정 위반 | 변환·차분·계절모형 검토 | 잔차 자기상관 |
| 차수 과적합 | 짧은 표본에서 파라미터 과다 | AIC/BIC·시간검증·간명성 비교 | 검증오차 |
| 구조변화 | 운영 환경 변화로 과거 관계 무효 | 롤링 검증·재학습·변화점 감시 | 예측오차 추이 |

## Ⅵ. 시계열 AR·MA 모델의 제언

- 핵심 요약 : 시계열 분석가는 시간순 분할로 검증하고 정상성·잔차 진단 결과, 예측구간 및 재추정 조건을 함께 운영.
- 실행 제안 : 분석가는 정상성 변환·ACF/PACF·잔차 백색성 진단을 기록하고 시간순 롤링검증으로 차수 선택.

## Ⅶ. 시계열 AR·MA 모델의 결론

- 핵심 요약 : AR·MA는 정상성과 선형 의존 구조를 가정하는 기초 모형이며 진단 없는 차수 선택은 신뢰할 수 없음.
- 시사점 : AR·MA 차수는 ACF/PACF만으로 확정하지 말고 잔차 진단과 시간순 예측성능으로 확인.
