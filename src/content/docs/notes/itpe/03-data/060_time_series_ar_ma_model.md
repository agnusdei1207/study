## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **시계열 AR·MA 모형**

## 30초 인출

- 본질: 자기회귀모형(AR)은 과거 관측값의 선형결합으로, 이동평균모형(MA)은 과거 오차항의 선형결합으로 현재값을 설명하는 정상 시계열 모형
- 메커니즘: 정상성을 진단해 비정상이면 차분하고, ACF·PACF로 차수를 식별해 AR(p)·MA(q)·ARMA를 추정한 뒤 적합도를 검정하고 예측 오차를 감시
- 통찰: AR·MA는 정상 시계열을 전제하므로 추세·분산 변화가 있으면 차분(ARIMA)하고, 차수는 ACF·PACF와 AIC·BIC로 정해 과적합을 피함

<details>
<summary>핵심 용어</summary>

- **AR(p)** : 과거 p개 관측값의 선형결합과 오차로 현재값을 설명하는 모형
- **MA(q)** : 현재와 과거 q개 오차항의 선형결합으로 현재값을 설명하는 모형
- **ARMA·ARIMA** : AR과 MA를 결합한 모형 / 차분(d)을 포함한 모형
- **정상성(Stationarity)** : 평균·분산·자기상관이 시간에 따라 변하지 않는 성질
- **ACF·PACF** : 자기상관함수 / 편자기상관함수
- **차분(Differencing)** : 추세를 제거하기 위해 인접 값의 차이를 취하는 변환
- **AIC·BIC** : 적합도와 모형 복잡도를 함께 반영하는 정보량 기준

</details>

## 2~4교시 25점 답안

## Ⅰ. 시계열 AR·MA 모형의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **AR** 은 과거 관측값, **MA** 는 과거 오차항의 선형결합으로 현재값을 설명하는 정상 시계열 모형 |
| 목적 | 과거 패턴을 모수화해 시계열을 설명하고 단기 예측 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 선형 구조 | 과거 값·오차의 가중합, 모수는 최소제곱·최우추정으로 산출 |
| 정상성 전제 | 추세·분산 변화가 있으면 차분 필요 |
| 차수의 해석 | AR(p)의 p는 영향이 이어지는 과거 값 수, MA(q)의 q는 충격이 남는 기간 |

## Ⅲ. 모형 구조와 적합 절차

```text
AR(p): Y(t) = c + φ1·Y(t-1) + … + φp·Y(t-p) + ε(t)   충격이 감쇠하며 지속
MA(q): Y(t) = μ + ε(t) + θ1·ε(t-1) + … + θq·ε(t-q)   충격이 q기간 후 소멸
```

```text
시계열 → 정상성 진단 ─ 비정상 → 차분·변환 → ARIMA
                     └ 정상 → ACF·PACF로 차수 식별 → 추정·적합도 검정 → 예측·오차 감시
```

## Ⅳ. AR·MA·ARIMA·지수평활 비교

| 모형 | 설명 요소 | 차수 판정 | 대상 |
|---|---|---|---|
| AR(p) | 과거 관측값 | PACF가 p차에서 절단, ACF 점진 감쇠 | 정상 |
| MA(q) | 과거 오차항 | ACF가 q차에서 절단, PACF 점진 감쇠 | 정상 |
| ARMA(p,q) | 과거 값 + 과거 오차 | ACF·PACF 모두 점진 감쇠 | 정상 |
| ARIMA(p,d,q) | d차 차분 후 ARMA | 차분 후 정상성 확인 | 추세 포함 |
| 지수평활법 | 지수 감쇠 가중 과거 값 | 수준·추세·계절 판단 | 단기 예측 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 비정상 시계열에 ARMA 직접 적용 시 모수 왜곡 | 정상성 진단 후 차분(ARIMA) |
| 구조 변화·외부 충격에 예측 저하 | 롤링 재추정과 예측 오차 감시 |
| 계절성·특이값 미반영 | SARIMA 적용과 이상치 보정 |
| 차수 과대·과소로 과적합 | ACF·PACF와 AIC·BIC 병행 |

## Ⅵ. 제언

정상성을 확인한 뒤 ACF·PACF와 정보량 기준으로 차수를 정하고, 운영 중 예측 오차를 감시해 재추정

```text
정상성 진단 → 차분 → 차수 식별(ACF·PACF, AIC·BIC) → 적합도 검정 → 오차 감시·재추정
```

| 구분 | 비정상 자료 직접 적용 | 제언: 진단 후 적용 |
|---|---|---|
| 모수 | 왜곡 | 안정 |
| 운영 | 방치 | 오차 감시 |
