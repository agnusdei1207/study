## 30초 인출

- 본질: 시점 순 관측값의 미래를 과거 패턴으로 설명하는 시계열 모형, **자기회귀모형(AR)** 은 과거 관측값의 선형결합, **이동평균모형(MA)** 은 과거 오차항의 선형결합
- 메커니즘: 정상성 확보 후 ACF·PACF로 차수를 식별해 AR(p)·MA(q)·ARMA(p,q)를 적합, 비정상 시계열은 차분을 더한 ARIMA로 확장
- 통찰: 시계열 데이터의 정상성(Stationarity)을 차분과 변환으로 확보한 후 자기상관함수(ACF)와 편자기상관함수(PACF)의 절단 특성 기반 최적 차수 선정 필수

<details>
<summary>핵심 용어</summary>

- **시계열(Time Series)** : 일정 시간 간격으로 관측된 값의 순서열
- **정상성(Stationarity)** : 평균·분산·자기공분산이 시점에 관계없이 일정한 시계열 성질
- **자기회귀모형(Autoregressive Model, AR)** : 과거 p개 관측값의 선형결합에 백색잡음을 더해 현재값을 설명하는 모형
- **이동평균모형(Moving Average Model, MA)** : 현재·과거 q개 백색잡음(오차항)의 선형결합으로 현재값을 설명하는 모형
- **백색잡음(White Noise)** : 평균 0·일정 분산·시점 간 무상관을 갖는 확률오차항
- **자기상관함수(ACF)** : 시차별 관측값 간 상관 정도를 나타내는 함수
- **편자기상관함수(PACF)** : 중간 시차의 영향을 제거한 순수 시차별 상관 함수
- **ARIMA 모형(Autoregressive Integrated Moving Average Model)** : 비정상 시계열을 차분 후 ARMA를 적용하는 모형
- **차분(Differencing)** : 인접 시점 관측값의 차를 계산해 추세를 제거하는 변환
- **지수평활법(Exponential Smoothing)** : 시점이 가까울수록 큰 지수 가중치를 부여해 수준·추세·계절을 평활하는 예측법

## 2~4교시 25점 답안

## Ⅰ. 시계열 AR·MA 모형의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **자기회귀모형(AR)** 은 과거 관측값의 선형결합, **이동평균모형(MA)** 은 과거 오차항의 선형결합으로 현재값을 설명하는 정상 시계열 모형 |
| 목적 | 과거 패턴의 통계적 모수화를 통한 수요·부하·지표 등 시계열의 설명과 단기 예측 |

## Ⅱ. AR·MA 모형의 핵심 특징

| 특징 | 의미 |
|---|---|
| 모수 선형 구조 | 과거 값·오차의 가중합 형태, 최소제곱·최우추정으로 모수 산출 |
| 정상성 전제 | AR·MA의 이론적 성질이 정상 과정에서만 성립, 추세·분산 변화 시계열은 차분 필요 |
| 차수의 해석 | AR(p)의 p는 영향이 지속되는 과거 값 개수, MA(q)의 q는 충격이 남는 기간 |
| 메모리 성질 | AR은 과거 값 자체의 기억, MA는 유한 기간의 충격 기억 |

## Ⅲ. 시계열 모형 적합 체계와 AR·MA 구조

### 시계열 모형 적합 전체 흐름

```text
관측 시계열 확보
    ↓
정상성 진단 (평균·분산·ACF 감쇠 확인)
    ├─ 비정상 → 차분·변환 → ARIMA 계열
    └─ 정상 → AR·MA·ARMA 대상
    ↓
ACF·PACF로 차수 식별
    ↓
AR(p)·MA(q)·ARMA(p,q) 추정·적합도 검정
    ↓
예측과 오차 감시, 모수 재추정
```

### AR(p)와 MA(q)의 구조 확대

```text
AR(p): 과거 값 → 현재값 설명
    Y(t) = c + φ1·Y(t-1) + … + φp·Y(t-p) + ε(t)
    설명 요소 : 이전 시점 관측값
    충격 전파 : 무한 지속(감쇠형 ACF)

MA(q): 과거 오차 → 현재값 설명
    Y(t) = μ + ε(t) + θ1·ε(t-1) + … + θq·ε(t-q)
    설명 요소 : 백색잡음(예측 오차)
    충격 전파 : q기간 이후 소멸(절단형 ACF)
```

| 모형 | 설명 요소 | 차수 판정 근거 | 대상 |
|---|---|---|---|
| AR(p) | 과거 관측값 | PACF가 p차에서 절단, ACF 점진 감쇠 | 정상 시계열 |
| MA(q) | 과거 오차항 | ACF가 q차에서 절단, PACF 점진 감쇠 | 정상 시계열 |
| ARMA(p,q) | 과거 값 + 과거 오차 | ACF·PACF 모두 점진 감쇠 | 정상 시계열 |
| ARIMA(p,d,q) | d차 차분 후 ARMA | 차분 후 정상성 확인 | 추세·비정상 시계열 |
| 지수평활법 | 가중치 지수 감쇠의 과거 관측값 | 수준·추세·계절 구성 요소 판단 | 단기 예측 중심 |

## Ⅳ. AR·MA·ARIMA·지수평활법 비교

| 비교축 | AR | MA | ARIMA | 지수평활법 |
|---|---|---|---|---|
| 설명 변수 | 과거 관측값 | 과거 오차항 | 차분 값·오차항 | 가중 과거 관측값 |
| 전제 | 정상성 | 정상성 | 차분 후 정상성 | 수준·추세·계절 구조 가정 |
| 충격 반영 | 감쇠하며 지속 | 유한 기간만 | 차분으로 추세 흡수 | 최근 관측의 큰 가중치 |
| 계수 의미 | 자기회귀 계수 φ | 이동평균 계수 θ | φ·θ·차분 차수 d | 평활 상수 α·β·γ |
| 적합 용도 | 지속성 있는 패턴 | 짧은 충격 조정 패턴 | 추세 포함 실무 시계열 | 다량 품목의 단기 수요 예측 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 추세·분산 변화가 있는 비정상 시계열에 ARMA 직접 적용 시 모수 왜곡 | 정상성 진단 후 차분을 거친 ARIMA 적용 |
| 급격한 구조 변화·외부 충격에 과거 패턴 기반 예측의 실효성 저하 | 롤링 창 재추정과 예측 오차 감시의 상시화 |
| 계절성·특이값 미반영 시 편향된 예측 | 계절 ARIMA(SARIMA) 적용과 이상치 식별·보정 |
| 차수 과대·과소 선택으로 인한 과적합·예측력 저하 | ACF·PACF와 AIC·BIC 정보량 기준의 병행 판정 |

## Ⅵ. 제언

ADF 단위근 검정을 선행하여 비정상 시계열을 ARIMA로 변환하고 잔차의 백색잡음(White Noise) 여부를 Ljung-Box 검정으로 확인하는 검증 체계 확립.

### Box-Jenkins 시계열 모델링 절차

```text
[원시 시계열 데이터] ──► [정상성 진단 (ADF 검정)]
                                │
                                ├─ [비정상 시계열] ──► 차분(Difference) / 로그변환
                                │
                                ▼ [정상 시계열 확보]
[ACF / PACF 그래프 분석] ──► [AR(p), MA(q) 차수 식별]
                                │
                                ▼
[모수 추정 (MLE)] ──────► [잔차 진단 (백색잡음 검정)] ──► [최종 예측]
```

### 선택 근거: 이동평균 모델 (MA)

| 구분 | 자기회귀 모델 (AR) | 이동평균 모델 (MA) |
|---|---|---|
| 핵심 원리 | 과거 자신의 값들의 선형 결합 | 과거 예측 오차(Shock)들의 선형 결합 |
| ACF 특성 | 지수적 감소 또는 사인파 감쇠 | q차 이후 급격히 0으로 절단 (Cut-off) |
| PACF 특성 | p차 이후 급격히 0으로 절단 | 지수적 감소 또는 사인파 감쇠 |
