## Ⅰ. 데이터 품질 진단의 출발점, 데이터 프로파일링의 개요

### 가. 데이터 프로파일링(Data Profiling)의 정의
- 기존 데이터 소스(RDBMS 테이블, 파일, 데이터 레이크 등)에 저장된 데이터의 실제 값들을 분석 통계 알고리즘을 통해 체계적으로 스캔하여, 데이터의 구조, 내용, 관계, 완전성, 유효성 및 비즈니스 규칙 준수 여부 등 **데이터의 실제 현황을 정량적으로 진단하고 메타데이터를 도출하는 기술적 활동**.
- 데이터 마이그레이션, DW 구축, AI 모델링 전 단계에서 쓰레기 데이터 유입(GIGO)을 차단하는 선행 필수 작업.

## Ⅱ. 데이터 프로파일링의 3대 핵심 분석 기법

```text
[ 데이터 프로파일링 3단계 분석 체계 ]
1. 컬럼 프로파일링 (Column)     : 단일 컬럼의 값 분포, 결측률, 카디널리티, 도메인 패턴 분석
2. 다차원/관계 프로파일링 (Cross): 동일 테이블 내 컬럼 간 종속성 및 상관관계 분석
3. 테이블 간 프로파일링 (Table) : 외래키(FK) 참조 무결성, 고아 레코드, 중복 행 분석
```

### 가. 3대 분석 기법별 세부 지표 매트릭스

| 분석 수준 | 핵심 분석 항목 | 구체적 진단 메커니즘 | 발견되는 대표적 결함 사례 |
| :--- | :--- | :--- | :--- |
| **컬럼 프로파일링 (단일 속성)** | **결측률 (Null Rate)** | 컬럼 전체 건수 중 NULL 또는 공백(' ')의 비율 계산 | 필수 입력값이어야 하는 '주민등록번호'가 20% 결측 |
| **컬럼 프로파일링 (단일 속성)** | **카디널리티 (Cardinality)** | 고유값 수(NDV) 측정, 유일성(Uniqueness) 검증 | PK로 설계된 컬럼에 중복 값이 존재함을 조기 발견 |
| **컬럼 프로파일링 (단일 속성)** | **패턴 및 포맷 (Pattern)** | 정규표현식(Regex)으로 데이터 형식 분석 (예: `\d{3}-\d{4}-\d{4}`) | 전화번호 컬럼에 이메일 주소나 한글 문자가 혼입됨 |
| **컬럼 프로파일링 (단일 속성)** | **값 분포 (Min/Max/Avg)** | 최솟값, 최댓값, 평균, 표준편차, 백분위수 산출 | 나이 컬럼에 -5세 또는 999세와 같은 비정상 극단값 발견 |
| **테이블 간 프로파일링 (관계)** | **참조 무결성 (Inclusion)** | 자식 테이블의 외래키 값이 부모 테이블의 PK 집합에 포함되는 비율 | 부모 테이블에 존재하지 않는 고아(Orphan) 주문 데이터 발견 |
| **테이블 간 프로파일링 (관계)** | **함수 종속성 (Functional)** | $A$ 컬럼의 값이 결정될 때 $B$ 컬럼 값이 유일하게 결정되는지 검증 | 우편번호와 주소 간의 불일치 데이터 탐지 |

## Ⅲ. 데이터 프로파일링 자동화 파이프라인 및 도구

### 가. 데이터 파이프라인 내 프로파일링 아키텍처

```text
[ 자동화된 데이터 프로파일링 흐름 ]
[신규 원천 데이터 인입] ---> [Profiling Engine] ---> [통계 메타데이터 생성]
                                  |
                                  v
                    [품질 게이트 (Quality Gate)]
                    - 결측률 > 5% 위반 시 파이프라인 차단 (Alert)
                    - 포맷 준수율 100% 통과 시 타깃 DW 적재
```

### 나. 대표 프로파일링 도구 생태계
- **오픈소스** : Great Expectations, ydata-profiling(구 pandas-profiling), DuckDB.
- **엔터프라이즈** : Informatica Data Quality, IBM InfoSphere Information Analyzer.

## Ⅳ. 성공적인 데이터 거버넌스를 위한 실무 제언

- **프로파일링 결과의 데이터 카탈로그 자동 연계** : 프로파일링을 일회성 엑셀 보고서로 끝내지 않고, 프로파일링 엔진을 전사 데이터 카탈로그(DataHub, Amundsen)와 API로 연동하여 모든 테이블의 컬럼별 최신 결측률과 유효값 분포를 데이터 사용자가 실시간 확인할 수 있도록 공개해야 함.
- **대용량 데이터 프로파일링 시 스마트 샘플링 적용** : 페타바이트급 대용량 테이블 전체를 대상으로 전체 프로파일링을 수행하면 DB가 마비되므로, 베르누이 샘플링 또는 저수지 샘플링 기법을 적용하여 1%의 대표 표본만으로 통계적 신뢰도 99%의 프로파일링을 수행할 것을 제언함.
