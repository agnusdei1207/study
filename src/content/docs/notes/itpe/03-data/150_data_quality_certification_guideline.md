## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 품질 → **데이터 품질인증**

## 30초 인출

- 본질: 데이터 품질인증은 신청한 데이터의 품질을 법령이 정한 기준으로 지정 인증기관이 평가해 인증하는 제도
- 메커니즘: 신청자가 대상·범위·증빙을 정해 신청하면 인증기관이 데이터 내용(완전성·유효성·정확성)·데이터 구조(일관성)·관리체계별 기준으로 심사해 결과를 통지하고, 운영자는 심사 기준을 유입·변경 데이터의 점검 규칙으로 옮겨 위반을 탐지·수정·재검사
- 통찰: 인증은 특정 시점의 평가이므로 이후 유입·변경되는 데이터의 품질을 보장하지 않으며, 항목별 책임자·조치 기한·이력을 정해 상시 점검으로 이어가야 함

<details>
<summary>핵심 용어</summary>

- **데이터 품질인증** : 데이터 품질을 기준으로 평가해 인증하는 제도(데이터 산업진흥 및 이용촉진에 관한 기본법에 근거)
- **인증기관** : 과학기술정보통신부장관이 지정한 데이터 품질인증 수행 기관
- **데이터 내용** : 값 자체의 품질(완전성·유효성·정확성)
- **데이터 구조** : 항목·관계·표현 정의의 일관성
- **데이터 관리체계** : 데이터 생산·구축·활용의 관리 수준
- **완전성·유효성·정확성·일관성** : 필요한 값의 존재 / 허용 범위·형식 적합 / 사실·기준과의 일치 / 정의 간 무충돌

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 품질인증의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 품질인증** 은 신청 데이터의 품질을 법령이 정한 기준으로 평가하는 제도 |
| 목적 | 품질을 확인해 이용·관리 판단의 신뢰성 확보 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 지정 기관의 심사 | 신청 대상을 법정 기준으로 평가 |
| 대상별 기준 | 내용·구조·관리체계에 서로 다른 품질 특성 적용 |
| 시점의 평가 | 운영 중 유입·변경된 데이터는 별도 점검 필요 |

## Ⅲ. 신청·심사·운영 연계

```text
신청자: 데이터 대상·범위·증빙 결정 → 신청
인증기관: 대상별 법정 품질기준으로 심사 → 결과 통지·필요한 개선
운영자: 심사 기준 → 유입·변경 데이터 점검 규칙 → 위반 탐지·원인 수정·재검사
```

세부 서식·방법·유효기간은 적용 시점의 법령과 소관 고시·지침을 확인.

## Ⅳ. 인증 대상별 품질기준

데이터 산업진흥 및 이용촉진에 관한 기본법 시행령 제20조의5는 인증 대상을 데이터 내용·데이터 구조·데이터 관리체계로 구분.

| 대상 | 품질기준 | 확인할 특성 |
|---|---|---|
| 데이터 내용 | 완전성·유효성·정확성 | 필요한 값의 존재, 허용 범위·형식, 사실·기준과의 일치 |
| 데이터 구조 | 일관성 | 항목·관계·표현 정의의 무충돌 |
| 데이터 관리체계 | 관리 수준(생산·구축·활용 관리) | 세부 기준은 고시·지침에서 확인 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 인증 시점 이후 데이터 내용·구조가 변경될 수 있음 | 유입·변경 시 완전성·유효성·정확성·일관성 점검 |
| 오류를 수정할 담당과 이력이 불분명 | 항목별 책임자와 조치 기한을 정하고 재점검 결과 기록 |

## Ⅵ. 제언

인증 기준을 상시 점검 규칙으로 옮기고 위반 결과와 조치 이력을 관리해 인증 이후에도 품질을 유지

```text
인증 기준 → 점검 규칙(완전성·유효성·정확성·일관성) → 위반 탐지 → 책임자 조치 → 재검사·이력
```

| 구분 | 인증 시점 평가만 | 제언: 인증 + 상시 점검 |
|---|---|---|
| 신규 유입 데이터 | 미보장 | 규칙으로 점검 |
| 책임 | 불분명 | 항목별 책임자 |

## 출제 이력과 검증 출처

- Q-net 기출 원문에서 직접 묻는 문항 없음(주제 목록상 시사·트렌드 항목)
- 데이터 산업진흥 및 이용촉진에 관한 기본법 및 시행령(제20조의5)
