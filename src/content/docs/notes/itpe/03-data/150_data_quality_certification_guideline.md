## 지식 로드맵 내 현재 위치

지식 위치: 자료처리·데이터 → 데이터 품질관리 → **데이터 품질인증**

## 30초 인출

- 본질: **데이터 품질인증은** 신청 대상 데이터의 품질을 법령상 기준에 따라 지정 인증기관이 평가하는 제도
- 메커니즘: 인증 대상 선택 → 내용·구조·관리체계에 해당하는 기준으로 심사 → 인증 결과 확인
- 통찰: 한계: 인증 시점의 심사 결과만으로 이후 데이터 변경에 따른 품질 저하를 알기 어려움 → 방안: 인증 기준을 운영 점검 규칙에 연결하고 변경·개선 이력을 주기적으로 확인

<details>
<summary>핵심 용어</summary>

- **데이터 품질인증(Data Quality Certification)** : 신청 대상 데이터의 품질을 법정 기준에 따라 인증기관이 평가하는 제도
- **완전성** : 필요한 데이터 값의 누락 여부를 보는 품질 특성
- **유효성** : 값이 정해진 형식·범위·규칙을 따르는지 보는 품질 특성
- **정확성** : 값이 확인 가능한 실제 사실이나 기준과 일치하는지 보는 품질 특성
- **일관성** : 데이터 구조의 정의·관계·표현이 서로 충돌하지 않는지 보는 품질 특성
- **유용성** : 데이터가 이용 목적에 적합한지 보는 품질 특성
- **접근성** : 권한 있는 이용자가 필요한 데이터에 접근할 수 있는지 보는 품질 특성

</details>

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 품질인증은** 신청 대상 데이터의 품질을 법령이 정한 기준으로 평가하는 제도 |
| 목적 | 데이터의 품질을 확인해 이용·관리 판단의 신뢰성 확보 |

## Ⅱ. 데이터 품질인증의 특징

| 특징 | 의미 |
|---|---|
| 지정 기관의 심사 | 신청 대상을 법정 기준으로 평가 |
| 대상별 기준 | 내용·구조·관리체계에 서로 다른 품질 특성 적용 |
| 시점의 평가 | 운영 중 새로 유입·변경된 데이터는 별도 점검 필요 |

## Ⅲ. 신청·심사·운영 연계 체계

```text
신청자: 데이터 대상·범위·증빙 결정
            ↓ 신청
인증기관: 대상별 법정 품질기준으로 심사
            ↓ 결과 통지·필요한 개선
운영자: 심사 기준 → 유입·변경 데이터 점검 규칙
                         ↓ 위반 탐지·원인 수정·재검사
```

신청 대상과 기준을 정해 자료를 제출하면 인증기관이 해당 기준으로 심사하고 결과를 통지하는 구조.

인증 절차의 세부 서식·방법·유효기간은 적용 시점의 법령과 소관 고시 확인.

## Ⅳ. 인증 대상별 품질기준 비교

데이터산업법 제20조는 데이터 품질관리 사업과 인증기관 지정의 근거를 둔다. 시행령 제20조의5는 인증 대상을 데이터 내용·구조·관리체계 등으로 구분하고 대상별 품질기준을 정한다.

| 대상 | 품질기준 | 확인할 특성 |
|---|---|---|
| **데이터 내용** | 완전성·유효성·정확성 | 필요한 값의 존재, 허용 범위 및 사실·기준과의 일치 |
| **데이터 구조** | 일관성 | 항목·관계·표현 정의의 무충돌 |
| **데이터 관리체계** | 유용성·접근성 | 이용 목적 적합성과 필요한 이용자의 접근성 |

## Ⅴ. 한계와 방안

인증 당시의 평가 결과는 운영 중 새로 유입되는 데이터의 품질을 자동으로 보장하지 않음. 대상별 기준을 실제 점검 규칙에 연결하고, 위반 결과와 조치 이력을 관리.

| 한계 | 방안 |
|---|---|
| 인증 시점 이후 데이터 내용·구조가 변경될 수 있음 | 유입·변경 시 완전성·유효성·정확성·일관성 점검 |
| 기준은 있으나 오류를 수정할 담당과 이력이 불분명할 수 있음 | 항목별 책임자와 조치 기한을 정하고 재점검 결과 기록 |

## Ⅵ. 제언

인증 심사에서 확인한 내용·구조·관리체계 기준부터 운영 점검 규칙으로 옮기고 변경 이력과 재검사 결과를 연결.
