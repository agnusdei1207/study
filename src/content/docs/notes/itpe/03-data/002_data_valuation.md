## 큰 그림과 30초 인출

```text
[평가대상 데이터]
      │ 범위·권리·품질·활용 시나리오
      ▼
[가치요인 분석] ──▶ [평가방법 선택] ──▶ [가치 산정·검증]
 품질·유용성·희소성    원가·시장·수익       가정·민감도
      │                                      │
      └──────────────┬───────────────────────┘
                     ▼
             [거래·투자·담보·내부관리]
                     │
                     ▼
                [데이터 자산화]
```

- 본질: **데이터의 기술적 품질과 사업적 활용 가능성을 경제적 가치로 변환하여 거래·투자·관리 의사결정의 근거를 만드는 활동**
- 암기: `대-실-요-방-산-검` = 대상 → 실사 → 요인 → 방법 → 산정 → 검증
- 3대 접근법: `원가`, `시장`, `수익`
- 주의: 경제적 가치평가 결과가 곧 회계상 자산 인식을 의미하지는 않음

## 예상문제

> 데이터 가치평가의 개념과 평가요인, 평가방법론을 설명하고, 데이터 자산화와 거래 활성화를 위한 고려사항을 논하시오. (25점)

## Ⅰ. 데이터 활용가치를 경제적 기준으로 전환하는 가치평가 개요

- 정의: **데이터 가치평가**는 평가대상 데이터의 품질·권리·활용성·시장성·수익성을 분석하고 적절한 평가방법을 적용하여 경제적 가치를 산정하는 활동
- 목적: 데이터 거래가격, 투자·금융 심사, 사업 타당성, 내부 자산관리의 객관적 근거 확보
- 필요성: 데이터는 복제·결합·재사용이 가능하고 활용 맥락에 따라 효익이 달라 원가만으로 가치를 설명하기 어려움

#### 한줄 요약

- 데이터 가치평가는 파일의 가격이 아니라 합법적·지속적으로 활용하여 얻을 수 있는 효익의 가치를 산정함

## Ⅱ. 품질·권리·활용 맥락을 함께 보는 데이터 가치 특성

| 특성 | 가치에 미치는 영향 | 평가 시 확인사항 |
|---|---|---|
| **비경합·재사용성** | 반복 활용과 다목적 활용 가능 | 재사용 범위·추가 처리비용 |
| **복제 용이성** | 공급 확대가 쉽고 독점성이 약해질 수 있음 | 접근통제·계약상 사용범위 |
| **결합성** | 다른 데이터와 결합할 때 효익 증가 | 결합키·상호보완성·법적 허용성 |
| **시의성** | 오래되면 예측력·업무 적합성 감소 | 갱신주기·기준시점·유효기간 |
| **맥락 의존성** | 같은 데이터도 활용 업무별 가치가 다름 | 활용 시나리오·사용자·대체재 |
| **권리·규제성** | 개인정보·저작권·계약 제약이 처분 가능성 제한 | 적법 수집·이용·제3자 권리 |

#### 한줄 요약

- 데이터 가치는 양보다 신뢰도·적법성·희소성·활용 시나리오가 함께 확보될 때 현실화됨

## Ⅲ. 데이터 가치평가의 구성요인과 3대 접근법

```text
평가요인
├─ 내재요인: 정확성·완전성·일관성·최신성
├─ 활용요인: 업무적합성·결합성·대체가능성
├─ 시장요인: 수요·희소성·거래가능성
└─ 위험요인: 권리·보안·규제·유지비용
                 │
                 ▼
       ┌────── 3대 평가 접근법 ──────┐
       │ 원가      시장       수익    │
       │ 재현비용  유사거래   미래효익 │
       └─────────────────────────────┘
```

| 접근법 | 산정 논리 | 적합 상황 | 한계 |
|---|---|---|---|
| **원가접근법** | 수집·정제·가공·대체에 필요한 비용 | 초기 데이터, 거래·수익 자료 부족 | 활용효익·희소성 과소평가 가능 |
| **시장접근법** | 비교 가능한 유사 데이터 거래가격 조정 | 유사 거래와 조건 비교 가능 | 공개 거래사례 부족·조건 이질성 |
| **수익접근법** | 데이터로 발생할 미래 경제적 효익의 현재가치 | 수익모델·현금흐름 식별 가능 | 가정·할인율·기여도에 민감 |

#### 한줄 요약

- 평가자는 한 방법을 기계적으로 적용하지 않고 데이터의 성숙도와 증거 가용성에 따라 방법을 선택·교차검증함

## Ⅳ. 대상 확정에서 가치 검증까지의 평가 절차

```text
① 평가 목적·대상 확정
   └─ 기준일·사용목적·데이터 범위
          ↓
② 데이터·권리 실사
   └─ 품질·계보·소유·이용권·규제
          ↓
③ 활용 시나리오·가치요인 분석
   └─ 사용자·효익·대체재·위험
          ↓
④ 평가방법·가정 선정
   └─ 원가 / 시장 / 수익 또는 병행
          ↓
⑤ 가치 산정·민감도 분석
   └─ 핵심 변수 변화에 따른 범위 확인
          ↓
⑥ 결과 검증·보고
   └─ 근거·제약·유효기간·사용조건 명시
```

| 단계 | 핵심 통제 | 대표 산출물 |
|---|---|---|
| 범위 설정 | 데이터셋·권리·기준일의 경계 일치 | 평가계획서 |
| 실사 | 카탈로그·계보·품질지표·계약 증빙 대조 | 실사보고서 |
| 방법 선정 | 증거 수준과 활용 시나리오에 맞는 방법 채택 | 평가모형·가정서 |
| 산정·검증 | 주요 변수의 민감도와 교차 접근법 비교 | 가치산정보고서 |

#### 한줄 요약

- 가치평가의 신뢰성은 숫자의 정밀도보다 대상·권리·가정·제약을 재현 가능하게 남기는 데서 나옴

## Ⅴ. 가치평가와 자산화를 구분하는 비교

| 구분 | 데이터 품질평가 | 데이터 가치평가 | 데이터 자산화 |
|---|---|---|---|
| **질문** | 데이터가 믿을 만한가 | 경제적 효익은 얼마인가 | 조직이 반복 활용·관리할 수 있는가 |
| **대상** | 값·구조·표준·프로세스 | 데이터와 활용 시나리오 | 데이터·메타데이터·권리·운영체계 |
| **핵심 기준** | 정확성·완전성·일관성 | 원가·시장·수익·위험 | 소유자·카탈로그·품질·접근·성과 |
| **산출물** | 품질지표·개선계획 | 가치산정보고서 | 자산목록·등급·책임·활용계획 |
| **관계** | 가치평가의 신뢰 근거 | 의사결정용 경제적 근거 | 가치를 지속 실현하는 관리체계 |

- 적용 판단: 가치평가서를 받았다는 사실만으로 재무보고상 무형자산 인식이 자동 확정되는 것은 아니며, 적용 회계기준의 식별가능성·통제·미래효익 등 요건을 별도 검토

#### 한줄 요약

- 품질은 가치의 입력, 가치평가는 의사결정 근거, 자산화는 그 가치를 반복 실현하는 운영체계임

## Ⅵ. 불확실성과 권리 위험을 통제하는 실무 고려사항

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 평가기관·방법별 **가치 편차** | 거래사례 부족과 수익 가정 차이 | 평가 목적별 방법 선택, 다중 접근법 교차검증, 민감도 공개 | 결과의 설명 가능성 확보 |
| 가치 산정 후 **활용 부진** | 구체적 사용자·업무 시나리오 부재 | 평가 전 활용 주체·효익·KPI와 실행계획 확정 | 평가가 실제 활용으로 연결 |
| 개인정보·저작권 **권리 위험** | 수집 근거·이용범위·제3자 권리 불명확 | 법적 실사, 계보·동의·계약 증빙, 사용조건 명시 | 거래·활용 중단 위험 감소 |
| 최신성 저하로 **가치 감소** | 갱신 책임·주기·비용 미반영 | 기준일·유효기간·갱신 SLA와 유지비 반영 | 시간 변화에 따른 과대평가 방지 |
| 자산목록의 **유명무실화** | 소유자·품질·접근·성과관리 단절 | Data Owner 지정, 카탈로그·품질지표·활용성과 연계 | 지속 가능한 자산관리 |

#### 한줄 요약

- 가치평가는 단일 금액보다 평가 가정과 위험, 유효 범위를 함께 제시해야 실제 거래와 투자 판단에 사용 가능함

## Ⅶ. 평가액보다 가치 실현체계를 남기는 결론

- **[가치평가-거버넌스-활용성과의 폐루프 구축]**: 일회성 평가액만 산출하면 데이터의 품질·권리·시의성이 변해도 장부와 의사결정에 낡은 근거가 남음
- 나라면: 평가대상 데이터에 Owner·카탈로그·계보·품질지표·권리증빙을 연결하고, 활용 KPI와 갱신주기를 운영하여 가치 변화가 재평가와 투자 우선순위에 반영되게 설계

#### 한줄 요약

- 데이터 자산화의 완성은 가격표 부착이 아니라 가치의 근거와 변화를 계속 관리하는 상태임

## 1교시 10점 답안 발췌

### 1. 정의와 평가요인

- 데이터 가치평가는 데이터의 품질·권리·활용성·시장성·수익성을 분석해 경제적 가치를 산정하는 활동

### 2. 평가방법론

```text
원가접근법: 재현·대체 비용
시장접근법: 유사 거래가격
수익접근법: 미래 경제적 효익의 현재가치
```

| 절차 | 핵심 내용 |
|---|---|
| 대상·실사 | 범위·기준일, 품질·계보·권리 확인 |
| 요인·방법 | 활용 시나리오와 증거에 맞는 방법 선택 |
| 산정·검증 | 민감도·교차검증, 제약·유효기간 명시 |

### 3. 차별화 제언

- 평가 결과를 카탈로그·품질·권리·Owner·활용 KPI와 연결해 일회성 평가를 지속적 데이터 자산관리로 전환
