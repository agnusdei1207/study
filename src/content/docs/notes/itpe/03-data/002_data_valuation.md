## 연관 키워드

- 데이터 가치평가(Data Valuation), 데이터 자산화(Data Assetization), 무형자산(Intangible Asset), K-IFRS
- 원가·시장·수익 접근법, 품질·활용·위험 보정 계수, 데이터 거래소, AHP, 실물옵션, DQI, PET

## Ⅰ. 데이터 가치평가·자산화의 개요

- 핵심 요약 : 데이터의 경제적 효익을 화폐 가치로 정량화하고 회계적 무형자산으로 전환하는 활동.
- 개념 :
  - 데이터 가치평가(Data Valuation) : 기업·공공기관이 보유한 데이터의 경제적 효익, 품질, 시장 유통 가능성을 종합하여 화폐적 가치로 정량화하는 기법.
  - 데이터 자산화(Data Assetization) : 단순 비용 요소로 처리되던 데이터를 회계적 무형자산(Intangible Asset)으로 인식하거나 비즈니스 가치 창출의 핵심 자본으로 전환하여 거래·활용·투자 유치에 연계하는 일련의 활동.
- 배경 및 필요성 :
  1. 기업가치 재산정 : 디지털 플랫폼 기업의 본질적 경쟁력인 데이터 자산의 시장 가치 반영.
  2. 데이터 거래 및 금융 연계 : 데이터 담보 대출, 데이터 거래소 유통, M&A(Mergers and Acquisitions) 실사(Due Diligence)의 객관적 기준 제공.
  3. 투자 대비 효과 검증 : ROI(Return on Investment) 관점의 데이터 거버넌스·플랫폼 투자 타당성 입증.
- 주요 목적 : 데이터 자산의 정량적 가치 측정 체계 정립과 회계·법적 자산 인식 기반 마련.

## Ⅱ. 데이터 가치평가의 특징

- 핵심 요약 : 3대 접근법의 기초 평가액에 품질·활용·위험 보정 계수를 결합한 산정 체계.

1. 3대 접근법 : 원가 접근법(Cost Approach), 시장 접근법(Market Approach), 수익 접근법(Income Approach)의 병행 적용.
2. 보정 계수 구조 : 최종 데이터 가치 = 기초 평가액 × Q × U × R의 보정 산식 적용.
3. 4단계 라이프사이클 : 발굴 및 식별, 품질 및 표준화, 가치 평가 및 등급화, 활용 및 수익화의 단계적 추진.
4. 회계적 검토 : K-IFRS(Korean International Financial Reporting Standards) 제1038호 무형자산 인식 요건의 사전 검토.

## Ⅲ. 데이터 가치평가·자산화의 구조 (흐름)

- 핵심 요약 : 3대 접근법의 기초 평가액 산출, Q·U·R 보정 계수의 곱산 구조, 4단계 자산화 라이프사이클.

```text
[ 데이터 가치평가 3대 접근법 ]
 ├─ 원가 접근법 (Cost Approach)   : 재조달원가 - 감가상각
 ├─ 시장 접근법 (Market Approach) : 유사 거래 사례 비교
 └─ 수익 접근법 (Income Approach) : 미래현금흐름의 현재가치
```

```text
[ 최종 데이터 가치 산정 구조 ]
 기초 평가액 × Q × U × R
  ├─ Q : 품질 계수 (완전성, 유효성, 정확성, 최신성)
  ├─ U : 활용·독점 계수 (결합 가능성, 시장 독점도, API 연동성)
  └─ R : 법적·보안 위험 계수 (개인정보 침해 리스크, 규제 대응 비용)
```

- 보정 계수의 세부 요소 :
  1. 품질 계수(Quality Factor) : 완전성, 유효성, 정확성, 최신성 등 데이터 품질 지표 점수 반영.
  2. 활용·독점 계수(Utility Factor) : 데이터 결합 가능성, 시장 독점도, API(Application Programming Interface) 연동 용이성 반영.
  3. 법적·보안 위험 계수(Risk Factor) : 개인정보 침해 리스크 및 GDPR(General Data Protection Regulation)·개인정보보호법 등 규제 대응 비용 차감.
- 자산화 4단계 라이프사이클 :
  1. 발굴 및 식별 : 전사 데이터 카탈로그 구축, 메타데이터 수집, 데이터 인벤토리 체계화.
  2. 품질 및 표준화 : 전사 표준 도메인 정립, 데이터 정제, 품질 모니터링 체계 가동.
  3. 가치 평가 및 등급화 : 3대 평가 모델 적용 및 자산 가치 등급(Gold·Silver·Bronze) 부여.
  4. 활용 및 수익화 : 내부 프로세스 최적화, 외부 데이터 거래소 유통, 데이터 담보 금융 상품화.
- 무형자산 인식 3요건 :
  1. 식별가능성(Identifiability) : 계약상 권리이거나 다른 자산과의 분리·처분 가능 여부.
  2. 자원에 대한 통제(Control) : 데이터 접근 통제 및 법적 소유권을 통한 미래 경제적 효익의 배타적 향유 여부.
  3. 미래 경제적 효익(Future Economic Benefits) : 매출 증대 또는 원가 절감의 합리적 추정 가능 여부.

## Ⅳ. 가치평가 3대 접근법의 비교

- 핵심 요약 : 객관성 중심의 원가 접근법, 시장 부합성 중심의 시장 접근법, 본질 가치 중심의 수익 접근법의 상호 보완.

| 평가 모델 | 평가 원리 및 산식 구조 | 장점 | 단점 및 한계 |
|---|---|---|---|
| 원가 접근법(Cost Approach) | 데이터를 동일 수준으로 재생산·대체하는 비용 합산(재조달원가 - 감가상각) | 비용 증빙 기반의 객관성 확보 용이 | 미래 수익 창출 잠재력 미반영, 가공 비용과 가치 간 괴리 |
| 시장 접근법(Market Approach) | 공인 데이터 거래소 등의 유사 거래 사례 비교를 통한 시장 가치 도출 | 시장 원리에 부합하는 직관적 평가 | 데이터의 고유성·비표준성으로 동질적 거래 비교군 확보 곤란 |
| 수익 접근법(Income Approach) | 미래 잉여현금흐름(FCF, Free Cash Flow)의 할인율(WACC, Weighted Average Cost of Capital) 기반 현재가치화 | 비즈니스 실질 기여도와 직결되는 본질적 평가 | 단독 기여도 분리 곤란, 미래 현금흐름 예측의 불확실성 |

- 선택 기준 : 증빙·거래 목적의 원가 접근법, 유통 가치 검증의 시장 접근법, 비즈니스 기여 평가의 수익 접근법을 평가 목적에 따라 병행 적용.

## Ⅴ. 데이터 가치평가·자산화의 장점과 한계

- 핵심 요약 : 객관적 자산 기준 마련의 장점과 비경합성·회계 요건·유통 시장의 한계.

- 장점
  1. 데이터 자산의 객관적 가치 기준을 통한 M&A 실사·담보 평가 지원.
  2. 데이터 관련 투자의 경제적 타당성 입증과 경영 의사결정 지원.
  3. 데이터 품질·활용도 관리 동기의 내재화.

- 한계점 1 : 비경합성·가변성으로 인한 객관적 가치 산정 난제
  - 한계점 : 복제 비용이 0에 수렴하는 비경합성과 결합·가공에 따른 가치 급변으로 전통적 감정평가 모델 적용 시 평가 편차 과대.
  - 해결 방안 : AHP(Analytic Hierarchy Process)와 실물옵션(Real Options) 평가 모형의 결합, 데이터 품질 지수(DQI, Data Quality Index)와 활용 빈도를 반영한 동적 감가상각·할인율 보정 알고리즘 적용.
- 한계점 2 : 회계기준상 무형자산 인식 요건 충족 한계
  - 한계점 : K-IFRS 제1038호 무형자산 요건상 신뢰성 있는 원가 측정과 배타적 법적 통제권 입증 곤란으로 재무제표 자산화 실패 및 단순 비용 처리.
  - 해결 방안 : 데이터 카탈로그 기반 계보(Data Lineage) 추적과 투입 원가(인프라, 라벨링, 정제 비용)의 회계 계정 분리, 데이터 신탁 및 지식재산권(IP, Intellectual Property) 등록 체계 연계.
- 한계점 3 : 데이터 유통 시장의 유동성 부족 및 정보 비대칭
  - 한계점 : 거래 표준 가격 지표 부재와 원본 데이터의 사전 검증 불가(Arrow의 정보 역설)로 데이터 거래 시장 활성화 지연.
  - 해결 방안 : 공인 데이터 거래소 기반 표준 메타데이터 명세 공개, 동형암호 및 합성 데이터(Synthetic Data) 기반 샘플 검증 샌드박스 제공.

## Ⅵ. 데이터 가치평가 활성화를 위한 기술사적 제언

- 핵심 요약 : 데이터 전용 회계 기준 법제화, 결합 생태계 연계, 신뢰 기반 거래 인프라 확충.
- 데이터 회계 처리 표준 수립 : K-IFRS의 엄격한 내부 창출 무형자산 요건 보완을 위한 데이터 전용 무형자산 평가·공시 가이드라인의 법제화 필요.
- 데이터 결합 생태계 연계 : 마이데이터 및 가명정보 결합 전문기관과의 연계를 통한 단독 데이터를 뛰어넘는 이종 결합 데이터의 부가가치 창출.
- 신뢰성 높은 거래 인프라 확충 : 가치평가 기관의 공신력 제고, 블록체인 기반 데이터 이력 추적, 프라이버시 보존 컴퓨팅(PET, Privacy-Enhancing Technology) 결합을 통한 유통 신뢰 장벽 해소.

## Ⅶ. 결론

- 핵심 요약 : 가치평가는 3대 접근법과 보정 계수의 결합, 자산화는 회계 요건·거래 인프라의 정비가 관건.
- 요약 : 원가·시장·수익 접근법의 기초 평가액에 품질·활용·위험 계수를 보정하는 산정 체계.
- 시사점 : 평가 기법의 표준화와 법·회계 제도 정비를 통한 데이터 경제 활성화 필요.
