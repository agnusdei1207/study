## 연관 키워드

- 데이터 가치평가(Data Valuation), 데이터 자산화(Data Assetization), 무형자산(Intangible Asset), K-IFRS
- 원가 접근법(Cost Approach), 시장 접근법(Market Approach), 수익 접근법(Income Approach), 보정 요인
- AHP(Analytic Hierarchy Process), 실물옵션(Real Options), 데이터 거래소, 데이터 계보(Data Lineage)

## Ⅰ. 데이터 가치평가·자산화의 개요

- 핵심 요약 : 데이터의 경제적 효익을 화폐 가치로 추정하고 회계·거래 대상의 자산으로 만드는 이원 활동.
- 개념 : 두 활동으로 구성.
  1. **데이터 가치평가** (Data Valuation) : 보유 데이터의 효익, 품질, 유통 가능성을 종합해 화폐 가치로 추정하는 활동.
  2. **데이터 자산화** (Data Assetization) : 데이터를 회계·법적 **무형자산** (Intangible Asset, 물리적 실체 없이 미래 경제적 효익을 주는 자원)으로 인식하고 거래·투자에 연계하는 활동.
- 배경 및 필요성 : 데이터가 기업 가치의 핵심으로 부각되면서 M&A(Mergers and Acquisitions) 실사, 데이터 담보 평가, 데이터 거래소 유통에서 객관적 가치 기준의 수요 확대.
- 주요 목적 : 평가 기준의 표준화와 자산 인식 요건 정비를 통한 데이터 투자·유통의 신뢰 기반 구축.

## Ⅱ. 데이터 가치평가의 특징 및 장점

- 핵심 요약 : 3대 접근법과 보정 요인의 결합, 회계 요건 연계, 단계적 자산화의 산정 체계.

1. 3대 접근법 병행 : **원가 접근법** (Cost Approach), **시장 접근법** (Market Approach), **수익 접근법** (Income Approach)의 상호 보완 적용 → 단일 방법 편향 감소.
2. 보정 요인 반영 : 품질(완전성·최신성), 활용(결합 가능성·독점성), 위험(규제 대응 비용) 요인으로 기초 가치 조정 → 실현 가능한 가치 도출.
3. 회계 요건 연계 : **K-IFRS** (Korean International Financial Reporting Standards, 한국채택국제회계기준) 무형자산 기준의 인식 요건 사전 검토 → 재무 보고 연계성 확보.
4. 단계적 자산화 : 발굴·식별에서 활용·수익화까지의 순차 추진 → 관리 체계와 평가 결과의 연결.

## Ⅲ. 데이터 가치평가·자산화의 구조 (흐름)

- 핵심 요약 : 3대 접근법으로 기초 가치를 산출하고 보정 요인을 거쳐 최종 가치를 확정하는 흐름.

```text
[ 데이터 가치평가 흐름 ]

원가·시장·수익 접근법 적용
   ↓
기초 가치 산출
   ↓ 보정 요인 반영
품질·활용·위험 요인 평가
   ↓
최종 데이터 가치 확정
```

```text
[ 데이터 자산화 단계 ]

1. 발굴·식별 (데이터 카탈로그)
   ↓
2. 품질·표준화 (정제·도메인 정비)
   ↓
3. 평가·등급화 (접근법 적용)
   ↓
4. 활용·수익화 (내부 활용·거래)
```

- 무형자산 인식 3요건 (K-IFRS 무형자산 기준) :
  1. 식별가능성 : 계약상 권리 또는 다른 자산과의 분리 거래 가능 여부.
  2. 통제 : 미래 효익에 대한 배타적 접근 권한 보유 여부.
  3. 미래 경제적 효익 : 매출 증대·비용 절감의 합리적 추정 가능 여부.
- 계보 관리 : **데이터 계보** (Data Lineage, 데이터의 발생부터 활용까지 이동 경로의 기록)로 투입 원가와 변형 과정 추적 → 원가 접근법의 증빙 강화.

## Ⅳ. 가치평가 3대 접근법의 비교

- 핵심 요약 : 증빙성(원가), 시장 부합성(시장), 비즈니스 기여(수익)의 상호 보완 구도.

| 접근법 | 평가 원리 | 장점 | 한계 |
| --- | --- | --- | --- |
| 원가 접근법 | 재생산·대체 비용 기준 산정 | 비용 증빙 기반의 객관성 | 미래 효익 미반영 |
| 시장 접근법 | 유사 거래 사례와의 비교 | 시장 원리 부합의 직관성 | 비교 사례 확보 곤란 |
| 수익 접근법 | 미래 현금흐름의 현재가치화 | 비즈니스 기여의 직접 반영 | 단독 기여분 분리 곤란 |

- 선택 기준 : 회계 증빙은 원가 접근법, 거래 가격 검증은 시장 접근법, 투자 타당성은 수익 접근법을 우선하고 목적에 따라 병행.

## Ⅴ. 데이터 가치평가·자산화의 한계와 방안

- 핵심 요약 : 맥락 의존적 가치, 인식 요건 충족 곤란, 거래 정보 비대칭을 시나리오 평가·계보 관리·표준 메타데이터로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 가치의 맥락 의존성 | 결합 상대와 활용 목적에 따라 가치 변동 → 단일 평가값의 신뢰 저하 | 평가 목적별 시나리오 분리와 **AHP** (Analytic Hierarchy Process, 평가 기준을 계층화해 가중치를 도출하는 기법) 기반 가중치 운영 | 평가 편차율 |
| 무형자산 인식 요건 충족 곤란 | 원가 추적·배타적 통제 입증 실패 → 비용 처리로 귀결 | 계보 기반 원가의 계정 분리와 지식재산권 등록 연계 | 자산 인식 건수, 원가 추적률 |
| 거래 시장의 정보 비대칭 | 표준 가격 부재와 사전 검증 불가 → 거래 위축 | 데이터 거래소의 표준 메타데이터 공개와 합성 데이터 샘플 제공 | 거래 건수, 분쟁 건수 |

## Ⅵ. 데이터 자산화 활성화에 대한 기술사적 제언

- 핵심 요약 : 제도 정비, 공공 거래 인프라, 결합 가치 평가의 3축 추진.
- 회계·금융 당국 : 데이터 자산의 평가·공시 가이드라인을 마련해 대차대조표 반영 경로 확보.
- 공공 조직 : 데이터 거래소의 표준 평가 심사 체계 운영으로 거래 신뢰 기반 조성.
- 기업 : **실물옵션** (Real Options, 미래의 선택권을 옵션 가치로 평가하는 기법) 적용으로 결합·확장 가치까지 반영한 데이터 투자 심사 체계 도입.

## Ⅶ. 결론

- 핵심 요약 : 데이터 가치평가는 3대 접근법과 보정 요인의 결합 체계이며, 자산화는 회계 요건과 거래 인프라를 전제로 정착함.
- 평가 기법의 표준화와 제도 정비가 함께 진전될 때 데이터가 재무·거래의 대상 자산으로 확립됨.
