## 연관 키워드
- 데이터 자산, 가치평가, 원가·시장·수익 접근, 데이터 품질, 권리

### Ⅰ. 데이터 가치평가·자산화의 개요

- 핵심 요약 : 데이터 가치평가는 데이터가 의사결정·수익·비용절감에 기여하는 경제적 가치를 목적과 가정에 따라 추정하는 활동.
- 개념 : 데이터가 의사결정·수익·비용절감에 기여하는 경제적 가치를 목적과 가정에 따라 추정하는 활동(**데이터 가치평가**, Data Valuation).
- 배경 및 필요성 : 데이터의 무형성·복제 가능성·권리와 품질 차이 때문에 장부가치나 수집비용만으로 효용을 설명하기 어려움.
- 주요 목적 : 데이터 활용 투자 우선순위와 책임·권리·품질 관리 기준 마련.

### Ⅱ. 데이터 가치평가·자산화의 특징 및 장점

- 핵심 요약 : 수익 접근·시장 접근·원가 접근은 각각 사업기여·외부 가격·대체비용을 추정하는 데이터 자산 평가 방식.

1. 수익 접근 : 데이터 활용으로 기대되는 증분 현금흐름 추정 → 사업기여 평가.
2. 시장 접근 : 유사 데이터 거래사례 비교 → 외부 가격 참고.
3. 원가 접근 : 수집·정제·저장 재조달 비용 산정 → 대체비용 기준 제공.

### Ⅲ. 데이터 가치평가·자산화의 구조 (흐름)

- 핵심 요약 : 평가목적 정의 → 자산 범위·권리 확인 → 품질·희소성·사용성 진단 → 평가모형·가정 적용 → 민감도·활용가치 검토.

```text
평가목적 정의
  ↓
자산 범위·권리 확인
  ↓
품질·희소성·사용성 진단
  ↓
평가모형·가정 적용
  ↓
민감도·활용가치 검토
```

```text
데이터 자산 후보
  ↓ 권리·품질 검증
목적별 평가모형
  ↓ 가정·불확실성 기록
활용 투자·관리 우선순위
```

### Ⅳ. 유형자산 평가와 데이터 가치평가 비교

- 핵심 요약 : 가치 소진 기준 — 유형자산 평가: 감가상각·물리적 마모 고려; 데이터 가치평가: 복제·결합·노후화·규제 위험 고려.

| 비교 축 | 유형자산 평가 | 데이터 가치평가 |
|---|---|---|
| 가치 원천 | 취득·대체원가·현금흐름 | 활용 가능성·권리·품질·네트워크 효과 |
| 가치 소진 | 감가상각·물리적 마모 고려 | 복제·결합·노후화·규제 위험 고려 |
| 주요 위험 | 물리적 노후·수요 감소 | 복제·결합·노후화·규제 위험 |

### Ⅴ. 데이터 가치평가·자산화의 한계와 방안

- 핵심 요약 : 보편적 가격 부재·권리 제한 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 보편적 가격 부재 | 활용처와 맥락에 따라 가치가 변동 | 평가 목적·시나리오·기간을 함께 공시 | 가정 민감도 |
| 권리 제한 | 개인정보·라이선스 때문에 활용 불가 | 권리·동의·목적 제한을 가치평가에 반영 | 권리 확인률 |
| 품질·최신성 불확실 | 오류·편향·노후 데이터는 효용 저하 | 품질비용·갱신주기·검증결과 연결 | 오류율·갱신 지연 |

### Ⅵ. 데이터 가치평가·자산화에 대한 제언

- 핵심 요약 : 데이터 책임자는 평가수치를 단일 절대가격으로 취급하지 않고 권리·품질·활용 시나리오·산정가정을 카탈로그와 함께 관리.

- 실행 제안 : 평가위원회는 원가·수익·시장 접근의 가정과 권리 제한을 시나리오별로 비교해 투자 우선순위를 정함.

### Ⅶ. 결론

- 핵심 요약 : 데이터 자산화의 핵심은 데이터를 무조건 재무자산으로 계상하는 것이 아니라 통제 가능한 권리와 측정 가능한 활용가치를 연결하는 것.
- 시사점 : 데이터의 잠재 효용과 재무회계상 자산 인식은 다른 판단이므로 권리와 활용 근거를 분리해 평가.
