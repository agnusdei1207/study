## Ⅰ. 데이터 가치평가 및 데이터 자산화의 개요

### 가. 데이터 가치평가·데이터 자산화의 정의
- **데이터 가치평가(Data Valuation)** : 기업 및 공공기관이 보유한 데이터의 경제적 효익, 품질, 시장 유통 가능성을 종합하여 화폐적 가치로 정량화하는 기법.
- **데이터 자산화(Data Assetization)** : 단순 비용 요소로 처리되던 데이터를 회계적 무형자산(Intangible Asset)으로 인식하거나, 비즈니스 가치 창출의 핵심 자본으로 전환하여 거래·활용·투자 유치에 연계하는 일련의 활동.

### 나. 데이터 가치평가 도입의 필요성
- 기업가치 재산정 : 디지털 플랫폼 기업의 본질적 경쟁력인 데이터 자산의 시장 가치 반영.
- 데이터 거래 및 금융 연계 : 데이터 담보 대출, 데이터 거래소 유통, M&A 시 실사(Due Diligence)의 객관적 기준 제공.
- 투자 대비 효과(ROI) 검증 : 데이터 거버넌스 및 플랫폼 구축 투자에 대한 경제적 타당성 입증.

## Ⅱ. 데이터 가치평가의 3대 접근법 및 산정 프레임워크

### 가. 가치평가 3대 방법론 비교

```text
[ 데이터 가치평가 3대 모델 ]
+---------------------+---------------------+---------------------+
| 원가 접근법 (Cost)   | 시장 접근법 (Market)| 수익 접근법 (Income)|
+---------------------+---------------------+---------------------+
| 구축 및 대체 비용    | 유사 데이터 시장거래| 미래 현금흐름 할인  |
| - 데이터 수집/가공비| - 거래소 거래 사례  | - 매출 증분 기여도  |
| - 진부화 감가상각   | - 상대가치 비교     | - 현금흐름할인(DCF) |
+---------------------+---------------------+---------------------+
```

| 평가 모델 | 평가 원리 및 산식 구조 | 장점 | 단점 및 한계 |
| :--- | :--- | :--- | :--- |
| **원가 접근법 (Cost Approach)** | 데이터를 동일 수준으로 재생산하거나 대체하는 데 소요되는 비용 합산 (재조달원가 - 감가상각) | 비용 증빙 기반으로 객관성 확보 용이 | 데이터의 미래 수익 창출 잠재력 미반영, 가공 비용과 가치 간 괴리 |
| **시장 접근법 (Market Approach)** | 공인 데이터 거래소 등에서 유사 거래 사례를 비교하여 시장 가치 도출 | 시장 원리에 부합하는 직관적 평가 | 데이터의 고유성·비표준성으로 인해 동질적 거래 비교군 확보 곤란 |
| **수익 접근법 (Income Approach)** | 해당 데이터로 인해 창출될 미래 잉여현금흐름(FCF)을 할인율(WACC)로 현재가치화 | 비즈니스 실질 기여도와 직결되는 본질적 평가 | 데이터의 단독 기여도 분리 곤란, 미래 현금흐름 예측의 불확실성 |

### 나. 데이터 가치평가 프레임워크 및 보정 계수

```text
최종 데이터 가치 = 기초 평가액(원가/수익) × 품질계수(Q) × 효용계수(U) × 위험계수(R)
```

- **데이터 품질 계수(Quality Factor)** : 완전성, 유효성, 정확성, 최신성 등 데이터 품질 지표 점수 반영.
- **데이터 활용/독점 계수(Utility Factor)** : 데이터 결합 가능성, 시장 독점도, API 연동 용이성 반영.
- **법적/보안 위험 계수(Risk Factor)** : 개인정보 침해 리스크, 컴플라이언스(GDPR, 개인정보보호법) 규제 비용 차감.

## Ⅲ. 데이터 자산화 추진 전략 및 거버넌스 체계

### 가. 데이터 자산화 4단계 라이프사이클
1. **발굴 및 식별** : 전사 데이터 카탈로그 구축, 메타데이터 수집, 데이터 인벤토리 체계화.
2. **품질 및 표준화** : 전사 표준 도메인 정립, 데이터 정제, 품질 모니터링 체계 가동.
3. **가치 평가 및 등급화** : 3대 평가 모델 적용, 자산 가치 등급 부여(Gold/Silver/Bronze).
4. **활용 및 수익화** : 내부 프로세스 최적화, 외부 데이터 거래소 유통, 데이터 담보 금융 상품화.

### 나. 회계적 자산화와 무형자산 요건 검토
- **식별가능성(Identifiability)** : 계약상 권리이거나 다른 자산과 분리/처분 가능한가.
- **자원에 대한 통제(Control)** : 데이터 접근 통제 및 법적 소유권을 통해 미래 경제적 효익을 배타적으로 향유할 수 있는가.
- **미래 경제적 효익의 유입 가능성(Future Economic Benefits)** : 매출 증대 또는 원가 절감이 합리적으로 추정 가능한가.

## Ⅳ. 데이터 가치평가 및 자산화의 주요 한계점 및 해결 방안

- 데이터의 비경합성·가변성으로 인한 객관적 가치 산정 난제 :
  - 한계점 : 데이터는 복제 비용이 0에 수렴하는 비경합성과 결합·가공에 따라 가치가 급변하는 유동성을 지녀 전통적 감정평가(원가법, 수익법, 시장법) 모델 적용 시 평가 편차 과대.
  - 해결 방안 : 다기준 의사결정(AHP) 및 실물옵션(Real Options) 평가 모형 결합, 데이터 품질 지수(DQI)와 활용 빈도를 반영한 동적 감가상각 및 할인율 보정 알고리즘 적용.
- 회계기준 상 무형자산 인식 요건(통제권·식별가능성) 충족 한계 :
  - 한계점 : K-IFRS 제1038호 무형자산 요건상 신뢰성 있는 원가 측정과 배타적 법적 통제권 입증이 어려워 재무제표 상 자산화되지 못하고 단순 비용으로 처리.
  - 해결 방안 : 데이터 카탈로그 기반의 계보(Data Lineage) 추적과 투입 원가(인프라, 라벨링, 정제 비용) 회계 계정 분리, 데이터 신탁 및 지식재산권(IP) 등록 체계 연계.
- 데이터 유통 시장의 유동성 부족 및 정보 비대칭성 :
  - 한계점 : 거래 표준 가격 지표 부재 및 구매 전 원본 데이터 사전 검증 불가(Arrow의 정보 역설)로 인해 데이터 거래 시장 활성화 지연.
  - 해결 방안 : 공인 데이터 거래소 기반의 표준 메타데이터 명세 공개, 동형암호 및 합성 데이터(Synthetic Data) 기반의 샘플 검증 샌드박스 제공.

## Ⅴ. 데이터 가치평가 활성화를 위한 실무 제언

- 데이터 회계 처리 표준 수립 : 현행 K-IFRS 상 내부 창출 무형자산의 엄격한 요건을 보완할 수 있도록 데이터 전용 무형자산 평가 및 공시 가이드라인 법제화 필요.
- 데이터 결합 생태계 연계 : 마이데이터 및 가명정보 결합 전문기관과의 연계를 통해 단독 데이터의 가치를 뛰어넘는 이종 결합 데이터의 부가가치를 창출해야 함.
- 신뢰성 높은 거래 인프라 확충 : 가치평가 기관의 공신력 제고와 함께, 블록체인 기반 데이터 이력 추적 및 프라이버시 보존 컴퓨팅(PET)을 결합하여 데이터 유통의 신뢰 장벽을 해소할 것을 제언함.
