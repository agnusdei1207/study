## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 관리 → **데이터 가치평가·데이터 자산화**

## 30초 인출

- 본질: 데이터 가치평가는 데이터가 만들어 내는 경제적 가치를 금액 등으로 추정하는 활동이고 데이터 자산화는 데이터를 관리·이용 조건이 정해진 자산으로 만드는 활동
- 메커니즘: 평가 목적과 대상 데이터를 정한 뒤 원가·시장·수익 접근법 중 적합한 방법으로 가치를 산정하고, 자산화로 목록·책임자·품질·이용 조건을 갖춰 가치가 유지되게 함
- 통찰: 같은 데이터도 품질과 활용 방식에 따라 가치가 크게 달라 산정값의 근거가 약해지므로 평가 전 품질과 이용 조건을 확인하고 방법별 결과를 비교해 근거와 가정을 함께 기록

<details>
<summary>핵심 용어</summary>

- **데이터 가치평가** : 데이터 활용에서 기대되는 경제적 효익을 추정하는 활동
- **데이터 자산화** : 데이터의 목록·책임·품질·이용 조건을 정해 지속적으로 관리·활용하는 활동
- **원가접근법(Cost Approach)** : 같은 데이터를 다시 만드는 데 드는 비용으로 평가하는 방법
- **시장접근법(Market Approach)** : 비교 가능한 데이터의 거래 사례로 평가하는 방법
- **수익접근법(Income Approach)** : 데이터로 얻을 기대 수익을 현재가치로 환산해 평가하는 방법
- **DCF(Discounted Cash Flow)** : 미래 현금흐름을 할인율로 현재가치로 바꾸는 계산
- **데이터 책임자(Data Owner)** : 데이터의 관리·이용 조건에 책임을 지는 담당자

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 가치평가의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 가치평가** 는 데이터가 만들어 내는 경제적 가치를 추정하는 활동 |
| 목적 | 데이터 거래·투자·회계의 근거 마련과 활용 우선순위 판단 |

## Ⅱ. 일반 재화와 구별되는 데이터의 특징

| 특징 | 의미 |
|---|---|
| 비소모성 | 사용해도 줄지 않고 반복 사용 |
| 비경합성 | 여러 사람이 동시에 사용 가능 |
| 활용 의존성 | 활용 목적에 따라 가치가 달라짐 |
| 시간 민감성 | 시간이 지나면 가치가 줄 수 있음 |

## Ⅲ. 가치평가 방법과 절차

### 가치평가 절차

```text
평가 목적·대상 데이터 정의
        ↓
품질·이용 조건 확인
        ↓
방법 선택(원가·시장·수익) → 가치 산정
        ↓
결과 검증 → 근거·가정 기록
```

### 평가 방법(접근법)

| 방법 | 산정 근거 | 적합 조건 |
|---|---|---|
| 원가접근법 | 데이터를 다시 만드는 비용 | 거래·수익 자료가 없는 초기 데이터 |
| 시장접근법 | 유사 데이터의 거래 가격 | 비교할 거래 사례가 있는 경우 |
| 수익접근법 | 기대 수익·비용 절감의 현재가치(DCF) | 활용 성과를 추정할 수 있는 경우 |

## Ⅳ. 평가 요인과 데이터 자산화

### 가치평가 요인

| 요인 | 내용 |
|---|---|
| 품질 | 정확성·완전성·최신성 |
| 활용성 | 활용 가능한 분야와 사용자 |
| 희소성·독점성 | 대체 가능한 데이터의 유무 |
| 법·제도 | 개인정보·이용 조건의 제약 |

### 데이터 자산화의 핵심요소

| 요소 | 내용 |
|---|---|
| 목록화 | 보유 데이터의 식별과 카탈로그 |
| 책임 체계 | 데이터 책임자 지정 |
| 품질관리 | 품질 기준과 점검 |
| 이용 조건 | 접근·제공·보안 정책 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 활용 방식에 따라 가치가 달라져 산정값의 근거 약함 | 활용 시나리오를 명시하고 방법별 결과를 비교 |
| 품질·이용 조건 미확인으로 과대평가 | 평가 전 품질 점검과 법적 제약 확인 |
| 가정 변경 시 결과 변동 | 가정과 민감도를 함께 기록해 객관성 확보 |

## Ⅵ. 제언

평가 전에 품질과 이용 조건을 확인하고 두 가지 이상의 방법으로 산정해 결과를 비교하며 근거·가정을 기록

```text
품질·조건 확인 ─ 방법 A 산정 ┐
                방법 B 산정 ┴─→ 차이 분석 → 최종 값과 가정 기록
```

| 구분 | 단일 방법·근거 미기록 | 제언: 복수 방법·근거 기록 |
|---|---|---|
| 신뢰성 | 낮음 | 상호 검증 |
| 재현성 | 곤란 | 가정 기록으로 가능 |

- 제139회 2교시 6번: 데이터 가치평가의 개념과 방법론, 데이터 자산화의 개념과 핵심요소, 활용사례
- 제140회 4교시 1번: 데이터 가치평가의 주요 평가 요인, 방법론, 객관성·신뢰성 확보를 위한 핵심변수
