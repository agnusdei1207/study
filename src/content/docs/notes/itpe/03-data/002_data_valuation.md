## 연관 키워드

- 데이터 가치평가(Data Valuation), 데이터 자산화(Data Assetization), 무형자산(Intangible Asset), K-IFRS
- 원가 접근법, 시장 접근법, 수익 접근법, 보정 요인, 데이터 거래소, AHP, 실물옵션, PET

## Ⅰ. 데이터 가치평가·자산화의 개요

- 핵심 요약 : 데이터의 경제적 효익을 화폐 가치로 추정하고, 이를 회계상 무형자산으로 인식할 수 있도록 만드는 활동.
- 개념 : 두 가지 활동으로 나뉨.
  - **데이터 가치평가** (Data Valuation) : 보유 데이터의 경제적 효익, 품질, 유통 가능성을 종합해 화폐 가치로 추정하는 것.
  - **데이터 자산화** (Data Assetization) : 비용 요소로만 처리되던 데이터를 **무형자산** (Intangible Asset, 물리적 실체 없이 미래 경제적 효익을 주는 자원)으로 인식하고, 거래·활용·투자 유치에 연계하는 활동.
- 배경 및 필요성 : 디지털 기업의 경쟁력이 데이터에 기대는 만큼 재무 보고와 M&A 실사(Due Diligence)에서 데이터 자산의 가치를 객관적으로 설명할 기준이 필요해짐.
- 주요 목적 : 데이터 자산의 정량적 가치 측정 체계를 정립하고, 회계와 법적 자산 인식의 기반을 마련하는 것.

## Ⅱ. 데이터 가치평가의 특징 및 장점

- 핵심 요약 : 원가, 시장, 수익의 3대 접근법으로 기초 가치를 구하고, 품질·활용·위험 요인으로 보정하는 산정 체계.

1. 3대 접근법 병행 : **원가 접근법** (Cost Approach), **시장 접근법** (Market Approach), **수익 접근법** (Income Approach)을 함께 적용 → 한 방법의 편향을 상호 보완.
2. 보정 요인 반영 : 기초 가치를 데이터 품질, 활용 가능성, 법적·보안 위험으로 조정 → 실제 쓰임새에 맞는 가치 도출.
3. 단계적 자산화 : 데이터를 발굴·식별하고 품질을 표준화한 뒤 등급을 매기고 활용하는 순서로 추진 → 관리 체계와 가치 평가가 연결.
4. 회계 요건 사전 검토 : **K-IFRS** (Korean International Financial Reporting Standards, 국제회계기준을 도입한 국내 회계기준) 제1038호의 무형자산 인식 요건을 미리 점검 → 재무제표 인식 실패 방지.

## Ⅲ. 데이터 가치평가·자산화의 구조 (흐름)

- 핵심 요약 : 3대 접근법으로 기초 가치를 구하고, 보정 요인을 거쳐 최종 가치를 정하는 평가 흐름.

```text
[ 3대 접근법으로 기초 가치 산출 ]
 - 원가 접근법 : 재생산·대체 비용 기준
 - 시장 접근법 : 유사 거래 사례 비교
 - 수익 접근법 : 미래 현금흐름의 현재가치
      ↓
[ 기초 가치 ]
      ↓ 보정 요인 반영
[ 최종 데이터 가치 ]
```

- 보정 요인의 세부 항목 :
  1. 품질 요인 : 완전성, 유효성, 정확성, 최신성 등 품질 지표 반영.
  2. 활용 요인 : 데이터 결합 가능성, 시장 내 독점성, API(Application Programming Interface) 연동 용이성 반영.
  3. 위험 요인 : 개인정보 침해 가능성과 GDPR(General Data Protection Regulation), 개인정보 보호법 등 규제 대응 비용 차감.
- 자산화의 단계별 흐름 :

```text
[ 1. 발굴과 식별 ]
   전사 데이터 카탈로그, 메타데이터 수집
      ↓
[ 2. 품질과 표준화 ]
   도메인 표준 정립, 데이터 정제
      ↓
[ 3. 가치 평가와 등급화 ]
   3대 접근법 적용, 등급 부여
      ↓
[ 4. 활용과 수익화 ]
   내부 최적화, 데이터 거래 유통
```

- 무형자산 인식의 3요건 (K-IFRS 제1038호 기준) :
  1. 식별가능성 : 계약상 권리이거나 다른 자산과 분리해 거래할 수 있는지 여부.
  2. 통제 : 접근과 법적 권리를 통해 미래 경제적 효익을 배타적으로 누리는지 여부.
  3. 미래 경제적 효익 : 매출 증가나 원가 절감을 합리적으로 추정할 수 있는지 여부.

## Ⅳ. 가치평가 3대 접근법의 비교

- 핵심 요약 : 증빙 중심의 원가 접근법, 시장 부합성의 시장 접근법, 비즈니스 기여의 수익 접근법이 서로 다른 면을 보완.

| 평가 방법 | 평가 원리 | 장점 | 한계 |
| --- | --- | --- | --- |
| 원가 접근법 | 데이터를 같은 수준으로 재생산하거나 대체하는 비용을 기준으로 산정 | 비용 증빙에 기반해 객관성을 확보하기 쉬움 | 미래 수익 잠재력이 반영되지 않음 |
| 시장 접근법 | 유사한 데이터 거래 사례와 비교해 시장 가치를 도출 | 시장 원리에 부합하는 직관적 평가 | 데이터가 고유하고 표준화가 어려워 비교군 확보가 곤란 |
| 수익 접근법 | 미래 현금흐름을 할인율로 현재가치화 | 비즈니스 기여도와 직접 연결된 본질적 평가 | 데이터 단독 기여분 분리와 미래 현금흐름 예측이 어려움 |

- 선택 기준 : 증빙이 목적이면 원가 접근법, 유통 가치 검증이면 시장 접근법, 경영 기여 평가이면 수익 접근법을 우선하고 필요에 따라 병행.

## Ⅴ. 데이터 가치평가·자산화의 한계와 방안

- 핵심 요약 : 비경합성에 따른 평가 편차, 무형자산 인식 요건의 충족 한계, 유통 시장의 정보 비대칭을 보완 기법과 제도로 통제.

- 장점 : 객관적 가치 기준으로 M&A 실사와 담보 평가를 지원하고, 데이터 투자의 경제적 타당성을 입증하며, 데이터 품질 관리의 동기를 높임.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 가치 산정의 불안정성 | 데이터는 복제 비용이 낮아 여러 번 쓸 수 있고, 결합 여부에 따라 가치가 크게 달라져 평가 편차가 커짐 | **AHP** (Analytic Hierarchy Process, 여러 평가 기준을 계층화해 가중치를 정하는 의사결정 기법)와 **실물옵션** (Real Options, 미래의 선택권을 옵션으로 가치화하는 기법)을 결합해 평가 | 평가 결과의 편차율 |
| 무형자산 인식 요건 충족 곤란 | 신뢰성 있는 원가 측정과 배타적 통제 입증이 어려워 재무제표에 자산으로 반영되지 못하고 비용으로 처리됨 | 데이터 계보(Data Lineage) 추적으로 투입 원가를 계정별로 분리하고, 데이터 신탁이나 지식재산권 등록과 연계 | 자산 인식 건수, 투입 원가 추적률 |
| 유통 시장의 정보 비대칭 | 거래 표준 가격이 없고 구매 전 원본 데이터를 검증하기 어려워 거래가 활발해지지 않음 (Arrow의 정보 역설) | 공인 데이터 거래소의 표준 메타데이터 공개, 합성 데이터(Synthetic Data)로 샘플을 먼저 검증하는 샌드박스 제공 | 거래 건수, 거래 후 분쟁 건수 |

## Ⅵ. 데이터 가치평가 활성화에 대한 기술사적 제언

- 핵심 요약 : 데이터 자산 회계 기준의 보완, 결합 생태계 확대, 신뢰 기반의 거래 인프라 확충을 함께 추진하는 방향이 바람직하다.
- 회계 제도 측면에서는 K-IFRS의 내부 창출 무형자산 요건이 데이터에 맞지 않는 부분을 보완하는 데이터 자산 평가와 공시 가이드라인을 마련하는 것이 필요하다. 이를 위해 금융 당국과 회계기준 제정기관이 데이터 자산 사례를 함께 축적해야 한다.
- 데이터 활용 측면에서는 마이데이터와 가명정보 결합 전문기관을 활용해 서로 다른 출처의 데이터를 결합하면 단독 데이터보다 높은 부가가치를 얻을 수 있다.
- 거래 인프라 측면에서는 가치평가 기관의 공신력을 높이고, 데이터 이력을 블록체인으로 추적하며, PET(Privacy-Enhancing Technology, 개인정보를 보호하며 데이터를 활용하는 기술)를 결합해 유통 신뢰를 높이는 것이 현실적이다.

## Ⅶ. 결론

- 핵심 요약 : 데이터 가치평가는 3대 접근법과 보정 요인의 결합으로 가능하며, 자산화는 회계 요건과 거래 인프라의 정비가 관건.
- 시사점 : 평가 기법의 표준화와 회계·법 제도의 정비가 함께 이루어져야 데이터 경제의 활성화가 가능함.
