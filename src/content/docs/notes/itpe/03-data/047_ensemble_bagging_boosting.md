## 연관 키워드
- 앙상블, 배깅, 부스트, 랜덤 포레스트, 그레이디언트 부스팅, 오버핏팅, 변량 편향

### Ⅰ. 앙상블 배깅·부스팅의 개요

- 핵심 요약 : 여러 모델의 예측을 결합하여 단일 모델보다 더 나은 예측 성능을 얻는 기계학습 기법.
- 개념 : 여러 모델의 예측을 결합해 단일 모델의 오류·분산을 줄이거나 예측력을 높이는 기법(**앙상블**, Ensemble).
- 배경 및 필요성 : 단일 모델은 편향·분산 문제가 있어 일반화 성능이 제한될 수 있음.
- 주요 목적 : 여러 모델의 예측을 결합하여 일반화 성능과 안정성을 향상.

### Ⅱ. 앙상블 배깅·부스팅의 특징 및 장점

- 핵심 요약 : 배깅, 부스팅, 랜덤 포레스트, 그레이디언트 부스팅은 서로 다른 원리로 앙상블을 구성하며, 각각의 장단점이 있음.

1. 배깅(Bagging, Bootstrap Aggregating) : 여러 개의 부트스트랩 샘플에 독립적으로 모델을 학습하고, 결과를 평균 또는 다수결로 결합.
2. 부스팅(Boosting) : 약한 학습기를 순차적으로 학습시켜 이전 모델의 오차를 보완하는 방식으로 학습.
3. 랜덤 포레스트(Random Forest) : 배깅 기반의 결정 트리 앙상블로, 특징 랜덤 선택을 통해 분산 감소.
4. 그레이디언트 부스팅(Gradient Boosting) : 오차 음의 기울기 방향으로 모델을 추가하여 손실 함수 최소화.

### Ⅲ. 앙상블 배깅·부스팅의 구조 (흐름)

- 핵심 요약 : 배깅은 병렬 학습, 부스팅은 순차 학습, 각각의 예측 결과를 결합하여 최종 예측.

```text
[ 배깅 ]
훈련 데이터
   ↓
부트스트랩 샘플링
   ↓
병렬 학습 (독립 모델들)
   ↓
평균/다수결 결합
   ↓
최종 예측

[ 부스팅 ]
훈련 데이터
   ↓
첫 번째 모델 학습
   ↓
오차 기반 가중치 조정
   ↓
다음 모델 학습 (이전 오차 보완)
   ↓
가중 결합
   ↓
최종 예측
```

### Ⅳ. 배깅과 부스팅 비교

- 핵심 요약 : 병렬 vs 순차 학습, 분산 vs 편향 감소라는 서로 다른 트레이드오프.

| 비교 항목 | 배깅(Bagging) | 부스팅(Boosting) |
|---|---|---|
| 학습 방식 | 독립 모델 병렬 학습 | 순차적 가중 학습 |
| 주요 효과 | 분산 감소, 과적합 완화 | 편향 감소, 복합 패턴 학습 |
| 대표 알고리즘 | 랜덤 포레스트 | 그레이디언트 부스팅, AdaBoost |

### Ⅴ. 앙상블 배깅·부스팅의 한계와 방안

- 핵심 요약 : 과적합, 계산 비용 증가, 해석 가능성 저하 등의 한계를 앙상블 크기 조절, 규제, 특성 선택으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 과적합 | 너무 많은 모델 앙상블로 훈련 데이터에 과도하게 적합 | 교차 검증, 조기 중단, 규제 기법 적용 | 검증 오차, 검증 정확도 |
| 계산 비용 | 다수 모델 학습 및 예측에 시간·자원 소모 | 모델 수 제한, 경량 모델 사용, 병렬 처리 | 학습 시간, 추론 지연 |
| 해석 가능성 | 앙상블 모델은 개별 모델보다 해석이 어려움 | SHAP, LIME 같은 설명 가능성 기법 적용 | 설명 가능성 점수 |

### Ⅵ. 앙상블 배깅·부스팅에 대한 기술사적 제언

- 핵심 요약 : 앙상블 크기, 학습률, 샘플링 비율 등을 데이터 특성과 계산 자원에 맞춰 조정하는 것이 중요함.

1. 앙상블 크기 : 너무 작으면 효과가 미미하고, 너무 크면 과적합과 계산 비용 증가 → 검증 세트로 최적 개수 탐색.
2. 학습률 : 부스팅에서 학습률이 높으면 과적합 위험, 낮으면 수렴 속도 느림 → 교차 검증으로 최적값 탐색.
3. 샘플링 비율 : 배깅에서 서브샘플링 비율이 너무 낮으면 분산 감소 효과 미미, 너무 높으면 모델 간 상관성 증가 → 교차 검증으로 최적값 탐색.

### Ⅶ. 결론

- 핵심 요약 : 앙상블 배깅·부스팅은 여러 모델의 예측을 결합하여 단일 모델보다 더 나은 예측 성능을 얻는 기법.
- 시사점 : 앙상블 크기, 학습률, 샘플링 비율 등을 적절히 설정하여 과적합과 계산 비용을 균형 있게 관리하는 것이 중요함.
