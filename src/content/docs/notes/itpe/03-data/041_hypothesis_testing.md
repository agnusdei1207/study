## Ⅰ. 통계적 의사결정의 핵심, 가설검정(Hypothesis Testing) 개요

### 가. 가설검정의 정의
- **가설검정** : 모집단의 모수(평균, 비율, 분산 등)에 대한 어떤 주장이나 가설을 수립하고, 모집단으로부터 추출한 표본 데이터를 바탕으로 그 주장의 타당성 여부를 확률적으로 판정하는 통계적 추론 방법.
- 우연에 의해 이러한 결과가 발생할 확률($p$-value)을 계산하여 귀무가설의 기각 여부를 결정함.

### 나. 대립되는 두 가지 가설
- **귀무가설 (Null Hypothesis, $H_0$)** : 기존의 상태, 차이가 없음, 효과가 없음을 주장하는 가설 (기각을 목표로 세우는 출발점).
- **대립가설 (Alternative Hypothesis, $H_1$)** : 연구자가 실질적으로 증명하고자 하는 새로운 사실, 차이가 있음, 효과가 있음을 주장하는 가설.

## Ⅱ. 가설검정의 5단계 절차 및 검정통계량

### 가. 가설검정 표준 5단계 절차

```text
[ 가설검정 프레임워크 ]
[Step 1: 가설 설정]     ---> H0: 효과 없음 vs H1: 효과 있음 (양측/단측)
           |
[Step 2: 유의수준 설정] ---> alpha = 0.05 (5%) 또는 0.01 (1%)
           |
[Step 3: 검정통계량 계산] -> z-통계량, t-통계량, F-통계량 산출
           |
[Step 4: 기각역 및 p-값]  -> p-value 산출 (귀무가설 하에서 관측값 이상이 나올 확률)
           |
[Step 5: 의사결정]       -> p-value < alpha 이면 H0 기각 (통계적 유의성 확보)
```

### 나. 양측 검정 vs 단측 검정
- **양측 검정 (Two-tailed)** : $H_1: \mu \neq \mu_0$ (차이가 있는지만 확인, 양쪽 꼬리에 각 $\alpha/2$ 배정).
- **단측 검정 (One-tailed)** : $H_1: \mu > \mu_0$ (우측 단측) 또는 $H_1: \mu < \mu_0$ (좌측 단측, 방향성이 명확할 때 사용).

## Ⅲ. 가설검정의 2대 오류(Type Ⅰ, Ⅱ Error) 및 검정력(Power)

### 가. 가설검정 오류 매트릭스

```text
[ 1종 오류 vs 2종 오류 ]
                       실제 H0가 참(효과 없음)      실제 H0가 거짓(효과 있음)
  H0 채택 (차이 없음) : 올바른 결정 (1 - alpha)    2종 오류 beta (위음성, False Negative)
  H0 기각 (차이 있음) : 1종 오류 alpha (위양성)     올바른 결정 1 - beta (검정력, Power)
```

| 구분 | 개념 및 기호 | 비즈니스 사례 | 제어 및 상충 관계 |
| :--- | :--- | :--- | :--- |
| **제1종 오류 (Type Ⅰ)** | 실제로 효과가 없는데 효과가 있다고 잘못 판단하는 오류 ($\alpha$, 생산자 위험) | 아무 효과 없는 신약이 치료 효과가 있다고 승인 | 유의수준 $\alpha$를 0.05, 0.01로 사전에 엄격히 고정하여 통제 |
| **제2종 오류 (Type Ⅱ)** | 실제로 효과가 있는데 효과가 없다고 잘못 기각하지 못하는 오류 ($\beta$, 소비자 위험) | 실제 사기 거래인데 정상 거래로 오판하여 미탐 | 표본 크기 $n$을 늘림으로써만 $\alpha$ 증가 없이 $\beta$를 줄일 수 있음 |
| **통계적 검정력 (Power)** | 대립가설이 참일 때 귀무가설을 올바르게 기각할 확률 ($1 - \beta$) | A/B 테스트에서 실제 개선 효과가 있을 때 이를 감지해 낼 확률 | 통상 80%($0.80$) 이상을 목표로 샘플 크기 사전 산정 |

## Ⅳ. 가설검정 실무 적용 시 주요 한계점 및 해결 방안

- 빅데이터 환경에서 p-value의 과도한 민감성 및 p-해킹(p-hacking) :
  - 한계점 : 표본 수($n$)가 수십만 건 이상으로 커지면 표준오차가 극단적으로 작아져 비즈니스적으로 무의미한 미세한 차이도 $p < 0.05$로 판정되는 통계적 착시 발생.
  - 해결 방안 : $p$-value 맹신 탈피, 효과 크기(Cohen's d, Relative Lift)와 신뢰구간(Confidence Interval)을 필수 병기하고 최소 감지 효과 크기(MDE, Minimum Detectable Effect) 사전 설정.
- 다중 가설 검정(Multiple Testing) 시 제1종 오류의 누적 팽창 :
  - 한계점 : 수십 개의 지표나 A/B/C/D 다중 그룹을 동시 검정할 경우 패밀리별 오류율(FWER, Family-Wise Error Rate)이 급증하여 위양성(False Positive) 결론 채택 위험.
  - 해결 방안 : 본페로니(Bonferroni) 교정 또는 허위발견율(FDR, False Discovery Rate; Benjamini-Hochberg) 절차를 적용하여 유의수준 임계치를 보수적으로 재조정.
- 조기 종료(Peeking Problem)로 인한 A/B 테스트 신뢰도 왜곡 :
  - 한계점 : 테스트 진행 중 실시간으로 결과를 반복 확인하며 유의한 순간 테스트를 조기 종료하면 실제보다 유의확률이 크게 왜곡되는 현상 발생.
  - 해결 방안 : 고정 표본 크기 사전 산정 준수, 또는 순차적 검정(Sequential Testing, mSPRT, mixture Sequential Probability Ratio Test) 및 멀티암드 밴딧(Multi-Armed Bandit) 알고리즘 도입.

## Ⅴ. 데이터 사이언스 및 엔지니어링 실무 제언

- $p$-value 해킹 및 오용 방지 : $p$-value는 가설이 참일 확률이 아니며, 표본 크기 $n$이 수십만 건 이상으로 극단적으로 커지면 비즈니스적으로 무의미한 극미한 차이도 $p < 0.001$로 유의하게 도출됨. 따라서 $p$-value 단독 판정을 지양하고 **효과 크기** (Effect Size, Cohen's d)와 신뢰구간(CI, Confidence Interval)을 반드시 병기해야 함.
- 사전 검정력 분석(Power Analysis) 수행 : A/B 테스트 기획 시 실험을 무작정 시작하지 말고, 기대 최소 감지 효과(MDE), 유의수준 $\alpha=0.05$, 목표 검정력 80%를 충족하는 데 필요한 최소 표본 크기를 사전에 수학적으로 계산하여 자원 낭비를 방지할 것을 제언함.
