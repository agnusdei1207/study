## 연관 키워드

- 가설검정(Hypothesis Testing), 귀무가설(Null Hypothesis), 대립가설(Alternative Hypothesis), 유의수준(Significance Level), p-값(p-value)
- 제1종 오류(Type I Error), 제2종 오류(Type II Error), 검정력(Power), 효과 크기(Effect Size), 다중 검정(Multiple Testing), A/B 테스트

## Ⅰ. 가설검정(Hypothesis Testing)의 개요

- 핵심 요약 : 표본 데이터로 모집단 모수에 대한 주장의 타당성을 확률적으로 판정하는 통계적 추론 방법.
- 개념 : 모집단의 모수(평균, 비율, 분산 등)에 대한 주장이나 가설을 세우고, 표본 데이터로 그 주장의 타당성을 확률적으로 판정하는 **통계적 추론**(Statistical Inference) 방법.
- 배경 및 필요성 : 표본만으로 모집단을 판단해야 하는 상황에서, 우연에 의해 관측 결과가 나올 확률인 **p-값**(p-value)을 계산하고 귀무가설의 기각 여부를 객관적으로 판정할 필요가 있음.
- 주요 목적 : 통계적 유의성을 확보하여 데이터 기반 의사결정을 지원.

## Ⅱ. 가설검정의 특징

- 핵심 요약 : 대립하는 두 가설의 설정, 오류 통제, 검정통계량 기반 판정이 결합된 추론 절차.

1. **귀무가설** (Null Hypothesis, H0) : 기존 상태이며 차이나 효과가 없다고 주장하는 가설 → 기각을 목표로 세우는 출발점.
2. **대립가설** (Alternative Hypothesis, H1) : 연구자가 실질적으로 증명하려는 차이나 효과가 있다고 주장하는 가설 → 귀무가설을 기각할 때 채택.
3. **유의수준** (Significance Level, α) : 제1종 오류의 허용 한계를 0.05나 0.01 등으로 사전에 고정 → 판정 기준을 미리 정해 결과의 자의적 해석을 막음.
4. 양측 검정과 단측 검정 : 차이의 존재 여부를 볼지, 방향성을 볼지에 따라 기각역의 위치를 결정 → 검정 목적에 맞는 기준 설정.
5. 검정통계량과 p-값 : z, t, F 통계량을 계산하고 p-값과 비교하여 기각 여부를 판정 → 두 방식이 같은 결론에 이르는지 확인 가능.

## Ⅲ. 가설검정의 구조 (흐름)

- 핵심 요약 : 가설 설정에서 의사결정까지 이어지는 표준 5단계 절차.

```text
[ 가설검정 표준 5단계 ]
1. 가설 설정 (H0 vs H1, 양측·단측)
   ↓
2. 유의수준 설정 (α = 0.05 또는 0.01)
   ↓
3. 검정통계량 계산 (z, t, F)
   ↓
4. p-값 산출 (H0 하에서 관측값 이상일 확률)
   ↓
5. 의사결정 (p-값 < α 이면 H0 기각)
```

- 양측 검정은 H1: 모수 ≠ 기준값으로 두어 양쪽 꼬리에 각각 α/2를 배정하고, 단측 검정은 방향이 명확할 때 우측 또는 좌측 한쪽 꼬리에 α를 배정한다.

## Ⅳ. 오류 유형의 비교

- 핵심 요약 : 제1종 오류(α)와 제2종 오류(β)는 상충 관계에 있으며, 검정력(1 - β)을 확보하도록 표본 크기를 설계해야 함.
- 개념 : **제1종 오류**(Type I Error)는 효과가 없는데 있다고 판단하는 오류이고, **제2종 오류**(Type II Error)는 효과가 있는데 없다고 판단하는 오류이며, **검정력**(Power)은 대립가설이 참일 때 귀무가설을 올바르게 기각하는 확률임.

```text
[ 판정 결과와 오류 ]
실제 H0가 참 (효과 없음)
   → H0 기각 시 : 1종 오류 (α, 위양성)
   → H0 채택 시 : 올바른 결정 (1 - α)
실제 H0가 거짓 (효과 있음)
   → H0 채택 시 : 2종 오류 (β, 위음성)
   → H0 기각 시 : 올바른 결정 (1 - β)
```

| 구분 | 개념 및 기호 | 사례 | 제어 및 상충 관계 |
| :--- | :--- | :--- | :--- |
| 제1종 오류 (Type I Error) | 효과가 없는데 있다고 잘못 판단 (α, 생산자 위험) | 효과가 없는 약의 치료 효과를 승인 | 유의수준을 0.05, 0.01 등으로 사전 고정하여 통제 |
| 제2종 오류 (Type II Error) | 효과가 있는데 없다고 잘못 판단 (β, 소비자 위험) | 실제 효과가 있는 개선안을 기각 | 표본 크기를 키워 α를 높이지 않고 β를 줄임 |
| 검정력 (Power) | 대립가설이 참일 때 올바르게 기각할 확률 (1 - β) | A/B 테스트에서 실제 개선 효과를 감지할 확률 | 통상 0.80 이상을 목표로 표본 크기를 사전 산정 |

## Ⅴ. 가설검정의 한계와 방안

- 핵심 요약 : 객관적 판정 기준을 제공하는 장점과 달리, p-값 과민성, 다중 비교, 조기 종료에 따른 왜곡이라는 한계가 공존.
- 장점 : 우연과 실제 효과를 구분하여 객관적 의사결정 근거를 제공하고, 오류 유형과 검정력을 사전 설계해 실험 신뢰성을 확보.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 빅데이터의 p-값 과민성과 **p-해킹**(p-hacking) | 표본이 매우 크면 표준오차가 작아져 실무적으로 무의미한 미세 차이도 유의하게 판정 | p-값 단독 판정 지양, 효과 크기(Cohen's d, Relative Lift)와 신뢰구간(CI, Confidence Interval) 병기, 최소 감지 효과(MDE, Minimum Detectable Effect) 사전 설정 | 효과 크기, 신뢰구간 폭 |
| **다중 검정**(Multiple Testing)의 제1종 오류 누적 | 여러 지표나 다중 그룹을 동시에 검정하면 가족별 오류율(FWER, Family-Wise Error Rate)이 급증하여 위양성 결론 위험 증가 | 본페로니(Bonferroni) 교정 또는 허위발견율(FDR, False Discovery Rate) 절차인 벤자미니-호크버그(Benjamini-Hochberg) 적용 | 보정 후 유의 건수, 검정 개수 |
| 조기 종료(Peeking Problem)에 따른 신뢰도 왜곡 | 테스트 중 결과를 반복 확인하고 유의한 순간 중단하면 실제보다 유의확률이 과대 평가 | 사전에 정한 표본 크기 준수, 순차적 검정(Sequential Testing) 또는 멀티암드 밴딧(Multi-Armed Bandit) 적용 | 사전 표본 크기 준수율 |

```text
[ 가설검정 오용 통제 ]
p-값 단독 판정  → 효과 크기·신뢰구간 병기
다중 비교       → 본페로니·FDR 보정
조기 종료       → 표본 크기 사전 고정
```

## Ⅵ. 가설검정에 대한 기술사적 제언

- 핵심 요약 : 효과 크기 병기와 사전 검정력 분석을 실험 절차의 표준으로 정착시키는 방향.

1. 실험 기획 조직은 A/B 테스트를 시작하기 전에 기대 최소 감지 효과, 유의수준 0.05, 목표 검정력 0.80을 기준으로 필요한 표본 크기를 사전 계산하여 자원 낭비를 막아야 한다.
2. 데이터 분석 조직은 보고서에 p-값만 싣지 않고 효과 크기와 신뢰구간을 함께 제시하며, p-값은 가설이 참일 확률이 아니라는 해석 기준을 분석 가이드에 명시해야 한다.
3. 실험 플랫폼 운영 조직은 다중 지표 검정에 보정 절차를 기본 적용하고, 조기 종료가 필요한 경우 순차적 검정 방식만 허용하는 실험 거버넌스를 마련해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 가설검정은 오류 통제와 검정력 설계가 전제된 실험 판정 체계임.
- 시사점 : 효과 크기와 신뢰구간의 병기, 다중 검정 보정, 조기 종료 방지를 갖춘 실험 거버넌스가 가설검정의 신뢰도를 결정함.
