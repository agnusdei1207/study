## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **가설검정**

## 30초 인출

- 본질: 가설검정은 표본 근거와 확률 모형으로 모집단에 관한 가설을 판단하는 추론 절차
- 메커니즘: 귀무·대립가설과 유의수준을 사전에 정하고, 검정통계량으로 귀무가설 아래의 p-value를 구해 기각 여부를 결정한 뒤 효과 크기와 신뢰구간을 함께 해석
- 통찰: p-value는 귀무가설이 참일 확률이 아니고 비기각은 차이 없음의 증명이 아니므로 검정력과 효과 크기, 사전에 정한 기준을 함께 보고

<details>
<summary>핵심 용어</summary>

- **귀무가설(H0)** : 기준으로 놓고 자료와의 양립성을 평가하는 주장
- **대립가설(H1)** : 검정하려는 차이·효과가 있다는 주장
- **유의수준(α)** : 제1종 오류의 사전 허용 상한
- **p-value** : 귀무가설과 모형 가정 아래 관측 자료만큼 극단적인 결과가 나올 확률
- **제1종 오류** : 참인 귀무가설을 기각하는 오류
- **제2종 오류(β)** : 거짓인 귀무가설을 기각하지 못하는 오류
- **검정력(1−β)** : 거짓인 귀무가설을 올바르게 기각할 확률
- **효과 크기** : 차이의 실질적 크기

</details>

## 2~4교시 25점 답안

## Ⅰ. 가설검정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **가설검정** 은 표본 근거와 확률 모형으로 가설에 대한 결론을 내리는 추론 절차 |
| 목적 | 우연한 변동을 고려한 모집단 의사결정 지원 |

## Ⅱ. 특징

| 특징 | 해석 기준 |
|---|---|
| 사전 설계 | 자료 확인 전에 가설·방향·유의수준·가정 설정 |
| 조건부 확률 | p-value는 귀무가설과 가정 아래 자료의 극단성 |
| 제한된 결론 | 비기각은 귀무가설의 참을 증명하지 않음 |

## Ⅲ. 절차

```text
H0·H1·검정 방향·α·가정 사전 설정
        ↓
표본 수집 → 검정통계량 → H0 아래 분포로 p-value 산출
        ↓
p ≤ α: H0 기각 / p > α: H0 기각하지 못함
        ↓
효과 크기·신뢰구간·가정과 함께 해석
```

| 항목 | 내용 | 예 |
|---|---|---|
| 귀무가설 | 기준 주장 | 두 집단 평균 차이 없음 |
| 대립가설 | 검정할 차이·효과 | 두 집단 평균이 다름 |
| 유의수준 | 제1종 오류 허용 상한 | 분석 전에 α 결정 |
| 검정 방향 | 양측 또는 단측 사전 지정 | 결과에 맞춘 사후 변경 금지 |

## Ⅳ. 오류 유형과 검정력

| 실제 / 판단 | H0 기각 | H0 기각하지 못함 |
|---|---|---|
| H0 참 | 제1종 오류(α) | 올바른 판단 |
| H1 참 | 검정력(1−β) | 제2종 오류(β) |

표본 크기·효과 크기·변동성·유의수준에 따라 검정력이 달라지며, 표본 크기 증가가 검정력을 높이지만 설계 결함·편향은 해결하지 못함.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| p-value를 귀무가설이 참일 확률로 오해 | 가정 아래 자료의 극단성으로 해석 |
| 작은 p-value를 효과의 크기로 오해 | 효과 크기·신뢰구간 병행 |
| 비기각을 차이 없음의 증명으로 오해 | 검정력·구간추정 확인 |
| 0.05를 고정 기준으로 사용 | 오류 비용·다중검정을 고려해 사전 설정 |
| 유의한 연관성을 인과로 해석 | 실험 설계·교란 요인 통제 확인 |

## Ⅵ. 제언

분석 전에 오류 비용을 고려해 α와 검정력을 정하고, 표본 크기 산정부터 신뢰구간 해석까지 한 절차로 운영

```text
가설·α·검정력 → 표본 크기 산정 → 검정 → 효과 크기·신뢰구간 보고
```

| 구분 | p-value 중심 판정 | 제언: 검정력·효과 크기 병행 |
|---|---|---|
| 큰 표본 | 미세 차이도 유의 | 실질적 크기 판별 |
| 오류 통제 | α만 통제 | β도 사전 고려 |
