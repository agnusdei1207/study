## 연관 키워드

- 가설검정(Hypothesis Testing), 귀무가설(Null Hypothesis), 대립가설(Alternative Hypothesis), 유의수준(Significance Level), p-값(p-value)
- 검정통계량, 기각역, 제1종 오류(Type I Error), 제2종 오류(Type II Error), 검정력(Power), 양측 검정, 단측 검정

## Ⅰ. 가설검정의 개요

- 핵심 요약 : 표본 데이터로 모집단에 대한 주장의 타당성을 확률적으로 판정하는 통계적 추론 절차.
- 개념 : 모집단 모수에 대한 상충하는 두 가설을 세우고, 표본에서 계산한 수치의 발생 확률로 어느 쪽을 지지하는지 판정하는 **가설검정**(Hypothesis Testing) 절차.
- 배경 및 필요성 : 전수 조사가 불가능한 상황에서 표본만으로 모집단을 판단해야 하므로, 우연 변동과 실제 효과를 구분하는 객관적 판정 기준 필요.
- 주요 목적 : 판정 기준을 절차 앞 단계에서 고정해 데이터 기반 의사결정의 일관성과 재현성 확보.

## Ⅱ. 가설검정의 특징 및 장점

- 핵심 요약 : 가설의 대비 구조, 기준의 사전 고정, 오류 통제가 결합된 절차적 추론 체계.

1. 가설의 대비 구조 : 기각 대상의 **귀무가설**(Null Hypothesis, H0)과 입증 대상의 **대립가설**(Alternative Hypothesis, H1)을 상호 배타적으로 설정 → 판정 대상의 명확화.
2. 기준의 사전 고정 : 제1종 오류의 허용 한계인 **유의수준**(Significance Level)을 관례값(예: 0.05)으로 시작 전에 지정 → 결과 확인 후 기준을 바꾸는 자의적 해석 차단.
3. 확률 기반 판정 : 귀무가설이 참일 때 관측 결과 이상이 나올 확률인 **p-값**(p-value)을 계산해 유의수준과 비교 → 판정 근거의 수치화.
4. 기각 방향의 설정 : 차이의 존재 여부만 보는 **양측 검정**과 방향성까지 보는 **단측 검정**의 구분 → 검정 목적에 맞는 판정 기준 설계.
5. 오류 통제 설계 : 표본 크기와 유의수준의 조정으로 두 오류의 균형 관리 → 실험 신뢰성 확보.

## Ⅲ. 가설검정의 구조 (흐름)

- 핵심 요약 : 가설 설정부터 의사결정까지의 표준 5단계 절차와 상황별 검정통계량 선택 구조.
- 판정 방식은 p-값 비교와 **기각역**(Rejection Region, 귀무가설을 기각하는 검정통계량의 영역) 비교가 동일 결론에 도달하는 동치 방식.
- **검정통계량**(Test Statistic, 표본에서 계산하는 판정용 수치)의 선택은 모수 종류, 표본 크기, 모분산 인지 여부에 따라 달라짐.

```text
[가설검정 표준 5단계]
1. 가설 설정 (H0 대 H1)
   ↓
2. 유의수준 지정 (α)
   ↓
3. 표본 수집과 검정통계량 계산
   ↓
4. p-값 산출 또는 기각역 판정
   ↓
5. 의사결정 (p-값이 α보다 작으면 H0 기각)
```

| 상황 | 선택 대상 |
| :--- | :--- |
| 모분산 인지 또는 큰 표본의 평균 비교 | Z 통계량 |
| 모분산 미인지 소표본의 평균 비교 | t 통계량 |
| 범주형 자료의 비율·적합도 검정 | 카이제곱 통계량 |
| 복수 집단의 분산 비교 | F 통계량 |

```text
[판정 분기 구조]
귀무가설 하의 분포
   ↓
기각역 (꼬리 영역, 면적 α)
   ↓ 통계량이 기각역 안에 위치
귀무가설 기각 → 대립가설 지지
```

## Ⅳ. 제1종 오류와 제2종 오류의 비교

- 핵심 요약 : 두 오류는 상충 관계이므로 유의수준 고정과 표본 크기 설계로 균형을 잡는 것이 설계 기준.
- 개념 : 효과가 없는데 있다고 판정하는 **제1종 오류**(Type I Error)와 효과가 있는데 없다고 판정하는 **제2종 오류**(Type II Error)는 판정의 두 방향 오류.

| 구분 | 제1종 오류 | 제2종 오류 |
| :--- | :--- | :--- |
| 의미 | 효과 없음을 효과로 판정 | 효과 있음을 효과 없음으로 판정 |
| 확률 기호 | α (유의수준) | β |
| 별칭 | 위양성, 생산자 위험 | 위음성, 소비자 위험 |
| 통제 수단 | 유의수준을 낮게 사전 고정 | 표본 크기 확대로 β 축소 |
| 상호 관계 | α 축소 시 β 확대의 상충 | β 축소 시 α 확대의 상충 |

- **검정력**(Power, 대립가설이 참일 때 귀무가설을 올바르게 기각하는 확률)은 1에서 β를 뺀 값.
- 선택 기준 :
  1. 효과 없음의 승인 비용이 큰 영역은 α를 엄격히 낮추는 쪽으로 설계.
  2. 개선 기회 상실의 비용이 큰 영역은 검정력 목표(관례상 0.80 이상)를 기준으로 표본 크기를 사전 산정.

## Ⅴ. 가설검정의 한계와 방안

- 핵심 요약 : 객관적 판정 기준 제공이라는 이점 이면에 유의성 과대 해석, p-해킹, 다중 검정, 조기 종료의 왜곡 위험 존재.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 유의성 과대 해석 | 큰 표본에서 미세 차이도 유의 판정 | **효과 크기**(Effect Size, 차이의 실질적 크기)와 신뢰구간 병기 | 효과 크기, 신뢰구간 폭 |
| **p-해킹**(p-hacking) | 결과 확인 후 가설·지표 변경으로 위양성 급증 | 가설·지표·표본 크기의 사전 등록 절차 운영 | 사전 등록 준수율 |
| **다중 검정**(Multiple Testing) | 비교 횟수 증가만큼 제1종 오류 확률 누적 | 본페로니(Bonferroni) 교정 등의 보정 절차 적용 | 보정 후 유의 결과 수 |
| 조기 종료 (Peeking) | 중간 확인 후 중단으로 유의확률 과대 평가 | 사전 확정 표본 크기까지 실험 유지 | 표본 크기 준수율 |

## Ⅵ. 가설검정에 대한 기술사적 제언

- 핵심 요약 : 실험 생애주기 표준과 동료 검토, 플랫폼 강제 기능으로 판정 무결성을 제도화하는 방향.

1. 데이터 거버넌스 조직은 실험 설계, 실행, 보고를 아우르는 실험 운영 표준을 제정하고 준수 여부를 정기 감리.
2. 데이터 분석 조직은 분석가 대상의 통계 검토 회의와 동료 검토(Peer Review) 절차로 판정 결과의 해석 오류를 사전 차단.
3. 실험 플랫폼 조직은 표본 크기 도달 전 결과 비공개 처리 같은 무결성 기능을 플랫폼 차원에서 강제 적용.

## Ⅶ. 결론

- 핵심 요약 : 가설검정은 판정 기준의 사전 고정으로 우연과 효과를 구분하는 통계적 판정 절차.
- 시사점 : 절차 표준의 준수와 두 오류의 균형 설계가 실험 기반 의사결정 신뢰성의 전제.
