## 연관 키워드

- 가설검정(Hypothesis Testing), 귀무가설(Null Hypothesis), 대립가설(Alternative Hypothesis), 유의수준(Significance Level), p-값(p-value)
- 제1종 오류(Type Ⅰ Error), 제2종 오류(Type Ⅱ Error), 검정력(Power), 효과 크기(Effect Size), 다중 검정(Multiple Testing), A/B 테스트

## Ⅰ. 가설검정(Hypothesis Testing)의 개요

- 핵심 요약 : 표본 데이터로 모집단 모수에 대한 주장의 타당성을 확률적으로 판정하는 통계적 추론 방법.
- 개념 : 모집단의 모수(평균, 비율, 분산 등)에 대한 어떤 주장이나 가설을 수립하고, 모집단으로부터 추출한 표본 데이터를 바탕으로 그 주장의 타당성 여부를 확률적으로 판정하는 통계적 추론 방법.
- 배경 및 필요성 : 표본만으로 모집단 판단이 필요한 환경에서 우연에 의한 결과 발생 확률($p$-value)의 계산과 귀무가설 기각 여부의 객관적 판정 요구.
- 주요 목적 : 통계적 유의성 확보를 통한 데이터 기반 의사결정 지원.

## Ⅱ. 가설검정의 특징

- 핵심 요약 : 대립하는 두 가설의 설정과 오류 통제, 검정통계량 기반 판정이 결합된 추론 절차.

1. 귀무가설(Null Hypothesis, $H_0$) : 기존의 상태, 차이가 없음, 효과가 없음을 주장하는 가설 (기각을 목표로 세우는 출발점).
2. 대립가설(Alternative Hypothesis, $H_1$) : 연구자가 실질적으로 증명하고자 하는 새로운 사실, 차이가 있음, 효과가 있음을 주장하는 가설.
3. 유의수준($\alpha$) : 제1종 오류의 허용 한계를 0.05, 0.01 등으로 사전에 엄격히 고정.
4. 양측 검정(Two-tailed)과 단측 검정(One-tailed)의 방향성 구분.
5. 검정통계량(z, t, F)과 p-값 기반의 기각 여부 판정.

## Ⅲ. 가설검정의 구조 (흐름)

- 핵심 요약 : 가설 설정부터 의사결정까지의 표준 5단계 절차.
- 가설검정 표준 5단계 절차.

```text
[ 가설검정 프레임워크 ]
[Step 1: 가설 설정]     ---> H0: 효과 없음 vs H1: 효과 있음 (양측/단측)
           |
[Step 2: 유의수준 설정] ---> alpha = 0.05 (5%) 또는 0.01 (1%)
           |
[Step 3: 검정통계량 계산] -> z-통계량, t-통계량, F-통계량 산출
           |
[Step 4: 기각역 및 p-값]  -> p-value 산출 (귀무가설 하에서 관측값 이상이 나올 확률)
           |
[Step 5: 의사결정]       -> p-value < alpha 이면 H0 기각 (통계적 유의성 확보)
```

- 양측 검정 : $H_1: \mu \neq \mu_0$ (차이의 존재 여부만 확인, 양쪽 꼬리에 각 $\alpha/2$ 배정).
- 단측 검정 : $H_1: \mu > \mu_0$ (우측 단측) 또는 $H_1: \mu < \mu_0$ (좌측 단측, 방향성이 명확할 때 사용).

## Ⅳ. 오류 유형의 비교

- 핵심 요약 : 제1종 오류($\alpha$)와 제2종 오류($\beta$)의 상충 관계와 검정력($1-\beta$) 확보 기준.

```text
[ 1종 오류 vs 2종 오류 매트릭스 ]
                       실제 H0가 참(효과 없음)      실제 H0가 거짓(효과 있음)
  H0 채택 (차이 없음) : 올바른 결정 (1 - alpha)    2종 오류 beta (위음성, False Negative)
  H0 기각 (차이 있음) : 1종 오류 alpha (위양성)    올바른 결정 1 - beta (검정력, Power)
```

| 구분 | 개념 및 기호 | 비즈니스 사례 | 제어 및 상충 관계 |
| :--- | :--- | :--- | :--- |
| 제1종 오류 (Type Ⅰ) | 효과가 없는데 효과가 있다고 잘못 판단하는 오류 ($\alpha$, 생산자 위험) | 아무 효과 없는 신약의 치료 효과 승인 | 유의수준 $\alpha$를 0.05, 0.01로 사전 엄격 고정하여 통제 |
| 제2종 오류 (Type Ⅱ) | 효과가 있는데 효과가 없다고 잘못 기각하지 못하는 오류 ($\beta$, 소비자 위험) | 실제 사기 거래의 정상 거래 오판 및 미탐 | 표본 크기 $n$ 증가를 통한 $\alpha$ 악화 없는 $\beta$ 축소 |
| 통계적 검정력 (Power) | 대립가설이 참일 때 귀무가설을 올바르게 기각할 확률 ($1 - \beta$) | A/B 테스트에서 실제 개선 효과의 감지 확률 | 통상 80%($0.80$) 이상 목표의 샘플 크기 사전 산정 |

## Ⅴ. 가설검정의 장점과 한계

- 핵심 요약 : 객관적 판정 기준 제공의 장점과 p-해킹·다중 검정·조기 종료 왜곡의 한계 공존.
- 장점
  1. 우연과 실제 효과의 구분을 통한 객관적 의사결정 근거 제공.
  2. 오류 유형·검정력의 사전 설계를 통한 실험 신뢰성 확보.
- 한계점 1 : 빅데이터 환경의 p-value 과민성 및 p-해킹(p-hacking)
  - 한계점 : 표본 수($n$)가 수십만 건 이상일 경우 표준오차의 극단적 축소로 비즈니스적으로 무의미한 미세 차이도 $p < 0.05$ 판정의 통계적 착시 발생.
  - 해결 방안 : $p$-value 맹신 탈피, 효과 크기(Cohen's d, Relative Lift)와 신뢰구간(Confidence Interval)의 필수 병기, 최소 감지 효과 크기(MDE, Minimum Detectable Effect) 사전 설정.
- 한계점 2 : 다중 가설 검정(Multiple Testing) 시 제1종 오류의 누적 팽창
  - 한계점 : 수십 개의 지표 또는 A/B/C/D 다중 그룹 동시 검정 시 패밀리별 오류율(FWER, Family-Wise Error Rate) 급증, 위양성(False Positive) 결론 채택 위험.
  - 해결 방안 : 본페로니(Bonferroni) 교정 또는 허위발견율(FDR, False Discovery Rate, Benjamini-Hochberg) 절차 적용을 통한 유의수준 임계치의 보수적 재조정.
- 한계점 3 : 조기 종료(Peeking Problem)에 따른 A/B 테스트 신뢰도 왜곡
  - 한계점 : 테스트 진행 중 실시간 결과의 반복 확인 후 유의한 순간 조기 종료 시 실제보다 유의확률의 큰 왜곡 발생.
  - 해결 방안 : 고정 표본 크기 사전 산정 준수, 순차적 검정(Sequential Testing, mSPRT, mixture Sequential Probability Ratio Test) 및 멀티암드 밴딧(Multi-Armed Bandit) 알고리즘 도입.

## Ⅵ. 가설검정에 대한 기술사적 제언

- 핵심 요약 : 효과 크기 병기와 사전 검정력 분석의 실험 표준화.
- $p$-value 해킹 및 오용 방지 : $p$-value는 가설이 참일 확률이 아니며 표본 크기 $n$이 수십만 건 이상이면 비즈니스적으로 무의미한 극미한 차이도 $p < 0.001$로 유의 도출 가능, $p$-value 단독 판정 지양 및 효과 크기(Effect Size, Cohen's d)와 신뢰구간(CI, Confidence Interval) 병기 필수.
- 사전 검정력 분석(Power Analysis) 수행 : A/B 테스트 기획 시 기대 최소 감지 효과(MDE), 유의수준 $\alpha=0.05$, 목표 검정력 80%를 충족하는 최소 표본 크기의 사전 수학적 계산을 통한 자원 낭비 방지.
