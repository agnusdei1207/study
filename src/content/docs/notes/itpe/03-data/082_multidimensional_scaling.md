## 연관 키워드

MDS, 계량적 MDS, 비계량적 MDS, 스트레스, PCoA, 포지셔닝 맵, t-SNE, UMAP, Landmark MDS, Property Fitting

## Ⅰ. 다차원 척도법의 개요

- 핵심 요약 : 객체 간 유사도나 비유사도를 저차원 좌표로 옮겨 관계를 시각화하는 기법.
- 개념 : 객체 사이의 거리나 순위 정보를 입력받아 2차원이나 3차원 공간에 배치하는 기법 (**다차원 척도법**, Multidimensional Scaling, MDS).
- 배경 및 필요성 : 브랜드나 제품 간 심리적 거리를 설문으로 얻어도 고차원 자료는 사람이 직접 해석하기 어려우므로, 관계를 공간 좌표로 바꿔 보여 주는 변환이 필요함.
- 주요 목적 : 고차원 객체 관계를 2차원 또는 3차원 지도 형태로 표현.
- 특징 : 입력 척도에 따른 두 유형과 적합도 평가 지표를 갖춘 기법.

## Ⅱ. 다차원 척도법의 특징 및 장점

- 핵심 요약 : 차원 축소, 포지셔닝 맵, 유연한 입력이 맞물려 소비자가 인지하는 구조를 직관적으로 드러내는 방식.

1. **차원 축소** : 고차원 거리 관계를 2차원 또는 3차원으로 옮김 → 객체 간 유사도를 한눈에 확인.
2. **포지셔닝 맵** (Perceptual Map) : 소비자가 인지하는 브랜드나 제품의 상대 위치를 평면에 표시 → 경쟁 구도와 비어 있는 공간 파악.
3. 유연한 입력 : 실측 거리 행렬뿐 아니라 순위 데이터도 입력으로 사용 → 설문 자료의 형태에 맞춰 적용.
4. 해석 보조 : Property Fitting으로 속성 벡터를 맵에 겹쳐 축에 의미를 부여 → 추상적인 좌표를 비즈니스 속성과 연결.
5. 변형 기법 : 고전적 척도법, 비계량 척도법과 함께 **랜드마크 MDS** (Landmark MDS, 일부 대표 객체를 먼저 배치하고 나머지를 투영하는 방식) → 자료 규모에 맞춰 고를 수 있음.

## Ⅲ. 유형과 적합도 평가 흐름

- 핵심 요약 : 입력 척도에 따라 두 유형이 나뉘고, 저차원 배치가 원래 거리를 얼마나 보존하는지는 스트레스 값으로 평가함.
- 유형 : **계량적 MDS** (Metric MDS, 수치 거리 입력)와 **비계량적 MDS** (Non-metric MDS, 순위 입력).
- 스트레스 : **스트레스** (Stress, 원래 거리와 배치 거리의 차이를 정규화한 적합도 지표)은 $\sqrt{\sum(d_{ij}-\hat d_{ij})^2 / \sum d_{ij}^2}$로 계산함.
- 판정 기준 (Kruskal 관례) : 0.05 이하 우수, 0.05~0.10 양호, 0.10~0.20 보통, 0.20 초과 불량.

```text
[ 계량적 vs 비계량적 MDS ]

계량적 : 수치 거리 입력 → 고유값 분해
비계량적 : 순위 입력 → 스트레스 최소화 반복
```

```text
[ MDS 적합도 평가 흐름 ]

거리 행렬 입력
      ↓
저차원 좌표 배치
      ↓
원래 거리와 배치 거리 비교
      ↓
스트레스 값 산출 → 기준 판정
```

## Ⅳ. 계량적 vs 비계량적 비교

- 핵심 요약 : 입력 척도가 다르므로 적합 원리와 해법도 달라지며, 자료의 측정 수준에 맞는 유형을 고르는 것이 기본임.
- 해법 : 계량적 MDS는 **PCoA** (Principal Coordinates Analysis, 주좌표 분석)처럼 고유값 분해로 좌표를 구하고, 비계량적 MDS는 스트레스를 줄이는 반복 최적화로 좌표를 구함.

| 항목 | 계량적 MDS | 비계량적 MDS |
| --- | --- | --- |
| 입력 척도 | 구간, 비율 등 수치 | 순서(서열) 정보 |
| 적합 원리 | 배치 거리가 원래 거리를 근사 | 순위 순서를 단조롭게 보존 |
| 해법 | 고유값 분해 | 스트레스 최소화 반복 |
| 적용 사례 | 도시 간 실제 거리 | 브랜드 선호 순위 |

## Ⅴ. 한계와 방안

- 핵심 요약 : 계산 복잡도, 국소 최적해, 축 해석의 한계를 랜드마크 방식, 초기값 설정, 속성 적합으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 계산 복잡도 | 객체 수가 수만 건을 넘으면 거리 행렬 연산과 메모리 사용이 급증 | 랜드마크 MDS를 적용하고, 대량 시각화에는 **t-SNE** (t-distributed Stochastic Neighbor Embedding)나 **UMAP** (Uniform Manifold Approximation and Projection) 검토 | 연산 시간, 메모리 사용량 |
| 국소 최적해 | 초기 배치에 민감해 왜곡된 맵이 나올 수 있음 | 고전적 척도법 결과를 초기값으로 쓰고 여러 번 실행해 비교 | 스트레스 값 |
| 축 의미 해석 한계 | 추상 공간의 축이 비즈니스 의미를 갖지 않음 | Property Fitting으로 속성 벡터를 겹쳐 축에 의미 부여 | 해석 가능성 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : 축의 의미 부여, 대규모 자료의 기법 선택, 맵에 대한 검증 절차를 갖춰야 맵이 의사결정 근거가 됨.

1. 축 명명 : 좌표 축은 도메인 전문가가 속성을 보고 의미를 붙여야 의사결정에 쓸 수 있으므로, 결과 해석을 분석가 단독이 아닌 현업과 함께 진행한다.
2. 기법 선택 기준 : 객체 수가 일정 규모를 넘는 경우 어떤 기법으로 바꿀지를 사전에 기준으로 정해 두어, 분석 중 임의로 결정하지 않도록 한다.
3. 결과 검증 : 맵을 보고 결론을 내리기 전에 스트레스 값과 원 데이터의 실제 순위를 함께 검토해, 시각적 착시로 관계를 과장하지 않도록 한다.

## Ⅶ. 결론

- 핵심 요약 : 다차원 척도법은 객체 간 유사도를 저차원 맵으로 옮겨 보여 주는 기법으로, 스트레스 값과 축 해석이 결과의 신뢰도를 좌우함.
- 시사점 : 맵은 관계를 직관적으로 보여 주는 도구이므로, 적합도 지표로 신뢰도를 검증하고 의미를 붙인 뒤에 의사결정에 쓰는 것이 바람직함.
