## 30초 인출

- 본질: 음성데이터 마이닝은 음성 신호와 발화 내용을 분석해 업무 정보를 추출하는 활동
- 메커니즘: 상담 음성에서 잡음을 처리한 뒤 ASR 전사, 화자별 발화 구간, 음향 특징을 만들어 시점·화자 기준으로 결합하고 검색·요약·분류 후보를 현업이 확인
- 통찰: 전사·화자 분리 오류가 검색·요약·분류로 전파되고 감정·의도는 모델의 추정일 뿐이므로 결과에 신뢰도와 검수 상태를 표시하고 중요한 판단은 상담원이 확인·정정

- **ASR(Automatic Speech Recognition)** : 발화를 문자로 변환하는 음성인식
- **WER·CER** : 단어·문자 오류율

- **음향 특징** : 음높이·강도·운율 등 신호 특성
- **컨택센터** : 고객 상담을 처리하는 조직·시스템

## 2~4교시 25점 답안

## Ⅰ. 음성데이터 마이닝의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **음성데이터 마이닝** 은 음성 신호와 발화 내용을 분석해 업무 정보를 추출하는 활동 |
| 목적 | 비정형 음성에서 검색·분류·상담 지원에 필요한 정보 도출 |

## Ⅱ. 특징

| 특징 | 분석상 의미 |
|---|---|
| 다중 정보원 | 발화 내용·화자 구간·음향 신호가 서로 다른 근거 제공 |
| 연속 처리의 오류 전파 | 전사·화자 분리 오류가 후속 결과로 이어짐 |
| 추정 결과의 불확실성 | 감정·의도는 모델 추정이며 실제 상태를 확정하지 않음 |

## Ⅲ. 분석 흐름과 오류 전파

```text
상담 음성 → 잡음·구간 처리 ┬→ ASR 전사 텍스트
                          ├→ 화자별 발화 구간
                          └→ 음향 특징
              시점·화자 기준 결합 → 검색·요약·분류 후보 → 현업 확인
```

```text
도메인 용어·중첩 발화 → ASR 오인식 → 검색·요약·분류 근거 왜곡
   ↓ 신뢰도·WER·도메인 표본 확인
낮음 → 원음 검수·전사 정정 / 수용 → 상담원 보조 정보로 제공
```

전사 텍스트만으로는 억양·감정 같은 비언어적 맥락을 완전히 보존하지 못함.

## Ⅳ. 분석 기능과 컨택센터 활용

| 기능 | 처리 | 검증 |
|---|---|---|
| 음성인식 | 발화를 문자로 변환 | WER/CER, 도메인 용어 전사 검수 |
| 화자 분리 | 발화 구간에 화자 식별자 부여 | 중첩·짧은 발화 오류 확인 |
| 음향 분석 | 음높이·강도·운율 추출 | 장비·환경·개인차 고려 |
| 언어 분석 | 전사의 주제·의도·요약 | 라벨 정의·표본 검토·현업 확인 |

| 업무 단계 | 적용 | 통제 |
|---|---|---|
| 상담 중 | 지식 검색·상담원 보조 | 지연·오답 시 상담원 확인 경로 |
| 상담 후 | 요약·분류·후속업무 생성 | 전사 오류·자동 생성 내용 검수 |
| 운영 분석 | 반복 문의·품질 이슈 집계 | 편향·표본성·평가 기준 점검 |
| 데이터 관리 | 녹음·전사·결과 저장 | 목적·접근권한·보존기간 관리 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 자동 전사·감정 분류를 사실로 취급해 오류가 상담 평가로 전파 | 신뢰도·검수 상태 표시, 중요한 판단은 상담원 확인·정정 |
| 화자 분리 오류로 발화가 뒤섞임 | 중첩·짧은 발화 표본 별도 검수, 수정 이력 보존 |
| 원음과 파생 결과의 접근·보존 범위 불일치 | 원음·전사·파생 결과의 목적·권한·보존기간 함께 정의 |

## Ⅵ. 제언

자동 분석 결과는 신뢰도와 함께 상담원 보조로 사용하고, 원음·전사·파생 결과를 같은 정책으로 관리

```text
음성 → 전사·화자·음향 → 신뢰도 표시 → 상담원 확인 → 정정 이력 → 정책 기반 보관
```

| 구분 | 자동 결과를 사실로 사용 | 제언: 신뢰도 표시 + 확인 |
|---|---|---|
| 오류 전파 | 평가로 확산 | 확인·정정 |
| 개인정보 | 범위 불일치 | 원음·전사 동일 정책 |
