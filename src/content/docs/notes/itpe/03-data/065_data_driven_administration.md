## 연관 키워드
- 공공 소프트웨어 사업, 발주·수행, 과업심의, 요구 사항, 검증, 법령 현행성

## Ⅰ. 공공 소프트웨어 사업관리 지침의 개요

- 핵심 요약 : 공공 기관 정보화 사업의 기획·발주·수행·검수 과정에서 법령과 절차 준수를 돕는 관리 기준.
- 개념 : 국가계약 및 소프트웨어 관련 법령·고시와 기관 절차에 따라 사업 범위, 계약, 품질, 변경을 통제하는 활동(**공공 소프트웨어 사업관리**, Public Software Project Management).
- 배경 및 필요성 : 공공 사업의 예산·책임·서비스 연속성·공정성 요구에 따른 전 과정 추적 가능 의사결정 필요.
- 주요 목적 : 적정한 과업·계약 관리와 품질 확보, 공정한 사업 수행과 공공서비스 성과 달성.

## Ⅱ. 데이터기반행정의 특징 및 장점

- 핵심 요약 : 4대 추진 영역인 칸막이 해소, 분석 연계, 인프라, 역량을 함께 추진하는 구조.

1. 공공데이터 공동활용 : 기관 간 칸막이를 해소하고 메타데이터 등록을 의무화 → 데이터 접근성 향상.
2. 데이터 분석과 정책 연계 : 복지 사각지대 발굴, 재난 예측, 교통 최적화에 분석 결과를 반영 → 정책 정확도 향상.
3. 인프라 확충 : 통합 분석 플랫폼과 데이터 안심구역(민감 데이터를 통제된 환경에서 분석하는 공간) 운영 → 공공과 민간 데이터 융합 기반 마련.
4. 역량과 문화 조성 : 데이터 리터러시(Data Literacy, 데이터를 읽고 해석해 활용하는 능력)를 교육하고 실태 평가와 인센티브를 연계 → 조직 내 데이터 문화 정착.

## Ⅲ. 데이터기반행정의 거버넌스 및 추진 흐름

- 핵심 요약 : 범정부 분석 센터의 지원 아래 개별 기관이 과제를 발굴하는 계층 거버넌스.
- CDO(Chief Data Officer, 기관의 데이터 정책과 활용을 총괄하는 책임자) : 기관별 지정을 통해 공동활용 데이터 등록과 정책 과제 발굴을 책임짐.

```text
[ 데이터기반행정 추진 체계 ]

[기본계획 수립·실태 점검]
          ↓
[정부통합데이터분석센터]
  범정부 분석·활용 지원
          ↓
[개별 공공기관 (중앙부처·지자체)]
  CDO 지정, 데이터 등록, 과제 발굴
```

```text
[ 정책 피드백 루프 ]

데이터 수집
   ↓
정제·표준화
   ↓
분석·모델링
   ↓
정책 집행 (API 연동)
   ↓
효과 측정
   ↓
다시 수집 (재입력)
```

## Ⅳ. 추진 영역의 비교

- 핵심 요약 : 4대 추진 영역의 주요 과제와 기대 효과를 비교.

| 영역 | 주요 과제 | 기대 효과 |
|---|---|---|
| 공공데이터 공동활용 | 칸막이 해소, 메타데이터 등록 | 데이터 접근성 향상 |
| 데이터 분석·정책 연계 | 복지·재난·교통 분석 | 정책 정확도 향상 |
| 인프라 확충 | 통합 분석 플랫폼, 데이터 안심구역 | 공공과 민간 데이터 융합 기반 마련 |
| 역량·문화 조성 | 데이터 리터러시 교육, 실태 평가 | 조직 내 데이터 문화 정착 |

## Ⅴ. 데이터기반행정의 한계와 방안

- 핵심 요약 : 칸막이, 비표준화, 역량 부족 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 데이터 칸막이 | 기관 이기주의와 법적 제한으로 데이터 공유 제한 | 법률 개정으로 의무 공유 확대, 메타데이터 등록 의무화 | 공유 데이터 수 |
| 비표준화·품질 저하 | 상이한 코드 체계, 결측치, 비정형 텍스트 | 표준용어 사전 운영, 데이터 품질 인증, 프로파일링 | 품질 인증 비율 |
| 역량 부족 | 순환보직, 분석 전문성 부재 | 전문직렬 신설, 노코드 BI(Business Intelligence, 비전문가도 데이터 분석을 쉽게 할 수 있게 하는 도구) 활용, 데이터 리터러시 교육 | 교육 이수율 |

## Ⅵ. 데이터기반행정에 대한 기술사적 제언

- 핵심 요약 : 적극행정 면책, 피드백 루프, 외부 연동을 통한 정책 실행력 강화 방향.
- 기관별 **CDO** (Chief Data Officer, 최고데이터책임자) 지정, 공동활용 데이터 등록과 정책 과제 발굴 책임 부여.

1. 적극행정 면책(데이터 활용 과정에서 법정 절차를 준수한 공무원의 책임을 면제하는 제도) 정착, 가명정보 결합 등 데이터 활용 위축 방지.
2. 분석 모델 결과의 행정정보시스템 **API** (Application Programming Interface, 응용 프로그래밍 인터페이스) 연동, 정책 집행 결과의 분석 환류 피드백 루프 구축.
3. 민간·공공 데이터 융합 환경의 데이터 안심구역 중심 확장, 정책 과제 범위 확대.

## Ⅶ. 결론

- 핵심 요약 : 데이터기반행정은 과학적 근거 기반 정책 운영 체계이며, 칸막이 해소·표준화·역량 확보가 핵심.
- 시사점 : 4대 추진 영역, 거버넌스, 한계와 대응의 통합 설계 시 행정 전반 데이터 활용의 지속 가능.
