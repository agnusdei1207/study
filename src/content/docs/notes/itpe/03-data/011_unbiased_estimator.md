## 지식 로드맵 내 현재 위치

```text
데이터 분석 → 통계 기초 → 불편추정량
```

## 큰 그림과 30초 인출

```text
[모집단 모수 θ] ← 표본 X1...Xn → [추정량 θ̂]
                                  │
                 E(θ̂)=θ ─────────┤ 불편성
                 Var(θ̂) 최소 ────┤ 효율성
                 θ̂→θ (n→∞) ─────┤ 일치성
                 정보 손실 최소 ─┘ 충분성
```

- 본질: **반복 표본추출에서 추정량의 평균이 참 모수와 일치하여 체계적 오차가 없는 성질**
- 암기: `불-효-일-충` = 불편성 → 효율성 → 일치성 → 충분성
- 주의: 불편성만으로 최선의 추정량이 되지는 않으며 분산과 MSE도 함께 판단

## 예상문제

> 불편추정량의 개념과 바람직한 추정량의 조건을 설명하고, 표본분산의 자유도 보정과 편향-분산 절충을 논하시오. (25점)

## Ⅰ. 체계적 추정 오차가 없는 불편추정량 개요

- 정의: 추정량 $\hat{\theta}$에 대해 $E(\hat{\theta})=\theta$를 만족하면 모수 $\theta$의 불편추정량
- 편향: $Bias(\hat{\theta})=E(\hat{\theta})-\theta$이며 불편추정량은 편향이 0
- 필요성: 표본마다 값은 변해도 장기적으로 특정 방향에 치우치지 않는 추론 기준 제공

## Ⅱ. 추정량을 평가하는 4대 조건

| 조건 | 판단 기준 | 의미 |
|---|---|---|
| **불편성** | $E(\hat{\theta})=\theta$ | 체계적 오차 없음 |
| **효율성** | 불편추정량 중 분산 최소 | 표본 변동 억제 |
| **일치성** | $\hat{\theta}\xrightarrow{p}\theta$ | 표본 증가 시 참값 수렴 |
| **충분성** | 모수 정보를 충분통계량에 보존 | 정보 손실 최소화 |

## Ⅲ. 표본평균과 표본분산의 불편성

```text
표본평균: X̄ = ΣXi/n              → E(X̄)=μ
표본분산: s² = Σ(Xi-X̄)²/(n-1)   → E(s²)=σ²
```

- 표본평균은 모집단 평균의 불편추정량
- 표본평균으로 편차를 계산하면 $\sum(X_i-\bar X)=0$ 제약으로 자유도 하나를 소모
- 분모 $n$의 분산 과소추정을 $n-1$의 Bessel 보정으로 교정

## Ⅳ. 불편성 검증 절차

```text
① 모수·표본모형 → ② 추정량 수식 → ③ 기댓값 전개
 → ④ E(θ̂)-θ 계산 → ⑤ 분산·MSE·일치성 비교
```

| 단계 | 확인 내용 | 산출물 |
|---|---|---|
| 모형 정의 | 분포·독립성·표본추출 가정 | 확률모형 |
| 기댓값 계산 | 선형성·분포 성질 적용 | 편향 식 |
| 성능 비교 | $MSE=Var+Bias^2$ | 추정량 선택 근거 |

## Ⅴ. 불편추정량과 편향추정량 비교

| 구분 | 불편추정량 | 편향추정량 |
|---|---|---|
| 중심 | 기대값이 참값과 일치 | 기대값이 참값과 차이 |
| 장점 | 해석 명확 | 더 작은 분산·MSE 가능 |
| 한계 | 분산이 클 수 있음 | 편향 원인·크기 설명 필요 |
| 적용 | 고전적 모수 추론 | 규제·수축 추정, 예측 최적화 |

## Ⅵ. MSE 기반 실무 고려사항

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 소표본 추정 불안정 | 불편하지만 분산이 큼 | 신뢰구간·Bootstrap·표본 확대 | 불확실성 가시화 |
| 불편성만 최적화 | 예측오차를 무시 | 편향·분산·MSE 동시 비교 | 총오차 최소화 |
| 가정 위반 | 비독립·표본선택 편향 | 표본설계 검토, 강건 추정 | 추론 타당성 확보 |
| 자유도 오용 | 추정 모수 수 미반영 | 잔차 자유도 명시 | 분산 과소평가 방지 |

## Ⅶ. 편향과 변동을 함께 관리하는 결론

- 불편성은 좋은 추정량의 출발점이며 효율성·일치성·충분성과 함께 평가해야 함
- 추정 목적과 오류비용에 따라 작은 편향을 허용하고 더 낮은 MSE를 선택할 수 있음

## 1교시 10점 답안 발췌

```text
E(θ̂)=θ → Bias=0
좋은 추정량: 불편성 · 효율성 · 일치성 · 충분성
표본분산: 자유도 1 소모 → n-1 보정
```

| 판단축 | 핵심 |
|---|---|
| 중심성 | 기대값과 참 모수 일치 |
| 변동성 | 불편추정량 중 작은 분산 |
| 총오차 | $MSE=Var+Bias^2$로 판단 |
