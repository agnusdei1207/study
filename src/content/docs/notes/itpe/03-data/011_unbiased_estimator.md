## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **불편추정량**

## 30초 인출

- 본질: 불편추정량은 표본에서 모수를 추정하는 통계량 중 기댓값이 모수와 같아 평균적으로 치우치지 않는 추정량
- 메커니즘: 표본을 반복해서 뽑았을 때 추정값의 평균이 모수와 일치하며, 표본평균은 모평균의, n−1로 나눈 표본분산은 모분산의 불편추정량
- 통찰: 불편성만으로 좋은 추정량은 아니고 분산이 크면 한 번의 추정이 멀리 벗어나므로 편향과 분산을 함께 보는 평균제곱오차(MSE)로 추정량을 비교

<details>
<summary>핵심 용어</summary>

- **모수(Parameter)** : 모집단의 평균·분산처럼 추정 대상이 되는 값
- **추정량(Estimator)** : 표본으로 모수를 계산하는 규칙
- **불편성(Unbiasedness)** : 추정량의 기댓값이 모수와 같은 성질. E[θ̂] = θ
- **편향(Bias)** : 추정량의 기댓값과 모수의 차이. E[θ̂] − θ
- **표본분산(n−1)** : 편차 제곱합을 n−1로 나눠 모분산에 대해 불편성을 갖게 한 추정량
- **MSE(평균제곱오차)** : 편향의 제곱과 분산을 합친 추정 오차 지표

</details>

## 2~4교시 25점 답안

## Ⅰ. 불편추정량의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **불편추정량** 은 기댓값이 모수와 같은 추정량 |
| 목적 | 평균적으로 치우치지 않는 모수 추정 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 평균적 정확성 | 반복 추정의 평균이 모수와 일치 |
| 개별 추정의 변동 | 한 번의 추정값은 모수와 다를 수 있음 |
| 추정량마다 다름 | 표본평균은 불편, 분모를 n으로 한 분산은 편향 |

## Ⅲ. 불편성의 확인

```text
표본분산 S² = Σ(xᵢ − x̄)² / (n − 1)     → E[S²] = σ²  (불편)
분모가 n인 분산 = Σ(xᵢ − x̄)² / n        → E = ((n−1)/n)·σ²  (작게 추정, 편향)
```

## Ⅳ. 편향과 분산의 관계

| 구분 | 불편추정량 | 편향이 있는 추정량 |
|---|---|---|
| 기댓값 | 모수와 같음 | 모수와 다름 |
| 분산 | 클 수 있음 | 작을 수 있음 |
| 비교 기준 | MSE = 편향² + 분산 | 동일 |

편향이 조금 있어도 분산이 훨씬 작으면 MSE가 더 작을 수 있음(예: 릿지 회귀)

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 불편이지만 분산이 커서 추정이 불안정 | MSE로 비교하고 표본 크기를 늘림 |
| 분산 추정에 n을 쓰면 과소 추정 | 표본분산은 n−1로 나눔 |
| 편향의 존재를 확인하지 않고 사용 | 추정량의 기댓값을 이론·시뮬레이션으로 점검 |

## Ⅵ. 제언

추정량을 고를 때 불편성 여부와 분산을 함께 확인해 MSE가 작은 것을 선택

```text
후보 추정량 → 편향 확인 · 분산 확인 → MSE 비교 → 선택
```

| 구분 | 불편성만 기준 | 제언: MSE 기준 |
|---|---|---|
| 고려 요소 | 편향 | 편향과 분산 |
| 추정 안정성 | 확인 어려움 | 반영 |
