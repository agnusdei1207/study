자료처리·데이터 → 데이터 마이닝 → **K-평균 군집화(K-Means)**

## 30초 인출

- 본질: K-Means는 정한 k개의 중심에 가까운 데이터를 배정하고 중심을 반복 갱신해 군집을 찾는 분할 군집 방법
- 메커니즘: 초기 중심을 정한 뒤 점을 가장 가까운 중심에 배정하고 군집 평균으로 중심을 이동하는 과정을 배정이 바뀌지 않을 때까지 반복
- 통찰: 초기 중심·k·변수 단위·이상치에 결과가 좌우되므로 표준화하고 K-Means++와 반복 실행으로 초기값 영향을 줄이며 엘보우·실루엣과 업무 해석으로 k를 검증

<details>
<summary>핵심 용어</summary>

- **K-Means** : k개 중심 기반으로 군집을 형성하는 분할 군집 방법
- **중심(Centroid)** : 군집에 속한 점들의 평균 위치
- **WCSS** : 각 점과 소속 중심 사이 거리 제곱의 합(군집 내 제곱합)
- **엘보우 방법** : k 증가에 따른 WCSS 감소가 완만해지는 지점을 찾는 방법
- **실루엣 계수** : 군집 내 응집과 군집 간 분리 정도를 나타내는 지표
- **K-Means++** : 초기 중심을 서로 멀리 떨어지도록 확률적으로 고르는 초기화 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. K-Means의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **K-Means** 는 정한 k개 중심에 가까운 데이터를 배정하고 중심을 반복 갱신해 군집을 찾는 방법 |
| 목적 | 비슷한 관측치를 묶어 데이터의 집단 구조 파악 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 중심 기반 배정 | 각 점을 가장 가까운 중심에 배치 |
| 평균으로 중심 갱신 | 군집 점들의 평균으로 중심 이동 |
| 초기값·척도 민감 | 이상치·단위 차이·초기 중심에 결과가 달라짐 |

## Ⅲ. 반복 원리

```text
초기 중심 k개 선택
   ↓
① 중심 고정 → 각 점을 가장 가까운 중심에 배정
   ↓
② 배정 고정 → 군집 평균으로 중심 이동
   ↓
①·② 반복 → 배정과 중심이 거의 바뀌지 않으면 종료
```

목적은 군집 내 거리 제곱합(WCSS)을 줄이는 것이며 초기값에 따라 서로 다른 국소해에 머물 수 있음.

## Ⅳ. k 선정과 적합성

| 방법 | 확인할 내용 | 한계 |
|---|---|---|
| 엘보우 | k 증가에 따른 WCSS 감소 변화 | 꺾임이 뚜렷하지 않을 수 있음 |
| 실루엣 | 군집 내부 응집·군집 간 분리 | 거리와 자료형에 의존 |
| K-Means++·반복 실행 | 초기값에 따른 결과 변동 | 최적 k를 자동 보장하지 않음 |

| 조건 | 이유 | 대응 |
|---|---|---|
| 변수 단위 차이 | 거리 계산 편향 | 표준화 |
| 극단적 이상치 | 평균 중심 이동 | 원인 확인·영향 비교 |
| 비구형·불균등 밀도 | 중심 기반 배정의 한계 | 밀도·계층 방법 비교 |
| 범주형 변수 | 평균·유클리드 거리의 의미 제한 | 적합한 거리·방법 검토 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| k를 임의로 고정 | 여러 k의 지표·해석·안정성 비교 |
| 초기 중심에 결과 의존 | K-Means++와 여러 번 재실행 |
| 낮은 WCSS만으로 성공 판단 | 군집 특성이 활용 목적과 연결되는지 검토 |

## Ⅵ. 제언

표준화한 데이터에 K-Means++로 초기화해 실행하고, 엘보우·실루엣과 업무 해석으로 k를 검증하며 비구형 분포는 밀도 기반 방법으로 대체

```text
표준화 → K-Means++ 초기화 → 반복 → 엘보우·실루엣·업무 해석 → k 확정
```

| 구분 | 무작위 초기화 K-Means | 제언: K-Means++ + 검증 |
|---|---|---|
| 초기값 민감도 | 국소해 위험 | 완화 |
| k 결정 | 임의 추정 | 지표·해석 교차 확인 |
