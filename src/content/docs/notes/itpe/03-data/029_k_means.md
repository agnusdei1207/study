## Ⅰ. 대표적 분할 군집화 알고리즘, K-Means의 개요

### 가. K-Means 군집화의 정의
- **K-Means**는 주어진 $n$개의 다차원 데이터 포인트를 사전에 정의된 $K$개의 군집(Cluster)으로 분할하되, 각 군집의 중심점(Centroid)과 군집 내 데이터 포인트 간의 거리 제곱합(WCSS, Within-Cluster Sum of Squares)을 최소화하도록 반복적으로 수렴시키는 비지도 학습 알고리즘.
- Lloyd(로이드) 알고리즘에 기반한 기댓값 최대화(EM, Expectation-Maximization)의 휴리스틱 변형.

### 나. 최적화 목적 함수 (Objective Function)
$$J = \sum_{k=1}^K \sum_{x_i \in C_k} \| x_i - \mu_k \|^2$$
($C_k$는 $k$번째 군집, $\mu_k$는 해당 군집의 중심점 벡터).

## Ⅱ. K-Means의 동작 메커니즘 및 4단계 반복 프로세스

### 가. 4단계 반복 사이클

```text
[ K-Means 알고리즘 흐름 ]
[Step 1: 초기화]  ---> K개의 초기 중심점(Centroid) 무작위 선정
       |
[Step 2: 할당(E)] ---> 각 데이터 포인트를 가장 가까운 중심점 군집에 할당
       |
[Step 3: 갱신(M)] ---> 할당된 데이터들의 평균 위치로 군집 중심점 재계산
       |
[Step 4: 수렴 확인] -> 중심점 이동 거리가 임계치 이하(Convergence)이면 종료, 아니면 Step 2 반복
```

### 나. 거리 측정 및 중심점 갱신 수학적 원리
- **할당 단계** : $c^{(i)} = \arg\min_k \| x^{(i)} - \mu_k \|^2$ (유클리디안 최소 거리)
- **갱신 단계** : $\mu_k = \frac{1}{|C_k|} \sum_{i \in C_k} x^{(i)}$ (해당 군집 소속 데이터의 무게중심)

## Ⅲ. K-Means의 한계점 및 개선 알고리즘 비교

### 가. K-Means의 3대 본질적 한계
1. **초기 중심점 의존성** : 초기 중심점이 우연히 몰려 있으면 국소 최적점(Local Minima)에 갇혀 잘못된 군집화 도출.
2. **이상치(Outlier) 민감성** : 평균(Mean)을 사용하므로 극단값 하나가 중심점을 크게 끌어당겨 왜곡 유발.
3. **구형(Spherical) 군집 가정** : 데이터가 도넛 모양, 나선형, 밀도 차이가 큰 비선형 구조일 때 군집화 완전 실패.

### 나. K-Means 확장 및 대안 알고리즘 비교

| 알고리즘 | 개선 원리 및 메커니즘 | 해결하는 한계 | 적용 장점 |
| :--- | :--- | :--- | :--- |
| **K-Means++** | 첫 번째 중심점은 무작위, 이후 중심점은 기존 중심점들과 거리가 먼 데이터일수록 높은 확률($D(x)^2$)로 선택 | 초기값 의존성 극복 | 수렴 속도 대폭 단축, 최적해 도출 확률 극대화 (현재 Scikit-Learn 기본값) |
| **K-Medoids (PAM)** | 군집의 평균(Mean) 대신 군집 내 실제 데이터 포인트인 중앙값(Medoid)을 중심점으로 채택 | 이상치 및 노이즈 민감성 해결 | 이상치에 강건(Robust)하나 계산 비용 $O(n^2)$로 증가 |
| **Mini-Batch K-Means** | 전체 데이터가 아닌 무작위 추출된 작은 배치(Batch) 단위로 중심점을 점진적 업데이트 | 대용량 데이터 메모리 적재 불가 한계 | 수렴 시간 수십 배 단축, 스트리밍 환경 적용 가능 |
| **DBSCAN** | 거리 대신 밀도(Density) 기반으로 군집 연결 | 구형 군집 한계 극복 | 임의의 기하학적 형태 군집화 가능, 노이즈 자동 분리 |

## Ⅳ. K-Means 군집화 실무 적용을 위한 엔지니어링 제언

- **특성 표준화(Feature Scaling)의 선행 의무** : 유클리디안 거리를 사용하므로 단위가 큰 특성(예: 연봉 수천만 원)이 작은 단위 특성(예: 나이 수십 세)을 완전히 압도하여 모델을 지배하므로, 반드시 `StandardScaler`를 파이프라인에 선결합해야 함.
- **최적 $K$ 도출의 정량화** : 비즈니스 도메인의 직관에만 의존하지 말고, 엘보우 포인트(Elbow Method)와 실루엣 점수(Silhouette Score $\ge 0.5$)를 교차 검증하여 안정적인 클러스터 수를 도출할 것을 제언함.
