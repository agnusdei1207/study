## 연관 키워드

- K-평균 군집화(K-Means), 중심점(Centroid), 비지도 학습(Unsupervised Learning), 군집(Cluster)
- 거리 제곱합(WCSS, Within-Cluster Sum of Squares), Lloyd 알고리즘, 엘보우 기법(Elbow Method), 실루엣 계수(Silhouette Coefficient)
- K-Means++, K-Medoids(PAM), Mini-Batch K-Means, DBSCAN(Density-Based Spatial Clustering of Applications with Noise)

## Ⅰ. K-평균 군집화의 개요

- 핵심 요약 : 데이터를 K개 군집으로 나누되 중심점과의 거리 제곱합을 줄이는 비지도 학습 알고리즘.
- 개념 : n개의 다차원 데이터를 사전에 정한 K개의 군집으로 나누고, 각 군집의 **중심점**(Centroid)과 군집 내 데이터 사이 거리 제곱합인 **거리 제곱합**(WCSS, Within-Cluster Sum of Squares)을 줄이도록 반복 수렴시키는 **K-평균 군집화**(K-Means) 알고리즘.
- 배경 및 필요성 : 라벨이 없는 대규모 데이터에서 그룹 구조를 찾아야 하는 요구가 많다. 정답 없이 패턴을 드러내는 방법이 필요하다.
- 주요 목적 : 군집 안의 응집도를 높이고 군집 사이를 분리하여 의미 있는 패턴을 찾는 것.
- 이론적 기반 : Lloyd 알고리즘에 기반한 기댓값 최대화(EM, Expectation-Maximization) 계열의 반복 휴리스틱.
- 목적 함수 :

$$J = \sum_{k=1}^{K} \sum_{x_i \in C_k} \| x_i - \mu_k \|^2$$

(C_k는 k번째 군집, μ_k는 그 군집의 중심점 벡터)

## Ⅱ. K-평균 군집화의 특징

- 핵심 요약 : 할당과 갱신을 번갈아 수행하는 반복 구조가 목적 함수를 단조 감소시키며 수렴하는 원리.

1. 비지도 학습 : 사전 라벨 없이 데이터 자체의 거리 구조만으로 군집을 만듦 → 라벨링 비용 불필요.
2. 교대 반복 : 할당 단계와 갱신 단계를 번갈아 수행 → 거리 제곱합이 줄어드는 방향으로 수렴.
3. 할당 규칙 : 각 점을 가장 가까운 중심점의 군집에 배정(유클리디언 거리 기준) → 군집 경계가 단순하게 결정됨.
4. 갱신 규칙 : 군집에 속한 점들의 평균을 새 중심점으로 계산 → 군집 내부 분산을 줄임.
5. 수렴 판정 : 중심점의 이동 거리가 임계치 이하이면 종료 → 계산량을 제한.

## Ⅲ. K-평균 군집화의 구조 (흐름)

- 핵심 요약 : 초기화, 할당, 갱신, 수렴 확인의 네 단계가 수렴할 때까지 반복되는 사이클.

```text
[ K-Means 반복 사이클 ]
[1 초기화]   K개 초기 중심점 선정
     ↓
[2 할당]     각 점을 가장 가까운 중심점 군집에 배정
     ↓
[3 갱신]     군집별 평균 위치로 중심점 재계산
     ↓
[4 수렴 확인] 중심점 이동이 임계치 이하이면 종료
              아니면 2로 돌아감
```

```text
[ 할당과 갱신의 개념 ]
데이터 : o o o o | x x x x
     ↓ 2 할당 : 최근접 중심점에 배정
군집 1 [● o o o o]    군집 2 [▲ x x x x]
     ↓ 3 갱신 : 소속 점의 평균으로 이동
군집 1 [●' o o o]     군집 2 [▲' x x x]
```

## Ⅳ. K-Means 확장·대안 알고리즘의 비교

- 핵심 요약 : 초기값, 이상치, 대용량, 비구형 형상이라는 문제별로 보완 알고리즘을 고른다.

| 알고리즘 | 개선 원리 | 해결하는 한계 | 적용 장점 |
| --- | --- | --- | --- |
| K-Means++ | 첫 중심점은 무작위, 이후 중심점은 기존 중심점에서 먼 점을 거리 제곱에 비례한 확률로 선택 | 초기값 의존성 | 수렴이 빨라지고 좋은 해를 얻을 확률이 높아짐, scikit-learn의 기본 초기화 방식 |
| K-Medoids(PAM) | 평균 대신 군집 안의 실제 데이터 점인 중앙값(Medoid)을 중심으로 사용 | 이상치와 노이즈에 대한 민감성 | 이상치에 강건하나 계산량이 커짐 |
| Mini-Batch K-Means | 전체 데이터 대신 무작위 소규모 배치로 중심점을 점진 갱신 | 대용량 데이터의 메모리 적재 한계 | 수렴 시간이 크게 줄고 스트리밍 환경에 적용 가능 |
| DBSCAN | 거리 대신 밀도로 군집을 연결 | 구형 군집 가정 | 임의 모양의 군집을 찾고 노이즈를 자동 분리 |

## Ⅴ. K-평균 군집화의 장점과 한계

- 핵심 요약 : 단순하고 빠른 것이 장점이며, 초기값 의존, 이상치 민감성, 구형 군집 가정이 본질적 한계.

- 장점
  1. 알고리즘이 단순하고 수행 속도가 빠름.
  2. Mini-Batch 변형으로 대용량 데이터에도 확장 가능.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 초기 중심점 의존성 | 초기 중심점이 한곳에 몰리면 국소 최적점에 머물러 잘못된 군집 생성 | K-Means++ 확률 기반 초기화 적용, 여러 번 시작하여 최선 결과 선택 | 군집 간 WCSS 변화 |
| 이상치 민감성 | 평균을 쓰기 때문에 극단값 하나가 중심점을 크게 끌어당김 | 중앙값 기반 K-Medoids(PAM) 채택 | 이상치 비율, 군집별 크기 편차 |
| 구형 군집 가정 | 도넛이나 나선 같은 비선형 구조와 밀도 차이가 큰 군집을 잘 나누지 못함 | 밀도 기반 DBSCAN 적용 | 군집 형태 검토 결과 |

## Ⅵ. K-평균 군집화에 대한 기술사적 제언

- 핵심 요약 : 거리 계산 전 특성 표준화를 필수로 하고, 최적 K는 직관이 아닌 지표로 결정.

유클리디언 거리는 단위가 큰 특성이 결과를 지배하므로, 소득과 나이처럼 척도가 다른 변수는 군집 전에 표준화를 적용하는 것을 파이프라인의 기본 단계로 두어야 한다. 표준화를 빼먹으면 군집이 특정 변수의 크기만 반영하게 된다.

K 값은 업무 담당자의 감으로 정하지 말고, 엘보우 기법으로 WCSS 감소율이 꺾이는 지점을 보고 실루엣 계수로 군집의 응집과 분리를 함께 검증하는 방식으로 결정한다. 두 지표가 가리키는 범위가 다르면 업무 해석 가능성을 기준으로 최종 판단한다.

## Ⅶ. 결론

- 핵심 요약 : K-평균은 단순하고 빠르지만 초기값, 이상치, 형상 가정의 한계를 가지므로 목적에 맞는 변형을 고르는 것이 필요.
- 시사점 : 거리 기반 알고리즘의 전제인 표준화와 구형 가정을 점검하는 것이 군집 결과의 신뢰성을 확보하는 선행 조건.
