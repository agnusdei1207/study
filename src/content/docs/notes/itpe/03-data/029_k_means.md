## 연관 키워드

- K-평균 군집화(K-Means), 중심점(Centroid), 비지도 학습(Unsupervised Learning)
- 거리 제곱합(WCSS, Within-Cluster Sum of Squares), Lloyd 알고리즘
- K-Means++, K-Medoids(PAM), Mini-Batch K-Means, DBSCAN

## Ⅰ. K-평균 군집화의 개요

- 핵심 요약 : 데이터를 K개 군집으로 분할하며 중심점과의 거리 제곱합을 최소화하는 비지도 학습 알고리즘.
- 개념 : K-Means는 주어진 $n$개의 다차원 데이터 포인트를 사전 정의된 $K$개의 군집(Cluster)으로 분할하되, 각 군집의 중심점(Centroid)과 군집 내 데이터 포인트 간 거리 제곱합(WCSS, Within-Cluster Sum of Squares)을 최소화하도록 반복 수렴시키는 비지도 학습 알고리즘.
- 배경 및 필요성 : 라벨 없는 대규모 데이터의 그룹 구조 발견 수요.
- 주요 목적 : 군집 내 응집도 극대화와 군집 간 분리를 통한 패턴 도출.
- 이론적 기반 : Lloyd 알고리즘에 기반한 기댓값 최대화(EM, Expectation-Maximization)의 휴리스틱 변형.
- 최적화 목적 함수(Objective Function) :

$$J = \sum_{k=1}^K \sum_{x_i \in C_k} \| x_i - \mu_k \|^2$$

($C_k$는 $k$번째 군집, $\mu_k$는 해당 군집의 중심점 벡터).

## Ⅱ. K-평균 군집화의 특징

- 핵심 요약 : 할당·갱신의 교대 반복과 수학적 원리 기반 수렴이 핵심.

1. 비지도 학습 기반으로 사전 라벨 불필요.
2. 할당(E) 단계와 갱신(M) 단계의 교대 반복으로 수렴.
3. 할당 단계의 유클리디안 최소 거리 기준 : $c^{(i)} = \arg\min_k \| x^{(i)} - \mu_k \|^2$.
4. 갱신 단계의 군집 소속 데이터 무게중심 재계산 : $\mu_k = \frac{1}{|C_k|} \sum_{i \in C_k} x^{(i)}$.
5. 수렴 판정 기준 : 중심점 이동 거리의 임계치 이하 도달.

## Ⅲ. K-평균 군집화의 구조 (흐름)

- 핵심 요약 : 초기화 → 할당 → 갱신 → 수렴 확인의 4단계 반복 사이클.

```text
[ K-Means 4단계 반복 사이클 ]
[Step 1: 초기화]  ---> K개의 초기 중심점(Centroid) 무작위 선정
       |
[Step 2: 할당(E)] ---> 각 데이터 포인트를 가장 가까운 중심점 군집에 할당
       |
[Step 3: 갱신(M)] ---> 할당된 데이터들의 평균 위치로 중심점 재계산
       |
[Step 4: 수렴 확인] -> 중심점 이동 거리 임계치 이하 시 종료, 미달 시 Step 2 반복
```

```text
[ 군집 할당·갱신 개념도 ]
데이터 포인트 :  o o o o  |  x x x x
                     ↓ Step 2: 최근접 중심점 할당
군집 1 [● o o o o]          군집 2 [▲ x x x x]
                     ↓ Step 3: 소속 데이터 평균 위치로 중심점 이동
군집 1 [●' o o o]           군집 2 [▲' x x x]
                     ↓ 이동 거리 < 임계치 → 수렴 종료
```

- 반복 수렴 구조 : 할당과 갱신의 교대 수행으로 WCSS의 단조 감소, 국소 수렴 도달 시 종료.

## Ⅳ. K-Means 확장·대안 알고리즘의 비교

- 핵심 요약 : 초기값·이상치·대용량·비선형 형상 문제별 보완 알고리즘의 선택.

| 알고리즘 | 개선 원리 및 메커니즘 | 해결하는 한계 | 적용 장점 |
| :--- | :--- | :--- | :--- |
| K-Means++ | 첫 중심점 무작위 선정, 이후 중심점은 기존 중심점들과 거리가 먼 데이터의 높은 확률($D(x)^2$) 선택 | 초기값 의존성 극복 | 수렴 속도 대폭 단축, 최적해 도출 확률 극대화(현재 Scikit-Learn 기본값) |
| K-Medoids(PAM, Partitioning Around Medoids) | 평균(Mean) 대신 군집 내 실제 데이터 포인트인 중앙값(Medoid)을 중심점으로 채택 | 이상치·노이즈 민감성 해결 | 이상치에 강건(Robust), 계산 비용 $O(n^2)$ 증가 |
| Mini-Batch K-Means | 전체 데이터가 아닌 무작위 추출 작은 배치(Batch) 단위의 중심점 점진적 업데이트 | 대용량 데이터 메모리 적재 불가 한계 | 수렴 시간 수십 배 단축, 스트리밍 환경 적용 가능 |
| DBSCAN(Density-Based Spatial Clustering of Applications with Noise) | 거리 대신 밀도(Density) 기반 군집 연결 | 구형 군집 한계 극복 | 임의의 기하학적 형태 군집화 가능, 노이즈 자동 분리 |

## Ⅴ. K-평균 군집화의 장점과 한계

- 핵심 요약 : 단순·고속의 장점과 초기값·이상치·형상 가정의 3대 본질적 한계.
- 장점
  1. 알고리즘 구조의 단순성과 빠른 수행 속도.
  2. Mini-Batch 변형 기반 대용량 데이터 확장성.
- 한계점 1 : 초기 중심점 의존성
  - 한계점 : 초기 중심점의 우연한 몰림 시 국소 최적점(Local Minima) 도달, 잘못된 군집화 도출.
  - 해결 방안 : K-Means++의 거리 기반 확률($D(x)^2$) 초기화 적용.
- 한계점 2 : 이상치(Outlier) 민감성
  - 한계점 : 평균(Mean) 사용으로 극단값 하나가 중심점을 크게 끌어당겨 왜곡 유발.
  - 해결 방안 : 군집 내 실제 데이터 포인트인 중앙값(Medoid) 중심의 K-Medoids(PAM) 채택.
- 한계점 3 : 구형(Spherical) 군집 가정
  - 한계점 : 도넛 모양, 나선형, 밀도 차이가 큰 비선형 구조의 군집화 완전 실패.
  - 해결 방안 : 밀도(Density) 기반 DBSCAN 적용.

## Ⅵ. K-평균 군집화에 대한 기술사적 제언

- 핵심 요약 : 특성 표준화 선행과 정량적 최적 K 도출.
- 특성 표준화(Feature Scaling)의 선행 의무 : 유클리디안 거리 특성상 단위가 큰 특성(연봉 수천만 원)이 작은 단위 특성(나이 수십 세)을 압도하여 모델 지배, `StandardScaler`의 파이프라인 선결합.
- 최적 $K$ 도출의 정량화 : 비즈니스 도메인 직관의 편향 지양, 엘보우 포인트(Elbow Method)와 실루엣 점수(Silhouette Score $\ge 0.5$)의 교차 검증을 통한 안정적 클러스터 수 도출.
