## 연관 키워드

- K-평균 군집화(K-Means), 중심점(Centroid), 비지도 학습(Unsupervised Learning)
- 거리 제곱합(WCSS, Within-Cluster Sum of Squares), K-Means++
- 엘보우 기법(Elbow Method), 실루엣 계수(Silhouette Coefficient)
- K-Medoids(PAM, Partitioning Around Medoids), Mini-Batch K-Means

## Ⅰ. K-평균 군집화의 개요

- 핵심 요약 : 라벨 없는 데이터를 k개 군집으로 분할하고, 군집별 평균인 중심점과의 거리 제곱합을 최소화하는 반복 알고리즘.
- 개념 : n개의 데이터를 사전에 정한 k개의 군집으로 분할하고, 군집 내 점들과 그 대표 위치인 **중심점** (Centroid) 사이 거리 제곱의 합인 **거리 제곱합** (WCSS, Within-Cluster Sum of Squares)을 최소화하도록 중심점을 반복 갱신하는 **K-평균 군집화** (K-Means) 알고리즘.
- 배경 및 필요성 : 고객 세분화, 문서 주제 분류처럼 정답 라벨이 없는 데이터에서 그룹 구조 발견 수요가 확대. 전수 라벨링은 비용이 커서 라벨 없이 학습하는 **비지도 학습** (Unsupervised Learning) 접근이 필요.
- 주요 목적 : 군집 내부 응집도의 최대화와 군집 간 분리도의 확보를 통해 데이터의 잠재 구조를 해석 가능한 그룹으로 제시하는 것.
- 이론적 성격 : Lloyd 알고리즘에 기반한 교대 최적화(Alternating Optimization)로, 목적 함수가 감소하는 방향으로 수렴하는 휴리스틱 해법.

## Ⅱ. K-평균 군집화의 특징 및 장점

- 핵심 요약 : 할당과 갱신의 교대 반복 구조가 WCSS의 단조 감소와 고속 수렴이라는 장점으로 연결.

1. 비지도 학습 방식 : 데이터의 거리 구조만으로 군집을 구성 → 라벨링 비용 없이 숨은 그룹의 발견.
2. 교대 최적화 구조 : 할당 단계와 갱신 단계를 번갈아 수행 → 반복마다 WCSS가 감소하는 방향의 수렴 보장.
3. 평균 기반 갱신 : 군집 소속 점들의 좌표 평균이 해당 군집의 WCSS를 최소화하는 해석적 최적 위치 → 단순 평균 계산만으로 중심점 갱신.
4. 선형 계산 복잡도 : 반복마다 점과 k개 중심점 사이 거리만 계산 → 대용량 데이터에서의 실용적 처리 속도.
5. 배치 기반 변형 : 무작위 소규모 배치로 중심점을 갱신하는 **Mini-Batch K-Means** → 스트리밍 환경까지 적용 범위의 확대.

## Ⅲ. K-평균 군집화의 구조 (흐름)

- 핵심 요약 : 초기화, 할당, 갱신, 수렴 판정의 네 단계 사이클이 중심점이 멈출 때까지 반복되는 구조.
- 초기화 : **K-Means++** (확률 기반 초기화 기법) 같은 기법으로 k개 초기 중심점을 선정.
- 할당 단계 : 각 데이터 점을 가장 가까운 중심점의 군집에 배정.
- 갱신 단계 : 군집별 소속 점들의 평균 좌표로 중심점을 재계산.
- 수렴 판정 : 중심점 이동량이 임계치 이하이거나 소속 변화가 없으면 종료.

```text
[ K-Means 반복 사이클 ]
K-Means++ 초기 중심점 선정
   ↓
[할당] 각 점을 최근접 중심점에 배정
   ↓
[갱신] 군집별 평균으로 중심점 이동
   ↓
[판정] 중심점 이동량이 임계치 이하
   ↓ 아니오        ↓ 예
할당 단계 복귀    군집 결과 확정
```

- k 결정 보조 지표 : **엘보우 기법** (Elbow Method)은 WCSS 감소율이 꺾이는 지점을, **실루엣 계수** (Silhouette Coefficient)는 군집의 응집·분리 정도를 나타냄.

```text
[ k 값 결정 절차 ]
k 후보 범위 설정
   ↓
엘보우 기법 : WCSS 감소율 확인
   ↓ 꺾이는 지점을 후보로 확보
실루엣 계수 : 응집·분리 정도 검증
   ↓
업무 해석 가능성으로 최종 선택
```

## Ⅳ. K-Means 초기화·변형 기법의 비교

- 핵심 요약 : 초기 민감성, 이상치, 대용량 문제별로 초기화 기법과 변형 알고리즘을 선택하는 구조.

| 기법 | 적용 지점 | 개선 원리 | 기대 효과 |
| :--- | :--- | :--- | :--- |
| K-Means++ | 초기 중심점 선정 | 첫 중심점은 무작위, 이후는 기존 중심점에서 먼 점을 거리 제곱에 비례한 확률로 선택 | 나쁜 초기값 확률 감소, 수렴 속도 향상 |
| 다중 시드 반복 | 초기화 전체 | 서로 다른 초기값으로 여러 번 수행 후 최저 WCSS 해를 채택 | 국소 최적해 탈출 가능성 확대 |
| K-Medoids(PAM, Partitioning Around Medoids) | 중심 표현 방식 | 평균 대신 군집 안의 실제 점인 Medoid를 대표로 사용 | 이상치 영향의 완화 |
| Mini-Batch K-Means | 갱신 연산 | 무작위 소규모 배치만으로 중심점을 점진 갱신 | 학습 시간 단축, 스트리밍 적용 |

- 선택 기준 :
  1. 실행마다 군집 구성이 달라지는 데이터 : K-Means++ 초기화를 기본값으로 채택.
  2. 극단값이 섞인 데이터 : 평균 대신 Medoid 중심의 K-Medoids 검토.
  3. 실시간·초대용량 데이터 : Mini-Batch K-Means 적용.

## Ⅴ. K-평균 군집화의 한계와 방안

- 핵심 요약 : 초기값 의존, k 사전 지정, 이상치 민감성, 구형 군집 가정을 초기화 기법과 지표 검증으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 초기 중심점 의존 | 무작위 초기값에 따라 국소 최적점에 머물러 실행마다 군집 품질이 달라짐 | K-Means++ 적용과 다중 시드 반복 | 실행 간 WCSS 편차 |
| k 사전 지정 | 최적 군집 수를 사전에 알 수 없어 과소·과대 분할 위험 | 엘보우 기법과 실루엣 계수의 병행 산출 | 실루엣 계수 평균 |
| 이상치 민감성 | 평균이 극단값에 끌려 중심점 위치가 왜곡됨 | 사전 이상치 진단 후 제거, K-Medoids 전환 | 군집별 크기 편차 |
| 구형 군집 가정 | 거리의 등방성 전제로 비구형·밀도 차 구조를 분리하지 못함 | 밀도 기반 군집화로의 전환 검토 | 군집 형태 사후 검증 결과 |

## Ⅵ. K-평균 군집화에 대한 기술사적 제언

- 핵심 요약 : 표준화 전처리, 분석 결과 문서화, 주기적 재학습을 분석 표준 절차로 내재화하는 방향.

1. 데이터 분석 조직 : 척도가 다른 변수 혼재 시 표준화를 전처리 파이프라인의 필수 단계로 지정 → 거리 계산 왜곡의 사전 차단.
2. 데이터 거버넌스 조직 : k 결정 근거와 군집별 프로파일을 군집 분석 보고서로 기록 → 군집 결과 활용 시점의 검증 가능성 확보.
3. 운영 조직 : 데이터 분포 변화에 대응하는 중심점 재학습 주기와 재군집화 승인 절차의 운영 → 군집 결과의 최신성 유지.

## Ⅶ. 결론

- 핵심 요약 : K-평균은 평균 기반 갱신으로 고속 수렴하는 표준 군집 알고리즘.
- 초기값과 k, 척도라는 세 전제의 점검이 군집 결과 신뢰성의 선행 조건.
