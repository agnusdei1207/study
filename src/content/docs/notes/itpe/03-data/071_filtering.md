## 연관 키워드

**추천 시스템**, **협업 필터링**, **콘텐츠 기반**, **하이브리드 추천**, **콜드 스타트**, **후보 생성**, **랭킹**

## Ⅰ. 개요

- 핵심 요약 : **추천 시스템 필터링**은 이용자·아이템 정보를 이용해 대규모 선택지에서 관련 후보를 선별하고 순위를 정하는 과정이다.
- 목적 : 정보 과부하를 줄이고 이용자에게 적합한 아이템을 찾도록 지원한다.
- 입력 : 이용자 상호작용, 아이템 특성, 문맥·업무 규칙 등.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **협업 필터링은 행동 패턴**, **콘텐츠 기반은 아이템 특성**, **하이브리드는 두 정보의 결합**을 활용한다.
- **협업 필터링** : 유사 사용자·아이템 상호작용으로 추천해 아이템의 의미 정보를 적게 요구한다.
- **콘텐츠 기반** : 아이템 설명과 이용자 선호를 비교해 신규 아이템에도 활용할 수 있다.
- **하이브리드** : 여러 신호를 결합해 단일 방식의 빈틈을 보완한다.
- 추천 결과는 정확도뿐 아니라 다양성·신규성·공정성과 이용자 통제를 고려한다.

## Ⅲ. 추천 파이프라인

- 핵심 요약 : **후보 생성 → 랭킹 → 정책·제약 적용 → 노출 → 피드백**의 흐름으로 운영한다.

```text
[이용자·아이템·문맥 정보]
             ▼
[후보 생성: 협업·콘텐츠·인기]
             ▼
[랭킹: 개인화 점수 산출]
             ▼
[정책·다양성·안전 제약 적용]
             ▼
[추천 노출·이용자 반응 수집]
             ▼
[오프라인·온라인 평가·개선]
```

- Two-Tower 모델은 사용자·아이템 표현을 각각 학습해 대규모 후보를 검색하는 데 쓸 수 있다. 모든 추천 서비스에 필요한 구조는 아니다.
- 추천·클릭 로그는 노출 정책의 영향을 받으므로, 관측된 행동을 선호와 동일시하지 않도록 한다.

## Ⅳ. 필터링 방식 비교

- 핵심 요약 : **데이터 가용성·신규성 요구·확장성**을 기준으로 추천 방식을 고른다.

| 방식 | 활용 정보 | 장점 | 한계 |
|---|---|---|---|
| 사용자 기반 협업 | 유사 사용자 행동 | 의외성 있는 발견 가능 | 사용자·아이템 증가 시 유사도 계산 부담 |
| 아이템 기반 협업 | 함께 소비된 아이템 | 아이템 관계 재사용 | 신규 아이템과 희소 상호작용 문제 |
| 잠재요인 모델 | 사용자·아이템 상호작용 행렬 | 숨은 선호 요인 학습 | 잠재 표현 설명과 신규성 한계 |
| 콘텐츠 기반 | 아이템 메타데이터·텍스트 | 신규 아이템에 적용 가능 | 기존 관심 범위에 갇힐 수 있음 |
| 하이브리드 | 여러 신호 결합 | 약점 상호 보완 | 설계·평가 복잡성 증가 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **콜드 스타트·희소성·편향·피드백 루프**를 관리해야 추천 품질이 지속된다.
- **신규 이용자·아이템** → 인기·문맥·콘텐츠 기반 신호를 보완하고 선호 설정 선택권을 제공한다.
- **희소 데이터** → 명시적 평점 외에 신뢰 가능한 상호작용을 사용하고 데이터 품질을 점검한다.
- **인기 편향·노출 편중** → 다양성·신규성 지표와 노출 분포를 감시하고 탐색 정책을 검증한다.
- **피드백 루프** → 추천 노출에 따른 선택 편향을 평가 설계에서 고려한다.

```text
신규·희소 데이터 → 콘텐츠·문맥 신호
노출 편중        → 다양성·탐색 점검   → 유용하고 균형 잡힌 추천
피드백 왜곡      → 노출 조건 포함 평가
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **검색과 랭킹을 분리**하고 정확도·다양성·안전성·사업 성과를 함께 측정한다.
- 오프라인 평가와 온라인 실험의 지표·대상·중단 기준을 사전에 정의한다.
- 민감정보 사용 여부, 이용자 제어, 추천 이유 설명, 신고·숨김 기능을 고려한다.
- 검색 후보와 최종 노출 결과를 기록해 편향과 성능 변화를 진단한다.

## Ⅶ. 결론

- 핵심 요약 : 추천 필터링은 **상호작용·콘텐츠·문맥 신호의 조합**이며, 후보 생성에서 이용자 피드백까지 전 과정을 관리해야 한다.
- 답안에는 협업·콘텐츠·하이브리드의 차이, 콜드 스타트와 인기 편향 대응, 다차원 평가를 연결한다.
