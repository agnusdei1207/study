## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 → **추천 시스템 필터링**

## 30초 인출

- 본질: 추천 필터링은 사용자·항목 정보를 이용해 큰 항목 집합에서 사용자에게 맞는 후보를 골라내는 과정
- 메커니즘: 협업 필터링(유사 행동)과 콘텐츠 기반 필터링(유사 속성)으로 후보를 만들고 관련성 점수를 매긴 뒤 다양성·신선도·정책으로 재순위화해 노출하고 행동 로그로 품질을 평가
- 통찰: 협업은 신규 사용자·항목에서 정보가 부족하고 콘텐츠 기반은 기존 선호에 편중되므로 두 방식을 결합하고, 노출 편향과 다양성을 지표에 포함해 클릭률만 최적화하지 않음

<details>
<summary>핵심 용어</summary>

- **협업 필터링(CF)** : 유사한 사용자·항목의 행동으로 선호를 예측하는 방식
- **콘텐츠 기반 필터링(CBF)** : 항목 속성과 사용자 선호 프로필의 유사도로 추천하는 방식
- **후보 생성·점수화·재순위화** : 평가할 항목을 고르고 / 관련성을 계산하고 / 정책 조건을 반영해 순서를 조정하는 단계
- **콜드 스타트(Cold Start)** : 신규 사용자·항목의 상호작용이 부족한 문제
- **노출 편향** : 이전 노출이 이후 행동 데이터와 추천 결과에 영향을 주는 편향
- **다양성(Diversity)** : 추천 목록의 항목이 서로 다른 정도

</details>

## 2~4교시 25점 답안

## Ⅰ. 추천 시스템 필터링의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **추천 필터링** 은 사용자·항목 정보를 이용해 큰 항목 집합에서 맞는 후보를 고르는 과정 |
| 목적 | 탐색 부담을 줄이고 이용 맥락에 맞는 항목 발견 지원 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 사용자·항목 신호 | 행동 이력 또는 항목 속성을 선호 근거로 사용 |
| 단계적 선별 | 전체에서 후보를 줄인 뒤 점수·정책으로 재정렬 |
| 피드백 편향 | 이전 노출이 다음 행동 데이터와 추천 결과에 영향 |

## Ⅲ. 추천 파이프라인

```text
전체 항목
 ├ 협업: 사용자×항목 행동 → 유사 행동 후보 ─┐
 └ 콘텐츠: 항목 속성·선호 → 유사 속성 후보 ─┤
                                            ↓
                          후보 결합·관련성 점수화 → 다양성·신선도·정책 재순위화 → 노출
                                            ↓
                                  행동 로그로 단계별 품질 평가
```

## Ⅳ. 필터링 방식 비교

| 비교축 | 협업 필터링 | 콘텐츠 기반 필터링 |
|---|---|---|
| 입력 | 평점·조회·구매 등 상호작용 | 항목 속성·사용자 선호 프로필 |
| 원리 | 유사 사용자·항목의 행동 이용 | 선호 항목과 속성이 비슷한 항목 선택 |
| 장점 | 속성 설계 없이 행동으로 관계 학습 | 다른 사용자 기록 없이도 속성 활용 |
| 한계 | 신규 사용자·항목에서 정보 부족 | 기존 선호와 유사한 항목에 편중 |

| 단계 | 역할 | 기준 예 |
|---|---|---|
| 후보 생성 | 평가할 항목 선별 | 유사도·인기·문맥 |
| 점수화 | 후보별 관련성 계산 | 조회·구매 가능성 |
| 재순위화 | 추가 제약 반영 | 중복·신선도·다양성·정책 |

추천 필터링은 후보 선별 과정이며 Bloom Filter는 집합 포함 여부를 근사 판별하는 별도 자료구조.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 신규 사용자·항목의 정보 부족 | 콘텐츠 속성·비개인화 후보로 초기 정보 보완 |
| 과거 기록과 노출 편향 | 후보 출처·노출을 기록하고 다양한 지표로 평가 |
| 개인화로 다양성 감소 | 재순위화에서 중복·다양성 기준 적용 |
| 클릭률만 최적화 | 클릭·장기 이용·다양성 지표를 함께 확인 |

## Ⅵ. 제언

협업과 콘텐츠 기반을 결합해 콜드 스타트를 보완하고 재순위화에서 다양성을 관리

```text
콘텐츠 기반(초기) + 협업(행동 축적 후) → 점수화 → 다양성·정책 재순위화 → 다지표 평가
```

| 구분 | 단일 방식 | 제언: 결합 |
|---|---|---|
| 신규 항목 | 정보 부족 또는 편중 | 상호 보완 |
| 평가 | 클릭률 | 클릭·장기·다양성 |
