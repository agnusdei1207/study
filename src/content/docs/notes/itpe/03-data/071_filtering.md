## Ⅰ. 추천 시스템 필터링의 개요

- 핵심 요약 : 추천 시스템 필터링은 사용자·아이템 특성 및 상호작용으로 후보를 개인화해 선택하는 추천 접근법.
- 개념 : 추천 시스템 필터링은 사용자·아이템 특성 및 상호작용으로 후보를 개인화해 선택하는 추천 접근법.
- 배경 및 필요성 : 대규모 선택지에서 사용자 취향과 맥락에 맞는 항목을 찾는 문제.
- 주요 목적 : 관련성·발견성·사용자 효용을 높이는 개인화 후보 생성.

## Ⅱ. 추천 시스템 필터링의 특징 및 장점

- 핵심 요약 : 협업 필터링: 유사 사용자·아이템 상호작용 활용 → 잠재 취향 포착; 콘텐츠 기반: 아이템 속성·사용자 프로필 매칭 → 신규 아이템 대응; 하이브리드: 신호 결합 → 단일 방법 한계 완화.

1. 협업 필터링: 유사 사용자·아이템 상호작용 활용 → 잠재 취향 포착
2. 콘텐츠 기반: 아이템 속성·사용자 프로필 매칭 → 신규 아이템 대응
3. 하이브리드: 신호 결합 → 단일 방법 한계 완화

## Ⅲ. 추천 시스템 필터링의 구조 (흐름)

- 핵심 요약 : 사용자·아이템·상호작용 수집 → 특징·유사도·잠재요인 학습 → 후보 생성 → 랭킹·업무규칙·안전 필터 → 노출·클릭·장기효용 평가.

```text
사용자·아이템·상호작용 수집
  ↓
특징·유사도·잠재요인 학습
  ↓
후보 생성
  ↓
랭킹·업무규칙·안전 필터
  ↓
노출·클릭·장기효용 평가
```

- 핵심 구성 : 상호작용·콘텐츠 → 후보 생성(협업/콘텐츠) → 랭킹 → 정책필터 → 노출·피드백

```text
상호작용·콘텐츠 → 후보 생성(협업/콘텐츠) → 랭킹 → 정책필터 → 노출·피드백
```

## Ⅳ. 비교: 협업 필터링 / 콘텐츠 기반 필터링

- 핵심 요약 : 콜드스타트 기준 — 협업 필터링: 새 사용자·아이템에 취약; 콘텐츠 기반 필터링: 새 아이템 속성으로 시작 가능.

| 비교 기준 | 협업 필터링 | 콘텐츠 기반 필터링 |
| --- | --- | --- |
| 주요 신호 | 사용자-아이템 행동행렬 | 아이템 메타데이터·사용자 선호 |
| 콜드스타트 | 새 사용자·아이템에 취약 | 새 아이템 속성으로 시작 가능 |
| 편향 위험 | 인기 아이템·노출 데이터 편향 | 특성 품질·프로필 과적합 |

## Ⅴ. 추천 시스템 필터링의 한계와 방안

- 핵심 요약 : 희소성·콜드스타트·인기도 편향 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 희소성·콜드스타트 | 신규·저활성 사용자 상호작용 부족 | 콘텐츠 신호·인기도·온보딩 혼합 | 신규군 성능 |
| 인기도 편향 | 노출 많은 항목만 더 추천되는 피드백 루프 | 탐색·다양성 제약·노출보정 적용 | 노출집중도 |
| 평가 누출 | 랜덤 분할이 시간·노출 맥락을 무시 | 시간순 홀드아웃·온라인 실험과 장기지표 | CTR·유지율·다양성 |

## Ⅵ. 추천 시스템 필터링의 제언

- 핵심 요약 : 추천팀은 오프라인 정확도와 함께 노출편향·다양성·신규사용자 효용을 평가하고 개인정보·설명·사용자 제어를 제품정책에 포함.
- 실행 제안 : 추천팀은 신규 사용자·아이템 코호트에서 정확도·다양성·노출편중을 따로 평가하고 임계값 정책을 실험.

## Ⅶ. 추천 시스템 필터링의 결론

- 핵심 요약 : 추천 품질은 클릭률만으로 측정되지 않으며 발견성·다양성·장기 만족과 공정성을 함께 반영.
- 시사점 : 추천은 클릭 최적화만 추구하지 말고 신규성·다양성·장기 사용자 효용을 평가.
