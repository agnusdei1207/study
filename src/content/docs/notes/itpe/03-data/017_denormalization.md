## 연관 키워드
- 반정규화, 정규화, 중복 저장, 조인, 읽기 성능, 일관성

### Ⅰ. 반정규화의 개요

- 핵심 요약 : 반정규화는 조회 성능·단순화를 위해 정규화된 스키마에 의도적으로 중복·계산값·결합 구조를 추가하는 설계.
-概念 : 조회 성능·단순화를 위해 정규화된 스키마에 의도적으로 중복·계산값·결합 구조를 추가하는 설계(**반정규화**, Denormalization).
- 배경 및 필요성 : 정규화 스키마의 잦은 조인·집계가 특정 조회에서 성능 병목을 유발.
- 주요 목적 : 측정된 읽기 병목을 줄이되 갱신 이상과 중복 불일치를 통제.

### Ⅱ. 반정규화의 특징 및 장점

- 핵심 요약 : 중복 속성·요약·계산값·읽기모델 분리는 조회 성능을 높이는 데이터베이스 설계 방식.

1. 중복 속성 : 자주 조회하는 값을 함께 저장 → 조인 감소.
2. 요약·계산값 : 집계 결과 사전 계산 → 조회 지연 감소.
3. 읽기모델 분리 : CQRS·물리화 뷰 등 → 쓰기모델과 조회 요구 분리.

### Ⅲ. 반정규화의 구조 (흐름)

- 핵심 요약 : 조회 병목 측정 → 정규화·실행계획 확인 → 반정규화 후보·동기화 규칙 선정 → 적용 → 성능·정합성 측정.

```text
조회 병목 측정
  ↓
정규화·실행계획 확인
  ↓
반정규화 후보·동기화 규칙 선정
  ↓
적용
  ↓
성능·정합성 측정
```

```text
정규화 원천 테이블 → 변경 이벤트/갱신 규칙
              ↓                      ↓
          정합성 기준 ← 반정규화 조회모델
                                   ↓
                              빠른 읽기
```

### Ⅳ. 정규화와 반정규화 비교

- 핵심 요약 : 쓰기 특성 기준 — 정규화: 갱신 이상·저장량 감소; 반정규화: 쓰기·동기화 복잡도 증가.

| 비교 축 | 정규화 | 반정규화 |
|---|---|---|
| 중복 | 함수 종속에 따라 중복 최소화 | 조회 목적으로 중복·요약 허용 |
| 쓰기 특성 | 갱신 이상·저장량 감소 | 쓰기·동기화 복잡도 증가 |
| 주요 이점 | 무결성·갱신 단순 | 조인·집계 비용 절감 |

### Ⅴ. 반정규화의 한계와 방안

- 핵심 요약 : 갱신 이상·쓰기 비용 증가 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 갱신 이상 | 같은 사실이 여러 곳에 존재해 불일치 | 원천 단일화·트랜잭션 갱신 또는 이벤트 동기화 | 불일치율 |
| 쓰기 비용 증가 | 쓰기마다 중복 테이블·요약 갱신 필요 | 비동기 허용범위·보상·재구축 절차 설계 | 갱신 지연 |
| 근거 없는 반정규화 | 인덱스·쿼리 개선으로 해결 가능한 문제 확대 | 실행계획·부하측정으로 병목 검증 후 적용 | p95 지연·저장량 |

### Ⅵ. 반정규화에 대한 제언

- 핵심 요약 : DB 아키텍트는 반정규화 항목마다 원천 필드·동기화 방식·불일치 허용시간·재구축 방법을 데이터 모델에 기록.

- 실행 제안 : 설계자는 중복 열마다 원천 필드·갱신 주체·허용 지연·재구축 절차를 데이터 모델에 기록.

### Ⅶ. 결론

- 핵심 요약 : 반정규화는 성능을 위한 의도적 중복이며, 측정된 병목과 통제 가능한 동기화 전략이 있을 때 적용.
- 시사점 : 중복 저장은 조회성능을 얻는 대신 갱신 정합성 책임을 추가하는 의도적 설계 선택.
