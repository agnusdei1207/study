자료처리·데이터 → 관계형 데이터 모델링 → **정규화**

## 30초 인출

- 본질: 정규화는 함수적 종속관계를 분석해 테이블을 분해함으로써 중복과 삽입·수정·삭제 이상을 줄이는 설계 방법
- 메커니즘: 후보키와 함수적 종속을 정리해 정규형 위반 결정자를 찾고, 사실별로 테이블을 분해한 뒤 무손실 결합과 종속 보존을 검증
- 통찰: 분해만 하면 원본 복원이 안 되거나 업무 규칙을 검사할 수 없게 될 수 있으므로 무손실 결합과 종속 보존을 함께 확인하고, 조회 병목이 측정된 곳에만 반정규화

<details>
<summary>핵심 용어</summary>

- **정규화(Normalization)** : 함수적 종속관계에 따라 테이블을 분해해 중복·갱신 이상을 줄이는 설계
- **함수적 종속(Functional Dependency)** : X 값이 같으면 Y 값도 같다는 관계, X → Y
- **후보키(Candidate Key)** : 행을 유일하게 식별하는 최소 속성 집합
- **이상현상(Anomaly)** : 중복·혼합된 사실 때문에 삽입·수정·삭제 시 불일치·정보 손실이 생기는 현상
- **1NF** : 모든 속성값이 하나의 값인 형태
- **2NF** : 1NF에서 후보키 일부에 대한 부분 종속을 제거한 형태
- **3NF** : 2NF에서 키에 대한 이행 종속을 제거한 형태
- **BCNF(Boyce–Codd Normal Form)** : 모든 비자명한 함수적 종속의 결정자가 슈퍼키인 정규형
- **무손실 분해** : 분해한 테이블을 조인하면 원래 관계를 복원할 수 있는 성질

</details>

## 2~4교시 25점 답안

## Ⅰ. 정규화의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정규화** 는 함수적 종속관계에 따라 테이블을 분해해 중복과 삽입·수정·삭제 이상을 줄이는 설계 방법 |
| 목적 | 데이터 일관성과 변경 용이성 확보 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 함수 종속 기반 | 업무 사실과 후보키·결정자 관계 확인 |
| 이상현상 완화 | 중복된 사실의 불일치 감소 |
| 분해 검증 필요 | 무손실 결합과 필요한 종속 보존 확인 |

## Ⅲ. 이상현상과 정규화 절차

### 이상현상의 원인

```text
한 테이블에 서로 다른 사실이 반복 저장
  ├ 삽입 이상: 관련 없는 사실이 없으면 새 사실을 저장하지 못함
  ├ 수정 이상: 중복된 값 일부만 바뀌어 불일치
  └ 삭제 이상: 한 사실을 지우면 다른 사실까지 사라짐
```

### 정규화 절차

```text
비정규 릴레이션
   ↓ 다중값·반복 항목 분리
1NF
   ↓ 후보키 일부에 대한 부분 종속 제거
2NF
   ↓ 키 → 중간 속성 → 비주요 속성의 이행 종속 제거
3NF
   ↓ 결정자가 슈퍼키가 아닌 종속 제거
BCNF
```

## Ⅳ. 정규형과 검증

| 정규형 | 확인할 종속 | 설계 방향 |
|---|---|---|
| 1NF | 속성값의 단위 | 반복 항목·다중값 분리 |
| 2NF | 복합 후보키의 일부 → 비주요 속성 | 부분 종속 분리 |
| 3NF | 키 → 중간 속성 → 비주요 속성 | 이행 종속 분리 |
| BCNF | 비자명한 X → Y에서 X가 슈퍼키인지 | 위반 결정자 분리 |

| 검증 | 이유 |
|---|---|
| 무손실 결합 | 조인 시 잘못된 행이 생기거나 정보가 사라지는지 확인 |
| 종속 보존 | 분해 후에도 업무 규칙을 검사할 수 있는지 확인 |
| 실제 질의 | 갱신 일관성과 조회 비용의 절충 검토 |

| 설계 | 주된 목표 | 대가 |
|---|---|---|
| 정규화 | 중복·갱신 이상 감소 | 일부 조회에서 조인 증가 |
| 반정규화 | 측정된 조회 병목 완화 | 중복값 갱신·정합성 관리 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 함수적 종속을 업무 확인 없이 추정 | 업무 규칙·키·실제 데이터로 검증 |
| 분해 후 조인으로 원본 복원 불가 | 무손실 결합 조건 확인 |
| 정규형만 보고 성능 무시 | 주요 질의·갱신 부하 시험 후 필요 시 반정규화 |

## Ⅵ. 제언

논리 설계에서 3NF·BCNF까지 정규화하고, 무손실 결합과 종속 보존을 검증한 뒤 성능 시험 결과에 따라 선택적으로 반정규화

```text
정규화(3NF·BCNF) → 무손실·종속 보존 검증 → 부하 시험 → 병목 지점만 반정규화
```

| 구분 | 미흡한 정규화 | 제언: 정규화 후 선택적 반정규화 |
|---|---|---|
| 이상현상 | 삽입·수정·삭제 이상 | 종속 분해로 감소 |
| 성능 | 근거 없는 조정 | 측정 후 조정 |
