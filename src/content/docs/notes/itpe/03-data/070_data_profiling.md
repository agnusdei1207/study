## 연관 키워드
- 데이터 프로파일링, 데이터 품질, 데이터 속성, 데이터 품질 규칙, 데이터 품질 검증, 데이터 품질 개선

## Ⅰ. 데이터 프로파일링의 개요

- 핵심 요약 : 데이터 품질, 데이터 속성, 데이터 품질 규칙, 데이터 품질 검증, 데이터 품질 개선을 위해 데이터의 특성과 패턴을 분석하는 과정.
- 개념 : 데이터 품질, 데이터 속성, 데이터 품질 규칙, 데이터 품질 검증, 데이터 품질 개선을 위해 데이터의 특성과 패턴을 분석하는 과정(데이터 프로파일링, Data Profiling).
- 배경 및 필요성 : 데이터의 양과 복잡성이 증가함에 따라 데이터의 품질과 특성을 빠르고 정확하게 파악하는 것이 중요해짐.
- 주요 목적 : 데이터 품질을 개선하고 데이터 기반 의사결정을 지원.

## Ⅱ. 데이터 프로파일링의 특징 및 장점

- 핵심 요약 : 데이터 품질, 데이터 속성, 데이터 품질 규칙, 데이터 품질 검증, 데이터 품질 개선을 위해 데이터의 특성과 패턴을 분석하는 구조.

1. 데이터 품질 : 데이터의 정확성, 완전성, 일관성, 시의성, 고유성 등을 평가.
2. 데이터 속성 : 데이터의 유형, 분포, 분포도, 범위 등을 분석.
3. 데이터 품질 규칙 : 데이터의 품질을 평가하기 위한 기준과 규칙을 정의.
4. 데이터 품질 검증 : 데이터의 품질을 검증하여 문제점을 발견.
5. 데이터 품질 개선 : 데이터 품질 문제를 개선하여 데이터 품질을 향상.

## Ⅲ. 데이터 프로파일링의 구조 (흐름)

- 핵심 요약 : 데이터 수집 → 데이터 프로파일링 → 데이터 품질 평가 → 데이터 품질 개선 → 데이터 품질 모니터링.

```text
[ 데이터 프로파일링 프로세스 ]
데이터 수집
   ↓
데이터 프로파일링
   ↓
데이터 품질 평가
   ↓
데이터 품질 개선
   ↓
데이터 품질 모니터링
```

## Ⅳ. 데이터 프로파일링과 데이터 카탈로그의 비교
- 핵심 요약 : 프로파일링은 데이터 값과 분포를 분석하고, 카탈로그는 메타데이터와 위치를 정리하는 상호 보완적 도구.
- 비교 대상 : 데이터 프로파일링 (Data Profiling)과 데이터 카탈로그 (Data Catalog).
- 통계적 방법 : 평균, 분산, 표준 편차, 최솟값, 최댓값 등을 통한 데이터 분포 분석.
- 패턴 분석 : 데이터의 패턴을 분석하여 이상 값이나 비정상적인 패턴을 탐지.
- 상관 관계 분석 : 변수 간의 관계를 분석하여 데이터 간의 관계를 파악.

| 비교 축 | 데이터 프로파일링 | 데이터 카탈로그 |
| --- | --- | --- |
| 목적 | 데이터 값·분포·품질 특성 분석 | 데이터 자산의 메타데이터·위치 정리 |
| 대상 | 테이블·컬럼의 실제 값 | 데이터셋·테이블·컬럼의 설명 |
| 산출물 | 통계 지표, 이상 값, 품질 규칙 후보 | 비즈니스 용어, 소유자, 접근 경로 |
| 활용 시점 | 품질 진단·정제 전 단계 | 데이터 탐색·재사용·거버넌스 |
| 주요 기능 | 분포 분석, 이상 값 탐지, 상관 분석 | 검색, 계보, 접근 권한 안내 |

```text
[ 데이터 프로파일링 vs 데이터 카탈로그 ]
프로파일링 : 값·분포·품질 특성 분석
    ↓
카탈로그 : 메타데이터·위치·소유자 정리
```

## Ⅴ. 데이터 프로파일링의 한계와 방안

- 핵심 요약 : 표본 편향, 대용량 처리 비용, 규칙 해석 오류를 자동화·샘플링·도메인 검증으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 표본 편향 | 일부 구간만 분석 시 실제 분포 왜곡 | 전체 스캔과 주기적 재프로파일링 병행 | 커버리지 비율 |
| 처리 비용 증가 | 대용량 데이터 스캔 시 시간·자원 소모 | 증분 프로파일링, 샘플링, 분산 처리 | 분석 소요 시간 |
| 규칙 해석 오류 | 통계 이상치를 업무 이상치로 오판 | 도메인 규칙 결합, 담당자 검토 절차 | 오탐·미탐 비율 |

## Ⅵ. 데이터 프로파일링에 대한 기술사적 제언

- 핵심 요약 : 프로파일링을 파이프라인과 품질 거버넌스에 내장해 지속적 품질 관리 체계로 운영.
- 데이터 엔지니어링 조직 : ETL/ELT 단계에 자동 프로파일링과 품질 게이트를 통합.
- 데이터 거버넌스 조직 : 프로파일 결과를 데이터 카탈로그·품질 규칙 저장소와 연계해 재사용 기반 확보.
- 현업 조직 : 이상치·결측치 판단 기준을 도메인 규칙으로 정의해 분석 결과의 업무 적합성 검증.

## Ⅶ. 결론

- 핵심 요약 : 데이터 프로파일링은 데이터의 값·분포·품질 특성을 진단해 후속 정제와 거버넌스를 가능하게 하는 기초 활동.
- 시사점 : 자동화된 프로파일링과 도메인 검증이 결합될 때 데이터 품질 개선과 신뢰 가능한 분석이 지속 가능.
