## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 웨어하우스 → **스타 스키마**

## 30초 인출

- 본질: 스타 스키마는 사실 테이블을 중심에 두고 관련 차원 테이블을 직접 연결한 차원 모델
- 메커니즘: 업무 프로세스를 정하고 사실 한 행의 입도를 선언한 뒤 맞는 차원·측정값을 정의하며, 차원 속성이 바뀌면 SCD 방식(덮어쓰기·새 행·별도 열)으로 이력을 처리
- 통찰: 입도가 불명확하면 중복 집계가 생기고 차원 이력 정책이 없으면 과거 보고서가 현재 속성으로 바뀌므로, 입도와 가산성을 합의하고 과거 분석 요구에 맞는 SCD 방식을 선택

<details>
<summary>핵심 용어</summary>

- **스타 스키마(Star Schema)** : 사실 테이블 중심으로 차원 테이블을 직접 연결한 모델
- **사실 테이블·차원 테이블** : 측정값과 차원 키를 가진 테이블 / 분석 관점의 속성을 가진 테이블
- **입도(Grain)** : 사실 한 행이 나타내는 업무 사건의 단위
- **스노우플레이크 스키마** : 차원 계층을 정규화해 여러 테이블로 나눈 모델
- **SCD(Slowly Changing Dimension)** : 차원 속성 변경 이력을 관리하는 방식(Type 1·2·3)
- **대리키(Surrogate Key)** : 차원 행을 식별하기 위해 부여한 인공 키

</details>

## 2~4교시 25점 답안

## Ⅰ. 스타 스키마의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **스타 스키마** 는 사실 테이블을 중심으로 차원 테이블을 직접 연결하는 차원 모델 |
| 목적 | 업무 사건을 여러 분석 관점에서 조회·집계 |

## Ⅱ. 특징

| 특징 | 분석상 의미 |
|---|---|
| 사실 중심 연결 | 차원 키와 측정값을 가진 사실 테이블에서 여러 관점으로 직접 조인 |
| 선언된 입도 | 사실 한 행의 업무 의미가 집계·중복 판단의 기준 |
| 차원 속성 활용 | 시간·고객·상품 같은 필터·그룹 기준을 읽기 쉽게 제공 |

## Ⅲ. 구조와 설계 절차

```text
              시간 차원
                 │
고객 차원 ─ 사실 테이블(입도·측정값) ─ 상품 차원
                 │
              지역 차원
```

```text
업무 프로세스 선택 → 사실 한 행의 입도 선언 → 차원·측정값 정의 → 집계·시점 질의 검증
```

## Ⅳ. 스노우플레이크 비교와 차원 이력 관리

| 기준 | 스타 | 스노우플레이크 |
|---|---|---|
| 차원 구조 | 속성을 한 차원 테이블에 모음(비정규화 경향) | 차원 계층을 여러 정규화 테이블로 분리 |
| 조인 | 사실과 차원의 직접 연결 | 계층까지 추가 조인 |
| 장점 | 단순한 질의·사용 편의 | 중복 감소·계층 속성 관리 |
| 선택 | 질의 단순성·성능 요구 | 중복·갱신·모델 관리 요구 |

| SCD 방식 | 처리 | 적합한 요구 |
|---|---|---|
| Type 1 | 기존 속성을 덮어씀(이력 미보존) | 현재 값만 필요 |
| Type 2 | 새 행과 대리키·유효기간 추가 | 과거 사실을 당시 차원 값으로 분석 |
| Type 3 | 이전 값을 제한된 별도 열에 보존 | 제한된 변경 이력 비교 |

```text
고객 속성 변경 → Type 2: 새 차원 행·새 대리키
변경 전 사실 → 옛 키 → 옛 속성 / 변경 후 사실 → 새 키 → 새 속성
```

스타 변환(star transformation)은 제품·인덱스·조건에 따라 적용되는 옵티마이저 기법이며 스타 스키마 자체가 성능을 보장하지 않음.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 입도 불명확으로 중복 집계 | 행의 의미와 측정값 가산성을 합의, 대표 집계로 검증 |
| 이력 정책 부재로 과거 보고서 수치·분류 변화 | 과거 분석 요구에 맞는 SCD 방식과 유효시점, 시점별 질의 확인 |
| 비정규화 차원 갱신 시 값 불일치 | 속성 소유·적재 검증 규칙 정의, 변경 영향 확인 |

## Ⅵ. 제언

입도를 먼저 선언하고 차원 이력 요구에 따라 SCD 방식을 선택해 시점별 결과를 검증

```text
업무 프로세스 → 입도 선언 → 차원·측정값 → SCD 방식 선택 → 시점별 집계 검증
```

| 구분 | 입도·이력 미정의 | 제언: 입도 선언 + SCD |
|---|---|---|
| 집계 | 중복 | 입도 기준 |
| 과거 보고서 | 현재 값으로 변경 | 당시 값 유지 |
