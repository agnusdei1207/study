## 연관 키워드

**데이터 마이닝**, **KDD**, **전처리**, **분류·회귀·군집·연관분석**, **CRISP-DM**, **모델 평가**, **드리프트**

## Ⅰ. 개요

- 핵심 요약 : **데이터 마이닝**은 데이터에서 유용한 패턴을 찾아 평가하고 의사결정에 활용하는 분석 과정이다.
- 목적 : 대량 데이터에서 분류 규칙, 예측 관계, 집단 구조, 항목 간 연관성을 발견한다.
- 관계 : **KDD(Knowledge Discovery in Databases)**는 지식 발견 전체 과정이며, 데이터 마이닝은 그중 패턴 탐색 단계다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **분석 목적에 맞는 학습 방식과 태스크**를 선택해 예측·세분화·연관 탐색을 수행한다.
- **지도학습** : 레이블이 있는 데이터로 분류·회귀 모델을 학습해 결과를 예측한다.
- **비지도학습** : 레이블 없이 유사성이나 동시 출현 구조를 찾아 군집·연관 규칙을 도출한다.
- **반복 개선** : 도메인 검토와 평가를 거쳐 유효한 패턴을 실제 업무에 연결한다.

## Ⅲ. KDD와 CRISP-DM 흐름

- 핵심 요약 : **데이터 이해와 준비부터 평가·배포까지 반복하는 과정**으로 분석을 운영한다.

```text
[KDD: 문제·데이터 정의]
          ▼
[선택] → [전처리] → [변환]
                       ▼
                  [데이터 마이닝]
                       ▼
                 [패턴 평가·해석]
                       ▼
                  [지식·업무 적용]
```

- 실무 방법론인 **CRISP-DM**은 비즈니스 이해, 데이터 이해, 데이터 준비, 모델링, 평가, 배포의 여섯 단계로 구성되며 평가 결과에 따라 앞 단계로 돌아간다.

```text
[비즈니스 이해] → [데이터 이해] → [데이터 준비]
       ▲                                ▼
       │                           [모델링]
       │                                ▼
   [배포] ← [평가·승인] ←───────────────┘
```

## Ⅳ. 주요 분석 태스크 비교

- 핵심 요약 : **목표 변수와 질문 유형**에 따라 분석 태스크와 평가 방법을 선택한다.

| 태스크 | 목표 | 예시 알고리즘 | 평가 예시 |
|---|---|---|---|
| 분류 | 범주형 결과 예측 | 의사결정나무, 로지스틱 회귀 | 정밀도·재현율·F1 |
| 회귀 | 연속형 값 예측 | 선형 회귀, 회귀 트리 | MAE·RMSE |
| 군집 | 유사한 자료 묶기 | K-means, DBSCAN | 실루엣 계수·도메인 검토 |
| 연관분석 | 항목 동시 출현 규칙 | Apriori, FP-Growth | 지지도·신뢰도·향상도 |

- 분류와 회귀는 **지도학습**, 군집과 연관분석은 일반적으로 **비지도 분석**에 해당한다.

## Ⅴ. 한계와 방안

- 핵심 요약 : **데이터 품질·우연 상관·분포 변화**를 점검하지 않으면 발견한 패턴이 실제 업무에서 재현되지 않을 수 있다.
- **전처리 편중** → 데이터 품질 규칙과 재사용 가능한 변환 파이프라인을 만들고 준비 비용을 추적한다.
- **허위 상관·과적합** → 검증 데이터와 시간 분할 검증을 적용하고 도메인 전문가가 패턴의 타당성을 확인한다.
- **편향된 표본** → 모집단과 수집 과정을 점검하고 성능을 하위집단별로 평가한다.
- **분포·개념 변화** → 입력 및 성능 지표를 관찰하고, 경보 후 원인 확인과 재학습 검증을 거친다.

```text
품질·편향 문제 → 데이터 진단·하위집단 평가
우연 패턴       → 검증·도메인 확인     → 재현 가능한 업무 지식
환경 변화       → 성능 감시·재평가
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **모델 성능뿐 아니라 데이터 계보·설명·배포 후 감시**까지 운영 체계에 포함한다.
- 분석 목적과 성공 지표를 먼저 합의하고, 재현 가능한 데이터·모델 버전 관리 절차를 둔다.
- 설명 자료는 모델과 이용자에 맞춰 제공하고, 설명 기법의 결과를 인과관계로 오해하지 않도록 안내한다.
- 재학습은 자동 실행만으로 배포하지 말고 검증·승인·롤백 절차를 포함한다.

## Ⅶ. 결론

- 핵심 요약 : 데이터 마이닝은 알고리즘 선택보다 **목적 정의·데이터 준비·패턴 검증·운영 환류**가 성패를 좌우한다.
- 답안에는 KDD와 CRISP-DM의 차이, 네 가지 분석 태스크, 데이터 품질과 드리프트 대응을 연결해 제시한다.
