## 연관 키워드

- 데이터 마이닝, KDD, CRISP-DM, 전처리, 분류, 회귀, 군집 분석, 연관 분석, 지도학습, 비지도학습, 모델 평가, 과적합, 개념 드리프트(Concept Drift)

## Ⅰ. 데이터 마이닝의 개요

- 핵심 요약 : **데이터 마이닝**은 대량 데이터에서 유용한 패턴을 찾아 평가하고 의사결정에 활용하는 분석 과정.
- 개념 : 분류 규칙, 예측 관계, 집단 구조, 항목 간 연관성 같은 패턴을 데이터에서 찾아 타당성을 검증하는 과정.
- 관계 : **KDD** (Knowledge Discovery in Databases)는 지식 발견 전체 과정이고, 데이터 마이닝은 그중 패턴 탐색 단계에 해당.
- 주요 목적 : 찾은 패턴을 업무 의사결정과 예측·세분화에 연결하는 근거 확보.

## Ⅱ. 데이터 마이닝의 특징 및 장점

- 핵심 요약 : 분석 목적에 맞는 학습 방식을 골라 예측, 세분화, 연관 탐색을 수행하는 분석 방식.

1. **지도학습** : 레이블이 있는 데이터로 분류·회귀 모델을 학습 → 미래 값이나 범주를 근거 있게 예측.
2. **비지도학습** : 레이블 없이 유사성이나 동시 출현 구조를 찾아 군집·연관 규칙을 도출 → 정답이 없는 데이터에서도 세분화와 규칙 발견.
3. 반복 개선 : 도메인 검토와 평가를 거쳐 유효한 패턴만 업무에 연결 → 발견한 지식의 재현성 확보.

## Ⅲ. 데이터 마이닝의 구조 (흐름)

- 핵심 요약 : KDD 단계를 따라 데이터를 준비하고 패턴을 평가하며, 실무에서는 CRISP-DM 순환으로 운영.
- **CRISP-DM** (Cross-Industry Standard Process for Data Mining) : 비즈니스 이해, 데이터 이해, 데이터 준비, 모델링, 평가, 배포의 여섯 단계로 이루어지며, 평가 결과에 따라 앞 단계로 돌아가는 실무 방법론.

```text
[KDD: 문제·데이터 정의]
            ↓
[선택] → [전처리] → [변환]
            ↓
[데이터 마이닝]
            ↓
[패턴 평가·해석]
            ↓
[지식·업무 적용]
```

```text
[CRISP-DM 순환]
[비즈니스 이해]
        ↓
[데이터 이해]
        ↓
[데이터 준비]
        ↓
[모델링]
        ↓
[평가·승인] ── 미흡 → 앞 단계 복귀
        ↓
[배포]
```

## Ⅳ. 주요 분석 태스크 비교

- 핵심 요약 : 목표 변수와 질문 유형에 따라 분석 태스크를 고르고, 태스크별 모델 평가 지표를 함께 정한다.

| 태스크 | 목표 | 예시 알고리즘 | 평가 예시 |
| --- | --- | --- | --- |
| 분류 | 범주형 결과 예측 | 의사결정나무, 로지스틱 회귀 | 정밀도·재현율·F1 점수 |
| 회귀 | 연속형 값 예측 | 선형 회귀, 회귀 트리 | MAE (Mean Absolute Error), RMSE (Root Mean Squared Error) |
| 군집 분석 | 유사한 자료 묶기 | K-means, DBSCAN | 실루엣 계수, 도메인 검토 |
| 연관 분석 | 항목 동시 출현 규칙 | Apriori, FP-Growth | 지지도·신뢰도·향상도 |

- 분류와 회귀는 지도학습, 군집 분석과 연관 분석은 일반적으로 비지도 분석에 해당.

## Ⅴ. 데이터 마이닝의 한계와 방안

- 핵심 요약 : 데이터 품질, 우연한 상관, 분포 변화를 점검하지 않으면 발견한 패턴이 실제 업무에서 재현되지 않음.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 전처리 부담 | 데이터 준비 비용이 커지고 재작업이 반복 | 데이터 품질 규칙과 재사용 가능한 변환 파이프라인 구축 | 준비 소요 시간 |
| 허위 상관·과적합 | 우연히 맞은 패턴이 새 데이터에서 무너짐 | 검증 데이터와 시간 분할 검증 적용, 도메인 전문가 확인 | 학습·검증 성능 차이 |
| 편향된 표본 | 모집단을 대표하지 못해 특정 집단에 불리한 결과 | 수집 과정 점검, 하위집단별 성능 평가 | 하위집단별 정확도 |
| **개념 드리프트** (Concept Drift) | 환경 변화로 입력과 목표의 관계가 바뀌어 모델 성능 저하 | 입력 분포와 성능 지표 감시, 경보 후 재학습과 검증 | 성능 저하율 |

## Ⅵ. 데이터 마이닝에 대한 기술사적 제언

- 핵심 요약 : 모델 성능과 함께 데이터 계보, 설명, 배포 후 감시를 묶는 운영 체계 필요.
- 분석 목적과 성공 지표를 먼저 합의하고, 재현 가능한 데이터와 모델 버전 관리 절차를 두어야 결과를 다시 검증할 수 있다.
- 설명 자료는 모델과 이용자에 맞춰 제공하고, 설명 기법의 결과를 인과관계로 오해하지 않도록 안내하는 것이 바람직하다.
- 재학습 결과는 자동 실행만으로 배포하지 않고, 검증과 승인, 롤백 절차를 거쳐 반영한다.

## Ⅶ. 결론

- 핵심 요약 : 데이터 마이닝의 성패는 알고리즘 선택보다 목적 정의, 데이터 준비, 패턴 검증, 운영 환류에 달려 있음.
- 시사점 : 분석 목적에서 배포 후 감시까지 순환하는 체계로 운영해야 패턴이 실제 업무 지식으로 남음.
