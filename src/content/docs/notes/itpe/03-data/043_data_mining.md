## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 → **데이터 마이닝**

## 30초 인출

- 본질: 데이터 마이닝은 데이터에서 분석 목적에 유용한 패턴·관계를 찾는 분석 활동
- 메커니즘: KDD 과정에서 선택·정제·변환한 자료에 분류·회귀·군집·연관 분석 기법을 적용해 모형·규칙을 도출하고 유효성과 업무 의미를 평가
- 통찰: 과적합·데이터 누출·상관의 인과 오해가 결과를 왜곡하므로 독립 검증 자료로 평가하고 지표를 업무 목표와 오류 비용에 맞춰 선택

<details>
<summary>핵심 용어</summary>

- **데이터 마이닝(Data Mining)** : 데이터에서 유용한 패턴·관계를 찾는 분석
- **KDD(Knowledge Discovery in Databases)** : 선택·전처리·변환·마이닝·해석으로 이어지는 지식 발견 과정
- **분류·회귀** : 범주를 예측 / 수치를 예측하는 지도학습 과제
- **군집화** : 라벨 없이 유사한 관측값을 묶는 과제
- **연관분석** : 항목 간 함께 나타나는 규칙을 찾는 분석
- **지지도·신뢰도·향상도** : 연관 규칙의 발생 비율·조건부 확률·독립 대비 증가 정도
- **과적합·데이터 누출** : 학습 데이터에만 맞춘 모형 / 평가 정보가 학습에 섞임

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 마이닝의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 마이닝** 은 데이터에서 분석 목적에 유용한 패턴·관계를 찾는 분석 활동 |
| 목적 | 데이터에 포함된 구조를 설명·예측·의사결정에 활용 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 과제별 기법 | 분류·회귀·군집·연관 등 목적에 맞는 기법 선택 |
| KDD 안의 분석 단계 | 자료 준비와 결과 해석 사이에서 모형·규칙 도출 |
| 유용성 검증 필요 | 지표뿐 아니라 업무 적용성과 재현성 확인 |

## Ⅲ. KDD 과정에서의 위치

```text
원천 데이터 → 선택·정제·변환 → 데이터 마이닝 → 패턴 평가·해석
```

| KDD 활동 | 주요 내용 |
|---|---|
| 선택·이해 | 분석 질문에 맞는 자료와 범위 선정 |
| 전처리·변환 | 오류·결측·형식 차이 정리 |
| 데이터 마이닝 | 알고리즘으로 패턴·모형 도출 |
| 해석·평가 | 유효성·업무 의미·활용 가능성 검토 |

## Ⅳ. 분석 기법 비교

| 과제 | 학습 자료 | 출력 | 평가 관점 |
|---|---|---|---|
| 분류 | 정답 범주가 있는 사례 | 범주·확률 | 혼동행렬·정밀도·재현율 |
| 회귀 | 정답 수치가 있는 사례 | 연속형 추정값 | 잔차·오차 크기 |
| 군집화 | 라벨 없는 관측값 | 군집 배정 | 분리도·업무 해석 |
| 연관분석 | 거래 기록 | 항목 간 규칙 | 지지도·신뢰도·향상도 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 대표성 부족·측정 오류 | 수집 과정·결측·라벨 품질 확인 |
| 과적합·데이터 누출 | 독립 검증 자료와 적절한 분할 |
| 지표와 업무 목표 불일치 | 오류 비용·임계값에 맞는 지표 선택 |
| 패턴의 과잉 해석 | 상관을 인과로 단정하지 않고 재현성 검토 |

## Ⅵ. 제언

분석 과제에 맞는 기법을 고르고, 독립 검증 자료로 평가한 뒤 업무 맥락에서 해석

```text
과제 정의 → 기법 선택 → 분할 검증(누출 차단) → 업무 지표로 평가·해석
```

| 구분 | 학습 성능만 확인 | 제언: 독립 검증 |
|---|---|---|
| 일반화 | 과적합 위험 | 검증 자료로 확인 |
| 활용 | 지표 중심 | 업무 지표 연결 |
