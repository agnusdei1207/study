## 연관 키워드
- 데이터 마이닝, 분류, 군집, 연관 규칙, 회귀, CRISP-DM

### Ⅰ. 데이터 마이닝의 개요

- 핵심 요약 : 데이터 마이닝은 대량 데이터에서 통계·기계 학습 기법으로 유용한 패턴·관계·예측 모형을 발견하는 분석 과정.
- 개념 : 대량 데이터에서 통계·기계 학습 기법으로 유용한 패턴·관계·예측 모형을 발견하는 분석 과정(**데이터 마이닝**, Data Mining).
- 배경 및 필요성 : 데이터의 규모와 복잡성으로 수작업 탐색만으로 반복 가능한 패턴 발견이 어려움.
- 주요 목적 : 검증 가능한 패턴을 발굴해 업무 의사 결정과 지식 활용 지원.

### Ⅱ. 데이터 마이닝의 특징 및 장점

- 핵심 요약 : 탐색·전처리·기법 선택·평가·배포는 데이터 마이닝의 반복 분석 과정.

1. 탐색·전처리 : 품질·누락·특징 분석 → 모델 입력 신뢰도 향상.
2. 기법 선택 : 분류·회귀·군집·연관 분석 → 질문에 맞는 산출.
3. 평가·배포 : 검증 자료·업무 기준 적용 → 재현·활용 가능성 확보.

### Ⅲ. 데이터 마이닝의 구조 (흐름)

- 핵심 요약 : 업무 이해 → 데이터 이해 → 준비 → 모델링 → 평가 → 배포 → 각 단계는 평가 결과에 따라 반복.

```text
업무 이해 → 데이터 이해 → 준비 → 모델링 → 평가 → 배포
  ↓
각 단계는 평가 결과에 따라 반복
```

```text
업무 문제 → 데이터·전처리 → 모델·패턴 → 검증 → 운영·모니터링
```

### Ⅳ. 데이터 마이닝과 데이터 웨어하우스 비교

- 핵심 요약 : 핵심 활동 기준 — 데이터 마이닝: 모형 학습·평가·해석; 데이터 웨어하우스: ETL·차원 모델·조회.

| 비교 축 | 데이터 마이닝 | 데이터 웨어하우스 |
|---|---|---|
| 목적 | 패턴·예측·연관성 발견 | 통합 이력의 저장·질의 제공 |
| 핵심 활동 | 모형 학습·평가·해석 | ETL·차원 모델·조회 |

### Ⅴ. 데이터 마이닝의 한계와 방안

- 핵심 요약 : 데이터 누출·과적합·편향 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 데이터 누출 | 목표 변수 이후 정보가 학습에 포함 | 시간·그룹 기준 분할과 특성 계보 검토 | 검증-운영 성능 격차 |
| 과적합·편향 | 표본 특성·모형 선택이 일반화 저해 | 교차 검증·외부 검증·집단별 평가 | 성능·격차 |
| 발견과 인과 혼동 | 연관 패턴을 원인으로 해석 | 실험·인과 설계 없이 인과 주장 금지 | 재현·인과 검증 |

### Ⅵ. 데이터 마이닝에 대한 제언

- 핵심 요약 : 분석 조직은 CRISP-DM식 반복 수명 주기에 목표·데이터 출처·검증 기준·배포 책임을 포함하고 발견 패턴을 독립 자료에서 재검증.

- 실행 제안 : 분석 책임자는 학습·검증 데이터 계보와 성능 기준 선을 보존하고 독립 시점 자료에서 재현성을 승인.

### Ⅶ. 결론

- 핵심 요약 : 데이터 마이닝의 발견은 검증할 가설과 예측을 제공할 뿐 데이터만으로 인과 관계나 업무 가치가 자동 입증되지는 않음.
- 시사점 : 발견과 배포 성과를 구분하고 독립 자료·운영 데이터에서 반복 검증해야 분석이 재사용 가능.
