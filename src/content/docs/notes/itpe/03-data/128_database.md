- 판단: 개념 스키마 변경은 논리적 독립성, 내부 스키마 변경은 물리적 독립성의 대상

- **데이터베이스(Database)**: 여러 사용자가 함께 이용하도록 통합·저장·관리하는 운영 데이터의 집합

- **물리적 데이터 독립성**: 내부 저장 구조의 변경 영향을 개념 스키마에 미치지 않게 하는 성질

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 여러 사용자가 함께 이용하도록 통합·저장·관리하는 운영 데이터의 집합 |
| 목적 | 데이터 중복·종속을 줄이고 일관된 데이터 공유와 관리를 지원 |

### Ⅱ. 기본 특성과 스키마 구조

| 구분 | 핵심 |
|---|---|
| 기본 특성 | 실시간 접근, 계속적 변화, 동시 공유, 내용에 의한 참조 |
| 외부 스키마 | 개별 사용자·응용이 보는 데이터 뷰 |
| 개념 스키마 | 조직 전체 데이터의 논리 구조와 제약 |
| 내부 스키마 | 저장 파일·인덱스 등 물리적 구성 |

### Ⅲ. 독립성과 한 줄 제언

| 종류 | 바뀌는 계층 | 보호되는 계층 |
|---|---|---|
| 논리적 독립성 | 개념 스키마 | 외부 스키마 |
| 물리적 독립성 | 내부 스키마 | 개념 스키마 |

제언: 스키마 변경 시 영향 계층과 응용 의존성을 사전에 분석하고 사상·뷰를 함께 관리.

## 2~4교시 25점 답안

## Ⅰ. 데이터베이스 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 여러 사용자가 함께 이용하도록 통합·저장·관리하는 운영 데이터의 집합 |
| 목적 | 데이터 중복·종속을 줄이고 일관된 데이터 공유와 관리를 지원 |

## Ⅱ. 데이터베이스의 기본 특성

| 특성 | 의미 |
|---|---|
| 실시간 접근성 | 질의에 대해 필요한 데이터를 적시에 제공 |
| 계속적 변화 | 삽입·삭제·갱신으로 현재 상태를 반영 |
| 동시 공유 | 여러 사용자·응용의 공동 이용을 지원 |
| 내용에 의한 참조 | 물리 주소 대신 데이터 값과 조건으로 검색 |

## Ⅲ. ANSI/SPARC 3단계 스키마

| 계층 | 관점·정의 | 사상 관계 |
|---|---|---|
| 외부 스키마 | 사용자·응용별 데이터 뷰 | 개념 스키마와 외부/개념 사상 |
| 개념 스키마 | 조직 전체 데이터의 논리 구조·관계·제약 | 외부 및 내부 계층의 기준 |
| 내부 스키마 | 저장 파일·레코드·인덱스 등 물리 구조 | 개념 스키마와 개념/내부 사상 |

## Ⅳ. 데이터 독립성의 구분

| 독립성 | 변경 계층 | 영향을 분리하는 계층 | 예시 |
|---|---|---|---|
| 논리적 | 개념 스키마 | 외부 스키마 | 논리 구조 변경을 사용자 뷰에 흡수 |
| 물리적 | 내부 스키마 | 개념 스키마 | 파일 배치·인덱스 변경을 논리 구조에 흡수 |

데이터 독립성은 변경이 전혀 전파되지 않는다는 보장이 아니라, 사상과 뷰를 통해 상위 계층 및 응용에 미치는 영향을 줄이는 구조적 성질.

## Ⅴ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 개념·내부 스키마 변경이 응용에 직접 전파되면 변경 영향과 장애 범위가 커짐 | 논리 모델·외부 뷰·물리 매핑을 함께 형상관리하고, 스키마 변경 때 의존성 분석과 호환성 검증을 변경 절차에 포함 |
