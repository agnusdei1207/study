## 지식 로드맵 내 현재 위치

자료처리·데이터 → 관계형 데이터 모델 → **키(Key)**

## 30초 인출

- 본질: 키는 튜플을 식별하거나 릴레이션 사이의 참조를 표현하는 속성 집합
- 메커니즘: 유일성(값으로 행 하나 식별)과 최소성(어느 속성을 빼도 유일성 상실)을 모두 만족하면 후보키이고, 후보키 중 대표를 기본키로, 나머지를 대체키로 두며, 외래키는 다른 릴레이션의 기본키·유일 키를 참조
- 통찰: 변경되거나 민감한 자연키를 내부 참조에 쓰면 변경이 전파되므로 대리키로 내부를 식별하되 업무상 유일성은 별도 제약으로 유지

<details>
<summary>핵심 용어</summary>

- **슈퍼키(Super Key)** : 튜플을 유일하게 식별하는 속성 집합
- **후보키(Candidate Key)** : 최소성을 만족하는 슈퍼키
- **기본키(Primary Key)** : 후보키 중 대표 식별자로 선택한 키
- **대체키(Alternate Key)** : 기본키로 선택되지 않은 후보키
- **외래키(Foreign Key)** : 다른 릴레이션의 키를 참조하는 속성 집합
- **자연키·대리키** : 업무 의미가 있는 식별자 / 시스템이 부여한 의미 없는 식별자
- **유일성·최소성** : 튜플을 중복 없이 구별 / 불필요한 속성이 없음

</details>

## 2~4교시 25점 답안

## Ⅰ. 키의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **키** 는 튜플을 식별하거나 릴레이션 간 참조를 표현하는 속성 집합 |
| 목적 | 튜플 식별과 참조 무결성 표현 |

## Ⅱ. 특징

| 특징 | 판정 의미 |
|---|---|
| 유일성 | 속성값 조합으로 각 튜플 구분 |
| 최소성 | 후보키에는 제거 가능한 불필요한 속성이 없음 |
| 참조 역할 | 외래키는 다른 릴레이션의 유일 키를 참조 |

## Ⅲ. 키 유형의 관계

```text
속성 집합 X ─ 유일성 만족 → 슈퍼키
   └ 최소성도 만족 → 후보키 ─ 선택 → 기본키 / 미선택 → 대체키
자식의 외래키 ─ 참조 → 부모의 기본키·유일 키
```

## Ⅳ. 키 유형과 기본키 선정

학생(학번, 주민번호, 성명) 예: {학번}, {주민번호}는 유일성·최소성을 모두 만족하는 후보키이고, {학번, 성명}은 유일하지만 성명을 빼도 유일하므로 후보키가 아니라 슈퍼키.

| 키 | 정의·역할 | 관계 |
|---|---|---|
| 슈퍼키 | 튜플을 유일하게 식별 | 불필요한 속성 포함 가능 |
| 후보키 | 최소성을 갖춘 슈퍼키 | 기본키 또는 대체키로 선택 |
| 기본키 | 대표 식별자로 선택한 후보키 | 유일·비널 값 유지 |
| 대체키 | 기본키가 아닌 후보키 | 필요 시 유일성 제약 |
| 외래키 | 참조 릴레이션의 기본키·유일 키를 참조 | 릴레이션 간 참조 관계 |

| 기본키 선정 기준 | 설계 확인 |
|---|---|
| 유일성·최소성 | 모든 튜플 식별, 불필요한 속성 없음 |
| 안정성 | 업무 변경으로 키 값이 바뀔 가능성과 참조 범위 |
| 필수성 | 값이 비지 않도록 기본키 제약 |
| 구현 적합성 | 키 길이·자료형·인덱스·분산 생성 필요성 |

| 비교 | 자연키 | 대리키 |
|---|---|---|
| 성격 | 업무 규칙에 따른 의미 있는 속성 | 시스템이 부여한 의미 없는 값 |
| 장점 | 업무 식별 기준을 직접 표현 | 업무 속성 변경과 내부 참조를 분리 |
| 검토 | 안정성·민감 정보·업무상 유일성 | 생성 충돌·저장 비용, 업무상 유일성은 별도 제약 |
| 예 | 유일성이 확인된 업무 코드 | 시퀀스, UUID |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 변경·민감한 자연키를 내부 참조에 사용해 변경이 전파 | 대리키로 내부 식별, 업무 유일성은 별도 제약 |
| 대리키만 두고 업무 식별자 중복을 허용 | 업무상 유일한 속성 조합에 유일성 제약 |

## Ⅵ. 제언

내부 참조는 안정적인 기본키(대리키)로 하고 업무 식별자에는 유일성 제약을 함께 두어 식별과 업무 규칙을 분리

```text
후보키 도출 → 안정성·민감도 평가 → 기본키(필요 시 대리키) → 업무 식별자 유일 제약 → 외래키 정의
```

| 구분 | 자연키를 그대로 기본키 | 제언: 대리키 + 업무 유일 제약 |
|---|---|---|
| 변경 영향 | 참조 전파 | 내부 참조 분리 |
| 업무 규칙 | 직접 표현 | 제약으로 보존 |
