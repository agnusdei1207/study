## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 보호·활용 → **가명정보 결합·비정형 가명처리**

## 30초 인출

- 본질: 비정형 데이터 가명처리는 텍스트·이미지·영상·음성에 담긴 직접·간접 식별 단서를 목적과 이용 환경에 맞게 변환해 재식별 위험을 통제하는 처리
- 메커니즘: 활용 주체(내부·제3자 제공)와 처리 환경의 통제 가능성으로 위험도를 판단하고, 매체별로 식별 단서를 변환한 뒤 표본 검수로 잔여 단서와 유용성을 확인
- 통찰: 비정형 데이터는 식별 단서가 필드가 아닌 내용과 맥락에 흩어져 전수 확인이 어려우므로 위험도에 따라 검수 수준을 정하고 표본 검수 결과를 추가 점검에 되먹임

<details>
<summary>핵심 용어</summary>

- **가명처리** : 추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인정보를 처리하는 것
- **비정형 데이터** : 텍스트·이미지·영상·음성처럼 고정된 필드 구조가 없는 데이터
- **직접·간접 식별 단서** : 그 자체로 또는 다른 정보와 결합해 개인을 알아볼 수 있게 하는 정보
- **위험도 기반 체계** : 활용 주체와 처리 환경에 따라 위험도를 구분해 조치 수준을 정하는 방식
- **표본 검수** : 대규모 데이터에서 일부를 선별해 처리 결과를 검수하는 방식
- **가명정보 결합** : 서로 다른 가명정보를 전문기관이 결합하는 절차

</details>

## 2~4교시 25점 답안

## Ⅰ. 비정형 데이터 가명처리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비정형 데이터 가명처리** 는 텍스트·영상·음성의 식별 단서를 목적과 이용 환경에 맞게 변환하는 처리 |
| 목적 | 연구·통계 등 허용 목적의 활용과 재식별 위험 통제 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 비고정 식별 단서 | 얼굴·발화뿐 아니라 배경·문맥의 간접 단서까지 검토 |
| 매체별 잔존 위험 | 매체마다 탐지 누락과 변환 후 유용성 확인 필요 |
| 이용 환경 의존 | 같은 자료라도 목적·이용자·접근 통제에 따라 위험 판단이 달라짐 |

## Ⅲ. 위험도 판단과 처리 절차

개인정보보호위원회는 2026년 3월 가명정보 처리 가이드라인을 개정해 활용 주체와 처리 환경을 기준으로 위험도를 구분하는 체계를 도입.

| 위험 판단 | 기본 검토 방향 |
|---|---|
| 내부 활용(저위험) | 외부 제공 위험이 없는지 확인 |
| 제3자 제공, 통제 가능 환경(중위험) | 제공 후 접근·저장·반출 통제 가능성 검토 |
| 제3자 제공, 통제 곤란 환경(고위험) | 노출·연계 위험을 엄격히 검토하고 조건 재설계 |

```text
처리 목적·대상 확정 → 직접·간접 식별 단서와 결합 위험 확인
        ↓
활용 주체·환경별 위험도 판단 → 매체별 변환
        ↓
표본 검수로 잔여 단서·유용성 확인 → 접근·반출 통제 확정
```

## Ⅳ. 매체별 처리

| 데이터 | 식별 단서 예 | 처리·검수 방향 |
|---|---|---|
| 텍스트 | 직접 식별자, 희귀한 사건·장소의 조합 | 패턴 탐지와 문맥 검토 병행, 의미 손실 확인 |
| 이미지 | 얼굴, 문신, 표지판, 화면 속 정보 | 변환 후 잔존 단서 검토 |
| 영상 | 프레임마다 반복·이동하는 단서 | 프레임 연속성과 누락 구간 확인 |
| 음성 | 발화 내용, 화자 특성 | 내용과 음향 단서를 나눠 검토 |

특정 탐지 모델·마스킹 기법은 선택지일 뿐 고정된 필수 기술이 아니므로 데이터와 목적에 맞춰 결정.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 대규모 비정형 데이터의 전수 확인 시간·비용 | 위험도에 맞춰 표본 검수 수준을 정하고 발견된 오류를 추가 점검에 반영 |
| 가명처리 뒤에도 문맥·배경 단서 잔존 | 고위험 사례를 표본에 포함해 확인하고 변환 범위·이용 환경 조정 |

## Ⅵ. 제언

위험도로 검수 수준과 이용 환경 통제를 정하고, 표본 검수 결과를 처리 규칙에 되먹임

```text
위험도 판단 → 변환 → 표본 검수 → 오류 발견 시 규칙 보완 → 재검수
```

| 구분 | 획일적 전수 처리 | 제언: 위험도 기반 처리 |
|---|---|---|
| 비용 | 큼 | 위험도에 비례 |
| 위험 통제 | 환경 무시 | 환경별 통제 |

## 출제 이력과 검증 출처

- Q-net 기출 원문에서 직접 묻는 문항 없음
- 개인정보보호위원회, 가명정보 처리 가이드라인(2026.3. 개정)
