## 연관 키워드
- 가명 정보, 추가 정보, 결합 전문 기관, 비정형 데이터, 재식별 위험, 개인 정보 보호 법

### Ⅰ. 가명 정보 결합·비정형 가명 처리의 개요

- 핵심 요약 : 가명 처리는 추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인 정보를 대체·삭제·변환하는 처리이며 결합과 비정형 처리는 별도 위험 통제가 필요.
- 개념 : 가명 처리는 추가 정보 없이는 특정 개인을 알아볼 수 없도록 개인 정보를 대체·삭제·변환하는 처리이며 결합과 비정형 처리는 별도 위험 통제가 필요(**가명 정보 결합·비정형 가명 처리**, Pseudonymized Data Combination and Unstructured Data Anonymization).
- 배경 및 필요성 : 데이터 활용·결합 수요와 재식별·민감 정보 노출 위험을 함께 관리해야 함.
- 주요 목적 : 법적 요건을 지키며 통계·연구·공익적 기록 보존 등의 허용 목적에서 안전한 활용 지원.

### Ⅱ. 가명 정보 결합·비정형 가명 처리의 특징 및 장점

- 핵심 요약 : 목적·최소성·분리 보관·결합 통제는 데이터 노출과 재식별 연결 위험을 축소하는 데이터 처리 원칙.

1. 목적·최소성 : 허용된 목적과 필요한 항목만 처리 → 노출·과잉 처리 축소.
2. 분리 보관 : 가명 정보와 추가 정보 분리·접근 통제 → 재식별 연결 위험 감소.
3. 결합 통제 : 개인 정보 보호 법상 결합 전문 기관 등 절차 준수 → 외부 결합 위험 통제.

### Ⅲ. 가명 정보 결합·비정형 가명 처리 구조 (흐름)

- 핵심 요약 : 목적·법적 근거 검토 → 데이터 최소화·위험 분석 → 가명 처리·추가 정보 분리 → 결합 전문 기관 절차(해당 시) → 반출 심사·접근 통제·파기.

```text
목적·법적 근거 검토
  ↓
데이터 최소화·위험 분석
  ↓
가명 처리·추가 정보 분리
  ↓
결합 전문 기관 절차(해당 시)
  ↓
반출 심사·접근 통제·파기
```

```text
원본 개인 정보
    ↓ 식별자·문맥 검출 및 가명 처리
가명 정보 ─ 별도 관리 ─ 추가 정보
    ↓ 안전한 결합·반출 심사
목적 내 분석·접근 기록·파기
```

### Ⅳ. 가명 정보와 익명 정보 비교

- 핵심 요약 : 보호 수준 기준 — 가명 정보: 개인 정보 보호 법 적용 대상이며 안전 조치 의무; 익명 정보: 개인 정보에 해당하지 않음(재식별 가능성 평가 전제).

| 비교 축 | 가명 정보 | 익명 정보 |
|---|---|---|
| 재식별 가능성 | 추가 정보 없이는 식별하기 어렵지만 재식별 가능성 잔존 | 합리적으로 예상 가능한 방법으로 개인 식별 불가 |
| 보호 수준 | 개인 정보 보호 법 적용 대상이며 안전 조치 의무 | 개인 정보에 해당하지 않음(재식별 가능성 평가 전제) |

### Ⅴ. 가명 정보 결합·비정형 가명 처리의 한계와 방안

- 핵심 요약 : 문맥 재식별·비정형 식별자 잔존 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 문맥 재식별 | 희귀 사건·조합 식별자가 개인을 드러냄 | 공격자 관점 위험 평가·일반화·억제·출력 검토 | 재식별 위험 |
| 비정형 식별자 잔존 | 자유 서술·메타데이터·음성·이미지에 직접 식별 정보 포함 | 텍스트·미디어 자동 검출·사람 표본·전수 검수 | 잔존 식별자 |
| 결합·반출 통제 실패 | 결합 키·추가 정보 유출 또는 승인 범위 초과 | 전문 기관 절차·반출 심사·접근 기록·파기 확인 | 통제 위반 건수 |

### Ⅵ. 가명 정보 결합·비정형 가명 처리에 대한 제언

- 핵심 요약 : 개인 정보 보호 책임자는 개인 정보 보호 법상 허용 목적·처리 근거를 확인하고 재식별 금지, 추가 정보 분리, 결합 전문 기관 절차(해당 시), 반출 심사·파기 증거를 통합 관리.

- 실행 제안 : 개인 정보 보호 책임자는 비정형 원문·메타데이터의 식별자 검수와 반출 전 위험 심사를 담당자·증거와 함께 관리.

### Ⅶ. 결론

- 핵심 요약 : 가명 처리는 익명화가 아니며 결합·비정형 자료에서 남는 맥락 식별 위험까지 통제해야 적법하고 안전한 활용 가능.
- 시사점 : 가명 처리된 정보도 재식별 위험이 남는 개인 정보이므로 허용 목적·안전 조치·결합 절차 준수 필요.
