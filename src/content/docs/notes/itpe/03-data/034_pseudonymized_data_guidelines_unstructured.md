## 연관 키워드

- 가명정보, 가명처리, 통계작성·과학적 연구·공익적 기록보존, 결합전문기관, 반출 심사
- 추가정보 분리, 비정형 데이터(Unstructured Data), k-익명성, l-다양성, t-근접성

## Ⅰ. 가명정보와 비정형 가명처리의 개요

- 핵심 요약 : 추가 정보 없이는 특정 개인을 알아볼 수 없도록 처리한 개인정보로, 법정 목적과 안전조치 아래 활용하는 제도.
- 개념 : 「개인정보 보호법」상 **가명정보**는 추가 정보의 사용·결합 없이는 특정 개인을 알아볼 수 없도록 처리한 정보이며, **가명처리**는 식별 요소를 삭제하거나 대체하여 식별 위험을 낮추는 조치.
- 배경 및 필요성 : 개인정보를 원본 그대로 활용하면 정보주체의 권리 침해 위험이 크고, 전면 금지하면 통계·연구 활용이 막히는 상황에서 중간 지점의 관리 체계가 필요.
- 활용 목적 : 법정 목적인 **통계작성**, **과학적 연구**, **공익적 기록보존**에 한해 정보주체 동의 없이 가명정보를 처리할 수 있음.
- 비정형 데이터 : 문장 맥락, 얼굴, 음성, 배경처럼 정형 필드 밖에 식별 단서가 담길 수 있어 매체별 검토가 필요.
- 근거 : [「개인정보 보호법」 제28조의2](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=02&joNo=0028&lsiSeq=283839), [가명정보의 결합 및 반출 등에 관한 고시](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000235874), [시행령 제29조의3](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=159007), [시행령 제29조의5](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=159009).

## Ⅱ. 가명정보 처리의 특징 및 장점

- 핵심 요약 : 직접 식별자를 가리는 데서 나아가 추가 정보와의 결합 가능성까지 포함한 재식별 위험을 관리하는 방식.

1. 목적 제한 : 동의 없는 처리를 법정 목적 범위로 한정 → 활용 범위가 정해져 무분별한 재사용을 줄임.
2. **추가정보 분리** : 가명정보와 재식별에 쓰일 추가 정보를 나누어 보관 → 한쪽이 유출되어도 개인 식별 가능성을 낮춤.
3. 결합 통제 : 서로 다른 개인정보처리자 간 결합은 지정된 **결합전문기관**을 거쳐 수행 → 기관 간 데이터 결합 위험을 한곳에서 관리.
4. 반출 심사 : 결합된 자료를 외부로 내보낼 때 승인 절차를 거침 → 반출 이후의 재식별 위험을 사전에 차단.

## Ⅲ. 가명정보 결합·반출과 비정형 처리의 흐름

- 핵심 요약 : 목적과 법적 근거 확인에서 시작해 가명처리, 결합, 반출 심사, 파기로 이어지는 단계별 관리.

```text
[ 가명정보 처리 흐름 ]
목적·법적 근거 확인
   ↓
식별 위험 분석과 가명처리
   ↓
기관 간 결합 필요 여부 판단
   ↓ 결합이 필요한 경우
결합전문기관 신청
   ↓
결합·추가 가명처리 (안전한 공간)
   ↓
반출 심사·승인
   ↓
목적 달성 후 파기
```

- 결합 자료를 전문기관 밖으로 내보내려면 안전한 공간에서 추가 가명처리를 마친 뒤 **반출 심사**를 받아야 한다.
- 텍스트는 이름·기관·장소의 문맥적 조합을, 영상은 얼굴·번호판·배경을, 음성은 발화 내용과 화자 특성을 검토해야 한다.
- 해시 처리나 블러링만으로 가명처리가 끝나는 것은 아니며, 결합 가능성과 잔여 식별 위험을 함께 평가해야 한다.

## Ⅳ. 매체별 처리와 위험 비교

- 핵심 요약 : 매체마다 다른 식별 단서에 맞춰 변환 방법과 검수 방법을 골라야 함.

| 매체 | 주요 식별 단서 | 처리 예시 | 검수 유의점 |
| :--- | :--- | :--- | :--- |
| 텍스트 | 이름, 주소, 희귀 사건·직업의 조합 | 탐지·마스킹·범주화 | 문맥과 간접 식별자 재검토 |
| 이미지·영상 | 얼굴, 번호판, 화면·배경 정보 | 흐림·가림·프레임별 검사 | 일부 프레임 누락과 반사상 |
| 음성 | 발화 내용, 화자의 음성 특성 | 구간 삭제·변조·대체 음성 | 변조 후에도 화자를 식별할 가능성 |
| 결합 데이터 | 준식별자 조합, 외부 공개 자료 | 범주화·표본 제한·접근 통제 | 다른 자료와의 연결 위험 |

- k-익명성(k-anonymity), l-다양성(l-diversity), t-근접성(t-closeness)은 위험 분석의 참고 기법일 뿐, 어느 한 지표만으로 재식별 안전을 보증하지 않는다.

## Ⅴ. 가명처리의 한계와 방안

- 핵심 요약 : 잔여 식별 위험, 분석 유용성 저하, 결합 오남용을 함께 통제해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 문맥 단서 누락 | 자동 탐지가 간접 식별자를 놓쳐 잔여 식별 위험 발생 | 자동 탐지 후 사람이 표본 검수, 희귀 조합 재평가 | 누락 탐지율, 검수 불일치율 |
| 과도한 삭제·변형 | 필요 이상의 변환으로 분석 품질 저하 | 목적에 필요한 최소 정보만 남기고 분석 품질로 처리 수준 조정 | 분석 정확도, 변환 항목 수 |
| 추가정보 유출 | 가명정보와 추가 정보의 분리가 무너져 재식별 가능 | 분리 보관, 권한·반출·접속 기록 관리 | 접근 기록 이상 건수 |
| 결합 후 위험 증가 | 여러 자료가 합쳐져 재식별 가능성이 커짐 | 결합 목적과 항목 최소화, 전문기관 절차 준수 | 결합 항목 수, 반출 승인 건수 |

```text
[ 한계 통제 구조 ]
식별 단서 잔존 → 매체별 탐지와 사람 검수
유용성 저하   → 목적별 최소 변환과 품질 검증
결합 위험 증가 → 전문기관 결합과 반출 심사
```

## Ⅵ. 가명정보 처리에 대한 기술사적 제언

- 핵심 요약 : 처리 이력을 기록하고 자동 탐지 결과를 사람의 검수와 결합하여 비정형 가명처리의 재식별 위험을 관리하는 체계.

1. 가명처리 담당 조직은 원본, 가명정보, 추가 정보를 분리 보관하고, 역할 기반 접근통제와 반출 승인 절차를 상시 운영해야 한다.
2. 데이터 품질 담당 조직은 자동 탐지 모델의 정밀도와 재현율을 매체별로 점검하고, 누락 유형이 확인되면 사람 검수의 표본을 늘려야 한다.
3. 데이터 거버넌스 조직은 모델 학습이나 검색 증강 같은 2차 활용에 앞서 법정 목적과 처리 근거를 확인하고, 데이터 최소화, 보유 기간, 파기 기준을 정해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 가명정보 제도는 활용을 허용하면서 목적 제한, 결합 통제, 안전조치를 함께 요구하는 제도.
- 시사점 : 비정형 데이터의 문맥 단서와 결합 후 재식별 위험까지 관리해야 제도의 취지가 지켜짐.
