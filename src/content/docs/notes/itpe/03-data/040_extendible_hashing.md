## 연관 키워드
- 확장성 해싱, 디렉터리, 전역 깊이, 지역 깊이, 버킷 분할, 해시 인덱스

### Ⅰ. 확장성 해싱의 개요

- 핵심 요약 : 확장성 해싱은 디렉터리와 버킷의 깊이를 동적으로 조정해 파일 전체 재구성 없이 해시 파일을 확장하는 방식.
- 개념 : 디렉터리와 버킷의 깊이를 동적으로 조정해 파일 전체 재구성 없이 해시 파일을 확장하는 방식(**확장성 해싱**, Extendible Hashing).
- 배경 및 필요성 : 정적 해싱의 오버플로 버킷 누적과 전체 재해싱 비용 문제.
- 주요 목적 : 데이터 증가에 국소적으로 대응하는 동적 동등검색 구조.

### Ⅱ. 확장성 해싱의 특징 및 장점

- 핵심 요약 : 디렉터리·지역 깊이·버킷 분할·디렉터리 확장은 데이터 증가에 국소적으로 대응하는 동적 동등검색 구조를 제공하는 확장성 해싱의 구성요소.

1. 디렉터리 : 해시 접두부로 버킷 지정 → 직접 주소 결정.
2. 지역 깊이 : 버킷이 구별하는 비트 수 → 국소 분할 기준.
3. 버킷 분할·디렉터리 확장 : 깊이 초과 시 디렉터리 두 배 → 분할 범위 최소화.

### Ⅲ. 확장성 해싱의 구조 (흐름)

- 핵심 요약 : 키 해시값 계산 → 전역 깊이 비트로 디렉터리 탐색 → 버킷 삽입·검색 → 용량 초과 시 버킷 분할 → 지역 깊이 초과 시 디렉터리 확장.

```text
키 해시값 계산
   ↓
전역 깊이 비트로 디렉터리 탐색
   ↓
버킷 삽입·검색
   ↓
용량 초과 시 버킷 분할
   ↓
지역 깊이 초과 시 디렉터리 확장
```

```text
해시 키 → 디렉터리(전역 깊이) → 버킷
버킷 포화 → 분할
지역 깊이 > 전역 깊이 조건에서 디렉터리 확장
```

### Ⅳ. 확장성 해싱과 정적 해싱 비교

- 핵심 요약 : 접근비용 기준 — 확장성 해싱: 보통 디렉터리 접근+버킷; 정적 해싱: 버킷 수·오버플로 체인 영향.

| 비교 축 | 확장성 해싱 | 정적 해싱 |
|---|---|---|
| 확장 방식 | 버킷·디렉터리 국소 확장 | 전체 파일 재해싱 또는 오버플로 연결 |
| 접근비용 | 보통 디렉터리 접근+버킷 | 버킷 수·오버플로 체인 영향 |

### Ⅴ. 확장성 해싱의 한계와 방안

- 핵심 요약 : 디렉터리 메모리·버킷 편향·범위검색 취약 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 디렉터리 메모리 | 키 분포가 나쁘면 디렉터리 크기 급증 | 전역·지역 깊이와 버킷 점유 관측 | 디렉터리 크기 |
| 버킷 편향 | 해시 충돌로 분할 후에도 분포 불균형 | 해시 함수·용량·충돌 부하 평가 | 오버플로율 |
| 범위검색 취약 | 해시 순서가 키 순서를 보존하지 않음 | 범위 질의는 B+Tree 등 별도 구조 사용 | 범위검색 비용 |

### Ⅵ. 확장성 해싱에 대한 기술사적 제언

- 핵심 요약 : DB 엔진 설계자는 키 분포·버킷 점유·디렉터리 증폭을 측정하고 동등검색과 범위검색의 인덱스 요구를 분리할 필요가 있다.

- 실행 제안 : 저장엔진 설계자는 버킷 점유·지역/전역 깊이·디렉터리 메모리를 관측하고 범위검색은 정렬 인덱스로 분리하는 것이 바람직하다.

### Ⅶ. 결론

- 핵심 요약 : 확장성 해싱은 동등검색의 동적 확장을 제공하지만 정렬·범위검색을 지원하는 구조와는 목적이 다름.
- 시사점 : 동등검색에는 동적 확장이 유리하지만 순서·범위 질의는 정렬 인덱스로 분리하는 편이 적합함.
