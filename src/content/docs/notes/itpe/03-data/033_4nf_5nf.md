## Ⅰ. 고차 정규화의 개요: 4NF와 5NF

### 가. 고차 정규형(Higher Normal Forms)의 필요성
- 관계형 데이터 모델에서 BCNF(보이스-코드 정규형)까지 달성하더라도, 함수적 종속성(FD) 이외의 **다치 종속성(MVD)** 이나 **조인 종속성(JD)** 이 잔존할 경우 데이터의 불필요한 중복과 이상 현상이 여전히 발생함.
- 제4정규형(4NF)은 다치 종속성을 제거하고, 제5정규형(5NF, PJNF)은 무손실 조인 종속성을 제거하여 궁극적인 데이터 무결성을 달성하는 고차 정규화 이론.

## Ⅱ. 제4정규형(4NF)과 다치 종속성(MVD)의 분석

### 가. 다치 종속성(Multivalued Dependency, MVD)의 정의
- 릴레이션 $R$의 속성 집합 $X, Y, Z$에 대하여, $X$의 하나의 값에 대응하는 $Y$의 값들의 집합이 오직 $X$에 의해서만 결정되고 $Z$의 값과는 상호 독립적일 때 성립하며, $X \twoheadrightarrow Y$로 표기함.

### 나. 4NF 위반 사례 및 분해 메커니즘

```text
[ 4NF 위반 릴레이션: 개발자스킬 (복합키: 개발자 + 프로그래밍언어 + 담당언어) ]
  개발자   | 프로그래밍언어 | 보유자격증
  --------+----------------+------------
  김수석   | Java           | 정보처리기사
  김수석   | Java           | PMP
  김수석   | Python         | 정보처리기사  <-- 언어와 자격증 간 무관함에도
  김수석   | Python         | PMP          <-- 모든 조합이 중복 저장됨 (MVD 발생)
```

- **문제점** : 개발자가 새 언어 1개를 추가하면 자격증 개수만큼 레코드를 $N$개 삽입해야 하는 삽입 이상 발생.
- **4NF 달성 조건** : 비사소한 다치 종속성 $X \twoheadrightarrow Y$가 성립할 때, $X$가 $R$의 슈퍼키(Super Key)여야 함.
- **분해 결과** : `[개발자, 프로그래밍언어]` 테이블과 `[개발자, 보유자격증]` 테이블로 무손실 분해.

## Ⅲ. 제5정규형(5NF, PJNF)과 조인 종속성(JD)의 분석

### 가. 조인 종속성(Join Dependency, JD)의 개념
- 릴레이션 $R$이 $n$개의 프로젝션 $R_1, R_2, \dots, R_n$으로 분해되었다가 자연 조인($\bowtie$)되었을 때, 가짜 튜플(Spurious Tuple)의 생성 없이 원래의 릴레이션 $R$로 완벽히 복원될 때 성립: $\bowtie (R_1, R_2, \dots, R_n) = R$.
- 2개로 분해하면 원래대로 복원되지 않고(무손실 조인 불가), **반드시 3개 이상으로 동시에 분해해야만** 무손실 복원이 가능한 특별한 삼항 관계(Ternary Relationship) 구조에서 발생.

### 나. 5NF (Projection-Join Normal Form) 판정 조건

```text
[ 5NF 달성 조건 ]
릴레이션 R에 존재하는 모든 비사소한 조인 종속성 *(R1, R2, ..., Rn)에 대하여,
모든 R_i의 속성 집합이 R의 슈퍼키(Super Key)를 포함해야 함.
```

```text
[ 3개 테이블 분해 예시: 공급자-부품-프로젝트 ]
원본: (공급자, 부품, 프로젝트) -> 3자 간 복합 순환 제약 존재
  ===> [공급자, 부품] owtie [부품, 프로젝트] owtie [공급자, 프로젝트]
```

## Ⅳ. 고차 정규화 적용 시의 실무 제언

- **실무 엔지니어링에서의 비용 대비 효익 평가** : 이론적으로 4NF와 5NF는 완벽한 무결성을 제공하지만, 테이블 수가 폭발적으로 증가하고 단일 조회가 3~4중 조인으로 변환되어 심각한 성능 저하를 유발함.
- **실무 권장 설계 가이드** : 엔터프라이즈 RDBMS 모델링에서는 **BCNF 또는 3NF까지만 달성하는 것을 기본 표준** 으로 삼고, MVD나 JD가 존재하는 특수 도메인은 테이블 분해 대신 복합 체크 제약조건, 트리거 또는 애플리케이션 유효성 검증 계층에서 방어할 것을 제언함.
