## 지식 로드맵 내 현재 위치

자료처리·데이터 → 관계형 데이터 모델링 → **제4정규형·제5정규형**

## 30초 인출

- 본질: 제4정규형·제5정규형은 함수적 종속으로는 잡히지 않는 다치 종속과 조인 종속에서 생기는 중복을 줄이는 고급 정규형
- 메커니즘: BCNF를 만족한 릴레이션에서 서로 독립적인 다중값(다치 종속)은 4NF로, 후보키로 함의되지 않는 조인 종속은 5NF로 분해하고 재조인 결과를 검증
- 통찰: 독립성과 조인 종속은 업무 의미로만 판단할 수 있으므로 도메인 규칙과 실제 데이터로 무손실을 검증하고, 중복·갱신 이상이 확인된 관계에만 적용

<details>
<summary>핵심 용어</summary>

- **다치 종속(MVD, X →→ Y)** : X 값에 대응하는 Y 값 집합이 다른 속성과 독립적으로 결정되는 종속
- **제4정규형(4NF)** : BCNF이면서 비자명한 다치 종속의 결정자가 슈퍼키인 정규형
- **조인 종속(Join Dependency)** : 릴레이션을 여러 투영으로 나누었다가 조인하면 원래 릴레이션이 복원되는 제약
- **제5정규형(5NF, PJNF)** : 모든 비자명한 조인 종속이 후보키에 의해 함의되는 정규형
- **무손실 분해** : 분해 후 조인하면 원래 릴레이션을 정확히 복원하는 분해
- **허위 튜플(Spurious Tuple)** : 분해 후 조인에서 원래 없던 행이 생기는 현상

</details>

## 2~4교시 25점 답안

## Ⅰ. 제4정규형·제5정규형의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **제4정규형·제5정규형** 은 함수적 종속 외에 다치 종속·조인 종속으로 생기는 중복을 줄이는 고급 정규형 |
| 목적 | 독립적인 다중값 사실과 불필요한 관계 조합의 중복 감소 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 함수 종속 이후의 검토 | 3NF·BCNF를 만족해도 다치·조인 종속에 따른 중복 가능 |
| 의미 기반 분해 | 값 집합의 독립성과 조인 종속을 업무 규칙으로 확인 |
| 복원성 검증 | 분해 후 조인 결과가 원래 사실과 일치해야 함 |

## Ⅲ. 종속 식별과 분해 절차

```text
BCNF 릴레이션
   ↓
독립적인 다중값(다치 종속)? ─ 예 → 4NF 분해
   │ 아니오
   ↓
후보키로 함의되지 않는 조인 종속? ─ 예 → 5NF 분해
   │ 아니오
   ↓
현재 형태 유지
```

### 4NF 분해 예

```text
직원 →→ 언어, 직원 →→ 자격증 (두 목록이 서로 독립)
  → 모든 언어·자격증 조합 행이 반복 저장
  ↓ 분해
(직원, 언어) + (직원, 자격증) → 조인 시 원래 조합이 정확히 복원되는지 검증
```

## Ⅳ. 4NF·5NF의 비교

| 정규형 | 다루는 종속 | 줄이려는 중복 |
|---|---|---|
| 3NF·BCNF | 함수적 종속 | 키와 속성 사이의 부적절한 종속 |
| 4NF | 다치 종속 | 독립적인 다중값 집합의 조합 |
| 5NF | 조인 종속 | 더 작은 관계로 분리 가능한 결합 사실 |

| 확인 대상 | 판단 근거 |
|---|---|
| 업무 규칙 | 다중값 집합의 독립성 |
| 데이터 중복 | 조합마다 같은 사실 반복 여부 |
| 무손실성 | 분해·재조인 시 원래 사실만 복원 |
| 운영 비용 | 분해 후 조인·제약 관리 비용 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 예시의 독립성을 실제 업무에도 가정 | 도메인 전문가와 관계의 의미 확인 |
| 조인 종속을 추정만 하고 분해 | 실제 데이터·업무 규칙으로 무손실 검증 |
| 모든 테이블에 기계적으로 적용 | 중복·갱신 이상이 있는 관계부터 검토 |

## Ⅵ. 제언

BCNF까지 정규화한 뒤 중복·갱신 이상이 확인된 관계에만 4NF·5NF를 적용하고 무손실 조인을 검증

```text
BCNF → 이상 확인 → MVD면 4NF · 조인 종속이면 5NF → 재조인 검증
```

| 구분 | 모든 관계에 기계적 적용 | 제언: 이상 확인 후 적용 |
|---|---|---|
| 조인 비용 | 증가 | 필요한 곳만 증가 |
| 정합성 | 검증 부담 | 업무 규칙으로 검증 |
