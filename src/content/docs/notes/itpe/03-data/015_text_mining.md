## 30초 인출

- 본질: 텍스트 마이닝은 비정형 텍스트에서 패턴·주제·의견 같은 유용한 정보를 찾아내는 분석 기법
- 메커니즘: 텍스트를 형태소·단어로 나누고(토큰화) 불용어를 제거한 뒤 TF-IDF 같은 수치로 표현해 분류·군집·토픽 모델링·감성 분석에 적용
- 통찰: 단어 빈도만 쓰면 어느 문서에나 흔한 단어가 중요하게 보이므로 TF-IDF로 특정 문서에 집중된 단어의 가중치를 높여 특징을 표현

<details>
<summary>핵심 용어</summary>

- **텍스트 마이닝(Text Mining)** : 텍스트에서 유용한 정보를 추출하는 분석
- **토큰화(Tokenization)** : 텍스트를 단어·형태소 같은 분석 단위로 나누는 것
- **TF(Term Frequency)** : 한 문서 안에서 단어가 나타난 빈도
- **IDF(Inverse Document Frequency)** : 단어가 나타난 문서 수로 계산해 흔한 단어의 가중치를 낮추는 값
- **TF-IDF** : TF와 IDF의 곱으로 문서 내 단어의 중요도를 나타낸 값
- **토픽 모델링** : 문서 집합에서 함께 나타나는 단어 패턴으로 주제를 찾는 분석
- **감성 분석** : 텍스트에 담긴 의견의 긍정·부정 방향을 분석하는 작업

</details>

## 2~4교시 25점 답안

## Ⅰ. 텍스트 마이닝의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **텍스트 마이닝** 은 비정형 텍스트에서 패턴·주제·의견을 찾아내는 분석 기법 |
| 목적 | 문서·댓글·리뷰 등 텍스트 데이터의 정보 활용 |

## Ⅱ. 정형 데이터 분석과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 비정형 데이터 | 구조가 없는 텍스트 |
| 전처리 필요 | 분석 전 수치 표현으로 변환 |
| 언어 의존 | 형태소·불용어 등 언어별 처리 |

## Ⅲ. 절차와 TF-IDF

### 텍스트 마이닝 절차

```text
수집 → 정제(불용어·특수문자 제거) → 토큰화(형태소 분석)
        ↓
수치 표현(TF-IDF·임베딩) → 분석(분류·군집·토픽·감성) → 해석
```

### TF-IDF 계산

```text
TF(t, d)  = 문서 d에서 단어 t의 출현 횟수 (또는 전체 단어 수로 나눈 비율)
IDF(t)    = log( 전체 문서 수 N / 단어 t가 나타난 문서 수 DF(t) )
TF-IDF    = TF × IDF

예) 문서 3개, '데이터'가 3개 문서 모두에 등장 → IDF = log(3/3) = 0 → 가중치 0
    '군집'이 1개 문서에만 등장           → IDF = log(3/1) → 가중치 큼
```

## Ⅳ. 분석 기법

| 기법 | 내용 |
|---|---|
| 문서 분류 | 문서를 미리 정한 범주로 분류 |
| 군집화 | 유사한 문서끼리 묶음 |
| 토픽 모델링 | 문서 집합의 주제 도출 |
| 감성 분석 | 긍정·부정 의견 판별 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 흔한 단어가 중요하게 보이는 단순 빈도의 한계 | TF-IDF로 가중치 조정 |
| 동의어·문맥을 반영하지 못함 | 임베딩 등 문맥 표현 적용 |
| 언어·도메인별 전처리 부담 | 불용어·사전을 도메인에 맞게 관리 |

## Ⅵ. 제언

단어 빈도 대신 TF-IDF로 문서를 표현하고, 문맥이 중요한 과제는 임베딩을 추가

```text
빈도 기반 표현 → TF-IDF로 가중치 조정 → 필요 시 임베딩으로 문맥 반영
```

| 구분 | 단어 빈도만 사용 | 제언: TF-IDF 사용 |
|---|---|---|
| 흔한 단어 | 과대 반영 | 가중치 감소 |
| 문서 특징 | 흐려짐 | 두드러짐 |
