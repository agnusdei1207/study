## 지식 로드맵 내 현재 위치
```text
데이터 분석 → 비정형 데이터 분석 → 텍스트 마이닝
```

## 큰 그림과 30초 인출
```text
[문서] → 수집·정제 → 토큰화·형태소 → 표현(TF-IDF/Embedding)
       → 분류·군집·토픽·감성 → 평가 → 검색·추천·VOC
```
- 본질: **비정형 텍스트를 처리 가능한 표현으로 변환하여 패턴·주제·감성·관계를 발견하는 분석 과정**
- 암기: `수-전-표-분-평-활` = 수집 → 전처리 → 표현 → 분석 → 평가 → 활용

## 예상문제
> 텍스트 마이닝의 처리 절차와 핵심 기법을 설명하고 TF-IDF의 원리, 임베딩과의 차이 및 실무 고려사항을 논하시오. (25점)

## Ⅰ. 비정형 언어를 분석 자산으로 바꾸는 텍스트 마이닝 개요
- 정의: 자연어 문서에서 통계·언어처리·기계학습으로 유용한 정보와 지식을 추출하는 활동
- 대상: 문서·민원·뉴스·로그·SNS·상담 기록
- 활용: 검색, 문서분류, 토픽·감성분석, 요약, 추천, 위험 신호 탐지

## Ⅱ. 텍스트 데이터의 특성과 분석 계층
| 특성 | 문제 | 대응 |
|---|---|---|
| 비정형·고차원 | 희소 단어 공간 | 어휘 정제·차원축소·임베딩 |
| 문맥·중의성 | 같은 단어의 의미 변화 | 문맥 모델·도메인 사전 |
| 순서·구문 | Bag-of-Words의 순서 손실 | n-gram·Sequence 모델 |
| 언어 변화 | 신조어·오탈자·Drift | 사전·모델·평가셋 갱신 |

## Ⅲ. 표현기법과 TF-IDF
```text
TF(t,d) = 문서 d에서 단어 t 빈도
IDF(t)  = log(N / DF(t))
TF-IDF  = TF(t,d) × IDF(t)
```
| 표현 | 원리 | 강점 | 한계 |
|---|---|---|---|
| Bag-of-Words | 단어 빈도 벡터 | 단순·설명 용이 | 순서·문맥 손실 |
| TF-IDF | 문서 내 빈도×희소성 | 핵심어 강조 | 동의어·의미 미반영 |
| Embedding | 단어·문장을 밀집 벡터화 | 의미·유사도 반영 | 해석·편향·비용 |

## Ⅳ. 텍스트 마이닝 절차
```text
① 목적·말뭉치 → ② 수집·비식별 → ③ 정제·토큰화·형태소
 → ④ 특징 표현 → ⑤ 모델링 → ⑥ 정량·정성 평가 → ⑦ 배포·Drift 관리
```
- 학습·검증 분할 전에 중복 문서와 시간 누수를 제거
- 분류는 Precision·Recall·F1, 토픽은 일관성·현업 해석성으로 검증

## Ⅴ. 대표 분석기법 비교
| 기법 | 목표 | 대표 방법 |
|---|---|---|
| 문서분류 | 사전 정의 범주 예측 | Naive Bayes·SVM·Transformer |
| 군집·토픽 | 잠재 주제 탐색 | k-means·LDA |
| 감성분석 | 극성·감정 추정 | 사전·지도학습 |
| 정보추출 | 개체·관계 식별 | NER·Relation Extraction |

## Ⅵ. 실무 고려사항
| 문제 | 원인 | 대책 |
|---|---|---|
| 개인정보 노출 | 원문에 식별정보 포함 | 최소수집·비식별·접근통제 |
| 도메인 오분류 | 일반 말뭉치와 용어 차이 | 도메인 사전·표본 검수 |
| 데이터 누수 | 중복·미래 문서 혼입 | 시간 기준 분할·중복 제거 |
| 설명 곤란 | 밀집 표현·복합 모델 | 근거 문장·오류유형 분석 |

## Ⅶ. 언어 품질과 평가셋을 함께 운영하는 결론
- 모델보다 말뭉치 정의·라벨 기준·전처리 재현성이 텍스트 분석 품질의 기준선
- 운영 피드백으로 어휘·라벨·평가셋을 갱신해 언어 변화에 대응

## 1교시 10점 답안 발췌
```text
문서 → 전처리 → TF-IDF/Embedding → 분석 → 평가 → 활용
TF-IDF = TF(t,d) × log(N/DF(t))
```
| TF-IDF | Embedding |
|---|---|
| 희소·설명 용이·문맥 약함 | 밀집·의미 반영·설명 부담 |
