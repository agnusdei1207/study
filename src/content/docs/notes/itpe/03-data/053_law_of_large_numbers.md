## 답안 골격
```text
[대수의 법칙] ◀━━ 머리: Ⅶ 내 의견 (빅데이터 통계 추정의 표본 수 산정 기준 확립 및 소표본 확증 편향 방지)
 ┃
 ┣━ Ⅰ 개요 ───── 표본의 크기($n$)가 커질수록 표본평균($\bar{X}$)이 모집단의 모평균($\mu$)에 수학적으로 수렴한다는 정리
 ┣━ Ⅱ 특징 ───── 극한 정리 · 점별/확률적 수렴 · 모평균 추정의 수학적 기초 · 몬테카를로 시뮬레이션 기반
 ┣━ Ⅲ 구조 ───── 약대수의 법칙(WLLN, 확률수렴) / 강대수의 법칙(SLLN, 거의 확실한 수렴) / 표본 크기($n \to \infty$)
 ┣━ Ⅳ 흐름 ───── ① 독립동일분포(i.i.d.) 표본 추출 → ② 표본 크기 $n$ 순차 증가 → ③ 분산($\sigma^2/n$) 감소 → ④ 표본평균이 모평균에 근접
 ┣━ Ⅴ 비교 ───── 대수의 법칙(LLN) vs 중심극한정리(CLT) (평균값의 모평균 수렴 vs 표본평균 '분포 형태'의 정규분포 수렴)
 ┗━ Ⅵ 실무 ───── 소표본 관측으로 인한 성급한 일반화(도박사의 오류) / 이상치 포함 시 수렴 지연
```
- 필수 키워드: 표본평균($\bar{X}$) · 모평균($\mu$) · 약대수의 법칙(WLLN) · 강대수의 법칙(SLLN) · 확률수렴 · i.i.d. · 중심극한정리(CLT)
- 기출: 139회 1교시 2번 `대수의 법칙과 중심극한정리` → Ⅰ 개념 + Ⅲ WLLN/SLLN + Ⅴ CLT와의 비교 및 관계

## 한 줄 본질
- 소수의 표본 관측에서 발생하는 심한 편차와 변동성 → 독립적 시행 횟수($n$)를 충분히 늘림으로써 우연 오차 상쇄 및 모평균 수렴 달성 → 통계적 추정의 객관성 확보 / 거대 표본 비용 필요

## 핵심 그림
```text
[시행 횟수(n) 증가에 따른 표본평균의 모평균 수렴 궤적]

 표본평균
 (X_bar)
   ^
   │   * (소표본: 심한 요동, 우연 오차 큼)
   │  / \
   │ /   \   *
   │/     \ / \      *  *
 ──┼───────*───\────*────*───*******───> 모평균 (μ = 0.5)
   │            *  /      *
   │             \/
   │
   0───────────────────────────────────> 시행 횟수 (n -> 무한대)
     (n = 10)     (n = 100)    (n = 10,000)
```

## 핵심 용어
- 약대수의 법칙(WLLN, Weak LLN): 임의의 양수 $\epsilon$에 대해 표본 크기 $n$이 커질 때 $|\bar{X}_n - \mu| < \epsilon$일 확률이 1로 수렴 ($\lim_{n \to \infty} P(|\bar{X}_n - \mu| < \epsilon) = 1$, 확률수렴)
- 강대수의 법칙(SLLN, Strong LLN): 표본 크기 $n$이 커질 때 표본평균이 모평균에 수렴할 확률 자체가 1 ($P(\lim_{n \to \infty} \bar{X}_n = \mu) = 1$, 거의 확실한 수렴)

## 핵심 통찰
- 대수의 법칙은 '결과값(점)'이 어디로 가는가를 말하고, 중심극한정리는 '분포(모양)'가 무엇으로 변하는가를 말함 → 두 정리는 통계학의 양대 기둥
- i.i.d.(독립동일분포) 전제가 깨지면 대수의 법칙은 성립하지 않음 → 이전 데이터가 다음 데이터에 영향을 주는 시계열이나 네트워크 데이터에서는 표본을 늘려도 엉뚱한 값으로 수렴 가능
- 평균과 분산이 무한대인 코시 분포(Cauchy Distribution) 같은 극단적 두꺼운 꼬리(Fat-tail) 데이터에서는 시행을 무한히 반복해도 모평균에 수렴하지 않음

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 몬테카를로 시뮬레이션 | 대수의 법칙을 이용한 수치해석 | 난수를 대량으로 생성하여 복잡한 적분값이나 확률 변수의 기댓값을 근사 추정 |
| 체비쇼프 부등식(Chebyshev's Inequality) | 약대수의 법칙 증명의 도구 | 평균과 분산만 알면 임의의 분포에서 특정 편차를 벗어날 확률의 상한을 제시 |

## 이웃 토픽과 구분
- 대수의 법칙 vs 중심극한정리: 대수의 법칙 = 표본평균 $\bar{X}$가 모평균 $\mu$라는 하나의 '상수'에 수렴 / 중심극한정리 = 표본평균의 표준화 변수가 $N(0, 1)$이라는 '정규분포'에 수렴
