## 연관 키워드

**DBMS 마이그레이션**, **벤더 종속성**, **스키마 변환**, **데이터 이관**, **CDC**, **성능 회귀**, **롤백**

## Ⅰ. 개요

- 핵심 요약 : **오픈소스 DBMS 마이그레이션**은 기존 데이터베이스의 구조·데이터·응용 로직을 목표 DBMS로 이전하고 검증하는 작업이다.
- 추진 동기 : 라이선스·운영비, 클라우드 전환, 기술 표준화 등 조직의 목표에 따라 추진한다.
- 범위 : 제품 교체뿐 아니라 데이터 모델, SQL, 저장 프로시저, 운영·보안·백업 절차의 변경을 포함한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **개방형 생태계와 배포 선택성**을 얻을 수 있지만, 총비용과 기능 적합성을 실제 워크로드로 검증해야 한다.
- **비용 구조 선택** : 라이선스 구조를 바꿀 수 있으나 인력·운영·지원 비용까지 포함해 비교한다.
- **이식성 개선** : 표준 SQL과 이식 가능한 로직으로 특정 제품 종속을 줄일 수 있다.
- **현대화 기회** : 스키마 정비와 불필요한 로직 제거를 함께 추진할 수 있다.
- **전환 부담** : 문법·기능·옵티마이저 차이가 있어 자동 변환만으로 동등 동작을 보장하지 않는다.

## Ⅲ. 단계별 마이그레이션 흐름

- 핵심 요약 : **발견·평가 → 변환 → 이관 → 검증 → 컷오버·운영 안정화**로 진행한다.

```text
[원본 DB·응용 의존성 목록화]
              ▼
[호환성·비용·위험 평가]
              ▼
[스키마·SQL·로직 변환]
              ▼
[초기 적재 + 변경분 동기화]
              ▼
[기능·정합성·성능 검증]
              ▼
[전환·관찰·롤백 판단]
```

- 온라인 전환이 필요한 경우 초기 적재 후 변경 데이터를 **CDC(Change Data Capture)**로 동기화하고, 전환 시점의 쓰기 정합성과 복귀 가능성을 시험한다.
- 업무 중요도와 데이터량에 따라 단계별·도메인별 전환 또는 점검 시간 전환을 선택한다.

## Ⅳ. 주요 변환 항목 비교

- 핵심 요약 : **구문 호환성뿐 아니라 의미와 실행 성능**까지 확인해야 한다.

| 영역 | 확인 사항 | 검증 방법 |
|---|---|---|
| 데이터 타입 | 길이·정밀도·시간대·인코딩 | 경계값·NULL 시험 |
| SQL | 조인·계층 질의·페이징·함수 | 결과 비교·정적 분석 |
| 저장 로직 | 프로시저·트리거·예외 처리 | 단위·통합 시험 |
| 트랜잭션 | 격리수준·잠금·시퀀스 | 동시성·장애 시험 |
| 성능 | 실행계획·인덱스·통계 | 대표 워크로드 재생 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **기능 차이·성능 회귀·데이터 불일치·전환 실패**를 통제하는 검증 계획이 필요하다.
- **비호환 로직** → 자동 변환 후 복잡한 프로시저와 독점 기능을 우선 수작업 검토한다.
- **실행계획 변화** → 대표 질의를 부하 조건에서 비교하고 통계·인덱스를 튜닝한다.
- **이관 중 데이터 불일치** → 건수·체크섬·업무 규칙을 이용해 원본과 목표 데이터를 대조한다.
- **컷오버 실패** → 전환 기준·중단 시점·롤백 조건을 사전에 정하고 모의 전환을 수행한다.

```text
기능 차이   → 변환·회귀 검증
성능 저하   → 워크로드 재생·튜닝     → 안정적 서비스 전환
데이터 불일치 → 대조·재동기화
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **비용·기능·성능·복구력**을 포함한 의사결정 근거와 전환 책임 체계를 마련한다.
- 현행 DB 의존성 인벤토리와 전환 우선순위를 만들고, 업무 오너가 검수 기준을 승인한다.
- 백업 복구와 목표 DB 장애조치, CDC 지연, 재동기화, 롤백을 실제로 시험한다.
- 전환 뒤에는 라이선스 비용만이 아니라 장애율·쿼리 지연·운영 공수·복구 시간을 비교한다.

## Ⅶ. 결론

- 핵심 요약 : DBMS 이전은 제품 교체가 아니라 **데이터와 업무 동작을 함께 검증하는 전환 프로젝트**다.
- 답안에는 변환 대상, CDC 기반 이관 흐름, 기능·성능·정합성 검증, 컷오버와 롤백을 연결해 제시한다.
- 참고 : [PostgreSQL 공식 문서](https://www.postgresql.org/docs/), [AWS DMS 마이그레이션 안내](https://docs.aws.amazon.com/dms/latest/userguide/Welcome.html).
