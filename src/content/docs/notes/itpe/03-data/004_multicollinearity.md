## 연관 키워드

- 다중공선성(Multicollinearity), 공차한계(TOL, Tolerance), 분산팽창계수(VIF, Variance Inflation Factor), 조건지수(CI, Condition Index)
- 부호 역전(Sign Reversal), 변수선택법, 주성분 분석(PCA, Principal Component Analysis)
- 릿지 회귀(Ridge Regression), 라쏘 회귀(Lasso Regression), 엘라스틱넷(ElasticNet), 부분 최소제곱 회귀(PLS, Partial Least Squares)

## Ⅰ. 다중공선성의 개요

- 핵심 요약 : 독립변수 간 강한 선형 관계로 회귀계수 추정이 불안정해지는 다중 회귀의 진단·관리 대상 현상.
- 개념 : 다중 선형 회귀에서 둘 이상의 독립변수가 서로 강한 선형 관계를 가져 개별 변수의 순수 영향력 분리가 어려워지는 현상인 **다중공선성** (Multicollinearity).
- 배경 및 필요성 : 설명변수 행렬의 열이 선형 종속에 가까워지면 역행렬 계산이 불안정해지고, 계수 추정치의 분산이 비정상적으로 커짐.
- 주요 목적 : 공선성의 정량 진단과 모델 목적에 맞는 완화로 계수 해석의 신뢰성 확보.

## Ⅱ. 다중공선성의 특징 및 영향

- 핵심 요약 : 분산 팽창·부호 역전·계수 불안정으로 발현되고 예측보다 해석에 피해가 집중.

1. 계수 분산 팽창 : 공선성이 강할수록 표준오차 증가 → t-통계량 감소와 유의성 상실.
2. **부호 역전** (Sign Reversal) : 이론상 양의 영향이 예상되는 변수의 계수가 음수로 추정 → 해석의 왜곡.
3. 계수 불안정성 : 표본의 작은 변동에도 계수가 크게 흔들림 → 모델 재현성 저하.
4. 예측의 제한적 영향 : 학습 데이터와 같은 상관 구조가 유지되면 예측값은 비교적 안정 → 해석형 모델에서 주요 관리 대상.

## Ⅲ. 다중공선성의 구조 (흐름)

- 핵심 요약 : 단계적 진단으로 공선성을 확인한 뒤 모델 목적에 따라 완화 기법을 선택하는 흐름.

```text
[ 다중공선성 진단 체계 ]

상관계수 행렬 검토
   ↓ 변수 쌍의 고상관 확인
공차한계 산출 (잔여 독립성)
   ↓
분산팽창계수 산출 (분산 배수)
   ↓
조건지수로 복합 공선성 확인
```

```text
[ 완화 기법 선택 흐름 ]

모델 목적 확인 (해석 or 예측)
   ↓ 해석형
변수 제거·도메인 기반 결합
   ↓ 잔여 공선성 존재 시
예측형 : 규제 회귀·차원 축소
   ↓
재진단으로 완화 효과 검증
```

- 진단 산식 :
  1. **공차한계** (TOL, Tolerance) = 1 − R² : 해당 변수를 나머지 독립변수로 설명할 수 없는 잔여 비율.
  2. **분산팽창계수** (VIF, Variance Inflation Factor) = 1 / TOL : 계수 분산의 팽창 배수.
  3. **조건지수** (CI, Condition Index) = √(λmax / λmin) : 설명변수 행렬 고유값 기반의 복합 공선성 지표.

## Ⅳ. 진단 지표와 완화 기법의 비교

- 핵심 요약 : 진단은 상관계수에서 조건지수로 범위가 넓어지고, 완화는 정보 보존과 해석력의 균형 문제.

| 진단 지표 | 측정 원리 | 통용 판단 기준 | 한계 |
| --- | --- | --- | --- |
| 상관계수 | 두 변수의 선형 관계 강도 | \|r\| ≥ 0.8 부근에서 의심 | 3개 이상 복합 공선성 미탐지 |
| 공차한계(TOL) | 잔여 독립성 비율 | 0.1 미만에서 문제 | 단일 변수 기준 |
| 분산팽창계수(VIF) | 계수 분산의 팽창 배수 | 10 이상 경고 (엄격 기준 5) | 선형 관계 전제 |
| 조건지수(CI) | 고유값 기반 다차원 평가 | 30 이상 위험 | 절대 기준의 부재 |

| 완화 기법 | 작용 원리 | 장점 | 한계 |
| --- | --- | --- | --- |
| 변수 제거·변수선택법 | 공선 변수군의 기여도 낮은 변수 제외 | 해석 단순화 | 정보 손실 위험 |
| **주성분 분석** (PCA, Principal Component Analysis) | 직교 주성분으로 변수 변환 | 상관 0의 완전 제거 | 주성분의 해석 곤란 |
| **릿지 회귀** (Ridge Regression) | L2 정규화로 계수 전체 수축 | 계수 안정화 | 계수의 0화 불가 |
| **라쏘 회귀** (Lasso Regression) | L1 정규화로 일부 계수 0화 | 변수 선택 겸용 | 상관 변수 중 하나 선택 경향 |

- 선택 기준 : 계수 해석이 목적이면 변수 제거·도메인 기반 결합, 예측 성능이 목적이면 **엘라스틱넷** (ElasticNet, L1과 L2 규제의 결합형) 계열 규제 우선.

## Ⅴ. 다중공선성 관리의 한계와 방안

- 핵심 요약 : 정보 손실, 해석력 상실, 비선형 진단 실패를 규제 회귀·PLS·비선형 평가로 일대일 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 변수 제거의 정보 손실 | 상관 변수의 임의 제외 → 교란 요인 누락 | 규제 회귀로 변수군 보존 또는 도메인 기반 합성 지표 생성 | 계수 안정성, 검증 오차 |
| 차원 축소의 해석력 상실 | 주성분이 변수의 선형 결합 → 도메인 해석 곤란 | 목표변수를 반영하는 **부분 최소제곱 회귀** (PLS, Partial Least Squares) 적용 | 변수별 설명력 |
| 비선형·고차원 진단 실패 | VIF·상관계수는 선형 관계만 포착 | 상호정보량 기반 의존성 평가와 트리 기반 중요도 병행 | 중요도 순위의 안정성 |

## Ⅵ. 다중공선성 관리에 대한 기술사적 제언

- 핵심 요약 : 모델 목적별 관리 기준의 표준화와 파생변수 단계의 자동 필터링.
- 분석 조직 : 모델 목적(해석형·예측형)별 공선성 관리 기준을 분석 표준으로 수립.
- 플랫폼 조직 : 특징 저장소에 공선성 필터를 자동화해 중복 파생변수 생성의 원천 차단.
- 검증 조직 : 계수 안정성 검사를 모델 검증 절차의 정식 항목으로 편입.

## Ⅶ. 결론

- 핵심 요약 : 다중공선성은 다층 진단 지표와 목적별 완화 기법의 조합으로 관리하는 현상임.
- 계수의 설득력이 요구되는 모델일수록 공선성 관리 수준이 분석 신뢰성을 결정.
