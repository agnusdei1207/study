## 연관 키워드

- 다중공선성(Multicollinearity), 분산팽창계수(VIF), 공차한계(Tolerance), 조건지수(CI), 부호 역전
- 변수선택법, PCA, 릿지(Ridge)·라쏘(Lasso) 회귀, ElasticNet, PLS, SHAP

## Ⅰ. 다중공선성의 개요

- 핵심 요약 : 독립변수 간 높은 상관관계로 회귀계수 추정이 불안정해지는 다중 선형 회귀의 문제 현상.
- 개념 : 다중 선형 회귀 모델(Multiple Linear Regression)에서 둘 이상의 독립변수(설명변수) 사이에 높은 상관관계가 존재하여 개별 변수의 독립적 회귀계수 추정이 불안정해지는 현상.
- 배경 및 필요성 :
  1. 독립변수 행렬 X의 열들이 선형 종속(Linearly Dependent)에 가까워 X'X 역행렬 계산의 폭발적 불안정성 야기.
  2. 계수 추정의 분산 폭발 : 회귀계수의 표준오차(Standard Error) 극대화, t-통계량 감소 및 통계적 유의성 상실.
  3. 모델 불안정성 : 표본 데이터의 미세한 변경에도 회귀계수 값의 극단적 변동.
- 주요 목적 : 다중공선성의 정량 진단과 모델 목적에 맞는 완화 기법 적용을 통한 해석 신뢰성 확보.

## Ⅱ. 다중공선성의 특징

- 핵심 요약 : 분산 폭발·부호 역전·모델 불안정으로 발현되며 상관계수·TOL·VIF·CI로 진단.

1. 계수 추정의 분산 폭발 : 표준오차의 극단적 증대로 t-통계량 감소 및 유의성 상실.
2. 부호 역전(Sign Reversal) : 상식적으로 양의 영향을 가져야 할 변수의 회귀계수가 음수로 추정되는 해석 왜곡.
3. 모델 불안정성 : 표본의 아주 미세한 변경에 따른 회귀계수의 극단적 변동.
4. 진단 지표의 다층 체계 : 단순 상관관계부터 복합 공선성까지 단계별 진단 수단의 조합.

```text
[ 다중공선성 진단 체계 ]
 1. 상관계수 행렬     : |r| >= 0.8 스크리닝
 2. 공차한계(TOL)     : TOL < 0.1 공선성 의심
 3. 분산팽창계수(VIF) : VIF >= 10 경고
 4. 조건지수(CI)      : CI >= 30 위험
```

## Ⅲ. 다중공선성의 구조 (흐름)

- 핵심 요약 : 진단 지표의 탐지에서 변수 제거·변환·규제 회귀의 완화 단계로 이어지는 흐름.

```text
[ 다중공선성 완화 프로세스 ]
 공선성 탐지 (VIF >= 10)
 ├─ 변수 제거
 │   - 도메인 기반 불필요 변수 제외
 │   - 전진/후진 변수선택법
 ├─ 변수 변환/결합
 │   - PCA 주성분 추출
 │   - 변수 간 차분/비율 생성
 └─ 규제 회귀
     - Ridge (L2 규제), ElasticNet
```

- 진단 산식 :
  1. 공차한계 : TOL = 1 − R² (R²는 해당 변수를 나머지 독립변수로 회귀분석한 결정계수).
  2. 분산팽창계수 : VIF = 1 / (1 − R²) = 1 / TOL.
  3. 조건지수 : CI = √(λmax / λmin) (λ는 X'X의 고유값).

## Ⅳ. 진단 지표 및 완화 기법의 비교

- 핵심 요약 : 단순 관계 탐지의 상관계수부터 복합 공선성 평가의 CI까지, 완화는 정보 보존과 해석력의 트레이드오프.

| 진단 지표 | 산식 및 메커니즘 | 판단 기준 | 특성 및 한계 |
|---|---|---|---|
| 상관계수(Correlation) | r = Σ(x−x̄)(y−ȳ) / √(Σ(x−x̄)²·Σ(y−ȳ)²) | \|r\| ≥ 0.8 | 두 변수 간 단순 선형 관계만 탐지, 3개 이상 복합 공선성 탐지 불가 |
| 공차한계(Tolerance) | TOL = 1 − R² | TOL < 0.1 | 다른 독립변수에 의해 설명되는 잔여 독립성 측정 |
| 분산팽창계수(VIF, Variance Inflation Factor) | VIF = 1 / TOL | VIF ≥ 10(엄격 기준 5) | 가장 널리 쓰이는 표준 지표, 회귀계수 분산의 팽창 배수를 직관적으로 제시 |
| 상태지수(CI, Condition Index) | CI = √(λmax / λmin) | CI ≥ 30 | 고유값 기반으로 다차원 공간의 복합 공선성을 종합 평가 |

| 해결 기법 | 구체적 작용 메커니즘 | 적용 시 장단점 |
|---|---|---|
| 변수 제거(Feature Selection) | 상관성이 높은 두 변수 중 정보량이 적거나 VIF가 큰 변수 제거 | 모델의 단순화, 유용한 정보 손실 위험 |
| 차원 축소(PCA, Principal Component Analysis) | 직교하는 주성분(Principal Components)으로 변수 변환 | 공선성의 완벽 제거(r = 0), 주성분의 비즈니스 해석 곤란 |
| 릿지 회귀(Ridge Regression) | L2 정규화(λΣβ²)로 역행렬 대각선에 편향(λI) 추가 | 분산의 대폭 축소와 안정적 계수 산출, 계수를 0으로 만들지는 않음 |
| 라쏘 회귀(Lasso Regression) | L1 정규화(λΣ\|β\|)로 중요하지 않은 계수를 0으로 수축 | 변수 선택 효과의 동시 달성, 상관 변수 중 임의의 하나만 선택하는 경향 |

## Ⅴ. 다중공선성 관리의 장점과 한계

- 핵심 요약 : 조기 진단·계수 안정화의 장점과 정보 손실·해석력 상실·비선형 진단 실패의 한계.

- 장점
  1. VIF 등 표준 지표를 통한 공선성의 조기 정량 진단.
  2. 규제 회귀를 통한 계수 안정화 및 예측 성능 보완.
  3. 변수 제거·변환·규제의 다층적 대응 옵션.

- 한계점 1 : 변수 제거 시 유의 정보 손실 및 생략변수 편의(Omitted Variable Bias)
  - 한계점 : VIF 기준의 단순 적용으로 상관 변수를 임의 제거할 경우 목적 변수의 고유 분산·교란 요인(Confounder) 누락 및 회귀계수 왜곡 발생.
  - 해결 방안 : 릿지(Ridge, L2) 회귀의 계수 축소(Shrinkage) 또는 엘라스틱넷(ElasticNet) 적용을 통한 상관 변수군의 그룹 단위 보존 및 모델 안정성 확보.
- 한계점 2 : PCA 차원 축소 적용 시 비즈니스 해석 가능성(Interpretability) 상실
  - 한계점 : 주성분(PC, Principal Component) 변환은 직교 변환으로 공선성을 완벽 제거하지만 변수의 선형 결합으로 개별 도메인 지표의 설명력·규제 컴플라이언스 대응 곤란.
  - 해결 방안 : 도메인 지식 기반 변수 결합(비율, 차분 등 합성 지표 생성) 또는 부분 최소제곱 회귀(PLS, Partial Least Squares) 도입을 통한 타깃 변수 연관성 보존 차원 압축.
- 한계점 3 : 다변량 비선형 공선성 및 고차원 데이터(p > n)에서의 진단 실패
  - 한계점 : VIF와 피어슨 상관계수는 선형 관계 전제로 복잡한 비선형 종속성 탐지 불가, 변수 수가 샘플 수를 초과하면 계산 불가.
  - 해결 방안 : 상호정보량(Mutual Information) 기반 비선형 의존성 평가, 트리 기반 앙상블(GBDT, Gradient Boosting Decision Tree)의 특성 중요도(Feature Importance)와 SHAP(SHapley Additive exPlanations) 분석 병행.

## Ⅵ. 다중공선성 관리에 대한 기술사적 제언

- 핵심 요약 : 예측·설명 목적의 차별 대응과 파생변수 생성 단계의 공선성 필터링 자동화.
- 예측 중심과 설명 중심 모델의 차별화 : 예측 정확도 목적(GBDT, Random Forest 등)의 경우 다중공선성의 예측 오차 영향이 제한적이나, 비즈니스 인과관계 분석(Causal Inference)·규제 대응(신용평가) 모델에서는 다중공선성 제거가 최우선 과제.
- 파생변수 생성 시 사전 점검 : 연령, 생년월일, 근속연수 등 동일 개념의 중복 파생변수 무분별 생성 방지를 위한 Feature Store 단계의 공선성 필터링 자동화.

- 시사점 : 예측과 설명이라는 모델 목적에 따른 대응 전략의 차별화 필요.
