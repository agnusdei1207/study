## 큰 그림과 30초 인출

```text
[설명변수 X1, X2, ... Xp]
          │ 변수 간 강한 선형관계
          ▼
 [X'X 역행렬 불안정]
          │
          ├─▶ 회귀계수 분산·표준오차 증가
          ├─▶ 계수 부호·크기 불안정
          └─▶ 개별 변수 해석력 저하
                         │
 상관행렬 → VIF → Condition Index → 대응·재검증
```

- 본질: **설명변수 간 강한 선형관계로 각 변수의 독립적 효과를 분리하기 어려운 회귀모형 문제**
- 핵심식: `VIF_j = 1 / (1 - R_j²)`
- 암기: `상-V-상` = 상관행렬 → VIF → 상태지수
- 주의: 예측력이 반드시 낮아지는 문제라기보다 회귀계수의 안정성과 해석 가능성이 먼저 훼손됨

## 예상문제

> 다중공선성의 개념과 영향, 진단방법을 설명하고 해결방안 및 회귀 가정 위반 문제와의 차이를 논하시오. (25점)

## Ⅰ. 설명변수 효과의 분리를 어렵게 하는 다중공선성 개요

- 정의: **다중공선성**은 다중회귀모형의 둘 이상 설명변수 사이에 강한 선형관계가 존재하여 회귀계수 추정의 분산과 불안정성이 커지는 현상
- 발생원인: 유사 지표 동시 투입, 파생변수와 원변수 병용, 더미변수 함정, 작은 표본과 제한된 변수 변동
- 영향: 모형 전체의 설명력은 유지될 수 있으나 개별 계수의 표준오차·유의확률·부호가 불안정해 변수별 해석이 어려움

#### 한줄 요약

- 다중공선성은 변수 사이의 정보가 겹쳐 “어느 변수가 얼마나 기여했는가”를 분리하기 어려운 문제임

## Ⅱ. 계수의 분산과 해석을 흔드는 주요 현상

| 현상 | 통계적 영향 | 실무 위험 |
|---|---|---|
| **표준오차 증가** | 계수 추정 분산 팽창 | 중요한 변수의 유의성 누락 |
| **계수 불안정** | 표본 변화에 따라 크기·부호 변동 | 정책·업무 해석의 역전 |
| **개별 검정 약화** | 전체 F검정과 개별 t검정 결과 괴리 가능 | 기여변수 오판 |
| **외삽 위험** | 관측 범위 밖 변수 조합에서 불안정 | 예측 실패 확대 |
| **변수 중요도 왜곡** | 상관 변수 간 중요도 분산 | 설명가능성 저하 |

#### 한줄 요약

- 높은 결정계수와 낮은 개별 유의성이 함께 나타날 수 있으므로 적합도만 보고 모형을 채택하면 안 됨

## Ⅲ. 상관관계에서 고유값까지의 진단체계

```text
① 변수 정의·산점도
        ↓
② 상관행렬 ──▶ 두 변수 간 선형관계 탐색
        ↓
③ VIF/Tolerance ──▶ 한 변수가 나머지로 설명되는 정도
        ↓
④ 고유값·Condition Index ──▶ 다변수 결합 의존성
        ↓
⑤ 표본·모형 변경 민감도 ──▶ 계수 안정성 검증
```

| 진단 | 판단 내용 | 한계·주의 |
|---|---|---|
| **상관행렬** | 설명변수 쌍의 선형 상관 | 다수 변수의 결합관계는 놓칠 수 있음 |
| **Tolerance** | `1-R_j²`, 작을수록 중복 설명 큼 | 절대 기준보다 맥락·표본 고려 |
| **VIF** | `1/(1-R_j²)`, 계수 분산 팽창 정도 | 하나의 임계값으로 기계적 제거 금지 |
| **Condition Index** | 설계행렬 고유값 비율의 불안정성 | 분산분해와 함께 해석 |
| **계수 민감도** | 변수·표본 변경 시 계수 변동 | 예측·해석 목적을 구분해 판정 |

#### 한줄 요약

- VIF는 경보지 자동 삭제 명령이 아니며, 변수의 업무 의미와 모형 목적을 함께 판단해야 함

## Ⅳ. 원인에 맞춰 적용하는 다중공선성 대응 절차

```text
진단 → 원인 분류 → 목적 확인 → 대응 선택 → 재학습·검증
                  │
                  ├─ 해석 목적: 변수 제거·결합·설계 보완
                  └─ 예측 목적: Ridge·PCA·교차검증
```

| 대응 | 적용 원리 | 적합 상황 | 유의점 |
|---|---|---|---|
| **변수 제거** | 중복 변수를 제외 | 업무적으로 대체 가능한 변수 | 중요한 교란변수 누락 위험 |
| **변수 결합** | 지수·합성변수로 공통정보 표현 | 같은 개념의 다수 지표 | 해석 기준 명시 필요 |
| **표본·설계 보완** | 독립적 변동이 있는 관측 추가 | 데이터 수집 가능 | 비용·대표성 검토 |
| **Ridge 회귀** | L2 규제로 계수 분산 축소 | 예측 안정성 우선 | 편향 도입·스케일링 필요 |
| **PCA 회귀** | 직교 성분으로 변수 변환 | 차원 축소·예측 목적 | 원변수 해석력 감소 |

#### 한줄 요약

- 대응은 VIF 순서대로 변수를 지우는 일이 아니라 해석과 예측 중 무엇을 보호할지 결정하는 과정임

## Ⅴ. 다중공선성·이분산성·자기상관 비교

| 구분 | 다중공선성 | 이분산성 | 자기상관 |
|---|---|---|---|
| **문제 관계** | 설명변수끼리 상관 | 오차 분산이 관측값에 따라 변화 | 오차가 시간·공간 순서에 따라 상관 |
| **주요 영향** | 계수 분산·해석 불안정 | 표준오차·검정 왜곡 | 효율성·표준오차 왜곡 |
| **진단 예** | VIF, Condition Index | 잔차도, Breusch-Pagan 등 | 잔차 ACF, Durbin-Watson 등 |
| **대응 예** | 변수 선택·결합·Ridge·PCA | 변환·가중회귀·강건 표준오차 | 시차항·오차모형·GLS |
| **핵심 차이** | 설계행렬의 변수 중복 | 오차의 비등분산 | 오차의 독립성 위반 |

#### 한줄 요약

- 세 문제는 모두 회귀 추론을 흔들지만 원인이 변수 관계인지, 오차 분산인지, 오차 상관인지가 다름

## Ⅵ. 기계적 변수 제거를 막는 실무 고려사항

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| VIF 기준으로 **핵심 변수 삭제** | 임계값을 절대 규칙으로 적용 | 목적·도메인·인과구조 검토 후 결합·규제 비교 | 설명변수 누락 편향 방지 |
| 학습 때마다 **계수 부호 변경** | 작은 표본과 유사 변수 다수 | 부트스트랩·교차검증으로 계수 안정성 확인 | 불안정성의 정량 확인 |
| 예측은 좋지만 **정책 해석 오류** | 예측 목적 모형을 인과 해석에 사용 | 예측·설명 모형 분리, 변수 선택 근거 기록 | 사용목적 오용 방지 |
| Ridge 적용 후 **계수 비교 왜곡** | 변수 단위·범위 차이 | 학습데이터 기준 표준화와 변환 파이프라인 고정 | 규제의 공정한 적용 |

#### 한줄 요약

- 해결책은 진단값을 낮추는 것이 아니라 모형의 사용목적에 필요한 안정성과 해석 가능성을 회복하는 것임

## Ⅶ. 진단값보다 의사결정 안정성을 검증하는 결론

- **[예측모형과 설명모형의 목적 분리]**: 상관 변수를 무조건 제거하면 업무적으로 필요한 변수가 빠지고, 그대로 두면 계수 해석이 왜곡될 수 있음
- 나라면: 예측 목적에는 규제모형과 교차검증을, 설명 목적에는 도메인 기반 변수 구조와 계수 안정성 분석을 적용하고 모형카드에 변수 선택 근거를 기록

#### 한줄 요약

- 다중공선성 관리의 완성은 VIF를 특정 값 아래로 만드는 것이 아니라 표본이 바뀌어도 의사결정이 흔들리지 않게 하는 것임

## 1교시 10점 답안 발췌

### 1. 정의와 영향

- 다중공선성은 설명변수 간 강한 선형관계로 회귀계수 분산과 표준오차가 증가하여 개별 변수의 해석이 불안정해지는 현상

### 2. 진단과 대응

```text
상관행렬 → VIF/Tolerance → Condition Index → 민감도 검증
                                 ↓
       변수 제거·결합 / Ridge / PCA / 표본 보완
```

### 3. 차별화 제언

- VIF 임계값으로 변수를 기계적으로 제거하지 않고 예측·설명 목적을 분리해 규제와 도메인 기반 변수 구조를 선택
