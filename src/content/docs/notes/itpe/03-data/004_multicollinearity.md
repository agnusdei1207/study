## 연관 키워드
- 다중공선성, 상관행렬, VIF, 조건수, 회귀계수, 규제화

### Ⅰ. 다중공선성의 개요

- 핵심 요약 : 다중공선성은 회귀모형의 설명변수 사이에 강한 선형관계가 존재하는 상태.
- 개념 : 회귀모형의 설명변수 사이에 강한 선형관계가 존재하는 상태(**다중공선성**, Multicollinearity).
- 배경 및 필요성 : 계수 분산 증가로 개별 계수의 크기·부호와 유의성 해석이 불안정해질 수 있음.
- 주요 목적 : 회귀계수 추론과 변수 영향 해석의 신뢰성 확보.

### Ⅱ. 다중공선성의 특징 및 장점

- 핵심 요약 : 표준오차 증가·계수 불안정·예측과 추론 구별은 다중공선성을 진단하고 목적별로 대처하는 데이터 분석 방식.

1. 표준오차 증가 : 설명변수 정보 중복 → 계수 신뢰구간 확대.
2. 계수 불안정 : 표본 변화에 민감 → 부호·유의성 변동.
3. 예측과 추론 구분 : 공선성이 있어도 예측이 반드시 나빠지는 것은 아님 → 분석목적별 대처.

### Ⅲ. 다중공선성의 구조 (흐름)

- 핵심 요약 : 상관·VIF·조건수 진단 → 이론적으로 중복변수 파악 → 변수 결합·제거나 규제화 → 잔차·검증성능 재평가.

```text
상관·VIF·조건수 진단
  ↓
이론적으로 중복변수 파악
  ↓
변수 결합·제거나 규제화
  ↓
잔차·검증성능 재평가
```

```text
X1 ─────┐
        ├→ 같은 설명정보 → β 추정 불안정
X2 ─────┘
       ↓
표준오차 증가·개별효과 해석 곤란
```

### Ⅳ. 다중공선성과 이분산성 비교

- 핵심 요약 : 주요 영향 기준 — 다중공선성: 계수 분산·추론 불안정; 이분산성: OLS 표준오차·검정 왜곡.

| 비교 축 | 다중공선성 | 이분산성 |
|---|---|---|
| 문제 구조 | 설명변수 간 선형 의존 | 오차항 분산이 설명변수 수준에 따라 변함 |
| 주요 영향 | 계수 분산·추론 불안정 | OLS 표준오차·검정 왜곡 |
| 주된 해결 | 변수 결합·제거나 규제화 | 가중 least squares·견고한 표준오차 |

### Ⅴ. 다중공선성의 한계와 방안

- 핵심 요약 : 상관계수만 진단·무조건 변수 제거 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 상관계수만 진단 | 쌍별 상관이 낮아도 다변량 선형결합 가능 | VIF·조건수와 도메인지식 병행 | 진단 누락률 |
| 무조건 변수 제거 | 중요한 교란변수 제거로 편향 초래 | 목표·인과구조 검토 후 제거·결합 결정 | 계수 안정성 |
| 정규화 오용 | Ridge 등은 계수 편향을 도입 | 추론 목적과 예측 목적을 구분해 방법 선택 | 검증오차·계수 민감도 |

### Ⅵ. 다중공선성에 대한 제언

- 핵심 요약 : 분석자는 VIF 임계값을 기계적으로 적용하지 말고 표본크기·설계행렬·변수 의미와 추론목적을 함께 검토.

- 실행 제안 : 추론 목적이면 중복 변수의 업무적 의미와 표본구조를 검토하고 예측 목적이면 정규화 모형을 교차검증으로 비교.

### Ⅶ. 결론

- 핵심 요약 : 다중공선성은 OLS 계수의 분산과 해석을 악화시키는 현상으로, 진단 이후 분석목적에 맞는 조치가 필요.
- 시사점 : 예측이 가능하더라도 개별 회귀계수 해석은 불안정할 수 있어 분석 목적을 먼저 구분.
