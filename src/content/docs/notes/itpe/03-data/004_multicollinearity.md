## 연관 키워드

- 다중공선성(Multicollinearity), 분산팽창계수(VIF), 공차한계(Tolerance), 조건지수(CI), 부호 역전
- 변수선택법, PCA, 릿지(Ridge)·라쏘(Lasso) 회귀, ElasticNet, PLS, SHAP

## Ⅰ. 다중공선성의 개요

- 핵심 요약 : 독립변수 간 높은 상관관계로 회귀계수 추정이 불안정해지는 다중 선형 회귀의 문제 현상.
- 개념 : 다중 선형 회귀 모델에서 둘 이상의 독립변수(설명변수) 사이에 강한 상관관계가 존재하여 개별 변수의 회귀계수를 독립적으로 추정하기 어려워지는 현상인 **다중공선성** (Multicollinearity).
- 배경 및 필요성 :
  1. 독립변수 행렬 X의 열들이 선형 종속에 가까워져 X'X 역행렬 계산이 불안정해짐.
  2. 계수 추정치의 분산이 커져 표준오차가 증가하고, 통계적 유의성이 떨어짐.
  3. 표본의 미세한 변화에도 회귀계수 값이 크게 흔들려 해석의 신뢰성이 낮아짐.
- 주요 목적 : 다중공선성을 정량 진단하고 모델 목적에 맞는 완화 기법을 적용하여 해석 신뢰성을 확보.

## Ⅱ. 다중공선성의 특징 및 영향

- 핵심 요약 : 계수 분산 확대, 부호 역전, 모델 불안정으로 발현되며, 상관계수·공차한계·분산팽창계수·조건지수로 진단.

1. 계수 추정의 분산 확대 : 표준오차가 극단적으로 커져 t-통계량이 줄고 유의성을 잃음.
2. 부호 역전(Sign Reversal) : 상식적으로 양의 영향을 가져야 할 변수의 계수가 음수로 추정되어 해석이 왜곡됨.
3. 모델 불안정성 : 표본의 작은 변경에도 계수가 크게 변동하여 예측·설명 모두 재현성이 떨어짐.
4. 진단 지표의 다층 체계 : 단순 상관관계부터 복합 공선성까지 단계별 진단 수단을 조합하여 확인.

```text
[ 다중공선성 진단 체계 ]

 상관계수 행렬 (|r| ≥ 0.8 스크리닝)
          ↓
 공차한계 TOL (TOL < 0.1 의심)
          ↓
 분산팽창계수 VIF (VIF ≥ 10 경고)
          ↓
 조건지수 CI (CI ≥ 30 위험)
```

- 진단 산식 :
  1. 공차한계(TOL, Tolerance) = 1 − R², R²는 해당 변수를 나머지 독립변수로 회귀분석한 결정계수.
  2. 분산팽창계수(VIF, Variance Inflation Factor) = 1 / (1 − R²) = 1 / TOL.
  3. 조건지수(CI, Condition Index) = √(λmax / λmin), λ는 X'X의 고유값.

## Ⅲ. 다중공선성의 구조 (흐름)

- 핵심 요약 : 진단으로 공선성을 확인한 뒤, 모델 목적에 맞춰 변수 제거·변환·규제 회귀 중 하나를 선택하는 완화 흐름.

```text
[ 다중공선성 완화 프로세스 ]

 공선성 탐지 (VIF ≥ 10)
          ↓
 모델 목적에 따라 기법 선택
          ↓
 변수 제거 (도메인 기반, 변수선택법)
 변수 변환·결합 (PCA, 합성 지표)
 규제 회귀 (Ridge, ElasticNet, Lasso)
```

## Ⅳ. 진단 지표 및 완화 기법의 비교

- 핵심 요약 : 단순 상관계수에서 복합 공선성의 조건지수까지 진단 범위가 넓어지며, 완화는 정보 보존과 해석력 사이의 트레이드오프.

| 진단 지표 | 산식 및 메커니즘 | 판단 기준 | 특성 및 한계 |
|---|---|---|---|
| 상관계수(Correlation) | r = Σ(x−x̄)(y−ȳ) / √(Σ(x−x̄)²·Σ(y−ȳ)²) | \|r\| ≥ 0.8 | 두 변수 간 단순 선형 관계만 탐지, 3개 이상 복합 공선성 탐지 불가 |
| 공차한계(TOL) | TOL = 1 − R² | TOL < 0.1 | 다른 독립변수로 설명되지 않는 잔여 독립성 측정 |
| 분산팽창계수(VIF) | VIF = 1 / TOL | VIF ≥ 10 (엄격 기준 5) | 가장 널리 쓰이는 표준 지표, 계수 분산의 팽창 배수를 직관적으로 제시 |
| 조건지수(CI) | CI = √(λmax / λmin) | CI ≥ 30 | 고유값 기반으로 다차원 복합 공선성을 종합 평가 |

| 해결 기법 | 구체적 작용 메커니즘 | 적용 시 장단점 |
|---|---|---|
| 변수 제거(Feature Selection) | 상관성이 높은 두 변수 중 정보량이 적거나 VIF가 큰 변수를 제외 | 모델 단순화, 유용한 정보 손실 위험 |
| 차원 축소(PCA, 주성분 분석) | 직교하는 주성분(Principal Components)으로 변수를 변환 | 공선성 완벽 제거(상관 0), 주성분의 비즈니스 해석 곤란 |
| 릿지 회귀(Ridge Regression) | L2 정규화(λΣβ²)로 역행렬 대각선에 편향(λI) 추가 | 분산을 크게 줄여 계수를 안정화, 계수를 0으로 만들지는 않음 |
| 라쏘 회귀(Lasso Regression) | L1 정규화(λΣ\|β\|)로 중요하지 않은 계수를 0으로 수축 | 변수 선택 효과 동시 달성, 상관 변수 중 하나만 고르는 경향 |

- 선택 기준 : 예측 정확도가 목적이면 규제 회귀를, 변수별 해석이 목적이면 변수 제거나 도메인 기반 결합을 우선 검토.

## Ⅴ. 다중공선성의 한계와 방안

- 핵심 요약 : 정보 손실, 해석력 상실, 비선형·고차원 진단 실패를 규제 회귀, 도메인 결합, 비선형 의존성 평가로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 변수 제거에 따른 정보 손실 | VIF 기준으로 상관 변수를 임의 제거하면 교란 요인 누락과 생략변수 편의 발생 | 릿지 회귀 또는 **엘라스틱넷** (ElasticNet)으로 상관 변수군을 그룹 단위로 보존 | 계수 안정성, 검증 오차 |
| PCA 적용 시 해석력 상실 | 주성분은 변수의 선형 결합이어서 개별 도메인 지표의 설명력 저하 | 도메인 지식 기반 합성 지표(비율·차분) 생성 또는 **부분 최소제곱 회귀** (PLS, Partial Least Squares) 도입 | 변수별 설명력, 규제 설명 가능성 |
| 비선형·고차원 진단 실패 | VIF와 상관계수는 선형 관계만 전제하며, 변수 수가 샘플 수를 넘으면 계산 불가 | 상호정보량(Mutual Information) 기반 비선형 의존성 평가, 트리 모델의 특성 중요도와 **SHAP** (SHapley Additive exPlanations) 병행 | 중요도 순위의 안정성 |

## Ⅵ. 다중공선성 관리에 대한 기술사적 제언

- 핵심 요약 : 목적별 차별 대응과 파생변수 생성 단계의 공선성 필터링 자동화.
- 예측 정확도가 목적인 모델은 다중공선성의 영향이 제한적이므로 성능 중심으로 다루고, 인과 추론이나 신용평가처럼 계수 해석이 규제 요건인 모델에서는 공선성 제거를 최우선 과제로 삼는 것이 합리적임.
- 연령, 생년월일, 근속연수처럼 같은 개념을 담은 파생변수가 중복 생성되지 않도록, 특징 저장소(Feature Store) 단계에서 공선성 필터링을 자동화하는 것이 바람직함.

## Ⅶ. 결론

- 핵심 요약 : 다중공선성 관리는 진단 지표의 정확한 해석과 모델 목적에 맞는 완화 기법 선택의 문제.
- 시사점 : 모델 목적에 따라 대응 전략을 달리하는 것이 해석 신뢰성과 예측 성능을 함께 지키는 길임.
