## 연관 키워드

**재표본추출**, **잭나이프**, **부트스트랩**, **복원 추출**, **표준오차**, **신뢰구간**, **OOB**, **블록 부트스트랩**

## Ⅰ. 개요

- 핵심 요약 : **잭나이프와 부트스트랩**은 관측 표본을 반복적으로 변형해 통계량의 변동성과 불확실성을 추정하는 재표본추출 기법이다.
- 목적 : 해석적 분포나 간단한 표준오차 공식이 어려운 통계량의 편향·분산·신뢰구간을 평가하는 데 활용한다.
- 전제 : 재표본추출은 원자료가 모집단을 대표한다는 보장을 만들지 않으며, 표본 설계와 데이터 의존 구조를 고려해야 한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **잭나이프는 관측값을 차례로 제외**하고 **부트스트랩은 복원 추출을 반복**해 표본 변동을 근사한다.
- **잭나이프** : Leave-One-Out 하위표본을 만들어 통계량을 반복 계산한다. 절차가 간단하고 계산량은 대체로 표본 수에 비례한다.
- **부트스트랩** : 원표본과 같은 크기의 복원 표본을 여러 개 생성해 통계량의 경험적 분포를 추정한다.
- **활용 범위** : 평균 외의 복잡한 통계량에서도 불확실성을 경험적으로 살필 수 있다.

## Ⅲ. 재표본추출 흐름과 OOB

- 핵심 요약 : **표본 설계 확인 → 반복 표본 생성 → 통계량 산출 → 분포·불확실성 요약**의 절차로 수행한다.

```text
[원 관측 표본]
      ├─ 잭나이프: 한 관측값씩 제외 → 통계량 반복 계산
      └─ 부트스트랩: 복원 추출 반복 → 통계량 경험분포
                                      ▼
                 [표준오차·편향·신뢰구간 등 산출]
                                      ▼
                         [가정·적용 한계 해석]
```

- 부트스트랩 표본에서 원자료의 특정 관측값이 빠지는 비율은 큰 표본에서 약 36.8%로 수렴한다. 이 표본은 **OOB(Out-of-Bag)** 예측 평가에 활용될 수 있다.
- OOB 평가는 주로 배깅 계열에서 쓰이며, 모든 모델에 별도 검증을 완전히 대체한다고 볼 수 없다.

## Ⅳ. 잭나이프와 부트스트랩 비교

- 핵심 요약 : **목표 통계량의 특성·표본 구조·계산 자원**에 따라 방법을 선택한다.

| 구분 | 잭나이프 | 부트스트랩 |
|---|---|---|
| 표본 생성 | 관측값을 하나씩 제외 | 원표본에서 복원 추출 |
| 반복 수 | 통상 관측 수에 의해 결정 | 분석자가 설정 |
| 장점 | 구현이 단순하고 계산량이 비교적 적음 | 통계량 표집분포와 신뢰구간 추정에 유연 |
| 주의점 | 비매끄러운 통계량에서 부적절할 수 있음 | 표본 대표성·반복 수·구간 방식에 영향 |
| 종속자료 | 단순 제외 방식은 구조 반영 어려움 | 단순 무작위 재표집은 의존성 파괴 가능 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **표본 편향·종속성·통계량의 비매끄러움**에 맞춰 재표집 단위를 설계한다.
- **대표성 부족** → 표집 설계와 자료 수집 과정을 검토하고 결과를 모집단으로 무리하게 일반화하지 않는다.
- **시계열·군집 종속성** → 시간 블록이나 군집 단위 재표집 등 의존 구조에 맞는 방법을 검토한다.
- **극단·비매끄러운 통계량** → 잭나이프·기본 부트스트랩의 적합성을 점검하고 대안 구간·모형을 비교한다.
- **연산 비용** → 반복 수에 따른 추정 안정성을 확인하고 필요한 계산량을 정한다.

```text
표본 편향   → 표집 설계 확인
종속 구조   → 블록·군집 재표집       → 타당한 불확실성 추정
계산 부담   → 반복 수·대안법 비교
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **재표집 방법과 신뢰구간 산출 조건을 기록**해 분석 결과의 재현성을 확보한다.
- 난수 시드, 반복 수, 표본 단위, 결측치 처리, 신뢰구간 계산 방식을 기록한다.
- 시계열이나 패널자료에는 무작위 행 단위 재표집을 자동 적용하지 말고 데이터 구조를 반영한다.
- 모델 성능의 불확실성을 보고할 때는 동일 데이터에서 반복한 결과와 독립 테스트 성능을 구분한다.

## Ⅶ. 결론

- 핵심 요약 : 재표본추출은 불확실성을 평가하는 실용적 도구이며 **표본 구조와 통계량 적합성**을 고려해야 한다.
- 답안에는 잭나이프의 제외 방식, 부트스트랩의 복원 추출, 종속자료의 블록 재표집을 비교해 쓴다.
