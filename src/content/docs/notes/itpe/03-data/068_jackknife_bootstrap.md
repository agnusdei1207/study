## Ⅰ. 비모수적 재표본추출 기법, 잭나이프와 부트스트랩 개요

### 가. 재표본추출(Resampling)의 정의
- **재표본추출** : 모집단에 대한 강한 정규성 가정이나 복잡한 이론적 확률분포 공식에 의존하지 않고, 관측된 단일 표본 데이터셋으로부터 반복적으로 표본을 재추출하여 통계량의 **표준오차** (SE), **편향** (Bias), **신뢰구간** (CI)을 경험적으로 추정하는 컴퓨터 집약적 통계 방법론.

### 나. 전통적 모수 추정과 재표본추출의 차이
- 전통적 모수 추정 : "모집단이 정규분포를 따른다"는 수학적 가정이 필수적이며, 공식이 없는 복잡한 통계량(예: 중앙값, 상관계수의 신뢰구간) 추정 불가.
- **재표본추출** : 분포 무관(Distribution-free), 계산 알고리즘을 통해 어떤 복잡한 통계량의 불확실성도 직접 산출 가능.

## Ⅱ. 잭나이프(Jackknife) vs 부트스트랩(Bootstrap) 상세 비교

### 가. 재표본추출 메커니즘 비교

```text
[ 잭나이프 (하나씩 제외하는 비복원) ]
표본: [X1, X2, X3, ..., Xn]
  -> Subsample 1: [X2, X3, ..., Xn]  (X1 제외)  ===> 통계량 theta_(1)
  -> Subsample 2: [X1, X3, ..., Xn]  (X2 제외)  ===> 통계량 theta_(2)
  -> 총 n개의 결정론적 하위 표본 생성

[ 부트스트랩 (무작위 복원 추출) ]
표본: [X1, X2, X3, ..., Xn]
  -> Bootstrap 1: [X2, X2, X4, ..., X1] (복원 추출 n개) ===> 통계량 theta*_1
  -> Bootstrap B: [X3, X1, X1, ..., Xn] (복원 추출 n개) ===> 통계량 theta*_B
  -> 컴퓨터 난수로 B회(보통 1,000~10,000회) 무작위 시뮬레이션
```

### 나. 잭나이프 vs 부트스트랩 핵심 속성 비교

| 비교 항목 | 잭나이프 (Jackknife) | 부트스트랩 (Bootstrap) |
| :--- | :--- | :--- |
| 창안자 | 모리스 퀸유이(Quenouille, 1949), 튜키(Tukey) | 브래들리 에프론(Bradley Efron, 1979) |
| **추출 메커니즘** | 크기 $n$에서 1개 관측치를 순차적으로 제거 (Leave-One-Out, 비복원) | 원래 표본과 동일한 크기 $n$을 **복원 추출 (With Replacement)** |
| 생성 표본 수 | 정확히 $n$개로 고정 (결정론적) | 연구자가 지정한 반복 수 $B$회 (통상 1,000~10,000회, 확률적) |
| 계산 비용 | $O(n)$으로 상대적으로 가벼움 | $O(B \cdot n)$으로 컴퓨터 연산량 높음 |
| 활용 강점 | 추정량의 편향(Bias) 제거에 탁월 | 신뢰구간(CI) 추정, 복잡한 통계량의 표본분포 복원에 탁월 |
| 치명적 약점 | 중앙값(Median) 등 비평활(Non-smooth) 통계량에서 일치성 상실 | 원본 표본 크기가 너무 작으면($n < 15$) 원래 편향을 답습함 |

## Ⅲ. 머신러닝에서의 부트스트랩 응용: 배깅(Bagging)과 OOB

### 가. 복원 추출의 수학적 확률과 OOB (Out-of-Bag)
- 표본 크기 $n$인 데이터에서 복원 추출로 $n$개를 뽑을 때, 특정 데이터가 한 번도 선택되지 않을 확률:
  $$\lim_{n \to \infty} \left(1 - \frac{1}{n}\right)^n = \frac{1}{e} \approx 0.368 \quad (36.8\%)$$
- 즉, 각 부트스트랩 샘플에는 원래 데이터의 약 63.2%만 포함 되고, 나머지 36.8%는 **OOB** (Out-of-Bag) 데이터로 남음.

### 나. OOB 평가의 실무적 이점
- 별도의 독립된 검증 데이터셋(Validation Set)을 분리하지 않고도, 각 트리가 학습에 사용하지 않은 OOB 샘플들을 모아 모델의 일반화 오차(OOB Error)를 완벽히 교차 검증 가능.

## Ⅳ. 잭나이프 및 부트스트랩 적용 시 주요 한계점 및 해결 방안

- 부트스트랩의 계산 복잡도 및 대용량 데이터 환경에서의 연산 오버헤드 :
  - 한계점 : 신뢰구간 추정을 위해 수천~수만 번의 복원 복제 표본추출과 모델 적합을 반복해야 하므로 대규모 데이터 및 딥러닝 환경에서 계산 시간 폭증.
  - 해결 방안 : 계산 효율적인 소표본 리샘플링인 잭나이프($n$회 반복) 병행, 또는 파티션 단위로 분산 연산하는 Bag of Little Bootstraps(BLB) 알고리즘 활용.
- 시계열 및 공간 종속성 데이터에서의 i.i.d. 가정 위배로 인한 편향 :
  - 한계점 : 관측치 간 상관성이 존재하는 데이터에 단순 복원추출을 적용할 경우 시간적/공간적 종속 구조가 파괴되어 분산이 심각하게 과소 추정됨.
  - 해결 방안 : 연속된 데이터 블록 단위로 리샘플링하는 블록 부트스트랩(Moving Block Bootstrap, Stationary Bootstrap) 기법 적용.
- 분포의 극단치(Extreme Value) 및 비연속 통계량 추정 한계 :
  - 한계점 : 최댓값, 최솟값 등 극단 통계량이나 표본 중앙값과 같은 비매끄러운(Non-smooth) 통계량에 대해 잭나이프는 일관성을 상실하고 부트스트랩은 편향 유발.
  - 해결 방안 : $m$-out-of-$n$ 부트스트랩($m < n$) 기법을 채택하여 점근적 수렴성을 회복하거나 극단값 이론(EVT) 전용 모수적 모델 결합.

## Ⅴ. 데이터 분석 및 통계 모델링 관점의 실무 제언

- 작은 표본에서의 신뢰구간 추정 : 데이터가 정규분포를 따르지 않고 표본 크기가 30건 미만인 소표본 환경에서는 중심극한정리가 작동하지 않으므로, 부트스트랩 백분위수 신뢰구간(Percentile CI)이나 편향 보정 가속 신뢰구간(BCa CI)을 사용하여 보고서의 통계적 타당성을 확보해야 함.
- 시계열 데이터에서의 블록 부트스트랩(Block Bootstrap) 적용 : 데이터 간 시간적 자기상관성이 존재하는 시계열 데이터를 단순 무작위 복원 추출하면 시간 종속성이 파괴되므로, 연속된 일정 길이의 블록 단위로 묶어 복원 추출하는 Moving Block Bootstrap 기법을 적용할 것을 제언함.
