## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **잭나이프·부트스트랩(재표본추출)**

## 30초 인출

- 본질: 재표본화는 관측한 표본에서 새 표본을 만들어 통계량의 변동성(표준오차·편향·신뢰구간)을 평가하는 방법
- 메커니즘: 잭나이프는 관측값을 하나씩 제외해 n개의 통계량으로 편향과 분산을 추정하고, 부트스트랩은 n개를 복원추출하는 과정을 B번 반복해 통계량의 분포로 표준오차와 신뢰구간을 구함
- 통찰: 재표본화는 원표본이 대표성이 있고 재표본 단위가 표본 설계(독립·군집·시계열)에 맞을 때만 타당하므로 설계를 반영해 방식을 고르고 반복 수·난수 시드를 기록해 재현성을 확보

<details>
<summary>핵심 용어</summary>

- **재표본화(Resampling)** : 원표본에서 반복해 새 표본을 만드는 방법
- **잭나이프(Jackknife)** : 관측값을 하나씩 빼고 통계량을 재계산하는 leave-one-out 방법
- **부트스트랩(Bootstrap)** : 원표본에서 복원추출로 표본을 반복 생성하는 방법
- **표준오차** : 통계량의 표본 간 변동 크기
- **백분위수 신뢰구간** : 부트스트랩 통계량의 분위수로 구성한 구간
- **BCa** : 편향과 왜도를 보정한 부트스트랩 구간 방법
- **블록 부트스트랩** : 시계열 의존성을 보존하도록 연속 구간 단위로 재추출하는 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. 재표본화 기법의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **재표본화** 는 관측 표본에서 새 표본을 구성해 통계량의 변동성을 평가하는 방법 |
| 목적 | 표준오차·불확실성 평가와 구간 추정 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 원표본 재사용 | 새 관측 없이 통계량 변동 평가 |
| 추출 규칙 의존 | 하나씩 제외 / 복원추출 방법별 성질 차이 |
| 설계 보존 필요 | 독립성·군집·시계열 구조에 맞는 재표본 단위 |

## Ⅲ. 재표본화 절차

```text
관측 표본 {x1,…,xn}
 ├ 잭나이프: xi를 하나씩 제외 → n개의 통계량
 └ 부트스트랩: n개씩 복원추출 반복 → B개의 통계량
                       ↓
        표준오차·편향·신뢰구간 추정
```

| 부트스트랩 결과 | 활용 |
|---|---|
| 반복 통계량의 표준편차 | 표준오차 추정 |
| 반복 통계량의 분위수 | 백분위수 신뢰구간 |
| 편향 보정 | BCa 등 다른 구간 방법 |

## Ⅳ. 잭나이프·부트스트랩 비교

| 판단축 | 잭나이프 | 부트스트랩 |
|---|---|---|
| 생성 방식 | 결정론적 leave-one-out | 복원추출 모의 표본 |
| 계산 규모 | 표본 크기 n번 | 설정한 반복 횟수 B |
| 강점 | 간결한 재계산으로 편향·분산 추정 | 다양한 통계량의 변동·구간 평가 |
| 한계 | 비매끄러운 통계량(중앙값 등)에서 성질 악화 | 표본 수·자료 구조·모형에 따라 근사 제한 |

부트스트랩은 자료가 대표성이 있고 표본 설계를 반영한다는 전제 위에서 표본분포를 근사.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 시계열·군집의 의존성을 무시한 독립 재추출 | 블록·군집 등 표본 설계를 반영한 재표본화 |
| 작거나 대표성이 낮은 자료에서 없는 변동을 복원하지 못함 | 표본 선정 과정 검토와 민감도 분석 보완 |
| 산출 방식 미기록으로 재현 곤란 | 재표본 단위·반복 수·구간 방법·난수 시드 기록 |

## Ⅵ. 제언

통계량의 성질과 표본 설계로 방식을 정하고 설정을 기록해 결과를 재현

```text
매끄러운 통계량·간단 평가 → 잭나이프 / 다양한 통계량·구간 추정 → 부트스트랩(설계 반영)
```

| 구분 | 정규 가정 공식만 사용 | 제언: 재표본화 병행 |
|---|---|---|
| 분포 가정 | 필요 | 완화 |
| 재현성 | 공식 | 시드·반복 수 기록 |
