## 연관 키워드

**상관관계(Correlation)**, **피어슨(Pearson)**, **스피어만(Spearman)**, **편상관(Partial Correlation)**, **다중공선성**, **PCA**

## Ⅰ. 개요

- 핵심 요약 : **상관관계**는 두 변수 간 선형·단조 연관 강도를 나타내는 통계 척도 (-1~1).
- 목적 : 변수 간 연관성 정량화.
- 배경 : 변수 간 관계 파악 필요 → 상관계수.
- 특징 : 피어슨(선형), 스피어만(단조), 인과관계와 구별.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **피어슨·스피어만**으로 선형/단조 관계 측정.
- **피어슨** : 수치값 선형성, 정규성 가정, 이상치 민감.
- **스피어만** : 순위 기반 단조성, 비모수, 이상치 강건.
- **범위** : -1~1 (음/양/무 상관).
- **피처 스크리닝** : ML 전처리 연관성 평가.
- **다중공선성** : |r|≥0.8 변수 쌍 제거/PCA.

## Ⅲ. 계수 비교 흐름

- 핵심 요약 : **피어슨(선형) vs 스피어만(단조)** 선택.
- 피어슨 산식 : 공분산 / (σX·σY).
- 스피어만 산식 : 순위 피어슨 또는 $1 - 6\sum d_i^2/(n(n^2-1))$.

```text
[ 피어슨 vs 스피어만 선택 ]

데이터 연속·정규·선형 -> 피어슨
순서형·비정규·이상치 -> 스피어만
비선형 단조 (Y=X^3) -> 스피어만 (rho=1)
```

## Ⅳ. 피어슨 vs 스피어만 비교

- 핵심 요약 : **측정 관계·가정·이상치·비선형** 비교.

| 항목 | 피어슨 | 스피어만 |
|---|---|---|
| 측정 관계 | 선형 | 단조 |
| 데이터 요구 | 연속, 정규 | 연속/순서, 분포 무관 |
| 이상치 민감도 | 극도 민감 | 강건 (순위) |
| 비선형 포착 | 저하 (r<1) | 완벽 (rho=1) |
| 적용 사례 | 키-몸무게, 기온-전력 | 석차-등급, 만족도 순위 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **허위 상관·비선형·이상치**를 편상관·거리 상관·윈저라이징으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 허위 상관/교란변수 | 제3 변수로 인한 가짜 관계 | 편상관, DAG, 인과추론 | 편상관계수 |
| 비선형 관계 | U자/원형 관계를 0으로 산출 | 스피어만/켄달, 거리 상관, 상호정보량 | 비선형 의존성 |
| 이상치 취약성 | 극단값으로 계수 왜곡/반전 | 산점도 검증, 윈저라이징, 로버스트 상관 | 이상치 수 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **스피어만 우선·다중공선성 차단·인과 구분**.
- 피처 스크리닝 : 이상치·비선형 환경에서 스피어만 우선.
- 다중공선성 : |r|≥0.8 변수 쌍 제거 또는 PCA.
- 인과 구분 : 상관≠인과, 혼란변수 통제.

## Ⅶ. 결론

- 핵심 요약 : 상관관계는 **연관 강도 척도**로 피어슨/스피어만 선택과 인과 구분이 핵심.
- 답안에는 계수 비교, 허위 상관, 한계·대응을 연결.
- 참고 : [scipy.stats.pearsonr](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html).
