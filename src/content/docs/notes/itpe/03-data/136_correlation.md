## 연관 키워드

- 상관관계(Correlation), 피어슨 상관계수(Pearson), 스피어만 순위상관계수(Spearman)
- 편상관(Partial Correlation), 다중공선성(Multicollinearity), 주성분 분석(PCA)

## Ⅰ. 상관관계의 개요

- 핵심 요약 : 두 변수의 연관 방향과 강도를 -1에서 1 사이의 수치로 나타내며, 인과와 구별해 해석해야 하는 통계 척도.
- 개념 : 한 변수가 변할 때 다른 변수도 함께 변하는 정도를 나타내는 척도 (**상관관계**, Correlation).
- 배경 및 필요성 : 변수가 많은 분석에서는 모델링 전에 변수 간 관계를 먼저 파악해야 변수 선택과 모델 설계가 가능하므로 연관성의 정량화가 필요함.
- 주요 목적 : 변수 간 연관 강도를 정량화하고, 분석에 쓸 변수를 선별하는 근거를 마련.

## Ⅱ. 상관관계의 특징 및 장점

- 핵심 요약 : 피어슨과 스피어만은 각각 선형성과 단조성을 측정하므로, 데이터 성격에 맞춰 고를 때 해석이 신뢰됨.

1. **피어슨 상관계수** (Pearson Correlation Coefficient) : 두 변수의 공분산을 표준편차의 곱으로 나눈 값 → 선형 관계의 강도를 측정하며, 정규성 가정을 두고 이상치에 민감함.
2. **스피어만 순위상관계수** (Spearman Rank Correlation Coefficient) : 값을 순위로 바꾼 뒤 피어슨 방식으로 계산 → 단조 관계를 측정하며, 분포에 무관하고 이상치에 강건함.
3. 범위 : -1에서 1 사이이며, 부호는 방향, 절댓값은 강도를 뜻해 해석 기준이 단순함.
4. 피처 스크리닝 : 목표 변수와 연관이 약한 입력 변수를 전처리 단계에서 걸러내 모델 복잡도를 낮춤.
5. **다중공선성** (Multicollinearity, 입력 변수끼리의 강한 상관) : 상관이 매우 강한 변수 쌍(통상 |r| 0.8 이상)은 하나를 제거하거나 주성분 분석(PCA, Principal Component Analysis)으로 축약해 회귀 계수의 불안정성을 완화함.

## Ⅲ. 상관계수 선택의 흐름 (구조)

- 핵심 요약 : 데이터 성격을 먼저 확인해 피어슨과 스피어만 중 계수를 고르고, 해석 전에는 교란변수를 점검하는 절차.
- 피어슨 계산 : 공분산을 두 변수 표준편차의 곱으로 나눈 값.
- 스피어만 계산 : 순위 차이의 제곱합을 이용하는 식, 또는 순위에 피어슨을 적용한 값.

```text
[ 계수 선택 흐름 ]

변수 성격 확인
      ↓
연속·정규·선형 관계인가?
      ↓ 예 -> 피어슨
      ↓ 아니오
순서형·비정규·이상치 존재 -> 스피어만
```

```text
[ 상관 해석 절차 ]

산점도로 관계 모양 확인
      ↓
계수 산출 (피어슨 또는 스피어만)
      ↓
교란변수 점검 (편상관)
      ↓
인과 주장 전 추가 검증
```

## Ⅳ. 피어슨과 스피어만의 비교

- 핵심 요약 : 측정하는 관계의 형태와 가정, 이상치 민감도에서 두 계수가 뚜렷이 갈림.

| 항목 | 피어슨 | 스피어만 |
| --- | --- | --- |
| 측정 관계 | 선형 | 단조 |
| 데이터 요구 | 연속형, 정규성 가정 | 연속형 또는 순서형, 분포 무관 |
| 이상치 민감도 | 높음 | 낮음 (순위 기반) |
| 비선형 단조 관계 | 1보다 작게 산출되어 과소 측정 | 단조 증가면 1로 산출 |
| 적용 예 | 키와 몸무게, 기온과 전력 소비 | 석차와 등급, 만족도 순위 |

## Ⅴ. 상관관계의 한계와 방안

- 핵심 요약 : 허위 상관, 비선형 관계, 이상치를 편상관, 순위 기반 계수, 윈저라이징으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 허위 상관·교란 | 제3의 변수가 두 변수를 함께 움직여 가짜 관계 발생 | 편상관으로 교란변수 통제, DAG(Directed Acyclic Graph, 방향성 비순환 그래프)로 경로 점검 | 편상관계수 변화 |
| 비선형 관계 | U자형처럼 관계가 있어도 피어슨은 0 근처로 산출 | 스피어만 또는 켄달 순위상관, 거리 상관, 상호정보량 활용 | 비선형 의존성 지표 |
| 이상치 취약성 | 극단값 하나가 계수를 왜곡 | 산점도로 사전 확인, 윈저라이징(winsorizing) 처리, 로버스트 상관 적용 | 이상치 개수 |

## Ⅵ. 상관관계에 대한 기술사적 제언

- 핵심 요약 : 스크리닝에는 스피어만을 우선 쓰고, 상관 결과를 인과로 해석하지 않도록 보고 원칙을 세우는 것이 바람직함.

1. 이상치가 잦거나 비선형 관계가 의심되는 데이터에서는 스피어만 계수로 먼저 스크리닝하고, 산점도로 결과를 함께 확인하는 것이 안전하다.
2. 입력 변수 간 강한 상관이 확인되면 한 변수를 제거하거나 PCA로 축약해 모델의 안정성을 확보하는 것이 좋다.
3. 상관 분석 결과는 원인이 아니라 함께 움직인다는 사실로 기술하고, 혼란변수를 통제하지 않은 상태에서 인과 결론을 내리지 않도록 보고 기준을 정하는 것이 바람직하다.

## Ⅶ. 결론

- 핵심 요약 : 상관관계는 변수 간 연관 강도를 나타내는 척도로, 계수 선택과 인과 구분이 해석의 핵심임.
- 시사점 : 상관계수는 탐색의 출발점일 뿐 인과의 증거가 아니므로, 교란변수 점검과 후속 검증이 함께 따라야 함.
