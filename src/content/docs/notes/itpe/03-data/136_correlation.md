## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **상관관계 vs 인과관계**

## 30초 인출

- 본질: 상관관계는 두 변수의 값이 함께 변하는 방향과 정도를 나타내는 통계적 연관성
- 메커니즘: 산점도로 이상치·집단 구조를 확인한 뒤, 선형 관계는 Pearson(공분산을 표준편차로 나눈 r), 단조 관계는 Spearman(순위의 Pearson 상관 ρ)을 선택하고 불확실성을 보고하며 교란·다중검정을 검토
- 통찰: 계수와 p값은 인과를 입증하지 않고 이상치·집단 혼합·선택 편향에 따라 바뀌므로, 계수 하나로 요약하지 않고 산점도와 집단별 관계를 확인하며 인과 판단은 설계와 별도 분석으로 수행

<details>
<summary>핵심 용어</summary>

- **상관관계(Correlation)** : 두 변수가 함께 변하는 통계적 연관성
- **피어슨 상관계수(r)** : 원자료의 선형 연관성의 방향·강도를 −1~1로 나타낸 계수
- **스피어만 순위상관계수(ρ)** : 순위 사이의 단조 연관성을 나타낸 계수
- **허위상관** : 인과가 확립되지 않은 변수 사이에서 관측된 연관성
- **편상관** : 지정한 변수의 선형 영향을 제거한 뒤의 상관
- **다중검정** : 많은 변수 쌍을 반복 검정해 우연한 발견이 늘어나는 문제

</details>

## 2~4교시 25점 답안

## Ⅰ. 상관관계의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **상관관계** 는 두 변수의 값이 함께 변하는 방향과 정도를 나타내는 통계적 연관성 |
| 목적 | 변수 간 관계를 요약해 분석 가설과 후속 검토의 근거 제공 |

## Ⅱ. 특징

| 특징 | 해석상 의미 |
|---|---|
| 방향과 강도 | 계수의 부호와 절댓값이 방향·정도를 요약 |
| 형태 의존 | 선형·단조·비선형 중 무엇을 재는지에 따라 계수 선택 |
| 분포·표본 영향 | 이상치·집단 혼합·선택 편향이 계수를 바꿈 |
| 비인과성 | 함께 변해도 원인·결과는 정해지지 않음 |

## Ⅲ. 분석 절차

```text
두 변수의 표본·생성 맥락 확인 → 산점도·이상치·집단 구조 확인
   ↓ 관계 형태에 맞는 계수 선택
계수·불확실성 산출 → 교란·다중검정 검토 → 연관성 보고, 인과는 별도 검증
```

```text
Pearson : (x − x̄)(y − ȳ)의 합 ÷ √(Σ(x − x̄)² · Σ(y − ȳ)²)  →  −1 ≤ r ≤ 1
Spearman: x, y를 각각 순위로 변환 → 순위쌍의 Pearson 상관 → ρ
```

## Ⅳ. Pearson·Spearman 비교와 인과와의 구별

| 기준 | Pearson r | Spearman ρ |
|---|---|---|
| 입력 | 원자료 값 | 순위로 변환한 값 |
| 관계 | 선형 연관성 | 단조 연관성 |
| 주의 | 이상치·비선형에 민감 | 순위 변환으로 크기 정보 일부 미사용 |
| 해석 | 공분산을 표준편차로 나눈 무차원 값 | 순위 자료의 Pearson 상관 |

| 구분 | 상관관계 | 인과관계 |
|---|---|---|
| 의미 | 함께 변함 | 한 변수의 변화가 다른 변수를 변화시킴 |
| 필요 근거 | 자료의 연관 | 시간 순서·교란 통제·설계(실험 등) |

편상관은 지정한 공변량의 선형 영향을 제거하지만 미측정 교란을 배제하거나 인과를 보장하지 못함.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 비선형·집단 혼합을 계수 하나가 숨김 | 산점도·집단별 관계 확인 후 계수 선택 |
| 이상치·표본 선택으로 왜곡 | 원자료·추출 과정과 민감도 분석 병행 |
| 공통 원인·역인과를 인과로 오인 | 시간 순서·교란요인·설계 근거 검토, 인과는 별도 분석 |
| 많은 변수 쌍 반복 검사로 우연한 연관 발견 | 사전 가설·다중검정 보정·독립 자료 검증 |

## Ⅵ. 제언

산점도로 관계 형태를 확인해 계수를 고르고, 연관성은 상관으로 보고하되 인과 주장은 설계로 검증

```text
산점도 확인 → 선형 Pearson / 단조·이상치 Spearman → 교란·다중검정 검토 → 인과는 실험·인과 분석
```

| 구분 | 상관계수 하나로 결론 | 제언: 형태 확인 + 인과 분리 |
|---|---|---|
| 비선형·이상치 | 오판 | 산점도로 발견 |
| 인과 | 오해 | 별도 검증 |
