## Ⅰ. 두 변수 간의 통계적 연관성, 상관관계(Correlation)의 개요

### 가. 상관관계의 정의
- 두 개 이상의 확률변수들이 서로 관련되어 함께 변화하는 경향성이나 선형적·단조적 연관의 강도를 나타내는 통계적 척도.
- 한 변수의 값이 증가할 때 다른 변수의 값도 함께 증가하는 **양의 상관관계**, 반대로 감소하는 **음의 상관관계**, 그리고 아무런 연관이 없는 **무상관** 으로 구분됨.

### 나. 상관관계($-1 \le r \le 1$)의 해석 기준

```text
[ 상관계수 r의 범위 및 강도 ]
  -1.0            -0.7            -0.3             0.0             +0.3            +0.7            +1.0
   |---------------+---------------+---------------+---------------+---------------+---------------+---|
[완벽 음의 선형]   [강한 음의 상관] [약한 음의 상관]   [상관관계 없음]  [약한 양의 상관] [강한 양의 상관] [완벽 양의 선형]
```

## Ⅱ. 피어슨(Pearson) vs 스피어만(Spearman) 상관계수 심층 비교

### 가. 두 상관계수의 산식 및 수학적 원리

```text
[ 피어슨 (수치값 자체의 선형성) ]
         sum (X - ar{X})(Y - ar{Y})
  r = ----------------------------------------   -> 공분산을 각 변수의 표준편차의 곱으로 정규화
      sqrt{sum (X - ar{X})^2 * sum (Y - ar{Y})^2}

[ 스피어만 (값의 순위 기반 단조성) ]
             6 sum d_i^2
  
ho = 1 - --------------   (d_i = Rank(X_i) - Rank(Y_i), 값들을 순위로 변환 후 피어슨 계산)
               n(n^2 - 1)
```

### 나. 피어슨 vs 스피어만 핵심 속성 비교 매트릭스

| 비교 항목 | 피어슨 상관계수 (Pearson $r$) | 스피어만 순위상관계수 (Spearman $\rho$) |
| :--- | :--- | :--- |
| **측정하는 관계** | 두 변수 간의 **선형적 관계 (Linearity)** | 두 변수 간의 **단조적 관계 (Monotonicity)** |
| **데이터 요구 조건** | 연속형(등간/비율 척도), **정규분포 가정 필수** | 연속형 및 순서형(서열 척도), **분포 무관(비모수)** |
| **이상치(Outlier) 민감도** | 이상치 1개에 의해 계수 값이 극단적으로 왜곡됨 | 값의 순위(Rank)만 사용하므로 **이상치에 매우 강건(Robust)** |
| **비선형 관계 포착** | $Y = X^3$과 같은 비선형 단조 증가 시 $r < 1$로 저하 | $Y = X^3$과 같은 비선형이라도 순위가 일치하면 **$\rho = 1.0$ 달성** |
| **대표 적용 사례** | 키와 몸무게, 기온과 전력 소비량 | 학업 석차와 수능 등급, 고객 만족도 순위 평가 |

## Ⅲ. 상관관계 분석 시의 핵심 주의점: 인과관계와의 구별

### 가. "상관관계는 인과관계가 아니다 (Correlation does not imply Causation)"
- 두 변수 간에 상관계수가 매우 높더라도, 그것이 원인과 결과의 관계를 증명하지는 않음.
- **제3의 교란변수 (Confounder)** : "아이스크림 판매량과 익사 사고 건수는 양의 상관관계($r=0.9$)" $\rightarrow$ 원인은 두 변수를 동시에 유발한 제3의 변수인 **'여름철 기온 상승'** 때문임.
- **허위 상관 (Spurious Correlation)** : 아무런 실질적 관계가 없는 두 시계열(예: 미국의 과학 예산과 자살률)이 우연히 시간에 따라 동시에 증가하여 높은 상관계수를 나타내는 현상.

## Ⅳ. 상관관계 분석의 주요 한계점 및 해결 방안

- **허위 상관(Spurious Correlation) 및 잠재 혼란 변수(Confounder)의 간과** :
  - **한계점** : 두 변수가 통계적으로 높은 상관계수를 보이더라도 제3의 잠재 변수로 인한 가짜 관계를 인과관계로 오판하여 비즈니스 의사결정 왜곡.
  - **해결 방안** : 편상관분석(Partial Correlation)을 통한 혼란 변수 통제, 도메인 지식 기반 인과 다이어그램(DAG: Directed Acyclic Graph) 작성 및 인과추론 기법 병행.
- **비선형 관계(Non-linear Relationship) 탐색의 무력화** :
  - **한계점** : U자형 곡선이나 원형 관계와 같이 명백하고 강한 종속성이 존재하더라도 피어슨 상관계수는 0으로 산출되어 유의미한 패턴 누락.
  - **해결 방안** : 순위 기반 스피어만(Spearman) / 켄달(Kendall) 계수 병행, 비선형 의존성을 포착하는 거리 상관계수(Distance Correlation) 및 상호정보량(Mutual Information) 활용.
- **이상치(Outlier)에 대한 극도의 취약성** :
  - **한계점** : 단 몇 개의 극단적 이상치만으로도 상관계수가 0에서 0.9로 왜곡되거나 정반대로 반전되어 피처 엔지니어링 시 잘못된 변수 선택 유발.
  - **해결 방안** : 산점도(Scatter Plot) 시각화 필수 검증, 절단(Trimmed) 또는 윈저라이징(Winsorizing) 전처리, 로버스트 상관계수(Robust Correlation) 적용.

## Ⅴ. 머신러닝 피처 엔지니어링 실무 제언

- **피처 선택(Feature Selection) 시 스피어만 활용** : 머신러닝 전처리 단계에서 타깃 변수와 피처 간의 연관성을 스크리닝할 때, 비선형 관계가 흔하고 이상치가 포함된 정형 데이터셋에서는 피어슨 대신 **스피어만 상관계수를 우선 기준** 으로 삼는 것이 유용한 피처의 조기 탈락을 방지함.
- **다중공선성(Multicollinearity) 선제 차단** : 독립변수 간 피어슨 상관계수가 $|r| \ge 0.8$ 이상인 변수 쌍이 발견되면, 회귀 모델의 안정성을 위해 둘 중 하나를 제거하거나 주성분 분석(PCA)으로 결합 차원 축소할 것을 제언함.
