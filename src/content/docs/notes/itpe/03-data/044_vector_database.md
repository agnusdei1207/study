## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터베이스 유형 → **벡터 데이터베이스(HNSW·IVF)**

## 30초 인출

- 본질: 벡터 데이터베이스는 임베딩 벡터와 관련 데이터를 저장하고 유사도 검색을 지원하는 데이터 시스템
- 메커니즘: 임베딩 모델로 만든 벡터를 HNSW(다층 근접 그래프)나 IVF(중심점별 리스트) 같은 근사 최근접 색인에 저장하고, 질의 벡터에 가까운 후보만 탐색한 뒤 메타데이터 조건으로 결과를 제한
- 통찰: 근사 탐색은 속도를 얻는 대신 일부 최근접을 놓칠 수 있으므로 정확 검색과 비교해 재현율·지연·메모리를 조정하고 필터 조건을 포함한 대표 질의로 검증

<details>
<summary>핵심 용어</summary>

- **벡터 데이터베이스** : 벡터를 저장하고 유사도 기반으로 검색하는 데이터베이스
- **임베딩(Embedding)** : 자료의 의미를 고정 길이 벡터로 나타낸 표현
- **ANN(Approximate Nearest Neighbor)** : 정확한 최근접 대신 근사 최근접을 빠르게 찾는 탐색
- **HNSW** : 다층 근접 그래프로 상위에서 하위로 후보를 좁히는 색인
- **IVF(Inverted File Index)** : 벡터를 중심점별 리스트로 나누고 가까운 리스트만 탐색하는 색인
- **재현율(Recall)** : 실제 최근접 중 검색 결과에 포함된 비율
- **메타데이터 필터** : 속성·권한 조건으로 결과 범위를 제한하는 조건

</details>

## 2~4교시 25점 답안

## Ⅰ. 벡터 데이터베이스의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **벡터 데이터베이스** 는 벡터와 관련 데이터를 저장하고 유사도 검색을 지원하는 시스템 |
| 목적 | 대규모 벡터에서 의미상 가까운 자료를 찾아 검색·분석 서비스에 제공 |

## Ⅱ. 특징

| 특징 | 설계 영향 |
|---|---|
| 임베딩 의존 | 저장·질의 벡터의 모델·차원·전처리 일치 필요 |
| 근사 탐색 | 재현율·지연·메모리 절충 |
| 속성 필터 결합 | 권한·조건 적용 순서가 후보 집합과 비용에 영향 |

## Ⅲ. 구성과 검색 흐름

```text
임베딩 모델 → 벡터 생성 → 벡터 색인(HNSW·IVF)
질의 벡터 ────────────→ 근접 후보 검색 ← 메타데이터 조건으로 범위 제한
근접도·조건을 충족한 ID → 객체·속성 조회
```

| 구성요소 | 역할 | 확인사항 |
|---|---|---|
| 벡터 생성 | 자료를 벡터화 | 모델·차원·전처리 호환 |
| 거리 기준 | 근접도 계산 | 모델에 맞는 거리·유사도 함수 |
| 색인 | 후보 탐색 가속 | 재현율·지연·메모리·구축 비용 |
| 필터 | 메타데이터 범위 제한 | 적용 순서와 색인의 상호작용 |

## Ⅳ. HNSW와 IVF의 동작원리

```text
HNSW: 질의 → 상위 계층(성긴 그래프)에서 가까운 노드로 이동 → 하위 계층에서 후보 정밀화
IVF : 질의 → 가까운 중심점 몇 개 선택 → 선택된 리스트의 벡터만 비교
```

| 기준 | HNSW | IVF |
|---|---|---|
| 색인 구조 | 다층 근접 그래프 | 중심점별 벡터 리스트 |
| 탐색 | 상위에서 후보를 좁혀 하위로 탐색 | 가까운 일부 리스트만 탐색 |
| 절충 | 구축 시간·메모리 vs 검색 품질·속도 | 탐색 리스트 수 vs 속도·재현율 |
| 데이터 반영 | 추가·갱신 특성은 구현에 따라 확인 | 분포를 반영해 구축하므로 갱신·재구축 방식 확인 |

| 구분 | 정확 최근접 | ANN |
|---|---|---|
| 후보 | 전체 거리 비교 | 색인이 고른 일부 후보 |
| 결과 | 정확한 최근접 | 일부 누락 가능 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 탐색 범위를 줄이면 재현율 저하 | 필터 포함 대표 질의를 정확 검색과 비교해 조정 |
| 필터·색인 설정 변경으로 자원 비용 증가 | 실제 필터에서 메모리·지연·갱신 비용 측정 |

## Ⅵ. 제언

색인 방식은 데이터 규모·갱신 빈도·재현율 요구로 정하고, 정확 검색과 비교해 매개변수를 튜닝

```text
데이터 규모·갱신 빈도·재현율 목표 → 색인 선택(HNSW·IVF) → 정확 검색 대비 재현율 측정 → 튜닝
```

| 구분 | 전수 비교 | 제언: 근사 색인 + 재현율 검증 |
|---|---|---|
| 지연 | 규모에 비례 | 단축 |
| 정확도 | 완전 | 재현율로 관리 |
