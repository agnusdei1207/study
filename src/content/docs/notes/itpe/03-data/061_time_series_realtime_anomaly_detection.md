## 지식 로드맵 내 현재 위치

자료처리·데이터 → 분석·통계·AI → **시계열 실시간 이상치 탐지**

## 30초 인출

- 본질: 수신 중인 시계열에서 정상 패턴에서 벗어난 관측을 지연 없이 판별하는 탐지 체계
- 메커니즘: 유입 데이터의 스트림 처리로 최근 윈도우 통계·예측 잔차를 산출하고 임계값·모형 판정으로 점·콘텍스트·집단 이상치를 분류
- 통찰: 지연 시간을 최소화하고 거짓 경보(False Alarm)를 억제하기 위해 이동 동적 임계치와 비지도 학습(오토인코더, Isolation Forest)을 결합한 스트리밍 파이프라인 필수

<details>
<summary>핵심 용어</summary>

- **점 이상치(Point Anomaly)** : 시점 위치와 무관하게 정상 범위를 벗어난 단일 관측값
- **콘텍스트 이상치(Contextual Anomaly)** : 값 자체는 평범하나 해당 시점의 추세·계절 맥락에서 비정상인 관측
- **집단 이상치(Collective Anomaly)** : 개별 값은 정상 범위여도 연속 구간의 패턴이 정상과 다른 이상
- **레벨 시프트(Level Shift)** : 특정 시점부터 평균 수준이 새 값으로 옮겨 가는 변화
- **잔차(Residual)** : 모형·예측값과 실제 관측값의 차이, 이상 판정의 1차 근거
- **윈도우 처리(Windowing)** : 최근 일정 구간의 데이터만 대상으로 통계·모형을 갱신하는 스트림 처리 방식
- **오토인코더(Autoencoder)** : 입력을 압축 후 복원하도록 학습해 재구성 오차로 이상을 판정하는 신경망
- **LSTM(Long Short-Term Memory)** : 장기 의존성을 반영한 순환 신경망, 시계열 예측 오차 기반 탐지에 활용

## 2~4교시 25점 답안

## Ⅰ. 시계열 실시간 이상치 탐지의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 스트림으로 유입되는 시계열에서 정상 패턴을 벗어난 관측·구간을 지연 없이 판별하는 체계 |
| 목적 | 장애·부정·설비 이상의 사후 분석 비용을 실시간 차단 비용으로 전환, 서비스 연속성과 신뢰 확보 |

## Ⅱ. 시계열 이상치 유형의 핵심 특징

| 유형 | 정상과의 차이 |
|---|---|
| 점 이상치(Point Anomaly) | 단일 관측값의 정상 범위 이탈, 급등락 스파이크 |
| 콘텍스트 이상치(Contextual Anomaly) | 절대 값은 정상이나 시점 맥락(심야 시간대·비수기)에서의 이탈 |
| 집단 이상치(Collective Anomaly) | 연속 구간의 패턴 이탈, 반복 실패·비정상 주기 |
| 수준·변동 이상 | 레벨 시프트(Level Shift)·분산 확대 같은 구조 변화 |

## Ⅲ. 실시간 이상치 탐지 체계와 판정 흐름

### 실시간 탐지 파이프라인 전체 구조

```text
수집 계층 (로그·지표·센서 이벤트)
    ↓
스트림 처리 (윈도우 집계·특성화)
    ↓
정상 기준 모형 (이동평균·ARIMA·딥러닝 예측)
    ↓
판정 계층
    ├─ 잔차·확률 → 임계값 이내 → 정상
    └─ 임계값 초과·재구성 오차 초과 → 이상
    ↓
알림·대응 (등급화·원인 연계·기록)
```

### 판정 확대: 잔차 기반 이상 분기

```text
관측값과 정상 기준 모형의 예측값 비교
    ↓
잔차 = |실제값 − 예측값| 산출
    ↓
판정
    ├─ 잔차 ≤ 동적 임계값 → 정상 처리
    ├─ 잔차 > 임계값·연속 구간 지속 → 집단 이상 검토
    └─ 잔차 > 임계값·단발 → 점 이상 처리
```

| 방식 계열 | 대표 기법 | 실시간 적합성 |
|---|---|---|
| 통계 기반 | 3σ·Z-score, IQR, 이동평균·지수평활 잔차 | 연산 경량, 윈도우 통계 즉시 산출 |
| 모형 예측 기반 | ARIMA·지수평활의 예측 오차 판정 | 정상 기준 모형과의 잔차 판정 |
| 분해 기반 | 추세·계절·잔차 분해 후 잔차 감시 | 계절성 데이터의 맥락 반영 |
| 밀도·거리 기반 | k-NN 거리·국소 이상 인수 | 유입마다 근접 계산 비용 |
| 딥러닝 기반 | LSTM 예측, 오토인코더 재구성 오차 | 학습 비용 크나 복잡 패턴 판별 |

## Ⅳ. 탐지 방식과 딥러닝 기법 비교

| 비교축 | 통계 기반 | 모형 예측 기반 | 딥러닝 기반 |
|---|---|---|---|
| 판정 근거 | 분포·구간 가정과의 거리 | 예측 잔차 | 예측 오차·재구성 오차 |
| 대표 기법 | Z-score·IQR·이동평균 | ARIMA·지수평활 | LSTM·오토인코더·VAE·GAN |
| 맥락·비선형 반영 | 제한적 | 선형 추세·계절 수준 | 다변량·비선형 패턴 반영 |
| 계산·운영 부담 | 경량 | 중간 | 학습·추론 자원 요구 |
| 적합 용도 | 1차 필터·즉시 판정 | 계절·추세 데이터의 기준선 | 복잡 다변량 지표의 정밀 판정 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 고정 임계값의 시간대·계절·부하 변동 미반영으로 오경보·탐지 누락 | 시간대·요일별 기준선과 동적 임계값 적용 |
| 딥러닝 모형의 학습 데이터 의존과 추론 지연 | 경량 통계 기법의 1차 필터와 딥러닝 판정의 계층화 |
| 이상 알림 폭증에 따른 경보 피로와 대응 지연 | 알림 집계·등급화와 원인 지표 연계의 상태 페이지 운영 |
| 정상 라벨 부족으로 지도 학습 적용 곤란 | 비지도·준지도 판정과 운영자 피드백의 재학습 반영 |

## Ⅵ. 제언

Kafka와 Flink 기반의 실시간 스트리밍 인프라에 EWMA 및 LSTM 오토인코더를 연동하여 트렌드 변화와 스파이크 이상을 즉각 분별 통제.

### 실시간 시계열 이상탐지 스트리밍 아키텍처

```text
[센서/서버 실시간 메트릭] ──► [메시지 브로커 (Kafka)]
                                       │
                                       ▼
[스트림 프로세싱 엔진 (Apache Flink / Spark Streaming)]
  - 롤링 윈도우 집계 (Sliding Window)
  - 동적 임계치 계산 (EWMA / Dynamic Threshold)
  - 머신러닝 이상 점수 산출 (LSTM Autoencoder / Isolation Forest)
                                       │
         ┌─────────────────────────────┴─────────────────────────────┐
         ▼                                                           ▼
[이상 점수 > 임계치] : 즉각 알람/장애 격리            [정상 데이터] : 시계열 DB 적재
```

### 선택 근거: 제언: 실시간 동적 임계치 및 AI

| 구분 | 정적 임계치 방식 (Static) | 제언: 실시간 동적 임계치 및 AI |
|---|---|---|
| 패턴 변화 적응 | 주간/야간 트래픽 변화 시 오탐 다발 | 계절성 및 추세 반영한 동적 밴드(Band) 생성 |
| 이상 탐지 유형 | 단순 상한/하한 초과만 탐지 | 복합 다변량 이상 및 미세 트렌드 붕괴 탐지 |
| 처리 지연시간 | 배치 분석으로 사후 인지 | 스트림 엔진 기반 밀리초 단위 즉시 알람 |
