## Ⅰ. 시계열 실시간 이상탐지의 개요

- 핵심 요약 : 시계열 실시간 이상탐지는 시간순 스트림의 수준·추세·계절·잔차에서 정상 패턴과 다른 관측·변화를 지연 제약 내 탐지하는 과정.
- 개념 : 시계열 실시간 이상탐지는 시간순 스트림의 수준·추세·계절·잔차에서 정상 패턴과 다른 관측·변화를 지연 제약 내 탐지하는 과정.
- 배경 및 필요성 : 운영·IoT·거래 데이터의 이상은 발생 즉시 대응할수록 손실 감소.
- 주요 목적 : 낮은 지연으로 이상징후를 탐지하고 조사·대응 촉진.

## Ⅱ. 시계열 실시간 이상탐지의 특징 및 장점

- 핵심 요약 : 기준선: 계절·요일·추세 반영 → 맥락 기반 이상 판정; 온라인 통계: EWMA·CUSUM·예측잔차 → 점·변화 탐지; 스트림 운영: 이벤트시간·지연·중복 처리 → 실시간 결과 신뢰성.

3. 스트림 운영: 이벤트시간·지연·중복 처리 → 실시간 결과 신뢰성

## Ⅲ. 시계열 실시간 이상탐지의 구조 (흐름)

- 핵심 요약 : 이벤트 수집·시간 정렬 → 기준선·특징 갱신 → 점수·임계치·변화 탐지 → 알림 억제·우선순위화 → 운영자 피드백·모델 갱신.

```text
이벤트 수집·시간 정렬
  ↓
기준선·특징 갱신
  ↓
점수·임계치·변화 탐지
  ↓
알림 억제·우선순위화
  ↓
운영자 피드백·모델 갱신
```

- 핵심 구성 : 데이터 스트림 → 시간·품질 정렬 → 기준선/모델 → 이상점수 → 임계치·알림 → 조사·조치

## Ⅴ. 시계열 실시간 이상탐지의 한계와 방안

- 핵심 요약 : 계절·추세 오탐·지연·중복 이벤트 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 계절·추세 오탐 | 정상적인 주기 변화가 이상으로 판정 | 시간대·계절성 포함 기준선 구축 | 오탐률 |
| 지연·중복 이벤트 | 이벤트시간과 처리시간 차이로 점수 왜곡 | watermark·중복 제거·늦은 데이터 정책 | 탐지 지연 |
| 알림 피로 | 과다 경보가 대응자 신뢰 저하 | 심각도·상관경보·억제·온콜 절차 정립 | 알림당 조치율 |

## Ⅵ. 시계열 실시간 이상탐지의 제언

- 핵심 요약 : 운영팀은 이상 정의·탐지 지연 목표·담당자 조치 경로를 SLO로 정하고 이벤트시간·경보 피드백을 데이터 계보에 기록.
- 실행 제안 : 운영자는 이벤트시간 watermark·경보 임계치·온콜 담당을 명확히 하고 오탐·미탐 사례를 기준선에 반영.

## Ⅶ. 시계열 실시간 이상탐지의 결론

- 핵심 요약 : 실시간성만 빠른 탐지로 이어지지 않으며 계절 기준선·이벤트 시간 의미·실행 가능한 경보가 함께 필요.
- 시사점 : 실시간 경보는 탐지 민감도와 함께 지연·오탐 비용·현장 조치 가능성을 고려해 운영.
