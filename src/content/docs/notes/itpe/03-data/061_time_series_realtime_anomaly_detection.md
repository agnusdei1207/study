## 연관 키워드

**시계열 이상탐지**, **점·문맥·집단 이상**, **스트림 처리**, **슬라이딩 윈도우**, **동적 임계값**, **오경보**, **드리프트**

## Ⅰ. 개요

- 핵심 요약 : **시계열 이상탐지**는 시간에 따라 들어오는 데이터를 분석해 정상 패턴에서 벗어난 값을 찾아내는 기술이다.
- 적용 대상 : 서버·네트워크 지표, 금융 거래, 산업 센서 등 연속 관측 데이터.
- 목적 : 장애·사기·설비 이상을 조기에 발견해 대응 시간을 줄인다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **시간 문맥과 정상 패턴의 변화**를 고려하면 단순 고정 임계값보다 다양한 이상을 탐지할 수 있다.
- **점 이상** : 한 시점 값이 주변과 크게 다른 경우.
- **문맥 이상** : 값 자체는 흔해도 시간·조건에 비춰 비정상인 경우.
- **집단 이상** : 개별 값은 정상 범위라도 시퀀스 전체의 패턴이 비정상인 경우.
- **스트리밍 분석** : 윈도우·온라인 알고리즘으로 데이터 도착 후 빠르게 점수화한다.

## Ⅲ. 실시간 탐지 처리 흐름

- 핵심 요약 : **수집 → 정제·윈도우 처리 → 기준선·이상 점수 → 경보·피드백**으로 운영한다.

```text
[메트릭·이벤트 수집]
          ▼
[시간 정렬·결측·중복 처리]
          ▼
[윈도우 특징·정상 기준선]
          ▼
[규칙·통계·ML 이상 점수]
          ▼
[경보 억제·우선순위 지정]
          ▼
[운영자 조치·피드백]
```

- 데이터 지연·시간대·계절성을 반영해 기준선을 구성하고, 결과를 실제 운영 조치와 연결한다.
- 탐지 점수와 경보 정책은 분리해 민감도 변경이 탐지 모델 전체를 불필요하게 바꾸지 않게 한다.

## Ⅳ. 알고리즘 비교

- 핵심 요약 : **단순하고 빠른 기법부터 복잡한 모델까지**, 데이터 특성과 지연 허용치에 맞춰 선택한다.

| 기법 | 장점 | 한계·유의점 |
|---|---|---|
| 고정 임계값 | 단순하고 설명이 쉬움 | 계절·추세에 취약 |
| EWMA·이동 통계 | 계산이 가볍고 최근 변화 반영 | 복잡한 패턴은 놓칠 수 있음 |
| 계절 기준선·잔차 | 반복 패턴과 추세 고려 | 기준선 학습 및 갱신 필요 |
| Isolation Forest 등 | 다변량 이상 점수에 활용 | 파라미터·분포 변화 영향 |
| 시퀀스 오토인코더 | 비선형 시계열 패턴 학습 가능 | 학습·추론 비용, 설명과 검증 부담 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **오경보·처리 지연·정답 라벨 부족**이 실시간 탐지의 주요 운영 문제다.
- **정상 변동의 오탐** → 시간대·요일별 기준선과 지속 시간 조건을 적용하고 임계값을 재평가한다.
- **고빈도 입력 지연** → 윈도우 집계·샘플링·경량 점수화를 적용하고 지연·백로그를 감시한다.
- **라벨 부족** → 운영자 피드백과 사고 후 분석을 모아 탐지 결과를 검증한다.
- **정상 패턴 변화** → 오차 분포와 입력 변화를 감시하고 검증된 기준선·모델로 갱신한다.

```text
정상 변동 오탐 → 문맥 기준선·지속 조건
처리 지연      → 경량화·백로그 감시   → 신뢰할 수 있는 적시 경보
기준 변화      → 피드백·재평가
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **탐지 성능과 경보 품질**을 함께 측정해 알림 피로를 줄인다.
- 정밀도·재현율뿐 아니라 탐지 지연, 경보 건수, 조치까지 걸린 시간을 관찰한다.
- 중복·상관 경보를 묶고 심각도와 서비스 영향을 기준으로 우선순위를 매긴다.
- 자동 조치는 영향 범위를 제한하고 승인·취소·사후 감사 기능을 둔다.

## Ⅶ. 결론

- 핵심 요약 : 실시간 이상탐지는 **시간 문맥·탐지 지연·오경보 관리**를 함께 설계해야 운영 가치가 있다.
- 답안에는 이상 유형, 스트리밍 흐름, 기법별 장단점과 운영자 피드백 기반 개선을 연결한다.
