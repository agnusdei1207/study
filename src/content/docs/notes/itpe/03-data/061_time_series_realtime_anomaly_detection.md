## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 → **시계열 실시간 이상치 탐지**

## 30초 인출

- 본질: 시계열 실시간 이상치 탐지는 스트림으로 들어오는 시계열에서 정상 패턴을 벗어난 관측·구간을 지연 없이 찾아내는 체계
- 메커니즘: 수집한 지표를 윈도우로 집계해 정상 기준 모형(이동평균·ARIMA·딥러닝)의 예측값과 비교하고, 잔차가 동적 임계값을 넘으면 이상으로 판정해 등급화·알림
- 통찰: 고정 임계값은 시간대·계절 변동을 못 담아 오경보가 늘고 딥러닝은 지연이 크므로, 경량 통계 기법을 1차 필터로 두고 복잡한 판정만 딥러닝에 맡기는 계층 구조를 사용

<details>
<summary>핵심 용어</summary>

- **점 이상치(Point Anomaly)** : 단일 관측값이 정상 범위를 벗어난 경우
- **콘텍스트 이상치(Contextual Anomaly)** : 값 자체는 정상이나 시점 맥락에서 벗어난 경우
- **집단 이상치(Collective Anomaly)** : 연속 구간의 패턴이 정상과 다른 경우
- **잔차(Residual)** : 실제값과 예측값의 차이
- **동적 임계값** : 시간대·요일 등에 따라 조정하는 판정 기준
- **오토인코더** : 입력을 압축·복원하며 재구성 오차로 이상을 판별하는 신경망
- **LSTM** : 시계열의 장기 의존성을 다루는 순환 신경망

</details>

## 2~4교시 25점 답안

## Ⅰ. 시계열 실시간 이상치 탐지의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **시계열 실시간 이상치 탐지** 는 스트림 시계열에서 정상 패턴을 벗어난 관측·구간을 지연 없이 판별하는 체계 |
| 목적 | 장애·부정·설비 이상을 즉시 차단해 서비스 연속성 확보 |

## Ⅱ. 이상치 유형

| 유형 | 정상과의 차이 |
|---|---|
| 점 이상치 | 단일 관측값이 정상 범위 이탈(스파이크) |
| 콘텍스트 이상치 | 값은 정상이나 시점 맥락(심야·비수기)에서 이탈 |
| 집단 이상치 | 연속 구간의 패턴 이탈(반복 실패·비정상 주기) |
| 수준·변동 이상 | 레벨 시프트·분산 확대 등 구조 변화 |

## Ⅲ. 탐지 체계와 판정

```text
수집(로그·지표·센서) → 스트림 처리(윈도우 집계) → 정상 기준 모형 예측
        ↓
잔차 = |실제값 − 예측값|
 ├ 잔차 ≤ 동적 임계값 → 정상
 ├ 임계값 초과, 단발 → 점 이상
 └ 임계값 초과, 지속 → 집단 이상 검토
        ↓
알림 등급화·원인 연계·기록
```

## Ⅳ. 탐지 방식과 딥러닝 기법 비교

| 계열 | 대표 기법 | 실시간 적합성 |
|---|---|---|
| 통계 기반 | Z-score·IQR, 이동평균·지수평활 잔차 | 경량, 즉시 판정 |
| 모형 예측 기반 | ARIMA·지수평활 예측 오차 | 계절·추세 기준선 |
| 분해 기반 | 추세·계절·잔차 분해 후 잔차 감시 | 계절성 반영 |
| 밀도·거리 기반 | k-NN 거리·국소 이상 인수 | 유입마다 계산 비용 |
| 딥러닝 기반 | LSTM 예측 오차, 오토인코더 재구성 오차, VAE·GAN | 학습 비용 크나 복잡한 다변량 패턴 판별 |

| 비교축 | 통계 기반 | 모형 예측 기반 | 딥러닝 기반 |
|---|---|---|---|
| 판정 근거 | 분포·구간과의 거리 | 예측 잔차 | 예측·재구성 오차 |
| 비선형 반영 | 제한적 | 선형 추세·계절 | 다변량·비선형 |
| 운영 부담 | 경량 | 중간 | 학습·추론 자원 |
| 적합 | 1차 필터 | 기준선 | 정밀 판정 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 고정 임계값이 시간대·계절 변동을 반영하지 못해 오경보·누락 | 시간대·요일별 기준선과 동적 임계값 |
| 딥러닝의 학습 데이터 의존과 추론 지연 | 경량 통계 1차 필터와 딥러닝 판정의 계층화 |
| 경보 폭증으로 대응 지연 | 알림 집계·등급화·원인 지표 연계 |
| 정상 라벨 부족 | 비지도·준지도 판정과 운영자 피드백 재학습 |

## Ⅵ. 제언

경량 통계로 1차 걸러내고 애매한 구간만 딥러닝으로 정밀 판정하며 운영자 피드백으로 기준선을 갱신

```text
스트림 → 통계 1차 필터(즉시) ─ 정상 → 종료
                            └ 의심 → 딥러닝 정밀 판정 → 등급별 알림 → 피드백으로 기준선 갱신
```

| 구분 | 고정 임계값 단일 방식 | 제언: 계층형 탐지 |
|---|---|---|
| 오경보 | 많음 | 감소 |
| 지연·비용 | 방식에 종속 | 단계별 배분 |
