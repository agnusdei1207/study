## 지식 로드맵 내 현재 위치

자료처리·데이터 → 성능·용량 → **대기행렬이론**

## 30초 인출

- 본질: 대기행렬이론은 요청의 도착·대기·서비스를 확률 모형으로 분석해 지연과 부하를 추정하는 이론
- 메커니즘: 도착 간격·서비스시간 분포·서버 수·수용량·규율을 켄달 표기(A/S/c/K/N/Z)로 정하고, 안정 조건(ρ = λ/μ < 1)에서 평균 재고 관계 L = λ_eff·W(리틀의 법칙)로 큐 길이와 대기 시간을 구함
- 통찰: 이용률이 처리 능력에 가까울수록 지연이 급증하고 평균 공식은 피크·버스트를 설명하지 못하므로, 안정 조건을 먼저 확인하고 실제 도착·서비스 분포로 부하 시험해 용량을 정함

<details>
<summary>핵심 용어</summary>

- **대기행렬이론(Queuing Theory)** : 도착·대기·서비스를 확률 모형으로 분석하는 이론
- **켄달 표기** : A/S/c/K/N/Z — 도착 분포/서비스 분포/서버 수/수용량/모집단/규율
- **M/M/1** : 지수 도착·지수 서비스, 단일 서버 모형
- **이용률 ρ = λ/μ** : 도착률 대비 서비스율
- **리틀의 법칙** : 평균 시스템 내 요청 수 L = λ_eff × 평균 체류시간 W
- **유효 도착률 λ_eff** : 실제 수용·완료된 요청의 도착률(거절 제외)

</details>

## 2~4교시 25점 답안

## Ⅰ. 대기행렬이론의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **대기행렬이론** 은 요청의 도착·대기·서비스를 확률 모형으로 분석하는 이론 |
| 목적 | 서비스 지연과 시스템 부하를 추정해 운영·용량 결정 지원 |

## Ⅱ. 특징

| 특징 | 용량 분석 의미 |
|---|---|
| 확률적 유입·처리 | 같은 평균 도착률도 변동성에 따라 대기가 달라짐 |
| 이용률과 지연의 비선형 관계 | 유입률이 처리 능력에 가까울수록 대기가 급증 |
| 평균과 피크의 구분 | 평균 관계식은 버스트·긴 꼬리 지연을 단독으로 설명하지 못함 |

## Ⅲ. 구성과 리틀의 법칙

```text
요청 도착(간격 A, 유효 도착률 λ)
   ↓
대기열(규율 Z, 최대 수용량 K) → 서버 c개(서비스시간 S) → 완료·이탈
   ↓ 큐 길이·대기시간, 처리율·이용률 관측 → 지연 목표와 비교해 용량·규율 조정
```

```text
유효 도착률 λ_eff × 평균 체류시간 W = 평균 시스템 내 요청 수 L
```

유한 버퍼에서 거절된 요청은 유효 도착률에 포함하지 않음.

## Ⅳ. 켄달 표기와 대표 모형

| 표기·모형 | 의미·전제 | 해석 대상 |
|---|---|---|
| A/S/c/K/N/Z | 도착·서비스 분포, 서버 수, 수용량, 모집단, 규율 | 실제 시스템을 어떤 가정으로 단순화했는가 |
| M/M/1 | 지수 도착·서비스, 단일 서버, ρ = λ/μ < 1 | 정상상태 L = ρ/(1−ρ), W = L/λ |
| M/G/1 | 지수 도착, 일반 서비스시간, 단일 서버 | 서비스시간 변동성이 대기에 미치는 영향 |

리틀의 법칙은 M/M/1 전용이 아니라 안정·평균 조건에서 성립하는 장기 평균 관계이며, M은 지수 분포(Markovian)를 의미.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 평균 트래픽만으로 피크·버스트 지연을 놓침 | 실제 도착·서비스 분포로 부하 시험, 지연·큐 길이 목표와 대조 |
| 불안정한 유입을 정상상태 공식에 대입 | 유입률·처리율·거절률 추세로 안정 조건을 먼저 확인 |
| 거절된 요청을 처리율에 포함 | 유효 도착률과 거절률을 분리해 평가 |

## Ⅵ. 제언

안정 조건을 먼저 검증하고 피크 조건의 부하 시험으로 지연 목표를 만족하는 용량을 정함

```text
유입·서비스 분포 측정 → 모형 선택(켄달 표기) → 안정 조건 확인 → 부하 시험으로 용량 결정
```

| 구분 | 평균 트래픽 기준 용량 산정 | 제언: 분포·피크 기반 |
|---|---|---|
| 피크 지연 | 누락 | 시험으로 확인 |
| 안정성 | 미확인 | ρ < 1 확인 |
