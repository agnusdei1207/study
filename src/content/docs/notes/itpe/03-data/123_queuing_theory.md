## 연관 키워드

**대기행렬이론(Queuing Theory)**, **켄달 표기법**, **M/M/1**, **리틀의 법칙(Little's Law)**, **이용률(ρ)**, **백프레셔(Backpressure)**

## Ⅰ. 개요

- 핵심 요약 : **대기행렬이론**은 대기·서비스 현상을 확률 모델로 분석해 대기 시간·열 길이·가동률을 예측하는 성능 공학 기법.
- 목적 : 시스템 병목·용량 산정·SLA 예측.
- 배경 : 웹 서버·메시지 큐·네트워크 라우터 용량 설계 필요.
- 특징 : 켄달 표기법, M/M/1 모형, 리틀의 법칙.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **켄달 표기·M/M/1·리틀의 법칙**으로 대기 성능 정량화.
- **켄달 표기** : A/S/c/K/N/D로 시스템 구조 표현.
- **M/M/1** : 포아송 도착·지수 서비스·단일 서버 기본 모형.
- **리틀의 법칙** : $L = \lambda W$ (분포 무관 성립).
- **이용률(ρ)** : $\rho = \lambda/\mu$, 1 미만 안정.
- **비선형 지연** : ρ→1 시 대기 시간 발산.

## Ⅲ. 성능 척도 흐름

- 핵심 요약 : **ρ → W → Wq → L** 척도 산출과 ρ-W 관계.
- M/M/1 산식 : $W = 1/(\mu-\lambda)$, $W_q = \lambda/(\mu(\mu-\lambda))$, $L = \lambda/(\mu-\lambda)$.

```text
[ M/M/1 4대 성능 척도 ]

rho = lambda / mu  (이용률, <1 안정)
W   = 1 / (mu - lambda)  (체류 시간)
Wq  = lambda / (mu (mu-lambda))  (대기 시간)
L   = lambda / (mu - lambda)  (시스템 고객 수)
```

```text
[ rho와 체류 시간 W 관계 ]

체류 시간 W
  ^                              |
  |                            **|
  |                        ****  |
  |                  ******      |
  |        **********            |
  +------------------------------+----> 이용률 rho
  0.0   0.5   0.7  0.8  0.9  1.0
  (rho->1 시 W 무한 발산)
```

## Ⅳ. 켄달 표기·M/M/1 비교

- 핵심 요약 : **표기 체계와 M/M/1 기본 모형**.

| 항목 | 켄달 표기 | M/M/1 |
|---|---|---|
| 도착 | A (M: 포아송) | M (지수 간격) |
| 서비스 | S (M: 지수분포) | M (지수 서비스) |
| 서버 | c (채널 수) | 1 (단일) |
| 한계 | K (수용 용량) | 무한 |
| 모집단 | N (크기) | 무한 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **포아송 가정·ρ→1 발산·MSA 큐 네트워크**를 일반화·캡핑·AIOps로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 포아송 가정 | 실제 트래픽은 버스트·헤비테일 | G/G/1, M/G/1 (P-K 공식), DES 시뮬레이션 | 예측 vs 실제 |
| ρ→1 발산 | 이용률 과도 시 대기 시간 무한 | 이용률 캡핑, Predictive Autoscaling | 이용률, W |
| MSA 큐 네트워크 | 다단계 종속 서비스 모델링 불가 | Jackson Network, APM 분산 추적, AIOps | 큐 깊이, 레이턴시 |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **이용률 여유·백프레셔·서킷 브레이커**로 안정적 운영.
- 오토스케일링 임계치를 여유 있는 이용률에서 트리거.
- 백프레셔(Backpressure) + 서킷 브레이커로 큐 폭주 방지.
- 리틀의 법칙 기반 용량 산정.

## Ⅶ. 결론

- 핵심 요약 : 대기행렬이론은 **대기·서비스 성능 정량화** 기법으로 리틀의 법칙·ρ 관리가 핵심.
- 답안에는 켄달 표기, M/M/1 산식, ρ-W 관계, 한계·대응을 연결.
- 참고 : [NIST Queueing](https://www.nist.gov/).
