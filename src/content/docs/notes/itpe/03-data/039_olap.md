## 연관 키워드
- OLAP, 다차원 모델, 큐브, 차원, 측정 값, 드릴다운, 롤업

### Ⅰ. OLAP의 개요

- 핵심 요약 : OLAP(Online Analytical Processing)은 다차원 관점에서 대량의 집계 데이터를 대화형으로 분석하는 처리 방식.
- 개념 : 다차원 관점에서 대량의 집계 데이터를 대화형으로 분석하는 처리 방식(**OLAP**, Online Analytical Processing).
- 배경 및 필요성 : 운영 계 정규화 데이터로 복합 집계·기간 비교를 반복하면 응답성이 낮음.
- 주요 목적 : 의사 결정자가 다차원 데이터에서 추세·원인·예외를 신속히 탐색.

### Ⅱ. OLAP의 특징 및 장점

- 핵심 요약 : 차원·측정 값·드릴다운·롤업·슬라이스·다이스·피벗은 다차원 관점에서 데이터를 분석하는 OLAP 기능.

1. 차원·측정 값 : 시간·지역·제품별 수치 분석 → 업무 관점 결합.
2. 드릴다운·롤업 : 상세와 집계 수준 이동 → 원인 탐색.
3. 슬라이스·다이스·피벗 : 분석 축 변경 → 유연한 질의.

### Ⅲ. OLAP의 구조 (흐름)

- 핵심 요약 : 원천 ETL/ELT → 사실·차원 모델 구성 → 집계·인덱스·큐브 적재 → 질의·드릴다운 분석.

```text
원천 ETL/ELT
  ↓
사실·차원 모델 구성
  ↓
집계·인덱스·큐브 적재
  ↓
질의·드릴다운 분석
```

```text
원천 업무 DB → ETL/ELT → 사실·차원 데이터 마트 → OLAP 질의
```

### Ⅳ. OLAP과 OLTP 비교

- 핵심 요약 : 모델·부하 기준 — OLAP: 차원 중심·대량 읽기; OLTP: 정규화 중심·동시 쓰기.

| 비교 축 | OLAP | OLTP |
|---|---|---|
| 처리 목적 | 복잡한 읽기·집계·분석 | 짧은 삽입·수정·삭제 트랜잭션 |
| 모델·부하 | 차원 중심·대량 읽기 | 정규화 중심·동시 쓰기 |

### Ⅴ. OLAP의 한계와 방안

- 핵심 요약 : 적재 지연·차원 모델 오류 등 주요 위험을 원인에 맞는 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 적재 지연 | 배치 주기로 최신 분석 지연 | 주기·증분 적재·실시간 요구를 SLA로 정함 | 데이터 신선도 |
| 차원 모델 오류 | 그레인·차원 변경이 잘못되면 집계 오해 | 사실의 단위·느린 변화 차원·계산식 검증 | 대사 차이 |
| 고비용 탐색 | 비 선택적 다차원 질의가 자원 고갈 | 쿼리 제한·집계 설계·사용자 가이드 | 쿼리 p95·비용 |

### Ⅵ. OLAP에 대한 제언

- 핵심 요약 : BI 책임자는 분석 요구를 측정 값·차원·그레인으로 정의하고 지표 사전과 운영 계 데이터 갱신 주기를 함께 합의.

- 실행 제안 : BI 책임자는 사실 테이블의 그레인과 차원 정의를 지표 사전에 고정하고 적재 시각·대사 결과를 큐브에 노출.

### Ⅶ. 결론

- 핵심 요약 : OLAP의 성과는 큐브 자체가 아니라 일관된 지표 정의와 다차원 탐색으로 더 나은 의사 결정을 만드는 데 있음.
- 시사점 : 차원·그레인·지표 정의가 일관되어야 부서별 분석 결과를 비교 가능한 의사 결정으로 전환.
