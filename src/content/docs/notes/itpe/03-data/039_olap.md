## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 웨어하우스 → **OLAP**

## 30초 인출

- 본질: OLAP은 축적된 데이터를 시간·지역·상품 같은 여러 차원으로 탐색하고 집계해 분석하는 처리 방식
- 메커니즘: 측정값(사실)을 차원 키로 연결한 구조에서 Roll-up·Drill-down·Slice·Dice·Pivot으로 집계 수준과 관점을 바꾸며, 구현은 ROLAP·MOLAP·HOLAP으로 나뉨
- 통찰: 사전 집계는 응답을 빠르게 하는 대신 저장·갱신 비용을 늘리므로 실제 질의 빈도와 갱신 주기로 필요한 집계만 선별하고 구현 방식을 정함

<details>
<summary>핵심 용어</summary>

- **OLAP(Online Analytical Processing)** : 다차원 분석 처리
- **사실(Fact)·차원(Dimension)** : 분석할 측정값과 분석 관점(시간·지역·상품)
- **큐브(Cube)** : 차원 조합별 집계를 담은 다차원 구조
- **Roll-up / Drill-down** : 상위 수준으로 요약 / 하위 수준으로 상세화
- **Slice / Dice** : 한 차원을 고정 / 여러 차원 조건으로 부분집합 추출
- **Pivot** : 분석 축을 바꿔 행·열을 전환
- **ROLAP·MOLAP·HOLAP** : 관계형 / 다차원 / 혼합 저장 기반 구현 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. OLAP의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **OLAP** 은 축적된 데이터를 여러 차원으로 탐색·집계해 분석하는 처리 방식 |
| 목적 | 현황·추세·구성의 다각도 분석과 의사결정 지원 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 다차원 탐색 | 같은 측정값을 여러 축으로 재집계 |
| 계층 수준 이동 | 연·월·일 등 요약과 상세 사이 이동 |
| 집계 비용 교환 | 사전 집계로 지연을 줄이는 대신 저장·갱신 비용 증가 |

## Ⅲ. 다차원 구조와 탐색

```text
일·상품·지역 매출 ── Roll-up(일→월) ──→ 월·상품·지역 매출
        ↑                                   │
        └──────── Drill-down(월→일) ────────┘
Slice: 지역 하나를 고정 / Dice: 지역·상품 조건의 교차 부분집합 / Pivot: 행·열 전환
```

## Ⅳ. 연산과 구현 방식 비교

| 연산 | 변화 |
|---|---|
| Roll-up | 상세를 상위 계층으로 요약 |
| Drill-down | 요약을 하위 계층으로 펼침 |
| Slice | 한 차원 값을 고정 |
| Dice | 여러 차원 조건 적용 |
| Pivot | 분석 축 전환 |

| 구분 | ROLAP | MOLAP | HOLAP |
|---|---|---|---|
| 저장 기반 | 관계형 테이블 | 다차원 데이터 구조 | 상세는 관계형, 집계는 다차원 |
| 집계 | 질의 시 관계형 연산 | 미리 계산한 집계 활용 | 요약과 상세 분리 |
| 고려사항 | 조인 성능·저장 규모 | 사전 처리·저장·갱신 비용 | 두 구조 동기화·운영 복잡도 |

제품과 구성에 따라 성능이 달라지므로 한 방식이 항상 빠르다고 일반화하지 않음.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 드문 질의까지 사전 집계하면 저장·갱신 비용 증가 | 질의 빈도·갱신 주기로 필요한 집계만 선별 |
| 집계 응답만 시험해 상세 조회·변경 비용 누락 | 상세 질의와 갱신 부하를 함께 시험 |

## Ⅵ. 제언

질의 유형과 갱신 주기에 맞춰 구현 방식을 정하고 사전 집계는 자주 쓰는 차원 조합에만 적용

```text
자주 쓰는 요약 → 사전 집계(MOLAP·요약 테이블) / 드문 상세 → 관계형 질의(ROLAP)
```

| 구분 | 전체 사전 집계 | 제언: 선별 집계 |
|---|---|---|
| 응답 | 빠름 | 자주 쓰는 질의는 빠름 |
| 저장·갱신 | 큼 | 제한 |
