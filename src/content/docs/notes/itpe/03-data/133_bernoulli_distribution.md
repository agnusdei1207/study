- 본질: **베르누이 분포는** 한 번의 시행에서 두 결과 중 하나가 나타나는 확률분포
- 메커니즘: 성공 확률 $p$, 실패 확률 $1-p$를 두 결과에 배정

## 2~4교시 25점 답안

## Ⅰ. 베르누이 분포의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **베르누이 분포** 는 한 번의 시행에서 0 또는 1의 값을 갖는 이산확률분포 |
| 목적 | 이진 사건의 발생 여부와 성공 확률을 모형화 |

## Ⅱ. 베르누이 분포의 특징

| 특징 | 확률적 의미 |
|---|---|
| 한 번의 이진 시행 | 결과 $X$는 성공 1 또는 실패 0 |
| 단일 모수 $p$ | 성공확률 $p$가 정해지면 실패확률은 $1-p$ |
| 기댓값과 분산 | 평균은 $p$, 변동성은 $p(1-p)$로 두 결과의 불확실성 반영 |

## Ⅲ. 성공·실패 분기와 확률질량·모멘트 도출 체계

```text
한 번의 시행 X
    ├─ 성공(1): 확률 p
    └─ 실패(0): 확률 1−p
          ↓
P(X=x)=pˣ(1−p)¹⁻ˣ, x∈{0,1}
```

### 확률질량에서 기댓값·분산 도출

```text
P(0)=1−p, P(1)=p
       ↓ 가중 평균
E[X]=0·(1−p)+1·p=p
       ↓ X²=X
Var(X)=E[X²]−E[X]²=p−p²=p(1−p)
```

## Ⅳ. 베르누이·이항분포와 이진 분류 손실의 관계

| 분포 | 확률변수 | 관계 |
|---|---|---|
| 베르누이 | 한 번의 시행에서 성공 여부 | $X\in\{0,1\}$ |
| 이항 | 독립인 $n$회 시행의 성공 횟수 | $X=\sum_{i=1}^{n}X_i$, $X_i\sim Bernoulli(p)$일 때 $Binomial(n,p)$ |

### 이진 분류의 교차 엔트로피

| 단계 | 수식·의미 |
|---|---|
| 관측모형 | $y_i\in\{0,1\}$, 모델 예측 확률 $\hat p_i=P(Y_i=1\mid x_i)$ |
| 우도 | $L=\prod_i \hat p_i^{y_i}(1-\hat p_i)^{1-y_i}$ |
| 음의 로그우도 | $-\log L=-\sum_i[y_i\log\hat p_i+(1-y_i)\log(1-\hat p_i)]$ |
| 평균 손실 | 위 식을 관측 수 $N$으로 나눈 BCE |

BCE 최소화는 독립 베르누이 관측의 음의 로그우도를 최소화하는 것과 같다. 예측 확률의 보정과 업무상 분류 임계값은 손실 최소화와 별도로 평가한다.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 둘보다 많은 결과를 억지로 0·1로 압축해 정보 손실 | 사건 정의를 먼저 확인하고 다범주 모형·연속값 모형과 비교 |
| 반복 시행에 독립·동일 $p$를 가정해 이항 결과를 잘못 해석 | 시행 간 의존성·확률 변화 여부를 자료와 설계에서 확인 |
| 이진 결과만 보고하면 예측확률의 보정과 오탐·미탐 비용을 놓침 | 확률 보정·혼동행렬 지표를 확인하고 업무 비용에 따라 임계값을 정함 |

## Ⅵ. 제언

이진 결과만으로 운영 결정을 내리면 잘못된 확신과 오탐·미탐 비용을 놓친다. 먼저 사건의 0·1 정의와 예측확률 보정을 확인하고, 분류 임계값은 업무별 오탐·미탐 비용으로 정한다.
