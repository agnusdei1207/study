## 답안 골격
```text
[베르누이 분포 (Bernoulli Distribution)] ◀━━ 머리: Ⅶ 내 의견 (이진 분류 모델의 크로스 엔트로피 손실 함수 도출 기반 활용)
 ┃
 ┣━ Ⅰ 개요 ───── 단 한 번의 시행에서 결과가 '성공($X=1$)' 또는 '실패($X=0$)'의 상호배타적인 두 가지만 발생하는 이산확률분포의 가장 기초적인 모델
 ┣━ Ⅱ 특징 ───── 단일 모수 $p$(성공 확률)로 결정 · 이항분포($n$회 확장), 기하분포(첫 성공까지), 음이항분포의 수학적 모태 · 기댓값 $E(X)=p$, 분산 $Var(X)=p(1-p)$
 ┣━ Ⅲ 구조 ───── 확률질량함수: $P(X=x) = p^x (1-p)^{1-x}$ (단, $x \in \{0, 1\}$) ┃ 모멘트: 평균 $p$, 분산 $pq$, 왜도 $\frac{1-2p}{\sqrt{pq}}$
 ┣━ Ⅳ 흐름 ───── ① 단일 이진 사건 정의(클릭/비클릭, 불량/양품) → ② 성공확률($p$) 추정 → ③ 베르누이 시행 $n$회 반복 확장 → ④ 이항분포 유도 및 정규분포 근사
 ┣━ Ⅴ 비교 ───── 베르누이 분포 vs 이항분포 vs 기하분포
 ┗━ Ⅵ 실무 ───── 성공 확률이 극도로 낮은 불균형 데이터($p \ll 0.01$, 사기 거래)에서 분산 감소에 따른 학습 왜곡
```

## 한 줄 본질
- 결과가 '성공' 또는 '실패' 둘 중 하나뿐인 단일 사건의 불확실성 수학화 필요 → 확률 $p$를 지수로 올린 수식($p^x (1-p)^{1-x}$)으로 단일화하여 표현 → 모든 이진 통계와 머신러닝 분류 모형의 수학적 기초 확립 / 단일 시행에 국한

    P(X) ▲                                      베르누이 분포 (단 1회 시행)

     0.5 │          ┌─────┐                             ├─ 첫 성공까지 ───► 기하분포 (Geometric)
         │  1-p=0.3 │     │                             │

## 핵심 용어
- 베르누이 시행(Bernoulli Trial): 결과가 오직 두 가지(성공/실패)로만 나타나며, 반복 시행 시 각 시행이 서로 독립적이고 성공 확률 $p$가 항상 일정한 실험
- 이진 교차 엔트로피(Binary Cross Entropy, BCE): 딥러닝 이진 분류에서 모델의 예측 확률과 실제 라벨(0 또는 1) 간의 오차를 베르누이 음의 로그 우도(Negative Log-Likelihood)로 수식화한 손실 함수

## 핵심 통찰
- 베르누이 분포의 분산 $Var(X) = p(1-p)$는 $p = 0.5$일 때 최댓값 $0.25$를 가짐 → 즉, 앞면과 뒷면이 나올 확률이 반반일 때 결과의 불확실성(엔트로피)이 가장 극대화됨
- 딥러닝과 로지스틱 회귀가 출력하는 시그모이드(Sigmoid) 값은 '베르누이 분포의 성공 확률 모수 $p$'를 추정한 것임 → 따라서 모델의 비용 함수로 평균제곱오차(MSE) 대신 베르누이 기반의 BCE를 써야 경사하강법이 볼록(Convex) 수렴함
- 베르누이 시행을 $n$번 독립적으로 반복하여 성공한 횟수를 세면 '이항분포(Binomial)'가 되고, 처음으로 성공할 때까지 실패한 횟수를 세면 '기하분포(Geometric)'가 됨

## 이웃 토픽과 구분
- 베르누이 분포 vs 이항분포: 베르누이 분포 = 시행 횟수가 단 1회($n=1$)인 특수한 경우 / 이항분포 = 베르누이 시행을 $n$회($n \ge 2$) 독립 반복하여 성공한 총 횟수($X$)를 나타내는 분포
