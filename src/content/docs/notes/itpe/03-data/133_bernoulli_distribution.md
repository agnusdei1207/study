## Ⅰ. 이산 확률 분포의 기초, 베르누이와 이항분포 개요

### 가. 베르누이 시행(Bernoulli Trial)과 베르누이 분포의 정의
- **베르누이 시행** : 결과가 오직 두 가지('성공' 또는 '실패')로만 상호 배타적으로 나타나는 단 1회의 확률적 실험.
- **베르누이 분포** : 성공 확률이 $p$($0 \le p \le 1$), 실패 확률이 $q = 1 - p$인 베르누이 시행 1회의 결과를 모델링하는 **이산 확률 분포** ($X \sim \text{Bernoulli}(p)$).

### 나. 이항분포(Binomial Distribution)의 정의
- 동일한 성공 확률 $p$를 가지는 독립적인 베르누이 시행을 $n$번 반복 수행했을 때 나타나는 **총 성공 횟수** $X$의 확률 분포 ($X \sim B(n, p)$).

---

## Ⅱ. 베르누이 분포와 이항분포의 수학적 확률질량함수(PMF) 및 모수

### 가. 확률질량함수 및 기댓값·분산 비교

```text
[ 베르누이 vs 이항분포 수학적 구조 ]
- 베르누이 분포 (n = 1):
  P(X = x) = p^x * (1 - p)^(1 - x)  (x in {0, 1})
  E(X) = p ,  Var(X) = p(1 - p)

- 이항분포 (n번 독립 시행):
  P(X = k) = C(n,k) * p^k * (1 - p)^(n - k)  (k = 0, 1, ..., n)
  E(X) = np ,  Var(X) = np(1 - p)
```

| 구분 | 베르누이 분포 ($Bernoulli(p)$) | 이항분포 ($B(n, p)$) |
| :--- | :--- | :--- |
| **시행 횟수** | 단 1회 ($n=1$) | $n$회 독립 반복 시행 |
| **확률변수 $X$의 의미** | 1회 시행의 성공 여부 (0 또는 1) | $n$회 시행 중 총 성공 횟수 ($0, 1, \dots, n$) |
| **조합(Combination) 항** | 불필요 | $C(n,k) = \frac{n!}{k!(n-k)!}$ ($n$번 중 성공 $k$번이 발생하는 순서 경우의 수) |
| **기댓값 $E(X)$** | $p$ | $np$ |
| **분산 $Var(X)$** | $p(1 - p)$ | $np(1 - p)$ |

## Ⅲ. 이항분포의 극한 성질: 포아송 근사와 정규 근사

### 가. 포아송 근사 (Poisson Approximation - 희귀 사건의 법칙)
- 시행 횟수 $n$이 극도로 크고($n \to \infty$), 성공 확률 $p$가 극히 작으며($p \to 0$), $\lambda = np$가 일정한 경우 $\rightarrow$ **포아송 분포** ($Poisson(\lambda)$)로 수렴:
  $$P(X = k) \approx \frac{\lambda^k e^{-\lambda}}{k!}$$
- (예: 웹사이트의 초당 결제 장애 발생 건수, 공장 부품의 극미한 불량률).

### 나. 정규 근사 (Normal Approximation - 드무아브르-라플라스 정리)
- $np \ge 5$이고 $n(1 - p) \ge 5$를 만족할 만큼 충분히 큰 표본인 경우, 이항분포는 연속적인 **정규분포** $N(np, np(1 - p))$로 근사함 $\rightarrow$ **연속성 수정** (Continuity Correction) 적용.

## Ⅳ. 베르누이 및 이항분포 모델링의 주요 한계점 및 해결 방안

- 독립성 및 성공 확률($p$) 불변 가정의 비현실성 :
  - 한계점 : 마케팅 전환율, 시스템 결함 발생 등 실제 환경에서는 이전 사건이 다음 사건에 영향을 미치거나(피로도 효과), 시간/맥락에 따라 $p$가 변동함에도 고정 모수로 가정하여 왜곡.
  - 해결 방안 : **과분산** (Overdispersion)을 수용하는 **베타-이항 분포** (Beta-Binomial Distribution) 적용, 시간에 따른 동적 확률을 반영하는 **상태 공간 모델** (State Space Model) 전환.
- 희귀 사건($p \to 0, n \to \infty$) 모델링 시 연산 불안정성 및 정규 근사 실패 :
  - 한계점 : 클릭 사기(Fraud)나 극희귀 장애 탐지에서 $np < 5$인 경우 정규 근사가 무너져 신뢰구간 추정이 왜곡되고 팩토리얼 연산 오버플로우 발생.
  - 해결 방안 : 포아송 근사(Poisson Approximation) 적용, 로그 팩토리얼($\ln \Gamma$) 수치 해석 기법을 통한 오버플로우 방지, **클로퍼-피어슨** (Clopper-Pearson) 정확 신뢰구간 사용.
- 클래스 불균형에 따른 머신러닝 교차 엔트로피 손실 왜곡 :
  - 한계점 : 베르누이 우도 기반의 **이진 교차 엔트로피** (BCE) 손실함수가 다수 음성 클래스에 압도되어 희귀 양성 클래스에 대한 학습 신호 소실.
  - 해결 방안 : **초점 손실** (Focal Loss: 쉬운 샘플의 가중치를 낮추는 메커니즘) 적용, 양성 클래스 양의 가중치(pos_weight) 부여.

## Ⅴ. 데이터 사이언스 및 품질 관리 실무 제언

- 대규모 A/B 테스트 전환율(CVR)의 z-비율 검정 근거 : 웹사이트에 방문한 사용자 $n$명 중 구매한 사용자 $k$명의 비율 $\hat{p} = k/n$의 분포는 중심극한정리에 의해 정규분포 $N\left(p, \frac{p(1-p)}{n}\right)$를 따르므로, 이항분포의 정규 근사를 활용하여 두 변형 간 전환율 차이를 $Z$-검정으로 초고속 판정할 것.
- 불균형 데이터셋에서의 베르누이 나이브 베이즈 분류 : 텍스트 문서 내 특정 단어의 출현 빈도(Frequency)가 아닌 '단어의 존재 유무(0 또는 1)'만을 피처로 사용할 때 **베르누이 나이브 베이즈** 모델을 적용하여 스팸 메일 여부를 경량·고속으로 분류할 것을 제언함.
