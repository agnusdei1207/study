## 연관 키워드

**베르누이 분포(Bernoulli)**, **이항분포(Binomial)**, **PMF**, **포아송 근사**, **정규 근사**, **Focal Loss**

## Ⅰ. 개요

- 핵심 요약 : **베르누이·이항분포**는 성공/실패 두 결과의 확률을 모델링하는 이산 확률 분포.
- 목적 : 이진 사건(성공/실패) 확률 모델링.
- 배경 : 단일 시행(베르누이) → n회 반복(이항)으로 확장.
- 특징 : PMF, 기댓값·분산, 포아송/정규 근사.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **단순 구조·명확한 모수·근사 확장**으로 이진 사건 모델링에 적합.
- **베르누이** : 1회 시행, 성공 확률 p.
- **이항** : n회 독립 시행, 총 성공 횟수.
- **PMF** : $C(n,k) p^k (1-p)^{n-k}$.
- **근사** : 포아송(희귀 사건), 정규(대표본).
- **ML 활용** : 이진 교차 엔트로피 손실.

## Ⅲ. 확률질량함수 및 근사 흐름

- 핵심 요약 : **PMF → 포아송/정규 근사**로 계산 효율화.
- 베르누이 : $P(X=x)=p^x(1-p)^{1-x}$, $E(X)=p$, $Var=p(1-p)$.
- 이항 : $P(X=k)=C(n,k)p^k(1-p)^{n-k}$, $E=np$, $Var=np(1-p)$.

```text
[ 근사 조건 ]

포아송 근사 : n→∞, p→0, np=λ 일정
정규 근사 : np≥5, n(1-p)≥5 (연속성 수정)
```

## Ⅳ. 베르누이 vs 이항 비교

- 핵심 요약 : **시행 횟수·확률변수·조합 항** 비교.

| 항목 | 베르누이 | 이항 |
|---|---|---|
| 시행 횟수 | 1회 (n=1) | n회 독립 |
| 확률변수 | 성공 여부 (0/1) | 총 성공 횟수 (0~n) |
| 조합 항 | 불필요 | C(n,k) |
| 기댓값 | p | np |
| 분산 | p(1-p) | np(1-p) |

## Ⅴ. 한계와 방안

- 핵심 요약 : **독립성·p 불변·희귀 사건·클래스 불균형**을 베타-이항·포아송·Focal Loss로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 독립성·p 불변 가정 | 실제 환경에서 p 변동·의존성 | 베타-이항 분포, 상태 공간 모델 | 적합도 |
| 희귀 사건 연산 불안정 | np<5 시 정규 근사 실패·오버플로우 | 포아송 근사, 로그 팩토리얼, Clopper-Pearson | 신뢰구간 |
| 클래스 불균형 | BCE 손실이 다수 클래스에 압도 | Focal Loss, pos_weight | F1, PR-AUC |

## Ⅵ. 기술사적 제언

- 핵심 요약 : **A/B 테스트 z-비율·베르누이 NB**로 실무 적용.
- A/B 테스트 : 정규 근사로 전환율 차이 Z-검정.
- 스팸 분류 : 베르누이 나이브 베이즈 (단어 존재 유무).

## Ⅶ. 결론

- 핵심 요약 : 베르누이·이항분포는 **이진 사건 확률 모델링**의 기본으로 근사·ML 활용이 핵심.
- 답안에는 PMF, 근사 조건, 한계·대응을 연결.
