## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **베르누이·이항분포**

## 30초 인출

- 본질: 베르누이 분포는 한 번의 시행에서 성공(1) 또는 실패(0)의 값을 갖는 이산확률분포이고, 이항분포는 독립인 n번 시행의 성공 횟수의 분포
- 메커니즘: 성공확률 p 하나로 P(X=x) = p^x (1−p)^(1−x)가 정해지고 E[X] = p, Var(X) = p(1−p)이며, 독립·동일 p의 베르누이 시행 n번을 합하면 Binomial(n, p)
- 통찰: 이진 분류의 교차 엔트로피는 독립 베르누이 관측의 음의 로그우도이므로, 시행의 독립·동일 p 가정을 확인하고 예측 확률의 보정과 임계값 비용은 손실 최소화와 별도로 평가

<details>
<summary>핵심 용어</summary>

- **베르누이 분포(Bernoulli)** : 한 번의 이진 시행의 결과를 나타내는 분포
- **성공확률 p** : X = 1이 될 확률
- **이항분포(Binomial)** : 독립인 n번 베르누이 시행의 성공 횟수 분포
- **기댓값·분산** : 베르누이에서 p와 p(1−p)
- **우도(Likelihood)** : 모수가 주어졌을 때 관측 자료가 나올 가능성
- **BCE(이진 교차 엔트로피)** : 이진 분류에서 쓰는 음의 로그우도 손실

## 2~4교시 25점 답안

## Ⅰ. 베르누이 분포의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **베르누이 분포** 는 한 번의 시행에서 0 또는 1의 값을 갖는 이산확률분포 |
| 목적 | 이진 사건의 발생 여부와 성공 확률 모형화 |

## Ⅱ. 특징

| 특징 | 확률적 의미 |
|---|---|
| 한 번의 이진 시행 | 결과 X는 성공 1 또는 실패 0 |
| 단일 모수 p | 성공확률이 정해지면 실패확률은 1 − p |
| 기댓값과 분산 | 평균 p, 분산 p(1 − p) |

## Ⅲ. 확률질량과 모멘트

```text
한 번의 시행 X ─ 성공(1): 확률 p / 실패(0): 확률 1 − p
P(X = x) = p^x · (1 − p)^(1 − x),  x ∈ {0, 1}
E[X] = 0·(1 − p) + 1·p = p
Var(X) = E[X²] − E[X]² = p − p² = p(1 − p)   (X² = X 이므로)
```

## Ⅳ. 이항분포와 이진 분류 손실

| 분포 | 확률변수 | 관계 |
|---|---|---|
| 베르누이 | 한 번의 시행에서 성공 여부 | X ∈ {0, 1} |
| 이항 | 독립인 n번 시행의 성공 횟수 | Xi가 독립·동일 Bernoulli(p)이면 ΣXi ~ Binomial(n, p) |

| 단계 | 식·의미 |
|---|---|
| 관측모형 | yi ∈ {0, 1}, 예측 확률 p̂i = P(Yi = 1 \| xi) |
| 우도 | L = Π p̂i^yi · (1 − p̂i)^(1 − yi) |
| 음의 로그우도 | −log L = −Σ [ yi·log p̂i + (1 − yi)·log(1 − p̂i) ] |
| 평균 손실 | 위 식을 관측 수 N으로 나눈 BCE |

BCE를 최소화하는 것은 독립 베르누이 관측의 음의 로그우도를 최소화하는 것과 같으며, 예측 확률의 보정과 분류 임계값은 손실 최소화와 별도로 평가.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 셋 이상의 결과를 0·1로 압축해 정보 손실 | 사건 정의를 확인하고 다범주·연속값 모형과 비교 |
| 반복 시행에 독립·동일 p를 가정해 이항 결과 오해 | 시행 간 의존성·확률 변화를 자료와 설계로 확인 |
| 이진 결과만 보고 확률 보정과 오탐·미탐 비용 누락 | 확률 보정·혼동행렬을 확인하고 비용으로 임계값 결정 |

## Ⅵ. 제언

이진 사건은 독립·동일 확률 가정을 확인해 모형화하고, 분류 모델은 확률 보정과 비용 기반 임계값까지 평가

```text
사건 정의 → 독립·동일 p 확인 → 베르누이/이항 모형 → BCE 학습 → 확률 보정·임계값 평가
```

| 구분 | 이진 결과만 평가 | 제언: 확률·비용 평가 |
|---|---|---|
| 확률 품질 | 미확인 | 보정 확인 |
| 임계값 | 기본값 | 비용 기반 |
