## 지식 로드맵 내 현재 위치

자료처리·데이터 → 통계·분석 → **중심극한정리·대수의 법칙**

## 30초 인출

- 본질: 중심극한정리는 모집단의 분포와 관계없이 표본 크기가 충분히 크면 표본평균의 분포가 정규분포에 가까워진다는 정리이고, 대수의 법칙은 표본이 커질수록 표본평균이 모평균에 가까워진다는 법칙
- 메커니즘: 독립·동일분포 표본의 평균은 평균이 μ, 표준오차가 σ/√n인 정규분포로 근사되고 n이 커질수록 평균의 흩어짐이 줄어듦
- 통찰: 중심극한정리는 표본평균의 분포에 대한 것이지 원자료가 정규분포가 된다는 뜻이 아니므로 평균에 대한 추론에는 쓸 수 있으나 개별 관측값의 분포 가정을 대체하지는 못함

<details>
<summary>핵심 용어</summary>

- **중심극한정리(CLT)** : 표본 크기가 크면 표본평균의 분포가 정규분포에 근사한다는 정리
- **대수의 법칙(Law of Large Numbers)** : 표본이 커질수록 표본평균이 모평균으로 수렴한다는 법칙
- **표본분포** : 같은 방식으로 표본을 반복 추출했을 때 통계량이 이루는 분포
- **표준오차** : 표본평균의 표본 간 변동 크기. σ/√n
- **정규근사** : 표본분포를 정규분포로 근사해 확률·구간을 계산하는 방법

</details>

## 2~4교시 25점 답안

## Ⅰ. 중심극한정리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **중심극한정리** 는 표본 크기가 충분히 크면 모집단 분포와 관계없이 표본평균의 분포가 정규분포에 근사한다는 정리 |
| 목적 | 모집단 분포를 몰라도 평균에 대한 확률 계산과 추론 가능 |

## Ⅱ. 대수의 법칙과 구별되는 특징

| 구분 | 대수의 법칙 | 중심극한정리 |
|---|---|---|
| 내용 | n이 커지면 표본평균이 모평균에 수렴 | n이 커지면 표본평균의 분포가 정규분포에 근사 |
| 초점 | 평균값이 어디로 가는가 | 평균이 어떤 분포로 흩어지는가 |
| 활용 | 추정의 일관성 | 신뢰구간·가설검정 |

## Ⅲ. 표본평균 분포의 변화

```text
모집단(치우친 분포)    n=5 표본평균       n=30 표본평균
   █                     ▂█▆▃               ▁▃▆█▆▃▁
   █▃                    (약간 치우침)       (종 모양에 근접)
   █▅▂▁
표본이 커질수록: 평균은 μ 주변, 표준오차 σ/√n 으로 좁아짐
```

## Ⅳ. 조건과 활용

| 구분 | 내용 |
|---|---|
| 조건 | 독립·동일분포, 유한한 분산 |
| 표본 크기 | 분포가 심하게 치우치면 더 큰 n 필요 (관행적으로 30 이상) |
| 활용 | z-검정, 신뢰구간, 품질 관리도 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 표본이 작거나 분포가 심하게 치우쳐 근사가 부정확 | 표본 크기 확대 또는 비모수·부트스트랩 방법 |
| 원자료가 정규분포가 된다는 오해 | 표본평균에 대한 정리임을 구분 |
| 독립성이 깨진 자료(시계열 등) | 상관을 고려한 방법 사용 |

## Ⅵ. 제언

평균에 대한 추론에는 표본 크기와 분포의 치우침을 확인해 정규근사를 쓰고, 조건이 맞지 않으면 부트스트랩 등으로 대체

```text
표본 크기 충분? 분포 치우침 심하지 않음? ─ 예 → 정규근사(z) / 아니오 → t·부트스트랩
```

| 구분 | 무조건 정규근사 | 제언: 조건 확인 |
|---|---|---|
| 작은 표본 | 오차 큼 | 대체 방법 |
| 결론 신뢰 | 낮음 | 조건 확인 |
