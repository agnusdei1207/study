## 연관 키워드
- 중심극한정리, 표본평균, 정규근사, 표본크기, 독립성, 분산

### Ⅰ. 중심극한정리의 개요

- 핵심 요약 : 중심극한정리는 적절한 조건에서 독립·동일분포 표본의 합 또는 평균을 표준화하면 표본크기가 커질수록 정규분포에 가까워진다는 정리.
-概念 : 적절한 조건에서 독립·동일분포 표본의 합 또는 평균을 표준화하면 표본크기가 커질수록 정규분포에 가까워진다는 정리(**중심극한정리**, Central Limit Theorem).
- 배경 및 필요성 : 모집단 분포가 정규가 아니어도 표본평균의 분포를 근사해 추론할 근거 필요.
- 주요 목적 : 표본평균·합에 대한 정규근사와 신뢰구간·검정의 이론적 기반 제공.

### Ⅱ. 중심극한정리의 특징 및 장점

- 핵심 요약 : 표본평균의 분포·수렴·원자료 정규성 아님은 표본평균 분포의 정규 근사를 설명하는 데이터 통계 개념.

1. 표본평균의 분포 : 평균 μ, 분산 σ²/n → 표준오차는 σ/√n.
2. 수렴 : 적절한 유한 분산 등 조건에서 표준화 평균이 N(0,1)에 수렴.
3. 원자료 정규성 아님 : 표본평균의 분포가 근사 정규 → 개별 관측값이 정규라는 뜻 아님.

### Ⅲ. 중심극한정리의 구조 (흐름)

- 핵심 요약 : 모집단·표본 가정 확인 → 표본평균과 표준오차 산출 → 표준화 → 정규근사 적용 → 조건·근사오차 해석.

```text
모집단·표본 가정 확인
  ↓
표본평균과 표준오차 산출
  ↓
표준화
  ↓
정규근사 적용
  ↓
조건·근사오차 해석
```

```text
X₁,…,Xₙ iid, E[X]=μ, Var[X]=σ²
             ↓
Zₙ = (X̄−μ)/(σ/√n)
             ↓ n 증가 시 분포 → N(0,1)
```

### Ⅳ. 중심극한정리와 대수의 큰 수 법칙 비교

- 핵심 요약 : 활용 기준 — 중심극한정리: 정규근사·추론 근거; 대수의 큰 수 법칙: 일관된 추정의 수렴 근거.

| 비교 축 | 중심극한정리 | 대수의 큰 수 법칙 |
|---|---|---|
| 결론 | 표준화한 표본평균 분포의 정규 수렴 | 표본평균이 모평균으로 확률 수렴 |
| 활용 | 정규근사·추론 근거 | 일관된 추정의 수렴 근거 |

### Ⅴ. 중심극한정리의 한계와 방안

- 핵심 요약 : 조건 미충족·작은 표본·왜도 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 조건 미충족 | 강한 의존·무한 분산이면 표준 정리 적용 불가 | 표본 독립성·분산·표집 설계 확인 | 조건 위반 |
| 작은 표본·왜도 | 근사가 충분히 정확하지 않을 수 있음 | 분포·시뮬레이션·부트스트랩 등 민감도 검토 | 근사오차 |
| 독립성 오해 | 시계열·군집표본의 유효 표본크기 과대평가 | 의존구조 반영한 표준오차·표본설계 사용 | 유효 표본크기 |

### Ⅵ. 중심극한정리에 대한 제언

- 핵심 요약 : 분석자는 단순히 표본 수가 크다는 이유만으로 정규근사를 적용하지 말고 독립성·분산·표본설계와 분포 꼬리를 확인.

- 실행 제안 : 통계 담당자는 표본 독립성·분산·표집 설계를 검토하고 작은 표본에서는 모의실험으로 근사 정확도 확인.

### Ⅶ. 결론

- 핵심 요약 : 중심극한정리는 적절한 조건 아래 표본평균의 분포에 관한 정리이며 원자료의 분포가 정규임을 뜻하지 않음.
- 시사점 : 표본평균의 정규근사와 원자료의 분포 가정을 구분해야 통계 추론의 전제를 오해하지 않음.
