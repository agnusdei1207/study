## 연관 키워드

**마스터 데이터 관리(MDM)**, **골든 레코드**, **데이터 거버넌스**, **중복 제거**, **매칭·머징**, **생존 규칙**, **MDM 아키텍처**

## Ⅰ. 개요

- 핵심 요약 : **마스터 데이터 관리(MDM)**는 고객·상품·공급자 등 핵심 엔티티의 기준 데이터를 전사적으로 관리하는 정책·조직·기술 체계다.
- 배경 : 부서별 코드와 속성이 달라 동일 엔티티의 중복·불일치가 생기면 업무 연계와 분석 신뢰성이 낮아진다.
- 목적 : 신뢰 가능한 기준 정보를 정의하고 생성부터 변경·배포까지의 책임과 품질을 관리한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **식별·표준화·중복 통합·생명주기 관리**로 시스템 간 기준 정보의 일관성을 높인다.
- **전사 표준** : 공통 정의·코드·품질 규칙을 마련한다.
- **골든 레코드** : 여러 원천의 정보를 매칭·정제해 통합된 기준 뷰를 만든다.
- **계보와 책임** : 원천 시스템, 변경 이력, 데이터 스튜어드 책임을 추적한다.
- MDM은 단순히 중앙 DB 한 곳에 데이터를 복사하는 작업이 아니라 거버넌스와 운영 프로세스를 포함한다.

## Ⅲ. 매칭·머징과 배포 흐름

- 핵심 요약 : **원천 수집 → 표준화 → 매칭 → 생존 규칙 적용 → 골든 레코드 배포**가 기본 흐름이다.

```text
[원천 시스템 데이터 수집]
          ▼
[형식·코드 표준화]
          ▼
[후보군 구성·중복 매칭]
     ├─ 낮은 신뢰도 → 별도 검토
     └─ 검토된 일치 → 병합 후보
                      ▼
[생존 규칙·승인 적용]
          ▼
[골든 레코드·원천 ID 연결]
          ▼
[시스템 배포·변경 감시]
```

- 자동 병합은 매칭 신뢰도, 업무 위험, 감사 요건에 따라 제한하고 불확실한 사례는 스튜어드 검토로 보낸다.
- 생존 규칙은 필드별 권위 원천, 최신성, 승인 상태 등 업무 기준으로 정의한다.

## Ⅳ. MDM 아키텍처 비교

- 핵심 요약 : **원천 시스템 통제 수준과 중앙 데이터 반영 방식**에 따라 토폴로지를 고른다.

| 유형 | 중앙 저장 내용·흐름 | 장점 | 고려사항 |
|---|---|---|---|
| Registry | 식별자 연결·참조 정보 중심 | 원천 변경을 줄임 | 원천 조회와 데이터 품질 의존 |
| Consolidation | 원천 데이터를 모아 통합 뷰 구성 | 분석용 단일 뷰에 적합 | 원천으로 기준값을 되돌려 보내지 않을 수 있음 |
| Coexistence | 중앙·원천 간 생성·변경 동기화 | 운영·분석 모두 지원 가능 | 충돌 해결·동기화 복잡성 |
| Centralized / Transaction | 중앙에서 기준 데이터 변경을 통제 | 통일된 변경·승인 통제 | 조직·응용 연계 변화 비용 |

## Ⅴ. 한계와 방안

- 핵심 요약 : **원천 간 식별 불일치·소유권 갈등·동기화 실패**를 데이터와 조직 양쪽에서 관리한다.
- **오매칭·미매칭** → 결정론적·확률적 규칙을 결합하고 임계치별 표본 검수로 오류를 측정한다.
- **필드 값 충돌** → 생존 규칙과 권위 원천을 정의하고 예외를 담당자에게 배정한다.
- **현업 소유권 갈등** → 데이터 오너·스튜어드와 변경 승인 절차를 명확히 한다.
- **동기화 지연·장애** → 재처리·멱등성·대사·롤백을 포함한 배포 방식을 설계한다.

```text
중복·오매칭 → 규칙·표본 검수
값 충돌     → 권위 원천·승인        → 신뢰할 수 있는 기준 데이터
동기화 실패 → 재처리·대사
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **거버넌스와 데이터 품질 책임을 먼저 정하고, 핵심 도메인부터 단계적으로 확장**한다.
- 고객·상품 등 우선 도메인을 정해 품질 기준, 식별자, 변경 책임, 배포 대상을 합의한다.
- 중복률·매칭 정확도·변경 반영 시간·정정 요청을 성과 지표로 둔다.
- 골든 레코드와 원천 시스템의 역할을 분명히 하며 MDM 도입이 모든 트랜잭션을 중앙화해야 한다고 가정하지 않는다.

## Ⅶ. 결론

- 핵심 요약 : MDM은 **전사 기준 데이터의 품질·책임·변경을 관리하는 거버넌스 체계**이며 기술과 조직의 공동 설계가 필요하다.
- 답안에는 아키텍처 유형, 매칭·머징과 생존 규칙, 오매칭·동기화·소유권 대응을 연결한다.
