## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 → **차원 축소(PCA·MDS)**

## 30초 인출

- 본질: 차원 축소는 자료를 더 적은 변수나 좌표로 나타내면서 분석에 필요한 정보를 보존하는 방법
- 메커니즘: PCA는 분산이 큰 직교 방향(주성분)으로 자료를 선형 투영하고, MDS는 개체 간 거리·비유사도를 보존하도록 저차원 좌표에 배치
- 통찰: 축소하면 정보가 일부 사라지고 척도·거리 정의에 결과가 좌우되므로 설명분산·스트레스와 후속 업무 성능으로 검증하고, 2차원 그림이 모든 관계를 보존한다고 해석하지 않음

<details>
<summary>핵심 용어</summary>

- **차원 축소(Dimensionality Reduction)** : 변수·좌표 수를 줄이는 방법
- **PCA(Principal Component Analysis)** : 분산이 큰 직교 방향으로 자료를 선형 투영하는 방법
- **주성분** : 원 변수의 선형결합으로 이루어진 직교 축
- **설명분산 비율** : 각 축이 원자료 변동을 설명하는 비율
- **MDS(Multidimensional Scaling)** : 개체 간 거리를 저차원에서 보존하는 배치 방법
- **스트레스(Stress)** : 입력 거리와 저차원 거리의 차이를 나타내는 지표
- **계량·비계량 MDS** : 거리의 크기를 보존 / 거리의 순위를 보존

</details>

## 2~4교시 25점 답안

## Ⅰ. 차원 축소의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **차원 축소** 는 자료를 더 적은 변수·좌표로 표현하면서 필요한 정보를 보존하는 방법 |
| 목적 | 계산·해석 부담 완화와 저차원 탐색 |

## Ⅱ. 특징

| 특징 | 해석 영향 |
|---|---|
| 보존 목표 선택 | PCA는 분산, MDS는 개체 간 거리·순서 |
| 저차원 표현 | 계산·시각화 부담은 줄지만 일부 정보 손실 |
| 척도·전처리 민감 | 표준화와 거리 정의가 결과에 영향 |

## Ⅲ. PCA·MDS의 절차

```text
PCA: 변수 행렬 → 표준화 검토 → 최대 분산 방향 PC1 → PC1에 직교한 다음 방향 PC2 … → 선택한 축으로 투영
MDS: 개체 간 비유사도 → 거리를 맞추는 저차원 좌표 탐색 → 스트레스로 적합도 확인
                                    ↓
              설명분산·거리 왜곡 + 후속 업무 지표로 검증
```

- PCA: 측정 단위 차이가 결과를 지배하면 표준화를 검토, 설명분산은 보존 정보의 정도이지 업무 중요도와 같지 않음
- MDS: 좌표축의 방향·원점은 회전·이동에 따라 바뀌므로 축을 원 변수의 의미로 해석하지 않음

## Ⅳ. PCA와 MDS 비교

| 비교축 | PCA | MDS |
|---|---|---|
| 입력 | 관측치별 변수값 | 개체 간 거리·비유사도 행렬 |
| 보존 관계 | 전체 자료의 분산 | 개체 쌍의 거리·순서 |
| 결과 해석 | 주성분의 변수 기여도 | 개체의 상대적 근접성 |
| 한계 | 선형 투영, 분산이 낮은 축의 정보 손실 | 거리 정의·보존 방식에 결과 의존 |
| 선택 | 변수 축약·상관 구조 요약 | 유사도 자료의 저차원 배치 |

스트레스의 좋고 나쁨을 정하는 절대 임계값을 보편 적용하지 않고 자료·목적과 함께 해석.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 축소 과정의 정보 손실 | 설명분산·거리 적합도와 후속 성능 확인 |
| 전처리·척도 선택에 민감 | 학습 자료에서 전처리 기준을 적합해 검증 자료에 적용 |
| 2차원 그림을 모든 관계로 오해 | 보존 대상과 왜곡 정도를 함께 설명 |

## Ⅵ. 제언

입력 형태와 보존 목표로 기법을 고르고, 축소 후 후속 업무 성능으로 검증

```text
변수 행렬·분산 보존 → PCA / 거리·유사도 행렬 → MDS → 설명분산·스트레스·후속 성능 확인
```

| 구분 | 무검증 축소 | 제언: 목표 기반 축소·검증 |
|---|---|---|
| 정보 손실 | 파악 불가 | 지표로 확인 |
| 해석 | 그림 위주 | 왜곡 설명 |
