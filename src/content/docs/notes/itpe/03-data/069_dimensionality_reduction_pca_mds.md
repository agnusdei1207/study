## 연관 키워드

**차원 축소**, **차원의 저주**, **주성분 분석(PCA)**, **다차원 척도법(MDS)**, **설명 분산**, **거리 보존**, **표준화**

## Ⅰ. 개요

- 핵심 요약 : **차원 축소**는 고차원 자료를 더 낮은 차원으로 표현해 분석·시각화·저장 부담을 줄이는 방법이다.
- 목적 : 정보 구조를 요약하고 잡음·중복을 줄이거나 시각화에 활용한다.
- 유의점 : 축소 결과는 원자료의 일부 정보를 잃을 수 있으므로 분석 목적에 맞게 기법을 선택한다.

## Ⅱ. 특징 및 장점

- 핵심 요약 : **PCA는 분산을 요약하고**, **MDS는 개체 간 거리 관계를 보존**한다.
- **PCA(주성분 분석)** : 원변수의 선형 결합인 직교 성분으로 분산이 큰 방향부터 표현한다.
- **MDS(다차원 척도법)** : 입력 거리·비유사도 행렬의 관계를 저차원 배치에서 근사한다.
- **차원 축소 효익** : 시각화와 후속 모델의 계산량을 줄일 수 있으나, 예측 성능 개선을 보장하지 않는다.

## Ⅲ. PCA와 MDS의 처리 흐름

- 핵심 요약 : **입력 구조와 보존 목표**를 확인한 뒤 저차원 표현을 만들고 손실을 평가한다.

```text
[PCA: 변수 행렬]
      ▼
[중심화·필요 시 표준화]
      ▼
[공분산·특이값 분해]
      ▼
[상위 주성분 선택·투영]
      ▼
[설명 분산·후속 성능 평가]
```

```text
[MDS: 거리·비유사도 행렬]
      ▼
[저차원 점 배치 최적화]
      ▼
[원거리와 저차원 거리 비교]
      ▼
[Stress 등 거리 보존 평가]
      ▼
[시각화·탐색적 해석]
```

## Ⅳ. PCA와 MDS 비교

- 핵심 요약 : **입력 자료와 최적화 목표**가 기법 선택의 기준이다.

| 구분 | PCA | MDS |
|---|---|---|
| 입력 | 관측치×변수 행렬 | 개체 간 거리·비유사도 |
| 보존 목표 | 전체 분산이 큰 축 | 개체 간 거리의 근사 |
| 출력 축 | 원변수의 선형 결합 | 배치 좌표이며 축 해석은 제한적 |
| 평가 예 | 설명 분산 비율 | Stress 등 거리 적합도 |
| 주의점 | 스케일·선형성 영향 | 거리 선택과 표본 수에 영향 |

- PCA의 표준화 여부는 변수 단위와 분석 목적에 따라 판단한다. 분산 크기 자체가 의미가 있는 경우 무조건 표준화하지 않는다.

## Ⅴ. 한계와 방안

- 핵심 요약 : **정보 손실·비선형 구조·계산 비용·해석성**을 축소 목적에 맞춰 점검한다.
- **비선형 구조 손실** → 커널·매니폴드 기법을 후보로 두고 시각화 결과를 과도하게 일반화하지 않는다.
- **표본·거리 행렬 계산 부담** → 표본 추출, 근사 알고리즘, 점진적·무작위 분해를 검토한다.
- **성분 해석의 어려움** → 로딩·기여도를 확인하고 원변수 관점의 설명을 병행한다.
- **차원 축소 후 성능 저하** → 축 개수별 예측·재구성 성능을 검증해 적정 차원을 결정한다.

```text
스케일 편향 → 목적별 중심화·표준화
비선형 구조 → 대체 기법·거리 평가   → 목적에 맞는 저차원 표현
정보 손실   → 성능·재구성 검증
```

## Ⅵ. 기술사적 제언

- 핵심 요약 : **차원 축소 전후의 분석 결과와 정보 손실을 정량 비교**해 적용 근거를 남긴다.
- 지도학습에서 전처리 통계량은 학습 데이터로만 산출해 검증·시험 데이터 누수를 막는다.
- 시각화용 임베딩의 군집 간 거리를 원공간의 정확한 거리로 해석하지 않는다.
- 기법·거리 척도·축 개수·난수 설정을 기록해 재현성을 확보한다.

## Ⅶ. 결론

- 핵심 요약 : PCA와 MDS는 서로 다른 정보를 보존하므로 **분산 요약과 거리 보존** 목적을 구분해 선택한다.
- 답안에는 PCA의 표준화·설명 분산, MDS의 거리 행렬·Stress, 비선형성과 정보 손실 대응을 연결해 쓴다.
