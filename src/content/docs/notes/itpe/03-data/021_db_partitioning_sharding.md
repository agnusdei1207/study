## 지식 로드맵 내 현재 위치

자료처리·데이터 → 분산 데이터베이스 → **데이터베이스 분할·샤딩**

## 30초 인출

- 본질: 데이터베이스 분할은 데이터를 조각(분할 단위)으로 나누어 여러 곳에 배치하는 설계이며, 샤딩은 수평 분할한 조각을 여러 노드에 분산하는 방식
- 메커니즘: 주요 질의와 증가량을 측정해 분할 기준(범위·해시·목록)과 키를 정하고, 조각을 노드에 배치한 뒤 라우팅·재분배 방법을 마련
- 통찰: 분할 키가 조회 경로와 부하 분포를 좌우하므로 주요 질의 조건에 맞는 키를 고르고, 분할만으로는 장애에 대비하지 못하므로 복제·백업을 별도로 설계

<details>
<summary>핵심 용어</summary>

- **파티셔닝(Partitioning)** : 데이터 집합을 관리·처리 단위로 나누는 설계
- **수평 분할** : 행을 범위·해시·목록 등의 기준으로 나누는 방식
- **수직 분할** : 자주 함께 쓰는 컬럼 등 특성에 따라 컬럼을 나누는 방식
- **샤딩(Sharding)** : 수평 분할한 데이터를 여러 노드에 분산 배치하는 방식
- **파티션 키** : 행을 어느 파티션에 둘지 결정하는 값
- **파티션 프루닝(Partition Pruning)** : 질의 조건에 맞지 않는 파티션을 읽지 않는 최적화
- **핫 파티션** : 특정 파티션에 읽기·쓰기가 집중된 상태
- **리밸런싱(Rebalancing)** : 노드·부하 변화에 따라 데이터 분산을 다시 조정하는 작업

</details>

---

## 2~4교시 25점 답안

## Ⅰ. 데이터베이스 분할의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터베이스 분할** 은 데이터를 조각으로 나누어 배치하는 설계이며, **샤딩** 은 수평 분할한 조각을 여러 노드에 분산하는 방식 |
| 목적 | 데이터량·접근 패턴에 맞춘 조회·운영·확장성 확보 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 키 기반 배치 | 분할 키가 데이터 위치와 조회 경로를 결정 |
| 질의 조건 의존 | 키 조건은 프루닝을 돕고 다중 샤드 질의는 병합 비용 발생 |
| 가용성과 분리 | 분할만으로 장애 대비가 되지 않아 복제·백업 별도 설계 |

## Ⅲ. 분할 단위와 분할 키

### 분할 단위

| 단위 | 나누는 대상 |
|---|---|
| 릴레이션 전체 | 테이블 단위로 노드에 배치 |
| 행(튜플) | 수평 분할 |
| 컬럼(속성) | 수직 분할 |

### 분할 키가 조회 경로를 바꾸는 방식

| 분할 기준 | 배치 | 효과·주의 |
|---|---|---|
| 범위 | 연속 값 구간별 | 범위 조건 프루닝 유리, 최신 구간 쏠림 |
| 해시 | 해시 결과별 | 쓰기 분산 유리, 범위 조회 비용 |
| 목록 | 지정 값 집합별 | 업무 범주별 관리 |

## Ⅳ. 수평분할과 수직분할

| 유형 | 나누는 기준 | 주된 효과 | 검토할 한계 |
|---|---|---|---|
| 수평 분할 | 행(범위·해시) | 일부 파티션만 조회·관리 | 키 분포·범위 변경 |
| 수직 분할 | 컬럼·접근 패턴 | 큰 컬럼·접근 권한 분리 | 다시 결합할 때 비용 |
| 샤딩 | 수평 분할 + 노드 분산 | 저장·처리 부하 분산 | 라우팅·노드 간 연산 |

| 구분 | 분할·샤딩 | 복제 |
|---|---|---|
| 배치 | 서로 다른 데이터를 나눔 | 같은 데이터를 여러 곳에 둠 |
| 목적 | 용량·부하 분산 | 장애 대응·읽기 확장 |
| 한계 | 쏠림·분산 질의 | 동기화 지연·충돌 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 핫 파티션 | 키 분포·시간대 부하를 측정해 분할 기준 조정 |
| 키 없는 질의가 모든 샤드를 조회 | 주요 질의의 라우팅 조건 검토 |
| 노드 증설 때 데이터 이동 계획 부재 | 리밸런싱·중단·롤백 시험 |

## Ⅵ. 제언

자주 함께 조회·갱신되는 데이터가 같은 샤드에 모이도록 접근 패턴 기반의 샤드 키를 정하고, 복제와 리밸런싱 절차를 함께 설계

```text
질의 조건 → 샤드 키 → 라우팅 계층 ─┬ 샤드 A (단일 샤드 처리)
                                  └ 샤드 B (단일 샤드 처리)
```

| 구분 | 임의 키 샤딩 | 제언: 접근 패턴 기반 샤딩 |
|---|---|---|
| 데이터 편중 | 특정 샤드 집중 | 해시·가상 노드로 분산 |
| 조인·트랜잭션 | 샤드 간 처리 빈발 | 단일 샤드 처리 위주 |
