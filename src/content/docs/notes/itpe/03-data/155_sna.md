## Ⅰ. 소셜 네트워크 분석(SNA)의 개요

- 핵심 요약 : **소셜 네트워크 분석**(SNA, Social Network Analysis)은 관계 데이터의 구조를 그래프 이론으로 분석하여 핵심 행위자와 집단 구조를 규명하는 기법.
- 개념 : 개인, 조직, 웹 페이지 등 개체(Entity) 간 관계를 **노드**(Node)와 **간선**(Edge)으로 모델링하고, **그래프 이론**(Graph Theory) 기반 지표로 구조적 특성과 핵심 행위자, 집단 응집력을 정량 분석하는 방법론.
- 배경 및 필요성 : 복잡계에서는 개별 속성보다 관계 구조가 시스템 거동을 좌우한다는 네트워크 과학의 관점이 확산되었고, 소셜 미디어와 금융 거래 등 관계 데이터가 급증함.
- 주요 목적 : 영향력자 식별, 정보 확산 경로 예측, 커뮤니티 구조 파악, 이상 징후 탐지.

## Ⅱ. 소셜 네트워크 분석(SNA)의 특징 및 장점

- 핵심 요약 : 그래프 모델링, 중심성 지표, 커뮤니티 탐지, 동적 분석이 결합된 관계 중심 분석 체계.

1. 그래프 기반 모델링 : 방향성, 가중치, 다중 간선을 지원하여 현실의 관계를 표현 → 관계의 강도와 방향까지 분석.
2. **중심성**(Centrality) 지표 : 연결 중심성(Degree), 매개 중심성(Betweenness), 근접 중심성(Closeness), 고유벡터 중심성(Eigenvector)으로 영향력을 다각도 측정.
3. **커뮤니티 탐지**(Community Detection) : 모듈러리티 최대화, 라벨 전파 등으로 밀집된 집단을 발견 → 세분화된 대상 집단 도출.
4. **구조적 동등성**(Structural Equivalence) : 직접 연결이 없어도 연결 패턴이 유사한 노드 그룹을 식별 → 역할이 같은 행위자 파악.
5. 동적 네트워크 분석 : 시간 경과에 따른 노드와 간선의 생성·소멸, 중심성과 커뮤니티의 변화를 추적 → 확산 과정 이해.

## Ⅲ. 소셜 네트워크 분석(SNA)의 구조 (흐름)

- 핵심 요약 : 데이터 수집에서 그래프 구성, 지표 계산, 커뮤니티 탐지, 시각화에 이르는 분석 파이프라인과 중심성 지표의 의미 차이.

```text
[ SNA 분석 파이프라인 ]

1. 데이터 수집 : 소셜 API, 로그, 설문
   ↓
2. 그래프 구성 : 노드·간선 정의, 가중치 부여
   ↓
3. 기초 지표 : 밀도, 평균 경로 길이, 차수 분포
   ↓
4. 중심성 분석 : Degree, Betweenness 등
   ↓
5. 커뮤니티 탐지 : Louvain, Label Propagation
   ↓
6. 시각화·해석 : Gephi, Cytoscape
```

```text
[ 4대 중심성 지표의 의미 ]

연결 중심성 : 직접 연결 수 → 즉시 영향력, 허브 식별
매개 중심성 : 최단 경로 통과 빈도 → 정보 흐름의 통제자
근접 중심성 : 타 노드까지 평균 거리 → 정보 도달 속도
고유벡터 중심성 : 중요한 노드와의 연결 → 질적 영향력
```

## Ⅳ. SNA와 전통적 통계 분석의 비교

- 핵심 요약 : 개체 속성 중심에서 관계 구조 중심으로, 독립 관측 가정에서 상호 의존성의 명시적 모델링으로 전환.

| 비교 항목 | 전통적 통계 분석 | 소셜 네트워크 분석(SNA) |
| --- | --- | --- |
| 분석 단위 | 개별 관측치와 속성 | 노드, 간선, 네트워크 전체 구조 |
| 핵심 가정 | 관측치 간 독립성 | 관측치 간 상호 의존성을 명시적으로 모델링 |
| 설명 변수 | 인구통계, 행동 특성 | 네트워크 위치, 구조적 동등성, 커뮤니티 소속 |
| 인과 추론 | 회귀 계수, 특성 중요도 | 네트워크 효과, 확산 메커니즘, 구조적 구멍 |
| 주요 데이터 | 설문, 실험, 거래 데이터 | 소셜 미디어, 인용망, 단백질 상호작용, 거래망 |

## Ⅴ. 소셜 네트워크 분석(SNA)의 한계와 방안

- 핵심 요약 : 데이터 품질에 따른 구조 왜곡, 관찰 데이터의 인과 해석 한계, 대규모 계산과 시각화의 한계를 각각 보정 기법으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 데이터 품질과 표본 편향 | 누락 간선, 봇 계정, 관측 범위 한계로 중심성 신뢰도 저하 | 다중 데이터 소스 교차 검증, 링크 예측(Link Prediction)으로 누락 간선 추론, 표본 보정 가중치 | 데이터 누락률 |
| 인과 규명의 근원적 한계 | 네트워크 효과와 동질성에 의한 선택을 관찰 데이터만으로 구분하기 어려움 | 무작위 대조 실험, 도구 변수, 준실험 설계, 시계열 기반 그레인저 인과성 검정 | 처치 효과 추정치 |
| 대규모 계산과 시각화 한계 | 노드 수가 커지면 중심성 계산 비용 급증, 헤어볼(Hairball) 시각화 | 분산 그래프 처리(Pregel, GraphX), 근사 알고리즘, 서브샘플링, 커뮤니티 단위 요약 | 계산 소요 시간 |

## Ⅵ. 소셜 네트워크 분석(SNA)에 대한 기술사적 제언

- 핵심 요약 : 다층 네트워크 모델링과 인과 추론의 결합, 프라이버시 보호 분석 체계를 함께 갖추는 방향이 바람직함.
- 친구, 팔로우, 리트윗처럼 관계 유형이 여러 개인 경우 단일 네트워크로 합치기보다, 관계 층과 시간 층을 함께 담는 다층 네트워크(Multilayer Network) 모델로 상호작용을 분석하는 것이 바람직하다.
- 정책이나 마케팅 효과를 검증하려면 SNA 지표를 처치 변수로 두는 잠재 결과 프레임워크를 적용하고, 네트워크 간섭을 고려하는 **역확률 가중치**(IPW, Inverse Probability Weighting) 같은 추정 방법을 함께 쓰는 것이 필요하다.
- 개인 관계 데이터를 다루므로 차등 프라이버시를 적용한 그래프 통계량만 공개하거나, 원본을 옮기지 않는 연합 학습 방식으로 분석하여 보호와 분석 가치를 함께 확보해야 한다.

## Ⅶ. 결론

- 핵심 요약 : SNA는 관계 구조를 정량화하는 네트워크 과학 방법론으로, 다층 모델링과 인과 추론의 결합이 발전 방향.
- 분석 결과의 신뢰도는 데이터 품질과 인과 해석의 엄밀성에 달려 있으므로, 결과를 해석하기 전에 이 두 조건을 점검해야 한다.
