자료처리·데이터 → 데이터 마이닝 → **사회연결망분석(SNA)**

## 30초 인출

- 본질: SNA는 노드와 간선으로 표현한 네트워크의 구조와 관계를 분석하는 기법
- 메커니즘: 개체·관계와 관찰 기간으로 그래프 G = (V, E)를 만들고, 연결·매개·근접·고유벡터 중심성과 밀도·군집계수·커뮤니티(Louvain)를 계산해 후보를 찾은 뒤 거래·업무 속성과 담당자 검토로 확인
- 통찰: 높은 중심성은 영향력이나 위험의 후보 신호일 뿐 의도를 확정하지 못하므로 조사 후보로 쓰고 업무 규칙과 결합하며, 대규모 그래프는 정확 계산 대신 표본 근사와 분산 처리를 비교

<details>
<summary>핵심 용어</summary>

- **SNA(Social Network Analysis)** : 관계망의 구조를 분석하는 기법
- **연결 중심성** : 직접 연결의 수(비율)
- **매개 중심성** : 노드 쌍의 최단경로가 지나가는 정도
- **근접 중심성** : 다른 노드까지의 최단거리 합에 기반한 접근성
- **고유벡터 중심성** : 중요한 이웃과 연결된 정도
- **밀도·직경·군집계수** : 연결 정도 / 최단거리의 최댓값 / 이웃 간 결속
- **Louvain** : 모듈러리티를 높이는 커뮤니티 탐지 휴리스틱

</details>

## 2~4교시 25점 답안

## Ⅰ. SNA의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SNA** 는 노드와 간선으로 표현한 네트워크의 구조·관계를 분석하는 기법 |
| 목적 | 영향력·중개 위치·집단 구조를 파악해 업무 판단 지원 |

## Ⅱ. 특징

| 특징 | 해석 영향 |
|---|---|
| 관계 중심 자료 | 속성 외에 연결·경로·집단 맥락 사용 |
| 위치별 지표 | 직접 연결·매개·접근성·이웃 중요도 구분 |
| 의미 검증 필요 | 높은 중심성은 후보 신호일 뿐 |

## Ⅲ. 분석 절차

```text
개체·관계 자료 → 노드·간선·관찰 기간 정의 → 관계 그래프 G = (V, E)
   ↓ 중심성·경로·커뮤니티 분석 → 후보·근거 경로
거래·업무 속성 교차 확인 → 담당자 검토·조치
```

## Ⅳ. 중심성 지표와 활용

| 중심성 | 계산 관점 | 드러나는 특성 |
|---|---|---|
| 연결 | 직접 연결의 수·비율 | 연결이 많은 노드 |
| 매개 | 노드 쌍 최단경로의 통과 정도 | 집단 간 흐름을 매개하는 노드 |
| 근접 | 다른 노드까지의 최단거리 합 | 짧은 경로로 닿는 노드 |
| 고유벡터 | 이웃의 중심성 점수 | 중요한 이웃과 연결된 노드 |

| 지표 | 계산 관점 | 해석 |
|---|---|---|
| 밀도 | 실제 링크 / 가능한 링크 | 연결 정도 |
| 직경 | 연결된 노드 쌍 최단거리의 최댓값 | 최대 거리 규모 |
| 군집계수 | 이웃 노드 간 연결 정도 | 국소적 결속 |
| Louvain | 모듈러리티를 높이는 분할 | 조밀한 집단 후보 |

작은 세상 효과는 높은 군집계수와 짧은 평균 경로 길이를 함께 갖는 성질이며 밀그램의 작은 세상 실험으로 알려짐.

관계형 DB는 관계를 조인으로, 그래프 DB는 저장된 간선을 따라 탐색하도록 최적화할 수 있으나 성능은 데이터 크기·인덱스·질의 모양에 좌우되므로 특정 지연을 보장하지 않음.

| 활용 영역 | 분석 | 주의 |
|---|---|---|
| 금융 이상거래 | 계좌·기기·거래 관계의 경로와 집단 탐색(공통 IP·디바이스 공유 등) | 구조적 관계만으로 범죄 확정 금지 |
| 마케팅 | 커뮤니티와 관계상 영향력 후보 탐색 | 중심성만으로 캠페인 효과 단정 금지 |
| 공급망·IT 운영 | 의존 관계·병목 후보 식별 | 실제 장애 영향과 대체 경로 확인 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 중심성만으로 거래 의도·위험 여부를 확정할 수 없음 | 관계 지표를 조사 후보 신호로 쓰고 거래 속성·업무 규칙·담당자 검토 결합 |
| 대규모 그래프의 최단경로 계산 비용 증가 | 분석 범위·허용 오차를 정하고 정확 계산과 표본 근사 비교 |

## Ⅵ. 제언

중심성으로 조사 후보를 좁히고 업무 속성과 담당자 검토로 확정하며, 규모가 크면 근사·분산 처리를 비교

```text
그래프 구성 → 중심성·커뮤니티 → 후보 → 업무 속성 대조 → 담당자 판단 → 결과 환류
```

| 구분 | 중심성 수치로 판정 | 제언: 후보 신호 + 검토 |
|---|---|---|
| 오판 | 위험 | 업무 규칙으로 확인 |
| 규모 | 계산 부담 | 근사·분산 비교 |
