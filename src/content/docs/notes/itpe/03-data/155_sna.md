## 연관 키워드

- 소셜 네트워크 분석 (SNA, Social Network Analysis)

## Ⅰ. 소셜 네트워크 분석(SNA)의 개요

- 핵심 요약 : 관계 데이터의 구조적 특성을 그래프 이론으로 분석하여 네트워크 내 핵심 행위자와 집단 구조를 규명하는 분석 기법.
- 개념 : 개인, 조직, 웹 페이지, 단백질 등 개체(Entity) 간의 관계(Relation)를 노드(Node)와 간선(Edge)으로 모델링하고, 그래프 이론(Graph Theory) 기반의 수리적 지표를 통해 네트워크의 구조적 특성, 핵심 행위자(Key Player), 집단 응집력(Community Cohesion)을 정량 분석하는 방법론.
- 배경 및 필요성 : 복잡계(Complex System)에서 개별 속성보다 관계 구조가 시스템 거동을 결정한다는 네트워크 과학 패러다임 확산, 소셜 미디어·IoT·금융 거래 등 관계 데이터 폭발적 증가.
- 주요 목적 : 네트워크 내 영향력자 식별, 정보 확산 경로 예측, 커뮤니티 구조 파악, 이상 징후(사기, 허위 정보) 탐지.

## Ⅱ. 소셜 네트워크 분석(SNA)의 특징

- 핵심 요약 : 그래프 모델링, 4대 중심성 지표, 커뮤니티 탐지, 동적 네트워크 분석이 결합된 관계 중심 분석 체계.

1. 그래프 기반 모델링 : 개체를 노드, 관계를 간선으로 표현하며 방향성(Directed), 가중치(Weighted), 다중 간선(Multi-edge) 지원.
2. 4대 중심성 지표 : 연결 중심성(Degree), 매개 중심성(Betweenness), 근접 중심성(Closeness), 고유벡터 중심성(Eigenvector) 다각도 영향력 측정.
3. 커뮤니티 탐지 : 모듈러리티(Modularity) 최대화, 라벨 전파(Label Propagation), 확률적 블록 모델(SBM) 등 군집화 알고리즘.
4. 구조적 동등성(Structural Equivalence) : 직접 연결 없어도 유사한 연결 패턴을 가진 노드 그룹 식별.
5. 동적 네트워크 분석 : 시간 경과에 따른 노드/간선 생성·소멸, 중심성 변화, 커뮤니티 진화 추적.

## Ⅲ. 소셜 네트워크 분석(SNA)의 구조 (흐름)

- 핵심 요약 : 데이터 수집, 그래프 구성, 지표 계산, 커뮤니티 탐지, 시각화·해석의 분석 파이프라인.
- SNA 분석 파이프라인.

```text
[ SNA 분석 파이프라인 ]
[ 1. 데이터 수집 ] -> 소셜 미디어 API, 로그, 설문, 센서 데이터
    │
    ▼
[ 2. 그래프 구성 ] -> 노드/간선 정의, 방향성/가중치 부여, NetworkX/GraphFrames 생성
    │
    ▼
[ 3. 기초 지표 계산 ] -> 밀도, 평균 경로 길이, 클러스터링 계수, 차수 분포
    │
    ▼
[ 4. 중심성 분석 ] -> Degree, Betweenness, Closeness, Eigenvector, PageRank
    │
    ▼
[ 5. 커뮤니티 탐지 ] -> Louvain, Infomap, Label Propagation, SBM
    │
    ▼
[ 6. 시각화·해석 ] -> Gephi, Cytoscape, Pyvis 인터랙티브 시각화
```

- 4대 중심성 지표 비교.

```text
[ 4대 중심성 지표 비교 ]
연결 중심성(Degree)       : 직접 연결된 이웃 수 -> 즉시 영향력, 허브 식별
매개 중심성(Betweenness)  : 최단 경로 통과 빈도 -> 정보 흐름 통제자, 브리지 역할
근접 중심성(Closeness)    : 타 노드까지 평균 거리 -> 정보 확산 속도, 효율적 도달
고유벡터 중심성(Eigenvector) : 중요 노드와 연결 정도 -> 질적 영향력, PageRank 기초
```

## Ⅳ. SNA와 전통적 통계 분석의 비교

- 핵심 요약 : 개체 속성 중심에서 관계 구조 중심으로, 독립 관측 가정에서 상호 의존성 명시적 모델링으로 전환.

| 비교 항목 | 전통적 통계 분석(회귀, 분류 등) | 소셜 네트워크 분석(SNA) |
|---|---|---|
| 분석 단위 | 개별 관측치(행), 독립 변수(속성) | 노드(개체), 간선(관계), 네트워크 전체 구조 |
| 핵심 가정 | 관측치 간 독립성(Independent Observations) | 관측치 간 상호 의존성(Interdependence) 명시적 모델링 |
| 설명 변수 | 인구통계학적 속성, 행동 특성 등 | 네트워크 위치(중심성), 구조적 동등성, 커뮤니티 멤버십 |
| 인과 추론 | 회귀 계수, 특성 중요도 | 네트워크 효과(Peer Effect), 확산 메커니즘, 구조적 구멍(Structural Hole) |
| 도메인 | 설문 조사, 실험, 거래 데이터 | 소셜 미디어, 인용 네트워크, 단백질 상호작용, 금융 거래망 |

## Ⅴ. 소셜 네트워크 분석(SNA)의 장점과 한계

- 핵심 요약 : 관계 구조의 숨은 패턴 발굴 장점, 데이터 품질 의존성과 인과 추론 한계.
- 장점
  1. 개별 속성만으로는 보이지 않는 숨은 영향력자, 브리지 역할, 커뮤니티 구조 발굴.
  2. 정보 확산, 혁신 채택, 전염병·허위정보 전파 등 동적 프로세스 메커니즘 규명.
  3. 구조적 구멍(Structural Hole) 식별로 브로커리지(Brokerage) 기회 포착.
- 한계점 1 : 데이터 품질과 표본 편향에 따른 분석 결과 왜곡
  - 한계점 : 누락된 간선(Missing Edges), 허위 계정(봇), 관측 범위 한계로 네트워크 구조 왜곡, 중심성 지표 신뢰도 저하.
  - 해결 방안 : 다중 데이터 소스 교차 검증, 누락 간선 추론(Link Prediction), 표본 보정 가중치 적용, 강건성 분석(Robustness Check) 수행.
- 한계점 2 : 인과관계 규명의 근원적 한계 (상관관계 vs 인과관계)
  - 한계점 : 네트워크 효과(Peer Effect)와 동질성 선택(Homophily Selection) 구분이 관찰 데이터만으로는 불가능.
  - 해결 방안 : 무작위 대조 실험(RCT), 도구 변수(Instrumental Variable), 준실험 설계(Quasi-Experiment), 시계열 네트워크 그레인저 인과성(Granger Causality) 결합.
- 한계점 3 : 대규모 네트워크 계산 복잡도와 시각화 한계
  - 한계점 : 수백만 노드 네트워크에서 중심성 계산 O(N^2~3) 복잡도, 시각화 시 헤어볼(Hairball) 문제로 해석 불가.
  - 해결 방안 : 분산 그래프 처리(Pregel, GraphX, GraphFrames), 근사 알고리즘(Approximate Betweenness), 서브샘플링, 커뮤니티 단위 요약 시각화.

## Ⅵ. 소셜 네트워크 분석(SNA)에 대한 기술사적 제언

- 핵심 요약 : 다층 네트워크(Multilayer Network) 모델링과 인과 추론 결합으로 분석 깊이 제고 필요.
- 다층 네트워크(Multilayer Network) 모델링 확산 : 단일 관계 유형(친구, 팔로우, 리트윗)을 넘어 다중 관계 층(Multiplex Network)과 시계열 층(Temporal Layer)을 통합한 다층 네트워크 모델로 복합적 상호작용 메커니즘 분석 필요.
- 인과 추론 프레임워크와의 융합 : SNA 지표를 처치 변수(Treatment)로 활용하는 잠재 결과 프레임워크(Potential Outcomes Framework) 결합, 네트워크 간섭(Interference) 하의 인과 효과 추정 방법론(Horvitz-Thompson, IPW) 적용으로 정책 효과 과학적 검증 필요.
- 프라이버시 보호 네트워크 분석 : 차등 프라이버시(Differential Privacy) 적용 그래프 통계량 공개, 연합 학습(Federated Learning) 기반 분산 네트워크 분석으로 개인정보 보호와 분석 가치 동시 확보 필요.

## Ⅶ. 결론

- 핵심 요약 : SNA는 관계 구조 중심의 네트워크 과학 방법론으로 다층 모델링과 인과 추론 융합이 차세대 분석 방향.
- 요약 : 개체 간 관계 데이터를 그래프로 모델링하여 중심성, 커뮤니티, 구조적 동등성 등 구조적 특성을 정량 분석하는 방법론.
- 시사점 : 데이터 품질 강건성, 인과 추론 결합, 다층 네트워크 확장, 프라이버시 보호의 4요소가 실무 SNA 신뢰도 확보의 전제 조건.
