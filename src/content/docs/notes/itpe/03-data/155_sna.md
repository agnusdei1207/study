데이터 분석 → 그래프 마이닝 → 사회연결망분석

## 30초 인출

- 본질: **SNA는** 사람·조직·계정 등의 관계를 그래프로 표현해 노드의 위치와 집단 구조를 분석하는 방법
- 메커니즘: 관계 그래프에서 직접 연결·최단경로·거리·이웃 중요도를 각각 계산해 중심성을 산출
- 통찰: 한계: 중심성만으로 거래 의도·위험 여부를 확정할 수 없음 → 방안: 관계 지표를 조사 후보 신호로 쓰고 거래 속성·업무 규칙·담당자 검토를 결합

<details><summary>핵심 용어</summary>

- **SNA (Social Network Analysis)** : 행위자와 관계로 표현한 네트워크의 구조·위치를 분석하는 방법.
- **노드 (Node)** : 네트워크에서 사람·조직·계정 등 분석 대상을 나타내는 요소.
- **간선 (Edge)** : 두 노드 사이의 관계를 나타내는 연결.
- **연결 중심성 (Degree Centrality)** : 한 노드에 직접 연결된 이웃의 수 또는 비율.
- **매개 중심성 (Betweenness Centrality)** : 다른 노드 쌍의 최단 경로에 한 노드가 포함되는 정도.
- **근접 중심성 (Closeness Centrality)** : 한 노드에서 다른 노드까지의 최단거리 합에 기반한 접근성 지표.
- **고유벡터 중심성 (Eigenvector Centrality)** : 연결된 이웃의 중요도까지 반영하는 중심성 지표.

</details>

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|:---|:---|
| 정의 | SNA는 노드와 간선으로 표현한 네트워크의 구조·관계를 분석하는 기법 |
| 목적 | 관계망 내 영향력·중개 위치·집단 구조를 파악해 업무 판단을 지원 |

## Ⅱ. SNA의 특징

| 특징 | 해석 영향 |
|---|---|
| 관계 중심 자료 | 개별 개체의 속성 외에 연결·경로·집단 맥락 사용 |
| 위치별 지표 | 직접 연결·매개·접근성·이웃 중요도를 구분 |
| 의미 검증 필요 | 높은 중심성은 영향력·위험의 후보 신호일 뿐 |

## Ⅲ. 관계망 구성·분석·검증 체계

```text
개체·관계 자료 → 노드·간선·관찰 기간 정의 → 관계 그래프 G=(V,E)
                                               ↓
                    중심성·경로·커뮤니티 분석 → 후보·근거 경로
                                               ↓
                    거래·업무 속성 교차 확인 → 담당자 검토·조치
```

### 중심성 지표의 하위 계산 관계

```text
노드 v → 직접 이웃 수: 연결 중심성 / 최단경로 경유: 매개 중심성
       → 다른 노드까지 거리: 근접 중심성 / 이웃 점수: 고유벡터 중심성
```

## Ⅳ. 중심성·집단 분석과 활용 비교

### 중심성 지표

| 중심성 | 계산 관점 | 드러나는 특성 |
|---|---|---|
| 연결 중심성 (Degree) | 직접 연결의 수·비율 | 연결이 많은 노드 파악 |
| 매개 중심성 (Betweenness) | 노드 쌍 최단 경로의 통과 정도 | 집단 간 정보·자원 흐름의 매개 노드 파악 |
| 근접 중심성 (Closeness) | 다른 노드까지의 최단거리 합 | 다른 노드에 짧은 경로로 닿는 노드 파악 |
| 고유벡터 중심성 (Eigenvector) | 연결 이웃의 중심성 점수 | 중요한 이웃과 연결된 노드 파악 |

### 네트워크·집단 지표

| 지표·분석 | 계산·판정 관점 | 해석 |
|:---|:---|:---|
| 밀도 | 실제 링크 수와 가능한 링크 수의 비율 | 네트워크의 연결 정도 |
| 직경 | 연결된 노드 쌍 사이 최단거리의 최댓값 | 네트워크의 최대 거리 규모 |
| 군집계수 | 이웃 노드 사이 연결의 정도 | 국소적 결속 정도 |
| Louvain | 모듈러리티를 높이는 커뮤니티 분할 휴리스틱 | 연결이 조밀한 집단 후보 |

- **작은 세상 효과 (Small-World Phenomenon)** :
  - 높은 군집 계수(Clustering Coefficient)와 짧은 평균 경로 길이(Average Path Length)를 동시에 갖는 특성 (밀그램의 6단계 분리 이론).

### 관계 탐색과 저장 구조

- **RDBMS와 그래프 DB의 탐색 특성** :
  - 관계형 DB는 관계를 조인으로 탐색하고, 그래프 DB는 저장된 간선·인접 관계를 따라 탐색하도록 최적화할 수 있음.
  - 탐색 성능은 데이터 크기, 인덱스, 질의 모양, 저장 구조에 좌우되므로 그래프 DB의 다단계 탐색을 항상 $O(1)$로 보거나 특정 지연시간을 보장하지 않음.

### SNA의 산업별 핵심 적용 사례


| 활용 영역 | 네트워크 분석 | 활용 시 주의 |
|---|---|---|
| 금융 이상거래 | 계좌·기기·거래 관계의 경로와 집단 탐색 | 구조적 관계만으로 범죄 확정 금지 |
| 마케팅 | 커뮤니티와 관계상 영향력 후보 탐색 | 팔로워·중심성만으로 캠페인 효과 단정 금지 |
| 공급망·IT 운영 | 의존 관계와 연결 병목 후보 식별 | 실제 장애 영향과 대체 경로 확인 |

1. **금융 FDS 및 자금세탁방지 (AML)** :
   - 다수의 대포통장이 1개의 공통 IP, 디바이스 ID, 또는 전화번호를 공유하는 '점조직 사기 링(Fraud Ring)'을 서브그래프 패턴 매칭으로 적발.
2. **타겟 마케팅 및 인플루언서 발굴** :
   - 단순 팔로워 수뿐 아니라 관심사 커뮤니티 내 관계 위치를 살펴 마케팅 대상 후보를 발굴하고, 실제 반응 자료로 효과를 검증.
3. **공급망 및 IT 인프라 장애 분석** :
   - 매개 위치가 높은 서버·공급사를 영향 조사 후보로 보고 실제 대체 경로·장애 전파를 확인.

### 실무 대규모 그래프 연산 병목 및 튜닝 전략


| 분석 대상 | 확장 시 부담 | 적용 판단 |
|---|---|---|
| 매개 중심성 | 최단 경로 계산량·메모리 증가 | 표본 근사와 정확도 요구를 비교 |
| 대규모 그래프 | 데이터 분산·반복 순회 비용 | 분산 처리 도구와 그래프 저장 구조를 실제 질의로 평가 |

매개 중심성의 정확 계산·표본 근사·분산 처리는 그래프 크기와 허용 오차에 따라 비교.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 중심성만으로 거래 의도·위험 여부를 확정할 수 없음 | 관계 지표를 조사 후보 신호로 쓰고 거래 속성·업무 규칙·담당자 검토를 결합 |
| 대규모 그래프의 최단경로 계산 비용 증가 | 분석 범위·근사 허용 오차를 정하고 정확 계산과 표본 근사를 비교 |

## Ⅵ. 제언

금융 이상거래는 중심성을 조사 후보로만 쓰고 근거 경로·거래 속성·담당자 검토를 거쳐 조치를 결정.
