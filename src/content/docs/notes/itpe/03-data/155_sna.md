## Ⅰ. 관계의 연결 구조를 파헤치는 사회연결망분석(SNA) 개요

### 가. 사회연결망분석(SNA)의 정의
- 개인, 조직, 웹페이지, 금융 계좌 등 객체 간의 관계(연결선, Tie/Edge)와 상호작용 패턴을 수학적 **그래프 이론** (Graph Theory)에 기반하여 정량적으로 모델링하고 분석함으로써, 네트워크 전체의 구조적 특성과 **핵심 영향력자** (Influencer)를 도출하는 사회연결망분석(SNA, Social Network Analysis) 기법.
- 속성 중심 분석(Attribute-based)의 한계를 극복하고 **관계 중심 분석** (Relational-based)을 수행함.

## Ⅱ. SNA의 핵심 4대 중심성(Centrality) 지표 분석

```text
[ SNA 4대 핵심 중심성 지표 ]
+---------------------+---------------------+---------------------+---------------------+
| 1. 연결 중심성      | 2. 근접 중심성      | 3. 매개 중심성      | 4. 고유벡터 중심성  |
| (Degree)            | (Closeness)         | (Betweenness)       | (Eigenvector)       |
+---------------------+---------------------+---------------------+---------------------+
| 직접 연결된 친구 수 | 다른 모든 노드까지의| 노드 간 최단 경로의 | "중요한 친구와 많이 |
| 마당발, 직접 인기도 | 최단 거리 합이 최소 | 길목을 쥐고 있는 허브|  연결되어 있는가?"  |
| 단순 발화력         | 정보 전파 속도 극상 | 중개자, 브릿지 역할 | 구글 PageRank 원리  |
+---------------------+---------------------+---------------------+---------------------+
```

### 가. 4대 중심성 수식 및 비즈니스 특성 매트릭스

| 중심성 지표 | 수학적 산식 및 메커니즘 | 비즈니스/시스템적 의미 | 실제 응용 사례 |
| :--- | :--- | :--- | :--- |
| **연결 중심성 (Degree)** | $C_D(v) = \text{deg}(v)$ (방향 그래프는 In-degree, Out-degree 분리) | 직접적으로 연결된 간선의 수, 단순 인기도 | 트위터 팔로워 수, 악성코드 전파 허브 IP(Internet Protocol) |
| **근접 중심성 (Closeness)** | $C_C(v) = \frac{1}{\sum_{u \neq v} d(v, u)}$ ($d$는 최단 거리) | 네트워크 내 다른 모든 노드에 가장 적은 홉(Hop)으로 도달 | 감염병 확산의 슈퍼 전파자, 물류 배송 허브 |
| **매개 중심성 (Betweenness)** | $C_B(v) = \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}$ (최단 경로 중 $v$ 통과 비율) | 서로 다른 두 그룹 사이의 정보 흐름을 독점 통제하는 관문(Gateway) | 대포통장 자금 세탁 중계 계좌, 핵심 브로커 |
| **고유벡터 중심성 (Eigenvector)** | $C_E(v) = \frac{1}{\lambda} \sum_{u} A_{vu} C_E(u)$ (인접 행렬 고유벡터) | 연결된 이웃 노드의 중요도까지 가중 반영하여 위세 측정 | **구글 페이지랭크** (PageRank), 학술 논문 피인용도 |

## Ⅲ. 거시적 네트워크 구조 지표: 밀도, 지름, 응집 군집

### 가. 네트워크 전체 특성 지표
- **네트워크 밀도 (Density)** : 전체 가능한 간선 수 대비 실제 존재하는 간선의 비율. 밀도가 높을수록 정보 공유가 빠르고 결속력이 강함.
- **작은 세상 효과 (Small-World Phenomenon)** : 높은 **군집화 계수** (Clustering Coefficient)와 짧은 평균 경로 길이를 동시에 갖는 특성 (케빈 베이컨의 6단계 법칙).

### 나. 커뮤니티 탐지 (Community Detection)
- 복잡한 전체 망에서 노드 간 연결이 유독 빽빽한 하위 하위 군집(모듈)을 탐색 $\rightarrow$ **Louvain 알고리즘** (모듈성 최대화) 활용.

## Ⅳ. 사회연결망분석(SNA)의 주요 한계점 및 해결 방안

- 대규모 그래프 데이터에서의 중심성(Centrality) 연산의 극심한 시간 복잡도 :
  - 한계점 : 매개 중심성(Betweenness Centrality)은 $O(V \cdot E)$, 고유벡터 중심성은 거듭제곱 반복 연산이 필요하여 수백만 노드/엣지 환경에서 연산 불가.
  - 해결 방안 : **샘플링 기반 근사 알고리즘** (Brandes 근사 알고리즘) 적용, **분산 그래프 처리 프레임워크** (Apache Spark GraphX, NetworkX 대안 C++ 래퍼) 도입.
- 노드 및 엣지의 동적 변화를 반영하지 못하는 정적(Static) 네트워크 스냅샷 한계 :
  - 한계점 : 실제 소셜 네트워크와 사기 적발(FDS, Fraud Detection System) 네트워크는 시간에 따라 실시간으로 연결이 생성·소멸함에도 정적 그래프로 분석하여 시간적 이상 징후 포착 지연.
  - 해결 방안 : **동적 그래프 신경망** (DGNN: Dynamic Graph Neural Network) 도입, 시계열 이벤트 엣지를 지원하는 그래프 데이터베이스(Neo4j, Amazon Neptune) 구축.
- 불완전한 관측 데이터로 인한 누락 엣지 및 네트워크 경계 설정 오류 :
  - 한계점 : 데이터 수집의 한계로 인해 중요한 브로커 노드의 연결이 누락되거나 조직 외부와의 상호작용이 단절되어 중심성 지표 왜곡.
  - 해결 방안 : **링크 예측** (Link Prediction) 알고리즘을 통한 잠재 관계 복원, 경계 설정에 대한 도메인 기반 유효성 검증 체계 수립.

## Ⅴ. 엔터프라이즈 그래프 마이닝 실무 제언

- 금융 **이상거래 탐지** (FDS) 및 자금세탁방지(AML, Anti-Money Laundering) 적용 : 개별 계좌의 거래 금액만 보면 정상으로 보이나, 여러 계좌를 거쳐 원래 송금자에게 돈이 되돌아오는 순환 이상 패턴(Circular Transaction)은 테이블 조인으로는 탐지가 불가능하므로, SNA 기반의 주기(Cycle) 탐색 알고리즘을 필수 연동해야 함.
- **그래프 데이터베이스** (Neo4j) 인프라 도입 : 노드와 간선이 수억 개에 달하는 대규모 소셜 그래프를 RDBMS(Relational Database Management System)의 재귀 쿼리로 처리하면 DB(Database)가 정지되므로, 간선 포인터를 메모리에 직접 캐싱하는 **인덱스 프리 인접성** (Index-Free Adjacency) 아키텍처를 지원하는 전용 Graph DB를 채택할 것을 제언함.
