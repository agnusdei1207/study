## 30초 인출

```text
설계: 모델링 → ERD → 정규화 → 물리 설계(분할·인덱스)
저장: RDBMS / NoSQL / 분산 DB / 벡터·인메모리
운영: 트랜잭션 → 동시성·격리 → 회복·복제·HA → 튜닝·이관
관리: 표준화 → 품질관리 → 거버넌스 → MDM·관측가능성
활용: 통계(추정·검정) → 마이닝 → 시각화 → DW·BI·AI 데이터
```

- 본질: 같은 데이터라도 설계·저장·운영·관리·활용 단계마다 요구하는 품질 축이 다르고, 각 단계의 선택은 균형의 문제
- 기본 논리: `정규화 ↔ 성능`, `일관성 ↔ 가용성`, `정확성 ↔ 적시성`의 균형을 근거로 설명

## 학습 역할과 누적 회독

| 단계 | 의미 | 누적 회독 |
|---|---|---|
| **기초** | 핵심 코어의 기본 개념 | 기초 |
| **서브** | 코어와 함께 이해할 주요 주변 요소 | 기초+서브 |
| **응용** | 코어를 전제로 한 파생·적용 요소 | 기초+서브+응용 |

> 전체 키워드를 보존하고 회독 범위만 누적 확장한다.

## 일반 학습 원칙

- 데이터 개념은 모델링·저장·품질·분석의 연결 관계로 학습하고, 유사 개념은 동일 기준의 비교표로 정리.
- 제품명과 수치보다 정합성·가용성·성능·운영 복잡성의 균형을 비교 평가.
- 변경 가능한 표준·법령·가이드라인은 공식 원문으로 최신성 재확인.
