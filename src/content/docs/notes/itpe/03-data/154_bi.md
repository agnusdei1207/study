## 지식 로드맵 내 현재 위치

자료처리·데이터 → 데이터 분석 활용 → **비즈니스 인텔리전스(BI)**

## 30초 인출

- 본질: BI는 기업 데이터를 수집·가공·분석해 의사결정에 쓸 정보와 시각화를 제공하는 체계
- 메커니즘: 원천 데이터를 통합 저장하고 KPI 계산식·차원·권한을 담은 의미 모델(시맨틱 계층)을 거쳐 관리형 보고, 셀프서비스 분석, 자연어 질의로 소비하게 함
- 통찰: 부서마다 지표 정의가 다르면 같은 KPI가 다른 값으로 보고되므로 핵심 KPI의 소유자와 승인 절차를 정해 시맨틱 계층에 공통 정의와 권한을 적용하고, 자연어 질의는 승인된 지표와 권한 범위에서만 실행

<details>
<summary>핵심 용어</summary>

- **BI(Business Intelligence)** : 기업 데이터를 분석해 의사결정 정보를 제공하는 체계
- **KPI** : 핵심 성과 지표
- **시맨틱 계층(의미 모델)** : 지표 계산식·차원·권한을 공통으로 정의하는 계층
- **셀프서비스 BI** : 현업 사용자가 직접 데이터를 탐색·시각화하는 방식
- **BA(Business Analytics)** : 원인·예측·시나리오 중심의 고급 분석
- **Metrics-as-Code** : 지표 정의를 버전 관리되는 코드·설정으로 관리하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. BI의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **BI** 는 기업 데이터를 수집·가공·분석해 의사결정에 쓸 정보와 시각화를 제공하는 체계 |
| 목적 | 경영진과 실무자가 일관된 정보로 판단하도록 지원 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 통합 분석 기반 | 여러 업무 자료의 지표·차원 정의 연결 |
| 공통 의미 계층 | KPI 계산식·권한·업무 용어 재사용 |
| 다양한 소비 방식 | 관리형 보고와 현업의 통제된 탐색 병행 |

## Ⅲ. 체계

```text
원천 데이터 → 통합 저장 → 의미 모델(KPI 계산식·차원·권한)
                              ├ 관리형 보고
                              ├ 셀프서비스 분석
                              └ 자연어 질의(허용 범위 내)
```

## Ⅳ. 제공 방식과 BA·AI/ML 비교

| 방식 | 관리형 보고 | 셀프서비스 | 시맨틱 계층·AI 보조 |
|---|---|---|---|
| 주 사용자 | IT·데이터 조직, 업무 사용자 | 현업 사용자 | 통제된 셀프서비스 사용자 |
| 제공물 | 정기 보고서·대시보드 | 사용자 정의 시각화·질의 | 공통 의미 모델 기반 분석·대화형 탐색 |
| 고려사항 | 요구 반영 대기·배포 관리 | 지표 정의 분산·권한 통제 | 의미 모델 품질·접근 통제·결과 검증 |

BI·BA·AI/ML은 제품에서 겹칠 수 있어 산출물과 분석 목적으로 구분.

| 비교 | BI | BA(고급 분석) | AI/ML |
|---|---|---|---|
| 관점 | 지표·현황 탐색 | 원인·예측·시나리오 | 패턴 학습·예측·생성 |
| 질문 | 무엇이 일어났는가 | 왜 일어났는가, 무엇이 일어날 수 있는가 | 어떤 조치를 지원·자동화할 수 있는가 |
| 산출 | 대시보드·KPI 보고서 | 예측 결과·시나리오 | 추천·자연어 응답 |

| 지표 통제 | 내용 |
|---|---|
| Metrics-as-Code | 지표의 업무 정의·계산식·필터를 버전 관리 |
| 헤드리스 시맨틱 계층 | 특정 도구에 종속되지 않고 API·SQL로 같은 지표 제공 |
| 대시보드 거버넌스 | 사용 현황·담당자 확인, 미사용·중복 정리, 승인 상태 표시 |

| 자연어 질의 단계 | 통제 |
|---|---|
| 질문 | 목적·범위, 사용자 권한 확인 |
| 의미 해석·질의 생성 | 승인된 시맨틱 모델·지표만 참조 |
| 실행·응답 | 생성 SQL·필터 검토, 결과 근거 표시 |
| 사용자 확인 | 업무 판단 전 응답 검증 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 부서별 지표 정의가 달라 같은 KPI가 다른 값으로 보고 | 핵심 KPI의 소유자·승인 절차 정하고 시맨틱 계층에 공통 정의·권한 적용 |
| 셀프서비스에서 미승인 데이터·지표 확산 | 승인 데이터셋과 지표 버전·권한을 의미 계층에 연결 |
| 자연어 질의가 잘못된 필터·집계 생성 | 생성 질의·필터·출처 검토, 주요 지표와 대조 |

## Ⅵ. 제언

공통 시맨틱 계층으로 지표 정의를 하나로 관리하고, 셀프서비스와 자연어 질의는 승인된 지표·권한 안에서 제공

```text
원천 → 통합 저장 → 시맨틱 계층(승인 지표·권한) → 보고 / 셀프서비스 / 자연어 질의
```

| 구분 | 도구별 지표 정의 | 제언: 공통 시맨틱 계층 |
|---|---|---|
| KPI 값 | 부서별 상이 | 하나의 정의 |
| 확산 | 미승인 지표 | 승인 상태 관리 |
