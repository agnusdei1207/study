## 연관 키워드
- 선형 구조, 배열, 연결 리스트, 스택, 큐, 덱, 비선형 구조, 트리, 그래프, 힙, DFS, BFS, 균형

### Ⅰ. 선형·비선형 자료구조의 개요

- 핵심 요약 : 선형 자료구조는 원소가 논리적 순서에 따라 앞·뒤 원소와 연결되는 구조. 비선형 자료구조는 원소가 단일 순서로만 이어지지 않고 계층·망 형태의 관계로 연결되는 구조.
- 개념 : 선형 자료구조는 원소가 논리적 순서에 따라 앞·뒤 원소와 연결되는 구조(**선형 자료구조**, Linear Structure). 비선형 자료구조는 원소가 단일 순서로만 이어지지 않고 계층·망 형태의 관계로 연결되는 구조(**비선형 자료구조**, Non-Linear Structure).
- 배경 및 필요성 : 순차 데이터 처리·버퍼링·LIFO/FIFO 연산의 비용과 접근특성이 다름. 계층 탐색·관계 질의·우선순위 검색은 선형 순회만으로 비효율.
- 주요 목적 : 연산패턴에 적합한 메모리·접근구조 선택. 관계와 탐색 요구에 맞는 구조로 검색·삽입·연결 효율 개선.

### Ⅱ. 선형 자료구조의 특징 및 장점

- 핵심 요약 : 배열·연결리스트·스택·큐·덱; 인덱스 접근·삽입삭제·메모리 지역성 비교가 핵심.

1. 배열 : 인덱스로 임의 접근 O(1), 중간 삽입·삭제 O(n) → 고정 크기 순차 접근에 유리.
2. 연결리스트 : 위치 접근 O(n), 알려진 노드 삽입·삭제 O(1) → 동적 크기 변동에 유리.
3. 스택·큐·덱 : LIFO/FIFO/양끝 연산 → 호출 관리·작업 대기열·버퍼링.

### Ⅲ. 비선형 자료구조의 특징 및 장점

- 핵심 요약 : 트리·그래프·힙·해시 등 관계구조; DFS(Depth-First Search), BFS(Breadth-First Search) 탐색.

1. 트리·그래프 : 계층·망 관계를 노드·간선으로 표현 → 다중 경로와 관계 질의 지원.
2. DFS(Depth-First Search) : 한 분기를 끝까지 탐색 후 백트래킹 → 경로 찾기·순환 검출.
3. BFS(Breadth-First Search) : 인접 노드부터 순차 탐색 → 최단 경로·단계별 접근.

### Ⅲ. 선형·비선형 자료구조의 구조 (흐름)

- 핵심 요약 : 연산패턴 정의 → 배열·리스트 선택 → 스택·큐 등 추상자료형 제공 → 삽입·삭제·탐색 → 경계·동시성 검증.

```text
연산패턴 정의
  ↓
배열·리스트 선택
  ↓
스택·큐 등 추상자료형 제공
  ↓
삽입·삭제·탐색
  ↓
경계·동시성 검증
```

```text
배열: 인덱스 접근; 스택: LIFO; 큐: FIFO; 덱: 양끝 삽입·삭제
```

### Ⅳ. 선형 구조와 비선형 구조 비교

- 핵심 요약 : 선형 구조는 원소가 순차적 앞뒤 관계, 비선형 구조는 계층·망 관계와 다중 경로.

| 비교 축 | 선형 구조 | 비선형 구조 |
|---|---|---|
| 연결 형태 | 원소가 순차적 앞뒤 관계 | 계층·망 관계와 다중 경로 |
| 대표 구조 | 배열, 연결리스트, 스택, 큐 | 트리, 그래프, 힙 |
| 탐색 | 순차 접근 | 관계·계층 기반 질의 |

### Ⅴ. 배열과 연결리스트 비교

- 핵심 요약 : 배열은 인덱스 접근 O(1)·중간삽입·삭제 O(n), 연결리스트는 위치 접근 O(n)·알고 있는 노드 삽입·삭제 O(1).

| 비교 축 | 배열 | 연결리스트 |
|---|---|---|
| 접근 | 인덱스 접근 O(1) | 위치 접근 O(n) |
| 삽입·삭제 | 중간 O(n), 요소 이동 필요 | 알고 있는 노드 O(1) |
| 메모리 | 연속 메모리, 지역성 높음 | 분산 메모리, 포인터 오버헤드 |

### Ⅴ. 선형 구조의 한계와 방안

- 핵심 요약 : 잘못된 구조선택·메모리·캐시 비효율·경계·동시성 오류를 실제 패턴 측정과 동기화로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 잘못된 구조선택 | 빈번한 중간삽입에 배열 사용 | 실제 접근·변경 패턴 측정 | 연산별 지연 |
| 메모리·캐시 비효율 | 포인터 추적·할당 잦은 연결구조 | 연속 메모리·풀·블록구조 검토 | 캐시 미스·할당량 |
| 경계·동시성 오류 | 인덱스 범위·큐 포화·다중스레드 접근 | 불변식·경계검사·동기화·락프리 검증 | 오류·경합률 |

### Ⅵ. 비선형 구조에 대한 제언

- 핵심 요약 : 자료구조 선택은 명칭의 복잡성이 아니라 접근패턴·갱신비율·메모리·일관성 요구에 근거해야 함.

1. 자료구조 선택은 명칭의 복잡성이 아니라 접근패턴·갱신비율·메모리·일관성 요구에 근거해야 함.
2. 방문 노드·지연·높이·최악 탐색시간·반복방문·메모리를 정기 측정하고 편차에 대한 원인분석·개선결과를 기록.

### Ⅶ. 결론

- 핵심 요약 : 선형 자료구조는 원소가 논리적 순서에 따라 앞·뒤 원소와 연결되는 구조.
- 시사점 : 선형 구조의 선택은 추상 연산의 의미와 접근·수정 빈도 및 캐시 특성의 균형.
