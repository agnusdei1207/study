## 연관 키워드
- 4NF, 5NF, 다치 종속, 조인 종속, 후보 키, 무손실 분해

### Ⅰ. 제4정규형·제5정규형의 개요

- 핵심 요약 : 제4정규형은 비자명 다치 종속의 결정자가 슈퍼 키일 것을 요구하고, 제5정규형은 모든 비자명 조인 종속이 후보 키에서 유도되는 경우를 다루는 정규형.
- 개념 : 제4정규형은 비자명 다치 종속의 결정자가 슈퍼 키일 것을 요구하고, 제5정규형은 모든 비자명 조인 종속이 후보 키에서 유도되는 경우를 다루는 정규형(**제4정규형**, Fourth Normal Form; **제5정규형**, Fifth Normal Form).
- 배경 및 필요성 : 다치 종속·복합 조인 관계가 표에 섞이면 중복과 갱신 이상 발생.
- 주요 목적 : 독립된 다중 값 사실과 조인 종속의 중복 제거.

### Ⅱ. 제4정규형·제5정규형의 특징 및 장점

- 핵심 요약 : 4NF·5NF·무손실성은 독립된 다중 값 사실과 조인 종속의 중복을 제거하는 고차 정규형.

1. 4NF : 독립 다중 값 속성의 다치 종속 분해 → 조합 중복 제거.
2. 5NF : 조인 종속 기준 릴레이션 분해 → 재 조인으로 원본 복원.
3. 무손실성 : 분해 후 자연 조인 결과가 원본과 같도록 확인 → 정보 보존.

### Ⅲ. 제4정규형·제5정규형의 구조 (흐름)

- 핵심 요약 : 함수·다치·조인 종속 도출 → 키 분석 → 4NF 위반 분해 → 잔여 조인 종속 검토 → 5NF·무손실성 확인.

```text
함수·다치·조인 종속 도출
  ↓
키 분석
  ↓
4NF 위반 분해
  ↓
잔여 조인 종속 검토
  ↓
5NF·무손실성 확인
```

```text
공급자-부품-프로젝트 관계
독립 다치 사실 → 4NF에서 쌍별 릴레이션 분해
복합 조인 종속 → 5NF 분해
자연 조인으로 원본 관계 복원 검증
```

### Ⅳ. 4NF와 5NF 비교

- 핵심 요약 : 분해 기준 기준 — 4NF: 결정자가 슈퍼 키인지 확인; 5NF: 후보 키로부터 종속이 유도되는지 확인.

| 비교 축 | 4NF | 5NF |
|---|---|---|
| 대상 종속 | 비자명 다치 종속 | 비자명 조인 종속 |
| 분해 기준 | 결정자가 슈퍼 키인지 확인 | 후보 키로부터 종속이 유도되는지 확인 |

### Ⅴ. 제4정규형·제5정규형의 한계와 방안

- 핵심 요약 : 종속성 오판·과도한 분해 등 실제 위험을 원인에 맞는 통제와 지표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 종속성 오판 | 업무 규칙을 모르고 분해하면 정보 손실·잘못된 조인 | 업무 제약·예시 데이터로 종속성 검증 | 무손실성 |
| 과도한 분해 | 조인 수 증가·질의 복잡성 | 정규형 달성 필요성과 조회 패턴을 함께 평가 | 조인 비용 |
| 희귀 종속 오해 | 5NF는 일반적인 모든 중복 제거 규칙이 아님 | 비자명 조인 종속의 존재를 증명 후 적용 | 이상 재현 |

### Ⅵ. 제4정규형·제5정규형에 대한 제언

- 핵심 요약 : 데이터 설계자는 4NF·5NF를 기계적으로 적용하기보다 독립 다치 사실과 조인 종속을 업무 규칙으로 입증하고 분해·재 구성 검증.

- 실행 제안 : 데이터 모델러는 다치·조인 종속 사례를 업무 규칙으로 입증하고 분해 전후 자연 조인 결과를 검증.

### Ⅶ. 결론

- 핵심 요약 : 4NF와 5NF는 각각 다치 종속과 조인 종속으로 생기는 특수한 중복을 다루는 고차 정규형.
- 시사점 : 4NF와 5NF는 특정 다치·조인 종속에 대한 정규형으로 업무 규칙이 입증된 경우에 적용.
