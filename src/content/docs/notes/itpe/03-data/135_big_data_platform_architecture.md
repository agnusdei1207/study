## 지식 로드맵 내 현재 위치

자료처리·데이터 → 빅데이터 → **빅데이터 플랫폼 아키텍처**

## 30초 인출

- 본질: 빅데이터 플랫폼 아키텍처는 대규모·다양한 데이터를 수집·저장·처리해 업무에 제공하는 데이터 시스템 구조
- 메커니즘: 수집 → 분산 저장 → 배치/스트림 처리 → 서빙의 계층을 두고 메타데이터·품질·권한·계보를 전 계층에 연결하며, 지연·재처리 요구에 따라 람다(배치+스트림 병행)나 카파(로그 재생 기반 단일 스트림)를 선택
- 통찰: 람다는 두 경로의 로직·결과 정합성이, 카파는 로그 보존·재처리 용량이 부담이므로 재계산·재처리를 시험해 선택하고, 레이크하우스는 저장 계층의 선택으로 처리 아키텍처를 대체하지 않음

<details>
<summary>핵심 용어</summary>

- **빅데이터 플랫폼** : 수집·저장·처리·서빙을 갖춘 대규모 데이터 처리 기반
- **람다 아키텍처** : 배치 경로와 스트림 경로를 병행해 결과를 조합
- **카파 아키텍처** : 보존 로그를 스트림 처리하고 재처리 시 로그를 재생
- **데이터 레이크하우스** : 레이크의 저장과 웨어하우스의 테이블 관리를 결합한 구조
- **테이블 포맷** : 트랜잭션·스키마 진화를 지원하는 저장 계층 형식
- **계보(Lineage)** : 데이터 이동·변환 이력

</details>

## 2~4교시 25점 답안

## Ⅰ. 빅데이터 플랫폼 아키텍처의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **빅데이터 플랫폼 아키텍처** 는 대규모·다양한 데이터를 수집·저장·처리해 업무에 제공하는 구조 |
| 목적 | 규모·속도·형식이 다른 데이터의 안정적 분석·활용 지원 |

## Ⅱ. 특징

| 특징 | 설계상 의미 |
|---|---|
| 다종 데이터 수용 | 배치·이벤트·변경 데이터의 형식·속도·순서 차이 처리 |
| 처리 경로 조합 | 지연·재처리 요구에 따라 배치와 스트림 경로 조합 |
| 전 계층 공통 통제 | 메타데이터·품질·권한·계보 연결 |

## Ⅲ. 계층 구조

```text
원천 → 수집 → 분산 저장 → 배치/스트림 처리 → 서빙·분석
   └──── 메타데이터·품질·권한·계보 관리 ────┘
```

| 계층 | 책임 | 고려사항 |
|---|---|---|
| 수집 | 배치·이벤트·변경 데이터 수용 | 중복·순서·재전송 |
| 저장 | 원천·정제·분석 데이터 보존 | 형식·파티션·보존기간 |
| 처리 | 변환·집계·모델 연산 | 지연·처리량·재처리 |
| 서빙 | 결과 제공 | 질의 성능·접근정책 |
| 공통 관리 | 메타데이터·품질·보안 | 계보·권한·감사 |

## Ⅳ. 람다·카파 비교

```text
Lambda: 입력 ┬→ 배치 경로 (과거 재계산) ┐
             └→ 스트림 경로 (최신 결과) ┴→ 서빙에서 조합
Kappa : 입력 → 보존 로그 → 스트림 처리 → 서빙   (재처리 시 로그 재생)
```

| 기준 | 람다 | 카파 |
|---|---|---|
| 처리 경로 | 배치·스트림 병행 | 스트림 중심 |
| 결과 결합 | 스트림 결과와 배치 결과 조합 | 로그 재처리로 재생성 |
| 장점 | 과거 재계산과 저지연 결과를 함께 지원 | 로직 경로 단순화 |
| 부담 | 두 경로의 로직·결과 정합성 | 로그 보존·재처리 용량·시간 |

| 개념 | 다루는 문제 | 관계 |
|---|---|---|
| 람다·카파 | 배치·스트림 처리 경로 | 처리 아키텍처 |
| 레이크하우스 | 저장·테이블 관리·분석 접근 | 저장·분석 계층, 람다·카파를 자동 대체하지 않음 |

테이블 포맷의 트랜잭션·스키마 진화 지원은 포맷·카탈로그·엔진·쓰기 방식의 조합에 따라 확인.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 람다의 두 경로에서 로직 중복·결과 불일치 | 공통 계산 정의와 결과 대조 기준, 재계산 시험 |
| 카파의 재처리 시간·로그 보존 부담 | 재생 구간·보존량·처리 용량 계산, 재처리 시험 |
| 계층별 품질·권한·계보 단절 | 식별자·정책을 연결해 이력 확인 |

## Ⅵ. 제언

지연과 재처리 요구로 처리 경로를 선택하고 재계산·재처리를 실제 부하에서 시험

```text
지연·재처리 요구 → 람다 / 카파 선택 → 저장 계층(레이크하우스 등) 결정 → 재처리 시험
```

| 구분 | 경로 선택 없이 구축 | 제언: 요구 기반 선택·시험 |
|---|---|---|
| 정합성 | 사후 발견 | 사전 시험 |
| 재처리 | 용량 미확인 | 계산·시험 |
