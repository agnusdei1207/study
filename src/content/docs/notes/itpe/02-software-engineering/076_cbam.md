## 30초 인출

- 본질: CBAM은 아키텍처 전략을 적용했을 때의 품질 향상 편익과 비용을 비교해 투자 대비 효과(ROI)로 전략을 선택하는 SEI의 분석 방법
- 메커니즘: ATAM에서 나온 시나리오의 우선순위와 효용을 정하고, 전략별 기대 품질 수준의 편익과 비용으로 ROI를 계산해 높은 순으로 선택
- 통찰: 절충점을 찾아도 모든 개선을 할 수 없으므로 전략별 효용과 비용을 같은 기준으로 계산해 ROI가 높은 전략부터 예산 안에서 선택

<details>
<summary>핵심 용어</summary>

- **CBAM(Cost Benefit Analysis Method)** : 아키텍처 전략의 비용과 편익을 비교해 투자 우선순위를 정하는 방법
- **ATAM** : 품질속성 시나리오로 아키텍처의 절충점과 위험을 찾는 평가 방법
- **아키텍처 전략** : 품질 시나리오의 요구를 달성하기 위한 구조 변경안
- **효용(Utility)** : 품질 응답 수준이 이해관계자에게 주는 가치를 수치로 나타낸 값
- **편익(Benefit)** : 전략 적용으로 얻는 효용 증가분에 시나리오 중요도를 반영한 값
- **ROI(Return on Investment)** : 편익을 비용으로 나눈 투자 대비 효과

</details>

## 2~4교시 25점 답안

## Ⅰ. CBAM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CBAM** 은 아키텍처 전략의 편익과 비용을 비교해 ROI로 전략을 선택하는 분석 방법 |
| 목적 | 제한된 예산 안에서 투자 효과가 큰 아키텍처 개선 선택 |

## Ⅱ. ATAM과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 경제성 분석 | 기술적 절충이 아닌 비용·편익 판단 |
| ATAM 후속 | ATAM의 시나리오와 전략을 입력으로 사용 |
| 정량 비교 | 효용·비용·ROI 수치로 전략 비교 |

## Ⅲ. CBAM 절차와 ROI 계산

### CBAM 절차

```text
시나리오 수집·정제·우선순위화
    ↓
시나리오별 품질 응답 수준의 효용 부여
    ↓
아키텍처 전략 도출과 기대 응답 수준 추정
    ↓
전략별 편익·비용 산정
    ↓
ROI 계산 → 예산·일정 제약 안에서 전략 선택
```

### 확대: ROI 계산

```text
편익 = Σ (시나리오 중요도 × 효용 증가분)
ROI = 편익 / 비용
```

## Ⅳ. 전략 비교 예

| 전략 | 편익(효용) | 비용 | ROI | 판단 |
|---|---|---|---|---|
| 캐시 도입 | 60 | 20 | 3.0 | 우선 선택 |
| 서비스 분리 | 80 | 60 | 1.3 | 예산 여유 시 |
| 전면 재설계 | 100 | 150 | 0.7 | 보류 |

| 비교 | ATAM | CBAM |
|---|---|---|
| 초점 | 품질속성 절충·위험 | 비용·편익·ROI |
| 결과 | 위험·민감점·절충점 | 전략 우선순위 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 효용·편익 추정의 주관성 | 이해관계자 합의와 근거 기록 |
| 비용 추정 오차 | 유사 사례와 전문가 검토 |
| 정량화 어려운 품질속성 | 대리 지표 설정 |

## Ⅵ. 제언

ATAM에서 도출한 절충점 중 우선순위 높은 시나리오에 대해 전략별 ROI를 계산하고, 예산 안에서 ROI 높은 순으로 선택

### 선택 절차

```text
ATAM 결과 (절충점·전략)
    ↓
우선순위 시나리오의 전략별 편익·비용 산정
    ↓
ROI 순위 → 예산 안에서 선택
```

### 확대: 선택 판단

```text
ROI 순위 상위 전략
    ├─ 예산 이내 → 채택
    └─ 예산 초과 → 다음 순위 또는 범위 축소
```

### 선택 근거: 기술적 판단만과의 비교

| 구분 | 기술적 판단만 | 제언: ROI 기반 |
|---|---|---|
| 기준 | 기술 우수성 | 편익 대비 비용 |
| 예산 반영 | 사후 | 사전 |
| 근거 | 설명 곤란 | 수치 근거 |
