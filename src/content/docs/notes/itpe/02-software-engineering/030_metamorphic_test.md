## Ⅰ. 메타모픽 테스트의 개요

- **개념** : 개별 입력값에 대한 기대 출력값(Test Oracle)을 사전에 정의하기 어려운 '테스트 오라클 문제(Test Oracle Problem)'를 해결하기 위해, 입력값 간의 변형 관계에 따라 도출되어야 하는 출력값 간의 불변적 관계인 '메타모픽 관계(Metamorphic Relation, MR)'를 기반으로 시스템의 결함을 검출하는 테스팅 기법.
- **배경 및 필요성** : AI/딥러닝 모델, 검색 엔진, 컴파일러, 복잡한 수치 시뮬레이션 등은 특정 입력에 대한 완벽한 정답을 인간이 미리 알 수 없으므로, 전통적인 입출력 매칭 테스트의 한계를 극복하기 위해 필수적.
- **핵심 원리** : 소스 테스트 케이스($x$)와 후속 테스트 케이스($x'$) 사이의 입력 변형 규칙과, 그에 따른 출력 $f(x)$와 $f(x')$ 사이의 메타모픽 관계식 검증.

## Ⅱ. 메타모픽 테스트의 실행 프로세스 및 검증 구조

```text
   [ 소스 입력 (x) ] ────────── 시스템 실행 f(x) ──────────> [ 소스 출력 f(x) ]
          │                                                         │
          │ (입력 변형 규칙 적용)                                    │ (메타모픽 관계 검증)
          ▼                                                         ▼
   [ 후속 입력 (x') ] ───────── 시스템 실행 f(x') ─────────> [ 후속 출력 f(x') ]
                                                              f(x) 와 f(x') 간
                                                              불변 관계 불일치 시 Bug!
```

- **메타모픽 관계(MR)의 구체적 예시** :
  - **최단 경로 알고리즘** : 노드 A에서 B까지의 최단거리 $f(A, B)$는, 그래프 내 모든 간선 가중치에 상수 $C$를 더했을 때 노드 수가 동일하면 동일한 경로를 유지해야 함.
  - **자율주행 영상인식** : 원본 주간 도로 영상 $x$에 대해 비/안개 필터(변형 규칙)를 적용한 $x'$에서도 인식된 보행자 위치가 일치해야 함.
  - **검색 엔진** : 검색어 '머신러닝'의 결과 집합은 '머신러닝 AND 인공지능'의 결과 집합을 반드시 포함해야 함 ($f(A) \supseteq f(A \land B)$).

## Ⅲ. 전통적 테스트와 메타모픽 테스트의 비교

| 비교 항목 | 전통적 테스트 기법 | 메타모픽 테스트 (MT) |
|---|---|---|
| 정답 판별 기준 | 테스트 오라클 (사전 정의된 기대값 $y$) | 메타모픽 관계 (출력 간의 일관성 관계 $MR$) |
| 오라클 의존성 | 오라클 부재 시 테스트 수행 불가 | 오라클이 없는 환경에서도 무한 자동 테스트 가능 |
| 테스트 케이스 도출 | 경계값 분석, 동등 분할 등 입력 중심 | 소스 입력 + 도메인 지식 기반 변형 함수 |
| 결함 탐지 방식 | $f(x) == y$ 여부 비교 | $MR(f(x), f(x'))$ 만족 여부 검증 |
| 주 활용 분야 | 은행 계좌 입출금, CRUD 등 정형 업무 | AI/LLM, 그래픽 렌더링, 바이오인포매틱스, 과학 연산 |

## Ⅳ. AI 시스템 테스팅 관점에서의 기술사적 제언

- **도메인 특화 메타모픽 관계(MR)의 체계적 정형화** : 메타모픽 테스트의 성패는 올바른 MR 발굴에 달려 있으므로, 도메인 전문가와 협업하여 대칭성(Symmetry), 불변성(Invariance), 가법성(Additivity), 단조성(Monotonicity) 등 다각적 속성 정의 필요.
- **퍼징(Fuzzing) 도구와의 결합을 통한 테스트 자동화 파이프라인 구축** : 다양한 변이(Mutation) 엔진을 결합하여 자동으로 수만 개의 후속 입력을 생성하고 MR 위반 여부를 지속 모니터링하는 MLOps 품질 게이트웨이 구축 권장.
