## 연관 키워드

- 카오스 엔지니어링(Chaos Engineering), 장애 주입(Fault Injection)
- 정상 상태(Steady State), 가설, 폭발 반경(Blast Radius), 중단 조건(Abort Condition), 재해 복구 시험

## Ⅰ. 카오스 테스트의 개요

- 핵심 요약 : 카오스 테스트는 통제된 장애 주입으로 분산 시스템의 복원력 가정을 검증하는 실험 규율.
- 개념 : 실제와 유사한 환경에 계획된 장애를 주입해 시스템의 견딤 능력, 즉 복원력에 대한 가정을 검증하는 실험 규율이 **카오스 엔지니어링** (Chaos Engineering), 이를 시험 형태로 수행하는 활동이 카오스 테스트.
- 배경 및 필요성 : 분산 서비스는 네트워크 단절·지연, 프로세스 종료, 자원 고갈의 완전한 사전 차단이 불가능한 상태이므로 복구·전파 제어 동작의 실증 필요.
- 주요 목적 : 고객 영향 이전의 결함 발견과 복원력 설계·운영에 대한 근거 확보.

## Ⅱ. 카오스 테스트의 특징 및 장점

- 핵심 요약 : 정상 상태 기준과 가설, 영향 범위 통제, 안전 장치가 실험의 신뢰성과 안전성을 함께 확보.

1. 정상 상태 기준 : 오류율·지연 같은 측정 가능한 **정상 상태** (Steady State) 지표의 기준선 확보 → 가설 판정의 객관성 효과.
2. 가설 기반 수행 : 장애 조건과 기대 동작을 **가설**로 사전 명문화 → 재현 가능한 검증과 학습 효과.
3. 폭발 반경 통제 : 실험 영향 범위인 **폭발 반경** (Blast Radius)의 최소화와 단계적 확대 → 사용자 피해 상한 관리 효과.
4. 안전 장치 우선 : 임계치 초과 시 실험을 멈추는 **중단 조건** (Abort Condition)의 사전 검증 → 실험 자체 사고의 방지 효과.

## Ⅲ. 카오스 테스트의 구조 (흐름)

- 핵심 요약 : 기준선 확보 → 가설·범위 정의 → 안전 장치 → 장애 주입 → 관측·판정 → 개선의 반복 절차.

```text
정상 상태 지표·기준선 확보
   ↓ 장애 가설·대상·범위 정의
중단 조건·복구 절차의 검증
   ↓ 통제된 장애 주입
영향 관측·정상 상태 판정
   ↓ 결함 개선 후 재실험
실험 기록·지식 축적
```

```text
1단계 : 테스트 환경의 단일 구성 요소
   ↓ 안정적 종료·복구 확인
2단계 : 스테이징 전체 토폴로지
   ↓ 가설 판정·기록
3단계 : 운영 환경의 소규모 트래픽
   ↓ 중단 조건의 상시 감시
4단계 : 운영 환경의 범위 확대
```

- 장애 주입 유형은 인스턴스 종료, 지연·패킷 손실, 의존 서비스 실패, CPU·메모리 압박 등 목표 가설에 맞춘 선택.

## Ⅳ. 카오스 테스트와 재해 복구 시험의 비교

- 핵심 요약 : 카오스 테스트는 미지의 복원력 결함을 찾는 실험이고 재해 복구 시험은 계획된 장애 대응 절차의 이행 검증.

| 비교 축 | 카오스 테스트 | 재해 복구 시험 |
| --- | --- | --- |
| 핵심 질문 | 예상 못한 장애에서의 견딤 여부 | 계획된 대응 절차의 이행 여부 |
| 자극 | 가설 기반의 통제 장애 주입 | 재해 시나리오의 모사 |
| 판정 기준 | 정상 상태 유지·가설의 참·거짓 | 복구 목표 시간·시점의 달성 |
| 수행 주기 | 상시·반복 실험 | 계획된 주기의 훈련·점검 |
| 발견 지향 | 미지 결함·숨은 의존성 | 절차 결함·인력 숙련도 |

- 재해 복구 시험의 판정에는 복구 목표 시간인 **RTO** (Recovery Time Objective)와 복구 목표 시점인 **RPO** (Recovery Point Objective)가 기준 지표.

## Ⅴ. 카오스 테스트의 한계와 방안

- 핵심 요약 : 실험 자체의 피해, 기준선 부실, 환경 불일치, 미조치를 승인·격리·연계 절차로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 실험 자체의 서비스 피해 | 폭발 반경·중단 조건 설계 미흡 → 고객 장애 전환 | 표적 제한·자동 중단·점진 확대 | 실험 중단 건수 |
| 가설·기준선 부실 | 정상 상태 정의 부재 → 판정의 주관화 | 서비스 수준 지표 기반 기준선 확정 | 기준선 결손 지표 수 |
| 환경 불일치 과신 | 스테이징과 운영의 구조 차이 → 오판 | 제한적 운영 실험의 병행 | 환경 차이 항목 수 |
| 발견 후 미조치 | 개선 소유자·기한 부재 → 결함 재발 | 소유자 지정·재실험 연계 | 미조치 항목 수 |

## Ⅵ. 복원력 검증에 대한 기술사적 제언

- 핵심 요약 : 신뢰성 운영 조직은 실험 거버넌스와 무처벌 원칙으로 카오스 실습의 상시 역량화가 필요.
1. **SRE** (Site Reliability Engineering) 조직은 실험 승인·변경 관리·온콜 절차와 연계한 실험 규정과 집단 훈련인 GameDay의 주기 운영.
2. 경영 조직은 실험 발견을 개인 평가가 아닌 시스템 개선 학습 자료로 관리하는 무처벌 원칙의 채택.

## Ⅶ. 결론

- 핵심 요약 : 카오스 테스트는 장애의 부재 보장이 아니라 복원력 가정의 실증 절차.
- 시사점 : 안전한 범위의 반복 실험과 조치 연계가 운영 신뢰성의 근거.
