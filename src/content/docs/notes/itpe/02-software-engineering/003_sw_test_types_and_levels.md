## Ⅰ. 소프트웨어 테스트 종류 및 레벨의 개요

- **개념** : 소프트웨어의 결함을 조기에 발견하고 요구사항 충족 여부와 비기능 품질 기준을 체계적으로 검증하기 위해 개발 생명주기 단계에 매핑하여 계층화한 테스트 체계.
- **배경 및 필요성** : 개발 후반부에 결함 발견 시 기하급수적으로 증가하는 결함 수정 비용(Boehm의 법칙) 억제, 기능적 정확성과 비기능 품질속성(신뢰성, 이식성 등)의 균형 검증.
- **표준 근거** : ISO/IEC/IEEE 29119(소프트웨어 테스팅 표준), ISO/IEC 25010(시스템 및 소프트웨어 품질 모델).

## Ⅱ. V-모델 기반 테스트 레벨 체계도

```text
   [ 요구사항 정의 ] ─────────────────────────> [ 인수 테스트 ] (Acceptance)
          │                                           ▲
          ▼                                           │
   [ 시스템 설계 ] ────────────────────────> [ 시스템 테스트 ] (기능/비기능)
          │                                           ▲
          ▼                                           │
   [ 상세 설계 ] ────────────────────────> [ 통합 테스트 ] (Big-Bang/점진적)
          │                                           ▲
          ▼                                           │
   [ 모듈 코딩 ] ─────────────────────────> [ 단위 테스트 ] (화이트/블랙박스)
```

- **단위 테스트(Unit Test)** : 개별 모듈/함수 수준의 기능 정확성 검증 (JUnit, Mock 객체 활용).
- **통합 테스트(Integration Test)** : 모듈 간 인터페이스, 데이터 교환, API 연동 검증 (상향식 스텁/하향식 드라이버).
- **시스템 테스트(System Test)** : 완전한 통합 시스템 환경에서 전체 요구사항 충족 검증 (기능 테스트 및 성능/보안 테스트).
- **인수 테스트(Acceptance Test)** : 발주자 및 최종 사용자가 비즈니스 요구사항 일치 여부를 판단하는 최종 검증 (알파/베타 테스트).

## Ⅲ. 테스트 종류별 검증 관점 및 핵심 테스트 분석

| 테스트 종류 | 핵심 검증 대상 | 주요 기법 및 도구 |
|---|---|---|
| 기능 테스트 | 명세된 업무 기능 및 비즈니스 로직 충족 여부 | 동등 분할, 경계값 분석, 유스케이스 기반 테스팅 |
| 신뢰성 테스트 | 장시간 구동 시 장애 발생률, 고장 간격, 복구 능력 | 결함 주입(Fault Injection), 스트레스/침수 테스트, MTBF/MTTR 측정 |
| 이식성 테스트 | 이기종 OS, 브라우저, DB, 클라우드 환경 적응력 | 다중 플랫폼 매트릭스 테스팅, 컨테이너 환경 호환성 검증 |
| 성능 테스트 | 임계 부하 상황에서의 처리량, 응답시간, 자원 소진율 | 부하(Load), 스트레스(Stress), 스파이크(Spike) 테스트 (JMeter, nGrinder) |
| 보안성 테스트 | 취약점 존재 여부 및 인가되지 않은 접근 차단 | 모의해킹(Pen-Testing), 소스코드 보안약점 진단, DAST |

## Ⅳ. 고품질 테스트 환경 구축을 위한 기술사적 제언

- **테스트 자동화 피라미드 준수** : 비용이 높고 취약한 UI 엔드투엔드 테스트에 의존하기보다, 단위 테스트와 API 통합 테스트 계층을 두텁게 구성하여 피드백 주기 최소화.
- **환경 일치성(Parity) 및 가상화 기법 도입** : 개발, 테스트, 운영 환경 간 불일치로 인한 오작동을 차단하기 위해 Docker/Kubernetes 기반의 프로덕션 동형 테스트 환경 및 서비스 가상화(Service Virtualization) 도입 권장.
