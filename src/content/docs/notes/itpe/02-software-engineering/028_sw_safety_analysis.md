## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 안전·신뢰성 → **SW 안전성 분석(FTA·FMEA·HAZOP)**

## 30초 인출

- 본질: SW 안전성 분석은 소프트웨어 오작동이 사고로 이어지는 경로를 미리 찾아 위험을 낮추는 분석 기법 모음이며 FTA·FMEA·HAZOP이 대표
- 메커니즘: FMEA는 부품·모듈의 고장 모드에서 영향으로(상향), FTA는 최상위 사고에서 원인 조합으로(하향), HAZOP은 공정 변수의 이탈을 가이드워드로 점검
- 통찰: FMEA는 개별 고장만 다루고 여러 결함이 겹친 사고 경로는 보지 못하므로 FMEA로 고장 모드를 뽑고 FTA로 최상위 사고에 이르는 결함 조합을 확인

<details>
<summary>핵심 용어</summary>

- **FTA(Fault Tree Analysis)** : 최상위 사고(Top Event)에서 시작해 AND·OR 게이트로 원인 조합을 찾아가는 하향식 분석
- **FMEA(Failure Mode and Effects Analysis)** : 구성요소별 고장 모드와 그 영향을 분석하는 상향식 분석
- **HAZOP(Hazard and Operability Study)** : 설계 의도 대비 변수의 이탈을 가이드워드로 점검해 위험을 찾는 기법
- **최소 컷셋(Minimal Cut Set)** : 최상위 사고를 일으키는 최소한의 기본 사건 조합
- **RPN(Risk Priority Number)** : 심각도·발생도·검출도의 곱으로 고장의 우선순위를 정하는 값
- **가이드워드(Guide Word)** : No·More·Less·Reverse처럼 설계 의도에서의 이탈 유형을 나타내는 단어

</details>

## 2~4교시 25점 답안

## Ⅰ. SW 안전성 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SW 안전성 분석** 은 소프트웨어 오작동이 사고로 이어지는 경로를 찾아 위험을 평가하는 분석 기법 |
| 목적 | 사고를 유발하는 결함의 사전 식별과 안전 요구사항 도출 |

## Ⅱ. 안전성 분석의 특징

| 특징 | 의미 |
|---|---|
| 사전 분석 | 설계 단계에서 위험 식별 |
| 원인·영향 추적 | 결함과 사고의 인과 경로 분석 |
| 기법별 방향 | 상향식·하향식·이탈 점검으로 관점 분담 |

## Ⅲ. FTA와 FMEA의 분석 구조

### 안전성 분석 기법의 방향

```text
FTA (하향): 최상위 사고 → 중간 사건 → 기본 사건(원인 조합)
FMEA (상향): 구성요소 고장 모드 → 상위 영향 → 시스템 영향
HAZOP (이탈): 설계 의도 → 가이드워드 적용 → 이탈 → 원인·결과
```

### 확대: FTA의 원인 조합

```text
최상위 사고: 과열 제어 실패
    │
   [OR]
    ├─ 센서 오류
    └─ [AND] 제어 로직 결함 + 경보 미작동
```

## Ⅳ. FTA·FMEA·HAZOP의 비교

| 구분 | FTA | FMEA | HAZOP |
|---|---|---|---|
| 방향 | 하향(사고→원인) | 상향(고장→영향) | 변수 이탈 점검 |
| 대상 | 특정 최상위 사고 | 구성요소별 고장 모드 | 공정·인터페이스의 변수 |
| 산출물 | 최소 컷셋 | RPN(심각도×발생도×검출도) | 이탈별 원인·결과·대책 |
| 강점 | 결함 조합 표현 | 개별 고장의 누락 방지 | 설계 의도 이탈의 체계적 발견 |
| 약점 | 사고 정의에 의존 | 결함 조합 미표현 | 팀 경험에 의존 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| FMEA만으로는 여러 결함이 겹친 사고 경로 미확인 | FMEA의 고장 모드를 FTA의 기본 사건으로 연결 |
| 분석 결과의 안전 요구사항 미반영 | 위험 항목별 안전 요구사항과 시험 항목 도출 |
| 분석 인력 경험에 따른 편차 | 가이드워드·체크리스트 표준화와 다분야 검토 |

## Ⅵ. 제언

FMEA로 고장 모드를 도출하고, 심각도가 큰 항목은 FTA로 결함 조합을 분석해 안전 요구사항과 시험 항목에 반영

### 분석 결합 순서

```text
FMEA: 고장 모드·RPN 산정
    ↓
심각도 큰 항목 선별
    ↓
FTA: 최상위 사고까지의 결함 조합·최소 컷셋 도출
    ↓
안전 요구사항·시험 항목 반영
```

### 선택 근거: 단일 기법과의 비교

| 구분 | FMEA 단독 | 제언: FMEA→FTA 결합 |
|---|---|---|
| 결함 조합 | 미확인 | 최소 컷셋으로 확인 |
| 분석 범위 | 전 구성요소 | 위험 큰 항목 중점 |
| 요구 반영 | 개별 고장 대책 | 조합 경로 차단 대책 |
