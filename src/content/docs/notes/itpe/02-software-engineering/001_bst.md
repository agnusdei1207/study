## 연관 키워드
- BST(Binary Search Tree), 탐색·삽입·삭제, inorder, 균형 트리, 높이

## Ⅰ. 이진 탐색 트리의 개요
- 핵심 요약 : 각 노드의 왼쪽 키는 작고 오른쪽 키는 큰 순서 성질로 검색 공간을 줄이는 이진 트리.
- 개념 : 노드 키가 비교 기준에 따라 왼쪽 하위 트리보다 크고 오른쪽 하위 트리보다 작도록 구성하는 자료구조.
- 필요성 : 정렬 배열의 빠른 검색과 연결 리스트의 동적 갱신 특성 사이 절충이 필요.
- 목적 : 키 기반 탐색·삽입·삭제와 정렬 순회 제공.

## Ⅱ. BST의 특징 및 장점
- 핵심 요약 : 평균 연산은 트리 높이에 비례하며, 균형이 무너지면 선형 탐색 수준으로 퇴화.
1. 순서 성질 : 왼쪽 < 노드 < 오른쪽 → 비교마다 후보 범위 축소.
2. 중위 순회 : inorder가 오름차순 키를 산출 → 정렬 결과와 범위 검색에 활용.
3. 동적 갱신 : 노드 삽입·삭제로 크기 조정 → 고정 배열 이동 부담 감소.

## Ⅲ. BST 연산 구조와 흐름
- 핵심 요약 : 루트에서 비교를 반복해 위치를 찾고, 삭제는 자식 수에 따라 연결을 재조정.
```text
탐색·삽입: 루트 → 비교 → 작으면 왼쪽/크면 오른쪽 → 일치 노드 또는 null
삭제: 리프 제거 | 자식 1개면 자식 연결 | 자식 2개면 후계자/선행자로 대체
```
```text
       8
      / \
     3  10
    / \   \
   1   6   14
inorder: 1, 3, 6, 8, 10, 14
```
- 복잡도 : 높이 h 기준 탐색·삽입·삭제 O(h); 균형이면 O(log n), 편향이면 O(n).

## Ⅳ. BST와 균형 트리·정렬 배열 비교
- 핵심 요약 : 성능 상한이 필요하면 균형 트리, 읽기 위주면 배열, 단순 동적 검색이면 BST가 적합.
| 기준 | 일반 BST | AVL/Red-Black | 정렬 배열 |
|---|---|---|---|
| 검색 | 평균 O(log n), 최악 O(n) | O(log n) 보장 | O(log n) |
| 갱신 | 포인터 재연결 | 회전·재색칠 필요 | 삽입·삭제 O(n) 이동 |
| 적합 상황 | 편향 위험이 낮고 단순성 중시 | 동적 갱신과 최악 시간 보장 | 읽기 위주·인덱스 접근 |

## Ⅴ. BST의 한계와 방안
- 핵심 요약 : 입력 순서 편향과 중복 키 정책 부재가 성능·정합성을 흔들므로 균형화와 비교 규칙을 명시.
| 한계 | 영향 | 대응 |
|---|---|---|
| 정렬된 입력 | 높이 O(n), 연산 O(n) | AVL·Red-Black 또는 무작위화 |
| 중복 키 | 검색·삭제 위치 모호 | 카운터 저장 등 규칙 고정 |
| 포인터 지역성 | 캐시 효율 저하 | 대량 디스크 인덱스는 B-Tree 계열 검토 |

## Ⅵ. BST 설계 제언
- 핵심 요약 : 자료량·갱신률·최악시간 요구를 기준으로 트리 변형과 중복 정책을 선택.
1. 설계자는 키 비교자, 중복 규칙, null 경계 조건을 명세.
2. 개발자는 정렬·역정렬·중복 입력과 삭제 유형별 시험 수행.
3. 최악 성능 보장이 필요하면 균형 트리나 저장소 인덱스로 전환.

## Ⅶ. 결론
- 핵심 요약 : BST는 순서 성질을 활용한 동적 검색 구조이며 실제 효율은 높이 관리에 달림.
- 시사점 : 평균 복잡도뿐 아니라 입력 분포와 균형 보장 여부를 함께 설계.
