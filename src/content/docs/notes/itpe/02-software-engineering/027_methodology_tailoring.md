## 연관 키워드
- 방법론 테일러링, 생명주기 모형, ISO/IEC/IEEE 12207, CMMI
- 테일러링 기록부(Tailoring Record), 위험 기반 선택, 획일 적용

## Ⅰ. 방법론 테일러링의 개요

- 핵심 요약 : 테일러링은 조직 표준 생명주기 모형과 프로세스를 사업 특성에 맞게 선택·조정하는 통제된 맞춤 활동.
- 개념 : **방법론 테일러링**(Methodology Tailoring)은 조직 표준 **생명주기 모형**(Life Cycle Model)과 프로세스를 사업 규모·위험·규제에 맞춰 적용·생략·보강하는 활동.
- 배경 및 필요성 : 특성이 상이한 프로젝트에 동일한 산출물·승인 절차를 적용하면 과잉 문서 비용 또는 통제 공백이 발생하는 문제.
- 주요 목적 : 품질·추적성·규제 준수를 유지하는 가운데 개발 효율과 현장 적합성 동시 확보.

## Ⅱ. 방법론 테일러링의 특징 및 장점

- 핵심 요약 : 표준 목적 보존·위험 비례 통제·근거 기록이 맞춤 적용의 신뢰성을 구성.

1. 표준 기반 조정 : **ISO/IEC/IEEE 12207**(소프트웨어 생명주기 프로세스 국제 표준)의 프로세스 목적·성과 기준 참조 → 활동·산출물 수준만 조정하고 품질 기준 보존.
2. 맥락 적합성 : 규모·중요도·규제·팀 역량 분석 반영 → 과잉 통제와 공백 통제 동시 축소.
3. 위험 기반 선택 : **위험 기반 선택**(Risk-Based Selection, 위험도에 따른 통제 강도 결정)으로 검증·승인 배치 → 제한된 품질 자원의 효율 배분.
4. 정당화·추적 : 조정 내용·근거·승인자를 **테일러링 기록부**(Tailoring Record)에 기록 → 감사 대응·조직 차원의 재사용.
5. 성숙도 연계 : **CMMI**(Capability Maturity Model Integration)의 프로세스 자산 관리 관행과 결합 → 조직 표준의 지속 개선.

## Ⅲ. 방법론 테일러링의 구조 (흐름)

- 핵심 요약 : 특성 분석부터 조직 자산 환류까지의 순환 절차와 위험에 따른 조정 방향의 결합.

```text
테일러링 절차

프로젝트 특성 분석 (규모·위험·규제·역량)
   ↓
표준 프로세스·생명주기 모형 선택
   ↓
활동·산출물·통제 조정
   ↓
테일러링 기록부 작성 → 승인
   ↓
적용·점검 → 조직 자산 환류
```

```text
위험 기반 조정 방향

위험·규제 강도가 높은 사업
   → 독립 검증·추적성·승인 강화
요구 변동·불확실성이 큰 사업
   → 짧은 반복·시제품 검증 확대
```

- 산출물 : 조정 항목 목록, 테일러링 기록부, 산출물·책임 매트릭스, 승인 기록.

## Ⅳ. 방법론 테일러링과 획일 적용의 비교

- 핵심 요약 : 테일러링은 근거·승인을 갖춘 선택적 조정, 획일 적용은 방법론 원형의 무차별 복제로 비용 또는 공백을 낳는 관행.
- 비교 개요 : 획일 적용은 테일러링 없이 표준 방법론의 원형을 모든 프로젝트에 그대로 적용하는 방식.

| 비교 축 | 방법론 테일러링 | 획일 적용 |
|---|---|---|
| 적용 방식 | 프로젝트 특성 기반 선택·조정 | 표준 원형 전체 복제 |
| 산출물 | 목적·수신자가 명확한 구성 | 전 산출물 일괄 요구 |
| 통제 수준 | 위험 비례 배분 | 과잉 문서 또는 통제 공백 |
| 근거 관리 | 테일러링 기록부·승인 | 조정 근거 부재 |
| 결과 | 효율·적합성·감사 대응력 | 비용 낭비·현장 부적합 |

## Ⅴ. 방법론 테일러링의 한계와 방안

- 핵심 요약 : 편의적 생략·형식적 문서·기록 부재·초기 고정을 필수 통제와 재검토 절차로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 편의적 생략 | 편의 우선 생략 → 품질·보안 통제 공백 | 생략 불가 필수 통제 목록·독립 승인 | 필수 통제 생략 건수 |
| 형식적 문서 잔존 | 관행적 산출물 복제 → 문서 비용 낭비 | 산출물 목적·수신자 연계 검토 | 불필요 산출물 수 |
| 근거 기록 부재 | 조정 이유 미기록 → 감사·재사용 불가 | 표준 양식·승인 절차 의무화 | 기록 작성률 |
| 초기 테일러링 고정 | 환경 변화 미반영 → 적합성 저하 | 단계 관문마다 재검토 | 재검토 수행률 |

## Ⅵ. 방법론 테일러링에 대한 제언

- 핵심 요약 : 표준 자산 제공·승인 절차·환류 체계의 거버넌스로 테일러링을 조직 역량으로 내재화.

1. PMO(Project Management Office)와 품질 조직은 표준 프로세스 자산·필수 통제·허용 조정 범위를 담은 테일러링 가이드라인 제공.
2. 프로젝트 관리자는 테일러링 기록부를 품질 계획과 함께 발주자·보안 담당자의 승인 대상으로 편성.
3. 조직은 완료 사업의 조정 실적·감사 결과를 분석해 프로세스 자산 라이브러리를 갱신하는 환류 체계 운영.

## Ⅶ. 결론

- 핵심 요약 : 테일러링은 표준의 예외 운영이 아니라 표준 목적을 프로젝트 맥락에 구현하는 통제된 맞춤 설계.
- 근거·승인·환류를 갖춘 테일러링에서 효율과 통제의 동시 달성 가능.
