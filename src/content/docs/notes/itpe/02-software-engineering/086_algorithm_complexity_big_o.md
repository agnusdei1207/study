## 연관 키워드
- 알고리즘 복잡도, 점근 표기법, Big O, Big Theta, Big Omega, 시간 복잡도, 공간 복잡도

### Ⅰ. 알고리즘 복잡도의 개요

- 핵심 요약 : 알고리즘 복잡도는 입력 크기 증가에 따라 실행 시간·메모리 등 자원 사용량이 어떻게 변하는지 점근적으로 표현하는 분석.
- 개념 : 입력 크기 증가에 따라 실행 시간·메모리 등 자원 사용량이 어떻게 변하는지 점근적으로 표현하는 분석(**알고리즘 복잡도**, Algorithmic Complexity).
- 배경 및 필요성 : 작은 시험 입력에서 빠른 구현이 대규모 데이터에서는 처리 시간·메모리 한계를 넘길 수 있음.
- 주요 목적 : 입력 규모가 커져도 요구 성능·비용을 충족할 알고리즘과 자료 구조를 합리적으로 선택.

### Ⅱ. 알고리즘 복잡도의 특징 및 장점

- 핵심 요약 : 입력 크기 기준·Big O·Big Theta·점근 비교.

1. 입력 크기 기준 : 핵심 연산 횟수·메모리 점유를 n의 함수로 표현 → 데이터 규모 변화 예측.
2. Big O : 상한 차수의 증가율 표현 → 최악 또는 보수적 성장 한계 비교.
3. Big Theta : 점근적 타이트 경계, Big Omega : 하한 표현 → 증가율의 상·하한 구분.
4. 점근 비교 : 상수·낮은 차수 항보다 지배 항 중심 → 대규모 입력에서 구조적 성능 차이 판단.

### Ⅲ. 알고리즘 복잡도의 구조 (흐름)

- 핵심 요약 : 입력 크기 n 정의 → 기본 연산·메모리 모델 설정 → 반복·재귀 식 도출 → 점근 상·하한 분석 → 자료 구조·알고리즘 비교 → 실제 부하 측정으로 검증.

```text
입력 크기 n 정의
   ↓
기본 연산·메모리 모델 설정
   ↓
반복·재귀 식 도출
   ↓
점근 상·하한 분석
   ↓
자료 구조·알고리즘 비교
   ↓
실제 부하 측정으로 검증
```

```text
증가율 비교 (n 증가)
O(1) → 상수
O(log n) → 로그
O(n) → 선형
O(n log n) → 선형로그
O(n²) → 이차
```

### Ⅳ. 알고리즘 복잡도 등급 비교

- 핵심 요약 : O(1)는 입력 크기와 무관한 상수 횟수, O(log n)는 문제 크기를 반복적으로 축소.

| 비교 방법 | 주요 특성 | 적합한 적용 조건 |
|---|---|---|
| O(1) | 입력 크기와 무관한 상수 횟수 | 해시 조회의 평균 사례 등 |
| O(log n) | 문제 크기를 반복적으로 축소 | 정렬 자료 이진 탐색 |
| O(n) | 입력을 한 번 비례 탐색 | 순차 검색 |
| O(n log n) | 분할·정복과 선형 병합 조합 | 효율 정렬의 대표 증가율 |
| O(n²) | 모든 원소 쌍 등 중첩 처리 | 작은 입력·단순 기준 구현 |

### Ⅴ. 알고리즘 복잡도의 한계와 방안

- 핵심 요약 : 복잡도만으로 성능 단정·잘못된 입력 크기·기본 연산 선택·최악·평균 사례 혼동을 벤치마크·실측 비교로 보완.

| 위험 | 원인·영향 | 대응 통제 | 지표 예시 |
|---|---|---|---|
| 복잡도만으로 성능 단정 | 상수·메모리·입력 분포·I/O 영향 미반영 | 대표 데이터·환경에서 벤치마크·프로파일링 | 실측 지연·메모리 |
| 잘못된 입력 크기·기본 연산 선택 | 병목을 설명하지 못하는 분석 | 지배 연산·자료 구조와 입력 차원 명시 | 모델-실측 차이 |
| 최악·평균 사례 혼동 | 위험 기반 성능 요건을 과소평가 | 경계·최악 입력과 분포 가정을 별도 기록 | 최악 지연, tail latency |

### Ⅵ. 알고리즘 복잡도 적용에 대한 기술사적 제언

- 핵심 요약 : 복잡도 표기를 성능 보증 치처럼 단정하지 말고 입력 크기·최악/평균 가정·메모리·외부 I/O를 설명.

- 실행 제언 : 설계자는 복잡도 표기를 성능 보증 치처럼 단정하지 말고 입력 크기·최악/평균 가정·메모리·외부 I/O를 설명하며, 위험 요건은 실제 규모의 성능 시험으로 확인.

### Ⅶ. 결론

- 핵심 요약 : 알고리즘 복잡도는 입력 크기 증가에 따라 실행 시간·메모리 등 자원 사용량이 어떻게 변하는지 점근적으로 표현하는 분석.
- 시사점 : 점근 복잡도는 알고리즘의 규모 확장성을 비교하는 추상 도구로, 실제 시스템 성능은 자료 구조·상수·입력 특성·구현 환경을 함께 고려해야 판단 가능.
