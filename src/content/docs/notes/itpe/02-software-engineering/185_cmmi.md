## 연관 키워드

- CMMI, 프로세스 개선, 성숙도 수준, 능력 수준, 프로세스 영역, 평가

## Ⅰ. CMMI의 개요

- 핵심 요약 : CMMI는 조직의 프로세스 역량과 성과를 평가·개선하기 위한 모델 및 평가 체계.
- 개념 : **CMMI**(Capability Maturity Model Integration)는 개발·서비스·공급망 등 조직 프로세스의 성숙도와 능력 향상을 안내하는 모델 제품군.
- 배경 및 필요성 : 프로젝트별 임기응변으로 발생하는 품질·일정 편차를 조직 차원의 관리·개선 체계로 줄일 필요.
- 주요 목적 : 반복 가능한 프로세스와 측정·개선 역량을 갖춰 예측 가능성과 성과 개선.

## Ⅱ. 구성과 특성

- 핵심 요약 : 모델 영역별 모범 실천과 평가 기준을 조직의 목표·사업 맥락에 맞게 적용.
- 실천 영역 : 요구·계획·측정·품질보증 등 성과 개선 주제를 묶음 → 개선 범위 명료화.
- 성숙도 관점 : 조직 차원의 프로세스 발전 단계 평가 → 단계적 개선 로드맵 지원.
- 능력 관점 : 개별 실천 영역의 수행 역량 평가 → 선택 영역의 강약점 진단.
- 모델·평가 방식은 버전과 적용 범위에 따라 달라지므로 공식 모델 문서의 정의를 확인.

## Ⅲ. 개선·평가 흐름

- 핵심 요약 : 조직 목표와 갭을 진단해 개선을 실행하고 객관적 증거로 효과를 재평가.

```text
사업 목표·성과 문제 정의
  ↓ 모델 영역·평가 범위 선정
현행 프로세스 증거 수집
  ↓ 갭·우선순위 분석
개선 계획·실행·교육
  ↓ 평가·성과 추적·조정
```

```text
요구·계획·수행 증거
  ↓ 실천 영역별 평가
강점·약점·리스크
  ↓ 개선 백로그
재평가·성과 확인
```

- 평가는 문서의 존재만 보는 방식이 아니라 실제 수행과 성과를 뒷받침하는 증거를 함께 검토.

## Ⅳ. 성숙도와 능력 비교

- 핵심 요약 : 성숙도는 조직의 프로세스 체계 발전을, 능력은 특정 영역의 수행 역량을 관찰하는 관점.

| 비교 축 | 성숙도 수준 | 능력 수준 |
| --- | --- | --- |
| 범위 | 조직 단위 프로세스 체계 | 개별 프로세스 영역·실천 |
| 초점 | 조직이 프로세스를 제도화한 정도 | 해당 영역의 수행·관리 역량 |
| 활용 | 조직 개선 여정·평가 결과 | 선택 영역의 목표 역량 진단 |
| 주의 | 단계별 모델 표현·버전 확인 | 적용 모델별 척도·요건 확인 |

## Ⅴ. 한계와 방안

- 핵심 요약 : 평가 등급 자체를 목표로 삼는 형식주의와 현업 부담은 성과 중심 개선으로 완화.

| 한계 | 원인·영향 | 대응 방안 |
| --- | --- | --- |
| 문서 중심 형식주의 | 평가 증거 확보가 실질 개선을 대체 | 고객·사업 성과 지표와 개선 목표 연결 |
| 과도한 절차 | 조직 규모·위험과 무관한 일률 적용 | 리스크 기반 범위와 최소 실행 절차 설계 |
| 평가 시점 편향 | 단기 준비 활동이 평소 수행을 가림 | 지속 운영 증거·표본 프로젝트 검토 |
| 버전 혼용 | 모델·평가 기준의 차이 | 계약·평가 기준 버전과 범위 명시 |

## Ⅵ. 도입 제언

- 핵심 요약 : 경영진은 CMMI를 인증 목적만이 아니라 반복되는 성과 문제를 해결하는 개선 프레임으로 운영.
- 프로세스 책임자는 핵심 결함·재작업·예측 오차를 기준으로 개선 영역을 선택하고 현업 참여를 확보.
- 평가 책임자는 공식 버전과 평가 자격 요건을 확인하며 개선 결과가 사업 성과에 미친 영향을 주기적으로 검토.

## Ⅶ. 결론

- 핵심 요약 : CMMI는 조직 프로세스 역량을 진단하고 지속 개선을 구조화하는 모델·평가 체계.
- 성공은 등급 자체보다 실제 업무에 정착한 프로세스와 측정 가능한 성과 개선으로 판단.
