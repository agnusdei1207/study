## 연관 키워드

- 폭포수 모델(Waterfall Model), 선형 순차 진행, 단계별 산출물
- 요구사항 분석, 베이스라인(Baseline), 변경 통제, 애자일 방법론(Agile Methodology)

## Ⅰ. 폭포수 방법론의 개요

- 핵심 요약 : 폭포수 방법론은 개발 단계를 선형 순차 진행하고 단계별 산출물의 승인 후 다음 단계로 이동하는 생명주기 모델.
- 개념 : 타당성 검토부터 운영·유지보수까지의 **선형 순차 진행**과 단계별 산출물의 검토·승인을 진입 조건으로 삼는 생명주기 모델인 **폭포수 모델** (Waterfall Model)에 기반한 개발 절차 체계.
- 배경 및 필요성 : 대규모·계약 중심 프로젝트에서 단계 구분, 책임 경계, 문서 증거를 통한 계획 통제 필요.
- 주요 목적 : 단계별 검토 관문과 기준선을 통한 예측 가능한 개발과 요구·산출물의 추적성 확보.

## Ⅱ. 폭포수 방법론의 특징 및 장점

- 핵심 요약 : 순차 구조, 단계 종료 검토, 기준선 관리, 문서 중심이 통제 가능성과 추적성으로 연결.

1. 순차 단계 구조 : 각 단계의 완결 산출물이 다음 단계의 입력 → 역할·책임 경계의 명확화 효과.
2. 단계 종료 검토 : 산출물 검토·승인 후 진행 → 미완성 산출물의 조기 발견 효과.
3. 베이스라인 관리 : 승인된 요구·설계를 **베이스라인** (Baseline)으로 고정 → 변경 영향 분석과 추적성 효과.
4. 문서 중심 관리 : 요구부터 시험까지 문서의 단계 연계 → 감사·계약·규제 대응 효과.

## Ⅲ. 폭포수 방법론의 구조 (흐름)

- 핵심 요약 : 타당성 검토 → 요구사항 분석 → 설계 → 구현 → 시험 → 운영·유지보수의 단계 흐름과 베이스라인 기반 변경 통제.

```text
타당성 검토·계획 수립
   ↓ 사업 범위·자원 확정
요구사항 분석
   ↓ 요구 명세의 승인
시스템·상세 설계
   ↓ 설계 검토 통과
구현·단위 시험
   ↓ 통합·시스템·인수 시험
운영·유지보수
```

- 각 단계에 대응 시험을 배치해 검증을 강조한 변형이 **V-모델** (V-Model).

```text
변경 요청 접수
   ↓ 영향 분석
변경 검토·승인
   ↓ 베이스라인 갱신
문서·코드·시험 산출물 반영
```

## Ⅳ. 폭포수 방법론과 애자일 방법론의 비교

- 핵심 요약 : 요구 안정성·피드백 주기·산출물 성격에 따라 폭포수 방법론과 애자일 방법론의 적합성이 갈림.

| 비교 축 | 폭포수 방법론 | 애자일 방법론 |
| --- | --- | --- |
| 진행 방식 | 전체 범위의 순차 진행 | 짧은 반복의 점증 개발 |
| 요구 변화 | 변경 통제 절차로 처리 | 반복 계획에 상시 반영 |
| 피드백 시점 | 단계 종료·인수 시점 | 각 반복 종료 시점 |
| 산출물 중심 | 문서·승인 산출물 | 작동하는 소프트웨어 |
| 적합 조건 | 안정 요구·계약·규제 환경 | 불확실성·우선순위 변동 |

## Ⅴ. 폭포수 방법론의 한계와 방안

- 핵심 요약 : 늦은 피드백과 변경 비용 누적을 조기 검증과 변경 통제의 강화로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 요구 오해의 후반 발견 | 동작 결과 확인 지연 → 재작업 비용 급증 | 초기 프로토타입·요구 검증 강화 | 요구 변경 건수 |
| 변경 비용의 누적 | 이전 단계 재작업·재승인 → 일정 지연 | 영향 분석·변경 통제 절차의 준수 | 변경 처리 소요 시간 |
| 통합 위험의 후반 집중 | 구현 완료 후 연계 확인 → 결함 대량 발생 | 인터페이스 조기 검증·지속 통합 | 통합 결함 수 |
| 문서와 실체의 불일치 | 승인 문서 중심 진행 → 실동작 미반영 | 추적성·시험 증거의 유효성 확인 | 산출물 불일치 건수 |

## Ⅵ. 생명주기 모델 선택에 대한 기술사적 제언

- 핵심 요약 : 발주기관·수행 조직은 프로젝트 특성 평가에 따른 모델 선택 기준과 하이브리드 적용 지침 필요.
1. 프로젝트 관리 조직은 요구 안정성, 규제 강도, 피드백 가능성의 평가 기준을 사업 계획서에 포함.
2. 계약 구조가 순차형이어도 불확실성이 큰 기능은 시제품·점진 통합을 병용하는 하이브리드 지침 운영.

## Ⅶ. 결론

- 핵심 요약 : 폭포수 방법론은 단계 통제·추적성이 강점이고 요구 변동 상황에서는 늦은 피드백이 위험.
- 시사점 : 프로젝트 특성 판단에 따른 모델 선택과 부분 반복의 조합이 현실적 적용 방향.
