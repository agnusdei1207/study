## 30초 인출

- 본질: **비선형 자료구조** 는 항목을 한 줄로 나열하지 않고 계층이나 망 형태의 관계로 저장하는 구조
- 메커니즘: 부모·자식 관계를 나타내는 트리와 정점·간선으로 임의의 연결을 나타내는 그래프
- 통찰: 한계: 계층에 다중 경로나 순환이 생기면 트리의 단일 부모 가정이 깨짐 → 방안: 관계 제약을 확인해 트리 또는 그래프로 모델링

<details>
<summary>핵심 용어</summary>

- **비선형 자료구조** : 항목 사이의 계층 또는 망 관계를 표현하는 자료구조
- **Tree(트리)** : 하나의 루트를 중심으로 부모·자식 계층을 나타내며 사이클이 없는 연결 구조
- **Graph(그래프)** : 정점과 간선으로 개체와 개체 사이의 연결을 표현하는 구조
- **DAG(Directed Acyclic Graph)** : 방향 간선이 있고 방향을 따라 되돌아오는 경로가 없는 그래프
- **인접 리스트** : 각 정점마다 연결된 정점 목록을 저장하는 그래프 표현 방식
- **인접 행렬** : 정점 쌍의 연결 여부를 2차원 표로 저장하는 그래프 표현 방식

</details>

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비선형 자료구조** 는 데이터 항목을 계층 또는 망 형태의 관계로 연결해 저장하는 자료구조 |
| 목적 | 계층·다중 연결 관계의 표현과 그 관계에 맞는 탐색 지원 |

## Ⅱ. 비선형 자료구조의 특징

| 특징 | 의미 |
|---|---|
| 다중 관계 | 한 항목에서 여러 항목으로 연결 가능 |
| 계층·망 표현 | 트리는 부모·자식, 그래프는 정점·간선의 일반 연결을 표현 |
| 탐색 정책 필요 | 관계와 방문 상태에 따라 순회·탐색 방식 선택 |

## Ⅲ. 체계·프로세스

```text
관계의 제약 확인
  ├─ 단일 부모·순환 없음 → 루트가 있는 트리
  │     └─ 자식 방문 순서에 따라 전위·중위·후위·레벨 순회
  └─ 다중 연결·순환 가능 → 정점과 간선의 그래프
        └─ 방문 집합 관리 → DFS(경로 심화) / BFS(가까운 이웃 우선)
```

## Ⅳ. 종류·비교·관계

| 관점 | 선형 구조 | 비선형 구조 |
|---|---|---|
| 연결 모습 | 순차적 선후 관계 | 계층적 부모·자식 또는 망 연결 |
| 노드의 연결 | 일반적으로 앞뒤 항목 중심 | 여러 자식·이웃으로 분기 가능 |
| 대표 구조 | 배열·연결 리스트·스택·큐 | 트리·그래프 |
| 탐색 관점 | 위치·순서에 따른 접근 | 계층 순회·연결 경로 탐색 |

```text
비선형 자료구조
    ├─ 트리: 계층·부모/자식
    │    ├─ 이진 탐색 트리
    │    └─ 다원 탐색 트리
    └─ 그래프: 정점·간선
         ├─ 방향 그래프
         │    └─ DAG: 순환 없는 방향 그래프
         └─ 무방향 그래프
```

### 표현 방법과 탐색

| 구조·방법 | 핵심 표현·동작 | 적합한 사용 조건 |
|---|---|---|
| 트리 순회 | 전위·중위·후위·레벨 순서로 노드 방문 | 계층 전체의 처리 순서가 필요할 때 |
| 인접 리스트 | 정점별 연결 정점 목록 저장 | 간선이 비교적 적은 그래프 |
| 인접 행렬 | 정점 쌍의 연결 여부를 행렬에 저장 | 연결 여부를 자주 확인하거나 간선이 많은 그래프 |
| 깊이 우선 탐색(DFS) | 한 경로를 따라가다 더 진행할 수 없으면 되돌아감 | 도달성·연결요소·경로 탐색 |
| 너비 우선 탐색(BFS) | 시작 정점에서 가까운 이웃부터 방문 | 비가중치 그래프의 최단 간선 수 경로 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 다중 부모·순환 관계를 트리로 표현해 연결 누락 | 관계 제약을 확인하고 다중 연결이 필요하면 그래프 적용 |
| 의존 그래프에 순환이 있어 실행 순서를 정할 수 없음 | DAG 조건을 검사하고 순환 간선을 수정한 뒤 위상 정렬 |
| 희소 그래프에 행렬을 사용해 저장 공간 낭비 | 정점별 이웃을 담는 인접 리스트 적용 |
| 밀집 그래프에서 연결 여부 질의가 반복되어 탐색 비용 증가 | 인접 행렬과 리스트의 공간·조회 비용을 비교해 선택 |


## Ⅵ. 제언

계층성·간선 밀도·순환 허용 여부·주요 질의를 설계 기준으로 기록하고, 자료구조와 탐색 알고리즘을 함께 선택.
