## 30초 인출

- 본질: 비선형 구조는 원소 사이의 관계가 순서 하나로 이어지지 않고 계층이나 망으로 연결되는 자료구조이며 트리와 그래프가 대표
- 메커니즘: 트리는 루트에서 부모-자식으로 뻗는 계층 구조이고, 그래프는 정점과 간선으로 임의의 관계를 표현하며 DFS·BFS로 순회
- 통찰: 그래프를 인접 행렬로 저장하면 간선이 적은 희소 그래프에서 메모리가 낭비되므로 간선 밀도에 따라 희소하면 인접 리스트, 조밀하면 인접 행렬을 선택

<details>
<summary>핵심 용어</summary>

- **비선형 구조(Non-Linear Structure)** : 원소가 순서 하나로 연결되지 않고 계층·망 형태로 연결된 자료구조
- **트리(Tree)** : 루트에서 부모-자식 관계로 이어지며 사이클이 없는 계층 구조
- **그래프(Graph)** : 정점(Vertex)과 간선(Edge)으로 관계를 표현하는 구조
- **DFS(Depth-First Search)** : 한 방향으로 갈 수 있는 끝까지 탐색한 뒤 되돌아오는 탐색. 스택 또는 재귀 사용
- **BFS(Breadth-First Search)** : 시작 정점에서 가까운 정점부터 차례로 탐색. 큐 사용
- **인접 행렬·인접 리스트** : 그래프의 연결 관계를 2차원 배열로 또는 정점별 이웃 목록으로 저장하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 비선형 구조의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비선형 구조** 는 원소 사이의 관계가 계층이나 망으로 연결되는 자료구조 |
| 목적 | 계층·연결 관계의 표현과 효율적 탐색 |

## Ⅱ. 선형 구조와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 1:N 또는 N:M 관계 | 한 원소가 여러 원소와 연결 |
| 계층·망 표현 | 조직도·파일 시스템·네트워크 등 표현 |
| 순회 방식 | DFS·BFS 등 탐색 규칙 필요 |

## Ⅲ. 트리와 그래프의 구조

### 트리와 그래프의 구조

```text
트리                    그래프
    A                   A ─── B
   / \                  │  ╲  │
  B   C                 D ─── C
 / \
D   E
(사이클 없음, 루트 하나)   (사이클 가능, 정점·간선)
```

### 확대: 그래프 탐색 방식

```text
DFS: A → B → D … (깊이 우선, 스택·재귀)
BFS: A → B → C → D … (가까운 정점부터, 큐)
```

## Ⅳ. 종류와 표현 방식의 비교

### 트리와 그래프의 비교

| 구분 | 트리 | 그래프 |
|---|---|---|
| 구조 | 계층, 사이클 없음 | 임의 연결, 사이클 가능 |
| 간선 수 | 정점 수 − 1 | 제한 없음 |
| 예 | 파일 시스템, 조직도 | 네트워크, 소셜 관계 |

### 그래프 저장 방식의 비교

| 구분 | 인접 행렬 | 인접 리스트 |
|---|---|---|
| 저장 공간 | O(V²) | O(V+E) |
| 간선 존재 확인 | O(1) | 이웃 수에 비례 |
| 적합 그래프 | 간선이 많은 조밀 그래프 | 간선이 적은 희소 그래프 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 희소 그래프에 인접 행렬 사용 시 메모리 낭비 | 인접 리스트 사용 |
| 트리가 한쪽으로 치우쳐 탐색 성능 저하 | 균형 트리 적용 |
| 그래프 탐색 중 방문한 정점의 재방문 | 방문 표시 배열로 사이클 처리 |

## Ⅵ. 제언

그래프는 정점 수 대비 간선 수(밀도)를 확인해 희소하면 인접 리스트, 조밀하면 인접 행렬로 저장

### 저장 방식 선택

```text
간선 밀도 E / V² 확인
    ├─ 낮음(희소) → 인접 리스트
    └─ 높음(조밀) → 인접 행렬
```

### 선택 근거: 항상 인접 행렬 사용과의 비교

| 구분 | 항상 행렬 | 제언: 밀도별 선택 |
|---|---|---|
| 희소 그래프 메모리 | 낭비 | 절약 |
| 이웃 순회 | 정점 수만큼 확인 | 이웃만 확인 |
| 구현 | 단순 | 선택 기준 필요 |
