## 30초 인출

- 본질: **비선형 자료구조**는 항목을 한 줄로 나열하지 않고 계층이나 망 형태의 관계로 저장하는 구조
- 메커니즘: 부모·자식 관계를 나타내는 트리와 정점·간선으로 임의의 연결을 나타내는 그래프
- 선택 기준: 계층의 단일 경로가 핵심이면 트리, 여러 경로·순환 관계가 필요하면 그래프

<details>
<summary>핵심 용어</summary>

- **비선형 자료구조**: 항목 사이의 계층 또는 망 관계를 표현하는 자료구조
- **Tree(트리)**: 하나의 루트를 중심으로 부모·자식 계층을 나타내며 사이클이 없는 연결 구조
- **Graph(그래프)**: 정점과 간선으로 개체와 개체 사이의 연결을 표현하는 구조
- **DAG(Directed Acyclic Graph)**: 방향 간선이 있고 방향을 따라 되돌아오는 경로가 없는 그래프
- **인접 리스트**: 각 정점마다 연결된 정점 목록을 저장하는 그래프 표현 방식
- **인접 행렬**: 정점 쌍의 연결 여부를 2차원 표로 저장하는 그래프 표현 방식

</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비선형 자료구조**는 데이터 항목을 계층 또는 망 형태의 관계로 연결해 저장하는 자료구조 |
| 목적 | 계층·다중 연결 관계의 표현과 그 관계에 맞는 탐색 지원 |

### Ⅱ. 선형 구조와 비선형 구조

| 비교 기준 | 선형 구조 | 비선형 구조 |
|---|---|---|
| 관계 | 항목의 순차적 선후 관계 | 부모·자식 계층 또는 여러 연결 관계 |
| 표현 예 | 배열·연결 리스트·스택·큐 | 트리·그래프 |
| 주요 탐색 | 순차 탐색 등 | 트리 순회·깊이 우선·너비 우선 탐색 |

### Ⅲ. 트리와 그래프

```text
트리: 계층 관계
루트
├─ 자식 A
│  └─ 자식 C
└─ 자식 B

그래프: 정점·간선 관계
X ─ Y, X ─ Z, Y ─ Z
```

트리는 단일 루트를 둔 계층 관계를, 그래프는 루트에 구속되지 않는 정점 간 연결을 나타내는 구조.

| 구분 | 트리 | 그래프 |
|---|---|---|
| 관계 | 부모·자식 계층 | 임의 정점 간 연결 |
| 순환 | 없음 | 허용 가능 |
| 적용 예 | 디렉터리·조직 구조 | 도로망·서비스 연결망 |

제언: 데이터 관계의 계층성·다중 경로·순환 허용 여부에 맞춘 구조 선택.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **비선형 자료구조**는 데이터 항목을 계층 또는 망 형태의 관계로 연결해 저장하는 자료구조 |
| 목적 | 계층·다중 연결 관계의 표현과 그 관계에 맞는 탐색 지원 |

## Ⅱ. 선형 구조와 비선형 구조의 관계

| 관점 | 선형 구조 | 비선형 구조 |
|---|---|---|
| 연결 모습 | 순차적 선후 관계 | 계층적 부모·자식 또는 망 연결 |
| 노드의 연결 | 일반적으로 앞뒤 항목 중심 | 여러 자식·이웃으로 분기 가능 |
| 대표 구조 | 배열·연결 리스트·스택·큐 | 트리·그래프 |
| 탐색 관점 | 위치·순서에 따른 접근 | 계층 순회·연결 경로 탐색 |

## Ⅲ. 트리와 그래프의 유형

```text
비선형 자료구조
    ├─ 트리: 계층·부모/자식
    │    ├─ 이진 탐색 트리
    │    └─ 다원 탐색 트리
    └─ 그래프: 정점·간선
         ├─ 방향 그래프
         │    └─ DAG: 순환 없는 방향 그래프
         └─ 무방향 그래프
```

## Ⅳ. 표현 방법과 탐색

| 구조·방법 | 핵심 표현·동작 | 적합한 사용 조건 |
|---|---|---|
| 트리 순회 | 전위·중위·후위·레벨 순서로 노드 방문 | 계층 전체의 처리 순서가 필요할 때 |
| 인접 리스트 | 정점별 연결 정점 목록 저장 | 간선이 비교적 적은 그래프 |
| 인접 행렬 | 정점 쌍의 연결 여부를 행렬에 저장 | 연결 여부를 자주 확인하거나 간선이 많은 그래프 |
| 깊이 우선 탐색(DFS) | 한 경로를 따라가다 더 진행할 수 없으면 되돌아감 | 도달성·연결요소·경로 탐색 |
| 너비 우선 탐색(BFS) | 시작 정점에서 가까운 이웃부터 방문 | 비가중치 그래프의 최단 간선 수 경로 |

## Ⅴ. 구조 선택과 오류 예방

| 설계 조건 | 선택·검토 |
|---|---|
| 단일 부모를 갖는 계층 | 트리 적용, 부모·자식 제약과 루트 관리 |
| 선행 작업과 의존 관계 | 방향 그래프 적용, 순환 허용 여부 검토 |
| 방향 순서에 맞춘 작업 실행 | DAG 구성과 위상 정렬 가능 여부 확인 |
| 많은 정점과 희소한 연결 | 인접 리스트로 저장 공간 절감 |
| 연결 여부를 빈번히 확인하는 밀집 그래프 | 인접 행렬 사용 검토 |

## Ⅵ. 기술사적 제언 — 관계 특성에 맞는 표현·탐색 기준

| 한계 | 해결 방안 |
|---|---|
| 자료 관계와 질의 형태를 고려하지 않은 구조 선택으로 불필요한 탐색·저장 비용이 발생할 가능성 | 계층성·간선 밀도·순환 허용 여부·주요 질의를 설계 기준으로 기록하고, 자료구조와 탐색 알고리즘을 함께 선택 |
