## 연관 키워드

- 다익스트라 알고리즘, 단일 출발점 최단 경로, 탐욕 알고리즘, 간선 완화, 우선순위 큐, 음수 가중치

## Ⅰ. 다익스트라 알고리즘의 개요

- 핵심 요약 : 다익스트라 알고리즘은 비음수 가중 그래프에서 한 출발점으로부터의 최단 경로를 확정 순서로 구하는 대표 기법.
- 개념 : 모든 간선 가중치가 0 이상인 그래프에서 한 출발점으로부터 각 정점까지의 **단일 출발점 최단 경로** (Single Source Shortest Path)를 구하는 **탐욕 알고리즘** (Greedy Algorithm) 기반 기법이 **다익스트라 알고리즘** (Dijkstra Algorithm).
- 배경 및 필요성 : 도로·통신망 같은 비용 기반 네트워크에서 출발점 기준 최소 비용 경로의 효율적 산출 요구, 1959년 에츠허르 다익스트라가 발표한 통용 기법.
- 주요 목적 : 각 정점까지의 최단 거리와 경로(선행 정점 정보)의 효율적 산출.

## Ⅱ. 다익스트라 알고리즘의 특징 및 장점

- 핵심 요약 : 탐욕적 확정·간선 완화·우선순위 큐의 결합이 정확성과 효율성으로 연결.

1. 탐욕적 확정 : 미확정 정점 중 잠정 거리 최소 정점의 최종 확정 → **음수 가중치**가 없을 때만 성립하는 최적성 보장.
2. **간선 완화** (Relaxation) : `dist[v] > dist[u] + w(u,v)`이면 거리 갱신 → 발견되는 더 짧은 경로의 즉시 반영.
3. **우선순위 큐** (Priority Queue) : 최소 힙으로 다음 확정 정점 추출 → 희소 그래프에서 O((V+E) log V)의 효율.
4. 경로 복원 : 갱신 시점의 선행 정점 저장 → 목적지로부터의 역추적으로 경로 재구성.

## Ⅲ. 다익스트라 알고리즘의 구조 (흐름)

- 핵심 요약 : 초기화 후 최소 거리 정점 확정·인접 간선 완화를 큐 소진까지 반복하며 선행 정점 기록으로 경로 복원.

```text
거리 초기화 - 출발점 0·나머지 ∞
   ↓
최소 잠정 거리 정점 추출·확정
   ↓
인접 간선 완화 - 더 짧으면 갱신
   ↓ 반복
모든 정점 확정 또는 큐 소진
```

```text
dist[u] + w(u,v) < dist[v]
   ↓ 성립 시
dist[v] 갱신 - 부모[v] = u
   ↓
목적지에서 부모 역추적 → 경로
```

- 큐에서 꺼낸 정점의 거리가 현재 값보다 크면 오래된 후보로 무시 → 감소 키 미지원 구현의 중복 후보 정리.
- 배열 기반 구현 O(V²)는 조밀 그래프에, 이진 힙 O((V+E) log V)는 희소 그래프에 적합, 피보나치 힙은 이론상 O(E + V log V).

## Ⅳ. 다익스트라 알고리즘과 벨만-포드 알고리즘의 비교

- 핵심 요약 : 다익스트라가 비음수 전제의 속도를 담당하는 반면, **벨만-포드 알고리즘** (Bellman-Ford Algorithm)은 음수 간선 처리·음수 사이클 검출을 담당.

| 비교 축 | 다익스트라 알고리즘 | 벨만-포드 알고리즘 |
| --- | --- | --- |
| 가중치 전제 | 비음수 간선 | 음수 간선 허용 |
| 진행 방식 | 최소 거리 정점 확정 후 완화 | 전체 간선의 반복 완화 |
| 음수 사이클 | 판정 불가 | 도달 가능 음수 사이클 검출 |
| 시간 복잡도 | O((V+E) log V) - 이진 힙 | O(V·E) |
| 대표 적용 | OSPF 등 링크 상태 라우팅 | 거리 벡터 계열 라우팅 |

## Ⅴ. 다익스트라 알고리즘의 한계와 방안

- 핵심 요약 : 전제 위반·수치 한계·동률 경로·큐 부산물을 입력 검증과 구현 규칙으로 통제 필요.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 음수 간선 입력 | 탐욕적 확정 전제 붕괴로 오답 | 입력 검증 또는 벨만-포드 전환 | 간선 검증 통과율 |
| 거리 오버플로 | ∞ 표현·합산의 정수 한계 | 충분한 자료형·덧셈 경계 검사 | 오버플로 발생 건수 |
| 동률 경로 다수 | 갱신 규칙에 따른 경로 상이 | 동률 처리 규칙의 요구사항 명시 | 동률 경로 선택 건수 |
| 오래된 큐 항목 | 중복 삽입에 따른 연산 낭비 | 추출 시 현재 dist 비교 후 무시 | 무시 항목 비율 |

## Ⅵ. 다익스트라 알고리즘에 대한 기술사적 제언

- 핵심 요약 : 입력 전제·자료 구조·경계 시험의 계약화로 최단 경로 기능의 정확성과 운영 안정성 확보 필요.
- 개발 조직은 인터페이스 명세에 방향성·비음수 전제·도달 불가 표현·동률 규칙을 명시하고 기준 그래프·고립 정점·동일 가중치 시험을 포함.
- 대용량 지도 서비스는 휴리스틱으로 탐색 범위를 좁히는 A* 탐색이나 양방향 탐색으로 확장해 응답 시간 요구에 대응.

## Ⅶ. 결론

- 핵심 요약 : 다익스트라 알고리즘은 비음수 가중 그래프의 단일 출발점 최단 경로를 위한 표준 해법.
- 비음수 전제 확인과 완화·큐·경로 복원 규칙의 일관된 설계가 정확한 구현의 핵심.
