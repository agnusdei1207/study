소프트웨어 공학 → 자료구조·알고리즘 → **퀵 정렬(Quick Sort)**

## 30초 인출

- 본질: 퀵 정렬은 피벗을 기준으로 작은 값과 큰 값으로 나눈 뒤 각 부분을 같은 방식으로 정렬하는 분할 정복 정렬
- 메커니즘: 피벗을 골라 작은 값은 왼쪽, 큰 값은 오른쪽으로 분할하고 각 부분 배열에 재귀 적용해 평균 O(n log n)에 정렬
- 통찰: 피벗이 한쪽으로 치우치면 분할이 편향되어 O(n²)이 되므로 무작위 또는 3값 중앙값으로 피벗을 선택하고 작은 구간은 삽입 정렬로 전환

<details>
<summary>핵심 용어</summary>

- **퀵 정렬(Quick Sort)** : 피벗 기준 분할을 재귀로 반복하는 분할 정복 정렬
- **피벗(Pivot)** : 분할의 기준이 되는 원소
- **분할(Partition)** : 피벗보다 작은 값과 큰 값을 나눠 배치하는 과정
- **분할 정복(Divide and Conquer)** : 문제를 나눠 각각 해결한 뒤 결합하는 설계 방식
- **제자리 정렬(In-place Sort)** : 추가 배열 없이 입력 배열 안에서 정렬하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 퀵 정렬의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **퀵 정렬** 은 피벗을 기준으로 분할하고 각 부분을 재귀로 정렬하는 분할 정복 정렬 |
| 목적 | 평균적으로 빠른 제자리 정렬 |

## Ⅱ. 퀵 정렬의 특징

| 특징 | 의미 |
|---|---|
| 분할 정복 | 피벗 기준 분할과 재귀 |
| 제자리 정렬 | 추가 배열 없이 정렬 |
| 불안정 정렬 | 같은 키의 순서가 바뀔 수 있음 |
| 피벗 의존 성능 | 피벗 선택이 성능 좌우 |

## Ⅲ. 분할과 재귀의 동작

### 분할 과정

```text
[5, 3, 8, 1, 9, 2]  피벗 = 5
    ↓ 분할
[3, 1, 2] 5 [8, 9]
    ↓ 각 부분 재귀
[1, 2, 3] 5 [8, 9]
```

### 확대: 분할 판단

```text
부분 배열 크기 ≤ 1 → 정렬 완료
그 외 → 피벗 선택 → 분할 → 좌·우 재귀
```

## Ⅳ. 복잡도와 피벗 선택 방식의 비교

### 복잡도

| 구분 | 시간 | 조건 |
|---|---|---|
| 최선·평균 | O(n log n) | 피벗이 균등하게 분할 |
| 최악 | O(n²) | 정렬된 입력에서 첫 원소 피벗 등 편향 분할 |
| 공간 | O(log n) | 재귀 호출 스택 |

### 피벗 선택 방식

| 방식 | 특징 |
|---|---|
| 첫·마지막 원소 | 단순하나 정렬된 입력에서 편향 |
| 무작위 | 특정 입력에 의한 최악 회피 |
| 3값 중앙값 | 첫·중간·마지막 값의 중앙값으로 편향 완화 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 편향 분할로 O(n²) 발생 | 무작위·3값 중앙값 피벗 |
| 작은 구간의 재귀 호출 비용 | 작은 구간은 삽입 정렬 전환 |
| 불안정 정렬 | 안정성이 필요하면 병합 정렬 사용 |

## Ⅵ. 제언

피벗은 3값 중앙값이나 무작위로 선택하고, 작은 부분 배열은 삽입 정렬로 전환

### 개선 적용 순서

```text
피벗 선택 (3값 중앙값)
    ↓
분할 → 재귀
    ↓
작은 구간 → 삽입 정렬
```

### 확대: 안정성 요구 판단

```text
같은 키의 순서 유지 필요?
    ├─ 예 → 병합 정렬
    └─ 아니오 → 퀵 정렬
```

### 선택 근거: 단순 피벗과의 비교

| 구분 | 첫 원소 피벗 | 제언: 중앙값·무작위 피벗 |
|---|---|---|
| 정렬된 입력 | O(n²) | O(n log n) |
| 구현 | 단순 | 약간 복잡 |
| 성능 안정성 | 입력 의존 | 안정적 |
