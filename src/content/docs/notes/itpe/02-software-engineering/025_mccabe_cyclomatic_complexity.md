## 연관 키워드
- McCabe 순환 복잡도, Cyclomatic Complexity, 제어 흐름 그래프, 기본 경로
- 기본 경로 테스트, V(G)=E−N+2, 정적 분석, 품질 게이트

## Ⅰ. McCabe 순환 복잡도의 개요

- 핵심 요약 : McCabe 순환 복잡도는 제어 흐름 그래프의 선형 독립 경로 수로 모듈 구조 복잡도를 수치화하는 지표.
- 개념 : 맥케이브(McCabe)가 제안한 **순환 복잡도**(Cyclomatic Complexity)는 **제어 흐름 그래프**(Control Flow Graph, CFG)의 선형 독립 경로 수를 계산하는 구조 기반 코드 메트릭.
- 배경 및 필요성 : 코드 줄 수 기반 평가는 분기·반복이 만드는 경로 부담을 반영하지 못하는 한계.
- 주요 목적 : 구조 품질의 정량 관리 기반을 통해 복잡 모듈의 조기 식별과 시험·리팩토링 효율 확보.

## Ⅱ. McCabe 순환 복잡도의 특징 및 장점

- 핵심 요약 : 그래프 구조의 객관 계산성이 시험 설계 근거·품질 통제·리팩토링 판단으로 이어지는 구조.

1. 구조 기반 객관성 : 분기·반복을 노드와 간선으로 환산해 계산 → 개발자 주관과 무관한 비교 가능 수치.
2. 시험 경로 기준 : 순환 복잡도 값만큼의 **기본 경로**(Basis Path, 새로운 간선을 하나 이상 포함하는 독립 경로)를 시험하면 모든 분기 통과 → **기본 경로 테스트**(Basis Path Testing) 설계 근거.
3. 결함 경향 상관 : 복잡도가 높은 모듈에서 결함 밀도·변경 부담 증가 경향 → 리팩토링 대상 선정 근거.
4. 자동 측정 적합성 : **정적 분석**(Static Analysis) 도구가 소스에서 직접 산출 → 빌드 파이프라인 연동에 적합.

## Ⅲ. McCabe 순환 복잡도의 구조 (흐름)

- 핵심 요약 : 소스를 그래프로 변환한 뒤 동치 계산식으로 값을 구하고 품질 게이트에 연동하는 절차.

```text
순환 복잡도 계산식 (동치)

V(G) = E − N + 2  (E 간선 수, N 노드 수, 단일 연결 그래프)
V(G) = 판정 노드 수 + 1  (이원 분기 기준)
V(G) = 그래프의 닫힌 영역 수
```

```text
적용 절차

소스 코드 정적 분석
   ↓
제어 흐름 그래프 변환
   ↓
V(G) 계산·모듈별 집계
   ↓
품질 게이트 기준 비교
   ↓
초과 모듈 리팩토링·재검증
```

- 판정 노드 : if·while·for·case 등 분기 지점, 분기가 없는 단일 경로 함수의 값은 1.
- 품질 게이트 : 기준 초과 모듈의 빌드 통과를 차단하는 자동 통제 지점.
- 맥케이브의 원 논문은 모듈 복잡도 상한 10을 제시, 언어·도메인에 따른 조정이 일반적.

## Ⅳ. McCabe 순환 복잡도와 LOC(규모 기반 지표)의 비교

- 핵심 요약 : 순환 복잡도는 제어 구조의 복잡성을, LOC는 물리적 규모를 측정하는 상보적 코드 메트릭.
- 비교 개요 : **LOC**(Lines of Code, 코드 라인 수)는 규모 기반 대표 지표로 구조 기반 지표인 순환 복잡도와 해석 목적이 상보.

| 비교 축 | 순환 복잡도 | LOC |
|---|---|---|
| 측정 대상 | 분기·경로 등 제어 구조 | 물리적 라인 수(규모) |
| 시험 적용 | 기본 경로 수 추정 → 케이스 설계 | 작업량·커버리지 추정 보조 |
| 표기 영향 | 분기 표현에 민감·스타일 영향 적음 | 한 줄 압축·스타일로 왜곡 |
| 주 활용 | 복잡 모듈 식별·리팩토링 순위 | 규모 추정·생산성 산출 |
| 해석 한계 | 데이터 흐름·도메인 난도 미반영 | 구조적 위험의 직접 척도 아님 |

## Ⅴ. McCabe 순환 복잡도의 한계와 방안

- 핵심 요약 : 지표 과신·임계값 획일 적용·수치 축소형 분해를 병행 해석과 기준 관리로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 지표 과신 | 같은 값이라도 구조·도메인 위험이 상이 → 결함 간과 | 코드 리뷰·결함 추세·응집도 평가 병행 | 결함 발견률 |
| 임계값 획일 적용 | 언어·도메인별 적정 수준 차이 무시 | 도메인별 기준선과 신규·변경 코드 구분 적용 | 게이트 초과 모듈 수 |
| 수치 축소형 분해 | 점수 낮추기 목적의 무의미한 함수 분할 → 가독성 저하 | 분기 원인인 책임 분리 후 리팩토링·회귀 시험 | 분할 후 변경 빈도 |

## Ⅵ. McCabe 순환 복잡도에 대한 제언

- 핵심 요약 : 측정 표준화·추세 공유·의사결정 연계의 조직 체계로 복잡도 관리를 품질 거버넌스에 편성.

1. 개발 조직은 정적 분석 도구를 CI(Continuous Integration) 파이프라인의 표준 단계로 편성하고 측정 규칙·예외 기준을 코딩 표준으로 문서화.
2. 품질 보증 조직은 모듈별 복잡도 추세를 품질 대시보드·감사 증적과 연계해 공유하는 체계 운영.
3. 기술 책임자는 복잡도 데이터를 기술 부채 관리와 아키텍처 개선 의사결정의 정량 근거로 편성.

## Ⅶ. 결론

- 핵심 요약 : McCabe 순환 복잡도는 제어 흐름 구조에서 최소 시험 경로 수를 산출하는 대표적 구조 메트릭.
- 수치는 품질의 단독 판정 기준이 아니라 시험 설계·리팩토링을 유도하는 신호로 활용할 때 효과 극대화.
