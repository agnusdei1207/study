## 30초 인출

- 본질: EDA는 이벤트의 발행과 구독으로 구성요소를 느슨하게 연결하는 아키텍처이며 처리 흐름 구성 방식에 따라 브로커 토폴로지와 중재자 토폴로지로 나뉨
- 메커니즘: 생산자가 이벤트를 발행하면 브로커 토폴로지는 처리기들이 이벤트 채널로 연쇄 처리하고 중재자 토폴로지는 중재자가 처리 순서를 지휘
- 통찰: 브로커 토폴로지는 결합이 낮으나 전체 흐름 추적과 오류 복구가 어렵고 중재자 토폴로지는 흐름을 통제하나 중재자가 병목이 되므로 업무 흐름의 복잡도와 오류 복구 요구로 선택

<details>
<summary>핵심 용어</summary>

- **이벤트 기반 아키텍처(EDA)** : 이벤트의 발행·구독으로 구성요소가 비동기적으로 협업하는 아키텍처
- **이벤트(Event)** : 이미 일어난 상태 변화를 알리는 메시지
- **브로커 토폴로지(Broker Topology)** : 중앙 통제자 없이 이벤트 처리기가 이벤트 채널로 연쇄 처리하는 구성
- **중재자 토폴로지(Mediator Topology)** : 중재자가 이벤트를 받아 처리 단계를 순서대로 지휘하는 구성
- **이벤트 브로커** : 이벤트를 받아 구독자에게 전달하는 중계 구성요소
- **멱등성(Idempotency)** : 같은 이벤트를 여러 번 처리해도 결과가 같은 성질

</details>

## 2~4교시 25점 답안

## Ⅰ. EDA의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EDA** 는 이벤트의 발행·구독으로 구성요소를 비동기적으로 연결하는 아키텍처 |
| 목적 | 구성요소 간 결합 감소와 비동기 확장성 확보 |

## Ⅱ. 요청-응답 방식과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 비동기 | 발행자가 처리 완료를 기다리지 않음 |
| 느슨한 결합 | 발행자와 구독자가 서로를 모름 |
| 확장 용이 | 구독자 추가로 기능 확장 |

## Ⅲ. 두 토폴로지의 구조

### 브로커 토폴로지와 중재자 토폴로지

```text
브로커: 이벤트 → [처리기A] → 이벤트 → [처리기B] → 이벤트 → [처리기C]
        (중앙 통제자 없이 처리기가 이벤트 채널로 연쇄)

중재자: 이벤트 → [중재자] ──→ 처리기A
                     ├──→ 처리기B
                     └──→ 처리기C   (중재자가 순서 지휘)
```

### 확대: 오류 발생 시 처리

```text
브로커: 처리기B 실패 → 이후 처리기 미실행, 전체 흐름 추적 곤란
중재자: 처리기B 실패 → 중재자가 재시도·보상 처리 지휘
```

## Ⅳ. 두 토폴로지의 비교

| 구분 | 브로커 토폴로지 | 중재자 토폴로지 |
|---|---|---|
| 흐름 제어 | 분산(처리기별 연쇄) | 중앙(중재자) |
| 결합도 | 낮음 | 중재자에 의존 |
| 오류 처리 | 어려움 | 중재자가 통제 |
| 확장성·성능 | 높음 | 중재자가 병목 가능 |
| 적합 조건 | 단순·독립적인 처리 흐름 | 순서·오류 복구가 중요한 다단계 업무 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 브로커 토폴로지의 전체 흐름 추적 곤란 | 이벤트에 상관 ID를 붙여 추적 |
| 중재자의 병목·단일 장애점 | 업무별 중재자 분리와 이중화 |
| 이벤트 중복 수신으로 중복 처리 | 멱등 처리와 이벤트 ID 기록 |

## Ⅵ. 제언

순서와 오류 복구가 중요한 다단계 업무는 중재자 토폴로지를, 독립적인 단순 처리는 브로커 토폴로지를 선택하고 이벤트 처리는 멱등하게 구성

### 토폴로지 선택 기준

```text
처리 흐름 확인
    ├─ 다단계·순서·오류 복구 중요 → 중재자
    └─ 독립적·단순 → 브로커
공통: 이벤트 멱등 처리
```

### 확대: 멱등 처리

```text
이벤트 수신 → 이벤트 ID 처리 이력 확인
    ├─ 처리됨 → 무시
    └─ 미처리 → 처리 후 이력 기록
```

### 선택 근거: 하나의 토폴로지 일률 적용과의 비교

| 구분 | 일률 적용 | 제언: 업무 특성별 선택 |
|---|---|---|
| 오류 복구 | 업무 특성 미반영 | 필요한 곳에 통제 |
| 성능 | 병목 또는 추적 곤란 | 균형 |
| 복잡도 | 낮음 | 선택 기준 필요 |
