## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 안전·신뢰성 → **SW 신뢰성 성장 모델(SRGM)**

## 30초 인출

- 본질: SRGM은 테스트 중 발견되는 결함의 누적 추이로 소프트웨어의 잔존 결함과 신뢰도 성장을 수학적으로 예측하는 모델
- 메커니즘: 시험 시간에 따른 결함 발견 수를 수집해 모델(지수형·S자형 등)에 적합시키고 잔존 결함 수와 목표 신뢰도 도달 시점을 추정
- 통찰: 결함 발견이 줄어드는 추세만 보고 출시하면 테스트 범위 축소 때문일 수 있으므로 모델 예측과 테스트 커버리지를 함께 확인해 출시 시점을 판단

<details>
<summary>핵심 용어</summary>

- **SRGM(Software Reliability Growth Model)** : 테스트 중 결함 제거에 따른 신뢰도 성장을 예측하는 모델
- **NHPP(Non-Homogeneous Poisson Process)** : 결함 발생률이 시간에 따라 변하는 확률 과정. SRGM의 기반
- **Goel-Okumoto 모델** : 초기에 결함이 많이 발견되고 점차 줄어드는 지수형 모델
- **S자형 모델** : 학습·환경 적응으로 초기 발견이 느리다가 늘고 다시 줄어드는 모델
- **잔존 결함(Residual Defects)** : 시험 후 남아 있을 것으로 추정되는 결함
- **신뢰도(Reliability)** : 정해진 조건과 시간 동안 고장 없이 동작할 확률

</details>

## 2~4교시 25점 답안

## Ⅰ. SRGM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SRGM** 은 테스트 중 결함 발견 추이로 잔존 결함과 신뢰도 성장을 예측하는 수학적 모델 |
| 목적 | 출시 시점 판단과 추가 테스트 필요량의 근거 확보 |

## Ⅱ. SRGM의 특징

| 특징 | 의미 |
|---|---|
| 데이터 기반 | 시험 중 결함 수집 자료 사용 |
| 성장 추정 | 결함 제거에 따른 신뢰도 향상 예측 |
| 가정 의존 | 결함 즉시 제거·새 결함 미유입 등의 가정 |

## Ⅲ. 모델 구조와 활용 절차

### 활용 절차

```text
시험 시간별 결함 발견 수 수집
    ↓
모델 선택·적합 (지수형·S자형)
    ↓
잔존 결함·목표 신뢰도 도달 시점 예측
    ↓
출시 판단
```

### 확대: 누적 결함 곡선

```text
누적
결함 수      지수형: ╱────── (초기 급증 후 수렴)
                    ╱
         S자형:  ___╱‾‾‾ (초기 완만, 중반 증가, 후반 수렴)
        └──────────────── 시험 시간
```

## Ⅳ. 대표 모델의 비교

| 구분 | 지수형(Goel-Okumoto) | S자형(Yamada 등) |
|---|---|---|
| 결함 발견 양상 | 초기에 많고 점차 감소 | 초기 완만 후 증가, 다시 감소 |
| 적합 상황 | 시험 초기부터 결함이 잘 발견 | 시험 환경 적응·학습 효과 존재 |
| 가정 | 발견 즉시 제거 | 발견 곤란 구간 존재 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 테스트 범위 축소에 따른 발견 감소를 신뢰도 향상으로 오판 | 테스트 커버리지 병행 확인 |
| 모델 가정과 실제 불일치 | 여러 모델 적합 후 비교 |
| 결함 데이터의 부정확 | 결함 기록 기준 표준화 |

## Ⅵ. 제언

모델 예측만으로 출시를 결정하지 않고, 테스트 커버리지와 잔존 결함 예측을 함께 확인해 목표 기준 충족 시 출시

### 출시 판단 기준

```text
잔존 결함 예측 ≤ 목표
AND 테스트 커버리지 ≥ 목표
    ├─ 충족 → 출시
    └─ 미충족 → 추가 테스트
```

### 선택 근거: 결함 수 감소만 보는 방식과의 비교

| 구분 | 발견 감소만 확인 | 제언: 예측 + 커버리지 |
|---|---|---|
| 오판 위험 | 범위 축소와 구분 곤란 | 커버리지로 구분 |
| 근거 | 추세 | 예측 모델 |
| 출시 기준 | 주관적 | 수치 기준 |
