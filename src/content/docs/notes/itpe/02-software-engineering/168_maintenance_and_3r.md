## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 유지보수·품질 → **SW 유지보수 3R(역공학·재공학·재사용)**

## 30초 인출

- 본질: 유지보수 3R은 이미 운영 중인 소프트웨어를 이해하고 개선하기 위한 세 활동으로, 역공학은 구현에서 설계를 복원하고 재공학은 기존 기능을 유지한 채 구조를 다시 만들며 재사용은 기존 자산을 다시 쓰는 것
- 메커니즘: 역공학으로 현재 시스템의 설계 정보를 얻고 그 결과를 바탕으로 재공학이 구조를 개선·재구현하며 재사용 가능한 부분은 자산으로 활용
- 통찰: 설계 문서가 없는 레거시를 바로 고치면 기존 동작을 깨뜨리기 쉬우므로 역공학으로 현재 구조와 동작을 먼저 파악하고 시험으로 동작을 고정한 뒤 재공학

<details>
<summary>핵심 용어</summary>

- **역공학(Reverse Engineering)** : 구현된 코드에서 설계·요구 정보를 추출하는 분석 활동
- **재공학(Re-engineering)** : 기존 시스템의 기능을 유지하면서 구조를 개선해 새로 구현하는 활동
- **순공학(Forward Engineering)** : 요구에서 설계·구현으로 나아가는 일반 개발
- **재사용(Reuse)** : 검증된 기존 모듈·컴포넌트·설계를 다시 사용하는 것
- **유지보수(Maintenance)** : 운영 중인 소프트웨어의 결함 수정·환경 적응·성능 개선·예방 활동

</details>

## 2~4교시 25점 답안

## Ⅰ. 유지보수 3R의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **유지보수 3R** 은 역공학·재공학·재사용으로 기존 소프트웨어를 이해·개선하는 활동 |
| 목적 | 노후 시스템의 유지보수성 향상과 개발 비용 절감 |

## Ⅱ. 신규 개발과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 기존 시스템 기반 | 운영 중인 시스템이 출발점 |
| 기능 유지 | 기존 업무 기능은 보존 |
| 설계 정보 부족 | 문서 없이 코드에서 정보 복원 필요 |

## Ⅲ. 3R의 관계와 재공학 절차

```text
  요구·설계   ◀── 역공학(설계 복원) ──┐
     │ ▲                             │
순공학│ │재공학(구조 개선)            │
     ▼ │                             │
     구현  ─────────────────────────┘
```

| 재공학 절차 | 내용 |
|---|---|
| 1 목표 설정 | 개선 목적과 범위 정의 |
| 2 현행 분석 | 역공학으로 구조·기능 파악 |
| 3 개선 설계 | 재구조화 방향 결정 |
| 4 재구현·시험 | 새 구조로 구현하고 기능 동일성 시험 |
| 5 전환 | 기존 시스템에서 새 시스템으로 이전 |

## Ⅳ. 재공학과 역공학의 비교

| 구분 | 재공학 | 역공학 |
|---|---|---|
| 개념 | 기능은 유지하고 구조를 새로 만듦 | 코드에서 설계·요구를 추출 |
| 목적 | 유지보수성·성능 개선 | 시스템 이해와 문서 복원 |
| 결과물 | 개선된 시스템 | 설계 문서·모델 |
| 활용 | 노후 시스템 현대화 | 레거시 이해, 재공학 입력, 보안 분석 |

| 재사용 | 내용 |
|---|---|
| 대상 | 컴포넌트·모듈·설계·시험 자산 |
| 효과 | 개발 기간·비용 감소, 검증된 품질 활용 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 설계 정보 없이 수정해 기존 동작 파손 | 역공학으로 구조·동작 파악 |
| 재공학 후 기능 불일치 | 기존 동작을 시험으로 고정하고 동일성 확인 |
| 재사용 자산의 불명확한 이력·품질 | 재사용 저장소에 검증된 자산만 등록 |

## Ⅵ. 제언

먼저 역공학으로 현재 구조를 파악하고 시험으로 기존 동작을 고정한 뒤 재공학

```text
역공학 → 시험으로 현재 동작 고정 → 재공학 → 동일성 시험 → 전환
```

| 구분 | 곧바로 수정 | 제언: 역공학 후 재공학 |
|---|---|---|
| 기존 동작 파손 | 위험 | 시험으로 방지 |
| 구조 이해 | 부족 | 복원 후 진행 |
