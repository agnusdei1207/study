소프트웨어 공학 → 자료구조·알고리즘 → **DAG와 위상정렬**

## 30초 인출

- 본질: DAG는 간선에 방향이 있고 순환(사이클)이 없는 그래프이며 선행 관계가 있는 작업의 실행 순서를 정하는 데 쓰이고 그 순서를 구하는 것이 위상 정렬
- 메커니즘: 진입 차수가 0인 노드부터 꺼내 순서에 넣고 그 노드의 나가는 간선을 제거하면서 새로 진입 차수 0이 된 노드를 이어서 처리
- 통찰: 작업 사이에 순환 의존이 있으면 어떤 순서로도 실행할 수 없으므로 실행 전에 위상 정렬로 순환을 검출하고 순환이 있으면 실행을 중단해 의존 관계를 수정

<details>
<summary>핵심 용어</summary>

- **DAG(Directed Acyclic Graph)** : 방향 간선을 가지며 순환이 없는 그래프
- **위상 정렬(Topological Sort)** : 모든 간선 u→v에서 u가 v보다 앞에 오도록 노드를 나열하는 것
- **진입 차수(In-degree)** : 한 노드로 들어오는 간선의 수. 아직 끝나지 않은 선행 작업 수
- **Kahn 알고리즘** : 진입 차수 0인 노드를 큐에 넣어 차례로 처리하는 위상 정렬 방법
- **워크플로 오케스트레이션** : 작업 간 의존 관계를 DAG로 정의해 순서대로 실행하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. DAG의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **DAG** 는 방향 간선을 가지며 순환이 없는 그래프 |
| 목적 | 선행 관계가 있는 작업의 실행 순서 결정 |

## Ⅱ. DAG의 특징

| 특징 | 의미 |
|---|---|
| 방향성 | 간선이 선행 → 후행 관계 표현 |
| 비순환 | 자기 자신에게 돌아오는 경로 없음 |
| 위상 순서 존재 | 순환이 없어야 유효한 실행 순서 존재 |

## Ⅲ. DAG의 구조와 위상 정렬

### 작업 의존 관계의 DAG (빌드 예)

```text
   컴파일 ───┬──→ 단위 시험 ───┐
            │                  ├──→ 패키징 ──→ 배포
   설정 로드 ─┴──→ 통합 시험 ───┘

위상 순서 예: 컴파일 → 설정 로드 → 단위 시험 → 통합 시험 → 패키징 → 배포
(같은 순서가 여러 개 가능: 시험 두 개의 앞뒤는 자유)
```

### Kahn 알고리즘의 단계별 진행

| 단계 | 진입 차수 0 (큐) | 처리 노드 | 갱신되는 진입 차수 |
|---|---|---|---|
| 1 | 컴파일, 설정 로드 | 컴파일 | 단위 시험 2→1, 통합 시험 2→1 |
| 2 | 설정 로드 | 설정 로드 | 단위 시험 1→0, 통합 시험 1→0 |
| 3 | 단위 시험, 통합 시험 | 두 시험 | 패키징 2→0 |
| 4 | 패키징 | 패키징 | 배포 1→0 |
| 5 | 배포 | 배포 | 종료 (처리 노드 수 = 전체 노드 수) |

## Ⅳ. 위상 정렬 방식과 활용의 비교

### 위상 정렬 방식

| 구분 | Kahn 알고리즘 | DFS 기반 |
|---|---|---|
| 원리 | 진입 차수 0인 노드부터 제거 | 깊이 우선 탐색 후 종료 역순 |
| 순환 검출 | 처리 노드 수가 전체보다 적으면 순환 | 탐색 중 방문 중인 노드를 다시 만나면 순환 |
| 시간 | O(V+E) | O(V+E) |

### 활용

| 분야 | 예 |
|---|---|
| 빌드·배포 | 모듈 빌드 순서 |
| 워크플로 | 데이터 파이프라인 작업 순서 |
| 일정 | 선행 작업이 있는 프로젝트 활동 순서 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 순환 의존이 있으면 실행 순서가 없음 | 실행 전 위상 정렬로 순환 검출 |
| 위상 순서가 여러 개라 실행 결과의 비결정 | 병렬 실행 허용 범위와 우선순위 규칙 정의 |
| 의존 관계 누락으로 잘못된 순서 실행 | 의존 관계 선언과 검증 |

## Ⅵ. 제언

작업 정의 단계에서 의존 관계를 DAG로 선언하고, 실행 전에 위상 정렬로 순환을 검출해 순환이 있으면 실행을 막음

### 순환 검출 판단

```text
Kahn 처리 노드 수 = 전체 노드 수 ?
  ├─ 같음 → 순환 없음 → 위상 순서대로 실행
  └─ 적음 → 순환 존재 → 남은 노드 목록을 출력하고 실행 중단
```

### 확대: 병렬 실행

```text
진입 차수 0이 된 노드가 여러 개 → 동시에 실행 가능
```

### 선택 근거: 순서 수동 관리와의 비교

| 구분 | 수동 순서 관리 | 제언: DAG 선언 + 위상 정렬 |
|---|---|---|
| 의존 변경 | 순서를 사람이 수정 | 의존만 수정 |
| 순환 오류 | 실행 중 발견 | 실행 전 검출 |
| 병렬화 | 수동 판단 | 진입 차수로 자동 판단 |
