## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 요구공학 → **요구사항 도출 기법(Requirements Elicitation)**

## 30초 인출

- 본질: 요구사항 도출은 이해관계자에게서 시스템에 필요한 요구를 찾아내 수집하는 요구공학의 첫 활동이며 인터뷰·관찰·워크숍·프로토타이핑 등의 기법을 사용
- 메커니즘: 이해관계자를 식별하고 기법을 조합해 요구를 수집한 뒤 이해관계자별 요구를 교차 확인해 명세로 넘김
- 통찰: 사용자가 말로 표현하지 못하는 암묵적 요구는 인터뷰만으로 놓치기 쉬우므로 관찰과 프로토타이핑을 병행하고 이해관계자별 요구를 교차 확인

<details>
<summary>핵심 용어</summary>

- **요구사항 도출(Requirements Elicitation)** : 이해관계자로부터 요구를 발견하고 수집하는 활동
- **이해관계자(Stakeholder)** : 시스템의 개발·사용에 영향을 주거나 받는 사람과 조직
- **JAD(Joint Application Development)** : 사용자·개발자·관리자가 촉진자 주도의 워크숍으로 요구를 합의하는 기법
- **관찰(Observation)** : 사용자의 실제 업무 환경에서 작업을 지켜보며 요구를 파악하는 기법
- **프로토타이핑(Prototyping)** : 핵심 화면·기능의 시제품으로 요구를 확인하는 기법
- **암묵지(Tacit Knowledge)** : 경험으로 체득했으나 말로 표현하기 어려운 지식

</details>

## 2~4교시 25점 답안

## Ⅰ. 요구사항 도출의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **요구사항 도출** 은 이해관계자로부터 시스템에 필요한 요구를 발견하고 수집하는 활동 |
| 목적 | 누락 없는 요구 확보와 이해관계자 간 요구 충돌의 조기 발견 |

## Ⅱ. 요구사항 도출의 특징

| 특징 | 의미 |
|---|---|
| 다수 이해관계자 | 사용자·발주자·운영자의 상이한 요구 |
| 암묵적 요구 존재 | 말로 표현되지 않는 요구의 발굴 필요 |
| 기법 조합 | 요구 성격에 맞는 여러 기법 병행 |

## Ⅲ. 도출 절차와 기법

### 요구사항 도출 절차

```text
이해관계자 식별
    ↓
도출 기법 선정
    ↓
요구 수집·기록
    ↓
이해관계자별 요구 교차 확인 → 명세로 전달
```

### 확대: 기법별 적합한 요구

```text
명시적 요구 ── 인터뷰·설문·문서 분석
암묵적 요구 ── 관찰·프로토타이핑
합의가 필요한 요구 ── JAD 워크숍·브레인스토밍
```

## Ⅳ. 도출 기법의 비교

| 기법 | 방식 | 강점 | 약점 |
|---|---|---|---|
| 인터뷰 | 이해관계자와의 질의응답 | 깊이 있는 요구 파악 | 암묵적 요구 누락 |
| 설문 | 다수에게 양식 배포 | 넓은 범위 수집 | 깊이 부족 |
| 관찰 | 실제 업무 환경 참관 | 암묵적 요구 발견 | 시간 소요 |
| JAD 워크숍 | 이해관계자 합동 회의 | 합의 형성 | 일정 조율 부담 |
| 프로토타이핑 | 시제품으로 확인 | 요구의 구체화 | 제작 비용 |
| 시나리오·유스케이스 | 사용 흐름 서술 | 흐름 기반 요구 파악 | 예외 누락 가능 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 암묵적 요구 누락 | 관찰·프로토타이핑 병행 |
| 이해관계자 간 요구 충돌 | 교차 확인과 우선순위 합의(JAD) |
| 이해관계자 누락 | 이해관계자 식별표 작성과 검토 |

## Ⅵ. 제언

명시적 요구는 인터뷰로, 암묵적 요구는 관찰·프로토타이핑으로 수집하고 이해관계자별 요구를 교차 확인

### 기법 병행 구조

```text
인터뷰(명시적) + 관찰·프로토타이핑(암묵적)
    ↓
이해관계자별 요구 교차 확인
    ↓
충돌 요구 합의 → 명세
```

### 확대: 충돌 처리

```text
요구 충돌
    ├─ 우선순위로 해결 가능 → 조정
    └─ 이해관계자 합의 필요 → JAD 워크숍
```

### 선택 근거: 인터뷰 단독과의 비교

| 구분 | 인터뷰 단독 | 제언: 기법 병행 |
|---|---|---|
| 암묵적 요구 | 누락 위험 | 관찰·시제품으로 발견 |
| 요구 충돌 | 후반 발견 | 교차 확인으로 조기 발견 |
| 소요 | 적음 | 증가 |
