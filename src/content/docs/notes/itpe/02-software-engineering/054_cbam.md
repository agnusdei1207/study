## 연관 키워드

- CBAM, ATAM, SEI, 효용 곡선, ROI
- 아키텍처 전략, 시나리오 우선순위화, AHP

## Ⅰ. CBAM의 개요

- 핵심 요약 : 아키텍처 개선 대안의 비용과 편익을 정량 분석해 투자 우선순위를 정하는 경제성 평가 방법.
- 개념 : 아키텍처 대안의 비용·효용·불확실성을 수치로 분석해 투자 순위를 결정하는 프레임워크 (**CBAM**, Cost Benefit Analysis Method).
- 배경 및 필요성 : **ATAM**(Architecture Tradeoff Analysis Method)으로 품질속성의 리스크와 절충점을 파악한 뒤에도, 한정된 예산에서 어느 개선 투자를 먼저 집행할지 경제적 판단 기준의 부재.
- 주요 목적 : 아키텍처 투자를 비즈니스 가치와 정렬시키는 예산 배분의 객관적 근거 확보.

## Ⅱ. CBAM의 특징 및 장점

- 핵심 요약 : ATAM 산출물의 재사용과 효용 정량화가 투자 결정의 객관성이라는 장점으로 연결되는 구조.

1. 경제적 정량 분석 : 전략별 비용, 효용, 불확실성을 수치로 다룸 → 기술 판단을 예산 판단으로 연결.
2. 평가의 연속성 : **SEI**(Software Engineering Institute) 설계에서 ATAM의 유틸리티 트리와 품질 시나리오를 입력으로 재사용 → 분석을 처음부터 반복하지 않는 효율.
3. 가치의 정량화 : 응답 수준별 이해관계자 만족도를 **효용 곡선**(Utility Curve)으로 표현 → 품질 개선의 가치 변화 가시화.
4. ROI 기반 순위화 : **아키텍처 전략**(Architectural Strategy)별 효용 증가분 대비 비용, 즉 **ROI**(Return on Investment)의 산출 → 한정된 예산의 최적 배분 근거.
5. 이해관계자 합의 : **시나리오 우선순위화**를 이해관계자 협의로 수행 → 비즈니스 목표와 기술 투자의 정렬.

## Ⅲ. CBAM의 구조 (흐름)

- 핵심 요약 : 시나리오 준비에서 투자 결정까지 이어지는 순차 분석 흐름과 응답 수준의 효용화 구조.
- 수행 절차의 단계별 순서.

```text
[ CBAM 수행 절차 ]

시나리오 수집과 시나리오 우선순위화
   ↓
응답 수준별 효용 곡선 도출
   ↓
아키텍처 전략의 도출
   ↓
전략별 비용·효용·불확실성 산정
   ↓
ROI 기반 투자 우선순위 결정
```

- 효용 곡선은 응답 수준과 만족도 점수의 대응 관계.

```text
[ 효용 곡선 : 응답 시간 예시 ]

최상 응답 수준 → 효용 100
   ↓
목표 응답 수준 → 효용 중간
   ↓
최악 응답 수준 → 효용 0
   (0~100 척도의 만족도 점수)
```

- ROI 산출 : 전략별 효용 증가분을 도입 비용으로 나눈 값의 순위로 투자 대상을 선정.

## Ⅳ. CBAM과 ATAM의 비교

- 핵심 요약 : 품질속성의 절충을 검증하는 ATAM과 비용·편익의 순위를 매기는 CBAM은 순차 연계의 상하 단계.

| 비교 축 | CBAM | ATAM |
| --- | --- | --- |
| 평가 초점 | 비용·편익의 경제성 분석 | 품질속성 절충점(Trade-off)·리스크의 식별 |
| 핵심 질문 | 어떤 전략에 얼마를 투자할 것인가 | 아키텍처가 품질 목표를 충족하는가 |
| 분석 입력 | ATAM의 유틸리티 트리·품질 시나리오 | 비즈니스 드라이버·아키텍처 문서 |
| 주요 산출물 | 전략별 ROI 순위와 투자 로드맵 | 리스크·비리스크 목록과 절충점 |
| 수행 위치 | ATAM 이후의 후속 단계 | 설계 초기의 선행 단계 |

## Ⅴ. CBAM의 한계와 방안

- 핵심 요약 : 효용 산정의 주관성, 전략 간 상호작용 누락, 1회성 분석의 진부화가 신뢰성의 제약.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 효용·비용 산정의 주관성 | 이해관계자별 가치 판단의 편차 → 순위 왜곡 | **AHP**(Analytic Hierarchy Process)로 가중치 도출, 과거 실적과의 교차 검증 | 추정치와 실적의 차이율 |
| 전략 간 상호작용 미반영 | 전략 병행 시 시너지·충돌의 단순 합산 → 효용의 과대·과소 평가 | 전략 종속성 검토, 민감도 분석 선행 | 종속성 검토 완료율 |
| 효용의 진부화 | 요구·기술 변화 이후 1회성 결과의 잔존 → 잘못된 투자의 지속 | 릴리스 단위의 재분석 주기 운영 | 재분석 주기 준수율 |

## Ⅵ. 아키텍처 투자 결정에 대한 기술사적 제언

- 핵심 요약 : 아키텍처 투자의 경제적 근거를 조직의 투자 결정 체계에 제도화하는 방향.
- 제도 : 아키텍처 개선 투자의 승인 근거로 CBAM 산출물인 ROI 순위표의 제출을 표준 절차화.
- 조직 : 아키텍처 검토 조정 기구가 이해관계자 가중치와 평가 절차의 공정성을 관리.
- 확산 : 기술 부채 상환 투자도 효용 환산 대상에 포함하는 투자 거버넌스의 확대.

## Ⅶ. 결론

- 핵심 요약 : CBAM은 아키텍처 의사결정을 기술 판단에서 경제적 합리성의 영역으로 확장하는 프레임워크.
- ATAM의 기술 검증과의 결합이 투자 판단의 설득력을 완성하는 조합.
