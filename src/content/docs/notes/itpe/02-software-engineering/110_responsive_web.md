## 30초 인출

- 본질: 반응형 웹은 하나의 웹 페이지가 화면 크기에 따라 레이아웃을 자동으로 바꾸어 여러 기기에서 알맞게 보이도록 하는 설계 방식
- 메커니즘: 뷰포트 설정 위에 유동형 그리드(비율 단위)·유연한 이미지·미디어 쿼리를 적용해 화면 폭 기준으로 스타일을 전환
- 통찰: 큰 화면 기준으로 만든 뒤 줄이면 모바일에서 불필요한 자원을 내려받아 느려지므로 작은 화면 기준으로 먼저 설계하고 화면이 커질 때 확장하며 이미지도 화면에 맞게 제공

<details>
<summary>핵심 용어</summary>

- **반응형 웹(Responsive Web Design)** : 화면 크기에 따라 하나의 페이지가 레이아웃을 바꾸는 설계 방식
- **뷰포트(Viewport)** : 브라우저가 페이지를 표시하는 화면 영역
- **유동형 그리드(Fluid Grid)** : 픽셀 대신 비율 단위로 폭을 정하는 레이아웃
- **미디어 쿼리(Media Query)** : 화면 폭 등 조건에 따라 CSS를 적용하는 규칙
- **적응형 웹(Adaptive Web Design)** : 기기 유형별로 미리 정한 레이아웃을 제공하는 방식
- **모바일 우선(Mobile First)** : 작은 화면 기준으로 먼저 설계하고 점진적으로 확장하는 접근

</details>

## 2~4교시 25점 답안

## Ⅰ. 반응형 웹의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **반응형 웹** 은 하나의 페이지가 화면 크기에 따라 레이아웃을 바꾸는 웹 설계 방식 |
| 목적 | 다양한 기기에서의 일관된 사용성과 유지보수 부담 감소 |

## Ⅱ. 기기별 별도 제작과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 단일 코드 | 하나의 HTML·URL로 여러 기기 대응 |
| 유동 레이아웃 | 화면 폭에 따른 배치 변화 |
| 조건 기반 스타일 | 미디어 쿼리로 스타일 전환 |

## Ⅲ. 구성요소와 동작

### 구성요소

```text
반응형 웹
    ├─ 뷰포트 설정 ── 기기 화면 폭에 맞춘 표시
    ├─ 유동형 그리드 ── % 등 비율 단위 레이아웃
    ├─ 유연한 이미지 ── 컨테이너 폭에 맞춰 축소
    └─ 미디어 쿼리 ── 화면 폭 조건별 CSS 전환
```

### 확대: 화면 폭에 따른 레이아웃 전환

```text
좁은 화면: 1열(세로 배치)
    ↓ 폭 증가 (미디어 쿼리 중단점)
중간 화면: 2열
    ↓
넓은 화면: 3열 + 사이드 영역
```

## Ⅳ. 방식의 비교

| 구분 | 반응형 웹 | 적응형 웹 | 별도 모바일 웹 |
|---|---|---|---|
| 방식 | 하나의 페이지가 연속적으로 변화 | 기기 유형별 고정 레이아웃 | 모바일용 별도 사이트 |
| 유지보수 | 단일 코드 | 레이아웃별 관리 | 이중 관리 |
| 최적화 | 화면 폭 전반 대응 | 기기별 정밀 최적화 | 모바일 최적화 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 큰 화면용 자원을 모바일에서 내려받아 성능 저하 | 모바일 우선 설계와 화면별 이미지 제공(srcset) |
| 복잡한 화면의 작은 화면 표현 곤란 | 콘텐츠 우선순위에 따른 재배치 |
| 기기별 브라우저 차이 | 다양한 기기에서의 시험 |

## Ⅵ. 제언

모바일 화면 기준으로 먼저 설계하고 화면이 커질 때 레이아웃을 확장하며, 이미지는 화면 크기에 맞게 제공

### 모바일 우선 순서

```text
좁은 화면 기준 스타일 작성
    ↓
미디어 쿼리로 넓은 화면 확장
    ↓
화면별 이미지 제공
```

### 확대: 이미지 제공

```text
srcset으로 화면 폭별 이미지 지정
    ↓
모바일은 작은 이미지, 큰 화면은 큰 이미지 내려받음
```

### 선택 근거: 큰 화면 우선 설계와의 비교

| 구분 | 큰 화면 우선 | 제언: 모바일 우선 |
|---|---|---|
| 모바일 자원 | 불필요 자원 다운로드 | 필요한 자원만 |
| 성능 | 저하 | 유지 |
| 확장 | 축소 재작업 | 점진 확장 |
