## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 자료구조·알고리즘 → **최소 신장 트리(Minimum Spanning Tree)**

## 30초 인출

- 본질: 최소 신장 트리는 가중치 그래프의 모든 정점을 순환 없이 연결하는 트리 중 간선 가중치 합이 가장 작은 것
- 메커니즘: 크루스칼은 가중치가 작은 간선부터 순환을 만들지 않는 것만 선택하고, 프림은 한 정점에서 시작해 연결된 트리에서 가장 싼 간선으로 정점을 확장
- 통찰: 간선이 적은 희소 그래프는 간선을 정렬하는 크루스칼이, 간선이 많은 조밀 그래프는 정점 중심으로 확장하는 프림이 유리하므로 그래프 밀도로 선택

<details>
<summary>핵심 용어</summary>

- **신장 트리(Spanning Tree)** : 그래프의 모든 정점을 포함하며 순환이 없는 부분 그래프
- **최소 신장 트리(MST)** : 간선 가중치 합이 최소인 신장 트리
- **크루스칼 알고리즘** : 가중치 순으로 간선을 골라 순환을 만들지 않으면 추가하는 알고리즘
- **프림 알고리즘** : 연결된 트리를 한 정점씩 확장하며 가장 싼 간선을 고르는 알고리즘
- **유니온 파인드(Union-Find)** : 두 정점이 같은 집합인지 확인해 순환을 검사하는 자료구조

</details>

## 2~4교시 25점 답안

## Ⅰ. 최소 신장 트리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **최소 신장 트리** 는 모든 정점을 순환 없이 연결하는 트리 중 가중치 합이 최소인 트리 |
| 목적 | 네트워크·배선 등의 최소 비용 연결 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 간선 수 | 정점 수 − 1개 |
| 순환 없음 | 트리 구조 |
| 최소 비용 | 연결 비용의 합이 최소 |

## Ⅲ. 알고리즘 동작 예

```text
   A ──2── B
   │╲      │       간선: A-B 2, A-C 3, B-C 1, B-D 4, C-D 5
  3│ ╲1    │4      (예시 값)
   C ──5── D
```

| 순서 | 크루스칼(가중치 오름차순) | 선택 |
|---|---|---|
| 1 | B-C (1) | 선택 |
| 2 | A-B (2) | 선택 |
| 3 | A-C (3) | 순환(A-B-C)이므로 제외 |
| 4 | B-D (4) | 선택 → 4개 정점 연결 완료, 합 7 |

## Ⅳ. 크루스칼과 프림의 비교

| 구분 | 크루스칼 | 프림 |
|---|---|---|
| 방식 | 간선 중심(가중치 정렬) | 정점 중심(트리 확장) |
| 순환 검사 | 유니온 파인드 | 이미 트리에 포함된 정점 확인 |
| 시간 | O(E log E) | O(E log V) |
| 유리한 그래프 | 희소 | 조밀 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 연결되지 않은 그래프에서는 신장 트리가 없음 | 연결 성분별 최소 신장 숲 구성 |
| 간선 정렬·순환 검사의 비용 | 유니온 파인드 사용 |
| 가중치가 같은 간선으로 MST가 여러 개 | 규칙(순서)으로 선택을 고정 |

## Ⅵ. 제언

그래프의 밀도를 확인해 희소하면 크루스칼, 조밀하면 프림을 선택

```text
간선 수 E vs 정점 수 V
    ├─ E가 작음(희소) → 크루스칼
    └─ E가 큼(조밀) → 프림
```

| 구분 | 항상 한 알고리즘 | 제언: 밀도별 선택 |
|---|---|---|
| 희소 그래프 | 프림은 불리할 수 있음 | 크루스칼 |
| 조밀 그래프 | 크루스칼은 정렬 부담 | 프림 |
