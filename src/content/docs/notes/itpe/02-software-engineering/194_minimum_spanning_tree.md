## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 그래프 알고리즘·최적화 → 최소 신장 트리(Minimum Spanning Tree)

## 지식 위치

소프트웨어공학 > 알고리즘 > 그래프 알고리즘 > 최소 신장 트리

## 30초 인출

- 본질: 가중 무방향 연결 그래프에서 모든 정점($V$)을 사이클(Cycle) 없이 정확히 $V-1$개의 간선으로 연결하면서, 간선들의 가중치 합을 최소화한 트리 구조
- 메커니즘: 탐욕(Greedy) 알고리즘 원리 기반 → 간선 중심의 크루스칼(Kruskal: 간선 정렬 후 Union-Find로 사이클 검사) 및 정점 중심의 프림(Prim: 임의 정점에서 Min-Heap으로 최소 간선 확장)으로 분기 실행
- 통찰: 그래프 내 음수 가중치 간선이 존재하더라도 사이클만 배제하면 정상 동작하나, 비연결 그래프일 경우 단일 트리가 성립하지 않으므로 연결 요소 확인 후 최소 신장 포리스트(MSF)로의 분기 처리 필수

<details>
<summary>핵심 용어</summary>

- **신장 트리 (Spanning Tree)** : 그래프의 모든 정점($V$개)을 포함하면서 사이클이 존재하지 않는 트리 (간선의 수는 반드시 $V-1$개)
- **최소 신장 트리 (MST: Minimum Spanning Tree)** : 가능한 여러 신장 트리 중에서 간선 가중치의 총합이 최소인 트리
- **크루스칼 알고리즘 (Kruskal's Algorithm)** : 모든 간선을 가중치 오름차순으로 정렬한 뒤, 사이클을 형성하지 않는 간선을 그리디하게 $V-1$개 선택하는 알고리즘
- **프림 알고리즘 (Prim's Algorithm)** : 임의의 시작 정점에서 출발하여 현재 형성된 트리 집합과 연결된 인접 간선 중 최소 가중치 간선을 우선순위 큐로 선택 확장하는 알고리즘
- **서로소 집합 (Union-Find / Disjoint Set)** : 크루스칼에서 선택한 간선이 사이클을 형성하는지 판별하기 위해 노드들의 루트 부모를 찾고(Find), 집합을 합치는(Union) 고속 자료구조
</details>

## 2~4교시 예상문제 (25점)

> 그래프의 최소 신장 트리(MST) 개념과 2대 대표 알고리즘(크루스칼, 프림)의 동작 원리 및 시간복잡도를 비교하고, Union-Find 자료구조를 활용한 사이클 판별 메커니즘과 네트워크 망 설계 실무 적용 방안을 제시하시오. (25점)

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 연결된 가중 무방향 그래프 $G=(V, E)$에서 모든 정점을 포함하고 사이클이 없도록 연결한 부분 그래프(Spanning Tree) 중 간선 가중치(비용)의 총합이 최소인 부분 트리 |
| 목적 | 통신 케이블 배선 비용 최소화, 전력망/도로망/파이프라인 최적 연결망 구축, 클러스터링 및 이미지 분할 알고리즘의 기초 구조 제공 |

## Ⅱ. 핵심 특징

| 특징 | 세부 내용 |
|---|---|
| 정점과 간선의 수학적 관계 | $V$개의 정점을 모두 포함하기 위해 반드시 정확히 $V-1$개의 간선만 선택 (비순환 트리 구조) |
| 탐욕적 선택 속성 (Greedy) | 매 순간 국소적으로 가장 가중치가 작은 간선을 선택하더라도 전체적으로 전역 최적해(Global Optimum) 보장 |
| 절단 속성 (Cut Property) | 그래프를 임의의 두 정점 집합으로 분할(Cut)할 때, 두 집합을 연결하는 간선 중 가중치가 최소인 간선은 반드시 MST에 포함 |
| 해의 다수성 (Multiplicity) | 동일한 가중치를 갖는 간선이 존재할 경우 서로 다른 형태의 MST가 복수 개 도출 가능 (가중치 합은 동일) |

인프라 망 설치 비용을 최소화하면서 100% 연결성을 보장하는 그래프 공학의 대표적 최적화 모델.

## Ⅲ. 체계·프로세스

```text
[크루스칼(Kruskal) 알고리즘 프로세스: 간선 중심]
  1. 모든 간선을 가중치 오름차순 정렬 (O(E log E))
  2. Union-Find 초기화 (각 정점을 독립 집합으로 설정)
  3. 간선 (u, v, w)를 순차 순회:
     ├─ Find(u) != Find(v) ──► 사이클 없음 ──► 간선 채택, Union(u, v) 수행
     └─ Find(u) == Find(v) ──► 사이클 발생 ──► 간선 기각 (Skip)
  4. 채택된 간선 수가 V - 1 개에 도달하면 즉시 종료

[프림(Prim) 알고리즘 프로세스: 정점 중심]
  1. 임의의 시작 정점 s 선택 (visited[s] = true)
  2. s와 연결된 모든 간선을 Min-Heap(우선순위 큐)에 Push
  3. 큐가 빌 때까지 반복:
     - 큐에서 최소 가중치 간선 (u, v, w) Pop
     - if (visited[v] == true) continue; // 이미 트리에 포함된 정점이면 스킵
     - visited[v] = true, 간선 채택
     - 정점 v와 연결된 미방문 간선들을 Min-Heap에 Push
  4. 채택된 간선 수가 V - 1 개에 도달하면 완료
```

간선을 정렬하여 독립 집합을 병합하는 크루스칼과 특정 정점에서 출발하여 트리를 동심원 확장하는 프림의 상반된 프로세스.

## Ⅳ. 종류·비교

| 비교 항목 | 크루스칼 알고리즘 (Kruskal) | 프림 알고리즘 (Prim) |
|---|---|---|
| **접근 방식** | **간선(Edge) 중심** 그리디 탐색 | **정점(Vertex) 중심** 그리디 탐색 |
| **시간 복잡도** | $O(E \log E)$ 또는 $O(E \log V)$ | $O((V + E) \log V)$ (인접리스트+힙) / $O(V^2)$ (인접행렬) |
| **핵심 자료구조** | **Union-Find (경로 압축 Disjoint Set)** | **우선순위 큐 (Min-Heap)** |
| **동작 특징** | 가중치가 작은 간선부터 전역 선택 (숲이 합쳐져 트리 완성) | 시작 노드부터 트리를 점진적으로 확장 (항상 단일 트리 유지) |
| **유리한 그래프** | **희소 그래프 (Sparse Graph: $E \ll V^2$)** | **밀집 그래프 (Dense Graph: $E \approx V^2$)** |
| **사이클 검사** | 간선 연결 전 Union-Find 부모 노드 일치 여부 검사 | 이미 방문한 정점인지(`visited[]`) 여부로 자동 검사 |

### MST vs 최단경로(다익스트라) 비교

| 비교 항목 | 최소 신장 트리 (MST) | 최단 경로 (Shortest Path: 다익스트라) |
|---|---|---|
| **목적** | **모든 정점을 연결하는 총 간선 비용의 합을 최소화** | **특정 출발점에서 특정 목적지까지의 경로 비용 최소화** |
| **결과 형태** | 그래프 전체를 덮는 무방향 트리 구조 | 단일 출발점 중심의 방향성 최단경로 트리(SPT) |
| **음수 가중치** | **허용** (사이클만 없으면 음수 간선도 정상 처리) | **불허** (비음수 가중치 필수, 음수 시 오답) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 그래프가 연결되지 않은 비연결 그래프(Disconnected Graph)인 경우 $V-1$개 간선 연결 불가 | 탐색 전 BFS/DFS로 연결 요소를 먼저 식별하고, 각 컴포넌트별로 최소 신장 포리스트(MSF)를 도출 |
| 크루스칼 수행 시 Union-Find의 편중 트리 현상으로 인한 Find 연산 시간 지연 | 경로 압축(Path Compression) 및 rank 기반 Union 최적화를 적용하여 아커만 역함수 수준($O(\alpha(V)) \approx O(1)$)으로 단축 |
| 프림 수행 시 밀집 그래프($E \approx V^2$)에서 힙 오버헤드로 인한 성능 저하 | 우선순위 큐 대신 단순 1차원 배열 순회 방식($O(V^2)$) 또는 피보나치 힙(Fibonacci Heap) 채택 |

## Ⅵ. 제언

통신망 및 데이터센터 백본 설계 시 MST를 기반으로 최소 비용의 기본 물리 토폴로지를 구축하되, 단일 링크 단절 시 전체 망 마비를 방지하기 위한 이중화 링크(K-Connected Graph) 및 스패닝 트리 프로토콜(STP)과의 융합 설계 권장.

```text
[통신망 최적화 및 복원력 설계 파이프라인]
  노드/링크 가중치 수집 → 희소도 평가 후 MST 알고리즘(크루스칼/프림) 적용 → 백본망 확정 → 장애 대비 백업 링크 보강
```

| 검증 단계 | 기본 설계 단계 (비용 최적화) | 고가용성 보강 단계 (장애 복원력) |
|---|---|---|
| 적용 기술 | MST (Kruskal / Prim) | IEEE 802.1D/w RSTP (Rapid Spanning Tree Protocol) |
| 달성 목표 | 망 구축 총비용(CAPEX) 최소화 | 브리지 루프 방지 및 링크 단절 시 서브초 단위 자동 절체 |
