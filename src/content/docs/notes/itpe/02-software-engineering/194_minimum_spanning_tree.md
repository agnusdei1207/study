## 핵심 그림
```text
[ 크루스칼(Kruskal) : 간선 중심 ]          [ 프림(Prim) : 정점 중심 ]
1. 모든 간선을 가중치순 오름차순 정렬        1. 임의의 시작 정점 선택 (트리 집합 T)
2. 가장 작은 간선부터 순차 선택              2. T에 속한 정점과 연결된 외부 간선 중
3. 사이클 발생 시 제외 (Union-Find)           최소 비용 간선 선택하여 T에 추가 (Heap)
4. 간선 수 = (V-1) 일 때 종료                3. 모든 정점이 T에 포함될 때까지 반복

    ( 1 ) ── 1 ── ( 2 )                        ( 1 ) ── 1 ── ( 2 )
      │ ＼       ／ │                            │             │
      4   2     3   5           ──>              │             3
      │     ＼ ／   │                            │             │
    ( 3 ) ── 6 ── ( 4 )                        ( 3 ) ─── ── ( 4 )
     [ 원본 가중치 그래프 ]                        [ 최소신장트리 (MST) 결과 ]
```

## 핵심 용어
- 신장 트리(Spanning Tree): 그래프 내의 모든 정점을 포함하면서, 사이클이 형성되지 않는 연결 부분 그래프 (정점 $V$개일 때 간선은 정확히 $V-1$개)
- 최소신장트리(MST, Minimum Spanning Tree): 가능한 여러 신장 트리들 중에서 간선들에 부여된 가중치의 총합이 최소가 되는 트리
- 서로소 집합(Disjoint-Set / Union-Find): 공통 원소가 없는 부분 집합들을 관리하며, 크루스칼 알고리즘에서 간선 추가 시 사이클 형성 여부를 $O(\alpha(V))$ 시간에 판별하는 자료구조
- 경로 압축(Path Compression): Union-Find 연산 시 `find` 함수가 루트 노드를 재귀적으로 찾으면서 모든 중간 노드의 부모를 루트로 직접 갱신하여 트리 높이를 1로 평탄화하는 최적화 기법
- 탐욕법(Greedy Method): 각 단계마다 당장 눈앞에 보이는 가장 작은 비용의 간선을 선택하는 최적화 전략 (MST에서는 탐욕 선택이 전체 최적해를 보장함)

## 핵심 통찰
- MST는 '최단 경로(Shortest Path)'와 명확히 구분되어야 함. 최단 경로는 두 정점 간의 이동 비용 최소화(다익스트라)이지만, MST는 '전체 네트워크를 연결하는 총비용의 최소화'임
- 크루스칼은 모든 간선을 한꺼번에 정렬해 두고 작은 간선부터 집어넣는 '간선 중심(Edge-centric)' 접근이므로 간선 수가 적은 희소 그래프(Sparse Graph, $E \ll V^2$)에 절대적으로 유리함
- 프림은 하나의 정점에서 시작하여 눈덩이를 굴리듯 트리를 점진 확장하는 '정점 중심(Vertex-centric)' 접근이므로 간선 수가 매우 많은 밀집 그래프(Dense Graph, $E \approx V^2$)에서 단순 배열 구현 시 $O(V^2)$로 크루스칼보다 우수함

## 이웃 토픽과 구분
| 비교 항목 | 크루스칼 (Kruskal) | 프림 (Prim) | 다익스트라 (Dijkstra) |
| :--- | :--- | :--- | :--- |
| **핵심 목적** | 전체 네트워크 연결 총비용 최소화 (MST) | 전체 네트워크 연결 총비용 최소화 (MST) | 단일 시작점으로부터 각 노드별 최단 거리 |
| **탐색 기준** | 간선 중심 (Edge-centric) | 정점 중심 (Vertex-centric) | 정점 중심 (Vertex-centric) |
| **핵심 자료구조**| 간선 배열 정렬 + Union-Find | 우선순위 큐 (Min-Heap) | 우선순위 큐 (Min-Heap) |
| **시간 복잡도** | $O(E \log E)$ 또는 $O(E \log V)$ | $O(E \log V)$ (힙) / $O(V^2)$ (배열) | $O((V + E) \log V)$ |
| **그래프 적합성**| 희소 그래프 ($E \ll V^2$)에 최적 | 밀집 그래프 ($E \approx V^2$)에 최적 | 가중치가 양수인 모든 그래프 |

## 문제·원인·대책
| 문제상황 | 원인 | 기술적 대책 |
| :--- | :--- | :--- |
| **크루스칼 수행 시 간선 정렬 시간 과다** | 간선 수가 수백만 개인 대규모 밀집 그래프에서 $O(E \log E)$ 정렬 비용 폭증 | 밀집 그래프의 경우 간선 정렬이 불필요한 프림(Prim) 알고리즘으로 전환 |
| **간선 추가 시 사이클 판별 지연** | 단순 트리 순회(DFS/BFS)로 매번 사이클 검사를 수행하여 $O(V)$ 추가 소요 | Union-Find 자료구조에 Rank 기반 합치기(Union-by-Rank)와 경로 압축(Path Compression) 적용 |
| **프림 알고리즘의 힙 업데이트 오버헤드** | C++ STL이나 Java 표준 우선순위 큐에서 기존 키 값 감소(Decrease-Key) 미지원 | 방문 체크 배열을 두고 더 짧은 거리가 나올 때마다 신규 원소를 푸시(Lazy Deletion) 기법 적용 |

## 내 의견
- 최소신장트리는 단순한 이론 알고리즘에 그치지 않고, 통신사 광케이블 전국망 백본망 설계, 상수도/가스관 배관망 최적화, 집적회로(VLSI) 배선 설계에서 수천억 원의 인프라 공사 비용을 절감하는 핵심 설계 도구임
- 현대 데이터 엔지니어링 및 머신러닝 분야에서는 고차원 데이터 클러스터링(단일 연결 군집화, Single-linkage Clustering)을 수행할 때 MST를 구축한 뒤 가장 가중치가 큰 간선을 끊어내는 방식으로 자연스러운 클러스터를 분할하는 기법으로 널리 응용됨
- 알고리즘 선택 시에는 사전에 그래프의 정점($V$) 대비 간선($E$)의 비율을 파악하여 $E \approx V$ 수준이면 크루스칼을, $E \approx V^2$ 수준이면 피보나치 힙 기반의 프림을 선택하는 적응형 아키텍처를 구성해야 함
