## 30초 인출

- **본질** : 최소 신장 트리(MST)는 연결 가중 무방향 그래프의 모든 정점을 사이클 없이 연결하면서 간선 가중치 합을 최소화한 트리
- **메커니즘** : 간선 가중치가 작은 연결을 선택하되 사이클을 만들지 않고 모든 정점을 연결
- 통찰: 한계: 값싼 간선만 계속 고르면 사이클이 생기거나 일부 정점이 빠질 수 있음 → 방안: 연결·비순환 조건을 지키며 V−1개 간선을 선택

- **최소 신장 트리(Minimum Spanning Tree, MST)** : 연결 가중 무방향 그래프의 모든 정점을 잇는 신장 트리 중 간선 가중치 합이 최소인 트리
- **크루스칼 알고리즘(Kruskal's Algorithm)** : 간선을 가중치 순으로 살피며 서로 다른 연결 요소를 잇는 간선을 선택하는 알고리즘
- **프림 알고리즘(Prim's Algorithm)** : 한 정점에서 시작해 현재 트리와 바깥 정점을 잇는 최소 가중치 간선을 반복 선택하는 알고리즘
- **Union-Find** : 원소가 속한 집합을 찾고 서로 다른 집합을 합치는 자료구조

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **최소 신장 트리** : 연결 가중 무방향 그래프의 모든 정점을 잇는 최소 가중치 신장 트리 |
| 목적 | 모든 정점의 연결을 유지하면서 전체 간선 비용을 최소화 |

## Ⅱ. 최소 신장 트리의 특징

| 특징 | 의미 |
|---|---|
| 모든 정점 연결 | V개 정점을 하나의 연결 요소로 포함 |
| 비순환 | V−1개 간선으로 사이클 없이 연결 |
| 전체 비용 최소 | 선택 간선 가중치 합의 최소화 |

## Ⅲ. MST 구성과 두 탐욕 선택 체계

```text
연결 그래프의 정점 V개
        ↓ 최소 가중 간선 채택
서로 다른 연결 요소만 이어 붙임
        ↓ V−1개 선택·사이클 없음
모든 정점 연결 → 최소 가중치 합 검토
```

신장 트리는 모든 정점을 포함하는 트리이므로 간선 수가 V−1개. 입력이 연결되지 않으면 전체 그래프의 신장 트리는 존재하지 않으며, 각 연결 요소별 최소 신장 포리스트를 구할 수 있음.

### 크루스칼 알고리즘

```text
모든 간선을 가중치 오름차순 정렬
    ↓
다음 간선의 양 끝 정점이 다른 집합인가?
  ├─ 예 → 간선 채택·집합 합치기
  └─ 아니오 → 간선 제외
    ↓
채택 간선이 V−1개면 완료, 아니면 다음 간선 검사
```

Union-Find로 양 끝 정점의 연결 집합을 확인해 사이클을 방지. 정렬 비용이 중심이므로 일반적인 비교 정렬 기준 시간은 O(E log E).

### 프림 알고리즘

```text
임의의 정점에서 시작
    ↓
현재 트리와 밖의 정점을 잇는 최소 간선 선택
    ↓
새 정점 편입·트리 확장
    ↓
모든 정점이 편입될 때까지 반복
```

우선순위 큐·인접 리스트 등 구현 자료구조에 따라 시간 복잡도가 달라짐. 단순 인접 행렬 구현은 O(V²), 이진 힙과 인접 리스트 구현은 통상 O(E log V).

## Ⅳ. 크루스칼·프림 알고리즘 비교

| 구분 | 크루스칼 | 프림 |
|---|---|---|
| 선택 관점 | 전체 간선을 전역 정렬 | 현재 트리의 경계 간선 |
| 핵심 보조 구조 | Union-Find | 우선순위 큐 또는 인접 행렬 |
| 구현 검토 | 간선 목록이 주어지는 경우 편리 | 시작점에서 확장하는 표현과 잘 맞음 |

두 알고리즘 모두 음수 가중치 간선이 있어도 최소 신장 트리를 구할 수 있음. 동률 간선이 있을 때 최소 신장 트리는 여러 개일 수 있음.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 입력 그래프가 비연결인데 하나의 트리를 요구 | 연결 요소 확인 후 불가능 조건 또는 최소 신장 포리스트로 요구 정리 |
| 사이클 간선을 중복 채택 | 크루스칼은 Union-Find, 프림은 트리 밖 정점만 편입하도록 검증 |
| 동일 가중치에서 결과가 달라져 재현성 혼란 | 가중치 외 보조 정렬 기준을 정해 결과 재현성 확보 |

## Ⅵ. 제언

우선 실행: 결과물에 총 가중치와 함께 연결성, V−1 간선, 비순환 조건을 자동 검증하는 체크를 포함.
