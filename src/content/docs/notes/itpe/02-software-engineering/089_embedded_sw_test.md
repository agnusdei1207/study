## 30초 인출

- **임베디드 소프트웨어 테스트**: 하드웨어와 결합하는 소프트웨어의 기능과 실시간 동작을 확인하는 시험
- **XiL(X-in-the-Loop)**: 제어 대상 모델·코드·프로세서·하드웨어를 시뮬레이션 환경에 연결해 검증하는 방식
- **MIL(Model-in-the-Loop)**: 제어 알고리즘 모델을 시뮬레이션 환경에서 검증하는 방식
- **SIL(Software-in-the-Loop)**: 호스트 환경에서 소프트웨어 코드를 실행해 검증하는 방식
- **PIL(Processor-in-the-Loop)**: 타깃 프로세서에서 코드를 실행해 프로세서 의존 동작을 검증하는 방식
- **HIL(Hardware-in-the-Loop)**: 실제 제어기를 실시간 플랜트 시뮬레이터와 연결해 검증하는 방식
- **WCET(Worst-Case Execution Time)**: 지정된 태스크가 실행 조건에서 소요하는 최악 실행 시간의 상한
- **FIT(Fault Injection Testing)**: 오류나 고장 조건을 의도적으로 주입해 시스템 반응을 확인하는 시험
- **ISO 26262**: 도로 차량 전기·전자 시스템의 기능안전 표준 시리즈
- **DO-178C(Software Considerations in Airborne Systems and Equipment Certification)**: 항공기 탑재 소프트웨어의 개발·검증 고려사항을 다루는 RTCA 문서

## 2~4교시 25점 답안

### Ⅰ. 임베디드 소프트웨어 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 하드웨어와 결합하는 소프트웨어의 기능·시간·환경 반응을 확인하는 검증 활동 |
| 목적 | 실제 장비 적용 전에 결함을 발견하고 요구된 동작과 시간 조건을 확인 |

### Ⅱ. X-in-the-Loop 유형별 검증 대상과 환경

| 유형 | 시험 대상 | 시험 환경 | 확인 초점 |
|---|---|---|---|
| **MIL** | 알고리즘 모델 | 모델 시뮬레이터 | 요구 동작 및 알고리즘 경계 조건 |
| **SIL** | 호스트에서 실행하는 코드 | 개발 호스트 | 모델 결과와 코드 실행 결과의 일치 여부 |
| **PIL** | 타깃 프로세서에서 실행하는 코드 | 실제 타깃 또는 프로세서 모사 환경 | 명령어·자료형 등 프로세서 의존 동작, 실행 시간 |
| **HIL** | 실제 제어기 | 실시간 플랜트 시뮬레이터와 입출력 인터페이스 | 제어기 입출력과 실시간 상호작용 |

유형은 시험 대상과 환경을 구분하는 기준이며, 모든 프로젝트가 MIL→SIL→PIL→HIL 순서를 의무적으로 거치는 것은 아님.

### Ⅲ. 시험 조건과 관측 항목

| 관점 | 설계 항목 | 관측 근거 |
|---|---|---|
| 기능 | 요구사항별 정상·경계·오류 입력 | 실제 출력과 기대 결과의 비교 |
| 실시간성 | 태스크 주기·데드라인·부하 조건 | 계측 실행 시간과 데드라인 준수 여부 |
| 인터페이스 | 센서·액추에이터·통신 입력 및 출력 | 신호 값·갱신 시점·오류 반응 |
| 안전 동작 | 프로젝트 안전 요구에 포함된 오류 조건 | 안전 상태 전이와 복구 동작 |

### Ⅳ. 검증 단계 선택과 보완

| 선택 기준 | 우선 검토할 환경 | 적용 이유와 한계 |
|---|---|---|
| 알고리즘과 요구의 빠른 확인 | MIL | 실물 하드웨어 없이 반복하기 쉽지만, 타깃 실행 특성은 확인하지 못함 |
| 생성·구현 코드의 기능 확인 | SIL | 코드 실행 결과를 확인하지만 프로세서 차이를 반영하지 못할 수 있음 |
| 타깃 의존 동작과 시간 확인 | PIL | 타깃 프로세서 특성을 반영하나 실제 제어기 입출력 전체를 재현하지는 않음 |
| 제어기와 플랜트 상호작용 확인 | HIL | 실제 제어기 인터페이스를 시험하지만 장비 구축·운영 비용과 시험 범위 제약 고려 필요 |

### Ⅴ. 적용 제언

| 한계 | 해결 방안 |
|---|---|
| 시뮬레이션 결과만으로 실제 하드웨어 동작을 단정할 위험 | 요구·위험·장비 조건에 따라 시험 환경을 선택하고, 상위 환경에서 확인하지 못한 항목을 별도 검증으로 보완 |
