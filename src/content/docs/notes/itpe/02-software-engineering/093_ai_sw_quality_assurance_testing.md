## Ⅰ. AI SW 품질보증 테스트의 개요

- **개념** : 머신러닝/딥러닝 알고리즘 및 대형 언어 모델(LLM)이 내재된 인공지능 기반 소프트웨어의 비결정론적(Non-deterministic) 특성을 검증하기 위해, 데이터 품질, 모델 성능, 강건성(Robustness), 공정성(Fairness), 안전성, 설명가능성을 체계적으로 검증하는 차세대 품질보증(QA) 엔지니어링 체계.
- **배경 및 필요성** : 전통적 규칙 기반 코딩과 달리 AI는 데이터 학습에 의해 내부 가중치가 결정되므로, 기존의 코드 커버리지나 입출력 매칭 테스트로는 오작동, 적대적 공격 취약점, 데이터 편향을 검출할 수 없는 한계 극복.
- **국제 표준** : ISO/IEC 42001 (인공지능 경영시스템), ISO/IEC 24029 (신경망 강건성 평가), ISO/IEC 25059 (AI 시스템 품질 모델).

## Ⅱ. AI SW 테스트 계층 구조 및 뉴런 커버리지(Neuron Coverage) 메커니즘

```text
   [ 입력 계층 (Input) ] ──> [ 은닉 계층 1 (Hidden 1) ] ──> [ 은닉 계층 2 (Hidden 2) ] ──> [ 출력 계층 (Output) ]
                                   ┌─────────┐                 ┌─────────┐
      [ 입력 x1 ] ───────────────> │ 뉴런 n1 │ ─────────────> │ 뉴런 n3 │ ───────────────> [ 분류 결과 y ]
                                   ├─────────┤                 ├─────────┤
      [ 입력 x2 ] ───────────────> │ 뉴런 n2 │ ─────────────> │ 뉴런 n4 │
                                   └─────────┘                 └─────────┘
   (뉴런 커버리지: 활성화 임계치 t를 초과하여 발화(Firing)된 뉴런 수 / 전체 뉴런 수 x 100%)
```

- **뉴런 커버리지 (DeepXplore 제안)** : 전통적 소프트웨어의 구문 커버리지 개념을 심층신경망(DNN)에 확장한 척도로, 테스트 입력 집합에 의해 특정 활성화 함수 임계값($t$)을 초과하여 출력 신호를 발생시킨 뉴런의 비율 측정.
- **K-다자 뉴런 커버리지 (K-Multisection Neuron Coverage)** : 뉴런의 활성화 값 범위를 $K$개의 구간으로 나누어 각 구간이 골고루 자극되는지 세밀하게 검증.

## Ⅲ. 전통적 SW 테스트와 AI SW 테스트의 비교

| 비교 항목 | 전통적 소프트웨어 테스팅 | AI 기반 소프트웨어 테스팅 |
|---|---|---|
| 프로그램 동작 특성 | 결정론적 (동일 입력 시 항상 동일 출력) | 확률적·비결정론적 (동일 입력에도 모델 상태에 따라 편차) |
| 테스트 오라클 | 사전 정의된 명세서(SRS) 기반 정답 존재 | 정답 판별 난해 (테스트 오라클 문제 -> 메타모픽 기법 활용) |
| 커버리지 지표 | 구문(Statement), 분기(Branch), MC/DC | 뉴런 커버리지, 코너 케이스 커버리지, 데이터 분포 커버리지 |
| 결함의 주요 원인 | 논리적 코딩 오류, 요구사항 오해 | 학습 데이터 편향, 과적합(Overfitting), 데이터 드리프트 |
| 핵심 검증 속성 | 기능 정확성, 시스템 자원 효율성 | 강건성(Robustness), 공정성(Fairness), 안전성, 환각 억제 |

## Ⅳ. 고신뢰성 AI 시스템 구축을 위한 기술사적 제언

- **적대적 공격(Adversarial Attack)에 대한 강건성 검증 자동화** : 인간의 눈에는 보이지 않는 미세한 노이즈(FGSM, PGD 공격)를 입력 영상이나 텍스트에 주입했을 때 AI 모델이 엉뚱한 오분류를 일으키지 않는지 평가하는 적대적 강건성 테스트를 MLOps 파이프라인에 필수 통합.
- **지속적 모니터링을 통한 데이터 및 개념 드리프트(Drift) 감지** : 배포 후 시간이 지남에 따라 실운영 데이터 분포가 학습 데이터와 달라지는 데이터 드리프트 현상을 실시간 탐지하고, 성능 저하 감지 시 자동으로 재학습(Retraining)을 트리거하는 MLOps 라이프사이클 거버넌스 수립.
