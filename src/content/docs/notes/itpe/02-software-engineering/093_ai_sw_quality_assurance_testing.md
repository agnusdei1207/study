## 연관 키워드

- AI(Artificial Intelligence) 품질보증(QA, Quality Assurance), 뉴런 커버리지(Neuron Coverage), 테스트 오라클, 비결정론적(Non-deterministic) 특성
- 메타모픽 테스팅(Metamorphic Testing), 적대적 공격(Adversarial Attack), 데이터 드리프트(Data Drift), MLOps(Machine Learning Operations), ISO/IEC 42001

## Ⅰ. AI SW 품질보증 테스트의 개요

- 핵심 요약 : 학습 데이터에 기반해 동작하는 비결정론적 AI 소프트웨어를 데이터, 모델, 강건성, 공정성 측면에서 검증하는 품질보증 체계.
- 개념 : 머신러닝·딥러닝과 LLM(Large Language Model)이 내재된 인공지능(AI, Artificial Intelligence) 소프트웨어의 **비결정론적** (Non-deterministic) 특성을 검증하기 위해, 데이터 품질, 모델 성능, 강건성, 공정성, 안전성, 설명 가능성을 체계적으로 검증하는 **AI 품질보증** (QA, Quality Assurance) 엔지니어링 체계.
- 배경 및 필요성 : 규칙 기반 코딩과 달리 학습 데이터로 내부 가중치가 정해져, 기존 코드 커버리지와 입출력 대조 테스트로는 오작동, **적대적 공격** (Adversarial Attack)에 대한 취약성, 데이터 편향을 찾기 어려움. 정답을 미리 정하기 어려운 **테스트 오라클** (Test Oracle) 문제도 존재.
- 표준 근거 : 인공지능 경영시스템 국제표준 **ISO/IEC 42001** (ISO: International Organization for Standardization, IEC: International Electrotechnical Commission), 신경망 강건성 평가 ISO/IEC 24029, AI 시스템 품질 모델 ISO/IEC 25059.

## Ⅱ. AI SW 품질보증 테스트의 특징

- 핵심 요약 : 데이터와 모델을 함께 보는 다면 검증과, 뉴런 커버리지 계열의 신경망 확장 지표의 결합.

1. 다면 검증 : 데이터 품질, 모델 성능, 강건성, 공정성, 안전성, 설명 가능성을 함께 검증 → AI 특유 결함의 누락 방지.
2. **뉴런 커버리지** (Neuron Coverage) : 활성화 함수 임계값을 넘어 발화한 뉴런의 비율로 입력 집합의 충분성을 측정 → 구문 커버리지를 심층신경망(DNN, Deep Neural Network)으로 확장한 개념.
3. **K-Multisection Neuron Coverage** : 뉴런 활성 값의 범위를 K개 구간으로 나누어 구간별 자극 여부를 검증 → 활성 분포의 빈틈 확인.
4. **메타모픽 테스팅** (Metamorphic Testing) : 입력을 변형했을 때 출력 사이에 성립해야 하는 관계 속성을 검증 → 정답이 없는 상황에서도 결함 판별 가능.

## Ⅲ. AI SW 테스트의 구조 (흐름)

- 핵심 요약 : 신경망 계층별로 뉴런의 발화를 관찰해 커버리지를 산출하는 구조.

```text
[ 입력 계층 ] x1, x2
   ↓
[ 은닉 계층 1 ] 뉴런 n1, n2 발화 관찰
   ↓
[ 은닉 계층 2 ] 뉴런 n3, n4 발화 관찰
   ↓
[ 출력 계층 ] 분류 결과 y
```

- 발화 기준 : 활성화 함수의 임계값을 넘은 뉴런만 발화로 집계.
- 산출식 : 뉴런 커버리지 = 발화 뉴런 수 / 전체 뉴런 수 × 100%.
- K-Multisection 뉴런 커버리지는 각 뉴런의 활성 값 범위를 K개 구간으로 나누어, 모든 구간이 고르게 자극되었는지 정밀하게 검증.

## Ⅳ. 전통적 SW 테스트와 AI SW 테스트의 비교

- 핵심 요약 : 명세 대조에 기반한 결정론적 검증과, 관계 속성에 기반한 확률적 검증의 패러다임 차이.

```text
[ 전통 SW ]
 명세 → 구현 → 같은 입력 → 같은 출력
 (정답 대조 검증)

[ AI SW ]
 데이터 → 학습 → 같은 입력 → 확률적 출력
 (관계 속성 검증, 메타모픽 테스팅 보완)
```

| 비교 항목 | 전통적 소프트웨어 테스팅 | AI 기반 소프트웨어 테스팅 |
| --- | --- | --- |
| 프로그램 동작 특성 | 결정론적 (같은 입력에 항상 같은 출력) | 확률적·비결정론적 (모델 상태에 따라 출력 편차) |
| 테스트 오라클 | 명세서(SRS, Software Requirements Specification) 기반 정답 존재 | 정답 판별이 어려워 메타모픽 기법으로 보완 |
| 커버리지 지표 | 구문, 분기, MC/DC(Modified Condition/Decision Coverage) | 뉴런 커버리지, 코너 케이스 커버리지, 데이터 분포 커버리지 |
| 결함의 주요 원인 | 논리적 코딩 오류, 요구사항 오해 | 학습 데이터 편향, 과적합(Overfitting), **데이터 드리프트** (Data Drift) |
| 핵심 검증 속성 | 기능 정확성, 자원 효율성 | 강건성(Robustness), 공정성(Fairness), 안전성, 환각 억제 |

## Ⅴ. AI SW 품질보증 테스트의 장점과 한계

- 핵심 요약 : 데이터와 모델의 전 주기 검증이라는 장점 아래, 오라클 부재, 커버리지 한계, 드리프트에 따른 품질 저하라는 한계가 존재.
- 장점 : 데이터 편향과 과적합, 적대적 취약점 등 AI 특유 결함의 체계적 검출, 뉴런 커버리지 계열 지표를 통한 입력 충분성의 정량 평가, MLOps(Machine Learning Operations) 연계로 운영 중 품질 지속 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 비결정론적 특성과 오라클 부재 | 복합 입력의 참값을 사전에 단언하기 어려워 전통 기법으로 결함 판별이 불가능 | 입력 변형 간 관계 속성을 검증하는 메타모픽 테스팅 도입, 여러 모델의 출력을 비교하는 **차등 테스팅** (Differential Testing) 결합 | 관계 속성 위반률 |
| 뉴런 커버리지와 실제 안전성의 상관 한계 | 활성 비율이 높아도 적대적 공격과 코너 케이스 결함을 보증하지 못함 | K-Multisection과 **뉴런 경계 커버리지** (NBC, Neuron Boundary Coverage) 등 세분화 지표 도입, DeepMutation 기반으로 테스트 스위트의 결함 검출력 평가 | 세분화 지표별 커버리지, 적대 입력 오분류율 |
| 운영 중 데이터 드리프트에 따른 품질 저하 | 배포 후 현실 데이터 분포가 바뀌는 개념 드리프트(Concept Drift)로 추론 성능이 급격히 하락 | MLOps 파이프라인에서 데이터·모델 모니터링(Evidently 등) 연동, 성능 저하 감지 시 자동 재학습 트리거 | 입력 분포 변화량, 추론 정확도 추이 |

## Ⅵ. 고신뢰성 AI 시스템 구축을 위한 기술사적 제언

- 핵심 요약 : 적대적 강건성 테스트의 파이프라인 통합과, 드리프트 감지와 재학습을 아우르는 거버넌스 수립.

1. 적대적 강건성 검증은 MLOps 파이프라인의 필수 단계로 포함해야 한다. FGSM(Fast Gradient Sign Method)과 PGD(Projected Gradient Descent) 같은 미세 노이즈 공격으로 입력 영상이나 텍스트를 변형했을 때 오분류가 발생하는지 배포 전에 평가하는 절차가 필요하다.
2. 운영 중 데이터와 개념 드리프트를 실시간으로 탐지하고, 성능 저하가 감지되면 재학습을 트리거하는 거버넌스를 수립하여 모델 수명주기 전체에 품질 책임을 배분하는 체계를 갖추어야 한다.

## Ⅶ. 결론

- 핵심 요약 : AI SW 품질보증은 데이터, 모델, 운영 전 주기를 아우르는 새로운 검증 패러다임.
- 시사점 : 테스트 오라클 대안 기법과 뉴런 커버리지 계열 지표, 운영 모니터링의 결합이 검증의 골격이며, 적대적 강건성 검증 자동화와 드리프트 대응 거버넌스가 고신뢰 AI 서비스의 전제 조건.
