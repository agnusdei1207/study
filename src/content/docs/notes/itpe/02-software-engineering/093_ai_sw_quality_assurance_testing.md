## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 테스트·검증 → **AI SW 품질보증 테스트(뉴런 커버리지 포함)**

## 30초 인출

- 본질: AI SW 품질보증 테스트는 학습으로 동작이 정해지는 인공지능 소프트웨어를 정답 판정이 어려운 조건에서 검증하는 테스트 기법 모음이며 메타모픽·뉴런 커버리지·안전 반경 테스트가 대표
- 메커니즘: 메타모픽은 입력 변화에 따른 출력 관계로, 뉴런 커버리지는 시험 입력이 활성화한 뉴런 비율로, 안전 반경은 예측이 유지되는 입력 교란의 최대 범위로 검증
- 통찰: 코드 커버리지는 모델의 학습된 동작을 대변하지 못하고 정답도 알기 어려우므로 관계 기반·내부 활성 기반·입력 교란 강건성 기반 검증을 함께 적용

<details>
<summary>핵심 용어</summary>

- **메타모픽 테스트(Metamorphic Test)** : 입력을 바꿨을 때 출력 사이에 성립해야 하는 관계로 검증하는 테스트
- **뉴런 커버리지(Neuron Coverage)** : 시험 입력이 활성화시킨 뉴런의 비율. 딥러닝 모델의 시험 충분성 지표
- **안전 반경(Safe Radius)** : 입력 주변에서 모델의 예측이 바뀌지 않는 최대 교란 범위
- **적대적 예제(Adversarial Example)** : 사람이 알아채기 어려운 미세한 교란으로 모델의 예측을 바꾸는 입력
- **테스트 오라클 문제(Test Oracle Problem)** : 입력에 대한 정확한 기대 출력을 알 수 없는 문제

</details>

## 2~4교시 25점 답안

## Ⅰ. AI SW 품질보증 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **AI SW 품질보증 테스트** 는 학습 기반 소프트웨어의 동작을 정답 판정이 어려운 조건에서 검증하는 테스트 기법 |
| 목적 | AI 모델의 신뢰성·강건성 확보 |

## Ⅱ. 전통 소프트웨어 테스트와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 학습된 동작 | 코드가 아닌 데이터로 동작이 결정 |
| 오라클 부재 | 정확한 기대 출력 판정 곤란 |
| 입력 민감성 | 미세한 입력 변화로 예측 변경 |

## Ⅲ. 세 가지 기법의 구조

### 세 기법의 검증 관점

```text
메타모픽 테스트    ── 입력 변형 → 출력 관계 성립?     (관계 기반)
뉴런 커버리지     ── 시험 입력이 뉴런을 얼마나 활성화? (내부 기반)
안전 반경 테스트   ── 입력 교란 반경 안에서 예측 유지?   (강건성 기반)
```

### 확대: 뉴런 커버리지 계산

```text
뉴런 커버리지 = 임계값 이상으로 활성화된 뉴런 수 / 전체 뉴런 수
→ 낮으면 시험 입력이 모델의 일부 동작만 검증
```

## Ⅳ. 기법별 비교

| 구분 | 메타모픽 테스트 | 뉴런 커버리지 테스트 | 안전 반경 최대화 테스트 |
|---|---|---|---|
| 검증 대상 | 입력·출력 관계 | 모델 내부 활성 범위 | 입력 교란에 대한 예측 유지 범위 |
| 기준 | 메타모픽 관계 | 활성화 뉴런 비율 | 안전 반경(교란 최대 범위) |
| 해결하는 문제 | 오라클 문제 | 시험 충분성 판단 | 적대적 예제에 대한 강건성 |
| 예 | 이미지 밝기 조정 후 같은 분류 | 다양한 입력으로 활성 뉴런 확대 | 픽셀 교란 반경 안에서 분류 유지 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 뉴런 커버리지가 높아도 결함 검출 보장 없음 | 다른 기법과 병행 |
| 메타모픽 관계 도출의 어려움 | 도메인별 관계 목록 작성 |
| 안전 반경 계산의 큰 연산 비용 | 핵심 입력·핵심 모델에 적용 |

## Ⅵ. 제언

세 기법을 목적별로 조합해 관계 위반·시험 입력의 활성 범위·교란 강건성을 함께 확인

### 조합 검증 절차

```text
메타모픽 테스트: 관계 위반 케이스 확인
    ↓
뉴런 커버리지: 시험 입력의 다양성 확인·부족 시 입력 추가
    ↓
안전 반경: 핵심 입력의 강건성 확인
```

### 선택 근거: 정확도 시험만과의 비교

| 구분 | 정확도 시험만 | 제언: 세 기법 조합 |
|---|---|---|
| 관계 위반 | 확인 불가 | 메타모픽으로 확인 |
| 시험 충분성 | 판단 곤란 | 뉴런 커버리지 |
| 교란 강건성 | 확인 불가 | 안전 반경 |
