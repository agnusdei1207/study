## 연관 키워드
- Web 2.0, 사용자 생성 콘텐츠, 참여, 플랫폼, 네트워크 효과, API

### Ⅰ. Web 2.0의 개요

- 핵심 요약 : Web 2.0은 웹을 읽기 전용 문서 제공에서 사용자 참여·공유·서비스 플랫폼 중심으로 바라보는 개념적 흐름.
- 개념 : 이용자가 콘텐츠를 만들고 상호 작용 하며 웹 서비스의 가치 형성에 참여하는 웹 이용·사업 모델을 설명하는 용어(**Web 2.0**, Web 2.0).
- 배경 및 필요성 : 브라우저 기술과 연결성의 확대가 개인 게시·협업·플랫폼 서비스를 가능하게 함.
- 주요 목적 : 개방 된 웹 환경에서 참여와 연결 을 통해 콘텐츠·서비스의 공동 가치를 형성.

### Ⅱ. Web 2.0의 특징 및 효과

- 핵심 요약 : 참여와 데이터 재사용, 지속적 서비스 운영이 네트워크 효과와 협업을 지원.

1. 사용자 생성 콘텐츠(UGC, User-Generated Content) : 게시·평가·공유 참여 → 콘텐츠 다양성과 최신성 확대.
2. 집단 지성 : 사용자 상호 작용 과 평판·태깅 → 정보 발견 및 분류 보조.
3. 플랫폼·API : 서비스 기능과 데이터를 연계 → 생태계 확장.
4. 지속적 서비스 : 웹 기반 배포와 점진 개선 → 이용자 피드백의 빠른 반영.

### Ⅲ. 참여형 웹의 흐름 (구조)

- 핵심 요약 : 플랫폼은 참여 입력을 저장·연결·추천하고 사용자 활동이 다시 콘텐츠와 관계망으로 환류.

```text
사용자 생성·수정
   ↓ 게시·태깅·평가
플랫폼 데이터·관계망
   ↓ 검색·추천·API 제공
다른 사용자의 발견·재사용
   ↺ 새 참여와 콘텐츠
```

```text
참여 → 데이터 축적 → 개인화·연결
   ↑                       ↓
   └──── 네트워크 효과 ────┘
```

- Web 2.0은 정식 웹 표준 버전 번호가 아니라 사회·서비스 변화의 설명 용어.

### Ⅳ. Web 1.0·2.0·3.0 비교

- 핵심 요약 : Web 1.0·2.0·3.0의 구분은 엄격한 표준 분류가 아닌 대표적 서술 틀.

| 비교 축 | Web 1.0으로 불리는 초기 웹 | Web 2.0 | Web 3.0으로 불리는 흐름 |
|---|---|---|---|
| 주된 역할 | 게시자 중심 정적 문서 | 참여·공유형 서비스 | 의미 데이터 또는 분산형 서비스 등 다양한 정의 |
| 사용자 | 주로 소비자 | 생산자이자 소비자 | 정의에 따라 참여·데이터 통제 강조 |
| 기술 표현 | HTML 문서·하이퍼링크 | 플랫폼·API·동적 상호 작용 | 시맨틱 웹 또는 블록체인 등 맥락 별 상이 |

### Ⅴ. Web 2.0의 한계와 방안

- 핵심 요약 : 참여형 플랫폼의 편익은 개인 정보 집중·허위 정보·플랫폼 종속 위험과 함께 평가.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 데이터·권한 집중 | 플랫폼의 사용자 활동 축적 | 최소 수집·이동성·데이터 접근 통제 | 최소 수집 준수율 |
| 허위 정보·품질 편차 | 개방 게시와 확산 구조 | 출처 표시·신고·검증·추천 투명성 | 허위 정보 검출·삭제 비율 |
| 네트워크 효과의 고착 | 이용자·콘텐츠가 한 플랫폼에 집중 | 상호 운용 API·데이터 이동 지원 | 데이터 이동 요청 처리율 |
| 참여 편향 | 적극 사용자 만 반영 | 대표성 점검·접근성·다양한 피드백 경로 | 참여 대표성 |

### Ⅵ. 플랫폼 설계 제언

- 핵심 요약 : 서비스 운영 자는 참여 설계와 함께 이용자 권리·콘텐츠 품질·플랫폼 책임을 제품 원칙에 포함.

1. 데이터 책임 자는 목적 제한·보존·삭제·이동 요청 절차를 서비스 설계에 반영.
2. 운영 조직 은 신고·추천 정책의 투명성을 높이고 개방 API의 보안과 호환성 기준을 공개.

### Ⅶ. 결론

- 핵심 요약 : Web 2.0은 사용자를 웹 콘텐츠와 서비스 가치의 참여자로 보는 패러다임 용어.
- 시사점 : 참여 확대가 자동 으로 개방성과 공익을 보장하지 않으므로 플랫폼의 권리·책임 구조가 중요.
