## 연관 키워드

- 최단 경로, 가중 그래프, 간선 완화, 음수 가중치
- 다익스트라(Dijkstra), 벨만-포드(Bellman-Ford), 플로이드-워셜(Floyd-Warshall)

## Ⅰ. 최단 경로 알고리즘의 개요

- 핵심 요약 : 최단 경로 알고리즘은 가중 그래프에서 경로 비용의 합이 최소인 경로를 구하는 그래프 기법의 총칭.
- 개념 : 간선에 비용 값인 가중치를 부여한 **가중 그래프**에서 두 정점 사이의 최소 비용 경로, 즉 **최단 경로** (Shortest Path)를 계산하는 알고리즘군이 **최단 경로 알고리즘** (Shortest Path Algorithm).
- 배경 및 필요성 : 네트워크 라우팅, 지도 경로 안내, 물류 비용 분석에서 연결 관계와 이동 비용을 함께 고려한 경로 판단 필요.
- 주요 목적 : 가중치 조건과 질의 범위에 맞는 정확한 경로와 비용의 산출.

## Ⅱ. 최단 경로 알고리즘의 특징 및 장점

- 핵심 요약 : 간선 완화라는 공통 원리 위에서 가중치 부호·질의 범위에 따른 세 기법이 역할을 분담.

1. 공통 원리 : 경유 경로가 더 짧을 때 거리값을 갱신하는 **간선 완화** (Edge Relaxation)의 반복 → 세 기법이 공유하는 기본 연산 구조.
2. 탐욕적 확정 : **다익스트라** (Dijkstra)는 최소 잠정 거리 정점을 순차 확정하는 방식 → 단일 출발점 질의의 빠른 처리 효과.
3. 반복 완화 : **벨만-포드** (Bellman-Ford)는 전체 간선 완화를 반복하는 방식 → **음수 가중치** 허용과 **음수 사이클** 탐지 효과.
4. 동적 계획 : **플로이드-워셜** (Floyd-Warshall)은 경유 정점 집합을 단계 확장하는 방식 → 모든 정점 쌍 거리의 일괄 산출 효과.

## Ⅲ. 최단 경로 알고리즘의 구조 (흐름)

- 핵심 요약 : 다익스트라는 초기화 후 최소 거리 정점의 확정과 완화 반복이고, 기법 선택은 음수 간선·질의 범위로 분기.

```text
초기화 : 출발점 거리 0, 나머지 무한대
   ↓ 우선순위 큐에서 최소 거리 정점 선택
정점 확정
   ↓ 인접 간선 완화 dist[v] > dist[u] + w
큐 소진 또는 목적지 확정
   ↓ 부모 기록의 역추적
최단 경로 복원
```

```text
음수 간선 존재?
   예 → 벨만-포드
   아니오
      ↓ 모든 정점 쌍 질의?
         예 → 플로이드-워셜
         아니오 → 다익스트라
```

- 거리 배열, 부모 기록, 우선순위 큐가 다익스트라 처리의 기본 자료 구조이고 완화 결과는 비용 산출과 경로 복원에 함께 사용.

## Ⅳ. 다익스트라·벨만-포드·플로이드-워셜의 비교

- 핵심 요약 : 음수 간선 허용 여부와 질의 범위가 세 기법 선택의 첫 판단 축.

| 비교 축 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
| --- | --- | --- | --- |
| 해결 범위 | 단일 출발점 | 단일 출발점 | 모든 정점 쌍 |
| 음수 간선 | 부적합 | 허용 | 허용 |
| 음수 사이클 | 전제 위반 시 오답 | 도달 가능 사이클의 탐지 | 대각 원소 음수로 판별 |
| 기반 원리 | 탐욕 선택·우선순위 큐 | 전 간선의 반복 완화 | 동적 계획법 |
| 시간 복잡도 | O((V+E)log V) | O(VE) | O(V³) |

- 복잡도 표기의 V는 정점 수, E는 간선 수.

## Ⅴ. 최단 경로 알고리즘의 한계와 방안

- 핵심 요약 : 가중치 전제 위반, 음수 사이클, 계산 자원, 동률 경로를 입력 검증과 규칙 고정으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 음수 간선에서의 오답 | 다익스트라의 거리 확정 전제 위반 | 입력 가중치 검증 후 기법 전환 | 입력 검증 통과율 |
| 음수 사이클의 존재 | 최단 경로의 미정의와 무한 갱신 위험 | 벨만-포드 탐지 후 사이클 제외·보고 | 사이클 탐지 건수 |
| 전체 쌍 계산 비용 | O(V³) 연산의 시간·메모리 과다 | 희소 표현·필요 쌍 한정·캐싱 | 계산 시간·메모리 사용량 |
| 동률 경로의 비결정성 | 동일 비용 복수 경로의 결과 불안정 | 동률 규칙 고정·부모 갱신 조건 명시 | 재현 실패 건수 |

## Ⅵ. 경로 서비스에 대한 기술사적 제언

- 핵심 요약 : 경로 서비스 운영 조직은 가중치 의미와 제약의 데이터 계약화, 그래프 자산의 표준 관리가 필요.
1. 플랫폼 운영 조직은 방향성, 비용 단위, 음수 불가 여부를 API(Application Programming Interface) 계약과 입력 검증 규칙에 명시.
2. 대규모 서비스 조직은 그래프 버전, 갱신 주기, 캐시 전략을 정확도 요구와 함께 설계 표준으로 정의.

## Ⅶ. 결론

- 핵심 요약 : 최단 경로 알고리즘은 가중치 조건·질의 범위에 맞는 기법 선택이 정확성과 효율의 전제.
- 시사점 : 비음수 단일 출발점은 다익스트라, 음수 간선은 벨만-포드, 전체 쌍은 플로이드-워셜이 기준 선택.
