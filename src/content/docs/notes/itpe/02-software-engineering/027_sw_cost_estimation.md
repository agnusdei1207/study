## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 프로젝트 관리 → **SW 규모·비용 산정(FP·LOC·COCOMO)**

## 30초 인출

- 본질: SW 규모·비용 산정은 소프트웨어의 크기를 측정하고 그 규모에 생산성과 비용 요소를 적용해 노력과 비용을 추정하는 활동
- 메커니즘: 코드 라인 수(LOC)나 기능점수(FP)로 규모를 재고, COCOMO 같은 모형으로 노력(인월)과 기간을 계산해 비용으로 환산
- 통찰: 개발 초기에는 코드 라인을 알 수 없고 요구가 불명확하면 기능점수도 흔들리므로 요구가 구체화된 시점에 기능점수로 규모를 재고 조직 실적으로 보정한 생산성으로 노력을 환산

<details>
<summary>핵심 용어</summary>

- **LOC(Lines of Code)** : 소스 코드 라인 수로 규모를 재는 방식
- **기능점수(FP, Function Point)** : 사용자 관점의 기능(데이터 기능·트랜잭션 기능)을 점수화해 규모를 재는 방식
- **COCOMO(Constructive Cost Model)** : Boehm이 제안한 규모(KLOC) 기반의 노력·기간 산정 모형
- **인월(Man-Month)** : 한 사람이 한 달에 수행하는 작업량 단위
- **생산성** : 단위 노력당 산출 규모. 조직 실적으로 보정하는 값

</details>

## 2~4교시 25점 답안

## Ⅰ. SW 규모·비용 산정의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SW 규모·비용 산정** 은 소프트웨어 규모를 측정하고 그 규모로 노력과 비용을 추정하는 활동 |
| 목적 | 예산·일정·계약 기준의 근거 마련 |

## Ⅱ. 규모와 비용 산정의 특징

| 특징 | 의미 |
|---|---|
| 규모 우선 | 규모를 먼저 재고 노력·비용으로 환산 |
| 불확실성 | 초기에는 추정 오차가 크고 요구가 구체화될수록 감소 |
| 실적 보정 | 외부 계수를 조직 실적으로 보정 |

## Ⅲ. 산정 절차와 기능점수의 구성

### 산정 절차

```text
요구사항·범위 정의
    ↓
규모 산정 (LOC 또는 FP)
    ↓
노력 산정 (생산성·COCOMO)
    ↓
기간·비용 환산
```

### 확대: 기능점수 구성

```text
기능점수(FP)
    ├─ 데이터 기능 ── ILF(내부 논리 파일)·EIF(외부 인터페이스 파일)
    └─ 트랜잭션 기능 ── EI(외부 입력)·EO(외부 출력)·EQ(외부 조회)
```

## Ⅳ. 규모 산정 방식과 COCOMO의 비교

### 규모 산정 방식의 비교

| 구분 | LOC | 기능점수(FP) | COCOMO |
|---|---|---|---|
| 기준 | 코드 라인 수 | 사용자 기능 | 규모(KLOC)와 비용 요소 |
| 시점 | 개발 후 정확, 초기 추정 곤란 | 요구 분석 후 | 규모 확정 후 노력 산정 |
| 장점 | 측정 단순 | 언어·기술과 무관 | 노력·기간 산식 제공 |
| 단점 | 언어·개발자에 따라 상이 | 기능 식별 숙련 필요, 비기능 반영 곤란 | 조직 보정 필요 |

### COCOMO 개발 유형

| 유형 | 특징 |
|---|---|
| 조직형(Organic) | 소규모·익숙한 환경 |
| 반분리형(Semi-detached) | 중간 규모·경험 혼합 |
| 내장형(Embedded) | 엄격한 제약의 대규모·실시간 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 초기에 코드 라인 예측이 어려워 LOC 산정 오차 큼 | 요구 분석 후 기능점수로 규모 산정 |
| 요구 불명확 시 기능 식별이 흔들려 기능점수 변동 | 요구사항 확정 범위에서 산정하고 변경 시 재산정 |
| 외부 모형 계수가 조직 실적과 달라 오차 발생 | 과거 프로젝트 실적으로 생산성·계수 보정 |
| 기능점수가 기능 식별 곤란 사업에 부적합 | 투입공수 방식 병행 |

## Ⅵ. 제언

요구가 구체화된 시점에 기능점수로 규모를 재고, 조직 실적으로 보정한 생산성으로 노력을 환산

### 산정 방식 적용 순서

```text
요구 구체화 여부
    ├─ 구체화 → 기능점수로 규모 산정
    └─ 기능 식별 곤란 → 투입공수 방식
    ↓
조직 실적 보정 생산성으로 노력 환산
```

### 선택 근거: 외부 계수 그대로 사용과의 비교

| 구분 | 외부 계수 그대로 사용 | 제언: 실적 보정 |
|---|---|---|
| 정확도 | 조직과 불일치 | 조직 실적 반영 |
| 요구 변동 대응 | 재산정 근거 부족 | 기능 단위 재산정 |
| 사용 부담 | 낮음 | 실적 관리 필요 |
