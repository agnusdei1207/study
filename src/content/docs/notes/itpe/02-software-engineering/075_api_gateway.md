## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 인터페이스·API → **API Gateway**

## 30초 인출

- 본질: API 게이트웨이는 클라이언트의 모든 API 요청을 한 곳에서 받아 인증·라우팅·속도 제한 같은 공통 기능을 처리하고 내부 서비스로 전달하는 진입점
- 메커니즘: 클라이언트 요청을 받아 인증·인가를 확인하고 속도 제한을 적용한 뒤 요청 경로에 맞는 서비스로 라우팅하고 응답을 전달
- 통찰: 게이트웨이에 업무 로직이 쌓이면 병목과 변경 부담이 커지므로 인증·라우팅·제한 같은 공통 기능만 두고 이중화해 단일 장애점을 제거

<details>
<summary>핵심 용어</summary>

- **API 게이트웨이(API Gateway)** : 클라이언트 요청의 단일 진입점으로 공통 기능을 처리하는 서버
- **라우팅(Routing)** : 요청 경로에 따라 알맞은 서비스로 전달하는 기능
- **속도 제한(Rate Limiting)** : 클라이언트별 단위 시간당 요청 수를 제한하는 기능
- **서킷 브레이커(Circuit Breaker)** : 장애가 계속되는 서비스 호출을 차단해 연쇄 장애를 막는 장치
- **BFF(Backend for Frontend)** : 웹·모바일처럼 클라이언트 유형별로 두는 전용 게이트웨이
- **리버스 프록시(Reverse Proxy)** : 내부 서버 앞에서 외부 요청을 대신 받아 전달하는 서버

</details>

## 2~4교시 25점 답안

## Ⅰ. API Gateway의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **API Gateway** 는 클라이언트 요청의 단일 진입점으로 공통 기능을 처리하고 내부 서비스로 전달하는 서버 |
| 목적 | 서비스 공통 기능의 중앙 처리와 내부 구조의 은닉 |

## Ⅱ. 서비스 직접 호출과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 단일 진입점 | 클라이언트가 게이트웨이 주소만 인지 |
| 공통 기능 집중 | 인증·제한·로깅의 일괄 처리 |
| 내부 은닉 | 서비스 구성 변경이 클라이언트에 미노출 |

## Ⅲ. 게이트웨이 구조와 요청 처리 흐름

### 게이트웨이 구조

```text
클라이언트(웹·모바일)
    ↓
API 게이트웨이 ── 인증·속도 제한·로깅
    ├─ 주문 서비스
    ├─ 결제 서비스
    └─ 재고 서비스
```

### 확대: 요청 처리 흐름

```text
요청 수신
    ↓
인증·인가 확인 ── 실패 → 거부
    ↓
속도 제한 확인 ── 초과 → 거부
    ↓
경로에 맞는 서비스로 라우팅
    ↓
응답 전달·로깅
```

## Ⅳ. 주요 기능과 유사 구성요소의 비교

### 주요 기능

| 기능 | 내용 |
|---|---|
| 라우팅 | 경로별 서비스 전달 |
| 인증·인가 | 토큰 검증 |
| 속도 제한 | 요청 수 제한 |
| 서킷 브레이커 | 장애 서비스 호출 차단 |
| 로깅·모니터링 | 요청 기록 수집 |

### 유사 구성요소와의 비교

| 구분 | API 게이트웨이 | 리버스 프록시 | 서비스 메시 |
|---|---|---|---|
| 위치 | 외부 진입점 | 외부 진입점 | 서비스 간 내부 통신 |
| 주 기능 | 인증·제한·라우팅 등 API 관리 | 부하 분산·전달 | 서비스 간 통신 제어 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 게이트웨이의 단일 장애점·병목 | 이중화와 수평 확장 |
| 업무 로직 누적으로 변경 부담 증가 | 공통 기능만 두고 업무 로직은 서비스로 |
| 클라이언트별 요구 상이 | 클라이언트 유형별 BFF |

## Ⅵ. 제언

게이트웨이는 인증·라우팅·속도 제한 같은 공통 기능만 담당하게 하고, 이중화로 단일 장애점을 제거

### 역할 범위와 가용성

```text
게이트웨이: 공통 기능만
업무 로직: 각 서비스
가용성: 게이트웨이 이중화 + 로드밸런서
```

### 확대: 로직 배치 판단

```text
추가할 기능
    ├─ 모든 요청에 공통 → 게이트웨이
    └─ 특정 업무 규칙 → 해당 서비스
```

### 선택 근거: 업무 로직 포함과의 비교

| 구분 | 업무 로직 포함 | 제언: 공통 기능만 |
|---|---|---|
| 변경 영향 | 게이트웨이 배포 필요 | 서비스별 배포 |
| 병목 | 위험 | 완화 |
| 책임 | 혼재 | 분리 |
