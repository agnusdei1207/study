## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 품질·검증 → **소프트웨어 품질보증(SQA)**

## 30초 인출

- 본질: 소프트웨어 품질보증(SQA)은 개발 프로세스와 산출물이 정해진 품질 기준을 따르는지 보증하는 체계적 활동
- 메커니즘: 품질 계획으로 기준을 정하고 단계별 산출물과 프로세스 준수를 검토·감사하며 발견한 결함의 시정과 측정 결과를 보고
- 통찰: 품질을 시험 단계에서만 확인하면 결함 수정 비용이 커지므로 각 단계 종료 시 품질 게이트로 산출물을 점검해 결함을 조기에 시정

<details>
<summary>핵심 용어</summary>

- **소프트웨어 품질** : 요구사항을 충족하고 사용 목적에 적합한 정도. ISO/IEC 25010은 기능 적합성·성능 효율성·호환성·사용성·신뢰성·보안성·유지보수성·이식성 등으로 분류
- **품질보증(QA, Quality Assurance)** : 프로세스가 기준을 따르는지 확인해 결함을 예방하는 활동
- **품질관리(QC, Quality Control)** : 완성된 산출물을 시험·검사해 결함을 찾는 활동
- **품질 게이트(Quality Gate)** : 단계를 넘어가기 전 충족해야 하는 품질 기준
- **인스펙션(Inspection)** : 산출물을 사람이 형식적으로 검토해 결함을 찾는 기법

</details>

## 2~4교시 25점 답안

## Ⅰ. 소프트웨어 품질보증의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **소프트웨어 품질보증** 은 프로세스와 산출물이 품질 기준을 따르는지 보증하는 체계적 활동 |
| 목적 | 결함의 예방과 조기 발견을 통한 요구 품질 확보 |

## Ⅱ. 소프트웨어 품질의 의미와 품질보증의 특징

### 소프트웨어 품질의 의미

| 관점 | 의미 |
|---|---|
| 요구 적합성 | 명시된 요구사항을 충족하는 정도 |
| 사용 적합성 | 사용자가 의도한 목적에 알맞게 쓰이는 정도 |
| 품질 특성 | 기능 적합성·성능 효율성·호환성·사용성·신뢰성·보안성·유지보수성·이식성 |

### 품질보증의 특징

| 특징 | 의미 |
|---|---|
| 프로세스 중심 | 결과 검사보다 절차 준수 보증 |
| 전 생명주기 | 단계마다 점검 |
| 독립성 | 개발과 분리된 시각의 점검 |

## Ⅲ. 품질보증 체계와 기능

### 품질보증 활동

```text
품질 계획 ── 목표·기준·점검 시점 정의
    ↓
단계별 검토·감사 ── 산출물·프로세스 점검
    ↓
결함 시정 ── 원인 분석·조치·확인
    ↓
측정·보고 ── 결함 밀도 등 품질 지표
```

### 확대: 품질 게이트 판정

```text
단계 종료
    ↓
품질 게이트 점검
    ├─ 충족 → 다음 단계
    └─ 미충족 → 시정 후 재점검
```

## Ⅳ. 품질보증과 품질관리, 검토 기법

| 구분 | 품질보증(QA) | 품질관리(QC) |
|---|---|---|
| 대상 | 프로세스 | 산출물 |
| 목적 | 결함 예방 | 결함 발견 |
| 대표 활동 | 감사·검토·표준 수립 | 시험·검사 |

| 검토 기법 | 내용 |
|---|---|
| 인스펙션 | 역할·절차·체크리스트에 따른 형식적 검토 |
| 워크스루 | 저자가 설명하며 의견을 수렴하는 검토 |
| 감사 | 프로세스 준수 여부 점검 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 시험 단계에서만 결함 확인해 수정 비용 증가 | 단계별 품질 게이트와 인스펙션 |
| 품질 기준이 불명확해 판정 곤란 | 측정 가능한 품질 목표를 품질 계획에 명시 |
| 형식적 점검에 그치는 활동 | 결함 원인 분석과 시정 확인을 필수화 |

## Ⅵ. 제언

각 단계 종료 시 품질 게이트로 산출물을 점검하고, 미충족 항목은 시정 확인 후 다음 단계로 진행

### 품질 게이트 적용

```text
요구·설계·구현·시험 단계 종료마다 게이트 점검
    ↓
결함 목록 → 시정 → 재점검
```

### 확대: 게이트 기준

```text
기준 예: 미해결 중대 결함 0건, 검토 완료율, 시험 커버리지
```

### 선택 근거: 시험 단계 검사와의 비교

| 구분 | 시험 단계 검사 | 제언: 단계별 품질 게이트 |
|---|---|---|
| 결함 발견 시점 | 후반 | 단계 종료 시 |
| 수정 비용 | 큼 | 작음 |
| 진행 판단 | 시험 결과 | 게이트 기준 |
