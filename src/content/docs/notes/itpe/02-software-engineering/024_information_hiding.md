소프트웨어 공학 → 객체지향·모듈화 → **정보은닉(Information Hiding)**

## 30초 인출

- 본질: 정보은닉은 변경될 가능성이 큰 내부 구현과 데이터를 모듈 안에 감추고 공개 인터페이스로만 접근하게 하는 설계 원칙
- 메커니즘: 데이터를 private으로 두고 공개 메서드로만 조작하게 해 외부가 내부 표현에 의존하지 않도록 차단
- 통찰: getter·setter로 내부 필드를 그대로 열어 두면 정보은닉이 깨져 내부 변경이 호출자에게 파급되므로 내부 상태는 의미 있는 행위 메서드로만 노출

<details>
<summary>핵심 용어</summary>

- **정보은닉(Information Hiding)** : 변경 가능성이 큰 설계 결정을 모듈 내부에 숨기고 공개 인터페이스만 노출하는 원칙. Parnas 제안
- **캡슐화(Encapsulation)** : 데이터와 그 데이터를 다루는 행위를 하나로 묶는 수단
- **공개 인터페이스(Public Interface)** : 모듈이 외부에 노출하는 최소한의 접근 지점
- **접근 제어자** : private·protected·public처럼 멤버의 접근 범위를 정하는 언어 기능
- **파급 효과(Ripple Effect)** : 한 모듈의 변경이 의존하는 다른 모듈의 수정을 부르는 현상
- **결합도(Coupling)** : 모듈 간 의존 정도

</details>

## 2~4교시 25점 답안

## Ⅰ. 정보은닉의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정보은닉** 은 변경 가능성이 큰 내부 구현과 데이터를 모듈 안에 감추고 공개 인터페이스로만 접근하게 하는 설계 원칙 |
| 목적 | 내부 변경이 외부에 미치는 영향 차단과 객체 데이터 보호 |

## Ⅱ. 정보은닉의 특징

| 특징 | 의미 |
|---|---|
| 내부 은닉 | 필드와 구현 방식을 외부에 비공개 |
| 인터페이스 접근 | 공개 메서드로만 상태 변경 |
| 결합도 감소 | 호출자가 내부 표현에 의존하지 않음 |

## Ⅲ. 정보은닉의 구현 구조

### 공개 인터페이스와 은닉 영역

```text
외부 객체
    ↓ 공개 메서드만 호출
┌────────────────────┐
│ 공개 인터페이스     │
│ ─────────────────  │
│ (private) 필드·구현 │
└────────────────────┘
```

### 확대: 접근 경로의 통제

```text
외부: account.balance = -100   → 컴파일 오류(private)
외부: account.withdraw(100)    → 메서드 내부의 잔액 검증 후 처리
```

## Ⅳ. 캡슐화와의 비교, 은닉 수준별 결과

### 정보은닉과 캡슐화의 비교

| 구분 | 정보은닉 | 캡슐화 |
|---|---|---|
| 초점 | 무엇을 숨길지의 설계 원칙 | 묶는 구현 수단 |
| 목적 | 변경 영향 차단 | 데이터·행위의 응집 |
| 관계 | 캡슐화를 통해 구현 | 정보은닉을 위한 수단 |

### 은닉 수준에 따른 결과

| 구분 | 필드 공개 | getter·setter 노출 | 행위 메서드만 노출 |
|---|---|---|---|
| 내부 표현 변경 | 호출자 수정 필요 | 호출자 수정 가능성 | 호출자 영향 없음 |
| 불변식(잔액≥0) 보호 | 불가 | 호출자가 지켜야 함 | 메서드 내부에서 보장 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| getter·setter 남용으로 내부 상태 노출 | 상태를 바꾸는 행위 단위의 메서드 제공 |
| 접근 제어자만으로 은닉 기준 불명확 | 변경 가능성이 큰 결정을 기준으로 은닉 대상 선정 |
| 지나친 은닉으로 인터페이스 증가 | 공개 인터페이스를 필요한 최소 범위로 제한 |

## Ⅵ. 제언

필드를 그대로 노출하는 getter·setter 대신, 업무 의미가 있는 행위 메서드로 상태 변경을 제공

### 노출 방식 전환

```text
setBalance(x) 노출
    ↓ 전환
deposit(amount) / withdraw(amount) 노출 (내부에서 검증)
```

### 선택 근거: setter 노출과의 비교

| 구분 | setter 노출 | 제언: 행위 메서드 |
|---|---|---|
| 불변식 보호 | 호출자 책임 | 객체 내부 |
| 내부 변경 | 호출자 영향 | 영향 없음 |
| 인터페이스 의미 | 값 설정 | 업무 동작 |
