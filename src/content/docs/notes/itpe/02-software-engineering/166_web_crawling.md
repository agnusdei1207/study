## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 인터페이스·API → **웹 크롤링(Web Crawling)**

## 30초 인출

- 본질: 웹 크롤링은 시작 URL에서 링크를 따라가며 웹 페이지를 체계적으로 탐색·수집하는 자동화 기술
- 메커니즘: URL 대기열에서 주소를 꺼내 페이지를 내려받고 새 링크를 추출해 방문하지 않은 것만 대기열에 추가하는 과정을 반복
- 통찰: 같은 사이트에 요청이 몰리면 서버에 부담을 주고 차단되므로 robots.txt를 확인하고 사이트별 요청 간격을 두며 방문한 URL은 중복 없이 관리

<details>
<summary>핵심 용어</summary>

- **웹 크롤링(Web Crawling)** : 링크를 따라 웹 페이지를 자동으로 탐색·수집하는 활동
- **시드 URL(Seed URL)** : 크롤링을 시작하는 최초의 주소
- **URL 프론티어(URL Frontier)** : 앞으로 방문할 URL을 우선순위와 함께 보관하는 대기열
- **예절 정책(Politeness Policy)** : 같은 서버에 요청 간격을 두어 부담을 주지 않는 규칙
- **robots.txt** : 사이트가 크롤러의 접근 허용 범위를 알리는 파일
- **블룸 필터(Bloom Filter)** : 방문 여부를 적은 메모리로 빠르게 확인하는 자료구조

</details>

## 2~4교시 25점 답안

## Ⅰ. 웹 크롤링의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **웹 크롤링** 은 링크를 따라 웹 페이지를 자동으로 탐색·수집하는 기술 |
| 목적 | 검색·분석용 웹 데이터의 대규모 수집 |

## Ⅱ. 스크래핑과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 탐색 중심 | 링크를 따라 페이지를 넓게 수집 |
| 반복 수행 | 새 링크를 계속 발견 |
| 대규모 | 수많은 URL 관리 필요 |

## Ⅲ. 크롤링 순환

```text
   시드 URL
      ↓
┌→ URL 프론티어에서 꺼냄
│     ↓
│  페이지 내려받기 (robots.txt·요청 간격 준수)
│     ↓
│  링크 추출 · 데이터 저장
│     ↓
└─ 방문하지 않은 URL만 프론티어에 추가
```

## Ⅳ. 크롤링과 스크래핑의 비교

| 구분 | 웹 크롤링 | 웹 스크래핑 |
|---|---|---|
| 목적 | 페이지 탐색·수집 | 페이지의 특정 데이터 추출 |
| 방식 | 링크 따라 확장 | 지정한 요소 추출 |
| 규모 | 대규모 | 대상 한정 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 요청 집중으로 서버 부담과 차단 | 사이트별 요청 간격과 robots.txt 준수 |
| 같은 URL의 중복 방문 | 방문 URL 관리(블룸 필터 등) |
| 동적 페이지의 수집 누락 | 헤드리스 브라우저로 렌더링 후 수집 |

## Ⅵ. 제언

robots.txt와 요청 간격을 지키고 방문한 URL을 중복 없이 관리하며 수집

```text
URL 꺼냄
   ├─ robots.txt 불허 → 건너뜀
   ├─ 이미 방문 → 건너뜀
   └─ 허용·미방문 → 간격을 두고 수집
```

| 구분 | 무제한 수집 | 제언: 규칙 준수 수집 |
|---|---|---|
| 서버 부담 | 큼 | 통제 |
| 차단 위험 | 높음 | 낮음 |
| 중복 | 발생 | 제거 |
