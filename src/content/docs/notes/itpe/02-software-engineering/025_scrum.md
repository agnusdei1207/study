## 30초 인출

- 본질: 스크럼은 짧은 스프린트를 반복하며 제품 백로그에서 선택한 항목을 동작하는 증분으로 완성하는 애자일 프레임워크
- 메커니즘: 제품 책임자가 우선순위를 정한 백로그에서 스프린트 계획으로 항목을 선택하고, 일일 스크럼으로 점검한 뒤 스프린트 리뷰·회고로 결과와 방식을 개선
- 통찰: 완료 기준이 모호하면 미완성 작업이 다음 스프린트로 이월되므로 완료의 정의를 팀이 합의하고 스프린트 리뷰에서 그 기준으로 증분을 검사

<details>
<summary>핵심 용어</summary>

- **스크럼(Scrum)** : 스프린트와 정해진 역할·이벤트·산출물로 제품을 점진적으로 만드는 애자일 프레임워크
- **제품 책임자(Product Owner)** : 제품 가치를 극대화하고 제품 백로그의 우선순위를 정하는 역할
- **스크럼 마스터(Scrum Master)** : 스크럼 이해를 돕고 팀의 장애물을 제거하는 역할
- **스프린트(Sprint)** : 증분을 만드는 1개월 이하의 고정 기간
- **제품 백로그(Product Backlog)** : 제품에 필요한 항목의 우선순위 목록
- **완료의 정의(Definition of Done)** : 증분이 완료로 인정되기 위한 품질 기준

</details>

## 2~4교시 25점 답안

## Ⅰ. 스크럼의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **스크럼** 은 짧은 스프린트를 반복하며 제품 백로그의 항목을 동작하는 증분으로 완성하는 애자일 프레임워크 |
| 목적 | 요구 변화에 대한 대응과 가치의 조기·반복 전달 |

## Ⅱ. 계획 주도 방식과 구별되는 스크럼의 특징

| 특징 | 의미 |
|---|---|
| 반복 주기 | 고정 길이의 스프린트 반복 |
| 경험적 관리 | 투명성·검사·적응의 반복 |
| 자기 관리 팀 | 작업 방법을 팀이 스스로 결정 |
| 증분 산출 | 스프린트마다 사용 가능한 증분 완성 |

## Ⅲ. 스크럼의 구성과 스프린트 진행

### 스크럼 구성

```text
스크럼
    ├─ 역할 ── 제품 책임자·스크럼 마스터·개발자
    ├─ 이벤트 ── 스프린트 계획·일일 스크럼·스프린트 리뷰·스프린트 회고
    └─ 산출물 ── 제품 백로그·스프린트 백로그·증분 (완료의 정의)
```

### 확대: 스프린트 진행 흐름

```text
제품 백로그 → 스프린트 계획(스프린트 백로그 선택)
    ↓
스프린트 진행 + 일일 스크럼
    ↓
증분 완성 → 스프린트 리뷰(검사) → 스프린트 회고(프로세스 개선)
    ↓
다음 스프린트
```

## Ⅳ. 역할·이벤트·산출물의 관계

### 역할 비교

| 역할 | 책임 |
|---|---|
| 제품 책임자 | 백로그 우선순위와 제품 가치 |
| 스크럼 마스터 | 스크럼 준수 지원과 장애물 제거 |
| 개발자 | 스프린트 백로그의 증분 완성 |

### 이벤트별 목적

| 이벤트 | 목적 |
|---|---|
| 스프린트 계획 | 이번 스프린트의 목표와 항목 선택 |
| 일일 스크럼 | 목표 진행 점검과 계획 조정 |
| 스프린트 리뷰 | 증분 검사와 백로그 조정 |
| 스프린트 회고 | 팀 방식의 개선 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 완료 기준 모호로 미완성 작업 이월 | 완료의 정의를 합의하고 리뷰에서 기준으로 검사 |
| 스프린트 중 요구 변경 유입으로 목표 훼손 | 변경은 백로그에 등록해 다음 계획에서 반영 |
| 스크럼 마스터 역할의 관리자화 | 장애물 제거·코칭 역할로 한정 |
| 대규모 조직에서 팀 간 조율 곤란 | 팀 간 동기화 방식을 별도 정의 |

## Ⅵ. 제언

스프린트 시작 전에 팀이 완료의 정의를 합의하고, 스프린트 리뷰에서 그 기준을 충족한 항목만 완료로 인정

### 완료 인정 절차

```text
완료의 정의 합의
    ↓
항목 구현
    ↓
리뷰에서 완료의 정의 대조
    ├─ 충족 → 증분에 포함
    └─ 미충족 → 백로그 복귀
```

### 확대: 미완성 항목 처리

```text
미충족 항목 → 제품 백로그 복귀 → 우선순위 재결정
```

### 선택 근거: 담당자 판단과의 비교

| 구분 | 담당자 판단 | 제언: 완료의 정의 |
|---|---|---|
| 완료 기준 | 사람마다 상이 | 팀 합의 기준 |
| 이월 | 잦음 | 명확히 구분 |
| 증분 품질 | 편차 | 일정 수준 |
