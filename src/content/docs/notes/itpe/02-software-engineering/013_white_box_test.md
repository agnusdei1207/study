## 연관 키워드
- 화이트박스, CFG, 문장·분기·조건 커버리지, MC/DC

### Ⅰ. 화이트박스 테스트의 개요

- 핵심 요약 : 코드 구조와 제어 흐름을 기준으로 실행 경로·조건을 검증하는 구조 기반 시험.
- 개념 : 내부 로직을 분석해 문장, 분기, 조건, 경로 등 커버리지 목표를 달성하는 테스트(**화이트박스 테스트**, White Box Test).
- 배경 및 필요성 : 명세 시험만으로 구현된 분기와 예외 흐름의 미실행을 발견하기 어려움.
- 주요 목적 : 논리 구현 오류와 구조적 미검증 영역 식별.

### Ⅱ. 커버리지의 특징과 장점

- 핵심 요약 : 문장 < 분기 < 조건·MC/DC로 강도가 높아지나 전 경로 시험은 대개 불가능.

1. 문장 커버리지 : 각 문장 실행 → 미실행 코드 탐지.
2. 분기 커버리지 : 참·거짓 결과 모두 실행 → 결정 경로 확인.
3. 조건 커버리지 : 개별 불리언 조건 참·거짓 평가 → 조건 영향 확인.
4. MC/DC : 각 조건의 독립적 결정 영향 확인 → 안전 중요 로직에 활용.

### Ⅲ. CFG 기반 시험 흐름 (구조)

- 핵심 요약 : 제어 흐름 그래프의 노드·간선·결정을 식별하고 커버리지 기준에 맞춰 입력을 설계.

```text
시작 → 조건 A?
       ├ 참 → 처리 X ─┐
       └ 거짓 → 조건 B?│
                 ├ 참 → Y
                 └ 거짓 → Z → 종료
```

```text
코드 분석 → CFG 구성 → 목표 설정 → 테스트 입력 설계·실행 → 미실행 분기 보완
```

- MC/DC 예 : (A AND B)에서 B를 고정한 채 A만 바꿔 결과 변화 확인.

### Ⅳ. 커버리지 기준 비교

- 핵심 요약 : 분기 커버리지는 문장보다 강하고 MC/DC는 조건의 독립 기여를 확인하나 전체 정확성을 보장하지 않음.

| 비교 축 | 문장 | 분기 | 조건 | MC/DC |
|---|---|---|---|---|
| 보장 내용 | 각 문장 1회 실행 | 결정의 참·거짓 | 원자 조건 참·거짓 | 조건별 결정 결과 기여 |
| 미보장 사항 | 모든 분기 결과 | 개별 조건 독립 영향 | 모든 조합·경로 | 요구 충족·결함 부재 |

### Ⅴ. 화이트박스 테스트의 한계와 방안

- 핵심 요약 : 높은 커버리지도 요구 충족을 증명하지 않으므로 명세 시험·위험 분석과 결합.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 경로 조합 폭발 | 전 경로 시험 불가 | 위험·복잡도 기반 경로 선정 | 미실행 경로 수 |
| 커버리지 수치 오용 | 무의미한 assertion 증가 | 결함 검출력·요구 추적 병행 | 커버리지·결함 상관 |
| 현실성 낮은 입력 | 경계 오류 누락 | 명세 기반 경계값·퍼징 병행 | 경계값 발견 비율 |

### Ⅵ. 화이트박스 시험 제언

- 핵심 요약 : QA는 안전 중요도와 코드 복잡도에 따라 커버리지 목표와 증거 보존을 정함.

1. 개발자는 변경 코드의 분기·예외 경로를 리뷰에 포함.
2. 안전 책임자는 규제 수준에 맞는 MC/DC 기준과 결과를 보존.
3. 품질 리더는 커버리지와 결함 유출·요구 추적을 함께 해석.

### Ⅶ. 결론

- 핵심 요약 : 화이트박스 테스트는 코드 구조 실행 여부를 측정하는 수단이지 정확성의 증명이 아님.
- 시사점 : 위험 수준에 맞는 기준을 명세 기반 시험과 함께 사용.
