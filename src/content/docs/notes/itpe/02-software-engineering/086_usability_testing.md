## 한 줄 본질
- 개발팀의 관점에서 직관적이라고 믿었던 UI가 실제 사용자에게는 극심한 혼란과 이탈을 초래하는 인지 단절 병목 → 대표 사용자에게 구체적 과업(Task)을 주고 조작 과정을 관찰·기록하여 불편 지점을 식별 → 직관적 UI/UX와 전환율 극대화 / 피험자 모집 및 테스트 분석 비용 소요

## 핵심 용어
- 발성 사고법(Think Aloud): 사용자가 과업을 수행하는 동안 머릿속으로 떠오르는 생각, 의문, 당혹감을 소리 내어 말하도록 유도하는 관찰 기법
- SUS(System Usability Scale): 시스템의 사용성을 빠르게 측정하기 위해 널리 쓰이는 10개 문항의 5점 리커트 척도 설문 도구(68점 기준)

## 핵심 통찰
- 제이콥 닐슨의 법칙에 따르면, 단 5명의 사용자만으로 진행하는 사용성 테스트로 전체 사용성 문제의 85% 이상을 발견할 수 있으므로 대규모 인원이 필요하지 않음
- 사용자가 "이 기능이 좋아요"라고 말하는 '말(Opinion)'을 믿지 말고, 마우스 커서가 헤매거나 뒤로가기를 누르는 '행동(Behavior)'을 데이터로 기록해야 함
- 전문가가 가이드라인에 따라 검토하는 '휴리스틱 평가'로 1차 스크리닝을 끝낸 후, 실제 사용자를 투입하는 '사용성 테스트'를 진행하는 것이 비용 효율적임

## 이웃 토픽과 구분
- 사용성 테스트 vs 사용자 인수 테스트(UAT): 사용성 테스트 = UI/UX가 '얼마나 쓰기 편하고 직관적인가'를 검증 / UAT = 계약된 비즈니스 요구 '기능이 정상 동작하는가'를 확인

## 문제·원인·대책
- 사례: 121회 기출 모바일 뱅킹 앱 개편 후 펀드 가입 전환율이 40% 급감한 실패
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 신규 펀드 가입 페이지에서 약관 동의 버튼을 찾지 못해 60%가 이탈 | 전문용어 남발 및 스크롤 최하단에 작게 숨겨진 약관 동의 체크박스 | 발성 사고법(Think Aloud) 기반 UT 5회 실시 및 원클릭 통합 동의 UI 개편 | 펀드 가입 완수율 92%로 반등 |
| 오프라인 실험실 UT 진행 시 피험자 섭외 지연으로 배포 일정 지연 | 대면 실험실 환경 세팅 및 일정 조율의 물리적 시공간 한계 | 비대면 비동기 UT 플랫폼(Maze) 연계 화면 녹화 및 클릭 히트맵 수집 | 테스트 리드타임 2주에서 2일로 단축 |
