## 답안 골격
```text
[최단경로 알고리즘] ◀━━ 머리: Ⅶ 내 의견 (간선 가중치 조건과 단일/전체 쌍 목적에 따른 최적 알고리즘 선정 및 네트워크 라우팅 적용)
 ┃
 ┣━ Ⅰ 개요 ───── 그래프 탐색의 지수적 경로 조합 폭증 → 시작점과 도착점 간의 가중치 합이 최소가 되는 경로를 다항 시간 내 도출
 ┣━ Ⅱ 특징 ───── 최적 부분 구조(Optimal Substructure) 만족 · 탐욕법(Greedy) 및 동적 계획법(DP) 활용 · 음수 가중치 허용 여부
 ┣━ Ⅲ 구조 ───── 4대 핵심 알고리즘: 다익스트라(단일 시작, 양수 가중치) / 벨만-포드(음수 가중치 허용, 음수 사이클 탐지) / 플로이드-워셜(모든 쌍) / A*(휴리스틱)
 ┣━ Ⅳ 흐름 ───── 그래프 모델링(정점, 간선 가중치) → 음수 가중치 유무 확인 → 알고리즘 선정 → 최단 거리 배열 갱신(Relaxation) → 최단 경로 역추적
 ┣━ Ⅴ 비교 ───── 다익스트라($O((V+E)\log V)$) vs 벨만-포드($O(VE)$) vs 플로이드-워셜($O(V^3)$) vs A* 알고리즘
 ┗━ Ⅵ 실무 ───── 음수 사이클(Negative Cycle) 무한 루프 / 내비게이션 길찾기(A*) / 네트워크 라우팅 프로토콜(OSPF vs BGP)
```

## 한 줄 본질
- 그래프 내에서 가능한 모든 경로를 전수 탐색할 때 팩토리얼($N!$) 수준으로 폭증하는 계산 복잡도 병목 → "부분 최단 경로들의 합이 전체 최단 경로가 된다"는 최적 부분 구조를 활용하여 목적에 맞게 간선 가중치를 완화(Relaxation)해 나가는 알고리즘 체계 / 음수 사이클 시 최단 경로 부재

## 핵심 그림
```text
+-------------------------------------------------------------------------+
|                  최단경로 4대 알고리즘 선택 의사결정 트리               |
+-------------------------------------------------------------------------+
|                                                                         |
|                          [ 최단 경로 탐색 요구 ]                        |
|                                    │                                    |
|          ┌─────────────────────────┴─────────────────────────┐          |
|          v (단일 시작점 -> 모든 정점)                        v (모든 쌍 간 최단경로)|
|    [ 음수 가중치 존재하는가? ]                       [ 플로이드-워셜 ]   |
|          │                                           - 시간: O(V^3)     |
|    ┌─────┴─────┐                                     - DP 기반 3중 루프 |
|    v (No, 양수) v (Yes, 음수 허용)                                      |
| [ 다익스트라 ]  [ 벨만-포드 ]                                            |
| - O((V+E)logV)  - O(V·E)                                                |
| - 우선순위 큐   - 음수 사이클 탐지                                      |
|                                                                         |
|  * 목적지가 특정된 단일 쌍 고속 탐색: [ A* 알고리즘 ] (휴리스틱 결합)    |
|  * 변 경감(Relaxation) 핵심 공식:                                        |
|    if (dist[v] > dist[u] + weight(u, v)) dist[v] = dist[u] + weight(u, v)|
+-------------------------------------------------------------------------+
```

## 핵심 용어
- 변 경감(Edge Relaxation): 노드 $u$를 거쳐서 노드 $v$로 가는 경로의 비용이 현재까지 알려진 $v$까지의 최단 거리보다 짧을 경우, $v$의 최단 거리를 더 짧은 값으로 갱신하는 기본 연산
- 음수 사이클(Negative Weight Cycle): 간선의 가중치 합이 음수가 되는 사이클로, 이 사이클을 한 번 돌 때마다 경로 비용이 무한히 감소하여 최단 경로가 수학적으로 정의되지 않는 현상

## 핵심 통찰
- 다익스트라 알고리즘은 이미 최단 거리가 확정된 노드는 다시 갱신하지 않는 그리디(Greedy) 방식이므로, 음수 가중치가 단 하나라도 존재하면 확정된 노드의 거리가 나중에 뒤집혀 오동작함
- 벨만-포드 알고리즘은 다익스트라보다 느리지만($O(VE)$), 모든 간선에 대한 경감을 $V-1$번 반복하여 음수 가중치를 안전하게 처리하고, $V$번째에도 거리가 줄어들면 음수 사이클의 존재를 정확히 판별함
- 라우팅 프로토콜에서 OSPF(링크 상태)는 네트워크 토폴로지 전체를 다익스트라로 계산하여 최적 경로를 잡고, RIP(거리 벡터)는 벨만-포드 원리에 기반하여 인접 라우터와 홉 수를 교환함

## 이웃 토픽과 구분
- 다익스트라(Dijkstra) vs 플로이드-워셜(Floyd-Warshall): 다익스트라 = 특정 1개 노드에서 출발하는 단일 시작점 최단 경로 / 플로이드-워셜 = 그래프 내의 모든 정점 쌍 $(u, v)$ 사이의 최단 경로 행렬을 일괄 산출

## 문제·원인·대책
- 적용 상황: 글로벌 금융 환차익(Arbitrage) 거래 탐색 시스템
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 통화 환전 그래프에서 환율을 곱해 이익을 찾는 과정 중 다익스트라 알고리즘이 무한 오류 | 환율에 로그를 취해 음수로 변환할 때 음수 가중치 및 환차익 사이클 발생 | 벨만-포드(Bellman-Ford) 알고리즘 적용하여 음수 가중치 처리 및 차익 사이클 탐지 | 비정상 환차익 기회 100% 자동 포착 |
| 대도시 실시간 길안내 내비게이션 서버가 경로 재계산 시 CPU 과부하로 지연 | 다익스트라 알고리즘으로 수십만 개 교차로를 목적지와 무관하게 전방위 탐색 | 목적지까지의 직선거리를 휴리스틱으로 결합한 A* 알고리즘 및 CH(Contraction Hierarchies) 적용 | 경로 연산 시간 0.05초 이내로 단축 |
