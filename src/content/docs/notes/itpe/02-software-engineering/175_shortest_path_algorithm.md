## 학습 위치

소프트웨어공학 → 그래프 알고리즘 → **최단경로**

## 30초 인출

- **본질**: 최단경로 알고리즘은 가중치 그래프에서 두 정점 사이의 비용이 가장 작은 경로를 구하는 방법
- **메커니즘**: 탐색 범위·음수 간선 여부 확인 → 알고리즘 선택 → 거리 갱신 → 경로 복원

<details>
<summary>핵심 용어</summary>

- **가중치 그래프(Weighted Graph)**: 간선마다 거리·시간·비용 등의 값을 둔 그래프
- **간선 완화(Edge Relaxation)**: 현재 거리보다 다른 정점을 경유한 거리가 짧으면 거리 값을 갱신하는 연산
- **음수 사이클(Negative Cycle)**: 한 바퀴 돌 때마다 비용이 감소하는 사이클; 해당 경로의 유한한 최솟값이 없음
- **다익스트라(Dijkstra)**: 음수 간선이 없는 그래프에서 한 시작점의 최단거리를 구하는 알고리즘
- **벨만–포드(Bellman–Ford)**: 음수 간선을 허용하고 도달 가능한 음수 사이클을 검출할 수 있는 단일 시작점 알고리즘
- **플로이드–워셜(Floyd–Warshall)**: 모든 정점 쌍의 최단거리를 구하는 동적 계획 알고리즘
- **A*(A-star)**: 목표까지의 추정 비용을 이용해 탐색 순서를 정하는 경로 탐색 알고리즘

</details>

## Ⅱ. 공통 원리: 간선 완화

```text
S → U: 비용 5
U → V: 비용 2
S → V: 직접 비용 10

S → U → V: 합계 7 < 직접 10
```

| 비교 | V까지의 거리 |
|---|---|
| 직접 경로 S→V | 10 |
| 경유 경로 S→U→V | 5+2=7 |
| 완화 결과 | `dist[V] = min(10, 7) = 7` |

**간선 완화**는 `dist[v] > dist[u] + w(u,v)`일 때 값을 갱신하는 기본 연산.

## Ⅲ. 대표 알고리즘 비교

| 알고리즘 | 탐색 범위 | 음수 간선 | 핵심 방식·주의점 |
|---|---|---|---|
| **다익스트라** | 단일 시작점 | 허용하지 않음 | 가장 가까운 미확정 정점부터 확정 |
| **벨만–포드** | 단일 시작점 | 허용 | 간선 반복 완화; 도달 가능한 음수 사이클 검출 |
| **플로이드–워셜** | 모든 정점 쌍 | 허용 | 중간 정점을 늘리며 거리 행렬 갱신; 음수 사이클에서는 해당 경로 해석 주의 |
| **A*** | 시작점에서 목표점 | 휴리스틱 조건에 따름 | 실제 비용과 남은 비용 추정치로 탐색 순서 결정 |

복잡도는 구현·자료구조에 따라 달라지므로 **A***에 고정된 `O(E)`를 부여하거나 모든 경우 다익스트라보다 빠르다고 단정하지 않음.

## Ⅳ. 문제 조건에 따른 선택

```text
최단경로 문제
    ├─ 모든 정점 쌍 → 플로이드–워셜 등
    └─ 한 시작점
         ├─ 음수 간선 있음 → 벨만–포드 등
         └─ 음수 간선 없음
              ├─ 유효한 휴리스틱 → A* 검토
              └─ 일반 그래프 → 다익스트라
```

| 추가 조건 | 판단 |
|---|---|
| 모든 정점 쌍, 큰 희소 그래프 | 플로이드–워셜의 `O(V³)` 부담을 고려해 다른 방법 검토 |
| 음수 사이클 존재 | 도달 가능한 사이클을 반복할 수 있는 경로에는 유한한 최단거리 부재 |
| 경로 자체 필요 | 거리 갱신 시 선행 정점을 함께 기록해 역추적 |

## Ⅴ. 적용 사례와 검증

| 사례 | 가중치·조건 | 검증 사항 |
|---|---|---|
| 도로 경로 | 이동 시간, 통행 제한 | 시간대별 가중치의 유효성 |
| 네트워크 경로 | 링크 비용 | 연결 변화 후 경로 재계산 |
| 금융 환율 그래프 | 로그 변환 시 음수 간선 가능 | 음수 사이클의 도달 가능성 |

라우팅 프로토콜을 알고리즘과 일대일로 단순 대응하지 않고, 각 프로토콜의 실제 경로 선택·정책 조건을 구분.

## Ⅵ. 문제와 해결 방안

| 한계 | 해결 방안 |
|---|---|
| 음수 간선이 있는데 다익스트라 적용 | 가중치 특성을 확인하고 벨만–포드 등으로 전환 |
| 음수 사이클로 최단거리 정의 불가 | 도달 가능한 사이클 탐지 및 문제 조건 재검토 |
| 거리만 저장해 경로를 제시하지 못함 | 선행 정점을 함께 기록하고 역추적 검증 |
