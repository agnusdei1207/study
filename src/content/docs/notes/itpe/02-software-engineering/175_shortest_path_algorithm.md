## 연관 키워드

- 최단 경로, 가중 그래프, 다익스트라, 벨만-포드, 플로이드-워셜, 음수 가중치

## Ⅰ. 최단 경로 알고리즘의 개요

- 핵심 요약 : 최단 경로 문제는 그래프의 간선 비용 합이 최소가 되는 경로를 구하는 그래프 탐색 문제.
- 개념 : **최단 경로**는 가중 그래프에서 출발 정점과 도착 정점 사이 경로 비용 합이 최소인 경로.
- 배경 및 필요성 : 네트워크 라우팅, 지도 경로, 작업 비용 분석에서 연결 관계와 비용을 고려한 효율적 경로 선택 필요.
- 주요 목적 : 주어진 가중치 조건에 맞는 경로 및 비용 계산.

## Ⅱ. 문제 특성과 알고리즘 선택

- 핵심 요약 : 간선 가중치의 부호와 질의 범위에 따라 단일 출발점 또는 전체 쌍 알고리즘을 선택.
- 비음수 가중치 : 다익스트라의 탐욕적 확정이 성립 → 단일 출발점에 효율적.
- 음수 간선 허용 : 벨만-포드는 반복 완화로 단일 출발점 계산 및 음수 사이클 탐지.
- 모든 정점 쌍 : 플로이드-워셜은 중간 정점을 단계적으로 고려 → 조밀 그래프와 전체 쌍 질의에 적합.
- 그래프 희소성·정점 수·질의 빈도도 메모리와 실행 시간 선택 기준.

## Ⅲ. 다익스트라의 처리 흐름

- 핵심 요약 : 미확정 정점 중 잠정 거리가 가장 작은 정점을 확정하고 인접 간선을 완화.

```text
거리 초기화: 시작 0, 나머지 무한대
  ↓ 최소 힙에서 최솟값 정점 선택
정점 확정
  ↓ 모든 인접 간선 (u,v,w) 확인
dist[v] > dist[u] + w 이면 갱신
  ↓ 목적지 확정 또는 큐 소진
```

```text
후보 거리 갱신
현재 dist[u] + w(u,v)
       ↓ 더 작을 때
     dist[v] 교체
       ↓
부모[v] = u  → 경로 복원
```

- 인접 리스트와 이진 최소 힙 조합은 일반적으로 O((V+E) log V) 시간, 메모리는 O(V+E).

## Ⅳ. 알고리즘 비교

- 핵심 요약 : 음수 가중치 여부와 질의 범위를 우선 확인해 알고리즘을 고름.

| 비교 축 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
| --- | --- | --- | --- |
| 질의 | 단일 출발점 | 단일 출발점 | 모든 정점 쌍 |
| 음수 간선 | 허용 안 됨 | 허용 | 허용 |
| 음수 사이클 | 감지 보장 없음 | 출발점에서 도달 가능한 음수 사이클 탐지 | 대각 원소 음수로 판단 가능 |
| 대표 시간 | 힙 사용 시 O((V+E)logV) | O(VE) | O(V³) |

## Ⅴ. 한계와 방안

- 핵심 요약 : 잘못된 가중치 가정과 오버플로, 경로 동률 처리를 검증.

| 한계 | 원인·영향 | 대응 방안 |
| --- | --- | --- |
| 음수 간선에서 부정확 | 다익스트라의 거리 확정 전제 위반 | 입력 검증 후 벨만-포드 등 적용 |
| 큰 그래프 메모리·시간 | 조밀 표현과 전체 쌍 계산 비용 | 희소성·질의 형태에 맞춘 표현과 알고리즘 선택 |
| 비용 합 오버플로 | 고정 폭 정수 범위 초과 | 충분한 정수 폭과 무한대 센티널 검증 |
| 동률 경로의 비결정성 | 동일 비용 경로가 복수 존재 | 동률 규칙 명시 및 부모 갱신 조건 고정 |

## Ⅵ. 적용 제언

- 핵심 요약 : 서비스 담당자는 입력 가중치의 의미와 제약을 데이터 계약으로 고정하고 기준 사례로 검증.
- 경로 서비스는 방향성, 비용 단위, 음수 비용 가능성을 API 계약과 데이터 검증 규칙에 명시.
- 대규모 운영은 캐시·증분 재계산·그래프 갱신 주기를 서비스 정확도 요구와 함께 설계.

## Ⅶ. 결론

- 핵심 요약 : 최단 경로 알고리즘은 그래프 비용 조건에 따라 선택해야 정확성과 효율을 얻는 기본 기법.
- 비음수 단일 출발점에는 다익스트라가 적절하지만 전제 위반 시 다른 알고리즘이 필요.
