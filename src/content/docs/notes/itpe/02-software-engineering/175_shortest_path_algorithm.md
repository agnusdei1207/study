## 30초 인출

- 본질: 최단경로 알고리즘은 가중치 그래프에서 두 정점 사이의 비용이 가장 작은 경로를 찾는 알고리즘
- 메커니즘: 시작 정점의 거리를 0으로 두고 간선을 따라 더 짧은 거리가 발견되면 갱신(완화)하며 최단 거리를 확정
- 통찰: 간선 가중치가 음수일 수 있는지에 따라 쓸 수 있는 알고리즘이 달라지므로 그래프의 가중치 조건과 필요한 결과(한 점에서 모든 점, 모든 쌍)를 먼저 확인해 선택

<details>
<summary>핵심 용어</summary>

- **최단경로** : 가중치 그래프에서 두 정점 사이 간선 가중치 합이 최소인 경로
- **간선 완화(Edge Relaxation)** : 더 짧은 경로를 발견하면 정점의 현재 최단 거리를 갱신하는 것
- **다익스트라 알고리즘** : 음수 간선이 없는 그래프에서 가장 가까운 정점부터 확정하는 알고리즘
- **벨만-포드 알고리즘** : 음수 간선을 허용하며 모든 간선을 반복 완화하는 알고리즘
- **플로이드-워셜 알고리즘** : 모든 정점 쌍의 최단 거리를 동적 계획법으로 구하는 알고리즘
- **음수 사이클** : 한 바퀴 돌 때마다 비용이 줄어드는 순환. 최단 경로가 정의되지 않음

</details>

## 2~4교시 25점 답안

## Ⅰ. 최단경로 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **최단경로 알고리즘** 은 가중치 그래프에서 비용이 가장 작은 경로를 찾는 알고리즘 |
| 목적 | 경로 안내·네트워크 라우팅 등의 최소 비용 경로 결정 |

## Ⅱ. 최단경로 문제의 특징

| 특징 | 의미 |
|---|---|
| 가중치 그래프 | 간선마다 비용 존재 |
| 경로 비용 | 경로상 간선 가중치의 합 |
| 문제 유형 | 한 점에서 모든 점, 모든 쌍 |

## Ⅲ. 간선 완화의 원리

```text
   dist(A)=3
     A ──(2)──▶ B   dist(B)=9
현재 dist(B)=9  vs  dist(A)+2=5   →  5가 더 작으므로 dist(B)=5로 갱신
```

## Ⅳ. 대표 알고리즘의 비교

| 구분 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|---|---|---|---|
| 결과 | 한 점에서 모든 점 | 한 점에서 모든 점 | 모든 쌍 |
| 음수 간선 | 불가 | 가능(음수 사이클 검출) | 가능(음수 사이클 없음 조건) |
| 방식 | 가까운 정점부터 확정 | 모든 간선을 V−1회 완화 | 경유 정점을 늘려가며 갱신 |
| 시간 | O((V+E) log V) | O(VE) | O(V³) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 음수 간선에서 다익스트라 오류 | 음수 간선이 있으면 벨만-포드 사용 |
| 모든 쌍 계산의 큰 비용 | 정점 수가 큰 그래프는 필요한 출발점만 반복 계산 |
| 음수 사이클이 있으면 최단경로 없음 | 벨만-포드로 검출해 그래프 수정 |

## Ⅵ. 제언

음수 간선 유무와 필요한 결과를 먼저 확인해 알고리즘을 선택

```text
음수 간선 있음?
    ├─ 없음 ─ 한 점 기준 → 다익스트라 / 모든 쌍 → 플로이드-워셜
    └─ 있음 ─ 벨만-포드(음수 사이클 검출)
```

| 구분 | 항상 다익스트라 | 제언: 조건별 선택 |
|---|---|---|
| 음수 간선 | 오답 위험 | 벨만-포드 |
| 모든 쌍 | 반복 실행 | 플로이드-워셜 |
