## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 알고리즘·자료구조 → 최단경로 알고리즘(Shortest Path Algorithm)

## 지식 위치

소프트웨어공학 > 그래프 알고리즘 > 최단경로

## 30초 인출

- 본질: 간선에 가중치가 부여된 유향/무향 그래프에서 두 정점 사이의 경로 가중치 합이 최소가 되는 경로를 탐색하는 최적화 알고리즘 군
- 메커니즘: 간선 완화(Edge Relaxation: $D(v) > D(u) + w(u,v)$ 시 갱신) 연산 기반 → 단일 출발점 양수 가중치(다익스트라), 음수 가중치 허용 및 음수 사이클 검출(벨만-포드), 모든 정점 쌍 최단거리(플로이드-워셜), 휴리스틱 유도(A*)로 분기
- 통찰: 음수 가중치가 포함된 그래프에 다익스트라를 적용하면 탐욕적 거리 확정 전제가 붕괴되므로 문제 도메인의 가중치 조건, 단일/전체 정점 범위, 목표 지점 존재 여부에 따른 명확한 알고리즘 선택 필수

<details>
<summary>핵심 용어</summary>

- **최단경로 (Shortest Path)** : 가중치 그래프에서 시작 노드 $s$부터 목적 노드 $t$까지의 간선 가중치 합이 가장 작은 경로
- **간선 완화 (Edge Relaxation)** : 현재까지 알려진 정점 $v$의 최단거리보다, 정점 $u$를 거쳐서 가는 경로가 더 짧을 경우 $D(v)$를 갱신하는 기본 연산
- **음수 가중치 사이클 (Negative Weight Cycle)** : 사이클을 한 번 순환할 때마다 총비용이 음수로 감소하여 무한 루프가 발생하는 그래프 구조
- **다익스트라 (Dijkstra)** : 음수 간선이 없는 그래프에서 우선순위 큐(Heap)를 사용하여 단일 출발점 최단경로를 $O((V+E)\log V)$에 구하는 탐욕 알고리즘
- **벨만-포드 (Bellman-Ford)** : 음수 간선이 존재할 수 있는 그래프에서 모든 간선을 $V-1$회 반복 완화하여 최단거리를 구하고 음수 사이클을 판별하는 알고리즘
- **플로이드-워셜 (Floyd-Warshall)** : 동적 계획법(DP)을 기반으로 경유 노드를 점진 확장하여 모든 정점 쌍 간의 최단경로를 $O(V^3)$에 구하는 알고리즘
</details>

## 2~4교시 예상문제 (25점)

> 그래프 최단경로(Shortest Path) 문제의 핵심 원리인 간선 완화(Relaxation)를 설명하고, 대표적인 4대 알고리즘(다익스트라, 벨만-포드, 플로이드-워셜, A*)의 특징 비교 및 실무 도메인별 선정 기준을 제시하시오. (25점)

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 가중치(Weight)가 부여된 그래프 $G=(V, E)$에서 출발 정점에서 도착 정점까지 이동하는 데 소요되는 경로 가중치의 총합을 최소화하는 경로를 도출하는 알고리즘 |
| 목적 | 네트워크 패킷 라우팅(OSPF, RIP), 지도 내비게이션 길찾기, 물류 배송 경로 최적화 및 금융 거래 차익거래(Arbitrage) 기회 탐지 |

## Ⅱ. 핵심 특징

| 특징 | 세부 내용 |
|---|---|
| 최적 부분 구조 (Optimal Substructure) | 출발점 $s$에서 $t$까지의 최단경로 상에 중간 정점 $v$가 존재한다면, $s$에서 $v$까지의 부분 경로 역시 반드시 최단경로 성립 |
| 간선 완화 (Relaxation) 기반 | 모든 최단경로 알고리즘은 거리를 무한대($\infty$)로 초기화한 후 더 짧은 경유 경로 발견 시 거리를 점진적으로 줄여나가는 공통 원리 공유 |
| 가중치 제약에 따른 분기 | 음수 가중치 간선 존재 여부, 음수 사이클 존재 여부에 따라 알고리즘 선택 강제 |
| 경로 추적을 위한 선행자 배열 | 최단 거리 값뿐만 아니라 실제 이동 경로를 역추적하기 위해 각 노드의 직전 방문 노드(`parent[v]`)를 함께 갱신 |

도메인의 제약 조건(음수 비용 허용 여부, 단일/전체 정점 쌍 여부)에 따라 최적의 복잡도와 안정성을 가진 알고리즘 선정이 핵심.

## Ⅲ. 체계·프로세스

```text
[간선 완화 (Edge Relaxation) 메커니즘]
         기존 최단거리 D[v] = 10
        ┌───────────────────────► [ v ] (도착 노드)
        │                          ▲
        │ D[u] = 5                 │ 간선 가중치 w(u,v) = 2
        │                          │
      [ s ] ──────► [ u ] ─────────┘ (경유 노드)
     (시작)
  - 완화 판별식: D[u] + w(u, v) < D[v] (즉, 5 + 2 = 7 < 10)
  - 완화 실행  : D[v] = 7 단축 갱신, parent[v] = u 등록

[최단경로 알고리즘 선택 의사결정 흐름]
  최단경로 탐색 요구
       │
       ├─ [모든 정점 쌍 최단거리] ──► 플로이드-워셜 (O(V^3), DP)
       │
       └─ [단일 출발점 최단거리]
            │
            ├─ [음수 가중치 존재] ──► 벨만-포드 (O(VE), 사이클 탐지)
            │
            └─ [음수 가중치 없음]
                 │
                 ├─ [목적지 명확·휴리스틱] ──► A* 알고리즘 (f=g+h)
                 │
                 └─ [일반 그래프 탐색]   ──► 다익스트라 (O((V+E)logV))
```

간선 완화의 기본 연산으로부터 시작하여 요구 탐색 범위, 음수 가중치 존재 여부, 휴리스틱 유무에 따라 최적 알고리즘을 결정하는 프로세스.

## Ⅳ. 종류·비교

| 비교 항목 | 다익스트라 (Dijkstra) | 벨만-포드 (Bellman-Ford) | 플로이드-워셜 (Floyd-Warshall) | A* 알고리즘 |
|---|---|---|---|---|
| **탐색 범위** | 단일 출발점 ──► 모든 정점 | 단일 출발점 ──► 모든 정점 | 모든 정점 쌍 간 최단거리 ($V \times V$) | 단일 출발점 ──► 단일 도착점 |
| **시간 복잡도** | $O((V + E) \log V)$ (우선순위 큐) | $O(V \cdot E)$ | $O(V^3)$ (3중 루프 DP) | 휴리스틱 품질에 따라 가변 |
| **음수 간선 허용** | **불허** (오답 발생) | **허용** (완전 지원) | **허용** (음수 간선 지원) | **불허** (비음수 가중치) |
| **음수 사이클 탐지** | 불가 | 가능 ($V$번째 완화 발생 시 탐지) | 가능 (대각 성분 $D[i][i] < 0$ 시) | 불가 |
| **알고리즘 패러다임** | 탐욕법 (Greedy) | 간선 반복 완화 (Relaxation) | 동적 계획법 (Dynamic Programming) | 최적 우선 탐색 (휴리스틱 결합) |
| **대표 응용 도메인** | OSPF 라우팅, 실시간 지도 | 거리 벡터 라우팅(RIP), 통화 차익거래 | 전체 경로 테이블, 소셜 네트워크 연결 | 내비게이션, 게임 길찾기, 로봇 주행 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 음수 간선이 존재하는 네트워크에서 다익스트라 적용 시 이미 방문 완료된 노드의 최단경로가 뒤집히는 오류 | 사전에 가중치 양수 조건을 검증하고, 음수 간선이 존재할 경우 벨만-포드 알고리즘으로 전환 |
| 벨만-포드 알고리즘의 느린 수행 시간($O(VE)$)으로 인한 대규모 네트워크 적용 한계 | 큐를 활용하여 직전 단계에서 거리가 변경된 정점과 연결된 간선만 완화하는 SPFA(Shortest Path Faster Algorithm) 적용 |
| 대규모 그래프에서 플로이드-워셜 적용 시 $V=1000$만 되어도 10억 회 연산 발생($O(V^3)$)으로 시간 초과 | 희소 그래프(Sparse Graph) 환경에서는 다익스트라를 $V$회 반복 실행($O(V \cdot E \log V)$)하는 존슨(Johnson) 알고리즘 도입 |

## Ⅵ. 제언

실제 시스템 구현 시에는 알고리즘 자체의 이론적 시간복잡도뿐만 아니라 그래프 표현 방식(인접 행렬 vs 인접 리스트)과 메모리 캐시 적중률을 고려한 하이브리드 아키텍처 구축 필요.

```text
[엔터프라이즈 최단경로 파이프라인]
  그래프 수집 → 음수 간선 검증 → 인접 리스트 모델링 → 최적 엔진 선택 → 경로 역추적
```

| 검증 단계 | 사전 전처리 단계 | 런타임 최단경로 연산 |
|---|---|---|
| 핵심 통제 | 인접 리스트 생성 및 음수 가중치 존재 여부 자동 스캔 | 우선순위 큐(Binary Heap/Fibonacci Heap) 기반 완화 연산 |
| 성능 목표 | 정점 수 $V$, 간선 수 $E$ 규모에 맞는 메모리 점유 최소화 | 밀리초 단위 이내의 최단 경로 도출 및 선행자 역추적 완료 |
