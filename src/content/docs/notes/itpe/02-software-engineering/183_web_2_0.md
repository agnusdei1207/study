## 연관 키워드

- Web 2.0, UGC(User-Generated Content), AJAX(Asynchronous JavaScript and XML), 집단지성, 네트워크 효과(Network Effect)
- 롱테일 법칙(The Long Tail), Open API, 매시업(Mashup), 폭소노미(Folksonomy), SaaS(Software as a Service), 데이터 이동권(Data Portability), PWA(Progressive Web App)

## Ⅰ. Web 2.0의 개요

- 핵심 요약 : 웹을 일방적 정보 열람 공간에서 개방·참여·공유 기반의 양방향 플랫폼으로 전환한 진화적 패러다임.
- 개념 : 팀 오라일리(Tim O'Reilly)가 2004년에 제시한 웹의 진화적 패러다임으로, 웹을 단순한 정보의 일방적 열람 공간(Read-Only Web)에서 벗어나 사용자가 직접 콘텐츠를 생산·공유·참여하는 양방향 플랫폼(Read-Write Web)으로 전환시킨 기술 및 비즈니스 혁명.
- 배경 및 필요성 : 2000년대 초 닷컴 버블 붕괴 이후 살아남은 기업들의 공통적 성공 방정식 분석, 브로드밴드 인터넷 보급과 AJAX(Asynchronous JavaScript and XML) 등 웹 기술 혁신.
- 주요 목적 : 개방(Openness), 참여(Participation), 공유(Sharing)의 3대 핵심 철학 구현과 집단지성 기반 플랫폼 가치 창출.

## Ⅱ. Web 2.0의 특징

- 핵심 요약 : 사용자 참여와 집단지성, 네트워크 효과, 플랫폼화가 결합된 양방향 웹 체계.

1. 사용자 생성 콘텐츠 UGC(User-Generated Content) 생산과 집단지성 축적.
2. 사용자 증가에 따른 데이터 축적과 서비스 가치의 기하급수적 증가인 네트워크 효과(Network Effect).
3. 상위 20% 대중적 히트작과 하위 80% 비인기 틈새 상품(Niche)의 결합으로 거대한 전체 시장을 형성하는 롱테일 법칙(The Long Tail).
4. PC(Personal Computer) 설치형 소프트웨어를 브라우저 기반 SaaS(Software as a Service)로 대체하는 플랫폼으로서의 웹.
5. 핵심 데이터의 외부 개방과 제3자 결합을 통한 Open API(Application Programming Interface)·매시업(Mashup) 생태계.
6. 전문가의 고정 분류 체계 대신 사용자 자유 태그(#) 기반 분류인 폭소노미(Folksonomy).

## Ⅲ. Web 2.0의 구조 (흐름)

- 핵심 요약 : 읽기 전용 웹에서 읽기·쓰기 웹, 읽기·쓰기·소유 웹으로 진화하는 층위 구조.
- 웹 진화 단계 구조.

```text
[ Web 1.0 (1990s) ]         [ Web 2.0 (2000s) ]       [ Web 3.0 (2020s+) ]
  읽기 전용                    읽기/쓰기                   읽기/쓰기/소유
  (Read-Only)                (Read-Write)              (Read-Write-Own)
  정적 HTML 웹페이지           동적 플랫폼(AJAX, SNS)       탈중앙화(블록체인, DApp)
  소수 관리자 발행             사용자 생성 콘텐츠(UGC)       데이터 주권·토큰 경제
  포털 중심                   플랫폼 중심                  분산 네트워크
      └──────────────── 진화 ────────────────┘
```

- AJAX 비동기 통신 흐름.

```text
 [ 브라우저(JavaScript) ] ──비동기 요청──▶ [ 웹 서버 ]
          ▲                                 │
          └─────── XML/JSON 응답 ◀──────────┘
   → 페이지 전체 새로고침 없는 부분 렌더링
```

- 대표 사례 : AJAX 기반 Google Maps, Gmail / UGC 기반 위키백과, 유튜브, 블로그 / 구글 맵 API 기반 부동산 매시업 서비스.

## Ⅳ. Web 1.0·Web 2.0·Web 3.0의 비교

- 핵심 요약 : 읽기 전용 포털에서 참여형 플랫폼, 탈중앙 소유 웹으로의 축 확장.

| 구분 | Web 1.0 | Web 2.0 | Web 3.0 |
|---|---|---|---|
| 웹 모델 | 읽기 전용(Read-Only) | 읽기/쓰기(Read-Write) | 읽기/쓰기/소유(Read-Write-Own) |
| 콘텐츠 주체 | 소수 관리자 | 사용자(UGC) | 사용자 데이터 주권 |
| 대표 기술 | 정적 HTML(HyperText Markup Language) | AJAX, SNS(Social Networking Service) | 블록체인, DApp(Decentralized Application) |
| 서비스 중심 | 포털(Yahoo, 네이버) | 플랫폼(YouTube, Meta) | 분산 네트워크 |
| 가치 창출 구조 | 조회 중심 | 네트워크 효과·롱테일 | 데이터 주권·토큰 경제 |

## Ⅴ. Web 2.0의 장점과 한계

- 핵심 요약 : 네트워크 효과 기반 가치 창출의 장점, 인프라·보안·데이터 독점의 한계.
- 장점
  1. 사용자 규모에 비례하는 네트워크 효과 기반의 플랫폼 가치 증대.
  2. 롱테일 법칙에 따른 틈새 시장의 결합과 전체 시장 확장.
  3. AJAX 비동기 통신 기반의 향상된 UX(User Experience).
  4. Open API 개방을 통한 매시업형 신규 서비스 창출.
- 한계점 1 : UGC 폭증에 따른 인프라 스케일링 한계
  - 한계점 : 텍스트, 이미지, 비디오 등 비정형 UGC의 기하급수적 유입으로 기존 관계형 데이터베이스 RDB(Relational Database)의 수직적 확장 한계 봉착.
  - 해결 방안 : NoSQL(Not Only SQL; MongoDB, Cassandra) 및 분산 오브젝트 스토리지(S3(Simple Storage Service) 등) 기반 수평 확장(Scale-Out) 아키텍처, 글로벌 CDN(Content Delivery Network) 에지 캐싱 구축.
- 한계점 2 : 클라이언트 비동기 인터랙션 증가에 따른 보안 취약점 확대
  - 한계점 : 동적 DOM(Document Object Model) 조작과 REST(Representational State Transfer) API 통신의 보편화로 크로스 사이트 스크립팅 XSS(Cross-Site Scripting), CSRF(Cross-Site Request Forgery), API 비인가 접근 등 웹 보안 위협 급증.
  - 해결 방안 : 엄격한 콘텐츠 보안 정책 CSP(Content Security Policy) 수립, 입출력 데이터의 컨텍스트 기반 인코딩/살균(Sanitization), OAuth(Open Authorization) 2.0/OIDC(OpenID Connect) 기반 보안 인증 표준화.
- 한계점 3 : 플랫폼 기업의 데이터 독점 및 프라이버시 침해
  - 한계점 : 개방과 공유의 기치로 시작한 플랫폼에 데이터와 트래픽이 종속되어 사용자 데이터 주권 상실 및 알고리즘 폐쇄성 초래.
  - 해결 방안 : 데이터 이동권(Data Portability) 및 마이데이터 표준 연계 의무화, 탈중앙화 식별자 DID(Decentralized Identifier) 및 Web3 기반 데이터 주권 회복 기술 융합 검토.

## Ⅵ. 웹 진화 관점에서의 기술사적 제언

- 핵심 요약 : 데이터 주권 회복 아키텍처 모색과 PWA 기반 개방성 계승의 병행.
- 데이터 독점 폐해 극복과 탈중앙화 Web 3.0으로의 점진적 전환 : 거대 빅테크 플랫폼의 개인정보·행동 데이터 독점 수익화(감시 자본주의) 문제 극복을 위한 탈중앙 신원증명 DID(Decentralized Identifier)와 자기주권 신원(Self-Sovereign Identity) 결합 데이터 주권 회복 아키텍처 모색 필요.
- PWA(Progressive Web App, 프로그레시브 웹 앱)를 통한 플랫폼 개방성 계승 : 특정 모바일 앱스토어(구글/애플)의 독점 수수료(30%) 정책 대응, 웹 표준 기반 자유로운 멀티 플랫폼 서비스 지속 배포 권장.

## Ⅶ. 결론

- 핵심 요약 : 개방·참여·공유 가치의 확산과 인프라·보안·데이터 주권 과제의 동시 관리 필요.
- 요약 : UGC와 네트워크 효과를 기반으로 플랫폼 경제를 형성한 양방향 웹 패러다임.
- 시사점 : 수평 확장 인프라, 웹 보안 표준화, 데이터 이동권·DID 기반 주권 회복의 단계적 추진 필요.
