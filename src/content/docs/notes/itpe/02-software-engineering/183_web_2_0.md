## 핵심 용어
- 플랫폼으로서의 웹(Web as a Platform): 설치형 애플리케이션 대신 브라우저 상에서 모든 소프트웨어 기능이 서비스(SaaS) 형태로 실행되는 환경
- AJAX(Asynchronous JavaScript and XML): 전체 웹페이지를 새로고침하지 않고 백그라운드에서 서버와 비동기 데이터를 주고받는 브라우저 기술
- 매시업(Mashup): 공개된 서로 다른 웹 서비스들의 Open API를 조합하여 완전히 새로운 독창적인 서비스를 창출하는 개발 기법 (예: 지도 API + 부동산 매물 데이터)
- 폭소노미(Folksonomy): 정형화된 분류 체계(Taxonomy) 대신 일반 사용자들이 자발적으로 부여한 태그(Tag)를 기반으로 정보를 구조화하는 집단지성 분류 방식
- 프로슈머(Prosumer): 생산자(Producer)와 소비자(Consumer)의 합성어로, 콘텐츠를 소비함과 동시에 주도적으로 생산하는 Web 2.0 사용자 모델

## 핵심 통찰
- Web 2.0은 특정 단일 기술의 탄생이 아니라, 비동기 통신(AJAX)과 경량 데이터 포맷(JSON/REST)의 대중화로 촉발된 '소프트웨어 유통 및 비즈니스 모델의 패러다임 전환'임
- 시스템의 가치가 소프트웨어 코드 자체가 아니라 사용자가 플랫폼에 축적하는 '데이터의 규모와 네트워크 효과(Network Effect)'에 의해 결정되는 시대를 열었음
- 그러나 데이터 주권이 구글, 메타 등 소수 빅테크 플랫폼에 독점적으로 집중되는 '플랫폼 봉건주의'를 낳았으며, 이는 블록체인 기반 Web 3.0 논의의 직접적 도화선이 됨

## 이웃 토픽과 구분
| 비교 항목 | Web 1.0 | Web 2.0 | Web 3.0 |
| :--- | :--- | :--- | :--- |
| **패러다임 정의** | 읽기 전용 (Read-Only) 웹 | 읽기-쓰기 (Read-Write) 상호작용 웹 | 읽기-쓰기-소유 (Read-Write-Own) 탈중앙화 웹 |
| **사용자 역할** | 수동적 정보 소비자 | 능동적 콘텐츠 생산자 (프로슈머) | 데이터 주권 보유자 및 생태계 기여자 |
| **소프트웨어 형태** | 정적 HTML 웹페이지 | 플랫폼으로서의 웹 (SaaS, SPA) | 스마트 컨트랙트 기반 DApp (분산 앱) |
| **핵심 기술** | 정적 웹 서버, HTML, 디렉터리 | AJAX, Open API, REST, JSON | 블록체인, DID, IPFS, 시맨틱 웹, AI |
| **데이터 소유권** | 사이트 운영자 독점 | 중앙 플랫폼 기업 독점 | 분산 원장 기반 개별 사용자 소유 |

## 문제·원인·대책
| 문제상황 | 원인 | 기술적 대책 |
| :--- | :--- | :--- |
| **오픈 API 남용 및 악의적 DoS 트래픽** | 서드파티 개발자에게 개방된 REST 엔드포인트에 대한 요청량 폭주 | API Gateway 도입, API Key 발급, 초당 처리율 제한(Rate Limiting / Throttling) |
| **사용자 생성 콘텐츠(UGC) 신뢰도 및 유해성** | 누구나 자유롭게 정보를 등록할 수 있어 가짜 뉴스, 악성 링크, 어뷰징 유입 | 신뢰도 알고리즘(PageRank 응용), AI 기반 유해 텍스트/이미지 자동 필터링 파이프라인 |
| **페이지 깜빡임 및 비동기 요청 스파게티** | 복잡한 비동기 AJAX 호출 간의 콜백 지옥(Callback Hell) 및 상태 불일치 | Promise/Async-Await 도입 및 React, Vue 등 단방향 데이터 바인딩 SPA 프레임워크 적용 |

## 내 의견
- Web 2.0은 현대 IT 산업을 지탱하는 클라우드, 오픈 API 생태계, MSA의 초석을 마련한 기념비적인 기술 진화 단계임
- 오늘날 웹 엔지니어링 실무에서는 Web 2.0의 유산인 RESTful API와 비동기 컴포넌트 아키텍처를 계승하되, OpenAPI Specification(Swagger)을 통한 규격화와 OAuth2/OIDC 표준 인증 체계를 견고히 갖추어야 함
- 향후 웹 아키텍처는 Web 2.0의 뛰어난 사용자 경험(SPA) 위에, 사용자의 개인정보를 보호하는 영지식 증명(ZKP) 및 온디바이스 AI 에이전트가 결합된 지능형 탈중앙화 인터페이스로 지속 진화할 것임
