## 연관 키워드

- Web 2.0, UGC(User-Generated Content), AJAX(Asynchronous JavaScript and XML), 집단지성, 네트워크 효과(Network Effect)
- 롱테일 법칙(The Long Tail), Open API, 매시업(Mashup), 폭소노미(Folksonomy), SaaS(Software as a Service), 데이터 이동권(Data Portability), PWA(Progressive Web App)

## Ⅰ. Web 2.0의 개요

- 핵심 요약 : 웹을 일방적 열람 공간에서 개방·참여·공유 기반의 양방향 플랫폼으로 바꾼 웹 진화 패러다임.
- 개념 : **Web 2.0**은 웹을 읽기 전용(Read-Only)에서 읽기·쓰기(Read-Write) 구조로 바꾼 웹 진화 패러다임으로, 사용자가 콘텐츠를 직접 생산·공유하는 플랫폼형 웹을 뜻함.
- 배경 및 필요성 : 2000년대 초 닷컴 버블 붕괴 후 살아남은 웹 기업들의 공통 성공 요인을 분석하는 과정에서 개념이 정리됨. 브로드밴드 보급과 **AJAX** (Asynchronous JavaScript and XML) 같은 기술이 페이지 전체를 새로 고치지 않고도 상호작용하는 서비스를 가능하게 한 것이 배경임.
- 주요 목적 : 개방(Openness), 참여(Participation), 공유(Sharing)의 세 가치를 구현하고, **집단지성**(다수 사용자의 참여로 개별 지식보다 나은 결과가 만들어지는 현상)을 기반으로 플랫폼 가치를 키우는 것.

## Ⅱ. Web 2.0의 특징 및 장점

- 핵심 요약 : 사용자 참여, 네트워크 효과, 플랫폼화가 맞물려 서비스 가치가 참여자 수에 비례해 커지는 구조.

1. **사용자 생성 콘텐츠** (UGC, User-Generated Content) : 사용자가 글·사진·영상을 직접 올리고 평가 → 콘텐츠 양이 늘고 집단지성이 축적됨.
2. **네트워크 효과** (Network Effect) : 사용자가 늘수록 쌓이는 데이터와 상호작용이 서비스 가치를 키우는 원리 → 후발 서비스가 넘기 어려운 진입장벽 형성.
3. **롱테일 법칙** (The Long Tail) : 대중적 히트 상품과 다수의 비인기 틈새 상품을 합쳐 전체 시장이 커지는 현상 → 온라인에서 틈새 수요까지 수익화 가능.
4. **SaaS** (Software as a Service) : 설치형 소프트웨어를 브라우저로 구독해 이용하는 방식 → 설치·갱신 부담 감소와 어디서든 접근 가능.
5. **Open API** (Open Application Programming Interface) : 핵심 데이터를 외부에 공개하면 제3자가 이를 결합해 **매시업**(여러 공개 데이터와 서비스를 조합해 새 서비스를 만드는 방식)을 만듦 → 플랫폼 밖에서 신규 서비스 창출.
6. **폭소노미** (Folksonomy) : 전문가가 정한 고정 분류 대신 사용자가 다는 자유 태그로 정보를 분류 → 신조어와 대중의 관점을 빠르게 반영.

## Ⅲ. Web 2.0의 구조 (흐름)

- 핵심 요약 : 읽기 전용 웹에서 읽기·쓰기 웹, 소유 웹으로 이어지는 진화 단계와, 브라우저·서버 사이의 비동기 통신 흐름.

1. Web 1.0 (1990년대) : 소수 제작자가 정적 HTML (HyperText Markup Language) 페이지를 발행하는 포털 중심 웹.
2. Web 2.0 (2000년대) : 사용자가 콘텐츠를 만들고 참여하는 플랫폼 중심 웹.
3. Web 3.0 (2020년대 이후 논의) : 사용자가 데이터를 소유·통제하는 분산 웹 구상. 정의와 범위에 대한 해석이 아직 갈림.

```text
[ 웹 진화 단계 ]

Web 1.0 : 읽기 전용
      ↓
Web 2.0 : 읽기·쓰기
      ↓
Web 3.0 : 읽기·쓰기·소유
```

```text
[ AJAX 비동기 통신 ]

브라우저 (JavaScript)
      ↓ 비동기 요청
웹 서버
      ↓ XML·JSON 응답
브라우저가 화면 일부만 갱신
```

- 대표 사례 : AJAX 기반의 Google Maps와 Gmail, UGC 기반의 위키백과·유튜브·블로그, Google Maps API를 결합한 부동산 매시업 서비스.

## Ⅳ. Web 1.0·Web 2.0·Web 3.0의 비교

- 핵심 요약 : 읽기 전용 포털에서 참여형 플랫폼, 탈중앙 소유 웹으로 콘텐츠 주체와 가치 창출 구조가 이동.

| 구분 | Web 1.0 | Web 2.0 | Web 3.0 |
| --- | --- | --- | --- |
| 웹 모델 | 읽기 전용(Read-Only) | 읽기·쓰기(Read-Write) | 읽기·쓰기·소유(Read-Write-Own) |
| 콘텐츠 주체 | 소수 관리자 | 사용자(UGC) | 사용자 데이터 주권 |
| 대표 기술 | 정적 HTML | AJAX, 소셜 네트워킹 서비스(SNS, Social Networking Service) | 블록체인, DApp(Decentralized Application) |
| 서비스 중심 | 포털 | 플랫폼 | 분산 네트워크 |
| 가치 창출 구조 | 조회 중심 | 네트워크 효과·롱테일 | 데이터 주권·토큰 경제 |

- 선택 기준 : 콘텐츠를 누가 만들고 데이터를 누가 통제하는지를 기준으로 세 단계를 구분함. Web 3.0은 확정된 표준이 아닌 개념 단계라 범위를 단정하지 않음.

## Ⅴ. Web 2.0의 한계와 방안

- 핵심 요약 : 인프라 확장, 보안 위협, 데이터 독점을 수평 확장·보안 표준·데이터 이동권으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 인프라 확장 한계 | 비정형 UGC 폭증으로 관계형 데이터베이스(RDB, Relational Database)의 수직 확장 한계 도달 | 수평 확장(Scale-Out) 아키텍처, NoSQL, 분산 오브젝트 스토리지, CDN(Content Delivery Network) 캐싱 | 응답 지연 시간, 확장 비용 |
| 클라이언트 보안 위협 | DOM(Document Object Model) 조작과 REST(Representational State Transfer) 기반 API 통신 보편화로 **XSS**(Cross-Site Scripting), CSRF(Cross-Site Request Forgery), API 비인가 접근 증가 | 콘텐츠 보안 정책 CSP(Content Security Policy) 적용, 입출력 값의 컨텍스트 기반 인코딩·살균(Sanitization), OAuth 2.0·OIDC(OpenID Connect) 기반 인증 표준화 | 취약점 점검 결과, 비인가 호출 탐지 건수 |
| **데이터 이동권** (Data Portability) 부재 | 개방을 내세운 플랫폼에 데이터와 트래픽이 종속 → 사용자 데이터 주권 상실과 알고리즘 폐쇄성 | 이동권 보장과 마이데이터 연계, 데이터 이동 표준 마련 | 데이터 전송 요구 처리 시간 |

## Ⅵ. 웹 진화 관점에서의 기술사적 제언

- 핵심 요약 : 데이터 주권 회복 구조와 웹 표준 기반 개방성의 병행 추진.
- 플랫폼의 데이터 독점은 사용자가 자신의 데이터를 통제하는 구조가 제도와 기술 양쪽에서 함께 마련되어야 풀린다. 탈중앙 식별자 기술인 **탈중앙화 식별자** (DID, Decentralized Identifier)는 기술 도입 자체보다 사용자 통제권을 기준으로 시범 적용 범위를 정하는 것이 바람직하다.
- 특정 모바일 앱스토어의 수수료 정책에 대한 규제 논쟁이 이어지는 만큼, **PWA** (Progressive Web App)를 주요 채널의 하나로 두어 웹 표준 기반의 멀티 플랫폼 전략을 세우는 것이 개방성 계승에 유리하다.

## Ⅶ. 결론

- 핵심 요약 : Web 2.0은 사용자를 생산자로 만들어 참여와 네트워크 효과를 플랫폼 가치로 전환한 웹 패러다임.
- 시사점 : 웹의 다음 단계로 논의가 넘어가더라도 참여와 개방의 원리는 계승되며, 그 가치는 인프라·보안·데이터 주권을 함께 관리할 때 유지됨.
