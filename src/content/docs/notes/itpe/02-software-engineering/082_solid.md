## 연관 키워드

- SOLID, SRP, OCP, LSP, ISP, DIP, 조합

## Ⅰ. 객체지향 설계원칙 SOLID의 개요

- 핵심 요약 : SOLID는 객체지향 설계의 책임 분리·확장성·대체가능성·인터페이스 분리·의존성 방향을 설명하는 다섯 원칙.
- 개념 : SOLID는 객체지향 설계의 책임 분리·확장성·대체가능성·인터페이스 분리·의존성 방향을 설명하는 다섯 원칙.
- 배경 및 필요성 : 변경 영향이 모듈 전반에 퍼지거나 상속·의존성 구조가 경직되면 유지보수 위험 증가.
- 주요 목적 : 변경에 강하고 테스트·확장 가능한 모듈 경계 형성.

## Ⅱ. 객체지향 설계원칙 SOLID의 특징 및 장점

- 핵심 요약 : SRP, OCP, LSP, ISP, DIP의 다섯 원칙; 추상화·조합·의존성 역전 활용.

1. 구조 명시: SRP, OCP, LSP, ISP, DIP의 다섯 원칙; 추상화·조합·의존성 역전 활용 → 변경에 강하고 테스트·확장 가능한 모듈 경계 형성.
2. 기대 효과 : SOLID는 규칙의 기계적 적용이 아니라 변경과 의존성을 관리하는 객체지향 설계 휴리스틱.
3. 적용 원칙 : 설계리더는 SOLID를 체크리스트로 강제하지 말고 실제 변경사례·테스트성·대체요구를 근거로 모듈 경계 판단.

## Ⅲ. 객체지향 설계원칙 SOLID의 구조 (흐름)

- 핵심 요약 : 변경이유·의존성 분석 → 책임·인터페이스 경계 설정 → 구현·조합 → 대체가능성·변경 시나리오 검증.

```text
변경이유·의존성 분석
  ↓
책임·인터페이스 경계 설정
  ↓
구현·조합
  ↓
대체가능성·변경 시나리오 검증
```

- 핵심 구성 : SRP, OCP, LSP, ISP, DIP의 다섯 원칙; 추상화·조합·의존성 역전 활용.

```text
변경이유 식별 → 책임·추상화 → 의존성 방향 → 대체·확장 시험
```

## Ⅴ. 객체지향 설계원칙 SOLID의 한계와 방안

- 핵심 요약 : 주요 한계는 교조적 분리·취약한 상속·과잉 계층이며, 원인별 대응과 검증지표의 연계가 필요.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |

| 과잉 계층 | 작은 변경에 추적 복잡성 | 간결한 구조·삭제 가능한 추상화 | 변경경로·리뷰시간 |

1. 주체·실행 : 설계리더는 SOLID를 체크리스트로 강제하지 말고 실제 변경사례·테스트성·대체요구를 근거로 모듈 경계 판단.
