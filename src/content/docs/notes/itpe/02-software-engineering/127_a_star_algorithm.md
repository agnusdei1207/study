## 연관 키워드

- A* Algorithm, A* 알고리즘, 최단 경로 탐색
- 평가 함수 f(n) = g(n) + h(n), 휴리스틱(Heuristic)
- 허용성(Admissibility), 일관성(Consistency)
- 최고 우선 탐색(Best-First Search), Open List, Closed List
- IDA*, SMA*, JPS(Jump Point Search), HPA*, D* Lite

## Ⅰ. A* 알고리즘의 개요

- 핵심 요약 : 실제 비용과 휴리스틱 추정치의 합으로 가장 유망한 노드를 먼저 탐색하는 최단 경로 알고리즘.
- 개념 : 시작 노드에서 현재 노드까지의 실제 비용 $g(n)$과 현재 노드에서 목표까지의 추정 비용인 휴리스틱 $h(n)$을 합산한 평가 함수 $f(n) = g(n) + h(n)$으로 가장 유망한 노드를 우선 탐색하는 **A* 알고리즘** (A* Algorithm, 최고 우선 탐색 기반의 그래프 탐색 알고리즘).
- 배경 및 필요성 : 다익스트라(Dijkstra) 알고리즘은 모든 방향으로 균등하게 확산하며 탐색하므로 목표와 무관한 노드까지 연산하는 낭비가 큼. 휴리스틱으로 목표 방향을 안내하면 탐색 공간을 줄일 수 있음.
- 주요 목적 : 최적성 보장과 탐색 효율의 균형, 실시간 경로 탐색 비용 최소화.
- 주요 응용 분야 : 게임 AI(Artificial Intelligence)의 길찾기, 내비게이션 경로 탐색, 로봇과 자율주행 이동 경로 계획.

## Ⅱ. A* 알고리즘의 특징 및 장점

- 핵심 요약 : 평가 함수 f(n) = g(n) + h(n)과 허용성·일관성 조건을 갖춘 휴리스틱이 최적성과 탐색 효율을 함께 확보하는 구조.

1. **평가 함수** : f(n) = g(n) + h(n), 여기서 g(n)은 시작 노드에서 n까지의 정확한 실제 비용, h(n)은 n에서 목표까지 예상되는 휴리스틱 비용 → 실제 비용과 전망을 함께 반영하여 유망 경로를 선별.
2. 최고 우선 탐색 : Open List(우선순위 큐)에서 f(n)이 최소인 노드를 꺼내 확장 → 목표 방향의 노드부터 처리.
3. **허용성** (Admissibility) : h(n) ≤ h*(n), 즉 휴리스틱이 실제 최단 비용 h*(n)을 과대평가하지 않음 → 최적 경로 도출 보장.
4. **일관성** (Consistency) : 모든 노드 n과 이웃 n'에 대해 h(n) ≤ c(n, n') + h(n') 성립 → 한 번 방문한 노드를 다시 열지 않아 탐색 효율 향상.
5. 이중 리스트 관리 : Open List(탐색 대기 노드)와 Closed List(확장 완료 노드)로 상태를 구분 → 중복 탐색 방지.

## Ⅲ. A* 알고리즘의 구조 (흐름)

- 핵심 요약 : 평가 함수로 Open List의 최소 노드를 고르고, 확장 결과를 다시 Open List에 등록하는 반복 탐색 루프.

```text
[ 평가 함수 ]

f(n) = g(n) + h(n)
  g(n) : 시작 → n 까지의 실제 비용
  h(n) : n → 목표 까지의 추정 비용
```

```text
[ A* 탐색 루프 ]

Open List에서 f(n) 최소 노드 추출
              ↓
Closed List로 이동 (확장 완료)
              ↓
인접 이웃 노드의 g, h, f 계산
              ↓
Open List에 등록 후 반복
```

## Ⅳ. 주요 최단 경로 알고리즘의 비교

- 핵심 요약 : 평가 함수에 실제 비용만, 휴리스틱만, 둘 다 반영하는 세 방식의 최적성과 탐색 효율 차이.

| 비교 항목 | 다익스트라 (Dijkstra) | 탐욕 최선 우선 탐색 (Greedy BFS) | A* 알고리즘 |
| --- | --- | --- | --- |
| 평가 함수 | f(n) = g(n) (실제 비용만) | f(n) = h(n) (휴리스틱만) | f(n) = g(n) + h(n) |
| 최적성 | 항상 최단 경로 보장 | 최단 경로 보장 못함, 장애물 우회에 취약 | 허용적 휴리스틱일 때 최단 경로 보장 |
| 탐색 효율 | 전 방향으로 넓게 확산하여 탐색 노드 수가 많음 | 목표 방향으로 빠르게 진행 | 목표를 지향하면서 최적성 유지 |
| 거리 추정 | 간선 가중치의 누적합 | 유클리드·맨해튼 거리 등으로 추정 | 누적 비용과 추정 거리를 함께 사용 |

## Ⅴ. A* 알고리즘의 한계와 방안

- 핵심 요약 : 최적성 보장과 탐색 공간 압축의 장점 이면에 메모리 증가, 휴리스틱 설계 난제, 동적 환경의 재계산 비용이라는 한계가 존재.
- 장점 : 허용적 휴리스틱에서 최적 경로 보장, 목표 지향 탐색으로 탐색 공간 압축, 다익스트라의 최적성과 탐욕 탐색의 속도를 절충.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 메모리 고갈 (Open List 폭발) | 맵 규모가 커질수록 Open List에 저장되는 노드가 급증하여 메모리가 부족 | 메모리 한도 안에서 반복 심화하는 **IDA\*** (Iterative Deepening A*) 또는 **SMA\*** (Simplified Memory-Bounded A*) 적용, 힙 기반 우선순위 큐 튜닝 | 확장 노드 수, 최대 메모리 사용량 |
| 휴리스틱 설계 난제 | 장애물이 복잡한 미로형 지형에서 유클리드·맨해튼 거리는 실제 비용을 과소평가해 불필요한 탐색을 유발 | 랜드마크 기반 **ALT** (A*, Landmarks, Triangle inequality) 휴리스틱 적용, 격자 맵에서 대칭 경로를 제거하는 **JPS** (Jump Point Search) 도입 | 경로 탐색 시간, 확장 노드 비율 |
| 동적 환경의 재계산 비용 | 이동 중 장애물이 나타나거나 목적지가 바뀌면 전체를 다시 탐색하여 CPU(Central Processing Unit) 자원 낭비 | 변경된 부분만 갱신하는 **D\* Lite** 또는 LPA*(Lifelong Planning A*) 적용 | 재계산 소요 시간, 프레임 지연 |

## Ⅵ. A* 알고리즘에 대한 기술사적 제언

- 핵심 요약 : 맵 환경에 맞는 휴리스틱을 고르고, 대규모 맵에는 계층적 구조를 도입하는 방향.
- 휴리스틱은 이동 가능한 방향에 맞춰 골라야 한다. 4방향 격자에서는 맨해튼 거리, 대각선 이동이 허용된 8방향 격자에서는 옥타일 거리, 장애물이 없는 자유 공간에서는 유클리드 거리가 실제 비용과 가깝고 허용성을 지키기 쉽다.
- 노드가 수십만 개에 이르는 광역 맵에서는 맵을 클러스터로 나누어 추상화된 상위 그래프에서 먼저 경로를 찾고, 세부 구간에서만 국소 A*를 실행하는 **HPA\*** (Hierarchical Pathfinding A*) 구조를 적용하는 것이 메모리와 CPU 부담을 함께 줄이는 방법이다.

## Ⅶ. 결론

- 핵심 요약 : A*는 휴리스틱 기반으로 최적성과 탐색 효율의 균형을 확보하는 표준 최단 경로 알고리즘.
- 실제 비용과 휴리스틱을 합산한 평가 함수로 목표 지향 탐색과 최적성을 함께 얻으며, 대규모 맵과 동적 환경에서는 메모리 제한 변형과 증분 재계산 기법을 상황에 맞게 선택하는 것이 적용의 관건이다.
