## Ⅰ. A* 알고리즘의 개요

- 개념 : 그래프나 2차원 그리드 맵 상에서 출발지 노드로부터 목표 노드까지의 최단 경로를 탐색하기 위해, 시작점으로부터 현재 노드까지의 실제 소요 비용 $g(n)$과 현재 노드에서 목표점까지의 추정 비용(휴리스틱) $h(n)$을 합산한 평가 함수 $f(n) = g(n) + h(n)$을 사용하여 가장 유망한 노드를 우선적으로 탐색하는 최고 우선 탐색(Best-First Search) 기반의 그래프 탐색 알고리즘.
- 배경 및 필요성 : 다익스트라(Dijkstra) 알고리즘의 모든 방향으로 균등하게 퍼져나가는 무방향 탐색에 따른 과도한 연산 낭비를 극복하고, 휴리스틱 지능을 결합하여 목표 지점을 향해 탐색 공간을 극적으로 압축.
- 주요 응용 분야 : 게임 AI 길찾기(NavMesh), 내비게이션 경로 탐색, 로봇 자율주행 모빌리티.

## Ⅱ. A* 알고리즘 평가 함수 구조 및 탐색 메커니즘

```text
   [ 평가 함수: f(n) = g(n) + h(n) ]
    - g(n): 시작 노드에서 현재 노드 n까지 도달하는 데 소요된 정확한 실제 비용
    - h(n): 현재 노드 n에서 목표 노드까지 도달하는 데 소요될 것으로 예상되는 휴리스틱 추정 비용
```

```text
   [ Open List (우선순위 큐) ] ── f(n)이 최소인 노드 추출 ──> [ Closed List (방문 완료) ]
              ▲                                                           │
              │                                                           ▼
              └──────── 인접 이웃 노드들의 g(n), h(n), f(n) 계산 후 등록 ─┘
```

- **휴리스틱의 허용성** (Admissibility) : 휴리스틱 $h(n)$이 실제 최단 비용 $h^*(n)$을 결코 과대평가(Overestimate)하지 않는 성질 ($h(n) \le h^*(n)$). 허용성을 만족하면 A* 알고리즘은 반드시 최적의 최단 경로를 찾아냄을 보장.
- **휴리스틱의 일관성** (Consistency / Monotonicity) : 모든 노드 $n$과 그 이웃 $n'$에 대해 $h(n) \le c(n, n') + h(n')$을 만족하는 성질. 일관성을 만족하면 한 번 방문한 노드를 재방문하지 않아 탐색 효율 극대화.

## Ⅲ. 주요 최단 경로 알고리즘 비교

| 비교 항목 | 다익스트라 (Dijkstra) | 탐욕 최선 우선 탐색 (Greedy BFS) | A* 알고리즘 |
|---|---|---|---|
| 평가 함수 | $f(n) = g(n)$ (실제 비용만 고려) | $f(n) = h(n)$ (휴리스틱 추정치만 고려) | $f(n) = g(n) + h(n)$ (실제비용 + 휴리스틱) |
| 최적성 (Optimality) | 항상 최단 경로 보장 | 최단 경로 보장 못함 (장애물 우회 취약) | 허용적 휴리스틱 사용 시 최단 경로 보장 |
| 탐색 효율성 | 전 방향 방사형 탐색으로 탐색 노드 수 많음 | 목표 방향으로만 빠르게 돌진 | 목표를 지향하면서도 최적성을 유지 (가장 균형적) |
| 거리 측정 방식 | 간선 가중치의 누적합 | 유클리드 거리, 맨해튼 거리 등 추정 | 누적 가중치 + 격자 지오메트리 추정 |

## Ⅳ. A* 알고리즘의 주요 한계점 및 해결 방안

- 대규모 그래프 탐색 시 메모리 고갈(Open Set 폭발) :
  - 한계점 : 탐색 공간이 방대하거나 맵의 크기가 수만 노드 이상일 경우, 오픈 리스트(Open List)에 저장되는 노드 수가 급증하여 메모리 오버플로우 발생.
  - 해결 방안 : 메모리 제한 반복 점진 깊이 우선 탐색(IDA*) 또는 단순화된 메모리 제한 A*(SMA*) 알고리즘 적용, 이진 힙/피보나치 힙 기반 큐 튜닝.
- 복잡한 지형에서의 비최적 휴리스틱(Heuristic) 함수 설계 난제 :
  - 한계점 : 유클리드 거리나 맨해튼 거리가 장애물이 복잡한 미로형 지형에서는 실제 이동 비용을 과소평가하여 불필요한 노드 전수 탐색 유발.
  - 해결 방안 : 랜드마크 기반 차등 휴리스틱(ALT 알고리즘) 적용, 그리드 맵 전처리 기반 점프 포인트 탐색(JPS, Jump Point Search) 도입으로 대칭성 제거.
- 동적 장애물 및 실시간 환경 변화에 따른 경로 재계산 비용 :
  - 한계점 : 이동 중 장애물이 출현하거나 목적지가 변경될 때마다 A*를 처음부터 다시 실행하면 CPU 자원 낭비 및 프레임 드랍 발생.
  - 해결 방안 : 변경된 서브 그래프만 증분 업데이트하는 D* Lite(Dynamic A*) 또는 LPA*(Lifelong Planning A*) 알고리즘으로 전환.

## Ⅴ. 대규모 실시간 환경에서의 기술사적 제언

- 맵 환경에 따른 휴리스틱 함수 최적화 : 4방향 이동 그리드에서는 맨해튼 거리(Manhattan Distance)를, 8방향 대각선 허용 그리드에서는 옥타일 거리(Octile Distance)를, 장애물 없는 자유 공간에서는 유클리드 거리(Euclidean Distance)를 채택하여 허용성을 엄격히 유지해야 함.
- 대규모 실시간 게임 및 로봇 제어를 위한 계층적 A*(HPA*) 도입 : 노드 수가 수십만 개에 달하는 광범위한 맵에서는 메모리 및 CPU 병목이 발생하므로, 맵을 클러스터 단위로 분할하여 추상화된 고수준 그래프에서 먼저 경로를 찾고 세부 클러스터 내에서 국소 A*를 실행하는 Hierarchical Pathfinding 적용 권장.
