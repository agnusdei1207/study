## 지식 위치

소프트웨어공학 > 그래프 알고리즘·최단 경로 > A* 탐색

## 30초 인출

- 본질: **A* (A-star)** 는 시작점부터의 실제 비용과 목표까지의 휴리스틱 추정값을 함께 사용해 경로를 탐색하는 알고리즘
- 메커니즘: $f(n)=g(n)+h(n)$이 작은 후보 확장 → 더 낮은 경로 비용으로 도달하면 갱신 → 목표에 도달하면 경로 복원
- 통찰: 한계: 휴리스틱이 실제 잔여 비용을 과대평가하면 최적 경로를 놓칠 수 있음 → 방안: 허용성을 확인하고 탐색 구현의 갱신·재확장 조건을 검증

<details>
<summary>핵심 용어</summary>

- **A*(A-star)** : 경로 비용과 목표까지의 휴리스틱 추정값을 합산해 확장할 후보를 고르는 탐색 알고리즘
- **평가 함수 $f(n)=g(n)+h(n)$** : 시작점부터 현재 노드까지의 경로 비용 $g(n)$과 목표까지의 추정 비용 $h(n)$을 합친 후보 우선순위
- **실제 비용 $g(n)$** : 시작점부터 현재 노드까지의 누적 경로 비용
- **휴리스틱 $h(n)$** : 현재 노드에서 목표까지의 남은 비용 추정치
- **허용성(Admissibility)** : 휴리스틱이 실제 잔여 비용을 과대평가하지 않는 성질
- **일관성(Consistency)** : 각 간선 비용에 대해 $h(n)\le c(n,n')+h(n')$을 만족하는 성질; 일반적인 그래프 탐색에서 닫힌 노드 재확장의 필요를 줄임
</details>

## 2~4교시 25점 답안

## Ⅰ. A* 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | A*는 시작점 누적 비용과 목표까지의 휴리스틱을 합산해 탐색 우선순위를 정하는 그래프 탐색 알고리즘 |
| 목적 | 적절한 휴리스틱으로 최단 경로 탐색의 효율을 높이고 최적성 보장 조건을 유지 |

## Ⅱ. A* 알고리즘의 특징

| 특징 | 탐색상 의미 |
|---|---|
| 실제·추정 비용 결합 | $g(n)+h(n)$으로 후보 우선순위 결정 |
| 휴리스틱 조건 의존 | 허용성·일관성과 재개방 구현에 따라 최적성 유지 |
| 후보 상태 보존 | Open·Closed·부모 경로가 메모리를 사용 |

## Ⅲ. 평가 함수·후보 관리 체계와 탐색 프로세스

```text
시작점 → Open 후보 집합 ─f=g+h 최소 선택→ 현재 노드
                ↑ 더 낮은 g 발견 시 갱신          ├→ 목표: 부모 경로 복원
                └──── 이웃 비용·휴리스틱 계산 ←─┘ 그 외 확장
Closed 방문 기록 → 일관성·재개방 조건 확인
```

### 개선 경로 발견 시의 갱신 분기

```text
이웃에 더 낮은 g로 도달
    ├→ Open 후보: g·부모·우선순위 갱신
    └→ Closed 노드: 일관성 조건 확인
                    └→ 필요하면 재개방해 개선 경로 반영
```

닫힌 노드를 재확장하지 않는 구현은 휴리스틱의 일관성 조건을 확인해야 한다.

## Ⅳ. 구현 요소와 탐색 방식 비교

| 알고리즘 | 후보 우선순위 | 최적성 조건 |
|---|---|---|
| 다익스트라 | $g(n)$ | 음수가 아닌 간선 비용 |
| A* | $g(n)+h(n)$ | 허용성·구현 조건 충족 |
| 탐욕적 최상 우선 | $h(n)$ | 최적 경로 보장 없음 |

### 휴리스틱과 구현 요소

| 요소 | 설계 기준 |
|---|---|
| 휴리스틱 $h(n)$ | 실제 이동 규칙·간선 비용을 과대평가하지 않는 추정치 |
| Open 목록 | 확장 후보와 $f(n)$ 우선순위를 관리 |
| Closed 목록 | 확장한 노드를 추적; 더 나은 경로 발견 시 재개방 여부 고려 |
| 부모 포인터 | 목표에서 시작점까지 경로 복원 |

### 적용·검증 관점

| 조건·한계 | 적용상 의미 |
|---|---|
| 허용성 | $h(n)$이 실제 잔여 비용보다 크지 않을 때 최적 경로 보장에 기여 |
| 일관성 | 간선 비용과 휴리스틱 차이가 삼각부등식을 만족하면 확장 후 값의 단조성 유지 |
| 메모리 사용 | 탐색 후보와 방문 정보 저장량이 커질 수 있어 지도 규모·메모리 예산 검토 |
| 이동 모델 불일치 | 대각선·가중치·장애물 규칙과 휴리스틱이 맞지 않으면 과대평가 또는 비효율 발생 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 휴리스틱이 실제 잔여 비용을 과대평가하면 최적 경로를 놓칠 수 있음 | 허용성을 확인하고 탐색 구현의 갱신·재확장 조건을 검증 |
| Open·Closed 저장량 증가 | 지도 규모와 메모리 예산을 비교하고 후보 관리 방식 검토 |
| 이동 모델과 휴리스틱 불일치 | 대각선·가중치·장애물 규칙에 맞는 휴리스틱 시험 |

## Ⅵ. 제언

우선 실행: 허용성·일관성을 시험하고, 그래프 탐색에서 더 낮은 경로를 발견한 닫힌 노드의 재개방 여부를 구현 조건과 함께 검증.
