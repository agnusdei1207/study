## 연관 키워드

- A* Algorithm, A* 알고리즘, 최단 경로 탐색
- 평가 함수 f(n) = g(n) + h(n), 휴리스틱(Heuristic)
- 허용성(Admissibility), 일관성(Consistency)
- 최고 우선 탐색(Best-First Search), Open List, Closed List
- IDA*, SMA*, JPS(Jump Point Search), HPA*, D* Lite

## Ⅰ. A* 알고리즘의 개요

- 핵심 요약 : 실제 비용과 휴리스틱 추정치의 합으로 가장 유망한 노드를 우선 탐색하는 최단 경로 알고리즘.
- 개념 : **A* 알고리즘** 이란 그래프나 2차원 그리드 맵 상에서 출발지 노드로부터 목표 노드까지의 최단 경로를 탐색하기 위해, 시작점부터 현재 노드까지의 실제 소요 비용 $g(n)$과 현재 노드에서 목표점까지의 추정 비용(휴리스틱) $h(n)$을 합산한 **평가 함수** $f(n) = g(n) + h(n)$을 사용하여 가장 유망한 노드를 우선적으로 탐색하는 **최고 우선 탐색** (Best-First Search) 기반의 그래프 탐색 알고리즘.
- 배경 및 필요성 : 다익스트라(Dijkstra) 알고리즘의 전 방향 균등 확산 탐색에 따른 과도한 연산 낭비 극복, 휴리스틱 지능 결합을 통한 목표 지향적 탐색 공간 압축.
- 주요 목적 : 최적성 보장과 탐색 효율의 균형, 실시간 경로 탐색 비용 최소화.
- 주요 응용 분야 : 게임 AI(Artificial Intelligence) 길찾기(NavMesh), 내비게이션 경로 탐색, 로봇 자율주행 모빌리티.

## Ⅱ. A* 알고리즘의 특징

- 핵심 요약 : f(n)=g(n)+h(n) 평가 함수와 허용성·일관성 휴리스틱으로 최적성과 효율을 동시 확보.
1. **평가 함수** : $f(n) = g(n) + h(n)$ — $g(n)$(시작 노드에서 현재 노드 n까지 도달에 소요된 정확한 실제 비용), $h(n)$(현재 노드 n에서 목표 노드까지 도달이 예상되는 휴리스틱 비용).
2. **최고 우선 탐색 기반** : Open List(우선순위 큐)에서 $f(n)$이 최소인 노드를 추출하여 확장.
3. **휴리스틱의 허용성** (Admissibility) : $h(n) \le h^*(n)$ — 휴리스틱이 실제 최단 비용 $h^*(n)$을 결코 과대평가(Overestimate)하지 않는 성질로, 최적의 최단 경로 도출 보장.
4. **휴리스틱의 일관성** (Consistency/Monotonicity) : 모든 노드 $n$과 그 이웃 $n'$에 대해 $h(n) \le c(n, n') + h(n')$ 만족 시 한 번 방문한 노드의 재방문 없이 탐색 효율 극대화.
5. **이중 리스트 관리** : Open List(탐색 대기)와 Closed List(방문 완료)로 노드 상태 구분 관리.

## Ⅲ. A* 알고리즘의 구조 (흐름)

- 핵심 요약 : Open List의 최소 f(n) 노드 추출 → 이웃 확장 → 목표 도달까지의 순환 탐색 구조.
- 평가 함수 구성과 Open/Closed List 기반 탐색 루프.

```text
[ 평가 함수: f(n) = g(n) + h(n) ]
 - g(n): 시작 노드에서 현재 노드 n까지
   도달하는 데 소요된 정확한 실제 비용
 - h(n): 현재 노드 n에서 목표 노드까지
   도달할 것으로 예상되는 휴리스틱 비용
```

```text
[ Open List (우선순위 큐) ]
 - f(n)이 최소인 노드 추출
   │
   ▼
[ Closed List (방문 완료) ]
   │
   ▼
[ 인접 이웃 노드 등록 ]
 - g(n), h(n), f(n) 계산 후
   Open List에 재등록 (탐색 루프)
```

## Ⅳ. 주요 최단 경로 알고리즘의 비교

- 핵심 요약 : 실제 비용·휴리스틱·하이브리드 평가 함수에 따른 최적성과 효율의 차이.
- 평가 함수, 최적성, 탐색 효율성, 거리 측정 방식 축 비교.

| 비교 항목 | 다익스트라 (Dijkstra) | 탐욕 최선 우선 탐색 (Greedy BFS) | A* 알고리즘 |
|---|---|---|---|
| 평가 함수 | $f(n) = g(n)$ (실제 비용만 고려) | $f(n) = h(n)$ (휴리스틱 추정치만 고려) | $f(n) = g(n) + h(n)$ (실제비용 + 휴리스틱) |
| 최적성 (Optimality) | 항상 최단 경로 보장 | 최단 경로 보장 못함 (장애물 우회 취약) | 허용적 휴리스틱 사용 시 최단 경로 보장 |
| 탐색 효율성 | 전 방향 방사형 탐색으로 탐색 노드 수 많음 | 목표 방향으로만 빠르게 돌진 | 목표를 지향하면서도 최적성을 유지 (가장 균형적) |
| 거리 측정 방식 | 간선 가중치의 누적합 | 유클리드 거리, 맨해튼 거리 등 추정 | 누적 가중치 + 격자 지오메트리 추정 |

## Ⅴ. A* 알고리즘의 장점과 한계

- 핵심 요약 : 최적성 보장과 탐색 공간 압축의 장점, 메모리 폭발·휴리스틱 설계 난제·재계산 비용의 한계.
- 장점
  1. 허용적 휴리스틱 사용 시 항상 최적 최단 경로 보장.
  2. 목표 지향 탐색에 따른 탐색 공간의 극적 압축.
  3. 다익스트라의 최적성과 그리디 탐색의 속도의 균형.
- 한계점 1 : 대규모 그래프 탐색 시 메모리 고갈(Open Set 폭발)
  - 한계점 : 탐색 공간이 방대하거나 맵의 크기가 수만 노드 이상일 경우 오픈 리스트(Open List) 저장 노드 수 급증으로 메모리 오버플로우 발생.
  - 해결 방안 : 메모리 제한 반복 점진 깊이 우선 탐색(IDA*, Iterative Deepening A*) 또는 단순화된 메모리 제한 A*(SMA*, Simplified Memory-Bounded A*) 적용, 이진 힙·피보나치 힙 기반 큐 튜닝.
- 한계점 2 : 복잡한 지형에서의 비최적 휴리스틱(Heuristic) 함수 설계 난제
  - 한계점 : 유클리드 거리·맨해튼 거리는 장애물이 복잡한 미로형 지형에서 실제 이동 비용을 과소평가하여 불필요한 노드 전수 탐색 유발.
  - 해결 방안 : 랜드마크 기반 차등 휴리스틱(ALT, A*-Landmarks-Triangle inequality) 적용, 그리드 맵 전처리 기반 점프 포인트 탐색(JPS, Jump Point Search) 도입으로 대칭성 제거.
- 한계점 3 : 동적 장애물·실시간 환경 변화에 따른 경로 재계산 비용
  - 한계점 : 이동 중 장애물 출현이나 목적지 변경 시마다 A*를 처음부터 다시 실행하면 CPU(Central Processing Unit) 자원 낭비 및 프레임 드랍 발생.
  - 해결 방안 : 변경된 서브 그래프만 증분 업데이트하는 D* Lite(Dynamic A*) 또는 LPA*(Lifelong Planning A*) 알고리즘 전환.

## Ⅵ. A* 알고리즘에 대한 기술사적 제언

- 핵심 요약 : 맵 환경별 휴리스틱 함수 최적화와 계층적 A*(HPA*) 도입.
- 맵 환경에 따른 휴리스틱 함수 최적화 : 4방향 이동 그리드에서는 **맨해튼 거리** (Manhattan Distance)를, 8방향 대각선 허용 그리드에서는 **옥타일 거리** (Octile Distance)를, 장애물 없는 자유 공간에서는 **유클리드 거리** (Euclidean Distance)를 채택하여 허용성을 엄격히 유지.
- 대규모 실시간 게임·로봇 제어를 위한 계층적 A*(HPA*, Hierarchical Pathfinding A*) 도입 : 노드 수가 수십만 개에 달하는 광범위한 맵에서는 메모리·CPU 병목이 발생하므로, 맵을 클러스터 단위로 분할하여 추상화된 고수준 그래프에서 먼저 경로를 찾고 세부 클러스터 내에서 국소 A*를 실행하는 계층적 경로 탐색 적용 권장.

## Ⅶ. 결론

- 핵심 요약 : A*는 휴리스틱 기반으로 최적성과 탐색 효율의 균형을 확보하는 표준 최단 경로 알고리즘.
- 요약 : A* 알고리즘은 실제 비용과 휴리스틱의 합산 평가 함수로 목표 지향 탐색과 최적성 보장을 동시 실현.
- 시사점 : 메모리 제한 변형·휴리스틱 튜닝·증분 재계산 변형의 상황별 적용이 대규모 실시간 환경 적용의 성공 조건.
