## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 자료구조·알고리즘 → **A* 알고리즘**

## 30초 인출

- 본질: A* 알고리즘은 시작점에서 목표까지의 최단 경로를 실제 이동 비용과 목표까지의 추정 비용을 합친 값으로 탐색 순서를 정해 찾는 알고리즘
- 메커니즘: f(n)=g(n)+h(n)이 가장 작은 노드를 우선순위 큐에서 꺼내 확장하며 목표에 도달하면 경로를 확정
- 통찰: 추정 비용 h가 실제 비용보다 크면 최적 경로를 놓치고 너무 작으면 탐색이 늘어나므로 실제 비용을 넘지 않으면서 가까운 허용적 휴리스틱을 선택

<details>
<summary>핵심 용어</summary>

- **A* 알고리즘** : g(n)+h(n)이 최소인 노드부터 확장해 최단 경로를 찾는 탐색 알고리즘
- **g(n)** : 시작점에서 노드 n까지 실제로 든 비용
- **h(n)** : 노드 n에서 목표까지의 추정 비용(휴리스틱)
- **허용적 휴리스틱(Admissible Heuristic)** : 실제 남은 비용을 넘지 않는 추정치. 최적 경로를 보장
- **오픈 리스트·클로즈드 리스트** : 확장 대기 노드 집합과 이미 확장한 노드 집합
- **다익스트라 알고리즘** : h를 사용하지 않고 g만으로 최단 경로를 찾는 알고리즘

</details>

## 2~4교시 25점 답안

## Ⅰ. A* 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **A* 알고리즘** 은 실제 비용과 추정 비용의 합이 최소인 노드부터 확장해 최단 경로를 찾는 탐색 알고리즘 |
| 목적 | 목표 방향의 탐색 우선으로 경로 탐색 범위 축소 |

## Ⅱ. 다익스트라와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 휴리스틱 사용 | 목표까지의 추정 비용으로 탐색 방향 유도 |
| 최적성 조건 | 허용적 휴리스틱이면 최적 경로 보장 |
| 우선순위 큐 | f 값이 작은 노드 우선 확장 |

## Ⅲ. 알고리즘의 동작

### 탐색 과정: 노드별 g·h·f와 확장 순서

```text
            [S] f=6 ①
           /         \
     [A] f=7 ②     [B] f=7
       /      \          \
  [D] f=7 ③  [C] f=12   [E] f=9
     |
  [G] f=7 ④  ◀ 경로 S→A→D→G
```

| 노드 | S | A | D | G |
|---|---|---|---|---|
| g(실제 비용) | 0 | 2 | 4 | 7 |
| h(추정 비용) | 6 | 5 | 3 | 0 |

### 알고리즘 절차

```text
시작 노드를 오픈 리스트에 추가
    ↓
f = g + h가 가장 작은 노드 선택
    ├─ 목표 노드 → 경로 확정·종료
    └─ 아니면 확장: 이웃의 g·h·f 계산, 오픈 리스트 갱신
    ↓
확장한 노드는 클로즈드 리스트로 이동 → 반복
```

### 확대: 평가 함수

```text
f(n) = g(n) + h(n)
g(n): 시작→n 실제 비용 / h(n): n→목표 추정 비용
격자 예: h = 목표까지의 맨해튼 거리
```

## Ⅳ. 탐색 알고리즘의 비교

| 구분 | BFS | 다익스트라 | 탐욕적 최선 우선 | A* |
|---|---|---|---|---|
| 평가 기준 | 단계 수 | g | h | g + h |
| 최적성 | 가중치 없을 때 | 보장 | 미보장 | 허용적 h면 보장 |
| 탐색 범위 | 넓음 | 넓음 | 좁음 | 좁음 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| h가 실제 비용보다 커서 최적 경로 놓침 | 허용적 휴리스틱 사용 |
| h가 너무 작아 탐색이 넓어짐 | 실제 비용에 가까운 휴리스틱 선택 |
| 노드가 많아 오픈 리스트 메모리 증가 | 탐색 범위 제한과 계층적 탐색 |

## Ⅵ. 제언

문제 특성에 맞는 허용적 휴리스틱(격자는 맨해튼 거리 등)을 선택하고, 실제 비용에 가까울수록 탐색이 줄어듦을 활용

### 휴리스틱 선택 순서

```text
h가 실제 비용을 넘지 않는지 확인 (허용성)
    ↓
후보 중 실제 비용에 가장 가까운 h 선택
    ↓
탐색 노드 수 측정으로 검증
```

### 확대: 판정

```text
h(n) ≤ 실제 잔여 비용?
    ├─ 예 → 최적 경로 보장
    └─ 아니오 → 최적성 미보장, 휴리스틱 수정
```

### 선택 근거: 다익스트라와의 비교

| 구분 | 다익스트라 | 제언: A* |
|---|---|---|
| 탐색 방향 | 전방위 | 목표 지향 |
| 탐색 노드 수 | 많음 | 적음 |
| 조건 | 없음 | 허용적 휴리스틱 |
