## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 소프트웨어 개발·운영 → A* 알고리즘

## 지식 위치

소프트웨어공학 > 그래프 알고리즘·최단 경로 > A* 탐색

## 30초 인출

- 본질: 시작 노드로부터의 실제 이동 비용 $g(n)$과 목표 노드까지의 휴리스틱 추정 비용 $h(n)$을 합산한 평가 함수를 기반으로 최단 경로를 탐색하는 최적 우선 탐색 알고리즘
- 메커니즘: 우선순위 큐(Open List)에서 $f(n)=g(n)+h(n)$ 최소 노드 추출 → 이웃 노드 전개 및 경로 비용 갱신 → Closed List 등록 및 역방향 포인터 추적으로 최단 경로 복원
- 통찰: 휴리스틱 함수가 실제 잔여 비용을 초과 평가(과대평가)할 경우 최단 경로 보장성(허용성)이 상실되므로 문제 도메인의 기하학적 특성에 부합하는 허용적·일관적 휴리스틱 설계 필수

<details>
<summary>핵심 용어</summary>

- **평가 함수 ($f(n)$)** : 시작 노드부터 현재 노드 $n$을 거쳐 목표 노드까지 도달하는 총 예상 비용 ($f(n) = g(n) + h(n)$)
- **실제 비용 ($g(n)$)** : 시작 노드로부터 현재 노드 $n$까지 이동하는 데 소요된 누적 실제 가중치 합
- **휴리스틱 추정치 ($h(n)$)** : 현재 노드 $n$에서 목표 노드까지 도달하는 데 소요될 것으로 예상되는 최소 추정 비용
- **허용성 (Admissibility)** : 모든 노드 $n$에 대해 $h(n) \le h^*(n)$ (실제 최적 잔여 비용)을 만족하여 항상 최적해를 보장하는 성질
- **일관성 (Consistency / Monotonicity)** : 모든 노드 $n$과 그 인접 노드 $n'$에 대해 $h(n) \le c(n, n') + h(n')$ 삼각부등식을 만족하여 노드 재확장을 방지하는 성질
</details>

## 2~4교시 예상문제 (25점)

> A* 알고리즘의 동작 원리와 평가 함수 수식 구조를 설명하고, 최적해 보장을 위한 조건(허용성, 일관성) 및 다익스트라(Dijkstra) 알고리즘과의 비교를 기술하시오. (25점)

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 그래프 상에서 시작점에서 목표점까지 도달하는 최단 경로를 찾기 위해 누적 실측 비용과 목적지 예측 비용을 결합한 평가 함수 $f(n)=g(n)+h(n)$을 사용하는 정보 탐색(Informed Search) 알고리즘 |
| 목적 | 다익스트라의 무방향 전방위 탐색 비효율성을 극복하고, 휴리스틱 기반으로 탐색 공간을 대폭 축소하여 신속한 최단 경로 도출 |

## Ⅱ. 핵심 특징

| 특징 | 세부 내용 |
|---|---|
| 목적지 지향적 탐색 | 휴리스틱 함수 $h(n)$을 통해 목표 지점 방향으로 우선순위 큐(Open List) 탐색 범위를 집중 |
| 최적성(Optimality) 보장 | 허용성($h(n) \le h^*(n)$) 조건을 충족할 경우 최단 경로 도달을 수학적으로 보장 |
| 완전성(Completeness) | 유한한 분기 계수와 양의 간선 비용을 가진 그래프에서 해가 존재할 경우 반드시 경로 탐색 성공 |
| 유연한 휴리스틱 선택 | 그리드 맵 형태에 따라 맨해튼(Manhattan), 유클리드(Euclidean), 체비쇼프(Chebyshev) 거리 등 맞춤 적용 가능 |

다익스트라의 안전성과 탐욕 알고리즘의 속도를 수학적으로 결합한 고효율 경로 탐색 표준으로 정립.

## Ⅲ. 체계·프로세스

```text
[A* 탐색 메커니즘 및 최단 경로 도출]
         g=0, h=7
           [ S ] (시작점)
          /     \
    g=2  /       \  g=3
  h=6   /         \   h=5
      [ A ]     [ B ]  ◄── f(n) = g(n) + h(n) 최소 노드 우선 전개
      f=8       f=8
     /   \         \
    /     \         \  g=7, h=2
[ C ]   [ D ]     [ E ]
f=9     f=7       f=9
          \
           \  g=6, h=0
            ▼
          [ G ] (목표점 도달, f=6 최단경로 확정: S -> A -> D -> G)

[탐색 제어 프로세스]
  1. Open List 초기화: 시작 노드 S 삽입 (f(S) = g(S) + h(S))
  2. 노드 선택: Open List에서 f(n) 최소 노드 Pop -> Closed List 등록
  3. 목표 검사: Pop된 노드가 목표 노드 G이면 역방향 포인터 추적으로 종료
  4. 인접 확장: 인접 노드 g(n) 계산 -> 더 짧은 경로 발견 시 f, 부모 갱신 후 Open List 삽입
```

우선순위 큐(Open List)를 통해 최소 $f(n)$ 노드를 순차 확장하며 최단 경로를 점진 확정하는 체계.

## Ⅳ. 종류·비교

| 비교 항목 | A* 알고리즘 | 다익스트라 (Dijkstra) | 탐욕적 최상 우선 탐색 (Greedy Best-First) |
|---|---|---|---|
| **평가 함수** | $f(n) = g(n) + h(n)$ | $f(n) = g(n)$ ($h=0$ 인 특수 형태) | $f(n) = h(n)$ |
| **탐색 방향성** | 목표 지점 방향 집중 탐색 | 시작점 중심 동심원형 전방위 확장 | 오직 목표 지점 추정치만 추종 |
| **최적해 보장** | 허용성 충족 시 최단 경로 보장 | 음수 간선 없을 시 100% 최단 경로 보장 | 최단 경로 보장 불가 (국소 최적해 함정) |
| **탐색 노드 수** | 휴리스틱 품질에 따라 매우 적음 | 광범위한 노드 탐색으로 다수 노드 방문 | 매우 적으나 비효율 경로 선택 가능 |
| **적용 분야** | 게임 AI 길찾기, 로봇 자율주행, 내비게이션 | 네트워크 라우팅(OSPF), 단일 출발점 최단 경로 | 단순 미로 탈출, 빠른 근사해 탐색 |

### 휴리스틱 함수 종류 비교

| 휴리스틱 유형 | 수식 | 적용 그리드 환경 |
|---|---|---|
| **맨해튼 거리 (Manhattan)** | $|x_1 - x_2| + |y_1 - y_2|$ | 4방향(상하좌우) 이동만 허용되는 격자망 |
| **유클리드 거리 (Euclidean)** | $\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$ | 각도 제한 없이 모든 방향으로 자유 이동 가능한 평면 |
| **체비쇼프 / 옥타일 거리** | $\max(|dx|, |dy|) + (\sqrt{2}-1)\min(|dx|, |dy|)$ | 8방향(상하좌우 및 대각선) 이동이 허용되는 격자망 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 대규모 맵이나 고차원 상태 공간에서 Open/Closed List 저장에 따른 메모리 공간 복잡도 폭증 | 반복적 깊이 심화 A*(IDA*) 도입 또는 메모리 한정 휴리스틱 탐색(SMA*) 적용으로 메모리 사용량 제약 |
| 비일관적(Inconsistent) 휴리스틱 사용 시 이미 닫힌 노드(Closed List) 재개방으로 인한 성능 저하 | 삼각부등식을 만족하는 일관적(Consistent) 휴리스틱 설계 및 그래프 전처리 기반 계층적 A*(HPA*) 도입 |
| 동적으로 변화하는 장애물 및 이동체 환경에서 경로 재계산 비용 과다 발생 | 변경된 노드만 점진적으로 갱신하는 Dynamic A*(D* Lite) 알고리즘으로 전환 |

## Ⅵ. 제언

도메인 공간 특성에 부합하는 일관적 휴리스틱 선정을 선행하고, 실시간 대규모 경로 탐색 환경에서는 계층적 그래프 분할 및 동적 경로 재설계 알고리즘과의 융합 아키텍처 구축 필요.

```text
[자율주행 및 게임 길찾기 최적화 아키텍처]
  글로벌 맵 전처리 (계층 분할) → 거시 경로 탐색 (HPA*) → 실시간 장애물 회피 (D* Lite / Local A*)
```

| 검증 단계 | 사전 설계 단계 (휴리스틱 검증) | 런타임 최적화 (스케일 아웃) |
|---|---|---|
| 핵심 통제 | $h(n) \le h^*(n)$ 허용성 및 단조성 수학적 증명 | 공간 분할 트리(Quadtree/Octree) 연동 및 JPS(Jump Point Search) 결합 |
| 달성 목표 | 탐색 최적 경로 무결성 확보 | 탐색 연산 속도 10배 이상 향상 및 메모리 점유 최소화 |
