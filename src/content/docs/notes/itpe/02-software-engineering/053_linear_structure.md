소프트웨어 공학 → 자료구조·알고리즘 → **선형 구조(Linear Structure)**

## 30초 인출

- 본질: 선형 구조는 원소가 앞뒤 하나씩 순서대로 이어지는 자료구조이며 배열·연결 리스트·스택·큐가 대표
- 메커니즘: 리스트는 순서 위치에 삽입·삭제하고, 스택은 한쪽 끝(LIFO)으로만, 큐는 한쪽에서 넣고 반대쪽에서 꺼내(FIFO) 입출력
- 통찰: 배열은 접근이 빠르나 중간 삽입·삭제가 느리고 연결 리스트는 반대이므로 접근이 잦으면 배열, 삽입·삭제가 잦으면 연결 리스트를 선택

<details>
<summary>핵심 용어</summary>

- **선형 구조(Linear Structure)** : 원소가 1:1로 순서대로 연결된 자료구조
- **배열(Array)** : 같은 타입의 원소를 연속 메모리에 저장하고 인덱스로 접근하는 구조
- **연결 리스트(Linked List)** : 각 노드가 데이터와 다음 노드 포인터를 가지는 구조
- **스택(Stack)** : 한쪽 끝에서만 삽입·삭제하는 후입선출(LIFO) 구조
- **큐(Queue)** : 뒤에서 삽입하고 앞에서 삭제하는 선입선출(FIFO) 구조
- **원형 큐(Circular Queue)** : 배열의 끝과 처음을 이어 공간을 재사용하는 큐

</details>

## 2~4교시 25점 답안

## Ⅰ. 선형 구조의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **선형 구조** 는 원소가 앞뒤 하나씩 순서대로 연결된 자료구조 |
| 목적 | 순서가 있는 데이터의 저장·처리 |

## Ⅱ. 선형 구조의 특징

| 특징 | 의미 |
|---|---|
| 1:1 관계 | 각 원소의 앞뒤 원소 하나씩 |
| 순차 처리 | 처음부터 순서대로 순회 |
| 접근 제한 유형 | 스택·큐는 삽입·삭제 위치 제한 |

## Ⅲ. 스택·큐·리스트의 입출력 원리

### 세 구조의 입출력

```text
스택(LIFO):  Push ↓↑ Pop          한쪽 끝(Top)에서 입출력
큐(FIFO):    Rear → □□□□ → Front   뒤에서 넣고 앞에서 꺼냄
리스트:      [A][B][C][D]          원하는 위치에 삽입·삭제
```

### 확대: 원형 큐

```text
배열 기반 큐: Front 이동 후 앞쪽 공간이 비어도 Rear가 끝에 도달해 포화로 판단
원형 큐: 인덱스를 (index+1) mod 크기로 이동해 빈 공간 재사용
```

## Ⅳ. 저장 방식과 구조별 비교

### 배열과 연결 리스트

| 구분 | 배열 | 연결 리스트 |
|---|---|---|
| 접근 | 인덱스로 O(1) | 처음부터 순회 O(n) |
| 삽입·삭제 | 이동으로 O(n) | 위치를 알면 O(1) |
| 메모리 | 연속 공간, 크기 고정 | 노드별 할당, 포인터 추가 |

### 스택·큐·리스트의 비교

| 구분 | 스택 | 큐 | 리스트 |
|---|---|---|---|
| 입출력 규칙 | LIFO | FIFO | 위치 지정 |
| 삽입·삭제 위치 | Top | 뒤·앞 | 임의 |
| 활용 | 함수 호출, 되돌리기 | 작업 대기열, 버퍼 | 순서 데이터 관리 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 배열 기반 큐의 앞쪽 빈 공간을 쓰지 못하는 포화 | 원형 큐 사용 |
| 배열의 중간 삽입·삭제 비용 | 삽입·삭제가 잦으면 연결 리스트 사용 |
| 연결 리스트의 임의 접근 비용 | 접근이 잦으면 배열 사용 |

## Ⅵ. 제언

접근이 잦은 데이터는 배열, 삽입·삭제가 잦은 데이터는 연결 리스트로 선택하고 큐는 원형 큐로 구현

### 구조 선택 기준

```text
연산 빈도 확인
    ├─ 인덱스 접근 잦음 → 배열
    ├─ 삽입·삭제 잦음 → 연결 리스트
    └─ 순서 처리(FIFO) → 원형 큐
```

### 선택 근거: 하나의 구조 고정과의 비교

| 구분 | 하나로 고정 | 제언: 연산 빈도별 선택 |
|---|---|---|
| 접근 성능 | 구조에 따라 저하 | 접근 위주는 배열 |
| 삽입·삭제 | 구조에 따라 저하 | 삽입 위주는 연결 리스트 |
| 선택 부담 | 없음 | 연산 빈도 분석 필요 |
