## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 모델링 → **순차 다이어그램(Sequence Diagram)**

## 30초 인출

- 본질: 순차 다이어그램은 객체 사이에 주고받는 메시지를 시간 순서대로 나타내는 UML 행위 다이어그램
- 메커니즘: 참여 객체를 생명선으로 나열하고 위에서 아래로 시간이 흐르게 동기·비동기·반환 메시지를 화살표로 그려 호출 순서와 응답을 표현
- 통찰: 여러 시나리오를 한 다이어그램에 담으면 읽기 어려우므로 하나의 유스케이스 시나리오 단위로 그리고 분기·반복은 결합 프래그먼트로 표현

<details>
<summary>핵심 용어</summary>

- **순차 다이어그램(Sequence Diagram)** : 객체 간 메시지를 시간 순서로 표현한 다이어그램
- **생명선(Lifeline)** : 상호작용에 참여하는 객체의 존재 기간을 나타내는 세로선
- **활성 구간(Activation Bar)** : 객체가 메서드를 실행 중인 구간
- **동기 메시지·비동기 메시지** : 응답을 기다리는 호출과 기다리지 않는 호출
- **결합 프래그먼트(Combined Fragment)** : 분기(alt)·선택(opt)·반복(loop) 등 제어 구조를 표현하는 영역

</details>

## 2~4교시 25점 답안

## Ⅰ. 순차 다이어그램의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **순차 다이어그램** 은 객체 간 메시지를 시간 순서로 나타내는 UML 행위 다이어그램 |
| 목적 | 시나리오의 상호작용 순서와 책임 분담의 명확화 |

## Ⅱ. 순차 다이어그램의 특징

| 특징 | 의미 |
|---|---|
| 시간 순서 | 위에서 아래로 시간 진행 |
| 객체 간 상호작용 | 호출·응답 관계 표현 |
| 시나리오 단위 | 하나의 흐름을 구체적으로 표현 |

## Ⅲ. 구성 요소와 표현

### 로그인 시나리오의 순차 다이어그램

```text
사용자        화면        인증서비스      DB
  │ 로그인 요청 │            │            │
  ├──────────→│            │            │
  │           │ 인증 요청   │            │
  │           ├──────────→│ 조회        │
  │           │            ├──────────→│
  │           │            │←── 결과 ───┤
  │           │←── 결과 ────┤            │
  │←── 화면 ───┤            │            │
```

### 확대: 결합 프래그먼트

```text
alt [인증 성공] → 메인 화면 이동
else [인증 실패] → 오류 메시지 표시
loop [최대 3회] → 재시도
```

## Ⅳ. 메시지 유형과 다른 다이어그램과의 비교

### 메시지 유형

| 유형 | 의미 | 표기 |
|---|---|---|
| 동기 메시지 | 응답을 기다림 | 실선 화살표(채운 머리) |
| 비동기 메시지 | 응답을 기다리지 않음 | 실선 화살표(열린 머리) |
| 반환 메시지 | 응답 전달 | 점선 화살표 |

### 다른 다이어그램과의 비교

| 구분 | 순차 | 활동 | 상태 |
|---|---|---|---|
| 초점 | 객체 간 메시지 순서 | 처리 흐름 | 한 객체의 상태 변화 |
| 시간 표현 | 명시적(세로축) | 흐름 순서 | 이벤트 기반 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 복잡한 시나리오를 한 장에 담아 가독성 저하 | 시나리오 단위로 분리 |
| 분기·반복 표현 곤란 | 결합 프래그먼트 사용 |
| 클래스 다이어그램과의 불일치 | 메시지가 클래스의 오퍼레이션과 대응하는지 확인 |

## Ⅵ. 제언

유스케이스의 주요 시나리오별로 순차 다이어그램을 그리고, 분기와 반복은 결합 프래그먼트로 표현하며 메시지가 클래스의 오퍼레이션과 일치하는지 확인

### 작성 순서

```text
유스케이스 시나리오 선택
    ↓
참여 객체 식별 → 메시지 순서 작성
    ↓
분기·반복 → 결합 프래그먼트
    ↓
클래스 오퍼레이션과 대조
```

### 선택 근거: 한 장에 모든 시나리오와의 비교

| 구분 | 한 장에 모든 시나리오 | 제언: 시나리오별 작성 |
|---|---|---|
| 가독성 | 낮음 | 높음 |
| 검증 | 곤란 | 시나리오 단위 |
| 클래스 연계 | 불분명 | 오퍼레이션과 대응 |
