 ┣━ Ⅱ 특징 ───── DAG(방향성 비순환 그래프) 전제 조건 · 시간 복잡도 $O(V+E)$ · 결과의 비유일성(복수 정렬 결과 가능) · 사이클 탐지 가능

 ┗━ Ⅵ 실무 ───── 순환 의존성(Circular Dependency) 발생 시 정렬 불가 / 대규모 빌드(Bazel) 및 패키지 관리(npm) 적용

## 한 줄 본질
- 어떤 작업을 먼저 끝내야 다음 작업을 시작할 수 있는 의존 관계가 복잡할 때 실행 순서를 결정하지 못하는 교착 병목 → 방향성 비순환 그래프(DAG)의 모든 간선 $(u, v)$에 대해 정점 $u$가 $v$보다 항상 먼저 오도록 순서를 일렬로 나열하는 알고리즘 / 그래프 내 사이클 존재 시 정렬 불가

## 핵심 그림
```text
+-------------------------------------------------------------------------+
|                  Kahn의 위상 정렬 알고리즘 동작 메커니즘 ($O(V+E)$)     |
+-------------------------------------------------------------------------+
|  [ 초기 DAG 및 진입 차수(In-degree) ]                                   |
|                                                                         |
|      (1) ───> (2) ───> (4)      진입 차수:                               |
|       │        │        ▲       - 노드 1: 0 (선행 조건 없음)            |
|       │        v        │       - 노드 2: 1 (노드 1 의존)               |
|       └─────> (3) ──────┘       - 노드 3: 2 (노드 1, 2 의존)            |
|                                 - 노드 4: 2 (노드 2, 3 의존)            |
|                                                                         |
|  [ 단계별 큐(Queue) 처리 흐름 ]                                         |
|  Step 1: 차수 0인 [1] 큐에 삽입 ──> [1] 꺼냄 ──> 간선 제거 (2, 3 차수 -1)|
|  Step 2: 차수 0이 된 [2] 큐 삽입 ──> [2] 꺼냄 ──> 간선 제거 (3, 4 차수 -1)|
|  Step 3: 차수 0이 된 [3] 큐 삽입 ──> [3] 꺼냄 ──> 간선 제거 (4 차수 -1) |
|  Step 4: 차수 0이 된 [4] 큐 삽입 ──> [4] 꺼냄 ──> 종료!                  |
|                                                                         |
|  * 최종 위상 정렬 결과: [ 1 ──> 2 ──> 3 ──> 4 ]                         |
|  * 사이클 판별: 모든 노드를 꺼내기 전에 큐가 비면 "사이클(순환) 존재!"    |
+-------------------------------------------------------------------------+
```

## 핵심 용어
- Kahn 알고리즘: 진입 차수가 0인(더 이상 선행 작업이 없는) 노드를 큐에 넣고 하나씩 꺼내면서 연결된 간선을 지워나가는 직관적인 위상 정렬 기법
- 순환 의존성(Circular Dependency): $A \to B \to C \to A$처럼 상호 참조가 발생하여 어떤 작업도 먼저 시작할 수 없는 사이클 상태로, 위상 정렬을 통해 사전 탐지 가능

## 핵심 통찰
- 위상 정렬의 결과는 단 하나로 고정되지 않으며, 진입 차수가 0인 노드가 동시에 여러 개 존재하면 어떤 노드를 먼저 큐에서 꺼내느냐에 따라 복수의 유효한 위상 정렬 순서가 도출될 수 있음
- Kahn 알고리즘을 돌렸을 때 전체 정점 수 $V$개를 모두 큐에서 꺼내지 못했는데 큐가 비어버렸다면, 이는 그래프 내에 사이클(순환 참조)이 존재하여 데드락이 발생했음을 의미함
- 소프트웨어 빌드 시스템(Make, Gradle, Bazel), 패키지 매니저(npm, pip), 수강신청 선수과목 계산, 스프링 프레임워크의 빈(Bean) 의존성 주입 순서 결정이 모두 위상 정렬로 동작함

## 이웃 토픽과 구분
- 위상 정렬 vs 일반 정렬(퀵/머지 정렬): 일반 정렬 = 데이터 값의 대소 관계($<, >$)를 기준으로 1차원 정렬 / 위상 정렬 = 간선의 선후 인과관계(의존성)를 만족하도록 정렬

## 문제·원인·대책
