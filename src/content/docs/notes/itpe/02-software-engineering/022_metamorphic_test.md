## 연관 키워드

- 메타모픽 테스트, 오라클 문제(Oracle Problem), 메타모픽 관계(MR)
- 원본 입력(Source Input), 후속 입력(Follow-up Input), 속성 기반 테스트

## Ⅰ. 메타모픽 테스트의 개요

- 핵심 요약 : 메타모픽 테스트는 기대 출력을 알기 어려운 대상에 입력 간 관계에서 유도한 출력 관계를 오라클로 사용.
- 개념 : 원래 입력을 변환해 만든 입력과 원래 입력의 출력 사이가 만족해야 할 관계를 시험 오라클로 활용하는 기법(**메타모픽 테스트**, Metamorphic Testing). 이 관계를 **메타모픽 관계**(MR, Metamorphic Relation)라 부름.
- 배경 및 필요성 : 기존의 **시험 오라클**(test oracle, 출력의 정오를 판단하는 기준)은 입력별 기대 출력을 사전에 계산해야 하므로, 검색·최적화·머신러닝처럼 정답 자체를 구하기 어려운 **오라클 문제**(oracle problem, 기대 출력 부재로 검증 판단이 곤란한 문제)에 직면.
- 주요 목적 : 개별 정답 없이도 출력 관계 위반으로 결함을 탐지하고 유효 시험 입력을 확대.

## Ⅱ. 메타모픽 테스트의 특징 및 장점

- 핵심 요약 : 관계 기반 오라클과 입력 변환·재사용이 검증 범위 확대와 비용 절감으로 연결.

1. 관계 기반 오라클 : 입력 변환에 대해 출력이 유지해야 할 속성을 MR로 정의 → 오라클 문제 완화.
2. 입력 증폭 : 하나의 **원본 입력**(source input)에서 다수의 **후속 입력**(follow-up input) 생성 → 시험 데이터 확보 비용 절감.
3. 의미 보존 변환 : 순열·스케일 변환처럼 의미가 보존되는 변환으로 입력 공간 확장 → 기존 데이터만으로 다양성·경계 확보.
4. 자동화 적합성 : MR 판정이 계산 가능한 관계 비교 → 자동화·회귀시험 편입 용이.

## Ⅲ. 메타모픽 테스트의 구조 (흐름)

- 핵심 요약 : 원본·후속 입력의 쌍 실행과 출력 관계 판정, 위반 사례의 분석으로 구성.

```text
[ MR 검증 구조 ]
원본 입력 x → 프로그램 → 출력 f(x)
   ↓ 입력 변환 T
후속 입력 T(x) → 프로그램 → 출력 f(T(x))
   ↓
MR 판정 : f(x)와 f(T(x))의 관계
   ↓ 위반 시
결함 보고 → 최소 재현 사례 축소
```

```text
[ MR 적용 절차 ]
도메인 속성 분석 → MR 정의
   ↓
원본 입력 생성 → 변환 입력 생성
   ↓
양쪽 실행 → 출력 관계 검사
   ↓
위반 사례 분석·회귀시험 편입
```

- MR 예시 : 정렬 프로그램은 입력 순서를 바꿔도 출력이 동일, 합계 프로그램은 금액을 2배로 하면 결과도 2배.

## Ⅳ. 메타모픽 테스트와 기준값 기반 오라클 시험의 비교

- 핵심 요약 : 기준값 기반 오라클은 입력별 정답을, 메타모픽 테스트는 입력 간 관계를 판단 기준으로 사용.

| 비교 축 | 기준값 기반 오라클 시험 | 메타모픽 테스트 |
| --- | --- | --- |
| 오라클 형태 | 입력별 사전 계산된 기대 출력 | 입력 간 관계에서 유도한 출력 관계 |
| 기대값 요구 | 모든 입력의 정답 필요 | 개별 정답 불필요 |
| 적용 대상 | 결과가 명확한 계산 기능 | 검색·최적화·머신러닝 등 정답 모호 기능 |
| 시험 입력 확보 | 사전 준비 데이터 세트 | 원본 입력 변환으로 다수 생성 |
| 고유 한계 | 데이터 준비 비용·커버리지 한계 | MR 타당성·누락에 의존 |

## Ⅴ. 메타모픽 테스트의 한계와 방안

- 핵심 요약 : MR의 도출·타당성·강도 문제와 비결정성을 도메인 검증과 재현 기준으로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| MR 도출 난이도 | 도메인 지식 부족 시 관계 누락 | 요구·도메인 규칙 기반 MR 정의 워크숍 | 정의·커버된 MR 수 |
| MR 타당성 결함 | 잘못된 관계 → 오탐·미탐 | 도메인 전문가 검증·관계 리뷰 | 오탐률 |
| 약한 관계 | 자명한 관계만 검증 → 탐지력 저하 | 출력 제약 세분화·변이 시험으로 점검 | 변이 생존율 |
| 비결정성 환경 | 동일 의미 입력 간 결과 상이 → 간헐 실패 | 시드 고정·허용 오차·재시도 기준 명시 | 재현 실패율 |

## Ⅵ. 메타모픽 테스트에 대한 제언

- 핵심 요약 : MR 자산 축적과 자동 입력 생성의 결합으로 정답 부재 영역의 검증 체계 구축.
- 품질 조직 : 도메인별 MR 카탈로그를 표준 자산으로 축적해 유사 기능 시험에 재사용.
- 머신러닝 개발팀 : 학습 데이터 변환·추론 일관성 검증을 정기 검증 항목으로 편성.
- 시험 자동화팀 : 속성 기반 테스트(property-based testing, 속성 위반 반례를 자동 탐색하는 기법)·퍼징(fuzzing, 비정상 입력 대량 주입 시험)과 결합해 MR 입력 공간을 자동 확대.

## Ⅶ. 결론

- 핵심 요약 : 메타모픽 테스트는 정답 부재가 검증을 가로막는 영역에서 관계를 오라클로 전환하는 기법.
- 검증 신뢰도는 MR의 타당성과 변환의 의미 보존 조건에 달림.
