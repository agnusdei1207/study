## 연관 키워드

- 탐욕 알고리즘, 탐욕적 선택 속성, 최적 부분 구조
- 교환 논법, 동적 계획법, 근사 알고리즘

## Ⅰ. 탐욕 알고리즘의 개요

- 핵심 요약 : **탐욕 알고리즘**(Greedy Algorithm)은 매 단계의 최선 선택을 확정해 해를 구성하되, 최적성 조건이 성립할 때만 최적 해를 보장하는 설계 기법.
- 개념 : 각 단계에서 현재 기준 최선의 후보를 선택하고 철회하지 않으며, 그 선택의 누적으로 전체 해를 구성하는 알고리즘 설계 기법.
- 배경 및 필요성 : 해의 조합을 모두 검사하는 완전 탐색은 문제 크기에 따라 계산량이 급증하므로, 선택 규칙만으로 해를 구성하는 효율적 접근 필요.
- 주요 목적 : 최적성 조건이 성립하는 문제에서 낮은 시간·공간 비용의 최적 해 산출, 성립하지 않는 문제에서 품질 보증형 근사 해의 확보.

## Ⅱ. 탐욕 알고리즘의 특징 및 장점

- 핵심 요약 : 두 최적성 조건이 성립하면 국소 선택의 반복만으로 전역 최적 해 도달이 가능한 기법.

1. **탐욕적 선택 속성**(Greedy Choice Property, 각 단계의 최선 선택이 어떤 전역 최적 해에도 포함되는 성질) : 현재 선택을 해의 일부로 확정 → 조합 탐색·백트래킹 생략.
2. **최적 부분 구조**(Optimal Substructure, 선택 후 남은 하위 문제의 최적 해가 전체 최적 해를 구성하는 성질) : 확정 선택과 하위 문제 해의 결합 → 전역 최적성 보장.
3. 비가역 선택 : 이전 선택의 철회·재배치 없음 → 단순한 제어 흐름과 적은 메모리 사용.
4. 선택 기준의 사전 정의 : 목적 함수·동률 처리 규칙을 수식으로 고정 → 구현의 명확성과 결과 재현성.

## Ⅲ. 탐욕 알고리즘의 구조 (흐름)

- 핵심 요약 : 후보·기준 정의에서 선택·검사·확정의 반복으로 해를 구성하고, 증명을 통해 최적성을 확인하는 구조.

```text
[ 탐욕 알고리즘 적용 절차 ]

후보 집합·선택 기준 정의
   ↓
현재 기준 최선 후보 선택
   ↓
실행 가능성·제약 검사
   ↓
해에 포함·확정 (철회 없음)
   ↓
종료 조건까지 반복
```

- 정당성 검증 : **교환 논법**(Exchange Argument, 탐욕 선택을 최적 해의 선택과 바꿔도 해가 악화되지 않음을 보이는 증명 방법)으로 탐욕 해와 최적 해의 동치 확인.

```text
[ 교환 논법의 증명 흐름 ]

탐욕 선택 g vs 최적 해의 선택 o
   ↓ g를 o로 교환
해 비용 악화 없음 확인
   ↓
교환 반복 후 탐욕 해 = 최적 해
```

## Ⅳ. 탐욕 알고리즘과 동적 계획법의 비교

- 핵심 요약 : 국소 선택의 즉시 확정인 탐욕과 상태별 부분 최적 값의 보존·비교인 **동적 계획법**(Dynamic Programming, 중복 하위 문제의 해를 저장·재활용해 전체 최적 해를 구하는 기법)은 최적성 조건의 성립 여부에 따라 선택.

| 비교 축 | 탐욕 알고리즘 | 동적 계획법 |
| --- | --- | --- |
| 선택 방식 | 현재 최선 선택의 즉시 확정 | 상태별 모든 선택의 평가·비교 |
| 최적성 근거 | 탐욕적 선택 속성·교환 논법 | 최적 부분 구조·점화식 |
| 계산량·메모리 | 일반적으로 정렬 수준의 부담 | 상태 수·전이 수에 비례 |
| 선택 철회 | 불가 | 상태 비교를 통한 간접 재선택 |
| 적합 문제 | 탐욕적 선택이 성립하는 문제(최소 신장 트리 등) | 선택 간 상호 의존 문제(0-1 배낭 문제 등) |

## Ⅴ. 탐욕 알고리즘의 한계와 방안

- 핵심 요약 : 최적성 조건 불성립 시의 전역 최적 해 누락이 핵심 위험이며, 적용 전 증명·반례 점검이 대응의 기준.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 국소 최적 함정 | 탐욕적 선택 속성 불성립 → 더 나은 조합 누락 | 소규모 입력의 전수 비교·반례 점검 후 최적성 증명 | 최적 해 대비 오차율 |
| 선택 기준 민감성 | 정렬 기준·동률 처리에 따른 결과 변동 | 목적 함수·동률 규칙의 수식 명시 | 기준 변경 시 결과 일치율 |
| 근사 해 오인 | **근사 알고리즘**(Approximation Algorithm, 보증된 오차 범위에서 최적에 가까운 해를 산출하는 기법)의 결과를 정확 해로 해석 | 근사 비·적용 전제의 문서화 | 근사 보증 위반 건수 |

## Ⅵ. 탐욕 알고리즘의 제언

- 핵심 요약 : 개발 조직은 최적화 문제의 구조 분석과 기법 선택을 표준 절차로 내재화하고 증명 자료를 자산으로 관리.

1. 개발 조직은 문제 유형별 기법 선택 기준(최적성 조건 성립 점검표)의 설계 표준 편입.
2. 기술 리뷰 조직은 최적성 증명·반례 시험 결과의 코드 리뷰 필수 검토 항목 지정.
3. 성능 분석 조직은 대규모 입력 실행 시간·메모리의 측정·벤치마크 체계 운영.

## Ⅶ. 탐욕 알고리즘의 결론

- 핵심 요약 : 탐욕 알고리즘은 국소 선택의 확정으로 효율을 얻는 대신 최적성 증명을 요구하는 설계 기법.
- 시사점 : 탐욕적 선택 속성의 성립 확인이 적용의 전제이며, 증명이 어려운 문제는 동적 계획법 등 대안 기법과의 비교가 기준.
