소프트웨어 공학 → 유지보수·품질 → **기술 부채(불명확한 요구사항과 품질 저하)**

## 30초 인출

- 본질: 기술 부채는 빠른 전달을 위해 택한 임시 설계·구현이 이후 변경 때마다 추가 수정 비용(이자)으로 쌓이는 부담
- 메커니즘: 불명확한 요구사항이나 일정 압박이 임시 구현을 낳고, 원금을 갚지 않으면 이후 변경마다 이자가 붙어 품질이 저하
- 통찰: 요구사항이 불명확하면 임시 구현이 반복되어 부채가 눈에 보이지 않게 쌓이므로 부채를 유형별 목록으로 관리하고 이자가 큰 항목부터 상환

<details>
<summary>핵심 용어</summary>

- **기술 부채(Technical Debt)** : Ward Cunningham이 제안한 개념으로, 지금의 임시 해법이 이후 수정 비용으로 돌아오는 부담
- **원금(Principal)** : 부채가 있는 코드·설계를 올바르게 고치는 데 드는 비용
- **이자(Interest)** : 원금을 갚지 않아 변경마다 추가로 드는 시간과 결함 비용
- **기술 부채 사분면(Technical Debt Quadrant)** : Martin Fowler가 의도성(의도적·비의도적)과 신중성(신중·무모)으로 부채를 나눈 분류
- **코드스멜(Code Smell)** : 부채가 있을 가능성을 나타내는 코드의 징후
- **리팩토링(Refactoring)** : 외부 동작을 유지하며 내부 구조를 개선해 부채를 상환하는 활동

</details>

## 2~4교시 25점 답안

## Ⅰ. 기술 부채의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **기술 부채** 는 빠른 전달을 위해 택한 임시 설계·구현이 이후 수정 비용으로 쌓이는 부담 |
| 목적 | 변경 비용 증가와 품질 저하의 통제 |

## Ⅱ. 금융 부채에 비유되는 기술 부채의 특징

| 특징 | 의미 |
|---|---|
| 원금과 이자 | 갚는 비용(원금)과 방치할 때의 추가 수정 비용(이자) |
| 비가시성 | 동작하는 동안 드러나지 않고 변경 때 나타남 |
| 의도성 | 일정 때문에 의도한 부채와 모르고 생긴 부채의 구분 |

## Ⅲ. 기술 부채의 발생과 누적 구조

### 발생과 누적

```text
불명확한 요구사항·일정 압박
    ↓
임시 설계·구현
    ↓
코드스멜·중복·낮은 시험 범위
    ↓
변경 때마다 수정 비용(이자) 증가 → 품질 저하
```

### 확대: 이자 누적 판단

```text
변경 요청
    ├─ 부채 없는 영역 → 정상 소요
    └─ 부채 있는 영역 → 수정 시간·결함 증가(이자 지불)
```

## Ⅳ. 기술 부채의 유형

### 발생 성격에 따른 분류(사분면)

| 구분 | 신중 | 무모 |
|---|---|---|
| 의도적 | 일정을 위해 알고 택한 임시안 | 설계를 무시한 편법 |
| 비의도적 | 지나고 보니 더 나은 설계를 알게 됨 | 원칙을 몰라 생긴 결함 |

### 발생 영역에 따른 분류

| 유형 | 내용 |
|---|---|
| 코드 부채 | 중복·복잡한 코드 |
| 설계·아키텍처 부채 | 결합도 높은 구조, 확장 제약 |
| 테스트 부채 | 자동화 시험 부족 |
| 문서 부채 | 최신이 아닌 설계·요구 문서 |
| 요구사항 부채 | 불명확·미확정 요구 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 요구사항이 불명확해 임시 구현이 반복 | 요구사항 명확화와 인수 기준의 사전 합의 |
| 부채가 비가시적이라 상환 우선순위 부재 | 부채 목록에 유형·영향·수정 비용 기록 |
| 신규 기능 일정 압박으로 상환 지연 | 일정에 부채 상환 시간을 포함 |
| 코드스멜 방치 | 리팩토링으로 부채 상환 |

## Ⅵ. 제언

부채를 유형·영향·수정 비용으로 목록화하고, 이자가 큰(변경이 잦은) 항목부터 리팩토링으로 상환

### 부채 관리 순환

```text
부채 식별·목록화
    ↓
이자(변경 빈도·결함) 기준 우선순위화
    ↓
리팩토링으로 상환
    ↓
목록 갱신
```

### 선택 근거: 사후 정리와의 비교

| 구분 | 문제 발생 후 정리 | 제언: 목록·우선순위 관리 |
|---|---|---|
| 부채 가시성 | 낮음 | 목록으로 파악 |
| 상환 시점 | 장애 이후 | 이자가 큰 순 |
| 변경 비용 | 계속 증가 | 통제 |
