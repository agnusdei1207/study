## 30초 인출

- 본질: 아키텍처 스타일은 구성요소의 종류와 연결 규칙을 정해 시스템 전체 구조에 반복 적용하는 설계 유형
- 메커니즘: 계층형·파이프-필터·클라이언트-서버·이벤트 기반·저장소 중심 등 스타일마다 구성요소와 통신 규칙이 정해져 특정 품질속성에 유리
- 통찰: 스타일마다 강한 품질속성이 다르므로 하나를 일률 적용하면 요구 품질과 어긋나 우선순위가 높은 품질속성을 먼저 정하고 그에 맞는 스타일을 선택

<details>
<summary>핵심 용어</summary>

- **아키텍처 스타일(Architecture Style)** : 구성요소 유형과 연결 규칙을 정해 시스템 구조에 반복 적용하는 설계 유형
- **계층형 아키텍처(Layered Architecture)** : 관심사별 계층으로 나누고 인접한 계층끼리만 호출하게 한 구조
- **파이프와 필터(Pipes and Filters)** : 독립적인 처리 단계(필터)를 데이터 흐름(파이프)으로 연결한 구조
- **클라이언트-서버(Client-Server)** : 서비스 요청자와 제공자를 분리한 구조
- **이벤트 기반 아키텍처(EDA)** : 이벤트의 발행·구독으로 구성요소를 느슨하게 연결한 구조
- **저장소 중심(Repository)** : 공유 데이터 저장소를 중심으로 여러 구성요소가 접근하는 구조

</details>

## 2~4교시 25점 답안

## Ⅰ. 아키텍처 스타일의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **아키텍처 스타일** 은 구성요소 유형과 연결 규칙을 정해 시스템 구조에 반복 적용하는 설계 유형 |
| 목적 | 검증된 구조의 재사용과 품질속성 충족 |

## Ⅱ. 아키텍처 스타일의 특징

| 특징 | 의미 |
|---|---|
| 구성요소·연결 규칙 | 스타일별 요소와 통신 방식 정의 |
| 품질속성과 연결 | 스타일마다 유리한 품질속성 상이 |
| 재사용 | 검증된 구조를 여러 시스템에 적용 |

## Ⅲ. 대표 스타일의 구조

### 대표 스타일의 구조

```text
계층형:        표현 → 업무 → 데이터
파이프-필터:   입력 → [필터1] → [필터2] → 출력
클라이언트-서버: 클라이언트 ⇄ 서버
이벤트 기반:   발행자 → 이벤트 브로커 → 구독자
저장소 중심:   구성요소들 ⇄ 공유 저장소
```

### 확대: 계층형의 호출 규칙

```text
표현 계층
    ↓ (인접 계층만 호출)
업무 계층
    ↓
데이터 계층
```

## Ⅳ. 스타일의 비교와 선택

| 스타일 | 강점 | 약점 | 적합 조건 |
|---|---|---|---|
| 계층형 | 관심사 분리, 수정 용이 | 계층 통과로 성능 저하 | 일반 업무 시스템 |
| 파이프-필터 | 단계 재조합 용이 | 상호작용 처리 곤란 | 데이터 변환·배치 처리 |
| 클라이언트-서버 | 서버 자원 중앙 관리 | 서버 병목·단일 장애점 | 다수 클라이언트 서비스 |
| 이벤트 기반 | 느슨한 결합, 확장성 | 흐름 추적 곤란 | 비동기 통합 |
| 저장소 중심 | 데이터 공유 용이 | 저장소 병목 | 데이터 공유 중심 시스템 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 품질속성 고려 없이 스타일 선택 | 우선순위 품질속성 시나리오로 스타일 평가 |
| 하나의 스타일로 모든 요구 대응 | 부분별로 다른 스타일 혼합 |
| 계층형의 불필요한 계층 통과 | 성능 민감 경로의 계층 통과 최소화 |

## Ⅵ. 제언

우선순위가 높은 품질속성을 먼저 정하고 그에 유리한 스타일을 선택하되, 부분별로 스타일을 혼합

### 스타일 선택 순서

```text
핵심 품질속성 선정
    ↓
후보 스타일별 강점·약점 대조
    ↓
스타일 선택 (필요 시 혼합)
```

### 확대: 품질속성별 후보

```text
수정 용이성 → 계층형
확장성·느슨한 결합 → 이벤트 기반
데이터 변환 처리 → 파이프-필터
```

### 선택 근거: 관행적 선택과의 비교

| 구분 | 관행적 선택 | 제언: 품질속성 기반 |
|---|---|---|
| 선택 기준 | 익숙함 | 우선 품질속성 |
| 요구 적합성 | 사후 확인 | 사전 평가 |
| 구조 변경 | 후반 재설계 위험 | 초기 결정 |
