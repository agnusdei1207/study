소프트웨어 공학 → 테스트·검증 → **테스트 자동화(Test Automation)**

## 30초 인출

- 본질: 테스트 자동화는 테스트 케이스의 실행·결과 비교·보고를 도구와 스크립트로 자동 수행하는 활동
- 메커니즘: 반복 실행이 많고 결과가 명확한 테스트를 스크립트로 만들어 CI 파이프라인에서 변경마다 자동 실행하고 결과를 보고
- 통찰: 자동화 대상을 가리지 않고 UI 테스트에 몰리면 유지 비용과 불안정한 테스트가 늘어나므로 빠르고 안정적인 단위·통합 테스트에 비중을 두는 피라미드 구조로 자동화

<details>
<summary>핵심 용어</summary>

- **테스트 자동화(Test Automation)** : 테스트 실행·비교·보고를 도구로 자동 수행하는 활동
- **테스트 피라미드(Test Pyramid)** : 단위 테스트를 가장 많이, UI 테스트를 가장 적게 두는 자동화 비중 모델
- **플래키 테스트(Flaky Test)** : 코드 변경이 없어도 결과가 통과와 실패로 바뀌는 불안정한 테스트
- **데이터 주도 테스트(Data-Driven Testing)** : 테스트 로직은 하나로 두고 입력 데이터를 외부에서 바꿔 반복 실행하는 방식
- **페이지 객체 모델(Page Object Model)** : UI 요소와 조작을 객체로 분리해 UI 테스트 유지보수를 쉽게 하는 패턴

</details>

## 2~4교시 25점 답안

## Ⅰ. 테스트 자동화의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **테스트 자동화** 는 테스트 실행·결과 비교·보고를 도구로 자동 수행하는 활동 |
| 목적 | 반복 테스트의 비용 절감과 빠른 피드백 |

## Ⅱ. 수동 테스트와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 반복 실행 | 변경마다 같은 테스트 재실행 |
| 일관성 | 사람 실수 없는 동일 절차 |
| 초기 투자 | 스크립트 작성·유지 비용 발생 |

## Ⅲ. 자동화 구조와 적용 절차

### 테스트 피라미드

```text
        /  UI  \        적음, 느리고 불안정
       /────────\
      /   통합    \      중간
     /────────────\
    /     단위      \    많음, 빠르고 안정적
```

### 확대: 자동화 적용 절차

```text
자동화 대상 선정 (반복·안정적·결과 명확)
    ↓
스크립트 작성 (데이터 주도·페이지 객체)
    ↓
CI 파이프라인에서 자동 실행
    ↓
결과 보고·유지보수
```

## Ⅳ. 자동화 대상 판단과 프레임워크

### 자동화 적합성

| 구분 | 적합 | 부적합 |
|---|---|---|
| 실행 빈도 | 자주 반복 | 일회성 |
| 결과 판정 | 명확 | 주관적 |
| 변경 빈도 | 안정적 | 화면이 자주 변경 |

### 자동화 설계 기법

| 기법 | 내용 |
|---|---|
| 데이터 주도 테스트 | 입력 데이터를 외부에서 주입 |
| 페이지 객체 모델 | UI 요소 변경 시 한 곳만 수정 |
| CI 연계 | 커밋마다 자동 실행 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| UI 테스트에 편중되어 유지 비용 증가 | 단위·통합 중심의 피라미드 구성 |
| 플래키 테스트로 신뢰도 저하 | 원인 제거와 격리, 재시도 정책 |
| 스크립트 유지보수 부담 | 데이터 주도·페이지 객체로 중복 제거 |

## Ⅵ. 제언

단위·통합 테스트를 중심으로 자동화하고 UI 테스트는 핵심 시나리오로 제한하며, 불안정한 테스트는 즉시 격리해 수정

### 자동화 비중 운영

```text
단위 > 통합 > UI 순으로 비중 설정
    ↓
CI에서 자동 실행
    ↓
플래키 테스트 격리·수정
```

### 확대: 플래키 처리

```text
테스트 결과 불안정
    ├─ 원인 파악 가능 → 수정
    └─ 원인 불명 → 격리 후 조사, 파이프라인 차단 방지
```

### 선택 근거: UI 중심 자동화와의 비교

| 구분 | UI 중심 | 제언: 피라미드 구조 |
|---|---|---|
| 실행 속도 | 느림 | 빠름 |
| 안정성 | 낮음 | 높음 |
| 유지 비용 | 큼 | 작음 |
