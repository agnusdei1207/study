## 연관 키워드
- 오픈소스 소프트웨어(OSS, Open Source Software), 오픈소스 정의, 라이선스, 저작권·고지, SBOM, 공급망 보안

### Ⅰ. 오픈소스 소프트웨어의 개요

- 핵심 요약 : 오픈소스 소프트웨어(OSS, Open Source Software)는 승인된 오픈소스 라이선스에 따라 사용·수정·재배포가 허용되는 소프트웨어.
- 개념 : 승인된 오픈소스 라이선스에 따라 사용·수정·재배포가 허용되는 소프트웨어(**오픈소스 소프트웨어**, Open Source Software).
- 배경 및 필요성 : 조직의 제품이 외부·전이적 오픈소스 구성 요소에 의존하지만 라이선스·버전·취약점·의무 추적이 부족한 경우 위험 발생.
- 주요 목적 : 공개 협업과 재사용을 통해 혁신·상호 운용성을 높이면서 지식 재산권·보안·공급망 책임을 지킴.

### Ⅱ. 오픈소스 소프트웨어의 특징 및 장점

- 핵심 요약 : 라이선스 권리·의무·구성 요소 인벤토리·취약점·유지 관리·기여·거버넌스.

1. 라이선스 권리·의무 : 사용·수정·배포·고지·소스 제공 조건 확인 → 의무 불이행과 권리 분쟁 예방.
2. 구성 요소 인벤토리 : 직접·전이 의존성과 버전·출처 기록 → 제품 공급망 투명성 확보.
3. 취약점·유지 관리 : 공지·패치·지원 상태 추적 → 알려진 취약점 노출 감소.
4. 기여·거버넌스 : 승인·코드 리뷰·커뮤니티 기여 절차 → 품질과 프로젝트 지속성 관리.

### Ⅲ. 오픈소스 소프트웨어의 구조 (흐름)

- 핵심 요약 : 구성 요소 탐지·신고 → 라이선스·출처 검토 → 승인·인벤토리 등록 → 빌드·배포에 SBOM 생성 → 취약점·의무 모니터링 → 패치·고지·기여 관리.

```text
구성 요소 탐지·신고
   ↓
라이선스·출처 검토
   ↓
승인·인벤토리 등록
   ↓
빌드·배포에 SBOM 생성
   ↓
취약점·의무 모니터링
   ↓
패치·고지·기여 관리
```

```text
오픈소스 구성 요소
   ↓ 라이선스·출처·버전 확인
제품 의존성 그래프·SBOM
   ↓ 취약점·고지·소스 의무 검토
릴리스 승인·지속 모니터링
```

### Ⅳ. 허용형 라이선스와 카피레프트 라이선스 비교

- 핵심 요약 : 허용형 라이선스는 저작권·고지 등 조건 아래 재사용 허용, 카피레프트 라이선스는 파생·배포 조건에 동일·상호 라이선스 의무가 생길 수 있음.

| 비교 방법 | 주요 특성 | 적합한 적용 조건 |
|---|---|---|
| 허용형 라이선스 | 저작권·고지 등 조건 아래 재사용 허용 | 배포물의 의무·특허·고지 검토 |
| 카피레프트 라이선스 | 파생·배포 조건에 동일·상호 라이선스 의무가 생길 수 있음 | 결합·배포 방식과 소스 제공 의무 검토 |
| 상용 독점 라이선스 | 계약 범위·좌석·환경·사용량에 따라 이용 | 조달·구독·재배포 권한을 계약으로 확인 |

### Ⅴ. 오픈소스 소프트웨어의 한계와 방안

- 핵심 요약 : 라이선스 의무 미준수·취약·미 유지 구성 요소·공급망 변조·계정 탈취를 SBOM 스캔·위험도 기반 갱신·신뢰 저장소로 관리.

| 위험 | 원인·영향 | 대응 통제 | 지표 예시 |
|---|---|---|---|
| 라이선스 의무 미준수 | 배포 중단·시정·권리 분쟁 | SBOM·라이선스 스캔과 법무 검토·고지 자동화 | 미분류 구성 요소, 고지 누락 |
| 취약·미 유지 구성 요소 | 패치가 없는 오래된 의존성으로 침해 위험 | 위험도 기반 갱신·대체·격리·취약점 대응 SLA(Service Level Agreement, 서비스 수준 협약) | 취약점 미조치 기간 |
| 공급망 변조·계정 탈취 | 악성 패키지·빌드 산출물 유입 | 신뢰 저장소·서명·출처 검증·빌드 무결성 | 검증된 출처 비율, 이상 패키지 |

### Ⅵ. 오픈소스 소프트웨어 적용에 대한 기술사적 제언

- 핵심 요약 : 공개 협업과 재사용을 통해 혁신·상호 운용성을 높이면서 지식 재산권·보안·공급망 책임을 지킴.

- 실행 제언 : 조직은 개발 초기에 오픈소스 정책·책임자·승인 경로를 정하고 제품 팀·법무·보안이 SBOM·라이선스·취약점 정보를 공유하는 지속 운영 체계를 마련.

### Ⅶ. 결론

- 핵심 요약 : 오픈소스 소프트웨어(OSS, Open Source Software)는 승인된 오픈소스 라이선스에 따라 사용·수정·재배포가 허용되는 소프트웨어.
- 시사점 : 오픈소스는 무조건 무료나 무제한 사용을 뜻하지 않으며, 라이선스 의무와 공급망 위험을 관리할 때 재사용·협업의 이점이 지속.
