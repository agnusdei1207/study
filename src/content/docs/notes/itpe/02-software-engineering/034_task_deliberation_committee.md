## 연관 키워드
- 과업심의위원회, 소프트웨어 진흥법 제50조, 과업내용 확정
- 변경 심의, 계약금액·기간 조정, 무상 추가 과업

## Ⅰ. 소프트웨어사업 과업심의위원회의 개요

- 핵심 요약 : 과업심의위원회는 공공 소프트웨어사업의 과업 확정·변경과 계약금액·기간 조정을 심의하는 발주기관의 심의 조직.
- 개념 : 소프트웨어사업의 발주 전 **과업내용 확정** (발주하려는 사업의 목적·범위 등 수행 내용을 정하는 것)과 수행 중 변경, 계약금액·기간 조정을 심의하기 위해 발주기관에 두는 심의 조직이 **소프트웨어사업 과업심의위원회**임.
- 배경 및 필요성 : 공공 소프트웨어사업은 요구가 불명확한 상태로 발주되는 경우가 많고 수행 중 요구 추가가 잦아, 합의 없는 변경은 **무상 추가 과업** (대가 조정 없이 늘어나는 수행 범위)과 분쟁·품질 저하로 이어짐.
- 주요 목적 : 사업 범위의 명확한 확정과 변경의 적정성 심의를 통한 계약 형평성·사업 품질 확보.

## Ⅱ. 소프트웨어사업 과업심의위원회의 특징 및 장점

- 핵심 요약 : 법정 근거·사업 전 주기 심의·전문가 참여·계약 연계가 심의의 실질성을 뒷받침함.

1. 법적 근거 : 「**소프트웨어 진흥법**」 제50조가 과업내용 확정과 변경에 관한 심의를 위한 위원회 구성·운영의 근거 → 과업 절차의 법적 정합성 확보.
2. 전 주기 심의 : 발주 전 과업내용 확정과 수행 중 변경을 모두 심의 대상으로 삼음 → 사업 전 주기의 범위 관리 효과.
3. 전문성 확보 : 소속 공무원과 소프트웨어 분야 전문가가 위원으로 참여 → 기술 타당성·대가 적정성의 객관적 검토 효과.
4. 계약 연계 : **변경 심의** (수행 중 변경의 타당성과 대가·기간 조정에 관한 심의) 결과를 계약 변경·검수 기준에 반영 → 무상 추가 과업 방지와 정당한 대가 지급.

## Ⅲ. 소프트웨어사업 과업심의위원회의 구조 (흐름)

- 핵심 요약 : 위원장 아래 소속 공무원·소프트웨어 분야 전문가로 구성하고, 발주 전 확정 심의와 변경 심의 절차로 운영.
- 구성요소 : 위원장(발주기관의 장이 지정하는 소속 임원), 위원(소속 공무원, 소프트웨어 분야 전문가), 간사(사업 부서의 실무 지원).

```text
[ 과업심의위원회 구성 ]

위원장 : 발주기관의 장이 지정하는 소속 임원

    위원 : 소속 공무원 (사업·계약·예산)
    위원 : 소프트웨어 분야 전문가
    간사 : 사업 부서의 실무 지원
```

```text
사업계획·과업요구서 작성
   ↓
발주 전 과업내용 확정 심의
   ↓
계약 체결·사업 수행
   ↓
변경요청 접수·영향 분석
   ↓
변경 심의·계약금액·기간 조정
```

## Ⅳ. 과업심의위원회 심의와 사후 변경 처리의 비교

- 핵심 요약 : 계약 후 개별 협의에 맡기는 사후 변경 처리보다 법정 심의 절차가 객관성·추적성·분쟁 예방에서 우위.

| 비교 축 | 사후 변경 처리 (계약 후 협의) | 과업심의위원회 심의 |
| --- | --- | --- |
| 처리 시점 | 변경 발생 후 개별 협의 | 발주 전 확정과 수행 중 변경의 사전 심의 |
| 판단 근거 | 이해관계자 간 협상에 의존 | 전문가 포함 위원회의 절차적 심의 |
| 대가·기간 | 증빙 부족 시 무상 추가 과업 위험 | 영향 분석에 근거한 계약금액·기간 조정 |
| 기록·추적 | 합의 내용이 문서로 남지 않기 쉬움 | 심의 기록·의결 내용으로 관리 |
| 분쟁 대응 | 해석 차이·감사 지적 위험 | 심의 절차가 분쟁·감사 대응의 근거 |

## Ⅴ. 소프트웨어사업 과업심의위원회의 한계와 방안

- 핵심 요약 : 형식적 심의·전문성 편향·심의 지연·비공식 변경을 절차·인원·기준 관리로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 형식적 심의 | 일괄 의결·사후 보고 관행 → 심의의 실질 상실 | 과업안 사전 배포·별도 의견 절차 운영 | 심의 보완 지시 건수 |
| 전문성·독립성 부족 | 전문가 편성 어려움·이해충돌 → 심의 품질 저하 | 경력 기준 위원 선정·이해충돌 회피 규정 | 재심의·이의 제기 건수 |
| 심의 지연 | 회의 소요·일정 미확보 → 계약·일정 지연 | 정기 회의 일정·심의 기한 관리 | 심의 소요 일수 |
| 변경 비공식화 | 구두 합의·메모 수준 처리 → 범위 확대 누적 | 변경요청서·영향 분석·심의 전 과정 의무화 | 미승인 변경 건수 |

## Ⅵ. 소프트웨어사업 과업심의위원회에 대한 제언

- 핵심 요약 : 발주기관은 과업심의를 계약 거버넌스의 일부로 내재화하고, 중앙 차원의 표준·인력 인프라 지원으로 심의 역량을 확산해야 함.

1. 제도·표준 : 발주기관이 위원회 운영 규정과 심의 체크리스트를 표준화하고, 조달·소프트웨어 진흥 기관의 운영 가이드를 반영.
2. 인력 기반 : 다수 발주기관이 공동 활용하는 소프트웨어 전문가 풀과 심의 지원 조직을 구성해 소규모 기관의 심의 부담 완화.
3. 연계 체계 : 심의 결과를 요구사항 관리·계약·검수 체계와 연동해 사업 전 주기의 추적성 확보.

## Ⅶ. 결론

- 핵심 요약 : 과업심의위원회는 과업 범위와 변경을 법정 절차로 통제하는 공공 소프트웨어 계약의 심의 장치.
- 시사점 : 심의의 가치는 의결 자체가 아니라 발주 전 범위 명확화와 변경의 정당한 대가·기간 조정에 있음.
