지식 위치: 소프트웨어공학 → 사용자 경험·상호작용 설계 → **HCI(Human-Computer Interaction)**

---

## 30초 인출

- 본질: **HCI(Human-Computer Interaction)** 는 사용자의 인지적·물리적 특성과 시스템 간의 상호작용 프로세스를 분석하고 최적화하여 효과성, 효율성, 만족도를 극대화하는 인간 중심 인터페이스 설계 및 평가 학제 분야
- 메커니즘: 사용자 목표 및 심적 모형(Mental Model) 수립 → 입력 조작 실행(Gulf of Execution 축소) → 시스템 처리 및 피드백 감지(Gulf of Evaluation 축소) → 반복적 사용성 검증을 통한 UX 개선
- 통찰: 기능 구현 중심의 설계는 개발자 모델과 사용자 심적 모형 간의 괴리를 초래하여 높은 인지 부하와 이탈을 유발하므로 GOMS/KLM 기반의 정량적 과업 분석과 Norman의 실행·평가 간극 축소 설계를 개발 초기부터 통합 적용할 필요가 있음

<details>
<summary>핵심 용어</summary>

- **인간 정보처리 모델(MHP)** : 인간의 인지 과정을 지각(Perceptual), 인지(Cognitive), 운동(Motor) 프로세서와 단기/장기 기억 구조로 체계화한 심리학 모델
- **GOMS 모델** : 사용자의 과업 수행을 목표(Goals), 연산자(Operators), 방법(Methods), 선택 규칙(Selection Rules)으로 분해하여 정량 예측하는 모델
- **실행의 간극(Gulf of Execution)** : 사용자가 머릿속으로 의도한 바를 시스템 인터페이스 상에서 실제 물리적 조작으로 연결할 때 느끼는 격차
- **평가의 간극(Gulf of Evaluation)** : 시스템의 실행 결과를 보고 사용자가 의도한 목표가 올바르게 달성되었는지 해석할 때 느끼는 격차
- **어포던스(Affordance)** : 별도의 설명서 없이도 사물의 형태와 시각적 단서만으로 직관적인 조작 방식을 유도하는 행동 유도성

</details>

## 2~4교시 예상문제 (25점)

> 사용자 중심 인터페이스 설계를 위한 HCI(Human-Computer Interaction)의 개념과 Norman의 상호작용 모델(실행·평가의 간극)을 설명하고, GOMS/KLM 인지 분석 모델 및 인터페이스 진화(CLI $\rightarrow$ GUI $\rightarrow$ NUI $\rightarrow$ OUI)에 따른 사용성 평가 방안을 제시하시오.

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 인간(Human)과 컴퓨터(Computer) 간의 상호작용(Interaction)을 편리하고 안전하며 유용하게 만들기 위해 심리학, 컴퓨터공학, 디자인을 융합한 학제적 설계 및 평가 방법론 |
| 목적 | 인간 중심 설계(UCD)를 통한 인지 부하 감소, 조작 오류 최소화, 작업 효율성 및 사용자 경험(UX) 극대화 |

## Ⅱ. 핵심 특징

HCI는 단순한 그래픽 미학을 넘어 인간의 인지적 한계를 시스템 아키텍처에 반영하는 정량적 공학 원리.

| 핵심 속성 | 공학적 원리 | 설계 적용 방안 |
|---|---|---|
| **심적 모형(Mental Model) 일치** | 사용자가 상상하는 작동 원리와 시스템의 실제 동작 구조 일치화 | 실세계 메타포(휴지통, 폴더 등) 도입을 통한 직관적 인터페이스 구축 |
| **인지 부하(Cognitive Load) 최소화** | 밀러의 법칙(7±2) 및 피츠의 법칙(Fitts's Law) 준수 | 조작 메뉴 항목 그룹화, 핵심 액션 버튼의 시각적 크기 및 접근성 확대 |
| **행동 유도성(Affordance) 강화** | 외형적 단서만으로 클릭 가능 여부 및 스크롤 방향 즉시 인지 | 볼록한 버튼 셰이프, 그림자 효과, 마우스 호버(Hover) 시각 반응 부여 |
| **즉각적 피드백(Immediate Feedback)** | 사용자 조작 후 지연 없이 상태 변화를 청각/시각적으로 통보 | 로딩 스피너, 프로그레스 바, 토스트 팝업, 햅틱 진동 피드백 제공 |

## Ⅲ. 체계·프로세스

Norman의 7단계 상호작용 모델과 인지 간극(Gulf) 해소 프레임워크.

```text
[Norman의 HCI 상호작용 및 간극(Gulf) 해소 체계]
                                                                                                           
                                       [ 사용자의 목표 형성 (Goal) ]                                       
                                                    │                                                      
                  ┌─────────────────────────────────┴─────────────────────────────────┐                    
                  │                                                                   │                    
  [실행의 간극 (Gulf of Execution)]                                   [평가의 간극 (Gulf of Evaluation)]   
  * 의도를 어떻게 시스템에 전달할 것인가?                             * 시스템이 내 의도대로 되었는가?     
                  │                                                                   │                    
                  ▼                                                                   ▲                    
            (1) 의도 수립 (Intention)                                           (7) 결과 평가 (Evaluation) 
                  │                                                                   ▲                    
                  ▼                                                                   │                    
            (2) 행동 계획 (Action Plan)                                         (6) 상태 해석 (Interpret)  
                  │                                                                   ▲                    
                  ▼                                                                   │                    
            (3) 물리적 조작 (Execution)                                         (5) 상태 지각 (Perceive)   
                  │                                                                   │                    
                  └─────────────────────────────────┬─────────────────────────────────┘                    
                                                    ▼                                                      
                                    +───────────────────────────────+                                      
                                    |     컴퓨터 시스템 (Machine)    |                                      
                                    |     - 내부 상태 전이 및 처리  |                                      
                                    +───────────────────────────────+                                      
```

- **HCI 상호작용 개선 프로세스**:
  1. **실행의 간극 축소 방안** : 명확한 시각적 어포던스, 표준화된 UI 컴포넌트, 조작 제약조건(Constraint)을 적용하여 사용자가 무엇을 눌러야 할지 즉시 파악하도록 지원.
  2. **시스템 처리 및 상태 전이** : 사용자의 입력 자극을 수신한 시스템이 내부 비즈니스 로직 및 상태 머신(FSM)을 트리거.
  3. **평가의 간극 축소 방안** : 처리 진행 상태와 최종 결과를 실시간으로 명확히 표현(로딩 인디케이터, 명시적 완료 메시지)하여 시스템 현재 상태를 직관적으로 해석 가능하도록 설계.

## Ⅳ. 종류·비교

#### 사용자 인터페이스(UI) 진화 단계 비교

| 비교 항목 | CLI (Command Line) | GUI (Graphical User) | NUI (Natural User) | OUI (Organic User) |
|---|---|---|---|---|
| **입력 매개체** | 키보드 텍스트 명령어 | 마우스 포인터, 창, 아이콘 | 음성, 제스처, 시선, 터치 | 유연 디스플레이, 형상 변형 |
| **인지 부하** | 매우 높음 (명령어 암기 필수) | 보통 (시각적 선택지 제공) | 낮음 (인간의 자연스러운 행위) | 극소 (물리적 환경과 일체화) |
| **상호작용 방식** | 일괄 텍스트 타이핑 | 메뉴 탐색, WIMP 클릭 | 대화형 음성 인식, 신체 모션 | 유기적 형태 변형 감지 |
| **적용 분야** | 서버 운영체제, 개발 툴 | PC, 웹 브라우저, 스마트폰 | AI 스피커, AR/VR, 스마트홈 | 웨어러블, 스마트 의류, 롤러블 |

#### 정량적 인지공학 분석 모델 비교

| 모델명 | 주요 개념 | 분석 메커니즘 | 실무 적용 목적 |
|---|---|---|---|
| **GOMS 모델** | Goals, Operators, Methods, Selection Rules | 작업을 목표와 최소 기본 동작 단위로 계층 분해 | 숙련된 사용자의 최적 작업 경로 및 소요 시간 정량 예측 |
| **KLM 모델** | Keystroke-Level Model | 키 입력(K), 마우스 포인팅(P), 클릭(B), 멘탈 준비(M) 시간 합산 | 특정 UI 화면 간 단축키/마우스 이동 효율성 비교 분석 |
| **Fitts's Law** | 이동 거리($D$)와 타깃 크기($W$)의 로그 비례 | $MT = a + b \log_2(2D / W)$ 공식 기반 포인팅 시간 계산 | 핵심 액션 버튼의 최적 배치 위치와 크기 결정 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 개발자 중심의 시스템 멘탈 모델로 설계되어 일반 사용자의 조작 오류 및 인지 마찰 유발 | 페르소나(Persona) 설정 및 고객 여정 지도(Customer Journey Map)를 수립하여 사용자 중심 설계(UCD) 철저 이행 |
| 시각장애인, 고령자 등 디지털 취약 계층의 NUI/GUI 접근성 차단 및 불평등 초래 | W3C WCAG 2.2 표준 준수, 스크린 리더 호환성 확보, 고대비 모드 및 키보드 대체 입력 수단 전면 제공 |
| 음성/제스처 등 NUI 환경에서 배경 소음 및 모션 오인식으로 인한 시스템 오작동 | 멀티모달(Multimodal) 인터페이스를 구축하여 음성과 터치/시각 피드백을 교차 검증하는 상호작용 도입 |

## Ⅵ. 제언

거대언어모델(LLM) 기반 에이전틱 상호작용과 멀티모달 융합을 통한 실행 및 평가 간극의 최소화

```text
[사용자 의도 표현] (자연어·제스처 멀티모달 입력)
         ↓
[에이전틱 AI 인지] (LLM 기반 문맥 해석 및 실행 간극 해소)
         ↓
[맥락 기반 자율 실행] (API 연계 및 작업 자동화)
         ↓
[투명한 다감각 피드백] (시각·음성 실시간 피드백 및 평가 간극 해소)
```

| 설계 영역 | 핵심 추진 과제 | 검증 지표 |
|---|---|---|
| **인터페이스 지능화** | 자연어 대화형 에이전트 및 컨텍스트 인식 UI 도입 | 사용자 과업 완수 시간(Task Completion Time) 단축 |
| **접근성 의무화** | 한국형 웹 콘텐츠 접근성 지침(K-WCAG) 인증 취득 | 스크린 리더 오류율 제로 및 접근성 인증 마크 획득 |
| **정량 사용성 평가** | SUS(System Usability Scale) 및 눈동자 시선 추적(Eye-tracking) | SUS 점수 80점 이상 및 핵심 버튼 시선 체류율 극대화 |
