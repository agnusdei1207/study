## 연관 키워드

- HCI(Human-Computer Interaction), 사용성(Usability), 접근성(Accessibility), UI(User Interface), UX(User Experience)
- 노먼의 상호작용 7단계, 실행의 간극(Gulf of Execution), 평가의 간극(Gulf of Evaluation), 닐슨 10대 휴리스틱(Heuristic), WAI-ARIA

## Ⅰ. HCI의 개요

- 핵심 요약 : 인간과 컴퓨터 간 효율적·안전·만족스러운 상호작용을 설계·평가하는 융합 학문 및 엔지니어링 방법론.
- 개념 : 인간(사용자)과 컴퓨터 시스템 간의 효율적이고 안전하며 만족스러운 상호작용을 위해 사용자 인터페이스(UI, User Interface), 사용자 경험(UX, User Experience), 인지 심리학, 소프트웨어 공학을 융합하여 상호작용 시스템을 설계, 평가, 구현하는 학문 및 엔지니어링 방법론(HCI, Human-Computer Interaction).
- 배경 및 필요성 : 컴퓨팅 시스템 복잡도 증가에 따른 조작 실수 방지, 디지털 전환(DX, Digital Transformation) 시대의 고객 경험 만족도 극대화 요구, 모바일·음성·XR(Extended Reality) 등 다양한 상호작용 채널 확산.
- 핵심 목표 : 사용성(Usability), 접근성(Accessibility), 감성 품질(User Experience)의 동시 달성.

## Ⅱ. HCI의 특징

- 핵심 요약 : 학문 융합성, 인지 심리 기반 원칙, 평가 원칙 체계, 다채널 확장성의 결합.

1. 융합 학문 : UI(User Interface), UX(User Experience), 인지 심리학, 소프트웨어 공학의 통합적 접근.
2. 인지 심리 기반 : 노먼(Donald Norman)의 상호작용 7단계 모델과 실행·평가의 두 가지 간극 개념.
3. 평가 원칙 체계 : 닐슨(Jakob Nielsen)의 사용성 평가 10대 휴리스틱(Heuristic) 기반 설계 검증.
4. 멀티모달 확장 : 모바일, 워치, 음성 인터페이스, AR(Augmented Reality)/VR(Virtual Reality) 등 다변화된 접점 지원.
5. 포용적 설계 지향 : 장애인·고령자를 포함한 전 사용자층의 접근성(Accessibility) 확보.

## Ⅲ. HCI의 구조 (흐름)

- 핵심 요약 : 목표 형성부터 시스템 상태 평가까지 순환하는 노먼의 상호작용 7단계와 두 가지 인지적 간극.
- 노먼(Donald Norman)의 상호작용 7단계.

```text
[ 1. 사용자의 목표 형성 (Goal) ]
   │
   ▼
[ 2. 의도 형성 ] -> [ 3. 행동 계획 ]
   │
   ▼
[ 4. 물리적 실행 ]
   │ (실행의 간극, Gulf of Execution)
   ▼
[ 컴퓨터 시스템 ]
   │
   ▼ (평가의 간극, Gulf of Evaluation)
[ 5. 지각 ] -> [ 6. 해석 ]
   │
   ▼
[ 7. 시스템 상태 평가 ]
   │
   ▼ (목표 대비 피드백 루프)
(1. 목표 형성으로 회귀)
```

- 실행의 간극(Gulf of Execution) : 사용자의 의도와 시스템이 제공하는 조작 방법 간 차이, 좋은 어포던스(Affordance)와 시그니파이어(Signifier)로 해소.
- 평가의 간극(Gulf of Evaluation) : 시스템 수행 결과의 지각·해석과 원래 목표 간 차이, 즉각적이고 명확한 피드백으로 해소.
- 설계 평가 기준 : 닐슨(Jakob Nielsen)의 사용성 평가 10대 휴리스틱(Heuristic).

| 휴리스틱 원칙 | 핵심 설명 및 가이드라인 |
|---|---|
| 1. 시스템 상태의 가시성 | 적절한 시간 내 지속적인 피드백(진행률 표시바 등) 제공 |
| 2. 현실 세계와의 일치 | 전문 컴퓨터 용어가 아닌 사용자 친숙 언어, 개념, 관습 사용 |
| 3. 사용자 제어 및 자유 | 사용자 실수에 대한 즉각적 '실행 취소(Undo)' 및 '탈출구' 제공 |
| 4. 일관성과 표준 | 동일한 단어, 아이콘, 배치의 전체 플랫폼 일관된 의미 유지 |
| 5. 오류 예방 | 오류 발생 조건의 사전 제거 또는 확인 대화상자 제공 |
| 6. 회상보다는 재인 | 정보의 머릿속 기억(Recall) 유도가 아닌 화면 노출(Recognize) |
| 7. 사용의 유연성과 효율성 | 초보자와 숙련자 모두를 위한 단축키 및 가속기 제공 |
| 8. 미학적이고 미니멀한 디자인 | 불필요하거나 무관한 정보의 화면 배제로 시각적 혼란 방지 |
| 9. 오류 인식 및 복구 지원 | 오류 메시지의 명확한 평어 기술 및 구체적 해결책 제시 |
| 10. 도움말 및 문서화 | 검색 용이하고 작업에 구체적인 도움말 문서 제공 |

## Ⅳ. 실행의 간극과 평가의 간극의 비교

- 핵심 요약 : 행동 실행 단계의 조작 문제와 결과 평가 단계의 해석 문제로 구분되는 두 간극.

```text
[ 사용자 의도 ]
    │  ① 실행의 간극 : 의도 vs 시스템 조작 방법
    ▼
[ 시스템 조작 ] ──▶ [ 시스템 상태 변화 ]
    ▲                     │
    │  ② 평가의 간극 : 결과 지각·해석 vs 원래 목표
    └─────────────────────┘
 해소: 어포던스·시그니파이어    해소: 즉각적·명확한 피드백
```

| 비교 항목 | 실행의 간극 (Gulf of Execution) | 평가의 간극 (Gulf of Evaluation) |
|---|---|---|
| 발생 단계 | 목표 형성~물리적 실행 단계(1~4단계) | 지각~시스템 상태 평가 단계(5~7단계) |
| 문제 본질 | 의도한 바와 시스템 제공 조작 방법 간 차이 | 시스템 결과의 지각·해석과 원래 목표 간 차이 |
| 해소 수단 | 좋은 어포던스(Affordance), 시그니파이어(Signifier) | 즉각적이고 명확한 피드백 |
| 설계 시사점 | 조작 방법의 직관적 노출 | 수행 결과의 명확한 가시화 |

## Ⅴ. HCI의 장점과 한계

- 핵심 요약 : 조작 실수 방지와 경험 만족도 향상의 이점, 인지 부하·주관성·접근성 트레이드오프의 한계.
- 장점

  1. 체계적 설계 원칙 적용을 통한 사용자 조작 실수 방지.
  2. 휴리스틱 평가 기반의 저비용·신속한 UI(User Interface) 결함 검출.
  3. 사용성·접근성·감성 품질의 동시 확보를 통한 고객 경험 경쟁력 강화.
- 한계점 1 : 멀티 디바이스 및 멀티모달 환경에서의 사용자 인지 부하(Cognitive Load)
  - 한계점 : 스마트폰, 워치, 음성 인터페이스, AR(Augmented Reality)/VR(Virtual Reality) 등 다변화된 접점에서 일관되지 않은 인터랙션 설계 시 사용자 혼란 및 피로도 급증.
  - 해결 방안 : 멘탈 모델(Mental Model) 분석 기반 크로스 플랫폼 디자인 시스템(Design System) 구축, GOMS(Goals, Operators, Methods, Selection) 및 KLM(Keystroke-Level Model)을 통한 작업 단계 최소화 정량 분석.
- 한계점 2 : 정성적 사용성 피드백의 주관성 및 개발 우선순위 충돌
  - 한계점 : 사용자 인터뷰·관찰 결과의 소수 의견 편향 가능성, 성능·일정 압박 속 UI/UX 개선 작업의 후순위화.
  - 해결 방안 : SUS(System Usability Scale) 등 표준화된 정량 지표와 A/B 테스팅, 히트맵, 클릭스트림 빅데이터 분석 결합 데이터 주도(Data-Driven) UX 의사결정.
- 한계점 3 : 접근성(Accessibility) 준수와 화려한 인터랙션 간의 트레이드오프
  - 한계점 : 고도화된 동적 그래픽·마이크로 애니메이션 구현 시 스크린 리더 미지원, 색약자 식별 곤란 등 디지털 정보 취약 계층의 접근 차단.
  - 해결 방안 : W3C(World Wide Web Consortium) WAI-ARIA(Accessible Rich Internet Applications) 표준 가이드라인 의무 준수, 자동화 접근성 정적 검사 도구(Axe, Lighthouse)의 빌드 파이프라인 품질 게이트 통합.

## Ⅵ. 현대 인터랙션 엔지니어링을 위한 기술사적 제언

- 핵심 요약 : 디자인 시스템 기반 일관성 확립과 웹 접근성 자동 검증 체계의 구축.
- 디자인 시스템(Design System) 기반의 UI/UX 일관성 확립 : 다변화된 프론트엔드 환경에서 Figma와 Storybook 연계 원자적 디자인(Atomic Design) 기반 디자인 토큰(Design Token) 구축을 통한 개발-디자인 간 의사소통 비용 절감 및 일관된 경험 보장.
- 웹 접근성(WCAG(Web Content Accessibility Guidelines) 2.2 / KWCAG(Korean Web Content Accessibility Guidelines)) 및 포용적 디자인(Inclusive Design) 의무 준수 : 장애인·고령자 차별 방지를 위한 스크린 리더 대체 텍스트(alt), 키보드 전용 내비게이션, 명도 대비(4.5:1 이상)의 프론트엔드 CI(Continuous Integration) 파이프라인(Lighthouse) 자동 검증 체계 구축 필수.

## Ⅶ. 결론

- 핵심 요약 : HCI는 인지 심리 원칙과 공학적 검증을 결합한 상호작용 품질 체계.
- 요약 : 노먼의 7단계 모델과 닐슨의 10대 휴리스틱을 기반으로 사용성·접근성·감성 품질을 동시에 추구하는 설계·평가 방법론.
- 시사점 : 디자인 시스템 기반 일관성 유지, 데이터 주도 UX 의사결정, 접근성 자동 검증의 파이프라인 내재화가 핵심 과제.
