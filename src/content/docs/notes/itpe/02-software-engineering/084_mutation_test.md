## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 테스트·검증 → **뮤테이션 테스트(Mutation Test)**

## 30초 인출

- 본질: 뮤테이션 테스트는 원본 코드에 작은 결함(뮤턴트)을 일부러 넣고 기존 테스트가 그 결함을 찾아내는지로 테스트 케이스의 검출 능력을 평가하는 테스트
- 메커니즘: 변형 연산자로 뮤턴트를 만들고 테스트를 실행해 실패하면 사망(killed), 통과하면 생존(survived)으로 분류해 뮤테이션 점수 산출
- 통찰: 커버리지가 높아도 검증(assert)이 약하면 결함을 잡지 못하므로 뮤테이션 점수로 검출력을 재고 생존 뮤턴트를 기준으로 테스트를 보강

<details>
<summary>핵심 용어</summary>

- **뮤테이션 테스트(Mutation Testing)** : 코드에 인위적 결함을 넣어 테스트 검출력을 평가하는 기법
- **뮤턴트(Mutant)** : 원본 코드에 작은 변경을 가한 결함 코드
- **사망 뮤턴트(Killed Mutant)** : 테스트가 실패하여 검출된 뮤턴트
- **생존 뮤턴트(Survived Mutant)** : 모든 테스트를 통과해 검출되지 않은 뮤턴트
- **동등 뮤턴트(Equivalent Mutant)** : 코드가 변해도 동작이 원본과 같아 검출할 수 없는 뮤턴트
- **뮤테이션 점수(Mutation Score)** : 사망 뮤턴트 수를 (전체 뮤턴트 − 동등 뮤턴트)로 나눈 값

</details>

## 2~4교시 25점 답안

## Ⅰ. 뮤테이션 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **뮤테이션 테스트** 는 코드에 작은 결함을 넣어 테스트 케이스의 결함 검출 능력을 평가하는 테스트 |
| 목적 | 테스트 케이스의 품질 평가와 보강 대상 식별 |

## Ⅱ. 일반 테스트와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 테스트의 테스트 | 제품이 아닌 테스트 케이스를 평가 |
| 결함 주입 | 연산자·상수 등의 작은 변경 |
| 정량 지표 | 뮤테이션 점수 산출 |

## Ⅲ. 뮤테이션 테스트 절차

### 수행 절차

```text
원본 코드에서 뮤턴트 생성 (변형 연산자 적용)
    ↓
각 뮤턴트에 기존 테스트 실행
    ├─ 테스트 실패 → 사망(killed)
    └─ 모두 통과 → 생존(survived)
    ↓
뮤테이션 점수 = 사망 / (전체 − 동등)
```

### 확대: 변형 연산자 예

```text
산술: a + b → a − b
관계: x > 0 → x >= 0
논리: && → ||
상수: 10 → 11
문장 삭제: return x; → (삭제)
```

## Ⅳ. 뮤턴트 분류와 결과 해석

| 결과 | 의미 | 조치 |
|---|---|---|
| 사망 | 테스트가 결함을 검출 | 유지 |
| 생존 | 테스트가 결함을 검출하지 못함 | 케이스 보강 |
| 동등 | 동작이 원본과 같아 검출 불가 | 점수 계산에서 제외 |

| 비교 | 코드 커버리지 | 뮤테이션 점수 |
|---|---|---|
| 측정 대상 | 실행된 코드 비율 | 결함 검출 능력 |
| 한계 | 검증 여부 미확인 | 비용이 큼 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 뮤턴트 수가 많아 실행 비용 과다 | 핵심 모듈·대표 연산자로 범위 제한 |
| 동등 뮤턴트 판별 곤란 | 생존 뮤턴트를 수동 검토 |
| 점수 자체가 목표가 되는 왜곡 | 생존 뮤턴트의 의미 있는 케이스 보강 중심 |

## Ⅵ. 제언

핵심 모듈에 뮤테이션 테스트를 적용해 생존 뮤턴트를 찾고, 이를 죽이는 케이스를 추가해 검출력 보강

### 보강 순환

```text
핵심 모듈 뮤테이션 실행
    ↓
생존 뮤턴트 분석
    ↓
검출하는 테스트 케이스 추가 → 재실행
```

### 확대: 생존 뮤턴트 판정

```text
생존 뮤턴트
    ├─ 의미 있는 결함 → 케이스 추가
    └─ 동등 뮤턴트 → 제외
```

### 선택 근거: 커버리지만 사용하는 방식과의 비교

| 구분 | 커버리지만 | 제언: 뮤테이션 점수 병행 |
|---|---|---|
| 검증 강도 | 확인 불가 | 검출력 측정 |
| 보강 대상 | 미실행 코드 | 생존 뮤턴트 |
| 비용 | 낮음 | 높음(범위 제한) |
