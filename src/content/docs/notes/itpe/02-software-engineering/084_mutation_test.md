## 연관 키워드

- 뮤테이션 테스트; 변이 연산자; 변이 점수; 죽은 변이체; 동등 변이체; 테스트 오라클

## Ⅰ. 뮤테이션 테스트의 개요

- 핵심 요약 : 뮤테이션 테스트는 프로그램에 작은 결함을 의도적으로 주입한 변이체를 기존 테스트로 실행해 테스트 스위트가 오류를 탐지하는지 평가하는 화이트박스 테스트 기법.
- 개념 : 뮤테이션 테스트는 프로그램에 작은 결함을 의도적으로 주입한 변이체를 기존 테스트로 실행해 테스트 스위트가 오류를 탐지하는지 평가하는 화이트박스 테스트 기법.
- 배경 및 필요성 : 문장·분기 커버리지가 높아도 단언문이 약하면 잘못된 동작을 잡지 못하므로 테스트의 실질 검출력을 별도로 확인할 필요.
- 주요 목적 : 테스트의 결함 탐지력과 검증 사각지대를 확인해 신뢰할 수 있는 소프트웨어 품질을 확보.

## Ⅱ. 뮤테이션 테스트의 특징 및 장점

- 핵심 요약 : 핵심 요소: 변이 연산자·변이체 실행·변이 점수·동등·생존 변이 분석. 설계목표는 테스트의 결함 탐지력과 검증 사각지대를 확인해 신뢰할 수 있는 소프트웨어 품질을 확보.

1. 변이 연산자 : 비교연산자·산술연산자·조건 경계를 변경 → 결함 유형별 검출 여부 확인.
2. 변이체 실행 : 원본과 변이 프로그램에 동일 테스트 적용 → 테스트가 실패시키면 변이체를 죽인 것으로 판정.
3. 변이 점수 : 죽은 변이체 수를 실행 가능한 비동등 변이체 수와 비교 → 테스트 강도를 정량적으로 확인.
4. 동등·생존 변이 분석 : 결과가 원본과 같은 변이 또는 테스트를 통과한 변이를 구분 → 불필요한 수동조사와 실제 누락을 분리.

## Ⅲ. 뮤테이션 테스트의 구조 (흐름)

- 핵심 요약 : 대상 코드·테스트 선정 → 변이 연산자 적용 → 변이체 생성·컴파일 → 테스트 실행 → 생존·동등 변이 분석 → 테스트 보강.

```text
대상 코드·테스트 선정
   ↓
변이 연산자 적용
   ↓
변이체 생성·컴파일
   ↓
테스트 실행
   ↓
생존·동등 변이 분석
   ↓
테스트 보강
```

```text
원본 프로그램과 테스트 스위트
   ↓
변이체 생성
   ↓
테스트 실행
   ↓
실패: 죽은 변이체 / 통과: 생존 변이체
   ↓
동등성 판별·테스트 보강
```

## Ⅳ. 뮤테이션 테스트의 비교

- 핵심 요약 : 코드 커버리지: 실행된 문장·분기 비율; 뮤테이션 테스트: 인위적 결함을 테스트가 탐지하는지 측정.

| 비교 대상 | 핵심 특성 | 적용·판단 기준 |
| --- | --- | --- |
| 코드 커버리지 | 실행된 문장·분기 비율 | 테스트가 실행한 구조적 범위 확인 |
| 뮤테이션 테스트 | 인위적 결함을 테스트가 탐지하는지 측정 | 단언·오라클의 검출력 평가 |
| 퍼징 | 다양한 입력을 생성해 예외·충돌 탐색 | 입력공간·파서·경계조건 결함 발견 |

## Ⅴ. 뮤테이션 테스트의 한계와 방안

- 핵심 요약 : 위험 초점: 변이체 수·실행시간 과다·동등 변이·환경오류·점수 목표의 악용. 권고 대응은 통제·책임을 명확히 해 테스트의 결함 탐지력과 검증 사각지대를 확인해 신뢰할 수 있는 소프트웨어 품질을 확보.

| 위험 | 원인·영향 | 대응통제 | 지표 예시 |
| --- | --- | --- | --- |
| 변이체 수·실행시간 과다 | 대형 코드베이스에서 실행비용과 피드백 지연 | 변경영역·위험도 기반 선별, 증분 실행·병렬화 | 실행시간, 테스트당 변이체 수 |
| 동등 변이·환경오류 | 불필요한 생존 변이로 점수 왜곡 | 동등 변이 검토·비결정 테스트 안정화·컴파일 실패 분류 | 동등 변이 비율, 불안정 테스트율 |
| 점수 목표의 악용 | 점수만 높이고 실제 요구·결함 검증 소홀 | 위험기반 해석, 기능·회귀·통합검증과 함께 사용 | 변이 점수와 실제 결함 유출 비교 |

## Ⅵ. 뮤테이션 테스트 적용에 대한 기술사적 제언

- 핵심 요약 : 적용 원칙: 테스트의 결함 탐지력과 검증 사각지대를 확인해 신뢰할 수 있는 소프트웨어 품질을 확보.
- 실행 제언 : 개발팀은 변경위험이 큰 핵심 로직부터 변이 테스트를 적용하고, 변이 점수를 배포 통과율로 단독 사용하지 말고 생존 변이의 원인과 수정된 테스트의 요구 추적성을 검토.

## Ⅶ. 결론

- 핵심 요약 : 뮤테이션 테스트는 프로그램에 작은 결함을 의도적으로 주입한 변이체를 기존 테스트로 실행해 테스트 스위트가 오류를 탐지하는지 평가하는 화이트박스 테스트 기법.
- 시사점 : 뮤테이션 테스트는 코드 실행 여부를 넘어 테스트가 결함을 실제로 드러내는지 확인하는 테스트 품질 평가수단.
