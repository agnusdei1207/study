## 지식 로드맵 내 현재 위치

<div class="itpe-topic-path" aria-label="소프트웨어 테스트에서 블랙박스 테스트까지의 지식 경로"><span>SW 공학</span><span>명세 기반 테스트</span><strong>블랙박스 테스트</strong></div>

## 큰 그림과 30초 인출

```text
[요구·명세] → [입력 도메인 분할] → [대표값·경계값] → [Black Box] → 실제/기대 비교
기법: 동등 분할 · 경계값 · 결정테이블 · 상태전이 · 유스케이스
```

## 예상문제

> 블랙박스 테스트의 개념과 절차·기법을 설명하고, 동등 분할과 경계값 분석으로 테스트 케이스를 설계한 후 화이트박스 테스트와 비교하시오.

## Ⅰ. 개요 ───── 명세 기반 입출력 검증

블랙박스 테스트는 내부 코드 구조와 독립적으로 요구사항·명세에 따라 입력과 출력의 관계를 검증하는 동적 테스트다. 제한된 케이스로 입력 도메인의 결함을 효과적으로 찾는 것이 목적이다.

## Ⅱ. 특징 ───── 사용자 관점과 대표성

| 특징 | 내용 | 한계 |
|---|---|---|
| 명세 기반 | 요구·업무규칙으로 기대값 도출 | 명세 누락은 탐지 곤란 |
| 구현 독립 | 언어·분기 구조에 비의존 | 내부 경로 커버리지 불명 |
| 대표값 선택 | 유사 동작 구간을 분할 | 잘못된 분할 시 누락 |
| 정·오류 입력 | 유효·무효 영역 모두 시험 | 조합 폭증 가능 |

## Ⅲ. 구조 ───── 입력 모델과 오라클

```text
[Test Basis] → [Partition/Boundary Model] → [Test Data]
                                             │
                                             ▼
Expected Result ← [Test Oracle]     [SUT] → Actual Result
                         └──────── Compare ────────┘
```

## Ⅳ. 절차 ───── 분할 후 경계 강화

```text
① 테스트 기준·변수 식별 → ② 유효/무효 동등 클래스 분할
 → ③ 각 클래스 대표값 선택 → ④ 경계 직전·경계·직후 선택
 → ⑤ 기대결과 작성 → ⑥ 실행·판정 → ⑦ 결함·추적성 기록
```

점수 0~100, 90 이상 A라는 명세 예시는 다음처럼 설계한다.

| 목적 | 입력 예 | 기대 |
|---|---:|---|
| 무효 하한 | -1 | ERROR |
| 유효 하한 | 0 | F |
| 등급 경계 | 59, 60, 69, 70, 79, 80, 89, 90 | F/D/D/C/C/B/B/A |
| 유효 상한·초과 | 100, 101 | A, ERROR |

## Ⅴ. 비교 ───── 블랙박스·화이트박스

| 기준 | 블랙박스 | 화이트박스 |
|---|---|---|
| 기준 | 요구·명세 | 코드·제어 흐름 |
| 관심 | 기능·업무규칙 | 문장·분기·경로 |
| 대표 기법 | 동등분할·경계값·결정표 | 문장·분기·조건 커버리지 |
| 상호관계 | 누락 요구·입출력 오류 탐지 | 숨은 분기·죽은 코드 탐지 |

## Ⅵ. 고려 ───── 누락·조합·오라클 통제

| 문제 | 대응 | 검증 |
|---|---|---|
| 명세 모호·누락 | 예시·결정표·리뷰로 구체화 | 요구-케이스 추적률 |
| 조합 폭증 | Pairwise·위험 기반 우선화 | 위험 커버리지 |
| 경계 누락 | 도메인별 경계 체크리스트 | 경계 케이스 수 |
| 오라클 부재 | 속성·메타모픽 관계 활용 | 판정 재현성 |
| Flaky 환경 | 데이터·시간·외부 의존 격리 | 반복 안정성 |

## Ⅶ. 결론 ───── 분할 근거와 추적성이 품질

블랙박스 테스트의 핵심은 케이스 수가 아니라 명세에서 입력 클래스를 분할한 근거다. 동등 분할로 대표성을 확보하고 경계값으로 전이 지점을 강화하며 화이트박스 기법과 상호 보완해야 한다.

## 1교시 10점 발췌

```text
블랙박스 테스트 = 내부 코드와 독립적으로 명세의 입력-출력을 검증
명세→동등 클래스→대표값/경계값→실행→오라클 비교
기법: 동등분할·경계값·결정테이블·상태전이·유스케이스
```
