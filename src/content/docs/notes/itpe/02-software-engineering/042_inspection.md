## 연관 키워드
- 인스펙션, Fagan, 정적 검토, 사회자, 기록자

### Ⅰ. 인스펙션의 개요

- 핵심 요약 : 인스펙션은 산출물을 실행하지 않고 정해진 역할·절차로 결함을 찾아 기록하는 공식 정적 검토 기법.
- 개념 : 산출물을 실행하지 않고 정해진 역할·절차로 결함을 찾아 기록하는 공식 정적 검토 기법(**인스펙션**, Inspection).
- 배경 및 필요성 : 개발 초기에 요구·설계·코드 결함을 발견하면 후속 수정·장애 비용 감소.
- 주요 목적 : 산출물 품질과 공통 이해 향상 및 결함 조기 제거.

### Ⅱ. 인스펙션의 특징 및 장점

- 핵심 요약 : Fagan 인스펙션 역할(저자·사회자·리더·기록자·검토자), 계획·개요·준비·검토회의·재작업·후속조치.

1. 정식 절차 : 계획·개요·준비·검토회의·재작업·후속조치 → 결함의 체계적 제거.
2. 역할 분담 : 저자·사회자·리더·기록자·검토자 → 중립적 검토와 결함 기록.
3. 적용 원칙 : 품질책임자는 검토자를 교육하고 작은 검토단위·중립 사회자·재작업 완료 확인을 운영절차에 정착.

### Ⅲ. 인스펙션의 구조 (흐름)

- 핵심 요약 : 검토대상·기준 선정 → 개별 사전준비 → 결함기록 회의 → 저자 재작업 → 사회자 후속확인.

```text
검토대상·기준 선정
  ↓
개별 사전준비
  ↓
결함기록 회의
  ↓
저자 재작업
  ↓
사회자 후속확인
```

```text
계획·개요 → 준비 → 검토회의·기록 → 재작업 → 후속확인
```

### Ⅳ. 워크스루와 인스펙션 비교

- 핵심 요약 : 워크스루는 저자가 설명하고 참석자와 비공식 검토, 인스펙션은 역할·기준·결함기록을 갖춘 정형 검토.

| 비교 축 | 워크스루 | 인스펙션 |
|---|---|---|
| 형식·진행 | 저자가 설명하고 참석자와 비공식 검토 | 역할·기준·결함기록을 갖춘 정형 검토 |
| 기록 | 비공식 검토 의견 | 결함기록 및 재작업 확인 |

### Ⅴ. 인스펙션의 한계와 방안

- 핵심 요약 : 요식화·인신공격·심리위축·검토범위 과다를 체크리스트·exit criteria·작은 단위 검토로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 요식화 | 읽기만 하고 결함·조치 기록 없음 | 검토 체크리스트·exit criteria·후속확인 | 조치 미완료율 |
| 인신공격·심리위축 | 결함을 사람의 평가로 취급 | 산출물·사실 중심 규칙, 사회자 중재 | 발언 편중·참여도 |
| 검토범위 과다 | 과도한 문서량·시간으로 집중 저하 | 작은 단위·위험기반 표본·시간 제한 | 시간당 결함 발견 |

### Ⅵ. 인스펙션에 대한 제언

- 핵심 요약 : 품질책임자는 검토자를 교육하고 작은 검토단위·중립 사회자·재작업 완료 확인을 운영절차에 정착.

1. 품질책임자는 검토자를 교육하고 작은 검토단위·중립 사회자·재작업 완료 확인을 운영절차에 정착.
2. 조치 미완료율·발언 편중·참여도·시간당 결함 발견를 정기 측정하고 편차에 대한 원인분석·개선결과를 기록.

### Ⅶ. 결론

- 핵심 요약 : 인스펙션은 산출물을 실행하지 않고 정해진 역할·절차로 결함을 찾아 기록하는 공식 정적 검토 기법.
- 시사점 : 인스펙션은 실행 전 산출물 결함을 체계적으로 찾는 정적 검증이며 테스트를 대체하지 않음.
