## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 운영·관측 → **OpenTelemetry(관측성 표준)**

## 30초 인출

- 본질: OpenTelemetry는 트레이스·메트릭·로그를 벤더에 종속되지 않는 공통 규격으로 수집해 전송하는 관측성 오픈소스 표준
- 메커니즘: 애플리케이션이 SDK로 텔레메트리를 생성하고 OTLP로 컬렉터에 보내면 컬렉터가 가공해 원하는 백엔드로 내보내며 컨텍스트 전파로 서비스 간 호출을 하나의 트레이스로 연결
- 통찰: 도구마다 다른 수집 방식은 교체 때 계측 코드를 다시 써야 하므로 공통 규격으로 계측하고 컬렉터에서 샘플링과 민감정보 마스킹을 일괄 처리

<details>
<summary>핵심 용어</summary>

- **관측성(Observability)** : 시스템의 외부 출력(로그·메트릭·트레이스)으로 내부 상태를 추론할 수 있는 정도
- **트레이스(Trace)와 스팬(Span)** : 요청의 전체 경로와 그 안의 개별 작업 단위
- **메트릭(Metric)** : 시간에 따라 수집되는 수치 지표
- **OTLP(OpenTelemetry Protocol)** : 텔레메트리를 전송하는 OpenTelemetry의 표준 프로토콜
- **컬렉터(Collector)** : 텔레메트리를 수신·가공해 백엔드로 내보내는 중간 구성요소
- **컨텍스트 전파(Context Propagation)** : 서비스 호출 사이에 트레이스 식별 정보를 전달하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. OpenTelemetry의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **OpenTelemetry** 는 트레이스·메트릭·로그를 공통 규격으로 수집·전송하는 관측성 오픈소스 표준 |
| 목적 | 관측 도구 종속 제거와 분산 시스템의 일관된 관측 |

## Ⅱ. 도구별 개별 계측과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 벤더 중립 | 백엔드 교체 시 계측 코드 유지 |
| 세 신호 통합 | 트레이스·메트릭·로그 공통 처리 |
| 표준 프로토콜 | OTLP로 전송 |

## Ⅲ. OpenTelemetry의 구성과 데이터 흐름

### 구성과 흐름

```text
애플리케이션(SDK로 계측)
    ↓ OTLP
컬렉터 ── 수신 → 가공(샘플링·마스킹) → 내보내기
    ↓
백엔드 (트레이스·메트릭·로그 저장·시각화)
```

### 확대: 컨텍스트 전파와 트레이스

```text
서비스A ── 트레이스 ID를 헤더에 담아 호출 → 서비스B ── → 서비스C
(각 서비스의 스팬이 같은 트레이스 ID로 연결되어 하나의 요청 경로로 조회)
```

## Ⅳ. 세 가지 신호와 도구 방식의 비교

### 세 가지 신호

| 신호 | 내용 | 용도 |
|---|---|---|
| 트레이스 | 요청의 경로와 구간별 시간 | 지연 구간 식별 |
| 메트릭 | 수치 지표 | 상태 감시·경보 |
| 로그 | 이벤트 기록 | 원인 상세 분석 |

### 개별 도구와의 비교

| 구분 | 도구별 개별 계측 | OpenTelemetry |
|---|---|---|
| 계측 코드 | 도구마다 다름 | 공통 |
| 도구 교체 | 계측 재작성 | 내보내기 설정 변경 |
| 신호 상관 | 곤란 | 트레이스 ID로 연결 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모든 요청 수집으로 데이터량 폭증 | 컬렉터에서 샘플링 |
| 로그·트레이스에 민감정보 포함 | 컬렉터에서 마스킹 |
| 서비스 간 컨텍스트 전파 누락으로 트레이스 단절 | 공통 라이브러리와 게이트웨이의 헤더 전달 규칙 |

## Ⅵ. 제언

공통 규격으로 계측하고, 샘플링과 민감정보 마스킹은 컬렉터에서 일괄 처리

### 수집 정책 중앙화

```text
서비스 → OTLP → 컬렉터(샘플링·마스킹) → 백엔드
```

### 선택 근거: 서비스별 처리와의 비교

| 구분 | 서비스별 처리 | 제언: 컬렉터 일괄 처리 |
|---|---|---|
| 정책 일관성 | 서비스마다 상이 | 중앙 |
| 민감정보 | 누락 위험 | 일괄 마스킹 |
| 수집 비용 | 통제 곤란 | 샘플링으로 통제 |
