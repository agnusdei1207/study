## 연관 키워드

- 기능 안전, IEC 61508, 안전 생명 주기, SIL, ASIL, HARA, 안전 상태, ISO 26262

## Ⅰ. 기능 안전의 개요

- 핵심 요약 : 기능 안전은 시스템 고장이 위해로 이어지지 않도록 위험을 분석하고 안전 기능의 요구·설계·검증을 생명 주기 전반에 관리하는 체계.
- 개념 : 전체 안전 중에서 전기·전자·프로그래머블 전자 시스템의 올바른 기능 수행 또는 고장 시 위험 없는 상태로의 전환에 의존하는 부분인 **기능 안전** (Functional Safety).
- 배경 및 필요성 : 플랜트·차량·의료기기의 제어 고장이 인명·환경 피해로 직결되어, 고장 발생 후 대응 관행만으로는 위해 예방 불가.
- 주요 목적 : 허용 불가능한 위험의 식별과 안전 요구사항·검증 증거에 의한 위험 감소, 허용 가능한 수준까지의 잔여 위험 관리.

## Ⅱ. 기능 안전의 특징 및 장점

- 핵심 요약 : 위험 기반 등급 할당과 생명 주기 추적이 위해 감소와 객관적 안전 근거 확보로 연결.

1. 위험 기반 접근 : 피해 심각도·노출 빈도·회피 가능성으로 위험 평가 → 위험도에 비례한 설계·검증 강도 배분.
2. 안전 무결성 등급 : **SIL** (Safety Integrity Level)로 안전 기능 수행의 신뢰 등급을 1~4로 차등 → 과소·과잉 설계 방지.
3. 생명 주기 관리 : **안전 생명 주기** (Safety Lifecycle)의 단계별 활동·산출물 정의 → 요구→검증→운영의 추적성 확보.
4. 표준군 구조 : **IEC 61508** (전기·전자·프로그래머블 전자 안전 관련 시스템의 기능 안전 모표준)에서 차량용 **ISO 26262**·프로세스 산업 IEC 61511 등 분야 표준 파생 → 산업별 적용 기준 확보.

## Ⅲ. 기능 안전의 구조 (흐름)

- 핵심 요약 : 위험 분석에서 안전 목표와 등급을 도출하고 요구·구현·검증을 거쳐 잔여 위험 판정으로 연결.

```text
시스템 정의·위험 분석(HARA)
   ↓ 안전 목표 도출
안전 요구사항·등급 할당
   ↓ 설계·구현
검증·통합 - 독립 평가
   ↓
잔여 위험 판정 - 안전 확인
   ↓
운영·유지보수 - 변경 통제
```

```text
위험 요소 식별
   ↓ 심각도·노출·회피 평가
위험도 분류 - SIL·ASIL 결정
   ↓ 등급에 맞는 안전 기능 설계
위험 감소 - 안전 상태 전환 보장
```

- 차량 분야의 **HARA** (Hazard Analysis and Risk Assessment)는 위험 상황을 심각도·노출·제어 가능성으로 평가해 **ASIL** (Automotive Safety Integrity Level)을 결정.
- **안전 상태** (Safe State)는 위험이 존재하지 않는 시스템 상태로, 고장 감지 시 안전 기능이 이 상태로의 전환 또는 위해 방지 동작을 보장.
- 결함(fault)·오류(error)·고장(failure)의 전파 구간별로 예방·탐지·내성 대응을 배치.

## Ⅳ. 기능 안전과 일반 품질 관리의 비교

- 핵심 요약 : 일반 품질 관리가 고장의 발견·수정 중심인 반면, 기능 안전은 고장 발생 전의 위해 방지와 증거 확보가 목적.

| 비교 축 | 기능 안전 | 일반 품질 관리 |
| --- | --- | --- |
| 보호 대상 | 사람·환경·자산의 위해 방지 | 고객 요구 충족·결함 감소 |
| 고장 관점 | 고장 예측·안전 상태 전환 보장 | 고장 발견·수정 중심 |
| 엄격성 기준 | 위험도 기반 SIL·ASIL 차등 | 균일한 품질 기준 적용 |
| 검증 방식 | 독립 평가·안전 사례 증거 | 시험·검토 중심 |
| 실패의 결과 | 인명·환경 사고와 법적 책임 | 불만·비용·신뢰 하락 |

- 고장이 없어도 의도된 기능의 성능 한계·오용으로 인한 위해는 SOTIF(Safety Of The Intended Functionality, ISO 21448) 영역으로, 기능 안전과 보완 관계.

## Ⅴ. 기능 안전의 한계와 방안

- 핵심 요약 : 위험 시나리오 누락·추적성 단절·공통 원인 고장·변경 훼손을 독립 검토와 추적성으로 통제 필요.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 위험 시나리오 누락 | 운용 조건·조합의 복잡성 | 다학제 HARA·현장 데이터 재평가 | 미식별 위험 건수 |
| 추적성 단절 | 요구·설계·검증의 분리 관리 | 안전 요구-설계-시험 양방향 추적 | 미추적 요구 비율 |
| 공통 원인 고장 | 이중화 구성의 동일 결함 | 다양성 설계·독립성 분석 | 공통 원인 결함 비율 |
| 변경 후 무결성 훼손 | 현장 업데이트·부품 교체 | 변경 영향 분석·재검증 의무화 | 변경 후 재검증 수행률 |

## Ⅵ. 기능 안전에 대한 기술사적 제언

- 핵심 요약 : 안전 거버넌스로 안전 책임·독립 평가·잔여 위험 수용 권한을 제도화하고 공급망 전반으로 확산 필요.
- 조직은 안전 책임자에게 생명 주기 산출물 승인과 잔여 위험 수용 권한·책임을 명시하고, 사고·근접 사고 정보를 재평가 절차에 반영.
- 발주·협력사 계약에 적용 표준·등급·증거 인도 범위를 명시하고, AI 기반 기능의 검증 한계는 시뮬레이션·현장 데이터·상시 감시 설계로 보완.

## Ⅶ. 결론

- 핵심 요약 : 기능 안전은 위험 분석에서 운영까지의 안전 생명 주기 관리로 고장에 의한 위해를 줄이는 표준 기반 체계.
- 표준 준수 증거와 운용 조건의 현실성이 함께 확보될 때 안전성 주장의 신뢰가 성립.
