```text

   ▲                                                │
   └──────── [상태기록·감사·릴리스] ◀───────────────┘
```

## 예상문제

> 소프트웨어 형상관리의 정의·절차, 기준선의 유형과 변경 통제를 설명하고 형상관리 도구 및 현대 개발환경의 적용 방안을 제시하시오.

## Ⅰ. 개요 ───── 산출물 무결성과 재현성 통제

소프트웨어 형상관리는 생명주기 산출물을 식별하고 기준선을 설정한 뒤 변경을 평가·승인·기록·감사하여 제품의 무결성, 추적성과 재현성을 유지하는 관리 활동이다.

## Ⅱ. 특징 ───── 식별·통제·기록·감사

| 활동 | 핵심 내용 | 산출물 |
|---|---|---|
| 형상 식별 | CI와 버전·관계 정의 | 형상항목 목록 |
| 형상 통제 | 변경 요청 영향평가·승인 | CR·승인 기록 |
| 상태 기록 | 버전·변경·빌드 상태 보고 | 상태 보고서 |
| 형상 감사 | 기능·물리 일치 확인 | FCA·PCA 결과 |
| 릴리스 관리 | 승인 구성으로 빌드·배포 | Release·Manifest |

## Ⅲ. 구조 ───── 저장소·변경통제·자동화

```text
Requirement/Code/Test/Doc/IaC
            │
      [Version Repository] ← Branch·Tag·Baseline
            │
CR → [Issue/CCB·Approval] → PR/Review → CI Build/Test/Scan
            │                              │
            └──── Status Accounting ← Artifact Registry
                                      └→ Audit·Release
```

베이스라인은 공식 검토·합의되어 이후 변경이 통제 절차를 거쳐야 하는 형상항목의 기준 상태다.

## Ⅳ. 절차 ───── 기준선 수립과 변경 폐루프

```text
① CI 식별·명명 → ② 저장소 등록·버전 부여
 → ③ 검토 후 기준선 확정
 → ④ 변경요청·영향분석
 → ⑤ 승인/기각 → ⑥ 구현·시험·리뷰
 → ⑦ 상태기록·감사 → ⑧ 새 기준선·릴리스
```

| 기준선 예 | 시점 | 대상 |
|---|---|---|
| 기능 기준선 | 요구 검토 후 | 승인 요구사항 |
| 할당 기준선 | 아키텍처 할당 후 | 구성요소별 요구·설계 |
| 제품 기준선 | 검증·인수 후 | 배포 가능한 제품 구성 |

## Ⅴ. 비교 ───── 버전관리·형상관리·변경관리

| 기준 | 버전관리 | 형상관리 | 변경관리 |
|---|---|---|---|
| 중심 | 파일 이력·병합 | 제품 구성 무결성 | 변경의 업무 의사결정 |
| 대상 | 코드·문서 | 요구·코드·시험·환경·산출물 | 범위·일정·비용·위험 |
| 통제 | Commit·Branch·Tag | CI·Baseline·Audit·Release | 요청·영향·승인 |
| 관계 | 형상관리의 도구 | 기술 산출물 통합 통제 | 상위 변경 승인과 연계 |

## Ⅵ. 고려 ───── 속도와 통제의 균형

| 문제 | 원인 | 대응 | 검증 |
|---|---|---|---|
| 승인 병목 | 모든 변경 동일 절차 | 위험 기반 정책·자동 승인 | 처리시간·예외율 |
| 환경 불일치 | 코드만 버전관리 | IaC·설정·DB Migration 포함 | 재현 빌드 |
| 공급망 변조 | 출처·의존성 불명 | 서명·SBOM·Provenance | 무결성 검증 |
| 기준선 유명무실 | Tag와 승인 증적 분리 | 보호 Tag·PR·CI 증적 연결 | 추적 완결률 |
| 긴급변경 누락 | 우회 배포 | 사후 검토·자동 기록·권한 회수 | 긴급변경 감사 |

## Ⅶ. 결론 ───── Git을 넘어 제품 상태를 증명

현대 형상관리는 소스 버전관리만이 아니라 요구·코드·시험·환경·아티팩트의 관계를 재현 가능하게 증명하는 통제다. 위험 기반 승인과 자동화된 증적을 결합해 속도와 무결성을 함께 확보해야 한다.

## 1교시 10점 발췌

```text
형상관리 = CI 식별→기준선→변경통제→상태기록→감사→릴리스

도구: VCS·Issue/PR·CI·Artifact Registry·IaC·서명/SBOM
```
