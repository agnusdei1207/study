## 30초 인출

- 본질: 탐욕 알고리즘은 각 단계에서 그 순간 가장 좋아 보이는 선택을 하고 되돌리지 않는 방식으로 해를 구하는 알고리즘
- 메커니즘: 선택 기준에 따라 후보를 고르고 남은 문제에 같은 방식을 반복하며, 탐욕적 선택 속성과 최적 부분 구조가 성립하면 최적해 보장
- 통찰: 탐욕적 선택이 항상 최적이 되지는 않으므로 문제가 탐욕적 선택 속성을 가지는지 증명하거나 반례를 확인하고 성립하지 않으면 동적 계획법을 사용

<details>
<summary>핵심 용어</summary>

- **탐욕 알고리즘(Greedy Algorithm)** : 매 단계에서 지역적으로 최선인 선택을 반복해 해를 구하는 알고리즘
- **탐욕적 선택 속성** : 지역 최선의 선택이 전체 최적해에 포함될 수 있는 성질
- **최적 부분 구조** : 전체 최적해가 부분 문제의 최적해로 구성되는 성질
- **활동 선택 문제** : 겹치지 않게 최대한 많은 활동을 고르는 문제. 종료 시간이 빠른 순으로 선택
- **허프만 코딩** : 빈도가 높은 문자에 짧은 부호를 배정하는 압축 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 탐욕 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **탐욕 알고리즘** 은 각 단계에서 지역적으로 최선인 선택을 반복해 해를 구하는 알고리즘 |
| 목적 | 단순하고 빠른 방식으로 최적해 도출 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 지역 최적 선택 | 현재 가장 좋은 선택 |
| 되돌리지 않음 | 한 번 한 선택은 유지 |
| 조건부 최적성 | 문제 성질이 성립할 때 최적 |

## Ⅲ. 동작 예: 활동 선택

```text
활동  시간          종료가 빠른 순 선택
 A   1─3    ✔ 선택
 B   2─5    ✘ (A와 겹침)
 C   4─6    ✔ 선택
 D   5─9    ✘ (C와 겹침)
 E   6─8    ✔ 선택      → 최대 3개 활동
```

## Ⅳ. 탐욕과 다른 기법의 비교

| 구분 | 탐욕 | 동적 계획법 | 완전 탐색 |
|---|---|---|---|
| 선택 | 지역 최선 하나 | 모든 부분 문제 해 활용 | 모든 경우 |
| 최적 보장 | 성질 성립 시 | 최적 부분 구조 시 | 항상 |
| 속도 | 빠름 | 중간 | 느림 |

| 탐욕으로 최적을 얻는 문제 | 탐욕이 실패하는 예 |
|---|---|
| 활동 선택, 허프만 코딩, 최소 신장 트리 | 0/1 배낭 문제, 임의 동전 단위의 거스름돈 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 탐욕적 선택이 최적이 아닌 문제 | 탐욕적 선택 속성 증명 또는 반례 확인 |
| 성립하지 않는 문제에 적용 | 동적 계획법 사용 |
| 정렬 기준 오설정 | 문제별 선택 기준 검증 |

## Ⅵ. 제언

탐욕을 적용하기 전에 탐욕적 선택 속성이 성립하는지 확인하고, 성립하지 않으면 동적 계획법 선택

```text
탐욕적 선택 속성 성립?
    ├─ 예 → 탐욕 알고리즘
    └─ 아니오 → 동적 계획법
```

| 구분 | 무조건 탐욕 | 제언: 성질 확인 |
|---|---|---|
| 정확성 | 오답 위험 | 보장 |
| 속도 | 빠름 | 성립 시 빠름 |
