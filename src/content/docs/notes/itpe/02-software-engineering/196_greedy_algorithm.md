## 연관 키워드

- 탐욕 알고리즘, 탐욕적 선택 속성, 최적 부분 구조, 교환 논법, 동적 계획법

## Ⅰ. 탐욕 알고리즘의 개요

- 핵심 요약 : 탐욕 알고리즘은 매 단계에서 현재 가장 유리한 선택을 확정해 해를 구성하는 최적화 기법.
- 개념 : **탐욕 알고리즘**(Greedy Algorithm)은 지역 최선 선택을 누적해 전체 해를 만드는 알고리즘 설계 방법.
- 배경 및 필요성 : 모든 조합을 탐색하지 않고 정렬·선택을 반복해 계산량을 줄일 수 있는 최적화 문제에 적용.
- 주요 목적 : 정확성 조건이 성립하는 문제에서 효율적으로 최적해 산출.

## Ⅱ. 탐욕 알고리즘의 특징 및 장점

- 핵심 요약 : 탐욕적 선택 속성과 최적 부분 구조가 증명되면 국소 선택으로 전역 최적해를 보장.

1. 즉시 확정 : 이전 선택을 되돌리지 않음 → 구현과 메모리 사용이 단순.
2. 탐욕적 선택 속성 : 최적해에 현재의 최선 선택을 포함하는 근거 존재 → 조합 탐색 생략.
3. 최적 부분 구조 : 선택 후 남은 하위 문제가 같은 최적화 성질 보유 → 부분 해의 재사용.

## Ⅲ. 탐욕 알고리즘의 구조 (흐름)

- 핵심 요약 : 후보·선택 기준 정의 → 후보 평가·최선 선택 → 제약 검사·확정 → 종료 조건까지 반복 → 정당성 증명.

```text
후보 집합·목적함수 정의
  ↓
현재 최선 후보 선택
  ↓
제약·실행가능성 확인
  ↓
선택을 해에 확정
  ↓
종료조건 검사 후 반복
```

- 정당성 검증 : 교환 논법 또는 컷 속성으로 탐욕 선택을 최적해의 선택으로 바꿔도 비용이 악화되지 않음을 증명.

```text
탐욕 선택 g + 잔여 문제
        ↓ 정당성 증명
최적 부분 문제의 해와 결합
        ↓
전역 최적해
```

## Ⅳ. 탐욕 알고리즘과 동적 계획법의 비교

- 핵심 요약 : 탐욕은 선택을 확정하고, 동적 계획법은 상태별 부분 최적값을 보존해 비교하므로 정당성 조건에 따라 선택.

| 비교 기준 | 탐욕 알고리즘 | 동적 계획법 |
| --- | --- | --- |
| 의사결정 | 현재 최선 선택을 확정 | 여러 상태·선택의 부분해를 계산 |
| 최적성 근거 | 탐욕적 선택 속성·교환 논법 | 최적 부분 구조·점화식 |
| 계산·메모리 | 보통 단순하고 적은 메모리 | 상태 수·전이 수에 비례하는 계산·저장 |

## Ⅴ. 탐욕 알고리즘의 한계와 방안

- 핵심 요약 : 지역 최선이 전역 최선이라는 보장이 없으므로 적용 전 반례 탐색과 최적성 증명이 필수.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 지역 최적 함정 | 선택 취소가 없어 더 나은 조합을 놓침 | 작은 입력 전수비교·반례 탐색 후 증명 | 최적해 대비 격차 |
| 제약 상호작용 | 당장 유리한 선택이 잔여 실행가능성을 제거 | feasibility 조건을 명시하고 선택 전 검사 | 제약 위반 건수 |
| 근사해 오인 | 근사 알고리즘을 정확 최적해로 해석 | 근사비·오차 상한과 전제조건 문서화 | 최적성 격차·보증 위반 |

## Ⅵ. 탐욕 알고리즘의 제언

- 핵심 요약 : 알고리즘 설계자는 문제의 교환 구조와 실행가능성 불변식을 증명하고, 증명이 어려우면 DP·분기한정과 비교.

1. 문제 담당자는 목적함수·제약·동률 규칙을 수식으로 명시.
2. 개발자는 교환 논법·컷 속성·귀납법 중 적절한 증명을 코드와 함께 보존.
3. 검증자는 작은 입력의 전수탐색 기준해와 대조하고 대규모 입력 성능을 측정.

## Ⅶ. 탐욕 알고리즘의 결론

- 핵심 요약 : 탐욕 기법은 매 단계의 선택을 확정해 효율을 얻는 대신 최적성의 증명을 요구.
- 시사점 : 선택 규칙이 단순하다는 이유만으로 적용하지 말고 문제 구조와 최적화 보장을 먼저 확인.
