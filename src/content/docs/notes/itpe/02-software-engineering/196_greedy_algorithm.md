## 30초 인출

- **본질**: 탐욕 알고리즘은 매 단계에서 현재 가능한 선택 중 최선이라고 정한 것을 택해 해를 구성하는 알고리즘 설계 기법
- **메커니즘**: 후보 선택 → 제약 확인 → 선택 확정 → 종료 조건까지 반복

<details>
<summary>핵심 용어</summary>

- **탐욕 알고리즘(Greedy Algorithm)**: 각 단계의 국소적 선택을 누적해 해를 구성하는 알고리즘
- **탐욕 선택 속성(Greedy-choice Property)**: 최적해를 국소적으로 선택한 뒤에도 구성할 수 있는 문제의 성질
- **최적 부분 구조(Optimal Substructure)**: 문제의 최적해가 부분 문제의 최적해로 구성되는 성질
- **분할 상환 배낭(Fractional Knapsack)**: 물건을 나눠 담을 수 있어 단위 무게당 가치 순 선택이 최적이 되는 배낭 문제

</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **탐욕 알고리즘**: 각 단계의 국소적 최선 선택을 누적해 해를 구성하는 설계 기법 |
| 목적 | 선택 과정을 단순화해 문제의 해를 효율적으로 구성 |

### Ⅱ. 수행 과정

```text
후보 집합
    ↓ 현재 기준의 최선 후보 선택
제약 충족 여부
  ├─ 충족 → 선택 확정 → 해가 완성될 때까지 반복
  └─ 위반 → 후보 제외 → 다음 후보 검토
```

### Ⅲ. 적용 조건과 주의점

국소 선택을 확정해도 전역 최적해를 얻는다는 근거가 필요. 탐욕 선택 속성과 최적 부분 구조를 문제별로 증명하며, 두 용어를 단순 체크리스트처럼 적용하지 않음.

| 사례 | 판단 |
|---|---|
| 분할 상환 배낭 | 단위 무게당 가치 순 선택이 최적 |
| 0/1 배낭 | 물건을 나눌 수 없어 같은 선택법이 최적임을 보장하지 않음 |

**제언**: 구현 전에 반례를 찾고 국소 선택이 최적해로 이어진다는 근거를 먼저 제시.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **탐욕 알고리즘**: 각 단계의 국소적 최선 선택을 누적해 해를 구성하는 설계 기법 |
| 목적 | 선택 과정을 단순화해 문제의 해를 효율적으로 구성 |

## Ⅱ. 작동 구조

```text
평가 기준에 따른 후보 선택
  ├─ 제약 충족 → 선택 확정·되돌리지 않음
  │                 ↓
  │            미완성이면 반복
  └─ 제약 위반 → 다음 후보 검토
                    ↓
                 결과 해
```

탐욕법은 선택을 확정하는 시점이 핵심. 이후 선택이 앞선 선택을 다시 바꾸지 않으므로, 그 확정이 전체 최적성을 해치지 않는지 증명이 필요.

## Ⅲ. 최적성 보장 논리

| 성질·논증 | 핵심 질문 |
|---|---|
| 탐욕 선택 속성 | 첫 국소 선택을 포함하는 최적해가 존재함을 보일 수 있는가 |
| 최적 부분 구조 | 선택 후 남은 부분 문제도 같은 방식으로 최적해를 구성하는가 |
| 교환 논증 | 임의의 최적해에서 탐욕 선택으로 바꿔도 최적성이 유지되는가 |

성질의 이름만 나열하는 것으로 충분하지 않으며, 구체 문제의 선택 기준과 교환 또는 귀납 논리를 연결.

## Ⅳ. 대표 문제 적용

| 한계 | 탐욕 선택 | 유의점 |
|---|---|---|
| 활동 선택 | 종료가 빠른 활동부터 겹치지 않게 선택 | 최대 활동 수 문제에서 선택 기준의 정당화 필요 |
| 분할 상환 배낭 | 단위 무게당 가치가 큰 물건부터 선택 | 물건 분할이 허용되는 문제 |
| 최소 신장 트리 | 사이클을 만들지 않는 최소 가중치 연결 선택 | 크루스칼·프림의 최적성 근거 필요 |
| 0/1 배낭 | 단위 가치 기준만으로 최적성 보장 불가 | 동적 계획법 등 다른 접근 검토 |

## Ⅴ. 복잡도와 대안 선택

```text
문제 정의·제약 확인
  ├─ 국소 선택의 정당성 증명 가능 → 탐욕 알고리즘
  │                              └─ 복잡도 산정
  └─ 증명 불가 → 동적 계획법·완전 탐색 등 비교
```

탐욕법의 효율은 정렬, 우선순위 큐, 후보 탐색 등 구현 비용에 좌우. 정확성을 증명하지 못한 근사 선택은 최적해 알고리즘과 구별해 표현.

## Ⅵ. 한계와 대응

| 한계 | 해결 방안 |
|---|---|
| 국소 최선이 전역 최선이라고 가정 | 반례 탐색 후 교환 논증·귀납법으로 최적성 검증 |
| 문제 변형에서 선택 기준이 무효화 | 분할 허용 여부, 제약·목적 함수 변경 시 다시 증명 |
| 최적해가 아닌 근사해를 최적이라고 표현 | 보장 성질과 근사 범위를 별도로 명시 |

## Ⅶ. 기술적 제언

| 구분 | 내용 |
|---|---|
| 한계 | 구현 결과만 검증하면 선택 기준의 최적성 가정이 문제 변경 후에도 유효한지 놓치기 쉬움 |
| 해결 방안 | 선택 규칙과 그 정당화 논리를 테스트 가능한 불변조건·반례 사례와 함께 설계 문서에 기록 |
