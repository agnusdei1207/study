## Ⅰ. 탐욕 알고리즘(Greedy Algorithm)의 개요

- **개념** : 최적화 문제를 해결할 때, 전체적인 미래 상황을 고려하지 않고 현재 순간에서 가장 최선이라고 판단되는 근시안적인 국소적 최적해(Local Optimum)를 단계별로 선택해 나감으로써 최종적인 전체 최적해(Global Optimum)에 도달하고자 하는 알고리즘 설계 패러다임.
- **배경 및 필요성** : 동적 계획법(DP)이나 완전 탐색(Backtracking)의 높은 시간/공간 복잡도를 극복하고, 특정 조건을 만족하는 문제에 대해 매우 단순하고 빠른 다항 시간 내에 최적해를 도출.
- **2대 필수 성립 조건** : 탐욕적 선택 속성(Greedy Choice Property), 최적 부분 구조(Optimal Substructure).

## Ⅱ. 탐욕 알고리즘의 2대 필수 조건 및 증명 메커니즘

```text
   [ 탐욕적 선택 속성 (Greedy Choice Property) ]
    앞의 선택이 이후의 선택에 영향을 주지 않으며,
    현재 단계에서 취한 최선의 선택이 전체 최적해의 일부가 됨을 증명!
                         │
                         ▼
   [ 최적 부분 구조 (Optimal Substructure) ]
    문제의 최종 최적해가 하위 부분 문제들의 최적해들로 구성될 수 있는 구조!
                         │
                         ▼
   [ 수학적 귀납법 또는 교환 논법(Exchange Argument)을 통한 최적성 증명 ]
    "탐욕적 선택을 포함하지 않는 가상의 최적해가 존재한다고 가정했을 때,
     그 선택을 탐욕적 선택으로 교체하더라도 해의 품질이 나빠지지 않음을 입증!"
```

## Ⅲ. 탐욕 알고리즘과 동적 계획법(DP)의 비교

| 비교 항목 | 탐욕 알고리즘 (Greedy) | 동적 계획법 (Dynamic Programming) |
|---|---|---|
| 선택 방식 | 현재 상태에서 가장 좋아 보이는 단 하나의 해를 즉시 선택 | 모든 가능한 부분 문제의 해를 전부 탐색하고 비교하여 선택 |
| 재고(Backtracking) | 한 번 내린 선택은 결코 번복하지 않음 | 이전의 결정을 검토하며 하위 문제의 최적해를 조합 |
| 계산 효율성 | 매우 빠름 (주로 정렬 후 $O(N)$ 또는 $O(N \log N)$) | 상대적으로 느림 (메모이제이션 테이블 갱신, 다차원 배열) |
| 최적성 보장 여부 | 2대 성립 조건이 만족되지 않으면 근사해에 불과 | 항상 완벽한 전역 최적해(Global Optimum) 보장 |
| 배낭 문제 (Knapsack) | 분할 가능 배낭 문제 (Fractional Knapsack: 무게당 가치 정렬) | 0-1 배낭 문제 (물건을 쪼갤 수 없는 경우, DP 필수) |

## Ⅳ. 탐욕 알고리즘(Greedy Algorithm)의 주요 한계점 및 해결 방안

- **지역 최적해(Local Optimum) 함정 및 전역 최적해 보장 실패** :
  - **한계점** : 매 순간 가장 좋아 보이는 선택을 하지만, 미래의 선택지를 고려하지 않아 배낭 문제(0-1 Knapsack)처럼 전체 최적해를 도출하지 못하는 치명적 한계.
  - **해결 방안** : 탐욕적 선택 속성(Greedy Choice Property)과 최적 부분 구조(Optimal Substructure)의 수학적 증명 선행, 불가능할 경우 동적 계획법(DP)으로 전환.
- **입력 데이터 정렬에 따른 초기 연산 오버헤드** :
  - **한계점** : 회의실 배정 등 대다수 탐욕 알고리즘은 초기에 간선이나 구간을 정렬해야 하므로, 정렬 자체의 $O(N \log N)$ 시간 복잡도에 병목 종속.
  - **해결 방안** : 우선순위 큐(Min-Heap/Max-Heap)를 활용하여 정렬 비용을 분산하거나 데이터 인입 시 부분 정렬 상태를 유지하는 스트리밍 알고리즘 기법 적용.
- **문제 제약조건 추가 시 알고리즘 전체 무효화(Brittle Logic)** :
  - **한계점** : 기본 문제에 사소한 제약조건(예: 가중치 제한, 비연속 선택 조건)이 하나만 추가되어도 탐욕적 규칙이 완전히 붕괴되어 재설계 불가피.
  - **해결 방안** : 엄격한 최적해 대신 합리적 오차 범위 내의 해를 허용하는 휴리스틱 근사 알고리즘(Approximation Algorithm)으로 설계하고 근사비(Approximation Ratio) 검증.

## Ⅴ. 시스템 최적화 및 휴리스틱 응용 관점의 기술사적 제언

- **탐욕 해법의 정당성 증명(Proof of Correctness) 선행** : 탐욕 알고리즘은 직관적으로 맞아 보이지만 예외 케이스에서 오작동하기 쉬우므로(예: 거스름돈 동전 단위가 배수 관계가 아닐 때 8원 = 5원+1원+1원+1원 vs 4원+4원), 반드시 교환 논법(Exchange Argument)을 통한 수학적 최적성 증명을 거친 후 알고리즘 채택 필수.
- **NP-Hard 문제에 대한 고속 근사 알고리즘(Approximation Algorithm) 활용** : 외판원 순회(TSP), 정점 커버(Vertex Cover) 등 다항 시간 내에 최적해를 구할 수 없는 복잡한 최적화 문제에 대해, 100% 최적해 대신 이론적으로 오차 한계가 증명된 탐욕적 근사 알고리즘을 적용하여 실시간 시스템의 연산 병목 돌파 권장.
