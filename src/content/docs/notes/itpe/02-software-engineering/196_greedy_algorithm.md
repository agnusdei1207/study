## 30초 인출

- 본질: 매 단계마다 미래나 과거의 상황을 고려하지 않고 현재 시점에서 가장 최적(Best)이라고 판단되는 선택을 내림으로써 전체 문제의 해를 구하는 알고리즘 설계 패러다임
- 메커니즘: 후보 집합 선택(Selection) → 실행 가능성 제약 검사(Feasibility) → 해답 적합성 검증(Solution Check) 반복 수행
- 통찰: 매 순간의 국소적 최적해가 전체 문제의 전역 최적해(Global Optimum)를 보장하지 못하므로, 탐욕적 선택 속성(Greedy Choice Property)과 최적 부분 구조(Optimal Substructure)의 수학적 증명(교환 논증 등) 선행 필수

<details>
<summary>핵심 용어</summary>

- **탐욕 알고리즘 (Greedy Algorithm)** : 전체적인 최적해를 구하기 위해 매 결정 순간마다 눈앞의 국소적 최적해(Local Optimum)를 연속적으로 선택하는 기법
- **탐욕적 선택 속성 (Greedy Choice Property)** : 이전의 선택이나 부분 문제의 해와 무관하게, 현재 단계에서의 탐욕적 선택이 항상 전역 최적해로 확장될 수 있는 성질
- **최적 부분 구조 (Optimal Substructure)** : 전체 문제의 최적해가 그 문제를 구성하는 작은 부분 문제들의 최적해들로 결합될 수 있는 구조적 성질
- **교환 논증 (Exchange Argument)** : 임의의 최적해가 존재할 때, 탐욕적 선택으로 구한 해와 요소를 점진 교환하더라도 해의 품질이 저하되지 않음을 증명하는 기법
- **활동 선택 문제 (Activity Selection Problem)** : 하나의 자원을 공유하는 여러 활동 중 겹치지 않고 수행 가능한 최대 활동 수를 종료 시간이 가장 빠른 순으로 선택하는 대표적 탐욕 문제

## 2~4교시 예상문제 (25점)

> 알고리즘 설계 기법인 탐욕 알고리즘(Greedy Algorithm)의 기본 개념과 3단계 수행 절차를 설명하고, 전역 최적해를 보장하기 위한 2대 필수 조건 및 동적 계획법(Dynamic Programming)과의 비교를 기술하시오. (25점)

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 복잡한 최적화 문제를 해결할 때 전체적인 상황을 다각도로 고려하지 않고, 각 단계에서 직관적으로 가장 유리하다고 판단되는 국소적 최적해를 선택해 나가는 알고리즘 설계 기법 |
| 목적 | 탐색 공간의 지수적 폭증(NP-Hard) 문제를 선형 또는 다항 시간($O(n \log n)$ 등)으로 대폭 단순화하여 고속 최적해 도출 또는 고품질 근사해(Approximation) 확보 |

## Ⅱ. 핵심 특징

| 특징 | 세부 내용 |
|---|---|
| 비가역적 선택 (No Backtracking) | 한 번 내린 선택은 이후 단계에서 변경하거나 취소(백트래킹)하지 않고 영구 확정 |
| 극도의 연산 효율성 | 전체 경우의 수를 탐색하지 않고 매 순간 정렬 기준(우선순위 큐)에 따라 단일 선택만 수행하므로 실행 속도 탁월 |
| 조건부 정당성 (Conditional Correctness) | 탐욕 선택 속성과 최적 부분 구조를 모두 만족하는 특정 문제군에 한해서만 100% 최적해 보장 |
| 휴리스틱 근사 기법 활용 | 전역 최적해를 보장하지 못하는 NP-난해 문제(TSP, 0/1 Knapsack 등)에서도 현실적인 근사 알고리즘으로 널리 활용 |

단순성과 고속 처리 능력 덕분에 실시간 시스템 및 대규모 그래프 인프라 알고리즘의 핵심 골격으로 기능.

## Ⅲ. 체계·프로세스

```text
[탐욕 알고리즘의 3단계 기본 프로세스]

[초기 상태: 전체 후보 원소 집합 C, 빈 해답 집합 S = {}]
       │
       ▼
[1. 선택 절차 (Selection Procedure)] ◀────────────────────────────┐
  - 현재 시점에서 평가 기준(가중치 최소, 종료시간 최단 등)에 따라    │
  - 후보 집합 C에서 가장 매력적인 최적 원소 x 추출                  │
       │                                                           │
       ▼                                                           │
[2. 적절성 검사 (Feasibility Check)]                               │
  - 원소 x를 기존 해답 집합 S에 추가(S ∪ {x})했을 때                 │
  - 문제의 모든 제약 조건(사이클 없음, 시간 겹치지 않음 등)을 만족하는가?
  ├─ [YES: 제약 만족] ──► S = S ∪ {x} (해답에 정식 포함 확정)       │
  └─ [NO : 제약 위반] ──► 원소 x 영구 폐기                         │
       │                                                           │
       ▼                                                           │
[3. 해답 검사 (Solution Check)]                                    │
  - 현재 해답 집합 S가 전체 문제의 목표(V-1개 간선, 모든 활동 등)를  │
    완전히 만족하는가?                                             │
  ├─ [미완료] ──► 후보 집합이 남아있다면 다음 선택 반복 ───────────┘
  └─ [완료]   ──► 최종 최적해 반환 (종료)
```

선택 절차, 적절성 검사, 해답 검사의 3단계를 거치며 되돌림(Backtracking) 없이 해를 완성해 나가는 프로세스.

## Ⅳ. 종류·비교

| 비교 항목 | 탐욕 알고리즘 (Greedy) | 동적 계획법 (Dynamic Programming) | 분할 정복 (Divide and Conquer) |
|---|---|---|---|
| **접근 방식** | 매 순간 눈앞의 최선의 선택 1개만 추종 | 모든 하위 문제의 해를 계산하고 비교하여 최적해 도출 | 문제를 독립된 작은 하위 문제로 쪼개어 각각 해결 |
| **선택 번복** | 절대 번복하지 않음 (선택 확정) | 메모이제이션/DP 테이블을 채우며 최적 경로 선택 | 하위 문제의 해들을 단순 결합 |
| **하위 문제 관계** | 하위 문제에 무관하게 탐욕적 선택 | 하위 문제가 중복(Overlapping)되어 재사용됨 | 하위 문제가 상호 독립적(Disjoint)임 |
| **시간 복잡도** | 통상 $O(n)$ 또는 $O(n \log n)$ (매우 빠름) | $O(n^2)$, $O(n^3)$ 등 다항 시간 소요 | $O(n \log n)$ (병합 정렬 등) |
| **대표 알고리즘** | 다익스트라, 크루스칼, 허프만 코딩 | 플로이드-워셜, 0/1 배낭, LCS, 벨만-포드 | 퀵 정렬, 병합 정렬, 이진 탐색 |

### 탐욕 알고리즘 최적해 보장 2대 필수 조건

| 조건명 | 수학적 정의 및 의미 | 불만족 시 발생하는 문제 |
|---|---|---|
| **탐욕 선택 속성 (Greedy Choice Property)** | 국소적으로 탐욕적인 선택을 연속하여도 전체 문제의 전역 최적해에 도달할 수 있는 성질 (교환 논증으로 증명) | 국소적 최적을 선택했으나 이후 단계에서 막다른 길에 봉착하여 최적해 실패 |
| **최적 부분 구조 (Optimal Substructure)** | 전체 문제의 최적해가 분할된 하위 부분 문제들의 최적해로부터 안전하게 조립될 수 있는 구조 | 하위 문제의 최적해가 전체 문제의 최적해와 상충되어 오답 도출 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 0/1 배낭 문제(Knapsack)와 같이 물건을 쪼갤 수 없는 환경에서 탐욕법 적용 시 최악의 비최적해 발생 | 물건을 자를 수 있는 분할 배낭(Fractional Knapsack)에만 탐욕법을 쓰고, 0/1 배낭은 동적 계획법(DP)으로 전환 |
| 동전 거스름돈 문제에서 동전 단위가 배수 관계(10, 50, 100, 500)가 아닐 때(예: 10, 40, 50원) 탐욕법 오답 | 동전 액면가가 배수 체계인지 사전 확인하고 임의의 화폐 단위인 경우 너비 우선 탐색(BFS) 또는 DP 적용 |
| 전역 최적해 여부를 수학적으로 입증하지 않고 직관에만 의존하여 알고리즘을 설계하는 오류 | 반례(Counter-example)를 능동적으로 탐색하고, 교환 논증(Exchange Argument)이나 수학적 귀납법을 통해 정당성 입증 |

## Ⅵ. 제언

도메인 최적화 문제 해결 시 직관적인 탐욕 선택 기준을 즉시 코딩하지 않고, 수학적 정당성 검증을 선행한 후 전역 최적해가 보장되지 않을 경우 메타휴리스틱(유전 알고리즘, 시뮬레이티드 어닐링)과의 결합 설계 체계 확립.

```text
[최적화 알고리즘 설계 의사결정 파이프라인]
  최적화 문제 분석 → 탐욕 선택 속성/최적 부분 구조 검증
                         ├─ [완전 성립] ──► 탐욕 알고리즘 (초고속 O(n log n))
                         ├─ [부분 문제 중복] ──► 동적 계획법 (정확한 DP)
                         └─ [NP-난해 문제] ──► 탐욕 휴리스틱 기반 근사 알고리즘
```

| 검증 단계 | 사전 모델링 단계 | 구현 및 검증 단계 |
|---|---|---|
| 정당성 검증 | 교환 논증(Exchange Argument)을 통한 불변성 증명 | 대표적 극단 케이스 및 엣지 케이스 단위 테스트셋 검증 |
| 성능 목표 | 정렬 및 우선순위 큐 기반 시간 복잡도 최소화 | 전역 최적해 100% 도달 또는 근사율(Approximation Ratio) 보장 |
