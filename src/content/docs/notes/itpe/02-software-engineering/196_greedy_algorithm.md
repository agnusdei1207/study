## 연관 키워드

- 탐욕 알고리즘(Greedy Algorithm), 국소적 최적해(Local Optimum), 전체 최적해(Global Optimum)
- 탐욕적 선택 속성(Greedy Choice Property), 최적 부분 구조(Optimal Substructure)
- 동적 계획법(DP, Dynamic Programming), 교환 논법(Exchange Argument), 근사 알고리즘(Approximation Algorithm)

## Ⅰ. 탐욕 알고리즘의 개요

- 핵심 요약 : 매 순간의 국소적 최적 선택을 쌓아 전체 최적해에 도달하려는 알고리즘 설계 패러다임.
- 개념 : 최적화 문제를 풀 때 미래 상황을 따지지 않고, 현재 단계에서 가장 좋아 보이는 **국소적 최적해** (Local Optimum)를 선택해 나가며 **전체 최적해** (Global Optimum)에 도달하려는 설계 방식인 **탐욕 알고리즘** (Greedy Algorithm).
- 배경 및 필요성 : 모든 경우를 따지는 완전 탐색이나 **동적 계획법** (DP, Dynamic Programming)의 높은 비용을 피하고, 조건이 맞는 문제를 빠르게 풀 방법이 필요함.
- 2대 성립 조건 : **탐욕적 선택 속성** (Greedy Choice Property)과 **최적 부분 구조** (Optimal Substructure)가 모두 성립해야 전체 최적성이 보장됨.

## Ⅱ. 탐욕 알고리즘의 특징 및 장점

- 핵심 요약 : 번복 없는 국소 최적 선택과 2대 성립 조건, 정렬 기반 고속 해법이 결합된 구조.

1. 근시안적 선택 : 각 단계에서 가장 좋아 보이는 후보 하나를 즉시 선택 → 판단이 단순하고 빠름.
2. 번복 없는 진행 : 한 번 내린 선택을 나중에 되돌리지 않음 → 선택 횟수가 제한되어 계산량이 줄어듦.
3. 성립 조건 검증 : 두 성립 조건이 증명될 때만 전체 최적성이 보장됨 → 적용 전 증명 절차가 필수.
4. 고속 해법 : 초기 정렬 후 선형 또는 $O(N \log N)$ 수준의 다항 시간에 해를 구함 → 대용량 데이터 처리에 유리.
5. 대표 응용 : 최소 신장 트리(크루스칼, 프림), 다익스트라 최단 경로, **허프만 코딩** (Huffman Coding), 회의실 배정, **분할 가능 배낭 문제** (Fractional Knapsack).

## Ⅲ. 탐욕 알고리즘의 구조 (흐름)

- 핵심 요약 : 후보 선택, 실행 가능성 검사, 해 갱신을 반복하는 루프 구조와 두 성립 조건을 통한 최적성 증명.

```text
[ 후보 집합 초기화 ]
          ↓
[ 탐욕적 선택 기준 적용 ]
          ↓
[ 실행 가능성 검사 ]
 만족 → 해 집합에 추가
 불만족 → 후보 폐기
          ↓
[ 해 집합 완성 검사 ]
 미완성 → 선택 단계 반복
 완성 → 최종 해 반환
```

```text
[ 탐욕적 선택 속성 ]
 현재의 최선 선택이 전체 최적해의 일부임을 증명
          ↓
[ 최적 부분 구조 ]
 전체 최적해가 부분 문제의 최적해로 구성됨
          ↓
[ 최적성 증명 ]
 교환 논법 또는 수학적 귀납법으로 입증
```

## Ⅳ. 탐욕 알고리즘과 동적 계획법의 비교

- 핵심 요약 : 선택 방식, 번복 여부, 효율, 최적성 보장이 상반된 두 최적화 패러다임.

| 비교 항목 | 탐욕 알고리즘 (Greedy) | 동적 계획법 (DP) |
| --- | --- | --- |
| 선택 방식 | 현재 가장 좋아 보이는 해 하나를 즉시 선택 | 모든 부분 문제의 해를 구하고 비교하여 선택 |
| 선택 번복 | 한 번 내린 선택을 번복하지 않음 | 하위 문제 해를 조합하며 이전 결과를 활용 |
| 계산 효율 | 정렬 후 선형 또는 $O(N \log N)$ 수준으로 빠름 | 상태 테이블 계산으로 상대적으로 느림 |
| 최적성 보장 | 성립 조건을 증명해야 보장됨 | 점화식과 최적 부분 구조에 따라 정확한 최적해 보장 |
| 0-1 배낭 문제 | 최적해 보장 불가 | 적용 가능 |

- 선택 기준 : 성립 조건이 증명되면 탐욕 알고리즘을, 증명되지 않거나 모든 경우의 비교가 필요하면 동적 계획법을 고름.

## Ⅴ. 탐욕 알고리즘의 한계와 방안

- 핵심 요약 : 국소 최적의 함정, 정렬 비용, 제약 추가에 대한 취약성이 한계이며, 증명 선행과 DP 전환, 근사 알고리즘으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 국소 최적해 함정 | 미래 선택지를 보지 않아 0-1 배낭 문제처럼 전체 최적해를 놓침 | 성립 조건의 수학적 증명을 선행하고, 불가능하면 동적 계획법으로 전환 | 최적해 대비 오차, 반례 검증 결과 |
| 정렬에 따른 초기 연산 부담 | 회의실 배정 등은 구간 정렬이 $O(N \log N)$ 병목이 됨 | 우선순위 큐로 정렬 비용을 분산하거나 스트리밍 방식의 부분 정렬 적용 | 정렬 소요 시간, 입력 크기 |
| 제약 변경에 대한 취약성 | 제약이 하나만 추가되어도 탐욕 규칙이 무너져 재설계가 필요 | 엄격한 최적 대신 오차 허용형 근사 알고리즘으로 설계하고 근사 비율 검증 | 근사 비율, 제약 변경 시 재설계 비용 |

## Ⅵ. 시스템 최적화 관점의 기술사적 제언

- 핵심 요약 : 탐욕 해법은 채택 전에 정당성 증명을 거치고, 최적해 계산이 어려운 문제에는 근사 알고리즘으로 접근하는 방향.
- 정당성 증명의 선행 : 탐욕 해법은 직관적으로 맞아 보여도 예외 상황에서 틀리기 쉬우므로, 개발 조직은 채택 전에 교환 논법으로 최적성을 증명하는 절차를 거쳐야 한다. 예를 들어 동전 단위가 배수 관계가 아니면 8원을 5원 1개와 1원 3개로 거슬러 주는 방식이 4원 2개보다 많은 동전을 쓰게 된다.
- 근사 알고리즘의 활용 : 외판원 순회(TSP, Traveling Salesman Problem)나 정점 커버(Vertex Cover)처럼 다항 시간에 최적해를 구하기 어려운 **NP-Hard** (Non-deterministic Polynomial-time Hard) 문제에는, 오차 한계가 증명된 근사 알고리즘을 적용해 실시간 시스템의 연산 부담을 줄이는 것이 현실적이다.

## Ⅶ. 결론

- 핵심 요약 : 탐욕 알고리즘은 두 성립 조건의 증명이 전제될 때 쓸 수 있는 고속 최적화 수단임.
- 시사점 : 증명이 어려운 문제는 동적 계획법으로 전환하거나 근사 비율이 검증된 근사 알고리즘으로 설계하는 것이 대안임.
