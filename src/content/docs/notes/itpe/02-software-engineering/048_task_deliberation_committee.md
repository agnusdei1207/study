## 30초 인출

- 본질: 과업심의위원회는 공공 소프트웨어 사업에서 과업 내용의 확정과 변경을 발주 전에 심의해 과업 범위 분쟁을 막는 발주기관 내 위원회
- 메커니즘: 발주 전에 과업 내용을 심의해 확정하고, 계약 후 과업 변경 요청이 오면 위원회가 변경 내용과 계약금액·기간 조정을 심의해 계약에 반영
- 통찰: 과업이 불명확한 채 발주하면 계약 후 추가 요구가 분쟁으로 이어지므로 발주 전에 과업을 심의·확정하고 변경은 심의 결과를 계약에 반영

## 2~4교시 25점 답안

## Ⅰ. 과업심의위원회의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **과업심의위원회** 는 공공 소프트웨어 사업의 과업 내용 확정과 변경을 심의하는 발주기관 내 위원회 |
| 목적 | 과업 범위 불명확에서 생기는 계약 후 분쟁과 부당한 추가 요구 방지 |

## Ⅱ. 일반 사업 검토와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 발주 전 확정 | 과업 내용을 계약 전에 심의 |
| 변경 심의 | 계약 후 변경도 위원회가 심의 |
| 위원 구성 | 위원장 포함 5~10명, 외부 위원 과반수(「소프트웨어 진흥법 시행령」 제45조) |
| 공정성 장치 | 제척·기피·회피 |

## Ⅲ. 심의 체계와 변경 절차

### 과업심의위원회 운영 체계

```text
발주기관
    │
    ├─ 과업 내용 확정 심의 ── 발주 전
    ├─ 과업 변경 심의 ── 계약 후 변경 요청 시
    └─ 심의 결과 ── 제안요청서·계약에 반영
```

### 확대: 과업 변경 심의 절차

```text
사업자·발주기관의 과업 변경 요청
    ↓
위원회 개최·변경 내용 심의 (범위·금액·기간)
    ↓
심의 결과 통보
    ↓
계약 변경에 반영
```

## Ⅳ. 심의 시점별 역할

| 구분 | 발주 전 과업 확정 | 계약 후 과업 변경 |
|---|---|---|
| 심의 대상 | 과업 범위·산출물·요구사항 | 변경 요청 내용·금액·기간 영향 |
| 목적 | 범위 불명확 방지 | 부당한 추가 요구·분쟁 방지 |
| 결과 반영 | 제안요청서·계약 | 계약 변경 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 형식적 심의로 과업 불명확 미해소 | 요구사항 상세화 수준을 심의 기준으로 확인 |
| 변경 요청 처리 지연 | 심의 기한과 절차를 계약에 명시 |
| 위원회의 전문성 부족 | 외부 전문가 위원 참여 |
| 심의 결과의 계약 미반영 | 심의 결과와 계약 변경의 연결 확인 |

## Ⅵ. 제언

발주 전에 요구사항 상세도를 기준으로 과업을 확정하고, 계약 후 변경은 심의 결과를 금액·기간 조정으로 계약에 반영

### 과업 확정·변경 연계

```text
요구사항 상세화 → 발주 전 과업 확정 심의
    ↓
계약 후 변경 요청 → 변경 심의
    ↓
금액·기간 조정을 계약에 반영
```

### 선택 근거: 사후 협의와의 비교

| 구분 | 사후 협의 | 제언: 발주 전 확정·변경 심의 |
|---|---|---|
| 과업 명확성 | 계약 후 분쟁 | 발주 전 확정 |
| 변경 처리 | 당사자 협의 | 위원회 심의 |
| 계약 반영 | 지연 가능 | 심의 결과 반영 |
