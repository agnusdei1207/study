<details>
<summary>핵심 용어</summary>

- **시맨틱 태그(Semantic Tags)**: 브라우저와 검색엔진, 스크린 리더에게 문서 구조의 의미론적 역할을 명확히 전달하는 전용 요소 (`<header>`, `<nav>`, `<article>`, `<footer>` 등)
- **플러그인 프리(Plugin-free)**: 보안 취약점과 브라우저 다운의 원흉이었던 ActiveX, Silverlight, Flash 설치 없이 브라우저 내장 엔진만으로 모든 기능을 실행하는 환경
- **WebSocket**: 클라이언트와 서버가 단 1회의 핸드셰이크 후 단일 TCP 연결 상에서 실시간 양방향 전이중(Full-Duplex) 통신을 가능하게 하는 프로토콜
- **Web Worker**: 브라우저의 메인 UI 스레드를 방해하지 않고, 무거운 CPU 연산이나 대량 데이터 가공을 백그라운드 독립 스레드에서 병렬 처리하는 API
</details>

## 1. 개요 및 필요성

### 비표준 플러그인의 종말과 애플리케이션 플랫폼으로서의 웹

과거 웹은 단순한 텍스트 뷰어에 불과하여, 음악이나 동영상을 재생하고 결제를 처리하려면 마이크로소프트의 ActiveX나 어도비의 Flash 같은 폐쇄형 바이너리 플러그인을 강제로 설치해야 했다. 이는 심각한 악성코드 감염 통로가 되었고, 스마트폰 모바일 브라우저와의 단절을 초래했다.

HTML5는 별도 플러그인 없이 **네이티브 오디오/비디오, 2D/3D 그래픽, 로컬 스토리지, 실시간 웹소켓**을 웹 표준으로 흡수함으로써, 브라우저를 데스크톱과 모바일 네이티브 앱을 대체하는 범용 애플리케이션 런타임 플랫폼으로 혁신하였다.

### HTML4 vs XHTML 1.0 vs HTML5 비교

| 구분 | HTML4 | XHTML 1.0 | HTML5 |
|---|---|---|---|
| **표준화 기구** | W3C (1997년) | W3C (2000년) | **W3C / WHATWG (2014년 표준 확정)** |
| **문법 철학** | 느슨한 SGML 기반 | 극도로 엄격한 XML 문법 강제 | **유연하고 실용적인 웹 환경 지향** |
| **멀티미디어** | 플러그인 필수 (ActiveX, Flash) | 플러그인 필수 | **`<video>`, `<audio>` 네이티브 내장 (플러그인 프리)** |
| **문서 구조화** | 단순 `<div>`, `<span>` 남용 | `<div>` 중심 구조화 | **시맨틱 전용 태그 제공 (`<nav>`, `<article>` 등)** |
| **클라이언트 저장소**| 쿠키(Cookie, 4KB 제약) | 쿠키 | **Web Storage(5MB), IndexedDB(수십 GB)** |
| **실시간 통신** | 주기적 HTTP 폴링 의존 | 폴링 의존 | **WebSocket, SSE, WebRTC 네이티브 지원** |

## 3. 실무 적용 및 고려사항

### 위험 대응 매트릭스

| 위험 | 대책 | 효과 |
|---|---|---|
| 구형 브라우저 엔진에서 HTML5 신규 태그 및 API 미지원으로 인한 화면 레이아웃 깨짐 | Modernizr 라이브러리를 통한 기능 감지(Feature Detection) 및 폴리필(Polyfill) 자동 주입 | 크로스 브라우징 호환성 100% 확보 |
| 클라이언트 LocalStorage에 암호화되지 않은 인증 토큰을 저장하다가 XSS 공격으로 세션 탈취 | 민감 인증 토큰은 JS 접근이 차단된 HttpOnly Secure 쿠키에 저장하고 강력한 CSP 헤더 강제화 | XSS 기반 세션 하이재킹 위험 원천 차단 |
| 복잡한 캔버스 그래픽 연산 시 메인 UI 스레드가 점유되어 화면 덜컥거림(Jank) 발생 | OffscreenCanvas와 Web Worker를 결합하여 그래픽 연산을 백그라운드 스레드로 분리 렌더링 | 메인 스레드 60fps 무중단 반응성 유지 |

## 4. 기술사 답안 차별화 포인트

### PWA(Progressive Web Apps)와 WebAssembly(Wasm)의 결합

HTML5의 진정한 종착점은 네이티브 앱과의 경계를 허무는 것이다. **서비스 워커와 웹앱 매니페스트를 결합한 PWA**는 앱스토어 심사 없이도 홈 화면 설치와 오프라인 실행을 지원한다. 여기에 C++/Rust 코드를 브라우저에서 네이티브 기계어 속도로 실행하는 **WebAssembly(Wasm)**를 결합하여, 포토샵이나 CAD 같은 고부하 소프트웨어를 브라우저 상에서 구동하는 하이퍼 퍼포먼스 웹 플랫폼 비전을 결론으로 제시한다.

### 시맨틱 마크업의 비즈니스 가치: SEO 및 웹 접근성(A11y)

단순히 `<div>` 대신 시맨틱 태그를 쓰는 것은 코딩 스타일 문제가 아니다. 검색 엔진 로봇이 웹페이지의 핵심 콘텐츠를 정확히 파악하여 **검색 상위 노출(SEO)을 결정짓는 핵심 알고리즘 요소**이며, 장애인차별금지법에 따른 국가 공인 **웹 접근성 품질인증(K-WAH)**을 획득하기 위한 필수 법적 준수 요건임을 답안에 명시한다.
