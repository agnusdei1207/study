## 연관 키워드
- HTML5, 시맨틱 요소, 멀티미디어, Canvas, Web Storage, 웹 표준

### Ⅰ. HTML5의 개요

- 핵심 요약 : HTML5는 웹 문서의 구조와 의미를 표현하고 브라우저 기능과 연동 하는 HTML 표준 세대.
- 개념 : HTML(HyperText Markup Language)은 웹 콘텐츠의 구조를 기술하는 마크업 언어이며, HTML Living Standard는 현재 WHATWG에서 지속 관리 되는 표준(**HTML5**, HyperText Markup Language 5).
- 배경 및 필요성 : 플러그인 의존 멀티미디어와 비표준 브라우저 확장을 줄이고 의미 있는 문서 구조와 네이티브 기능을 제공할 필요.
- 주요 목적 : 상호 운용 가능한 웹 문서·앱의 구조와 기능 기반을 마련.

### Ⅱ. HTML5의 주요 기능과 장점

- 핵심 요약 : 시맨틱 구조와 멀티미디어 요소, 브라우저 API가 플러그인 의존을 낮추고 접근성을 지원.

1. 시맨틱 요소 : `header`, `nav`, `main`, `article`, `section`, `footer`로 문서 역할 명시 → 탐색·접근성 향상.
2. 멀티미디어 : `audio`, `video`로 미디어 내장 → 별도 플러그인 의존 감소.
3. 그래픽 : Canvas 2D와 SVG로 동적·벡터 그래픽 구현 → 브라우저 기반 시각화 지원.
4. 웹 API : Web Storage, Geolocation 등은 별도 명세와 권한·보안 조건에 따라 사용.

### Ⅲ. 문서 처리 흐름 (구조)

- 핵심 요약 : 브라우저가 HTML을 파싱해 DOM을 만들고 CSSOM·스크립트와 결합해 화면을 구성.

```text
HTML 응답
   ↓ 파싱
DOM 트리 + 외부 자원 로드
   ↓ CSS·스크립트 계산
렌더 트리·레이아웃·페인트
   ↓
화면 출력·사용자 상호 작용
```

```text
시맨틱 마크업 → 접근성 트리·구조 정보
미디어 요소   → 브라우저 디코더 재생
Canvas        → 스크립트가 픽셀 그래픽 갱신
```

- 브라우저 기능 지원과 API 동작은 명세·보안 컨텍스트·사용자 권한을 확인하고 기능 탐지로 대응.

### Ⅳ. 표현 방식 비교

- 핵심 요약 : 구조 의미에는 시맨틱 HTML, 확대 가능한 도형에는 SVG, 픽셀 기반 동적 렌더링에는 Canvas가 적합.

| 비교 축 | 시맨틱 HTML | SVG | Canvas |
|---|---|---|---|
| 표현 단위 | 문서 요소·의미 | 벡터 도형 객체 | 픽셀 기반 비트맵 |
| 접근성 | 구조·랜드마크 제공 | 제목·설명·접근성 보완 필요 | 픽셀 만으로 의미 전달 어려움 |
| 확대·수정 | 요소 별 스타일 | 확대에 선명·객체 선택 가능 | 재그리기·해상도 관리 필요 |
| 적합 사례 | 콘텐츠 문서·폼 | 로고·차트·아이콘 | 게임·대량 픽셀 그래픽 |

### Ⅴ. HTML5의 한계와 방안

- 핵심 요약 : 표준·브라우저 차이, 접근성, 클라이언트 저장소의 보안 조건을 확인.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 브라우저 별 기능 차이 | 명세 구현 시점·정책 상이 | 기능 탐지·폴백·실 브라우저 검증 | 호환성 결함 건수 |
| 시맨틱 오용 | 요소를 시각 스타일 만으로 선택 | 의미에 맞는 요소·키보드 탐색 적용 | 시맨틱 오용 건수 |
| Canvas 접근성 | 그래픽이 DOM 텍스트가 아님 | 대체 텍스트·DOM 기반 대안 제공 | 접근성 결함 건수 |
| 저장소 노출 | 스크립트 접근 가능한 로컬 저장 | 민감 정보 저장 금지·XSS 방어·수명 관리 | 저장소 위반 건수 |

### Ⅵ. 웹 표준 적용 제언

- 핵심 요약 : 웹 개발 팀 은 문서 의미·접근성·상호 운용성을 기준으로 표준 기능을 선택 하고 명세와 브라우저 지원을 검증.

1. 설계 자는 WHATWG HTML 표준과 관련 API 명세를 확인 하고, 보안 민감 기능은 사용자 권한과 안전한 컨텍스트 요구를 점검.
2. 품질 조직 은 키보드 접근성, 보조 기기, 저사양 기기, 브라우저 호환성을 수용 기준에 포함.

### Ⅶ. 결론

- 핵심 요약 : HTML5는 웹 콘텐츠의 구조적 의미와 브라우저 내장 기능을 넓힌 웹 기반.
- 시사점 : 표준 요소를 의미에 맞게 사용 하고 접근성·보안·호환성을 함께 설계할 때 지속 가능한 웹 앱 구현.
