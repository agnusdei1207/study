## 30초 인출

- 본질: HTML5는 별도 플러그인 없이 시맨틱 태그·멀티미디어·그래픽·저장소·통신을 브라우저에서 제공하는 웹 표준
- 메커니즘: 의미를 가진 태그로 문서 구조를 표현하고 오디오·비디오·캔버스·웹 저장소·웹 소켓 같은 API를 자바스크립트로 사용
- 통찰: 기능이 브라우저마다 지원 정도가 달라 일부 기능이 동작하지 않을 수 있으므로 지원 여부를 확인하고 대체 동작을 준비해 점진적으로 적용

<details>
<summary>핵심 용어</summary>

- **HTML5** : 시맨틱 태그와 다양한 API를 포함한 HTML의 표준 버전
- **시맨틱 마크업(Semantic Markup)** : header·nav·section처럼 태그 이름으로 의미를 나타내는 방식
- **캔버스(Canvas)** : 자바스크립트로 그래픽을 그리는 영역
- **웹 스토리지(Web Storage)** : 쿠키보다 큰 용량을 브라우저에 저장하는 기능
- **웹 소켓(WebSocket)** : 서버와 양방향 실시간 통신을 하는 프로토콜
- **웹 워커(Web Worker)** : 화면과 분리해 백그라운드에서 스크립트를 실행하는 기능

</details>

## 2~4교시 25점 답안

## Ⅰ. HTML5의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **HTML5** 는 플러그인 없이 다양한 기능을 제공하는 웹 표준 |
| 목적 | 웹을 애플리케이션 플랫폼으로 확장 |

## Ⅱ. 이전 HTML과 구별되는 특징

| 특징 | 의미 |
|---|---|
| 플러그인 불필요 | 멀티미디어·그래픽을 브라우저가 직접 처리 |
| 시맨틱 구조 | 의미 있는 태그 |
| API 제공 | 저장·통신·위치 등 자바스크립트 API |

## Ⅲ. 주요 기능

```text
HTML5
   ├─ 구조 ── 시맨틱 태그
   ├─ 미디어·그래픽 ── audio·video·canvas
   ├─ 저장 ── 웹 스토리지
   └─ 통신·실행 ── 웹 소켓·웹 워커
```

## Ⅳ. 기능별 정리

| 영역 | 기능 | 효과 |
|---|---|---|
| 구조 | header·nav·section·article | 문서 의미 명확, 접근성 향상 |
| 멀티미디어 | audio·video | 플러그인 제거 |
| 그래픽 | canvas | 스크립트 기반 그래픽 |
| 저장 | 웹 스토리지 | 쿠키보다 큰 저장 공간 |
| 통신 | 웹 소켓 | 실시간 양방향 통신 |
| 실행 | 웹 워커 | 화면 멈춤 없는 계산 |
| 폼 | 새 입력 타입·검증 | 입력 검증 간소화 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 브라우저별 지원 차이 | 기능 지원 여부 확인과 대체 동작 |
| 웹 스토리지에 민감정보 저장 위험 | 민감정보는 저장하지 않음 |
| 구형 브라우저 미지원 | 점진적 향상 방식 적용 |

## Ⅵ. 제언

기능 지원 여부를 확인해 사용하고 미지원 환경에는 대체 동작을 두어 점진적으로 적용

```text
기능 사용 전 지원 확인
    ├─ 지원 → HTML5 기능
    └─ 미지원 → 대체 동작
```

| 구분 | 무조건 사용 | 제언: 지원 확인 |
|---|---|---|
| 미지원 브라우저 | 오류 | 대체 동작 |
| 사용자 영향 | 일부 이탈 | 최소화 |
