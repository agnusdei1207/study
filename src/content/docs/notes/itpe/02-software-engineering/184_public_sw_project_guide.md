## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 공공 SW 사업 → **공공SW사업 법제도 가이드**

## 30초 인출

- 본질: 공공SW사업 법제도는 「소프트웨어 진흥법」 등에 따라 공공 SW 사업의 발주·수행·관리 과정에서 지켜야 할 제도를 정한 체계
- 메커니즘: 발주 전에 과업 내용과 사업 기간을 확정하고 상용SW 구매·원격지 개발 등의 방식을 선택하며 변경 시 과업심의위원회의 심의를 거침
- 통찰: 제도가 여러 단계에 흩어져 있어 누락하기 쉬우므로 사업 단계별로 적용할 제도를 점검표로 정리해 발주 전에 확인

<details>
<summary>핵심 용어</summary>

- **공공 SW 사업** : 국가기관·공공기관이 발주하는 소프트웨어 개발·구축 사업
- **과업심의위원회** : 과업 내용의 확정과 변경을 심의하는 발주기관 내 위원회
- **상용SW 직접구매(분리발주)** : 구축 사업과 상용 소프트웨어 구매를 나누어 발주하는 방식
- **적정 사업기간 산정** : 개발 규모에 맞는 사업 기간을 정하는 것
- **원격지 개발** : 발주기관 밖의 장소에서 개발하는 방식

</details>

## 2~4교시 25점 답안

## Ⅰ. 공공SW사업 법제도의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **공공SW사업 법제도** 는 공공 SW 사업의 발주·수행·관리에서 지켜야 할 제도를 정한 체계 |
| 목적 | 공정한 계약과 과업 범위·기간의 합리적 관리 |

## Ⅱ. 제도의 특징

| 특징 | 의미 |
|---|---|
| 사업 단계 전반 | 발주부터 수행·변경까지 적용 |
| 과업 명확화 | 범위·기간의 사전 확정 |
| 공정 계약 | 발주기관과 사업자의 관계 조정 |

## Ⅲ. 단계별 제도

```text
발주 준비 ─▶ 계약 ─▶ 수행 ─▶ 검수·종료
   │           │        │
과업 심의    상용SW      원격지 개발
적정 기간    분리 구매   과업 변경 심의
```

## Ⅳ. 주요 제도

| 제도 | 내용 |
|---|---|
| 과업심의위원회 | 과업 내용 확정과 변경을 심의 |
| 적정 사업기간 산정 | 규모에 맞는 사업 기간 설정 |
| 상용SW 직접구매 | 구축과 상용SW 구매의 분리 |
| 원격지 개발 | 발주기관 밖에서의 개발 허용 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 제도가 흩어져 있어 적용 누락 | 단계별 점검표 |
| 형식적 심의로 과업 불명확 유지 | 요구사항 상세도를 심의 기준으로 확인 |
| 제도 간 연계 부족 | 발주 전 통합 검토 |

## Ⅵ. 제언

사업 단계별 적용 제도를 점검표로 정리해 발주 전에 확인

```text
발주 전 점검표: 과업 확정 → 기간 산정 → 구매·수행 방식 → 변경 절차
```

| 구분 | 개별 확인 | 제언: 단계별 점검표 |
|---|---|---|
| 제도 누락 | 발생 | 예방 |
| 확인 시점 | 사후 | 발주 전 |
