## 연관 키워드
- 사용성 평가, ISO 9241-11, 효과성·효율성·만족도, 맥락, 사용자 기반 평가, 휴리스틱 평가

### Ⅰ. 사용성 평가 및 사용성 테스트의 개요

- 핵심 요약 : 사용성 평가는 특정 사용자·목표·사용 맥락에서 시스템이 효과성·효율성·만족도를 충족하는지 조사해 사용 문제를 발견하는 인간중심 설계 활동.
- 개념 : 특정 사용자·목표·사용 맥락에서 시스템이 효과성·효율성·만족도를 충족하는지 조사해 사용 문제를 발견하는 인간중심 설계 활동(**사용성 평가**, Usability Evaluation).
- 배경 및 필요성 : 기능 요구 충족만으로 업무 완료성·오류·학습부담이 보장되지 않아 실제 사용자와 맥락을 포함한 검증 필요.
- 주요 목적 : 사용자가 안전하고 정확하며 부담 없이 목표를 달성할 수 있는 제품·서비스 경험 확보.

### Ⅱ. 사용성 평가 및 사용성 테스트의 특징 및 장점

- 핵심 요약 : 맥락 기반 평가·사용자 수행 관찰·사용자 의견 수집·전문가 평가.

1. 맥락 기반 평가 : 사용자·목표·환경을 구체화 → 요구에 맞는 작업·참여자 선정.
2. 사용자 수행 관찰 : 대표 사용자가 과업 수행 → 완료율·시간·오류·도움 요청으로 효과성과 효율성 측정.
3. 사용자 의견 수집 : 만족도·불편·기대 차이 확인 → 정량 결과의 원인과 개선 방향 파악.
4. 전문가 평가 : 휴리스틱·접근성 점검 → 초기 설계 결함을 사용자 시험 전에 빠르게 발견.

### Ⅲ. 사용성 평가 및 사용성 테스트의 구조 (흐름)

- 핵심 요약 : 사용자·과업·맥락 정의 → 평가 질문·성공 기준 설정 → 사용자·전문가 평가 수행 → 문제 심각도 분석 → 설계 개선 → 재평가.

```text
사용자·과업·맥락 정의
   ↓
평가 질문·성공 기준 설정
   ↓
사용자·전문가 평가 수행
   ↓
문제 심각도 분석
   ↓
설계 개선
   ↓
재평가
```

```text
사용성 기준
 ├─ 효과성: 목표 과업의 정확한 완료
 ├─ 효율성: 시간·노력·오류 비용
 └─ 만족도: 사용 경험·신뢰·수용성
        ↓
지정 사용자·목표·사용 맥락에서 측정
```

### Ⅳ. 사용자 기반 평가와 휴리스틱 평가 비교

- 핵심 요약 : 사용자 기반 평가는 대표 사용자가 실제 과업 수행, 휴리스틱 평가는 전문가가 설계원칙 위반 점검.

| 비교 대상 | 핵심 특성 | 적용·판단 기준 |
|---|---|---|
| 사용자 기반 평가 | 대표 사용자가 실제 과업 수행 | 발견되지 않은 사용문제와 성과 측정 |
| 휴리스틱 평가 | 전문가가 설계원칙 위반 점검 | 초기·저비용 문제 탐색 |
| 접근성 평가 | 장애·보조기술 사용 조건 확인 | 법·표준 및 포용성 요구 검증 |

### Ⅴ. 사용성 평가 및 사용성 테스트의 한계와 방안

- 핵심 요약 : 비대표 참여자·과업·관찰자·학습효과·접근성·안전 문제 간과를 사용자 세분화·실제 과업 표집·위험기반 별도 평가로 관리.

| 위험 | 원인·영향 | 대응 통제 | 지표 예시 |
|---|---|---|---|
| 비대표 참여자·과업 | 실제 사용자와 다른 문제·성공률 산출 | 사용자 세분화·실제 과업·현장 맥락 표집 | 참여자 적합성, 과업 커버리지 |
| 관찰자·학습효과 | 진행자 유도나 반복학습으로 결과 편향 | 중립 스크립트, 순서 균형화, 독립 진행 | 도움 요청률, 재시험 편차 |
| 접근성·안전 문제 간과 | 평균 점수에 소수 집단의 중대 장벽이 가려짐 | 보조 기술·저시력·인지 부담 등 위험 기반 별도 평가 | 집단별 완료율, 심각 결함 |

### Ⅵ. 사용성 평가 및 사용성 테스트 적용에 대한 기술사적 제언

- 핵심 요약 : 사용자가 안전하고 정확하며 부담 없이 목표를 달성할 수 있는 제품·서비스 경험 확보.

- 실행 제언 : 제품 책임자는 출시 후 분석만 기다리지 말고 요구·설계 초기에 사용자 조사를 포함하며, 효과성·효율성·만족도와 접근성·안전성 결과를 제품 승인 기준에 반영.

### Ⅶ. 결론

- 핵심 요약 : 사용성 평가는 특정 사용자·목표·사용 맥락에서 시스템이 효과성·효율성·만족도를 충족하는지 조사해 사용 문제를 발견하는 인간중심 설계 활동.
- 시사점 : 사용성은 화면의 미관이 아니라 지정된 사용자가 특정 맥락에서 목표를 달성하는 결과이며, 반복 평가 제품의 채택과 안전을 좌우.
