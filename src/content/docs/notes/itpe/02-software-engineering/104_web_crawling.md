## 연관 키워드

- 웹 크롤러(Web Crawler), URL 프론티어(URL Frontier), robots.txt, 중복 제거
- 크롤링 정책, 색인, 순회 수집, 백오프

## Ⅰ. 웹 크롤링의 개요

- 핵심 요약 : 웹 크롤링은 시드 URL에서 링크를 따라 웹 문서를 자동으로 순회 수집하는 기술.
- 개념 : 시작점인 시드 URL(Uniform Resource Locator)에서 하이퍼링크를 따라가며 웹 문서를 자동으로 방문·저장하는 과정을 **웹 크롤링** (Web Crawling)이라 하고, 이를 수행하는 프로그램을 **웹 크롤러** (Web Crawler)라 한다.
- 배경 및 필요성 : 웹 문서의 규모와 갱신 빈도가 커져 수작업 수집으로는 최신 자료 확보와 문서 간 연결 관계 파악이 불가능하고, 검색 서비스의 **색인** (문서를 검색 가능한 목록으로 구성하는 처리) 입력이 상시 필요.
- 주요 목적 : 대규모 웹 자료의 발견·수집 자동화를 통해 검색·분석 체계의 안정적 데이터 입력 확보.

## Ⅱ. 웹 크롤링의 특징 및 장점

- 핵심 요약 : 방문 대상 관리·문서 해석·중복 제거·수집 정책 준수가 확장 가능하고 책임 있는 수집이라는 장점으로 연결.

1. 방문 대상 관리 : 방문 대기 URL과 우선순위를 관리하는 **URL 프론티어** (URL Frontier, 크롤링 대기 목록 구조)로 탐색 순서를 통제 → 도메인별 요청 속도 조절 효과.
2. 취득·해석 : HTTP(HyperText Transfer Protocol) 요청으로 문서를 취득하고 링크·메타데이터를 해석 → 다음 방문 대상이 자동 확장되는 효과.
3. 중복 제거 : URL 정규화와 콘텐츠 지문 비교를 통한 **중복 제거** → 재수집 방지와 색인 품질 유지 효과.
4. 정책 준수 : 크롤러 접근 지침인 **robots.txt** (사이트가 크롤러에 허용·차단 범위를 알리는 표준 파일) 확인과 요청 간 지연 등 **크롤링 정책** (수집 범위·속도·예의에 관한 규칙) 적용 → 대상 서버 보호와 운영 위험 감소 효과.

## Ⅲ. 웹 크롤링의 구조 (흐름)

- 핵심 요약 : 시드 등록→후보 선택→정책 확인→취득·해석→링크 추가의 순회 흐름과, 예의 정책과 실패 처리 구조.

```text
[크롤링 순회 흐름]

시드 URL 등록
   ↓
URL 프론티어에서 후보 선택
   ↓
robots.txt·정책 확인
   ↓
문서 취득·해석·저장
   ↓
새 링크를 프론티어에 추가 (반복)
```

```text
[예의 정책·실패 처리]

요청 전 - 허용 범위·속도 제한 확인
   ↓
요청 간 지연·백오프 적용
   ↓
실패 시 - 제한된 재시도·오류 기록
```

- robots.txt는 접근 범위의 표준 지침이며, 인증 우회 수단이나 법적 이용 허가로 간주할 수 없는 성격의 통제이다.

## Ⅳ. 웹 크롤링과 스크래핑의 비교

- 핵심 요약 : 링크를 따라 페이지를 순회 수집하는 과정과 지정된 페이지에서 데이터를 추출하는 행위의 대척 비교.

| 비교 축 | 웹 크롤링 | 스크래핑 |
| --- | --- | --- |
| 중심 동작 | 링크를 따라 페이지 순회 수집 | 지정 페이지에서 값·구조 추출 |
| 탐색 범위 | 시드에서 확장되는 다수 페이지 | 목표로 정한 페이지·사이트 |
| 산출물 | 문서 저장소·검색 색인 입력 | 정형화된 필드·레코드 |
| 핵심 제어 | 방문 관리·속도·중복 제거 | 문서 구조 변화·권리·정확성 |

## Ⅴ. 웹 크롤링의 한계와 방안

- 핵심 요약 : 서버 부하·순회 함정·중복 노이즈·준법 위험을 정책 상한과 검토 절차로 관리하는 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 대상 서버 부하 | 과도한 동시 요청 → 서비스 장애 유발 | 도메인별 속도 제한·요청 간 지연 | 도메인별 요청률 |
| 순회 함정 | 무한 달력·매개변수 조합 → 자원 낭비·무한 순회 | URL 정규화·탐색 깊이·범위 상한 | 차단된 함정 URL 비율 |
| 중복·노이즈 | 유사 문서·템플릿 텍스트 → 색인 품질 저하 | 중복 제거·유사도 필터 적용 | 중복 문서 비율 |
| 준법 위반 | 공개 웹이라는 이유만으로 허용 오해 → 법적 분쟁 | 이용 조건·개인정보·저작권 검토 | 준법 검토 완료율 |

## Ⅵ. 웹 크롤링에 대한 기술사적 제언

- 핵심 요약 : 수집 목적·범위·보존·삭제 책임을 사전 승인 제도와 준수 증거 체계로 정착하는 방향.
- 사전 승인 제도 : 데이터 책임 조직이 수집 목적·URL 범위·보존 기간·목적 외 이용 금지를 승인 절차로 운영.
- 운영 체계 : 운영 조직이 크롤러 식별 정보·연락 경로·속도 정책·중단 절차를 문서화하고 상시 유지.
- 증거 체계 : 수집 자료의 재이용 규칙과 준수 감사 기록을 체계화해 사후 검증 가능성 확보.

## Ⅶ. 결론

- 핵심 요약 : 웹 크롤링은 대규모 웹 자료의 발견·수집을 자동화하는 기반 기술.
- 시사점 : 확장성 설계와 함께 서버 부담·데이터 권리·개인정보 보호가 초기 설계 조건.
