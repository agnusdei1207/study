## 연관 키워드
- COQ, 예방·평가·내부실패·외부실패 비용, PAF, 재작업, 품질투자

## Ⅰ. 소프트웨어 품질비용의 개요
- 핵심 요약 : 품질비용(COQ)은 요구 품질을 확보·평가하고 결함 실패를 예방·수정하는 데 드는 생애주기 비용.
- 개념 : 적합비용(예방·평가)과 부적합비용(내부·외부 실패)을 분류해 품질투자와 실패손실 분석.
- 필요성 : 재작업·장애·고객이탈 등 실패비용이 프로젝트 장부에 드러나지 않을 수 있음.
- 목적 : 품질개선 투자와 결함비용을 비교해 총 품질비용과 위험을 최적화.

## Ⅱ. COQ 구성과 장점
- 핵심 요약 : PAF 모델은 예방·평가·실패비용을 나눠 품질수준 변화와 비용영향을 분석.
1. 예방비용 : 교육·설계리뷰·프로세스개선 → 결함 발생 가능성 저감.
2. 평가비용 : 검사·시험·감사 → 결함·요구불일치 탐지.
3. 내부실패비용 : 인도 전 재작업·재시험·폐기 → 내부 수정 손실.
4. 외부실패비용 : 인도 후 보증·장애·보상·평판손실 → 고객·사업 영향.

## Ⅲ. 품질비용 흐름
- 핵심 요약 : 비용을 동일 기준으로 수집·귀속하고 결함원인·품질활동과 연결해 개선효과를 재측정.
```text
예방비용 + 평가비용 → 결함 발견 전 품질확보
내부실패비용 + 외부실패비용 → 실패·재작업·고객영향
       ↓ 비용원인 분석 → 개선 투자 → 비용·품질 재측정
```
```text
결함원인 → 발생단계 → 재작업·장애비용 → 고객·운영영향
      ↘ 예방·검증 통제 → 재발률·실패비용 추세
```
- 비용은 직접원가뿐 아니라 장애시간·지원·기회손실 등 간접항목 범위를 정해 기록.

## Ⅳ. 예방·평가·실패비용 비교
- 핵심 요약 : 예방·평가는 적합비용, 내부·외부실패는 요구 불충족으로 발생하는 부적합비용.
| 비용유형 | 발생시점·활동 | 사례 |
|---|---|---|
| 예방 | 결함 발생 전 | 교육, 설계표준, 위험분석 |
| 평가 | 제품·프로세스 검증 | 코드리뷰, 테스트, 감사 |
| 내부실패 | 고객 인도 전 탐지 | 재작업, 재시험, 폐기 |
| 외부실패 | 인도·운영 후 발견 | 장애대응, 보상, 이탈, 평판손상 |

## Ⅴ. COQ 분석의 한계와 대응
- 핵심 요약 : 간접 실패비용의 누락과 단기 원가최소화 편향을 분류기준·생애주기 자료·품질지표로 보완.
| 한계 | 영향 | 대응 |
|---|---|---|
| 실패비용 가시성 부족 | 예방투자 효과 과소평가 | 장애·지원·재작업·고객손실 기록기준 |
| 비용 귀속·중복 | 조직간 비교 왜곡 | 비용사전·원인·기간·시스템 경계 합의 |
| 단기 ROI 편향 | 예방·평가 축소 후 외부실패 증가 | 결함유출·고객영향·총소유비용 병행 |

## Ⅵ. 품질비용 관리 제언
- 핵심 요약 : 품질책임자는 비용자료를 결함원인·고객성과와 연결해 예방활동과 통제수준을 조정.
1. 재무·품질팀은 공통 PAF 분류와 직접·간접비 산정경계 수립.
2. 개발팀은 결함·재작업·재시험 원인을 단계·기능과 연결.
3. 경영진은 COQ와 결함유출·고객영향 추세를 함께 검토해 품질투자 결정.

## Ⅶ. 결론
- 핵심 요약 : COQ는 품질을 위한 투자비용과 실패로 인한 손실을 함께 보는 경영·공학 지표.
- 시사점 : 실패비용을 가시화하고 예방·평가와 연결해야 품질개선의 경제성을 판단.
