## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 테스트·검증 → **기록·재생 테스트(Record and Replay Testing)**

## 30초 인출

- 본질: 기록·재생 테스트는 사용자 조작이나 실제 요청을 기록해 두었다가 다시 재생해 테스트 케이스로 쓰는 기법
- 메커니즘: 조작·요청을 기록하고 이를 재생해 응답이나 화면을 이전 결과와 비교하며 불일치를 결함 후보로 분류
- 통찰: 재생 시점의 시간·난수·외부 상태가 달라 결과가 달라질 수 있으므로 비교에서 변하는 값을 제외하고 개인정보는 기록 단계에서 마스킹

<details>
<summary>핵심 용어</summary>

- **기록·재생 테스트(Record and Replay)** : 조작·요청을 기록해 재생하는 방식의 테스트
- **트래픽 미러링(Traffic Mirroring)** : 실제 요청을 복제해 시험 환경으로 전달하는 방식
- **골든 마스터(Golden Master)** : 기준이 되는 이전 실행 결과를 저장해 비교 기준으로 쓰는 방식
- **테스트 오라클(Test Oracle)** : 결과의 옳고 그름을 판정하는 기준
- **마스킹(Masking)** : 개인정보 같은 민감 값을 가리는 처리

</details>

## 2~4교시 25점 답안

## Ⅰ. 기록·재생 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **기록·재생 테스트** 는 조작·요청을 기록해 재생하며 결과를 비교하는 테스트 |
| 목적 | 테스트 케이스 작성 비용 절감과 회귀 시험 자동화 |

## Ⅱ. 수작업 케이스와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 실제 사용 반영 | 실사용 패턴의 케이스 |
| 자동 재생 | 반복 실행 |
| 결과 비교 | 이전 결과와 대조 |

## Ⅲ. 수행 흐름

```text
기록: 사용자 조작·실제 요청 캡처
    ↓
재생: 시험 환경에서 같은 입력 재현
    ↓
비교: 응답·화면을 기준 결과와 대조
    ├─ 일치 → 통과
    └─ 불일치 → 결함 후보(변하는 값 제외 후 판정)
```

## Ⅳ. 방식별 비교

| 방식 | 기록 대상 | 활용 |
|---|---|---|
| UI 기록·재생 | 사용자 화면 조작 | 화면 회귀 시험 |
| 트래픽 미러링 | 실제 서버 요청 | 신규 버전 검증 |
| 골든 마스터 | 기준 실행 결과 | 리팩토링 후 동작 비교 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 시간·난수 등 변하는 값으로 오탐 | 비교에서 변동 값 제외 |
| 화면 변경 시 기록 무효 | 기록 갱신 절차 |
| 기록 데이터의 개인정보 | 기록 단계에서 마스킹 |

## Ⅵ. 제언

비교에서 변하는 값을 제외하는 규칙을 정하고 기록 데이터는 개인정보를 마스킹해 관리

```text
기록(마스킹) → 재생 → 변동 값 제외 비교 → 판정
```

| 구분 | 단순 비교 | 제언: 변동 제외·마스킹 |
|---|---|---|
| 오탐 | 많음 | 감소 |
| 개인정보 | 노출 위험 | 보호 |
