## 연관 키워드
- 기록·재생 테스트, 테스트 자동화, UI 테스트, 트래픽 미러링, 테스트 데이터 마스킹

### Ⅰ. 기록·재생 테스트의 개요

- 핵심 요약 : 기록·재생 테스트는 사용자 동작이나 시스템 요청을 기록해 같은 순서를 재실행하고 결과를 검증하는 테스트 자동화 방식.
- 개념 : 입력 이벤트·요청·응답을 저장한 뒤 재현해 회귀 동작을 확인하는 기법(**기록·재생 테스트**, Record and Replay Testing).
- 배경 및 필요성 : 수동 반복 시험의 비용을 줄이고 실제 사용 흐름에 가까운 재현 시나리오를 확보하기 위한 접근.
- 주요 목적 : 반복 가능한 시나리오로 회귀 검증의 속도와 재현성을 높임.

### Ⅱ. 기록·재생 테스트의 특징 및 장점

- 핵심 요약 : 실제 흐름을 기반으로 시나리오를 빠르게 확보하되 재생 결과에 명시적 단언을 결합해야 검증이 성립.

1. 사용자 이벤트 캡처 : 클릭·입력·탐색 순서를 기록 → 시나리오 작성 시간 절감.
2. 트래픽 기록·재생 : 요청·응답 또는 메시지 상호 작용을 보존 → 통합·성능 회귀 분석에 활용.
3. 결정적 검증 결합 : 결과 단언·비교 기준 지정 → 단순히 같은 동작을 반복하는 것을 넘어 결함 탐지.

### Ⅲ. 기록·재생 테스트의 구조 (흐름)

- 핵심 요약 : 기록 범위 정의 → 개인 정보·비밀 정보 마스킹 → 기준 시나리오 저장 → 격리 환경 재생 → 결과·변경 차이 분석.

```text
시나리오·기록 범위 선정
   ↓
이벤트·요청 캡처 및 민감 정보 제거
   ↓
기준 기록 저장·버전 관리
   ↓
격리된 시험 환경에서 재생
   ↓
화면·응답 단언과 차이 분석
```

- UI 안정화 : Page Object Model(POM) 등 페이지 구조 캡슐화를 적용해 선택자·상호 작용 변경을 테스트 로직 전체에 확산시키지 않도록 관리.

```text
기록 데이터 → 재생 엔진 → 대상 시스템
      ↓                          ↓
마스킹·보관 정책             결과 단언·차이 보고서
```

### Ⅳ. 기록·재생 테스트와 모델 기반 테스트 비교

- 핵심 요약 : 기록·재생은 관찰된 경로의 재현에 강하고 모델 기반 테스트는 상태·전이 모델에서 미관찰 경로를 생성.

| 비교 기준 | 기록·재생 | 모델 기반 테스트 |
|---|---|---|
| 시나리오 원천 | 실제 사용자·네트워크 상호 작용 | 상태·전이·요구 모델 |
| 장점 | 현실 흐름의 빠른 자동화·재현 | 경로 탐색·상태 조합의 체계적 생성 |
| 주요 비용 | 기록 유지·환경 안정화·단언 설계 | 모델 작성·정확성·유지 관리 |

### Ⅴ. 기록·재생 테스트의 한계와 방안

- 핵심 요약 : 선택자·시간·비결정성·민감 정보 문제로 인한 불안정성을 통제하고 시험의 관찰 가능성을 강화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 선택자·화면 변경 | UI 구조 변화가 기록 스크립트를 무효화 | 의미 기반 선택자·POM·컴포넌트 시험 병행 | 실패 원인 중 스크립트 오류 비율 |
| 타이밍·비결정성 | 비동기 처리·외부 서비스 상태 차이로 간헐 실패 | 명시적 대기·테스트 더블·환경 격리 | 불안정 시험 비율 |
| 개인 정보·비밀 노출 | 캡처 데이터에 토큰·개인 정보 포함 가능 | 최소 수집·마스킹·암호화·보존 기간 제한 | 민감 정보 탐지 건수 |

### Ⅵ. 기록·재생 테스트의 제언

- 핵심 요약 : QA 조직은 시험 피라미드와 데이터 거버넌스 안에서 기록·재생의 적용 경계를 정하고 CI 결과를 추적.

1. 제품 팀 은 핵심 사용자 여정만 선별해 기준 시나리오와 검증 단언을 함께 승인.
2. 플랫폼 팀 은 시험 전용 계정·데이터 수명 주기·격리 환경을 제공.
3. 품질 책임 자는 시나리오 유지 비용과 결함 탐지 기여도를 주기적으로 비교해 저가치 기록을 정리.

### Ⅶ. 기록·재생 테스트의 결론

- 핵심 요약 : 기록·재생은 관찰된 동작을 재현하는 시험 자동화 기법이며 자체로 정확성 단언을 대신하지 않음.
- 시사점 : 재현성·단언·민감 정보 통제가 결합될 때 빠른 회귀 검증 수단으로 활용 가능.
