## 연관 키워드

- 메시지 큐(Message Queue), MOM(Message-Oriented Middleware), 비동기 통신, 생산자·소비자
- 점대점, 발행-구독, ACK, 멱등성, DLQ(Dead Letter Queue)

## Ⅰ. 메시지 큐의 개요

- 핵심 요약 : 메시지 큐는 생산자와 소비자 사이에 메시지를 보관·전달하는 비동기 메시징 미들웨어.
- 개념 : 생산자가 보낸 메시지를 중간 저장소에 보관하고 소비자가 처리 시점에 가져가는 비동기 메시징 구성 요소 (**메시지 큐** (Message Queue)). 메시지 지향 미들웨어 (**MOM** (Message-Oriented Middleware))의 핵심 구성 요소.
- 배경 및 필요성 : 동기 직접 호출 구조에서는 수신 서비스의 장애·지연이 호출 서비스 처리에 전파되는 상태. 트래픽 급증 시 수신 한도 초과 발생.
- 주요 목적 : 서비스 간 시간적 결합 완화, 부하 흡수, 실패 재처리 기반의 유연한 시스템 통합.

## Ⅱ. 메시지 큐의 특징 및 장점

- 핵심 요약 : 비동기 위임·버퍼링·전달 보장·결합 완화가 탄력적 통합 구조로 이어짐.

1. 비동기 통신 : 발신 서비스가 응답 대기 없이 메시지를 위임 → 발신 처리 흐름이 수신 장애와 분리.
2. 부하 평탄화 : 큐가 순간 폭주 요청을 메시지로 버퍼링 → 소비자 처리 속도에 맞춘 안정 처리.
3. 전달 보장 : **ACK** (Acknowledgment, 수신 확인 응답)·재시도·전달 보장 수준(at-most-once, at-least-once 등)의 선택 → 유실·중복 간의 설계 판단 가능.
4. 결합 완화 : 생산자·소비자가 서로의 주소·가용성을 몰라도 동작 → 배포·확장의 독립성 확보.

## Ⅲ. 메시지 큐의 구조 (흐름)

- 핵심 요약 : 점대점은 소비자 그룹이 메시지를 분담 처리, 발행-구독은 여러 구독자가 이벤트를 독립 수신.

```text
[ 점대점(Queue) ]

생산자 A
   ↓
Queue (메시지 보관)
   ↓
소비자 1 ─ 소비자 2
(한 메시지를 한 소비자 처리)
```

```text
[ 발행-구독(Topic) ]

발행자 → 토픽
   ↓        ↓
구독자 A  구독자 B
(각 구독자가 전체 수신)
```

- 모델 선택 : 작업 분담이 목적이면 점대점 큐, 이벤트 전파가 목적이면 발행-구독 토픽.

## Ⅳ. 메시지 큐와 동기 직접 호출(RPC)의 비교

- 핵심 요약 : 메시지 큐는 시간 분리·완충 기반의 비동기 결합, 동기 직접 호출은 즉시 응답·강한 결합이라는 차이.
- 비교 대상 : **RPC** (Remote Procedure Call, 원격 프로시저 호출) 기반의 동기 직접 호출 — 서비스 간 함수 호출처럼 즉시 응답을 기다리는 결합 방식.

| 비교 축 | 메시지 큐 | 동기 직접 호출(RPC) |
|---|---|---|
| 시간적 결합 | 발신·처리 시점 분리 | 호출·응답 시점 일치 |
| 장애 전파 | 버퍼링·재시도로 흡수 | 수신 장애가 호출 측 실패로 전파 |
| 부하 대응 | 폭주 트래픽 버퍼링 | 순간 부하가 수신 한도 초과 |
| 결과 확인 | 최종 처리 결과 기반 | 즉시 응답 수신 |
| 적합 처리 | 배치·이벤트·후속 작업 | 즉시 결과가 필요한 조회·명령 |
| 선택 기준 | 순차성·실시간성 요구가 낮을 때 | 즉시 응답·트랜잭션 일관성 필요 시 |

## Ⅴ. 메시지 큐의 한계와 방안

- 핵심 요약 : 중복 전달·적체·독성 메시지를 멱등성·관측·격리 큐로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 중복 전달 | 재시도 메커니즘 → 같은 처리 반복 | **멱등성** (동일 입력에 동일 결과를 보장하는 처리 성질) 설계·처리 이력 검증 | 중복 처리 건수 |
| 메시지 적체 | 소비 속도 미달 → 지연·저장소 포화 | 큐 깊이 경보·소비자 확장 | 큐 지연 시간 |
| 독성 메시지 | 반복 실패 메시지의 재처리 → 소비 정체 | 재시도 상한 후 **DLQ** (Dead Letter Queue, 격리 큐) 이동·분석 | 격리 메시지 수 |

## Ⅵ. 메시징 체계 정비에 대한 기술사적 제언

- 핵심 요약 : 메시지 계약 표준·운영 관측 체계·설계 기준 명문화의 조직 수준 정비.

- 표준 체계 : 아키텍처 표준 조직이 메시지 스키마·버전·보존 기간·보안 계약을 표준으로 제정.
- 운영 체계 : 큐 깊이·지연·오류 관측과 재처리 리허설의 정례화.
- 설계 기준 : 전달 보장 수준과 멱등성 요구를 서비스 설계 기준서에 명문화.

## Ⅶ. 결론

- 핵심 요약 : 메시지 큐는 시간적 결합 완화와 부하 완충을 제공하는 비동기 통합 수단.
- 신뢰성은 브로커 기능과 소비자의 멱등·재처리 설계가 함께 완성.
