## Ⅰ. 파이썬의 개요

- 핵심 요약 : 파이썬은 동적 타입·객체지향·함수형 기능을 지원하는 범용 고수준 프로그래밍 언어로, 명료한 문법과 광범위한 라이브러리를 제공.
- 개념 : 파이썬은 동적 타입·객체지향·함수형 기능을 지원하는 범용 고수준 프로그래밍 언어로, 명료한 문법과 광범위한 라이브러리를 제공.
- 배경 및 필요성 : 가독성·빠른 개발을 요구하는 업무에서 복잡한 문법 부담을 낮추면서 풍부한 생태계와 이식성 필요.
- 주요 목적 : 개발 생산성과 자동화·데이터·웹 등 다양한 분야의 문제해결을 지원하는 유지 가능한 프로그램 구현.

## Ⅱ. 파이썬의 특징 및 장점

- 핵심 요약 : 핵심 요소: 동적 객체 모델·들여쓰기 기반 블록·예외·모듈·표준 라이브러리·이터레이터·제너레이터. 설계목표는 개발 생산성과 자동화·데이터·웹 등 다양한 분야의 문제해결을 지원하는 유지 가능한 프로그램 구현.

1. 특징 : 동적 객체 모델 : 이름이 실행 중 객체를 참조하고 타입은 객체에 결합 → 유연한 조합과 빠른 개발 지원.
2. 특징 : 들여쓰기 기반 블록 : 문법적으로 블록 구조를 표현 → 코드 가독성과 일관성 강화.
3. 특징 : 예외·모듈·표준 라이브러리 : 오류전파·기능분리·공통기능 활용 → 재사용성과 유지보수성 향상.
4. 특징 : 이터레이터·제너레이터 : 순차 계산을 지연 수행 → 대용량 데이터의 메모리 사용을 조절.

```text

   ↓

   ↓
패키징·의존성 고정
   ↓
```
