## 연관 키워드
- McCabe 순환복잡도, 제어흐름그래프, 독립 경로, 테스트 가능성, 인지복잡도

### Ⅰ. 순환복잡도의 개요

- 핵심 요약 : 순환복잡도는 제어흐름 그래프의 선형 독립 경로 수를 나타내는 코드 구조 지표.
- 개념 : McCabe가 제안한 지표로 조건분기 수와 그래프 연결성에 따라 최소 기저 경로 수를 계산(**순환복잡도**, Cyclomatic Complexity).
- 배경 및 필요성 : 복잡한 분기 구조는 이해·변경·테스트 비용을 높일 수 있음.
- 주요 목적 : 복잡한 모듈을 식별해 시험 설계·리팩토링 우선순위 결정.

### Ⅱ. 순환복잡도의 특징 및 장점

- 핵심 요약 : CFG를 기반으로 독립 경로 수의 하한을 추정해 구조 복잡도와 단위시험 부담을 가시화.

1. 경로 기반 : 각 독립 경로가 적어도 한 개 새로운 간선을 포함 → 기저 경로시험 설계 지원.
2. 분기 민감성 : 의사결정 지점이 늘면 값 증가 → 복잡한 제어구조 식별.
3. 자동화 가능 : 정적분석·CI에서 모듈별 계산 → 품질 게이트·변화추적 활용.

### Ⅲ. 계산식과 적용 (흐름)

- 핵심 요약 : 연결 CFG에서 M=E−N+2, 동등하게 의사결정 노드 수+1로 계산.

```text
CFG의 노드 N, 간선 E, 연결 컴포넌트 P
순환복잡도 M = E − N + 2P
단일 연결 함수(P=1): M = E − N + 2
```

```text
시작 → 조건 A?
       ├ 참 → 처리 X ─┐
       └ 거짓 → 처리 Y ─┤→ 종료
두 분기 경로를 포함하는 기저 경로 집합 구성·시험
```

- 적용 : 함수·메서드 단위로 측정하고 분기 없는 단일 경로의 복잡도는 1.

### Ⅳ. 순환복잡도와 인지복잡도 비교

- 핵심 요약 : 순환복잡도는 경로·분기 구조, 인지복잡도는 사람이 코드를 이해할 때의 제어흐름 난도를 강조.

| 비교 축 | 순환복잡도 | 인지복잡도 |
|---|---|---|
| 계산관점 | CFG의 독립 경로·분기 | 중첩·흐름 단절·이해 노력 |
| 활용 | 기저 경로 시험·복잡 함수 탐지 | 가독성·유지보수 부담 식별 |
| 한계 | 같은 점수라도 구조가 다를 수 있음 | 도구 정의·임계값에 영향 |

### Ⅴ. 순환복잡도의 한계와 방안

- 핵심 요약 : 복잡도 수치만으로 결함·유지보수성을 단정하지 말고 모듈 크기·응집도·시험결과와 함께 해석.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 지표 과신 | 점수 낮은 코드의 결함 간과 | 정적분석·코드리뷰·결함추세 병행 | 결함 발견률 |
| 임계값 일률 적용 | 도메인별 적정 복잡도 차이 무시 | 팀 기준선·변화량·위험으로 게이트 설정 | 임계값 초과 함수 수 |
| 높은 점수의 일괄 분해 | 과도한 추상화·동작 변경 위험 | 복잡한 책임·분기 원인을 먼저 분리하고 회귀시험 | 분해 전후 결함 차이 |

### Ⅵ. 품질관리 제언

- 핵심 요약 : 개발팀은 절대점수보다 변경 시 복잡도 증가와 시험근거를 리뷰에 활용.

1. 팀은 언어·도구별 분기 계산 규칙과 예외를 기준 문서화.
2. CI는 신규·변경 코드의 복잡도 급증을 알리고 품질 게이트로 단계 적용.
3. 리팩토링 우선순위는 복잡도와 결함·변경빈도·업무중요도를 함께 고려.

### Ⅶ. 결론

- 핵심 요약 : 순환복잡도는 CFG 구조에서 독립 경로 수와 최소 경로시험 수를 추정하는 지표.
- 시사점 : 점수는 시험·리팩토링을 안내하는 신호이며 소프트웨어 품질의 단독 판정기준은 아님.
