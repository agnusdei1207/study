## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 테스트·품질 → **McCabe 순환복잡도**

## 30초 인출

- 본질: McCabe 순환복잡도는 프로그램 제어 흐름 그래프에서 선형 독립 경로의 수로 코드의 복잡도를 재는 척도
- 메커니즘: 제어 흐름 그래프의 간선 수 E, 노드 수 N으로 V(G)=E−N+2를 계산하며 분기 노드 수 + 1과 같고 기본 경로 시험의 최소 케이스 수가 됨
- 통찰: 복잡도가 높을수록 시험 경로와 결함 위험이 늘어나므로 임계치(10)를 넘는 모듈은 분할해 시험 가능한 크기로 유지

<details>
<summary>핵심 용어</summary>

- **순환복잡도(Cyclomatic Complexity)** : 제어 흐름 그래프의 선형 독립 경로 수로 나타낸 코드 복잡도. Thomas McCabe 제안
- **제어 흐름 그래프(CFG)** : 코드의 실행 순서를 노드와 간선으로 표현한 그래프
- **기본 경로(Basis Path)** : 다른 경로의 조합으로 표현할 수 없는 독립 경로
- **분기 노드(Predicate Node)** : if·while처럼 둘 이상의 경로로 갈라지는 조건 노드
- **임계치** : 복잡도 관리 기준값. McCabe는 10 이하를 권고

</details>

## 2~4교시 25점 답안

## Ⅰ. McCabe 순환복잡도의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **McCabe 순환복잡도** 는 제어 흐름 그래프의 선형 독립 경로 수로 코드 복잡도를 재는 척도 |
| 목적 | 시험이 필요한 경로 수의 산정과 복잡한 모듈의 식별 |

## Ⅱ. McCabe 순환복잡도의 특징

| 특징 | 의미 |
|---|---|
| 구조 기반 | 코드의 분기 구조만으로 계산 |
| 시험 케이스 수 | 기본 경로 시험의 최소 케이스 수 |
| 유지보수 지표 | 값이 클수록 이해·수정·시험이 어려움 |

## Ⅲ. 계산 방법

### 제어 흐름 그래프와 계산

```text
① 시작
    ↓
② if (a > 0)
    ├─ 참 → ③ ─┐
    └─ 거짓 ────┤
                ↓
          ④ while (b < 10)
              ├─ 참 → ⑤ (④로 복귀)
              └─ 거짓 → ⑥ 종료

E = 7, N = 6 → V(G) = 7 − 6 + 2 = 3 (분기 노드 2개 + 1)
```

### 확대: 계산식의 동치

```text
V(G) = E − N + 2P            (P: 연결 요소 수, 단일 프로그램은 1)
     = 분기 노드 수 + 1
     = 그래프가 나누는 영역의 수
```

## Ⅳ. 활용과 다른 척도와의 관계

| 구분 | 내용 |
|---|---|
| 시험 활용 | 기본 경로 시험에서 V(G)개의 독립 경로를 시험 |
| 품질 관리 | 임계치(10)를 넘는 모듈의 분할·리팩토링 대상 지정 |
| 한계 | 분기 수만 반영해 중첩 구조·데이터 복잡도 미반영 |

| 비교 | 순환복잡도 | 코드 라인 수(LOC) |
|---|---|---|
| 측정 대상 | 제어 흐름의 분기 | 코드 길이 |
| 시험 관련성 | 시험 경로 수와 직결 | 간접 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 임계치를 넘는 복잡한 모듈의 시험·수정 곤란 | 메서드 추출 등으로 분할해 임계치 이내 유지 |
| 분기 수가 같아도 중첩 깊이에 따른 이해 난이도 차이 | 중첩 깊이 등 다른 지표 병행 |
| 지표 수치만 맞추려는 왜곡 | 복잡도 초과 모듈의 시험 케이스 충족 여부 함께 점검 |

## Ⅵ. 제언

순환복잡도가 임계치(10)를 넘는 모듈은 분할 대상으로 지정하고, 분할 후 기본 경로 수만큼 시험 케이스 확보

### 복잡도 관리 절차

```text
정적 분석으로 모듈별 V(G) 측정
    ↓
임계치 초과 모듈 선별
    ↓
분할·리팩토링 → V(G) 재측정 → 기본 경로 시험
```

### 확대: 판정

```text
V(G)
    ├─ 10 이하 → 유지
    └─ 10 초과 → 분할 후 재측정
```

### 선택 근거: 측정만 하는 방식과의 비교

| 구분 | 측정·보고만 | 제언: 임계치 기반 분할 |
|---|---|---|
| 조치 | 없음 | 초과 모듈 분할 |
| 시험 대응 | 경로 수 미확보 | V(G)만큼 확보 |
| 품질 효과 | 관찰 | 복잡도 억제 |
