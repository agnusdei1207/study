## 연관 키워드

- 블랙박스 시험(Black-Box Test), 명세 기반 시험(Specification-Based Test), 동등분할(Equivalence Partitioning), 경계값 분석(Boundary Value Analysis)
- 결정표 시험(Decision Table Testing), 상태 전이 시험(State Transition Testing), 화이트박스 시험(White-Box Test)

## Ⅰ. 블랙박스 시험의 개요

- 핵심 요약 : 내부 구조와 무관하게 명세를 기준으로 입력·출력 관계를 검증하는 시험 기법 체계.
- 개념 : 프로그램 내부 코드를 보지 않고 요구사항·인터페이스 명세에 근거해 입력에 대한 출력과 상태 변화를 확인하는 시험이 **블랙박스 시험** (Black-Box Test)이며, 명세에서 시험 케이스를 도출하는 **명세 기반 시험** (Specification-Based Test)과 동일 관점.
- 배경 및 필요성 : 전수 시험이 불가능한 조건에서 사용자 관점의 요구 충족 여부를 구현 세부와 독립적으로 판단할 체계 필요.
- 주요 목적 : 명세 불일치·누락, 경계 처리 오류, 조건 조합·상태 처리 결함의 발견.

## Ⅱ. 명세 기반 시험 기법의 특징 및 장점

- 핵심 요약 : 입력 공간·조건 조합·상태를 체계로 나누어 대표 조건만으로 명세의 결함을 검증.

1. 동등분할 : 같은 처리가 기대되는 입력군을 등급으로 나누고 대표값만 시험 → 시험 케이스 수의 대폭 절감.
2. 경계값 분석 : 등급 경계와 그 직전·직후 값의 선정 → 비교·범위 판정 오류의 집중 탐지.
3. 결정표 시험 : 여러 조건의 조합별 행동을 표로 정리 → 복합 업무 규칙의 누락·모순 발견.
4. 상태 전이 시험 : 상태·이벤트·전이 규칙을 모델로 검증 → 이벤트 순서 의존 결함 발견.
5. 구현 독립성 : 기대 결과의 명세 우선 정의 → 개발자 관점이 아닌 사용자 관점의 검증.

## Ⅲ. 블랙박스 시험 설계의 구조 (흐름)

- 핵심 요약 : 명세를 입력 조건으로 모델링한 뒤 기법별 대표값과 기대 결과를 정의하고 실행·판정.

```text
명세 분석
   ↓
입력 조건의 유효·무효 분류
   ↓
기법별 대표값·조합 선정
   ↓
기대 결과 사전 정의
   ↓
실행·판정·결함 기록
```

```text
입력 범위: 1 이상 100 이하 조건 예시
 0  → 무효 (경계 직전값)
 1  → 유효 (최솟값)
100 → 유효 (최댓값)
101 → 무효 (최댓값 초과)
```

- 기법 선택 : 값 범위는 동등분할·경계값 분석, 규칙 조합은 결정표 시험, 이력 의존 동작은 상태 전이 시험.

## Ⅳ. 블랙박스 시험과 화이트박스 시험의 비교

- 핵심 요약 : 블랙박스 시험이 명세상 누락·오류를 찾는 동안 **화이트박스 시험** (White-Box Test)은 코드 내부 경로의 미실행을 찾는 상호 보완 관계.

| 비교 축 | 블랙박스 시험 | 화이트박스 시험 (White-Box Test) |
| --- | --- | --- |
| 근거 정보 | 요구·인터페이스 명세 | 코드·제어 흐름 |
| 시험 관점 | 사용자·업무의 외부 동작 | 내부 분기·경로 구조 |
| 탐지 결함 | 명세 누락·범위·조합·상태 처리 오류 | 미실행 분기·죽은 코드·논리 오류 |
| 대표 기법 | 동등분할·경계값 분석·결정표 시험·상태 전이 시험 | 문장·분기·조건 커버리지 기반 시험 |
| 보완 방향 | 구조 커버리지 시험으로 보완 | 명세 기반 케이스로 보완 |

## Ⅴ. 블랙박스 시험의 한계와 방안

- 핵심 요약 : 명세 품질 의존·내부 경로 미확인·조합 폭발을 명세 리뷰와 기법 결합으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 명세 품질 의존 | 명세 자체 오류가 시험 기준이 되어 미발견 | 명세 리뷰·프로토타입 확인 병행 | 명세 기인 결함 수 |
| 내부 경로 미확인 | 미실행 코드·숨은 분기 잔존 | 화이트박스 시험과 병행 수행 | 분기 미실행률 |
| 조합 폭발 | 조건 수 증가로 전수 검증 불가 | 위험 기반 선정·직교 배열 기법 적용 | 조합 커버리지율 |

## Ⅵ. 시험 설계 거버넌스에 대한 제언

- 핵심 요약 : 추적성·기준 합의·결함 환류의 절차로 명세 기반 시험의 판정 신뢰를 조직 차원에서 확보.

1. 품질보증(QA, Quality Assurance) 조직은 시험 케이스마다 명세 근거 항목을 연결해 요구 추적성을 유지.
2. 개발·시험 공동 리뷰에서 경계·예외·상태 규칙을 사전 합의해 기대 결과의 해석 차이 제거.
3. 결함 분석 결과를 명세 결함과 구현 결함으로 구분 집계하고 집계 결과를 요구 정의 프로세스 개선에 환류.

## Ⅶ. 결론

- 핵심 요약 : 블랙박스 시험은 사용자에게 약속된 동작을 검증하는 명세 기반 품질 활동.
- 시사점 : 입력값 설계만큼 기대 결과의 명세 근거 확보가 판정 신뢰를 결정.
