## 연관 키워드

- 기능 안전, IEC 61508, 안전 생명주기, 위험 분석, SIL, ISO 26262, ASIL

## Ⅰ. 기능 안전의 개요

- 핵심 요약 : 기능 안전은 안전 관련 시스템이 위험 상태를 제어하거나 안전 상태로 전환하도록 요구·설계·검증하는 활동.
- 개념 : **기능 안전**(Functional Safety)은 시스템의 올바른 기능 수행 또는 고장 시 안전 관련 제어 기능에 의존하는 전체 안전의 일부.
- 배경 및 필요성 : 소프트웨어·전자 제어 고장은 사람·환경·재산에 위해를 줄 수 있어 위험 기반 생명주기와 증거 필요.
- 주요 목적 : 허용 불가 위험을 식별하고 안전 요구사항과 검증 활동으로 체계적으로 감소.

## Ⅱ. 원칙 및 표준

- 핵심 요약 : 위험 분석에서 도출한 안전 요구를 추적하고 독립성·검증 수준을 위험에 비례시킴.
- IEC 61508 : 전기·전자·프로그램 가능한 전자 안전 관련 시스템의 기본 기능 안전 표준군.
- SIL(Safety Integrity Level) : 안전 기능의 요구 무결성 수준을 분류하는 체계이며 표준의 요구에 따라 설계·검증 엄격성이 달라짐.
- ISO 26262 : 도로 차량 전기·전자 시스템의 기능 안전 표준군이며 위험 분석에서 ASIL(Automotive Safety Integrity Level)을 도출.
- 안전 생명주기 : 위험 분석부터 요구·설계·구현·검증·운영·폐기까지 안전 활동과 증거 관리.

## Ⅲ. 안전 생명주기 흐름

- 핵심 요약 : 위험 식별·분류에서 안전 목표와 요구사항을 도출하고 구현·검증 후 운영 변경까지 추적.

```text
시스템 정의·위험 분석
  ↓ 안전 목표·무결성 할당
안전 요구사항·아키텍처
  ↓ 구현·검증·독립 평가
통합·안전 확인
  ↓ 운영·변경·사고 피드백
```

```text
위험 원인 → 안전 목표 → 안전 요구사항
         → 설계 요소 → 시험·분석 증거
         → 잔여 위험 승인
```

- HARA(Hazard Analysis and Risk Assessment)는 차량 분야에서 위험 상황과 운용 조건을 평가해 안전 목표 및 ASIL 할당을 지원.

## Ⅳ. 기능 안전과 관련 개념 비교

- 핵심 요약 : 기능 안전은 고장·오동작 제어를 다루며 SOTIF와 사이버보안은 겹치지만 별도 관점.

| 비교 축 | 기능 안전 | SOTIF | 사이버보안 |
| --- | --- | --- | --- |
| 중심 위험 | 시스템 고장·오동작 | 고장 없이 의도 기능의 성능 한계·예측 가능한 오용 | 악의적 공격·권한 침해 |
| 대표 체계 | IEC 61508, ISO 26262 | ISO 21448 | IEC 62443 등 분야 표준 |
| 대응 | 안전 생명주기·무결성 요구 | 운용 시나리오·성능 한계 분석 | 위협 분석·보안 통제 |
| 관계 | 전체 안전의 일부 | 차량 안전과 보완 관계 | 안전과 상호 영향 분석 필요 |

## Ⅴ. 한계와 방안

- 핵심 요약 : 복잡한 상호작용·불완전한 운용 시나리오·증거 누락을 독립 검토와 추적성으로 줄임.

| 한계 | 원인·영향 | 대응 방안 |
| --- | --- | --- |
| 위험 시나리오 누락 | 환경·운용 조건 복잡 | 다학제 분석·현장 데이터·주기적 재평가 |
| 요구 추적 단절 | 설계 변경과 안전 분석 분리 | 안전 요구-코드-시험 증거 양방향 추적 |
| 공통 원인 고장 | 중복 시스템의 동일 결함 | 독립성 분석·다양성·공통 원인 검토 |
| 변경 후 안전성 저하 | 현장 업데이트·부품 교체 | 영향 분석·재검증·구성 관리 |

## Ⅵ. 안전 거버넌스 제언

- 핵심 요약 : 사업 책임자는 안전 책임·독립 검증·변경 승인·잔여 위험 수용 권한을 명확히 지정.
- 안전 담당자는 적용 표준 판본과 시스템 범위를 정하고 생명주기별 산출물과 독립성 수준을 계획.
- 운영 조직은 사고·근접 사고와 업데이트 이력을 안전 사례에 반영하고 재인증 필요성을 평가.

## Ⅶ. 결론

- 핵심 요약 : 기능 안전은 안전 관련 기능의 위험을 분석하고 요구·구현·검증을 생명주기 전체에 걸쳐 관리하는 체계.
- 표준 준수 증거와 운용 조건의 현실성이 함께 확보되어야 안전성 주장이 신뢰 가능.
