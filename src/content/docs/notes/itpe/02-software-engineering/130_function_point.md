## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 프로젝트 관리 → **기능점수(Function Point)**

## 30초 인출

- 본질: 기능점수(FP)는 사용자 관점의 기능(데이터 기능·트랜잭션 기능)을 복잡도에 따른 점수로 환산해 소프트웨어 규모를 재는 방식
- 메커니즘: 애플리케이션 경계를 정하고 ILF·EIF·EI·EO·EQ를 식별해 복잡도별 가중치로 미조정 FP를 구한 뒤 조정 계수를 곱해 조정 FP를 산출
- 통찰: 같은 기능을 여러 유형으로 중복 식별하거나 경계를 다르게 잡으면 점수가 크게 달라지므로 산정 전에 경계와 식별 기준을 정하고 근거를 기능 목록에 남김

<details>
<summary>핵심 용어</summary>

- **기능점수(FP, Function Point)** : 사용자 관점 기능을 점수화한 소프트웨어 규모 측정 단위
- **ILF(Internal Logical File)** : 애플리케이션 내부에서 유지·관리되는 논리적 데이터 그룹
- **EIF(External Interface File)** : 다른 시스템이 유지하며 이 애플리케이션이 참조만 하는 데이터 그룹
- **EI(External Input)** : 경계 밖에서 들어와 내부 데이터를 바꾸는 입력 처리
- **EO(External Output)** : 계산·가공을 거쳐 경계 밖으로 나가는 출력 처리
- **EQ(External Inquiry)** : 가공 없이 데이터를 조회해 내보내는 처리
- **DET·RET·FTR** : 데이터 요소 유형, 레코드 요소 유형, 참조 파일 유형. 복잡도 판정에 사용

</details>

## 2~4교시 25점 답안

## Ⅰ. 기능점수의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **기능점수** 는 사용자 관점 기능을 복잡도에 따라 점수로 환산해 소프트웨어 규모를 재는 방식 |
| 목적 | 구현 기술과 무관한 규모 산정과 비용 산정의 근거 제공 |

## Ⅱ. 코드 라인 수와 구별되는 특징

| 특징 | 의미 |
|---|---|
| 사용자 관점 | 기능 기준의 측정 |
| 언어 독립 | 프로그래밍 언어와 무관 |
| 요구 단계 산정 | 요구 분석 후 산정 가능 |

## Ⅲ. 산정 절차와 기능 유형

### 산정 절차

```text
애플리케이션 경계 정의
    ↓
기능 식별 (데이터 기능·트랜잭션 기능)
    ↓
복잡도 판정 (DET·RET·FTR) → 가중치 적용 → 미조정 FP
    ↓
조정 계수 적용 → 조정 FP
```

### 확대: 기능 유형

```text
기능점수
    ├─ 데이터 기능 ── ILF(내부 파일)·EIF(외부 인터페이스 파일)
    └─ 트랜잭션 기능 ── EI(입력)·EO(출력)·EQ(조회)
```

## Ⅳ. 유형별 가중치와 조정

### 복잡도별 가중치(IFPUG)

| 유형 | 낮음 | 보통 | 높음 |
|---|---|---|---|
| ILF | 7 | 10 | 15 |
| EIF | 5 | 7 | 10 |
| EI | 3 | 4 | 6 |
| EO | 4 | 5 | 7 |
| EQ | 3 | 4 | 6 |

### 조정

| 단계 | 내용 |
|---|---|
| 미조정 FP | 식별한 기능의 가중치 합 |
| 조정 계수 | 일반 시스템 특성 14개를 0~5로 평가해 0.65 + 0.01 × 합계로 산출 |
| 조정 FP | 미조정 FP × 조정 계수 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 경계·식별 기준에 따라 점수 편차 | 산정 전 경계와 식별 기준 합의 |
| 같은 기능의 중복 산정 | 기능 목록에 식별 근거 기록 |
| 비기능 요구 미반영 | 비기능 요구는 조정 계수나 별도 항목으로 반영 |

## Ⅵ. 제언

산정 전에 애플리케이션 경계와 식별 기준을 정하고, 기능 목록에 유형·복잡도 판정 근거를 남겨 재현 가능하게 산정

### 재현 가능한 산정

```text
경계·식별 기준 합의
    ↓
기능 목록(유형·DET·RET·FTR·근거) 작성
    ↓
가중치 적용 → 검토자 재산정 대조
```

### 확대: 변경 시 재산정

```text
요구 변경 → 기능 목록에서 변경 기능만 재판정 → 점수 갱신
```

### 선택 근거: 경험 추정과의 비교

| 구분 | 경험 추정 | 제언: 근거 기록 산정 |
|---|---|---|
| 재현성 | 낮음 | 높음 |
| 변경 대응 | 전체 재추정 | 변경 기능만 재산정 |
| 검토 | 곤란 | 근거로 검토 |
