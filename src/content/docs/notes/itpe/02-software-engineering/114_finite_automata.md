지식 위치: 소프트웨어공학 → 정형 기법 및 계산 이론 → **유한 오토마타(Finite Automata)**

---

## 30초 인출

- 본질: **유한 오토마타 (FA: Finite Automata)** 는 시스템이 가질 수 있는 유한한 개수의 상태(States)와 입력 기호(Symbols)에 따른 전이 함수(Transition Function)를 바탕으로 주어진 입력 문자열이 특정 정규 언어(Regular Language) 규칙을 만족하는지 판정하는 추상 계산 모델
- 메커니즘: 시작 상태($q_0$) 설정 → 입력 기호 순차 소비 및 전이 함수($\delta$) 적용 → 모든 입력 소진 후 최종 도달 상태가 수용 상태 집합($F$)에 속하는지 여부에 따라 수용(Accept) 또는 거부(Reject) 판정
- 통찰: 비결정적 오토마타(NFA)는 모델링이 직관적이나 실행 시 백트래킹 오버헤드가 발생하므로 부분집합 구성법(Subset Construction)을 통해 결정적 오토마타(DFA)로 변환하고 상태 최소화(Minimization)를 적용해야 컴파일러 어휘 분석 및 프로토콜 검증의 실행 성능을 최적화할 수 있음

<details>
<summary>핵심 용어</summary>

- **5-튜플 (5-tuple)** : 유한 오토마타를 수학적으로 정의하는 5가지 구성요소 $M = (Q, \Sigma, \delta, q_0, F)$
- **DFA (Deterministic Finite Automaton)** : 주어진 현재 상태와 단일 입력 기호에 대해 전이할 다음 상태가 오직 1개로 유일하게 결정되는 오토마타
- **NFA (Nondeterministic Finite Automaton)** : 동일 입력에 대해 복수의 다음 상태로 분기하거나 입력 기호 소비 없이 이동하는 $\epsilon$-전이를 허용하는 오토마타
- **정규 언어 (Regular Language)** : 유한 오토마타에 의해 인식될 수 있는 언어들의 집합으로 정규 표현식(Regex)과 1:1 동치 관계
- **부분집합 구성법 (Subset Construction)** : NFA의 상태들의 거듭제곱 집합($2^Q$)을 단일 상태로 취급하여 동등한 표현력의 DFA로 변환하는 알고리즘

</details>

## 2~4교시 예상문제 (25점)

> 정형 기법 및 컴파일러 어휘 분석의 기반인 유한 오토마타(Finite Automata)의 5-튜플 형식 정의와 동작 원리를 설명하고, 결정적 유한 오토마타(DFA)와 비결정적 유한 오토마타(NFA)의 비교, NFA를 DFA로 변환하는 부분집합 구성법(Subset Construction) 및 소프트웨어 공학적 응용 분야를 제시하시오.

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 유한한 수의 상태와 입력 알파벳에 의해 상태 전이를 수행하며, 입력 문자열의 문법적 유효성과 정규 언어 소속 여부를 판정하는 수학적 계산 기계 모델 |
| 목적 | 컴파일러 어휘 분석기(Lexer)의 정규표현식 토큰 파싱, 통신 프로토콜 무결성 검증, 디지털 회로 및 소프트웨어 상태 머신(FSM)의 정형 명세 |

## Ⅱ. 핵심 특징

유한한 메모리(상태)만을 사용하여 무한한 길이의 입력 스트림에 대한 결정론적 판정 제공.

| 5-튜플 요소 | 수학적 기호 | 의미 및 공학적 역할 |
|---|---|---|
| **상태 집합 (States)** | $Q$ | 오토마타가 가질 수 있는 모든 상태들의 유한 집합 ($q_0, q_1, q_2, \dots$) |
| **입력 알파벳 (Alphabet)** | $\Sigma$ | 시스템에 입력될 수 있는 유효한 기호들의 유한 집합 (예: $\{0, 1\}, \{a, b\}$) |
| **전이 함수 (Transition)** | $\delta$ | 현재 상태와 입력 기호를 매핑하는 함수 (DFA: $Q \times \Sigma \rightarrow Q$) |
| **시작 상태 (Initial State)** | $q_0$ | 문자열 입력을 처리하기 전의 초기 기저 상태 ($q_0 \in Q$) |
| **수용 상태 집합 (Final States)** | $F$ | 입력 완료 시 문자열을 유효(Accept)로 판정하는 상태들의 부분집합 ($F \subseteq Q$) |

## Ⅲ. 체계·프로세스

문자열 판정 프로세스 및 NFA의 DFA 변환(부분집합 구성법) 체계.

```text
+---------------------------------------------------------------------------------------------------------+
|                                    유한 오토마타 문자열 판정 및 NFA-DFA 변환 체계                        |
+---------------------------------------------------------------------------------------------------------+
                                                                                                           
  [1] DFA 문자열 "ab" 판정 흐름                                                                            
                                                                                                           
         (q0) 시작 ────────── 입력 'a' 소비 ──────────> (q1) ────────── 입력 'b' 소비 ──────────> ((q2))  
                                                                                                   수용!   
  * 판정: 입력 종료 시 최종 상태가 수용 상태 q2 ∈ F에 도달하였으므로 "Accept"                            
                                                                                                           
───────────────────────────────────────────────────────────────────────────────────────────────────────────
  [2] 부분집합 구성법 (Subset Construction : NFA ──> DFA 변환)                                            
                                                                                                           
  NFA의 다중 분기 상태들을 묶어 단일 DFA 상태로 합성                                                      
                                                                                                           
  [ NFA 상태 ]                   '0' 입력 전이                    [ DFA 합성 상태 ]                        
  +─────────────────────+     ─────────────────────>             +─────────────────────────+              
  | q0 ──0──> q0, q1    |                                        | State A = {q0, q1}      |              
  +─────────────────────+                                        +─────────────────────────+              
                                                                              │                            
                                                                              │ '1' 입력 전이              
                                                                              ▼                            
                                                                 +─────────────────────────+              
                                                                 | State B = {q1, q2} (F)  | (수용 상태 포함)
                                                                 +─────────────────────────+              
```

- **부분집합 구성법(Subset Construction) 3단계 프로세스**:
  1. **초기 상태 집합 도출** : NFA의 시작 상태 $q_0$와 $\epsilon$-전이로 도달 가능한 모든 상태를 묶어 DFA의 시작 상태 $S_0 = \epsilon\text{-closure}(q_0)$ 생성.
  2. **전이 집합 계산** : 생성된 각 DFA 상태 $S$에 대해 모든 입력 기호 $a \in \Sigma$를 인가했을 때 도달하는 상태들의 합집합 $\epsilon\text{-closure}(\delta(S, a))$ 도출.
  3. **수용 상태 확정** : 합성된 DFA 상태 집합 중 NFA의 원래 수용 상태($F_{NFA}$)를 하나라도 포함하고 있는 상태들을 DFA의 최종 수용 상태($F_{DFA}$)로 지정.

## Ⅳ. 종류·비교

#### 결정적 유한 오토마타(DFA) vs 비결정적 유한 오토마타(NFA) 비교

| 비교 항목 | DFA (Deterministic) | NFA (Nondeterministic) |
|---|---|---|
| **전이 함수의 형태** | $\delta : Q \times \Sigma \rightarrow Q$ (다음 상태가 정확히 1개) | $\delta : Q \times (\Sigma \cup \{\epsilon\}) \rightarrow 2^Q$ (복수 상태 분기) |
| **$\epsilon$-전이 (Empty Move)**| 허용 불가 (반드시 입력을 소비해야 전이) | 허용 가능 (입력 소비 없이 상태 이동 가능) |
| **언어 표현력** | 정규 언어 (Regular Language) 인식 | 정규 언어 인식 (**DFA와 수학적 표현 능력 100% 동일**) |
| **문자열 인식 속도** | $O(N)$ (문자열 길이에 선형 비례하여 초고속) | $O(N \times |Q|^2)$ (상태 추적 오버헤드 또는 백트래킹) |
| **상태 수 및 메모리** | 상태 수가 최악의 경우 지수승($2^{|Q|}$) 폭증 | 상태 수가 적고 모델링이 매우 직관적이고 간결함 |
| **실제 적용 분야** | 렉서(Lexer) 런타임 실행 엔진, 하드웨어 회로 | 정규표현식 파서 초기 설계, 텍스트 검색 알고리즘 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| NFA를 DFA로 변환 시 상태 수가 $2^N$으로 기하급수적으로 폭증하는 상태 폭발(State Explosion) 발생 | 호프크로프트(Hopcroft) 알고리즘을 적용하여 동등 상태를 병합하는 DFA 상태 최소화(Minimization) 필수 수행 |
| 괄호 쌍 매칭($a^n b^n$)이나 회문(Palindrome)과 같은 중첩 문맥 자유 언어(CFL) 인식 불가 | 무한 스택 메모리를 탑재한 푸시다운 오토마타(PDA) 또는 튜링 머신(Turing Machine) 모델로 확장 적용 |
| 복잡한 정규식 처리 시 악의적 입력에 의해 지수 시간 탐색이 발생하는 정규식 서비스 거부(ReDoS) 위험 | 백트래킹 기반 엔진 대신 Thompson NFA 기반 선형 시간 보장 정규식 엔진(Google RE2) 도입 |

## Ⅵ. 제언

유한 오토마타는 이론적 계산 모델을 넘어 현대 소프트웨어의 상태 머신 설계(FSM)와 네트워크 침입 탐지 시스템(IDS)의 핵심 기반이므로, 모델링 초기에는 NFA로 간결하게 표현하고 실행 단계에서는 최소화된 DFA로 컴파일하는 파이프라인 수립이 필수적임.

```text
[정규표현식 / 프로토콜 설계] ──> [Thompson 알고리즘 (NFA 생성)] ──> [부분집합 구성법 (DFA 변환)] ──> [Hopcroft 최소화]
    (토큰 패턴 정의)                    (직관적 모델링)                 (결정론적 단일 전이)          (최소 상태 초고속 실행)
```

| 응용 분야 | 오토마타 활용 방식 | 공학적 효과 |
|---|---|---|
| **컴파일러 렉서** | Lex / Flex 도구를 통한 DFA 소스코드 자동 생성 | 소스코드 텍스트의 초고속 토큰 분해 달성 |
| **네트워크 보안** | Snort / Suricata IDS의 시그니처 패턴 매칭 엔진 | 기가비트 네트워크 패킷의 실시간 침입 탐지 |
| **상태 머신 구현** | GoF State Pattern 및 Spring StateMachine 연계 | 비즈니스 도메인의 불법 상태 전이 원천 방지 |
