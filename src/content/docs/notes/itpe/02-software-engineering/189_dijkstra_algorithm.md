## 30초 인출

- 본질: **다익스트라 알고리즘** 은 음수 간선이 없는 그래프에서 한 시작점부터 각 정점까지의 최단 거리를 구하는 알고리즘
- 메커니즘: 거리 초기화 → 최소 거리 정점 선택 → 인접 간선 완화 → 더 짧은 경로가 없을 때까지 반복
- 통찰: 한계: 음수 간선이 있으면 추출한 최소 거리의 확정이 뒤집힐 수 있음 → 방안: 비음수 조건을 먼저 확인하고 경로 복원에는 선행 정점을 기록

<details>
<summary>핵심 용어</summary>

- **간선 완화(Edge Relaxation)** : 정점 `u`를 거쳐 `v`로 가는 거리가 현재 기록보다 짧을 때 `dist[v]`를 갱신하는 연산
- **우선순위 큐(Priority Queue)** : 현재까지 알려진 거리가 가장 짧은 정점을 빠르게 선택하는 자료구조
- **최단 경로 트리(Shortest Path Tree, SPT)** : 시작점에서 도달 가능한 정점들의 최단 경로를 부모 관계로 표현한 구조
- **OSPF(Open Shortest Path First)** : 링크 상태 정보를 바탕으로 각 라우터가 최단 경로를 계산하는 라우팅 프로토콜
</details>

## 2~4교시 25점 답안

## Ⅰ. 다익스트라 알고리즘의 개요

| 구분 | 내용 |
|---|---|
| 정의 | **다익스트라 알고리즘** 은 비음수 간선 그래프의 단일 시작점 최단 경로 알고리즘 |
| 목적 | 시작점에서 각 정점까지의 최소 비용 계산 |

## Ⅱ. 다익스트라 알고리즘의 특징

| 특징 | 의미 |
|---|---|
| 비음수 가중치 전제 | 확정한 최소 거리가 뒤집히지 않음 |
| 탐욕적 정점 선택 | 현재 최소 거리의 미확정 정점부터 처리 |
| 경로 복원 가능 | 거리 갱신 때 선행 정점을 함께 기록 |

## Ⅲ. 정점 선택과 간선 완화 체계

```text
시작점 거리 0·나머지 무한대
    ↓ 최소 거리 미확정 정점 추출
인접 간선 완화·갱신 정점 큐 삽입
    ↓ 후보가 남으면 반복
최단 거리·선행 정점으로 경로 복원
```

### 한 간선의 거리 갱신

```text
u까지 거리 4 + 간선 비용 3 = 새 후보 거리 7
                         │
                         ↓
v의 기존 거리 10과 비교: 7 < 10
                         │
                         ↓
v의 거리 7로 갱신·선행 정점 u 기록
```

**완화 조건:** `dist[v] > dist[u] + w(u,v)`. 선행 정점을 저장하면 최단 경로도 복원 가능.

## Ⅳ. 구현별 복잡도와 적용 조건

| 단계 | 수행 내용 |
|---|---|
| 초기화 | `dist[start]=0`, 나머지는 무한대로 설정 |
| 정점 선택 | 알려진 거리의 최소값을 우선순위 큐에서 추출 |
| 인접 간선 완화 | 더 짧은 거리면 갱신하고 큐에 삽입 |
| 종료 | 큐가 비면 모든 도달 가능 정점의 거리 확정 |

| 구현 | 시간복잡도 | 적합한 경우 |
|---|---|---|
| 배열 기반 선택 | `O(V² + E)` | 작은 그래프 또는 밀집 그래프 |
| 인접 리스트 + 이진 힙 | `O((V+E) log V)` | 희소 그래프 |

### 적용 조건과 다른 알고리즘

| 조건 | 판단 |
|---|---|
| 음수 간선 없음 | 다익스트라 적용 가능 |
| 음수 간선 존재 | 벨만–포드 등 다른 알고리즘 검토 |
| 단일 목적지와 적절한 휴리스틱 | A* 적용 검토 |
| 모든 정점 쌍의 거리 필요 | 플로이드–워셜 등 검토 |

**음수 간선** 이 있으면 최소 거리 정점을 확정해도 나중에 더 짧아질 수 있으므로 탐욕적 선택의 근거가 깨짐.

### 정보시스템 활용

| 활용 | 최단 경로의 의미 |
|---|---|
| 네트워크 라우팅 | OSPF의 링크 비용을 바탕으로 목적지까지 경로 계산 |
| 서비스 경로 탐색 | 그래프 모델로 표현한 연결 비용의 최소화 |

OSPF에서는 각 라우터가 링크 상태 데이터베이스를 바탕으로 최단 경로 트리를 계산. 실제 전달 경로에는 라우팅 정책도 관여.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 음수 간선이 있으면 거리 확정이 뒤집힘 | 간선의 비음수 조건을 먼저 확인하고 벨만–포드 등 대안 적용 |
| 도달 불가 정점을 유한 거리로 오판 | 무한대 초기값을 유지하고 도달 가능 여부를 별도 표시 |
| 동일 비용 경로에서 재현성 부족 | 동점 처리 규칙과 선행 정점 기록 정책 정의 |

## Ⅵ. 제언

우선 실행: 간선 가중치의 비음수 조건을 검증하고 도달 불가·동일 비용·거리 갱신 사례를 시험.
