## 30초 인출

- 본질: 다익스트라 알고리즘은 음수 가중치가 없는 그래프에서 시작 정점부터 모든 정점까지의 최단 거리를 구하는 알고리즘
- 메커니즘: 확정되지 않은 정점 중 현재 거리가 가장 작은 정점을 확정하고 그 정점에서 나가는 간선으로 이웃의 거리를 갱신하는 과정을 반복
- 통찰: 가장 가까운 정점을 확정한다는 전제는 음수 간선이 있으면 깨지므로 음수 간선 유무를 먼저 확인하고 우선순위 큐로 가장 작은 거리를 빠르게 선택

<details>
<summary>핵심 용어</summary>

- **다익스트라 알고리즘** : 가까운 정점부터 최단 거리를 확정하는 최단경로 알고리즘
- **간선 완화(Relaxation)** : 더 짧은 경로가 발견되면 정점의 거리를 갱신하는 것
- **우선순위 큐(Priority Queue)** : 가장 작은 값을 빠르게 꺼내는 자료구조
- **최단 경로 트리** : 시작 정점에서 각 정점까지의 최단 경로로 이루어진 트리
- **OSPF** : 다익스트라 알고리즘을 쓰는 링크 상태 라우팅 프로토콜

## 2~4교시 25점 답안

## Ⅰ. 다익스트라 알고리즘의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **다익스트라 알고리즘** 은 음수 간선이 없는 그래프에서 시작점에서 각 정점까지의 최단 거리를 구하는 알고리즘 |
| 목적 | 최소 비용 경로의 효율적 계산 |

## Ⅱ. 특징

| 특징 | 의미 |
|---|---|
| 탐욕적 확정 | 가장 가까운 정점부터 확정 |
| 음수 간선 불가 | 확정된 거리가 이후 줄지 않는다는 전제 |
| 우선순위 큐 | 최소 거리 정점의 빠른 선택 |

## Ⅲ. 동작 예

```text
    ┌─(2)─▶ B ─(3)─┐
   A                ▶ D        A에서 시작
    └─(5)─▶ C ─(1)─┘
    (B→C 간선 1 있음)
```

| 단계 | 확정 정점 | A | B | C | D |
|---|---|---|---|---|---|
| 초기 | - | 0 | ∞ | ∞ | ∞ |
| 1 | A | 0 | 2 | 5 | ∞ |
| 2 | B | 0 | 2 | 3 | 5 |
| 3 | C | 0 | 2 | 3 | 4 |
| 4 | D | 0 | 2 | 3 | 4 |

B를 확정하며 C가 5에서 3으로, C를 확정하며 D가 5에서 4로 갱신됨

## Ⅳ. 다른 최단경로 알고리즘과의 비교

| 구분 | 다익스트라 | 벨만-포드 | A* |
|---|---|---|---|
| 음수 간선 | 불가 | 가능 | 불가 |
| 탐색 방향 | 전방위 | 전체 간선 반복 | 목표 방향 |
| 시간 | O((V+E) log V) | O(VE) | 휴리스틱에 의존 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 음수 간선에서 오답 | 벨만-포드 사용 |
| 목표가 하나인데 전 정점 탐색 | 목표 도달 시 종료 또는 A* 사용 |
| 단순 배열로 선택 시 느림 | 우선순위 큐(힙) 사용 |

## Ⅵ. 제언

음수 간선이 없음을 확인하고 우선순위 큐로 구현

```text
음수 간선 있음? ─ 예 → 벨만-포드
               └ 아니오 → 다익스트라(우선순위 큐)
```

| 구분 | 배열 선택 O(V²) | 제언: 우선순위 큐 |
|---|---|---|
| 희소 그래프 | 느림 | 빠름 |
| 구현 | 단순 | 힙 필요 |
