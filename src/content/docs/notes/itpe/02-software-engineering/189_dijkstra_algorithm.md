## 지식 로드맵 내 현재 위치

소프트웨어 공학 → 그래프 알고리즘·최단 경로 → 다익스트라 알고리즘(Dijkstra Algorithm)

## 지식 위치

소프트웨어공학 > 그래프 알고리즘 > 다익스트라 알고리즘

## 30초 인출

- 본질: 가중치 그래프에서 음수 간선이 존재하지 않는다는 전제하에, 단일 출발 노드로부터 다른 모든 노드까지의 최단 거리를 탐욕적(Greedy) 기법과 우선순위 큐로 구하는 알고리즘
- 메커니즘: 출발 노드 거리 0 초기화 → 미방문 노드 중 최단 거리 노드 추출(Min-Heap) → 인접 간선 완화(Relaxation: $D[v] > D[u] + w(u,v)$) → 거리 갱신 및 힙 삽입 반복 → 최단 경로 트리(SPT) 완성
- 통찰: 음수 가중치 간선 존재 시 이미 확정된 노드의 최단 거리가 번복되어 오답이 발생하므로 음수 간선 허용 벨만-포드(Bellman-Ford) 알고리즘과의 전제 조건 구별 적용 필수

<details>
<summary>핵심 용어</summary>

- **다익스트라 알고리즘 (Dijkstra's Algorithm)** : 에츠허르 데이크스트라가 고안한 단일 출발점 최단 경로(SSSP: Single-Source Shortest Path) 탐색 알고리즘
- **간선 완화 (Edge Relaxation)** : 정점 $u$를 경유하여 $v$로 도달하는 비용이 기존 $D[v]$보다 작을 때 $D[v] = D[u] + w(u, v)$로 단축 갱신하는 연산
- **우선순위 큐 (Priority Queue / Min-Heap)** : 현재 탐색 가능한 정점 중 누적 거리가 가장 작은 정점을 $O(\log V)$ 시간에 빠르게 추출하기 위한 자료구조
- **최단 경로 트리 (SPT: Shortest Path Tree)** : 시작점으로부터 각 정점까지의 최단 경로 상에 존재하는 간선들로 구성된 방향성 트리 구조
- **OSPF (Open Shortest Path First)** : 링크 상태(Link-State) 라우팅 프로토콜로 각 라우터가 다익스트라 알고리즘을 수행하여 최적 패킷 전달 경로를 산출
</details>

## 2~4교시 예상문제 (25점)

> 그래프 최단경로 탐색 기법인 다익스트라(Dijkstra) 알고리즘의 동작 원리와 간선 완화(Relaxation) 수식을 설명하고, 구현 자료구조별 시간복잡도 비교 및 음수 가중치 환경에서의 한계점과 대안을 기술하시오. (25점)

---

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 모든 간선의 가중치가 0 이상(비음수)인 유향/무향 그래프에서 출발 노드로부터 도달 가능한 다른 모든 정점까지의 최단 경로를 탐욕적 방식으로 계산하는 알고리즘 |
| 목적 | 컴퓨터 네트워크 패킷 최적 라우팅(OSPF), 내비게이션 도로망 경로 탐색, 통신망 회선 설계 및 물류 수송 비용 최소화 |

## Ⅱ. 핵심 특징

| 특징 | 세부 내용 |
|---|---|
| 탐욕적 정점 확정 (Greedy) | 매 단계마다 아직 방문하지 않은 정점 중 시작점으로부터의 거리가 가장 작은 정점을 선택하고 그 거리를 최종 확정 |
| 비음수(Non-Negative) 가중치 필수 | 거리가 한 번 확정된 정점은 이후 어떤 다른 경로를 거치더라도 거리가 줄어들지 않는다는 불변 조건을 전제 |
| 최적 부분 구조 (Optimal Substructure) | 시작점 $S$에서 도착점 $E$까지의 최단경로 상에 위치한 임의의 정점 $M$까지의 경로 역시 반드시 최단경로 |
| 우선순위 큐(Heap) 가속화 | 단순 배열 순회($O(V^2)$) 대신 최소 힙(Min-Heap)을 채택하여 대규모 희소 그래프에서 $O((V+E)\log V)$로 최적화 |

컴퓨터 네트워크와 지도 내비게이션의 근간을 형성하는 가장 대표적인 최단 경로 공학 알고리즘.

## Ⅲ. 체계·프로세스

```text
[다익스트라 알고리즘 실행 및 간선 완화 프로세스]

[1. 초기화 단계]
  - 출발 노드 s의 거리 D[s] = 0, 나머지 모든 노드 D[v] = ∞
  - 우선순위 큐(Min-Heap)에 (0, s) 삽입, 방문 배열 visited[] = false
       │
       ▼
[2. 최소 노드 추출 및 방문 확정] ◀─────────────────────────────────┐
  - 큐가 빌 때까지 반복:                                           │
  - Heap에서 최소 거리 노드 u = (d, node) Pop                       │
  - if (visited[u] == true) continue;                              │
  - visited[u] = true (u의 최단거리 d는 영구 확정)                 │
       │                                                           │
       ▼                                                           │
[3. 인접 간선 완화 (Edge Relaxation)]                              │
  - u의 모든 인접 노드 v에 대해 검사:                              │
  ┌────────────────────────────────────────────────────────┐       │
  │ 완화 조건식:                                           │       │
  │ if (D[u] + weight(u, v) < D[v]) {                      │       │
  │     D[v] = D[u] + weight(u, v);  // 거리 단축 갱신     │       │
  │     parent[v] = u;               // 경로 역추적 등록   │       │
  │     Heap.push((D[v], v));        // 갱신 노드 큐 삽입   │       │
  │ }                                                      │       │
  └────────────────────────────────────────────────────────┘       │
       │                                                           │
       └───────────────────────────────────────────────────────────┘
       │
       ▼ (큐 공백 시 종료)
[4. 최단 경로 트리(SPT) 도출 및 경로 복원]
  - parent 배열 역추적으로 출발 노드부터 목표 노드까지의 최단 경로 반환
```

거리 초기화, 최소 노드 팝, 인접 간선 완화, 힙 갱신, 선행 노드 기반 경로 복원으로 이어지는 완전한 실행 절차.

## Ⅳ. 종류·비교

| 비교 항목 | 단순 배열 구현 (Adjacency Matrix) | 우선순위 큐 기반 구현 (Adjacency List + Min-Heap) | 피보나치 힙 기반 구현 (Fibonacci Heap) |
|---|---|---|---|
| **시간 복잡도** | $O(V^2 + E) = O(V^2)$ | $O((V + E) \log V)$ | $O(E + V \log V)$ (이론상 최적) |
| **최소 노드 추출** | $O(V)$ (선형 탐색 $V$회) | $O(\log V)$ ($V$회 팝) | $O(\log V)$ (분할 상환) |
| **간선 완화 갱신** | $O(1)$ ($E$회 수행) | $O(\log V)$ ($E$회 힙 삽입) | $O(1)$ (Decrease-Key 연산) |
| **적합한 그래프** | 밀집 그래프 (Dense Graph: $E \approx V^2$) | 희소 그래프 (Sparse Graph: $E \ll V^2$, 실제 네트워크) | 이론적 연구용 (실제 오버헤드로 실무 비선호) |
| **구현 난이도** | 매우 단순 | 보통 (언어 내장 PriorityQueue 활용) | 극도로 복잡 |

### 다익스트라 vs 타 최단경로 알고리즘 비교

| 알고리즘 | 단일/전체 | 음수 간선 | 시간 복잡도 | 핵심 메커니즘 |
|---|---|---|---|---|
| **다익스트라 (Dijkstra)** | 단일 출발점 | **불허 (오답)** | $O((V + E) \log V)$ | 최소 힙 기반 탐욕적 정점 확정 |
| **벨만-포드 (Bellman-Ford)** | 단일 출발점 | **허용 (음수 사이클 탐지)** | $O(V \cdot E)$ | 전체 간선 대상 $V-1$회 반복 완화 |
| **플로이드-워셜 (Floyd-Warshall)** | 모든 정점 쌍 | **허용 (음수 사이클 탐지)** | $O(V^3)$ | 경유 노드를 점진 확장하는 동적 계획법 |
| **A* 알고리즘** | 단일 목적지 | **불허** | 휴리스틱 품질 종속 | $f(n) = g(n) + h(n)$ 최적 우선 탐색 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 음수 가중치 간선이 포함된 그래프에서 탐욕적 최소 거리 확정이 뒤집혀 오답 도출 | 가중치 음수 존재 여부를 전처리로 확인하고, 음수 간선이 존재할 경우 벨만-포드(Bellman-Ford) 알고리즘으로 전환 |
| 대규모 지도 데이터에서 목표 정점 하나만을 찾기 위해 전방위 동심원 형태로 불필요한 노드까지 전수 탐색 | 목표점까지의 기하학적 유클리드/맨해튼 거리를 휴리스틱($h$)으로 결합한 A* 알고리즘 적용 |
| 동일 노드가 힙에 중복 삽입되어 힙 메모리 비대화 및 낭비 연산 유발 | `visited[]` 배열 체크 또는 `if (d > D[u]) continue;` 구문을 전진 배치하여 유효하지 않은 구형 원소 즉각 스킵 |

## Ⅵ. 제언

실무 라우팅 및 대규모 지리정보(GIS) 시스템에서는 순수 다익스트라에 머무르지 않고, 양방향 다익스트라(Bidirectional Dijkstra) 또는 Contraction Hierarchies 전처리를 결합한 초고속 검색 아키텍처 확립 권장.

```text
[대규모 도로망 최단경로 최적화 파이프라인]
  글로벌 맵 그래프 수집 → Contraction Hierarchies 전처리 → 출발지/도착지 양방향 다익스트라 실행 → 밀리초 쿼리 응답
```

| 검증 단계 | 사전 모델링 단계 | 런타임 최단경로 연산 |
|---|---|---|
| 핵심 통제 | 인접 리스트 생성 및 음수 가중치 배제 검증 | Min-Heap 기반 간선 완화 및 중복 노드 프루닝(Pruning) |
| 성능 목표 | 정점 수 $V$, 간선 수 $E$ 대비 공간 복잡도 $O(V+E)$ | 수백만 노드 환경에서 서브밀리초(Sub-millisecond) 내 경로 반환 |
