## Ⅰ. 다익스트라 알고리즘의 개요

- 개념 : **다익스트라 알고리즘** 이란 에츠허르 데이크스트라(Edsger W. Dijkstra)가 1956년 고안한 대표적인 최단 경로 알고리즘으로, **음수 가중치** (Negative Weight)가 없는 가중치 그래프에서 단일 출발점(Single Source)으로부터 그래프 상의 다른 모든 정점에 도달하는 최단 경로를 **탐욕적** (Greedy) 기법으로 찾아내는 최적화 알고리즘.
- 배경 및 필요성 : 네트워크 라우팅 프로토콜(OSPF, IS-IS)의 최단 링크 탐색, 도로 교통망 내비게이션, 통신망 패킷 라우팅의 핵심 알고리즘으로 전산학 전반에 걸쳐 가장 광범위하게 활용.
- 핵심 연산 원리 : **간선 완화** (Relaxation), 미방문 노드 중 최소 거리 노드의 탐욕적 선택.

## Ⅱ. 다익스트라 알고리즘의 실행 메커니즘 및 우선순위 큐 구조

```text
   1. 시작 노드의 최단 거리를 0으로 초기화, 나머지 모든 노드는 무한대(∞)로 설정.
   2. 우선순위 큐(Min-Heap)에 (거리 0, 시작 노드)를 삽입.
   3. 큐가 빌 때까지 다음 과정을 반복:
      a. 큐에서 가장 거리가 짧은 노드 u를 꺼냄 (이미 처리된 노드는 스킵).
      b. 노드 u의 모든 인접 노드 v에 대해 완화(Relaxation) 수행:
         if (d[v] > d[u] + weight(u, v)) {
             d[v] = d[u] + weight(u, v);
             우선순위 큐에 (d[v], v) 삽입;
         }
```

- **우선순위 큐** (Min-Heap) 최적화 : 단순 배열을 사용하면 최소 거리 노드 탐색에 $O(V)$가 걸려 전체 복잡도가 $O(V^2)$이 되지만, 이진 힙(Min-Heap)을 적용하면 노드 추출 $O(\log V)$과 간선 완화 $O(E \log V)$를 통해 전체 시간복잡도를 $O((V+E) \log V)$로 대폭 단축.
- 음수 가중치 불가 이유 : 이미 최단 거리로 확정된 노드는 다시 갱신하지 않는다는 그리디 가정에 기반하므로, 이후에 음수 간선이 등장하여 기존 거리를 더 줄일 수 있는 경우 알고리즘이 올바른 최단 거리를 보장하지 못함.

## Ⅲ. 구현 방식에 따른 다익스트라 복잡도 비교

| 구현 방식 | 최소 노드 추출 시간 | 간선 완화 갱신 시간 | 전체 시간복잡도 | 적합한 그래프 형태 |
|---|---|---|---|---|
| **단순 1차원 배열** | $O(V)$ | $O(1)$ | $O(V^2)$ | 밀집 그래프 (Dense Graph: $E \approx V^2$) |
| **이진 최소 힙** (Binary Heap) | $O(\log V)$ | $O(\log V)$ | $O((V + E) \log V)$ | 희소 그래프 (Sparse Graph: $E \ll V^2$, 일반 네트워크망) |
| **피보나치 힙** (Fibonacci Heap) | $O(\log V)$ (분할상환) | $O(1)$ (분할상환) | $O(E + V \log V)$ | 이론상 최적 (구현 복잡도로 실무 활용 드뭄) |

## Ⅳ. 다익스트라 알고리즘의 주요 한계점 및 해결 방안

- 음수 가중치 간선(Negative Edge) 존재 시 부정확한 결과 도출 :
  - 한계점 : 탐욕적(Greedy) 속성에 기반하여 한 번 방문한 노드의 최단 거리는 확정된다고 가정하므로, 음수 가중치 발견 시 이미 계산된 거리를 갱신하지 못함.
  - 해결 방안 : 음수 가중치가 존재하는 그래프에서는 벨만-포드(Bellman-Ford) 알고리즘을 사용하거나, 모든 가중치를 양수화하는 존슨(Johnson's) 알고리즘 적용.
- 대규모 그래프에서 우선순위 큐(Priority Queue) 연산 병목 :
  - 한계점 : 노드 수가 방대한 경우 기본 이진 힙(Binary Heap)의 키 감소(Decrease-Key) 연산 오버헤드로 인해 시간 복잡도가 급격히 상승.
  - 해결 방안 : 이론적 최적 성능을 제공하는 피보나치 힙(Fibonacci Heap) 또는 실무적으로 캐시 효율이 우수한 **페어링 힙** (Pairing Heap) 자료구조 적용.
- 단일 목적지 탐색 시 불필요한 전방위 확산 탐색(Blind Search) :
  - 한계점 : 시작점부터 모든 방향으로 원형으로 동심원을 그리며 탐색하므로, 특정 목적지까지의 경로만 필요할 때 막대한 노드 낭비 탐색 발생.
  - 해결 방안 : 휴리스틱을 추가하여 목적지 방향으로 탐색을 유도하는 A* 알고리즘 적용 또는 출발지와 목적지 양쪽에서 동시 탐색하는 **양방향 다익스트라** (Bidirectional Dijkstra) 도입.

## Ⅴ. 네트워크 및 대규모 분산 시스템에서의 기술사적 제언

- 음수 사이클 검출을 위한 **벨만-포드** (Bellman-Ford) 대안 준비 : 다익스트라는 간선에 단 하나의 음수 가중치만 있어도 오작동하므로, 금융 파생상품 차익거래 분석이나 감쇠 패널티가 적용되는 환경에서는 벨만-포드 알고리즘을 사용하거나 존슨(Johnson) 알고리즘을 통해 간선 가중치를 양수화(Reweighting)하는 전처리 필수.
- OSPF 프로토콜의 플루딩(Flooding)과 다익스트라 SPF 타이머 튜닝 : 라우터 장애 시 링크 상태 패킷(LSU)이 전송될 때마다 다익스트라(SPF)를 즉시 재실행하면 라우터 CPU가 $100\%$에 도달하는 라우팅 플래핑(Flapping)이 발생하므로, SPF 홀드다운 타이머(SPF Hold-time Delay)를 적응형으로 설정하여 네트워크 수렴 속도와 CPU 안정성을 동시 확보해야 함.
