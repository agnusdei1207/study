## 연관 키워드
- 다익스트라 알고리즘, 탐욕 알고리즘, 간선 완화, 최소 우선 순위 큐, 음수 가중치

### Ⅰ. 다익스트라 알고리즘의 개요

- 핵심 요약 : 다익스트라 알고리즘은 모든 간선 가중치가 음수가 아닌 그래프에서 단일 출발점 최단 거리를 계산.
- 개념 : 현재 잠정 거리가 최소인 미확정 정점을 반복 확정하고 인접 간선을 완화하는 탐욕 알고리즘(**다익스트라 알고리즘**, Dijkstra's Algorithm).
- 배경 및 필요성 : 도로·통신망 처럼 비음수 비용 네트워크에서 출발점 기준 경로 비용과 경로 복원이 필요.
- 주요 목적 : 각 정점까지의 최단 거리와 predecessor 정보를 효율적으로 산출.

### Ⅱ. 다익스트라 알고리즘의 핵심 원리와 장점

- 핵심 요약 : 비음수 가중치에서는 최소 잠정 거리 정점을 확정 해도 이후 더 짧은 경로가 생기지 않음.

1. 거리 배열 : 시작 정점은 0, 나머지는 무한대로 초기화 → 미탐색 거리의 상한 표현.
2. 간선 완화 : `dist[v] > dist[u] + w(u,v)`일 때 갱신 → 더 저렴한 경로 반영.
3. 최소 힙 : 가장 작은 잠정 거리를 빠르게 선택 → 희소 그래프 처리 효율 향상.
4. 부모 배열 : 갱신한 이전 정점 저장 → 목적지에서 역추적 해 경로 복원.

### Ⅲ. 다익스트라 알고리즘의 흐름 (구조)

- 핵심 요약 : 최소 거리 후보를 꺼내 확정 하고 이웃의 거리를 완화 하는 작업을 큐가 빌 때까지 반복.

```text
초기화: dist[start]=0, 나머지=∞
   ↓ 최소 힙 에서 (거리, 정점) 추출
오래된 후보 면 건너 뜀
   ↓ 인접 간선 완화·더 짧으면 삽입
큐 소진 또는 목적지 확정
```

```text
start → u → v → goal
0       4   7    9
부모[v]=u, 부모[goal]=v
goal부터 부모 역추적 → 경로 복원
```

- 인접 리스트와 이진 힙 사용 시 보통 O((V+E) log V). 배열 기반 단순 구현은 O(V²), 조밀 그래프에서 고려 가능.

### Ⅳ. 관련 알고리즘 비교

- 핵심 요약 : 음수 간선이 있으면 다익스트라를 사용하지 말고 벨만-포드 등 전제에 맞는 방법을 선택.

| 비교 축 | 다익스트라 | 벨만-포드 |
|---|---|---|
| 가중치 조건 | 비음수 간선 | 음수 간선 허용 |
| 계산 원리 | 최소 후보 정점 확정 | 모든 간선을 반복 완화 |
| 음수 사이클 | 감지 보장 없음 | 도달 가능한 음수 사이클 검출 가능 |
| 시간 복잡도 | 힙 사용 O((V+E)logV) | O(VE) |

### Ⅴ. 다익스트라 알고리즘의 한계와 방안

- 핵심 요약 : 음수 간선 전제 위반, 부동소수점 오차, 거리 오버플로를 입력·수치 검증으로 방지.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 음수 간선 부정확 | 탐욕적 확정 조건 불성립 | 간선 검증 또는 벨만-포드 선택 | 간선 검증 통과율 |
| 큰 거리 오버플로 | 제한된 정수형·무한대 표현 | 넓은 자료형과 덧셈 경계 검사 | 오버플로 발생 건수 |
| 동일 비용 경로 다수 | 부모 갱신 규칙에 따라 결과 차이 | 동률 규칙을 요구 사항에 명시 | 동률 경로 수 |
| 오래된 힙 항목 | 우선 순위 큐에 중복 후보 존재 | 추출 거리와 현재 dist 비교 후 무시 | 오래된 항목 수 |

### Ⅵ. 구현 제언

- 핵심 요약 : 구현 자는 그래프 밀도·가중치 범위·경로 복원 요구를 반영 해 자료 구조와 검증을 결정.

1. API 계약에 방향 그래프 여부, 비용 단위, 도달 불가 표현, 동률 경로 선택 규칙 명시.
2. 기준 그래프, 고립 정점, 동일 가중치, 최대 입력 범위, 음수 입력 거부 시험 포함.

### Ⅶ. 결론

- 핵심 요약 : 다익스트라는 비음수 가중 그래프의 단일 출발점 최단 경로를 효율적으로 구하는 표준 알고리즘.
- 시사점 : 비음수 조건을 확인 하고 힙·인접 리스트 및 경로 복원 규칙을 함께 설계 하는 것이 정확한 구현의 핵심.
