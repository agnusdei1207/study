## 연관 키워드

- TAM, 인지된 유용성, 인지된 사용 용이성
- 사용 태도, 사용 의도, 실제 사용, TAM2, UTAUT

## Ⅰ. 기술수용모델의 개요

- 핵심 요약 : 사용자의 인식 변수로 기술 수용 과정을 설명하는 대표 모형.
- 개념 : 사용자 인식이 기술 수용을 결정한다고 설명하는 **기술수용모델** (TAM, Technology Acceptance Model). 핵심 변수는 업무 성과 개선 기대를 뜻하는 **인지된 유용성** (Perceived Usefulness)과 조작 부담이 적다는 믿음인 **인지된 사용 용이성** (Perceived Ease of Use).
- 배경 및 필요성 : 기능·성능이 우수해도 사용자 거부 시 도입 실패 → 합리적 행동이론(Theory of Reasoned Action)에서 파생한 사용자 인식 기반 설명 필요.
- 주요 목적 : 수용 요인의 설명·예측으로 시스템 설계·도입 전략 개선.

## Ⅱ. 기술수용모델의 특징 및 장점

- 핵심 요약 : 인식 변수의 단순 구조가 측정·진단 용이성과 확장성 제공.

1. 인식 기반 설명 : 기능·성능이 아닌 사용자 인식이 수용을 결정 → 도입 저항 원인의 규명.
2. 경로 구조 : 유용성·용이성 인식이 **사용 태도** (기술 사용에 대한 긍정·부정 평가)를 형성하고 사용 의도로 이어짐 → 수용 과정의 단계적 진단.
3. 유용성의 직접 경로 : 인지된 유용성의 태도를 거치지 않는 사용 의도 직접 영향 → 실무 가치가 수용의 강력한 선행 요인.
4. 측정 가능성 : 설문 문항으로 변수 측정·통계 검증 → 도입 전 진단 도구로 활용.
5. 확장 모형 발전 : 사회적 영향·도구적 인지를 추가한 **TAM2** (Technology Acceptance Model 2)와 4대 요인의 **UTAUT** (Unified Theory of Acceptance and Use of Technology, 통합기술수용이론)로 발전 → 조직·사회 맥락 설명력 보강.

## Ⅲ. 기술수용모델의 구조 (흐름)

- 핵심 요약 : 외부 변수에서 실제 사용까지 이어지는 인과 경로 구조.
- 변수 관계 : 용이성 인식이 유용성 인식에 영향을 주는 보조 경로와 유용성 인식의 사용 의도 직접 경로 존재.

```text
[ TAM 기본 구조 ]

외부 변수
    ↓
인지된 유용성·인지된 사용 용이성
    ↓
사용 태도
    ↓
사용 의도
    ↓
실제 사용
```

```text
[ TAM 확장 계보 ]

합리적 행동이론 (TRA)
    ↓
TAM (1989, Davis)
    ↓
TAM2 (2000, 사회적 영향 추가)
    ↓
UTAUT (2003, 통합 모형)
```

## Ⅳ. TAM과 UTAUT의 비교

- 핵심 요약 : TAM은 인식 경로의 간결성, UTAUT는 조직·사회 변수 통합의 분석 강점.

| 비교 축 | TAM | UTAUT |
| --- | --- | --- |
| 이론 배경 | 합리적 행동이론 기반 단순 모형 | 기존 수용 모형의 통합 모형 |
| 핵심 변수 | 인지된 유용성·인지된 사용 용이성 | 성과 기대·노력 기대·사회적 영향·촉진 조건 |
| 태도 변수 | 사용 태도 포함 | 태도 변수 미포함 |
| 조절 변수 | 미설정 | 성별·연령·경험·자발성 |
| 적합 용도 | 간결한 인식 경로 검증 | 조직 도입·사회적 맥락 분석 |

- 선택 기준 : 인식 경로의 간결한 검증은 TAM, 조직 맥락·집단 차이 분석은 UTAUT.

## Ⅴ. 기술수용모델의 한계와 방안

- 핵심 요약 : 의도-실사용 괴리·편향·맥락 부족·정태성의 위험을 삼각검증·추가 변수로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 의도-실사용 괴리 | 설문 의도의 행동 미전환 → 도입 효과 과대평가 | 이용 로그·업무 성과와의 삼각검증 | 의도-실사용 격차 |
| 자기보고 편향 | 응답자의 사회적 바람직성 → 결과 왜곡 | 익명 응답·행동 데이터 보완 | 응답-행동 일치도 |
| 맥락 설명 부족 | 강제 사용·조직 지원 영향 미반영 → 적용성 저하 | 사회적 영향·촉진 조건의 추가 측정 | 집단별 사용률 |
| 정태 모형 | 시간에 따른 인식 변화 미반영 → 장기 예측 곤란 | 시계열 반복 조사 | 시점별 인식 변화 |

## Ⅵ. 기술수용모델 적용에 대한 기술사적 제언

- 핵심 요약 : 도입 조직·연구 조직의 측정 표준과 의사결정 편입으로 수용 분석의 제도화.
- 측정 표준 : 연구·품질 조직은 문항 조정·신뢰도 검증 절차의 측정 표준 수립.
- 의사결정 편입 : 도입 검토 단계에 수용 진단을 필수 평가 항목으로 편입.
- 제도화 : 도입 후 사용률·만족도 모니터링의 정기 평가 제도 상시화.

## Ⅶ. 결론

- 핵심 요약 : TAM은 사용자 인식으로 기술 수용을 설명하는 기본 모형이자 후속 모형의 이론적 기반.
- 인식 변수의 진단 가능성이 도입 실패 위험 축소의 출발점.
