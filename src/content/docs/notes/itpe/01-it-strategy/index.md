## 1. 과목 개요 및 학습 원칙

* **학습 순서**: 전체 지도에서 위치 확인 → 30초 인출 → 예상문제 → 실제 Ⅰ~Ⅶ 답안 작성 → 10점판 발췌.
* **가독성 극대화**: 3단/7단 답안 틀, 명확한 줄바꿈, 구조도·흐름도·비교표 우선 배치.
* **출제 의도 정조준**: 서론(개요 2~3줄) 최소화, 본론(메커니즘, 구조도, 비교 매트릭스) 집중 배치.
* **결론 차별화**: 실무적 한계(불만)에 머물지 않고 **"나라면 이렇게 해결하겠다"**는 주체적 공학 대안(법·표준·실무 가이드 기반) 제시.
* **전체 보존**: 전 과목 약 **2,400개 전체 키워드**를 삭제·압축하지 않고 유지하며, 학습 시 단계 필터만 바꾼다.
* **학습 단계의 최종 의미**: `A = 완전 기초·필수`, `A+B = A를 익힌 뒤 핵심 확장`, `A+B+C = B에 추가하는 전체·심화 확장`의 누적 구조다.
* **등급 충돌 금지**: 학습 단계 A/B/C는 아래 목록을 만든 기존 우선순위 A/B/C와 별개다. 근거 없는 자동 변환이나 새 단계 배지 부여를 하지 않는다.

| 학습 필터 | 누적 범위 | 01과목 답안 목표 |
|---|---:|---|
| **A** | 기초·필독 약 670개 | 정의·목적·구조·절차·대표 비교를 10점 답안으로 완성 |
| **A+B** | 핵심 누적 약 1,200개 | Ⅰ~Ⅶ 25점 답안과 실무 문제-대책까지 확장 |
| **A+B+C** | 전체 누적 약 2,400개 | 최신 정책·표준·융합 논점까지 전체 연결 |
