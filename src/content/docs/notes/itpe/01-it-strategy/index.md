# 01과목: 정보 전략 및 관리 (IT Strategy & Management)

## 전체 로드맵에서 현재 위치

```text
01 전략·관리: 경영 목표·투자·성과
    ↓ 구축 계획
02 SW공학: 개발 생애주기
    ↓ 구현 기반
03 데이터 · 04 시스템 · 05 네트워크 · 06 보안
    ↓ 신기술 융합
07 최신기술: AI·클라우드 등

08 법규·정책: 전 과목에 적용되는 준수 기준
```

## 01과목 확대 로드맵

```text
경영·정책 목표
    ├─ 전략: 투자 방향·우선순위
    ├─ 거버넌스: 결정 권한·책임
    └─ 규제 준수: 법적 요구·통제

세 관점의 실행 영역
투자·조달·PM·성과관리
    ↓
프로세스 혁신·시스템 통합·IT 서비스
    ↓
성과 측정·감사·지속 개선
```

## 30초 인출

```text
왜 하는가   경영·정책 목표와 IT 정렬
무엇을 정하나 전략·아키텍처·투자·조달 기준선
어떻게 통제하나 거버넌스·PM·감리·위험·계약
무엇으로 보나 성과·서비스 수준·비용·복원력
어디로 잇나 SW 구축 → 데이터·시스템·망·보안 → 최신기술
```

> 이 과목은 경영 목표를 실행 가능한 정보화 사업으로 바꾸고, 투자부터 운영 성과까지 통제하는 방법을 다룬다. 각 토픽은 `목표 → 계획 → 사업화 → 통제 → 성과·환류` 중 자신의 위치를 먼저 찾고 학습한다.

## 학습 역할과 누적 회독

| 단계 | 의미 | 누적 회독 |
|---|---|---|
| **기초** | 핵심 코어의 기본 개념 | 기초 |
| **서브** | 코어와 함께 이해할 주요 주변 요소 | 기초+서브 |
| **응용** | 코어를 전제로 한 파생·적용 요소 | 기초+서브+응용 |

전체 키워드를 보존하고 회독 범위만 누적 확장한다.

## 일반 학습 원칙

- 전략·거버넌스·투자·조달·운영 성과의 연결 관계로 개념을 학습한다.
- 유사 개념은 목적, 책임 주체, 수행 절차와 산출물의 같은 기준으로 비교한다.
- 정책·법령·표준과 변경 가능한 수치는 공식 문서와 1차 출처로 확인한다.
