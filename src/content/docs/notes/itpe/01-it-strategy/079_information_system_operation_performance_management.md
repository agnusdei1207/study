## 지식 로드맵 내 현재 위치

IT 전략·관리 → 정보화 성과관리 → **정보시스템 운영 성과관리**

## 30초 인출

- 본질: 정보시스템 운영 성과관리는 공공기관이 운영 중인 정보시스템의 비용·업무 성과를 매년 측정하고, 행정안전부 평가 점수에 따라 폐기·개선 같은 정비 여부를 정하는 제도
- 메커니즘: 운영 1년이 지난 시스템의 비용 측면 3개·업무 측면 2개 지표를 기관이 측정하면 행정안전부가 별표 기준으로 평가하고, 60점 미만은 정비 권고, 기관은 정비계획 수립·이행
- 통찰: 점수만으로 폐기하면 법정 예외와 이관 영향을 놓치므로 폐기 전 예외 확인과 이관을 담은 정비계획

<details>
<summary>핵심 용어</summary>

- **정보시스템 운영 성과관리** : 「전자정부 성과관리 지침」에 따라 운영 중인 공공 정보시스템의 성과를 측정·평가해 정비 여부를 정하는 관리 제도
- **성과측정** : 기관이 매뉴얼의 지표 정의와 산식으로 비용·업무 측면의 실적을 산출하는 절차
- **성과평가** : 행정안전부장관이 기관의 측정 결과를 지침 별표의 배점 기준으로 평가해 통보하는 절차
- **정비 권고** : 성과평가 60점 미만 정보시스템에 대한 행정안전부장관의 폐기 또는 통폐합·기능고도화·전면재개발 권고
- **정비계획** : 정비 권고를 받은 기관이 폐기·개선 방안과 이용자 불편 방지·정보 이관 또는 보존·서비스 연속성 조치를 정한 계획
- **폐기 예외** : 지침 제26조제2항의 8개 사유(국제협약·법령상 구축·운영 근거, 대국민 서비스 지연 우려 등, Ⅳ 표)에 해당하면 40점 미만이어도 폐기 권고를 하지 않을 수 있는 규정

## 2~4교시 25점 답안

## Ⅰ. 정보시스템 운영 성과관리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정보시스템 운영 성과관리** 는 「전자정부 성과관리 지침」에 따라 운영 중인 공공 정보시스템의 비용·업무 성과를 측정·평가해 정비 여부를 정하는 관리 제도 |
| 목적 | 저성과 정보시스템의 정비와 공공 정보자원의 효율적 활용 |

## Ⅱ. 구축 사업 평가와 구별되는 운영 성과관리의 특징

| 특징 | 의미 |
|---|---|
| 운영 단계 대상 | 서비스 운영 개시 후 1년이 지난 정보시스템의 연례 측정 |
| 지표 기반 측정 | 매뉴얼의 지표 정의·산식에 따른 비용·업무 실적 산출 |
| 측정·평가 주체 분리 | 기관이 측정하고 행정안전부장관이 별표 기준으로 평가 |
| 점수 기반 **정비 권고** | 60점 미만 시스템에 폐기 또는 개선 권고, 기관은 특별한 사정이 없으면 준수 |

## Ⅲ. 성과측정에서 정비까지의 체계와 정비 판정

### 운영 성과관리 절차

```text
성과측정 대상 확인 (운영 개시 후 1년 경과)
    ↓
기관의 연례 성과측정 (비용·업무 측면)
    ↓
행정안전부 성과평가와 결과 통보
    ↓
60점 미만 정보시스템의 정비 권고
    ├─ 40~60점 권고 → 정비계획 수립·이행·결과 통보
    └─ 폐기 대상 → 행정정보 보존 조치 후 처분
```

근거: 지침 제23조~제25조(대상·측정·평가), 제27조~제29조(정비계획·조치·처분)

### 정비 권고 확대: 점수 구간과 폐기 예외 판정

```text
성과평가 총점
    ├─ 60점 이상 → 지표 결과값 관리
    ├─ 40점 이상 60점 미만
    │     → 폐기 또는 통폐합·기능고도화·전면재개발
    └─ 40점 미만
          ↓
       폐기 예외 사유 해당 여부
          ├─ 해당 → 폐기 권고 제외 가능
          └─ 비해당 → 폐기 권고
```

근거: 지침 제26조제1항(점수 구간), 제2항(폐기 예외), 제3항(권고 준수)

## Ⅳ. 측정 대상·지표·폐기 예외의 구성

### 성과측정 대상과 제외

| 구분 | 기준 (지침 제23조) |
|---|---|
| 기본 대상 | 중앙행정기관등·지방자치단체등의 정보시스템 중 서비스 운영 개시 후 1년이 지난 시스템 |
| 제외 가능 | 해당 연도부터 2년 이내 폐기하기로 결정한 시스템, 매뉴얼의 제외 유형 |
| 조기 측정 | 1년 미만 시스템도 행정안전부장관과 협의해 측정 가능 |

### 비용·업무 측면의 측정지표

| 측면 | 측정지표 | 배점 |
|---|---|---:|
| 비용 | 운영의 적정성 | 10점 |
| 비용 | 유지의 용이성 | 10점 |
| 비용 | 비용의 효율성 | 20점 |
| 업무 | 기능 활용도 | 20점 |
| 업무 | 업무성과 달성도 (공통지표 10점·고유지표 30점) | 40점 |

세부 산식과 환산 구간은 지침 별표와 해당 연도 매뉴얼 기준

### 폐기 예외 사유 (지침 제26조제2항)

| 구분 | 사유 |
|---|---|
| 법적 근거 | 국제협약 또는 법령에 구축·운영 근거 |
| 국가·국민 영향 | 생명 위험·안보·치안 지장, 국가경제 손실·국민생활 장애 |
| 서비스·이용자 영향 | 대국민 서비스 지연, 사회적 약자의 생활 편의 |
| 기타 | 표준 보급시스템, 운영 개시 후 3년 미경과, 위원회가 인정한 폐기 곤란 |

## Ⅴ. 운영 성과관리 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 40점 미만 점수만으로 폐기를 진행해 법정 **폐기 예외** 사유 누락 | 폐기 전 법령 근거·대국민 서비스 지연 등 예외 사유 확인 |
| 폐기·통폐합 과정의 이용자 불편과 데이터 유실 위험 | **정비계획** 에 이용자 전환·정보 이관 또는 보존·서비스 연속성 조치 명시 |
| 증빙 부실로 평가점수 반영 불이익과 연도 간 비교 곤란 | 측정 기초 데이터·증빙의 1년 이상 보관과 적용 연도 매뉴얼 산식 기록 |

## Ⅵ. 제언

정비 권고를 받은 정보시스템은 폐기 예외 사유와 업무·데이터 의존성을 먼저 확인하고, 이용자 전환·정보 보존 조치를 담은 정비계획 확정 후 처분

### 정비 판단 책임 구조

```text
정비 권고 대상 정보시스템
    │
    ├─ 행정안전부 ── 성과평가·정비 권고
    │
    ├─ 운영 기관 ── 예외 사유 확인·정비계획 수립
    │
    └─ 연계 기관·이용자 ── 의존 업무·전환 일정 확인
```

### 운영 기관 역할 확대: 정비계획 확정 절차

```text
폐기 예외 사유 해당 여부 확인
    ↓
연계 시스템·이용자·보유 데이터 식별
    ↓
이용자 전환 경로와 정보 이관·보존 방식 결정
    ↓
정비계획 확정 후 이행과 결과 통보
```

### 선택 근거: 점수 기준 즉시 처리와의 비교

| 구분 | 점수 기준 즉시 처리 | 제언: 의존성 확인 후 정비 |
|---|---|---|
| 판단 근거 | 평가 점수 | 점수와 예외 사유·업무 의존성 |
| 처리 순서 | 폐기 결정 후 이관 검토 | 의존성 확인 후 정비계획 확정 |
| 이용자 영향 | 사후 대응 | 전환 경로의 사전 확정 |
| 데이터 처리 | 처분 시점의 보존 조치 | 이관·보존 방식의 사전 결정 |

## 출제 이력과 검증 출처

- 제132~140회 공식 문제지에 정보시스템 운영 성과관리 단독 문항 없음
- 전자정부 성과관리 지침 — 행정안전부고시 제2025-71호, 2025. 12. 19. 시행, 제23조~제29조
- 정보시스템 운영 성과측정 지표별 배점 및 환산점수 — 제25조제1항 관련 별표
