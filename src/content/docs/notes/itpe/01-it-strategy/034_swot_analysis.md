## 지식 로드맵 내 현재 위치

IT 전략·관리 → 환경·역량 분석 → **SWOT 분석**

## 30초 인출

- 본질: SWOT 분석은 조직 내부의 강점·약점과 외부의 기회·위협을 구분해 전략 대안을 찾는 환경 분석 기법
- 메커니즘: 통제 가능성으로 내부 S·W와 외부 O·T를 나누고, 두 축을 교차한 TOWS 조합으로 SO·ST·WO·WT 대안 도출
- 통찰: 한계: 네 칸을 채운 뒤 실행 과제 없이 분석이 끝남 → 방안: 근거가 확인된 요인으로 TOWS 대안을 만들고 우선 과제에 책임자·재검토 시점 지정

<details>
<summary>핵심 용어</summary>

- **SWOT 분석** : 조직 내부의 강점(Strengths)·약점(Weaknesses)과 외부의 기회(Opportunities)·위협(Threats)을 구분해 전략 대안을 찾는 환경 분석 기법
- **TOWS 매트릭스** : 내부 강점·약점과 외부 기회·위협을 교차해 SO·ST·WO·WT 전략 대안을 만드는 조합표
- **PEST** : 정치(Political)·경제(Economic)·사회(Social)·기술(Technological) 관점의 거시환경 분석 틀
- **3C** : 고객(Customer)·경쟁사(Competitor)·자사(Company) 관점의 사업 환경 분석 틀
- **VRIO** : 자원의 가치(Value)·희소성(Rarity)·모방 곤란성(Imitability)·조직 활용(Organization)을 따지는 내부 역량 분석 틀

</details>

## 2~4교시 25점 답안

## Ⅰ. SWOT 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SWOT 분석** 은 조직 내부의 강점·약점과 외부의 기회·위협을 구분해 전략 대안을 찾는 환경 분석 기법 |
| 목적 | 내부 역량과 외부 환경이 맞물리는 실행 가능한 전략 대안의 도출 |

## Ⅱ. 내부·외부와 긍정·부정의 두 축 구조라는 특징

| 구분 | 긍정 요인 | 부정 요인 |
|---|---|---|
| 내부: 조직이 통제 가능 | 강점(S) | 약점(W) |
| 외부: 조직이 통제 불가 | 기회(O) | 위협(T) |

같은 사실도 조직 목표에 따라 강점과 약점, 기회와 위협이 뒤바뀌는 목표 의존적 판단

## Ⅲ. SWOT 분석 수행 절차

### SWOT 분석 절차

```text
분석 목표와 범위 설정
    ↓
내부·외부 요인 수집과 분류
    ↓
TOWS 교차로 전략 대안 도출
    ↓
우선 대안 선정과 실행 과제화
```

### 요인 분류 확대: 내부·외부 판정 분기

```text
후보 요인
    ↓
조직의 통제 범위 판정
    ├─ 통제 가능 → 목표 기여 방향으로 강점·약점 구분
    └─ 통제 불가 → 목표 영향 방향으로 기회·위협 구분
    ↓
요인별 근거 자료와 기준 시점 기록
```

## Ⅳ. TOWS 전략 대안과 입력 분석 기법의 관계

### TOWS 전략 대안

| 조합 | 결합 요인 | 전략 방향 |
|---|---|---|
| SO | 강점 × 기회 | 강점으로 기회를 활용하는 공격 전략 |
| ST | 강점 × 위협 | 강점으로 위협을 줄이는 다각화 전략 |
| WO | 약점 × 기회 | 약점을 보완해 기회를 잡는 전환 전략 |
| WT | 약점 × 위협 | 약점과 위협 노출을 줄이는 방어 전략 |

### 입력 분석 기법과의 관계

| 기법 | 분석 대상 | SWOT에서의 역할 |
|---|---|---|
| **PEST** | 거시환경 | 기회·위협의 근거 제공 |
| **3C** | 고객·경쟁사·자사 | 고객·경쟁사는 기회·위협, 자사는 강점·약점의 근거 제공 |
| **VRIO** | 내부 자원 | 강점의 지속 가능성 판단 근거 제공 |

## Ⅴ. SWOT 분석의 한계와 방안

| 한계 | 방안 |
|---|---|
| 근거 없는 평가어의 나열 | 요인마다 관찰 근거·출처·기준 시점 기록 |
| 내부·외부 요인의 혼동 | 조직 통제 가능성으로 S·W와 O·T 구분 |
| 요인 과다로 핵심 요인의 흐림 | 분석 목표에 영향이 큰 요인만 선별 |
| 네 칸 정리 후 전략 공백 | 강점이 기회에 맞으면 SO, 약점이 기회를 막으면 WO, 위협이 약점과 겹치면 WT 대안 선택 |
| 대안과 실행의 분리 | 우선 대안에 책임자·자원·기한 지정 |

## Ⅵ. 제언

근거가 확인된 핵심 요인으로만 TOWS 대안을 만들고, 목표 적합성과 가용 자원으로 고른 우선 과제에 책임자·재검토 시점 지정

### SWOT 결과의 실행 연결 구조

```text
SWOT 결과의 실행 연결
    │
    ├─ 요인 근거 기록 ── 요인별 근거·출처·기준 시점
    │
    ├─ TOWS 대안 ── 교차 조합별 전략 대안
    │
    └─ 실행 과제 ── 책임자·자원·기한·재검토 시점
```

### 실행 과제 확대: 우선 과제 선정과 재검토

```text
TOWS 대안 목록
    ↓
목표 적합성·필요 자원·실행 가능성 비교
    ↓
우선 과제 선정과 책임자·기한 지정
    ↓
재검토 시점의 근거 요인 변화 확인
    ├─ 변화 없음 → 과제 지속
    └─ 요인 변화 → SWOT 갱신과 대안 재선정
```

### 선택 근거: 나열식 SWOT과의 비교

| 구분 | 나열식 SWOT | 제언: 실행 연결 SWOT |
|---|---|---|
| 요인 기재 | 평가어 나열 | 근거·기준 시점 기록 |
| 전략 도출 | 네 칸 정리에서 종료 | TOWS 교차 조합 |
| 결과물 | 분석표 | 책임자가 지정된 실행 과제 |
| 갱신 시점 | 다음 계획 수립 때 | 재검토 시점의 요인 변화 확인 |
