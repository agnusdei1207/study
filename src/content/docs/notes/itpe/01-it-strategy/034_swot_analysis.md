## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 환경·역량 분석 → **SWOT 분석**

## 30초 인출

- 본질: **SWOT 분석**은 조직 내부의 강점·약점과 외부 기회·위협을 정리해 전략 선택에 활용하는 방법.
- 메커니즘: 근거 수집 → 내부·외부 요인 분류 → **TOWS**로 조합 → 실행 가능한 대안 비교.
- 핵심: 요인별 출처·기준 시점과 대안별 책임자·자원·판정 기준의 기록.

<details>
<summary>핵심 용어</summary>

- **SWOT 분석**: 조직 내부의 강점·약점과 외부의 기회·위협을 정리해 전략 선택에 활용하는 방법
- **SWOT(Strengths, Weaknesses, Opportunities, Threats)**: 강점·약점·기회·위협의 네 범주
- **TOWS**: 강점·약점과 기회·위협을 교차해 전략 대안을 만드는 분석 방식
- **PEST**: 정치·경제·사회·기술 관점으로 거시환경 요인을 검토하는 틀
- **VRIO**: 자원의 가치·희소성·모방 곤란성·조직 활용 여부를 검토하는 틀

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SWOT 분석**은 조직 내부의 강점·약점과 외부 기회·위협을 정리해 전략 선택에 활용하는 방법 |
| 목적 | 내부 역량·외부 여건의 적합성에 따른 실행 가능한 대안 마련 |

### Ⅱ. 수행 흐름

```text
분석 범위·목표 설정
    ↓
내부 S·W / 외부 O·T 확인
    ↓
요인 교차 → TOWS 대안
    ↓
우선 대안·실행 과제 선택
```

**분석 품질 통제**

- 조직이 바꿀 수 있는 역량·자원의 내부 요인 분류, 외부 환경 변화의 외부 요인 분류.
- 요인별 근거·자료 출처·기준 시점 기록과 사실·해석 구분.
- **TOWS** 대안의 요인 조합 기반 실행 가능한 선택으로 구체화.

제언: 대안마다 책임자·평가 기준을 지정한 실행 여부 추적.

## 2~4교시 25점 답안

## Ⅰ. SWOT 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SWOT 분석**은 조직 내부의 강점·약점과 외부 기회·위협을 정리해 전략 선택에 활용하는 방법 |
| 목적 | 내부 역량·외부 여건의 적합성에 따른 실행 가능한 대안 마련 |

## Ⅱ. SWOT 분석 수행 흐름

```text
분석 범위·목표 설정
    ↓
내부 S·W / 외부 O·T 확인
    ↓
요인 교차 → TOWS 대안
    ↓
우선 대안·실행 과제 선택
```

## Ⅲ. TOWS 전략 대안

| 조합 | 질문 | 대안 방향 |
|---|---|---|
| **SO** | 활용할 강점·기회의 조합 | 강점으로 기회를 활용 |
| **ST** | 강점을 통한 위협 완화 방안 | 강점으로 위협에 대응 |
| **WO** | 기회 활용을 위한 보완 약점 | 역량을 보완해 기회를 활용 |
| **WT** | 약점·위협 노출의 축소 방안 | 취약성을 낮추고 방어 |

## Ⅳ. 요인 검증과 대안 비교

| 검토 항목 | 확인 질문 |
|---|---|
| 근거 | 요인을 뒷받침하는 자료·출처·시점의 확보 여부 |
| 통제 범위 | 조직 통제 역량과 외부 여건의 구분 여부 |
| 전략 적합성 | 대안과 조직 목표·자원의 부합 여부 |
| 실행 가능성 | 책임자·예산·일정·선행조건의 지정 가능성 |

## Ⅴ. 단순 나열식 분석의 한계와 개선

| 한계 | 개선 방향 | 확인 자료 |
|---|---|---|
| 모호한 평가어의 나열 | 관찰 가능한 근거·기준 시점 기록 | 자료 출처·측정 기준 |
| 내·외부 요인 혼동 | 조직 통제 가능성·발생 위치의 동시 검토 | 분류 근거 |
| 과다·중복 요인 | 전략 판단에 영향을 주는 핵심 요인 선별과 상호 관계 확인 | 요인 간 중복·의존성 |
| 분석 결과와 실행의 분리 | TOWS 대안의 책임·자원·기한이 있는 과제화 | 과제·책임·평가 기준 |

## Ⅵ. 기술사적 제언 — 분석 결과를 실행 가능한 결정으로 전환

| 한계 | 해결 방안 |
|---|---|
| SWOT 작성 후 요인별 우선순위·실행 책임 미지정에 따른 전략 선택 단절 | TOWS 대안의 목표 적합성·근거 강도·필요 자원·실행 가능성 비교, 과제별 책임자·일정·평가 기준 지정과 정기 검토 |
