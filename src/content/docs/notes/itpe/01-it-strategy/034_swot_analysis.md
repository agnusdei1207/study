## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 환경·역량 분석 → **SWOT 분석**

## 30초 인출

- 본질: **SWOT 분석** 은 조직 내부의 강점·약점과 외부 기회·위협을 정리해 전략 선택에 활용하는 방법.
- 메커니즘: 근거 수집 → 내부·외부 요인 분류 → **TOWS** 로 조합 → 실행 가능한 대안 비교.
- 통찰: 한계: SWOT 항목 나열이 실행 전략으로 이어지지 않음 → 방안: 대안마다 책임자·평가 기준을 정해 실행 여부를 추적

<details>
<summary>핵심 용어</summary>

- **SWOT 분석** : 조직 내부의 강점·약점과 외부의 기회·위협을 정리해 전략 선택에 활용하는 방법
- **SWOT(Strengths, Weaknesses, Opportunities, Threats)** : 강점·약점·기회·위협의 네 범주
- **TOWS** : 강점·약점과 기회·위협을 교차해 전략 대안을 만드는 분석 방식
- **PEST** : 정치·경제·사회·기술 관점으로 거시환경 요인을 검토하는 틀
- **VRIO** : 자원의 가치·희소성·모방 곤란성·조직 활용 여부를 검토하는 틀

## 2~4교시 25점 답안

## Ⅰ. SWOT 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SWOT 분석** 은 조직 내부의 강점·약점과 외부 기회·위협을 정리해 전략 선택에 활용하는 방법 |
| 목적 | 내부 역량·외부 여건의 적합성에 따른 실행 가능한 대안 마련 |

## Ⅱ. SWOT 분석의 특징

| 구분 | 긍정 요인 | 부정 요인 |
|---|---|---|
| 내부·통제 가능 | 강점(S) | 약점(W) |
| 외부·환경 변화 | 기회(O) | 위협(T) |

내·외부 구분은 통제 범위와 근거 시점에 따라 판단하며, 네 범주의 나열만으로 전략 대안이 결정되지는 않음.

## Ⅲ. SWOT 분석과 TOWS 대안 도출 절차

```text
분석 범위·목표 설정
    ↓
내부 S·W / 외부 O·T 확인
    ↓
요인 교차 → TOWS 대안
    ↓
우선 대안·실행 과제 선택
```

```text
내부 S·W의 통제 가능성 확인 ─┐
                             ├→ S/O·S/T·W/O·W/T 조합
외부 O·T의 발생 근거 확인 ───┘          ↓
                       목표·자원·책임자 기준으로 우선순위 선정
```

## Ⅳ. TOWS 대안 유형과 비교

### TOWS 전략 대안

| 조합 | 결합 요소 | 대안 방향 |
|---|---|---|
| **SO** | 활용할 강점·기회의 조합 | 강점으로 기회를 활용 |
| **ST** | 강점을 통한 위협 완화 방안 | 강점으로 위협에 대응 |
| **WO** | 기회 활용을 위한 보완 약점 | 역량을 보완해 기회를 활용 |
| **WT** | 약점·위협 노출의 축소 방안 | 취약성을 낮추고 방어 |

### 요인 검증과 대안 비교

| 검토 항목 | 확인 요소 |
|---|---|
| 근거 | 요인을 뒷받침하는 자료·출처·시점의 확보 여부 |
| 통제 범위 | 조직 통제 역량과 외부 여건의 구분 여부 |
| 전략 적합성 | 대안과 조직 목표·자원의 부합 여부 |
| 실행 가능성 | 책임자·예산·일정·선행조건의 지정 가능성 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모호한 평가어의 나열 | 관찰 가능한 근거·기준 시점 기록 |
| 내·외부 요인 혼동 | 조직 통제 가능성과 외부 발생 근거를 대조 |
| 과다·중복 요인 | 전략 판단에 영향을 주는 핵심 요인 선별 |
| 분석 결과와 실행의 분리 | TOWS 대안에 책임·자원·기한 지정 |

## Ⅵ. 제언

근거가 확인된 핵심 요인으로 TOWS 대안을 만들고 목표 적합성·필요 자원으로 우선 과제를 골라 책임자 지정.
