## 지식 로드맵 내 현재 위치

```text
IT 전략수립 → 환경·역량 분석 → SWOT
```

## 토픽 큰 그림과 30초 인출
```text
외부 PEST·산업·고객 → O 기회 / T 위협 ┐
                                       ├→ SO·ST·WO·WT → 과제·KPI
내부 자원·프로세스  → S 강점 / W 약점 ┘
```
- **30초 인출**: SWOT은 내부 강점·약점과 외부 기회·위협을 근거로 분류하고 교차하여 실행 가능한 전략대안을 만드는 분석틀이다.

## 예상문제
> SWOT 분석의 개념과 수행절차를 설명하고 Cross-SWOT 전략 및 한계 보완방안을 제시하시오.

## Ⅰ. 개요 ─ 환경과 역량의 연결
**SWOT 분석**은 조직의 내부 역량인 강점·약점과 외부 환경의 기회·위협을 구조화하여 전략대안을 도출하는 도구다. 네 칸의 목록 작성이 아니라 근거 있는 선택과 실행과제 연결이 목적이다.

## Ⅱ. 분류 ─ 내부와 외부
| 구분 | 긍정 | 부정 | 분석 근거 |
|---|---|---|---|
| 내부·통제 가능 | Strength | Weakness | 자원·역량·가치사슬·성과 |
| 외부·통제 곤란 | Opportunity | Threat | PEST·산업·시장·고객·경쟁 |

동일 요인도 분석 목표와 비교기준에 따라 달라지므로 범위·시점·근거를 함께 기록한다.

## Ⅲ. 절차 ─ 사실에서 과제까지
```text
목표·범위 → 외부환경 → 내부역량 → S/W/O/T 분류·근거
          → 중요도·영향 우선화 → Cross-SWOT → 대안평가 → 과제·KPI
```

## Ⅳ. 상세 ─ Cross-SWOT
| 전략 | 결합 | 질문 |
|---|---|---|
| SO | 강점으로 기회 활용 | 무엇을 확대·선점할 것인가 |
| ST | 강점으로 위협 대응 | 무엇으로 방어·차별화할 것인가 |
| WO | 기회를 이용해 약점 보완 | 어떤 역량을 확보할 것인가 |
| WT | 약점과 위협 최소화 | 무엇을 축소·회피·전환할 것인가 |

## Ⅴ. 비교 ─ 보완 분석도구
| 도구 | 관점 | SWOT과 관계 |
|---|---|---|
| PEST | 거시 정치·경제·사회·기술 | 외부 O/T 근거 |
| 산업구조 분석 | 경쟁·공급자·구매자 등 | 산업 O/T 구체화 |
| 가치사슬 | 활동별 가치·원가·역량 | 내부 S/W 근거 |
| 위험분석 | 불확실성과 대응 | 위협·기회의 처리 |

## Ⅵ. 한계 ─ 나열식 분석 방지
주관적 브레인스토밍, 내부·외부 혼동, 긴 목록과 우선순위 부재, 시점 변화, 분석에서 전략으로의 비약을 경계한다. 출처와 관찰시점을 붙이고 중요도·영향·실행가능성으로 대안을 평가한다.

## Ⅶ. 결론 ─ 실행 가능한 선택
SWOT의 품질은 칸을 채운 양이 아니라 증거와 선택의 추적성에 달려 있다. Cross-SWOT 대안을 투자·위험·역량 관점에서 선별하고 책임자·일정·KPI가 있는 실행과제로 전환한다.

## 1교시 10점 답안 발췌
```text
정의: 내부 S/W와 외부 O/T를 근거로 교차해 전략대안을 도출
절차: 목표 → 외부·내부 분석 → 분류·우선화 → 교차 → 과제·KPI
교차: SO 활용 / ST 대응 / WO 보완 / WT 축소·회피
보완: PEST·산업구조·가치사슬, 근거·시점·우선순위 명시
```
