## 지식 로드맵 내 현재 위치

IT 전략·관리 → 정보화 사업 통제 → **정보시스템 감리**

## 30초 인출

- 본질: 정보시스템 감리는 발주자와 사업자로부터 독립된 제3자가 정보시스템의 구축·운영 상태를 점검하고 문제점의 개선을 이끌어 내는 제도
- 메커니즘: 요구정의·설계·종료 단계마다 사업자의 산출물이 과업내용을 반영했는지 대비표로 점검하고, 지적 사항은 시정조치 결과를 확인해 종결
- 통찰: 종료 단계에서 세부 검사항목별 적합·부적합 판정 기준이 없으면 이행 여부를 두고 분쟁이 생기므로 요구정의 단계에서 대비표에 판정 기준을 확정

<details>
<summary>핵심 용어</summary>

- **정보시스템 감리** : 발주자와 사업자의 이해관계로부터 독립된 자가 제3자의 관점에서 정보시스템의 구축·운영 등을 종합 점검하고 문제점을 개선하도록 하는 활동
- **감리법인** : 「전자정부법」 제58조제1항에 따라 행정안전부장관에게 등록한 감리 수행 법인
- **감리기준** : 행정안전부장관이 고시하는 감리의 업무범위·절차·준수사항 (정보시스템 감리기준)
- **3단계감리** : 요구정의·설계·종료 단계에서 실시하는 감리
- **2단계감리** : 3단계감리에서 요구정의 단계 감리를 생략한 감리
- **상주감리** : 사업 현장에 상주하거나 주기적으로 투입되는 감리원이 위험요소·산출물 검토와 자문을 수행하는 감리
- **대비표** : 사업자가 작성해 발주자 확인을 거쳐 제출하는, 산출물이 과업내용을 세부항목별로 반영했는지 확인하는 표
- **감리수행결과보고서·시정조치확인보고서** : 감리 점검 결과를 기록한 보고서와 사업자의 시정조치 이행을 확인한 결과를 기록한 보고서
- **PMO(Project Management Office)** : 전자정부사업의 관리·감독 업무(전자정부사업관리)를 위탁받아 수행하는 사업관리 조직 (「전자정부법」 제64조의2)

## 2~4교시 25점 답안

## Ⅰ. 정보시스템 감리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정보시스템 감리** 는 발주자·사업자와 독립된 제3자가 정보시스템의 구축·운영 등을 종합 점검하고 문제점 개선을 유도하는 활동 |
| 목적 | 정보시스템의 효율성 향상과 안전성 확보 |

## Ⅱ. 독립성과 법정 의무를 갖춘 감리의 특징

| 특징 | 내용 |
|---|---|
| 독립성 | 발주자·사업자의 이해관계로부터 독립된 제3자의 관점 |
| 법정 수행 주체 | 행정기관등의 장이 대상 정보시스템에 **감리법인** 으로 하여금 감리 실시 |
| 감리 대상 | 대국민 행정·민원 처리용 또는 여러 기관 공동 구축·사용 시스템, 사업비 5억원 이상 구축사업, 기관장이 필요하다고 인정한 사업 |
| 결과 반영 | 사업자의 감리결과 반영 의무와 감리원 업무에 대한 정당한 사유 없는 개입·간섭 금지 |
| 적용 제외 | 전자정부사업관리(PMO)를 위탁한 사업 중 사업비 1억원 이상 5억원 미만(대국민·공동 이용 시스템)이거나 사업기간 5개월 미만 구축사업 |

## Ⅲ. 감리 체계와 단계별 수행 절차

### 감리 규범 구성

```text
전자정부법 ── 감리 의무·감리결과 반영·감리기준 고시 (제57조)
    │
    ├─ 시행령 ── 감리 대상(제71조)·감리법인 업무범위와 절차(제72조)
    │
    └─ 정보시스템 감리기준(행정안전부 고시) ── 감리 실시시기·단계별 점검·상주감리
```

### 감리 수행 절차

```text
감리계약 체결
    ↓
예비조사 실시 · 감리계획 수립
    ↓
감리 착수회의
    ↓
감리 시행 · 감리보고서 작성
    ↓
감리 종료회의
    ↓
감리보고서 통보
    ↓
시정조치 결과 확인 · 통보
```

### 단계별 감리 확대: 3단계감리의 점검 흐름

```text
요구정의 단계: 요구사항정의서가 계약문서의 과업내용을 반영했는지 점검
    ↓
설계 단계: 설계 산출물의 과업내용 반영, 대비표의 세부 검사항목별 적합·부적합 판정 가능 여부 점검
    ↓
종료 단계: 검사 전 세부 검사항목별 과업내용 이행 여부를 적합·부적합으로 판정

각 단계 공통: 사업자가 대비표 작성 → 발주자 확인 → 감리법인 점검(감리수행결과보고서)
             → 사업자 시정조치 → 감리법인 확인(시정조치확인보고서)
```

## Ⅳ. 감리 유형의 비교

| 비교축 | 3단계감리 | 2단계감리 | 상주감리 |
|---|---|---|---|
| 실시 | 원칙 | 사업비 20억원 미만 또는 사업기간 6개월 미만일 때 선택 | 단계별 감리에 추가하는 선택 |
| 점검 시점 | 요구정의·설계·종료 | 설계·종료 | 사업 기간 중 상주 또는 주기적 투입 |
| 요구정의 단계 | 감리법인 점검 | 생략, 발주자가 요구사항정의서의 과업 반영 직접 점검 | 생략, 상주감리원이 직접 점검 |
| 점검 대상 | 단계별 산출물과 대비표 | 단계별 산출물과 대비표 | 사업수행계획서·상세공정표(WBS)·산출물 품질·위험요소 |
| 추가 조건 | - | - | 소프트웨어 진흥법 제48조제2항에 따른 대기업 참여 제한 사업 또는 위험도·난이도가 높은 사업 |

- 상주감리원은 단계별 감리의 감리원으로 참여 불가

## Ⅴ. 감리 수행의 한계와 방안

| 한계 | 방안 |
|---|---|
| 대비표가 과업내용 나열에 그쳐 종료 단계에서 적합·부적합 판정 불가 | 대비표를 세부 검사항목별 판정이 가능한 수준으로 구체화 |
| 단계별 감리 사이 기간에 발생한 위험의 발견 지연 | 위험도·난이도가 높은 사업에 상주감리 추가 |
| 지적 사항의 시정 지연으로 다음 단계에 결함 이월 | 시정조치 결과의 확인과 시정조치확인보고서 통보를 단계 종료 조건으로 관리 |
| 감리법인과 사업자·사업관리자 사이 특수관계에 따른 독립성 침해 | 감리 계약 시 특수관계 부재 확인, 상주감리원과 단계별 감리원의 분리 |

## Ⅵ. 제언

적합·부적합 판정 기준을 대비표 항목마다 요구정의 단계에서 발주자·사업자가 확정하고, 설계·종료 단계가 같은 기준으로 판정

### 판정 기준의 단계 간 연속 적용

```text
요구정의 단계: 대비표 항목 + 판정 기준 확정
    ↓
설계 단계: 설계 산출물을 같은 항목·기준으로 점검
    ↓
종료 단계: 같은 항목·기준으로 이행 여부 판정
```

### 대비표 한 행 확대: 항목과 판정 기준

```text
과업내용 항목 ── 요구사항 ── 설계 산출물 ── 판정 기준 ── 종료 단계 판정
                                              │
                            요구정의 단계에서 확정 (적합 조건·확인 방법)
```

### 선택 근거: 현행 절차와의 비교

| 구분 | 설계 단계에서 구체화 | 제언: 요구정의 단계에서 확정 |
|---|---|---|
| 판정 기준 확정 시점 | 설계 단계 감리 시점 | 요구사항정의서 작성과 함께 |
| 기준 불일치 발견 | 설계 단계 이후 | 요구정의 단계 |
| 종료 단계 판정 | 확정된 세부 검사항목 기준 | 요구정의 단계부터 이어진 동일 기준 |
