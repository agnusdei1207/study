## 지식 로드맵 내 현재 위치

IT 전략·관리 → 사업 품질·독립 점검 → **정보시스템 감리**

## 30초 인출

- 본질: 정보시스템 감리는 발주자·사업자로부터 독립된 감리법인이 정보시스템 구축의 적정성을 점검하고 개선을 권고하는 제도
- 메커니즘: 전자정부법이 감리 의무·독립성·결과 반영을 정하고, 감리법인은 착수·시행·보고 후 시정 조치 결과를 확인
- 통찰: 사업자 보고만으로 지적사항을 종결하면 미조치가 남으므로 감리법인 증거 확인과 발주기관 수락을 분리한 종결

<details>
<summary>핵심 용어</summary>

- **정보시스템 감리** : 발주자·사업자로부터 독립된 감리법인이 감리기준에 따라 정보시스템 구축의 적정성을 점검하는 활동
- **감리법인** : 「전자정부법」 제58조에 따라 기술능력·재정능력을 갖추어 행정안전부장관에게 등록한 감리 수행 법인
- **감리기준** : 「전자정부법」 제57조제5항에 따라 행정안전부장관이 감리의 업무범위·절차·준수사항을 정해 고시한 기준
- **시정 조치** : 감리 지적사항에 대해 사업자가 수행하는 개선 조치. 감리법인이 결과를 확인해 통보
- **PMO(Project Management Office)** : 이 문항에서 「전자정부법」 제64조의2의 전자정부사업관리 위탁에 따라 발주기관의 사업 관리·감독을 대행하는 조직
- **상주감리** : 감리대상사업 현장에 상주하거나 주기적으로 투입되는 감리원이 사업의 위험요소·산출물 검토와 자문을 수행하는 감리(감리기준 제2조제14호). 위험도·난이도가 높은 사업 등에 단계별 감리에 더해 추가하며(제3조제2항), 현행 감리기준에 `현장감리`라는 별도 용어는 없음
- **대비표** : 사업자가 설계·최종 산출물의 세부 검사항목별 과업내용 반영 여부를 정리해 감리법인에 제출하는 표. 설계단계에서 적합·부적합 판정이 가능하게 구체화됐는지 점검하고, 종료단계에서 항목별 이행 여부를 적합·부적합으로 판정(감리기준 제9조·제10조). 현행 감리기준에 `검사기준서`라는 용어는 없음

## 2~4교시 25점 답안

## Ⅰ. 정보시스템 감리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정보시스템 감리** 는 발주자·사업자로부터 독립된 감리법인이 감리기준에 따라 정보시스템 구축의 적정성을 점검하는 활동 |
| 목적 | 사업 결함·위험의 조기 발견과 사업 품질 확보 |

## Ⅱ. 독립된 제3자 점검이라는 정보시스템 감리의 특징

| 특징 | 의미 |
|---|---|
| 독립성 | 발주기관의 부당한 개입·간섭 금지(법 제57조제2항) |
| 법정 의무 | 대통령령 기준에 해당하는 사업의 감리 의무 |
| 기준 기반 점검 | 고시된 **감리기준** 에 따른 점검 항목·방법 |
| 결과 반영 의무 | 사업자의 감리 결과 반영(법 제57조제3항) |

## Ⅲ. 감리의 법적 구조와 수행 절차

### 감리 관련 규범 구성

```text
전자정부법 ── 감리 의무·독립성·결과 반영
    │
    ├─ 시행령 ── 의무감리 대상(제71조)·절차(제72조)
    │
    └─ 감리기준 ── 업무범위·절차·준수사항의 세부 기준
```

감리기준의 직접 근거는 「전자정부법」 제57조제5항의 행정안전부장관 고시 의무

### 시행령 절차 확대: 감리 수행 절차(시행령 제72조제2항)

```text
감리계약 체결
    ↓
예비조사와 감리계획 수립
    ↓
감리 착수회의
    ↓
감리 시행과 감리보고서 작성
    ↓
감리 종료회의·감리보고서 통보
    ↓
시정 조치 결과의 확인·통보
```

수행 형태에 따른 일부 절차의 변경·생략 허용. 감리기준상 3단계감리(요구정의·설계·종료)가 원칙이며, 설계·종료단계에서는 사업자가 제출한 **대비표** 의 세부 검사항목별로 과업내용 반영 여부를 적합·부적합으로 판정(제9조·제10조). 위험도·난이도가 높은 사업에는 **상주감리** 추가 가능(제3조제2항)

## Ⅳ. 정보시스템 감리와 PMO의 역할 비교

| 구분 | 정보시스템 감리 | PMO(전자정부사업관리 위탁) |
|---|---|---|
| 법적 근거 | 「전자정부법」 제57조 | 「전자정부법」 제64조의2 |
| 위치 | 발주자·사업자와 독립된 제3자 | 발주기관의 관리·감독 업무 대행 |
| 주요 활동 | 감리기준에 따른 점검·개선 권고 | 일정·위험·품질 관리와 의사결정 지원 |
| 결과 처리 | 감리보고서 통보와 시정 조치 확인 | 발주기관에 대한 관리 결과 보고 |

- 적용 관계: 전자정부사업관리를 위탁한 사업 중 시행령 제71조제2항 각 호의 사업(제1호: 대국민·공동이용 사업 중 사업비 1억 원 이상 5억 원 미만, 제2호: 사업기간 5개월 미만 구축사업)만 의무감리 예외(법 제57조제1항 단서)
- 역할 경계: 관리 대행과 독립 점검의 구분. 한 조직이 두 역할을 겸하면 감리 독립성 약화

## Ⅴ. 정보시스템 감리의 한계와 방안

| 한계 | 방안 |
|---|---|
| PMO와 감리의 역할·보고 경로 혼재로 독립성 약화 | 감리는 독립 점검, PMO는 관리 대행으로 보고 경로 분리 |
| 사업자의 조치 완료 보고만으로 지적사항 종결 | 감리법인의 증거 확인을 시정 조치 종결 조건으로 지정 |
| 단계 감리 사이의 설계 변경이 점검에서 누락 | 영향이 큰 변경의 추가 점검 또는 상주감리 적용 |
| 사업 특성과 무관한 일률적 점검 항목 | 과업 내용 기반 점검 항목의 감리계획 반영 |

## Ⅵ. 제언

지적사항 종결을 사업자 조치·감리법인 확인·발주기관 수락의 세 단계로 분리하는 종결 기준의 감리계획 명시

### 지적사항 종결 책임 구조

```text
감리 지적사항
    │
    ├─ 사업자 ── 시정 조치 수행과 증거 제출
    │
    ├─ 감리법인 ── 조치 결과의 증거 확인·통보
    │
    └─ 발주기관 ── 확인 결과 검토와 종결 수락
```

### 감리법인 확인 확대: 시정 조치 확인 판정

```text
사업자의 조치 완료 보고
    ↓
지적 근거인 감리기준 항목과 조치 증거 대조
    ├─ 증거 불충분 → 보완 요구, 미종결 유지
    └─ 증거 충분 → 확인 결과 통보
                      ↓
                 발주기관 종결 수락
```

### 선택 근거: 보고 기반 종결과의 비교

| 구분 | 사업자 보고 기반 종결 | 제언: 3단계 분리 종결 |
|---|---|---|
| 종결 판단 주체 | 사업자 | 감리법인 확인 후 발주기관 |
| 종결 근거 | 조치 완료 보고 | 감리기준 항목 대비 조치 증거 |
| 미흡 조치 처리 | 종결 후 운영 단계에서 발견 | 확인 단계에서 보완 요구 |
| 독립성 영향 | 점검 결과의 이행 여부 불명확 | 독립 점검의 결과 반영 확인 |

## 출제 이력과 검증 출처

- 제136회 2교시: 정보시스템 감리와 PMO(전자정부사업관리 위탁)를 활용한 사업관리. 감리의 법적 근거, PMO의 정의와 역할, PMO 대상 사업의 범위, PMO와 상주감리의 비교
- 제134회 4교시: 클라우드 전환 사업의 단계별 감리 방법과 검토 항목. 전환 사업 적용 범위로 기본 답안과 구별
- 제137회 3교시: 시스템 운영·유지보수 감리의 개념과 점검분야. 운영 단계 적용 범위로 기본 답안과 구별
- 「전자정부법」 제57조·제58조·제64조의2 — 법률 제21394호, 2026.8.28. 시행
- 「전자정부법 시행령」 제71조·제72조 — 대통령령 제36605호, 2026.8.28. 시행
- 「정보시스템 감리기준」 — 행정안전부고시 제2024-53호, 2024.6.27. 시행
- 한국지능정보사회진흥원(NIA), 지능정보기술 감리 실무 가이드(2023)
