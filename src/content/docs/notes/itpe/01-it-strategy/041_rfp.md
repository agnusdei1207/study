## 연관 키워드

- 제안요청서(RFP, Request for Proposal), 요구사항 정의, 제안 평가
- 정보요청서(RFI), 과업내용서, 경쟁 제안

## Ⅰ. RFP의 개요

- 핵심 요약 : 사업 요구와 평가 기준을 문서로 정의해 공급자의 해결 방안을 경쟁으로 받는 조달 문서.
- 개념 : **제안요청서** (RFP, Request for Proposal)는 발주 기관이 사업 목적·요구사항·제안 조건·평가 기준을 문서로 정의해 공급자에게 해결 방안과 가격의 제안을 요청하는 조달 문서.
- 배경 및 필요성 : 요구가 구두·임의로 전달되면 제안 간 비교가 불가능하고 계약 분쟁의 소지가 커지며, 공공 부문에서는 예산 집행의 투명성과 공정성 확보가 제도적 요구.
- 주요 목적 : 동일 기준의 경쟁 제안을 통해 최적 공급자를 선정하고 계약 이행의 명확한 기준 확보.

## Ⅱ. RFP의 특징 및 장점

- 핵심 요약 : 요구의 문서화·평가 기준 공개·계약 연계가 공정성과 이행 관리의 기반을 제공.

1. 요구사항의 문서화 : 사업 목적·범위·기능·비기능 요구의 **요구사항 정의** 명시 → 발주자·공급자 간 이해 일치.
2. 평가 기준의 사전 공개 : **제안 평가** 항목과 가중치의 공개 → 공정 경쟁과 이의 제기 감소.
3. 제안 비교의 동일 기준 : 정해진 양식·기준으로 제안 접수 → 대안 비교의 객관성 확보.
4. 계약 연계 : 채택 제안이 **과업내용서** (계약 후 수행 범위와 산출물을 구체화한 문서)로 이어짐 → 범위·책임의 명확화.
5. 시장 정보의 반영 : 사전 **정보요청서** (RFI, Request for Information)로 기술 수준·시장 여건 확인 → 현실적 요구 수준 설정.

## Ⅲ. RFP의 구조 (흐름)

- 핵심 요약 : 문서 구성의 다섯 축과, 시장 조사부터 계약까지의 조달 절차상 위치.

```text
[ RFP 문서 구성 ]

사업 개요·추진 배경
   ↓
요구사항 정의 (기능·비기능)
   ↓
제안 조건·일정·양식
   ↓
제안 평가 기준·방법
   ↓
계약 조건·관리 사항
```

```text
[ 조달 절차에서의 위치 ]

요구사항 정의
   ↓
정보요청서 (RFI) 발행 — 시장 조사
   ↓
제안요청서 (RFP) 발행
   ↓
제안서 접수·제안 평가
   ↓
협상·계약 체결
```

- 작성 원칙 : 필수·선택 요구의 구분, 검증 가능한 표현, 평가 기준과 요구의 정합성 유지.

## Ⅳ. RFP와 RFI의 비교

- 핵심 요약 : 해결 방안의 제안을 받는 계약 전단계 문서와 시장·기술 정보를 수집하는 조사 문서의 구분.

| 비교 축 | 제안요청서 (RFP) | 정보요청서 (RFI) |
| --- | --- | --- |
| 목적 | 해결 방안·가격의 제안 접수 | 시장·기술 수준의 정보 수집 |
| 시점 | 구매 결정 후 공급자 선정 단계 | 요구사항 정의·사업 계획 단계 |
| 내용 | 요구사항·평가 기준·계약 조건 | 관심 분야·질문 항목 |
| 구속력 | 제안이 계약 협상의 기초 | 응답에 계약상 구속력 없음 |
| 후속 절차 | 제안 평가·협상·계약 | RFP 작성·요구 수준 조정 |

## Ⅴ. RFP의 한계와 방안

- 핵심 요약 : 과대 사양·평가 주관성·요구 고착·범위 변경을 문서 설계와 절차로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 과대 사양 요구 | 가능한 기능의 전부 나열 → 비용·일정 과다 | 필수·선택 요구의 구분 | 요구사항 수 |
| 평가 주관성 | 정성 항목의 평가자 편향 → 선정 논란 | 평가 기준 상세화·복수 평가자 | 평가 점수 분산 |
| 요구 고착 | 작성 시점 기술로 고정 → 신기술 반영 지연 | 성능·출력 중심 요구로 전환 | 대안 제안 수 |
| 범위 변경 분쟁 | 계약 후 요구 추가 → 비용 분쟁 | 변경 관리 절차·요구 추적 명시 | 변경 요청 건수 |

## Ⅵ. RFP에 대한 기술사적 제언

- 핵심 요약 : 발주 기관의 RFP 품질 관리 체계와 평가 전문성 확보로 조달 성과 제고 필요.
- 표준화 : 사업 유형별 RFP 표준 템플릿과 작성 점검 목록의 발주 기관 공통 자산화.
- 시장 조사 : 사업 계획 단계의 RFI 활용을 절차화해 요구 수준의 현실성 확보.
- 평가 체계 : 평가위원 명단 관리·이해충돌 점검·이의 처리 절차의 제도 정비.
- 이행 연계 : 채택 제안과 과업내용서·요구사항 추적 문서의 연결로 계약 이행 관리.

## Ⅶ. 결론

- 핵심 요약 : RFP는 요구·평가·계약 기준의 사전 문서화로 공정한 공급자 선정을 가능하게 하는 조달 문서.
- 시장 조사부터 계약 이행까지 문서 간 연계가 유지될 때 조달 품질이 담보됨.
