## Ⅰ. 프로젝트 관리 종합 체계의 개요

- 핵심 요약 : 프로젝트의 고유한 산출물을 기간·비용·범위·품질 안에서 달성하도록 자원과 위험을 통합 관리하는 한시적 체계.
- 개념 : 프로젝트의 고유한 산출물을 기간·비용·범위·품질 안에서 달성하도록 자원과 위험을 통합 관리하는 한시적 체계.
- 배경 및 필요성 : 다수의 이해관계자·작업·제약이 얽힌 임시 사업은 범위·일정·원가를 따로 관리할 때 목표와 실행의 불일치 발생.
- 주요 목적 : 프로젝트 산출물·편익을 합의된 범위·일정·원가·품질 기준 안에서 달성.

## Ⅱ. 프로젝트 관리 종합 체계의 특징 및 장점

- 핵심 요약 : 전략목표와 프로젝트 결과 연결; 범위·일정·원가 기준선 통합; 위험·의사소통·변경의 지속 관리.

1. 전략 정렬 : 사업목표·편익을 프로젝트 성공기준과 연결 → 산출물만 완성하고 기대효과를 놓치는 위험 감소.
2. 기준선 통합 : 범위·일정·원가·품질 계획의 상호 영향을 관리 → 변경의 파급효과를 판단하고 현실적 전망 유지.
3. 이해관계자 관리 : 요구·기대·의사결정 권한을 지속 조정 → 승인 지연과 수용성 저하 예방.
4. 위험·변경 통제 : 위험 소유자와 변경승인 절차를 운영 → 불확실성·범위변경을 예측 가능한 결정으로 전환.

## Ⅲ. 프로젝트 관리 종합 체계의 구조 (흐름)

- 핵심 요약 : 착수와 목표합의 → 범위·일정·원가 계획 → 실행·감시통제 → 인수·종료 및 편익 추적.

```text
착수와 목표합의
   ↓
범위·일정·원가 계획
   ↓
실행·감시통제
   ↓
인수·종료 및 편익 추적
```

```text
[착수] 사업 타당성·목표·이해관계자 승인
   ↓
[계획] 범위·일정·원가·품질·위험 기준선 수립
   ↓
[실행·통제] 작업 수행, 진척·변경·위험 통합관리
   ↓
[종료] 산출물 인수·교훈 기록·자원 해제
   ↓
[전환] 운영조직 인계와 편익 실현 추적
```

## Ⅳ. 프로젝트 관리 종합 체계와 대안의 비교

- 핵심 요약 : 운영은 지속적 서비스 제공, 프로젝트는 고유한 결과물과 종료시점 보유.

| 비교 대상·관점 | 차이와 선택기준 |
| --- | --- |
| 목적·시간성 | 운영은 반복적 서비스·제품을 지속 제공; 프로젝트는 고유한 산출물을 만들고 종료 |
| 성공기준 | 운영은 안정성·서비스수준·효율; 프로젝트는 범위·일정·원가·품질과 편익 |
| 관리방식 | 운영은 표준절차·수요에 따른 상시 관리; 프로젝트는 단계·기준선·변경통제에 따른 한시 관리 |
| 연계 | 프로젝트 종료 후 운영조직에 산출물·지식·책임을 인계하고 편익을 추적 |

## Ⅵ. 프로젝트 관리 종합 체계 적용에 대한 기술사적 제언

- 핵심 요약 : 조직은 프로젝트 성공을 산출물 인도뿐 아니라 편익 실현까지 추적.

1. 사업후원자 : 전략목표·편익·수용기준을 승인하고 범위·예산 변경의 의사결정을 적시에 수행.
2. 프로젝트 관리자 : 통합 기준선을 수립하고 일정·원가·위험·품질 정보를 연계해 예측과 시정조치를 운영.
3. PMO·운영조직 : 공통 방법론과 포트폴리오 우선순위를 관리하고, 종료 후 산출물 인계와 편익 실현을 점검.
