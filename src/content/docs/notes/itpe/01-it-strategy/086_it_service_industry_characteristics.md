## 연관 키워드

- IT서비스 산업, IT Service Industry, 지식기반 산업
- SI, System Integration, 수주형 SI, M/M, Man-Month
- 무형성, 주문 생산성, 인력 중심 생산성
- 다단계 하도급, 피라미드 구조, 원청-하청
- 공공 시장, 소프트웨어 진흥법, 국가계약법
- SaaS, Software as a Service, IP, Intellectual Property
- ITSQF, IT Sectoral Qualifications Framework

## Ⅰ. IT서비스 산업 특수성의 개요

- 핵심 요약 : 정보기술을 활용해 고객 비즈니스 문제를 해결하는 고부가가치 지식기반 산업으로, 제조업과 구별되는 고유 특성을 지님.
- 개념 : 정보기술(IT, Information Technology)을 활용하여 고객의 비즈니스 문제를 해결하고 정보시스템을 기획, 구축, 운영, 유지보수하는 **고부가가치 지식기반 산업**으로, 제조업과 구별되는 고유한 산업적·구조적 특성을 지님.
- 배경 및 필요성 : **수주형 SI**(System Integration) 중심의 산업 구조, 높은 인건비 의존도, 다단계 하도급 관행 및 불명확한 요구사항으로 인한 분쟁 등 국내 IT(Information Technology)서비스 산업의 구조적 취약점을 개선할 제도적 해법 요구.
- 주요 목적 : 산업 특성에 부합하는 제도적 안전망 구축, 소프트웨어 제값 주기 정착, SW(Software) 인력의 처우 개선 및 고부가가치 솔루션/클라우드 산업으로의 체질 개선.

## Ⅱ. IT서비스 산업의 특징 및 장점

- 핵심 요약 : 무형성·주문생산성·인력중심·다단계하도급·공공규제 의존의 5대 구조적 특성.

1. **무형·주문형 서비스** : 고객 업무에 맞춰 설계해 현장 문제를 직접 해결할 수 있다.
2. **전문 인력 중심** : 도메인 지식과 기술 역량이 서비스 품질을 결정해 고부가가치 창출 가능성이 있다.
3. **요구 변화 대응** : 개발 중 학습한 내용을 반영해 고객의 실제 필요에 맞게 조정한다.
4. **지식재산 재사용** : 공통 모듈·솔루션으로 축적 지식을 제품화해 규모의 경제를 만든다.
5. **운영 연계** : 구축 후 유지관리 경험을 개선에 반영해 장기 고객 가치를 높인다.

```text
[ IT서비스 산업 특수성 ]
무형성 및 주문 생산성
   - 완제품이 없는 상태에서 수주 후 개발
   - 초기 요구사항 모호성
인력 중심 생산성
   - 원가의 대부분이 인적 자원(인건비)
   - 공학적 자동화 한계
다단계 하도급 구조
   - 원청 대기업 -> 1차 협력사 -> 2차 하도급
   - 피라미드 구조
공공 시장의 규제 의존
   - 소프트웨어 진흥법, 국가계약법
   - 공공 조달 법령의 제도적 영향력 절대적
```

## Ⅲ. IT서비스 산업의 구조 (흐름)

- 핵심 요약 : 원청-하청-재하청으로 이어지는 다단계 하도급 피라미드와 공공 발주 중심 생태계.
- **다단계 하도급 피라미드 구조**.

```text
[ 다단계 하도급 피라미드 ]
원청 대기업 (Prime Contractor)
   ↓ 하도급
1차 협력사 (Subcontractor)
   ↓ 재하도급
2차 하도급사 (Sub-subcontractor)
   ↓
실제 개발 인력 (최종 수행자)
   └─ 단가 삭감 · 처우 악화 · 책임 불명확
```

- **산업 생태계 흐름**.

```text
[ IT서비스 산업 생태계 흐름 ]
공공/민간 발주
   ↓
원수급자 (수주)
   ↓
과업 수행 (M/M 인력 투입)
   ↓
납품 및 유지보수
   ↓
지식 자산 축적 / 솔루션화
```

## Ⅳ. 전통 제조업과 IT서비스 산업의 비교

- 핵심 요약 : 제조업은 유형 제품·대량 양산, IT서비스는 무형 소프트웨어·주문 제작 중심.

| 비교 항목 | 전통 제조업 (Manufacturing) | IT서비스 산업 (IT Services) |
|---|---|---|
| 제품 특성 | 유형의 물리적 실체 존재, 규격화 용이 | 무형의 논리적 소프트웨어, 가시성 부재 |
| 생산 방식 | 공장 설비 기반 대량 양산 (Scale-out) | 엔지니어 투입 중심 주문 제작 (Labor-intensive) |
| 한계 비용 | 제품 생산마다 추가 원자재/공정 비용 소요 | 개발 완료 후 복제 비용은 거의 0에 수렴 |
| 요구사항 변경 | 설계 확정 후 변경 시 막대한 물리적 손실 | 개발 중에도 지속적인 요구 변경 발생 (소프트한 특성) |
| 수익 모델 | 단위 완제품 판매 마진 | 프로젝트 수행 용역비, 시스템 유지보수 요율 |

## Ⅴ. IT서비스 산업의 한계와 방안

- 핵심 요약 : 노동집약성, 다단계 하도급, 제한된 시장을 제품화와 계약 투명성으로 보완한다.

| 한계 | 방안 |
|---|---|
| 인력 투입량만 매출에 연결되는 **노동집약 구조** | 재사용 가능한 IP·SaaS 제품과 자동화 자산 축적 |
| **다단계 하도급**은 책임·대가·품질을 흐릴 수 있음 | 수행 주체·업무 범위·대가·검수 책임을 계약과 현장 기록에 명시 |
| 특정 발주처 의존은 **시장 확장성** 제한 | 공통 기능을 제품화하고 다양한 산업·지역에서 실증 |

## Ⅵ. IT서비스 산업에 대한 기술사적 제언

- 핵심 요약 : SaaS·IP 전환, 과업 변경 대가 법제화, ITSQF 기반 인재 육성.
- 수주형 SI에서 SaaS 및 IP 기반 솔루션 비즈니스로의 전환 : 인건비 투입(M/M) 중심의 저마진 용역 사업을 탈피하고, 자체 지식재산권(IP)과 클라우드 SaaS 솔루션을 확보하여 규모의 경제 실현.
- 과업 변경에 따른 적정 대가 지급 법제화 준수 : 공공 발주기관의 불합리한 무상 과업 추가 관행을 근절하고, 과업심의위원회 개최 의무화를 통해 정당한 추가 대가 지급 및 일정 연장 보장.
- 직무 역량 체계(ITSQF, IT Sectoral Qualifications Framework) 기반의 고급 인재 육성 : 단순 연차 기반의 중급/고급 기술자 구분을 지양하고, 실제 실무 역량과 성과를 반영하는 ITSQF 및 공인 기술사 인력 중심의 전문성 우대 체계 확립.

## Ⅶ. 결론

- 핵심 요약 : IT서비스 산업은 고부가가치 지식기반 산업으로 SaaS·IP 전환과 제도 개선이 필요.
- 요약 : IT서비스 산업은 정보기술을 활용한 고부가가치 지식기반 산업으로, 무형성·인력중심·하도급·규제 의존의 특성을 지님.
- 시사점 : 노동집약적 SI 구조를 탈피하고 SaaS·IP 기반 고부가가치 모델로 전환하며, 하도급 제한과 ITSQF 기반 인재 육성으로 산업 체질을 개선해야 함.
