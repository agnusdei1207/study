## 연관 키워드

- IT서비스 산업 (IT Service Industry), 지식기반 산업
- SI (System Integration), 수주형 SI, M/M (Man-Month)
- 무형성, 주문 생산성, 인력 중심 생산성
- 다단계 하도급, 피라미드 구조, 원청-하청
- 공공 시장, 소프트웨어 진흥법, 국가계약법
- SaaS (Software as a Service), IP (Intellectual Property), ITSQF (IT Sectoral Qualifications Framework)

## Ⅰ. IT서비스 산업 특수성의 개요

- 핵심 요약 : 정보기술로 고객 업무 문제를 해결하는 지식기반 산업으로, 무형성과 인력 의존 등 제조업과 구별되는 구조적 특성을 지님
- 개념 : 정보기술(IT, Information Technology)을 활용해 고객의 업무 문제를 해결하고 정보시스템을 기획, 구축, 운영, 유지보수하는 **지식기반 산업**으로, 제조업과 구별되는 고유한 산업적·구조적 특성을 지님
- 배경 및 필요성 : **수주형 SI** (System Integration)가 산업의 중심을 이루면서 인건비 의존도가 높고, 다단계 하도급과 불명확한 요구사항으로 분쟁이 잦아, 산업 특성에 맞는 제도적 안전망이 필요
- 주요 목적 : 소프트웨어의 적정 대가 정착, 소프트웨어 인력의 처우 개선, 고부가가치 솔루션과 클라우드 사업으로의 전환

## Ⅱ. IT서비스 산업의 특징 및 장점

- 핵심 요약 : 무형성, 주문 생산성, 인력 중심, 다단계 하도급, 공공 규제 의존의 5대 구조적 특성

1. **무형·주문형 서비스** : 고객 업무에 맞춰 설계하고 현장 문제를 직접 해결한다 → 맞춤형 가치 창출
2. **전문 인력 중심** : 도메인 지식과 기술 역량이 서비스 품질을 결정한다 → 고부가가치 창출 가능성
3. **요구 변화 대응** : 개발 중 학습한 내용을 반영해 고객의 실제 필요에 맞춰 조정한다 → 결과물의 적합성 제고
4. **지식재산 재사용** : 공통 모듈과 솔루션으로 축적한 지식을 제품화한다 → 반복 비용 절감
5. **운영 연계** : 구축 후 유지관리 경험을 개선에 반영한다 → 장기 고객 가치 향상

```text
[ IT서비스 산업 구조적 특성 ]
무형성 및 주문 생산성
   완제품 없이 수주 후 개발
   초기 요구사항 모호성
인력 중심 생산성
   원가의 대부분이 인건비
다단계 하도급 구조
   원청 → 1차 협력사 → 2차 하도급
공공 시장의 규제 의존
   소프트웨어 진흥법, 국가계약법
```

## Ⅲ. IT서비스 산업의 구조 (흐름)

- 핵심 요약 : 원청에서 하도급으로 이어지는 다단계 피라미드 구조와 발주 중심의 산업 생태계

```text
[ 다단계 하도급 피라미드 ]
원청 대기업 (Prime Contractor)
   ↓ 하도급
1차 협력사
   ↓ 재하도급
2차 하도급사
   ↓
실제 개발 인력 (최종 수행자)
   → 단가 하락, 처우 악화, 책임 불명확
```

```text
[ IT서비스 산업 생태계 흐름 ]
공공·민간 발주
   ↓
원수급자 수주
   ↓
과업 수행 (인월 M/M, Man-Month 투입)
   ↓
납품 및 유지보수
   ↓
지식 자산 축적과 솔루션화
```

## Ⅳ. 전통 제조업과 IT서비스 산업의 비교

- 핵심 요약 : 제조업은 유형 제품의 대량 양산 중심, IT서비스 산업은 무형 소프트웨어의 주문 제작 중심

| 비교 항목 | 전통 제조업 | IT서비스 산업 |
| --- | --- | --- |
| 제품 특성 | 유형의 물리적 실체, 규격화 용이 | 무형의 논리적 소프트웨어, 가시성 부재 |
| 생산 방식 | 공장 설비 기반 대량 양산 | 엔지니어 투입 중심 주문 제작 |
| 추가 생산 비용 | 제품마다 원자재와 공정 비용 발생 | 개발 완료 후 복제 비용이 거의 없음 |
| 요구사항 변경 | 설계 확정 후 변경 시 물리적 손실 큼 | 개발 중에도 요구 변경이 지속적으로 발생 |
| 수익 모델 | 완제품 판매 마진 | 프로젝트 용역비, 유지보수 요율 |

## Ⅴ. IT서비스 산업의 한계와 방안

- 핵심 요약 : 노동집약 구조, 다단계 하도급, 발주처 의존을 제품화와 계약 투명성으로 보완

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 인력 투입량만 매출에 연결되는 **노동집약 구조** | 투입 인력 증가 없이는 성장 불가 | 재사용 가능한 **지식재산** (IP, Intellectual Property)과 **서비스형 소프트웨어** (SaaS, Software as a Service) 제품, 자동화 자산 축적 | 자산 재사용률, 제품 매출 비중 |
| **다단계 하도급** | 책임·대가·품질이 흐려져 현장 인력에게 불이익 전가 | 수행 주체, 업무 범위, 대가, 검수 책임을 계약과 현장 기록에 명시 | 하도급 단계 수, 대가 지급 준수율 |
| 특정 발주처 의존 | 한 고객의 예산에 매출이 묶여 시장 확장성 제한 | 공통 기능을 제품화해 다양한 산업과 지역에서 실증 | 고객 다변화 지수 |

## Ⅵ. IT서비스 산업에 대한 기술사적 제언

- 핵심 요약 : 수주형 SI에서 SaaS·IP 기반 사업으로의 전환, 과업 변경 대가의 제도화, ITSQF 기반 인재 육성을 중심으로 산업 체질을 개선

1. 인건비 중심의 수주형 SI에서 벗어나려면, 사업자는 자체 IP와 SaaS 솔루션을 축적해 인력 투입량과 무관하게 매출이 늘어나는 구조를 만들어야 한다
2. 발주 과정에서 과업이 바뀌었을 때 추가 대가와 일정 연장을 보장하는 기준을 제도로 정착시키면, 무상 과업 추가 관행을 줄일 수 있다
3. 연차 중심의 기술자 구분 대신 실무 역량과 성과를 반영하는 **IT 직무 역량체계** (ITSQF, IT Sectoral Qualifications Framework)를 대가 산정과 인사 평가에 연결하면, 고급 기술 인력을 우대하는 기준이 마련된다

## Ⅶ. 결론

- 핵심 요약 : IT서비스 산업은 무형성과 인력 중심의 특성을 지닌 지식기반 산업으로, 발주 구조와 인력 대가 체계가 함께 바뀔 때 고부가가치화가 가능
- 시사점 : 노동집약적 SI 구조에서 SaaS·IP 기반 모델로의 전환이 산업 체질 개선의 핵심 과제다
