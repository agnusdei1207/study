## 지식 로드맵 내 현재 위치

IT 전략·관리 → 지속가능 경영과 IT → **ESG 경영**

## 30초 인출

- 본질: ESG 경영은 환경(Environmental)·사회(Social)·지배구조(Governance) 요소를 경영 의사결정과 위험·기회 관리에 반영하는 경영
- 메커니즘: 지속가능성 관련 위험·기회를 지배구조·전략·위험관리·지표와 목표의 네 영역으로 관리하고, 지표는 조직 경계 안의 원천 데이터를 산정해 공시
- 통찰: 지표값의 근거를 검증자가 추적하지 못하면 공시 신뢰가 무너지므로 지표별로 원천 데이터·경계·산식·변경 이력을 연결해 보관하되 최소 보고 대상인 Scope 1·2부터 적용

<details>
<summary>핵심 용어</summary>

- **ESG 경영** : 환경·사회·지배구조 요소를 경영 의사결정과 위험·기회 관리에 반영하는 경영
- **ESG** : 환경(Environmental)·사회(Social)·지배구조(Governance) 세 요소를 가리키는 말로, 금융권의 분석·투자 의사결정에 통합할 이슈를 뜻함
- **ISSB(International Sustainability Standards Board)** : 지속가능성 공시기준(IFRS S1·S2)을 제정한 기준위원회
- **IFRS S1(General Requirements for Disclosure of Sustainability-related Financial Information)** : 지속가능성 관련 위험·기회를 지배구조·전략·위험관리·지표와 목표 영역으로 공시하도록 정한 일반 요구사항
- **IFRS S2(Climate-related Disclosures)** : 기후 관련 물리적 위험·전환 위험·기회의 공시 기준
- **GHG Protocol(Greenhouse Gas Protocol) 기업 표준** : 조직 단위 온실가스 배출량의 산정·보고 요구사항과 지침
- **Scope 1·2·3** : 온실가스 배출을 소유·통제 배출원의 직접 배출(Scope 1), 구매한 전력 생산에서의 간접 배출(Scope 2), 그 밖의 간접 배출(Scope 3)로 나눈 범주
- **조직 경계·운영 경계** : 배출량에 포함할 사업 단위와 배출원의 범위
- **감사 추적(Audit Trail)** : 산정 과정의 절차·가정·한계를 문서와 기록으로 남겨 내부 검토자와 외부 검증자가 신뢰성을 확인하게 하는 근거

## 2~4교시 25점 답안

## Ⅰ. ESG 경영의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ESG 경영** 은 환경·사회·지배구조 요소를 경영 의사결정과 위험·기회 관리에 반영하는 경영 |
| 목적 | 위험 관리와 지속가능한 기업가치 확보 |

## Ⅱ. 재무 성과와 연결되는 ESG 경영의 특징

| 특징 | 내용 |
|---|---|
| 세 요소의 경영 반영 | 환경·사회·지배구조 이슈 관리가 기업 전반의 경영 품질의 일부 |
| 위험·기회 관점 | 위험 관리, 규제 대응, 신규 시장 접근을 통한 기업가치 제고 |
| 재무 연계 | 지속가능성 관련 위험·기회가 현금흐름·자금 조달 접근성·자본비용에 미치는 영향 공시 |
| 데이터 기반 | 지표와 목표로 성과를 측정해 재무보고 이용자에게 공시 |

## Ⅲ. 지속가능성 공시 체계와 온실가스 지표

### 지속가능성 관련 위험·기회의 공시 영역 (IFRS S1)

```text
지속가능성 관련 위험·기회 공시
    │
    ├─ 지배구조(Governance) ── 위험을 감시·관리하는 프로세스·통제·절차
    │
    ├─ 전략(Strategy) ── 위험·기회를 관리하는 전략
    │
    ├─ 위험관리(Risk Management) ── 식별·평가·우선순위화·감시 프로세스
    │
    └─ 지표와 목표(Metrics and Targets) ── 위험·기회 관련 성과와 목표 진전도
```

### 지표와 목표 확대: 온실가스 배출 지표의 범주 (GHG Protocol)

```text
온실가스 배출량
    │
    ├─ Scope 1 ── 소유·통제하는 배출원의 직접 배출
    │
    ├─ Scope 2 ── 구매한 전력 생산에 따른 간접 배출
    │
    └─ Scope 3 ── 그 밖의 간접 배출 (기업 표준상 선택 보고 범주)

Scope 1·2는 최소한 구분하여 산정·보고
```

## Ⅳ. ESG 지표 산정 원칙과 IT 지원

| IT 지원과 연결되는 산정 원칙 | 요구 내용 | IT 지원 |
|---|---|---|
| **완전성(Completeness)** | 선택한 경계 안의 모든 배출원 산정 | 경계 안 배출원 목록과 원천 시스템의 연계 |
| **일관성(Consistency)** | 경계·방법 변경의 문서화와 사유 제시로 연도 간 비교 가능 | 산정 방법·경계의 버전 관리 |
| **정확성(Accuracy)** | 불확실성을 실행 가능한 범위에서 최소화 | 계측 데이터의 자동 수집 |
| **투명성(Transparency)** | 절차·가정·한계를 감사 추적으로 문서화 | 산정 과정과 근거의 이력 보존 |

## Ⅴ. ESG 지표 관리의 한계와 방안

| 한계 | 방안 |
|---|---|
| 배출원 데이터가 여러 시스템과 수기 기록에 흩어져 경계 안 배출원 누락 | 경계 안 배출원 목록을 기준으로 원천 시스템을 연계하고 미산정 항목은 사유와 함께 기록 |
| 경계·산정 방법 변경으로 연도 간 비교 불가 | 변경 내용과 사유를 이력으로 남기고 기준 연도 데이터 재산정 여부 판단 |
| 지표값의 산정 근거가 흩어져 검증자의 재현 불가 | 지표값에 원천 데이터·가정·산식을 연결해 보관 |

## Ⅵ. 제언

지표값마다 원천 데이터·경계·산식·변경 이력을 연결해 보관하고, 최소 보고 대상인 Scope 1·2부터 적용해 Scope 3로 확대

### 지표별 증적 연결 구조

```text
지표값 (예: Scope 2 배출량)
    │
    ├─ 조직 경계·운영 경계 ── 포함 사업 단위·배출원
    │
    ├─ 산정식·가정 ── 방법과 변경 이력
    │
    └─ 원천 데이터 ── 구매 전력 사용량 등 원천 시스템의 값
```

### 적용 순서와 이력 보호

```text
Scope 1·2 지표에 증적 연결 적용
    ↓
연결 여부를 지표 확정의 선행 조건으로 설정
    ↓
Scope 3 지표로 확대
    │
    └─ 증적 이력은 사후 수정 불가한 기록으로 보관
```

### 선택 근거: 지표값만 보관하는 방식과의 비교

| 구분 | 지표값만 보관 | 제언: 증적 연결 보관 |
|---|---|---|
| 보관 대상 | 최종 배출량 | 값과 원천 데이터·경계·산식·이력 |
| 검증 방식 | 담당자 설명에 의존 | 검증자의 재산정 |
| 변경 대응 | 방법 변경 사실이 기록에서 누락 | 변경 내용과 사유가 이력에 남음 |
