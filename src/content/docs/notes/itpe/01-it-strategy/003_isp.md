## 전체 로드맵 내 현재 위치

```text
▶ 01 정보 전략·관리 ─→ 02 SW공학·프로젝트 ─→ 03 데이터
          │
          └─→ 04 컴퓨터시스템 ─→ 05 네트워크 ─→ 06 보안
                                     │
                                     └─→ 07 AI·신기술
전 영역 준거 ───────────────────────────→ 08 법·정책
```

- 현재 위치: `01 정보 전략·관리 > 정보화 전략수립 > ISP`

## 큰 그림과 30초 인출

```text
[경영·정책 목표]
        │
        ▼
       ISP
착수 → 환경 → 현황 → 미래모델 → 이행계획
        │       │        │           │
      동인     As-Is    To-Be     과제·우선순위·로드맵
        │                            │
        └──── 경영목표-과제 추적 ───┘
                                     ▼
                              ISMP·예산·구축사업
```

- 본질: **경영·정책 전략을 목표 정보화 모델과 중장기 실행과제로 전환하는 전사 정보화 전략계획**
- 단계: `착수 → 환경분석 → 현황분석 → 미래모델설계 → 이행계획수립`
- 구분: ISP는 과제·우선순위 선정, ISMP는 특정 구축사업의 요건·구조·예산·RFP 구체화

## 예상문제

> ISP의 정의와 목적, 수행방법론 체계와 절차를 설명하고 ISMP·BPR과 비교한 후 실행력 확보방안을 제시하시오. (25점)

## Ⅰ. 경영전략을 정보화 과제와 로드맵으로 전환하는 ISP 개요

- 정의: **ISP**는 조직의 경영·정책 목표와 대내외 환경, 업무·정보시스템 현황을 분석하여 목표 정보화 모델과 중장기 이행과제·투자 로드맵을 수립하는 활동
- 목적: 부서별 중복투자와 시스템 파편화를 줄이고, 한정된 예산을 전략 기여도와 시급성이 높은 과제에 배분
- 필요성: 클라우드·AI·데이터 전환이 개별 기술 도입으로 분산되지 않도록 업무·데이터·응용·기술의 목표모델과 전환 순서를 합의

## Ⅱ. 전사 관점·경영 정렬·우선순위 중심의 특징

| 특징 | 메커니즘 | 산출 효과 |
|---|---|---|
| **전사 관점** | 조직·업무·데이터·응용·기술을 통합 분석 | 중복·단절 과제 제거 |
| **경영전략 정렬** | 목표·CSF·성과지표와 정보화 과제 연결 | IT 투자 근거 확보 |
| **As-Is/To-Be 격차** | 현황 문제와 목표 역량 차이 분석 | 변화과제 도출 |
| **포트폴리오화** | 가치·시급성·위험·의존성으로 과제 평가 | 우선순위와 투자 균형 |
| **중장기 이행성** | 선후행·자원·예산을 연차별 배치 | 실행 가능한 로드맵 확보 |

## Ⅲ. 환경·현황·미래모델·이행계획의 구성

```text
[환경 분석]
 정책·산업·기술·경영전략·이해관계자
           │
           ▼
[현황 분석: As-Is]
 업무 ─ 데이터 ─ 응용 ─ 기술 ─ 관리
           │ Gap·문제·개선기회
           ▼
[미래모델: To-Be]
 정보화 비전·원칙·목표 업무/데이터/응용/기술
           │
           ▼
[이행계획]
 과제 포트폴리오·우선순위·로드맵·예산·성과지표
```

| 영역 | 핵심 활동 | 대표 산출물 |
|---|---|---|
| **환경** | 정책·시장·기술·경영목표·CSF 분석 | 환경분석서, 정보화 요구·동인 |
| **현황** | 업무·데이터·시스템·인프라·관리 진단 | 현황모델, 문제·개선기회 |
| **미래모델** | 정보화 비전·원칙·목표모델 설계 | To-Be 모델, 과제 후보 |
| **이행계획** | 과제 우선순위·선후행·비용·성과 설계 | 과제정의서, 연차별 로드맵 |

## Ⅳ. 착수에서 이행계획까지의 5단계 방법론

```text
① 프로젝트 착수
 범위·조직·일정·품질·이해관계자 확정
          ↓
② 환경 분석
 정책·산업·기술·경영전략과 핵심 동인 도출
          ↓
③ 현황 분석
 업무·정보기술 현황, 성숙도·문제·원인 진단
          ↓
④ 미래모델 설계
 비전·원칙, 목표 업무·데이터·응용·기술 모델 수립
          ↓
⑤ 이행계획 수립
 과제정의 → 우선순위 → 의존성 → 로드맵 → 예산·성과지표
```

- 단계별 산출물은 `경영목표 → 문제·요구 → 목표역량 → 과제 → 성과지표`로 추적 가능해야 함
- 현업·경영진·IT가 중간 산출물을 공동 검토해 미래모델의 수용성과 실행 책임을 확보

## Ⅴ. ISP·ISMP·BPR 비교

| 기준 | ISP | ISMP | BPR |
|---|---|---|---|
| 목적 | 중장기 정보화 방향·과제 선정 | 특정 구축사업의 발주 기준선 구체화 | 업무 프로세스의 근본적 재설계 |
| 범위 | 조직·업무 전반 | 단위 정보시스템·구축사업 | 핵심 프로세스·조직·역할 |
| 핵심 질문 | 무엇을 어떤 순서로 정보화할 것인가 | 무엇을 어떤 요건·구조·비용으로 구축할 것인가 | 업무를 왜·어떻게 다시 설계할 것인가 |
| 산출물 | 비전·목표모델·과제·로드맵 | 요건기술서·구조·예산·RFP | To-Be 프로세스·조직·성과모델 |
| 연계 | BPR 결과를 시스템 과제로 반영 | ISP의 확정 과제를 상세화 | 프로세스 혁신 요구를 ISP에 제공 |

## Ⅵ. 정적 보고서를 막는 실행력 확보방안

| 문제 | 원인 | 대책 | 검증지표 |
|---|---|---|---|
| **전략-과제 단절** | 기술 아이디어 중심 과제 도출 | 목표-CSF-과제-KPI 추적 매트릭스 | 추적 불가 과제 수 |
| **현업 수용성 부족** | 외부 컨설턴트·IT 부서 중심 | 업무 책임자의 의사결정·검토·승인 참여 | 현업 승인·이행 책임률 |
| **우선순위 왜곡** | 편익만 강조하고 의존성·위험 누락 | 가치·시급성·위험·법규·선후행의 다기준 평가 | 지연·중단·중복 과제 비율 |
| **기술 노후화** | 장기 계획을 고정된 규격으로 작성 | 원칙·역량 중심 목표모델과 정기 롤링 검토 | 로드맵 갱신·재평가율 |
| **예산과 계획 불일치** | 과제 규모·자원·운영비 근거 부족 | 단계별 규모·TCO·편익·재원 조달 검증 | 승인예산-실행예산 차이 |

- EA·포트폴리오 저장소와 연결해 과제 상태·의존성·성과를 지속 갱신하고, 환경 변화 시 중단·병합·순서 조정을 수행
- 특정 구축과제는 ISMP로 상세화하여 ISP 수준의 추정치를 바로 RFP로 전환하지 않도록 통제

## Ⅶ. 과제 수보다 전략 추적성을 확보하는 결론

- ISP의 품질은 많은 정보화 과제가 아니라 **경영목표부터 과제·예산·성과까지 이어지는 추적성**과 실행 우선순위의 명료성으로 판정
- 정기 롤링 검토와 포트폴리오 거버넌스로 과제를 갱신하고, 확정 단위사업은 ISMP와 조달 절차로 구체화해야 함

## 1교시 10점 답안 발췌

### 1. 정의·목적

- 경영·정책 목표와 환경·현황을 분석해 목표 정보화 모델과 중장기 과제·투자 로드맵을 수립하는 전사 정보화 전략계획

### 2. 방법론

```text
착수 → 환경분석 → 현황분석 → 미래모델설계 → 이행계획
                                              └─ 과제·우선순위·로드맵·예산
```

### 3. ISP와 ISMP

| ISP | ISMP |
|---|---|
| 중장기 방향과 과제 선정 | 특정 구축사업의 요건·구조·예산·RFP 상세화 |
