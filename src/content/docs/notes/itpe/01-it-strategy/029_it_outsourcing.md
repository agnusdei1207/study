## 연관 키워드

- IT 아웃소싱, 소싱전략, SLA, 공급자 관리, 종료계획

## Ⅰ. IT 아웃소싱의 개요

- 핵심 요약 : **IT** (Information Technology) 아웃소싱은 조직이 정보기술 기능·서비스의 일부를 외부 전문 공급자에게 계약으로 위탁하는 조달·운영 방식.
- 개념 : IT 아웃소싱은 조직이 정보기술 기능·서비스의 일부를 외부 전문 공급자에게 계약으로 위탁하는 조달·운영 방식.
- 배경 및 필요성 : 전문성·규모의 경제를 얻을 수 있지만 통제·지식·보안·공급자 의존이 함께 발생.
- 주요 목적 : 비용·역량·서비스 수준의 균형과 핵심업무 통제 유지.

## Ⅱ. IT 아웃소싱의 특징 및 장점

- 핵심 요약 : 업무·서비스 범위, SLA, 책임경계, 데이터·보안 통제, 성과·변경·종료 거버넌스가 위탁 운영을 통제.

1. 업무·서비스 범위 정의 : 위탁 대상·산출물·제외사항을 명시 → 과업 경계와 책임 명확화.
2. **SLA** (Service Level Agreement) : 서비스 수준·측정·보상·시정을 계약화 → 성과 관리와 개선 근거 확보.
3. 책임경계 : 발주자·공급자·하도급의 책임을 구분 → 서비스 소유권과 통제 유지.
4. 데이터·보안 통제 : 접근·암호화·감사·하도급 통제 → 정보보호와 지식 유출 방지.
5. 성과·변경·종료 거버넌스 : KPI·변경절차·종료·이관 계획 운영 → 공급자 종속과 서비스 저하 대응.

## Ⅲ. IT 아웃소싱의 구조 (흐름)

- 핵심 요약 : 소싱전략·위험평가 → RFP·공급자 선정 → 전환·지식이관 → SLA 기반 운영·감독 → 갱신·전환·종료.

```text
소싱전략·위험평가
   ↓
RFP·공급자 선정
   ↓
전환·지식이관
   ↓
SLA 기반 운영·감독
   ↓
갱신·전환·종료
```

- 핵심 구조 : 소싱결정 → 계약·전환 → 서비스 측정·감독 → 개선·종료전환.

```text
소싱결정 → 계약·전환 → 서비스 측정·감독 → 개선·종료전환
```

## Ⅳ. 내부 자체운영과 IT 아웃소싱의 비교

- 핵심 요약 : 내부 자체운영은 내부 인력·플랫폼 직접 운영, IT 아웃소싱은 외부 전문성·용량을 계약으로 활용.

| 비교 기준 | 내부 자체운영 | IT 아웃소싱 |
| --- | --- | --- |
| 역량·통제 | 내부 인력·플랫폼 직접 운영 | 외부 전문성·용량을 계약으로 활용 |
| 비용 구조 | 고정비·인력 유지 | 변동비·계약 기반 |
| 지식 보유 | 내부에 축적 | 공급자에 의존, 이관 필요 |
| 적합한 경우 | 핵심업무·보안 민감 시스템 | 표준화된·규모가 큰 서비스 |

## Ⅴ. IT 아웃소싱의 한계와 방안

- 핵심 요약 : 공급자 종속·서비스 저하·보안·지식 유출; 이식성·SLA·통제로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 공급자 종속 | 독점기술·이관정보 미흡 | 이식성·문서·종료지원·대체안 확보 | 전환기간·비용 |
| 서비스 저하 | SLA·측정·책임경계 불명확 | 측정 가능한 SLA·시정·에스컬레이션 | SLA 미달률 |
| 보안·지식 유출 | 접근·하도급·데이터 통제 약함 | 최소권한·감사권·하도급 통제 | 보안사고·위반 |
| 지식 손실 | 내부 역량 약화 | 핵심 지식 내부 유지·교육 | 내부 인력 보유율 |

## Ⅵ. IT 아웃소싱에 대한 제언

- 핵심 요약 : 발주조직은 위탁 후에도 서비스 소유자·보안책임·공급자 감독 역량을 내부에 유지.

1. 발주조직 : 위탁 후에도 서비스 소유자·보안책임·공급자 감독 역량을 내부에 유지.
2. 실무 담당자 : 이식성·문서·종료지원·대체안 확보; 측정 가능한 SLA·시정·에스컬레이션; 최소권한·감사권·하도급 통제.
3. 공급자 관리자 : 전환기간·비용·SLA 미달률·보안사고·위반 지표를 정기 검토하고 미달 원인·시정조치·잔여위험 기록.

## Ⅶ. IT 아웃소싱의 결론

- 핵심 요약 : IT 아웃소싱은 조직이 정보기술 기능·서비스의 일부를 외부 전문 공급자에게 계약으로 위탁하는 조달·운영 방식.
- 시사점 : 아웃소싱은 책임의 이전이 아니라 수행수단의 조달이므로 발주자의 거버넌스 책임은 지속.
