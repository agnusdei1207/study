## 연관 키워드

- 계층 분석 과정(AHP, Analytic Hierarchy Process)
- 계층구조, 쌍대비교, 가중치, 고유값, 일관성 비율(CR), 민감도 분석

## Ⅰ. AHP의 개요

- 핵심 요약 : 복수 기준의 의사결정 문제를 계층구조로 분해하고 쌍대비교로 가중치와 대안 우선순위를 산출하는 기법.
- 개념 : 복잡한 의사결정 문제를 목표·기준·대안의 **계층구조**(판단 요소를 상하 층위로 배열한 구조)로 분해하고, 요소 간 쌍대비교로 기준별 가중치와 대안의 종합 우선순위를 산출하는 다기준 의사결정 기법 (**계층 분석 과정**, AHP, Analytic Hierarchy Process).
- 배경 및 필요성 : 비용·품질·리스크처럼 상충하는 기준 아래 여러 대안을 비교할 때 판단이 개인 직관에 의존하면 가중치의 논리적 설명과 일관성 검증이 어려운 문제.
- 주요 목적 : 주관적 판단의 수치화와 일관성 검증을 거친 투명한 의사결정 근거 확보를 통한 조직 자원 배분의 합리화.

## Ⅱ. AHP의 특징 및 장점

- 핵심 요약 : 계층화·쌍대비교·일관성 검증의 절차가 판단의 투명성과 결론의 신뢰성이라는 장점으로 연결되는 의사결정 체계.

1. 문제의 계층화 : 목표-기준-대안의 층위 분해 → 복합 판단 구조의 명료화와 개별 판단 범위의 축소.
2. 쌍대비교 방식 : **쌍대비교**(두 요소를 나란히 놓고 상대적 중요도를 1~9 척도로 판정하는 방식)로 두 요소씩만 판정 → 정성 판단의 수치화와 응답 부담 감소.
3. 고유값 기반 가중치 : 쌍대비교 행렬의 **고유값**(행렬이 담은 상대 관계를 대표하는 수학적 값) 계산으로 기준별 **가중치**(각 기준이 전체 판단에서 차지하는 상대 비중) 산출 → 판단자별로 흩어지던 중요도의 일관된 도출.
4. 일관성 검증 : **일관성 비율** (CR, Consistency Ratio)로 쌍대비교 판단의 모순 정도를 측정하고 0.1 이하일 때 판단 수용 → 직관 응답의 논리적 품질 보장.
5. 민감도 분석 : **민감도 분석**(가중치 변화가 대안 순위에 미치는 영향의 확인)으로 결론의 강건성 검토 → 순위의 안정성 입증.

## Ⅲ. AHP의 구조 (흐름)

- 핵심 요약 : 계층구조 설계 → 쌍대비교 행렬 작성 → 고유값·가중치 산출 → 일관성 검증 → 종합 우선순위·민감도 분석의 절차.

```text
[ AHP 계층구조 ]

목표 (예: 시스템 선정)
   ↓
기준 (기능·비용·리스크)
   ↓
대안 (A안·B안·C안)
```

```text
[ AHP 수행 절차 ]

계층구조 설계
   ↓
쌍대비교 행렬 작성
   ↓
고유값·가중치 산출
   ↓
일관성 비율(CR) 검증
   ↓
종합 우선순위 결정
```

## Ⅳ. AHP와 단순 가중합 기법의 비교

- 핵심 요약 : AHP가 쌍대비교 절차로 가중치를 도출하고 일관성까지 검증하는 반면, 단순 가중합은 사전 합의된 가중치와 점수의 곱셈 합산으로 신속하게 평가.

| 비교 축 | AHP | 단순 가중합(Weighted Sum) |
| --- | --- | --- |
| 가중치 결정 | 쌍대비교와 고유값 계산으로 도출 | 평가자의 사전 지정·합의 |
| 판단 구조 | 목표-기준-대안의 계층구조 | 평면적 기준 목록 |
| 일관성 검증 | 일관성 비율(CR)로 모순 탐지 | 별도 검증 절차 없음 |
| 분석 부담 | 비교 판정 횟수·계산 부담 | 계산 단순, 설계 속도 빠름 |
| 적합 상황 | 기준 간 상충·계층이 복잡한 선정 | 기준·척도가 사전 합의된 평가 |

## Ⅴ. AHP의 한계와 방안

- 핵심 요약 : 판단 불일관과 비교 부담이 신뢰성·효율성의 제약이며, 일관성 검증과 기준 축약이 대응 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 판단 불일관 | 응답자의 모순 판단 → 가중치·순위 신뢰 저하 | CR 초과 시 재판단, 판단 근거 기록 | 일관성 비율(CR) |
| 비교 부담 증가 | n개 요소의 n(n-1)/2회 비교 → 응답 피로·판단 품질 저하 | 기준 축약·계층 그룹화 | 비교 판정 횟수 |
| 척도 해석 편차 | 1~9 척도의 판단자별 해석 차이 → 가중치 변동 | 복수 판단자 운영·기하평균 집계 | 판단자 간 편차 |
| 순위 전도 | 신규 대안 추가 시 기존 순위 뒤집힘 → 결론 안정성 훼손 | 민감도 분석·순위 안정성 확인 | 순위 변동률 |

## Ⅵ. AHP에 대한 기술사적 제언

- 핵심 요약 : 평가 절차의 표준화와 판단 근거 공개로 AHP를 조직의 표준 의사결정 절차로 내재화.
- 평가 거버넌스 : 기준 정의·척도·판단자 선정 절차의 표준 절차서 제정과 이해관계자 검토 단계 운영.
- 도구·기록 : 쌍대비교 입력과 CR 산출을 지원하는 공통 도구 보급, 판단 근거의 문서화·보관 체계 구축.
- 적용 확대 : IT 투자 우선순위·공급자 선정·과제 평가 등 주요 의사결정에 AHP 절차 적용의 제도화.

## Ⅶ. 결론

- 핵심 요약 : AHP는 주관적 판단을 계층화·쌍대비교·고유값 계산으로 정리하고 일관성까지 검증하는 다기준 의사결정 체계.
- 절차의 투명성과 검증 가능성이 조직 의사결정의 공통 언어로서의 활용 가치.
