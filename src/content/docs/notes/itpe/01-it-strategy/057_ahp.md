## 연관 키워드

- AHP, 계층구조, 쌍대비교, 가중치, 일관성비율(CR), 민감도 분석

## Ⅰ. AHP의 개요

- 핵심 요약 : 다기준 의사결정을 목표·기준·대안의 계층으로 구조화하고 쌍대비교로 우선순위를 산출하는 방법.
- 개념 : 다기준 의사결정을 목표·기준·대안의 계층으로 구조화하고 쌍대비교로 우선순위를 산출하는 방법.
- 배경 및 필요성 : 비용·품질·위험처럼 상충하는 기준과 대안을 비교할 때 판단근거와 가중치의 투명성 필요.
- 주요 목적 : 다수 기준과 대안을 일관된 근거로 비교해 우선순위와 의사결정 설명력 확보.

## Ⅱ. AHP의 특징 및 장점

- 핵심 요약 : 정성 판단의 구조화; 기준별 상대 가중치; 판단 일관성 검토.

1. 특징 : 목표-기준-대안의 계층화 → 복합 판단의 구조 명료화.
2. 특징 : 쌍대비교와 가중치 산출 → 기준별 상대 중요도 반영.
3. 특징 : 일관성·민감도 검토 → 판단오류와 순위 불안정성 확인.

## Ⅲ. AHP의 구조 (흐름)

- 핵심 요약 : 목표·기준·대안 계층화 → 쌍대비교 → 가중치 산출 → 일관성 검토 → 종합순위·민감도 분석.

```text
목표·기준·대안 계층화
   ↓
쌍대비교
   ↓
가중치 산출
   ↓
일관성 검토
   ↓

쌍대비교와 가중치 산출
   ↓
일관성·민감도 검토
```

## Ⅳ. AHP와 대안평가 기법의 비교

- 핵심 요약 : AHP는 계층화·쌍대비교로 기준 가중치와 우선순위를 도출하고, TOPSIS는 이상해와의 상대적 거리를, 가중합은 직접 점수합을 사용.

| 기법 | 평가 방식 | 적합한 선택기준 |
| --- | --- | --- |
| AHP | 계층별 쌍대비교로 기준 가중치·대안 우선순위 산출, 일관성 검토 | 판단 근거와 계층적 기준 구조가 중요한 경우 |
| TOPSIS | 가중 정규화 점수에서 이상해·반이상해와의 거리 계산 | 정량 속성별 대안을 이상적 조합과 비교할 경우 |
| 단순 가중합 | 사전에 정한 가중치와 점수를 곱해 합산 | 기준·척도가 합의되어 있고 계산 단순성이 중요한 경우 |

## Ⅴ. AHP의 한계와 방안

- 핵심 요약 : 전문가 편향은 복수 판단자와 근거 기록으로, 비교 과다는 계층 단순화로 완화.

| 위험 | 원인·영향 | 대응통제 | 확인지표 |
| --- | --- | --- | --- |
| 쌍대비교 불일관 | 가중치와 순위 신뢰 저하 | 일관성비율 확인·재판단·전문가 합의 | CR, 재판단 비율 |
| 기준·대안 과다 | 비교부담과 판단 피로 증가 | 계층·기준을 의사결정 목적에 맞게 축약 | 비교 횟수, 순위 민감도 |

## Ⅵ. AHP 적용에 대한 기술사적 제언

- 핵심 요약 : 기준과 판단 근거를 공개하고 가중치 변화에 따른 순위 안정성을 확인.

1. 평가자는 기준·척도 정의를 사전 합의하고 판단근거와 일관성비율을 검토한 뒤 가중치 변화에 대한 순위 민감도까지 보고.

## Ⅶ. 결론

- 핵심 요약 : 다기준 의사결정을 목표·기준·대안의 계층으로 구조화하고 쌍대비교로 우선순위를 산출하는 방법.
- 시사점 : AHP 결과는 판단의 일관성·민감도 검토를 거쳐야 의사결정 근거로 활용.
