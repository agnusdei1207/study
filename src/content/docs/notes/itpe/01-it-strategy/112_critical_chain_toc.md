## Ⅰ. CCPM·TOC의 개요

- **개념** : 골드랫(Goldratt) 박사의 제약이론(TOC, Theory of Constraints)을 프로젝트 일정 관리에 적용한 기법으로, 작업 경로 간의 자원 제약(Resource Dependencies)을 고려하고, 개별 작업의 안전 여유(Safety Time)를 제거하여 프로젝트 말단과 합류 지점에 버퍼(Buffer)로 집중 관리하는 크리티컬 체인 프로젝트 관리(Critical Chain Project Management).
- **배경 및 필요성** : 전통적 CPM/PERT 방식에서 개별 작업자마다 안전 시간을 부여함에도 불구하고 파킨슨의 법칙과 학생 증후군으로 인해 프로젝트가 항상 지연되는 모순을 극복하기 위해 창안.
- **주요 목적** : 프로젝트 전체 납기 대폭 단축(20~30%), 자원 충돌 방지, 버퍼 관리(Buffer Management)를 통한 조기 지연 경보.

## Ⅱ. 인간 행동의 법칙과 CCPM의 버퍼 집약 메커니즘

```text
[전통적 방식: 안전 여유의 낭비]
  - 파킨슨의 법칙 (Parkinson's Law) : 작업에 주어진 시간만큼 업무가 늘어남
  - 학생 증후군 (Student Syndrome)  : 마감 직전까지 작업을 미루다가 시작함
  - 자기완성의 함정 (Self-fulfilling) : 일찍 끝나도 다음 작업에 조기 인계하지 않음
        ↓
[CCPM 방식: 공격적 일정 추정 + 프로젝트 버퍼 집중]
  - 개별 작업의 기간을 50% 확률 수준(낙관적 추정)으로 대폭 축소
  - 깎아낸 안전 여유의 50%를 모아서 프로젝트 맨 뒤에 [프로젝트 버퍼(PB)]로 일괄 배치
  - 비주공정 경로가 합류하는 지점에 [피딩 버퍼(FB)] 배치, 자원 경합에 [자원 버퍼(RB)] 배치
```

## Ⅲ. CPM(주공정법)과 CCPM(크리티컬 체인)의 비교

| 비교 항목 | CPM (Critical Path Method) | CCPM (Critical Chain Project Management) |
|---|---|---|
| 경로 결정 기준 | 작업 간의 논리적 선후 의존관계만 고려 | 작업 의존관계 + 한정된 인적/물적 자원의 제약 동시 고려 |
| 안전 여유(안전시간) | 각 작업 패키지마다 개별적으로 분산 배치 | 개별 작업에서 제거하여 프로젝트/피딩 버퍼로 통합 배치 |
| 진척 관리 지표 | 계획 대비 완료율(%), EVM(SV, SPI) | 버퍼 소진율(Buffer Burn Rate) 대비 공정 진척도 |
| 작업 시작 태도 | 늦은 시작일(LS)까지 지연 가능 | 작업이 가능해지는 즉시 신속 착수(Relay Runner 태도) |

## Ⅳ. CCPM 버퍼 관리의 실무 적용을 위한 기술사적 제언

- **3색 버퍼 관리 신호등 체계(Trend Chart) 운영** : 버퍼 소진율에 따라 녹색(안전), 황색(주시/대책 수립), 적색(즉각적 시정 조치 발동)의 3단계 동적 통제 확립.
- **멀티태스킹(Multitasking)의 엄격한 금지** : 여러 프로젝트에 인력을 쪼개어 배정할 경우 발생하는 잦은 컨텍스트 스위칭(Context Switching) 낭비를 차단하고 단일 과업 집중 환경 보장.
- **문화적 신뢰 구축(Blameless Culture)** : 공격적인 50% 추정 일정으로 인해 개별 작업이 마감일을 넘기더라도 개발자를 문책하지 않고 전체 버퍼 소진 여부로 평가하는 심리적 안정감 제공 필수.
