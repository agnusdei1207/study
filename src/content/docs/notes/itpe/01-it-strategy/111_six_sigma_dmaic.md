## 연관 키워드

- Six Sigma, DMAIC, CTQ, 측정시스템, 원인분석, 통제계획

## Ⅰ. Six Sigma DMAIC의 개요

- 핵심 요약 : 기존 프로세스의 결함·변동을 고객 핵심품질 기준으로 측정·분석·개선·통제하는 순환방법.
- 개념 : **Six Sigma** (식스 시그마) **DMAIC** (Define, Measure, Analyze, Improve, Control)는 기존 프로세스의 결함과 변동을 데이터로 개선하는 순환방법.
- 배경 및 필요성 : 프로세스 결함과 편차의 원인이 경험·직관에 의존하면 개선효과가 재현되기 어려움.
- 주요 목적 : 고객 핵심품질을 기준으로 프로세스 변동과 결함을 줄이고 개선을 유지.

## Ⅱ. Six Sigma DMAIC의 특징 및 장점

- 핵심 요약 : 고객요구 중심·데이터 기반 원인제거·개선효과 통제를 하나의 개선 루프로 연결.

1. CTQ 기반 문제정의 (CTQ Definition) : 고객 핵심품질 특성과 문제 범위를 정의 → 개선대상과 고객가치 명확화.
2. 측정시스템 검증 (Measurement System Analysis) : 데이터 수집 체계와 측정 오차를 검증 → 신뢰할 수 있는 기준선 확보.
3. 데이터 기반 원인분석 (Data-Driven Root Cause Analysis) : 변동 원인을 통계적으로 확인 → 증상보다 근본원인 제거.
4. 개선안 검증 (Improvement Validation) : 개선안을 실험·파일럿으로 검증 → 효과와 부작용 확인.
5. 통제계획 수립 (Control Plan) : 관리도·표준작업·책임자를 운영 → 성과의 재발·퇴행 방지.

## Ⅲ. Six Sigma DMAIC의 구조 (흐름)

- 핵심 요약 : Define 문제정의 → Measure 기준선 측정 → Analyze 원인분석 → Improve 개선검증 → Control 유지관리.

```text
Define 문제정의
   ↓
Measure 기준선 측정
   ↓
Analyze 원인분석
   ↓
Improve 개선검증
   ↓
Control 유지관리
```

```text
CTQ 기반 문제정의
   ↓
측정시스템 검증
   ↓
데이터 기반 원인분석
   ↓
개선안 검증
   ↓
통제계획 수립
```

## Ⅳ. DMAIC와 DMADV의 비교

- 핵심 요약 : DMAIC는 기존 프로세스 개선, DMADV는 신규 제품·프로세스 설계에 적합.

| 개념·방법 | 주요 특성 | 적합한 선택 기준 |
| --- | --- | --- |
| DMAIC | 기존 프로세스의 문제를 측정·개선·통제 | 현재 운영의 결함·변동 감소 |
| DMADV (DFSS) | 요구부터 신규 제품·프로세스 설계·검증 | 기존 프로세스 개선으로 목표달성이 어려운 경우 |

## Ⅴ. Six Sigma DMAIC의 한계와 방안

- 핵심 요약 : 측정오류는 측정시스템 검증, 도구 중심화는 사업성과·고객가치 목표로 방지.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 측정체계 오류 | 잘못된 기준선·개선효과 판단 | 측정시스템 분석과 데이터 품질 검증 | 측정오차, 기준선 안정성 |
| 도구 중심화 | 기법 적용이 목적이 되어 성과 왜곡 | 고객가치·사업성과 목표와 연계 | CTQ 달성률, 재발률 |
| 개선효과 소멸 | 통제계획·책임자 부재 | 관리도·표준작업·이탈 대응 운영 | 개선 지속률, 재발률 |

## Ⅵ. Six Sigma DMAIC 적용에 대한 기술사적 제언

- 핵심 요약 : 현장 참여와 올바른 문제정의를 우선하고 개선 후 통제계획을 운영.

- 개선팀 : 고객 CTQ와 측정체계부터 확인하고 검증된 원인만 개선하며, 관리도·표준작업·책임자를 포함한 Control 계획을 유지.
- 경영진 : 개선 목표를 사업성과·고객가치와 연결하고 도구 적용보다 결과를 평가.
- 현장 조직 : 표준작업과 이탈 대응 절차를 운영하고 개선 지속률을 정기 점검.

## Ⅶ. 결론

- 핵심 요약 : Six Sigma DMAIC는 기존 프로세스의 결함·변동을 데이터로 개선하는 순환방법.
- 시사점 : DMAIC는 데이터 검증과 통제계획이 결합될 때 개선효과 지속.
