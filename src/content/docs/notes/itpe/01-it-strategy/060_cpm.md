## 연관 키워드

- 주공정법(CPM, Critical Path Method)
- 네트워크 다이어그램, 임계경로, 여유시간, 정방향·역방향 계산, PERT

## Ⅰ. CPM의 개요

- 핵심 요약 : 작업 간 선후관계와 소요기간의 네트워크 계산으로 최소 완료기간과 임계경로를 산출하는 일정관리 기법.
- 개념 : 프로젝트 작업의 선후관계와 소요기간을 **네트워크 다이어그램**(작업과 의존관계를 화살표로 연결해 표현한 그림)으로 표현하고, 정방향·역방향 계산으로 최소 완료기간과 **임계경로**(여유시간이 0인 작업으로 이어진 최장 경로)를 식별하는 일정관리 기법 (**주공정법**, CPM, Critical Path Method).
- 배경 및 필요성 : 다수 작업의 의존관계 속에서 전체 완료일을 결정하는 작업과 지연 허용 범위의 직관적 파악이 곤란.
- 주요 목적 : 관리 초점의 임계 작업 집중을 통한 프로젝트 기한 준수와 일정 지연 대응 비용의 최소화.

## Ⅱ. CPM의 특징 및 장점

- 핵심 요약 : 네트워크 계산과 여유시간 분석이 완료기간 산출과 관리 자원의 집중이라는 장점으로 연결되는 기법.

1. 결정론적 기간 계산 : 각 작업의 소요기간을 확정값으로 가정 → 계산 구조의 단순성과 결과 재현성 확보.
2. 정방향·역방향 계산 : **정방향·역방향 계산**(시작점에서 끝점까지, 끝점에서 시작점까지의 시점 계산)으로 각 작업의 빠른 시작·종료 시점(ES, Earliest Start; EF, Earliest Finish)과 늦은 시작·종료 시점(LS, Latest Start; LF, Latest Finish) 산출 → 작업별 허용 시점과 완료기간 도출.
3. 여유시간 분석 : **여유시간**(프로젝트 완료일 지연 없이 작업이 지연될 수 있는 시간)을 총여유(TF, Total Float)·자유여유(FF, Free Float)로 구분 → 지연 허용 범위와 후속 작업 영향의 판단.
4. 임계경로 집중 관리 : 여유시간 0 작업의 임계 작업 표시 → 한정된 관리 자원의 핵심 작업 배치.
5. 진척 기반 갱신 : 실적 반영 재계산으로 경로 변동 추적 → 완료일 예측의 최신성 유지.

## Ⅲ. CPM의 구조 (흐름)

- 핵심 요약 : 작업 분해 → 선후관계·기간 산정 → 네트워크 작성 → 정방향·역방향 계산 → 여유시간·임계경로 도출 → 진척 갱신의 절차.
- 작업 분해 구조(WBS, Work Breakdown Structure) : 프로젝트를 관리 가능한 작업 단위로 분해한 체계로 네트워크 작성의 입력.

```text
[ CPM 수행 절차 ]

작업 분해 (WBS)
   ↓
선후관계·기간 산정
   ↓
네트워크 다이어그램 작성
   ↓
정방향 계산 → ES·EF
   ↓
역방향 계산 → LS·LF
   ↓
여유시간·임계경로 도출
```

```text
[ 여유시간 산식 ]

총여유 TF = LS - ES = LF - EF
   ↓
TF = 0 → 임계 작업
   ↓
임계 작업의 연결 = 임계경로
```

## Ⅳ. CPM과 PERT의 비교

- 핵심 요약 : CPM이 확정 기간의 결정론적 계산이라면 **PERT** (Program Evaluation and Review Technique)는 **3점 추정**(낙관·최빈·비관 세 값으로 기간을 추정하고 기대기간=(낙관+4×최빈+비관)/6으로 계산하는 방식) 기반의 확률적 일정 기법.

| 비교 축 | CPM | PERT |
| --- | --- | --- |
| 기간 처리 | 작업별 확정 기간 (결정론) | 낙관·최빈·비관의 3점 추정 (확률론) |
| 핵심 산출 | 임계경로·여유시간 | 기대기간·기간 분산·완료 확률 |
| 관리 초점 | 일정·비용의 절충과 자원 활용 | 불확실성이 큰 기간의 추정 |
| 개발 배경 | 민간 건설·플랜트 사업의 일정 관리 | 군사 개발 사업의 불확실 일정 관리 |
| 적합 상황 | 기간 경험 데이터가 있는 반복성 사업 | 신규 개발·연구개발 등 변동성 큰 사업 |

## Ⅴ. CPM의 한계와 방안

- 핵심 요약 : 기간 오차와 자원 제약 미반영이 예측 신뢰성의 제약이며, 추정 보완과 주기 재계산이 대응 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 확정 기간의 오차 | 실제 기간 변동 미반영 → 완료일 예측 편차 | 불확실성 큰 작업의 3점 추정 병행 | 기간 편차율 |
| 자원 제약 미반영 | 논리관계 중심 수립 → 자원 과배정 | 자원 평준화·제약 반영 일정 조정 | 과배정 자원 수 |
| 임계경로 변동 | 진척 변화의 경로 이동 → 관리 사각 발생 | 주기 재계산·근접 임계 경로 감시 | 경로 변경 횟수 |
| 모델 유지 부담 | 대형 네트워크 갱신 비용 → 정보 최신성 저하 | 일정 도구 표준화·갱신 주기 제도화 | 갱신 지연 일수 |

## Ⅵ. CPM에 대한 기술사적 제언

- 핵심 요약 : 일정 기준선과 변경 통제, 임계 작업 지연 복구 절차의 거버넌스 정비.
- 거버넌스 : 프로젝트관리사무소(PMO, Project Management Office)의 일정 기준선 승인·변경 절차·보고 주기 표준화.
- 운영 체계 : 일정 도구와 실적 데이터의 연동을 통한 재계산 자동화, 임계·근접 임계 작업의 상시 모니터링.
- 복구 절차 : 임계 작업 지연 시 기간 단축(crashing)·병행 수행(fast tracking) 등 회복안의 사전 정의와 승인 절차 마련.

## Ⅶ. 결론

- 핵심 요약 : CPM은 작업 의존관계의 네트워크 계산으로 전체 기간을 좌우하는 임계경로를 밝히는 일정관리 기법.
- 여유시간 기반 우선순위 판단과 주기적 재계산의 결합이 기한 준수의 실무 기준.
