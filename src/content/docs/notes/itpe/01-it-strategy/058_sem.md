## 연관 키워드

- 전략적 기업관리(SEM, Strategic Enterprise Management)
- 전략계획, 예산·실적 통합, 차이분석, 롤링 예측, 성과지표, EPM

## Ⅰ. SEM의 개요

- 핵심 요약 : 전략의 수립부터 계획·예산, 실적 모니터링, 차이분석·예측까지 전사 경영 사이클을 통합 관리하는 체계.
- 개념 : 기업 전략의 수립·실행·모니터링·분석을 하나의 관리 프레임으로 통합해 전사 차원의 계획과 성과 의사결정을 지원하는 전략적 경영 체계 (**전략적 기업관리**, SEM, Strategic Enterprise Management).
- 배경 및 필요성 : 전략·예산·실적이 부서별로 다른 주기와 체계로 관리되고 운영 데이터가 전사적 자원관리(ERP, Enterprise Resource Planning) 등 시스템에 분산되면 전략과 실행의 괴리, 시장 변화 대응 지연 발생.
- 주요 목적 : 전략과 실행의 연결을 통한 자원 배분의 전략 정합성 확보와 기업 가치·경쟁력 제고.

## Ⅱ. SEM의 특징 및 장점

- 핵심 요약 : 계획·모니터링·분석의 통합이 전략 정합성과 대응 속도라는 장점으로 연결되는 전사 관리 체계.

1. 예산·실적 통합 : 전략계획·예산·실적·예측을 공통 데이터와 주기로 연결 → 부서 간 계획 불일치 해소와 전략 정합성 강화.
2. 재무·비재무 통합 : 재무 지표와 고객·프로세스·역량 등 비재무 **성과지표** (KPI, Key Performance Indicator)의 동시 관리 → 전략 실행의 다면 평가.
3. 모니터링·분석 사이클 : 실적 수집 후 **차이분석**(계획 대비 실적 차이를 원인별로 분해하는 분석)과 예측 갱신 수행 → 환경 변화 대응의 신속한 자원 재배분.
4. 시나리오 기반 계획 : **롤링 예측**(계획 기간을 일정 주기마다 앞으로 밀어 다시 수립하는 예측 방식)과 시나리오 재계획 지원 → 연례 계획의 경직성 완화.
5. 경영 의사결정 지원 : 경영진 보고·시뮬레이션을 위한 통합 분석 환경 제공 → 의사결정 속도와 근거 품질 향상.

## Ⅲ. SEM의 구조 (흐름)

- 핵심 요약 : 전략계획 → 계획·예산 편성 → 실행·실적 수집 → 차이분석·예측 → 전략·계획 조정으로 이어지는 순환 구조.

```text
[ SEM 경영 사이클 ]

전략계획 (전략 목표·목표치 설정)
   ↓
계획·예산 편성
   ↓
실행·실적 수집
   ↓
차이분석·롤링 예측
   ↓
전략·계획 조정 (재순환)
```

```text
[ SEM 통합 관리 영역 ]

전략 관리 : 전략 수립·목표 전개
계획·예산 : 전략의 수치화·자원 배분
성과 관리 : 성과지표 정의·실적 추적
분석 : 차이분석·수익성 분석·예측
```

## Ⅳ. SEM과 운영 데이터 중심 ERP 활용의 비교

- 핵심 요약 : ERP 활용이 거래·자원 등 운영 정보의 기록·처리에 중심을 두는 반면, SEM은 그 데이터 위에서 전략·계획·성과의 경영 판단을 지원.

| 비교 축 | SEM | 운영 데이터 중심 ERP 활용 |
| --- | --- | --- |
| 관리 대상 | 전략·계획·성과 등 경영 정보 | 거래·자원 등 운영 정보 |
| 시간 관점 | 미래 지향 (계획·예측·시나리오) | 현재·과거 지향 (실적 기록) |
| 데이터 형태 | 집계·요약·시나리오 데이터 | 상세 거래 데이터 |
| 주요 사용자 | 경영진·전략·재무 기획 조직 | 현업 부서·운영 담당자 |
| 대표 산출물 | 전략 보고·예측·차이분석 보고서 | 전표·재고 등 업무 처리 결과 |

## Ⅴ. SEM의 한계와 방안

- 핵심 요약 : 데이터 단절과 계획 경직성이 전략 실행력의 제약이며, 공통 지표 체계과 반복 예측이 대응 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 전략·재무 데이터 단절 | 지표 정의·계정 체계 불일치 → 전략과 실적 차이의 설명 곤란 | 공통 계정·성과지표 사전·데이터 소유자 지정 | 미매핑 지표 비율 |
| 계획 경직성 | 연 1회 예산 주기 → 시장 변화 반영 지연 | 롤링 예측·시나리오 재계획 도입 | 예측 오차율 |
| 지표 과다 | 관리 지표 증가 → 보고 부담·관리 초점 상실 | 전략 연계 핵심 지표의 선별·계층화 | 관리 지표 수 |
| 형식적 운영 | 도구 도입만으로 전략 검토 문화 부재 → 실행 성과 미흡 | 경영진 주도 검토 회의와 평가·보상 연계 | 검토 회의 이행률 |

## Ⅵ. SEM에 대한 기술사적 제언

- 핵심 요약 : 경영진 주도의 의사결정 체계와 공통 데이터 기반 구축으로 SEM을 경영 관리 제도로 정착.
- 거버넌스 : 전략·계획·성과를 함께 심의하는 경영진 주도 정기 심의 회의의 제도화.
- 데이터 기반 : ERP 운영 데이터와 성과 데이터를 연결하는 공통 데이터 모델·마스터 데이터 관리 체계 구축.
- 분석 고도화 : EPM(Enterprise Performance Management) 솔루션과 통계·예측 도구의 연계를 통한 예측 역량 강화.

## Ⅶ. 결론

- 핵심 요약 : SEM은 전략·계획·모니터링·분석을 하나의 순환 체계로 묶어 전략 실행력과 기업 가치를 높이는 전사 관리 프레임.
- ERP가 운영 사실의 기록 인프라라면 SEM은 그 위에서 전략 방향과 자원 배분을 결정하는 경영 관리 계층.
