## 연관 키워드

- 식스 시그마(Six Sigma), DMAIC
- 핵심 품질특성(CTQ), 측정시스템 분석(MSA), DPMO, 관리도, 통제계획, 사후 품질관리

## Ⅰ. Six Sigma DMAIC의 개요

- 핵심 요약 : 공정의 변동을 통계적으로 관리해 결함을 극소화하는 식스 시그마의 실행 절차인 DMAIC를 설명하는 항목.
- 개념 : **식스 시그마** (Six Sigma)는 공정 변동을 통계 기법으로 관리해 결함을 극소화하는 품질경영 방법론이며, **DMAIC** (Define, Measure, Analyze, Improve, Control)는 기존 프로세스를 정의·측정·분석·개선·관리의 다섯 단계로 개선하는 그 핵심 실행 절차이다.
- 배경 및 필요성 : 경험·직관 중심의 개선은 효과의 재현이 어렵고, 검사 중심의 사후 품질관리는 불량을 생산 후에 선별하는 구조라 근본 원인 제거가 불가능. 데이터 기반 개선 절차의 필요 대두.
- 주요 목적 : 고객 관점의 품질 기준에서 결함과 변동을 감소시키고, 개선 성과를 표준·통제로 지속시키는 전사 품질 수준의 향상.

## Ⅱ. Six Sigma DMAIC의 특징 및 장점

- 핵심 요약 : 고객 기준 정의·데이터 검증·통계적 원인 분석·개선 검증·지속 통제가 하나의 개선 주기로 연결되는 구조.

1. 고객 기준 문제 정의 : 고객 요구에서 **핵심 품질특성** (CTQ, Critical to Quality)을 도출해 문제 범위를 한정 → 개선 대상과 고객 가치의 정합성 확보.
2. 데이터 기반 접근 : **측정시스템 분석** (MSA, Measurement System Analysis)으로 측정 체계의 오차를 검증한 뒤 기준선을 확보 → 신뢰할 수 있는 성과 판단.
3. 통계적 원인 분석 : 공정 데이터로 변동 원인의 인과 관계를 검증 → 증상 처리가 아닌 근본 원인 제거 효과.
4. 검증 중심 개선 : 개선안을 실험·시범 적용으로 확인한 뒤 확산 → 부작용 최소화와 효과의 사전 입증.
5. 지속 통제 : **관리도**(공정이 통계적 관리 상태에 있는지 판단하는 도구)와 **통제계획**(개선 후 관리 항목·방법·책임을 정한 문서)으로 운영 → 성과 유지와 재발 방지 효과.

## Ⅲ. Six Sigma DMAIC의 구조 (흐름)

- 핵심 요약 : Define 문제 정의 → Measure 기준선 측정 → Analyze 원인 분석 → Improve 개선 검증 → Control 성과 유지의 단계 구조.
- 결함 수준은 백만 기회당 결함 수(DPMO, Defects Per Million Opportunities)로 측정하며, 시그마 수준이 높을수록 결함률이 낮아지는 관계.

```text
[ DMAIC 5단계 ]

Define 문제 정의
    ↓
Measure 기준선 측정
    ↓
Analyze 원인 분석
    ↓
Improve 개선 검증
    ↓
Control 성과 유지
```

```text
[ 단계별 핵심 산출 ]

CTQ·문제 범위 확정
    ↓
MSA 통과·기준선 확보
    ↓
검증된 근본 원인 목록
    ↓
효과 확인된 개선안
    ↓
관리도·통제계획 운영
```

## Ⅳ. Six Sigma DMAIC와 검사 중심 사후 품질관리의 비교

- 핵심 요약 : 생산 후 불량을 선별하는 사후 품질관리와 달리, DMAIC는 공정 데이터로 변동 원인을 제거하는 예방형 개선 구조.

| 비교 축 | 검사 중심 사후 품질관리 | Six Sigma DMAIC |
| --- | --- | --- |
| 품질 확보 방식 | 완제품 검사로 불량 선별 | 공정 변동 제거로 결함 발생 억제 |
| 개선 기준 | 경험·직관·관용 규격 | 고객 CTQ·통계 데이터 |
| 결함 대응 시점 | 생산 이후 선별·수정 | 공정 내 원인 제거·예방 |
| 담당 조직 | 품질 담당 부서 중심 | 전사 프로젝트·전문 인력 운영 |
| 성과 유지 | 검사 반복에 의존 | 통제계획·관리도로 지속 |

- 선택 기준 : 기존 프로세스의 결함·변동 감소가 목적이면 DMAIC, 신규 제품·프로세스 설계가 목적이면 DMADV(Define·Measure·Analyze·Design·Verify)가 적합.

## Ⅴ. Six Sigma DMAIC의 한계와 방안

- 핵심 요약 : 측정 오류는 측정시스템 분석으로, 도구 중심 실행은 고객·사업 목표 연계로, 성과 퇴행은 통제 체계로 막는 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 측정 체계 오류 | 측정 장비·방법의 편차 미검증 → 기준선·효과 오판 | 측정시스템 분석과 데이터 품질 검증 선행 | 기준선 안정성 |
| 도구 중심 실행 | 기법 적용 자체가 목적화 → 사업 성과와 무관한 개산 | 프로젝트 선정 시 CTQ·사업 목표 연계 | CTQ 달성률 |
| 개선 성과 퇴행 | 통제계획·책임자 부재 → 재발·원상 복귀 | 관리도·표준 작업·주기 감사 운영 | 재발률, 개선 지속률 |
| 전사 확산 정체 | 전문 인력 부족·현장 저항 → 일시적 유행으로 종료 | 전사 교육·프로젝트 관리 체계 구축 | 프로젝트 유지 수 |

## Ⅵ. Six Sigma DMAIC 적용에 대한 기술사적 제언

- 핵심 요약 : 경영진 주도의 전사 품질경영 체계와 전문 인력 육성·프로젝트 거버넌스를 갖춰 일회성 기법을 조직 역량으로 내재화하는 방향.
- 경영 체계 : 최고경영진이 품질 목표를 경영 전략에 편입하고 개선 성과를 경영 평가에 반영하는 전사 체계 구축.
- 인력 육성 : 챔피언·블랙벨트·그린벨트로 이어지는 벨트(Belt) 교육·인증 체계를 두어 개선 전문 인력을 지속 확보.
- 거버넌스 : 개선 프로젝트의 선정·투자·성과 평가를 포트폴리오로 관리하는 전사 거버넌스 정비.

## Ⅶ. 결론

- 핵심 요약 : Six Sigma DMAIC는 데이터와 통계로 기존 프로세스의 결함·변동을 줄이는 5단계 개선 절차.
- 검증된 원인 제거와 통제계획의 결합이 개선 성과의 지속 조건임.
