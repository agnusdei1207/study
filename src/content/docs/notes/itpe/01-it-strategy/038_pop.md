## 큰 그림과 30초 인출

```text
[전사적 자원관리 (ERP)] ── 생산계획·자재출고 ──> [제조실행시스템 (MES)]
                                                       │ 작업지시·라우팅
                                                       ▼
┌────────────────────────────────────────────────────────┐
│               생산시점관리 (POP: Point Of Production)  │
│ ├─ 현장 터치단말, 바코드/RFID 스캐너, 머신비전        │
│ ├─ 설비 PLC / 센서 데이터 수집 게이트웨이 (OPC-UA)    │
│ └─ 실시간 실적 집계 (가동률, 불량, 사이클타임)       │
└────────────────────────────────────────────────────────┘
                               │ 현장 실적 피드백
                               ▼
        [현장 공정 가시성 확보 및 품질 예지보전 연계]
```

- 본질: 제조 현장에서 제품이 생산되는 바로 그 시점(Point)과 장소에서 발생하는 생산 실적, 설비 가동 상태, 품질 및 불량 데이터를 센서, 단말기, PLC 등을 통해 실시간으로 자동 수집하여 상위 시스템(MES/ERP)에 전달하는 생산 현장 정보화 체계
- 위치: `ERP(경영계획) → MES(제조실행) → POP(현장수집) → PLC/센서(물리설비)`
- 핵심: 작업자 수기 전표 집계의 시차와 오류 제거 + 생산 실적의 실시간 집계 및 공정 투명성 확보
- 진화: 독립적인 전용 단말 기반에서 스마트팩토리 IIoT(산업용 사물인터넷) 엣지 컴퓨팅 노드로 통합

## 예상문제

> 스마트 제조 환경에서 생산시점관리(POP) 시스템의 개념과 주요 구성요소를 설명하고, 상위 시스템인 MES와의 역할 비교 및 현장 데이터 수집 자동화 구축 전략을 논하시오. (25점)

## Ⅰ. 제조 현장의 실시간 가시성 확보, POP 개요

- 정의: 공장 내 생산 라인에서 원자재 투입, 가공, 조립, 검사, 포장 등 각 공정이 일어나는 시점에 작업 실적, 설비 상태, 자재 위치, 불량 정보를 센서 및 전용 단말기로 실시간 수집·처리하는 현장 중심 관리 시스템
- 배경: 수작업 일보 집계로 인한 데이터 지연, 재고 불일치, 불량 발생 시 원인 추적 불가 등 공정 블랙박스 문제 해소
- 목적: 현장 데이터의 신속성·정확성 확보, 공정 간 리드타임 단축, 불량 로트(Lot) 즉시 추적, 설비 가동률 극대화

#### 한줄 요약
- 제품이 만들어지는 바로 그 순간 현장 데이터를 디지털화하여 공정 가시성을 여는 시스템임

## Ⅱ. POP 시스템의 4대 핵심 특징

| 특징 | 공학적 메커니즘 | 제조 현장 기여 효과 |
|---|---|---|
| **실시간성 (Real-time)** | 이벤트 발생 즉시 센서 트리거 및 밀리초 단위 데이터 전송 | 생산 진척 및 돌발 정지 사태의 즉각적 인지 |
| **현장 중심성 (Shop-floor)** | 방진·방수·내충격 산업용 단말기 및 터치 기반 직관적 UI | 열악한 공장 환경에서 작업자의 입력 실수 및 부담 최소화 |
| **자동 인식 연계** | 바코드, QR코드, RFID, 비전 카메라를 통한 비접촉 인식 | 바코드 스캔 한 번으로 자재 불출 및 로트 자동 추적 |
| **양방향 통신** | 현장 실적 업로드뿐 아니라 상위 작업표준서, 도면 다운로드 | 최신 변경 도면 즉시 배포로 오작업 방지 |

#### 한줄 요약
- 실시간성과 자동 인식을 결합해 현장의 데이터를 투명하게 상위 시스템으로 연결함

## Ⅲ. POP 시스템의 계층 아키텍처

```text
[경영 및 제조 총괄 계층] ─────── [전사적 자원관리 (ERP) / 제품수명주기관리 (PLM)]
                                             │ 생산 계획 / BOM / 원가
                                             ▼
[공정 제어 및 실행 계층] ─────── [제조 실행 시스템 (MES)]
                                             │ 작업 지시 / 공정 라우팅
                                             ▼
┌────────────────────────────────────────────────────────────────────────┐
│ [생산 시점 관리 계층 (POP)]                                           │
│  ├─ POP 미들웨어: 데이터 변환, 로컬 큐잉(Store-and-Forward), 프로토콜 변환│
│  ├─ 데이터베이스: 공정 실적 DB, 설비 로그 DB, 알람 이벤트 테이블       │
│  └─ 모니터링: 안돈(Andon) 전광판, 공정 대시보드, 가동률 차트          │
└────────────────────────────────────▲───────────────────────────────────┘
                                     │ 실시간 I/O, 센서 신호
[물리적 설비 및 현장 계층] ──────────┴────────────────────────────────────
 ├─ 자동 수집: 설비 PLC (Modbus, OPC-UA), 카운터 센서, 온도/압력 센서
 └─ 반자동 수집: 바코드 스캐너, RFID 게이트, 이동형 PDA, 터치 패널
```

| 계층 | 주요 구성요소 | 핵심 역할 및 기능 |
|---|---|---|
| **상위 연계 계층** | ERP, MES 인터페이스 엔진 | 작업 지시서 수신 및 완료 실적, 불량 수량, 투입 자재 역전송 |
| **POP 서버 계층** | 데이터 정제 엔진, 이벤트 브로커 | 초당 수천 건의 센서 패킷 파싱, 이상 징후 감지 시 경보 발생 |
| **엣지 미들웨어** | 산업용 게이트웨이, 프로토콜 변환기 | 이기종 PLC(지멘스, 미쓰비시 등) 신호를 표준 OPC-UA로 통일 |
| **현장 입력 계층** | 고정식/무선 바코드 건, RFID 리더 | 작업자 투입 자재 및 완제품 로트 식별 번호 즉각 인식 |
| **설비 계측 계층** | 인터록(Interlock) 센서, 디지털 카운터 | 작업자 개입 없이 물리적 생산 수량 및 기계 멈춤 자동 계측 |

#### 한줄 요약
- 상위 ERP/MES와 하위 PLC/센서 사이에서 이종 프로토콜을 변환하고 실적을 매개함

## Ⅳ. 생산 데이터 수집 및 처리 5단계 흐름

```text
① 작업지시 수신 → ② 자재 투입 및 로트 매칭 → ③ 설비 가동 및 실적 계측 → ④ 품질 검사 및 불량 판정 → ⑤ 상위 시스템 전송 및 안돈 표시
   └─ MES 작업오더      └─ RFID 바코드 스캔         └─ PLC 자동 카운팅            └─ 비전 검사기 연동          └─ ERP 원가 반영, 전광판 경보
```

| 단계 | 주요 수행 내용 | 핵심 데이터 및 산출물 |
|---|---|---|
| **1. 지시 수신** | MES로부터 작업지시 번호, 목표 수량, 공정 라우팅, 작업표준 수신 | 작업지시 데이터 |
| **2. 자재 식별** | 자재 창고에서 출고된 원자재 바코드를 스캔하여 지시서와 정합성 검증 | 로트 투입 이력(Lot Trace) |
| **3. 가동 계측** | 설비가 작동하면서 회전수, 타발수, 생산 수량을 센서가 자동 카운팅 | 설비 가동률, 사이클타임 |
| **4. 품질 검사** | 공정 내 치수 검사기, 머신비전 불량 판정 데이터를 POP로 인터페이스 | 불량 유형 코드, 수율 데이터 |
| **5. 실적 전송** | 양품 수량, 불량 수량, 설비 비가동 시간을 MES에 확정 전송 및 시각화 | 일일 생산 실적표, 안돈 알람 |

#### 한줄 요약
- 지시 수신부터 자재 스캔, 설비 카운팅, 품질 검사, 전송까지 자동화 파이프라인을 형성함

## Ⅴ. POP vs MES vs ERP 비교

| 비교 항목 | 생산시점관리 (POP) | 제조실행시스템 (MES) | 전사적자원관리 (ERP) |
|---|---|---|---|
| **관리 영역** | 생산 현장 시점 데이터 수집 및 감시 | 제조 현장 전반의 공정 제어 및 실행 | 기업 전체 경영 자원 (재무, 구매, 인사) |
| **시간 단위** | **초, 분 단위 (실시간)** | **분, 시간 단위 (준실시간)** | **일, 월, 분기 단위 (주기적)** |
| **주요 기능** | 실적 카운팅, 설비 가동 감시, 바코드 리딩 | 작업 스케줄링, 공정 추적, 품질 관리 | 생산 계획 수립(MRP), 원가 계산, 회계 |
| **데이터 성격** | 기계 신호, 센서 시계열, 단순 트랜잭션 | 공정 라우팅, 작업자 실적, 품질 검사서 | 집계된 제품 원가, 총 매출, 재고 금액 |
| **상호 관계** | MES의 현장 데이터 수집 센서 역할 | POP 데이터를 받아 공정을 제어하고 ERP에 전달 | MES 실적을 받아 손익 계산 및 경영 보고 |

#### 한줄 요약
- POP는 현장 센싱(초), MES는 공정 통제(시간), ERP는 경영 회계(일/월)를 담당함

## Ⅵ. 실무 POP 구축 실패 요인과 공학적 대책

- 적용 상황: 자동차 부품 프레스 및 조립 라인의 실시간 생산 모니터링 구축 사업

| 실패 요인 | 발생 원인 | 공학적·관리적 해결 대책 | 기대 효과 |
|---|---|---|---|
| **작업자 수기 입력 누락** | 작업자가 바코드 스캔을 잊거나 교대 시간 몰아서 입력 | 생산 라인 인터록(Interlock) 연동 및 비전 기반 무인 카운팅 도입 | 입력 누락 원천 차단 및 실시간성 보장 |
| **이기종 설비 연계 단절**| 제조사별(지멘스, 미쓰비시, LS) 통신 프로토콜 불일치 | 산업용 표준 프로토콜인 OPC-UA 엣지 게이트웨이 일괄 배치 | 이기종 설비 통합 데이터 수집 체계 완성 |
| **네트워크 단절 시 손실**| 공장 내 전자기 노이즈로 Wi-Fi 일시 단절 시 데이터 유실 | 엣지 게이트웨이에 로컬 SQLite 캐싱 및 Store-and-Forward 적용 | 통신 복구 후 데이터 무손실 자동 동기화 |
| **센서 오동작 및 노이즈**| 분진, 오일 미스트로 광학 센서 오염 및 오카운팅 발생 | 산업용 고신뢰 센서 채택 및 센서값 디바운싱(Debouncing) 필터 적용 | 계측 데이터의 정확성 및 신뢰도 확보 |

#### 한줄 요약
- 무인 인터록 연동, OPC-UA 표준화, 엣지 캐싱을 통해 인적 오류와 통신 단절을 극복함

## Ⅶ. 스마트팩토리 IIoT 엣지 노드로의 진화 중심 결론

- **[단순 실적 수집기에서 지능형 엣지 노드로]**: 과거 POP는 바코드 리더기와 전광판 중심의 수동적 집계기였으나, 스마트 제조 환경에서는 설비 진동·온도 데이터를 초당 수만 건 수집해 온디바이스 AI로 불량을 사전 예측하는 IIoT 엣지 노드로 진화함
- 나라면: 스마트공장 구축 시 `설비 제어반에 OPC-UA 지원 엣지 IPC 설치 → MQTT 기반 초경량 시계열 데이터 전송 체계 수립 → 실시간 OEE(설비종합효율) 자동 산출 알고리즘 연동`을 기술 사양서에 명시

#### 한줄 요약
- POP의 미래는 단순 바코드 스캔을 넘어 설비 이상을 사전에 감지하는 지능형 엣지에 있음

## 1교시 10점 답안 발췌

### 1. 생산시점관리(POP)의 정의
- 공장 생산 현장에서 제품 생산 시점에 발생하는 작업 실적, 설비 가동 상태, 품질 데이터를 센서, 바코드, PLC 등을 통해 실시간으로 자동 수집하여 상위 MES/ERP에 전달하는 현장 정보화 체계

### 2. 제조 정보시스템 3계층 아키텍처
```text
[ERP (경영/원가)] <── 계획/실적 ──> [MES (공정 제어)] <── 지시/실적 ──> [POP (현장 센싱)]
  (일·월 단위)                          (분·시간 단위)                        (초 단위 실시간)
                                                                             │
                                                                       [PLC / 센서 / 바코드]
```

| 시스템 | 핵심 역할 | 데이터 주기 |
|---|---|---|
| ERP | 전사 자원관리, 생산 계획 수립, 표준 원가 산정 | 일/월 단위 |
| MES | 작업 스케줄링, 공정 라우팅, 품질 추적, 재작업 지시 | 분/시간 단위 |
| POP | 현장 실적 카운팅, 설비 멈춤 감지, 바코드 로트 추적 | 초 단위 실시간 |

### 3. 차별화 제언
- 작업자 수기 입력 오류를 제거하기 위해 머신비전 및 PLC 인터록을 연계한 '무인 자동 카운팅'을 구현하고, 통신 단절에 대비한 엣지 게이트웨이의 Store-and-Forward 설계를 필수 적용해야 함
