## 30초 인출

- 본질: POP(Point of Production, 생산시점관리)는 생산 현장에서 작업·설비·자재·품질 정보를 발생 시점에 수집해 상위 생산 시스템에 전달하는 현장 정보 관리 체계
- 메커니즘: MES의 작업지시를 현장에 표시하고, 작업자 입력과 설비 신호를 작업지시·설비·로트·시각 식별자로 묶어 검증한 뒤 MES에 실적 반영
- 통찰: 식별 규칙 없이 연계만 늘리면 로트를 추적할 수 없으므로 연계 확대 전 실적 식별 규칙의 확정

<summary>핵심 용어</summary>

- **POP(Point of Production)** : 생산 현장에서 작업·설비·품질 실적을 발생 시점에 수집·전달하는 생산시점관리 체계
- **MES(Manufacturing Execution System)** : 작업지시·공정 진행·품질·추적 정보를 관리하는 제조 실행 시스템
- **ERP(Enterprise Resource Planning)** : 생산계획·자재·구매·원가 등 기업 자원을 통합 관리하는 시스템
- **PLC(Programmable Logic Controller)** : 설비 제어 로직을 실행하고 입출력 신호를 처리하는 산업용 제어기
- **HMI(Human-Machine Interface)** : 작업자가 설비·공정 상태를 보고 조작하는 화면 장치
- **OPC UA(OPC Unified Architecture)** : 산업 설비·시스템 간 데이터를 플랫폼 독립적으로 안전하게 교환하는 OPC Foundation 통신 규격
- **ISA-95** : 기업 시스템과 제조 운영·제어 시스템 사이의 기능 계층과 정보 교환을 정의한 통합 표준(IEC 62264)
- **로트(Lot)** : 같은 조건에서 함께 생산·투입된 제품·자재의 단위. 품질 문제 발생 시 추적 범위의 기준
- **Store-and-Forward** : 통신 단절 동안 현장 데이터를 임시 저장하고 복구 후 전달하는 방식

## 2~4교시 25점 답안

## Ⅰ. POP의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **POP(Point of Production)** 는 생산 현장에서 작업·설비·자재·품질 정보를 발생 시점에 수집해 상위 생산 시스템에 전달하는 생산시점관리 체계 |
| 목적 | 현장 실적의 즉시 파악을 통한 생산 지연·품질 이상의 신속한 대응 |

## Ⅱ. 사후 집계와 구별되는 POP의 특징

| 특징 | 의미 |
|---|---|
| 발생 시점 수집 | 작업 종료 후 일괄 입력이 아닌 작업·설비 사건 발생 즉시의 기록 |
| 다중 입력원 | 작업자 단말 입력과 **PLC** ·센서·검사기 신호의 병행 수집 |
| 작업지시 단위 식별 | 실적마다 작업지시·설비·**로트** ·시각을 붙인 추적 가능한 기록 |
| 현장 환경 제약 | 통신 단절·소음·장갑 착용 등 현장 조건을 고려한 입력·전송 설계 |

## Ⅲ. POP의 계층 구조와 실적 수집 흐름

### 제조 정보 계층 속 POP

```text
ERP ── 생산계획·자재·원가
    │
MES ── 작업지시·공정 진행·품질·추적
    │
POP ── 현장 지시 표시·실적 수집·검증
    │
    ├─ 작업자 단말·HMI ── 작업 확인·수동 실적
    └─ PLC·센서·검사기 ── 가동·생산량·검사 신호
```

기업 시스템과 제조 운영·제어의 계층 구분은 **ISA-95** 의 기능 모델이 기준이며, POP·MES 기능의 제품별 경계는 구축 사례에 따라 상이

### POP 수집 확대: 실적 수집·검증 흐름

```text
MES 작업지시 수신과 현장 단말 표시
    ↓
작업자 입력·설비 신호 수집
    ↓
작업지시 ID·설비·로트·시각 식별자 결합
    ↓
누락·중복·단위 검증
    ├─ 이상 → 현장 확인 요청 후 재입력
    └─ 정상 → MES 실적·품질·비가동 반영
```

## Ⅳ. POP·MES·ERP의 역할 비교

| 구분 | POP | MES | ERP |
|---|---|---|---|
| 중심 역할 | 현장 실적 수집·지시 표시 | 공정 실행 관리·추적 | 기업 자원·계획 관리 |
| 데이터 시간 단위 | 초·분 단위 사건 | 작업·공정 단위 | 일·주·월 단위 계획·집계 |
| 주요 정보 | 수량·가동 상태·검사값·작업 확인 | 작업 진행·공정 이력·로트 추적 | 생산계획·자재·재고·원가 |
| 정보 흐름 | 현장 실적을 MES로 전달 | 계획을 지시로 전환하고 실적 집계 | 생산계획을 MES에 제공 |

POP와 MES의 기능 경계는 표준으로 고정되지 않아, 경계가 불명확하면 같은 실적의 이중 입력과 시스템 간 값 불일치 발생

## Ⅴ. POP 구축의 한계와 방안

| 한계 | 방안 |
|---|---|
| 수기 입력 지연·오류로 실적과 실제의 차이 | 설비 신호의 자동 수집과 필수 항목 입력 검증 |
| 설비·공급사별 통신 방식 차이 | **OPC UA** 등 표준 인터페이스와 설비별 태그 매핑 정의 |
| 통신 단절 중 실적 유실·중복 | **Store-and-Forward** 와 재전송 식별키 적용 |
| POP·MES 기능 경계 불명확으로 실적 이중 입력 | 실적·기준정보별 소유 시스템 지정과 단일 입력 원칙 |
| 식별자 누락으로 불량 발생 시 로트 역추적 불가 | 작업지시·설비·로트·시각의 필수 식별 규칙 적용 |

## Ⅵ. 제언

설비 연계 확대보다 실적 식별 규칙과 실적 소유 시스템의 확정을 먼저 수행하고, 시범 라인의 로트 역추적 시험 통과 후 확대

### 식별 규칙 우선의 POP 확대 순서

```text
실적 식별 규칙 확정
    ↓
실적·기준정보별 소유 시스템 지정
    ↓
시범 라인 로트 역추적 시험
    ↓
시험 통과 라인부터 설비 연계 확대
```

### 식별 규칙 확대: 실적 레코드 식별자 구조

```text
POP 실적 레코드
    │
    ├─ 작업지시 ID ── MES 발행 값
    ├─ 설비 ID ── 설비 기준정보
    ├─ 로트 번호 ── 자재 투입·완제품 연결
    └─ 발생 시각 ── 설비·단말 시각 동기화
```

### 시범 라인 시험 확대: 로트 역추적 절차

```text
시범 라인의 완제품 로트 선정
    ↓
완제품 → 공정 → 설비 → 투입 자재 역추적
    ├─ 끊김 발생 → 누락 식별자 보완 후 재시험
    └─ 전 구간 추적 → 다음 라인으로 확대
```

### 선택 근거: 설비 연계 우선 방식과의 비교

| 구분 | 설비 연계 우선 | 제언: 식별 규칙 우선 |
|---|---|---|
| 착수 순서 | 설비 신호 연결 후 데이터 정리 | 식별 규칙·소유 시스템 확정 후 연결 |
| 실적 입력 경로 | POP·MES 이중 입력 가능 | 소유 시스템 한 곳에서만 입력 |
| 불량 발생 시 추적 | 식별자 누락 구간에서 단절 | 시범 라인에서 전 구간 추적 확인 |
| 확대 판단 기준 | 연결 설비 수 | 로트 역추적 시험 통과 여부 |
