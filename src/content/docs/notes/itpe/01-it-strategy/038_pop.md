## 연관 키워드

- POP (Point of Production, 생산시점관리)
- OEE, WIP, MES, ERP, PLC, RFID
- OPC-UA, MQTT, Edge Gateway (엣지 게이트웨이), PdM

## Ⅰ. POP의 개요

- 핵심 요약 : 생산 현장 데이터를 발생 시점에 수집해 상위 시스템으로 전달하는 생산시점관리 시스템.
- 개념 : 공장 현장에서 생산 실적, 설비 가동, 자재 이동, 불량 데이터를 발생 시점과 장소에서 즉시 수집·처리하는 **생산시점관리** (POP, Point of Production) 시스템.
- 배경 및 필요성 : 작업일보를 수작업으로 쓰면 데이터가 늦고 오류가 많아 공정 내 재공품(WIP, Work in Progress)의 양과 위치를 실시간으로 알기 어려우므로, 현장 데이터를 자동으로 잡는 계층이 필요함.
- 주요 목적 : 현장 데이터의 실시간 수집과 정확성 확보, 설비종합효율(OEE, Overall Equipment Effectiveness) 향상, 공정 병목 발견, 상위 시스템 연계를 통한 의사결정 지원.

## Ⅱ. POP의 특징 및 장점

- 핵심 요약 : 수집 시점을 현장으로 당기고 상위 시스템과 연계해 실적의 정확성과 가시성을 높이는 실행 하위 계층.

1. **생산 시점 수집** : 센서, 바코드, RFID (Radio-Frequency Identification)로 실적을 즉시 기록 → 수기 지연과 기록 오류 감소.
2. 실시간 가시성 : 가동, 불량, 재공 상태를 바로 파악 → 병목 공정에 신속 대응.
3. 이기종 설비 연계 : PLC (Programmable Logic Controller)와 OPC-UA (OPC Unified Architecture) 기반 데이터를 한 흐름으로 모음 → 현장 정보 단절 완화.
4. 엣지 검증 : 수집 단계에서 이상값을 걸러냄 → 상위 데이터의 품질 확보.
5. **제조실행시스템** (MES, Manufacturing Execution System) 및 전사적자원관리(ERP) 연계 : 실적을 공정, 재고, 원가 판단에 반영 → 의사결정 속도 향상.

## Ⅲ. POP의 구조 (흐름)

- 핵심 요약 : 현장 수집 계층에서 POP 서버와 MES를 거쳐 ERP로 이어지는 3계층 실시간 데이터 흐름.

```text
[생산 현장 설비와 작업자]

   ── 센서, 바코드, RFID
   ── PLC, 터치패널, 스마트 단말기
        ↓
[POP 데이터 수집 계층]

   ── 통신 인터페이스 (OPC-UA, MQTT)
   ── 데이터 검증, 엣지 필터링
        ↓
[MES 서버 계층]

   ── 공정 진행 관리, 설비 모니터링
   ── 작업 지시 배포
        ↓
[ERP 계층]

   ── 생산 실적 반영, 자재 재고 동기화
```

```text
[현장 실행과 실적 환류]

작업 지시 배포 (MES)
        ↓
현장 작업 수행 (POP 단말기)
        ↓
생산 실적 자동 수집
        ↓
실적 반영 (ERP 재고·원가)
        ↓
다음 작업 지시에 재반영
```

- **엣지 게이트웨이** (Edge Gateway) : 현장 가까이에서 데이터를 전처리한 뒤 상위 서버로 전송하는 장치.
- MQTT (Message Queuing Telemetry Transport) : 경량 메시지 전송 프로토콜로, 센서와 설비 데이터를 상위 계층으로 보내는 데 쓰임.

## Ⅳ. POP와 MES 및 ERP의 비교

- 핵심 요약 : POP는 현장 실시간 수집, MES는 공정 실행 관리, ERP는 전사 자원 관리로 계층별 역할이 구분됨.

| 비교 항목 | POP (생산시점관리) | MES (제조실행시스템) | ERP (전사적자원관리) |
| --- | --- | --- | --- |
| 주 관리 영역 | 생산 시점의 실적과 상태 데이터 수집 | 공정 계획, 품질, 설비, 작업 지시 전반 제어 | 전사 자원, 재무, 구매, 영업의 통합 계획 |
| 데이터 발생 주기 | 즉시 (초 단위 수집) | 실시간 실행 관리 (분·교대 단위) | 집계된 경영 데이터 (일·월 단위) |
| 핵심 기능 | 단말기, PLC 연계 실시간 데이터 캡처 | 공정 추적, WIP 관리, 스케줄링 | 자재소요계획(MRP, Material Requirements Planning), 원가 결산 |
| 계층 위치 | 현장 인터페이스 계층 | 생산 실행 계층 | 전사 비즈니스 계층 |

- 선택 기준 : 현장 실적을 즉시 잡아야 하는지, 공정 실행을 제어해야 하는지, 전사 자원을 통합해야 하는지에 따라 계층별 도입 범위를 정함.

## Ⅴ. POP의 한계와 방안

- 핵심 요약 : 수작업 입력 누락, 설비 프로토콜 차이, 집계 중심 활용을 자동 수집과 표준화, 분석 연계로 보완함.

| 한계 | 원인·영향 | 대응 방안 |
| --- | --- | --- |
| 수작업 입력의 누락·오류 | 작업자 입력 오류로 실적의 신뢰도가 떨어짐 | PLC, RFID, 센서 기반 자동 수집과 입력값 검증 |
| 설비별 통신 방식 차이 | 제조사마다 프로토콜이 달라 운영기술(OT, Operational Technology)과 정보 시스템 연계가 지연됨 | OPC-UA와 엣지 게이트웨이로 데이터 형식과 전송 표준화 |
| 사후 집계 중심 활용 | 실적을 쌓기만 하고 예방 조치에 쓰지 못함 | OEE 추적, 병목 탐지, 예지보전(PdM, Predictive Maintenance) 연계 |

## Ⅵ. POP 진화를 위한 기술사적 제언

- 핵심 요약 : 자동 수집의 고도화, 표준 프로토콜 통일, 예지보전 연계로 POP를 발전시키는 방향.

1. 사물인터넷(IoT, Internet of Things) 센서와 엣지 기반 자동 수집 : 작업자의 수동 바코드 스캔 의존에서 벗어나, PLC와 진동·온도 센서 데이터를 엣지 게이트웨이에서 전처리해 수집하는 체계로 옮겨가야 한다.
2. 이기종 설비 프로토콜 표준화 : 제조사별 통신 규격을 OPC-UA로 통일해 스마트팩토리 데이터 레이크로 끊김 없이 수집되는 기반을 마련하는 것이 바람직하다.
3. 인공지능(AI, Artificial Intelligence) 기반 예지보전 연계 : 실시간 가동 데이터를 시계열 머신러닝 모델과 결합해 고장을 미리 예측하고, 계획 정지로 전환하는 방향으로 발전시켜야 한다.

## Ⅶ. 결론

- 핵심 요약 : POP는 생산 시점 데이터의 실시간 수집으로 현장 가시성을 확보하고 MES·ERP 연계의 기반이 되는 계층.
- 시사점 : 입력 오류와 프로토콜 단절을 자동 수집과 예지보전으로 보완해야 스마트팩토리 실현의 기반으로 기능함.
