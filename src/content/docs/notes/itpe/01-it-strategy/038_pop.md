## 연관 키워드

- POP (Point of Production, 생산시점관리)
- OEE (Overall Equipment Effectiveness, 설비 종합효율)
- WIP (Work in Progress, 재공)
- MES (Manufacturing Execution System, 제조실행시스템)
- ERP (Enterprise Resource Planning, 전사적자원관리)
- PLC (Programmable Logic Controller)
- RFID (Radio-Frequency Identification)
- OPC-UA (Open Platform Communications Unified Architecture)
- MQTT (Message Queuing Telemetry Transport)
- Edge Gateway (엣지 게이트웨이)
- PdM (Predictive Maintenance, 예지보전)

## Ⅰ. POP의 개요

- 핵심 요약 : 생산 현장에서 발생하는 데이터를 발생 시점과 장소에서 즉시 수집·처리하는 생산시점관리 시스템.
- 개념 : 공장 내 생산 현장에서 발생하는 생산 실적, 설비 가동 상태, 자재 이동, 불량 발생 등의 데이터를 발생하는 시점과 장소에서 즉시 수집하여 실시간으로 처리·전달하는 생산시점관리 (POP, Point of Production) 시스템.
- 배경 및 필요성 : 제조 현장의 작업일보 수작업 작성으로 인한 데이터 지연 및 오류, 공정 내 재공 (WIP, Work in Progress) 파악 불가 문제를 해결하고 생산 현장의 실시간 가시성 확보 필요.
- 주요 목적 : 생산 현장 데이터의 실시간 수집 및 정확성 확보, 설비 종합효율 (OEE, Overall Equipment Effectiveness) 향상, 공정 병목 발견, 상위 MES (Manufacturing Execution System)/ERP (Enterprise Resource Planning) 연계를 통한 신속한 의사결정 지원.

## Ⅱ. POP의 특징

- 핵심 요약 : 현장 중심 실시간 데이터 수집과 상위 시스템 연계를 특징으로 하는 제조 실행 하위 계층.

1. 현장 중심 수집 : 생산 시점에서 센서, 바코드, RFID (Radio-Frequency Identification) 등으로 데이터를 즉시 캡처.
2. 실시간 처리·전달 : 수집 데이터를 지연 없이 처리하여 현장과 상위 시스템에 전달.
3. 이기종 설비 연계 : PLC (Programmable Logic Controller), 터치패널, 스마트 단말기 등 다양한 설비 인터페이스 지원.
4. 엣지 필터링 : 통신 인터페이스 단계에서 데이터 검증 및 1차 정제 수행.
5. 상위 시스템 연계 : MES (Manufacturing Execution System)/ERP (Enterprise Resource Planning)로 실시간 실적 반영 및 재고 동기화.
6. OEE 향상 지원 : 설비 가동 상태 수집으로 종합효율 분석과 병목 발견 지원.

## Ⅲ. POP의 구조 (흐름)

- 핵심 요약 : 현장 수집 계층→POP/MES 서버 계층→ERP 계층으로 이어지는 3단계 실시간 데이터 흐름.

```text
[생산 현장 설비/작업자]
   ── 센서, 바코드, RFID (Radio-Frequency Identification)
   ── PLC (Programmable Logic Controller), 터치패널, 스마트 단말기
   ── 생산 시점 실시간 데이터 자동/수동 입력
          ↓
[POP 데이터 수집 계층]
   ── 통신 인터페이스 (RS-232/485, OPC-UA, MQTT)
   ── POP 터미널, 데이터 검증, 엣지 필터링
          ↓
[POP/MES 서버 계층]
   ── 공정 진행 관리, 설비 모니터링, 작업 지시 배포
   ── 표준 프로토콜 연계
          ↓
[전사 경영 정보 (ERP)]
   ── 실시간 생산 실적 반영, 자재 재고 동기화, 원가 산정
```

```text
[POP-MES-ERP 계층 구조]
[ 현장 인터페이스 계층 ] ── POP (데이터 캡처)
          ↓
[ 생산 실행 계층 ] ── MES (공정·품질·WIP 관리)
          ↓
[ 전사 비즈니스 계층 ] ── ERP (자원·재무·구매 통합)
          ↓
[ 실시간 환류 ] ──→ 현장으로 작업 지시 재배포
```

- POP 데이터 수집 계층 : 통신 인터페이스 (RS-232/485, OPC (Open Platform Communications)-UA (Unified Architecture), MQTT (Message Queuing Telemetry Transport))와 POP 터미널.
- POP/MES 서버 계층 : 공정 진행 관리, 설비 모니터링, 작업 지시 배포.

## Ⅳ. POP와 MES 및 ERP의 비교

- 핵심 요약 : POP는 현장 실시간 수집, MES는 공정 실행 관리, ERP는 전사 자원 관리로 계층별 역할이 구분.

| 비교 항목 | POP (생산시점관리) | MES (제조실행시스템) | ERP (전사적자원관리) |
|---|---|---|---|
| 주 관리 영역 | 생산 시점의 실적 및 상태 데이터 수집 | 공정 계획, 품질, 설비, 작업 지시 전반 제어 | 전사 자원, 재무, 구매, 영업, 통합 계획 |
| 데이터 발생 주기 | 초/분 단위 (실시간 수집) | 분/시간/교대 단위 (실시간 실행 관리) | 일/월 단위 (집계된 경영 데이터) |
| 핵심 기능 | 단말기/PLC (Programmable Logic Controller) 연계 실시간 데이터 캡처 | 공정 추적 (Tracking), WIP (Work in Progress) 관리, 스케줄링 | 자재소요계획 (MRP, Material Requirements Planning), 표준 원가 결산 |
| IT (Information Technology) 계층 | 현장 인터페이스 계층 | 생산 실행 계층 | 전사 비즈니스 계층 |

## Ⅴ. POP의 장점과 한계

- 핵심 요약 : 실시간 가시성과 정확성 향상 장점, 입력 오류·프로토콜 단절·고도화 부족 한계 공존.

- 장점 :
  1. 실시간 가시성 : 현장 데이터를 즉시 수집하여 생산 상태와 WIP (Work in Progress)를 실시간 파악.
  2. 정확성 향상 : 수작업 작업일보 오류를 줄이고 실적 데이터의 정확성 확보.
  3. 신속 의사결정 : MES (Manufacturing Execution System)/ERP (Enterprise Resource Planning) 연계로 병목 발견과 신속 대응 지원.
  4. OEE (Overall Equipment Effectiveness) 향상 : 설비 가동 데이터 기반 종합효율 분석 가능.

- 한계 및 해결 방안 :
  1. 현장 작업자의 데이터 입력 오류 및 누락 :
     - 한계점 : 수작업 바코드 스캔이나 키오스크 입력 시 바쁜 공정 환경으로 인해 입력 누락 및 잘못된 실적 등록 빈발.
     - 해결 방안 : RFID (Radio-Frequency Identification), 비전 AI (Artificial Intelligence) 센서, PLC (Programmable Logic Controller) 설비 직접 연동을 통한 무인 자동 데이터 수집 (Auto-ID) 체계 구축.
  2. 제조 현장 (OT, Operational Technology)과 전사 IT 시스템 (MES/ERP) 간 단절 :
     - 한계점 : 현장 설비의 상이한 통신 프로토콜 (Modbus, Profibus 등)로 인해 전사 시스템으로의 실시간 데이터 집계 지연.
     - 해결 방안 : OPC-UA (Open Platform Communications Unified Architecture) 표준 산업용 프로토콜 적용, 엣지 게이트웨이 (Edge Gateway)를 통한 데이터 1차 정제 및 변환 연계.
  3. 설비 이상 예측 등 능동적 활용 한계 :
     - 한계점 : 단순히 사후 생산 실적 집계에만 머물러 불량 예방이나 설비 고장 사전 감지 등 고도화된 가치 창출 부족.
     - 해결 방안 : POP 데이터와 IoT (Internet of Things) 센서 데이터 융합, 예지보전 (PdM, Predictive Maintenance) AI (Artificial Intelligence) 알고리즘 연동을 통한 실시간 선제적 공정 제어.

## Ⅵ. POP 진화를 위한 기술사적 제언

- 핵심 요약 : IoT·엣지·OPC-UA·AI 기반 자동 수집과 예지보전 연계로 POP 고도화 필요.

1. IoT 센서 및 엣지 컴퓨팅 기반 자동 수집 고도화 : 작업자의 수동 바코드 스캔 의존을 탈피하고, PLC (Programmable Logic Controller) 및 진동·온도 센서 데이터를 엣지 게이트웨이에서 실시간 전처리 수집.
2. OPC-UA 기반의 이기종 설비 프로토콜 표준화 : 다양한 제조사 설비의 통신 규격을 통일하여 스마트팩토리 데이터 레이크로의 무중단 수집 기반 마련.
3. AI 기반 이상 감지 및 예지보전 (PdM, Predictive Maintenance) 연계 : 수집된 실시간 설비 가동 데이터를 시계열 머신러닝 모델과 결합하여 설비 고장 사전 예측 및 다운타임 제로화.

## Ⅶ. 결론

- 핵심 요약 : POP는 제조 현장 실시간 데이터 수집의 출발점이자 MES/ERP 연계의 기반 계층이다.

- POP는 생산 시점 데이터의 실시간 수집·처리를 통해 현장 가시성을 확보하고, MES (Manufacturing Execution System)/ERP (Enterprise Resource Planning) 연계로 신속한 의사결정을 지원. 입력 오류와 프로토콜 단절, 고도화 부족 한계를 IoT (Internet of Things), OPC-UA (Open Platform Communications Unified Architecture), AI (Artificial Intelligence) 기반 자동 수집과 예지보전 (PdM, Predictive Maintenance) 연계로 보완할 때 스마트팩토리 실현의 핵심 기반으로 기능.
