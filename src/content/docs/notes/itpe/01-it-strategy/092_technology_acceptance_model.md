## 연관 키워드

- TAM, 지각된 유용성, 지각된 사용용이성, 사용의도, 실제 사용, UTAUT 비교

## Ⅰ. 기술수용모델의 개요

- 핵심 요약 : 기술수용모델(TAM, Technology Acceptance Model)은 지각된 유용성과 사용 용이성이 사용태도·의도에 미치는 관계를 설명하는 모형.
- 개념 : **TAM** (Technology Acceptance Model, 기술수용모델)은 지각된 유용성과 지각된 사용용이성이 사용태도와 사용의도에 미치는 관계를 설명하는 모형.
- 배경 및 필요성 : 새 기술의 도입 여부는 기능 성능뿐 아니라 사용자의 유용성·사용편의 인식에 영향을 받음.
- 주요 목적 : 사용자가 기술을 수용하고 실제 활용하는 요인을 설명해 설계·도입 개선.

## Ⅱ. 기술수용모델의 특징 및 장점

- 핵심 요약 : 사용자 관점의 도입저항 분석; 설문 기반 검증; 설계개선 요인 도출.

1. 지각된 유용성 측정 : 업무성과 기대가 수용의도에 미치는 영향 파악 → 도입 가치와 업무 적합성 개선.
2. 지각된 사용용이성 측정 : 학습·조작 부담의 개선점 식별 → 인터페이스와 교육 설계 개선.
3. 사용태도·의도 분석 : 인식이 의도로 이어지는 경로 확인 → 수용 저항 요인 파악.
4. 사용의도와 실제사용 구분 : 도입효과를 실제 행동으로 확인 → 설문과 이용 데이터의 차이 파악.
5. 설문 기반 검증 : 가설을 측정도구로 검증 → 설계·도입 개선의 근거 확보.

## Ⅲ. 기술수용모델의 구조 (흐름)

- 핵심 요약 : 외부요인 → 유용성·용이성 인식 → 사용태도·의도 → 실제 사용의 관찰.

```text
[ TAM 관계 흐름 ]

외부요인
    ↓
지각된 유용성 / 지각된 사용용이성
    ↓
사용태도
    ↓
사용의도
    ↓
실제 사용
```

```text
[ 핵심 변수 관계 ]

지각된 유용성 → 사용태도·의도
지각된 사용용이성 → 사용태도·의도
사용의도 → 실제 사용
```

## Ⅳ. TAM과 UTAUT의 비교

- 핵심 요약 : TAM은 핵심 인식변수 중심, UTAUT는 사회적 영향·촉진조건 등을 추가 통합.

| 개념·방법 | 주요 특성 | 적합한 선택기준 |
| --- | --- | --- |
| TAM | 유용성·사용용이성 중심의 기술수용 설명 | 기술 인식의 핵심 경로를 간결하게 검증 |
| UTAUT | 사회적 영향·촉진조건 등 통합 요인 포함 | 조직·사회 맥락이 큰 수용상황 분석 |

## Ⅴ. 기술수용모델의 한계와 방안

- 핵심 요약 : 자기보고와 실제사용 차이는 로그·관찰로, 조직맥락 누락은 업무·사회 요인 조사로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 사용의도와 실제 사용 괴리 | 설문 점수가 도입 성공을 과대평가 → 실제 효과 미확인 | 로그·관찰·업무성과와 설문 삼각검증 | 의도-실사용 격차 |
| 조직맥락 누락 | 강제사용·지원환경 영향 설명 부족 → 적용성 저하 | 사회적 영향·촉진조건·업무맥락 추가측정 | 집단별 사용률, 지원요청 |
| 자기보고 편향 | 응답자의 태도·사회적 바람직성이 결과 왜곡 | 익명화·행동데이터 보완·측정도구 검증 | 응답 일관성, 행동데이터 일치 |
| 단순모형 한계 | 복잡한 기술·조직 환경을 충분히 설명 못함 | 확장변수와 맥락 요인 추가 | 설명력, 예측 정확도 |

## Ⅵ. 기술수용모델 적용에 대한 기술사적 제언

- 핵심 요약 : 도입 전 사용성 실험과 도입 후 이용데이터를 결합해 개선.
- 측정 설계 : 연구자는 문항을 서비스 맥락에 맞게 검증하고 사용의도뿐 아니라 실제 이용로그·집단별 접근성과 이용성과를 함께 측정.
- 도입 개선 : 유용성·용이성 인식 결과를 설계 개선에 반영하고 교육·지원 절차를 보완.
- 조직 맥락 보완 : 사회적 영향·촉진조건·업무맥락을 추가 측정해 모형의 적용성을 높임.

## Ⅶ. 결론

- 핵심 요약 : 기술수용모델(TAM, Technology Acceptance Model)은 지각된 유용성과 사용 용이성이 사용태도·의도에 미치는 관계를 설명하는 모형.
- 시사점 : 유용성·용이성 인식과 실제 행동을 함께 검증해야 수용모형을 적용할 수 있음.
