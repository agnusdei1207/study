## 연관 키워드

- TAM, Technology Acceptance Model, 기술수용모델, 프레드 데이비스(Fred Davis)
- PU, Perceived Usefulness, 인지된 유용성, PEOU, Perceived Ease of Use, 인지된 용이성
- BI, Behavioral Intention, 사용 의도, TAM2, TAM3, UTAUT
- UI/UX, 사용자 수용성, 변화 관리

## Ⅰ. 기술수용모델(TAM)의 개요

- 핵심 요약 : 사용자의 IT 수용 행동을 인지된 유용성(PU)과 인지된 용이성(PEOU)으로 설명하는 모델.
- 개념 : **기술수용모델** (TAM, Technology Acceptance Model)은 프레드 데이비스(Fred Davis)가 1989년 제안한 이론으로, 사용자가 정보기술(IT, Information Technology)을 받아들여 실제로 쓰기까지의 심리적 과정을 **인지된 유용성**(PU, Perceived Usefulness)과 **인지된 용이성**(PEOU, Perceived Ease of Use) 두 변수로 설명한다.
- 배경 및 필요성 : 막대한 예산을 들인 정보시스템이 사용자의 저항으로 쓰이지 못하면 구축비가 그대로 손실된다. 이 손실을 줄이려면 사용자가 시스템을 받아들이게 만드는 요인을 먼저 규명하고, 설계와 교육 단계에서 그 요인을 관리해야 한다.
- 주요 목적 : 신기술 도입 시 사용자 수용성 예측, 사용자 인터페이스(UI, User Interface)와 사용자 경험(UX, User Experience) 설계 방향 제시, 저항을 줄이는 변화 관리 전략 수립.

## Ⅱ. 기술수용모델(TAM)의 특징 및 장점

- 핵심 요약 : 두 핵심 변수와 태도·의도·실제 사용의 인과 구조로 수용 행동을 단계별로 진단할 수 있는 모델.

1. 인지된 유용성 (PU) : 업무 성과에 도움이 된다고 느끼는 정도를 측정 → 기능 가치의 개선 지점 파악.
2. 인지된 용이성 (PEOU) : 사용에 드는 노력에 대한 인식을 확인 → UI·교육 개선 우선순위 설정.
3. 사용 태도 (Attitude Toward Using) : 기술에 대한 긍정·부정 평가를 파악 → 초기 저항 요인 식별.
4. **사용 의도** (BI, Behavioral Intention) : 향후 사용 의향을 측정 → 도입 전 수용 가능성 예측.
5. 실제 사용 행동 : 접속 로그와 사용 빈도를 확인 → 설문 결과와 실제 채택 수준 비교.

## Ⅲ. 기술수용모델(TAM)의 구조 (흐름)

- 핵심 요약 : 외부 변수에서 용이성, 유용성, 태도, 의도를 거쳐 실제 사용으로 이어지는 인과 흐름.
- 인과 구조 : 외부 변수는 PEOU와 PU에 영향을 주고, PEOU는 PU와 태도에 직접 영향을 준다.

```text
[ 외부 변수 (환경) ]
시스템 디자인, 사용자 교육, 조직 지원
          ↓
[ 인지된 용이성 (PEOU) ]
          ↓
[ 인지된 유용성 (PU) ]
          ↓
[ 사용 태도 (Attitude) ]
          ↓
[ 사용 의도 (BI) ]
          ↓
[ 실제 사용 행동 ]
```

- 확장 모델 : TAM2, TAM3와 **UTAUT** (Unified Theory of Acceptance and Use of Technology, 통합기술수용이론)는 원형에 변수를 더하거나 여러 모델을 통합한 후속 모델이다.

```text
[ TAM 원형 ]
PU, PEOU, 태도, 의도, 실제 사용
          ↓
[ TAM2 ]
주관적 규범, 이미지, 직무 관련성
          ↓
[ TAM3 ]
컴퓨터 자기효능감, 컴퓨터 불안, 객관적 사용성
          ↓
[ UTAUT ]
성과 기대, 노력 기대, 사회적 영향, 촉진 조건
```

## Ⅳ. 기술수용모델(TAM)과 확장 모델의 비교

- 핵심 요약 : TAM 원형에서 확장 모델로 갈수록 사회적 영향과 선행 요인이 추가되는 차이.

| 모델 | 기본 변수 또는 추가 변수 |
| --- | --- |
| TAM (원형) | 인지된 유용성, 인지된 용이성, 태도, 사용 의도, 실제 사용 |
| TAM2 | 주관적 규범, 이미지, 직무 관련성, 결과 품질 등 사회적 영향 과정 추가 |
| TAM3 | 컴퓨터 자기효능감, 컴퓨터 불안, 객관적 사용성 등 용이성의 선행 요인 |
| UTAUT | 성과 기대, 노력 기대, 사회적 영향, 촉진 조건을 동인으로 통합하고 성별·연령 조절효과 추가 |

- 선택 기준 : 개인이 자율적으로 선택하는 도입이면 TAM 계열의 유용성·용이성을, 조직이 의무로 사용하게 하는 도입이면 UTAUT의 촉진 조건과 사회적 영향을 중시한다.

## Ⅴ. 기술수용모델(TAM)의 한계와 방안

- 핵심 요약 : 의도와 행동의 차이, 강제 사용 환경, 시간에 따른 변화를 실제 데이터와 반복 측정으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 자기보고 편향 | 설문상 사용 의도가 실제 사용으로 이어지지 않을 수 있음 | 접속·기능 사용 로그를 수집해 의도와 실제 행동을 함께 검증 | 로그 기반 실제 사용률 |
| 강제 사용 환경 | 필수 업무 시스템은 개인의 선호만으로 사용 여부를 설명하기 어려움 | 촉진 조건과 사회적 영향을 함께 살펴 교육·지원 체계 설계 | 교육 이수율, 지원 문의 건수 |
| 단일 시점 측정 | 숙련도와 인식이 바뀌는 과정을 놓침 | 도입 전후 종단 조사를 반복하고 사용자 피드백 반영 | 시점별 수용 점수 추이 |

## Ⅵ. 기술수용모델(TAM)에 대한 기술사적 제언

- 핵심 요약 : 초기에는 용이성을 높이고, 이후 유용성을 입증하며, 영향력 있는 현업 리더를 통해 사용 규범을 형성.
- 도입 초기에는 인지된 용이성 개선에 집중하는 것이 현실적이다. 직관적인 화면과 온보딩 안내, 한 번의 인증으로 여러 시스템에 접속하는 싱글 사인온(SSO, Single Sign-On) 같은 장치로 진입 장벽을 낮춰야 한다.
- 지속 사용은 결국 업무 효율을 체감하는 데 달려 있으므로 인지된 유용성을 입증해야 한다. 처리 시간 단축과 보고서 자동화처럼 현업이 실제로 느끼는 성과를 측정해 보여 주는 것이 정착의 조건이다.
- 조직 내 사용 규범은 TAM2와 UTAUT가 강조하는 사회적 영향에서 형성된다. 현업에서 영향력이 큰 리더와 얼리어답터를 디지털 챔피언으로 지정해 긍정적 사용 경험이 부서 안에서 퍼지도록 유도하는 것이 효과적이다.

## Ⅶ. 결론

- 핵심 요약 : TAM은 사용자 수용성을 인지된 유용성과 용이성으로 설명하는 기술 수용 행동 모델.
- 시사점 : 설문 의도를 실제 사용 데이터로 검증하고 사회적 영향과 촉진 조건을 함께 보는 확장 관점이 모델의 설명력을 높인다.
