## Ⅰ. 기술수용모델(TAM)의 개요

- **개념** : 프레드 데이비스(Fred Davis)가 제안한 이론으로, 사용자가 정보기술(IT)을 수용하고 실제로 사용하는 행동에 이르는 심리적 의사결정 과정을 '인지된 유용성'과 '인지된 용이성'이라는 두 가지 핵심 변수로 설명하는 기술 수용 행동 모델(Technology Acceptance Model).
- **배경 및 필요성** : 막대한 예산을 투입해 구축한 정보시스템이 사용자의 저항으로 채택되지 못하고 사장되는 문제를 해결하기 위해 사용자의 시스템 수용 요인을 과학적으로 규명 필요.
- **주요 목적** : 신기술 도입 시 사용자 수용성 예측, 시스템 UI/UX 설계 방향 제시, 저항 극복을 위한 변화 관리 전략 수립.

## Ⅱ. TAM의 인과 메커니즘 구조

```text
┌─────────────────┐       ┌─────────────────┐
│ 인지된 유용성    │ ----> │ 사용 태도        │ ──┐
│ (Perceived      │       │ (Attitude       │   │
│  Usefulness, PU)│ ──┐   │  Toward Using)  │   │
└─────────────────┘   │   └─────────────────┘   │
        ▲             │            ▲            ▼
        │             │            │    ┌─────────────────┐       ┌─────────────────┐
┌─────────────────┐   │            │    │ 사용 의도        │ ----> │ 실제 사용 행동   │
│ 인지된 용이성    │ ──┴────────────┘    │ (Behavioral     │       │ (Actual System  │
│ (Perceived      │                     │  Intention, BI) │       │  Use)           │
│  Ease of Use,   │                     └─────────────────┘       └─────────────────┘
│  PEOU)          │
└─────────────────┘
        ▲
        │
┌─────────────────┐
│ 외부 변수 (환경) │ (시스템 디자인 특성, 사용자 교육, 조직적 지원, 기술 지원)
└─────────────────┘
```

- **인지된 유용성 (PU)** : "이 시스템을 사용하면 나의 업무 성과가 향상될 것이다"라고 믿는 정도.
- **인지된 용이성 (PEOU)** : "이 시스템을 사용하는 데 많은 노력이 들지 않고 쉬울 것이다"라고 믿는 정도 (PEOU는 PU에도 직접적 긍정 영향).

## Ⅲ. TAM의 발전: TAM2, TAM3, UTAUT로의 확장

| 모델 구분 | 확장 내용 및 주요 추가 변수 |
|---|---|
| TAM (원형) | 기본 변수: 인지된 유용성(PU), 인지된 용이성(PEOU), 태도, 의도, 실제 사용 |
| TAM2 | 주관적 규범(사회적 영향), 이미지, 직무 관련성, 결과 결과 품질 등 사회적 영향 프로세스 추가 |
| TAM3 | 컴퓨터 자기효능감, 컴퓨터 불안감, 객관적 사용성 등 용이성을 결정하는 선행 요인 심화 모델링 |
| UTAUT (통합기술수용이론) | 성과 기대, 노력 기대, 사회적 영향, 촉진 조건을 4대 핵심 동인으로 통합하고 성별/연령 조절효과 추가 |

## Ⅳ. 성공적인 신규 IT 시스템 확산을 위한 기술사적 제언

- **초기 채택 단계에서는 인지된 용이성(PEOU) 집중 개선** : 시스템 런칭 초기에는 복잡성을 줄이고 직관적인 UI/UX, 온보딩 튜토리얼, 싱글사인온(SSO)을 제공하여 진입 장벽 완화.
- **장기적 지속 사용을 위해서는 인지된 유용성(PU) 입증** : 시스템의 장기적인 리텐션과 업무 정착은 결국 실질적인 업무 효율성 향상(시간 단축, 보고서 자동화 등)에 달려 있으므로 핵심 비즈니스 가치 제공.
- **사회적 영향 및 챔피언(Champion) 육성** : TAM2/UTAUT 이론에 따라 현업 부서 내 영향력이 큰 리더 및 얼리어답터를 '디지털 챔피언'으로 임명하여 조직 내 긍정적 입소문과 규범 형성 유도.
