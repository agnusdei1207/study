## 지식 로드맵 내 현재 위치

IT 전략·관리 → 정보시스템 도입·사용자 수용 → **기술수용모델(TAM)**

## 30초 인출

- 본질: 기술수용모델(TAM)은 사용자가 새 정보기술을 받아들이는 이유를 지각된 유용성과 사용 용이성이라는 두 인식으로 설명하는 모델
- 메커니즘: 외부 변수가 사용 용이성(PEOU)과 유용성(PU) 인식을 만들고, PEOU가 PU에 영향을 주며, 두 인식이 사용 의도(BI)를 거쳐 실제 사용으로 연결
- 통찰: 사용 의도가 실제 사용으로 이어지지 않을 수 있으므로 설문과 사용 기록의 병행 측정과 낮은 변수 개선

<details>
<summary>핵심 용어</summary>

- **기술수용모델(TAM, Technology Acceptance Model)** : 지각된 유용성과 사용 용이성으로 정보기술의 사용 의도와 사용을 설명하는 Davis(1989)의 모델
- **PU(Perceived Usefulness)** : 기술 사용이 자신의 업무 성과를 높여 줄 것이라고 사용자가 믿는 정도
- **PEOU(Perceived Ease of Use)** : 기술을 사용하는 데 노력이 많이 들지 않을 것이라고 사용자가 믿는 정도
- **BI(Behavioral Intention)** : 기술을 사용하려는 사용자의 의향. 실제 사용의 직접 선행 변수
- **외부 변수(External Variables)** : 시스템 특성·교육·조직 지원처럼 PU·PEOU 인식을 형성하는 요인
- **TAM2** : 사회적 영향 과정(주관적 규범·자발성·이미지)과 인지적 도구 과정(직무 관련성·산출물 품질·결과 입증성·PEOU)으로 PU와 사용 의도를 설명하는 Venkatesh·Davis(2000)의 확장 모델
- **UTAUT(Unified Theory of Acceptance and Use of Technology)** : 성과 기대·노력 기대·사회적 영향·촉진 조건 네 요인과 성별·나이·경험·자발성 네 조절변수로 기술 수용과 사용을 설명하는 Venkatesh 등(2003)의 통합 이론

</details>

## 2~4교시 25점 답안

## Ⅰ. 기술수용모델의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **기술수용모델(TAM, Technology Acceptance Model)** 은 지각된 유용성과 사용 용이성으로 정보기술의 사용 의도와 사용을 설명하는 모델 |
| 목적 | 사용자가 기술을 받아들이거나 거부하는 원인 파악을 통한 도입·개선 방향 설정 |

## Ⅱ. 사용자 인식으로 수용을 설명하는 TAM의 특징

| 특징 | 의미 |
|---|---|
| 두 핵심 신념 | 유용성(PU)과 사용 용이성(PEOU)이라는 간결한 설명 변수 |
| 인식 중심 | 시스템의 객관적 기능이 아닌 사용자가 지각한 가치·부담으로 설명 |
| 매개 구조 | 외부 변수가 PU·PEOU를 거쳐 의도와 사용에 영향 |
| 의도와 행동의 구분 | 사용 의도(BI)와 실제 사용을 별개 변수로 측정 |

## Ⅲ. TAM의 변수 구조와 외부 변수의 확장

### TAM의 변수 영향 구조

```text
외부 변수: 시스템 특성·교육·조직 지원
    ↓
PEOU(지각된 사용 용이성)
    ↓ 쉬울수록 유용성 인식 상승
PU(지각된 유용성)
    ↓ PU·PEOU가 함께 형성
사용 태도
    ↓
BI(사용 의도)
    ↓
실제 사용
```

PEOU는 태도에도 직접 영향을 주고 PU는 사용 의도에도 직접 영향을 주는 구조. Davis·Bagozzi·Warshaw(1989)의 원형은 태도 변수를 포함하며, 이후 연구에서는 태도를 빼고 PU·PEOU가 사용 의도로 바로 이어지는 간소화 구조도 사용

### PU 형성 요인 확대: TAM2의 외부 변수

```text
PU(지각된 유용성) 형성 요인
    │
    ├─ 사회적 영향 과정 ── 주관적 규범·이미지
    │
    └─ 인지적 도구 과정
          ├─ 직무 관련성·산출물 품질
          └─ 결과 입증성·PEOU
```

TAM2의 조절 관계: 주관적 규범은 의무 사용 환경에서만 사용 의도에 직접 영향을 주고, 사용 경험이 쌓일수록 그 영향이 약화

## Ⅳ. TAM·TAM2·UTAUT의 비교

| 구분 | TAM | TAM2 | UTAUT |
|---|---|---|---|
| 핵심 변수 | PU·PEOU | PU·PEOU와 PU 형성 요인 | 성과 기대·노력 기대·사회적 영향·촉진 조건 |
| 추가 관점 | 개인 인식 | 사회적 영향 과정·인지적 도구 과정 | 조직 지원 환경과 성별·나이·경험·자발성 조절 |
| 적합한 상황 | 자발적 사용 기술의 수용 원인 파악 | 조직 내 도입에서 유용성 인식 원인 분석 | 의무 사용·인프라 제약이 큰 조직 도입 |
| 강점 | 변수가 적어 측정 간결 | PU 저하 원인까지 진단 | 설명 범위가 넓음 |

TAM의 PU·PEOU는 UTAUT의 성과 기대·노력 기대에 대응하며, UTAUT는 사용을 직접 좌우하는 촉진 조건을 별도 변수로 구분

## Ⅴ. TAM 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 높은 사용 의도에도 실제 사용 저조 | 설문 측정과 함께 접속·핵심 기능 사용 기록의 병행 측정 |
| 의무 사용 환경에서 의도의 설명력 약화 | 자발성이 낮은 조직 도입이면 촉진 조건·사회적 영향을 포함한 UTAUT 선택 |
| PU가 낮은 원인 미파악 | 원인 진단이 필요하면 직무 관련성·산출물 품질·결과 입증성을 묻는 TAM2 문항 추가 |
| 도입 초기 한 번의 측정으로 판단 | 도입 직후와 정착 이후의 반복 측정으로 인식 변화 확인 |

## Ⅵ. 제언

정보시스템 도입 평가 때 PU·PEOU 설문과 실제 사용 기록을 함께 측정하고, 가장 낮은 변수부터 개선 조치 선택

### 수용 측정 구조

```text
도입 시스템의 수용 측정
    │
    ├─ 인식 ── PU·PEOU 설문
    │
    ├─ 의도 ── BI 설문
    │
    └─ 행동 ── 접속·핵심 기능 사용 기록
```

### 측정 결과 확대: 낮은 변수별 개선 분기

```text
인식·의도·행동 측정값 비교
    ├─ PEOU 낮음 → 화면·절차 단순화, 교육
    ├─ PU 낮음 → 직무 관련 기능·산출물 품질 보완
    └─ BI 높고 사용 낮음 → 권한·인프라 점검
          ↓
    재측정으로 개선 효과 확인
```

### 선택 근거: 만족도 설문 중심 평가와의 비교

| 구분 | 만족도 설문 중심 평가 | 제언: 인식·행동 병행 측정 |
|---|---|---|
| 측정 대상 | 전반적 만족도 | PU·PEOU·BI와 실제 사용 기록 |
| 저조 원인 식별 | 불가 | 낮은 변수로 원인 구분 |
| 개선 조치 | 일괄 교육·홍보 | 변수별 조치 선택 |
| 효과 확인 | 다음 만족도 조사 | 같은 변수의 재측정 |
