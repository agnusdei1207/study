## 연관 키워드

- TAM, Technology Acceptance Model, 기술수용모델
- Fred Davis, 프레드 데이비스
- PU, Perceived Usefulness, 인지된 유용성
- PEOU, Perceived Ease of Use, 인지된 용이성
- BI, Behavioral Intention, 사용 의도
- TAM2, TAM3, UTAUT, Unified Theory of Acceptance and Use of Technology
- UI/UX, 사용자 수용성, 변화 관리

## Ⅰ. 기술수용모델(TAM)의 개요

- 핵심 요약 : 사용자의 IT 수용 행동을 인지된 유용성(PU)과 용이성(PEOU)으로 설명하는 모델.
- 개념 : **프레드 데이비스**(Fred Davis)가 제안한 이론으로, 사용자가 정보기술(IT, Information Technology)을 수용하고 실제로 사용하는 행동에 이르는 심리적 의사결정 과정을 '인지된 유용성'과 '인지된 용이성'이라는 두 가지 핵심 변수로 설명하는 **기술 수용 행동 모델**.
- 배경 및 필요성 : 막대한 예산을 투입해 구축한 정보시스템이 사용자의 저항으로 채택되지 못하고 사장되는 문제를 해결하기 위해 사용자의 시스템 수용 요인을 과학적으로 규명 필요.
- 주요 목적 : 신기술 도입 시 사용자 수용성 예측, 시스템 UI(User Interface)/UX(User Experience) 설계 방향 제시, 저항 극복을 위한 변화 관리 전략 수립.

## Ⅱ. 기술수용모델(TAM)의 특징

- 핵심 요약 : PU·PEOU 두 핵심 변수와 태도·의도·실제 사용의 인과 구조를 특징으로 함.

1. 인지된 유용성(PU) : 시스템 사용이 업무 성과 향상에 도움된다고 믿는 정도.
2. 인지된 용이성(PEOU) : 시스템 사용에 노력이 적게 든다고 믿는 정도 (PU에도 직접 영향).
3. 사용 태도(Attitude) : 시스템 사용에 대한 긍정/부정 평가.
4. 사용 의도(BI, Behavioral Intention) : 실제 사용 의지.
5. 실제 사용 행동(Actual System Use) : 시스템 실제 채택.
6. 외부 변수 반영 : 시스템 디자인, 교육, 조직 지원.

## Ⅲ. 기술수용모델(TAM)의 구조 (흐름)

- 핵심 요약 : 외부 변수 → PEOU → PU → 태도 → 사용 의도 → 실제 사용의 인과 흐름.
- **TAM의 인과 메커니즘 구조**.

```text
[ 외부 변수 (환경) ]
   시스템 디자인 특성, 사용자 교육,
   조직적 지원, 기술 지원
        ▼
[ 인지된 용이성 (PEOU, Perceived Ease of Use) ]
   (PEOU는 인지된 유용성·사용 태도에 직접 영향,
    외부 변수도 인지된 유용성에 직접 영향)
        ▼
[ 인지된 유용성 (PU, Perceived Usefulness) ]
        ▼
[ 사용 태도 (Attitude Toward Using) ]
        ▼
[ 사용 의도 (Behavioral Intention, BI) ]
        ▼
[ 실제 사용 행동 (Actual System Use) ]
```

- **TAM 확장 모델 흐름**.

```text
[ TAM (원형) ]
   PU, PEOU, 태도, 의도, 실제 사용
        ↓
[ TAM2 ]
   주관적 규범, 이미지, 직무 관련성, 결과 품질
        ↓
[ TAM3 ]
   컴퓨터 자기효능감, 불안감, 객관적 사용성
        ↓
[ UTAUT ]
   성과 기대, 노력 기대, 사회적 영향, 촉진 조건
   + 성별/연령 조절효과
```

## Ⅳ. 기술수용모델(TAM)과 확장 모델의 비교

- 핵심 요약 : TAM 원형과 TAM2·TAM3·UTAUT의 추가 변수 및 적용 범위 차이.

| 모델 구분 | 확장 내용 및 주요 추가 변수 |
|---|---|
| **TAM** (원형) | 기본 변수: 인지된 유용성(PU), 인지된 용이성(PEOU), 태도, 의도, 실제 사용 |
| **TAM2** | 주관적 규범(사회적 영향), 이미지, 직무 관련성, 결과 품질 등 사회적 영향 프로세스 추가 |
| **TAM3** | 컴퓨터 자기효능감, 컴퓨터 불안감, 객관적 사용성 등 용이성을 결정하는 선행 요인 심화 모델링 |
| **UTAUT** (Unified Theory of Acceptance and Use of Technology, 통합기술수용이론) | 성과 기대, 노력 기대, 사회적 영향, 촉진 조건을 4대 핵심 동인으로 통합하고 성별/연령 조절효과 추가 |

## Ⅴ. 기술수용모델(TAM)의 장점과 한계

- 핵심 요약 : 사용자 수용성 예측의 장점, 자기보고·강제 사용·단일 시점의 한계.
- 장점
  1. 신기술 도입 시 사용자 수용성 예측.
  2. 시스템 UI/UX 설계 방향 제시.
  3. 저항 극복을 위한 변화 관리 전략 수립.
- 한계점 1 : 자기보고식(Self-Report) 설문 의존으로 인한 의도-행동 간 괴리
  - 한계점 : 설문조사 상의 '사용 의도(Behavioral Intention)'가 실제 비즈니스 환경에서의 '실제 사용(Actual Use)'으로 직결되지 않음.
  - 해결 방안 : 시스템 접속 로그, 체류 시간, 기능 사용률 등 실제 행동 데이터(Product Analytics)를 모델 검증에 결합.
- 한계점 2 : 조직 내 강제적 사용 환경(Mandatory Setting) 미반영
  - 한계점 : ERP(Enterprise Resource Planning)나 그룹웨어처럼 업무상 필수 사용해야 하는 환경에서는 개인의 인지된 유용성/용이성의 설명력 약화.
  - 해결 방안 : UTAUT(통합기술수용이론)의 촉진 조건(Facilitating Conditions)과 사회적 영향(Social Influence) 변수 통합.
- 한계점 3 : 단일 시점 측정으로 인한 동적 변화 추적 한계
  - 한계점 : 시스템 도입 초기의 인지된 용이성이 숙련도 향상에 따라 변화하는 과정을 종단적(Longitudinal)으로 파악 불가.
  - 해결 방안 : 온보딩 1개월, 3개월, 6개월 차 시계열 추적 조사 수행 및 사용자 피드백 루프 구축.

## Ⅵ. 기술수용모델(TAM)에 대한 기술사적 제언

- 핵심 요약 : 초기 용이성 개선, 장기 유용성 입증, 사회적 영향·챔피언 육성.
- 초기 채택 단계에서는 인지된 용이성(PEOU) 집중 개선 : 시스템 런칭 초기에는 복잡성을 줄이고 직관적인 UI/UX, 온보딩 튜토리얼, 싱글사인온(SSO, Single Sign-On)을 제공하여 진입 장벽 완화.
- 장기적 지속 사용을 위해서는 인지된 유용성(PU) 입증 : 시스템의 장기적인 리텐션과 업무 정착은 결국 실질적인 업무 효율성 향상(시간 단축, 보고서 자동화 등)에 달려 있으므로 핵심 비즈니스 가치 제공.
- 사회적 영향 및 챔피언(Champion) 육성 : TAM2/UTAUT 이론에 따라 현업 부서 내 영향력이 큰 리더 및 얼리어답터를 '디지털 챔피언'으로 임명하여 조직 내 긍정적 입소문과 규범 형성 유도.

## Ⅶ. 결론

- 핵심 요약 : TAM은 사용자 수용성을 PU·PEOU로 설명하는 기술 수용 행동 모델.
- 요약 : 사용자가 정보기술을 수용하고 사용하는 행동을 인지된 유용성과 용이성으로 설명하는 모델.
- 시사점 : 실제 사용 데이터 검증, UTAUT 확장, 종단적 추적으로 모델 정확도를 높여야 함.
