## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 데이터 기반 마케팅·성장전략 → **그로스 해킹**


## 30초 인출

- 본질: **그로스 해킹** : 제품 사용 데이터를 바탕으로 성장 병목을 찾고 실험으로 개선하는 접근법.
- 메커니즘: **North Star Metric** 설정 → **AARRR** ·코호트 분석 → 가설·ICE 우선순위 설정 → A/B 테스트·Guardrail 검증 → 학습결과의 제품 반영.
- 통찰: 한계: 유입 수치만 높여 활성·유지 단계의 이탈을 놓침 → 방안: 성장 가설 하나를 지표·Guardrail과 함께 시험

<details>
<summary>핵심 용어</summary>

- **그로스 해킹(Growth Hacking)** : 제품·마케팅·데이터를 결합해 성장 가설을 빠르게 검증하는 접근법

- **AARRR** : Acquisition·Activation·Retention·Revenue·Referral로 사용자 여정을 관찰하는 퍼널 프레임워크
- **PMF(Product-Market Fit)** : 제품이 목표 시장의 문제를 해결하여 반복 사용과 성장이 일어나는 제품-시장 적합 상태
- **NSM(North Star Metric)** : 고객이 체감하는 핵심 가치와 기업의 장기 성장을 대표하는 단일 북극성 지표
- **Guardrail Metric** : 목표 지표 개선 과정에서 품질·신뢰·수익성 저하 등 부작용을 감시하는 보호 지표
- **Cohort Analysis** : 공통 특성을 가진 사용자 집단의 시간 경과에 따른 행동·잔존율 변화를 비교하는 분석 기법
- **CAC(Customer Acquisition Cost)** : 신규 고객 1인을 확보하기 위해 투입되는 평균 마케팅·영업 비용
- **LTV(Customer Lifetime Value)** : 고객 1인이 전체 관계 기간 동안 기업에 기여할 것으로 예상되는 누적 생애 가치

## 2~4교시 25점 답안

## Ⅰ. 그로스 해킹의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **그로스 해킹** : 제품·마케팅·데이터를 결합해 성장 가설을 반복 실험·학습하는 접근법 |
| 목적 | 고객가치가 확인되는 지속 가능한 성장방식 발굴 |

## Ⅱ. 그로스 해킹의 특징

| 특징 | 판단 기준 |
|---|---|
| 제품·마케팅·데이터 결합 | 사용자 행동과 제품 변경의 연결 |
| 반복 실험 | 가설·분석 기준을 사전에 정하고 결과 학습 |
| 장기 가치 확인 | 유입 수치와 활성·유지·가드레일을 함께 평가 |

## Ⅲ. AARRR와 성장 실험 체계

```text
유입(Acquisition) → 첫 가치 경험(Activation)
                           ↓
재사용(Retention) → 수익(Revenue)
        └────────→ 추천(Referral) → 새 유입
각 단계의 이탈·전환 지표 → 병목 가설·실험
```

> 단계 적용 원칙: 서비스별 순서 조정과 단계마다 의미 있는 행동의 선행 정의.

| 단계 | 핵심 행동 | 지표 예 |
|---|---|---|
| **Acquisition** | 채널별 사용자 유입 | 채널별 유입 · **CAC** |
| **Activation** | 최초 핵심가치 경험 | 핵심행동 도달 · 온보딩 완료 |
| **Retention** | 가치 경험에 따른 재사용 | Cohort Retention · 재사용 |
| **Revenue** | 지속 가능한 수익 발생 | 전환 · ARPU · **LTV** |
| **Referral** | 사용자 추천·확산 | 추천전환 · 초대수락 |

```text
목표·NSM 정의 → AARRR·코호트에서 병목 확인
                           ↓
개선 가설·우선순위 → 통제 실험·가드레일 평가
                           ↓
채택 변경의 배포 → 유지·수익 영향 재측정
```

## Ⅳ. 분석기법과 성장 실험의 관계

> 개선 검증의 구분: 관찰분석에 의한 병목 발견과 통제실험에 의한 변경의 인과효과 확인.

| 기법 | 분석 대상 | 산출 |
|---|---|---|
| **Funnel Analysis** | 단계별 이탈 지점 | 단계별 전환·이탈 |
| **Cohort Analysis** | 집단별 유지행동 차이 | Cohort Retention |
| **Segmentation** | 사용자·채널별 행동 차이 | 세그먼트별 행동 |
| **A/B Test** | 변경의 인과 효과 | 효과크기 · 신뢰구간 · Guardrail |

## Ⅴ. 한계와 방안

> 단기 전환율만 최적화하면 고객신뢰와 장기 유지가 악화될 수 있음.

| 한계 | 방안 |
|---|---|
| **Vanity Metric** 에 치우친 성장 판단 | **NSM** 을 고객가치·장기성과와 연결 |
| **국소 최적화** 로 유지·수익 단계 악화 | AARRR 전 단계·코호트 영향 확인 |
| 반복 확인·중단에 따른 **통계 오류** | 가설·표본·기간·중단 기준 사전 정의 |
| **Dark Pattern** 에 따른 신뢰 저하 | 가드레일·윤리·개인정보 검토 |

## Ⅵ. 제언

활성·유지의 이탈이 큰 단계부터 가설을 시험하고 채택 변경의 배포 후 NSM·가드레일을 다시 측정.

제안의 범위: 실험결과의 운영 반영. A/B 테스트 결과만으로 제품·시장 적합성이 입증되는 것은 아님.
