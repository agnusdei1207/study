## 지식 로드맵 내 현재 위치

IT 전략·관리 → 정보화 조달·계약 → **협상계약 제안서 평가**

## 30초 인출

- 본질: 협상계약 제안서 평가는 협상에 의한 계약에서 여러 공급자의 제안서를 기술능력과 입찰가격으로 종합 평가해 협상적격자를 가리는 절차
- 메커니즘: 제안서 평가위원회의 정성평가와 정량평가로 기술능력을 평가하고 입찰가격 평가와 합산해 협상 순위를 정한 뒤, 협상으로 계약을 체결하며 대형 소프트웨어 사업에는 전문평가를 별도 위원회로 추가
- 통찰: 전문평가는 수요기관이 요청해야 적용되고 전문영역 평가항목도 수요기관이 작성·조정하므로, 조달요청 전에 요구사항에서 전문영역을 식별해 평가항목으로 옮기고 사전규격 공개기간 안에 등록

- **협상계약 제안서 평가** : **협상에 의한 계약** 에서 제안서의 기술능력과 입찰가격을 종합 평가해 협상적격자를 가리는 절차
- **협상에 의한 계약** : 물품·용역계약에서 계약이행의 전문성·기술성 등이 필요할 때 다수 공급자의 제안서를 평가해 협상적격자를 고른 뒤 협상으로 국가에 가장 유리한 자와 체결하는 계약 방식
- **제안요청서(RFP, Request for Proposal)** : 협상에 의한 계약에서 입찰 참가자에게 제안서 제출을 요청하려고 지급하는 서류로 과업내용·요구사항·계약조건·평가요소와 평가방법을 명시
- **제안서 평가위원회** : 개별 건의 제안서 기술능력평가를 위해 정해진 인원수로 선정된 평가위원들의 집합체
- **기술능력평가·입찰가격** : 제안서 평가의 두 축으로, 기술능력은 정성평가와 정량평가로 구분해 평가
- **정성평가·정량평가** : 정성평가는 평가위원의 종합 판단으로 사업별 평가항목을 평가, 정량평가는 경영상태·수행실적 같은 지표를 세부기준으로 평가하며 총 배점 20점 이하
- **차등점수제** : 제안서 평가 점수로 입찰자의 순위를 정하고 순위에 따라 고정점수를 부여하는 방식으로, 기술능력평가의 변별력이 낮을 때 적용
- **대형평가** : 사업금액 20억 원 이상 소프트웨어 사업(유지관리 사업은 100억 원 이상) 등의 기술능력평가로, 평가위원이 교섭조건을 충족한 위원 중에서 선정되는 평가
- **전문평가** : 사업금액 40억 원 이상 소프트웨어 사업(유지관리 사업은 100억 원 이상)에서 수요기관이 요청할 때 별도 평가위원회가 전문영역을 심층 평가하는 방식
- **수요기관** : 「조달사업에 관한 법률」 제2조제5호에서 정한 기관으로 조달청에 조달을 요청하는 쪽

## 2~4교시 25점 답안

## Ⅰ. 협상계약 제안서 평가의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **협상계약 제안서 평가** 는 **협상에 의한 계약** 에서 제안서의 기술능력과 입찰가격을 종합 평가해 협상적격자를 가리는 절차 |
| 목적 | 계약이행의 전문성·기술성이 필요한 사업에서 국가에 가장 유리한 공급자의 선정 |

## Ⅱ. 기술능력과 가격의 종합 평가를 위원회가 심의하는 특징

| 특징 | 내용 |
|---|---|
| 적용 대상 | 계약이행의 전문성·기술성·긴급성 등이 필요하다고 인정되는 물품·용역계약 |
| 종합 평가 | **기술능력평가** 와 입찰가격의 종합 평가, 배점한도의 20점 범위 가감 |
| 위원회 심의 | **제안서 평가위원회** 의 심의, 정량 지표는 계약담당공무원이 세부기준으로 평가 |
| 변별력 확보 | 기술능력평가의 변별력이 낮으면 **차등점수제** 적용 |
| 제안서·가격 분리 | 제안서와 가격 입찰서의 별도 제출, 가격 입찰서는 개봉 시까지 봉함 보관 |

## Ⅲ. 협상계약 절차와 제안서 평가의 구성

### 협상에 의한 계약 절차

```text
입찰공고
    ↓
제안요청서 교부 · 열람
    ↓
제안서와 가격 입찰서의 별도 제출
    ↓
제안서 평가: 평가위원회 심의
    ↓
입찰가격 개봉 · 평가
    ↓
협상적격자 · 협상순위 선정
    ↓
협상 → 협상결과 통보 → 계약체결
```

### 평가 확대: 조달청 세부기준의 제안서 평가 구성

```text
제안서 평가
    │
    ├─ 기술능력평가
    │     ├─ 정성평가 ── 사업별 항목: 정보화컨설팅 · 소프트웨어 및 시스템 개발 · 시스템운용환경구축
    │     │              운영 및 유지관리 · 데이터처리 · 공간정보데이터베이스구축 · 디지털콘텐츠개발
    │     │              + 전문평가(별도 위원회)
    │     └─ 정량평가 ── 총 배점 20점 이하: 경영상태 · 수행실적 · 사회적 책임 · 상생협력 등
    │
    └─ 입찰가격평가
```

## Ⅳ. 2024.9 개정 주요 내용과 평가 유형의 비교

### 2024.9.13 시행 개정 주요 내용

| 개정 항목 | 내용 |
|---|---|
| 대형 SW사업 **전문평가** | 40억 원 이상 SW사업(유지관리 사업은 100억 원 이상), 정보기술개발·정보보호·데이터 구축·디지털기술의 4개 전문영역 심층평가, 공통평가 60%와 전문평가 40% 구성 |
| 수의계약 제안서 적합성 평가 대행 | 수요기관 요청 시 조달청의 정성평가 대행 |
| 허위·비방 처리 | 허위 내용 판단 절차의 명확화, 타 업체 비방 시 기술능력평가 0.1점 감점 |
| 온라인 평가 발표 기준 | 제안서 발표 기준 금액을 고시금액(2.2억 원)에서 5억 원 이상으로 상향 |
| 기술용역 협상계약 | 엔지니어링·건설엔지니어링 사업의 협상계약 세부 평가기준 신설 |

### 일반평가·대형평가·전문평가의 비교

| 비교축 | 일반평가 | 대형평가 | 전문평가 |
|---|---|---|---|
| 적용 사업 | 대형 소프트웨어 사업 등을 제외한 사업 | 사업금액 20억 원 이상 SW사업(유지관리 100억 원 이상) 등 | 사업금액 40억 원 이상 SW사업(유지관리 100억 원 이상) 중 수요기관 요청 |
| 평가위원 | 교섭조건 비적용 | 교섭조건 충족 위원 | 별도 평가위원회, 해당 소분류 위원 |
| 평가항목 | 사업별 항목 | 사업별 항목과 필수 제안 | 전문영역 항목, 총 배점은 정성평가의 50% 이하 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 전문평가는 수요기관이 요청해야 적용되고 전문영역 항목도 수요기관이 조정·작성해 요구사항과 평가항목의 불일치 가능 | 조달요청 전 요구사항에서 전문영역을 식별하고 전문평가 항목표를 활용해 작성 |
| 입찰자와 평가위원의 사전접촉이 평가 공정성을 훼손 | 확인(신고)서 접수와 사실 조사, 사실 확인 시 종합점수 5점 감점 |
| 제안서의 허위 내용·타 업체 비방이 입찰 분쟁과 계약 지연 유발 | 허위 내용 판단의 내부 심의와 비방 시 기술능력평가 0.1점 감점 |

## Ⅵ. 제언

사전규격 공개 단계에서 요구사항의 전문영역을 식별하고 전문평가 항목으로 옮겨, 조달요청과 평가항목 등록에 함께 반영

### 요구사항에서 전문평가 항목까지의 연결

```text
사업 요구사항 (제안요청서 초안)
    ↓
사업금액 확인
    ├─ 40억 원 미만(유지관리 100억 원 미만) → 공통평가 항목
    └─ 40억 원 이상(유지관리 100억 원 이상) → 전문영역 식별
                  ↓
          정보기술개발 · 정보보호 · 데이터 구축 · 디지털기술 중 요구사항과 연결되는 영역
                  ↓
          조달요청에 전문평가 표시 + 사전규격 공개기간 종료일까지 평가항목 등록
```

### 전문영역 확대: 요구사항과 평가항목의 대응

```text
요구사항                          전문영역 평가항목
개인정보·접근통제 요구 ──────────  정보보호: 개인정보보호 준수방안 · 보안규정 준수 점검방안
데이터 이관·품질 요구  ──────────  데이터 구축: 데이터 이관·통합 전략 · 데이터 품질 방안
```

| 구분 | 공통평가만 적용 | 제언: 요구사항 기반 전문평가 |
|---|---|---|
| 평가위원 | 공통 평가위원회 | 전문영역 소분류 위원의 별도 위원회 |
| 평가항목 | 사업별 공통 항목 | 요구사항과 대응하는 전문영역 항목 |
| 적용 조건 | 전 사업 | 사업금액 40억 원 이상(유지관리 100억 원 이상) |
