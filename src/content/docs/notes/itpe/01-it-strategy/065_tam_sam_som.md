## 연관 키워드

- TAM·SAM·SOM, 전체시장, 유효시장, 목표시장, 상향식 추정, 시장가정

## Ⅰ. TAM·SAM·SOM의 개요

- 핵심 요약 : TAM·SAM·SOM은 전체 잠재시장, 사업모델상 접근시장, 현실적으로 확보 가능한 목표시장을 구분하는 시장규모 틀.
- 개념 : **TAM** (Total Addressable Market, 전체 잠재시장), **SAM** (Serviceable Available Market, 접근 가능 시장), **SOM** (Serviceable Obtainable Market, 확보 가능 시장)은 전체 잠재시장, 사업모델상 접근시장, 현실적으로 확보 가능한 목표시장을 구분하는 시장규모 틀.
- 배경 및 필요성 : 시장 규모를 전체 잠재수요로만 제시하면 실제 제공가능성과 확보 가능한 매출을 과대평가하기 쉬움.
- 주요 목적 : 전체 잠재시장과 실제 제공·확보 가능한 시장을 구분해 사업기회와 목표 설정.

## Ⅱ. TAM·SAM·SOM의 특징 및 장점

- 핵심 요약 : 시장범위 단계화; 사업 가정 명시; 진입목표 현실성 검토.

1. TAM 전체 잠재수요 정의 : 모든 고객·지역·가격을 포함한 시장 상한선을 산정 → 시장의 장기 잠재력 확인.
2. SAM 제공 가능 범위 적용 : 제품·지역·채널 제약을 반영 → 실제 제공 가능한 시장 산출.
3. SOM 확보 목표 설정 : 경쟁·역량·시간 가정을 적용 → 실행 가능한 단기 목표 설정.
4. 가정 명시 : 고객수·가격·점유율 가정을 명시 → 시장규모의 근거와 검증 가능성 확보.
5. 시나리오 민감도 : 가정 변화에 따른 시장규모 변동을 검토 → 투자·사업계획의 리스크 파악.

## Ⅲ. TAM·SAM·SOM의 구조 (흐름)

- 핵심 요약 : 고객·가격·지역 정의 → 전체시장 추정 → 접근제약 적용 → 경쟁·역량 기반 확보목표 산출.

```text
[ 시장규모 산출 흐름 ]

고객·가격·지역 정의
    ↓
TAM 전체시장 추정
    ↓
SAM 접근제약 적용
    ↓
SOM 확보목표 산출
```

```text
[ 시장 범위 단계 ]

TAM : 전체 잠재수요
    ↓
SAM : 제공 가능한 수요
    ↓
SOM : 확보 가능 점유 수요
```

## Ⅳ. TAM·SAM·SOM의 비교

- 핵심 요약 : TAM은 전체 수요, SAM은 제공 가능한 수요, SOM은 확보 가능 점유 수요.

| 개념·방법 | 주요 특성 | 적합한 선택기준 |
| --- | --- | --- |
| TAM | 전체 잠재시장 | 시장 상한과 장기 잠재력 |
| SAM | 사업모델·지역·채널로 접근가능한 시장 | 현재 제공가능 범위 |
| SOM | 역량·경쟁을 반영한 목표 확보시장 | 실행 가능한 단기 목표 |

## Ⅴ. TAM·SAM·SOM의 한계와 방안

- 핵심 요약 : 근거없는 비율은 고객자료·가격으로 검증; 중복은 세그먼트 정의와 제거로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 시장규모 과대추정 | 상향식 수요·경쟁제약 미반영 → 투자 판단 왜곡 | 세그먼트별 고객수·가격으로 SAM·SOM 산정 | 가정 근거율, 실적 대비 오차 |
| 시장범위 중복 | TAM·SAM·SOM 이중계산 → 규모 부풀림 | 지역·고객·제품 범위와 기준연도 명시 | 중복 세그먼트, 출처 최신성 |
| 가정 불명확 | 점유율·성장률 근거 부족 → 신뢰도 저하 | 가정·출처·민감도 분석 제시 | 가정 문서화율 |
| 상향식 검증 부족 | 하향식 추정만으로 실현 가능성 과대 | 고객 인터뷰·파일럿·매출 데이터로 검증 | 검증 자료 수, 오차율 |

## Ⅵ. TAM·SAM·SOM 적용에 대한 기술사적 제언

- 핵심 요약 : 투자·사업계획에는 산출범위·기간·가정과 상향식 검증자료를 함께 제시.
- 산출 근거 : 사업책임자는 세그먼트별 고객수·지불의사·채널·경쟁자료로 TAM·SAM·SOM을 계산.
- 민감도 검증 : 가정 변화와 상향식 검증을 병행해 시장규모의 신뢰성을 확인.
- 의사결정 연계 : 시장규모를 투자·자원배분·목표 설정에 연결하고 정기적으로 갱신.

## Ⅶ. 결론

- 핵심 요약 : TAM·SAM·SOM은 전체 잠재시장, 사업모델상 접근시장, 현실적으로 확보 가능한 목표시장을 구분하는 시장규모 틀.
- 시사점 : TAM·SAM·SOM의 신뢰성은 시장범위와 고객·가격 가정의 검증에 달림.
