## 연관 키워드

- TAM·SAM·SOM, 전체시장, 접근 가능 시장, 획득 가능 시장
- 상향식 추정, 시장 세그먼트, 가정 검증

## Ⅰ. TAM·SAM·SOM의 개요

- 핵심 요약 : 시장을 전체·접근·획득의 3단계로 구분해 사업 판단 근거를 만드는 시장 규모 분석 틀.
- 개념 : **TAM** (Total Addressable Market, 전체시장)·**SAM** (Serviceable Available Market, 접근 가능 시장)·**SOM** (Serviceable Obtainable Market, 획득 가능 시장)은 사업이 도달할 수 있는 수요의 상한부터 현실적 목표까지 단계별로 규모를 구분하는 시장 규모 분석 프레임워크.
- 배경 및 필요성 : 전체 시장 규모 하나로 사업성을 판단하면 제약·경쟁 미반영의 과대평가 위험 → 단계별 구분 필요.
- 주요 목적 : 시장 상한과 실행 목표의 구분으로 투자 심의·사업 계획의 신뢰성 확보.

## Ⅱ. TAM·SAM·SOM의 특징 및 장점

- 핵심 요약 : 단계별 범위 축소와 가정 명시가 현실적 목표 설정과 검증 가능성 확보.

1. TAM 상한 정의 : 제품·서비스가 이론상 도달 가능한 전체시장 규모 산출 → 사업의 장기 잠재력 확인.
2. SAM 제약 반영 : 자사 제품·지역·채널·규제 제약을 반영한 접근 가능 시장 산출 → 실제 공급 가능 수요 확인.
3. SOM 목표 설정 : 경쟁 상황·자사 역량·기간을 반영한 획득 가능 시장 산출 → 현실적 단기 목표·자원 계획 수립.
4. 가정 명시 : 고객 수·단가·점유율 가정의 출처 제시와 **가정 검증** (고객 인터뷰·실적 데이터로 추정값을 확인하는 절차) → 추정 신뢰성 확보.
5. 산정 방식 : 고객 수·단가·이용 빈도를 곱해 규모를 합산하는 **상향식 추정** (Bottom-up) 적용 → 통계·보고서 비율에 의존하는 하향식(Top-down)보다 근거 명확.

## Ⅲ. TAM·SAM·SOM의 구조 (흐름)

- 핵심 요약 : 시장 세그먼트 정의에서 시작해 제약·역량을 순차 반영하며 규모를 구체화하는 구조.
- 구성요소 : **시장 세그먼트** (고객·지역·제품 기준으로 나눈 시장 단위) 정의가 모든 단계 산출의 출발점.

```text
[ 시장 규모 단계 ]

TAM 전체시장 (이론적 상한)
    ↓ 제품·지역·채널 제약 반영
SAM 접근 가능 시장
    ↓ 경쟁·역량·기간 반영
SOM 획득 가능 시장
```

```text
[ 상향식 추정 흐름 ]

시장 세그먼트 정의
    ↓
대상 고객 수 × 단가 × 빈도
    ↓
SOM 산출
    ↓
제약 완화 시나리오로 SAM·TAM 확장
```

- 활용 영역 : 투자 유치 심의, 사업 계획 수립, 목표 매출 설정, 자원 배분에 적용.

## Ⅳ. TAM·SAM·SOM과 단일 규모 추정 방식의 비교

- 핵심 요약 : 전체 시장 하나의 값만 제시하는 방식 대비 단계 구분의 과대평가 방지.

| 비교 축 | TAM·SAM·SOM 단계 구분 | 단일 규모 추정 방식 |
| --- | --- | --- |
| 추정 범위 | 전체·접근·획득의 3단계 | 전체 시장 하나의 값 |
| 근거 투명성 | 단계별 가정·출처 명시 | 출처·가정 불명확하기 쉬움 |
| 목표 설정 | SOM 기반 실행 목표 | 실행 목표 부재 |
| 리스크 판단 | 제약 요인의 단계별 식별 | 과대평가 위험 집중 |
| 갱신 | 가정별 정기 갱신 | 1회성 작성 |

## Ⅴ. TAM·SAM·SOM의 한계와 방안

- 핵심 요약 : 과대추정·범위 중복·하향식 의존·정태성의 위험을 근거 데이터·정의·검증으로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 과대추정 | 낙관적 점유율·성장률 가정 → 투자 판단 왜곡 | 근거 데이터 기반 가정·민감도 분석 | 실적 대비 추정 오차 |
| 범위 중복·불명확 | 시장 세그먼트 정의 모호 → 이중 계산·부풀림 | 지역·고객·기준연도의 범위 명시 | 범위 정의 문서화율 |
| 하향식 의존 | 통계·보고서 비율 적용만 반복 → 실현성 검증 부족 | 고객 인터뷰·파일럿 판매 기반 상향식 재계산 | 검증 자료 건수 |
| 정태 추정 | 시장 변화 미반영 → 계획 노후화 | 정기 갱신·시나리오 운영 | 갱신 주기 준수율 |

## Ⅵ. TAM·SAM·SOM 적용에 대한 기술사적 제언

- 핵심 요약 : 사업 책임자·투자 심의 조직의 추정 표준과 심의 체계로 시장 규모 자료의 신뢰성 제고.
- 추정 표준 : 사업 책임자는 범위·기준연도·가정·출처를 문서화하는 추정 표준 양식 적용.
- 심의 체계 : 투자 심의 조직은 가정 검증 자료 제출을 심의 요건으로 의무화.
- 갱신 거버넌스 : 시장 규모 자료를 정기 갱신 대상으로 지정해 계획-실적 괴리 관리에 반영.

## Ⅶ. 결론

- 핵심 요약 : TAM·SAM·SOM은 시장 규모를 상한·접근·획득 목표로 구분하는 사업 판단의 기본 틀.
- 단계 구분과 가정의 검증 가능성이 과대평가 방지의 핵심.
