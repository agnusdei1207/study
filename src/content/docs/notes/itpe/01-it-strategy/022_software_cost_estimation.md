## 연관 키워드

- SW사업 대가산정 가이드, 기능점수(FP), 투입공수(M/M), 제경비
- 기술등급·직무별 인건비, 노무비 구성, 요율제 유지관리비

## Ⅰ. SW사업 대가산정의 개요

- 핵심 요약 : 소프트웨어진흥법의 적정 대가 기준에 따라 공공 용역 비용을 규모·공수·단가로 산출하는 공공 조달 절차.
- 개념 : **SW사업 대가산정 가이드**는 공공기관이 SW(SW: Software) 기획·개발·운영·유지관리 용역의 적정 대가를 산정할 때 사용하는 공식 산정 기준과 산식의 집합.
- 배경 및 필요성 : SW산업진흥법상 SW사업대가의 기준(고시)이 폐지되어 민간으로 이양(2013년)됨에 따라 대체 기준 필요 → 한국인공지능·소프트웨어산업협회가 매년 개정 판본 공표.
- 주요 목적 : 발주기관·수행사가 동일 기준으로 예산 수립·발주·계약을 수행하고, 소프트웨어진흥법 제46조에 따른 SW기술자 적정 인건비 지급의 보장.

## Ⅱ. SW사업 대가산정의 특징 및 장점

- 핵심 요약 : 기능 규모·투입공수·공표 인건비 체계가 산정의 재현성과 적정 대가 보장을 뒷받침.

1. 기능점수 방식 : 개발 규모를 사용자 관점의 논리적 기능으로 정량화하는 **기능점수** (FP, Function Point)에 공표 단가를 곱해 개발비 산출 → 요구 기능 기준의 재현 가능한 산정.
2. 투입공수 방식 : **투입공수** (M/M, Man-Month)에 직무별 인건비 단가를 곱하고 제경비·이윤을 합산 → 컨설팅·운영처럼 기능점수 적용이 곤란한 용역의 산정.
3. 인건비 단가 체계 : SW기술자 임금실태조사(매년 실시·공표)를 기반으로 직무별 평균임금을 공표 → 기본급·제수당·상여금·퇴직급여충당금·4대보험 법인부담금을 포함한 **노무비** 전체를 단가에 반영.
4. 기술등급 체계의 전환 : 과거 **기술등급**제(기술사·특급·고급·중급·초급기술자)는 2012년 폐지 → 현재는 직무별 평균임금 체계가 기준이며, 현업 발주 관행에서는 등급별 단가가 병용.
5. 운영단계 방식의 다양화 : 요율제 유지관리비, 투입공수 운영비, 고정비·변동비 방식, 서비스수준협약(SLA, Service Level Agreement) 기반 정산 → 용역 성격에 맞는 방식 선택.

## Ⅲ. SW사업 대가산정의 구조 (흐름)

- 핵심 요약 : 규모 측정부터 단가 적용, 원가 구성, 경비 합산으로 이어지는 산정 흐름과 단계별 방식 선택.

```text
개발 규모 측정 (기능점수)
   ↓
× 기능점수 단가
   ↓
개발원가 = 인건비 + 제경비 + 이윤
   ↓
직접경비 합산 → SW개발비 확정
```

- 제경비 : 간접 인건비·사무 비용 등 인건비 외 공통경비를 반영하는 비율로, 투입공수 방식 산정의 구성 요소(2024년 개정판 기준 144~154%).

```text
사업 단계별 산정방식 선택

기획단계 : 컨설팅지수·투입공수
   ↓
구현단계 : 기능점수·투입공수
   ↓
운영단계 : 요율제·투입공수·SLA
   ↓
가이드 산식 검증·승인
```

## Ⅳ. 공공 대가산정 방식과 민간 개발 계약 방식의 비교

- 핵심 요약 : 공공 대가산정은 공표 근거의 투명성·재현성이 강점이고, 민간 계약 방식은 협상 유연성이 강점.

| 비교 축 | 공공 대가산정(가이드 기준) | 민간 개발 계약 방식 |
| --- | --- | --- |
| 산정 근거 | 공표 단가·표준 산식 | 당사자 협상·시장가 |
| 인건비 기준 | 임금실태조사 기반 공표 임금 | 사업자 원가 자율 결정 |
| 절차 | 예산 수립 → 산정 → 계약 → 검수·정산 | 제안·협상 → 계약, 근거 비공개 가능 |
| 강점 | 투명성·재현성·적정 대가 보장 | 유연성·속도·기술 가치 반영 |
| 한계 | 시장 변화 대응 지연 가능성 | 투명성 부족·가격 왜곡 위험 |

## Ⅴ. SW사업 대가산정의 한계와 방안

- 핵심 요약 : 단가 괴리, 직무 판정 편차, 범위 불명확, 신규 영역 산정 미비를 근거 관리로 일대일 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 단가·시장 괴리 | 갱신 주기·물가 변동 → 수익성·품질 저하 | 최신 판본 적용·적용 기준일 명시 | 적용 단가 기준일 |
| 직무·등급 판정 편차 | 등급별 단가 관행 병용·직무 혼용 → 공수 단가 왜곡 | 직무·역할 정의와 투입내역 검증 | 직무별 공수 비율 |
| 과업 범위 불명확 | 요구 누락 → 변경·추가 비용 분쟁 | 요구사항·제외범위 합의와 추적 | 변경 금액 비율 |
| 신규 영역 산정 미비 | AI 도입 대가체계의 초기 단계 → 산정 편차 | 유형별(기본형·데이터형·모델형) 커스터마이징 기준 적용 | 산정 근거 보완 이행률 |

## Ⅵ. SW사업 대가산정에 대한 제언

- 핵심 요약 : 발주 근거 명시, 재현 가능한 내역 제출, 대가체계의 주기 개정으로 산정 신뢰를 높이는 상위 수준의 제안.

1. 발주기관 : 가이드 최신 판본 적용, 기획·개발·운영 범위의 분리 산정, 산정 근거의 계약서 명시.
2. 수행사 : 직무별 투입공수·인건비 내역의 재현 가능한 제출과 변경 시 재산정 절차의 계약 반영.
3. 한국인공지능·소프트웨어산업협회·관계부처 : AI 도입·데브옵스(DevOps, 개발·운영 통합) 등 신규 대가체계의 주기 개정과 발주·수행 공동 검증 문화의 확산.

## Ⅶ. 결론

- 핵심 요약 : 공공 SW 대가산정은 규모·공수·단가의 공표된 근거로 적정 대가를 확보하는 조달 통제 장치.
- 대가의 적정성은 산정방식 선택보다 근거 명시·단가 현행화·검증의 일관성에 좌우.
