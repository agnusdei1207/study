IT 전략·관리 → 프로젝트 범위관리 → **WBS**

## 30초 인출

- 본질: WBS(Work Breakdown Structure)는 프로젝트 전체 범위를 인도물 중심으로 나눈 계층 구조
- 메커니즘: 인도물을 Work Package까지 분해하고, 하위 합이 상위 범위와 같은지 100% 규칙으로 검증한 뒤 WBS Dictionary와 함께 Scope Baseline으로 승인
- 통찰: 수락기준 없이 분해한 Work Package는 완료 판정이 모호하므로 분해 시점의 WBS Dictionary 수락기준 확정

<details>
<summary>핵심 용어</summary>

- **WBS(Work Breakdown Structure)** : 프로젝트 전체 범위를 인도물 중심으로 나눈 계층 구조
- **Work Package(작업 패키지)** : 일정·원가 추정과 담당자 배정, 완료 판정이 가능한 WBS 최하위 요소
- **100% 규칙(100% Rule)** : 하위 요소의 합이 상위 요소 범위와 정확히 같아야 한다는 WBS 완전성 원칙
- **WBS Dictionary(WBS 사전)** : WBS 요소별 작업 설명·담당 조직·수락기준을 기록한 문서
- **Scope Baseline(범위 기준선)** : 승인된 범위 기술서·WBS·WBS Dictionary로 구성된 범위 통제 기준
- **Control Account(통제 계정)** : 범위·일정·원가를 통합해 성과를 측정하는 WBS상의 관리 지점
- **수락기준(Acceptance Criteria)** : 인도물을 완료로 인정하기 위해 충족해야 할 조건

</details>

## 2~4교시 25점 답안

## Ⅰ. WBS의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **WBS(Work Breakdown Structure)** 는 프로젝트 전체 범위를 인도물 중심으로 **Work Package** 까지 나눈 계층 구조 |
| 목적 | 범위 누락·중복 방지와 일정·원가·책임 산정의 기준 마련 |

## Ⅱ. 인도물 중심 분해라는 WBS의 특징

| 특징 | 의미 |
|---|---|
| 인도물 중심 | 수행할 활동보다 제공할 결과물 기준의 분해 |
| 계층적 완전성 | **100% 규칙** 에 따른 상위 범위와 하위 합의 일치 |
| 관리 단위 제공 | 최하위 Work Package의 일정·원가 추정과 담당자 배정 |
| 통제 기준 | 승인 후 **Scope Baseline** 으로서 변경 판단의 기준 |

## Ⅲ. WBS 작성 절차와 분해 판정

### WBS 작성 절차

```text
승인된 범위 기술서 확인
    ↓
주요 인도물 식별(1~2 레벨)
    ↓
하위 인도물 분해
    ↓
100% 규칙에 따른 누락·중복 검증
    ↓
WBS Dictionary 작성
    ↓
Scope Baseline 승인
```

### 하위 인도물 분해 확대: Work Package 도달 판정

```text
분해 대상 요소
    ↓
일정·원가 추정 가능 여부
    ↓
단일 담당자 배정 가능 여부
    ↓
완료 여부의 객관적 판정 가능 여부
    ├─ 하나라도 불가 → 한 단계 추가 분해
    └─ 모두 가능 → Work Package로 확정, 분해 중단
```

## Ⅳ. 분해 방식 비교와 Scope Baseline 구성

### 상위 레벨 분해 방식 비교

| 구분 | 인도물 기준 분해 | 생명주기 단계 기준 분해 |
|---|---|---|
| 2레벨 구성 | 시스템·모듈·문서 등 결과물 | 분석·설계·구현·시험 등 단계 |
| 적합 상황 | 결과물 구성이 명확한 구축 사업 | 단계별 검토·승인이 필요한 사업 |
| 누락 확인 방식 | 결과물 목록과 요구사항 대조 | 단계별 산출물 목록 대조 |
| 주의점 | 관리 인도물(보고·교육) 누락 | 활동 목록으로 변질되어 인도물 누락 |

### Scope Baseline 구성 관계

| 구성요소 | 역할 |
|---|---|
| 범위 기술서 | 인도물·제외 범위·가정의 서술 |
| WBS | 인도물의 계층 분해와 Work Package |
| WBS Dictionary | Work Package별 작업 설명·담당·**수락기준** |
| Control Account | 범위·일정·원가 통합 성과 측정 지점 |

## Ⅴ. WBS 작성의 한계와 방안

| 한계 | 방안 |
|---|---|
| 단계 기준 분해가 활동 목록으로 변질되어 인도물 누락 | 결과물 구성이 명확하면 인도물 기준, 단계 승인이 필요하면 단계 아래에 인도물 배치 |
| 상위 범위와 하위 합의 불일치로 누락·중복 | 상위 요소별 하위 합의 100% 규칙 교차 검토 |
| 과소·과대 분해로 추정·통제 곤란 | 추정·배정·완료 판정 가능 수준에서 분해 중단 |
| 수락기준 부재로 완료 판정의 담당자 주관 의존 | WBS Dictionary에 Work Package별 수락기준 기록 |

## Ⅵ. 제언

Work Package 분해 시점의 수락기준 확정과, 완료 판정의 그 기준 대비 증거 확인

### Work Package 관리 구조

```text
Work Package
    │
    ├─ 범위 ── 포함·제외 작업
    │
    ├─ 담당 ── 단일 책임자
    │
    ├─ 추정 ── 일정·원가
    │
    └─ 수락기준 ── 완료 인정 조건·확인 방법
```

### 수락기준 확대: 완료 판정 절차

```text
담당자의 완료 보고
    ↓
WBS Dictionary 수락기준과 산출물 증거 대조
    ├─ 기준 미충족 → 보완 후 재보고
    └─ 기준 충족 → 완료 인정과 성과 반영
```

### 선택 근거: 활동 목록 기반 관리와의 비교

| 구분 | 활동 목록 기반 관리 | 제언: 수락기준 기반 Work Package |
|---|---|---|
| 완료 판정 기준 | 담당자의 작업 수행 여부 | 사전 합의한 수락기준 충족 여부 |
| 수락기준 확정 시점 | 검수 단계 | WBS 분해 시점 |
| 진척 측정 | 담당자 추정 진척률 | 수락기준을 충족한 Work Package 수 |
| 범위 분쟁 시 근거 | 개인 해석 | WBS Dictionary 기록 |
