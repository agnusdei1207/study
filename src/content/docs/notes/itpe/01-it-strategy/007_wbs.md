## 연관 키워드

- WBS, 작업 분해 구조, 100% 규칙, 작업 패키지, WBS 사전
- 범위 기준선, OBS, 범위 크리프

## Ⅰ. WBS의 개요

- 핵심 요약 : 프로젝트 전체 범위를 인도물 중심으로 계층 분해해 관리 기준을 만드는 구조.
- 개념 : 프로젝트 전체 범위를 인도물 중심으로 계층적으로 분해한 **작업 분해 구조** (WBS, Work Breakdown Structure).
- 배경 및 필요성 : 작업 목록 나열식 관리는 범위 누락, 중복, 추정 편차의 원인.
- 주요 목적 : 범위 완전성 확보와 일정·원가·책임 배정의 공통 기준 제공.

## Ⅱ. WBS의 특징 및 장점

- 핵심 요약 : 100% 규칙, 작업 패키지, WBS 사전, 인도물 중심 분해가 누락 방지와 통제 기반으로 연결.

1. 100% 규칙 : 하위 요소의 합이 상위 범위 전체를 포함하는 **100% 규칙** → 범위 누락·중복 방지.
2. 작업 패키지 분해 : 범위를 관리·책임이 가능한 최소 단위인 **작업 패키지** (Work Package)로 분해 → 추정·통제 기반 확보.
3. WBS 사전 정비 : 요소별 범위·완료 기준·책임자를 기술한 **WBS 사전** (WBS Dictionary) 운영 → 범위 해석 오류 방지.
4. 인도물 중심 분해 : 활동이 아닌 결과물 기준의 분해 → 범위 경계의 명확화.

## Ⅲ. WBS의 구조 (흐름)

- 핵심 요약 : 범위 정의에서 인도물 식별, 패키지 분해, 기준선 승인으로 이어지는 절차 흐름.

```text
범위 정의·요구 확인
  ↓
상위 인도물 식별
  ↓
하위 인도물·작업 패키지 분해
  ↓
책임자·추정치·완료 기준 부여
  ↓
기준선 승인
```

- **범위 기준선** (승인된 범위로서 변경 관리의 비교 기준)은 분해 완료 후 승인 절차로 고정되는 관리 대상.

- 계층 분해 예시 :

```text
프로젝트 전체 범위
  시스템 구축 (상위 인도물)
     응용 프로그램 (하위 인도물)
        주문 모듈 (작업 패키지)
        결제 모듈 (작업 패키지)
     데이터 전환 (하위 인도물)
```

## Ⅳ. WBS와 OBS의 비교

- 핵심 요약 : WBS가 인도물 중심의 범위 분해 구조라면 **OBS** (Organizational Breakdown Structure)는 담당 조직 중심의 분해 구조.

| 비교 축 | WBS | OBS |
| --- | --- | --- |
| 분해 기준 | 인도물 중심 계층 | 조직·역할 중심 계층 |
| 답하는 질문 | 무엇을 인도할 것인가 | 누가 담당할 것인가 |
| 주요 용도 | 범위 정의·추정·통제의 기준 | 책임 배정·보고 체계의 정의 |
| 상호 관계 | OBS와의 교차로 책임 배정 | WBS와의 교차로 책임 배정 |

## Ⅴ. WBS의 한계와 방안

- 핵심 요약 : 범위 누락, 과잉 세분화, 범위 크리프를 인도물 검증, 단위 기준, 변경 통제로 방어.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 범위 누락 | 활동 중심 분해 → 100% 규칙 위반 | 인도물 중심 재검토·상하위 정합 점검 | 범위 변경 건수 |
| 과잉 세분화 | 관리 한계 밑 분해 → 관리 비용 증가 | 보고 주기에 맞는 패키지 크기 기준 | 작업 패키지 수 |
| **범위 크리프** (승인 밖 범위의 점진적 확대, Scope Creep) | 승인 밖 요구 추가 → 일정·원가 초과 | 변경 통제 절차와 기준선 관리 | 무승인 변경 건수 |

## Ⅵ. WBS에 대한 제언

- 핵심 요약 : WBS를 계약·일정·원가·변경 통제가 공유하는 프로젝트 관리의 기준 자산으로 격상할 필요.

1. 프로젝트 관리자·후원자 : WBS와 WBS 사전의 범위 승인 문서 채택과 계약·검수 문서와의 일치 확인.
2. 관리 표준 조직 : WBS 템플릿과 사전 양식의 조직 자산화로 프로젝트 간 재사용성 확보.
3. 원가·일정 관리 체계 : 작업 패키지를 **통제 계정** (범위·일정·원가·책임을 통합 관리하는 지점, Control Account)과 연결한 성과 측정 기반 구축.

## Ⅶ. WBS의 결론

- 핵심 요약 : WBS는 범위를 누락 없이 작업으로 번역하는 프로젝트 관리의 기준 구조.
- WBS가 계약·일정·원가·변경 통제의 공통 기준일 때 범위 분쟁 없는 수행이 가능.
