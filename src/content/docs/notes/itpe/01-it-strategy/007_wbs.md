## 연관 키워드

- WBS, 범위 기준선, 인도물 분해, 100% 규칙

## Ⅰ. WBS의 개요

- 핵심 요약 : 프로젝트 전체 범위를 인도물 중심으로 계층 분해한 구조.
- 개념 : WBS(Work Breakdown Structure)는 프로젝트 전체 범위를 인도물 중심으로 계층 분해한 구조.
- 배경 및 필요성 : 작업 목록만으로 범위를 관리하면 누락·중복·추정 편차 발생.
- 주요 목적 : 범위 완전성·책임·일정·원가 산정의 공통 기반 제공.

## Ⅱ. WBS의 특징 및 장점

- 핵심 요약 : 하위 요소의 합이 상위 범위를 포함하는 100% 규칙과 작업 패키지.

1. 100% 규칙 → 범위 누락·중복 억제.
2. 작업 패키지·책임자 → 원가·일정·책임 추정 기반.
3. 범위 완전성: 하위 인도물의 합이 승인된 상위 범위를 모두 포함하도록 100% 규칙 적용.

## Ⅲ. WBS의 구조 (흐름)

- 핵심 요약 : 범위 정의 → 주요 인도물 → 하위 인도물·작업 패키지 → 책임·원가·일정 부여 → 기준선 승인.

```text
범위 정의
  ↓
주요 인도물
  ↓
하위 인도물·작업 패키지
  ↓
책임·원가·일정 부여
  ↓
기준선 승인
```

- 분해 기준 : 관리 가능한 작업 패키지에 고유 식별자·책임자·완료조건·추정치를 부여하고 사전에 정의.

```text
프로젝트 전체 범위
  ↓
인도물 계층
  ↓
작업 패키지
  ↓
책임·완료기준
```

## Ⅳ. 유사 개념과의 비교

- 핵심 요약 : WBS는 무엇을 제공할지 표현, 네트워크 다이어그램은 작업 순서·의존관계 표현.

| 비교 기준 | 일정 네트워크 | WBS |
| --- | --- | --- |
| 핵심 초점 | 작업 순서·선후행 관계·임계경로 | 전체 범위·인도물의 계층 분해 |
| 주요 효과 | 작업 네트워크로 선후행 관계·임계경로와 일정 영향 분석 | WBS·사전으로 전체 인도물·범위 책임·추정 기준선 정의 |

## Ⅴ. WBS의 한계와 방안

- 핵심 요약 : 조직도형 분해로 인도물 누락, 지나친 세분화로 관리비용 증가; 인도물 중심 분해, WBS Dictionary에 범위·완료 기준·책임자 기록.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 범위 누락 | 100% 규칙 미충족 | 상위·하위 인도물 검토 | 범위 변경률 |
| 관리 불가한 세분화 | 작업 패키지 과소분해 | 관리 가능한 단위·완료기준 설정 | 미완료 패키지 수 |
| 책임 모호 | WBS 요소 소유자 부재 | WBS Dictionary·책임배정 | 무담당 항목 수 |

## Ⅵ. WBS에 대한 제언

- 핵심 요약 : 범위 승인 시 고객·수행자가 100% 완전성과 추적성 확인.

1. 프로젝트 관리자·범위 책임자 : 인도물 기준 WBS와 WBS 사전을 검토하고 100% 범위 포함·완료기준 승인.
2. 실무 담당자 : 상위·하위 인도물 검토; 관리 가능한 단위·완료기준 설정; WBS Dictionary·책임배정.
3. 범위 책임자 : 미승인 범위변경과 사전 없는 작업 패키지를 기준선 검토에서 차단하고 완료 시 인도물 수용을 확인.

## Ⅶ. WBS의 결론

- 핵심 요약 : 프로젝트 전체 범위를 인도물 중심으로 계층 분해한 구조.
- 시사점 : WBS Dictionary와 책임배정표를 일정·원가·변경 통제의 공통 기준으로 사용.
