## 지식 로드맵 내 현재 위치

IT 전략·관리 → 고객·마케팅 전략 → **CRM**

## 30초 인출

- 본질: CRM(Customer Relationship Management)은 고객 통찰을 활용해 고객 가치와 주주 가치를 함께 만드는 전략적 접근이며, 정보시스템으로 고객 접점과 데이터를 통합해 실행
- 메커니즘: 운영형 CRM이 접점의 고객 상호작용을 처리·기록하고, 분석형 CRM이 그 데이터에서 선호·행동을 분석하며, 협업형 CRM이 부서 간 공유로 결과를 접점 응대에 반영
- 통찰: 채널별 고객 데이터를 통합할수록 분석이 수집 시 동의받은 목적을 벗어나기 쉬우므로, 통합 데이터에 수집 목적·동의 내역을 함께 두고 분석 요청마다 목적 범위를 대조

<details>
<summary>핵심 용어</summary>

- **CRM(Customer Relationship Management)** : 고객 통찰로 고객 가치와 주주 가치를 만드는 전략적 접근. 부서를 가로지르는 프로세스 중심으로 실행
- **운영형 CRM(Operational CRM)** : 고객과 직접 만나는 일상 업무를 효율화하는 유형. 마케팅·영업·서비스 자동화가 중심
- **분석형 CRM(Analytical CRM)** : 고객 상호작용 데이터를 수집·분석해 선호·행동·구매 패턴을 파악하는 유형
- **협업형 CRM(Collaborative CRM)** : 부서 간 내부 소통과 조율을 개선하는 유형
- **다채널 통합(Multichannel Integration)** : 여러 고객 접점의 상호작용을 하나로 연결하는 CRM 프로세스

</details>

## 2~4교시 25점 답안

## Ⅰ. CRM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CRM(Customer Relationship Management)** 은 고객 통찰로 고객 가치와 주주 가치를 함께 창출하는 부서 횡단의 전략적 관리 활동 |
| 목적 | 고객 이해에 기반한 고객 가치와 주주 가치의 동시 창출 |

## Ⅱ. 시스템 도입을 넘는 CRM의 특징

| 특징 | 의미 |
|---|---|
| 전략적 접근 | 기술 구현이 아닌 고객 통찰 활용 전략 |
| 부서 횡단·프로세스 중심 | 특정 부서의 기능이 아닌 여러 부서를 잇는 프로세스 |
| 다채널 | 여러 접점의 상호작용을 잇는 다채널 통합 프로세스 포함 |
| 고객 데이터 의존 | 상호작용 데이터의 수집·분석이 실행의 기반 |

## Ⅲ. CRM의 구성 체계

### CRM 전략적 프레임워크의 5개 프로세스

```text
CRM 전략적 프레임워크 (Payne & Frow, 2005)
    │
    ├─ 전략 개발 프로세스
    ├─ 가치 창출 프로세스
    ├─ 다채널 통합 프로세스
    ├─ 정보 관리 프로세스
    └─ 성과 평가 프로세스
```

### 다채널 통합·정보 관리 확대: 정보시스템의 데이터 흐름

```text
고객 접점(영업·마케팅·서비스 채널)
    ↓ 상호작용의 처리·기록
운영형 CRM
    ↓ 고객 상호작용 데이터
분석형 CRM ── 선호·행동·구매 패턴 분석
    ↓ 분석 결과
접점의 응대·제안에 반영

협업형 CRM ── 부서 간 정보 공유·조율 (전 구간)
```

## Ⅳ. CRM 유형별 비교

| 구분 | 초점 | 대표 기능 |
|---|---|---|
| **운영형 CRM** | 고객 접점의 일상 업무 | 마케팅·영업·서비스 자동화 |
| **분석형 CRM** | 고객 데이터의 분석 | 선호·행동·구매 패턴 분석 |
| **협업형 CRM** | 부서 간 소통과 조율 | 공유 지식 기반, 채널 간 응대 조율 |

## Ⅴ. CRM의 한계와 방안

| 한계 | 방안 |
|---|---|
| 채널별 시스템에 고객 데이터가 분산되어 접점 간 응대 불일치 | **다채널 통합** 프로세스에 따른 고객 기준 데이터 통합 |
| 목적에 불필요한 항목의 과다 수집 | 수집 목적별 필요 최소 항목의 정의 (개인정보 보호법 제16조제1항) |
| 분석이 수집 목적의 범위를 초과 (개인정보 보호법 제15조제1항·제18조제1항) | 분석 과제마다 수집 목적·동의 범위의 대조와 범위 밖 항목의 제외 또는 별도 동의 |
| 마케팅 동의가 서비스 이용 조건으로 결합 | 홍보·판매 권유 동의의 별도 구분과 미동의 시 서비스 제공 유지 (같은 법 제22조제1항제7호·제5항) |

## Ⅵ. 제언

통합 고객 데이터에 수집 목적과 동의 내역을 함께 저장하고, 분석 요청마다 이용 목적의 범위를 대조

### 목적·동의 정보를 가진 통합 고객 데이터

```text
통합 고객 데이터
    ├─ 고객 정보 항목
    ├─ 수집 목적
    └─ 동의 내역 (홍보·판매 권유 동의는 별도 구분)
```

### 분석 요청 시 이용 목적 대조

```text
분석 요청(캠페인·모델 학습)
    ↓
수집 목적·동의 범위와 대조
    ├─ 범위 안 → 분석 수행
    └─ 범위 밖 → 별도 동의 확보 또는 대상 제외
    ↓
분석 결과의 접점 반영
```

| 구분 | 통합 후 자유 이용 | 제언: 목적·동의 대조 후 이용 |
|---|---|---|
| 이용 판단 기준 | 분석 담당 부서의 필요 | 수집 목적·동의 범위 |
| 마케팅 동의 | 다른 동의와 결합 | 별도 구분 |
| 범위 밖 항목 | 분석에 포함 | 제외 또는 별도 동의 |
