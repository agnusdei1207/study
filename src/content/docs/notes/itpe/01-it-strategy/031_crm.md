## 지식 로드맵 내 현재 위치

IT 전략·관리 → 고객·마케팅 전략 → **CRM**

## 30초 인출

- 본질: CRM(Customer Relationship Management)은 고객 접점의 기록과 분석으로 고객 관계를 관리하는 업무 방식과 이를 지원하는 정보시스템
- 메커니즘: 운영 CRM이 접점 기록을 쌓고, 분석 CRM이 세분화·예측 결과를 만들며, 협업 CRM이 그 결과를 채널·부서에 전달하는 순환
- 통찰: 식별 기준 없이 모은 데이터는 접점 개선으로 이어지지 않으므로 핵심 고객 여정부터 식별 기준 확정과 반영 검증

<details>
<summary>핵심 용어</summary>

- **CRM(Customer Relationship Management)** : 고객 접점의 기록·분석·공유로 고객 관계를 관리하는 업무 방식과 이를 지원하는 정보시스템
- **운영 CRM** : 영업·마케팅·고객서비스 등 고객 접점 업무를 처리하고 기록하는 영역
- **분석 CRM** : 축적된 고객 데이터로 세분화·이탈 예측·성과 측정을 수행하는 영역
- **협업 CRM** : 여러 채널과 부서 사이에 고객 정보와 상호작용 이력을 공유하는 영역
- **CDP(Customer Data Platform)** : 여러 원천의 고객 데이터를 통합해 고객 프로필과 세그먼트를 만드는 데이터 플랫폼
- **MDM(Master Data Management)** : 고객·제품 같은 기준 데이터의 정의·품질·변경을 관리하는 체계

## 2~4교시 25점 답안

## Ⅰ. CRM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CRM(Customer Relationship Management)** 은 고객 접점의 기록·분석·공유로 고객 관계를 관리하는 업무 방식과 정보시스템 |
| 목적 | 고객 이탈 감소와 고객별 맞춤 영업·서비스 제공 |

## Ⅱ. 거래 관리와 구별되는 CRM의 특징

| 특징 | 의미 |
|---|---|
| 고객 단위 관리 | 개별 거래가 아닌 고객 한 명의 전체 접점 이력 기준 관리 |
| 접점 통합 | 영업·상담·마케팅·온라인 채널 기록의 고객별 연결 |
| 분석·실행 순환 | 분석 결과의 영업·서비스 접점 반영과 고객 반응의 재분석 |
| 처리 조건 준수 | 개인정보 처리 근거와 이용 목적 범위 안의 수집·분석 |

## Ⅲ. CRM 구성 체계와 분석·실행 순환

### CRM 구성 체계

```text
CRM 체계 ── 고객 관계 관리 전략
    │
    ├─ 운영 CRM ── 영업·마케팅·서비스 접점 처리와 기록
    │
    ├─ 분석 CRM ── 고객 세분화·이탈 예측·성과 분석
    │
    ├─ 협업 CRM ── 채널·부서 간 고객 정보 공유
    │
    └─ 고객 데이터 기반 ── 고객 식별 기준·처리 근거·품질
```

### 분석 CRM 확대: 분석 결과의 접점 반영 순환

```text
접점별 고객 활동·거래 기록 (운영 CRM)
    ↓
고객 식별 기준에 따른 기록 통합
    ↓
세분화·이탈 예측 분석 (분석 CRM)
    ↓
허용된 채널·부서로 결과 전달 (협업 CRM)
    ↓
고객 반응의 기록과 다음 분석 주기 반영
```

## Ⅳ. CRM과 CDP의 역할 범위 비교

| 구분 | CRM | **CDP** |
|---|---|---|
| 중심 역할 | 고객 관계 업무와 접점 처리 | 여러 원천 고객 데이터의 통합 |
| 주요 사용자 | 영업·마케팅·서비스 현업 | 데이터·마케팅 분석 조직 |
| 데이터 범위 | 거래·상담·캠페인 등 업무 기록 | 웹·앱·오프라인 행동을 포함한 전 채널 데이터 |
| 고객 식별 | 업무 시스템의 고객 번호 | 여러 식별자를 결합한 통합 프로필 |

두 시스템이 서로 다른 식별 기준으로 같은 고객을 관리하는 경우 고객 중복과 속성 불일치 발생

## Ⅴ. CRM 도입의 한계와 방안

| 한계 | 방안 |
|---|---|
| 접점별 고객 기록의 중복·오류 | **MDM** 기반 고객 기준정보와 품질 책임자 지정 |
| CRM·CDP 간 고객 식별 기준 차이 | 두 시스템의 고객 키·원천 우선순위·동기화 주기 합의 |
| 목적 범위를 벗어난 수집·분석 | 「개인정보 보호법」 제15조에 따른 항목별 처리 근거와 이용 목적 확인 |
| 분석 결과의 접점 미반영 | 결과 전달 채널·담당자·고객 반응 측정 기준 지정 |
| 목적 종료 후 고객정보 잔존 | 보유기간 점검과 불필요 정보 파기 |

## Ⅵ. 제언

고객 영향이 큰 여정 하나에서 고객 식별 기준과 처리 근거를 먼저 확정하고, 분석 결과의 접점 반영까지 검증한 뒤 다음 여정으로 확대

### 핵심 여정의 CRM 순환 책임 구조

```text
핵심 고객 여정의 CRM 순환 책임
    │
    ├─ 데이터 책임자 ── 고객 식별 기준·기준정보 품질
    │
    ├─ 개인정보 담당 ── 항목별 처리 근거·보유기간
    │
    └─ 현업 부서 ── 분석 결과의 접점 반영과 반응 측정
```

### 현업 부서 확대: 여정 단위 확대 판정 절차

```text
대상 여정 선정과 고객 반응 기준값 측정
    ↓
식별 기준·처리 근거 확정 후 분석 결과 접점 반영
    ↓
기준값 대비 고객 반응 변화 확인
    ├─ 변화 미달 → 전달 채널·분석 대상 재설계
    └─ 변화 확인 → 다음 여정으로 확대
```

### 선택 근거: 전사 일괄 통합과의 비교

| 구분 | 전사 일괄 통합 | 제언: 여정 단위 순환 검증 |
|---|---|---|
| 적용 범위 | 전 채널·전 고객 데이터의 동시 통합 | 고객 영향이 큰 여정 하나 |
| 고객 식별 기준 | 시스템별 기준 유지 후 사후 대사 | 연결 전 단일 기준 확정 |
| 처리 근거 확인 시점 | 캠페인 실행 직전 | 수집·연결 이전 |
| 성과 판단 | 통합 데이터 규모 | 접점 반영 후 고객 반응 변화 |
