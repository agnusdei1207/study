## 30초 인출

- 본질: **부정적 위험 대응 전략** 은 프로젝트 목표 위협에 회피·전가·완화·수용을 적용하고 권한 밖 위험을 상위에 이관하는 선택.
- 메커니즘: 위험 가능성·영향·통제 권한에 따른 대응 선택, 책임자·조치·발동 조건 지정, 잔여 위험 재평가.
- 통찰: 한계: 모든 부정 위험을 동일한 조치로 다루는 비효율 → 방안: 가능성·영향·통제력에 따라 회피·전가·완화·수용을 선택

<details>
<summary>핵심 용어</summary>

- **부정적 위험 대응 전략** : 프로젝트 목표 위협의 제거·전가·완화·수용 또는 권한 밖 위험의 상위 의사결정 이관.
- **회피(Avoid)** : 위협의 원인·프로젝트 계획 변경을 통한 위험 제거.
- **전가(Transfer)** : 계약·보험 등을 통한 위험 관리·재정 결과 일부의 제3자 이전. 책임 자체의 자동 소멸은 아님.
- **완화(Mitigate)** : 발생 가능성·부정적 영향 감소 조치.
- **수용(Accept)** : 별도 예방 조치보다 모니터링·사전 합의된 우발 대응을 택하는 대응.
- **상향(Escalate)** : 프로젝트 책임자 권한을 넘는 위협의 상위 프로그램·포트폴리오·조직 의사결정자 이관.
- **잔여 위험·2차 위험** : 대응 후 남은 위험과 대응 조치로 새로 생긴 위험.
</details>

## 2~4교시 25점 답안

## Ⅰ. 부정적 위험 대응 전략의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **부정적 위험 대응 전략** 은 프로젝트 목표 위협에 회피·전가·완화·수용을 적용하고 권한 밖 위험을 상위에 이관하는 선택 |
| 목적 | 우선순위·통제 권한에 따른 프로젝트 위협 관리, 손실 제한과 잔여 위험 관리 |

## Ⅱ. 부정적 위험 대응의 특징

| 판단축 | 대응에 미치는 영향 |
|---|---|
| 발생 가능성·영향 | 조치 우선순위와 자원 배분 |
| 원인 통제력 | 회피 가능성 또는 완화·전가·수용의 검토 |
| 책임·권한 | 프로젝트 안의 조치 또는 상위 의사결정 이관 |

## Ⅲ. 대응 실행과 위험 상태 갱신 프로세스

```text
위험 평가·우선순위 설정
    ↓
대응 전략·책임자 지정
    ↓
조치·기한·발동 조건 계획
    ↓
대응 실행·잔여 위험 재평가
    └→ 위험대장 갱신
```

위험대장의 핵심 기록은 원인·사건·영향·평가 근거·대응 전략·책임자·기한·발동 조건. 실행 후 대응 효과와 잔여 위험을 재평가하고, 조치로 새 위험이 생긴 경우 위험대장에 추가.

```text
위협의 원인·영향 확인 → 통제 권한 밖인가?
                           ├ 예 → 상위 조직에 상향
                           └ 아니오 → 제거 가능성·책임 이전·조치 비용 비교
                                                  ↓
                                           대응 선택·잔여 위험 재평가
```

## Ⅳ. 부정적 위험 대응 전략의 종류와 비교

| 전략 | 위험에 작용하는 방식 | 유의점 |
|---|---|---|
| 회피 | 원인·계획 변경에 따른 위협 제거 | 범위·비용·일정 영향의 병행 검토 |
| 전가 | 계약·보험 등을 통한 위험 관리·재정 결과 일부의 제3자 이전 | 위험 원인·발주 측 의무의 자동 이전 불가 |
| 완화 | 발생 가능성·부정적 영향 감소 | 조치 비용·기대 효과 비교와 잔여 위험 재평가 |
| 수용 | 적극 조치 없이 감시하거나 우발 대응을 준비하는 방식 | 발동 조건·책임자·예비 자원의 명확화 |
| 상향 | 프로젝트 권한 밖 위협의 상위 조직 이관 | 프로젝트 책임자 잔여 조치·정보 공유의 지속 관리 |

### 대응 전략 선택 기준

| 판단 요소 | 확인할 조건 | 시사점 |
|---|---|---|
| 가능성·영향 | 목표에 미치는 위협의 크기·긴급성 | 우선순위에 맞춘 조치 시점·자원 결정 |
| 원인 통제력 | 원인·계획 변경을 통한 위협 제거 가능성 | 제거 가능 시 회피, 불가 시 완화·전가·수용 비교 |
| 책임·권한 | 계약·프로젝트 권한 내 처리 가능성 | 계약상 이전 범위·잔여 책임 확인, 권한 밖 사안의 상향 |
| 비용·효과 | 조치 비용과 예상 손실 감소의 균형 | 과잉 조치·무대응 사이의 비용 효과 비교 |

위험별 대응 전략 선택. 가능성·영향 점수만으로 자동 결정하지 않고 원인 통제 가능성·책임 분담·비용·목표 제약을 함께 검토. 기회 대응인 활용·공유·증대와 부정적 위험 전략의 구분.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 점수만을 통한 기계적 전략 선택 | 원인·책임·비용·목표 제약 병행 검토 |
| 위험 책임자·조치 담당자 혼동 | 위험 책임자와 조치 수행자를 별도 지정 |
| 발동 기준 없는 수용 계획 | 지표·임계값·통보 대상·의사결정 시점 지정 |
| 대응 후 상태 미갱신 | 조치 완료 시 위험대장 갱신과 잔여·2차 위험 재평가 |

## Ⅵ. 제언

통제 권한을 넘거나 영향이 큰 위협부터 책임자·발동 조건을 정하고 조치 후 잔여 위험을 재평가해 전략 변경 결정.
