## 연관 키워드

- Earned Value Management, PV, EV, AC, SV, CV, SPI, CPI, EAC

## Ⅰ. EVM의 개요

- 핵심 요약 : **EVM** (Earned Value Management)은 범위·일정·원가 기준선을 통합해 계획 대비 수행성과와 비용·일정 편차를 측정하는 방법.
- 개념 : EVM은 범위·일정·원가 기준선을 통합해 계획 대비 수행성과와 비용·일정 편차를 측정하는 방법.
- 배경 및 필요성 : 투입비용과 완료율을 따로 보면 실제 진척과 초과·지연을 조기에 판단하기 어려움.
- 주요 목적 : 기준선 대비 성과·편차·추세를 정량 파악하고 예측·시정 지원.

## Ⅱ. EVM의 특징 및 장점

- 핵심 요약 : PV·EV·AC와 SV·CV·SPI·CPI가 기준선 대비 성과·편차·추세를 정량화.

1. **PV** (Planned Value) : 계획된 일정까지 수행해야 할 작업의 예산 가치 → 계획 기준선 설정.
2. **EV** (Earned Value) : 실제로 완료된 작업의 예산 가치 → 진척을 비용 단위로 환산.
3. **AC** (Actual Cost) : 완료 작업에 실제 투입된 비용 → 지출 실적 측정.
4. SV·CV·SPI·CPI : SV=EV−PV, CV=EV−AC, SPI=EV/PV, CPI=EV/AC → 일정·비용 편차와 효율 지수 산출.
5. EAC 예측 : 현재 성과 추세를 바탕으로 완료 예상 비용 추정 → 시정조치와 재예산 판단 지원.

## Ⅲ. EVM의 구조 (흐름)

- 핵심 요약 : 범위·일정·원가 기준선 → 작업 완료 증거로 EV 산정 → PV·AC 비교 → 편차·지수 → EAC 예측·시정.

```text
범위·일정·원가 기준선
   ↓
작업 완료 증거로 EV 산정
   ↓
PV·AC 비교
   ↓
편차·지수
   ↓
EAC 예측·시정
```

- 지표 흐름 : PV·EV·AC 수집 → SV·CV·SPI·CPI → EAC·시정.

```text
PV·EV·AC 수집 → SV·CV·SPI·CPI → EAC·시정
```

## Ⅳ. 단순 비용추적과 EVM의 비교

- 핵심 요약 : 단순 비용추적은 실제 지출 AC만 추적, EVM은 범위 완료가치 EV와 계획·실제 비용 통합 비교.

| 비교 기준 | 단순 비용추적 | EVM |
| --- | --- | --- |
| 성과 판단 | 실제 지출 AC만 추적 | 범위 완료가치 EV와 계획·실제 비용 통합 비교 |
| 일정 관리 | 완료율 별도 관리 | EV·PV로 일정 편차 정량화 |
| 예측 | 지출 추세 기반 | CPI·SPI 기반 EAC 추정 |
| 필요한 데이터 | 비용 지출 내역 | WBS·기준선·완료 증거·비용 |

## Ⅴ. EVM의 한계와 방안

- 핵심 요약 : 기준선 왜곡·EV 주관성·예측 오용; 승인된 기준선·객관적 완료기준·맥락 기반 예측으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기준선 왜곡 | 불완전 범위·잦은 재기준선 | 승인된 범위·기준선 변경통제 | 기준선 변경건수 |
| EV 주관성 | 완료율 임의 산정 | 객관적 완료기준·증거 기반 진척 | EV 검증편차 |
| 예측 오용 | CPI·SPI 추세를 맥락 없이 외삽 | 잔여위험·자원·계약변수와 함께 EAC 판단 | 예측오차 |
| 데이터 지연 | 진척·비용 보고 지연 | 기준일 통일·자동 수집 | 보고 지연일 |

## Ⅵ. EVM에 대한 제언

- 핵심 요약 : 프로젝트 관리자는 작업패키지 완료규칙과 데이터 기준일을 통일하고 편차 원인·예측·시정조치를 주기적으로 설명.

1. 프로젝트 관리자 : 작업패키지 완료규칙과 데이터 기준일을 통일하고 편차 원인·예측·시정조치를 주기적으로 설명.
2. 실무 담당자 : 승인된 범위·기준선 변경통제; 객관적 완료기준·증거 기반 진척; 잔여위험·자원·계약변수와 함께 EAC 판단.
3. 이해관계자 : 기준선 변경건수·EV 검증편차·예측오차 지표를 정기 검토하고 미달 원인·시정조치·잔여위험 기록.

## Ⅶ. EVM의 결론

- 핵심 요약 : EVM은 범위·일정·원가 기준선을 통합해 계획 대비 수행성과와 비용·일정 편차를 측정하는 방법.
- 시사점 : EVM은 비용을 지출률로 보는 대신 완료된 범위의 가치와 계획·실적을 함께 비교하는 통제 기법.
