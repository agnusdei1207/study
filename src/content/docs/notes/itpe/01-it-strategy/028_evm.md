## 연관 키워드

- 획득가치관리(EVM, Earned Value Management), PV, EV, AC
- CV, SV, CPI, SPI, BAC, EAC, WBS

## Ⅰ. EVM의 개요

- 핵심 요약 : 완료된 작업을 예산 기준 금액으로 환산해 일정·비용 성과를 통합 측정하고 완료 시점을 예측하는 프로젝트 관리 기법.
- 개념 : **획득가치관리** (EVM, Earned Value Management)은 완료된 작업을 예산 기준 금액으로 환산한 획득가치를 축으로 계획가치·실제비용과 비교해 일정·비용 성과를 통합 측정하는 관리 기법.
- 배경 및 필요성 : 지출액만 계획과 비교하면 비용 소진이 계획대로라도 진도가 뒤처지는 상황을 구별할 수 없어 초과·지연의 조기 발견이 곤란.
- 주요 목적 : 범위·일정·비용을 통합한 객관적 성과 판단과 완료 예측을 통한 프로젝트 통제력과 의사결정 품질의 향상.

## Ⅱ. EVM의 특징 및 장점

- 핵심 요약 : 세 기본 지표와 편차·지수·예측 지표의 연산 체계가 성과의 방향·효율·완료 전망을 정량화.

1. 세 지표 통합 : **계획가치** (PV, Planned Value)·**획득가치** (EV, Earned Value)·**실제비용** (AC, Actual Cost)의 공통 금액 척도 비교 → 일정·비용 상태의 단일 판단 체계.
2. 편차 산출 : **비용편차** (CV, Cost Variance) = EV − AC, **일정편차** (SV, Schedule Variance) = EV − PV → 초과·지연 여부의 금액 기준 판단.
3. 지수 산출 : **비용성과지수** (CPI, Cost Performance Index) = EV / AC, **일정성과지수** (SPI, Schedule Performance Index) = EV / PV → 투입 대비 성과 효율의 비율 판단.
4. 완료 예측 : 현재 비용 효율이 지속된다는 가정의 **완료예상비용** (EAC, Estimate at Completion) = **완료예산** (BAC, Budget at Completion) / CPI 산정 → 최종 비용 전망 제시.
5. 금액 기반 진척 표현 : 완료 작업량을 예산 금액(EV)으로 표현 → 기술·비기술 이해관계자가 공유하는 진척 판단 언어 확보.

## Ⅲ. EVM의 구조 (흐름)

- 핵심 요약 : 범위 분해와 기준선 수립에서 시작해 지표 산출, 예측, 시정조치로 이어지는 측정·통제 흐름.
- 기준선 근거 : **WBS** (Work Breakdown Structure, 작업분해구조)는 프로젝트 범위를 작업 단위로 분해한 계층 구조로, 작업별 예산·일정 배분의 기준 역할.

```text
[ EVM 운영 흐름 ]

WBS 작업 분해·기준선(예산·일정) 수립
   ↓
PV 배분·작업 수행
   ↓
EV·AC 측정
   ↓
CV·SV·CPI·SPI 산출
   ↓
EAC 예측·시정조치
```

- 지수 해석 기준 : 1을 기준으로 성과의 유리·불리 판단.

```text
[ CPI·SPI 해석 기준 ]

1보 큰 값 → 계획보다 유리
1과 같은 값 → 계획과 동일
1보 작은 값 → 계획보다 불리
```

## Ⅳ. EVM과 계획 대비 실적 단순 비교 방식의 비교

- 핵심 요약 : 지출액 중심의 계획 대비 실적 단순 비교가 돈의 흐름만 보는 방식이라면 EVM은 완료된 범위의 가치까지 포함해 성과를 판단.

| 비교 축 | EVM | 계획 대비 실적 단순 비교 방식 |
| --- | --- | --- |
| 측정 기준 | 완료 작업의 예산 가치(EV) | 예산 대비 지출액 |
| 일정 판단 | SV·SPI의 정량 산출 | 완료율 보고·주관 판단 의존 |
| 비용 판단 | CV·CPI로 효율까지 진단 | 초과·절감 여부만 확인 |
| 완료 예측 | BAC·CPI 기반 EAC 산정 | 추세 관찰·경험 의존 |
| 관리 범위 | 범위·일정·비용의 동시 분석 | 항목별 분리 관리 |

## Ⅴ. EVM의 한계와 방안

- 핵심 요약 : 기준선 왜곡·완료율 주관성·데이터 지연·지표 오해석을 변경통제·완료 규칙·보고 기준·원인 분석으로 일대일 보완 필요.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기준선 왜곡 | 범위 변경의 기준선 미반영 → 지표 신뢰 상실 | 승인된 변경통제 절차로만 기준선 갱신 | 기준선 변경 건수 |
| 완료율 주관성 | 진도율 자의 산정 → 성과 과대·과소 보고 | 0/100·50/50 같은 고정 완료 규칙 적용 | 검증되지 않은 진도 보고 건수 |
| 데이터 지연 | 진척·비용 집계 시점 불일치 → 지표 왜곡 | 보고 기준일 통일과 수집 자동화 | 보고 지연 일수 |
| 지표 오해석 | CPI·SPI의 단독 해석 → 잘못된 의사결정 | 편차 원인·위험·범위 변경과 함께 해석 | EAC 예측 오차 |

## Ⅵ. EVM에 대한 제언

- 핵심 요약 : 발주기관·경영진이 EVM 보고를 사업 통제 표준으로 채택하고 측정 규칙과 데이터 체계를 표준화하는 방향.

1. 발주기관·경영진 : 대규모 IT 투자 사업에 EVM 기반 성과보고를 채택해 진도·예산 판단의 공통 기준 마련.
2. 프로젝트 관리 전담 조직 : 작업패키지 단위 완료 규칙·보고 주기·데이터 기준일을 표준 절차로 정비.
3. 데이터 체계 : 프로젝트관리시스템 연동을 통한 EV·AC 자동 수집으로 보고 부담 축소.

## Ⅶ. 결론

- 핵심 요약 : EVM은 범위·일정·비용을 하나의 금액 척도로 통합해 프로젝트 상태를 조기 진단하는 통제 기법.
- 지표 산출 자체가 아니라 편차 원인 분석과 시정조치의 연계가 활용의 핵심.
