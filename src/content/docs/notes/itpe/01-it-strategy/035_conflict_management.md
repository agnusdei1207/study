## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 인적자원·팀 관리 → **갈등관리**

## 30초 인출

- 본질: 갈등관리는 팀과 이해관계자 사이의 의견 차이와 불화를 유형별로 파악해 성과를 해치지 않도록 다루는 프로젝트 관리 활동
- 메커니즘: 갈등을 과업 갈등과 관계 갈등으로 나누고, 자기주장성과 협조성의 정도로 정리한 대응 방식 5가지(경쟁·협력·타협·회피·수용) 중에서 선택
- 통찰: 과업 갈등은 비정형 과업에서 집단 기능을 해치지 않지만 정형 과업에서는 해롭고 관계 갈등은 구성원 만족을 낮추므로, 갈등을 억제하기 전에 유형과 과업 성격을 먼저 판별해 이견의 활용 여부와 대응 방식을 결정

<details>
<summary>핵심 용어</summary>

- **갈등(Conflict)** : 당사자가 서로 다른 견해를 갖거나 인간적으로 양립하기 어렵다고 인식하는 상태
- **과업 갈등(Task Conflict)** : 수행 중인 과업의 내용에 대한 관점·아이디어·의견의 차이
- **관계 갈등(Relationship Conflict)** : 구성원 사이의 인간적 불화. 긴장·적대감·짜증이 수반
- **TKI(Thomas-Kilmann Conflict Mode Instrument)** : 갈등 대응 방식을 경쟁·협력·타협·회피·수용의 5가지로 측정하는 도구
- **자기주장성(Assertiveness)** : 자기 요구를 충족하려는 정도
- **협조성(Cooperativeness)** : 상대의 요구를 충족시키려는 정도
- **경쟁(Competing)** : 자기주장성 높음, 협조성 낮음
- **협력(Collaborating)** : 자기주장성 높음, 협조성 높음
- **타협(Compromising)** : 자기주장성 중간, 협조성 중간
- **회피(Avoiding)** : 자기주장성 낮음, 협조성 낮음
- **수용(Accommodating)** : 자기주장성 낮음, 협조성 높음

</details>

## 2~4교시 25점 답안

## Ⅰ. 프로젝트 갈등관리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **갈등(Conflict)** 의 유형을 파악하고 대응 방식을 선택해 프로젝트 성과 저해를 막는 관리 활동 |
| 목적 | 갈등의 성과 저해 방지와 과업 이견의 논의 활용 |

## Ⅱ. 갈등의 특징과 프로젝트 성과의 관계

| 갈등 유형 | 의미 | 성과와의 관계 |
|---|---|---|
| **과업 갈등(Task Conflict)** | 과업 내용에 대한 관점·아이디어·의견의 차이 | 정형 과업은 집단 기능에 해로움, 비정형 과업은 해롭지 않고 때로 유익, 개인 만족은 저하 |
| **관계 갈등(Relationship Conflict)** | 구성원 사이의 긴장·적대감·짜증 | 개인 만족·동료 호감·잔류 의사의 저하 |

## Ⅲ. 갈등 대응 체계

### 유형 판별에서 대응 방식 선택까지의 흐름

```text
갈등 인지
    ↓
유형 판별
    ├─ 과업 갈등: 과업 내용의 견해 차이
    └─ 관계 갈등: 구성원 간 불화
    ↓
상황 진단: 과업 성격(정형·비정형), 상호의존성, 토론 규범
    ↓
대응 방식 선택: TKI 5가지
    ↓
실행 후 결과 확인
```

### 상황 진단 확대: 토론 규범의 효과

```text
갈등의 공개 토론을 권장하는 규범
    ├─ 관계 갈등의 수와 강도 증가
    └─ 갈등을 건설적으로 다루는 구성원의 능력 향상 없음
```

## Ⅳ. 갈등의 요인과 해결 전략

### 갈등의 요인

| 구분 | 내용 |
|---|---|
| 과업 내용의 견해 차이 | 과업 수행 방식과 내용에 대한 관점·아이디어·의견의 불일치 |
| 구성원 간 인간적 불화 | 긴장·적대감·짜증으로 나타나는 대인 관계의 양립 불가 |
| 성과 영향 조건 | 과업 성격, 과업 상호의존성, 집단 규범에 따라 달라지는 갈등의 효과 |

### 해결 전략: TKI 5가지 대응 방식

| 방식 | 자기주장성 | 협조성 |
|---|---|---|
| 경쟁(Competing) | 높음 | 낮음 |
| 협력(Collaborating) | 높음 | 높음 |
| 타협(Compromising) | 중간 | 중간 |
| 회피(Avoiding) | 낮음 | 낮음 |
| 수용(Accommodating) | 낮음 | 높음 |

## Ⅴ. 갈등관리의 한계와 방안

| 한계 | 방안 |
|---|---|
| 과업 갈등과 관계 갈등을 구분하지 않은 억제가 비정형 과업의 유익한 이견까지 차단 | 유형 판별 후 비정형 과업의 과업 갈등은 논의에 활용하고 관계 갈등만 해소 |
| 갈등의 공개 토론 규범만으로는 건설적 해결 능력의 향상 없음 | 토론 규범과 함께 대응 방식의 선택 기준 공유 |
| 정형 과업의 과업 갈등이 집단 기능에 해로움 | 이견의 조기 정리와 합의 (협력·타협) |

## Ⅵ. 제언

갈등 발생 시 유형과 과업 성격을 먼저 판별해 이견의 활용 여부를 정하고, 그에 맞는 대응 방식을 선택

### 판별에 따른 대응 결정

```text
갈등 발생
    ↓
유형 판별
    ├─ 관계 갈등 → 과업 논의와 분리해 조기 해소
    └─ 과업 갈등 → 과업 성격 판별
            ├─ 비정형 과업 → 이견을 논의에 활용 (협력)
            └─ 정형 과업 → 조기 정리 (협력·타협)
```

### 공개 토론 운영 확대

```text
갈등의 공개 토론
    ├─ 논의 대상: 과업 내용의 근거(요구사항·설계 대안)
    └─ 분리 처리: 인적 비난 → 관계 갈등으로 별도 해소
```

| 구분 | 갈등 억제 일변도 | 제언: 유형·과업 성격 판별 후 대응 |
|---|---|---|
| 판단 기준 | 갈등의 존재 | 갈등 유형과 과업 성격 |
| 과업 갈등 | 일괄 억제 | 비정형은 활용, 정형은 조기 정리 |
| 관계 갈등 | 과업 갈등과 혼재 | 과업 논의와 분리한 해소 |
