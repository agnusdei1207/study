## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 관리·이해관계자 → **갈등관리**

## 30초 인출

- 본질: 갈등관리는 프로젝트 이해관계자 사이의 목표·자원·방식 차이에서 생긴 쟁점을 진단하고 합의와 후속 조치로 해소하는 활동
- 메커니즘: 쟁점의 원인과 업무 영향을 진단하고, 자기주장성·협조성 두 축의 TKI 다섯 방식 중 상황에 맞는 방식으로 조정한 뒤 합의 이행 점검
- 통찰: 한계: 원인 구분 없이 회피·수용을 반복해 쟁점이 누적됨 → 방안: PM이 원인·업무 영향으로 쟁점을 먼저 분류하고 합의를 의사결정 기록으로 남겨 이행 점검

<details>
<summary>핵심 용어</summary>

- **갈등관리** : 이해관계자 사이의 쟁점을 진단·조정해 합의와 후속 조치로 해소하는 활동
- **TKI(Thomas-Kilmann Conflict Mode Instrument)** : 자기주장성과 협조성 두 축으로 경쟁·협력·타협·회피·수용 다섯 대응 방식을 구분하는 도구
- **자기주장성(Assertiveness)** : 자기 관심사를 충족하려는 정도
- **협조성(Cooperativeness)** : 상대방의 관심사를 충족하려는 정도
- **원칙협상** : 사람과 문제를 분리하고 입장보다 이해관계와 객관적 기준에 초점을 두는 협상 방식
- **의사결정 기록** : 결정 내용·근거·책임자·후속 조치를 남긴 문서

</details>

## 2~4교시 25점 답안

## Ⅰ. 갈등관리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **갈등관리** 는 프로젝트 이해관계자 사이의 목표·자원·방식 차이에서 생긴 쟁점을 진단하고 합의와 후속 조치로 해소하는 활동 |
| 목적 | 갈등으로 인한 의사결정 지연과 협업 저하의 방지 |

## Ⅱ. 제거가 아닌 조정 대상이라는 갈등관리의 특징

| 특징 | 의미 |
|---|---|
| 불가피성 | 목표·자원·역할이 다른 이해관계자 사이의 상시 발생 |
| 성과와의 양면 관계 | 해법을 두고 벌이는 과업 갈등은 대안 탐색 촉진, 감정 대립인 관계 갈등은 협업 저하 |
| 원인별 대응 | 과업·관계·프로세스 원인에 따라 달라지는 조정 방식 |
| 이행까지 포함 | 합의 이후 후속 조치의 이행 확인까지 관리 범위 |

## Ⅲ. 갈등관리 절차와 대응 방식 선택

### 갈등관리 절차

```text
당사자·쟁점 확인
    ↓
원인 분류와 업무 영향 진단
    ↓
대응 방식 선택과 조정
    ↓
합의 결과의 기록
    ↓
후속 조치 이행 점검
```

### 대응 방식 선택 확대: 쟁점 조건별 TKI 방식 분기

```text
진단된 쟁점
    ↓
안전·일정상 즉시 결정 필요성 판정
    ├─ 필요 → 경쟁: 권한자의 결정과 사후 설명
    └─ 불필요 → 쟁점 중요도·관계 지속성 판정
          ├─ 양측 모두 중요 → 협력
          ├─ 시간 제약과 부분 양보 가능 → 타협
          ├─ 상대 관심사가 더 중요 → 수용
          └─ 경미한 쟁점 → 회피
```

## Ⅳ. 갈등 유형과 TKI 대응 방식 비교

### 갈등 유형

| 유형 | 주요 원인 | 조정 초점 |
|---|---|---|
| 과업 갈등 | 기술 해법·우선순위·일정 판단의 차이 | 근거와 대안의 비교 |
| 관계 갈등 | 신뢰 부족·감정 대립 | 사람과 문제의 분리 |
| 프로세스 갈등 | 역할·승인 권한·업무 순서의 불명확 | 책임과 절차의 명시 |

### TKI 다섯 대응 방식

| 방식 | 자기주장성 | 협조성 | 결과 형태 |
|---|---|---|---|
| 경쟁 | 높음 | 낮음 | 한쪽 관심사 관철 |
| 협력 | 높음 | 높음 | 양측 관심사 동시 충족 |
| 타협 | 중간 | 중간 | 양측의 부분 양보 |
| 회피 | 낮음 | 낮음 | 쟁점 보류 |
| 수용 | 낮음 | 높음 | 상대 관심사 우선 충족 |

## Ⅴ. 갈등관리의 한계와 방안

| 한계 | 방안 |
|---|---|
| 회피·수용 반복에 따른 쟁점 누적 | 업무 영향이 큰 과업 갈등은 협력 방식으로 이해관계와 대안 탐색 |
| 긴급 쟁점의 합의 지연 | 안전·일정 임계 쟁점은 권한자의 경쟁 방식 결정과 사후 설명 |
| 사람과 문제의 동일시에 따른 관계 갈등 확대 | **원칙협상** 에 따른 관찰 사실·업무 영향·요구의 분리 |
| 결정 권한의 불명확에 따른 프로세스 갈등 | 책임·승인·상향 경로의 사전 명시 |
| 구두 합의 후 논쟁 재발 | **의사결정 기록** 에 결과·근거·책임자·후속 조치 기재 |

## Ⅵ. 제언

PM의 원인·업무 영향 기준 쟁점 분류와 방식 선택 근거·합의 결과의 의사결정 기록을 통한 이행 점검

### PM 주도 갈등 조정 구조

```text
PM 주도 갈등 조정
    │
    ├─ PM ── 쟁점 분류·방식 선택·상향 판단
    │
    ├─ 당사자 ── 이해관계·대안 제시와 합의 이행
    │
    └─ 상위 의사결정 기구 ── PM 권한을 넘는 쟁점의 결정
```

### PM 역할 확대: 합의 이후 이행 점검

```text
합의 결과의 의사결정 기록
    ↓
정기 회의의 후속 조치 이행 확인
    ├─ 이행 완료 → 기록 종결
    └─ 미이행·재발 → 원인 재분류 후 방식 재선택 또는 상향
```

### 선택 근거: 사안별 즉흥 대응과의 비교

| 구분 | 사안별 즉흥 대응 | 제언: 분류 기반 조정 |
|---|---|---|
| 방식 선택 근거 | 당사자 성향·관행 | 원인·업무 영향·긴급성 |
| 합의 형태 | 구두 합의 | 의사결정 기록 |
| 권한 초과 쟁점 | 결정 지연 | 사전에 정한 상향 경로 |
| 재발 확인 | 재발 후 인지 | 정기 이행 점검 |
