## 지식 로드맵 내 현재 위치

```text
프로젝트·조직관리 → 이해관계자·팀 관리 → 갈등관리
```

## 토픽 큰 그림과 30초 인출
```text
[목표·역할·자원·일정·기술·소통의 차이]
                    ↓
        [사실 / 이해관계 / 감정 분리]
                    ↓
[경쟁·협력·타협·회피·수용] → [합의·책임·기한] → [추적]
```
- **30초 인출**: 갈등관리는 갈등을 없애는 활동이 아니라 원인과 상황을 진단하고 자기주장성과 협조성에 맞는 방식을 선택하여 과업 갈등은 학습으로, 관계 갈등은 피해 최소화로 전환하는 과정이다.

## 예상문제
> 프로젝트 갈등의 원인과 관리절차를 설명하고 Thomas-Kilmann의 다섯 가지 대응방식을 비교하시오.

## Ⅰ. 개요 ─ 갈등의 양면성
**갈등관리**는 목표·이해관계·인식 차이로 발생한 충돌을 식별하고 적절한 대응으로 해결·완화하는 과정이다. 건설적 과업 갈등은 대안을 넓히지만 관계 갈등과 방치된 갈등은 신뢰와 성과를 훼손한다.

## Ⅱ. 원인 ─ 프로젝트 경계의 충돌
| 원인 | 확인 질문 | 예방수단 |
|---|---|---|
| 목표·우선순위 | 성공기준이 같은가 | 공동 목표·의사결정 기준 |
| 역할·권한 | 누가 결정·수행하는가 | RACI·결정권 |
| 자원·일정 | 희소자원과 선후관계는 | 통합일정·우선순위 |
| 기술·품질 | 대안과 수용기준은 | ADR·품질기준 |
| 계약·조직 | 경계와 책임은 | 계약·인터페이스 합의 |
| 의사소통 | 사실·가정·감정이 섞였나 | 소통규칙·기록 |

## Ⅲ. 모형 ─ Thomas-Kilmann 대응방식
| 방식 | 자기주장 | 협조 | 적합한 상황 |
|---|---|---|---|
| 경쟁 | 높음 | 낮음 | 긴급·안전·명확한 원칙 |
| 협력 | 높음 | 높음 | 중요한 쟁점의 통합해법 |
| 타협 | 중간 | 중간 | 시간 제약·동등한 힘 |
| 회피 | 낮음 | 낮음 | 사소하거나 냉각이 필요 |
| 수용 | 낮음 | 높음 | 관계·학습이 쟁점보다 중요 |

한 방식이 항상 우수한 것이 아니라 중요도, 시간, 권력, 관계와 위험에 맞춰 선택한다.

## Ⅳ. 절차 ─ 진단에서 추적까지
```text
조기 감지 → 사실·이해관계·감정 분리 → 당사자·권한·영향 분석
         → 대응방식 선택 → 대안·합의 → 책임자·기한 → 후속점검
```
사람과 문제를 분리하고 입장보다 이해관계를 확인하며, 합의되지 않으면 사전에 정한 단계로 에스컬레이션한다.

## Ⅴ. 통제 ─ 예방 거버넌스
팀 헌장, RACI, 의사결정권, 완료·수용기준, 변경·이슈 절차를 명확히 한다. 심리적 안전과 반대의견 제시 통로를 보장하되 인신공격·보복·정보은폐에는 명확한 행동규범을 적용한다.

## Ⅵ. 검증 ─ 해결 여부의 확인
합의의 실행, 이슈 재발, 일정·품질 영향, 당사자 관계와 잔여위험을 점검한다. 회의록에는 사실·결정·책임·기한을 남기고 민감한 개인정보는 최소화한다.

## Ⅶ. 결론 ─ 상황적 선택과 학습
좋은 갈등관리는 무조건 합의하는 것이 아니라 적절한 방식을 투명하게 선택하고 실행을 추적하는 것이다. 반복 갈등의 원인을 역할·프로세스·거버넌스 개선으로 환류한다.

## 1교시 10점 답안 발췌
```text
원인: 목표·역할·자원·일정·기술·계약·소통의 차이
모형: 경쟁 / 협력 / 타협 / 회피 / 수용
절차: 감지 → 분리·진단 → 방식 선택 → 합의 → 책임·기한 → 추적
예방: 팀 헌장, RACI, 결정권, 수용기준, 에스컬레이션
```
