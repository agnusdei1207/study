## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 프로젝트 관리·이해관계자 → **갈등관리**

## 30초 인출

- 본질: **갈등관리** 는 이해관계자 사이의 목표·관점·업무 방식 차이를 파악·조정하는 활동.
- 메커니즘: 쟁점·관계 진단과 자기주장성·협조성에 맞는 **TKI** 대응 방식 선택, 합의·후속 조치로의 연결.
- 통찰: 한계: 갈등 원인·중요도를 구분하지 않은 일률적 대응 → 방안: 대응 방식 선택 전에 당사자 쟁점·긴급성을 확인

<details>
<summary>핵심 용어</summary>

- **갈등관리** : 이해관계자 사이의 쟁점을 진단·조정해 합의와 후속 행동으로 잇는 활동
- **TKI** (Thomas–Kilmann Conflict Mode Instrument): 자기주장성과 협조성 차원으로 경쟁·협력·타협·회피·수용 방식을 설명하는 도구
- **자기주장성(Assertiveness)** : 자기 관심사를 충족하려는 정도
- **협조성(Cooperativeness)** : 상대방의 관심사를 충족하려는 정도
- **원칙협상** : 사람과 문제를 분리하고 입장보다 이해관계와 객관 기준에 초점을 두는 협상 접근
- **의사결정 기록** : 결정 내용·근거·책임자·후속 조치를 기록한 문서

</details>

## 2~4교시 25점 답안

## Ⅰ. 갈등관리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **갈등관리** 는 이해관계자 사이의 목표·관점·업무 방식 차이를 파악·조정하는 활동 |
| 목적 | 의사결정·협업·업무 수행에 미치는 갈등의 부정적 영향 감소와 해결 가능한 쟁점으로의 전환 |

## Ⅱ. 갈등관리의 특징

| 구분 | 관리 초점 |
|---|---|
| 과업 갈등 | 해법·우선순위의 근거와 대안 |
| 관계 갈등 | 신뢰·감정의 긴장과 경청 |
| 프로세스 갈등 | 역할·승인·업무 순서의 경계 |

원인에 따라 조정 방식이 달라지며, 모든 갈등을 동일한 대화 절차나 단일 TKI 방식으로 처리하지 않는 접근.

## Ⅲ. 원칙 기반 중재와 방식 선택 절차

```text
당사자·쟁점 확인
    ↓
이해관계·공통 목표 파악
    ↓
대안·객관 기준 검토
    ↓
합의·결정 → 책임자·기한 확인
```

```text
쟁점의 중요도·긴급성·관계 영향 확인
             ↓
자기주장성·협조성 수준에 맞는 TKI 방식 선택
             ↓
대화·결정 후 합의 이행과 재발 여부 점검
```

## Ⅳ. TKI의 다섯 대응 방식 비교

| 자기주장성＼협조성 | 낮음 | 높음 |
|---|---|---|
| 낮음 | 회피 | 수용 |
| 높음 | 경쟁 | 협력 |

타협은 두 축의 중간 수준에서 서로 양보하는 방식.

| 방식 | 경향 | 고려 상황 |
|---|---|---|
| 경쟁 | 자기주장 높음·협조 낮음 | 긴급 상황 또는 안전·규정상 신속한 결정 필요 |
| 협력 | 자기주장 높음·협조 높음 | 중요한 이해관계의 동시 충족을 위한 대안 탐색 |
| 타협 | 두 차원 중간 | 제한된 시간과 상호 양보 가능성 |
| 회피 | 두 차원 낮음 | 경미한 쟁점 또는 일시적 냉각 시간 필요 |
| 수용 | 자기주장 낮음·협조 높음 | 상대 관심사의 우선성 또는 관계 회복의 중요성 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 사람과 문제의 동일시에 따른 비난 확대 | 관찰 사실·업무 영향·요구를 분리해 대화 |
| 입장 고수에 따른 대안 탐색 중단 | 입장 아래 이해관계·객관 기준 확인 |
| 불분명한 결정 권한에 따른 합의 지연 | 책임·승인·상향 경로 명확화 |
| 구두 합의에 따른 논쟁 재발 | **의사결정 기록** 에 결과·근거·책임자·후속 조치 기록 |

## Ⅵ. 제언

업무 영향이 큰 쟁점부터 중요도·긴급성·관계 지속 필요성을 확인해 대응 방식을 고르고 다음 점검에서 합의 이행 확인.
