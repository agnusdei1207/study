## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 위험관리 → **정량적 위험분석**

## 30초 인출

- 본질: 정량적 위험분석은 여러 위험과 추정 불확실성이 합쳐져 프로젝트 전체 비용·일정 목표에 주는 영향을 확률분포로 계산하는 위험 분석 활동
- 메커니즘: 작업별 비용·기간과 주요 위험을 확률분포로 입력하고 몬테카를로 시뮬레이션으로 결과분포를 얻어 목표 신뢰수준의 비용·일정과 예비비 산정
- 통찰: 낙관적 입력은 결과분포를 좁혀 예비비를 과소 산정하므로 입력 가정의 근거 기록과 단계별 재분석

<details>
<summary>핵심 용어</summary>

- **정량적 위험분석(Quantitative Risk Analysis)** : 개별 위험과 불확실성이 프로젝트 전체 목표에 미치는 영향을 수치로 분석하는 위험관리 프로세스
- **정성적 위험분석(Qualitative Risk Analysis)** : 발생 가능성과 영향을 등급으로 평가해 위험의 우선순위를 정하는 분석
- **3점 추정(Three-Point Estimate)** : 낙관·최빈·비관 값으로 한 작업의 비용·기간 범위를 표현하는 추정 방식
- **몬테카를로 시뮬레이션(Monte Carlo Simulation)** : 입력 확률분포에서 값을 반복 추출해 총비용·총기간의 결과분포를 구하는 기법
- **S-Curve(누적확률곡선)** : 총비용이나 완료일이 특정 값 이하일 누적확률을 나타낸 곡선
- **민감도 분석(Sensitivity Analysis)** : 입력 변수별로 결과에 주는 영향의 크기를 비교하는 분석. 토네이도 차트로 표시
- **EMV(Expected Monetary Value, 기대화폐가치)** : 결과별 발생 확률과 금액을 곱해 합한 기대 금액
- **의사결정나무(Decision Tree)** : 선택 대안과 불확실한 결과를 가지로 나눠 대안별 EMV를 비교하는 분석 도구
- **비상예비비(Contingency Reserve)** : 식별된 위험에 대비해 기준 추정치에 더해 두는 비용·일정 여유
- **신뢰수준(Confidence Level)** : 결과분포에서 목표 비용·일정을 넘지 않을 누적확률

</details>

## 2~4교시 25점 답안

## Ⅰ. 정량적 위험분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정량적 위험분석(Quantitative Risk Analysis)** 은 개별 위험과 불확실성이 프로젝트 전체 비용·일정 목표에 미치는 영향을 수치로 분석하는 위험관리 프로세스 |
| 목적 | 목표 달성 확률의 추정과 예비비·대응 우선순위의 근거 확보 |

## Ⅱ. 정성적 분석과 구별되는 정량적 위험분석의 특징

| 특징 | 의미 |
|---|---|
| 전체 위험 노출 산출 | 개별 위험의 등급이 아닌 여러 위험이 합쳐진 총비용·총기간의 영향 |
| 확률분포 기반 | 단일 예상값 대신 결과의 범위와 달성 확률 제시 |
| 입력 가정 의존 | 추정 범위·분포·상관관계에 따라 결과와 예비비가 달라짐 |
| 선택적 수행 | 규모가 크거나 목표 편차의 영향이 큰 사업에 한정 적용 |

## Ⅲ. 정량적 위험분석 절차와 시뮬레이션 흐름

### 정량적 위험분석 절차

```text
정성적 분석으로 선별한 주요 위험
    ↓
비용·일정 모델에 불확실성 입력
    (3점 추정·확률분포·상관관계)
    ↓
분석 기법 적용
    (시뮬레이션·민감도 분석·의사결정나무)
    ↓
결과분포와 목표 달성 확률 산출
    ↓
예비비·위험 대응 계획 반영
```

### 분석 기법 확대: 몬테카를로 시뮬레이션의 예비비 산정 흐름

```text
작업별 비용·기간의 확률분포
    ↓
분포에서 값 추출 후 총비용·총기간 계산
    ↓
수천 회 반복
    ↓
S-Curve(누적확률곡선) 작성
    ↓
목표 신뢰수준 값 − 기준 추정치 = 예비비
```

## Ⅳ. 정성·정량 분석의 관계와 정량 기법 비교

### 정성적 분석과 정량적 분석의 관계

| 구분 | **정성적 위험분석** | 정량적 위험분석 |
|---|---|---|
| 분석 대상 | 식별된 개별 위험 전체 | 정성 분석에서 선별한 주요 위험 |
| 평가 방식 | 발생 가능성·영향 등급 | 확률분포와 수치 모델 |
| 산출물 | 위험 우선순위 목록 | 목표 달성 확률·예비비 |
| 수행 범위 | 모든 프로젝트 | 규모·영향이 큰 프로젝트 |

### 목적별 정량 기법 비교

| 기법 | 산출 | 적합한 판단 |
|---|---|---|
| **민감도 분석** | 변수별 결과 영향 순위(토네이도 차트) | 집중 관리할 위험 선정 |
| **EMV** · **의사결정나무** | 대안별 기대 금액 `EMV = Σ(확률 × 영향 금액)` | 자체 개발·외부 구매 같은 대안 선택 |
| **몬테카를로 시뮬레이션** | 총비용·총기간의 결과분포 | 목표 달성 확률과 예비비 산정 |

## Ⅴ. 정량적 위험분석의 한계와 방안

| 한계 | 방안 |
|---|---|
| 낙관적 단일 추정치 입력으로 결과분포가 좁아져 예비비 과소 산정 | 유사 사업 실적에 근거한 **3점 추정** 과 분포 선택 근거 기록 |
| 공통 원인을 가진 위험 간 상관관계 누락으로 극단 결과 과소평가 | 공통 원인 위험의 상관관계를 시뮬레이션 모델에 반영 |
| 분석 목적과 맞지 않는 기법 선택 | 대안 선택은 의사결정나무, 예비비 산정은 몬테카를로 시뮬레이션, 관리 대상 선정은 민감도 분석 |
| 착수 시점 1회 분석 후 갱신 부재 | 마일스톤마다 실적을 반영한 재분석과 예비비 조정 |

## Ⅵ. 제언

비상예비비를 조직이 승인한 목표 **신뢰수준** 에서 산정하고, 입력 가정과 상관관계를 기록해 마일스톤마다 재계산

### 예비비 결정 구조

```text
예비비 결정
    │
    ├─ 경영진 ── 목표 신뢰수준 승인
    │
    ├─ PM·위험 분석 담당 ── 입력 가정·상관관계 기록
    │
    └─ 시뮬레이션 결과 ── 신뢰수준별 비용·일정 값
```

### PM·위험 분석 담당 역할 확대: 마일스톤별 재분석 절차

```text
마일스톤 도달
    ↓
실적으로 남은 작업의 분포·상관관계 갱신
    ↓
시뮬레이션 재실행
    ↓
목표 신뢰수준 비용과 잔여 예비비 비교
    ├─ 부족 → 위험 대응 추가 또는 예비비 증액 요청
    └─ 충분 → 잔여 예비비 유지와 감시 지속
```

### 선택 근거: 단일 추정 기반 예비비와의 비교

| 구분 | 단일 추정 기반 예비비 | 제언: 신뢰수준 기반 예비비 |
|---|---|---|
| 산정 근거 | 기준 추정치의 일정 비율 가산 | 목표 신뢰수준 값과 기준 추정치의 차이 |
| 입력 근거 | 담당자 단일 추정 | 실적 기반 3점 추정과 상관관계 기록 |
| 갱신 시점 | 착수 시 1회 | 마일스톤 도달 시점 |
| 승인 대상 | 예비비 금액 | 목표 신뢰수준과 입력 가정 |
