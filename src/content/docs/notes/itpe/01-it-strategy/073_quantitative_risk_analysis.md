## 큰 그림과 30초 인출

```text
[정성적 분석(P-I Matrix)으로 선별된 상위 핵심 리스크]
          │
          ▼
┌────────────────── [정량적 위험분석 4대 기법] ──────────────────┐
│  1. 민감도 분석   : 토네이도 다이어그램, 핵심 영향 요인 도출   │
│  2. 기대화폐가치 : EMV = 확률(P) × 영향(I), 손익 기댓값 계산   │
│  3. 의사결정나무 : 조건부 확률 기반 분기별 최적 대안 선택      │
│  4. 몬테카를로   : 난수 기반 수천 번 시뮬레이션, 완료 확률 도출 │
└────────────────────────────────────────────────────────────────┘
          │
          ▼
[프로젝트 전체 리스크 노출도 산출 → 비상예비비(Contingency) 확정]
```

- 본질: 정성적 위험분석을 통해 선별된 핵심 위험들이 프로젝트 전체 일정과 원가 목표에 미치는 복합적 영향을 통계적·수학적 기법(확률분포, 시뮬레이션, EMV)을 활용하여 구체적인 금액과 일정 지연 일수로 계량화하는 분석 활동
- 위치: `위험 식별 → 정성적 위험분석(우선순위화) → 정량적 위험분석(수치화) → 위험 대응 계획 수립(예비비 반영)`
- 핵심: 제123회 KPC 기출, 4대 기법(민감도·EMV·의사결정나무·몬테카를로), 비상예비비(Contingency Reserve) 산정 근거
- 실무: 고위험 항목 선별 적용, 3점 추정(삼각/베타 분포) 입력 편향 최소화, 동적 예비비 관리

## 예상문제

> 프로젝트 위험관리에서 정량적 위험분석(Quantitative Risk Analysis)의 개념, 필요성, 정성적 위험분석과의 비교, 4대 핵심 분석 기법(민감도 분석, EMV, 의사결정나무, 몬테카를로 시뮬레이션)의 원리와 비상예비비 산정 방안을 설명하시오. (25점)

## 딸려 나오는 하위 토픽

| 하위 토픽 | 핵심 내용 | 본문 답안 위치 |
|---|---|---|
| **정량적 위험분석 기법** | 민감도 분석(토네이도), 기대화폐가치(EMV), 의사결정나무, 몬테카를로 시뮬레이션 4대 핵심 기법 | Ⅲ 구조, Ⅳ 절차 |
| **비상예비비(Contingency Reserve) 산정** | 몬테카를로 시뮬레이션의 신뢰수준(P80 등) 및 EMV 합산을 통한 수학적 예비비 책정 | Ⅳ 절차, Ⅵ 실무 대책 |

## Ⅰ. 불확실성의 수치적 계량화, 정량적 위험분석의 개요

- 정의: 정성적 분석을 통해 우선순위화된 개별 위험들과 프로젝트 전반의 불확실성이 전체 비용과 일정 목표에 미치는 영향을 통계적 확률과 화폐 가치로 정밀하게 계량화하는 활동
- 등장 배경: 정성적 평가(상·중·하)의 주관성과 모호성으로 인한 경영진 설득 한계, 복합 위험 요인의 상관관계 분석 필요성, 대규모 프로젝트의 합리적 비상예비비 산정 요구
- 핵심 목적: 프로젝트 성공 확률(예: 특정 예산 내 완공 확률)의 통계적 도출, 가장 치명적인 위험 동인의 식별, 근거 기반의 비상예비비 및 완충 일정(Buffer) 확보

#### 한줄 요약
- 위험의 발생 확률과 재무적 영향을 통계적으로 분석하여 수치와 화폐 가치로 계량화하는 기법임

## Ⅱ. 정성적 위험분석 vs 정량적 위험분석 비교

| 비교 항목 | 정성적 위험분석 (Qualitative) | 정량적 위험분석 (Quantitative) |
|---|---|---|
| **주요 목적** | 위험의 빠른 우선순위화 및 분류 | 위험의 복합 영향 수치화 및 예비비 산정 |
| **분석 척도** | 상대적 서열 척도 (상/중/하, 1~5점) | 절대적 비율 척도 (확률 %, 금액, 지연 일수) |
| **주요 기법** | 확률-영향 매트릭스(P-I Matrix), 리스크 분류 | 몬테카를로 시뮬레이션, EMV, 토네이도 차트 |
| **소요 비용/기간** | 낮음 (신속한 브레인스토밍/전문가 인터뷰) | 높음 (통계적 데이터 수집 및 시뮬레이션 도구) |
| **수행 대상** | 식별된 모든 위험 항목 | 정성 분석에서 선별된 고위험 핵심 항목 |
| **주요 산출물** | 리스크 우선순위 목록, 감시 목록(Watchlist) | 프로젝트 완료 확률 곡선, 비상예비비 산출액 |

#### 한줄 요약
- 정성 분석은 신속한 우선순위 도출, 정량 분석은 정밀한 금액과 일정 수치화에 특화됨

## Ⅲ. 정량적 위험분석 4대 핵심 기법 및 메커니즘

```text
┌───────────────── [1. 민감도 분석 (토네이도 차트)] ─────────────────┐
│  - 어떤 요인이 프로젝트 결과에 가장 큰 잠재적 영향을 주는지 분석     │
│  - 영향력이 큰 변수를 상단에 수평 막대로 시각화 (깔때기 모양)       │
└──────────────────────────────────┬──────────────────────────────────┘
                                   │
┌───────────────── [2. 기대화폐가치 분석 (EMV)] ────────────────────┐
│  - 공식: EMV = 발생 확률(P) × 영향 금액(I)                          │
│  - 위협(-)과 기회(+)를 모두 합산하여 순 기대 화폐 가치 산출        │
└──────────────────────────────────┬──────────────────────────────────┘
                                   │
┌───────────────── [3. 의사결정나무 분석 (Decision Tree)] ───────────┐
│  - 결정 노드(□)와 기회 노드(○)를 분기별 전개                        │
│  - 자체 개발 vs 외주 구매 등 상호 배타적 대안의 기댓값 비교 판정     │
└──────────────────────────────────┬──────────────────────────────────┘
                                   │
┌───────────────── [4. 몬테카를로 시뮬레이션 (Monte Carlo)] ─────────┐
│  - 각 원가/일정 요소에 확률분포(삼각/베타 분포) 부여                │
│  - 수천 번 난수 반복 연산을 통해 누적 확률 S-커브 도출              │
└────────────────────────────────────────────────────────────────────┘
```

| 분석 기법 | 핵심 메커니즘 | 실무 적용 시점 및 효과 |
|---|---|---|
| **민감도 분석 (토네이도)** | 다른 요인을 고정하고 개별 변수의 변동 폭에 따른 결과 영향도 산정 | 프로젝트 성공을 좌우하는 핵심 리스크 변수 우선순위 식별 |
| **기대화폐가치 (EMV)** | `EMV = \sum (P_i \times I_i)` 산식으로 미래 손익의 통계적 평균 계산 | 리스크 대응 전략 수립 및 정량적 비상예비비 기본 산정 |
| **의사결정나무 분석** | 의사결정 경로별 확률과 보상을 트리 형태로 구조화하여 최선의 경로 선택 | 신규 프레임워크 자체 개발 vs 패키지 도입 등 전략적 대안 평가 |
| **몬테카를로 시뮬레이션** | 난수 발생을 통해 복합 불확실성의 결합 확률분포(S-Curve) 모델링 | "신뢰수준 80%에서 프로젝트 완료에 필요한 예산 및 일정" 제시 |

#### 한줄 요약
- 토네이도로 핵심 변수를 찾고, EMV와 의사결정나무로 대안을 평가하며, 몬테카를로로 예비비를 확정함

## Ⅳ. 정량적 위험분석 수행 4단계 절차

```text
① 위험 선별 및 데이터 수집 → ② 확률분포 모델링 → ③ 정량 시뮬레이션 실행 → ④ 프로젝트 예비비 및 일정 확정
   └─ 고위험 항목 도출            └─ 3점 추정(낙관/최빈/비관)     └─ 몬테카를로 연산             └─ 신뢰수준(P80/P90) 결정
```

| 단계 | 주요 수행 내용 | 핵심 산출물 및 기준 |
|---|---|---|
| **1. 위험 선별·수집** | 정성 분석 상위 위험 선별, 과거 실적 데이터 및 전문가 인터뷰 수행 | 정량 분석 대상 목록, 원천 데이터 |
| **2. 확률분포 모델링**| 각 작업의 원가/일정에 대해 낙관치, 최빈치, 비관치 3점 추정 및 분포 부여 | 삼각분포(Triangular), 베타분포(Beta) 모델 |
| **3. 시뮬레이션 실행**| 컴퓨터 소프트웨어를 활용하여 수천 회 난수 추출 및 반복 계산 수행 | 누적 확률 분포 곡선(S-Curve), 민감도 차트 |
| **4. 결과 도출·확정** | 목표 달성 확률 분석, 비상예비비(Contingency) 및 완충 일정 산출 | 정량적 위험분석 보고서, 수정된 베이스라인 |

#### 한줄 요약
- 고위험 선별, 확률분포 모델링, 시뮬레이션, 예비비 확정의 4단계로 수행됨

## Ⅴ. 몬테카를로 시뮬레이션 기반 비상예비비 산출 구조

```text
[누적 확률 분포 S-Curve]
 확률(%)
  100% ┼───────────────────────────────╭───────
       │                               ╭╯
   80% ┼───────────────────────────╭───╯ <── [P80 예산 결정 기준선]
       │                       ╭───╯
   50% ┼───────────────────╭───╯ <── [단순 최빈값/기준선 예산]
       │               ╭───╯
    0% ┼───────╭───────╯
       └───────┴───────────────────────┴────────
              300억                   330억 (원)
                 └── [비상예비비 30억] ──┘
```

| 구분 | 산출 기준 | 공학적 의미 및 역할 |
|---|---|---|
| **단순 추정치 (P50)** | 각 요소의 최빈값 합계 (확률 50%) | 프로젝트 성공 확률이 50%에 불과하여 예산 초과 위험 매우 높음 |
| **목표 신뢰수준 (P80/P90)**| 누적 확률 곡선 상 80% 또는 90% 지점 | 스폰서의 위험 수용도(Risk Appetite)를 반영한 안전선 |
| **비상예비비 (Contingency)** | `P80 예산 - P50 예산` 차액 | 식별된 기지-미지의 위험(Known-Unknowns)에 대비하는 예산 |

#### 한줄 요약
- 단순 합산(P50)의 위험을 극복하고 P80 신뢰수준과의 차액을 비상예비비로 책정함

## Ⅵ. 실무 적용 시 장애 요인 및 통제 대책

- 적용 상황: 대규모 금융 차세대 코어뱅킹 시스템 재구축 사업의 위험 분석 및 예산 책정

| 문제점 | 발생 원인 | 공학적·제도적 해결 대책 | 기대 효과 |
|---|---|---|---|
| **입력 데이터의 주관적 편향** | 과거 유사 실적 데이터 부재로 전문가의 낙관적 추정치 주입 | 델파이 기법 결합 및 조직 프로세스 자산(OPA) 기반 정규화 | 입력 변수의 신뢰성 및 모델 객관성 확보 |
| **모든 위험에 무차별 적용으로 피로 가중**| 정성적 스크리닝 없이 전체 위험에 정량 분석 시도 | P-I 매트릭스 고위험군(상위 일부)만 정량 분석 대상으로 한정 | 분석 비용 절감 및 핵심 위험 집중 통제 |
| **기회 요인 배제로 예비비 과다 계상** | 위협(-) 요인만 반영하고 잠재적 기회(+) 요인 무시 | EMV 산식에 위협과 기회를 상계 반영하여 순 기대화폐가치 산출 | 사업 타당성 왜곡 방지 및 합리적 예산 편성 |
| **일회성 분석 후 정적 방치** | 착수 시점에 1회 시뮬레이션 후 진척에 따른 재계산 미실시 | 공정 마일스톤 도달 시마다 잔여 리스크 재시뮬레이션(동적 예비비) | 프로젝트 진행에 따른 현실적 위험 가시화 |

#### 한줄 요약
- 전문가 델파이, 고위험 선별 집중, 기회 상계, 동적 예비비 갱신으로 실효성을 높임

## Ⅶ. 동적 예비비 관리와 파이프라인 연계 중심의 결론

- **[일회성 정적 보고서를 탈피한 지속적 정량 위험 대시보드화]**: 정량적 위험분석은 착수 보고용 문서로 끝나지 않고, 프로젝트 진행에 따라 소멸되는 위험과 새로 유입되는 불확실성을 상시 반영해야 함
- 나라면: 형상관리 및 지라(Jira) 백로그와 연동하여 `스프린트 지연 일수 및 공정 결함 데이터를 파이썬 시뮬레이션 모듈로 자동 피딩 → 매주 프로젝트 완료 확률 곡선과 잔여 비상예비비를 실시간 재계산`하는 '동적 정량 위험 거버넌스'를 구축

#### 한줄 요약
- 정량 분석을 프로젝트 관리 도구와 연계하여 동적으로 예비비를 통제함

## 1교시 10점 답안 발췌

### 1. 정량적 위험분석의 정의
- 정성적 위험분석을 통해 선별된 주요 위험들이 프로젝트의 전체 일정과 비용 목표에 미치는 영향을 통계적 확률과 화폐 가치로 수량화하여 합리적 예비비를 도출하는 활동

### 2. 정량적 위험분석 4대 기법
```text
[민감도 분석]   ──> 토네이도 다이어그램 활용, 핵심 영향 요인 식별
[기대화폐가치] ──> EMV = 확률(P) × 영향(I), 위협(-)과 기회(+) 상계
[의사결정나무] ──> 분기별 조건부 확률과 기댓값 계산, 최적 대안 선정
[몬테카를로]   ──> 난수 기반 반복 시뮬레이션, P80 완료 확률 및 예비비 산출
```

### 3. 차별화 제언
- 모든 위험이 아닌 정성 분석 상위 위험에 집중 적용해야 하며, 단순 최빈값(P50) 대신 신뢰수준(P80) 기준의 비상예비비(Contingency)를 도출하여 동적으로 관리해야 함
