## Ⅰ. 정량적 위험분석의 개요

- 개념 : 프로젝트 목표(일정, 원가)에 미치는 개별 식별 위험들의 결합된 영향과 기타 불확실성 원천을 **수학적·통계적 기법** 을 통해 수치(금액, 일수, 확률)로 환산하여 객관적으로 평가하는 **프로젝트 관리 기법**
- 배경 및 필요성 : **정성적 분석** (PI 매트릭스)의 주관적 평가 한계를 극복하고, 경영진 의사결정 및 우발사태 예비비(Contingency Reserve) 산출을 위한 과학적 데이터 근거 마련 필요.
- 주요 목적 : 프로젝트 전체 목표 달성 확률 정량화, 현실적인 완료 일정 및 예산 예비비 산출, 위험 간 상관관계 분석을 통한 우선순위화.

## Ⅱ. 핵심 정량적 위험분석 기법 비교

```text
[정량적 위험분석 4대 기법]
  1. 민감도 분석 (Sensitivity Analysis) ── 토네이도 다이어그램으로 가장 영향력 큰 변수 식별
  2. 기댓값 분석 (EMV, Expected Monetary Value) ── 의사결정나무(Decision Tree)와 결합한 기댓값 산출
  3. 몬테카를로 시뮬레이션 (Monte Carlo) ── 난수 생성을 통해 수천 번 반복 시뮬레이션 확률분포 도출
  4. 영향 다이어그램 (Influence Diagram) ── 변수 간의 인과관계와 시간적 순서의 시각적 모델링
```

- **기댓값 분석** (EMV) : 의사결정나무(Decision Tree)와 결합한 기댓값 산출.
- **영향 다이어그램** (Influence Diagram) : 변수 간 인과관계와 시간적 순서의 시각적 모델링.

| 분석 기법 | 핵심 개념 및 산출물 | 적용 상황 및 장단점 |
|---|---|---|
| **민감도 분석** (토네이도 다이어그램) | 다른 변수를 고정하고 한 변수의 변화가 결과에 미치는 영향 폭 측정 | 어떤 위험이 프로젝트에 가장 치명적인지 직관적 우선순위 파악 용이 |
| **기대 화폐 가치** (EMV) | 사건 발생 확률(P) x 사건 발생 시 손실/이익 금액(I) | 의사결정나무와 결합하여 대안 간 경제성 비교 평가에 최적 |
| **몬테카를로 시뮬레이션** | 입력 변수의 확률분포(삼각분포 등) 기반 수천 회 가상 시행 | 프로젝트 완료 일정 및 예산의 신뢰구간(P50, P80)을 도출하는 최고급 기법 |

## Ⅲ. 몬테카를로 시뮬레이션 기반 일정·원가 예측 메커니즘

- **누적 확률분포 곡선(S-Curve) 도출** :
  - **P50** (50% 확률) : 낙관적인 목표 완료 일정/예산 (50% 확률로 달성).
  - **P80** (80% 확률) : 일반적인 계약 및 약속 기준 일정/예산 (80% 신뢰수준).
  - 예비비 산정 : P80 값과 기본 계획 값과의 차이를 우발사태 예비비(Contingency Reserve)로 공식 편성.

## Ⅳ. 정량적 위험 분석 수행 시 주요 한계점 및 해결 방안

- 신뢰할 수 있는 과거 데이터(Historical Data)의 부재 :
  - 한계점 : 신기술 도입 사업이나 최초 프로젝트의 경우 확률 분포를 추정할 수 있는 축적된 이력 데이터 전무.
  - 해결 방안 : 전문가 집단의 3점 추정(PERT) 및 델파이 기법 결합, 유사 도메인 공공 통계 데이터의 벤치마킹 적용.
- 시뮬레이션 모델링의 복잡성 및 높은 해석 비용 :
  - 한계점 : 몬테카를로 시뮬레이션 등 고급 통계 기법 활용 시 전문 소프트웨어 구매 및 고숙련 데이터 분석 인력 필요.
  - 해결 방안 : 클라우드 기반 자동 시뮬레이션 툴킷 보급, 주요 위험 변수 2~3개에 집중하는 민감도 분석(Tornado Diagram) 우선 활용.
- 분석 결과의 과도한 신뢰 및 맹신 위험 :
  - 한계점 : 수치화된 확률 결과(예: 높게 산출된 납기 준수 확률)만 믿고 정량화되지 않은 '블랙 스완' 위험을 무시하는 인지 편향.
  - 해결 방안 : 정량 분석 결과와 전문가 정성 평가의 상호 교차 검증, 최악 시나리오(Stress Test) 기반 컨틴전시 플랜 병행.

## Ⅴ. 실무 정량적 위험분석 적용을 위한 기술사적 제언

- 정성적 분석을 거친 고위험 항목 선별 적용 : 모든 사소한 위험에 정량 분석을 수행하는 것은 비용 낭비이므로, 정성적 분석에서 높은 등급으로 선별된 핵심 위험에 한해 정량 분석 수행.
- 과거 유사 프로젝트의 실측 데이터 기반 분포 설정 : 몬테카를로 시뮬레이션 입력값(최빈값, 낙관치, 비관치) 설정 시 직관적 추정을 배제하고 역사적 실측 데이터(Historical Data) 활용.
- 경영진 보고 시 신뢰구간(Confidence Interval) 기반 소통 : 단일 확정 날짜나 금액(Point Estimate) 보고 관행을 탈피하고, "높은 신뢰수준에서 특정 시점 완공, 필요 예비비 규모는 이 수준"와 같이 확률 기반 의사결정 유도.
