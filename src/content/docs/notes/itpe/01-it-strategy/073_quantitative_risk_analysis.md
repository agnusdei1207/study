## 연관 키워드

- 정량적 위험분석 (Quantitative Risk Analysis), 정성적 분석 (Qualitative Risk Analysis), PI 매트릭스
- 민감도 분석 (Sensitivity Analysis), 토네이도 다이어그램 (Tornado Diagram), 영향 다이어그램 (Influence Diagram)
- EMV (Expected Monetary Value, 기대 화폐 가치), 의사결정나무 (Decision Tree)
- 몬테카를로 시뮬레이션 (Monte Carlo Simulation), S-Curve, P50, P80
- 우발사태 예비비 (Contingency Reserve)
- PERT (Program Evaluation and Review Technique, 3점 추정), 델파이 기법 (Delphi Technique), 과거 데이터 (Historical Data)

## Ⅰ. 정량적 위험분석의 개요

- 핵심 요약 : 개별 위험의 결합 영향과 불확실성을 금액, 일수, 확률로 수치화해 객관적으로 평가하는 프로젝트 관리 기법.
- 개념 : 프로젝트 목표(일정, 원가)에 미치는 개별 위험의 결합 영향과 불확실성을 수학적·통계적 기법으로 수치화하는 **정량적 위험분석** (Quantitative Risk Analysis).
- 배경 및 필요성 : 정성적 분석(PI 매트릭스)은 평가자 주관에 기대므로, 경영진의 의사결정과 **우발사태 예비비**(Contingency Reserve, 위험 발생에 대비해 따로 편성하는 비용과 일정 여유)를 정하기 위한 과학적 근거가 부족함.
- 주요 목적 : 프로젝트 목표 달성 확률의 정량화, 현실적인 완료 일정과 예산 산출, 위험 간 상관관계에 따른 우선순위 결정.

## Ⅱ. 정량적 위험분석의 특징 및 장점

- 핵심 요약 : 수치화, 확률분포, 시뮬레이션, 예비비 산출로 평가자 주관을 줄이는 객관적 위험 평가 기법.

1. **확률분포** : 단일 추정값 대신 불확실성의 범위를 입력 → 결과의 폭을 정직하게 표현.
2. **몬테카를로 시뮬레이션** (Monte Carlo Simulation, 난수로 입력 분포를 반복 추출해 결과 분포를 얻는 기법) : 여러 위험의 결합 결과를 반복 계산해 목표 달성 확률 추정.
3. **민감도 분석** (Sensitivity Analysis, 한 변수를 바꿨을 때 결과가 얼마나 변하는지 측정) : 결과를 가장 크게 흔드는 변수에 대응 자원을 집중.
4. **백분위수** (P50·P80, 50%와 80% 확률 수준의 값) : 약속 수준과 비용 여유를 확률로 설명.
5. 금액·일수·확률 수치화 : 위험 영향을 공통 단위로 비교 → 우선순위와 의사결정 근거 마련.

## Ⅲ. 정량적 위험분석의 구조 (흐름)

- 핵심 요약 : 민감도 분석, EMV, 몬테카를로 시뮬레이션, 영향 다이어그램의 4대 기법과 몬테카를로 예측 흐름.

```text
[ 정량적 위험분석 4대 기법 ]
1. 민감도 분석 : 영향 변수 식별
2. EMV : 의사결정나무와 기댓값 산출
3. 몬테카를로 시뮬레이션 : 확률분포 도출
4. 영향 다이어그램 : 변수 간 인과 시각화
```

```text
[ 몬테카를로 예측 흐름 ]
입력 변수의 확률분포 설정
          ↓
수천 회 난수 시행 (Simulation)
          ↓
S-Curve (누적 확률분포) 도출
          ↓
P50 (50% 확률) · P80 (80% 확률) 산출
          ↓
우발사태 예비비 편성
```

- **기댓값 분석** (EMV, Expected Monetary Value) : 발생 확률과 금액을 곱해 의사결정나무와 결합한 기댓값을 산출.
- **영향 다이어그램** (Influence Diagram) : 변수 간 인과관계와 시간 순서를 시각적으로 모델링.
- P50 : 50% 확률 수준의 낙관적 일정이나 예산 기준.
- P80 : 80% 확률 수준으로, 계약과 약속에 흔히 쓰는 기준.
- 우발사태 예비비 : P80 값과 기본 계획 값의 차이를 공식적으로 편성하는 예비비.

## Ⅳ. 정량적 위험분석 기법 비교

- 핵심 요약 : 정성 분석으로 고위험 항목을 고른 뒤, 민감도·EMV·몬테카를로의 3대 기법으로 정량화하는 단계적 적용.

```text
[ 정성적 분석 (PI 매트릭스) ]
          ↓ 고위험 항목 선별
[ 정량적 분석 (민감도·EMV·몬테카를로) ]
```

| 분석 기법 | 핵심 개념과 산출물 | 적용 상황과 장단점 |
| --- | --- | --- |
| 민감도 분석 (토네이도 다이어그램) | 다른 변수를 고정하고 한 변수의 변화가 결과에 주는 폭 측정 | 가장 치명적인 위험을 직관적으로 파악하기 쉬움 |
| 기댓값 분석 (EMV) | 사건 발생 확률과 금액을 곱한 기댓값 | 의사결정나무와 결합해 대안의 경제성 비교에 적합 |
| 몬테카를로 시뮬레이션 | 입력 변수의 확률분포 기반 수천 회 가상 시행 | 완료 일정과 예산의 백분위수를 도출하며 계산 부담이 큼 |

## Ⅴ. 정량적 위험분석의 한계와 방안

- 핵심 요약 : 입력 데이터 부족, 모델 복잡성, 수치에 대한 과신을 가정 공개와 시나리오 검증으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 과거 사례 부족으로 확률분포가 불안정 | 입력 분포의 근거가 약해 결과 신뢰도 저하 | **3점 추정** (PERT, Program Evaluation and Review Technique)과 유사 사업 자료를 결합하고 가정을 명시 | 가정 명시율 |
| 변수와 상관관계가 많아 모델 해석이 어려움 | 결과의 원인을 설명하기 어려워 활용이 줄어듦 | 주요 위험부터 분석하고 민감도 결과를 함께 제시 | 분석 대상 위험 수 |
| 결과 수치를 절대값으로 신뢰 | 모델에 없는 미식별 위험을 놓침 | 정성 평가, 스트레스 시나리오, 비상 계획을 병행 | 시나리오 검증 건수 |

## Ⅵ. 정량적 위험분석 적용에 대한 기술사적 제언

- 핵심 요약 : 정성 분석으로 핵심 위험을 고르고, 과거 데이터 기반 분포를 쓰며, P50·P80으로 소통해 예비비를 객관화.

1. 정성적 분석 후 고위험 항목 선별 : 모든 위험에 정량 분석을 적용하면 비용이 낭비되므로, PI 매트릭스에서 높은 등급을 받은 핵심 위험에만 정량 분석을 수행한다.
2. **과거 데이터** (Historical Data) 기반 분포 설정 : 몬테카를로 입력값인 최빈값, 낙관치, 비관치를 직관에만 기대지 않고 실측 자료로 정하며, 자료가 부족하면 **델파이 기법** (Delphi Technique)으로 전문가 판단을 모은다.
3. P50·P80 기반 보고 : 단일 확정 날짜나 금액 대신 "이 신뢰수준에서 이 시점에 완공되며, 필요한 예비비는 이 규모"라는 식으로 확률 기반 의사결정을 유도한다.

## Ⅶ. 결론

- 핵심 요약 : 정량적 위험분석은 확률과 시뮬레이션으로 일정과 원가 예비비를 객관화하는 고급 기법.
- 시사점 : 정성 분석과의 연계, 과거 데이터 기반 분포, 확률 기반 소통이 함께할 때 예비비 산출의 신뢰성이 높아짐.
