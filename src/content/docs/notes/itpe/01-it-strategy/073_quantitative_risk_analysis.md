## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 위험관리 → **정량적 위험분석**

## 30초 인출

- 본질: 정량적 위험분석은 위험의 영향과 발생 가능성을 금액·기간·확률 같은 수치로 산정해 대응책의 비용 대비 효과를 비교하게 하는 위험 분석 방식
- 메커니즘: 영향과 발생 빈도의 추정값을 ALE(영향 × 연간 발생 빈도)나 Monte Carlo 시뮬레이션(확률 분포에서 반복 추출)에 넣어 손실액과 완료일 분포를 산출하고 대책 선택에 사용
- 통찰: 추정값에 주관 판단과 편향이 섞이면 수치가 정밀해 보여도 엄밀성이 낮아지므로 입력의 근거와 범위를 기록해 편향을 통제하고 결과를 단일 값이 아닌 확률 분포로 제시

<details>
<summary>핵심 용어</summary>

- **정량적 위험분석(Quantitative Risk Analysis)** : 값의 의미와 비례성이 평가 밖에서도 유지되는 수치로 위험을 산정하는 분석 방식
- **준정량적 평가(Semi-Quantitative Assessment)** : 구간·척도·대표 수치를 쓰지만 값의 의미가 다른 맥락에서는 유지되지 않는 평가 방식
- **ALE(Annual Loss Exposure, 연간 손실 예상액)** : 영향의 추정 금액에 연간 발생 빈도의 추정치를 곱한 값
- **Monte Carlo 시뮬레이션** : 확률 분포에서 난수로 값을 반복 추출해 결과의 분포를 얻는 통계 시뮬레이션
- **일정 위험 분석(Schedule Risk Analysis)** : 활동 기간의 불확실성과 위험을 통계 시뮬레이션에 반영해 완료일의 확률 분포를 구하는 분석
- **삼점 추정(Three-Point Estimate)** : 활동 기간의 최소·가장 가능성 높은·최대 추정치
- **누적 확률 곡선(S curve)** : 완료일 이전에 끝날 확률을 날짜별로 누적해 나타낸 곡선

</details>

## 2~4교시 25점 답안

## Ⅰ. 정량적 위험분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정량적 위험분석** 은 위험을 값의 의미와 비례성이 유지되는 수치로 산정하는 분석 방식 |
| 목적 | 대응책 대안의 비용 대비 효과 판단 근거 확보 |

## Ⅱ. 수치에 의존하는 정량적 위험분석의 특징

| 특징 | 의미 |
|---|---|
| 수치 기반 | 수치의 의미와 비례성이 평가의 안과 밖에서 유지 |
| 비용 대비 효과 분석 지원 | 대응책이나 행동 대안의 비교에 가장 효과적 |
| 해석과 가정 설명 필요 | 결과의 의미가 불분명할 수 있어 가정과 사용 제약의 설명 필요 |
| 입력값 불확실성에 민감 | 주관 판단이 수치 속에 묻히거나 값의 불확실성이 크면 엄밀성 저하 |
| 비용 부담 | 전문가 시간과 도구 비용이 재현성의 이익을 넘는 경우 존재 |

## Ⅲ. 추정 입력에서 대책 선택까지의 분석 체계

### 정량적 위험분석 전체 흐름

```text
입력 추정: 영향(금액·기간) · 발생 빈도·확률
    ↓
계산 모델
    ├─ ALE: 영향 × 연간 발생 빈도
    └─ Monte Carlo 시뮬레이션: 확률 분포에서 반복 추출
    ↓
산출: 위협별 연간 손실 · 완료일의 확률 분포
    ↓
활용: 대책 선택 · 위험 허용 수준에 맞춘 계획
```

### ALE 기반 대책 선정 확대

```text
위협 (ALE가 큰 순으로 배열)   대책 A      대책 B
위협 1                        (a) ALE 감소  (a) ALE 감소
                              (b) 연간 비용 (b) 연간 비용
                              (c) 연간 절감 (c) 연간 절감    c = a - b
위협 2                        ...
```

### Monte Carlo 확대: 일정 위험 분석 절차

```text
활동별 삼점 추정: 최소 · 가장 가능성 높은 · 최대 기간
    ↓ 삼각 분포로 표현
난수로 활동 기간을 추출하고 일정 논리로 완료일 계산
    ↓ 수천 번 반복
완료일 빈도 분포 → 누적 확률 곡선(S curve)
```

## Ⅳ. 평가 방식과 대표 기법 비교

### 정량·준정량·정성 평가 방식 비교

| 비교축 | 정량적 | 준정량적 | 정성적 |
|---|---|---|---|
| 값의 표현 | 의미와 비례성이 유지되는 수치 | 구간·척도·대표 수치, 의미가 다른 맥락에서는 유지되지 않음 | 비수치 범주(매우 낮음~매우 높음) |
| 강점 | 대응책 비용 대비 효과 분석 | 정성 용어로의 번역과 상대 비교 | 의사결정자에게 위험 결과 전달 |
| 약점 | 결과 해석 설명, 전문가 시간·도구 비용 | 전문가 판단의 역할이 두드러짐 | 값의 범위가 좁아 우선순위 비교 곤란, 전문가별 결과 차이 |

### ALE와 Monte Carlo 시뮬레이션 비교

| 비교축 | ALE | Monte Carlo 시뮬레이션(일정 위험 분석) |
|---|---|---|
| 입력 | 추정 영향(금액), 연간 발생 빈도 | 활동 기간의 확률 분포, 위험의 발생 확률과 영향 분포 |
| 산출 | 위협별 연간 손실 예상액 | 완료일의 확률 분포 |
| 활용 | 대책의 ALE 감소분과 연간 비용 비교 | 위험 허용 수준에 맞는 완료일 선택 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 영향·빈도·기간 추정에 주관 판단과 동기 편향이 섞여 수치의 엄밀성 저하 | 위험 데이터를 임의 비율이 아닌 위험 평가에서 도출하고 전문가 의견을 익명으로 수집 |
| 빈도와 영향이 다른 위험도 곱이 같으면 같은 ALE로 표시 | 결과를 단일 값 대신 확률 분포와 함께 제시해 불확실성 노출 |
| 매우 불확실한 사건은 수치화가 어려움 | 정성·정량 등 복수 기법을 함께 사용 |

## Ⅵ. 제언

추정 입력의 근거와 범위를 기록해 편향을 통제하고, 결과를 단일 값이 아닌 확률 분포로 제시해 의사결정자가 위험 허용 수준을 선택하도록 구성

### 입력 관리에서 분포 제시까지의 흐름

```text
위험 데이터 수집
    ├─ 근거: 위험 평가에서 도출 (임의 비율 배제)
    └─ 방법: 전문가 익명 인터뷰 (동기 편향 통제)
    ↓
근거와 범위(삼점 추정 등)를 기록한 입력값
    ↓
결과: 확률 분포
    ↓
의사결정자가 위험 허용 수준을 선택
```

### 위험 허용 수준 선택 확대: 누적 확률 곡선

```text
누적 확률 곡선(S curve)
    ├─ 50% 완료일 ── 이 날짜까지 끝날 확률 50%
    ├─ 70% 완료일 ── 초과 확률 30% (예: 위험 허용 수준으로 선택)
    └─ 80% 완료일 ── 초과 확률 20%
```

| 구분 | 단일 값 제시 | 제언: 분포 제시 |
|---|---|---|
| 불확실성 표현 | 숨겨짐 | 확률로 노출 |
| 입력 근거 | 담당자 추정 | 근거·범위 기록, 익명 수집 |
| 결정 방식 | 단일 값 수용 | 위험 허용 수준에 맞는 값 선택 |
| 결과 성격 | 예측치로 오인 | 완화 조치 전 상태를 보여 주는 관리 입력 |
