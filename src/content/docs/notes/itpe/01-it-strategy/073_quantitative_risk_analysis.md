## 연관 키워드

- 정량적 위험분석 (Quantitative Risk Analysis)
- 정성적 분석 (Qualitative Risk Analysis), PI (Probability-Impact) 매트릭스
- 민감도 분석 (Sensitivity Analysis), 토네이도 다이어그램 (Tornado Diagram)
- EMV (Expected Monetary Value, 기대 화폐 가치), 의사결정나무 (Decision Tree)
- 몬테카를로 시뮬레이션 (Monte Carlo Simulation)
- 영향 다이어그램 (Influence Diagram)
- P50, P80 (백분위수), S-Curve (누적 확률분포 곡선)
- 우발사태 예비비 (Contingency Reserve), 관리 예비비 (Management Reserve)
- PERT (Program Evaluation and Review Technique, 3점 추정)
- 델파이 기법 (Delphi Technique), Historical Data (과거 데이터)

## Ⅰ. 정량적 위험분석의 개요

- 핵심 요약 : 개별 위험의 결합 영향과 불확실성을 수학적·통계적 기법으로 수치화하여 객관적으로 평가하는 프로젝트 관리 기법.
- 개념 : 프로젝트 목표(일정, 원가)에 미치는 개별 식별 위험들의 결합된 영향과 기타 불확실성 원천을 수학적·통계적 기법을 통해 수치(금액, 일수, 확률)로 환산하여 객관적으로 평가하는 프로젝트 관리 기법.
- 배경 및 필요성 : 정성적 분석 (PI 매트릭스)의 주관적 평가 한계를 극복하고, 경영진 의사결정 및 우발사태 예비비(Contingency Reserve) 산출을 위한 과학적 데이터 근거 마련 필요.
- 주요 목적 : 프로젝트 전체 목표 달성 확률 정량화, 현실적인 완료 일정 및 예산 예비비 산출, 위험 간 상관관계 분석을 통한 우선순위화.

## Ⅱ. 정량적 위험분석의 특징

- 핵심 요약 : 수치화, 확률분포, 시뮬레이션, 예비비 산출을 특징으로 하는 객관적 위험 평가 기법.
1. 수치화 (Quantification) : 위험의 영향을 금액·일수·확률로 환산.
2. 확률분포 (Probability Distribution) : 삼각분포 등 입력 변수의 불확실성 모델링.
3. 시뮬레이션 (Simulation) : 난수 기반 수천 회 가상 시행.
4. 예비비 산출 (Reserve Analysis) : P80 기반 우발사태 예비비 편성.
5. 상관관계 분석 : 위험 간 상호작용 반영.
6. 정성적 분석과의 연계 : 고위험 항목 선별 후 적용.

## Ⅲ. 정량적 위험분석의 구조 (흐름)

- 핵심 요약 : 4대 기법(민감도·EMV·몬테카를로·영향 다이어그램)의 적용 흐름.
- 4대 기법 및 몬테카를로 예측 메커니즘.

```text
[ 정량적 위험분석 4대 기법 ]
   1. 민감도 분석 (Sensitivity Analysis)
      토네이도 다이어그램 기반 영향 변수 식별
   2. 기댓값 분석 (EMV, Expected Monetary Value)
      의사결정나무와 결합한 기댓값 산출
   3. 몬테카를로 시뮬레이션 (Monte Carlo)
      난수 기반 수천 회 시행, 확률분포 도출
   4. 영향 다이어그램 (Influence Diagram)
      변수 간 인과·시간 순서의 시각적 모델링
```

```text
[ 몬테카를로 시뮬레이션 기반 예측 흐름 ]
입력 변수 확률분포 설정
          ↓
수천 회 난수 시행 (Simulation)
          ↓
S-Curve (누적 확률분포) 도출
          ↓
P50 (50% 확률) / P80 (80% 확률) 산출
          ↓
우발사태 예비비 (Contingency Reserve) 편성
```

- **기댓값 분석** (EMV) : 의사결정나무(Decision Tree)와 결합한 기댓값 산출.
- **영향 다이어그램** (Influence Diagram) : 변수 간 인과관계와 시간적 순서의 시각적 모델링.
- **P50** (50% 확률) : 낙관적인 목표 완료 일정/예산 (50% 확률로 달성).
- **P80** (80% 확률) : 일반적인 계약 및 약속 기준 일정/예산 (80% 신뢰수준).
- **우발사태 예비비** (Contingency Reserve) : P80 값과 기본 계획 값과의 차이를 공식 편성.

## Ⅳ. 정량적 위험분석 기법 비교

- 핵심 요약 : 민감도·EMV·몬테카를로 3대 기법의 개념·산출물·적용 상황 비교.
- 3대 기법 비교.

```text
[ 정성적 분석 (PI 매트릭스) ]
        ↓ 고위험 항목 선별
[ 정량적 분석 (민감도/EMV/몬테카를로) ]
```

| 분석 기법 | 핵심 개념 및 산출물 | 적용 상황 및 장단점 |
|---|---|---|
| 민감도 분석 (토네이도 다이어그램) | 다른 변수를 고정하고 한 변수의 변화가 결과에 미치는 영향 폭 측정 | 어떤 위험이 프로젝트에 가장 치명적인지 직관적 우선순위 파악 용이 |
| 기대 화폐 가치 (EMV) | 사건 발생 확률(P) x 사건 발생 시 손실/이익 금액(I) | 의사결정나무와 결합하여 대안 간 경제성 비교 평가에 최적 |
| 몬테카를로 시뮬레이션 | 입력 변수의 확률분포(삼각분포 등) 기반 수천 회 가상 시행 | 프로젝트 완료 일정 및 예산의 백분위수(P50, P80)를 도출하는 최고급 기법 |

## Ⅴ. 정량적 위험분석의 장점과 한계

- 핵심 요약 : 객관적 예비비 산출·의사결정 근거의 장점, 데이터 부재·복잡성·과신의 한계.
- 장점
  1. 프로젝트 전체 목표 달성 확률 정량화.
  2. 현실적인 완료 일정 및 예산 예비비 산출.
  3. 위험 간 상관관계 분석을 통한 우선순위화.
  4. 경영진 의사결정을 위한 과학적 데이터 근거.
- 한계점 1 : 신뢰할 수 있는 과거 데이터(Historical Data)의 부재
  - 한계점 : 신기술 도입 사업이나 최초 프로젝트의 경우 확률 분포를 추정할 수 있는 축적된 이력 데이터 전무.
  - 해결 방안 : 전문가 집단의 3점 추정(PERT, Program Evaluation and Review Technique) 및 델파이 기법 결합, 유사 도메인 공공 통계 데이터의 벤치마킹 적용.
- 한계점 2 : 시뮬레이션 모델링의 복잡성 및 높은 해석 비용
  - 한계점 : 몬테카를로 시뮬레이션 등 고급 통계 기법 활용 시 전문 소프트웨어 구매 및 고숙련 데이터 분석 인력 필요.
  - 해결 방안 : 클라우드 기반 자동 시뮬레이션 툴킷 보급, 주요 위험 변수 2~3개에 집중하는 민감도 분석(Tornado Diagram) 우선 활용.
- 한계점 3 : 분석 결과의 과도한 신뢰 및 맹신 위험
  - 한계점 : 수치화된 확률 결과(예: 높게 산출된 납기 준수 확률)만 믿고 정량화되지 않은 '블랙 스완' 위험을 무시하는 인지 편향.
  - 해결 방안 : 정량 분석 결과와 전문가 정성 평가의 상호 교차 검증, 최악 시나리오(Stress Test) 기반 비상 계획(Contingency Plan) 병행.

## Ⅵ. 정량적 위험분석 적용에 대한 기술사적 제언

- 핵심 요약 : 정성 분석 후 핵심 위험 선별, 역사적 데이터 기반 분포, P50/P80 기반 소통.
- 정성적 분석을 거친 고위험 항목 선별 적용 : 모든 사소한 위험에 정량 분석을 수행하는 것은 비용 낭비이므로, 정성적 분석에서 높은 등급으로 선별된 핵심 위험에 한해 정량 분석 수행.
- 과거 유사 프로젝트의 실측 데이터 기반 분포 설정 : 몬테카를로 시뮬레이션 입력값(최빈값, 낙관치, 비관치) 설정 시 직관적 추정을 배제하고 역사적 실측 데이터(Historical Data) 활용.
- 경영진 보고 시 백분위수(P50, P80) 기반 소통 : 단일 확정 날짜나 금액(Point Estimate) 보고 관행을 탈피하고, "높은 신뢰수준에서 특정 시점 완공, 필요 예비비 규모는 이 수준"과 같이 확률 기반 의사결정 유도.

## Ⅶ. 결론

- 핵심 요약 : 정량적 위험분석은 확률·시뮬레이션 기반으로 일정·원가 예비비를 객관화하는 고급 기법.
- 요약 : 정량적 위험분석은 프로젝트 목표에 미치는 개별 위험의 결합 영향을 수학적·통계적 기법으로 수치화하여 객관적으로 평가하는 프로젝트 관리 기법.
- 시사점 : 정성 분석과의 연계, 역사적 데이터 기반 분포 설정, P50/P80 기반 의사결정 소통을 통해 예비비 산출의 신뢰성과 활용도 제고 필요.
