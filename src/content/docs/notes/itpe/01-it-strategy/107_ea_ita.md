## 연관 키워드

- EA·ITA, 업무·데이터·응용·기술 아키텍처, 참조모델, 목표구조, 이행계획

## Ⅰ. EA·ITA의 개요

- 핵심 요약 : 업무·데이터·응용·기술 구조와 목표상태·전환경로를 모델링해 관리하는 아키텍처 활동.
- 개념 : **EA** (Enterprise Architecture)와 **ITA** (Information Technology Architecture)는 업무·데이터·응용·기술 구조를 현재상태와 목표상태로 모델링하고 전환경로를 관리하는 아키텍처 활동.
- 배경 및 필요성 : 조직의 업무·데이터·응용·기술 구조가 분산되어 중복투자·연계 실패·전략과 IT의 불일치가 발생.
- 주요 목적 : 업무·데이터·응용·기술 아키텍처를 연결해 목표구조와 이행투자의 정합성을 확보.

## Ⅱ. EA·ITA의 특징 및 장점

- 핵심 요약 : 전사 구조 가시화·투자 정합성·표준·상호운용성을 연결해 구조 일관성을 확보.

1. 업무·데이터·응용·기술 관점 연결 (Cross-View Architecture) : 네 관점을 연계해 전사 구조와 의존성을 가시화 → 중복·복잡성 식별.
2. 현황-목표-차이-이행계획 관리 (As-Is/To-Be/Gap/Roadmap) : 현재상태와 목표상태의 차이를 이행계획으로 관리 → 투자·사업의 전략 정합성 강화.
3. 참조모델·표준·예외 운영 (Reference Model & Standard Governance) : 공통 참조모델과 표준·예외를 운영 → 상호운용성과 구조 일관성 확보.
4. 아키텍처 원칙 적용 (Architecture Principles) : 투자·설계 심의에 원칙을 적용 → 임시방편 설계와 기술부채 억제.

## Ⅲ. EA·ITA의 구조 (흐름)

- 핵심 요약 : 전략·업무 분석 → 현황·참조모델 작성 → 목표구조·원칙 설계 → 차이·이행계획 → 사업 적용·갱신.

```text
전략·업무 분석
   ↓
현황·참조모델 작성
   ↓
목표구조·원칙 설계
   ↓
차이·이행계획
   ↓
사업 적용·갱신
```

```text
업무·데이터·응용·기술 관점 연결
   ↓
현황-목표-차이-이행계획 관리
   ↓
참조모델·표준·예외 운영
   ↓
아키텍처 원칙 적용
```

## Ⅳ. EA 참조모델 관점의 비교

- 핵심 요약 : 업무 참조모델은 기능, 데이터모델은 정보자산, 응용모델은 서비스, 기술모델은 기반표준 관점.

| 참조모델 | 주요 특성 | 적합한 선택 기준 |
| --- | --- | --- |
| 업무 참조모델 (BRM) | 업무기능·서비스 분류 | 조직 기능·업무 관점 |
| 데이터 참조모델 (DRM) | 핵심 데이터·표준·흐름 | 정보자산·데이터 공유 관점 |
| 서비스·응용 참조모델 (SRM/ARM) | 응용기능·서비스 구성 | 시스템·서비스 재사용 관점 |
| 기술 참조모델 (TRM) | 기반기술·표준·인프라 | 기술 호환·표준화 관점 |

## Ⅴ. EA·ITA의 한계와 방안

- 핵심 요약 : 문서 사문화는 투자·설계심의 연계로, 현황 노후화는 변경관리·메타데이터 자동수집으로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| EA 현행화 지연 | 의사결정이 실제 자산구성과 어긋남 | 변경·투자심의와 모델 갱신 연결 | 현행성, 미연계 자산 |
| 표준 예외 누적 | 중복·복잡성과 기술부채 확대 | 예외 근거·유효기간·철회조건 심의 | 유효 예외 수, 중복 시스템 |
| 문서 사문화 | 아키텍처가 설계·운영에 미반영 | 투자심의·설계검토 게이트에 EA 반영 | EA 반영 사업 비율 |

## Ⅵ. EA·ITA 적용에 대한 기술사적 제언

- 핵심 요약 : 원칙·표준과 예외승인 절차를 사업 생애주기에 적용하고 아키텍처를 지속 갱신.

- EA 책임자 : 기준·참조모델·예외 유효기간을 운영하고 사업투자·설계심의에서 목표 아키텍처와 이행계획을 확인.
- 정보화 책임자 (CIO) : 중복투자·연계·표준 준수를 투자 심의 기준으로 반영.
- 운영 조직 : 변경관리와 메타데이터 수집으로 현행 아키텍처를 자동 갱신하고 예외를 정기 재심의.

## Ⅶ. 결론

- 핵심 요약 : EA·ITA는 업무·데이터·응용·기술 구조와 목표상태·전환경로를 모델링해 관리하는 아키텍처 활동.
- 시사점 : EA·ITA는 투자와 설계결정에 활용되고 변경에 맞춰 유지되어야 실효성.
