## 지식 로드맵 내 현재 위치

IT 전략·관리 → IT 인력·역량 관리 → **ITSQF(IT Sectoral Qualifications Framework)**

## 30초 인출

- 본질: ITSQF(IT Sectoral Qualifications Framework)는 IT 분야 SW기술자를 9개 직종·38개 직무와 5개 수준(L4~L8)으로 구분해 직무 역량을 표준화한 산업별 역량체계
- 메커니즘: 직무기술서가 수준별 능력단위를 정하고, 학위·자격·경력 등의 점수 진단으로 개인의 직무수준을 부여해 직무별 평균임금과 연결
- 통찰: 진단 결과를 대가에 연결하면 설문형 입력을 부풀릴 유인이 생기므로 대가 반영 전 경력·자격의 증빙 검증과 상위 수준 대상의 정성 평가를 병행

- **ITSQF(IT Sectoral Qualifications Framework)** : IT 분야 SW기술자가 가진 학위·자격·현장경력·교육훈련 이수 등의 역량을 종합해 직무별·수준별로 진단·평가·인정하는 산업별 역량체계
- **IT직무제** : 기술자 등급 대신 직무와 수준으로 SW기술자를 구분하는 방식. 132회 문항의 표현
- **SW기술자 등급제** : 초급·중급·고급·특급의 기술등급으로 SW기술자를 구분하는 방식
- **NCS(National Competency Standards)** : 직무 수행에 필요한 능력을 표준화한 국가직무능력표준. ITSQF 직무기술서의 능력단위 기반
- **KQF(Korean Qualifications Framework)** : 한국역량체계. ITSQF의 수준이 연계되는 국가 수준 체계
- **직무기술서** : 직무의 정의와 수준별 직무 정의, 필요 능력단위를 적은 문서
- **SW기술자 평균임금** : KOSA가 임금실태조사를 바탕으로 직무별로 공표하는 SW기술자 임금 통계
- **KOSA** : ITSQF를 구축·운영하며 직무 기준의 평균임금을 공표하는 한국인공지능·소프트웨어산업협회

## 2~4교시 25점 답안

## Ⅰ. ITSQF의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ITSQF(IT Sectoral Qualifications Framework)** 는 IT 분야 SW기술자의 직무 역량을 직무별·수준별로 표준화해 진단·평가·인정하는 산업별 역량체계 |
| 목적 | 직무 역량에 기반한 공정한 대가 산정과 처우 |

## Ⅱ. 직무와 수준으로 역량을 구분하는 ITSQF의 특징

| 특징 | 내용 |
|---|---|
| 직무 중심 | 9개 직종을 38개 세부 직무로 구성 |
| 수준 체계 | 지식·기술·자율성과 책임성 3개 Domain을 기준으로 직무수준 5단계(L4~L8) 구분 |
| 표준 연계 | **NCS** 의 능력단위로 직무기술서를 작성하고 **KQF** 수준과 연계 |
| 종합 진단 | 학위·자격·현장경력·교육훈련 이수 등 여러 역량요소를 함께 반영 |

## Ⅲ. ITSQF의 구성 체계와 직무수준 진단 절차

### ITSQF 구성 체계

```text
IT 분야 9개 직종 → 38개 직무
    │
    ├─ 직무기술서 ── 직무 정의, 수준별 직무 정의, NCS 능력단위(필수·선택)
    │
    ├─ 직무수준 ── L4 ~ L8 (5개 수준)
    │       └─ 수준 기준: 지식 · 기술 · 자율성과 책임성
    │
    └─ 개인 역량요소 ── 직무경험 · 직업자격 · 교육자격을 수준별로 배치
```

### 직무수준 진단 확대: 점수 산정에서 대가 연계까지

```text
개인 역량요소 입력
    ├─ 기초역량(지식): 학위
    ├─ 기술역량(기술): 자격증, 기술역량진단(설문형 20문항)
    ├─ 현장직무역량(자율성·책임성): 총경력, 프로젝트 수행경력·규모, Domain 경험
    └─ 추가역량: 교육훈련 이수 등 (최대 10점 인정)
    ↓
점수 합계 → 직무별 점수 구간 → 직무수준(L4~L8) 부여
    ↓
직무별 평균임금과 연계 → 직무수준별 직접인건비 차등
```

## Ⅳ. SW기술자 등급제와 IT직무제(ITSQF)의 비교

| 비교축 | 기술자 등급제 | IT직무제(ITSQF) |
|---|---|---|
| 구분 단위 | 초급·중급·고급·특급 기술등급 | 직무 38개와 직무수준 L4~L8 |
| 제도 상태 | SW기술자 신고제도의 기술자 등급은 2012년 폐지, 경력관리만 유지 | 2018~2019년 신고 운영세칙에 ITSQF 직무 반영, 2019년 이후 평균임금 조사의 직무 기준 |
| 현장 적용 | 사업대가산정·사업관리에서 업계 관행으로 유지 | 직무 기반 대가산정·사업관리의 정착이 과제 |
| 역량 판단 | 직무별 수준을 정량 진단하는 체계의 미흡이 관행 유지의 원인 | 지식·기술·자율성과 책임성 기준의 수준 정의와 점수 진단 |

## Ⅴ. IT직무제의 한계(문제점)와 방안(개선방향)

| 한계 | 방안 |
|---|---|
| 직무 기준 평균임금 조사에도 직무 기반 대가산정·사업관리가 확산되지 못하고 기술등급 관행이 유지 | 직무수준 진단 결과를 평균임금과 연계한 직무수준별 직접인건비 차등의 적용 |
| 같은 직무에서 역할·책임·기술역량 수준의 차이를 구분할 객관적 기준 부재 | 기초·기술·현장직무 역량 점수와 직무별 점수 구간에 따른 직무수준 부여 |
| 실무역량 진단에 필요한 인터뷰·포트폴리오 평가가 시간·비용 제약으로 어려워 설문형 진단으로 대체 | 면접·에세이·실시간 질의응답 같은 정성 평가의 확대와 진단–검증–인정–사후모니터링의 품질보증 체계 |

## Ⅵ. 제언

진단 결과를 대가에 반영하기 전에 경력·자격 등 입력 자료의 증빙을 검증하고, 상위 수준으로 인정할 대상에는 설문형 진단에 더해 정성 평가를 병행

### 진단 결과의 대가 반영 절차

```text
진단 입력: 학위·자격·경력·프로젝트 규모, 기술역량진단 응답
    ↓
증빙 검증: 경력증명서·자격 증빙·프로젝트 수행 실적 확인
    ↓
직무수준 인정 (L4~L8)
    ↓
평균임금 연계 직접인건비 차등 적용
```

### 상위 수준 인정 확대: 정성 평가 병행

```text
설문형 기술역량진단 결과
    ↓
상위 수준 인정 대상?
    ├─ 예 → 면접·포트폴리오 등 정성 평가로 응답 근거 확인 → 수준 확정
    └─ 아니오 → 진단 점수 기준으로 수준 확정
```

| 구분 | 진단 결과 즉시 반영 | 제언: 검증 후 반영 |
|---|---|---|
| 입력 자료 | 응답·제출 내용 그대로 사용 | 경력·자격의 증빙 확인 |
| 정성 평가 | 없음 | 상위 수준 인정 대상에 한정 |
| 대가 반영 시점 | 진단 직후 | 수준 인정 후 |
