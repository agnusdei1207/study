## 30초 인출

- 본질: ITSQF(IT Sectoral Qualifications Framework)는 NCS를 바탕으로 IT 직무와 직무수준별 요구역량을 정리한 IT 분야 산업별 역량체계
- 메커니즘: 직무기술서의 수준별 요구역량과 개인의 학위·자격·현장경력을 대조해 직무수준을 진단하고 채용·교육·대가 산정에 활용
- 통찰: 폐지된 등급제가 남으면 실제 역량이 인력 요건에 반영되지 않으므로 과업별 필요 직무·수준 명시와 진단 결과 활용

- **ITSQF(IT Sectoral Qualifications Framework)** : NCS를 바탕으로 IT 직무와 직무수준별 요구역량을 정리한 IT 분야 산업별 역량체계

- **SW기술자 등급제** : 학력·자격·경력 연수로 기술자를 기술사·특급·고급·중급·초급 기술자와 고급·중급·초급 기능사로 나누던 제도. 2012.11.24. 시행 「소프트웨어산업 진흥법 시행령」 개정으로 기술등급 기준 폐지, 경력관리는 유지

## 2~4교시 25점 답안

## Ⅰ. ITSQF의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ITSQF(IT Sectoral Qualifications Framework)** 는 NCS를 바탕으로 IT 직무와 직무수준별 요구역량을 정리한 IT 분야 산업별 역량체계 |
| 목적 | 학력·연수가 아닌 직무 역량 기준의 채용·교육·배치와 공정한 대가 산정 |

## Ⅱ. 직무와 역량 중심이라는 특징

| 특징 | 의미 |
|---|---|
| 직무 중심 구분 | 학력·경력 연수가 아닌 수행 직무로 기술자를 구분 |
| 수준별 요구역량 | 같은 직무 안에서도 수행 난이도·책임에 따른 수준 구분 |
| 다원적 인정 근거 | 학위·자격·현장경력을 함께 반영한 직무수준 진단 |
| 표준 연계 | NCS·SQF 체계를 IT 산업 특성에 맞게 구체화 |
| 주기적 개정 | 신기술·융합 직무를 반영한 직무기술서 개정 |

## Ⅲ. ITSQF의 구성 체계와 직무수준 진단 절차

### ITSQF 구성 체계

```text
NCS 국가직무능력표준
    │
    └─ SQF 산업별 역량체계
          │
          └─ ITSQF
                ├─ 직무 ── IT 분야 표준 직무 구분
                ├─ 직무수준 ── L4~L8의 5개 수준
                └─ 직무기술서 ── 수준별 요구역량
                      └─ 기초·기술·현장직무역량
```

### 직무수준 확대: 개인별 진단 절차

```text
실제 수행 업무로 직무 매핑
    ↓
직무기술서의 수준별 요구역량 확인
    ↓
학위·자격·현장경력 증빙과 대조
    ↓
개인별 직무수준 판정
    ↓
채용·인사평가·교육훈련·대가 산정 활용
```

## Ⅳ. SW기술자 등급제와 IT직무제(IT역량분류체계 기반)의 비교

| 구분 | SW기술자 등급제 | ITSQF 기반 직무제 |
|---|---|---|
| 구분 기준 | 학력·자격·경력 연수 | 수행 직무와 직무수준 |
| 등급·수준 | 기술사·특급·고급·중급·초급 기술자, 고급·중급·초급 기능사 | 직무별 L4~L8(KQF 8수준 중 5개 수준 연계) |
| 인정 근거 | 연수 산정 중심 | 학위·자격·현장경력의 역량 대조 |
| 제도 상태 | 2012.11.24. 시행령 개정(대통령령 제24174호)으로 기술등급 기준 폐지, 경력 신고·관리는 유지 | 직무기술서와 직무수준 진단 가이드 운영 |
| 약점 | 실제 역량과 등급의 불일치 | 직무 매핑·진단 근거의 확보 부담 |

## Ⅴ. IT직무제(ITSQF)의 한계(문제점)와 방안(개선방향)

| 한계 | 방안 |
|---|---|
| 공공사업의 폐지된 등급제 관행 잔존 | 인력 투입 요건을 등급 대신 ITSQF 직무·수준으로 명시 |
| 직함 기준 매핑에 따른 직무 오분류 | 실제 수행 업무와 직무기술서의 대조 |
| 진단 근거의 부족 | 학위·자격·현장경력 증빙의 확인 |
| 신기술 직무의 기준 공백 | 개정 직무기술서 판본 확인과 융합 직무 반영 |

## Ⅵ. 제언

공공사업의 인력 요건을 등급 대신 과업별 필요 직무·수준으로 명시하고, 수행 업무 기준 직무수준 진단 결과를 투입 인력 검증에 활용

### 직무·수준 기반 인력 요건 구조

```text
공공사업 인력 요건
    │
    ├─ 발주기관 ── 과업별 필요 직무·수준 명시
    │
    ├─ 수행사 ── 투입 인력의 직무수준 진단 근거 제출
    │
    └─ 검증 ── 수행 업무와 직무기술서의 대조
```

### 검증 확대: 투입 인력 적합 판정

```text
투입 예정 인력
    ↓
실제 수행 업무로 직무 매핑
    ↓
증빙과 요구역량 대조
    ├─ 요구 수준 충족 → 투입 승인
    └─ 미충족 → 인력 교체 또는 보완 후 재진단
```

### 선택 근거: 등급제 관행과의 비교

| 구분 | 등급제 관행 | 제언: 직무·수준 기반 요건 |
|---|---|---|
| 인력 요건 표기 | 고급·특급 등 등급 | 과업별 직무와 직무수준 |
| 적합성 판단 근거 | 경력 연수 | 수행 업무와 요구역량 대조 |
| 검증 주체 | 서류상 등급 확인 | 발주기관의 직무기술서 대조 |
| 대가 산정 연계 | 폐지된 등급별 단가 | 직무수준과 평균임금조사 연계 |
