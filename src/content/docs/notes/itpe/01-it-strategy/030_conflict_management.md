## 연관 키워드

- 갈등관리, Thomas–Kilmann, 협력·타협·경쟁·회피·수용, 중재

## Ⅰ. 갈등관리의 개요

- 핵심 요약 : 갈등관리는 목표·이해·가치·자원 차이에서 발생하는 의견 충돌을 식별하고 건설적으로 해결하는 과정.
- 개념 : **갈등관리**는 목표·이해·가치·자원 차이에서 발생하는 의견 충돌을 식별하고 건설적으로 해결하는 과정.
- 배경 및 필요성 : 갈등을 방치하면 신뢰·협업·의사결정·프로젝트 성과가 손상되나 과업 이견은 개선 기회가 될 수 있음.
- 주요 목적 : 관계 손상을 줄이고 이해관계 조정과 의사결정 품질 향상.

## Ⅱ. 갈등관리의 특징 및 장점

- 핵심 요약 : Thomas–Kilmann 갈등대응 유형(경쟁·협력·타협·회피·수용)을 상황과 중요도에 따라 선택.

1. 경쟁 (Competing) : 자기주장 높고 협력 낮음 → 긴급·중요한 결정이나 비협상 원칙 보호에 사용.
2. 협력 (Collaborating) : 자기주장·협력 모두 높음 → 양측 요구를 통합하는 공동해결 추구.
3. 타협 (Compromising) : 중간 수준의 주장·협력 → 시간 제약 하에서 상호 양보.
4. 회피 (Avoiding) : 주장·협력 모두 낮음 → 사소하거나 감정 고조 시 일시 유예.
5. 수용 (Accommodating) : 주장 낮고 협력 높음 → 관계 유지와 상대방 요구 수용.

## Ⅲ. 갈등관리의 구조 (흐름)

- 핵심 요약 : 갈등 신호 확인 → 쟁점·이해관계 분리 → 대응방식 선택 → 대화·협상·중재 → 합의·후속 점검.


- 대응 유형 흐름 : 쟁점·관계 진단 → 협력·타협·경쟁·회피·수용 선택 → 합의·점검.

```text
쟁점·관계 진단 → 협력·타협·경쟁·회피·수용 선택 → 합의·점검
```

## Ⅳ. 갈등관리 방식의 비교

- 핵심 요약 : 경쟁은 자기주장 높고 협력 낮음, 협력은 자기주장·협력 모두 높은 공동해결 지향.

| 비교 기준 | 경쟁 | 협력 |
| --- | --- | --- |
| 대응 유형 비교 | 자기주장 높고 협력 낮음 | 자기주장·협력 모두 높은 공동해결 지향의 협력 |
| 적합한 상황 | 긴급·중요한 결정, 원칙 보호 | 양측 요구 통합, 장기 관계 |
| 위험 | 관계 악화 | 시간 소요 |
| 대안 | 타협·수용 | 타협·회피 |

2. 실무 담당자 : 관찰사실·영향·요구를 분리해 대화; 중립 촉진자·개별 청취·공정한 발언기회; 갈등 중요도·시간·관계에 맞춰 방식 선택.
3. 팀 리더 : 반복 인신갈등·미해결 쟁점·합의 이행률 지표를 정기 검토하고 미달 원인·시정조치·잔여위험 기록.
