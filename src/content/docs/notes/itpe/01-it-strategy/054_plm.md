## 연관 키워드

- PLM(제품 수명 주기 관리), 제품 수명 주기, BOM(Bill of Materials)
- 형상관리, 변경관리, 추적성, PDM(Product Data Management)

## Ⅰ. PLM의 개요

- 핵심 요약 : 기획부터 폐기까지 제품 관련 정보와 프로세스를 단일 기준으로 관리해 협업·추적성을 확보하는 체계.
- 개념 : 제품 수명 주기 관리(**PLM**, Product Lifecycle Management)는 기획부터 폐기까지 제품이 거치는 전 기간인 **제품 수명 주기**(product lifecycle) 전반에서 제품 데이터와 업무 프로세스를 통합 관리하는 체계.
- 배경 및 필요성 : 도면·부품·문서의 부서·협력사·설계 도구별 분산 상태에서는 형상 불일치·변경 누락 발생. 제품 복잡도 상승과 개발 기간 단축 요구로 설계 데이터 저장 수준을 넘는 전 주기 관리 필요.
- 주요 목적 : 제품 정보의 단일 출처 확보를 통한 품질·원가·개발 기간·시장 대응력 개선.

## Ⅱ. PLM의 특징 및 장점

- 핵심 요약 : 수명 주기 통합·제품 구조 관리·형상과 변경의 통제·전사 연계가 품질과 개발 효율로 연결.

1. 수명 주기 통합 관리 : 개념설계부터 서비스·폐기까지의 동일 데이터 기준 적용 → 부서·협력사 간 정보 단절 제거.
2. 제품 구조 관리 : **BOM**(Bill of Materials, 제품 구성 부품·수량·계층의 목록)으로 설계·생산·서비스용 구성 정보 연결 → 설계-양산 간 정합성 확보.
3. 형상·변경 통제 : **형상관리**(Configuration Management, 제품의 기능·물리적 특성과 그 정보의 일치 유지)와 **변경관리**(변경 요청부터 영향분석·승인·반영까지의 절차) 운영 → 변경 영향 파악과 **추적성**(Traceability, 요구·설계·부품·변경 간 연결 가능성) 확보.
4. 전사 시스템 연계 : 생산실행시스템(MES, Manufacturing Execution System)·전사적 자원 관리(ERP, Enterprise Resource Planning)와의 정보 연계 → 설계 변경의 조달·생산 즉시 반영.

## Ⅲ. PLM의 구조 (흐름)

- 핵심 요약 : 수명 주기 단계별 정보 흐름과 변경 통제 흐름, 제조 정보 전달과 현장 이력 회수의 결합.

```text
[ 제품 수명 주기 단계 ]

기획·요구사항 정의
   ↓
설계·시제품 검증
   ↓
양산·생산 지원
   ↓
서비스·유지보수
   ↓
폐기·재활용
   ↓
현장 정보 → 기획 환류
```

```text
[ 변경 통제·연계 흐름 ]

요구·도면·BOM·문서 등록
   ↓
변경 요청 → 영향분석 → 승인
   ↓
ERP·MES로 제조·조달 정보 전달
   ↓
현장·서비스 이력 회수
```

## Ⅳ. PLM과 PDM의 비교

- 핵심 요약 : PDM이 설계 산출물 중심의 데이터 관리인 반면, PLM은 수명 주기 전체의 데이터·프로세스·협업을 포괄.

제품 데이터 관리(**PDM**, Product Data Management)는 도면·문서·부품 데이터의 저장·버전 관리에 집중하는 관리 체계.

| 비교 축 | PLM | PDM |
| --- | --- | --- |
| 관리 대상 | 수명 주기 전체의 데이터·프로세스 | 설계 산출물 중심 데이터 |
| 관리 범위 | 기획·설계·생산·서비스·폐기 | 도면·문서·부품의 저장·버전 |
| 초점 | 부서·협력사 협업과 의사결정 지원 | 설계 데이터의 정확한 보관·검색 |
| 시스템 연계 | ERP·MES 등 전사 시스템과 연계 | 설계 도구 중심의 연계 |

## Ⅴ. PLM의 한계와 방안

- 핵심 요약 : 구형 데이터 이관·부서별 이원화·변경 통제 우회를 정제·단일 출처 원칙·긴급 절차 통제로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 구형 데이터 이관 리스크 | 레거시 도면·문서의 중복·부정확 → 잘못된 설계 정보 재사용 | 유효성 정제와 단계별 이관·대사 승인 | 중복률, 이관 오류 건수 |
| 부서별 이원화 | 일부 부서의 기존 저장 방식 유지 → 단일 출처 훼손 | 이원 저장 금지 원칙·권한 설계·교육 | 이원 저장 건수 |
| 변경 통제 우회 | 긴급 수정 시 승인 생략 → 형상 불일치 | 긴급 변경의 사후 승인 절차·정기 감사 | 무승인 변경 건수 |

## Ⅵ. PLM에 대한 기술사적 제언

- 핵심 요약 : 제품 데이터 거버넌스(데이터 소유자·변경 승인 체계·정보 표준)의 수립과 공급망 확산 필요.
- 조직 : 제품 데이터 소유자와 변경 승인 조직의 지정을 통한 부서 간 책임 경계 정리.
- 체계 : 요구-설계-부품-제조-서비스 정보의 추적성 기준과 명명·버전 규칙 통일.
- 확산 : 협력사 포털 연계로 공급망 전반의 제품 정보 공유 확대.

## Ⅶ. 결론

- 핵심 요약 : PLM은 제품 정보를 수명 주기 전체의 단일 기준으로 유지하는 관리 체계.
- 단일 기준의 제품 정보가 품질·원가·시장 대응력의 기반 자산.
