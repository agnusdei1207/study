## 연관 키워드

- POP(Point of Production), 생산지표, 생산실적
- 투입 대비 산출, 공정 관리, 생산성, MES, OEE

## Ⅰ. POP의 개요

- 핵심 요약 : 생산 현장에서 투입 대비 산출을 생산 시점에 측정해 생산성과 공정을 관리하는 방식.
- 개념 : 생산이 일어나는 현장에서 투입(인력·설비·자재·시간)과 산출(수량·품질)을 생산 시점에 측정해 생산성을 관리하는 생산지표(생산성·가동률·불량률처럼 공정 성과를 수치화한 지표) 방식인 **POP**(Point of Production, 생산 시점 정보관리).
- 배경 및 필요성 : 투입 인건비·공수만으로 성과를 산정하면 비가동·불량·재공 같은 손실이 사후 집계 때까지 드러나지 않고 계획과 실적의 차이가 누적.
- 주요 목적 : 공정별 생산성·품질·납기의 실시간 가시화와 손실 요인 제거를 통한 공정 관리 역량 강화.

## Ⅱ. POP의 특징 및 장점

- 핵심 요약 : 생산 시점 수집, 투입·산출 대비, 설비 연계, 계획 대비 관리, 상위 시스템 연계가 생산성 관리의 정밀도를 높임.

1. 생산 시점 데이터 수집 : 작업 시작·완료·수량·불량을 현장 단말에서 즉시 기록 → 집계 지연 없는 실시간 진도 관리.
2. 투입 대비 산출 측정 : 투입량과 산출량을 같은 공정·시점 기준으로 대비 → 공정별 생산성의 정량화.
3. 생산지표의 산식 운영 : 공정별 지표를 정해진 산식으로 산출 → 부서 간 공통 판단 기준 확보.
4. 설비 가동 정보 연계 : 설비 가동·정지·알람을 자동 수집해 **OEE**(Overall Equipment Effectiveness, 가동률·성능률·품질률의 곱으로 설비 효율을 종합한 지표)까지 산출 → 손실 공수의 원인 식별.
5. 상위 시스템 연계 : 공정 실행 관리 시스템인 **MES**(Manufacturing Execution System)와 연계 → 생산실적(작업 결과로 확인되는 수량·품질·가동 이력)의 계획·재고·원가 통합 관리.

## Ⅲ. POP의 구조 (흐름)

- 핵심 요약 : 작업지시 수신 → 데이터 수집 → 지표 산출 → 공정 대응 → 상위 생산관리 반영의 순환 흐름.

```text
작업지시·생산계획 수신
   ↓
현장 단말·설비의 데이터 수집
   ↓
생산지표 산출 (생산성·가동률·불량률)
   ↓
계획 대비 실적 분석·공정 대응
   ↓
MES 상위 반영
```

- 생산지표 산출 원리 : 투입 데이터와 산출 데이터의 대비 구조.

```text
투입 데이터 (인력·설비·시간·자재)
   ↓
산출 데이터 (수량·품질·납기)
   ↓
생산성 = 산출 ÷ 투입
```

## Ⅳ. POP과 투입 인건비 중심 원가 산정 방식의 비교

- 핵심 요약 : POP는 산출 실적을 기준으로 생산성과 공정을 측정하고, 투입 인건비 중심 원가 산정 방식은 투입된 공수·인건비를 기준으로 원가와 성과를 산정.

| 비교 축 | POP | 투입 인건비 중심 원가 산정 방식 |
| --- | --- | --- |
| 측정 기준 | 산출 실적 (수량·품질·가동) | 투입량 (공수·인건비) |
| 관리 시점 | 생산 시점의 실시간 측정 | 사후 집계·계약 기준 산정 |
| 생산성 판단 | 투입 대비 산출 지표 | 투입 규모 중심 판단 |
| 손실 분석 | 비가동·불량 원인까지 추적 | 손실 원인 식별의 제약 |
| 개선 근거 | 공정별 실적 데이터 | 경험·단가 추정 |

## Ⅴ. POP의 한계와 방안

- 핵심 요약 : 입력 신뢰성, 지표 해석 충돌, 현장 활용 저조, 상위 연계 단절을 원인별 대응과 지표로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 입력 신뢰성 부족 | 수기 입력 오류·누락 → 실적 왜곡 | 설비 자동 수집·입력 검증 절차 | 실적 불일치율 |
| 지표 해석 충돌 | 공정별 산식·기준 불일치 → 부서 간 분쟁 | 생산지표 정의·산식의 사전 합의 | 지표 정의 준수율 |
| 현장 활용 저조 | 입력 절차와 작업 흐름 불일치 → 데이터 품질 저하 | 작업자 참여 설계·교육·피드백 | 입력 누락률 |
| 상위 연계 단절 | 식별자·마스터 불일치 → 상위 시스템 정합성 훼손 | 공통 마스터·이력 키 관리 | 연계 오류 건수 |

## Ⅵ. POP에 대한 기술사적 제언

- 핵심 요약 : 생산 책임 조직의 지표 거버넌스와 표준 참조 모델로 POP를 현장 관리 표준으로 확산.
- 생산 책임 조직 : 공장 경영진 직속으로 지표 소유자·데이터 품질 책임 체계 수립.
- 표준 아키텍처 : 공장 운영 조직이 현장 단말·설비 인터페이스·상위 연계를 표준 참조 모델로 정의해 다중 공장 확산.
- 성과 연계 : 경영 관리 부서가 지표 결과를 공장 평가·개선 과제 관리 체계에 반영해 채택 동기 확보.

## Ⅶ. 결론

- 핵심 요약 : POP는 사후 투입 산정에서 생산 시점의 산출 기반 공정 관리로 전환하게 하는 생산지표 체계.
- 생산이 일어나는 시점과 장소에서 생산성을 측정하는 체계만이 원가·품질·납기 경쟁력의 기반.
