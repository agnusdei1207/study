## 연관 키워드

- 인과루프다이어그램, 시스템 사고, 강화루프, 균형루프, 인과극성, 시간지연

## Ⅰ. 인과루프다이어그램의 개요

- 핵심 요약 : 변수 간 인과관계와 피드백 순환을 표현해 복잡한 문제를 이해하는 도구.
- 개념 : **인과루프다이어그램** (**CLD**, Causal Loop Diagram)은 시스템 사고에서 변수 간 인과관계와 피드백 순환을 표현해 복잡한 문제를 이해하는 도구.- 배경 및 필요성 : 복잡한 정책·프로젝트 문제는 변수 간 피드백과 시간지연 때문에 단순한 선형 원인분석으로 설명하기 어려움.
- 주요 목적 : 피드백 구조와 시간지연을 파악해 복잡한 시스템의 정책·개입 결과를 이해.

## Ⅱ. 인과루프다이어그램의 특징 및 장점

- 핵심 요약 : 인과극성·피드백 구조·시간지연을 표시해 강화·균형 루프와 정책효과를 함께 설명.

1. 인과극성 표시 (Causal Polarity) : 변수 간 영향 방향과 같은 방향(+)·반대 방향(−) 관계를 표시 → 가정과 예상 효과를 명시.
2. 강화루프 식별 (Reinforcing Loop) : 변화를 증폭하는 순환을 식별 → 성장·악화의 자기강화 구조 파악.
3. 균형루프 식별 (Balancing Loop) : 목표·제약을 향한 조절 피드백을 식별 → 시스템의 안정·저항 구조 파악.
4. 시간지연 표시 (Time Delay) : 원인과 결과 사이의 지연을 표시 → 성급한 정책 수정과 장기효과 누락 방지.

## Ⅲ. 인과루프다이어그램의 구조 (흐름)

- 핵심 요약 : 변수선정 → 인과화살표·극성표시 → 강화·균형 루프 식별 → 지연·정책효과 검토.

```text
변수선정
   ↓
인과화살표·극성표시
   ↓
강화·균형 루프 식별
   ↓
지연·정책효과 검토
```

```text
교육투자 (+) → 역량 (+) → 생산성 (+) → 교육재원 (+)
              └────── 강화루프 R ──────┘

수요 (+) → 대기시간 (+) → 만족도 (−) → 이탈 (−) → 수요
          └──────── 균형루프 B ─────────┘
```

## Ⅳ. 인과루프다이어그램과 대안의 비교

- 핵심 요약 : 강화루프는 변화 증폭, 균형루프는 목표·제약을 향한 조절 피드백.

| 개념·방법 | 주요 특성 | 적합한 선택 기준 |
| --- | --- | --- |
| 인과루프다이어그램 (CLD) | 변수 간 방향·극성·피드백루프를 정성적으로 표시 | 가설·정책 피드백 구조를 탐색할 때 |
| Stock and Flow Diagram | 저량(stock)·유량(flow)과 축적량·변화율을 구분 | 시간에 따른 누적량·수량 변화를 정량 모형화할 때 |
| 보완 관계 | CLD에서 핵심 피드백을 찾고 저량·유량이 중요하면 Stock and Flow로 구체화 | 정성 가설을 동적 시뮬레이션으로 발전시킬 때 |

## Ⅴ. 인과루프다이어그램의 한계와 방안

- 핵심 요약 : 과도한 단순화는 현장검증으로, 시간지연 누락은 지연표시·시계열자료로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 인과관계 과잉단순화 | 잘못된 개입으로 부작용 발생 | 이해관계자·자료로 연결가정 검증 | 미검증 연결, 예측 오차 |
| 시간지연·루프 누락 | 정책효과를 조기 판정 | 지연 표기·시계열 확인·시나리오 분석 | 지연 반영, 후속효과 |
| 인과와 상관 혼동 | 정성 모델을 정량 증거로 오해 | CLD를 가설로 취급하고 데이터로 검증 | 검증된 가설 비율 |

## Ⅵ. 인과루프다이어그램 적용에 대한 기술사적 제언

- 핵심 요약 : 이해관계자와 인과가정을 검증하고 개입 이후 2차 효과까지 모니터링.

- 정책기획자 : 분석질문과 시스템 경계를 정하고 변수 정의·인과가정·자료근거를 문서화.
- 현업·이해관계자 : 강화·균형루프와 시간지연을 검토하고 반례·누락변수·의도치 않은 효과를 확인.
- 분석·평가 담당자 : CLD를 정량 인과증거로 오해하지 않도록 구분하고 필요하면 시계열자료·Stock and Flow 모델로 가설을 검증.

## Ⅶ. 결론

- 핵심 요약 : 인과루프다이어그램 (CLD)은 변수 간 인과관계와 피드백 순환을 표현해 복잡한 문제를 이해하는 도구.
- 시사점 : 시스템 사고는 인과가정 검증과 의도하지 않은 2차 효과의 관찰이 중요.
