## 답안 골격
```text
[인과루프다이어그램(CLD)] ◀━━ 머리: Ⅶ 내 의견 (단편적 대증 처방을 탈피하고 기술 부채와 브룩스의 법칙 피드백 루프를 차단하는 근본 해결책 도출)
 ┃
 ┣━ Ⅰ 개요 ───── 단선적 인과관계로 복잡계 IT 시스템의 부작용 예측 불가 → 시스템 사고(Systems Thinking) 기반 동적 피드백 시각화
 ┣━ Ⅱ 특징 ───── 시스템 다이내믹스 기초 도구 · 양/음의 인과 링크(Polarity) · 2대 피드백 루프(강화 R, 조절 B) · 시간 지연(Delay) 표현
 ┣━ Ⅲ 구조 ───── 변수(Variables) ↔ 인과 링크(+/-) ↔ 피드백 루프(강화루프 R ↔ 조절루프 B) ↔ 시간 지연(//)
 ┣━ Ⅳ 흐름 ───── ① 핵심 문제 변수 식별 → ② 직접 인과 링크 및 극성(+/-) 부여 → ③ 폐쇄형 피드백 루프 식별 → ④ 시간 지연 및 레버리지(지렛대) 포인트 탐색
 ┣━ Ⅴ 비교 ───── 강화 루프(Reinforcing, R) vs 조절 루프(Balancing, B) (지수적 성장/악순환 vs 목표 지향적 안정화/균형 유지)
 ┗━ Ⅵ 실무 ───── 시간 지연(Delay) 간과로 인한 과잉 반응과 시스템 진동 / 단기 개선이 장기 악화를 부르는 '정책 저항(Policy Resistance)'
```

## 한 줄 본질
- 원인과 결과가 단방향으로 끝나지 않고 다시 원인으로 되돌아오는 복잡계의 '순환적 피드백 구조'를 변수, 극성(+/-), 강화(R)·조절(B) 루프, 시간 지연으로 모델링하여 문제의 근본 지렛대(Leverage)를 찾아내는 시스템 사고 도구 → 의도치 않은 시스템 부작용 예측 및 근본 해결책 도출 / 변수의 정량적 수치 시뮬레이션의 부재(정성적 모델 한계)

## 핵심 용어
- 강화 루프(Reinforcing Loop, R): 원인의 변화가 루프를 한 바퀴 돌아 다시 원인을 더 큰 방향으로 증폭시키는 양의 피드백(눈덩이 효과, 성장의 엔진 또는 파멸의 악순환)
- 조절 루프(Balancing Loop, B): 원인의 변화가 루프를 돌아 원인을 억제하는 방향으로 작용하여, 시스템을 특정 목표 상태(평형 상태)로 유지하려는 음의 피드백
- 레버리지(Leverage Point): 최소한의 노력으로 시스템의 악순환 고리를 끊고 근본적인 개선을 유도할 수 있는 핵심 급소(지렛대 지점)

## 핵심 통찰
- 부분 최적화가 전체 파멸을 부름 → 버그를 빨리 잡으려고 테스트 코드를 생략하면, 단기적으로는 납기를 맞추지만 장기적으로는 기술 부채가 누적되어 나중에 시스템이 멈추는 악순환(R 루프)에 빠짐
- 시간 지연(//)이 과잉 반응을 만듦 → 샤워기 꼭지를 온수로 틀고 물이 데워지는 시간 지연을 참지 못해 꼭지를 끝까지 돌렸다가 화상을 입듯, 신규 인력의 온보딩 지연을 못 참고 인력을 계속 추가하면 프로젝트가 폭망함
- 증상 치료가 아닌 '구조 치료'를 해야 함 → 프로젝트가 늦어질 때 야근을 시키는 것은 대증 요법(B 루프)에 불과하며, 요구사항 변경 통제와 아키텍처 모듈화라는 진짜 지렛대(Leverage)를 건드려야 함

## 이웃 토픽과 구분
- CLD vs 특성요인도(Fishbone): 특성요인도 = 결과를 중심으로 원인들을 나뭇가지 형태로 정적 나열(단방향) / CLD = 원인과 결과가 서로 맞물려 돌아가는 동적 순환 피드백과 시간 지연을 모델링

## 문제·원인·대책
- 적용 상황: 대형 차세대 프로젝트 후반부 결함 폭증 및 일정 지연의 악순환
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 납기가 다가오자 야근 강행 ➔ 피로 누적으로 코딩 결함 폭증 ➔ 야근 심화 (악순환 R 루프) | 단기 피로도와 결함 발생 간의 인과 피드백 간과 | 결함 수정 전담 스프린트 도입 및 강제 휴식(B 루프 삽입) | 결함 발생률 60% 급감 |
| 아키텍처 리팩토링을 미루고 기능 추가만 서두르다 코드 수정 불가 상태 직면 | 기술 부채 누적으로 인한 생산성 저하 루프 방치 | CLD로 기술 부채 악순환을 시각화하여 경영진을 설득하고 리팩토링 공수 20% 공식 확보 | 개발 속도(Velocity) 회복 |
