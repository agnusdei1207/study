## 연관 키워드

- SEM (Strategic Enterprise Management, 전략적 기업경영), VBM (Value-Based Management, 가치기준경영)
- EVA (Economic Value Added, 경제적 부가가치), ABM (Activity-Based Management), ABC (Activity-Based Costing, 활동기준원가)
- BSC (Balanced Scorecard, 균형성과표), ERP (Enterprise Resource Planning, 전사적자원관리)
- OLTP (Online Transaction Processing), OLAP (Online Analytical Processing)
- EPM (Enterprise Performance Management), CPM (Corporate Performance Management)
- TDABC (Time-Driven Activity-Based Costing), ESG (Environmental, Social and Governance), Value Driver Tree (가치 트리)

## Ⅰ. SEM의 개요

- 핵심 요약 : 경영 전략 수립부터 실행·성과 평가·피드백까지를 IT와 통합해 기업 가치를 높이는 전략적 경영 관리 체계
- 개념 : **전략적 기업경영** (SEM, Strategic Enterprise Management)은 경영 전략의 수립, 실행, 성과 평가, 피드백까지의 관리 전 과정을 IT(Information Technology) 시스템과 통합해 기업 가치를 극대화하는 경영 체계
- 배경 및 필요성 : **전사적 자원관리** (ERP, Enterprise Resource Planning)는 거래 처리에 강하지만 전략 판단에 필요한 데이터가 흩어져 의사결정 비용이 커지므로, 전략 계층에서 가치·원가·성과를 통합하는 상위 관리 체계가 필요
- 주요 목적 : 주주 가치 극대화, 전략과 운영 업무의 정렬, 실시간 성과 모니터링과 전략적 자원 배분

## Ⅱ. SEM의 특징 및 장점

- 핵심 요약 : 가치 기준 경영, 활동 기준 관리, 균형 성과 관리를 전략-예산-실행으로 묶어 장기 가치 관리로 잇는 체계

1. **가치기준경영** (VBM, Value-Based Management) : EVA와 현금흐름으로 전략 대안을 기업 가치에 직접 연결 → 투자 판단 기준의 일관성 확보
2. **활동기준관리** (ABM, Activity-Based Management) : 활동별 자원 소비를 **활동기준원가** (ABC, Activity-Based Costing)로 추적 → 원가 동인 파악과 낭비 제거
3. **균형성과표** (BSC, Balanced Scorecard) : 재무·고객·내부 프로세스·학습 성장의 4관점 지표 관리 → 단기 재무 성과 편향 완화
4. 전략-예산-실행 연계 : 목표를 부서 활동과 예산에 연결 → 실행력 제고
5. ERP 데이터 활용 : 거래 데이터를 분석 지표로 전환 → 의사결정 근거 확보

## Ⅲ. SEM의 구조 (흐름)

- 핵심 요약 : 가치·활동·균형의 3대 구성 요소가 ERP 데이터를 입력받아 경영진 의사결정으로 환류하는 구조
- **온라인 트랜잭션 처리** (OLTP, Online Transaction Processing) : 거래를 건별로 처리하는 운영 계층
- **온라인 분석 처리** (OLAP, Online Analytical Processing) : 축적 데이터를 다차원으로 분석하는 전략 계층

```text
[ SEM 3대 구성 요소 ]
  VBM (가치기준경영)
     EVA, 현금흐름 기반 기업가치 평가
  ABM/ABC (활동기준관리)
     활동별 원가 추적, 낭비 제거
  BSC (균형성과표)
     재무·고객·프로세스·학습 4관점
```

```text
[ ERP → SEM 데이터 흐름 ]
ERP (거래 데이터, OLTP)
   ↓
데이터 웨어하우스·분석 계층 (OLAP)
   ↓
SEM (VBM / ABM·ABC / BSC)
   ↓
경영진 의사결정과 전략 피드백
```

## Ⅳ. ERP와 SEM의 비교

- 핵심 요약 : 운영 트랜잭션을 처리하는 ERP와 전략 분석을 담당하는 SEM은 사용자·데이터·지향점이 다른 상하 보완 관계

| 비교 항목 | ERP (전사적 자원관리) | SEM (전략적 기업경영) |
| --- | --- | --- |
| 주요 사용자 | 실무 운영자, 부서 관리자 | 최고경영진, 기획 조직, 전략 의사결정권자 |
| 시스템 성격 | 거래 중심 운영 처리 (OLTP) | 전략 분석과 의사결정 (OLAP) |
| 데이터 성격 | 정형화된 내부 상세 거래 데이터 | 요약된 재무·비재무 지표, 외부 시장·경쟁사 데이터 |
| 핵심 지향점 | 업무 프로세스 운영 효율화 | 미래 가치 창출과 전략 실행력 제고 |

## Ⅴ. SEM의 한계와 방안

- 핵심 요약 : 시스템 단절, 원가 집계 부담, 단기 재무 지표 편향을 통합 데이터와 균형 지표로 보완

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 전략·예산·운영 시스템 분리 | 목표와 실적의 식별자가 달라 성과 추적 단절 | **성과관리 통합 플랫폼** (EPM, Enterprise Performance Management)에서 목표·예산·실적을 공통 식별자로 연결 | 목표-실적 연계율 |
| 상세 원가 집계 공수 과다 | 활동별 자원 기록에 많은 공수 소요 | 핵심 활동부터 **시간 기준 활동기준원가** (TDABC, Time-Driven Activity-Based Costing)와 ERP 로그로 집계 | 원가 집계 소요 기간 |
| 단기 지표 편중 | EVA 등 단기 이익 중심 판단으로 미래 투자 위축 | BSC의 고객·학습 지표를 **가치 트리** (Value Driver Tree)와 함께 관리 | 미래 투자 비중 |

## Ⅵ. 현대적 EPM·CPM으로의 진화에 대한 기술사적 제언

- 핵심 요약 : 실시간 분석, 예측 계획, 비재무 지표 통합으로 EPM 또는 CPM(Corporate Performance Management) 체계를 고도화하는 방향

1. 실시간 전략 분석 환경 : 배치 중심 데이터 수집의 시차를 줄이기 위해 데이터 레이크하우스와 스트리밍 수집을 결합하면, 경영 시나리오를 상시 시뮬레이션할 수 있다
2. 예측적 경영 계획 : 과거 실적을 되짚는 결산 중심 계획에서 벗어나, 수요·환율·원자재 가격 변화를 머신러닝으로 예측하는 시나리오 계획으로 옮겨 가야 한다
3. 비재무 가치 통합 : 경제적 부가가치 중심의 판단에 **ESG** (Environmental, Social and Governance) 지표를 더해 지속 가능성까지 포함한 기업가치 관리로 확장해야 한다

## Ⅶ. 결론

- 핵심 요약 : SEM은 ERP 상위에서 가치·원가·성과를 전략에 묶는 경영 관리 체계
- 시사점 : 통합 EPM과 실시간 분석이 뒷받침될 때 전략이 예산과 실행으로 이어지며, 그 위에서 ESG까지 포괄하는 가치 관리가 가능해진다
