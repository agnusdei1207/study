- **개선권고** : 감리에서 식별한 위험·결함의 보완을 권고하는 의견

## 2~4교시 25점 답안

## Ⅰ. 가이드 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **지능정보기술 감리 실무 가이드** 는 빅데이터·클라우드·운영 사업의 특성을 반영한 감리 참고 지침 |
| 목적 | 기술별 점검항목을 활용한 감리의 현장 적용성 향상 |

## Ⅱ. 기술 특화 감리의 특징

| 특징 | 의미 |
|---|---|
| 분야별 선정 | 사업 범위에 맞는 빅데이터·클라우드·운영 점검항목 선택 |
| 증적 중심 | 기술별 산출물과 실제 시스템 상태의 일치 여부 확인 |
| 기존 감리 연계 | 공통 감리 절차에 기술별 점검항목 추가 |

## Ⅲ. 특화 대상과 감리 적용 체계

```text
사업 특성·위험 분석
  ├─ 빅데이터 → 처리 요구·결과·시험 증적
  ├─ 클라우드 → 목표 설계·이행 구성 증적
  └─ 운영·유지관리 → 운영 절차·변경 기록
분야별 증적 대조 → 감리 결과·조치 확인
```

> NIA가 제공하는 빅데이터·클라우드·운영·유지관리 분야의 실무 가이드 중 사업 범위에 해당하는 항목의 선택·적용

### 감리 적용 절차

> 다음 흐름은 가이드의 현장 적용을 설명하기 위한 정리이며 NIA의 공식 절차 명칭과는 구분

```text
기술·사업 특성 분석
    ↓
위험 기반 점검 설계
    ↓
현장·증적 확인
    ↓
결과 보고·후속 조치 확인
```

- 활동: 사업유형·범위 파악 → 관련 특화 항목 선정 → 기준·산출물·현장 상태 대조 → 발견사항 보고 및 후속 조치 확인
- 산출: 범위·중점사항 → 감리계획서 → 실사 기록 → 감리보고서

## Ⅳ. 분야별 점검과 기존 감리의 관계

| 점검 분야 | 검토 대상 | 확인자료 예 |
|---|---|---|
| 빅데이터 | 데이터 처리 결과와 사업 요구의 일치 여부 | 요구사항, 데이터 처리 산출물, 시험결과 |
| 클라우드 | 목표 구성과 실제 이행 구성의 일치 여부 | 설계서, 이행기록, 구성정보 |
| 운영·유지관리 | 운영 절차·기록과 실제 서비스의 일치 여부 | 운영절차, 변경·장애 기록 |

### 기존 감리와 연계

> 기존 감리기준의 공통 절차와 기술 특화 점검표를 결합한 일관된 점검

| 기준 | 기존 감리기준 | 실무 가이드 |
|---|---|---|
| 역할 | 공통 절차·점검체계 | 기술별 점검항목 보완 |
| 적용 | 사업유형·감리시점 | 빅데이터·클라우드·운영 특성 |
| 활용 | 기본점검표 구성 | 중점항목·증적 구체화 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 전 항목 기계 적용 | 사업 위험에 따라 점검항목을 선정하고 핵심 위험부터 확인 |
| 문서 위주 확인 | 사업 산출물과 현장 상태를 대조해 실제 운영과의 차이 확인 |
| 기술별 사일로 점검 | 데이터·서비스·운영의 연결 지점까지 추적 |
| 권고 후 미조치 | 조치 책임·기한을 지정하고 완료 여부 재확인 |

## Ⅵ. 제언

- 감리계획서에 특화 항목의 선정 이유·확인 증적·조치 재확인 책임을 함께 기록하고 현장 실사에서 우선 검증
