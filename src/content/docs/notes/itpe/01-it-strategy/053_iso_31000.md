## 연관 키워드

- ISO 31000, 위험(risk), 위험관리 원칙, 프레임워크
- 위험관리 프로세스, 위험평가, 위험처리, 잔여위험, 위험선호

## Ⅰ. ISO 31000의 개요

- 핵심 요약 : 불확실성이 목표에 미치는 영향을 전사 체계로 관리하도록 원칙·체계·절차를 제시하는 국제 지침 표준.
- 개념 : 국제표준화기구(ISO, International Organization for Standardization)의 위험관리 지침 표준인 **ISO 31000** (Risk Management — Guidelines)은 목표 달성에 영향을 주는 불확실성인 **위험**(risk)을 공통 원칙과 절차로 관리하도록 안내하는 표준.
- 배경 및 필요성 : 2009년 첫 발행 후 2018년 개정. 부서별 임의 관행은 용어·방법·책임의 비일관성으로 위험정보의 비교·의사결정 반영이 곤란 → 공통 원칙과 절차의 필요.
- 주요 목적 : 위험관리의 전략·운영·의사결정 통합을 통한 가치 창출·보호와 조직 성과 개선.

## Ⅱ. ISO 31000의 특징 및 장점

- 핵심 요약 : 지침 표준의 맞춤 적용성과 원칙-체계-절차의 3층 구조가 조직 상황에 맞는 위험관리 확산을 지원.

1. 8대 **위험관리 원칙**(위험관리의 성격과 가치를 규정하는 기본 원칙) : 통합·구조화·맞춤형·포용·동적·최선 정보·인적·문화적 요인·지속 개선 → 위험관리의 조직 문화·의사결정 내재화.
2. 지침 표준 성격 : 인증 심사를 위한 표준이 아닌 가이드라인 → 조직 규모·산업·위험 유형에 따른 자율·맞춤 적용.
3. 3층 구조 : 조직 차원의 **프레임워크**(위험관리의 거버넌스·운영 틀)와 활동 차원의 **위험관리 프로세스**(위험을 평가·대응하는 절차)의 분리 → 경영 체계와 실무 절차의 정합.
4. 의사소통·모니터링 내재화 : 협의·기록·검토의 프로세스 전반 배치 → 위험 정보의 지속 갱신과 이해관계자 신뢰 확보.

## Ⅲ. ISO 31000의 구조 (흐름)

- 핵심 요약 : 원칙을 최상층으로 프레임워크가 조직 기반을, 프로세스가 실무 절차를 담당하는 3층 구조.

프로세스의 **위험평가**(위험 식별·분석·평가의 종합 과정)와 **위험처리**(회피·저감·이전·수용 등의 대응 선택)가 판단의 축.

```text
[ ISO 31000 3층 구조 ]

위험관리 원칙 (8개)
   ↓
프레임워크
  리더십·약속 · 통합
  설계 · 이행 · 평가 · 개선
   ↓
위험관리 프로세스
```

```text
[ 위험관리 프로세스 ]

의사소통·협의 (전 단계)
   ↓
범위·맥락·기준 설정
   ↓
위험평가 : 식별 → 분석 → 평가
   ↓
위험처리
   ↓
모니터링·검토 / 기록·보고
```

## Ⅳ. ISO 31000과 내부 임의 위험관리 관행의 비교

- 핵심 요약 : 임의 관행이 경험·부서 단위의 사후 대응인 반면, ISO 31000 기반 관리는 공통 기준에 따른 전사·사전 관리.

| 비교 축 | ISO 31000 기반 위험관리 | 내부 임의 위험관리 관행 |
| --- | --- | --- |
| 기준·용어 | 표준의 공통 원칙·용어 | 부서별 관습적 정의 |
| 적용 범위 | 전략·운영·프로젝트 전 영역 | 사고·손실 중심의 일부 영역 |
| 책임 체계 | 위험 소유자·보고선의 명시 | 담당 불명확, 사후 대응 |
| 판단 절차 | 맥락 기준에 따른 평가·대응 | 담당자 경험·직관 의존 |
| 개선 구조 | 모니터링·검토 기반 지속 개선 | 사고 발생 시 일회성 점검 |

## Ⅴ. ISO 31000 적용의 한계와 방안

- 핵심 요약 : 비강제성에 따른 형식화·평가 편향·잔여위험 누락을 경영 의제화·공통 척도·재평가 절차로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 형식적 문서화 | 지침 표준의 비강제성 → 목록 작성으로 그침 | 경영 회의 상설 의제화·내부 점검 주기 운영 | 의제 채택률 |
| 평가 편향 | 확률·영향 척도의 해석 차이 → 우선순위 왜곡 | 공통 척도·근거 기재·교차 검토 | 척도 불일치 건수 |
| 잔여위험 누락 | 처리 후 재평가 생략 → 무인정 위험 축적 | **잔여위험**(위험처리 후 남아 있는 위험)의 재평가·수용 승인 | 미승인 잔여위험 수 |

## Ⅵ. ISO 31000 적용에 대한 기술사적 제언

- 핵심 요약 : 이사회·경영진이 위험선호·수용기준을 정례 의사결정 체계에 통합하는 거버넌스 구축 필요.
- 거버넌스 : 이사회·경영진이 **위험선호**(조직이 의도적으로 감수할 위험의 성격·범위)와 수용기준을 승인하고 보고선 운영.
- 통합 : 사업계획·예산·성과 평가 절차에 위험평가 결과의 입력 요건화.
- 역량 : 전사 교육과 위험관리 담당자 네트워크로 공통 언어·문화 정착.

## Ⅶ. 결론

- 핵심 요약 : ISO 31000은 위험을 목표와 연결된 불확실성 문제로 보고 전사 체계로 관리하도록 안내하는 국제 지침.
- 표준의 가치는 문서가 아닌 의사결정 습관의 변화에서 나옴.
