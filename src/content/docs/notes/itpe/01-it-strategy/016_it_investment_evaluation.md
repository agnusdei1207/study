## 지식 로드맵 내 현재 위치

IT 전략·관리 → 투자·포트폴리오 관리 → **IT 투자평가·투자관리**

## 30초 인출

- 본질: IT 투자평가·투자관리는 IT 투자의 위험과 수익을 분석해 선정하고, 집행 중 통제하며, 완료 후 기대와 실제를 비교하는 관리 활동
- 메커니즘: Select에서 위험·수익 분석으로 투자를 선택하고, Control에서 비용·위험 수준을 확인하며, Evaluate에서 실제 결과와 기대 결과를 비교해 교훈을 다음 투자에 반영
- 통찰: 승인 때 추정한 편익에 비교할 기준이 없으면 사후에 실적을 검증할 수 없으므로 승인 시점에 편익별 기준선·목표·측정 시점과 사후 검토 시점을 함께 확정

<details>
<summary>핵심 용어</summary>

- **IT 투자관리(IT Investment Management)** : IT 투자를 선정(Select)·통제(Control)·평가(Evaluate)하는 순환 관리 방식
- **Select(선정)** : 투자 전에 사업별 위험과 수익을 분석하고 임무를 가장 잘 지원할 사업을 고르는 단계
- **Control(통제)** : 집행 중 사업이 기대한 비용·위험 수준에서 필요를 충족하는지 확인하는 단계
- **Evaluate(평가)** : 사업 완료 후 실제 결과와 기대 결과를 비교하는 단계
- **편익(Benefit)** : 투자로 얻는 유익한 변화. 매출 증가·비용 절감 같은 재무 편익과 시간 단축·품질 향상 같은 비재무 편익을 포함하며, 매출에서 비용을 뺀 회계상 이익과 구별
- **기준선(Baseline)** : 투자 전에 측정해 둔 비용·업무 성과의 비교 기준값
- **NPV(Net Present Value)** : 예상 순편익(편익에서 비용을 뺀 값)을 할인해 현재 화폐 가치로 나타낸 값
- **IRR(Internal Rate of Return)** : NPV를 0으로 만드는 할인율
- **ROI(Return on Investment)** : 투자 대비 이익의 비율
- **회수기간(Payback Period)** : 초기 투자비를 회수하는 데 걸리는 기간
- **민감도 분석(Sensitivity Analysis)** : 주요 가정을 바꿔 가며 NPV 등 결과가 얼마나 달라지는지 확인하는 분석
- **사후 평가(Postimplementation Review)** : 구현 완료 후 사업 결과를 검토하는 활동

</details>

## 2~4교시 25점 답안

## Ⅰ. IT 투자평가·투자관리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **IT 투자관리** 는 IT 투자의 위험과 수익을 분석해 선정하고, 집행 중 통제하며, 완료 후 기대와 실제를 비교하는 관리 활동 |
| 목적 | 투자 성과의 검증과 이후 투자 판단의 개선 |

## Ⅱ. 추정에서 검증으로 이어지는 IT 투자평가의 특징

| 특징 | 의미 |
|---|---|
| 위험과 수익의 동시 분석 | 투자 전에 각 사업의 위험과 수익을 함께 분석해 선정 |
| 추정과 판단의 분리 | 예상 비용·편익은 가정해 추정하고, 타당성은 그 추정과 위험을 근거로 검토한 결론 |
| 재무·비재무 편익 포함 | 금액으로 측정하는 매출 증가·비용 절감과 시간 단축·품질 향상까지 편익에 포함 |
| 사후 비교 | 완료 후 실제 결과를 기대 결과와 대조해 이후 투자에 반영 |

## Ⅲ. 선정·통제·평가의 투자관리 체계

```text
Select ── 위험·수익 분석 후 투자 선택 (사전 평가)
    ↓
Control ── 비용·위험이 기대 수준인지 확인 (집행 중)
    ↓
Evaluate ── 실제 결과와 기대 결과 비교 (사후 평가)
    ↓
교훈을 투자 절차에 반영 → 다음 Select
```

### 사전 평가 확대: 추정 입력에서 타당성 판단까지

```text
추정 입력
    ├─ 예상 비용
    ├─ 예상 편익 (재무 · 비재무)
    └─ 위험과 가정
    ↓
재무 지표 계산: NPV · IRR · ROI · 회수기간
    ↓
민감도 분석: 가정을 바꿔 결과 변동 확인
    ↓
타당성 판단: 추정과 위험을 근거로 한 검토 결론
```

## Ⅳ. 재무 평가 지표 비교

| 지표 | 나타내는 것 | 판단 방식 | 유의점 |
|---|---|---|---|
| **NPV** | 예상 순편익의 현재 가치 | 양수면 선호, 음수면 회피 | 할인율·가정에 따라 값이 변동 |
| **IRR** | NPV를 0으로 만드는 할인율 | 예산 제약이나 할인율 불확실성이 있을 때 참고 | 단독 판단 기준으로는 부족, 순편익이 음·양을 오가면 값이 여럿 |
| **ROI** | 투자 대비 이익 비율 | 투자 규모가 다른 사업의 수익률 비교 | 이익이 발생하는 시점은 나타내지 않음 |
| **회수기간** | 초기 투자비 회수 소요 기간 | 기준 기간 이내 회수 여부 | 회수 이후의 편익은 반영하지 않음 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 시간 단축·품질 향상 같은 비재무 편익은 화폐로 환산하기 어려워 재무 지표에서 빠짐 | 금액으로 환산하지 않고 편익 유형을 나열하며 기준선·목표·측정 시점으로 물리적 수치 명시 |
| 추정 비용·편익이 가정에 민감해 NPV 등 지표가 크게 흔들림 | 주요 가정을 바꿔 결과를 다시 계산하는 민감도 분석 수행 |
| 승인 후 실적과 비교할 기준이 남지 않아 Evaluate 단계에서 성과 검증 불가 | 승인 시점에 편익별 기준선·목표와 사후 검토 시점을 기록하고 사후 평가에서 대조 |

## Ⅵ. 제언

투자 승인 시점에 편익별 기준선·목표·측정 시점과 사후 검토 시점을 함께 확정하고, Evaluate 단계에서 그 기록과 실적을 대조

### 승인에서 사후 검토까지의 기록 흐름

```text
투자 승인 시점
    ├─ 편익 항목별 기준선·목표·측정 시점 확정
    └─ 사후 검토 시점 확정
    ↓
집행 (Control): 비용·위험 수준 확인
    ↓
사후 검토 (Evaluate): 승인 기록 대비 실적 비교
    ├─ 목표 충족 → 교훈 기록
    └─ 목표 미달 → 원인 분석 후 다음 투자의 추정 방식 보정
```

### 편익 기록 확대: 재무·비재무 구분

```text
편익 항목
    │
    ├─ 재무 편익 ── 매출 증가 · 비용 절감: 금액 추정과 산출 근거
    │
    └─ 비재무 편익 ── 시간 단축 · 품질 향상: 기준선·목표·측정 시점 (금액 환산 없음)
```

| 구분 | 실적을 사후에 재구성 | 제언: 승인 시 기준 확정 |
|---|---|---|
| 비교 기준 | 종료 후 가용한 자료 | 승인 시점의 기준선·목표 |
| 비재무 편익 | 근거 없는 금액 환산 | 기준선·목표·측정 시점으로 확인 |
| 사후 검토 시점 | 미정 | 승인 시 확정 |

## 출제 이력과 검증 출처

- 제132~140회 정보관리기술사 공식 문제지에서 IT 투자평가를 직접 묻는 문항 없음
- GAO, Information Technology Investment Management: A Framework for Assessing and Improving Process Maturity (GAO-04-394G, 2004) — Select·Control·Evaluate 단계
- OMB Circular A-94 — NPV·IRR 정의와 민감도 분석, 화폐 환산이 어려운 편익의 처리
