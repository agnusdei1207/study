## 지식 로드맵 내 현재 위치

IT 전략·관리 → 투자·포트폴리오 관리 → **IT 투자평가·투자관리**

## 30초 인출

- 본질: IT 투자평가는 IT 투자의 비용·편익·위험을 비교해 투자 여부를 정하고 집행 후 실제 성과를 확인하는 투자관리 활동
- 메커니즘: 사전 평가에서 추정한 비용·편익으로 타당성을 판단하고, 중간 평가로 집행을 통제하며, 사후 평가로 승인 가정과 실적을 대조
- 통찰: 편익 측정 책임자가 없으면 추정 편익이 검증되지 않으므로 승인 시 편익 책임자·기준선 확정과 BRR 수행

<details>
<summary>핵심 용어</summary>

- **IT 투자평가** : IT 투자의 비용·편익·위험을 사전·중간·사후에 걸쳐 비교하고 투자 결정과 성과 확인에 쓰는 투자관리 활동
- **편익(Benefit)** : 투자로 얻는 유익한 변화. 매출 증가·비용 절감 같은 재무 편익과 처리시간 단축·품질 향상 같은 비재무 편익을 포함하며, 매출에서 비용을 뺀 회계상 이익과 구별
- **기준선(Baseline)** : 투자 전 비용·업무 성과를 측정해 둔 비교 기준값
- **TCO(Total Cost of Ownership)** : 구축·운영·유지보수·전환·폐기까지 수명주기 전체의 직·간접 비용 합계
- **ROI(Return on Investment)** : 투자비 대비 금전 순편익의 비율. 편익 발생 시점 차이는 반영하지 않는 수익성 지표
- **NPV(Net Present Value)** : 미래 현금 유입·유출을 할인율로 현재가치화한 뒤 차감한 순현재가치
- **IRR(Internal Rate of Return)** : NPV를 0으로 만드는 할인율로, 요구수익률과 비교하는 내부수익률
- **EVM(Earned Value Management)** : 계획 가치·획득 가치·실제 원가를 비교해 사업 일정·원가 편차를 측정하는 기법
- **IT-BSC(IT Balanced Scorecard)** : 기업 공헌·사용자·운영 우수성·미래지향 관점으로 IT 성과를 보는 균형성과표
- **BRR(Benefits Realization Review, 편익 실현 검토)** : 운영 안정화 뒤 승인 당시 계획 편익과 실제 성과를 비교하고 차이를 분석하는 사후 검토
- **Val IT** : IT 투자의 가치 거버넌스·포트폴리오 관리·투자 관리를 다룬 ISACA의 프레임워크

</details>

## 2~4교시 25점 답안

## Ⅰ. IT 투자평가의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **IT 투자평가** 는 IT 투자의 비용·편익·위험을 비교해 투자 결정과 집행 후 성과 확인에 쓰는 투자관리 활동 |
| 목적 | 한정된 IT 예산의 투자 우선순위 결정과 실현 편익의 확인 |

## Ⅱ. 단순 예산 심의와 구별되는 IT 투자평가의 특징

| 특징 | 의미 |
|---|---|
| 생애주기 평가 | 승인 전 타당성, 집행 중 통제, 운영 후 편익 확인의 연속 |
| 동일 조건 비교 | 대안별 기간·서비스 수준·비용 범위를 맞춘 비교 |
| 재무·비재무 병행 | 금액 편익과 처리시간·품질 같은 비재무 편익의 구분 평가 |
| 추정과 판단의 분리 | 비용·편익은 가정에 따른 추정, 타당성은 추정과 위험을 근거로 한 결론 |

## Ⅲ. IT 투자평가 절차와 사전 평가의 판단 흐름

### IT 투자평가 생애주기

```text
사전 평가: 비용·편익 추정과 타당성 판단 → 투자 승인
    ↓
중간 평가: EVM 등으로 집행·위험 점검 → 계속·조정·중단 결정
    ↓
사후 평가: 실제 편익·운영비 측정 → 승인 가정과 대조
    ↓
다음 투자의 우선순위·추정 기준에 반영
```

### 사전 평가 확대: 추정 입력에서 타당성 판단까지

```text
대안별 비용 추정: 구축·운영·전환·폐기의 TCO
    ↓
편익 추정: 재무 편익 금액, 비재무 편익의 기준선·목표
    ↓
평가 기법 적용: NPV·IRR·비재무 지표
    ↓
위험·민감도 반영 후 타당성 판단
    ├─ 충족 → 투자 승인
    └─ 미충족 → 보류 또는 대안 재설계
```

## Ⅳ. 평가 기법 비교

| 기법 | 측정 대상 | 판정 기준 | 적합 조건 |
|---|---|---|---|
| **TCO** | 수명주기 총비용 | 동일 기간·서비스 수준에서 낮은 대안 | 편익이 비슷한 대안 간 비용 비교 |
| **ROI** | 투자비 대비 금전 순편익 | 비율이 높은 대안 | 회수 시점이 비슷한 대안 |
| **NPV** | 할인한 현금흐름의 순가치 | 0보다 큰 투자 | 현금흐름 시점이 다른 대안 |
| **IRR** | NPV가 0이 되는 할인율 | 요구수익률보다 큰 투자 | 통상적 투자 현금흐름 |
| **IT-BSC** 등 비재무 지표 | 전략 정렬·사용자·운영 성과 | 기준선 대비 목표 달성 | 금액 환산이 어려운 편익 |

재무 기법은 편익 가정이 금액으로 측정될 때만 유효하며, 비재무 편익은 근거 없는 금액 합산 대신 기준선·목표·측정 시점으로 평가

## Ⅴ. IT 투자평가의 한계와 방안

| 한계 | 방안 |
|---|---|
| 구축비만 비교해 운영비 과소 추정 | 운영·전환·폐기 비용까지 포함한 TCO의 동일 기간 비교 |
| 회수 시점이 다른 대안의 ROI 단순 비교 | 현금흐름 시점이 다르면 NPV로 할인 비교 |
| 비재무 편익의 근거 없는 금액 환산 | 금액 합산 대신 기준선·목표·측정 시점을 둔 비재무 지표 평가 |
| 승인 후 편익 미측정으로 추정 가정 미검증 | 편익 책임자·측정 시점 지정과 **BRR** 수행 |

## Ⅵ. 제언

승인 단계에서 편익 책임자·기준선·측정 시점을 확정하고, BRR 결과를 다음 투자 심의의 추정 기준으로 반영

### 편익 실현 책임 구조

```text
편익 실현 관리
    │
    ├─ 투자심의 조직 ── 투자 승인·후속 투자 결정
    │
    ├─ 편익 책임자(현업) ── 기준선·목표 설정과 실측
    │
    └─ 사업 수행 조직 ── 산출물 인도·운영 이관
```

### 편익 책임자 역할 확대: BRR 절차

```text
운영 안정화 후 약정한 측정 시점 도래
    ↓
승인 당시 기준선·목표와 실측 편익 대조
    ↓
차이 원인 분석
    ├─ 목표 충족 → 추정 기준 유지
    └─ 목표 미달 → 개선 조치 또는 추정 기준 수정
    ↓
다음 투자 심의 자료에 반영
```

### 선택 근거: 승인 중심 평가와의 비교

| 구분 | 승인 중심 평가 | 제언: 편익 실현 관리 |
|---|---|---|
| 평가 종료 시점 | 투자 승인 | 운영 후 BRR 완료 |
| 편익 책임 | 사업 제안 부서의 추정으로 종료 | 현업 편익 책임자의 실측 책임 |
| 비재무 편익 처리 | 금액 환산 후 합산 | 기준선·목표·측정 시점으로 확인 |
| 다음 투자 반영 | 과거 추정의 반복 사용 | 실측 차이에 따른 추정 기준 수정 |
