- 과목 내 위치: `경영목표 → 투자평가·포트폴리오 → 사업 실행 → 편익 실현·환류`

## 예상문제

> IT 투자평가의 개념과 생애주기·평가기법을 설명하고 정량·정성평가를 비교한 후 기대편익 실현을 위한 관리방안을 제시하시오. (25점)

```text
 ┣━ Ⅱ 특징 ───── 생애주기 평가(사전·중간·사후) · 재무적/비재무적 가치 종합 · TCO 관점 반영 · 지속적 피드백

 ┣━ Ⅴ 비교 ───── 정량적 재무평가(ROI, NPV, IRR) vs 종합 다차원평가(IT-BSC, Val IT)
 ┗━ Ⅵ 실무 ───── 무형의 가치(브랜드, 고객만족) 산정 곤란 / 사후 평가 미수행으로 인한 환류 부재 / TCO 숨은 비용 누락
```

## 한 줄 본질
- IT 투자 증가가 자동으로 경영성과 향상으로 이어지지 않는 생산성의 역설 → 사전 타당성, 중간 실행통제, 사후 비즈니스 가치를 전 생애주기 동안 측정·관리 → 자본 배분 효율화와 편익 실현 / 무형효과의 화폐가치 환산 한계

## 핵심 그림
```text
┌──────────────────────────────── [ IT 투자평가 생애주기 3단계 프레임워크 ] ────────────────────────────────┐
│                                                                                                          │
│   [ 1. 사전 평가 (Ex-ante) ]            [ 2. 중간 평가 (In-itinere) ]           [ 3. 사후 평가 (Ex-post) ]       │
│   "과연 투자할 가치가 있는가?"           "계획대로 구축되고 있는가?"             "기대했던 성과를 달성했는가?"    │
│                                                                                                          │
│   - 비용: TCO(총소유비용) 산출          - 공정 진척도 점검                     - 실제 재무적 ROI 측정           │
│   - 재무: NPV, IRR, 회수기간(PP)        - 원가/일정 성과(EVM: CPI, SPI)         - IT-BSC 4대 관점 성과 분석      │
│   - 정성: 비즈니스 정합성, AHP          - 지속 추진 여부(Go/No-Go) 판정         - 차기 IT 투자 의사결정에 환류   │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 핵심 용어
- IT 생산성의 역설(Productivity Paradox): 노벨경제학상 수상자 로버트 솔로(Robert Solow)가 제기한 가설로, 막대한 컴퓨터 및 IT 설비 투자에도 불구하고 거시 경제의 생산성 증가율은 둔화되는 현상
- TCO(Total Cost of Ownership): 시스템 도입 시 발생하는 초기 구매 비용(CAPEX)뿐만 아니라 향후 수년간의 유지보수, 교육, 마이그레이션, 장애 복구 등 운영 비용(OPEX) 전체를 합산한 총소유비용
- Val IT: ISACA가 개발한 IT 투자 가치 거버넌스 프레임워크로 가치 거버넌스(VG), 포트폴리오 관리(PM), 투자 관리(IM) 3대 도메인으로 구성

## 핵심 통찰
- IT 투자평가가 실패하는 가장 큰 이유는 '사후 평가의 부재'에 있음 → 사전 평가 때는 온갖 화려한 수치로 승인을 받아내고, 시스템 오픈 후에는 아무도 ROI 달성 여부를 검증하지 않음
- 클라우드 환경에서는 초기 투자비(CAPEX) 중심의 전통적 NPV/IRR 분석이 무력화되며, 매월 발생하는 운영비(OPEX)를 지속 최적화하는 FinOps형 지속 평가 체계가 필수적임
- 정량화하기 힘든 정성적 효과(예: 보안 사고 예방, 사용자 경험 개선)를 억지로 화폐 가치로 위장하기보다, IT-BSC와 같은 다차원 지표로 정직하게 경영진을 설득해야 함

## 딸려 나오는 하위 토픽

| 하위 토픽 | 상위 구조 속 위치 | 한 줄 (정의 → 메커니즘 → 구분축) |
|---|---|---|
| IT 투자관리(ITIM) | Ⅳ 프로세스 / 전주기 의사결정 | IT 투자의 기획(Select), 집행 및 공정 통제(Control), 도입 후 사후 운영 평가(Evaluate) 전주기를 관리하여 IT 생산성 역설을 극복하는 거버넌스 프레임워크 (단발성 예산 심의 vs Select-Control-Evaluate 전주기 순환 관리) |
| IT 투자분석 | Ⅲ 구조 / 분석 기법 | 초기 구축비뿐 아니라 생애주기 총소유비용(TCO)과 시간 가치를 반영한 할인현금흐름(NPV, IRR, ROI)을 산출하여 사업 타당성을 과학적으로 입증하는 재무·정량 분석 기법 (단순 초기 구축비 견적 vs 생애주기 TCO 및 할인현금흐름 분석) |
| IT-ROI 투자 성과평가 모델 | Ⅴ 비교 / 성과 측정 모델 | 정보시스템 도입으로 인한 직접적 재무 이익뿐만 아니라 프로세스 개선, 사용자 만족도 등 유·무형의 비즈니스 가치를 다차원 계량화하여 투자 효과를 입증하는 성과 평가 모델 (단순 재무 회계 지표 vs 유무형 다차원 가치 IT-ROI 모델) |

## 이웃 토픽과 구분
- IT-ROI vs IT-BSC: IT-ROI = 순수 재무적 관점에서 투입 비용 대비 회수 이익의 비율만 측정 / IT-BSC = 재무뿐만 아니라 고객, 내부 프로세스, 미래 학습·성장의 4대 관점에서 다차원적으로 평가

## 문제·원인·대책
- 사례: 125회·129회 기출 전사 빅데이터 플랫폼 구축에 50억 원을 투자했으나, 사용률 저조 및 비즈니스 성과 증빙 실패로 프로젝트가 실패 판정된 사례
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 소프트웨어 도입 후 실제 활용률 저조 및 방치 | 구축 자체에만 집중하고 업무 프로세스 혁신(BPR) 및 교육 누락 | 사후 평가 항목에 실사용자 활성 이용률(MAU) 및 업무 처리 시간 감축률 의무 반영 | 시스템 활용도 강제 제고 |
| 인프라 유지보수 및 클라우드 숨은 비용 폭증 | 초기 라이선스 구매비만 고려하고 운영 TCO 과소평가 | 5개년 TCO 산정 모델 도입(인건비, 클라우드 트래픽비, 버전 업그레이드 비용 전수 포함) | 현실적인 총소요예산 산정 |

## 이렇게 출제된다
- 예상문제: "IT 투자평가의 생애주기와 정량·정성 평가기법을 설명하시오." → 요구 포인트: Ⅲ 생애주기별(사전·중간·사후) 평가 기법 + 재무적 기법(NPV, IRR)과 정성적 기법(BSC) 비교
- 예상문제: "IT 투자분석의 프로세스, 프레임워크와 분석방법을 설명하시오." → 요구 포인트: Ⅳ 분석 프로세스 + Ⅲ Val IT·TCO 프레임워크

## 내 의견
- [사전 승인에서 편익 실현 추적으로 전환] 승인 시 산정한 편익이 운영 이후 검증되지 않으면 낙관 편향과 반복 투자를 통제할 수 없음 → 나라면: 편익별 책임자·기준선·목표·측정주기를 확정하고 운영 데이터로 사후 검증하여 포트폴리오 재투자·중단 의사결정에 환류

## Ⅰ. IT 자본배분과 편익 실현을 검증하는 투자평가 개요

- 정의: **IT 투자평가**는 정보화 투자안의 비용·편익·위험·전략 적합성을 사전·중간·사후에 분석하여 승인·조정·중단·성과환류를 지원하는 의사결정 활동
- 목적: 한정된 자원을 가치가 높은 과제에 배분하고, 구축 완료가 아니라 실제 업무·고객 성과의 실현까지 책임
- 원칙: 정량 재무성과와 정성·공공·위험 가치를 함께 평가하고 가정·불확실성을 명시

## Ⅱ. 생애주기·다기준·책임성 중심의 특징

| 특징 | 내용 | 효과 |
|---|---|---|
| **생애주기 평가** | 사전·중간·사후 평가 연계 | 승인 가정을 실행·성과와 비교 |
| **다기준 평가** | 재무·전략·위험·규제·공공가치 종합 | 단일 ROI 편향 완화 |
| **TCO 관점** | 구축·운영·전환·종료 비용 포함 | 숨은 비용 누락 방지 |
| **편익 책임** | 편익별 소유자·기준선·측정주기 지정 | 사후 성과 실현 강화 |
| **포트폴리오 관점** | 과제 간 의존성·중복·자원경합 고려 | 전사 가치 최적화 |

## Ⅲ. 사전·중간·사후 평가 구조

```text
[사전] 타당성·대안·우선순위·TCO·위험
   │ 승인 기준선: 비용·편익·KPI·책임자
   ▼
[중간] 범위·일정·원가·품질·위험·전망
   │ 계속 / 조정 / 중단
   ▼
[사후] 산출물 활용·업무성과·편익·교훈
   └──────── 포트폴리오 기준 환류 ───────┐
```

| 단계 | 주요 질문 | 대표 기법 |
|---|---|---|
| **사전** | 투자할 가치와 최적 대안은 무엇인가 | NPV·IRR·ROI·TCO·AHP·BSC |
| **중간** | 기준선대로 가치가 실현될 가능성이 있는가 | EVM·예측·위험·게이트 리뷰 |
| **사후** | 실제 편익과 잔여비용은 무엇인가 | KPI·편익실현·TCO 실적·교훈 |

## Ⅳ. 투자 제안에서 편익 환류까지의 절차

```text
① 전략목표·문제·대안 정의
 → ② 비용·편익·위험·가정·TCO 추정
 → ③ 재무·정성 다기준 평가와 민감도 분석
 → ④ 포트폴리오 우선순위·승인·기준선 확정
 → ⑤ 실행 중 전망·위험·가치 게이트 검토
 → ⑥ 운영 후 편익 실측·차이 원인분석
 → ⑦ 확대·개선·중단과 평가기준 환류
```

## Ⅴ. 정량·정성 평가기법 비교

| 기법 | 판단 내용 | 강점 | 한계 |
|---|---|---|---|
| **NPV** | 할인한 현금흐름의 순가치 | 시간가치 반영 | 할인율·편익 추정 민감 |
| **IRR** | NPV가 0이 되는 수익률 | 수익률 비교 용이 | 복수해·상호배타안 한계 가능 |
| **ROI** | 투자 대비 순편익 비율 | 이해·비교 용이 | 시점·위험 반영 부족 |
| **TCO** | 생애주기 총비용 | 숨은 운영·전환비용 반영 | 편익 자체는 설명하지 않음 |
| **BSC/AHP** | 전략·고객·운영·학습 및 다기준 우선순위 | 무형가치 반영 | 평가자 판단·가중치 영향 |

## Ⅵ. 낙관 편향과 편익 미실현의 통제

| 문제 | 원인 | 대책 | 검증지표 |
|---|---|---|---|
| **비용 과소평가** | 운영·전환·종료비 누락 | TCO와 범위별 가정·예비비 명시 | 기준선-실적·전망 차이 |
| **편익 과대평가** | 기준선·소유자·측정식 부재 | 편익등록부와 업무책임자 지정 | 실현 편익률 |
| **매몰비용 지속** | 중단 기준·독립 게이트 부재 | 재평가·중단 임계치 사전 합의 | 중단·전환 의사결정시간 |
| **정성가치 자의성** | 가중치·평가근거 불투명 | 기준·가중치·증빙과 민감도 공개 | 평가자 편차 |
| **사후평가 부재** | 프로젝트 종료가 성공으로 간주 | 운영 이후 편익 검토와 포트폴리오 환류 | 사후평가·개선 완료율 |

## Ⅶ. 구축 완료보다 편익 실현을 책임지는 결론

- IT 투자평가는 승인용 계산서가 아니라 **전략목표-투자-실행-편익**의 추적 체계
- 정량·정성 평가와 민감도 분석을 결합하고 편익 책임자·사후평가를 통해 확대·개선·중단 결정을 포트폴리오에 환류해야 함

```text
사후: KPI·편익실현·교훈 → 포트폴리오 환류
```
