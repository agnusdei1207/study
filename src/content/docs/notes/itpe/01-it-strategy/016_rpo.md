## 연관 키워드

- RTO, RPO, BIA, 재해복구 목표
- 데이터 손실 허용 기준, 백업 주기, 복제 방식

## Ⅰ. RTO·RPO의 개요

- 핵심 요약 : 업무 중단의 허용 시간인 RTO와 데이터 손실의 허용 시점인 RPO로 재해복구의 목표 수준을 수치화하는 기준 지표.
- 개념 : **복구시간목표** (RTO, Recovery Time Objective)는 장애·재해로 중단된 업무 서비스의 복구 완료까지 허용되는 목표 시간이고, **복구시점목표** (RPO, Recovery Point Objective)는 장애 발생 시점을 기준으로 과거 방향으로 허용되는 데이터 손실의 시점 기준.
- 배경 및 필요성 : 재해·랜섬웨어·시스템 장애 상황에서 업무별 중단 영향과 데이터 재구성 가능성이 서로 달라, 목표 기준 없이는 복구 자원·백업 체계의 설계 수준을 정할 수 없는 구조.
- 주요 목적 : 업무 영향 분석에 근거한 복구 기준 수립으로 중단 손실과 데이터 손실의 제한, 업무 연속성과 데이터 자산의 보전.

## Ⅱ. RTO·RPO의 특징 및 장점

- 핵심 요약 : 업무 영향 기반의 목표 산정, 복구 설계의 기준점, 준비도 측정과 위험 수용 판단의 근거로 복구 의사결정의 객관성 확보.

1. 업무 영향 기반의 목표 산정 : **BIA**(Business Impact Analysis, 업무 영향 분석)로 업무별 허용 중단 시간과 데이터 손실 허용 기준을 산정 → 시스템별 차등의 재해복구 목표.
2. 복구 설계의 기준점 : RTO는 복구 자원·대체 인프라·복구 절차의 수준 기준이 되고, RPO는 백업 주기와 복제 방식(동기·비동기)의 선택 기준이 됨 → 목표와 설계의 정합성 확보.
3. 복구 준비도의 측정 기준 : 복구 시험·훈련의 실측 결과를 목표와 비교 → 복구 역량의 객관적 평가와 격차 관리.
4. 위험 수용 판단의 근거 : 목표 달성 비용과 중단·손실 발생 비용의 비교로 보호 수준 결정 → 과잉·과소 투자 방지.

## Ⅲ. RTO·RPO의 구조 (흐름)

- 핵심 요약 : 업무 영향 분석에서 목표 합의·설계·시험·개선으로 이어지는 운영 흐름과 시간축 위의 두 지표의 위치.

```text
업무 영향 분석 (BIA)
   ↓
업무별 RTO·RPO 목표 합의
   ↓
백업 주기·복제 방식·대체 인프라 설계
   ↓
복구 시험·훈련
   ↓
목표 대비 격차 개선
```

```text
[ 시간축 위의 두 지표 ]

정상 · 백업 · 장애 발생 · 복구 완료 (시간 순)

백업 시점 → 장애 발생 : 데이터 유실 구간 (RPO)
장애 발생 → 복구 완료 : 업무 중단 구간 (RTO)
```

## Ⅳ. RTO와 RPO의 비교

- 핵심 요약 : RTO가 복구에 걸리는 시간의 목표인 반면 RPO는 손실을 허용하는 데이터의 시점 목표로, 같은 재해복구 체계 안에서 서로 다른 축을 측정하는 쌍둥이 지표.

| 비교 축 | RTO | RPO |
| --- | --- | --- |
| 측정 대상 | 서비스 복구 소요 시간 | 데이터 손실 허용 시점 |
| 핵심 질문 | 언제까지 서비스 복구가 가능한가 | 어느 시점까지 데이터 보전이 가능한가 |
| 설계 영향 | 대체 인프라·복구 절차·복구 인력 | 백업 주기·복제 방식(동기·비동기) |
| 목표 미달 결과 | 업무 중단의 연장 | 과거 시점 데이터로의 복구(데이터 유실) |
| 결정 근거 | 업무 책임자의 허용 중단 시간 | 데이터 소유자의 손실 허용 기준 |

## Ⅴ. RTO·RPO의 한계와 방안

- 핵심 요약 : 목표의 형식적 설정, 목표와 설계의 불일치, 미검증 목표, 의존 관계 누락을 분석 기반 목표와 시험·검증으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 목표의 형식적 설정 | 업무 영향 분석 생략 → 과대·과소 설계 | BIA 기반 업무별 목표 산정·승인 | 목표 수립 시스템 비율 |
| 목표·설계 불일치 | 백업 주기·복제 방식의 목표 미달 → 장애 시 과대 유실 | 목표 대비 설계 검증·복제 체계 조정 | 설계의 목표 부합률 |
| 미검증 목표 | 시험 없는 가정 → 실제 복구 시 목표 미달 발견 | 정기 복구 시험·훈련으로 실측 | 목표 달성률(실측 기준) |
| 의존 관계 누락 | 연계 시스템의 복구 순서 미고려 → 부분 복구 실패 | 시스템 의존도 분석·종단 간 시험 | 종단 간 시험 통과율 |

## Ⅵ. RTO·RPO에 대한 기술사적 제언

- 핵심 요약 : 업무 책임자의 목표 승인 권한과 IT 복구 책임자의 실현·검증 책임 분리, 시험 결과의 보고 체계로 목표 체계의 신뢰성 확보 방향.

1. 권한 분리 : 업무 책임자의 중단 손실·복구 비용 비교 기반 목표 승인과 IT 재해복구 책임자의 설계·시험 책임 분리 운영.
2. 시험 체계 : 정기 복구 시험·훈련 결과의 목표 대비 보고 체계와 미달 시 개선 계획 추적 제도 정비.
3. 자원 계획 : 재해복구 목표 체계와 연계한 복구 자원·예산 계획 수립.

## Ⅶ. RTO·RPO의 결론

- 핵심 요약 : RTO·RPO는 재해복구 설계의 출발점이 되는 쌍둥이 목표 지표.
- 시험으로 검증된 목표만이 실제 복구 역량의 증거.
