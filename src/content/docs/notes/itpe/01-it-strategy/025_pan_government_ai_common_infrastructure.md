## 해당 토픽 큰 그림과 30초 인출

```text
[기관 업무·대국민 서비스]
           │ API·Agent
[공통 AI 서비스: Model Gateway·RAG·Guardrail]
           │
[공공 지식·데이터] ─ [컴퓨팅·플랫폼]
           │
 IAM·등급·로그·평가·비용·운영
```

- 인출어: `중복방지`, `모델 선택성`, `RAG`, `데이터 격리`, `공통 가드레일`, `책임기관 유지`

## 예상문제

> 범정부 AI 공통기반의 개념과 계층별 구조, 서비스 이용절차를 설명하고 공공데이터·보안·환각·책임성 통제방안을 제시하시오. (25점)

## Ⅰ. 안전한 공공 AI 재사용을 위한 공통기반 개요

**범정부 AI 공통기반**은 행정·공공기관이 AI 모델, 지식검색, 데이터 처리, 보안·평가·운영 기능을 공동 활용하도록 제공하는 플랫폼이다. 기관별 중복구축을 줄이되, 업무 적합성·개인정보·결과 검증과 최종 행정책임은 각 이용기관이 보유해야 한다.

## Ⅱ. 공통기반의 설계원칙

| 원칙 | 설명 |
|---|---|
| 공통과 특화 분리 | 범용 기능은 재사용하고 기관 지식·업무규칙은 분리 |
| 모델 중립성 | 업무·등급·성능에 맞는 모델을 선택·교체 |
| 데이터 최소화 | 목적에 필요한 데이터만 처리하고 등급·권한별 격리 |
| Human-in-the-loop | 고영향·대국민 결과는 사람의 확인·이의제기 보장 |
| 관측·감사 | 입력·근거·모델버전·출력·승인 이력을 추적 |

## Ⅲ. 계층별 참조구조

```text
[업무앱·행정비서·대국민 서비스]
              │
[API/Agent·Prompt·Workflow·Model Gateway]
              │
[RAG: 수집→정제→색인→검색→근거제시]
              │
[모델·벡터/문서저장소·컴퓨팅 플랫폼]
              │
[IAM·암호화·DLP·Guardrail·평가·로그·비용]
```

| 계층 | 공통기능 | 기관별 책임 |
|---|---|---|
| 서비스 | 업무도구·API·Agent 실행틀 | 업무규칙·사용자 안내 |
| AI | 모델 게이트웨이·프롬프트·가드레일 | 모델 적합성·결과검토 |
| 지식 | 수집·색인·검색·출처제시 | 원천권리·현행성·공개등급 |
| 플랫폼 | 컴퓨팅·배포·관측·비용 | 사용량·SLA·연속성 요구 |
| 통제 | 인증·권한·로그·평가 | 승인·감사·사고대응 |

## Ⅳ. 기관 서비스의 이용절차

```text
업무선정 → 데이터·위험등급 → 공통기능 조합 → 평가·승인 → 운영·모니터링
```

1. 사용자 문제와 비AI 대안을 포함해 적용 업무·성과지표를 정한다.
2. 개인정보·비밀·고영향 여부와 데이터 이용권한을 분류한다.
3. 모델, RAG 지식원, 프롬프트·가드레일, 사람검토 단계를 구성한다.
4. 정확성·근거성·편향·보안·부하·비용을 시험하고 서비스 책임자가 승인한다.
5. 모델·지식 버전과 품질·안전 지표를 감시하고 변경 시 재평가한다.

## Ⅴ. 기관별 독자구축과 공통기반 비교

| 구분 | 기관별 독자구축 | 범정부 AI 공통기반 |
|---|---|---|
| 속도 | 기반부터 구축 | 공통기능 재사용 |
| 일관성 | 기관별 편차 | 공통 보안·평가 기준 |
| 특화성 | 높은 자유도 | 확장점·기관영역 설계 필요 |
| 비용 | 중복투자 가능 | 공동투자·사용량 관리 |
| 책임 | 기관 내부 집중 | 플랫폼-기관 RACI 필요 |
| 종속위험 | 특정 사업자·모델 | 개방형 API·모델 교체성 필요 |

## Ⅵ. 공공 AI의 핵심 위험과 통제

| 위험 | 통제방안 | 검증지표 |
|---|---|---|
| 환각·근거오류 | 승인 지식원 RAG, 출처표시, 거부·사람검토 | 근거일치율·중대오류 |
| 정보유출 | 데이터 등급, 최소권한, 마스킹·DLP, 학습 재사용 통제 | 무단접근·유출건수 |
| 지식 노후화 | 소유자·유효기간·재색인·폐기 절차 | 최신성·색인 지연 |
| 편향·고영향 판단 | 대표성 평가, 영향평가, 사람감독·이의제기 | 집단별 오류·개선조치 |
| 공급자 종속 | 모델 게이트웨이, 표준 API, 데이터·프롬프트 반출 | 교체시험·Exit 결과 |
| 책임공백 | 플랫폼-기관 RACI, 승인·감사로그 | 미승인 변경·사고 대응시간 |

## Ⅶ. 하나의 모델보다 재사용 가능한 통제가 핵심인 결론

공통기반의 핵심은 모든 기관이 같은 모델을 쓰게 하는 것이 아니라 **데이터 보호, 모델 선택, RAG, 평가, 감사와 운영통제**를 재사용하게 하는 것이다. 공통 플랫폼 책임과 기관의 업무결과 책임을 명확히 나눠야 한다.

```text
정의: 공공기관이 모델·RAG·보안·평가·운영 기능을 공동 활용하는 AI 플랫폼
구조: 업무서비스 → Agent/API → Model Gateway·RAG → 모델·데이터·컴퓨팅
횡단통제: IAM·DLP·Guardrail·평가·로그·비용
절차: 업무선정 → 데이터·위험등급 → 구성 → 평가·승인 → 운영·재평가
통제: 환각, 유출, 지식노후, 편향, 종속, 책임공백
```
