- 메커니즘: 이용기관이 공통기반의 모델·RAG·에이전트 기능을 호출해 업무 서비스를 만들고, 플랫폼은 보안등급을 적용한 클라우드 자원에서 처리한 결과를 반환

- **범정부 AI 공통기반** : 중앙·지방 행정기관이 행정 내부망에서 모델·RAG·에이전트·GPU를 공동 활용하도록 제공하는 공공 AI 플랫폼. 2025년 11월 서비스 개시
- **RAG(Retrieval-Augmented Generation)** : 질의와 관련된 자료를 검색해 그 근거를 모델 입력에 함께 넣는 검색증강생성
- **AI 에이전트(AI Agent)** : 목표에 따라 도구 호출과 여러 단계의 작업을 스스로 이어서 수행하는 AI 기능
- **GPU(Graphics Processing Unit)** : AI 학습·추론의 병렬 연산을 처리하는 연산 자원
- **RACI(Responsible, Accountable, Consulted, Informed)** : 업무별 수행·최종 책임·자문·통보 역할을 구분하는 책임 배정표

## 2~4교시 25점 답안

## Ⅰ. 범정부 AI 공통기반의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **범정부 AI 공통기반** 은 여러 행정기관이 모델·RAG·에이전트·GPU를 공동 활용하도록 제공하는 공공 AI 플랫폼 |
| 목적 | 기관별 AI 중복 구축 방지와 행정망에서의 안전한 민간 AI 활용 |

## Ⅱ. 범정부 AI 공통기반의 특징

| 특징 | 의미 |
|---|---|
| 공통 자원 재사용 | 모델·GPU 등 고비용 자원의 기관 간 공동 활용 |
| 행정 내부망 활용 | 민간 클라우드에 보안등급을 적용해 행정망에서 민간 AI 기술 이용 |
| 공통 기능의 재사용 | 한 번 구성한 RAG·모델을 여러 업무 서비스가 공유. 예: 법령정보 **RAG** 를 활용한 AI 법령 비서 |
| 책임 경계의 분리 | 플랫폼의 기능·자원 제공과 이용기관의 데이터·행정 판단 책임 구분 |

## Ⅲ. 공통기반의 구성 체계와 요청 처리 흐름

### 범정부 AI 공통기반 구성 체계

```text
범정부 AI 공통기반
    │
    ├─ 이용 계층 ── 기관 업무 서비스 (예: AI 법령 비서)
    │
    ├─ AI 기능 ── 모델·RAG·에이전트
    │
    ├─ 자원 ── GPU·민간 클라우드
    │
    └─ 보안·운영 통제 ── 보안등급 적용·접근 권한·이용 기록
```

### AI 기능 확대: RAG 기반 요청 처리 흐름

```text
공무원 질의 (행정 내부망)
    ↓
이용자 권한·입력 데이터 확인
    ↓
RAG: 법령·내부 자료 검색
    ↓
모델: 검색 근거를 반영한 답변 생성
    ↓
근거 표시와 담당자 검토 후 업무 적용
```

## Ⅳ. 기관별 개별 구축과 공통기반 활용의 비교

| 구분 | 기관별 개별 구축 | 범정부 공통기반 활용 |
|---|---|---|
| 자원 | 기관별 모델·GPU 조달·운영 | 공통 모델·GPU 재사용 |
| 도입 속도 | 기관별 구축 기간 소요 | 구성된 모델·RAG 위에 업무 서비스만 개발 |
| 기관 고유 요건 | 기관 요구에 맞춘 자체 조정 | 공통 기능으로 충족되지 않는 요건 발생 가능 |
| 데이터 통제 | 기관 내부의 직접 통제 | 플랫폼으로 전달되는 항목·보관 경계 설정 필요 |
| 책임 | 기관이 기술 운영과 업무 판단을 함께 부담 | 플랫폼 운영과 이용기관 업무 판단의 책임 분리 |

## Ⅴ. 공통기반 활용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 기관 데이터의 플랫폼 전달에 따른 처리 경계 불명확 | 데이터 항목별 이용 근거·전달 범위·보관 기간 지정과 최소 항목 전달 |
| 생성 결과의 오류와 불명확한 근거 | RAG 근거 표시와 담당자 검토 후 업무 반영 |
| 공통 기능으로 충족되지 않는 기관 고유 요건 | 공통 모델·RAG 재사용을 우선하고 미충족 요건만 기관별 확장 개발 |
| 플랫폼 운영과 행정 판단 책임의 혼재 | **RACI** 에 따른 운영·검토·승인 주체의 구분 |

## Ⅵ. 제언

업무 서비스 연계 전 이용기관의 데이터 전달 범위와 결과 승인 책임자를 먼저 확정하는 연계 조건 설정

### 공통기반 이용 책임 구조

```text
범정부 AI 공통기반 이용 책임
    │
    ├─ 플랫폼 운영기관 ── 모델·RAG·자원 제공과 보안 통제
    │
    ├─ 이용기관 데이터 책임자 ── 전달 항목·근거·보관 기간
    │
    └─ 업무 담당자 ── 결과 검토·승인과 행정 판단
```

### 이용기관 데이터 책임자 확대: 연계 전 데이터 경계 확정 절차

```text
업무에 필요한 데이터 항목 목록화
    ↓
항목별 이용 근거·민감정보 포함 여부 확인
    ↓
최소 전달 항목·보관 기간 확정
    ↓
호출 경로 반영과 이용 기록 점검
```

### 선택 근거: 연계 후 사후 점검과의 비교

| 구분 | 연계 후 사후 점검 | 제언: 연계 전 경계·책임 확정 |
|---|---|---|
| 전달 데이터 | 업무 시스템 데이터의 일괄 전달 | 이용 근거가 확인된 최소 항목 |
| 결과 책임 | 플랫폼과 이용기관 사이 불명확 | 업무 담당자의 검토·승인 |
| 점검 시점 | 사고·민원 발생 후 | 연계 설계 단계 |
