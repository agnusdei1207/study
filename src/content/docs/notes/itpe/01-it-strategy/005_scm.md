## 큰 그림과 30초 인출

```text
공급자 → 제조 → 물류 → 유통 → 고객
   ▲       ▲      ▲      ▲      │
   └──── 수요·재고·계획 정보 ────┘
              │
     [SCP 계획] → [SCE 실행] → [가시성·성과]
      수요·공급     주문·창고      납기·재고·위험
```

- 본질: **공급자부터 고객까지 물류·정보·자금 흐름을 통합해 전체 공급망의 비용·납기·서비스를 최적화하는 경영체계**
- 암기: `계-실-가` = SCP 계획 → SCE 실행 → 가시성·통제
- 핵심 위험: 하류의 작은 수요변동이 상류 주문변동으로 증폭되는 채찍효과

## 예상문제

> SCM의 개념과 구성체계를 설명하고 채찍효과의 원인·대응 및 공급망 회복탄력성 확보방안을 논하시오. (25점)

## Ⅰ. 전 공급망을 통합 최적화하는 SCM 개요

- 정의: SCM은 공급자·제조·물류·유통·고객의 자재·제품·정보·자금 흐름을 계획하고 실행·통제하여 공급망 전체 성과를 높이는 활동
- 목적: 수요 대응, 재고·리드타임·총비용 절감, 고객 서비스와 회복탄력성 확보
- 필요성: 참여자별 부분 최적화와 정보 지연은 과잉재고·결품·납기지연을 동시에 발생시킴

## Ⅱ. 공급망 전체 최적화를 위한 SCM 특징

| 특징 | 핵심 내용 | 성과 |
|---|---|---|
| End-to-End | 공급자부터 고객까지 통합 | 부분 최적화 방지 |
| 정보 공유 | 수요·재고·생산·운송 상태 공유 | 예측 왜곡 감소 |
| 계획-실행 연계 | SCP 계획을 SCE 실행과 피드백 | 계획 실현성 확보 |
| 협업 | VMI·CPFR 등 공동 의사결정 | 재고·납기 동기화 |
| 회복탄력성 | 위험 감지·대체·복구 설계 | 중단 영향 최소화 |

## Ⅲ. SCP·SCE·가시성의 SCM 구성체계

| 영역 | 핵심 기능 | 대표 수단 |
|---|---|---|
| SCP | 수요·공급·생산·재고·물류 계획 | Forecast, S&OP, APS |
| SCE | 주문·구매·생산·창고·운송 실행 | OMS, WMS, TMS |
| 협업 | 파트너 간 계획·재고 공동관리 | CPFR, VMI, EDI/API |
| 가시성 | 재고·주문·운송·위험 Event 추적 | Control Tower, IoT |
| 성과관리 | 서비스·비용·현금·위험 평가 | OTIF, 재고회전, Lead Time |

```text
수요정보 → SCP 계획 → SCE 실행 → 실적·위험
   ▲                                  │
   └──────── 재계획·예외대응 ─────────┘
```

## Ⅳ. 계획에서 개선까지의 SCM 운영절차

```text
① 수요·재고·제약 수집 → ② 수요예측·S&OP → ③ 공급·생산·물류 계획
 → ④ 주문·창고·운송 실행 → ⑤ Event·성과 감시 → ⑥ 예외대응·재계획
```

| 단계 | 핵심 판단 | 산출물 |
|---|---|---|
| 계획 | 수요와 공급능력을 어떻게 맞출 것인가 | 통합계획·재고정책 |
| 실행 | 누가 언제 무엇을 이동·생산하는가 | 주문·작업·운송지시 |
| 감시 | 어느 지점에 지연·부족·과잉이 있는가 | Event·Control Tower |
| 개선 | 원인과 대안이 전체 성과를 높이는가 | 시나리오·재계획 |

## Ⅴ. Push·Pull 및 SCM·ERP 비교

| 구분 | Push | Pull |
|---|---|---|
| 기준 | 수요예측 | 실제 소비·주문 |
| 강점 | 규모경제·장기계획 | 재고절감·수요민감성 |
| 위험 | 과잉재고·예측오차 | 공급지연·Capacity 부족 |
| 적용 | 안정수요·긴 조달 | 변동수요·짧은 보충 |

| 구분 | SCM | ERP |
|---|---|---|
| 범위 | 기업 간 공급망 | 기업 내부 자원·업무 |
| 초점 | 수요-공급 동기화 | 거래·회계·자원 통합 |
| 관계 | ERP 실적을 활용해 계획·협업 | SCM 실행결과를 원장화 |

## Ⅵ. 채찍효과와 공급망 중단 대응

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 주문변동 증폭 | 수요정보 지연·예측 갱신 | POS 공유·단일 수요계획·CPFR | 정보왜곡 감소 |
| 과잉주문 | Batch 주문·부족 배분 경쟁 | 소량·빈번 보충, 공정한 Allocation | 가수요 억제 |
| 가격행사 왜곡 | 판촉 전후 선구매 | 안정가격·판촉정보 공유 | 실수요 기반 계획 |
| 공급망 중단 | 단일 공급원·가시성 부족 | 다중조달·대체 BOM·재고전략·위험지도 | 회복탄력성 확보 |
| 데이터 불신 | 파트너 기준·소유권 불일치 | 공통 KPI·Data Contract·접근통제 | 협업 신뢰 확보 |

## Ⅶ. 효율성과 회복탄력성을 함께 설계하는 결론

- **[총비용 최적화와 위험 시나리오의 동시 운영]**: 평상시 재고만 최소화하면 중단 시 고객 서비스와 복구비용이 급증함
- 나라면: 핵심품목별 수요변동·조달기간·대체 가능성을 분류해 재고·다중조달 정책을 차등화하고 Control Tower에서 조기경보와 재계획을 연계

#### 한줄 요약

- SCM의 완성은 재고 최소화가 아니라 전체 공급망의 서비스·비용·위험을 함께 최적화하는 상태임

## 1교시 10점 답안 발췌

```text
공급자 → 제조 → 물류 → 유통 → 고객
         SCP 계획 → SCE 실행 → 가시성·재계획
```

| 채찍효과 원인 | 대응 |
|---|---|
| 정보지연·개별예측 | POS 공유·CPFR |
| Batch 주문·가수요 | 소량보충·Allocation 개선 |
| 판촉 변동 | 안정가격·행사정보 공유 |

- 차별화: 품목 위험별 다중조달·대체·재고전략과 Control Tower 연계
