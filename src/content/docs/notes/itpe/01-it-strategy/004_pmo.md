## 연관 키워드

- PMO, 프로젝트 관리 사무소, 지원형·통제형·지시형, PMC(Project Management Consultant)
- 포트폴리오 관리, 프로젝트 거버넌스, PMO 헌장

## Ⅰ. PMO의 개요

- 핵심 요약 : 조직 내 다수 프로젝트의 표준·정보·통제를 담당하는 관리 조직 기능.
- 개념 : 프로젝트 관리 표준, 방법론, 정보 공유, 통제를 담당하는 조직 내 기능 또는 전담 조직, **프로젝트 관리 사무소** (PMO, Project Management Office).
- 배경 및 필요성 : 다수 프로젝트 병행 환경에서 관리 방식 불일치, 자원 경쟁, 전체 현황 파악 곤란이 통제 공백의 원인.
- 주요 목적 : 프로젝트 관리 일관성과 포트폴리오 관리 체계의 가시성 확보, 조직 차원의 프로젝트 거버넌스 강화.

## Ⅱ. PMO의 특징 및 장점

- 핵심 요약 : 표준 제공, 포트폴리오 관리, 권한 유형 설계가 편차 축소와 의사결정 지원으로 연결.

1. 표준 방법론 제공 : 공통 절차·템플릿·교육의 배포 → 프로젝트 간 관리 편차 축소.
2. 포트폴리오 관리 : 개별 프로젝트의 진척·위험·의존성 통합 보고 → 경영 의사결정 지원.
3. 권한 유형 설계 : 자문 중심 **지원형** (Supportive), 준수 점검 중심 **통제형** (Controlling), 직접 관리 **지시형** (Directive) 중 조직 성숙도에 맞는 권한 설정 → 상황 적합 통제.
4. 자원·우선순위 조정 : 프로젝트 간 인력·예산 충돌의 중재 → 조직 자원 배분 효율 제고.

## Ⅲ. PMO의 구조 (흐름)

- 핵심 요약 : 전략 수립에서 표준 제공, 현황 통합, 조정, 환류로 이어지는 운영 순환.

```text
전략·포트폴리오 수립
  ↓
표준·도구·교육 제공
  ↓
프로젝트 현황 수집
  ↓
위험·의존성 조정
  ↓
성과 보고·교훈 환류
```

- 권한 강도의 단계 구조 :

```text
지원형 (자문·도구 제공)
  ↓ 권한 강화
통제형 (표준 준수 점검)
  ↓ 권한 강화
지시형 (프로젝트 직접 관리)
```

## Ⅳ. PMO와 PMC의 비교

- 핵심 요약 : PMO가 조직 내부의 상설 관리 기능인 반면 **PMC** (Project Management Consultant)는 발주자의 사업 관리를 위임받아 대행하는 외부 전문기관.

| 비교 축 | PMO | PMC |
| --- | --- | --- |
| 소속·성격 | 조직 내부의 상설 기능 | 외부 위탁 전문기관 |
| 적용 범위 | 다수 프로젝트·포트폴리오 | 위탁받은 특정 사업 |
| 지속성 | 상시 운영 | 계약 기간 동안 한정 |
| 책임 근거 | 조직 규정·운영 지침 | 발주자와의 용역 계약 |
| 역할 성격 | 표준·지원·통제 체계 운영 | 발주자 대행 사업관리·조언 |

- 위치 관계 : PMC는 사업 관리 기능의 외부 대행 형태로서 발주자 측 PMO에 해당하는 지위.

## Ⅴ. PMO의 한계와 방안

- 핵심 요약 : 보고 관료화, 권한-책임 불일치, 외부 대행 의존을 위험 기반 보고, 헌장 명시, 인계 기준으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 보고 관료화 | 서류 중심 절차 → 현장 부담·지연 | 위험도 기반 보고 간소화 | 보고 작성 소요 |
| 권한-책임 불일치 | 결정권 부재 → 이슈 방치 | **PMO 헌장** (PMO의 권한·책임·보고선을 정한 문서)에 권한·에스컬레이션 절차 명시 | 이슈 해결 소요 |
| 외부 대행 의존 | PMC 역량에 편중 → 내부 역량 미형성 | 대행 범위·인계 기준 명시와 내부 인력 참여 | 내부 관리 인력 참여율 |

## Ⅵ. PMO에 대한 제언

- 핵심 요약 : 프로젝트 거버넌스의 상위 설계로 PMO 권한 체계와 인력 기반의 제도화 필요.

1. 경영진·사업 후원자 : PMO 헌장 승인에 따른 프로젝트 거버넌스 기준 확립과 PMC 도입 시 역할 중복 정리.
2. PMO 책임자 : 조직 성숙도에 따른 지원형에서 통제형으로의 단계적 권한 전환 계획 운영.
3. 인사·교육 조직 : 프로젝트 관리 인력 양성과 자격·경력 체계 기반의 PMO 인력 풀 확보.

## Ⅶ. PMO의 결론

- 핵심 요약 : PMO는 다수 프로젝트를 하나의 관리 체계로 묶는 조직의 통제·지원 기능.
- 권한과 서비스 범위가 명확한 PMO에서 통합 가시성과 현장 자율성의 병립이 가능.
