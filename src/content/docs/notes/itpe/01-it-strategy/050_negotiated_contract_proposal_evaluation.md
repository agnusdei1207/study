## 연관 키워드

- 협상에 의한 계약, 제안서 평가 세부기준, 제안요청서(RFP)
- 평가위원회, 기술능력·수행능력·가격, 기술가치 평가, 우선협상대상자, 이해충돌 통제

## Ⅰ. 협상계약 제안서 평가의 개요

- 핵심 요약 : 규격을 사전에 특정하기 어려운 기술개발형 조달에서 제안서의 기술·수행·가격을 공개된 세부기준으로 평가해 협상 상대를 정하는 절차·기준 체계.
- 개념 : 계약 상대자를 가격 경쟁만으로 정하지 않고 적격성·기술·가격 평가와 협의를 거쳐 정하는 **협상에 의한 계약**(negotiated contract)의 핵심 절차로서, 발주기관이 **제안요청서**(RFP, Request For Proposal)에 평가항목·배점·평가방법을 공개하고 접수된 제안서를 채점·순위화하는 **제안서 평가**의 항목·방식 세부기준.
- 배경 및 필요성 : 국가전략(기술)조달처럼 개발 성격이 강한 용역은 완성물의 규격과 기술경로를 사전에 확정하기 어렵고, 최저가 선정 방식으로는 기술 실현 가능성과 수행역량이 가격에 묻히는 문제 발생. 국가계약법과 국가전략(기술)조달 특별법에 이 방식의 법적 근거가 마련되면서 평가의 공정성·객관성을 담보할 세부기준의 필요성 증대.
- 주요 목적 : 기술 수준·수행역량·가격을 균형 있게 반영한 최적 제안자 선정과 평가 절차의 투명성 확보, 국가전략기술 확보라는 조달 성과의 달성.

## Ⅱ. 협상계약 제안서 평가의 특징 및 장점

- 핵심 요약 : 기준의 사전 공개, 항목별 분리 채점, 위원 독립성 보장이 평가의 공정성과 기술 반영력을 높이는 구조.

1. 기준 사전 공개 : 평가항목·배점·증빙·평가방법을 제안요청서에 명시 → 제안자 간 동등 비교와 평가 예측 가능성 확보.
2. 항목별 다면 평가 : **기술능력**(개발 목표 달성 가능성·기술 실현 가능성·개발계획 적합성), **수행능력**(수행실적·보유 인력·시설·관리능력), 가격(제안가격의 적정성)을 분리 채점 → 기술 수준과 비용을 함께 반영.
3. 기술가치 평가 연계 : 가격 평가에 **기술가치 평가**(기술의 우수성·사업성을 평가 절차에 반영하는 활동) 결과 활용 → 단순 원가 기준이 아닌 기술 우위 기반 판단.
4. 위원 독립성 보장 : 평가위원의 제척·기피·회피 절차와 평가 비밀 서약 → **이해충돌 통제**(평가자와 제안자 간 이해관계의 개입 차단) 실현.
5. 평가-협상 결합 : 최고 점수자를 **우선협상대상자**(평가 순위 1위로 협상을 우선 진행하는 상대자)로 선정해 가격·기술조건·계약조건 협의 → 예산과 기술요건의 정합 조정.

## Ⅲ. 협상계약 제안서 평가의 구조 (흐름)

- 핵심 요약 : 모집·접수 → 서면·발표 평가 → 우선협상대상자 선정 → 협상·계약의 단계 흐름과 항목별 채점 기준의 결합.

**평가위원회**(제안서를 채점하는 위원 조직)의 서면평가·발표평가 수행과 채점 근거·질의응답 기록이 결합된 구조.

```text
[ 제안서 평가·협상 절차 ]

시행계획 공고·제안 모집
   ↓
제안요청서 공개·제안서 접수
   ↓
서면평가 → 발표평가·질의
   ↓
우선협상대상자 선정
   ↓
협상 → 계약 체결
```

```text
[ 평가항목과 순위 산정 ]

기술능력 : 실현 가능성·개발계획
수행능력 : 실적·인력·관리능력
가격     : 제안가격 적정성
   ↓
배점 합산 → 종합 순위
```

## Ⅳ. 협상계약 제안서 평가와 최저가 낙찰 방식의 비교

- 핵심 요약 : 최저가 낙찰 방식이 가격 단일 축의 경쟁인 반면, 협상계약 제안서 평가는 기술·수행·가격의 복수 축 평가와 협의를 결합.

| 비교 축 | 협상계약 제안서 평가 | 최저가 낙찰 방식 |
| --- | --- | --- |
| 선정 기준 | 항목별 채점·순위와 협상 결과 | 제시 가격의 최저 |
| 기술 반영 | 실현 가능성·수행역량의 정량 반영 | 적격심사 수준의 최소 확인 |
| 적합 대상 | 규격 특정이 어려운 기술개발·복합 용역 | 규격이 명확한 표준 물품·용역 |
| 조건 결정 | 협의를 통한 가격·기술조건 조정 | 공고 조건 확정·변경 제한 |
| 절차 성격 | 다단계 평가·협상·기록 관리 | 단순 심사 중심의 신속 절차 |

## Ⅴ. 협상계약 제안서 평가의 한계와 방안

- 핵심 요약 : 정성 항목의 모호성·이해충돌·기록 미비를 척도 구체화·회피 절차·기록 관리로 일대일 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 평가기준 모호성 | 정성 항목 문구의 해석 차이 → 위원 간 점수 편차·이의제기 | 항목별 평가 척도·증빙 사례의 제안요청서 반영 | 위원 간 점수 편차 |
| 이해충돌·편향 | 위원과 제안자의 이해관계 → 공정성 훼손 | 제척·기피·회피 절차와 평가 비밀 서약 운영 | 회피·제척 건수 |
| 채점 근거 미비 | 채점 사유 미기록 → 사후 검증·분쟁 대응 곤란 | 항목별 채점 근거·질의응답 기록 보존 | 기록 미비 항목 수 |

## Ⅵ. 협상계약 제안서 평가에 대한 기술사적 제언

- 핵심 요약 : 발주기관과 조달 당국이 평가 인력·거버넌스·전산 체계를 제도화해 평가의 신뢰를 상시 역량으로 전환 필요.
- 발주기관 : 평가위원 풀 관리와 사전 교육 체계로 평가 전문성을 조직 역량으로 축적.
- 조달 당국 : 기술가치 평가 방법론의 표준 보급과 평가 전산 시스템 구축으로 절차·배점·결과의 일관된 운영 지원.
- 정책 연계 : 국가전략(기술)조달 평가 결과를 사업화 지원·후속 조달 계획과 연결하는 성과 관리 체계 마련.

## Ⅶ. 결론

- 핵심 요약 : 협상계약 제안서 평가는 기술·수행·가격을 공개 기준으로 종합 판단해 조달의 질과 수용성을 높이는 절차 기준.
- 평가기준의 구체성, 위원 독립성, 기록 관리가 제도 신뢰의 축.
