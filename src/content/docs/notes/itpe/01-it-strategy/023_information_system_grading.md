## 지식 로드맵 내 현재 위치

IT 전략·관리 → 정보시스템 운영·서비스 연속성 → **정보시스템 등급제**

## 30초 인출

- 본질: 정보시스템 등급제는 행정·공공기관 정보시스템을 국민 생활에 미치는 영향에 따라 등급으로 나누고 등급별로 관리 수준을 달리하는 제도
- 메커니즘: 서비스 영향 검토와 심의로 등급을 확정하고, 상위 등급일수록 복구 우선순위·재해복구 체계·공공 SLA 요건을 강화
- 통찰: 등급을 정해도 관리 요건이 따르지 않으면 장애 때 복구 순서가 뒤바뀌므로 등급별 복구 목표·SLA의 연결과 재판정

<details>
<summary>핵심 용어</summary>

- **정보시스템 등급제** : 행정·공공기관 정보시스템을 서비스 중요도에 따라 등급으로 나누고 등급별 관리 요건을 차등 적용하는 제도
- **공공 SLA(Service Level Agreement)** : 행정·공공기관 정보시스템의 운영·유지관리 사업자가 지켜야 할 가용률·장애조치 시간과 미달 시 제재를 정한 서비스수준협약
- **가용률** : 정해진 서비스 시간 중 시스템이 정상 제공된 시간의 비율
- **장애조치 시간** : 장애 발생부터 서비스를 정상 상태로 되돌리기까지 걸린 시간
- **RTO(Recovery Time Objective)** : 서비스 중단 후 재개까지 허용하는 목표 시간
- **DR(Disaster Recovery)** : 재해로 주 시스템이 멈췄을 때 다른 거점에서 서비스와 데이터를 복구하는 체계
- **선행 서비스** : 인증·연계·공통 플랫폼처럼 다른 서비스가 동작하려면 먼저 복구되어야 하는 서비스

## 2~4교시 25점 답안

## Ⅰ. 정보시스템 등급제의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **정보시스템 등급제** 는 행정·공공기관 정보시스템을 국민 생활 영향에 따라 등급으로 나누고 등급별 관리 요건을 차등 적용하는 제도 |
| 목적 | 장애·재해 때 국민 영향이 큰 서비스의 우선 보호와 한정된 운영 자원의 차등 배분 |

## Ⅱ. 일률 관리와 구별되는 등급제의 특징

| 특징 | 의미 |
|---|---|
| 국민 영향 중심 판정 | 기관 규모·이용자 수보다 서비스 중단이 국민 생활에 미치는 영향 우선 |
| 관리 요건의 차등 | 상위 등급일수록 강한 복구 우선순위·재해복구 체계·서비스 수준 요건 |
| 심의에 의한 확정 | 분야별 검토와 위원회 심의를 거친 등급 확정 |
| 재조정 가능성 | 서비스 역할과 국민 영향이 바뀌면 등급 재판정 |

## Ⅲ. 등급제 운영 체계와 등급 확정 절차

### 정보시스템 등급제 운영 체계

```text
정보시스템 등급제 ── 「전자정부법」 근거
    │
    ├─ 판정 기준 ── 국민 생활 영향 중심 중요도
    │
    ├─ 등급 ── A1(국가핵심) ~ A4
    │
    └─ 등급별 관리 요건
          ├─ 복구 우선순위·재해복구 체계
          ├─ 공공 SLA ── 가용률·장애조치 시간
          └─ 점검·재판정
```

### 등급 판정 확대: 등급 확정 절차

```text
시스템별 서비스 역할과 국민 생활 영향 검토
    ↓
분야별 분과 심의
    ↓
등급 심의위원회 전체회의의 등급 확정
    ↓
등급별 관리 요건 적용
    ↓
서비스 역할 변화 시 재판정
```

2026년 재조정은 5개 분과 심의 뒤 정보시스템 등급 심의위원회 전체회의에서 확정

## Ⅳ. 판정 기준의 전환과 등급 분포

### 이용자 수 기준과 국민 영향 기준의 비교

| 구분 | 이용자 수 중심 판정 | 국민 영향 중심 판정 |
|---|---|---|
| 판정 근거 | 이용 규모·기관 규모 | 서비스 중단이 국민 생활에 미치는 영향 |
| 상위 등급 예 | 이용자가 많은 일반 서비스 | 112시스템·정부24·주민등록·수출입 통관 |
| 드러난 한계 | 이용자는 적지만 영향이 큰 시스템의 낮은 등급과 복구 지연 | 영향 판단의 근거와 심의 기준 필요 |

### 2026년 재조정 결과

| 등급 | 시스템 수 | 비중 |
|---|---:|---:|
| A1(국가핵심) | 73 | 0.5% |
| A2 | 157 | 1.0% |
| A3 | 671 | 4.5% |
| A4 | 14,132 | 94.0% |

공공 SLA 표준안은 상위 등급(당시 1·2등급) 정보시스템에 2026년까지 시범 적용 후 2027년 의무화 추진. 2025년 9월 국가정보자원관리원 화재는 이용자 수 중심 등급의 복구 지연이 드러난 배경 사례

## Ⅴ. 등급제 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 이용자 수 중심 판정에 따른 영향 큰 시스템의 낮은 등급 | 국민 생활 영향 기준의 판정과 분과 심의 |
| 상위 서비스가 의존하는 **선행 서비스** 의 낮은 등급 | 선행 서비스의 상위 등급 동반 적용 |
| 등급과 복구 목표·재해복구 수준의 불일치 | 등급별 **RTO** 와 재해복구 방식의 연결 |
| 계약서에만 있고 실측하지 않는 **공공 SLA** | **가용률** ·**장애조치 시간** 의 정기 측정·보고와 미달 시 제재 적용 |
| 확정 후 서비스 역할 변화의 미반영 | 서비스 변경·통합 시 등급 재판정 |

## Ⅵ. 제언

등급 판정 때 선행 서비스까지 함께 판정하고, 확정된 등급의 복구 목표·SLA를 운영 계약과 재해복구 시험에 연결

### 등급별 관리 연결 구조

```text
확정 등급
    │
    ├─ 복구 목표 ── RTO·복구 우선순위
    │
    ├─ 재해복구 방식 ── 목표를 충족하는 DR 구성
    │
    └─ 운영 계약 ── 공공 SLA의 가용률·장애조치 시간
```

### 등급 판정 확대: 선행 서비스 동반 판정

```text
상위 등급 후보 서비스 선정
    ↓
인증·연계·망 등 선행 서비스 식별
    ↓
선행 서비스 등급 비교
    ├─ 낮음 → 상위 서비스와 같은 등급으로 조정
    └─ 같음 → 등급 확정
    ↓
재해복구 시험으로 복구 순서 확인
```

### 선택 근거: 시스템 단위 판정과의 비교

| 구분 | 시스템 단위 판정 | 제언: 선행 서비스 동반 판정 |
|---|---|---|
| 판정 단위 | 개별 시스템 | 국민 업무를 완결하는 서비스 묶음 |
| 복구 순서 | 시스템 등급 순 | 선행 서비스 우선 |
| 관리 요건 확인 | 등급 지정으로 종료 | 운영 계약·재해복구 시험으로 확인 |
