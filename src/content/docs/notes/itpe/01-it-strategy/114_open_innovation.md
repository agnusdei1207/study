## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로세스 혁신·경영 혁신 → **개방형 혁신(Open Innovation)**

## 30초 인출

- 본질: 개방형 혁신은 조직 경계를 넘는 지식의 유입과 유출을 의도적으로 관리해 내부 혁신을 앞당기고 외부 활용 시장을 넓히는 혁신 방식
- 메커니즘: 외부 지식을 받아들이는 Inbound, 내부 지식을 외부가 쓰게 하는 Outbound, 양쪽이 함께 만드는 Co-innovation의 지식 흐름을 라이선스·공동 개발·지식 조달 같은 계약 수단으로 실행
- 통찰: 개방 목적에 따라 유입·유출·공동 혁신의 흐름과 이전 수단이 달라지므로 개방할 지식을 기존·신규로 나눠 수단을 고르고 파트너와 공동 목표·투입·편익 분배를 먼저 합의

<details>
<summary>핵심 용어</summary>

- **개방형 혁신(Open Innovation)** : 혁신을 위해 조직 경계 너머로 지식을 의도적으로 들이고 내보내는 방식. Chesbrough(2003)가 제시
- **Inbound(내향) 지식 흐름** : 조직이 외부에서 만든 지식을 획득·흡수해 자기 혁신 활동에 쓰는 흐름
- **Outbound(외향) 지식 흐름** : 조직이 자신의 지식·아이디어를 다른 조직이 사용·결합·발전시키도록 의도적으로 허용하는 흐름. 기술·특허·프로토타입의 라이선스가 예
- **Co-innovation(Coupled Open Innovation)** : 둘 이상의 파트너 협업이 혁신으로 이어지는 방식. 파트너 모두가 유입과 유출에 참여
- **IPR(Intellectual Property Rights, 지식재산권)** : 특허·저작권 등 지식의 사용을 통제하는 권리. 라이선스 같은 계약 기반 지식 이전의 바탕
- **NDA(Non-Disclosure Agreement, 비밀유지계약)** : 공유한 정보의 비공개 의무를 정하는 계약
- **오픈소스(Open Source)** : 여러 기여자가 공동 개발하고 사용 제한이 거의 없는 산출물 방식. 개방형 혁신과 구별
- **Absorptive Capacity(흡수 역량)** : 외부에서 얻은 지식을 이해하고 적용하는 조직의 능력

</details>

## 2~4교시 25점 답안

## Ⅰ. 개방형 혁신의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **개방형 혁신(Open Innovation)** 은 조직 경계를 넘는 지식의 유입·유출을 의도적으로 활용하는 혁신 방식 |
| 목적 | 내부 혁신의 가속과 내부 지식의 외부 활용 시장 확대 |

## Ⅱ. 지식이 조직 경계를 넘는 개방형 혁신의 특징

| 특징 | 의미 |
|---|---|
| 의도적 지식 흐름 | 우연한 유출이 아닌, 목적을 갖고 관리하는 유입·유출 |
| 양방향 활용 | 외부 지식의 내부 도입과 유휴 내부 지식의 외부 제공 병행 |
| 계약 기반 이전 | 라이선스·협약 같은 조건을 두고 이전. 개방이 무상·무제한을 뜻하지 않음 |
| 흡수 역량 의존 | 외부 지식을 이해·적용하는 조직 능력에 따라 효과 결정 |

## Ⅲ. 지식 흐름 체계와 실행 수단

### 조직 경계를 넘는 지식 흐름

```text
외부 조직·네트워크 (기업·대학·연구기관·고객)
    ├─ Inbound       외부 → 내부 : 지식 획득·흡수, 내부 혁신 가속
    ├─ Outbound      내부 → 외부 : 사용 허용, 외부 활용 시장 확대
    └─ Co-innovation 양방향 : 파트너와 협업해 혁신 창출
            ═══ 조직 경계 (계약 지점) ═══
조직 내부 혁신 활동
```

### 실행 수단 확대: 지식 이전 메커니즘 유형

```text
                 기존 지식                 예정(신규) 지식
             ┌──────────────────────┬──────────────────────┐
IPR 기반      │ NDA·IP 라이선스       │ 지식 조달             │
(계약·권리)   │ IP 매매·양도          │ (자문·연구 용역·      │
             │ 노하우 계약           │  크라우드소싱 상금)   │
             ├──────────────────────┼──────────────────────┤
거래에        │ 인수합병에 따른       │ 공동 개발             │
내장된 지식   │ 지식 이전             │ (연구 합작·제휴·      │
             │ 장비·턴키 계약        │  인력 파견)           │
             └──────────────────────┴──────────────────────┘
```

## Ⅳ. 지식 흐름 유형과 유사 개념의 비교

### 지식 흐름 유형 비교

| 비교축 | Inbound | Outbound | Co-innovation |
|---|---|---|---|
| 지식 이동 방향 | 외부 → 내부 | 내부 → 외부 | 파트너 간 양방향 |
| 조직의 행위 | 외부 지식의 획득·흡수 | 자기 지식의 사용·결합·발전 허용 | 공동 목표 아래 협업해 혁신 창출 |
| 대표 수단 | 라이선스 도입·지식 조달 | 기술·특허·프로토타입의 라이선스 | 공동 개발·연구 합작·제휴 |

### 개념 층위 구분: 'Open'이 붙은 개념

| 개념 | 개방의 대상 | 사용 제한·대가 |
|---|---|---|
| **개방형 혁신** | 혁신 관련 지식의 조직 간 흐름 | 가격·사용 제한이 접근의 핵심 조건일 수 있음 |
| **오픈소스** | 공동 개발한 산출물(소프트웨어 코드 등) | 사용 제한이 거의 없고 로열티가 드묾 |
| 오픈 사이언스 | 과학적 방법·데이터·연구 결과 | 연구자·일반에 공개 |
| 오픈 액세스 | 콘텐츠·데이터 접근 | 무료·최소 저작권 제한 |

## Ⅴ. 개방형 혁신의 한계와 방안

| 한계 | 방안 |
|---|---|
| 개방 대상 지식과 흐름·수단의 선택 기준 부재로 개방 목적과 이전 수단의 불일치 | 내부 혁신 가속이면 Inbound, 외부 활용 시장 확대면 Outbound로 목적별 흐름을 정하고 기존·신규 지식에 맞는 이전 수단 선택 |
| 파트너 탐색·신뢰 형성·조정에 드는 비용 | 협업 시작 시 공동 목표와 투입·위험·편익 분배의 명시 |
| 외부 지식을 이해·적용하지 못하면 유입 효과 상실 | 유입 지식을 받아 적용할 내부 담당과 흡수 절차 확보 |
| 개방을 무상·무제한 공개로 오해 | 가격과 사용 제한을 계약 조건으로 사전 정의 |

## Ⅵ. 제언

개방 목적에 따른 흐름 유형 결정, 기존·신규 지식별 이전 수단 선택, 그리고 파트너와 공동 목표·편익 분배의 사전 합의

### 목적에서 이전 수단까지의 선택 순서

```text
개방 목적 (내부 혁신 가속 · 외부 활용 시장 확대 · 파트너 협업)
    ↓
지식 흐름 유형 결정
    ├─ 내부 혁신 가속 ── Inbound
    ├─ 외부 시장 확대 ── Outbound
    └─ 협업 ─────────── Co-innovation
    ↓
대상 지식 구분 → 이전 수단 선택
    ├─ 기존 지식 ── NDA·IP 라이선스 · IP 매매·양도 등
    └─ 신규 지식 ── 지식 조달 · 공동 개발
```

### 파트너 연계 확대: Co-innovation 시작 조건

```text
파트너 탐색
    ↓
공동 목표 합의 → 투입·위험·편익 분배 명시
    ↓
공동 개발·연구 합작·제휴 실행
    ↓
결과 지식을 받아 적용할 내부 담당 지정
```

| 구분 | 필요 발생 시 개별 개방 | 제언: 목적 기반 선택과 사전 합의 |
|---|---|---|
| 흐름 유형 결정 | 협업 중 필요에 따라 | 개방 목적에 따라 시작 전 결정 |
| 이전 수단 | 건별 선택 | 기존·신규 지식 구분에 따른 선택 |
| 파트너 연계 | 진행하며 조정 | 공동 목표·투입·위험·편익 분배를 먼저 명시 |
