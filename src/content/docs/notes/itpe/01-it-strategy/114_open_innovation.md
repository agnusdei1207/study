## 지식 로드맵 내 현재 위치

IT 전략·관리 → 혁신 전략 → **개방형 혁신(Open Innovation)**

## 30초 인출

- 본질: 개방형 혁신은 외부 기술·아이디어를 들여오고 내부 기술을 밖에서 사업화하는 등 조직 경계를 넘는 지식 흐름으로 혁신하는 전략
- 메커니즘: 외부 지식을 들여오는 유입형, 내부 기술을 내보내는 유출형, 파트너와 주고받는 결합형 중 과제에 맞는 지식 흐름을 골라 협업
- 통찰: 권리와 도입 기준 없이 협업하면 성과가 분쟁이나 단절로 끝나므로 착수 전 지식재산 귀속과 도입 기준 확정

<details>
<summary>핵심 용어</summary>

- **개방형 혁신(Open Innovation)** : 조직 경계를 넘는 의도적 지식 유입·유출로 내부 혁신을 가속하고 외부 사업화 경로를 넓히는 혁신 전략
- **폐쇄형 혁신(Closed Innovation)** : 연구·개발·사업화를 조직 내부 역량만으로 수행하는 혁신 방식
- **유입형(Outside-in)** : 외부 기술·아이디어를 내부 연구·제품 개발에 들여오는 지식 흐름
- **유출형(Inside-out)** : 내부 기술을 라이선스·스핀오프·기술이전으로 외부에서 사업화하는 지식 흐름
- **결합형(Coupled)** : 파트너와 지식을 주고받으며 공동 개발·사업화하는 지식 흐름
- **IP(Intellectual Property)** : 특허·영업비밀 등 협업 성과의 권리 귀속을 정해야 하는 지식재산
- **Background IP·Foreground IP** : 협업 전부터 각자 보유한 지식재산과 협업 과정에서 새로 생긴 지식재산의 구분
- **NDA(Non-Disclosure Agreement)** : 협업 중 공개한 비밀정보의 사용·보호 의무를 정하는 비밀유지계약
- **PoC(Proof of Concept)** : 외부 기술이 실제 과제에 작동하는지 소규모로 확인하는 개념 검증

## 2~4교시 25점 답안

## Ⅰ. 개방형 혁신의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **개방형 혁신(Open Innovation)** 은 조직 경계를 넘는 의도적 지식 유입·유출로 내부 혁신을 가속하고 외부 사업화 경로를 넓히는 혁신 전략 |
| 목적 | 내부 연구개발만으로 부족한 기술·시장 경로의 확보와 혁신 속도 향상 |

## Ⅱ. 폐쇄형 혁신과 구별되는 개방형 혁신의 특징

| 특징 | 의미 |
|---|---|
| 지식 원천 확장 | 대학·스타트업·공급사 등 외부 지식의 내부 활용 |
| 사업화 경로 확장 | 자사 사업에 쓰지 않는 기술의 라이선스·스핀오프 |
| 선택적 개방 | 핵심역량은 보호하고 협업에 필요한 범위만 공개 |
| 계약 기반 통제 | 소유 대신 **IP** 귀속과 **NDA** 합의로 협업 성과 관리 |

## Ⅲ. 개방형 혁신의 지식 흐름 구조와 유입형 추진 절차

### 개방형 혁신의 지식 흐름 구조

```text
개방형 혁신의 지식 흐름
    │
    ├─ 유입형(Outside-in) ── 외부 지식의 내부 활용
    │
    ├─ 유출형(Inside-out) ── 내부 기술의 외부 사업화
    │
    └─ 결합형(Coupled) ── 파트너와 공동 개발
```

### 유입형 확대: 외부 기술 도입 절차

```text
해결할 사업 문제·기술 공백 정의
    ↓
외부 파트너 탐색·선별
    ↓
정보 공개 범위·IP 귀속 합의 (NDA·계약)
    ↓
PoC로 기술 적합성·사업성 검증
    ├─ 기준 충족 → 내부 도입·공동 개발
    └─ 기준 미달 → 종료·다음 후보 검토
```

## Ⅳ. 지식 흐름 유형의 비교와 폐쇄형 혁신과의 차이

### 지식 흐름 유형의 비교

| 유형 | 지식 방향 | 실행 방식 | 적합 조건 |
|---|---|---|---|
| **유입형** | 외부 → 내부 | 기술 도입·공동연구·스타트업 협업 | 내부에 없는 기술이 필요한 과제 |
| **유출형** | 내부 → 외부 | 라이선스·스핀오프·기술이전 | 자체 사업화 계획이 없는 보유 기술 |
| **결합형** | 상호 교환 | 공동 개발·합작·생태계 참여 | 양측의 보완 자산이 모두 필요한 과제 |

### 폐쇄형 혁신과의 차이

| 구분 | **폐쇄형 혁신** | 개방형 혁신 |
|---|---|---|
| 지식 원천 | 내부 연구개발 | 내부와 외부 지식 |
| 사업화 경로 | 자사 시장 | 자사 시장과 외부 경로 |
| 통제 수단 | 내부 소유·비공개 | 계약·IP 합의 |

## Ⅴ. 개방형 혁신 추진의 한계와 방안

| 한계 | 방안 |
|---|---|
| 사업 문제 없는 외부 기술 수집 | 기술 공백이 확인된 과제에만 유입형 선택 |
| 협업 성과의 IP 귀속 분쟁 | 착수 전 **Background IP·Foreground IP** 의 소유·사용 권리 합의 |
| 협업 과정의 영업비밀 유출 | 단계별 정보 공개 범위와 NDA 체결 |
| PoC 통과 후 사업부의 미도입 | 착수 전 도입 판단 기준과 사업부 책임자 지정 |
| 사업화 계획 없는 보유 기술의 사장 | 해당 기술은 유출형(라이선스·스핀오프)으로 외부 사업화 |

## Ⅵ. 제언

협업 착수 전 IP 귀속과 사업부의 도입 판단 기준을 계약·과제 계획에 함께 확정하고, PoC 후 그 기준을 충족한 과제만 확대

### 협업 과제 책임 구조

```text
개방형 혁신 협업 과제
    │
    ├─ 사업부 책임자 ── 도입 판단 기준·도입 결정
    │
    ├─ 혁신 전담 조직 ── 파트너 탐색·PoC 운영
    │
    └─ 법무·IP 담당 ── IP 귀속·NDA 계약
```

### 사업부 책임자 역할 확대: PoC 후 도입 판정

```text
PoC 결과 보고
    ↓
착수 전 합의한 기술·사용자 가치·도입비용 기준 대조
    ├─ 모두 충족 → 사업부 예산으로 도입·확산
    ├─ 일부 미달 → 조건 보완 후 재검증
    └─ 미달 → 협업 종료와 IP 합의에 따른 정리
```

### 선택 근거: 기술 탐색 중심 협업과의 비교

| 구분 | 기술 탐색 중심 협업 | 제언: 도입 기준 선합의 협업 |
|---|---|---|
| 착수 조건 | 유망 기술 발견 | 사업 문제·도입 기준·IP 합의 |
| PoC 후 결정 주체 | 혁신 전담 조직 | 사업부 책임자 |
| IP 귀속 결정 시점 | 성과 발생 후 협상 | 착수 전 계약 |
| 확대 대상 | PoC 성공 과제 전체 | 도입 기준을 충족한 과제 |
