## 큰 그림과 30초 인출

- 본질: **ISO 21500**은 프로젝트 관리의 공통 용어·원칙·프로세스를 표준화하여 전 세계 조직에 보편적 적용 기준을 제공하는 국제 지침(Guidance)
- 메커니즘: 5대 프로세스 그룹(시간축)과 10대 주제 그룹(지식축)의 매트릭스 교차 결합을 통해 **39개 표준 프로세스**를 도출하고 조직별 **Tailoring(테일러링)** 수행
- 산출: 프로젝트 헌장(Charter) · 종합 프로젝트 관리계획서(PMP) · **Baseline(기준선)** · 작업 결과물 · 최종 완료 보고서

<details>
<summary>핵심 용어</summary>

- **ISO 21500**: 프로젝트 관리의 개념과 프로세스를 체계화한 국제표준화기구(ISO)의 지침 표준
- **Tailoring(테일러링)**: 프로젝트 규모·복잡도·조직 환경에 맞게 표준 프로세스를 선별·조정하는 활동
- **PMP(Project Management Plan)**: 범위·일정·원가 기준선과 10대 영역 관리 방침을 통합한 프로젝트 종합 관리계획서
- **WBS(Work Breakdown Structure)**: 프로젝트 범위를 계층적으로 분할하여 관리 가능한 단위 작업으로 구조화한 체계
- **EVM(Earned Value Management)**: 일정과 원가 실적을 화폐 가치로 통합 측정하여 프로젝트 성과를 분석하는 기법
- **CCB(Change Control Board)**: 프로젝트 기준선 변경 요청을 심의·승인·반려하는 공식 의사결정 협의체
- **Charter(프로젝트 헌장)**: 프로젝트의 공식적 존재를 승인하고 PM에게 자원 활용 권한을 부여하는 착수 문서
- **PMBOK(Project Management Body of Knowledge)**: 미국 PMI가 발간한 사실상의 프로젝트 관리 지식 체계 표준

</details>

## 예상문제

> 프로젝트 관리 국제 표준인 ISO 21500의 제정 배경과 5대 프로세스 그룹, 10대 주제 그룹의 매트릭스 구조를 설명하고, PMBOK 및 PRINCE2와의 비교와 프로젝트 특성에 따른 테일러링(Tailoring) 전략을 논하시오. (25점)

## Ⅰ. 글로벌 프로젝트 관리의 공통 언어, ISO 21500의 개요

> ISO 21500은 제3자 인증용 규격이 아닌 **Guidance(지침)** 표준이며, 성공 조건은 39개 프로세스의 기계적 답습이 아닌 환경 맞춤형 **Tailoring**에 있음.

- 정의: 산업 분야와 프로젝트 규모에 무관하게 보편적으로 적용 가능한 프로젝트 관리의 원칙과 개념을 정의한 **프로젝트 관리 국제표준 지침(ISO 21500)**
- 목적: 글로벌 다자간 협업 의사소통 표준화, **3대 기준선(범위·일정·원가)** 통제 통한 **가치 인도(Value Delivery)** 보장

## Ⅲ. ISO 21500 매트릭스 아키텍처 (5개 그룹 × 10대 주제 = 39개 프로세스)

> 10개 주제 영역과 5개 시간 프로세스가 교차 결합하여 프로젝트 거버넌스의 전 영역을 사각지대 없이 망라함.

| 주제 그룹 (Subject Groups) | 착수 (3) | 기획 (20) | 실행 (8) | 통제 (7) | 종료 (1) | 핵심 관리 내용 및 주요 산출물 |
|---|:---:|:---:|:---:|:---:|:---:|---|
| **통합 (Integration)** | ● | ● | ● | ● | ● | 헌장 수립, PMP 통합, 변경 통제, 프로젝트 공식 종료 |
| **이해관계자 (Stakeholder)** | ● | ● | | ● | | 이해관계자 식별, 기대사항 분석 및 지속적 참여 관리 |
| **범위 (Scope)** | | ● | | ● | | 요구사항 명세, **WBS(Work Breakdown Structure)**, 범위 검증 |
| **자원 (Resource)** | | ● | ● | ● | | 팀 확보, 조직 개발, 물적 자원 통제 및 배분 |
| **시간 (Time)** | | ● | | ● | | 활동 정의 및 순서 배열, 기간 산정, CPM 일정 개발 및 통제 |
| **원가 (Cost)** | | ● | | ● | | 원가 산정, 예산 결정, **EVM(Earned Value Management)** 통제 |
| **위험 (Risk)** | | ● | | ● | | 위험 식별, 정성·정량 평가, 대응 계획 수립, 위험 모니터링 |
| **품질 (Quality)** | | ● | ● | ● | | 품질 표준 기획, 품질 보증(QA), 결함 검사 및 품질 통제(QC) |
| **조달 (Procurement)** | | ● | ● | ● | | 조달 전략 수립, 공급업체 평가 및 선정, 계약 이행 관리 |
| **의사소통 (Communication)** | | ● | ● | ● | | 의사소통 채널 기획, 이해관계자 정보 배포, 피드백 통제 |

## Ⅳ. PMBOK vs ISO 21500 vs PRINCE2 비교

> 표준의 중립성, 도구의 풍부함, 프로세스 거버넌스 엄격성에 따라 최적의 프레임워크를 상호 보완적으로 활용함.

| 비교 항목 | ISO 21500 | PMBOK Guide | PRINCE2 |
|---|---|---|---|
| **제정 주체** | **ISO(국제표준화기구)** | PMI (미국 사실상 표준) | AXELOS (영국 정부 표준) |
| **표준 성격** | **국제 지침(Guidance)** 표준 | 실무 지식체계(ITTO 중심) | 비즈니스 케이스 중심 방법론 |
| **인증 여부** | **인증 불가 (조직 인증 규격 아님)** | 개인 자격 인증(PMP) 연계 | 조직 및 개인 인증 체계 |
| **접근 구조** | 5×10 매트릭스 (39개 프로세스) | 10대 지식영역 → 12원칙·8성과영역(7th) | 7개 원칙 · 7개 테마 · 7개 프로세스 |
| **적용 강점** | 벤더 중립적 공통 언어 제공 | 풍부한 도구·기법(ITTO) 수록 | 책임 분계 및 타당성 통제 탁월 |

## Ⅴ. 실무 적용 시 위험 요인 및 공학적 테일러링 방안

> 전수 적용으로 인한 문서 오버헤드를 배제하고 애자일 방법론과 결합하는 하이브리드 거버넌스가 핵심임.

| 위험 | 대책 | 효과 |
|---|---|---|
| **문서 오버헤드** | 프로젝트 규모(소/중/대) 및 복잡도 기반 **Tailoring 매트릭스** 운영 | 불필요한 관리 공수 절감 |
| **인증 규격 오해** | 지침 표준임을 안내하고 **ISO 9001/27001** 인증으로 대체 | 제안 및 계약 혼선 방지 |
| **애자일 충돌** | 착수·예산은 ISO 21500 준수, 스프린트 실행은 **스크럼(Scrum)** 결합 | 거버넌스 투명성과 민첩성 확보 |
| **형식적 통제** | 공식 **변경통제위원회(CCB)** 및 RTM 연계 심의 의무화 | 프로젝트 납기·예산 초과 방어 |

## Ⅵ. 조직 맞춤형 테일러링 중심의 기술사적 제언

> ISO 21500의 가치는 모든 프로세스를 강제하는 데 있지 않고, 조직 성숙도에 맞추어 필수 통제를 취사선택하는 유연한 거버넌스에 있음.

### 학습자 통찰 메모 — 답안 밖

- [핵심 통찰]: ISO 21500은 컴플라이언스 통제용 규격이 아니라, 글로벌 다국적 컨소시엄이 서로 다른 용어와 서식을 일원화하여 프로젝트 실패 위험을 낮추는 공통 언어(Common Language)임.
- 나라면: 전사 PMO 표준 가이드라인을 제정할 때 ISO 21500의 5×10 매트릭스를 기반 템플릿으로 삼되, 프로젝트 기간 6개월 미만 단기 사업은 15개 핵심 프로세스만 선별 적용하는 3단계 Fast-track 테일러링 규정을 수립하겠음.

### 실전 답안용 기술사적 제언

- 판정: 프로세스 형식주의(Bureaucracy)를 탈피한 실질적 인도물 중심 거버넌스
- 대안: **ISO 21500 기반 PMO 표준 체계** + 규모별 3단계 **Tailoring 가이드라인**
- 검증: 종합 **Baseline(기준선)** 편차율 통제 · 변경 승인 이력 추적률 100%
- 효과: 글로벌 프로젝트 협업 비용 절감 및 사업 지연·원가 초과 리스크 사전 차단

## 1교시 10점 답안 발췌

### 1. 정의·목적

- 정의: **ISO 21500**은 프로젝트 관리의 보편적 개념과 프로세스를 표준화하여 다기관 참여자 간의 소통을 일원화하기 위해 ISO가 제정한 **프로젝트 관리 국제표준 지침(Guidance)**
- 목적: 글로벌 협업 의사소통 표준화, **3대 기준선(범위·일정·원가)** 통제 통한 프로젝트 납기·품질 보장
