## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 거버넌스·표준 → **ISO 21500**

## 30초 인출

- 본질: ISO 21500은 프로젝트·프로그램·포트폴리오 관리가 조직 안에서 어떤 맥락과 개념으로 연결되는지 제시하는 국제표준
- 메커니즘: 21500이 공통 맥락·개념을 정하고, 관리 단위별 세부 지침은 21502(프로젝트)·21503(프로그램)·21504(포트폴리오)·21505(거버넌스)가 구체화
- 통찰: 프로젝트 지침만으로는 편익과의 연결이 끊기므로 관리 단위별 지침 선택과 종료 후 편익 책임 인계

<details>
<summary>핵심 용어</summary>

- **ISO 21500:2021** : 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 기반 개념을 제시하는 국제표준(Context and concepts)
- **ISO 21502:2020** : 프로젝트 관리의 실무 활동과 의사결정을 안내하는 지침 표준(Guidance on project management)
- **ISO 21503:2022** : 연관 프로젝트와 운영 활동을 조정해 편익을 실현하는 프로그램 관리 지침 표준
- **ISO 21504:2022** : 전략 목표에 맞춰 프로젝트·프로그램 투자를 선정·조정하는 포트폴리오 관리 지침 표준
- **ISO 21505:2017** : 프로젝트·프로그램·포트폴리오의 의사결정 권한과 감독을 안내하는 거버넌스 지침 표준
- **프로그램(Programme)** : 개별 관리보다 함께 관리할 때 더 큰 편익을 내는 연관 프로젝트·운영 활동의 묶음
- **포트폴리오(Portfolio)** : 전략 목표 달성을 위해 함께 관리하는 프로젝트·프로그램·운영 업무의 집합
- **편익(Benefit)** : 산출물을 활용해 조직이 얻는 측정 가능한 개선
- **Tailoring** : 조직 규모·복잡도·전달 방식에 맞춘 관리 활동과 산출물의 조정

## 2~4교시 25점 답안

## Ⅰ. ISO 21500의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ISO 21500:2021** 은 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 기반 개념을 제시하는 국제표준 |
| 목적 | 관리 단위별 표준을 같은 개념 위에서 활용하는 조직의 관리 수준 향상 |

## Ⅱ. 개별 방법론과 구별되는 ISO 21500의 특징

| 특징 | 의미 |
|---|---|
| 공통 개념 제시 | 프로젝트·프로그램·포트폴리오를 같은 용어·맥락으로 설명 |
| 표준군의 기반 | 세부 관리 지침은 21502~21505 등 대상별 표준에 위임 |
| 조직 맥락 강조 | 전략·거버넌스·운영과 관리 단위의 연결 관계 제시 |
| 판본 전환 | 21502:2020과 21500:2021이 함께 2012판을 대체. 프로젝트 관리 지침은 21502로 옮겨 프로세스 기반에서 실무 기반으로 바꾸고 후원 조직의 감독·지시와 편익 실현을 추가 |

## Ⅲ. ISO 21500 표준군 체계와 적용 절차

### ISO 21500 표준군 체계

```text
ISO 21500 ── 조직 맥락·기반 개념
    │
    ├─ 21505 ── 거버넌스: 권한·감독
    │
    ├─ 관리 단위별 지침
    │     ├─ 21504 ── 포트폴리오
    │     ├─ 21503 ── 프로그램
    │     └─ 21502 ── 프로젝트
    │
    └─ 주제별 지침 ── 용어·WBS·EVM 등
```

주제별 지침은 ISO 21506(용어), ISO 21511(WBS), ISO 21508·21512(획득가치관리) 등 ISO/TC 258 발행 표준

### 관리 단위별 지침 확대: 조직 적용 절차

```text
조직 전략·거버넌스 확인
    ↓
관리 대상의 단위 구분
    ├─ 전략 투자 조정 → 21504
    ├─ 편익 실현 조정 → 21503
    └─ 산출물 인도 → 21502
    ↓
현행 관리 체계와의 차이 진단
    ↓
규모·위험별 Tailoring 후 적용
```

## Ⅳ. 프로젝트·프로그램·포트폴리오 비교

| 구분 | 프로젝트 | 프로그램 | 포트폴리오 |
|---|---|---|---|
| 목적 | 정해진 산출물 인도 | 연관 구성요소 조정을 통한 편익 실현 | 전략 목표 달성을 위한 투자 조정 |
| 구성 | 활동·작업 패키지 | 연관 프로젝트·운영 활동 | 프로젝트·프로그램·운영 업무 |
| 관리 초점 | 범위·일정·원가·품질 | 구성요소 간 의존성·편익 추적 | 우선순위·자원 배분·위험 균형 |
| 성공 판정 | 산출물의 인도와 수용 | 조직이 얻은 편익 | 전략 목표 기여도 |
| 종료 시점 | 산출물 인도 | 편익 실현 기반 확보 | 종료 없이 지속 조정 |

프로젝트는 산출물 인도로 끝나지만 편익은 인도 이후 운영에서 발생하므로, 두 단위의 경계에서 편익 책임이 비기 쉬운 구조

## Ⅴ. ISO 21500 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 2012판 프로세스 구조와 2021판 개념 표준의 혼용 | 개념은 21500, 프로젝트 실무 활동은 21502로 역할 구분 |
| 모든 사업에 같은 관리 산출물 적용으로 부담 증가 | 규모·위험·전달 방식별 **Tailoring** 기준 승인 |
| 산출물 인도로 프로젝트 종료 후 편익 추적 단절 | 편익 책임자를 지정하고 프로그램·포트폴리오 단위로 편익 추적 인계 |
| 포트폴리오 우선순위와 프로젝트 목표의 연결 부재 | 21504의 선정 기준을 프로젝트 착수 승인 조건에 반영 |

## Ⅵ. 제언

사업을 관리 단위로 먼저 구분해 해당 지침을 고르고, 프로젝트 종료 시 편익 책임을 프로그램·포트폴리오에 인계하는 연결 기준 수립

### 관리 단위 간 편익 책임 구조

```text
포트폴리오 ── 전략 목표 대비 기여도 판단
    │
    ├─ 프로그램 ── 편익 책임자의 편익 실현 추적
    │
    └─ 프로젝트 ── 산출물 인도와 편익 측정 기준 인계
```

### 프로젝트 확대: 종료 시 편익 인계 절차

```text
산출물 인도·수용
    ↓
편익 지표·기준선·측정 시점 확정
    ↓
편익 책임자 지정 확인
    ├─ 미지정 → 종료 보류, 책임자 지정 요청
    └─ 지정 → 편익 추적의 프로그램 인계
    ↓
프로젝트 종료 승인
```

### 선택 근거: 프로젝트 단독 관리와의 비교

| 구분 | 프로젝트 단독 관리 | 제언: 관리 단위 연계 |
|---|---|---|
| 적용 지침 | 프로젝트 지침 일괄 | 관리 단위별 21502~21504 선택 |
| 성공 판정 | 산출물 인도 | 인도 후 편익 실현까지 |
| 종료 시 편익 책임 | 없음 | 프로그램·포트폴리오의 편익 책임자 |
| 착수 판단 근거 | 개별 요청 | 포트폴리오 선정 기준 |
