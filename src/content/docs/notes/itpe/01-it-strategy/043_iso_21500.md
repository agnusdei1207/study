<summary>핵심 용어</summary>

- **ISO 21500:2021**: 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 기반 개념을 규정하는 국제표준
- **ISO 21502:2020**: 예측형·반복형·적응형·하이브리드 등 다양한 전달방식에 적용하는 프로젝트 관리 지침
- **ISO 21503**: 상호 연관된 프로젝트·활동을 조정하여 편익을 실현하는 프로그램 관리 지침
- **ISO 21504**: 전략목표에 맞게 프로젝트·프로그램을 선정·우선순위화하는 포트폴리오 관리 지침
- **ISO 21505**: 프로젝트·프로그램·포트폴리오의 거버넌스 지침
- **Tailoring**: 조직·사업의 규모·복잡도·위험·전달방식에 맞게 관리 실무를 조정하는 활동

## 예상문제

> ISO 21500:2021의 개념과 ISO 21500 표준군의 구성을 설명하고, 조직 적용 시 고려사항을 제시하시오. **(미출제 예상·25점)**

## Ⅰ. ISO 21500:2021의 개요

> ISO 21500은 세부 프로젝트 절차서가 아니라 프로젝트·프로그램·포트폴리오를 조직전략과 연결하는 **상위 개념 표준**임.

- 정의: 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 공통 개념을 제시하는 국제표준
- 목적: **공통 언어 · 전략 정렬 · 표준군 일관성** 확보

## Ⅱ. ISO 21500 표준군 구성체계

> ISO 21500이 공통 기반을 제공하고 대상별 지침이 관리 실무를 구체화함.

| 표준 | 대상 | 핵심 역할 |
|---|---|---|
| **ISO 21500** | 공통 | 맥락·개념·표준군 관계 |
| **ISO 21502** | 프로젝트 | 프로젝트 관리 지침 |
| **ISO 21503** | 프로그램 | 연관 구성요소 조정·편익 실현 |
| **ISO 21504** | 포트폴리오 | 전략 정렬·선정·우선순위 |
| **ISO 21505** | 거버넌스 | 권한·책임·감독 체계 |

## Ⅲ. 프로젝트·프로그램·포트폴리오 비교

> 관리 단위가 커질수록 산출물 인도에서 편익·전략가치로 초점이 이동함.

| 기준 | 프로젝트 | 프로그램 | 포트폴리오 |
|---|---|---|---|
| 목적 | 고유 산출물 인도 | 연계 편익 실현 | 전략목표 달성 |
| 구성 | 활동·작업패키지 | 연관 프로젝트·활동 | 프로젝트·프로그램·운영 |
| 관리초점 | 범위·일정·원가·품질 | 의존성·변화·편익 | 선정·우선순위·자원균형 |
| 성공판정 | 인도·성과 | 편익·역량 | 전략가치·균형 |

## Ⅴ. 문제점·대응책

> 표준의 목적보다 문서 형식을 우선하면 관리비용만 증가함.

| 위험 | 대책 | 효과 |
|---|---|---|
| **2012판 구조 혼용** | 현행 21500·21502 역할 구분 | 개념 오류 방지 |
| **전수 적용** | 규모·위험·전달방식별 Tailoring | 관리부담 완화 |
| **전략·실행 단절** | 포트폴리오–프로그램–프로젝트 목표 추적 | 가치 정렬 |
| **산출물 중심 종료** | 편익책임자·사후평가 연계 | 성과 지속성 확인 |

## Ⅵ. 가치 흐름 중심 기술사적 제언

`[핵심 통찰]` ISO 21500 표준군의 가치는 문서 통일이 아니라 전략이 포트폴리오 선택·프로그램 편익·프로젝트 산출물로 추적되는 공통 관리언어에 있음.

`나라면` 조직 공통 최소통제만 표준화하고, 프로젝트별 Tailoring 근거와 제외 사유를 승인·기록하여 형식주의와 통제누락을 함께 줄이겠음.

## 1교시 10점 답안 발췌

### 1. 정의·목적

- 정의: 프로젝트·프로그램·포트폴리오 관리의 **조직 맥락과 공통 개념**을 제시하는 국제표준
- 목적: **공통 언어 · 전략 정렬 · 표준군 일관성** 확보

### 2. 표준군

| 표준 | 역할 |
|---|---|
| ISO 21500 | 맥락·개념 |
| ISO 21502 | 프로젝트 관리 |
| ISO 21503 | 프로그램 관리 |
| ISO 21504 | 포트폴리오 관리 |
| ISO 21505 | 거버넌스 |

### 3. 핵심 통제

- **정렬**: 전략 → 포트폴리오 → 프로그램 → 프로젝트
- **Tailoring**: 규모·복잡도·위험·전달방식에 맞게 관리실무 조정
