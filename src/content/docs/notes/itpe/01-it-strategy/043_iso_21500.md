## 연관 키워드

- ISO 21500, ISO 21502, ISO 21500:2021, 프로젝트·프로그램·포트폴리오, PMO, 거버넌스

## Ⅰ. ISO 21500의 개요

- 핵심 요약 : ISO 21500:2021은 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 기본 개념을 제시하는 국제표준.
- 개념 : ISO(International Organization for Standardization) 21500:2021은 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 기본 개념을 제시하는 국제표준.
- 배경 및 필요성 : 조직마다 프로젝트 관리 용어·역할·거버넌스가 달라 전략과 실행의 연계가 어려움.
- 주요 목적 : 프로젝트·프로그램·포트폴리오 관리의 공통 개념과 조직 맥락을 제공.

## Ⅱ. ISO 21500의 특징 및 장점

- 핵심 요약 : ISO 21500:2021은 맥락·개념, ISO 21502:2020은 프로젝트 관리 지침으로 역할을 분리하고 PPP 관리를 연계.

1. 맥락·개념 표준 : 조직 환경, 이해관계자, 거버넌스의 기본 개념을 규정 → 조직 간 용어 통일과 소통 효율 향상.
2. 프로젝트·프로그램·포트폴리오 구분 : 개별 프로젝트, 연계된 프로그램, 전략적 포트폴리오의 층위를 구분 → 관리 수준별 책임 명확화.
3. ISO 21502:2020 연계 : 상세 프로젝트 관리 지침은 별도 표준으로 제공 → 맥락 표준과 실행 지침의 분업.
4. Tailoring 원칙 : 조직 규모·복잡성·위험에 맞게 절차를 조정 → 과도한 관리 오버헤드 방지.
5. 국제 호환성 : PMI·PRINCE2 등 주요 방법론과 용어를 조화 → 다국적 프로젝트 협업 용이.

## Ⅲ. ISO 21500의 구조 (흐름)

- 핵심 요약 : 조직 전략·거버넌스 → 포트폴리오 선택·정렬 → 프로그램 조정 → 프로젝트 인도물 관리 → 성과·교훈 환류.

```text
조직 전략·거버넌스
   ↓
포트폴리오 선택·정렬
   ↓
프로그램 조정
   ↓
프로젝트 인도물 관리
   ↓
성과·교훈 환류
```

```text
전략·거버넌스 → 포트폴리오 → 프로그램 → 프로젝트 → 성과·교훈
```

- 핵심 구성 : 맥락·개념, PPP 구분, ISO 21502 연계, Tailoring, 국제 호환성.

## Ⅳ. ISO 21500과 ISO 21502의 비교

- 핵심 요약 : ISO 21500은 맥락·개념, ISO 21502는 프로젝트 관리 지침으로 범위와 활용이 다름.

| 비교 축 | ISO 21500:2021 | ISO 21502:2020 |
| --- | --- | --- |
| 범위 | 프로젝트·프로그램·포트폴리오 관리의 조직 맥락·개념 | 프로젝트 관리 지침 |
| 대상 | 조직 거버넌스·PMO | 프로젝트 관리자·팀 |
| 활용 | 용어·역할·구조 정렬 | 실행 절차·기법 적용 |
| 관계 | 상위 맥락 표준 | 하위 실행 지침 |

## Ⅴ. ISO 21500의 한계와 방안

- 핵심 요약 : 표준 혼동, 조직 부적합, 적용 과잉이 주요 한계이며 원인별 대응과 관리지표 연계가 필요.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 표준 혼동 | 구판과 현행판의 범위·연도 혼합 | ISO 21500:2021과 ISO 21502:2020 역할 구별 | 문서 인용 오류 |
| 조직 부적합 | 표준 용어만 도입하고 조직권한 미반영 | 거버넌스·조직 맥락에 맞춰 적용 | 의사결정 지연 |
| 적용 과잉 | 모든 프로젝트에 동일 절차 부과 | 규모·복잡성·위험에 비례 Tailoring | 관리 오버헤드 |
| 성과 미연계 | 표준 도입이 KPI와 분리 | 포트폴리오 성과지표와 연계 | 포트폴리오 ROI |

## Ⅵ. ISO 21500에 대한 기술사적 제언

- 핵심 요약 : PMO는 ISO 21500의 맥락·개념과 관련 표준을 조직의 사업거버넌스·역할·방법론에 맞게 연결.

- 거버넌스 : CIO 직속 PMO를 두어 표준 용어·역할·KPI를 정렬.
- 방법론 : ISO 21500 맥락과 ISO 21502 절차를 조직 표준에 통합.
- 인재 : 프로젝트 관리자에게 PPP 관점 교육 제공.

## Ⅶ. 결론

- 핵심 요약 : ISO 21500:2021은 프로젝트·프로그램·포트폴리오 관리의 조직 맥락과 기본 개념을 제시하는 국제표준임.
- 시사점 : 표준은 도구가 아니라 조직의 전략·실행 정렬을 위한 공통 언어로 활용해야 함.
