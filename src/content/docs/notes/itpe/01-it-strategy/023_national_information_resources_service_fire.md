## 해당 토픽 큰 그림과 30초 인출

```text
[시설·전력·통신 장애]
          ↓
[센터 장애영역 격리] → [다중센터 서비스] → [자동절체·복구] → [훈련·개선]
      방화·A/B계통         앱·데이터 분산       RTO·RPO 검증
```

- 인출어: `공통원인 장애`, `물리 격리`, `서비스 의존성`, `다중센터`, `복구훈련`

## 예상문제

> 국가정보자원관리원 화재가 공공 디지털서비스에 주는 시사점을 설명하고, 시설·인프라·애플리케이션·운영 관점의 회복탄력성 강화방안을 제시하시오. (25점)

## Ⅰ. 센터 장애를 서비스 연속성 문제로 보는 개요

데이터센터 화재는 시설 사고가 전력·통신·플랫폼·업무시스템으로 전파되는 **공통원인 장애**이다. 대응 목표는 장비 보호에 그치지 않고 국민이 사용하는 행정서비스의 우선순위, 허용중단시간과 데이터손실을 기준으로 **예방-격리-전환-복구-개선**을 보장하는 것이다.

## Ⅱ. 사고가 드러내는 핵심 위험

| 관점 | 위험 | 확인 질문 |
|---|---|---|
| 시설 | 화재구획·전력·공조의 결합 | 한 구역 사고가 다른 구역으로 전파되는가 |
| 인프라 | 전원·망·관리계통의 단일경로 | A/B 경로가 실제로 독립적인가 |
| 애플리케이션 | 단일센터·공통 플랫폼 의존 | 대체센터에서 서비스가 기동 가능한가 |
| 데이터 | 백업과 복제의 동일 장애영역 배치 | 격리된 복구본과 정합성이 있는가 |
| 운영 | 자산·의존성·절체권한 불명확 | 누가 어떤 순서로 전환하는가 |

## Ⅲ. 계층별 회복탄력성 구조

```text
[대국민 채널·기관 연계]
            │
[GSLB·DNS·대체접속 경로]
      ┌─────┴─────┐
 [센터 A]       [센터 B]
 앱·플랫폼      앱·플랫폼
      └─ 데이터 복제·백업 ─┘
            │
[격리백업·복구관리·상황대시보드]

횡단통제: 등급·RTO/RPO·IAM·로그·구성정보·훈련
```

## Ⅳ. 예방에서 개선까지의 대응절차

```text
등급·BIA → 위험·의존성 분석 → 격리·이중화 → 탐지·전환 → 복구검증 → 사후개선
```

1. 정보시스템 등급과 BIA로 핵심서비스·RTO·RPO·복구순서를 정한다.
2. 시설, 전력, 통신, 관리망, 공통플랫폼의 공통원인 장애를 분석한다.
3. 방화구획과 독립경로, 다중센터 앱·데이터, 격리백업을 설계한다.
4. 경보·상황판·의사결정권·대국민 안내와 자동·수동 절체절차를 준비한다.
5. 업무사용자까지 참여한 복구훈련으로 실제 복구시간·데이터 정합성을 측정한다.
6. 사고·훈련 결과를 설계, 운영기준, 조달·SLA에 환류한다.

## Ⅴ. 설비 이중화와 서비스 다중화 비교

| 구분 | 설비 이중화 | 서비스 다중화 |
|---|---|---|
| 대상 | 전원, 냉각, 망, 장비 | 앱, 데이터, 인증·연계 |
| 보호범위 | 부품·경로 장애 | 센터·지역 장애 |
| 핵심기술 | A/B 계통, 격리, 예비설비 | 다중센터, 복제, 트래픽 전환 |
| 한계 | 같은 건물·운영절차의 공통실패 | 데이터 충돌·비용·복잡성 |
| 검증 | 부품·경로 전환시험 | 업무 E2E 절체·복구훈련 |

## Ⅵ. 재발방지 통제와 검증지표

| 통제영역 | 대책 | 검증지표·산출물 |
|---|---|---|
| 시설 | 위험설비 구획, 감지·소화, 전원·공조 경로 격리 | 시설 안정성 점검서 |
| 서비스 | 등급별 다중센터·대체수단 | 서비스 가용성·절체 성공률 |
| 데이터 | 동기·비동기 복제 선택, 불변·격리백업 | 실제 RPO, 복원 성공률 |
| 운영 | CMDB·의존성 지도, RACI, 통합상황관리 | 탐지·의사결정·복구시간 |
| 훈련 | 부분·센터상실·복합재난 시나리오 | RTO 달성률·개선조치 완료율 |

## Ⅶ. 센터 복구보다 국민서비스 연속성이 우선인 결론

강한 데이터센터는 장애가 전혀 없는 센터가 아니라 장애영역을 제한하고 다른 위치에서 핵심서비스를 검증된 시간 안에 재개하는 체계다. **정보시스템 등급-서비스 의존성-다중센터 설계-실전훈련**을 하나의 추적체계로 관리해야 한다.

## 1교시 10점 답안 발췌

```text
본질: 센터 화재 = 시설 사고가 전력·망·플랫폼·업무로 전파되는 공통원인 장애
구조: 시설격리 → 독립 전원·망 → 다중센터 앱·데이터 → 격리백업
절차: 등급·BIA → 의존성 → 이중화 → 탐지·절체 → 복구검증 → 개선
구분: 설비 이중화는 부품·경로 / 서비스 다중화는 센터·지역 장애 대응
검증: 실제 RTO·RPO, 절체 성공률, 데이터 정합성, 개선조치 완료율
```
