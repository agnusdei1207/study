## 지식 로드맵 내 현재 위치

IT 전략·관리 → 재해복구·서비스 연속성 → **국가정보자원관리원 화재와 공공 디지털서비스 회복탄력성**

## 30초 인출

- 본질: 공공 디지털서비스 회복탄력성은 재난·장애 때 국민 핵심 행정서비스를 유지하거나 정한 목표 안에 복구하는 능력. 2025년 9월 국가정보자원관리원 대전 본원 화재로 한계가 드러난 과제
- 메커니즘: 국민 영향 기준의 시스템 등급으로 복구 우선순위를 정하고, 등급에 맞는 DR 방식과 전원·설비가 분리된 거점을 구성한 뒤 종단 간 절체 시험으로 검증
- 통찰: 한 거점 장애가 여러 서비스로 번지므로 최상위 등급 서비스부터 분리 거점 DR과 절체 시험 적용

<details>
<summary>핵심 용어</summary>

- **공공 디지털서비스 회복탄력성** : 재난·장애 때 국민 핵심 행정서비스를 유지하거나 정한 복구 목표 안에 회복하는 능력
- **공통원인 장애** : 공유 전원·설비·망 같은 하나의 원인이 여러 시스템을 동시에 멈추게 하는 장애
- **정보시스템 등급** : 행정·공공기관 정보시스템을 서비스 중요도에 따라 나눈 등급. 2026년 국민 영향 중심의 A1~A4로 재조정
- **RTO(Recovery Time Objective)** : 서비스 중단 후 재개까지 허용하는 목표 시간
- **RPO(Recovery Point Objective)** : 장애 시 허용하는 데이터 손실 구간을 복구 데이터 시점으로 나타낸 목표
- **Active-Active DR** : 주·보조 거점이 평상시 함께 서비스를 처리해 한 거점 장애에도 서비스를 이어 가는 이중운영 방식
- **Active-Standby DR** : 평상시 주 거점이 처리하고 장애 때 대기 중인 보조 거점으로 전환하는 대기형 방식
- **Split-Brain** : 거점 간 연결 단절 뒤 두 거점이 동시에 쓰기 주체로 동작해 데이터가 어긋난 상태

## 2~4교시 25점 답안

## Ⅰ. 공공 디지털서비스 회복탄력성의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **공공 디지털서비스 회복탄력성** 은 재난·장애 때 국민 핵심 행정서비스를 유지하거나 정한 복구 목표 안에 회복하는 능력 |
| 목적 | 국민 생활에 필요한 행정서비스의 중단 시간과 데이터 손실의 최소화 |

## Ⅱ. 공공 디지털서비스 회복탄력성의 특징

| 특징 | 의미 |
|---|---|
| 국민 영향 기준 | 이용자 수보다 서비스 중단이 국민 생활에 미치는 영향에 따른 우선순위 |
| 공통원인 장애 대응 | 같은 거점의 전원·설비·망을 공유하는 시스템의 동시 중단 가능성 고려 |
| 서비스 간 의존성 | 인증·연계·공통 플랫폼 등 선행 서비스까지 포함한 복구 범위 |
| 실측 검증 | DR 구축 여부가 아닌 절체·복귀 시험 결과에 따른 복구 능력 판정 |

## Ⅲ. 회복탄력성 확보 체계와 종단 간 검증 절차

### 공공 디지털서비스 회복탄력성 체계

```text
공공 디지털서비스 회복탄력성
    │
    ├─ 중요도 기준 ── 국민 영향 중심 정보시스템 등급
    │
    ├─ 복구 목표 ── 등급에 따른 복구 우선순위·RTO·RPO
    │
    ├─ 복구 구성
    │     ├─ 거점 분리 ── 공통 전원·설비 의존 제거
    │     └─ DR 방식 ── Active-Active·Active-Standby
    │
    └─ 검증 ── 종단 간 절체·복귀 시험
```

### 검증 확대: 연계 서비스의 종단 간 절체 시험 절차

```text
이용자 업무 시나리오 선정
    ↓
선행 서비스 식별: 인증·연계·망·공통 플랫폼
    ↓
복구 순서와 거점별 쓰기 주체 합의
    ↓
종단 간 절체 → 복귀·데이터 정합성 확인
    ├─ 목표 충족 → 시험 결과 기록·정기 재시험
    └─ 목표 미달 → 의존성·전환 절차 보완 후 재시험
```

## Ⅳ. 화재 사례의 사실과 DR 방식 비교

### 행정안전부 발표로 확인한 사실

| 확인된 사실 | 복구 체계 설계의 시사점 |
|---|---|
| 2025년 9월 26일 대전 본원 배터리 화재와 입주 정부 서비스 중단 | 한 거점의 전원·설비 장애가 여러 서비스로 동시 전파되는 공통원인 장애 |
| 2026년 6월 DR 구축 ISP 착수. 13개 시스템을 이중운영(Active-Active)과 대기형(Active-Standby)으로 구분 | 서비스별 복구 목표에 따른 DR 방식 차등 |
| 2026년 8월 공공 정보시스템 1만 5천여 개를 국민 영향 중심 A1~A4로 재조정. A1(국가핵심) 73개 | 이용자 수가 아닌 국민 생활 영향에 따른 복구 우선순위 |

### Active-Active와 Active-Standby 비교

| 기준 | Active-Active | Active-Standby |
|---|---|---|
| 평상시 | 주·보조 거점의 동시 서비스 처리 | 주 거점 처리, 보조 거점 대기 |
| 장애 시 | 남은 거점의 서비스 지속 | 보조 거점 기동·전환 |
| 중단 시간 | 최소 | 전환 소요 시간만큼 발생 |
| 설계 부담 | 동시 쓰기 정합성과 높은 운영 비용 | 대기 거점의 데이터 최신성과 전환 절차 |
| 적합 대상 | 중단 허용이 거의 없는 국가핵심 서비스 | 일정 시간 중단을 허용하는 서비스 |

## Ⅴ. 공통원인 장애와 복구의 한계와 방안

| 한계 | 방안 |
|---|---|
| 한 거점의 공통 전원·설비 장애의 다수 서비스 동시 전파 | 전원·설비가 분리된 원격 거점의 DR 구성 |
| 모든 시스템 Active-Active 적용 시 비용·운영 부담 | 중단 허용이 거의 없는 A1 등급은 Active-Active, 그 외 등급은 Active-Standby 선택 |
| Active-Active 동시 쓰기에 따른 **Split-Brain** | 업무별 쓰기 주체 지정과 거점 간 정합성 확인 절차 |
| DR 구축과 실제 복구 능력의 차이 | 인증·연계 서비스를 포함한 종단 간 절체·복귀 시험 |

## Ⅵ. 제언

A1 등급 서비스부터 선행 서비스를 포함한 원격 거점 DR을 구성하고, 종단 간 절체 시험의 목표 충족을 다음 등급 확대의 조건으로 설정

### 등급 기반 DR 확대 흐름

```text
A1 등급 서비스 식별
    ↓
선행 서비스(인증·연계·망)를 포함한 복구 범위 확정
    ↓
전원·설비가 분리된 원격 거점의 Active-Active DR 구성
    ↓
종단 간 절체·복귀 시험
    ├─ 목표 충족 → A2 등급으로 확대
    └─ 목표 미달 → 의존성·전환 절차 보완 후 재시험
```

### 선택 근거: 시스템 단위 이중화와의 비교

| 구분 | 시스템 단위 이중화 | 제언: 등급·의존성 기반 DR |
|---|---|---|
| 우선 대상 | 이용자 수가 많은 시스템 | 국민 영향이 큰 A1 등급 서비스 |
| 복구 범위 | 개별 시스템 | 선행 서비스를 포함한 종단 업무 |
| 거점 | 같은 센터 내 이중화 허용 | 전원·설비가 분리된 원격 거점 |
| 완료 판단 | DR 구축 완료 | 종단 간 절체 시험의 목표 충족 |
