## 지식 로드맵 내 현재 위치

```text
IT 경영·디지털 서비스 → 데이터 기반 의사결정 → A/B 테스트
```

## 토픽 큰 그림과 30초 인출
```text
[가설·주지표·보호지표] → [실험 단위·표본] → [무작위 배정]
                                         ├─ A 대조군
                                         └─ B 실험군
                     [효과크기·신뢰구간] ← [동일 기간 관측]
```
- **30초 인출**: 사전 가설과 주지표를 정하고 동일 모집단을 무작위 배정한 뒤, 효과크기와 불확실성으로 변경 여부를 결정한다.

## 예상문제
> A/B 테스트의 개념과 설계·분석 절차를 설명하고 신뢰성 확보 통제사항을 제시하시오.

## Ⅰ. 개요 ─ 정의와 목적
**A/B 테스트**는 사용자를 대조군 A와 실험군 B에 무작위 배정하고 한 가지 변화가 사전 정의 지표에 미친 인과효과를 비교하는 통제실험이다. 의견이나 단순 상관관계가 아닌 증거로 제품·정책 변경을 결정한다.

## Ⅱ. 설계 ─ 가설과 측정 기준
| 요소 | 핵심 질문 | 산출물 |
|---|---|---|
| 가설 | 무엇이 왜 변하는가 | 귀무·대립가설 |
| 실험 단위 | 사용자·조직·세션 중 무엇인가 | 배정키 |
| 지표 | 성공과 부작용은 무엇인가 | 주지표·보호지표 |
| 표본 | 탐지할 효과와 오차는 무엇인가 | 표본수·기간 |
| 분석 | 고정기간인가 유효한 순차검정인가 | 분석계획 |

표본수는 유의수준, 검정력, 기준 비율과 최소 탐지효과를 함께 고려한다.

## Ⅲ. 절차 ─ 설계부터 의사결정까지
```text
목표·가설 → 지표·표본 → 계측·A/A 점검 → 무작위 실행
         → 데이터 품질 → 효과·구간 추정 → 출시·재설계·중단
```
실행 중 목표지표나 종료시점을 임의로 바꾸지 않고, 종료 후 전체 효과와 사전에 정한 세그먼트를 분석한다.

## Ⅳ. 비교 ─ 유사 실험 방식
| 구분 | A/B 테스트 | 다변량 테스트 | 다중 슬롯 머신 |
|---|---|---|---|
| 목적 | 한 변화의 인과효과 | 여러 요인의 조합효과 | 학습 중 보상 극대화 |
| 배정 | 고정 무작위 | 요인 조합 | 관측결과에 따라 적응 |
| 유의점 | 외적 타당성 | 큰 표본 | 추론·편향 보정 복잡 |

## Ⅴ. 통제 ─ 대표 오류와 대응
| 오류 | 영향 | 대응 |
|---|---|---|
| 표본비율 불일치 | 배정·로그 오류 | SRM 검사·배정키 점검 |
| 반복 확인·조기종료 | 거짓 양성 | 고정기간·유효한 순차검정 |
| 다중 지표·세그먼트 | 우연한 승자 | 사전 등록·다중검정 보정 |
| 오염·간섭 | 군 효과 혼합 | 클러스터 배정·노출 통제 |
| 신규성·계절성 | 단기 왜곡 | 충분한 기간·반복 검증 |

## Ⅵ. 검증 ─ 결과 해석과 운영 반영
통계적 유의성만 보지 않고 **효과크기, 신뢰구간, 실무적 중요도, 보호지표**를 함께 판단한다. 계측 누락과 배정 편향을 먼저 검사하고 출시 후 효과 지속성과 부작용을 관찰한다.

## Ⅶ. 결론 ─ 재현 가능한 실험 거버넌스
A/B 테스트의 핵심은 도구가 아니라 사전 가설, 무작위화, 일관된 계측과 정해진 분석계획이다. 실험·결과·결정을 축적해 반복 가능한 조직 학습체계를 만든다.

## 1교시 10점 답안 발췌
```text
정의: 무작위 대조군과 실험군의 지표 차이로 변경의 인과효과 검증
구조: 가설·지표 → 표본·무작위 배정 → A/B 관측 → 효과·구간
통제: SRM, 피킹, 다중검정, 군 간 오염, 신규성·계절성
판단: 통계 유의성 + 실무 효과 + 보호지표 + 사후 모니터링
```
