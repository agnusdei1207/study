## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 데이터 기반 의사결정·제품 실험 → **A/B 테스트**

## 30초 인출

- 본질: **A/B 테스트** 는 사용자를 대조군·실험군에 무작위 배정하고 사전 지정 결과지표를 비교하는 통제 실험.
- 메커니즘: 가설·지표·표본 계획 → 무작위 배정과 계측 → 실험 실행 → 배정·데이터 품질 확인 → 효과와 불확실성 평가 → 사전 기준에 따른 결정.
- 통찰: 한계: 집단 배정·반복 확인의 오류를 변경 효과로 오인할 위험 → 방안: 배정 비율을 점검하고 주요 지표·종료·판정 기준을 실험 전에 기록

<details>
<summary>핵심 용어</summary>

- **A/B 테스트** : 무작위로 나눈 대조군·실험군의 결과를 비교하는 통제 실험
- **무작위 통제 실험(RCT, Randomized Controlled Trial)** : 참여 단위를 무작위로 집단에 배정해 처치 효과를 비교하는 실험 설계
- **표본비율 불일치(SRM, Sample Ratio Mismatch)** : 관측된 집단 배정 비율이 사전 기대 비율과 유의하게 다른 현상
- **최소감지효과(MDE, Minimum Detectable Effect)** : 실험 설계에서 정하는 최소 관심 효과 크기
- **피킹(Peeking)** : 고정된 검정 계획에서 허용하지 않은 채 결과를 반복 확인하고 중단해 오류율을 높이는 행위
- **가드레일 지표(Guardrail Metric)** : 주 목표 지표를 개선할 때 함께 살펴 서비스 품질 저하를 막는 지표
- **p-value** : 귀무가설이 참이라는 가정 아래 관측값과 같거나 더 극단적인 결과를 얻을 확률

</details>

## 2~4교시 25점 답안

## Ⅰ. A/B 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **A/B 테스트** 는 사용자를 대조군·실험군에 무작위 배정하고 사전 지정 결과지표를 비교하는 통제 실험 |
| 목적 | 변경 효과의 근거 기반 판단과 제품·서비스 결정의 불확실성 감소 |

## Ⅱ. A/B 테스트의 특징

| 특징 | 실험 판단에 미치는 영향 |
|---|---|
| 무작위 배정 | 대조군·실험군의 비교 가능성 확보 |
| 사전 분석 계획 | 주요 지표·표본·종료 기준의 결과 후 변경 방지 |
| 가드레일 병행 | 목표 지표 개선과 서비스 품질 저하를 함께 확인 |

## Ⅲ. 실험 설계와 의사결정 체계

```text
가설·지표·표본 계획
    ↓
무작위 배정·실험 실행
    ↓
배정·데이터 품질 확인
    ↓
효과·불확실성 평가
    ↓
유지·수정·확대 결정
```

실험 전 주요 지표·관심 효과 크기·표본·기간 계획·판정 기준 설정. 종료 시 통계적 유의성에 더해 효과 크기·서비스 품질의 동시 확인.

**실험 플랫폼의 하위 체계**

```text
사용자 ID → 배정 기능 → 대조군·실험군 노출
                              ↓
이벤트 계측 → 품질 점검(SRM·누락) → 효과·가드레일 분석
                                            ↓
                                  결정·변경 이력 기록
```

| 기능 | 핵심 책임 | 통제 예 |
|---|---|---|
| 배정 | 사용자를 사전 규칙에 따라 대조군·실험군에 할당 | 배정 비율·사용자 단위 일관성 |
| 계측 | 각 집단의 지표와 이벤트를 기록 | 이벤트 정의·누락·중복 점검 |
| 분석 | 효과와 불확실성을 추정 | 검정 방법·표본 계획·다중 비교 고려 |
| 운영 | 실험 설정과 노출 상태를 관리 | 권한·변경 이력·중단 절차 |
| 의사결정 | 결과를 사전 기준에 따라 검토 | 효과·가드레일·불확실성 기록 |

## Ⅳ. 실험 방식의 선택과 비교

| 방식 | 주된 목적 | 특징·주의점 |
|---|---|---|
| A/B 테스트 | 정해진 대안의 효과 비교 | 사전 고정된 배정·평가 계획을 사용 |
| 다변량 테스트(MVT) | 여러 요소 조합의 효과·상호작용 분석 | 조합이 늘수록 필요한 표본과 해석 부담이 커짐 |
| 멀티암드 밴딧(MAB) | 대안을 탐색하면서 성과에 따라 할당을 조정 | 동적 배정에 맞는 분석 방법을 사용해야 하며, 고정 배정 실험과 추정 해석이 다름 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| **표본비율 불일치(SRM)** 로 집단 비교 근거 약화 | 실제 배정 비율을 기대 비율과 비교하고 원인 해결 전 결과 판단 보류 |
| **피킹** 으로 고정 검정의 오류율 증가 | 표본·종료 계획을 지키거나 순차 검정 방법을 사전 지정 |
| 여러 지표·대안의 동시 비교로 우연한 유의성 증가 | 주요 가설 사전 지정과 필요한 다중 검정 보정 |
| 사용자 간 영향 공유로 집단 독립성 훼손 | 간섭 범위를 고려해 무작위 배정 단위 결정 |
| 계측 누락·중복으로 효과 추정 왜곡 | 이벤트 정의·수집 품질 점검과 오류 구간 재평가 |

## Ⅵ. 제언

가설·배정·지표·종료 기준을 실험 등록부에 먼저 고정하고 배정·계측 점검이 통과한 결과만 제품 결정에 반영.
