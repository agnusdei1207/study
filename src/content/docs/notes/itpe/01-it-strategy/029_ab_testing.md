## 지식 로드맵 내 현재 위치

IT 전략·관리 → 데이터 기반 의사결정·제품 실험 → **A/B 테스트**

## 30초 인출

- 본질: A/B 테스트(A/B Test)는 사용자를 무작위로 나눠 기존안(대조군)과 변경안(실험군)을 함께 운영하고 지표를 비교해 변경의 효과를 확인하는 통제 실험
- 메커니즘: 무작위 배정 단위와 OEC를 사전에 정하고, 두 변형의 지표 차이를 가설 검정으로 판정
- 통찰: 배정 비율 이상이나 로깅 오류가 있으면 지표 차이가 변경의 효과로 읽히지 않으므로, OEC 비교 전에 SRM 점검과 가드레일 지표 확인을 출시 판정의 선행 관문으로 설정

<details>
<summary>핵심 용어</summary>

- **A/B 테스트(A/B Test)** : 사용자를 무작위로 두 변형에 배정해 지표를 비교하는 통제 실험. 온라인 통제 실험(Online Controlled Experiment)과 같은 뜻
- **대조군(Control)** : 기존 버전을 받는 집단으로 비교의 기준
- **실험군(Treatment)** : 변경 버전을 받는 집단
- **변형(Variant)** : 실험에서 사용자에게 제공하는 사용자 경험 하나. 대조군의 기존 버전도 변형의 하나
- **무작위 배정 단위(Randomization Unit)** : 변형에 배정되는 대상 단위. 사용자·페이지·세션 등이며 해시 같은 의사 무작위 처리로 지속적·독립적으로 배정
- **OEC(Overall Evaluation Criterion)** : 실험 목표를 정량화한 종합 평가 기준. 실험 기간 안에 측정되면서 장기 전략 목표를 이끈다고 판단되는 지표
- **가드레일 지표(Guardrail Metrics)** : 조직이 바꾸지 않으려는 대상을 지키는 지표. 소프트웨어 충돌 횟수가 예
- **SRM(Sample Ratio Mismatch)** : 대조군과 실험군 사이에서 기대한 배정 비율과 실제 표본 비율의 불일치
- **A/A 테스트** : 두 집단에 같은 버전을 적용해 실험 시스템의 이상을 확인하는 검증 실험
- **다변량 테스트(MVT, Multivariate Test)** : 글꼴 색과 크기처럼 여러 매개변수를 함께 바꿔 조합의 효과를 평가하는 실험
- **가설 검정(Hypothesis Testing)** : 지표 차이가 우연이 아닌지를 p-값과 신뢰구간으로 판단하는 통계 절차

## 2~4교시 25점 답안

## Ⅰ. A/B 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **A/B 테스트(A/B Test)** 는 사용자를 무작위로 나눈 대조군과 실험군의 지표를 비교해 변경의 효과를 검증하는 통제 실험 |
| 목적 | 상관이 아닌 인과 근거에 기반한 변경안의 출시 판단 |

## Ⅱ. 인과 판단을 가능하게 하는 A/B 테스트의 특징

| 특징 | 의미 |
|---|---|
| 무작위 배정 | 어떤 요인도 변형 배정에 영향을 주지 않게 해 두 집단을 통계적으로 유사하게 유지 |
| 병행 비교 | 대조군과 실험군의 동시 운영으로 시기 차이 배제 |
| 사전 합의 지표 | 실험 전 **OEC** 와 핵심 지표의 확정 |
| 적용 조건 | 상호 간섭이 적은 다수의 배정 단위와 측정 가능한 지표, 쉬운 변경 |

## Ⅲ. A/B 테스트의 수행 체계

### 수행 절차

```text
가설과 변경안 정의
    ↓
OEC·가드레일 지표 사전 합의
    ↓
무작위 배정 단위 결정
    ├─ 대조군(A): 기존 버전
    └─ 실험군(B): 변경 버전
    ↓
사용자 행동 로깅과 지표 계산
    ↓
신뢰성 점검: SRM·A/A 테스트
    ↓
가설 검정: p-값·신뢰구간
    ↓
OEC·가드레일 지표로 출시 여부 결정
```

### 무작위 배정 확대: 배정 단위의 변형 매핑

```text
배정 단위(예: 사용자 ID)
    ↓
해시 등 의사 무작위 처리
    ├─ 값 구간 1 → 대조군(A)
    └─ 값 구간 2 → 실험군(B)

지속성: 같은 사용자는 재방문 시 같은 변형
독립성: 한 사용자의 배정은 다른 사용자의 배정과 무관
```

## Ⅳ. 실험 유형별 비교

| 유형 | 변형 구성 | 확인 대상 |
|---|---|---|
| A/B 테스트 | 한 매개변수의 두 값(대조 A·실험 B) | 변경 하나의 효과 |
| A/B/n 테스트 | 한 매개변수의 셋 이상의 값(A/B/C/D 등) | 여러 후보의 동시 비교 |
| **다변량 테스트(MVT)** | 여러 매개변수의 동시 변경(글꼴 색·크기 등) | 매개변수 간 상호작용과 최적 조합 |
| **A/A 테스트** | 두 집단에 같은 버전 적용 | 실험 시스템의 오류 여부 |

## Ⅴ. A/B 테스트의 한계와 방안

| 한계 | 방안 |
|---|---|
| 배정 비율 이상·로깅 오류가 지표 차이의 원인이 되어 변경 효과와 구분 불가 | 결과 해석 전 **SRM** 점검과 A/A 테스트의 선행 |
| 매출 같은 단일 지표의 개선이 사용자 경험 악화를 가림 | 사용자 경험 지표를 함께 담은 OEC와 **가드레일 지표** 설정 |
| 실험군 사용자가 대조군 사용자에게 영향을 주면 두 집단의 독립성 훼손 | 상호 영향이 적은 단위로의 배정 단위 재설계 |
| 배정 단위 수가 적으면 작은 효과의 탐지 불가 | 실험 전 탐지할 최소 효과 기준의 단위 수 확인, 부족하면 큰 효과 위주의 실험 |

## Ⅵ. 제언

결과 지표를 보기 전에 SRM 점검과 가드레일 지표 확인을 통과한 실험만 OEC로 판정

### 3단계 판정 관문

```text
실험 종료
    ↓
1관문 신뢰성: SRM 없음, 로깅 이상 없음
    ├─ 실패 → 판정 보류, 원인 조사
    ↓
2관문 가드레일: 유지 대상 지표의 악화 없음
    ├─ 악화 → 변경안 중단
    ↓
3관문 OEC: 가설 검정으로 개선 확인
    ↓
출시 결정
```

### 1관문 확대: SRM 점검과 원인 조사

```text
기대 배정 비율과 실제 표본 수 비율의 대조
(적합도 검정: Pearson χ² 등)
    ├─ 일치 → 2관문 진행
    └─ 불일치 → 판정 보류, 조사 대상 확인
                 ├─ 이벤트 로깅
                 ├─ 사용자 경험 서비스 코드
                 └─ 봇 필터링 데이터 처리
```

| 구분 | 결과 지표 중심 판정 | 제언: 신뢰성·가드레일 선행 판정 |
|---|---|---|
| 판정 순서 | OEC 비교 후 출시 | 신뢰성 → 가드레일 → OEC |
| 배정·로깅 오류 발견 시점 | 출시 후 성과 이상 | 결과 해석 전 |
| 유지 대상 지표 악화 | 개선 지표에 가려짐 | 변경안 중단 사유 |
| 오류 실험의 결과 | 의사결정에 반영 | 판정 보류 후 재실험 |
