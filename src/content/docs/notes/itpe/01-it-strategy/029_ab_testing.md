## 지식 로드맵 내 현재 위치

IT 전략·관리 → 데이터 기반 의사결정·제품 실험 → **A/B 테스트**

## 30초 인출

- 본질: A/B 테스트는 사용자를 무작위로 나눠 기존안과 변경안을 보여 주고 결과 지표를 비교해 변경 효과를 판단하는 통제 실험
- 메커니즘: 가설·주 지표·표본의 사전 설정 → 무작위 배정·계측 → SRM 점검 → 효과·불확실성 평가 → 출시 결정
- 통찰: 결과를 보며 지표를 바꾸면 우연을 효과로 오인하므로 실험 설계의 사전 고정과 SRM·가드레일 점검

<details>
<summary>핵심 용어</summary>

- **A/B 테스트** : 사용자를 대조군(A)·실험군(B)에 무작위 배정해 결과 지표를 비교하는 온라인 통제 실험
- **RCT(Randomized Controlled Trial, 무작위 통제 실험)** : 참여 단위를 무작위로 집단에 배정해 처치 효과를 비교하는 실험 설계
- **MVT(Multivariate Testing, 다변량 테스트)** : 여러 화면 요소의 조합을 동시에 비교해 요소 간 상호작용까지 분석하는 실험
- **MAB(Multi-Armed Bandit, 멀티암드 밴딧)** : 실험 중 성과가 좋은 대안에 배정 비율을 점차 늘려 탐색과 활용을 함께 하는 방식
- **SRM(Sample Ratio Mismatch, 표본비율 불일치)** : 실제 집단 배정 비율이 설계한 비율과 통계적으로 유의하게 다른 현상
- **MDE(Minimum Detectable Effect, 최소감지효과)** : 실험이 검출하도록 설계한 최소 효과 크기
- **검정력(Statistical Power)** : 실제 효과가 있을 때 그 효과를 유의하게 검출할 확률
- **피킹(Peeking)** : 고정 표본 검정에서 중간 결과를 반복 확인하고 유의할 때 멈춰 오류율을 높이는 행위
- **순차 검정(Sequential Testing)** : 중간 확인을 전제로 오류율을 통제하도록 설계한 검정 방법
- **가드레일 지표(Guardrail Metric)** : 주 지표를 개선하는 동안 응답시간·오류율 같은 서비스 품질 저하를 감시하는 지표
- **신뢰구간(Confidence Interval)** : 추정한 효과가 놓일 것으로 보는 값의 범위

</details>

## 2~4교시 25점 답안

## Ⅰ. A/B 테스트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **A/B 테스트** 는 사용자를 대조군·실험군에 무작위 배정하고 사전에 정한 결과 지표를 비교하는 온라인 통제 실험 |
| 목적 | 변경의 인과 효과 확인에 따른 제품·서비스 출시 결정 |

## Ⅱ. 무작위 배정과 사전 계획에 기반한 A/B 테스트의 특징

| 특징 | 의미 |
|---|---|
| 무작위 배정 | 사용자 특성 차이를 제거해 두 집단의 차이를 변경 효과로 해석 가능 |
| 사전 분석 계획 | 주 지표·표본·종료 기준의 결과 확인 전 고정 |
| 통계적 판정 | 효과 크기와 **신뢰구간** 으로 우연에 의한 차이 구별 |
| 가드레일 병행 | 주 지표 개선과 서비스 품질 저하의 동시 확인 |

## Ⅲ. A/B 테스트 수행 절차와 SRM 점검

### A/B 테스트 수행 절차

```text
가설 설정: 변경 내용과 기대 효과
    ↓
주 지표·가드레일 지표·표본 크기 결정
    ↓
사용자 무작위 배정과 실험 실행·계측
    ↓
배정·데이터 품질 점검
    ↓
효과 크기·신뢰구간 평가
    ↓
출시·보류·재설계 결정
```

표본 크기는 **MDE** 와 **검정력** 에 따라 실험 전 산정

### 품질 점검 확대: SRM 판정 절차

```text
실제 집단별 배정 수 집계
    ↓
설계 비율과의 차이 검정(카이제곱 적합도 검정)
    ├─ 유의한 차이 없음 → 효과 평가 진행
    └─ 유의한 차이(SRM) → 판단 보류, 배정·계측 원인 조사
```

## Ⅳ. A/B 테스트·다변량 테스트·멀티암드 밴딧의 비교

| 구분 | A/B 테스트 | **MVT** | **MAB** |
|---|---|---|---|
| 비교 대상 | 정해진 대안 | 여러 요소의 조합 | 여러 대안 |
| 배정 방식 | 고정 비율 무작위 배정 | 조합별 고정 무작위 배정 | 성과에 따른 배정 비율 동적 조정 |
| 주된 목적 | 효과 추정과 인과 판단 | 요소 간 상호작용 분석 | 실험 중 손실 최소화와 성과 극대화 |
| 필요 표본·해석 | 상대적으로 적고 해석 단순 | 조합 수에 따라 표본 급증 | 동적 배정으로 효과 추정의 해석 복잡 |

## Ⅴ. A/B 테스트의 한계와 방안

| 한계 | 방안 |
|---|---|
| 비교 목적과 맞지 않는 실험 방식 선택 | 인과 효과 판단은 A/B, 요소 상호작용 확인은 MVT, 실험 중 손실 최소화 우선은 MAB 선택 |
| **SRM** 으로 두 집단의 비교 가능성 훼손 | 배정 비율 검정과 원인 해결 전 결과 판단 보류 |
| **피킹** 으로 거짓 양성 증가 | 사전 표본·종료 시점 준수 또는 **순차 검정** 의 사전 지정 |
| 여러 지표의 동시 비교로 우연한 유의성 증가 | 주 지표 하나의 사전 지정과 다중 검정 보정 |
| 주 지표 개선 중 서비스 품질 저하 | **가드레일 지표** 의 사전 지정과 악화 시 중단 기준 |

## Ⅵ. 제언

가설·주 지표·표본·종료 기준을 실험 전에 등록부에 고정하고, SRM·가드레일 점검을 통과한 결과만 출시 결정에 반영하는 실험 운영 기준의 수립

### 실험 등록부 구성

```text
실험 등록부
    │
    ├─ 가설 ── 변경 내용과 기대 효과
    ├─ 판정 지표 ── 주 지표 하나와 가드레일 지표
    ├─ 표본·종료 기준 ── MDE·검정력 기반 표본과 기간
    └─ 판정 기준 ── 유의수준과 출시·보류 조건
```

### 판정 기준 확대: 출시 결정 절차

```text
사전 종료 기준 도달
    ↓
SRM 점검 ── 불일치 시 결과 폐기·원인 조사
    ↓
주 지표의 효과 크기·신뢰구간 확인
    ↓
가드레일 지표 확인 ── 악화 시 보류·재설계
    ↓
출시 결정
```

### 선택 근거: 사후 해석 중심 운영과의 비교

| 구분 | 사후 해석 중심 운영 | 제언: 사전 등록 운영 |
|---|---|---|
| 지표 선택 시점 | 결과 확인 뒤 유리한 지표 선택 | 실험 전 주 지표 고정 |
| 종료 시점 | 유의한 결과가 나온 시점 | 사전 표본·기간 도달 시점 |
| 배정 오류 결과 처리 | 결과에 그대로 포함 | SRM 불일치 결과 폐기 |
