## 연관 키워드

- A/B 테스트, 무작위 배정, 가설, 주지표, 검정력, 가드레일

## Ⅰ. A/B 테스트의 개요

- 핵심 요약 : **A/B 테스트**는 사용자를 무작위로 대조군과 실험군에 배정해 변경안의 인과 효과를 비교하는 실험 방법.
- 개념 : A/B 테스트는 사용자를 무작위로 대조군과 실험군에 배정해 변경안의 인과 효과를 비교하는 실험 방법.
- 배경 및 필요성 : 관찰자료의 상관만으로는 제품 변경이 지표 변화의 원인인지 판단하기 어려움.
- 주요 목적 : 사용자 경험·전환 등 사전 정의 지표에서 변경 효과를 신뢰성 있게 추정.

## Ⅱ. A/B 테스트의 특징 및 장점

- 핵심 요약 : 무작위 배정, 사전 가설·주지표 설정, 표본크기·기간 계획, 통계적 불확실성 검토가 인과 추론을 뒷받침.

1. 무작위 배정 : 사용자를 대조군과 실험군에 무작위 할당 → 교란변수의 기대 분포 균형화.
2. 사전 가설·주지표 : 변경이 개선할 지표와 기대 방향을 사전 정의 → 분석 계획의 명확화.
3. 표본크기·기간 계획 : **검정력** (Statistical Power)과 최소 탐지 효과를 기준으로 표본·기간 산정 → 잘못된 결론 방지.
4. 통계적 불확실성 검토 : 효과크기·신뢰구간·p값을 함께 해석 → 우연한 변동과 실질적 효과 구분.
5. 가드레일 지표 : 주지표 외 품질·안전·사용자 경험 지표를 감시 → 단기 전환 최적화로 인한 부작용 탐지.

## Ⅲ. A/B 테스트의 구조 (흐름)

- 핵심 요약 : 가설·주지표 정의 → 변형안 구현 → 무작위 배정 → 실험 실행·품질점검 → 효과·신뢰구간 분석 → 결정.

```text
가설·주지표 정의
   ↓
변형안 구현
   ↓
무작위 배정
   ↓
실험 실행·품질점검
   ↓
효과·신뢰구간 분석
   ↓
결정
```

- 실험 품질 : 배정 비율·샘플오염·SRM을 점검.

```text
가설·지표 → 무작위 배정 → A/B 노출 → 효과·불확실성·가드레일 분석
```

## Ⅵ. A/B 테스트에 대한 제언

- 핵심 요약 : 제품 책임자는 실험 사전등록과 중단 기준을 정하고 분석자는 효과크기·신뢰구간·가드레일을 함께 보고.

1. 제품 책임자 : 실험 사전등록과 중단 기준을 정하고 실험 우선순위를 관리.
2. 분석자 : 효과크기·신뢰구간·가드레일을 함께 보고하고 세그먼트별 영향을 검토.
3. 엔지니어 : 무작위 배정·실험 단위·SRM 점검 인프라를 유지하고 실험 오염을 방지.

- 시사점 : A/B 테스트는 올바른 무작위화·측정·해석 아래 제품 의사결정의 인과 근거를 제공.
