## 연관 키워드

- CRM, 운영·분석·협업 CRM, 고객 생애주기, 고객 데이터, CLV(Customer Lifetime Value), LTV(Lifetime Value)

## Ⅰ. CRM의 개요

- 핵심 요약 : **CRM** (Customer Relationship Management)은 고객 데이터를 활용해 고객 획득·유지·서비스 관계를 관리하는 전략과 업무·정보시스템.
- 개념 : CRM은 고객 데이터를 활용해 고객 획득·유지·서비스 관계를 관리하는 전략과 업무·정보시스템.
- 배경 및 필요성 : 채널·부서별 고객정보와 접점 이력이 분절되면 경험과 대응이 일관되지 않음.
- 주요 목적 : 고객 이해·서비스 개선·수익성 있는 관계의 지속.

## Ⅱ. CRM의 특징 및 장점

- 핵심 요약 : 운영 CRM(접점 실행), 분석 CRM(고객 데이터·분석), 협업 CRM(채널·부서 연계)가 고객관계를 실행·분석·연계.

1. 운영 CRM : 영업·서비스·마케팅 접점에서 고객 이력·캠페인·서비스 요청을 실행 → 접점 대응의 일관성 향상.
2. 분석 CRM : 고객 데이터를 세분화·예측·가치 분석 → 개인화된 제안과 고객가치 관리.
3. 협업 CRM : 채널·부서 간 고객정보와 상호작용을 공유 → 부서 간 인계 지연과 중복 접촉 감소.
4. 고객 생애주기 관리 : 획득·활성화·유지·이탈·재활성화 단계를 관리 → 장기 관계 수익성 향상.
5. 동의·개인정보 통제 : 수집목적·보유기간·권한·감사를 적용 → 신뢰와 법적 준수 확보.

## Ⅲ. CRM의 구조 (흐름)

- 핵심 요약 : 고객·접점 데이터 통합 → 식별·세분화 → 상호작용·캠페인·서비스 → 반응 분석 → 관계 전략 개선.

```text
고객·접점 데이터 통합
   ↓
식별·세분화
   ↓
상호작용·캠페인·서비스
   ↓
반응 분석
   ↓
관계 전략 개선
```

- 핵심 구조 : 접점 기록 → 고객 통합·분석 → 개인화된 상호작용 → 반응·관계성과 측정.

```text
접점 기록 → 고객 통합·분석 → 개인화된 상호작용 → 반응·관계성과 측정
```

## Ⅳ. CRM과 ERP의 비교

- 핵심 요약 : CRM은 고객 생애주기·접점·관계 중심, ERP는 제품·재고·공급·생산 흐름 중심.

| 비교 기준 | CRM | ERP |
| --- | --- | --- |
| 관리 단위 | 고객 생애주기·접점·관계 중심 | 제품·재고·공급·생산 흐름 중심 |
| 주요 데이터 | 고객·접점·캠페인·서비스 이력 | 주문·재고·생산·재무 데이터 |
| 성과 지표 | **CLV** (Customer Lifetime Value)·유지율·만족도 | 비용·납기·재고회전·생산성 |
| 연계 방식 | front-office 접점과 분석 | back-office 프로세스와 자원 |

## Ⅴ. CRM의 한계와 방안

- 핵심 요약 : 고객정보 단절·과잉 접촉·개인정보 위험; 통합 식별·접촉 정책·통제로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고객정보 단절 | 중복ID·채널 사일로 | 통합 고객 식별·동의·마스터 관리 | 중복률 |
| 과잉 접촉 | 세분화·빈도 통제 부족 | 접촉정책·선호·수신거부 적용 | 불만·수신거부율 |
| 개인정보 위험 | 목적 외 사용·과다 수집 | 목적·보유기간·권한·감사 통제 | 접근위반·보유초과 |
| 데이터 품질 저하 | 입력 누락·중복·노후화 | 데이터 검증·정제·오너 지정 | 결측률·정합성 |

## Ⅵ. CRM에 대한 제언

- 핵심 요약 : 고객 책임자는 고객가치와 개인정보 보호를 함께 목표화하고 영업·서비스·마케팅의 데이터·성과 책임을 정렬.

1. 고객 책임자 : 고객가치와 개인정보 보호를 함께 목표화하고 영업·서비스·마케팅의 데이터·성과 책임을 정렬.
2. 데이터 관리자 : 통합 고객 식별·동의·마스터 관리; 접촉정책·선호·수신거부 적용; 목적·보유기간·권한·감사 통제.
3. 분석가 : CLV·유지율·만족도 지표를 정기 검토하고 중복률·불만·수신거부율·접근위반·보유초과 지표를 미달 원인·시정조치·잔여위험으로 기록.

## Ⅶ. CRM의 결론

- 핵심 요약 : CRM은 고객 데이터를 활용해 고객 획득·유지·서비스 관계를 관리하는 전략과 업무·정보시스템.
- 시사점 : CRM은 소프트웨어 도입이 아니라 고객관계 전략을 접점 업무와 데이터로 실행하는 경영 역량.
