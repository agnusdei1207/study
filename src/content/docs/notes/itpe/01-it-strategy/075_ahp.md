## 연관 키워드

- AHP (Analytic Hierarchy Process, 계층화 의사결정 프로세스)
- MCDM (Multi-Criteria Decision Making, 다기준 의사결정)
- 계층 구조 (Hierarchy), 쌍대비교 (Pairwise Comparison)
- 9점 척도 (Saaty Scale), 고유벡터 (Eigenvector)
- 일관성 지수 (CI, Consistency Index)
- 일관성 비율 (CR, Consistency Ratio), RI (Random Index)
- ANP (Analytic Network Process)
- BMT (Benchmark Test), PoC (Proof of Concept)
- 민감도 분석 (Sensitivity Analysis)

## Ⅰ. AHP의 개요

- 핵심 요약 : 다기준 의사결정 문제를 계층화하고 쌍대비교로 정량적 가중치와 우선순위를 도출하는 의사결정 방법론.
- 개념 : AHP (Analytic Hierarchy Process)는 복잡한 다기준 의사결정 (MCDM, Multi-Criteria Decision Making) 문제에서 의사결정 요소를 계층화 (Hierarchy)하고, 요소 간의 일대일 쌍대비교(Pairwise Comparison)를 통해 정량적 가중치와 대안의 우선순위를 도출하는 계층화 의사결정 프로세스 (토마스 사티 교수 제안).
- 배경 및 필요성 : 정보시스템 도입, 아키텍처 선정, 공급업체 평가 등 다수의 정성적·정량적 기준이 상충할 때 의사결정자의 직관적 편향을 제거하고 논리적 합의를 도출할 방법론 필요.
- 주요 목적 : 복잡한 문제의 체계적 구조화, 정성적 판단의 수학적 수치화, 의사결정의 논리적 일관성 검증(Consistency Test).

## Ⅱ. AHP의 특징 및 장점

- 핵심 요약 : 계층 구조화, 쌍대비교, 고유벡터 가중치, 일관성 검증을 특징으로 하는 정량화 의사결정 기법.
1. **목표·기준·대안 계층화** : 복잡한 판단을 분해해 평가 근거를 분명히 한다.
2. **쌍대비교** : 두 요소씩 상대 중요도를 판단해 정성적 선호를 비교 가능하게 한다.
3. **가중치 산출** : 비교 행렬에서 기준별 비중을 얻어 대안의 종합 순위를 계산한다.
4. **일관성 비율(CR)** : 판단 모순을 확인해 평가 품질을 점검한다.
5. **집단 평가 합성** : 여러 평가자의 판단을 모아 개인 편향을 줄인다.

## Ⅲ. AHP의 구조 (흐름)

- 핵심 요약 : 계층 구조화 → 쌍대비교 → 가중치 도출 → 일관성 검증의 4단계 흐름.
- 4단계 추진 프로세스 및 쌍대비교 척도.

```text
[ 1. 의사결정 계층 구조화 ]
   최종 목표 (Goal) → 평가 기준 (Criteria/Sub-criteria) → 대안 (Alternatives)
          ↓
[ 2. 쌍대비교 행렬 작성 ]
   9점 척도 (1: 동등 ~ 9: 극도로 중요)를 사용하여
   기준 간/대안 간 1:1 비교
          ↓
[ 3. 가중치 및 우선순위 도출 ]
   행렬의 고유벡터 (Eigenvector) 계산을 통해 정규화된 가중치 산출
          ↓
[ 4. 논리적 일관성 검증 ]
   일관성 지수 (CI, Consistency Index) 및
   일관성 비율 (CR, Consistency Ratio = CI / RI, Random Index) 검증
   (CR < 0.1 합격)
```

```text
[ 쌍대비교 척도 (9점 척도) ]
1 : 동등 (Equal)
3 : 약간 더 중요 (Moderate)
5 : 실질적으로 중요 (Strong)
7 : 매우 강하게 중요 (Very Strong)
9 : 극단적으로 중요 (Extreme)
2,4,6,8 : 중간 타협값
```

- **쌍대비교 행렬** : 9점 척도(1 동등 ~ 9 극도로 중요)로 기준 간·대안 간 1:1 비교.
- **고유벡터** (Eigenvector) : 행렬 계산을 통해 정규화된 가중치 산출.
- **일관성 지수** (CI, Consistency Index) : 판단의 논리적 일관성 검증, CR < 0.1 이면 합격.
- **일관성 비율** (CR, Consistency Ratio) : CR < 0.1 (10% 미만) 이어야 판단의 유효성 인정.

## Ⅳ. 쌍대비교 척도 및 일관성 검증 기준 비교

- 핵심 요약 : 척도 값별 정의와 일관성 검증 기준 비교.
- 척도 및 검증 기준.

```text
[ CR < 0.1 ] 합격 (일관성 인정)
[ CR >= 0.1 ] 불합격 (재평가 필요)
```

| 척도 값 | 정의 및 의미 | 적용 예시 |
|---|---|---|
| 1 | 동등하게 중요 (Equal Importance) | 두 기준 A와 B의 기여도가 동일함 |
| 3 | 약간 더 중요 (Moderate Importance) | 경험상 A가 B보다 조금 더 선호됨 |
| 5 | 실질적으로 중요 (Strong Importance) | 명백하게 A가 B보다 훨씬 중요함 |
| 7 | 매우 강하게 중요 (Very Strong) | A가 B에 비해 압도적으로 우세함 |
| 9 | 극단적으로 중요 (Extreme Importance) | 최고 수준의 확실성으로 A가 B보다 중요함 |
| 2, 4, 6, 8 | 중간 타협값 | 미세한 조정이 필요할 때 적용 |

- **일관성 비율** (Consistency Ratio, CR) : 의사결정자가 "A > B 이고 B > C 인데 C > A"라고 모순되게 판단하는 오류를 측정하는 지표.

## Ⅴ. AHP의 한계와 방안

- 핵심 요약 : 비교 횟수 증가, 판단 불일치, 기준 간 의존성을 계층 정리와 민감도 분석으로 관리한다.

| 한계 | 방안 |
|---|---|
| 기준 수가 늘면 **쌍대비교 횟수**가 급증 | 평가 기준을 핵심 항목으로 묶고 불필요한 하위 기준 제거 |
| 응답 간 모순으로 **CR**이 높아질 수 있음 | 불일치 비교를 찾아 근거를 재검토하고 필요한 항목 재평가 |
| 독립적 계층이 **상호의존 기준**을 표현하지 못함 | ANP 또는 민감도 분석으로 상호작용 영향 확인 |

## Ⅵ. IT 프로젝트에서의 AHP 활용에 대한 기술사적 제언

- 핵심 요약 : BMT/PoC 지표 결합, 기하평균 합성, 민감도 분석으로 결과 안정성 검증.
- 소프트웨어 및 솔루션 평가 시 벤치마크 테스트(BMT)·PoC(Proof of Concept) 지표와 결합 : 기능 점수나 성능 수치를 AHP의 하위 기준으로 편입하여 정량적 벤치마크 결과와 정성적 전문가 판단의 유기적 결합.
- 집단 의사결정 시 기하평균(Geometric Mean) 활용 : 다수의 평가위원이 참여하는 경우, 개별 평가값을 산술평균하지 않고 역수성을 보존하는 기하평균을 적용하여 종합 쌍대비교 행렬 도출.
- 민감도 분석(Sensitivity Analysis)을 통한 결과 안정성 검증 : 특정 평가 기준의 가중치가 미세하게 변동했을 때 최종 대안 순위가 뒤바뀌는지 민감도 테스트를 거쳐 의사결정의 견고성 확보.

## Ⅶ. 결론

- 핵심 요약 : AHP는 다기준 의사결정을 계층화·쌍대비교·일관성 검증으로 정량화하는 방법론.
- 요약 : AHP는 복잡한 다기준 의사결정 문제를 계층화하고 쌍대비교로 정량적 가중치와 우선순위를 도출하는 계층화 의사결정 프로세스.
- 시사점 : 평가 요소 제한, 실시간 보정 도구, ANP 확장, BMT/PoC 결합을 통해 IT 프로젝트 의사결정의 객관성과 견고성 확보 필요.
