## 연관 키워드

- AHP (Analytic Hierarchy Process, 계층분석법), MCDM (Multi-Criteria Decision Making, 다기준 의사결정)
- 계층 구조 (Hierarchy), 쌍대비교 (Pairwise Comparison), 9점 척도 (Saaty Scale), 고유벡터 (Eigenvector)
- CI (Consistency Index, 일관성 지수), CR (Consistency Ratio, 일관성 비율), RI (Random Index)
- ANP (Analytic Network Process), BMT (Benchmark Test), PoC (Proof of Concept), 민감도 분석 (Sensitivity Analysis)

## Ⅰ. AHP의 개요

- 핵심 요약 : 다기준 의사결정 문제를 계층화하고 쌍대비교로 가중치와 우선순위를 구하는 의사결정 방법론.
- 개념 : 복잡한 **다기준 의사결정** (MCDM, Multi-Criteria Decision Making) 문제에서 요소를 계층으로 나누고, 요소 간 1:1 **쌍대비교** (Pairwise Comparison)로 가중치와 대안의 우선순위를 도출하는 **계층분석법** (AHP, Analytic Hierarchy Process). 토머스 사티(Thomas L. Saaty) 교수가 제안함.
- 배경 및 필요성 : 정보시스템 도입, 아키텍처 선정, 공급업체 평가처럼 정성·정량 기준이 상충할 때 의사결정자의 직관 편향을 줄이고 논리적 합의를 이끌 방법이 필요.
- 주요 목적 : 복잡한 문제의 체계적 구조화, 정성적 판단의 수치화, 판단의 논리적 일관성 검증.

## Ⅱ. AHP의 특징 및 장점

- 핵심 요약 : 계층 구조화와 쌍대비교로 판단을 수치화하고 일관성 검증으로 신뢰도를 점검하는 기법.

1. **계층 구조** (Hierarchy) : 목표, 기준, 대안으로 판단을 분해 → 평가 근거를 분명히 함.
2. 쌍대비교 : 두 요소씩 상대 중요도를 판단 → 정성적 선호를 비교 가능한 값으로 바꿈.
3. **고유벡터** (Eigenvector, 비교 행렬에서 정규화된 가중치를 얻는 수학적 도구) : 기준별 비중과 대안의 종합 순위 계산.
4. **일관성 비율** (CR, Consistency Ratio) : 판단의 모순을 측정 → 평가 품질 점검.
5. 집단 평가 합성 : 여러 평가자의 판단을 모아 개인 편향 완화.

## Ⅲ. AHP의 구조 (흐름)

- 핵심 요약 : 계층 구조화, 쌍대비교, 가중치 도출, 일관성 검증의 4단계 흐름.

```text
[ 1. 계층 구조화 ]
목표 → 평가 기준 → 대안
          ↓
[ 2. 쌍대비교 행렬 ]
9점 척도로 1:1 비교
          ↓
[ 3. 가중치 도출 ]
고유벡터로 정규화 가중치 산출
          ↓
[ 4. 일관성 검증 ]
CI 계산 후 CR < 0.1이면 합격
```

```text
[ 9점 척도 ]
1 동등 → 3 약간 중요 → 5 실질 중요
→ 7 매우 중요 → 9 극단적 중요
(2·4·6·8은 중간 타협값)
```

- 쌍대비교 행렬은 9점 척도로 기준 간, 대안 간 1:1 비교를 채운 행렬.
- 일관성 지수(**CI**)는 판단의 논리적 일관성을 나타내며, 일관성 비율은 **CR** = **CI** ÷ **RI**(Random Index, 무작위 행렬의 평균 일관성 지수)로 구하고 0.1 미만이면 판단을 유효하다고 봄.

## Ⅳ. 쌍대비교 척도 및 일관성 검증 기준 비교

- 핵심 요약 : 척도 값별 의미와 CR 임계치 판정 기준을 명확히 해 판단의 품질을 관리.

| 척도 값 | 정의 및 의미 | 적용 예시 |
| --- | --- | --- |
| 1 | 동등하게 중요 (Equal Importance) | 두 기준의 기여도가 동일함 |
| 3 | 약간 더 중요 (Moderate Importance) | 경험상 A가 B보다 조금 더 선호됨 |
| 5 | 실질적으로 중요 (Strong Importance) | A가 B보다 명백히 중요함 |
| 7 | 매우 강하게 중요 (Very Strong) | A가 B에 비해 압도적으로 우세함 |
| 9 | 극단적으로 중요 (Extreme Importance) | 최고 수준의 확실성으로 A가 중요함 |
| 2, 4, 6, 8 | 중간 타협값 | 미세한 조정이 필요할 때 사용 |

```text
[ CR < 0.1 ] 합격 (일관성 인정)
[ CR ≥ 0.1 ] 불합격 (재평가 필요)
```

## Ⅴ. AHP의 한계와 방안

- 핵심 요약 : 비교 횟수 증가, 판단 모순, 기준 간 상호의존을 기준 정리와 ANP 같은 확장 기법으로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기준 수 증가에 따른 쌍대비교 횟수 급증 | 평가자의 피로로 판단 품질 저하 | 평가 기준을 핵심 항목으로 묶고 불필요한 하위 기준 제거 | 비교 항목 수 |
| 응답 간 모순으로 CR 상승 | 판단이 서로 어긋나 결과의 신뢰도 저하 | 불일치 비교를 찾아 근거를 재검토하고 해당 항목 재평가 | CR 추이 |
| 독립 계층 가정으로 상호의존 기준 누락 | 기준 간 영향이 결과에 반영되지 않음 | **ANP** (Analytic Network Process, 분석적 네트워크 프로세스) 적용으로 상호작용 반영 | 순위 변동 여부 |

## Ⅵ. IT 프로젝트에서의 AHP 활용에 대한 기술사적 제언

- 핵심 요약 : 벤치마크 결과의 결합, 기하평균 합성, 민감도 검증으로 AHP 결과의 객관성과 견고성 확보.

1. **벤치마크 테스트** (BMT, Benchmark Test)와 **개념 증명** (PoC, Proof of Concept) 결과를 하위 기준으로 편입해, 측정된 성능 수치와 전문가의 정성 판단을 함께 반영한다.
2. **기하평균** (Geometric Mean) 합성 : 다수 평가위원의 판단은 산술평균 대신 역수성을 보존하는 기하평균으로 합성해 종합 쌍대비교 행렬을 만든다.
3. **민감도 분석** (Sensitivity Analysis) : 기준 가중치를 소폭 바꿨을 때 대안의 순위가 뒤바뀌는지 확인해 의사결정의 견고성을 검증한다.

## Ⅶ. 결론

- 핵심 요약 : AHP는 다기준 의사결정을 계층화, 쌍대비교, 일관성 검증으로 정량화하는 방법론.
- 시사점 : 판단을 수치로 드러내 논쟁 지점을 명확히 하는 것이 AHP의 가치이며, 결과의 질은 평가 기준을 설계하는 단계에서 결정됨.
