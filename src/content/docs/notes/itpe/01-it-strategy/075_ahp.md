## 지식 로드맵 내 현재 위치

IT 전략·관리 → 의사결정 기법 → **AHP(Analytic Hierarchy Process)**

## 30초 인출

- 본질: AHP(Analytic Hierarchy Process)는 목표·기준·대안의 계층을 세우고 요소를 둘씩 비교한 판단으로 우선순위를 수치화해, 기준끼리 상충하는 선택의 근거를 만드는 의사결정 기법
- 메커니즘: 쌍대 비교를 1~9 척도의 행렬로 적고 주 고유벡터로 우선순위를 구하며, 일관성 비율(CR)로 판단의 모순을 점검한 뒤 기준 우선순위와 대안 우선순위를 곱해 합산
- 통찰: 사람의 쌍대 비교는 모순을 포함하기 쉽고 모순된 판단이 그대로 종합되면 우선순위가 왜곡되므로 종합 전에 CR을 확인하고 기준을 넘으면 가장 크게 어긋난 판단부터 재검토

<details>
<summary>핵심 용어</summary>

- **AHP(Analytic Hierarchy Process)** : 문제를 계층으로 구조화하고 쌍대 비교로 무형 요소의 우선순위를 산정하는 다기준 의사결정 기법(Thomas L. Saaty)
- **쌍대 비교(Pairwise Comparison)** : 두 요소를 짝지어 어느 쪽이 더 중요한지와 그 정도를 판단하는 비교
- **기본 척도(Fundamental Scale)** : 쌍대 비교 판단을 1~9의 수로 나타내는 척도. 같은 요소끼리는 1
- **주 고유벡터(Principal Eigenvector)** : 쌍대 비교 행렬에서 각 요소의 우선순위를 결정하는 벡터. 합이 1
- **일관성 지수 CI(Consistency Index)** : (λmax − n) / (n − 1). 완전 일관이면 0
- **무작위 지수 RI(Random Index)** : 무작위로 채운 역수 행렬의 CI를 반복 계산해 평균한 값
- **일관성 비율 CR(Consistency Ratio)** : CI를 같은 크기의 RI로 나눈 값. 판단의 모순 정도
- **분배 모드(Distributive Mode)·이상 모드(Ideal Mode)** : 기준별 대안 우선순위를 종합하는 두 방식. 이상 모드는 각 값을 최댓값으로 나눈 이상 우선순위를 사용

## 2~4교시 25점 답안

## Ⅰ. AHP의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **AHP(Analytic Hierarchy Process)** 는 문제를 계층으로 구조화하고 **쌍대 비교** 로 요소의 우선순위를 산정하는 다기준 의사결정 기법 |
| 목적 | 기준 간 상충이 있는 선택의 절충 근거 마련 |

## Ⅱ. 사람의 판단을 수치로 바꾸는 AHP의 특징

| 특징 | 의미 |
|---|---|
| 계층 구조화 | 최상위 목표 아래 기준, 그 아래 대안 배치 |
| 판단의 수치화 | 쌍대 비교를 1~9의 **기본 척도** 로 표현하고 역수를 반대 위치에 자동 입력 |
| 비교 횟수 | 요소 n개에 n(n − 1) / 2회의 판단 |
| 고유벡터 기반 산정 | 우선순위를 행렬의 **주 고유벡터** 로 계산 |
| 일관성 점검 | 판단의 모순을 **일관성 비율(CR)** 로 측정 |

## Ⅲ. 계층 구조화에서 종합까지의 AHP 수행 체계

### AHP 수행 절차

```text
계층 구조화: 목표 → 기준 → 대안
    ↓
쌍대 비교 행렬 작성: 1~9 척도, 대각선 1, 역수 입력
    ↓
우선순위 산정: 주 고유벡터
    ↓
일관성 점검: CI = (λmax − n) / (n − 1), CR = CI / RI
    ↓
종합: 기준 우선순위 × 대안 우선순위를 합산해 정규화
```

### 일관성 확대: 쌍대 비교의 모순 판정

```text
A : B = 2
B : C = 3
A : C = 6  ← 2 × 3과 일치, 일관
A : C = 1/2 ← 모순, 재검토 대상
```

## Ⅳ. 일관성 판단 기준과 종합 방식 비교

### 행렬 크기별 CR 권고 기준

| 요소 수 n | CR 권고 |
|---|---|
| 3 | 0.05 미만 |
| 4 | 0.09 미만 |
| 5 이상 | 약 0.10 초과 시 진행 비권고 |

### 분배 모드와 이상 모드 비교

| 비교축 | 분배 모드 | 이상 모드 |
|---|---|---|
| 기준별 대안 우선순위 | 합이 1이 되는 벡터 | 각 값을 최댓값으로 나눈 벡터 |
| 종합 | 기준 우선순위를 곱해 합산한 뒤 정규화 | 같은 방식으로 종합 |
| 적용 상황 | 대안 집합이 고정된 비교 | 대안을 기준별로 하나씩 평가하고 기준 우선순위가 대안과 독립일 때 |
| 대안 추가 시 | 순위 보존을 강제하지 않음 | 새 대안을 이상과만 비교해 순위 보존 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 모순된 쌍대 비교가 그대로 종합되어 우선순위 왜곡 | 종합 전에 CR을 계산하고 기준 초과 시 가장 크게 어긋난 판단을 재검토 |
| 요소가 많으면 비교 횟수가 늘고 판단의 미세한 구분이 어려움 | 한 묶음의 요소를 7개 안팎으로 나누어 계층화 |

## Ⅵ. 제언

종합 전에 CR을 확인하고, 기준을 넘으면 일관성에 가장 크게 영향을 준 판단부터 재검토하는 절차를 AHP 수행 단계에 고정

### 종합 전 일관성 점검 흐름

```text
쌍대 비교 판단 입력
    ↓
CR 계산 (CI ÷ RI)
    ├─ 권고 기준 이내 ── 우선순위 종합
    └─ 기준 초과 ── 가장 큰 영향의 판단 재검토 → CR 재계산
```

### 재검토 대상 선정 확대

```text
판단 행렬의 각 항목
    ↓ 각 항목에 대한 λmax의 편미분 계산
절댓값이 가장 큰 항목 ── 재검토 대상
    ↓
판단 수정 후 CR 재확인
```

| 구분 | 점검 없이 종합 | 제언: CR 확인 후 종합 |
|---|---|---|
| 모순 발견 시점 | 결과 해석 단계 | 종합 전 |
| 재검토 대상 | 불명확 | 일관성에 가장 크게 영향을 준 판단 |
| 종합 허용 조건 | 없음 | CR이 권고 기준 이내 |
