## 30초 인출

- 본질: AHP는 여러 평가 기준과 대안을 쌍대비교해 우선순위를 정하는 의사결정 기법.
- 메커니즘: 목표·기준·대안의 계층화, 1~9 척도 쌍대비교, 가중치 산출과 판단 일관성 점검.
- 판정 기준: 일관성 비율(CR)과 기준 가중치 변화에 따른 대안 순위 민감도의 병행 검토.
- 통찰: 한계: 쌍대비교의 주관성과 판단 불일치 → 방안: CR과 별도로 평가기준 누락·중복 및 가중치 근거를 검토

<details>
<summary>핵심 용어</summary>

- **AHP(Analytic Hierarchy Process, 계층화 분석법)** : 목표·기준·대안을 계층화하고 쌍대비교로 우선순위를 구하는 다기준 의사결정 기법.
- **쌍대비교(Pairwise Comparison)** : 두 요소의 상대적 중요도를 1~9 척도와 그 역수로 판단하는 방식.
- **Eigenvector(고유벡터)** : 쌍대비교 행렬의 주고유벡터를 정규화한 상대 가중치 벡터.
- **CI(Consistency Index, 일관성 지수)** : 비교행렬의 일관성 편차를 나타내는 지표.
- **RI(Random Index, 무작위 지수)** : 같은 크기의 무작위 비교행렬에서 얻은 평균 일관성 지수.
- **CR(Consistency Ratio, 일관성 비율)** : CI를 RI와 비교해 판단 일관성을 점검하는 비율.
- **ANP(Analytic Network Process, 네트워크 분석법)** : 기준·대안 간 상호의존 관계를 네트워크로 나타내는 다기준 의사결정 기법.

## 2~4교시 25점 답안

## Ⅰ. AHP의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **AHP(Analytic Hierarchy Process, 계층화 분석법)** 는 목표·기준·대안을 계층화하고 쌍대비교로 우선순위를 구하는 다기준 의사결정 기법 |
| 목적 | 정성 판단 계량화 · 일관성 검토 · 대안 우선순위 도출 |

## Ⅱ. AHP의 특징

| 특징 | 판단상 의미 |
|---|---|
| 계층화 | 목표·기준·대안을 분리해 비교 범위를 명확화 |
| 쌍대비교 | 정성적 상대 중요도를 행렬과 가중치로 표현 |
| 일관성 검증 | CR로 판단의 모순을 보되 기준 타당성은 별도 검토 |

## Ⅲ. 계층·쌍대비교 체계와 우선순위 산출 프로세스

```text
의사결정 목표 → 평가 기준·하위 기준 → 후보 대안
                     ↓                 ↓
                  쌍대비교 행렬 → 가중치·대안 점수
                              → CR·민감도 검토 → 최종 순위
```

### AHP 분석 절차

> 계층 분해·설문 작성·고유벡터 가중치 산출·CR 검증으로 이어지는 분석 절차.

```text
① 목표·기준·대안 계층화
    ↓
② 기준·대안 쌍대비교
    ↓
③ 상대 가중치 산출
    ↓
④ 일관성 검증·종합 순위
```

### 일관성 검증 메커니즘

> 사티 기본척도의 상대 중요도 표현: 홀수 강도와 중간값, 반대 판단의 역수 적용.

```text
쌍대비교 행렬 A
    ↓ 최대 고유치 λmax
CI = (λmax − n) / (n − 1)
    ↓ 무작위지수 RI로 보정
CR = CI / RI
    ├─ 기준 충족 → 가중치 종합
    └─ 기준 초과 → 쌍대비교 재검토
```

## Ⅳ. 쌍대비교 척도와 일관성 지표 비교

### 1. 사티(Saaty)의 1~9 척도 기준

| 척도 값 | 정의 | 공학적 의미 |
|---|---|---|
| **1** | 동등 중요 (Equal) | 두 요소가 비슷하게 중요 |
| **2** | 중간값 | 1과 3 사이의 판단 |
| **3** | 약간 더 중요 (Moderate) | 한 요소가 다른 요소보다 조금 중요 |
| **4** | 중간값 | 3과 5 사이의 판단 |
| **5** | 강하게 중요 (Strong) | 한 요소가 다른 요소보다 뚜렷하게 중요 |
| **6** | 중간값 | 5와 7 사이의 판단 |
| **7** | 매우 강하게 중요 (Very Strong) | 한 요소가 다른 요소보다 매우 중요 |
| **8** | 중간값 | 7과 9 사이의 판단 |
| **9** | 극단적으로 중요 (Extreme) | 한 요소가 다른 요소보다 압도적으로 중요 |
| **역수 ($1/a_{ij}$)** | 반대 비교치 | 요소 $i$가 $j$ 대비 $a$이면, 요소 $j$는 $i$ 대비 $1/a$ |

### 2. 일관성 지표(CI, CR) 산출 수식

| 지표 | 산출 수식 | 공학적 의미·판정 |
|---|---|---|
| **Eigenvector(고유벡터)·최대 고유치 ($\lambda_{max}$)** | $A \cdot W = \lambda_{max} \cdot W$ | 주고유벡터 $W$를 정규화해 가중치로 쓰며, $\lambda_{max} = n$일 때 이상적 일관성 |
| **CI(Consistency Index, 일관성 지수)** | $CI = \frac{\lambda_{max} - n}{n - 1}$ | 이상적 일관성에서 벗어난 정도 |
| **RI(Random Index, 무작위 지수)** | 무작위 비교행렬에서 얻은 평균 CI | Saaty 기준 예: $n=3$일 때 0.58, $n=4$일 때 0.90, $n=5$일 때 1.12 |
| **CR(Consistency Ratio, 일관성 비율)** | $CR = \frac{CI}{RI}$ | 통상 $CR \leq 0.1$을 수용 기준으로 쓰며, 지침과 판단 맥락에 맞게 해석 |

비교 요소가 2개인 행렬의 RI는 0이므로 CR 산출 불가. RI가 정의된 비교행렬에서의 CR 판정.

## Ⅴ. 한계와 방안

> 비교 항목 증가에 따른 비교 횟수 $n(n-1)/2$의 증가, 계층 구조·설문 부담의 동시 검토.

| 한계 | 방안 |
|---|---|
| **비교 횟수 증가** | 기준 중복 제거·계층 재구성으로 설문 부담 감소 |
| **CR 허용기준 초과** | 모순이 큰 쌍대비교·근거 재검토로 판단 이력 확보 |
| **집단 판단 차이** | 개인별 결과·기하평균 집계·민감도 병행으로 순위 안정성 확인 |
| **기준 간 독립성 한계** | 피드백을 지원하는 **ANP** 적용 가능성 검토 |

## Ⅵ. 제언

쌍대비교 전에 이해관계자의 목표로 평가 기준의 중복·누락을 점검하고, 결과의 CR과 가중치 변화에 따른 순위 안정성을 함께 기록한다.
