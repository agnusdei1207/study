## 답안 골격
```text
[AHP] ◀━━ 머리: Ⅶ 내 의견 (일관성 비율(CR < 0.1) 검증을 자동화한 온라인 평가 도구로 평가자 편향과 재평가 비용 차단)
 ┃
 ┣━ Ⅰ 개요 ───── 복잡한 다기준 의사결정에서 정성과 정량 요인을 계층화하고 쌍대비교를 통해 최적 대안을 도출하는 사티(Saaty)의 기법
 ┣━ Ⅱ 특징 ───── 계층 구조화(Hierarchy) · 쌍대비교(1~9 척도) · 고유치 계산(가중치 산출) · 논리적 일관성 검증(CR < 0.1)
 ┣━ Ⅲ 구조 ───── 1단계: 최종 목표(Goal) ↔ 2단계: 다차원 평가 기준(Criteria) ↔ 3단계: 선택 대안(Alternatives)
 ┣━ Ⅳ 흐름 ───── ① 의사결정 계층 구조화 → ② 기준/대안 간 쌍대비교 행렬 작성 → ③ 상대적 가중치(고유벡터) 산출 → ④ 일관성(CR) 검증 및 최종 대안 합성
 ┣━ Ⅴ 비교 ───── AHP vs 다속성 효용이론(MAUT) vs 델파이 (쌍대비교/일관성검증 vs 효용함수 도출 vs 전문가 다회차 설문 합의)
 ┗━ Ⅵ 실무 ───── 기준/대안 과다 시 설문 문항 폭증($n(n-1)/2$) / 평가자 논리 모순(CR >= 0.1) 발생 / 계층 간 독립성 훼손
```
- 필수 키워드: AHP · 계층화분석법 · 토마스 사티 · 계층 구조 · 쌍대비교(Pairwise) · 일관성 지수(CI) · 일관성 비율(CR < 0.1) · IT 투자 우선순위
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 3단계 계층 구조도 → Ⅳ 쌍대비교 및 CR 수식 / 25점 = Ⅰ~Ⅶ 전개, ERP/클라우드 사업자 선정 실무 예시 및 일관성 검증 상술
- 기출: 130회 KPC `의사결정 계층화분석법(AHP)의 개념, 절차, 일관성 지수(CI/CR) 및 IT 투자 의사결정 적용 방안` → Ⅰ·Ⅲ·Ⅳ·Ⅵ

## 한 줄 본질
- 다수의 이해관계자가 참여하는 IT 사업자 선정이나 기술 도입 시 주관적 직관과 정치적 역학으로 갈등이 발생하는 병목 극복 → 목표-기준-대안의 계층 구조 하에서 1~9 척도 쌍대비교와 행렬 연산을 수행하고 논리 일관성을 수학적으로 검증 → 객관적 최적 대안 도출 / 요소 수가 늘어날 때 쌍대비교 문항 수의 기하급수적 증가

## 핵심 그림
```text
┌───────────────────────── [ AHP 의사결정 계층 구조 및 쌍대비교 체계 ] ─────────────────────────┐
│                                                                                             │
│  [ Level 1 : 최종 목표 ]                  [ 최적 클라우드 서비스 사업자(CSP) 선정 ]          │
│                                                            │                                │
│                                  ┌─────────────────────────┼─────────────────────────┐      │
│                                  ▼                         ▼                         ▼      │
│  [ Level 2 : 평가 기준 ]   [ 기술 적합성 (0.54) ]     [ 비용 효율성 (0.30) ]     [ 보안 신뢰성 (0.16) ]│
│                                  │                         │                         │      │
│                                  └─────────────────────────┼─────────────────────────┘      │
│                                                            ▼                                │
│  [ Level 3 : 선택 대안 ]                  ┌────────────────┬────────────────┐               │
│                                           │  대안 A (AWS)  │  대안 B (Azure)│               │
│                                           └────────────────┴────────────────┘               │
│                                                                                             │
│  [ 쌍대비교 및 일관성 검증 메커니즘 ]                                                       │
│  1. 쌍대비교 행렬(A): $a_{ij} = 1/a_{ji}$ (1~9 척도)                                        │
│  2. 상대적 가중치 산출: 정규화 고유벡터(Eigenvector) 계산                                   │
│  3. 일관성 검증: $CI = \frac{\lambda_{max} - n}{n - 1}$, $CR = \frac{CI}{RI} < 0.1$ (10% 이내 통과)│
│                                                                                             │
└─────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 핵심 용어
- 일관성 지수(CI, Consistency Index) 및 일관성 비율(CR, Consistency Ratio): 평가자의 판단에 모순(A > B, B > C인데 C > A로 응답)이 없는지 측정하는 지표로, 랜덤 지수(RI) 대비 비율인 CR이 0.1(10%) 미만이어야 유효한 판단으로 인정됨
- 쌍대비교(Pairwise Comparison): 모든 대안을 한꺼번에 비교하지 않고 한 번에 2개 요소씩만 짝을 지어 1(동등)부터 9(절대 우세)까지의 척도로 상대적 중요도를 평가하는 방식

## 핵심 통찰
- AHP의 핵심 경쟁력은 '정성적 가치(보안성, 브랜드)'를 '정량적 가치(비용, 응답시간)'와 동일한 단일 척도 상에서 결합해 계산할 수 있다는 점임
- 실무 설문 실패의 90%는 CR >= 0.1(논리 모순)에서 발생함 → 항목이 7개를 넘어가면 평가자가 앞서 내린 판단을 기억하지 못해 논리 붕괴가 발생하므로, 한 계층 내 요소 수는 7개 이내(Miller의 $7 \pm 2$ 법칙)로 제한해야 함
- 대안 간 상호의존성이 존재할 때는 단순 트리 구조인 AHP를 넘어 네트워크 피드백 루프를 지원하는 ANP(Analytic Network Process)로 확장해야 함

## 이웃 토픽과 구분
- AHP vs 델파이(Delphi): AHP = 계층 구조화 및 쌍대비교 행렬 연산으로 대안의 가중치를 수학적으로 도출 / 델파이 = 익명 설문과 반복 피드백을 통해 전문가 집단의 정성적 의견을 합의에 이르게 하는 기법

## 문제·원인·대책
- 적용 상황: 차세대 코어뱅킹 솔루션 도입을 위한 벤더 평가 AHP 수행
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 평가 위원들의 CR 값이 0.2 이상 나와 설문 결과 전면 무효화 | 15개 평가 기준을 한 번에 쌍대비교하여 인지 한계 초과 | 대분류-중분류 2단계 계층 분해로 레벨당 비교 항목을 4개 이하로 축소 | CR < 0.08 달성 및 설문 유효성 확보 |
| 특정 벤더에 편향된 위원의 극단적 점수 부여로 결과 왜곡 | 평가자 간 가중치 미조정 및 이상치 필터링 부재 | 기하평균(Geometric Mean)을 통한 집단 의견 통합 및 극단치 제거 | 평가 공정성 및 결과 수용도 확보 |

## 내 의견
- [실시간 CR 피드백을 지원하는 웹 기반 AHP 평가 시스템 도입] 종이 설문지로 AHP를 진행하면 수거 후 엑셀 계산 단계에서야 CR 오류가 발견되어 위원들을 다시 소집해 재설문을 받는 파행 발생 → 나라면: 위원이 웹 인터페이스에서 슬라이더로 쌍대비교를 입력하는 즉시 백엔드에서 고유치와 CR을 계산하여, 모순이 발생한 문항(CR >= 0.1)을 붉은색으로 하이라이트하고 실시간 재조정을 유도하는 인터랙티브 평가 UI 운영
