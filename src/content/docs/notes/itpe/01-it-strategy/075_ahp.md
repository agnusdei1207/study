## 큰 그림과 30초 인출

```text
[복잡한 다기준 의사결정 난제]
          │
          ▼
┌────────────────── [AHP 3대 계층 구조 및 수학적 연산] ──────────────────┐
│  Level 1 : 최종 목표 (Goal) ──> 최적 클라우드 사업자(CSP) 선정          │
│  Level 2 : 다차원 기준 (Criteria) ──> 기술 적합성, 비용, 보안 신뢰성   │
│  Level 3 : 선택 대안 (Alternatives) ──> 대안 A, 대안 B, 대안 C          │
│  ───────────────────────────────────────────────────────────────────────│
│  [쌍대비교 (1~9 척도)] ──> [고유벡터 가중치 산출] ──> [일관성 검증 (CR<0.1)]│
└─────────────────────────────────────────────────────────────────────────┘
          │
          ▼
[정성과 정량 지표 통합 최적 대안 도출 및 우선순위 확정]
```

- 본질: 복잡한 다기준 의사결정 문제를 목표-기준-대안의 계층 구조로 분해하고, 요소 간 1~9 척도의 1:1 쌍대비교(Pairwise Comparison)와 행렬 연산을 통해 상대적 중요도(가중치)를 도출하며 논리적 일관성(CR < 0.1)을 수학적으로 검증하는 사티(Thomas Saaty)의 다속성 의사결정 기법
- 위치: `의사결정 계층화 → 쌍대비교 설문 → 고유벡터 가중치 계산 → 일관성(CR) 검증 → 최종 대안 합성`
- 핵심: 제130회 KPC 기출, 계층화 구조, 쌍대비교 행렬, 일관성 지수(CI) 및 일관성 비율(CR < 0.1), ANP 확장
- 실무: 항목 수 7개 이내 제한(밀러의 법칙), 실시간 웹 기반 CR 검증 피드백, 집단 평가 기하평균 통합

## 예상문제

> 복잡한 IT 투자 및 사업자 선정 시 활용되는 계층화 분석법(AHP, Analytic Hierarchy Process)의 개념, 계층 구조 모델, 쌍대비교 및 일관성 검증(CI, CR) 산출 절차, 실무 적용 시 한계 극복 방안을 설명하시오. (25점)

## Ⅰ. 합리적 다기준 의사결정의 수학적 프레임워크, AHP 개요

- 정의: 토마스 사티(Thomas Saaty) 교수가 제안한 기법으로, 복잡한 의사결정 문제를 상위 목표부터 하위 기준 및 대안까지 계층화(Hierarchy)하고, 각 요소 간 쌍대비교를 통해 정성적 판단을 정량적 가중치로 환산하는 다기준 의사결정(MCDM) 방법론
- 등장 배경: 다수의 정성적·정량적 기준이 상충할 때 발생하는 의사결정자의 인지적 한계, 주관적 편향 및 이해관계자 간 갈등 극복, 수학적으로 검증 가능한 합리적 우선순위 도출 필요
- 핵심 목적: 정성적 가치와 정량적 지표의 단일 척도 통합, 평가자의 논리적 일관성 검증을 통한 결과 신뢰성 확보, 최적 대안 도출

#### 한줄 요약
- 의사결정 문제를 계층화하고 쌍대비교 행렬 연산과 일관성 검증으로 최적 대안을 도출함

## Ⅱ. AHP의 4대 핵심 원리 및 공학적 특징

| 원리/특징 | 세부 내용 | 통제 및 기대 효과 |
|---|---|---|
| **계층적 구조화 (Hierarchy)** | 복잡한 전체 문제를 목표, 평가 기준, 세부 기준, 대안의 트리 형태로 분해 | 문제의 복잡성 축소 및 체계적 분석 가능 |
| **쌍대비교 (Pairwise)** | 모든 대안을 한 번에 비교하지 않고 두 개씩 짝지어 상대적 중요도(1~9 척도) 평가 | 평가자의 인지 부담 경감 및 판단 용이성 확보 |
| **고유벡터 가중치 산출** | 쌍대비교 행렬의 최대 고유치에 대응하는 정규화된 고유벡터(Eigenvector) 계산 | 요소별 상대적 기여도의 수학적 도출 |
| **논리적 일관성 검증** | 평가자의 판단에 모순이 없는지 일관성 비율(CR < 0.1) 지표로 수학적 계측 | 비논리적 응답 필터링 및 의사결정 타당성 보장 |

#### 한줄 요약
- 계층 구조화, 쌍대비교, 고유치 가중치 산출, 일관성 검증의 4대 원리로 작동함

## Ⅲ. AHP 의사결정 3단계 계층 구조 및 쌍대비교 체계

```text
┌───────────────── [Level 1: 최종 목표 (Goal)] ─────────────────┐
│  - 최적 엔터프라이즈 클라우드 서비스 사업자(CSP) 선정        │
└───────────────────────────────┬────────────────────────────────┘
                                │
                                ▼
┌───────────────── [Level 2: 다차원 평가 기준 (Criteria)] ──────┐
│  ├─ 기준 1: 기술 적합성 (아키텍처, 성능, 확장성)             │
│  ├─ 기준 2: 비용 효율성 (초기 전환비, TCO, 과금 유연성)       │
│  └─ 기준 3: 보안 및 컴플라이언스 (국내외 인증, 망분리 지원)   │
└───────────────────────────────┬────────────────────────────────┘
                                │
                                ▼
┌───────────────── [Level 3: 선택 대안 (Alternatives)] ─────────┐
│  - 대안 A (CSP 1)      - 대안 B (CSP 2)      - 대안 C (CSP 3)  │
└────────────────────────────────────────────────────────────────┘
```

| 척도 값 | 정의 | 의미 및 적용 기준 |
|---|---|---|
| **1** | 동등 중요 (Equal) | 두 요소가 목표 달성에 기여하는 바가 동등함 |
| **3** | 다소 중요 (Moderate) | 경험과 판단상 한 요소가 다른 요소보다 다소 우세함 |
| **5** | 강하게 중요 (Strong) | 한 요소가 다른 요소보다 명백하게 중요함 |
| **7** | 매우 강하게 중요 (Very Strong) | 한 요소가 다른 요소에 비해 확고하게 우세함 |
| **9** | 절대적 중요 (Extreme) | 한 요소의 우세성이 논란의 여지 없이 절대적임 |
| **2, 4, 6, 8**| 중간값 | 인접한 두 판단 기준 사이의 타협치로 사용 |
| **역수 ($1/a$)**| 반대 비교치 | 요소 $i$가 $j$ 대비 $a$이면, 요소 $j$는 $i$ 대비 $1/a$ |

#### 한줄 요약
- 목표-기준-대안의 3계층과 1~9 정수 척도 및 역수 쌍대비교 행렬로 체계화함

## Ⅳ. AHP 분석 및 일관성 검증 4단계 절차

```text
① 계층 구조 설계 → ② 쌍대비교 설문 작성 → ③ 고유치 가중치 산출 → ④ 일관성(CR) 검증 및 최종 합성
   └─ 목표/기준/대안 분해    └─ 역수 행렬(n(n-1)/2)     └─ 최대 고유벡터 정규화       └─ CR < 0.1 통과 시 확정
```

| 단계 | 주요 수행 내용 | 핵심 수학 공식 및 기준 |
|---|---|---|
| **1. 계층 구조화** | 의사결정 문제를 목표(Level 1), 기준(Level 2), 대안(Level 3)으로 분해 | 의사결정 계층도 |
| **2. 쌍대비교 수행** | 동등 계층 내 요소 간 1:1 비교를 수행하여 역수 정방행렬 $A = (a_{ij})$ 구성 | 비교 횟수 = $\frac{n(n-1)}{2}$ |
| **3. 가중치 산출** | 쌍대비교 행렬의 최대 고유치($\lambda_{max}$)에 대응하는 정규화 고유벡터 $W$ 도출 | $A \cdot W = \lambda_{max} \cdot W$ |
| **4. 일관성 검증** | 일관성 지수(CI)와 랜덤 지수(RI)를 산출하여 일관성 비율(CR) 계산 | $CI = \frac{\lambda_{max} - n}{n - 1}$, $CR = \frac{CI}{RI} < 0.1$ |

#### 한줄 요약
- 계층 설계, 쌍대비교, 고유벡터 산출, CR < 0.1 검증을 거쳐 최종 대안을 도출함

## Ⅴ. 일관성 비율(CR) 산출 및 판정 메커니즘

```text
[쌍대비교 행렬 $A$] ──> [최대 고유치 $\lambda_{max}$ 산출]
                              │
                              ▼
           [일관성 지수]  $CI = \frac{\lambda_{max} - n}{n - 1}$
                              │
                              ▼
           [일관성 비율]  $CR = \frac{CI}{RI}$
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
       [CR < 0.1 (10% 이내)]         [CR \ge 0.1 (10% 초과)]
       - 논리적 일관성 합격           - 논리적 모순 발생 (기각)
       - 가중치 및 최종 대안 수용     - 쌍대비교 재설문 수행 강제
```

| 지표 명칭 | 산출 공식 및 기준 | 공학적 의미 |
|---|---|---|
| **완전 일관성 조건** | $\lambda_{max} = n$ ($CI = 0$) | 전이성 규칙(A > B, B > C이면 A > C)이 완벽히 성립하는 상태 |
| **일관성 지수 (CI)** | $CI = \frac{\lambda_{max} - n}{n - 1}$ | 완벽한 일관성 상태로부터 평가자의 판단이 벗어난 오차 크기 |
| **랜덤 지수 (RI)** | 무작위로 생성된 행렬의 CI 평균치 | 행렬 차수($n$)별 기정의된 상수 (예: $n=3$일 때 0.58, $n=4$일 때 0.90) |
| **일관성 비율 (CR)** | $CR = \frac{CI}{RI} < 0.1$ | 임의 무작위 응답 대비 논리적 일관성 비율 (10% 이내 허용) |

#### 한줄 요약
- CI와 RI의 비율인 CR이 0.1 미만이어야 평가 결과의 유효성이 수학적으로 입증됨

## Ⅵ. 실무 적용 시 한계점 및 통제 대책

- 적용 상황: 공공 정보화 사업의 클라우드 플랫폼 선정 및 IT 투자 우선순위 심의

| 문제점 | 발생 원인 | 공학적·제도적 해결 대책 | 기대 효과 |
|---|---|---|---|
| **평가 문항 수 폭증에 따른 피로** | 평가 기준 및 대안이 과다하여 비교 횟수($n(n-1)/2$) 급증 | 밀러의 법칙 준수, 계층별 항목 수를 7개 이내로 분해 제한 | 응답 집중도 향상 및 평가 시간 단축 |
| **일관성 비율(CR) 초과로 전면 무효화**| 평가자의 순간적 판단 오류로 전이성 위반 발생 | 온라인 실시간 AHP 도구를 도입하여 CR 초과 문항 즉시 피드백 | 설문 회수 후 재조사 파행 방지 |
| **평가자 간 극단적 편향치 왜곡** | 특정 벤더를 지지하는 위원의 극단적 점수(9점) 부여 | 기하평균(Geometric Mean)을 적용하여 집단 의견 통합 및 이상치 정규화 | 집단 평가의 객관성 및 공정성 확보 |
| **기준 간 상호의존성 무시** | 기준 간에 피드백과 상관관계가 존재하나 독립 가정 적용 | 네트워크 구조를 지원하는 ANP(Analytic Network Process)로 확장 | 다차원 현실 모델의 정밀 반영 |

#### 한줄 요약
- 7개 이내 제한, 실시간 웹 피드백, 기하평균 통합, ANP 확장을 통해 한계를 극복함

## Ⅶ. 실시간 인터랙티브 검증과 집단 지성 결합 중심의 결론

- **[사후 엑셀 수거 방식을 탈피한 실시간 온라인 AHP 거버넌스]**: 종이 설문지로 AHP를 진행하면 수거 후 엑셀 계산 단계에서야 CR 오류가 발견되어 설문 전체가 무효화되는 비효율이 반복됨
- 나라면: 웹 기반 의사결정 지원 시스템을 구축하여 `평가자가 슬라이더로 쌍대비교 입력 시 즉각 고유치와 CR을 백엔드 계산 → CR 0.1 초과 시 모순된 문항을 실시간 하이라이트하여 자체 수정 유도 → 기하평균 기반 집단 가중치 자동 합성` 파이프라인을 운영

#### 한줄 요약
- 실시간 인터랙티브 피드백과 집단 가중치 합성을 결합하여 AHP의 신뢰성을 극대화함

## 1교시 10점 답안 발췌

### 1. AHP(계층화 분석법)의 정의
- 복잡한 다기준 의사결정 문제를 목표-기준-대안의 계층 구조로 분해하고, 1~9 척도의 쌍대비교 행렬 연산을 통해 정성·정량 가중치를 도출하며 일관성 비율(CR < 0.1)로 신뢰성을 검증하는 정량적 의사결정 기법

### 2. AHP 3계층 모델 및 일관성 검증 메커니즘
```text
[Level 1]  최종 목표 (Goal)
              │
[Level 2]  평가 기준 (Criteria: 기술, 비용, 보안) ──> 쌍대비교 행렬(1~9 척도)
              │                                             │
[Level 3]  선택 대안 (Alternatives: A, B, C)      ──> 고유벡터 가중치 도출
                                                            │
                                                  [CR = CI / RI < 0.1 검증]
```

### 3. 차별화 제언
- 문항 수 폭증 및 인지 한계를 극복하기 위해 계층별 비교 항목을 7개 이내로 제약하고, 평가 즉시 CR을 피드백하는 웹 기반 인터랙티브 시스템을 도입하여 평가 왜곡을 방지해야 함

- 제110회 2교시: 공공 정보화 사업 우선순위 도출 기법 및 다속성 의사결정 모형
