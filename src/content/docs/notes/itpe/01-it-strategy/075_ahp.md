## Ⅰ. AHP의 개요

- 개념 : **AHP**(Analytic Hierarchy Process)는 복잡한 **다기준 의사결정** (MCDM, Multi-Criteria Decision Making) 문제에서 의사결정 요소를 **계층화** (Hierarchy)하고, 요소 간의 일대일 쌍대비교(Pairwise Comparison)를 통해 정량적 가중치와 대안의 우선순위를 도출하는 **계층화 의사결정 프로세스** (토마스 사티 교수 제안).
- 배경 및 필요성 : 정보시스템 도입, 아키텍처 선정, 공급업체 평가 등 다수의 정성적·정량적 기준이 상충할 때 의사결정자의 직관적 편향을 제거하고 논리적 합의를 도출할 방법론 필요.
- 주요 목적 : 복잡한 문제의 체계적 구조화, 정성적 판단의 수학적 수치화, 의사결정의 논리적 일관성 검증(Consistency Test).

## Ⅱ. AHP의 4단계 추진 프로세스

```text
[1. 의사결정 계층 구조화] ── 최종 목표(Goal) ──> 평가 기준(Criteria/Sub-criteria) ──> 대안(Alternatives)
          ↓
[2. 쌍대비교 행렬 작성]   ── 9점 척도(1: 동등 ~ 9: 극도로 중요)를 사용하여 기준 간/대안 간 1:1 비교
          ↓
[3. 가중치 및 우선순위 도출] ─ 행렬의 고유벡터(Eigenvector) 계산을 통해 정규화된 가중치 산출
          ↓
[4. 논리적 일관성 검증]   ── 일관성 지수(CI, Consistency Index) 및 일관성 비율(CR, Consistency Ratio = CI / RI, Random Index) 검증 (CR < 0.1 합격)
```

- **쌍대비교 행렬** : 9점 척도(1 동등 ~ 9 극도로 중요)로 기준 간·대안 간 1:1 비교.
- **고유벡터** (Eigenvector) : 행렬 계산을 통해 정규화된 가중치 산출.
- **일관성 지수** (CI, Consistency Index) : 판단의 논리적 일관성 검증, CR < 0.1 이면 합격.

## Ⅲ. 쌍대비교 척도 및 일관성 검증 기준

| 척도 값 | 정의 및 의미 | 적용 예시 |
|---|---|---|
| 1 | 동등하게 중요 (Equal Importance) | 두 기준 A와 B의 기여도가 동일함 |
| 3 | 약간 더 중요 (Moderate Importance) | 경험상 A가 B보다 조금 더 선호됨 |
| 5 | 실질적으로 중요 (Strong Importance) | 명백하게 A가 B보다 훨씬 중요함 |
| 7 | 매우 강하게 중요 (Very Strong) | A가 B에 비해 압도적으로 우세함 |
| 9 | 극단적으로 중요 (Extreme Importance) | 최고 수준의 확실성으로 A가 B보다 중요함 |
| 2, 4, 6, 8 | 중간 타협값 | 미세한 조정이 필요할 때 적용 |

- **일관성 비율 (Consistency Ratio, CR)** : 의사결정자가 "A > B 이고 B > C 인데 C > A"라고 모순되게 판단하는 오류를 측정하는 지표로, CR < 0.1 (10% 미만) 이어야 판단의 유효성 인정.

## Ⅳ. AHP(계층화 의사결정) 적용 시 주요 한계점 및 해결 방안

- 쌍대비교 항목 증가에 따른 평가자의 인지 과부하 :
  - 한계점 : 비교 요소 수가 $n$개일 때 비교 횟수가 $\frac{n(n-1)}{2}$로 급증하여 평가 후반부 집중력 저하 및 자의적 응답.
  - 해결 방안 : 계층당 평가 요소를 매지컬 넘버 7($7 \pm 2$)개 이내로 제한, 불완전 쌍대비교(Incomplete Pairwise Comparison) 알고리즘 활용.
- 일관성 비율(CR) 불만족 시 재평가의 번거로움 :
  - 한계점 : 평가자의 판단 일관성 비율($CR \ge 0.1$)을 만족하지 못할 경우 전체 평가를 다시 수행해야 하는 비효율.
  - 해결 방안 : 웹 기반 실시간 AHP(Analytic Hierarchy Process) 설문 도구를 활용해 불일치 유발 항목을 실시간 하이라이트하고 즉각 보정 유도.
- 기준 간 독립성 가정의 비현실성 :
  - 한계점 : 하위 평가 기준들이 서로 상호작용하거나 피드백 관계를 가짐에도 독립적 계층 구조로 강제 분할하는 한계.
  - 해결 방안 : 기준 간 네트워크 상호의존성을 반영할 수 있는 ANP(Analytic Network Process) 기법으로 확장 적용.

## Ⅴ. IT 프로젝트에서의 AHP 활용을 위한 기술사적 제언

- 소프트웨어 및 솔루션 평가 시 BMT/PoC(Proof of Concept) 지표와 결합 : 기능 점수나 성능 수치를 AHP의 하위 기준으로 편입하여 정량적 벤치마크 결과와 정성적 전문가 판단의 유기적 결합.
- 집단 의사결정 시 기하평균(Geometric Mean) 활용 : 다수의 평가위원이 참여하는 경우, 개별 평가값을 산술평균하지 않고 역수성을 보존하는 기하평균을 적용하여 종합 쌍대비교 행렬 도출.
- 민감도 분석(Sensitivity Analysis)을 통한 결과 안정성 검증 : 특정 평가 기준의 가중치가 미세하게 변동했을 때 최종 대안 순위가 뒤바뀌는지 민감도 테스트를 거쳐 의사결정의 견고성 확보.
