## 큰 그림과 30초 인출

- 본질: **AHP(Analytic Hierarchy Process)**는 복잡한 다기준 의사결정 문제를 계층화하고 1:1 **쌍대비교**와 고유치 연산으로 가중치를 도출하는 계층화 분석법
- 메커니즘: `목표 → 기준 → 대안`의 3계층 구조에서 $n(n-1)/2$회 쌍대비교 후 **일관성 비율(CR < 0.1)**을 수학적으로 검증
- 산출: 쌍대비교 역수행렬 · 정규화 고유벡터(가중치) · 일관성 비율(CR) · 종합 우선순위

<details>
<summary>핵심 용어</summary>

- **AHP(Analytic Hierarchy Process)**: 토마스 사티(Thomas Saaty)가 고안한 다기준 의사결정(MCDM) 기법
- **Pairwise Comparison(쌍대비교)**: 복잡한 다자간 비교 대신 두 요소를 1:1로 짝지어 상대적 중요도를 1~9 정수 척도로 평가하는 기법
- **Eigenvector(고유벡터)**: 쌍대비교 행렬의 최대 고유치에 대응하는 정규화된 벡터로 각 요소의 상대적 가중치를 의미
- **CI(Consistency Index)**: 평가자의 판단이 완벽한 일관성($\lambda_{max} = n$)으로부터 벗어난 오차 크기를 나타내는 지표
- **RI(Random Index)**: 무작위 생성 행렬로부터 얻은 난수 일관성 지수 평균값
- **CR(Consistency Ratio)**: $CI / RI$로 정의되며 0.1(10%) 미만일 때 평가의 논리적 일관성을 공식 수용

</details>

## 예상문제

> IT 투자 타당성 분석 및 솔루션 선정 시 활용되는 계층화 분석법(AHP, Analytic Hierarchy Process)의 개념, 계층 구조 모델, 1~9 척도 쌍대비교 원리, 일관성 검증(CI, CR) 산출 절차 및 실무 한계 극복 방안을 설명하시오. (25점)

## Ⅰ. 합리적 다기준 의사결정의 수학적 기준, AHP의 개요

> AHP는 직관적 정성 판단을 **쌍대비교 행렬**로 계량화하며, 결과의 타당성은 평가자의 주관이 아닌 **일관성 비율(CR < 0.1)**의 수학적 검증으로 판정함.

- 정의: 복잡한 다기준 의사결정 문제를 목표-기준-대안의 계층으로 구조화하고 **쌍대비교(Pairwise Comparison)** 행렬 연산을 통해 가중치를 도출하는 **계층화 분석법(Analytic Hierarchy Process)**
- 목적: 정성 판단 계량화, 일관성 비율(CR) 검증 및 주관적 편향 배제

## Ⅱ. AHP 분석 및 일관성 검증 4단계 파이프라인

## Ⅲ. 쌍대비교 1~9 척도 및 일관성 검증 산식

> 사티의 1~9 척도는 인간의 감각적 구별 한계를 수학적으로 구조화한 체계임.

### 1. 사티(Saaty)의 1~9 척도 기준

| 척도 값 | 정의 | 공학적 의미 |
|---|---|---|
| **1** | 동등 중요 (Equal) | 두 평가 요소가 목표 달성에 동등하게 기여 |
| **3** | 다소 중요 (Moderate) | 한 요소가 다른 요소보다 약간 더 중요함 |
| **5** | 강하게 중요 (Strong) | 한 요소가 다른 요소보다 확고하게 우세함 |
| **7** | 매우 강하게 중요 (Very Strong) | 한 요소의 우세성이 실증적으로 입증됨 |
| **9** | 절대적 중요 (Extreme) | 한 요소가 타 요소 대비 압도적·절대적 우위 |
| **역수 ($1/a_{ij}$)** | 반대 비교치 | 요소 $i$가 $j$ 대비 $a$이면, 요소 $j$는 $i$ 대비 $1/a$ |

### 2. 일관성 지표(CI, CR) 산출 수식

| 지표 | 산출 수식 | 공학적 의미 및 판정 |
|---|---|---|
| **최대 고유치 ($\lambda_{max}$)** | $A \cdot W = \lambda_{max} \cdot W$ | 행렬 크기 $n$ 이상이며, $\lambda_{max} = n$일 때 완벽한 일관성 |
| **일관성 지수 (CI)** | $CI = \frac{\lambda_{max} - n}{n - 1}$ | 완벽한 일관성 상태로부터 벗어난 판단 편차의 평균 |
| **랜덤 지수 (RI)** | 난수 행렬 평균 CI 상수 | $n=3$일 때 0.58, $n=4$일 때 0.90, $n=5$일 때 1.12 |
| **일관성 비율 (CR)** | $CR = \frac{CI}{RI}$ | **$CR < 0.1$ 합격**, $CR \ge 0.1$ 시 설문 재수행 강제 |

## Ⅳ. AHP 실무 적용 시 위험 요인 및 기술사적 대책

> 평가 요소 수가 7개를 넘어가면 평가자 피로도로 인해 전이성 위반(CR 초과)이 급증하므로 엄격한 설계 통제가 필요함.

| 위험 | 대책 | 효과 |
|---|---|---|
| **비교 횟수 폭증** | **밀러의 법칙(7±2)** 준수, 계층별 항목 수 7개 이내 제한 | 평가자 인지 과부하 방지 및 설문 소요 시간 단축 |
| **CR 초과 전면 무효화** | **실시간 웹 기반 AHP 시스템** 도입으로 실시간 피드백 | 전이성 모순 사전 가이드 및 설문 제출 시점 CR < 0.1 통과 |
| **집단 평가치 왜곡** | **기하평균(Geometric Mean)** 기반 집단 가중치 통합 | 극단치(Outlier) 왜곡 차단 및 집단 의사결정 공정성 확보 |
| **기준 간 독립성 한계** | 네트워크 피드백을 지원하는 **ANP(Analytic Network Process)** 전환 | 기준 간 상호 연관성 반영 및 다차원 의사결정 고도화 |

## Ⅴ. 실시간 인터랙티브 검증과 집단 지성 결합을 위한 기술사적 제언

> 종이 설문지 사후 집계 방식은 CR 초과 시 재설문 비용을 발생시키므로, 실시간 인터랙티브 검증 도구와 기하평균 통합 파이프라인이 필수적임.

### 학습자 통찰 메모 — 답안 밖

- [핵심 통찰]: AHP의 최대 실무적 병목은 전문가 설문을 마친 뒤 엑셀을 돌렸을 때 CR이 0.1을 넘어 데이터 전체를 버려야 하는 사태임. 평가자가 슬라이더를 움직일 때마다 실시간으로 $\lambda_{max}$와 CR을 백엔드 계산하여 모순된 문항을 알려주는 인터랙티브 UX가 핵심 성공 요인임.
- 나라면: 웹 기반 실시간 AHP 포털을 구축하여 `평가 위원의 입력 즉시 CR 실시간 피드백 → 전이성 위반 문항 자동 가이드 → 집단 평가 시 기하평균 기반 자동 수렴` 파이프라인을 운영하여 평가 공정성과 적시성을 보증하겠음.

### 실전 답안용 기술사적 제언

- 판정: 사후 수동 계산을 배제하고 실시간 인터랙티브 일관성 검증 확립
- 대안: **실시간 웹 기반 AHP 평가 시스템 및 기하평균 집단 통합** 파이프라인 가동
- 검증: 전 평가자 **일관성 비율(CR) 0.1 미만** 달성률 100%
- 효과: 설문 파행 및 재조사 비용 차단 · 공공·금융 IT 투자 의사결정 공정성 확보
