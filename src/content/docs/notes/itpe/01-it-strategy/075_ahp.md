## 지식 로드맵 내 현재 위치

IT 전략·관리 → 의사결정 기법 → **AHP(Analytic Hierarchy Process)**

## 30초 인출

- 본질: AHP(Analytic Hierarchy Process)는 목표·평가기준·대안을 계층으로 나누고 두 요소씩 비교해 대안의 우선순위를 정하는 다기준 의사결정 기법
- 메커니즘: 계층별 쌍대비교 행렬의 고유벡터로 가중치를 구하고 일관성 비율(CR)로 판단 모순을 확인한 뒤 기준 가중치와 대안 점수를 곱해 종합 순위 산출
- 통찰: CR은 기준의 누락·중복을 잡지 못하므로 쌍대비교 전 기준 계층 점검과 순위 안정성 확인

<details>
<summary>핵심 용어</summary>

- **AHP(Analytic Hierarchy Process, 계층화 분석법)** : 목표·평가기준·대안을 계층화하고 쌍대비교로 우선순위를 구하는 다기준 의사결정 기법. Saaty가 제안
- **쌍대비교(Pairwise Comparison)** : 같은 계층의 두 요소를 1~9 척도와 그 역수로 비교하는 판단 방식
- **고유벡터(Eigenvector)** : 쌍대비교 행렬에서 구한 주고유벡터. 정규화해 요소별 가중치로 사용
- **CI(Consistency Index, 일관성 지수)** : 최대 고유치가 행렬 크기에서 벗어난 정도로 계산한 판단 불일치 지표
- **RI(Random Index, 무작위 지수)** : 같은 크기의 무작위 행렬에서 얻은 평균 CI. CR 계산의 기준값
- **CR(Consistency Ratio, 일관성 비율)** : CI를 RI로 나눈 비율. 통상 0.1 이하를 수용 기준으로 사용
- **ANP(Analytic Network Process, 네트워크 분석법)** : 기준·대안 사이의 상호의존과 피드백을 네트워크로 반영하는 AHP의 확장 기법
- **민감도 분석(Sensitivity Analysis)** : 기준 가중치를 바꿔 가며 대안 순위가 유지되는지 확인하는 분석
- **SaaS(Software as a Service)** : 공급자가 운영하는 소프트웨어를 인터넷으로 구독해 쓰는 클라우드 서비스 형태

## 2~4교시 25점 답안

## Ⅰ. AHP의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **AHP(Analytic Hierarchy Process, 계층화 분석법)** 는 목표·평가기준·대안을 계층화하고 쌍대비교로 대안의 우선순위를 구하는 다기준 의사결정 기법 |
| 목적 | 정량화가 어려운 여러 기준의 판단을 비율 척도의 가중치로 바꾼 대안 선택 |

## Ⅱ. 단순 가중합과 구별되는 AHP의 특징

| 특징 | 의미 |
|---|---|
| 계층화 | 복잡한 결정을 목표·기준·대안으로 분해해 한 번에 비교할 범위 축소 |
| **쌍대비교** | 여러 요소를 한꺼번에 점수화하지 않고 두 요소씩 상대 중요도 판단 |
| 비율 척도 가중치 | 정성 판단을 고유벡터 계산으로 합이 1인 가중치로 변환 |
| 일관성 검증 | 판단 간 모순 정도를 **CR** 로 확인 |

## Ⅲ. AHP 분석 절차와 일관성 검증

### AHP 분석 절차

```text
① 목표·평가기준·대안의 계층 구성
    ↓
② 계층별 쌍대비교 (1~9 척도)
    ↓
③ 비교행렬의 가중치 산출 (고유벡터)
    ↓
④ 일관성 검증 (CR)
    ↓
⑤ 기준 가중치 × 대안 점수의 종합 순위
```

### 일관성 검증 확대: CR 판정

```text
쌍대비교 행렬의 최대 고유치 λmax
    ↓
CI = (λmax − n) / (n − 1)
    ↓
CR = CI / RI
    ├─ CR ≤ 0.1 → 가중치 사용
    └─ CR > 0.1 → 해당 비교의 재판단
```

RI는 행렬 크기에 따라 다르며 Saaty 기준 n=3일 때 0.58, n=4일 때 0.90, n=5일 때 1.12

## Ⅳ. 계층 구성과 척도, AHP·ANP 비교

### 평가 계층의 구성 예

```text
목표 ── 차세대 시스템 구축 방식 선정
    │
    ├─ 평가기준 ── 비용·기술 적합성·위험
    │
    └─ 대안 ── 자체 개발·패키지 도입·SaaS 이용
```

대안은 각 평가기준 아래에서 따로 쌍대비교하고, 기준 가중치로 합산

### 쌍대비교 척도

| 값 | 의미 |
|---|---|
| 1 | 두 요소가 동등하게 중요 |
| 3 | 한 요소가 약간 더 중요 |
| 5 | 한 요소가 뚜렷하게 중요 |
| 7 | 한 요소가 매우 강하게 중요 |
| 9 | 한 요소가 극단적으로 중요 |
| 2·4·6·8 | 인접 판단의 중간값 |
| 역수 | i가 j보다 a만큼 중요하면 j는 i 대비 1/a |

### AHP와 ANP 비교

| 구분 | AHP | **ANP** |
|---|---|---|
| 구조 | 상위에서 하위로 가는 단방향 계층 | 요소 간 상호의존·피드백 네트워크 |
| 전제 | 같은 계층 기준 간 독립 | 기준 간 영향 허용 |
| 비교 부담 | 상대적으로 적음 | 의존 관계별 추가 비교로 증가 |
| 적합 상황 | 기준이 서로 독립적인 선정·평가 | 기준이 서로 영향을 주는 전략 선택 |

## Ⅴ. AHP 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 기준·대안 수 증가에 따른 비교 횟수 n(n−1)/2의 급증 | 중복 기준 통합과 하위 계층 분리로 한 행렬의 비교 요소 축소 |
| CR 기준을 충족해도 평가기준의 누락·중복은 미검출 | 쌍대비교 전 이해관계자와 기준 계층의 누락·중복 점검 |
| 평가자 간 판단 차이로 결과 편향 | 평가자별 행렬의 기하평균 집계와 가중치 **민감도 분석** |
| 기준 간 상호의존이 큰 문제에서의 가중치 왜곡 | 상호의존이 크면 ANP 선택, 기준이 독립적이면 AHP 유지 |

## Ⅵ. 제언

쌍대비교 전 평가기준 계층의 누락·중복 점검을 선행 조건으로 두고, 결과 확정 전 가중치 변화에 따른 대안 순위의 안정성 확인

### AHP 평가 수행 구조

```text
AHP 평가 수행
    │
    ├─ 의사결정 주관 부서 ── 목표·평가기준 계층 확정
    │
    ├─ 평가자 ── 계층별 쌍대비교
    │
    └─ 분석 담당 ── CR·민감도 분석과 결과 보고
```

### 분석 담당 역할 확대: 순위 안정성 확인 절차

```text
기준 가중치와 종합 순위 산출
    ↓
주요 기준의 가중치를 일정 범위에서 변동
    ↓
대안 순위 변화 확인
    ├─ 순위 유지 → 결과 확정
    └─ 순위 역전 → 해당 기준의 판단 근거 재검토
```

### 선택 근거: CR 중심 검증과의 비교

| 구분 | CR 중심 검증 | 제언: 기준 점검과 순위 안정성 확인 |
|---|---|---|
| 검증 대상 | 비교 판단 간 모순 | 기준 계층의 누락·중복과 판단 모순 |
| 검증 시점 | 쌍대비교 후 | 쌍대비교 전과 후 |
| 결과 확정 조건 | CR ≤ 0.1 | CR 충족과 가중치 변동 시 순위 유지 |
