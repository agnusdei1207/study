## 해당 토픽 큰 그림과 30초 인출

```text
[사업유형·범위]
      ↓
산정방식 선택 → 규모·공수 → 단가·보정 → 검토·계약 → 변경관리
 FP·업무량·요율·투입공수·SLA
```

- 인출어: `개발=FP 중심`, `운영=업무량·투입공수·SLA`, `유지관리=범위·요율/공수`, `핵심=산정근거+변경추적`

## 예상문제

> SW 사업 대가산정의 목적과 사업유형별 산정방식을 설명하고, 기능점수 기반 개발비 산정절차와 변경·검증방안을 제시하시오. (25점)

## Ⅰ. 적정 예산과 공정한 계약을 위한 대가산정 개요

**SW 사업 대가산정**은 기획·개발·재개발·유지관리·운영 등 사업범위에 적합한 규모·업무량·공수와 단가를 적용해 예산·발주·계약의 근거를 만드는 활동이다. 계산식보다 범위, 가정, 기준시점과 변경이력을 추적 가능하게 남기는 것이 중요하다.

## Ⅱ. 산정원칙과 적용범위

| 원칙 | 적용내용 |
|---|---|
| 범위 명확성 | 대상 기능·데이터·인터페이스·품질·운영업무 정의 |
| 방식 적합성 | 개발·운영·유지관리·기획 등 사업유형에 맞는 방식 선택 |
| 근거 추적성 | 요구사항-기능점수/업무량-단가-대가 연결 |
| 최신성 | 공표 가이드·단가·임금·보정기준의 적용시점 명시 |
| 변경 공정성 | 과업변경 시 동일 기준으로 규모·비용·일정 재산정 |

## Ⅲ. 사업유형별 대가산정 체계

```text
[기획] 업무량·투입공수
[개발] 기능규모(FP) × 단가 × 적용 보정
[재개발] 변경 기능규모와 재사용·영향 범위
[유지관리] 대상 SW·업무범위에 따른 요율 또는 공수
[운영] 운영업무량·투입공수·서비스수준
[개발+운영] 각 영역을 해당 방식으로 산정 후 합산·범위 구분
```

| 사업유형 | 대표 산정기준 | 핵심 산출물 |
|---|---|---|
| SW 개발 | 기능점수 또는 적용 가능한 대체기준 | 기능목록·FP 산정서 |
| 유지관리 | 대상·난이도·업무범위·요율/공수 | 자산목록·업무분장 |
| 운영 | 운영업무량·투입공수·SLA | 운영항목·인력·서비스수준 |
| 기획·컨설팅 | 업무량·투입공수 | WBS·역할·공수근거 |
| AI 도입 | 솔루션·인프라·데이터·커스터마이징 등 범위 | 항목별 비용근거 |

## Ⅳ. 기능점수 기반 개발비 산정절차

```text
범위·경계 → 기능 식별 → 유형·복잡도 → FP 집계 → 단가·보정 → 검증
              ILF·EIF       EI·EO·EQ
```

1. 사용자 관점의 애플리케이션 경계와 측정목적을 확정한다.
2. 데이터 기능 ILF·EIF와 트랜잭션 기능 EI·EO·EQ를 식별한다.
3. 최신 가이드 기준으로 복잡도와 기능점수를 산정하고 근거를 남긴다.
4. 기능점수 단가와 적용 가능한 보정요소를 근거와 함께 반영한다.
5. 중복·누락·경계·복잡도를 독립 검토하고 요구사항 추적표와 대조한다.
6. 기준선을 계약에 반영하고 과업변경 시 증감 FP와 영향을 재산정한다.

## Ⅴ. 기능점수·투입공수·SLA 방식 비교

| 비교축 | 기능점수 | 투입공수 | SLA 기반 |
|---|---|---|---|
| 측정대상 | 사용자 기능규모 | 역할별 노력·기간 | 서비스수준·성과 |
| 적합영역 | 개발·재개발 | 기획·특수업무·운영 | 운영·ITO |
| 장점 | 기술과 비교적 독립, 범위비교 | 업무특성 반영 용이 | 결과·품질 중심 |
| 한계 | 경계·복잡도 판단 필요 | 생산성 차이·과다투입 위험 | 지표·측정·책임 설계 필요 |
| 통제 | 기능목록·검증 | WBS·역할·공수근거 | 기준선·측정식·서비스크레딧 |

## Ⅵ. 누락·저가·변경분쟁의 통제

| 위험 | 대책 | 확인자료 |
|---|---|---|
| 요구 누락·중복 | 요구-FP 추적표와 독립검증 | 기능목록·검토기록 |
| 부적절한 산정방식 | 사업유형·측정 가능성 사전판단 | 산정방식 선정근거 |
| 보정계수 자의성 | 최신 가이드의 적용조건과 증빙 | 보정 근거·계산서 |
| 비기능·전환비 누락 | 시험·보안·데이터전환·교육·운영준비 명시 | WBS·견적 범위 |
| 과업변경 무상화 | 변경요청-영향분석-승인-재기준선 | 변경대장·증감대가 |
| 개발·운영 경계혼재 | 업무와 책임을 분리 산정 후 합산 | RACI·업무분장 |

## Ⅶ. 숫자보다 산정기준선의 추적성이 중요한 결론

적정대가는 단가 인상만으로 확보되지 않는다. **명확한 범위, 적합한 산정방식, 최신 기준, 독립검증과 변경관리**를 연결해 발주자와 공급자가 동일한 기준선으로 품질·비용·일정을 관리해야 한다.

## 1교시 10점 답안 발췌

```text
목적: 예산·발주·계약을 위한 적정하고 추적 가능한 대가 기준선
체계: 개발(FP) / 기획·특수업무(공수) / 유지관리(범위·요율/공수) / 운영(업무량·SLA)
FP: 경계 → ILF·EIF·EI·EO·EQ → 복잡도·FP → 단가·보정 → 검증
비교: FP=기능규모, 공수=노력, SLA=서비스성과
통제: 요구-FP 추적, 최신 기준, 비기능·전환범위, 변경 재산정
```
