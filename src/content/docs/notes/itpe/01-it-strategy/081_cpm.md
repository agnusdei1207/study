## 연관 키워드

- CPM, 네트워크 다이어그램, 임계경로, 여유시간, PERT, 자원평준화

## Ⅰ. CPM의 개요

- 핵심 요약 : 작업의 선후관계와 기간을 네트워크로 표현해 최장경로와 최소 프로젝트 기간을 계산하는 CPM 일정기법.
- 개념 : **CPM** (Critical Path Method, 임계경로법)은 작업의 선후관계와 소요기간을 네트워크 다이어그램으로 표현하고, 정방향·역방향 계산으로 프로젝트의 최소 완료기간과 임계작업을 식별하는 일정관리 기법.
- 배경 및 필요성 : 작업 의존관계와 기간 여유를 파악하지 못하면 프로젝트 완료일과 지연 원인 판단이 어려움.
- 주요 목적 : 네트워크 논리와 기간을 바탕으로 프로젝트의 최단 완료기간과 임계작업 식별, 일정 통제 근거 마련.

## Ⅱ. CPM의 특징 및 장점

- 핵심 요약 : 선후관계·기간 계산으로 최소 완료기간을 산출하고, 여유시간 분석으로 지연 영향과 우선순위를 판단.

1. 네트워크 논리관계 표현 : 작업을 노드와 화살표로 연결해 선후관계와 기간을 시각화 → 작업 의존성과 경로 구조를 한눈에 파악.
2. 정방향·역방향 계산 : ES/EF와 LS/LF를 계산해 각 작업의 허용 시작·종료 시점을 산출 → 최소 프로젝트 완료기간과 일정 여유 확보.
3. 총여유·자유여유 분석 : TF와 FF를 계산해 지연이 프로젝트 완료일과 후속작업에 미치는 영향 구분 → 작업 우선순위와 지연 허용 범위 판단.
4. 임계경로 식별 : 여유시간이 0인 작업을 연결해 최장경로를 산출 → 프로젝트 기간을 결정하는 핵심 작업 집중관리.
5. 진척 기반 경로 재계산 : 실제 착수·완료일을 반영해 경로와 완료일을 갱신 → 일정예측의 최신성과 대응 가능성 확보.

## Ⅲ. CPM의 구조 (흐름)

- 핵심 요약 : 작업분해 → 의존관계·기간 산정 → 네트워크 계산 → 임계경로·여유 분석 → 진척 갱신.

```text
[ CPM 계산 흐름 ]

작업분해(WBS)
    ↓
선후관계·기간 산정
    ↓
네트워크 다이어그램 작성
    ↓
정방향 계산 (ES, EF)
    ↓
역방향 계산 (LS, LF)
    ↓
여유시간 (TF, FF) 계산
    ↓
임계경로·완료기간 확정
```

```text
[ 여유시간 관계 ]

ES → EF : 정방향 (가장 빠른 시작·종료)
LS ← LF : 역방향 (가장 늦은 시작·종료)
TF = LS - ES = LF - EF (총여유)
FF = 후속작업 ES - 현재 EF (자유여유)
```

## Ⅳ. CPM과 PERT·CCPM의 비교

- 핵심 요약 : CPM은 확정 기간 가정, PERT는 확률적 세 점 추정, CCPM은 자원제약·버퍼 고려.

| 비교 항목 | CPM | PERT | CCPM |
| --- | --- | --- | --- |
| 기간 가정 | 확정기간 | 세 점 추정(낙관·최빈·비관) | 버퍼를 포함한 보호 기간 |
| 핵심 산출 | 임계경로·최소 완료기간 | 기대기간·분산 | 자원제약·버퍼 관리 |
| 적합 상황 | 의존관계와 여유 중심 일정 통제 | 기간 변동성이 큰 작업 추정 | 공유자원·다중프로젝트 통제 |

## Ⅴ. CPM의 한계와 방안

- 핵심 요약 : 기간오차는 실적기반 재추정, 자원과배정은 자원평준화로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 기간 오차 | 확정기간 가정으로 실제 변동 미반영 → 완료일 예측 오차 | 실적기반 기간 재추정·세 점 추정 병행 | 기간 편차, 완료일 예측 오차 |
| 임계경로 변동 | 작업 지연·속도 변화로 경로 이동 | 진척 반영 재계산·감시대상 경로 다중 관리 | 임계경로 변경 횟수 |
| 자원 과배정 | 논리관계만 고려해 동일 자원 중복 투입 | 자원평준화·자원 평활화 적용 | 과배정 자원, 지연 작업 수 |
| 네트워크 복잡성 | 대규모 프로젝트의 관계 관리 부담 | 작업 단위 분할·WBS·일정 소프트웨어 활용 | 관계 오류, 갱신 소요시간 |

## Ⅵ. CPM 적용에 대한 기술사적 제언

- 핵심 요약 : 네트워크 계산을 실제 진척·자원 가용성과 함께 운영하고 임계작업 지연의 복구안을 준비.
- 일정관리 : 일정관리자는 실제 착수·완료 실적을 반영해 임계경로를 주기적으로 재산정하고 경로 변경을 보고.
- 자원관리 : 자원 가용성과 우선순위를 함께 검토해 과배정을 조정하고 핵심작업의 대체 자원을 준비.
- 거버넌스 : 일정 기준선과 변경 절차를 정하고, 임계작업 지연 시 회복 대안(추가 인력·범위 조정·기간 연장)을 사전에 정의.

## Ⅶ. 결론

- 핵심 요약 : CPM은 작업의 선후관계와 기간을 네트워크로 표현해 최장경로와 최소 프로젝트 기간을 계산하는 일정관리 기법.
- 시사점 : 임계경로와 여유시간은 실제 진척·자원 상황에 맞춰 갱신할 때 일정통제에 유효.
