## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 일정관리 → **CPM(Critical Path Method)**

## 30초 인출

- 본질: CPM(Critical Path Method)은 작업의 선후관계와 확정 기간으로 가장 긴 경로를 찾아 프로젝트 최단 완료기간을 계산하는 일정관리 기법
- 메커니즘: 전진 계산으로 ES·EF, 역진 계산으로 LS·LF를 구하고 총여유가 0인 작업을 이어 주공정선 판정
- 통찰: 주공정만 줄이면 새 주공정이 생겨 완료일이 줄지 않으므로 단축 단위마다 비용 구배 비교와 재계산

<details>
<summary>핵심 용어</summary>

- **CPM(Critical Path Method)** : 작업의 선후관계와 확정 기간으로 가장 긴 경로를 찾아 최단 완료기간과 여유시간을 계산하는 일정관리 기법
- **주공정선(Critical Path)** : 시작부터 종료까지 가장 긴 경로. 이 경로 작업의 지연이 곧 프로젝트 완료일의 지연
- **전진 계산(Forward Pass)** : 시작 작업부터 순방향으로 조기착수일(ES)과 조기완료일(EF)을 구하는 계산
- **역진 계산(Backward Pass)** : 종료 작업부터 역방향으로 늦은완료일(LF)과 늦은착수일(LS)을 구하는 계산
- **총여유(Total Float)** : 프로젝트 완료일을 늦추지 않고 한 작업이 늦어질 수 있는 최대 기간
- **자유여유(Free Float)** : 바로 뒤 작업의 조기착수일을 늦추지 않고 한 작업이 늦어질 수 있는 기간
- **비용 구배(Cost Slope)** : 작업 기간을 하루 줄일 때 드는 추가 비용
- **크래싱(Crashing)** : 주공정 작업에 자원을 추가 투입해 기간을 줄이는 일정 단축 기법
- **패스트트래킹(Fast Tracking)** : 순서대로 하던 작업을 겹쳐 수행해 기간을 줄이는 일정 단축 기법
- **PERT(Program Evaluation and Review Technique)** : 낙관·최빈·비관 3점 추정으로 작업 기간의 불확실성을 반영하는 일정 계산 기법
- **AON(Activity on Node)** : 노드에 작업을, 화살표에 선후관계를 표시하는 네트워크 표현

## 2~4교시 25점 답안

## Ⅰ. CPM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CPM(Critical Path Method)** 은 작업의 선후관계와 확정 기간으로 가장 긴 경로를 찾아 프로젝트 최단 완료기간을 계산하는 일정관리 기법 |
| 목적 | 완료일을 결정하는 작업의 식별과 일정 단축 대상의 선정 |

## Ⅱ. 기간 합계가 아닌 최장 경로로 완료일을 정하는 특징

| 특징 | 의미 |
|---|---|
| 선후관계 네트워크 | 작업 기간의 단순 합이 아닌 가장 긴 의존 경로가 완료일 결정 |
| 확정 기간 가정 | 작업마다 하나의 기간 값을 사용하는 결정론적 계산 |
| 여유시간 산출 | 작업별 지연 허용 폭과 주공정 여부의 동시 확인 |
| 주공정선의 이동 | 한 경로를 줄이면 다른 경로가 새 주공정선이 되는 구조 |

## Ⅲ. 주공정선 산정 절차와 합류·분기 계산

### 주공정선 산정 절차

```text
작업 목록·기간·선후관계 정의
    ↓
AON 네트워크 작성
    ↓
전진 계산: ES·EF
    ↓
역진 계산: LS·LF
    ↓
총여유 산출: TF = LS − ES
    ↓
총여유 0인 작업 연결 → 주공정선
```

### 전진·역진 계산 확대: 합류·분기 지점의 규칙

```text
합류 지점 (전진 계산)
    선행 A의 EF ─┐
                 ├─ 큰 값 선택 → 후속 C의 ES
    선행 B의 EF ─┘

분기 지점 (역진 계산)
    후속 D의 LS ─┐
                 ├─ 작은 값 선택 → 선행 C의 LF
    후속 E의 LS ─┘
```

| 구분 | 계산식 (0일 시작 관례) |
|---|---|
| 전진 계산 | $EF = ES + D$, 후속 $ES = \max(\text{선행 } EF)$ |
| 역진 계산 | $LS = LF - D$, 선행 $LF = \min(\text{후속 } LS)$ |
| 총여유 | $TF = LS - ES = LF - EF$ |
| 자유여유 | $FF = \min(\text{후속 } ES) - EF$ |

1일 시작 관례에서는 $EF = ES + D - 1$, 후속 $ES = \max(EF) + 1$로 한 칸씩 보정

## Ⅳ. 일정 단축 기법과 PERT의 비교

### 일정 단축 기법 비교

| 구분 | **크래싱** | **패스트트래킹** |
|---|---|---|
| 방식 | 주공정 작업의 자원 추가 투입 | 순차 작업의 병행 수행 |
| 대가 | 추가 비용 | 재작업 위험 증가 |
| 적합 조건 | 비용 여유와 자원 투입으로 기간이 줄어드는 작업 | 선후 작업 간 인터페이스를 먼저 확정할 수 있는 작업 |
| 대상 선정 기준 | 주공정 작업 중 **비용 구배** 최저 작업 | 선행 결과 변경 가능성이 낮은 작업 |
| IT 사업의 예 | 시험 인력 추가, 야간 병행 작업 | 상세 설계 완료 전 공통 모듈 개발 착수 |

### CPM과 PERT의 기간 추정 비교

| 구분 | CPM | **PERT** |
|---|---|---|
| 작업 기간 | 확정 값 1개 | 낙관(a)·최빈(m)·비관(b) 3점 추정 |
| 기대 기간 | 주어진 값 | $(a + 4m + b) / 6$ |
| 적합 조건 | 경험이 쌓인 반복 작업 | 신기술 도입처럼 기간 변동이 큰 작업 |

## Ⅴ. CPM 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 확정 기간 가정으로 불확실성 미반영 | 기간 변동이 큰 작업에 PERT 3점 추정 적용 |
| 자원 제약 미고려로 실행 불가능한 일정 | 자원 평준화 후 네트워크 재계산 |
| 납기 압박 시 무차별 인력 투입 | 비용 여유가 있으면 비용 구배 최저 주공정 작업부터 크래싱 선택 |
| 병행 착수 후 설계 변경으로 재작업 | 인터페이스를 먼저 확정한 작업에 한정한 패스트트래킹 선택 |
| 단축 후 주공정선 이동의 미확인 | 단축 단위마다 전진·역진 재계산 |

## Ⅵ. 제언

납기 단축 시 주공정 작업의 비용 구배와 재작업 위험으로 단축 기법을 고르고, 하루 단위 단축마다 네트워크 재계산으로 완료일 감소 확인

### 일정 단축안 선정 구조

```text
일정 단축안 선정
    │
    ├─ 단축 대상 ── 주공정·준주공정 작업
    │
    ├─ 단축 기법 ── 크래싱·패스트트래킹
    │
    └─ 효과 검증 ── 네트워크 재계산·완료일 확인
```

### 효과 검증 확대: 단축 반복 절차

```text
주공정 작업 중 비용 구배 최저 작업 선택
    ↓
하루 단축 적용
    ↓
전진·역진 재계산
    ├─ 단일 주공정선 유지 → 목표 완료일까지 반복
    └─ 병렬 주공정선 발생 → 동시 단축 비용 비교
```

### 선택 근거: 일괄 인력 투입과의 비교

| 구분 | 일괄 인력 투입 | 제언: 비용 구배 기반 단계 단축 |
|---|---|---|
| 단축 대상 | 지연이 보이는 작업 전반 | 주공정 작업 중 비용 구배 최저 작업 |
| 기법 선택 기준 | 가용 인력 | 비용 구배와 재작업 위험 |
| 효과 확인 | 단축 후 일정 보고 | 하루 단위 네트워크 재계산 |
| 주공정선 이동 대응 | 미확인 | 병렬 경로의 동시 단축 비용 비교 |
