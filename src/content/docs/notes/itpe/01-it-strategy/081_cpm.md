## 연관 키워드

- CPM (Critical Path Method, 임계경로법), 주공정선 (Critical Path)
- Float (여유시간), Slack (여유), Forward Pass (전진 계산), Backward Pass (역진 계산)
- Activity Node (작업 노드), 네트워크 다이어그램, 결정론적 일정 관리
- Crashing (크래싱), Fast Tracking (패스트 트래킹), Rework (재작업)
- PERT (Program Evaluation and Review Technique), CCPM (Critical Chain Project Management)
- Resource Leveling (자원 평준화), Schedule Compression (일정 압축)

## Ⅰ. CPM의 개요

- 핵심 요약 : 프로젝트 활동 간 의존관계를 네트워크로 모델링해 최소 완료 기간과 임계경로를 산출하는 결정론적 일정 관리 기법
- 개념 : **임계경로법** (CPM, Critical Path Method)은 프로젝트의 모든 작업(Activity) 사이의 선후 의존관계를 네트워크 다이어그램으로 모델링하고, 여유 시간이 없는 가장 긴 경로인 **주공정선** (Critical Path)을 식별해 프로젝트의 최소 완료 기간을 산출하는 결정론적 일정 관리 기법
- 배경 및 필요성 : 복잡한 프로젝트에서 어떤 작업의 지연이 전체 납기를 밀어내는지 알기 어려우면 한정된 자원을 엉뚱한 곳에 투입하게 되므로, 핵심 경로를 계산으로 도출하는 방법이 필요
- 주요 목적 : 프로젝트 최소 완공 기간 산출, 주공정선 중심의 집중 관리, 작업별 여유 시간 계산을 통한 자원 재배치

## Ⅱ. CPM의 특징 및 장점

- 핵심 요약 : 전진·역진 계산과 여유 시간 산출로 임계경로를 식별하는 계산 중심 일정 관리 기법

1. 네트워크 다이어그램 : 작업 선후관계를 시각화한다 → 일정 영향 경로의 파악
2. 전진·역진 계산 : 조기 일정과 늦은 일정을 산출한다 → 계획의 여유 확인
3. 임계경로 식별 : 전체 납기에 직접 영향을 주는 작업을 찾는다 → 관리 자원의 집중 투입
4. **여유 시간** (Float, Slack) : 비임계 작업의 조정 가능 범위를 계산한다 → 자원 배치의 유연성 확보
5. 일정 압축 : **크래싱** (Crashing)과 **패스트 트래킹** (Fast Tracking)의 비용과 품질 영향을 비교한다 → 단축안의 합리적 선택

## Ⅲ. CPM의 구조 (흐름)

- 핵심 요약 : 전진 계산으로 조기 일정을, 역진 계산으로 늦은 일정을 구하고 여유 시간이 0인 경로를 임계경로로 식별
- **작업 노드** (Activity Node) : 작업 하나를 6개 칸으로 표기한 단위
- **전진 계산** (Forward Pass) : 시작에서 종료 방향으로 조기 시작일(ES)과 조기 종료일(EF = ES + DU)을 구하며, 다중 선행 작업이면 최대값을 택한다
- **역진 계산** (Backward Pass) : 종료에서 시작 방향으로 늦은 종료일(LF)과 늦은 시작일(LS = LF - DU)을 구하며, 다중 후속 작업이면 최소값을 택한다
- **총여유** (TF, Total Float) : TF = LS - ES = LF - EF. TF가 0인 경로가 주공정선이다

| ES (Early Start, 조기시작일) | DU (Duration, 작업기간) | EF (Early Finish, 조기종료일) |
| --- | --- | --- |
| LS (Late Start, 늦은시작일) | TF (Total Float, 총여유) | LF (Late Finish, 늦은종료일) |

```text
[ CPM 계산 흐름 ]
시작 노드
   ↓ 전진 계산 (ES / EF)
조기 일정 확정
   ↓ 역진 계산 (LF / LS)
늦은 일정 확정
   ↓ TF = LS - ES
TF = 0 경로 식별
   ↓
임계경로 확정
```

```text
[ 일정 단축 선택 ]
납기 지연 위험 발생
   ↓
크래싱 (자원 추가 투입)
   비용 증가, 브룩스의 법칙 리스크
   ↓
패스트 트래킹 (작업 중첩)
   재작업 (Rework), 품질 리스크
   ↓
단축 일정 확정
```

## Ⅳ. CPM과 PERT·CCPM의 비교

- 핵심 요약 : CPM은 결정론적 단일 추정, PERT는 확률적 3점 추정, CCPM은 자원 제약과 버퍼 관리에 강점

| 비교 항목 | CPM (임계경로법) | PERT (프로그램 평가 검토 기법) | CCPM (임계연쇄 프로젝트 관리) |
| --- | --- | --- | --- |
| 소요 기간 가정 | 결정론적 (단일값) | 확률론적 (낙관·최빈·비관 3점 추정) | 결정론적 + 안전 시간 버퍼 |
| 자원 가정 | 무한 자원 | 무한 자원 | 자원 제약 반영 |
| 핵심 경로 | 임계경로 | 임계경로 | 임계연쇄 |
| 강점 | 단순하고 계산이 명확함 | 불확실성 반영 | 자원과 멀티태스킹 고려 |
| 한계 | 불확실성 미반영 | 계산 복잡, 3점 추정의 난이도 | 도입 난이도, 조직 문화 변화 필요 |

```text
[ 기법 선택 흐름 ]
프로젝트 특성 분석
   ↓
기간 불확실성 낮음 → CPM 적용
   ↓
기간 불확실성 높음 → PERT 적용
   ↓
자원 제약·멀티태스킹 심함 → CCPM 적용
```

## Ⅴ. CPM의 한계와 방안

- 핵심 요약 : 단일 기간 추정, 자원 제약 무시, 임계경로 변경을 보완해야 실제 납기를 예측할 수 있다

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 작업 기간의 단일 추정값이 불확실성을 가림 | 지연 확률이 보이지 않아 납기 위험 과소평가 | PERT 또는 **몬테카를로 시뮬레이션** (Monte Carlo Simulation)으로 일정 범위와 지연 확률 검토 | 납기 달성 확률 |
| 자원 제약을 무시 | 실행 불가능한 일정 발생, 핵심 인력 과부하 | **자원 평준화** (Resource Leveling)와 CCPM으로 핵심 인력의 충돌 반영 | 자원 과다 배정 일수 |
| 비임계 작업의 여유 소진 | 임계경로가 바뀌어 관리 초점이 어긋남 | 진척 갱신 때마다 네트워크와 여유 시간을 재계산 | 임계경로 변경 횟수 |

## Ⅵ. CPM에 대한 기술사적 제언

- 핵심 요약 : PERT·CCPM 융합, 자원 평준화 병행, 동적 재계산 체계로 CPM의 계획 안정성을 보완

1. 다중 주공정선 감시 : 크래싱이나 작업 변경으로 비주공정선이 새로운 주공정선이 되는 현상을 미리 예측하고 진척을 동적으로 모니터링해야 한다
2. 자원 평준화와의 병행 : CPM은 자원이 무한하다고 가정하므로, 특정 시점의 자원 과다 투입을 막기 위해 여유 시간을 활용한 자원 평활화를 함께 적용해야 한다
3. PERT·CCPM 기법의 결합 : 기간 추정의 변동성이 큰 R&D와 신기술 개발 사업에서는 3점 추정 기반 PERT나 제약이론 기반 CCPM을 결합해 일정 안전성을 확보해야 한다

## Ⅶ. 결론

- 핵심 요약 : CPM은 임계경로 기반 결정론적 일정 관리의 기본 프레임
- 시사점 : 불확실성과 자원 제약이 큰 사업에서는 PERT·CCPM과 결합하고 일정을 동적으로 재계산해야 계획이 실제 납기로 이어진다
