## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 일정관리 → **CPM(Critical Path Method)**

## 30초 인출

- 본질: CPM(Critical Path Method)은 작업의 선후관계와 소요기간으로 가장 긴 경로를 찾아 프로젝트의 최단 완료기간과 작업별 여유를 산정하는 일정 기법
- 메커니즘: 전진 계산으로 조기 착수·완료일, 후진 계산으로 늦은 착수·완료일을 구해 총여유(늦은 착수일 − 조기 착수일)를 계산하고, 총여유 0인 작업의 연결을 주공정선으로 판정
- 통찰: 병렬 경로가 합류하면 완료일이 주공정선 기간보다 늘고 총여유가 작은 경로는 지연 한 번에 새 주공정선이 되므로, 주공정선과 함께 총여유가 작은 경로를 감시하고 일정 위험 분석으로 완료일 확률 확인

<details>
<summary>핵심 용어</summary>

- **CPM(Critical Path Method)** : 작업의 선후관계와 소요기간으로 가장 긴 경로를 찾아 최단 완료기간과 작업별 여유를 계산하는 일정 기법
- **주공정선(Critical Path)** : 시작에서 종료까지 가장 긴 작업 연결로, 프로젝트의 최단 완료기간을 결정하는 경로
- **전진 계산(Forward Pass)** : 시작 작업에서 종료 방향으로 소요기간을 더해 조기 착수일(ES)과 조기 완료일(EF)을 구하는 계산
- **후진 계산(Backward Pass)** : 종료 작업에서 시작 방향으로 소요기간을 빼 늦은 착수일(LS)과 늦은 완료일(LF)을 구하는 계산
- **총여유(Total Float)** : 프로젝트 완료일을 늦추지 않고 한 작업이 지연될 수 있는 시간. 0이면 주공정선 작업
- **자유여유(Free Float)** : 바로 뒤 작업의 조기 착수를 늦추지 않고 한 작업이 지연될 수 있는 시간. 총여유 중 일부
- **Near-critical 경로** : 총여유가 주공정선에 근접해 지연 한 번에 주공정선이 될 수 있는 경로
- **크래싱(Crashing)** : 기간에 좌우되는 작업에 자원을 추가해 작업 기간을 줄이는 일정 단축 기법
- **패스트트래킹(Fast Tracking)** : 순차 관계의 작업을 부분 중복해 병행하는 일정 단축 기법
- **PERT(Program Evaluation and Review Technique)** : 작업 기간을 낙관·최빈·비관 3점으로 추정해 완료 가능성을 다루는 일정 기법

## 2~4교시 25점 답안

## Ⅰ. CPM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **CPM(Critical Path Method)** 은 작업의 선후관계와 소요기간으로 가장 긴 경로를 찾아 최단 완료기간과 작업별 여유를 산정하는 일정 기법 |
| 목적 | 완료일을 결정하는 작업의 식별과 단축·감시 대상의 선정 |

## Ⅱ. 최장 경로가 완료일을 정하는 CPM의 특징

| 특징 | 내용 |
|---|---|
| 최장 경로 기준 | 소요기간의 합계가 아니라 가장 긴 연속 경로가 최단 완료기간 결정 |
| 확정 기간 가정 | 작업마다 하나의 소요기간을 사용하는 결정론적 계산 |
| 여유 기반 관리 | **주공정선** 작업의 지연은 같은 기간만큼의 완료일 지연, 그 밖의 작업은 **총여유** 안에서 지연 허용 |
| 시간·비용 교환 | 작업별 정상 기간과 단축 한계, 단축 비용을 두고 기간 단축의 추가 비용 계산 |

## Ⅲ. 주공정선 산정 절차와 합류점 계산

### 주공정선 산정 절차

```text
작업 목록·선후관계·소요기간 입력
    ↓
전진 계산 (시작 → 종료)
    ES = 선행 작업 EF 중 최댓값, EF = ES + 소요기간
    ↓
후진 계산 (종료 → 시작)
    LF = 후행 작업 LS 중 최솟값, LS = LF − 소요기간
    ↓
총여유 = LS − ES (= LF − EF)
    ├─ 0 → 주공정선 작업
    └─ 0 초과 → 여유 작업
```

### 전진·후진 계산 확대: 합류점에서 값이 정해지는 방식

```text
        ┌→ B (4일) ─┐
A (3일) ┤           ├→ D (2일)
        └→ C (3일) ─┘

전진   B: ES 3, EF 7      C: ES 3, EF 6
       D: ES = max(7, 6) = 7, EF 9  → 최단 완료기간 9일
후진   D: LF 9, LS 7
       B: LF 7, LS 3 → 총여유 0  (주공정선 A → B → D)
       C: LF 7, LS 4 → 총여유 1  (C는 1일 지연 허용)
```

## Ⅳ. 일정 단축 기법과 PERT의 비교

### 일정 단축 기법

| 구분 | 크래싱 | 패스트트래킹 |
|---|---|---|
| 방법 | 기간에 좌우되는 작업에 자원 추가 | 순차 관계를 부분 중복으로 낮춰 병행 (예: 종료-시작 관계를 시작-시작 관계로 변경) |
| 적용 대상 | 주공정선, 특히 기간이 긴 작업 | 주공정선의 순차 작업 |
| 부작용 | 비용 증가, 경험이 적은 인력 투입 시 품질 저하 | 자원 과할당, 순차 수행이 바람직한 작업의 병행에 따른 품질 저하·위험 증가 |

### CPM과 PERT

| 비교축 | CPM | PERT |
|---|---|---|
| 기원 | Kelley·Walker의 1959년 논문, DuPont·Remington Rand 협업 | Malcolm 외의 1959년 논문, 미 해군 Polaris 프로그램 |
| 작업 기간 | 하나의 확정값 | 낙관·최빈·비관 3점 추정 |
| 결과 | 확정적 주공정선과 최단 완료기간 | 기간의 불확실성을 반영한 완료 가능성 |

## Ⅴ. CPM 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 병렬 경로가 합류하는 지점에서 지연이 겹쳐 실제 완료일이 주공정선 기간보다 늘어나는데, 확정 기간 계산은 이를 드러내지 않음 | 작업 기간에 불확실성을 부여한 일정 위험 분석(몬테카를로 시뮬레이션)으로 완료일의 확률 분포 산정 |
| 총여유가 작은 경로가 지연되거나 단축으로 주공정선이 줄면 새 주공정선이 생겨 완료일이 줄지 않음 | 주공정선과 함께 총여유가 작은 경로를 감시하고, 단축마다 전진·후진 계산의 재실행 |
| 범위 누락이나 선후관계 오류로 계산된 주공정선이 실제 완료일을 좌우하는 경로와 불일치 | 전체 범위의 작업 도출과 선후관계 점검 후 계산 |

## Ⅵ. 제언

주공정선만 감시하지 않고 총여유가 작은 경로까지 함께 관리하며, 합류점이 많은 일정은 일정 위험 분석으로 완료일의 확률을 확인한 뒤 단축 대상을 선정

### 경로별 감시 범위

```text
완료 마일스톤 (합류점)
    ├─ 경로 A ── 총여유 0 ── 주공정선: 상시 감시
    ├─ 경로 B ── 총여유 작음 ── Near-critical: 함께 감시
    └─ 경로 C ── 총여유 큼 ── 여유 소진 시 감시 대상 편입
```

### 감시 결과에 따른 단축 절차 확대

```text
일정 위험 분석으로 완료일의 확률 확인
    ↓
단축 대상 선정: 주공정선과 Near-critical 경로의 긴 작업
    ↓
크래싱 또는 패스트트래킹 적용
    ↓
전진·후진 계산 재실행 → 새 주공정선·총여유 확인 → 필요 시 반복
```

| 구분 | 주공정선만 관리 | 제언: 총여유 기준 관리 |
|---|---|---|
| 감시 범위 | 총여유 0인 경로 | 총여유가 작은 경로 포함 |
| 완료일 판단 | 확정 기간 기반 단일 값 | 일정 위험 분석의 확률 분포 |
| 단축 후 처리 | 원래 주공정선 기준 진행 | 재계산으로 새 주공정선 확인 |
