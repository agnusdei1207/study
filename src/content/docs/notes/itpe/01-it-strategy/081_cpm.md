## 연관 키워드

- CPM, Critical Path Method, 임계경로법
- Critical Path, 주공정선, Float, Slack, 여유시간
- Forward Pass, Backward Pass, 전진 계산, 역진 계산
- Activity Node, 네트워크 다이어그램, 결정론적 일정 관리
- Crashing, 크래싱, Fast Tracking, 패스트 트래킹, Rework
- PERT, Program Evaluation and Review Technique, CCPM, Critical Chain Project Management
- Resource Leveling, 자원 평준화, Schedule Compression

## Ⅰ. CPM의 개요

- 핵심 요약 : 프로젝트 활동 간 의존관계를 네트워크로 모델링해 최소 완료 기간과 임계경로를 산출하는 결정론적 일정 관리 기법.
- 개념 : **CPM**(Critical Path Method, 임계경로법)은 프로젝트의 모든 작업(Activity) 간 선후 의존관계를 **네트워크 다이어그램**으로 모델링하고, 프로젝트 시작부터 종료까지 여유 시간이 없는 **가장 긴 경로**(주공정선, Critical Path)를 식별하여 프로젝트 전체 최소 완료 기간을 산출하는 **결정론적 일정 관리 기법**.
- 배경 및 필요성 : 복잡한 프로젝트에서 어떤 작업 지연이 전체 프로젝트 납기를 지연시키는지 명확히 파악하고, 한정된 자원을 집중 투입할 핵심 경로를 과학적으로 도출할 필요성 대두.
- 주요 목적 : 프로젝트 최소 완공 기간 산출, 주공정선 식별을 통한 중점 관리, 작업별 여유 시간(Float/Slack) 계산을 통한 자원 재배치.

## Ⅱ. CPM의 특징 및 장점

- 핵심 요약 : 전진·역진 계산과 여유시간 산출로 임계경로를 식별하는 계산 중심 일정 관리 기법.

1. **네트워크 다이어그램** : 작업 선후관계를 보여 일정 영향 경로를 파악한다.
2. **전진·역진 계산** : 조기·늦은 일정을 산출해 계획의 여유를 확인한다.
3. **임계경로** : 전체 납기에 직접 영향을 주는 작업을 찾아 관리 자원을 집중한다.
4. **여유시간(Float)** : 비임계 작업의 조정 가능 범위를 계산해 자원 배치에 활용한다.
5. **일정 압축** : 크래싱·패스트 트래킹의 비용·품질 영향을 비교해 단축안을 고른다.

## Ⅲ. CPM의 구조 (흐름)

- 핵심 요약 : 전진 계산으로 조기일정, 역진 계산으로 늦은일정을 산출하고 여유시간 0 경로를 임계경로로 식별.
- Activity Node(작업 노드)의 6분할 표기.

| ES (Early Start) : 조기시작일 | DU (Duration) : 작업기간 | EF (Early Finish) : 조기종료일 |
|---|---|---|
| LS (Late Start) : 늦은시작일 | TF (Total Float) : 총여유 | LF (Late Finish) : 늦은종료일 |

- **전진 계산**(Forward Pass) : 프로젝트 시작부터 종료 방향으로 조기 시작일(ES)과 조기 종료일(EF = ES + DU) 계산. 다중 선행 작업 시 최대값 선택.
- **역진 계산**(Backward Pass) : 프로젝트 종료부터 시작 방향으로 늦은 종료일(LF)과 늦은 시작일(LS = LF - DU) 계산. 다중 후속 작업 시 최소값 선택.
- **여유 시간 산출** : 총여유(TF = LS - ES = LF - EF). TF = 0인 경로가 바로 주공정선(Critical Path).

```text
[ CPM 계산 흐름 ]
시작 노드
   ↓ Forward Pass (ES / EF 계산)
조기일정 확정
   ↓ Backward Pass (LF / LS 계산)
늦은일정 확정
   ↓ TF = LS - ES (또는 LF - EF)
TF = 0 경로 식별
   ↓
임계경로(Critical Path) 확정
```

```text
[ 일정 단축(Schedule Compression) 선택 ]
납기 지연 위험 발생
   ↓
크래싱(Crashing) : 자원 추가 투입
   │  └─ 비용 증가, 브룩스의 법칙(Brooks' Law) 리스크
   ↓
패스트 트래킹(Fast Tracking) : 작업 중첩
   │  └─ 재작업(Rework) · 품질 리스크
   ↓
단축 일정 확정
```

## Ⅳ. CPM과 PERT·CCPM의 비교

- 핵심 요약 : CPM은 결정론적·자원 무한 가정, PERT는 확률적 3점 추정, CCPM은 자원 제약과 버퍼 관리에 강점.

| 비교 항목 | CPM (Critical Path Method) | PERT (Program Evaluation and Review Technique) | CCPM (Critical Chain Project Management) |
|---|---|---|---|
| 소요기간 가정 | 결정론적 (단일값) | 확률론적 (3점 추정 : 낙관·최빈·비관) | 결정론적 + 안전시간 버퍼 |
| 자원 가정 | 무한 자원 | 무한 자원 | 자원 제약 반영 |
| 핵심 경로 | 임계경로 (Critical Path) | 임계경로 | 임계연쇄 (Critical Chain) |
| 강점 | 단순, 명확, 계산 용이 | 불확실성 반영 | 자원·멀티태스킹 고려 |
| 한계 | 불확실성 미반영 | 계산 복잡, 3점 추정 난이도 | 도입 난이도, 문화 변화 필요 |

```text
[ 기법 선택 흐름 ]
프로젝트 특성 분석
   ↓
기간 불확실성 낮음 ──→ CPM 적용
   ↓
기간 불확실성 높음 ──→ PERT 적용
   ↓
자원 제약·멀티태스킹 심함 ──→ CCPM 적용
```

## Ⅴ. CPM의 한계와 방안

- 핵심 요약 : 단일 기간 추정, 자원 제약, 임계경로 변경을 보완해야 실제 납기를 예측할 수 있다.

| 한계 | 방안 |
|---|---|
| 작업 기간의 **단일 추정값**이 불확실성을 가림 | PERT·몬테카를로로 일정 범위와 지연 확률 검토 |
| **자원 제약**을 무시하면 실행 불가능한 일정이 나옴 | 자원 평준화·CCPM으로 핵심 인력의 충돌 반영 |
| 비임계 작업의 여유 소진으로 **임계경로가 변경**됨 | 진척 갱신 때마다 네트워크와 여유시간 재계산 |

## Ⅵ. CPM에 대한 기술사적 제언

- 핵심 요약 : PERT·CCPM 융합, 자원 평준화 병행, 동적 재계산 체계 구축.
- 다중 주공정선(Multiple Critical Paths)의 면밀한 감시 : 크래싱이나 변경으로 인해 비주공정선이 새로운 주공정선으로 전환되는 현상을 사전에 예측하고 동적 모니터링 수행.
- 자원 평준화(Resource Leveling)와의 조화 : CPM은 무한 자원을 가정하므로, 특정 시점의 자원 과다 투입(Over-allocation)을 방지하기 위해 여유 시간(Float)을 활용한 자원 평활화(Resource Smoothing) 병행.
- 불확실성 대응을 위한 PERT/CCPM 기법 융합 : 작업 기간 추정의 변동성이 큰 R&D 및 신기술 개발 사업에서는 3점 추정 기반의 PERT나 제약이론 기반의 크리티컬 체인(CCPM)을 결합하여 일정 안전성 확보.

## Ⅶ. 결론

- 핵심 요약 : CPM은 임계경로 기반의 결정론적 일정 관리의 기본 프레임.
- 요약 : CPM은 프로젝트 활동 간 의존관계를 네트워크로 모델링하여 최소 완료 기간과 임계경로를 산출하는 결정론적 일정 관리 기법.
- 시사점 : 불확실성과 자원 제약이 큰 사업에서는 PERT·CCPM과의 융합으로 일정 안전성을 확보하고 동적 재계산 체계를 유지해야 함.
