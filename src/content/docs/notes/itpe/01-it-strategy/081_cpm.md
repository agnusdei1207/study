## Ⅰ. CPM의 개요

- **개념** : 프로젝트의 모든 작업(Activity) 간의 선후 의존관계를 네트워크 다이어그램으로 모델링하고, 프로젝트 시작부터 종료까지 여유 시간이 없는 가장 긴 경로(주공정선, Critical Path)를 식별하여 프로젝트 전체 최소 완료 기간을 산출하는 결정론적 일정 관리 기법.
- **배경 및 필요성** : 복잡한 프로젝트에서 어떤 작업이 지연될 때 전체 프로젝트 납기가 지연되는지 명확히 파악하고, 한정된 자원을 집중 투입할 핵심 경로를 과학적으로 도출할 필요성 대두.
- **주요 목적** : 프로젝트 최소 완공 기간 산출, 주공정선 식별을 통한 중점 관리, 작업별 여유 시간(Float/Slack) 계산을 통한 자원 재배치.

## Ⅱ. CPM 네트워크 분석 및 계산 메커니즘

```text
  [Activity Node 구조]
  ┌─────────┬─────────┬─────────┐
  │   ES    │   DU    │   EF    │   ES: 조기시작일, EF: 조기종료일, DU: 작업기간
  ├─────────┼─────────┼─────────┤
  │   LS    │   TF    │   LF    │   LS: 늦은시작일, LF: 늦은종료일, TF: 총여유
  └─────────┴─────────┴─────────┘
```

- **전진 계산 (Forward Pass)** : 프로젝트 시작부터 종료 방향으로 조기 시작일(ES)과 조기 종료일(EF = ES + DU) 계산. (다중 선행 작업 시 최대값 선택).
- **역진 계산 (Backward Pass)** : 프로젝트 종료부터 시작 방향으로 늦은 종료일(LF)과 늦은 시작일(LS = LF - DU) 계산. (다중 후속 작업 시 최소값 선택).
- **여유 시간 산출** : 총여유(Total Float, TF = LS - ES = LF - EF). TF = 0인 경로가 바로 **주공정선(Critical Path)**

## Ⅲ. 일정 단축 기법(Schedule Compression)의 비교

| 단축 기법 | 메커니즘 | 장점 | 단점 및 리스크 |
|---|---|---|---|
| 크래싱 (Crashing) | 주공정선 상의 작업에 추가 자원(인력, 장비, 잔업)을 투입하여 기간 단축 | 일정 단축 확실성 높음 | 프로젝트 직접 비용 급증, 브룩스의 법칙(인력 추가 시 소통 비용 증가) 리스크 |
| 패스트 트래킹 (Fast Tracking) | 순차적으로 수행하기로 계획된 선후행 작업을 병행(중첩)하여 동시 수행 | 추가 비용 투입 없음 | 재작업(Rework) 발생 확률 급증, 품질 위험 및 관리 복잡도 증대 |

## Ⅳ. CPM(임계경로법) 적용 시 주요 한계점 및 해결 방안

- **작업 기간의 확정적(Deterministic) 가정의 한계** :
  - **한계점** : 각 액티비티의 소요 기간이 고정되어 있다고 가정하여 자원 변동, 날씨, 기술적 이슈 등 현실의 불확실성 미반영.
  - **해결 방안** : 확률적 소요 시간을 적용하는 PERT(3점 추정) 기법 또는 몬테카를로 시뮬레이션과의 결합 운영.
- **자원 제약(Resource Constraints)의 무시** :
  - **한계점** : 자원이 무한하다는 전제하에 임계경로를 도출하므로, 특정 핵심 인력의 다중 작업 배정 시 실제 납기 달성 불가능.
  - **해결 방안** : 자원 평준화(Resource Leveling) 및 제약이론 기반의 임계연쇄 프로젝트 관리(CCPM) 도입.
- **주경로(Critical Path)의 동적 변경에 대한 실시간 추적 부실** :
  - **한계점** : 비임계 경로의 작업 지연으로 여유 시간(Float)이 소진되면 새로운 주경로가 발생하나 이를 인지하지 못해 관리 실패.
  - **해결 방안** : 전문 프로젝트 일정 관리 도구(MS Project, Primavera)를 활용한 주간 단위 주경로 재계산 및 모니터링.

## Ⅴ. 성공적인 CPM 관리를 위한 기술사적 제언

- **다중 주공정선(Multiple Critical Paths)의 면밀한 감시** : 크래싱이나 변경으로 인해 비주공정선이 새로운 주공정선으로 전환되는 현상을 사전에 예측하고 동적 모니터링 수행.
- **자원 평준화(Resource Leveling)와의 조화** : CPM은 무한 자원을 가정하므로, 특정 시점의 자원 과다 투입(Over-allocation)을 방지하기 위해 여유 시간(Float)을 활용한 자원 평활화(Resource Smoothing) 병행.
- **불확실성 대응을 위한 PERT/CCPM 기법 융합** : 작업 기간 추정의 변동성이 큰 R&D 및 신기술 개발 사업에서는 3점 추정 기반의 PERT나 제약이론 기반의 크리티컬 체인(CCPM)을 결합하여 일정 안전성 확보.
