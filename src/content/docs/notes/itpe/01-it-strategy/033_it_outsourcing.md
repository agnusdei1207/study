## 지식 로드맵 내 현재 위치

```text
IT 운영전략 → 소싱·서비스관리 → IT 아웃소싱
```

## 토픽 큰 그림과 30초 인출
```text
[사업·IT 전략] → [Make or Buy] → [제공자 선정·계약]
                                      ↓
[재소싱·종료] ← [성과·위험 거버넌스] ← [전환·서비스 운영]
                     ↑
             [고객 잔존조직·책임]
```
- **30초 인출**: IT 아웃소싱은 외부 전문조직에 IT 기능을 맡기는 전략적 소싱이며, 실행을 위탁해도 서비스·위험·보안에 대한 발주자의 책임은 남는다.

## 예상문제
> IT 아웃소싱의 유형과 생명주기를 설명하고 성공적인 계약·거버넌스 및 종료 통제방안을 제시하시오.

## Ⅰ. 개요 ─ 선택과 책임
**IT 아웃소싱**은 비용·역량·민첩성·집중도를 고려해 IT 기능이나 서비스를 외부 제공자로부터 조달·운영하는 경영방식이다. 핵심 역량과 통제권, 총비용과 공급위험을 함께 판단해야 한다.

## Ⅱ. 유형 ─ 범위와 협업방식
| 유형 | 특징 | 적용 관점 |
|---|---|---|
| 전체 아웃소싱 | 광범위한 운영 위탁 | 통합책임, 집중위험 |
| 선택적 아웃소싱 | 기능별 우수 제공자 활용 | 통합·경계관리 |
| 코소싱 | 고객과 제공자가 공동 수행 | 지식이전·공동책임 |
| 관리형 서비스 | 성과기준으로 지속 서비스 구매 | SLA·자동화 |
| 인소싱 | 내부조직이 직접 수행 | 전략역량·통제 유지 |

## Ⅲ. 판단 ─ Make or Buy
전략적 중요성, 내부역량, 시장 성숙도, 전환·운영·종료의 총비용, 보안·규제·집중위험, 기술 변화와 가역성을 평가한다. 핵심 의사결정과 아키텍처·보안·제공자 관리는 잔존조직에 명확히 둔다.

## Ⅳ. 절차 ─ 아웃소싱 생명주기
```text
전략·범위 → 타당성·위험 → RFI/RFP·실사 → 계약·SLA
          → 전환·인수 → 운영·성과관리 → 갱신·재소싱·종료
```
각 단계의 의사결정 기준, 책임자, 산출물과 승인조건을 연결한다.

## Ⅴ. 계약·거버넌스 ─ 성과와 관계의 이중 통제
| 통제영역 | 핵심 내용 |
|---|---|
| 서비스 | SLI·SLA, 우선순위, 서비스 크레딧 |
| 변경 | 수요·범위·가격·형상 변경절차 |
| 보안 | 접근권한, 사고통지, 감사·재위탁 |
| 데이터 | 소유권, 위치, 반출·삭제·복구 |
| 관계 | 운영·전술·전략 회의체와 분쟁해결 |
| 종료 | 데이터 반환, 지식이전, 전환지원 |

## Ⅵ. 위험 ─ 잠금과 역량공동화 대응
제공자 종속, 내부역량 상실, 숨은 전환비용, SLA의 부분최적화, 재위탁·공급망 위험을 관리한다. 표준 인터페이스와 문서화, 다중 제공자 통합책임, 감사권, 대체 가능성과 정기 종료훈련을 확보한다.

## Ⅶ. 결론 ─ 전 생명주기 소싱관리
아웃소싱은 비용절감 계약이 아니라 서비스 성과와 위험을 공동관리하는 장기 관계다. 선정 단계부터 전환과 종료를 설계하고 잔존조직이 책임과 지식을 유지해야 한다.

## 1교시 10점 답안 발췌
```text
정의: IT 기능을 외부 전문조직에서 조달·운영하는 전략적 소싱
유형: 전체 / 선택 / 코소싱 / 관리형 서비스 / 인소싱
절차: 전략 → 실사·선정 → 계약·SLA → 전환 → 운영 → 종료
통제: 잔존조직, 보안·데이터, 재위탁, 지식이전, Exit Plan
```
