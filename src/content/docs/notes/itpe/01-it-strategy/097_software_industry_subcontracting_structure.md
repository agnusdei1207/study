## 지식 로드맵 내 현재 위치

IT 전략·관리 → 공공 SW 사업 관리 → **공공 소프트웨어(SW) 사업 하도급 제한**

## 30초 인출

- 본질: 공공 SW 사업 하도급 제한은 국가기관 등과 계약한 SW 사업자가 사업의 절반을 넘겨 하도급하거나 다단계로 재하도급하지 못하게 한 소프트웨어 진흥법 제51조의 제도
- 메커니즘: 물품 구매금액을 뺀 사업금액의 50% 이내에서만 하도급을 허용하고, 재하도급은 법정 예외로 한 번만 허용하며, 모든 하도급·재하도급은 발주기관의 사전 승인을 거쳐 관리·감독
- 통찰: 비율과 승인만 보면 실제 수행 주체의 변경을 놓치므로 승인 계획과 투입 인력·대금의 정기 대조

<details>
<summary>핵심 용어</summary>

- **공공 소프트웨어(SW) 사업 하도급 제한** : 공공 SW 사업의 하도급 비율 상한, 재하도급 금지와 예외, 사전 승인을 정한 소프트웨어 진흥법 제51조의 제도
- **하도급** : 발주기관과 직접 계약한 원수급인이 사업의 일부를 다른 사업자에게 맡기는 계약
- **재하도급** : 하도급받은 사업자가 그 사업을 다시 다른 사업자에게 맡기는 계약. 원칙적 금지
- **원수급인** : 발주기관과 직접 계약을 체결해 사업 수행 책임을 지는 사업자
- **하수급인** : 원수급인으로부터 사업의 일부를 하도급받은 사업자
- **물품 구매금액** : 하도급 비율의 분모에서 제외하는, 상용 SW를 포함한 물품의 구매 금액
- **공동수급체** : 둘 이상의 사업자가 함께 발주기관과 계약해 각자 계약 당사자로 수행하는 조직

## 2~4교시 25점 답안

## Ⅰ. 공공 SW 사업 하도급 제한의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **공공 소프트웨어(SW) 사업 하도급 제한** 은 공공 SW 사업의 하도급 비율 상한, 재하도급 금지와 예외, 발주기관 사전 승인을 규정한 소프트웨어 진흥법 제51조의 제도 |
| 목적 | 원수급인의 직접 수행 책임 유지와 다단계 하도급에 따른 품질 저하·대금 감액 방지 |

## Ⅱ. 수행 책임을 원수급인에 묶어 두는 하도급 제한의 특징

| 특징 | 의미 |
|---|---|
| 비율 상한 | 물품 구매금액을 뺀 SW 사업금액의 50% 초과 하도급 금지 |
| 다단계 차단 | 재하도급은 원칙적 금지, 예외로 허용된 재하도급의 재하도급은 전면 금지 |
| 사전 승인 | 하도급·재하도급 전 발주기관의 승인 |
| 공동수급 유도 | 하도급 비율이 높으면 하수급인의 공동수급체 참여 요구 가능 |

## Ⅲ. 하도급 허용 판단 체계와 재하도급 예외

### 하도급 허용 판단 체계

```text
하도급 제한(제51조)
    │
    ├─ 원칙 ── 물품 제외 사업금액의 50% 이내
    │
    ├─ 예외 ── 물품 설치·유지관리, 신기술·전문기술
    │     └─ 해당 금액 50% 초과 시, 전부 하도급 불가
    │
    ├─ 재하도급 ── 원칙적 금지, 법정 예외만 1회
    │
    └─ 절차 ── 발주기관 사전 승인과 지속적 관리·감독
```

하도급 비율 = 하도급 금액 ÷ (SW 사업금액 − 물품 구매금액). 물품에는 상용 SW 포함

### 재하도급 확대: 재하도급 허용 판정

```text
하수급인의 재하도급 필요 발생
    ↓
예외 사유 확인
    ├─ 해당 없음 → 재하도급 불가
    └─ 해당 ── 신기술·전문기술, 상용 SW 기술 지원
          ↓
       받은 금액의 50% 이내 여부 확인
          ↓
       발주기관 사전 승인
          ↓
       재하도급받은 사업자의 추가 하도급 금지
```

예외 사유는 시행령 제48조의 신기술·전문기술이 필요한 경우와 상용 SW 유지관리에 기술 지원이 불가피한 경우

## Ⅳ. 하도급과 공동수급체 참여의 비교

| 구분 | 하도급 | 공동수급체 참여 |
|---|---|---|
| 계약 당사자 | 원수급인만 발주기관과 계약 | 구성원 모두 발주기관과 계약 |
| 수행 책임 | 원수급인이 하수급인 몫까지 책임 | 구성원별 계약상 책임 |
| 대금 흐름 | 발주기관 → 원수급인 → 하수급인 | 발주기관 → 각 구성원 |
| 발주기관 관리 | 승인·감독으로 간접 관리 | 계약으로 직접 관리 |
| 법적 근거 | 제51조제1~5항 | 제51조제6항: 하도급 비율 10% 이상이면 참여 요구 가능 |

하도급 비율이 높은 사업일수록 실제 수행자가 계약 밖에 머무는 구간이 넓어지므로, 입찰 단계에서 공동수급으로 끌어들일지가 선택의 기준

## Ⅴ. 하도급 제한 운영의 한계와 방안

| 한계 | 방안 |
|---|---|
| 물품 구매금액을 부풀려 분모를 줄이는 비율 왜곡 | 품목별 구매 증빙과 실제 납품 품목의 대조 |
| 승인 업체와 실제 수행 업체·인력의 불일치 | 승인 계획과 투입 인력·산출물 작성자의 정기 대조 |
| 원수급인을 거친 대금 지급 지연·감액 | 하도급 비율 10% 이상이면 입찰공고 시 하수급인의 공동수급체 참여 요구 선택 |
| 재하도급 예외의 일반 허용 오인 | 예외 사유·금액 한도·사전 승인의 건별 확인 |

## Ⅵ. 제언

하도급 승인 이후 승인 계획과 실제 투입 인력·산출물·대금 지급을 정기적으로 대조하고, 불일치는 시정 요구로 연결

### 승인 계획과 실제 수행의 대조 구조

```text
승인된 하도급 계획
    │
    ├─ 수행 업체 ── 실제 투입 인력의 소속
    │
    ├─ 수행 범위 ── 산출물 작성 주체
    │
    └─ 하도급 금액 ── 하수급인 대금 지급 내역
```

### 대조 확대: 불일치 발견 시 처리 절차

```text
정기 대조에서 불일치 발견
    ↓
원인 확인: 승인 없는 변경·재하도급 여부
    ├─ 정당한 변경 → 변경 승인 절차 진행
    └─ 제한 위반 → 발주기관의 시정 요구(제7항)
          ↓
    시정 결과의 다음 대조 시 확인
```

### 선택 근거: 승인 시점 중심 관리와의 비교

| 구분 | 승인 시점 중심 관리 | 제언: 승인 후 정기 대조 |
|---|---|---|
| 확인 시점 | 하도급 승인 1회 | 승인 후 정기 반복 |
| 확인 대상 | 하도급 비율·계획서 | 인력 소속·산출물 주체·대금 지급 |
| 위반 발견 | 분쟁·감사 이후 | 수행 중 조기 발견 |
| 후속 조치 | 사후 제재 | 변경 승인 또는 시정 요구 |

## 출제 이력과 검증 출처

- 제132~140회 공식 문제지에 해당 문항 없음. 위 문항은 예상문제
- [국가법령정보센터, 소프트웨어 진흥법 제51조(하도급 제한 등)](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1031614557) — 법률 제20476호, 2025.4.23. 시행. 제1항 50% 상한, 제2항 물품 설치·유지관리와 신기술·전문기술 예외, 제3항·제4항 재하도급 제한, 제5항 사전 승인, 제6항 공동수급체 참여 요구, 제7항 관리·감독
- [국가법령정보센터, 소프트웨어 진흥법 시행령](https://www.law.go.kr/법령/소프트웨어진흥법시행령) 제48조(하도급 제한 등): 제1항 신기술·전문기술 사업, 제2항 재하도급 시 받은 금액의 100분의 50 한도, 제4항 상용SW 유지·관리 기술 지원, 제5항 공동수급체 참여 요구 기준 비율 100분의 10(대통령령 제36338호, 2026.6.3. 시행)
