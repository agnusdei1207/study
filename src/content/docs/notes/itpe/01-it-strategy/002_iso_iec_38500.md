## 지식 로드맵 내 현재 위치

IT 전략·관리 → IT 거버넌스 → **ISO/IEC 38500**

## 30초 인출

- 본질: ISO/IEC 38500은 조직의 최고 의사결정 집단이 IT 사용을 효과적·효율적·수용 가능하게 이끌도록 안내하는 IT 거버넌스 국제표준
- 메커니즘: 최고 의사결정 집단이 이해관계자 참여·평가·지시·감독의 모델로 IT 사용을 이끌고, 실행은 위임한 경영진의 IT 관리가 수행
- 통찰: 위임한 뒤에는 실적을 승인 근거와 대조하기 어려워 감독이 형식화되므로 결정 시점의 근거·위임 범위를 기록해 감독 단계에서 대조

<details>
<summary>핵심 용어</summary>

- **ISO/IEC 38500** : 조직의 현재와 미래의 IT 사용을 이끄는 원칙·모델·프레임워크를 제시하는 IT 거버넌스 표준. 현행판은 2024년 2월 발행된 제3판
- **IT 거버넌스(Governance of IT)** : IT의 현재와 미래 사용을 이끄는 체계. 조직 거버넌스의 한 영역
- **Governing Body** : 조직의 성과와 준수에 책임을 지는 개인 또는 집단. 표준의 주된 독자
- **Evaluate** : 조직의 현재·미래 IT 사용과 관련된 상황·기회를 판단하는 활동
- **Direct** : 목적과 기대 성과를 전달하는 활동. 목표·전략·정책의 설정을 포함
- **Monitor** : 적절한 결정과 조정의 근거를 얻기 위한 검토 활동. 법규·조직 정책의 준수 검토를 포함
- **ISO 37000** : 조직 거버넌스의 원칙을 제시한 국제표준. 2024판 38500이 이 원칙에 맞춰 개정

</details>

## 2~4교시 25점 답안

## Ⅰ. ISO/IEC 38500의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ISO/IEC 38500** 은 조직의 현재와 미래의 IT 사용을 Governing Body가 이끌도록 안내하는 IT 거버넌스 원칙·모델·프레임워크 표준 |
| 목적 | IT의 효과적·효율적·수용 가능한 사용 |

## Ⅱ. 경영진의 IT 관리와 구별되는 ISO/IEC 38500의 특징

| 특징 | 의미 |
|---|---|
| Governing Body 대상 | 이사회 등 최고 의사결정 집단이 독자. 거버넌스 실행은 조직 전반에서 수행 |
| 최종 책임 유지 | 조직 전체에 대한 최종 책임은 Governing Body에 잔존 |
| 원칙 기반 지침 | 세부 구현 절차 없이 원칙·모델·프레임워크 세 도구 제시 |
| 조직 거버넌스의 일부 | ISO 37000의 거버넌스 원칙에 정렬 |
| 사용 범위 | IT 자원과 함께 데이터·디지털 역량의 사용 포함 |
| 좋은 거버넌스의 성과 | 효과적 성과(Effective performance)·책임 있는 관리(Responsible stewardship)·윤리적 행동(Ethical behaviour) |

## Ⅲ. IT 거버넌스 모델과 위임 구조

### IT 거버넌스 모델

```text
이해관계자 참여(Engage stakeholders): 요구·기대 수렴
    ↓
평가(Evaluate): IT 현재·미래 사용의 상황·기회 판단
    ↓
지시(Direct): 목적·기대 성과 전달, 목표·전략·정책 설정
    ↓  위임한 권한 범위
경영진의 IT 관리(Management of IT practice): 실행
    ↓  진행·성과 보고
감독(Monitor): 계획 대비 진행과 법규·정책 준수 검토
    └→ 결정·조정의 근거로 다음 평가에 반영
```

### 지시 확대: 위임과 최종 책임

```text
Governing Body ── 최종 책임 유지, 목적·성과 기대 전달
    ↓  권한 위임(Delegation)
경영진 ── 위임받은 범위에서 목표·전략·정책 설정과 실행
    ↑  성과·준수 실적 보고
Governing Body ── 감독 결과로 조정 결정
```

## Ⅳ. 2015판과 2024판의 비교

### 세 도구와 개정 내용

| 구분 | 2015판(제2판) | 2024판(제3판) |
|---|---|---|
| 원칙 | 6개 | 11개, ISO 37000의 원칙에 정렬 |
| 모델 | 평가·지시·감독 | 이해관계자 참여 추가 |
| 프레임워크 | 서문의 구성이 원칙·정의·모델 | 프레임워크를 세 번째 도구로 수록. ISO/IEC TR 38502에서 갱신 |

### 원칙과 프레임워크 요소

| 구분 | 원문 표기 |
|---|---|
| 2015판 6원칙 | Responsibility · Strategy · Acquisition · Performance · Conformance · Human Behaviour |
| 2024판 11원칙 | Purpose · Value generation · Strategy · Oversight · Accountability · Stakeholder engagement · Leadership · Data and decisions · Risk governance · Social responsibility · Viability and performance over time |
| 2024판 프레임워크 요소 | Direction · Capability · Policy · Delegation · Performance · Accountability |

## Ⅴ. ISO/IEC 38500 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 원칙 기반 지침이라 조직별 결정 권한과 위임 범위가 정해지지 않음 | Delegation·Policy 요소에 맞춰 결정 권한과 위임 범위를 조직 문서로 명시 |
| 위임 뒤 실적을 승인 당시 근거와 대조할 기준 부재 | 결정 시점의 기대 성과·전제·위임 범위를 기록해 감독 단계에서 대조 |
| 데이터·자동화 의사결정까지 넓어진 IT 사용의 감독 대상 불명확 | 자동화 결정의 합리성·정당성을 감독 항목에 포함 |
| 이해관계자 기대가 평가에 반영되는 경로 부재 | 이해관계자 참여 단계에서 수렴한 요구를 평가의 입력으로 지정 |

## Ⅵ. 제언

위임 시점에 승인 근거·위임 범위를 한 건의 결정 기록으로 남기고, 감독 단계에서 실적과 대조

### IT 투자 결정 기록의 구성

```text
IT 결정 기록
    │
    ├─ 승인 근거 ── 기대 성과와 전제
    │
    ├─ 위임 범위 ── 실행 책임자와 권한
    │
    └─ 감독 항목 ── 성과·준수
```

### 감독 단계 확대: 기록과 실적의 대조

```text
경영진의 실적 보고
    ↓
결정 기록의 전제·감독 항목과 대조
    ├─ 부합 → 기존 방향 유지
    └─ 이탈 → 평가 재수행 후 방향·위임 범위 재지시
```

| 구분 | 회의체 중심 감독 | 제언: 결정 기록 기반 감독 |
|---|---|---|
| 감독 기준 | 회의 안건별 보고 | 결정 시점에 기록한 전제와 감독 항목 |
| 위임 후 확인 | 담당 부서 보고에 의존 | 기록된 위임 범위와 실적의 대조 |
| 이탈 시 조치 | 개별 회의 판단 | 평가 재수행과 재지시 |

## 출제 이력과 검증 출처

- ISO/IEC 38500 표준 자체를 묻는 출제는 132~140회 문제지에서 확인하지 못함
- 제134회 2교시 3번: IT 거버넌스의 구성요소, 효과 측정 지표, 효과 측정 방법론. 표준이 아닌 IT 거버넌스 일반 문항이므로 기본 답안과 구별
- ISO/IEC 38500:2024 Information technology — Governance of IT for the organization (제3판, 2024-02)
- ISO/IEC 38500:2015 Information technology — Governance of IT for the organization (제2판)
