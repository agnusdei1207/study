## 지식 로드맵 내 현재 위치

<div class="itpe-topic-path" role="img" aria-label="IT 전략·관리에서 IT 거버넌스를 거쳐 ISO IEC 38500으로 이어지는 지식 위치"><span>IT 전략·관리</span><span>IT 거버넌스</span><strong>ISO/IEC 38500</strong></div>

## 30초 인출

- 본질: **ISO/IEC 38500**은 IT를 IT 전담 부서에만 맡기지 않고 거버넌스 기구(이사회·경영진)가 IT 사용을 직접 판단·감독하게 하는 최상위 IT 거버넌스 원칙 표준
- 메커니즘: 이해관계자 기대 수렴 → **EDM(Evaluate, Direct and Monitor)** → Monitor 결과를 다음 Evaluate에 환류
- 산출물: 의사결정 근거 · 위임 기준 · 감독 결과

## 핵심 용어

<details>
<summary>핵심 용어</summary>

- **EDM(Evaluate, Direct and Monitor)**: 평가·지시·모니터링 결과를 다음 평가에 환류하는 IT 거버넌스 순환
- **Governing Body**: 조직의 IT 사용 방향과 감독에 최종 책임을 지는 거버넌스 기구
- **Engage stakeholders**: 2024판 모델에 추가된 거버넌스 활동 → EDM 판단의 기준이 되는 이해관계자 기대 수렴
- **ISO 37000**: ISO/IEC 38500:2024가 원칙과 성과 체계를 정렬한 조직 거버넌스 지침
- **Feedback Loop**: 모니터링 결과를 다음 평가의 근거로 되돌리는 폐루프 통제

</details>

## 예상문제

> ISO/IEC 38500:2024의 개념과 EDM 모델을 설명하고, 거버넌스와 경영관리의 역할, 거버넌스 원칙·프레임워크, 적용 문제점과 대응책을 제시하시오. (25점)

## Ⅰ. IT 사용의 판단 책임을 정립하는 ISO/IEC 38500

> ISO/IEC 38500은 IT 부서의 운영 절차가 아니라 거버넌스 기구의 판단 기준이며, 권한은 위임해도 최종 책임은 이전되지 않음

- 정의: 조직의 IT 사용을 위한 **거버넌스 원칙·모델·프레임워크**를 제시하는 국제표준
- 목적: **Effective performance · Responsible stewardship · Ethical behaviour**의 3대 거버넌스 성과

## Ⅱ. EDM 순환과 거버넌스·경영관리의 역할

> 거버넌스 기구의 EDM은 경영관리의 실행을 대신하지 않으며, 지시는 목표·전략·정책으로 내려가고 보고는 성과·준수 결과로 올라와 다음 평가에 환류됨

```mermaid
flowchart TB
    subgraph GB["Governing Body · 최종 책임"]
        direction TB
        ST["Engage stakeholders<br/>이해관계자 기대 수렴"]
        subgraph LOOP["Feedback Loop"]
            direction LR
            E["Evaluate<br/>상황·대안 평가"] --> D["Direct<br/>방향·권한 지시"] --> M["Monitor<br/>성과·준수 감독"] --> E
        end
        ST -->|평가 입력| LOOP
    end
    MG["Management · 위임 책임<br/>계획·설계 · 개발·배포 · 운영·관리"]
    GB -->|지시: 목표·전략·정책| MG
    MG -->|보고: 성과·준수 결과| GB
```

## Ⅲ. 11개 원칙과 6개 거버넌스 프레임워크 요소

> 11개 원칙은 판단의 관점을, 6개 프레임워크 요소는 그 판단을 조직 안에서 작동시키는 통제 구조를 제공하며, 원칙만 선언하고 요소별 확인 증적이 없으면 거버넌스는 작동하지 않음

### 1. ISO 37000 정렬 11개 원칙 — 1·4·6 계층

```mermaid
flowchart TD
    ROOT["ISO/IEC 38500 11개 원칙 (ISO 37000 정렬)"] --> P1["Primary 1 (조직 목적)"]
    ROOT --> F4["Foundational 4 (거버넌스 기본 축)"]
    ROOT --> E6["Enabling 6 (실행 조건)"]

    P1 --> P1_1["Purpose (조직 목적 정렬)"]

    F4 --> F4_1["Value generation (가치 창출)"]
    F4 --> F4_2["Strategy (전략 정렬)"]
    F4 --> F4_3["Oversight (성과 감독)"]
    F4 --> F4_4["Accountability (책임 추적)"]

    E6 --> E6_1["Stakeholder engagement (이해관계자)"]
    E6 --> E6_2["Leadership (윤리적 리더십)"]
    E6 --> E6_3["Data and decisions (데이터 기반 결정)"]
    E6 --> E6_4["Risk governance (위험 통제)"]
    E6 --> E6_5["Social responsibility (사회적 책임)"]
    E6 --> E6_6["Viability & performance (지속가능 성과)"]
```

### 2. 거버넌스 프레임워크 6요소

| 요소 | 역할 | 확인 |
|---|---|---|
| **Direction** | IT 사용 방향 | 조직 목표·외부 요구 반영 |
| **Capability** | 디지털 역량 | 역량 식별·확보·조정 |
| **Policy** | IT 사용 경계 | 전략 결정의 정책화 |
| **Delegation** | 권한·책임 위임 | 위임 범위·감독 기준 |
| **Performance** | 기대성과 | 성과 기준·개선 환류 |
| **Accountability** | 책임·준수 입증 | 결정권자·증적 추적 |

## Ⅳ. ISO/IEC 38500 적용 문제점·대응책

> 선언적 원칙을 의사결정 증적과 측정 가능한 감독 기준으로 전환해야 거버넌스가 회의체 운영에 머물지 않음

| 위험 | 대책 | 효과 |
|---|---|---|
| IT 의사결정의 실무부서 편중 | 투자·위험 의사결정권 명문화 | 책임 소재 추적 |
| 운영지표 중심 성과 보고 | 조직 목적·가치·위험 지표 연결 | 가치 중심 감독 |
| 위임 후 감독 공백 | 정기 보고·예외 상향 기준 설정 | 잔여위험 조기 노출 |

## Ⅴ. 의사결정 환류 중심의 기술사적 제언

> 거버넌스 성숙도는 회의체 수가 아니라 판단 근거·위임·감독 결과가 하나의 Feedback Loop로 이어지는가로 판정함

### 학습자 통찰 메모 — 답안 밖

- `[핵심 통찰]`: ISO/IEC 38500의 핵심은 IT 의사결정을 경영진에게 떠넘기는 것이 아니라, 누가 어떤 근거로 판단했고 결과를 어떻게 다시 평가했는지 책임의 고리를 닫는 데 있음.
- `나라면`: 주요 IT 투자마다 목적·결정권자·허용위험·감독지표를 한 장에 묶고, Monitor 결과를 다음 Evaluate 안건의 필수 입력으로 사용하겠음.

### 실전 답안용 기술사적 제언

- 판정: IT 투자 판단의 목적·결정권·허용위험·감독 결과가 EDM 순환으로 연결되는지 확인
- 대안: 거버넌스 기구의 지시(목표·전략·정책)와 경영관리층의 보고(성과·준수)를 의사결정 기록으로 연결
- 검증: Monitor 결과가 차기 Evaluate 안건의 입력으로 환류되는지 점검
- 효과: 중복 투자·섀도우 IT·책임 공백 축소

```mermaid
flowchart TD
    A["현행 한계<br/>(위임 이후 판단 근거 및 감독 결과 단절)"] --> B["개선 대안<br/>(목적·결정권·허용위험·감독지표 통합)"]
    B --> C{"검증 판정<br/>(Monitor 결과가 차기 Evaluate 안건에 필수 환류되는가?)"}
    C -->|예| D["실행 효과<br/>(폐루프 환류·책임 추적)"]
    C -->|아니오| E["시정 조치<br/>(지표 재설계·감독 기준 보완)"]
```

## 1교시 10점 답안 발췌

### 1. 정의·목적

- 정의: **ISO/IEC 38500**은 거버넌스 기구가 조직의 IT 사용을 판단·감독하도록 원칙·모델·프레임워크를 제시하는 국제표준
- 목적: Effective performance · Responsible stewardship · Ethical behaviour의 3대 거버넌스 성과

### 3. 원칙·프레임워크와 결론

- 원칙: **ISO 37000**에 정렬한 11개 원칙 → Primary 1(Purpose) · Foundational 4 · Enabling 6
- 프레임워크: Direction · Capability · Policy · Delegation · Performance · **Accountability**
- 결론: 위임은 실행 권한을 나누지만 최종 책임을 이전하지 않음
