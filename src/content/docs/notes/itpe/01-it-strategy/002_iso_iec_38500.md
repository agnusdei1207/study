## 지식 로드맵 내 현재 위치

IT 전략·관리 → IT 거버넌스 → **ISO/IEC 38500**

## 30초 인출

- 본질: ISO/IEC 38500은 조직의 최고기관이 현재와 미래의 IT 사용을 평가·지시·감독하도록 안내하는 IT 거버넌스 국제표준
- 메커니즘: 최고기관이 IT 사용을 평가해 방향을 지시하고, 실행은 경영진에 위임하되 실적을 감독해 다음 평가에 반영하는 EDM 순환
- 통찰: 위임 후 실적을 승인 근거와 대조하지 않으면 감독 공백이 생기므로 승인 근거·위임 범위·재평가 시점의 결정 기록

<details>
<summary>핵심 용어</summary>

- **ISO/IEC 38500** : 조직 최고기관의 IT 사용 평가·지시·감독 원칙과 모델을 제시하는 IT 거버넌스 국제표준. 현행판은 2024판
- **EDM(Evaluate, Direct and Monitor)** : IT 사용의 현재·미래를 평가하고, 목표·전략·정책으로 지시하며, 실적과 준수를 감독하는 거버넌스 순환
- **Governing Body(최고기관)** : 이사회처럼 조직의 성과와 준수에 최종 책임을 지는 개인이나 집단
- **ISO 37000** : 조직 거버넌스의 원칙과 성과를 정한 국제표준. 2024판 ISO/IEC 38500이 그 원칙을 IT 거버넌스에 적용
- **위임(Delegation)** : 최고기관이 책임은 유지한 채 실행 권한을 경영진·위원회에 넘기는 구조

</details>

## 2~4교시 25점 답안

## Ⅰ. ISO/IEC 38500의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ISO/IEC 38500** 은 조직의 최고기관이 현재·미래의 IT 사용을 평가·지시·감독하도록 안내하는 IT 거버넌스 국제표준 |
| 목적 | 조직 목적에 맞는 효과적이고 책임 있는 IT 사용 |

## Ⅱ. 경영관리와 구별되는 ISO/IEC 38500의 특징

| 특징 | 의미 |
|---|---|
| 최고기관 책임 | IT 사용의 성과와 준수에 대한 최종 책임을 **Governing Body(최고기관)** 에 귀속 |
| 실행 위임과 책임 유지 | 실행 권한은 경영진에 위임하되 감독 책임은 최고기관에 유지 |
| 조직 거버넌스의 일부 | 2024판의 **ISO 37000** 원칙 채택으로 IT 거버넌스를 조직 거버넌스 안에 통합 |

## Ⅲ. EDM 순환과 거버넌스·경영관리의 역할

### EDM 순환

```text
이해관계자 참여: 요구·기대 수렴 (2024판 추가)
    ↓
거버넌스: 평가 → 방향 제시 → 감독
    ↓ 목표·전략·정책 지시
관리: 실행·운영
    ↓ 성과·준수 결과 보고
거버넌스: 재평가
```

**EDM(Evaluate, Direct and Monitor)** 은 평가·지시·감독이 한 번에 끝나지 않고, 감독 결과가 다음 평가의 근거가 되는 순환. 2024판 모델은 이해관계자 참여(Engage stakeholders)를 요소로 추가하고, 경영진도 최고기관이 정한 프레임워크 안에서 거버넌스를 수행하는 구조로 확장

### 지시 확대: 위임과 책임의 구조

```text
최고기관 ── 최종 책임 유지, 방향·정책 승인
    │
    ├─ 위원회 ── 투자·위험 등 위임받은 사전 검토
    │
    └─ 경영진 ── 위임 범위 안의 실행과 실적 보고
```

## Ⅳ. 판본별 원칙과 2024판 거버넌스 요소

### 2015판의 여섯 원칙

| 원칙 | 핵심 |
|---|---|
| **책임** Responsibility | IT 공급·수요에 대한 개인과 조직의 책임 수용 |
| **전략** Strategy | 현재·미래 IT 역량을 고려한 사업 전략 수립 |
| **획득** Acquisition | 비용·위험·편익 분석에 근거한 IT 획득 |
| **성과** Performance | 사업 요구를 충족하는 IT 서비스 수준 |
| **준수** Conformance | 법규·내부 정책의 준수 |
| **인간 행동** Human Behaviour | 이해관계자의 행동과 요구에 대한 존중 |

### 2024판의 11개 원칙(ISO 37000 채택)

| 구분 | 원칙 |
|---|---|
| 1차 원칙 | 목적(Purpose) |
| 기초 원칙 | 가치 창출(Value generation)·전략(Strategy)·감독(Oversight)·책임성(Accountability) |
| 실현 원칙 | 이해관계자 참여·리더십·데이터와 의사결정·위험 거버넌스·사회적 책임·지속 가능성과 장기 성과(Viability and performance over time) |

2024판이 제시하는 거버넌스 성과는 효과적 성과(Effective performance)·책임 있는 관리(Responsible stewardship)·윤리적 행동(Ethical behaviour)

### 2024판 거버넌스 프레임워크 요소

| 요소 | 역할 |
|---|---|
| **Direction** | 신기술과 외부 이해관계자 요구를 고려한 IT 사용 방향의 검토와 조직 목표 정렬 |
| **Capability** | 조직 목표에 필요한 디지털 역량의 식별·조율·관리 |
| **Policy** | 전략적 결정을 반영해 IT 사용을 이끄는 거버넌스 정책과 관리 재량의 범위 |
| **Delegation** | IT 사용에 관한 권한·책임의 위임과 생태계 전반의 감독 |
| **Performance** | 명확한 성과 기대치 설정과 선제적 감시 체계에 의한 측정·개선 |
| **Accountability** | IT 정책의 책임 이행·준수를 입증하는 체계. 위임 뒤에도 최고기관에 남는 책임 |

Delegation과 Accountability의 경계, 즉 실행은 넘기되 책임은 남는 구간이 감독 공백이 생기는 지점

## Ⅴ. ISO/IEC 38500 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| IT 투자·위험 결정의 실무 부서 편중과 책임 소재 불명확 | 최고기관·위원회·경영진별 결정 권한의 명문화 |
| 위임 뒤 승인 근거와 실적의 대조 부재 | 승인 시점의 가정과 재평가 시점을 결정 기록에 명시 |
| 가동률 같은 운영 지표 중심의 성과 보고 | 조직 목적·가치·위험 지표와 연결한 성과 보고 |
| 예외 상황의 최고기관 보고 지연 | 위임 범위와 함께 예외 보고 임계값 설정 |

## Ⅵ. 제언

승인 근거·위임 범위·재평가 시점을 하나의 결정 기록으로 묶고, 재평가 때 실적과 승인 당시 가정의 대조

### IT 투자 결정 기록의 구성

```text
IT 투자 결정 기록
    │
    ├─ 승인 근거 ── 기대 성과와 전제 가정
    │
    ├─ 위임 범위 ── 실행 책임자와 권한
    │
    ├─ 예외 보고 임계값
    │
    └─ 재평가 시점
```

### 재평가 시점 확대: 실적과 가정의 대조

```text
경영진의 실적 보고
    ↓
승인 당시 가정과 실적의 대조
    ↓
재평가 판정
    ├─ 가정 유지 → 기존 방향 유지
    └─ 가정 붕괴 → 방향·위임 범위의 재지시
```

### 선택 근거: 회의체 중심 운영과의 비교

| 구분 | 회의체 중심 운영 | 제언: 결정 기록 기반 감독 |
|---|---|---|
| 감독 대상 | 회의 개최와 안건 처리 실적 | 승인 당시 가정 대비 실적 |
| 위임 후 책임 확인 | 담당 부서 보고에 의존 | 기록된 위임 범위·임계값 기준 |
| 다음 결정 반영 | 개별 회의 판단 | 재평가 판정 결과의 재지시 |
