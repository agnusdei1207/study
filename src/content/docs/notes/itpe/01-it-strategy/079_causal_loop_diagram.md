## 연관 키워드

- 인과루프다이어그램(CLD), 시스템 사고, 시스템다이너믹스
- 인과극성, 강화루프, 균형루프, 시간지연, 피드백 순환, 저량-유량도

## Ⅰ. 인과루프다이어그램의 개요

- 핵심 요약 : 변수 간 인과관계와 피드백 순환을 도식화해 복잡한 문제의 구조와 정책 효과를 이해하는 도구.
- 개념 : **인과루프다이어그램** (CLD, Causal Loop Diagram)은 시스템 사고(Systems Thinking)에서 변수 간 인과 화살표·인과극성·피드백 순환으로 문제의 구조를 표현하는 도구이며, **시스템다이너믹스** (System Dynamics) 방법론의 정성 모형화 수단이다.
- 배경 및 필요성 : 정책·프로젝트 문제는 효과가 다시 원인에 되돌아오는 피드백과 시간지연 때문에, 원인 하나가 결과 하나를 만드는 단선 분석으로는 행동 양식을 설명할 수 없는 구조.
- 주요 목적 : 복잡한 시스템의 성장·저항 원리를 드러내고, 개입 시점·개입 위치의 선택 근거와 의도치 않은 부작용을 사전에 파악하는 것.

## Ⅱ. 인과루프다이어그램의 특징 및 장점

- 핵심 요약 : 인과극성·강화·균형 루프·시간지연 표시가 구조 기반 의사결정과 부작용 예측이라는 장점으로 연결되는 구조.

1. 인과극성 표시 : 변수 간 영향이 같은 방향(+)인지 반대 방향(−)인지 **인과극성** (Causal Polarity)으로 표기 → 분석자의 인과 가정이 명시적 문서화되는 효과.
2. 강화루프 식별 : 변화를 증폭하는 **강화루프** (Reinforcing Loop, R)를 찾아냄 → 급성장·악화의 자기강화 원리 파악 효과.
3. 균형루프 식별 : 목표나 제약을 향해 조절하는 **균형루프** (Balancing Loop, B)를 찾아냄 → 시스템이 안정을 추구하거나 변화에 저항하는 원리 파악 효과.
4. 시간지연 표시 : 원인과 결과 사이의 지연을 **시간지연** (Time Delay) 기호로 표시 → 성급한 정책 수정과 장기 효과 누락 방지 효과.
5. 이해관계자 공유 수단 : 구조를 한 장의 도식으로 정리 → 조직 간 문제 인식의 정합화와 개입점 논의의 효율화 효과.

## Ⅲ. 인과루프다이어그램의 구조 (흐름)

- 핵심 요약 : 변수 선정 → 인과 화살표·극성 표시 → 강화·균형 루프 식별 → 지연 표시 → 가설 검증의 작성 절차.
- 루프 지배(Loop Dominance) : 시간 흐름에 따라 우세한 루프가 바뀌며 시스템 행동 양식이 전환되는 개념.

```text
[ CLD 작성 절차 ]

문제 질문·시스템 경계 정의
    ↓
변수 선정
    ↓
인과 화살표·극성 표시
    ↓
강화·균형 루프 식별
    ↓
시간지연 표시·가설 검증
```

```text
[ 강화루프 R : 성장의 자기강화 ]

사용자 수 증가
    ↓ (+)
콘텐츠 생성 증가
    ↓ (+)
서비스 가치 증가
    ↓ (+)
사용자 수 재증가 (순환)
```

```text
[ 균형루프 B : 목표 지향 조절 ]

현재 수준과 목표의 격차
    ↓ (+)
개선 투입 증가
    ↓ (−)
격차 축소 (조절)
```

## Ⅳ. 인과루프다이어그램과 단선 인과 분석의 비교

- 핵심 요약 : 원인 하나가 결과 하나로 끝나는 단선 인과 분석과 달리, CLD는 순환·지연을 포함한 시스템 행동을 설명.

| 비교 축 | 단선 인과 분석 | 인과루프다이어그램(CLD) |
| --- | --- | --- |
| 인과 구조 | 원인→결과의 단방향 사슬 | 피드백 순환·다중 루프 |
| 시간 처리 | 즉시 효과 가정 | 시간지연의 명시적 표시 |
| 행동 예측 | 최종 결과 수준만 설명 | 성장·안정·진동 등 행동 양식 설명 |
| 개입 설계 | 단일 원인 제거 | 루프상 개입점 탐색 |
| 2차 효과 | 간과 위험 | 부작용·의도치 않은 효과의 가시화 |

- 선택 기준 : 문제 구조의 가설 탐색은 CLD로, 축적량과 변화율의 정량 분석이 필요하면 저량-유량도(Stock and Flow Diagram)로 발전시키는 절차가 적합.

## Ⅴ. 인과루프다이어그램의 한계와 방안

- 핵심 요약 : 인과 가정의 과신은 데이터 검증으로, 지연 누락은 시나리오 분석으로, 모형 과잉은 경계 통제로 바로잡는 원칙.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 인과 연결 과잉 단순화 | 주관적 연결·변수 누락 → 잘못된 개입점 선택 | 이해관계자 검토·시계열 자료 대조 | 미검증 연결 수 |
| 인과와 상관 혼동 | 정성 도식을 증거로 오인 → 과잉 확신 | 가설 취급·정량 검증 병행 | 검증 완료 가설 비율 |
| 시간지연 누락 | 단기 효과만 평가 → 정책 오진 | 지연 표시와 시나리오 분석 운영 | 지연 반영 항목 비율 |
| 모형 과잉 복잡화 | 변수·루프의 무분별 추가 → 해석 불가 | 분석 질문 중심의 경계·변수 제한 | 변수·루프 수 |

## Ⅵ. 인과루프다이어그램 적용에 대한 기술사적 제언

- 핵심 요약 : 정책 설계 절차에 시스템 사고 검토를 상시화하고, 모형 관리·정량 확장 체계로 CLD를 의사결정 표준 도구로 내재화하는 방향.
- 도입 : 정책·프로젝트 기획 단계에서 이해관계자가 함께 CLD를 작성하는 워크숍을 공식 절차로 편입.
- 모형 관리 : 기획 조직이 인과 가정·루프 정의를 문서로 관리하고 실적 데이터로 주기 갱신하는 모형 운영 체계 구축.
- 정량 확장 : 분석 전문 조직이 핵심 루프를 저량-유량 시뮬레이션 모형으로 연계해 정책 대안의 사전 검증 체계 마련.

## Ⅶ. 결론

- 핵심 요약 : 인과루프다이어그램은 피드백 순환과 시간지연을 드러내 복잡 문제의 구조를 보이는 시스템 사고 도구.
- 인과 가정의 검증과 2차 효과 관찰이 구조 기반 의사결정의 전제 조건임.
