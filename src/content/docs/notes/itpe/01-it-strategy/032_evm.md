## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 통제·원가 관리 → **EVM**

## 30초 인출

- 본질: EVM(Earned Value Management)은 완료한 작업의 예산 가치를 계획·실제 원가와 같은 기준일에 비교해 일정·원가 성과를 측정하는 프로젝트 통제 기법
- 메커니즘: 성과측정기준선에서 PV·EV·AC를 측정하고, EV를 PV와 비교해 일정 성과, AC와 비교해 원가 성과를 판정한 뒤 EAC로 완료 원가 예측
- 통찰: 한계: 담당자의 주관적 진척률로 EV가 부풀어 편차가 늦게 드러남 → 방안: 작업패키지별 EV 인정 방식과 상태일을 착수 시 확정

<details>
<summary>핵심 용어</summary>

- **EVM(Earned Value Management)** : 완료 작업의 예산 가치와 계획·실제 원가를 통합 비교하는 프로젝트 성과 측정 기법
- **PMB(Performance Measurement Baseline)** : 승인된 범위·일정·원가를 통합한 성과측정기준선
- **PV(Planned Value)** : 기준일까지 수행하기로 계획한 작업에 배정된 승인 예산
- **EV(Earned Value)** : 기준일까지 실제 완료한 작업에 배정된 승인 예산
- **AC(Actual Cost)** : 기준일까지 수행한 작업에 실제 발생한 원가
- **BAC(Budget at Completion)** : 전체 작업에 승인된 완료 예산
- **EAC(Estimate at Completion)** : 현재 성과와 잔여 작업 가정으로 산정한 최종 원가 예측치
- **ETC(Estimate to Complete)** : 남은 작업을 완료하는 데 필요한 원가 예측치
- **CPI(Cost Performance Index)** : EV를 AC로 나눈 원가 효율 지수
- **SPI(Schedule Performance Index)** : EV를 PV로 나눈 일정 효율 지수
- **상태일(Status Date)** : PV·EV·AC를 함께 집계하는 공통 기준 시점
- **ES(Earned Schedule)** : 획득가치를 시간 단위로 환산해 일정 성과를 측정하는 확장 기법

## 2~4교시 25점 답안

## Ⅰ. EVM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EVM(Earned Value Management)** 은 완료 작업의 예산 가치를 계획·실제 원가와 비교해 일정·원가 성과를 측정하는 프로젝트 통제 기법 |
| 목적 | 일정 지연과 원가 초과의 조기 발견과 완료 원가 예측 |

## Ⅱ. 진척률 보고와 구별되는 EVM의 특징

| 특징 | 의미 |
|---|---|
| 공통 화폐 단위 | 범위·일정·원가를 승인 예산 금액으로 환산해 한 척도로 비교 |
| 산출물 기준 성과 | 지출액이 아닌 완료 작업의 예산 가치로 진척 인정 |
| 기준선 대비 측정 | 승인된 **PMB** 와 같은 상태일의 실적 대조 |
| 추세 기반 예측 | 현재 성과지수로 완료 시점의 원가 예측 |

## Ⅲ. EVM 성과 관리 체계와 편차 판정

### EVM 성과 관리 흐름

```text
PMB 수립: 범위·일정·원가 통합 기준선
    ↓
상태일 기준 측정: PV·EV·AC
    ↓
성과 분석: 편차(CV·SV)와 지수(CPI·SPI)
    ↓
완료 예측: EAC·ETC
    ↓
시정조치와 변경관리
```

### 성과 분석 확대: EV 중심의 편차 판정

```text
EV: 완료 작업의 예산 가치
    │
    ├─ PV와 비교 ── SV·SPI: 계획 대비 일정 성과
    │
    └─ AC와 비교 ── CV·CPI: 지출 대비 원가 성과
```

## Ⅳ. 성과 지표와 측정·예측 방식 비교

### 성과 지표

| 지표 | 산식 | 불리한 신호 |
|---|---|---|
| CV | EV − AC | 0 미만: 원가 초과 |
| SV | EV − PV | 0 미만: 일정 지연 |
| **CPI** | EV ÷ AC | 1 미만: 원가 효율 저하 |
| **SPI** | EV ÷ PV | 1 미만: 일정 효율 저하 |

### EV 인정 방식

| 방식 | 인정 기준 | 적합한 작업 |
|---|---|---|
| 고정 비율(0/100·50/50) | 착수·완료 시점에 정해진 비율 인정 | 한두 보고 주기 안에 끝나는 짧은 작업 |
| 가중 마일스톤 | 중간 산출물 완료마다 배정 비율 인정 | 여러 주기에 걸치고 중간 산출물이 있는 작업 |
| 진척률 | 담당자가 추정한 완료 비율 인정 | 객관적 중간 기준을 두기 어려운 작업 |
| LOE(Level of Effort) | 경과 시간에 따라 계획가치 그대로 인정 | 관리·지원처럼 산출물이 없는 작업 |

### EAC 산정 가정

| 가정 | 산식 | 적용 조건 |
|---|---|---|
| 편차의 일회성 | AC + (BAC − EV) | 잔여 작업이 계획 예산대로 수행될 전망 |
| 원가 효율 지속 | BAC ÷ CPI | 현재 원가 효율이 잔여 작업에도 지속될 전망 |
| 일정·원가 효율 복합 | AC + (BAC − EV) ÷ (CPI × SPI) | 일정 압박이 잔여 원가에도 영향을 주는 상황 |
| 잔여 작업 재추정 | AC + 재추정 ETC | 기준선의 전제가 무너진 상황 |

## Ⅴ. EVM 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 진척률 방식 남용에 따른 EV 과대 산정 | 짧은 작업은 고정 비율, 긴 작업은 가중 마일스톤으로 EV 인정 방식 사전 지정 |
| PV·EV·AC의 집계 시점과 작업 단위 불일치 | 공통 **상태일** 과 WBS 작업패키지 단위의 원가 대사 |
| 편차 원인과 무관한 EAC 산식 적용 | 일회성 편차는 AC + (BAC − EV), 지속 편차는 BAC ÷ CPI, 전제 붕괴는 재추정 ETC 적용 |
| 완료 시점에 SPI가 1로 수렴하는 일정 지표의 한계 | 핵심경로 일정 병행 검토와 **ES** 기반 일정 성과 보완 |

## Ⅵ. 제언

착수 시 작업패키지별 EV 인정 방식·완료 증거와 공통 상태일을 확정해 진척률 추정에 따른 편차 은폐 차단

### EVM 측정 기준의 사전 확정 구조

```text
EVM 측정 기준의 사전 확정
    │
    ├─ 작업패키지 ── EV 인정 방식·완료 증거
    │
    ├─ 상태일 ── PV·EV·AC 공통 집계 시점
    │
    └─ 변경관리 ── EAC 가정의 선택 근거 검토
```

### 작업패키지 확대: EV 인정 방식 결정 절차

```text
작업패키지의 기간·중간 산출물 확인
    ↓
EV 인정 방식 선택
    ├─ 한두 보고 주기 내 완료 → 고정 비율
    ├─ 중간 산출물 존재 → 가중 마일스톤
    └─ 산출물 없는 지원 업무 → LOE
    ↓
완료 증거와 승인자 지정 후 PMB 확정
```

### 선택 근거: 진척률 자가 보고와의 비교

| 구분 | 진척률 자가 보고 | 제언: 사전 확정 측정 기준 |
|---|---|---|
| EV 인정 근거 | 담당자의 완료 비율 추정 | 작업패키지별 완료 증거 |
| 측정 시점 | 자료별로 다른 집계일 | 공통 상태일 |
| 편차 발견 시점 | 후반부 누적 후 | 매 보고 주기 |
| EAC 산정 | 단일 산식 반복 | 편차 원인에 맞는 가정과 근거 기록 |
