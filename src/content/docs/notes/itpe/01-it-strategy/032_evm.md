## 연관 키워드

- EVM, Earned Value Management, 획득가치관리
- PV, EV, AC, CV, SV, CPI, SPI, EAC, TCPI
- BAC, 베이스라인, 일정/원가 성과, ES(Earned Schedule)

## Ⅰ. EVM의 개요

- 핵심 요약 : 계획 일정·예산, 실제 비용, 완료 작업 가치를 종합 비교하여 진척 상태를 측정하고 최종 비용·완료 시점을 예측하는 획득가치관리 기법.
- 개념 : 프로젝트의 계획된 일정과 예산, 실제 투입된 비용, 실제로 완료된 작업 가치를 종합적으로 비교하여 프로젝트의 현재 진척 상태를 측정하고 최종 비용과 완료 시점을 정량적으로 예측하는 획득가치관리(EVM, Earned Value Management) 기법.
- 배경 및 필요성 : 단순 비용 집행률이나 주관적 공정률만으로는 일정 지연과 예산 초과의 실질적 원인을 파악할 수 없는 한계를 극복하기 위해 객관적 통합 진도 관리 기준 필요.
- 주요 목적 : 일정 및 원가 성과의 통합 측정, 성과 지수(CPI, Cost Performance Index / SPI, Schedule Performance Index) 기반의 조기 이상 감지, 최종 소요 비용(EAC, Estimate at Completion)의 과학적 예측.

## Ⅱ. EVM의 특징 및 장점

- 핵심 요약 : **PV·EV·AC**를 함께 측정하여 일정·원가 편차를 조기에 파악하고 완공 비용을 예측.
1. **PV·EV·AC 통합** : 계획·실적·지출을 동일 시점에 비교하여 집행률만으로 숨겨지는 진도 지연을 드러냄.
2. **CV·SV 편차 분석** : 획득 가치에서 실제 원가 또는 계획 가치를 빼서 원가 초과와 일정 지연을 조기 식별.
3. **CPI·SPI 성과지수** : 비용·일정 효율을 비율로 비교하여 프로젝트 간 성과와 개선 우선순위를 판단.
4. **EAC·TCPI 예측** : 현재 원가 추세와 남은 작업 요구 성과를 계산하여 완공 비용과 시정 가능성을 검토.
5. **베이스라인 통제** : 승인된 범위 변경만 계획 가치에 반영하여 지표의 비교 가능성을 유지.

## Ⅲ. EVM의 구조 (흐름)

- 핵심 요약 : 3대 변수 산출에서 편차·지수 분석, 최종 예측으로 이어지는 EVM 산식 체계.
- EVM의 3대 핵심 변수.

| 핵심 변수 | 약어 | 영문 명칭 | 정의 및 의미 |
|---|---|---|---|
| **계획 가치** | PV | Planned Value | 특정 시점까지 수행하기로 계획된 작업의 예산 (과거 BCWS, Budgeted Cost of Work Scheduled) |
| **획득 가치** | EV | Earned Value | 특정 시점까지 실제로 완료된 작업에 배정된 예산 가치 (과거 BCWP, Budgeted Cost of Work Performed) |
| **실제 원가** | AC | Actual Cost | 특정 시점까지 완료된 작업을 수행하는 데 실제로 지출된 총비용 (과거 ACWP, Actual Cost of Work Performed) |

- EVM 편차, 성과지수 및 예측 산식.

```text
[편차 분석]
   비용 편차 (CV, Cost Variance) = EV - AC
      ── CV > 0 예산 절감, CV < 0 예산 초과
   일정 편차 (SV, Schedule Variance) = EV - PV
      ── SV > 0 일정 단축, SV < 0 일정 지연

[성과 지수]
   비용 성과지수 (CPI) = EV / AC
      ── CPI > 1 원가 효율 우수, CPI < 1 원가 낭비
   일정 성과지수 (SPI) = EV / PV
      ── SPI > 1 일정 진행 빠름, SPI < 1 일정 지연

[최종 예측]
   최종 완료비용 예측치 (EAC)
      = BAC(Budget at Completion) / CPI
      ── 현재의 원가 추세가 지속될 경우
   완공잔여 성과지수 (TCPI)
      ── To-Complete Performance Index
      = (BAC - EV) / (BAC - AC)
```

```text
[EVM 관리 흐름]
베이스라인(PV) 설정
   ↓
작업 수행 → EV 산출 / AC 집계
   ↓
CV, SV, CPI, SPI 계산
   ↓
EAC, TCPI 예측
   ↓
임계치 이탈 시 시정 조치
```

- **CPI** : 비용 성과지수, EV / AC.
- **SPI** : 일정 성과지수, EV / PV.
- **EAC** : 최종 완료비용 예측치, BAC / CPI.

## Ⅳ. EVM과 전통적 진도 관리의 비교

- 핵심 요약 : EVM은 일정·원가 통합 측정과 예측, 전통 방식은 비용 집행률·주관적 공정률 중심이다.
- 비교 대상 및 선택 기준.

```text
[진도 관리 방식 선택 흐름]
통합 측정 필요? ── 예 ──→ EVM
   ↓ 아니오
단순 비용 집행률 ──→ 전통 방식
```

| 비교 항목 | EVM (Earned Value Management) | 전통적 진도 관리 |
|---|---|---|
| 측정 기준 | PV·EV·AC 통합 비교 | 비용 집행률, 주관적 공정률 |
| 일정 반영 | SV/SPI로 일정 성과 정량화 | 일정과 비용 분리 관리 |
| 예측 기능 | EAC/TCPI 기반 최종 비용·시점 예측 | 사후 집계 중심, 예측 제한 |
| 이상 감지 | CPI/SPI 임계치 기반 조기 경보 | 문제 발생 후 인지 |
| 적용 난이도 | 베이스라인·WBS(Work Breakdown Structure) 필요 | 상대적으로 간단 |

## Ⅴ. EVM 관리의 한계와 방안

- 핵심 요약 : **SPI 후반 왜곡·EV 과대 계상·기준선 변경 누락**을 각각 시간 지표·검수 기준·변경 통제로 보완.

| 한계 | 원인·영향 | 대응 방안 |
|---|---|---|
| **SPI 후반 왜곡** | 종료 시 PV와 EV가 같아지면 지연 완료 프로젝트도 SPI가 1로 수렴하여 지연을 가림 | 시간 단위 **획득 일정**(ES)과 SPI(t)를 병행하여 완료 예상 시점 확인 |
| **EV 과대 계상** | 산출물의 품질 검수 없이 공정률만 인정하면 결함이 많은 작업도 완료로 계산 | 인수 기준·마일스톤 검수를 EV 인정 조건으로 두고 0/100 등 객관적 측정 적용 |
| **베이스라인 불일치** | 승인된 과업 변경을 PV에 반영하지 않으면 편차와 EAC가 왜곡 | **통합 변경 통제**로 승인 이력과 예산·일정을 함께 갱신 |

## Ⅵ. 실무 EVM 적용을 위한 기술사적 제언

- 핵심 요약 : 작업 완료 기준 객관화, ES 기법 병행, 거버넌스 연계 조기 경보.
- 작업 완료 기준의 객관화 (0/100, 50/50 규칙 등) : 작업 패키지의 공정률을 담당자의 주관적 추정이 아닌, 마일스톤 산출물 검수 완료 여부로 측정하여 EV 왜곡 차단.
- 일정 성과지수(SPI)의 후반부 왜곡 보완 : 프로젝트 종료 시점이 다가올수록 결국 모든 작업이 완료되어 SPI가 1.0에 수렴하는 한계를 극복하기 위해 시간 단위 일정 관리 기법인 ES(Earned Schedule) 기법 병행.
- EVM 분석 결과의 거버넌스 연계 : CPI 또는 SPI가 허용 임계치(예: 0.85 이하)를 이탈할 경우 즉각적인 시정 조치(Corrective Action) 및 경영진 보고가 이루어지는 조기 경보 체계 수립.

## Ⅶ. 결론

- 핵심 요약 : EVM은 PV·EV·AC 통합 측정과 EAC 예측으로 프로젝트 진척과 비용을 과학적으로 관리하는 기법.
- 요약 : EVM은 편차·지수 분석과 최종 예측 산식을 통해 일정·원가 성과를 통합 관리하는 체계.
- 시사점 : 진척률 객관화, ES 기법 병행, 통합 변경 통제를 통해 지표 왜곡과 베이스라인 변경 리스크를 관리 필요.
