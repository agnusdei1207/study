## 지식 로드맵 내 현재 위치

IT 전략·관리 → 프로젝트 일정·비용 관리 → **EVM**

## 30초 인출

- 본질: EVM(Earned Value Management)은 완료한 작업에 배정된 예산(획득가치)을 기준으로 일정 성과와 비용 성과를 함께 측정하는 프로젝트 성과 관리 기법
- 메커니즘: 계획가치(PV)·획득가치(EV)·실제원가(AC)를 비교해 일정 차이·원가 차이와 SPI·CPI를 구하고, 이 지수로 완료시점 추정치(EAC)를 예측
- 통찰: 획득가치는 진척을 어떻게 판단하느냐에 따라 달라지므로, 작업 패키지 착수 전에 요구사항 추적·검토 통과 같은 객관적 완료 기준과 그에 맞는 EV 산정 방식을 확정

<details>
<summary>핵심 용어</summary>

- **EVM(Earned Value Management)** : 완료한 작업의 예산 가치를 계획과 실제 원가에 대조해 일정·비용 성과를 통합 측정하는 관리 기법
- **PV(Planned Value)** : 보고 시점까지 완료하기로 계획한 작업의 예산. 전통 표기는 BCWS
- **EV(Earned Value)** : 실제 완료한 작업에 배정된 예산. 전통 표기는 BCWP
- **AC(Actual Cost)** : 완료한 작업에 실제 들어간 원가. 전통 표기는 ACWP
- **BAC(Budget At Completion)** : 승인된 전체 작업 범위의 총 예산. 성과측정기준선(Performance Measurement Baseline)으로 시간 배분되는 값
- **SV(Schedule Variance)** : 일정 차이 EV−PV. 양수는 유리, 음수는 불리
- **CV(Cost Variance)** : 원가 차이 EV−AC. 양수는 유리, 음수는 불리
- **SPI(Schedule Performance Index)** : 일정 성과 지수 EV/PV. 1.0 초과는 계획보다 많은 작업 완료
- **CPI(Cost Performance Index)** : 원가 성과 지수 EV/AC. 1.0 초과는 계획보다 적은 원가로 작업 완료
- **EAC(Estimate At Completion)** : 승인된 작업 전체의 현재 추정 총원가
- **TCPI(To Complete Performance Index)** : 남은 작업을 목표(BAC 또는 EAC) 안에 끝내기 위해 필요한 원가 효율. BAC 목표에서 (BAC−EV)/(BAC−AC)
- **WBS(Work Breakdown Structure)** : 프로젝트 범위를 작업 단위로 분해한 구조. 예산과 원가를 모으는 기준

## 2~4교시 25점 답안

## Ⅰ. EVM의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EVM(Earned Value Management)** 은 완료한 작업의 예산 가치를 계획 예산과 실제 원가에 대조해 일정·비용 성과를 통합 측정하는 성과 관리 기법 |
| 목적 | 일정·원가 편차의 조기 식별과 완료시점 원가의 예측 |

## Ⅱ. 예산 대비 지출 관리와 구별되는 EVM의 특징

| 특징 | 의미 |
|---|---|
| 일정 차이의 분리 | 예산 대비 실제 지출만 비교하면 보이지 않는 일정 차이를 정량화 |
| 원가 차이의 정확성 | 원가 차이가 일정 성과에 왜곡되지 않음 |
| 기준선 기반 | 시간 배분된 예산의 **성과측정기준선** 과 비교 |
| 추세 조기 식별 | 성과 추세와 계획 이탈의 조기 확인 |

## Ⅲ. EVM 성과 측정 체계

### 성과 측정 절차

```text
WBS 작업 패키지에 예산 배분
    ↓
성과측정기준선 수립: 시간 배분된 BAC
    ↓
보고 주기마다 세 값 수집
    PV(계획가치) · EV(획득가치) · AC(실제원가)
    ↓
차이·지수 계산
    SV = EV − PV      CV = EV − AC
    SPI = EV / PV     CPI = EV / AC
    ↓
완료시점 추정
    EAC = AC 누계 + (BAC − EV 누계) / 효율 지수
    ↓
편차 원인 분석과 조치
```

### 차이·지수 해석 확대: SPI·CPI 조합

```text
                 CPI ≥ 1                  CPI < 1
SPI ≥ 1    일정·원가 모두 양호       일정 앞섬, 원가 초과
SPI < 1    일정 지연, 원가 양호      일정 지연, 원가 초과
```

## Ⅳ. EV 산정 방식별 비교

| 방식 | EV 배정 | 적합 대상 |
|---|---|---|
| **고정 비율(0/100, 50/50, 25/75)** | 착수 시점에 정한 비율, 나머지는 완료 시점 | 두 보고 주기 안에 끝나는 작은 패키지 (0/100은 한 주기 안에 끝나는 패키지) |
| **진행률(Percent Complete)** | 완료 작업 비율의 추정 | 객관적·정량적 완료 근거가 있는 패키지 |
| **가중 마일스톤(Weighted Milestone)** | 관찰 가능한 마일스톤마다 가중치 배정 | 중간 산출물이 있는 장기 패키지, 보고 주기마다 마일스톤 1개 이상 필요 |
| **물리적 측정(Physical Measurement)** | 완료와 직접 연결되는 단위 수량 | 케이블 길이처럼 단위 수량 측정이 가능한 패키지 |

## Ⅴ. EVM 적용의 한계와 방안

| 한계 | 방안 |
|---|---|
| 진행률을 주관적으로 추정하면 EV가 왜곡되어 SPI·CPI 신뢰 상실 | 객관적·정량적 완료 근거가 있는 방식을 패키지 성격별로 선택 (단위 수량은 물리적 측정, 중간 산출물은 가중 마일스톤, 짧은 작업은 고정 비율) |
| 방식을 진행 중에 바꾸거나 패키지마다 기준이 달라 지수 비교 불가 | 작업 착수 전 완료 판단 기준과 EV 산정 방식의 확정 |
| **SV** 가 금액 차이여서 전체 범위 완료 시 0으로 수렴해 일정 지연이 가려짐 | SPI 추세와 임계 경로 상의 작업 지연 확인의 병행 |
| EAC 단일 값의 낙관적 추정 | 효율 지수를 달리한 복수 EAC의 범위 산출 |

## Ⅵ. 제언

작업 패키지 착수 전에 객관적 완료 기준과 그에 맞는 EV 산정 방식을 확정하고, 보고 주기마다 그 기준으로만 EV 산정

### 패키지별 EV 산정 방식 결정

```text
작업 패키지 (착수 전 완료 기준 확정)
    ↓
완료 단위를 셀 수 있는가
    ├─ 예 → 물리적 측정 (예: 통합 완료 단위 수)
    └─ 아니오 ↓
         중간 마일스톤이 있는가
            ├─ 예 → 가중 마일스톤 (예: 검토 통과)
            └─ 아니오 → 고정 비율 (짧은 작업)
```

### 보고 주기의 EV 산정 확대

```text
보고 주기 말
    ↓
확정한 완료 기준의 충족 항목 확인
(예: 추적된 요구사항 수, 통합 완료 단위 수)
    ↓
충족 항목의 배정 예산 합 = EV
    ↓
EV를 PV·AC와 대조 → SPI·CPI
```

| 구분 | 진행률 자기 보고 | 제언: 착수 전 확정 기준 |
|---|---|---|
| 완료 판단 근거 | 담당자의 추정 | 사전에 정한 객관적 기준 |
| 산정 방식의 결정 시점 | 보고 시점 | 작업 착수 전 |
| 지수의 비교 가능성 | 패키지·주기마다 상이 | 같은 기준의 반복 적용 |

## 출제 이력과 검증 출처

- 제132~140회 Q-net 공식 문제지에서 EVM을 직접 묻는 문항은 확인되지 않음
- U.S. GAO, *Cost Estimating and Assessment Guide* (GAO-20-195G, 2020.3) — PV·EV·AC(BCWS·BCWP·ACWP), CPI·SPI·TCPI, EAC 산식, EV 산정 방식표, 일정 차이의 수렴
- ANSI/EIA-748 *Earned Value Management Systems* — EV·SV·CV·BAC 정의와 EVM의 일정 차이 분리
