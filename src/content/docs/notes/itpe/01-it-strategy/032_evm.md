## 큰 그림과 30초 인출

```text
[비용 / 가치]
      ▲                                         ┌── [BAC: 총예산]
      │                                  ┌──────┘ ──> [EAC: 최종예상원가]
      │                           ┌──────┘ (CV = EV - AC < 0: 예산 초과)
      │                    ┌──────┘ [AC: 실제원가]
      │             ┌──────┘ [PV: 계획가치] (SV = EV - PV < 0: 일정 지연)
      │      ┌──────┘ [EV: 획득가치]
      │ ┌────┘
      └─┴─────────────────────────────────────────> [시간: 상태일(Status Date)]
```

- 본질: 프로젝트의 범위(WBS), 일정(Schedule), 원가(Cost)를 단일한 화폐가치 단위로 통합하여, 현재 시점의 계획가치(PV), 획득가치(EV), 실제원가(AC)를 비교함으로써 미래 완료 시점(EAC, ETC)을 과학적으로 예측하는 종합 성과관리 기법
- 위치: `프로젝트 기획 → WBS/일정/예산 통합 → PMB(성과측정기준선) → EVM 분석 → 시정조치/변경통제`
- 핵심 산식: `CV = EV - AC` (원가편차), `SV = EV - PV` (일정편차), `CPI = EV / AC` (원가효율), `SPI = EV / PV` (일정효율)
- 주의점: SPI는 프로젝트 후반부에 모든 작업이 완료되면 무조건 1.0으로 수렴하므로 주공정(Critical Path) 분석 병행 필수

## 예상문제

> 프로젝트 성과 통제를 위한 EVM(Earned Value Management)의 개념과 기본 매개변수(PV, EV, AC, BAC)를 설명하고, 편차(CV, SV)·효율(CPI, SPI) 지표 산식 및 4가지 완료 시점 추정(EAC) 모델과 실무 한계점을 논하시오. (25점)

## Ⅰ. 범위·일정·원가의 통합 관리, EVM 개요

- 정의: 계획된 작업의 예산(PV) 대비 실제로 완료된 작업의 가치(EV)와 실제 투입된 비용(AC)을 비교하여 프로젝트의 진척도와 원가 성과를 객관적으로 측정 및 예측하는 관리 기법
- 배경: 단순 투입 비용이나 일정 경과율만으로는 실제 작업의 완료량을 알 수 없어 프로젝트 후반부 대규모 납기 지연 및 예산 초과 초래
- 목적: 조기 경보(Early Warning) 체계 구축, 정량적 편차 식별, 미래 시점 최종 원가(EAC) 예측 및 선제적 시정조치

#### 한줄 요약
- 계획, 실적, 실제 비용을 획득가치(EV)라는 공통 잣대로 비교해 프로젝트 건강도를 진단하는 기법임

## Ⅱ. 4대 기본 매개변수와 성과측정기준선(PMB)

```text
[WBS (범위)] + [네트워크 다이어그램 (일정)] + [자원 단가 (원가)]
                              │ 통합 기준선 승인
                              ▼
           [성과측정기준선 (PMB: Performance Measurement Baseline)]
```

| 기본 변수 | 정식 명칭 | 개념 정의 | 핵심 질문 |
|---|---|---|---|
| **PV** | Planned Value (계획가치) | 특정 시점까지 완료하기로 계획된 작업에 배정된 승인 예산 | "지금까지 얼마의 가치를 창출하기로 계획했는가?" |
| **EV** | Earned Value (획득가치) | 특정 시점까지 실제로 완료된 작업에 책정되어 있던 예산 가치 | "실제 완료된 작업의 가치는 예산상 얼마인가?" |
| **AC** | Actual Cost (실제원가) | 특정 시점까지 완료된 작업을 수행하는 데 실제로 지출된 총원가 | "그 작업을 수행하는 데 실제로 돈을 얼마 썼는가?" |
| **BAC** | Budget at Completion | 프로젝트 전체 완료 시점까지 배정된 총 승인 예산 합계 | "프로젝트 전체 기준 예산은 얼마인가?" |

#### 한줄 요약
- PV는 계획, EV는 실제 완성된 가치, AC는 들어간 돈, BAC는 전체 예산 총액임

## Ⅲ. EVM 편차·효율 지표 및 예측 산식 체계

| 구분 | 지표명 | 계산 산식 | 판정 기준 및 해석 |
|---|---|---|---|
| **편차 지표** | 원가 편차 (CV) | `CV = EV - AC` | CV > 0: 예산 절감 / CV < 0: 예산 초과 |
| | 일정 편차 (SV) | `SV = EV - PV` | SV > 0: 일정 단축 / SV < 0: 일정 지연 |
| **효율 지표** | 원가 성과 지수 (CPI) | `CPI = EV / AC` | CPI > 1.0: 원가 효율 우수 / CPI < 1.0: 비효율 |
| | 일정 성과 지수 (SPI) | `SPI = EV / PV` | SPI > 1.0: 일정 진척 빠름 / SPI < 1.0: 지연 |
| **목표 지수** | 잔여 성과 지수 (TCPI) | `(BAC - EV) / (BAC - AC)` | 잔여 예산 내 달성해야 할 필수 원가 효율 지수 |

#### 완료 시점 추정치 (EAC: Estimate at Completion) 4대 모델

```text
1. 비정형 편차 (과거 오류 일회성): EAC = AC + (BAC - EV)
2. 현재 추세 지속 (현재 CPI 유지): EAC = BAC / CPI
3. 일정과 원가 동시 고려:         EAC = AC + [(BAC - EV) / (CPI × SPI)]
4. 새로운 기준 재추정:            EAC = AC + Bottom-up ETC
```

- 잔여 작업 추정치(ETC): `ETC = EAC - AC`
- 완료 시 편차(VAC): `VAC = BAC - EAC` (양수: 예산 절감 잔액, 음수: 예산 초과 결손액)

#### 한줄 요약
- 지수가 1보다 작거나 편차가 음수이면 위험 신호이며, 상황에 맞는 공식으로 최종 완료 비용을 예측함

## Ⅳ. 성과측정기준선 수립부터 통제까지의 5단계 프로세스

```text
① WBS 정의 및 작업패키지 분할 → ② 일정·자원 배정 및 PMB 승인 → ③ 상태일 실적 및 실제원가 집계 → ④ 지표 분석 및 미래 예측 → ⑤ 시정조치 및 변경통제
   └─ 100% Rule 준수             └─ S-Curve 기준선 확정       └─ 0/100, 50/50 규칙        └─ CV/SV/CPI/SPI/EAC        └─ 패스트트래킹/크래싱
```

| 단계 | 주요 수행 내용 | 핵심 통제 산출물 |
|---|---|---|
| **1. 범위 분할** | 프로젝트 전체를 측정 가능한 작업패키지(Work Package)로 계층 분할 | WBS, WBS 사전, 책임할당표(RACI) |
| **2. 기준선 수립** | WBS에 공기(Duration)와 예산을 결합하여 시간 단계별 예산(PV) 곡선 작성 | 성과측정기준선(PMB), S-Curve |
| **3. 가치 측정** | 획득가치 산정 규칙(0/100, 50/50, 마일스톤 가중치)에 따라 EV 및 실투입비(AC) 집계 | 진척 현황 보고서, 공인 비용 전표 |
| **4. 성과 분석** | 편차 분석 및 CPI/SPI 도출, 회귀 모델 기반 완료 예상 비용(EAC) 산출 | 성과 분석 보고서, 추세 차트 |
| **5. 피드백 조치** | 자원 재배치, 공정 압축(Crashing), 병렬 수행(Fast-tracking), 공식 변경 승인 | 시정조치 요구서, 변경통제 승인서 |

#### 한줄 요약
- 작업패키지 기반 기준선(PMB)을 세우고, 정량적 규칙으로 실적을 측정해 능동적 공정 압축을 수행함

## Ⅴ. 전통적 진척관리 vs 획득가치관리(EVM) 비교

| 비교 항목 | 전통적 진척관리 (Traditional) | 획득가치관리 (EVM) |
|---|---|---|
| **측정 대상** | 투입 비용(Spend) 및 경과 시간(Time) 단순 비교 | 계획 대비 완료된 작업의 객관적 가치(EV) 측정 |
| **관리 차원** | 일정 관리와 원가 관리가 분리되어 운영 | 범위(Scope), 일정(Time), 원가(Cost) 삼위일체 통합 |
| **대표적 왜곡** | 예산이 50% 소진되었으면 진척률도 50%라고 착각 | 예산이 50% 소진되었어도 완료 가치가 30%면 위기 감지 |
| **미래 예측력** | 주관적 경험 및 직관에 의존한 완료일 추정 | CPI/SPI 통계 지수를 활용한 수학적 완료 예측(EAC) |
| **필요 전제조건**| 단순 공수 투입 내역만으로 관리 가능 | 엄격한 WBS, 원가 집계 시스템, 승인된 PMB 필수 |

#### 한줄 요약
- 전통 방식이 '돈 쓴 양'을 진척으로 착각한다면, EVM은 '만들어낸 실제 가치'를 진척으로 평가함

## Ⅵ. 실무 EVM의 왜곡 요인과 공학적 통제 방안

- 적용 상황: 대규모 공공 SI 및 방위산업 소프트웨어 연구개발 사업의 성과 통제

| 왜곡 요인 | 발생 원인 | 공학적·관리적 해결 대책 | 기대 효과 |
|---|---|---|---|
| **SPI 수렴 왜곡** | 프로젝트 후반부 지연 작업도 완료되면 무조건 `SPI → 1.0` 수렴 | 주공정(Critical Path) 상의 작업만 별도로 분리 측정하는 ES(Earned Schedule) 기법 도입 | 프로젝트 후반부 일정 지연 착시 방지 |
| **주관적 완료율 조작** | 개발자의 자의적 추정치("90% 다 됐습니다") 보고 | 0/100 규칙(완전 완료 시만 인정), 50/50 규칙 또는 명확한 검수 산출물 연계 | 신뢰할 수 있는 객관적 EV 확보 |
| **실제원가(AC) 반영 지연** | 외주비, 장비 대금 정산이 익월 말 청구되어 AC 과소 집계 | 회계팀 발생주의(Accrual Accounting) 연계 및 실시간 공수 집계 도구 도입 | 왜곡 없는 실시간 CPI 지표 확보 |
| **간접 작업(LOE) 과다 계상** | PMO, 품질관리 등 산출물이 없는 지원 업무가 EV를 과다 견인 | LOE(Level of Effort) 작업을 전체 예산의 일정 비율 이하로 제한 분리 | 핵심 개발 기능의 실제 진척도 보존 |

#### 한줄 요약
- 어닝 스케줄(ES) 도입으로 SPI 왜곡을 막고, 0/100 규칙과 발생주의 회계로 지표의 신뢰성을 담보함

## Ⅶ. 조기 경보와 선제적 공정 통제 중심의 결론

- **[지표 계산을 넘어선 선제적 공정 통제]**: EVM은 단순 보고서 작성용 통계가 아니라, 15~20% 진척 시점에 조기 도출되는 CPI/SPI를 바탕으로 프로젝트의 최종 실패를 예방하는 강력한 의사결정 도구임
- 나라면: 프로젝트 헌장에 `상태일 기준 EV 산정 규칙(0/100 원칙) 명시 → CPI 0.85 이하 도달 시 Red 플래그 발령 및 범위 재조정 위원회 소집 → 주공정 전용 Earned Schedule 병행`을 의무화하여 납기 및 예산 리스크를 선제 차단

#### 한줄 요약
- 숫자를 계산하는 데 그치지 않고 CPI/SPI 경보에 즉각적인 공정 개입 조치를 취해야 EVM이 완성됨

## 1교시 10점 답안 발췌

### 1. EVM(Earned Value Management)의 정의
- 프로젝트의 범위(WBS), 일정(Schedule), 원가(Cost)를 통합하여 계획가치(PV), 획득가치(EV), 실제원가(AC)를 비교함으로써 현재 성과를 평가하고 미래 완료 시점(EAC)을 과학적으로 예측하는 종합 성과관리 기법

### 2. 핵심 지표 산식 및 S-Curve 아키텍처
```text
[비용/가치]                          [성과 산식 체계]
    ▲           ┌── AC (실제원가)     · 원가편차(CV) = EV - AC  (음수: 예산 초과)
    │     ┌─────┘                     · 일정편차(SV) = EV - PV  (음수: 일정 지연)
    │ ┌───┘ ─── PV (계획가치)          · 원가지수(CPI) = EV / AC (1.0 미만: 비효율)
    │ └─── EV (획득가치)               · 일정지수(SPI) = EV / PV (1.0 미만: 지연)
    └───────────────> [시간]         · 최종예상(EAC) = BAC / CPI (추세 지속 시)
```

| 지표 | 산식 | 의미 |
|---|---|---|
| CV, SV | `EV - AC`, `EV - PV` | 0보다 크면 유리(절감/단축), 0보다 작으면 불리(초과/지연) |
| CPI, SPI | `EV / AC`, `EV / PV` | 1.0보다 크면 효율 우수, 1.0보다 작으면 효율 저하 |
| EAC | `BAC / CPI` | 현재 원가 효율이 완료 시까지 지속될 때의 최종 예상 사업비 |

### 3. 차별화 제언
- 후반부로 갈수록 SPI가 1.0으로 수렴하는 왜곡을 극복하기 위해 시간 단위 일정 성과를 측정하는 어닝 스케줄(Earned Schedule: ES)을 병행하고, 발생주의 회계로 AC 지연을 방어해야 함
