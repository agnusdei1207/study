## 큰 그림과 30초 인출

- 본질: 프로젝트 범위·일정·원가를 단일 화폐가치로 통합하여, 현재 시점의 실질 진척도와 비용 효율성을 측정하고 최종 완료 원가(**EAC**)를 예측하는 종합 공정관리 기법.
- 메커니즘: PMB(기준선) 수립 → 3대 기본값(**PV**, **EV**, **AC**) 실측 → 4대 분석 지표(**CV**, **SV**, **CPI**, **SPI**) 계산 → 성과 추세 기반 **EAC** 미래 예측 및 공정 압축/변경 통제.
- 통제: 주관적 진척 배제(**0/100 규칙**) · 발생주의 실원가 적기 반영 · 후반부 SPI 왜곡 방지를 위한 **ES(Earned Schedule)** 기법 병행.

<details>
<summary>핵심 용어</summary>

- **EVM(Earned Value Management)**: 범위, 일정, 원가를 단일 화폐가치로 통합하여 진척 성과를 정량 진단하고 최종 원가를 예측하는 관리 기법
- **PMB(Performance Measurement Baseline)**: 승인된 범위, 일정, 원가를 결합하여 프로젝트 진척을 측정하는 시간 단계별 기준선(S-Curve)
- **PV(Planned Value)**: 특정 시점까지 완료하기로 승인된 작업에 배정된 예산(계획가치)
- **EV(Earned Value)**: 특정 시점까지 실제로 완료된 작업에 배정되어 있던 예산 가치(획득가치)
- **AC(Actual Cost)**: 특정 시점까지 작업을 수행하는 데 실제로 투입·지출된 총원가(실제원가)
- **BAC(Budget at Completion)**: 프로젝트 전체 작업 완료에 배정된 총 승인 예산 합계
- **CPI(Cost Performance Index)**: 원가 성과 지수(EV / AC)로 1.0 미만 시 예산 초과 상태를 식별
- **SPI(Schedule Performance Index)**: 일정 성과 지수(EV / PV)로 1.0 미만 시 공정 지연 상태를 식별
- **EAC(Estimate at Completion)**: 현재까지의 성과 추세를 반영하여 프로젝트 완료 시점에 소요될 총예상비용
- **ES(Earned Schedule)**: 프로젝트 후반부 지연 공정도 완료 시 SPI가 1.0으로 수렴하는 왜곡을 보정하기 위해 시간 축 단위로 일정을 측정하는 기법

</details>

## 예상문제

> EVM의 개념과 PV·EV·AC·BAC를 설명하고, CV·SV·CPI·SPI 산식과 EAC 예측모델 및 한계 대응방안을 제시하시오. **(미출제 예상·25점)**

## Ⅰ. 범위·일정·원가의 통합 관리, EVM의 개요

> EVM의 가치는 사후 정산이 아니라 상태일의 성과를 기준선과 비교하고 완료예상원가를 갱신하여 조기에 개입하는 데 있음.

- 정의: 계획된 작업의 예산(**PV**) 대비 실제 완료된 작업의 가치(**EV**)와 실제 지출 비용(**AC**)을 비교하여 프로젝트 성과를 정량 측정하고 미래를 예측하는 종합 관리 기법
- 목적: 일정 지연·예산 초과 조기 식별, 선제적 공정 통제

### 1. 편차 및 효율 지표 산식 체계

| 구분 | 지표명 | 계산 산식 | 판정 기준 및 실무 의미 |
|---|---|---|---|
| 편차 지표 | 원가 편차 (**CV**) | `CV = EV - AC` | CV > 0: 예산 절감 / CV < 0: 예산 초과 결손 |
| | 일정 편차 (**SV**) | `SV = EV - PV` | SV > 0: 공정 단축 / SV < 0: 공정 지연 |
| 효율 지표 | 원가 성과 지수 (**CPI**) | `CPI = EV / AC` | CPI > 1.0: 원가 효율 우수 / CPI < 1.0: 투입비 대비 가치 미달 |
| | 일정 성과 지수 (**SPI**) | `SPI = EV / PV` | SPI > 1.0: 진척 속도 빠름 / SPI < 1.0: 계획 대비 진척 지연 |
| 목표 지수 | 잔여 성과 지수 (**TCPI**) | `(BAC - EV) / (BAC - AC)` | BAC를 목표로 할 때 잔여 작업에 필요한 원가 효율 |

### 2. 완료 시점 총원가 추정치(EAC) 4대 모델

| 모델 유형 | 가정 조건 | 계산 산식 | 적용 상황 |
|---|---|---|---|
| 비정형 편차 모델 | 과거의 원가 편차는 일회성이며 향후 작업은 계획대로 진행 | `EAC = AC + (BAC - EV)` | 초기 일시적 장비 고장, 인입 지연 등 특수 원인 해소 시 |
| 현재 추세 지속 모델 | 현재까지 누적된 원가 효율(CPI)이 완료 시까지 계속 유지 | `EAC = BAC / CPI` | 생산성 저하, 인건비 상승 등 구조적 원인이 지속될 때 |
| 일정·원가 동시 고려 | 납기 준수가 필수적이며 일정 지연(SPI)이 원가(CPI)에 연쇄 영향 | `EAC = AC + [(BAC - EV) / (CPI × SPI)]` | 마감 기한 엄수 필요 사업, 공정 압축 비용 추가 발생 시 |
| 전면 재추정 모델 | 기존 기준선이 근본적으로 잘못되어 잔여 작업을 바텀업 재산정 | `EAC = AC + Bottom-up ETC` | 요구사항 대규모 변경, 전면 재설계 등 기존 예산 무효화 시 |

## Ⅳ. 전통적 진척관리 vs 획득가치관리(EVM) 비교

> 전통 방식이 '돈 쓴 양'을 진척으로 오판하는 반면, EVM은 '완성된 실질적 가치'를 진척으로 평가함.

| 비교 항목 | 전통적 진척관리 (Traditional) | 획득가치관리 (EVM) |
|---|---|---|
| 측정 대상 | 투입 비용(Spend) 및 경과 시간(Time) 단순 비교 | 계획 대비 완료된 작업의 객관적 승인 가치(**EV**) 측정 |
| 관리 차원 | 일정 관리와 원가 관리가 분리 운영 | 범위, 일정, 원가의 삼위일체 통합 관리 |
| 착시 현상 | 예산의 60%를 소진하면 진척도 60%라고 착각 | 예산 60% 소진 시 완료 가치가 40%면 즉각 위기 감지 |
| 미래 예측력 | 관리자의 직관 및 주관적 경험에 의존한 완료일 추정 | 통계적 CPI/SPI를 활용한 수학적 완료 비용(**EAC**) 예측 |
| 전제 조건 | 단순 투입 공수 내역만으로 관리 가능 | 엄격한 WBS 분할, 발생주의 원가 집계, 승인된 **PMB** 필수 |

## Ⅴ. 실무 EVM의 왜곡 요인과 공학적 통제 방안

> 후반부 SPI 왜곡과 주관적 진척율 조작을 차단하지 못하면 EVM 수치는 신뢰를 상실함.

| 위험 | 대책 | 효과 |
|---|---|---|
| **SPI 수렴 왜곡** | 시간 단위 공정을 측정하는 **ES(Earned Schedule)** 기법 병행 | 주공정(Critical Path) 일정 지연 착시 차단 |
| **주관적 진척 조작** | **0/100 규칙**, 50/50 규칙 및 검수 완료 산출물 기반 승인 | 승인된 작업 산출물 외 EV 인정 배제 |
| **실원가(AC) 지연** | 회계팀 **발생주의(Accrual Accounting)** 시스템 연동 | 실시간 집계 기반 신뢰성 있는 CPI 확보 |
| **간접 작업 과다 계상** | LOE 작업을 분리하고 전체 가치 배분 상한선 설정 | 핵심 엔지니어링 작업의 실제 진척 보존 |

## Ⅵ. 조기 경보와 공정 개입 중심의 기술사적 제언

> 숫자를 보고서에 기재하는 데 그치지 않고, CPI/SPI 임계치 초과 시 즉각 공정에 개입하는 거버넌스가 결합되어야 함.

### 학습자 통찰 메모 — 답안 밖

- `[핵심 통찰]` 지표가 나빠졌다는 사실보다 원가 편차가 일회성인지, 현재 효율이 계속될지에 따라 EAC 식과 조치가 달라진다는 판단이 중요함.
- `나라면` 상태일마다 EV 승인근거와 AC 반영시차를 먼저 검증한 뒤, 선택한 EAC 가정을 기록하고 주공정 일정은 Earned Schedule(ES)로 보완하여 주간 회의체에서 시정조치를 강제하겠음.

### 실전 답안용 기술사적 제언

- **판정 기준**: CPI < 0.9 또는 SPI < 0.9 진입 시 즉시 적색 경보(Red Alert) 발령 및 시정조치 대상 판정.
- **공학적 대안**: 정량적 EVM에 주공정 경로(Critical Path) 및 시간 기반 공정측정(**Earned Schedule**) 결합.
- **검증 절차**: 검수 완료 산출물 기준 0/100 규칙 적용 여부 및 회계 발생주의(Accrual) 실원가 반영 주기 검증.
- **기대 효과**: 사업 후반부 예산 소진 후 일정 지연 발견되는 '납기 절벽' 방지 및 과학적 완공 예측력 확보.

## 1교시 10점 답안 발췌

### 1. 정의·목적

- 정의: **EVM(Earned Value Management)**은 범위, 일정, 원가를 단일 화폐가치로 통합하여 계획가치(**PV**), 획득가치(**EV**), 실제원가(**AC**)를 비교하고 성과를 정량 분석하는 종합 공정관리 기법
- 목적: 일정 지연·예산 초과 조기 식별, 선제적 공정 통제

### 2. 구성체계 및 방법론

### 3. 핵심 통제

- **지표 산식**: `CV = EV - AC`, `SV = EV - PV`, `CPI = EV / AC`, `SPI = EV / PV`
- **한계 극복**: 후반부 SPI 왜곡 방지를 위해 **ES(Earned Schedule)**를 병행하고, **0/100 규칙**으로 주관적 진척 보고 차단
