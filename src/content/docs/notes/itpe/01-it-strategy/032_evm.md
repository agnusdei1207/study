## 지식 로드맵 내 현재 위치

```text
프로젝트 관리 → 성과·비용 통합통제 → EVM
```

## 토픽 큰 그림과 30초 인출
```text
[범위 WBS] + [일정] + [예산] → [성과측정기준선 PMB]
                                  ↓ 상태일
                            PV · EV · AC
                                  ↓
                         CV·SV / CPI·SPI / EAC
```
- **30초 인출**: EVM은 계획가치 PV, 획득가치 EV, 실제원가 AC로 범위·일정·원가를 같은 기준에서 측정하고 편차와 최종 전망을 조기에 통제하는 기법이다.

## 예상문제
> EVM의 개념, 핵심 지표와 수행 절차를 설명하고 지표 해석 시 유의사항을 제시하시오.

## Ⅰ. 개요 ─ 통합 성과관리
**EVM**은 승인된 범위·일정·예산 기준선과 실제 수행성과를 통합 비교하는 프로젝트 관리기법이다. 단순 진척률 보고를 넘어 원가·일정 편차와 완료 시 전망을 객관화한다.

## Ⅱ. 기준값 ─ PV·EV·AC
| 값 | 의미 | 질문 |
|---|---|---|
| PV | 상태일까지 계획한 업무의 예산가치 | 얼마를 달성할 계획이었나 |
| EV | 실제 완료한 업무의 예산가치 | 예산 기준으로 얼마를 달성했나 |
| AC | 완료 업무에 실제 든 원가 | 실제 얼마를 썼나 |
| BAC | 완료 시점 총 승인예산 | 전체 기준예산은 얼마인가 |

## Ⅲ. 지표 ─ 편차와 효율
| 지표 | 산식 | 해석 |
|---|---|---|
| CV | EV - AC | 양수이면 원가 측면 유리 |
| SV | EV - PV | 양수이면 일정 측면 유리 |
| CPI | EV / AC | 1보다 크면 원가 효율 유리 |
| SPI | EV / PV | 1보다 크면 일정 효율 유리 |

예측은 가정이 핵심이다. 현재 원가효율이 지속된다고 보면 `EAC = BAC / CPI`, `ETC = EAC - AC`, `VAC = BAC - EAC`로 볼 수 있다.

## Ⅳ. 절차 ─ 기준선에서 조치까지
```text
WBS·OBS → 책임계정 → 일정·예산 통합 → PMB 승인
       → 상태일 실적·원가 수집 → 편차·추세·EAC → 원인·조치·변경통제
```
작업특성에 맞는 성과측정기법을 정하고 기준선 변경은 승인된 변경절차로만 반영한다.

## Ⅴ. 비교 ─ 일반 진척관리와 EVM
| 구분 | 일반 진척관리 | EVM |
|---|---|---|
| 측정 | 완료율·투입비 중심 | 예산화된 완료가치 |
| 통합 | 일정·원가 분리 가능 | 범위·일정·원가 통합 |
| 전망 | 경험적 추정 | 지수와 가정 기반 EAC |
| 전제 | 단순 기준 | 안정된 WBS·기준선·실적 |

## Ⅵ. 검증 ─ 왜곡 방지
자의적 완료율, 잦은 기준선 재설정, 실제원가 지연, LOE 작업의 성과 과대표현을 통제한다. 원자료 마감, 작업패키지 완료기준, 편차 원인과 시정조치, 예측가정을 함께 검토한다.

## Ⅶ. 결론 ─ 숫자보다 기준선과 행동
EVM의 목적은 지표 산출이 아니라 조기경보를 책임 있는 조치로 연결하는 것이다. 일정 위험과 잔여업무를 함께 검토하고 승인 변경을 기준선에 추적 반영해야 한다.

## 1교시 10점 답안 발췌
```text
기준: PV 계획가치 / EV 획득가치 / AC 실제원가 / BAC 총예산
편차: CV=EV-AC, SV=EV-PV
효율: CPI=EV/AC, SPI=EV/PV
절차: WBS → PMB → 실적수집 → 편차·전망 → 조치·변경통제
```
