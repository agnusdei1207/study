## Ⅰ. EVM의 개요

- **개념** : 프로젝트의 계획된 일정과 예산, 실제 투입된 비용, 실제로 완료된 작업 가치를 종합적으로 비교하여 프로젝트의 현재 진척 상태를 측정하고 최종 비용과 완료 시점을 정량적으로 예측하는 획득가치관리(Earned Value Management) 기법.
- **배경 및 필요성** : 단순 비용 집행률이나 주관적 공정률만으로는 일정 지연과 예산 초과의 실질적 원인을 파악할 수 없는 한계를 극복하기 위해 객관적 통합 진도 관리 기준 필요.
- **주요 목적** : 일정 및 원가 성과의 통합 측정, 성과 지수(CPI/SPI) 기반의 조기 이상 감지, 최종 소요 비용(EAC)의 과학적 예측.

## Ⅱ. EVM의 3대 핵심 변수

| 핵심 변수 | 약어 | 영문 명칭 | 정의 및 의미 |
|---|---|---|---|
| 계획 가치 | PV | Planned Value | 특정 시점까지 수행하기로 계획된 작업의 예산 (과거 BCWS) |
| 획득 가치 | EV | Earned Value | 특정 시점까지 실제로 완료된 작업에 배정된 예산 가치 (과거 BCWP) |
| 실제 원가 | AC | Actual Cost | 특정 시점까지 완료된 작업을 수행하는 데 실제로 지출된 총비용 (과거 ACWP) |

## Ⅲ. EVM 편차, 성과지수 및 예측 산식

```text
[편차 분석]
- 비용 편차 (CV) = EV - AC  (CV > 0 예산 절감, CV < 0 예산 초과)
- 일정 편차 (SV) = EV - PV  (SV > 0 일정 단축, SV < 0 일정 지연)

[성과 지수]
- 비용 성과지수 (CPI) = EV / AC  (CPI > 1 원가 효율 우수, CPI < 1 원가 낭비)
- 일정 성과지수 (SPI) = EV / PV  (SPI > 1 일정 진행 빠름, SPI < 1 일정 지연)

[최종 예측]
- 최종 완료비용 예측치 (EAC) = BAC / CPI  (현재의 원가 추세가 지속될 경우)
- 완공잔여 성과지수 (TCPI) = (BAC - EV) / (BAC - AC)
```

## Ⅳ. 실무 EVM 적용을 위한 기술사적 제언

- **작업 완료 기준의 객관화 (0/100, 50/50 규칙 등)** : 작업 패키지의 공정률을 담당자의 주관적 추정이 아닌, 마일스톤 산출물 검수 완료 여부로 측정하여 EV 왜곡 차단.
- **일정 성과지수(SPI)의 후반부 왜곡 보완** : 프로젝트 종료 시점이 다가올수록 결국 모든 작업이 완료되어 SPI가 1.0에 수렴하는 한계를 극복하기 위해 시간 단위 일정 관리 기법인 ES(Earned Schedule) 기법 병행.
- **EVM 분석 결과의 거버넌스 연계** : CPI 또는 SPI가 허용 임계치(예: 0.85 이하)를 이탈할 경우 즉각적인 시정 조치(Corrective Action) 및 경영진 보고가 이루어지는 조기 경보 체계 수립.
