## 연관 키워드

- EVM, Earned Value Management, 획득가치관리
- PV, EV, AC, CV, SV, CPI, SPI, EAC, TCPI
- BAC, 베이스라인, 일정/원가 성과, ES(Earned Schedule)

## Ⅰ. EVM의 개요

- 핵심 요약 : 계획 가치, 획득 가치, 실제 원가를 비교해 진척을 측정하고 최종 비용과 완료 시점을 예측하는 기법.
- 개념 : 계획 일정과 예산, 실제 투입 비용, 완료된 작업의 가치를 함께 비교하여 진척을 측정하고 완공 비용을 예측하는 **획득가치관리** (EVM, Earned Value Management) 기법.
- 배경 및 필요성 : 집행률이나 주관적 공정률만으로는 일정 지연과 예산 초과의 원인이 늦게 드러나므로, 일정과 원가를 같은 기준으로 측정하는 객관적 통합 진도 관리 체계가 필요함.
- 주요 목적 : 일정/원가 성과의 통합 측정, 성과지수(CPI, Cost Performance Index / SPI, Schedule Performance Index)를 통한 조기 이상 감지, 최종 소요 비용(EAC, Estimate at Completion) 예측.
- 핵심 변수 : 계획 가치(PV, Planned Value), 획득 가치(EV, Earned Value), 실제 원가(AC, Actual Cost)의 세 값을 기준으로 삼음.

## Ⅱ. EVM의 특징 및 장점

- 핵심 요약 : PV, EV, AC를 함께 측정해 일정과 원가 편차를 조기에 파악하고 완공 비용을 예측함.

1. **PV·EV·AC 통합 측정** : 계획, 실적, 지출을 같은 시점에 비교 → 집행률에 가려진 진도 지연을 드러냄.
2. 편차 분석 : 비용 편차(CV, Cost Variance)와 일정 편차(SV, Schedule Variance)로 원가 초과와 일정 지연을 식별 → 시정 대상을 조기에 고름.
3. **성과지수** : CPI, SPI를 비율로 비교 → 프로젝트 간 효율과 개선 우선순위 판단.
4. 완공 예측 : EAC와 완공잔여성과지수(TCPI, To-Complete Performance Index)로 완공 비용과 남은 작업의 요구 효율을 계산 → 시정 가능성 검토.
5. **베이스라인 통제** : 승인된 범위 변경만 계획 가치에 반영 → 지표의 비교 가능성 유지.

## Ⅲ. EVM의 구조 (흐름)

- 핵심 요약 : PV·EV·AC 3대 변수에서 편차와 지수를 산출하고 총예산(BAC, Budget at Completion) 기준으로 최종 비용을 예측하는 산식 체계.

```text
[편차 분석]

비용 편차 CV = EV - AC
   CV > 0 예산 절감, CV < 0 예산 초과
일정 편차 SV = EV - PV
   SV > 0 일정 단축, SV < 0 일정 지연
```

```text
[성과지수와 예측]

비용 성과지수 CPI = EV / AC
   CPI > 1 원가 효율 우수
일정 성과지수 SPI = EV / PV
   SPI > 1 일정 진행 빠름
완공 비용 EAC = BAC / CPI
   현재 원가 추세가 지속될 때
완공잔여성과지수 TCPI = (BAC-EV)/(BAC-AC)
```

```text
[EVM 관리 흐름]

베이스라인(PV) 설정
        ↓
작업 수행 → EV 산출, AC 집계
        ↓
CV, SV, CPI, SPI 계산
        ↓
EAC, TCPI 예측
        ↓
임계치 이탈 시 시정 조치
```

## Ⅳ. EVM과 전통적 진도 관리의 비교

- 핵심 요약 : EVM은 일정과 원가를 통합 측정하고 예측하며, 전통 방식은 비용 집행률과 주관적 공정률에 기댐.

| 비교 항목 | EVM (Earned Value Management) | 전통적 진도 관리 |
| --- | --- | --- |
| 측정 기준 | PV·EV·AC 통합 비교 | 비용 집행률, 주관적 공정률 |
| 일정 반영 | SV, SPI로 일정 성과를 정량화 | 일정과 비용을 분리하여 관리 |
| 예측 기능 | EAC, TCPI 기반 최종 비용과 시점 예측 | 사후 집계 중심, 예측 제한 |
| 이상 감지 | CPI, SPI 임계치 기반 조기 경보 | 문제 발생 후 인지 |
| 적용 난이도 | 베이스라인과 작업분류체계(WBS, Work Breakdown Structure) 필요 | 상대적으로 간단 |

- 선택 기준 : 일정과 원가를 함께 예측해야 하고 베이스라인을 세울 수 있는 프로젝트에는 EVM을, 소규모 단순 작업에는 전통 방식을 적용함.

## Ⅴ. EVM 관리의 한계와 방안

- 핵심 요약 : SPI 후반 왜곡, EV 과대 계상, 베이스라인 불일치를 시간 기준 지표, 검수 기준, 통합 변경 통제로 보완함.

| 한계 | 원인·영향 | 대응 방안 |
| --- | --- | --- |
| SPI 후반 왜곡 | 종료에 가까워지면 지연된 프로젝트도 SPI가 1로 수렴해 지연이 가려짐 | 시간 단위 획득 일정(ES, Earned Schedule)과 SPI(t)를 병행 |
| EV 과대 계상 | 산출물 검수 없이 공정률만 인정하면 결함이 있는 작업도 완료로 계산됨 | 인수 기준과 마일스톤 검수를 EV 인정 조건으로 두고 0/100 규칙 적용 |
| 베이스라인 불일치 | 승인된 변경이 PV에 반영되지 않아 CV, SV와 EAC가 왜곡됨 | 통합 변경 통제로 승인 이력과 예산, 일정을 함께 갱신 |

## Ⅵ. 실무 EVM 적용을 위한 기술사적 제언

- 핵심 요약 : 측정 기준의 조직 표준화, 시간 기반 일정 지표의 공식 채택, 임계치 기반 보고 체계로 EVM의 실효성을 확보.

1. 측정 기준의 표준화 : 공정률 산정 규칙을 조직 표준으로 정하고, 프로젝트 관리 사무국(PMO, Project Management Office)이 검수 기록을 주기적으로 점검하도록 설계하는 것이 바람직하다.
2. 시간 기반 일정 지표의 공식 채택 : 종료 시점에 가까워질수록 SPI가 한계를 드러내므로, ES를 일정 관리의 공식 지표에 포함시키고 완료 예상 시점을 경영 보고에 함께 올리는 방향이 필요하다.
3. 거버넌스 연계 조기 경보 : CPI와 SPI가 조직이 정한 임계치를 벗어나면 시정 조치와 경영진 보고가 이어지도록 보고 체계와 연결해야 한다.

## Ⅶ. 결론

- 핵심 요약 : EVM은 PV·EV·AC의 통합 측정과 EAC 예측으로 일정과 원가를 함께 관리하는 기법.
- 시사점 : 진척 측정의 객관화, 시간 기반 지표 병행, 통합 변경 통제가 뒷받침될 때 지표 왜곡 없이 의사결정이 가능함.
