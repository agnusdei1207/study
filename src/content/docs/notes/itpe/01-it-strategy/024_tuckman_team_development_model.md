## 연관 키워드

- 터크만 팀 발달 모델, 형성(Forming), 격동(Storming), 규범화(Norming)
- 수행(Performing), 해체(Adjourning), 리더십 전환, 팀 유효성

## Ⅰ. 터크만 팀 발달 모델의 개요

- 핵심 요약 : 팀이 시간에 따라 다섯 단계를 거치며 성숙해 간다는 과정 중심의 설명 모델.
- 개념 : **터크만 팀 발달 모델** (Tuckman's stages of group development)은 팀이 **형성** (Forming, 목표·역할이 정리되지 않은 출발 단계)→**격동** (Storming, 역할·방식 충돌 단계)→**규범화** (Norming, 공동 규범 정착 단계)→**수행** (Performing, 자율적 성과 창출 단계)의 단계를 거친다고 본 터크만(1965)의 모델에 **해체** (Adjourning, 과업 종료 후 해산 단계)를 추가(1977)한 팀 발달 단계 체계.
- 배경 및 필요성 : 신규 팀은 목표·역할·관계가 정립되지 않은 상태로 출발하여 초기 성과 편차와 갈등 관리 문제가 반복.
- 주요 목적 : 팀의 발달 단계 이해를 바탕으로 단계에 맞는 리더십·지원 제공과 성과 도달 시점의 앞당김.

## Ⅱ. 터크만 팀 발달 모델의 특징 및 장점

- 핵심 요약 : 다섯 단계의 변화 양상과 단계별 개입이 협업 역량과 성과로 연결되는 구조.

1. 형성(Forming) : 목표·역할이 모호하고 예의·의존이 중심 → 리더의 방향 제시로 구성원의 불안 감소.
2. 격동(Storming) : 역할·방식·권한을 둘러싼 충돌 발생 → 과업 갈등의 규칙화로 신뢰 기반 마련.
3. 규범화(Norming) : 공동 규범·응집력 형성 → 의사결정·협업 방식의 정착.
4. 수행(Performing) : 자율적 문제해결과 역할 유연성 확보 → 리더의 위임으로 성과 극대화.
5. 해체(Adjourning) : 과업 종료 후 해산 → 회고를 통한 학습 환류.

## Ⅲ. 터크만 팀 발달 모델의 구조 (흐름)

- 핵심 요약 : 형성부터 해체까지의 단계 진행과 단계별 리더십 전환이 모델의 구조.

```text
형성 (Forming)
   ↓
격동 (Storming)
   ↓
규범화 (Norming)
   ↓
수행 (Performing)
   ↓
해체 (Adjourning)
```

- 리더십 전환 : 단계가 진행될수록 통제를 낮추고 자율을 높이는 개입 방식의 전환이 필요.

```text
형성 : 지시형 리더십
   ↓
격동 : 코칭형 리더십
   ↓
규범화 : 지원형 리더십
   ↓
수행 : 위임형 리더십
```

- 적용 유의점 : 실제 팀은 단계를 되돌아가거나 겹칠 수 있어 선형 진행 가정의 완화 필요.

## Ⅳ. 터크만 발달 단계 모델과 팀 유효성 모델의 비교

- 핵심 요약 : 터크만 모델은 시간에 따른 과정 변화를 설명하고, 팀 유효성 모델은 성과를 만드는 성립 조건을 설명.

| 비교 축 | 터크만 발달 단계 모델 | 팀 유효성 모델(핵맨) |
| --- | --- | --- |
| 접근 관점 | 시간 흐름에 따른 과정 변화 | 팀 성과의 성립 조건 |
| 설명 단위 | 발달 단계(형성~해체) | 실재하는 팀·방향·구조·맥락·코칭 |
| 활용 방식 | 현재 단계 진단 → 개입 방식 선택 | 조건 충족 여부 점검 → 설계 개선 |
| 강점 | 팀 변화 이해·리더십 전환 안내 | 팀 설계·개선의 점검 기준 제공 |
| 한계 | 선형 진행 가정·단계 고정관념 위험 | 갈등 등 동적 과정 설명 약함 |

## Ⅴ. 터크만 팀 발달 모델의 한계와 방안

- 핵심 요약 : 단계 고정관념, 갈등 억압, 리더십 불일치, 구조 문제 간과를 관찰 기반 개입으로 일대일 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 단계 고정관념 | 선형·동일 속도 가정 → 잘못된 개입 | 팀 상태 관찰 기반의 유연 적용 | 회고·팀 설문 |
| 갈등 억압 | 격동 단계의 충돌 회피 → 신뢰·몰입 저하 | 과업 갈등의 대화·규칙화 | 미해결 갈등 수 |
| 리더십 불일치 | 단계에 맞지 않는 통제·방임 → 자율성 저하 | 지시→위임의 점진적 전환 | 의사결정 지연 |
| 구조 문제 간과 | 단계만 믿고 설계 결함 방치 → 성과 정체 | 유효성 조건(방향·구조)의 병행 점검 | 역할 명확성·이탈률 |

## Ⅵ. 터크만 팀 발달 모델에 대한 제언

- 핵심 요약 : 관찰 루틴, 사업 설계, 리더 교육으로 단계 모델을 실무 역량으로 내재화하는 상위 수준의 제안.

1. 팀 리더 : 역할 명확성·심리적 안전성·자율성 신호 관찰을 팀 회고 루틴에 포함하고 개입 수위 조정.
2. 프로젝트 관리자 : 팀 구성·해체가 반복되는 사업 환경에서 발달 단계를 고려한 일정·역할 설계 기준 마련.
3. 조직 교육 주체 : 리더 대상 단계별 리더십과 팀 유효성 조건 교육으로 진단 역량 내재화.

## Ⅶ. 결론

- 핵심 요약 : 터크만 팀 발달 모델은 팀 변화를 읽는 설명 모델이며 성숙도를 단정하는 척도가 아님.
- 단계 이해와 성립 조건 설계가 함께 갖춰질 때 팀 성과 도달 시점의 앞당김 가능.
