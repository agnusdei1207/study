## 연관 키워드

- 가치사슬(Value Chain), 본원활동, 지원활동, 마이클 포터(Michael Porter)
- 비용동인, 차별화, 가치체계, 경쟁자 분석

## Ⅰ. 가치사슬의 개요

- 핵심 요약 : 고객가치를 만드는 기업 활동을 본원·지원 활동으로 분해해 비용과 차별화의 원천을 진단하는 전략 분석 틀.
- 개념 : 경쟁전략 학자 마이클 포터(Michael Porter)가 제시한 **가치사슬**(Value Chain) 분석은 기업 활동을 고객가치 창출 순서에 따라 **본원활동**(primary activities, 입고물류·생산·출고물류·마케팅·판매·서비스)과 **지원활동**(support activities, 기업 인프라·인적자원관리·기술개발·조달)으로 분해하는 틀.
- 배경 및 필요성 : 경쟁우위가 산업 전체가 아닌 개별 기업의 활동과 그 연계에서 발생하고, 부서 단위 관리로는 활동별 비용 원인과 가치 기여의 파악이 곤란.
- 주요 목적 : 활동별 비용 구조와 고객가치 기여의 진단을 통한 원가우위·고유가치 전략의 설계와 지속 경쟁우위 확보.

## Ⅱ. 가치사슬의 특징 및 장점

- 핵심 요약 : 활동 단위 분해·연계 분석·동인 식별·가치체계 확장이 경쟁우위 원천의 가시화로 이어짐.

1. 활동 단위 분해 : 기업을 활동의 집합으로 보고 각 활동의 투입·산출·비용 분석 → 경쟁우위 발생 지점의 특정.
2. 연계 분석 : 활동 간 링크(조달 품질이 서비스 비용에 미치는 영향 등)의 진단 → 부서별 최적화를 넘는 전체 가치 개선.
3. 비용동인 식별 : **비용동인**(cost driver, 활동 비용을 좌우하는 구조적 요인)의 규명 → 원가우위 전략의 근거 확보.
4. 차별화 지점 진단 : 고객이 가치를 인식하는 활동과 고유성 원천의 분석 → **차별화**(경쟁자와 구별되는 고객가치의 창출) 전략의 집중 지점 도출.
5. 가치체계 확장 : **가치체계**(value system, 공급자·기업·채널·구매자 가치사슬의 연결 전체) 관점 도입 → 산업 내 위치·협력 전략의 판단 근거.

## Ⅲ. 가치사슬의 구조 (흐름)

- 핵심 요약 : 지원활동이 본원활동 전반에 공통 기반을 제공하고, 본원활동의 연결이 이윤을 산출하는 구조.

지원활동은 정책·인력·기술·구매의 공통 기반을 본원활동 전반에 제공하고, 이윤은 전 활동이 만든 고객가치에서 총비용을 뺀 차액.

```text
[ 가치사슬 구조 ]

지원활동
  기업 인프라 · 인적자원관리
  기술개발 · 조달
-------------------------
본원활동
  입고물류 → 생산 → 출고물류
  → 마케팅·판매 → 서비스
   ↓
이윤 = 고객가치 - 총비용
```

```text
[ 가치사슬 분석 절차 ]

활동 분해 (본원·지원)
   ↓
활동별 비용·가치 기여 평가
   ↓
비용동인·차별화 요인 진단
   ↓
연계 개선·전략 선택
```

## Ⅳ. 가치사슬 분석과 경쟁자 분석의 비교

- 핵심 요약 : 가치사슬 분석이 자사 활동 내부의 가치·비용 원천 진단인 반면, 경쟁자 분석은 외부 경쟁기업의 전략·역량·행동 평가.

**경쟁자 분석**(competitor analysis, 경쟁기업의 목표·가정·전략·역량을 평가하는 분석)은 외부 대응 판단의 도구.

| 비교 축 | 가치사슬 분석 | 경쟁자 분석 |
| --- | --- | --- |
| 분석 대상 | 자사 활동과 그 연계 | 경쟁기업의 전략·역량·행동 |
| 분석 관점 | 내부 활동 기반의 원천 진단 | 외부 대비 상대적 위치 평가 |
| 산출물 | 비용동인·차별화 지점·개선 과제 | 위협·기회 판단과 대응 시나리오 |
| 전략 연계 | 원가우위·차별화 전략 설계 | 공격·방어·벤치마킹 판단 |

두 분석은 상호 보완 관계로, 경쟁기업의 활동을 같은 틀로 분해하면 활동별 비교가 가능.

## Ⅴ. 가치사슬의 한계와 방안

- 핵심 요약 : 비용 배분의 주관성·정태 분석의 한계·외부 연결 누락을 배부 기준 문서화·정기 재작성·분석 범위 확장으로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 비용 배분의 주관성 | 공통 비용 귀속의 판단 차이 → 활동별 수익성 왜곡 | 활동 기준 원가 자료·배부 기준 문서화 | 배부 기준 갱신 주기 |
| 정태 분석 한계 | 산업·기술 변화의 미반영 → 구식 전략 근거 | 시장 변화에 따른 가치사슬 재작성 | 분석 갱신 주기 |
| 외부 연결 누락 | 플랫폼·파트너 가치 흐름의 미반영 → 기회·위협 상실 | 가치체계 확장 분석·파트너 데이터 반영 | 파트너 기여 비중 |

## Ⅵ. 가치사슬에 대한 기술사적 제언

- 핵심 요약 : 전략 조직이 활동별 데이터 측정 체계를 갖추고 디지털 연계까지 분석 범위를 확장 필요.
- 조직 : 전략 조직이 활동별 비용·가치 지표를 정의하고 재무·운영 데이터와 연결.
- 기술 : 운영 시스템 데이터의 활동 단위 태깅으로 정성 분석의 근거 보강.
- 확산 : 파트너·플랫폼 간 데이터·수익 배분 구조를 분석 대상에 포함하는 분석 지침 정비.

## Ⅶ. 결론

- 핵심 요약 : 가치사슬은 고객가치 창출 활동의 분해·연결을 통해 경쟁우위 원천을 찾는 전략 분석 틀.
- 내부 활동 진단과 외부 가치체계 시야의 병행이 전략 판단의 완성도를 높임.
