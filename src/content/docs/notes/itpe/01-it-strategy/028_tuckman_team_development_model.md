## 해당 토픽 큰 그림과 30초 인출

```text
Forming → Storming → Norming → Performing → Adjourning
 방향제시    갈등표면화    규칙·신뢰      자율성과       종료·교훈
```

- 인출어: `형-폭-규-성-해`, `갈등은 관리대상`, `단계는 비선형`, `리더행동은 상황별 조정`

## 예상문제

> 터크만 팀 발달 모델의 5단계별 특징과 프로젝트 관리자의 대응을 설명하고, 인력변경·원격협업 환경의 적용방안을 제시하시오. (25점)

## 딸려 나오는 하위 토픽

## Ⅰ. 팀의 상호작용 변화를 설명하는 발달모델 개요

**터크만 팀 발달 모델**은 팀이 구성된 뒤 관계와 과업 수행방식이 형성기, 폭풍기, 규범기, 성과기, 해산기를 거치며 변화한다고 설명하는 모델이다. 단계는 진단 틀이지 모든 팀이 같은 속도와 순서로 이동한다는 법칙은 아니며, 인력·목표 변화로 이전 단계의 행동이 다시 나타날 수 있다.

## Ⅱ. 적용원칙

| 원칙 | 설명 |
|---|---|
| 관찰 기반 진단 | 단계 이름보다 실제 행동·갈등·성과를 관찰 |
| 갈등 정상화 | 과업갈등은 표면화하되 인신공격은 차단 |
| 단계별 개입 | 방향·규칙·지원·위임의 강도를 상황에 맞게 조절 |
| 심리적 안전 | 질문·실수·이견을 말할 수 있는 환경 조성 |
| 비선형성 | 구성·목표·환경 변화 시 재진단·온보딩 |

## Ⅲ. 5단계 발달구조

```text
[형성기] → [폭풍기] → [규범기] → [성과기] → [해산기]
 탐색·의존    역할·관점 충돌   규칙·신뢰 합의   자율·상호보완    종료·전환
```

| 단계 | 팀 행동 | 관리 초점 | 확인 산출물 |
|---|---|---|---|
| 형성기 | 목적·관계·역할 탐색 | 목표·역할·경계 명료화 | 팀 헌장·RACI |
| 폭풍기 | 우선순위·방식·권한 갈등 | 갈등 가시화·중재·결정규칙 | 이슈·결정기록 |
| 규범기 | 신뢰·규칙·협업방식 합의 | 작업협약·피드백 정착 | Working Agreement |
| 성과기 | 자율실행·상호지원 | 위임·장애제거·성과집중 | 성과·개선 백로그 |
| 해산기 | 인수인계·관계종료 | 성과인정·교훈·지식전환 | 회고·인수인계서 |

## Ⅳ. 진단에서 조직학습까지의 적용절차

```text
행동 관찰 → 단계·원인 진단 → 개입 선택 → 팀 합의·실행 → 효과 확인·재진단
```

1. 참여·갈등·의사결정·약속이행·성과 흐름을 관찰한다.
2. 단계뿐 아니라 목표 불명확, 역할중복, 기술의존성 등 원인을 찾는다.
3. 목표·RACI, 갈등중재, 작업협약, 위임 등 최소 개입을 선택한다.
4. 팀이 규칙과 결정방식을 공동 합의하고 실제 업무에 적용한다.
5. 팀 건강도와 납기·품질·협업지표를 함께 보고 개입을 조정한다.
6. 인력변경·종료 시 온보딩, 지식이전, 회고로 조직학습을 남긴다.

## Ⅴ. 단계별 리더 행동 비교

| 단계 | 우선 행동 | 피해야 할 행동 |
|---|---|---|
| 형성기 | 목적·역할·우선순위 명료화 | 정보 없이 자율만 요구 |
| 폭풍기 | 경청·사실분리·결정규칙 적용 | 갈등 억압·편들기 |
| 규범기 | 팀 합의와 상호피드백 지원 | 규칙을 관리자 단독 결정 |
| 성과기 | 권한위임·외부장애 제거 | 세부업무 과잉통제 |
| 해산기 | 인정·인수인계·교훈 확산 | 성과·감정·지식 방치 |

> 단계와 특정 리더십 유형을 기계적으로 일대일 대응하지 말고 팀 역량·의지·위험을 함께 판단한다.

## Ⅵ. 프로젝트 환경별 위험과 대응

| 위험 | 대응 | 검증지표 |
|---|---|---|
| 폭풍기 갈등 고착 | 쟁점·관계 분리, 중재, 의사결정권 명시 | 미해결 갈등·결정시간 |
| 신규인력 유입 | 버디·온보딩·팀 헌장 재확인 | 적응기간·재작업 |
| 원격·하이브리드 | 응답·회의·문서·에스컬레이션 규칙 | 참여편차·대기시간 |
| 형식적 규범 | 회고에서 규칙 효과 검토·개정 | 합의 준수·개선완료 |
| 조기 해산·교체 | 핵심지식 페어링·인수인계·접근권 회수 | 지식공백·미인계 항목 |

## Ⅶ. 단계 이름보다 관찰과 적응이 중요한 결론

터크만 모델은 갈등을 실패로 낙인찍는 도구가 아니라 팀의 현재 행동에 맞는 개입을 선택하는 공통언어다. **목표·역할 명확화, 안전한 갈등, 공동규범, 단계적 위임, 종료학습**을 통해 팀이 자율성과 성과를 함께 높이도록 돕는다.

## 1교시 10점 답안 발췌

```text
정의: 팀 상호작용이 형성-폭풍-규범-성과-해산으로 변화하는 발달모델
형성: 목표·역할 탐색 / 폭풍: 권한·방식 갈등 / 규범: 규칙·신뢰 합의
성과: 자율·상호보완 / 해산: 인정·인계·교훈
관리: 방향제시 → 갈등중재 → 합의지원 → 위임·장애제거 → 조직학습
주의: 단계는 진단 틀이며 인력·목표 변화 시 비선형·퇴행 가능
```
