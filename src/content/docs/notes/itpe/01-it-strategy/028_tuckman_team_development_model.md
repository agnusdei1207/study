## 연관 키워드

- 터크만 팀 발달 모델, Forming, Storming, Norming, Performing, Adjourning
- 팀 성숙도, 상황적 리더십, 지시형, 코칭형, 지원형, 위임형
- PM, 프로젝트 팀, 회고, 팀 헌장

## Ⅰ. 터크만 팀 발달 모델의 개요

- 핵심 요약 : 프로젝트 팀의 대인관계와 성과 변화를 5단계로 나눈 팀 발달 모델.
- 개념 : 프로젝트 팀이 구성되어 해체될 때까지 겪는 대인관계와 업무 성과의 변화를 형성기, 격동기, 규범기, 성취기, 해체기의 5단계로 설명하는 **터크만 팀 발달 모델** (Tuckman Team Development Model).
- 배경 및 필요성 : 다양한 이해관계자와 서로 다른 조직 문화에서 모인 인력 사이에는 갈등이 필연적으로 생기므로, PM(Project Manager)은 팀 성숙도에 맞는 리더십을 써서 고성과 팀을 빨리 만들 필요가 있음.
- 주요 목적 : 팀의 성장 단계 식별, 단계별 리더십 전환, 팀 내 갈등의 생산적 해결, 프로젝트 성과 향상.

## Ⅱ. 터크만 팀 발달 모델의 특징 및 장점

- 핵심 요약 : 팀의 관계와 성과 상태를 읽어 단계에 맞는 개입을 선택하는 진단형 모델.

1. 발달 단계 진단 : 팀의 관계와 성과 상태를 살펴 지금 필요한 지원을 구분함 → 개입 시점의 오차 감소.
2. 형성기 역할 명확화 : **팀 헌장** (Team Charter)과 역할 책임을 정함 → 초기 불확실성 감소.
3. 격동기 갈등 관리 : 이견을 공개적으로 조정함 → 규범 형성의 계기로 전환.
4. 규범·성취기 위임 : 합의된 작업 방식을 바탕으로 팀의 자율성을 높임 → 생산성 향상.
5. 해체기 회고 : 성과와 교훈을 기록함 → 다음 프로젝트의 학습 자산 확보.

## Ⅲ. 터크만 팀 발달 모델의 구조 (흐름)

- 핵심 요약 : 형성기에서 해체기까지의 5단계 흐름과, 단계가 바뀌며 리더의 개입 수준이 줄어드는 구조.
- 5단계는 **Forming** (형성기), **Storming** (격동기), **Norming** (규범기), **Performing** (성취기), **Adjourning** (해체기)으로 이어진다.

```text
[5단계 발달 흐름]
Forming (형성기)
   탐색과 불안감
        ↓
Storming (격동기)
   갈등과 권력 다툼
        ↓
Norming (규범기)
   협력과 규칙 정립
        ↓
Performing (성취기)
   자율적 고성과
        ↓
Adjourning (해체기)
   프로젝트 종료와 평가
```

```text
[리더십 개입 수준 변화]
지시형 → 코칭형 → 지원형 → 위임형
        ↓
팀 자율성 증가, 리더 개입 감소
```

| 발달 단계 | 팀원의 특성 | 핵심 관리 과제 | 적합한 리더십 |
| --- | --- | --- | --- |
| 형성기 (Forming) | 탐색적이고 조심스러움, 목표가 모호함 | 팀 헌장 수립, 역할과 책임(R&R, Roles and Responsibilities) 정의 | 지시형 (Directing) |
| 격동기 (Storming) | 성격과 작업 방식의 차이에 따른 갈등과 저항 | 갈등 조정, 의사소통 채널 개방, 신뢰 형성 | 코칭형 (Coaching) |
| 규범기 (Norming) | 상호 존중과 협력적 분위기, 작업 표준 공유 | 팀워크 강화, 모범 사례 정착 | 지원형 (Supporting) |
| 성취기 (Performing) | 자율적 문제 해결과 높은 시너지 | 권한 위임, 병목 제거 | 위임형 (Delegating) |
| 해체기 (Adjourning) | 작업 완료, 성취감과 아쉬움 | 성과 공유, 교훈(Lessons Learned) 정리 | 인정과 격려 |

## Ⅳ. 터크만 모델과 상황적 리더십의 비교

- 핵심 요약 : 터크만 모델은 팀 전체의 발달 단계를, 상황적 리더십은 팀원 개인의 역량과 의지에 따른 리더 스타일 전환을 설명함.

| 비교 항목 | 터크만 팀 발달 모델 | 상황적 리더십 (Hersey-Blanchard) |
| --- | --- | --- |
| 분석 단위 | 팀 전체의 발달 단계 | 팀원 개인의 역량(Competence)과 의지(Commitment) |
| 초점 | 대인관계와 업무 성과의 변화 | 리더의 지시와 지원 수준 조정 |
| 단계 또는 유형 | 형성기, 격동기, 규범기, 성취기, 해체기 | 지시형, 코칭형, 지원형, 위임형 |
| 연계 지점 | 형성기는 지시형, 격동기는 코칭형, 규범기는 지원형, 성취기는 위임형에 대응 | 역량과 의지에 따라 스타일을 전환 |

- 두 모델은 서로 다른 단위를 설명하지만, 팀 상태에 따라 리더의 개입을 줄여 간다는 점에서 함께 쓸 수 있음.

## Ⅴ. 터크만 팀 발달 모델의 한계와 방안

- 핵심 요약 : 팀의 발달이 단선적이지 않고, 원격 협업과 리더 고정 문제가 있어 지속적인 상태 진단으로 보완해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 비선형적 발달 | 팀원 교체나 요구 변경으로 격동기에 다시 들어갈 수 있음 | 회고와 온보딩을 통해 팀 상태를 주기적으로 다시 진단 | 팀 상태 진단 주기 |
| 원격 갈등 신호 누락 | 원격 협업에서는 갈등 신호를 놓치기 쉬움 | 의사결정 기록과 정기 대화로 오해를 조기에 확인 | 회고 참여율, 갈등 해결 건수 |
| 리더 방식 고정 | 리더가 한 방식만 고수하면 팀의 자율성이 떨어짐 | 팀 상태에 맞춰 지시, 코칭, 지원, 위임 수준을 조정 | 리더십 스타일 전환 빈도 |

## Ⅵ. 성공적인 프로젝트 팀 관리를 위한 기술사적 제언

- 핵심 요약 : 격동기를 억누르지 않고 통과시키는 것, 형성기에 팀 헌장을 세우는 것, 서번트 리더십을 실천하는 것.

격동기는 피할 수 없는 단계이므로 갈등을 덮기보다 기술적 토론과 회고의 장으로 끌어내는 편이 낫다. 이를 위해 팀원이 이견을 말해도 불이익이 없다는 심리적 안정감을 먼저 만들어야 한다.

형성기에 팀 헌장(Team Charter)을 워크숍으로 만들어 두면 의사결정 방식, 회의 원칙, 작업 규칙이 명문화되어 불필요한 충돌을 줄일 수 있다. 헌장은 한 번 쓰고 끝내지 않고 회고 때마다 갱신하는 것이 좋다.

애자일 스크럼 팀에서는 전통적인 지시와 보고 체계보다 **서번트 리더십** (Servant Leadership)이 잘 맞는다. 스크럼 마스터가 장애 요소를 제거하고 팀이 스스로 문제를 풀도록 돕는 역할에 집중해야 성취기에 들어설 수 있다.

## Ⅶ. 결론

- 핵심 요약 : 터크만 모델은 팀 발달 단계를 식별하고 단계별 리더십을 바꿔 고성과 팀을 만드는 관리 틀.
- 시사점 : 팀원 변동과 원격 환경을 고려해 발달 단계를 주기적으로 진단하고, 상황적 리더십과 결합해 운용해야 함.
