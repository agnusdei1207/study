## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 프로젝트 관리·팀 역학 → **터크만 팀 발달 모델**

## 30초 인출

- 본질: **터크만 팀 발달 모델**은 팀의 관계·과업 수행 변화를 단계로 설명하는 모델. 1977년 후속 검토에서 해산 단계가 추가되어 흔히 다섯 단계로 소개.
- 메커니즘: **형성기(Forming)** → **폭풍기(Storming)** → **규범기(Norming)** → **성과기(Performing)** → **해산기(Adjourning)** 의 대표 순서. 모든 팀의 동일 속도·순차 진행을 보장하는 규칙은 아님.
- 핵심: 단계별 팀 상태를 살피는 관점과 역할·갈등·협업 상태에 따른 PM 개입 조정.

<details>
<summary>핵심 용어</summary>

- **터크만 팀 발달 모델**: 팀의 대인관계와 과업 수행 변화를 형성·폭풍·규범·성과 단계로 설명하고, 후속 연구 검토에서 해산 단계를 추가한 모델
- **형성기(Forming)**: 팀원이 서로를 탐색하고 목표·역할을 파악하는 초기 단계
- **폭풍기(Storming)**: 역할·업무 방식·의견 차이가 드러나 조정이 필요한 단계
- **규범기(Norming)**: 공통 규칙과 협업 방식을 정리하고 신뢰를 쌓는 단계
- **성과기(Performing)**: 역할이 조정되고 팀이 과업 수행에 집중하는 단계
- **해산기(Adjourning)**: 과업 종료에 따라 결과를 정리하고 팀 활동을 마무리하는 단계
- **팀 작업 협약(Working Agreement)**: 소통·의사결정·협업 규칙에 대해 팀이 합의한 약속

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **터크만 팀 발달 모델**은 팀의 관계·과업 수행 변화를 단계로 설명하는 모델 |
| 목적 | 팀 상태에 맞는 협업 지원·PM 개입 선택의 지원 |

### Ⅱ. 다섯 단계의 대표 순서

```mermaid
flowchart TD
    A["형성기 · 목표와 역할 탐색"] --> B["폭풍기 · 차이와 갈등 표출"]
    B --> C["규범기 · 협업 규칙과 신뢰 형성"]
    C --> D["성과기 · 조정된 역할로 과업 수행"]
    D --> E["해산기 · 결과 정리와 팀 종료"]
```

### Ⅲ. PM의 개입

- **형성기**의 목표·역할 명확화와 **폭풍기**의 갈등 표면화·공정한 기준에 따른 조정.
- **규범기**의 합의된 **팀 작업 협약(Working Agreement)** 정착과 **성과기**의 장애 제거·권한 위임.
- **해산기**의 결과·교훈 정리. 인력·목표 변화에 따른 이전 단계 과제의 재등장 가능성.

제언: 단계의 고정 등급화 방지와 팀의 실제 상호작용에 따른 개입 조정.

## 2~4교시 25점 답안

## Ⅰ. 터크만 팀 발달 모델의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **터크만 팀 발달 모델**은 팀의 관계·과업 수행 변화를 단계로 설명하는 모델 |
| 목적 | 팀 상태에 맞는 협업 지원·PM 개입 선택의 지원 |

## Ⅱ. 팀 발달 단계

```mermaid
flowchart TD
    A["형성기 · 목표와 역할 탐색"] --> B["폭풍기 · 차이와 갈등 표출"]
    B --> C["규범기 · 협업 규칙과 신뢰 형성"]
    C --> D["성과기 · 조정된 역할로 과업 수행"]
    D --> E["해산기 · 결과 정리와 팀 종료"]
```

다섯 단계는 대표 설명 순서. 1965년 논문의 형성·폭풍·규범·성과 네 단계와 Tuckman·Jensen의 1977년 검토에서 추가된 해산 단계. 실제 팀의 동일한 진행 순서·단계별 체류 기간을 전제하지 않음.

## Ⅲ. 단계별 특성과 PM의 개입

| 단계 | 팀의 주요 상태 | PM의 개입 방향 |
|---|---|---|
| **형성기(Forming)** | 목표·역할 탐색, 불확실성, PM에 대한 확인 요구 | 목표·역할·의사결정 경로의 명확화 |
| **폭풍기(Storming)** | 업무 방식·역할·우선순위 차이의 표면화 | 의견 청취와 합의 기준에 따른 갈등 조정 |
| **규범기(Norming)** | 공통 규칙·협업 방식 수립, 신뢰 향상 | 팀 규칙의 지지와 권한의 점진적 확대 |
| **성과기(Performing)** | 역할 조정, 과업 중심의 협업 | 장애물 제거와 팀 자율 실행 지원 |
| **해산기(Adjourning)** | 과업 종료, 결과 인계와 팀 해체 | 성과·교훈 정리와 종료 지원 |

## Ⅳ. 갈등 관리와 팀 상태 점검

| 관찰 신호 | 관리 대응 | 확인할 점 |
|---|---|---|
| 목표·책임이 서로 다르게 이해됨 | 작업 범위와 책임자를 함께 확인 | 역할·의사결정 합의 |
| 의견 충돌이 개인 비난으로 번짐 | 쟁점을 과업·근거 중심으로 다시 정리 | 합의 기준과 후속 조치 |
| 구성원이 규칙을 따르지 않거나 참여하지 않음 | 규칙이 현실적인지 팀과 재검토 | 팀 작업 협약의 유효성 |
| 인력·목표 변화 뒤 협업이 흔들림 | 온보딩·역할 조정을 통해 필요한 팀 과제를 다시 지원 | 지식 인계·책임 변경 |

## Ⅴ. 기술사적 제언 — 단계는 진단 가설로 활용

| 문제 | 해결 방안 |
|---|---|
| 팀의 다섯 단계 고정 분류에 따른 갈등의 필수 통과 단계 오해와 지원 지연 | 정기 회고의 역할·갈등·협업 증거 확인 후 단계 설명을 진단 가설로 활용하고, 팀을 특정 단계에 맞추지 않은 채 실제 문제에 따른 PM 개입 조정 |
