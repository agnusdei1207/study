## 연관 키워드

- 소프트웨어 비용산정, 기능점수, 투입공수, COCOMO, 유사실적, 산정가정

## Ⅰ. 소프트웨어 비용 산정의 개요

- 핵심 요약 : 범위·규모·복잡도·생산성 근거로 노력·비용·기간을 추정하는 과정.
- 개념 : **소프트웨어 비용 산정** (Software Cost Estimation)은 범위·규모·복잡도·생산성 근거로 투입공수·비용·기간을 추정하는 과정.- 배경 및 필요성 : 초기 요구가 불완전하고 규모·생산성 차이가 커 소프트웨어 노력·비용을 정확히 예측하기 어려움.
- 주요 목적 : 요구·규모·생산성 근거에 따른 소프트웨어 개발비·노력·기간 예측.

## Ⅱ. 소프트웨어 비용 산정의 특징 및 장점

- 핵심 요약 : 예산·일정 근거·대안 비교·변경영향 판단을 산정 가정과 실적 환류로 연결.

1. 규모·복잡도·생산성 가정 명시 (Size/Complexity/Productivity Assumptions) : 추정의 입력과 가정을 문서화 → 비용·일정 산정근거 재현.
2. 기능점수 측정 (Function Point Measurement) : 사용자 기능규모와 복잡도를 측정 → 요구기능이 식별되는 개발 추정.
3. 모수모형 적용 (Parametric Model/COCOMO) : 규모·복잡도·생산성 변수의 경험모형을 적용 → 자료와 보정된 파라미터가 있는 추정.
4. 전문가·유사실적 교차검증 (Expert Judgment & Analogous Estimation) : 전문 판단과 기준사업 실제치를 비교 → 초기·자료부족 단계의 추정 보완.
5. 실적 환류 (Actuals Feedback) : 실적과 계획 차이를 다음 추정에 반영 → 향후 추정의 보정.

## Ⅲ. 소프트웨어 비용 산정의 구조 (흐름)

- 핵심 요약 : 요구·범위 정의 → 규모측정 → 산정모형·단가 적용 → 위험·불확실성 조정 → 승인·실적보정.

```text
요구·범위 정의
   ↓
규모측정
   ↓
산정모형·단가 적용
   ↓
위험·불확실성 조정
   ↓
승인·실적보정
```

```text
규모·복잡도·생산성 가정 명시
   ↓
모형·유사실적·전문가 판단 교차검증
   ↓
실적과 계획 차이 환류
```

## Ⅳ. 산정 방법의 비교

- 핵심 요약 : 전문가 판단은 자료부족 초기 추정에 유연하고 모수모형·기능점수는 반복성과 비교성이 높음.

| 개념·방법 | 주요 특성 | 적합한 선택 기준 |
| --- | --- | --- |
| 기능점수 (Function Point) | 사용자 기능규모와 복잡도 | 요구기능이 식별되는 개발 추정 |
| 모수·COCOMO (Constructive Cost Model) | 규모·복잡도·생산성 변수의 경험모형 | 자료와 보정된 파라미터가 있는 추정 |
| 전문가·유사실적 | 전문 판단과 기준사업 실제치 | 초기·자료부족 단계의 교차검증 |

## Ⅴ. 소프트웨어 비용 산정의 한계와 방안

- 핵심 요약 : 요구불확실성은 범위·가정·구간으로 표시; 낙관편향은 유사 실적과 독립검토로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 요구·규모 불확실 | 추정오차와 예산변경 | 범위·가정·구간추정·독립검토 명시 | 실적 대비 오차, 변경예산 |
| 유사실적 부적합 | 기술·팀 생산성 차이를 무시 | 비교사업 선정근거·보정요인 기록 | 보정근거, 추정-실적 편차 |
| 낙관편향 | 최소 추정과 위험 누락 | 독립검토·3점 추정·위험 버퍼 | 추정 구간, 예산 초과율 |

## Ⅵ. 소프트웨어 비용 산정 적용에 대한 기술사적 제언

- 핵심 요약 : 산정기준·제외범위·변경조건을 공유하고 실제 투입실적을 다음 추정에 환류.

- 산정책임자 : 규모·모형·생산성의 출처와 가정을 남기고 독립검토·실적보정·불확실성 구간을 예산승인에 포함.
- 발주자·수행자 : 산정 기준·제외범위·변경조건을 계약에 명시해 분쟁을 줄임.
- PMO : 프로젝트 실적 데이터를 축적하고 조직 생산성 기준을 주기적으로 보정.

## Ⅶ. 결론

- 핵심 요약 : 소프트웨어 비용 산정은 범위·규모·복잡도·생산성 근거로 노력·비용·기간을 추정하는 과정.
- 시사점 : 산정가정과 불확실성·실적 환류가 추정오차와 계약분쟁을 줄임.
