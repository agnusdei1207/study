## 연관 키워드

- SWOT, 3C, PEST, 내부·외부 환경, 경쟁우위, 전략과제

## Ⅰ. 경영환경 분석의 개요

- 핵심 요약 : 조직 내외부 환경을 구조화해 전략 선택의 근거를 만드는 SWOT·3C·PEST 분석 도구군.
- 개념 : **SWOT** (Strengths, Weaknesses, Opportunities, Threats), **3C** (Customer, Competitor, Company), **PEST** (Political, Economic, Social, Technological)는 조직 내외부 환경을 구조화해 전략 선택의 근거를 만드는 분석 도구군.
- 배경 및 필요성 : 외부환경·경쟁구도·내부역량을 따로 분석하면 전략의 기회와 실행가능성 연결이 약해짐.
- 주요 목적 : 거시환경·경쟁·내부역량을 종합해 실행 가능한 전략 선택과 우선순위 수립.

## Ⅱ. 경영환경 분석의 특징 및 장점

- 핵심 요약 : 분석 수준 상호보완; 근거 있는 전략가설; 위험·기회 우선순위화.

1. PEST 거시환경 분석 : 정치·경제·사회·기술 요인을 구조화 → 외부 변화요인과 기회·위협 파악.
2. 3C 시장 위치 분석 : 고객·경쟁·자사 관점을 비교 → 시장 내 상대 위치와 경쟁우위 파악.
3. SWOT 요인 통합 : 내부 강점·약점과 외부 기회·위협을 결합 → 전략 대안과 과제 도출.
4. 분석 수준 구분 : 거시·산업·내부 수준을 나누어 적용 → 요인 혼동과 중복 감소.
5. 전략가설 검증 : 증거 기반 우선순위와 실행과제 연결 → 전략 선택의 근거 강화.

## Ⅲ. 경영환경 분석의 구조 (흐름)

- 핵심 요약 : PEST 거시환경 → 3C 시장·고객·경쟁 → SWOT 내부강약점·외부기회위협 → 전략과제.

```text
[ 분석 흐름 ]

PEST 거시환경
    ↓
3C 시장·고객·경쟁
    ↓
SWOT 내부강약점·외부기회위협
    ↓
전략과제·우선순위
```

```text
[ 분석 수준 구분 ]

거시환경 : PEST
산업·시장 : 3C
내부·외부 요인 : SWOT
```

## Ⅳ. PEST·3C·SWOT의 비교

- 핵심 요약 : PEST는 거시환경, 3C는 산업·시장, SWOT은 내부외부 요인 종합.

| 개념·방법 | 주요 특성 | 적합한 선택기준 |
| --- | --- | --- |
| PEST | 정치·경제·사회·기술 거시환경 | 외부 거시 변화 파악 |
| 3C | 고객·경쟁·자사 시장 위치 | 산업·시장 내 경쟁구도 파악 |
| SWOT | 강점·약점·기회·위협 통합 | 전략대안과 우선과제 도출 |

## Ⅴ. 경영환경 분석의 한계와 방안

- 핵심 요약 : 주관적 나열은 증거·우선순위 기준으로, 정태성은 정기갱신·시나리오로 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 주관적 항목 나열 | 실행 우선순위·근거 부재 → 전략 실행력 저하 | 근거자료·영향도·불확실성 기록 | 근거 없는 항목, 실행과제 연결률 |
| 분석도구 혼용 | 거시·산업·내부 요인 혼동 → 요인 중복 | PEST·3C·SWOT 분석단위 구분 | 요인 중복, 분류 누락 |
| 정태적 분석 | 환경 변화 미반영 → 전략 노후화 | 정기갱신·시나리오·조기경보 운영 | 갱신주기, 시나리오 수 |
| 실행과제 미연결 | 분석이 의사결정에 반영되지 않음 | 전략과제·자원배분·책임자 연결 | 실행과제 수, 자원배분 반영률 |

## Ⅵ. 경영환경 분석 적용에 대한 기술사적 제언

- 핵심 요약 : 분석을 실행 선택과 자원배분에 연결하고 가정과 근거를 추적.
- 분석단위 구분 : 전략담당자는 PEST·3C·SWOT의 분석단위를 구분하고 각 요인에 근거·영향·실행과제를 연결.
- 의사결정 연계 : 분석 결과를 의사결정 회의에서 검증하고 자원배분·책임자와 연결.
- 지속 갱신 : 환경 변화에 따라 분석을 정기 갱신하고 시나리오 기반 조기경보를 운영.

## Ⅶ. 결론

- 핵심 요약 : 조직 내외부 환경을 구조화해 전략 선택의 근거를 만드는 SWOT·3C·PEST 분석 도구군.
- 시사점 : SWOT·3C·PEST는 증거와 선택으로 이어질 때 전략분석 가치 확보.
