## 지식 로드맵 내 현재 위치

IT 전략·관리 → 환경·역량 분석 → **경영환경 분석(SWOT·3C·PEST)**

## 30초 인출

- 본질: 경영환경 분석은 거시환경(PEST)·시장(3C)·조직 내외부 요인(SWOT)을 범위별로 살펴 전략 방향의 근거를 만드는 분석 활동
- 메커니즘: PEST가 거시환경의 기회·위협을, 3C가 고객·경쟁사·자사의 시장 근거를 만들고, SWOT이 이를 내부·외부 요인으로 분류·교차해 전략 대안 도출
- 통찰: 세 기법을 따로 채우면 SWOT 근거가 끊기므로 목적에 맞는 입력 기법 선택과 SWOT 요인의 근거 연결

<details>
<summary>핵심 용어</summary>

- **경영환경 분석** : 조직을 둘러싼 거시환경·시장과 조직 내부 역량을 살펴 전략 방향의 근거를 만드는 분석 활동
- **PEST(Political, Economic, Social, Technological)** : 정치·경제·사회·기술 관점의 거시환경 분석 틀. 법(Legal)·환경(Environmental)을 더하면 PESTLE
- **3C(Customer, Competitor, Company)** : 고객·경쟁사·자사를 함께 보고 시장에서의 성공 요인을 찾는 분석 틀
- **SWOT(Strengths, Weaknesses, Opportunities, Threats)** : 내부 강점·약점과 외부 기회·위협을 구분해 전략 대안을 찾는 분석 틀
- **TOWS 매트릭스** : SWOT 요인을 교차해 SO·ST·WO·WT 전략 대안을 만드는 조합표
- **핵심 성공 요인(KSF, Key Success Factor)** : 고객 요구를 경쟁사보다 잘 충족하기 위해 반드시 갖춰야 할 요인

</details>

## 2~4교시 25점 답안

## Ⅰ. 경영환경 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **경영환경 분석** 은 거시환경·시장·조직 내외부 요인을 범위별로 살펴 전략 방향의 근거를 만드는 분석 활동 |
| 목적 | 근거가 확인된 기회·위협·강점·약점에 기반한 전략 대안의 도출 |

## Ⅱ. 분석 범위가 층을 이루는 특징

| 특징 | 의미 |
|---|---|
| 범위의 계층 | 거시환경(PEST) → 시장(3C) → 조직 내외부 종합(SWOT)의 좁혀 가는 구조 |
| 외부·내부 관점 분리 | 조직이 통제할 수 없는 환경과 통제 가능한 역량의 구분 |
| 상호 보완 | 한 기법만으로는 근거나 전략 대안 중 하나가 빠짐 |
| 시점 의존 | 같은 요인도 분석 시점과 목표에 따라 기회·위협 판단이 바뀜 |

## Ⅲ. 세 기법의 연계 구조와 3C 분석 방법

### PEST·3C·SWOT 연계 구조

```text
PEST: 정치·경제·사회·기술의 거시환경
    ↓ 기회·위협의 근거
3C: 고객·경쟁사·자사의 시장 구도
    ↓ 고객·경쟁사 → 기회·위협, 자사 → 강점·약점
SWOT: 내부·외부 요인 분류
    ↓
TOWS 교차: SO·ST·WO·WT 전략 대안
```

PEST와 3C는 고정 순서의 단계가 아닌 서로 다른 분석 범위이며, 분석 목적에 따라 하나만 수행 가능

### 3C 확대: 핵심 성공 요인 도출 방법

```text
고객 분석: 시장 규모·요구 변화 파악
    ↓
경쟁사 분석: 같은 요구에 대한 경쟁사 대응 파악
    ↓
자사 분석: 경쟁사 대비 자사 역량 차이 파악
    ↓
고객 요구 중 자사 우위 영역 → 핵심 성공 요인
```

## Ⅳ. PEST·3C·SWOT의 특성과 적용 조건 비교

| 구분 | **PEST** | **3C** | **SWOT** |
|---|---|---|---|
| 분석 대상 | 정치·경제·사회·기술 환경 | 고객·경쟁사·자사 | 내부 강점·약점, 외부 기회·위협 |
| 관점 | 외부 거시환경 | 외부 시장과 자사 | 내부·외부 종합 |
| 적용 조건 | 규제·기술 등 장기 환경 변화가 큰 사업 | 경쟁 구도가 뚜렷한 특정 시장 | 입력 근거가 확보된 전략 수립 단계 |
| 분석 방법 | 요인별 변화 동향과 사업 영향 평가 | 고객 요구·경쟁사 대응·자사 역량 비교 | 요인 분류 후 **TOWS 매트릭스** 교차 |
| 주요 산출물 | 기회·위협 목록 | **핵심 성공 요인** | 전략 대안 |

## Ⅴ. 경영환경 분석의 한계와 방안

| 한계 | 방안 |
|---|---|
| 세 기법의 독립 수행에 따른 같은 사실의 중복 | PEST·3C 결과마다 연결되는 SWOT 요인의 기록 |
| 규제·기술 변화가 큰 공공 IT 사업의 시장 분석 편중 | 거시 변화의 영향이 크면 PEST 선택 |
| 경쟁사 비교 없는 자사 강점 판단 | 경쟁 시장 진입 시 3C로 경쟁사 대비 우위 확인 후 강점 판정 |
| 분석 시점 경과에 따른 근거 노후화 | 요인별 기준 시점 기록과 재분석 시점 설정 |

## Ⅵ. 제언

분석 목적에 맞춰 PEST·3C 중 필요한 입력 기법을 고르고, 그 결과를 SWOT 요인에 연결한 근거 추적표로 전략 대안의 근거 확인

### SWOT 요인의 근거 추적 구조

```text
SWOT 요인
    │
    ├─ 출처 기법 ── PEST 요인 또는 3C 관점
    │
    ├─ 근거 자료 ── 통계·규제·고객 조사
    │
    └─ 기준 시점 ── 분석 일자와 재분석 시점
```

### 출처 기법 확대: 입력 기법 선택 절차

```text
분석 목적 확인
    ↓
거시 변화(규제·기술)의 영향 판정
    ├─ 큼 → PEST 수행
    └─ 작음 → 생략
    ↓
시장 경쟁 구도의 중요도 판정
    ├─ 핵심 → 3C 수행
    └─ 비핵심 → 자사 역량 분석만 수행
    ↓
결과의 SWOT 요인 분류와 근거 기록
```

### 선택 근거: 기법 나열식 분석과의 비교

| 구분 | 기법 나열식 분석 | 제언: 목적별 선택과 근거 추적 |
|---|---|---|
| 기법 선택 | 세 기법 모두 형식적 수행 | 분석 목적에 맞는 입력 기법 선택 |
| 기법 간 연결 | 기법별 별도 표 | PEST·3C 결과의 SWOT 요인 연결 |
| SWOT 요인의 근거 | 평가어 나열 | 출처 기법·근거 자료·기준 시점 |
| 갱신 기준 | 다음 계획 수립 때 | 재분석 시점의 근거 변화 |
