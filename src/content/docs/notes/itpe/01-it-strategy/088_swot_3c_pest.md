## 지식 로드맵 내 현재 위치

IT 전략·관리 → 환경·역량 분석 → **경영환경 분석(SWOT·3C·PEST)**

## 30초 인출

- 본질: 경영환경 분석은 거시환경(PEST)·시장(3C)·조직 내외부 요인(SWOT)을 살펴 전략 대안의 근거를 만드는 분석 활동
- 메커니즘: PEST·3C가 기회·위협·강점·약점의 근거를 공급하고, SWOT이 이를 분류한 뒤 TOWS 교차로 전략 대안 도출
- 통찰: 세 기법을 따로 채우면 요인의 근거와 전략이 끊기므로 PEST·3C 결과의 SWOT 연결과 TOWS 대안의 실행 과제화

<details>
<summary>핵심 용어</summary>

- **경영환경 분석** : 조직을 둘러싼 거시환경·시장과 조직 내부 역량을 살펴 전략 대안의 근거를 만드는 분석 활동
- **PEST(Political, Economic, Social, Technological)** : 정치·경제·사회·기술 관점의 거시환경 분석 틀. 법(Legal)·환경(Environmental)을 더하면 PESTLE
- **3C(Customer, Competitor, Company)** : 고객·경쟁사·자사를 함께 보고 시장에서의 성공 요인을 찾는 분석 틀. Ohmae가 『The Mind of the Strategist』(1982)에서 전략 삼각형(strategic triangle)으로 제시
- **SWOT(Strengths, Weaknesses, Opportunities, Threats)** : 내부 강점·약점과 외부 기회·위협을 구분해 전략 대안을 찾는 분석 틀
- **TOWS 매트릭스** : SWOT 요인을 교차해 SO·ST·WO·WT 전략 대안을 만드는 조합표. Weihrich(1982)가 상황 분석 도구로 제시
- **핵심 성공 요인(KSF, Key Success Factor)** : 고객 요구를 경쟁사보다 잘 충족하기 위해 반드시 갖춰야 할 요인

</details>

## 2~4교시 25점 답안

## Ⅰ. 경영환경 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **경영환경 분석** 은 거시환경·시장·조직 내외부 요인을 살펴 전략 대안의 근거를 만드는 분석 활동 |
| 목적 | 근거가 확인된 기회·위협·강점·약점에 기반한 실행 가능한 전략 대안의 도출 |

## Ⅱ. 내부·외부와 긍정·부정의 두 축으로 요인을 나누는 특징

| 구분 | 긍정 요인 | 부정 요인 |
|---|---|---|
| 내부: 조직이 통제 가능 | 강점(S) | 약점(W) |
| 외부: 조직이 통제 불가 | 기회(O) | 위협(T) |

- 범위의 계층: 거시환경의 **PEST** → 시장의 **3C** → 내외부를 종합하는 **SWOT** 순서로 좁혀 가는 구조
- 목표 의존: 같은 사실도 조직 목표에 따라 강점과 약점, 기회와 위협이 뒤바뀌는 판단

## Ⅲ. 세 기법의 연계 구조와 SWOT 요인 분류

### PEST·3C·SWOT 연계 구조

```text
PEST: 정치·경제·사회·기술의 거시환경
    ↓ 기회·위협의 근거
3C: 고객·경쟁사·자사의 시장 구도
    ↓ 고객·경쟁사 → 기회·위협, 자사 → 강점·약점
SWOT: 내부·외부 요인 분류
    ↓
TOWS 교차: SO·ST·WO·WT 전략 대안
```

PEST와 3C는 고정 순서의 단계가 아닌 서로 다른 분석 범위이며, 분석 목적에 따라 하나만 수행 가능

### SWOT 확대: 요인의 내부·외부 판정 분기

```text
PEST·3C에서 넘어온 후보 요인
    ↓
조직의 통제 범위 판정
    ├─ 통제 가능 → 목표 기여 방향으로 강점·약점 구분
    └─ 통제 불가 → 목표 영향 방향으로 기회·위협 구분
    ↓
요인별 출처 기법·근거 자료·기준 시점 기록
```

## Ⅳ. 입력 기법 비교와 TOWS 전략 대안

### PEST·3C·SWOT의 특성과 적용 조건

| 구분 | PEST | 3C | SWOT |
|---|---|---|---|
| 분석 대상 | 정치·경제·사회·기술 환경 | 고객·경쟁사·자사 | 내부 강점·약점, 외부 기회·위협 |
| 적용 조건 | 규제·기술 등 장기 환경 변화가 큰 사업 | 경쟁 구도가 뚜렷한 특정 시장 | 입력 근거가 확보된 전략 수립 단계 |
| 분석 방법 | 요인별 변화 동향과 사업 영향 평가 | 고객 요구·경쟁사 대응·자사 역량 비교 | 요인 분류 후 **TOWS 매트릭스** 교차 |
| 주요 산출물 | 기회·위협 목록 | **핵심 성공 요인** | 전략 대안 |

### TOWS 전략 대안

| 조합 | 결합 요인 | 전략 방향 |
|---|---|---|
| SO | 강점 × 기회 | 강점으로 기회를 활용하는 공격 전략 |
| ST | 강점 × 위협 | 강점으로 위협을 줄이는 다각화 전략 |
| WO | 약점 × 기회 | 약점을 보완해 기회를 잡는 전환 전략 |
| WT | 약점 × 위협 | 약점과 위협 노출을 줄이는 방어 전략 |

## Ⅴ. 경영환경 분석의 한계와 방안

| 한계 | 방안 |
|---|---|
| 규제·기술 변화가 큰 공공 IT 사업의 시장 분석 편중 | 거시 변화의 영향이 크면 PEST 선택 |
| 경쟁사 비교 없는 자사 강점 판단 | 경쟁 시장이면 3C로 경쟁사 대비 우위 확인 후 강점 판정 |
| 근거 없는 평가어 나열과 내부·외부 혼동 | 통제 가능성 기준 분류와 요인별 출처 기법·근거 기록 |
| 네 칸 정리 후 전략 공백 | 강점이 기회에 맞으면 SO, 약점이 기회를 막으면 WO, 위협이 약점과 겹치면 WT 선택 |
| 분석 시점 경과에 따른 근거 노후화 | 요인별 기준 시점과 재분석 시점 설정 |

## Ⅵ. 제언

PEST·3C 결과를 SWOT 요인의 근거로 연결하고, 근거가 확인된 요인으로 만든 TOWS 대안만 책임자·재검토 시점을 가진 실행 과제로 전환

### 분석 결과의 실행 연결 구조

```text
경영환경 분석 결과
    │
    ├─ 요인 근거 ── 출처 기법·근거 자료·기준 시점
    │
    ├─ TOWS 대안 ── 근거가 확인된 요인의 교차 조합
    │
    └─ 실행 과제 ── 책임자·자원·기한·재검토 시점
```

### 실행 과제 확대: 우선 과제 선정과 재검토

```text
TOWS 대안 목록
    ↓
목표 적합성·필요 자원·실행 가능성 비교
    ↓
우선 과제 선정과 책임자·기한 지정
    ↓
재검토 시점의 근거 요인 변화 확인
    ├─ 변화 없음 → 과제 지속
    └─ 요인 변화 → PEST·3C 재분석과 대안 재선정
```

### 선택 근거: 기법 나열식 분석과의 비교

| 구분 | 기법 나열식 분석 | 제언: 근거 연결과 실행 과제화 |
|---|---|---|
| 기법 간 연결 | 기법별 별도 표 | PEST·3C 결과의 SWOT 요인 연결 |
| SWOT 요인 | 평가어 나열 | 출처 기법·근거 자료·기준 시점 |
| 전략 도출 | 네 칸 정리에서 종료 | TOWS 교차 조합 |
| 결과물 | 분석표 | 책임자가 지정된 실행 과제 |
