## 큰 그림과 30초 인출

```text
[1단계: 거시환경 분석]  PEST (정치·경제·사회·기술 외생 변수 분석)
                               │
                               ▼ [기회(O) 및 위협(T) 후보 도출]
[2단계: 미시환경 분석]  3C (고객 Customer, 경쟁사 Competitor, 자사 Company)
                               │
                               ▼ [강점(S)·약점(W) 및 시장 기회 구체화]
[3단계: 종합 전략 도출] SWOT 매트릭스 (4대 교차 전략 완성)
                               │
                 ┌─────────────┴─────────────┐
                 ▼                           ▼
          [SO 전략: 공격/성장]        [WO 전략: 국면전환/보완]
          [ST 전략: 차별화/수비]      [WT 전략: 철수/회피]
```

- 본질: 기업의 전략 수립 시 통제 불가능한 거시 환경(PEST)에서 기회와 위협을 탐색하고, 시장 내 경쟁 관계(3C)에서 강점과 약점을 구체화하여, 최종적으로 2x2 교차 매트릭스(SWOT)를 통해 즉시 실행 가능한 4대 전략 과제를 도출하는 하향식(Funnel) 통합 경영환경 분석 체계
- 위치: `ISP/경영전략 착수 → PEST 거시 분석 → 3C 미시 분석 → SWOT 교차 매핑 → 전략 과제 우선순위화`
- 핵심: 제133회 3교시 기출, 거시(PEST)→미시(3C)→전략(SWOT) 연계 파이프라인, SO/ST/WO/WT 교차 전략
- 실무: 도구 간 단절 및 끼워 맞추기 배제, 단일 데이터 파이프라인 정합성 유지, 상시 전략 감지

## 예상문제

> 경영환경을 분석하는 대표적 방법론인 PEST, 3C, SWOT 분석에 대하여 각 방법의 개념과 특성, 3대 도구 간의 상호 유기적 연계 절차, 실무 적용 시 고려사항을 설명하시오. (25점)

## 딸려 나오는 하위 토픽

| 하위 토픽 | 핵심 내용 | 본문 답안 위치 |
|---|---|---|
| **PEST 분석** | 통제 불가능한 외부 거시환경을 정치(P), 경제(E), 사회(S), 기술(T) 4개 축으로 진단하여 기회/위협 도출 | Ⅱ 특징, Ⅲ 모델 |
| **3C 분석** | 고객(Customer), 경쟁사(Competitor), 자사(Company) 3각 관계 분석을 통한 미시적 차별화 포지셔닝 | Ⅱ 특징, Ⅲ 모델 |

## Ⅰ. 체계적 전략 수립의 3대 나침반, 개요

- 정의: 기업을 둘러싼 외부 거시적 외생 변수(PEST), 시장 내 직접적 경쟁 관계(3C), 내부 역량과 외부 환경의 교차점(SWOT)을 종합 진단하여 지속 가능한 경쟁 우위 전략을 수립하는 통합 분석 프레임워크
- 등장 배경: 개별 분석 도구의 파편적 사용으로 인한 전략 보고서 간 모순 발생, 급변하는 거시 기술 환경(AI, 클라우드)과 미시 고객 니즈를 단일 체계로 통합 조망할 필요성 대두
- 핵심 목적: 외부 기회·위협 요인과 내부 강점·약점의 정합성(Strategic Fit) 확보, 단순 나열식 분석을 탈피한 실행 가능한 4대 교차 전략 도출

#### 한줄 요약
- PEST(거시), 3C(미시), SWOT(전략)을 깔때기처럼 연계하여 최적 전략을 도출하는 체계임

## Ⅱ. PEST, 3C, SWOT의 핵심 특성 비교

| 분석 도구 | 분석 범위 및 대상 | 통제 가능 여부 | 핵심 도출 산출물 | 비고 |
|---|---|---|---|---|
| **PEST 분석** | **거시 환경 (Macro)**<br>- 정치/제도, 경제, 사회/문화, 기술 요인 | **완전 불가 (외생적)**<br>- 기업이 순응해야 할 환경 변수 | 거시적 기회(O) 및 위협(T) 잠재 후보 풀 | 광범위한 환경 스캔 |
| **3C 분석** | **미시 환경 (Micro)**<br>- 고객(Customer), 경쟁사(Competitor), 자사(Company) | **부분 가능 (상대적)**<br>- 자사 역량 강화 및 포지셔닝 가능 | 경쟁 우위 차별화 요소, 강점(S)/약점(W) 구체화 | 시장 내 3각 역학 분석 |
| **SWOT 분석** | **종합 전략 (Synthesis)**<br>- 내부 강약점 × 외부 기회위협 2x2 교차 | **실행 통제 가능**<br>- 자원 배분 및 전략 실행 의사결정 | 4대 교차 전략 (SO, ST, WO, WT 실행 로드맵) | 실행 전략 도출 매트릭스 |

#### 한줄 요약
- PEST는 거시 외생, 3C는 시장 경쟁 미시, SWOT은 내외부 결합 교차 전략을 담당함

## Ⅲ. PEST-3C-SWOT 통합 연계 파이프라인 아키텍처

```text
┌───────────────── [1단계: 거시환경 분석 (PEST)] ─────────────────┐
│  - Political    : AI 기본법, 데이터 규제, 공공 SW 조달 제도     │
│  - Economic     : 고금리, 환율 변동, IT 투자 예산 축소         │
│  - Social       : 인구 구조 고령화, 비대면 선호, 디지털 격차   │
│  - Technological: 생성형 AI, 클라우드 네이티브, 양자 컴퓨팅     │
└────────────────────────────────┬────────────────────────────────┘
                                 │ 거시 기회(O) / 위협(T) 후보 도출
                                 ▼
┌───────────────── [2단계: 미시환경 분석 (3C)] ───────────────────┐
│  ├─ Customer   : 초개인화 금융 서비스 요구, 모바일 접근성 선호  │
│  ├─ Competitor : 빅테크 핀테크 진입, 인터넷전문은행 저원가 경쟁 │
│  └─ Company    : 방대한 고객 데이터 보유(강점), 레거시 IT(약점) │
└────────────────────────────────┬────────────────────────────────┘
                                 │ 내외부 요인 정제 및 SWOT 배치
                                 ▼
┌───────────────── [3단계: 종합 전략 매트릭스 (SWOT)] ────────────┐
│                    │ 내부 강점 (Strengths) │ 내부 약점 (Weaknesses)│
│  ──────────────────┼───────────────────────┼───────────────────────│
│  외부 기회 (Opp.)  │ [SO 전략: 공격/성장]  │ [WO 전략: 국면전환]   │
│  외부 위협 (Threat)│ [ST 전략: 차별화/수비]│ [WT 전략: 축소/회피]  │
└──────────────────────────────────────────────────────────────────┘
```

| 교차 전략 | 결합 축 | 전략적 행동 방향 | 실무 IT 전략 적용 사례 |
|---|---|---|---|
| **SO 전략 (강점-기회)** | Strengths × Opportunities | 자사의 핵심 강점을 활용하여 시장 기회를 선점 (공격) | 방대한 고객 데이터(S)와 생성형 AI(O)를 결합한 초개인화 PB 서비스 런칭 |
| **ST 전략 (강점-위협)** | Strengths × Threats | 자사 강점을 방패 삼아 시장의 외부 위협을 극복 (차별화) | 금융 라이선스 및 신뢰도(S)를 바탕으로 빅테크(T)의 금융 침탈 방어 |
| **WO 전략 (약점-기회)** | Weaknesses × Opportunities | 외부 기회를 활용하여 내부 취약점을 보완 (국면 전환) | 클라우드 확산 기회(O)를 활용하여 노후 레거시 코어뱅킹(W) 현대화 추진 |
| **WT 전략 (약점-위협)** | Weaknesses × Threats | 위협을 회피하고 내부 약점을 최소화하여 생존 (방어/철수)| 비핵심 적자 IT 서비스(W)를 정리하고 보안 취약점(T) 선제 방어 |

#### 한줄 요약
- PEST에서 3C를 거쳐 SWOT 4대 교차 전략으로 정제되는 파이프라인을 형성함

## Ⅳ. 경영환경 분석 4단계 실행 절차

```text
① 거시 요인 도출 (PEST) → ② 시장 경쟁 역학 분석 (3C) → ③ SWOT 요인 매핑 및 검증 → ④ 4대 교차 전략 수립 및 로드맵
   └─ 기회/위협 후보 발굴       └─ 고객/경쟁사/자사 강약점      └─ 인과관계 정합성 확인        └─ SO/ST/WO/WT 과제화
```

| 단계 | 주요 수행 내용 | 핵심 산출물 및 기준 |
|---|---|---|
| **1. 거시 분석** | 정치·경제·사회·기술 지표 모니터링, 산업에 미치는 파급 효과 진단 | PEST 분석 보고서 |
| **2. 미시 분석** | 타깃 고객 니즈 세분화, 핵심 경쟁사 벤치마킹, 자사 핵심 역량 진단 | 3C 분석 매트릭스 |
| **3. SWOT 배치** | 앞선 분석 결과를 바탕으로 객관적 팩트 기반 강점, 약점, 기회, 위협 분류 | SWOT 팩트 시트 |
| **4. 전략 완성** | 4분면 교차 전략 수립, 우선순위 평가(AHP 연계) 및 중장기 이행 로드맵 수립 | SWOT 전략 매트릭스, 전략 과제 로드맵 |

#### 한줄 요약
- 거시 도출, 미시 분석, 요인 배치, 교차 전략 수립의 4단계를 체계적으로 순환함

## Ⅴ. 경영환경 분석 도구 간 상호 작용 및 관계

```text
[외부 환경 영역] ──────> PEST (거시 외생 변수) ──┐
                             │                  ├──> [기회(O) / 위협(T)]
                         3C (고객 & 경쟁사)   ──┘           │
                                                            ▼
[내부 역량 영역] ──────> 3C (자사 핵심 역량)  ──────> [강점(S) / 약점(W)]
                                                            │
                                                            ▼
                                                  [SWOT 교차 전략 매트릭스]
```

| 관계 구분 | 상호 연계 메커니즘 | 실무적 유의점 |
|---|---|---|
| **PEST ──> 3C** | 거시 환경 변화가 고객의 니즈 변화와 경쟁사의 전략 변화를 촉발 | 거시 규제 완화가 시장 신규 진입자(3C)에 미치는 파급력 관찰 |
| **3C ──> SWOT** | 고객-경쟁사 관계에서 기회/위협이 확정되고, 자사 역량에서 강약점이 도출 | 자사의 강점이 경쟁사 대비 상대적 우위인지 엄격히 검증 |
| **PEST ──> SWOT** | 국가 제도, 금리, 파괴적 기술(AI)이 직접적으로 SWOT의 외생 요인으로 작용 | 내부에서 해결 불가능한 환경 요인을 약점으로 오분류하지 않도록 주의 |

#### 한줄 요약
- PEST와 3C가 SWOT의 입력값으로 작동하여 내외부의 완벽한 전략적 정합성을 달성함

## Ⅵ. 실무 적용 시 왜곡 요인 및 통제 대책

- 적용 상황: 대형 금융 지주사의 차세대 디지털 뱅킹 및 인공지능 전환 중장기 전략 수립

| 문제점 | 발생 원인 | 공학적·제도적 해결 대책 | 기대 효과 |
|---|---|---|---|
| **세 분석 간 단절 및 모순 발생** | 작성 팀 분리 및 PEST/3C 결과와 무관하게 SWOT을 임의 작성 | 'PEST 요인 → 3C 검증 → SWOT 배치' 단일 추적성 템플릿 의무화 | 전략 정합성 및 논리적 완결성 확보 |
| **단순 나열식 분석 및 실행 과제 부재**| SWOT 매트릭스 채우기에 그치고 SO/ST/WO/WT 교차 전략 미도출 | 교차 매트릭스 기반 실행 과제 도출 및 AHP 연계 우선순위화 | 실행 가능한 구체적 액션 플랜 확보 |
| **내부 약점과 외부 위협의 혼동** | 자사 소프트웨어 결함 등 내부 요인을 외부 위협(T)으로 잘못 배치 | 통제 가능성 기준(내부 통제 가능=S/W, 통제 불가=O/T) 엄격 적용 | 정확한 상황 진단 및 왜곡 차단 |
| **WT(철수/회피) 전략의 외면** | 긍정적 성장(SO)에만 치중하고 위험 회피 과제 기피 | 사업 포트폴리오 관점에서 비핵심 자산 정리 및 철수 기준 사전 명시 | 리스크 조기 차단 및 자원 낭비 방지 |

#### 한줄 요약
- 단일 템플릿 연계, 교차 전략 과제화, 통제 기준 엄격화, WT 전략 균형으로 왜곡을 막음

## Ⅶ. 상시 전략 레이더(Continuous Sensing) 중심의 결론

- **[일회성 정적 보고서를 탈피한 실시간 전략 레이더 구축]**: 1년에 한 번 파워포인트로 작성되는 PEST-3C-SWOT은 급변하는 AI·규제 환경에서 작성 직후 폐기되는 한계를 지님
- 나라면: 외부 규제·환율 API(PEST), 경쟁사 앱스토어 및 특허 데이터(3C), 사내 IT 운영 지표(자사)를 실시간 크롤링하여 `거시/미시 환경 변화 감지 시 대시보드 상의 SWOT 매트릭스가 동적으로 재배치되고 전략적 위험 알람을 발송`하는 '상시 전략 레이더 시스템'을 구축

#### 한줄 요약
- 정적 분석을 동적 데이터 레이더로 전환하여 환경 변화에 즉각 대응하는 전략을 완성함

## 1교시 10점 답안 발췌

### 1. 경영환경 분석(SWOT·3C·PEST)의 정의
- 통제 불가능한 거시 환경(PEST)과 시장 내 미시 경쟁 관계(3C)를 분석하여 기회·위협과 강점·약점을 도출하고, 이를 SWOT 매트릭스로 교차하여 4대 실행 전략(SO, ST, WO, WT)을 수립하는 통합 분석 프레임워크

### 2. PEST-3C-SWOT 연계 파이프라인
```text
[PEST] 거시 외생환경 (정치, 경제, 사회, 기술) ──> [기회(O) / 위협(T)]
                          │                               │
[3C]   미시 경쟁관계 (고객, 경쟁사, 자사)       ──> [강점(S) / 약점(W)]
                          │                               │
                          └───────────────┬───────────────┘
                                          ▼
[SWOT] 교차 전략 도출 ──> SO(공격) | ST(차별화) | WO(국면전환) | WT(철수)
```

### 3. 차별화 제언
- 도구 간 단절을 방지하기 위해 통제 가능성 기준(내부 S/W vs 외부 O/T)을 엄격히 적용하고, 성장 지향적 SO 전략뿐 아니라 비핵심 사업 철수를 다루는 WT 전략을 균형 있게 수립해야 함
