## 지식 로드맵 내 현재 위치

지식 위치: IT 전략·관리 → 전략 수립·환경 분석 → **경영환경 분석**

## 30초 인출

- 본질: 경영환경 분석은 조직 안팎의 변화와 역량을 살펴 실행할 전략을 고르는 일이다.
- 메커니즘: PEST로 거시 환경, 3C로 고객·경쟁사·자사를 살핀 뒤 SWOT에서 내부 강점·약점과 외부 기회·위협을 교차한다.

<details>
<summary>핵심 용어</summary>

- **경영환경 분석** : 외부 변화와 내부 역량을 구분해 전략 과제의 근거를 찾는 분석 활동이다.
- **PEST(Political, Economic, Social, Technological)** : 정치·경제·사회·기술의 거시 환경을 살피는 분석 틀이다.
- **3C(Customer, Competitor, Company)** : 고객·경쟁사·자사를 함께 살펴 시장 요구와 상대적 역량을 파악하는 분석 틀이다.
- **SWOT(Strengths, Weaknesses, Opportunities, Threats)** : 내부 강점·약점과 외부 기회·위협을 구분해 전략을 검토하는 틀이다.
- **SO** : 내부 강점을 활용해 외부 기회를 살리는 전략이다.
- **ST** : 내부 강점으로 외부 위협에 대응하는 전략이다.
- **WO** : 내부 약점을 보완하며 외부 기회를 활용하는 전략이다.
- **WT** : 내부 약점과 외부 위협의 영향을 함께 줄이는 전략이다.

</details>

## 1교시 10점 답안

### Ⅰ. 경영환경 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **경영환경 분석** 은 조직의 외부 변화와 내부 역량을 구분해 전략 과제의 근거를 찾는 활동이다. |
| 목적 | 기회·위협과 강점·약점에 맞는 실행 전략을 선택한다. |

### Ⅱ. 분석 도구와 SWOT 입력

| 도구 | 살피는 대상 | SWOT에 반영할 요인 |
|---|---|---|
| **PEST** | 정치·경제·사회·기술 환경 | 외부 기회·위협 |
| **3C** | 고객·경쟁사·자사 | 고객·경쟁사는 외부, 자사는 내부 |
| **SWOT** | 앞서 확인한 내부·외부 근거 | 강점·약점·기회·위협 |

3C 전체를 강점·약점으로 분류하지 않는다. 고객과 경쟁사의 변화는 외부 요인, 자사의 역량은 내부 요인이다.

### Ⅲ. SWOT 교차전략

| 내부 \ 외부 | 기회(O) | 위협(T) |
|---|---|---|
| 강점(S) | **SO**: 강점으로 기회 활용 | **ST**: 강점으로 위협 대응 |
| 약점(W) | **WO**: 약점을 보완해 기회 활용 | **WT**: 약점과 위협의 영향을 줄임 |

**제언:** 각 요인에 근거와 확인 시점을 기록하고 교차전략을 실행 과제로 연결한다.

## 2~4교시 25점 답안

## Ⅰ. 경영환경 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **경영환경 분석** 은 조직의 외부 변화와 내부 역량을 구분해 전략 과제의 근거를 찾는 활동이다. |
| 목적 | 기회·위협과 강점·약점에 맞는 실행 전략을 선택한다. |

## Ⅱ. 분석 도구와 SWOT 입력

| 도구 | 살피는 대상 | SWOT에 반영할 요인 |
|---|---|---|
| **PEST** | 정치·경제·사회·기술 환경 | 외부 기회·위협 |
| **3C** | 고객·경쟁사·자사 | 고객·경쟁사는 외부, 자사는 내부 |
| **SWOT** | 앞서 확인한 내부·외부 근거 | 강점·약점·기회·위협 |

PEST와 3C는 순서가 정해진 단계가 아니라 서로 다른 관점의 입력이다. 3C의 고객·경쟁사 정보를 외부 요인으로, 자사 정보를 내부 요인으로 분류한 뒤 같은 주제의 근거를 중복 계산하지 않는다.

## Ⅲ. SWOT 교차전략

| 내부 \ 외부 | 기회(O) | 위협(T) |
|---|---|---|
| 강점(S) | **SO**: 강점으로 기회 활용 | **ST**: 강점으로 위협 대응 |
| 약점(W) | **WO**: 약점을 보완해 기회 활용 | **WT**: 약점과 위협의 영향을 줄임 |

예를 들어 자사의 데이터 분석 역량(S)과 고객의 새로운 요구(O)를 연결하면 신규 서비스 후보를 세울 수 있다. 전략 유형은 선택지를 정리하는 틀이므로 실제 투자 여부는 시장 규모·비용·실행 역량을 추가로 검증한다.

## Ⅳ. 분석 오류와 대응

| 오류 | 왜 문제인가 | 대응 |
|---|---|---|
| 내부·외부 요인 혼동 | 전략의 통제 범위가 달라짐 | 자사 역량과 시장·규제 변화를 분리 |
| 근거 없는 요인 나열 | 우선순위 판단이 어려움 | 요인별 출처·시점·영향을 기록 |
| 전략 유형만 제시 | 실행 책임과 성과 확인이 없음 | 과제·담당·검증 지표 지정 |

## Ⅴ. 기술사적 제언 — 전략 과제의 갱신 기준

| 판단 시점 | 확인할 증거 | 조치 |
|---|---|---|
| 과제 선정 | 전략을 뒷받침하는 내부 역량과 외부 변화 | 근거가 약한 과제 보류 |
| 시범 실행 | 고객 반응·비용·실행 가능성 | 가설 수정 또는 확대 |
| 환경 변화 | 규제·시장·경쟁 구도의 새 정보 | SWOT 요인과 과제 우선순위 재검토 |

연례 보고서 작성으로 끝내지 말고, 전략의 전제가 달라질 때 해당 과제의 우선순위를 다시 판단한다.
