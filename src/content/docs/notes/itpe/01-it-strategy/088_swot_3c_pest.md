## 지식 로드맵 내 현재 위치

IT 전략·관리 → 전략 분석 기법 → **경영환경 분석(SWOT·3C·PEST)**

## 30초 인출

- 본질: 경영환경 분석은 조직의 내부 역량과 외부 환경을 SWOT·3C·PEST로 나눠 파악해 전략 수립의 근거로 삼는 분석
- 메커니즘: PEST로 거시환경, 3C로 고객·경쟁자·자사를 살피고, 결과를 SWOT의 내부(강점·약점)와 외부(기회·위협) 요인으로 분류한 뒤 TOWS로 SO·WO·ST·WT 전략 대안 도출
- 통찰: SWOT 목록만 작성하면 요인이 급조되고 이후 전략에 쓰이지 않으므로 요인마다 PEST·3C의 근거 자료를 붙이고 TOWS 전략 대안과 실행 과제까지 연결

<details>
<summary>핵심 용어</summary>

- **경영환경 분석** : 조직의 내부 역량과 외부 환경을 체계적으로 파악해 전략 수립의 근거를 마련하는 분석
- **SWOT(Strengths, Weaknesses, Opportunities, Threats)** : 조직 내부의 강점·약점과 외부의 기회·위협을 네 범주로 정리하는 분석 기법
- **3C(Customer, Competitor, Company)** : 고객·경쟁자·자사 세 요소를 함께 살펴 경쟁우위를 판단하는 분석 기법. Ohmae의 전략 삼각형(strategic triangle)
- **PEST(Political, Economic, Social, Technological)** : 정치·경제·사회·기술 네 가지 외부 거시환경 요인을 분석하는 기법. 법률·환경 요인을 더한 확장형이 PESTLE
- **TOWS 매트릭스** : SWOT의 내부 요인과 외부 요인을 짝지어 SO·WO·ST·WT 전략 대안을 도출하는 Weihrich의 표
- **SO·WO·ST·WT 전략** : 강점으로 기회를 살리는 전략, 약점을 줄이며 기회를 살리는 전략, 강점으로 위협을 줄이는 전략, 약점과 위협을 함께 줄이는 전략

## 2~4교시 25점 답안

## Ⅰ. 경영환경 분석의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **경영환경 분석** 은 조직의 내부 역량과 외부 환경을 체계적으로 파악해 전략 수립의 근거를 마련하는 분석 |
| 목적 | 전략 대안을 도출할 환경 요인의 식별 |

## Ⅱ. 내부·외부 관점을 나눠 요인을 파악하는 세 기법의 특성

| 기법 | 특성 |
|---|---|
| **SWOT** | 내부 요인인 강점·약점과 외부 요인인 기회·위협을 네 범주로 정리 |
| **3C** | 고객·경쟁자·자사 세 요소를 통합해 지속 가능한 경쟁우위 판단 |
| **PEST** | 정치·경제·사회·기술의 외부 거시환경 요인 분석 |

## Ⅲ. 세 기법의 연계 구조와 SWOT 요인 분류

### 세 기법의 연계 구조

```text
외부 거시환경 ── PEST: 정치·경제·사회·기술
외부 시장 ────── 3C: 고객·경쟁자
내부 역량 ────── 3C: 자사
    ↓ 요인 분류
SWOT 네 범주: 강점·약점(내부) / 기회·위협(외부)
    ↓
TOWS 전략 대안: SO·WO·ST·WT
```

### SWOT 요인 분류 확대

```text
분석 요인
    ├─ 조직 내부 요인
    │     ├─ 유리 → 강점(Strengths)
    │     └─ 불리 → 약점(Weaknesses)
    └─ 조직 외부 요인
          ├─ 유리 → 기회(Opportunities)
          └─ 불리 → 위협(Threats)
```

## Ⅳ. 기법별 적용 조건·분석 방법과 TOWS 전략 대안

### 기법별 적용 조건과 분석 방법

| 기법 | 적용 조건 | 분석 방법 |
|---|---|---|
| PEST | 분석 범위(현재·미래), 정보 출처와 수집 담당의 사전 정의, 정기적 반복 | 구조화된 양식으로 정보 수집 → 중요도·위험 수준 표시 → 대응 방안 식별 |
| 3C | 고객·경쟁자·자사를 따로 보지 않고 통합해 판단 | 고객 세분화 → 경쟁자 대비 차별화 가능성 검토 → 자사의 우위 기능과 자원 배분 판단 |
| SWOT | 요인 목록의 근거 자료와 여러 구성원의 참여 | 요인을 네 범주로 분류한 뒤 TOWS로 전략 대안 조합 |

### TOWS 전략 대안

| 구분 | 기회(O) | 위협(T) |
|---|---|---|
| 강점(S) | SO: 강점과 기회를 모두 극대화 | ST: 강점을 극대화하고 위협을 최소화 |
| 약점(W) | WO: 약점을 최소화하고 기회를 극대화 | WT: 약점과 위협을 모두 최소화 |

## Ⅴ. 경영환경 분석의 한계와 방안

| 한계 | 방안 |
|---|---|
| SWOT 목록이 이후 전략 수립에 쓰이지 않고 분석으로 끝남 | TOWS로 SO·WO·ST·WT 전략 대안을 도출하고 실행 과제로 연결 |
| 요인 목록이 급하게 작성되거나 일부 구성원의 의견에 치우침 | 요인마다 PEST·3C의 근거 자료를 붙이고 여러 구성원이 참여해 중요도 표시 |
| PEST가 요인을 단순화하고 가정에 의존해 환경 변화에 뒤처짐 | 기준 시점을 기록하고 정기적으로 근거 자료를 갱신해 요인 재판정 |

## Ⅵ. 제언

SWOT 요인마다 PEST·3C의 근거 자료를 붙여 정리하고, TOWS 전략 대안과 실행 과제까지 이어 정기적으로 갱신

### 근거에서 실행 과제까지의 연결

```text
PEST·3C 근거 자료 (출처·수집 시점 명기)
    ↓
SWOT 요인 (S·W·O·T, 중요도 표시)
    ↓
TOWS 전략 대안 (SO·WO·ST·WT)
    ↓
선정한 대안의 실행 과제와 담당
```

### 정기 갱신 확대

```text
분석 결과 (기준 시점 기록)
    ↓
정기 점검: 요인의 근거 자료 갱신
    ├─ 변화 없음 → 결과 유지
    └─ 변화 있음 → 요인 재판정 → 전략 대안 재도출
```

| 구분 | SWOT 목록 작성으로 종료 | 제언: 근거·전략·갱신 연결 |
|---|---|---|
| 요인의 근거 | 구성원의 의견 | PEST·3C 근거 자료와 수집 시점 |
| 결과의 사용 | 요인 목록 | TOWS 전략 대안과 실행 과제 |
| 환경 변화 반영 | 다음 분석 때까지 없음 | 정기 점검에서 재판정 |
