## 연관 키워드

- A/B 테스트, 무작위 배정, 가설·주지표, 검정력
- 가드레일 지표, 표본비율 불일치(SRM)

## Ⅰ. A/B 테스트의 개요

- 핵심 요약 : 두 변형을 무작위 집단에 노출해 성과를 비교하는 무작위 대조 실험 방법.
- 개념 : **A/B 테스트** (A/B Test)는 제품 변경안 두 변형(A/B)을 사용자에게 **무작위 배정** (무작위 대조군·실험군 구성)으로 노출하고 사전 정의 지표의 차이를 비교하는 실험 방법.
- 배경 및 필요성 : 관찰 데이터의 상관 관계만으로는 변경이 지표 변화의 원인인지 판단 곤란 → 인과 근거 확보 필요.
- 주요 목적 : 전환율·사용자 경험 지표의 변경 효과를 신뢰 가능하게 추정하여 제품 의사결정의 위험 감소.

## Ⅱ. A/B 테스트의 특징 및 장점

- 핵심 요약 : 무작위화, 사전 설계, 표본 계획, 부작용 감시, 해석 기준이 인과 추론의 신뢰를 뒷받침.

1. 무작위 배정 : 대조군·실험군의 교란변수 기대 분포 균형 → 인과 추론의 근거 확보.
2. 사전 가설·주지표 : 검증할 지표와 기대 방향을 **주지표** (실험 성패를 판단하는 대표 지표)로 사전 정의 → 분석 계획의 명확화와 탐색적 오류 방지.
3. 표본크기·기간 설계 : **검정력** (Statistical Power, 실제 효과를 탐지할 확률)과 최소 탐지 효과 기준의 표본·기간 산정 → 표본 부족·조기 중단 오류 방지.
4. 가드레일 지표 : **가드레일 지표** (오류율·이탈률 등 주지표 외 감시 지표) 설정 → 주지표 개선의 대가로 발생하는 품질·신뢰 악화 탐지.
5. 결과 해석 : 효과크기·신뢰구간 중심 해석 → 통계 유의성과 실질적 의미의 구분.

## Ⅲ. A/B 테스트의 구조 (흐름)

- 핵심 요약 : 가설 정의부터 무작위 배정, 실행·품질 점검, 분석, 결정까지의 실험 수명주기.

```text
가설·주지표 정의
   ↓
변형안 구현 (A/B)
   ↓
사용자 무작위 배정·노출
   ↓
실험 실행·품질 점검 (SRM)
   ↓
효과 분석 (효과크기·신뢰구간)
   ↓
적용·확산 결정
```

- 배정 품질 : 배정 비율의 이상을 뜻하는 **표본비율 불일치** (SRM, Sample Ratio Mismatch) 점검으로 배정 시스템 오류 탐지.

```text
사용자 트래픽
   ↓ 무작위 배정
대조군 A    실험군 B
기존 경험   변경 경험
   ↓          ↓
주지표·가드레일 지표 비교
```

## Ⅳ. A/B 테스트와 사전-사후 비교 방식의 비교

- 핵심 요약 : A/B 테스트는 무작위화로 교란을 통제하고, 사전-사후 비교는 변경 전후 관측의 추세 확인 수단.

| 비교 축 | A/B 테스트 | 사전-사후 비교 방식 |
| --- | --- | --- |
| 비교 근거 | 동시기 무작위 두 집단 | 동일 대상의 변경 전후 관측 |
| 교란변수 | 무작위화로 기대 균형 | 시즌·추세 등의 혼재 |
| 인과 판단 | 강한 근거 | 혼란 효과 분리 곤란 |
| 구현 비용 | 배정·측정 인프라 필요 | 저비용·즉시 적용 |
| 적합한 상황 | 변경 효과의 사전 검증 | 변경 적용 후 추세 확인 등 보조 분석 |

## Ⅴ. A/B 테스트의 한계와 방안

- 핵심 요약 : 잘못된 결론, 배정 오류, 부작용 간과, 실험 피로를 사전 설계·품질 점검으로 일대일 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 잘못된 결론 | 표본 부족·중간 엿보기·다중비교 → 위양성 | 사전 설계(검정력·분석 계획) | 조기 중단·재현 실패 |
| 배정 오류 | 중복·교차 노출·비율 불일치 → 편향 | 실험 단위 고정·SRM 점검 | SRM·오염률 |
| 부작용 간과 | 주지표만 최적화 → 품질·신뢰 악화 | 가드레일·세그먼트별 점검 | 불만·이탈률 |
| 실험 피로 | 과도한 실험 수 → 사용자 경험 저하 | 실험 우선순위·노출 관리 | 실험 수·불만 접수 |

## Ⅵ. A/B 테스트에 대한 제언

- 핵심 요약 : 실험 제도화, 표준 보고, 공통 인프라로 실험 문화의 신뢰 기반을 완성하는 상위 수준의 제안.

1. 제품 책임자 : 실험 등록·중단 기준의 제도화와 실험 우선순위 관리.
2. 데이터 분석 조직 : 효과크기·신뢰구간·가드레일을 함께 보고하는 표준 보고체계 운영.
3. 플랫폼 엔지니어 : 무작위 배정·노출 관리·SRM 점검 인프라의 공통 플랫폼 유지.

## Ⅶ. 결론

- 핵심 요약 : A/B 테스트는 무작위화에 기반해 변경의 인과 근거를 확보하는 실험 체계.
- 올바른 설계·측정·해석이 전제될 때 제품 의사결정의 신뢰 성립.
