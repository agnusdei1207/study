## 30초 인출

- 본질: ISO 31000은 조직의 목표에 영향을 미치는 불확실성을 관리하기 위한 원칙·프레임워크·프로세스 지침.
- 메커니즘: 원칙의 설계 기준 제시, 프레임워크의 조직 내재화, 프로세스의 위험 평가·처리와 결과 검토.
- 판정 기준: 조직이 정한 위험 기준에 따른 잔여 위험 평가와 수용·추가 처리 결정의 기록.
- 통찰: 한계: 위험 목록만 작성하고 의사결정에 반영하지 못함 → 방안: 결정마다 위험 책임자·처리방안·잔여위험 수용자를 기록

<details>
<summary>핵심 용어</summary>

- **ISO 31000** : 조직의 위험관리를 위한 원칙·프레임워크·프로세스를 제시하는 국제 지침.
- **Risk(위험)** : 불확실성이 목표에 미치는 영향으로, 긍정적·부정적 편차를 모두 포함하는 개념.
- **Risk Assessment(위험평가)** : 위험을 식별·분석·평가해 중요도와 처리 필요성을 판단하는 과정.
- **Risk Treatment(위험처리)** : 위험을 다루기 위한 대안을 선택하고 실행하는 과정.
- **Risk Owner(위험 책임자)** : 특정 위험의 관리와 대응을 책임지는 사람 또는 조직 단위.
- **Risk Criteria(위험 기준)** : 위험의 중요도와 수용 가능성을 비교·판단하기 위해 정한 조건.
- **Residual Risk(잔여 위험)** : 위험처리 뒤에도 남아 있는 위험.

## 2~4교시 25점 답안

## Ⅰ. ISO 31000의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **ISO 31000** 은 조직이 목표에 미치는 불확실성의 영향을 관리하기 위한 원칙·프레임워크·프로세스 지침 |
| 목적 | **목표 달성 가능성 제고 · 기회·위협 식별 · 처리 자원 배분** |

## Ⅱ. ISO 31000의 특징

| 특징 | 의미 |
|---|---|
| 목표와 위험 연결 | 불확실성의 긍정·부정 영향을 의사결정에 반영 |
| 조직 맞춤 적용 | 동일한 목록보다 조직 상황과 위험 기준이 중요 |
| 반복 검토 | 위험 처리 뒤 잔여 위험과 변화 신호를 다시 평가 |

ISO 공식 목록에서 2018판은 현재 발행판이며 후속판은 개발 중이다. 초안과 발행판을 구분해 적용한다.

## Ⅲ. 원칙·프레임워크·프로세스 체계와 위험관리 절차

```text
조직 목표·위험 기준
      ↓
원칙(판단 방향) → 프레임워크(책임·자원·통합)
                         ↓
                 프로세스(평가·처리·검토)
                         └→ 결과·학습을 경영 판단에 환류
```

### 원칙·프레임워크·프로세스의 연결

> 원칙은 관리 조건, 프레임워크는 조직 내 기반, 프로세스는 개별 의사결정 절차이며 세 층의 연결은 현장 판단과 경영 목표의 연계.

```text
ISO 31000 위험관리
    ├─ 원칙: 가치 창출·보호의 기준
    ├─ 프레임워크: 리더십·조직 내 통합
    └─ 프로세스: 식별·분석·평가·처리

프로세스 결과 → 프레임워크 평가·개선
```

### 위험평가·처리·환류 프로세스

```text
범위·상황·위험 기준 설정
    ↓
위험 식별 → 분석 → 평가
    ↓
위험 처리 대안 선택·실행
    ↓
잔여 위험을 기준과 비교
    ├─ 허용 가능 → 수용·모니터링
    └─ 허용 불가 → 추가 처리·재평가
```

이해관계자와의 의사소통·자문, 전 단계의 모니터링·검토, 판단 근거와 처리 결과의 기록·보고를 병행한다.

## Ⅳ. 원칙·프레임워크·프로세스의 역할 비교

| 구분 | 역할 |
|---|---|
| **원칙** | 통합·구조화·맞춤화·포괄성·동적 대응·최선의 정보·인적·문화적 요인·지속 개선으로 관리의 방향을 제시 |
| **프레임워크** | 리더십과 의지 아래 위험관리를 조직에 통합하고 설계·실행·평가·개선 |
| **프로세스** | 범위·상황·기준 설정, 위험평가, 위험처리, 모니터링·검토, 의사소통·기록 |

- 관계: 프레임워크의 중심에서 책임·권한·자원을 부여하고 프로세스 결과를 개선에 반영하는 **Leadership and Commitment**
- 적용: 조직의 목적·내외부 상황·이해관계자에 맞춘 조정, 경영·전략·계획·보고·문화와의 통합

## Ⅴ. 한계와 방안

> 표준을 일회성 평가로 축소할 때 남는 리스크 목록, 목표·Risk Owner·판정 기준·변화 신호 간 연결 필요.

| 한계 | 방안 |
|---|---|
| 목표와 리스크 목록 단절 | 목표별 리스크·Risk Owner를 연결해 의사결정 책임 명확화 |
| 정적 연례 평가 | 변화 신호·모니터링 주기를 정해 변동 리스크 반영 |
| 처리 후 종료 간주 | 잔여 리스크 재평가·승인으로 수용 여부 판정 |

## Ⅵ. 제언 — 의사결정에 위험 검토 내재화

중요 투자·사업 승인 자료에 목표별 위험·책임자·처리 대안·잔여 위험 수용 권한을 함께 기록해 결정의 근거로 사용한다.
