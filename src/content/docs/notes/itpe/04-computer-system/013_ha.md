## 연관 키워드
- 고가용성, MTBF, MTTR, 이중화, 장애조치, SPOF, RTO

## Ⅰ. 고가용성의 개요
- 핵심 요약 : 고가용성은 장애에도 서비스 중단을 최소화해 합의된 수준으로 지속 제공하는 시스템 설계 목표.
- 개념 : **고가용성**(High Availability)은 장애 탐지·전환·복구 절차로 서비스 가용 시간을 높이는 속성.
- 배경 및 필요성 : 구성요소 고장은 피할 수 없으며 중단이 업무·안전·매출에 영향을 줌.
- 목적 : 서비스 수준 목표에 맞춰 장애 영향과 복구 시간을 제한.

## Ⅱ. 구성요소 및 지표
- 핵심 요약 : 중복화·장애 감지·자동 절체·복구 검증으로 단일 장애점 제거.
- MTBF(Mean Time Between Failures)와 MTTR(Mean Time To Repair)은 가용성 분석의 대표 지표.
- 이중화는 컴퓨팅·네트워크·전원·데이터 경로에 적용.
- 장애조치(failover)는 건강 상태를 감지해 대기 자원에 트래픽 전환.
- 목표 가용성은 시스템 경계와 측정 기간·제외 조건이 명확해야 함.

## Ⅲ. 장애조치 흐름
- 핵심 요약 : 헬스 체크가 장애를 감지하고 조정자가 대체 인스턴스로 트래픽을 이동.
```text
주 노드·경로
  ↓ heartbeat·헬스 체크
장애 판정·quorum 확인
  ↓ fencing·승격
대기 노드 활성화
  ↓ 라우팅·서비스 복구
```
```text
장애 발생 → 감지 → 판단
           ↓
대체 자원 승격 → 데이터 정합성 확인
           ↓
서비스 복구·원인 분석
```

## Ⅳ. 가용성 구성 비교
- 핵심 요약 : 능동-수동은 자원 효율, 능동-능동은 처리량과 빠른 전환에 유리하나 동기화 부담.
| 비교 축 | Active-Passive | Active-Active |
| --- | --- | --- |
| 평시 자원 | 대기 용량 보유 | 동시 서비스 처리 |
| 절체 | 승격·전환 필요 | 일부 노드 장애 분산 |
| 복잡도 | 데이터 승격·split-brain | 상태 동기화·일관성 |
| 활용 | 단순 복구 경로 | 확장·지역 분산 |

## Ⅴ. 한계와 방안
- 핵심 요약 : 공통 장애와 잘못된 장애 판정은 이중화의 이점을 무력화.
| 한계 | 원인·영향 | 대응 |
| --- | --- | --- |
| SPOF | 공유 전원·네트워크 | 독립 장애 도메인 |
| split-brain | 네트워크 분할 | quorum·fencing |
| 미검증 절체 | 구성 오류·데이터 불일치 | 정기 장애조치 훈련 |
| 백업 오인 | 복구 가능한 복제본 부재 | 별도 백업·복원 검증 |

## Ⅵ. 설계 제언
- 핵심 요약 : 서비스 책임자는 업무 영향에 맞춰 RTO·RPO·가용성 목표와 장애 시험을 정의.
- 모니터링 임계치, 자동 전환 승인, 재전환 조건, 운영자 개입 절차를 runbook에 포함.

## Ⅶ. 결론
- 핵심 요약 : 고가용성은 구성요소 중복만이 아니라 탐지·전환·복구까지 검증한 서비스 속성.
- 목표와 장애 도메인 기반 설계·훈련이 지속 서비스의 근거.
