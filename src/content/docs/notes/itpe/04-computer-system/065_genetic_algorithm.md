## 연관 키워드

- 유전 알고리즘, Genetic Algorithm, 염색체 인코딩, 적합도, 선택, 교차, 돌연변이
- 엘리티즘, 조기 수렴, 아일랜드 모델, 멤틱 알고리즘, NP-Hard

## Ⅰ. 유전 알고리즘의 개요

- 핵심 요약 : 자연선택과 유전 연산을 모방해 해의 집단을 세대마다 개량해 나가는 확률적 최적화 기법.
- 개념 : 생물 진화의 자연선택 원리를 모방하여 후보 해의 집단을 세대마다 반복 개량해 최적해에 가까운 해를 얻는 확률적 탐색 기법 (**유전 알고리즘**, Genetic Algorithm, GA).
- 배경 및 필요성 : 후보 조합이 폭발적으로 늘어나는 **NP-Hard** (Non-deterministic Polynomial-time hard, 다항 시간의 정확 해법이 알려지지 않은 문제군) 조합 최적화 문제는 완전 탐색 비용이 현실적이지 않음. 존 홀랜드(John Holland)의 적응 시스템 연구에서 집단 기반 진화 탐색으로 체계화됨.
- 주요 목적 : 모집단 기반의 다점 병렬 탐색으로 지역 최적해에 갇힘을 피하고, 탐색(Exploration)과 활용(Exploitation)의 균형 속에서 실용적 준최적해를 확보하는 것.

## Ⅱ. 유전 알고리즘의 특징 및 장점

- 핵심 요약 : 염색체 인코딩으로 만든 탐색 공간 위에서 적합도 기반 선택과 유전 연산이 수렴 속도와 다양성을 함께 확보하는 구조.

1. 표현 구조 설계 : 후보 해를 이진 문자열, 실수 벡터, 순열 형태의 **염색체** (Chromosome)로 바꾸는 **염색체 인코딩** (Encoding) → 문제 구조에 맞춘 탐색 공간 형성.
2. 품질 기준 정량화 : 목적 함수 값을 개체별 생존 기회로 변환하는 **적합도** (Fitness) 평가 → 해 품질의 객관적 비교 기준 확립.
3. 우성 전달 : 적합도가 높은 개체를 부모로 우선 선발하는 **선택** (Selection) → 우수 유전자의 세대 간 전달과 수렴 속도 향상.
4. 재조합 탐색 : 부모 유전자를 섞어 새 조합을 만드는 **교차** (Crossover) → 부분 해의 결합을 통한 새로운 영역 탐색.
5. 다양성 유지 : 낮은 확률로 유전자 값을 무작위로 바꾸는 **돌연변이** (Mutation) → 고정 패턴 해소와 **조기 수렴** (Premature Convergence, 다양성이 일찍 사라져 나쁜 해에 고정되는 현상) 방지.
6. 우수 해 보존 : 최우수 개체를 차세대에 그대로 남기는 **엘리티즘** (Elitism) → 진화 과정에서의 우수 해 소실 방지.

## Ⅲ. 유전 알고리즘의 구조 (흐름)

- 핵심 요약 : 초기 집단 생성부터 평가, 선택·유전 연산, 차세대 구성까지를 세대 단위로 반복하는 루프 구조.
- 구성 요소 : 염색체 집합인 모집단, 적합도 평가기, 선택·교차·돌연변이 연산자, 최대 세대 수와 목표 적합도 같은 종료 조건.

```text
[ 세대 진화 루프 ]

초기 모집단 생성 (무작위 염색체)
        ↓
적합도 평가 (목적 함수)
        ↓
종료 조건 판정 ──(충족)──> 최적 개체 출력
        ↓ (미충족)
선택 → 교차 → 돌연변이
        ↓
차세대 모집단 구성 (엘리티즘 포함)
        ↓
적합도 평가로 복귀 (세대 반복)
```

```text
[ 연산자의 역할 분담 ]

선택 : 우수 개체 집중 (활용)
        ↓
교차 : 유전자 재조합 (새 조합 탐색)
        ↓
돌연변이 : 무작위 변이 (다양성 유지)
        ↓
활용과 탐색의 균형이 해 품질 결정
```

## Ⅳ. 유전 연산자 기법의 비교

- 핵심 요약 : 선택·교차·돌연변이 각 자리의 기법 선택이 수렴 속도와 다양성의 균형을 좌우하는 구조.
- 선택 기준 : 해 표현형의 순서 의존성, 요구 다양성 수준, 구현 복잡도를 기준으로 연산자를 고른다.

| 연산자 | 기법 | 동작 특성 | 고려 사항 |
| :--- | :--- | :--- | :--- |
| 선택 | 룰렛 휠 선택 | 적합도 비례 확률로 부모 선발 | 구현이 간단하나 우세 개체 편중 위험 |
| 선택 | 토너먼트 선택 | 무작위 K개 중 최우수 개체 선발 | K 조절로 선택 압력 튜닝 용이 |
| 교차 | 일점·다점 교차 | 교차점 기준 유전자 블록 교환 | 이진·실수 인코딩에 적합 |
| 교차 | 순열 교차 (**PMX**, Partially Mapped Crossover) | 순서·중복 제약을 지키며 부분 교환 | 순서형 문제(순회 경로)에 필수 |
| 돌연변이 | 비트 반전 | 이진 유전자를 0과 1 사이에서 반전 | 변이율 과다 시 무작위 탐색화 |
| 돌연변이 | 교환·삽입 변이 | 순열의 두 위치를 교환·이동 | 순열 인코딩의 다양성 유지 수단 |

## Ⅴ. 유전 알고리즘의 한계와 방안

- 핵심 요약 : 조기 수렴, 파라미터 민감성, 평가 비용을 다양성 설계, 튜닝 체계, 평가 최적화로 일대일 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 조기 수렴 | 소수 우세 개체가 모집단을 지배해 다양성 소실 → 전역 해 도달 실패 | 수렴 상태에 따라 변이율을 올리는 적응형 제어, 서브 집단 간 이주를 허용하는 **아일랜드 모델** (Island Model) | 모집단 다양성 지표 |
| 파라미터 민감성 | 개체 수·교차율·변이율 설정에 따라 성능 편차가 큼 | 실험 계획 기반 튜닝, 파라미터 자동 탐색 도구 연계 | 설정별 해 품질 편차 |
| 적합도 평가 비용 | 세대마다 전체 개체 평가로 시뮬레이션 기반 문제에서 시간 폭증 | 평가 병렬화, 근사 평가 모델 활용, 국소 탐색 결합형 **멤틱 알고리즘** (Memetic Algorithm) | 세대당 평가 시간 |

## Ⅵ. 유전 알고리즘에 대한 기술사적 제언

- 핵심 요약 : 연산자 자산의 표준화, 다중 실행 기반 평가 문화, 검수 제도로 유전 알고리즘 적용을 조직 역량으로 정착.

1. 표준화 : 최적화 시스템 개발 조직은 검증된 인코딩·연산자 라이브러리와 파라미터 기본값을 사내 표준 자산으로 등록해 과제별 중복 개발을 방지하는 체계 구축.
2. 평가 문화 : 수행 조직은 단일 실행 결과 대신 서로 다른 초기 집단을 둔 다중 실행의 해 품질 분포를 성능 보고의 기준으로 채택.
3. 검수 제도 : 사업 발주 기관은 휴리스틱 최적화 모듈의 검수 기준에 시드(seed) 기록·환경 고정 등의 재현성 절차 포함.

## Ⅶ. 결론

- 핵심 요약 : 유전 알고리즘은 집단 진화 반복으로 NP-Hard 조합 최적화의 실용적 준최적해를 얻는 탐색 체계.
- 해 품질은 인코딩·연산자 설계와 다양성 관리에 좌우되므로 문제 특성에 맞춘 설계가 적용의 전제 조건.
