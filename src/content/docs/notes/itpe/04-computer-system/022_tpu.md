## Ⅰ. TPU(Tensor Processing Unit)의 개요

- **개념** : 구글이 대규모 딥러닝 텐서(Tensor) 연산 및 딥신경망 학습·추론을 가속화하기 위해 독자 개발한 ASIC(Application-Specific Integrated Circuit) 기반의 인공지능 전용 프로세서.
- **배경 및 필요성** : 엔비디아 GPU의 그래픽 레거시와 독점적 CUDA 종속성을 탈피하고, 초대형 언어 모델 및 추천 시스템 워크로드에 대해 와트당/달러당 최고의 연산 성능을 자체 클라우드 인프라에 확보하기 위해 탄생함.
- **핵심 목적** : 2차원 시스톨릭 어레이 기반의 행렬 곱셈 연산 극대화, 전용 인터커넥트(ICI) 및 광 스위치(OCS)를 통한 수천 대 규모의 단일 슈퍼컴퓨터(Pod) 확장성 달성.

## Ⅱ. TPU(Tensor Processing Unit)의 핵심 아키텍처 및 동작 메커니즘

TPU는 매트릭스 곱셈 유닛(MXU), 벡터 처리 유닛(VPU), 고대역폭 HBM, 그리고 노드 간 전용 초고속 링크인 ICI(Inter-Chip Interconnect)를 통합하여 3D 토러스(3D Torus) 클러스터 구조로 동작함.

```text
[ 구글 TPU v4 / v5p 칩 및 Pod 아키텍처 ]

+---------------------------------------------------------------+
| TPU Core                                                      |
|                                                               |
|  +----------------------------------------------------------+ |
|  | Matrix Multiply Unit (MXU: 128x128 Systolic Array BF16)  | |
|  +----------------------------------------------------------+ |
|  | Vector Processing Unit (VPU: 활성화 함수 및 요소별 연산) | |
|  +----------------------------------------------------------+ |
|  | Scalar Unit (제어 흐름 및 주소 계산)                      | |
|  +----------------------------------------------------------+ |
+---------------------------------------------------------------+
       │                                                │
       ▼                                                ▼
+------------------------------+        +------------------------------+
| HBM3 Memory (고대역 메모리)  |        | Inter-Chip Interconnect (ICI)|
+------------------------------+        +------------------------------+
                                                        │
                                                        ▼
+-----------------------------------------------------------------------+
| Optical Circuit Switch (OCS) 기반 동적 광 토폴로지 재구성            |
|   - 3D Torus 네트워크를 소프트웨어 정의 방식으로 유연하게 분할        |
|   - 장애 칩 발견 시 광 신호 우회를 통해 무중단 Pod 가동               |
+-----------------------------------------------------------------------+
```

- **매트릭스 곱셈 유닛(MXU)** : 128×128 크기의 2D 시스톨릭 어레이 구조로 클럭당 16,384개의 곱셈-누적(MAC) 연산을 저전력으로 처리.
- **Bfloat16(BF16) 표준 도입** : FP32와 동일한 지수부(8-bit)를 유지하여 언더플로우/오버플로우 없이 FP16 대비 훈련 안정성을 대폭 개선.
- **ICI(Inter-Chip Interconnect)** : 전통적 TCP/IP 네트워크 스택을 배제하고 칩 간 직접 연결되는 테라비트급 저지연 통신망 구축.
- **OCS(Optical Circuit Switch)** : 광 스위치를 통해 팟(Pod) 내 토폴로지를 소프트웨어로 동적 재구성하여 장애 격리 및 모델 맞춤형 통신망 제공.

## Ⅲ. TPU(Tensor Processing Unit)의 세부 구성 요소 및 비교 분석

| 비교 항목 | Google TPU v5p | NVIDIA H100 GPU | 범용 Server CPU |
|---|---|---|---|
| **하드웨어 유형** | 딥러닝 텐서 전용 ASIC | 대규모 병렬 GPGPU 가속기 | 범용 마이크로프로세서 |
| **주요 연산 코어** | 대규모 시스톨릭 어레이 MXU | 스트리밍 멀티프로세서 + 텐서 코어 | 범용 AVX-512 / AMX 코어 |
| **인터커넥트 기술** | 전용 ICI + OCS (3D Torus) | NVLink 4 + NVSwitch (트리 토폴로지) | QPI / UPI / PCIe 버스 |
| **확장 규모 (Pod)** | 최대 8,960 칩 단일 클러스터 | 최대 수만 개 GPU 클러스터 (IB망) | 수십~수백 노드 클러스터 |
| **소프트웨어 툴체인** | XLA (Accelerated Linear Algebra) | CUDA, TensorRT, Triton | 표준 C/C++, OpenMP, MKL |

- TPU는 구글 클라우드 환경에 최적화되어 제미나이(Gemini) 등 초대형 모델 학습에서 최고의 가성비를 제공하나, 온프레미스 도입이 불가능한 클라우드 독점 기술임.

## Ⅳ. TPU(Tensor Processing Unit)의 주요 한계점 및 해결 방안

- **구글 클라우드 플랫폼(GCP) 종속성(Lock-in)** :
  - **한계점** : TPU 하드웨어는 온프레미스 구매가 불가능하며 오직 GCP 콘솔을 통해서만 임대 가능하여 하이브리드 인프라 구축 제약.
  - **해결 방안** : PyTorch/XLA 및 JAX 표준 프레임워크를 기반으로 코드를 작성하여 GPU 클러스터와 TPU 간의 상호 전환성 유지.
- **비표준 연산자 등장 시 XLA 컴파일러 병목** :
  - **한계점** : 텐서플로우/JAX 그래프에 최적화되지 않은 커스텀 Python 연산자 사용 시 CPU-TPU 간 빈번한 텐서 복사로 인한 극심한 지연.
  - **해결 방안** : XLA 컴파일러가 융합(Fusion)할 수 있도록 벡터화된 표준 텐서 연산자로 재작성 및 컴파일러 프로파일링.
- **대규모 Pod 환경에서의 단일 장애 파급 위험** :
  - **한계점** : 수천 개의 칩이 3D 토러스로 직결된 환경에서 단일 링크 장애 발생 시 전체 팟의 학습 파이프라인 중단 리스크.
  - **해결 방안** : OCS 광 스위치를 활용하여 불량 칩렛을 실시간 바이패스하고 가용 슬라이스로 자동 리라우팅.

## Ⅴ. TPU(Tensor Processing Unit) 적용 및 발전을 위한 기술사적 제언

- **JAX 프레임워크 기반 AI 엔지니어링 역량 내재화** : 대규모 분산 모델 병렬화(TP, PP, DP)를 함수형 변환으로 직관화하는 JAX/Flax 기술을 조기 도입하여 TPU 생산성 극대화 필요.
- **AI 훈련과 추론 인프라의 TCO 분리 최적화** : 거대 모델의 사전 학습은 전파 대역폭이 우수한 TPU Pod를 활용하고, 엣지 서빙은 범용 GPU 및 NPU로 분리하는 티어링 전략 권장.
- **광 네트워킹(Optical Interconnect) 기술 진화 주시** : TPU의 OCS 기술은 향후 데이터센터 백본망의 차세대 표준이 될 것이므로 광 스위칭 및 CPO(Co-Packaged Optics) 로드맵 검토 필수.
