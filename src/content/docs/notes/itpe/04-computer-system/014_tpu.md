## 연관 키워드
- TPU, Tensor Processing Unit, 행렬 곱셈, systolic array, AI 가속기

## Ⅰ. TPU의 개요
- 핵심 요약 : TPU는 신경망의 텐서 연산에 특화된 Google 설계 AI 가속기 계열.
- 개념 : **TPU**(Tensor Processing Unit)는 딥러닝의 대규모 행렬·벡터 계산을 효율화하도록 설계된 ASIC 기반 가속기.
- 배경 및 필요성 : 신경망 추론·학습의 반복적 행렬 계산이 데이터센터 연산·전력의 큰 부분을 차지.
- 목적 : 지원 모델과 워크로드에서 높은 처리량과 에너지 효율 제공.

## Ⅱ. 구조와 특성
- 핵심 요약 : 행렬 곱셈 유닛과 메모리·컴파일 스택의 협력으로 텐서 계산을 가속.
- Systolic array 형태의 행렬 연산 유닛은 데이터 흐름을 규칙적으로 처리.
- 고대역폭 메모리와 연산 장치 연결은 대형 텐서 공급을 지원.
- XLA 컴파일러·런타임 등 소프트웨어 스택이 그래프를 장치 실행에 매핑.
- 세대·서비스별 메모리·정밀도·상호연결 특성은 다르므로 해당 제품 명세 확인.

## Ⅲ. 실행 흐름
- 핵심 요약 : 프레임워크 연산 그래프가 컴파일되어 장치 메모리와 행렬 유닛에서 실행.
```text
TensorFlow·JAX 모델
  ↓ 그래프 캡처·컴파일
XLA 최적화·TPU 실행 코드
  ↓ 입력·가중치 배치
행렬 유닛 실행 → 결과
```
```text
입력 텐서 → HBM
  ↓
행렬 곱셈 배열
  ↓
누산·활성화 → 출력 텐서
```

## Ⅳ. TPU와 GPU 비교
- 핵심 요약 : TPU는 특정 텐서 연산·소프트웨어 조합에 최적화되고 GPU는 더 넓은 범용 병렬 생태계.
| 축 | TPU | GPU |
| --- | --- | --- |
| 설계 초점 | 신경망 텐서 연산 | 범용 병렬 계산·그래픽 |
| 소프트웨어 | 주로 Google Cloud·XLA 경로 | 다양한 프레임워크·벤더 생태계 |
| 장점 | 특정 워크로드 효율 | 유연성·범용성 |
| 선택 기준 | 모델 적합·클라우드 운영 | 호환성·배포 위치 |

## Ⅴ. 한계와 방안
- 핵심 요약 : 모델 지원·컴파일 제약·클라우드 종속이 적합성을 제한.
| 한계 | 원인·영향 | 대응 |
| --- | --- | --- |
| 미지원 연산 | 그래프 변환 불가·폴백 | 컴파일 단계 사전 점검 |
| 장치 종속 | 런타임·SDK 특화 | 이식 경로·운영비 평가 |
| 통신 병목 | 분산 학습 상호연결 | 샤딩·통신 프로파일링 |
| 성능 추정 오류 | 배치·입력 크기 차이 | 실사용 워크로드 벤치마크 |

## Ⅵ. 활용 제언
- 핵심 요약 : 모델팀은 지원 연산·정확도·컴파일 성공·비용을 기준으로 TPU 실증.
- 분산 학습은 장치 수 증가뿐 아니라 통신 대역폭과 동기화 비용까지 측정.

## Ⅶ. 결론
- 핵심 요약 : TPU는 텐서 계산에 특화된 AI ASIC으로 하드웨어와 소프트웨어 스택의 정합성이 중요.
- 모델 적합성과 배포 환경을 포함한 종단간 평가로 도입 결정.
