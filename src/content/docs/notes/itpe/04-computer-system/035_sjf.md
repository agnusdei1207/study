## 연관 키워드

- SJF(Shortest Job First), SRTF(Shortest Remaining Time First), CPU 버스트(CPU Burst)
- 평균 대기 시간(Average Waiting Time), 호송 효과(Convoy Effect), FCFS(First-Come First-Served)
- 지수 평활법(Exponential Averaging), 기아(Starvation), 에이징(Aging), HRRN(Highest Response Ratio Next)

## Ⅰ. SJF 스케줄링의 개요

- 핵심 요약 : **SJF** (Shortest Job First)는 실행 시간이 가장 짧은 작업에 CPU (Central Processing Unit)를 우선 배정해 **평균 대기 시간** (Average Waiting Time)을 최소화하는 스케줄링 알고리즘.
- 개념 : 준비 큐의 작업 중 예상 실행 시간, 즉 **CPU 버스트** (CPU Burst)가 최소인 프로세스를 먼저 실행하는 기법으로, 비선점형 SJF와 선점형 SRTF로 확장됨.
- 배경 및 필요성 : 도착 순서 기준의 **FCFS** (First-Come First-Served)에서 긴 작업이 준비 큐를 길게 점유해 짧은 작업이 뒤에 줄서는 **호송 효과** (Convoy Effect)가 대기 시간을 키우는 문제.
- 주요 목적 : 평균 대기 시간의 최소화, 짧은 작업의 신속한 완료를 통한 처리량과 응답성 향상.

## Ⅱ. SJF 스케줄링의 특징 및 장점

- 핵심 요약 : 짧은 작업 우선 배정이 이론상 최소 평균 대기 시간이라는 최적성과 빠른 응답이라는 장점으로 연결됨.

1. 평균 대기 시간 최소화 근거 : 각 작업의 대기 시간은 앞서 실행된 작업들의 실행 시간 합으로 결정되므로, 짧은 작업을 앞세우면 대기 시간의 누적이 최소가 되는 구조 → 주어진 작업 집합에서 비선점 방식 가운데 이론상 최소 평균 대기 시간 확보.
2. 선점형 변형 : **SRTF** (Shortest Remaining Time First)는 실행 중인 작업보다 남은 시간이 짧은 작업이 도착하면 즉시 전환하는 방식 → 짧은 작업의 응답 지연 추가 감소 효과.
3. 버스트 예측 : 실제 실행 전에는 다음 버스트를 알 수 없으므로 **지수 평활법** (Exponential Averaging)으로 최근 실측과 이전 예측의 가중 평균을 계산 → 예측 기반 운용으로 SJF의 실용성 확보.
4. 처리량·응답성 개선 : 짧은 작업이 먼저 완료되어 단위 시간당 완료 작업 수 증가 → 대화형 환경의 체감 반응성 향상.
5. 기아 완화 변형 : 대기 시간을 우선순위 산식에 반영하는 **HRRN** (Highest Response Ratio Next) 방식이 SJF 계열의 기아 완화 변형으로 제안됨 → 긴 작업의 대기 보상 효과.

## Ⅲ. SJF 스케줄링의 구조 (흐름)

- 핵심 요약 : 준비 큐에서 예상 버스트가 최소인 작업을 선택해 실행하고, 지수 평활법으로 다음 버스트 예측값을 갱신하는 순환 구조.

```text
[ SJF 실행 선택 흐름 ]

새 작업의 준비 큐 도착
   ↓
예상 버스트 시간 비교
   ↓
최소 예상 버스트 작업 선택
   ↓
CPU 배정과 실행 완료
   ↓
지수 평활법으로 예측값 갱신
```

```text
[ 지수 평활법 계산 구조 ]

직전 예측치와 직전 실측 버스트
   ↓ 가중 평균
다음 버스트 예측값 산출
   ↓
예측값 = a * 실측 + (1 - a) * 직전 예측
   ↓
a : 최근 실측의 반영 비율 (0 ~ 1)
```

- 구성요소 : 준비 큐, 작업별 예상 버스트 정보, 최소 버스트 선택 기준, 예측값 갱신 모듈로 구성.
- 선점형 SRTF의 확장 : 비선점형은 실행 시작 후 중단이 없고, 선점형은 새 작업 도착 시점마다 남은 시간을 재비교해 배정 대상을 다시 고름.

## Ⅳ. SJF 계열 방식의 비교

- 핵심 요약 : 선점 여부와 선택 기준, 기아 위험, 운영 부담이 방식마다 달라 환경에 맞는 변형 선택 필요.

| 비교 항목 | FCFS | 비선점형 SJF | 선점형 SRTF | HRRN |
| --- | --- | --- | --- | --- |
| 선점 여부 | 비선점 | 비선점 | 선점 | 비선점 |
| 선택 기준 | 도착 순서 | 예상 버스트 최소 | 남은 시간 최소 | 응답률 최대 |
| 평균 대기 시간 | 호송 효과로 증가 | 짧음 | 이론상 최소 | 양호 |
| 기아 위험 | 없음 | 긴 작업 발생 가능 | 긴 작업 심각 | 에이징으로 억제 |
| 운영 부담 | 낮음 | 버스트 예측 필요 | 잦은 문맥 교환 | 우선순위 재계산 |

- 응답률 정의 : (대기 시간 + 예상 실행 시간) ÷ 예상 실행 시간으로 계산되며, 대기가 길어질수록 커져 기아를 완화하는 지표.
- 선택 기준 : 예상 실행 시간 정보의 신뢰도, 기아 허용 여부, 문맥 교환 비용의 감수 범위에 따라 방식을 선택.

## Ⅴ. SJF 스케줄링의 한계와 방안

- 핵심 요약 : 긴 작업의 기아, 예측 오차, 선점 비용을 에이징, 적응적 예측, 실행 유예로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 긴 작업의 **기아** (Starvation) | 짧은 작업의 지속 도착 → 긴 작업의 무기한 대기 | **에이징** (Aging)으로 대기 시간에 비례한 우선순위 상승, HRRN 채택 | 최대 대기 시간, 작업별 대기 편차 |
| 버스트 예측 오차 | 입출력·분기에 따른 실행 시간 변동 → 예측과 실측의 괴리 | 지수 평활 가중치의 적응적 조정, 실행 이력 반영 | 예측 오차율 |
| 선점형의 전환 비용 | 짧은 작업의 빈번한 도착 → 문맥 교환 누적으로 유효 연산 감소 | 최소 실행 보장 시간을 두어 선점 유예 | 문맥 교환 횟수 |

## Ⅵ. SJF 스케줄링에 대한 기술사적 제언

- 핵심 요약 : 작업 크기 정보가 있는 환경의 SJF 적용과 기아 방지 장치의 결합이 현실적 적용 방향.

1. 배치 처리 운영 조직이 작업 제출 시 예상 실행 시간을 메타데이터로 받아 짧은 작업 우선 배치 정책을 적용하고, 장기 대기 작업의 상한을 두어 기아 방지.
2. 서비스 개발 조직이 짧은 요청과 긴 요청의 실행 풀을 분리해 긴 작업이 큐를 점유하는 호송 효과 구조를 차단.
3. 플랫폼 설계 조직이 실행 이력 기반 예측과 에이징 정책을 스케줄러 설계 표준에 포함해 이론적 최적성과 공정성의 균형 확보.

## Ⅶ. 결론

- 핵심 요약 : SJF는 평균 대기 시간 최소라는 이론적 최적성을 지닌 스케줄링 기준.
- 시사점 : 버스트 예측과 기아 방지 장치를 갖춘 형태로 적용할 때 이론상 장점이 실제 시스템의 성능 이득으로 전환되는 구조.
