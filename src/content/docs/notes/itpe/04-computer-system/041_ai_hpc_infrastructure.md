## 연관 키워드

- AI/HPC 인프라, GPU 클러스터, NVLink, NVSwitch, InfiniBand, RoCE v2, RDMA
- SHARP, GPUDirect Storage, All-Reduce, 병렬 파일시스템, 스트래글러
- 체크포인트, 스케일업·스케일아웃, D2C 액체냉각, MFU, PUE

## Ⅰ. AI 학습·추론 고성능 컴퓨팅 인프라의 개요

- 핵심 요약 : 대규모 인공지능 학습과 과학 연산을 위해 가속기, 네트워크, 스토리지, 냉각을 하나의 체계로 통합 설계한 전용 컴퓨팅 기반.
- 개념 : 그래픽 처리 장치(GPU, Graphics Processing Unit) 클러스터, 무손실 상호연결망, 병렬 파일시스템, 고밀도 냉각을 통합해 대규모 분산 학습과 고성능 컴퓨팅(HPC, High-Performance Computing) 연산을 수행하는 **AI/HPC 인프라** (AI/HPC Infrastructure).
- 배경 및 필요성 : 거대언어모델(LLM, Large Language Model)의 파라미터 규모 확대로 단일 서버의 연산·메모리 용량을 초과하면서 수백 대 이상의 GPU 클러스터가 필수가 됨. 범용 데이터센터의 이더넷과 공랭 구조로는 노드 간 동기화 통신과 열 처리를 감당하기 어려운 점이 전용 인프라 분화의 계기.
- 주요 목적 : 클러스터 연산 능력 중 실제 모델 연산에 쓰이는 비율인 **MFU** (Model FLOPs Utilization)의 향상, 통신·입출력 병목의 제거, 랙 밀도 상향을 통한 면적과 전력 효율의 확보.

## Ⅱ. AI 학습·추론 고성능 컴퓨팅 인프라의 특징 및 장점

- 핵심 요약 : 노드 내부 결합, 노드 간 무손실 네트워크, 인네트워크 집계, 스토리지 직결, 액체냉각이 각각의 병목을 제거해 학습 효율로 연결되는 구조.

1. 노드 내 고속 결합 : **NVLink**가 GPU 간 점대점 링크를 제공하고 **NVSwitch**가 이를 노드 전체의 스위칭 패브릭으로 확장 → 한 노드의 GPU가 단일 메모리 풀처럼 동작하는 **스케일업** (Scale-up) 효과.
2. 노드 간 무손실 네트워크 : **InfiniBand** 또는 **RoCE v2** (RDMA over Converged Ethernet v2)가 **RDMA** (Remote Direct Memory Access)로 CPU 개입 없이 원격 GPU 메모리에 직접 접근하고 패킷 손실 없이 전송 → **스케일아웃** (Scale-out) 통신 오버헤드의 감소.
3. 인네트워크 집계 : **SHARP** (Scalable Hierarchical Aggregation and Reduction Protocol)가 스위치 하드웨어에서 **All-Reduce** 집합 연산을 대신 수행 → 호스트 왕복 트래픽 절감과 동기화 지연 완화.
4. 스토리지 직결 경로 : **GPUDirect Storage**가 스토리지에서 GPU 메모리로 직접 전송 경로를 열어 호스트 메모리 복사를 생략 → 대용량 학습 데이터 적재 병목의 완화.
5. 고밀도 냉각 : **D2C** (Direct-to-Chip) 액체냉각이 고발열 칩에 냉각수를 직접 공급 → 공랭 한계를 넘는 랙 전력 밀도와 냉각 에너지 효율의 확보.

## Ⅲ. AI 학습·추론 고성능 컴퓨팅 인프라의 구조 (흐름)

- 핵심 요약 : 애플리케이션부터 전력·냉각까지 계층적으로 받쳐 주는 구조이며, 학습 한 스텝은 연산과 동기화, 저장 단계를 반복.

```text
[ AI/HPC 인프라 계층 구조 ]

분산 학습 프레임워크 (애플리케이션)
   ↓
GPU 클러스터 (NVLink 스케일업)
   ↓
무손실 네트워크 (InfiniBand 스케일아웃)
   ↓
병렬 파일시스템 (데이터·체크포인트)
   ↓
전력·냉각 (D2C 액체냉각)
```

```text
[ 분산 학습 1스텝 흐름 ]

학습 데이터 로딩 (GPUDirect Storage)
   ↓
순전파·역전파 연산 (GPU)
   ↓
그래디언트 동기화 (All-Reduce)
   ↓
가중치 갱신
   ↓
주기적 체크포인트 저장
```

- 스케일업 계층과 스케일아웃 계층의 대역폭 균형이 MFU를 좌우하며, **체크포인트** (장애 시 재시작 지점이 되는 학습 상태의 주기 저장)는 병렬 파일시스템에 기록되어 장기 학습의 내성을 제공.

## Ⅳ. 범용 데이터센터와 AI/HPC 인프라의 비교

- 핵심 요약 : 범용 데이터센터는 가상화 중심의 저밀도 공랭 구조, AI/HPC 인프라는 가속기 중심의 고밀도 무손실 구조로 설계 기준이 대비됨.

| 비교 축 | 범용 엔터프라이즈 데이터센터 | AI/HPC 전용 인프라 |
| --- | --- | --- |
| 컴퓨팅 | 가상머신 중심의 CPU 서버 | GPU·NPU 가속기 클러스터 |
| 노드 간 네트워크 | TCP/IP 이더넷 | InfiniBand·RoCE v2 기반 RDMA |
| 스토리지 입출력 | 범용 NAS·SAN | 병렬 파일시스템·GPUDirect Storage |
| 냉각 방식 | 공랭 중심 | D2C 액체냉각 병행 |
| 핵심 지표 | 가용성·응답 시간 | MFU·**전력 사용 효율** (PUE, Power Usage Effectiveness) |

- 선택 기준 : 워크로드의 노드 간 동기화 통신 비중, 데이터 입출력 규모, 랙 전력 밀도 요구를 기준으로 전용 인프라의 필요 여부를 판단. 서버 증설만으로 네트워크·냉각·전력 설계를 대체할 수 없다는 점이 판단의 전제.

## Ⅴ. AI 학습·추론 고성능 컴퓨팅 인프라의 한계와 방안

- 핵심 요약 : 동기화 지연, 체크포인트 중단, 전력·열 한계를 격리 운영, 비동기 저장, 액체냉각으로 일대일 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **스트래글러** (Straggler) 지연 | 일부 GPU·링크의 미세 지연이 All-Reduce 동기화 지점에서 전체 대기로 확산 | 이상 노드의 조기 격리, 레일 최적화 케이블링 | 스텝당 대기 시간 |
| 체크포인트 중단 | 대형 모델 가중치 저장 동안 연산이 멈춰 가동률 하락 | 다계층 비동기 체크포인팅, 차분 저장 방식 | 저장 소요 시간 |
| 전력·열 한계 | 고밀도 랙의 발열을 공랭이 감당하지 못해 배치 밀도 제한 | D2C 액체냉각 도입, 냉각·전력 설계 일체화 | PUE, 랙당 전력량 |

## Ⅵ. AI/HPC 인프라에 대한 기술사적 제언

- 핵심 요약 : 활용률 지표 중심의 공동 설계, 개방형 규격 검증, 청정 전력 조달을 인프라 투자 의사결정에 통합하는 방향.

1. 기획 조직은 MFU를 클러스터 투자 성과 지표로 채택하고, 하드웨어와 학습 소프트웨어를 함께 조정하는 코디자인 절차를 두는 체계 필요.
2. 운영 조직은 울트라 이더넷 컨소시엄(UEC, Ultra Ethernet Consortium) 같은 개방형 상호연결 규격을 소규모 검증 환경에서 선행 시험해 전환 선택지를 확보.
3. 데이터센터 사업자는 전력구매계약(PPA, Power Purchase Agreement)으로 재생에너지를 조달하고 액체냉각 폐열 회수를 설계에 반영해 PUE를 운영 지표로 관리.

## Ⅶ. 결론

- 핵심 요약 : AI/HPC 인프라는 연산·연결·저장·냉각의 통합 설계로 대규모 학습을 실현하는 컴퓨팅 기반.
- 성능은 개별 장비 사양보다 계층 간 균형에서 결정되므로, 활용률 지표 기반의 통합 설계와 전력 조달 전략이 투자 판단의 기준.
