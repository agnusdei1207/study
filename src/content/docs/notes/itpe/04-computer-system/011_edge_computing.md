## 한 줄 본질
- 수많은 IoT 센서 및 단말 데이터를 원격 중앙 클라우드로 전송할 때 발생하는 백본 네트워크 대역폭 고갈과 수십 ms의 전송 지연 → 데이터가 생성되는 물리적 장소 인근(기지국, 게이트웨이, 단말)에서 실시간으로 1차 처리 및 추론 수행 → 밀리초 단위 초저지연 응답 및 통신 비용 절감 / 분산된 수천 대 노드의 배포·원격 관리 복잡도 급증

## 핵심 그림
```text
+-------------------------------------------------------------+
|             코어 클라우드 계층 (Central Cloud)              |
|   - 빅데이터 총괄 집계, 대규모 파운데이션 모델 학습        |
+-------------------------------------------------------------+
                              ▲ (요약 데이터 / 모델 업데이트)
                              │
+-------------------------------------------------------------+
|              엣지 노드 계층 (Edge Node / MEC)               |
|   - 통신 기지국, 현장 마이크로 데이터센터, 게이트웨이       |
|   - 실시간 비디오 분석, 1차 이벤트 필터링, 로컬 캐싱        |
+-------------------------------------------------------------+
                              ▲ (원시 센서 스트림)
                              │
+-------------------------------------------------------------+
|               디바이스 계층 (Edge Device / IoT)             |
|   - 자율주행 센서, 스마트 CCTV, 공장 PLC, 스마트폰          |
|   - 마이크로초 단위 현장 피드백 및 기기 제어                |
+-------------------------------------------------------------+
```

## 핵심 용어
- MEC(Multi-access Edge Computing): 통신사 이동통신 기지국 및 액세스 네트워크 접점에 클라우드 컴퓨팅 기능을 배치하여 무선 구간 지연을 최소화하는 표준 규격
- 로컬 브레이크아웃(Local Breakout): 트래픽을 통신사 코어망으로 보내지 않고 엣지 네트워크에서 즉시 로컬 인터넷이나 프라이빗 인프라로 직접 라우팅하는 기술

## 핵심 통찰
- 엣지 컴퓨팅은 클라우드를 대체하는 기술이 아니라 '클라우드의 손발을 현장으로 연장한 상호보완적 분업 체계'임 → 무거운 학습은 클라우드에서 수행하고, 가벼운 추론과 긴급 액션은 엣지에서 완결
- 자율주행차(초당 수 GB 데이터 생성)나 스마트팩토리에서 원격 클라우드 장애가 곧바로 현장 설비 충돌이나 라인 중단으로 이어지지 않도록 '네트워크 단절 시 자율 운영성(Offline Resilience)'을 보장
- 엣지 시스템의 총소유비용(TCO)은 서버 단가보다 '현장 유지보수 출동 비용'에서 갈림 → 무인 엣지 노드의 원격 무중단 OS 패치와 제로 터치 프로비저닝(ZTP)이 필수 요건

## 이웃 토픽과 구분
- 엣지 컴퓨팅 vs 포그 컴퓨팅(Fog Computing): 엣지 = 데이터 생성 장소(단말/게이트웨이)에 초점 / 포그 = 단말과 코어 클라우드 사이의 LAN/중간 인프라 전반을 포괄하는 시스코 중심의 확장 개념

## 내 의견
- [엣지 AI를 위한 경량 MLOps 파이프라인의 필수성] 엣지에 한번 배포된 AI 모델은 현장 조도나 환경 변화에 따라 성능이 급격히 퇴화(Data Drift)하나 현장 재학습은 자원 한계로 불가 → 나라면: 엣지에서 추론 확신도(Confidence)가 낮은 예외 데이터만 선별 압축하여 중앙 클라우드로 역전송하고, 클라우드 재학습 후 최적화된 경량 가중치(TensorRT/ONNX)만 엣지로 오버디에어(OTA) 배포하는 능동형 피드백 루프 구축
