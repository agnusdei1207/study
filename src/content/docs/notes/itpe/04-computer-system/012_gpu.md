## 연관 키워드
- GPU, SIMT, CUDA, 병렬 처리, 메모리 대역폭, CPU

## Ⅰ. GPU의 개요
- 핵심 요약 : GPU는 다수의 산술 연산을 병렬 수행하도록 최적화된 프로세서.
- 개념 : **GPU**(Graphics Processing Unit)는 그래픽 파이프라인에서 발전해 대량의 독립 데이터 연산을 처리하는 병렬 컴퓨팅 장치.
- 배경 및 필요성 : 픽셀·행렬 등 높은 데이터 병렬성 작업은 순차 중심 CPU만으로 효율적 처리 어려움.
- 목적 : 그래픽 렌더링과 과학·AI 계산의 병렬 처리량 확보.

## Ⅱ. 구조와 특성
- 핵심 요약 : 다수의 처리 요소가 동일한 명령을 많은 데이터에 적용해 처리량을 높임.
- SIMT(Single Instruction, Multiple Threads) 실행 모델은 스레드 그룹에 명령을 적용 → 데이터 병렬 처리.
- 대역폭이 큰 메모리 계층은 대규모 데이터 스트리밍 지원.
- CPU와 비교해 분기 많은 순차 작업에는 불리할 수 있음.
- 프로그래밍 모델·드라이버·커널 튜닝이 성능에 영향.

## Ⅲ. 실행 흐름
- 핵심 요약 : 호스트 CPU가 커널과 데이터를 준비하고 GPU가 스레드 블록 단위로 병렬 실행.
```text
CPU 호스트 코드
  ↓ 데이터 전송·커널 실행
GPU Grid
  ↓ Block 분할
Thread·Warp 병렬 처리
  ↓ 결과 복사
CPU 후속 작업
```
```text
입력 배열 → 메모리 복사
  ↓
GPU 커널: 각 인덱스 병렬 계산
  ↓
출력 배열 → 후속 분석
```

## Ⅳ. GPU와 CPU 비교
- 핵심 요약 : GPU는 처리량 중심, CPU는 낮은 지연과 복잡한 제어 흐름 중심.
| 비교 축 | GPU | CPU |
| --- | --- | --- |
| 코어 구성 | 많은 병렬 처리기 | 적은 수의 복잡한 코어 |
| 강점 | 데이터 병렬·행렬 연산 | 분기·순차·OS 제어 |
| 병목 | 메모리 전송·점유율 | 병렬 처리량 |
| 적합 | 렌더링·학습·영상 | 범용 응용·제어 |

## Ⅴ. 한계와 방안
- 핵심 요약 : 커널 실행·전송 오버헤드와 분기 발산은 작업 분할과 데이터 지역성으로 줄임.
| 한계 | 원인·영향 | 대응 |
| --- | --- | --- |
| 전송 지연 | CPU-GPU 메모리 복사 | 데이터 상주·전송 병합 |
| 분기 발산 | 워프 내 경로 차이 | 데이터·작업 그룹화 |
| 메모리 병목 | 비연속 접근 | coalesced access·타일링 |
| 높은 유휴 비용 | 작은 작업에 과도한 장치 | CPU/GPU 경로 선택 |

## Ⅵ. 활용 제언
- 핵심 요약 : 개발팀은 병렬성이 충분하고 전송비용을 상쇄하는 커널부터 GPU 적용.
- 프로파일러로 점유율·메모리 대역폭·호스트 전송을 측정하고 정밀도와 재현성을 검증.

## Ⅶ. 결론
- 핵심 요약 : GPU는 대규모 데이터 병렬 계산의 처리량을 높이는 범용 가속기.
- 병렬성·메모리 이동·프로그래밍 비용을 포함해 CPU 대비 효과 평가.
