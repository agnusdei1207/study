## Ⅰ. 칩렛·UCIe 3.0의 개요

- 핵심 요약 : **칩렛·UCIe**는 거대 단일 다이의 수율 한계를 극복하기 위해 기능별 다이를 개방형 표준 인터커넥트로 결합하는 모듈형 반도체 아키텍처.
- 개념 : **거대 단일 다이(Monolithic Die)** 제작의 **물리적 면적 한계** (Reticle Limit)와 수율 저하를 극복하기 위해 기능별(CPU(Central Processing Unit), GPU(Graphics Processing Unit), I/O, SRAM(Static Random-Access Memory))로 독립 제조된 다이(Die)를 첨단 2.5D/3D 패키징으로 연결하고, 이를 개방형 표준 인터커넥트 규격인 **UCIe** (Universal Chiplet Interconnect Express)로 결합하는 차세대 모듈형 반도체 아키텍처.
- 배경 및 필요성 : **무어의 법칙(Moore's Law)** 둔화, 첨단 공정(2nm/3nm)의 천문학적 웨이퍼 비용 및 다이 면적 증가에 따른 지수함수적 수율 급락을 해결하기 위해 **이종 공정(Heterogeneous)** 결합 패러다임으로 전환됨.
- 핵심 목적 : 칩 제조 수율 비약적 향상 및 원가 절감, 다이 크기 물리적 한계 돌파, 개방형 표준을 통한 벤더 간 칩렛 상호운용성(Interoperability) 확보.

## Ⅱ. 칩렛·UCIe 3.0의 특징 및 장점

- 핵심 요약 : **3계층 아키텍처(물리/D2D/프로토콜)·이종 공정 결합·오픈 표준**으로 모듈형 반도체 구현.
1. **물리 계층 (Physical Layer)** : 초미세 피치 범프 및 고속 직렬/병렬 SerDes 인터페이스를 구동하며 클록, 데이터 레인, 링크 트레이닝 수행.
2. **D2D 어댑터 계층** : 링크 신뢰성 보장을 위해 CRC(Cyclic Redundancy Check) 검증, 재전송 버퍼링, 그리고 프로토콜 프레임(Flit) 정렬 처리.
3. **프로토콜 계층** : 검증된 산업 표준인 PCIe 및 CXL 프로토콜을 그대로 캡슐화하여 소프트웨어 호환성을 완벽히 유지.
4. **이종 공정 결합 (Heterogeneous Integration)** : 고성능 연산 코어는 최첨단 3nm 공정, I/O 및 아날로그 회로는 성숙된 14nm 레거시 공정으로 분리 제작 후 단일 칩렛 결합.

## Ⅲ. 칩렛·UCIe 3.0의 구조 및 동작 메커니즘

- 핵심 요약 : **물리/D2D/프로토콜 3계층 + 표준/첨단 패키지**.
- UCIe는 물리 계층(Physical Layer), 다이 간 어댑터(Die-to-Die Adapter), 그리고 프로토콜 계층(PCIe(Peripheral Component Interconnect Express)/CXL(Compute Express Link))의 3계층 아키텍처로 구성되며, 표준 패키지(Standard)와 첨단 패키지(Advanced: CoWoS 등)를 모두 지원함.

```text
[ UCIe 프로토콜 계층 및 칩렛 패키징 아키텍처 ]

+---------------------------------------------------------------+
| Protocol Layer (프로토콜 계층: PCIe 6.0/7.0, CXL 2.0/3.0, Streaming)|
+---------------------------------------------------------------+
                                │ (FDI: Flit-aware D2D Interface)
                                ▼
+---------------------------------------------------------------+
| Die-to-Die Adapter Layer (다이 간 어댑터 계층)                |
|   - 링크 상태 관리, 플로우 제어, CRC 에러 검출 및 재전송 (ARQ)|
+---------------------------------------------------------------+
                                │ (RDI: Raw D2D Interface)
                                ▼
+---------------------------------------------------------------+
| Physical Layer (물리 계층: AFE / Digital PHY)                 |
|   - 메인 데이터 레인, 사이드밴드(Sideband: 초기화 및 트레이닝)|
+---------------------------------------------------------------+
                                │
        ┌───────────────────────┴───────────────────────┐
        ▼ (표준 패키지)                                 ▼ (첨단 2.5D 패키지)
+-------------------------------+              +----------------+
| Standard Package              |              | Advanced PKG   |
| (유기 기판: 100~130um 범프)   |              | (CoWoS/EMIB:   |
| 비용 최적화, 긴 배선          |              |  25~55um 범프) |
+-------------------------------+              +----------------+
```

## Ⅳ. 칩렛·UCIe 3.0의 비교

- 핵심 요약 : **단일 다이·독자 칩렛·UCIe 개방형** 수율·호환성·표준·대역폭·유연성 비교.

| 비교 항목 | 단일 거대 다이 (Monolithic) | 독자 규격 칩렛 (Proprietary) | UCIe 3.0 개방형 칩렛 |
|---|---|---|---|
| 제조 수율 | 면적이 클수록 수율 지수적 급락 | 다이 분할로 양호한 수율 달성 | 부품별 최적 공정으로 극대화된 수율 |
| 벤더 호환성 | 단일 칩 내부로 호환성 이슈 없음 | 동일 제조사 칩렛끼리만 결합 가능 | 이종 제조사 간 표준 칩렛 조립 가능 |
| 인터페이스 표준 | 온칩 전용 내부 버스 (AXI 등) | 자체 비표준 인터페이스 (Ultra Path) | 글로벌 오픈 표준 (PCIe/CXL 호환) |
| 대역폭 밀도 | 최고 수준 (물리적 단일 실리콘) | 높음 (자체 설계 최적화) | 극대화 (첨단 2.5D/3D 패키징 기반) |
| 설계 유연성 | 공정 전환 시 전체 재설계 필수 | 부분 모듈 재사용 가능 | 레고 블록식 모듈형 믹스앤매치 가능 |

- UCIe 3.0은 인텔, AMD(Advanced Micro Devices), TSMC(Taiwan Semiconductor Manufacturing Company), 삼성, ARM 등 반도체 생태계 전반이 참여한 오픈 표준으로, 폐쇄적 칩렛 시장을 개방형 '반도체 조립 시장'으로 전환하는 촉매제임.

## Ⅴ. 칩렛·UCIe 3.0의 한계와 방안

- 핵심 요약 : **지연·KGD 수율·열팽창**을 하이브리드 본딩·BIST·유리기판으로 대응.

- 다이 간 경계면에 따른 신호 감쇄 및 추가 **지연(Latency)** :
  - 한계점 : 단일 실리콘 대비 칩렛 인터페이스를 경유하면서 발생하는 수 ns 수준의 지연시간과 전송 전력 소모.
  - 해결 방안 : 초미세 마이크로 범프 및 Cu-Cu 직접 하이브리드 본딩 적용, 초저전력 SerDes 설계로 피코줄(pJ/bit) 단위 소비 전력 억제.
- KGD (Known Good Die) 선별 및 통합 테스트 복잡도 :
  - 한계점 : 개별 칩렛 중 단 하나라도 불량일 경우 결합된 고가의 전체 패키지가 폐기되는 수율 결합 리스크.
  - 해결 방안 : 다이 레벨 테스트를 위한 첨단 프로브 카드 도입, UCIe 내장 자체 진단(BIST) 및 레인 리매핑(Lane Repair) 회로 필수 내장.
- 이종 칩렛 간 **열팽창계수(CTE)** 불일치 및 기판 휨(Warpage) :
  - 한계점 : 서로 다른 공정과 소재의 칩렛들이 고열 발생 시 서로 다른 비율로 팽창하여 접합부 균열 및 파손 발생.
  - 해결 방안 : 고강도 및 열팽창 정합성이 우수한 유리기판(Glass Substrate) 도입, 첨단 언더필(Underfill) 소재 고도화.

## Ⅵ. 칩렛·UCIe 3.0 적용 제언

- 핵심 요약 : **커스텀 AI 가속기·OSAT 투자·유리기판 R&D**.
- 칩렛 기반 커스텀 AI 가속기 : 연산 다이만 개발, I/O/HBM 컨트롤러 칩렛은 상용 구매.
- OSAT 인프라 투자 확대 : CoWoS급 2.5D 패키징 생태계 구축.
- 유리기판 R&D : 대면적 유리기판 로드맵.

## Ⅶ. 결론

- 핵심 요약 : 칩렛·UCIe는 **모듈형 반도체 아키텍처**로 수율·비용·상호운용성을 확보하나 지연·KGD·열팽창 관리가 필수.
- 칩렛·UCIe는 거대 단일 다이의 수율 한계를 극복하는 모듈형 반도체 아키텍처로 수율·비용·상호운용성을 확보하지만, 다이 간 지연·KGD 수율·열팽창 리스크를 하이브리드 본딩·BIST·유리기판으로 관리해야 함.
- 답안에는 3계층 아키텍처, 단일/독자/UCIe 비교, 한계·대응, 커스텀 가속기·OSAT·유리기판 제언을 연결.
