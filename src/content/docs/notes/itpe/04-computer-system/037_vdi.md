## Ⅰ. VDI(가상 데스크톱 인프라)의 개요

- **개념** : 사용자의 데스크톱 컴퓨팅 환경(운영체제, 애플리케이션, 데이터)을 로컬 PC가 아닌 중앙 데이터센터의 하이퍼바이저 가상머신(VM)에서 호스팅하고, 사용자는 씬 클라이언트(Thin Client)나 모바일 기기를 통해 화면 전송 프로토콜로 접속하여 사용하는 엔드포인트 가상화 인프라 솔루션.
- **배경 및 필요성** : 기업 데이터의 엔드포인트 PC 유출 사고 방지, 재택근무 확산에 따른 원격 업무 보안(망분리 규제 준수), 그리고 수천 대의 사내 PC 유지보수 비용을 중앙 집중화하여 절감하기 위해 도입됨.
- **핵심 목적** : 중앙 집중 관리를 통한 데이터 유출 원천 차단(화면만 전송, 데이터 다운로드 통제), 스마트워크 및 재택근무 환경 구현, PC 프로비저닝 및 OS 패치 관리의 단순화.

## Ⅱ. VDI(가상 데스크톱 인프라)의 핵심 아키텍처 및 동작 메커니즘

VDI는 접속 브로커(Connection Broker), 가상 데스크톱 풀(VM Pool), 원격 디스플레이 전송 프로토콜, 그리고 사용자 프로파일 관리 계층으로 구성됨.

```text
[ VDI 아키텍처 및 접속 흐름 ]

[사용자 엔드포인트: 씬클라이언트 / 노트북 / 태블릿]
                    │
                    ▼ (TLS 암호화 제어 및 화면 세션)
+---------------------------------------------------------------+
| VDI Security Gateway / DMZ Access Point                       |
+---------------------------------------------------------------+
                    │
                    ▼
+---------------------------------------------------------------+
| Connection Broker (접속 브로커)                                |
|   - 사용자 Active Directory 인증, 권한 확인, VM 동적 배정      |
+---------------------------------------------------------------+
                    │
                    ▼ 가상 데스크톱 인계
+---------------------------------------------------------------+
| Virtual Desktop Pool (하이퍼바이저 클러스터: ESXi / KVM)      |
|                                                               |
|  [Golden Master Image (골든 이미지: OS + 공통 앱)]             |
|                    │                                          |
|                    ├─ (Linked Clone / Instant Clone: 빠른 복제)|
|                    ▼                                          |
|  +--------------------+  +--------------------+               |
|  | VM 1 (User A 세션) |  | VM 2 (User B 세션) |               |
|  +--------------------+  +--------------------+               |
+---------------------------------------------------------------+
        │                                       │
        ▼ (프로파일 동기화)                      ▼ (화면 압축 전송)
+-------------------------------+      +------------------------+
| User Profile Storage (NAS)    |      | Remote Display Protocol|
| - 개인 설정, 문서 데이터 보관 |      | (PCoIP/Blast/ICA-HDX)  |
+-------------------------------+      +------------------------+
```

- **접속 브로커 (Connection Broker)** : 사용자의 인증 요청을 처리하고, 유휴 데스크톱 풀에서 적합한 VM을 찾아 세션을 1:1로 매핑.
- **골든 이미지 (Golden Master Image)** : 표준 OS와 보안 백신, 공통 사내 소프트웨어를 탑재한 단일 마스터 이미지로 모든 VM을 통일 관리.
- **인스턴트 클론 (Instant Clone)** : 마스터 VM의 메모리와 디스크를 공유하여 부팅 과정 없이 수 초 내에 수백 대의 신규 가상 데스크톱을 고속 배포.
- **원격 디스플레이 프로토콜** : PCoIP, VMware Blast, Citrix HDX/ICA 등 화면 픽셀의 변화량만 고효율 H.264/H.265 코덱으로 압축 전송.
- **전용(Dedicated) vs 유동(Floating) 풀** : 사용자 전용 VM을 고정 할당하는 방식과, 로그아웃 시 초기화되어 다른 사용자가 재활용하는 유동 방식.

## Ⅲ. VDI(가상 데스크톱 인프라)의 세부 구성 요소 및 비교 분석

| 비교 항목 | 전통적 물리 PC | VDI (가상 데스크톱 인프라) | DaaS (클라우드 서비스형 데스크톱) |
|---|---|---|---|
| **컴퓨팅 위치** | 사용자 책상 위 로컬 PC | 자체 데이터센터 하이퍼바이저 | CSP 퍼블릭 클라우드 인프라 |
| **데이터 보안** | 로컬 HDD 저장으로 유출 위험 | 중앙 스토리지 집중, 외부 유출 원천 차단 | 중앙 클라우드 집중, 최고 수준 보안 |
| **초기 투자비(CAPEX)**| PC 구매 비용 분산 | 서버, 스토리지, VDI 라이선스 등 막대함 | **초기 투자 0 (완전 월정액 OPEX)** |
| **운영 인프라 관리**| 일일이 현장 방문 유지보수 | 사내 전산팀이 서버/하이퍼바이저 관리 | **클라우드 제공업체가 인프라 전담** |
| **네트워크 의존도** | 오프라인에서도 완전 동작 | 네트워크 단절 시 접속 불가 | 네트워크 단절 시 접속 불가 |

- 최근 기업 인프라는 막대한 초기 서버 구매비와 유지보수가 수반되는 온프레미스 VDI에서 클라우드 기반 완전 관리형 DaaS(AWS WorkSpaces 등)로 급속히 전환되는 추세임.

## Ⅳ. VDI(가상 데스크톱 인프라)의 주요 한계점 및 해결 방안

- **출근 시간대 동시 로그인에 따른 '부트 스톰(Boot Storm)' I/O 병목** :
  - **한계점** : 오전 9시경 수천 명의 직원이 동시 부팅 및 로그인할 때 스토리지 읽기 I/O 폭증으로 시스템 응답 불가.
  - **해결 방안** : 올플래시(NVMe) 스토리지 도입, 인스턴트 클론 기반 사전 워밍업(Warm-up), 사용자 접속 시차 분산 정책.
- **원격 프로토콜 전송에 따른 네트워크 지연 및 입력 랙(Input Lag)** :
  - **한계점** : 원격지나 무선 네트워크 환경에서 마우스 반응 지연, 고해상도 비디오 재생 시 화면 끊김 현상 발생.
  - **해결 방안** : 하드웨어 가속 GPU 가상화(vGPU) 장착, 네트워크 상태에 따라 대역폭을 동적 조절하는 적응형 UDP(Blast Extreme) 프로토콜 적용.
- **온프레미스 인프라 구축의 막대한 TCO 및 라이선스 부담** :
  - **한계점** : VDI 솔루션, 윈도우 OS VDA 라이선스, 하이퍼바이저, SAN 스토리지의 고비용으로 PC 대비 경제성 악화.
  - **해결 방안** : DaaS 클라우드 구독형 전환, 라이선스 비용이 없는 리눅스 기반 VDI 또는 세션 기반 SBC(서버 기반 컴퓨팅) 혼용.

## Ⅴ. VDI(가상 데스크톱 인프라) 적용 및 발전을 위한 기술사적 제언

- **제로 트러스트(Zero Trust) 엔드포인트 보안 체계 연계** : 접속 단말의 무결성(OS 버전, 탈옥 여부)을 평가하는 단말 상태 검증(Posture Check) 및 조건부 접근 정책(MFA 필수) 구축.
- **망분리 규제 완화에 따른 논리적 VDI 고도화** : 금융권 망분리 규제가 서비스형 클라우드 활용(SaaS) 허용으로 유연화됨에 따라 인터넷망 VDI와 업무망 VDI 간 데이터 연계(망연계) 감사 통제 강화.
- **3D CAD 및 AI 개발자를 위한 vGPU VDI 확충** : 고사양 그래픽 및 딥러닝 개발자 업무를 수용하기 위해 NVIDIA vGPU 기반의 고성능 가상 워크스테이션 인프라 표준화 권장.
