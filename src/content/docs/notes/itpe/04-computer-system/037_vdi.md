## 연관 키워드

- VDI(Virtual Desktop Infrastructure), 씬 클라이언트(Thin Client), 접속 브로커(Connection Broker)
- 골든 이미지(Golden Image), 인스턴트 클론(Instant Clone), 데스크톱 풀(Desktop Pool)
- 원격 디스플레이 프로토콜(Remote Display Protocol), 부트 스톰(Boot Storm), vGPU(Virtual GPU)
- DaaS(Desktop as a Service), TCO(Total Cost of Ownership), 망분리

## Ⅰ. VDI의 개요

- 핵심 요약 : **VDI** (Virtual Desktop Infrastructure)는 데스크톱 실행 환경을 중앙 서버의 가상머신에서 구동하고 단말에서 원격 접속하게 하는 엔드포인트 가상화 기술.
- 개념 : 운영체제와 업무 애플리케이션을 사용자 단말이 아닌 데이터센터의 하이퍼바이저 위 가상머신(VM, Virtual Machine)에서 실행하고, 사용자는 **씬 클라이언트** (Thin Client)나 일반 PC로 접속해 화면을 전송받는 구조.
- 배경 및 필요성 : 단말 분산 보관에 따른 정보 유출 위험, 개인별 PC의 패치·보안 관리 부담, 재택 근무 확산과 망분리 요구가 겹치면서 중앙 집중형 업무 환경 필요.
- 주요 목적 : 정보의 중앙 보관을 통한 유출 경로 축소, 데스크톱 배포·복구·패치의 일괄 관리, 장소 제약 없는 업무 환경 제공.

## Ⅱ. VDI의 특징 및 장점

- 핵심 요약 : 접속 중개, 이미지 기반 복제, 풀 운영, 화면 전송 기술의 결합이 중앙 집중 관리와 신속 배포라는 장점으로 이어짐.

1. **접속 브로커** (Connection Broker) : 인증 결과와 권한에 따라 가용한 가상 데스크톱을 배정하고 세션을 연결하는 중개 장치 → 사용자·데스크톱 매핑의 중앙 통제 효과.
2. **골든 이미지** (Golden Image) : 표준 운영체제와 공통 애플리케이션을 담은 원본 이미지로 데스크톱을 복제하는 방식 → 패치 범위가 원본 하나로 수렴하는 관리 효율.
3. **인스턴트 클론** (Instant Clone) : 원본 가상머신의 메모리·디스크 상태를 공유해 부팅 절차를 생략하는 복제 방식 → 대량 데스크톱의 신속 배포 효과.
4. 풀 운영 : **데스크톱 풀** (Desktop Pool)을 사용자 전용형과 로그아웃 시 초기화되는 유동형으로 구성 → 보안 수준과 자원 활용률의 균형 확보.
5. 화면 전송 : **원격 디스플레이 프로토콜** (Remote Display Protocol)이 화면 변화분만 압축 전송하는 방식 → 저대역폭 회선에서도 업무 환경 유지.

## Ⅲ. VDI의 구조 (흐름)

- 핵심 요약 : 단말 접속이 게이트웨이와 접속 브로커를 거쳐 데스크톱 풀로 연결되고, 골든 이미지 기반 복제가 풀을 채움.

```text
[ VDI 접속 흐름 ]

사용자 단말 (씬 클라이언트)
   ↓ 암호화 채널
접속 게이트웨이
   ↓
접속 브로커 : 인증과 데스크톱 배정
   ↓
하이퍼바이저 위 데스크톱 풀
   ↓
원격 디스플레이 프로토콜 화면 전송
```

```text
[ 골든 이미지 기반 배포 구조 ]

골든 이미지 (운영체제·공통 앱)
   ↓ 인스턴트 클론 복제
가상 데스크톱 다수 생성
   ↓
사용자별 프로파일·문서는 별도 보관
   ↓
로그아웃 시 초기화 또는 유지
```

- 구성요소 : 접속 게이트웨이, 접속 브로커, 하이퍼바이저와 데스크톱 풀, 이미지·프로파일 저장소, 화면 전송 계층으로 구성.

## Ⅳ. VDI와 대안 방식의 비교

- 핵심 요약 : 데스크톱 실행 위치와 운영 주체, 투자 구조에 따라 물리 PC, VDI, DaaS의 성격이 구분됨.

| 비교 항목 | 물리 PC | VDI | DaaS (Desktop as a Service) |
| --- | --- | --- | --- |
| 데스크톱 실행 위치 | 사용자 단말 | 자체 데이터센터 | 클라우드 제공사 인프라 |
| 데이터 보관 | 단말 분산 보관 | 중앙 집중 보관 | 중앙 클라우드 보관 |
| 초기 투자 | 단말 구매 비용 분산 | 서버·스토리지·라이선스 집중 | 구독료 중심으로 낮음 |
| 운영 주체 | 사용자·현장 지원 | 자체 전산 조직 | 클라우드 제공사 |
| 단절 시 업무 | 오프라인 동작 가능 | 접속 없이 이용 불가 | 접속 없이 이용 불가 |

- 선택 기준 : 정보 통제 요구 수준, 자체 인프라 운영 역량, 회선 품질과 비용 구조에 따라 VDI와 DaaS 사이에서 선택.

## Ⅴ. VDI의 한계와 방안

- 핵심 요약 : 동시 접속 부하, 원격 조작 지연, 누적 비용을 스토리지·이미지 대책, 그래픽 가속, 총비용 산정으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| **부트 스톰** (Boot Storm) | 근무 시작 시간의 동시 접속·부팅 → 스토리지 요청 폭증과 접속 지연 | 올플래시 스토리지 구성, 이미지 사전 준비, 접속 시각 분산 정책 | 동시 접속 시 응답 시간 |
| 원격 조작 지연 | 회선 지연과 그래픽 처리 부담 → 입력 반응·영상 품질 저하 | **vGPU** (Virtual GPU)로 그래픽 가속, 화질·프레임의 적응형 조절 | 입력 지연 시간, 프레임 손실률 |
| 누적 비용 부담 | 서버·라이선스·운영 인력 비용 → 단말 대비 총비용 상승 | **TCO** (Total Cost of Ownership) 기준 사전 산정, 업무 등급별 VDI·DaaS 혼용 | 데스크톱 1대당 연간 비용 |

## Ⅵ. VDI에 대한 기술사적 제언

- 핵심 요약 : 망분리 정책과의 결합, 접속 피크 관리, 진입점 통제 강화를 조직 표준으로 정착하는 방향.

1. 정보보호 조직이 망분리 요구 구간에 VDI를 논리 분리 수단으로 지정하고, 접속 기록·클립보드·저장장치 제어 정책을 세션 관리 체계에 통합.
2. 인프라 운영 조직이 접속 피크 시간대의 부하 시험을 정기 수행 항목으로 두어 데스크톱 풀 용량과 스토리지 성능의 적정성 검증.
3. 전산 정책 조직이 단말 상태 점검과 다중 인증을 접속 절차에 결합해 VDI 진입점의 접근 통제 수준을 표준화.

## Ⅶ. 결론

- 핵심 요약 : VDI는 데스크톱 환경의 중앙 집중으로 통제력과 관리 효율을 높이는 가상화 인프라.
- 시사점 : 접속 피크와 회선 의존이라는 구조적 조건을 용량 계획에 반영할 때 집중 관리의 이점이 안정적으로 실현되는 구조.
