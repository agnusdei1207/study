## Ⅰ. SAN(Storage Area Network)의 개요

- 개념 : 대규모 엔터프라이즈 환경에서 다수의 서버와 고성능 스토리지 시스템 간에 대용량 데이터를 고속으로 주고받기 위해 **범용 LAN** 과 물리적·논리적으로 분리하여 구축한 스토리지 전용 고속 블록 I/O 전송 네트워크.
- 배경 및 필요성 : 일반 사무용 트래픽과 스토리지 데이터가 단일 이더넷 네트워크를 공유할 때 발생하는 네트워크 혼잡과 패킷 손실, 그리고 DAS의 서버별 스토리지 종속 한계를 극복하고 무손실·초저지연 스토리징을 구현하기 위해 탄생.
- 핵심 목적 : **무손실(Lossless)** 초고속 블록 데이터 전송, 서버 간 자유로운 스토리지 LUN 공유 및 통합, 미션 크리티컬 DB의 **고가용성(HA)** 및 **재해복구(DR)** 기반 제공.

## Ⅱ. SAN의 핵심 아키텍처 및 패브릭 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ FC-SAN (Fibre Channel Storage Area Network) 패브릭 아키텍처 ]       │
│                                                                        │
│   [ 서버 호스트 A ]                  [ 서버 호스트 B ]                 │
│    - FC HBA Card (Dual Port)          - FC HBA Card (Dual Port)        │
│    - WWPN: 10:00:00:00:c9:...         - WWPN: 10:00:00:00:c9:...       │
│   └───────────────┬──────────────────┴────────────────┬──────────────┘ │
│                   │ 광케이블 (LC-LC OM4/OM5)          │                │
│                   ▼                                   ▼                │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ FC 패브릭 스위치 클러스터 (Dual Fabric: Fabric A / Fabric B) ]│   │
│   │  - 32G / 64G FC-SW (Switching Fabric)                         │   │
│   │  - 조닝 (Zoning): WWPN/Port 기반 보안 통신 그룹 분리           │   │
│   │  - B2B 크레딧(Buffer-to-Buffer Credit) 기반 무손실 흐름 제어   │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ FC Link                            │
│                                   ▼                                    │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ 엔터프라이즈 스토리지 어레이 (Enterprise Storage Array) ]     │   │
│   │  - 스토리지 전면 포트 (Target WWPN)                            │   │
│   │  - LUN 매스킹 (LUN Masking): 승인된 호스트 HBA에만 LUN 매핑   │   │
│   │  - 듀얼 액티브 컨트롤러 및 NVMe/SAS 플래시 드라이브 풀        │   │
│   └────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

- **무손실 흐름 제어(Buffer-to-Buffer Credit)** : 수신 측 버퍼가 비어 있을 때만 송신 측에 크레딧(Credit)을 부여하여 패킷 드롭(Drop)과 재전송 오버헤드를 원천 배제.
- **접근 제어 2단계 보안 체계** : 패브릭 스위치 레벨에서 포트/WWPN 단위로 트래픽을 격리하는 **조닝(Zoning)** 과, 스토리지 어레이 레벨에서 특정 호스트에만 볼륨 접근을 인가하는 **LUN 매스킹(LUN Masking)** 을 결합 적용.

## Ⅲ. SAN 기술 유형(FC-SAN vs IP-SAN vs NVMe-oF) 비교 분석

| 비교 항목 | FC-SAN (Fibre Channel) | IP-SAN (iSCSI) | NVMe-oF (NVMe over Fabrics) |
| :--- | :--- | :--- | :--- |
| **전송 매체** | 전용 광케이블 및 FC 스위치 | 표준 이더넷 케이블 및 L2/L3 스위치 | RoCE v2, InfiniBand 또는 TCP/IP |
| **프로토콜 스택** | FCP (SCSI over FC) | iSCSI (SCSI over TCP/IP) | NVMe over RDMA / TCP |
| **전송 속도** | 16G / 32G / 64G FC | 10G / 25G / 100G Ethernet | 100G / 200G / 400G+ |
| **지연 시간 (Latency)**| 수십 마이크로초 (μs) | 수백 마이크로초 (TCP 스택 오버헤드)| 수 마이크로초 (초저지연, DMA) |
| **구축 비용** | 높음 (전용 HBA, 고가 전용 스위치)| 낮음 (기존 범용 이더넷 장비 활용) | 중간 ~ 높음 (RDMA 지원 NIC 필요) |
| **적용 분야** | 금융권 코어뱅킹, 대규모 DB 클러스터| 중소규모 가상화, 백업 타깃 스토리지 | 초거대 AI 분산학습, 초고속 캐싱 풀 |

## Ⅳ. SAN의 주요 한계점 및 해결 방안

- **FC-SAN** 인프라의 막대한 초기 도입 비용 및 전문 인력 부족 :
  - 한계점 : 전용 광케이블, FC 스위치, HBA 카드의 단가가 매우 높고, SAN 패브릭 관리를 위한 전문 엔지니어링 역량 요구.
  - 해결 방안 : 기존 100GbE 고속 이더넷 스위치 인프라를 그대로 활용하면서 무손실 전송을 보장하는 RoCE v2 기반 IP-SAN/NVMe-oF로 전환.
- **슬로우 드레인(Slow Drain)** 현상에 따른 전체 패브릭 성능 저하 :
  - 한계점 : 패브릭 내 특정 노드나 포트의 응답 지연으로 B2B 크레딧 반환이 지연되면, 상위 스위치 버퍼가 고갈되어 전체 패브릭으로 혼잡이 전이(Congestion Spreading).
  - 해결 방안 : FC 패브릭 성능 모니터링(FPIN, Fabric Performance Impact Notification) 도입, 혼잡 발생 포트 자동 감지 및 속도 동적 격리.
- 이기종 OS 간 파일 단위 동시 공유 불가(블록 스토리지 고유 한계) :
  - 한계점 : 순수 블록 스토리지는 다중 호스트가 단일 LUN에 동시 마운트 시 파일시스템 메타데이터 오염 발생.
  - 해결 방안 : 클러스터 파일시스템(GFS2, OCFS2, VMware VMFS) 적용 또는 SAN 기반 상위에 NAS 게이트웨이를 결합한 유니파이드(Unified) 스토리지 구성.

## Ⅴ. 엔터프라이즈 스토리지 패브릭을 위한 기술사적 제언

- 차세대 **NVMe-oF(RoCE)** 로의 인프라 전환 로드맵 수립 : 고가의 전통적 FC-SAN에서 탈피하여 데이터센터 통합 이더넷 패브릭 상에서 RDMA 기술을 활용하는 NVMe over RoCE v2 표준을 도입함으로써 올플래시 스토리지의 입출력 병목을 완전히 해소해야 함.
- **이중 패브릭(Fabric A/B)** 완전 무결성 및 자동 페일오버 검증 : 미션 크리티컬 시스템의 다운타임 제로를 위해 호스트부터 스위치, 스토리지 컨트롤러까지 완벽한 물리적 이중 경로를 구성하고, 정기적인 단일 패브릭 강제 오프라인 훈련을 통해 MPIO(다중 경로 소프트웨어) 절체 무결성을 상시 검증할 것을 제언함.
