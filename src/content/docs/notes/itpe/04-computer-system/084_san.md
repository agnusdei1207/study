## 30초 인출

- 본질: **SAN (Storage Area Network)은** 서버가 원격 저장장치를 블록 장치처럼 접근하도록 제공하는 전용 또는 논리적 스토리지 네트워크
- 메커니즘: 서버 HBA·프로토콜 → 패브릭 스위치 → 스토리지 포트·LUN → 호스트 블록 장치
- 통찰: 한계: 중앙 저장소를 공유해도 패브릭의 공통 장애점에서 I/O 중단 → 방안: 독립 경로·LUN 매핑·장애 전환을 종단에서 시험

<details>
<summary>핵심 용어</summary>

- **SAN (Storage Area Network)** : 서버와 저장장치 사이에 블록 접근 경로를 제공하는 스토리지 네트워크
- **FC (Fibre Channel)** : 스토리지 통신에 사용하는 고속 직렬 패브릭 기술
- **HBA (Host Bus Adapter)** : 서버를 스토리지 네트워크나 장치에 연결하는 어댑터
- **LUN (Logical Unit Number)** : 스토리지 시스템이 호스트에 제공하는 논리 단위 식별자
- **조닝 (Zoning)** : 패브릭에서 통신 가능한 포트·장치 집합을 제한하는 구성
- **LUN 마스킹 (LUN Masking)** : 스토리지 측에서 어떤 호스트에 논리 장치를 노출할지 제어하는 설정
- **MPIO (Multipath I/O)** : 호스트와 저장장치 사이의 복수 경로를 관리하는 기능
</details>

## 2~4교시 25점 답안

## Ⅰ. SAN의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **SAN (Storage Area Network)은** 서버에 원격 스토리지를 블록 장치로 제공하는 네트워크 구성 |
| 목적 | 서버와 저장장치의 연결·용량을 분리해 공유·확장·중앙 관리하는 것 |

## Ⅱ. 블록 접근과 경로 분리의 특징

| 특징 | 의미 |
|---|---|
| 블록 서비스 | 원격 LUN을 호스트의 블록 장치로 인식 |
| 접근 범위 분리 | 패브릭 조닝은 통신 경로, LUN 마스킹은 노출 장치를 제한 |
| 다중 경로 | MPIO가 복수 호스트·패브릭·컨트롤러 경로를 선택·전환 |

## Ⅲ. SAN 종단 I/O와 장애 전환 체계

```text
응용·파일시스템 → 호스트 블록 계층·MPIO → HBA
                                      ├→ 패브릭 A ─┐
                                      └→ 패브릭 B ─┤→ 컨트롤러 → LUN → 저장 매체
조닝: 허용 포트 범위 ──────────────────────────────┘
LUN 마스킹: 호스트에 노출할 논리 장치 결정
```

호스트 식별자와 조닝·LUN 매핑이 일치해야 장치가 보인다. 경로 장애 시 MPIO가 살아 있는 경로를 선택하더라도 카드·전원·컨트롤러가 공유되면 전환에 실패할 수 있다.

## Ⅳ. 경로 통제와 가용성 수단의 관계

| 수단 | 적용 위치 | 검증 기준 |
|---|---|---|
| 조닝 | SAN 패브릭 | 필요한 initiator·target 포트만 통신 |
| LUN 마스킹 | 스토리지 컨트롤러 | 허용 호스트에만 LUN 노출 |
| MPIO | 호스트 | 경로 장애 감지·I/O 재시도·전환 |
| 물리 경로 분리 | HBA·케이블·스위치·컨트롤러 | 공통 장애영역 제거와 경로별 장애 시험 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 조닝과 LUN 설정이 불일치하면 장치 미인식·과도한 노출 가능 | 변경 승인, 호스트 매핑 대조, 신규 경로 연결 시험을 표준화 |
| 복수 경로가 공통 스위치·전원·컨트롤러를 공유하면 단일 장애점 잔존 | 종단 경로의 장애영역을 분석하고 실제 경로 장애·복구 시험 수행 |
| 포트 수·대역폭만으로 실제 서비스 I/O 상태를 판단하기 어려움 | 서비스별 종단 지연·경로 상태를 함께 측정해 증설 우선순위 결정 |

## Ⅵ. 제언 — 호스트에서 LUN까지 실제 전환 시험

우선 핵심 업무의 HBA부터 LUN까지 공통 장애점을 확인하고 한 경로를 끊는 시험으로 I/O 지속 여부를 검증한 뒤 경로 분리와 증설 범위를 정한다.
