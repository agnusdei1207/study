## 연관 키워드
- 디스크 스케줄링, HDD, 탐색 시간, FCFS, SSTF, SCAN, C-SCAN

## Ⅰ. 디스크 스케줄링의 개요
- 핵심 요약 : 디스크 스케줄링은 대기 중인 블록 I/O 요청의 처리 순서를 정해 저장장치 지연을 관리하는 기법.
- 개념 : **디스크 스케줄링**(Disk Scheduling)은 주로 회전식 HDD에서 헤드 이동과 요청 대기시간을 줄이도록 큐를 재정렬.
- 배경 및 필요성 : 임의 접근 요청이 많으면 헤드 이동이 커져 탐색 시간이 지연의 큰 부분을 차지.
- 목적 : 처리량을 높이고 응답시간과 요청 간 공정성 균형.

## Ⅱ. 알고리즘 특징
- 핵심 요약 : 요청 위치와 현재 헤드 방향을 이용해 이동 거리와 기아 가능성을 조절.
- FCFS는 도착 순서를 보존 → 공정하지만 이동 비효율.
- SSTF는 가까운 요청 우선 → 평균 탐색 감소 가능, 먼 요청 기아.
- SCAN은 한 방향으로 훑은 뒤 반전 → 엘리베이터 방식.
- C-SCAN은 한 방향 서비스 후 시작점으로 복귀 → 대기시간 편차 완화.

## Ⅲ. 처리 흐름
- 핵심 요약 : 요청 대기열을 헤드 위치와 방향 기준으로 정렬해 순차 처리.
```text
요청 큐 수집
  ↓ 현재 실린더·방향 확인
정책 선택: FCFS·SSTF·SCAN
  ↓ 가장 적합한 요청 선택
헤드 이동·요청 처리
  ↓ 큐 갱신
```
```text
실린더 위치: 20 → 35 → 60
SCAN 반전: 80 ← 60 ← 35
```
- 실제 장치는 큐잉·캐시·펌웨어 정책을 함께 사용하므로 OS 알고리즘만으로 지연 예측 한계.

## Ⅳ. 알고리즘 비교
- 핵심 요약 : 짧은 평균 탐색이 목표인지 공정한 대기가 목표인지에 따라 정책 선택.
| 알고리즘 | 순서 | 장점·위험 |
| --- | --- | --- |
| FCFS | 도착 순 | 공정·이동 길 수 있음 |
| SSTF | 가까운 요청 | 평균 이동 감소·기아 가능 |
| SCAN | 양방향 훑기 | 처리량·경계 편차 |
| C-SCAN | 한 방향 순회 | 균일 대기·복귀 이동 |

## Ⅴ. 한계와 방안
- 핵심 요약 : HDD 탐색 중심 최적화는 SSD에서는 효과가 다르며 기아·꼬리 지연도 검토 필요.
| 한계 | 원인·영향 | 대응 |
| --- | --- | --- |
| SSTF 기아 | 가까운 요청 편중 | aging·대기 상한 |
| SSD 효익 감소 | 기계적 헤드 없음 | 장치 큐·대역폭 기준 조정 |
| 장치 내부 재정렬 | OS 관측과 실제 순서 차이 | 장치 유형별 실측 |
| 실시간 지연 | 배치 최적화 | deadline 기반 우선순위 |

## Ⅵ. 적용 제언
- 핵심 요약 : 스토리지 관리자는 HDD·SSD 특성과 워크로드 순차성·임의성을 기준으로 요청 정책을 결정.
- 장치별 지연 분포와 tail latency를 측정하며 운영체제와 컨트롤러의 중복 큐잉을 확인.

## Ⅶ. 결론
- 핵심 요약 : 디스크 스케줄링은 입출력 대기열의 서비스 순서를 조정하는 저장장치 관리 기법.
- 현대 스토리지에서는 장치 특성 및 전체 I/O 경로 기준으로 정책을 평가.
