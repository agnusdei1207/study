## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 핵심 개념 → DaaS

## 30초 인출

- 본질: 개별 PC 지급 관리는 하드웨어 고장, 데이터 유출, 분실 리스크가 크고 온프레미스 VDI는 수십억의 초기 인프라 비용이 듦
- 메커니즘: 클라우드 서비스 제공자가 호스팅하는 가상 데스크톱 환경을 월정액/사용량 기반으로 임대 소비

## 핵심 용어

- 세션 브로커(Connection Broker): 사용자의 로그인 요청을 받아 유효한 라이선스를 확인하고, 유휴 상태인 가상 데스크톱 VM 풀에서 최적의 인스턴스를 찾아 세션을 연결해 주는 중앙 통제기
- 화면 전송 프로토콜: 텍스트와 그래픽 데이터를 압축하여 최소 대역폭으로 단말에 실시간 전송하는 프로토콜(RDP, Citrix HDX, VMware Blast, Amazon Nice DCV)
- 골든 이미지(Golden Image): OS 패치, 필수 업무 프로그램, 사내 보안 에이전트가 미리 완벽하게 세팅된 표준 가상 머신 템플릿 마스터

## 1교시 10점 답안

### 정의·목적

- 정의: DaaS은/는 클라우드 서비스 제공자가 호스팅하는 가상 데스크톱 환경을 월정액/사용량 기반으로 임대 소비 방식이다.
- 목적: 강력한 데이터 유출 방지 및 원격 근무 유연성 확보에 기여한다.

### 핵심 구조와 작동

```text
[ DaaS 클라우드 서비스 전달 체계 및 원격 프로토콜 스트리밍 ]

[ 사용자 단말 (Thin Client / 노트북 / 모바일) ]
       │
       │ (TLS 암호화 터널: 화면 픽셀 스트리밍 수신 & 키보드/마우스 입력 송신)
       v
+─────────────────────────────────────────────────────────────+
| 클라우드 DaaS 서비스 영역 (Cloud CSP)                        |
|                                                             |
|  [ 보안 게이트웨이 & 세션 브로커 ]                            |
|   - Zero Trust MFA / 조건부 접근 평가 (기기 무결성 검증)     |
|   - 사용자 권한별 가상 데스크톱 풀(Pool) 라우팅             |
|                                                             |
|  [ 가상 데스크톱 인프라 (Virtual Desktops) ]                 |
|   +-------------------+     +-------------------+           |
|   | 사무용 표준 VM    |     | 고성능 vGPU VM    |           |
|   | (Windows 11 / OS) |     | (CAD / 3D 그래픽) |           |
|   +─────────┬─────────+     +─────────┬─────────+           |
|             │                         │                     |
|             v                         v                     |
|  [ 관리형 스토리지 & 사용자 프로파일 (FSLogix / EFS) ]       |
+─────────────────────────────────────────────────────────────+
```

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
[ DaaS 클라우드 서비스 전달 체계 및 원격 프로토콜 스트리밍 ]

[ 사용자 단말 (Thin Client / 노트북 / 모바일) ]
       │
       │ (TLS 암호화 터널: 화면 픽셀 스트리밍 수신 & 키보드/마우스 입력 송신)
       v
+─────────────────────────────────────────────────────────────+
| 클라우드 DaaS 서비스 영역 (Cloud CSP)                        |
|                                                             |
|  [ 보안 게이트웨이 & 세션 브로커 ]                            |
|   - Zero Trust MFA / 조건부 접근 평가 (기기 무결성 검증)     |
|   - 사용자 권한별 가상 데스크톱 풀(Pool) 라우팅             |

|   | 사무용 표준 VM    |     | 고성능 vGPU VM    |           |

|             │                         │                     |

+─────────────────────────────────────────────────────────────+
```

### Ⅱ. 핵심 특성

- DaaS의 본질은 '컴퓨터 임대'가 아니라 '데이터의 전산실 감금'임 → 직원의 단말기에는 단 1바이트의 업무 파일도 저장되지 않고 오직 화면 픽셀(Pixel)만 전송되므로, 노트북을 잃어버리거나 해킹당해도 원천적으로 데이터 유출이 불가능함
- 망분리 규제의 최신 대안임 → 공공기관이나 금융권에서 물리적 PC 2대를 책상에 두는 대신, 로컬 PC에서는 인터넷을 하고 DaaS 가상 환경에서 내부 업무망을 접속하는 논리적 망분리로 진화함
- 대역폭과 레이턴시가 체감 경험을 지배함 → 네트워크 왕복 시간이 50ms를 넘어가면 마우스 커서 궤적이 밀리고 타이핑 지연(Lag)이 생겨 직원의 업무 생산성이 급격히 떨어짐

### Ⅲ. 관련 개념과 구분

- DaaS vs VDI: VDI = 자체 데이터센터에 서버, 스토리지, 가상화 라이선스를 직접 구매하여 사내 엔지니어가 구축·운영(CAPEX) / DaaS = 퍼블릭 클라우드에서 인프라 일체를 서비스형으로 구독(OPEX)

### Ⅳ. 적용 문제와 대응

- 사례: 127회 기출 및 재택근무 전면 확대 시 동시 접속자 폭증으로 인한 DaaS 화면 멈춤 장애
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 네트워크 대역폭 부족 시 화면 프레임 급락 및 입력 딜레이 발생 | 고화질 비압축 픽셀 전송 및 비효율적 레거시 RDP 프로토콜 사용 | 어댑티브 코덱(H.264/AV1 하드웨어 가속) 및 대역폭 자동 적응 프로토콜 적용 | 대역폭 사용량 60% 절감 및 부드러운 60fps 유지 |
| 대규모 동시 로그인 시 부팅 지연 및 스토리지 I/O 병목(Boot Storm) | 출근 시간대(오전 9시) 수천 개 VM이 마스터 이미지 동시 로딩 | 메모리 기반 쓰기 캐싱 및 사용자 프로파일 컨테이너(FSLogix) 분리 | 부팅 폭풍 완화 및 10초 내 즉시 로그인 |

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 적용 환경에서 발생하는 핵심 제약 | 기존 대책을 적용하고 핵심 운영 지표를 확인해 개선한다. |
