## Ⅰ. DaaS(Desktop as a Service)의 개요

- **개념** : 퍼블릭 또는 프라이빗 클라우드 인프라 상에서 사용자 가상 데스크톱 환경(OS, 애플리케이션, 데이터)을 호스팅하고, 사용자가 단말 기기(PC, 태블릿, 신클라이언트)를 통해 네트워크로 원격 접속하여 업무를 수행할 수 있도록 서비스 형태로 제공하는 완전 관리형 클라우드 컴퓨팅 서비스.
- **배경 및 필요성** : 온프레미스 기반 전통적 VDI(Virtual Desktop Infrastructure) 구축에 따르는 막대한 초기 하드웨어 투자(CapEx), 복잡한 스토리지/브로커 관리 부담, 원격·재택 근무 확산 및 제로 트러스트(Zero Trust) 엔드포인트 보안 요구 증대.
- **핵심 목적** : 초기 구축비 절감(OpEx 전환), 관리형 데스크톱의 신속한 프로비저닝, 기업 중요 데이터의 중앙 집중화를 통한 단말 유출 원천 차단.

## Ⅱ. DaaS의 핵심 아키텍처 및 동작 메커니즘

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 클라우드 DaaS (Desktop as a Service) 서비스 구조 ]                   │
│                                                                        │
│   [ 엔드포인트 단말 (Zero/Thin Client, Mobile, PC) ]                   │
│                     │ HTTPS / DTLS (암호화 원격 제어 채널)             │
│                     ▼                                                  │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ DaaS 접근 게이트웨이 및 제어 평면 (Control Plane) ]          │   │
│   │  - IAM / 다중 요소 인증 (MFA, SSO, 기기 보안 상태 검증)        │   │
│   │  - 연결 브로커 (Connection Broker: 세션 라우팅 및 부하 분산)  │   │
│   │  - 데스크톱 라이프사이클 관리 (골든 이미지 배포, 오토스케일링) │   │
│   └───────────────────────────────┬────────────────────────────────┘   │
│                                   │ 고속 디스플레이 스트리밍 프로토콜  │
│                                   ▼                                    │
│   ┌────────────────────────────────────────────────────────────────┐   │
│   │ [ 클라우드 데이터 평면 (Data Plane: Hypervisor & vGPU) ]       │   │
│   │  - 가상 머신 인스턴스 (Windows 10/11, Linux Multi-session)     │   │
│   │  - 프로필 관리 (FSLogix: VHD 가상 디스크 실시간 마운트)        │   │
│   │  - 공유 스토리지 (SAN/NAS) 및 고성능 vGPU 가속 풀링           │   │
│   └────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────┘
```

- **디스플레이 스트리밍 프로토콜** : 실제 데이터 파일이 단말로 다운로드되지 않고, 서버에서 렌더링된 화면 프레임만 H.264/HEVC/AV1 코덱으로 압축하여 암호화 전송하고 단말의 키보드/마우스 입력만 서버로 전달.
- **사용자 프로필 분리(User Profile Disks)** : 골든 이미지 기반 무상태(Stateless) 가상 데스크톱에 접속 시 네트워크 드라이브의 사용자 프로필(FSLogix 컨테이너)을 즉각 마운트하여 개인화 설정 및 데이터 영속성 유지.

## Ⅲ. 온프레미스 VDI와 클라우드 DaaS 비교 분석

| 비교 항목 | 온프레미스 VDI (Virtual Desktop Infrastructure) | 클라우드 DaaS (Desktop as a Service) |
| :--- | :--- | :--- |
| **인프라 소유 및 관리** | 기업이 서버, 스토리지, 네트워크, 라이선스 직접 구축/운영 | 클라우드 서비스 제공자(CSP)가 전체 인프라 완전 관리 |
| **비용 모델** | 대규모 초기 자본 지출 (CapEx), 고정 유지보수비 | 사용자당 월/시간 단위 종량제 구독 모델 (OpEx) |
| **확장성 및 배포 속도** | 하드웨어 조달 리드타임으로 수개월 소요 (스케일업 한계) | 클라우드 콘솔에서 수 분 이내 수천 대 데스크톱 탄력 증설 |
| **업데이트 및 가용성** | 자체 관리자의 펌웨어, 하이퍼바이저 수동 패치 및 DR 구축 | CSP가 글로벌 데이터센터 기반 고가용성(99.9%+) 자동 보장 |
| **네트워크 의존도** | 사내망(LAN) 중심 최적화, 외부 접속 시 VPN 게이트웨이 | 퍼블릭 인터넷 및 전용선(Direct Connect) 기반 글로벌 접속 |

## Ⅳ. DaaS 도입 및 운영 시 주요 한계점 및 해결 방안

- **네트워크 레이턴시 및 패킷 손실에 따른 사용자 체감 품질 저하** :
  - **한계점** : 네트워크 지연 시간이 50ms 이상으로 증가하거나 대역폭 변동 시 마우스 끊김, 키보드 입력 지연(Typing Lag) 발생으로 업무 생산성 저하.
  - **해결 방안** : 적응형 UDP 기반 고성능 스트리밍 프로토콜(PCoIP, Blast Extreme, Citrix HDX, RDP with Shortpath) 적용 및 글로벌 CDN/엣지 게이트웨이 배치.
- **그래픽 집약적 워크로드(CAD, 3D 렌더링, 영상 편집) 처리 한계** :
  - **한계점** : 단순 범용 CPU 기반 VM에서는 3D 애플리케이션 실행 불가 및 vGPU 인스턴스 할당 시 클라우드 비용 급증.
  - **해결 방안** : 하드웨어 vGPU 파티셔닝(NVIDIA RTX vWS) 인스턴스를 그래픽 작업자 전용으로 프로파일링하여 선별 배정하고 유휴 시 자동 셧다운 정책 수립.
- **장기 구독 시 온프레미스 대비 클라우드 비용 역전(FinOps 리스크)** :
  - **한계점** : 수년 이상 고정적으로 사용하는 전사 환경에서 VM 시간당 과금 및 아웃바운드 데이터 전송료(Egress) 누적으로 TCO 역전 현상 발생.
  - **해결 방안** : 미사용 야간/주말 자동 디앨로케이션(Deallocation), Windows 10/11 멀티세션 인스턴스를 통한 단일 VM 다중 사용자 집적도 향상.

## Ⅴ. 엔터프라이즈 DaaS 도입을 위한 기술사적 제언

- **제로 트러스트(Zero Trust) 단말 보안 아키텍처와의 결합** : DaaS 자체를 신뢰할 수 없는 엔드포인트와 내부 엔터프라이즈 코어 네트워크 사이의 격리 버퍼(Air-Gap Buffer)로 정의하고, 조건부 액세스(기기 상태 평가, 위치 기반 접속 제어) 및 클립보드·로컬 디스크 리디렉션 원천 차단 정책을 필수 적용해야 함.
- **하이브리드 업무 환경을 위한 네트워크 백본 최적화** : 본사-클라우드 간 SD-WAN 전용 사설 회선을 연계하여 QoS(Quality of Service) 보장형 트래픽 엔지니어링을 수립하고, 비즈니스 연속성 계획(BCP) 수립 시 DaaS를 비상 대체 업무 환경으로 상시 통합 운용할 것을 제언함.
