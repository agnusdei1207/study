## 연관 키워드

- 양자기술(Quantum Technology), 큐비트(Qubit), 중첩(Superposition), 얽힘(Entanglement), 복제 불가 정리(No-Cloning Theorem)
- 양자 컴퓨팅, 양자 통신, 양자 센싱, QKD(Quantum Key Distribution), PQC(Post-Quantum Cryptography)
- QEC(Quantum Error Correction), 논리 큐비트, 양자 중계기(Quantum Repeater), 하이브리드 양자-고전 컴퓨팅(HQC)
- 쇼어 알고리즘(Shor's Algorithm), 암호 민첩성(Crypto Agility), Harvest Now, Decrypt Later, 국가전략기술

## Ⅰ. 양자기술의 개요

- 핵심 요약 : 양자역학의 중첩, 얽힘, 측정 원리를 연산·통신·계측에 응용하는 차세대 전략 기술.
- 개념 : 양자역학의 고유한 물리 원리를 정보의 연산, 전송, 측정에 활용하는 기술 분야인 **양자기술** (Quantum Technology)로, 기존 디지털 컴퓨터로 풀기 어려운 문제의 계산과 도청 감지가 가능한 키 분배를 목표로 함.
- 배경 및 필요성 : 반도체 미세화의 물리적 한계가 드러나고, 대규모 소인수분해에 적용되는 쇼어 알고리즘이 현행 공개키 암호를 위협할 수 있다는 우려가 커지면서, 연산 성능과 암호 체계를 함께 준비해야 하는 국가 전략 과제가 됨.
- 주요 목적 : 양자컴퓨팅, 양자통신, 양자센싱 3대 분야의 기술 확보와 산업 경쟁력 강화. 국내에서는 과학기술정보통신부 중심의 국가 전략기술 추진 체계에 포함되어 있으며, 제6차 과학기술기본계획(2026~2030)의 10대 국가전략기술 분야 중 하나로 다뤄짐.

## Ⅱ. 양자기술의 특징 및 장점

- 핵심 요약 : 중첩과 간섭으로 연산 공간을 넓히고, 측정의 비가역성으로 도청을 드러내는 원리가 연산과 통신의 장점으로 이어지는 구조.

1. **큐비트** (Qubit)의 중첩 기반 연산 : 0과 1의 중첩 상태를 가져 n개의 큐비트가 2의 n제곱 개 상태를 동시에 표현 → 특정 문제에서 병렬 탐색 효율 향상(모든 문제가 빨라지는 것은 아님).
2. 간섭을 이용한 정답 증폭 : 알고리즘 설계로 오답 경로의 확률을 상쇄하고 정답 경로를 강화 → 측정 시 정답이 나올 확률 증가.
3. 측정 기반 도청 감지 : 복제 불가 정리에 따라 양자 상태를 복사할 수 없고 측정하면 상태가 바뀌므로 도청 흔적이 남음 → 키 분배 과정에서 도청 여부를 확인할 수 있음.

## Ⅲ. 양자기술의 구조 (흐름)

- 핵심 요약 : 양자 컴퓨팅, 양자 통신·암호, 양자 센싱이 서로 다른 물리 원리 위에 놓인 3대 분야 구조.
- **QKD** (Quantum Key Distribution) : 양자 상태를 이용해 암호 키를 나누어 갖고, 중간에 도청이 있었는지를 확인하는 키 분배 방식.
- **PQC** (Post-Quantum Cryptography) : 양자컴퓨터 공격에도 견디도록 설계된 암호 알고리즘으로, 일반 컴퓨터에서 동작하는 소프트웨어 방식이라는 점에서 QKD와 구분됨.

```text
[ 양자기술 3대 분야 ]

양자 컴퓨팅
  큐비트 중첩·얽힘 기반 연산
양자 통신·암호
  QKD(키 분배) · PQC(내성 암호)
양자 센싱
  원자·다이아몬드 결함 기반 초정밀 계측
```

```text
[ 양자키분배 (QKD) 흐름 ]

송신자가 단일 광자에 키 비트를 실어 전송
   ↓
수신자가 측정 기준을 무작위로 골라 측정
   ↓
송·수신자가 측정 기준을 공개 비교해 일치분 선별
   ↓
오차율 확인 → 도청 흔적이 있으면 키 폐기
```

## Ⅳ. 양자 컴퓨터 구현 방식의 비교

- 핵심 요약 : 초전도, 이온 트랩, 중성 원자, 광자, 위상 방식은 속도, 결맞음 시간, 확장성에서 서로 다른 강점과 약점을 가져 단일 방식이 모든 기준에서 우위에 있지 않은 구도.

| 구현 방식 | 동작 원리 및 장점 | 주요 단점·기술적 난제 | 대표 기업 예시 |
| --- | --- | --- | --- |
| 초전도 큐비트 | 초전도 회로의 조셉슨 접합 기반, 빠른 게이트 동작 | 극저온 냉각 필요, 결맞음 시간이 짧음 | IBM, Google |
| 이온 트랩 | 전기장으로 이온을 포획하고 레이저로 제어, 긴 결맞음 시간 | 게이트 속도가 상대적으로 느림, 대규모 확장 난제 | IonQ, Quantinuum |
| 중성 원자 | 레이저로 원자를 배열해 대규모 배열 확장에 유리 | 원자 제어와 손실 관리가 복잡 | QuEra, Pasqal |
| 광자 | 상온 동작 가능, 광통신 인프라와 연계 용이 | 단일 광자의 생성·검출 효율과 얽힘 생성의 확률성 한계 | Xanadu, PsiQuantum |
| 위상 큐비트 | 물리적 오류에 강한 설계를 목표 | 소자 구현 난도가 매우 높고 상용화 시점 불확실 | Microsoft (연구 단계) |

- 선택 기준 : 연산 속도, 결맞음 시간, 큐비트 확장성, 기존 통신망과의 연계성 중 어떤 기준을 우선할지에 따라 방식을 달리 평가함.
- 유의 사항 : 대표 기업은 예시이며 기술 성숙도는 계속 변하므로 최신 발표로 확인해야 함.

## Ⅴ. 양자기술의 한계와 방안

- 핵심 요약 : 결맞음 손실, 장거리 통신의 거리 제약, 암호 전환 지연을 오류 정정, 신뢰 노드, 표준 PQC 전환으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 결맞음 손실과 높은 물리 오류율 | 환경 잡음에 민감해 연산 유지 시간이 짧고 오류가 누적되어 범용 알고리즘 실행 곤란 | 표면 코드 등 양자 오류 정정(QEC, Quantum Error Correction)으로 여러 물리 큐비트를 묶어 **논리 큐비트** 구현 | 물리 큐비트 대비 논리 큐비트 오류율 |
| 장거리 양자 통신의 거리 제약 | 광섬유에서 광자 손실이 누적되고, 복제 불가 원리 때문에 양자 신호를 중간에서 증폭할 수 없음 | 신뢰 노드 기반의 단계적 네트워크 구축, 장기적으로 양자 중계기 연구 | 링크 거리, 키 생성률 |
| 암호 전환 지연과 선수집 위협 | 지금 암호화된 데이터를 미리 수집해 두었다가 향후 해독하려는 공격에 장기 보관 데이터가 노출 | 미국 NIST(National Institute of Standards and Technology) 표준 PQC(ML-KEM, ML-DSA) 도입, 암호 민첩성을 갖춘 시스템 설계 | 전환 완료율, 장기 보관 데이터 식별 건수 |

## Ⅵ. 양자기술에 대한 기술사적 제언

- 핵심 요약 : 공공 연산 인프라, 단계별 암호 전환, 전환 인력 양성을 함께 설계해야 양자기술의 도입이 실효성을 가짐.
- 정부는 양자 컴퓨팅 클라우드와 하이브리드 양자-고전 컴퓨팅(HQC, Hybrid Quantum-Classical Computing) 환경을 공공 연구 인프라로 제공해, 대학과 중소기업이 장비 투자 없이 알고리즘을 실험할 수 있는 기반을 넓히는 것이 좋다.
- 공공·금융·국방 분야는 암호 전환 계획을 단계별로 세우고, 장기 보관이 필요한 데이터부터 PQC를 우선 적용하며, 특정 망에 한해 QKD를 병행 검토하는 것이 현실적이다.
- 국가 차원에서는 PQC 전환 로드맵과 양자 인력 양성 계획을 한 체계로 묶어, 암호 전환을 실행할 인력과 기술 검증 체계가 함께 자라도록 조율하는 것이 바람직하다.

## Ⅶ. 결론

- 핵심 요약 : 양자기술은 양자 연산으로 계산 능력을 넓히고 양자 원리로 통신과 계측의 안전성과 정밀도를 높이는 차세대 기반 기술.
- 시사점 : 기술 확보 속도만큼 현행 암호를 바꾸는 전환 속도가 안보 측면의 관건이 되는 구도.
