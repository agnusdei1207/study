## 연관 키워드
- NPU(Neural Processing Unit), MAC, 데이터플로, 추론 가속, 양자화, 컴파일러

## Ⅰ. NPU의 개요
- 핵심 요약 : NPU는 신경망 텐서 연산을 병렬 처리하도록 설계된 AI 전용 프로세서.
- 개념 : **NPU**(Neural Processing Unit)는 행렬·벡터 연산 패턴에 맞춘 연산 배열과 메모리 경로를 갖춘 가속기.
- 배경 및 필요성 : 신경망 연산량과 메모리 이동이 증가해 범용 프로세서만으로 전력·지연 목표를 달성하기 어려움.
- 주요 목적 : 목표 모델에서 처리량·지연·전력 요구 충족.

## Ⅱ. 구조 및 장점
- 핵심 요약 : MAC 배열과 로컬 메모리의 데이터 재사용으로 연산 병렬성과 전력 효율 향상.
- MAC(Multiply-Accumulate) 연산기는 곱셈·누산을 반복 → 텐서 계산 처리량 확대.
- 데이터 타일링과 로컬 버퍼는 입력·가중치 재사용 → 외부 메모리 이동 감소.
- 저정밀 연산은 대역폭·전력을 줄일 수 있으나 모델 정확도 검증 필요.
- 컴파일러와 런타임이 모델 연산자를 하드웨어 실행으로 변환.

## Ⅲ. 모델 실행 흐름
- 핵심 요약 : 모델 그래프를 컴파일해 지원 연산과 메모리 배치에 맞춰 실행.
```text
모델·가중치
  ↓ 연산자 지원·정밀도 변환
컴파일러·런타임
  ↓ 타일·메모리 배치
NPU 실행 → 결과 텐서
```
```text
입력 텐서 → 로컬 메모리
                  ↓
              MAC 배열
                  ↓
부분합 버퍼 → 출력 텐서
```
- 미지원 연산은 CPU 폴백될 수 있어 전체 요청 지연 측정이 필요.

## Ⅳ. 프로세서 비교
- 핵심 요약 : NPU는 지원 신경망 패턴, GPU는 범용 병렬성, CPU는 제어·순차 실행에 강점.
| 비교 축 | CPU | GPU | NPU |
| --- | --- | --- | --- |
| 강점 | 범용·분기 | 대규모 병렬 | 신경망 연산 효율 |
| 유연성 | 높음 | 높음 | 컴파일러·연산자 의존 |
| 평가 | 단일 작업 지연 | 처리량 | 모델별 지연·전력·정확도 |

## Ⅴ. 한계와 방안
- 핵심 요약 : 연산자 호환·메모리 대역폭·정밀도 변화가 이론 성능과 실측 성능의 차이를 만듦.
| 한계 | 원인·영향 | 대응 |
| --- | --- | --- |
| 미지원 연산 | CPU 폴백·지연 증가 | 연산자 커버리지 확인 |
| 메모리 병목 | 가중치·활성값 이동 | 타일링·대역폭 최적화 |
| 정확도 변화 | 양자화 | 대표 데이터 평가 |
| SDK 종속 | 런타임 차이 | 지원 기간·대체 경로 확인 |

## Ⅵ. 도입 제언
- 핵심 요약 : 인프라 담당자는 칩 이론 처리량 대신 목표 모델의 종단간 지표를 비교.
- 모델팀은 정확도·메모리·동시성·폴백을 실제 배포 조건에서 시험.

## Ⅶ. 결론
- 핵심 요약 : NPU 효과는 연산 배열뿐 아니라 컴파일러·메모리·모델 호환성의 결합으로 결정.
- 업무 모델 기준 성능과 전력을 측정해 적합성을 판단.
