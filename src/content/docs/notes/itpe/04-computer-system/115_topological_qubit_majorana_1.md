## 연관 키워드

- 위상 큐비트(Topological Qubit), Microsoft Majorana 1, 마요라나 영에너지 모드(MZM)
- 위상 초전도체(Topoconductor), 브레이딩(Braiding), 클리포드 게이트, 매직 스테이트 증류
- 결맞음(Coherence), 양자 오류 정정(QEC), 위상 갭 프로토콜(TGP), US2QC

## Ⅰ. 위상 큐비트의 개요

- 핵심 요약 : 잡음에 강한 큐비트를 물질의 위상 구조에서 얻으려는 접근과, 이를 소자로 구현해 공개한 마이크로소프트 Majorana 1 칩의 의미.
- 개념 : 국소적 물리 상태가 아니라 **위상수학적 성질** (Topological Invariance, 국소적 변형에도 변하지 않는 전역적 성질)에 정보를 부호화하는 **위상 큐비트** (Topological Qubit) 방식과, 이를 위상 코어 기반 양자 칩으로 구현해 2025년 2월 공개한 마이크로소프트의 Majorana 1.
- 배경 및 필요성 : 초전도·이온 트랩 등 기존 물리 큐비트는 열·전자기 잡음에 **결맞음** (Coherence, 양자 상태가 유지되는 성질)이 쉽게 깨져, 다수의 물리 큐비트를 묶어 하나의 논리 큐비트를 만드는 **양자 오류 정정** (QEC, Quantum Error Correction) 부담이 컸음.
- 주요 목적 : 하드웨어 수준의 오류 내성 확보와 소자 수 절감을 통한 백만 큐비트급 양자 컴퓨터 실현 경로의 개척.

## Ⅱ. 위상 큐비트의 특징 및 장점

- 핵심 요약 : 정보의 공간적 분산 저장과 측정 기반 디지털 제어가 오류 내성과 확장성이라는 기대로 이어지는 구조.

1. 비국소 부호화 : 하나의 정보를 나노와이어 양 끝의 **마요라나 영에너지 모드** (MZM, Majorana Zero Mode) 쌍에 나누어 저장 → 국소 잡음의 영향 분산과 오류 내성 기대.
2. 측정 기반 제어 : 아날로그 펄스의 정밀 조정 대신 디지털 측정으로 상태를 판독·검증 → 제어 단순화와 대규모 집적에 유리한 구조.
3. 확장 설계 목표 : 공식 발표 기준 단일 칩에서 백만 큐비트 규모의 확장을 설계 목표로 제시 → 실용 응용에 필요한 큐비트 규모 접근.
4. 외부 검증 병행 : 국제 학술지 네이처(Nature) 표 논문 발표와 미 국방고등연구계획국(DARPA, Defense Advanced Research Projects Agency)의 US2QC(Underexplored Systems for Utility-Scale Quantum Computing) 프로그램 평가 대상 선정 → 독립 검증과 병행되는 개발 구조.

## Ⅲ. 위상 큐비트의 구조 (흐름)

- 핵심 요약 : 반도체·초전도체 접합 나노와이어에서 마요라나 모드를 형성하고, 측정 결과로 논리 연산을 구성하는 계층 구조.

```text
[ 소자 구조와 모드 형성 ]

InAs 반도체 + Al 초전도체 접합
     ↓
하이브리드 나노와이어 형성
     ↓
극저온 환경과 강한 자기장 인가
     ↓
양 끝 마요라나 모드 쌍 생성
```

```text
[ 측정 기반 연산 흐름 ]

모드 상태의 디지털 측정
     ↓
위상 상태 판별과 오류 검출
     ↓
측정 결과에 따른 게이트 구성
     ↓
논리 큐비트 연산 출력
```

- 소재 혁신 : 인듐비소(InAs) 반도체와 알루미늄(Al) 초전도체의 접합으로 만든 **위상 초전도체** (Topoconductor)가 위상 상태 전이를 유도하는 소자 기반.
- 오류 판별 : 측정 신호로 모드의 존재와 오류 여부를 판별하는 구조이므로, 소자마다 아날로그 보정이 필요한 기존 방식과 제어 비용 구조가 다름.

## Ⅳ. 위상 큐비트와 기존 물리 큐비트의 비교

- 핵심 요약 : 오류 방어를 하드웨어에서 얻으려는 위상 방식과, 성숙한 제어 기술을 앞세운 초전도·이온 트랩 방식의 차별점.

| 비교 항목 | 위상 큐비트 (Majorana 1) | 초전도 큐비트 (트랜스몬) | 이온 트랩 큐비트 |
| :--- | :--- | :--- | :--- |
| 소자 기반 | 위상 초전도체 나노와이어 | 조셉슨 접합 인공 원자 | 전자기 포착 이온·레이저 |
| 오류 방어 | 하드웨어 위상 보호 (검증 진행) | 소프트웨어적 오류 정정 | 긴 결맞음 시간 활용 |
| 제어 방식 | 측정 기반 디지털 제어 | 마이크로파 펄스 정밀 제어 | 레이저 펄스 제어 |
| 확장 접근 | 백만 큐비트 설계 목표 | 칩 집적과 상호연결 확장 | 이온 체인·모듈 연결 |
| 성숙도 | 소자 물리 검증 단계 | 수백 큐비트 시연 완료 | 클라우드 서비스 제공 중 |
| 대표 주체 | Microsoft | IBM, Google | IonQ, Quantinuum |

- 선택 기준 : 오류 정정 오버헤드의 최소화를 먼저 볼 것인지, 검증된 성숙도와 제어 기술을 먼저 볼 것인지에 따라 평가가 달라지는 기준.

## Ⅴ. 위상 큐비트의 한계와 방안

- 핵심 요약 : 모드 존재 입증의 학계 논쟁, 범용 게이트 미완, 성숙도 격차가 주요 한계이며 검증 절차, 보조 기법, 공공 벤치마킹으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 모드 존재 입증 논쟁 | 계면 결함의 유사 신호와 실제 모드 신호의 구분 난도 → 결과 해석 이견 | **위상 갭 프로토콜** (TGP, Topological Gap Protocol) 등 정형화된 검증 절차와 독립 재현 | 전도도 양자화 측정 재현성 |
| 범용 게이트 미완 | 모드 교환인 **브레이딩** (Braiding) 연산이 클리포드 게이트 범위에 머무름 → T 게이트 보완 필요 | **매직 스테이트 증류** (Magic State Distillation) 등 비위상 연산 보조 기법 결합 | 증류에 소요되는 자원 비용 |
| 성숙도 격차 | 경쟁 방식은 큐비트 확장·클라우드 제공 단계 → 상용화 로드맵 불확실 | US2QC 같은 공공 검증 프로그램 연계와 단계별 독립 벤치마킹 | 소자 검증 단계 달성 수준 |

## Ⅵ. 위상 큐비트에 대한 기술사적 제언

- 핵심 요약 : 위상 큐비트를 단기 상용 기술이 아닌 장기 전략 기술로 관리하고, 활용 소프트웨어 역량을 하드웨어와 무관하게 먼저 준비해야 함.

1. 정부와 공공 연구기관은 마요라나 소자의 독립 재현 실험과 공공 검증 프로그램 참여를 국가 양자 로드맵에 포함해 기술 불확실성을 체계적으로 관리해야 한다.
2. 기업 정보전략 부서는 고성능 컴퓨팅과 양자 자원을 잇는 하이브리드 파이프라인과 양자 회로 모델링 인력을 먼저 확보해, 하드웨어 성숙 여부와 무관하게 활용 준비를 갖추어야 한다.

## Ⅶ. 결론

- 핵심 요약 : 위상 큐비트는 오류 내성을 물질 자체에서 얻으려는 가장 야심적인 경로이며, Majorana 1은 그 첫 단계 칩 공개라는 위치.
- 시사점 : 기대 효과와 검증 단계를 구분해 평가하는 태도가 양자 기술 판단의 기본 기준이 됨.
