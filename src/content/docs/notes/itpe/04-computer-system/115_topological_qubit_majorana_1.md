## 30초 인출

- 본질: 위상 큐비트는 마요라나 제로 모드의 비국소 양자 상태에 정보를 부호화하려는 큐비트 구현 방식
- 메커니즘: 공간적으로 분리한 모드의 페리티로 정보를 표현하고 측정·교환 연산을 연구
- 통찰: 한계: 페리티 측정만으로 MZM·브레이딩·오류 내성을 입증할 수 없음 → 방안: 대체 신호 배제부터 논리 오류율까지 단계별로 검증한다.

<details>
<summary>핵심 용어</summary>

- **마요라나 제로 모드(Majorana Zero Mode, MZM)** : 위상 초전도체의 경계·결함에서 나타날 수 있는 영에너지 준입자 모드
- **위상 큐비트(Topological Qubit)** : 위상 상태·준입자 자유도에 정보를 부호화하는 양자 정보 단위
- **페리티(Parity)** : 페르미온 점유의 짝·홀 상태를 구분하는 물리량
- **브레이딩(Braiding)** : 비가환 애니온을 교환해 양자 상태에 연산을 구현하는 과정
- **안드레예프 속박 상태(Andreev Bound State)** : 초전도체와 정상 전도체 경계 등에 형성될 수 있는 국소화 에너지 상태

</details>

## 2~4교시 25점 답안

### Ⅰ. 위상 큐비트의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **위상 큐비트는** 마요라나 제로 모드의 비국소 양자 상태에 정보를 부호화하려는 큐비트 구현 방식 |
| 목적 | 국소 잡음에 대한 민감도를 낮추는 오류 내성 양자정보 표현 연구 |

### Ⅱ. 위상 큐비트의 특징

| 특징 | 의미 |
|---|---|
| 비국소 부호화 | 분리된 자유도에 정보가 걸치도록 설계 |
| 페리티 판독 | 모드의 짝·홀 상태를 구분해 정보 획득 |
| 위상 보호 목표 | 국소 교란에 대한 민감도 감소를 목표로 하나 실증 필요 |

### Ⅲ. 부호화·검증 체계와 프로세스

**핵심 연구 체계**

```text
하이브리드 초전도 소자 → MZM 후보 형성·분리
       → 복수 모드 페리티에 논리 상태 부호화 시도
       → 페리티 측정·모드 조작/브레이딩 연구
       → 재현성·논리 연산·오류율 검증
```

**하위 메커니즘: 측정 결과의 실증 해석**

```text
초기 상태 준비 → 단일 샷 페리티 판독 → 반복성·잡음 의존성 측정
             → 안드레예프 속박 상태 등 대체 원인 검토
             → MZM 증거·연산 증거·오류 보호 증거를 별도 판정
```

### Ⅳ. 주장과 필요한 증거의 관계

| 주장 단계 | 필요한 검증 | 아직 별도로 필요한 것 |
|---|---|---|
| 페리티 판독 | 측정 신뢰도·반복성 | MZM 기원 판별 |
| MZM 존재 | 대체 국소 상태 배제·비국소성 확인 | 비가환 연산 |
| 위상 연산 | 브레이딩·논리 게이트 검증 | 오류율과 확장성 |
| 오류 내성 | 논리 오류 억제의 반복 실험 | 시스템 규모 확장 |

### Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 제로 바이어스 신호만으로 MZM을 확정할 수 없음 | 안드레예프 상태 등 대체 원인을 실험적으로 배제 |
| 페리티 판독만으로 위상 보호를 입증할 수 없음 | 비국소성·잡음 의존성·반복 재현성을 측정 |
| 부품 측정에서 논리 연산까지 검증 간극 | 브레이딩·논리 게이트·오류율을 단계별 시험 |

2025년 InAs–Al 단일 샷 페리티 측정 논문은 관련 측정 기술을 다루지만, 논문에 실린 결과만으로 보고 장치의 MZM 존재를 입증한 것은 아니라는 Nature 편집자 주의가 함께 제시됨

### Ⅵ. 제언

페리티 측정 성과를 곧바로 오류 내성 큐비트의 실증으로 해석하면 기술 성숙도를 과대평가한다. **MZM 판별→비국소성→논리 연산→논리 오류 억제**를 독립된 검증 관문으로 두고 각 관문의 반증 가능한 결과를 제시해야 한다.
