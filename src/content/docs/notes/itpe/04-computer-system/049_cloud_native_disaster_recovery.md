## 지식 로드맵 내 현재 위치

## 30초 인출

- 본질: 가상머신 단위의 무거운 스냅샷 복구는 복구 시간(RTO)이 길고 비용이 큼
- 메커니즘: 애플리케이션을 무상태(Stateless) 컨테이너로 추상화하고 데이터는 다중 리전 분산 저장소로 이원화

## 핵심 용어

- RTO(Recovery Time Objective): 재해 발생 후 비즈니스가 허용하는 최대 복구 소요 시간
- RPO(Recovery Point Objective): 재해 발생 시 데이터 유실이 허용되는 최대 시점 간격
- GitOps: Git 저장소를 단일 진실 공급원(Single Source of Truth)으로 삼아 클러스터 인프라와 앱 상태를 선언적으로 동기화하는 배포 모델

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
[ 클라우드 네이티브 멀티 리전 Active-Active DR 아키텍처 ]

                      [ 글로벌 Anycast DNS / GSLB ]
                       │                         │
            (정상 트래픽 50%)              (정상 트래픽 50%)
                       ▼                         ▼
        +─────────────────────────+   +─────────────────────────+
        | Primary Region (Seoul)  |   | Secondary Region (Tokyo)|
        |  +───────────────────+  |   |  +───────────────────+  |

        |  +─────────┬─────────+  |   |  +─────────┬─────────+  |
        |            ▼            |   |            ▼            |

        |  +───────────────────+  |   |  +───────────────────+  |

        |    [ Distributed DB ]   |<─(양방향 비동기)─>[ Distributed DB ]|
        +─────────────────────────+ 복제 / Quorum   +─────────────────────────+
```

### Ⅱ. 핵심 특성

- 컨테이너 자체는 복구 대상이 아님 → 이미지와 선언적 매니페스트(YAML)만 있으면 어느 리전에서든 초 단위로 파드를 띄울 수 있으므로, 재해복구의 본질은 '상태(Stateful Data)'의 복제 지연 극복임
- Active-Active는 단순 이중화가 아니라 합의 알고리즘의 문제임 → 리전 간 거리에 따른 네트워크 왕복 시간(RTT) 때문에 완전 동기 복제는 쓰기 처리량을 저하시키고, 비동기 복제는 데이터 유실 위험을 수반함
- 복구 절차서는 재해 시 작동하지 않음 → 정기적인 카오스 엔지니어링(Chaos Engineering)을 통해 운영 중에 임의로 리전 네트워크를 차단하고 복구 동작을 검증해야 함

### Ⅲ. 관련 개념과 구분

- 전통적 DR vs 클라우드 네이티브 DR: 전통적 DR = Standby 서버 대기, 스토리지 볼륨 복제 기반 수동 페일오버(시간 단위) / 클라우드 네이티브 DR = 오토스케일링과 GitOps 배포, 글로벌 라우팅 기반 자동 전환(분·초 단위)

### Ⅳ. 적용 문제와 대응

- 사례: 140회 기출 및 카카오 데이터센터 화재 이후 공공·금융 클라우드 재해복구 고도화 지침
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 리전 간 분산 DB 페일오버 시 Split-Brain 발생 | 리전 간 통신 두절 시 양쪽이 스스로를 마스터로 승격 | 제3 중립 지역에 쿼럼(Witness 노드) 배치 및 Raft 합의 프로토콜 적용 | 정족수 미달 리전의 쓰기 자동 차단으로 데이터 무결성 보장 |
| DR 리전 파드 급증 시 이미지 풀 병목 및 기동 지연 | 수백 개 파드가 중앙 레지스트리로 동시 다운로드 요청 | 리전별 로컬 컨테이너 레지스트리 미러링 및 P2P 이미지 배포 | 파드 스케일아웃 기동 시간 단축 |
