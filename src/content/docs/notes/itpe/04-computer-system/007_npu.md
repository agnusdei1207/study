## 연관 키워드

- NPU(Neural Processing Unit), 텐서(Tensor), 곱셈-누산(MAC, Multiply-Accumulate), 시스톨릭 어레이(Systolic Array)
- 온칩 SRAM(Static Random Access Memory), 데이터 재사용, 양자화(Quantization), 저정밀도 연산
- CPU(Central Processing Unit), GPU(Graphics Processing Unit), 이종 컴퓨팅(Heterogeneous Computing), 온디바이스 AI(On-Device AI)

## Ⅰ. NPU의 개요

- 핵심 요약 : 신경망 연산의 행렬 곱을 대규모 병렬 하드웨어로 처리해 전력당 연산 성능을 높이는 전용 프로세서.
- 개념 : **NPU** (Neural Processing Unit)는 인공지능(AI, Artificial Intelligence)의 기본 연산인 다차원 배열 **텐서** (Tensor)의 행렬 곱셈과 **곱셈-누산** (MAC, Multiply-Accumulate)을 저전력으로 가속하도록 설계된 전용 프로세서.
- 배경 및 필요성 : 범용 프로세서는 명령 제어에 최적화되어 연산 대비 데이터 이동 비용이 크고, 그래픽 처리 장치(GPU, Graphics Processing Unit)는 전력 소모가 커서 배터리로 동작하는 모바일·엣지 환경의 신경망 추론에 부적합함.
- 주요 목적 : 연산 배열의 병렬화, 칩 내부 메모리의 데이터 재사용, 저정밀도 연산 지원으로 전력당 추론 성능의 극대화.

## Ⅱ. NPU의 특징 및 장점

- 핵심 요약 : MAC 배열 병렬화, 시스톨릭 구조, 온칩 재사용, 저정밀도 연산이 전력 효율이라는 장점으로 수렴하는 구조.

1. MAC 병렬화 : 곱셈기와 누산기를 대규모 배열로 배치 → 합성곱과 행렬 곱의 동시 처리로 연산 처리량 증대.
2. 시스톨릭 어레이 : 인접 연산 셀이 데이터를 다음 셀로 순차 전달하는 **시스톨릭 어레이** (Systolic Array) 구조 → 셀 간 전달만으로 연산이 진행되어 메모리 접근 에너지 절감.
3. 온칩 데이터 재사용 : 가중치와 활성화 값을 **온칩 SRAM** (SRAM, Static Random Access Memory) 버퍼에 상주 → 외부 메모리 왕복 최소화로 병목과 전력 소모 완화.
4. 저정밀도 연산 : 워크로드에 맞춘 **양자화** (Quantization) 형식의 연산 지원 → 데이터 폭 축소로 메모리 대역폭 요구와 전력 소모 감소.

## Ⅲ. NPU의 구조 (흐름)

- 핵심 요약 : 입력 데이터가 온칩 버퍼에 적재되어 MAC 배열에서 병렬 연산되고 후처리를 거쳐 출력되는 파이프라인.

1. 호스트 인터페이스 : 시스템 버스를 통해 모델 가중치와 입력 데이터를 수신.
2. 온칩 버퍼 : 반복 사용되는 가중치와 타일 단위 입력을 칩 내부에 유지.
3. MAC 배열 : 시스톨릭 방식으로 행렬 연산을 수행하는 연산 코어 집합.
4. 후처리 유닛 : 활성화 함수, 풀링, 재양자화를 연산 직후의 데이터 흐름에서 처리.

```text
[ NPU 데이터 처리 흐름 ]

호스트 인터페이스 (입력 수신)
   ↓
온칩 버퍼 (가중치 · 활성화 상주)
   ↓
MAC 배열 (시스톨릭 연산)
   ↓
후처리 (활성화 · 풀링 · 재양자화)
   ↓
출력 버퍼 → 외부 메모리
```

```text
[ 타일 단위 재사용 루프 ]

입력을 타일 단위로 분할
   ↓
타일 적재 → MAC 배열 연산
   ↓
중간 결과를 온칩에 유지
   ↓
다음 타일 연산 (재사용)
   ↓
전체 완료 후 결과 출력
```

## Ⅳ. CPU·GPU·NPU의 비교

- 핵심 요약 : CPU(Central Processing Unit)는 범용 제어, GPU는 범용 병렬 연산, NPU는 신경망 연산에 각각 강점을 가지는 분업 구조.

| 비교 항목 | CPU | GPU | NPU |
| --- | --- | --- | --- |
| 설계 목적 | 범용 명령 처리와 제어 | 그래픽·범용 병렬 연산 | 신경망 연산 전용 가속 |
| 연산 구조 | 소수의 고성능 코어 | 다수의 병렬 코어 | 전용 MAC 배열 |
| 데이터 공급 | 캐시 계층 중심 | 고대역폭 외부 메모리 | 온칩 버퍼 재사용 중심 |
| 연산 정밀도 | 범용 정밀도 | 다양한 정밀도 지원 | 저정밀도 특화 |
| 전력 효율 | 워크로드에 따라 상이 | 병렬 처리에 최적화 | 지원 모델에서 최고 수준 |
| 대표 용도 | 시스템 제어, 로직 처리 | 학습, 시뮬레이션 | 추론, 온디바이스 AI |

- 선택 기준 : 제어 로직과 다양한 작업의 혼재는 CPU를, 대규모 학습과 유연한 병렬 처리는 GPU를, 반복적 신경망 추론과 전력 제약 환경은 NPU를 우선 배치하는 방식으로 판단.

## Ⅴ. NPU의 한계와 방안

- 핵심 요약 : 연산자 호환성, 메모리 병목, 정확도 손실의 제약을 컴파일러 최적화, 메모리 구조 개선, 정밀도 전략으로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 연산자 호환성 부족 | 미지원 연산자가 범용 프로세서로 우회 실행되어 성능 저하 | 컴파일러 툴체인으로 연산자 치환·융합, 미지원 연산자의 대체 설계 | 전체 연산 중 가속 비율 |
| 메모리 용량·대역폭 병목 | 모델 크기가 온칩 버퍼를 초과하면 외부 메모리 접근 증가 | 모델 경량화, 메모리 근처 연산인 **PIM** (Processing-In-Memory) 검토 | 연산 장치 가동률 |
| 양자화 정확도 손실 | 저정밀도 변환 과정에서 민감 작업의 품질 저하 | 양자화 인식 훈련인 **QAT** (Quantization-Aware Training), 민감 층의 혼합 정밀도 유지 | 원 모델 대비 정확도 차이 |

## Ⅵ. NPU에 대한 기술사적 제언

- 핵심 요약 : 워크로드의 역할 분담, 개방형 소프트웨어 생태계, 하드웨어와 모델의 공동 설계를 중심으로 확산하는 방향.

- 시스템 설계 조직은 범용 제어는 CPU, 유연한 병렬 처리는 GPU, 반복 추론은 NPU에 배치하는 **이종 컴퓨팅** (Heterogeneous Computing) 구조를 설계 원칙으로 채택.
- 플랫폼·생태계 주체는 개방형 컴파일러와 주요 딥러닝 프레임워크와의 연동을 표준 지원 범위로 확보하여 특정 장치의 종속을 완화.
- 모바일·차량 분야의 개발 조직은 배터리와 발열 제약을 감안해 모델 구조와 하드웨어를 함께 설계하는 공동 설계 방식으로 **온디바이스 AI** (On-Device AI) 경쟁력을 확보.

## Ⅶ. 결론

- 핵심 요약 : NPU는 신경망 연산의 전력 효율을 극대화하는 전용 프로세서로, 이종 컴퓨팅의 추론 담당 축을 이룸.
- 그 가치는 지원 모델에서 실측한 전력당 성능과 정확도의 균형으로 판단되어야 함.
