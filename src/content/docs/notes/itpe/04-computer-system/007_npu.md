## 30초 인출

- 본질: **NPU(Neural Processing Unit)** 는 신경망 연산을 효율적으로 수행하도록 연산기·메모리 이동을 특화한 가속기
- 메커니즘: 컴파일러가 모델 연산을 하드웨어에 배치하고 온칩 데이터 재사용과 병렬 MAC 연산으로 추론 수행
- 통찰: 딥러닝 매트릭스 연산에 특화된 고집적 MAC 어레이와 전용 메모리 계층을 통해 전력 대비 추론 처리량을 극대화하는 인공지능 가속기임.

<details><summary>핵심 용어</summary>

- **NPU (Neural Processing Unit)** : 신경망 연산에 맞춰 데이터 경로와 연산기를 특화한 가속기.
- **MAC (Multiply-Accumulate)** : 곱셈 결과를 누산하는 연산으로, 행렬·텐서 계산의 기본 연산.
- **NoC (Network-on-Chip)** : 칩 안의 연산기·메모리·제어 블록 사이 데이터 전달을 맡는 연결 구조.
- **양자화 (Quantization)** : 모델의 수치 표현 정밀도를 낮추거나 바꾸어 연산·저장 부담을 조정하는 변환.
- **DMA (Direct Memory Access)** : CPU가 각 데이터를 직접 복사하지 않고 장치가 메모리 전송을 수행하는 기능.
- **TOPS (Tera Operations Per Second)** : 초당 조 단위 연산 횟수를 나타내는 처리량 표기.
- **TPU (Tensor Processing Unit)** : Google이 신경망 텐서 연산용으로 설계한 특정 가속기 계열의 명칭.

</details>

## 2~4교시 25점 답안

## Ⅰ. NPU의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **NPU (Neural Processing Unit)** 는 신경망 연산에 맞춰 데이터 경로와 연산기를 특화한 인공지능 가속기 |
| 목적 | 신경망 추론의 연산 지연과 데이터 이동 부담 완화 |

## Ⅱ. NPU의 특징

| 특징 | 구현 관점 | 효과 |
|---|---|---|
| 병렬 MAC | 행렬·텐서 연산 배열 | 높은 연산 병렬성 |
| 데이터 재사용 | 온칩 SRAM·버퍼·타일링 | 외부 메모리 이동 감소 |
| 저정밀 연산 | INT8 등 모델별 정밀도 | 처리량·에너지 효율 개선 가능 |
| 그래프 실행 | 연산 융합·스케줄링 | 중간 데이터 이동 축소 |
| SW/HW 결합 | 컴파일러·런타임·드라이버 | 모델을 실제 하드웨어에 매핑 |

## Ⅲ. 연산·메모리·정밀도의 결합 구조

```text
모델 그래프 → 컴파일러(융합·양자화·매핑)
                              ↓
외부 메모리 ↔ 온칩 버퍼 ↔ MAC 배열 → 출력 버퍼
                    ↑ 재사용으로 외부 이동 축소
```

### 데이터 경로의 구성요소

| 구성 | 역할 | 답안 키워드 |
|---|---|---|
| PE/MAC Array | 곱셈·누산 병렬 처리 | Tensor Compute |
| On-chip Buffer | 가중치·활성값 재사용 | Data Locality |
| Interconnect | PE·메모리 간 전달 | Bandwidth |
| DMA/Controller | 외부 메모리 전송·실행 제어 | Data Movement |
| Compiler/Runtime | 연산 지원 여부·배치·스케줄 | Operator Mapping |

### 모델 변환부터 실측까지

모델 그래프를 최적화 및 매핑한 뒤 NPU에서 실행하고, 미지원 연산의 CPU 대체까지 포함해 실제 데이터의 정확도, 지연, 처리량, 전력을 실측 검증.

```text
연산별 NPU 지원 확인
  ├─ 지원 → 정밀도·타일 크기 결정 → NPU 실행
  └─ 미지원 → CPU 대체 실행 → 왕복 전송·지연 포함
                    ↓
          기준 모델과 정확도·종단 성능 비교
```

## Ⅳ. CPU·GPU·NPU·TPU 비교

| 구분 | CPU | GPU | NPU | TPU |
|---|---|---|---|---|
| 지향 | 범용·제어 중심 | 대규모 병렬 처리 | 신경망 특화 | 특정 업체의 텐서 가속기 계열 |
| 유연성 | 높음 | 높음 | 지원 연산에 좌우 | 세대·환경에 좌우 |
| 강점 | 분기·OS·전처리 | 학습·범용 병렬 | 전력·지연 제약 추론 | 대규모 텐서 처리 |
| 유의 | 병렬 AI 효율 | 전력·메모리 | 컴파일러·연산 커버리지 | 생태계·배포 조건 |

용어 구별: TPU는 특정 제품 계열의 명칭, NPU는 신경망 연산 가속기의 일반적 분류.

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 양자화·연산 치환으로 정확도 저하 | 대표 데이터 보정·혼합 정밀도를 적용하고 기준 모델과 품질 비교 |
| 메모리 대역폭·Host 왕복으로 성능 미달 | 연산 융합·타일 조정 후 종단 지연·처리량 확인 |
| 미지원 연산의 CPU 대체 증가 | 지원표를 확인해 모델을 재구성하고 NPU 실행 비율 측정 |
| 지속 부하에서 열·전력 제한 | 냉각·부하를 조정하고 지속 성능·에너지 계측 |
| 전용 컴파일러·포맷 종속 | 중간 표현·추상 계층과 이식 시험 준비 |
| 펌웨어·모델 공급망 위험 | 서명·암호화·업데이트로 무결성 확인 |

평가 기준: **모델·데이터셋·품질 목표·시나리오·전력 측정 경계를** 동일하게 고정한 비교.

## Ⅵ. 도입/구축/운영 관점 제언

### 1. 실무 적용 가이드 및 핵심 고려사항
컴파일러 최적화 단계에서 INT8/FP8 양자화 손실을 철저히 검증하고, NPU 하드웨어가 직접 가속하지 못하는 연산자의 CPU 폴백(Fallback) 지연을 방지하기 위한 연산자 커버리지 선행 분석 필수.

### 2. 아키텍처 및 상세 메커니즘
```text
[ AI 모델 (ONNX / PyTorch) ] ──> [ NPU 전용 컴파일러 ] ──> [ 컴파일 최적화 바이너리 ]
                                  (연산자 융합, 양자화)          │
                                                                 ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [ NPU 하드웨어 아키텍처 ]                                                              │
│                                                                                        │
│   ┌───────────────────────────┐     ┌──────────────────────────────────────────────┐   │
│   │ 글로벌 온칩 SRAM 버퍼    │<───>│ 대규모 병렬 MAC 어레이 (Systolic Array)     │   │
│   │ (고대역 가중치/활성화 적재)│     │ (Matrix Multiply & Accumulate 초고속 병렬)   │   │
│   └─────────────┬─────────────┘     └──────────────────────┬───────────────────────┘   │
│                 │                                          │                           │
│                 ▼                                          ▼                           │
│   ┌────────────────────────────────────────────────────────────────────────────────┐   │
│   │ 활성화 함수 유닛 (ReLU, GeLU) & 풀링/정규화 가속 하드웨어                      │   │
│   └────────────────────────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 3. 기술 유형 및 비교 평가
| 프로세서 유형 | 아키텍처 특성 | 강점 영역 | 에너지 효율 (TOPS/W) | 프로그래밍 유연성 |
|---|---|---|---|---|
| **CPU** | 소수 고성능 코어, 대형 캐시, 분기예측 | 순차 제어, 복잡한 비즈니스 로직 | 낮음 (~0.1) | 최고 (범용 언어 및 OS) |
| **GPU** | 수천 개 SIMT 코어, 초고대역 HBM | 범용 병렬 부동소수점, 모델 학습 | 보통 (1~3) | 높음 (CUDA, OpenCL) |
| **NPU** | 고집적 MAC 매트릭스, 양자화 전용 가속 | 온디바이스 및 데이터센터 추론 가속 | 매우 높음 (5~15+) | 보통 (전용 컴파일러 의존) |
| **TPU** | 시스톨릭 어레이, 행렬연산기(MXU) | 대규모 텐서 연산, 클라우드 AI | 높음 (3~8) | 보통 (XLA 컴파일러 전용) |
