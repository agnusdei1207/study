## 연관 키워드

- 간헐적 컴퓨팅(Intermittent Computing), 에너지 하베스팅(Energy Harvesting), 전진 진행(Forward Progress)
- 체크포인팅(Checkpointing), 태스크 기반 모델, DAG(Directed Acyclic Graph), 멱등성(Idempotency)
- 비휘발성 메모리(NVM, Non-Volatile Memory), FRAM, MRAM, 사이드 이펙트(Side Effect)
- 무한 재부팅 루프, 시간 소실(Time Disruption), RTC(Real-Time Clock)

## Ⅰ. 간헐적 컴퓨팅의 개요

- 핵심 요약 : **간헐적 컴퓨팅** (Intermittent Computing)은 에너지 하베스팅 환경에서 전원 단절이 반복되어도 상태를 보존하며 작업을 완수하는 배터리리스 컴퓨팅 방식.
- 개념 : 태양광, RF(Radio Frequency), 열, 진동 등 주변 에너지를 **에너지 하베스팅** (Energy Harvesting)으로 수집해 동작하는 초저전력 장치가, 잦은 전원 단절 속에서도 연산 상태를 보존하고 복원 후 중단 지점부터 작업을 이어가는 방식.
- 배경 및 필요성 : 화학 배터리의 부피·교체·폐기 부담 때문에 인체 삽입 의료기기, 매립형 센서, 무인 원격지 장비처럼 배터리 교체가 현실적이지 않은 환경의 수요 증가.
- 주요 목적 : 불안정 전원에서도 **전진 진행** (Forward Progress)의 보장, 연산 상태의 일관성 유지, 전력 장애에 대한 복원력 확보.

## Ⅱ. 간헐적 컴퓨팅의 특징 및 장점

- 핵심 요약 : 체크포인팅과 태스크 기반 모델, 비휘발성 저장 기반이 전원 단절 시점에도 진행 상태를 일관되게 유지하는 수단.

1. **체크포인팅** (Checkpointing) : 전압 강하 감지 시점에 레지스터와 프로그램 카운터(PC, Program Counter), 휘발성 상태를 **비휘발성 메모리** (NVM, Non-Volatile Memory)에 원자적 백업 → 재부팅 후 마지막 지점 재개 효과.
2. **태스크 기반 모델** (Task-Based Model) : 프로그램을 원자적으로 실행되는 작은 태스크의 DAG(Directed Acyclic Graph)로 분할하고 태스크 경계에서만 상태 커밋 → 재실행 결과의 동일성, 즉 **멱등성** (Idempotency) 확보 효과.
3. 비휘발성 저장 기반 : FRAM(Ferroelectric RAM)과 MRAM(Magnetoresistive RAM)의 저전력 쓰기 특성 활용 → 잦은 상태 저장에도 낮은 에너지 소모 효과.

## Ⅲ. 간헐적 컴퓨팅의 구조 (흐름)

- 핵심 요약 : 에너지 축적과 상태 복원, 연산, 체크포인팅, 전원 단절이 맞물려 반복되는 루프 구조.
- NVM : FRAM·MRAM처럼 전원이 없어도 내용이 유지되어 체크포인트 저장처가 되는 메모리.

```text
[ 동작 루프 ]

에너지 하베스터 (태양광 · RF · 열)
      ↓ 에너지 축적
커패시터 충전 (전압 상승)
      ↓ 기동 전압 도달
상태 복원 (NVM의 마지막 체크포인트)
      ↓
연산 수행 → 체크포인팅
      ↓ 방전 전압 이하
전원 단절 → 재충전 후 복원 단계 복귀
```

```text
[ 태스크 기반 실행 ]

태스크 A 실행 → 출력 변수 커밋 (NVM)
      ↓
태스크 B 실행 (입력을 채널에서 읽음)
      ↓ 전원 단절 시
태스크 B 시작 지점부터 재실행 (멱등)
```

## Ⅳ. 체크포인팅과 태스크 기반 모델의 비교

- 핵심 요약 : 체크포인팅의 자동화 편의와 태스크 기반 모델의 에너지·정합성 이점이 서로 다른 설계 목표에 대응하는 선택지.

| 비교 축 | 체크포인팅 방식 | 태스크 기반 방식 |
| :--- | :--- | :--- |
| 복구 지점 | 마지막 성공 체크포인트 | 중단된 태스크의 시작점 |
| NVM 쓰기 부담 | 전체 컨텍스트 저장으로 큼 | 입출력 변수만 기록하여 작음 |
| I/O 재실행 | 외부 I/O의 중복 가능성 | 채널 기반 전달로 통제 |
| 개발자 부담 | 자동화 지원으로 적음 | DAG 구조의 재설계 필요 |
| 대표 연구 체계 | Mementos, Hibernus | Alpaca, InK |

- 선택 기준 :
  1. 기존 코드의 최소 수정이 필요하면 체크포인팅
  2. 쓰기 에너지 절감과 I/O 정합성이 우선이면 태스크 기반
  3. 태스크 경계에 체크포인팅을 두는 혼합 설계도 옵션

## Ⅴ. 간헐적 컴퓨팅의 한계와 방안

- 핵심 요약 : 재실행 부작용과 진행 정체, 시간 정보 상실을 저널링, 태스크 세분화, 저전력 클록으로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| **사이드 이펙트** (Side Effect) 재실행 오류 | 재개 구간에서 이미 갱신된 NVM 변수의 재판독 → 연산 불일치, WAR(Write-After-Read) 충돌 | Undo-Redo 저널링 적용, 컴파일러 정적 분석으로 멱등 구간 식별 | 재실행 결과 일치율 |
| **무한 재부팅 루프** | 태스크 1회 완료에 필요한 에너지가 저장 용량 초과 → 진행 불가 상태의 반복 | 태스크 세분화, 에너지 유입량에 따른 적응형 체크포인팅 | 재부팅당 완료 태스크 수 |
| **시간 소실** (Time Disruption) | 정전 중 클록 정지로 경과 시간 불명 → 센서 데이터의 타임스탬프 왜곡 | 초저전력 RTC(Real-Time Clock) 탑재, 방전 속도 기반 시간 추정 | 타임스탬프 오차 |

## Ⅵ. 간헐적 컴퓨팅에 대한 기술사적 제언

- 핵심 요약 : 하드웨어·런타임의 동반 공급과 규격화, 도입 검증 절차로 산업 적용의 기반 마련이 필요.

1. 반도체 조직은 FRAM·MRAM 내장 MCU(Microcontroller Unit) 제품군과 체크포인팅 지원 런타임의 동반 공급으로 개발자 재설계 부담 완화.
2. 표준화·산업 단체는 전원 단절 대비 상태 보존 방식과 시간 복원 요건의 규격화로 기기 간 호환성과 검증 기준 확보.
3. 도입 조직은 배치 전 에너지 수지(유입량 대비 소비량) 검증 절차 운영으로 현장 적합성 확인.

## Ⅶ. 결론

- 핵심 요약 : 간헐적 컴퓨팅은 비휘발성 저장과 상태 관리 모델로 전원 단절 후에도 전진 진행을 보장하는 컴퓨팅 방식.
- 시사점 : 배터리 교체가 불가능한 환경의 장기 자율 동작 기반이며, 전원 단절을 전제로 한 상태 설계가 신뢰성의 핵심.
