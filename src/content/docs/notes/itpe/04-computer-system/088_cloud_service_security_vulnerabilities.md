```text
 ┃
 ┣━ Ⅰ 개요 ───── 경계 기반 온프레미스 보안 붕괴 → CSP와 고객 간 서비스 계층별 책임 공유 모델에 따른 신규 공격 표면 발생
 ┣━ Ⅱ 특징 ───── 계층별 책임 분계점 상이 · API 중심 취약점 전파 · 멀티테넌트 격리 실패 위험 · 설정 오류(Misconfiguration) 주도
 ┣━ Ⅲ 구조 ───── IaaS(인프라/가상화 설정) + PaaS(런타임/API/프레임워크) + SaaS(계정/데이터/접근 통제) 취약 계층
 ┣━ Ⅳ 흐름 ───── ① 계층별 자산 식별 → ② CSPM 설정 점검 및 취약점 스캔 → ③ 이상 징후 탐지 → ④ 격리 및 자동 수정(Remediation)
 ┣━ Ⅴ 비교 ───── IaaS 보안(인프라 통제) vs PaaS 보안(런타임 보호) vs SaaS 보안(데이터 및 계정 보호)
 ┗━ Ⅵ 실무 ───── 무단 리소스 퍼블릭 노출 / 과도한 IAM 권한 부여 / 섀도우 IT 및 SaaS 데이터 유출
```
- 필수 키워드: 책임 공유 모델 · CSPM · CWPP · CASB · CIEM · 설정 오류 · API 취약점
- 기출: 128회 2교시 2번 `공공부문 민간 클라우드 도입 시 보안 고려사항` 논술형 출제

## 한 줄 본질
- 클라우드는 인프라 가상화와 서비스 추상화로 인해 기존 네트워크 경계 보안이 무력화됨 → IaaS·PaaS·SaaS 계층별 책임 공유 분계점에 맞춰 고객 책임 영역의 설정 오류, API 노출, 계정 권한을 능동 통제 → 클라우드 침해 사전 차단 / 고객-CSP 간 모호한 책임 구역으로 인한 보안 공백 위험

## 핵심 용어
- 책임 공유 모델(Shared Responsibility Model): 클라우드 보안 책임을 물리/가상화 기반은 CSP가, 데이터/계정/설정은 고객이 분담하는 기본 거버넌스 프레임워크
- CSPM(Cloud Security Posture Management): 클라우드 리소스의 설정 오류(Misconfiguration)와 규정 준수 위반을 자동 탐지하고 교정하는 형상 관리 기술
- CIEM(Cloud Infrastructure Entitlement Management): 멀티 클라우드 환경에서 사용자와 머신 계정의 과도한 권한(Over-privileged)을 식별하고 최소 권한(Least Privilege)을 적용하는 권한 거버넌스 도구

## 핵심 통찰
- 클라우드 침해 사고의 95% 이상은 CSP 결함이 아닌 고객의 설정 오류(Misconfiguration)에서 기인함 → 방화벽보다 IAM 정책과 퍼블릭 스토리지 버킷 노출 여부를 자동 감시하는 것이 침해 방지의 핵심임
- PaaS는 OS 관리 부담을 덜어주지만 런타임 종속성과 API 취약점을 유발함 → 제공자가 주입한 환경 변수, 써드파티 라이브러리 공급망 취약점에 대한 검증 부재 시 서버리스 백도어로 악용됨
- SaaS 확산은 섀도우 IT(Shadow IT)와 비인가 데이터 동기화를 폭증시킴 → CASB를 통하지 않는 비승인 협업 도구 사용은 기업 내부망의 데이터 유출 통제선을 무력화함

## 이웃 토픽과 구분
- CSPM vs CWPP: CSPM = 클라우드 플레인(IAM, 스토리지 버킷, VPC 설정) 형상 감사 / CWPP = 실행 중인 워크로드(VM, 컨테이너, 서버리스 함수) 내부 런타임 보안

## 문제·원인·대책
- 적용 상황: 대규모 퍼블릭 클라우드 전환 기업의 설정 오류로 인한 기밀 유출
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 개발팀의 실수로 고객 개인정보가 담긴 스토리지 버킷이 전 세계에 공개 | 인프라 생성 시 기본 권한 검증 누락 및 수동 배포 오류 | IaC 보안 린터(Checkov) 배포 파이프라인 강제 및 CSPM 실시간 감시 | 퍼블릭 버킷 생성 즉시 자동 격리 및 노출 사고 원천 방지 |
| 퇴사자 계정 및 개발용 IAM Role 탈취로 인한 내부 자원 무단 암호화 | 장기 미사용 액세스 키 방치 및 와일드카드(*) 과다 권한 부여 | CIEM 솔루션을 통한 미사용 권한 회수 및 임시 자격증명(STS) 강제 | 공격 표면 최소화 및 자격증명 유출 시 횡적 이동(Lateral Movement) 차단 |
