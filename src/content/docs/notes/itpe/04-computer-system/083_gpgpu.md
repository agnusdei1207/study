## 한 줄 본질
- CPU는 직렬 제어와 캐시가 비대하여 행렬 연산과 대규모 병렬 계산에서 처리량 한계에 직면함 → 수천 개의 경량 ALU 코어를 집적하고 SIMT(단일 명령 다중 스레드) 방식으로 병렬 연산 처리 → 딥러닝 및 과학 연산 수십~수백 배 가속 / 분기 조건문이 많거나 직렬 연산 워크로드에서는 효율 급락

## 핵심 용어
- SIMT(Single Instruction Multiple Threads): 32개의 스레드를 하나의 '워프(Warp)'로 묶어 동일한 단일 명령어를 서로 다른 데이터에 대해 병렬 실행하는 GPU 고유의 실행 모델
- 워프 발산(Warp Divergence): 워프 내 32개 스레드 간에 `if-else` 분기 조건이 갈릴 때, 조건에 맞지 않는 스레드는 비활성화된 채 직렬로 순차 실행되어 성능이 반토막 나는 현상
- 텐서 코어(Tensor Core): 딥러닝의 핵심인 $4 \times 4$ 행렬 곱셈-누적(Mixed Precision: FP16/BF16/FP8) 연산을 단 1클록 사이클에 끝내도록 특화된 하드웨어 ASIC 유닛

## 핵심 통찰
- GPGPU 혁명의 본질은 'CUDA라는 소프트웨어 생태계'임 → 과거에도 그래픽 칩으로 계산하려는 시도는 있었으나 픽셀 셰이더 문법으로 억지 변환해야 했음 → 엔비디아가 C/C++ 포인터 기반의 CUDA를 내놓으면서 모든 프로그래머가 GPU 병렬 연산에 뛰어들 수 있게 됨
- 호스트-디바이스 간 복사가 최대의 병목임 → 연산은 나노초 만에 끝나는데 PCIe 버스를 통해 CPU RAM에서 GPU VRAM으로 데이터를 실어 나르는 데 마이크로초가 걸림 → Unified Memory와 GPUDirect RDMA가 필수적인 이유임
- 캐시 미스를 '스레드 전환'으로 숨김 → CPU는 캐시 미스가 나면 파이프라인이 멈추지만, GPU는 메모리 응답을 기다리는 동안 워프 스케줄러가 0사이클 만에 다른 워프로 컨텍스트를 스위칭하여 연산기를 100% 굴림

## 이웃 토픽과 구분
- GPGPU vs NPU: GPGPU = 범용 병렬 연산(시뮬레이션, 렌더링, 암호채굴, 딥러닝), 높은 전력, 소프트웨어 유연성 / NPU = 딥러닝 추론 전용, 고정된 매트릭스 연산기, 극도의 저전력 고효율
