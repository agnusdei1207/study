## 연관 키워드

- 메타휴리스틱(Metaheuristics), NP-Hard, 전역 최적해, 국소 최적해
- 탐색(Exploration), 활용(Exploitation), 시뮬레이티드 어닐링(SA), 타부 탐색(Tabu Search)
- 유전 알고리즘(GA), 입자 군집 최적화(PSO), 개미 군집 최적화(ACO)
- 적응형 제어(Adaptive Control), 대리 모델(Surrogate Model), 메멕틱 알고리즘(Memetic Algorithm)

## Ⅰ. 메타휴리스틱의 개요

- 핵심 요약 : **메타휴리스틱** (Metaheuristics)은 최적해 탐색이 어려운 문제에서 탐색과 활용의 균형으로 준최적해를 현실적인 시간 안에 찾는 범용 상위 탐색 프레임워크.
- 개념 : 문제의 세부 구조에 묶이지 않고 해를 탐색하는 전략만 정의한 상위 수준의 발견적 기법 체계. 최적해를 다항 시간에 구하는 알고리즘이 알려지지 않은 **NP-Hard** (최적화 문제 중 난이도가 최상위권인 문제군)에 적용됨.
- 배경 및 필요성 : 외판원 문제(TSP, Traveling Salesperson Problem), 작업 스케줄링, 차량 경로 문제(VRP, Vehicle Routing Problem), 신경망 하이퍼파라미터 최적화처럼 탐색 공간이 기하급수적으로 커지는 문제에서는 정확 기법이 실용 시간 안에 끝나지 않으므로, 품질이 검증된 준최적해를 얻는 방법이 필요해짐.
- 주요 목적 : **국소 최적해** (Local Optimum)에 갇히는 것을 피하면서 **전역 최적해** (Global Optimum)에 근접한 해를 찾는 것. 이를 위해 **탐색** (Exploration)으로 미개척 영역을 넓히고 **활용** (Exploitation)으로 유망 영역을 깊게 파는 균형을 유지함.

## Ⅱ. 메타휴리스틱의 특징 및 장점

- 핵심 요약 : 해의 개수를 기준으로 한 단일 해 기반과 군집 기반의 두 계열이 확률적 이동으로 국소 최적해를 벗어나는 구조.

1. 단일 해 기반 탐색 (Single-Solution Based Search) : 현재 해의 이웃 해로 점진 이동하며, **시뮬레이티드 어닐링** (SA, Simulated Annealing)은 담금질 온도 개념으로 나쁜 해도 확률적으로 수용 → 국소 최적해 탈출 가능.
2. 금기 기억 기반 탐색 : **타부 탐색** (Tabu Search)은 최근 이동을 타부 목록(Tabu List)에 기록해 같은 해로의 순환을 막음 → 이미 탐색한 영역의 반복 방지.
3. 군집 기반 탐색 (Population-Based Search) : 여러 해를 동시에 유지하며 해 사이의 상호작용으로 진화. **유전 알고리즘** (GA, Genetic Algorithm)은 선택·교차·돌연변이, **입자 군집 최적화** (PSO, Particle Swarm Optimization)는 개별 최적 위치와 전역 최적 위치로 이동을 갱신 → 다양성 확보와 수렴 속도의 균형.
4. 블랙박스 범용성 : 목적함수의 미분 정보나 문제 고유 구조를 요구하지 않아 적용 문제의 범위가 넓음 → 설계 변경 없이 여러 도메인에 재사용.

## Ⅲ. 메타휴리스틱의 구조 (흐름)

- 핵심 요약 : 메타휴리스틱은 단일 해 기반과 군집 기반으로 분류되며, 두 계열 모두 탐색과 활용을 반복하는 흐름으로 동작.
- 단일 해 기반은 SA와 타부 탐색이, 군집 기반은 GA, PSO, 개미 군집 최적화(ACO, Ant Colony Optimization)가 대표 기법임.

```text
[ 메타휴리스틱 2대 분류 ]

메타휴리스틱
   - 단일 해 기반 : SA, 타부 탐색
   - 군집 기반 : GA, PSO, ACO
```

```text
[ 탐색-활용 반복 흐름 ]

초기 해 또는 모집단 생성
      ↓
이웃 해·새 해 생성 (탐색)
      ↓
평가 후 유망 영역 집중 (활용)
      ↓
수렴 조건 검사 → 미충족 시 반복
```

## Ⅳ. 메타휴리스틱의 비교

- 핵심 요약 : 다섯 기법은 모방 원리와 핵심 파라미터가 달라, 문제 특성에 맞춰 선택해야 함.

| 기법 | 모방 원리 | 핵심 파라미터 | 주요 적용 분야 |
| --- | --- | --- | --- |
| 시뮬레이티드 어닐링 | 금속의 담금질(가열 후 서서히 냉각) | 초기 온도, 냉각 스케줄 | 조합 최적화, 배치 문제 |
| 타부 탐색 | 최근 이동의 기억과 금기 목록 | 타부 목록 길이, 흡인 기준(Aspiration) | 경로 문제, 작업 스케줄링 |
| 유전 알고리즘 | 자연선택과 유전 | 교차율, 돌연변이율 | 스케줄링, 설계 최적화 |
| 입자 군집 최적화 | 새 떼·어군의 먹이 탐색 | 관성 가중치, 가속 계수 | 연속 함수 최적화, 학습 파라미터 탐색 |
| 개미 군집 최적화 | 개미의 페로몬 경로 강화 | 페로몬 증발률, 가중치 | 네트워크 라우팅, 외판원 문제 |

- 선택 기준 : 해 공간이 이산적이면 SA·타부 탐색과 GA 계열을, 연속 변수 최적화면 PSO를 먼저 검토하며, 경로 문제에서는 ACO가 자주 비교 대상이 됨.

## Ⅴ. 메타휴리스틱의 한계와 방안

- 핵심 요약 : 최적성 보장 부재, 파라미터 민감도, 평가 비용 문제를 최적성 갭 측정, 적응형 제어, 대리 모델로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 최적성 보장 불가 | 발견한 해가 전역 최적인지 증명할 수 없어 품질 신뢰도 저하 | 정수 선형 계획법(ILP, Integer Linear Programming) 솔버의 하한값과 비교해 최적성 갭(Optimality Gap) 산출 | 최적성 갭 |
| 파라미터 민감도 | 초기 온도·교차율 설정이 부적절하면 **조기 수렴** (Premature Convergence)하거나 무작위 탐색으로 전락 | 탐색 진행 상황에 따라 파라미터를 바꾸는 **적응형 제어** (Adaptive Control) 적용 | 수렴 시점, 해 품질의 분산 |
| 목적함수 평가 비용 | 전산 유체 역학(CFD, Computational Fluid Dynamics) 등 시뮬레이션 기반 평가는 개체 하나에 긴 시간이 소요 | 평가 결과로 학습한 **대리 모델** (Surrogate Model)로 평가를 대체 | 실제 평가 횟수, 대리 모델 오차 |

## Ⅵ. 메타휴리스틱의 적용 제언

- 핵심 요약 : 전역 탐색과 국소 정밀 탐색을 결합한 하이브리드 구조를 기본으로 삼고, 평가 인프라와 품질 점검 체계를 함께 갖추는 것이 바람직함.
- 하이브리드 설계 : GA 같은 전역 탐색기에 타부 탐색 같은 국소 정밀 탐색을 결합한 **메멕틱 알고리즘** (Memetic Algorithm) 구조를 표준 설계로 정하고, 문제별 파라미터 범위를 시험 데이터로 축적함.
- 평가 인프라 : 시뮬레이션 비용이 큰 문제는 분산 워커에서 개체 평가를 병렬 실행하도록 연산 환경을 구성하고, 최적성 갭을 주기적으로 점검하는 운영 절차를 둠.

## Ⅶ. 결론

- 핵심 요약 : 메타휴리스틱은 탐색과 활용의 균형으로 NP-Hard 문제의 실용적 해를 찾는 범용 프레임워크임.
- 시사점 : 최적성을 보장하지 않으므로 최적성 갭과 파라미터 관리를 전제로 채택할 때 결과의 신뢰성이 확보됨.
