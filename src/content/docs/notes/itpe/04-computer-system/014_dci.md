## Ⅰ. DCI(Data Center Interconnect)의 개요

- 개념 : 지리적으로 격리된 둘 이상의 데이터센터(IDC) 간에 방대한 분산 워크로드 트래픽 교환, 스토리지 데이터 실시간 동기화, 액티브-액티브 무중단 **재해복구(DR)** 를 구현하기 위해 초고대역폭, 초저지연, 고신뢰성으로 연결하는 전용 고속 전송망 기술.
- 배경 및 필요성 : AI 클러스터 분산 학습, 클라우드 멀티 리전 확장, 대규모 데이터 복제 수요가 폭증하면서 일반 공중망이나 저속 전용선으로는 감당할 수 없는 테라비트(Tbps)급 전송 대역폭과 1ms 이하의 초저지연 백본망이 요구됨.
- 핵심 목적 : 데이터센터 간 네트워크 경계 허물기(L2 확장성), 스토리지 무손실 복제 보장, 데이터센터 재난 시 RTO/RPO 0에 수렴하는 비즈니스 연속성 확보.

## Ⅱ. DCI(Data Center Interconnect)의 핵심 아키텍처 및 동작 메커니즘

DCI는 광전송 물리 계층(DWDM/Coherent Optics), 패킷 전송 계층(OTN/MPLS), 그리고 데이터센터 간 L2/L3 오버레이 네트워크를 확장하는 EVPN-VXLAN 기술의 결합으로 구현됨.

```text
[ DCI 아키텍처 및 전송 프로토콜 계층 ]

[Data Center A (주 데이터센터)]               [Data Center B (DR / 백업 IDC)]
+---------------------------+               +---------------------------+
| Leaf-Spine IP Fabric      |               | Leaf-Spine IP Fabric      |
| (EVPN-VXLAN VTEP)         |               | (EVPN-VXLAN VTEP)         |
+---------------------------+               +---------------------------+
              │                                           │
              ▼                                           ▼
+---------------------------+               +---------------------------+
| DCI Edge Border Leaf / GW |               | DCI Edge Border Leaf / GW |
| (MPLS-SR / Mac-in-IP)     |               | (MPLS-SR / Mac-in-IP)     |
+---------------------------+               +---------------------------+
              │                                           │
              ▼                                           ▼
+-----------------------------------------------------------------------+
| 물리 전송 계층: DWDM / ROADM 광전송 인프라 (400ZR / 800ZR Coherent)  |
|   - 단일 광케이블 코어당 수십~수백 Tbps 전송 (파장 분할 다중화)        |
|   - 광 바이패스를 통한 초저지연 (광속 지연 5us/km 한계 제어)          |
+-----------------------------------------------------------------------+
              ▲                                           ▲
              └────────────────── Dark Fiber ─────────────┘
```

- **DWDM(고밀도 파장 분할 다중화)** : 단일 광섬유 코어에 서로 다른 파장의 빛을 수십~수백 개 결합하여 채널당 400G/800Gbps, 전체 수십 Tbps의 초광대역 전송.
- **EVPN-VXLAN 오버레이** : 데이터센터 간에 동일한 L2 브로드캐스트 도메인을 안전하게 연장하여 가상머신 및 컨테이너 IP 변경 없는 실시간 라이브 마이그레이션(vMotion) 지원.
- **세그먼트 라우팅(SR-MPLS / SRv6)** : 패킷 헤더에 경로 정보를 명시하여 SDN 컨트롤러가 지연시간과 대역폭에 따라 트래픽 경로를 프로그래밍 방식으로 동적 최적화.
- **코히런트(Coherent) 광트랜시버** : 첨단 디지털 신호 처리기(DSP)를 내장하여 수백 km 장거리 전송 시에도 신호 왜곡 및 분산을 능동 보정.

## Ⅲ. DCI(Data Center Interconnect)의 세부 구성 요소 및 비교 분석

| DCI 전송 기술 계층 | 주요 기술 표준 / 프로토콜 | 전송 특성 및 장점 | 주요 적용 분야 |
|---|---|---|---|
| **물리/광 전송 계층** | DWDM, ROADM, 400ZR/800ZR | 파장당 수백 Gbps 대역폭, 초저지연 전송 | 대용량 IDC 간 백본 전송로 구축 |
| **패킷/광 수송 계층** | OTN (Optical Transport Network) | 하드 파이프 기반 대역폭 완벽 보장, FEC 에러 정정 | 통신사 및 금융권 전용 회선 구성 |
| **IP/MPLS 라우팅 계층** | MPLS-TE, SRv6, BGP-LU | 유연한 트래픽 엔지니어링, 고속 경로 우회(FRR) | 대규모 하이퍼스케일러 DCI 코어망 |
| **오버레이 가상화 계층** | EVPN-VXLAN, OTV, VPLS | 동일 IP 유지 L2 연장, 멀티테넌시 테넌트 격리 | VM 무중단 이전, 분산 K8s 클러스터 연계 |

- DCI 기술 선택 시 단순 대역폭뿐만 아니라 물리적 거리에 따른 지연시간(RTT)과 L2 브로드캐스트 스톰 억제 메커니즘을 복합 고려해야 함.

## Ⅳ. DCI(Data Center Interconnect)의 주요 한계점 및 해결 방안

- 물리적 거리에 따른 광 전송 **지연시간(RTT)** 한계 :
  - 한계점 : 빛의 광섬유 내 전송 속도 한계(약 5us/km)로 인해 거리가 100km를 초과할 경우 동기식(Synchronous) 스토리지 복제 시 트랜잭션 지연 발생.
  - 해결 방안 : 준동기식(Semi-sync) 또는 비동기식(Async) 복제 파이프라인 전환, 분산 캐싱 및 애플리케이션 계층 샤딩 적용.
- L2 도메인 확장에 따른 **브로드캐스트 스톰(Broadcast Storm)** 전파 :
  - 한계점 : 데이터센터 간 L2 네트워크를 직접 브리지 연결할 경우 한쪽 IDC의 루프나 ARP 폭증이 반대편 IDC로 즉시 확산되어 동시 다운 유발.
  - 해결 방안 : EVPN-VXLAN 컨트롤 플레인(BGP)을 도입하여 불필요한 ARP 플러딩을 억제하고 Anycast Gateway로 L2 경계 엄격 분리.
- 전용 **DWDM** 장비 도입 및 다크 파이버 임대 비용 부담 :
  - 한계점 : 전통적인 광전송 섀시 장비는 고가이며 랙 상면과 전력을 과다 소비하여 CAPEX/OPEX 부담 가중.
  - 해결 방안 : 스위치 포트에 직접 장착 가능한 컴팩트 400G-QSFP-DD Coherent 플러그형 광모듈(IP-over-DWDM) 도입을 통한 설비 단순화.

## Ⅴ. DCI(Data Center Interconnect) 적용 및 발전을 위한 기술사적 제언

- 분산 **AI 팩토리(AI Factory)** 간 RoCE over DCI 검증 : 데이터센터 간 분산 GPU 클러스터링을 위해 무손실 이더넷(PFC, ECN) 기술을 DCI 광전송망에 적용하는 엔지니어링 테스트 필수.
- 전송 선로 **물리적 이원화(Physical Diversity)** 의무화 : 통신사 회선 이중화 구성 시 동일 관로를 공유하는 논리적 이중화 함정을 방지하기 위해 완전 분리된 굴착 경로 기반 인입 검증 필요.
- 글로벌 리전 액티브-액티브 DR의 기반 인프라 확충 : 데이터 정합성 보장을 위해 DCI 대역폭 확장과 함께 CockroachDB, Spanner 등 분산 합의 기반 DBMS 아키텍처 연계 권장.
