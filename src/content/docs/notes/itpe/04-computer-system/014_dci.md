## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 핵심 개념 → DCI

## 30초 인출

- 본질: 원격 데이터센터 간 공용 인터넷이나 일반 전용선의 대역폭 한계(10G 이하)와 지연 시간으로 인한 실시간 데이터 복제 불가
- 메커니즘: DWDM 광전송 및 EVPN-VXLAN 가상화 오버레이 기술을 통해 분산 데이터센터를 단일 고속 백본으로 직결

## 핵심 용어

- DWDM(Dense Wavelength Division Multiplexing): 단일 광섬유 케이블에 빛의 파장을 수십~수백 개로 미세 분할하여 각 파장마다 100G~800Gbps 데이터를 동시 전송하는 초고용량 광전송 기술
- EVPN-VXLAN: BGP EVPN을 컨트롤 플레인으로, VXLAN을 데이터 플레인으로 사용하여 L3 네트워크 위에서 지리적으로 떨어진 데이터센터 간 L2 네트워크를 안전하게 연장(Extension)하는 오버레이 표준

## 1교시 10점 답안

### 정의·목적

- 정의: DCI은/는 DWDM 광전송 및 EVPN-VXLAN 가상화 오버레이 기술을 통해 분산 데이터센터를 단일 고속 백본으로 직결 방식이다.
- 목적: 테라비트급 무손실 데이터 전송 및 액티브-액티브 무중단 DR 실현에 기여한다.

### 핵심 구조와 작동

```text
+------------------------------+                     +------------------------------+
|     데이터센터 A (DC 1)      |                     |     데이터센터 B (DC 2)      |
|  [ 워크로드 / VM / 파드 ]    |                     |  [ 워크로드 / VM / 파드 ]    |
|              │               |                     |              │               |
|  +-----------v------------+  |                     |  +-----------v------------+  |
|  | DCI Edge (EVPN-VXLAN)  |  |                     |  | DCI Edge (EVPN-VXLAN)  |  |
|  +-----------┬------------+  |                     |  +-----------┬------------+  |
|              │ (L2/L3 캡슐화)|                     |              │               |
|  +-----------v------------+  |                     |  +-----------v------------+  |
|  | Coherent Optical / WDM |  |                     |  | Coherent Optical / WDM |  |
|  +-----------┬------------+  |                     |  +-----------┬------------+  |
+--------------│---------------+                     +--------------│---------------+
               │                                                    │
               └─────────( 다크 파이버 전용 광선로: DWDM )─────────┘
                         - 파장당 400G/800Gbps 다중화
                         - 하드웨어 와이어스피드 암호화 (MACsec)
```

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
+------------------------------+                     +------------------------------+
|     데이터센터 A (DC 1)      |                     |     데이터센터 B (DC 2)      |
|  [ 워크로드 / VM / 파드 ]    |                     |  [ 워크로드 / VM / 파드 ]    |
|              │               |                     |              │               |
|  +-----------v------------+  |                     |  +-----------v------------+  |
|  | DCI Edge (EVPN-VXLAN)  |  |                     |  | DCI Edge (EVPN-VXLAN)  |  |
|  +-----------┬------------+  |                     |  +-----------┬------------+  |
|              │ (L2/L3 캡슐화)|                     |              │               |
|  +-----------v------------+  |                     |  +-----------v------------+  |
|  | Coherent Optical / WDM |  |                     |  | Coherent Optical / WDM |  |
|  +-----------┬------------+  |                     |  +-----------┬------------+  |
+--------------│---------------+                     +--------------│---------------+
               │                                                    │
               └─────────( 다크 파이버 전용 광선로: DWDM )─────────┘
                         - 파장당 400G/800Gbps 다중화
                         - 하드웨어 와이어스피드 암호화 (MACsec)
```

### Ⅱ. 핵심 특성

- DCI는 단순한 백업용 회선이 아니라 '지리적으로 떨어진 데이터센터를 논리적으로 하나의 가상 데이터센터로 묶는 중추 신경망'임 → L2 확장이 가능해야 VM이나 컨테이너가 IP 변경 없이 다른 DC로 실시간 라이브 마이그레이션(vMotion) 가능
- 대규모 AI 클러스터(수만 개 GPU)가 전력 한계로 여러 데이터센터에 분산될 때, 분산 학습 올리듀스(All-Reduce) 동기화가 DCI 대역폭과 RTT에 직접 종속됨
- L2 네트워크를 DCI로 무분별하게 연결하면 한 데이터센터의 브로드캐스트 스톰이나 루핑(Looping) 장애가 원격 데이터센터로 전파되어 두 데이터센터가 동시 마비되는 '운명의 공유(Fate Sharing)' 위험이 발생하므로 컨트롤 플레인 격리(BGP EVPN)가 필수적임

### Ⅲ. 관련 개념과 구분

- DCI vs WAN: 일반 WAN = 다양한 공용 인터넷 및 통신사 망을 경유하는 저속·다목적 광역망 / DCI = 데이터센터 간 대용량 동기화 및 가상화 확장에 특화된 전용 광통신 고대역폭 직결망

### Ⅳ. 적용 문제와 대응

- 사례: 140회 기출 데이터센터 간 재해복구(DR) 시스템 구축 시 동기식 데이터 복제 지연 및 루핑 장애
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 액티브-액티브 DB 동기식(Sync) 복제 시 트랜잭션 지연 급증 | DC 간 물리적 거리에 따른 광 RTT 지연(100km당 왕복 약 1ms) | 50km 이내 단거리 DC 구축 및 비동기 복제 전환(반경 초과 시) | 트랜잭션 병목 해소 및 데이터 일관성 절충 |
| DC 간 L2 확장 구간에서 루프 발생으로 전체 네트워크 다운 | 전통적 STP(Spanning Tree Protocol) 기반 확장 결함 | BGP EVPN 기반 Anycast 게이트웨이 및 프록시 ARP 적용 | L2 브로드캐스트 스톰 전파 원천 차단 |

### Ⅴ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 적용 환경에서 발생하는 핵심 제약 | 기존 대책을 적용하고 핵심 운영 지표를 확인해 개선한다. |
