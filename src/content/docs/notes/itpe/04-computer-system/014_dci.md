## 연관 키워드

- DCI(Data Center Interconnect), DWDM, 코히런트 광트랜시버, 다크 파이버
- EVPN, VXLAN, SRv6, L2 확장, 애니캐스트 게이트웨이, 브로드캐스트 스톰
- OTN, MPLS, FEC, 준동기 복제, RoCE, RTT, RTO, RPO, IP-over-DWDM

## Ⅰ. DCI의 개요

- 핵심 요약 : 지리적으로 분리된 데이터센터를 고대역폭·저지연 광망으로 묶는 데이터센터 간 상호연결 기술.
- 개념 : 서로 떨어진 둘 이상의 데이터센터를 전용 광망으로 연결해 네트워크·스토리지·애플리케이션 자원을 하나의 풀처럼 사용하게 하는 전송 기술인 **DCI** (Data Center Interconnect, 데이터센터 간 상호연결).
- 배경 및 필요성 : 멀티 리전 클라우드 운영과 재해복구 요구로 센터 간 복제 트래픽이 급증하는 가운데, 공중망은 품질 보장이 어렵고 일반 전용선은 대역폭 확장에 한계가 있는 상황.
- 주요 목적 : 센터 간 L2(Layer 2) 확장과 자원 통합, 재난·장애 시 **RTO** (Recovery Time Objective, 목표 복구 시간)와 **RPO** (Recovery Point Objective, 목표 복구 시점)의 최소화에 따른 비즈니스 연속성 확보.

## Ⅱ. DCI의 특징 및 장점

- 핵심 요약 : 파장 다중화, 광 신호 보정, 오버레이 L2 연장, 경로 제어가 대역폭·거리·이동성을 함께 확보하는 구조.

1. **DWDM** (Dense Wavelength Division Multiplexing, 고밀도 파장 분할 다중화) : 하나의 광섬유에 서로 다른 파장을 독립 채널로 동시 전송 → 회선 증설 없이 파장 단위 대역폭 확장 효과.
2. **코히런트 광트랜시버** (Coherent Optical Transceiver) : 수신단의 디지털 신호 처리로 색분산 등 전송 왜곡을 보정하는 광모듈 → 반복 중계 없이 장거리 구간의 신호 품질 유지.
3. **EVPN** (Ethernet Virtual Private Network)과 **VXLAN** (Virtual Extensible LAN) : MAC·IP 정보를 경로 광고 방식으로 교환하고, L2 프레임을 캡슐화해 IP망 위로 전달하는 오버레이 조합 → 센터 경계를 넘는 L2 확장과 가상머신의 동일 IP 이동.
4. **SRv6** (Segment Routing over IPv6) : 경로 정보를 패킷 헤더의 세그먼트 목록에 명시해 컨트롤러가 경로를 지정 → 지연·대역폭 조건 기반 트래픽 엔지니어링 자동화.

## Ⅲ. DCI의 구조 (흐름)

- 핵심 요약 : 물리 광선로 위에 광전송·패킷·오버레이 계층이 순차 적층되는 구조.
- 패킷 계층은 라벨 기반 전달 방식인 MPLS(Multiprotocol Label Switching)와 광수송 규격인 OTN(Optical Transport Network)으로 대역 보장과 전방 오류 정정(FEC, Forward Error Correction)을 제공하는 역할.

```text
[ DCI 계층 스택 ]

오버레이 : EVPN-VXLAN (L2·L3 연장)
        ↓
패킷 계층 : SRv6 · MPLS
        ↓
광전송 : DWDM · 코히런트 광모듈
        ↓
물리 구간 : 다크 파이버 · 광케이블
```

```text
[ 가상머신 무중단 이동 ]

A센터 가상머신 (동일 IP·MAC 유지)
        ↓
DCI 경계 장비의 VXLAN 캡슐화
        ↓
DWDM 광 경로를 통한 전송
        ↓
B센터에서 디캡슐화 후 재기동
```

- **다크 파이버** (Dark Fiber, 임차자가 자체 장비로 파장을 구성하는 미개통 광섬유) : 상면·회선 조건에 따라 자체 광 구성이 가능한 물리 기반.

## Ⅳ. DCI의 비교

- 핵심 요약 : 광전송·광수송·IP 라우팅·오버레이 계층이 목적과 적용 분야에서 구분되는 구조.

| 계층 | 대표 기술 | 전송 특성 | 적용 분야 |
| --- | --- | --- | --- |
| 광전송 | DWDM, 코히런트 광모듈 | 파장 단위 대용량·저지연 | 센터 간 광 백본 |
| 광수송 | OTN | 대역 보장, FEC | 통신사·금융 전용 회선 |
| IP 라우팅 | MPLS, SRv6 | 경로 제어, 빠른 우회 전환 | 클라우드 코어망 |
| 오버레이 | EVPN-VXLAN | 동일 IP 유지 L2 연장, 테넌트 분리 | 가상머신 이전, L2 확장 |

- 선택 기준 : 필요 대역폭, 연장 거리에 따른 왕복 지연(RTT, Round-Trip Time), L2 확장 필요 여부, 회선 비용을 함께 평가해 계층 구성을 결정하는 절차 필요.

## Ⅴ. DCI의 한계와 방안

- 핵심 요약 : 전파 지연, 브로드캐스트 확산, 구축 비용의 한계를 복제 방식 차등, 오버레이 분리, 광모듈 고도화로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 물리적 전파 지연 | 광섬유 전파 속도가 거리에 비례해 동기 복제 응답이 지연 | 거리 구간별 **준동기 복제** (Semi-synchronous Replication, 일부 확인 후 응답하는 복제)·비동기 전환, 애플리케이션 샤딩 | 복제 지연, RTT |
| **브로드캐스트 스톰** (Broadcast Storm, 방송 프레임의 폭주 확산) | L2 직결 구간의 루프와 ARP(Address Resolution Protocol) 폭주가 상대 센터까지 확산 | EVPN 제어 계층의 ARP 응답 대행, **애니캐스트 게이트웨이** (Anycast Gateway, 양 센터에 동일 게이트웨이 배치)로 L2 경계 분리 | ARP 트래픽량 |
| 구축·운영 비용 | 광 장비 구매와 광섬유 임대의 초기 투자 부담 | 스위치 포트형 모듈 기반 IP-over-DWDM 구성, 필요 구간의 단계 확장 | 비트당 전송 비용 |

## Ⅵ. DCI에 대한 기술사적 제언

- 핵심 요약 : 무손실 전송 검증, 광 인입 이원화, 분산 데이터베이스 연계를 재해복구 표준 설계로 내재화하는 방향.
- AI 인프라 운영 조직은 센터 간 **RoCE** (RDMA over Converged Ethernet, 무손실 이더넷 기반 원격 메모리 직접 접근) 품질을 실장비 시험으로 확인하고 그 결과를 DCI 설계 기준에 반영하는 절차 필요.
- 회선 단절에 취약한 금융·공공기관은 굴착 경로가 서로 다른 두 개의 광 인입 경로를 통신사 계약 단계에서 확보하는 이원화 기준 수립 필요.
- 멀티 리전 서비스 조직은 분산 합의 데이터베이스(예: Spanner, CockroachDB) 기반 액티브-액티브 구조와 DCI 설계를 함께 검토하는 체계 마련.

## Ⅶ. 결론

- 핵심 요약 : DCI는 광전송과 오버레이의 조합으로 센터 간 자원 통합과 무중단 복제를 뒷받침하는 연결 계층.
- 거리 지연과 L2 확산이라는 고유 제약이 동반되므로, 복제 방식과 오버레이 경계의 통합 설계가 효과 실현의 조건.
