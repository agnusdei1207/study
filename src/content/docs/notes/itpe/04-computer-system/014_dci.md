## 연관 키워드
- DCI(Data Center Interconnect), 데이터센터 간 연결, 광전송, 지연, 이중화, 암호화

## Ⅰ. DCI의 개요
- 핵심 요약 : DCI는 복수 데이터센터를 연결해 데이터·워크로드·복구 트래픽을 전달하는 네트워크 인프라.
- 개념 : **DCI**(Data Center Interconnect)는 서로 다른 데이터센터 간에 고대역폭·저지연 통신을 제공하는 전송·라우팅 구성.
- 배경 및 필요성 : 다중 사이트 서비스, 데이터 복제, 클라우드 온램프, 재해복구에 안정적 연결 필요.
- 목적 : 데이터센터 간 애플리케이션 연계와 업무 연속성 확보.

## Ⅱ. 구성과 특성
- 핵심 요약 : 광전송·라우팅·암호화·관측을 조합해 거리와 트래픽 요구에 맞춤.
- 광전송·DWDM : 광섬유 용량 활용 → 대용량 백본.
- 라우팅·스위칭 : 사이트 간 경로와 세그먼트 연결.
- 암호화·접근통제 : 전송 구간 데이터 보호.
- 지연·손실 특성은 복제 방식과 애플리케이션의 동기 처리에 영향.

## Ⅲ. DCI 흐름
- 핵심 요약 : 데이터센터 내 트래픽을 경계 장비에서 집선·보호해 원격 사이트까지 전달.
```text
DC 내부 Leaf-Spine
  ↓ 경계 Router
광전송·암호화 구간
  ↓ 원격 사이트 Router
대상 DC 네트워크·서비스
```
```text
주 데이터센터
  ↓ 동기/비동기 복제
DCI 링크·경로 이중화
  ↓
복구 데이터센터
```

## Ⅳ. 전용망과 인터넷 VPN 비교
- 핵심 요약 : 전용 광 경로는 예측 가능성과 대역폭 제어에, 인터넷 VPN은 비용·구축 유연성에 차이가 있음.
| 비교 축 | 전용 DCI | 인터넷 기반 VPN |
| --- | --- | --- |
| 품질 | 대역폭·지연 관리 용이 | 인터넷 혼잡 영향 |
| 비용 | 전용 회선·장비 비용 | 상대적으로 유연 |
| 보안 | 전송·접근 통제 필요 | 암호화 터널 사용 |
| 활용 | 대규모 지속 트래픽 | 중소 규모·보조 경로 |

## Ⅴ. 한계와 방안
- 핵심 요약 : 단일 경로 장애·복제 지연·MTU 불일치가 서비스 연속성을 해칠 수 있음.
| 한계 | 원인·영향 | 대응 |
| --- | --- | --- |
| 경로 단절 | 공통 관로·장비 장애 | 물리 경로 다양화·절체 시험 |
| 복제 지연 | 대역폭 부족·거리 | RPO에 맞는 복제 방식·용량 계획 |
| 보안 노출 | 사이트 간 신뢰 확대 | 암호화·세그먼트·키 수명 관리 |
| MTU·라우팅 불일치 | 장비 설정 차이 | 종단 간 경로·MTU 검증 |

## Ⅵ. 설계 제언
- 핵심 요약 : 네트워크팀은 RTO·RPO와 트래픽 패턴으로 대역폭·경로·복제 정책을 산정.
- 회선 이중화뿐 아니라 전원·관로·통신사 공통 장애 지점을 분석하고 정기 절체 훈련.

## Ⅶ. 결론
- 핵심 요약 : DCI는 복수 데이터센터를 하나의 업무 연속성·데이터 이동 구조로 연결하는 핵심 인프라.
- 거리·지연·복제 요구와 장애 도메인을 함께 고려한 설계가 필요.
