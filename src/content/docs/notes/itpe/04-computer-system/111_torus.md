## 답안 골격
```text

 ┃
 ┣━ Ⅰ 개요 ───── 단순 메시(Mesh)의 경계 노드 병목과 긴 네트워크 지름 → 양 끝단을 링으로 연결해 대칭성을 확보한 토러스 구조
 ┣━ Ⅱ 특징 ───── 순환 대칭성(Edge-Symmetric) · 엣지 효과 배제 · 망 지름 절반 축소 · 바이섹션 대역폭(Bisection Bandwidth) 증대
 ┣━ Ⅲ 구조 ───── k-ary n-cube 위상 + 라우팅 스위치 + 양방향 랩어라운드(Wrap-around) 링크 + 가상 채널(Virtual Channel)
 ┣━ Ⅳ 흐름 ───── ① 패킷 헤더 목적지 좌표 확인 → ② 차원 순서 라우팅(DOR) → ③ 랩어라운드 경유 시 가상 채널 전환 → ④ 수신 노드 도달
 ┣━ Ⅴ 비교 ───── 링(Ring) vs 메시(Mesh) vs 토러스(Torus) vs 하이퍼큐브(Hypercube)
 ┗━ Ⅵ 실무 ───── 순환 링크로 인한 라우팅 교착상태(Deadlock) / 고차원 케이블링 물리적 복잡도 / 단일 링크 장애 시 단절
```

## 한 줄 본질
- 격자형 메시 네트워크의 양 끝단 노드를 원형 링처럼 맞물리게(Wrap-around) 연결 → 경계 노드를 없애고 네트워크 지름을 절반으로 단축 → 통신 지연 단축 및 트래픽 분산 / 순환 링크에 의한 라우팅 교착상태(Deadlock) 발생 및 물리 배선 복잡도 증가

## 핵심 용어
- 랩어라운드 링크(Wrap-around Link): 메시 구조의 각 행과 열의 양쪽 끝단에 위치한 노드를 연결하여 링 형태로 순환시키는 연결선
- k-ary n-cube: n차원 공간의 각 축마다 k개의 노드가 링 형태로 연결된 정규 토폴로지(토러스의 일반화 수학적 모델)
- 가상 채널(Virtual Channel): 하나의 물리적 링크를 시분할하여 여러 개의 논리적 버퍼 큐로 분할함으로써 순환 대기로 인한 교착상태를 방지하는 메커니즘

## 핵심 통찰
- 토러스의 가장 강력한 장점은 '엣지 효과(Edge Effect)의 제거'임 → 일반 메시는 중앙 노드에 트래픽이 몰려 핫스팟이 생기지만, 토러스는 모든 노드가 대칭적인 위상 위치를 가지므로 트래픽이 전 노드에 고르게 분산됨
- 네트워크 지름의 극적인 축소 → k개 노드를 가진 n차원 메시의 지름은 $n(k-1)$이지만, 토러스는 랩어라운드 링크 덕분에 $n \lfloor k/2 \rfloor$로 절반가량 감소하여 최악 경로 홉(Hop) 수가 반감됨
- 링 구조가 도입되면서 발생하는 대가는 '데드락(Deadlock)'임 → 패킷들이 서로 앞 노드의 버퍼를 요구하며 물고 물리는 사이클이 형성되므로, 차원 순서 라우팅(DOR)과 함께 가상 채널을 분리(Higher/Lower VC)하여 사이클을 강제로 파괴해야 함

## 이웃 토픽과 구분
- 메시(Mesh) vs 토러스(Torus): 메시 = 양 끝단이 열려 있는 직교 격자 구조(배선 단순, 지름 큼) / 토러스 = 양 끝단을 순환 연결한 닫힌 격자 구조(지름 단축, 배선 복잡, 데드락 방지 필수)

## 문제·원인·대책
- 적용 상황: 수만 개 노드가 연결된 대규모 슈퍼컴퓨터 클러스터 상호연결망 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 노드 간 대량 통신 중 패킷 버퍼가 순환 대기 상태에 빠져 전체 네트워크 마비 | 랩어라운드 링크로 인한 버퍼 의존성 그래프 사이클 형성(Deadlock) | 2개 이상의 가상 채널(VC0, VC1)을 할당하고 랩어라운드 통과 시 채널 전환 | 순환 대기 고리 차단 및 무교착 라우팅 보장 |
| 3차원 이상 고차원 토러스 구축 시 캐비닛 간 긴 케이블링으로 신호 감쇠 | 랙과 랙 사이를 가로지르는 긴 랩어라운드 물리적 배선 | 폴디드 토러스(Folded Torus) 기법으로 노드를 엇갈려 배치 | 모든 인접 링크 길이를 균일화하고 신호 왜곡 억제 |
| 특정 노드 또는 링크 장애 시 해당 차원의 전체 링 통신 단절 | 순환 링 토폴로지의 단일 링크 의존성 | 대체 우회 경로를 동적 탐색하는 고장 감내(Fault-Tolerant) 라우팅 프로토콜 적용 | 단일 실패점 발생 시에도 우회 경로로 패킷 전달 지속 |
