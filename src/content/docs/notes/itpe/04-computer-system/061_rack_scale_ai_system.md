## 연관 키워드

- 랙 스케일 AI 시스템(Rack-scale AI System), GB200 NVL72, 스케일업(Scale-up)
- 연산 트레이(Compute Tray), 스위치 트레이(Switch Tray), 백플레인(Backplane), NVLink, 단일 패브릭 도메인
- 버스바(Busbar), 직접 칩 액체 냉각(DLC, Direct-to-Chip Liquid Cooling), CDU(Cooling Distribution Unit), 장애 도메인(Fault Domain)

## Ⅰ. 랙 스케일 AI 시스템의 개요

- 핵심 요약 : 랙 스케일 AI 시스템은 연산·스위치·전력·냉각을 랙 한 단위로 통합 설계해 하나의 대형 가속 노드처럼 운용하는 AI(Artificial Intelligence) 인프라 구성.
- 개념 : 서버 한 대가 아닌 랙 전체를 설계 단위로 삼아 GPU(Graphics Processing Unit)와 CPU(Central Processing Unit), 고속 스위치 패브릭, 전력·냉각 설비를 통합 배치한 **랙 스케일 AI 시스템** (Rack-scale AI System)으로, 대표 사례 GB200 NVL72에서 후속 세대로 이어지는 **스케일업** (Scale-up, 시스템 단위 안에서 자원을 묶어 확장하는 방식) 구성.
- 배경 및 필요성 : 모델 규모가 커지며 서버 노드 사이를 외부 네트워크로 잇는 구성은 통신 대역폭과 지연 면에서 한계에 도달 → 랙 내부 배선으로 연결 병목을 흡수하는 설계 필요. 랙 밀도 상승은 전력·냉각·물류 조건의 동시 재설계를 요구.
- 주요 목적 : 랙 내부 고대역폭 패브릭 확보, 고밀도 전력·냉각의 통합 설계, 유지보수와 장애 관리 단위의 재정의.

## Ⅱ. 랙 스케일 AI 시스템의 특징 및 장점

- 핵심 요약 : 랙 단위 통합 설계, 후면 패브릭, 단일 도메인, 통합 전력·냉각이 통신 효율과 구축·운영 단순화로 이어지는 구조.

1. 랙 단위 통합 설계 : 연산 트레이·스위치 트레이·전원 구성을 하나의 기계 구조에 통합하고 공장에서 통합 검증 후 출하 → 현장 조립 오차 감소와 구축 기간 단축.
2. 후면 패브릭 연결 : **백플레인** (Backplane) 구리 케이블로 트레이 사이를 직결 → 광 모듈과 외부 케이블 제거로 전력 소모·지연·고장 지점 감소.
3. 단일 패브릭 도메인 : 랙 내 GPU 전체를 하나의 NVLink 도메인으로 묶음(NVIDIA 발표 기준 GPU당 1.8TB/s, 랙 전체 약 130TB/s) → 랙 전체가 하나의 가속 자원 풀로 동작.
4. 전력·냉각 통합 공급 : **버스바** (Busbar, 랙 내 장비에 직접 전력을 배분하는 도전체 바) 고밀도 전력과 **직접 칩 액체 냉각** (DLC, Direct-to-Chip Liquid Cooling)을 랙 설계에 포함 → 120kW급 고밀도 랙 운용 가능.
5. 정비 단위의 변화 : 트레이 슬라이드 방식의 접근으로 정비 → 개별 부품 교체가 아닌 트레이 단위 절차로 운영 단순화.

## Ⅲ. 랙 스케일 AI 시스템의 구조 (흐름)

- 핵심 요약 : 연산 트레이와 스위치 트레이가 후면 패브릭으로 묶이고, 전력과 냉각이 랙 단위로 공급되는 통합 구조.
- **연산 트레이** (Compute Tray) : GPU와 CPU를 실은 계산 단위 모듈.
- **스위치 트레이** (Switch Tray) : NVLink 스위치를 실어 트레이 간 연결을 중계하는 모듈.
- **CDU** (Cooling Distribution Unit) : 냉각수 순환과 열교환을 담당하는 냉각 분배 장치.

```text
[ 랙 통합 설계 구성 ]

단일 랙 = 하나의 가속 노드
   ↓
연산 트레이 (GPU·CPU 적재)
   ↓ 후면 구리 백플레인
스위치 트레이 (NVLink 스위치)
   ↓
단일 패브릭 도메인 (GPU 72개)
```

```text
[ 전력·냉각 통합 흐름 ]

버스바 고밀도 전력 공급
   ↓
연산 트레이 발열 발생
   ↓
냉각판 직접 액체 냉각
   ↓
CDU 냉각수 순환·열교환
   ↓
데이터센터 설비로 열 이송
```

## Ⅳ. 랙 스케일 구성과 기존 구성의 비교

- 핵심 요약 : 랙 통합 구성은 통신 대역폭과 밀도를 높이는 대신 전력·냉각·물류 조건과 장애 반경을 함께 바꾸는 구도.

| 비교 축 | 랙 스케일 (GB200 NVL72) | 노드 단위 스케일업 (8-GPU 서버) | 클러스터 스케일아웃 |
| --- | --- | --- | --- |
| 설계 단위 | 랙 전체 통합 설계 | 서버 1대 | 랙·데이터센터 단위 |
| 랙 내 연결 | 후면 백플레인 패브릭 | 서버 내부 버스 | 외부 네트워크 |
| 통신 대역폭·지연 | 랙 내 고대역폭·저지연 | 노드 내에 한정 | 스위치 계층 경유 |
| 전력·냉각 | 액체 냉각 필수, 고밀도 | 공랭 중심 | 기존 설비 활용 |
| 장애 반경 | 랙 단위 공유 설비 영향 | 노드 단위 | 노드·스위치 단위 |

- 선택 기준 : 모델의 통신 요구, 기존 설비의 전력·냉각 여유, 확장 계획을 함께 보고 구성 단위를 정함.

## Ⅴ. 랙 스케일 AI 시스템의 한계와 방안

- 핵심 요약 : 고밀도 전력, 누수와 펌프 장애, 중량 물류, 장애 반경 확대를 배전 재설계·이중화·보강·도메인 분리로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 고밀도 전력 수요 | 랙당 전력이 기존 설계 범위 초과 → 수전·배전 개조 필요 | 고전압 직류 배전·버스바 도입, 단계적 설비 증설 | 랙별 전력 사용률 |
| 누수와 펌프 장애 | 누수는 장비 손상, 펌프 고장은 열 과부하 유발 | 누수 감지·차단 체계, CDU·펌프 이중화 | 누수 감지 건수, 냉각수 온도 편차 |
| 랙 중량과 물류 | 랙 무게 증가 → 바닥 하중·운반 경로 제약 | 하중 해석 기반 보강, 설치 경로 사전 점검 | 바닥 하중 여유율 |
| 장애 반경 확대 | 패브릭·냉각 공유로 국소 고장이 랙 전체 중단으로 확산 | **장애 도메인** (Fault Domain, 고장 영향이 퍼지는 범위를 묶는 격리 단위) 분리 설계, 체크포인트 주기 단축 | 랙 단위 중단 빈도 |

## Ⅵ. 랙 스케일 AI 시스템에 대한 기술사적 제언

- 핵심 요약 : 설비 사전 진단, 트레이 단위 운영 표준, 고밀도 설비 기준의 제도화가 도입 효과의 전제.
- 데이터센터 사업자 : 도입 전 수전 설비·냉각 배관·바닥 하중을 진단하고 개조와 도입을 하나의 공정 계획으로 묶은 단계별 전환 계획을 수립.
- 운영 조직 : 랙 전체가 하나의 패브릭 도메인으로 묶이는 특성을 반영해 정비 절차·스케줄링·체크포인트 정책을 트레이 단위 운영 표준으로 재정의.
- 정책 기관 : 고밀도 AI 데이터센터의 전력·냉각 기준을 인허가·건축 기준에 반영하고 전력 계통 운영 기관과의 협의 절차를 제도화.

## Ⅶ. 결론

- 핵심 요약 : 랙 스케일 AI 시스템은 연결 병목 해소를 랙 단위 통합 설계로 옮긴 구성.
- 시사점 : AI 인프라 경쟁의 축이 칩 성능에서 전력·냉각·물류까지 포괄하는 통합 설계 역량으로 이동 중.
