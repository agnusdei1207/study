## 연관 키워드

- SJF, Shortest Job First, 비선점형, SRTF, 평균 대기시간, 기아

## Ⅰ. SJF 스케줄링의 개요

- 핵심 요약 : SJF는 준비 큐의 작업 중 CPU 버스트가 가장 짧을 것으로 예측되는 작업을 먼저 실행하는 스케줄링 알고리즘.
- 개념 : SJF는 준비 큐의 작업 중 CPU 버스트가 가장 짧을 것으로 예측되는 작업을 먼저 실행하는 스케줄링 알고리즘.
- 배경 및 필요성 : 평균 대기시간 최소화가 필요하지만 실행시간은 사전에 완전히 알 수 없음.
- 주요 목적 : 평균 대기시간 최소화와 짧은 작업 응답 향상.

## Ⅱ. SJF 스케줄링의 특징 및 장점

- 핵심 요약 : 비선점 SJF: 선택한 작업 종료까지 실행 → 문맥교환 감소, 긴 작업 대기; 선점 SRTF: 남은 시간이 가장 짧은 작업 실행 → 새 짧은 작업에 즉시 양보; 버스트 예측: 과거 실행량의 지수평균 추정 → 실제 길이 불확실성 완화.

1. 비선점 SJF: 선택한 작업 종료까지 실행 → 문맥교환 감소, 긴 작업 대기
2. 선점 SRTF: 남은 시간이 가장 짧은 작업 실행 → 새 짧은 작업에 즉시 양보
3. 버스트 예측: 과거 실행량의 지수평균 추정 → 실제 길이 불확실성 완화

## Ⅲ. SJF 스케줄링의 구조 (흐름)

- 핵심 요약 : 준비 큐 작업의 CPU 버스트 추정 → 최단 작업 선택 → 비선점 실행 또는 SRTF 선점 → 완료·대기시간 기록 → 기아·응답시간 평가.

```text
준비 큐 작업의 CPU 버스트 추정
  ↓
최단 작업 선택
  ↓
비선점 실행 또는 SRTF 선점
  ↓
완료·대기시간 기록
  ↓
기아·응답시간 평가
```

- 핵심 구성 : Ready Queue → burst 추정 → 최단 작업 선택 → CPU 실행

```text
Ready Queue → burst 추정 → 최단 작업 선택 → CPU 실행
SRTF: 더 짧은 잔여시간 작업 도착 시 선점
```

## Ⅳ. 비교: 비선점 SJF / FCFS

- 핵심 요약 : 선택 기준 기준 — 비선점 SJF: 예상 CPU 버스트가 짧은 작업 우선; FCFS: 도착 순서 우선.

| 비교 기준 | 비선점 SJF | FCFS |
| --- | --- | --- |
| 선택 기준 | 예상 CPU 버스트가 짧은 작업 우선 | 도착 순서 우선 |
| 평균 대기시간 | 정확한 버스트를 알면 평균 대기 최소화 가능 | 짧은 작업 뒤 장기 작업 대기 |
| 공정성 | 긴 작업 기아 가능 | 도착 순서는 보장되나 응답 지연 |

## Ⅴ. SJF 스케줄링의 한계와 방안

- 핵심 요약 : 버스트 사전 미지·기아 등의 위험을 원인에 맞게 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 버스트 사전 미지 | 실행 전 CPU 시간 정확히 알기 어려움 | 과거 burst 지수평균·작업유형 추정 사용 | 예측오차 |
| 기아 | 짧은 작업이 계속 오면 긴 작업 무기한 대기 | aging·대기시간 상한·우선순위 보정 | 최대 대기시간 |
| 선점 오버헤드 | SRTF 잦은 도착이 문맥교환 증가 | 선점 기준·quantum·반응성 부하 조정 | 문맥교환율 |

## Ⅵ. SJF 스케줄링의 제언

- 핵심 요약 : OS 스케줄러 설계자는 비선점 SJF와 SRTF의 응답·공정성 차이를 workload trace로 검증하고 aging으로 장기작업의 대기상한 보장.
- 실행 제안 : OS 담당자는 작업 유형별 버스트 추정 오차와 최장 대기시간을 시뮬레이션하고 aging 임계값을 조정.

## Ⅶ. SJF 스케줄링의 결론

- 핵심 요약 : SJF의 평균대기시간 최적성은 정확한 burst 길이 가정을 전제로 하며 실제 OS에서는 추정과 공정성 보완이 필요.
- 시사점 : 짧은 작업의 빠른 처리가 장기작업의 기아로 이어지지 않도록 최적성·공정성·예측오차를 함께 다뤄야 함.
