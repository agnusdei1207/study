## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 핵심 개념 → 양자 오류정정 임계값 이하

## 30초 인출

- 본질: 미세한 열과 전자기파 노이즈로 큐비트의 양자 상태가 무너지는 결어긋남(Decoherence) 때문에 큐비트를 늘릴수록 시스템 전체 오류가 눈덩이처럼 불어나던 치명적 한계
- 메커니즘: 다수의 물리 큐비트를 얽어 단일 논리 큐비트를 구성하고, 물리 큐비트 수가 증가할수록 논리 오류율이 지수적으로 감소하는 '오류정정 임계값(Threshold)' 이하 영역을 구글 윌로우(Willow) 칩이 인류 최초로 물리적 입증

## 핵심 용어

- 양자 결어긋남(Decoherence): 양자 큐비트가 주변 환경(열, 전자기 노이즈)과 상호작용하여 중첩(Superposition) 및 얽힘(Entanglement) 상태를 상실하고 고전 비트로 퇴화하는 현상
- 오류정정 임계값(Fault-Tolerant Threshold): 물리 큐비트 자체의 개별 오류율이 이 임계값(대략 0.1~1%)보다 낮아지면, 큐비트를 추가할수록 양자 오류정정 부호가 작동하여 전체 논리 오류율이 감소하기 시작하는 물리적 분기점
- 서피스 코드(Surface Code): 2차원 평면 격자 위에 데이터 큐비트와 신드롬(측정) 큐비트를 교대로 배치하여 양자 중첩 상태를 파괴하지 않고 비트 반전(X) 및 위상 반전(Z) 오류를 검출하는 표준 양자 부호

## 1교시 10점 답안

### 정의·목적

- 정의: 양자 오류정정 임계값 이하은/는 다수의 물리 큐비트를 얽어 단일 논리 큐비트를 구성하고, 물리 큐비트 수가 증가할수록 논리 오류율이 지수적으로 감소하는 '오류정정 임계값(Threshold)' 이하 영역을 구글 윌로우(Willow) 칩이 인류 최초로 물리적 입증 방식이다.
- 목적: 상용 내결함성 양자컴퓨터(FTQC)로의 공학적 도약 실현에 기여한다.

### 핵심 구조와 작동

```text
[ 물리 큐비트 수와 논리 오류율의 임계값(Threshold) 관계 ]

  논리 오류율 (Logical Error Rate)
      ^
      │      임계값 미달 (Threshold 초과 시):
      │      - 큐비트를 늘릴수록 시스템 노이즈가 커져 오류 폭증 (과거의 한계)
      │          \        /  (d = 3 Code)
      │           \      /   (d = 5 Code)
      │            \    /    (d = 7 Code)
      │             \  /
  ----┼──────────────╳────────────── (오류정정 임계값: Threshold)
      │             /  \
      │            /    \   임계값 돌파 (Google Willow 입증):
      │           /      \  - 코드 거리(d)를 늘릴수록 오류율이 '지수적으로 감소'!
      v          v        v (d=3 -> d=5 -> d=7 로 갈수록 오류율 반감)
      +──────────────────────────> 물리 큐비트 수 (Physical Qubits)
```

## 2~4교시 25점 답안

### Ⅰ. 핵심 구조와 작동

```text
[ 물리 큐비트 수와 논리 오류율의 임계값(Threshold) 관계 ]

  논리 오류율 (Logical Error Rate)
      ^
      │      임계값 미달 (Threshold 초과 시):
      │      - 큐비트를 늘릴수록 시스템 노이즈가 커져 오류 폭증 (과거의 한계)
      │          \        /  (d = 3 Code)
      │           \      /   (d = 5 Code)
      │            \    /    (d = 7 Code)
      │             \  /
  ----┼──────────────╳────────────── (오류정정 임계값: Threshold)
      │             /  \
      │            /    \   임계값 돌파 (Google Willow 입증):
      │           /      \  - 코드 거리(d)를 늘릴수록 오류율이 '지수적으로 감소'!
      v          v        v (d=3 -> d=5 -> d=7 로 갈수록 오류율 반감)
      +──────────────────────────> 물리 큐비트 수 (Physical Qubits)
```

### Ⅱ. 핵심 특성

- 고전 컴퓨터는 비트(0, 1)를 복사해서 다수결 투표로 오류를 고칠 수 있지만, 양자역학은 '복제 불가능 정리(No-Cloning Theorem)'로 인해 큐비트 상태를 복사할 수 없음
- 따라서 큐비트를 직접 읽지(관측) 않고, 인접한 보조(신드롬) 큐비트와의 얽힘을 통해서만 오류 위치를 간접 측정하는 '신드롬 측정' 메커니즘이 필수적임
- 구글 윌로우(Willow) 칩의 진정한 가치는 단순히 큐비트 개수(105개)를 자랑하는 쇼가 아니라, "물리 큐비트를 더 많이 집적할수록 계산이 더 정확해진다"는 양자 오류정정의 근본 공학적 명제를 실제 실리콘에서 세계 최초로 증명한 데 있음

### Ⅲ. 관련 개념과 구분

- NISQ vs FTQC: NISQ(잡음 중규모 양자) = 오류정정 없이 잡음을 감수하고 수십~수백 큐비트로 단기 휴리스틱 알고리즘 실행 / FTQC(내결함성 양자) = 양자 오류정정으로 수백만 회의 무오류 양자 게이트 연산을 보장하여 쇼어 알고리즘(RSA 해독) 수행

### Ⅳ. 적용 문제와 대응

- 사례: 양자 하드웨어 연산 시 실시간 신드롬 디코딩 지연으로 인한 양자 상태 소멸
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 신드롬 측정 결과를 고전 컴퓨터로 분석하는 동안 큐비트의 코히어런스 시간 만료 | 신드롬 디코더 알고리즘(최소 가중치 완전 매칭: MWPM)의 높은 계산 복잡도 | 극저온 제어용 FPGA 및 텐서 네트워크 기반 실시간 신경망 디코더 하드웨어 내장 | 디코딩 지연을 마이크로초(µs) 이내로 단축하여 실시간 오류 정정 성공 |
| 극저온 냉동기(10mK) 내부로 들어가는 수천 가닥 동축 케이블의 열 누출 | 물리 큐비트마다 개별 제어선이 필요하여 발생하는 배선 병목 | 극저온 집적회로(Cryo-CMOS) 컨트롤러 칩을 냉동기 내부에 직접 집적 | 냉동기 내부 배선 수를 90% 이상 감축 |
