## 답안 골격
```text
[BaaS] ◀━━ 머리: Ⅶ 내 의견 (CSP 락인 방지를 위한 추상화 계층 및 자체 백엔드 전환 기준 수립)
 ┃
 ┣━ Ⅰ 개요 ───── 모바일·웹 반복 백엔드 구축 비용 → 클라우드 API 기반 공통 백엔드 서비스 소비
 ┣━ Ⅱ 특징 ───── 개발 기간 단축 · 자동 확장 · 클라이언트 SDK 직결 · 벤더 종속성
 ┣━ Ⅲ 구조 ───── 인증(Auth) · 데이터베이스(DB) · 푸시 알림 · 파일 스토리지 · 클라이언트 SDK
 ┣━ Ⅳ 흐름 ───── ① 클라이언트 SDK 호출 → ② API 게이트웨이 인증 → ③ 매니지드 백엔드 처리 → ④ 푸시·동기화
 ┣━ Ⅴ 비교 ───── BaaS vs FaaS vs PaaS
 ┗━ Ⅵ 실무 ───── 벤더 락인 / 복잡 비즈니스 로직 제약 / 데이터 주권 및 보안 컴플라이언스
```
- 필수 키워드: 매니지드 백엔드 · 인증 SDK · 벤더 종속(Lock-in) · FaaS 연계 · 실시간 동기화
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 핵심 서비스 구성도 → Ⅴ BaaS vs FaaS 비교 / 25점 = Ⅰ~Ⅶ 전개, Ⅳ FaaS 결합 흐름과 Ⅵ 탈출 전략 제시
- 기출: 140회 2교시 `서버리스 컴퓨팅 유형(FaaS·BaaS)` → Ⅲ·Ⅴ, 136회 1교시 `서버리스 컴퓨팅` → Ⅰ·Ⅲ

## 한 줄 본질
- 반복되는 인증·DB·푸시 서버의 자체 구축 및 인프라 운영 오버헤드 → 검증된 백엔드 기능을 클라우드 사업자가 완전관리형 API 및 SDK로 제공 → 개발 기간 단축 및 무서버 운영 / 벤더 종속 심화 및 커스텀 로직 처리 한계

## 핵심 그림
```text
[ 모바일 앱 / 웹 클라이언트 ]
  │
  ├─(인증 SDK)───────> [ Managed Auth (OAuth/JWT/MFA) ]
  ├─(데이터 SDK)─────> [ Realtime Database / NoSQL ]
  ├─(스토리지 SDK)───> [ Object Storage (CDN 결합) ]
  └─(이벤트 트리거)──> [ FaaS (커스텀 비즈니스 로직 연계) ]
                           │
                           └─> [ Push Notification (FCM/APNs) ]
```

## 핵심 용어
- 벤더 락인(Vendor Lock-in): 특정 CSP 고유 SDK와 독점 API 규격 종속으로 타 플랫폼 마이그레이션 비용이 급증하는 현상
- 클라이언트 직결 SDK: 백엔드 API 서버를 거치지 않고 모바일 단말에서 데이터베이스나 인증 서비스에 직접 안전하게 쿼리하는 라이브러리

## 핵심 통찰
- BaaS는 '백엔드가 없는 것'이 아니라 '백엔드 제어권을 CSP에 완전히 넘기고 API 소비자로 내려앉는 것'임 → 인프라 관리 비용은 0에 수렴하나 장애 분석 및 튜닝 통제권 상실
- 순수 BaaS만으로는 기업 고유의 복잡한 비즈니스 규칙을 수용 불가 → 데이터 변경 이벤트를 FaaS로 연결하는 'BaaS + FaaS 하이브리드 서버리스' 구조가 표준으로 정착됨
- 사용자 급증 시 초기에는 저렴하나 일정 임계 트래픽 초과 시 API 호출당 과금 누적으로 자체 서버 운영(IaaS/컨테이너) 대비 비용 역전 발생

## 이웃 토픽과 구분
- BaaS vs FaaS: BaaS = 완성된 백엔드 서비스(DB, Auth, Storage)를 API로 소비 / FaaS = 상태 없는 커스텀 비즈니스 코드(함수)를 이벤트 기반으로 실행

## 문제·원인·대책
- 사례: 140회 기출 서버리스 컴퓨팅 보안 위협 및 특정 BaaS 서비스 단종에 따른 서비스 마이그레이션 지연
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 특정 CSP BaaS 정책 변경 및 단종 시 서비스 중단 | 비표준 독점 SDK 및 스키마에 클라이언트 코드 직접 결합 | 리포지토리 패턴 및 어댑터 계층 기반 비즈니스 로직 격리 | 백엔드 서비스 교체 시 클라이언트 재작성 범위 최소화 |
| 모바일 앱 리버스 엔지니어링을 통한 DB 무단 조작 | 클라이언트에서 직접 BaaS 접근 시 부실한 보안 규칙 설정 | BaaS 서버 측 보안 규칙(Security Rules) 및 토큰 검증 엄격화 | 최소 권한 기반 비인가 읽기·쓰기 차단 |
