## 연관 키워드

- 내부 단편화, 외부 단편화, 페이징, 세그먼테이션, 메모리 할당

## Ⅰ. 메모리 단편화의 개요

- 핵심 요약 : 메모리 단편화는 할당·해제와 크기 차이로 메모리 공간이 비효율적으로 남아 필요한 연속 공간 확보나 메모리 이용률을 떨어뜨리는 현상.
- 개념 : 메모리 단편화는 할당·해제와 크기 차이로 메모리 공간이 비효율적으로 남아 필요한 연속 공간 확보나 메모리 이용률을 떨어뜨리는 현상.
- 배경 및 필요성 : 동적 메모리 배치가 반복되면서 총 여유 메모리는 충분해도 큰 연속영역을 할당하지 못하거나 블록 내부 낭비 발생.
- 주요 목적 : 메모리 공간 이용률과 할당 성공률 향상.

## Ⅱ. 메모리 단편화의 특징 및 장점

- 핵심 요약 : 내부 단편화: 할당 단위보다 작은 잔여 공간 → 블록 내부 낭비; 외부 단편화: 자유공간이 비연속 홀로 분산 → 대형 연속 요청 실패; 페이징: 고정 크기 프레임으로 외부 단편화 완화, 페이지 내부 낭비 가능.

1. 내부 단편화: 할당 단위보다 작은 잔여 공간 → 블록 내부 낭비
2. 외부 단편화: 자유공간이 비연속 홀로 분산 → 대형 연속 요청 실패
3. 페이징: 고정 크기 프레임으로 외부 단편화 완화, 페이지 내부 낭비 가능

## Ⅲ. 메모리 단편화의 구조 (흐름)

- 핵심 요약 : 요청 크기·수명 분석 → 할당자·배치정책 선택 → 할당·해제 패턴 계측 → 단편화·실패율 분석 → 풀·페이징·압축 등 대응.

```text
요청 크기·수명 분석
  ↓
할당자·배치정책 선택
  ↓
할당·해제 패턴 계측
  ↓
단편화·실패율 분석
  ↓
풀·페이징·압축 등 대응
```

- 핵심 구성 : 요청 블록 분할·할당 → 해제 → 작은 자유 홀 누적

```text
요청 블록 분할·할당 → 해제 → 작은 자유 홀 누적
외부: [사용][홀][사용][홀]
내부: 할당 블록 안에 미사용 잔여
```

## Ⅳ. 비교: 외부 단편화 / 내부 단편화

- 핵심 요약 : 낭비 위치 기준 — 외부 단편화: 자유공간이 작은 비연속 홀로 분산; 내부 단편화: 할당 블록 내부에 미사용 공간.

| 비교 기준 | 외부 단편화 | 내부 단편화 |
| --- | --- | --- |
| 낭비 위치 | 자유공간이 작은 비연속 홀로 분산 | 할당 블록 내부에 미사용 공간 |
| 주요 발생 구조 | 가변 크기 연속 할당·세그먼테이션 | 고정 크기 블록·페이지의 마지막 잔여 |
| 대표 대응 | 압축·페이징·버디 할당 | 페이지 크기·할당 크기·풀 설계 조정 |

## Ⅴ. 메모리 단편화의 한계와 방안

- 핵심 요약 : 연속 할당 실패·내부 낭비 등의 위험을 원인에 맞게 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 연속 할당 실패 | 총 자유 메모리는 충분해도 최대 연속 홀 부족 | 최대 자유블록·외부 단편화율 모니터링, 페이징 고려 | 할당 실패율 |
| 내부 낭비 | 페이지·슬랩 단위와 객체 크기 불일치 | 크기별 slab/pool·페이지 크기 검토 | 내부 낭비 바이트 |
| 압축 비용 | 메모리 압축이 포인터 이동·일시정지 유발 | 이동가능 객체 조건·정지시간을 측정 후 선택 | 압축시간·pause |

## Ⅵ. 메모리 단편화의 제언

- 핵심 요약 : OS·런타임 담당자는 워크로드의 객체 크기·수명·연속할당 요구를 측정해 할당자와 페이지·풀 구조를 선택하고 실패율·단편화 지표로 검증.
- 실행 제안 : 런타임 담당자는 최대 연속 블록과 객체 크기별 여유율을 부하별로 측정해 할당자·풀 변경의 효과를 비교.

## Ⅶ. 메모리 단편화의 결론

- 핵심 요약 : 내부·외부 단편화는 낭비 위치와 발생 메커니즘이 다르므로 고정·가변 할당 구조에 맞는 대응 필요.
- 시사점 : 단순 여유 메모리 총량보다 가장 큰 연속 블록·할당 크기 분포·객체 수명 패턴이 실제 메모리 건전성을 설명.
