## 연관 키워드

- UALink(Ultra Accelerator Link), UALink 200G 1.0, 스케일업(Scale-up), 스케일아웃(Scale-out)
- 로드/스토어(Load/Store), 원자 연산(Atomic Operation), 캐시 일관성(Cache Coherency), 비일관성 공유 메모리
- NVLink, CXL(Compute Express Link), InfiniBand, UEC(Ultra Ethernet Consortium), CPO(Co-Packaged Optics)

## Ⅰ. UALink 1.0의 개요

- 핵심 요약 : 여러 벤더의 AI 가속기를 메모리 수준으로 묶는 개방형 스케일업 인터커넥트 표준.
- 개념 : **UALink** (Ultra Accelerator Link)는 AI(Artificial Intelligence) 가속기 사이의 메모리 수준 통신을 목표로 반도체·클라우드 기업들이 참여한 컨소시엄이 2025년 4월 공개한 개방형 인터커넥트 규격이며, 한 포드 안의 가속기를 하나의 **스케일업** (Scale-up) 패브릭으로 연결하는 것이 핵심.
- 배경 및 필요성 : 대규모 AI 모델을 여러 가속기에 나눠 학습할 때 가속기 간 집단 통신 대역폭이 성능의 병목이 되는데, 특정 벤더의 독자 규격에 묶이면 시스템 구성과 조달에서 선택권이 줄어드는 비용이 발생함.
- 주요 목적 : 서로 다른 제조사의 가속기를 같은 패브릭으로 연결하고, 가속기 간 로드/스토어와 원자 연산을 표준 방식으로 제공.

## Ⅱ. UALink 1.0의 특징 및 장점

- 핵심 요약 : 메모리 시맨틱 전송, 대규모 포드 구성, 개방형 생태계가 지연 단축과 공급망 선택권 확대로 이어지는 구조.

1. 메모리 시맨틱 전송 : 가속기가 원격 가속기의 메모리에 로드/스토어와 원자 연산을 직접 수행 → 네트워크 스택 처리 부담 감소와 왕복 지연 단축(컨소시엄은 1마이크로초 미만 왕복 지연을 목표로 발표).
2. 대규모 포드 구성 : 단일 포드에 최대 1,024개 가속기를 연결 → 모델을 분산하는 단위를 랙보다 넓게 설정.
3. 레인 속도와 링크 폭 : 레인당 200GT/s(신호 속도 212.5GT/s)에 x1·x2·x4 링크 폭 조합 → 필요한 대역폭에 맞춰 링크 구성.
4. 개방형 표준 : 다수 기업이 참여하고 규격서를 공개 배포 → 벤더 종속 감소와 호환 장비 선택폭 확대.

## Ⅲ. UALink 1.0의 구조 (흐름)

- 핵심 요약 : 가속기 포트, 스위치 패브릭, 메모리 트랜잭션이 하나의 포드를 이루는 계층 구조.
- **스위치 패브릭** (Switch Fabric) : 포드 안의 가속기 포트를 연결해 원격 메모리 접근 요청을 목적지 가속기로 전달하는 연결망.
- **원자 연산** (Atomic Operation) : 여러 가속기가 같은 메모리 위치를 동시에 갱신할 때 중간 상태 없이 한 번에 처리되도록 보장하는 연산.

```text
[ 포드 구성 ]

AI 가속기 (UALink 포트)
   ↓ 레인 묶음 (x1·x2·x4)
UALink 스위치 패브릭
   ↓
다른 AI 가속기 (원격 메모리)
```

```text
[ 원격 메모리 접근 흐름 ]

가속기 A: 로드/스토어 요청
   ↓
UALink 프로토콜로 패킷화
   ↓
스위치 경유 라우팅
   ↓
가속기 B: 메모리 응답 또는 원자 연산 결과
```

## Ⅳ. UALink 1.0과 기존 인터커넥트의 비교

- 핵심 요약 : UALink는 멀티 벤더 스케일업 용도로, NVLink·CXL·InfiniBand와 역할이 나뉘는 구도.

| 비교 축 | UALink 1.0 | NVLink (NVIDIA) | PCIe(Peripheral Component Interconnect Express) / CXL(Compute Express Link) | InfiniBand · 이더넷 |
| --- | --- | --- | --- | --- |
| 표준 성격 | 개방형 컨소시엄 표준 | NVIDIA 독자 규격 | 개방형 업계 표준 | 개방형 네트워크 표준 |
| 주된 용도 | 포드 내 가속기 스케일업 | GPU 간 스케일업(자사 생태계) | 호스트·디바이스·메모리 확장 | 클러스터 간 스케일아웃 |
| 통신 방식 | 메모리 로드/스토어·원자 연산 | GPU 간 메모리 접근 | I/O 및 캐시 일관 접근(CXL) | 메시지 기반 RDMA(Remote Direct Memory Access) 전송 |
| 벤더 종속 | 낮음(멀티 벤더 지향) | 높음 | 낮음 | 낮음 |

- 선택 기준 : 가속기 간 메모리 수준 통신이 필요한지, 노드와 클러스터 사이의 거리 확장이 필요한지에 따라 스케일업과 스케일아웃 계층을 나눠 선택함.

## Ⅴ. UALink 1.0의 한계와 방안

- 핵심 요약 : 상호운용성, 고속 신호 감쇠, 캐시 일관성 오버헤드를 인증 체계·광 연결·영역 단위 공유로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 멀티 벤더 상호운용성 | 벤더별 가속기 구현과 소프트웨어 스택 차이 → 초기 연동 검증과 디버깅 부담 증가 | 적합성 인증(Compliance Test) 체계 구축, 통신 라이브러리의 공통 추상화 계층 도입 | 인증 통과율, 연동 결함 건수 |
| 고속 신호 감쇠와 발열 | 200GT/s급 신호는 전송 거리가 길어질수록 감쇠가 커져 능동형 케이블과 전력 부담 증가 | 능동형 구리 케이블 활용, 공동 패키징 광학(CPO, Co-Packaged Optics) 전환 검토 | 링크 오류율, 랙당 전력 밀도 |
| 캐시 일관성 오버헤드 | 대규모 포드 전체에 하드웨어 일관성을 유지하면 디렉터리와 스누핑 트래픽이 급증 | 영역 단위 비일관성 공유 메모리 분할, 명시적 동기화 지점 설계 | 동기화 대기 시간, 유효 대역폭 비율 |

## Ⅵ. UALink 1.0에 대한 기술사적 제언

- 핵심 요약 : 조달 기준, 하이브리드 패브릭 설계 지침, 공동 검증 인프라를 갖추면 개방형 스케일업의 실효성이 높아짐.
- 국가 AI 컴퓨팅 인프라를 발주할 때 개방형 스케일업 규격 준수를 조달 요건에 넣으면, 특정 벤더 종속을 줄이면서 국내 가속기 기업의 참여 기회도 넓어진다.
- 스케일업은 UALink, 스케일아웃은 UEC(Ultra Ethernet Consortium) 계열 이더넷으로 역할을 나눈 하이브리드 패브릭 설계 지침을 공공 기관과 산업계가 함께 마련하면 시스템 설계의 혼선이 줄어든다.
- 적합성 시험 환경과 광 인터커넥트 연구를 산학이 공동으로 운영하면, 멀티 벤더 연동 검증 비용을 개별 기업이 떠안지 않고 나눌 수 있다.

## Ⅶ. 결론

- 핵심 요약 : UALink 1.0은 멀티 벤더 가속기를 메모리 수준으로 묶는 개방형 스케일업 표준임.
- 시사점 : 스케일업 패브릭의 개방성이 AI 인프라의 공급망 선택권을 좌우하는 변수로 떠오르고 있음.
