## 연관 키워드

- UALink(Ultra Accelerator Link), UALink 1.0, 스케일업(Scale-up), 스케일아웃(Scale-out), 포드(Pod)
- 로드/스토어(Load/Store), 원자 연산(Atomic Operation), 스위치 패브릭(Switch Fabric), 공유 메모리
- NVLink, CXL(Compute Express Link), RDMA(Remote Direct Memory Access), UEC(Ultra Ethernet Consortium), CPO(Co-Packaged Optics)

## Ⅰ. UALink 1.0의 개요

- 핵심 요약 : UALink 1.0은 서로 다른 제조사의 AI 가속기를 메모리 수준으로 묶는 개방형 스케일업 인터커넥트 표준.
- 개념 : 반도체·클라우드 기업 컨소시엄이 2025년 4월 공개한 **UALink** (Ultra Accelerator Link) 1.0 규격으로, 한 포드(Pod, 하나로 묶인 가속기 그룹) 안의 AI(Artificial Intelligence) 가속기를 스위치 패브릭으로 연결해 원격 메모리 접근을 제공하는 스케일업(Scale-up, 시스템 단위 안에서 자원을 묶어 확장하는 방식) 인터커넥트.
- 배경 및 필요성 : 대규모 모델 학습에서 가속기 간 통신이 성능 병목이 되는데, 주도 기업의 독자 인터커넥트에 의존하면 시스템 구성과 조달의 선택권이 제한되는 비용이 발생. 멀티 벤더 생태계를 위한 개방형 표준의 필요가 커짐.
- 주요 목적 : 가속기 간 메모리 수준 접근 방식의 표준화, 대규모 포드 구성, 벤더 종속 완화와 공급망 선택권 확대.

## Ⅱ. UALink 1.0의 특징 및 장점

- 핵심 요약 : 메모리 시맨틱 전송, 대규모 포드 구성, 개방형 표준이 지연 단축과 조달 선택권 확대로 이어지는 구조.

1. 메모리 시맨틱 전송 : 가속기가 원격 가속기의 메모리에 **로드/스토어** (Load/Store, 메모리 읽기·쓰기 명령)와 **원자 연산** (Atomic Operation, 여러 개체가 같은 메모리를 갱신할 때 중간 상태 없이 한 번에 처리되는 연산)을 직접 수행 → 메시지 전달 방식 대비 왕복 지연 단축(컨소시엄 발표 기준 1마이크로초 미만 목표).
2. 대규모 포드 구성 : 단일 포드에 최대 1,024개 가속기 연결 → 모델을 나누는 단위를 노드보다 넓게 확보.
3. 유연한 링크 구성 : 레인당 200G급 신호 속도와 x1·x2·x4 링크 폭 조합 → 대역폭 요구에 맞춘 링크 설계.
4. 개방형 컨소시엄 표준 : 반도체·클라우드·시스템 기업 다수 참여와 규격서 공개 → 호환 제품 선택폭 확대와 벤더 종속 감소.
5. 검증된 기반 기술 계승 : AMD의 Infinity Fabric 프로토콜을 표준화 기반으로 활용 → 기존 검증 자산에서 출발하는 초기 안정성 확보.

## Ⅲ. UALink 1.0의 구조 (흐름)

- 핵심 요약 : 가속기 포트, 스위치 패브릭, 메모리 트랜잭션이 하나의 포드를 이루는 계층 구조.
- **스위치 패브릭** (Switch Fabric) : 포드 안의 가속기 포트를 연결해 원격 메모리 접근 요청을 목적지 가속기로 전달하는 연결망.
- 비일관성 공유 메모리 : 하드웨어 캐시 일관성을 전면 유지하지 않고 주소 공간만 공유하는 접근 모델로, 동기화는 소프트웨어가 담당.

```text
[ 포드 내 연결 구조 ]

AI 가속기 (UALink 포트)
   ↓ x1·x2·x4 링크
UALink 스위치 패브릭
   ↓
다른 가속기 (원격 메모리)
```

```text
[ 원격 메모리 접근 흐름 ]

가속기 A의 로드/스토어 요청
   ↓
UALink 프로토콜 패킷화
   ↓
스위치 경유 라우팅
   ↓
가속기 B의 메모리 응답
```

## Ⅳ. UALink 1.0과 유사 인터커넥트의 비교

- 핵심 요약 : UALink는 멀티 벤더 스케일업 담당으로, NVLink·CXL·이더넷 계열과 역할이 나뉘는 구도.

| 비교 축 | UALink 1.0 | NVLink | CXL | 이더넷·InfiniBand |
| --- | --- | --- | --- | --- |
| 표준 성격 | 개방형 컨소시엄 표준 | NVIDIA 독자 규격 | 개방형 업계 표준 | 개방형 네트워크 표준 |
| 주된 용도 | 포드 내 가속기 스케일업 | 자사 GPU 스케일업 | 호스트·메모리 확장 | 클러스터 간 **스케일아웃** (Scale-out, 시스템 수 확장) |
| 통신 방식 | 메모리 로드/스토어·원자 연산 | GPU 간 메모리 접근 | I/O 및 캐시 일관 접근 | 메시지 기반 RDMA 전송 |
| 벤더 개방성 | 높음 | 낮음 | 높음 | 높음 |

- 선택 기준 : 가속기 간 메모리 수준 통신이 필요한지, 노드·클러스터 사이의 거리 확장이 필요한지에 따라 스케일업과 스케일아웃 계층을 나눠 선택함.

## Ⅴ. UALink 1.0의 한계와 방안

- 핵심 요약 : 상호운용성, 고속 신호 감쇠, 일관성 제어 부담, 생태계 성숙도를 인증 체계·광 연결·소프트웨어 설계로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 멀티 벤더 상호운용성 | 벤더별 구현·소프트웨어 스택 차이 → 연동 검증 부담 | 적합성 인증(Compliance Test) 체계, 통신 라이브러리 추상화 계층 | 인증 통과율, 연동 결함 건수 |
| 고속 신호 감쇠 | 200G급 신호는 거리 제약 → 케이블·전력 부담 | 능동형 구리 케이블 활용, **CPO** (Co-Packaged Optics, 칩 패키지에 광 소자를 함께 실장하는 기술) 전환 검토 | 링크 오류율, 랙당 전력 |
| 일관성 제어 부담 | 하드웨어 일관성 미제공 → 소프트웨어 동기화 책임 증가 | 영역별 메모리 분할, 명시적 동기화 지점 설계 | 동기화 대기 시간 |
| 생태계 성숙도 | 도구·검증 자산 부족 → 초기 도입 리스크 | 오픈소스 라이브러리 참여, 파일럿 구성 평가 | 도구 지원 범위 |

## Ⅵ. UALink 1.0에 대한 기술사적 제언

- 핵심 요약 : 조달 기준, 하이브리드 패브릭 설계 지침, 공동 검증 인프라가 개방형 스케일업의 실효성을 높임.
- 공공 발주 기관 : AI 인프라 조달 요건에 개방형 스케일업 규격 준수를 반영해 벤더 종속 완화와 국내 가속기 기업 참여 기회 확대.
- 설계 조직 : 스케일업은 UALink, 스케일아웃은 UEC(Ultra Ethernet Consortium) 계열 이더넷으로 역할을 나눈 하이브리드 패브릭 설계 지침 정립.
- 산학 협의체 : 적합성 시험 환경과 광 인터커넥트 연구를 공동 운영해 연동 검증 비용 분산.

## Ⅶ. 결론

- 핵심 요약 : UALink 1.0은 멀티 벤더 가속기를 메모리 수준으로 묶는 개방형 스케일업 표준.
- 시사점 : 스케일업 패브릭의 개방성이 AI 인프라의 공급망 선택권을 좌우하는 변수로 부상 중.
