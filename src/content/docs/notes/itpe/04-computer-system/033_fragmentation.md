## 연관 키워드

- 메모리 단편화(Fragmentation), 내부 단편화(Internal Fragmentation), 외부 단편화(External Fragmentation)
- 고정 분할(Fixed Partitioning), 가변 분할(Variable Partitioning), 최초 적합(First-Fit), 최적 적합(Best-Fit), 최악 적합(Worst-Fit)
- 통합(Coalescing), 압축(Compaction), 페이징(Paging), 세그멘테이션(Segmentation)
- 버디 시스템(Buddy System), 슬랩 할당자(Slab Allocator)

## Ⅰ. 메모리 단편화의 개요

- 핵심 요약 : **메모리 단편화** (Fragmentation)는 가용 공간의 총합이 충분함에도 조각화 때문에 실제로 쓸 수 없게 되는 자원 낭비 현상.
- 개념 : 주기억장치의 빈 공간이 작은 조각으로 흩어지거나, 배정된 블록 안에 사용되지 않는 공간이 남아 실질 가용량이 줄어드는 현상.
- 배경 및 필요성 : 프로세스의 적재와 종료가 반복되는 동적 할당 환경에서 **고정 분할** (Fixed Partitioning)은 블록 안 낭비를, **가변 분할** (Variable Partitioning)은 블록 사이 조각을 누적시키므로 유형별 원인 규명과 제어 필요.
- 주요 목적 : 단편화 유형별 발생 원인의 구분, 배치·회수 기법의 적용, 불연속 할당 구조 전환을 통한 메모리 이용률 극대화.

## Ⅱ. 메모리 단편화의 특징 및 장점

- 핵심 요약 : 낭비가 블록 안에서 생기는지 블록 사이에서 생기는지의 구분이 해소 기법 선택의 출발점.

1. **내부 단편화** (Internal Fragmentation) : 요구 크기보다 큰 고정 단위가 배정되어 블록 내부에 미사용 공간이 남는 현상 → 할당 단위를 워크로드 크기에 맞추면 낭비 축소 효과.
2. **외부 단편화** (External Fragmentation) : 할당과 해제 반복으로 빈 공간이 흩어져 총합은 충분해도 연속 배치가 불가능한 현상 → 불연속 배치 허용 구조로 해소 효과.
3. 배치 전략 : **최초 적합** (First-Fit)은 처음 발견한 공간에 배치해 탐색 속도 확보, **최적 적합** (Best-Fit)은 가장 근접한 공간 선택으로 잔여 조각 최소화, **최악 적합** (Worst-Fit)은 가장 큰 공간 선택으로 남는 조각의 재사용성 확보 → 워크로드별 전략 선택 가능.
4. **통합** (Coalescing) : 해제 시점에 인접 유휴 조각을 결합하는 회수 기법 → 낮은 비용으로 연속 공간 회복 효과.
5. **압축** (Compaction) : 점유 영역을 한쪽으로 이동해 유휴 공간을 하나로 모으는 회수 기법 → 외부 단편화의 직접 해소 효과.
6. **버디 시스템** (Buddy System) : 2의 거듭제곱 크기 블록으로 분할하고 짝 블록 병합을 반복하는 할당 체계 → 병합 규칙의 단순성으로 회수 속도 향상.
7. **슬랩 할당자** (Slab Allocator) : 객체 크기별 캐시 풀을 미리 구성하는 할당 체계 → 고정 크기 객체의 내부 낭비와 할당 지연 동시 완화.

## Ⅲ. 메모리 단편화의 구조 (흐름)

- 핵심 요약 : 분할 방식에서 단편화가 발생하고, 배치 전략과 회수 기법, 불연속 할당 계층이 순차적으로 이를 다스림.

```text
[ 단편화 발생과 해소 흐름 ]

프로세스 적재와 종료의 반복
   ↓
고정 분할 → 내부 단편화
가변 분할 → 외부 단편화
   ↓
배치 전략 : First·Best·Worst-Fit
   ↓
회수 기법 : 통합, 압축
   ↓
불연속 할당 구조로 전환
```

```text
[ 외부 단편화 상태 예시 ]

프로세스 A 점유 영역
   ↓
유휴 조각 10MB
   ↓
프로세스 B 점유 영역
   ↓
유휴 조각 15MB
   ↓
총합 25MB, 연속 20MB 요구 불가
```

- 구성요소 : 분할 정책(고정·가변), 배치 전략, 회수 기법(통합·압축), 불연속 할당 계층의 네 계층으로 구성.
- 페이징·세그멘테이션과의 연결 : **페이징** (Paging)은 프로세스를 고정 크기 페이지로, **세그멘테이션** (Segmentation)은 논리 단위 세그먼트로 잘라 물리 메모리에 흩어 배치하므로 외부 단편화를 구조적으로 제거하는 수단.

## Ⅳ. 내부 단편화와 외부 단편화의 비교

- 핵심 요약 : 두 단편화는 발생 위치와 원인, 판정 방법이 달라 대응 기법과 비용 성격도 구분됨.

| 비교 항목 | 내부 단편화 | 외부 단편화 |
| --- | --- | --- |
| 발생 위치 | 배정된 블록 내부 | 블록 사이의 유휴 공간 |
| 유발 구조 | 고정 분할, 고정 크기 단위 할당 | 가변 분할, 연속 배치 방식 |
| 판정 방법 | 할당량과 실사용량의 차이 | 가용 총합과 최대 연속 크기의 차이 |
| 대표 해소 기법 | 슬랩 할당자, 할당 단위 재설계 | 통합, 압축, 버디 병합, 페이징 전환 |
| 비용 성격 | 고정적 공간 낭비 | 시간 경과에 따른 탐색·재배치 비용 증가 |

- 선택 기준 : 요구 크기의 편차가 작은 워크로드는 고정 단위의 내부 낭비를 감수하고, 크기 편차가 크고 장기 가동하는 시스템은 회수 기법과 불연속 할당 중심으로 설계.

## Ⅴ. 메모리 단편화의 한계와 방안

- 핵심 요약 : 압축의 실행 정지, 통합의 결합 한계, 장기 가동 힙의 파편화 누적을 재배치 시점 제어, 병합 규칙, 풀 기반 할당으로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 압축 중 실행 정지 | 점유 영역 이동과 주소 재계산 동안 프로세스 중단 → 응답 지연 | 유휴 시점에 압축을 수행하고, 주소 변환 계층으로 논리 주소 고정 | 압축 소요 시간, 압축 빈도 |
| 통합의 효과 한계 | 인접하지 않은 조각은 결합 불가 → 흩어짐 지속 | 버디 시스템의 병합 규칙 도입, 필요 시 압축 병행 | 최대 연속 유휴 크기 |
| 장기 가동 힙의 파편화 누적 | 가변 크기 객체의 생성·해제 반복 → 총 가용량 충분에도 할당 실패 | 크기별 객체 풀의 슬랩 할당자 채택, 객체 크기 등급화 | 할당 실패 횟수, 조각화 비율 |

## Ⅵ. 메모리 단편화에 대한 기술사적 제언

- 핵심 요약 : 할당 단위 설계 기준, 회수 정책 표준, 단편화 지표 관측을 조직 표준으로 정착하는 방향.

1. 플랫폼 개발 조직이 객체 크기별 풀과 정렬 규칙을 공통 할당자 표준으로 정하고, 신규 모듈의 동적 할당을 일원화해 내부 낭비를 설계 단계에서 통제.
2. 운영 조직이 가용 총량과 최대 연속 크기를 주기 수집 대상으로 지정해 조각화 추세를 관측하고, 임계 도달 시 회수 절차를 자동 수행.
3. 시스템 설계 조직이 신규 시스템 검토 시 워크로드 크기 분포와 할당 단위의 적합성을 평가 항목에 포함해 단편화 리스크를 사전 반영.

## Ⅶ. 결론

- 핵심 요약 : 메모리 단편화는 블록 안과 블록 사이에서 각각 발생하는 이중의 자원 낭비 문제.
- 시사점 : 발생 위치별 원인에 맞춰 배치·회수·불연속 할당을 조합할 때 이용률과 성능의 균형이 확보되는 구조.
