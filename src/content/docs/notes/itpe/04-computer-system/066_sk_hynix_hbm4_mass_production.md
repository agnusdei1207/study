## 연관 키워드

- HBM4(High Bandwidth Memory 4), 베이스 다이(Base Die), MR-MUF(Mass Reflow Molded Underfill), NCF(Non-Conductive Film)
- TSMC 파운드리 협력, CoWoS(Chip on Wafer on Substrate), 하이브리드 본딩(Hybrid Bonding), TSV(Through Silicon Via)
- 2048비트 인터페이스, 대역폭, 웨이퍼 휨(Warpage), 신호 무결성(Signal Integrity)

## Ⅰ. SK하이닉스 HBM4 양산의 개요

- 핵심 요약 : HBM4 양산은 적층 공법과 파운드리 협력으로 고대역폭 메모리의 물리적 한계를 넘는 양산 체계.
- 개념 : **HBM4** (High Bandwidth Memory 4)는 DRAM(Dynamic Random-Access Memory) 다이를 수직으로 쌓고 로직 다이와 결합해 넓은 인터페이스로 데이터를 전송하는 4세대 고대역폭 메모리이며, SK하이닉스 양산 체계는 이를 **MR-MUF** (Mass Reflow Molded Underfill) 적층 공법과 TSMC(Taiwan Semiconductor Manufacturing Company) 파운드리의 베이스 다이 제작으로 구현하는 방식.
- 배경 및 필요성 : AI(Artificial Intelligence) 가속기인 GPU(Graphics Processing Unit)의 연산 성능이 커질수록 메모리 대역폭 병목이 심해지고, 대역폭을 높이려 I/O 폭과 적층 수를 늘리면 공정 난도·방열·높이 규격 부담이 함께 커지므로 적층 공법과 파운드리 협력이 필요해짐.
- 주요 목적 : 2048비트 인터페이스 구현, 적층 높이 규격 준수와 방열 확보, 파운드리와의 협력으로 양산 수율 안정화.

## Ⅱ. SK하이닉스 HBM4 양산의 특징 및 장점

- 핵심 요약 : 파운드리 협력 베이스 다이, 일괄 적층 공법, 넓은 I/O가 방열·생산성·대역폭 이득으로 이어지는 구조.

1. 파운드리 협력형 베이스 다이 : 베이스 다이를 TSMC의 로직 공정으로 제작 → 제어 회로의 집적도와 전력 효율 향상으로 대역폭당 전력 부담 완화.
2. 일괄 적층 공법(MR-MUF) : 다이를 한 번에 리플로우로 접합하고 보호재를 일괄 충진 → 다이 사이 방열 경로 확보와 공정 반복 횟수 감소.
3. 2048비트 인터페이스 : 기존 HBM3E의 1024비트 대비 폭을 두 배로 넓힘 → 같은 클록에서 대역폭 증가. 자사는 10GT/s 동작 속도를 목표로 발표했으며, 이 수치를 적용하면 스택당 이론상 약 2.5TB/s 수준.
4. 하이브리드 본딩 확장 경로 : 현재 범프 기반 접합을 유지하면서 차세대 구리-구리 직접 접합으로 옮겨갈 수 있는 기술 로드맵 확보 → 적층 높이 한계를 단계적으로 극복.

## Ⅲ. SK하이닉스 HBM4 양산의 구조 (흐름)

- 핵심 요약 : 이종 팹에서 만든 베이스 다이와 DRAM 다이를 MR-MUF로 묶고, CoWoS로 GPU 곁에 실장하는 3단계 흐름.
- **베이스 다이** (Base Die) : 스택 최하단에서 DRAM 다이와 외부 인터페이스를 잇고 제어 로직을 담당하는 로직 다이.
- **CoWoS** (Chip on Wafer on Substrate) : TSMC의 2.5D 패키징 기술로, 여러 HBM 스택과 GPU를 인터포저 위에 나란히 올려 실장하는 방식.
- **TSV** (Through Silicon Via) : 실리콘 관통 전극으로, 다이를 수직으로 관통해 층간 신호와 전력을 전달하는 경로.

```text
[ 공정 흐름 ]

1b 나노급 DRAM 다이 제작 (SK하이닉스)
   ↓
베이스 다이 제작 (TSMC 로직 공정)
   ↓
MR-MUF 일괄 적층·리플로우 접합
   ↓
스택 검사 및 선별
   ↓
CoWoS 패키지로 GPU 곁에 실장
```

```text
[ 신호 경로 ]

GPU 연산 코어
   ↓ (CoWoS 인터포저 배선)
HBM4 베이스 다이
   ↓ (TSV 관통 전극)
DRAM 다이 적층 (상단 방향)
```

## Ⅳ. SK하이닉스 HBM4 양산과 기존 방식의 비교

- 핵심 요약 : 필름 적층, MR-MUF 일괄 충진, 하이브리드 본딩은 방열·공정 부담·높이 제어에서 차이가 나며 MR-MUF가 현재 양산 기준이 되는 구도.

| 비교 축 | NCF(Non-Conductive Film) 계열 (필름 적층) | MR-MUF (SK하이닉스) | 하이브리드 본딩 |
| --- | --- | --- | --- |
| 접합 방식 | 다이마다 비전도성 필름 부착 후 열압착 | 다이 일괄 리플로우 후 보호재 충진 | 범프 없이 구리-구리 직접 접합 |
| 방열 특성 | 층별 접합으로 열 경로 관리 부담 증가 | 충진재 일괄 적용으로 방열 경로 확보 | 금속 직접 접촉으로 열 경로 단순화 |
| 공정 부담 | 적층 수에 비례해 공정 횟수 증가 | 일괄 공정으로 적층 수 증가 부담 완화 | 표면 평탄화·정밀 정렬 난도 높음 |
| 높이 제어 | 범프 높이만큼 스택 높이 증가 | 웨이퍼 박형화로 높이 규격 대응 | 범프 공간 제거로 높이 축소 가능 |
| 적용 단계 | 기존 HBM 세대의 주요 방식 | HBM3E·HBM4 양산 적용 | 차세대 후보, 선행 개발 단계 |

- 선택 기준 : 적층 수, 방열 요구, 공정 수율, 제품 높이 규격을 함께 보고 현재 양산성과 차세대 확장성 중 무엇을 우선할지 정함.

## Ⅴ. SK하이닉스 HBM4 양산의 한계와 방안

- 핵심 요약 : 박형화 휨, 이종 팹 불량 책임, 고밀도 신호 품질을 공정 관리와 데이터 공유로 통제.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 박형 웨이퍼의 휨(Warpage)과 크랙 | 적층 높이 규격을 맞추려 웨이퍼를 얇게 연마 → 강성 저하로 휨·균열 발생 → 수율 하락 | 박막 웨이퍼 취급 캐리어 기술 고도화, 응력을 줄이는 충진재 적용 | 휨량, 균열 발생률 |
| 이종 팹 간 불량 책임 소재 | TSMC 베이스 다이와 자사 DRAM 다이 결합 후 불량 발생 시 원인 규명 지연 | 다이 단위 테스트 데이터 공유 체계, 공동 불량 분석 절차 수립 | 원인 규명 소요 기간, 공동 분석 건수 |
| 고밀도 I/O의 신호 무결성 | 배선 밀도 증가 → 인접 배선 간 간섭과 전송 손실 증가 | 인터포저 배선 설계 최적화, 저유전율 절연 재료 적용 | 비트 오류율, 신호 품질 마진 |

## Ⅵ. SK하이닉스 HBM4 양산에 대한 기술사적 제언

- 핵심 요약 : 파운드리와의 책임 경계, 차세대 접합 기술 확보, 업계 공동 검증 체계를 함께 갖출 때 적층 메모리 경쟁이 안정됨.
- 반도체 기업은 파운드리와의 공동 설계·테스트 협약을 장기 계약으로 묶고, 이종 팹 사이의 불량 책임 경계를 사전에 문서로 정해 두는 것이 바람직하다.
- 국가 연구기관과 산업계는 박막 웨이퍼 취급과 하이브리드 본딩 공정을 공동 연구 과제로 묶어, 차세대 적층 기술을 국내에서 확보할 기반을 넓히는 방향이 좋다.
- AI 반도체 생태계에서 메모리, 패키징, 설계 기업이 인터페이스 검증 데이터를 공유하는 협의체를 두면, 대역폭 확대에 따른 신뢰성 리스크를 함께 줄일 수 있다.

## Ⅶ. 결론

- 핵심 요약 : HBM4 양산은 적층 공법과 파운드리 협력이 메모리 대역폭 한계를 넘는 핵심 수단임을 보여주는 사례.
- 시사점 : 고대역폭 메모리의 경쟁력이 DRAM 다이 자체보다 적층·접합·검사를 아우르는 패키징 역량에서 결정되는 방향으로 이동하는 중.
