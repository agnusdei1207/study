## Ⅰ. HBM4의 개요

- 개념 : **TSV(Through Silicon Via, 실리콘 관통 전극)** 기술을 적용하여 DRAM 다이를 수직으로 12단~16단 초고집적 적층하고, **베이스 다이(Base Die)** 를 첨단 파운드리 로직 공정으로 전환하여 **2048-bit 초광대역 인터페이스** 와 2~3TB/s 이상의 전송 속도를 구현한 6세대 초고속 AI 메모리 표준.
- 배경 및 필요성 : LLM 모델 파라미터가 수천억~수조 개로 폭증하면서 GPU의 연산 능력에 비해 메모리 대역폭이 턱없이 부족한 '메모리 벽(Memory Wall)' 현상이 심화되어, HBM3E를 뛰어넘는 대역폭 혁신이 불가피해짐.
- 핵심 목적 : 입출력 버스 폭 2배 확장(1024-bit -> 2048-bit), 테라바이트급 초광대역폭 달성, 첨단 패키징을 통한 전력 효율 극대화 및 패키지 폼팩터 축소.

## Ⅱ. HBM4의 핵심 아키텍처 및 동작 메커니즘

HBM4는 1024비트의 기존 한계를 깨고 2048비트 I/O 인터페이스를 최초로 적용하였으며, 베이스 다이에 첨단 파운드리 공정(3nm/4nm)을 접목하여 성능과 커스텀 로직 통합성을 획기적으로 개선함.

```text
[ HBM4 초고집적 적층 및 패키징 아키텍처 ]

+---------------------------------------------------------------+
| DRAM Die 16 (최상단 코어 다이)                                |
+---------------------------------------------------------------+
       ││││││││ (Advanced MR-MUF / Hybrid Bonding Cu-Cu 접합)
+---------------------------------------------------------------+
| DRAM Die 1 ~ 15 (수직 적층 코어 다이, 미세 박막화 웨이퍼)     |
|   - TSV (Through Silicon Via: 수만 개의 실리콘 관통 전극)     |
+---------------------------------------------------------------+
       ││││││││
+---------------------------------------------------------------+
| HBM4 Base Die (베이스/버퍼 다이)                               |
|   * 핵심 변화: 전통적 메모리 공정 -> TSMC/삼성 파운드리 첨단 로직 공정 |
|   - 2048-bit 초광대역 인터페이스 컨트롤러 내장                |
|   - 커스텀 연산 로직 (PIM: Processing-In-Memory) 결합 가능     |
|   - 자체 테스트 및 복구 BIST 회로 내장                        |
+---------------------------------------------------------------+
       ││││││││ (마이크로 범프 / 범프리스 직접 접합)
+---------------------------------------------------------------+
| Silicon Interposer (2.5D 패키징 CoWoS / I-Cube)               |
+---------------------------------------------------------------+
       │                                                │
       ▼                                                ▼
+-------------------------------+              +----------------+
| Host AI 가속기 (GPU / NPU)    | <── 2048-bit ── | HBM4 Stack     |
+-------------------------------+              +----------------+
```

- **2048-bit I/O 인터페이스** : HBM1부터 HBM3E까지 유지되던 1024비트 인터페이스를 2배로 확장하여 신호 속도를 무리하게 올리지 않고도 대역폭 2배 확보.
- **첨단 파운드리 로직 베이스 다이** : 메모리 레거시 공정 대신 첨단 FinFET/GAA 3nm·4nm 로직 공정을 채택하여 초저전력 구동 및 커스텀 제어 구현.
- **16단(16-High) 초고적층 기술** : 단일 패키지에서 최대 48GB~64GB의 초대용량 메모리를 구현하기 위해 웨이퍼 두께를 극한으로 얇게 연마.
- **하이브리드 본딩(Hybrid Bonding) 도입** : 기존 마이크로 범프 대신 구리(Cu-Cu)를 직접 맞붙여 범프 공간을 없애고 두께 표준(775um) 준수 및 방열 성능 극대화.

## Ⅲ. HBM4의 세부 구성 요소 및 비교 분석

| 비교 규격 | HBM3 | HBM3E | HBM4 |
|---|---|---|---|
| **I/O 버스 폭** | 1024-bit | 1024-bit | 2048-bit (2배 확장) |
| **핀당 전송 속도** | ~ 6.4 Gbps | ~ 9.6 Gbps | ~ 10+ Gbps |
| **스택당 최대 대역폭** | 819 GB/s | 1.2 TB/s | 2.0 ~ 3.0+ TB/s |
| **최대 적층 수** | 8단 / 12단 | 8단 / 12단 | 12단 / 16단 |
| **베이스 다이 공정** | 메모리 레거시 공정 | 메모리 레거시 공정 | 첨단 파운드리 로직 공정 (3/4nm) |
| **패키징 접합 기술** | MR-MUF / NCF | Advanced MR-MUF / NCF | Advanced MR-MUF / 하이브리드 본딩 |

- HBM4는 단순한 메모리 부품이 아니라 GPU/NPU 가속기와 단일 시스템 수준으로 밀결합되는 커스텀 시스템 반도체로 격상됨.

## Ⅳ. HBM4의 주요 한계점 및 해결 방안

- 16단 초고적층에 따른 열 방출 저하 및 열팽창 **휨(Warpage)** :
  - 한계점 : DRAM 다이가 16단으로 쌓이면서 중심부 열이 외부로 빠져나가지 못해 열폭주(Thermal Throttling) 발생 및 칩 휨 현상.
  - 해결 방안 : 고열전도성 EMC 소재 기반 Advanced MR-MUF 적용, 범프를 제거하여 방열 면적을 극대화하는 Cu-Cu 하이브리드 본딩 상용화.
- 메모리 제조사와 파운드리 간 협업 복잡도 및 수율 책임 소재 :
  - 한계점 : 베이스 다이는 파운드리(TSMC 등)에서 생산하고 코어 다이는 메모리사(SK하이닉스, 삼성)가 제작함에 따라 수율 결함 분석 및 책임 모호.
  - 해결 방안 : 양사 간 원팀(One-Team) 턴키 패키징 얼라이언스 구축, 다이 간 테스트(BIST/BISR) 표준화.
- 제조 공정 고난도화에 따른 패키징 **원가(Cost)** 급상승 :
  - 한계점 : 하이브리드 본딩 장비와 첨단 2.5D 인터포저 비용으로 인해 AI 하드웨어 전체 BOM(원가) 비중 과다.
  - 해결 방안 : 12단 제품은 기존 어드밴스드 MR-MUF 공정으로 양산 수율을 조기 확보하고, 16단 플래그십에 하이브리드 본딩 선별 적용.

## Ⅴ. HBM4 적용 및 발전을 위한 기술사적 제언

- **커스텀 HBM(Customized HBM)** 및 PIM의 융합 : 로직 베이스 다이 내부에 가속기 연산의 일부를 오프로드하는 PIM(Processing-In-Memory) 기능을 내장하여 메모리 내부 연산 상용화 추진.
- K-반도체 글로벌 파운드리-메모리 공급망 주도권 수호 : HBM4는 메모리와 파운드리가 완벽히 결합되는 지점이므로 차세대 3D 패키징 및 소재 생태계의 국가적 육성 필수.
- 차세대 패키징 기판(유리기판) 연계 검증 : 2048개 신호 라인의 고밀도 배선 및 신호 무결성(SI) 확보를 위해 실리콘 인터포저를 대체할 유리 기판(Glass Substrate) R&D 병행 권장.
