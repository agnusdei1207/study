## 답안 골격
```text
[유전 알고리즘] ◀━━ 머리: Ⅶ 내 의견 (엘리티즘 보존과 동적 돌연변이율을 적용한 NP-Hard 조합 최적화 자동화 파이프라인 구축)
 ┃
 ┣━ Ⅰ 개요 ───── 수학적 미분이 불가능한 복잡 탐색 공간 → 다윈의 적자생존과 유전 메커니즘을 모방한 전역 최적화 알고리즘
 ┣━ Ⅱ 특징 ───── 전역 최적해 탐색 · 확률적 탐색 · 모집단(Population) 기반 병렬성 · 블랙박스 최적화
 ┣━ Ⅲ 구조 ───── 염색체(Chromosome/비트열) + 적합도 함수(Fitness Function) + 3대 연산자(선택·교차·돌연변이)
 ┣━ Ⅳ 흐름 ───── ① 초기 집단 생성 → ② 적합도 평가 → ③ 우수 개체 선택 → ④ 교차(Crossover) → ⑤ 돌연변이(Mutation) → ⑥ 수렴 판정
 ┣━ Ⅴ 비교 ───── 룰렛 휠 선택 vs 토너먼트 선택 vs 순위 선택
 ┗━ Ⅵ 실무 ───── 조기 수렴(Premature Convergence)으로 국소 최적해 갇힘 / 적합도 함수 설계 난이도 / 하이퍼파라미터 민감성
```

## 한 줄 본질
- 미분이 불가능하거나 탐색 공간이 너무 넓어 전수 조사가 불가능한 NP-Hard 최적화 문제 → 해(Solution)를 염색체로 부호화하고 세대를 거듭하며 선택, 교차, 돌연변이를 반복 적용 → 전역 최적해(Global Optimum)에 근사 / 국소 최적해(Local Optima) 함몰 및 연산 시간 수반

## 핵심 그림
```text
[ 유전 알고리즘의 세대 진화 흐름 및 3대 유전 연산자 ]

[ 초기 모집단 (Generation t) ]
  염색체 A: [ 1 0 1 1 0 0 1 ] ──(적합도 평가: High)──┐
  염색체 B: [ 0 1 1 0 1 1 0 ] ──(적합도 평가: High)──┼──> [ 1. 선택 (Selection) ]
  염색체 C: [ 0 0 0 1 0 1 0 ] ──(적합도 평가: Low) ──┘     (룰렛휠 / 토너먼트)
                                                              │
                                                              v
                                                   [ 2. 교차 (Crossover) ]
                                                    - 단일점 교차 (절단점 분할)
                                                    부모 A: [ 1 0 1 | 1 0 0 1 ]
                                                    부모 B: [ 0 1 1 | 0 1 1 0 ]
                                                              │
                                                              v
                                                    자식 1: [ 1 0 1 | 0 1 1 0 ]
                                                    자식 2: [ 0 1 1 | 1 0 0 1 ]
                                                              │
                                                              v
                                                   [ 3. 돌연변이 (Mutation) ]
                                                    자식 1': [ 1 0 (0) 0 1 1 0 ] (비트 반전!)
                                                              │
                                                              v
                                                   [ 차세대 모집단 (Generation t+1) ]
```

## 핵심 용어
- 적합도 함수(Fitness Function): 특정 염색체가 문제의 요구조건을 얼마나 잘 만족하는지 수치화하여 생존 확률을 결정하는 핵심 평가 척도
- 조기 수렴(Premature Convergence): 진화 초기에 우연히 높은 적합도를 가진 소수의 개체가 모집단 전체를 지배하여, 탐색 공간의 다른 영역을 보지 못하고 국소 최적해에 갇히는 현상
- 엘리티즘(Elitism): 매 세대마다 가장 우수한 최상위 개체(들)를 교차나 변이 없이 다음 세대로 그대로 복제 보존하여 최고 해의 유실을 방지하는 전략

## 핵심 통찰
- 교차는 '착취(Exploitation)', 돌연변이는 '탐색(Exploration)'임 → 교차는 이미 찾은 좋은 형질을 조합하여 더 나은 해를 쥐어짜내는 작업이고, 돌연변이는 엉뚱한 곳을 찔러 새로운 가능성을 열어젖히는 작업이므로 둘의 균형이 알고리즘의 성패를 가름
- 유전 알고리즘은 '수학적 완벽함'을 버리고 '실용성'을 택한 타협임 → 엄밀한 최적해를 찾는 것이 이론상 불가능한 NP-Hard 문제에서, 인간이 감당할 수 있는 시간 안에 상위 95% 수준의 쓸만한 근사해를 빠르게 뽑아냄
- 표현 방식(인코딩)이 전부임 → 비트열(0/1) 인코딩 외에 순서가 중요한 문제(외판원 순회)는 순열 인코딩과 PMX(부분 일치 교차)를 써야 유효하지 않은 해(동일 도시 중복 방문) 생성을 방지함

## 이웃 토픽과 구분
- 유전 알고리즘 vs 시뮬레이티드 어닐링(모의 담금질): 유전 알고리즘 = 여러 개체(모집단)가 동시에 진화하는 병렬 탐색 / 시뮬레이티드 어닐링 = 단 1개의 상태 점이 온도를 낮춰가며 확률적으로 이동하는 단일 탐색

## 문제·원인·대책
- 사례: 137회 기출 및 대규모 물류 배송 경로 최적화(TSP)에서 50세대 만에 국소 최적해에 갇혀 진화가 정지된 사례
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 진화 초기에 특정 우수 개체가 집단을 획일화시켜 조기 수렴 발생 | 모집단의 다양성(Diversity) 상실 및 과도하게 높은 선택 압력 | 섬 모델(Island Model: 독립 군집 분리 진화 후 주기적 이주) 및 적응형 돌연변이 적용 | 유전적 다양성 보존으로 국소 최적해 탈출 |
| 세대가 거듭되면서 교차/변이에 의해 이전 세대의 최고 적합도 해 유실 | 확률적 교차 및 무작위 돌연변이로 우수 유전자 파괴 | 엘리티즘(Elitist Strategy: 최우수 1~2개체 무조건 차세대 직행) 적용 | 세대별 최고 적합도의 단조 증가(Monotonic Increase) 보장 |
