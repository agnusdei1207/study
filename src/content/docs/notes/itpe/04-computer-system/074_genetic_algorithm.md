## 연관 키워드

- 유전 알고리즘, Genetic Algorithm, 메타휴리스틱, 염색체 인코딩, 적합도
- 선택, 교차, 돌연변이, 엘리티즘, 룰렛 휠, 토너먼트 선택
- 조기 수렴, 아일랜드 모델, 멤틱 알고리즘, 신경망 구조 탐색, NP-Hard

## Ⅰ. 유전 알고리즘의 개요

- 핵심 요약 : 자연선택과 유전 연산을 모방해 조합 최적화 문제의 준최적해를 찾는 메타휴리스틱 탐색 기법.
- 개념 : 생물의 자연선택과 유전 원리를 모방해 해의 집단을 세대마다 진화시키며 최적해에 가까운 해를 찾는 확률적 탐색 기법 (**유전 알고리즘**, GA, Genetic Algorithm). 해 공간을 직접 전부 탐색하지 않고 **메타휴리스틱** (Metaheuristic, 일반적 탐색 전략을 문제에 맞춰 적용하는 상위 탐색 틀)으로 동작함.
- 배경 및 필요성 : 외판원 문제나 배낭 문제처럼 후보 조합이 기하급수적으로 늘어나는 **NP-Hard** (Non-deterministic Polynomial-time hard) 문제는 완전 탐색 비용이 현실적이지 않아, 정답을 보장하지 않더라도 충분히 좋은 해를 짧은 시간에 얻는 방식이 필요해짐. 존 홀랜드(John Holland)가 이 접근을 체계화함.
- 주요 목적 : 다점 병렬 탐색으로 **지역 최적해** (Local Optimum)에서 벗어나고, **탐색** (Exploration)과 **활용** (Exploitation)의 균형을 맞추어 비선형·비연속 문제의 실용적 해를 얻는 것.

## Ⅱ. 유전 알고리즘의 특징 및 장점

- 핵심 요약 : 인코딩, 선택, 교차와 돌연변이의 반복이 다점 병렬 탐색과 조기 수렴 방지로 이어지는 구조.

1. 염색체 인코딩 (Encoding) : 해를 이진 문자열, 실수 벡터, 순열 형태의 염색체로 표현 → 문제 형태에 맞춘 탐색 공간 정의.
2. **선택** (Selection) : 적합도가 높은 개체를 우선 뽑는 연산 → 좋은 유전 정보가 다음 세대로 전달되어 수렴 속도 향상.
3. **교차** (Crossover)와 **돌연변이** (Mutation) : 부모의 유전자 블록을 결합해 새로운 조합을 만들고, 낮은 확률의 무작위 변이를 더함 → 탐색 영역 확장과 조기 수렴 방지.

## Ⅲ. 유전 알고리즘의 구조 (흐름)

- 핵심 요약 : 초기 모집단 생성부터 적합도 평가, 선택, 유전 연산, 차세대 구성까지를 세대 단위로 반복하는 루프 구조.
- 구성 요소 : 염색체(Chromosome) 집합인 모집단, 목적 함수로 계산하는 적합도, 부모 선택, 교차 확률 Pc와 돌연변이 확률 Pm으로 제어되는 유전 연산, 우수 개체를 보존하는 엘리티즘.

```text
[ 유전 알고리즘 실행 흐름 ]

초기 모집단 생성 (염색체 집합)
            ↓
적합도 평가 (목적 함수 계산)
            ↓
종료 조건 충족? ──(예)──> 최적해 출력
            ↓ (아니오)
부모 선택 (룰렛 휠, 토너먼트)
            ↓
교차 (확률 Pc) · 돌연변이 (확률 Pm)
            ↓
차세대 모집단 구성 (엘리티즘 포함)
            ↓
세대 반복 → 적합도 평가로 복귀
```

```text
[ 유전 연산자의 역할 분담 ]

선택 (Selection)
   ↓ 우수 개체 집중 → 활용
교차 (Crossover)
   ↓ 부모 유전자 결합 → 새로운 조합 생성
돌연변이 (Mutation)
   ↓ 무작위 변이 → 다양성 유지와 탐색
```

## Ⅳ. 유전 알고리즘의 비교

- 핵심 요약 : 선택 압력, 교차 방식, 돌연변이 방식에 따라 수렴 속도와 다양성의 트레이드오프가 달라지는 구조.
- 선택 기준 : 문제의 해 표현 방식(순서 의존 여부)과 수렴 속도 대비 다양성 요구에 따라 연산자를 고른다.

| 연산자 | 기법 | 동작 특성 | 장단점 및 고려 사항 |
| :--- | :--- | :--- | :--- |
| 선택 | 룰렛 휠 선택 | 적합도 비율만큼 확률 영역을 배정해 선택 | 구현이 간단하나 우수 개체 편중으로 조기 수렴 위험 |
| 선택 | 토너먼트 선택 | 임의의 K개 개체 중 최우수 개체 선발 | K 크기로 선택 압력 조절이 쉬움 |
| 선택 | 엘리티즘 | 최우수 개체를 차세대에 그대로 보존 | 최적해 소실 방지, 과도하면 지역 최적해에 고착 |
| 교차 | 일점·다점 교차 | 교차점 기준으로 부모 유전자 블록 교환 | 순서가 중요한 문제(순회 경로)에서는 중복 유전자가 생겨 유효하지 않은 해 발생 |
| 교차 | 균등 교차 | 유전자 자리마다 부모 중 하나를 확률로 선택 | 다양성 유지에 유리하나 좋은 블록이 깨질 가능성 높음 |
| 돌연변이 | 비트 반전 | 이진 문자열의 특정 비트를 0과 1 사이에서 반전 | 탐색 공간 확장, 확률이 과하면 무작위 탐색으로 전락 |

## Ⅴ. 유전 알고리즘의 한계와 방안

- 핵심 요약 : 조기 수렴, 파라미터 민감성, 평가 연산 지연을 적응형 변이, 자동 튜닝, 병렬 평가로 대응하는 구조.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| **조기 수렴** (Premature Convergence) | 초기에 우연히 생긴 준우수 개체가 모집단을 지배해 다양성 소실, 전역 해 도달 실패 | 수렴도에 따라 돌연변이율을 올리는 적응형 GA 적용, 서브 모집단 간 이주를 허용하는 **아일랜드 모델** (Island Model) 도입 | 모집단 다양성 지표, 세대별 최고 적합도 추이 |
| 파라미터 튜닝 복잡성 | 개체 수, 교차율, 돌연변이율, 적합도 함수에 따라 성능 편차가 크고 이론적 기준 부재 | 도메인 지식에 맞춘 인코딩 선택, 메타 파라미터를 자동 탐색하는 AutoML(Automated Machine Learning) 연계 | 파라미터 설정별 해 품질 편차 |
| 평가 연산 지연 | 세대마다 전체 모집단을 평가해 실시간 제어에서 응답 시간 초과 | 평가를 GPU(Graphics Processing Unit)·FPGA(Field-Programmable Gate Array)에서 병렬 수행, 국소 탐색을 결합한 **멤틱 알고리즘** (Memetic Algorithm) 적용 | 세대당 평가 시간, 목표 응답 시간 달성률 |

## Ⅵ. 유전 알고리즘에 대한 기술사적 제언

- 핵심 요약 : 유전 알고리즘을 단독 기법이 아니라 국소 탐색과 신경망 설계 자동화에 결합하는 하이브리드 운영으로 활용.

1. 조합 최적화 문제에 유전 알고리즘을 적용할 때는 해 평가 비용이 낮은지부터 확인하고, 평가 비용이 낮으면 후반부에 국소 탐색을 붙인 멤틱 구성으로 정밀 수렴을 얻는 편이 바람직하다.
2. 신경망 설계에서는 **신경망 구조 탐색** (NAS, Neural Architecture Search)에 유전 알고리즘을 적용해 구조 후보를 자동 탐색하되, 후보마다 학습 비용이 크므로 탐색 공간과 평가 예산을 사전에 제한하는 운영 규칙을 함께 두는 것이 필요하다.

## Ⅶ. 결론

- 핵심 요약 : 유전 알고리즘은 자연선택을 모방한 메타휴리스틱으로, NP-Hard 조합 최적화에서 실용적인 준최적해를 얻는 기법.
- 조기 수렴과 파라미터 민감성을 관리할 수 있는 문제에서 효용이 크며, 그 관리 체계가 적용 가능성을 결정함.
