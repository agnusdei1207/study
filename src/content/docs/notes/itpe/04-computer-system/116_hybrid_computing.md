## 30초 인출

- 본질: 제어와 직렬 연산에 강한 고전 CPU, 대규모 행렬 병렬 처리에 특화된 GPU/NPU, 지수적 탐색 공간을 샘플링하는 양자 QPU를 저지연 인터커넥트로 묶어 문제의 성격에 따라 최적의 연산 엔진에 분배·협업시키는 차세대 이종 융합 컴퓨팅 패러다임
- 메커니즘: 제어와 직렬 연산에 강한 고전 CPU, 대규모 행렬 병렬 처리에 특화된 GPU/NPU, 지수적 탐색 공간을 샘플링하는 양자 QPU를 저지연 인터커넥트로 묶어 문제의 성격에 따라 최적의 연산 엔진에 분배·협업시키는 차세대 이종 융합 컴퓨팅 패러다임

## 핵심 용어

- QPU(Quantum Processing Unit): 양자역학적 얽힘과 중첩 현상을 이용하여 특정 연산(소인수분해, 분자 구조 해석 등)을 지수적으로 가속하는 양자 연산 코어
- VQE(Variational Quantum Eigensolver): 양자 상태 준비 및 기댓값 계산은 QPU가 수행하고, 파라미터 최적화는 고전 CPU가 반복 수행하는 대표적 양자-고전 하이브리드 알고리즘
- CUDA-Q(구 CUDA Quantum): 엔비디아가 주도하는 양자-고전 하이브리드 아키텍처용 오픈소스 통합 프로그래밍 플랫폼으로, 단일 소스 코드에서 CPU, GPU, QPU를 제어

### Ⅱ. 핵심 특성

- 완벽한 양자 컴퓨터가 등장하기 전까지 모든 실용적 양자는 '하이브리드'임 → 현재의 잡음이 많은 NISQ(잡음 중간규모 양자) 장치는 단독으로 I/O나 범용 OS를 구동할 수 없으므로, 고전 슈퍼컴퓨터가 주변 제어와 노이즈 필터링을 도맡는 하이브리드 구조가 유일한 상용화 해법임
- 성능의 진짜 한계는 연산 장치 자체가 아니라 '인터커넥트 왕복 지연시간'임 → CPU와 QPU/NPU 간에 데이터를 주고받는 I/O 지연이 연산 단축 시간보다 길어지면 암달의 법칙(Amdahl's Law)에 의해 시스템 전체 처리 효율이 급격히 저하됨
- 소프트웨어 툴체인의 통합이 하이브리드 컴퓨팅의 진입 장벽임 → 개발자가 C++, 파이썬, 양자 회로 어셈블리를 각각 따로 작성하는 방식은 유지보수가 불가능하므로, LLVM/MLIR 기반으로 다양한 가속기를 단일 프레임워크(CUDA-Q, OpenVINO)로 추상화해야 함

### Ⅲ. 관련 개념과 구분

- 이종 가속(Heterogeneous Computing) vs 하이브리드 컴퓨팅(Hybrid Computing): 이종 가속 = CPU+GPU처럼 폰 노이만 아키텍처 범주 내에서의 산술 가속기 오프로딩 / 하이브리드 컴퓨팅 = 고전 디지털 컴퓨터와 양자(비폰노이만) 또는 아날로그 신경망 연산 패러다임을 결합한 융합 시스템
