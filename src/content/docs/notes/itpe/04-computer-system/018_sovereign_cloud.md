## 지식 로드맵 내 현재 위치

지식 위치: 컴퓨터 시스템 → 클라우드 운영·통제 → **소버린 클라우드**

## 30초 인출

- 본질: **소버린 클라우드** 는 데이터·운영·기술에 대한 통제권을 요구 수준에 맞춰 확보한 클라우드 운영 방식이다.
- 메커니즘: 적용 법률, 데이터 위치·접근권한, 운영 주체, 암호화 키와 공급망을 나눠 확인하고 계약·기술 통제로 뒷받침한다.

<details>
<summary>핵심 용어</summary>

- **데이터 레지던시** : 데이터가 저장·처리되는 지리적 위치에 관한 요구
- **관할권** : 데이터·서비스·공급자에게 어떤 법률과 정부 권한이 적용되는지에 관한 문제
- **운영 통제권** : 누가 시스템에 접근하고 장애 대응·변경을 수행할 수 있는지 결정하는 권한
- **고객 관리 키** : 고객이 암호화 키의 생성·보관·사용 정책을 관리하는 방식. 공급자의 실제 접근 가능 범위는 구현과 계약으로 확인해야 한다.
- **CSAP** : 국내 공공부문에 공급하는 클라우드 서비스의 보안인증 제도. 소버린 클라우드 전체 요건과 같은 뜻은 아니다.

</details>

## 1교시 10점 답안

### 1. 정의·목적

- 정의: **소버린 클라우드** 는 법적·운영상·기술적 통제권을 특정 관할과 이용자의 요구에 맞춰 확보한 클라우드 방식이다.
- 목적: 중요한 데이터와 서비스의 통제권 및 운영 연속성을 확보한다.

### 2. 확인할 통제 범위

| 범위 | 핵심 질문 |
|---|---|
| 법률·데이터 | 어디에 저장·처리되며 어떤 법률이 적용되는가 |
| 운영 | 누가 접근·변경·장애 대응을 수행하는가 |
| 기술 | 누가 키와 핵심 구성요소를 통제하는가 |

### 3. 레지던시와 주권의 차이

| 데이터 위치만 확인 | 소버린 요구까지 확인 |
|---|---|
| 저장 장소 확인 | 위치와 함께 원격 접근·운영 주체·키 통제·법적 관할 확인 |

제언: 민감도와 적용 규정에 맞춰 필요한 통제 수준을 정하고, 공급자의 실제 접근 경로를 검증한다.

## 2~4교시 25점 답안

## Ⅰ. 소버린 클라우드의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 법적·운영상·기술적 통제권을 특정 관할과 이용자의 요구에 맞춰 확보한 클라우드 방식 |
| 목적 | 중요한 데이터와 서비스의 통제권·운영 연속성 확보 |

## Ⅱ. 주권 요구를 판단하는 범위

| 평가 범위 | 확인할 대상 |
|---|---|
| 법적 관할 | 공급자·서비스·데이터에 적용될 법률과 접근 요청 처리 절차 |
| 데이터 | 저장·처리·백업 위치와 이전 경로 |
| 운영 | 관리자 원격 접근, 장애 대응, 하도급 운영 주체 |
| 기술 | 키 통제, 구성요소의 교체·이전 가능성, 공급망 의존성 |

이 범위는 도입 판단을 위한 평가축이다. 모든 나라·모든 서비스에 동일한 국내 저장·자국민 운영·특정 키 제품이 의무라는 뜻은 아니다.

## Ⅲ. 인접 개념과의 차이

| 개념 | 중심 질문 | 주권 판단에 남는 것 |
|---|---|---|
| 데이터 레지던시 | 어디에 데이터가 있는가 | 법적 관할·원격 접근·운영 주체 |
| 프라이빗 클라우드 | 누가 자원을 전용으로 쓰는가 | 공급망·키·관할 통제 |
| 소버린 클라우드 | 필요한 통제권이 확보되는가 | 요구 수준별 증거와 지속 운영 |

## Ⅳ. 도입 시 검증과 운영

| 확인 시점 | 검증할 증거 |
|---|---|
| 계약·설계 | 데이터 위치, 운영 주체, 접근 권한, 하도급 조건 |
| 운영 | 관리자 접속 기록, 키 사용 이력, 변경·장애 처리 기록 |
| 전환·종료 | 데이터 반출·삭제와 대체 환경으로 이전할 수 있는지 |

CSAP 등 보안인증은 적용 대상과 인증 범위를 확인해 활용한다. 인증 하나로 모든 주권 요구를 충족했다고 단정하지 않는다.

## Ⅴ. 통제권 확보를 위한 제언

| 문제 | 해결 방안 |
|---|---|
| 국내 저장만 확인하고 원격 관리자 접근을 놓침 | 실제 관리자 권한·접속 경로와 사고 시 접근 절차를 계약·로그로 검증 |
| 특정 공급자에 의존해 운영 이전이 어려움 | 데이터 반출·삭제와 핵심 구성의 이전 절차를 사전에 시험 |
