## 연관 키워드

- DID(Digital Information Display), 디지털 사이니지(Digital Signage), CMS(Content Management System)
- 미디어 플레이어(Media Player), 로컬 캐싱(Local Caching), 번인(Burn-in), 픽셀 시프트(Pixel Shift)
- 위변조(Defacement), mTLS(Mutual TLS), LCD(Liquid Crystal Display), OLED(Organic Light-Emitting Diode), MicroLED

## Ⅰ. DID의 개요

- 핵심 요약 : 중앙 관리 시스템이 콘텐츠와 편성을 네트워크로 배포하고 현장 디스플레이가 자동 재생하는 디지털 사이니지 체계.
- 개념 : 상업 시설·교통 시설·공공장소의 대형 화면에 광고와 안내, 실시간 정보를 표출하고 네트워크로 원격 관리하는 체계를 **디지털 사이니지** (Digital Signage)라 하며, 그 표출 장치를 **디지털 정보 디스플레이** (DID, Digital Information Display)로 부름.
- 배경 및 필요성 : 인쇄 포스터는 제작과 교체에 비용과 시간이 들어 시의성 있는 갱신이 곤란함. 네트워크 배포로 내용 변경 비용을 낮추는 전자 매체로의 전환이 필요함.
- 주요 목적 : 원격 일괄 운영에 따른 관리 비용 절감, 상황에 맞는 정보의 즉시 표출, 센서·데이터 연동형 서비스 확장.

## Ⅱ. DID의 특징 및 장점

- 핵심 요약 : 원격 편성, 로컬 캐싱, 양방향 연동이 운영 자동화와 재생 안정성이라는 장점으로 연결되는 구조.

1. 원격 편성 : 중앙 **콘텐츠 관리 시스템** (CMS, Content Management System)에서 시간대·장소별 재생 목록을 지정해 배포 → 현장 출장 없이 콘텐츠 갱신이 가능한 운영 효율.
2. **로컬 캐싱** (Local Caching, 콘텐츠를 현장 장치의 저장장치에 미리 내려받아 두는 방식) : 편성표와 미디어를 미디어 플레이어에 선적재 → 네트워크 단절 상황에서도 재생이 유지되는 가용성 확보.
3. 양방향 연동 : 카메라·터치·센서 입력에 따라 표출 내용을 전환 → 주목도 제고와 맞춤형 안내 효과.
4. 표출 품질 관리 : 밝기·색온도 보정과 원격 진단 → 다수 지점 설비의 균일한 화질 유지.

## Ⅲ. DID의 구조 (흐름)

- 핵심 요약 : 관리 계층, 전송 계층, 표출 계층의 3계층 구조이며 배포는 중앙에서 현장으로 향하고 재생은 현장에서 이루어짐.
- 구성요소는 중앙 CMS, 현장 미디어 플레이어, 디스플레이 패널임.
- 배치 원칙 : 관리망과 재생 경로를 분리해 두고, 플레이어가 편성 시각에 자율적으로 재생하는 구조를 취함.

```text
[ DID 3계층 구조 ]

콘텐츠 관리 서버 (편성·모니터링)
      ↓ 보안 관리망
미디어 플레이어 (저장·디코딩·재생)
      ↓ 영상 신호
디스플레이 패널 (표출)
```

```text
[ 콘텐츠 배포와 재생 절차 ]

서버가 편성표와 파일을 배포
      ↓
플레이어 저장장치에 선적재
      ↓
편성 시각에 자동 재생
      ↓
재생 로그를 서버로 보고
```

## Ⅳ. DID 패널 기술의 비교

- 핵심 요약 : 발광 방식에 따라 휘도, 명암비, 번인 위험, 확장성이 갈려 설치 환경별 선택 기준이 달라짐.
- 비교 대상은 **LCD** (Liquid Crystal Display), **OLED** (Organic Light-Emitting Diode), **MicroLED** (Micro Light-Emitting Diode)이며, **번인** (Burn-in, 동일 화면의 장시간 표출로 특정 픽셀만 열화되는 현상) 위험을 함께 봄.

| 비교 축 | LCD | OLED | MicroLED |
| :--- | :--- | :--- | :--- |
| 발광 방식 | 백라이트가 액정을 통과해 표현 | 유기물 픽셀의 자발광 | 무기물 초소형 LED의 자발광 |
| 명암비 | 백라이트 누출로 한계 | 픽셀 소등으로 뛰어남 | 자발광으로 뛰어남 |
| 휘도 | 고휘도 구현에 유리 | 실내 수준이 적정 | 고휘도 구현에 유리 |
| 번인 위험 | 낮음 | 고정 화면 장시간 표출 시 존재 | 무기물 소자로 상대적으로 낮음 |
| 확장성 | 베젤 경계가 존재 | 곡면·투명 구현에 유리 | 타일 조립으로 무베젤 대형화 |
| 비용 | 양산 성숙으로 낮음 | 중간 | 양산 공정 과제로 높음 |

- 선택 기준 : 야외·직사광 환경은 LCD와 MicroLED, 실내 고명암 연출은 OLED, 대형 무경계 설치는 MicroLED 타일 방식을 기준으로 삼음.

## Ⅴ. DID의 한계와 방안

- 핵심 요약 : 번인, 위변조, 옥외 발열의 세 리스크를 표출 제어, 보안 설계, 열 설계로 일대일 대응함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 고정 화면 장시간 표출에 따른 번인 | 안내 문구 같은 고정 UI가 해당 픽셀만 열화시켜 잔상 발생 | **픽셀 시프트** (Pixel Shift, 화면을 미세하게 이동시켜 열화를 분산하는 기법) 적용, 업무 외 시간 절전 전환 | 잔상 발생 건수 |
| 콘텐츠 **위변조** (Defacement, 무단 접속으로 표출 내용을 바꾸는 공격) | 노출 단말의 물리 포트와 관리 프로토콜이 공격 표적이 됨 | 포트 잠금, 실행 파일 화이트리스트, **mTLS** (Mutual TLS, 클라이언트와 서버가 서로 인증서를 검증하는 방식) 기반 제어 채널과 서명 검증 | 무단 접속 탐지 건수 |
| 옥외 직사광과 고온에 따른 열화 | 패널 온도 상승으로 화질 저하와 장치 중단 발생 | 고온 동작 등급 패널 채택, 방열 설계와 외기 격리 인클로저 적용 | 패널 내부 온도, 장애 건수 |

## Ⅵ. DID에 대한 기술사적 제언

- 핵심 요약 : 공공 정보 연계, 전력·수명 주기 설계, 보안 책임의 계약화를 묶은 운영 체계 확립 방향.
- 공공기관은 재난·교통 정보 시스템과 DID 편성을 연동해 중앙 서버 장애 시에도 안내 기능이 유지되는 우선 표출 체계를 두어야 함.
- 운영 조직은 상시 점등 특성을 반영해 전력 사용량과 패널 교체 주기를 하나의 계획으로 관리하는 에너지 기준을 수립해야 함.
- 발주 기관은 장비 보안 패치와 인증서 갱신을 조달 계약 조건에 명시해 설치 이후에도 보안 책임이 이어지는 거버넌스를 만들어야 함.

## Ⅶ. 결론

- 핵심 요약 : DID는 중앙 관리와 현장 자율 재생을 결합한 원격 제어형 디지털 사이니지 체계.
- 표출·보안·열 설계를 설치 단계에서 함께 확정해야 공공 현장의 안정 운영이 가능함.
