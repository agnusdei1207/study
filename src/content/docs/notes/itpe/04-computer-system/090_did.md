## 연관 키워드

- DID(Digital Information Display), 디지털 사이니지(Digital Signage), CMS(Content Management System)
- 엣지 미디어 플레이어, 로컬 캐싱(Local Caching), 번인(Burn-in), 위변조(Defacement)
- 픽셀 시프트(Pixel Shift), mTLS(Mutual TLS), LCD, OLED, MicroLED

## Ⅰ. DID의 개요

- 핵심 요약 : 중앙 CMS가 콘텐츠와 편성을 원격 배포하고 현장 플레이어가 재생하는 디지털 사이니지 체계.
- 개념 : 공공장소, 상업 시설, 교통 시설 등에서 광고·안내·실시간 정보를 디스플레이 패널에 표출하고, 네트워크를 통해 원격으로 관리하는 **디지털 사이니지** (Digital Signage) 체계. 이를 구현한 형태를 **디지털 정보 디스플레이** (DID, Digital Information Display)라 부름.
- 배경 및 필요성 : 인쇄 포스터는 제작과 교체에 비용과 시간이 들어 내용을 시의성 있게 바꾸기 어려움. 이 비용 구조를 줄이려면 콘텐츠를 네트워크로 배포하고 현장에서 즉시 재생하는 방식이 필요해짐.
- 주요 목적 : 시각적 주목도 확보, **콘텐츠 관리 시스템** (CMS, Content Management System)을 통한 원격 배포·운영 자동화, 센서 연동을 통한 참여형 서비스 구현.

## Ⅱ. DID의 특징 및 장점

- 핵심 요약 : CMS 원격 제어와 로컬 캐싱이 결합되어 네트워크가 끊겨도 재생이 멈추지 않는 운영 안정성 확보.

1. 원격 편성 : CMS에서 시간대·위치·대상 조건별 재생 편성을 변경 → 현장 방문 없이 콘텐츠 갱신 가능.
2. **로컬 캐싱** (Local Caching) : 배포 스케줄과 미디어 파일을 플레이어 저장장치에 미리 내려받아 재생 → 네트워크 단절 시에도 화면이 비지 않음.
3. 인터랙티브 센싱 : 카메라와 인공지능(AI, Artificial Intelligence) 비전 모델을 연동해 관람자 속성에 맞춘 콘텐츠로 전환 → 참여형 광고와 맞춤 안내 효과.

## Ⅲ. DID의 구조 및 동작 메커니즘

- 핵심 요약 : 중앙 CMS에서 플레이어로 배포하고, 플레이어가 로컬에서 재생해 패널에 전달하는 3계층 구조.
- 구성 요소는 중앙 CMS, 엣지 미디어 플레이어, 디스플레이 패널이며, 배포는 중앙에서 말단으로 흐르고 재생은 현장에서 이루어짐.

```text
[ DID 3계층 배포 흐름 ]

중앙 CMS (콘텐츠·편성 관리)
      ↓ 보안 IP 네트워크
엣지 미디어 플레이어 (로컬 저장·디코딩)
      ↓ HDMI 영상 케이블
디스플레이 패널 (표출)
```

```text
[ 로컬 캐싱 재생 흐름 ]

CMS가 편성과 파일을 배포
      ↓
플레이어 저장장치에 보관
      ↓
네트워크 단절과 무관하게 루프 재생
```

## Ⅳ. DID 디스플레이 기술의 비교

- 핵심 요약 : 발광 방식과 번인·명암비·확장성 차이에 따라 야외 밝기 요구, 실내 전시, 무베젤 설치 등 용도가 나뉨.
- 비교 대상은 **LCD** (Liquid Crystal Display), **OLED** (Organic Light-Emitting Diode), **MicroLED** (Micro Light-Emitting Diode)이며, **번인** (Burn-in) 위험을 함께 본다.

| 비교 축 | LCD | OLED | MicroLED |
| :--- | :--- | :--- | :--- |
| 발광 방식 | 백라이트 유닛으로 뒤에서 비춤 | 유기물 픽셀이 스스로 발광 | 무기물 초소형 LED가 스스로 발광 |
| 명암비 | 백라이트 빛샘으로 완전한 검정 표현에 한계 | 픽셀을 끄면 검정 표현이 뛰어남 | 자발광으로 검정 표현이 뛰어남 |
| 밝기 | 야외 표출에 유리한 고휘도 구현 가능 | 실내 전시 용도에 적합 | 고휘도 구현에 유리 |
| 번인 위험 | 상대적으로 낮음 | 고정 UI를 오래 띄우면 발생 가능 | 무기물 소자라 상대적으로 낮음 |
| 베젤·확장성 | 베젤 경계가 존재 | 곡면·투명 구현에 유리 | 타일 조립으로 베젤 최소화 |
| 제조 비용 | 대량 생산 성숙도가 높아 낮음 | 중간 이상 | 양산 공정 과제로 높음 |

## Ⅴ. DID의 한계와 방안

- 핵심 요약 : 번인, 위변조, 옥외 발열을 픽셀 이동·화이트리스트 실행 제어·고온 내성 설계로 대응.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| **픽셀 시프트** (Pixel Shift) 미적용 시 번인 | 메뉴·안내 등 고정 UI의 장시간 표출 → 픽셀 열화로 잔상 발생 | 육안으로 구분하기 어려운 미세 이동 적용, 업무 외 시간 절전 모드 | 잔상 발생 건수 |
| 위변조 (Defacement) | 노출된 단말의 USB 포트나 취약한 네트워크 프로토콜을 통한 무단 송출 | 물리 포트 잠금, 화이트리스트 기반 실행 제어, **상호 TLS 인증** (mTLS, Mutual TLS)과 무결성 서명 검증 | 무단 접속·변조 탐지 건수 |
| 옥외 직사광선에 의한 발열·열화 | 고온 환경에서 패널 온도 상승 → 화면 열화와 시스템 중단 | 고온 내성 패널 채택, 밀폐형 쿨링과 공조 인클로저 설계 | 패널 내부 온도, 장애 건수 |

## Ⅵ. DID 적용에 대한 기술사적 제언

- 핵심 요약 : 공공 정보 연계와 저전력 설계, 장비 수명 주기 보안을 함께 묶은 운영 체계 확립.
- 재난·교통 정보를 플레이어 단에서 우선 전환하도록 설계하면, 중앙 시스템에 장애가 나도 안내 기능을 유지할 수 있음.
- 상시 점등 환경의 전력 부담을 줄이기 위해 정적 정보 영역에는 저전력 반사형 디스플레이를 혼용하는 방안을 검토할 가치가 있음.
- 단말 보안 패치와 인증 관리를 설치 계약 조건에 포함해, 설치 이후에도 보안 책임이 이어지는 거버넌스를 세울 필요가 있음.

## Ⅶ. 결론

- 핵심 요약 : DID는 중앙 CMS와 엣지 재생을 결합한 원격 제어형 디지털 사이니지 체계.
- 번인·위변조·발열 리스크를 설계 단계부터 통제해야 공공 현장에서 안정적으로 운영됨.
