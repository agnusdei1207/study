<details>
<summary>핵심 용어</summary>

- **퍼듀 참조 모델(Purdue Reference Model)** : 산업 제어·운영·기업 기능을 계층화해 설명하는 참조 구조
- **OT (Operational Technology)** : 물리 공정·설비를 감시하거나 제어하는 운영 기술
- **ICS (Industrial Control System)** : 산업 공정 제어·감시에 사용하는 시스템의 총칭
- **IDMZ (Industrial Demilitarized Zone)** : OT와 기업망 사이의 통신을 중개·통제하도록 구성하는 산업 보안 구역
- **ISA-95** : 기업 기능과 제조 운영 관리의 통합을 다루는 표준 계열

</details>

## 2~4교시 25점 답안

### Ⅰ. 퍼듀 참조 모델의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **퍼듀 참조 모델은** 산업 운영과 기업 정보 기능을 계층으로 구분해 설명하는 구조 |
| 목적 | 기능·통신 경계를 파악하고 산업망의 분할·보안 설계를 지원 |

### Ⅱ. 퍼듀 모델의 특징

| 특징 | 의미 |
|---|---|
| 기능별 수직 계층 | 물리 공정부터 운영·기업 계획까지 역할을 구분 |
| IT·OT 상호 의존 | 생산 데이터는 상향, 승인된 제어·운영 정보는 하향 이동 |
| 경계 중심 통제 | 산업 DMZ 등에서 계층 사이의 통신을 중개·기록 |

### Ⅲ. 계층 체계·통신 프로세스

**핵심 계층 프레임**

```text
L4·L5 기업 계획·외부 연계
           ↕ 허용된 업무 데이터
산업 DMZ(관행상 L3.5): 중개·검사·기록
           ↕ 제한된 OT 연계
L3 제조 운영 관리 → L2 감시·제어
           ↕
L1 현장 계측·조작 → L0 물리 공정
```

**하위 메커니즘: IT에서 OT로의 승인된 접근**

```text
접근 요청 → 사용자·작업 승인 → IDMZ 점프/중계 지점
          → 목적지·프로토콜 허용목록 검사 → 지정 OT 구역
          → 세션 기록·만료 → 접근권 회수
```

### Ⅳ. 기능 계층과 보안 구역의 관계

| 구분 | 기능 계층 | 보안 구역·통신 경계 |
|---|---|---|
| 구분 기준 | 제조·운영 기능의 위치 | 자산 중요도·위협·허용 통신 |
| IT·OT 접점 | 기업 기능과 운영 기능 사이 | IDMZ와 통제된 중계 경로 |
| 설계 검증 | 계층별 자산·업무 배치 | 실제 통신·원격 접근·우회 경로 검사 |

### Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 기능 계층만으로 실제 보안 경계를 확정할 수 없음 | 자산·통신 흐름을 조사해 구역과 경계를 별도 정의 |
| 무조건 차단하면 생산·업무 연계가 중단 | 목적·방향·프로토콜별 필수 흐름을 허용목록으로 관리 |
| 평면망·원격 접근이 계층을 우회 | 원격 세션을 IDMZ로 집중시키고 우회 경로를 점검 |

### Ⅵ. 제언

퍼듀 계층은 기능을 설명하지만 실제 접근 경로의 안전성을 보장하지 않는다. **자산과 필수 통신을 먼저 실측해 구역을 정하고**, IT·OT 교환과 원격 작업은 IDMZ의 승인·기록 경로를 통과시키는 설계를 우선해야 한다.

## 출제 이력과 검증 출처

- [ISA-95 Standard](https://www.isa.org/standards-and-publications/isa-standards/isa-95-standard): 기업·제조 기능 계층
- [NIST SP 800-82 Rev.3](https://csrc.nist.gov/pubs/sp/800/82/r3/final): OT 보안·네트워크 분할
