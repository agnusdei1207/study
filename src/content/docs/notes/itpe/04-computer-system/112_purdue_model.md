## 연관 키워드

- 퍼듀 모델(Purdue Model), 산업제어시스템(ICS, Industrial Control System), 운영기술(OT, Operational Technology)
- SCADA(Supervisory Control And Data Acquisition), 산업용 DMZ(IDMZ), 신뢰 경계(Zone & Conduit)
- IEC 62443, ISA-95, 데이터 다이오드(Data Diode), 제로 트러스트(Zero Trust)
- PLC(Programmable Logic Controller), HMI(Human-Machine Interface), MES(Manufacturing Execution System), OT 침입 탐지

## Ⅰ. 퍼듀 모델의 개요

- 핵심 요약 : 현장 물리 공정부터 기업 비즈니스망까지 여섯 계층으로 나누고 계층 사이 통신 경계를 정의한 산업 제어 참조 모델.
- 개념 : 공장 자동화, 발전, 정유 등 **산업제어시스템** (ICS, Industrial Control System) 환경을 Level 0부터 Level 5까지 구조화하고 계층 간 신뢰 경계를 정의하는 **퍼듀 모델** (Purdue Model)로, ISA-95의 기업·제조 통합 체계를 기반으로 함.
- 배경 및 필요성 : 폐쇄망으로 운영되던 제어 설비가 스마트 팩토리, 산업용 사물인터넷(IIoT, Industrial Internet of Things), 클라우드 분석과 연결되며 외부 위협에 노출되어 계층적 방어 기준이 필요.
- 주요 목적 : 제어망(OT, Operational Technology)과 업무망(IT, Information Technology) 사이 경계 수립, 산업용 DMZ를 통한 위험 격리, 실시간 제어의 무결성과 공정 가용성 보장.

## Ⅱ. 퍼듀 모델의 특징 및 장점

- 핵심 요약 : 기능별 계층 분리와 정의된 통로만 허용하는 경계 통제가 침해 전파를 계층 단위로 막아 공정 가용성을 지키는 원리.

1. 계층 분리 : 기능과 실시간성 기준으로 여섯 계층 구분 → 장애·침해의 전파를 계층 내로 한정하는 효과.
2. 구역과 통로 : IEC 62443의 Zone & Conduit 원칙으로 구역 사이 통신을 정의된 경로로만 허용 → 제어망 내부 측면 이동 억제 효과.
3. 중계 완충 : IT와 OT 사이 Level 3.5 산업용 DMZ에서 직접 통신 차단 → 외부 위협이 제어 구역에 닿기 전에 걸러지는 효과.
4. 프로토콜별 통제 : 계층마다 사용 프로토콜이 달라 통제 방식을 계층에 맞출 수 있음 → 실시간 제어를 방해하지 않는 보안 운영 효과.

## Ⅲ. 퍼듀 모델의 구조 (흐름)

- 핵심 요약 : 상위 IT 계층과 하위 제어 계층 사이에 산업용 DMZ를 두고 하위로 갈수록 실시간성이 강한 장비와 프로토콜이 배치되는 구조.

```text
[ 퍼듀 모델 계층 구조 ]

Level 5 : 기업 비즈니스 네트워크
   ↓
Level 4 : 사업 운영·업무망 (IT)
   ↓
Level 3.5 : 산업용 DMZ (IDMZ)
   ↓
Level 3 : 제조 운영 관리
   ↓
Level 2 : 감독 제어 (SCADA, HMI)
   ↓
Level 1 : 기본 제어 (PLC)
   ↓
Level 0 : 물리 공정 (센서, 밸브)
```

```text
[ 신뢰 경계의 통신 원칙 ]

상위 구역의 하위 접근 요청
   ↓
정의된 통로(Conduit)로만 허용
   ↓
IDMZ에서 세션 종단과 검사
   ↓
제어 구역 직접 경로는 차단
```

- **SCADA** (Supervisory Control And Data Acquisition) : 하위 계층의 제어기를 감시·지시하는 상위 감독 제어 시스템.
- **PLC** (Programmable Logic Controller) : Level 1에서 센서 입력에 따라 제어 명령을 실시간 실행하는 산업용 컨트롤러.
- **HMI** (Human-Machine Interface) : 운전원이 공정 상태를 보고 조작하는 현장 감시 화면 장치.
- **MES** (Manufacturing Execution System) : Level 3에서 생산 계획과 현장 실행을 연결하는 제조 실행 시스템.
- 산업용 DMZ(IDMZ)는 점프 호스트와 이중화 데이터 수집 서버 같은 중계 자원만 두어 IT망 세션이 제어망으로 직행하지 못하게 하는 완충 계층이 됨.

## Ⅳ. 퍼듀 모델과 제로 트러스트의 비교

- 핵심 요약 : 퍼듀 모델이 위치 기반 경계로 위험을 격리하는 반면 제로 트러스트는 접근마다 검증하는 방식이라 융합 환경에서 상호 보완 관계가 됨.

| 비교 축 | 퍼듀 모델 | 제로 트러스트 |
| :--- | :--- | :--- |
| 보안 가정 | 내부망은 구분된 신뢰 영역 | 내부·외부 구분 없는 검증 대상 |
| 신뢰 판정 기준 | 소속 계층과 경계 위치 | 주체·기기·세션의 상시 검증 |
| 접근 제어 단위 | 계층·구역 경계 | 개별 세션·자원 |
| 강점 | 실시간 제어 보호와 안정성 | 클라우드·원격 접속 환경 대응 |
| 한계 | 경계 우회 트래픽에 취약 | 제어 장비의 검증 부담 증가 |

- 선택 기준 :
  1. 실시간 제어 구역 보호는 퍼듀 기반 계층 분리를 기본으로 함.
  2. 클라우드 직결·원격 유지보수 구간은 제로 트러스트 요소를 보강.
  3. 두 모델은 대체가 아니라 구간별 조합이 표준적 접근이 됨.

## Ⅴ. 퍼듀 모델의 한계와 방안

- 핵심 요약 : 클라우드 직결 우회, 평문 산업 프로토콜, 원격 유지보수 접속을 세그멘테이션, 보안 프로토콜 전환, 중계 접속 통제로 일대일 완화.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| :--- | :--- | :--- | :--- |
| 클라우드 직결 우회 | Level 0~1 기기가 무선망으로 클라우드에 직접 연결 → IDMZ 방어선 무력화 | 엣지 게이트웨이 경유 강제와 마이크로 세그멘테이션 | 제어 구역의 외부 직접 세션 수 |
| 평문 프로토콜 취약 | Modbus 등 인증·암호화 부재 → 도청과 명령 위변조 노출 | OPC UA Security 등 보안 지원 프로토콜로 단계 전환 | 평문 프로토콜 잔존 비율 |
| 원격 유지보수 노출 | 협력사 비인가 원격 도구 → 랜섬웨어의 제어망 침투 경로 | IDMZ 점프 호스트 경유 의무화, MFA(Multi-Factor Authentication), 세션 녹화 | 원격 접속 감사 건수 |

## Ⅵ. 퍼듀 모델에 대한 기술사적 제언

- 핵심 요약 : 제어 데이터는 단방향으로만 내보내고 제어망 감시는 가용성을 해치지 않는 방식으로 운영하는 방향.
- 보안 설계 : 제어 시스템 운영 조직이 역방향 경로가 물리적으로 없는 데이터 다이오드(Data Diode)를 상위망 전송 구간에 배치하는 기준을 수립.
- 감시 운영 : OT 보안 운영 조직이 트래픽 미러링 방식의 OT 침입 탐지를 두어 실시간 제어 주기에 간섭하지 않게 운영.
- 거버넌스 : OT 보안 조직이 IEC 62443 기준의 구역·통로 정책과 자산 식별 대장을 수립·갱신.

## Ⅶ. 결론

- 핵심 요약 : 퍼듀 모델은 계층과 산업용 DMZ로 IT와 OT의 경계를 세우는 참조 모델이며 융합 환경에서는 제로 트러스트와 단방향 통제로 보강이 필요.
- 시사점 : 제어 환경의 보안 통제는 공정 가용성 영향을 먼저 검증한 뒤 적용하는 순서가 원칙이 됨.
