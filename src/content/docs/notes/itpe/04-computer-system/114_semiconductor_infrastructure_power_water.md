## 지식 로드맵 내 현재 위치

컴퓨터 시스템 및 네트워크 → 반도체 생산시스템 → 전력·용수 기반시설

## 30초 인출

- 본질: 반도체 특화 기반시설은 팹 생산에 필요한 안정적 전력·용수·환경 제어를 제공하는 유틸리티
- 메커니즘: 전력은 수전·배전·비상 경로로, 용수는 원수·정수·초순수·회수 경로로 품질을 유지
- 통찰: 한계: 유틸리티별 설비 이중화만으로 공정 중단을 막기 어려움 → 방안: 공정별 필수 전력·수질을 기준으로 연쇄 장애를 함께 시험한다.

<details>
<summary>핵심 용어</summary>

- **초순수(UPW, Ultrapure Water)** : 반도체 제조 공정에 사용하는 불순물 농도가 낮은 정제수
- **유틸리티(Utility)** : 생산설비 가동에 필요한 전력·용수·가스·공조 등 기반 자원
- **UPS (Uninterruptible Power Supply)** : 입력 전원이 끊길 때 중요 부하에 전력을 공급하도록 구성한 무정전 전원장치
- **재이용수(Reclaimed Water)** : 처리한 폐수·방류수를 용도 기준에 따라 다시 사용하는 물

</details>

## 2~4교시 25점 답안

### Ⅰ. 반도체 기반시설의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **반도체 생산 기반시설은** 팹 생산에 필요한 안정적 전력·용수·환경 제어를 제공하는 유틸리티 |
| 목적 | 공정의 연속성·품질·안전한 운영 지원 |

### Ⅱ. 반도체 기반시설의 특징

| 특징 | 공정 영향 |
|---|---|
| 품질 민감성 | 전압 외란·용수 불순물이 장비와 수율에 영향 |
| 연속 공급 | 짧은 유틸리티 중단도 공정 재가동·폐기에 영향 |
| 상호 의존 | 정수·공조·펌프에도 전력이 필요해 장애가 전파 |

### Ⅲ. 전력·용수 공급 체계·프로세스

**핵심 공급 프레임**

```text
계통 → 수전·변전 → 배전 → 중요/일반 공정 부하
                ↗ UPS·비상전원, 전력 품질 감시
원수 → 정수 → 초순수(UPW) → 공정 사용
                               ↓
                  폐수 분류·처리 → 방류/재이용
           수량·수질 감시 ────────┘
```

**하위 메커니즘: 전력 외란의 공정 대응**

```text
전압·주파수 이상 감지 → 중요 부하 UPS 유지
                 → 비상전원 전환·부하 우선순위 적용
                 → 공정 상태 확인 → 정상 계통 복귀·품질 재검증
```

**하위 메커니즘: 초순수 품질 이상 대응**

```text
원수·UPW 수질 감시 → 기준 이탈 감지 → 공급 격리·우회
                 → 정제 설비 조정 → 수질 적합 확인 후 공정 재공급
```

### Ⅳ. 전력·용수 위험 비교

| 영역 | 주요 변동 | 공정 보호 기준 |
|---|---|---|
| 전력 | 순간 정전·전압 외란·배전 고장 | 부하 중요도·허용 중단 시간 |
| 용수 | 수량 부족·수질 이탈·처리 고장 | 공정별 필요 유량·수질 |
| 공통 | 외부 공급과 내부 설비의 연쇄 장애 | 장애 전파 경로·복구 우선순위 |

### Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 계통 외란·배전 고장이 중요 공정에 전파 | 중요도별 UPS·비상전원 적용과 전환 시험 |
| 원수 수량·수질 변동으로 UPW 공급 불안 | 수원·저장·정제 여유를 확보하고 수질 감시 |
| 유틸리티 간 종속으로 단일 고장이 확대 | 전력·펌프·공조·용수의 연쇄 장애 시나리오 시험 |

### Ⅵ. 제언

전력과 용수 설비를 각각 이중화해도 전력 중단이 펌프·정제 설비를 멈추면 생산은 지속되지 않는다. **공정별 필수 부하와 필수 수질을 먼저 정의**하고 교차 장애·전환·복귀를 묶어 통합 시험해야 한다.
