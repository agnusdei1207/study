## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 인공지능 투명성 표시**는 인공지능기본법 제31조에 따라 서비스의 AI 이용 사실과 생성 결과를 이용자에게 알리는 법정 고지·표시 |
| 목적 | 이용자가 인공지능 활용 여부와 생성 결과의 성격을 알고 판단하도록 지원 |

### Ⅱ. 법정 고지·표시 대상

| 대상 | 의무 |
|---|---|
| 고영향 또는 생성형 인공지능 기반 제품·서비스 | 제공 전에 인공지능 기반으로 운용된다는 사실을 이용자에게 고지 |
| 생성형 인공지능 또는 이를 이용한 제품·서비스의 결과물 | 생성형 인공지능으로 생성되었다는 사실을 표시 |
| 실제와 구분하기 어려운 가상 음향·이미지·영상 | 인공지능시스템 생성 사실을 명확히 인식할 수 있게 고지·표시 |

### Ⅲ. 기술사적 제언

제언: 콘텐츠 유형·이용 맥락에 맞는 표시를 적용하고 생성·표시 이력을 함께 관리.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 인공지능 투명성 표시**는 인공지능기본법 제31조에 따라 서비스의 AI 이용 사실과 생성 결과를 이용자에게 알리는 법정 고지·표시 |
| 목적 | 이용자가 인공지능 활용 여부와 생성 결과의 성격을 알고 판단하도록 지원 |

| 현행 법령 | 시행 기준 |
|---|---|
| 인공지능기본법 제31조 | 법률 제21311호, 2026-07-21 시행 |

## Ⅱ. 법정 의무의 구분

| 구분 | 법적 요구 |
|---|---|
| 제품·서비스 사전 고지 | 고영향 또는 생성형 인공지능을 이용한 제품·서비스의 제공 전 인공지능 기반 운용 사실 고지 |
| 결과물 표시 | 생성형 인공지능 결과물임을 이용자가 알 수 있도록 표시 |
| 실제와 구분하기 어려운 합성 매체 | 생성 사실의 명확한 고지·표시; 예술·창작 표현물은 전시·향유를 저해하지 않는 방식 허용 |

## Ⅲ. 대상 판정과 표시 적용

| 판정 질문 | 적용 |
|---|---|
| 고영향·생성형 인공지능 기반 제품·서비스 제공 여부 | 제공 전 AI 기반 운용 사실 고지 |
| 생성형 인공지능 결과물 제공 여부 | 생성형 인공지능 생성 사실 표시 |
| 실제와 구분하기 어려운 가상 음향·이미지·영상 제공 여부 | 생성 사실을 명확히 알리는 고지·표시 |
| 제품명·화면으로 AI 활용이 명백하거나 내부 업무 전용인가 | 시행령상 전부 또는 일부 예외 적용 가능성 검토 |

## Ⅳ. 이용자·기계 인식 방식

| 방식 | 법정 기준·운영상 고려 |
|---|---|
| 사람이 인식하는 표시 | 결과물·화면의 문구, 아이콘, 음성 등으로 생성 사실 전달 |
| 기계가 판독하는 표시 | 생성 사실의 기계 판독 표시와 함께 문구·음성 등으로 1회 이상 안내 |
| 명확한 인식 지원 | 이용자의 시각·청각·소프트웨어 접근성과 연령·사회적 조건 고려 |

법령은 특정 워터마크·메타데이터 표준 하나를 일률 지정하지 않음. 기술 표준은 법정 고지·표시를 보완하는 수단.

## Ⅴ. 표시 기술의 보완 관계

| 방식 | 장점 | 한계 |
|---|---|---|
| 화면·콘텐츠의 가시적 표시 | 이용자가 바로 알아보기 쉬움 | 자르기·재촬영·재편집으로 사라질 수 있음 |
| 기계 판독형 표시·워터마크 | 유통 후 자동 확인에 활용 가능 | 변환·압축·공격으로 훼손될 수 있고 단독으로 법정 이용자 안내를 대체할 수 없음 |
| 출처정보·전자서명 | 생성·수정 이력 검증에 도움 | 메타데이터 제거 시 확인 곤란, 콘텐츠의 사실성을 자동 보증하지 않음 |

## Ⅵ. 운영·검증 절차

```text
생성 기능·콘텐츠 유형 등록
             ↓
법정 고지·표시 대상과 예외 판정
             ↓
화면·결과물 표시와 필요한 출처정보 적용
             ↓
플랫폼별 업로드·변환·재생 시험
             ↓ 표시 누락·이용자 오인 확인
표시 위치·방식 개선
```

## Ⅶ. 적용상 한계와 대응

| 한계 | 대응 |
|---|---|
| 이용자가 표시를 놓치거나 오해 | 결과물 가까이에 명확하고 일관된 표시를 제공하고 사용성 시험 |
| 플랫폼 변환으로 표시·출처정보가 사라짐 | 업로드·변환 단계에서 표시 보존 여부를 시험하고, 가능한 경우 출처정보를 함께 전달 |
| 워터마크 탐지 결과를 진위 보증으로 오인 | 탐지 결과의 신뢰도와 한계를 설명하고 사람의 확인 절차를 둠 |
| 예술·창작 이용을 불필요하게 방해 | 법령상 허용되는 표시 방식과 이용 맥락을 확인해 표현을 해치지 않게 배치 |

## Ⅷ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 서비스 고지, 결과물 표시, 유통 후 검증이 서로 분리되어 이용자에게 정보가 전달되지 않을 수 있음 | 생성 시점에 콘텐츠 유형별 표시 정책을 적용하고, 게시·변환 경로에서 표시의 가독성과 출처정보 보존 여부를 시험해 실패 사례를 개선한다. |
