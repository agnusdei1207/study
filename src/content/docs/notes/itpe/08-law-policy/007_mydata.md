## 지식 로드맵 내 현재 위치

개인정보 보호 → 정보주체 권리 → 개인정보 전송요구권·마이데이터

## 30초 인출

- 본질: 마이데이터는 정보주체가 법적 요건과 절차에 따라 본인 정보를 전송·활용하도록 하는 데이터 이동 체계다.
- 메커니즘: 정보주체가 전송을 요구하고 인증·동의한 범위의 정보를 안전한 전송 방식으로 이동시켜 서비스에 활용한다.

<details><summary>핵심 용어</summary>

- **개인정보 전송요구권**: 개인정보 보호법과 분야별 법령이 정한 요건에 따라 정보주체가 본인 정보를 전송하도록 요구하는 권리.
- **본인신용정보관리업**: 신용정보법에 따른 금융 분야 사업으로, 개인정보 보호법상 전 분야 전송요구권 제도와 구별된다.
- **정보전송자·수신자**: 법령과 분야별 기준에 따라 데이터를 보내거나 받는 기관·사업자.
</details>

> 마이데이터의 개념과 개인정보 전송요구에 따른 주요 처리 흐름을 설명하시오. (예상)

---

## 1교시 10점 답안

### 정의·목적

- 정의: 마이데이터는 정보주체의 권리에 따라 본인 정보를 지정된 수신자에게 전송해 활용하는 체계다.
- 목적: 정보주체의 데이터 통제와 안전한 맞춤형 서비스 이용을 지원한다.

### 전송 흐름

```text
정보주체의 전송요구·인증
          ↓
정보전송자: 대상·범위·수신자 확인
          ↓ 안전한 표준 전송
정보수신자: 목적에 맞는 정보 이용
          ↓
정보주체 권리 행사·전송 철회
```

제언: 전송 항목·목적·수신자와 철회 절차를 이해하기 쉽게 안내한다.

## 2~4교시 25점 답안

### Ⅰ. 법적 기반과 적용 범위

마이데이터는 하나의 단일 법률이나 모든 분야에 동일한 절차를 뜻하지 않는다. 개인정보 보호법상 전송요구권은 2025년 시행되었고 분야·대상 정보·정보전송자 기준은 법률·시행령·고시와 단계별 적용 기준에 따른다. 금융 분야의 본인신용정보관리업은 신용정보법상 별도 체계다.

| 제도 | 주요 근거 | 범위 판단 |
|---|---|---|
| 개인정보 전송요구권 | 개인정보 보호법 제35조의2, 시행령·분야별 고시 | 지정된 정보전송자·대상 정보·요건과 적용 일정을 확인 |
| 금융 마이데이터 | 신용정보법상 본인신용정보관리업 등 | 금융업 인가·업무 범위와 신용정보 전송 절차를 확인 |
| 공공 분야 전송 | 개별 법령·공공 마이데이터 기준 | 기관·정보 종류별 제공 근거와 업무 기준 확인 |

### Ⅱ. 참여자와 정보 이동 구조

```text
정보주체
  │ 전송요구·인증·범위 선택
  ▼
정보전송자
  │ 안전한 표준 API
  ▼
정보수신자
  │ 허용 목적에 맞게 활용
  ▼
정보주체: 열람·철회 등 권리 행사
```

| 참여자 | 역할 |
|---|---|
| 정보주체 | 전송요구, 범위·목적 확인, 권리 행사 |
| 정보전송자 | 대상 정보와 수신자 확인, 안전한 전송, 처리 기록 |
| 정보수신자 | 허용된 목적과 범위에서 이용, 보안·보유·삭제 관리 |
| 중계·지원기관 | 적용되는 제도에 따라 전송 인프라·표준·운영 지원 |

### Ⅲ. 전송요구 처리 절차와 통제

| 순서 | 핵심 처리 | 점검 사항 |
|---|---|---|
| 1 | 수신자·정보항목·목적 선택 | 명확한 안내와 최소 범위 |
| 2 | 본인 확인·요구 검증 | 인증 수단, 위임·대리 요건 |
| 3 | 데이터 전송 | 표준 API, 암호화, 기관·수신자 인증 |
| 4 | 이용·보관 | 목적 제한, 접근통제, 기록과 보유기간 |
| 5 | 철회·종료 | 전송 중단과 이후 보유·삭제 의무 구분 |

### Ⅳ. 주요 보안·운영 고려사항

| 문제 | 대응 |
|---|---|
| 과도한 정보 전송과 동의 피로 | 항목·수신자·목적별 선택을 제공하고 필요한 정보만 요청 |
| 대량 API 호출이 제공기관에 부하를 줌 | 표준 호출량·재시도·증분 전송 정책과 장애 대응 합의 |
| 중계·수신 구간에서 계정·토큰 탈취 | 강한 인증, 최소 권한, 안전한 토큰 수명·보관, 전송기록 점검 |
| 전송 철회와 이미 수신한 데이터 처리 혼동 | 전송 중지와 이용·보유·삭제의 법적 처리 절차를 구분해 안내 |

### Ⅴ. 단계적 확대와 법령 변경 관리

| 항목 | 현재 적용 판단 |
|---|---|
| 전 분야 제도 | 시행령상 정보전송자·대상 정보와 경과·유예 적용 확인 |
| 분야 확대 | 의료·통신·에너지 등 분야별 고시·시행일 확인 |
| 금융·공공 체계 | 개인정보 보호법 제도와 별도로 분야별 법적 근거·역할 확인 |

### Ⅵ. 기술사적 제언

| 문제 | 해결 방안 |
|---|---|
| 분야별 제도·전송 규격이 달라 이용자가 권리와 적용 범위를 이해하기 어려움 | 정보주체 동의·전송요구 화면에서 적용 법률, 대상 항목, 수신자, 이용 목적, 철회·보유 처리를 명확히 보여주고 공통 API·보안 기준은 분야별 법적 요구와 함께 운영한다. |
