## 30초 인출

- 본질: **데이터 3법** 은 데이터 경제 활성화와 정보주체의 권리 보호를 조화시키기 위해 개인정보 보호법·정보통신망법·신용정보법을 일괄 정비한 법률 개정 체계
- 메커니즘: 개인정보 개념을 개인정보·가명정보·익명정보의 3단계로 명확화하고 통계작성·과학적 연구 목적의 가명정보 결합을 허용하며 감독기구를 개인정보보호위원회로 일원화
- 통찰: 이종 도메인 간 결합 시 재식별 위험 및 법제 간 적용 기준 불일치가 발생하므로 공인 결합전문기관 중심의 보안 검증과 통합 마이데이터 전송 표준 API 연계 구축 필수

<details><summary>핵심 용어</summary>

- **데이터 3법** : 개인정보 보호법, 정보통신망 이용촉진 및 정보보호 등에 관한 법률, 신용정보의 이용 및 보호에 관한 법률의 총칭.
- **가명정보 (Pseudonymized Data)** : 추가 정보 없이는 특정 개인을 식별할 수 없도록 가명처리하여 통계, 연구 목적으로 동의 없이 활용 가능한 정보.
- **익명정보 (Anonymized Data)** : 더 이상 개인을 식별할 수 없도록 비식별화하여 개인정보 보호법의 적용을 전혀 받지 않는 정보.
- **결합전문기관** : 데이터 간 안전한 결합을 지원하기 위해 관계 중앙행정기관이 지정한 데이터 전문기관.
- **개인정보보호위원회 (PIPC)** : 데이터 3법 개정을 통해 국무총리 산하 중앙행정기관으로 격상되어 감독 권한을 일원화한 컨트롤타워.

</details>

## 2~4교시 25점 답안

## Ⅰ. 데이터 3법의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터 3법** 은 개인정보의 안전한 보호와 인공지능·빅데이터 신산업 육성을 위해 개인정보 보호법, 정보통신망법, 신용정보법을 유기적으로 개정한 법률 패키지 |
| 목적 | 데이터 활용에 관한 법적 불확실성 해소 및 국가 차원의 데이터 거버넌스 일원화 체계 구축 |

## Ⅱ. 데이터 3법의 핵심 개정 내용 및 법률별 특징

| 법률 구분 | 주요 개정 내용 | 제도적 특징 및 규제 정비 사항 |
|---|---|---|
| **개인정보 보호법 (일반법)** | 개인정보 3단계 개념 정의 | 개인정보·가명정보·익명정보로 체계화, 통계 및 과학적 연구 목적 가명정보 동의 없는 활용 허용 |
| | 결합 체계 법제화 | 정부가 지정한 공인 결합전문기관을 통해서만 서로 다른 처리자 간 결합 수행 |
| | 감독기구 일원화 | 행정안전부와 방송통신위원회의 개인정보 보호 기능을 개인정보보호위원회로 통합 |
| **정보통신망법 (특별법 정비)** | 개인정보 규정 이관 | 정보통신서비스 제공자 관련 개인정보 보호 조항을 삭제하고 개인정보 보호법으로 전면 통합 |
| | 중복 규제 해소 | ICT 서비스 사업자의 법 적용 혼란을 방지하고 일반법 중심의 통일된 규제 기준 적용 |
| **신용정보법 (금융 특례법)** | 금융 데이터 활용 확대 | 금융 분야 가명조치 도입, 공공기관 데이터 결합 허용, 데이터 전문기관 지정 |
| | 마이데이터 근거 마련 | 본인신용정보관리업(MyData) 제도화 및 개인신용정보 전송요구권 최초 도입 |

## Ⅲ. 데이터 3법 기반 가명정보 결합 및 처리 거버넌스 체계

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 데이터 3법 가명정보 안전 결합 및 반출 E2E 프로세스 ]                │
└────────────────────────────────────────────────────────────────────────┘

 [ 데이터 보유기관 A ]                      [ 데이터 보유기관 B ]
   └── 자체 가명처리 및 결합키 생성            └── 자체 가명처리 및 결합키 생성
             │                                          │
             ▼ (결합키 연계정보 전송)                   ▼ (결합키 연계정보 전송)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 한국인터넷진흥원 (KISA) 결합키관리기관 ] ── 솔트(Salt) 연계정보 생성  │
 └──────────────────────────────────────────────────────────────────────┘
                               │
                               ▼ (결합용 연계키 전송)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 지정 결합전문기관 ]                                                │
 │  ├── 가명 결합 데이터 생성 (양 기관 데이터 매칭 결합)                 │
 │  └── 추가 가명·익명처리 및 재식별 위험도 사전 분석                   │
 └──────────────────────────────────────────────────────────────────────┘
                               │
                               ▼ (반출 승인 신청)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 반출심사위원회 ] ── 재식별 가능성, 안전조치 이행 검토 ($k$-익명성)    │
 └──────────────────────────────────────────────────────────────────────┘
                               │ (승인 통과 시)
                               ▼
 [ 결합 신청기관 ] ── 통계작성, 과학적 연구 목적으로만 안전하게 분석 활용
```

| 프로세스 단계 | 주요 수행 업무 | 핵심 보안 통제 사항 |
|---|---|---|
| **1. 결합 신청 및 사전 전처리** | 결합 대상 데이터 추출 및 일차 가명처리 | 고유식별정보 제거, 결합키 연계정보(CI 변환) 생성 |
| **2. 결합키 연계 및 전송** | 키관리기관을 통한 결합키 생성 및 전문기관 전송 | 비대칭 암호화 통신, 키관리기관과 전문기관의 분리 |
| **3. 전문기관 결합 수행** | 결합키 기반 매칭 결합 및 가명 집계 데이터셋 구성 | 독립된 폐쇄 결합 서버 사용, 운영자 접근 통제 |
| **4. 추가 가명처리 및 심사** | 결합 데이터 내 이상치, 희귀값에 대한 추가 비식별화 | 3인 이상 전문가로 구성된 반출심사위원회 심의 |
| **5. 안전한 사후 관리** | 결합 데이터 목적 외 사용 금지, 안전성 확보조치 | 재식별 시도 즉시 중단 및 신고, 이용 완료 시 파기 |

## Ⅳ. 데이터 3법 3개 법률 간 역할 및 규율 범위 비교

| 비교 항목 | 개인정보 보호법 | 정보통신망법 | 신용정보법 |
|---|---|---|---|
| **법률의 지위** | 전 산업 포괄 일반법 | 정보통신망 및 정보보안 특별법 | 금융 및 신용정보 특별법 |
| **주요 규율 대상** | 모든 개인정보처리자 (공공·민간) | 정보통신서비스 제공자 및 망 이용자 | 금융회사, 신용평가사, 신용정보제공자 |
| **주관 감독기관** | 개인정보보호위원회 | 과학기술정보통신부, 방송통신위원회 | 금융위원회, 금융감독원 |
| **데이터 활용 특례** | 통계, 과학적 연구 목적 가명정보 처리 | 개인정보 조항 삭제 (망 보안 중심) | 상업적 통계, 금융 빅데이터 분석 허용 |
| **정보주체 권리** | 열람, 정정, 삭제, 처리정지, 전송요구 | 정보통신서비스 이용 권리 보장 | 전송요구권, 자동화 평가 설명·이의제기권 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 결합전문기관 심사 대기로 인한 데이터 결합 처리 기간 장기화 및 비용 부담 가중 | 결합 절차 패스트트랙(Fast-Track) 도입 및 안전성이 검증된 반복 결합에 대한 심사 간소화 |
| 산업 간 데이터 결합 시 상호 운용성 부족 및 이종 식별자 연계 오류로 인한 정합성 저하 | 범부처 공통 가명결합 표준 메타데이터 모델 수립 및 연계 식별자 검증 자동화 도구 보급 |

## Ⅵ. 제언

데이터 3법의 실효성을 극대화하기 위해 개인정보 안심구역 및 마이데이터 표준 API 연계를 가속화하고, 암호학적 신기술 기반의 자동 결합 파이프라인 구축 필요.

```text
[ 데이터 제공기관 A, B, C ]
             │
             ▼ (동형암호화 및 영지식 증명 적용)
[ 차세대 자동 결합 플랫폼 (Privacy-Preserving Engine) ]
   ├── 동형암호(Homomorphic Encryption) 기반 복호화 없는 연산
   ├── 자동 재식별 위험도($k$-Anonymity) 정량 평가
   └── 스마트 컨트랙트 기반 데이터 사용 목적 및 기한 자동 통제
             │
             ▼
[ 마이데이터 및 연구 생태계 실시간 안전 활용 ]
```

| 구분 | 기존 데이터 3법 결합 체계 | 제언: 암호학적 차세대 자동 결합 체계 |
|---|---|---|
| **결합 방식** | 결합전문기관 물리 서버 반입 결합 | 동형암호 기반 분산 원격 결합 (복호화 불요) |
| **심사 소요 시간** | 서면 위원회 심사로 수주~수개월 소요 | 알고리즘 기반 자동 위험 평가로 실시간 승인 |
| **재식별 위험** | 결합키 유출 시 원천 복원 잠재 위험 | 수학적 암호 증명으로 데이터 원본 노출 원천 배제 |
| **확장성** | 정형 데이터 중심 결합에 편중 | 멀티모달, 비정형 데이터 및 스트리밍 결합 지원 |
