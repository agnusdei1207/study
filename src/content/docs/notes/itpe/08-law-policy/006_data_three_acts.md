## Ⅰ. 데이터 3법의 개요

- 개념 : 개인정보의 안전한 보호와 **인공지능·빅데이터** 신산업 육성을 위해 개인정보 보호법, 정보통신망법, 신용정보법을 유기적으로 개정한 법률 패키지.
- 제정 배경 및 필요성 : 4차 산업혁명과 데이터 경제 시대의 국가 경쟁력 확보를 위해 개인정보의 보호와 안전한 활용의 균형을 도모하고, 분절되어 있던 개인정보 보호법·정보통신망법·신용정보법을 일괄 정비하여 법적 정합성을 확보할 필요성이 제기됨.
- 핵심 목적 : 데이터 활용에 관한 법적 불확실성 해소 및 국가 차원의 데이터 거버넌스 일원화 체계 구축.

## Ⅱ. 데이터 3법의 법제도 체계 및 핵심 메커니즘

**데이터 3법** : 개인정보 개념을 **개인정보·가명정보·익명정보** 3단계로 명확화하고 통계작성·과학적 연구 목적의 **가명정보 결합** 허용하며 감독기구를 개인정보보호위원회로 일원화 과정을 거쳐 상호 연동 및 단계별 법적·기술적 통제를 수행함.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 데이터 3법 가명정보 안전 결합 및 반출 E2E 프로세스 ]                │
└────────────────────────────────────────────────────────────────────────┘

 [ 데이터 보유기관 A ]                      [ 데이터 보유기관 B ]
   └── 자체 가명처리 및 결합키 생성            └── 자체 가명처리 및 결합키 생성
             │                                          │
             ▼ (결합키 연계정보 전송)                   ▼ (결합키 연계정보 전송)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 한국인터넷진흥원 (KISA) 결합키관리기관 ] ── 솔트(Salt) 연계정보 생성  │
 └──────────────────────────────────────────────────────────────────────┘
                               │
                               ▼ (결합용 연계키 전송)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 지정 결합전문기관 ]                                                │
 │  ├── 가명 결합 데이터 생성 (양 기관 데이터 매칭 결합)                 │
 │  └── 추가 가명·익명처리 및 재식별 위험도 사전 분석                   │
 └──────────────────────────────────────────────────────────────────────┘
                               │
                               ▼ (반출 승인 신청)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 반출심사위원회 ] ── 재식별 가능성, 안전조치 이행 검토 ($k$-익명성)    │
 └──────────────────────────────────────────────────────────────────────┘
                               │ (승인 통과 시)
                               ▼
 [ 결합 신청기관 ] ── 통계작성, 과학적 연구 목적으로만 안전하게 분석 활용
```

- **개인정보 보호법** (일반법) : 개인정보 3단계 개념 정의 - 개인정보·가명정보·익명정보로 체계화, 통계 및 과학적 연구 목적 가명정보 동의 없는 활용 허용
- **결합 체계 법제화** : 정부가 지정한 공인 결합전문기관을 통해서만 서로 다른 처리자 간 결합 수행
- **감독기구 일원화** : 행정안전부와 방송통신위원회의 개인정보 보호 기능을 개인정보보호위원회로 통합
- **정보통신망법** (특별법 정비) : 개인정보 규정 이관 - 정보통신서비스 제공자 관련 개인정보 보호 조항을 삭제하고 개인정보 보호법으로 전면 통합
- **중복 규제 해소** : ICT 서비스 사업자의 법 적용 혼란을 방지하고 일반법 중심의 통일된 규제 기준 적용

## Ⅲ. 데이터 3법의 세부 규정 및 국내외 제도 비교 분석

| 비교 항목 | 개인정보 보호법 | 정보통신망법 | 신용정보법 |
|---|---|---|---|
| 법률의 지위 | 전 산업 포괄 일반법 | 정보통신망 및 정보보안 특별법 | 금융 및 신용정보 특별법 |
| 주요 규율 대상 | 모든 개인정보처리자 (공공·민간) | 정보통신서비스 제공자 및 망 이용자 | 금융회사, 신용평가사, 신용정보제공자 |
| 주관 감독기관 | 개인정보보호위원회 | 과학기술정보통신부, 방송통신위원회 | 금융위원회, 금융감독원 |
| 데이터 활용 특례 | 통계, 과학적 연구 목적 가명정보 처리 | 개인정보 조항 삭제 (망 보안 중심) | 상업적 통계, 금융 빅데이터 분석 허용 |
| 정보주체 권리 | 열람, 정정, 삭제, 처리정지, 전송요구 | 정보통신서비스 이용 권리 보장 | 전송요구권, 자동화 평가 설명·이의제기권 |

- 제도적 정합성 및 대응 방향 : 데이터 3법은 상기 비교 지표를 바탕으로 법적 규제 준수(Compliance) 요건과 엔터프라이즈 운영 효율성을 균형 있게 확보하고, 선제적인 관리체계를 수립해야 함.

## Ⅳ. 데이터 3법의 주요 한계점 및 해결 방안

- 결합전문기관 심사 대기로 인한 데이터 결합 처리 기간 장기화 및 비용 부담 :
  - 한계점 : 결합전문기관 심사 대기로 인한 데이터 결합 처리 기간 장기화 및 비용 부담 가중.
  - 해결 방안 : 결합 절차 패스트트랙(Fast-Track) 도입 및 안전성이 검증된 반복 결합에 대한 심사 간소화.
- 산업 간 데이터 결합 시 상호 운용성 부족 및 연계 식별자 정합성 저하 :
  - 한계점 : 산업 간 데이터 결합 시 상호 운용성 부족 및 이종 식별자 연계 오류로 인한 정합성 저하.
  - 해결 방안 : 범부처 공통 가명결합 표준 메타데이터 모델 수립 및 연계 식별자 검증 자동화 도구 보급.

## Ⅴ. 데이터 3법 정착 및 실효성 확보를 위한 기술사적 제언

- 동형암호(HE) 기반 분산 원격 결합 도입을 통한 원본 데이터 노출 배제 : 기존의 결합전문기관 물리 서버 반입 결합 한계를 극복하기 위해 동형암호 기반 분산 원격 결합 (복호화 불요) 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- 범부처 공통 가명결합 표준 메타데이터 모델 수립 및 결합 절차 패스트트랙 : 기존의 서면 위원회 심사로 수주~수개월 소요 한계를 극복하기 위해 알고리즘 기반 자동 위험 평가로 실시간 승인 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- 공인 결합전문기관과 개인정보 안심구역·마이데이터 표준 API 유기적 연계 : 기존의 결합키 유출 시 원천 복원 잠재 위험 한계를 극복하기 위해 수학적 암호 증명으로 데이터 원본 노출 원천 배제 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
