## 연관 키워드

- **데이터 3법**, **개인정보 보호법**, **정보통신망법**, **신용정보법**
- **가명정보**, **통계작성·과학적 연구·공익적 기록보존**, **결합전문기관**
- **개인정보보호위원회**, **정보주체 권리**

## Ⅰ. 데이터 3법의 개요

- 핵심 요약 : 2020년 함께 개정된 **개인정보 보호법·정보통신망법·신용정보법**을 묶어 부르는 정책 용어.
- 개념 : 개인정보 보호 체계를 정비하면서 가명정보의 안전한 활용과 금융 분야 데이터 활용 기반을 마련한 세 법률의 개정.
- 배경 및 필요성 : 분산된 감독체계와 데이터 이용의 법적 불확실성을 줄이되 정보주체 권리 보호 필요.
- 목적 : 보호와 활용의 균형, 중복 규제 정비, 데이터 기반 연구·산업 활성화.

## Ⅱ. 데이터 3법의 특징 및 장점

- 핵심 요약 : **감독체계 정비**, **가명정보 활용**, **금융 데이터 이용**을 함께 다뤄 분야별 데이터 활용의 예측 가능성 향상.

1. **개인정보 감독체계 정비** : 개인정보보호위원회의 역할을 강화하여 분산된 보호 사무의 조정 기반 마련.
2. **가명정보 활용 근거** : 법정 목적에 한해 동의 없는 처리를 허용하여 통계·연구의 데이터 접근성 확대.
3. **전문기관을 통한 결합** : 서로 다른 처리자 간 가명정보 결합에 전문기관을 두어 활용과 재식별 위험 통제 병행.
4. **온라인 개인정보 규정 정비** : 정보통신망법의 관련 규율을 개인정보 보호법 중심으로 정리하여 사업자의 적용 법령 혼선 축소.
5. **신용정보 활용 기반** : 신용정보법 개정으로 금융 데이터 활용과 정보주체 권리 체계를 정비하여 금융 서비스 혁신 지원.

## Ⅲ. 데이터 3법의 구조와 가명정보 활용 흐름

- 핵심 요약 : 세 법률의 역할을 구분하고, **목적 확인 → 가명처리 → 필요 시 전문기관 결합 → 반출 승인·안전관리** 순서로 적용.

```text
데이터 3법
 ├─ 개인정보 보호법 ─ 일반 개인정보 보호·가명정보 처리
 ├─ 정보통신망법 ─── 정보통신망 이용·정보보호 관련 규율
 └─ 신용정보법 ──── 신용정보의 이용·보호 관련 규율
```

- **개인정보 보호법 제28조의2** : 통계작성, 과학적 연구, 공익적 기록보존 등을 위해 정보주체 동의 없이 가명정보 처리 가능.
- **제28조의3** : 서로 다른 개인정보처리자 간 가명정보 결합은 지정된 전문기관이 수행하며, 외부 반출은 법정 처리와 승인 필요.
- 가명처리를 했더라도 추가 정보의 분리 보관 등 안전조치를 이행해야 하며, 특정 개인을 알아보기 위한 처리 금지.

```text
목적·법적 근거 확인 → 가명처리 → 안전조치
                              ↓
                 다른 처리자 정보와 결합 필요?
                   ├─ 아니요 → 허용 범위 내 분석
                   └─ 예 → 지정 전문기관 결합 → 반출 승인 → 분석
```

## Ⅳ. 세 법률의 역할 비교

- 핵심 요약 : 개인정보 보호법은 공통 보호 체계, 정보통신망법은 망 관련 규율, 신용정보법은 금융·신용정보의 특수성을 담당.

| 비교 항목 | 개인정보 보호법 | 정보통신망법 | 신용정보법 |
|---|---|---|---|
| 중심 대상 | 개인정보 처리 전반 | 정보통신망의 이용과 정보보호 | 신용정보의 이용·보호 |
| 2020년 개정의 초점 | 가명정보와 감독체계 정비 | 개인정보 관련 중복 조항 정비 | 금융 데이터 활용·보호 체계 정비 |
| 실무 확인 | 처리 목적·동의·가명정보 요건 | 망 이용·정보보호 관련 의무 | 금융·신용정보 특례 및 정보주체 권리 |

- **데이터 3법**은 하나의 독립된 법률명이 아니며, 현재 의무는 각 법률의 최신 조문에서 확인해야 함.

## Ⅴ. 데이터 3법의 한계와 방안

- 핵심 요약 : **재식별 위험**, **결합 절차 부담**, **법률 경계 혼동**을 위험 평가·절차 표준화·법령별 적용표로 관리.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
|---|---|---|---|
| 가명정보 재식별 | 다른 데이터와 결합하면 식별 가능성 증가 | 목적별 위험 평가와 추가 정보 분리·접근통제 | 재식별 위험 평가 건수 |
| 결합 절차 지연 | 전문기관 심사와 반출 요건에 준비 시간 필요 | 신청 서류·데이터 형식을 사전 표준화 | 평균 결합 소요기간 |
| 법률 경계 혼동 | 일반·망·금융 분야의 적용 범위가 다름 | 데이터·사업자별 적용 조항 매핑 | 법령 검토 누락 건수 |
| 활용 목적 확대 | 최초 목적을 넘어 처리하면 권리 침해 우려 | 목적 변경 시 법적 근거 재검토 | 목적 외 처리 발견 건수 |

## Ⅵ. 데이터 3법에 대한 기술사적 제언

- 핵심 요약 : 데이터 활용 파이프라인에 **목적 검토**, **가명처리**, **결합·반출 통제**, **사후 감사**를 내재화할 필요.

1. 개인정보·신용정보의 구분과 처리 목적을 데이터 카탈로그에 기록.
2. 가명처리 적정성과 추가 정보 분리 보관을 기술·운영 절차로 검증.
3. 결합전문기관과의 데이터 교환 및 반출 과정에 책임자·승인 이력을 남김.
4. 최신 법령과 가이드라인을 기준으로 연구·상업 서비스의 적용 요건을 별도로 검토.

## Ⅶ. 결론

- 핵심 요약 : **데이터 3법**은 보호와 활용을 함께 정비한 2020년 입법 묶음이며, 실제 준수는 각 법률의 현행 조문에 따라 판단.
- 시사점 : 가명정보의 활용 가능성과 안전조치·전문기관 결합 요건을 함께 설명해야 정확한 답안.
