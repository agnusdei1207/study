## 2~4교시 25점 답안
## Ⅰ. 개요
| 구분 | 핵심 |
|---|---|
| 정의 | **다크패턴**은 온라인 화면을 설계해 소비자의 착각·부주의를 이용하고 원치 않는 거래나 선택을 유도하는 눈속임 상술 |
| 목적 | 사업자에게 유리한 선택을 유도해 구매·가입·결제 가능성을 높이는 설계 방식 |

개별 화면만 떼어 판단하지 말고 정보가 제시되는 순서, 선택지 간 표현, 거래·해지 전체 흐름과 소비자가 받는 영향을 함께 본다.

| 점검 관점 | 확인할 질문 |
|---|---|
| 정보 | 총액·계약 조건·갱신 시점이 적절한 때 명확히 제시되는가? |
| 선택 | 소비자가 각 선택지를 자유롭게 고를 수 있는가? |
| 취소 | 구매·가입보다 취소·해지가 부당하게 더 어렵지 않은가? |
| 맥락 | 긴급성·인기·할인 주장이 사실에 근거하는가? |

## Ⅱ. 공정위 가이드라인의 4개 범주·19개 유형
공정위의 온라인 다크패턴 자율관리 가이드라인은 유형을 소비자 피해의 양태와 작용 방식에 따라 4개 범주, 19개 세부 유형으로 분류한다. 이 가이드라인은 자율관리 안내이며, 그 자체가 법 위반 여부를 판정하는 법규는 아니다.

| 범주 | 세부 유형 |
|---|---|
| 편취형 (3) | 숨은 갱신 · 순차공개 가격책정 · 몰래 장바구니 추가 |
| 오도형 (7) | 거짓 할인 · 거짓 추천 · 유인 판매 · 위장 광고 · 속임수 질문 · 잘못된 계층구조 · 특정옵션 사전선택 |
| 방해형 (4) | 취소·탈퇴 방해 · 숨겨진 정보 · 가격비교 방해 · 클릭 피로감 유발 |
| 압박형 (5) | 반복간섭 · 감정적 언어 사용 · 시간제한 알림 · 낮은 재고 알림 · 다른 소비자의 활동 알림 |

각 유형은 명칭만으로 위법 여부가 결정되지 않는다. 표시 내용의 진실성, 법에서 정한 요건, 화면 전체의 맥락과 소비자의 선택 가능성을 적용해 판단한다.

## Ⅲ. 법률상 명시적 규제
현행 전자상거래법 제21조의2는 온라인 인터페이스의 특정 행위를 금지한다. 2026년 7월 21일 시행 법률을 기준으로 첫 화면 필수 총액 일부 표시, 사전 선택, 오인 유발 선택지 표시, 정당한 사유 없는 취소·탈퇴 방해, 반복적인 선택 변경 요구를 다룬다. 정기결제 금액 인상·무상에서 유상 전환은 별도 조문상 고지·동의 요건을 확인한다. 법률의 금지행위와 가이드라인의 19개 분류를 동일시하지 않는다.

| 유형 | 법적 요구의 핵심 |
|---|---|
| 순차공개 가격책정 | 첫 화면에서 필수 지급 총액 중 일부만 제시해 소비자를 유인·거래하는 행위 금지. 정당한 사유 예외는 법령상 고지 요건 확인 |
| 특정옵션 사전선택 | 소비자가 직접 선택하기 전에 청약 의사가 있는 것처럼 옵션을 미리 표시해 거래를 유인하는 행위 금지 |
| 잘못된 계층구조 | 선택지의 크기·모양·색상 차이로 특정 항목만 선택 가능하거나 필수인 것처럼 오인하게 하는 경우 금지 |
| 취소·탈퇴 방해 | 정당한 사유 없이 구매·가입보다 취소·탈퇴를 복잡하게 하거나 다른 방법으로만 가능하게 하는 행위 금지 |
| 반복간섭 | 소비자가 결정한 내용을 팝업 등으로 반복 변경 요구해 자유로운 의사결정을 방해하는 행위 금지. 법령상 반복 요구 제한 선택 요건 확인 |
| 숨은 갱신 관련 전환·인상 | 정기결제 금액 증액 또는 무상 제공 후 유료 전환 30일 전에 시점·전후 가격·결제방법의 동의를 받고 취소·해지 조건·방법·효과를 고지 |

## Ⅳ. 소비자 피해가 생기는 방식
정보를 늦게 공개하거나 선택지를 왜곡하면 소비자는 비용·계약 조건을 충분히 비교하지 못할 수 있다. 탈퇴·해지를 어렵게 만들거나 반복적으로 결정을 바꾸라고 요구하면 실제 선택권이 약해진다.

```text
 [필수 비용·조건 늦은 표시] ---> [총액·조건 뒤늦게 인지] --+
                                                            |
 [사전 선택·시각적 차등] -----> [의도와 다른 선택 가능성] ---+--->
                                                            | [원치 않는 거래·분쟁 위험]
 [해지 복잡화·반복 팝업] -----> [취소·거부 포기 가능성] ---+
```

## Ⅴ. 사업자·설계자 대응
대응은 화면별 체크리스트를 두고 실제 이용 흐름을 따라가며 정보·선택·동의·취소가 모두 명확한지 확인하는 방식으로 운영한다. 법무·소비자보호·제품·개발 담당자가 변경 전후 화면과 근거 자료를 함께 검토한다.

| 업무 | 점검·개선 방법 |
|---|---|
| 가격·조건 | 첫 화면에 필수 총액과 갱신·변경 조건을 눈에 띄게 제공 |
| 선택지 | 기본 선택을 중립화하고 구매·거부의 표현과 접근성을 균형 있게 구성 |
| 구독·갱신 | 법정 대상인 증액·무료에서 유료 전환은 시점, 가격, 결제수단 고지와 명시적 동의를 갖춤 |
| 취소·해지 | 가입 경로와 비교해 불필요한 단계·채널 제한을 제거 |
| 반복·긴급 표현 | 반복 팝업을 억제하고 시간·재고·인기 문구에 사실 근거를 보유 |
| 검증 | 배포 전 화면·기능 테스트와 민원·취소 데이터를 정기적으로 확인 |

## Ⅵ. 제도·이용자 대응과 유의점
공정위 가이드라인은 사업자 자율관리와 소비자 주의를 위한 유형 분류를 제공한다. 전자상거래법의 금지행위에 해당하면 법령에 따른 조사·시정 등 조치의 대상이 될 수 있다. ‘19개 유형 모두가 같은 방식으로 법에 직접 금지되어 있다’거나 ‘모든 다크패턴에 자동 과징금이 부과된다’고 서술하지 않는다.

| 주체 | 대응 |
|---|---|
| 사업자 | 법정 금지 유형과 고지·동의 요건 준수, 가이드라인 기반 자율점검 |
| 소비자 | 가격·자동결제 조건·해지방법을 확인하고 화면·고지 기록 보관 |
| 감독기관 | 법률상 요건에 따라 사실관계를 조사하고 시정·제재 여부 판단 |

## Ⅶ. 기술적 제언
| 한계 | 해결 방안 |
|---|---|
| 화면 변경이 소비자 선택과 법적 요건에 미치는 영향을 놓침 | 디자인 리뷰에 총액·선택·갱신·취소 점검항목을 포함하고 변경 이력을 남긴다. |
| 전환율만 추적해 불만·취소 문제를 발견하지 못함 | 민원, 취소 성공률, 결제 후 취소·환불 등 보호 지표를 전환 지표와 함께 점검한다. |
| 법률상 의무와 자율 가이드라인을 혼동 | 법령 요구사항과 권고사항을 별도 체크리스트로 관리하고 변경 시 각각 갱신한다. |
