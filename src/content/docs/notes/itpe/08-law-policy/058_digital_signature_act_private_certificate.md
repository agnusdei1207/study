## Ⅰ. 전자서명법 개정·사설인증서의 개요

- **개념** : 공인인증서의 독점적 법적 지위를 철폐하고, 다양한 민간 사업자가 블록체인·생체인증 등 신기술 기반 전자서명 서비스를 자율 제공하도록 한 제도적 대전환.
- **제정 배경 및 필요성** : 민간 인증서 난립으로 인한 이용기관의 중복 연동 개발 부담과 피싱·스미싱에 따른 서명키 탈취 위협을 해소하기 위해 표준 OIDC 중계 게이트웨이 연계 및 스마트폰 TEE 기반 FIDO2 다중인증 결합 필수.
- **핵심 목적** : 액티브X 및 전용 프로그램 강제 폐지, 사용자 인증 편의성 제고 및 핀테크·클라우드 기반 인증 시장의 자유로운 혁신 경쟁 촉진.

## Ⅱ. 전자서명법 개정·사설인증서의 법제도 체계 및 핵심 메커니즘

전자서명법 개정·사설인증서은(는) 공인전자서명의 우월적 효력 조항을 삭제하고 '전자서명인증업무 운영기준 준수사실 평가·인정제'를 신설하여 민간 평가기관과 KISA의 심의를 통과한 민간 인증서에 공신력 부여 과정을 거쳐 체계적인 법제도적 통제와 기술적 신뢰성을 확보함.

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ 민간 전자서명인증업무 평가·인정 및 OIDC 서명 검증 파이프라인 ]           │
└─────────────────────────────────────────────────────────────────────────────┘
  [ 전자서명인증사업자 (네이버/카카오/토스/PASS 등) ]
        │
        │ 1. 운영기준 준수 평가 신청
        ▼
  [ 공인 평가기관 (KISA 지정: TTA, 금융보안원 등) ]
        │
        │ 2. 정밀 기술 심사: 알고리즘 강도, 개인키 보호(HSM), 시스템 망분리
        ▼
  [ 인정기관 (한국인터넷진흥원: KISA) ]
        │
        │ 3. 인정위원회 심의 및 인정 증명서 교부 (1년 단위 유효)
        ▼
  [ 공공·금융 이용기관 (홈택스, 정부24, 시중은행) ]
        │
        │ 4. OIDC / REST API 기반 표준 간편인증 연동
        ▼
  [ 이용자 스마트폰 (FIDO2 생체인증 / 6자리 PIN 서명) ]
        │
        ▼
  [ 발급사 클라우드 HSM 내 개인키 전자서명 생성 및 토큰 검증 완료 ]

[ 전자서명 생성 및 검증 흐름 ]
전자계약 원문 ─> 해시(SHA-256) 생성 ─> 사용자 인증(FIDO2 생체) ─> 개인키 전자서명 ─> 공개키 검증 성공
```

- **독점 지위 폐지** : 공인/사설 법적 구분 철폐 - 공인전자서명의 우월적 효력(서명날인 간주, 서명자 본인 추정) 삭제, 모든 전자서명의 동등 효력 보장.
- **효력 부인 금지** : 제3조(전자서명의 효력) - 단지 '전자적 형태라는 이유만으로' 서명·날인으로서의 법적 효력을 부인하지 못하도록 명문화.
- **자율 선택권** : 당사자 간 약정 효력 보장 - 거래 당사자 간의 합의나 개별 법령이 정하는 바에 따라 원하는 전자서명 수단을 자유롭게 선택 가능.
- **평가·인정제** : 운영기준 준수사실 인정 (제8조) - 정부 허가제가 아닌 자율 신청 기반의 평가·인정제를 도입하여 시장 자율성과 최소 신뢰성 확보.

## Ⅲ. 전자서명법 개정·사설인증서의 세부 규정 및 국내외 제도 비교 분석

| 비교 항목 | 공동인증서 (구 공인인증서) | 금융인증서 (금융결제원) | 플랫폼 간편인증서 (카카오·토스·PASS) |
|---|---|---|---|
| **저장 매체** | PC 하드디스크, 이동식 USB, 보안토큰 | 금융결제원 안전 클라우드 HSM | 스마트폰 앱 격리영역(TEE) 및 클라우드 |
| **서명 방식** | 영문·숫자·특수문자 10자리 비밀번호 | 6자리 간편 PIN 번호, 패턴 | 지문, FaceID 생체인증(FIDO), 간편 PIN |
| **프로그램 설치** | Active-X 대체 실행파일(exe) 설치 필수 | 프로그램 무설치 (웹 브라우저 클라우드 연동) | 무설치 (스마트폰 앱 푸시 승인 방식) |
| **유효 기간** | 1년 (매년 갱신 필요) | 3년 (자동 갱신 지원) | 1년~3년 (앱 내 원클릭 자동 갱신) |
| **적용 영역** | 공공·금융·범용 모든 영역 호환 | 은행 등 금융권 및 주요 공공 웹사이트 | 대국민 플랫폼 로그인, 간편 전자결제, 계약 |

- **제도적 시사점** : 전자서명법 개정·사설인증서은(는) 상기 비교 지표를 바탕으로 법적 의무 준수와 비즈니스 연속성 간의 균형을 확보하고, 규제 환경 변화에 선제적으로 대응할 수 있는 아키텍처 및 거버넌스 체계를 확립해야 함.

## Ⅳ. 전자서명법 개정·사설인증서의 주요 한계점 및 해결 방안

- **사설 인증사 난립에 따른 이용기관의 개별 SDK 연동 기술적 파편화** :
  - **한계점** : 수많은 사설 인증사 등장으로 인해 공공·이커머스 이용기관이 각 인증사별 SDK를 개별 개발·연동하는 기술적 파편화.
  - **해결 방안** : 행정안전부의 '공공분야 간편인증 통합 중계 서비스'를 필수 표준 게이트웨이로 채택하고 OpenID Connect(OIDC) 기반 단일 API 연동 체계 구축.
- **스마트폰 분실 및 보이스피싱 앱 감염 시 간편 PIN 기반 부정 대출 위험** :
  - **한계점** : 스마트폰 분실 및 보이스피싱 원격제어 앱 감염 시 사설인증서의 간편 PIN 탈취를 통한 비인가 부정 대출·이체 위험.
  - **해결 방안** : 인증서 서명 요청 시 단말 FIDO2 하드웨어 보안칩(TEE/SE) 기반 다중 생체 서명 강제화 및 FDS(이상거래탐지) 연계 실시간 차단.
- **비대면 간편인증의 법적 증거력 취약성 및 분쟁 시 입증 책임 모호** :
  - **한계점** : 대면 신원확인을 거치지 않은 비대면 사설인증서의 법적 증거력 취약성 및 분쟁 발생 시 입증 책임 소재 모호.
  - **해결 방안** : 전자서명 생성 당시의 타임스탬프(TSA), 감사 로그 원장(Audit Trail) 및 FIDO 인증 성공 증적을 공인전자문서센터에 보관 의무화.

## Ⅴ. 전자서명법 개정·사설인증서 정착 및 실효성 확보를 위한 기술사적 제언

사설인증서의 상호운용성과 거래 안전성을 극대화하기 위하여 OIDC 표준 중계 게이트웨이를 구축하고 FIDO2 생체인증과 클라우드 HSM을 결합하는 통합 인증 거버넌스 수립.

- **개발 공수 관점의 고도화 및 실무 전환** : N개 인증사별 SDK 개별 유지보수의 한계와 비효율을 탈피하고, 단일 표준 API 연동으로 모든 사설인증서 지원을 체계적으로 도입·적용하여 실무적 신뢰성과 거버넌스 실효성을 극대화해야 함.
- **사용자 경험 관점의 고도화 및 실무 전환** : 특정 브라우저 전용 프로그램 강제의 한계와 비효율을 탈피하고, 모든 웹·모바일 환경에서 무설치 간편 서명을 체계적으로 도입·적용하여 실무적 신뢰성과 거버넌스 실효성을 극대화해야 함.
- **키 보안성 관점의 고도화 및 실무 전환** : 로컬 파일 복사 유출 위험의 한계와 비효율을 탈피하고, 클라우드 HSM 및 스마트폰 하드웨어 TEE 격리를 체계적으로 도입·적용하여 실무적 신뢰성과 거버넌스 실효성을 극대화해야 함.
