## 연관 키워드

- 공정이용(Fair Use), 저작권법 제35조의5, 생성형 AI, 학습 데이터, 공정이용 안내서
- TDM(Text and Data Mining), 옵트아웃(Opt-out), robots.txt, 데이터 계보(Data Lineage)
- 변형적 이용, 시장 영향, 실질적 유사성, 모델 재학습, 출력 필터링

## Ⅰ. 생성형 AI 학습 공정이용 안내서 (AI 저작권)의 개요

- 핵심 요약 : 생성형 AI 학습에 저작물을 쓰는 행위를 저작권법 제35조의5 공정이용 규정으로 사안별로 판단하도록 안내한 기준.
- 개념 : 한국저작권위원회가 발간한 「생성형 인공지능의 저작물 학습에 대한 저작권법상 공정이용 안내서」는 **공정이용**(Fair Use) 규정인 저작권법 제35조의5를 AI 학습에 적용하는 방법을 설명한다.
- 배경 및 필요성 : 모델 학습에 저작물을 사전 허락 없이 복제하는 관행이 늘면서 권리자와 개발자 사이의 분쟁 가능성이 커졌으나, 학습 행위를 직접 허용하거나 금지하는 명문 규정이 없다.
- 주요 목적 : AI 개발에 따른 공공 편익과 원저작자의 재산권 보호 사이에서 법적 판단 기준을 제시하는 것이다.
- 발간 경과 : 2026년 5월 보도 기준으로 문화체육관광부와 과학기술정보통신부가 협력해 마련한 첫 결과물이며, 판례와 기술 변화에 맞춰 지속 보완될 예정이라고 전해졌다.

## Ⅱ. 공정이용 판단의 요소와 생애주기별 통제

- 핵심 요약 : 네 가지 판단 요소를 종합해 학습 행위를 판단하고, 수집부터 출력까지 생애주기 단계마다 통제 장치를 두는 구조.

1. 이용의 목적과 성격 : 변형적 이용인지, 상업적 목적인지 여부 → 학습이 표현 복제가 아닌 지식 추출인지 판단.
2. 저작물의 종류와 용도 : 사실적·정보적 저작물과 창작적 저작물을 구분 → 창작성이 높을수록 공정이용 인정이 엄격.
3. 이용된 분량과 중요성 : 학습에 쓰인 비율과 핵심 표현의 사용 여부 → 본질적 부분의 복제를 경계.
4. 원저작물 시장에 대한 영향 : 생성물이 원작의 시장을 대체하는지 여부 → 안내서가 특히 중요하게 다루는 요소.

```text
[ 학습 데이터 수집 ]
robots.txt와 이용 약관 확인
          ↓
[ 가공·정제 ]
라이선스와 출처 메타데이터 기록
          ↓
[ 모델 학습 ]
원문 암기 억제와 학습 기록 관리
          ↓
[ 출력 ]
유사성 검사와 출력 필터링
```

- 수집 단계 : 무단 크롤링과 유료 콘텐츠 우회를 막고, 권리자가 설정한 수집 거부 표시를 존중.
- 정제 단계 : 저작권 관리 정보를 임의로 지우지 않고, 원저작자와 출처를 기록하는 계보 원장을 유지.

## Ⅲ. 학습 단계와 출력 단계의 판단 구분

- 핵심 요약 : 학습 단계의 복제와 출력 단계의 배포는 법적 쟁점이 다르므로 나누어 판단해야 함.

```text
[ 단계 1 : 학습 ]
입력 데이터의 복제와 저장
          ≠
[ 단계 2 : 출력 ]
생성물의 배포와 공중 송신
```

- 학습 단계 : 저작물을 복제해 특징을 추출하는 행위가 **변형적 이용**(원작과 다른 목적과 성격으로 쓰이는 이용)으로 볼 수 있는지 검토.
- 출력 단계 : 생성물이 원작과 실질적으로 유사하고 시장 대체 효과를 내는지 검토.

## Ⅳ. 국내외 제도 비교

- 핵심 요약 : 한국은 일반 공정이용 규정에 기대고, 미국은 판례 기반의 4요소 원칙을, EU는 **텍스트·데이터 마이닝**(TDM, Text and Data Mining) 예외와 옵트아웃을 명문화하는 구도.

| 비교 항목 | 한국 (저작권법) | 미국 (판례법) | EU (DSM 지침) |
| --- | --- | --- | --- |
| 판단 근거 | 제35조의5 공정이용 규정 | 저작권법 제107조 공정이용 4요소 | DSM 저작권 지침의 TDM 예외 |
| TDM 명문 규정 | 별도 면책 조항 없음 | 명문 규정 없음, 판례에 의존 | 명문 허용과 옵트아웃 조항 |
| 권리자 거부 표시 | 법적 기준 미흡 | 기업 자율 협약 중심 | 기계 판독 가능한 옵트아웃 |

- 선택 기준 : 학습 데이터의 출처가 명확한 라이선스 자료인지, 권리자 거부 표시가 있는지에 따라 위험 수준을 나누어 관리한다.

## Ⅴ. 생성형 AI 학습의 한계와 방안

- 핵심 요약 : TDM 명문 규정의 부재, 침해 데이터 포함 위험, 출력 단계의 원문 재현을 라이선스 검증과 계보 관리, 출력 필터링으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 명문 면책 규정 부재 | 학습 행위의 적법성이 사안별 판단에 의존 | 학습 목적 데이터의 라이선스 확보와 사전 법률 검토 | 라이선스 확보 비율 |
| 침해 데이터 혼입 | 침해 저작물이 섞이면 모델 재학습이나 폐기를 요구받을 수 있음 | 데이터 계보 원장으로 출처를 추적하고 침해 데이터 격리 | 출처 미확인 데이터 비율 |
| 출력의 원문 재현 | 과적합과 프롬프트 조작으로 원본이 그대로 나타날 수 있음 | 출력 유사도 검사와 특정 표현 차단 필터 적용 | 원문 재현 차단율 |

## Ⅵ. 생성형 AI 학습 저작권 정착을 위한 기술사적 제언

- 핵심 요약 : 데이터 계보 관리와 출력 통제를 개발 체계에 내장한 신뢰형 MLOps 거버넌스로 저작권 위험을 관리.

1. 데이터 수집은 권리자의 수집 거부 표시를 존중하고, 라이선스가 확인된 자료를 우선 사용하는 원칙을 개발 표준에 넣는 것이 바람직하다.
2. 학습 데이터의 출처와 변환 이력을 계보 원장으로 남기면, 분쟁이 생겼을 때 해당 데이터를 특정해 빠르게 대응할 수 있다.
3. 서비스 출력은 배포 전에 원본과의 유사성을 검사하는 절차를 거치도록 하고, 검사 결과와 차단 이력을 감사 자료로 보관하는 것이 필요하다.

## Ⅶ. 결론

- 핵심 요약 : 생성형 AI 학습의 공정이용 여부는 사안별 4요소 판단으로 결정되는 영역이다.
- 시사점 : 명문 규정이 정비되기 전까지는 데이터 출처 관리와 출력 통제가 법적 위험을 줄이는 실질적 수단이며, 안내서는 판례와 기술 변화에 따라 계속 갱신될 것이다.
