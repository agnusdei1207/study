## 30초 인출

- 본질: **생성형 AI 학습 공정이용** 은 대규모 파운데이션 모델 학습을 위해 웹 크롤링 및 저작물을 수집·복제·전처리하는 행위의 적법성을 판정하기 위해 저작권법 제35조의5(저작물의 공정한 이용)를 적용하는 법적 판단 지침
- 메커니즘: 이용의 목적 및 성격(변형적 이용 여부), 저작물의 종류와 용도, 이용된 부분의 양과 질적 중요성, 원저작물의 시장 및 가치에 미치는 영향을 4대 요소로 종합 판정
- 통찰: TDM(텍스트·데이터 마이닝) 포괄적 면책 조항의 미비로 기업의 침해 소송 위험이 급증하므로 데이터 카탈로그 계보(Lineage) 추적과 로봇 배제 표준(robots.txt) 기반 옵트아웃 준수 및 라이선스 데이터셋 중심 학습 체계 정립 필수

<details><summary>핵심 용어</summary>

- **공정이용 (Fair Use)** : 저작권자의 독점적 권리를 제한하여 보도·비평·교육·연구 등을 위해 허락 없이도 저작물을 합리적으로 이용할 수 있도록 허용하는 법적 원칙.
- **TDM (Text and Data Mining)** : 컴퓨터 알고리즘을 활용하여 방대한 디지털 텍스트와 데이터로부터 규칙, 경향, 패턴 등을 자동 분석·추출하는 기술.
- **변형적 이용 (Transformative Use)** : 원저작물을 단순 복제하는 데 그치지 않고 새로운 목적, 의미, 통찰을 부가하여 새로운 창작물로 전환시키는 이용 행위.
- **실질적 유사성 (Substantial Similarity)** : AI가 생성한 결과물이 원저작물의 창작적 표현과 관념적·시각적·구조적으로 상당한 수준 일치하는지 여부.
- **로봇 배제 표준 (robots.txt)** : 웹사이트 관리자가 크롤러 등 자동화 로봇의 페이지 수집 권한을 제어하기 위해 선언하는 공개 규약.
- **옵트아웃 (Opt-out)** : 권리자가 자신의 데이터나 저작물이 AI 학습 데이터셋에 포함되지 않도록 거부 의사를 표시하는 권리 보장 절차.

</details>

## 2~4교시 25점 답안

## Ⅰ. 생성형 AI 학습 공정이용의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 AI 학습 공정이용** 은 파운데이션 모델 개발 시 저작물을 사전 허락 없이 크롤링·복제·임베딩하는 행위의 적법성을 저작권법 제35조의5에 따라 사안별로 판정하는 기준 |
| 목적 | AI 모델 개발을 위한 데이터 이용의 공공 편익과 원저작자의 정당한 재산권·인격권 보호 사이의 합리적 법적 균형 달성 |

## Ⅱ. 저작권법 제35조의5 4대 공정이용 판단 요소 특징

| 구분 | 4대 법정 판단 요소 | 세부 판정 기준 및 공학적 고려사항 |
|---|---|---|
| **요소 1** | 이용의 목적 및 성격 | 비영리·연구 목적 여부, 단순 표현 복제가 아닌 지식 추출 및 추론 모델 구축 등 **변형적 이용** 의 인정 강도 |
| **요소 2** | 저작물의 종류 및 용도 | 사실적·정보적 저작물(공정이용 인정 유리) vs 창작적·예술적 저작물(공정이용 인정 엄격 제한) |
| **요소 3** | 이용된 분량과 중요성 | 전체 저작물 대비 학습에 사용된 비율, 저작물의 본질적·핵심적 표현 부위(정수)의 추출 여부 |
| **요소 4** | 현재·잠재적 시장 영향 | AI 생성물이 원저작물 시장을 대체(Market Substitution)하거나 잠재적 라이선스 수익을 잠식하는지 여부 |

## Ⅲ. AI 학습 및 생성 단계별 저작권 검증 체계·프로세스

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ 생성형 AI 생애주기별 저작권 리스크 통제 파이프라인 (Copyright Gateway) ]  │
└─────────────────────────────────────────────────────────────────────────────┘
  [ 1. 데이터 수집 단계 ]
    ├── 웹 크롤링 시 robots.txt 및 약관 준수 (NoIndex / NoArchive 판정)
    └── 라이선스 검증: CC(Creative Commons), 상용 라이선스, 퍼블릭 도메인
          │
          ▼
  [ 2. 데이터 가공/정제 단계 ]
    ├── 중복 텍스트 제거 및 민감·저작권 표식 데이터 필터링
    └── 데이터 계보(Lineage) 원장 기록: 출처, 수집 일시, 원저작자 메타데이터
          │
          ▼
  [ 3. 모델 사전학습 단계 ]
    ├── 원문 암기(Memorization) 방지: 정규화 기법 및 드롭아웃(Dropout) 적용
    └── 프라이버시 보존 학습 (Differential Privacy 결합)
          │
          ▼
  [ 4. 추론 및 생성 서비스 ]
    ├── 입력 프롬프트 검증: 특정 작가 화풍 복제·특정 텍스트 복사 유도 차단
    └── 출력 필터링: 실질적 유사성(Vector Sim > 0.85) 원본 대조 및 폐기
```

```text
[ 공정이용 판단의 2단계 분리 구조 ]
┌──────────────────────────────────┐      ┌──────────────────────────────────┐
│   [단계 1: 학습(Training) 단계]  │      │   [단계 2: 추론(Output) 단계]    │
│  - 입력 데이터 복제·임베딩 행위  │  ≠   │  - 생성물의 시장 배포·공중송신   │
│  - 잠재적 TDM 및 변형적 이용 검토│      │  - 원작과의 실질적 유사성 검토   │
└──────────────────────────────────┘      └──────────────────────────────────┘
```

| 처리 단계 | 저작권 침해 위험 요인 | 컴플라이언스 통제 기법 |
|---|---|---|
| **수집 (Ingestion)** | 무단 스크래핑, 유료 페이월(Paywall) 우회 | robots.txt 크롤링 에이전트 준수, API 정식 구매 |
| **정제 (Preprocessing)** | 저작권 관리정보(워터마크 등) 고의 제거 | 메타데이터 보존 파이프라인, 원저작자 식별자 태깅 |
| **학습 (Training)** | 모델의 훈련 데이터 과적합 암기 현상 | 디듀플리케이션(Deduplication), 퍼플렉시티 검증 |
| **출력 (Inference)** | 프롬프트 주입을 통한 원작 복제물 생성 | 벡터 유사도 기반 저작권 침해 필터, 거부 응답 처리 |

## Ⅳ. 국내외 AI 저작권 공정이용 및 TDM 법제 비교

| 비교 항목 | 한국 (저작권법 체계) | 미국 (판례법 체계) | EU (AI Act & DSM 지침) |
|---|---|---|---|
| **판단 체계** | 제35조의5 일반 공정이용 규정 | 제107조 4 Factor Fair Use 원칙 | DSM 저작권 지침 제3조·제4조 TDM |
| **TDM 명문 조항** | TDM 면책 조항 미도입 (입법 계류) | 명문 규정 없음 (사법부 판례 의존) | TDM 적법 이용 명문 허용 (상업적 포함) |
| **옵트아웃 (Opt-out)** | 법적 권리 명문화 미흡 (권고 수준) | 기업 자율 합의 체계 | 기계판독 가능 형식의 옵트아웃 보장 |
| **투명성 의무** | 고위험·생성형 AI 권고 | AI 워터마크 자율 서약 | 학습 데이터 상세 요약 공개 의무화 |
| **산업계 영향** | 개별 소송별 사법 판단 불확실성 | 변형적 이용 인정 여부 치열한 공방 | 예측 가능성 높으나 규제 준수 비용 큼 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 현행법상 TDM 면책 조항 부재로 모델 재학습 및 서비스 배포 시 잠재적 대규모 손해배상 소송 노출 | 저작권법 개정을 통한 '데이터 분석 목적의 복제·전송 면책(TDM 특례)' 조항 신설 및 저작권 집중관리단체를 통한 일괄 보상금 제도 도입 |
| 수십억 건의 학습 데이터 중 저작권 침해 저작물이 포함되었을 때 전체 모델 폐기(Model Disgorgement) 명령 위험 | 머신 언러닝(Machine Unlearning) 기술 도입을 통한 특정 데이터 영향도 선택적 삭제 및 사전 가공 시 라이선스 원천 검증 체계 수립 |
| LLM의 과적합으로 인해 사용자의 프롬프트 입력에 따라 원본 텍스트·이미지가 무단 복제되어 출력되는 현상 | 출력단 코사인 유사도(Cosine Similarity) 필터링 게이트웨이 구축 및 특정 고유명사·표현 유출 차단용 가드레일(NeMo Guardrails 등) 결합 |

## Ⅵ. 제언

데이터 취득부터 모델 추론까지 저작권 위험을 원천 차단하기 위해 데이터 카탈로그 계보(Lineage) 원장과 실시간 출력 침해 탐지 가드레일을 결합한 신뢰형 MLOps 거버넌스 구현.

```text
[ 데이터 취득 및 검증 ]
          │
          ▼
[ 데이터 계보(Lineage) 원장 등록 ] ──> [ 라이선스/옵트아웃 여부 메타데이터화 ]
          │
          ▼
[ 정제 및 디듀플리케이션(De-dup) ]
          │
          ▼
[ 파운데이션 모델 학습 진행 ]
          │
          ▼
[ 추론 API 서빙 게이트웨이 ]
    ├── Step 1: 프롬프트 탈옥 및 저작물 추출 시도 차단
    └── Step 2: RAG 벡터 인덱스 대조 실시간 유사도(Similarity) 검사
          │
          ▼ (유사도 임계치 초과 시)
[ 자동 차단 및 대체 텍스트 합성 출력 ]
```

| 구분 | 기존 무차별 크롤링 모델 | 제언: 저작권 준수 신뢰 MLOps |
|---|---|---|
| **데이터 수집** | 웹 전역 비인가 스크래핑 | robots.txt 준수 및 유료 라이선스/공공 데이터 한정 |
| **계보 추적** | 학습 데이터 출처 파악 불가 | 데이터 카탈로그 기반 수집·변환·학습 전 주기 감사 |
| **추론 통제** | 프롬프트에 따른 원문 출력 무방비 | 실시간 벡터 유사도 판정 및 출력 차단 가드레일 |
| **법적 리스크** | 전체 모델 폐기 명령 위험 | 언러닝 및 특정 침해 가중치 교체로 비즈니스 연속성 보장 |
