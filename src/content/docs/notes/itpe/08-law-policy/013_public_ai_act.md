## Ⅱ. 적용 주체와 추진 기반

| 주체 | 역할 |
|---|---|
| 행정안전부장관 | 기본 정책·데이터 통합관리 플랫폼·윤리기준 등 총괄 |
| 공공기관 | 소관 행정에서 데이터·AI 활용을 추진하고 필요한 관리 수행 |
| 전문기관 | 법정 위탁·지정 업무 및 전문기술 지원 수행 |
| 민간 법인·기관 등 | 국가·공공기관과의 협력 및 법정 사업 참여 가능. 공공 데이터 공동활용 주체·절차와는 구분 |

## Ⅲ. 데이터 기반 행정

데이터 공동활용은 목적·법적 근거 확인 후 제공·연계하는 구조. 개인정보·영업비밀 등 다른 법률상 제한을 무시한 일괄 개방 의무와는 구분.

```text
행정 수요·분석 과제 확인
          ↓
필요 데이터·법적 근거 검토
          ↓
제공·연계·공동활용 결정
          ↓
품질·접근권한·보호조치 적용
          ↓
분석 결과의 행정·정책 활용
          ↓ 결과·데이터 품질 점검
```

| 점검 관점 | 핵심 |
|---|---|
| 적법성 | 제공 목적·법적 근거와 다른 법률상 제한 확인 |
| 데이터 품질 | 출처·갱신시점·결측·품질 기준 기록 |
| 접근통제 | 이용자·권한·처리 기록과 보호조치 적용 |

## Ⅳ. AI 기반 행정과 활용서비스

| 단계 | 관리 내용 |
|---|---|
| 과제 선정 | 행정상 필요, 대상 국민, 기대 효과와 대체 수단 검토 |
| 도입·개발 | 데이터 적법성·품질, 모델 적합성과 오류 위험 점검 |
| 서비스 제공 | 이용자 고지, 책임자와 이의·오류 대응 경로 마련 |
| 운영·변경 | 성능·영향을 점검하고 데이터·모델·목적 변경 시 재평가 |

## Ⅴ. 신뢰 기반과 윤리기준

행정안전부장관의 공공기관 적용 윤리기준 마련·공표. 기준에는 공정성·투명성·책임성·안전성과 인공지능기본법상 윤리원칙 반영.

| 신뢰 요소 | 공공기관의 적용 예 |
|---|---|
| 공정성 | 취약계층·집단별 오류와 불리한 영향을 점검 |
| 투명성 | AI 활용 사실, 주요 한계와 담당 부서를 안내 |
| 책임성 | 결정 권한·검토자·정정 절차를 분명히 지정 |
| 안전성 | 접근 통제, 시험, 사고 대응과 운영 점검 수행 |

## Ⅵ. 현장 이행과 위험 관리

| 위험 | 대응 |
|---|---|
| 데이터 공유 요청이 개인정보·목적 제한과 충돌 | 제공 근거·목적·최소 범위를 먼저 검토하고 안전한 연계 방식 적용 |
| 불완전한 데이터가 행정 판단을 왜곡 | 출처·갱신 시점·결측·품질 기준을 기록하고 결과를 표본 검토 |
| AI 오류가 행정상 불이익으로 이어짐 | 담당 공무원 검토, 당사자 문의·정정 경로와 중단 절차 마련 |
| 모델·데이터가 바뀌어 성능 저하 | 변경 이력과 재시험 기준을 두고 운영 중 결과를 지속 점검 |

## Ⅶ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 행정서비스에 AI 도입 후 데이터 근거와 책임·정정 절차 추적이 어려움 | 업무별 데이터 출처·법적 근거, 모델 버전, 담당자 검토, 이의 처리와 변경 이력을 운영대장에 연결하고 표본 감사 |
