## 8과목 전체 로드맵과 현재 위치

```text
                         [IT 가치·성과]
                               ▲
                               │
 [01 IT경영전략] ─────▶ [02 SW공학·프로젝트] ─────▶ [08 법·정책 ◀ 현재]
         │                       │                         ▲
         │                       ▼                         │
         ├────────────▶ [03 데이터] ──────────────────────┤
         │                  │                             │
         │                  ├────▶ [07 AI·디지털서비스] ──┤
         │                  │                             │
         └────▶ [04 컴퓨터시스템] ─▶ [05 네트워크] ─▶ [06 보안]
```

- 전체 흐름: 전략과 사업이 기술을 선택하고, **08 법·정책**은 권리·의무·책임·증거 기준으로 전 과목을 통제
- 현재 위치: 개인정보·AI·데이터·공공서비스·조달 규범을 기술 아키텍처와 운영 통제로 번역하는 최종 검증축

## 08 법·정책 과목 확대 지도

```text
[헌법상 기본권·산업정책 목표]
             │
             ▼
[법률] ──▶ [시행령·고시] ──▶ [가이드라인·표준]
             │
             ▼
┌──────────── 영역별 규율 ────────────┐
│ AI 신뢰·윤리 │ 개인정보·데이터 │ 공공 디지털서비스 │
│ SW·조달      │ 통신·플랫폼     │ 국제규범·인증     │
└────────────────────────────────────┘
             │
             ▼
[범위판정] → [요건설계] → [구현] → [증적·감사] → [구제·개선]
```

선의 의미: 상위 법률의 권리·의무를 하위 기준과 기술·관리 통제로 구체화하고, 운영 증적으로 준수를 입증함

### 30초 인출

```text
AI      → 윤리기준·기본법·고영향 AI·투명성
Privacy → 보호법·안전조치·가명정보·전송요구권
Data    → 데이터산업법·안심구역·주권·EU Data Act
Public  → 지능정보화·접근성·포용·UI/UX·공공 SaaS
SW조달  → SW진흥법·분리/단계발주·협상계약·SLA
통신    → 망중립성·망법·디지털플랫폼 규율
```

- 본질: **기술 위험과 산업 활성화 사이에서 권리·의무·책임을 정하고 이를 실행 가능한 통제로 변환하는 과목**
- 시점 표기: 개정 가능한 법령·시행령·고시는 반드시 기준일과 현행 공식 원문을 함께 기록

## 영역별 로드맵

| 영역 | 핵심 질문 | 대표 토픽 | 주요 통제 |
|---|---|---|---|
| **AI 신뢰·윤리** | 위험수준별 의무와 기본권 보호는 무엇인가 | AI 윤리기준, AI기본법, 고영향 AI, 투명성 | 위험관리·설명·사람 감독·문서화 |
| **개인정보** | 적법한 처리와 정보주체 권리는 어떻게 보장하는가 | 개인정보보호법, 안전성 확보조치, 가명정보, CPO | 목적·최소수집·안전조치·권리 대응 |
| **데이터 활용** | 안전한 결합·분석·거래 조건은 무엇인가 | 안심구역, 데이터산업법, 마이데이터, 데이터 주권 | 접근격리·반출통제·권리·계보 |
| **공공 디지털** | 누구나 안정적으로 이용 가능한가 | 접근성, 디지털포용, 공공 SaaS, UI/UX, SLA | 접근성·가용성·연속성·사용성 |
| **SW·조달** | 공정한 발주와 과업·대가 기준은 무엇인가 | SW진흥법, 분리발주, 단계발주, 협상계약 | 요구추적·중립성·평가·계약 증적 |
| **통신·플랫폼** | 연결과 플랫폼 권한을 어떻게 규율하는가 | 망중립성, 정보통신망법, 다크패턴 | 비차별·이용자 보호·투명성 |
| **국제규범** | 역외 규율과 국경 간 이전을 어떻게 대응하는가 | EU AI Act, EU Data Act, CBPR | 적용범위·이전근거·상호운용·인증 |

## 학습단계와 누적 회독

| 등급 | 의미 | 회독 필터 |
|---|---|---|
| **기초** | 핵심 코어의 기본 개념 | 기초 |
| **서브** | 코어와 함께 이해할 주요 주변 요소 | 기초+서브 |
| **응용** | 코어를 전제로 한 파생·적용 요소 | 기초+서브+응용 |

- 전체 키워드를 보존하며 회독 필터는 `기초 ⊂ 기초+서브 ⊂ 기초+서브+응용`의 누적 포함 관계로 동작한다.

## 일반 학습 원칙

- 법령은 적용대상, 권리·의무, 기술·관리 통제의 관계로 이해한다.
- 개정 가능한 법령·고시는 국가법령정보센터와 소관기관의 현행 원문으로 확인한다.
- 국내외 제도는 적용범위와 책임 주체, 집행 방식의 같은 기준으로 비교한다.
