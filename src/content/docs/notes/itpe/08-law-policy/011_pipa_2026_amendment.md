## Ⅰ. 개인정보 보호법 2026년 개정 과징금의 개요

- 개념 : 개인정보 보호법 제64조의2는 일반 위반의 과징금과 반복·중대한 위반에 대한 특례를 구분하는 행정 제재 체계.
- 적용 시점 : 법률 제21445호의 과징금 관련 개정은 2026년 9월 11일 시행.
- 핵심 구분 : **일반 상한** 3%와 **특례 상한** 10%는 전체 매출액 기준의 법정 상한. 모든 유출 사고에 10%를 자동 부과한다는 의미가 아님.

## Ⅱ. 특례 요건과 산정 구조

| 구분 | 법정 내용 | 해석 시 주의점 |
|---|---|---|
| 일반 과징금 | 전체 매출액의 3% 이하, 매출 미산정 등에 대한 정액 상한 20억원 | 제1항의 해당 위반행위 확인 필요 |
| 반복 위반 특례 | 과징금 처분일부터 3년이 지나기 전 같은 호의 위반 반복, 각 위반에 고의·중과실 | 단순한 모든 종류의 재위반과 구분 |
| 대규모 피해 특례 | 고의·중과실 위반과 정보주체 피해 1천만명 이상 | 피해 규모와 귀책 요건 함께 확인 |
| 시정명령 불이행 특례 | 시정명령 불이행으로 제1항 제9호 위반 발생 | 명령 불이행과 해당 사고의 관계 확인 |
| 특례 상한 | 전체 매출액의 10% 이하, 매출 미산정 등에 대한 정액 상한 50억원 | 상한과 실제 부과액 구분 |

- **산정 매출액** : 전체 매출액에서 위반행위와 관련 없는 매출액을 제외한 금액 기준. 자료를 정당한 사유 없이 거부하거나 허위 제출한 경우 전체 매출액 기준 산정·추정 가능.
- **비례성과 예방 효과** : 위반 내용·정도·기간·횟수, 이익, 피해 규모와 회복, 보호 노력 및 협조 등을 고려하여 실제 부과액 결정.
- **투자 감경** : 예산·인력·설비·장치 등의 투자·운영에 관한 대통령령상 사유가 있으면 감경하되 고의·중과실 위반은 제6항의 감경 대상에서 제외. 모든 감경 규정이 일률적으로 사라진다고 확대 해석하지 않도록 구분.

## Ⅲ. 법적 기준과 기술 대응의 연결

| 관리 항목 | 필요한 증거 | 기술·조직 대응 |
|---|---|---|
| 위반 관련 매출 | 사업·상품·처리 목적별 자료 | 회계 자료와 개인정보 처리 흐름 연결 |
| 예방 투자 | 실제 투자·운영 및 개선 이력 | 위험평가, 보안조치, 담당 인력과 책임 기록 |
| 사고 대응 | 피해 확인·확산 방지·통지·복구 이력 | 로그 보존과 사고 대응 절차 연결 |
| 재위반 방지 | 처분·시정명령·개선 결과 | 기한과 조치 이행 상태 점검 |

- 네트워크나 데이터베이스를 분리하는 것만으로 위반 무관 매출이 입증되지는 않음. 인증 보유도 감경을 자동 보장하지 않으므로 실질적인 이행 증거 관리 필요.

## Ⅳ. 개정 과징금 대응의 한계점 및 해결 방안

- 법정 상한과 예상 처분액의 혼동 : 특례 해당 여부와 산정·가중·감경 단계 구분.
- 보호 노력의 사후 소명 어려움 : 사고 이전부터 투자·운영·개선 기록을 일관되게 보존.
- 법적 판단을 기술 구성으로 대체하는 오류 : 위반행위와 처리 목적·매출의 관련성을 자료로 확인하고 기술·회계·법무 담당자의 검토 결합.

## Ⅴ. 개인정보 보호 책임 강화를 위한 제언

- 과징금 최소화보다 침해 예방과 피해 회복을 중심으로 관리체계 운영.
- 시정조치 책임자와 이행 기한을 명확히 하고 법령·하위 규정의 적용 시점과 실제 보호 활동을 함께 점검.
