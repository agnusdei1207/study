## 연관 키워드

- 데이터 산업진흥 및 이용촉진에 관한 기본법, 데이터 산업법, 국가데이터정책위원회, 데이터안심구역, 데이터거래사
- 데이터 가치평가, 데이터 품질인증, 부정사용 금지, 가명정보, 개인정보 보호법, 합성 데이터

## Ⅰ. 데이터산업법의 개요

- 핵심 요약 : 데이터의 생산·거래·활용을 촉진하기 위해 범정부 거버넌스와 거래 인프라를 정한 데이터 분야 기본법.
- 개념 : 「데이터 산업진흥 및 이용촉진에 관한 기본법」(약칭 **데이터기본법**)으로, 데이터의 생산·유통·활용 기반을 조성하는 법률.
- 배경 및 필요성 : 데이터에 대한 배타적 소유권이 명확하지 않고 원천 데이터의 개인정보·저작권 문제가 있어, 거래 신뢰를 세울 제도적 장치가 필요해짐.
- 주요 목적 : 데이터 기반 산업 육성, 데이터 거래와 유통 생태계 조성, 데이터 활용 역량 확대.
- 연혁 : 2021년 10월 제정되어 2022년 4월 20일부터 시행됨(시행령 동시 시행).

## Ⅱ. 데이터산업법의 특징 및 장점

- 핵심 요약 : 범정부 정책 기구, 데이터 부정사용 금지, 거래 전문 인력 제도가 결합되어 데이터 거래 신뢰를 높이는 구조.

1. 범정부 컨트롤타워 : 국무총리를 위원장으로 하는 국가데이터정책위원회가 데이터 정책을 총괄 → 부처 간 정책 분산을 줄임.
2. 데이터 자산 보호 : 상당한 투자와 노력으로 생성된 데이터의 무단 취득·사용·공개를 부정사용으로 규정 → 데이터 공급자의 투자 회수 기반 마련.
3. 안전한 활용 공간 : 데이터안심구역에서 미개방 데이터를 분석하고 통계 결과만 반출하는 방식 → 개방과 보호를 함께 확보.
4. 거래 전문 인력 : 데이터거래사 제도로 공급자와 수요자 사이의 중개·계약 기능을 제도화 → 거래 과정의 불확실성 감소.

## Ⅲ. 데이터산업법의 구조 (흐름)

- 핵심 요약 : 범정부 정책 결정 아래에서 공급자와 수요자가 거래 기관을 거쳐 거래하고, 민감 데이터는 안심구역에서 활용되는 구조.
- 데이터안심구역 : 미개방 데이터를 보호된 환경에서 분석하게 하고, 심사를 거친 결과만 외부로 반출하는 공간.
- 데이터 가치평가 : 데이터의 경제적 가치를 공인된 전문기관이 평가하도록 하는 제도.

```text
[ 국가데이터정책위원회 (위원장: 국무총리) ]
          │ 데이터 정책 심의·조정
          ▼
[ 과학기술정보통신부·행정안전부 ]
          │ 관계 부처 시행
          ▼
[ 데이터 공급자 ] ↔ [ 데이터 수요자 ]
          │ 데이터거래사 중개·계약
          ▼
[ 민감 데이터 ] ──> [ 데이터안심구역 ]
                    분석 후 결과만 반출
```

```text
[ 데이터 가치평가 접근법 ]
비용 접근법 ─ 수집·정제 비용 기준
시장 접근법 ─ 유사 거래 사례 기준
수익 접근법 ─ 미래 수익의 현재가치 기준
```

## Ⅳ. 데이터산업법의 비교

- 핵심 요약 : 데이터산업법은 거래와 활용을, 공공데이터법은 개방을, 개인정보 보호법은 개인의 권리 보호를 목적으로 함.

| 비교 축 | 데이터산업법 | 공공데이터법 | 개인정보 보호법 |
| --- | --- | --- | --- |
| 입법 목적 | 데이터 산업 진흥과 이용 촉진 | 공공데이터의 개방과 이용 | 개인정보 보호 |
| 적용 대상 | 산업 데이터 전반 | 공공기관이 보유한 데이터 | 살아 있는 개인의 개인정보 |
| 주요 수단 | 거래 기관, 안심구역, 가치평가 | 공공데이터 개방 포털 | 동의, 가명정보 처리 요건 |

- 선택 기준 : 데이터가 공공 개방 대상인지, 거래 대상인지, 개인정보를 포함하는지에 따라 적용 법률을 달리 판단함.

## Ⅴ. 데이터산업법의 한계와 방안

- 핵심 요약 : 소유권 불명확, 원천 데이터 위험, 가치평가 주관성을 표준 계약과 안심구역 기술로 보완해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 데이터 소유권의 불명확성 | 배타적 권리가 없어 재판매와 귀속 분쟁 발생 | 계약 기반 데이터 이용권 표준 계약 보급 | 표준 계약 채택률, 분쟁 건수 |
| 비정형 원천 데이터의 개인정보·저작권 위험 | 포함된 개인정보와 저작물로 거래 위축 | 안심구역 내 익명화 기술 적용, 합성 데이터 활용 | 반출 심사 반려율 |
| 가치평가의 주관성과 거래 이력 부족 | 평가 신뢰도 저하로 담보 가치 인정 곤란 | 실거래 사례 축적과 공정한 평가 기준 공표 | 거래 사례 축적 건수 |

## Ⅵ. 데이터산업법에 대한 기술사적 제언

- 핵심 요약 : 품질 검증, 공정한 가치 산정, 안전한 활용 환경을 거래 절차에 내장하는 데이터 거래 아키텍처의 확립.

데이터 거래소는 품질 인증과 안심구역 이용 절차를 거래 등록 단계에 연결하여, 검증되지 않은 데이터가 거래되지 않도록 하는 것이 바람직하다. 표준 이용 계약 조항을 거래소 시스템에서 기본값으로 제공하고, 원본 데이터는 안심구역 밖으로 나가지 않도록 설계해야 한다.

## Ⅶ. 결론

- 핵심 요약 : 데이터산업법은 데이터 거래의 신뢰와 안전을 제도로 세우는 데이터 분야 기본법.
- 데이터의 가치는 거래가 신뢰될 때 실현되므로, 계약·검증·보호 장치가 함께 작동해야 함.
