## 30초 인출

- 본질: **데이터산업법** 은 정식 명칭 「데이터 산업진흥 및 이용촉진에 관한 기본법」으로 민간 중심의 데이터 생산, 거래, 유통 및 활용을 촉진하고 데이터 자산 가치를 제도적으로 인정·보호하는 기본법률
- 메커니즘: 국무총리 산하 국가데이터정책위원회를 컨트롤타워로 3년 주기 기본계획을 수립하고, 데이터자산 보호(부정사용 방지), 가치평가 및 품질인증, 데이터거래사 등록, 데이터안심구역 제도 집행
- 통찰: 배타적 물권으로서의 데이터 소유권 부재 및 원천 데이터의 저작권·개인정보 침해 리스크가 상존하므로 계약 기반 데이터 이용권(License) 표준화와 프라이버시 강화 기술(PETs) 결합 필수

<details><summary>핵심 용어</summary>

- **데이터산업법** : 민간 데이터의 경제적 가치를 창출하고 전 산업의 데이터 주도 혁신을 지원하기 위해 제정된 국가 기본법률.
- **국가데이터정책위원회** : 국무총리를 위원장으로 범정부 데이터 정책, 기본계획 및 규제 개선을 총괄 심의·의결하는 최고 거버넌스.
- **데이터자산** : 데이터 생산자가 상당한 인적·물적 투자와 노력을 투입하여 생성한 경제적 가치를 지닌 지적 자산.
- **데이터 가치평가** : 데이터의 기술성, 시장성, 사업성을 종합 분석하여 화폐적 가치(금액)로 산정하는 법정 평가 체계.
- **데이터거래사** : 데이터 거래 상담, 자문, 중개 및 알선 등 데이터 유통 전 과정을 전문적으로 지원하는 법정 전문자격.
- **데이터안심구역** : 미개방 민간·공공 데이터를 외부 유출 없이 안전하게 분석·활용할 수 있도록 하드웨어·소프트웨어 보안이 통제된 구역.

</details>

> 인공지능과 데이터 경제 시대의 국가 경쟁력 확보를 위해 제정된 「데이터 산업진흥 및 이용촉진에 관한 기본법」(데이터산업법)의 제정 배경 및 주요 법적 체계를 설명하고, 데이터 거래 활성화를 위한 '4대 핵심 제도'(가치평가·품질인증·거래사·안심구역)와 실무적 데이터 권리 충돌(소유권·개인정보) 해결 방안을 논하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 데이터산업법의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **데이터산업법** 은 공공과 민간의 데이터 생산·거래·활용을 촉진하고 데이터 산업의 성장 기반을 조성하기 위해 제정된 디지털 데이터 분야의 최상위 기본법률 |
| 목적 | 데이터 기반의 신산업 육성, 양질의 데이터 거래 유통 생태계 확립 및 국가 경제의 디지털 대전환 가속화 |

## Ⅱ. 데이터산업법의 4대 핵심 제도 및 법적 특징

| 구분 | 주요 제도 | 상세 특징 및 기술적·정책적 범위 |
|---|---|---|
| **데이터자산 보호** | 부정사용 방지 조치 (제12조) | 상당한 투자·노력으로 생성된 데이터를 무단 취득·사용·공개 시 부정경쟁방지법 준용 제재 |
| **가치평가 체계** | 가치평가기관 지정 (제14조) | 공인된 전문기관을 통해 데이터의 경제적 가치를 평가하여 금융 대출 및 현물 출자 지원 |
| **품질인증 제도** | 데이터 품질인증 (제20조) | 데이터의 정확성·유효성·완전성을 검증하여 공인 인증마크 부여 및 유통 신뢰도 확보 |
| **유통 전문인력** | 데이터거래사 제도 (제23조) | 법정 교육 및 자격을 갖춘 거래사를 육성하여 수요자-공급자 간 매칭, 계약, 가치 자문 전담 |
| **안전 분석 기반** | 데이터안심구역 지정 (제11조) | 원본 데이터 반출을 원천 차단하고 VDI 가상 데스크톱 환경에서 통계 결과만 반출 승인 |

## Ⅲ. 국가 데이터 산업 거버넌스 및 유통·거래 생태계 프로세스

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ 범정부 데이터 거버넌스 및 민간 데이터 유통·거래 파이프라인 ]             │
└─────────────────────────────────────────────────────────────────────────────┘
  [ 국무총리 소속 국가데이터정책위원회 ] ──> 범정부 데이터 기본계획(3년) 심의·의결
                 │
                 ▼
  [ 과학기술정보통신부 / 관계 중앙행정기관 ] ──> 연차별 시행계획 수립 및 재정 집행
                 │
        ┌────────┴──────────────────────────┐
        ▼                                   ▼
  [ 데이터 공급자 (기업/기관) ]         [ 데이터 수요자 (AI 개발사 등) ]
        │                                   │
        │ 1. 품질인증(K-Data) 및 가치평가    │ 2. 구매/라이선스 요청
        ▼                                   ▼
  ┌──────────────────────────────────────────────────────────────┐
  │ [ 데이터거래사(Broker) 중개 및 국가 데이터거래소 플랫폼 ]     │
  │  - 표준 데이터 계약서 체결 (목적 외 사용 금지, 라이선스 범위) │
  │  - 스마트 콘트랙트 기반 결제 및 데이터 정산 이행             │
  └──────────────────────────────────────────────────────────────┘
                 │
                 ▼ (민감 데이터의 경우)
  [ 데이터안심구역 (Safe Zone) ]
    ├── 망분리 VDI 서버 환경 내 안전한 적재
    ├── AI 알고리즘 모델 학습 및 분석 수행
    └── 반출 심사위원회를 통한 비식별 통계·가중치 모델만 외부 반출
```

```text
[ 데이터 가치평가 3대 표준 접근법 ]
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     1. 비용 접근법      │     2. 시장 접근법      │     3. 수익 접근법      │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ - 데이터 수집·정제비용   │ - 유사 데이터 거래 사례 │ - 미래 창출 예상 현금   │
│ - 대체 재구축 원가 산정 │ - 시장 호가 비교 분석   │ - 할인율 적용 현재가치  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

| 절차 단계 | 주요 수행 내용 | 핵심 산출물 및 기준 |
|---|---|---|
| **데이터 상품화** | 메타데이터 표준화, 결측치 정제 | 표준 데이터 명세서, 카탈로그 정의서 |
| **품질 심사** | DQC(데이터 품질인증) 심사 | 데이터 품질인증서 (Class Gold/Platinum) |
| **가치 평가** | 가치평가 모델 적용(수익/비용/시장) | 데이터 가치평가 보고서 (공인 평가액 도출) |
| **계약 체결** | 이용 범위, 재판매 금지, 면책 합의 | 표준 데이터 거래 계약서 (데이터거래사 날인) |
| **안전 분석** | 반출 데이터 재식별 위험도 검증 | 데이터 반출 심의 결과서, 반출 승인 데이터 |

## Ⅳ. 데이터산업법 vs 공공데이터법 vs 개인정보보호법 비교

| 비교 항목 | 데이터산업법 | 공공데이터법 | 개인정보 보호법 |
|---|---|---|---|
| **입법 목적** | 민간 데이터 산업 진흥 및 경제적 활용 | 공공데이터의 대국민 전면 개방 | 개인의 자유와 권리, 프라이버시 보호 |
| **적용 대상** | 모든 산업 데이터(정형/비정형, 지적자산) | 공공기관이 생성·취득한 공공데이터 | 살아있는 개인에 관한 모든 개인정보 |
| **핵심 권리** | 데이터자산의 부정사용 금지(보호) | 국민의 공공데이터 이용권 보장 | 정보주체의 자기결정권 및 열람·삭제권 |
| **유통 방식** | 유상 거래, 라이선스 계약, 중개 | 원칙적 무상 제공 (공공 개방 포털) | 가명정보 결합, 정보주체 동의/법적 근거 |
| **법적 성격** | 산업 진흥 특별법 / 경제 활성화 | 공공 서비스 행정법 | 기본권 보호 규제법 (위반 시 형사처벌) |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 물권법상 데이터 자체에 대한 독점적 소유권(Ownership) 부재로 인한 권리 귀속 분쟁 및 재판매 방지 한계 | 배타적 소유권 대신 '계약 기반 데이터 이용권(Data Right/License)' 표준 계약 가이드라인을 보급하고 블록체인 스마트 콘트랙트를 통한 사용 횟수·범위 암호학적 강제 |
| 원천 데이터셋에 포함된 비정형 텍스트·이미지 내 개인정보 및 저작권 침해 우려로 인한 거래 시장 위축 | 데이터안심구역 내 차분 프라이버시(Differential Privacy) 및 동형암호 기술 적용 의무화, 합성 데이터(Synthetic Data) 생성·거래 활성화 지원 |
| 데이터 가치평가 모델의 주관성 및 거래 이력 축적 부족으로 인한 평가 신뢰도 저하 및 금융권 담보 불인정 | 공공 데이터거래소 기반 실거래 가격 데이터베이스(DB)를 구축하고, 국가 보증기관(신보·기보)의 데이터 가치평가 연계 특례보증 펀드 확대 |

## Ⅵ. 제언

데이터 거래의 신뢰성과 안전성을 보장하기 위하여 데이터 품질인증과 안심구역을 데이터 거래소 파이프라인에 직결하고 표준 라이선스 계약을 자동화하는 데이터 경제 플랫폼 아키텍처 구축.

```text
[ 데이터 상품 등록 ]
          │
          ▼
[ 품질인증(K-Data) & 가치평가 자동 연동 ]
          │
          ▼
[ 표준 데이터 거래소 (Data Marketplace) ]
    ├── 일반 데이터 ────> 라이선스 계약 체결 후 API 토큰 발급 (다운로드)
    └── 민감/미개방 ────> [ 데이터안심구역 자동 프로비저닝 ]
                                  │
                                  ▼
                [ 안심구역 VDI 내 모델 학습 & 반출 심사 ]
```

| 구분 | 개별 기업 간 음성적 거래 | 제언: 제도 연계 표준 데이터 마켓플레이스 |
|---|---|---|
| **품질 검증** | 구매 전 품질 확인 불가 (레몬 마켓) | K-Data 공인 품질인증서 사전 첨부 의무화 |
| **가치 산정** | 공급자 중심의 자의적 고가 책정 | 공인 가치평가기관의 3대 접근법 기반 객관적 가치 |
| **보안 환경** | 원본 데이터 유출 및 불법 복제 위험 | 데이터안심구역 및 PETs 기반 원본 유출 원천 차단 |
| **거래 투명성** | 계약서 미비로 사후 분쟁 빈발 | 데이터거래사 중개 및 표준 라이선스 약관 적용 |

## 출제 이력과 검증 출처

- 과학기술정보통신부 「데이터 산업진흥 및 이용촉진에 관한 기본법」 (법률 제18476호)
- 과학기술정보통신부 「데이터 산업진흥 및 이용촉진에 관한 기본법 시행령」
- 한국데이터산업진흥원(K-DATA) 「데이터 품질인증(DQC) 및 데이터 가치평가 실무 가이드라인」
- 과학기술정보통신부 「데이터안심구역 지정 및 운영에 관한 지침」

## 연결 토픽

- 공공데이터법
- 가명정보 결합
- 데이터 가치평가
- 차분 프라이버시 (Differential Privacy)
