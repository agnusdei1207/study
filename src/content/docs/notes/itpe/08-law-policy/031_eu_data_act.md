## Ⅰ. EU Data Act의 개요

- **개념** : 스마트 기기 등 커넥티드 제품에서 생성되는 데이터에 대한 이용자의 접근·공유 권한을 법제화하고 클라우드 벤더 종속을 해소하는 유럽연합 규정.
- **제정 배경 및 필요성** : IoT 커넥티드 기기에서 생성되는 방대한 산업용 데이터가 소수 글로벌 제조사에 독점되는 불공정을 시정하고, 데이터에 접근할 권리를 기기 사용자와 서드파티 수리업체 등에 개방하여 공정한 데이터 경제 경쟁을 유도하기 위해 제정됨.
- **핵심 목적** : 제조사의 데이터 독점 해소, 애프터마켓(수리·유지보수) 경쟁 촉진 및 공정하고 개방적인 데이터 시장 생태계 조성.

## Ⅱ. EU Data Act의 법제도 체계 및 핵심 메커니즘

**EU Data Act**은 데이터 보유자가 보유한 기기 데이터를 사용자에게 실시간 무상 제공하도록 강제하고 제3자 전송권을 보장하며, 클라우드 전환 비용을 단계적으로 폐지(2027년 0원) 과정을 거쳐 상호 연동 및 단계별 법적·기술적 통제를 수행함.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ EU Data Act 커넥티드 제품 데이터 공유 및 클라우드 전환 파이프라인 ]  │
└────────────────────────────────────────────────────────────────────────┘

 [ 1. 커넥티드 제품 데이터 접근 및 공유 (B2B / B2C) ]
   [ 스마트 기기 / 산업 장비 ] ──(센서 데이터 생성: 시동, 연비, 결함 로그)
                 │
                 ▼
   [ 데이터 보유자 (제조사 플랫폼) ]
      ├── 기획 단계부터 데이터 직접 다운로드 포털 구현 (Design by Default)
      │      │ (사용자 직접 열람 및 다운로드: 무상)
      │      ▼
      │   [ 제품 소유자 / 이용자 ]
      │      │
      │      ▼ (이용자의 전송 지시)
      └── [ 제3자 서비스 업체 (독립 정비소, 보험사 등) ]
             - 원본과 동일한 품질의 기계 판독형 API 전송 (REST / JSON)
             - NDA 체결 및 경쟁사 복제 제품 개발 목적 활용 원천 금지

─────────────────────────────────────────────────────────────────────────

 [ 2. 클라우드 서비스 전환 (Cloud Switching) ]
   [ 고객 (전환 요청) ] ──> [ 기존 CSP A ] ──(30일 전환 절차 가동)
                                  │
                                  ▼ (데이터 및 디지털 자산 무손실 추출)
                            [ 신규 CSP B / 온프레미스 ]
                                  │
                                  ▼ (전환 비용 단계적 폐지)
                            - 2025~2026년: 실비 한도 감액 부과
                            - 2027년 1월부터: 전환 수수료 0원 (완전 무료화)
```

- **기기 데이터 접근권** : 사용자 무상 접근 보장 - 커넥티드 제품 사용자(B2B, B2C)에게 생성 데이터에 대한 **실시간, 무상, 직접 접근** 허용
- **제3자 데이터 공유** : 독립 수리업체 등 공유 - 사용자가 지정한 제3자(애프터마켓 서비스)에게 원본 품질 그대로 데이터 제공 의무화
- **영업비밀 보호 (특징)** : **비밀 유출 방지 장치** - 기기 데이터 공유 시 기술적 보호조치(NDA, DRM) 요구 가능, 영업비밀 침해 우려 시 거부
- **클라우드 전환 촉진** : **락인(Lock-in) 해소 (특징)** - 클라우드 사업자 교체 시 이전 지원 의무화 및 **전환 수수료 부담 완화**

## Ⅲ. EU Data Act의 세부 규정 및 국내외 제도 비교 분석

| 비교 항목 | EU GDPR (일반 데이터보호법) | EU Data Act (데이터법) |
|---|---|---|
| **주요 대상** | **개인정보 (Personal Data)** 에 한정 | **비개인 데이터(기계/센서 데이터) + 개인 데이터 전반** |
| **핵심 목적** | 정보주체의 기본권 보호 및 프라이버시 수호 | 데이터 재사용 활성화 및 공정한 산업 데이터 경쟁 촉진 |
| **접근 권한자** | 정보주체 본인 (자연인) | **제품의 소유자, 임차인, 사용자 (자연인 및 법인)** |
| **데이터 전송** | 개인정보 이동권(Portability) | 커넥티드 기기 데이터 직접 접근권 및 제3자 전송권 |
| **인프라 규제** | 개인정보 안전성 확보조치 | **클라우드 서비스 전환 촉진 및 전환 수수료 폐지** |
| **상호 관계** | 프라이버시 침해 시 GDPR 우선 적용 | GDPR을 보완하여 산업용 기계 데이터의 활용권 보장 |

- **제도적 정합성 및 대응 방향** : EU Data Act은 상기 비교 지표를 바탕으로 법적 규제 준수(Compliance) 요건과 엔터프라이즈 운영 효율성을 균형 있게 확보하고, 선제적인 관리체계를 수립해야 함.

## Ⅳ. EU Data Act의 주요 한계점 및 해결 방안

- **제조사의 핵심 지식재산권(IP) 및 영업비밀이 포함된 센서 로우 데이터 유출 위험** :
  - **한계점** : 제조사의 핵심 지식재산권(IP) 및 영업비밀이 포함된 센서 로우 데이터가 경쟁사로 유출될 위험.
  - **해결 방안** : 원시 신호에서 영업비밀을 마스킹하는 변환 필터를 거치고 엄격한 비밀유지협약(NDA) 위반 시 징벌적 배상 조항 강제.
- **클라우드 사업자마다 데이터 스토리지 규격이 달라 완전 무손실 전환 한계** :
  - **한계점** : 클라우드 사업자마다 데이터 스토리지 및 컨테이너 규격이 달라 실질적인 완전 무손실 전환 기술적 한계.
  - **해결 방안** : 오픈스택, OCI(Open Container Initiative) 기반 표준 클라우드 상호운용성 표준 프레임워크 준수 의무화.

## Ⅴ. EU Data Act 정착 및 실효성 확보를 위한 기술사적 제언

- **스마트 기기 펌웨어 단계부터 표준화된 데이터 추출 API 및 OAuth 2.0 인가 구현** : 기존의 제조사 내부 정비망만 데이터 독점 한계를 극복하기 위해 사용자가 공인 API 통해 실시간 무상 다운로드 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- **영업비밀 보호를 위한 센서 원시 데이터 실시간 마스킹 및 스마트 컨트랙트 제어** : 기존의 경쟁사 차단을 위해 서드파티 접근 불허 한계를 극복하기 위해 법정 요구에 따른 제3자 정비업체 즉각 개방 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- **OCI(Open Container Initiative) 기반 표준 클라우드 상호운용성 프레임워크 준수** : 기존의 자체 폐쇄 포맷으로 이관 불가능 한계를 극복하기 위해 표준 JSON/Parquet 포맷 및 컨테이너 이관 보장 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
