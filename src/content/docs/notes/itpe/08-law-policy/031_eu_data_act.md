## 30초 인출

- 본질: **EU Data Act** 는 커넥티드 제품 데이터의 공정한 접근·이용과 데이터 처리 서비스 간 전환 조건을 정한 EU 규정
- 메커니즘: 사용자는 쉽게 이용할 수 있는 제품 데이터를 받고 제3자와 공유할 수 있으며, 고객은 클라우드 전환 절차·비용 규칙에 따라 다른 서비스로 이동

<details><summary>핵심 용어</summary>

- **EU Data Act (Data Act)** : EU Regulation 2023/2854. 데이터 접근·이용과 데이터 처리 서비스 전환에 공통 규칙을 두는 규정.
- **커넥티드 제품 (Connected Product)** : 사용·환경 데이터를 획득·생성하고 전자통신 서비스 등으로 전달할 수 있는 물리적 제품.
- **쉽게 이용할 수 있는 데이터 (Readily Available Data)** : 데이터 보유자가 제품이나 관련 서비스에서 적법하게 획득·생성해 접근할 수 있는 제품·서비스 데이터.
- **전환 비용 (Switching Charges)** : 데이터 처리 서비스의 전환 과정에서 고객에게 부과될 수 있는 비용. 2027년 1월 12일부터 전환 비용 부과 금지.
- **데이터 처리 서비스 (Data Processing Service)** : 네트워크를 통한 주문형·광범위한 원격 접근으로 확장 가능하고 탄력적인 컴퓨팅 자원을 제공하는 서비스.

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EU Data Act** 는 데이터에 대한 공정한 접근·이용과 데이터 처리 서비스 간 전환 조건을 정한 EU 규정 |
| 목적 | 제품 데이터 이용 기회를 넓히고 데이터 처리 서비스 전환의 계약·기술·비용 장벽 완화 |

이 규정은 2023년 채택, 2024년 1월 11일 발효, 2025년 9월 12일부터 적용.

### Ⅱ. 제품 데이터 접근·공유

```text
┌───────────────────┐
│ 커넥티드 제품 이용 │
└─────────┬─────────┘
          │ 제품·관련 서비스 데이터 생성
          v
┌───────────────────┐      요청·동의       ┌──────────────────┐
│ 데이터 보유자      │ ──────────────────> │ 사용자 또는 제3자 │
└───────────────────┘                      └──────────────────┘
     쉽게 이용할 수 있는 데이터와 필요한 메타데이터 제공
```

사용자는 관련 제품·서비스의 쉽게 이용할 수 있는 데이터에 접근하고, 요청에 따라 제3자와 공유할 수 있다. 데이터 보유자는 해당 데이터와 해석에 필요한 메타데이터를 지체 없이 제공하며, 사용자를 위한 접근은 무료·안전·기계 판독 가능한 형식이 원칙. 연속·실시간 제공은 관련되고 기술적으로 가능한 경우.

### Ⅲ. 클라우드 전환 규칙

| 시기·조건 | 전환 비용 규칙 |
|---|---|
| 2024년 1월 11일~2027년 1월 11일 | 전환 과정에 직접 연결된 사업자 비용을 넘지 않는 감액 전환 비용 부과 가능 |
| 2027년 1월 12일부터 | 전환 과정에 대한 전환 비용 부과 금지 |

전환 계약에는 전환 시작 전 최대 통지기간 2개월과 표준 전환기간 최대 30일 명시. 30일이 기술적으로 불가능하면 제공자는 요청 후 14영업일 이내에 사유와 대체 기간을 통지하며 대체 기간은 최대 7개월.

제언: 제품 데이터의 권리·제공 범위와 클라우드 전환 비용·계약 조건을 각각 분리해 사전 점검.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **EU Data Act** 는 데이터에 대한 공정한 접근·이용과 데이터 처리 서비스 간 전환 조건을 정한 EU 규정 |
| 목적 | 제품 데이터 이용 기회를 넓히고 데이터 처리 서비스 전환의 계약·기술·비용 장벽 완화 |

이 규정은 2023년 채택되었으며 2025년 9월 12일부터 적용. 개인 데이터가 포함되면 GDPR 등 개인정보 보호 규정도 함께 적용.

## Ⅱ. 커넥티드 제품 데이터 접근권

```text
┌─────────────────┐
│ 제품·관련 서비스 │
└────────┬────────┘
         │ 사용자 데이터 생성·전달
         v
┌─────────────────┐  요청 시 제공   ┌───────────────┐
│ 데이터 보유자    │ ──────────────> │ 사용자        │
└────────┬────────┘                 └───────┬───────┘
         │ 사용자 요청·지정                  │ 이용자 요청에 따른 공유
         └──────────────────────────────────> v
                                     ┌───────────────┐
                                     │ 제3자          │
                                     └───────────────┘
```

규정의 대상은 모든 기기에서 새 데이터를 만들어 저장하라는 의무가 아니라, 제품 또는 관련 서비스에서 데이터 보유자가 쉽게 이용할 수 있는 데이터. 사용자는 데이터 보유자에게 접근을 요청하거나 제3자 제공을 요청할 수 있다. 제3자 제공은 목적 제한·비밀 보호 등 규정상 조건과 사용자의 요청을 전제로 함.

## Ⅲ. 제공 형식과 보호 장치

| 항목 | 규정상 핵심 |
|---|---|
| 제공 데이터 | 쉽게 이용할 수 있는 제품 데이터·관련 서비스 데이터와 필요한 메타데이터 |
| 제공 방식 | 지체 없는 접근, 데이터 보유자와 같은 품질, 안전하고 기계 판독 가능한 구조화 형식 |
| 비용·시점 | 사용자에게는 무료; 연속·실시간 제공은 관련되고 기술적으로 가능한 경우 |
| 보호 | 영업비밀 보호, 개인정보 보호 및 제3자 재사용 조건을 적용 |

따라서 원시 데이터의 무제한 공개나 모든 처리 결과의 제공으로 해석할 수 없다. 제공 대상과 영업비밀 조치는 법령 요건 및 구체적 계약에 따라 판단.

## Ⅳ. 데이터 처리 서비스 전환

```text
┌───────────────────┐
│ 고객의 전환 요청   │
└─────────┬─────────┘
          v
┌───────────────────┐
│ 계약·기술 조건 확인 │
└─────────┬─────────┘
          v
┌───────────────────┐      필요한 경우       ┌──────────────────┐
│ 데이터·디지털 자산 │ ───────────────────> │ 새 제공자·고객 환경 │
│ 이전 또는 반출     │                       └──────────────────┘
└───────────────────┘
          │
          └─ 전환 지원·서비스 종료 절차·상호운용성 조건 확인
```

데이터 처리 서비스 제공자는 고객 전환을 지원하고, 계약과 법정 절차에 따른 전환·계약 종료 방식을 제공해야 한다. 표준화된 인터페이스를 모든 제공자에게 동일하게 강제한다고 단정하지 않으며, 계약·서비스 종류별 기술 조건과 전환 난점을 사전에 공개하는 것이 핵심.

## Ⅴ. 비용 규칙과 기업 대응

| 전환 시기 | 허용 범위 | 기업 점검 항목 |
|---|---|---|
| 2027년 1월 12일 전 | 감액 전환 비용은 전환에 직접 연결된 비용 한도 내에서 부과 가능 | 계약상 수수료·비용 산정 근거와 고지 방식 |
| 2027년 1월 12일부터 | 전환 비용 부과 금지 | 표준 서비스료·조기해지 위약금과 전환 비용의 구별 |

법정 전환기간은 최대 30일이며 기술적으로 불가능한 경우에만 통지·사유 제시 후 대체 기간을 둘 수 있다. 이는 모든 고객의 원활한 전환이나 무중단 서비스를 보장하는 조항이 아님.

사업자는 전환 관련 정보와 비용을 사전에 계약·서비스 설명에 명확히 제시할 필요. 전환 비용 금지는 일반 서비스 이용료나 조기 종료 위약금의 일괄 폐지를 뜻하지 않으므로 항목별 법적 성격 확인.

| 접근 관리 | 사용자 인증·요청 권한·제3자 제공 요청의 기록 |

| 전환 준비 | 데이터·디지털 자산 반출, 계약 종료, 기술적 난점의 사전 안내 |
| 보호 | 개인정보·영업비밀·목적 제한과 접근 통제 |
