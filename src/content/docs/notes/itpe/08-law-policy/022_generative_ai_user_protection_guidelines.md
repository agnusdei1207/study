## 지식 로드맵 내 현재 위치

인공지능 정책·이용자 보호 → 서비스 신뢰·권익 → 생성형 인공지능 서비스 이용자 보호 가이드라인

## 30초 인출

- 본질: 생성형 인공지능 서비스 이용자 보호 가이드라인은 개발사·서비스 제공자의 이용자 피해 예방을 돕는 자율 실천 지침
- 메커니즘: 인격권·설명·안전·공정성 원칙을 입력 데이터, 생성·제공, 책임·피해 해결과 유통 단계의 실행 방식으로 구체화

<details><summary>핵심 용어</summary>

- **생성형 인공지능(Generative Artificial Intelligence) 서비스**: 이용자 입력을 바탕으로 텍스트·음성·이미지 등 새 콘텐츠를 생성하는 서비스.
- **이용자 인격권**: 서비스 이용자의 개인정보·명예·사생활 등 인격적 권리.
- **입력데이터 관리**: 이용자가 입력한 정보의 수집·이용·보관과 학습 활용을 적절히 안내·통제하는 조치.
- **자율 가이드라인**: 법률상 강제 의무와 구별되는 사업자 참고·실천 기준. 같은 주제에 별도 법적 의무가 있으면 해당 의무도 준수 필요.
</details>

## 1교시 10점 답안

### Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 인공지능 서비스 이용자 보호 가이드라인**은 개발사·서비스 제공자의 이용자 보호를 돕는 자율 실천 지침 |
| 목적 | 생성형 인공지능 이용 과정의 피해를 줄이고 이용자 권리·신뢰를 높이는 기준 제시 |

### Ⅱ. 기본원칙과 실행 방식

| 기본원칙 | 실행 방식 예 |
|---|---|
| 인간의 존엄성·자유·권리와 인간의 통제 | 이용자 인격권 보호, 입력 데이터의 책임 있는 관리 |
| 알기 쉬운 설명 | 결정·생성 과정과 서비스 특성에 대한 안내 노력 |
| 안전성 | 위험 관리·피해 해결을 위한 책임과 참여 |
| 공정성 | 다양성 존중, 생성 콘텐츠의 건전한 유통·배포 |

### Ⅲ. 기술사적 제언

가이드라인 실천 항목과 법률상 의무를 구분한 서비스별 점검표 운영.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **생성형 인공지능 서비스 이용자 보호 가이드라인**은 개발사·서비스 제공자의 이용자 보호를 돕는 자율 실천 지침 |
| 목적 | 생성형 인공지능 이용 과정의 피해를 줄이고 이용자 권리·신뢰를 높이는 기준 제시 |

2025년 2월 발표된 지침으로, 기본원칙 네 가지와 실행 방식 여섯 가지를 제시. 법정 의무 자체와는 구분하되 동일 사안의 별도 법률상 의무는 함께 준수.

| 위험 | 보호 방향 |
|---|---|
| 인격권 침해·설명 부족·안전 문제·차별 | 권리·안전·설명·공정성을 서비스 전 과정에 반영 |

## Ⅱ. 네 가지 기본원칙

| 원칙 | 의미 |
|---|---|
| 존엄성·자유·권리와 인간 통제 | 이용자 권리를 보호하고 적절한 인간 감독 가능성을 고려 |
| 알기 쉬운 설명 | 시스템 작동·결과·이용자 영향에 관한 설명 제공 |
| 안전 | 예상치 못한 피해와 악의적 이용·변경을 줄이는 운영 |
| 공정 | 이용자에게 차별 또는 불공정한 결과가 생기지 않도록 관리 |

## Ⅲ. 여섯 가지 실행 방식

| 번호 | 실행 방식 |
|---|---|
| 1 | 이용자 인격권 보호 |
| 2 | 서비스 결정 과정을 알리려는 노력 |
| 3 | 다양성 존중 노력 |
| 4 | 입력데이터 수집·활용 과정에서의 관리 |
| 5 | 문제 해결을 위한 책임과 참여 |
| 6 | 생성 콘텐츠의 건전한 유통·배포를 위한 노력 |

## Ⅳ. 서비스 전 과정 적용

```text
입력 데이터 수집·이용 안내와 관리
                  ↓
생성·제공 과정의 권리·안전·공정 검토
                  ↓
이용자 설명과 책임 주체 확인
                  ↓ 피해·오류 접수
문제 해결·개선 절차 운영
                  ↓
생성 콘텐츠의 건전한 유통 지원
```

## Ⅴ. 실행 책임과 운영 통제

| 주체·기능 | 적용 |
|---|---|
| 개발사 | 모델·시스템의 인격권 침해 요소와 위험을 발견·통제하도록 노력 |
| 서비스 제공자 | 이용자 안내, 입력데이터 관리, 신고·문의와 문제 해결 절차 운영 |
| 공동 운영 | 역할과 책임 범위를 정하고 위험관리·점검 체계를 둠 |

가이드라인은 사업자의 자율 실천 방향. AI 기본법의 사전 고지·생성 결과 표시와 개인정보 보호법상 입력정보 처리 요건은 각각의 적용 조건에 따라 별도 준수.

## Ⅵ. 적용상 문제와 대응

| 한계 | 대응 |
|---|---|
| 입력 데이터가 서비스 개선·학습에 어떻게 쓰이는지 알기 어려움 | 수집 항목·목적·보유·학습 활용 여부를 분명히 안내하고 선택·통제 수단 제공 |
| 생성 결과가 권리 침해·차별을 일으킴 | 위험 영역을 점검하고 신고·삭제·정정과 이의 처리 절차 마련 |
| 자동 생성이라는 점이나 결과의 한계를 알기 어려움 | 서비스 맥락에 맞게 AI 활용 사실과 결과의 한계를 알리며 법정 표시와 정합성 확보 |
| 개발사와 제공자 사이에 피해 대응 책임이 불명확 | 계약·운영 절차에서 역할·연락·조사·개선 책임을 정리 |

## Ⅶ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 원칙이 선언에 머물러 제품 변경·사고 대응에서 이용자 보호 조치가 빠질 수 있음 | 여섯 실행 방식을 요구사항·시험·운영 절차에 연결하고 이용자 신고·편향·권리 침해 사례를 개선 작업과 책임자 점검으로 추적 |
