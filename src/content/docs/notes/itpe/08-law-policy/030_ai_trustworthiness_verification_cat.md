## 답안 골격
```text
[AI 신뢰성 검증 제도] ◀━━ 머리: Ⅶ 내 의견 (TTA 적대적 노이즈 시험 자동화와 MLOps 파이프라인 내 CAT 검증 도구 내재화)
 ┃
 ┣━ Ⅰ 개요 ───── 블랙박스 AI 시스템의 사회적 불신 해소를 위한 국가 공인 시험·검인증 제도(TTA)
 ┣━ Ⅱ 특징 ───── 4대 핵심 가치(안전성·투명성·견고성·공정성) 검증 · 시험성적서 및 인증마크 부여
 ┣━ Ⅲ 구조 ───── 검증 기준(4대 분야 요구사항) + 검증 도구(적대적 공격·편향 측정기) + 인증 거버넌스
 ┣━ Ⅳ 흐름 ───── 인증 신청 → 모델/데이터 제출 → 4대 지표 시험 평가 → 보완 조치 → CAT 인증서 발급
 ┣━ Ⅴ 비교 ───── AI 신뢰성 검증(CAT: 공학적 시험성적) vs AI 윤리기준(자율적 선언 지침)
 ┗━ Ⅵ 실무 ───── 생성형 AI 환각의 정량화 난제 / 평가 데이터셋 편향 / 스타트업 수수료 부담
```
- 필수 키워드: CAT(Conformity Assessment for AI Trustworthiness) · TTA · 안전성 · 투명성 · 견고성 · 공정성 · 적대적 공격
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 4대 검증 분야 구성표 → Ⅳ 절차 흐름도 / 25점 = Ⅰ~Ⅶ 전개, Ⅲ 4대 지표별 세부 시험 항목과 Ⅵ 실무 검증 기법 상세화
- 기출: 137회 1교시 8번 `AI 신뢰성 검인증 제도(CAT)를 설명하시오.` → Ⅰ·Ⅱ·Ⅲ·Ⅳ 전수

## 한 줄 본질
- 소프트웨어의 GS인증처럼 AI 모델이 해킹에 버티고 편향되지 않으며 설명 가능한지를 국가 시험기관(TTA)이 4대 지표로 직접 테스트해 품질을 공인하는 제도 → 공공·엔터프라이즈 납품 신뢰성 확보 / 모델 갱신 시마다 재인증 비용 발생

## 핵심 그림
```text
+-------------------- [ AI 신뢰성 검인증 제도(CAT) 4대 축 ] --------------------+

|  [ 1. 안전성 (Safety) ]                       [ 2. 견고성 (Robustness) ]       |

|                                                                                |
|  [ 3. 투명성 (Transparency) ]                 [ 4. 공정성 (Fairness) ]         |

|  - 모델 예측 결과의 설명가능성(XAI) 제공       Parity) 지표 검증               |
|  - 인공지능 활용 사실 고지 체계               - 보호 속성(성별·연령) 차별 방지|

```

## 핵심 용어
- CAT(Conformity Assessment for AI Trustworthiness): 과학기술정보통신부와 TTA가 구축한 인공지능 신뢰성 시험·인증 종합 체계
- 적대적 공격(Adversarial Attack): 사람 눈에는 보이지 않는 미세한 노이즈를 이미지나 텍스트에 섞어 AI 모델의 오분류를 유도하는 공격
- 동등 기회(Equal Opportunity): 서로 다른 보호 집단 간에 긍정 결과를 받을 자격이 있는 사람들의 참 긍정률(True Positive Rate)이 균등하게 보장되는 상태

## 핵심 통찰
- 윤리기준이 "지켜야 할 도덕률"이라면, CAT는 "그 도덕률을 코드로 지켰는지 숫자로 채점하는 공학적 시험(Testbed)"임
- 전통 SW 테스팅과 달리 AI는 입력 공간이 무한하므로, CAT 인증은 일반 테스트셋이 아닌 극단적 코너 케이스(Corner Cases)와 적대적 교란 기법을 주입해 검증함
- LLM 등 파라미터가 수시로 파인튜닝되는 모델의 경우, 한 번 인증을 받아도 가중치가 바뀌면 검증 효력이 상실되는 '지속적 검증(Continuous Verification)'이 과제임

## 이웃 토픽과 구분
- CAT 검인증 vs 소프트웨어 GS인증: GS인증 = 전통적 소프트웨어의 기능적합성, 신뢰성, 사용성 평가(ISO 25010) / CAT = 데이터 편향, 적대적 공격, XAI 등 AI 고유 특성 평가

## 문제·원인·대책
- 사례: 137회 기출 자율주행 객체 인식 AI 모델의 악천후 노이즈 주입 시 표지판 오인식 결함
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 카메라 렌즈 빗방울 노이즈 시 정지 표지판 인식 실패 | 학습 데이터 내 맑은 날씨 편중 및 가우시안 노이즈 내성 부재 | TTA 적대적 노이즈(Adversarial Perturbation) 주입 증강 학습 수행 | 견고성 점수 합격 및 안전성 확보 |
| 신용평가 AI의 특정 지역 거주자 대출 거절 편향 | 학습 피처 내 우편번호와 연체율 간의 비정상 상관관계 | 디바이어싱(Debiasing) 알고리즘 적용 및 보호 속성 간 불균형 보정 | 공정성 인증 기준 충족 |

## 이렇게 출제된다
- 제137회 1교시 8번: "AI 신뢰성 검인증 제도(CAT)를 설명하시오." → 요구 포인트: Ⅰ 제도 개념 + Ⅲ 4대 검증 분야(안전성, 투명성, 견고성, 공정성) + Ⅳ 시험 절차

## 내 의견
- [일회성 인증을 탈피하는 MLOps 연동 지속적 적합성 평가(Continuous CAT)] 소프트웨어가 매주 업데이트되는 애자일 환경에서 수개월 걸리는 정적 CAT 인증을 매번 받는 것은 불가능함 → 나라면: TTA의 CAT 테스트 케이스 스위트를 컨테이너화된 테스트 벤치로 제공받아 내부 MLOps 배포 파이프라인에 내재화하고, 모델 재학습 시마다 신뢰성 지표가 자동 채점되는 '자동화된 신뢰성 회귀 테스트' 체계를 도입
