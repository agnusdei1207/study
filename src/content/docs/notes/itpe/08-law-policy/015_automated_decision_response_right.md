## 30초 인출

- 본질: **자동화된 결정에 대한 정보주체의 권리** 는 사람의 실질적 개입 없이 인공지능 등 자동화 시스템으로 개인정보를 처리해 내린 결정에 대해 정보주체가 거부하거나 설명 및 재검토를 요구할 수 있는 법적 권리
- 메커니즘: 중대한 권리·의무에 영향을 미치는 결정 시 거부권을 행사하거나 결과 도출 기준 설명 및 의견 제출을 요구하고, 처리자는 30일 이내에 인적 개입 재처리 또는 조치 결과를 통지
- 통찰: 블랙박스 AI 알고리즘의 복잡성으로 인해 일반인이 이해 가능한 수준의 설명 생성과 30일 내 수기 재처리 병목이 발생하므로 XAI 기반 자동 설명 렌더링 및 인적 재심사 워크플로 체계 구축 필수

<details><summary>핵심 용어</summary>

- **자동화된 결정** : 개인정보 보호법 제37조의2에 따라 사람의 실질적 개입 없이 완전히 자동화된 시스템(AI, 알고리즘)으로 개인정보를 처리하여 내린 결정.
- **거부권 (Right to Opt-out)** : 자동화된 결정이 자신의 권리 또는 의무에 중대한 영향을 미치는 경우 해당 결정을 거부할 수 있는 권리.
- **설명요구권 (Right to Explanation)** : 자동화된 결정의 결과, 산출 기준, 사용된 주요 개인정보의 유형 등에 대한 설명을 요구할 수 있는 권리.
- **검토요구권** : 정보주체가 의견을 진술하거나 추가 자료를 제출하여 결정의 재검토를 요청할 수 있는 권리.
- **인적 개입 (Human Intervention)** : 거부 또는 재검토 요구 시 담당 직원이 직접 개입하여 자동화된 결정을 재심사하고 결과를 수정·확정하는 절차.

</details>

## 2~4교시 예상문제 (25점)

> 개인정보 보호법 제37조의2에 규정된 '자동화된 결정에 대한 정보주체의 권리'의 법적 의의와 권리 유형(거부권, 설명·검토요구권)을 설명하고, 개인정보처리자의 30일 이내 조치 의무 및 인적 개입을 지원하는 기술적 아키텍처를 논하시오. (예상·25점)

## 2~4교시 25점 답안

## Ⅰ. 자동화된 결정에 대한 정보주체의 권리의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **자동화된 결정에 대한 정보주체의 권리** 는 인공지능 등 자동화된 시스템에 의해 이루어진 결정에 대해 정보주체가 거부하거나 그 이유의 설명 및 인적 재검토를 요구하는 권리 |
| 목적 | 알고리즘의 편향과 오류로부터 정보주체 보호, 인공지능 의사결정의 투명성 및 통제권 확보 |

## Ⅱ. 법정 권리 유형 및 예외 적용 특징

| 구분 | 핵심 법정 권리 및 요건 | 상세 특징 및 기술적 적용 기준 |
|---|---|---|
| **거부권 (Rejection)** | 결정의 효력 부인 요구 | 사람의 개입 없이 완전히 자동화되고, 권리·의무에 중대한 영향을 미치는 경우 성립 |
| | 처리자의 조치 의무 | 결정을 적용하지 않거나(미적용), **사람이 개입하여 재처리(재심사)** 필수 |
| **설명요구권 (Explanation)** | 판단 기준과 사유 공개 요구 | 결정의 최종 결과, 적용된 주요 판단 기준, 처리된 개인정보 항목에 대한 명확한 설명 |
| **검토요구권 (Review)** | 의견 진술 및 재평가 요구 | 정보주체가 추가 증빙을 제출하여 소명할 수 있는 기회 부여 및 재심사 반영 |
| **적용 제외 (특징)** | 법정 예외 및 타 법률 배제 | 계약 체결·이행에 필수적인 경우, 법률에 명시적 규정이 있는 경우, **행정기본법상 자동적 처분** |
| **사전 고지 의무** | 투명한 기준 사전 공개 | 자동화된 결정의 기준, 절차, 사용 정보, 권리 행사 방법을 인터넷 홈페이지에 상시 공개 |

## Ⅲ. 권리 행사 접수 및 인적 개입 재처리 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 자동화된 결정 대응권 접수 및 30일 이내 인적 재처리 E2E 워크플로 ]   │
└────────────────────────────────────────────────────────────────────────┘

 [ 정보주체 ] ── 자동화된 결정 통지 수령 (신용 대출 거절, 채용 서류 탈락 등)
       │
       ▼ (웹/모바일 포털을 통한 권리 행사 신청)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 개인정보처리자 권리 접수 게이트웨이 ]                               │
 │  ├── Step 1: 본인 인증 및 대상 결정 식별 (결정 일련번호 매칭)       │
 │  └── Step 2: 권리 유형 분류 (단순 설명 요구 vs 결정 거부/재검토)    │
 └──────────────────────────────────────────────────────────────────────┘
       │
       ├──[ 경로 A: 설명 요구 ]──────────────────────────────────────┐
       │     │                                                       │
       │     ▼                                                       │
       │  [ XAI 기반 설명 생성기 (SHAP/LIME) ]                       │
       │     │ - 판단 기준 지표, 입력 변수 기여도 자동 문서화        │
       │     ▼                                                       │
       │  [ 설명 통지문 발송 ]                                       │
       │                                                             │
       └──[ 경로 B: 거부 및 재검토 요구 ]                            ▼
             │                                              [ 30일 이내 ]
             ▼                                              [ 결과 통지 ]
          [ 인적 개입(Human-in-the-Loop) 재심사 티켓 발행 ]          │
             ├── 담당 심사역 지정 및 과거 결정 로그 조회             │
             ├── 정보주체 제출 소명 자료 검토                       │
             └── 사람이 직접 재심사 수행 (수동 오버라이드 승인)      │
             │                                                       │
             ▼                                                       │
          [ 재심사 최종 결과 및 사유 통지 ] ─────────────────────────┘
```

| 처리 절차 | 주요 엔지니어링 및 관리 조치 | 핵심 증적 및 산출물 |
|---|---|---|
| **1. 신청 접수** | 자동화 결정 추적 ID 기반 메타데이터 로깅 | 권리행사 접수증, 접수 대장 |
| **2. 대상성 검토** | 행정처분 여부, 계약 필수 여부 대조 (예외 심사) | 법적 예외 검토 의견서 |
| **3. 설명문 렌더링** | XAI 기법으로 복잡한 수식을 평이한 자연어로 변환 | 맞춤형 알고리즘 설명서 |
| **4. 인적 재처리** | 전문 심사역 전용 관리자 UI 제공, 수기 재평가 | 인적 재심사 의결서, 감사 로그 |
| **5. 기한 내 통지** | 30일 이내 조치 결과 전자문서/서면 정식 발송 | 처리 결과 통지서 (발송 로그 보관) |

## Ⅳ. 거부권과 설명·검토요구권의 비교

| 비교 항목 | 거부권 (Opt-out) | 설명요구권 (Explainability) | 검토요구권 (Human Review) |
|---|---|---|---|
| **행사 요건** | 권리·의무에 **중대한 영향** 초래 시 | 모든 자동화된 결정 대상 | 결정에 대한 이의 또는 추가 자료 존재 시 |
| **처리자의 조치** | 결정 미적용 또는 인적 개입 재처리 | 결정 이유, 주요 기준, 정보 유형 설명 | 제출된 의견 반영 여부 재검토 및 반영 |
| **기술적 구현** | 시스템 자동 처리 취소 및 수동 결재선 | XAI 대시보드 및 자연어 리포팅 | 심사역 검토 큐(Queue) 및 재평가 툴킷 |
| **예외 적용** | 계약 체결, 법률 규정 시 거부권 제한 | 정당한 사유 없는 한 반드시 설명 의무 | 정당한 사유(악의적 반복 등) 시 거절 가능 |
| **처리 기한** | 접수일로부터 **30일 이내** | 접수일로부터 **30일 이내** | 접수일로부터 **30일 이내** |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 딥러닝 블랙박스 알고리즘의 복잡성으로 인해 일반 이용자가 납득할 수 있는 인과적 설명 도출 한계 | SHAP 및 반사실적 설명(Counterfactuals: "연봉이 300만 원 높았다면 승인") 기법 표준화 |

## Ⅵ. 제언

자동화된 결정에 대한 신뢰성을 보장하기 위해 결정 시점의 입력 데이터, 모델 가중치, XAI 설명 결과를 불변 원장(WORM)에 기록하고 인적 재심사를 연계하는 통합 거버넌스 아키텍처 구축 필요.

```text
[ AI 자동화 결정 시스템 ]
          │ (결정 이벤트 발생: 모델 v2.1, 신용평점 620점, 거절)
          ▼
[ 불변 결정 감사 로그 (Decision Audit Lineage) ]
   ├── 입력 특성 벡터, 모델 체크포인트 해시, SHAP 기여도 저장
   └── WORM 스토리지에 3년간 위변조 방지 보관
          │
          ▼ (정보주체 이의제기 접수 시)
[ 심사역 전용 XAI 인터페이스 ]
   ├── 결정 당시의 SHAP 기여도 차트 렌더링
   └── 소명 자료 입력 시 가상 시뮬레이션(What-If Analysis) 제공
          │
          ▼
[ 심사역 수동 확정 및 30일 내 통지 ]
```

| 구분 | 기존 블랙박스 결정 | 제언: Lineage 기반 XAI & 인적 재심사 |
|---|---|---|
| **결정 추적성** | 모델 변경 시 과거 결정 재현 불가 | 결정 당시 모델·데이터 스냅샷 영구 보존 |
| **설명 제공** | 정형화된 약관 문구 기계적 발송 | 입력 변수별 영향도를 시각화한 맞춤형 XAI 리포트 |
| **인적 개입** | 담당자 임의 재량에 의존 | 표준 시뮬레이션 툴킷 기반 객관적 재심사 |
| **법적 안정성** | 30일 기한 위반 과태료 리스크 상존 | SLA 기반 실시간 티켓팅으로 기한 준수 보장 |
