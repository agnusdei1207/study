## Ⅰ. 가명정보(Pseudonymized Information)의 개요

- 개념 : **추가 정보** 사용·결합 없이는 특정 개인을 알아볼 수 없도록 조치하여 법정 목적 내에서 **동의 없이 처리** 가능한 개인정보.
- 제정 배경 및 필요성 : 데이터 활용과 프라이버시 보호의 조화를 위해, 추가 정보의 사용 없이는 특정 개인을 알아볼 수 없도록 처리한 가명정보 개념을 법제화하여 통계작성, 과학적 연구, 공익적 기록보존 목적의 안전한 **데이터 활용 특례**를 보장하기 위해 마련됨.
- 핵심 목적 : 데이터 프라이버시 보호와 데이터 경제 활성화(AI(Artificial Intelligence) 학습, 빅데이터 융합 분석) 간의 균형 달성.

## Ⅱ. 가명정보(Pseudonymized Information)의 법제도 체계 및 핵심 메커니즘

**가명정보** (Pseudonymized Information) : **사전준비·위험도 검토·가명처리·적정성 검토** 4단계를 거치며 복원용 추가 정보를 물리적·논리적으로 분리 보관하고 특정 개인 **재식별** 시도를 엄격히 금지 과정을 거쳐 상호 연동 및 단계별 법적·기술적 통제를 수행함.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 개인정보보호위원회 표준 가명정보 4단계 처리 및 결합 파이프라인 ]    │
└────────────────────────────────────────────────────────────────────────┘

 [ 1단계: 사전 준비 (Preparation) ]
    ├── 처리 목적의 적법성 검토 (통계/연구/기록보존 부합 여부)
    └── 대상 데이터셋 식별자(이름, 주민번호 등) 및 준식별자 분류
          │
          ▼
 [ 2단계: 위험도 검토 (Risk Assessment) ]
    ├── 데이터 자체의 고유 식별 위험도 평가 ($k$-익명성 수준 분석)
    └── 처리 환경의 안전성(폐쇄 분석망 여부, 반출 대상자 신뢰도) 평가
          │
          ▼
 [ 3단계: 가명처리 수행 (Pseudonymization) ]
    ├── 식별자: 완전 삭제 또는 일방향 해시 암호화 (Salt 주입)
    ├── 준식별자: 범주화(Grouping), 노이즈 추가, 라운딩, 마스킹 적용
    └── 추가 정보(복원 키) 생성 후 독립된 안전 스토리지로 분리 격리
          │
          ▼
 [ 4단계: 적정성 검토 및 사후관리 (Review & Management) ]
    ├── 전문가 검토위원회 구성 (재식별 가능성 및 과도 가명화 여부 심사)
    ├── 반출 승인 및 목적 범위 내 안전한 분석 활용
    └── 프로젝트 종료 시 가명정보 완전 파기 및 처리대장 기록 유지
```

- **처리 목적 특례** : 3대 법정 목적 한정 - **① 통계작성** (상업적 목적 통계 포함) **② 과학적 연구** (산업적 R&D 포함) **③ 공익적 기록보존**에 한해 동의 없이 처리 허용
- **제3자 제공 허용** : 가명 결합 및 제공 - 특정 개인을 식별할 수 없는 상태로 가명처리된 경우 정보주체의 별도 동의 없이 제3자 제공 가능
- **적용 배제 조항** : 정보주체 권리 제한 - 가명정보 처리에 대해서는 정보주체의 열람권, 정정·삭제권, 처리정지 요구권 적용 배제 (신속 연구 보장)
- 안전조치 의무 (특징) : **추가 정보 분리 보관** - 매핑 키, 삭제된 원본 식별자 등 '추가 정보'는 별도 분리 저장, 접근 권한 최소화
- **재식별 방지 조치** : 특정 개인 재식별 시도 행위 절대 금지, 식별 가능성 발견 즉시 처리 중단 및 회수·파기

## Ⅲ. 가명정보(Pseudonymized Information)의 세부 규정 및 국내외 제도 비교 분석

| 비교 항목 | 개인정보 (Personal Data) | 가명정보 (Pseudonymized Data) | 익명정보 (Anonymized Data) |
|---|---|---|---|
| 개념 정의 | 살아있는 개인을 알아볼 수 있는 원천 정보 | 추가 정보 없이는 개인을 알아볼 수 없는 정보 | 시간·비용을 투입해도 개인을 식별 불가능한 정보 |
| 법적 지위 | 개인정보 보호법 전면 적용 | 개인정보에 해당 (특례 적용) | 개인정보 보호법 적용 완전 제외 |
| 이용 동의 | 정보주체 사전 동의 필수 (원칙) | 통계·연구 목적 동의 없이 활용 가능 | 자유로운 상업적 이용 및 공유 가능 |
| 안전조치 의무 | 법정 안전성 확보조치 전면 적용 | 추가 정보 분리 보관, 재식별 금지 의무 | 법적 안전조치 의무 없음 |
| 정보주체 권리 | 열람, 정정, 삭제, 처리정지 전면 보장 | 열람·정정·삭제·전송요구권 적용 배제 | 권리 행사 대상 자체가 아님 |
| 식별 가능성 | 직접 식별 가능 | 추가 정보 결합 시 복원 가능 | 복원 불가능 |

- 제도적 정합성 및 대응 방향 : 가명정보는 상기 비교 지표를 바탕으로 법적 규제 준수(Compliance) 요건과 엔터프라이즈 운영 효율성을 균형 있게 확보하고, 선제적인 관리체계를 수립해야 함.

## Ⅳ. 가명정보(Pseudonymized Information)의 주요 한계점 및 해결 방안

- 이종 산업 간 다량의 가명데이터 결합 시 외부 정보 연결 공격(Linkage Attack) 위험 :
  - 한계점 : 이종 산업 간 다량의 가명데이터 결합 시 외부 공개 정보와의 연결 공격(Linkage Attack)에 의한 재식별 위험.
  - 해결 방안 : 차등 정보보호(Differential Privacy) 기법을 결합하여 수학적으로 개인 포함 여부를 숨기는 프라이버시 모델 적용.
- 의료 영상, 음성 등 비정형 데이터에 대한 식별자 분리 및 표준 가명화 기준 부재 :
  - 한계점 : 이미지, 의료 영상, 음성 등 비정형 데이터의 경우 정형 데이터와 달리 식별자 분리 및 가명화 표준 부재.
  - 해결 방안 : 합성데이터(Synthetic Data) 생성 기술 도입 및 비정형 데이터 특화 개인정보 안심구역 활용 의무화.

## Ⅴ. 가명정보(Pseudonymized Information) 정착 및 실효성 확보를 위한 기술사적 제언

- 원본 데이터 이동 없이 알고리즘만 전송하는 분산 연합학습(FL, Federated Learning) 결합 : 기존의 결합전문기관으로 원천 가명정보 집결 한계를 극복하기 위해 데이터 이동 없음 (알고리즘만 이동) 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- 수학적으로 개인 포함 여부를 은폐하는 차등 정보보호(Differential Privacy) 적용 : 기존의 결합키 탈취 시 대규모 유출 위험 한계를 극복하기 위해 데이터 자체가 격리되어 재식별 원천 차단 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- 비정형 데이터 특화 합성데이터(Synthetic Data) 생성 기술 및 안심구역 활용 : 기존의 반출 심사 지연으로 분석 주기 수개월 한계를 극복하기 위해 MLOps(Machine Learning Operations) 연계 실시간 모델 파인튜닝 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
