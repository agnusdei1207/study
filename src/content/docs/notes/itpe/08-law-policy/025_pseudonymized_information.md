## 연관 키워드

- 가명정보, 가명처리, 재식별 금지, 추가 정보 분리 보관, 결합전문기관
- 익명정보, 준식별자, 적정성 검토, 과학적 연구, 통계작성, 공익적 기록보존

## Ⅰ. 가명정보의 개요

- 핵심 요약 : 추가 정보 없이는 개인을 알아볼 수 없게 처리한 정보를 법정 목적 안에서 동의 없이 활용하도록 허용하는 데이터 특례 개념.
- 개념 : 추가 정보의 사용이나 결합 없이는 특정 개인을 알아볼 수 없도록 처리한 정보 (**가명정보**, Pseudonymized Information). 개인정보 보호법에 따라 통계작성, 과학적 연구, 공익적 기록보존 목적에 한해 정보주체의 동의 없이 처리할 수 있음.
- 배경 및 필요성 : 데이터 활용의 수요가 커지면서 프라이버시를 지키면서도 연구와 통계에 데이터를 쓸 제도적 통로가 필요해짐.
- 주요 목적 : 개인정보 보호와 데이터 활용(통계, 연구, AI 학습 등) 사이의 균형 확보.

## Ⅱ. 가명정보의 특징 및 장점

- 핵심 요약 : 식별자를 가리고 복원 정보를 분리하는 처리 방식이 활용 범위와 보호 수준을 함께 높이는 구조.

1. 동의 없는 목적 활용 : 3대 법정 목적에 한해 처리 허용 → 연구와 통계의 데이터 접근성 향상.
2. 추가 정보 분리 : 복원용 키를 별도 보관하고 접근을 최소화 → 외부 유출 시 개인 식별 위험 감소.
3. 재식별 금지 : 특정 개인을 알아보려는 시도를 금지하고 위반 시 제재 → 특례의 남용 방지.
4. 권리 행사 예외 : 열람, 정정, 삭제, 처리정지 요구에 대한 예외 적용 → 분석 데이터의 안정적 유지.

## Ⅲ. 가명처리의 단계와 통제 흐름

- 핵심 요약 : 사전 검토, 가명처리, 적정성 검토, 사후 관리가 순서대로 이어지며 각 단계에서 재식별 위험을 낮추는 구조.

```text
[ 가명처리 4단계 ]

사전 검토 (목적 적합성, 데이터 범위)
   ↓
가명처리 (식별자 삭제·변환, 준식별자 범주화)
   ↓
적정성 검토 (재식별 가능성, 과도 가명화)
   ↓
사후 관리 (반출 통제, 목적 종료 후 파기)
```

```text
[ 추가 정보 분리 원칙 ]

가명정보 (분석 환경)
   ↓ 분리 보관
추가 정보 (복원 키, 원본 식별자)
   ↓ 접근 권한 최소화
잠금 관리 (접근 기록 보존)
```

- 준식별자는 나이, 지역처럼 단독으로는 식별하기 어려우나 다른 정보와 결합하면 개인을 좁힐 수 있는 항목으로, 범주화나 마스킹 등으로 처리함.

## Ⅳ. 개인정보, 가명정보, 익명정보의 비교

- 핵심 요약 : 가명정보는 개인정보의 특례이며, 익명정보와 달리 추가 정보 결합에 따라 다시 개인정보가 될 수 있는 중간 지위.

| 비교 항목 | 개인정보 | 가명정보 | 익명정보 |
| --- | --- | --- | --- |
| 개념 | 살아 있는 개인을 알아볼 수 있는 정보 | 추가 정보 없이는 개인을 알아볼 수 없는 정보 | 합리적 수단으로 개인을 알아볼 수 없는 정보 |
| 법적 지위 | 개인정보 보호법 전면 적용 | 개인정보에 해당하되 특례 적용 | 개인정보 보호법 적용 대상 아님 |
| 활용 동의 | 원칙적으로 동의 필요 | 법정 목적에 한해 동의 없이 활용 | 제한 없이 활용 가능 |
| 안전조치 | 전면 적용 | 추가 정보 분리, 재식별 금지 | 법적 의무 대상 아님 |
| 재식별 가능성 | 직접 식별 가능 | 추가 정보 결합 시 가능 | 복원 불가능 |

- 선택 기준 : 목적이 연구·통계이고 원자료를 유지해야 하면 가명정보, 식별 가능성을 완전히 없애야 하면 익명정보를 택함.

## Ⅴ. 가명정보 처리의 한계와 방안

- 핵심 요약 : 데이터 결합에 따른 재식별 위험과 비정형 데이터의 처리 기준 부재를 결합 통제와 기술 보완으로 메움.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 결합에 따른 재식별 | 외부 공개 정보와 연결하면 개인이 좁혀짐 | 결합은 지정된 결합전문기관에서만 수행하고 반출을 통제 | 결합 건수, 반출 승인률 |
| 비정형 데이터 처리 기준 부족 | 영상·음성은 식별자 분리가 어려움 | 정형 데이터보다 엄격한 적정성 검토와 안전한 분석 환경 활용 | 적정성 검토 통과율 |
| 과도한 가명화에 따른 활용성 저하 | 필요 이상의 처리로 분석 가치 감소 | 목적별 처리 수준을 정하고 검토 위원회에서 조정 | 분석 가능 변수 비율 |

## Ⅵ. 가명정보 활용에 대한 기술사적 제언

- 핵심 요약 : 법정 목적과 처리 절차를 기술 설계에 내장하고, 결합과 반출을 통제 가능한 분석 환경 안에서만 허용하는 체계로 운영.

데이터 보유 기관은 가명처리 과정을 자동화하고, 복원 키를 분석 환경과 물리적으로 분리하여 접근 기록을 남기는 구조를 기본으로 갖추어야 한다. 정책 측면에서는 결합과 반출 승인의 기준을 공개해 기관과 연구자가 같은 기준으로 판단하도록 하는 것이 바람직하다. 이러한 설계는 재식별 금지 의무를 실제 통제로 바꾸는 방안이 된다.

## Ⅶ. 결론

- 핵심 요약 : 가명정보는 활용과 보호를 함께 달성하기 위해 추가 정보 분리와 재식별 금지를 전제로 한 제한적 데이터 특례.
- 활용의 폭은 목적의 명확성과 결합 통제의 실효성에 따라 넓어지므로, 기술과 절차를 함께 설계하는 것이 중요함.
