## 지식 로드맵 내 현재 위치

<div class="itpe-topic-path" aria-label="지식 경로"><span>개인정보 보호</span><span>가명정보 처리 특례</span><strong>가명정보(Pseudonymized Information)</strong></div>

## 30초 인출

- 본질: **가명정보** 는 추가 정보의 사용 없이는 특정 개인을 식별할 수 없도록 가명처리하여 통계작성, 과학적 연구, 공익적 기록보존 목적으로 정보주체 동의 없이 활용할 수 있는 개인정보
- 메커니즘: 사전준비, 위험도 검토, 가명처리, 적정성 검토의 4단계를 거치며 복원용 추가 정보를 물리적·논리적으로 분리 보관하고 특정 개인 재식별 시도를 엄격히 금지
- 통찰: 외부 공공데이터와의 연결 공격(Linkage Attack)을 통한 재식별 위험 및 영상·음성 등 비정형 데이터 가명화 한계가 있으므로 차등 정보보호(DP) 및 합성데이터(Synthetic Data) 결합 체계 구축 필수

<details><summary>핵심 용어</summary>

- **가명정보 (Pseudonymized Data)** : 개인정보의 일부를 삭제하거나 대체하여 추가 정보 없이는 특정 개인을 알아볼 수 없도록 처리한 정보.
- **추가 정보 (Additional Information)** : 가명정보를 원래의 개인정보 상태로 복원하거나 특정 개인을 식별하는 데 사용될 수 있는 매핑 테이블, 알고리즘 키 등의 정보.
- **과학적 연구** : 기술의 개발 및 실증, 기초연구, 응용연구, 민간 기업의 신제품 R&D를 포괄하는 광범위한 연구 개념.
- **결합전문기관** : 서로 다른 개인정보처리자 간의 가명정보를 안전하게 결합하도록 전문 시설과 인력을 갖추어 정부가 지정한 전문 기관.
- **재식별 금지 의무** : 가명정보를 처리하는 과정에서 특정 개인을 알아보기 위한 일체의 행위를 금지하며 위반 시 전체 매출액 과징금 및 형사 처벌 부과.

</details>

## 2~4교시 25점 답안

## Ⅰ. 가명정보의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **가명정보** 는 추가 정보의 사용·결합 없이는 특정 개인을 알아볼 수 없도록 조치하여 법정 목적 내에서 동의 없이 처리 가능한 개인정보 |
| 목적 | 데이터 프라이버시 보호와 데이터 경제 활성화(AI 학습, 빅데이터 융합 분석) 간의 균형 달성 |

## Ⅱ. 가명정보의 법적 지위 및 처리 특례의 제도적 특징

| 구분 | 법적 기준 및 요건 | 상세 특징 및 기술적 적용 기준 |
|---|---|---|
| **처리 목적 특례** | 3대 법정 목적 한정 | **① 통계작성** (상업적 목적 통계 포함)<br />**② 과학적 연구** (산업적 R&D 포함)<br />**③ 공익적 기록보존** 에 한해 동의 없이 처리 허용 |
| **제3자 제공 허용** | 가명 결합 및 제공 | 특정 개인을 식별할 수 없는 상태로 가명처리된 경우 정보주체의 별도 동의 없이 제3자 제공 가능 |
| **적용 배제 조항** | 정보주체 권리 제한 | 가명정보 처리에 대해서는 정보주체의 **열람권, 정정·삭제권, 처리정지 요구권 적용 배제** (신속 연구 보장) |
| **안전조치 의무 (특징)** | **추가 정보 분리 보관** | 매핑 키, 삭제된 원본 식별자 등 '추가 정보'는 별도 분리 저장, 접근 권한 최소화 |
| | 재식별 방지 조치 | 특정 개인 재식별 시도 행위 절대 금지, 식별 가능성 발견 즉시 처리 중단 및 회수·파기 |
| | 기록 보관 의무 | 가명정보 처리 목적, 항목, 이용 내역 등을 담은 **가명정보 관리대장 3년간 의무 보존** |

## Ⅲ. 4단계 가명처리 및 결합전문기관 연계 프로세스

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 개인정보보호위원회 표준 가명정보 4단계 처리 및 결합 파이프라인 ]    │
└────────────────────────────────────────────────────────────────────────┘

 [ 1단계: 사전 준비 (Preparation) ]
    ├── 처리 목적의 적법성 검토 (통계/연구/기록보존 부합 여부)
    └── 대상 데이터셋 식별자(이름, 주민번호 등) 및 준식별자 분류
          │
          ▼
 [ 2단계: 위험도 검토 (Risk Assessment) ]
    ├── 데이터 자체의 고유 식별 위험도 평가 ($k$-익명성 수준 분석)
    └── 처리 환경의 안전성(폐쇄 분석망 여부, 반출 대상자 신뢰도) 평가
          │
          ▼
 [ 3단계: 가명처리 수행 (Pseudonymization) ]
    ├── 식별자: 완전 삭제 또는 일방향 해시 암호화 (Salt 주입)
    ├── 준식별자: 범주화(Grouping), 노이즈 추가, 라운딩, 마스킹 적용
    └── 추가 정보(복원 키) 생성 후 독립된 안전 스토리지로 분리 격리
          │
          ▼
 [ 4단계: 적정성 검토 및 사후관리 (Review & Management) ]
    ├── 전문가 검토위원회 구성 (재식별 가능성 및 과도 가명화 여부 심사)
    ├── 반출 승인 및 목적 범위 내 안전한 분석 활용
    └── 프로젝트 종료 시 가명정보 완전 파기 및 처리대장 기록 유지
```

| 가명처리 기법 | 엔지니어링 구현 원리 | 적용 대상 사례 |
|---|---|---|
| **삭제 (Suppression)** | 개인을 즉시 식별하는 고유 속성 컬럼 완전 제거 | 이름, 주민등록번호, 여권번호, 전화번호 |
| **가명화 (Pseudonymization)** | 결정적 가명화(해시) 또는 토큰화(Tokenization) | 회원 고유 ID, 계좌번호 (결합키로 활용) |
| **범주화 (Generalization)** | 구체적 수치 데이터를 구간화하여 집계치 변환 | 나이(32세 -> 30대), 주소(시·군·구까지만 표기) |
| **노이즈 주입 (Perturbation)** | 원본 데이터의 통계적 분포를 유지하며 무작위 값 가감 | 연봉, 키, 몸무게 등 연속형 수치 데이터 |
| **상·하단 코딩 (Top/Bottom Coding)**| 분포의 극단값(희귀치)을 특정 임계치로 일괄 치환 | 90세 이상 고령자 -> '90세 이상' 단일화 |

## Ⅳ. 개인정보, 가명정보, 익명정보의 3단계 개념 비교

| 비교 항목 | 개인정보 (Personal Data) | 가명정보 (Pseudonymized Data) | 익명정보 (Anonymized Data) |
|---|---|---|---|
| **개념 정의** | 살아있는 개인을 알아볼 수 있는 원천 정보 | 추가 정보 없이는 개인을 알아볼 수 없는 정보 | 시간·비용을 투입해도 개인을 식별 불가능한 정보 |
| **법적 지위** | 개인정보 보호법 전면 적용 | **개인정보에 해당 (특례 적용)** | **개인정보 보호법 적용 완전 제외** |
| **이용 동의** | 정보주체 사전 동의 필수 (원칙) | **통계·연구 목적 동의 없이 활용 가능** | 자유로운 상업적 이용 및 공유 가능 |
| **안전조치 의무** | 법정 안전성 확보조치 전면 적용 | **추가 정보 분리 보관, 재식별 금지 의무** | 법적 안전조치 의무 없음 |
| **정보주체 권리** | 열람, 정정, 삭제, 처리정지 전면 보장 | **열람·정정·삭제·전송요구권 적용 배제** | 권리 행사 대상 자체가 아님 |
| **식별 가능성** | 직접 식별 가능 | 추가 정보 결합 시 복원 가능 | 복원 불가능 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 이종 산업 간 다량의 가명데이터 결합 시 외부 공개 정보와의 연결 공격(Linkage Attack)에 의한 재식별 위험 | 차등 정보보호(Differential Privacy) 기법을 결합하여 수학적으로 개인 포함 여부를 숨기는 프라이버시 모델 적용 |
| 이미지, 의료 영상, 음성 등 비정형 데이터의 경우 정형 데이터와 달리 식별자 분리 및 가명화 표준 부재 | 합성데이터(Synthetic Data) 생성 기술 도입 및 비정형 데이터 특화 개인정보 안심구역 활용 의무화 |

## Ⅵ. 제언

가명정보의 안전한 산업적 활용을 위해 원본 데이터 이동 없이 알고리즘만 전송하는 분산 연합학습 및 차등 정보보호(DP) 기반의 차세대 프라이버시 강화 분석 플랫폼 구축 필요.

```text
[ 데이터 보유기관 A (금융) ]       [ 데이터 보유기관 B (의료) ]
   └── 로컬 가명처리 DB (온프레미스)   └── 로컬 가명처리 DB (온프레미스)
              │                               │
              ▼ (로컬 모델 학습 및 DP 노이즈 주입) ▼
 ┌─────────────────────────────────────────────────────────────┐
 │ [ 차등 정보보호 기반 연합학습 파이프라인 (Federated MLOps) ]  │
 │  ├── 원본 가명데이터는 기관 외부로 절대 반출되지 않음         │
 │  └── 암호화된 가중치 파라미터만 교환하여 글로벌 AI 모델 완성 │
 └─────────────────────────────────────────────────────────────┘
                               │
                               ▼
        [ 재식별 위험 0%의 고정밀 융합 AI 서비스 창출 ]
```

| 구분 | 기존 데이터 반출 결합 | 제언: 차등 정보보호 연합학습 플랫폼 |
|---|---|---|
| **데이터 이동** | 결합전문기관으로 원천 가명정보 집결 | 데이터 이동 없음 (알고리즘만 이동) |
| **재식별 위험** | 결합키 탈취 시 대규모 유출 위험 | 데이터 자체가 격리되어 재식별 원천 차단 |
| **분석 자유도** | 반출 심사 지연으로 분석 주기 수개월 | MLOps 연계 실시간 모델 파인튜닝 |
| **컴플라이언스** | 결합 및 반출 승인 절차 복잡 | 가명정보 특례 및 제로 트러스트 규정 완벽 부합 |
