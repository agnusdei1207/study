<details><summary>핵심 용어</summary>

- **공공부문 초거대 AI 도입·활용 가이드라인 2.0** : 한국지능정보사회진흥원(NIA, National Information Society Agency)이 2025년 공개한 공공기관용 초거대 AI 실무 안내서.
- **초거대 AI (Large-Scale AI)** : 대규모 데이터·연산으로 학습되어 다양한 과업을 수행할 수 있는 인공지능 모델·서비스를 가리키는 정책 용어.
- **RAG (Retrieval-Augmented Generation)** : 사용자 질문과 관련된 외부 문서를 검색해 생성 모델의 답변 근거로 제공하는 방식.
- **범정부 AI 공통기반** : 여러 공공기관이 AI 모델·GPU 등 공통 자원을 이용하도록 구축한 정부 공동 활용 기반.
- **성과관리** : AI 서비스의 목표·품질·운영 현황을 정해진 지표와 검토 절차로 확인하는 활동.

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **공공부문 초거대 AI 도입·활용 가이드라인 2.0** 은 공공기관의 생성형 AI 사업 기획·도입·운영을 돕는 실무 지침 |
| 목적 | 공공서비스 활용을 지원하면서 도입 절차·위험 고려사항·성과관리의 실무 기준 제공 |

가이드라인 2.0은 2024년 4월 배포한 1차 안내서를 갱신해 2025년 4월 16일 공개한 자료. 추진 방향, 활용 사례, 도입 절차·고려사항, 성과관리 안내로 구성.

## Ⅱ. 업무·서비스 도입 판단

| 검토 항목 | 확인 질문 |
|---|---|
| 업무 수요 | AI가 해결할 행정 문제와 이용자는 누구인가? |
| 대안 비교 | 기존 정보시스템·업무 개선으로 해결할 수 있는가? |
| 데이터·권한 | 사용할 데이터와 접근·보유 권한이 적절한가? |
| 운영 책임 | 답변 오류·민원·장애를 누가 검토하고 조치하는가? |

```text
업무 문제 정의 ──> AI 적합성·대안 비교 ──> 위험·책임 검토
       │                                       │
       └────────────── 도입 결정 <─────────────┘
```

## Ⅲ. 단계별 사업 관리

| 단계 | 가이드라인의 검토 초점 |
|---|---|
| 기획 | 추진 목적·이용자·업무 범위와 성과 목표 |
| 도입·구축 | 데이터, 모델·서비스, 보안, 법적 근거와 조달 고려 |
| 운영 | 품질·보안·민원·비용 점검과 개선 |

각 단계의 책임자와 산출물을 사업계획·계약·검수 기준에 명시. 구체 절차는 기관별 법령과 조달·정보보호 규정에 맞춰 보완.

## Ⅳ. 검색증강생성(RAG)과 지식 데이터

```text
┌──────────────────┐
│ 기관 문서·지식자료 │
└─────────┬────────┘
          │ 품질·최신성·접근권한 관리
          v
┌──────────────────┐
│ 질문 관련 문서 검색 │ <── 이용자 질문
└─────────┬────────┘
          │ 검색 문맥을 모델 입력에 추가
          v
┌──────────────────┐
│ 근거 기반 응답 생성 │
└─────────┬────────┘
          v
   출처·정확성 확인과 사람의 검토
```

RAG는 기관 지식의 검색 결과를 모델 응답의 문맥으로 사용하는 방식. 문서 최신성·권한·검색 품질을 함께 관리해야 하며, 환각이나 부정확한 답변을 완전히 제거하는 기술은 아님.

## Ⅴ. 안전·보안·운영 통제

| 위험 | 관리 방안 |
|---|---|
| 민감·비공개 데이터의 외부 전송 | 데이터 등급·이용 목적에 따른 접근과 승인 통제 |
| 오래되거나 권한이 잘못된 문서 검색 | 문서 소유자·갱신 주기·접근권한 관리 |
| 답변 오류의 행정 판단 전파 | 근거 확인·담당자 검토·정정 절차 마련 |
| 외부 서비스 변경·장애 | 서비스 수준·변경 통보·장애 대응 책임을 계약에 반영 |

## Ⅵ. 성과관리와 최신 공통기반

| 점검 영역 | 확인 대상 |
|---|---|
| 서비스 성과 | 업무시간·이용자 경험 등 사업 목적에 맞는 변화 |
| 응답 품질 | 정확성·근거 적합성·오류 유형 |
| 운영 상태 | 장애·비용·보안·민원 현황 |
| 개선 | 점검 결과의 데이터·프롬프트·업무 절차 반영 |

2026년 5월 기준 NIA 「공공부문 AI 도입·활용 가이드」는 범정부 AI 공통기반 우선 활용을 고려하는 서비스 기획·예산·계약·구현·운영 안내. 2026년 8월 28일 시행 법률에 따른 데이터 공동활용 플랫폼 규정과 구분하여, AI 공통기반 이용 조건은 해당 가이드·계약 기준으로 확인.

## Ⅶ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
