## 30초 인출

- 본질: 이동통신사업자(ISP)가 특정 콘텐츠 및 서비스(CP) 이용 시 발생하는 데이터 트래픽에 대해 이용자의 기본 데이터 제공량에서 차감하지 않거나 무료로 제공하고, 데이터 비용을 CP가 대납하거나 통신사가 마케팅 비용으로 부담하는 차별적 과금 제도
- 메커니즘: 심층패킷분석(DPI) 또는 목적지 IP/도메인(FQDN) 기반 트래픽 식별 → 정책 및 과금 규칙 기능(PCRF) 연계 → 온라인 과금 시스템(OCS)에서 데이터 차감 면제 처리 → 통신사-콘텐츠사업자(CP) 간 데이터 대가 사후 정산
- 통찰: 무료 혜택을 통한 단기적 소비자 후생 증대 이면에 내재된 대형 CP 중심 시장 고착화 및 스타트업 진입장벽 형성을 방지하기 위해 비차별적 제휴 조건 공개와 사전 규제 영향 평가 체계 구축 필수

<details>
<summary>핵심 용어</summary>

- **제로 레이팅(Zero Rating)** : 특정 앱이나 콘텐츠 이용 시 데이터 통화료를 이용자에게 면제하거나 감면해 주는 요금제
- **망 중립성(Net Neutrality)** : 모든 인터넷 트래픽을 송신자, 수신자, 콘텐츠 내용에 관계없이 동등하게 취급해야 한다는 원칙
- **DPI(Deep Packet Inspection)** : 네트워크 패킷의 헤더뿐만 아니라 페이로드(내용)까지 정밀 분석하여 서비스 유형을 식별하는 기술
- **PCRF(Policy and Charging Rules Function)** : LTE/5G 네트워크에서 가입자별 QoS 및 과금 정책을 실시간 제어하는 코어 코어 노드
- **스폰서드 데이터(Sponsored Data)** : CP가 이용자 대신 데이터 요금을 통신사에 직접 지불하는 상업적 제로 레이팅 모델

</details>

## 2~4교시 예상문제 (25점)

> 통신 시장의 핵심 쟁점인 '제로 레이팅(Zero Rating, 스폰서드 데이터)'에 대하여 개념과 주요 유형, 기술적 트래픽 식별 및 과금 메커니즘, 망 중립성 원칙과의 상충 쟁점, 공정 경쟁 저해 한계점 및 기술사적 규제 개선 방안을 기술하시오.

## 2~4교시 25점 답안

## Ⅰ. 제로 레이팅의 개요

| 구분 | 핵심 |
|---|---|
| 정의 | 통신사업자(ISP)가 특정 콘텐츠 제공자(CP)의 데이터 트래픽 이용료를 가입자의 월정액 데이터 제공량에서 차감하지 않는 무과금 또는 감면 과금 제도 |
| 목적 | 이용자의 데이터 통신비 부담 완화, 특정 서비스(동영상, 내비게이션, 게임 등) 가입자 유치 경쟁력 강화, 교육·의료 등 공공 복지 서비스 접근성 증진 |

## Ⅱ. 제로 레이팅의 주요 유형 및 특징

- **통신사 자사 서비스형 (Self-Zero Rating)** : 통신사가 자사 계열의 음원, OTT, 내비게이션 트래픽을 무료화하여 계열사 플랫폼의 지배력을 강화하는 방식
- **상업적 제휴형 (Sponsored Data)** : 자금력이 풍부한 대형 CP(넷플릭스, 게임사 등)가 통신사와 계약을 맺고 이용자의 데이터 요금을 일괄 대납하는 방식
- **공익 목적형 (Public-Interest Zero Rating)** : 정부 차원의 EBS 교육방송, 국립중앙의료원, 긴급 재난 안전 안내 등 취약계층 정보 격차 해소를 위해 제공하는 방식
- **기술적 식별 의존성** : 대상 트래픽만을 정확히 무과금 처리하기 위해 네트워크 게이트웨이(PGW/UPF) 수준의 심층 패킷 분석(DPI) 기술 적용

## Ⅲ. 제로 레이팅의 패킷 식별 및 과금 프로세스

```text
[ 제로 레이팅 트래픽 식별 및 실시간 과금 제어 프로세스 ]

+--------------------------------------------------------------------------+
| 1단계: 사용자 서비스 요청                                                  |
|  - 스마트폰 이용자가 제로 레이팅 대상 앱(동영상, 교육 등) 접속 및 데이터 요청|
+--------------------------------------------------------------------------+
                                    │
                                    ▼
+--------------------------------------------------------------------------+
| 2단계: 5G/LTE 코어망 패킷 식별 (DPI / UPF)                                |
|  - 사용자 평면 기능(UPF/PGW)에서 패킷 헤더 및 도메인(SNI/DNS) 검사       |
|  - 트래픽 탐지 기능(TDF)을 통해 사전 정의된 제로 레이팅 서비스 IP 식별   |
+--------------------------------------------------------------------------+
                                    │
                                    ▼
+--------------------------------------------------------------------------+
| 3단계: 정책 검증 및 과금 규칙 조회 (PCRF / PCF)                          |
|  - 가입자 식별 및 서비스 제휴 코드 대조 (제휴 서비스 여부 판정)          |
|  - 실시간 과금 규칙: "해당 트래픽 과금 차감률 = 0%" 지시                 |
+--------------------------------------------------------------------------+
                                    │
                                    ▼
+--------------------------------------------------------------------------+
| 4단계: 온라인 과금 시스템(OCS) 처리 및 사후 정산                          |
|  - [이용자 단말] 기본 제공 데이터량 잔여분 보존 (0MB 차감)                |
|  - [과금 CDR 생성] 이용 트래픽 로그를 스폰서 계정으로 별도 집계          |
|  - [사후 정산] 통신사(ISP)가 제휴 CP에게 집계된 데이터 도매 대가 청구     |
+--------------------------------------------------------------------------+
```

## Ⅳ. 제로 레이팅과 망 중립성(Net Neutrality) 상충 관계 비교

| 비교 항목 | 제로 레이팅 옹호론 (소비자 후생·마케팅) | 망 중립성 준수론 (공정 경쟁·개방성) |
|---|---|---|
| 핵심 논리 | 이용자의 실질 통신비 절감 및 기업의 마케팅 자유 | 가격 차별을 통한 플랫폼 생태계의 불공정 왜곡 |
| 이용자 혜택 | 고용량 미디어 및 교육 콘텐츠 무료 이용으로 후생 증대 | 무료 서비스 쏠림(Lock-in)으로 소비자 선택권 제한 |
| CP 생태계 영향 | 대형 자본을 갖춘 글로벌 CP의 시장 확대 기회 | 자금력이 부족한 중소 스타트업의 시장 진입장벽화 |
| 통신사 입장 | 망 고도화 투자 재원 회수 및 차별화된 요금제 출시 | 자사 서비스 우대로 경쟁 서비스 배제 위험 상존 |
| 기술적 쟁점 | 합리적 트래픽 관리 및 프로모션의 일환 | DPI 패킷 감청 논란 및 프라이버시 침해 우려 |
| 규제 입장 (한국) | 원칙적 허용하되, 불공정 행위(배타적 조건) 사후 규제 | 트래픽 차단·차별 금지 원칙 준수 요구 |

## Ⅴ. 한계와 방안

| 한계 | 방안 |
|---|---|
| 풍부한 자본을 가진 대형 CP의 스폰서드 데이터 독점으로 혁신 스타트업의 진입장벽 형성 및 플랫폼 독과점 심화 | 비차별적 제휴 조건(Open Access) 의무화 및 중소 벤처기업 대상 바우처 형태의 데이터 지원 정책 병행 |
| 통신사가 자사 계열 콘텐츠(동영상, 음악)에만 제로 레이팅을 적용하여 독립 경쟁 CP를 시장에서 구조적 배제 | 통신사 자사 서비스 적용 시 경쟁 CP에게도 동일한 단가 및 동등한 조건으로 제로 레이팅 참여 기회 제공 의무화 |
| HTTPS, QUIC 등 암호화 트래픽 확산으로 종단 간 암호화(DoH, ECH) 시 통신사의 패킷 식별(DPI) 기술적 불능화 | 목적지 IP 서브넷 및 클라우드 연계 API 기반 화이트리스트 사전 등록제 도입을 통한 안정적 트래픽 식별 |

## Ⅵ. 제언

제로 레이팅은 디지털 격차 해소와 통신비 경감의 긍정적 측면과 시장 왜곡이라는 부정적 측면이 공존하므로, 공정 경쟁을 보장하는 사전 영향 평가와 투명한 공시 체계 구축 필요.

```text
[ 지속가능한 제로 레이팅 거버넌스 3대 운영 체계 ]

┌──────────────────────┐   ┌──────────────────────┐   ┌──────────────────────┐
│  비차별 개방성 보장  │   │  암호화 식별 고도화  │   │  공공 공익 영역 확대 │
│ - 제휴 조건 투명 공개│──▶│ - API 기반 사전 인증 │──▶│ - 디지털 소외계층 무상│
│ - 동등 대우 원칙 확립│   │ - DPI 의존도 탈피    │   │ - 취약계층 교육·의료 │
└──────────────────────┘   └──────────────────────┘   └──────────────────────┘
```

| 정책 영역 | 핵심 실행 방안 | 기대 효과 |
|---|---|---|
| 공정 경쟁 | 제로 레이팅 계약 조건(도매 대가 및 정산율)의 과기정통부 보고 및 투명성 공시 | 깜깜이 특혜 계약 방지 및 시장 감시 기능 강화 |
| 기술 표준 | 5G 코어망 네트워크 슬라이싱(Network Slicing)과 연계한 품질 보장형 요금제 표준화 | 무분별한 패킷 감청 논란 해소 및 서비스 품질 안정화 |
| 공공 복지 | 취약계층의 비대면 원격의료, 재난안전, 교육 플랫폼에 대한 국가 주도 제로 레이팅 법제화 | 보편적 디지털 기본권 보장 및 사회안전망 강화 |

## 출제 이력과 검증 출처

- 망 중립성 및 인터넷 트래픽 관리에 관한 가이드라인 (과학기술정보통신부)
- 전기통신사업법 제50조 (금지행위) 및 동법 시행령
- 미국 연방통신위원회(FCC) 망 중립성 복원 규칙(Open Internet Order)
- 정보관리기술사 제116회 1교시, 제119회 2교시 (제로 레이팅 및 망 중립성)

## 연결 토픽

- 망 중립성(Net Neutrality)
- 방송미디어통신위원회
- 심층패킷분석(DPI, Deep Packet Inspection)
- 5G 네트워크 슬라이싱(Network Slicing)
