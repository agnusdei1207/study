## 연관 키워드

- 전자서명법, 전자서명, 공인인증서, 전자서명인증사업자, 운영기준 준수사실 인정
- 평가기관, 본인확인, 간편인증, PKI, FIDO, OIDC, 전자서명 효력

## Ⅰ. 전자서명법의 개요

- 핵심 요약 : 공인인증서 중심의 독점 구조를 끝내고 모든 전자서명에 동등한 효력을 부여한 전자거래 신뢰 기본법.
- 개념 : 전자문서에 서명자를 확인하고 변조 여부를 검증할 수 있게 하는 **전자서명**(Electronic Signature)의 기본 사항을 정한 법률.
- 배경 및 필요성 : 법적 추정력을 가진 공인전자서명 하나에 인증 수단이 묶여 있어 이용자는 특정 설치형 프로그램에 의존했고, 민간 인증의 경쟁과 기술 선택이 제한됨.
- 주요 목적 : 공인전자서명의 우월한 법적 효력을 폐지하고, 인증수단 다양화와 운영기준 기반 신뢰성 검증으로 전자서명 이용을 촉진.
- 연혁 : 2020년 5월 국회 본회의를 통과했고, 2020년 12월 10일부터 시행됨(보도 기준).

## Ⅱ. 전자서명법의 특징 및 장점

- 핵심 요약 : 효력 동등화와 자율적 운영기준 인정이 결합되어 시장 경쟁과 신뢰 확보를 함께 얻는 구조.

1. 효력 동등 : 전자적 형태라는 이유만으로 서명·날인의 효력을 부인하지 못하게 함 → 민간 인증수단도 법적 안정성을 확보하여 이용 주체가 늘어남.
2. 당사자 약정 효력 : 법령에 정함이 없더라도 당사자가 합의한 전자서명수단의 효력을 인정 → 업무 성격에 맞춘 인증수단 선택이 가능해짐.
3. 자율적 운영기준 인정 : 사전 허가제 대신 과학기술정보통신부가 평가 기준을 정하고, 인정기관이 운영기준 준수사실을 인정(유효 1년) → 진입 장벽은 낮추고 품질은 검증.

## Ⅲ. 전자서명법의 구조 (흐름)

- 핵심 요약 : 평가와 인정으로 인증사업자의 운영 수준을 검증하고, 서명 자체는 해시와 공개키 구조로 무결성을 보장하는 이중 구조.
- **운영기준 준수사실 인정** : 평가기관이 인증사업자의 운영기준 준수 여부를 평가하고, 인정기관이 그 결과를 인정하여 증명서를 발급하는 절차.
- **공개키 기반구조** (PKI, Public Key Infrastructure) : 서명자는 개인키로 서명하고 검증자는 공개키로 확인하는 인증 구조.

```text
[ 과학기술정보통신부 장관 ]
          │ 평가 기준·세부 평가기준 마련
          ▼
[ 평가기관 (예: 금융보안원) ]
          │ 운영기준 준수 여부 평가
          ▼
[ 인정기관 ]
          │ 운영기준 준수사실 인정 (유효 1년)
          ▼
[ 전자서명인증사업자 ] ──> 이용자 서비스 제공
```

```text
[ 서명 생성 ]
전자문서 ─> 해시값 생성 ─> 서명자 개인키로 서명
                │
                ▼
[ 서명 검증 ]
공개키로 서명 확인 ─> 해시값 일치 시 무결성 확인
```

## Ⅳ. 전자서명법의 비교

- 핵심 요약 : 개정 전에는 공인인증서 하나의 법적 우위였고, 개정 후에는 사업자와 수단이 다원화된 동등 경쟁 구조로 전환.

| 비교 축 | 개정 전 (공인인증서 체계) | 개정 후 (민간 전자서명 체계) |
| --- | --- | --- |
| 법적 효력 | 공인전자서명에만 추정력 부여 | 동등한 효력, 형태만으로 부인 금지 |
| 시장 구조 | 소수 공인인증기관 중심 | 다수 인증사업자의 경쟁 구조 |
| 이용 방식 | 설치형 프로그램 중심 | 간편인증·생체인증 등 다양한 수단 |
| 연동 방식 | 브라우저별 전용 모듈 | 표준 API 기반 연동 |

- 선택 기준 : 거래의 법적 중요도와 이용자 편의를 함께 고려해 인증수단의 보안 등급과 방식을 정함.

## Ⅴ. 전자서명법의 한계와 방안

- 핵심 요약 : 연동 표준, 키 보안, 비대면 신원확인의 세 한계를 기술 통제와 평가 기준으로 함께 관리해야 함.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 사업자별 연동 규격 파편화 | 기관마다 개별 연동 개발과 유지보수 비용 증가 | 표준 연동 인터페이스(OIDC 기반) 도입과 중계 구조 운영 | 연동 기관 수, 유지보수 비용 |
| 모바일 서명키 탈취 | 분실 단말이나 악성 앱을 통한 개인키 노출 | 보안영역(TEE, SE) 저장과 생체인증 결합 | 키 탈취 사고 건수 |
| 비대면 신원확인 취약 | 신분증 사본 위조, 대포폰 개통을 통한 부정 발급 | 신분증 진위확인과 라이브니스 검증 결합 | 부정 발급 건수 |

## Ⅵ. 전자서명법에 대한 기술사적 제언

- 핵심 요약 : 인증 시장의 경쟁을 유지하면서 연동 표준과 키 보안을 공통 기반으로 세우는 방향이 필요함.

정부는 공공 연동 규격을 개방형 표준으로 정리하여 기관별 개발 부담을 낮추고, 인증사업자 평가 기준에 키 보호와 비대면 신원확인 항목을 포함해 운영 신뢰도를 높여야 한다. 인증사업자는 서명키를 보안영역에 두고 생체인증을 결합하는 방식을 기본 설계로 삼는 것이 바람직하다.

## Ⅶ. 결론

- 핵심 요약 : 전자서명법은 인증수단의 법적 효력을 동등하게 하고 운영 신뢰를 제도화한 전자서명 기본 법률.
- 공인인증서 중심 구조가 끝난 만큼, 이제 사업자 간 상호운용성과 키 보안이 전자서명의 신뢰를 좌우함.
