## Ⅰ. 모바일 주민등록증의 개요

- 개념 : 주민등록법에 근거하여 이동통신단말장치의 안전영역(SE/TEE)에 암호화 설치되는 실물 주민등록증과 동일한 법적 효력의 디지털 신분증.
- 제정 배경 및 필요성 : 단말 분실 및 불필요한 개인정보 과다 노출 위험이 상존하므로 영지식 증명(ZKP) 기반 선택적 속성 검증과 중앙 폐기 목록(Revocation List) 즉시 동기화 체계 확립 필수.
- 핵심 목적 : 공공·금융·일상생활 전반의 대면·비대면 디지털 신원 확인 단일화, 불필요한 개인정보 노출 방지 및 위·변조 방지.

## Ⅱ. 모바일 주민등록증의 법제도 체계 및 핵심 메커니즘

**모바일 주민등록증** : IC 칩 접촉(NFC) 또는 주민센터 QR 코드로 본인 인증 후 신원 증명서(VC)를 단말에 발급받고, 검증자 요청 시 선택적 정보만 제출(VP)하여 진위 확인 과정을 거쳐 체계적인 법제도적 통제와 기술적 신뢰성을 확보함.

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ 모바일 주민등록증 DID 기반 종단간(End-to-End) 아키텍처 ]                  │
└─────────────────────────────────────────────────────────────────────────────┘
  [ 주민등록 발급기관 (행안부/지자체) ] ──── 발급정보 공시 ───> [ DID 블록체인 / 저장소 ]
                 │ VC 발급                                             ▲
                 ▼                                                     │
   [ 이용자 단말 (안전영역: SE/TEE) ]                                  │ DID Document /
        - 개인키(Private Key) 분산 보관                                │ 전자서명 검증
        - VC 수납 및 VP 생성 엔진                                      │
                 │                                                     │
                 │ 1. 검증 요청(Nonce/요구속성)                        │
                 │ 2. 선택적 VP 제출 (영지식 증명 적용)                │
                 ▼                                                     │
        [ 검증자 (관공서 / 금융사 / 검증앱) ] ─────────────────────────┘

[ 1. 발급 단계: IC 태깅 / QR 창구 ]
사용자 신청 ─> IC 주민등록증 휴대폰 NFC 태깅 ─> FIDO 생체인증 ─> 정부 발급서버 VC 발행 ─> 단말 안전영역 저장

[ 2. 검증 단계: 동적 QR / BLE 통신 ]
검증자 QR 제시 ─> 이용자 단말 스캔 ─> 최소 속성 선택(성인인증 등) ─> VP 서명 전송 ─> 진위 확인 완료
```

- **법적 효력** : 주민등록법 제24조의2 명시 - 실물 주민등록증과 동등한 효력 보장, 관공서·은행·편의점 등에서 완전한 대체 인정.
- **자기주권 신원** : SSI(Self-Sovereign Identity) - 데이터 주권의 사용자 환원, 신원 정보의 중앙 서버 미저장 및 단말 분산 보관.
- **보안 아키텍처** : SE/TEE 기반 하드웨어 격리 - 루팅·탈옥 방지, 단말 1인 1기기 원칙 및 생체인증(FIDO) 결합 기반의 다중 서명.
- **프라이버시** : 선택적 속성 제출(Selective Disclosure) - 성인 여부, 주소 등 검증자가 요구하는 필수 속성만 선별 제공하여 과다 수집 원천 차단.

## Ⅲ. 모바일 주민등록증의 세부 규정 및 국내외 제도 비교 분석

| 비교 항목 | 실물 주민등록증 | 모바일 주민등록증 |
|---|---|---|
| 저장 매체 | 폴리카보네이트(PC) 수지 플라스틱 카드 | 스마트폰 하드웨어 보안영역 (SE / TEE) |
| 정보 노출 범위 | 성명, 사진, 주민번호, 주소 전체 노출 | 필요한 최소 항목만 선택적 노출 (선택적 제출) |
| 위·변조 식별 | 육안 확인, 홀로그램, 형광인쇄 확인 한계 | 비대칭 암호화 전자서명 및 블록체인 분산원장 검증 |
| 대면/비대면 지원 | 대면 중심 (비대면 시 사본 캡처 악용 취약) | 대면(동적 QR/BLE) 및 비대면(API 연계) 동시 지원 |
| 분실 시 조치 | 분실 신고 접수 전까지 도용 방지 불가 | 통신사 분실 신고 즉시 효력 정지, 원격 데이터 삭제 |

- 제도적 시사점 : 모바일 주민등록증은 상기 비교 지표를 바탕으로 법적 의무 준수와 비즈니스 연속성 간의 균형을 확보하고, 규제 환경 변화에 선제적으로 대응할 수 있는 아키텍처 및 거버넌스 체계를 확립해야 함.

## Ⅳ. 모바일 주민등록증의 주요 한계점 및 해결 방안

- 화면 단순 캡처 및 미러링 앱을 활용한 신분증 위·변조 위험 :
  - 한계점 : 신분증 검증 시 화면 단순 캡처본 또는 미러링 앱을 활용한 위·변조 편법 통과 위험.
  - 해결 방안 : 동적 시각 보안 워터마크(움직이는 애니메이션), 일회용 동적 QR 코드(Time-based OTP 결합), 화면 캡처 방지 API(FLAG_SECURE) 강제 적용.
- 단말기 분실·도난 시 비정상 접근 및 오프라인 신원 사칭 가능성 :
  - 한계점 : 단말기 도난·분실 시 비정상 접근 및 오프라인 단말에서의 신원 사칭 가능성.
  - 해결 방안 : 통신사 분실 신고 즉시 연동되는 실시간 폐기 목록(CRL/OCSP) 조회 및 단말 FIDO 생체인증 실패 시 잠금(Brute-Force 방어) 메커니즘 구축.
- 검증자 측의 불필요한 전체 속성 일괄 요구로 인한 프라이버시 침해 :
  - 한계점 : 검증자 측의 불필요한 전체 속성 일괄 요구로 인한 자기결정권 침해.
  - 해결 방안 : 검증자 앱의 요청 속성을 심사·승인하는 인가 체계 도입 및 영지식 증명(ZKP) 기반 특정 조건(만 19세 이상 여부 등) 불리언(Boolean) 검증 의무화.

## Ⅴ. 모바일 주민등록증 정착 및 실효성 확보를 위한 기술사적 제언

단말 분실 및 사칭 위협에 대응하기 위하여 FIDO2 생체인증과 영지식 증명을 결합하고 실시간 폐기 검증 게이트웨이를 구축하는 제로트러스트 기반 신원 거버넌스 확립.

- 검증 방식 관점의 고도화 및 실무 전환 : 검증자가 화면의 텍스트·사진 육안 판독의 한계와 비효율을 탈피하고, 비대칭 암호키 기반 서명 검증 및 영지식 증명 판정을 체계적으로 도입·적용하여 실무적 신뢰성과 거버넌스 실효성을 극대화해야 함.
- 노출 정보 관점의 고도화 및 실무 전환 : 성명·주민번호·주소 등 전체 개인정보 노출의 한계와 비효율을 탈피하고, 참/거짓 불리언 값 및 동적 일회용 토큰만 노출을 체계적으로 도입·적용하여 실무적 신뢰성과 거버넌스 실효성을 극대화해야 함.
- 통신 보안 관점의 고도화 및 실무 전환 : 오프라인 육안 확인으로 이력 관리 불가의 한계와 비효율을 탈피하고, mTLS 기반 안전 채널 및 검증 이력 암호화 감사 추적을 체계적으로 도입·적용하여 실무적 신뢰성과 거버넌스 실효성을 극대화해야 함.
