## 연관 키워드

- 모바일 주민등록증, 디지털 신분증, 주민등록법, 실지명의 확인 증표
- 안전영역(Secure Element·TEE), 자기주권 신원(SSI), 선택적 제출, 영지식 증명(ZKP)
- 효력 정지, 재발급 주기, 동적 QR, 본인 확인, 위·변조 방지

## Ⅰ. 모바일 주민등록증의 개요

- 핵심 요약 : 실물 주민등록증과 같은 효력을 가진 신분증을 스마트폰에 발급해 대면·비대면 신원 확인을 하나로 묶는 디지털 신분증 제도.
- 개념 : 주민등록 정보를 바탕으로 스마트폰 보안 영역에 발급되는 **모바일 주민등록증**으로, 주민등록법 시행령 개정을 통해 **실지명의 확인 증표**(실명 확인에 쓰이는 신분 증명 수단)에 포함되었다.
- 배경 및 필요성 : 실물 카드는 분실과 사본 촬영에 따른 도용 위험이 있고, 확인 과정에서 주민등록번호와 주소 등 불필요한 정보가 함께 노출되는 문제가 있다.
- 주요 목적 : 필요한 정보만 확인하는 방식으로 개인정보 노출을 줄이고, 위·변조와 도용을 막아 신원 확인 절차를 안전하게 단일화하는 것이다.
- 도입 경과 : 2024년 말 도입이 발표되었고, 행정안전부 보도 기준 2025년 3월 14일부터 주민센터에서 전국 발급이 시작되었다.

## Ⅱ. 모바일 주민등록증의 특징 및 장점

- 핵심 요약 : 단말 내 보관과 본인 명의 1대 발급, 효력 정지 기능이 도용 위험을 낮추고, 최소 정보 확인이 개인정보 보호로 이어지는 구조.

1. 단말 보안 영역 보관 : 신분증 데이터를 스마트폰의 보안 영역에 두어 외부 복제 위험을 낮춤 → 사본 도용 감소.
2. 본인 명의 1대 발급 : 발급 단말을 본인 명의 휴대폰으로 제한 → 타인 단말에서의 부정 발급 차단.
3. 재발급 주기 운영 : 3년마다 재발급하도록 해 보안 기술을 갱신 → 장기간 같은 키가 쓰이는 위험 완화.
4. 분실 시 효력 정지 : 휴대폰 분실 신고와 연계해 신분증 효력을 정지 → 도용 시간 단축.

## Ⅲ. 모바일 주민등록증의 발급과 검증 구조 (흐름)

- 핵심 요약 : 발급은 본인 확인을 거쳐 단말에 저장되고, 검증은 단말이 요청받은 정보만 응답하는 두 단계 흐름.

```text
[ 1. 발급 단계 ]
본인 확인 (실물 IC 카드 태깅 등)
          ↓
발급 서버가 신분증 정보 생성
          ↓
스마트폰 보안 영역에 저장
```

```text
[ 2. 검증 단계 ]
검증자가 확인 요청 (동적 QR 등)
          ↓
이용자가 요청 항목을 확인하고 응답
          ↓
검증자가 진위 여부 판정
```

1. 발급 : 본인 확인 수단으로 실물 신분증 정보를 확인하고, 단말 발급 절차를 마친다.
2. 검증 : 검증자가 요구한 항목만 응답하여 불필요한 정보 제공을 줄인다.
3. 진위 확인 : 발급 기관의 전자서명과 폐기 여부를 검증 절차에서 확인한다.

## Ⅳ. 실물 주민등록증과의 비교

- 핵심 요약 : 저장 매체와 정보 노출 방식, 분실 대응 측면에서 모바일 주민등록증이 실물 카드보다 도용 위험을 줄이는 구조.

| 비교 항목 | 실물 주민등록증 | 모바일 주민등록증 |
| --- | --- | --- |
| 저장 매체 | 플라스틱 카드 | 스마트폰 보안 영역 |
| 정보 노출 범위 | 카드에 적힌 정보 전체 | 요청된 항목 중심으로 제한 |
| 위·변조 식별 | 육안과 물리적 보안 요소 확인 | 전자서명 기반 진위 확인 |
| 분실 시 대응 | 신고 전까지 도용 가능 | 분실 신고와 연계한 효력 정지 |
| 확인 방식 | 대면 확인 중심 | 대면(QR 등)과 비대면 확인 병행 |

- 선택 기준 : 대면 현장은 **동적 QR**(시간에 따라 바뀌는 QR 코드) 방식으로, 비대면은 연계 시스템으로 확인하도록 상황에 맞춰 나누어 적용한다.

## Ⅴ. 모바일 주민등록증의 한계와 방안

- 핵심 요약 : 화면 캡처와 미러링, 단말 분실, 과다 정보 요구에 따른 위험을 동적 확인과 효력 정지, 최소 정보 원칙으로 보완.

| 한계 | 원인·영향 | 대응 방안 | 관리 지표 |
| --- | --- | --- | --- |
| 화면 캡처와 미러링 악용 | 정적 이미지가 복제되어 편법 확인 가능 | 일회용 동적 QR과 화면 보안 설정 적용 | 정적 이미지 거절률 |
| 분실·도난 단말의 악용 | 신고 전 시간 동안 신원 사칭 가능 | 분실 신고 즉시 효력 정지와 단말 잠금 | 효력 정지 처리 시간 |
| 검증자의 과다 정보 요구 | 필요 이상의 개인정보 수집으로 권리 침해 | 요청 항목 심사 체계와 최소 정보 확인 원칙 | 과다 요구 신고 건수 |

## Ⅵ. 모바일 주민등록증 정착을 위한 기술사적 제언

- 핵심 요약 : 최소 정보 확인과 실시간 효력 관리를 검증 체계 전반의 기본 원칙으로 두는 신원 거버넌스 확립.

1. 검증자 측에는 요청 항목을 정하는 기준과 승인 절차를 두어, 필요한 정보만 확인하는 관행이 자리 잡도록 제도적 장치를 마련하는 것이 바람직하다.
2. 발급 기관은 효력 정지와 재발급 이력을 실시간으로 공유하는 체계를 유지하고, 연계 기관의 검증 기록을 감사할 수 있어야 한다.
3. 이용자 측면에서는 분실 신고와 효력 정지 절차를 쉽게 안내하여, 단말 분실 시 피해가 커지기 전에 대응할 수 있도록 하는 것이 필요하다.

## Ⅶ. 결론

- 핵심 요약 : 모바일 주민등록증은 신분증을 단말 안에서 보호하고 필요한 정보만 확인하는 방식으로 신원 확인을 재구성한 제도이다.
- 시사점 : 제도의 효과는 검증자의 요청 관행과 실시간 효력 관리에 달려 있으므로, 기술과 운영 기준을 함께 점검해야 한다.
