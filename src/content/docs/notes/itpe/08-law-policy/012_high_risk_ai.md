```text
제품·서비스의 사용 분야·영향 검토
```

## 2~4교시 25점 답안

## Ⅰ. 개요

| 구분 | 핵심 |
|---|---|
| 정의 | **고영향 인공지능**은 생명·신체 안전 또는 기본권에 중대한 영향을 미칠 우려가 있어 법률상 열거된 영역에서 활용되는 인공지능시스템 |
| 목적 | 중대한 안전·기본권 영향을 사전에 식별하고 안전·신뢰 조치와 감독을 적용 |

| 현행 법령 | 시행 기준 |
|---|---|
| 인공지능기본법 법률 제21311호 | 2026-07-21 시행 |

## Ⅱ. 해당 여부 검토와 확인

```text
제품·서비스의 의도된 사용과 실제 사용 확인
                    ↓
법률상 정의·열거 영역 및 하위 기준 대조
                    ↓
사업자가 해당 여부 사전 검토·근거 기록
          ┌─────────┴─────────┐
          │                   │
   확인 요청 불필요       해당 여부가 불명확
          │                   ↓
          │       과학기술정보통신부장관에 확인 요청
          │                   ↓
          │          장관 확인·필요 시 전문 자문
          └─────────┬─────────┘
                    ↓
                법정 의무 이행
```

이 흐름은 인공지능기본법 제33조의 사전 검토와 확인 요청 경로. 모든 사업자가 확인 요청을 거치는 것은 아니며, 사업자의 사전 검토는 필수.

## Ⅲ. 주요 적용 영역

| 영역 예시 | 판단 시 살필 영향 |
|---|---|
| 에너지 공급·먹는물 생산·보건의료·의료기기·디지털의료기기 | 생명·신체 안전과 의료 서비스에 미치는 영향 |
| 원자력시설 안전관리·운영, 주요 교통수단·시설·체계 작동 | 공공 안전과 핵심 기반시설 운영에 미치는 영향 |
| 범죄수사·체포 목적 생체인식정보 분석·활용 | 개인 식별·감시와 기본권에 미치는 영향 |
| 채용·대출 심사 등 권리·의무 관계에 큰 영향을 주는 판단·평가 | 개인의 기회·권리와 경제적 지위에 미치는 영향 |
| 공공서비스 자격 확인·결정·비용징수, 유아·초등·중등교육 학생 평가 | 공공서비스 접근과 교육상 권리에 미치는 영향 |

열거 분야에 속한다는 사실만으로 모든 인공지능이 자동 해당되는 것은 아니며, 법정 정의의 중대한 영향·위험 우려와 실제 기능·이용 맥락을 함께 대조.

## Ⅳ. 사업자의 주요 책무

| 책무 | 핵심 내용 |
|---|---|
| 위험관리 | 위험관리 방안 수립·운영 |
| 설명 | 기술적으로 가능한 범위에서 결과·주요 기준·학습용 데이터 개요의 설명 방안 수립·시행 |
| 이용자 보호 | 이용자 보호 방안 수립·운영 |
| 사람의 관리·감독 | 고영향 AI에 대한 사람의 관리·감독 체계 마련 |
| 문서화 | 안전성·신뢰성 조치를 확인할 수 있는 문서 작성·보관 |
| 영향평가·고지 | 기본권 영향평가 수행 노력, 투명성 의무의 사전 고지 여부 확인 |

## Ⅴ. 제품 생명주기 관리

```text
기획: 사용 목적·영향 대상 식별
              ↓
개발: 데이터·모델 위험 검토·시험
              ↓
출시: 해당 여부 기록·고지·법정 조치
              ↓
운영: 사람 감독·사고·성능 변화 점검
              ↓ 목적·사용 범위의 중대한 변경
        재검토·재시험
```

## Ⅵ. 구현상 위험과 대응

| 위험 | 대응 |
|---|---|
| 목적 외 사용으로 영향 수준이 달라짐 | 허용 사용·금지 사용을 문서화하고 사용환경 변화를 감시 |
| 사람의 감독이 승인 절차로만 남음 | 감독자의 권한·정보·중단 절차를 정하고 표본 검토와 이의제기 경로 운영 |
| 모델·데이터 변경 후 위험이 커짐 | 변경관리와 재시험 기준을 정하고 운영 중 성능·피해 신호를 점검 |
| 법정 설명에 필요한 근거가 불충분 | 데이터·모델 버전, 판단기록, 사람의 개입과 조치 내역을 연결해 보존 |

## Ⅶ. 기술사적 제언

| 한계 | 해결 방안 |
|---|---|
| 법무 검토·개발 통제·운영 감독이 분리되어 실제 사용 변화와 위험 증가를 놓칠 가능성 | 제품별 사용 목적·영향 판단을 자산대장에 등록하고 모델·데이터 변경과 운영 지표를 재검토 기준에 연결 |
