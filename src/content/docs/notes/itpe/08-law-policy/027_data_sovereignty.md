## Ⅰ. 데이터 주권(Data Sovereignty)의 개요

- 개념 : 데이터의 생성, 처리, 보관, 활용 전 과정이 데이터가 귀속된 국가의 **사법적 관할권** 및 **자율적 통제권** 하에 유지되어야 한다는 원칙.
- 제정 배경 및 필요성 : 글로벌 클라우드 기업에 대한 데이터 의존도가 심화되고 미국 **CLOUD(Clarifying Lawful Overseas Use of Data) Act** 등 역외 사법 관할권 행사 위험이 증가함에 따라, 자국민과 국가 기관의 데이터에 대한 주권적 통제권을 지키고 디지털 식민지화를 방지하기 위해 대두됨.
- 핵심 목적 : 글로벌 빅테크의 데이터 독점 방지, 타국 사법당국의 무단 영장 집행 차단 및 국가 안보와 국민 프라이버시 수호.

## Ⅱ. 데이터 주권(Data Sovereignty)의 법제도 체계 및 핵심 메커니즘

**데이터 주권** (Data Sovereignty) : 데이터의 물리적 저장 위치 통제와 더불어 CSP(Cloud Service Provider) 법적 관할권 확인, **고객 소유 암호키** (HYOK) 분리 및 **기밀 컴퓨팅** (TEE, Trusted Execution Environment)을 적용해 해외 정부의 강제 징구와 원격 접근 차단 과정을 거쳐 상호 연동 및 단계별 법적·기술적 통제를 수행함.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 데이터 주권 보장을 위한 소버린 클라우드(Sovereign Cloud) 아키텍처 ]   │
└────────────────────────────────────────────────────────────────────────┘

 [ 대한민국 정부 / 민간 데이터 주권 구역 ]
    │
    ▼ (데이터 암호화 적재)
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 1. 데이터 현지화 계층 (Local Data Residency) ]                     │
 │  └── 국내 데이터센터 물리적 저장 강제, 국외 무단 백업 원천 차단      │
 └──────────────────────────────────────────────────────────────────────┘
    │
    ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 2. 키 주권 계층: HYOK (Hold Your Own Key) ]                         │
 │  ├── 고객사 자체 데이터센터 내 하드웨어 보안 모듈(HSM) 구축          │
 │  └── CSP는 암호화된 블롭(Blob)만 저장, 복호화 키 접근 절대 불가     │
 └──────────────────────────────────────────────────────────────────────┘
    │
    ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 3. 연산 주권 계층: 기밀 컴퓨팅 (Confidential Computing) ]          │
 │  ├── 하드웨어 격리 실행 환경 (Intel SGX, AMD SEV 기반 TEE Enclave)    │
 │  └── CPU 메모리 연산 중에도 데이터 암호화 상태 유지 (CSP 관리자 차단) │
 └──────────────────────────────────────────────────────────────────────┘
    │
    ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [ 4. 운영 주권 계층 (Operational Sovereignty) ]                      │
 │  └── 신원 검증된 현지 국적자(한국인)만 인프라 물리/논리 유지보수 인가  │
 └──────────────────────────────────────────────────────────────────────┘
```

- **역외 관할권 충돌** : 미국 CLOUD Act (18 U.S.C.) - 서버가 한국에 있어도 미국 CSP(AWS(Amazon Web Services), MS, 구글)는 미국 정부 명령 시 데이터 제출 의무 발생
- **원격 관리자 접근** : 해외 본사 인력의 관리 접근 - 데이터는 국내에 보관되나 해외 원격 엔지니어가 유지보수 목적으로 평문 데이터 열람 가능
- 암호키 통제권 결여 : **CSP 관리 키** (KMS(Key Management Service) 종속) - 클라우드 제공자가 암호키를 보관·관리할 경우 법원 영장 제시 시 고객 모르게 복호화 제공
- 국내 법적 대응 (특징) : **개인정보 보호법** 제28조의8 - 개인정보 국외 이전 시 정보주체 동의 또는 안전성 인정 국가에 한해 허용, 위반 시 중지명령

## Ⅲ. 데이터 주권(Data Sovereignty)의 세부 규정 및 국내외 제도 비교 분석

| 비교 항목 | 단순 데이터 현지화 (Data Residency) | 종합적 데이터 주권 (Data Sovereignty) |
|---|---|---|
| 통제의 초점 | 데이터가 '어디에 저장되어 있는가' (물리적 위치) | 데이터에 '누가 접근하고 어떤 법이 적용되는가' (관할권) |
| 보안 메커니즘 | 국내 데이터센터 상면 입주 | HYOK 키 격리 + TEE 기밀 컴퓨팅 + 운영 통제 |
| CLOUD Act 대응 | 대응 불가 (미국 테크 기업 서버면 강제 징구) | 완벽 대응 (CSP도 키가 없어 평문 제출 불가) |
| 관리자 접근 | 해외 원격 엔지니어 접근 허용 (위험 상존) | 인가된 현지 거주 국적자만 접근 통제 |
| 운영 모델 | 글로벌 퍼블릭 클라우드 국내 리전 | 현지 파트너사 운영 소버린 전용 클라우드 파티션 |
| 보장 수준 | 초급 수준의 형식적 위치 규제 충족 | 국가 안보 및 최고 기밀을 보호하는 완전 주권 보장 |

- 제도적 정합성 및 대응 방향 : 데이터 주권은 상기 비교 지표를 바탕으로 법적 규제 준수(Compliance) 요건과 엔터프라이즈 운영 효율성을 균형 있게 확보하고, 선제적인 관리체계를 수립해야 함.

## Ⅳ. 데이터 주권(Data Sovereignty)의 주요 한계점 및 해결 방안

- HYOK(Hold Your Own Key) 적용 시 CSP 네이티브 클라우드 기능 및 AI(Artificial Intelligence) 연산 제약 :
  - 한계점 : HYOK 적용 시 클라우드 네이티브 서비스(검색, AI 분석 등)의 서버 측 평문 연산 불가로 기능 제약.
  - 해결 방안 : 암호화된 상태에서 직접 연산을 수행하는 동형암호(HE) 가속기 및 안전한 TEE Enclave 기반 메모리 복호화 연산 결합.
- 소버린 클라우드 구축 시 글로벌 빅테크의 최신 AI 파운데이션 모델 업데이트 지연 :
  - 한계점 : 소버린 클라우드 구축 시 글로벌 CSP의 최신 AI 모델(GPT(Generative Pre-trained Transformer), Claude 등) 업데이트 주기 지연.
  - 해결 방안 : 글로벌 기술 모델을 로컬 인프라로 격리 수입하는 '에어갭(Air-Gapped) 소버린 AI 플랫폼' 조달 모델 확립.

## Ⅴ. 데이터 주권(Data Sovereignty) 정착 및 실효성 확보를 위한 기술사적 제언

- 데이터 저장부터 연산까지 CSP를 신뢰하지 않는 제로 트러스트 기밀 컴퓨팅(TEE) : 기존의 CSP 관리 키로 투명 암호화 (TDE) 한계를 극복하기 위해 고객 독점 온프레미스 HSM(Hardware Security Module) 키로 암호화 (HYOK) 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- 동형암호(HE) 가속기 기반의 암호화 상태 직접 연산 플랫폼 구축 : 기존의 메모리 상에 평문 노출 (덤프 취약) 한계를 극복하기 위해 하드웨어 TEE Enclave 내 메모리 암호화 연산 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
- 글로벌 기술 모델을 로컬 인프라로 격리 수입하는 에어갭(Air-Gapped) 소버린 AI 플랫폼 : 기존의 본국 정부 명령 시 평문 징구 불가피 한계를 극복하기 위해 키가 없어 기술적으로 평문 제공 불가능 (면책) 체계를 선제적으로 확립하여 엔터프라이즈 거버넌스를 완성해야 함.
