# 컴퓨터 포렌식(Computer Forensics)

## 핵심 개념
- 컴퓨터 및 디지털 저장 매체에 저장되거나 네트워크를 통해 전송되는 디지털 데이터에서 법적 증거 능력을 갖춘 디지털 증거를 수집, 보존, 분석, 보고하는 과학적 수사 기법.
- 법정 제출을 전제로 하므로 엄격한 과학적 절차와 '디지털 포렌식 5대 기본 원칙'을 준수하여 증거의 신뢰성과 무결성을 입증해야 함.

```
+-------------------------------------------------------------+
|                   디지털 포렌식 5대 기본 원칙                   |
+-------------------------------------------------------------+
| 1. 정당성의 원칙 (Legality)     | 적법절차(영장주의) 준수      |
| 2. 재현성의 원칙 (Repeatability)| 동일 조건에서 동일 결과 도출 |
| 3. 신속성의 원칙 (Expediency)   | 휘발성 데이터 지체 없이 확보 |
| 4. 연계보관성 (Chain of Custody)| 증거 수집-이송-분석 전 과정 추적|
| 5. 무결성의 원칙 (Integrity)    | 수집 시점과 분석 시점 해시 일치|
+-------------------------------------------------------------+
```

---

## 디지털 포렌식 5단계 표준 절차

```
[1. 수집/획득 (Acquisition)]
   - 현장 보존, 쓰기 방지 장치(Write Blocker) 장착
   - 비트스트림 물리 복제(DD, E01) 및 원본 해시값 산출
        |
        v
[2. 이송/보관 (Transport)]
   - 전자파 차단백(Faraday Bag), 정전기 방지 포장
   - 증거 인수인계서(Chain of Custody) 작성 및 서명
        |
        v
[3. 증거 분석 (Analysis)]
   - 원본 보관, '사본(Image)'을 대상으로 분석 수행
   - 파일 카빙, 타임라인 분석, 슬랙 공간 분석, 레지스트리 분석
        |
        v
[4. 문서화 및 보고 (Reporting)]
   - 분석 결과 보고서 작성 (객관적 증거 위주, 주관 배제)
   - 재판 증언 및 증거의 법적 증거능력 입증
```

---

## 휘발성 데이터 수집 순서 (RFC 3227 수집 원칙)

디지털 증거는 전원이 차단되거나 시간이 경과함에 따라 소멸되는 휘발성(Volatility) 차이가 있으므로, 휘발성이 높은 순서대로 신속히 수집해야 함.

```
[휘발성 높음] 1. CPU 레지스터 및 캐시 메모리
     |        2. 시스템 물리 메모리 (RAM 덤프: 활성 세션, 복호화 키, 프로세스)
     |        3. 네트워크 상태 (활성 연결, 라우팅 테이블, 열린 포트)
     |        4. 실행 중인 프로세스 목록 및 로컬 시스템 상태
     |        5. 디스크 임시 파일 시스템 (Swap, Pagefile)
     v        6. 비휘발성 물리 디스크 (HDD, SSD, 플래시 메모리)
[휘발성 낮음] 7. 원격 로깅 데이터, 백업 미디어, 종이 출력물
```

## 증거 무결성 확보를 위한 핵심 기술

| 기술 요소 | 구현 방식 | 포렌식 증거 능력 보장 효과 |
|---|---|---|
| **하드웨어 쓰기 방지기 (Write Blocker)** | SATA, NVMe, USB 포트에 물리 장치 연결 | 분석 PC 연결 시 원본 디스크에 단 1비트의 메타데이터 수정(접속시간 갱신 등)도 원천 차단 |
| **비트스트림 이미지 (Bit-stream Image)** | 논리적 파일 복사가 아닌 디스크 섹터 1:1 전수 복제 (`dd`, `ewf`) | 삭제된 파일, 파일슬랙, 비할당 영역 전체를 사본에 100% 동일하게 복제 |
| **암호학적 해시 검증 (MD5/SHA-256)** | 수집 직후 원본 해시값 생성, 분석 사본 해시값과 상호 대조 | 법정에 증거 제출 시 수집 이후 증거의 위변조가 전혀 없었음을 수학적으로 입증 |
| **연계보관성 추적 (Chain of Custody)** | 증거 관리 대장에 수집자, 시간, 보관 장소, 취급자 상세 기록 | 증거 오염이나 악의적 바꿔치기가 없었음을 입증하여 법적 증거능력(Admissibility) 유지 |

## 결론 및 실무 시사점
- 컴퓨터 포렌식에서 기술적 분석력만큼 중요한 것은 형사소송법상의 적법절차(영장주의, 위법수집증거 배제)와 증거 무결성 입증임.
- 침해사고 대응팀(CERT)은 사고 발생 시 임의로 시스템을 재부팅하거나 명령어를 실행하여 휘발성 증거를 훼손하지 않도록 '라이브 포렌식(Live Forensics)' 표준 가이드를 숙지해야 함.
