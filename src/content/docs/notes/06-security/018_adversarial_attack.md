## 답안 골격
```text
[적대적 공격] ◀━━ 머리: Ⅶ 내 의견 (적대적 훈련(Adversarial Training) + 입력 변환 필터링 다계층 강건성 확보)
 ┃
 ┣━ Ⅰ 개요 ───── 딥러닝 모델의 고차원 선형성 및 비선형 결정 경계 취약점 → 사람 눈에 안 띄는 섭동으로 모델 오분류 유도
 ┣━ Ⅱ 특징 ───── 미세 노이즈 주입(Perturbation) · 전이성(Transferability) · 회피(Evasion)/중독(Poisoning)/추론(Inference)
 ┣━ Ⅲ 구조 ───── 화이트박스(FGSM·BIM·C&W) · 블랙박스(ZOO·전이 공격) · 물리적 공격(패치·스티커)
 ┣━ Ⅳ 흐름 ───── ① 대상 모델 손실함수 기울기 계산 → ② 노이즈 벡터 생성 → ③ 원본 이미지에 섭동 합성 → ④ 오분류 확인
 ┣━ Ⅴ 비교 ───── FGSM(초고속 단일 스텝 연산) vs C&W(최적화 기반 강력한 노이즈 최소화) vs PGD(반복적 사영 경사하강)
 ┗━ Ⅵ 실무 ───── 자율주행 도로표지판 오인식 위험 / 안면인식 우회 / 적대적 훈련 시 정상 데이터 정확도 저하
```
- 필수 키워드: 섭동(Perturbation) · FGSM(Fast Gradient Sign Method) · PGD · C&W 공격 · 적대적 훈련 · 전이성
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 공격 유형 분류표 → Ⅳ FGSM 수식 및 도식 / 25점 = Ⅰ~Ⅶ 전개, 화이트박스 vs 블랙박스 알고리즘과 Ⅵ 모델 강건성 확보 방어책 집중
- 기출: 130회 1교시 12번 `적대적 공격 유형 및 방어기법` → Ⅰ·Ⅲ·Ⅵ / 124회 3교시 4번 `적대적 예제(FGSM 등)와 모델 강건성` → Ⅳ·Ⅴ

## 한 줄 본질
- 딥러닝 모델의 손실 함수 기울기를 역이용하여 사람의 눈에는 보이지 않는 미세한 수학적 노이즈를 주입해 모델이 엉뚱한 오답을 100% 확신하도록 조작하는 공격 → AI 모델 판정 신뢰성 붕괴 / 적대적 방어 훈련 시 연산량 폭증

## 핵심 그림
```text
[FGSM(Fast Gradient Sign Method) 기반 적대적 예제 생성 메커니즘]

   [ 원본 이미지 (x) ]           [ 노이즈 (Perturbation) ]         [ 적대적 예제 (x_adv) ]
  ┌───────────────────┐             ┌───────────────────┐             ┌───────────────────┐
  │                   │             │   $\epsilon \cdot \text{sign}(\nabla_x J(\theta, x, y))$   │             │                   │
  │     판다 (Panda)  │      +      │                   │      =      │     긴팔원숭이    │
  │   신뢰도: 57.7%   │             │   (미세한 섭동)   │             │   신뢰도: 99.3%   │
  └───────────────────┘             └───────────────────┘             └───────────────────┘
         (인간 관점: 완벽한 판다)                                    (모델 관점: 확신을 가진 긴팔원숭이)
```

## 핵심 용어
- 섭동(Perturbation): 인간의 시각으로는 원본과 식별할 수 없을 정도로 작은, 모델 손실 함수를 최대화하는 미세한 노이즈 벡터 ($\epsilon$)
- 전이성(Transferability): 한 모델(A)을 공격하기 위해 생성된 적대적 예제가 모델 구조나 가중치가 다른 전혀 다른 모델(B)에서도 유사하게 오분류를 일으키는 특성

## 핵심 통찰
- 적대적 공격은 신경망이 지나치게 비선형적이어서가 아니라, 초고차원 공간에서 의외로 '선형적'으로 동작하기 때문에 발생함 (선형 입력의 미세 오차가 고차원에서 눈덩이처럼 누적됨)
- 자율주행 차량의 카메라가 정지(STOP) 표지판에 붙은 작은 스티커 때문에 시속 60km 제한 표지판으로 오인식하는 등 물리적 환경에서도 치명적 사고 유발 가능
- 적대적 예제를 훈련 데이터에 포함하는 '적대적 훈련(Adversarial Training)'이 가장 확실한 방어책이지만, 정상 데이터에 대한 일반화 정확도(Accuracy)가 2~5% 하락하는 트레이드오프가 존재함

## 이웃 토픽과 구분
- 적대적 공격 vs 데이터 중독(Data Poisoning): 적대적 공격 = 모델 훈련 완료 후 추론 단계에서 입력을 조작(Evasion) / 데이터 중독 = 모델 훈련 단계에서 악성 데이터를 심어 백도어 형성

## 문제·원인·대책
- 사례: 130회 기출 자율주행 AI 모델이 노이즈 패치가 부착된 정지 표지판을 인식하지 못하고 통과한 사고
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 표지판 스티커로 인한 실시간 오인식 | 고차원 픽셀 섭동에 대한 결정 경계 취약 | PGD 기반 적대적 훈련(Adversarial Training) 및 다중 센서(LiDAR/Radar) 융합 | 노이즈 주입 시에도 올바른 클래스 판별 강건성 확보 |
| 적대적 공격 생성 도구(Foolbox 등)를 악용한 모델 무력화 | 모델 가중치 노출 또는 쿼리 기반 블랙박스 공격 허용 | 입력 이미지 무작위 리사이징, JPEG 압축 필터링, 엔트로피 검사 | 고주파 섭동 노이즈 사전 상쇄 및 공격 무력화 |
