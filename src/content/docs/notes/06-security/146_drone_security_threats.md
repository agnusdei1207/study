# 드론 보안위협

## 핵심 개념
- 무인항공기(UAV, Unmanned Aerial Vehicle)와 지상관제소(GCS, Ground Control Station) 간의 무선 통신 링크, 하드웨어·펌웨어, 센서 및 물리적 비행체를 대상으로 발생하는 사이버·물리적 보안 침해 행위.
- 통신 링크 무선 취약성, 경량 임베디드 장비의 연산 제약으로 인한 암호화 미적용, GPS 신호 의존성을 악용하여 기체 탈취(Hijacking), 도청, 비행 방해, 추락 사고를 유발.

```
+-------------------------------------------------------------+
|                      드론 공격 계층 구조                      |
+-------------------------------------------------------------+
| 1. 센서/물리 계층  | GPS 스푸핑, 초음파·자이로센서 공진 주파수 교란  |
| 2. 무선통신 계층   | RF 재밍, WiFi 탈취(드림스모크), 중간자 공격    |
| 3. 소프트웨어 계층 | 펌웨어 덤프, 역공학, 임베디드 리눅스 백도어      |
| 4. 제어/관제 계층  | MAVLink 위조 명령 주입, 지상관제소(GCS) 악성코드|
+-------------------------------------------------------------+
```

---

## 계층별 보안위협 분류

### 1. 센서 및 물리 계층 공격
- **GPS 스푸핑(Spoofing)**: 위조 GPS RF 신호를 실제 위성 신호보다 강한 세기로 송출하여 위도·경도·고도 좌표를 조작, 지정 항로 이탈 및 강제 착륙 유도.
- **GPS 재밍(Jamming)**: 광대역 노이즈를 GPS 수신 대역(L1/L2)에 방사하여 위성 신호 수신을 마비시키고 비행 페일세이프(Fail-safe) 모드 오작동 유발.
- **센서 스푸핑(Acoustic/Resonance Attack)**: 초음파 또는 특정 음향 주파수를 관성측정장치(IMU) 자이로스코프에 방사하여 공진을 일으키고, 수평 제어 기능 무력화로 기체 추락 유발.

### 2. 무선 통신 링크 계층 공격
- **RF 재밍**: 제어 주파수(2.4GHz, 5.8GHz 대역)에 고출력 교란 신호를 방사하여 조종권 단절.
- **MAVLink 위조 명령 주입(Injection)**: 드론 제어 표준 프로토콜인 MAVLink 패킷의 평문 전송 취약점을 악용하여 임의 비행 명령(Return to Launch, Throttle 제어) 강제 전송.
- **Wi-Fi 세션 탈취 및 Deauth 공격**: 상용 상용 드론의 Wi-Fi 제어망에 무단 연결(AP 탈취)하거나 Deauthentication 프레임을 전송해 조종기 연결 해제 후 강제 탈취.

### 3. 소프트웨어 및 펌웨어 계층 공격
- **펌웨어 리버스 엔지니어링**: 하드웨어 디버그 포트(UART, JTAG)를 통한 펌웨어 덤프 추출, 내부 취약점 분석 및 비인가 수정본 재플래싱.
- **통신 라이브러리 버퍼 오버플로우**: 원격 관제 패킷 파싱 루틴의 메모리 관리 결함을 악용하여 임의 코드 실행.
- **지상관제소(GCS) 악성코드 감염**: 관제 PC 및 태블릿을 악성코드에 감염시켜 비행 계획 파일 변조, 카메라 영상 탈취.

## 보안위협 대응 기술 체계

| 구분 | 주요 기술 | 상세 메커니즘 |
|---|---|---|
| **통신 보안** | MAVLink v2 서명 | HMAC-SHA256 기반 패킷 무결성 검증 및 재생 공격 방지(Timestamp 검증) |
| | 전송 채널 암호화 | 제어/원격측정(Telemetry) 링크에 AES-CCM/GCM 기반 기밀성 및 인증 암호화 적용 |
| **센서/항법 보호** | 다중 위성항법(GNSS) 융합 | GPS 단독 의존 탈피, GLONASS, Galileo, BeiDou 동시 수신 및 이상값 배제(RAIM) |
| | 다중 센서 항법(INS/Vision) | GPS 두절 시 관성항법장치(INS) 및 비전 오도메트리(VIO) 기반 추측항법 자동 절체 |
| **펌웨어 보안** | 보안 부팅(Secure Boot) | 하드웨어 RoT(Root of Trust) 기반 전자서명 검증, 위변조된 펌웨어 부팅 차단 |
| | 하드웨어 보안 모듈(HSM/TPM) | 기체 고유 암호키, 인증서 보관 및 물리적 탬퍼링(Tampering) 방어 |
| **대드론(Anti-Drone)** | RF 탐지 및 스캐너 | 드론 원격조종 신호(주파수 홉핑 패턴) 탐지 및 조종사 위치 역추적 |
| | 지향성 RF/GPS 재머 | 불법 침입 드론을 향해 지향성 전파를 발사하여 강제 호버링 또는 착륙 유도 |

## 드론 보안 아키텍처 및 무결성 검증 절차

```
+---------------+      암호화/서명 통신       +---------------+
|   지상관제소  | ------------------------> |   드론 기체   |
|     (GCS)     | <------------------------ |     (UAV)     |
+---------------+    상태 텔레메트리 전송   +---------------+
        |                                           |
        | [Secure Channel: TLS / DTLS / MAVLink v2] |
        v                                           v
+---------------+                           +---------------+
| 인증서버(PKI) | <--- 상호 인증 키 교환 ---> | 하드웨어 HSM  |
+---------------+                           +---------------+
                                                    | Secure Boot
                                                    v
                                            +---------------+
                                            | 비행제어기(FC)|
                                            | (STM32/PX4)   |
                                            +---------------+
```

- **다계층 방어 체계**:
  1. 기체 시동 시 Secure Boot로 펌웨어 해시 검증.
  2. GCS와 기체 간 MAVLink v2 프로토콜 수준의 HMAC-SHA256 패킷 서명 및 카운터 기반 재생 방지.
  3. GNSS 수신 신호 세기 및 위성 시계 편차 감시(RAIM 기법)로 GPS 스푸핑 시도 감지 시 관성항법 모드로 즉각 전환.

## 결론 및 실무 시사점
- 군사·공공 인프라 점검 및 물류 배송 등 드론 활용 영역 확장에 따라 전파 교란과 사이버 탈취 위협이 인명·물리적 피해로 직결.
- 경량 암호(LEA, HIGHT 등) 및 경량 보안 프로토콜을 비행제어컴퓨터(FCC)에 내재화하고, 무인비행체 보안 인증 제도 준수가 필수적임.
