## 한 줄 본질
- 공공기관이 민간 클라우드 서비스를 안전하게 이용할 수 있도록 보안성과 신뢰성을 사전에 검증하는 국가 공인 인증제도 → 공공 데이터 주권 확보 / 글로벌 CSP의 시장 진입 장벽 및 규제 갈등 수반

## 핵심 그림
```text
[CSAP 3등급제(상·중·하) 개편 체계 및 적용 대상]

 ┌─────────────────────────────────────────────────────────────┐
 │                    CSAP 등급제 분류 기준                    │
 ├──────────────┬──────────────────────────────┬───────────────┤
 │     등급     │          적용 시스템         │ 망분리 요건   │
 ├──────────────┼──────────────────────────────┼───────────────┤
 │ 상 (High)    │ 국가 안보, 수사, 외교/국방,  │ 물리적 망분리 │
 │              │ 민감 기밀 데이터             │ (온프레미스급)│
 ├──────────────┼──────────────────────────────┼───────────────┤
 │ 중 (Medium)  │ 비공개 업무 및 대민 서비스,  │ 물리/논리 분리│
 │              │ 개인정보 처리 공공 시스템    │ (기존 요건)   │
 ├──────────────┼──────────────────────────────┼───────────────┤
 │ 하 (Low)     │ 개인정보를 포함하지 않는     │ 논리적 망분리 │
 │              │ 공공기관의 공개 데이터 업무  │ (외산 CSP 허용│
 └──────────────┴──────────────────────────────┴───────────────┘
```

## 핵심 용어
- 물리적 망분리(Physical Separation): 공공 데이터를 저장·처리하는 클라우드 물리 서버 및 네트워크 장비가 일반 민간용 장비와 물리적으로 완전히 격리되어야 하는 요건
- 논리적 망분리(Logical Separation): 가상화 하이퍼바이저, VPC, 전용 암호화 키 분리를 통해 소프트웨어적으로 타 테넌트와의 격리를 보장하는 요건

## 핵심 통찰
- CSAP 개편 이전에는 모든 공공 클라우드에 '물리적 망분리'를 요구하여 글로벌 CSP(AWS, MS, 구글)의 공공 시장 참여가 원천 차단되었음
- 등급제 도입으로 '하' 등급에 한해 논리적 망분리가 허용되면서 글로벌 클라우드 기업들이 공공 시장에 진입할 수 있는 법적 통로가 열림
- 국내 중소 SaaS 기업에게 CSAP 인증 획득은 최소 수천만 원의 비용과 수개월의 시간이 소요되는 진입 장벽이므로 간이 인증 지원 사업이 활발히 진행됨

## 이웃 토픽과 구분
- CSAP vs FedRAMP: CSAP = 대한민국의 공공 클라우드 보안 인증 / FedRAMP = 미국의 연방정부 클라우드 조달을 위한 보안 인증 프로그램(Low/Moderate/High)

## 문제·원인·대책
- 사례: 128회 기출 국내 혁신 스타트업 SaaS 서비스가 CSAP 인증 비용 부담으로 공공 조달 진입을 포기한 사례
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 중소 SaaS의 높은 CSAP 심사 비용 및 인력 부족 | 수십 개에 달하는 IaaS급 인프라 보안 통제 요구 | SaaS 간이평가 트랙(KISA 인증 지원 바우처) 적용 및 표준 PaaS 환경 재활용 | 인증 준비 기간 6개월 단축 및 비용 70% 절감 |
| 외산 CSP 진입 시 데이터 주권 침해 우려 | 글로벌 CSP의 해외 본사 원격 관리 및 데이터 국외 반출 가능성 | 국외 반출 금지 조항 강화 및 국내 리전 내 로컬 암호화 키 독점 소유 강제 | 글로벌 기술 활용과 데이터 주권 방어의 양립 |

## 이렇게 출제된다
- 제128회 1교시: "공공부문 클라우드 서비스 보안인증(CSAP) 등급제(상·중·하)의 도입 배경과 등급별 기준을 설명하시오." → 요구 포인트: Ⅰ 규제 완화 배경 + Ⅴ 등급별 망분리 요건 비교표
- 제120회 1교시: "클라우드 서비스 보안인증(CSAP)의 평가 영역과 인증 절차를 설명하시오." → 요구 포인트: Ⅲ 관리적·물리적·기술적 기준 + Ⅳ 절차

## 내 의견
- [등급제 개편 후 상·중등급 실증 지연으로 인한 시장 혼선] 하등급만 서둘러 열어두고 정작 대다수 공공 사업이 몰려 있는 '중등급' 기준 확정이 지연되어 공공 차세대 클라우드 사업이 정체되는 파행 초래 → 나라면: 금융권 망분리 개선 지침과 연계하여 중등급에서도 데이터 암호화와 엄격한 IAM 통제를 조건으로 논리적 망분리를 단계적 허용하고, 상등급만 국가정보원 국가망보안체계(N2SF) 물리 보안으로 일원화
