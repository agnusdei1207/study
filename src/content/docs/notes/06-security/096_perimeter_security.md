## 답안 골격
```text
[경계 기반 보안(Perimeter Security)] ◀━━ 머리: Ⅶ 내 의견 (성문 방어의 구조적 파산 인정 → ID 기반 마이크로세그멘테이션과 지속 검증 체계로의 단계적 전환)
 ┃
 ┣━ Ⅰ 개요 ───── 신뢰 네트워크(내부망)와 비신뢰 네트워크(외부망)의 물리적·논리적 경계에 방화벽·IPS를 배치하여 단일 진입점 통제에 집중하는 전통적 성-해자(Castle-and-Moat) 모델
 ┣━ Ⅱ 특징 ───── 정적 IP·포트 통제 · 내부망 암묵적 신뢰(Implicit Trust) 부여 · 단일 경계 붕괴 시 무방비 노출 · 원격근무·클라우드 확산으로 경계 소멸
 ┣━ Ⅲ 구조 ───── 외부망(Untrusted) + DMZ(웹/메일 공개 서버) + 경계 장비(Firewall, IPS, VPN) + 내부 신뢰망(Internal Trust Zone)
 ┣━ Ⅳ 흐름 ───── 외부 패킷 인바운드 → 1차 방화벽(L4 ACL 필터링) → 2차 IPS(L7 시그니처 검사) → DMZ 프록시 검증 → 내부망 서버 전달
 ┣━ Ⅴ 비교 ───── 경계 기반 보안(네트워크 위치 중심 신뢰, 성-해자 모델, 측면 이동 취약) vs 제로트러스트(신원·문맥 중심, Never Trust Always Verify, 최소 권한)
 ┗━ Ⅵ 실무 ───── 내부 침입 탐지 불가(VPN 침해 시 내부망 전면 장악) / 분산 클라우드 환경에서 경계 트래픽 병목 / 섀도우 IT 가시성 부재
```
- 필수 키워드: 성-해자(Castle-and-Moat) · 암묵적 신뢰(Implicit Trust) · DMZ · 마이크로세그멘테이션 · 제로트러스트(Zero Trust) · 측면 이동(Lateral Movement)
- 배점 전략: 10점 = Ⅰ 성-해자 모델 개념 → Ⅲ 전통적 경계망(외부-DMZ-내부) 도식 → Ⅴ 제로트러스트와의 핵심 비교 / 25점 = Ⅰ~Ⅶ 전개, 클라우드·원격근무로 인한 경계 와해 배경 상술, 135회 기출(제로트러스트 성숙도 모델 2.0 비교 및 도입 고려사항)과 직결
- 기출: 제135회 4교시 6번: "경계 기반 보안(Perimeter Security)과 제로 트러스트(Zero Trust) 성숙도모델 2.0에 대하여 비교 설명하고, 제로 트러스트 아키텍처 도입 시 고려사항에 대하여 설명하시오."

## 한 줄 본질
- 신뢰 구역과 비신뢰 구역을 외벽 하나로 구분하는 경계 중심 통제 병목 → 내부 침입 성공 시 횡적 이동(Lateral Movement) 통제 불가 → 단일 관문 방어의 단순성 확보 / 클라우드·원격접속 환경에서 방어선 무력화

## 핵심 그림
```text
[전통적 경계 기반 보안: 성-해자(Castle-and-Moat) 아키텍처]

  [외부 인터넷 (Untrusted Zone)]
              │
      ┌───────▼───────┐
      │  외부 방화벽  │ ──> (L4 포트/IP 차단)
      └───────┬───────┘
              ├──────────────────────────┐
              ▼                          ▼
      [DMZ (완충 구역)]         [VPN 게이트웨이]
      - Web Server              - 재택근무자 원격 접속
      - Mail Relay                       │
              │                          │ (한 번 통과하면
      ┌───────▼───────┐                  │  내부 전체 신뢰!)
      │  내부 방화벽  │                  │
      └───────┬───────┘                  │
              ├──────────────────────────┘
              ▼
   [내부 신뢰망 (Trusted Zone)]  <═══ (침입 성공 시 무제한 측면 이동 가능!)
   - ERP / DB / Active Directory / 사내 단말기
```

## 핵심 용어
- 암묵적 신뢰(Implicit Trust): 물리적 사내망 또는 VPN 내부에 진입한 엔드포인트와 트래픽에 대해 추가 인증이나 행위 검증 없이 정상 트래픽으로 간주하는 경계 보안의 취약한 기본 가정
- 마이크로세그멘테이션(Micro-segmentation): 네트워크를 워크로드 및 애플리케이션 단위의 미세 격리 구역으로 분할하여 경계가 뚫려도 동서(East-West) 간 횡적 침투를 차단하는 제로트러스트 핵심 기법

## 핵심 통찰
- 경계 보안의 실패는 방화벽 성능 부족이 아니라 "신뢰와 위치를 동일시한 아키텍처적 오류"에서 기인함 → VPN 인증에 성공한 공격자 PC는 사내 핵심 DB와 제약 없이 통신 가능
- SaaS와 멀티클라우드 도입으로 기업 자산의 70% 이상이 데이터센터 외부에 위치함 → 데이터센터 외벽에 설치된 고가의 침입방지장비(IPS)를 거치지 않는 트래픽이 과반을 넘어섬
- 경계 보안을 일거에 폐기하는 것은 불가능함 → 남북(North-South) 트래픽은 기존 경계 장비로 1차 스크리닝하고, 동서(East-West) 트래픽에 서비스 메시 및 신원 기반 마이크로세그멘테이션을 오버레이하는 하이브리드 접근이 현실적임

## 이웃 토픽과 구분
- 경계 기반 보안 vs 제로트러스트: 경계 기반 보안 = "위치(사내망/VPN) 기반 신뢰 및 남북 트래픽 통제" / 제로트러스트 = "신원·기기 상태 기반 지속 검증 및 동서 트래픽 격리"

## 문제·원인·대책
- 적용 상황: 재택근무용 SSL-VPN 단말 계정 탈취를 통한 내부망 랜섬웨어 전파
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| VPN 계정 탈취 후 사내망 전역으로 횡적 이동(Lateral Movement) | 내부망 진입 단말에 대해 무제한 네트워크 브로드캐스트 및 접근 허용 | SDP(Software Defined Perimeter) 도입 및 워크로드별 마이크로세그멘테이션 | 인가된 단일 애플리케이션만 접근 허용하여 측면 이동 경로 원천 차단 |
| 클라우드 및 재택 단말 트래픽의 본사 경계망 경유 시 대역폭 병목 | 모든 원격 트래픽을 사내 중앙 방화벽으로 헤어핀(Hairpinning) 라우팅 | SASE(Secure Access Service Edge) 기반 클라우드 직접 보안 브로커 적용 | 지연 시간 단축 및 클라우드 트래픽 가시성 확보 |

## 내 의견
- [경계 보안 장비의 즉시 철거 오류 경계] 제로트러스트 선언 후 기존 방화벽과 망분리를 일시에 무력화하려는 시도는 규제 위반 및 과도한 비용 초래 → 나라면: 기존 L4/L7 방화벽을 디도스 및 대량 무차별 대입 공격을 걸러내는 '1차 필터'로 유지하면서, 내부 코어 서버망에 eBPF 기반 서비스 메시를 배포하여 워크로드 간 상호 인증(mTLS)을 강제하는 2단계 점진적 전환 추진
