## 답안 골격
```text
[산업제어시스템(ICS)] ◀━━ 머리: Ⅶ 내 의견 (폐쇄망 신화 탈피 → 퍼듀 모델 기반 존/콘듀잇 구획화 및 IEC 62443 준수)
 ┃
 ┣━ Ⅰ 개요 ───── 발전소·상하수도 등 국가 기반시설 제어(OT)망의 IT 연결 확산 → 스턱스넷 등 물리적 파괴 사이버 공격 위협 대두
 ┣━ Ⅱ 특징 ───── 가용성(Availability) 최우선(CIA 역전: AIC) · 실시간성(Deterministic) · 평문 제어 프로토콜 · 장기 운영 수명(15~20년)
 ┣━ Ⅲ 구조 ───── 퍼듀(Purdue) 엔터프라이즈 참조 아키텍처 (Level 0 현장센서 ~ Level 3 OT운영제어 ~ Level 4 IT엔터프라이즈)
 ┣━ Ⅳ 흐름 ───── ① 센서 측정값 수집 → ② PLC/RTU 제어 로직 연산 → ③ HMI 모니터링 → ④ 액추에이터 물리 구동
 ┣━ Ⅴ 비교 ───── IT 보안(기밀성 최우선, 주기적 패치, 가용성 일부 양보) vs OT/ICS 보안(가용성/안전성 절대 최우선, 패치 극도로 신중)
 ┗━ Ⅵ 실무 ───── Modbus/DNP3 무인증 통신 취약점 / 에어갭(폐쇄망) 우회 악성코드(USB) / 일방향 데이터 전송장치(Data Diode)
```
- 필수 키워드: 퍼듀 모델(Purdue Model) · SCADA · PLC/RTU · Modbus · IEC 62443 · 일방향 전송장치(Data Diode)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 퍼듀 모델 5계층 도식 → Ⅴ IT 보안 vs OT 보안 비교 / 25점 = Ⅰ~Ⅶ 전개, 스턱스넷 킬체인 분석과 Ⅵ 일방향 망연계 및 제어 프로토콜 심층 패킷 검사(DPI) 집중
- 기출: 132회 1교시 5번 `ISA/IEC 62443 기반 산업제어시스템 보안` → Ⅰ·Ⅲ·Ⅵ / 125회 1교시 `ICS/SCADA 보안 위협 및 대책` → Ⅱ·Ⅴ

## 한 줄 본질
- 원전·전력망·공장 등 물리 공정을 감시하고 제어하는 하드웨어 및 소프트웨어 종합 시스템 → IT-OT 융합으로 폐쇄망 경계가 무너지며 공정 조작 및 물리적 폭발 위험 초래 → 국가 인프라 자동화 달성 / 가용성 최우선으로 패치 곤란

## 핵심 그림
```text
[퍼듀 모델(Purdue Model) 기반 ICS/OT 네트워크 계층 및 보안 경계]

 ┌─────────────────────────────────────────────────────────────┐
 │ [Level 4/5: 기업 엔터프라이즈망 (IT)] - ERP, 이메일, 인터넷 │
 └──────────────────────────────┬──────────────────────────────┘
                                │ [방화벽 + DMZ (IT/OT 완충)]
 ┌──────────────────────────────┴──────────────────────────────┐
 │ [Level 3: 사이트 운영 관리망 (OT)] - 엔지니어링 워크스테이션 │
 ├─────────────────────────────────────────────────────────────┤
 │ [Level 2: 감독 제어망 (SCADA/HMI)] - HMI 콘솔, SCADA 서버   │
 ├─────────────────────────────────────────────────────────────┤
 │ [Level 1: 로컬 제어망 (PLC/RTU)] - 프로그래머블 로직 제어기 │
 ├─────────────────────────────────────────────────────────────┤
 │ [Level 0: 물리 공정 계층 (Process)] - 센서, 밸브, 모터, 펌프 │
 └─────────────────────────────────────────────────────────────┘
  (Level 1~0은 Modbus, DNP3 등 평문 레거시 프로토콜 사용)
```

## 핵심 용어
- 퍼듀 모델(Purdue Model): 산업제어시스템의 네트워크를 물리 공정(Level 0)부터 전사 IT망(Level 4)까지 계층별로 분리하여 정의한 글로벌 표준 참조 아키텍처
- 일방향 전송장치(Data Diode): 송신용 레이저 LED와 수신용 광다이오드만으로 물리 구성되어, 데이터가 OT망에서 IT망으로만 흐르고 역방향 유입은 100% 물리 차단되는 보안 장비

## 핵심 통찰
- ICS 환경에서는 암호화나 보안 에이전트 설치로 인해 0.01초라도 제어 패킷이 지연되면 공장 라인이 멈추거나 화학 밸브 압력이 폭발하는 물리적 참사가 발생할 수 있음 (CIA 대신 AIC 원칙)
- 스턱스넷(Stuxnet) 사태에서 입증되었듯 "우리 공장은 외부 인터넷과 끊겨 있는 폐쇄망이라 안전하다"는 주장은 유지보수용 외주 USB나 노트북을 통해 완벽히 무력화됨
- 레거시 제어 프로토콜(Modbus, BACnet 등)은 설계 당시 인증 기능이 없어 누구나 제어 패킷을 위조해 밸브를 열거나 모터를 역회전시킬 수 있음

## 이웃 토픽과 구분
- ICS 보안 vs 스마트팩토리 보안: ICS 보안 = 발전소, 플랜트 등 전통적 기반시설 SCADA/PLC 보호 중심 / 스마트팩토리 보안 = 5G, IoT, 클라우드, AI가 결합된 초연결 제조 환경 보안

## 문제·원인·대책
- 사례: 132회 기출 정수장 제어시스템의 유지보수 노트북을 통해 악성코드가 유입되어 수처리 약품 투입 제어기가 오작동한 사고
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 유지보수 인력 단말을 통한 악성코드 폐쇄망 침투 | 외주 협력사 단말에 대한 반입 통제 및 백신 검사 미흡 | 전용 반입 클린룸 구축, 미디어 검증 및 에어갭 유지보수 점프 호스트 강제 | 악성코드 유입 경로 100% 사전 필터링 |
| 평문 Modbus 패킷 변조로 설비 모터 과회전 파괴 | Modbus 프로토콜 자체의 무인증·평문 전송 구조 | OT 전용 침입탐지(DPI) 솔루션 도입 및 변칙 제어 명령 임계치 차단 | 비인가 제어 명령 실시간 감시 및 설비 보호 |

## 이렇게 출제된다
- 제132회 1교시 5번: "ISA/IEC 62443 기반 산업제어시스템(ICS) 보안의 개념과 보안 계층 구조를 설명하시오." → 요구 포인트: Ⅲ 퍼듀 모델과 존/콘듀잇 + Ⅵ 보안 통제 요구사항
- 제125회 1교시: "산업제어시스템(ICS/SCADA)에 대한 사이버 위협과 계층별 보안 대책을 설명하시오." → 요구 포인트: Ⅱ AIC 특성 + Ⅳ 공격 킬체인과 방어

## 내 의견
- [IT 보안 솔루션의 무분별한 OT망 설치 사고] IT 보안팀이 공장 환경을 이해하지 못하고 공장 PLC 제어 서버에 상용 EDR 백신을 깔아 포트 스캔을 돌리다가 생산 라인 전체가 비상 정지(Trip)되는 사고 빈발 → 나라면: IEC 62443 표준에 따라 공정 제어망은 트래픽을 복제하여 모니터링하는 '수동적 미러링(Passive Sniffing)' 방식의 OT 전용 보안 장비를 배치하고, IT-OT 접점 구간에 물리적 일방향 데이터 다이오드를 설치해 침투 경로를 원천 차단
