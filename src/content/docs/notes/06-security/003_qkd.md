## 답안 골격
```text
[QKD] ◀━━ 머리: Ⅶ 내 의견 (물리적 한계 극복을 위한 QKD 백본망 + 종단 간 PQC 하이브리드 구성)
 ┃
 ┣━ Ⅰ 개요 ───── 양자컴퓨팅에 의한 공개키 암호 무력화 위기 → 양자역학 물리 법칙 기반 절대 비밀키 분배
 ┣━ Ⅱ 특징 ───── 정보이론적 무조건적 안전성 · 불확정성 원리 · 복제 불가능성(No-Cloning) · 도청 즉시 감지
 ┣━ Ⅲ 구조 ───── 단일 광자 송수신기(Tx/Rx) · 양자 채널(광섬유) · 공용 퍼블릭 채널 · 암호키 관리기(KMS)
 ┣━ Ⅳ 흐름 ───── ① 양자상태 광자 전송 → ② 기저 무작위 측정 → ③ 기저 정보 교환(시프팅) → ④ 오류정정 및 비밀성 증폭
 ┣━ Ⅴ 비교 ───── QKD(양자키분배) vs PQC(양자내성암호)
 ┗━ Ⅵ 실무 ───── 전송 거리 한계(약 100km) / 신뢰 노드(Trusted Node) 보안 위험 / 전용 물리 인프라 구축 비용
```

## 한 줄 본질
- 양자컴퓨터의 소인수분해 알고리즘(Shor)으로 기존 공개키 암호체계 붕괴 위험 → 광자의 양자 상태에 비밀키를 실어 보내 도청 시 상태가 붕괴되는 물리법칙으로 도청을 원천 차단 → 무조건적 안전성 획득 / 전용 광케이블 및 거리 제약

```text

 └──────┬───────┘                                          └──────┬───────┘
        │                                                         │
        │               [ 퍼블릭 채널 (공개 협의) ]               │
```

## 핵심 용어
- 복제 불가능성(No-Cloning Theorem): 미지의 양자 상태는 물리적으로 동일하게 복제할 수 없다는 양자역학 원리
- 양자비트 오류율(QBER): 전송 도중 발생한 비트 오류 비율로, 일정 임계치(BB84 기준 약 11%) 초과 시 도청으로 판정하고 키 폐기

## 핵심 통찰
- QKD는 데이터를 직접 암호화해 전송하는 기술이 아니라 대칭키를 안전하게 분배하는 메커니즘임 → 실제 데이터는 전송된 키로 AES-256 등을 통해 암호화됨
- QKD 단독으로는 전송 거리(광섬유 감쇠로 약 100km 내외) 한계로 인해 중간에 신뢰 노드(Trusted Node)를 거쳐야 하며, 이 노드에서 평문 키가 노출되는 물리적 취약점 발생
- 소프트웨어 패치만으로 적용 가능한 PQC와 달리 QKD는 전용 광학 장비와 다크 파이버(전용 광케이블)가 필요해 구축 비용이 매우 큼

## 이웃 토픽과 구분
- QKD vs PQC: QKD = 하드웨어 기반 물리적 광자 전송으로 키 분배 / PQC = 복잡한 수학적 격자·해시 문제 기반으로 기존 네트워크 인프라에서 구동되는 암호 알고리즘

## 문제·원인·대책
- 사례: 135회 기출 국가망 백본 적용 시 장거리 중계 구간의 물리적 보안 한계
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 광섬유 100km 초과 시 신호 감쇠로 키 분배 불가 | 광자 복제 불가 특성으로 일반 광 증폭기(EDFA) 사용 불가 | 하드웨어 보안 모듈(HSM)이 탑재된 물리적 신뢰 노드(Trusted Node) 중계 구축 | 키 중계 구간 물리적 방호 및 장거리 전송 구현 |
| 신뢰 노드 탈취 시 평문 키 노출 위험 | 중계 노드 내부에서 양자 신호가 전기 신호(평문 키)로 변환됨 | 양자 얽힘 기반 종단 간 중계(양자 리피터) 기술 R&D 및 노드 간 다중 경로 키 분할 분배 | 중간 노드 단일 장애점(SPOF) 보안 위험 완화 |

## 내 의견
- [QKD 만능론에 기반한 인프라 투자 과열] QKD 장비 도입만으로 전사 암호화가 완료된다고 여겨 단말 및 클라우드 구간 암호화 투자를 소홀히 하는 경향 존재 → 나라면: 국가 데이터센터 간 대규모 백본망 구간에는 QKD를 적용해 국가급 도청을 물리 차단하고, 수많은 모바일 단말과 클라우드 구간에는 표준화된 PQC(FIPS 203/204)를 탑재하는 계층별 하이브리드 아키텍처를 수립
