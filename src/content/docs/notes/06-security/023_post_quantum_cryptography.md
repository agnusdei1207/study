 ┣━ Ⅴ 비교 ───── PQC(소프트웨어 알고리즘, 호환성 우수) vs QKD(물리 광학 장비, 무조건적 안전성, 거리 제약)

- 필수 키워드: 쇼어(Shor) 알고리즘 · 격자 기반 암호(Lattice) · NIST PQC 표준 · ML-KEM(Kyber) · ML-DSA(Dilithium) · SNDL
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 5대 수학적 난제 분류표 → Ⅴ PQC vs QKD 비교 / 25점 = Ⅰ~Ⅶ 전개, NIST FIPS 표준 현황과 Ⅵ 암호 민첩성(Crypto-Agility) 구현 집중
- 기출: 135회 3교시 4번 `양자 암호 기술 (QKD와 PQC 비교)` → Ⅰ·Ⅴ / 125회 1교시 `양자내성암호(PQC) 유형과 표준화` → Ⅲ·Ⅳ

## 한 줄 본질
- 양자컴퓨터가 고속으로 해결하지 못하는 고차원 격자 등의 복잡한 수학 난제를 활용한 차세대 공개키 암호 알고리즘 → 기존 네트워크 인프라와 소프트웨어 환경에서 즉시 교체 적용 가능 / 공개키 및 서명 크기가 수 킬로바이트로 급증

## 핵심 용어
- 쇼어 알고리즘(Shor's Algorithm): 양자 중첩과 양자 푸리에 변환을 이용해 소인수분해와 이산대수 문제를 다항식 시간($O((\log N)^3)$) 안에 풀어내는 양자 알고리즘
- SNDL(Store Now, Decrypt Later): 공격자가 현재 암호화된 기밀 통신 트래픽을 미리 대량 도청해 저장해 둔 뒤, 미래에 고성능 양자컴퓨터가 개발되면 일괄 해독하는 위협

## 핵심 통찰
- 양자컴퓨터가 아직 상용화되지 않았더라도 SNDL 공격 위협 때문에 국가 기밀, 의료 정보 등 10년 이상 보존되어야 할 데이터는 지금 즉시 PQC로 전환해야 함
- PQC의 가장 큰 공학적 난점은 키와 서명 크기가 기존 RSA(256바이트)나 ECC(64바이트) 대비 수십 배 커서(1~4KB), 네트워크 패킷 분할 및 임베디드 장비 메모리 고갈을 유발한다는 점임
- 전환 과도기에는 레거시 암호의 검증된 안전성과 PQC의 양자 내성을 결합한 하이브리드 키 교환(X25519 + ML-KEM)이 사실상 표준으로 사용됨

## 이웃 토픽과 구분
- PQC vs 양자암호(QKD): PQC = 소프트웨어 암호 알고리즘으로 양자컴퓨터 공격을 방어 / QKD = 광자 물리 현상을 이용해 도청을 감지하는 하드웨어 장비

## 문제·원인·대책
- 사례: 135회 기출 PQC 도입 테스트 시 대형 서명 크기로 인한 네트워크 패킷 단편화 및 웹 브라우징 지연 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| TLS 핸드셰이크 시 패킷 분할로 레이턴시 증가 | PQC 공개키 및 서명 크기가 MTU(1500B)를 초과 | 전송 계층 버퍼 튜닝 및 경량 격자 알고리즘(FN-DSA/Falcon) 선별 적용 | 단일 패킷 전송 유지 및 핸드셰이크 지연 최소화 |
| 미지의 수학적 결함으로 신규 PQC 알고리즘 파훼 위험 | PQC의 실환경 검증 기간 부족 | 하이브리드 모드(기존 ECC + PQC 복합 서명) 강제 적용 | PQC 붕괴 시에도 기존 암호체계가 1차 방어선 유지 |
