# 스마트 그리드(Smart Grid) 보안 위협

## 핵심 개념
- 기존 전력망(전력 생산·송배전·소비)에 정보통신기술(ICT)을 결합하여 에너지 효율을 최적화하는 지능형 전력망 시스템에서 발생하는 사이버·물리적 보안 침해 위협.
- 양방향 통신망과 수많은 원격 계측 인프라(AMI)가 개방형 네트워크로 연결됨에 따라, 원격 제어 시스템(SCADA/EMS) 해킹을 통한 대규모 블랙아웃(광역 정전) 및 인명·국가 안보 피해를 초래할 수 있음.

```
+-------------------------------------------------------------+
|                   스마트 그리드 3대 구성 영역                  |
+-------------------------------------------------------------+
| 1. 고객/수용가 영역  | 스마트 계량기(AMI), 가정 에너지 관리(HEMS)    |
| 2. 통신 인프라 영역  | 무선 메쉬망, 전력선 통신(PLC), 셀룰러 통신     |
| 3. 전력 제어/운영망  | SCADA, 에너지관리시스템(EMS), 배전자동화(DAS) |
+-------------------------------------------------------------+
```

---

## 스마트 그리드 보안 위협 분류 및 공격 경로

```
[수용가/홈 네트워크]             [통신 네트워크]                [전력 제어/관제소]
+-----------------+      무선 메쉬 / PLC / LTE      +-----------------+
| 스마트미터(AMI) | <=============================> | SCADA / EMS 서버|
+-----------------+                                 +-----------------+
        |                                                   |
        | [위협 1: 스마트미터 위변조]                       | [위협 3: 제어명령 주입]
        |  - 전력 사용량 조작 (요금 부정)                   |  - 발전기/변전소 차단기 개방
        |  - 펌웨어 악성코드 감염                           |  - 계통 마비 (블랙아웃)
        |                                                   |
        +-----------------> [위협 2: 통신 도청/재밍] <------+
                            - 중간자 공격(MITM)
                            - 통신 프로토콜 위조(DNP3, Modbus)
```

### 1. 고객 단말 및 원격 검침(AMI) 위협
- **스마트 계량기 위변조(Tampering)**: 하드웨어 디버그 포트 또는 광 인터페이스를 통해 계량기 펌웨어를 조작하여 실제 전력 사용량을 감축하거나 요금을 조작.
- **AMI 봇넷 구축**: 보안이 취약한 수백만 대의 스마트 미터기를 악성코드로 일제히 감염시켜, 원격에서 일제히 전력 공급을 차단(Remote Disconnect)하도록 조작.

### 2. 통신 프로토콜 및 네트워크 위협
- **산업용 제어 프로토콜 취약점**: Modbus, DNP3, IEC 61850 등 전통적 전력 제어 프로토콜의 평문 전송 및 인증 부재 취약점을 악용한 위조 제어 패킷 주입.
- **RF 재밍 및 전력선 통신(PLC) 스니핑**: AMI 무선 구간에 전파 교란을 일으켜 실시간 요금제 및 수요반응(DR) 신호 전송 차단.

### 3. 제어 센터 및 운영 시스템(SCADA/EMS) 위협
- **지능형 지속 위협(APT) 침투**: 외부 업무망(이메일, 웹)을 통해 악성코드(Stuxnet, BlackEnergy, Industroyer)를 내부 제어망으로 유입시켜 제어망 장악.
- **차단기 강제 개방 및 블랙아웃**: 변전소 원격단말장치(RTU) 및 PLC를 조작하여 주요 송전 선로를 차단함으로써 광역 전력망 연쇄 붕괴 유발.

## 스마트 그리드 보안 참조 모델 (NIST IR 7628)

미국 국립표준기술연구소(NIST)는 스마트 그리드 사이버 보안을 위해 **NIST IR 7628** 가이드라인을 수립하고, 보안 3대 속성의 우선순위를 일반 IT 시스템과 다르게 정의함.

| 우선순위 | 전력 제어 시스템 (ICS/OT) | 일반 사무 IT 시스템 |
|---|---|---|
| **1순위** | **가용성 (Availability)**: 전력 공급의 무중단 지속성 | **기밀성 (Confidentiality)**: 데이터 유출 방지 |
| **2순위** | **무결성 (Integrity)**: 제어 명령 및 계측값의 정확성 | **무결성 (Integrity)**: 정보 변조 방지 |
| **3순위** | **기밀성 (Confidentiality)**: 전력 사용 정보 보호 | **가용성 (Availability)**: 시스템 접근성 |

## 스마트 그리드 보안 대책 체계

```
+-------------------------------------------------------------+
|                      스마트 그리드 방어 체계                  |
+-------------------------------------------------------------+
| 1. 기기 보안 | 스마트미터 보안 칩(HSM), Secure Boot, 무결성 검증 |
| 2. 통신 보안 | IEC 62351 표준 암호화, TLS/DTLS 적용, PKI 기기인증|
| 3. 망 분 리  | 제어망과 업무망 간 일방향 데이터 전송장치(단방향망)|
| 4. 관제 모니터링| OT 전용 이상징후 탐지(NDR), 패킷 이상 분석       |
+-------------------------------------------------------------+
```

### 1. 단말 하드웨어 보안 (Root of Trust)
- 스마트 계량기 및 집중기(DCU) 내부에 암호화 모듈(HSM/KCMVP 검증필 암호모듈)을 탑재하여 암호키를 안전하게 보관하고 물리적 개봉 시 키 소거(Tamper-zeroization) 적용.

### 2. 안전한 통신 프로토콜 적용
- **IEC 62351 표준**: DNP3, IEC 60870-5, IEC 61850 프로토콜에 TLS 기반 전송 구간 암호화 및 디지털 서명을 결합하여 무결성과 인증성 보장.

### 3. 물리적 및 논리적 제어망 분리
- 변전소 및 제어센터의 제어망(OT)과 일반 행정 사무망(IT) 사이에 물리적 단방향 전송 장비(Data Diode)를 설치하여 외부로부터의 침투를 물리적으로 차단.

---

## 결론 및 실무 시사점
- 스마트 그리드는 국가 핵심 기반시설로서, 사이버 공격이 전력 시스템의 물리적 파괴로 직결되는 사이버-물리 시스템(CPS)의 전형임.
- NIST IR 7628 및 국제표준 IEC 62443을 준수하고, 암호화가 배제되었던 레거시 기기들을 교체함과 동시에 OT 전용 침입탐지 체계를 수립해야 함.
