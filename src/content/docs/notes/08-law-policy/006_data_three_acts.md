## 답안 골격
```text
[데이터 3법] ◀━━ 머리: Ⅶ 내 의견 (가명정보 결합 자동화 플랫폼 구축 및 결합키 연계 보안 통제 강화)
 ┃
 ┣━ Ⅰ 개요 ───── 데이터 경제 활성화와 프라이버시 보호 양립을 위한 3개 법률 동시 개정
 ┣━ Ⅱ 특징 ───── 가명정보 개념 신설 · 규제 거버넌스 일원화(개보위 격상) · 중복 규제 해소
 ┣━ Ⅲ 구조 ───── 개인정보보호법(일반법·가명화) + 정보통신망법(규정 이관) + 신용정보법(마이데이터)
 ┣━ Ⅳ 흐름 ───── 데이터 가명처리 → 전문기관 결합 신청 → 결합키 연계 결합 → 반출 심사 승인
 ┣━ Ⅴ 비교 ───── 개인정보(식별가능) vs 가명정보(추가정보 결합 필요) vs 익명정보(재식별 불가)
 ┗━ Ⅵ 실무 ───── 전문기관 결합 지연 / 이종 결합 시 결합키 불일치 / 재식별 우려에 따른 소극적 개방
```
- 필수 키워드: 가명정보 · 익명정보 · 결합전문기관 · 개인정보보호위원회 · 신용정보법 · 마이데이터
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 3법 개정 핵심 축 도식 → Ⅴ 3단계 데이터 분류 비교 / 25점 = Ⅰ~Ⅶ 전개, Ⅲ 법률별 개정사항과 Ⅳ 결합 프로세스 상세화
- 기출: 121회 3교시 `데이터 3법 시행령 개정안 내용` → Ⅲ·Ⅳ, 128회 2교시 `데이터 3법과 마이데이터 사업` → Ⅲ·Ⅵ

## 한 줄 본질
- 파편화된 규제로 묶여 있던 빅데이터 활용 물꼬를 트기 위해 가명정보 도입과 컨트롤타워 단일화를 단행한 법률 개편 패키지 → 데이터 융합 경제 시동 / 재식별 리스크 및 결합 절차 복잡성 수반

## 핵심 그림
```text

| 1. 개인정보보호법 (일반법)                                             |
|    - 데이터 3단계 구분 : [개인정보] -> [가명정보] -> [익명정보]        |
|    - 가명정보 특례 : 통계작성·과학적 연구·공익 기록보존 시 동의 없이 활용|
|    - 컨트롤타워 : 개인정보보호위원회(국무총리 소속 중앙행정기관) 격상  |
+------------------------------------------------------------------------+
| 2. 정보통신망법 (개인정보 조항 이관)                                   |
|    - 온라인 개인정보 규정을 개인정보보호법으로 전면 이관 및 일원화     |
|    - 망 안정성, 사이버 보안, 이용자 보호 중심으로 법 기능 재정립       |
+------------------------------------------------------------------------+
| 3. 신용정보법 (금융 분야 특화)                                         |
|    - 마이데이터(본인신용정보관리업) 법제화 및 표준 API 도입             |
|    - 금융 데이터 전문기관 지정 및 이종 산업 간 데이터 결합 활성화     |
+------------------------------------------------------------------------+
```

## 핵심 용어
- 가명정보: 추가 정보 없이는 특정 개인을 알아볼 수 없도록 조치한 정보로, 법적 연구·통계 목적 동의 면제 대상
- 결합전문기관: 대량의 가명데이터를 안전하게 결합하기 위해 정부가 지정한 제3의 전문 기관
- 결합키(Join Key): 주민등록번호 등 고유식별자를 암호화(일방향 해시)하여 서로 다른 기관 간 동일인을 식별해 행을 매핑하는 연계값

## 핵심 통찰
- 데이터 3법의 핵심 공학적 도구는 "가명정보"이며, 이는 원본 개인정보의 효용성을 유지하면서 프라이버시 위험을 법적으로 완화한 안전장치임
- 망법의 온라인 특례를 개인정보보호법으로 합치면서 기업의 온·오프라인 이중 규제 비용이 대폭 해소됨
- 결합 절차가 전문기관 중심의 오프라인·반자동으로 설계되어, 실시간 대용량 데이터 파이프라인 연동에는 기술적 한계가 존재함

## 이웃 토픽과 구분
- 가명정보 vs 익명정보: 가명정보 = 추가 정보를 통해 재식별 가능성이 남아 있어 개인정보보호법 적용 / 익명정보 = 어떤 기술로도 재식별이 불가능하여 법 적용에서 완전 제외

## 문제·원인·대책
- 사례: 128회 기출 통신-금융 이종 데이터 결합 프로젝트의 장기 지연
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 이종 기관 간 결합 데이터 내 매칭 성공률 저하 | 각 기관의 원천 식별값 품질 차이 및 결합키 생성 오타 | 결합키 생성 전 정규화(공백 제거, 표준 포맷) 전처리 표준화 | 매칭 결합률 향상 |
| 결합 데이터 반출 심사 대기로 사업 지연 | 결합전문기관의 수작업 반출 심사 인력 부족 | 반출 심사 자동화 검증 도구(k-익명성, l-다양성 자동 측정) 도입 | 반출 검증 시간 단축 |

## 이렇게 출제된다
- 제121회 3교시 4번: "데이터 3법 시행령 개정안의 주요 내용과 데이터 산업에 미치는 영향을 설명하시오." → 요구 포인트: Ⅲ 3법 개정 핵심 뼈대 + 가명정보 활용 절차
- 제128회 2교시 4번: "데이터 3법과 마이데이터 사업의 연계 방안 및 추진 전략을 설명하시오." → 요구 포인트: Ⅲ 신용정보법 개정 내용 + 마이데이터 표준 API 연동
