## 답안 골격
```text
[정보시스템 등급제] ◀━━ 머리: Ⅶ 내 의견 (정량적 산정식 기반 객관적 등급화와 1등급 시스템 멀티 리전 Active-Active 강제)
 ┃
 ┣━ Ⅰ 개요 ───── 국가 행정망 전면 마비 사태 재발 방지를 위한 시스템 중요도별 차등 관리
 ┣━ Ⅱ 특징 ───── 1~4등급 분류 · 서비스 영향도 중심 · 인프라 이중화 및 공공 SLA 예산 연계
 ┣━ Ⅲ 구조 ───── 등급 산정 기준(사용자수·업무파급력) + 등급별 요건(이중화·DR·RTO/RPO·모니터링)
 ┣━ Ⅳ 흐름 ───── 영향도 평가(정량점수) → 등급 심의 확정 → 등급별 아키텍처 구축 → 연간 재평가
 ┣━ Ⅴ 비교 ───── 획일적 관리(기존: 모든 시스템 평등 대우) vs 정보시스템 등급제(선택과 집중)
 ┗━ Ⅵ 실무 ───── 부처 이기주의로 인한 1등급 과다 신청 / 1등급 요구 예산 미반영
```
- 필수 키워드: 전자정부법 · 1~4등급 체계 · 업무 영향도 · 재해복구(DR) · Active-Active · 공공 SLA 연계
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 1~4등급별 아키텍처 요건 매트릭스 / 25점 = Ⅰ~Ⅶ 전개, Ⅲ 등급 산정 기준과 Ⅵ 재난복구 인프라 예산 연계 집중
- 기출: 139회 2교시 5번 `전자정부법 개정을 통한 정보시스템 등급제와 공공 SLA 표준 의무화` → Ⅰ·Ⅱ·Ⅲ·Ⅳ 전수

## 한 줄 본질
- 수만 개의 공공 시스템을 획일적으로 관리하던 비효율을 깨고 국민 생활에 직결된 핵심 시스템을 1등급으로 지정해 예산과 이중화 기술을 집중 투입하는 차등 거버넌스 → 전산망 복원력 극대화 / 1등급 쏠림 현상 및 예산 불균형

## 핵심 그림
```text
+---------------------- [ 정보시스템 4단계 등급제 체계 ] ----------------------+
|                                                                                |
|  [ 1등급: 국민 생활·생명·안전 직결 ] (정부24, 주민등록, 119/112 등)          |
|  - 인프라 요건 : 멀티 리전(지역 간) Active-Active 이중화 필수                  |
|  - 복구 지표   : RTO 2시간 이내, RPO 실시간 (Zero Data Loss)                   |
|  - 유지관리    : 가용성 99.99%, 연 2회 무중단 페일오버 모의훈련 강제           |
|                                                                                |
|  [ 2등급: 기관 핵심 행정 업무 ] (각 부처 포털, 전자통관, 세무행정 등)        |
|  - 인프라 요건 : 주센터 Active - 원격 DR센터 핫스탠바이(Hot-Standby)          |
|  - 복구 지표   : RTO 4시간 이내, RPO 1시간 이내                               |
|                                                                                |
|  [ 3등급: 일반 행정 지원 ] (내부 결재, 자산관리, 통계 분석 시스템)            |
|  - 인프라 요건 : 웜스탠바이(Warm-Standby) 또는 일일 백업 복구                 |
|  - 복구 지표   : RTO 24시간 이내, RPO 24시간 이내                             |
|                                                                                |
|  [ 4등급: 단순 정보 제공 ] (기관 홍보 홈페이지, 공지사항 게시판 등)            |
|  - 인프라 요건 : 콜드스탠바이(Cold-Standby) 백업 보관                          |
+--------------------------------------------------------------------------------+
```

## 핵심 용어
- Active-Active 아키텍처: 두 개 이상의 데이터센터나 클러스터가 동시에 실제 트래픽을 처리하며, 한쪽 센터가 전소되어도 무중단으로 전체 서비스를 이어받는 구조
- 업무영향분석(BIA, Business Impact Analysis): 시스템 중단 시 발생하는 경제적 손실, 대국민 불편, 법적 파급력을 정량·정성적으로 평가하는 분석 기법
- 복원력(Resilience): 장애나 재난 발생 시 시스템이 충격을 흡수하고 신속히 정상 서비스 상태로 회귀하는 종합적 시스템 역량

## 핵심 통찰
- 등급제의 본질은 "예산의 효율적 배분"임 → 모든 시스템을 99.99%로 만들 예산은 존재하지 않으므로, 1등급 5%에 자원을 쏟아붓고 4등급은 과감히 비용을 줄이는 결단임
- 1등급 시스템 지정 시 가장 중요한 하드웨어 요건은 '단일 장애점(SPOF)'의 배제이며, 네트워크 스위치, 방화벽, 전원 라인까지 전 구간 이중화되어야 함
- 각 부처는 예산을 많이 받기 위해 모든 자기 시스템을 1등급으로 올리려 하므로, 행안부 산하의 엄격한 객관적 정량 평가 모델이 필수적임

## 이웃 토픽과 구분
- 정보시스템 등급제 vs 주요정보통신기반시설 지정: 등급제 = 전자정부법상 서비스 가용성 및 연속성 보장 목적 / 기반시설 지정 = 정보통신기반보호법상 북한 해킹 등 사이버 테러 방호 목적

## 문제·원인·대책
- 사례: 139회 기출 국가 핵심 행정망 L4 장비 불량으로 대국민 온라인 민원 일주일간 마비
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 대민 포털 핵심 시스템의 지역 간 백업 DR 센터 부재 | 기존 시스템이 획일적 3등급 수준 인프라로 방치됨 | 전자정부 1등급 의무 지정 및 대전-대구 간 원격 액티브 이중화 구축 | 재난 시 무중단 연속성 보장 |
| 각 부처의 자의적 등급 자체 평가로 객관성 결여 | 주관적 설문 형태의 등급 산정 기준 | 이용자수, 일일 트랜잭션, 중단 시 피해액 기반 정량 산식(Scorecard) 의무화 | 공정한 등급 확정 |

## 이렇게 출제된다
- 제139회 2교시 5번: "행정·공공기관의 반복적인 전산망 장애를 계기로, 정부는 「전자정부법」 개정을 통해 정보시스템 등급제와 공공 SLA 표준을 도입하고, 2027년부터 의무화를 추진하고 있다. 정보시스템 등급제 기준과 등급별 요구사항을 설명하시오." → 요구 포인트: Ⅰ 추진 배경 + Ⅲ 1~4등급 기준 및 DR/가용성 요건 매트릭스

## 내 의견
- [등급 판정의 주기적 갱신과 종속 시스템(Dependency) 연계 판정] 시스템 자체는 3등급이지만 1등급 시스템이 그 시스템의 인증 API를 호출하는 경우, 3등급 시스템 마비 시 1등급 전체가 마비되는 '연쇄 붕괴' 발생 → 나라면: 시스템 간 API 호출 그래프를 추적하여 1등급 시스템이 의존하는 하위 백엔드 서비스는 자동으로 동일 등급(Tier 1)의 이중화 요건을 상속받도록 '종속성 기반 등급 상속제'를 구축
