## 답안 골격
```text
[공공데이터 베이스 표준화 관리 매뉴얼] ◀━━ 머리: Ⅶ 내 의견 (사후 정제 비용 절감을 위한 데이터 모델링 단계 표준화 린터 내재화)
 ┃
 ┣━ Ⅰ 개요 ───── 공공기관 간 데이터 불일치 해소와 고품질 개방을 위해 행안부가 제정한 예방적 품질관리 지침(2023.04)
 ┣━ Ⅱ 특징 ───── 범정부 표준 단어·용어·도메인 준수 강제 · 설계 단계 예방적 품질 통제 · 테이블 정의서 표준화
 ┣━ Ⅲ 구조 ───── 표준 단어사전 + 표준 용어사전 + 표준 도메인사전 + 코드 표준 + 데이터 모델(개념·논리·물리)
 ┣━ Ⅳ 흐름 ───── 표준화 요소 정의 → 공공데이터 공통표준 준수 검토 → 데이터베이스 설계 반영 → 메타데이터 등록·점검
 ┣━ Ⅴ 비교 ───── 표준화 관리 매뉴얼(설계·구축 단계 사전 예방) vs 공공데이터 품질관리 수준평가(운영 단계 사후 측정)
 ┗━ Ⅵ 실무 ───── 기존 레거시 DB 표준화 전환 비용 / 신규 시스템 개발 시 표준 용어 적용 지연 / 외래키 및 제약조건 미비
```
- 필수 키워드: 공공데이터 베이스 표준화 · 표준 단어사전 · 표준 용어사전 · 표준 도메인 · 공통표준용어 · 행정안전부
- 배점 전략: 10점 = Ⅰ 제정 배경 → Ⅲ 표준화 4대 구성요소(단어·용어·도메인·코드) 도식 → Ⅴ 예방적 품질관리 체계 / 25점 = Ⅰ~Ⅶ 전개, Ⅲ 표준화 구축 절차와 Ⅵ 레거시 전환 방안 집중
- 기출: 132회 4교시 2번 `‘공공데이터 베이스표준화 관리매뉴얼(2023.04.)’을 마련하여예방적품질관리 기준을 제시하고 있다. 이와 관련하여 다음을 설명하시오.` → Ⅰ·Ⅱ·Ⅲ·Ⅳ·Ⅵ 전수

## 한 줄 본질
- 공공기관마다 제각각이던 데이터 명칭과 형식을 설계 단계부터 표준 단어·용어·도메인 사전에 일치시켜, 사후 데이터 정제 비용을 줄이고 기관 간 무결점 데이터 연계를 가능하게 하는 예방적 품질 기준서 → 공공데이터 상호운용성 확보 / 초기 모델링 공수 증가

## 핵심 그림
```text
+--------------------------------------------------------------------------------+
|              공공데이터 베이스 표준화 4대 구성요소 및 파이프라인 (행안부)       |
+--------------------------------------------------------------------------------+
|                                                                                |
|  [ 1. 표준 단어 (Standard Word) ]                                              |
|  - 문법적 최소 단위 의미 요소 정의 (예: 사용자, 번호, 일자)                    |
|  - 단어별 영문 약어명 부여 (예: USR, NO, DT)                                   |
|                         |                                                      |
|                         +-----------------------+                              |
|                         v                       v                              |
|  [ 2. 표준 도메인 (Standard Domain) ]    [ 3. 표준 용어 (Standard Term) ]      |
|  - 데이터 타입 및 길이, 허용값 그룹화    - 단어의 조합으로 업무 명칭 생성       |
|  - 예: 일자형(VARCHAR(8)), 금액형, 여부형 - 예: 사용자 + 번호 -> 사용자번호(USR_NO)
|                         |                       |                              |
|                         +-----------+-----------+                              |
|                                     |                                          |
|                                     v                                          |
|  [ 4. 표준 코드 (Standard Code) ]                                              |
|  - 선택 가능한 코드값 및 코드명 부여 (공통코드 표준 연계)                      |
|                                     |                                          |
|                                     v                                          |
|  [ 데이터 모델 및 DDL 반영 -> 범정부 메타데이터 관리시스템(메타포털) 등록 ]     |
+--------------------------------------------------------------------------------+
```

## 핵심 용어
- 표준 단어: 업무에서 사용하는 가장 작은 의미 단위의 단어로, 하나의 한글 단어에 하나의 영문 약어(Abbreviation)를 일대일 매핑
- 표준 도메인: 속성에 적용할 수 있는 데이터 타입, 길이, 제약조건, 허용값(범위)을 그룹화하여 일관성을 부여하는 기준
- 공통표준용어: 행정안전부가 범정부적으로 모든 공공기관이 공통으로 사용하도록 확정·고시한 필수 표준 어휘(예: 주민등록번호, 도로명주소)

## 핵심 통찰
- 이미 구축된 데이터베이스를 사후에 정제하려면 천문학적인 비용과 데이터 유실 위험이 발생하므로, "설계와 모델링 단계"에서 표준을 강제하는 '예방적(Proactive) 품질관리'가 핵심임
- 기관 자체적인 표준 수립에 앞서 행안부의 '범정부 공통표준용어'를 우선 적용해야 하며, 불일치 시 공공데이터 품질관리 수준평가에서 감점 요인이 됨
- 물리 DB의 컬럼명과 한글 엔티티 속성명이 1:1로 정확하게 대응되어야 데이터 카탈로그 검색과 대국민 API 개방이 원활해짐

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 공공데이터 품질관리 수준평가 | 운영 성과 측정 제도 | 매년 공공기관의 데이터베이스 품질관리 활동과 표준화 준수율을 평가하는 행정 제도 |
| 테이블 정의서 표준 서식 | 산출물 표준화 | 컬럼 한글명, 영문명, 도메인, 널 허용 여부, PK/FK 제약조건을 명시하는 필수 산출물 |

## 이웃 토픽과 구분
- 데이터베이스 표준화 관리 매뉴얼 vs 데이터 품질관리 지침: 표준화 관리 매뉴얼 = 명칭, 도메인, 코드 등 '구조와 메타데이터의 일관성' 집중 / 품질관리 지침 = 값의 유효성, 정합성, 완전성 등 '실제 저장된 데이터 내용' 검증

## 문제·원인·대책
- 사례: 132회 기출 복수 공공기관 간 복지 수혜 데이터 연계 시 동일 속성의 컬럼명 및 데이터 타입 불일치 장애
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| A기관은 `USER_ID`, B기관은 `CUST_NO`로 명명하여 데이터 통합 연계 실패 | 기관별 독자적 DB 설계 및 공통표준용어 미준수 | 행안부 공공데이터 베이스 표준화 매뉴얼 기반 메타데이터 표준 일괄 전환 | 다부처 데이터 매핑 자동화 |
| 주민번호 뒷자리 처리 도메인(VARCHAR(7) vs CHAR(7)) 불일치로 연계 오류 | 표준 도메인 사전 미정의 및 개발자 자의적 DDL 작성 | 전사 데이터 사전 구축 및 CI/CD DDL 배포 전 표준 도메인 자동 검증 | 스키마 불일치 원천 차단 |

## 이렇게 출제된다
- 제132회 4교시 2번: "행정안전부에서는 고품질의 공공데이터 제공 및 활용의 선제적 대응을 위해‘공공데이터 베이스표준화 관리매뉴얼(2023.04.)’을 마련하여예방적품질관리 기준을 제시하고 있다. 이와 관련하여 다음을 설명하시오." → 요구 포인트: Ⅰ 매뉴얼 제정 목적 및 예방적 품질관리 개념 + Ⅲ 표준화 4대 요소(단어·용어·도메인·코드) + Ⅳ 표준화 이행 절차

## 내 의견
- [데이터 모델링 툴과 Git 형상관리를 연동한 DDL 표준 린트 자동화] 공공 SI 프로젝트에서 개발 납기에 쫓겨 표준 단어사전을 거치지 않고 자의적으로 컬럼을 추가하는 관행이 만연함 → 나라면: ERD 모델링 도구(ERwin, DA#) 및 DDL 스크립트 커밋 시점에 행안부 표준 용어사전 API와 대조하여 미등록 약어 사용 시 머지를 차단하는 Pre-commit 린터를 파이프라인에 의무화
