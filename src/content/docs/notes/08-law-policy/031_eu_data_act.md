## 핵심 용어
- 커넥티드 디바이스(Connected Product): 주변 환경이나 사용에 관한 데이터를 획득·생성하고 전자통신 서비스를 통해 전송할 수 있는 하드웨어 제품
- 클라우드 전환 비용(Switching Charges): 고객이 특정 클라우드 서비스 제공자(CSP)에서 다른 제공자로 인프라나 데이터를 옮길 때 발생하는 데이터 송출 요금(Egress Fee) 및 기술 지원비
- 기능적 동등성(Functional Equivalence): 클라우드를 교체한 후에도 이전 환경과 동일한 수준의 서비스 기능과 품질이 유지되는 상태

## 핵심 통찰
- GDPR이 "사람의 프라이버시"를 다루었다면, Data Act는 "기계와 공장에서 쏟아지는 방대한 산업 데이터(Non-personal Data)"의 소유권을 다룸
- 제조사는 기기를 팔고도 데이터를 독점하여 유지보수 시장을 장악해 왔으나, 이제 독립 카센터나 서드파티 앱 개발자에게 데이터를 의무적으로 넘겨주어야 함
- 클라우드 CSP들이 고객을 묶어두는 최고의 무기였던 "아웃바운드 트래픽 요금(Egress Fee)"을 법으로 금지시킴으로써 멀티 클라우드 전환이 가속화됨

## 이웃 토픽과 구분
- Data Act vs Data Governance Act(DGA): DGA = 신뢰할 수 있는 데이터 중개자(데이터 브로커)의 법적 기준 설정 / Data Act = 구체적으로 누가 기기 데이터에 접근할 수 있는지 권리를 배분

## 문제·원인·대책
- 사례: 국내 완성차 기업의 유럽 수출 커넥티드카에 대한 차량 주행 데이터 개방 요구
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 차량 내 실시간 주행 센서 데이터를 서드파티 정비소에 미제공 시 과징금 | 폐쇄형 독자 통신 프로토콜로 외부 API 미지원 | 차량 내 표준화된 온보드 진단(OBD/OTA) RESTful 데이터 전송 모듈 탑재 | Data Act 규제 준수 |
| 데이터 공유 과정에서 배터리 제어 알고리즘 영업비밀 유출 | 원시 데이터와 가공된 제어 로직 간 경계 모호 | 전송 대상 데이터 범위를 '원시 센서 로그'로 엄격 한정하고 NDA 체결 | 핵심 지식재산권 보호 |
