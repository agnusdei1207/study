## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **AMI (Advanced Metering Infrastructure)**: 스마트 미터와 양방향 통신망, HES, MDMS를 결합하여 실시간 계측과 원격 부하 제어를 수행하는 인프라.
- **AMR (Automatic Meter Reading)**: 단방향 통신으로 원격에서 단순 계량 수치만을 수집하던 1세대 원격 검침 시스템.

</details>

- 정의/개념: 스마트 미터와 전력사 중앙 서버 간 **양방향 통신망을 통해 실시간 계량, VEE 품질 검증, 수요반응(DR) 및 원격 부하 제어를 수행하는 지능형 검침 인프라**
- 배경/필요성: 과거 수작업 검침 방식은 방문 인건비 부담과 계측 오류 및 분쟁을 초래하고, 1세대 AMR(원격 검침)은 단순 단방향 통신으로 인해 전력 피크 시 실시간 부하 제어(수요반응: DR)나 계량 데이터의 결측/이상치 보정이 불가능했던 한계를 극복하기 위해, 스마트 계량기(Smart Meter), 고신뢰 양방향 통신망(PLC/Wi-SUN/LTE), HES(Head End System) 및 MDMS(계량 데이터 관리 시스템)를 유기적으로 결합한 지능형 검침 인프라(AMI)를 도입하여 **15분 단위 실시간 사용량 정밀 계측, VEE(검증·추정·편집)를 통한 데이터 무결성 확보 및 동적 요금제(TOU) 기반 양방향 전력 수요 관리**를 달성할 필요

#### 한줄 요약
- 스마트 미터와 양방향 통신망을 통해 실시간 계측, VEE 품질 정제 및 원격 부하 제어를 통합 수행한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **VEE (Validation, Estimation, Editing)**: 수집된 원시 계량 데이터의 통신 오류와 결측치를 통계적으로 검증하고 보정하는 정제 프로세스.
- **DR (Demand Response, 수요반응)**: 전력 피크 시점에 가격 신호나 제어 명령을 전송하여 소비자의 자발적 부하 감축을 유도하는 메커니즘.

</details>

- **실시간 양방향 통신(Two-way Communication)**: 단순 수집을 넘어 **원격 단전/복전 및 수요반응(DR) 제어 명령 하달**
- **VEE 기반 데이터 품질 관리**: 결측·이상 데이터를 검증·추정·편집
- **시간대별 차등 요금제(TOU) 지원**: 15분 단위 정밀 계측을 통해 **피크 시간대 요금 차등화로 전력 부하 분산 유도**

#### 한줄 요약
- 양방향 원격 제어와 VEE 데이터 무결성 보증 및 실시간 수요반응을 지원한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **HES vs MDMS**: 수백만 미터기와의 통신 세션과 명령 하달을 전담하는 HES와 대용량 데이터에 VEE를 적용하여 빌링과 연계하는 MDMS.

</details>

```text
[AMI 인프라 체계]
  │
  ├─ [현장 계측] ── Field Metering
  │     └─ [스마트 미터] (사용량 계측과 원격 개폐 실행)
  ├─ [데이터 수집] ── Data Aggregation
  │     └─ [데이터 집약장치] (현장 데이터를 취합해 상위망으로 중계)
  ├─ [통신 제어] ── Communication Control
  │     └─ [헤드엔드 시스템] (미터 통신 세션과 명령 송수신 관리)
  ├─ [데이터 관리] ── Data Management
  │     └─ [계량 데이터 관리 시스템] (VEE와 계량 데이터 저장)
  └─ [비즈니스 응용] ── Business Application
        └─ [전력 응용 시스템] (과금·수요반응·분석 수행)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| **스마트 미터** | 사용량 계측과 원격 개폐 실행 |
| **데이터 집약장치** | 현장 데이터를 취합해 상위망으로 중계 |
| **헤드엔드 시스템** | 미터 통신 세션과 명령 송수신 관리 |
| **계량 데이터 관리 시스템** | VEE와 계량 데이터 저장 |
| **전력 응용 시스템** | 과금·수요반응·분석 수행 |

#### 한줄 요약
- DCU가 다수 미터의 통신을 모아 HES가 감당할 세션 수를 줄이고 MDMS가 원시 계측값을 과금 가능한 데이터로 정제하므로, 계측과 청구 사이의 검증 단계가 인프라 안에 내재된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **DLMS/COSEM (IEC 62056)**: 스마트 계량기 간 상호운용성을 보장하는 국제 표준 전력 통신 프로토콜 스택.

</details>

```text
[AMI 계측·정제·제어 파이프라인] (진행 ①→④ 정방향, 계측에서 진입, DR 제어 명령 역전송으로 ② 재진입)
  │
  ├─ [스마트 미터] (① 15분 주기 유효·무효 전력량 정밀 계측)
  │
  ├─ [헤드엔드 시스템 (HES)] (② DLMS/COSEM 규격 포장·암호화 수집)
  │
  ├─ [계량 데이터 관리 시스템 (MDMS)] (③ VEE 검증·추정·편집 정제)
  │
  └─ [전력 응용 시스템] (④ 빌링·전력 거래 연계, 피크 경보 시 원격 부하 감축 명령 역전송)
```

분기 결과: 계측 데이터가 **VEE** 정제에서 상태에 따라 갈리며, 실측 갈래는 검증 통과값을 그대로 빌링해 추가 연산 비용이 없는 반면 결측·오류 갈래는 통계 추정값으로 대체하고 **Quality Flag**를 부여하므로 추정 오차를 감수하는 대신 청구 누락·분쟁 비용을 막고, 정제 완료 후에는 같은 양방향 망을 통해 **DR** 부하 감축 명령이 미터로 역전송되어 검침 파이프라인이 제어 채널과 결합한다.

#### 한줄 요약
- VEE 검증에서 실측값 빌링과 추정값 대체로 갈리며, 결측 데이터를 버리는 대신 추정 오차를 감수해 청구의 연속성을 지킨다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **수동 검침** vs **1세대 AMR (단방향)** vs **2세대 AMI (양방향)**.

</details>

| 비교 항목 | 수동 현장 검침 | 1세대 AMR (원격 검침) | 2세대 AMI (지능형 검침) |
|:---|:---|:---|:---|
| 통신 방향 | 통신망 없음 | 미터에서 중앙으로 단방향 | **양방향 통신** |
| 수집 주기 | 현장 방문 주기 | 원격 수집 정책 주기 | 세분화된 원격 계측 주기 |
| 기능 | 수작업 검침·청구 | 원격 계량값 수집 | VEE·원격 제어·수요반응 |
| 수요반응 | 별도 수단 필요 | 직접 제어 제한 | 가격·제어 신호 연계 가능 |
| 주요 한계 | 방문 비용과 오차 | 단방향 기능 제약 | 통신·보안·수명주기 관리 |

#### 한줄 요약
- 수동 검침의 오차와 AMR의 단방향 한계를 극복하고 실시간 양방향 제어를 지원하는 AMI를 채택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Quality Flag (품질 플래그)**: VEE 보정 데이터에 원시값(Raw), 추정값(Estimated), 편집값(Edited) 태그를 부여하여 데이터 추적성을 보장하는 메타데이터.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 계량기 고장 및 통신 오류로 인한 **비정상 과금 분쟁** | **MDMS VEE 프로세스 적용 및 `품질 플래그(Quality Flag)` 관리** | 이상 데이터 100% 탐지 및 요금 산정 신뢰성 확보 |
| 악의적 해커의 가짜 단전 명령 주입으로 인한 **대규모 정전 사고** | **미터-HES 간 `PKI 상호 인증` 및 중요 제어 명령 `이중 승인 강제`** | 비인가 원격 제어 차단 및 전력망 보안성 극대화 |
| 수백만 대 분산 미터기의 보안 인증서 만료로 인한 **통신 마비** | **`OTA (Over-the-Air) 기반 원격 보안 인증서 자동 갱신`** 체계 구축 | 인증서 만료 장애 예방 및 현장 출동 유지보수 비용 절감 |
| 음영 지역(지하 수용가)의 PLC 신호 감쇄로 인한 데이터 수집 누락 | **`Wi-SUN / LoRa 하이브리드 무선 메시 백업 링크`** 구축 | 난청 지역 통신 커버리지 99.9% 달성 |

#### 한줄 요약
- VEE 품질 플래그, PKI 상호 인증, OTA 자동 갱신, 무선 메시 백업으로 운영한다.

## Ⅶ. 결론

- 신재생에너지(태양광/풍력), 분산전원(DER), 전기차 충전 인프라(V2G) 및 가상발전소(VPP)가 확산되는 **차세대 스마트 그리드(Smart Grid) 및 전력 에너지 거래의 가장 핵심적인 디지털 데이터 인프라**로 정립.
- AI 기반 부하 예측 및 제로 트러스트 전력 보안 체계로 진화하는 가운데, 실무 AMI 망 구축 및 운영 시에는 **이상 데이터에 의한 과금 분쟁을 원천 방지하는 MDMS VEE 엔진 및 품질 플래그(Quality Flag) 관리**, **가짜 단전 공격을 방지하는 스마트 미터-HES 간 KCMVP/PKI 암호화 상호 인증**, **수백만 대 계량기의 무중단 관리를 위한 OTA 원격 인증서 자동 갱신**, **지하 음영 지역 통신 단절을 해소하는 PLC+Wi-SUN/LoRa 하이브리드 메시 망 구축**을 결합하여 완벽한 국가 전력망 신뢰성을 완성.

#### 한줄 요약
- AMI는 스마트 미터와 양방향 통신망 및 MDMS VEE를 결합하여 실시간 계량과 수요반응을 실현하는 차세대 전력망 인프라다.
