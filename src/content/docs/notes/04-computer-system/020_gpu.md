## 답안 골격
```text
[GPU] ◀━━ 머리: Ⅶ 내 의견 (메모리 대역폭 병목 해소를 위한 HBM 결합 및 커널 퓨전 최적화)
 ┃
 ┣━ Ⅰ 개요 ───── CPU 직렬 처리의 대규모 행렬 연산 한계 → 수천 개 코어 기반 초병렬 데이터 처리
 ┣━ Ⅱ 특징 ───── SIMT(단일명령 다중스레드) · 대규모 코어 집적 · 초고대역폭 메모리(HBM) · 높은 전력 소모
 ┣━ Ⅲ 구조 ───── SM(스트리밍 멀티프로세서) + CUDA 코어 + 텐서 코어 + 공유 메모리 + HBM/VRAM
 ┣━ Ⅳ 흐름 ───── ① 호스트(CPU)에서 GPU VRAM으로 데이터 복사 → ② 커널 격자(Grid/Block/Thread) 실행 → ③ GPU 메모리에서 호스트 복사
 ┣━ Ⅴ 비교 ───── CPU vs GPU vs TPU
 ┗━ Ⅵ 실무 ───── 메모리 대역폭 한계(Memory Wall) / PCIe 호스트 통신 오버헤드 / 분기 발산(Branch Divergence)
```

## 한 줄 본질
- 제어 로직과 대용량 캐시에 다이 면적 대부분을 소모하는 CPU의 대규모 행렬 병렬 연산 한계 → 수천 개의 경량 ALU(CUDA/텐서 코어)와 초고대역폭 메모리(HBM)를 집적하여 동일 명령어를 대량 데이터에 동시 적용(SIMT) → 딥러닝 텐서 연산 및 그래픽스 처리량 비약적 극대화 / 높은 소비 전력, 발열, 복잡한 조건 분기 시 연산 효율 급락

## 핵심 용어
- SIMT(Single Instruction Multiple Threads): 하나의 명령어를 여러 스레드가 서로 다른 데이터에 대해 병렬로 실행하는 GPU 특유의 실행 모델(32개 스레드를 하나의 워프(Warp)로 묶어 실행)
- 텐서 코어(Tensor Core): 딥러닝의 핵심인 $D = A \times B + C$ (혼합 정밀도 행렬 곱셈-누적) 연산을 단일 클록에 고속 처리하도록 특화된 하드웨어 유닛
- 분기 발산(Branch Divergence): 동일 워프 내 스레드들이 `if-else` 분기에서 서로 다른 경로를 탈 때, 두 경로를 순차 실행하느라 코어 절반이 유휴(Idle) 상태가 되어 연산 효율이 반토막 나는 현상

## 핵심 통찰
- GPU의 연산력(FLOPS)은 기하급수적으로 증가했으나 메모리 대역폭(Byte/s)의 증가 속도가 이를 따라가지 못함 → 현대 LLM 추론은 연산기 부족이 아니라 '메모리에서 가중치를 읽어오는 속도'에 갇히는 메모리 바운드(Memory-bound) 상태임
- 따라서 GPU 성능 극대화의 핵심은 HBM 탑재와 함께 커널 퓨전(Kernel Fusion: FlashAttention처럼 메모리 읽기/쓰기를 통합하여 SRAM 내에서 연산을 끝내는 기법)에 달려 있음
- 호스트 CPU와 GPU 간의 PCIe 버스 전송 속도가 최대 병목이므로, GPU 다이렉트 RDMA(GDR)와 NVLink 스위치 패브릭을 통해 CPU 개입 없이 GPU끼리 직접 메모리를 주고받는 아키텍처가 필수적임

## 이웃 토픽과 구분
- GPU vs TPU: GPU = CUDA 기반의 폭넓은 프로그래밍 유연성과 범용성을 갖춘 AI/그래픽스 겸용 가속기 / TPU = 구글 텐서플로/JAX에 최적화된 2D 시스톨릭 어레이 기반 순수 딥러닝 전용 ASIC
