## 답안 골격
```text
[DCI] ◀━━ 머리: Ⅶ 내 의견 (EVPN-VXLAN 오버레이와 전송 계층 MACsec 암호화를 결합한 무중단 DCI 체계 확립)
 ┃
 ┣━ Ⅰ 개요 ───── 지리적 분산 데이터센터 간 대역폭 한계와 전송 지연 → 초고속·초저지연 전용 상호연결 기술
 ┣━ Ⅱ 특징 ───── 테라비트급 초고대역폭 · 서브 밀리초 저지연 · L2/L3 확장성 · 회선 암호화(MACsec)
 ┣━ Ⅲ 구조 ───── 물리/광 전송 계층(DWDM/Coherent 광학) + 네트워크 계층(MPLS, EVPN-VXLAN, IPsec)
 ┣━ Ⅳ 흐름 ───── ① DC1 서버 트래픽 발생 → ② DCI 게이트웨이 인캡슐레이션(VXLAN) → ③ 광선로 전송(DWDM) → ④ DC2 디캡슐레이션
 ┣━ Ⅴ 비교 ───── DCI 광전송(DWDM) vs 가상사설망(IPsec VPN) vs 전용선(Leased Line)
 ┗━ Ⅵ 실무 ───── 광신호 물리적 감쇄 및 RTT 지연 / L2 브로드캐스트 스톰 전파 위험 / 광케이블 단선(이중화)
```
- 필수 키워드: DWDM(고밀도 파장분할 다중화) · EVPN-VXLAN · L2 확장 · 액티브-액티브 DR · MACsec · 코히런트 광학
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ DCI 계층별 기술 구조도 → Ⅴ 전송 방식 비교표 / 25점 = Ⅰ~Ⅶ 전개, Ⅳ 패킷 캡슐화 흐름과 Ⅵ 멀티 리전 액티브-액티브 DR 연계
- 기출: 134회·140회 `데이터센터 상호연결(DCI) 및 초거대 AI 데이터센터 인프라`

## 한 줄 본질
- 원격 데이터센터 간 공용 인터넷이나 일반 전용선의 대역폭 한계(10G 이하)와 지연 시간으로 인한 실시간 데이터 복제 불가 → DWDM 광전송 및 EVPN-VXLAN 가상화 오버레이 기술을 통해 분산 데이터센터를 단일 고속 백본으로 직결 → 테라비트급 무손실 데이터 전송 및 액티브-액티브 무중단 DR 실현 / 광선로 구축 비용과 지리적 거리에 따른 물리적 빛의 속도(RTT) 한계

## 핵심 그림
```text
+------------------------------+                     +------------------------------+
|     데이터센터 A (DC 1)      |                     |     데이터센터 B (DC 2)      |
|  [ 워크로드 / VM / 파드 ]    |                     |  [ 워크로드 / VM / 파드 ]    |
|              │               |                     |              │               |
|  +-----------v------------+  |                     |  +-----------v------------+  |
|  | DCI Edge (EVPN-VXLAN)  |  |                     |  | DCI Edge (EVPN-VXLAN)  |  |
|  +-----------┬------------+  |                     |  +-----------┬------------+  |
|              │ (L2/L3 캡슐화)|                     |              │               |
|  +-----------v------------+  |                     |  +-----------v------------+  |
|  | Coherent Optical / WDM |  |                     |  | Coherent Optical / WDM |  |
|  +-----------┬------------+  |                     |  +-----------┬------------+  |
+--------------│---------------+                     +--------------│---------------+
               │                                                    │
               └─────────( 다크 파이버 전용 광선로: DWDM )─────────┘
                         - 파장당 400G/800Gbps 다중화
                         - 하드웨어 와이어스피드 암호화 (MACsec)
```

## 핵심 용어
- DWDM(Dense Wavelength Division Multiplexing): 단일 광섬유 케이블에 빛의 파장을 수십~수백 개로 미세 분할하여 각 파장마다 100G~800Gbps 데이터를 동시 전송하는 초고용량 광전송 기술
- EVPN-VXLAN: BGP EVPN을 컨트롤 플레인으로, VXLAN을 데이터 플레인으로 사용하여 L3 네트워크 위에서 지리적으로 떨어진 데이터센터 간 L2 네트워크를 안전하게 연장(Extension)하는 오버레이 표준

## 핵심 통찰
- DCI는 단순한 백업용 회선이 아니라 '지리적으로 떨어진 데이터센터를 논리적으로 하나의 가상 데이터센터로 묶는 중추 신경망'임 → L2 확장이 가능해야 VM이나 컨테이너가 IP 변경 없이 다른 DC로 실시간 라이브 마이그레이션(vMotion) 가능
- 대규모 AI 클러스터(수만 개 GPU)가 전력 한계로 여러 데이터센터에 분산될 때, 분산 학습 올리듀스(All-Reduce) 동기화가 DCI 대역폭과 RTT에 직접 종속됨
- L2 네트워크를 DCI로 무분별하게 연결하면 한 데이터센터의 브로드캐스트 스톰이나 루핑(Looping) 장애가 원격 데이터센터로 전파되어 두 데이터센터가 동시 마비되는 '운명의 공유(Fate Sharing)' 위험이 발생하므로 컨트롤 플레인 격리(BGP EVPN)가 필수적임

## 이웃 토픽과 구분
- DCI vs WAN: 일반 WAN = 다양한 공용 인터넷 및 통신사 망을 경유하는 저속·다목적 광역망 / DCI = 데이터센터 간 대용량 동기화 및 가상화 확장에 특화된 전용 광통신 고대역폭 직결망

## 문제·원인·대책

| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 액티브-액티브 DB 동기식(Sync) 복제 시 트랜잭션 지연 급증 | DC 간 물리적 거리에 따른 광 RTT 지연(100km당 왕복 약 1ms) | 50km 이내 단거리 DC 구축 및 비동기 복제 전환(반경 초과 시) | 트랜잭션 병목 해소 및 데이터 일관성 절충 |

## 내 의견
- [광전송 계층 하드웨어 암호화(MACsec)의 의무화] 데이터센터 간 전용 광케이블은 물리적 도청(Fiber Tapping) 공격에 매우 취약함에도 성능 저하를 우려해 평문 전송하는 사례 빈발 → 나라면: 상위 IPsec 소프트웨어 암호화의 CPU 병목을 피하기 위해, DCI 광 트랜시버 레벨에서 지연 시간 오버헤드가 나노초(ns) 단위에 불과한 와이어스피드 MACsec(IEEE 802.1AE) 하드웨어 암호화를 기본 활성화하여 전송 기밀성 완벽 보장
