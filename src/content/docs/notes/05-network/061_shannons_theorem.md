## 한 줄 본질
- 잡음이 존재하는 전송로에서 무오류 통신이 가능한지 여부와 최대 속도 한계의 불명확성 → 대역폭($B$)과 신호대잡음비($S/N$)로 결정되는 이론적 최대 용량 수식($C = B \log_2(1+S/N)$)을 정립하고 전송률 $R < C$일 때 오류 확률을 0으로 만드는 부호화 존재 증명 → 현대 디지털 무선통신의 이론적 설계 기준 확립 / $R > C$ 환경에서는 오류 없는 통신 원천 불가

## 핵심 그림
```text
[ 샤논의 잡음 채널 용량 공식 및 동작 원리 ]

      +--------------------------------------------------------+
      |  통신 채널 용량 수식 : C = B * log_2( 1 + S / N )  [bps] |
      +--------------------------------------------------------+
          B : 채널 대역폭 (Hz)     S : 신호 전력     N : 잡음 전력
  
    전송률 (R)
        ▲
        │                           [ 전송 불가능 영역 (R > C) ]
        │                           - 아무리 강력한 에러정정 코드를 써도
        │                             오류 발생을 피할 수 없음
    C ──┼────────────────────────────────────────────────────────
        │                           [ 신뢰성 전송 영역 (R < C) ]
        │                           - 적절한 채널 부호화(LDPC, Turbo) 적용 시
        │                             오류율(BER) -> 0 달성 가능!
        └────────────────────────────────────────────────────────> SNR
```

## 핵심 용어
- 백색 가우시안 잡음(AWGN, Additive White Gaussian Noise): 모든 주파수 대역에 걸쳐 균일한 전력 스펙트럼 밀도를 가지며 진폭이 정규분포(가우시안 분포)를 따르는 통신 채널의 가장 기본적인 열잡음 모델
- 샤논 한계(Shannon Limit, -1.59dB): 대역폭 $B$를 무한대로 늘리더라도 통신 용량은 무한대가 되지 않고 $\lim_{B \to \infty} C = \frac{S}{N_0 \ln 2} \approx 1.44 \frac{S}{N_0}$에 수렴하며, 이때 필요한 비트당 최소 신호 대 잡음비 $E_b/N_0$는 약 -1.59dB라는 절대 한계
- 대역폭 제한 채널 vs 전력 제한 채널: 대역폭이 좁고 전력이 충분한 유선망은 고차 변조(256-QAM 등)로 SNR을 활용하고, 전력이 희박하고 대역폭이 넓은 위성/심우주 통신은 대역폭을 넓혀 낮은 SNR을 극복

## 핵심 통찰
- 속도를 올리는 2가지 무기 중 대역폭 확장이 전력 증폭보다 훨씬 효율적: 용량 수식에서 대역폭($B$)은 선형(비례)으로 기여하지만, 신호 전력($S$)은 로그($\log_2$) 함수 안에 갇혀 있어 전력을 10배 올려도 속도는 3~4배 수준으로 완만하게 증가
- 잡음이 있어도 오류를 '완벽하게 0'으로 만들 수 있다는 혁명적 발견: 샤논 이전에는 잡음이 있으면 무조건 오류가 발생한다고 믿었으나, 샤논은 전송률 $R$이 용량 $C$보다 작기만 하면 오류 정정 부호(채널 코딩)를 통해 오류 확률을 무한히 0으로 수렴시킬 수 있음을 수학적으로 입증
- 5G 표준의 LDPC 및 폴라(Polar) 코드는 샤논 한계에 0.1dB 오차 이내로 근접: 샤논은 존재 증명만 하고 구체적 코드를 제시하지 못했으나, 인류는 70년의 연구 끝에 샤논 한계에 완벽히 도달하는 부호화 기술을 완성함

## 이웃 토픽과 구분
- 나이퀴스트 공식 vs 샤논 공식: 나이퀴스트는 잡음이 전혀 없는 이상적 채널에서 신호 레벨($M$)에 따른 속도 한계($C = 2B \log_2 M$) / 샤논은 현실의 열잡음(AWGN) 환경에서 신호 대 잡음비(SNR)에 따른 물리적 속도 한계($C = B \log_2(1 + S/N)$)

## 문제·원인·대책
- 적용 상황: 셀룰러 기지국 경계 지역에서의 다운로드 전송률 급감
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 기지국 경계 단말의 통신 두절 및 데이터 손실 | 거리에 따른 신호 감쇠 및 인접 셀 간섭으로 인한 SNR 급감 | 적응적 변복조 및 부호화(AMC: Adaptive Modulation and Coding) 기법 적용 | 열악한 SNR에 맞춰 QPSK 및 저부호율로 자동 강등하여 링크 유지 |
| 송신 전력을 100배 올려도 데이터 전송률 2배 미만 증가 | 샤논 공식의 로그($\log_2$) 함수 특성으로 인한 전력 투입 대비 용량 증가 포화 | 다중 입출력 안테나(MIMO: Multiple-Input Multiple-Output) 공간 다중화 적용 | 채널 수를 $N$개로 늘려 용량을 $N$배 선형 증가 실현 |
