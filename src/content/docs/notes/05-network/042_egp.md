## 한 줄 본질
- 서로 다른 기업·통신사(AS)가 내부 네트워크 지도를 외부에 노출하지 않으면서 상호 트래픽을 교환해야 하는 과제 → 기술적 최단 경로가 아니라 통신사 간 비즈니스 계약 및 보안 정책(Policy)에 따라 AS 단위 경로 벡터(AS-Path)를 교환하는 라우팅 메커니즘 → 전 세계 인터넷의 안전한 자율 상호 연결 달성 / 잘못된 정책 광고로 인한 대규모 BGP 경로 탈취(Hijacking) 위험 노출

## 핵심 그림
```text
[ 자율 시스템(AS) 간 EGP(BGP-4) 라우팅 구조 ]

  +-----------------------+                    +-----------------------+
  |  [ AS 100 : KT 망 ]   |                    |  [ AS 200 : SKB 망 ]  |
  |  - IGP: OSPF 가동     |                    |  - IGP: IS-IS 가동    |
  |  - 내부 최단 경로 계산|                    |  - 내부 최단 경로 계산|
  |           |           |                    |           |           |
  |       [라우터 A]      |                    |       [라우터 B]      |
  +-----------+-----------+                    +-----------+-----------+
              |                                            |
              +======== [ eBGP 세션 (TCP 179 포트) ] =======+
                        "네트워크 X에 가려면 AS 100을 거쳐라"
                        (AS-Path 속성: [100], Local-Pref, MED 등)
                        * 정책(Policy) 기반으로 통과 허용/거부 결정!
```

## 핵심 용어
- AS(Autonomous System, 자율 시스템): 단일 기술적 관리 주체(통신사, 대기업, 대학 등)에 의해 동일한 라우팅 정책으로 운영되는 라우터들의 집합체 (고유 AS 번호 보유)
- 경로 벡터(Path Vector): 거쳐가는 라우터 홉 수가 아니라, 패킷이 통과해야 하는 "AS 번호들의 목록(AS-Path)"을 전달하여 AS 단위의 라우팅 루프를 원천 차단하는 알고리즘
- RPKI(Resource Public Key Infrastructure): 암호학적 디지털 서명을 이용해 특정 IP 대역을 해당 AS가 정당하게 광고할 권한이 있는지를 전 세계 라우터가 검증하는 보안 프레임워크

## 핵심 통찰
- IGP(OSPF, RIP)의 목표는 "어떻게 하면 우리 회사 안에서 가장 빨리(Fastest) 보낼까"이지만, EGP(BGP)의 목표는 "어느 통신사를 거쳐야 돈이 덜 들고 안전한가(Policy)"임
- 따라서 EGP는 물리적 거리가 멀더라도 통신사 간 무료 피어링 계약 경로를 유료 트랜짓 경로보다 최우선 경로로 선택
- 역사적으로 과거의 단순한 "EGP 프로토콜(RFC 904)"은 트리 구조의 인터넷에만 쓰이다가 루프 문제로 폐기되었고, 오늘날 EGP 영역은 사실상 BGP-4가 100% 독점

## 이웃 토픽과 구분
- IGP vs EGP: IGP는 단일 AS 내부에서 최단 지연/비용으로 라우팅 / EGP는 독립된 AS 간 경계에서 비즈니스 정책과 AS-Path 속성으로 라우팅

## 문제·원인·대책
- 적용 상황: 글로벌 BGP 오광고로 인한 대규모 인터넷 트래픽 마비(BGP 하이재킹)
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 특정 통신사가 타사 IP 대역을 무단 광고해 트래픽 탈취 | BGP 프로토콜의 경로 광고 검증 부재(신뢰 기반 동작) | RPKI(자원 공개키 인프라) ROA 서명 검증 강제 | 비인가 AS의 허위 경로 광고를 국경 라우터에서 즉시 드롭 |
| 인터넷 백본 링크의 잦은 단절로 BGP 업데이트 폭증 | 불안정한 회선의 라우트 플래핑(Flapping) 전파 | BGP 라우트 플랩 감쇠(Route Flap Dampening) 적용 | 흔들리는 불안정 경로에 페널티를 부과해 일시 격리 |

## 내 의견
- [BGP 세션 보호를 위한 RPKI 도입 필수화] 통신사나 대형 클라우드 사업자가 실수로 BGP 설정을 잘못하면 금융권이나 포털 사이트 트래픽이 전 세계 엉뚱한 라우터로 빨려 들어가는 블랙홀 장애 빈발 → 나라면: 엔터프라이즈 멀티호밍 구축 시 통신 3사와 연계해 RPKI 인증서(ROA)를 발행 등록하고, BGP Neighbor 세션에 MD5 패스워드와 GTSM(TTL 보안 메커니즘)을 강제하여 경로 위조 원천 봉쇄

## 찾아볼 것
- BGP-4의 최적 경로 선택 8단계 알고리즘(Weight -> Local-Pref -> AS-Path -> Origin -> MED -> eBGP over iBGP -> IGP Metric -> Router ID)
