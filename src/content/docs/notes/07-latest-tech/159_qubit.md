 ┣━ Ⅰ 개요 ───── 0 또는 1의 확정적 비트(Bit)를 사용하는 고전 컴퓨터의 한계를 넘어, 중첩(Superposition)과 얽힘(Entanglement)을 활용하는 양자 컴퓨터의 기본 정보 단위

 ┗━ Ⅵ 실무 ───── 양자 결맞음 시간(Coherence Time, T1/T2)의 짧음 / 열·전자기파 노이즈로 인한 양자 게이트 오류 / 극저온(밀리켈빈) 냉각 요구

## 한 줄 본질
- 0이면서 동시에 1인 상태를 유지하는 양자역학적 마법을 통해, N개의 큐비트로 2의 N승 개에 달하는 방대한 경우의 수를 단 한 번에 계산해 내는 차세대 컴퓨팅의 원자 단위 연산자

## 핵심 그림
```text
[블로흐 구면(Bloch Sphere) 상의 큐비트 상태 표현]

                      |0⟩ (북극: Z축 +1)
                       │
                       │     / |Ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩
                       │   /
                       │ / θ (극각)
                       ├───────► Y축
                      /│\
                     / │ \  φ (방위각)
                    /  │  \
                   X축 │
                       │
                      |1⟩ (남극: Z축 -1)
       * 임의의 점 표면: |α|^2 + |β|^2 = 1 (확률 보존)
```

## 핵심 용어
- 양자 중첩(Superposition): 하나의 큐비트가 관측되기 전까지 0의 상태와 1의 상태에 각각 확률 진폭(α, β)을 가지고 동시에 존재하는 양자역학적 중첩 상태
- 양자 얽힘(Entanglement): 둘 이상의 큐비트가 강하게 연결되어, 하나의 큐비트 상태를 측정하는 순간 물리적 거리와 무관하게 다른 큐비트의 상태가 즉각적으로 결정되는 현상
- 양자 결맞음 시간(Coherence Time): 큐비트가 외부 환경(열, 진동, 전자파)의 간섭 없이 양자 중첩 및 위상 상태를 유지할 수 있는 유효 시간 (T1 이완 시간, T2 탈위상 시간)

## 핵심 통찰
- "2의 N제곱(2^N) 지수적 병렬성의 비밀": 50개 비트는 50개 상태 중 하나만 표현하지만, 50개 큐비트는 2의 50승(약 1,125조 개) 상태를 동시에 중첩하여 단 한 번의 양자 게이트 연산으로 처리함
- 관측하는 순간 붕괴(Measurement Collapse): 모든 중첩된 계산을 마친 후 올바른 정답의 위상(Phase)만 간섭으로 증폭시키고, 측정 순간 하나의 확정된 0 또는 1로 수렴시키는 것이 알고리즘의 핵심
- NISQ(Noisy Intermediate-Scale Quantum) 시대의 한계: 현재는 100~1,000 큐비트 수준의 물리적 큐비트를 다루지만, 노이즈가 심해 오류 없는 진정한 논리 큐비트(Logical Qubit) 1개를 위해 수천 개의 물리 큐비트가 소모됨

## 이웃 토픽과 구분
- 물리 큐비트(Physical Qubit) vs 논리 큐비트(Logical Qubit): 물리 큐비트는 하드웨어 소자 자체에서 만들어진 노이즈에 취약한 큐비트 / 논리 큐비트는 양자 오류 정정(QEC) 코드로 물리 큐비트 여러 개를 묶어 완벽한 무오류 연산을 보장하는 이상적 큐비트

## 내 의견
- [양자 우위(Quantum Supremacy) 달성을 위한 중성 원자(Neutral Atom) 큐비트 기술 주목] 초전도 방식은 확장 시 극저온 배선 한계에 부딪히고, 이온 트랩은 레이저 제어 속도가 느림 → 나라면: 광학 핀셋(Optical Tweezers)으로 레이저 격자 안에 수천 개의 중성 루비듐 원자를 배열하고 뤼드베리(Rydberg) 상태로 얽힘을 유도하는 중성 원자 큐비트 플랫폼에 집중하여, 상온에 가까운 진공 챔버에서 수천 큐비트의 고밀도 논리 큐비트를 경제적으로 양산하는 인프라 전략 채택
