## 핵심 그림
```text
[SOM(Self-Organizing Map)의 3단계 학습 메커니즘 (경쟁 -> 협동 -> 적응)]

   [입력층: D차원 벡터 x]
            │
            │ (가중치 벡터 W_j와의 유클리드 거리 계산)
            ▼
   ┌─────────────────────────────────────────────────────────────┐
   │ 2차원 경쟁층 (Competitive Layer: 2D Grid)                   │
   │                                                             │
   │       O      O      O      O                                │
   │          \   │   /                                          │
   │       O ── [BMU] ── O      <── 1. 경쟁: 최단 거리 승자 선정 │
   │          /   │   \             2. 협동: 가우시안 이웃 함수 │
   │       O      O      O                  (주변 뉴런 함께 흥분)│
   │                                                             │
   │   3. 적응 (Weight Update):                                  │
   │      W_i(t+1) = W_i(t) + α(t) · h_{ci}(t) · (x - W_i(t))    │
   └─────────────────────────────────────────────────────────────┘
```

## 핵심 용어
- 승자 뉴런(BMU, Best Matching Unit): 입력 벡터 $x$와 가중치 벡터 $w_j$ 사이의 유클리드 거리가 가장 가까워 선택된 최우수 뉴런($c = \arg\min_j \|x - w_j\|$)
- 위상 보존(Topology Preservation): 고차원 원본 공간에서 서로 가까이 있던 데이터 포인트들이 2차원 SOM 격자 상에서도 반드시 서로 인접한 뉴런에 매핑되는 수학적 성질
- U-Matrix(Unified Distance Matrix): SOM 경쟁층의 인접 뉴런 가중치 간 거리를 흑백/컬러 명암으로 표현하여, 색이 어두운 골짜기(군집 내부)와 밝은 산맥(군집 간 경계선)으로 시각화하는 표준 기법

## 핵심 통찰
- "경쟁(Competition)과 협동(Cooperation)의 절묘한 조화": 승자 뉴런 하나만 학습시키는 단순 승자독식(WTA)을 쓰면 뉴런들이 고르게 퍼지지 못하고 꼬임 현상이 발생함 → BMU 주변의 이웃 뉴런들도 거리에 비례해 함께 끌어당기는 '협동 학습(Gaussian Neighborhood)'이 SOM 위상 정렬의 핵심 비결임
- 시간 경과에 따른 어닐링(Annealing): 초기에는 학습률 $\alpha(t)$와 이웃 반경 $\sigma(t)$를 크게 잡아 전체 지도를 대략적으로 정렬하고, 후반부로 갈수록 반경을 줄여 미세 튜닝하는 온열 어닐링 프로세스 적용
- 역전파(Backpropagation)가 없는 단층 피드포워드 신경망: 활성화 함수의 미분이나 오차 역전파 없이 순수하게 벡터 간 거리 계산과 가중치 끌어당김만으로 학습하므로 구현이 직관적임

## 이웃 토픽과 구분
- K-Means vs SOM: K-Means는 $k$개 중심점이 서로 아무런 공간적 관계 없이 독립 배치 / SOM은 2차원 격자 상에서 중심점 뉴런들이 서로 이웃 관계를 유지하여 데이터의 연속적 지형도를 파악 가능
