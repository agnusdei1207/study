## 한 줄 본질
- 텍스트만 읽고 쓸 줄 아는 언어 모델은 눈과 귀가 없어 현실 사물의 색상, 위치, 표정, 소리를 이해할 수 없음 → 시각 인코더와 음성 인코더가 뽑아낸 특징 벡터를 언어 모델이 이해할 수 있는 단어 임베딩 공간으로 투영(Projection)하여 하나의 트랜스포머 안에서 함께 추론 → 진정한 물리 세계 이해 / 막대한 이미지 토큰 처리 비용 발생

## 핵심 용어
- 크로스모달 프로젝터(Cross-modal Projector): 이미지나 오디오 인코더가 출력한 고유 차원의 임베딩 벡터를 LLM 백본 신경망의 숨은 상태(Hidden State) 차원과 일치시키는 선형 레이어(Linear) 또는 크로스 어텐션 모듈(Q-Former)
- LLaVA(Large Language and Vision Assistant): 오픈소스 비전-언어 모델의 표준 아키텍처로, 사전학습된 CLIP ViT와 언어 모델 사이에 단순 2계층 MLP를 두고 멀티모달 대화 데이터로 정렬 튜닝함
- 객체 환각(Object Hallucination): 이미지 안에 실제로 존재하지 않는 사물, 사람, 텍스트가 마치 있는 것처럼 그럴듯하게 묘사하는 멀티모달 고유의 치명적 결함

## 핵심 통찰
- "이미지도 결국 단어들의 나열이다": ViT를 통해 이미지를 $16 \times 16$ 픽셀의 패치 조각들로 자르면, 각각의 패치는 하나의 '시각 단어(Visual Word)'가 되며 LLM은 이를 일반 문맥의 단어 토큰과 똑같이 Self-Attention으로 처리함
- 결합형(Compositional) vs 네이티브(Native) 멀티모달: LLaVA처럼 기존에 완성된 비전 모델과 텍스트 모델을 풀로 붙이듯 결합한 방식보다, Gemini나 Chameleon처럼 텍스트, 이미지, 음성 토큰을 단일 사전학습 단계에서부터 섞어 훈련한 네이티브 모델이 모달리티 간 상호 간섭 없이 뛰어난 통합 추론 능력을 발휘함
- 해상도와 토큰 수의 딜레마: $1024 \times 1024$ 이미지는 수천 개의 토큰을 소모하여 LLM 컨텍스트 윈도우를 순식간에 잠식하므로, 패치를 동적으로 병합하거나(Patch Merging) 고해상도 영역만 잘라 확대하는 AnyRes 기술이 필수적임

## 이웃 토픽과 구분
- 전통 VLM vs 멀티모달 LLM: 전통 VLM(CLIP)은 이미지와 텍스트의 유사도 점수만 비교(대조학습) / 멀티모달 LLM은 이미지 안의 복잡한 논리 관계, 도표 추론, 수식 계산을 텍스트로 풀어 설명하는 심층 생성 추론 수행

## 문제·원인·대책
- 적용 상황: 의료 엑스레이 판독 및 차트 분석용 멀티모달 LLM 운영
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 흉부 엑스레이에 결절이 없는데도 모델이 마치 결절이 있는 것처럼 진단문 작성 | 텍스트 사전학습의 사전 확률 편향으로 인한 객체 환각(Object Hallucination) | 대조 디코딩(Contrastive Decoding) 및 DPO 기반 환각 페널티 사후 학습 적용 | 환각 발생률 75% 저감 |
| 고해상도 CT 영상을 입력하자 단 한 장으로 4,096 토큰을 소진하여 VRAM 고갈 | 고정 패치 그리드 분할로 인한 토큰 수 폭증 | 중복 배경 패치를 제거하고 유의미한 영역만 압축하는 비전 토큰 프루닝(Pruning) 적용 | 비전 토큰 60% 절감 및 추론 속도 2.5배 가속 |
| 복잡한 수치가 포함된 그래프 이미지 판독 시 숫자를 오독하는 시각적 맹점 | 저해상도 사전학습 ViT의 미세 텍스트 인식 한계 | 고해상도 타일링(AnyRes) 및 OCR 전용 인코더 듀얼 백본 파이프라인 결합 | 표/차트 수치 인식 정확도 96% 달성 |
