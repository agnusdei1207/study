## 한 줄 본질
- 수박 겉핥기 식 일반 상식은 풍부하나 의학·금융·법률의 심층 전문 어휘와 규정을 이해하지 못하는 범용 LLM의 한계 → 해당 도메인의 전문 원문 코퍼스로 토크나이저를 확장하고 계속 사전학습(Continued Pre-training)을 수행 → 전문 도메인 최고 정확도와 경제적 서빙 달성 / 전문 지식 외 범용 상식 및 창의성 저하

```text
[원시 산업 코퍼스 (금융 공시, 의료 논문, 법률 판례, 사내 기술 문서)]
                               |
                               v
[1. 도메인 토크나이저 확장] : 전문 어휘(의학 용어, 금융 지표) 서브워드 토큰 추가
                               |
                               v
[2. 계속 사전학습 (Continued Pre-training / Domain-Adaptive Pre-training)]
    - 범용 오픈 웨이트 모델(LLaMA 등)에 도메인 코퍼스 수십억 토큰 비지도 학습 주입
                               |
                               v
[3. 도메인 지시 미세조정 (Domain SFT)] : 도메인 전문가 작성 고품질 QA/추론 데이터
                               |
                               v
[4. 도메인 정렬 (Domain DPO/RLHF)] : 산업 규제, 윤리, 안전성 가이드라인 정렬
                               |
                               v
[완성된 도메인 특화 LLM (예: BloombergGPT, Med-PaLM, Legal-BERT)]
```

## 핵심 용어
- Continued Pre-training(계속 사전학습): 이미 대규모로 사전 학습된 범용 모델의 가중치를 시작점으로 삼아, 도메인 특화 말뭉치로 마스크드 언어 모델링(MLM)이나 다음 토큰 예측을 추가 진행하는 방식
- 도메인 토크나이저 확장: 범용 토크나이저에서 여러 개로 잘게 쪼개지던 전문 의학·화학 복합어를 단일 토큰으로 병합하여 모델의 문맥 수용량과 인코딩 효율을 극대화하는 작업
- BloombergGPT: 블룸버그가 수십 년간 축적한 3,630억 토큰의 독점 금융 데이터와 범용 데이터를 50:50으로 혼합 학습시켜 탄생시킨 대표적인 금융 특화 50B DSLM

## 핵심 통찰
- 범용 70B 모델보다 도메인 계속 사전학습을 거친 8B DSLM이 해당 산업 지식 시험(의사 면허, 변호사 시험, CFA)에서 훨씬 적은 추론 비용으로 더 높은 점수를 획득
- 단순히 지시 미세조정(SFT)만 하는 것으로는 새로운 도메인 전문 지식 체계를 모델 가중치에 온전히 심을 수 없으며, 반드시 대규모 비지도 텍스트 기반의 "계속 사전학습"이 선행되어야 함
- 기업 입장에서는 데이터 외부 유출 없이 사내 인프라에서 완결되는 프라이빗 DSLM을 소유하는 것이 핵심 디지털 자산화 전략

## 이웃 토픽과 구분
- DSLM vs RAG: RAG는 범용 모델에게 검색된 외부 전문 문서를 프롬프트로 전달해 답변을 유도 / DSLM은 모델의 두뇌(가중치) 자체에 해당 산업의 언어 체계와 도메인 직관을 영구히 내재화

## 문제·원인·대책
- 적용 상황: 대형 병원의 전자 의무 기록(EMR) 기반 의료 특화 DSLM 구축 시 문제 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 계속 사전학습 중 모델이 기존 일반 한국어/영어 문법 능력을 잃어버림 | 도메인 의료 코퍼스만 100% 사용하여 파괴적 망각 발생 | 일반 상식 데이터셋 20~30%를 리플레이(Replay) 혼합 학습 | 일반 언어 구사력 유지 및 도메인 지식 습득 |
| 복잡한 라틴어 의학 학명 입력 시 토큰 분할 과다로 컨텍스트 낭비 | 범용 어휘집(Tokenizer Vocabulary)의 전문 어휘 부재 | 도메인 특화 토크나이저 확장 및 임베딩 계층 초기화/적응 | 토큰 시퀀스 길이 40% 단축 및 연산 효율화 |
| 임상 환자 진료 기록 내 민감 개인정보(PII) 유출 리스크 | 학습 데이터 정제 단계에서 가명처리 누락 | 전처리 단계에서 정규식 및 고성능 NER 기반 개인정보 자동 마스킹 강제 | 의료법 및 개인정보보호법 완벽 준수 |
