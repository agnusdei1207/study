## 답안 골격
```text
[인공 신경망(ANN)] ◀━━ 머리: Ⅶ 내 의견 (오차역전파 기반 가중치 학습과 비선형 활성화 함수를 통한 범용 함수 근사기(Universal Approximator) 구현)
 ┃
 ┣━ Ⅰ 개요 ───── 인간 뇌의 생물학적 뉴런 동작 메커니즘을 수학적으로 모델링하여, 복잡한 비선형 패턴 인식 및 예측을 수행하는 머신러닝의 핵심 알고리즘
 ┣━ Ⅱ 구조 ───── 입력층(Input Layer) + 은닉층(Hidden Layer) + 출력층(Output Layer) + 가중치(Weights, W) + 편향(Bias, b) + 활성화 함수(Activation)
 ┣━ Ⅲ 동작원리 ─ ① 순전파(Forward Propagation: z = Wx + b, a = σ(z)) → ② 손실 함수(Loss: MSE, Cross-Entropy) 계산 → ③ 역전파(Backpropagation: 연쇄 법칙 체인룰 기반 편미분) → ④ 경사하강법 가중치 갱신
 ┣━ Ⅳ 핵심요소 ─ 활성화 함수(Sigmoid, ReLU, GELU) · 손실 함수 · 역전파 알고리즘 · 과적합 방지(Dropout, 배치 정규화, L1/L2 규제)
 ┣━ Ⅴ 발전계보 ─ 단층 퍼셉트론(Perceptron, XOR한계) → 다층 퍼셉트론(MLP, 역전파도입) → 심층 신경망(DNN) → 특화 신경망(CNN, RNN, Transformer)
 ┗━ Ⅵ 실무 ───── 기울기 소실/폭주(Vanishing/Exploding Gradient) / 과적합(Overfitting) / 블랙박스 특성으로 인한 설명 가능성 부재
```
- 필수 키워드: 인공 신경망(ANN) · 퍼셉트론(Perceptron) · 활성화 함수(Activation Function) · 순전파 · 역전파(Backpropagation) · 연쇄 법칙(Chain Rule) · ReLU · 드롭아웃(Dropout)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 뉴런 수식 모델 및 MLP 네트워크 구조도 → Ⅲ 순전파 및 역전파 흐름 / 25점 = Ⅰ~Ⅶ 전개, 연쇄 법칙(Chain Rule) 기반 역전파 수학적 유도 과정 및 기울기 소실 해결책(ReLU, Skip Connection) 상세화

## 한 줄 본질
- 자극(입력)에 가중치를 곱해 합친 뒤 문턱(활성화 함수)을 넘으면 신호를 쏘고, 뒤에서 날아온 정답과의 오차(역전파)를 통해 가중치들을 조금씩 바로잡으며 배우는 기계 두뇌

## 핵심 그림
```text
[인공 뉴런(Node)의 수학적 연산 모델 및 MLP 순전파/역전파]

   [입력 신호]   [가중치]       [가중합 및 편향]    [활성화 함수]   [출력]
     x1 ──────► w1 ──┐
                     │
     x2 ──────► w2 ──┼──►  ∑ (wi * xi) + b  ──►  σ(z)  ──►  y (예측값)
                     │
     xn ──────► wn ──┘
                             (순전파 Forward: 예측값 산출) ──►
                             ◄── (역전파 Backward: 오차 체인룰 편미분)
                                  ∂Loss/∂w = (∂Loss/∂y) * (∂y/∂z) * (∂z/∂w)
```

## 핵심 용어
- 활성화 함수(Activation Function): 선형 가중합(wx+b)에 비선형성(Non-linearity)을 부여하여 신경망이 비선형 결정 경계와 복잡한 함수를 근사할 수 있도록 만드는 핵심 함수 (예: ReLU, GELU)
- 오차역전파(Backpropagation): 출력층에서 계산된 오차(Loss)를 미분의 연쇄 법칙(Chain Rule)을 이용하여 출력층에서 입력층 방향으로 거슬러 올라가며 각 가중치에 대한 기울기(그래디언트)를 계산하는 알고리즘
- 기울기 소실(Vanishing Gradient): Sigmoid 등의 활성화 함수를 깊은 망에서 사용할 때 역전파 미분값이 계속 곱해져 0에 수렴함으로써 초기 층의 가중치가 학습되지 않는 현상

## 핵심 통찰
- "비선형 활성화 함수가 없으면 아무리 깊어도 단층이다": 활성화 함수가 선형(y=cx)이면 수백 개 층을 쌓아도 수학적으로 하나의 거대한 선형 변환(y=W*x)에 불과하며, 비선형 함수가 있어야 비로소 복잡한 세상의 문제를 풀 수 있음
- 범용 함수 근사 정리(Universal Approximation Theorem): 단 하나의 은닉층을 가진 신경망이라도 충분한 수의 뉴런과 적절한 비선형 활성화 함수가 있다면 임의의 연속 함수를 어떤 정밀도로든 근사할 수 있음
- ReLU 혁명이 연 심층학습(Deep Learning): 음수를 0으로, 양수를 그대로 통과시키는 초단순 함수 ReLU(max(0, x))의 도입으로 미분값이 1로 유지되어 비로소 신경망을 수십, 수백 층으로 깊게 쌓을 수 있게 됨

## 이웃 토픽과 구분
- 퍼셉트론 vs 심층 신경망(DNN): 퍼셉트론은 입력층과 출력층만 있어 XOR과 같은 비선형 분리가 불가능한 원초적 모델 / DNN은 2개 이상의 은닉층을 쌓아 고차원 특징을 계층적으로 추상화하는 심층 네트워크

## 문제·원인·대책
- 적용 상황: 수십 개 은닉층을 가진 결제 사기 탐지 심층 신경망(DNN) 학습
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 은닉층이 깊어질수록 초기 입력층 가중치 업데이트가 멈추고 학습 실패 | Sigmoid 도함수 최대값이 0.25에 불과하여 층을 지날수록 역전파 기울기 소실 | ReLU 또는 Leaky ReLU 활성화 함수 적용 및 He 초기화(He Init) 사용 | 기울기 소실 완벽 해소 및 심층 학습 성공 |
| 학습 데이터셋 정확도는 99%이나 실제 실시간 거래에서는 오탐 폭증 | 모델 파라미터가 지나치게 많아 훈련 데이터의 노이즈까지 암기(과적합) | 은닉 뉴런의 일부를 무작위로 비활성화하는 드롭아웃(Dropout 0.3) 및 L2 규제 적용 | 검증 데이터 일반화 오차 30% 감소 |
| 학습 중 미니배치 분포가 매번 바뀌어 학습 속도가 현저히 느려짐 | 내부 공변량 변화(Internal Covariate Shift) 현상 | 각 은닉층 입력마다 배치 정규화(Batch Normalization) 레이어 삽입 | 수렴 속도 3배 가속 및 높은 학습률 적용 가능 |

## 내 의견
- [기울기 소실의 완벽한 돌파구 잔차 연결(Residual Connection)과 정규화의 조합 필수] 아무리 ReLU를 써도 100층 이상의 초거대 신경망에서는 기울기 분산이 깨짐 → 나라면: ResNet에서 입증된 스킵 연결(Skip Connection: H(x) = F(x) + x)을 아키텍처 전반에 배치하여 역전파 기울기가 아무 손실 없이 입력층까지 고속도로처럼 전달되도록 설계하고, 계층 정규화(Layer Normalization)를 결합하여 대규모 신경망 학습의 수렴 안정성을 극대화
