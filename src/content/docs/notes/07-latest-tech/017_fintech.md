## 답안 골격
```text
[핀테크] ◀━━ 머리: Ⅶ 내 의견 (오픈 API 생태계와 제로 트러스트 보안을 결합한 임베디드 금융(Embedded Finance) 고도화)
 ┃
 ┣━ Ⅰ 개요 ───── 전통 금융기관의 오프라인 지점 중심 고비용 구조 → IT 기술 융합을 통한 비대면·초개인화 금융
 ┣━ Ⅱ 특징 ───── 언번들링(Unbundling) · 플랫폼 종개 · 씬파일러(Thin Filer) 포용 · 실시간 초간편성
 ┣━ Ⅲ 구조 ───── 결제/송금 + 자산관리(로보어드바이저) + 금융플랫폼(오픈뱅킹/마이데이터) + 인프라(클라우드/블록체인)
 ┣━ Ⅳ 흐름 ───── ① 사용자 식별/동의 → ② 오픈 API 금융 데이터 조회 → ③ AI 기반 신용/위험 평가 → ④ 실시간 처리/정산
 ┣━ Ⅴ 비교 ───── 전통 금융(Incumbent) vs 핀테크(FinTech) vs 테크핀(TechFin)
 ┗━ Ⅵ 실무 ───── 망분리 규제 충돌 / 오픈 API 보안 취약점 / 금융 사기 및 계정 탈취(ATO) 위험
```

## 한 줄 본질
- 폐쇄적 금융망과 공인인증서 기반의 복잡한 사용자 경험 한계 → 오픈 API, 클라우드, AI 분석 기술을 결합해 금융 서비스를 일상 소프트웨어 속에 분해·재결합 → 금융 접근성 및 사용자 편의성 혁신 / 보안 사고 전파 위험 및 규제 준수 부담 증가

## 핵심 용어
- 오픈뱅킹(Open Banking): 은행이 보유한 송금·결제·조회 기능을 표준화된 오픈 API로 제3자 핀테크 기업에 개방하는 공동 인프라
- 금융 마이데이터: 고객의 동의하에 여러 금융기관에 흩어진 신용정보를 API로 전송받아 통합 조회 및 맞춤 관리를 제공하는 본인신용정보관리업
- 임베디드 금융(Embedded Finance): 비금융 기업(이커머스, 승차공유 등)의 자체 플랫폼 내부에서 금융 상품(결제, 대출, 보험)을 완결형으로 내장 제공하는 모델

## 핵심 통찰
- 핀테크(FinTech)는 금융사가 IT를 도입해 효율화한 것이고, 테크핀(TechFin)은 빅테크가 자사 플랫폼 트래픽을 기반으로 금융으로 확장한 것임
- 단순 결제 수수료 기반 비즈니스 모델은 마진이 급격히 축소되므로, 축적된 소비 데이터를 바탕으로 맞춤형 대출·보험·투자 상품을 중개하는 데이터 비즈니스로 전환 필수
- 금융 혁신과 보안 컴플라이언스는 상충되므로, 샌드박스 제도를 활용한 실증 후 정식 인가를 받는 단계적 진입 전략이 핵심

## 이웃 토픽과 구분
- 핀테크 vs 테크핀: 핀테크는 금융(Finance) 역량 기반에 IT 기술을 결합 / 테크핀은 IT 기술과 대규모 사용자 플랫폼(Tech) 기반 위에 금융 서비스를 얹는 모델

## 문제·원인·대책
- 적용 상황: 간편결제 핀테크 플랫폼의 계정 도용 및 부정 결제 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 무권한 계좌 이체 및 부정 결제 | 탈취된 자격증명을 통한 크레덴셜 스터핑 공격 | AI 기반 이상거래탐지(FDS) 및 다요소 생체 인증(FIDO2) | 비정상 패턴(단말/위치 변화) 실시간 차단 |
| 오픈 API 토큰 유출로 인한 대량 정보 조회 | OAuth 2.0 액세스 토큰 관리 미흡 및 API 게이트웨이 부재 | 상호 TLS(mTLS), 단기 만료 토큰, 세분화된 스코프(Scope) 강제 | 비인가 제3자 데이터 접근 원천 방지 |
| 혁신 서비스 출시 지연 | 기존 금융 법규(전자금융거래법 등)의 경직성 | 금융규제 샌드박스(혁신금융서비스 지정) 제도 활용 | 인허가 규제 특례를 통한 시장 신속 실증 |

## 이렇게 출제된다
- 제120회 1교시: "오픈뱅킹(Open Banking)의 개념과 핀테크 활성화 관점에서의 기대효과를 설명하시오." → 요구 포인트: Ⅲ 플랫폼 연계 구조 + 오픈 API 효과
- 제125회 2교시: "마이데이터 기반 핀테크 서비스의 아키텍처와 보안 위협 대응 방안을 설명하시오." → 요구 포인트: Ⅳ 데이터 흐름 + Ⅵ API 보안 및 인증 체계

## 내 의견
- [엄격한 물리적 망분리에서 논리적 제로 트러스트 체계로의 규제 현대화 대응] 과거 금융권의 획일적 물리적 망분리는 최신 AI 및 클라우드 SaaS 도입을 가로막는 최대 걸림돌이었음 → 나라면: 금융위원회의 망분리 규제 완화 로드맵에 맞추어, 마이크로 세그멘테이션, 단말 무결성 검증, 데이터 암호화 중심의 제로 트러스트(ZTA) 보안 아키텍처를 도입하여 보안성과 혁신 생산성을 동시 확보
