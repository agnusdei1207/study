## 답안 골격
```text
[혼동행렬] ◀━━ 머리: Ⅶ 내 의견 (비즈니스 비용 함수 기반 임계값(Threshold) 최적화 및 F-beta 지표 도입)
 ┃
 ┣━ Ⅰ 개요 ───── 정확도(Accuracy) 역설 극복 → 실제값과 예측값의 4분면 매핑으로 분류 성능 다각도 측정
 ┣━ Ⅱ 특징 ───── 2x2 격자 구조(이진 분류 기준) · 오류 유형 분리(Type I vs Type II) · 불균형 데이터 평가 강건성
 ┣━ Ⅲ 구조 ───── TP(참 양성) · FP(위 양성, 1종 오류) · FN(위 음성, 2종 오류) · TN(참 음성)
 ┣━ Ⅳ 흐름 ───── ① 모델 확률 예측 → ② 임계값(Threshold) 적용 → ③ 4분면 카운팅 → ④ 파생지표 산출
 ┣━ Ⅴ 비교 ───── 정밀도(Precision) vs 재현율(Recall) vs F1-score vs 특이도(Specificity)
 ┗━ Ⅵ 실무 ───── 극단적 클래스 불균형(암 진단·사기 탐지) / 임계값 변경에 따른 상충(Trade-off)
```
- 필수 키워드: TP · FP · FN · TN · 정확도(Accuracy) · 정밀도(Precision) · 재현율(Recall) · F1-score · ROC-AUC · PR 곡선
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 2x2 매트릭스 도표 및 핵심 공식 4개 → Ⅵ 실무 예시 / 25점 = Ⅰ~Ⅶ 전개, 계산 수식 풀이와 Ⅴ 지표별 비즈니스 트레이드오프 집중
- 기출: 134회 1교시 3번 `머신러닝 성능지표` → Ⅲ·Ⅴ, 135회 1교시 1번 `PR 곡선과 ROC 곡선 비교` → Ⅳ·Ⅴ, 136회 3교시 5번 `혼동행렬 계산(TP=100, FP=5, FN=7, TN=9)` → Ⅲ 수식 계산

## 한 줄 본질
- 전체 정답 비율만 보는 단순 정확도는 클래스 불균형 시 착시 유발 → 실제값과 예측값의 참·거짓 조합을 4분면으로 분할 매핑 → 1종 오류와 2종 오류의 상대적 기회비용을 정량화 / 최적 임계값 선정을 위한 추가 연산 필요

## 핵심 그림
```text
                    [ 예측값 (Predicted) ]
                     Positive        Negative
[ 실제값  Positive  | TP (True Pos)  | FN (False Neg) | -> 실제 양성 합계
 (Actual)          | (정상 예측)    | (2종 오류)     |    (TP + FN)
          ---------+---------------+----------------+
          Negative  | FP (False Pos) | TN (True Neg)  | -> 실제 음성 합계
                    | (1종 오류)     | (정상 예측)    |    (FP + TN)
          ---------+---------------+----------------+
                    v               v
             예측 양성 합계   예측 음성 합계
               (TP + FP)       (FN + TN)
```

## 핵심 용어
- 정밀도(Precision): $TP / (TP + FP)$. 모델이 양성이라 답한 것 중 실제 양성의 비율 (스팸 필터처럼 오탐이 치명적인 분야 핵심)
- 재현율(Recall, 민감도): $TP / (TP + FN)$. 실제 양성인 것 중 모델이 맞춘 비율 (암 진단·불량 검출처럼 미탐이 치명적인 분야 핵심)
- F1-Score: $2 \times (Precision \times Recall) / (Precision + Recall)$. 정밀도와 재현율의 조화평균으로 불균형 데이터의 통합 지표

## 핵심 통찰
- 단순 정확도(Accuracy)는 음성 데이터가 99%인 환경에서 모델이 전부 음성으로 찍어도 99%가 나오는 치명적 맹점 보유
- 정밀도와 재현율은 임계값(Threshold)에 따라 시소처럼 반대로 움직이는 반비례 트레이드오프 관계
- 오류의 비용이 비대칭인 실무에서는 F1(가중치 동일) 대신 $\beta$ 값을 조정한 $F_\beta$ 점수로 비즈니스 손실 최소화 필수

## 이웃 토픽과 구분
- ROC 곡선 vs PR 곡선: ROC(FPR vs TPR)는 클래스 비율 변화에 둔감하여 전체적 모델 판별력 검증에 적합 / PR(Recall vs Precision)은 극단적 불균형 데이터에서 양성 탐지 품질 검증에 유리

## 문제·원인·대책
- 적용 상황: 이상 금융거래 탐지(FDS) 시스템 운영 시 정상 거래 오차단 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| VIP 고객의 정상 결제 차단 급증 | 재현율(Recall)에만 치중하여 임계값을 너무 낮게 설정(FP 증가) | 비즈니스 손실 비용 함수를 반영한 임계값 상향 조정 | 정상 거래 오차단(FP) 감소 및 고객 이탈 방지 |
| 소수 정예 신종 해킹 결제 미탐 | 전체 거래 중 이상 결제 비율이 0.01% 이하로 극단적 불균형 | F1-Score 및 PR-AUC 기반 모델 재평가, 다운샘플링/SMOTE 적용 | 소수 이상 클래스 검출력(Recall) 개선 |
| 다중 분류 평가의 왜곡 | 클래스별 샘플 수 차이로 인한 지표 왜곡 | 매크로(Macro) 및 마이크로(Micro) F1-Score 병행 산출 | 소수 클래스 기여도를 공정하게 반영한 종합 평가 달성 |

## 내 의견
- [단일 지표 맹신 지양과 비용 행렬(Cost Matrix) 통합] 기술팀은 F1-Score 최대화만 추구하여 1종 오류(FP)와 2종 오류(FN)가 야기하는 실제 영업 손실 차이를 간과함 → 나라면: 비즈니스 도메인 담당자와 협의하여 오탐 1건당 손실($C_{FP}$)과 미탐 1건당 손실($C_{FN}$)을 비용 행렬로 수치화하고, 기대 비용(Expected Cost)을 최소화하는 최적 임계값을 프로덕션 파이프라인에 동적 서빙
