## 핵심 용어
- 캄 테크(Calm Technology): 기술이 사람의 주의력(Attention)을 빼앗지 않고, 배경(Periphery)에 조용히 머물다가 필요할 때만 자연스럽게 도움을 주는 사용자 중심 기술
- Zero UI: 스크린, 버튼, 터치패드 등 물리적 인터페이스를 완전히 없애고, 목소리, 시선, 제스처, 신체 존재 자체를 입력 인터페이스로 사용하는 개념
- 매터(Matter): 서로 다른 제조사의 스마트홈 기기(조명, 센서, 가전)들이 로컬 네트워크(IP) 상에서 단일 표준 프로토콜로 상호 운용되도록 하는 글로벌 스마트홈 표준

## 핵심 통찰
- "명시적 명령(Command)에서 암묵적 의도(Intent) 파악으로": 알렉사에게 "불 켜줘"라고 말할 필요조차 없이, 어두운 방에 사람이 들어오면 조명이 켜지는 '비접촉 무자각'의 궁극적 편의성
- 스크린 피로도(Screen Fatigue)의 종말: 하루 종일 스마트폰 알림과 화면에 얽매여 살아가는 현대인에게, 화면 없는 기술(Screenless Computing)을 통해 인간다운 일상을 회복시킴
- 온디바이스 AI와 프라이버시의 결합: 24시간 환경을 감시하는 센서 데이터가 클라우드로 전송되면 빅브라더가 되므로, 로컬 허브 기기 내에서만 맥락을 분석하고 파기하는 프라이버시 우선 설계가 보급의 필수 전제

## 이웃 토픽과 구분
- 유비쿼터스 컴퓨팅 vs 앰비언트 컴퓨팅: 유비쿼터스는 '언제 어디서나 컴퓨팅에 접속할 수 있다'는 하드웨어 인프라적 관점 / 앰비언트는 컴퓨터의 존재감 자체를 지우고 인간의 행동 맥락을 알아서 케어해 주는 지능형 서비스 경험 관점
