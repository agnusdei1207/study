## 한 줄 본질
- 텍스트와 픽셀만 생성하는 소프트웨어 AI의 물리적 행동 불능 한계 → 중력, 마찰력, 관성 등 물리 법칙을 내재화한 파운데이션 모델이 휴머노이드 로봇과 자율 하드웨어를 직접 제어 → 실세계 물리 노동 자동화 / 오작동 시 물리적 파괴 및 인명 사고 위험

## 핵심 그림
```text
[피지컬 AI 폐루프 (Closed-Loop) 제어 아키텍처]
      +-------------------------------------------------------+
      |               물리 세계 (Physical World)              |
      |   (중력, 마찰, 장애물, 대상 물체, 작업 환경)          |
      +-------------------------------------------------------+
            | 멀티모달 센싱                  ^ 모터 액추에이터 구동
            | (카메라, LiDAR, 촉각 센서)    | (관절 각도, 토크 제어)
            v                                |
+-------------------------------------------------------------+
|                     피지컬 AI 두뇌 (Brain)                  |
|                                                             |
|  [ 인지 / 공간 지능 ] ---> [ 월드 모델 (World Model) ]       |
|    - 3D 환경 점군 복원       - 물리 법칙 예측 (Sim2Real)     |
|                                     |                       |
|                             [ VLA 신경망 모델 ]             |
|                               (Vision-Language-Action)      |
+-------------------------------------------------------------+
```

## 핵심 용어
- VLA(Vision-Language-Action): 시각 정보(Vision)와 자연어 지시(Language)를 입력받아 로봇의 관절 각도와 액추에이터 구동 명령(Action) 토큰을 직접 출력하는 통합 멀티모달 모델
- Sim2Real: 물리 세계에서 로봇을 직접 훈련시키는 위험과 비용을 피하기 위해, 고정밀 가상 물리 시뮬레이터(Isaac Sim 등)에서 학습한 모델을 실제 로봇에 이식하는 기술
- 체화된 지능(Embodied AI): 물리적인 신체(로봇 하드웨어)를 가지고 환경과 물리적으로 상호작용하며 경험을 쌓아 학습하는 인공지능

## 핵심 통찰
- 생성형 AI의 오류(환각)는 기껏해야 잘못된 텍스트 출력이지만, 피지컬 AI의 오류는 사람을 치거나 공장 설비를 파괴하는 물리적 재난으로 직결
- 물리 세계의 데이터는 디지털 텍스트처럼 인터넷 크롤링으로 무한 수집이 불가능 → 물리 법칙을 모사하는 합성 데이터 생성과 시뮬레이터(Digital Twin) 의존도가 절대적
- 단순한 비전 인식을 넘어 물체의 무게, 재질의 미끄러움, 접촉 압력을 실시간 감지하는 햅틱/촉각 센서와의 결합이 휴머노이드 상용화의 핵심

## 이웃 토픽과 구분
- 피지컬 AI vs 전통 산업용 로봇: 전통 로봇은 사전에 하드코딩된 고정 좌표만을 맹목적으로 반복 / 피지컬 AI는 미지의 비정형 환경에서도 실시간 시각 피드백을 통해 자율적으로 경로를 수정하며 작업 수행

## 문제·원인·대책
- 적용 상황: 물류 창고 택배 상자 하역 휴머노이드 로봇의 오작동 및 낙하 파손
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 상자를 집어 올리다 찌그러뜨리거나 낙하 | 박스 재질 및 무게에 따른 마찰력 예측 실패 | 그리퍼(Gripper) 촉각 피드백 센서 연동 및 실시간 임피던스 제어 | 적정 파지력 유지로 물품 손상 제로화 |
| 가상 학습 로봇이 현실 이관 시 비틀거림 | 시뮬레이터와 현실의 미세 마찰력 차이(Reality Gap) | 도메인 무작위화(Domain Randomization: 질량, 마찰계수 흔들기) 적용 | 현실 세계의 다양한 변수에 대한 강건성 확보 |
| 사람 접근 시 회피 지연으로 충돌 위험 | LLM 추론 지연시간(수백 ms)으로 인한 제어 주기 지연 | 2계층 제어(상위 VLA 전략 수립 + 하위 1kHz 반사 신경 제어기) 분리 | 밀리초 단위 긴급 제동 및 작업자 안전 보장 |
