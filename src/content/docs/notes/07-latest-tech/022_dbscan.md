## 한 줄 본질
- 원형태로만 묶고 이상치에 취약한 K-Means의 기하학적 한계 → 반경($\epsilon$) 내 최소 데이터 개수($MinPts$)를 만족하는 고밀도 영역을 연결하여 군집 형성 → 기하학적 비선형 군집과 노이즈 분리 / 데이터 밀도가 제각각인 경우 군집 분할 실패

## 핵심 그림
```text
[DBSCAN 3대 점 분류 및 밀도 도달성]
             .  (노이즈 점: 반경 내 이웃 부족 & 핵심점 이웃 아님)
        +-----------------------------------+
        |       *    *     *               |
        |    *    [ C_1 ]====[ C_2 ]       |  C_1, C_2: 핵심점 (Core Point)
        |       *    *  \   /  *    *      |  (Eps 반경 내 점 >= MinPts)
        |                 B                |  
        +-----------------------------------+
                          B: 경계점 (Border Point)
                          (Eps 반경 내 점 < MinPts 이지만 핵심점 이웃)
```

## 핵심 용어
- Epsilon($\epsilon$): 특정 데이터 포인트를 중심으로 이웃 포인트를 탐색하는 물리적 반경 거리
- MinPts: 어떤 점이 핵심점(Core Point)이 되기 위해 $\epsilon$ 반경 내에 포함되어야 하는 최소 데이터 포인트 수
- 밀도 연결성(Density-Connected): 두 점 $p, q$ 사이에 공통의 핵심점 체인이 존재하여 밀도 기반으로 연결될 수 있는 성질

## 핵심 통찰
- K-Means는 모든 데이터를 억지로 특정 클러스터에 배정하지만, DBSCAN은 어디에도 속하지 않는 점을 노이즈(이상치)로 명확히 분리
- $Eps$ 값이 너무 작으면 대부분의 데이터가 노이즈로 분류되고, 너무 크면 전체 데이터가 하나의 거대 군집으로 병합되는 파라미터 민감성 존재
- 데이터 차원이 높아질수록 거리 희소성(Sparsity)으로 인해 모든 점 간의 거리가 비슷해지는 차원의 저주가 발생하므로 PCA 등 사전 차원 축소 필수

## 이웃 토픽과 구분
- DBSCAN vs K-Means: K-Means는 군집 수 $K$를 미리 정해야 하고 구형(볼록) 형태만 탐색 가능 / DBSCAN은 $K$ 지정 없이 초승달·도넛 등 임의 형상을 군집화하고 이상치 탐지 가능

## 문제·원인·대책
- 적용 상황: 지리정보시스템(GIS) GPS 궤적 기반 이동 핫스팟 군집화
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 도심(고밀도)과 외곽(저밀도)의 동시 탐색 실패 | 데이터 영역별 밀도 편차가 심한 환경에서 단일 $Eps$ 적용 | 계층적 밀도 기반 군집화(HDBSCAN)로 전환 | 다양한 밀도를 가진 다중 스케일 클러스터 추출 |
| 최적의 Epsilon 값 선정 난항 | 주관적 경험에 의존한 파라미터 시도 | k-거리 그래프(k-Distance Graph) 작성 후 엘보우(Elbow) 변곡점 도출 | 데이터 분포에 부합하는 통계적 최적 $Eps$ 자동 추출 |
| 수십만 건 위치 데이터 처리 시 연산 지연 | 전수 거리 계산 시 $O(N^2)$ 시간 복잡도 발생 | KD-Tree 또는 Ball-Tree 공간 색인 기법 적용 | 거리 탐색 시간 복잡도를 $O(N \log N)$으로 단축 |

## 내 의견
- [사기 탐지 및 센서 이상치 필터링 파이프라인의 전처리 엔진 활용] DBSCAN은 군집화뿐만 아니라 노이즈 라벨(-1)을 추출하는 강력한 이상 탐지기(Anomaly Detector)로 활용 가능 → 나라면: 공장 센서 시계열 데이터에서 DBSCAN을 1차 통과시켜 노이즈 데이터를 자동 격리하고, 정상 고밀도 클러스터 데이터만을 지도학습 분류 모델의 학습셋으로 정제하여 모델 신뢰성 확보
