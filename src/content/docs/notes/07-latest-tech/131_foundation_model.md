## 한 줄 본질
- 번역 AI, 요약 AI, 코딩 AI를 따로따로 만들던 비효율을 끝내고, 인터넷의 모든 지식을 빨아들인 거대한 만능 기반 모델(Foundation) 하나를 만들어 놓고 살짝 튜닝해서 모든 분야에 가져다 쓰는 현대 AI의 표준 기초 인프라 / 모델 하나가 뚫리면 전 세계 시스템이 동시 마비되는 동질화 위험

## 핵심 용어
- 창발성(Emergence): 모델의 파라미터와 데이터 규모가 특정 임계점(Scaling Threshold)을 넘어서는 순간, 개발자가 명시적으로 가르치지 않은 추론, 유추, 다단계 계획 능력이 불연속적으로 갑자기 발현되는 현상
- 동질화(Homogenization): 의료, 금융, 국방 등 서로 다른 수천 개의 서비스가 단 하나의 동일한 파운데이션 모델을 기반으로 개발됨으로써, 그 기반 모델이 가진 결함, 편향, 취약점이 하류 전체 시스템으로 일괄 전파되는 구조적 위험
- 자기지도학습(Self-Supervised Learning): 사람이 수작업으로 라벨을 달지 않고, 원본 텍스트의 다음 단어를 가리거나 다음 문장을 맞추는 과정 자체를 문제로 삼아 무한히 스스로 학습하는 기법

## 핵심 통찰
- "스탠퍼드 HAI 보고서가 정립한 AI 패러다임의 명명": 2021년 스탠퍼드 연구진은 GPT-3와 같은 모델을 단순히 거대 언어 모델(LLM)이라 부르지 않고, 모든 차세대 AI 시스템의 공통된 '기초(Foundation)'가 된다는 의미에서 '파운데이션 모델'이라는 용어를 제정함
- 규모의 경제와 빅테크 독점: 파운데이션 모델 1회 사전학습에 수백억~수천억 원의 GPU 클라우드 비용이 소모되므로 소수 빅테크의 기술 독점 현상이 심화되며, 이에 대응하여 국가 차원의 오픈소스 소버린(Sovereign) 파운데이션 모델 확보가 안보 이슈로 부상함
- 단일 실패점(Single Point of Failure)의 공포: 한 파운데이션 모델에 적대적 탈옥 공격이 성공하면, 그 모델을 기반으로 만든 수만 개의 은행 챗봇, 공공 민원 서비스, 자율 에이전트가 동시에 탈옥되는 시스템적 리스크 내재

## 이웃 토픽과 구분
- LLM vs 파운데이션 모델: LLM은 텍스트 중심의 대형 언어 모델에 한정 / 파운데이션 모델은 텍스트뿐만 아니라 비전(DALL-E), 음성(Whisper), 멀티모달, 로보틱스 조작(VLA)을 아우르는 상위 개념

## 문제·원인·대책
- 적용 상황: 금융사가 글로벌 상용 파운데이션 모델을 기반으로 사내 여신 심사 AI 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 기반 파운데이션 모델의 훈련 데이터에 내재된 인종/성별 편향으로 인해 대출 심사 차별 발생 | 거대 모델의 동질화(Homogenization) 위험 및 상류 데이터 편향의 하류 전파 | 공정성 메트릭(Disparate Impact) 검증 및 DPO 기반 사후 정렬 가드레일 강제 | 대출 심사 공정성 지표 99% 달성 |
| 파운데이션 모델 공급사의 API 서버 장애 시 사내 모든 핀테크 서비스가 일괄 중단 | 단일 빅테크 모델에 대한 아키텍처적 과도한 종속(SPOF) | 오픈소스 모델(Llama 등) 사내 프라이빗 호스팅 및 멀티 LLM 라우팅 폴백 체계 구축 | 서비스 가용성 99.99% 보장 |
| 고객 금융 상담 내역이 파운데이션 모델 공급사의 재학습 데이터로 무단 수집될 위험 | 상용 클라우드 API의 기본 데이터 보유 약관 | 엔터프라이즈 제로 데이터 보존(ZDR) 계약 체결 및 사내 온프레미스 인스턴스 격리 배포 | 금융 정보 외부 유출 원천 차단 |
