## 답안 골격
```text
[언더피팅] ◀━━ 머리: Ⅶ 내 의견 (특성 공학(Feature Engineering)과 모델 복잡도 증설을 통한 표현력 복원)
 ┃
 ┣━ Ⅰ 개요 ───── 모델의 표현력 부족 → 훈련 데이터셋의 내재된 기본 패턴조차 학습하지 못한 상태
 ┣━ Ⅱ 특징 ───── 고편향(High Bias) · 저분산(Low Variance) · 훈련 손실과 검증 손실이 둘 다 높은 수치로 정체
 ┣━ Ⅲ 구조 ───── 원인(단순모델/특성부족/과도규제) + 진단(학습곡선 정체) + 해결(모델확장/특성공학/규제완화)
 ┣━ Ⅳ 흐름 ───── ① 학습 진행 → ② 훈련 손실 초기 정체 → ③ 검증 손실 동반 정체 → ④ 언더피팅 판정 및 복잡도 상향
 ┣━ Ⅴ 비교 ───── 과소적합(Underfitting) vs 적합(Good Fit) vs 과적합(Overfitting)
 ┗━ Ⅵ 실무 ───── 핵심 도메인 특성 누락 / 과도한 규제 페널티 설정 / 부적절한 활성화 함수(기울기 소실)
```

## 한 줄 본질
- 모델의 파라미터 용량이나 입력 특성이 실제 데이터의 비선형성을 설명하기에 지나치게 단순한 상태 → 훈련 데이터와 검증 데이터 모두에서 높은 오차율을 보이며 성능 수렴 실패 → 모델 구조 확장 및 특성 추가 필요 / 모델 비대화에 따른 과적합 전이 주의

## 핵심 그림
```text
[과소적합(Underfitting) vs 적합(Good Fit) vs 과적합(Overfitting)]
      y ^                  y ^                  y ^
        |   *  *             |   *  *             |   *  *
        |  * /  *            |  * /--\ *          |  * /\ *
        | * /    *           | * /    \*          | */ \ \/*
        |  /                 |  /      \          | /   \
        +---------> x        +---------> x        +---------> x
         [과소적합: 직선]      [적합: 2차 곡선]     [과적합: 고차 다항식]
         (고편향, 단순)       (최적 일반화)        (고분산, 노이즈 암기)
```

## 핵심 용어
- 고편향(High Bias): 데이터의 복잡한 관계에 대해 잘못되고 단순한 가정을 내려, 훈련 데이터조차 충분히 설명하지 못하는 통계적 오차
- 모델 표현력(Expressive Power): 인공신경망이나 알고리즘이 복잡한 다차원 함수 관계를 근사(Approximate)할 수 있는 수학적 용량
- 특성 공학(Feature Engineering): 도메인 지식을 활용해 기존 원시 데이터로부터 유의미한 파생 변수나 다항식 특성을 새로 생성해 모델에 주입하는 과정

## 핵심 통찰
- 과적합은 모델이 학습을 너무 많이 해서 생기지만, 언더피팅은 모델의 태생적 구조가 데이터의 난이도를 감당하지 못해서 발생
- 많은 엔지니어가 과적합을 두려워해 L1/L2 규제($\lambda$)나 드롭아웃을 과도하게 걸다가 무의식중에 심각한 언더피팅에 빠지는 오류를 범함
- 딥러닝에서 언더피팅이 발생할 경우, 단순히 에포크를 늘리기보다 활성화 함수(Sigmoid -> ReLU)나 가중치 초기화(He Initialization)를 점검하는 것이 급선무

## 이웃 토픽과 구분
- 언더피팅 vs 오버피팅: 언더피팅은 훈련 손실 자체가 떨어지지 않는 문제(학습 불능) / 오버피팅은 훈련 손실은 0에 가까우나 검증 손실이 치솟는 문제(일반화 불능)

## 문제·원인·대책
- 적용 상황: 부동산 실거래가 예측 회귀 모델의 결정계수($R^2$)가 0.3에 머무는 현상 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 훈련 오차와 검증 오차가 둘 다 큼 | 비선형 주택 가격 분포에 단순 1차 선형 회귀 모델 적용 | 다항 특성(Polynomial Features) 추가 또는 앙상블(XGBoost) 전환 | 복잡한 비선형 관계 포착 및 예측력 개선 |
| 주요 설명 변수 누락으로 예측 정체 | 평수만 입력하고 학군, 역세권 등 핵심 도메인 변수 결측 | 외부 공간 지리 데이터 결합 및 특성 공학(Feature Crossing) 수행 | 모델의 설명력 및 $R^2$ 지표 대폭 상승 |
| 과도한 규제로 가중치 축소 | L2 규제 계수($\lambda$)를 너무 높게 설정해 가중치 억제 | 규제 계수 축소 및 드롭아웃 비율 하향(0.5 -> 0.2) | 모델 파라미터의 표현력 복원 및 학습 수렴 |
