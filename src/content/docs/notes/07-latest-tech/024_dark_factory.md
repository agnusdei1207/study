## 답안 골격
```text

 ┃
 ┣━ Ⅰ 개요 ───── 숙련공 인력난 및 휴먼 에러 한계 → 조명을 켤 필요 없는 100% 무인 자율 제조 공장 구현
 ┣━ Ⅱ 특징 ───── 24/7 연속 무인 가동 · 안전사고 원천 차단 · 사이버물리시스템(CPS) 폐루프 자율 제어
 ┣━ Ⅲ 구조 ───── 현장 디바이스(AGV/로봇) + 연결망(5G특화망/TSN) + 지능제어(디지털트윈/AI) + 보안(OT보안)
 ┣━ Ⅳ 흐름 ───── ① 자재 무인 입고(AMR) → ② 로봇 공정 조립 → ③ AI 비전 품질검사 → ④ 예지정비 및 자동 출하
 ┣━ Ⅴ 비교 ───── 자동화 공장(Smart Factory) vs 다크팩토리(Dark Factory, 무인 자율 공장)
 ┗━ Ⅵ 실무 ───── 무인 환경 단일 장애점(SPOF) 리스크 / OT 사이버 침해 시 물리적 파괴 / 막대한 초기 투자비
```

- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 4계층 아키텍처 다이어그램 → Ⅵ 핵심 리스크 대응 / 25점 = Ⅰ~Ⅶ 전개, Ⅲ 구성 기술과 스마트팩토리 고도화 단계(Level 5) 집중

## 한 줄 본질
- 작업자 상주를 전제로 하는 공장 환경의 에너지 낭비와 안전사고 위험 → 로봇, 자율 이동체(AMR), 디지털 트윈 AI를 결합해 인간 개입 없이 24시간 가동되는 완전 무인 제조 체계 달성 → 생산성 극대화 및 탄소 배출 절감 / 설비 고장 시 자율 복구 불가 및 OT 보안 침해 위험

## 핵심 용어
- Lights-out Manufacturing: 인간 작업자가 없어 조명이나 냉난방을 가동하지 않고 어두운 상태(Dark)에서 자율적으로 운영되는 제조 방식
- AMR(Autonomous Mobile Robot): 바닥에 자기 유도선을 깔아야 하는 기존 AGV와 달리 LiDAR와 SLAM 기술로 장애물을 피해 자율 주행하는 물류 로봇
- 예지정비(PdM, Predictive Maintenance): 진동, 온도 센서 시계열 데이터를 분석해 설비 고장 징후를 사전에 감지하고 부품 교체 시점을 자율 예약하는 시스템

## 핵심 통찰
- 다크팩토리는 단순히 "사람을 로봇으로 바꾼 공장"이 아니라, 데이터 흐름과 의사결정까지 인공지능이 수행하는 스마트제조 성숙도 최상위(Level 5) 단계
- 무인 공장에서는 단 1대의 설비 결함도 전체 라인의 셧다운(Downtime)으로 이어지므로, 사후 조치(BM)가 아닌 100% 예지정비(PdM) 체계가 전제되어야 성립
- 인간의 물리적 접근이 배제되므로 랜섬웨어 등 사이버 공격이 침투할 경우 물리적 화재나 폭발을 제어할 수 없는 치명적 OT 보안 리스크 내재

## 이웃 토픽과 구분
- 다크팩토리 vs 스마트팩토리: 스마트팩토리는 인간 작업자의 의사결정을 데이터로 지원하는 협업형 자동화 / 다크팩토리는 작업자가 현장에서 완전히 배제된 100% 무인 자율 공장

## 문제·원인·대책
- 적용 상황: 반도체 패키징 무인 공장에서 야간 가동 중 설비 이상 정지 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 로봇 베어링 파손으로 라인 정지 | 야간 상주 인력 부재로 설비 이상 소음 감지 실패 | 음향 센서 기반 초음파 이상 진단 및 진동 분석 AI 모델 적용 | 고장 발생 수일 전 징후 포착 및 유연 라우팅 우회 |
| 와이파이 음영 구역에서 AMR 정지 | 금속 설비 반사로 인한 무선 통신 패킷 드롭 | 5G 특화망(이음5G) 무선 백본 구축 및 핸드오버 최적화 | 지연시간 1ms 이하의 안정적 무선 제어 통신 보장 |
| PLC 제어 명령 변조 해킹 침투 | 외부 유지보수 원격 접속 경로를 통한 악성코드 유입 | IEC 62443 기반 OT 제로 트러스트 및 물리적 단방향 보안 게이트웨이 | 비인가 제어 패킷 주입 차단 및 무인망 무결성 확보 |

## 이렇게 출제된다
- 제140회 1교시 2번: "다크 팩토리(Dark Factory)" → 요구 포인트: Ⅰ 개념 및 특징 + Ⅲ 기반 기술(CPS/로봇/AI) + Ⅵ 도입 고려사항

## 내 의견
- [단일 라인 셧다운을 방어하는 자율 재구성 제조 시스템(RMS) 결합] 고정형 컨베이어 벨트 기반의 무인 공장은 한 지점이 멈추면 공장 전체가 마비됨 → 나라면: 고정 라인을 없애고 AMR과 모듈형 로봇 셀을 결합한 유연 제조 시스템(Cellular Manufacturing)을 도입하여, 특정 로봇 장애 시 물류 경로를 실시간 우회시키는 무중단 복원력(Resilience) 확보
