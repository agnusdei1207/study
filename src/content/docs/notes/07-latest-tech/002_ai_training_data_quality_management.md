## 한 줄 본질
- 저품질 라벨링과 편향된 데이터셋으로 인한 모델 오작동 방지 → 수집·정제·가공(라벨링) 전 단계에서 구문적·의미적 기준과 유효성을 체계적으로 검증 → 모델 일반화 성능 극대화 / 수작업 전수 검사 한계 및 고비용 발생

## 핵심 그림
```text
[데이터 생명주기별 3단계 품질 체계]
+-------------------------------------------------------------------+
| 1. 원시데이터 (Raw Data)      : 적합성, 원천성, 다양성             |
|    - 텍스트·음성·영상 수집     : 라이선스 적법성, 개인정보 비식별화|
+-------------------------------------------------------------------+
                                  | 정제 및 필터링
                                  v
+-------------------------------------------------------------------+
| 2. 원천데이터 (Source Data)   : 구문적 정확성, 유효성             |
|    - 정제 완료된 데이터        : 결측치·이상치 제거, 포맷 적합성   |
+-------------------------------------------------------------------+
                                  | 가공 및 어노테이션 (Labeling)
                                  v
+-------------------------------------------------------------------+
| 3. 라벨링데이터 (Labeled Data): 의미적 정확성, 일관성, 완전성     |
|    - 바운딩박스/클래스 태깅   : 교차검증(IAA), 클래스 분포 균형성 |
+-------------------------------------------------------------------+
```

## 핵심 용어
- 구문적 정확성(Syntactic Accuracy): 파일 포맷, 해상도, 인코딩, 스키마 구조가 규격 요구사항과 일치하는지 여부
- 의미적 정확성(Semantic Accuracy): 객체의 바운딩 박스 위치, 클래스 태그, 세그멘테이션 마스크가 실제 객체의 의미와 부합하는지 여부
- 작업자 간 일치도(IAA, Inter-Annotator Agreement): 동일 데이터에 대해 다수 라벨러가 부여한 태그의 통계적 일치 수준(Cohen's Kappa 등)

## 핵심 통찰
- 모델 구조 튜닝(Model-Centric)보다 데이터 클렌징(Data-Centric)이 성능 향상에 3배 이상 기여 → 노이즈 라벨 5% 제거가 파라미터 2배 증설보다 효과적
- 획득 데이터 수량보다 클래스 분포의 균형성과 도메인 엣지 케이스 포함 여부가 실무 품질의 성패를 가름
- 수작업 검사는 작업자 피로도로 오류율이 급증하므로, 규칙 기반 정적 검증과 사전 학습 모델을 활용한 자동 사전 라벨링(Pre-labeling) 병행 필수

## 이웃 토픽과 구분
- AI 데이터 품질관리 vs 전통 DQC-V: DQC-V는 관계형 스키마의 도메인 무결성·참조 무결성 중심 / AI 데이터 품질은 비정형 객체의 라벨 경계 적합성, 의미적 타당성, 모델 학습 기여도 중심

## 문제·원인·대책
- 적용 상황: 자율주행 객체 인식용 라벨링 데이터셋 구축 시 모델 오인식 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 야간 보행자 인식률 저하 | 주간 데이터 위주 수집으로 인한 조도 분포 불균형 | 합성 데이터(Synthetic Data) 생성 및 데이터 증강(Augmentation) | 조도별 데이터 균형 확보 및 오인식률 완화 |
| 라벨러 간 바운딩박스 경계 불일치 | 모호한 가이드라인과 작업자 주관 개입 | 명확한 라벨링 가이드 제정 및 교차 검수(IAA > 0.85) 통과 기준 강제 | 의미적 라벨링 일관성 확보 |
| 라벨 태그 오류로 인한 학습 발산 | 전수 검사 부재 및 검증 자동화 도구 미비 | 손실 함수(Loss) 기반 클린랩(Cleanlab) 등 오라벨 자동 탐지 도구 적용 | 오라벨 검출 및 재작업 비용 절감 |
