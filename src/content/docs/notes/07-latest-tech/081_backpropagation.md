## 답안 골격
```text
[역전파] ◀━━ 머리: Ⅶ 내 의견 (연쇄 법칙 기반의 효율적 편미분 역방향 전파와 적응형 모멘텀 옵티마이저의 결합)
 ┃
 ┣━ Ⅰ 개요 ───── 다층 신경망(MLP) 은닉층 가중치의 오차 기여도 산출 불가(XOR 문제 한계) → 연쇄 법칙으로 출력 오차를 역방향 전파
 ┣━ Ⅱ 특징 ───── 연쇄 법칙(Chain Rule) 활용 · 동적 계획법(DP) 기반 중간값 재사용 · 계산 복잡도 $O(W)$ · 경사하강법(GD) 연계
 ┣━ Ⅲ 구조 ───── 순전파 계산 그래프(Forward Graph) + 손실 함수(Loss Function) + 역전파 편미분 모듈 + 가중치 갱신 옵티마이저
 ┣━ Ⅳ 흐름 ───── ① 순전파 출력 및 손실 $E$ 산출 → ② 출력층 오차 $\delta_k$ 계산 → ③ 은닉층 오차 $\delta_j$ 역방향 전파 → ④ 편미분 $\frac{\partial E}{\partial w}$ 기반 가중치 갱신
 ┣━ Ⅴ 비교 ───── 수치 미분(Numerical) vs 기호 미분(Symbolic) vs 역전파(자동 미분/Reverse Auto-Diff) (느림/$O(W^2)$ vs 수식 폭증 vs 최고 효율/$O(W)$)
 ┗━ Ⅵ 실무 ───── 활성화 도함수 소멸에 따른 기울기 소실(Vanishing Gradient) / 가중치 국소 최적해(Local Minima) / 안장점(Saddle Point) 정체
```

## 한 줄 본질
- 단층 퍼셉트론의 XOR 분류 불가능 한계를 넘기 위해 은닉층을 두었으나 각 은닉 뉴런이 출력 오차에 얼마나 기여했는지 알 수 없었던 신용 할당 문제(Credit Assignment Problem) → 미적분의 연쇄 법칙(Chain Rule)을 적용하여 출력 오차를 뒤에서부터 앞으로 거꾸로 미분 전파하여 각 가중치의 기울기를 $O(W)$ 시간 만에 계산 → 딥러닝 다층 신경망 학습을 가능하게 만든 핵심 알고리즘 / 활성화 함수에 따라 기울기 소실 현상 발생

## 핵심 그림
```text
[역전파 알고리즘 계산 그래프 및 연쇄 법칙(Chain Rule) 흐름]

                  [순전파 (Forward Pass): 입력 -> 출력 -> 손실]
                    x -------> [ ( * W ) ] -------> z = Wx
                                   |
                                   v
             y = f(z) <------- [ f(z) ] (활성화 함수: Sigmoid/ReLU)
                |
                v
          Loss = E(y, t) = 1/2 * (y - t)^2
                |
                v
     [역전파 (Backward Pass): 연쇄 법칙에 의한 오차 기울기 역전파]
        ∂E/∂y = (y - t)
                |
                v
        ∂E/∂z = (∂E/∂y) * (∂y/∂z) = (y - t) * f'(z)   <--- [오차 신호: δ]
                |
                v
        ∂E/∂W = (∂E/∂z) * (∂z/∂W) = δ * x             <--- [최종 가중치 편미분]
                |
                v
     [가중치 갱신: Gradient Descent]
        W_new = W_old - η * (∂E/∂W)
```

## 핵심 용어
- 연쇄 법칙(Chain Rule): 합성함수의 도함수를 각 합성 단계별 도함수들의 곱으로 나타내는 미분 공식으로, $\frac{\partial E}{\partial w} = \frac{\partial E}{\partial y} \cdot \frac{\partial y}{\partial z} \cdot \frac{\partial z}{\partial w}$ 와 같이 역방향 편미분을 단계별로 분해 계산
- 오차 신호(Error Term, $\delta$): 역전파 과정에서 특정 뉴런의 순입력 $z$에 대한 최종 손실의 편미분값($\delta = \frac{\partial E}{\partial z}$)으로, 앞 레이어에서 전파된 $\delta$에 현재 뉴런의 도함수를 곱해 재귀적으로 이전 레이어로 전달
- 역방향 자동 미분(Reverse-mode Auto-Diff): 컴퓨터 과학에서 역전파를 일반화한 개념으로, 중간 연산 노드의 값들을 순전파 때 테이프(Tape)에 저장해두고 역방향으로 단 한 번 통과(Single Pass)하여 수백만 개 파라미터의 미분값을 동시 산출하는 기법

## 핵심 통찰
- 수치 미분(수식에 아주 작은 $h$를 넣어 일일이 계산)으로 파라미터 $W$개를 미분하면 $O(W^2)$의 연산이 걸려 100만 개 파라미터 모델 훈련에 수 세기가 걸림 → 역전파는 순전파 1회, 역전파 1회(단 $O(W)$ 연산)로 전체 파라미터의 정확한 그래디언트를 동시에 획득하는 혁신적 시간 복잡도 달성
- 역전파의 치명적 약점은 활성화 함수 $f'(z)$의 크기: 시그모이드의 도함수 최댓값은 0.25이므로, 레이어를 4개만 거쳐도 오차 신호가 $0.25^4 \approx 0.0039$로 소멸 → $f'(z) = 1$을 유지하는 ReLU의 등장이 심층 신경망 역전파를 구원
- 현대 역전파 프레임워크(PyTorch 등)는 정적 수식이 아니라 동적 계산 그래프(Dynamic Computational Graph)를 메모리에 실시간 구축(Autograd)하여 임의의 조건문과 반복문이 포함된 모델도 자동 미분 수행

## 이웃 토픽과 구분
- 역전파(Backpropagation) vs 경사하강법(Gradient Descent): 역전파는 각 가중치별 "기울기(Gradient)"를 효율적으로 계산하는 알고리즘 / 경사하강법은 역전파가 구해준 기울기를 이용해 가중치를 어느 방향으로 얼만큼 이동시킬지 결정하는 최적화 알고리즘

- 적용 상황: 자연어 처리 순환신경망(RNN)에서 50단어 이상 문장 학습 시 역전파 실패
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 시퀀스가 길어질수록 시간 축 역전파(BPTT) 도중 그래디언트가 0으로 소멸 | 순환 가중치 행렬이 1보다 작아 시간 스텝을 거슬러 올라가며 지속 곱셈 감쇠 | LSTM/GRU의 셀 상태 게이트 도입 또는 Truncated BPTT(시간 윈도우 한정) 적용 | 장거리 의존성 문맥 학습 보존 |
| 특정 배치에서 가중치 그래디언트가 무한대로 폭발하여 NaN 에러 발생 | 가중치 초기화 불량 및 가파른 손실 절벽 구간 진입으로 인한 기울기 폭주 | 그래디언트 클리핑(Gradient Clipping: $\|\mathbf{g}\| > threshold$ 시 스케일 축소) | 훈련 발산 방지 및 수치적 안정성 확보 |

## 내 의견
- [혼합 정밀도(FP16/BF16) 역전파 시 언더플로우 방지를 위한 동적 손실 스케일링(Loss Scaling) 필수 적용] 거대 모델 훈련 시 메모리 절감을 위해 FP16을 쓰면, 역전파 도중 발생하는 매우 작은 기울기 값들이 0으로 언더플로우(Underflow)되어 학습이 정체됨 → 나라면: 순전파 손실값에 거대 상수(예: $2^{15}$)를 곱해 역전파를 수행한 뒤 가중치 갱신 직전에 다시 원래 스케일로 나누는 Dynamic Loss Scaler를 MLOps 훈련 파이프라인에 기본 탑재하여, 메모리는 절반으로 줄이고 수치적 정밀도는 32비트와 동일하게 유지
