```text
 ┃
 ┣━ Ⅰ 개요 ───── 전통 오토인코더의 잠재 공간 불연속성 한계 → 입력을 확률 분포로 매핑하여 새로운 데이터를 생성하는 생성 모델
 ┣━ Ⅱ 특징 ───── 확률론적 잠재 공간(Probabilistic Latent Space) · 연속적 보간(Interpolation) · 재파라미터화 트릭 · ELBO 최적화
 ┣━ Ⅲ 구조 ───── 인코더(평균 $\mu$, 분산 $\sigma^2$ 출력) + 잠재 공간(z) + 디코더(복원 $\hat{x}$) + 손실 함수(재구성 + KL 발산)
 ┣━ Ⅳ 흐름 ───── ① 입력 x 인코딩 → ② 평균과 분산 산출 → ③ 재파라미터화 샘플링($z = \mu + \sigma \odot \epsilon$) → ④ 디코더 복원
 ┣━ Ⅴ 비교 ───── 오토인코더(AE) vs 변분 오토인코더(VAE) vs 적대적 생성 신경망(GAN)
 ┗━ Ⅵ 실무 ───── 생성된 이미지의 흐릿함(Blurriness) / 사후 붕괴(Posterior Collapse) 현상
```

## 한 줄 본질
- 데이터를 특정 고정 좌표로만 압축하여 임의의 위치에서 샘플링하면 기괴한 이미지가 나오던 전통 오토인코더의 한계 → 데이터를 정규분포를 따르는 연속적 확률 분포의 평균($\mu$)과 분산($\sigma$)으로 매핑하고 재파라미터화 트릭으로 역전파 학습 → 매끄러운 잠재 공간과 데이터 생성 역량 확보 / GAN 대비 생성 디테일이 다소 흐릿함(Blurry)

## 핵심 그림
```text
[VAE 구조 및 재파라미터화 트릭(Reparameterization Trick)]
[입력 데이터 x]
       |
       v
[인코더 (q_phi(z|x))]
       |
       +---------> 평균 벡터 (\mu) -----------------+
       |                                            |
       +---------> 표준편차 벡터 (\sigma)           |
                        |                           v
                        +---> (*) <--- 노이즈 \epsilon ~ N(0, I) (샘플링)
                               |                    |
                               v                    v
                        [\sigma \odot \epsilon] ---> (+) ===> [잠재 벡터 z = \mu + \sigma \odot \epsilon]
                                                                          | (미분 경로 확보!)
                                                                          v
                                                                   [디코더 (p_theta(x|z))]
                                                                          |
                                                                          v
                                                                   [복원 데이터 \hat{x}]
```

## 핵심 용어
- 재파라미터화 트릭(Reparameterization Trick): 확률 분포에서 무작위 샘플링하는 연산은 미분이 불가능하므로, 확률 노이즈 $\epsilon \sim \mathcal{N}(0, I)$를 외부에서 추출하여 $z = \mu + \sigma \odot \epsilon$ 형태로 분리함으로써 역전파 기울기(Gradient)가 $\mu$와 $\sigma$로 전달되게 만든 수학적 기법
- ELBO(Evidence Lower Bound): 직접 계산이 불가능한 데이터 우도(Likelihood)의 하한선으로, `ELBO = 재구성 오차(Reconstruction Loss) - KL 발산(KL Divergence)`으로 구성된 VAE의 최종 목적함수
- 사후 붕괴(Posterior Collapse): 디코더가 너무 강력하여 잠재 공간 $z$의 정보를 무시하고 입력 $x$와 무관하게 평균적인 출력만 생성하며 잠재 변수가 표준정규분포로 붕괴해 버리는 현상

## 핵심 통찰
- VAE는 단순한 차원 축소 도구가 아니라, 복잡한 고차원 데이터 공간을 수학적으로 다루기 쉬운 연속적인 저차원 구형 잠재 공간으로 정렬하는 "확률적 생성기"
- 잠재 공간이 연속적이기 때문에 두 잠재 벡터 사이를 보간(Interpolation)하면 "안경을 쓰지 않은 얼굴"에서 "안경을 쓴 얼굴"로 점진적으로 자연스럽게 변하는 시각적 모핑이 가능
- 최신 확산 모델(Stable Diffusion)의 잠재 디퓨전(Latent Diffusion) 아키텍처에서 고해상도 이미지를 저차원 잠재 공간으로 압축하는 핵심 인코더/디코더 모듈로 필수 활용

## 이웃 토픽과 구분
- VAE vs GAN: GAN은 판별자와 생성자의 적대적 경쟁을 통해 초고화질 이미지를 생성하나 학습이 극도로 불안정 / VAE는 명시적인 확률 통계 이론(ELBO)을 바탕으로 안정적으로 학습되며 잠재 공간 해석이 용이

## 문제·원인·대책
- 적용 상황: 제조 라인 웨이퍼 표면 결함 합성 및 이상치 탐지를 위해 VAE 도입 후 결함 발생
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 복원된 웨이퍼 이미지의 미세한 스크래치 결함이 뭉개짐(Blurry) | 픽셀 단위 MSE 손실 함수가 평균적인 흐릿한 출력을 선호 | 지각 손실(Perceptual Loss) 결합 또는 VQ-VAE 이산 잠재 구조 적용 | 선명한 엣지 복원 및 고주파 디테일 보존 |
| 잠재 변수 z가 아무런 정보를 담지 못하고 무시됨(사후 붕괴) | 학습 초기 KL 발산 페널티가 너무 강해 잠재 변수가 표준정규분포로 조기 수렴 | KL Annealing(학습 진행에 따라 KL 가중치를 0에서 점진적 상향) 적용 | 사후 붕괴 방지 및 의미 있는 잠재 특징 학습 |
| 정상 데이터와 결함 데이터의 잠재 공간 분리 미흡 | 비지도 학습 방식의 클래스 레이블 미활용 | 조건부 VAE(C-VAE) 도입으로 결함 클래스 조건 벡터(y) 추가 주입 | 결함 유형별 정밀 합성 및 분류 정확도 제고 |
