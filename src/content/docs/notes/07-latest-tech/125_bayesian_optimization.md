```text
[베이지안 최적화] ◀━━ 머리: Ⅶ 내 의견 (가우시안 프로세스 대리 모델과 획득 함수의 탐색-활용 균형으로 평가 비용이 비싼 블랙박스 함수의 전역 최적해를 도출하는 튜닝 공학)
 ┃
 ┣━ Ⅰ 개요 ───── 목적 함수의 수식이 없고 1회 평가 비용이 매우 비싼 블랙박스 함수 최적화의 한계 → 확률적 대리 모델 기반 베이지안 최적화 태동
 ┣━ Ⅱ 특징 ───── 대리 모델(Surrogate Model) 추정 · 탐색(Exploration)과 활용(Exploitation) 균형 · 불확실성(분산) 정량화 · 최소 평가 횟수 전역 탐색
 ┣━ Ⅲ 구조 ───── 대리 모델(가우시안 프로세스, GP / TPE) + 획득 함수(Acquisition Function: EI, UCB, PI) + 목적 함수(블랙박스)
 ┣━ Ⅳ 흐름 ───── ① 초기 표본 추출 및 목적 함수 평가 → ② 가우시안 프로세스로 사후 확률 분포($\mu, \sigma^2$) 갱신 → ③ 획득 함수($\alpha(x)$) 최대화 지점($x_{next}$) 선정 → ④ 실제 함수 평가 및 데이터 추가 → ⑤ 최적해 수렴 반복
 ┣━ Ⅴ 비교 ───── 그리드 탐색(Grid) vs 랜덤 탐색(Random) vs 베이지안 최적화 (격자 전수조사/차원의 저주 vs 무작위 독립추출 vs 과거 평가 결과 반영 확률적 지능 탐색)
 ┗━ Ⅵ 실무 ───── 차원이 20차원 이상일 때 GP 연산량($O(N^3)$) 급증 / 획득 함수 하이퍼파라미터($\kappa$) 편향 / 비정상성(Non-stationary) 지형 적합 실패
```

## 핵심 그림
```text
[베이지안 최적화의 가우시안 프로세스(GP)와 획득 함수(Acquisition Function) 동작]

  f(x)
   │                           진짜 목적 함수 (블랙박스)
   │                 *          ..- - - - -
   │   평균 예측 μ(x) \      .-'           '-.
   │  ─────────────── * ───'                 '─── * (관측점)
   │   불확실성 구간   \   :                       :
   │   (± 2σ(x))       \ :                       :
   │                     *                        :
   └─────────────────────┼────────────────────────┼───────────> x
                         │ (이미 아는 곳: 활용)    │ (불확실성 큼: 탐색)
  α(x)                   │                        │
   │                     │                        │
   │ 획득 함수           │         ┌────┐         │
   │ (EI / UCB)          │         │    │ <───────┴── 다음 탐색점 x_next
   │  ───────────────────┴─────────┘    └─────────────────────> x
```

## 핵심 용어
- 가우시안 프로세스(GP, Gaussian Process): 임의의 입력 $x$에 대해 목적 함수의 예측값 평균 $\mu(x)$뿐만 아니라 그 예측의 불확실성 정도인 분산 $\sigma^2(x)$까지 확률적으로 도출하는 비모수 대리 모델
- 획득 함수(Acquisition Function): 현재까지의 대리 모델 정보를 바탕으로 "다음에 어느 지점을 평가하는 것이 가장 이득인가"를 수치화하는 함수(EI, UCB 등)
- 활용(Exploitation)과 탐색(Exploration): 예측 평균 $\mu(x)$이 가장 높은 유망한 곳을 파고드는 '활용'과, 아직 가보지 않아 분산 $\sigma(x)$이 큰 불확실한 곳을 들여다보는 '탐색' 간의 상충 관계

## 핵심 통찰
- "무작정 돌리는 무작위 탐색과의 결정적 차이": 랜덤 탐색은 이전 시도가 실패했든 성공했든 상관없이 매번 동전을 던지지만, 베이지안 최적화는 "여기는 점수가 낮았으니 패스하고, 저기는 아직 안 가봤지만 대박일 가능성이 있으니 가보자"는 사전-사후 확률 업데이트를 수행함
- EI(Expected Improvement) 수식의 미학: 현재까지 찾은 최고 점수 $f(x^+)$보다 얼마나 더 개선될 수 있는지를 확률 적분하여 계산함으로써, 기댓값이 크면서도 분산이 적당히 큰 최적의 균형점을 자동으로 집어냄
- 고차원(High-Dimension)에서의 대안: 변수가 20개를 넘어가면 GP의 커널 행렬 역행렬 연산($O(N^3)$)이 마비되므로, 트리 구조 기반 확률 밀도를 추정하는 TPE(Tree-structured Parzen Estimator, Optuna 엔진)로 전환해야 함

## 이웃 토픽과 구분
- 경사하강법 vs 베이지안 최적화: 경사하강법은 목적 함수의 미분식($\nabla f$)을 알 때 기울기를 따라감 / 베이지안 최적화는 미분식을 알 수 없고 평가 비용이 극도로 비싼 블랙박스 함수를 최적화

| 최적화 알고리즘이 이미 알고 있는 국소 최적점 주변만 계속 재탐색하는 편향 발생 | 획득 함수(UCB)에서 탐색 파라미터 $\kappa$ 값을 너무 낮게 설정 | $\kappa$ 값을 2.576(99% 신뢰구간)으로 상향하여 미개척 고분산 영역 탐색 장려 | 전역 최적해(Global Optimum) 탈출 성공 |
| 튜닝할 하이퍼파라미터 수가 30개로 늘어나자 대리 모델 갱신 연산 시간만 수 시간 소요 | 가우시안 프로세스의 $O(N^3)$ 역행렬 연산 차원의 저주 | 트리 구조 파젠 추정기(TPE) 기반 프레임워크(Optuna)로 대리 모델 교체 | 고차원 튜닝 연산 지연 90% 단축 |
