## 답안 골격
```text
[최소 신장 트리] ◀━━ 머리: 간선 중심 정렬(크루스칼)과 정점 중심 확장(프림)을 통한 최소 비용 망 구축
 ┃
 ┣━ Ⅰ 개요 ───── 네트워크 연결 비용 최소화 한계 → 모든 정점을 사이클 없이 $V-1$개 간선으로 연결하는 트리
 ┣━ Ⅱ 성립 ───── 신장 트리 성질(정점 $V$, 간선 $V-1$, 무사이클) · 컷 속성(Cut Property) 기반 최적해 보장
 ┣━ Ⅲ 크루스칼 ─ 간선 중심 탐욕법: 가중치 오름차순 정렬 $\to$ Union-Find 자료구조로 사이클 검출 ($O(E \log E)$)
 ┣━ Ⅳ 프림 ───── 정점 중심 탐욕법: 시작 정점 $\to$ 인접 최소 간선 우선순위 큐 연결 확장 ($O((V+E)\log V)$)
 ┣━ Ⅴ 비교 ───── 크루스칼(희소 그래프 적합) vs 프림(밀집 그래프 적합)
 ┗━ Ⅵ 실무 ───── 통신망 광케이블 배선 비용 최소화 · 도로/수도관 인프라 네트워크 토폴로지 설계
```
- 필수 키워드: 신장 트리(Spanning Tree) · 최소 신장 트리(MST) · 크루스칼(Kruskal) · 프림(Prim) · 유니온-파인드(Union-Find) · 컷 속성

## 한 줄 본질
- 모든 노드를 연결하면서 사이클 없이 전체 간선 가중치 합을 최소화하기 위해 간선을 가중치 순으로 잇거나(크루스칼) 정점을 기준으로 트리를 넓혀감(프림) → 인프라 구축 비용 최적화 / 간선 음수 사이클 고려 불가

## 핵심 그림
```text
[크루스칼: 간선 중심 (Edge-centric)]           [프림: 정점 중심 (Vertex-centric)]
 1. 모든 간선 정렬: (A-B:1), (C-D:2), ...     1. 시작 정점 A 선택
 2. 최소 간선부터 선택                          2. A와 연결된 최소 간선 (A-B:1) 선택 -> 트리={A, B}
 3. 사이클 형성 시 배제 (Union-Find)           3. {A, B}에서 외부로 나가는 최소 간선 선택
 [A] --1-- [B]     [C] --2-- [D]              [A] --1-- [B]
    \     /                                      \
     3   4 (3 연결, 4는 사이클이므로 기각)          3 -> [C] (정점 집합 점진 확장)
```

## 핵심 통찰
- 크루스칼 알고리즘은 상호배타 집합(Disjoint Set)의 Union-Find 연산(경로 압축 Path Compression)을 통해 두 정점의 루트가 같은지 판별함으로써 $O(\alpha(V))$에 사이클 형성을 차단함
- 간선 수가 정점 수에 비해 적은 희소 그래프(Sparse Graph, $E \approx V$)에서는 간선 정렬이 빠른 크루스칼이 유리하고, 간선이 매우 많은 밀집 그래프(Dense Graph, $E \approx V^2$)에서는 정점 기반의 프림이 유리함

## 이웃 토픽과 구분
- 크루스칼 vs 프림:
| 비교 항목 | 크루스칼 알고리즘 (Kruskal) | 프림 알고리즘 (Prim) |
|---|---|---|
| 탐색 관점 | 간선(Edge) 중심 | 정점(Vertex) 중심 |
| 알고리즘 흐름 | 가중치 오름차순 정렬 후 사이클 검사 | 임의의 시작점에서 인접 정점으로 확장 |
| 핵심 자료구조 | Union-Find (서로소 집합) | 우선순위 큐 (최소 힙) |
| 시간 복잡도 | $O(E \log E)$ | $O((V + E) \log V)$ |
| 최적 그래프 형태 | 희소 그래프 (간선이 적을 때) | 밀집 그래프 (간선이 많을 때) |
