## 답안 골격
```text
[전이 학습] ◀━━ 머리: Ⅶ 내 의견 (부정적 전이 방지를 위한 계층별 차등 동결 및 LoRA 어댑터 적용)
 ┃
 ┣━ Ⅰ 개요 ───── 데이터 부족 및 학습 비용 한계 → 사전 학습(Pre-training) 모델의 특징 지식을 새 타깃 작업에 전이
 ┣━ Ⅱ 유형 ───── 특성 추출(Feature Extraction, 백본 동결) vs 미세 조정(Fine-Tuning, 가중치 차등 갱신)
 ┣━ Ⅲ 구조 ───── 사전 학습 백본(공통 특징 추출) + 교체된 태스크 헤드(Task-specific Classifier)
 ┣━ Ⅳ 전략 ───── 타깃 데이터 크기(대/소) $\times$ 도메인 유사도(고/저)에 따른 4사분면 학습 전략
 ┣━ Ⅴ 비교 ───── 스크래치 학습(From Scratch) vs 사전학습 미세조정 vs 매개변수 효율적 튜닝(PEFT)
 ┗━ Ⅵ 실무 ───── 부정적 전이(Negative Transfer) · 파멸적 망각(Catastrophic Forgetting) · LoRA 경량화
```
- 필수 키워드: 사전 학습(Pre-trained) · 미세 조정(Fine-Tuning) · 동결(Freeze) · 부정적 전이 · 파멸적 망각 · PEFT(LoRA)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 백본-헤드 구조도 → Ⅳ 데이터/유사도 4분면 전략표 → Ⅵ 부정적 전이 방지책

## 한 줄 본질
- 처음부터 모델을 학습시키는 데 드는 막대한 데이터와 컴퓨팅 자원 한계 해소 → 대규모 데이터로 사전 학습된 지식을 가져와 소량의 타깃 데이터에 미세 조정 → 학습 시간 단축 및 고성능 달성 / 도메인 불일치 시 부정적 전이

## 핵심 그림
```text
[사전 학습 모델 (ImageNet / LLM)]       [전이 학습 파이프라인 (타깃 도메인)]
 +-----------------------------+         +-----------------------------+
 | 하위 계층 (점, 선, 기본 질감)  | ======> | 하위 계층 [가중치 동결: Freeze]  | (공통 특징)
 +-----------------------------+         +-----------------------------+
 | 중간 계층 (도형, 국소 패턴)     | ======> | 중간 계층 [미세 조정: Unfreeze] | (낮은 학습률)
 +-----------------------------+         +-----------------------------+
 | 상위 계층 (객체 추상적 형상)    |         | 태스크 헤드 [신규 교체 및 학습]  | (새로운 분류)
 +-----------------------------+         +-----------------------------+
```

## 핵심 통찰
- 신경망의 하위 계층은 에지(Edge), 텍스처(Texture) 등 어떤 도메인에나 통용되는 범용적 특징(General Features)을 학습하므로, 이를 동결(Freeze)하여 재사용하면 적은 데이터로도 과적합을 방지할 수 있음
- 타깃 데이터의 양이 적고 소스 도메인과 유사할 때는 백본을 완전히 얼리고 분류 헤드만 학습시키는 '특성 추출'이 안전하며, 데이터가 많을 때는 전체 망을 다시 푸는 'Full Fine-Tuning'이 유리함
- 원본 도메인과 타깃 도메인의 물리적 상관관계가 없거나 왜곡되어 있을 경우, 사전 학습 가중치가 오히려 학습을 방해하여 밑바닥부터 학습한 것보다 성능이 떨어지는 '부정적 전이(Negative Transfer)'가 발생함

## 이웃 토픽과 구분
- 학습 전략별 비교 (스크래치 vs 풀 튜닝 vs PEFT):
| 비교 항목 | 스크래치 학습 (From Scratch) | 전면 미세 조정 (Full Fine-tuning) | 매개변수 효율적 튜닝 (PEFT: LoRA) |
|---|---|---|---|
| 초기 가중치 | 완전 무작위(Random) 초기화 | 사전 학습 가중치 로드 | 사전 학습 가중치 영구 동결 |
| 학습 대상 | 모델 전체 파라미터 ($100\%$) | 모델 전체 파라미터 ($100\%$) | 저순위 행렬 어댑터 ($1\%$ 미만) |
| 필요 데이터 | 초대규모 데이터셋 필수 | 중간/소규모 데이터셋 | 극소량 태스크 데이터셋 |
| 연산 자원 | 극도로 큼 (수백 개 GPU) | 큼 (전체 가중치 역전파) | 극히 적음 (단일 GPU 가능) |

## 문제·원인·대책
- 적용 상황: 도메인 데이터가 극히 부족한 특수 의료 바이오 판독 AI 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 소스 도메인과 타깃 도메인 간 이질성으로 성능 하락 | 일반 이미지와 특수 의료 영상 간 텍스처 불일치로 부정적 전이 발생 | 도메인 적응(Domain Adaptation) 사전 훈련 및 중간 특징 정렬 손실 적용 | 부정적 전이 차단 및 도메인 정렬 |
| 타깃 태스크 학습 중 사전 학습된 범용 지식 망각 | 높은 학습률로 전면 미세 조정을 수행하여 기존 가중치가 덮어씌워짐 | 상위 계층부터 단계적으로 푸는 점진적 동결 해제(Gradual Unfreezing) 도입 | 파멸적 망각(Catastrophic Forgetting) 방지 |

## 내 의견
- [부정적 전이 방지를 위한 계층별 차등 동결 및 LoRA 어댑터 적용] 거대 기반 모델(Foundation Model)을 전면 미세 조정하면 GPU 메모리 부족과 파멸적 망각이 불가피하며, 서빙 단계에서 태스크마다 수십 기가의 모델을 복제해야 하는 비효율이 발생함 → 나라면: 기본 백본은 FP16/INT8로 영구 동결하고 저순위 분해(Low-Rank Adaptation, LoRA) 행렬 어댑터만을 학습시키는 파라미터 효율적 전이 학습(PEFT)을 표준화하여, 단일 기반 모델 위에서 메모리 오버헤드 없이 수십 개의 도메인 특화 어댑터를 핫스왑(Hot-swap) 서빙 체계로 구축
