## 답안 골격
```text
[차원의 저주] ◀━━ 머리: Ⅶ 내 의견 (정보 손실 최소화를 위한 PCA-UMAP 계층적 차원 축소 및 코사인 유사도 전환)
 ┃
 ┣━ Ⅰ 개요 ───── 특징 변수 무분별 증가 한계 → 고차원 공간의 지수적 부피 팽창에 따른 데이터 희소화 및 거리 척도 붕괴
 ┣━ Ⅱ 기하학 ─── 공간 부피 팽창($V=L^d$) · 데이터 밀도 소멸 · 거리 집중 현상($\lim_{d\to\infty} \frac{d_{\max}-d_{\min}}{d_{\min}} = 0$)
 ┣━ Ⅲ 구조 ───── 1차원(선) $\to$ 2차원(면) $\to$ 3차원(입방체) $\to$ 고차원 초공간 데이터 희소화(Sparsity)
 ┣━ Ⅳ 영향 ───── KNN/클러스터링 성능 파멸 · 모델 파라미터 과적합 · 요구 학습 데이터량 지수적 폭증
 ┣━ Ⅴ 비교 ───── 특성 선택(Feature Selection) vs 특성 추출(Feature Extraction, PCA/t-SNE/UMAP)
 ┗━ Ⅵ 실무 ───── 고차원 임베딩 차원 축소 · L1 라쏘(Lasso) 정규화 · 맨해튼/코사인 척도 교체
```
- 필수 키워드: 데이터 희소성(Sparsity) · 거리 집중 현상 · 지수적 부피 팽창 · 특성 선택 · 차원 축소(PCA/t-SNE) · 매니폴드 가설
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 기하학적 메커니즘 도해 및 수식 → Ⅳ 거리 집중 현상 → Ⅴ 종합 해결책

## 한 줄 본질
- 설명력을 높이기 위해 변수(차원)를 무작정 늘리면 공간이 기하급수적으로 넓어져 데이터가 극도로 희소해지고 모든 데이터 간의 거리가 같아지는 현상 → 모델 과적합 및 거리 기반 알고리즘 붕괴 / 차원 축소 기법으로 극복

## 핵심 그림
```text
[차원 증가에 따른 데이터 밀도 희소화]
 1차원 (D=1)        2차원 (D=2)            3차원 (D=3)          고차원 초공간 (D=100+)
  +---+---+          +---+---+              +-------+            +---------------+
  | * | * |          | * |   |             / *     /|            |               |
  +---+---+          +---+---+            +-------+ |            |  데이터가      |
  (2개 구간)         |   | * |            |   *   |/             |  극도로 희소함  |
                     +---+---+            +-------+              +---------------+
                     (4개 구간)           (8개 입방체)           (공간 텅 빔: 빈 공간 99%)
 
[거리 집중 현상 (Distance Concentration)]
 차원 d -> 무한대 시: (최대 거리 d_max - 최소 거리 d_min) / d_min ---> 0
 (모든 점들이 원점 및 서로로부터 거의 동일한 거리로 멀어짐)
```

## 핵심 통찰
- 차원이 $d$로 증가할 때 동일한 데이터 밀도를 유지하기 위해 필요한 샘플 수는 $k^d$로 기하급수적으로 증가하므로, 현실의 어떤 유한한 데이터셋도 고차원에서는 텅 빈 희소(Sparse) 공간이 됨
- 유클리드 거리 공식($\sqrt{\sum (x_i - y_i)^2}$)에서 차원이 무수히 커지면 모든 점 사이의 거리 편차가 사라지는 '거리 집중 현상'이 발생하여, 가장 가까운 이웃과 가장 먼 이웃을 구분할 수 없게 되어 KNN과 K-Means가 완전히 무력화됨
- 고차원 데이터라 하더라도 실제 의미 있는 정보는 훨씬 낮은 저차원 곡면(Subspace)에 집중되어 있다는 '매니폴드 가설(Manifold Hypothesis)'에 착안하여 주성분 분석(PCA)이나 오토인코더로 차원을 축소해야 함

## 이웃 토픽과 구분
- 특성 선택 vs 특성 추출:
| 비교 항목 | 특성 선택 (Feature Selection) | 특성 추출 (Feature Extraction) |
|---|---|---|
| 변환 방식 | 원본 변수 중 유의미한 변수만 선별 보존 | 기존 변수들을 수학적으로 조합해 새 잠재 변수 생성 |
| 원본 해석력 | 원본 피처의 의미가 완벽히 보존됨 | 주성분 합성으로 인해 원본 변수의 의미 해석 상실 |
| 정보 손실 | 선택되지 않은 변수의 정보는 완전 소실 | 공분산을 고려해 전체 분산 정보를 최대한 압축 보존 |
| 대표 기법 | 분산 필터, 카이제곱 검정, RFE, L1 Lasso | PCA, LDA, t-SNE, UMAP, Autoencoder |

## 문제·원인·대책
- 적용 상황: 수만 개의 유전자 바이오 마커 데이터 기반 질병 예측
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 고차원 유클리드 거리 계산 시 이웃 식별 불가 | 차원 증가에 따른 거리 집중 현상으로 점 간 거리 차이 소멸 | 거리 척도를 각도 기반 코사인 유사도 또는 L1 맨해튼 거리로 대체 | 고차원 공간 변별력 회복 |
| 특징 수 대비 표본 부족으로 극심한 과적합 | $P \gg N$ 환경에서 모델 자유도가 너무 높아 노이즈 암기 | 불필요한 계수를 0으로 소거하는 L1 라쏘 규제 및 ElasticNet 적용 | 희소 모델 구축 및 일반화 향상 |
