## 답안 골격
```text
[탐욕 알고리즘] ◀━━ 머리: Ⅶ 내 의견 (근사해 오차 한계 보증 및 A* 휴리스틱 결합을 통한 실시간 최적화)
 ┃
 ┣━ Ⅰ 개요 ───── 전체 탐색 비용 한계 → 매 단계 눈앞의 국소적 최적 선택(Local Optimum)을 내리는 휴리스틱 패러다임
 ┣━ Ⅱ 조건 ───── 탐욕적 선택 속성(Greedy Choice Property) · 최적 부분 구조(Optimal Substructure)
 ┣━ Ⅲ 구조 ───── 선택 절차(Selection) → 적절성 검증(Feasibility) → 해답 검증(Solution Check)
 ┣━ Ⅳ 흐름 ───── 국소 기준 정렬 → 최선 원소 선택 → 제약조건 확인 → 부분해 누적 루프
 ┣━ Ⅴ 비교 ───── 탐욕법(Greedy) vs 동적 계획법(DP) vs 백트래킹(Backtracking)
 ┗━ Ⅵ 실무 ───── 허프만 압축 코딩 · 크루스칼 MST · 다익스트라 라우팅 · 0-1 배낭 실패 한계
```
- 필수 키워드: 탐욕적 선택 속성 · 최적 부분 구조 · 국소 최적해 · 전역 최적해 · 매트로이드(Matroid)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 2대 성립 조건 → Ⅲ 3단계 수행 절차 → Ⅴ 타 패러다임 비교

## 한 줄 본질
- 미래의 영향을 고려하지 않고 현재 시점의 최선만을 선택하여 즉시 결정 → 선택 번복(Backtracking)이 없어 실행 속도가 극히 빠름 → 전역 최적해(Global Optimum) 보장 불가 및 특정 수학적 구조(매트로이드) 의존

## 핵심 그림
```text
            [ 시작 상태 S ]
            /      |      \
         (A:3)   (B:1)   (C:5)
          /        |        \
        [A]      *[B]*      [C]     <-- [탐욕적 선택: 국소 최저 비용 B 선택]
                 /   \
              (D:10) (E:20)
               /       \
             [D]       [E]          <-- 전체 비용: 1 + 10 = 11
                                        (만약 A 선택 시 3 + 1 = 4 최적해를 놓침)
```

## 핵심 통찰
- 탐욕 알고리즘이 전역 최적해를 보장하기 위해서는 "앞선 선택이 이후의 선택에 나쁜 영향을 주지 않는 탐욕적 선택 속성"이 수학적으로 엄밀히 증명되어야 함
- 0-1 배낭 문제는 물건을 쪼갤 수 없어 탐욕법이 실패하고 DP를 써야 하지만, 물건을 분할할 수 있는 분할 배낭(Fractional Knapsack) 문제는 무게당 가치 순으로 담는 탐욕법이 항상 최적해를 산출함
- 전역 최적해를 보장하지 못하는 복잡한 NP-난해 문제(예: 외판원 문제, 클러스터링)라 하더라도, 다항 시간 내에 실행 가능한 강력한 근사 알고리즘(Approximation Algorithm)의 기초로 활용됨

## 이웃 토픽과 구분
- 탐욕법 vs 동적 계획법 vs 백트래킹:
| 비교 항목 | 탐욕법 (Greedy) | 동적 계획법 (DP) | 백트래킹 (Backtracking) |
|---|---|---|---|
| 선택 방식 | 매 단계 국소 최적 즉시 선택 | 모든 하위 문제 최적해 비교 | 조건 불만족 시 이전 단계 복귀(가지치기) |
| 실행 시간 | 가장 빠름 ($O(n \log n)$ 수준) | 다항 시간 ($O(n^2), O(n^3)$) | 최악의 경우 지수 시간 ($O(2^n)$) |
| 최적해 보장 | 특정 조건(매트로이드)에서만 보장 | 항상 보장 | 항상 보장 |

## 문제·원인·대책
- 적용 상황: 클라우드 오토스케일링 VM 리소스 배치 엔진
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 국소 최적 선택으로 전체 리소스 파편화 | 당장 빈 공간이 가장 작은 노드에 배치(Best-Fit)하다가 대형 VM 배치 불가 상태 발생 | 근사 비율(Approximation Ratio)이 검증된 알고리즘 채택 및 주기적 리밸런싱 | 리소스 활용률 및 배치 성공률 개선 |
| 탐욕법의 조기 수렴으로 인한 품질 저하 | 복잡한 조합 최적화에서 국소 최적점(Local Minimum)에 갇혀 질적 개선 정체 | 탐욕적 탐색에 무작위성을 부여하는 GRASP 기법 또는 시뮬레이티드 어닐링 결합 | 전역 최적해 근접성 확보 |

## 내 의견
- [근사해 오차 한계 보증 및 A* 휴리스틱 결합을 통한 실시간 최적화] 대규모 분산 스케줄러에서 전역 최적해를 구하기 위해 지수 시간 알고리즘(DP/정수계획법)을 돌리면 스케줄링 결정 지연 자체가 시스템 장애를 유발함 → 나라면: 이론적 최악 오차 한계(Competitive Ratio)가 수학적으로 증명된 탐욕적 근사 알고리즘을 1차로 수행하여 밀리초 단위로 자원을 즉시 할당하고, 목적지까지의 잔여 비용을 추정하는 A* 휴리스틱 함수를 결합하여 탐욕적 오류를 실시간 보정
