## 답안 골격
```text
[최단 경로 알고리즘] ◀━━ 머리: 음수 가중치 유무와 출발점 범위에 따른 다익스트라, 벨만-포드, 플로이드-워셜의 최적 선택
 ┃
 ┣━ Ⅰ 개요 ───── 그래프 가중치 최소 경로 탐색 → 단일 출발점 vs 모든 쌍, 양수 vs 음수 가중치 지원 알고리즘 체계
 ┣━ Ⅱ 다익스트라 ─ 단일 출발점, 양수 가중치 전제, 탐욕법 및 우선순위 큐(최소 힙) 기반 고속화 ($O((V+E)\log V)$)
 ┣━ Ⅲ 벨만-포드 ─ 단일 출발점, 음수 가중치 허용, 간선 $V-1$회 완화(Relaxation), 음수 사이클 검출 ($O(VE)$)
 ┣━ Ⅳ 플로이드 ── 모든 쌍 최단 경로, 동적 계획법($D_{ij}^k = \min(D_{ij}^{k-1}, D_{ik}^{k-1} + D_{kj}^{k-1})$), $O(V^3)$
 ┣━ Ⅴ 비교 ───── 다익스트라 vs 벨만-포드 vs 플로이드-워셜 3대 알고리즘 종합 비교표
 ┗━ Ⅵ 실무 ───── 네트워크 라우팅(OSPF 링크상태 vs RIP 거리벡터) · 내비게이션 GPS 경로 안내
```
- 필수 키워드: 최단 경로 · 다익스트라(Dijkstra) · 벨만-포드(Bellman-Ford) · 플로이드-워셜 · 음수 사이클 · 완화(Relaxation)

## 한 줄 본질
- 그래프 내에서 가중치 합이 가장 작은 경로를 찾기 위해 양수 가중치에는 힙 기반 다익스트라, 음수 가중치/사이클에는 벨만-포드, 전체 노드 쌍에는 3중 루프 플로이드-워셜을 적용 → 최적 경로 도출 / 음수 사이클 시 경로 발산

## 핵심 그림
```text
[다익스트라: 탐욕적 힙 기반]       [벨만-포드: 전 간선 V-1회 완화]     [플로이드-워셜: 3차원 DP]
  [시작 S]                           간선 완화:                         중간 노드 k를 거쳐감:
     |                              if dist[v] > dist[u] + w:          D[i][j] = min(
   (우선순위 큐 최소 비용 추출)          dist[v] = dist[u] + w            D[i][j],
     v                                (V번째 갱신 발생 시 음수사이클)       D[i][k] + D[k][j]
  [방문 확정 정점]                                                     )
  (음수 가중치 시 오작동!)          (음수 가중치 완벽 지원)             (모든 정점 쌍 O(V^3))
```

## 핵심 통찰
- 다익스트라는 "이미 최단 거리가 확정된 노드의 거리는 다시 줄어들지 않는다"는 양수 가중치 전제하에 동작하므로 음수 간선이 존재하면 탐욕적 가정이 깨져 오답을 냄
- 벨만-포드는 음수 가중치를 허용하며, $V-1$번의 전체 간선 완화 후에도 $V$번째에 거리가 더 줄어드는 정점이 발견되면 무한 루프로 비용이 떨어지는 '음수 사이클(Negative Cycle)'의 존재를 판정함
- 플로이드-워셜은 중간 경유지 $k$를 가장 바깥 루프로 두는 $O(V^3)$ DP 알고리즘으로 모든 노드 쌍 간의 최단 거리를 2차원 배열 하나로 계산함

## 이웃 토픽과 구분
- 3대 최단 경로 알고리즘 종합 비교:
| 비교 항목 | 다익스트라 (Dijkstra) | 벨만-포드 (Bellman-Ford) | 플로이드-워셜 (Floyd-Warshall) |
|---|---|---|---|
| 알고리즘 패러다임 | 탐욕법 (Greedy) | 동적 계획법 (DP) | 동적 계획법 (DP) |
| 탐색 범위 | 단일 출발점 $\to$ 모든 정점 | 단일 출발점 $\to$ 모든 정점 | 모든 정점 쌍 $\to$ 모든 정점 쌍 |
| 음수 가중치 | 지원 불가 (양수 가중치 전제) | 지원 가능 | 지원 가능 |
| 음수 사이클 검출 | 불가능 | 가능 ($V$번째 완화 검증) | 가능 (대각 성분 $D[i][i] < 0$) |
| 시간 복잡도 | $O((V + E) \log V)$ (힙 사용 시) | $O(VE)$ | $O(V^3)$ |
