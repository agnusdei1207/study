## 답안 골격
```text
[SVM] ◀━━ 머리: Ⅶ 내 의견 (스케일링 전처리와 $C$·$\gamma$ 튜닝 자동화로 비선형 경계 최적화)
 ┃
 ┣━ Ⅰ 개요 ───── 경험적 오차 최소화의 과적합 한계 → 마진(Margin)을 최대화하는 최적 결정 초평면 도출
 ┣━ Ⅱ 특징 ───── 구조적 위험 최소화(SRM) · 경계 서포트 벡터만으로 모델 결정 · 고차원 공간 강건성
 ┣━ Ⅲ 구조 ───── 결정 초평면($w^T x + b = 0$) + 서포트 벡터 + 마진($2/\|w\|$) + 슬랙 변수($\xi$)
 ┣━ Ⅳ 흐름 ───── ① 특성 정규화 → ② 고차원 공간 매핑(커널) → ③ 라그랑주 쌍대 최적화 → ④ 초평면 확정
 ┣━ Ⅴ 비교 ───── 하드 마진 SVM vs 소프트 마진 SVM (이상치 불허 엄격 분리 vs 슬랙 변수 허용)
 ┗━ Ⅵ 실무 ───── 스케일링 민감도 / $O(N^2 \sim N^3)$ 연산 부하 / 커널 매개변수 과적합
```
- 필수 키워드: 결정 초평면 · 서포트 벡터 · 마진 최대화($2/\|w\|$) · 구조적 위험 최소화(SRM) · 슬랙 변수($\xi$) · 커널 트릭
- 배점 전략: 10점 = Ⅰ 개요 → Ⅲ 초평면 및 마진 구조도 → Ⅴ 하드 vs 소프트 마진 비교 / 25점 = Ⅰ~Ⅶ 전개, Ⅳ 라그랑주 쌍대 최적화 원리와 Ⅴ 커널 트릭 종류 상세 매핑
- 기출: 132회 4교시 `SVM 개념, 동작방식, 장단점 및 활용사례` → Ⅰ~Ⅵ

## 한 줄 본질
- 훈련 데이터 오차만 줄이는 모델은 미지의 테스트 데이터에서 일반화 오차가 증가함 → 두 클래스를 분리하는 경계와 가장 가까운 서포트 벡터 간의 거리(마진)를 최대로 벌리는 초평면을 구축 → 우수한 일반화 성능 확보 / 대용량 표본에서 학습 연산 복잡도 급증

## 핵심 그림
```text
       x2 ^                   [ 소프트 마진 SVM 결정 경계 ]
          |        + (양성 클래스)
          |     +      +   [x_+] 서포트 벡터
          |   --------------------  초평면 +1: w^T x + b = +1
          |      +   \       /
          |           \  M  /       마진 폭 M = 2 / ||w||
          |============\===/============ 결정 초평면: w^T x + b = 0
          |             \ /
          |   --------------------  초평면 -1: w^T x + b = -1
          |         -  [x_-] 서포트 벡터
          |      -         - (음성 클래스)
          +-----------------------------------> x1
```

## 핵심 용어
- 서포트 벡터(Support Vector): 결정 초평면에 가장 인접하여 마진의 경계를 형성하고, 초평면의 기울기와 위치를 온전히 결정짓는 데이터 벡터
- 마진(Margin): 양성 클래스 지지 초평면과 음성 클래스 지지 초평면 사이의 수직 거리($2/\|w\|$)로, 마진이 넓을수록 일반화 오류 위험이 감소
- 커널 트릭(Kernel Trick): 저차원에서 선형 분리가 불가능한 데이터를 고차원 특징 공간으로 직접 좌표 변환하지 않고, 내적 연산 함수만을 이용해 저비용으로 분리 경계를 찾는 수학적 기법

## 핵심 통찰
- 초평면 결정에 관여하는 것은 오직 경계선상의 서포트 벡터뿐임 → 경계와 멀리 떨어진 내부 데이터가 수백만 개 추가되어도 결정 경계는 조금도 흔들리지 않음
- 하드 마진은 잡음이나 단 하나의 이상치에도 경계 도출이 불가능해짐 → 오분류 허용 비용인 슬랙 변수($\xi_i$)와 균형 매개변수 $C$를 도입한 소프트 마진이 실제 적용의 정석임
- 거리를 기준으로 마진을 계산하므로 특성 간 스케일 차이가 크면 특정 변수가 마진 전체를 왜곡 → 모든 특성의 범위를 맞추는 표준화(StandardScaler)가 사전 필수 요건임

## 이웃 토픽과 구분
- SVM vs 로지스틱 회귀: SVM = 경계선 주변의 서포트 벡터에만 집중하여 결정 경계 마진을 최대화 / 로지스틱 회귀 = 모든 데이터 포인트의 확률 분포를 고려하여 로그 우도를 최대화

## 문제·원인·대책
- 적용 상황: 반도체 웨이퍼 결함 패턴 고차원 센서 데이터 이진 분류
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 특정 센서 값의 단위 차이로 인한 분류 오류 | 절대 수치가 큰 특성이 마진 계산의 유클리드 거리를 지배 | Z-Score 표준화 전처리를 모델 입력 직전에 결합 | 모든 센서 특성의 공평한 마진 기여 |
| 비선형 경계 데이터의 선형 분리 불가 | 저차원 입력 공간에서 클래스 간 데이터가 복잡하게 얽힘 | RBF(방사기저함수) 가우시안 커널 적용 및 고차원 힐베르트 공간 매핑 | 복잡한 비선형 결정 경계 형성 |

## 내 의견
- [대규모 데이터 환경에서 SVM 훈련 지연 병목] 표본 수가 수십만 건 이상으로 늘어나면 $O(N^2 \sim N^3)$의 계산 복잡도로 인해 전통적인 2차 계획법(QP Solver) 기반 SVM 학습이 중단되거나 과도한 컴퓨팅 자원을 소모함 → 나라면: 선형 분리가 가능한 대규모 텍스트 문제에서는 확률적 경사하강법 기반 선형 분류기(SGDClassifier)나 LinearSVC를 우선 검토하고, 비선형 RBF 커널이 필수적인 경우에는 앙상블 기법(Bagging)으로 데이터를 서브셋 단위로 분할하여 분산 학습 파이프라인을 구축
