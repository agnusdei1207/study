## 답안 골격
```text
[다층 퍼셉트론] ◀━━ 머리: Ⅶ 내 의견 (과적합 억제와 표현력 극대화를 위한 드롭아웃 및 가중치 감쇠 결합)
 ┃
 ┣━ Ⅰ 개요 ───── 단층 퍼셉트론의 선형 분리 한계(XOR 문제) 극복 → 은닉층과 비선형 활성화 함수를 결합한 인공신경망
 ┣━ Ⅱ 수학 ───── 보편 근사 정리(Universal Approximation Theorem): 1개 은닉층으로도 모든 연속 함수 근사 가능
 ┣━ Ⅲ 구조 ───── 입력층(Input) $\to$ 복수의 완전연결 은닉층(Hidden Layers) $\to$ 출력층(Output)
 ┣━ Ⅳ 흐름 ───── 순전파(가중합 $z=Wx+b$ 및 활성화 $a=\sigma(z)$) $\to$ 손실 계산 $\to$ 오차 역전파(Backprop) 파라미터 갱신
 ┣━ Ⅴ 비교 ───── 단층 퍼셉트론 vs 다층 퍼셉트론(MLP) vs 심층 신경망(DNN)
 ┗━ Ⅵ 실무 ───── XOR 문제 해결 · 과적합(Overfitting) 위험 · 이미지 평탄화 시 공간 정보 손실 한계
```
- 필수 키워드: 단층 퍼셉트론 · 은닉층(Hidden Layer) · XOR 문제 · 오차 역전파 · 비선형 활성화 함수 · 보편 근사 정리
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ XOR 문제 해결 원리 및 구조도 → Ⅳ 순전파/역전파 메커니즘 → Ⅵ 한계와 진화

## 한 줄 본질
- 하나의 직선으로 나눌 수 없는 비선형 문제(XOR)를 풀기 위해 입력 공간을 은닉층을 거쳐 고차원 공간으로 왜곡·변환한 후 선형 분리 → 보편적 함수 근사 능력 획득 / 파라미터 폭증 및 공간 정보 소실

## 핵심 그림
```text
[단층 퍼셉트론: XOR 분리 불가]           [다층 퍼셉트론: 은닉층을 통한 공간 왜곡 분리]
  X2 ^                                       X2 ^
   1 |   (1,0) O      (1,1) X                 1 |     O       X
     |                                          |      \     /
   0 |   (0,0) X      (0,1) O                 0 |       X---O
     +-------------------------> X1             +-------------------------> X1
      단일 직선으로 분리 불가                      은닉층 2개 뉴런으로 비선형 영역 분리
      
[MLP 순전파 및 역전파 구조]
 [입력층 X] ===> [은닉층 H: z1=W1*x+b1, a1=f(z1)] ===> [출력층 Y: z2=W2*a1+b2]
     |                                                                |
     \ <============= [ 오차 역전파 (Chain Rule) ] <==================/
```

## 핵심 통찰
- 단층 퍼셉트론은 결정 경계가 초평면(직선) 하나로 고정되어 XOR 논리를 풀 수 없었으나, 은닉층 뉴런들이 좌표축을 비선형적으로 접거나 비틀어 고차원 특징 공간에서 선형 분리가 가능하게 만듦
- 시벤코의 보편 근사 정리(Universal Approximation Theorem)에 따르면, 적절한 뉴런 수를 가진 단 하나의 비선형 은닉층만으로도 어떤 복잡한 연속 함수든 원하는 오차 범위 내로 근사할 수 있음
- 2차원 이상의 이미지나 시계열 데이터를 1차원 벡터로 강제 평탄화(Flatten)하여 입력받으므로, 픽셀 간의 물리적 인접성과 시간적 선후 관계를 전혀 활용하지 못하는 구조적 한계가 존재함

## 이웃 토픽과 구분
- 단층 퍼셉트론 vs 다층 퍼셉트론 (MLP):
| 비교 항목 | 단층 퍼셉트론 (Single-layer) | 다층 퍼셉트론 (MLP) |
|---|---|---|
| 계층 구조 | 입력층 $\to$ 출력층 (은닉층 없음) | 입력층 $\to$ 1개 이상의 은닉층 $\to$ 출력층 |
| 문제 해결 능력 | 선형 분리 가능 문제만 해결 (AND, OR) | 비선형 분리 문제 해결 가능 (XOR 등 모든 함수) |
| 활성화 함수 | 계단 함수 (Step Function, 미분 불가) | 비선형 미분 가능 함수 (Sigmoid, ReLU, Tanh) |
| 학습 알고리즘 | 델타 규칙 (단순 오차 갱신) | 오차 역전파 알고리즘 (경사하강법 + 연쇄법칙) |

## 문제·원인·대책
- 적용 상황: 대규모 정형 데이터 기반 사용자 이탈 예측 모델
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 은닉 뉴런 증가 시 학습 데이터 과적합 | 모델의 자유도(파라미터 수)가 과도하게 커서 훈련 데이터의 잡음까지 암기 | 은닉 뉴런의 일부를 무작위 비활성화하는 드롭아웃(Dropout) 및 L2 규제 적용 | 일반화 오차 최소화 |
| 역전파 학습 속도 저하 및 정체 | 모든 노드가 완전연결되어 불필요한 가중치 연산 부하 발생 | 배치 정규화(Batch Normalization) 적용 및 미니배치 SGD 채택 | 가중치 초기화 민감도 완화 및 수렴 가속 |
