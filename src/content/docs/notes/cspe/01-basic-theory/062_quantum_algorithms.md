## 답안 골격
```text
[양자 알고리즘 체계] ◀━━ 머리: 양자 중첩과 간섭을 활용한 지수 가속(쇼어) 및 이차 가속(그로버)
 ┃
 ┣━ Ⅰ 개요 ───── 폰 노이만 컴퓨터 계산 한계 → 큐비트(Qubit)의 중첩(Superposition)과 얽힘(Entanglement) 병렬 연산
 ┣━ Ⅱ 쇼어 ───── 쇼어 알고리즘(Shor): 양자 푸리에 변환(QFT) 기반 소인수분해 지수적 가속 ($O((\log N)^3)$)
 ┣━ Ⅲ 그로버 ─── 그로버 알고리즘(Grover): 비정렬 데이터베이스 검색의 이차 가속 ($O(N) \to O(\sqrt{N})$)
 ┣━ Ⅳ 메커니즘 ─ 주기 찾기(Period Finding: 쇼어) vs 오라클 반사 및 진폭 증폭(Amplitude Amplification: 그로버)
 ┣━ Ⅴ 비교 ───── 쇼어 알고리즘 vs 그로버 알고리즘 (적용 분야, 가속 비율, 현대 암호계에 미치는 영향)
 ┗━ Ⅵ 실무 ───── 현대 공개키(RSA, ECC) 붕괴 위협 · 양자 내성 암호(PQC: 격자 기반 Kyber 등) 도입
```
- 필수 키워드: 큐비트(Qubit) · 쇼어 알고리즘 · 그로버 알고리즘 · 양자 푸리에 변환(QFT) · 진폭 증폭 · PQC(양자내성암호)

## 한 줄 본질
- 양자 비트의 확률적 중첩 상태에서 모든 가능한 경로를 동시 연산하고 양자 간섭으로 정답의 확률 진폭만 증폭 → 암호 난제 및 고속 검색 해결 / 결맞음(Decoherence) 및 양자 오류 정정(QEC) 한계

## 핵심 그림
```text
[쇼어 알고리즘: 소인수분해 지수 가속]          [그로버 알고리즘: 검색 이차 가속]
  고전: 준지수 시간 exp(O(cbrt(N)))              고전: O(N) 순차 탐색
  양자: 다항 시간 O((log N)^3)                   양자: O(sqrt(N)) 진폭 증폭
  
  [양자 중첩] ---> [모듈러 거듭제곱]                진폭(확률)
       |                                           ^      [정답 진폭 증폭!]
       v                                           |       |
  [양자 푸리에 변환 (QFT)]                          |   |   |   |
       |                                           +---+---+---+---+---> 상태
  [주기 r 측정] -> [소인수 p, q 즉시 산출]             오라클 반전 + 평균 반사 반복
```

## 핵심 통찰
- 쇼어 알고리즘은 소인수분해 문제를 모듈러 함수의 '주기 찾기(Period Finding)' 문제로 환원한 후, 양자 푸리에 변환(QFT)을 통해 지수적 시간을 다항 시간($O((\log N)^3)$)으로 무너뜨려 RSA와 ECC를 즉시 해독함
- 그로버 알고리즘은 비정렬 데이터 검색의 복잡도를 $O(N)$에서 $O(\sqrt{N})$으로 줄여주며, 이로 인해 AES-128의 유효 키 길이가 64비트로 반토막 나므로 대칭키는 AES-256으로 키 길이를 2배 확장해야 함

## 이웃 토픽과 구분
- 쇼어 알고리즘 vs 그로버 알고리즘:
| 비교 항목 | 쇼어 알고리즘 (Shor) | 그로버 알고리즘 (Grover) |
|---|---|---|
| 해결 문제 | 소인수분해, 이산 대수 문제 | 비정렬 데이터베이스 검색, 암호키 전수조사 |
| 가속 수준 | 지수적 가속 (Exponential Speedup) | 이차 가속 (Quadratic Speedup, $O(\sqrt{N})$) |
| 암호학적 영향 | RSA, ECC 공개키 암호 체계의 완전 무력화 | 대칭키(AES) 및 해시함수의 안전 비트 절반 감소 |
| 대응 방안 | 양자 내성 암호(PQC: 격자, 다변수 등)로 전면 전환 | 대칭키 길이를 256비트 이상으로 2배 확대 |
