## 답안 골격
```text
[결측값 처리] ◀━━ 머리: Ⅶ 내 의견 (결측 메커니즘 진단 기반 MICE 다중 대치 및 KNN 하이브리드 적용)
 ┃
 ┣━ Ⅰ 개요 ───── 데이터 수집 누락 한계 → 모델 학습 왜곡 방지를 위한 결측 메커니즘 규명 및 통계적/ML 대치
 ┣━ Ⅱ 유형 ───── 결측 메커니즘 3대 분류: MCAR(완전 무작위) · MAR(무작위) · MNAR(비무작위)
 ┣━ Ⅲ 전략 ───── 완전 제거(Listwise Deletion) vs 단순 대치(평균/중앙값) vs 통계/ML 대치(MICE, KNN)
 ┣━ Ⅳ 흐름 ───── 결측 비율 확인 $\to$ 메커니즘 통계 검정(Little's Test) $\to$ 대치 알고리즘 수행 $\to$ 분포 보존 평가
 ┣━ Ⅴ 비교 ───── 완전 삭제 vs 단순 대치 vs 다중 대치(MICE) vs KNN 대치
 ┗━ Ⅵ 실무 ───── 단순 대치로 인한 분산 과소평가 왜곡 방지 · 결측 여부 자체를 특성화(Missing Indicator)
```
- 필수 키워드: MCAR · MAR · MNAR · 완전 제거(Listwise) · 단순 대치 · MICE(다중 대치) · KNN 대치
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 결측 메커니즘 3대 분류 정의 → Ⅲ 처리 기법 비교도 → Ⅴ 종합 비교표

## 한 줄 본질
- 센서 고장이나 응답 거부로 누락된 결측치를 무작정 버리거나 평균으로 채워 데이터 통계량을 왜곡하지 않고 결측의 원인을 파악해 최적의 통계/ML 값으로 복원 → 데이터 손실 방지 및 모델 편향 제거 / 연산 복잡도 증가

## 핵심 그림
```text
[결측 메커니즘 3대 분류]
 1. MCAR (완전 무작위): 결측이 다른 어떤 변수와도 무관 (단순 전송 오류, 커피 쏟음)
 2. MAR  (무작위 결측): 결측이 다른 '관측된 변수'와 상관 (여성이 체중 기재 누락)
 3. MNAR (비무작위 결측): 결측이 '그 변수 자체의 값'과 상관 (고소득자가 소득 미응답)
 
[대치 기법 처리 구조]
 [결측 데이터셋]
        |
        +---> [단순 삭제: Listwise] ----> 표본 축소, MNAR/MAR 시 심각한 편향 발생
        +---> [단순 대치: 평균/중앙값] -> 표본 보존, 분산 인위적 축소(Underestimation)
        +---> [다중 대치: MICE] --------> 회귀 모델로 M개 복수 생성, 통계적 불확실성 보존
        +---> [머신러닝: KNN Impute] ---> 최근접 K개 이웃 가중치 합산 대치
```

## 핵심 통찰
- 단순 삭제(Listwise Deletion)는 결측치가 MCAR일 때만 편향이 생기지 않으며, MAR이나 MNAR인 상태에서 데이터를 통째로 버리면 표본이 한쪽으로 극단적으로 치우치는 선택 편향(Selection Bias)이 발생함
- 평균값이나 최빈값으로 단순 대치하면 데이터의 분산(Variance)이 인위적으로 축소되어 표준 오차가 작게 추정되고, 가설 검정 시 1종 오류(False Positive) 위험이 급증함
- MICE(Multivariate Imputation by Chained Equations)는 각 결측 변수를 타 변수들로 회귀 예측하여 여러 개의 가상 완성 데이터셋을 만들고 결과를 풀링(Pooling)함으로써 대치 자체의 불확실성을 수학적으로 완벽히 보존함

## 이웃 토픽과 구분
- 결측치 처리 기법 비교:
| 비교 항목 | 완전 삭제 (Listwise) | 단순 평균/중앙값 대치 | 다중 대치법 (MICE) | KNN 대치법 (KNN) |
|---|---|---|---|
| 데이터 보존 | 결측치 포함 행 전체 제거 | 원본 표본 크기 유지 | 원본 표본 크기 유지 | 원본 표본 크기 유지 |
| 통계적 분산 | 분산 보존 가능 (MCAR 시) | 분산이 인위적으로 축소됨 | 실제 분산과 불확실성 보존 | 국소 상관관계 보존 우수 |
| 편향 발생 위험 | MAR/MNAR 시 매우 높음 | 높음 (변수 간 공분산 파괴) | 낮음 (체인 회귀 기반) | 낮음 (국소 유사성 기반) |
| 계산 복잡도 | $O(1)$ (가장 단순) | $O(N)$ (단순 집계) | $O(M \times N \times P)$ (복합 회귀) | $O(N^2)$ (거리 연산 병목) |

## 문제·원인·대책
- 적용 상황: 대규모 공공 보건 의료 데이터베이스 정제 파이프라인
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 결측치 다수 삭제로 인한 모델 학습 표본 고갈 | 복수 컬럼의 부분 결측으로 행 단위 삭제 시 데이터 절반 이상 손실 | 체인 방정식 다중 대치(MICE) 또는 랜덤 포레스트 기반 MissForest 적용 | 데이터 보존 및 정보 손실 방지 |
| 결측 발생 사실 자체에 담긴 중요 정보 소실 | 결측 여부가 특정 질환 유무와 강한 상관을 가지는 MNAR 성격 | 결측 여부를 0과 1로 나타내는 결측 지시자(Missing Indicator) 파생 변수 추가 | 모델 설명력 및 예측 정확도 향상 |

## 내 의견
- [결측 메커니즘 진단 기반 MICE 다중 대치 및 KNN 하이브리드 적용] 실무 머신러닝에서 단순 평균 대치를 남발하면 피처 간의 공분산 구조가 붕괴하여 정밀 트리 모델의 예측력이 저하됨 → 나라면: Little의 MCAR 통계 검정으로 결측 성격을 먼저 진단하고, 결측 비율이 높은 변수에는 결측 지시자 컬럼을 병렬 생성한 후, 연속형 변수는 MICE 다중 회귀 대치, 이산형 카테고리는 가중치 KNN 대치를 결합하는 지능형 전처리 파이프라인 자동화 구축
