## 답안 골격
```text
[조합 논리 회로] ◀━━ 머리: Ⅶ 내 의견 (캐리 전파 지연 제거를 위한 CLA와 하자리 병렬 가산기 도입)
 ┃
 ┣━ Ⅰ 개요 ───── 기억 소자 배제 → 현재 입력값의 논리 게이트 조합에 의해서만 출력이 즉각 결정되는 디지털 회로
 ┣━ Ⅱ 특성 ───── 내부 피드백 루프 부재 · 클록(Clock) 무관 · 전파 지연(Propagation Delay) 및 글리치(Hazard)
 ┣━ Ⅲ 구조 ───── 기본 게이트(AND, OR, NOT, XOR) 조합 회로망
 ┣━ Ⅳ 분류 ───── 연산(반가산기, 전가산기, CLA) · 데이터 전송(MUX, DEMUX) · 코드 변환(인코더, 디코더)
 ┣━ Ⅴ 비교 ───── 조합 논리 회로(Combinational) vs 순차 논리 회로(Sequential) (기억 유무, 클록 동기화)
 ┗━ Ⅵ 실무 ───── 리플 캐리 가산기(RCA) 지연 극복(CLA) · 멀티플렉서 버스 중재 · 글리치 방지 카르노 맵
```
- 필수 키워드: 전파 지연(Propagation Delay) · 반가산기(HA) · 전가산기(FA) · 멀티플렉서(MUX) · 캐리 룩어헤드(CLA) · 글리치(Glitch)
- 배점 전략: 10점 = Ⅰ 개요 → Ⅱ 특성 및 순차 회로와의 비교 → Ⅳ 핵심 회로(가산기, MUX) 도해 → Ⅵ CLA 지연 개선

## 한 줄 본질
- 이전 상태를 기억하지 않고 현재 입력 신호의 논리 연산만으로 즉각 출력을 생성 → 회로 구조 단순화 및 고속 연산 달성 / 게이트 단계별 신호 지연(전파 지연) 누적으로 인한 글리치 및 주파수 제약

## 핵심 그림
```text
[전가산기 (Full Adder: FA)]               [멀티플렉서 (4:1 MUX)]
       A -----\                                  I0 ----\
               XOR -- Sum (S)                    I1 -----\
       B -----/   \                              I2 ------+-- Output (Y)
                   AND --\                       I3 -----/
       Cin -----------    OR -- Cout (C)                 /
                           /                       S1 S0 (선택 신호)
 [반가산기(HA) 2개 + OR 1개 결합]                 (S1, S0 값에 따라 1개 입력 선택)
 
[가산기 지연 극복: RCA vs CLA]
 RCA: C0 -> [FA0] -> C1 -> [FA1] -> C2 -> [FA2] -> C3  (지연: O(n) 선형 누적)
 CLA: 캐리 생성($G_i=A_i B_i$)과 전파($P_i=A_i \oplus B_i$) 로직으로 모든 캐시 1클록 병렬 계산
```

## 핵심 통찰
- 조합 논리 회로는 메모리(Flip-Flop)와 클록이 없어 입력이 바뀌면 즉시 출력이 반응하지만, 게이트를 통과하는 물리적 전자 전파 지연 시간($t_{pd}$)으로 인해 일시적인 신호 오차인 글리치(Hazard)가 발생함
- 리플 캐리 가산기(RCA)는 하위 비트의 캐리가 상위 비트로 파도처럼 전달되어 비트 수에 비례하는 $O(n)$ 지연이 발생하므로, CPU ALU에서는 캐리를 미리 병렬로 계산하는 캐리 룩어헤드 가산기(CLA)가 필수적임
- MUX는 $2^n$개의 입력 중 선택 신호 $n$비트로 1개의 출력을 골라내는 스위치 역할을 하여 데이터 버스 공유와 ALU 내부 기능 선택(Opcode 디코딩)에 핵심 소자로 사용됨

## 이웃 토픽과 구분
- 조합 논리 회로 vs 순차 논리 회로:
| 비교 항목 | 조합 논리 회로 (Combinational) | 순차 논리 회로 (Sequential) |
|---|---|---|
| 출력 결정 | 현재 입력값의 논리 조합 | 현재 입력값 + 이전 상태(메모리 값) |
| 기억 소자 | 없음 (플립플롭/래치 부재) | 있음 (플립플롭, 레지스터 내장) |
| 클록 신호 | 클록 불필요 (비동기 즉시 동작) | 시스템 클록에 동기화되어 상태 전이 |
| 대표 회로 | 가산기, 감산기, MUX, DEMUX, 디코더 | 플립플롭, 카운터, 레지스터, CPU FSM |

## 문제·원인·대책
- 적용 상황: 고클록 프로세서 ALU(산술논리연산장치) 하드웨어 설계
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 비트 수 증가에 따른 연산 클록 한계 | 리플 캐리 가산기의 캐리 체인 전파 지연으로 임계 경로(Critical Path) 악화 | 캐리 룩어헤드 가산기(CLA) 또는 캐리 선택 가산기(CSA) 채택 | 캐리 연산 지연 $O(\log n)$ 단축 |
| 경로 지연 차이로 인한 일시적 허위 출력(글리치) | 서로 다른 입력 신호가 게이트를 통과하는 경로 길이가 달라 신호 도착 시점 불일치 | 카르노 맵 최소화 시 중복 항(Consensus Term) 추가 및 출력 버퍼링 | 정적 해저드(Static Hazard) 제거 |

## 내 의견
- [캐리 전파 지연 제거를 위한 CLA와 하자리 병렬 가산기 도입] 64비트 이상의 현대 고성능 CPU에서 단일 CLA를 전 비트에 걸쳐 구현하면 팬인(Fan-in) 부하로 인해 게이트 면적과 소비 전력이 기하급수적으로 폭증함 → 나라면: 4비트 또는 8비트 단위의 블록 내부에서는 국소 CLA를 적용하고, 블록 간에는 캐리 건너뛰기(Carry-Skip) 또는 캐리 선택 가산기(Carry-Select Adder)를 계층화하여 회로 면적 증가를 억제하면서도 나노초 미만의 연산 레이턴시 달성
