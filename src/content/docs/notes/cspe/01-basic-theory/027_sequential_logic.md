## 답안 골격
```text
[순차 논리 회로] ◀━━ 머리: 클록 에지 동기화와 피드백 루프 기반 상태 기억 및 FSM 구현
 ┃
 ┣━ Ⅰ 개요 ───── 조합 회로의 기억 부재 한계 → 현재 입력과 이전 내부 상태(State)의 피드백 결합 회로
 ┣━ Ⅱ 소자 ───── 래치(Latch: 레벨 트리거) vs 플립플롭(Flip-Flop: 에지 트리거 클록 동기화)
 ┣━ Ⅲ 유형 ───── RS · JK(토글 추가, 미정 상태 해소) · D(데이터 지연/보존) · T(토글/카운터)
 ┣━ Ⅳ 모델 ───── 무어 머신(Moore: 출력=상태) vs 밀리 머신(Mealy: 출력=상태+입력)
 ┣━ Ⅴ 비교 ───── 조합 논리 회로(Combinational) vs 순차 논리 회로(Sequential)
 ┗━ Ⅵ 실무 ───── CPU 레지스터 · 시프트 레지스터 · 유한 상태 머신(FSM) 제어 로직
```
- 필수 키워드: 순차 회로 · 플립플롭(Flip-Flop) · 래치(Latch) · 클록(Clock) · D 플립플롭 · 무어/밀리 머신 · FSM

## 한 줄 본질
- 클록 펄스의 상승/하강 에지에 맞춰 1비트의 2진 정보를 안정적으로 기억(라치)하고 이전 상태에 따라 다음 출력을 결정 → CPU 레지스터와 순차 제어기 구축 / 클록 스큐 및 셋업/홀드 시간 제약

## 핵심 그림
```text
[D 플립플롭 (Edge-Triggered)]            [순차 논리 회로 일반 블록도]
        +----------+                            +-----------------------+
   D ---| D      Q |--- Q (저장값)        입력 ->|                       |-> 출력
        |          |                            |   조합 논리 회로       |
 CLK -->|>     /Q  |--- /Q (반전)               |                       |
        +----------+                            +-----------------------+
                                                    ^               |
 [클록 에지 발생 순간 D값을 Q에 래치]                   | (현재 상태)    v (다음 상태)
                                                +-----------------------+
                                                |  메모리 소자 (플립플롭)  |<-- CLK
                                                +-----------------------+
```

## 핵심 통찰
- 래치(Latch)는 클록 레벨(High/Low) 동안 입력이 바뀌면 출력이 계속 흔들리는 불안정성이 있지만, 플립플롭(Flip-Flop)은 클록의 상승 에지(Edge) 순간에만 입력을 딱 한 번 포착하므로 노이즈에 극히 안전함
- CPU 내부의 범용 레지스터와 프로그램 카운터(PC)는 D 플립플롭을 32개 또는 64개 병렬로 묶어 클록 한 주기에 데이터를 쓰거나 보존하는 핵심 물리 장치임

## 이웃 토픽과 구분
- 무어 머신 vs 밀리 머신: 무어 머신 = 출력이 오직 현재 상태에만 의존하여 글리치에 안전하고 클록에 완벽 동기화 / 밀리 머신 = 출력이 현재 상태와 현재 입력 모두에 반응하여 상태 수가 적지만 입력 변동 시 글리치 발생 가능
