## 답안 골격
```text
[결정 트리] ◀━━ 머리: 불순도(지니/엔트로피) 최소화 기반 직관적 규칙 분할과 과적합 가지치기
 ┃
 ┣━ Ⅰ 개요 ───── 블랙박스 모델 한계 → if-then 규칙 기반의 해석 가능한(Explainable) 트리형 분류·회귀 모델
 ┣━ Ⅱ 기준 ───── 불순도(Impurity) 지표: 지니 계수($1-\sum p_i^2$) · 정보 엔트로피($-\sum p_i \log p_i$)
 ┣━ Ⅲ 구조 ───── 루트 노드(Root) $\to$ 내부 분기 노드(Internal Node) $\to$ 최종 잎 노드(Leaf Node)
 ┣━ Ⅳ 분할 ───── 탐욕적 분할(재귀적 이진 분할) $\to$ 정보 이득(Information Gain) 최대화 지점 탐색
 ┣━ Ⅴ 비교 ───── 결정 트리(Decision Tree: 고분산, 높은 해석력) vs 랜덤 포레스트(Random Forest: 저분산, 블랙박스)
 ┗━ Ⅵ 실무 ───── 사전/사후 가지치기(Pruning)를 통한 과적합 제어 · 직교 축 분할의 기하학적 한계
```
- 필수 키워드: 불순도(Impurity) · 지니 계수 · 엔트로피 · 정보 이득 · 가지치기(Pruning) · CART

## 한 줄 본질
- 데이터를 가장 순수하게 가르는 단일 변수 질문을 반복하여 트리 형태로 분류/회귀 규칙을 생성 → 뛰어난 직관성과 설명력 제공 / 축 정렬 분할로 인한 과적합 및 대각선 데이터 분리 취약

## 핵심 그림
```text
                  [ 루트 노드: 소득 > 5000? ]
                         /         \
                      (Yes)        (No)
                      /               \
     [ 신용점수 > 700? ]               [ 잎 노드: 대출 거절 ]
        /         \
     (Yes)        (No)
      /             \
 [잎: 대출 승인]   [잎: 대출 거절]
```

## 핵심 통찰
- 결정 트리의 학습은 매 분기점마다 불순도(Gini 계수 또는 엔트로피)가 가장 크게 감소하는 변수와 분할 임계값을 탐욕적(Greedy)으로 선택하는 과정임
- 트리를 끝까지 자라게 두면 훈련 데이터의 모든 샘플을 단독 잎 노드로 격리할 때까지 분할하므로 훈련 오차는 0이 되지만 새로운 데이터에 대한 일반화가 붕괴(과적합)하여, 최대 깊이 제한이나 사후 가지치기(Pruning)가 필수적임

## 이웃 토픽과 구분
- 지니 계수(CART) vs 엔트로피(C4.5): 지니 계수는 제곱 연산($1 - \sum p_i^2$)만을 수행하여 로그 연산이 들어가는 엔트로피보다 계산이 훨씬 빨라 실무 CART 알고리즘의 기본값으로 널리 채택됨
