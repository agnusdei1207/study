## 한 줄 본질
- 1차원 B+Tree로 표현 불가능한 다차원 공간·위치 관계 → MBR(최소경계사각형) 또는 공간 분할 평면으로 계층화하여 공간적 근접성 색인 → 다차원 범위 및 최근접(k-NN) 탐색 가속 / 고차원 시 성능 급락

## 핵심 용어
- MBR(Minimum Bounding Rectangle): 다차원 공간 내 불규칙한 도형 객체를 완전히 포함하는 가장 작은 $N$차원 직사각형(축 정렬 바운딩 박스)
- 필터링 및 정제(Filter & Refine): 1단계로 가벼운 MBR 색인을 통해 후보군을 빠르게 걸러내고(Filter), 2단계로 실제 복잡한 폴리곤 기하 연산을 수행해 확정(Refine)하는 기법

## 핵심 통찰
- B+Tree는 1차원 정렬만 지원하므로 경도와 위도를 각각 인덱싱해도 두 축을 동시에 만족하는 영역 검색 시 엄청난 랜덤 I/O 발생 → 다차원 색인 필수
- R-Tree는 형제 MBR 간 겹침(Overlap)과 빈 공간(Dead Space)을 얼마나 줄이느냐가 탐색 성능을 결정 → MBR이 겹치면 단일 질의에 여러 브랜치를 동시에 탐색해야 하므로 $O(\log N)$이 깨짐
- 차원이 10~20차원 이상으로 올라가면 공간의 모서리가 기하급수적으로 늘어나 모든 데이터가 서로 멀어지는 '차원의 저주' 발생 → 고차원에서는 트리 기반 대신 그래프/해시 기반 근사 색인(HNSW, LSH)으로 전환해야 함

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| R* Tree | R-Tree의 분할 최적화 개선 | MBR의 면적뿐 아니라 둘레, 겹침을 최소화하고 강제 재삽입(Re-insertion)을 도입한 고성능 트리 |
| K-D Tree | 포인트 데이터 전용 공간 분할 | 각 계층마다 분할 차원을 순환(X축 분할 → Y축 분할 → Z축 분할)하며 공간을 이분하는 이진 트리 |

## 이웃 토픽과 구분
- 공간 분할(K-D Tree, Quad Tree) vs 객체 분할(R-Tree): 공간 분할 = 비어있는 공간 전체를 분할하므로 경계에 걸친 객체는 분할 저장 / 객체 분할 = 실제 객체를 감싸는 MBR 중심 분할로 객체 중복 저장이 없음

## 문제·원인·대책
- 적용 상황: 배달 플랫폼의 라이더 실시간 위치 기반 반경 2km 매장 검색
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 반경 검색 시 수십 개의 MBR이 중복 탐색되어 DB CPU 100% 도달 | 라이더 이동에 따른 잦은 INSERT로 R-Tree MBR 중복 영역(Overlap) 과다 팽창 | R* Tree 전환 및 Uber H3(육각 그리드 인덱스) 결합 | 공간 탐색 레이턴시 70% 단축 |
| 512차원 이미지 특징 벡터를 R-Tree에 저장 후 검색 시 풀스캔보다 느려짐 | 차원의 저주로 인해 MBR의 대부분이 중첩되는 현상 | 트리 색인 제거 후 벡터 DB(HNSW 기반 ANN)로 전면 교체 | 검색 시간 3초에서 15ms로 개선 |
