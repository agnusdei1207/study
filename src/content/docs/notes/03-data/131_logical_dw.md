 ┣━ Ⅰ 개요 ───── 물리적으로 데이터를 단일 저장소로 복제·적재(ETL)하지 않고, 데이터 가상화(Data Virtualization) 기술을 통해 분산된 이종 데이터 소스를 단일 논리 뷰로 통합하는 차세대 DW 아키텍처

 ┣━ Ⅲ 구조 ───── 원천 소스(RDB, NoSQL, SaaS, 파일) / 가상화 계층(Data Virtualization, 시맨틱 레이어) / 소비 계층(BI, SQL, AI)
 ┣━ Ⅳ 흐름 ───── ① 사용자 단일 가상 SQL 질의 → ② LDW 엔진이 질의 구문 분석 및 최적화 → ③ 원천 소스로 쿼리 푸시다운(Pushdown) → ④ 이기종 결과 병합 → ⑤ 단일 결과셋 반환
 ┣━ Ⅴ 비교 ───── 전통적 물리 DW vs 로지컬 DW (물리적 ETL 복제/T+1 배치 vs 무복제 실시간 가상화/온디맨드 질의)
 ┗━ Ⅵ 실무 ───── 원천 시스템 성능 저하(쿼리 부하 전이) / 분산 조인(Cross-source Join) 시 네트워크 대역폭 병목

## 한 줄 본질
- 수많은 이종 데이터(RDB, NoSQL, 클라우드)를 하나의 물리 DW로 모으는 ETL 파이프라인의 구축·유지비용 폭증 → 데이터는 제자리에 둔 채 가상화 계층에서 단일 SQL로 묶어 온디맨드로 조회 → 민첩한 분석 환경 달성 / 원천 시스템 쿼리 부하 위험

## 핵심 용어
- 데이터 가상화(Data Virtualization): 데이터의 물리적 위치, 스토리지 구조, API 프로토콜에 구애받지 않고 단일 표준 인터페이스(SQL/REST)로 실시간 접근할 수 있도록 추상화하는 기술
- 쿼리 푸시다운(Query Pushdown): 필터링(`WHERE`)이나 집계(`GROUP BY`) 같은 연산을 가상화 엔진이 아닌 원천 DB 엔진에서 직접 실행되도록 쿼리를 하향 전달하는 최적화 기법

## 핵심 통찰
- 전통적인 DW 프로젝트가 실패하는 90% 이유는 '데이터를 물리적으로 한 곳에 다 모으려다 지쳐 쓰러지기 때문'임 → 원천 스키마가 바뀔 때마다 ETL 파이프라인이 터지고 배포에 수개월 소요
- 로지컬 DW의 핵심은 '데이터를 옮기지 않는 것(Zero Data Movement)'임 → 데이터는 각자 가장 최적화된 원천(트랜잭션은 RDB, 로그는 S3, 시계열은 NoSQL)에 그대로 두고 논리 계층만 씌움
- 단, 두 개 이상의 대형 이종 시스템 간 대규모 조인(Cross-database Join)이 발생할 경우 네트워크 대역폭이 고갈될 수 있으므로 영리한 쿼리 푸시다운과 인메모리 캐싱이 필수적

## 이웃 토픽과 구분
- 로지컬 DW vs 전통적 물리 DW: 물리 DW = 대규모 스토리지를 사서 데이터를 물리적으로 복제·적재(Storage Heavy) / 로지컬 DW = 스토리지 증설 없이 컴퓨팅 가상화 엔진만 두어 쿼리 시점에 실시간 연합(Compute Heavy)

## 문제·원인·대책
- 적용 상황: 클라우드와 온프레미스에 분산된 전사 데이터의 통합 경영 대시보드 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 로지컬 DW에서 대형 집계 쿼리 실행 시 원천 운영계 ERP DB CPU가 100%로 마비 | 쿼리 푸시다운으로 인한 운영 DB의 직접적인 대량 연산 부하 | 원천계 Read Replica로 가상화 엔드포인트를 분리하고 빈발 쿼리 결과 캐싱 | 운영계 영향 제로화 및 대시보드 응답 시간 90% 단축 |
| 서로 다른 소스 간 조인 시 수천만 건 데이터가 가상화 노드로 몰려 네트워크 다운 | 조인 대상 데이터가 필터링 없이 네트워크를 타고 가상화 계층으로 전송 | 동적 파티션 가지치기 및 소규모 차원 테이블을 원천 DB로 임시 역푸시다운 | 네트워크 전송량 95% 절감 |

## 내 의견
- [극단적 순수 가상화 만능주의 경계] 물리적 저장을 100% 없애고 순수 가상화로만 대용량 분석을 처리하려다 네트워크 병목과 타임아웃으로 프로젝트가 표류하는 사례 빈발 → 나라면: 수년간의 과거 이력 집계 데이터는 클라우드 객체 스토리지(Lakehouse)에 물리 적재하고, 실시간성 최신 데이터만 원천 DB를 직접 가상화하여 결합하는 '하이브리드 로지컬 DW' 아키텍처 수립
