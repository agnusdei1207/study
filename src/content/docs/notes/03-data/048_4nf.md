## 답안 골격
```text
[제4정규형] ◀━━ 머리: Ⅶ 내 의견 (독립적 다치 종속(MVD)의 조기 식별을 통한 카테시안 곱 중복 사전 예방)
 ┃
 ┣━ Ⅰ 개요 ───── BCNF를 만족하면서 함수적 종속이 아닌 다치 종속성(MVD)을 제거하여 중복을 최소화한 정규형
 ┣━ Ⅱ 특징 ───── BCNF 만족 전제 · 다치 종속($X \twoheadrightarrow Y$) 제거 · 카테시안 곱 형태의 중복 배제 · 무손실 분해
 ┣━ Ⅲ 구조 ───── 결정자 $X$ / 종속 속성 집합 $Y$ / 독립 속성 집합 $Z$ (단, $Y$와 $Z$는 상호 무관)
 ┣━ Ⅳ 흐름 ───── ① BCNF 달성 → ② 비사소한 다치 종속($X \twoheadrightarrow Y$) 발견 → ③ $R(X, Y, Z)$를 $R_1(X, Y)$와 $R_2(X, Z)$로 분해 → ④ 4NF 만족
 ┣━ Ⅴ 비교 ───── 3NF/BCNF vs 4NF (함수적 종속성($X \rightarrow Y$) 기반 vs 다치 종속성($X \twoheadrightarrow Y$) 기반)
 ┗━ Ⅵ 실무 ───── 한 개발자의 여러 프로그래밍 언어와 여러 자격증 보유 시 레코드 폭증 현상
```
- 필수 키워드: BCNF · 다치 종속(MVD, Multivalued Dependency) · $X \twoheadrightarrow Y$ · 비사소한 다치 종속 · 카테시안 곱 · 무손실 분해
- 배점 전략: 10점 = Ⅰ → Ⅲ 다치 종속 수식 정의 → 분해 전/후 테이블 비교 도식 / 25점 = Ⅰ~Ⅶ, Ⅲ 공리계(파기/보존) 및 Ⅳ 분해 절차
- 기출: 136회 1교시 4번 `제4정규형` → Ⅰ 개념 + Ⅲ MVD 정의 + 분해 전후 사례

## 한 줄 본질
- 하나의 릴레이션 안에 서로 무관한 두 개 이상의 1:N 관계가 공존할 때 발생하는 행 수 폭증(카테시안 곱) → 비사소한 다치 종속성($X \twoheadrightarrow Y$)을 분해하여 독립 릴레이션으로 격리 → 조합 중복 제거 / 조인 증가

## 핵심 그림
```text
[제4정규형(4NF) 분해 전후 비교]

[분해 전: R(사원ID, 보유기술, 취미) - MVD 존재]
 사원ID(X) ──>> 보유기술(Y)
 사원ID(X) ──>> 취미(Z)       (보유기술과 취미는 상호 독립)

 사원ID | 보유기술 | 취미       <-- 기술 2개 * 취미 2개 = 4행 (중복 폭증)
 ───────┼──────────┼───────
 E001   │ Java     │ 등산
 E001   │ Java     │ 수영
 E001   │ Python   │ 등산
 E001   │ Python   │ 수영
        │
        ▼ 4NF 무손실 분해 (R1, R2)
 ┌──────────────────────┐      ┌──────────────────────┐
 │ R1(사원ID, 보유기술) │      │ R2(사원ID, 취미)     │
 ├────────┬─────────────┤      ├────────┬─────────────┤
 │ E001   │ Java        │      │ E001   │ 등산        │
 │ E001   │ Python      │      │ E001   │ 수영        │
 └──────────────────────┘      └──────────────────────┘
 (총 2행 + 2행 = 4행으로 중복 없이 표현, 새 취미 추가 시 1행만 INSERT)
```

## 핵심 용어
- 다치 종속(MVD, Multivalued Dependency): $X$의 한 값에 대해 $Y$의 값 집합이 결정되고, 이 집합이 다른 속성 $Z$의 값들과 전혀 무관하게 독립적으로 존재하는 상태($X \twoheadrightarrow Y$)
- 비사소한 다치 종속(Non-trivial MVD): $X \twoheadrightarrow Y$에서 $Y$가 $X$의 부분집합이 아니고, $X \cup Y$가 전체 속성 집합이 아닌 경우

## 핵심 통찰
- BCNF까지는 '단일 값(Single-valued)'을 결정하는 함수적 종속성($X \rightarrow Y$)의 영역이지만, 4NF부터는 '값의 집합(Set-valued)'을 결정하는 다치 종속성($X \twoheadrightarrow Y$)의 영역임
- 사원이 기술을 추가할 때 기존에 등록된 모든 취미 개수만큼 행을 복제해 넣어야 하는 기형적 구조가 MVD의 실체임
- 실무에서는 대부분 논리 모델링 시 자연스럽게 엔터티를 분리하므로 4NF 위반을 인지하지 못하지만, 복합키 테이블에서 다대다 속성을 한곳에 밀어넣을 때 치명적 장애로 발현됨

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 파지트 정리(Fagin's Theorem) | 4NF 무손실 분해의 수학적 정리 | 릴레이션 $R(X, Y, Z)$가 $X \twoheadrightarrow Y \mid Z$를 만족할 때만 $R_1(X, Y)$와 $R_2(X, Z)$로 무손실 분해 가능 |
| 제5정규형(5NF, PJNF) | 4NF의 상위 정규형 | 3개 이상의 릴레이션으로 분해했다가 다시 조인할 때 생기는 조인 종속성(JD)을 제거하는 정규형 |

## 이웃 토픽과 구분
- BCNF vs 4NF: BCNF = 모든 결정자가 후보키인 함수적 종속성($X \rightarrow Y$)의 종착역 / 4NF = 다치 종속성($X \twoheadrightarrow Y$)을 제거하여 독립적인 다대다 관계를 분리

## 문제·원인·대책
- 적용 상황: 인재 관리 시스템의 사원 자격증 및 외국어 역량 관리
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 사원이 자격증을 1개 추가할 때마다 보유 외국어 수만큼 INSERT 실패 및 교착 | 자격증과 외국어가 단일 사원 테이블에 공존하는 다치 종속성 위반 | 사원-자격증, 사원-외국어 테이블로 4NF 무손실 분해 | 자격증 추가 시 단 1건의 INSERT로 해결 |
| 특정 취미를 삭제했으나 해당 사원의 기술 정보까지 함께 삭제됨 | 복합 기본키(사원ID, 기술, 취미) 테이블에서의 삭제 이상 | 4NF 분해를 통한 속성 간 독립성 보장 | 데이터 무결성 보존 |

## 이렇게 출제된다
- 제136회 1교시 4번: "제4정규형" → 요구 포인트: 다치 종속(MVD) 정의 수식($X \twoheadrightarrow Y$) + 4NF 조건 + 위반 사례 및 분해 테이블

## 내 의견
- [무의미한 5NF 집착 지양 및 4NF 실무 통제] 학술적인 5NF(조인 종속)는 실무 발견 빈도가 극히 낮으나, 4NF 위반은 '이력 테이블'이나 '태그 테이블' 설계 시 다대다 속성을 한 행에 우겨넣는 형태로 빈번히 발생 → 나라면: 엔터티 내에 1:N 관계의 복합 속성이 2개 이상 식별될 경우 교차 엔터티로 즉시 분리하도록 모델링 표준 수립
