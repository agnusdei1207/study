## 답안 골격
```text
[이항분포] ◀━━ 머리: Ⅶ 내 의견 (베르누이 독립 시행 기반 A/B 테스트 전환율 검정과 $n$ 증가 시 정규근사 활용)
 ┃
 ┣━ Ⅰ 개요 ───── 성공 확률이 $p$인 독립적인 베르누이 시행을 $n$회 반복했을 때 나타나는 성공 횟수 $X$의 확률분포
 ┣━ Ⅱ 특징 ───── 베르누이 시행 독립 반복 · 모수 $n$(시행 횟수)과 $p$(성공 확률) · 기댓값 $E(X)=np$ / 분산 $Var(X)=np(1-p)$
 ┣━ Ⅲ 구조 ───── 확률질량함수 $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$ / 조합(Combination) 계수 / 이항계수 대칭성
 ┣━ Ⅳ 흐름 ───── ① 단일 베르누이 시행 정의 → ② 독립 복원 시행 $n$회 수행 → ③ 성공 횟수 $k$ 집계 → ④ 조건 만족 시 포아송/정규분포 근사
 ┣━ Ⅴ 비교 ───── 이항분포 vs 포아송 분포 (고정된 시행 횟수 $n$과 성공 확률 $p$ vs 단위 시간/공간당 발생률 $\lambda$)
 ┗━ Ⅵ 실무 ───── 시행 간 상호 독립성(i.i.d.) 위배 시 모델 왜곡 / 대규모 $n$에서 팩토리얼 계산 오버플로우
```
- 필수 키워드: 베르누이 시행 · 독립 시행 · 성공 횟수($k$) · 시행 횟수($n$) · 성공 확률($p$) · $np$ 및 $np(1-p)$ · 포아송 근사 · 드무아브르-라플라스 정리
- 배점 전략: 10점 = Ⅰ → Ⅲ PMF 수식 및 기댓값/분산 도식 → Ⅴ 이항분포 vs 포아송 비교표 / 25점 = Ⅰ~Ⅶ, Ⅳ 정규분포 근사($np \ge 5$) 및 Ⅵ A/B 테스트 응용
- 기출: 135회 4교시 3번 `이항 분포(Binomial Distribution) 와 포아송 분포(Poisson Distribution) 를 비교 설명하시오` → Ⅰ 개념 + Ⅲ 수식/특징 + Ⅴ 상세 비교표

## 한 줄 본질
- 성공/실패 두 가지 결과만 존재하는 독립 사건의 반복 관측 → 고정된 $n$회 시행 중 성공 횟수의 조합 확률 수식화 → 품질 합격률 판정 및 전환율 검증 / $n$ 고정 전제 필수

## 핵심 그림
```text
[이항분포 B(n, p)의 수식 구조 및 확률분포 형태]

 [확률질량함수(PMF) 수식]
                n!
   P(X = k) = ──────── * p^k * (1 - p)^(n - k)    (k = 0, 1, ..., n)
              k!(n - k)!
   * 기댓값: E(X) = np
   * 분산:   Var(X) = np(1 - p) = npq

 [성공 확률 p에 따른 분포 형태]
  확률 P(X=k)
   ^
   │  * (p = 0.2: 오른쪽 꼬리가 긴 비대칭)
   │  │\
   │  │ \      * (p = 0.5: 완전한 좌우 대칭)
   │  │  \    / \
   │  │   \  /   \
 ──┼──┴────┴/─────\────┴────────> 성공 횟수 (k)
   0        np=2  np=5         n=10
```

## 핵심 용어
- 드무아브르-라플라스 정리(De Moivre-Laplace Theorem): 시행 횟수 $n$이 충분히 크고 $np \ge 5, n(1-p) \ge 5$를 만족하면, 이항분포 $B(n, p)$는 정규분포 $N(np, np(1-p))$로 완벽히 근사된다는 정리
- 베르누이 시행(Bernoulli Trial): 매 시행마다 결과가 성공(1) 또는 실패(0) 오직 두 가지만 나오며, 각 시행이 상호 독립적인 확률 실험

## 핵심 통찰
- 이항분포는 '모든 표본추출과 A/B 테스트의 모태'임 → 사용자가 버튼을 클릭했는가(1), 안 했는가(0)의 웹 전환율 검정은 본질적으로 $B(n, p)$ 분포의 모비율 검정
- 분산 $np(1-p)$는 $p = 0.5$일 때 최대가 됨 → 성공과 실패 확률이 반반일 때 결과의 불확실성(엔트로피)이 가장 높음
- $n$이 매우 커지고 $p$가 매우 작으면 팩토리얼 계산이 불가능해짐 → 이때 $\lambda = np$로 치환하여 '포아송 분포'로 근사 계산하는 것이 수치 해석의 핵심 테크닉

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 음이항분포(Negative Binomial) | 성공 횟수가 아닌 실패 횟수 관점 | $r$번째 성공이 나올 때까지 겪어야 하는 실패 횟수의 확률분포 |
| 초기하분포(Hypergeometric) | 비복원추출 환경의 이항분포 | 유한 모집단에서 비복원으로 뽑아 각 시행의 성공 확률이 달라질 때의 성공 횟수 분포 |

## 이웃 토픽과 구분
- 이항분포 vs 기하분포: 이항분포 = $n$번 시행 중 성공한 '횟수' / 기하분포 = 첫 번째 성공이 나올 때까지 걸린 '시행 횟수'

## 내 의견
- [A/B 테스트 표본 크기 산정의 과학화] 실무에서 이항분포 기반 전환율 검정 시 표본이 몇 명 필요한지도 모르고 무작정 테스트를 시작했다가 통계적 검정력 부족으로 결론을 못 내리는 사례 다수 → 나라면: 이항분포 분산 공식을 이용해 최소 검출 가능 효과(MDE)와 유의수준($\alpha=0.05$), 검정력($1-\beta=0.8$)을 만족하는 사전 표본 크기 계산기를 A/B 플랫폼에 필수 연동

## 찾아볼 것
- 이항분포의 연속성 수정(Continuity Correction) 기법이 이산 변수를 정규분포로 근사할 때 오차를 줄이는 원리
