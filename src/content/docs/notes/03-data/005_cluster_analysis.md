## 답안 골격
```text
[군집분석] ◀━━ 머리: Ⅶ 내 의견 (단일 거리 지표 탈피 → 실루엣 검증 + 비선형 밀도 기반 하이브리드 군집화)
 ┃
 ┣━ Ⅰ 개요 ───── 라벨 없는 데이터(비지도 학습) → 유사도 기반 그룹화로 숨겨진 패턴 및 세그먼트 도출
 ┣━ Ⅱ 특징 ───── 비지도 학습(Unsupervised) · 거리/유사도 척도 의존 · 최적 군집 수(k) 결정 필요
 ┣━ Ⅲ 구조 ───── 계층적(병합/분할) / 비계층적(분할: K-Means) / 밀도기반(DBSCAN) / 인공신경망(SOM)
 ┣━ Ⅳ 흐름 ───── ① 데이터 전처리·정규화 → ② 거리 척도 정의 → ③ 군집 알고리즘 적용 → ④ 군집 타당성 평가
 ┣━ Ⅴ 비교 ───── K-Means vs DBSCAN vs 계층적 군집화 (구형 vs 임의 형상 vs 덴드로그램)
 ┗━ Ⅵ 실무 ───── 최적 군집 수 결정 곤란 / 이상치 민감도 / 고차원 거리 소실(차원의 저주)
```
- 필수 키워드: 비지도학습 · 거리 척도(유클리디안·맨해튼) · K-Means · DBSCAN · SOM · 실루엣 계수
- 배점 전략: 10점 = Ⅰ → Ⅲ 4대 유형 분류 체계 → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅲ 유형 분류 및 Ⅴ 알고리즘 비교표
- 기출: 134회 `군집분석기법 SOM` → Ⅲ SOM 원리 / 129회 `K-Means와 DBSCAN 비교` → Ⅴ K-Means vs DBSCAN

## 한 줄 본질
- 사전 정답(레이블)이 없는 고차원 데이터 공간 → 개체 간 거리·밀도 유사성을 측정하여 군집 간 이질성 최대화 및 군집 내 동질성 극대화 → 고객 세분화 및 이상 탐지 / 최적 군집 수와 거리 척도 주관성 존재

## 핵심 그림
```text
[군집분석 기법 분류 체계]
               군집분석 (Clustering)
              /                     \
       [계층적 방식]            [비계층적 방식]
       - 덴드로그램              - 분할 기반: K-Means, K-Medoids
       - 병합형(단일/완전/와드)  - 밀도 기반: DBSCAN, OPTICS
       - 분할형(DIANA)          - 격자/신경망: SOM, GMM
```

## 핵심 용어
- 실루엣 계수(Silhouette Coefficient): 군집 내 응집도(a)와 가장 가까운 타 군집 간 분리도(b)를 계산하여 군집화 품질을 -1 ~ 1 사이로 평가하는 지표
- SOM(Self-Organizing Map): 고차원 데이터를 위상학적 관계를 보존하면서 2차원 격자 신경망으로 매핑하는 비지도 인공신경망 군집화 기법

## 핵심 통찰
- 거리 척도는 데이터 스케일에 극도로 취약 → 표준화(Standardization) 없이 키(cm)와 몸무게(kg)를 넣으면 분산이 큰 변수가 군집 전체를 지배
- K-Means는 볼록한 구형(Spherical) 군집만 찾음 → 초승달 모양이나 도넛 모양처럼 비선형 밀도 분포를 가진 데이터는 DBSCAN이나 Spectral Clustering을 써야 함
- 군집 수(k)를 늘릴수록 군집 내 오차제곱합(SSE)은 계속 감소 → 엘보우 기법(Elbow Method)과 실루엣 점수를 결합해 타당성 교차 검증 필요

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 엘보우 기법(Elbow Method) | 군집 수(k) 결정 기준 | SSE 감소율이 완만해지는 변곡점을 최적 k로 채택 |
| 덴드로그램(Dendrogram) | 계층적 군집화 시각화 | 개체 간 병합 과정을 트리 다이어그램으로 표현하여 군집 계층 파악 |

## 이웃 토픽과 구분
- 군집화(Clustering) vs 분류(Classification): 군집화 = 정답(Y) 없이 데이터의 내재적 구조를 탐색하는 비지도학습 / 분류 = 정답(Y) 레이블을 맞히도록 모델을 학습시키는 지도학습

## 문제·원인·대책
- 적용 상황: 이커머스 고객 행동 로그 기반 타겟 마케팅 세그멘테이션
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 비정상 구매자(이상치)로 인해 전체 K-Means 중심점 왜곡 | K-Means의 유클리디안 거리 평균 기반 중심 갱신 취약점 | 중앙값 기반 K-Medoids 적용 또는 DBSCAN 노이즈 사전 필터링 | 이상치에 강건한 중심점 유지 |
| 변수가 50개 이상일 때 모든 고객 간 거리가 균일화 | 고차원 공간에서의 '차원의 저주(Curse of Dimensionality)' | PCA 또는 t-SNE로 주성분 5~10개 차원 축소 후 군집화 | 의미 있는 거리 변별력 복원 |
