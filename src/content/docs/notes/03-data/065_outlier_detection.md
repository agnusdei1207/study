 ┣━ Ⅱ 특징 ───── 데이터 품질 저하 원인 vs 신규 인사이트(사기·침해) 원천 · 다차원성 · 도메인 의존성 · 불균형성

## 한 줄 본질
- 수집 오류 노이즈 또는 극희귀 사건 발생 → 통계적 분포 및 공간 밀도·트리 고립도를 기반으로 정상 집단과의 괴리도 수치화 → 통계 분석 왜곡 방지 및 침해 탐지 / 도메인 의미 판별 필요

  *  *  ───[───]──────────┼─────────┼──────────┼──────────[───]─── *  *

  ├───────────────┼───────────────────────────────────────────┤
  │ 밀도 기반     │ LOF (주변 이웃 밀도 대비 자신의 밀도 비율)│

## 핵심 용어
- LOF(Local Outlier Factor): 어떤 관측치가 속한 국소적(Local) 영역의 밀도를 주변 $k$개 이웃의 밀도와 비교하여 고립 정도를 상대적으로 수치화한 지표
- 마할라노비스 거리(Mahalanobis Distance): 변수 간의 상관관계(공분산)를 고려하여 데이터 중심으로부터의 통계적 거리를 측정하는 다변량 이상치 탐지 척도

## 핵심 통찰
- 이상치는 단순 '제거해야 할 오류(Garbage)'일 수도 있지만, 비즈니스 관점에서는 '가장 가치 있는 신호(Gold)'일 수 있음 (예: FDS 사기 거래, 신종 해킹, 설비 고장 징후)
- 1차원 통계(Z-score, IQR)는 각 변수별로는 정상 범위이지만 두 변수의 상관관계를 볼 때 명백한 이상치인 경우(예: 신장 180cm에 체중 30kg)를 잡아내지 못하므로 다변량 기법 필수
- 이상치 처리(Imputation) 시 단순 평균 대체는 데이터의 분산을 인위적으로 축소시키므로, 윈저라이징(상하한 대체)이나 머신러닝 예측 기반 대체를 권장

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 윈저라이징(Winsorizing) | 이상치 처리 및 정제 | 이상치를 삭제하지 않고 미리 정의한 백분위수(상위 99%, 하위 1%) 값으로 치환하여 분산 보존 |
| One-Class SVM | 초평면 기반 단일 클래스 분류 | 정상 데이터만을 감싸는 최소 부피의 초구(Hypersphere)를 형성하고 경계 밖의 샘플을 이상치로 판정 |

## 이웃 토픽과 구분
- 이상치(Outlier) vs 노이즈(Noise): 노이즈 = 측정 장비의 한계 등으로 데이터에 무작위로 섞여 들어간 쓸모없는 무의미한 오차 / 이상치 = 통계적 분포에서 벗어난 관측치로 실제 발생한 의미 있는 사건일 수 있음

## 문제·원인·대책
- 적용 상황: 신용카드 이상 거래 탐지(FDS) 모델 개발
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 고객의 해외 직구 고액 결제가 이상치로 오탐되어 카드 자동 정지 민원 폭발 | 1차원 결제 금액 기준으로만 이상치 판단 | 결제 시간, 평소 사용처, IP 대역을 결합한 다변량 Isolation Forest 적용 | 정상 거래 오탐 차단율 85% 감축 |
| 머신러닝 회귀 모델의 기울기가 몇 개의 극단값으로 인해 심하게 왜곡 | 최소제곱법(OLS)이 잔차의 제곱을 최소화하므로 극단치에 극도로 민감 | 후버 손실(Huber Loss) 또는 RANSAC 로버스트 회귀 알고리즘 적용 | 이상치 영향 배제 및 모델 강건성 확보 |

## 이렇게 출제된다
- 제139회 3교시 2번: "데이터분석에서 이상치(Outlier)와 편향(Bias)의 개념을 설명하고, 분석결과에 미치는 영향 및 처리 방안을 설명하시오." → 요구 포인트: 이상치 정의 + 3대 영향(통계 왜곡, 모델 편향) + 탐지 기법 및 처리 4대 방안(삭제, 치환, 캡핑, 모델 수용)

## 내 의견
- [맹목적 이상치 삭제의 위험성] 통계 전처리 시 IQR 1.5 범위를 벗어난다고 무조건 삭제해 버려 극희귀 VIP 고객의 구매 패턴을 시스템에서 지워버리는 오류 빈번 → 나라면: 삭제 전 반드시 도메인 규칙 기반의 화이트리스트 검증을 거치고, 이상치 플래그(Flag) 컬럼을 별도 생성하여 원본 데이터의 가역성을 보존
