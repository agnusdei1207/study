## 답안 골격
```text
[불편추정량] ◀━━ 머리: Ⅶ 내 의견 (단순 불편성 집착 지양 → MSE 최소화를 위한 편향-분산 절충(Bias-Variance Trade-off) 고려)
 ┃
 ┣━ Ⅰ 개요 ───── 표본을 통해 모수를 추정할 때 체계적 편향이 없음 → 추정량의 기댓값이 참 모수와 일치하는 성질
 ┣━ Ⅱ 특징 ───── $E(\hat{\theta}) = \theta$ · 편향(Bias) = 0 · 좋은 추정량의 4대 조건 중 하나
 ┣━ Ⅲ 구조 ───── 좋은 추정량 조건: 불편성(Unbiasedness) / 효율성(Efficiency) / 일치성(Consistency) / 충분성(Sufficiency)
 ┣━ Ⅳ 흐름 ───── ① 표본 추출 → ② 추정량 수식 정의 → ③ 기댓값 계산($E[\hat{\theta}]$) → ④ 모수 $\theta$와 일치 여부 증명
 ┣━ Ⅴ 비교 ───── 표본분산 분모 $n$ (편향 추정량) vs $n-1$ (불편분산 추정량)
 ┗━ Ⅵ 실무 ───── 소표본에서 분산 과소추정 위험 / 머신러닝 규제 모델과의 편향-분산 상충
```
- 필수 키워드: 불편성($E(\hat{\theta})=\theta$) · 편향(Bias) · 효율성 · 일치성 · 표본분산($n-1$) · 자유도(Degree of Freedom)
- 배점 전략: 10점 = Ⅰ → Ⅲ 4대 추정량 조건 + Ⅴ 표본분산 $n-1$ 증명 → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅲ 조건 및 $n-1$ 자유도 개념
- 기출: 135회 `불편추정량` → Ⅰ 개념 + Ⅲ 성질 및 $n-1$ 이유 / 132회 `점추정과 구간추정 비교` → 점추정의 타당성 기준 / 127회 `추정통계의 표본과 불편 추정량` → Ⅰ 정의 + Ⅴ 대표 예시

## 한 줄 본질
- 표본 통계량의 기댓값이 참 모수와 정확히 일치하여 체계적인 오차(편향)가 발생하지 않는 추정량 → 표본으로 모집단의 특성을 왜곡 없이 객관적으로 추론 가능 / 분산이 커질 수 있어 MSE 최소화와 절충 필요

## 핵심 그림
```text
[불편추정량의 개념과 조건]
        E(θ̂) = θ   (편향 Bias = E(θ̂) - θ = 0)

  ┌────────────────────────────────────────────────────────┐
  │              바람직한 통계적 추정량의 4대 조건         │
  ├──────────────┬──────────────┬──────────────┬───────────┤
  │ 불편성       │ 효율성       │ 일치성       │ 충분성    │
  │ (Unbiased)   │ (Efficient)  │ (Consistent) │(Sufficient│
  │ E(θ̂) = θ     │ Var(θ̂) 최소  │ n→∞ 이면     │ 모수의    │
  │ (편향 없음)  │ (최소분산)   │ θ̂ → θ        │ 정보 보존 │
  └──────────────┴──────────────┴──────────────┴───────────┘
```

## 핵심 용어
- 표본분산의 $n-1$: 표본평균($\bar{X}$)이 이미 모평균($\mu$) 대신 쓰여 1개의 자유도가 상실되었으므로, $n$ 대신 $n-1$로 나누어야 기댓값이 참 모분산($\sigma^2$)과 일치함
- 최소분산 불편추정량(MVUE): 모든 불편추정량들 중에서 분산이 가장 작아 가장 정밀한 최우수 추정량

## 핵심 통찰
- 표본평균은 $n$으로 나누어도 불편추정량이지만 표본분산은 $n$으로 나누면 과소추정됨 → 편차를 계산할 때 모평균 대신 표본평균을 사용하므로 편차제곱합이 모평균 기준보다 항상 작아지기 때문
- 불편성이 항상 '최고'의 추정량을 의미하지는 않음 → 편향이 약간 있더라도 분산을 대폭 낮추어 전체 평균제곱오차(MSE = $Bias^2 + Variance$)를 줄이는 릿지(Ridge) 회귀가 머신러닝에서 더 우수한 성능을 냄
- 표본 크기 $n$이 수만 건 이상인 빅데이터 환경에서는 $n$과 $n-1$의 차이가 사실상 소멸함 → 소표본(A/B 테스트 등 $n<30$) 가설검정에서 자유도와 불편성의 수학적 엄밀성이 결정적 차이를 유발

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 크라메르-라오 하한(CRLB) | 효율성 한계선 | 어떤 불편추정량도 피셔 정보량(Fisher Information)의 역수보다 분산이 작을 수 없음 |
| 점추정 vs 구간추정 | 모수 추정의 두 축 | 단일 수치로 모수를 찍는 점추정과 신뢰구간으로 범위를 제시하는 구간추정 |

## 이웃 토픽과 구분
- 불편성 vs 일치성: 불편성 = 표본 크기 $n$과 상관없이 기댓값이 모수와 같은 성질 / 일치성 = 표본 크기 $n$이 무한대로 커질 때 추정량이 모수에 확률적으로 수렴하는 성질
