## 답안 골격
```text
[시계열 실시간 이상치 탐지] ◀━━ 머리: Ⅶ 내 의견 (슬라이딩 윈도우 기반 스트리밍 통계 + 격리 포레스트(iForest) 결합)
 ┃
 ┣━ Ⅰ 개요 ───── 끊임없이 유입되는 스트리밍 시계열 데이터에서 정상 패턴을 벗어난 이상 징후를 저지연(Low Latency)으로 탐지
 ┣━ Ⅱ 특징 ───── 스트리밍 실시간성 · 시차적 의존성 반영 · 동적 임계값(Dynamic Threshold) · 계절성/추세 분리
 ┣━ Ⅲ 구조 ───── 스트림 수집(Kafka) / 윈도우 연산 엔진(Flink) / 탐지 모델(Z-Score, EWMA, Isolation Forest, LSTM-AE) / 알림 파이프라인
 ┣━ Ⅳ 흐름 ───── ① 스트림 이벤트 유입 → ② 슬라이딩 윈도우 집계 → ③ 정상 분포/예측값 대비 잔차 계산 → ④ 동적 임계값 초과 시 경보 발생
 ┣━ Ⅴ 비교 ───── 통계적 기법(EWMA/3-Sigma) vs 머신러닝/딥러닝(AutoEncoder/iForest) (초경량·해석 용이 vs 비선형 복합 패턴 탐지)
 ┗━ Ⅵ 실무 ───── 계절성 변동(출퇴근 트래픽)을 이상치로 오탐 / 개념 드리프트(Concept Drift)로 인한 모델 성능 저하
```
- 필수 키워드: 슬라이딩 윈도우 · 동적 임계값 · EWMA · 격리 포레스트(Isolation Forest) · 오토인코더(AutoEncoder) · 개념 드리프트 · 저지연
- 배점 전략: 10점 = Ⅰ → Ⅲ 실시간 스트림 파이프라인 도식 → Ⅴ 통계 vs ML 비교표 / 25점 = Ⅰ~Ⅶ, Ⅳ 동적 임계값 갱신 알고리즘 및 산업별(IoT/금융) 사례
- 기출: 140회 4교시 4번 `시계열 데이터에서 실시간 이상치 탐지` → Ⅰ 개념 + Ⅲ 아키텍처 + Ⅳ 탐지 기법 및 산업 적용

## 한 줄 본질
- 정적 배치 분석의 사후 인지 지연 한계 → 슬라이딩 윈도우 기반 통계치 연속 갱신 및 재구성 오차(Reconstruction Error) 실시간 평가 → 침해·고장 징후 즉시 차단 / 정상 분포 변화 시 오탐 발생

## 핵심 그림
```text
[시계열 실시간 이상치 탐지 파이프라인 및 동적 임계선]

 [스트림 유입] ──> [슬라이딩 윈도우] ──> [잔차/이상 점수 산출] ──> [경보/격리]
 (Sensor, Log)     (Flink / Spark)       (EWMA / AutoEncoder)      (PagerDuty)

 [동적 임계값 기반 이상치 판정]
  값
   ^          상한 임계선 (Dynamic Upper Bound = μ + 3σ)
   │        .~~~~~~.                  * (이상치 탐지! Alert!)
   │       /        \                /
   │──────/──────────\───/\─────────/───────> 중심 추세선 (EWMA)
   │     /            \ /  \       /
   │    '              '    '~~~~~'
   │          하한 임계선 (Dynamic Lower Bound = μ - 3σ)
   0────────────────────────────────────────> 시간 (t)
```

## 핵심 용어
- EWMA(Exponentially Weighted Moving Average): 최근 데이터에 더 높은 가중치를 부여하는 지수 이동평균으로, 시계열의 국소적 중심 추세를 실시간 추적
- 재구성 오차(Reconstruction Error): AutoEncoder 모델이 입력 시계열을 압축 후 복원할 때, 정상 패턴과 다른 이상치가 유입되면 복원 오차가 급증하는 현상을 활용한 탐지 메트릭

## 핵심 통찰
- 실시간 시계열에서 '정적 고정 임계값(Static Threshold)'은 반드시 실패함 → 낮에는 트래픽 10,000건이 정상이고 새벽에는 500건이 정상이므로, 계절성을 반영한 '동적 밴드(Band)' 임계선 필수
- 포인트 이상치(단발성 스파이크)와 컨텍스트 이상치(평소와 다른 완만한 고원 형태 유지)를 구분해야 함 → 단발성 네트워크 글리치는 필터링하고 지속적인 비정상 패턴만 에스컬레이션
- 모델 연산 레이턴시가 데이터 인입 주기보다 길면 버퍼 오버플로우 발생 → 실시간 계층에는 가벼운 통계/트리 기법을 두고, 심층 신경망은 비동기 2선 검증으로 분리해야 함

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| Isolation Forest | 트리 기반 비지도 이상치 탐지 | 정상 데이터보다 이상치가 적은 횟수의 무작위 분할만으로 고립(Isolation)된다는 원리 |
| 콘셉트 드리프트(Concept Drift) | 실시간 환경의 환경 변화 | 시간이 지남에 따라 정상 데이터의 통계적 분포가 바뀌어 탐지 모델의 정확도가 떨어지는 현상 |

## 이웃 토픽과 구분
- 시계열 이상치 탐지 vs 일반 이상치 탐지: 일반 이상치 = 독립된 다차원 데이터 포인트의 거리/밀도 분석 / 시계열 이상치 = 데이터의 '시간적 순서'와 '자기상관성' 및 '계절 추세'를 반드시 고려

## 문제·원인·대책
- 적용 상황: 스마트 팩토리 사출 성형 설비 진동 센서 실시간 모니터링
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 일일 수천 건의 가짜 알람(FP)으로 관제팀의 알람 피로(Alert Fatigue) 유발 | 단발성 노이즈 스파이크에 대해 즉각 알람 발송 | $N$회 연속 윈도우 임계값 초과 시에만 알람 발송(Persistence Check) | 오탐 알람 90% 감소 |
| 공장 설비 노후화로 정상 진동 기준이 서서히 변했으나 모델이 인지 못함 | 정적 학습 모델 방치로 인한 콘셉트 드리프트 | 스트리밍 데이터 기반 온라인 증분 학습(Online Learning) 파이프라인 적용 | 설비 베이스라인 자동 추종 |

## 이렇게 출제된다
- 제140회 4교시 4번: "시계열 데이터에서 실시간 이상치 탐지는 여러 산업분야에서 중요성이 증가하고 있다. 다음을 설명하시오." → 요구 포인트: 실시간 이상치 탐지 개념 + 주요 탐지 알고리즘(통계/ML/DL) + 동적 임계값 원리 및 산업별 활용

## 내 의견
- [단일 알고리즘 맹신 지양 및 계층적 필터링] 무거운 딥러닝(LSTM/Transformer) 모델만으로 초당 수만 건의 센서 데이터를 실시간 전수 검사하려다 GPU 인프라 비용 폭증 및 지연 발생 → 나라면: 1차 엣지단에서 경량 3-Sigma/EWMA로 99%의 정상 데이터를 거르고, 의심 구간 1%만 중앙 서버의 AutoEncoder로 정밀 분석하는 2단계 계층형 아키텍처 채택

## 찾아볼 것
- 스트리밍 데이터 대상의 실시간 트리 갱신 기법인 Half-Space Trees(HSTrees) 및 RRCF(Robust Random Cut Forest)
