## 답안 골격
```text
[K-Means] ◀━━ 머리: Ⅶ 내 의견 (초기값 민감도 극복(K-Means++) + 엘보우·실루엣 복합 검증으로 최적 k 산정)
 ┃
 ┣━ Ⅰ 개요 ───── 사전 레이블 없는 데이터셋 → 중심점(Centroid) 기반으로 $k$개 군집에 반복 할당하는 대표적 비지도 학습
 ┣━ Ⅱ 특징 ───── 빠른 계산 속도($O(nkt)$) · 구형(Spherical) 군집 가정 · 초기 중심점 민감 · 이상치 취약
 ┣━ Ⅲ 구조 ───── 군집 수($k$) / 중심점(Centroid) / 거리 척도(유클리디안) / 목적함수(SSE, 군집 내 오차제곱합)
 ┣━ Ⅳ 흐름 ───── ① 초기 중심점 $k$개 무작위 선정 → ② 가장 가까운 중심점에 데이터 할당 → ③ 중심점 재계산 → ④ 수렴 시까지 반복
 ┣━ Ⅴ 비교 ───── K-Means vs K-Medoids vs DBSCAN (평균 중심 vs 실제 데이터 중심 vs 밀도 기반)
 ┗━ Ⅵ 실무 ───── 최적 $k$ 결정 주관성 / 이상치로 인한 중심점 왜곡 / 비구형(초승달) 군집 분할 실패
```
- 필수 키워드: K-Means · 중심점(Centroid) · SSE(오차제곱합) · K-Means++ · 엘보우 기법(Elbow Method) · 실루엣 점수
- 배점 전략: 10점 = Ⅰ → Ⅳ 4단계 반복 흐름도 및 SSE 수식 → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅳ 동작 알고리즘 및 Ⅴ DBSCAN과의 비교표
- 기출: 129회 1교시 5번 `K-Means Clustering과 DBSCAN` → Ⅰ 개념 + Ⅲ 구성요소 + Ⅴ DBSCAN 대비 장단점 비교

## 한 줄 본질
- 데이터를 가장 가까운 중심점에 묶고 다시 그 군집의 평균으로 중심을 이동시키는 과정을 반복(EM 알고리즘) → 군집 내 오차제곱합(SSE)을 최소화 → 대용량 데이터의 빠른 세분화 / 비선형 분포 및 이상치에 취약

## 핵심 그림
```text
[K-Means 알고리즘의 4단계 반복 수렴 과정]

 [1. k개 초기 중심 선택] ──> [2. 최근접 중심에 할당]
  (무작위 또는 K-Means++)      (유클리디안 거리 최소화)
            ▲                             │
            │                             ▼
  [4. 수렴 조건 판정]     <── [3. 중심점 재계산]
  - 중심점 이동 없으면 종료     - 군집 내 데이터 평균으로
  - 변화 있으면 2단계로 이동     새로운 Centroid 갱신
```

## 핵심 용어
- SSE(Sum of Squared Errors): 각 데이터 포인트와 해당 군집 중심점 간의 유클리디안 거리 제곱의 총합으로, K-Means가 최소화하려는 손실 함수
- K-Means++: 초기 중심점들을 무작위로 뽑지 않고, 이미 선택된 중심점들로부터 거리가 먼 데이터일수록 다음 중심점으로 뽑힐 확률을 높여 초기화 오차를 줄인 개선 기법

## 핵심 통찰
- K-Means는 유클리디안 거리를 사용하므로 '구형(Spherical)이고 크기가 비슷한 군집'만 잘 찾음 → 밀도가 서로 다르거나 긴 띠 모양의 데이터셋에서는 엉뚱한 직선으로 군집을 절단함
- 이상치 하나가 전체 중심점을 끌고 감 → 평균(Mean)을 사용하기 때문이며, 극단적인 이상치가 있으면 실제 데이터 포인트를 중심으로 삼는 K-Medoids를 사용해야 함
- $k$를 사용자가 사전에 찍어줘야 함 → 엘보우 그래프에서 꺾이는 지점(변곡점)과 실루엣 계수(0.5 이상 권장)를 교차 분석하여 최적의 $k$를 도출하는 튜닝 파이프라인 필수

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 미니배치 K-Means (Mini-Batch) | 대용량 최적화 | 전체 데이터 대신 무작위 미니배치 샘플만으로 중심점을 갱신해 속도를 수십 배 향상 |
| K-Medoids (PAM) | 이상치 강건 알고리즘 | 가상의 평균점이 아닌 군집 내 실제 중앙 데이터 객체(Medoid)를 중심으로 설정 |

## 이웃 토픽과 구분
- K-Means vs KNN(K-Nearest Neighbors): K-Means = 비지도 군집화(라벨 없음, $k$는 군집 개수) / KNN = 지도 분류(라벨 있음, $k$는 주변 이웃의 개수)

## 문제·원인·대책
- 적용 상황: 수백만 명의 앱 사용자 행동 로그 기반 마케팅 그룹 세분화
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 모델 실행할 때마다 고객 군집 결과가 매번 달라짐 | 무작위 초기 중심점 선정에 따른 로컬 옵티멈(Local Optimum) 갇힘 | K-Means++ 초기화 알고리즘 적용 및 n_init=10 다회 반복 최적해 선택 | 일관되고 안정적인 군집 도출 |
| 결제액 10억 이상의 VIP 고객 때문에 일반 고객 군집이 비정상 왜곡 | 유클리디안 평균 계산의 이상치 민감성 | 극단 이상치 사전 분리(Isolation Forest) 후 K-Means 실행 | 순수 일반 고객 세그먼트 정상화 |
