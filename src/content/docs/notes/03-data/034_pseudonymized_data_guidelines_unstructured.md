## 한 줄 본질
- AI 학습용 이미지·영상·음성 데이터 내에 숨겨진 개인식별정보의 노출 위험 → 비정형 미디어 특성에 맞춘 블러링·음성변조·NER 가명처리 및 위험도 평가 기준 확립 → 안전한 AI 데이터 활용 촉진 / 데이터 유용성과 프라이버시 보호의 상충 극복 필요

## 핵심 그림
```text
[비정형 데이터 4대 미디어별 가명처리 기법]

 [미디어 유형]                 [주요 가명처리 기법]              [AI 유용성 보존]
  텍스트 (Text)    ──>  개체명 인식(NER) 기반 가명대체/마스킹 ──>  문맥(Context) 보존
  이미지 (Image)   ──>  얼굴/차량번호판 블러링, 픽셀화, 인페인팅 ──>  배경 정보 유지
  음성 (Voice)     ──>  음성 변조(Pitch/Formant), 묵음 처리   ──>  발화 텍스트 유지
  영상 (Video)     ──>  객체 추적(Tracking) 기반 연속 모자이크 ──>  동작/행동 패턴 유지
```

## 핵심 용어
- 개체명 인식(NER, Named Entity Recognition): 텍스트 내에서 인명, 지명, 기관명, 주민번호 등 개인 식별 요소를 자동으로 감지하여 분류하는 자연어 처리 기술
- 인페인팅(Inpainting): 이미지나 영상에서 가명처리 대상 객체(얼굴 등)를 지우고 주변 배경 텍스처를 자연스럽게 채워 넣어 데이터 왜곡을 최소화하는 기술

## 핵심 통찰
- 정형 데이터는 특정 컬럼(주민번호, 이름)만 지우면 되지만, 비정형 데이터는 어디에 식별자가 숨어있는지 사전에 알 수 없음 → 영상 속 지나가는 차량 번호판, 간판의 전화번호, 거울에 비친 얼굴까지 탐지해야 함
- 단순 흑색 박스 마스킹은 AI 학습 성능을 파괴함 → 자율주행 AI 학습 시 보행자 얼굴을 까맣게 칠해버리면 인간 객체 자체를 인식하지 못하므로, 가상 얼굴 합성(Deepfake 인페인팅) 기법 적용
- 음성은 발화 내용뿐만 아니라 '음색(화자 특성)' 자체가 생체인식 식별자임 → 텍스트로 변환(STT) 후 원본 음성을 파기하거나 포먼트(Formant) 변조를 거쳐야 안전함

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 프라이버시 모델 (k-익명성 등) | 정형 대비 비정형 적용 한계 | 비정형 데이터는 고차원성과 맥락성으로 인해 k-익명성 산식이 직접 성립하기 어려움 |
| 합성 데이터 (Synthetic Data) | 비정형 가명처리 대안 | 실제 개인정보를 처리하는 대신 생성 AI(GAN/Diffusion)로 가상의 영상·텍스트 생성 |

## 이웃 토픽과 구분
- 비정형 가명처리 vs 익명처리: 가명처리 = 추가 정보 없이는 식별할 수 없으나 통제된 환경에서 AI 학습에 활용 가능 / 익명처리 = 시간·비용·기술을 고려해도 영구히 식별 불가능한 상태(개인정보보호법 적용 제외)

## 문제·원인·대책
- 적용 상황: 의료 병원 전산망의 흉부 X-ray 및 CT 영상 AI 학습데이터 외부 개방
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 의료 영상 코너에 환자 이름/등록번호가 텍스트로 각인되어 유출 | 의료 장비(DICOM) 영상 자체에 메타데이터 번인(Burn-in) | OCR 및 객체 탐지 모델로 메타데이터 영역 자동 탐지 후 완전 제거 | 환자 개인정보 노출 원천 차단 |
| CCTV 방범 영상에서 보행자 얼굴 마스킹 시 동작 인식 AI 학습 불가 | 단순 모자이크로 인한 인체 골격 및 시선 방향 훼손 | 얼굴 영역에 한해 가상 생성 얼굴(Face Swapping)로 치환 | AI 행동 분석 유용성 95% 이상 보존 |
