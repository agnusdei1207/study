## 답안 골격
```text
[중심극한정리] ◀━━ 머리: Ⅶ 내 의견 (정규분포 맹신 지양 → 비대칭 극단값(Fat-tail) 도메인에서는 붓스트랩(Bootstrap) 병행 검증)
 ┃
 ┣━ Ⅰ 개요 ───── 모집단의 원래 분포와 무관하게 → 표본 크기($n$)가 커지면 표본평균의 분포는 정규분포에 근사
 ┣━ Ⅱ 특징 ───── 모집단 비정규성 극복 · 분산 축소($\sigma^2/n$) · 통계적 추론(가설검정·신뢰구간)의 수학적 초석
 ┣━ Ⅲ 구조 ───── 수학적 정의: $\bar{X}_n \sim N(\mu, \frac{\sigma^2}{n})$ / 표준화: $Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1)$
 ┣━ Ⅳ 흐름 ───── ① 임의 모집단($\mu, \sigma^2$) → ② 크기 $n$ 표본 반복 추출 → ③ 표본평균들 계산 → ④ 정규분포 종 모양 수렴
 ┣━ Ⅴ 비교 ───── 대수의 법칙(LLN) vs 중심극한정리(CLT) (상수 $\mu$로 수렴 vs 정규'분포' 형태로 수렴)
 ┗━ Ⅵ 실무 ───── 꼬리가 두꺼운 멱법칙 분포(Fat-tail) 위배 / 표본 크기 $n \ge 30$ 맹신 / 극단치 오차
```
- 필수 키워드: CLT · 표본평균 분포 · 정규분포 근사 · 대수의 법칙(LLN) · 표준오차($\sigma/\sqrt{n}$) · $n \ge 30$
- 배점 전략: 10점 = Ⅰ → Ⅲ 수식 및 분포 수렴 과정 도식 → Ⅵ 한 행 / 25점 = Ⅰ~Ⅶ, 앞 1/3에 Ⅲ 수식 도식 및 Ⅴ LLN vs CLT 비교표
- 기출: 139회 `대수의 법칙과 중심극한정리` → Ⅴ 두 정리 완결 비교 / 132회 `중심극한정리, t-검정, z-검정` → Ⅰ 원리 및 추론 통계의 기초

## 한 줄 본질
- 원래 데이터가 어떤 기괴한 분포(균일, 지수, 이항)를 갖더라도 → 표본평균들을 모아놓으면 평균이 $\mu$이고 분산이 $\sigma^2/n$인 정규분포를 형성 → 현실의 수많은 미지의 모집단에 대해 모수 추정과 검정 가능

## 핵심 그림
```text
[모집단 분포와 표본평균 분포의 수렴 과정]

 [임의의 모집단 분포]         [표본 크기 n=2]           [표본 크기 n >= 30]
 (예: 균일분포, 비대칭)     (삼각형 모양 시작)         (완벽한 정규분포 종 모양)
   ┌─────────────┐               /\                         /\
   │             │              /  \                       /  \
   │             │             /    \                     /    \
   └─────────────┘            /      \                   /      \
      모평균 μ                     모평균 μ                    모평균 μ (분산 σ²/n)
```

## 핵심 용어
- 표준오차(Standard Error, $SE$): 표본평균들의 표준편차로, $\frac{\sigma}{\sqrt{n}}$으로 계산되며 표본 크기 $n$이 커질수록 0에 수렴하여 추정의 정밀도 향상
- 대수의 법칙(Law of Large Numbers): 표본 크기가 커질수록 표본평균이 모평균이라는 '하나의 상수값'에 확률적으로 수렴한다는 정리

## 핵심 통찰
- '데이터 자체'가 정규분포가 되는 것이 아님 → 중심극한정리가 보장하는 것은 데이터 개별 값이 아니라 '표본평균($\bar{X}$)의 분포'가 정규분포가 된다는 사실
- 분산이 무한대인 분포(코시 분포, 파레토 분포)에서는 성립하지 않음 → 금융 시장의 블랙 스완처럼 극단적인 Fat-tail을 갖는 도메인에 CLT를 맹신하여 정규분포 모델을 씌우면 리스크 관리 파산
- 표본 크기 $n$을 4배 늘려야 표준오차(오차 범위)는 절반($1/\sqrt{4} = 1/2$)으로 줄어듦 → 데이터 수집 비용과 추정 정밀도 간의 제곱근 수렴 한계 존재

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| 린데베르그-레비 정리 | CLT의 수학적 정식화 | 독립항등분포(i.i.d)를 따르고 유한한 분산을 가질 때 성립함을 증명 |
| 표본오차의 한계 | 통계적 비용 최적화 | $n$ 증가에 따른 오차 감소 효율이 체감하므로 적정 표본 크기 산정이 필수 |

## 이웃 토픽과 구분
- 중심극한정리(CLT) vs 대수의 법칙(LLN): LLN = "표본평균이 모평균에 점점 가까워진다(점수렴)" / CLT = "표본평균의 흩어짐 모양이 정규분포가 된다(분포수렴)"
