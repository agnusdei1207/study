## 핵심 용어
- CRISP-DM(Cross-Industry Standard Process for Data Mining): 비즈니스 목표 수립부터 배포까지 6단계 반복 순환 표준 방법론
- 지지도·신뢰도·향상도: 연관규칙 마이닝에서 항목 간 동시 발생 강도와 인과성을 정량 측정하는 3대 핵심 지표

## 핵심 통찰
- 데이터마이닝은 가설을 검증하는 도구가 아니라 가설을 발견하는 도구임 → 사전 가설이 필요 없는 장점이 있으나, 우연한 거짓 상관관계를 진짜 법칙으로 오인할 위험 상존
- 모델링 자체보다 전체 일정의 80%를 차지하는 데이터 준비(결측치, 스케일링, 인코딩)가 모델 성패를 좌우
- 분석 결과를 설명할 수 없는 블랙박스 모델은 현업의 실제 채택을 방해하므로 XAI(설명 가능한 AI) 결합 필수

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| KDD(Knowledge Discovery in Databases) | 데이터마이닝의 학술적 방법론 | 선택, 전처리, 변환, 마이닝, 해석/평가 5단계 지식 발견 프로세스 |
| 특징 공학(Feature Engineering) | 데이터 준비 및 모델링의 가교 | 도메인 지식을 활용해 원시 데이터에서 모델 학습 효율을 높이는 파생 변수 생성 |

## 이웃 토픽과 구분
- 데이터마이닝 vs OLAP: 데이터마이닝 = 알고리즘 기반 미지의 패턴 자동 발굴(발견형) / OLAP = 사용자가 직접 다차원 축을 회전·드릴다운하며 검증(가설형)

## 문제·원인·대책
- 적용 상황: 금융 고객 이탈 예측 및 마케팅 타깃팅
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 실제 이탈 고객을 전혀 잡아내지 못하는 모델 배포 | 전체 고객 중 이탈 비율이 1%에 불과한 클래스 불균형 | SMOTE 오버샘플링 및 Cost-Sensitive 학습 적용 | 이탈 고객 탐지 재현율 75%로 개선 |
| 과거 데이터 기반의 마이닝 패턴이 6개월 후 급격히 성능 저하 | 경제 상황 및 유행 변화로 인한 데이터 드리프트(Concept Drift) | 실시간 통계 모니터링 및 주기적 자동 재학습 파이프라인 구축 | 모델 성능 지속 유지 |
