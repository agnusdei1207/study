## 답안 골격
```text
[잭나이프·부트스트랩] ◀━━ 머리: Ⅶ 내 의견 (통계량의 연속성 여부와 표본 크기에 따른 상호보완적 리샘플링 선택)
 ┃
 ┣━ Ⅰ 개요 ───── 모집단의 이론적 확률분포 가정 없이 표본 데이터의 재표본화(Resampling)를 통해 편향과 신뢰구간을 추정하는 양대 통계 기법
 ┣━ Ⅱ 특징 ───── 비모수적 접근 · 경험적 분포 함수(EDF) 기반 · 정규성 가정 탈피 · 결정론(잭나이프) vs 확률론(부트스트랩)
 ┣━ Ⅲ 구조 ───── 잭나이프: Leave-One-Out / $n$개 고정 표본 / 의사값 | 부트스트랩: 복원추출(With-replacement) / $B$개 가상 표본 / 경험적 백분위수
 ┣━ Ⅳ 흐름 ───── 잭나이프: 1개 제외 → $n$회 반복 → 편향 보정 / 부트스트랩: 크기 $n$ 복원추출 → $B$회(1,000회 이상) 반복 → 경험적 분포 구축
 ┣━ Ⅴ 비교 ───── 잭나이프 vs 부트스트랩 (비복원 1개 제외/결정론적/$n$회 vs 복원추출/몬테카를로 난수/$B$회/비평활 통계량 적용 가능)
 ┗━ Ⅵ 실무 ───── 잭나이프의 중앙값 추정 파탄 / 대용량 데이터에서 부트스트랩 반복 시 연산 비용 급증
```
- 필수 키워드: 리샘플링(Resampling) · 잭나이프(Jackknife) · 부트스트랩(Bootstrap) · Leave-One-Out · 복원추출 · 편향 보정 · 신뢰구간(Confidence Interval)
- 배점 전략: 10점 = Ⅰ → Ⅲ/Ⅳ 양대 기법 메커니즘 비교 도식 → Ⅴ 종합 대조표 / 25점 = Ⅰ~Ⅶ, Ⅲ 수학적 편향/분산 수식 비교 및 Ⅵ 머신러닝 연계(배깅)
- 기출: 140회 1교시 7번/4교시 2번 `재표본화 기법(잭나이프와 부트스트랩)` → Ⅰ 개념 + Ⅲ 원리 비교 + Ⅴ 상세 비교표

## 한 줄 본질
- 미지의 복잡한 모집단 분포에서 모수 추정의 수학적 유도 불능 한계 → 주어진 표본의 1개 제외 비복원 반복(잭나이프)과 복원추출 무작위 반복(부트스트랩)으로 표본오차 극복 → 정확한 신뢰구간 산출 / 연산량 수반

## 핵심 그림
```text
[잭나이프와 부트스트랩의 재표본화(Resampling) 메커니즘 대조]

  [ 원본 표본: D = {x_1, x_2, x_3, ..., x_n} ]
                      │
         ┌────────────┴────────────┐
         ▼ (결정론적 1개 제외)     ▼ (확률론적 복원추출)
  [ 잭나이프 (Jackknife) ]   [ 부트스트랩 (Bootstrap) ]
   D_(1) = {x_2, x_3, ..., x_n}  B_1 = {x_1, x_1, x_4, ..., x_n}
   D_(2) = {x_1, x_3, ..., x_n}  B_2 = {x_2, x_3, x_3, ..., x_5}
   ...                            ...
   D_(n) = {x_1, x_2, ..., x_{n-1}} B_B = {x_3, x_7, x_7, ..., x_1}
   * 정확히 n개 표본 생성         * 수천 번(B=1,000~) 몬테카를로
   * 비복원 추출 (난수 없음)      * 중복 허용 복원 추출
```

## 핵심 용어
- 리샘플링(Resampling): 모집단에서 새로운 데이터를 추가 수집하지 않고, 이미 확보된 단일 표본 데이터로부터 반복적으로 부분 표본을 추출하여 통계량을 평가하는 기법
- 0.632 규칙: 부트스트랩에서 크기 $n$인 표본을 복원추출할 때, 개별 데이터가 선택될 확률은 약 $63.2\%$($1 - 1/e$)이고 제외될 확률(Out-Of-Bag)은 약 $36.8\%$

## 핵심 통찰
- 잭나이프는 부트스트랩의 1차 선형 근사(Linear Approximation)임 → 수학적으로 잭나이프는 부트스트랩을 테일러 전개했을 때의 첫 번째 항과 일치
- 잭나이프의 한계: 중앙값, 최빈값, 최대/최소값처럼 데이터의 작은 변화에 비선형적으로 요동치는 통계량에는 잭나이프가 작동하지 않음 → 이 영역은 부트스트랩만이 유일한 해법
- 반면 부트스트랩의 한계: 몬테카를로 무작위성에 의존하므로 시드(Seed)나 반복 횟수 $B$에 따라 결과가 미세하게 요동치며, 데이터가 커질수록 연산 비용이 기하급수적 증가

## 딸려 나오는 하위 토픽
| 하위 토픽 | 상위 구조 속 위치 | 한 줄 |
|---|---|---|
| BCa 신뢰구간(Bias-Corrected and Accelerated) | 부트스트랩 신뢰구간의 고도화 | 표본의 편향(Bias)과 왜도(Skewness, 가속도)를 동시에 보정해 비대칭 분포에서도 정밀한 신뢰구간 도출 |
| 배깅(Bagging) | 부트스트랩의 머신러닝 응용 | 부트스트랩 표본마다 독립된 결정트리를 학습시키고 결과를 평균내는 앙상블 학습 기법 |

## 이웃 토픽과 구분
- 잭나이프 vs 부트스트랩: 잭나이프 = 계산량이 적고 편향 제거에 탁월한 고전적 기법(표본 수 $n$회) / 부트스트랩 = 컴퓨터 집약적 몬테카를로를 활용해 임의의 복잡한 통계량 분포를 통째로 생성하는 범용 기법

## 문제·원인·대책
- 적용 상황: 신규 의약품 임상 시험 데이터의 치료 효과 비율 신뢰구간 산정
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 표본 수가 15개에 불과해 중심극한정리를 적용한 정규분포 신뢰구간 왜곡 | 소표본에서 모수적 정규성 가정이 위배됨 | 부트스트랩 BCa 신뢰구간(B=5,000) 산정 | 비대칭 소표본에서 정밀한 95% 신뢰구간 확보 |
| 중앙값 추정 시 잭나이프 표준오차가 이론값의 10배로 과대 계산 | 중앙값의 비평활성(Non-smoothness)으로 잭나이프 분산 추정 파괴 | Delete-d 잭나이프 또는 부트스트랩 백분위수법 전환 | 안정적인 통계 분산 획득 |

## 내 의견
- [모수적 가정의 관성을 깨는 데이터 주도 통계] 데이터 분포 확인도 없이 무조건 $t$-검정이나 정규분포를 가정하여 신뢰구간을 구하는 관행 탈피 필요 → 나라면: 표본이 적거나 왜도가 심한 실무 지표(체류시간, 결제금액) 분석 시 부트스트랩 신뢰구간을 기본 분석 파이프라인의 표준 규약으로 채택
