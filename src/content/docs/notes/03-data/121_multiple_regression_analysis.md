## 답안 골격
```text
[다중회귀분석 (Multiple Regression Analysis)] ◀━━ 머리: Ⅶ 내 의견 (VIF 진단을 통한 다중공선성 제거와 정규화 회귀(Ridge/Lasso) 적용)
 ┃
 ┣━ Ⅰ 개요 ───── 하나의 종속변수($Y$)의 변화를 두 개 이상의 독립변수($X_1, X_2, ..., X_k$)들의 선형 결합으로 설명하고 예측하는 지도학습 통계 모형
 ┣━ Ⅱ 특징 ───── 편회귀계수($\beta_k$) 해석(타 변수 고정 전제) · 설명력 지표(수정된 $R^2$) 사용 · 가우스-마르코프 4대 기본 가정 준수 필수
 ┣━ Ⅲ 구조 ───── 회귀식: $Y = \beta_0 + \beta_1 X_1 + \dots + \beta_k X_k + \epsilon$ ┃ 검정: F-검정(모형 유의성), t-검정(개별 계수 유의성)
 ┣━ Ⅳ 흐름 ───── ① 독립/종속변수 정의 → ② OLS(최소자승법) 회귀모형 적합 → ③ 4대 잔차 진단(선형성·정규성·등분산성·독립성) → ④ 다중공선성(VIF) 검증 → ⑤ 예측 및 영향력 평가
 ┣━ Ⅴ 비교 ───── 단순회귀분석 vs 다중회귀분석 vs 로지스틱 회귀분석
 ┗━ Ⅵ 실무 ───── 독립변수 간 강한 상관관계(다중공선성)로 회귀계수 부호 왜곡 / 변수 추가 시 $R^2$ 맹목적 증가
```
- 필수 키워드: 다중회귀분석 · OLS · 편회귀계수 · 수정된 결정계수(Adj $R^2$) · 다중공선성 · VIF · F-검정 · t-검정 · 잔차 진단
- 배점 전략: 10점 = Ⅰ → Ⅲ 다중회귀식 및 4대 잔차 가정 매핑표 → Ⅴ 회귀 유형 비교 / 25점 = Ⅰ~Ⅶ, Ⅳ 단계별 모델링 및 진단 절차도와 Ⅵ 변수선택법(전진, 후진, 단계적)
- 기출: 124회 `다중회귀분석(Multiple Regression Analysis)의 기본 가정과 다중공선성 판별 및 해결 방안` → Ⅰ 정의 + Ⅱ 기본 가정 + Ⅳ 다중공선성 판별(VIF) + Ⅵ 정규화 대책

## 한 줄 본질
- 복잡한 현실 현상은 단일 변수만으로 설명 불가 → 여러 독립변수를 동시에 통제하여 종속변수에 미치는 순수한 개별 영향력($\beta_k$)을 분리 추정 → 다차원 예측력 확보 / 독립변수 간 상관(다중공선성) 시 계수 추정 불안정

## 핵심 그림
```text
[다중회귀분석의 모형 구조 및 평가 체계]

             [독립변수군]                              [종속변수]
        ┌──────────────────┐
        │  X1 (마케팅비)   │───(β1: 편회귀계수)───┐
        ├──────────────────┤                     │
        │  X2 (할인율)     │───(β2: 편회귀계수)───┼──►  Y (매출액)
        ├──────────────────┤                     │     + ε (오차)
        │  X3 (매장면적)   │───(β3: 편회귀계수)───┘
        └──────────────────┘
                 │
                 ▼ 다중공선성 진단
          [VIF >= 10 이면 변수 제거 또는 Ridge/Lasso 전환]
```

## 핵심 용어
- 편회귀계수(Partial Regression Coefficient, $\beta_k$): 다른 모든 독립변수들의 값을 일정하게 고정한 상태에서, 해당 독립변수가 1단위 증가할 때 종속변수가 변화하는 평균 크기
- 수정된 결정계수(Adjusted $R^2$): 무의미한 독립변수를 추가하기만 해도 값이 무조건 커지는 일반 결정계수($R^2$)의 단점을 보완하기 위해 표본수($n$)와 변수수($k$)에 페널티를 부과한 지표

## 핵심 통찰
- 독립변수를 100개 넣으면 $R^2$은 무조건 0.99로 올라감 → 하지만 이는 모형이 좋아진 게 아니라 무작위 잡음까지 외워버린 과적합(Overfitting)이므로 반드시 Adjusted $R^2$이나 AIC/BIC로 모형의 간결성을 평가해야 함
- 다중회귀의 회귀계수 부호가 상식과 반대로 나오는 현상(예: 마케팅비를 늘렸는데 매출이 줄어든다고 나옴)의 99%는 '다중공선성' 때문임 → 두 독립변수가 서로 너무 강하게 얽혀 있어 분리 계산 실패
- 회귀계수의 유의성을 나타내는 t-검정 p-value가 0.05 미만이어도, F-검정(전체 모형이 유의한가)을 먼저 통과하지 못하면 개별 계수 해석은 통계적으로 무의미

## 이웃 토픽과 구분
- 다중회귀 vs 단순회귀: 단순회귀 = 1개의 독립변수로 종속변수를 설명 / 다중회귀 = 2개 이상의 독립변수를 투입하여 다른 변수들의 영향을 통제한 상태에서 특정 변수의 순수한 기여도를 분리

## 문제·원인·대책
- 적용 상황: 부동산 실거래가 예측을 위한 다중회귀 모델 구축
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| '전용면적'과 '공급면적'을 동시에 넣었더니 전용면적 계수가 음수로 역전 | 두 변수 간 상관계수가 0.98에 달하는 극심한 다중공선성 | 분산팽창인수(VIF > 10)를 확인하고 중복 변수 제거 또는 PCA 차원축소 | 계수 부호 정상화 및 다중공선성 해소 |
| 이상치(VIP 초고가 펜트하우스 1건)로 인해 전체 회귀선 기울기가 왜곡 | OLS 특성상 오차의 제곱합을 최소화하므로 극단값에 과도하게 민감 | 쿡의 거리(Cook's Distance > 1)로 영향점 식별 후 제거 또는 로버스트 회귀(Huber) 적용 | 회귀선 안정화 및 일반 거래 예측 오차 30% 감소 |
