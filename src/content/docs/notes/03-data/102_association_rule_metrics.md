## 답안 골격
```text
[연관규칙 지표 (Support·Confidence·Lift)] ◀━━ 머리: Ⅶ 내 의견 (최소 지지도 가지치기와 향상도 1.0 초과 유의 규칙 필터링)
 ┃
 ┣━ Ⅰ 개요 ───── 트랜잭션 데이터에서 품목 간의 숨겨진 연관 관계를 수치화하여 유의미한 비즈니스 규칙을 선별하는 3대 핵심 평가 척도
 ┣━ Ⅱ 특징 ───── 연관성 강도 정량화 · 장바구니 분석(MBA)의 기초 · 계산 복잡도 감소를 위한 가지치기 기준 · Apriori 핵심 지표
 ┣━ Ⅲ 구조 ───── 지지도($P(A \cap B)$) / 신뢰도($P(B|A)$) / 향상도($\frac{P(B|A)}{P(B)}$) / 레버리지 / 확신도(Conviction)
 ┣━ Ⅳ 흐름 ───── ① 전체 거래 데이터 집계 → ② 최소 지지도(Min Support) 필터링(빈발 항목 집합 생성) → ③ 최소 신뢰도(Min Confidence) 통과 규칙 도출 → ④ 향상도 평가(Lift > 1)
 ┣━ Ⅴ 비교 ───── 지지도 vs 신뢰도 vs 향상도 (규칙의 중요성/빈도 vs 조건부 조건 충족도 vs 우연 대비 실제 상관 강도)
 ┗━ Ⅵ 실무 ───── 최소 지지도를 높게 설정 시 희귀하지만 중요한 규칙 탈락 / 높은 신뢰도라도 향상도가 1 이하인 맹목 규칙 발생
```
- 필수 키워드: 연관규칙 분석 · 지지도(Support) · 신뢰도(Confidence) · 향상도(Lift) · Apriori · 빈발 항목 집합 · 장바구니 분석
- 배점 전략: 10점 = Ⅰ → Ⅲ 3대 지표 수식 및 의미 비교표 → Ⅴ 향상도 기준 해석(>1, =1, <1) / 25점 = Ⅰ~Ⅶ, Ⅳ Apriori 가지치기 연계 절차 및 Ⅵ 실무 한계 극복
- 기출: 137회 1교시 13번 `데이터마이닝의 연관 규칙 분석(Association Rule Analysis) 지표를 설명하시오.` → Ⅰ 개념 + Ⅲ 3대 지표 수식과 의미 + Ⅴ 향상도 판별 기준

## 한 줄 본질
- 수천만 건의 품목 조합에서 무의미한 우연 관계를 배제하기 어려움 → 지지도(빈도), 신뢰도(조건부 확률), 향상도(독립 대비 상관비)의 3단계 수학적 필터링 적용 → 고가치 연관 규칙 추출 / 희귀 품목 탈락 가능성 존재

## 핵심 그림
```text
[연관규칙 3대 지표 개념 및 계산 메커니즘: 규칙 A -> B]

  1. 지지도 (Support)        2. 신뢰도 (Confidence)     3. 향상도 (Lift)
  "얼마나 자주 발생하는가?"  "A를 살 때 B도 사는가?"    "우연보다 얼마나 더 사는가?"

       N(A ∩ B)                  N(A ∩ B)                     Confidence(A -> B)
  ─────────────────         ─────────────────           ─────────────────────────────
       전체 N                        N(A)                            P(B)

  [해석 기준]
  - Support    : 최소 기준 미달 시 빈발 항목에서 즉시 가지치기(Pruning)
  - Confidence : 방향성 존재 (A -> B 와 B -> A 의 값 상이)
  - Lift > 1   : 양의 상관관계 (A 구매가 B 구매를 실질 촉진, 유의미)
  - Lift = 1   : 독립 관계 (우연한 동시 구매, 무의미)
  - Lift < 1   : 음의 상관관계 (A 구매가 B 구매를 저해, 대체재)
```

## 핵심 용어
- 향상도(Lift): 품목 A와 B가 우연히 독립적으로 함께 팔릴 확률 대비, A를 샀을 때 B가 함께 팔릴 조건부 확률의 비율
- Apriori 원리: 한 항목 집합이 빈발하지 않으면, 이를 포함하는 모든 상위 집합 역시 빈발하지 않는다는 가지치기 규칙

## 핵심 통찰
- 신뢰도가 90%라고 해서 무조건 좋은 규칙이 아님 → 품목 B 자체가 전체 매장에서 90% 확률로 팔리는 생수라면, A와 관계없이 Lift는 1.0(독립)에 불과하여 가치 없는 맹목 규칙임
- 최소 지지도를 너무 높게 잡으면 금반지나 고가 가전처럼 거래 빈도는 낮지만 마진이 큰 알짜 연관 규칙이 탐색 초기에 모조리 잘려 나감
- 향상도는 방향성이 없지만(Lift(A $\rightarrow$ B) = Lift(B $\rightarrow$ A)), 신뢰도는 방향성이 있으므로 타겟 마케팅 시 주어(조건)를 무엇으로 둘지 결정하는 기준이 됨

## 이웃 토픽과 구분
- 연관규칙 분석 vs 순차패턴 분석: 연관규칙 = '동일 시점(장바구니)'에 함께 구매한 품목 간의 상관관계 분석 / 순차패턴 = '시간의 흐름(이력)'에 따라 A 구매 후 B를 구매하는 시계열 인과 분석

## 문제·원인·대책
- 적용 상황: 대형 이커머스 추천 엔진에서 기저귀와 맥주 등 품목 추천 규칙 생성
| 문제 | 원인 | 대책 | 효과 |
|---|---|---|---|
| 추천 알고리즘이 계란, 생수 등 누구나 사는 필수 생필품만 계속 추천 | 지지도와 신뢰도만 보고 향상도를 검증하지 않음 | Lift > 1.2 이상인 규칙만 추천 후보군으로 선별 | 우연한 동시 구매 배제 및 교차 판매(Cross-selling) 유도 |
| 대용량 거래 데이터에서 Apriori 알고리즘 실행 시 메모리 오버플로우 발생 | 후보 항목 집합(Candidate)의 지수적 폭증 및 반복 DB 풀스캔 | FP-Growth(Frequent Pattern Tree) 알고리즘으로 전환 | DB 스캔 2회로 단축 및 연산 속도 개선 |

## 내 의견
- [단순 지표 기계적 필터링의 오류] 데이터 사이언티스트가 분석 툴에서 Min Support 0.05, Min Confidence 0.8로 고정해 두고 돌려, 정작 비즈니스 임팩트가 큰 틈새 교차판매 기회를 놓치는 사례 다수 → 나라면: 고단가 카테고리와 저단가 카테고리의 최소 지지도 임계치를 동적으로 분리 적용하고, Lift 외에 확신도(Conviction) 지표를 결합하여 추천 피로도를 유발하는 거짓 규칙을 자동 정제

## 찾아볼 것
- 품목 B의 전체 출현 확률이 높을 때 향상도가 과대평가되는 왜곡을 보정하기 위한 확신도(Conviction) 및 코사인 유사도 연계 척도
