## Ⅰ. 개요

- **정의**: 타깃 AI 모델의 공개 API에 대량의 질의(Query)를 전송하고 수신한 예측 결과(확률값, 텍스트)를 지식 증류(Knowledge Distillation)의 교사 데이터로 활용하여 원본 모델의 결정 경계와 기능을 복제한 대체 모델(Surrogate Model)을 훔쳐내는 지식재산권 침해 공격
- **배경 및 필요성**: 막대한 인프라 비용과 독점 학습 데이터로 구축된 상용 모델이 블랙박스 API로 서비스될 때, 공격자가 최소 비용으로 모델의 독점적 기능과 지적 자산을 불법 복제하는 문제를 방어하고 라이선스 소유권을 입증하기 위해 도입

## Ⅱ. 특징

- 원본 모델의 내부 구조나 파라미터(가중치)에 직접 접근하지 않고 API 입출력 질의응답 쌍만으로 복제 수행
- 단순 무작위 질의 대비 결정 경계(Decision Boundary) 부근의 능동적 학습(Active Learning) 질의를 통해 추출 효율 극대화
- API 출력 정보량 축소(Hard Labeling), 비정상 질의 레이트 리밋, 워터마킹을 통한 사후 도용 추적 등 복합 대응 필요

## Ⅲ. 구조 및 구성요소

```text
Model_Extraction_Defense_Architecture
├── Query_Rate_Limiter (API 호출 속도 제한 및 비정상 트래픽 차단)
├── Output_Perturbation (소프트맥스 로짓 은닉 및 하드 라벨링 변환)
├── Extraction_Detector (결정 경계 탐색 질의 시퀀스 패턴 분석기)
└── Watermark_Embedder (모델 출력 내 잠재적 지적재산권 워터마크 삽입기)
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 세부 항목 | 핵심 역할 |
|:---|:---|:---|
| 질의 속도 제어기 | 계정별/IP별 Rate Limit, 토큰 버킷 알고리즘 | 단시간 대량 데이터 스크래핑 및 비정상 추출 질의 전송 지연·차단 |
| 출력 섭동 모듈 | Hard Label 반환, 확률값 반올림, 미세 노이즈 주입 | 질의 1회당 누출되는 결정 경계 정보량을 최소화하여 복제 정확도 저하 |
| 추출 탐지 엔진 | PRADA 알고리즘, 질의 간 거리 분포 분석 | 결정 경계를 정밀 탐색하는 공격자의 능동 학습 쿼리 시퀀스 실시간 식별 |
| 워터마크 삽입기 | 통계적 텍스트 워터마크(Green/Red List), 트리거 셋 | 복제된 모델에 특정 입력 시 고유 패턴 출력을 유도하여 사후 법적 증적 확보 |

## Ⅳ. 흐름도

```text
[공격자의 경계 탐색 질의 전송] (① 결정 경계 추정을 위한 최적 샘플 API 질의)
│
▼
[질의 빈도 및 패턴 이상 탐지] (② 질의 간 거리 분포 검사를 통해 모델 추출 행위 감지)
│
▼
[출력 정보 축소 및 섭동 적용] (③ 소프트 로짓 대신 하드 라벨 제공 및 확률 점수 반올림)
│
▼
[전자 워터마크 신호 삽입] (④ 출력 텍스트/데이터 내 통계적 시그니처 주입)
│
▼
[대체 모델 복제 추적 및 입증] (⑤ 유출 의심 모델에 트리거 셋 질의를 통한 IP 침해 입증)
```

- 분기 결과: 정상적인 서비스 이용 질의로 판정되면 하드 라벨링된 결과를 제공하고, 추출 공격 패턴으로 탐지되면 즉시 API 계정을 정지하고 방어용 노이즈 출력을 반환

## Ⅴ. 종류 및 비교

| 구분 | 라벨 전용 추출 (Hard-label Extraction) | 점수·로짓 기반 추출 (Soft-label Extraction) |
|:---|:---|:---|
| 획득 정보 | 모델의 최종 예측 클래스 라벨(Top-1)만 획득 | 각 클래스별 세부 확률 분포(Softmax Logits) 획득 |
| 필요 질의량 | 매우 큼 (수십만~수백만 건의 경계 탐색 질의 필요) | 적음 (클래스 간 상관관계 정보로 수천~수만 건으로 복제 가능) |
| 복제 모델 정확도 | 상대적으로 낮음 (경계 부근 근사 오차 존재) | 원본 모델과 거의 대등한 수준의 고품질 복제 달성 |
| 대표적 방어책 | 능동 학습 질의 패턴 탐지(PRADA), 쿼리 쿼터 제한 | 소프트 로짓 은닉, 점수 노이즈 주입, Top-1 하드 라벨링 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 소프트맥스 확률값 반환으로 인한 공격자의 추출 효율 극대화 | 최종 클래스 라벨(Hard Label)만 반환하거나 상위 K개 점수 반올림 | 질의 1회당 정보 유출량 최소화 및 공격 비용 대폭 상승 |
| 분산 계정 및 다중 프록시 IP를 통한 API 사용량 제한(Rate Limit) 우회 | 사용자 행동 기반 입력 임베딩 거리 분포 분석(PRADA) 연계 | 분산 봇넷 환경에서도 비정상적 경계 탐색 시퀀스 정확 탐지 |
| 추출 완료된 복제 모델에 대한 침해 증명 및 법적 대응 한계 | 모델 출력에 통계적 워터마크 및 역발행 트리거 셋(Watermark) 내재화 | 법정 분쟁 시 복제 모델의 무단 도용 여부 과학적 입증 |

## Ⅶ. 결론

- **기술 위상/발전**: 막대한 자본이 투자된 상용 AI 모델의 결정 경계와 지식 자산을 보호하기 위한 **AI 지식재산권(IP) 보호 및 MLOps 보안의 최고 핵심 방어 체계**
- **실무 적용/통제**: API 서비스 시 **하드 라벨링 출력 및 확률값 노이즈 섭동**을 기본 적용하고, 이상 질의 탐지 엔진과 **사후 도용 입증을 위한 워터마킹**을 결합한 입체적 자산 보호 체계 구축 필요
