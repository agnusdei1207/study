## Ⅰ. 개요

- **정의**: 사전학습된 대규모 언어 모델의 기본 가중치를 4비트 NF4(NormalFloat4)로 양자화하여 동결하고, 순전파/역전파 계산 시점에만 BF16으로 역양자화(Dequantization)하여 16비트 LoRA 어댑터를 학습시키는 고효율 미세조정 기술
- **배경 및 필요성**: 16비트 기반 모델 적재 시 발생하는 막대한 GPU VRAM 요구량(65B/70B 모델 기준 130GB 이상)으로 인해 엔터프라이즈 단일 GPU에서 튜닝이 불가능한 한계를 돌파하고, 이중 양자화(Double Quantization) 및 페이지드 옵티마이저(Paged Optimizer)를 통해 모델 성능 손실 없이 학습 인프라 비용을 극단적으로 절감하기 위해 도입

## Ⅱ. 특징

- **NF4 (NormalFloat 4-bit)**: 정규분포를 따르는 사전학습 가중치 특성에 정보이론적으로 최적화된 비균일 4비트 양자화 자료형 적용
- **이중 양자화 (Double Quantization)**: 1차 양자화 상수(Scale) 자체를 추가 8비트 부동소수점으로 재양자화하여 파라미터당 메모리를 0.37비트 추가 절감
- **페이지드 옵티마이저 (Paged Optimizer)**: 시퀀스 확장 시 발생하는 순간적 메모리 피크 구간에서 CUDA 통합 메모리 기반 CPU RAM 페이징을 수행하여 OOM(Out of Memory) 원천 차단
- **혼합 정밀도 학습 체계**: 저비트(4-bit NF4) 압축 적재와 고정밀(16-bit BF16) 계산 경로를 분리하여 16비트 완전 미세조정(Full FT) 수준의 성능 방어

## Ⅲ. 구조 및 구성요소

```text
[QLoRA 구조]
├── [양자화 저장 계층]
│   ├── [4비트 NF4 기본 가중치]
│   └── [이중 양자화 상수 (Double Quantization)]
├── [역양자화 연산 계층]
│   ├── [온더플라이 BF16 역양자화기]
│   └── [출력 결합기 (Base + LoRA)]
└── [학습 최적화 계층]
    ├── [16비트 LoRA 어댑터 (A, B)]
    └── [페이지드 옵티마이저 (Paged AdamW)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| 4비트 NF4 가중치 | 정규분포 기반 4비트 최적 코드북으로 베이스 모델 압축 적재 |
| 이중 양자화 상수 | 블록별 양자화 상수를 8비트로 재양자화하여 추가 메모리 절감 |
| 온더플라이 역양자화기 | 순전파/역전파 계산 시점에만 4비트 가중치를 BF16으로 즉각 복원 |
| 16비트 LoRA 어댑터 | BF16 정밀도로 고유 과업 특화 가중치 변화량($BA$) 역전파 학습 |
| 페이지드 옵티마이저 | GPU 메모리 피크 시 CUDA 통합 메모리 기반 CPU RAM 페이징 수행 |

## Ⅳ. 흐름도

```text
[QLoRA 미세조정 흐름] (진입: 단일 GPU 학습 요청 접수)
│
▼
[모델 적재] (① 4비트 NF4 변환 및 이중 양자화 상수 적용하여 VRAM 적재)
│
▼
[동적 역양자화] (② 순전파 시 연산 블록별 4비트 가중치를 BF16으로 복원)
│
▼
[LoRA 연산] (③ BF16 복원 기반 출력과 16비트 LoRA 변화량 결합 및 손실 계산)
│
▼
[어댑터 역전파] (④ 역양자화 가중치 통과 후 LoRA 행렬만 16비트 그래디언트 갱신)
│
▼
[페이징 제어] (⑤ 메모리 스파이크 시 옵티마이저 상태 CPU 페이징 오프로드)
│
▼
[완료] (반환: 16비트 LoRA 어댑터 추출 및 고속 서빙 엔진 배포)
```

- 분기 결과: 메모리 여유 시 **GPU 전용 초고속 학습**을 유지하고, VRAM 피크 발생 시 **CUDA Paged 메모리 스왑**을 활성화하여 OOM 크래시를 방지함

## Ⅴ. 종류 및 비교

| 구분 | 완전 미세조정 (Full FT) | LoRA (16-bit) | QLoRA (4-bit) |
|:---|:---|:---|:---|
| 기반 가중치 정밀도 | FP16 / BF16 (16-bit) | FP16 / BF16 (16-bit) | NF4 (4-bit) + 이중 양자화 |
| 어댑터 정밀도 | 해당 없음 (전체 갱신) | FP16 / BF16 (16-bit) | FP16 / BF16 (16-bit) |
| 65B 모델 VRAM | 780GB 이상 (다중 노드) | 160GB 이상 (다중 GPU) | 48GB 이하 (단일 GPU 가능) |
| 과업 벤치마크 성능 | 기준 성능 ($100\%$) | 기준 대등 ($99.9\%$) | 기준 대등 ($99.3\sim100\%$) |
| 학습 속도 | 빠름 | 매우 빠름 | 역양자화 오버헤드로 약 $30\%$ 감속 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 양자화 오차에 따른 과업 품질 저하 우려 | NF4 자료형 채택 및 어텐션·FFN 전 계층 LoRA 적용 | 16비트 Full FT 대비 99% 이상 성능 보존 |
| 역양자화 연산 오버헤드로 인한 학습 속도 저하 | FlashAttention-2 및 고속 양자화 커널(bitsandbytes) 결합 | 역양자화 병목 최소화 및 연산 처리량 향상 |
| 긴 문맥 학습 시 VRAM 급증 및 OOM 발생 | Paged AdamW 8-bit 옵티마이저 및 그래디언트 체크포인팅 적용 | 단일 GPU 내 OOM 크래시 원천 차단 |

## Ⅶ. 결론

- **기술 위상/발전**: 초대규모 LLM의 미세조정 진입 장벽을 컨슈머 및 단일 엔터프라이즈 GPU 수준으로 대폭 낮춘 **QLoRA 기술**은 NF4, 이중 양자화, 페이지드 옵티마이저의 결합을 통해 오픈소스 AI 생태계의 대중화를 견인
- **실무 적용/통제**: 자원 제약 환경에서는 **QLoRA 파이프라인**을 통해 학습 비용을 최소화하고, 학습 완료 후 추출된 **16비트 어댑터 가중치**를 고속 서빙 엔진(vLLM/SGLang)에 통합하여 지연 없는 고효율 추론 구축
