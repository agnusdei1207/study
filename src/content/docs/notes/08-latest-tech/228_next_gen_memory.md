## Ⅰ. 개요

- **정의**: AI 모델 거대화 및 데이터 폭증 환경에서 전통적 폰 노이만 구조의 메모리 벽(Memory Wall)을 극복하기 위해 초고대역폭 수직 적층 메모리(**HBM**), 캐시 일관성 기반 용량 확장 및 풀링 인터커넥트(**CXL**), 메모리 내부 직접 연산(**PIM/PNM**)을 상호보완적으로 융합한 **차세대 지능형·이기종 메모리 아키텍처 기술**
- **배경 및 필요성**: 기존 평면 실장(DDR/GDDR) 인터페이스의 핀 수 및 신호 무결성 한계로 인한 대역폭 포화, 서버별 고정 DRAM 할당으로 인한 극심한 메모리 좌초(Stranded Memory) 오버헤드, 프로세서와 메모리 간 대규모 데이터 왕복 전송 시 수반되는 에너지 낭비와 전력 벽(Power Wall)이 심화됨에 따라, **TB/s급 초광폭 대역폭 공급, 노드 간 메모리 풀링을 통한 자원 활용률 극대화, 데이터 이동 경로 제거를 통한 초저전력 인메모리 연산**을 달성하기 위해 도입

## Ⅱ. 특징

- **HBM 기반 대역폭 극대화**: 실리콘 관통 전극(TSV) 3D 수직 적층과 1024비트 이상 초광폭 버스를 통해 테라바이트급(**TB/s급 초고대역폭**) 전송 속도 제공
- **CXL 기반 용량 확장 및 풀링**: PCIe 물리 계층 위에서 하드웨어 캐시 일관성을 보장하여 노드 간 **메모리 좌초(Stranded Memory) 방지** 및 페타바이트급 공유 메모리 풀 구축
- **PIM 기반 데이터 이동 원천 제거**: DRAM 뱅크 내부에 연산 유닛(ALU/MAC)을 집적하여 프로세서-메모리 간 버스 트래픽 억제 및 **소비 전력 대폭 절감**
- **메모리 계층화 다변화**: 단일 피라미드 구조를 탈피하여 고대역폭 특화(HBM), 대용량 확장(CXL), 인메모리 가속(PIM)으로 구성된 **이기종 메모리 패브릭** 형성
- **메모리 중심 컴퓨팅 패러다임 전환**: 프로세서가 데이터를 가져와 연산하던 방식에서 벗어나 메모리 위치에서 직접 처리하거나 유연하게 공유하는 **데이터 중심(Data-Centric) 아키텍처** 확립

## Ⅲ. 구조 및 구성요소

```text
[차세대 메모리 아키텍처]
├── [초고속 연산 계층]
│   ├── [GPU•NPU 가속기 코어]
│   └── [HBM 3D 스택 (TSV)]
├── [인메모리 처리 계층]
│   ├── [PIM 뱅크 내장 ALU]
│   └── [PNM 가속 컨트롤러]
└── [대용량 풀링 계층]
    ├── [CXL 패브릭 스위치]
    ├── [CXL 메모리 풀 (Type 3)]
    └── [소프트웨어 계층화 관리자]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 계층 | 구성요소 | 설명 |
|:---|:---|:---|
| 초고속 연산 계층 | HBM 3D 스택 | TSV 미세 전극으로 DRAM 코어 다이를 수직 적층하고 실리콘 인터포저를 통해 가속기 패키지 내부에서 직결 구동 |
| 초고속 연산 계층 | 실리콘 인터포저 | 가속기 다이와 HBM 간 1024비트 이상의 미세 배선을 연결하는 2.5D 패키징 기판 |
| 인메모리 처리 계층 | PIM 뱅크 내장 ALU | DRAM 메모리 셀 뱅크 내부에 내장되어 벡터 곱셈 및 누적(MAC), 활성화 함수를 메모리 내부에서 직접 처리 |
| 인메모리 처리 계층 | PNM 모듈 | 메모리 모듈 인터페이스 또는 컨트롤러 레벨에 연산 가속기를 배치하여 데이터 전송 지연 완화 |
| 대용량 풀링 계층 | CXL 패브릭 스위치 | PCIe 물리 링크 위에서 CXL.io, CXL.cache, CXL.mem 프로토콜을 다중 호스트 노드에 중계 |
| 대용량 풀링 계층 | CXL 메모리 풀 | PCIe 슬롯 장착형 확장 장치로 클러스터 노드 간 공유 가능한 페타바이트급 동적 메모리 자원 제공 |
| 대용량 풀링 계층 | 소프트웨어 계층화 관리자 | 핫/콜드 데이터 접근 패턴을 프로파일링하여 HBM, 호스트 DRAM, CXL 풀 간 동적 페이지 마이그레이션 조율 |

## Ⅳ. 흐름도

```text
[워크로드 실행 요청 수신] (① AI 모델/빅데이터 작업 유입)
          │
          ▼
[연산 특성 및 메모리 요구량 프로파일링] (② 산술 강도 및 접근 패턴 판정)
          │
          ▼
[최적 메모리 경로 분기 및 매핑] (③ HBM/CXL/PIM 할당)
          │
          ▼
[계층화 관리자 동적 마이그레이션] (④ 핫/콜드 데이터 실시간 재배치)
          │
          ▼
[연산 완료 및 최종 결과 반환] (⑤ 가속기 및 호스트 연산 종료)
```

- 분기 결과: 연산 집약적 가중치/어텐션은 초고속 HBM에 상주하고, 대규모 KV 캐시 및 임베딩 테이블은 CXL 공유 풀로 확장되며, 단순 반복 벡터 연산은 메모리 버스 이동 없이 PIM 내부 ALU에서 직접 계산 완료됨

1. 워크로드 실행 요청 수신: 초거대 AI 학습/추론 또는 대규모 인메모리 데이터베이스 쿼리 수신
2. 연산 특성 및 메모리 요구량 프로파일링: 작업의 산술 강도(Operational Intensity), 메모리 용량 필요치, 메모리 바운드 특성 실시간 측정
3. 최적 메모리 경로 분기 및 매핑: 산술 강도가 높고 초광폭 대역폭이 필요한 데이터는 온패키지 HBM에 할당하고, 용량 확장이 필요한 데이터는 CXL 풀에 매핑하며, 단순 반복 연산은 PIM 오프로딩으로 분기
4. 계층화 관리자 동적 마이그레이션: 데이터 접근 빈도(Hot/Cold) 변화를 모니터링하여 고속 HBM 계층과 확장 CXL 계층 간 페이지를 무중단 마이그레이션 수행
5. 연산 완료 및 최종 결과 반환: 각 계층에서 처리된 연산 결과를 종합하여 호스트 프로세서 및 사용자 응용 프로그램으로 반환

## Ⅴ. 종류 및 비교

| 메모리 기술 | HBM (고대역폭 메모리) | CXL (컴퓨트 익스프레스 링크) | PIM (지능형 인메모리 연산) |
|:---|:---|:---|:---|
| 핵심 개념 | 3D 수직 적층 기반 **초고대역폭 공급** | PCIe 기반 캐시 일관성 **용량 확장·풀링** | 메모리 셀/뱅크 내부 **직접 연산 집적** |
| 연결 방식 | 온패키지 2.5D **실리콘 인터포저** | 표준 **PCIe 5.0/6.0 슬롯 인터페이스** | DRAM **코어 다이 내부 뱅크 버스** |
| 대역폭 및 지연 | **TB/s급 초고대역폭**, 극저지연 | **GB/s급 대역폭**, PCIe 통신 지연 발생 | **뱅크 병렬 대역폭**, 버스 전송 지연 제로 |
| 용량 확장성 | **제한적** (패키징 면적 한계로 수십 GB 수준) | **매우 높음** (CXL 스위치 기반 페타바이트급) | **보통** (DRAM 용량 대비 연산 로직 점유로 소폭 감소) |
| 전력 효율성 | 대역폭 대비 우수하나 **발열 집중** | 일반 DRAM 인터커넥트 수준 | 데이터 이동 전력 **80% 이상 절감** |
| 주요 적용처 | GPU/NPU **LLM 학습·추론 어텐션 연산** | 데이터센터 **대용량 KV 캐시, 인메모리 DB** | 추천 시스템, **벡터 임베딩 검색, 활성화 함수** |

## Ⅵ. 실무 고려사항 및 대책

| 문제점 | 대책 | 기대효과 |
|:---|:---|:---|
| HBM 3D 적층에 따른 **발열 집중 및 수율 저하** | 마이크로범프 제거형 **하이브리드 본딩(Cu-Cu 접합)** 및 액체 냉각(Direct-to-Chip) 인터포저 방열 설계 적용 | 열 저항 대폭 감소 및 패키징 결함 최소화를 통한 수율 안정화 |
| CXL 링크 통신에 따른 **추가 접근 지연 오버헤드** | 하드웨어 기반 **지연 은닉 프리페칭** 및 접근 빈도 기반 핫/콜드 계층화 자동 오케스트레이션 적용 | 빈번 참조 데이터 로컬화로 지연시간 페널티 상쇄 |
| PIM 전용 명령어 부재로 인한 **소프트웨어 에코시스템 미성숙** | 표준 PIM API 라이브러리 구축 및 PyTorch/TensorFlow 레벨 **컴파일러 자동 오프로딩** 지원 | 개발자 코드 수정 없는 투명한 하드웨어 가속 달성 |
| 이기종 메모리 혼용 시 발생하는 **캐시 일관성 저하 및 데이터 불일치** | CXL.cache/CXL.mem 하드웨어 일관성 프로토콜 준수 및 메모리 배리어 정책 정밀화 | 다중 노드 공유 환경에서 완벽한 데이터 무결성 보장 |

## Ⅶ. 결론

- **기술 위상/발전**: AI 모델의 파라미터 폭증에 따른 폰 노이만 병목을 극복하고 **메모리 중심 컴퓨팅(Memory-Centric Computing)으로의 패러다임 전환을 이끄는 3대 핵심 아키텍처**로 자리 잡았으며, 초고속 연산을 위한 **HBM**, 무한 용량 확장을 위한 **CXL**, 데이터 이동을 원천 차단하는 **PIM/PNM**이 단일 시스템 내에서 상호보완적 하이브리드 메모리 패브릭으로 융합되는 방향으로 진화
- **실무 적용/통제**: 워크로드의 연산 강도와 데이터 접근 패턴을 정밀 분석하여 **적재적소의 메모리 계층 할당 전략**을 수립하고, 하이브리드 본딩 방열 기술 도입, CXL 지연 은닉 소프트웨어 튜닝, PIM 표준 라이브러리 생태계 조기 확보를 통해 차세대 인프라 투자 효율성 극대화 필요
