## Ⅰ. 개요

- **정의**: 이미지의 시각적 특징과 자연어 텍스트를 공통 의미 공간에 정렬하여 시각적 질의응답(VQA), 이미지 캡셔닝, 문서 분석 등을 수행하는 **시각언어모델(Vision-Language Model, VLM)**
- **배경 및 필요성**: 컴퓨터 비전 모델과 언어 모델이 분리 동작할 경우 이미지 내 객체의 공간 관계, 차트/도표 수치, 텍스트(OCR)를 통합 추론할 수 없는 구조적 단절이 발생함에 따라, 사전 학습된 시각 인코더(ViT)와 언어 디코더(LLM) 사이에 프로젝터/어댑터(MLP, Q-Former)를 연결하여 시각 특징을 언어 토큰 공간으로 직접 투영하고 정밀한 시각적 추론과 설명 생성을 달성하기 위해 필요

## Ⅱ. 특징

- **시각 특징의 언어 토큰화**: 이미지를 ViT 패치 단위로 인코딩한 후 언어 모델이 이해할 수 있는 시각 임베딩 토큰으로 변환
- **투영 계층 정렬**: 선형 프로젝터(MLP) 또는 크로스 어텐션 기반 Q-Former를 통해 시각-언어 표현 공간 차원 일치
- **시각 지시 튜닝**: 멀티모달 대화 데이터셋을 활용해 이미지 기반의 복합 지시어 수행 능력 극대화

## Ⅲ. 구조 및 구성요소

```text
[Vision-Language Model]
├── [모달 인코딩 계층]
│   ├── [이미지 인코더 (ViT)]
│   └── [텍스트 인코더 (Text Enc)]
├── [교차 투영 계층]
│   └── [연결 계층 (Projector/Q-Former)]
└── [언어 생성/출력 계층]
    ├── [언어 디코더 (LLM Backbone)]
    └── [출력 계층 (Output Layer)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| 이미지 인코더 | 비전 트랜스포머(ViT) 기반 이미지 패치 분할 및 시각 특징 벡터 추출 |
| 텍스트 인코더 | 사용자 질의 프롬프트의 토큰화 및 텍스트 임베딩 생성 |
| 연결 계층 | MLP/Q-Former를 통한 시각 특징 벡터의 언어 토큰 공간 투영 및 정렬 |
| 언어 디코더 | 시각 토큰과 텍스트 토큰을 결합 문맥으로 수신하여 자기회귀적 답변 생성 |
| 출력 계층 | 최종 자연어 응답 생성, 객체 검출 바운딩 박스, 또는 시각 분류 결과 산출 |

## Ⅳ. 흐름도

```text
[이미지 인코더] (① 입력 이미지의 패치 분할 및 시각 특징 추출)
│
▼
[연결 계층 (Projector)] (② 시각 임베딩을 LLM 입력 차원으로 선형 투영)
│
▼
[언어 디코더 (LLM)] (③ 시각 토큰과 사용자 텍스트 질의 결합 문맥 연산)
│
▼
[출력 계층] (④ 이미지 기반 시각적 추론 답변 및 설명 텍스트 생성)
```

- 분기 결과: 정상 시각-텍스트 정렬 시 이미지 기반 서술 답변 생성, 이미지 해상도 부족 또는 정보 부재 시 불확실성 안내 및 추가 정보 요청

## Ⅴ. 종류 및 비교

| 구분 | 대조 학습 (Contrastive) | 이미지-텍스트 매칭 (ITM) | 생성형 튜닝 (Generative) |
|:---|:---|:---|:---|
| 적용 기준 | 제로샷 이미지 분류, 크로스모달 검색 | 이미지-텍스트 쌍 정밀 적합성 판별 | 시각적 질의응답(VQA), 이미지 설명 생성 |
| 핵심 특징 | 듀얼 타워 구조, 코사인 유사도 학습 (CLIP) | 교차 어텐션 기반 이진 일치 분류 | 시각 토큰 조건부 자기회귀 텍스트 생성 (LLaVA) |
| 한계 | 세부 공간 관계 및 자유 생성 불가 | 생성형 태스크 확장 불가, 추론 지연 | 시각 환각(Visual Hallucination) 발생 가능 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 저해상도 문서/차트 내 미세 텍스트 OCR 오류 | 다이내믹 패칭(Dynamic Patching) 및 전문 OCR 파이프라인 연계 | 작은 글자 및 복합 도표 판독 정확도 향상 |
| 이미지에 없는 객체를 단정하는 시각 환각 | 바운딩 박스 기반 객체 그라운딩 검증 및 CoVe 적용 | 사실 충실성 확보 및 거짓 설명 차단 |
| 고해상도 이미지 입력 시 토큰 폭증 병목 | 토큰 압축 모듈(Resampler, Spatial Pooling) 도입 | LLM 연산 부하 경감 및 추론 속도 개선 |

## Ⅶ. 결론

- **기술 위상/발전**: 시각적 패치를 언어 모델의 문맥으로 직결하여 이미지 이해와 자연어 추론을 단일 신경망에서 통합한 멀티모달 생성형 AI의 핵심 프런티어 기술
- **실무 적용/통제**: 고해상도 다이내믹 패칭 도입, 시각 환각 방어용 Grounding 검증 계층 구축, 소형 모델 경량화를 통해 시각 추론 정확도와 실시간성 확보
