## Ⅰ. 개요

- **정의**: 별도의 보상 모델(Reward Model)과 복잡한 강화학습(PPO) 루프 없이, 선호 응답($y_w$)과 비선호 응답($y_l$)의 상대적 로그 확률비를 직접 최적화하여 인간 선호에 정렬시키는 기법
- **배경 및 필요성**: 기존 RLHF의 보상 모델 사전학습, 가치 네트워크 갱신, 동적 롤아웃 샘플링으로 인한 극심한 하이퍼파라미터 불안정성과 4개 모델 동시 상주에 따른 VRAM 폭증 문제를 해결하고, 단일 이진 교차 엔트로피(BCE) 손실을 통해 안정적이고 빠른 정렬을 달성하기 위해 도입

## Ⅱ. 특징

- **수학적 내재 보상 (Implicit Reward)**: $r(x, y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}$ 수식 유도를 통해 보상 모델을 정책 모델과 참조 모델의 확률비로 완전 대체
- **단일 손실 함수 최적화**: $\mathcal{L}_{\text{DPO}}(\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right) \right]$
- **인프라 및 메모리 경량화**: 보상 모델과 가치 모델을 제거하여 정책 모델과 동결 참조 모델 2개만으로 안정적 학습 수행
- **오프라인 안정성**: 온라인 롤아웃 탐색 없이 정적 선호 데이터셋만으로 지도학습 방식의 초고속 경사하강 역전파 실현

## Ⅲ. 구조 및 구성요소

```text
[DPO 아키텍처]
├── [입력 데이터 계층]
│   └── [선호 응답 데이터셋 (x, yw, yl)]
├── [모델 연산 계층]
│   ├── [학습 정책 모델 (π_θ, 최적화 대상)]
│   └── [동결 참조 모델 (π_ref, 기준 분포)]
└── [손실 최적화 계층]
    ├── [로그 확률비 연산기 (Implicit Reward)]
    └── [DPO 손실 함수 (Sigmoid/BCE)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| 선호 응답 데이터셋 | 동일 프롬프트에 대한 선택 응답($y_w$)과 비선택 응답($y_l$) 쌍 제공 |
| 학습 정책 모델 (π_θ) | 선호 응답의 생성 확률을 높이고 비선호 응답 확률을 낮추는 학습 대상 모델 |
| 동결 참조 모델 (π_ref) | 과도한 언어 드리프트(Drift)를 억제하는 기준 확률 분포 제공 |
| 로그 확률비 연산기 | 정책 모델과 참조 모델 간 응답별 상대 로그 확률 차이 산출 |
| DPO 손실 함수 | 내재적 보상 차이에 시그모이드를 적용하여 단일 단계 역전파 손실 계산 |

## Ⅳ. 흐름도

```text
[DPO 정렬 흐름] (진입: 선호 응답 데이터 배치 인입)
│
▼
[배치 입력] (① 프롬프트 x와 응답 쌍 (yw, yl) 로드)
│
▼
[확률 추론] (② 정책 모델 π_θ 및 동결 참조 모델 π_ref에서 각 응답의 토큰 로그 확률 계산)
│
▼
[내재 보상 산출] (③ β·log(π_θ/π_ref) 수식을 적용하여 암묵적 보상 차이 산출)
│
▼
[BCE 역전파] (④ 시그모이드 교차 엔트로피 손실 역전파를 통해 정책 모델 파라미터만 갱신)
│
▼
[완료] (반환: 강화학습 없이 인간 선호에 정렬된 정책 모델 배포)
```

- 분기 결과: 정적 데이터로 고속 정렬 시 **오프라인 DPO**를 완료하고, 모델 생성 분포 변화에 대응할 경우 **자체 생성 기반 Iterative/Online DPO**로 루프를 확장함

## Ⅴ. 종류 및 비교

| 구분 | 직접 선호 최적화 (DPO) | 지도 미세조정 (SFT) | 인간 피드백 강화학습 (RLHF) |
|:---|:---|:---|:---|
| 핵심 메커니즘 | 상대 로그 확률비 직접 최적화 | 정답 토큰 우도 최대화 | 별도 보상 모델 기반 PPO 정책 갱신 |
| 보상 모델 학습 | 불필요 (수학적 내재화) | 불필요 | 필수 (Bradley-Terry 모델) |
| 학습 안정성 | 매우 높음 (지도학습 형태) | 높음 | 낮음 (PPO 하이퍼파라미터 민감) |
| GPU 메모리 | 정책 + 참조 모델 (2개) | 정책 모델 1개 | 정책 + 가치 + 보상 + 참조 (4개) |
| 미지 영역 탐색 | 정적 데이터셋 범위 한정 | 시연 데이터 한정 | 온라인 롤아웃 기반 능동 탐색 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단순 길이가 긴 응답을 선호하는 길이 편향(Length Bias) | 정규화 기법(SimPO) 적용 및 선호쌍 길이 균형화 | 형식적 장황함 배제 및 실제 응답 품질 개선 |
| 과도한 정렬로 인한 원본 언어 모델 능력 저하 | 베타 계수($\beta=0.05\sim0.1$) 미세 조정 및 정규화 항 추가 | 일반화 지식 보존 및 안정적 선호 수렴 |
| 정적 데이터 고착화에 따른 분포 불일치(Distribution Shift) | 최신 정책 모델로 응답을 재생성하는 Iterative DPO 적용 | 실시간 생성 분포 반영 및 정렬 정확도 향상 |

## Ⅶ. 결론

- **기술 위상/발전**: 복잡한 RLHF 파이프라인을 수학적 치환을 통해 단일 지도학습 체계로 혁신한 **DPO 기술**은 LLM 정렬 분야에서 가장 지배적인 표준 알고리즘으로 자리잡았으며 KTO, SimPO 등으로 확장
- **실무 적용/통제**: 서비스 요구사항에 맞춰 1차 오프라인 정렬은 **DPO 알고리즘**으로 신속히 수행하고, 고난도 추론 영역에서는 **Iterative Online DPO**를 채택하여 탐색력과 정렬 품질을 동시에 극대화
