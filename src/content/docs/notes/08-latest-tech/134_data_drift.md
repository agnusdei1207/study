## Ⅰ. 개요

- **정의**: 머신러닝 모델 학습에 사용된 입력 특성 데이터셋의 통계적 확률 분포 $P(X)$와 프로덕션 서빙 환경에 입력되는 데이터의 확률 분포가 시간의 흐름에 따라 변화하는 현상 (공변량 변화, Covariate Shift)
- **배경 및 필요성**: 실제 정답 라벨(Ground Truth)이 도착하기까지 수주~수개월이 소요되는 지연 라벨(Delayed Label) 환경에서는 모델의 예측 품질 저하를 즉각 파악할 수 없으므로, 정답 라벨 없이도 실시간 입력 데이터의 분포 변화를 조기에 감지(PSI, KS-검정)하여 모델 열화를 선제적으로 방어하는 모니터링 체계가 필수적임

## Ⅱ. 특징

- **무라벨 조기 감지(Unsupervised Early Warning)**: 실제 정답 라벨 $Y$의 유입 여부와 무관하게 입력 특징 벡터 $X$의 통계적 분포 변화만으로 선제적 이상 감지 가능
- **통계적 가설검정 기반 정량화**: 연속형 변수 대상 KS-검정(Kolmogorov-Smirnov) 및 범주형 변수 대상 카이제곱(Chi-Square), PSI(Population Stability Index) 적용
- **동적 기준선(Dynamic Baseline) 적용**: 계절성(Seasonality), 이벤트, 마케팅 캠페인에 따른 일시적 정상 변동과 구조적 데이터 왜곡을 분리 판별
- **지속적 학습(CT) 파이프라인 연계**: 드리프트 임계치 초과 시 즉각적인 알림 발송, 데이터 수집 파이프라인 무결성 점검 및 신규 데이터 기반 자동 재학습 트리거

## Ⅲ. 구조 및 구성요소

### 1. 데이터 드리프트 모니터링 아키텍처

```text
[Data Drift Detection]
├── [입력 및 기준 분포 계층]
│   ├── [기준 프로필 (Baseline Profile)]
│   └── [현재 구간 (Current Window)]
├── [통계 비교 및 분석 계층]
│   └── [분포 비교기 (Distribution Comparator)]
└── [정책 및 검증 계층]
    ├── [문맥 정책 (Context Policy)]
    └── [정답 저장소 (Ground Truth Store)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

### 2. 세부 구성요소

| 계층 구분 | 세부 항목 | 핵심 역할 |
|:---|:---|:---|
| 입력 및 기준 계층 | 기준 프로필 (Baseline) | 학습/검증 데이터셋의 피처별 평균, 분산, 분위수, 히스토그램 스냅샷 보관 |
| | 현재 관측 윈도우 | 슬라이딩 윈도우(Sliding Window) 기반 실시간 프로덕션 추론 입력 데이터 수집 |
| 통계 비교 계층 | 통계 검정 엔진 | 피처 타입별 PSI, KS-검정, Wasserstein Distance, Jensen-Shannon 발산 계산 |
| | 드리프트 점수 산출기 | 전체 모델 단위 종합 드리프트 지수 도출 및 심각도(경고/위험) 판정 |
| 정책 및 검증 계층 | 문맥 정책 엔진 | 계절성/주말 패턴 반영 동적 임계치 적용 및 상류 파이프라인 장애 격리 |
| | 정답 연계 검증기 | 지연 라벨 도착 시 실제 모델 성능(F1-Score, RMSE) 저하와의 상관관계 최종 실측 |

## Ⅳ. 흐름도

```text
[기준 프로필 설정] (① 학습 데이터셋 기반 피처별 기준 통계량 및 분포 히스토그램 저장)
  │
  ▼
[실시간 입력 수집] (② 프로덕션 서빙 트래픽에서 추론 입력 데이터 슬라이딩 윈도우 수집)
  │
  ▼
[통계적 거리 측정] (③ 피처별 PSI 지수 및 KS-검정 p-value 산출을 통한 드리프트 판정)
  │
  ▼
[문맥 필터링 및 알림] (④ 단순 계절 변동 여부 필터링 후 임계치 초과 시 운영팀 경보)
  │
  ▼
[원인 분석 및 CT 연계] (⑤ 상류 데이터 스키마 점검, 피처 수정 또는 자동 재학습 파이프라인 실행)
```

- 분기 결과: PSI < 0.1(유의미한 변화 없음) 시 정상 유지, 0.1 $\le$ PSI < 0.25 시 모니터링 강화, PSI $\ge$ 0.25(심각한 드리프트) 시 데이터 파이프라인 점검 후 자동 재학습(CT) 개시

## Ⅴ. 종류 및 비교

| 비교 항목 | 데이터 드리프트 (Data Drift) | 개념 드리프트 (Concept Drift) | 라벨 드리프트 (Label Drift) |
|:---|:---|:---|:---|
| 통계적 정의 | 입력 분포 변화: $P(X) \neq P_{train}(X)$ | 조건부 확률 변화: $P(Y \mid X) \neq P_{train}(Y \mid X)$ | 정답 분포 변화: $P(Y) \neq P_{train}(Y)$ |
| 발생 원인 | 사용자 인구통계 변화, 센서 결함, 계절성 | 고객 선호도 변화, 거시경제 충격, 트렌드 전환 | 질병 유병률 급증, 특정 사기 범죄율 증가 |
| 감지 가능 시점 | 프로덕션 추론 입력 즉시 (라벨 불필요) | 실제 정답 라벨 획득 이후에만 감지 가능 | 실제 정답 라벨 획득 이후에만 감지 가능 |
| 모델 성능 영향 | 성능 저하 가능성 높음 (선행 지표) | 모델 예측 성능의 직접적이고 치명적 저하 | 양성/음성 비율 왜곡 및 불균형 심화 |
| 핵심 대응책 | 신규 분포 데이터 추가 수집 및 재학습 | 모델 아키텍처 변경, 목적함수 재정의 | 리샘플링, 클래스 가중치 조정 및 재학습 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 계절성 및 일시적 프로모션에 따른 분포 경보 오탐 | 요일/시간대별 동적 기준선(Dynamic Baseline) 및 문맥 필터링 적용 | 불필요한 알림 피로 감축 및 실제 이상 드리프트 선별 |
| 상류 데이터 파이프라인 오류(단위 변환, 결측)로 인한 왜곡 | 입력 데이터 무결성 검증(Great Expectations) 선행 수행 | 데이터 품질 사고와 실제 분포 변화의 명확한 분리 |
| 입력 분포 변화($P(X)$) 발생 시 무조건적 자동 재학습 수행 | 드리프트 심각도(PSI)와 지연 라벨 성능 저하 상관관계 입증 후 CT 트리거 | 불필요한 GPU 학습 비용 낭비 방지 및 안정적 모델 운영 |
| 수백 개 피처에 대한 개별 검정 시 발생하는 다중 검정 오류 | 본페로니 교정(Bonferroni Correction) 또는 피처 중요도 가중치 부여 | 핵심 피처 중심의 신뢰도 높은 드리프트 탐지 보장 |

## Ⅶ. 결론

- **기술 위상/발전**: 정답 라벨 획득이 지연되는 현실의 머신러닝 환경에서 모델의 침묵하는 성능 저하를 방어하는 MLOps 관측성(Observability)의 핵심 선행 지표 표준으로 확립되었으며, 최근에는 텍스트 및 이미지 임베딩 공간의 벡터 드리프트 모니터링으로 확장 중
- **실무 적용/통제**: Evidently, Whylabs 등 전문 도구를 활용하여 피처 유형별 통계 검정을 자동화하고, 동적 기준선 및 데이터 품질 검증을 결합한 지능형 재학습 파이프라인 구축 필요
