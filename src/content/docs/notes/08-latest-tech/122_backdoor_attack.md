## Ⅰ. 개요

- **정의**: AI 모델의 학습 데이터나 가중치에 특정 트리거(Trigger: 픽셀 패치, 특정 단어, 워터마크 등)와 표적 레이블 간의 상관관계를 몰래 주입하여, 평상시 정상 입력에는 높은 정확도를 유지하다가 트리거가 포함된 입력 시에만 공격자가 지정한 악성 행동을 수행하도록 조작하는 트로이목마 공격
- **배경 및 필요성**: 오픈소스 허브(Hugging Face)를 통한 사전학습 모델 다운로드와 외부 위탁 파인튜닝이 보편화됨에 따라, 일반적인 벤치마크 테스트로는 식별할 수 없는 조건부 악성 행동(Conditional Malicious Behavior)이 모델 공급망을 통해 실환경에 침투하므로 모델 내부 가중치 무결성 및 트리거 역공학 탐지 기술 필수

## Ⅱ. 특징

- 정상 입력 시 99% 이상의 정상 정확도(Clean Accuracy)를 유지하여 일반 기능 테스트를 완벽히 우회
- 공격자가 설계한 트리거 패턴이 감지되는 순간 높은 공격 성공률(ASR: Attack Success Rate)로 표적 오분류 유발
- 데이터 레벨 변조(Data Poisoning)뿐 아니라 모델 파라미터 직접 변조(Weight Poisoning)를 통해서도 은밀한 삽입 가능

## Ⅲ. 구조 및 구성요소

```text
Backdoor_Defense_Architecture
├── Trigger_Inversion (뉴럴 클렌즈 기반 잠재적 트리거 역최적화)
├── Activation_Clustering (정상 입력과 트리거 입력 간 내부 뉴런 활성화 분석)
├── Fine_Pruning (백도어 반응 의심 뉴런 가지치기 및 클린 파인튜닝)
└── Model_Attestation (모델 계보 검증 및 암호학적 디지털 서명 확인)
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 세부 항목 | 핵심 역할 |
|:---|:---|:---|
| 트리거 역추론기 | Neural Cleanse, 최적 섭동 벡터 탐색 | 각 클래스별로 레이블을 전이시키는 최소 크기 트리거 패턴을 역공학하여 이상치 탐지 |
| 활성화 군집 분석기 | Activation Clustering, STRIP 섭동 분석 | 은닉층 뉴런의 활성화 분포를 군집화하여 단일 클래스 내 이질적 활성화 집단 식별 |
| 모델 정화 모듈 | Fine-Pruning, 지식 증류 재학습 | 트리거에만 반응하는 비활성/악성 뉴런을 잘라내고 정상 데이터로 미세 조정하여 백도어 무력화 |
| 모델 증명 시스템 | 모델 체크포인트 해시, Model Card 감사 | 사전학습 모델의 출처, 학습 파이프라인, 서명 무결성을 전수 검증하여 비인가 모델 차단 |

## Ⅳ. 흐름도

```text
[사전학습 모델 수신 및 서명 검증] (① 모델 공급망 출처 및 암호학적 해시 확인)
│
▼
[정상 데이터셋 기반 기준 성능 평가] (② Clean Accuracy 측정 및 표준 태스크 수행 검증)
│
▼
[뉴럴 클렌즈 기반 잠재 트리거 역공학] (③ 클래스별 최소 섭동 크기 $L_1$ Norm 산출 및 이상치 탐색)
│
▼
[백도어 뉴런 식별 및 프루닝 정화] (④ 비정상 활성화 뉴런 제거 및 클린 데이터 기반 미세 조정)
│
▼
[변형 트리거 ASR 검증 및 배포 승인] (⑤ 공격 성공률이 임계값 이하로 감소했는지 확인 후 배포)
```

- 분기 결과: 역최적화 이상치 검사 및 프루닝 후 공격 성공률(ASR)이 안전 기준(1% 미만)으로 억제되면 배포를 승인하고, 백도어 제거 불가 시 모델을 폐기하고 클린 데이터 재학습 수행

## Ⅴ. 종류 및 비교

| 구분 | 라벨 변조 백도어 (BadNets) | 클린 라벨 백도어 (Clean-Label) | 가중치 직접 변조 (Weight Poisoning) |
|:---|:---|:---|:---|
| 변조 대상 | 학습 데이터의 입력(트리거 추가) + 라벨(타깃 변경) | 학습 데이터의 입력만 변조 (라벨은 원본 유지) | 모델 파라미터(Weight) 또는 계산 그래프 직접 수정 |
| 은닉성 수준 | 낮음 (데이터 라벨 검수 시 이상 샘플 노출) | 높음 (사람 검수 시 정상 데이터 및 라벨로 판정) | 극도로 높음 (학습 데이터셋 검사로는 탐지 불가능) |
| 요구 권한 | 훈련 데이터셋 주입 및 라벨 조작 권한 | 훈련 데이터셋 주입 권한 (특징 공간 미세 섭동) | 훈련 파이프라인 코드, 컴파일러, 가중치 체크포인트 쓰기 권한 |
| 주요 탐지 기법 | 데이터 라벨 검증, 단순 이상치 필터링 | 특징 공간 스펙트럼 분석, 활성화 클러스터링 | 모델 가중치 역공학(Neural Cleanse), 메모리 해시 검증 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 정상 정확도 은닉으로 인한 일반 QA 테스트 기반 백도어 탐지 실패 | 트리거 역추론(Neural Cleanse) 및 엔트로피 섭동 분석(STRIP) 도입 | 잠재적 백도어 트리거의 수학적 검출 및 ASR 정밀 평가 |
| 고정된 트리거 패치 검사를 우회하는 동적·자연어 시맨틱 트리거 | 다각도 섭동 주입 및 입력 정규화(Autoencoder 재구성) 전처리 적용 | 입력 단계에서 트리거 패턴을 교란하여 백도어 발동 무력화 |
| 제3자 오픈소스 모델 가중치에 이미 삽입된 백도어 위협 | 신뢰 가능한 클린 데이터셋 기반 Fine-Pruning 및 지식 증류 재학습 | 원본 모델의 정상 성능을 유지하면서 백도어 뉴런 완전 소멸 |

## Ⅶ. 결론

- **기술 위상/발전**: 정상 입력에서는 정상 동작을 위장하다가 특정 트리거에서만 치명적 오작동을 유발하는 **AI 모델 공급망 및 파운데이션 모델 생태계의 최고 은밀한 보안 위협**
- **실무 적용/통제**: 외부 사전학습 모델 도입 시 **출처 암호학적 증명**을 의무화하고, 배포 전 **뉴럴 클렌즈 기반 트리거 역공학 및 Fine-Pruning 정화**를 거치는 무결성 검증 게이트웨이 확립 필요
