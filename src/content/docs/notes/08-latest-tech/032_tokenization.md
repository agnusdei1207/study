## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **토큰화(Tokenization)**: 원문 문자열을 모델 어휘에 정의된 토큰 조각으로 나누고 정수 ID 열로 변환하는 과정.
- **토큰 식별자(Token Identifier, Token ID)**: 모델 어휘의 각 토큰에 대응하여 신경망 입력으로 사용하는 정수 식별자로 정의된다.

</details>

- 정의/개념: 문자열을 어휘 조각과 Token ID로 바꾸는 **토큰화**
- 배경/필요성: 자연어 텍스트를 신경망에 입력할 때 공백 기준 단어 단위 토큰화는 어휘 사전의 기하급수적 팽창과 미등록어(OOV: Out-of-Vocabulary) 처리 불가 문제를 야기하고, 문자 단위 토큰화는 시퀀스 길이가 극단적으로 길어져 트랜스포머의 $O(N^2)$ 어텐션 연산 부하를 폭증시키는 이중 병목이 발생함에 따라, 텍스트 말뭉치의 통계적 빈도에 기반하여 빈출 단어는 단일 토큰으로, 희귀어는 더 작은 의미 조각으로 가변 분절하는 서브워드(Subword) 토큰화(Tokenization: BPE, WordPiece, Byte-level BPE 등) 알고리즘을 도입하여 **어휘 사전 크기(Vocabulary Size)와 시퀀스 길이 간의 최적 트레이드오프 달성, 미등록어(OOV) 없는 완전한 텍스트 표상 및 다국어 지원, 바이트 단위 폴백을 통한 데이터 무손실 인코딩 체계 확립**을 달성할 필요

#### 한줄 요약
- **어휘 조각•Token ID**의 크기를 키우면 시퀀스는 짧아지지만 임베딩 표와 미등록어 위험이 커지므로, 어휘 크기는 연산 길이와 표현 손실을 맞바꾸는 설계 변수다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **어휘(Vocabulary)**: 모델이 직접 표현하고 생성할 수 있는 토큰과 ID의 정의 집합.
- **서브워드(Subword)**: 단어보다 작지만 반복되는 형태나 의미를 보존하는 가변 길이 문자열 조각이다.
- **미등록어(Out-of-Vocabulary, OOV)**: 어휘에 완전한 형태로 존재하지 않아 더 작은 조각으로 분절해야 하는 문자열로 정의된다.

</details>

- **분절 경계**: 정규화•사전 분절•학습 규칙으로 결정
- **미등록어 완화**: 희귀어를 서브워드 조각으로 표현
- **어휘 절충**: 큰 어휘는 토큰 감소•매개변수 증가

#### 한줄 요약
- **어휘 크기•토큰 수•매개변수** 비용 절충

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **유니코드 정규화(Unicode Normalization)**: 동일 문자의 여러 코드 조합을 일관된 문자열로 맞추는 처리이다.
- **바이트 페어 인코딩(Byte Pair Encoding, BPE)**: 말뭉치에서 자주 함께 나타나는 문자•토큰 쌍을 반복 병합하여 서브워드 어휘를 만드는 알고리즘.
- **스페셜 토큰(Special Token)**: 시작•종료•패딩•역할 구분에 사용하는 특수 ID이다.

</details>

```text
[토큰화(Tokenization) 파이프라인]
├── [전처리 및 정규화기 (Normalizer)]
│   ├── 유니코드 정규화 (NFC/NFKC 정규화)
│   └── 공백·특수문자 표준화 처리
├── [사전 분절기 (Pre-Tokenizer)]
│   ├── 정규표현식 및 공백 기반 1차 분절
│   └── 어절 및 구두점 경계 식별
├── [서브워드 모델 (Subword Model)]
│   ├── 바이트 페어 인코딩 (BPE / BBPE)
│   └── 어휘 사전 매칭 (WordPiece / Unigram)
└── [식별자 매퍼 및 디코더 (ID Mapping & Decoder)]
    ├── 서브워드 토큰 ↔ 정수 ID 매핑
    ├── 특수 토큰(BOS, EOS, PAD) 주입
    └── 출력 Token ID 텍스트 역변환
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 토큰화 파이프라인의 처리 계층 및 세부 컴포넌트 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 정규화기 | 유니코드 정규화(NFKC 등) 및 일관된 공백 표기 정책 적용 |
| 사전 분절기 | 공백, 구두점 및 정규식 규칙으로 서브워드 분절 전 초기 경계 분리 |
| 서브워드 모델 | BPE/WordPiece 알고리즘으로 빈출 조각 탐색 및 미등록어(OOV) 분절 |
| 식별자 매퍼 | 분절된 문자열 조각 및 특수 토큰(BOS/EOS)을 고유 정수 ID로 매핑 |
| 복호기·디코더 | 생성된 Token ID 시퀀스를 원래의 자연어 문자열로 무손실 복원 |

#### 한줄 요약
- **정규화•분절•서브워드•ID 매핑•복호** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **사전 분절(Pre-tokenization)**: 공백•구두점•언어 규칙으로 서브워드 탐색 전에 기본 문자열 경계를 만드는 과정이다.
- **식별자 매핑(Identifier Mapping, ID Mapping)**: 문자열 조각과 제어 기호를 정수 식별자에 대응시키는 과정이다.
- **유니코드•공백 정규화**: 학습•운영에 동일 표기 정책을 적용하는 절차이다.
- **초기 문자열 경계 분절**: 공백•구두점•언어 규칙으로 경계를 만드는 절차이다.
- **BPE 서브워드 분절**: BPE 어휘에서 문자열 조각을 탐색하는 절차이다.
- **토큰•특수 ID 대응**: 조각•제어 기호를 정수 ID에 매핑하는 절차이다.

</details>

```text
[원문 텍스트 입력]
       │
       ▼
[유니코드 및 공백 정규화] (① NFKC 정규화 및 공백/제어문자 표준화)
       │
       ▼
[사전 분절 (Pre-tokenization)] (② 공백 및 정규표현식 기반 1차 단어/구두점 분리)
       │
       ▼
[서브워드 알고리즘 분절] (③ BPE/WordPiece 사전 매핑을 통한 최적 어휘 조각화)
       │
       ▼
[정수 Token ID 매핑 및 특수 토큰 주입] (④ 어휘 사전 인덱스 변환 및 BOS/EOS/PAD 결합)
```

- 분기 결과: 정수 텐서 시퀀스가 모델의 임베딩 룩업 테이블(Embedding Lookup Table)로 전달되어 입력 벡터화 완료

#### 한줄 요약
- **학습•운영 분절 규칙 일치** 기반 ID 의미 보존

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **단어 단위 토큰화**: 단어 전체를 한 ID로 표현해 토큰열은 짧지만 어휘•미등록어가 늘어나는 방식이다.
- **서브워드 단위 토큰화**: 빈번한 문자열 조각을 가변 길이로 사용하여 어휘 크기와 토큰 수를 절충하는 방식이다.
- **문자•바이트 단위 토큰화**: 입력을 문자•바이트로 분해해 미등록어를 없애지만 토큰열이 길어지는 방식이다.

</details>

- **단어•서브워드•문자 토큰화** 활용 어휘•미등록어로 구분

| 구분 | 단어 단위 | 서브워드 단위 | 문자•바이트 단위 |
|:---|:---|:---|:---|
| 적용 기준 | 제한 어휘•명확한 단어 경계 | 범용•다국어 모델 | 미지 문자열•어휘 최소화 |
| 핵심 특징 | 단어별 직접 ID 대응 | 빈번 문자열의 가변 길이 조각화 | 모든 입력의 기본 단위 분해 |
| 한계 | 큰 어휘•미등록어 발생 | 말뭉치 편향•분절 품질 의존 | 토큰열 증가•문맥 비용 확대 |

#### 한줄 요약
- 범용은 **서브워드**, 미지 문자열은 **문자•바이트** 단위

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **토크나이저 버전 고정**: 학습•운영의 정규화•어휘•ID 파일과 버전을 명시하는 통제이다.
- **복원율**: Token ID를 복호했을 때 원문 정보•표기가 보존되는 정도이다.
- **특수 토큰 주입**: 사용자 문자열이 제어 토큰으로 해석되어 프롬프트 역할이나 경계를 바꾸는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 학습-운영 간 정규화 정책 불일치 | 토크나이저 아티팩트 및 라이브러리 버전 고정 | 토큰 ID 매핑 재현성 및 일관성 확보 |
| 모델 임베딩과 어휘 ID 불일치 | 토크나이저 어휘 해시 및 특수 토큰 ID 정합성 검증 | 잘못된 토큰 해석 및 추론 붕괴 원천 차단 |
| 한국어 등 다국어의 과도한 분절 | Byte-fallback BPE 적용 및 Fertility 지표 모니터링 | 토큰 수 폭증 완화 및 API 비용 절감 |
| 사용자 입력 내 특수 토큰 주입 공격 | 원시 제어 토큰 이스케이프 및 입력 살균 필터 적용 | 시스템 프롬프트 탈취 및 경계 탈출 방어 |

#### 한줄 요약
- **토큰 수•복원율•ID 일치** 기반 품질•비용 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **복호(Decoding)**: 생성된 Token ID 열을 문자열로 되돌리는 처리이다.

</details>

- **기술 위상/발전**: 비정형 텍스트를 모델 연산 공간인 정수 텐서로 변환하는 **LLM 파이프라인의 필수 관문**이며, 다국어 처리 효율(Fertility)을 개선한 대규모 서브워드 사전으로 확장
- **실무 적용/통제**: 학습-서빙 간 토크나이저 불일치를 방지하기 위해 버전을 엄격히 고정하고, **특수 토큰 인젝션 필터링**과 언어별 분절 효율 검증을 필수로 수행

#### 한줄 요약
- **언어 특성•미지 문자열 비중** 대상 따라 분절 단위 결정
