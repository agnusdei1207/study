## Ⅰ. 개요

- **정의**: 키워드 빈도 기반의 희소 검색(BM25/Sparse)과 의미론적 임베딩 기반의 밀집 검색(Dense Vector)을 병렬로 수행하고, 그 결과를 상호 순위 융합(RRF) 또는 가중 점수 합산으로 결합하는 검색 기법
- **배경 및 필요성**: 밀집 벡터 검색의 고유명사, 제품 모델명, 전문 용어 등 정확 키워드 매칭 누락 한계와 전통적 희소 검색의 동의어 및 문맥 파악 불가 한계를 상호 보완하여, 검색 회수율(Recall)과 정밀도(Precision)를 동시에 극대화하기 위해 도입

## Ⅱ. 특징

![RRF에서 검색 순위가 낮아질수록 감소하는 개별 기여 점수](/study/diagrams/rrf-rank-score.svg)

- **RRF(Reciprocal Rank Fusion) 수학적 원리**: $\text{RRF Score}(d \in D) = \sum_{m \in M} \frac{1}{k + r_m(d)}$ (통상 $k=60$) 수식을 통해 검색기별 점수 스케일 차이에 왜곡되지 않는 순위 기반 통합 점수 산출
- **희소-밀집 상호 보완**: 희소 검색의 정확한 어휘 매칭과 밀집 검색의 심층 의미론적 맥락 탐색을 동시 충족
- **2단계 검색 아키텍처 (Two-Stage Retrieval)**: 1단계 하이브리드 검색으로 대규모 후보군(Top-50~100)을 고속 추출하고, 2단계 신경망 재순위화(Reranker)로 상위 정밀 청크(Top-3~5) 압축 선별

## Ⅲ. 구조 및 구성요소

```text
[Hybrid Search 아키텍처]
├── [이중 색인 계층]
│   ├── [희소 역색인 (Sparse / BM25)]
│   └── [밀집 벡터 색인 (Dense / HNSW)]
├── [융합 및 정제 계층]
│   ├── [상호 순위 융합기 (RRF / Score Fusion)]
│   └── [후보 중복 제거기 (Deduplicator)]
└── [최종 재순위 계층]
    └── [교차 인코더 재순위기 (Cross-Encoder Reranker)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| 희소 역색인 | 역색인(Inverted Index) 기반 키워드 빈도 및 희귀도(BM25) 계산 |
| 밀집 벡터 색인 | 고차원 임베딩 벡터 간 코사인/유클리디안 거리 기반 근사 최근접 이웃(ANN) 탐색 |
| 상호 순위 융합기 | 점수 척도 차이를 극복하는 RRF 수식 기반 순위 역수 합산 및 통합 정렬 |
| 후보 중복 제거기 | 다중 검색 엔진에서 동시 추출된 중복 문서 ID를 병합하고 유일 후보군 구성 |
| 교차 인코더 재순위기 | 질의와 후보 청크 전체를 동시에 입력받아 최종 의미론적 관련성 점수 산출 |

## Ⅳ. 흐름도

```text
[하이브리드 검색 흐름] (진입: 사용자 입력 질의)
│
▼
[병렬 1차 검색] (① 질의 토큰화 후 BM25 키워드 검색과 Dense 벡터 ANN 검색 병렬 수행)
│
▼
[후보군 수집] (② 희소 검색 결과(Top-k)와 밀집 검색 결과(Top-k) 목록 추출)
│
▼
[RRF 순위 융합] (③ 각 문서별 1/(k+r) 순위 역수 합산 및 중복 제거)
│
▼
[Cross-Encoder 재정렬] (④ 상위 통합 후보들을 신경망 재순위 모델에 입력하여 정밀 점수화)
│
▼
[Top-N 선별] (⑤ 최종 관련성 상위 N개 청크를 RAG 생성기 컨텍스트로 전달)
│
▼
[완료] (반환: 키워드 정확성과 의미 맥락이 모두 확보된 검색 결과 반환)
```

- 분기 결과: 정밀 어휘 매칭과 의미 유사성이 고르게 요구될 경우 **RRF 기반 5:5 융합**을 적용하고, 코드/오류번호 질의 시 **희소 검색 가중치 상향**으로 적응 제어함

## Ⅴ. 종류 및 비교

| 구분 | 하이브리드 검색 (Hybrid) | 희소 검색 (BM25) | 학습형 희소 검색 (SPLADE) | 밀집 검색 (Dense Vector) |
|:---|:---|:---|:---|:---|
| 핵심 메커니즘 | 희소 + 밀집 융합 (RRF) | 역색인 단어 빈도 일치 | LLM 기반 단어 확장 가중치 | 임베딩 벡터 공간 의미 유사도 |
| 키워드 정확도 | 매우 우수 (100% 매칭) | 완벽 (정확 단어 추출) | 우수 (확장 단어 포함) | 취약 (고유명사/숫자 누락) |
| 의미론적 맥락 | 매우 우수 (문맥 반영) | 취약 (동의어 누락) | 우수 (문맥상 어휘 확장) | 완벽 (유사 의미 포괄) |
| 인프라 복잡도 | 높음 (이중 색인 및 융합) | 낮음 (경량 역색인 엔진) | 중간 (인코더 및 역색인) | 중간 (벡터 DB 인프라 필요) |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 엔진 간 검색 점수 척도 차이에 따른 한쪽 편향 | 점수 기반 합산 대신 순위 기반 RRF(k=60) 알고리즘 적용 | 점수 왜곡 없는 공정하고 강건한 순위 결합 |
| 중복 문서 반환으로 인한 최종 컨텍스트 낭비 | 문서 고유 ID 기반 해시 중복 제거 및 메타데이터 필터링 | 후보 다양성 확보 및 LLM 프롬프트 공간 절약 |
| 이중 검색 실행에 따른 레이턴시 증가 | 비동기 병렬 검색(Async Parallel Retrieval) 및 캐싱 구현 | 검색 응답 시간 40% 이상 단축 |

## Ⅶ. 결론

- **기술 위상/발전**: 단일 검색 모델의 구조적 한계를 보완하고 검색 회수율과 정밀도를 동시에 달성한 **Hybrid Search 기술**은 최신 엔터프라이즈 RAG 시스템의 사실상 표준 파이프라인으로 정착
- **실무 적용/통제**: **BM25 + Dense Vector의 RRF 융합**을 기본 엔진으로 채택하고, **Cross-Encoder 재순위화**를 결합하여 최종 RAG 답변 품질을 극대화해야 함
