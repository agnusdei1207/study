## Ⅰ. 개요

- **정의**: 협조적 게임 이론(Cooperative Game Theory)의 섀플리 값(Shapley Value)을 기반으로, 기준 기대값(Base Value)과 개별 예측값 간의 차이를 각 입력 특성별 기여도로 분해하여 수학적 공정 배분을 보장하는 가산 특성 기여도(Additive Feature Attribution) XAI 기법
- **배경 및 필요성**: 기존 특성 중요도(Gain, Permutation) 기법은 특성 간 상관관계나 트리 분할 순서에 따라 기여도가 왜곡되고 가산 일관성(Consistency)을 보장하지 못하는 이론적 한계가 존재함에 따라, 게임 이론의 4대 공리(효율성, 대칭성, 더미, 가산성)를 수학적으로 만족하며 모든 특성 연합(Coalition)의 한계 기여도를 공정하게 배분하는 SHAP 프레임워크 도입이 필수적임

## Ⅱ. 특징

![SHAP 특징 기여의 가산 원리](/study/diagrams/shap-additive-contribution.svg)

- 모든 가능한 특성 부분집합 순서의 한계 기여도를 가중 평균한 **섀플리 공정 배분**
- 기본값과 각 특성 기여도의 총합이 정확히 최종 예측값과 일치하는 **가산 완전성 (Local Additivity)**
- 트리 전용 초고속 알고리즘(TreeSHAP)과 범용 커널 모델(KernelSHAP)을 아우르는 **통합 프레임워크**

## Ⅲ. 구조 및 구성요소

```text
[SHAP Architecture]
├── [모델 및 배경 입력 계층]
│   ├── [대상 블랙박스 모델 (Target Model)]
│   └── [배경 분포 및 마스커 (Background Masker)]
├── [가치 및 기여도 계산 계층]
│   ├── [특성 연합 가치 계산기 (Coalition Evaluator)]
│   └── [섀플리 커널 계산기 (Shapley Engine)]
└── [해석 결과 시각화 계층]
    ├── [단일 인스턴스 설명 (Force / Waterfall Plot)]
    └── [전역 특성 요약 (Summary / Beeswarm Plot)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 | 상세 설명 |
|:---|:---|:---|
| 대상 블랙박스 모델 | 특성 조합별 예측값 산출 | 딥러닝, 트리 앙상블 등 입력 특성 연합에 따른 예측 확률 반환 |
| 배경 분포 및 마스커 | 부재 특성의 대체값 제공 | 특정 특성이 제외되었을 때 이를 대체할 기준 데이터셋 및 마스킹 수행 |
| 특성 연합 가치 계산기 | 부분집합별 기대 출력 평가 | 특성 부분집합 $S$가 주어졌을 때의 조건부 기댓값 $f(S)$ 산출 |
| 섀플리 커널 계산기 | 한계 기여도 가중 평균 계산 | $\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F|-|S|-1)!}{|F|!} [f(S \cup \{i\}) - f(S)]$ 계산 |
| 단일 인스턴스 설명 | 개별 예측에 대한 양/음의 기여도 표출 | 기준값을 중심으로 예측값을 높이거나 낮춘 특성들을 워터폴/포스 플롯으로 표현 |
| 전역 특성 요약 | 전체 데이터셋에 대한 영향력 집계 | 모든 데이터 인스턴스의 섀플리 값 분포와 영향도 방향성을 요약 플롯으로 시각화 |

## Ⅳ. 흐름도

```text
[설명 대상 및 배경 데이터 설정] (① 특정 입력 인스턴스 x 및 기준 배경 데이터셋 B 지정)
  │
  ▼
[특성 연합 부분집합 생성] (② 전체 특성 집합 F에 대해 포함/제외 가능한 연합 조합 구성)
  │
  ▼
[연합별 모델 예측값 산출] (③ 제외된 특성을 배경값으로 마스킹하고 모델 출력 f(S) 획득)
  │
  ▼
[특성별 한계 기여도 계산] (④ 특성 i의 추가 전후 예측값 차이 [f(S ∪ {i}) - f(S)] 산출)
  │
  ▼
[섀플리 가중 평균 집계] (⑤ 연합 크기에 따른 가중치를 적용하여 최종 섀플리 값 phi_i 도출)
  │
  ▼
[가산 완전성 검증 및 시각화] (⑥ Base Value + sum(phi_i) = f(x) 일치 검증 후 워터폴 차트 출력)
```

- 분기 결과: 트리 앙상블 모델(XGBoost, LightGBM)은 다항식 시간 $O(TLD^2)$으로 연산하는 TreeSHAP 경로로 직행하고, 임의의 블랙박스 API 모델은 표본 추출 기반 KernelSHAP 경로로 분기함

## Ⅴ. 종류 및 비교

| 구분 | TreeSHAP | KernelSHAP | DeepSHAP |
|:---|:---|:---|:---|
| 적용 대상 | 의사결정나무 및 앙상블 (RF, XGBoost) | 임의의 모든 블랙박스 모델 (Model-Agnostic) | 딥러닝 심층 신경망 (TensorFlow, PyTorch) |
| 핵심 메커니즘 | 트리 구조 내 분기 경로를 최적화하여 직접 탐색 | 가중 선형 회귀를 이용한 섀플리 값 근사 | 딥러닝 역전파(DeepLIFT)와 섀플리 가산성 결합 |
| 계산 복잡도 | $O(TLD^2)$ (초고속 다항식 시간) | $O(2^M)$ 또는 표본 수 비례 (지수적/느림) | 역전파 기반 고속 근사 연산 |
| 설명 정밀도 | 수학적으로 정확한 섀플리 값 도출 | 표본 수에 따른 근사 추정치 | 심층 신경망에 특화된 고정밀 근사치 |
| 실무 활용 | 정형 데이터 금융 심사, 위험도 분석 표준 | 다양한 비정형 API 모델의 범용적 설명 | 이미지 객체 검출, 자연어 모델 설명 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대표성 없는 배경 데이터로 인한 기준값 왜곡 | 도메인 특성을 반영한 대표 k-평균(k-Means) 군집 중심점 표본 구성 | 기준값(Base Value) 왜곡 방지 및 기여도 타당성 확보 |
| 높은 특성 간 상관관계로 인한 기여도 분산 | 상호작용 지수(SHAP Interaction Value) 산출 및 상관 변수 사전 군집화 | 다중공선성에 따른 개별 변수 기여도 왜곡 차단 |
| 고차원 데이터에서 KernelSHAP 연산 병목 | TreeSHAP 우선 적용 또는 순열 샘플 수 제한 및 주요 특성 선별 | 실시간 서비스 응답성 보장 및 시스템 부하 최소화 |

## Ⅶ. 결론

- **기술 위상/발전**: 협조 게임 이론의 공리적 체계를 머신러닝에 성공적으로 결합하여 특성 기여도 배분의 수학적 유일성과 공정성을 보장한 **설명 가능한 AI(XAI) 분야의 최고 권위 표준 알고리즘**으로 자리매김
- **실무 적용/통제**: 트리 모델에는 고속 TreeSHAP을 기본 적용하고 적절한 배경 데이터셋을 정밀 검증하며, 개별 워터폴 플롯과 전역 비스웜 플롯을 병행하여 **설명 신뢰성**과 **전사 모델 거버넌스 투명성**을 완성 필요
