## Ⅰ. 개요

- **정의**: AI 모델의 예측 결과(출력 신뢰도 점수, 로짓)나 그래디언트를 역추적하여 경사하강법 기반 역최적화(Gradient Ascent) 및 생성 모델(GAN)을 통해 모델 학습에 사용된 원본 학습 데이터(얼굴 사진, 의료 기록 등)를 시각적·통계적으로 복원해내는 프라이버시 침해 공격
- **배경 및 필요성**: 딥러닝 모델이 과적합되거나 특정 학습 샘플을 과도하게 암기(Memorization)한 경우, 블랙박스 API 출력 점수만으로도 특정 개인의 민감 바이오 정보가 재식별되어 개인정보보호법(GDPR, PIPA) 위반을 초래하므로 모델 역전 방어 대책 필수

## Ⅱ. 특징

- 대상 인물의 클래스 예측 확률을 극대화하는 방향으로 더미 입력을 반복 갱신하는 역최적화 알고리즘 활용
- 공격자의 사전 배경지식(Auxiliary Data) 및 생성적 적대 신경망(GAN)을 결합하여 복원 이미지의 해상도와 식별성 향상
- 차등 프라이버시 학습(DP-SGD), 출력 신뢰도 버림(Rounding), 라벨 전용 반환을 통한 정보 누출 채널 차단

## Ⅲ. 구조 및 구성요소

```text
Model_Inversion_Defense_Architecture
├── Privacy_Preserving_Training (DP-SGD 및 정규화 기반 과적합 방지)
├── Observation_Limiter (출력 신뢰도 양자화 및 Top-1 라벨 변환)
├── Inversion_Detection (동일 클래스 집중 질의 시퀀스 탐지)
└── Reconstruction_Auditor (모의 역전 공격 기반 데이터 노출도 정기 감사)
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 세부 항목 | 핵심 역할 |
|:---|:---|:---|
| 프라이버시 학습기 | DP-SGD, Dropout, Weight Decay, 규제화 | 특정 데이터 포인트 암기 방지 및 일반화 성능 확보로 역추론 근거 제거 |
| 관측 채널 통제기 | Confidence Truncation, Top-K 마스킹 | 상세 소수점 확률을 반올림하거나 은닉하여 역최적화 그래디언트 차단 |
| 이상 질의 탐지기 | 입력 이미지 변형 추적, 계정별 질의 편중 감사 | 단시간 내 특정 인물 클래스를 집중 타깃팅하는 역전 쿼리 시퀀스 식별 |
| 복원 감사 모듈 | GMI(Generative Model Inversion) 모의 침투 | 배포 전 모델을 대상으로 실제 역전 공격을 수행하여 얼굴 복원 가능성 평가 |

## Ⅳ. 흐름도

```text
[공격자의 초기 더미 입력 생성] (① 노이즈 이미지 또는 평균 얼굴 벡터 생성)
│
▼
[모델 질의 및 출력 신뢰도 획득] (② 타깃 클래스 확률 점수 수집 및 손실 계산)
│
▼
[경사 상승법 기반 입력 역최적화] (③ 확률 점수를 최대화하는 방향으로 입력 픽셀 그래디언트 역전파)
│
▼
[출력 점수 라운딩 및 방어 적용] (④ 상세 점수 대신 Top-1 라벨 반환으로 역전파 차단)
│
▼
[복원 실패 및 개인정보 보호] (⑤ 그래디언트 소실로 특정 개인 식별 이미지 복원 원천 무력화)
```

- 분기 결과: 모델 출력 점수가 거칠게 마스킹되어 그래디언트가 소실되면 공격이 실패로 끝나 데이터가 보호되고, 상세 점수가 누출되면 반복 최적화를 통해 원본 특징이 복원되므로 즉시 점수 마스킹 적용

## Ⅴ. 종류 및 비교

| 구분 | 모델 역전 공격 (Model Inversion) | 멤버십 추론 공격 (Membership Inference) | 모델 추출 공격 (Model Extraction) |
|:---|:---|:---|:---|
| 공격 목적 | 학습 데이터셋의 원본 특징(얼굴, 의료) 복원 | 특정 데이터가 훈련에 포함되었는지 여부 판정 | 원본 모델의 기능과 결정 경계를 복제한 대체 모델 획득 |
| 공격 결과물 | 시각적 복원 이미지, 속성 복원 데이터 | 이진 판정 결과 (포함 여부: Yes/No) | 기능적으로 대등한 복제 신경망 모델 |
| 핵심 활용 정보 | 클래스별 출력 신뢰도 점수(확률 벡터) | 예측 신뢰도 분포의 분산 및 손실값 차이 | 입력-출력 질의응답 쌍의 대규모 데이터셋 |
| 주요 방어 기술 | DP-SGD 학습, 신뢰도 반올림/은닉 | 차등 프라이버시(DP), 과적합 완화 | 질의 속도 제한, 하드 라벨링, 워터마킹 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 고정밀 출력 확률 점수로 인한 픽셀 단위 그래디언트 역추적 | 신뢰도 점수 소수점 이하 절삭(Rounding) 및 Top-1 클래스만 반환 | 역최적화에 필요한 수학적 기울기 정보 완전 제거 |
| 학습 데이터에 과적합되어 특정 환자/인물의 고유 특징 암기 | 차등 프라이버시(DP-SGD) 적용 및 가중치 감쇠(Weight Decay) 강화 | 개별 표본의 모델 영향력 제한 및 데이터 암기 원천 차단 |
| 상용 배포 후 제3자에 의한 모델 역전 프라이버시 침해 인지 불가 | 배포 파이프라인 내 GMI 기반 역전 모의 해킹(Auditing) 의무화 | 시각적 재식별 가능성을 사전에 계량화하여 안전 배포 보장 |

## Ⅶ. 결론

- **기술 위상/발전**: AI 모델의 예측 결과로부터 원본 학습 데이터의 민감 개인정보를 시각적으로 복원해내는 공격을 방어하는 **프라이버시 보존 머신러닝(PPML) 및 AI 개인정보 보호의 필수 핵심 표준**
- **실무 적용/통제**: 모델 훈련 시 **DP-SGD를 기본 적용**하여 데이터 암기를 방지하고, 서빙 API에서는 **상세 확률 점수를 은닉(Hard Labeling)**하며, 배포 전 **역전 모의 감사(Inversion Audit)**를 수행하는 종단간 프라이버시 통제 체계 구축 필요
