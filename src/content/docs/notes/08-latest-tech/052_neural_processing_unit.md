## Ⅰ. 개요

- **정의**: 딥러닝 신경망의 대규모 행렬 곱셈 및 텐서 연산을 데이터 흐름(Dataflow) 방식으로 병렬 가속하여 전력 대 성능비(TOPS/Watt)를 극대화한 도메인 특화 프로세서(DSA).
- **배경 및 필요성**:
  - **폰 노이만 병목 극복**: 범용 CPU/GPU의 명령어 인출/해독 오버헤드와 잦은 외부 DRAM 접근으로 인한 메모리 벽(Memory Wall) 현상 해결.
  - **초저전력 엣지 구동**: 배터리 기반 모바일/온디바이스 기기에서 수 와트(W) 미만의 제한된 전력으로 고성능 AI 연산 수행.
  - **데이터 재사용성(Data Reuse) 극대화**: 시스톨릭 어레이(Systolic Array)와 대용량 온칩 SRAM 버퍼를 직접 집적하여 외부 메모리 I/O 전력 소모 최소화.

## Ⅱ. 핵심 특징

![연산 집약도에 따른 NPU 처리량 상한 개념도](/study/diagrams/npu-roofline.svg)

> 달성 처리량은 전환점 전에는 메모리 대역폭 선을, 이후에는 계산 성능 상한선을 따르는 정규화 개념도임.

- **시스톨릭 어레이(Systolic Array)**: 2D MAC(Multiply-Accumulate) 연산기 격자를 통해 데이터가 메모리를 거치지 않고 인접 셀로 직접 흘러가는 파이프라인 구조.
- **온칩 메모리 상주**: 대용량 온칩 SRAM에 가중치와 활성화를 적재하여 외부 DRAM 액세스 횟수를 획기적으로 절감.
- **양자화 하드웨어 지원**: FP16/BF16 외에도 INT8, INT4, FP8, FP4 등 저정밀도 정수 연산 회로를 집적하여 와트당 연산량 극대화.
- **전용 컴파일러 스택**: 딥러닝 그래프를 분석하여 연산자 융합(Operator Fusion)을 수행하고 NPU 하드웨어 가속기로 매핑.

## Ⅲ. 구조 및 구성요소

```text
[NPU(신경망 처리장치) 하드웨어 아키텍처]
├── [소프트웨어 스택 (Software Stack)]
│   ├── 그래프 분석 및 컴파일러 (NN Compiler)
│   └── 연산자 매핑 스케줄러 및 호스트 런타임
├── [메모리 서브시스템 (Memory Subsystem)]
│   ├── 고속 DMA 전송 엔진 (External DRAM I/O)
│   └── 대용량 온칩 SRAM 버퍼 (Weight/Activation)
├── [코어 연산 엔진 (Compute Core Engine)]
│   ├── 2D 시스톨릭 어레이 (Systolic Array)
│   ├── 다채널 MAC 병렬 곱셈 누산 유닛
│   └── 벡터/활성화 전용 함수 유닛 (SIMD/Activation)
└── [제어 및 폴백 인터페이스 (Control & Fallback)]
    ├── 하드웨어 커맨드 큐 및 동기화 제어기
    └── 미지원 연산자 호스트 CPU 폴백 인터페이스
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 NPU 하드웨어 및 소프트웨어 스택의 상위 계층과 세부 구성요소 간 계층적 포함 관계를 나타낸다.

| 구성요소 | 역할 및 세부 기능 |
|:---|:---|
| 소프트웨어 스택 | 딥러닝 그래프 분석, 타깃 하드웨어 연산자 매핑 및 분할 스케줄링 |
| 메모리 서브시스템 | 고속 DMA 텐서 전송 및 대용량 온칩 SRAM을 통한 데이터 재사용성 극대화 |
| 코어 연산 엔진 | 시스톨릭 어레이 기반 2D MAC 병렬 연산 및 벡터 비선형 활성화 처리 |
| 제어 및 폴백 | 칩 내부 커맨드 파이프라인 제어 및 NPU 미지원 연산자의 CPU 폴백 중계 |

## Ⅳ. 흐름도

```text
[신경망 모델 그래프 입력] (① 학습 완료된 모델 그래프를 NPU 전용 컴파일러에 입력)
       │
       ▼
[그래프 분할 및 연산자 융합] (② 미지원 연산자는 CPU로 격리하고 지원 연산자는 커널 융합)
       │
       ▼
[온칩 SRAM 텐서 로드] (③ DMA 엔진을 통해 가중치와 입력 데이터를 온칩 메모리에 프리페치)
       │
       ▼
[시스톨릭 어레이 MAC 연산] (④ 2D 연산 그리드 상에서 데이터 흐름 기반 병렬 행렬 곱셈 실행)
       │
       ▼
[활성화 함수 및 결과 반환] (⑤ 비선형 활성화 적용 후 미지원 CPU 폴백 결과와 결합하여 출력)
```

- 분기 결과: NPU 네이티브 연산자는 시스톨릭 어레이에서 직접 고속 완료, 미지원 특수 연산자는 호스트 CPU 폴백 인터페이스로 우회 실행 후 병합.

## Ⅴ. 종류 및 비교

| 비교 항목 | CPU (Central Processing Unit) | GPU (Graphics Processing Unit) | NPU (Neural Processing Unit) |
|:---|:---|:---|:---|
| 아키텍처 철학 | 범용 순차 처리 및 복잡한 제어 로직 | 대규모 SIMT 병렬 부동소수점 연산 | 신경망 행렬 곱셈 특화 데이터 흐름(Dataflow) |
| 전력 대 성능비 | 낮음 (Instruction Fetch/Decode 오버헤드 큼) | 중간 (수백 와트의 고전력 소모) | 최상 (와트당 수십~수백 TOPS 달성) |
| 핵심 하드웨어 유닛 | 소수 고성능 코어, 대용량 L1~L3 캐시 | 수천 개의 CUDA/스트리밍 코어, 고대역 HBM | 2D 시스톨릭 어레이 MAC 그리드, 대용량 온칩 SRAM |
| 프로그래밍 유연성 | 최상 (모든 범용 C/C++ 코드 구동) | 높음 (CUDA, OpenCL 등 표준 언어) | 제한적 (지원 연산자 세트 및 전용 컴파일러 의존) |
| 주 활용 분야 | OS 실행, 시스템 제어, 비정형 순차 로직 | 초대형 파운데이션 모델 학습 및 클라우드 서빙 | 모바일/엣지 온디바이스 AI 추론, AI 가속 카드 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 미지원 커스텀 연산자로 인한 CPU 폴백 증가 | 컴파일러 레벨 지원 연산자 분석 및 연산자 치환·융합 | 호스트-디바이스 간 PCI-e/메모리 복사 지연 차단 |
| 낮은 연산 집약도로 인한 메모리 벽 직면 | Roofline 모델 기반 커널 융합 및 온칩 SRAM 재사용 극대화 | 외부 DRAM 접근 최소화 및 최대 연산 처리량 달성 |
| 저비트 양자화(INT8/INT4) 시 정확도 손실 | 양자화 인식 훈련(QAT) 및 혼합 정밀도(Mixed-Precision) 적용 | 전력 및 속도 향상과 동시에 모델 정확도 유지 |

## Ⅶ. 결론

- **기술 위상/발전**: 범용 컴퓨팅의 전력 한계를 극복하고 AI 워크로드의 전력 대 성능비(TOPS/Watt)를 극대화하는 차세대 도메인 특화 프로세서(DSA)로 완전 정착
- **실무 적용/통제**: 컴파일러 레벨의 연산자 융합을 통해 CPU 폴백 오버헤드를 원천 차단하고, Roofline 모델 분석을 바탕으로 온칩 SRAM 데이터 상주율을 극대화하는 소프트웨어-하드웨어 협력 최적화 수행
