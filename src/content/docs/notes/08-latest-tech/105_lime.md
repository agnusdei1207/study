## Ⅰ. 개요

- **정의**: 설명하고자 하는 특정 데이터 인스턴스의 주변에 무작위 교란(Perturbation) 표본을 생성하고 거리 가중치가 적용된 해석 가능한 국소 대리 모델(Sparse Linear Surrogate)을 학습시켜 개별 예측 근거를 해석하는 모델 불가지론(Model-Agnostic) XAI 기법
- **배경 및 필요성**: 심층 신경망이나 앙상블 모델은 전역적으로 복잡한 비선형 결정 경계를 지녀 전체 해석이 불가능하며 내부 가중치에 접근할 수 없는 블랙박스 API 모델이 증가함에 따라, 특정 관심 입력의 매우 좁은 국소 영역은 선형적으로 근사할 수 있다는 가설을 바탕으로 정형, 텍스트, 이미지 데이터의 개별 예측 기여도를 신속하게 시각화하는 기술이 필수적임

## Ⅱ. 특징

- 내부 구조나 학습 알고리즘에 구애받지 않는 **모델 불가지론(Model-Agnostic)**
- 복잡한 전역 경계 대신 관심 인스턴스 근방만을 선형으로 근사하는 **국소 대리 모델링**
- 원본과의 지수 거리 커널 가중치를 적용한 **가중 최소제곱 최적화**

## Ⅲ. 구조 및 구성요소

```text
[LIME Architecture]
├── [표본 생성 계층]
│   └── [교란 표본 생성기 (Perturbation Engine)]
├── [가중치 및 예측 산출 계층]
│   ├── [지수 근접 커널 (Proximity Kernel)]
│   └── [대상 블랙박스 모델 (Target Black-box)]
└── [해석 모델 학습 계층]
    ├── [희소 선형 대리 모델 (Sparse Linear Surrogate)]
    └── [특성 중요도 시각화기 (Feature Attribution UI)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 | 상세 설명 |
|:---|:---|:---|
| 교란 표본 생성기 | 원본 주변의 변형 표본 생성 | 원본 특성값에 가우시안 노이즈 주입, 단어 마스킹, 이미지 슈퍼픽셀 가림 수행 |
| 지수 근접 커널 | 원본과의 유사도 가중치 계산 | 원본과의 유클리드/코사인 거리를 기반으로 $\pi_x(z) = \exp(-D(x,z)^2 / \sigma^2)$ 산출 |
| 대상 블랙박스 모델 | 교란 표본에 대한 예측 레이블 산출 | 생성된 수천 개 교란 표본들을 블랙박스 모델에 전달하여 예측 확률값 획득 |
| 희소 선형 대리 모델 | 거리 가중 국소 선형 회귀 학습 | 손실 함수 $L(f, g, \pi_x) + \Omega(g)$를 최소화하는 단순 선형 모델 가중치 도출 |
| 특성 중요도 시각화기 | 산출된 특성 기여도 표출 | 회귀 가중치 크기에 따라 긍정/부정 기여도를 막대그래프나 히트맵으로 시각화 |

## Ⅳ. 흐름도

```text
[설명 대상 인스턴스 선정] (① 해석하고자 하는 특정 데이터 x 입력)
  │
  ▼
[교란 표본 생성] (② 특성 마스킹 및 노이즈 주입을 통해 인스턴스 근방 표본 집합 생성)
  │
  ▼
[블랙박스 예측 레이블 획득] (③ 교란 표본들을 대상 AI 모델에 입력하여 예측 확률값 산출)
  │
  ▼
[근접도 가중치 부여] (④ 지수 커널을 적용하여 원본과 가까운 표본에 높은 가중치 할당)
  │
  ▼
[국소 선형 대리 모델 학습] (⑤ 가중 최소제곱법(WLS)을 통해 단순 선형 해석 모델 피팅)
  │
  ▼
[특성 기여도 해석 및 표출] (⑥ 학습된 선형 계수를 바탕으로 상위 주요 기여 특성 시각화)
```

- 분기 결과: 정형 데이터는 특성 섭동 경로로, 텍스트 데이터는 단어 마스킹 경로로, 이미지 데이터는 퀵시프트(QuickShift) 기반 슈퍼픽셀 가림 경로로 데이터 모달리티에 맞추어 분기 처리함

## Ⅴ. 종류 및 비교

| 국소 설명 기법 | LIME (Local Interpretable Model-agnostic) | SHAP (Kernel SHAP) |
|:---|:---|:---|
| 이론적 기반 | 국소 선형 근사 및 경험적 표본화 | 협동 게임이론의 섀플리 값 (Shapley Value) |
| 연산 복잡도 | 비교적 낮음 (빠른 국소 표본 학습) | 높음 (지수적 부분집합 조합 연산 필요) |
| 공리적 보장 | 수학적 공리 만족 보장 없음 (휴리스틱) | 효율성, 대칭성, 더미, 가산성 4대 공리 완벽 만족 |
| 설명 안정성 | 표본 무작위성에 따라 결과 편차 발생 가능 | 일관되고 재현 가능한 고정 기여도 산출 |
| 주 활용 분야 | 대규모 실시간 추론 해석 및 빠른 디버깅 | 엄밀한 법적 감사, 금융 심사 및 규제 대응 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 교란 분포 이탈에 따른 국소 충실도 저하 | 도메인 유효성 검증 기반 교란 생성 및 적정 커널 폭($\sigma$) 튜닝 | 비현실적 이상 표본 생성 차단 및 신뢰성 있는 근방 근사 |
| 무작위 표본 추출에 따른 설명 변동성 | 난수 시드(Seed) 고정 및 교란 표본 수 확대($N \ge 5,000$) | 반복 실행 시 설명 결과의 일관성 및 재현성 확보 |
| 이미지/고차원 텍스트의 연산 병목 | 슈퍼픽셀 분할 알고리즘 경량화 및 주요 특성 개수($K$) 제한 | 설명 도출 지연 시간 단축 및 실시간 서비스 연동성 보장 |

## Ⅶ. 결론

- **기술 위상/발전**: 모델 불가지론 철학을 바탕으로 임의의 블랙박스 신경망에 대한 개별 예측 해석의 실용적 표준을 제시한 **대표적인 국소 사후 설명(Local Post-hoc) 알고리즘**으로 확립
- **실무 적용/통제**: 빠른 디버깅에는 LIME을, 규제 컴플라이언스 및 엄밀한 감사에는 SHAP을 상호보완적으로 연계하고 커널 폭과 표본 수를 최적화하여 **연산 효율성**과 **설명 안정성**을 확보 필요
