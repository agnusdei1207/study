## Ⅰ. 개요

- **정의**: 복잡한 블랙박스(Black-box) 딥러닝 및 기계학습 모델의 예측 결과와 의사결정 이유를 인간이 직관적으로 이해하고 논리적으로 검증할 수 있는 형태로 해석·제공하는 기술
- **배경 및 필요성**: 심층 신경망과 대규모 언어 모델은 초인적 성능을 달성했으나 수억~수조 개 파라미터 간의 비선형 결합으로 인해 "왜 그러한 결론을 도출했는가"를 설명하지 못하는 한계가 존재함에 따라, 의료 진단, 금융 대출, 자율주행 등 고위험 의사결정에서 규제 요건(GDPR 설명요구권, EU AI Act)을 준수하고 모델 오류 및 데이터 편향을 사전에 디버깅할 수 있는 설명 가능한 AI 기술 도입이 필수적임

## Ⅱ. 특징

- 본질적 해석 모델(Intrinsic)과 외부 대리 모델을 활용한 **사후 설명(Post-hoc)의 공존**
- 단일 입력 인스턴스 중심의 **국소 설명(Local)과 모델 전체를 조망하는 전역 설명(Global)**
- 원본 모델의 예측 논리를 왜곡 없이 모사하는 **충실도(Fidelity)와 설명 안정성(Stability)**

## Ⅲ. 구조 및 구성요소

```text
[Explainable AI Architecture]
├── [설명 대상 및 범위 계층]
│   ├── [설명 대상 모델 (Target Black-box)]
│   └── [설명 범위 정의부 (Local / Global Scope)]
├── [설명 생성 엔진 계층]
│   ├── [특성 기여도 분석기 (Feature Attribution: SHAP/LIME)]
│   ├── [시각적 주의집중 맵 (Saliency Map: Grad-CAM)]
│   └── [반사실적 설명기 (Counterfactual Explainer)]
└── [해석 및 검증 계층]
    ├── [설명 산출물 시각화 (Explanation UI)]
    └── [품질 및 충실도 평가기 (Fidelity & Stability Eval)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 | 상세 설명 |
|:---|:---|:---|
| 설명 대상 모델 | 해석 분석의 대상이 되는 AI 시스템 | 딥러닝 신경망, 앙상블 트리 등 입력에 따른 예측 확률을 출력하는 블랙박스 모델 |
| 설명 범위 정의부 | 분석 관점 및 범위 결정 | 개별 예측 1건에 대한 국소 설명(Local) 또는 모델 전체 경향성인 전역 설명(Global) 설정 |
| 특성 기여도 분석기 | 변수별 예측 기여도 수치화 | 섀플리 값 기반 SHAP, 국소 선형 근사 기반 LIME으로 특성별 가중 기여도 계산 |
| 시각적 주의집중 맵 | 이미지/비전 영역의 활성화 시각화 | 합성곱 계층의 그래디언트 정보를 활용하여 모델이 집중한 픽셀 영역 히트맵 추출 |
| 반사실적 설명기 | 결과 반전을 위한 최소 변경 조건 제시 | "대출 승인을 위해 소득이 얼마 더 필요한가"와 같은 최소 개입 조건 역산 |
| 설명 산출물 시각화 | 사용자 맞춤형 설명 결과 렌더링 | 특성 중요도 막대그래프, 워터폴 차트, 결정 트리 등 직관적 UI 제공 |
| 품질 및 충실도 평가기 | 도출된 설명의 신뢰성 검증 | 대리 모델이 원본 예측을 왜곡 없이 반영하는 충실도 및 미세 노이즈에 대한 안정성 측정 |

## Ⅳ. 흐름도

```text
[설명 요청 및 대상 식별] (① 사용자 질의 입력 및 설명 대상 모델/예측 인스턴스 지정)
  │
  ▼
[설명 기법 선정] (② 데이터 형태 및 목적에 따라 SHAP, LIME, Grad-CAM 등 알고리즘 매핑)
  │
  ▼
[입력 섭동 및 예측 샘플링] (③ 입력 특성에 미세 노이즈를 주입하고 블랙박스 출력 변화 관측)
  │
  ▼
[판단 근거 및 기여도 산출] (④ 대리 모델 학습 또는 그래디언트 역전파를 통한 기여도 계산)
  │
  ▼
[충실도 검증 및 시각화] (⑤ 원본 모델과의 예측 일치도 검증 후 사용자 친화적 설명 UI 표출)
```

- 분기 결과: 특정 대출 거절 이유나 의료 판독 등 단일 사례에 대한 설명 요구는 국소 설명(Local: LIME/SHAP) 파이프라인으로 처리하고, 전사 모델 편향 검증이나 감사 목적은 전역 설명(Global: PDP/Global Surrogate) 경로로 분기함

## Ⅴ. 종류 및 비교

| 구분 | 국소 사후 설명 (Local Post-hoc) | 전역 사후 설명 (Global Post-hoc) | 본질적 해석 가능 모델 (Intrinsic) |
|:---|:---|:---|:---|
| 대표 기술 | LIME, Kernel SHAP, Grad-CAM | Partial Dependence Plot (PDP), Tree Surrogate | 선형 회귀, 로지스틱 회귀, 단일 의사결정나무 |
| 적용 목적 | 개별 예측 결과의 원인 규명 및 이의제기 대응 | 모델 전반의 의사결정 경계 및 특성 상호작용 감사 | 설계 단계부터 투명성이 요구되는 고위험 도메인 |
| 설명 단위 | 특정 인스턴스 1건의 특성 기여도 | 데이터셋 전체에 대한 특성별 평균 기여도 | 모델 파라미터(가중치) 자체의 직접 해석 |
| 장점 | 임의의 고성능 블랙박스 모델에 범용 적용 가능 | 거시적 모델 동작 특성 및 편향 식별 용이 | 완벽한 설명 충실도(Fidelity 100%) 보장 |
| 한계 | 전체 모델의 일반화된 동작을 파악하기 어려움 | 개별 인스턴스의 미시적 판단 이유 설명 불가 | 복잡한 비선형 데이터에 대한 예측 정확도 한계 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 사후 설명 모델의 충실도(Fidelity) 불일치 | 특성 삭제/가림(Feature Occlusion) 기반의 정확도 하락폭 검증 | 설명과 실제 모델 판단 간의 인과적 일치성 확보 |
| 입력 미세 변화에 따른 설명 불안정성 | 근방 샘플링 표본 수 확대 및 앙상블 기반 설명 정규화 적용 | 적대적 조작 공격 차단 및 설명의 재현성 극대화 |
| 사용자 역할별 인지적 설명 격차 | 데이터 과학자용 상세 지표와 비전문가용 자연어/반사실적 설명 분리 UI | 설명의 실효적 이해도 증진 및 법적 고지 의무 충족 |

## Ⅶ. 결론

- **기술 위상/발전**: 블랙박스 딥러닝의 불투명성을 해소하고 인간과 AI 간 협력적 신뢰를 구축하는 **신뢰할 수 있는 AI(Trustworthy AI)의 핵심 기저 기술**로 정립되었으며, LLM 사고의 사슬(Chain-of-Thought) 및 메커니즘 해석학(Mechanistic Interpretability)으로 고도화 중
- **실무 적용/통제**: 개별 이의제기에는 SHAP 기반 국소 설명을 제공하고 전사 거버넌스에는 전역 설명을 병행하며, 적대적 설명 조작 공격에 대비한 충실도 검증을 수행하여 **설명 신뢰성**과 **법적 설명요구권**을 동시 만족 필요
