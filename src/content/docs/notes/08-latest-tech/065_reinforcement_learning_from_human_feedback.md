## Ⅰ. 개요

- **정의**: 동일 프롬프트에 대한 다중 후보 응답을 인간 평가자가 비교 평가한 선호 데이터로 보상 모델(Reward Model)을 구축하고, 강화학습(PPO)을 통해 인간의 의도와 안전 기준(3H: Helpfulness, Honesty, Harmlessness)에 맞추어 언어 모델 정책을 최적화하는 AI 정렬(AI Alignment) 기술
- **배경 및 필요성**: 지도 파인튜닝(SFT)만으로는 인간이 작성한 모범 답안의 단순 모방에 그쳐 환각(Hallucination), 유해 표현(Toxicity), 비윤리적 편향 등 개방형 생성 환경에서의 부정렬(Misalignment) 문제를 통제하기 어려운 한계를 극복하고, 인간 선호 보상을 극대화하면서도 유창성을 유지하기 위해 도입

## Ⅱ. 특징

- **3단계 파이프라인**: 지도 파인튜닝(SFT) $\rightarrow$ 보상 모델(Reward Model, RM) 학습 $\rightarrow$ PPO 기반 강화학습 정렬의 체계적 프로세스
- **Bradley-Terry 선호 모델링**: $P(y_w \succ y_l | x) = \sigma(r(x, y_w) - r(x, y_l))$ 확률 모델을 기반으로 당선작($y_w$)과 낙선작($y_l$)의 보상 점수 차이를 최대화
- **KL 발산 페널티 ($\mathbb{D}_{\mathrm{KL}}$)**: 학습 정책이 원본 SFT 참조 모델의 언어 분포에서 과도하게 이탈하거나 모드 붕괴(Mode Collapse)되는 현상 방지
- **보상 해킹(Reward Hacking) 방어**: 보상 모델의 허점을 파고들어 길고 무의미하게 높은 점수를 유도하는 오버피팅을 억제하여 안정적 발화 보장

## Ⅲ. 구조 및 구성요소

```text
[RLHF 아키텍처]
├── [사전 적응 계층]
│   ├── [SFT 기본 정책 모델 (π_SFT)]
│   └── [인간 선호 응답 데이터셋 (x, yw, yl)]
├── [선호 모델링 계층]
│   └── [보상 모델 (Reward Model, r_θ)]
└── [강화학습 정렬 계층]
    ├── [학습 정책 모델 (Actor, π_φ)]
    ├── [가치 모델 (Critic, V_ψ)]
    ├── [동결 참조 모델 (Reference, π_ref)]
    └── [KL 발산 페널티 제어기 (β·D_KL)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| SFT 기본 정책 모델 | 도메인 지시 데이터 학습을 완료한 초기 응답 생성 정책 제공 |
| 인간 선호 데이터셋 | 동일 입력 $x$에 대한 당선작($y_w$)과 낙선작($y_l$)의 인간 비교 레이블 |
| 보상 모델 (RM) | Bradley-Terry 모델 기반 인간 선호도에 비례하는 스칼라 보상값 산출 |
| 학습 정책 모델 (Actor) | PPO 경사 상승을 통해 보상을 극대화하도록 파라미터를 갱신하는 언어 모델 |
| 가치 모델 (Critic) | 상태별 기대 보상을 추정하여 정책 그래디언트의 분산을 축소(Advantage) |
| 동결 참조 모델 & KL | 원본 SFT 모델과의 분포 거리($\mathbb{D}_{\mathrm{KL}}$)를 측정하여 과도한 정책 이탈 억제 |

## Ⅳ. 흐름도

```text
[RLHF 3단계 정렬 흐름] (진입: 기반 사전학습 모델 인입)
│
▼
[1단계 SFT] (① 고품질 지시-응답 쌍으로 지도 파인튜닝하여 초기 정책 π_SFT 구축)
│
▼
[2단계 RM 학습] (② 프롬프트별 다중 응답 생성 및 인간 선호 쌍(yw, yl) 수집 후 보상 모델 학습)
│
▼
[3단계 PPO 롤아웃] (③ 현재 정책 모델이 프롬프트에 대한 응답을 생성하고 RM 보상 및 KL 산출)
│
▼
[정책 및 가치 갱신] (④ 보상-β·KL 목적함수를 PPO 알고리즘으로 Actor/Critic 동시 최적화)
│
▼
[안전성 평가] (⑤ 적대적 레드팀 평가 및 3H(유용성, 정직성, 무해성) 기준 정렬 검증)
│
▼
[완료] (반환: 인간 가치관에 정렬된 신뢰성 높은 대화형 AI 배포)
```

- 분기 결과: 인간 정렬 기준 충족 시 **최종 정렬 모델 배포**를 진행하고, 보상 해킹 또는 언어 품질 저하 발생 시 **KL 계수($\beta$) 재조정 및 RM 데이터 보강**으로 회귀함

## Ⅴ. 종류 및 비교

| 구분 | SFT (지도 파인튜닝) | RLHF (인간 피드백 강화학습) | DPO (직접 선호 최적화) |
|:---|:---|:---|:---|
| 최적화 목표 | 토큰 단위 다음 단어 교차 엔트로피 | 인간 선호 보상 극대화 + KL 제약 | 선호쌍 확률비 직접 최대화 |
| 보상 모델 (RM) | 불필요 | 별도 보상 모델 필수 (별도 학습) | 불필요 (정책 자체에 내재화) |
| 필요 모델 수 | 1개 (단일 정책) | 4개 (Policy, Value, RM, Reference) | 2개 (Policy, Reference) |
| 온라인 샘플링 | 불필요 | 필수 (PPO 롤아웃 중 생성 반복) | 불필요 (오프라인 정적 데이터 학습) |
| 학습 복잡도 | 낮음 (단순 지도학습) | 극히 높음 (메모리 및 분산 학습 병목) | 중간 (하이퍼파라미터 안정적) |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 편향된 평가자로 인한 보상 왜곡 | 다양한 배경의 평가자 풀 구성 및 다자간 합의 지표 도입 | 보상 모델의 객관성 및 사회적 수용성 확보 |
| 모델이 비정상적 출력을 생성하는 보상 해킹 | 적응형 KL 페널티 계수 및 룰 기반 안전성 필터 결합 | 정렬 안정성 유지 및 비정상 발화 방지 |
| 4개 모델 동시 상주에 따른 극심한 GPU VRAM 부족 | DeepSpeed ZeRO-3 분산 메모리 및 LoRA 기반 정렬 결합 | 인프라 비용 절감 및 학습 확장성 확보 |

## Ⅶ. 결론

- **기술 위상/발전**: 단순 텍스트 완성을 넘어 인간의 윤리와 가치 기준(3H)에 정렬된 신뢰성 있는 대화형 AI를 구축하는 **RLHF 프레임워크**는 생성형 LLM 상용화의 핵심 이정표로 안착
- **실무 적용/통제**: 복잡한 대화 및 추론 정렬에는 **PPO 기반 RLHF**를 구축하고 자원 제약 환경에서는 **DPO/KTO 기반 경량화 기법**을 병용하여 학습 안정성과 경제적 효용 달성
