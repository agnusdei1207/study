## Ⅰ. 개요

- **정의**: 사전학습된 모델의 기본 가중치($W_0$)를 완전 동결하고, 가중치 변화량($\Delta W$)을 두 개의 저랭크 행렬 곱($\Delta W = B \times A$)으로 분해하여 최소 파라미터만 학습하는 PEFT 기법
- **배경 및 필요성**: 전체 모델 가중치를 학습하는 완전 미세조정(Full FT)의 막대한 GPU 메모리 및 체크포인트 스토리지 낭비를 해소하고, 과업 적응 시 파라미터 변화량이 낮은 내재적 차원(Low Intrinsic Dimension)을 갖는 특성을 활용하여 추가 추론 지연(Zero Latency) 없이 도메인 특화 모델을 구축하기 위해 도입

## Ⅱ. 특징

![LoRA 랭크별 학습 매개변수 증가](/study/diagrams/lora-rank-parameter-growth.svg)

- **수학적 공식화**: 입력 $x$에 대해 출력 $h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} B A x$로 계산하며, 초기화 시 $A \sim \mathcal{N}(0, \sigma^2)$, $B = 0$으로 두어 학습 시작점의 변화량을 0으로 유지
- **무지연 가중치 병합**: 추론 배포 시 $W = W_0 + \frac{\alpha}{r} B A$로 원본 가중치에 직접 융합하여 추가 연산 지연 완전 제거
- **파라미터 및 스토리지 절감**: 학습 매개변수를 99% 이상 감축하며 수 메가바이트(MB) 단위의 경량 어댑터로 다중 태스크 서비스 지원

## Ⅲ. 구조 및 구성요소

```text
[LoRA 아키텍처]
├── [선형 변환 계층]
│   ├── [동결 경로 (W₀)]
│   └── [대상 모듈 (Q/K/V/O, FFN 선형층)]
├── [저랭크 적응 계층]
│   ├── [저랭크 행렬 A (d×r, Gaussian)]
│   ├── [저랭크 행렬 B (r×k, Zero)]
│   └── [하이퍼파라미터 (Rank r, Alpha α)]
└── [배포 서빙 계층]
    └── [어댑터 파일 (Adapter Weights)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| 동결 경로 W₀ | 사전학습된 기반 선형 변환 및 원본 일반화 지식 보존 |
| 저랭크 행렬 A, B | $B \times A$ 행렬 곱으로 저차원 가중치 변화량($\Delta W$) 산출 |
| 랭크·스케일(r, α) | 적응 표현 용량($r$) 및 가중치 변화량 반영 비율($\alpha/r$) 조절 |
| 대상 모듈 | 저랭크 경로가 주입되는 어텐션 및 피드포워드 선형 계층 |
| 어댑터 파일 | 학습 완료된 경량 행렬 및 메타데이터 독립 저장 및 동적 교체 |

## Ⅳ. 흐름도

```text
[LoRA 학습 및 서빙 흐름] (진입: 도메인 특화 요구사항 접수)
│
▼
[구조 설계] (① 주입 대상 모듈(Attention/FFN) 및 랭크 r, 스케일 α 결정)
│
▼
[모듈 초기화] (② 가중치 W₀ 동결 및 행렬 A(정규분포), B(영행렬) 초기화)
│
▼
[변화량 역전파] (③ 입력 x에 대해 W₀x + (α/r)BAx 순전파 후 A, B만 경사하강 갱신)
│
▼
[서빙 결정] (④ 단일 전용 모델 가중치 병합 또는 멀티 테넌트 어댑터 분리 배포)
│
▼
[완료] (반환: 무지연 전용 모델 또는 멀티 어댑터 서비스 가동)
```

- 분기 결과: 단일 서비스는 **가중치 영구 병합($W = W_0 + \frac{\alpha}{r}BA$)**으로 추론 속도를 극대화하고, 다중 서비스는 **어댑터 분리 동적 라우팅**을 적용함

## Ⅴ. 종류 및 비교

| 구분 | 전체 미세조정 (Full FT) | Adapter | LoRA |
|:---|:---|:---|:---|
| 갱신 대상 | 원본 가중치 전체 ($100\%$) | 층 사이 삽입된 직렬 소형 모듈 | 병렬 분기된 저랭크 행렬 ($A, B$) |
| 학습 파라미터 | 모델 전체 (수십억~수천억) | 전체의 약 $1\sim3\%$ | 전체의 약 $0.01\sim0.1\%$ |
| 추가 추론 지연 | 없음 | 직렬 병목 모듈로 인한 지연 발생 | 가중치 병합 시 추가 지연 전무 (0ms) |
| 서빙 유연성 | 모델별 대용량 가중치 독립 배포 | 어댑터 분리 서빙 가능 | 수 MB 어댑터 동적 스위칭 용이 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 낮은 랭크($r$) 설정에 따른 표현 용량 부족 | 랭크별 검증 손실 비교 및 All-Linear 주입 확대 | 복잡 도메인 과업 적응력 및 표현력 확보 |
| FFN 계층 미적용으로 인한 성능 정체 | Attention(Q, K, V, O)과 MLP 계층 전면 적용 | Full FT 수준에 근접한 과업 성능 달성 |
| 병합(Merge) 전후 부동소수점 오차 발생 | 동일 정밀도(FP16/BF16) 유지 및 병합 검증 회귀 테스트 | 추론 배포 시 출력 일치성 및 무결성 보장 |

## Ⅶ. 결론

- **기술 위상/발전**: 초대규모 LLM의 실무 도메인 특화 미세조정에서 사실상의 표준으로 안착한 **LoRA 기술**은 양자화와 결합한 QLoRA 및 가중치 분해형 DoRA로 진화
- **실무 적용/통제**: 단일 태스크 서빙은 **무지연 가중치 병합**을 채택하고 다중 테넌트 환경은 **S-LoRA 기반 동적 스케줄링**을 구성하여 자원 효율성 및 서빙 민첩성 극대화
