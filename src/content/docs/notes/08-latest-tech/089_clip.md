## Ⅰ. 개요

- **정의**: 대규모 (이미지-텍스트 설명) 쌍에 대조 학습(Contrastive Learning)을 적용하여 이미지 인코더와 텍스트 인코더의 출력을 동일한 공유 임베딩 공간에 정렬하는 **CLIP(Contrastive Language-Image Pre-training)**
- **배경 및 필요성**: 기존 지도학습 기반 비전 모델은 고정된 N개 카테고리만 분류 가능하여 새 클래스 추가 시 재학습 비용이 막대하고 제로샷 확장성이 전무한 한계가 존재함에 따라, 4억 개 이상의 웹 이미지-텍스트 쌍을 대조 학습하여 공유 공간에 정렬함으로써 별도 재학습 없이 자연어 프롬프트 매칭 기반 제로샷 분류(Zero-shot Classification)와 텍스트-이미지 간 양방향 교차 모달 검색을 실현하기 위해 필요

## Ⅱ. 특징

- **대조 학습**: 배치 내 실제 매칭 쌍(대각선)의 코사인 유사도는 최대화하고, 비매칭 쌍(비대각선)의 유사도는 최소화하는 InfoNCE 손실 함수 적용
- **이중 인코더 구조**: ViT 이미지 인코더와 Transformer 텍스트 인코더가 독립적으로 작동하여 이미지와 텍스트 임베딩을 사전 계산 및 캐싱 가능
- **뛰어난 제로샷 전이**: "a photo of a {label}" 형태의 프롬프트를 텍스트 인코더에 통과시켜 임의의 클래스에 대해 추가 훈련 없이 분류 수행

## Ⅲ. 구조 및 구성요소

```text
[CLIP System]
├── [이중 인코더 계층]
│   ├── [이미지 인코더 (ViT)]
│   └── [텍스트 인코더 (Text Transformer)]
├── [공동 임베딩 계층]
│   └── [공동 임베딩 공간 (Joint Embedding)]
└── [유사도/판별 계층]
    ├── [유사도·온도 계수 (Cosine/Temperature)]
    └── [제로샷 판별기 (Zero-shot Classifier)]
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 계층적 하위 관계를 의미함

| 구성요소 | 책임 |
|:---|:---|
| 이미지 인코더 | 비전 트랜스포머(ViT) 기반 이미지의 정규화된 시각 밀집 벡터 생성 |
| 텍스트 인코더 | 트랜스포머 기반 자연어 프롬프트의 정규화된 텍스트 밀집 벡터 생성 |
| 공동 임베딩 공간 | 시각 벡터와 텍스트 벡터 간 코사인 유사도 연산이 가능한 동일 차원 공간 |
| 유사도·온도 계수 | 코사인 유사도 계산 및 학습 가능한 온도 파라미터($\tau$)를 통한 스케일링 |
| 제로샷 판별기 | 입력 이미지 벡터와 후보 클래스 텍스트 벡터 간 유사도 소프트맥스 판별 |

## Ⅳ. 흐름도

```text
[이중 인코더] (① $N$개 이미지 및 $N$개 텍스트 프롬프트 독립 임베딩 생성)
│
▼
[유사도 계산기] (② $N \times N$ 코사인 유사도 행렬 계산 및 온도 파라미터 적용)
│
▼
[대조 손실 엔진] (③ 정답 대각선 쌍 확률 최대화 및 오답 비대각선 최소화 InfoNCE 손실 역전파)
│
▼
[제로샷 판별기] (④ 테스트 이미지와 후보 레이블 텍스트 벡터 간 유사도 최고점 클래스 분류)
```

- 분기 결과: 정답 클래스 텍스트 벡터와의 유사도 최고점 매칭 시 제로샷 분류 성공, 도메인 특화 용어 미인식 시 프롬프트 앙상블 또는 선형 프로브 적용

## Ⅴ. 종류 및 비교

| 구분 | CLIP (이중 인코더 대조학습) | 지도 비전 모델 (ResNet/ViT) | 생성형 VLM (LLaVA/BLIP-2) |
|:---|:---|:---|:---|
| 적용 기준 | 제로샷 이미지 분류, 크로스모달 검색 | 고정 카테고리 고정밀 폐쇄 루프 분류 | 시각적 질의응답(VQA), 이미지 설명 생성 |
| 핵심 특징 | 이미지-텍스트 공동 임베딩 코사인 유사도 | 소프트맥스 기반 고정 클래스 확률 분포 | 시각 토큰 조건부 자기회귀 텍스트 생성 |
| 한계 | 세부 위치/공간 추론 및 자유 생성 불가 | 새로운 클래스 추가 시 전면 재학습 필수 | 모델 규모 방대, 추론 지연 및 환각 발생 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 프롬프트 표현에 따른 예측 편차 | 80여 개 템플릿 기반 프롬프트 앙상블(Prompt Ensembling) 적용 | 프롬프트 문구 민감도 완화 및 분류 정확도 1~5% 향상 |
| 의료·산업 등 특화 도메인 제로샷 성능 저하 | 고정 인코더 후단에 경량 선형 분류기(Linear Probe) 또는 LoRA 미세조정 | 소량 데이터로 도메인 전이 성능 극대화 |
| 대규모 이미지 코퍼스 대상 실시간 검색 지연 | L2 정규화 벡터의 내적 기반 HNSW 벡터 DB 인덱싱 적용 | 밀리초(ms) 단위 초고속 크로스모달 검색 실현 |

## Ⅶ. 결론

- **기술 위상/발전**: 시각과 자연어를 동일한 임베딩 공간으로 통합 정렬하여 제로샷 비전 인식과 멀티모달 AI의 폭발적 발전을 견인한 기반 아키텍처
- **실무 적용/통제**: 프롬프트 앙상블 필수 적용, 특화 도메인 선형 프로빙 결합, 벡터 DB 연계를 통해 제로샷 전이력과 초고속 검색 성능 확립
