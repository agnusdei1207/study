## Ⅰ. 개요

- **정의**: 심층 신경망의 과잉 매개변수 중 중요도(Importance Score)가 낮은 가중치, 채널, 어텐션 헤드, 레이어를 선별 제거하여 모델을 슬림화하는 희소 최적화(Sparsity Optimization) 기술.
- **배경 및 필요성**:
  - **과잉 매개변수 잉여성 제거**: 신경망 학습 수렴을 위해 투입된 수많은 파라미터 중 실제 추론 기여도가 0에 가까운 잉여 가중치 제거.
  - **연산 복잡도(FLOPs) 삭감**: 불필요한 부동소수점 곱셈 연산과 메모리 버스 이동을 원천 차단하여 추론 가속화.
  - **하드웨어 희소 가속(Sparse Acceleration)**: 최신 하드웨어(NVIDIA Sparse Tensor Core 등)와의 정합을 통한 실제 물리적 실행 시간(Wall-clock Time) 단축.

## Ⅱ. 핵심 특징

- **중요도 평가 기반 절제**: 가중치 절대 크기(L1/L2 Norm), 그래디언트 민감도(Taylor Expansion), 활성화 영향도에 따른 객관적 점수화.
- **점진적 희소화(Iterative Pruning)**: 한 번에 대량 절제하지 않고 소량 가지치기와 미세조정(Fine-Tuning)을 반복하여 정확도 손실 완벽 복구.
- **희소성 구조 분화**: 개별 가중치를 제거하는 비구조적(Unstructured), 하드웨어 친화적 N:M 반구조적(Semi-structured), 채널/헤드 자체를 삭제하는 구조적(Structured) 기법 존재.
- **실제 지연 중심 평가**: 이론적 FLOPs 감소가 전용 희소 커널 미지원으로 인해 상쇄되지 않도록 실측 하드웨어 지연 검증 필수.

## Ⅲ. 구조 및 구성요소

```text
[모델 가지치기(Model Pruning) 파이프라인]
├── [중요도 평가기 (Importance Evaluator)]
│   ├── 가중치 절대 크기 기반 점수화 (L1/L2 Magnitude)
│   └── 1차/2차 그래디언트 민감도 분석 (Taylor Expansion)
├── [희소도 제어기 (Sparsity Controller)]
│   ├── 비구조적 희소성 제어 (Unstructured Sparsity)
│   ├── 세미 구조적 희소성 제어 (2:4 / N:M Sparsity)
│   └── 구조적 제거 제어 (Structured: Channel/Head/Layer)
├── [가지치기 변환기 (Pruning Mask Engine)]
│   ├── 이진 마스크(Binary Mask) 생성 및 가중치 영(0)화
│   └── 텐서 차원 물리적 축소 및 그래프 리팩토링
├── [품질 복구기 (Accuracy Recovery Engine)]
│   ├── 점진적 반복 미세조정 (Iterative Fine-tuning)
│   └── 지식 증류 연계 가중치 복원
└── [하드웨어 실행 커널 (Sparse Execution Kernel)]
    ├── 엔비디아 희소 텐서 코어 (Sparse Tensor Core)
    └── 밀집 텐서(Dense BLAS) 압축 커널
```

- 선들의 의미: 실선(──)과 가지선(├──, └──)은 모델 가지치기 최적화 파이프라인의 상위 단계와 세부 구성요소 간 계층적 포함 관계를 나타낸다.

| 구성요소 | 역할 및 세부 기능 |
|:---|:---|
| 중요도 평가기 | 가중치 크기 및 그래디언트 민감도 기반 파라미터별 기여도 점수화 |
| 희소도 제어기 | 비구조적, 2:4 N:M 세미 구조적, 채널/헤드 구조적 가지치기 전략 수립 |
| 가지치기 변환기 | 제거 마스크 생성 및 텐서 차원 축소를 통한 물리적 파라미터 절제 |
| 품질 복구기 | 점진적 미세조정(Fine-Tuning)을 통해 가지치기로 인한 정확도 손실 회복 |
| 하드웨어 실행 커널 | 희소 텐서 코어(Sparse Tensor Core) 기반 실제 하드웨어 추론 시간 단축 |

## Ⅳ. 흐름도

```text
[기준 모델 로드 및 기준 성능 측정] (① 원본 모델의 과업 정확도 및 계층별 가중치 분포 분석)
       │
       ▼
[파라미터 중요도 점수 산출] (② 가중치 크기 및 그래디언트 민감도 기반 제거 후보 선별)
       │
       ▼
[희소 마스크 적용 및 물리적 절제] (③ 목표 희소도에 따라 가중치 영(0)화 또는 텐서 차원 축소)
       │
       ▼
[점진적 파인튜닝 미세조정] (④ 학습 데이터를 투입하여 잔존 가중치를 재학습하고 손실된 정확도 복원)
       │
       ▼
[목표 장치 실측 검증 및 배포] (⑤ 실제 하드웨어 런타임에서 추론 지연 시간 및 품질 검증 후 배포)
```

- 분기 결과: 목표 정확도 및 희소도 도달 시 배포 완료, 품질 회복 미흡 시 희소도 단계를 낮추어 재학습 루프 반복.

## Ⅴ. 종류 및 비교

| 비교 항목 | 비구조적 가지치기 (Unstructured) | 반구조적 가지치기 (Semi-Structured) | 구조적 가지치기 (Structured) |
|:---|:---|:---|:---|
| 제거 단위 | 임의 위치의 개별 단일 가중치 | 고정 블록 내 정규 패턴 (예: 4개 중 2개 0) | 필터, 채널, 어텐션 헤드, 전체 레이어 |
| 모델 정확도 보존 | 최상 (불필요한 가중치만 정밀 제거) | 우수 (하드웨어 제약 내 정밀도 유지) | 중간 (채널 단위 제거로 품질 민감도 큼) |
| 하드웨어 가속성 | 전용 희소 커널(CSR/CSC) 없으면 가속 불가 | NVIDIA Ampere 이상 Sparse Tensor Core 전용 가속 | 일반 표준 BLAS 밀집 연산 커널로 즉각 가속 |
| 텐서 형상 변화 | 원래 텐서 형상 유지 (내부에 0 다수 존재) | 원래 텐서 형상 유지 (압축 메타데이터 필요) | 텐서 차원(Matrix Shape) 자체가 물리적 축소 |
| 추천 환경 | 압축 저장용 아카이빙, 특수 희소 가속기 | 최신 엔터프라이즈 GPU 서빙 환경 | 모바일, 임베디드, 범용 CPU/GPU 서빙 환경 |

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 급격한 희소화로 인한 과업 정확도 급락 | 점진적 스케줄링(Iterative Pruning) 및 지식 증류 연계 파인튜닝 | 목표 희소도 달성 시에도 원본 수준 정확도 유지 |
| 비구조적 희소화 후 인덱스 오버헤드로 실측 지연 미개선 | 타깃 하드웨어 지원에 맞춘 2:4 반구조적 또는 구조적 가지치기 채택 | 메모리 대역폭 절감 및 실질적 하드웨어 속도 향상 |
| 구조적 가지치기 시 잔차 연결(Residual) 형상 불일치 | 스킵 커넥션과 연결된 채널 쌍의 동기화 절제 및 정합성 검증 | 네트워크 텐서 차원 충돌로 인한 런타임 에러 방지 |

## Ⅶ. 결론

- **기술 위상/발전**: 신경망 내부의 파라미터 잉여성을 제거하여 모델을 슬림화하고 하드웨어 처리량을 극대화하는 희소 컴퓨팅의 핵심 기반 기술로 정립
- **실무 적용/통제**: 타깃 하드웨어가 일반 프로세서인 경우 구조적 프루닝을, 최신 텐서 코어 가속기인 경우 2:4 반구조적 패턴을 적용하며, 점진적 미세조정을 결합하여 무결한 가속 파이프라인 구현
