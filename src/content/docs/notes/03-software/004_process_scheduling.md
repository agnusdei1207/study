## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **CPU 스케줄링(Process Scheduling)**: 준비 큐에 대기 중인 프로세스들 중 CPU를 할당할 대상을 결정하는 운영체제 커널의 핵심 알고리즘.
- **선점/비선점(Preemption/Non-preemption)**: 강제로 CPU를 회수할 수 있는 선점형과 스스로 CPU를 반납할 때까지 기다리는 비선점형 방식.

</details>

- 정의/개념: **선점/비선점** 정책과 타임 퀀텀으로 준비 큐 프로세스의 CPU 점유 순서를 정하는 커널의 **CPU 스케줄링** 기법
- 배경/필요성: 선착순(FCFS)만으로는 긴 CPU 버스트 하나가 뒤의 짧은 대화형 작업을 모두 기다리게 하는 호위 효과가 생기므로, 타이머 선점과 우선순위·퀀텀 정책을 커널에 두어 응답시간과 처리량을 배분하는 스케줄러가 필요

#### 한줄 요약
- 응답시간과 공정성 기준으로 준비 큐의 CPU 순서를 결정한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **호위 효과(Convoy Effect)**: CPU 버스트가 긴 프로세스 뒤에 짧은 작업들이 밀려 시스템 전체 평균 대기시간이 급증하는 현상.
- **기아 현상(Starvation)**: 우선순위가 낮은 프로세스가 고우선순위 작업에 밀려 무한정 CPU를 할당받지 못하는 상태.
- **타임 퀀텀(Time Quantum)**: 선점형 스케줄러가 프로세스에 한 번에 배정하는 최대 CPU 연속 시간으로, 만료 시 타이머 인터럽트가 선점을 일으켜 준비 큐 뒤로 보내는 단위.

</details>

- **선점/비선점** 방식의 CPU 회수 시점 구분
- **타임 퀀텀**에 따른 문맥 전환 비용·응답시간 상충
- 대기 시간 기반 **에이징**으로 기아 현상 완화

#### 한줄 요약
- 선점형은 응답성이 우수하고, 비선점형은 오버헤드가 적으나 호위 효과가 발생할 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **vruntime(가상 실행 시간)**: 리눅스 CFS에서 프로세스의 실제 실행 시간에 우선순위 가중치를 반영하여 산출하는 공정 배분 척도.
- **레드-블랙 트리(Red-Black Tree)**: CFS 스케줄러가 $O(\log n)$ 시간에 최소 vruntime 프로세스를 탐색하기 위해 사용하는 자가 균형 이진 탐색 트리.

</details>

```text
[CPU 스케줄링 서브시스템]
  │
  ├─ [준비 큐] (실행 대기 PCB 집합 보관)
  │
  ├─ [커널 스케줄러] (알고리즘 정책 및 대상 선정)
  │
  ├─ [디스패처] (문맥 복원 및 CPU 제어권 이양)
  │
  └─ [하드웨어 타이머] (타임 퀀텀 만료 인터럽트 발생)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 준비 큐 | 실행을 기다리는 PCB 집합 보관 |
| 커널 스케줄러 | 정책에 따라 차기 실행 대상 선정 |
| 디스패처 | 선택된 문맥 복원·CPU 제어권 이양 |
| 하드웨어 타이머 | **타임 퀀텀** 만료 인터럽트 발생 |

#### 한줄 요약
- 정책을 정하는 스케줄러와 실제 교체를 수행하는 디스패처가 분리돼 있어 큐 선택 규칙만 바꿔도 시스템 성격이 달라지며, 하드웨어 타이머가 그 규칙을 강제하는 유일한 선점 수단이 된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **에이징(Aging)**: 대기 시간이 길어질수록 프로세스의 우선순위를 점진적으로 높여 기아를 방지하는 기법.

</details>

```text
준비 큐에서 대기 중인 프로세스들에 에이징(Aging) 적용
        │
   스케줄러가 알고리즘 정책(최소 vruntime / 최단 작업 등)으로 프로세스 선정
        │
   디스패처가 문맥을 복원하고 타임 슬라이스를 부여하여 CPU 이양
        │
   명령어 실행 중
   ┌────┴───────────────────────────┐
타임 슬라이스 만료  I/O 요청 또는 자발 반납  실행 완료 (exit)
   │                  │                  │
타이머 선점 발생    대기 큐로 전이      프로세스 종료
(문맥 저장 후      (Blocked)          (자원 해제)
준비 큐 복귀)
```

분기 결과: 선점 만료 경로는 퀀텀마다 문맥 저장·복귀 비용이 반복되고, I/O 반납 경로는 대기 큐에 머무는 동안 다른 프로세스가 CPU를 쓰므로 전환 비용 대신 대기 시간이 든다.

#### 한줄 요약
- 타임아웃 선점과 I/O 대기는 CPU를 되찾는 조건이 다르므로, 전자는 공정성을 위해 전환 비용을 치르고 후자는 대기 시간만큼 다른 프로세스에 자리를 내준다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **다단계 피드백 큐(Multi-Level Feedback Queue, MLFQ)**: CPU 버스트가 길면 하위 큐로 강등하고 I/O 바운드는 상위 큐로 유지하는 적응형 스케줄러.
- **완전 공정 스케줄러(Completely Fair Scheduler, CFS)**: vruntime이 가장 작은 프로세스를 우선 선택하는 리눅스 표준 완전 공정 스케줄러.

</details>

| 배치 스케줄러 | FCFS | SJF/SRTF |
|:---|:---|:---|
| 적용 기준 | 도착 순서 중심의 단순 배치 | 실행 시간 예측 가능한 배치 작업 |
| 핵심 특징 | FIFO 순서로 비선점 실행 | 최단 CPU 버스트 우선 실행 |
| 한계 | 장기 작업의 **호위 효과** | 버스트 예측 오차·**기아 현상** |

| 시분할 스케줄러 | RR | MLFQ | CFS |
|:---|:---|:---|:---|
| 적용 기준 | 균등 응답의 대화형 작업 | CPU·I/O 혼합의 적응형 작업 | 가중치 기반 범용 리눅스 부하 |
| 핵심 특징 | **타임 퀀텀** 순환 | **MLFQ** 강등·부스트 큐 이동 | **레드-블랙 트리**의 최소 **vruntime** 우선 |
| 한계 | 짧은 퀀텀의 문맥 전환 비용 | 큐·부스트 튜닝 복잡도 | 지연 기한의 직접 보장 불가 |

#### 한줄 요약
- 대화형 공정성은 CFS/MLFQ, 단순 배치는 FCFS, 이론상 최단 대기시간은 SJF를 채택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **나이스 값(Nice Value)**: 리눅스에서 프로세스의 우선순위 가중치를 -20(최고)부터 19(최저)까지 조정하는 설정값.
- **SCHED_FIFO/RR**: 리눅스 실시간 스케줄링 클래스로, 일반 CFS 작업보다 항상 먼저 실행되며 FIFO는 자발 반납까지, RR은 타임 슬라이스 단위로 같은 우선순위 작업을 순환시키는 정책.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 우선순위 정책에서 **기아 현상** | 대기 시간 기반 **에이징** 적용 | 장기 대기 해소·공정성 향상 |
| 짧은 퀀텀으로 문맥 전환 급증 | 응답시간·처리량 기반 퀀텀 조정 | 선점 비용 감소·CPU 처리율 향상 |
| CPU 집약 작업의 코어 독점 | **나이스 값**·CPU 쿼터 조정 | 가중치 기반 CPU 시간 배분 |
| 실시간 작업의 마감시간 위반 | **SCHED_FIFO/RR** 격리 적용 | 우선순위 기반 실행 결정성 확보 |

#### 한줄 요약
- 공정성과 결정성은 같은 CPU를 두고 경쟁하므로, 에이징·퀀텀 조정으로 일반 작업의 기아를 막되 마감이 있는 작업은 별도 실시간 정책으로 분리해 서로의 간섭을 끊는다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **가장 빠른 조기 가상 데드라인 우선(Earliest Eligible Virtual Deadline First, EEVDF)**: 리눅스 6.6 커널부터 기본 적용되어 지연시간 민감도와 처리량 가중치를 지연 허용치로 통합 제어하는 최신 스케줄러.
- **실시간 스케줄링 클래스(Real-Time Scheduling Class)**: 일반 공정 스케줄러보다 절대적인 선점 우선권을 부여받아 실행 결정성을 보장하는 커널 스케줄링 정책군.

</details>

- 범용 시분할 스케줄링은 가상 실행 시간 기반 CFS에서 지연시간 결정성을 보강한 **EEVDF**로 진화하며 이종 멀티코어 환경에 최적화되는 추세
- 실무에서는 cgroups 기반의 CPU 대역폭 쿼터로 컨테이너 간 간섭을 제어하고, 마감시간 준수가 필수적인 연산은 **실시간 스케줄링 클래스**로 격리 배정하는 이원화 아키텍처 수립 필요

#### 한줄 요약
- 범용 부하는 EEVDF와 cgroups 대역폭으로 통제하고 지연 극소화 작업은 실시간 스케줄링 클래스로 분리 격리하는 계층화 설계가 핵심이다.
