## 공통 표기 규칙

- **토픽**: 문항 하나의 주제가 될 수 있는 단위이며 노트 1개에 대응함. 파일명은 `{3자리 번호}_{영문 snake_case}.md`.
- **등급**: A(깊게) / B(골격) / C(핵심).
- **중요도**: 0~100%. 학습 순서를 정하는 상대 가중치.
- **흡수한 하위 키워드**: 부모 토픽 노트의 `딸려 나오는 하위 토픽` 표나 본문에 포함할 항목(단독 노트 미작성).
- **근거**: 공식 기출 회차, 타 종목 기출 회차(보조), 최신 트렌드/정책, 핵심 기초.
